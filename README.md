# 启硕 PrimeTop

启硕 PrimeTop 是一款面向幼儿至高中阶段学生的一站式全学段 AI 辅助学习软件，定位为移动端智能助学 APP。项目围绕国内中小学教材课标和真实学习场景，整合 AI 大模型、同步教材资源、学习知识库与用户学习数据系统，为学生提供智能辅导、知识点讲解、习题答疑、错题整理、同步课堂学习、学情分析和学习规划等能力。

## 项目定位

- 中文名称：启硕
- 英文名称：PrimeTop
- 产品形态：移动端 APP 为主，适配 Android 与 iOS
- 后续拓展：Web 端、微信小程序、教师端、家长端、学校合作版本
- 服务对象：幼儿园、小学、初中、高中学生，以及家长、教师和教育管理者
- 核心理念：启智启蒙起步，深耕学识成才，AI 轻量化高效助学

## 核心能力

- AI 智能辅导：支持多轮问答、知识点讲解、学习建议和适龄化表达。
- 拍照搜题与习题答疑：通过 OCR 和大模型能力识别题目并生成分步解析。
- 同步课堂学习：对接国内主流教材版本，按年级、学科、章节组织学习内容。
- 拼音识字启蒙：面向幼儿和小学低年级提供拼音、识字、发音和朗读练习。
- 错题整理：支持错题收录、错因分析、分类管理和复习提醒。
- 学情分析：基于学习记录、答题结果和错题数据生成能力画像。
- 学习规划：按目标、学段、基础和可用时间生成可执行学习计划。
- 考点梳理：面向中考、高考场景进行知识图谱、考点清单和专题复习。
- 作文辅导：提供审题、提纲、素材、润色和批改反馈。
- 理科解题与文科背诵：覆盖数理化生推理讲解，以及语文、英语、政史地记忆辅助。

## 适配学段

| 学段 | 重点场景 |
| --- | --- |
| 幼儿启蒙 | 拼音识字、基础认知、语音陪练、亲子共学 |
| 小学阶段 | 同步课堂、作业辅导、基础知识巩固、作文启蒙 |
| 初中阶段 | 全科答疑、错题提升、考点梳理、中考备考 |
| 高中阶段 | 深度讲解、理科推导、文科背诵、高考冲刺 |

## 技术方向

项目规划采用以下技术能力建设整体产品体系：

- 接入主流 AI 大模型 API，支持通用问答、复杂推理、多模态识别和语音能力。
- 搭建独立学习知识库，通过 RAG 检索增强生成，提升回答与教材课标的匹配度。
- 对接国内同步教材资源，建立学段、年级、学科、教材版本、章节和知识点映射。
- 构建用户学习数据系统，沉淀学习记录、错题数据、学习计划和能力画像。
- 建设内容管理后台、AI 配置后台、运营看板和安全审核体系。

## 建议开发路径

1. 完成移动端 APP 原型和核心页面流程。
2. 搭建用户体系、AI 问答、拍题答疑、错题本和同步课堂基础能力。
3. 接入大模型 API、OCR、内容安全审核和基础知识库。
4. 建设管理后台，用于教材、知识点、Prompt、模型配置和运营数据管理。
5. 以 MVP 版本验证核心学习闭环，再逐步扩展作文辅导、学情分析、学习规划、考点梳理和多端能力。
