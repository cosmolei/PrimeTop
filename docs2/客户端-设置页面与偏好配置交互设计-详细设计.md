# 客户端 - 设置页面与偏好配置交互设计

## 1. 文档概述

### 1.1 文档目的

本文档详细设计 PrimeTop 客户端"设置"页面的 UI 架构、交互流程、组件规范及与偏好系统的数据衔接方案，使开发人员可直接据此实现完整的设置模块。

### 1.2 范围

- 设置页面整体布局与分组架构
- 各设置项的交互控件规范（开关、选择器、滑块等）
- 二级/三级设置子页面设计
- 设置项与 `客户端用户偏好设置与学习环境个性化系统` 的数据映射
- 分龄适配策略（幼儿/小学/初中/高中）
- 权限管控设置与家长中心联动
- 离线可用性与缓存同步

class SettingSection extends StatelessWidget {

### 3.3 SettingTile 组件族

```dart
/// 设置项基础类型
enum SettingTileType {
  navigation,   // 点击跳转子页面（右侧箭头 >）
  toggle,       // 开关切换（右侧 Switch）
  slider,       // 滑块调节（右侧 Slider）
  selection,    // 单选列表（弹窗选择）
  action,       // 点击执行操作（无额外控件）
  info,         // 仅展示信息（不可点击）
}

/// 通用设置项 Widget
class SettingTile extends StatelessWidget {
  final IconData? icon;
  final String title;
  final String? subtitle;      // 右侧描述文字
  final String? badge;         // 状态标签（如"已开启"）
  final SettingTileType type;
  final bool value;            // toggle/slider 当前值
  final ValueChanged<bool>? onChanged;
  final VoidCallback? onTap;
  final bool showDivider;      // 是否显示底部分割线
  final bool destructive;      // 是否为危险操作（红色）
  final Widget? trailing;      // 自定义右侧控件

  const SettingTile({
    super.key,
    this.icon,
    required this.title,
    this.subtitle,
    this.badge,
    this.type = SettingTileType.navigation,
    this.value = false,
    this.onChanged,
    this.onTap,
    this.showDivider = true,
    this.destructive = false,
    this.trailing,
  });

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final textColor = destructive
        ? theme.colorScheme.error
        : theme.colorScheme.onSurface;

    return InkWell(
      onTap: type == SettingTileType.toggle ? null : onTap,
      child: Padding(
        padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 12),
        child: Row(
          children: [
            if (icon != null)
              Padding(
                padding: const EdgeInsets.only(right: 12),
                child: Icon(icon, size: 20, color: textColor),
              ),
            Expanded(
              child: Text(title,
                style: theme.textTheme.bodyMedium?.copyWith(color: textColor),
              ),
            ),
            _buildTrailing(context),
          ],
        ),
      ),
    );
  }

  Widget _buildTrailing(BuildContext context) {
    if (trailing != null) return trailing!;
    switch (type) {
      case SettingTileType.navigation:
        return Row(
          mainAxisSize: MainAxisSize.min,
          children: [
            if (subtitle != null)
              Text(subtitle!,
                style: Theme.of(context).textTheme.bodyMedium?.copyWith(
                  color: Theme.of(context).colorScheme.onSurfaceVariant,
                ),
              ),
            if (badge != null)
              Container(
                padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
                decoration: BoxDecoration(
                  color: Theme.of(context).colorScheme.primaryContainer,
                  borderRadius: BorderRadius.circular(4),
                ),
                child: Text(badge!,
                  style: Theme.of(context).textTheme.labelSmall,
                ),
              ),
            const SizedBox(width: 4),
            const Icon(Icons.chevron_right, size: 18),
          ],
        );
      case SettingTileType.toggle:
        return Switch(value: value, onChanged: onChanged);
      case SettingTileType.slider:
        return SizedBox(
          width: 120,
          child: Slider(value: value ? 1.0 : 0.0, onChanged: (_) {}),
        );
      case SettingTileType.selection:
      case SettingTileType.action:
      case SettingTileType.info:
        if (subtitle != null) {
          return Text(subtitle!,
            style: Theme.of(context).textTheme.bodyMedium?.copyWith(
              color: Theme.of(context).colorScheme.onSurfaceVariant,
            ),
          );
        }
        return const SizedBox.shrink();
    }
  }
}
```

#### 4.1.2 应用锁设置

交互流程：

1. 用户切换应用锁开关 → ON
2. 弹出生物识别对话框（指纹/面容）
3. 验证通过后，弹出备用 PIN 设置（4-6位数字）
4. 保存设置到本地安全存储（`flutter_secure_storage`）
5. 后续启动/从后台恢复时触发生物识别

**应用锁触发时机：**

| 场景 | 触发条件 | 行为 |
|------|---------|------|
| 冷启动 | appLockEnabled=true | 显示锁屏页面 |
| 热启动（后台>30s） | appLockEnabled=true | 显示锁屏页面 |
| 进入设置-账号安全 | 总是 | 无需二次验证 |
| 进入家长管控 | 总是 | 需要PIN/生物识别 |

```dart
/// 应用锁服务
class AppLockService {
  static const _keyEnabled = 'app_lock_enabled';
  static const _keyPin = 'app_lock_pin';
  static const _keyMethod = 'app_lock_method';

  final FlutterSecureStorage _storage;

  /// 检查是否需要显示锁屏
  Future<bool> shouldShowLock({
    required Duration backgroundDuration,
  }) async {
    final enabled = await _storage.read(key: _keyEnabled);
    if (enabled != 'true') return false;
    // 后台超过 30 秒才触发
    return backgroundDuration.inSeconds > 30;
  }

  /// 设置应用锁
  Future<void> enable({
    required String pin,
    required String method,
  }) async {
    await _storage.write(key: _keyEnabled, value: 'true');
    await _storage.write(key: _keyPin, value: _hashPin(pin));
    await _storage.write(key: _keyMethod, value: method);
  }

  String _hashPin(String pin) {
    // SHA-256 with app-specific salt
    final bytes = utf8.encode(pin + '_primetop_salt_2026');
    return sha256.convert(bytes).toString();
  }
}
```

/// 年级学段数据模型
class GradeSelection {
  final String stage;    // 'kindergarten' | 'primary' | 'junior' | 'senior'
  final int grade;       // 0=幼儿园, 1-6=小学, 7-9=初中, 10-12=高中
  final String semester; // 'first' | 'second'

  String get displayName {
    const stages = {
      'kindergarten': '幼儿园',
      'primary': '小学',
      'junior': '初中',
      'senior': '高中',
    };
    final stageName = stages[stage] ?? '';
    if (stage == 'kindergarten') {
      return '幼儿园大班';
    }
    return '$stageName${grade}年级${semester == 'first' ? '上学期' : '下学期'}';
  }
}
