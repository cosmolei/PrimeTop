## 1. 模块概述

### 1.1 功能定位

教育内容中文文本可读性自动评估与阅读难度智能分级引擎（Content Readability Assessment & Difficulty Grading Engine，简称 **RAGE**）是 PrimeTop 内容基础设施层的核心组件。该引擎自动评估平台所有文本类教育内容的**阅读难度等级**，为内容生产、个性化推荐、分龄适配和学情分析提供量化依据。

**为什么需要这个引擎？**

当前平台已有的"适龄性评估"关注的是内容**是否适合**目标年龄段（涉及安全、价值观），而 RAGE 关注的是内容**能否被读懂**——即文本的语言学复杂度是否匹配学生的阅读理解能力。

| 维度 | 适龄性评估 | 可读性评估（RAGE） |
|------|-----------|-------------------|
| 评估目标 | 内容是否安全、合规、价值观正确 | 文本能否被目标年级学生读懂 |
| 核心指标 | 年龄分级标签 | 阅读难度分数（年级当量） |
| 适用范围 | 全部内容 | 文本类内容（讲解、题目、解析、作文范文等） |
| 输入 | 内容标签 + 规则引擎 | 文本特征 + 语言模型 |
| 典型场景 | 过滤不适宜内容 | 匹配学生阅读能力、推荐合适内容 |

### 1.2 覆盖的内容类型

| 内容类别 | 来源模块 | 典型文本长度 | 评估优先级 |
|----------|----------|-------------|-----------|
| 知识点讲解 | 内容服务、同步课堂 | 200-2000 字 | P0 |
| 题目题干 | 题目与题库服务 | 20-500 字 | P0 |
| 题目解析 | 题目与题库服务 | 100-1000 字 | P0 |
| AI 回答 | AI 智能辅导 | 200-3000 字 | P1（实时评估） |
| 作文范文 | 作文辅导 | 400-1500 字 | P0 |
| 英语阅读材料 | 英语专项学习 | 200-800 词 | P0 |
| 古诗文原文及注释 | 古诗文专项学习 | 20-500 字 | P1 |
| 教材课文 | 同步课堂 | 300-3000 字 | P0 |
| 学习报告文字 | 学情分析 | 100-500 字 | P2 |

### 1.3 核心目标

| 目标 | 指标 |
|------|------|
| 评估准确率 | 与教研专家标定的难度等级 Spearman 相关系数 ≥ 0.75 |
| 评估延迟（批处理） | 单篇 ≤ 200ms |
| 评估延迟（实时） | AI 回答实时评估 ≤ 50ms |
| 覆盖率 | P0 内容类型 100% 覆盖 |
| 更新及时性 | 内容修改后 5 分钟内完成重新评估 |

## 2. 可读性评估模型设计

### 2.1 评估模型总览

RAGE 采用**多层级特征融合 + 机器学习回归**方案，不依赖单一公式，而是综合以下信号：

```
┌──────────────────────────────────────────────────────┐
│                   输入文本                              │
└──────────────────────────┬───────────────────────────┘
                           │
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                  ▼
  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
  │  词汇层特征   │  │  句法层特征   │  │  语篇层特征   │
  │  (Lexical)   │  │ (Syntactic)  │  │ (Discourse)  │
  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘
         │                 │                  │
         └─────────────────┼──────────────────┘
                           ▼
              ┌───────────────────────┐
              │  学科上下文修正器       │
              │  (Subject Adjuster)   │
              └───────────┬───────────┘
                          ▼
              ┌───────────────────────┐
              │  梯度提升回归模型       │
              │  (LightGBM Regressor) │
              └───────────┬───────────┘
                          ▼
              ┌───────────────────────┐
              │  难度等级输出           │
              │  Grade Level + Score  │
              └───────────────────────┘
```

### 2.2 词汇层特征（Lexical Features）

| 特征名 | 计算方式 | 说明 |
|--------|---------|------|
| `avg_word_length` | 总字符数 / 总词数 | 平均词长，越长越难 |
| `lexical_density` | 实词数 / 总词数 | 实词（名词、动词、形容词、副词）占比 |
| `type_token_ratio` | 不重复词数 / 总词数 | 词汇丰富度 |
| `academic_word_ratio` | 学术词汇数 / 总词数 | 学科专业术语占比 |
| `idiom_density` | 成语/惯用语数 / 总句数 | 成语密度 |
| `rare_char_ratio` | 低频字数 / 总字数 | 使用频率排名 3000 以后字的占比 |
| `neologism_ratio` | 新词/网络词数 / 总词数 | 非标准用语占比 |

**低频字判定标准**：基于《现代汉语频率词典》的频率排名，排名 > 3000 的字记为低频字，按年级段调整阈值。

```python
def compute_lexical_features(text: str, segmenter) -> dict:
    """计算词汇层特征"""
    words = segmenter.cut(text)
    chars = list(text.replace(" ", "").replace("\n", ""))
    
    total_words = len(words)
    total_chars = len(chars)
    
    if total_words == 0:
        return _empty_lexical_features()
    
    # 实词识别（名词、动词、形容词、副词）
    content_words = [w for w in words if w.pos in {
        'n', 'nr', 'ns', 'nt', 'nz',  # 名词类
        'v', 'vd', 'vn',               # 动词类
        'a', 'ad', 'an',               # 形容词类
        'd'                             # 副词
    }]
    
    # 学术词汇匹配（从学科术语词表加载）
    academic_words = [w for w in words if w.word in ACADEMIC_WORD_SET]
    
    # 成语识别
    idioms = [w for w in words if w.word in IDIOM_DICT]
    
    # 低频字统计
    rare_chars = [c for c in chars if CHAR_FREQ_RANK.get(c, 0) > RARE_CHAR_THRESHOLD]
    
    # 不重复词
    unique_words = set(w.word for w in words)
    
    return {
        'avg_word_length': total_chars / total_words,
        'lexical_density': len(content_words) / total_words,
        'type_token_ratio': len(unique_words) / total_words,
        'academic_word_ratio': len(academic_words) / total_words,
        'idiom_density': len(idioms) / max(len(words), 1),
        'rare_char_ratio': len(rare_chars) / max(total_chars, 1),
        'total_words': total_words,
        'total_chars': total_chars,
    }
```

### 2.3 句法层特征（Syntactic Features）

| 特征名 | 计算方式 | 说明 |
|--------|---------|------|
| `avg_sentence_length` | 总词数 / 句子数 | 平均句长，越长越难 |
| `max_sentence_length` | 最长句子的词数 | 长句阅读负荷 |
| `long_sentence_ratio` | 长句数（>30词）/ 总句数 | 长句占比 |
| `clause_depth` | 从句嵌套平均深度 | 句法复杂度 |
| `passive_ratio` | 被动句数 / 总句数 | 被动语态密度 |
| `rhetorical_question_ratio` | 设问/反问句数 / 总句数 | 修辞句密度 |
| `conjunction_density` | 关联词数 / 总句数 | 逻辑连接词密度 |
| `sentence_type_diversity` | 不同句型种类数 | 句式多样性 |

**分句规则**：中文按 `。！？；` 进行断句，同时识别 `，、` 等为句内停顿。

```python
import re

def compute_syntactic_features(text: str, segmenter) -> dict:
    """计算句法层特征"""
    # 中文分句
    sentences = re.split(r'[。！？；\n]+', text)
    sentences = [s.strip() for s in sentences if s.strip()]
    
    if not sentences:
        return _empty_syntactic_features()
    
    sentence_word_counts = []
    clause_depths = []
    passive_count = 0
    rhetorical_count = 0
    conjunction_count = 0
    sentence_types = set()
    
    for sent in sentences:
        words = segmenter.cut(sent)
        word_count = len(words)
        sentence_word_counts.append(word_count)
        
        # 从句嵌套深度（基于标点层次估算）
        comma_count = sent.count('，') + sent.count('、')
        depth = min(comma_count + 1, 5)  # 限制最大深度为5
        clause_depths.append(depth)
        
        # 被动句识别
        if any(marker in sent for marker in ['被', '受', '遭', '让', '叫', '给']):
            passive_count += 1
            sentence_types.add('passive')
        
        # 设问/反问句识别
        if '？' in sent or any(m in sent for m in ['难道', '岂', '怎能', '何必']):
            rhetorical_count += 1
            sentence_types.add('rhetorical')
        
        # 关联词识别
        for conj in CONJUNCTION_SET:
            if conj in sent:
                conjunction_count += 1
        
        # 句型分类
        if sent.startswith('请') or sent.startswith('试'):
            sentence_types.add('imperative')
        elif any(m in sent for m in ['如果', '假设', '若']):
            sentence_types.add('conditional')
        elif any(m in sent for m in ['因为', '由于', '所以']):
            sentence_types.add('causal')
        else:
            sentence_types.add('declarative')
    
    total_sentences = len(sentences)
    total_words = sum(sentence_word_counts)
    
    return {
        'avg_sentence_length': total_words / total_sentences,
        'max_sentence_length': max(sentence_word_counts),
        'long_sentence_ratio': sum(1 for c in sentence_word_counts if c > 30) / total_sentences,
        'clause_depth': sum(clause_depths) / total_sentences,
        'passive_ratio': passive_count / total_sentences,
        'rhetorical_question_ratio': rhetorical_count / total_sentences,
        'conjunction_density': conjunction_count / total_sentences,
        'sentence_type_diversity': len(sentence_types),
        'total_sentences': total_sentences,
    }
```

### 2.4 语篇层特征（Discourse Features）

| 特征名 | 计算方式 | 说明 |
|--------|---------|------|
| `text_length` | 总字数 | 篇幅长度 |
| `paragraph_count` | 段落数 | 结构复杂度 |
| `avg_paragraph_length` | 总字数 / 段落数 | 段落信息密度 |
| `discourse_marker_density` | 篇章连接词数 / 段落数 | 语篇衔接度 |
| `concept_density` | 核心概念数 / 千字 | 概念密度 |
| `abstraction_level` | 抽象概念词数 / 总词数 | 抽象程度 |
| `cohesion_score` | 代词指代链密度 | 语篇连贯性 |
| `information_density` | 命题数 / 千字 | 信息负载 |

### 2.5 学科上下文修正器

### 2.6 难度评分模型

采用 LightGBM 回归模型，输出**年级当量值（Grade Equivalent, GE）**，范围 1.0-12.0+。

**训练数据来源**：
- 人工标注数据集：由教研团队对 3000+ 篇内容标注目标年级
- 题库历史数据：已有 `difficulty` 标签的题目（约 50000+ 条）
- 教材课文：天然有年级归属（约 8000+ 篇）

**模型参数**：

## 4. API 接口设计

### 4.1 单篇内容可读性评估

async def assess_ai_response_realtime(
    response_text: str,
    subject_code: str,
    target_grade: str

    AI 回答实时可读性评估
    目标延迟 ≤ 50ms
    """
    # 1. 使用轻量级特征（仅词汇层 + 句法层核心特征）
    features = compute_lightweight_features(response_text)

    base_ge = ONNX_MODEL.predict(features)
    
    # 3. 学科修正
    offset = SUBJECT_DIFFICULTY_OFFSET.get(subject_code, 0.0)
    adjusted_ge = base_ge + offset
    
    # 4. 与目标年级比较
    target_ge = GRADE_READING_BASELINE.get(target_grade, 7.0)
    deviation = adjusted_ge - target_ge

    suggestion = None
    if deviation > 2.0:
        suggestion = "simplify"  # 建议AI重新生成更简单的回答
    elif deviation < -2.0:
        suggestion = "elaborate"  # 可以更深入讲解
    
    return {
        "grade_equivalent": round(adjusted_ge, 1),
        "difficulty_level": ge_to_level(adjusted_ge),
        "target_ge": target_ge,
        "deviation": round(deviation, 1),
        "suggestion": suggestion,

### 5.3 学生阅读能力更新流程

学生阅读能力通过多源数据融合更新：

```
┌─────────────────────────────────────────────────────────┐
│                   数据来源                                │
├──────────┬──────────────┬──────────────┬────────────────┤
│ 阅读理解 │ 答题行为分析  │ 阅读时长分析  │ AI对话理解检测 │
│ 题正确率 │ (停顿/重读)   │ (速度/完成率) │ (追问频率)     │
└────┬─────┴──────┬───────┴──────┬───────┴───────┬────────┘
     │            │              │               │
     ▼            ▼              ▼               ▼
┌─────────────────────────────────────────────────────────┐
│              学生阅读能力融合计算引擎                       │
│                                                         │
│  1. 各数据源归一化为 0-1 能力值                            │
│  2. 加权融合 (权重随数据量动态调整)                         │
│  3. 映射为年级当量 GE 值                                  │
│  4. EMA 平滑 (避免单次评估剧烈波动)                        │
└─────────────────────┬───────────────────────────────────┘
                      ▼
            ┌──────────────────┐
            │ student_reading_ │
            │ profiles 更新     │
            └──────────────────┘
```

**阅读能力 EMA 更新公式：**

```
GE_new = α × GE_assessed + (1 - α) × GE_previous
```

其中 `α`（平滑系数）根据评估可信度动态调整：

```python
def compute_reading_level_update(
    previous_ge: float,
    assessed_ge: float,
    confidence: float,
    data_points: int
) -> float:
    """
    EMA 平滑更新学生阅读能力
    
    confidence: 本次评估的置信度 (0-1)
    data_points: 累计评估次数（影响 α 的初始值）
    """
    # 数据越多，对新评估的信任度越高
    base_alpha = min(0.3 + data_points * 0.02, 0.7)
    
    # 高置信度评估权重更大
    alpha = base_alpha * confidence
    
    new_ge = alpha * assessed_ge + (1 - alpha) * previous_ge
    return round(new_ge, 1)
```

## 6. 关键模块实现

### 6.1 评估服务核心类

```python
"""
readability_engine.py - 可读性评估引擎核心
"""

import time
import logging
from typing import Optional
from dataclasses import dataclass

logger = logging.getLogger(__name__)


@dataclass
class ReadabilityAssessment:
    """可读性评估结果"""
    grade_equivalent: float       # 年级当量值
    difficulty_level: int         # 难度等级 1-6
    difficulty_label: str         # 难度标签
    confidence_score: float       # 置信度
    features: dict                # 详细特征
    assessment_version: str       # 模型版本
    latency_ms: int              # 评估耗时


class ReadabilityEngine:
    """可读性评估引擎"""
    
    def __init__(
        self,
        segmenter,            # 中文分词器（jieba/HanLP）
        model_loader,         # 模型加载器
        cache_client,         # Redis 客户端
        db_client,            # 数据库客户端
    ):
        self.segmenter = segmenter
        self.model = model_loader.get_active_model()
        self.model_version = model_loader.get_active_version()
        self.cache = cache_client
        self.db = db_client
        
        # 预加载词表
        self._load_vocabularies()
    
    def _load_vocabularies(self):
        """加载预置词表"""
        self.academic_word_set = self._load_word_set('academic_words.txt')
        self.idiom_dict = self._load_word_set('idioms.txt')
        self.conjunction_set = self._load_word_set('conjunctions.txt')
        self.char_freq_rank = self._load_char_freq('char_frequency.json')
    
    def assess(
        self,
        text: str,
        subject_code: str = 'chinese',
        content_id: Optional[int] = None,
        content_type: Optional[str] = None,
        return_features: bool = False
    ) -> ReadabilityAssessment:
        """
        评估文本可读性
        
        Args:
            text: 待评估文本
            subject_code: 学科编码
            content_id: 内容ID（用于缓存）
            content_type: 内容类型
            return_features: 是否返回详细特征
            
        Returns:
            ReadabilityAssessment 评估结果
        """
        start_time = time.time()
        
        # 0. 缓存检查
        if content_id and content_type:
            cached = self._get_cached(content_type, content_id)
            if cached:
                cached.latency_ms = 1  # 缓存命中
                return cached
        
        # 1. 文本预处理
        cleaned_text = self._preprocess(text)
        if not cleaned_text or len(cleaned_text) < 10:
            return self._create_minimal_assessment(subject_code)
        
        # 2. 特征提取
        lexical_features = compute_lexical_features(cleaned_text, self.segmenter)
        syntactic_features = compute_syntactic_features(cleaned_text, self.segmenter)
        discourse_features = compute_discourse_features(cleaned_text)
        
        # 3. 组合特征向量
        feature_vector = self._build_feature_vector(
            lexical_features, syntactic_features, discourse_features
        )
        
        # 4. 模型推理
        base_ge = self.model.predict([feature_vector])[0]
        
        # 5. 学科修正
        subject_offset = SUBJECT_DIFFICULTY_OFFSET.get(subject_code, 0.0)
        adjusted_ge = max(1.0, min(15.0, base_ge + subject_offset))
        
        # 6. 计算置信度
        confidence = self._compute_confidence(
            len(cleaned_text), lexical_features, syntactic_features
        )
        
        # 7. 映射难度等级
        level, label = ge_to_level_and_label(adjusted_ge)
        
        # 8. 构建结果
        elapsed_ms = int((time.time() - start_time) * 1000)
        result = ReadabilityAssessment(
            grade_equivalent=round(adjusted_ge, 1),
            difficulty_level=level,
            difficulty_label=label,
            confidence_score=confidence,
            features={
                'lexical': lexical_features,
                'syntactic': syntactic_features,
                'discourse': discourse_features,
            } if return_features else {},
            assessment_version=self.model_version,
            latency_ms=elapsed_ms,
        )
        
        # 9. 写入缓存和数据库
        if content_id and content_type:
            self._save_assessment(
                content_id, content_type, subject_code, result
            )
        
        return result
    
    def _preprocess(self, text: str) -> str:
        """文本预处理"""
        import re
        # 去除 HTML 标签
        text = re.sub(r'<[^>]+>', '', text)
        # 去除 LaTeX 公式标记（数学内容）
        text = re.sub(r'\$\$[^$]+\$\$', '[公式]', text)
        text = re.sub(r'\$[^$]+\$', '[公式]', text)
        # 规范化空白
        text = re.sub(r'\s+', ' ', text).strip()
        return text
    
    def _compute_confidence(
        self,
        text_length: int,
        lexical: dict,
        syntactic: dict
    ) -> float:
        """计算评估置信度"""
        # 文本越短，置信度越低
        length_factor = min(text_length / 200, 1.0)
        
        # 句子越少，置信度越低
        sentence_factor = min(syntactic.get('total_sentences', 1) / 5, 1.0)
        
        # 综合置信度
        confidence = 0.5 + 0.3 * length_factor + 0.2 * sentence_factor
        return round(min(confidence, 0.99), 2)
    
    def _create_minimal_assessment(self, subject_code: str) -> ReadabilityAssessment:
        """文本过短时的默认评估"""
        return ReadabilityAssessment(
            grade_equivalent=3.0,
            difficulty_level=2,
            difficulty_label='初级',
            confidence_score=0.30,
            features={},
            assessment_version=self.model_version,
            latency_ms=5,
        )


def ge_to_level_and_label(ge: float) -> tuple:
    """年级当量值 → 难度等级和标签"""
    if ge < 3.0:
        return 1, '基础'
    elif ge < 5.0:
        return 2, '初级'
    elif ge < 7.0:
        return 3, '中级'
    elif ge < 9.0:
        return 4, '进阶'
    elif ge < 11.0:
        return 5, '高级'
    else:
        return 6, '精通'
```

### 6.2 批量评估消费者

```python
"""
readability_consumer.py - 监听内容事件，自动触发可读性评估
"""

import json
import logging

logger = logging.getLogger(__name__)


class ReadabilityEventConsumer:
    """可读性评估事件消费者"""
    
    def __init__(self, mq_client, content_service, readability_engine):
        self.mq = mq_client
        self.content_service = content_service
        self.engine = readability_engine
        self.exchange = 'content.events'
        self.queue = 'readability.assessment.queue'
        self.routing_keys = [
            'content.created',
            'content.updated',
            'question.published',
            'knowledge_point.updated',
        ]
    
    async def start(self):
        """启动消费者"""
        await self.mq.declare_exchange(self.exchange, 'topic')
        await self.mq.declare_queue(self.queue)
        for key in self.routing_keys:
            await self.mq.bind_queue(self.queue, self.exchange, key)
        
        await self.mq.consume(self.queue, self._handle_message)
        logger.info("ReadabilityEventConsumer started")
    
    async def _handle_message(self, channel, method, properties, body):
        """处理消息"""
        try:
            event = json.loads(body)
            event_type = event.get('event_type')
            
            logger.info(
                f"Processing readability assessment: "
                f"type={event_type}, id={event.get('content_id')}"
            )
            
            # 获取内容文本
            content = await self.content_service.get_content_text(
                content_id=event['content_id'],
                content_type=event['content_type']
            )
            
            if not content or not content.get('text'):
                logger.warning(f"Empty content text for id={event['content_id']}")
                channel.basic_ack(method.delivery_tag)
                return
            
            # 执行评估
            result = self.engine.assess(
                text=content['text'],
                subject_code=content.get('subject_code', 'chinese'),
                content_id=event['content_id'],
                content_type=event['content_type'],
                return_features=True,
            )
            
            # 发布评估完成事件
            await self._publish_assessment_event(event, result)
            
            logger.info(
                f"Readability assessed: id={event['content_id']}, "
                f"GE={result.grade_equivalent}, level={result.difficulty_label}, "
                f"latency={result.latency_ms}ms"
            )
            
            channel.basic_ack(method.delivery_tag)
            
        except Exception as e:
            logger.error(f"Readability assessment failed: {e}", exc_info=True)
            # 重试 3 次后进入死信队列
            if method.redelivered_count < 3:
                channel.basic_nack(method.delivery_tag, requeue=True)
            else:
                channel.basic_nack(method.delivery_tag, requeue=False)
                await self._send_to_dlq(method, body, str(e))
    
    async def _publish_assessment_event(self, source_event: dict, result):
        """发布评估完成事件"""
        event = {
            'event_type': 'readability.assessed',
            'content_id': source_event['content_id'],
            'content_type': source_event['content_type'],
            'grade_equivalent': result.grade_equivalent,
            'difficulty_level': result.difficulty_level,
            'difficulty_label': result.difficulty_label,
            'confidence_score': result.confidence_score,
            'timestamp': int(time.time()),
        }
        await self.mq.publish(
            exchange='readability.events',
            routing_key='readability.assessed',
            message=json.dumps(event)
        )
```

    (7.0, 4, '进阶', '#FF5722'),    # 深橙
    (9.0, 5, '高级', '#F44336'),    # 红色
    (11.0, 6, '精通', '#9C27B0'),   # 紫色
]


def ge_to_level(ge: float) -> int:
    """年级当量 → 难度等级数字"""
    for threshold, level, _, _ in reversed(DIFFICULTY_LEVEL_MAP):
        if ge >= threshold:
            return level
    return 1


def ge_to_label(ge: float) -> str:
    """年级当量 → 难度标签"""
    for threshold, _, label, _ in reversed(DIFFICULTY_LEVEL_MAP):
        if ge >= threshold:
            return label
    return '基础'


def ge_to_color(ge: float) -> str:
    """年级当量 → 颜色代码（前端展示用）"""
    for threshold, _, _, color in reversed(DIFFICULTY_LEVEL_MAP):
        if ge >= threshold:
            return color
    return '#4CAF50'


def is_suitable_for_grade(ge: float, target_grade: str) -> bool:
    """判断内容难度是否适合目标年级"""
    target_ge = GRADE_READING_BASELINE.get(target_grade, 7.0)
    # 允许 ±1.5 个年级当量的偏差
    return abs(ge - target_ge) <= 1.5


def get_difficulty_gap(ge: float, student_reading_level: float) -> str:
    """
    获取内容难度与学生阅读能力的差距描述
    
    Returns:
        'appropriate' - 合适
        'challenging' - 有挑战性
        'easy' - 较轻松
        'too_hard' - 过难
        'too_easy' - 过易
    """
    gap = ge - student_reading_level
    if abs(gap) <= 0.5:
        return 'appropriate'
    elif 0.5 < gap <= 1.5:
        return 'challenging'
    elif -1.5 <= gap < -0.5:
        return 'easy'
    elif gap > 1.5:
        return 'too_hard'
    else:
        return 'too_easy'
```

    base_prompt: str,
    target_grade: str,
    student_reading_level: float

    # 取学生阅读能力和目标年级的较低值作为约束

### 8.1 错误码定义

| `READABILITY_004` | 模型推理失败 | 返回上一次缓存结果；无缓存则返回默认值 |
| `READABILITY_005` | 不支持的内容类型 | 跳过评估，记录日志 |
| `READABILITY_006` | 学科编码无效 | 使用默认偏移 0.0 |
| `READABILITY_007` | 批量评估部分失败 | 记录失败项，成功项正常写入 |

### 8.2 降级策略

class ReadabilityEngineFallback:
    """可读性评估降级处理器"""
    
    @staticmethod
    def fallback_assess(text: str) -> ReadabilityAssessment:
        """模型不可用时的降级评估（基于规则）"""
        # 使用简化的规则公式
        char_count = len(text)
        sentence_count = max(text.count('。') + text.count('！') + text.count('？'), 1)
        avg_sentence_len = char_count / sentence_count
        
        # 简化规则：平均句长 → 难度估算
        if avg_sentence_len < 10:
            ge = 2.0
        elif avg_sentence_len < 15:
            ge = 4.0
        elif avg_sentence_len < 20:
            ge = 6.0
        elif avg_sentence_len < 25:
            ge = 8.0
        elif avg_sentence_len < 30:
            ge = 10.0
        else:
            ge = 12.0
        
        return ReadabilityAssessment(
            grade_equivalent=ge,
            difficulty_level=ge_to_level(ge),
            difficulty_label=ge_to_label(ge),
            confidence_score=0.40,  # 低置信度
            features={},
            assessment_version='fallback_rule_v1',
            latency_ms=1,
        )
```

### 9.3 异步批处理优化

```python
"""
批量评估使用协程池并发处理
单批 1000 篇，并发度 10
"""

import asyncio

BATCH_CONCURRENCY = 10
BATCH_SIZE = 1000

async def batch_assess(items: list, engine: ReadabilityEngine) -> dict:
    """批量异步评估"""
    semaphore = asyncio.Semaphore(BATCH_CONCURRENCY)
    
    async def assess_one(item: dict):
        async with semaphore:
            # 分词和特征提取是 CPU 密集型，放入线程池
            loop = asyncio.get_event_loop()
            return await loop.run_in_executor(
                None,
                engine.assess,
                item['text'],
                item.get('subject_code', 'chinese'),
                item.get('content_id'),
                item.get('content_type'),
                True
            )
    
    tasks = [assess_one(item) for item in items[:BATCH_SIZE]]
    results = await asyncio.gather(*tasks, return_exceptions=True)
    
    success_count = sum(1 for r in results if not isinstance(r, Exception))
    fail_count = len(results) - success_count
    
    return {
        'total': len(items),
        'success': success_count,
        'failed': fail_count,
        'results': results,
    }
```
