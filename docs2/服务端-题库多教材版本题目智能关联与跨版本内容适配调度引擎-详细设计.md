# 服务端-题库多教材版本题目智能关联与跨版本内容适配调度引擎-详细设计

## 1. 概述

### 1.1 模块定位

本引擎负责解决 PrimeTop 平台题库中**同一题目在不同教材版本间复用与关联**的核心问题。当同一道数学题在人教版七年级第三章、苏教版七年级第五章、北师大版八年级第二章中均出现时，引擎需要自动识别其等价性、建立跨版本映射关系，并在学生切换教材版本或区域适配时，智能调度正确的题目变体。

### 1.2 问题背景

| 痛点 | 描述 |
| --- | --- |
| 题目重复入库 | 不同教材版本的同一道题被反复录入，造成存储浪费和统计偏差 |
| 跨版本切换断层 | 学生从人教版转入苏教版后，错题本中的旧版本题目无法正确关联到新版本进度 |
| 区域适配困难 | 不同省份使用不同教材版本，统一出卷/组卷时难以保证题目覆盖一致性 |
| 统计偏差 | 同一题目被计为多道独立题目，影响知识点覆盖度和难度分析的准确性 |
| 维护成本高 | 题目勘误或答案修正需要在不同版本中分别操作，容易遗漏 |

### 1.3 设计目标

1. **统一题目标识**：为每道题目建立全局唯一标识（Universal Question ID），区分"逻辑题目"与"版本变体"。
2. **自动等价识别**：通过文本相似度 + 结构化特征匹配 + 知识点对齐，自动识别跨版本等价题目。
3. **版本变体管理**：支持同一逻辑题在不同教材版本下的微小差异（题干措辞、数据参数、图形差异等）。
4. **智能调度**：根据学生当前教材版本，自动选择最匹配的题目变体返回。
5. **批量同步**：当母题的答案或解析修正时，自动同步到所有已确认关联的版本变体。

### 1.4 适用范围

- 适用学段：小学、初中、高中全学段
- 适用学科：数学、物理、化学、生物、语文、英语、历史、地理、政治
- 交互系统：题库管理系统、练习测评系统、错题服务、组卷引擎、拍照搜题

## 2. 核心概念与术语

| 术语 | 定义 |
| --- | --- |
| **逻辑题目 (Logical Question)** | 抽象的题目实体，代表一个独立的考查意图，独立于任何教材版本 |
| **版本变体 (Version Variant)** | 逻辑题目在特定教材版本下的具体呈现形式，可能存在措辞、数据、图形差异 |
| **等价度 (Equivalence Score)** | 0~1 的浮点数，表示两道题目为同一逻辑题目的置信度 |
| **母题 (Master Variant)** | 逻辑题目中最早入库或质量评分最高的变体，作为关联基准 |
| **教材版本上下文 (Version Context)** | 学段+年级+学期+学科+教材版本的组合，如"初中-七年级-上-数学-人教版" |
| **关联确认状态** | AUTOMATED（自动识别）/ CONFIRMED（人工确认）/ REJECTED（人工拒绝） |

## 4. 核心算法与匹配策略

### 4.1 等价识别多级流水线

采用"粗筛 → 精排 → 人工确认"的三级流水线设计：

```
新题目入库
    │
    ▼
┌──────────────┐
│ 第一级：粗筛  │  ← 知识点 + 学科 + 学段 + 题型 + 难度区间 快速过滤
└──────┬───────┘
       │ 候选集（通常 50~200 道）
       ▼
┌──────────────┐
│ 第二级：精排  │  ← 文本相似度 + 结构化特征 + 图形指纹 + 答案匹配
└──────┬───────┘
       │ Top-K（K=5），score ≥ 0.75 的候选
       ▼
┌──────────────┐
│ 第三级：决策  │  ← 自动确认（≥0.95）/ 自动拒绝（<0.75）/ 人工审核
└──────────────┘
```

### 4.2 粗筛策略

```python
def coarsely_filter_candidates(new_question, all_questions):
    """
    粗筛：基于结构化属性快速缩小候选范围
    """
    filters = {
        'subject_code': new_question.subject_code,
        'stage_code': new_question.stage_code,
        'question_type': new_question.question_type,
    }
    
    # 知识点交集过滤：至少有1个共同知识点
    candidate_pool = []
    for q in all_questions.filter(**filters):
        overlap = set(new_question.knowledge_point_ids) & set(q.knowledge_point_ids)
        if len(overlap) == 0:
            continue
        
        # 难度区间过滤：±0.15
        if abs(new_question.difficulty - q.difficulty) > 0.15:
            continue
            
        candidate_pool.append(q)
    
    return candidate_pool
```

### 4.3 精排：多维度相似度计算

#### 4.3.1 文本语义相似度（权重 35%）

```python
import numpy as np
from sentence_transformers import SentenceTransformer

class TextSimilarityCalculator:
    def __init__(self):
        # 使用教育领域微调的嵌入模型
        self.model = SentenceTransformer('edu-text-embedding-v2')
        self._cache = {}  # question_id -> embedding
    
    def compute(self, q1_text: str, q2_text: str) -> float:
        """计算两道题目文本的语义相似度"""
        emb1 = self.model.encode(q1_text, normalize_embeddings=True)
        emb2 = self.model.encode(q2_text, normalize_embeddings=True)
        return float(np.dot(emb1, emb2))
    
    def compute_cached(self, q1_id: int, q1_text: str, 
                       q2_id: int, q2_text: str) -> float:
        if q1_id not in self._cache:
            self._cache[q1_id] = self.model.encode(q1_text, normalize_embeddings=True)
        if q2_id not in self._cache:
            self._cache[q2_id] = self.model.encode(q2_text, normalize_embeddings=True)
        return float(np.dot(self._cache[q1_id], self._cache[q2_id]))
```

#### 4.3.2 结构化特征相似度（权重 25%）

```python
class StructureSimilarityCalculator:
    """基于题目结构化属性的相似度计算"""
    
    FEATURE_WEIGHTS = {
        'answer_type': 0.30,      # 答案类型（数值/表达式/选项/文本）
        'option_count': 0.15,      # 选项数量
        'has_figure': 0.10,        # 是否含图
        'formula_count': 0.15,     # 公式数量
        'formula_types': 0.15,     # 公式类型集合
        'condition_count': 0.10,   # 条件数量
        'sub_question_count': 0.05, # 小问数量
    }
    
    def compute(self, q1_features: dict, q2_features: dict) -> float:
        total_score = 0.0
        for feature, weight in self.FEATURE_WEIGHTS.items():
            v1 = q1_features.get(feature)
            v2 = q2_features.get(feature)
            total_score += weight * self._compare_feature(feature, v1, v2)
        return total_score
    
    def _compare_feature(self, feature: str, v1, v2) -> float:
        if v1 is None or v2 is None:
            return 0.5  # 未知特征给中性分
        
        if feature == 'formula_types':
            # Jaccard 相似度
            s1, s2 = set(v1), set(v2)
            if not s1 and not s2:
                return 1.0
            intersection = s1 & s2
            union = s1 | s2
            return len(intersection) / len(union) if union else 0.0
        
        if isinstance(v1, (int, float)):
            return 1.0 if v1 == v2 else max(0, 1.0 - abs(v1 - v2) / max(v1, v2, 1))
        
        return 1.0 if v1 == v2 else 0.0
```

#### 4.3.3 答案/解析匹配度（权重 25%）

```python
class AnswerMatchCalculator:
    """比较两道题目的答案是否一致或等价"""
    
    def compute(self, q1_answer: dict, q2_answer: dict) -> float:
        """
        q1_answer/q2_answer 结构:
        {
            'answer_type': 'numeric|expression|text|option_list',
            'answer_value': '具体答案',
            'answer_steps': [...],  # 解题步骤（如有）
        }
        """
        if q1_answer['answer_type'] != q2_answer['answer_type']:
            return 0.0
        
        atype = q1_answer['answer_type']
        
        if atype == 'numeric':
            return self._compare_numeric(
                float(q1_answer['answer_value']), 
                float(q2_answer['answer_value'])
            )
        elif atype == 'expression':
            return self._compare_expression(
                q1_answer['answer_value'],
                q2_answer['answer_value']
            )
        elif atype == 'option_list':
            return self._compare_options(
                q1_answer['answer_value'],
                q2_answer['answer_value']
            )
        else:
            return self._compare_text(
                q1_answer['answer_value'],
                q2_answer['answer_value']
            )
    
    def _compare_numeric(self, v1: float, v2: float, tolerance: float = 1e-6) -> float:
        if abs(v1 - v2) < tolerance:
            return 1.0
        # 可能是参数变体（数据不同但题型一致）
        ratio = min(v1, v2) / max(v1, v2) if max(v1, v2) != 0 else 0
        return ratio * 0.5  # 数据不同降权
    
    def _compare_expression(self, e1: str, e2: str) -> float:
        """通过 SymPy 标准化后比较数学表达式等价性"""
        from sympy import simplify, sympify
        try:
            expr1 = sympify(e1)
            expr2 = sympify(e2)
            if simplify(expr1 - expr2) == 0:
                return 1.0
            return 0.0
        except Exception:
            return 0.3  # 无法解析的表达式给低分
    
    def _compare_options(self, o1: list, o2: list) -> float:
        if len(o1) != len(o2):
            return 0.0
        correct_match = sum(1 for a, b in zip(o1, o2) if a == b)
        return correct_match / len(o1) if o1 else 0.0
    
    def _compare_text(self, t1: str, t2: str) -> float:
        from difflib import SequenceMatcher
        return SequenceMatcher(None, t1, t2).ratio()
```

#### 4.3.4 图形指纹相似度（权重 15%）

```python
import hashlib
import cv2

class FigureFingerprintCalculator:
    """对题目中的图形提取感知哈希指纹进行比较"""
    
    def compute(self, q1_figures: list, q2_figures: list) -> float:
        if not q1_figures and not q2_figures:
            return 1.0  # 都没有图形
        if not q1_figures or not q2_figures:
            return 0.0  # 一方有图一方没有
        
        # 生成感知哈希
        hashes1 = [self._phash(f) for f in q1_figures]
        hashes2 = [self._phash(f) for f in q2_figures]
        
        # 比较哈希汉明距离
        best_score = 0.0
        for h1 in hashes1:
            for h2 in hashes2:
                score = self._hamming_similarity(h1, h2)
                best_score = max(best_score, score)
        
        return best_score
    
    def _phash(self, image_bytes: bytes) -> str:
        img = cv2.imdecode(np.frombuffer(image_bytes, np.uint8), cv2.IMREAD_GRAYSCALE)
        img = cv2.resize(img, (32, 32))
        img = cv2.dct(np.float32(img))
        dct_low = img[:8, :8]
        median = np.median(dct_low)
        bits = (dct_low > median).flatten()
        return ''.join(['1' if b else '0' for b in bits])
    
    def _hamming_similarity(self, h1: str, h2: str) -> float:
        distance = sum(c1 != c2 for c1, c2 in zip(h1, h2))
        return 1.0 - distance / len(h1)
```

### 4.4 综合评分与决策

```python
class EquivalenceDecisionEngine:
    """多维度综合评分与关联决策"""
    
    WEIGHTS = {
        'text': 0.35,
        'structure': 0.25,
        'answer': 0.25,
        'figure': 0.15,
    }
    
    AUTO_CONFIRM_THRESHOLD = 0.95
    AUTO_REJECT_THRESHOLD = 0.60
    HUMAN_REVIEW_RANGE = (0.60, 0.95)
    
    def evaluate(self, new_question: dict, candidate: dict) -> dict:
        text_sim = TextSimilarityCalculator().compute(
            new_question['stem'], candidate['stem']
        )
        struct_sim = StructureSimilarityCalculator().compute(
            new_question['features'], candidate['features']
        )
        answer_sim = AnswerMatchCalculator().compute(
            new_question['answer'], candidate['answer']
        )
        figure_sim = FigureFingerprintCalculator().compute(
            new_question.get('figures', []), 
            candidate.get('figures', [])
        )
        
        overall = (
            text_sim * self.WEIGHTS['text'] +
            struct_sim * self.WEIGHTS['structure'] +
            answer_sim * self.WEIGHTS['answer'] +
            figure_sim * self.WEIGHTS['figure']
        )
        
        decision = self._make_decision(overall)
        
        return {
            'overall_score': round(overall, 4),
            'details': {
                'text_similarity': round(text_sim, 4),
                'structure_similarity': round(struct_sim, 4),
                'answer_similarity': round(answer_sim, 4),
                'figure_similarity': round(figure_sim, 4),
            },
            'decision': decision,
        }
    
    def _make_decision(self, score: float) -> str:
        if score >= self.AUTO_CONFIRM_THRESHOLD:
            return 'AUTO_CONFIRM'
        elif score < self.AUTO_REJECT_THRESHOLD:
            return 'AUTO_REJECT'
        else:
            return 'HUMAN_REVIEW'
```

## 7. 批量教材版本入库处理

### 7.1 场景描述

当平台新接入一个教材版本（如"外研版高中英语"），需要将该版本下的全部题目（通常 5000~20000 道）导入并与现有题库建立跨版本关联。

### 7.2 批量处理流水线

```python
class BatchTextbookLinkingPipeline:
    """新教材版本入库批量关联流水线"""
    
    BATCH_SIZE = 200  # 每批处理题目数
    MAX_CONCURRENT = 4  # 最大并发数
    
    async def run(self, textbook_id: int, source_questions: list):
        """批量入库主流程"""
        # Phase 1: 按知识点分组建立索引
        kp_index = self._build_knowledge_point_index(source_questions)
        
        # Phase 2: 分批并行处理
        total = len(source_questions)
        processed, auto_linked, needs_review = 0, 0, 0
        
        for batch in self._chunk(source_questions, self.BATCH_SIZE):
            results = await asyncio.gather(*[
                self._process_single(q, kp_index) 
                for q in batch
            ], return_exceptions=True)
            
            for result in results:
                processed += 1
                if isinstance(result, Exception):
                    logger.error(f"Question linking failed: {result}")
                    continue
                if result.decision == 'AUTO_CONFIRM':
                    auto_linked += 1
                elif result.decision == 'HUMAN_REVIEW':
                    needs_review += 1
            
            # 进度上报
            await self._report_progress(textbook_id, processed, total)
        
        return {
            'textbook_id': textbook_id,
            'total_questions': total,
            'processed': processed,
            'auto_linked': auto_linked,
            'needs_review': needs_review,
            'review_queue_size': needs_review,
        }
    
    def _build_knowledge_point_index(self, questions: list) -> dict:
        """按知识点构建倒排索引，加速粗筛"""
        index = defaultdict(list)
        for q in questions:
            for kp_id in q.knowledge_point_ids:
                index[kp_id].append(q)
        return index
    
    def _chunk(self, items: list, size: int):
        for i in range(0, len(items), size):
            yield items[i:i + size]
```

## 9. 错误处理与降级策略

### 9.1 错误码定义

| 错误码 | 含义 | 触发场景 | 处理建议 |
| --- | --- | --- | --- |
| QL_4001 | 题目不存在 | question_id 无效 | 校验输入参数 |
| QL_4002 | 逻辑题不存在 | logical_uid 无效 | 检查标识是否正确 |
| QL_4003 | 重复关联请求 | 同一对题目已有确认关联 | 直接返回已有关联 |
| QL_4004 | 嵌入模型不可用 | 文本向量化服务超时 | 跳过文本相似度，降级为结构+答案匹配 |
| QL_4005 | 候选集过大 | 粗筛后候选超过500 | 收紧难度区间或知识点过滤 |
| QL_4006 | 图像处理失败 | 图形指纹提取异常 | 跳过图形维度，用其他三维评分 |
| QL_5001 | 数据库写入冲突 | 并发关联同一逻辑题 | 重试 + 乐观锁 |
| QL_5002 | 批量任务超时 | 单批处理超过30分钟 | 拆分为更小批次 |
| QL_5003 | 章节映射缺失 | 目标教材版本无章节映射 | 返回母题，标注"非本版本" |

### 9.2 降级策略

```python
class LinkingFallbackHandler:
    """多级降级处理器"""
    
    def handle_with_fallback(self, question, candidates):
        # Level 1: 完整四维匹配
        try:
            return self._full_match(question, candidates)
        except EmbeddingServiceUnavailable:
            logger.warning("Embedding service unavailable, falling back")
            
        # Level 2: 跳过文本嵌入，使用关键词匹配
        try:
            return self._keyword_match(question, candidates)
        except Exception:
            pass
        
        # Level 3: 仅使用结构化属性匹配
        try:
            return self._structure_only_match(question, candidates)
        except Exception:
            pass
        
        # Level 4: 全部失败 → 加入人工审核队列
        return self._enqueue_for_human_review(question)
    
    def _keyword_match(self, question, candidates):
        """基于关键词重叠的文本匹配（无嵌入模型时使用）"""
        from jieba import analyse
        q_keywords = set(analyse.extract_tags(question.stem, topK=10))
        
        scored = []
        for c in candidates:
            c_keywords = set(analyse.extract_tags(c.stem, topK=10))
            overlap = len(q_keywords & c_keywords) / max(len(q_keywords), 1)
            scored.append((c, overlap * 0.7))  # 关键词匹配整体降权
        
        return scored
```

```python
class VariantConsistencyChecker:
    """定时任务：校验逻辑题下变体的一致性"""
    
    def check_logical_question(self, logical_uid: str):
        """检查一个逻辑题下所有变体的一致性"""
        variants = get_variants(logical_uid)
        issues = []
        
        # 检查1: 知识点一致性
        kp_sets = [set(v.knowledge_points) for v in variants]
        if len(set(frozenset(s) for s in kp_sets)) > 1:
            issues.append({
                'type': 'KNOWLEDGE_POINT_INCONSISTENCY',
                'message': f'逻辑题 {logical_uid} 下变体知识点不一致',
                'details': [{'question_id': v.question_id, 'kps': v.knowledge_points} for v in variants]
            })
        
        # 检查2: 难度偏差
        difficulties = [v.difficulty for v in variants]
        if max(difficulties) - min(difficulties) > 0.2:
            issues.append({
                'type': 'DIFFICULTY_DEVIATION',
                'message': f'逻辑题 {logical_uid} 变体间难度差异过大',
                'max_diff': max(difficulties),
                'min_diff': min(difficulties)
            })
        
        # 检查3: 答案类型一致性
        answer_types = set(v.answer.answer_type for v in variants)
        if len(answer_types) > 1:
            issues.append({
                'type': 'ANSWER_TYPE_MISMATCH',
                'message': f'逻辑题 {logical_uid} 变体答案类型不一致',
                'types': list(answer_types)
            })
        
        return issues
```

### 16.2 数学表达式标准化示例

```python
from sympy import simplify, sympify, Rational

class MathExpressionNormalizer:
    """数学表达式标准化器"""
    
    def normalize(self, expr_str: str) -> str:
        """将数学表达式标准化为唯一形式"""
        try:
            expr = sympify(expr_str)
            expr = simplify(expr)
            return str(expr)
        except Exception:
            return expr_str.lower().replace(' ', '')
    
    def is_equivalent(self, e1: str, e2: str) -> bool:
        n1, n2 = self.normalize(e1), self.normalize(e2)
        try:
            return simplify(sympify(n1) - sympify(n2)) == 0
        except Exception:
            return n1 == n2
```
