# 服务端-学生跨学科错题关联分析与共享认知薄弱点诊断引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责跨学科维度挖掘学生错题数据中的共性薄弱点，识别隐藏在不同学科背后的**共享认知能力缺陷**（如逻辑推理、计算精度、阅读理解、空间想象等），并生成跨学科统一的干预推荐方案。

### 1.2 与现有模块的关系

| 现有模块 | 关注点 | 本引擎的差异 |
| --- | --- | --- |
| 学科常见错误模式挖掘引擎 | 单学科内的错误模式 | 跨学科的错误关联 |
| 错题相似题型聚类服务 | 同学科题目聚类 | 跨学科题目/能力聚类 |
| 学生偏科智能诊断引擎 | 学科间表现差异 | 学科间错误的共因分析 |
| 学生认知负荷监测引擎 | 单次学习会话负荷 | 长期跨学科认知模式 |

### 1.3 核心价值

传统单学科分析无法回答的关键问题：

- 学生在数学和物理中都频繁出错，是因为**计算能力不足**还是**审题习惯差**？
- 语文阅读理解和英语阅读理解同时薄弱，根因是**阅读策略缺陷**还是**词汇量不足**？
- 化学方程式配平和数学方程求解都出错，是否共享**等式变换逻辑**的薄弱点？

### 1.4 适用范围

- **学段**：小学三年级以上（需积累足够的跨学科错题数据）
- **触发方式**：每日批量分析 + 周度深度分析 + 按需实时查询
- **数据来源**：错题服务、答题记录服务、学习画像服务

## 2. 核心概念模型

### 2.1 认知能力维度体系

跨学科分析的基础是建立一套**通用认知能力维度**，每个维度可被多个学科的题目所考察：

```text
认知能力维度 (CognitiveDimension)
├── CR-01: 计算与运算能力
│   ├── 数学: 代数运算、数值计算
│   ├── 物理: 公式代入计算、单位换算
│   └── 化学: 化学方程式配平、摩尔计算
├── CR-02: 阅读理解与信息提取
│   ├── 语文: 阅读理解、文本分析
│   ├── 英语: 阅读理解、完形填空
│   └── 政治/历史: 材料分析题
├── CR-03: 逻辑推理与演绎
│   ├── 数学: 几何证明、逻辑推导
│   ├── 物理: 过程分析、因果推理
│   └── 化学: 反应推断、实验推理
├── CR-04: 空间想象与图形理解
│   ├── 数学: 立体几何、解析几何
│   ├── 物理: 受力分析图、电路图
│   ├── 化学: 分子结构、晶体结构
│   └── 地理: 地形图、等值线图
├── CR-05: 记忆与知识检索
│   ├── 语文: 古诗文默写、文学常识
│   ├── 英语: 单词拼写、语法规则
│   ├── 历史: 史实记忆
│   └── 政治: 概念背诵
├── CR-06: 审题与条件识别
│   ├── 全学科: 题目条件遗漏、隐含条件未识别
│   └── 全学科: 单位/量纲忽略、关键词误读
├── CR-07: 知识迁移与应用
│   ├── 跨学科: 模型迁移（如数学函数→物理运动）
│   ├── 跨学科: 概念类比（如化学平衡→物理平衡）
│   └── 跨学科: 实际情境建模
└── CR-08: 表达与规范输出
    ├── 语文: 作文结构、语言表达
    ├── 英语: 写作规范
    └── 理科: 解题步骤规范、符号使用
```

### 2.2 错误根因分类体系

```text
错误根因 (ErrorRootCause)
├── ERC-01: 知识盲区 — 完全未掌握该知识点
├── ERC-02: 概念混淆 — 对相似概念区分不清
├── ERC-03: 方法缺失 — 不知道该用什么方法/模型
├── ERC-04: 计算失误 — 思路正确但计算出错
├── ERC-05: 审题疏漏 — 条件遗漏或误读题意
├── ERC-06: 表达不规范 — 知道答案但表述不符合要求
├── ERC-07: 记忆遗忘 — 曾经掌握但遗忘
├── ERC-08: 思维定势 — 套用不适用的解题模式
└── ERC-09: 综合障碍 — 多个知识点综合时无法拆解
```

## 3. 数据结构定义

### 3.1 核心数据表

#### 3.1.1 认知能力维度表 `cognitive_dimensions`

```sql
CREATE TABLE cognitive_dimensions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    code            VARCHAR(16) NOT NULL UNIQUE COMMENT '维度编码 CR-01 ~ CR-08',
    name            VARCHAR(64) NOT NULL COMMENT '维度名称',
    description     TEXT COMMENT '维度描述',
    status          TINYINT DEFAULT 1 COMMENT '1=启用 0=停用',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='认知能力维度表';
```

#### 3.1.2 学科-能力维度映射表 `subject_cognitive_mapping`

```sql
CREATE TABLE subject_cognitive_mapping (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    subject_code        VARCHAR(16) NOT NULL COMMENT '学科编码',
    cognitive_dim_code  VARCHAR(16) NOT NULL COMMENT '认知维度编码',
    weight              DECIMAL(4,3) DEFAULT 0.500 COMMENT '该维度在本学科的权重(0-1)',
    description         VARCHAR(256) COMMENT '映射说明',
    UNIQUE KEY uk_subject_cognitive (subject_code, cognitive_dim_code),
    INDEX idx_subject (subject_code),
    INDEX idx_cognitive (cognitive_dim_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学科与认知能力维度映射';
```

#### 3.1.3 题目-认知维度标注表 `question_cognitive_tags`

```sql
CREATE TABLE question_cognitive_tags (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    question_id         BIGINT NOT NULL COMMENT '题目ID',
    cognitive_dim_code  VARCHAR(16) NOT NULL COMMENT '主要考察的认知维度',
    weight              DECIMAL(4,3) DEFAULT 0.500 COMMENT '该维度权重(0-1)',
    error_root_cause    VARCHAR(16) COMMENT '关联的错误根因编码 ERC-xx',
    tag_source          VARCHAR(16) DEFAULT 'AUTO' COMMENT 'AUTO=自动标注 MANUAL=人工标注',
    confidence          DECIMAL(4,3) DEFAULT 0.800 COMMENT '标注置信度',
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_question_dim (question_id, cognitive_dim_code),
    INDEX idx_cognitive (cognitive_dim_code),
    INDEX idx_root_cause (error_root_cause)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题目认知维度标注';
```

## 5. 核心算法设计

### 5.1 跨学科错题关联分析算法

#### 5.1.1 整体流程

```text
输入: 学生近期所有错题记录 (已标注认知维度和根因)
输出: 跨学科错题关联组列表

Step 1: 数据预处理 — 按认知维度分组错题
Step 2: 跨学科检测 — 识别同一维度下涉及多个学科的错题组
Step 3: 根因聚合 — 在同学科组内聚类相似根因
Step 4: 关联强度计算 — 量化跨学科关联的置信度
Step 5: 严重程度评估 — 根据频率、掌握度、影响范围定级
Step 6: 干预推荐生成 — 匹配训练策略模板
```

#### 5.1.2 关联强度计算

```python
import math
from collections import defaultdict
from typing import List, Dict

def calculate_cross_subject_correlation(
    error_records: List[dict],
    cognitive_dim_code: str
) -> Dict[str, float]:
    """
    计算同一认知维度下不同学科间错题的关联强度。
    
    使用改进的 Jaccard 系数 + 时间窗口加权 + 根因匹配加权。
    
    Args:
        error_records: 该认知维度下的错题记录列表
        cognitive_dim_code: 认知维度编码
        
    Returns:
        {("MATH", "PHYSICS"): 0.87, ("MATH", "CHEMISTRY"): 0.65, ...}
    """
    # 按学科分组
    subject_errors = defaultdict(list)
    for record in error_records:
        if record['cognitive_dim_code'] == cognitive_dim_code:
            subject_errors[record['subject_code']].append(record)
    
    subjects = list(subject_errors.keys())
    correlations = {}
    
    for i in range(len(subjects)):
        for j in range(i + 1, len(subjects)):
            subj_a, subj_b = subjects[i], subjects[j]
            errors_a = subject_errors[subj_a]
            errors_b = subject_errors[subj_b]
            
            # 1. 根因重叠度 (Root Cause Overlap)
            root_causes_a = set(e['error_root_cause'] for e in errors_a if e.get('error_root_cause'))
            root_causes_b = set(e['error_root_cause'] for e in errors_b if e.get('error_root_cause'))
            root_cause_overlap = len(root_causes_a & root_causes_b) / max(
                len(root_causes_a | root_causes_b), 1
            )
            
            # 2. 时间邻近度 (Temporal Proximity)
            # 错题发生在相近时间段内说明可能是同一认知缺陷的连续表现
            temporal_score = calculate_temporal_proximity(errors_a, errors_b)
            
            # 3. 错误模式相似度 (Error Pattern Similarity)
            # 比较错误类型、错因标签的相似度
            pattern_score = calculate_error_pattern_similarity(errors_a, errors_b)
            
            # 4. 数量权重 (Volume Weight)
            # 两学科都有足够多的错题才认为关联可靠
            min_count = min(len(errors_a), len(errors_b))
            volume_weight = 1 - math.exp(-min_count / 5.0)  # 5题时达到约63%权重
            
            # 综合关联强度
            correlation = (
                0.35 * root_cause_overlap +
                0.25 * temporal_score +
                0.25 * pattern_score +
                0.15 * volume_weight
            )
            
            correlations[f"{subj_a}:{subj_b}"] = round(correlation, 4)
    
    return correlations


def calculate_temporal_proximity(errors_a: List[dict], errors_b: List[dict]) -> float:
    """计算两组错题在时间上的邻近度"""
    from datetime import datetime, timedelta
    
    timestamps_a = [e['created_at'] for e in errors_a]
    timestamps_b = [e['created_at'] for e in errors_b]
    
    proximity_scores = []
    for ta in timestamps_a:
        for tb in timestamps_b:
            if isinstance(ta, str):
                ta = datetime.fromisoformat(ta)
            if isinstance(tb, str):
                tb = datetime.fromisoformat(tb)
            diff_days = abs((ta - tb).total_seconds()) / 86400
            # 7天内衰减到0
            score = max(0, 1 - diff_days / 7.0)
            proximity_scores.append(score)
    
    return sum(proximity_scores) / len(proximity_scores) if proximity_scores else 0


def calculate_error_pattern_similarity(errors_a: List[dict], errors_b: List[dict]) -> float:
    """计算两组错题的错误模式相似度"""
    # 提取错误特征向量：错误类型分布
    def get_error_type_distribution(errors):
        dist = defaultdict(int)
        for e in errors:
            dist[e.get('error_type', 'UNKNOWN')] += 1
        total = sum(dist.values())
        return {k: v / total for k, v in dist.items()}
    
    dist_a = get_error_type_distribution(errors_a)
    dist_b = get_error_type_distribution(errors_b)
    
    # 余弦相似度
    all_types = set(dist_a.keys()) | set(dist_b.keys())
    dot_product = sum(dist_a.get(t, 0) * dist_b.get(t, 0) for t in all_types)
    norm_a = math.sqrt(sum(v ** 2 for v in dist_a.values()))
    norm_b = math.sqrt(sum(v ** 2 for v in dist_b.values()))
    
    if norm_a == 0 or norm_b == 0:
        return 0
    
    return dot_product / (norm_a * norm_b)
```

### 5.2 认知维度掌握度计算

```python
def calculate_cognitive_dimension_mastery(
    student_id: int,
    cognitive_dim_code: str,
    period_start: str,
    period_end: str,
    question_cognitive_repo,
    answer_record_repo
) -> dict:
    """
    计算学生在指定认知维度上的跨学科综合掌握度。
    
    掌握度 = Σ(学科掌握度 × 学科权重) / Σ(学科权重)
    学科掌握度 = 正确题数 / 总题数 × 难度调整系数
    """
    # 1. 获取该维度涉及的所有学科
    subject_mappings = question_cognitive_repo.get_subjects_by_dimension(cognitive_dim_code)
    
    subject_mastery_scores = {}
    total_weight = 0
    weighted_sum = 0
    
    for subj_code, weight in subject_mappings:
        # 2. 获取该学科该维度下的所有答题记录
        records = answer_record_repo.get_records_by_student_subject_dimension(
            student_id=student_id,
            subject_code=subj_code,
            cognitive_dim_code=cognitive_dim_code,
            start_date=period_start,
            end_date=period_end
        )
        
        if not records:
            continue
        
        correct = sum(1 for r in records if r['is_correct'])
        total = len(records)
        raw_accuracy = correct / total
        
        # 3. 难度调整：答对难题权重更高
        difficulty_adjustment = calculate_difficulty_adjustment(records)
        adjusted_mastery = raw_accuracy * difficulty_adjustment * 100
        
        subject_mastery_scores[subj_code] = {
            'mastery': round(adjusted_mastery, 2),
            'error_count': total - correct,
            'total_count': total,
            'contribution': weight
        }
        
        weighted_sum += adjusted_mastery * weight
        total_weight += weight
    
    overall_mastery = weighted_sum / total_weight if total_weight > 0 else 0
    
    return {
        'overall_mastery': round(overall_mastery, 2),
        'subject_breakdown': subject_mastery_scores,
        'total_errors': sum(s['error_count'] for s in subject_mastery_scores.values())
    }


def calculate_difficulty_adjustment(records: List[dict]) -> float:
    """
    根据题目难度分布计算调整系数。
    如果学生答对的题目中难题占比高，系数>1；反之<1。
    """
    if not records:
        return 1.0
    
    difficulty_weights = {1: 0.6, 2: 0.8, 3: 1.0, 4: 1.2, 5: 1.5}
    
    total_weight = 0
    correct_weight = 0
    for r in records:
        difficulty = r.get('difficulty_level', 3)
        weight = difficulty_weights.get(difficulty, 1.0)
        total_weight += weight
        if r['is_correct']:
            correct_weight += weight
    
    expected = total_weight / len(records) * (len(records) / 2)  # 50%正确率的期望
    actual_ratio = correct_weight / total_weight if total_weight > 0 else 0
    
    # 将实际正确率通过难度加权后微调
    # 范围: 0.85 ~ 1.15
    adjustment = 0.85 + 0.30 * (actual_ratio - 0.5) * 2
    return max(0.7, min(1.3, adjustment))
```

        mastery_service=None

        if not template:
            return self._generate_generic_pack(student_id, cognitive_dim_code, weak_subjects)

        question_distribution = self._calculate_distribution(
            weak_subjects, template['base_question_count']
        )
        
        # 2. 按阶段选题
        phases = []
        for phase_name in template['phases']:
            phase_questions = self._select_phase_questions(
                student_id=student_id,
                phase_name=phase_name,
                cognitive_dim_code=cognitive_dim_code,
                distribution=question_distribution,
                question_repo=question_repo,
                mastery_service=mastery_service
            )
            phases.append({
                'phase': phase_name,
                'questions': phase_questions
            })
        
        # 3. 计算预估时间
        total_questions = sum(len(p['questions']) for p in phases)
        estimated_minutes = total_questions * 2  # 平均每题2分钟
        
        return {
            'packId': f"ipk_{cognitive_dim_code.lower()}_{student_id}_{DateUtil.today()}",
            'title': f"{template['name']}跨学科训练营",
            'cognitiveDimCode': cognitive_dim_code,
            'totalQuestions': total_questions,

            'estimatedMinutes': estimated_minutes,

        self, subjects: List[str], total: int
    ) -> Dict[str, int]:
        """根据学科薄弱程度分配题目数量"""
        # 最薄弱的学科分配更多题目
        n = len(subjects)
        if n == 0:
            return {}
        
        # 权重递减分配: 第一个学科40%, 第二个35%, 第三个25%
        weights = self._generate_weights(n)
        return {
            subj: max(2, int(total * w))
            for subj, w in zip(subjects, weights)
        }
    
    @staticmethod
    def _generate_weights(n: int) -> List[float]:
        if n == 1:
            return [1.0]
        if n == 2:
            return [0.55, 0.45]
        if n == 3:
            return [0.40, 0.35, 0.25]
        # n >= 4
        base = 1.0 / n
        return [base * (1.3 - 0.15 * i) for i in range(n)]

class DailyCrossSubjectAnalyzer:
    """每日增量跨学科分析器"""
    
    BATCH_SIZE = 200  # 每批处理学生数
    
    async def run_daily_analysis(self, target_date: date):
        """每日增量分析入口"""
        # 1. 获取当日有新增错题的学生列表
        active_student_ids = await self.get_active_students(target_date)
        
        logger.info(
            f"Daily cross-subject analysis: {len(active_student_ids)} students"
        )
        
        # 2. 分批处理
        for i in range(0, len(active_student_ids), self.BATCH_SIZE):
            batch = active_student_ids[i:i + self.BATCH_SIZE]
            
            try:
                await self.process_batch(batch, target_date)
            except Exception as e:
                logger.error(f"Batch {i} failed: {e}")
                # 记录失败批次，等待重试
                await self.record_failed_batch(batch, target_date, str(e))
        
        # 3. 更新认知维度掌握度趋势
        await self.update_mastery_trends(target_date)
    
    async def process_batch(
        self, student_ids: List[int], target_date: date
    ):
        """处理一批学生的跨学科分析"""
        async with DatabaseSession() as session:
            for student_id in student_ids:
                try:
                    await self.analyze_single_student(
                        student_id, target_date, session
                    )
                except Exception as e:
                    logger.warning(
                        f"Student {student_id} analysis failed: {e}, skipping"
                    )
                    continue
    
    async def analyze_single_student(
        self, student_id: int, target_date: date, session
    ):
        """分析单个学生的跨学科错题关联"""
        # 1. 获取学生近7天的错题记录（已标注认知维度）
        recent_errors = await self.fetch_recent_errors(
            student_id, days=7, session=session
        )
        
        # 过滤掉只有一个学科的记录（无法做跨学科分析）
        subjects_involved = set(e['subject_code'] for e in recent_errors)
        if len(subjects_involved) < 2:
            return  # 数据不足，跳过
        
        # 2. 按认知维度分组
        dim_groups = defaultdict(list)
        for error in recent_errors:
            dim_code = error.get('cognitive_dim_code')
            if dim_code:
                dim_groups[dim_code].append(error)
        
        # 3. 对每个维度进行跨学科关联分析
        new_clusters = []
        for dim_code, errors in dim_groups.items():
            # 至少涉及2个学科才分析
            dim_subjects = set(e['subject_code'] for e in errors)
            if len(dim_subjects) < 2:
                continue
            
            # 检查是否已有聚类（避免重复生成）
            existing = await self.get_existing_clusters(
                student_id, dim_code, target_date, session
            )
            
            if existing and not self._needs_update(existing, errors):
                continue
            
            # 计算关联强度
            correlations = calculate_cross_subject_correlation(errors, dim_code)
            
            # 只保留强关联（阈值0.5）
            strong_correlations = {
                k: v for k, v in correlations.items() if v >= 0.5
            }
            
            if not strong_correlations:
                continue
            
            # 创建/更新聚类
            cluster = await self.create_or_update_cluster(
                student_id=student_id,
                dim_code=dim_code,
                errors=errors,
                correlations=strong_correlations,
                session=session
            )
            new_clusters.append(cluster)
        
        # 4. 更新学生的跨学科能力快照
        if new_clusters:
            await self.update_mastery_snapshot(
                student_id, target_date, dim_groups, session
            )
            
            # 5. 检查是否需要触发通知
            await self.check_and_notify(student_id, new_clusters)

class AnalysisFallbackHandler:
    """分析降级处理器"""
    
    def analyze_with_fallback(
        self, student_id: int, errors: List[dict]
    ) -> dict:
        """带降级的分析流程"""
        
        # Level 0: 正常分析
        if len(errors) >= 20 and self._has_multi_subject(errors):
            return self.full_analysis(errors)
        
        # Level 1: 数据不足，简化分析
        if len(errors) >= 10:
            return self.simplified_analysis(errors)
        
        # Level 2: 数据严重不足
        if len(errors) >= 5:
            return {
                'status': 'INSUFFICIENT_DATA',
                'message': '错题数据不足，建议继续学习积累后再分析',
                'partial_results': self.basic_error_summary(errors),
                'recommendation': 'CONTINUE_LEARNING'
            }
        
        # Level 3: 无数据
        return {
            'status': 'NO_DATA',
            'message': '暂无足够的错题数据进行跨学科分析',
            'recommendation': 'NEED_MORE_PRACTICE'
        }
    
    def simplified_analysis(self, errors: List[dict]) -> dict:
        """简化版分析：只做认知维度统计，不做关联聚类"""
        dim_counts = Counter(e.get('cognitive_dim_code', 'UNKNOWN') for e in errors)
        
        return {
            'status': 'SIMPLIFIED',
            'message': '数据量有限，仅提供基础统计',
            'dimension_distribution': dict(dim_counts),
            'top_weak_dimension': dim_counts.most_common(1)[0] if dim_counts else None,
            'recommendation': 'ACCUMULATE_MORE_DATA'
        }
    
    @staticmethod
    def _has_multi_subject(errors: List[dict]) -> bool:
        subjects = set(e['subject_code'] for e in errors)
        return len(subjects) >= 2

            "question_types": ["MULTIPLE_CHOICE", "CONDITION_ANALYSIS"],
            "subjects": ["ALL"]
        }
    }
    
    def match(self, question: dict) -> List[dict]:
        """返回匹配到的认知维度列表"""
        matches = []
        content = question.get('content', '')
        q_type = question.get('question_type', '')
        subject = question.get('subject_code', '')
        
        for dim_code, rule in self.RULES.items():
            score = 0
            
            # 关键词匹配
            keyword_hits = sum(
                1 for kw in rule['keywords'] if kw in content
            )
            score += keyword_hits * 0.15
            
            # 题型匹配
            if q_type in rule['question_types']:
                score += 0.4
            
            # 学科匹配
            if 'ALL' in rule['subjects'] or subject in rule['subjects']:
                score += 0.2
            
            if score >= 0.3:
                matches.append({
                    'cognitive_dim_code': dim_code,
                    'confidence': min(score, 0.95),
                    'source': 'RULE'
                })
        
        return sorted(matches, key=lambda x: x['confidence'], reverse=True)
```

    PROMPT_TEMPLATE = """你是一个教育认知心理学专家。请分析以下题目主要考察学生的哪些认知能力维度。

- 年级: {grade}
- 题型: {question_type}

```json
[
  {{"code": "CR-XX", "weight": 0.0-1.0, "reason": "判断依据"}}
]
```"""
    
    async def annotate(self, question: dict) -> List[dict]:
        """使用大模型标注题目的认知维度"""
        prompt = self.PROMPT_TEMPLATE.format(
            subject=question.get('subject_code', '未知'),
            grade=question.get('grade', '未知'),
            question_type=question.get('question_type', '未知'),
            content=question.get('content', '')[:500]  # 截断防止超长
        )
        
        try:
            response = await self.llm_client.chat(
                model=self.model_name,
                messages=[{"role": "user", "content": prompt}],
                temperature=0.1,  # 低温度保证一致性
                max_tokens=500,
                response_format={"type": "json_object"}
            )
            
            result = self._parse_response(response)
            return result
            
        except Exception as e:
            logger.warning(f"AI annotation failed for question {question.get('id')}: {e}")
            return []
    
    @staticmethod
    def _parse_response(response: str) -> List[dict]:
        """解析大模型返回结果"""
        import json
        try:
            data = json.loads(response)
            if isinstance(data, list):
                return [
                    {
                        'cognitive_dim_code': item['code'],
                        'weight': float(item.get('weight', 0.5)),
                        'confidence': 0.85,
                        'source': 'AI',
                        'reason': item.get('reason', '')
                    }
                    for item in data
                    if item.get('code', '').startswith('CR-')
                ]
        except (json.JSONDecodeError, KeyError):
            pass
        return []
```

### 8.4 批量标注管线

```python
class CognitiveAnnotationPipeline:
    """认知维度批量标注管线"""
    
    async def run_batch_annotation(
        self,
        batch_size: int = 500,
        confidence_threshold: float = 0.7
    ):
        """批量标注未标注的题目"""
        
        # 1. 获取未标注题目
        untagged_ids = await self.question_repo.get_untagged_question_ids(
            limit=batch_size
        )
        
        logger.info(f"Found {len(untagged_ids)} untagged questions")
        
        annotated_count = 0
        for question_id in untagged_ids:
            question = await self.question_repo.get_by_id(question_id)
            if not question:
                continue
            
            # 2. 先尝试规则匹配
            rule_matches = self.rule_matcher.match(question)
            
            # 3. 规则匹配置信度足够则直接采用
            if rule_matches and rule_matches[0]['confidence'] >= confidence_threshold:
                await self.save_tags(question_id, rule_matches)
                annotated_count += 1
                continue
            
            # 4. 规则不足，调用AI标注
            ai_matches = await self.ai_annotator.annotate(question)
            
            if ai_matches:
                # 合并规则和AI结果
                merged = self._merge_matches(rule_matches, ai_matches)
                await self.save_tags(question_id, merged)
                annotated_count += 1
            else:
                # 都无法标注，标记为待人工处理
                await self.mark_for_manual_review(question_id)
        
        logger.info(f"Annotated {annotated_count}/{len(untagged_ids)} questions")
        return annotated_count
```
