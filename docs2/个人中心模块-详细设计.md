# 个人中心（我的）模块 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

个人中心（"我的"页面）是 PrimeTop APP 底部导航的第五个一级入口，承载用户个人信息管理、会员状态与续费、学习数据概览、家长中心入口、系统设置、帮助与反馈等综合功能。它是用户自我管理和产品配置的核心枢纽，直接影响用户留存和会员转化。

### 1.2 覆盖学段

全学段（幼儿至高中），通过分龄 UI 策略展示不同信息密度和功能入口。

### 1.3 优先级

P0 — MVP 阶段核心页面（底部导航 5 个 Tab 之一）

### 1.4 依赖模块

| 依赖模块 | 依赖说明 |
|----------|----------|
| 用户账号体系 | 用户基本信息读写、学生档案、第三方账号绑定 |
| 支付与会员订阅 | 会员状态、权益概览、续费入口、订单记录 |
| 学情分析 | 学习时长、连续天数、掌握度概览数据 |
| 家长中心 | 家长绑定入口、家长控制状态 |
| 消息与推送 | 消息中心入口、未读消息数 |
| 安全与内容合规 | 青少年模式、隐私政策、注销流程 |
| 用户反馈与AI质量评估 | 意见反馈入口 |

### 1.5 功能范围

## 2. 页面结构与布局设计

### 2.1 整体页面结构

个人中心页面采用 **分区卡片 + 列表菜单** 布局，自上而下分为以下区域：

```
┌──────────────────────────────────┐
│ ① 用户信息卡片区                  │  ← 头像 + 昵称 + 学段年级 + 会员标识
│    [编辑资料]                     │
├──────────────────────────────────┤
│ ② 学习数据概览条                  │  ← 连续学习天数 / 今日时长 / 累计时长
├──────────────────────────────────┤
│ ③ 会员状态卡片（非会员为转化卡片） │  ← 会员类型 / 到期时间 / 续费按钮
├──────────────────────────────────┤
│ ④ 功能菜单列表                    │
│   ├── 消息中心                    │  ← 未读角标
│   ├── 家长中心                    │  ← 仅低龄用户显示（≤小学）
│   ├── 青少年模式                  │  ← 开关 + 密码保护
│   ├── 我的订单                    │
│   ├── 学习档案                    │  ← 年级/教材版本设置
│   ├── 意见反馈                    │
│   ├── 设置                        │
│   ├── 隐私政策                    │
│   ├── 关于启硕                    │
│   └── 退出登录                    │
└──────────────────────────────────┘
```

### 2.2 分龄 UI 策略

| 学段 | 区域① 用户卡 | 区域② 数据条 | 区域③ 会员卡 | 区域④ 菜单 |
|------|-------------|-------------|-------------|-----------|
| 幼儿 | 大头像、可爱昵称、星星装饰 | 简化为"学习星星数" | 不突出，弱化商业感 | 精简：家长中心突出，隐藏设置/订单 |
| 小学 | 头像+昵称+年级标签 | 连续天数+今日星星 | 温和引导："升级获得更多功能" | 家长中心入口可见 |
| 初中 | 头像+昵称+年级+教材版本 | 连续天数+今日时长+本周排名 | 会员权益+到期时间 | 完整功能菜单 |
| 高中 | 简洁头像行+年级信息 | 连续天数+累计时长+薄弱项数 | 会员类型+权益使用量 | 完整功能菜单+高考专区入口 |

## 3. 数据结构定义

### 3.1 个人中心聚合响应 DTO

个人中心页面通过一个聚合 API 获取所有展示数据，减少多次请求。

```typescript
// GET /api/v1/user/profile-center
interface ProfileCenterResponse {
  // 用户基本信息
  user: {
    id: number;
    nickname: string;
    avatarUrl: string | null;
    gender: 0 | 1 | 2;           // 未知/男/女
    phone: string;                 // 脱敏: 138****1234
    phoneVerified: boolean;
    birthday: string | null;       // YYYY-MM-DD
  };

  // 学生档案
  studentProfile: {
    stage: 'preschool' | 'primary' | 'junior' | 'senior';
    stageLabel: string;            // "小学" / "初中" 等
    grade: number;                 // 0-12
    gradeLabel: string;            // "三年级" / "高一" 等
    semester: 'first' | 'second';
    textbookEdition: string | null;
    textbookEditionLabel: string | null;
  } | null;                        // 家长账号可能为 null

  // 会员信息
  membership: {
    level: 'free' | 'monthly' | 'annual' | 'exam_zhongkao' | 'exam_gaokao';
    levelLabel: string;            // "免费用户" / "年度会员" 等
    expireAt: string | null;       // ISO8601
    daysRemaining: number | null;  // null 表示永久或免费
    isExpiringSoon: boolean;       // ≤7 天为 true
    autoRenew: boolean;
  };

  // 学习数据概览
  studySummary: {
    consecutiveDays: number;       // 连续学习天数
    todayMinutes: number;          // 今日学习分钟数
    totalMinutes: number;          // 累计学习分钟数
    totalQuestions: number;        // 累计答题数
    totalMistakes: number;         // 累计错题数
  };

  // 消息
  unreadMessageCount: number;

  // 家长中心状态
  parentCenter: {
    isBound: boolean;              // 是否已绑定家长
    parentNickname: string | null;
    hasControlEnabled: boolean;    // 家长管控是否开启
  } | null;                        // 高中用户可隐藏

  // 青少年模式
  teenMode: {
    enabled: boolean;
    protectedByPassword: boolean;
  };

  // 第三方绑定状态
  oauthBindings: Array<{
    provider: 'wechat' | 'apple';
    bound: boolean;
    nickname: string | null;
  }>;
}
```

#### 4.2.3 更新学生档案（年级/教材版本切换）

```
PUT /api/v1/user/student-profile
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求体：**

```json
{
  "stage": "junior",
  "grade": 7,
  "semester": "first",
  "textbookEdition": "renjia"
}
```

**业务逻辑：**

1. **年级升级场景**：用户从小学升初中，触发以下联动：
   - 更新 `student_profiles` 表
   - 清除学情分析中的过期掌握度数据（标记为新学段重置）
   - 重新匹配同步课堂目录
   - 重置学习规划中的长期计划（保留短期任务）
   - 发送"升级恭喜"消息

2. **教材版本切换**：
   - 更新 `student_profiles.textbook_edition`
   - 触发同步课堂章节目录重新加载
   - 已有错题保持不变（知识点通用映射）
   - 学习进度标记需重新适配

3. **学期切换**：
   - 更新 `student_profiles.semester`
   - 同步课堂目录切换到对应学期

**年级与学段一致性校验：**

```python
# 年级与学段映射关系
GRADE_STAGE_MAP = {
    range(0, 3):  "preschool",   # 幼儿园小班-大班
    range(3, 9):  "primary",     # 小学一年级-六年级
    range(9, 12): "junior",      # 初一-初三
    range(12, 15): "senior",     # 高一-高三
}

def validate_grade_stage(stage: str, grade: int) -> bool:
    """校验年级与学段是否匹配"""
    for grade_range, mapped_stage in GRADE_STAGE_MAP.items():
        if grade in grade_range:
            return mapped_stage == stage
    return False
```

#### 4.2.4 上传头像

```
PUT /api/v1/user/avatar
Authorization: Bearer <access_token>
Content-Type: multipart/form-data
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | ✅ | 图片文件 |
| x | float | ❌ | 裁剪起始 X（0-1 比例） |
| y | float | ❌ | 裁剪起始 Y（0-1 比例） |
| width | float | ❌ | 裁剪宽度（0-1 比例） |
| height | float | ❌ | 裁剪高度（0-1 比例） |

**处理流程：**

```
客户端裁剪 → 上传原图+裁剪参数 → 服务端验证(≤5MB, jpg/png/webp)
    → 图片处理管线(裁剪+压缩+转webp, 目标 200x200)
    → 上传 OSS → CDN 分发 → 更新 users.avatar_url → 返回新 URL
```

**限制：**
- 文件大小：≤ 5MB
- 支持格式：JPEG、PNG、WebP
- 上传频率：每分钟最多 5 次
- 头像存储路径：`/avatars/{user_id}_{timestamp}.webp`

#### 4.2.5 退出登录

```
POST /api/v1/auth/logout
Authorization: Bearer <access_token>
Content-Type: application/json
```

**请求体：**

```json
{
  "deviceId": "device_abc123",
  "logoutAll": false
}
```

**处理逻辑：**

1. 将该设备的 `refresh_token` 标记为已注销
2. 若 `logoutAll=true`，将该用户所有设备的 `refresh_token` 全部注销
3. 当前 `access_token` 加入黑名单（Redis TTL = token 剩余有效期）
4. 客户端清除本地存储的 token、用户缓存数据
5. 保留本地错题、学习进度等离线数据（重新登录后可同步）

**响应：**

```json
{
  "code": 0,
  "message": "退出成功"
}
```

#### 4.2.6 账号注销流程

账号注销采用 **申请 → 冷静期 → 确认 → 删除** 的多步流程，符合《个人信息保护法》要求。

```
用户申请注销 → 短信验证码验证 → 进入 7 天冷静期
    → 冷静期内可随时撤销
    → 7 天后可确认注销
    → 确认后进入 15 天保留期（仅标记，数据不可访问）
    → 保留期结束后异步清理数据
```

**申请注销接口：**

```
POST /api/v1/user/cancel-account
```

```json
{
  "reason": "不再需要",
  "verificationCode": "123456"
}
```

**校验：**
- 必须已绑定手机号且通过验证
- 不能有未完成的有效订阅（需先取消订阅）
- 不能有未处理完的退款

**数据清理范围：**

| 数据 | 处理方式 |
|------|----------|
| 用户基本信息 | 硬删除 |
| 学生档案 | 硬删除 |
| 第三方绑定 | 解绑并删除记录 |
| AI 对话记录 | 软删除（保留匿名统计） |
| 错题记录 | 硬删除 |
| 学习记录 | 软删除（保留匿名统计） |
| 订单记录 | 保留（财务合规要求），脱敏用户信息 |
| 文件资源（头像等） | 异步清理 OSS 对象 |
| 缓存数据 | 立即清除 Redis 相关 key |

```python
# services/profile_center_service.py

class ProfileCenterService:
    """个人中心聚合数据服务"""

    def __init__(self,
                 user_repo: UserRepository,
                 student_profile_repo: StudentProfileRepository,
                 membership_service: MembershipService,
                 study_analytics_service: StudyAnalyticsService,
                 parent_service: ParentService,
                 message_service: MessageService,
                 cache: RedisCache):
        self.user_repo = user_repo
        self.student_profile_repo = student_profile_repo
        self.membership_service = membership_service
        self.study_analytics_service = study_analytics_service
        self.parent_service = parent_service
        self.message_service = message_service
        self.cache = cache

    async def get_profile_center(self, user_id: int) -> ProfileCenterResponse:
        """获取个人中心聚合数据"""

        # 1. 尝试缓存
        cache_key = f"profile_center:{user_id}"
        cached = await self.cache.get(cache_key)
        if cached:
            return ProfileCenterResponse(**json.loads(cached))

        # 2. 并行查询各模块数据
        results = await asyncio.gather(
            self._get_user_info(user_id),
            self._get_student_profile(user_id),
            self._get_membership(user_id),
            self._get_study_summary(user_id),
            self._get_parent_status(user_id),
            self._get_unread_count(user_id),
            self._get_teen_mode(user_id),
            self._get_oauth_bindings(user_id),
            return_exceptions=True,
        )

        # 3. 组装响应（容错处理）
        user, profile, membership, summary, parent, \
            unread, teen_mode, oauth = results

        response = ProfileCenterResponse(
            user=user if not isinstance(user, Exception) else None,
            student_profile=profile if not isinstance(profile, Exception) else None,
            membership=membership if not isinstance(membership, Exception)
              else MembershipInfo(level='free', levelLabel='免费用户', ...),
            study_summary=summary if not isinstance(summary, Exception)
              else StudySummary(consecutiveDays=0, todayMinutes=0, ...),
            unread_message_count=unread if not isinstance(unread, Exception) else 0,
            parent_center=parent if not isinstance(parent, Exception) else None,
            teen_mode=teen_mode if not isinstance(teen_mode, Exception)
              else TeenMode(enabled=False, protectedByPassword=False),
            oauth_bindings=oauth if not isinstance(oauth, Exception) else [],
        )

        # 4. 缓存 10 分钟
        await self.cache.set(cache_key, response.json(), ttl=600)

        return response

    async def _get_study_summary(self, user_id: int) -> StudySummary:
        """从学情分析服务获取概览数据"""
        return await self.study_analytics_service.get_summary(user_id)

    async def _get_parent_status(self, user_id: int) -> ParentCenterStatus | None:
        """获取家长中心状态，高中用户不显示"""
        user = await self.user_repo.get_by_id(user_id)
        profile = await self.student_profile_repo.get_by_user_id(user_id)

        # 高中用户不显示家长中心入口
        if profile and profile.stage == 'senior':
            return None

        binding = await self.parent_service.get_binding(user_id)
        if not binding:
            return ParentCenterStatus(isBound=False, ...)

        return ParentCenterStatus(
            isBound=True,
            parentNickname=binding.parent_nickname,
            hasControlEnabled=binding.control_enabled,
        )
```

```python
# services/student_profile_service.py

class StudentProfileService:
    """学生档案更新服务"""

    def __init__(self,
                 profile_repo: StudentProfileRepository,
                 event_bus: EventBus,
                 cache: RedisCache):
        self.profile_repo = profile_repo
        self.event_bus = event_bus
        self.cache = cache

    async def update_profile(self, user_id: int, request: UpdateStudentProfileRequest) -> StudentProfile:
        """更新学生档案，处理联动逻辑"""

        # 1. 获取当前档案
        current = await self.profile_repo.get_by_user_id(user_id)
        if not current:
            raise BusinessError(ErrorCode.PROFILE_NOT_FOUND, "学生档案不存在")

        # 2. 校验学段-年级一致性
        if not validate_grade_stage(request.stage, request.grade):
            raise BusinessError(ErrorCode.INVALID_GRADE_STAGE, "学段与年级不匹配")

        # 3. 检测是否为重大变更
        is_stage_change = current.stage != request.stage
        is_grade_change = current.grade != request.grade
        is_textbook_change = current.textbook_edition != request.textbook_edition

        # 4. 更新数据库
        current.stage = request.stage
        current.grade = request.grade
        current.semester = request.semester
        if request.textbook_edition:
            current.textbook_edition = request.textbook_edition
        await self.profile_repo.save(current)

        # 5. 清除缓存
        await self.cache.delete(f"profile_center:{user_id}")
        await self.cache.delete(f"student_profile:{user_id}")

        # 6. 发布领域事件（触发联动）
        if is_stage_change or is_grade_change:
            await self.event_bus.publish(StudentGradeChangedEvent(
                user_id=user_id,
                old_stage=current.stage,
                new_stage=request.stage,
                old_grade=current.grade,
                new_grade=request.grade,
            ))

        if is_textbook_change:
            await self.event_bus.publish(TextbookChangedEvent(
                user_id=user_id,
                old_textbook=current.textbook_edition,
                new_textbook=request.textbook_edition,
            ))

        return current
```

```python
    ALLOWED_TYPES = {'image/jpeg', 'image/png', 'image/webp'}
    MAX_SIZE = 5 * 1024 * 1024  # 5MB
    TARGET_SIZE = (200, 200)

    def __init__(self,
                 user_repo: UserRepository,
                 storage_service: StorageService,
                 image_processor: ImageProcessor,
                 cache: RedisCache,
                 rate_limiter: RateLimiter):
        self.user_repo = user_repo
        self.storage = storage_service
        self.image_processor = image_processor
        self.cache = cache
        self.rate_limiter = rate_limiter

    async def upload_avatar(self, user_id: int, file: UploadFile,
                            crop: CropParams | None = None) -> str:
        """上传并处理头像"""

        # 1. 频率限制
        key = f"avatar_upload:{user_id}"
        if not await self.rate_limiter.allow(key, max_requests=5, window=60):
            raise BusinessError(ErrorCode.RATE_LIMITED, "上传过于频繁，请稍后再试")

        # 2. 验证文件
        content = await file.read()
        if len(content) > self.MAX_SIZE:
            raise BusinessError(ErrorCode.FILE_TOO_LARGE, "图片大小不能超过5MB")

        content_type = file.content_type
        if content_type not in self.ALLOWED_TYPES:
            raise BusinessError(ErrorCode.INVALID_FILE_TYPE, "仅支持 JPG/PNG/WebP 格式")

        # 3. 图片处理：裁剪 + 压缩 + 转 WebP
        processed = await self.image_processor.process(
            content,
            crop=crop,
            resize=self.TARGET_SIZE,
            output_format='webp',
            quality=85,
        )

        # 4. 上传到 OSS
        timestamp = int(time.time())
        object_key = f"avatars/{user_id}_{timestamp}.webp"
        avatar_url = await self.storage.upload(
            object_key=object_key,
            data=processed,
            content_type='image/webp',
        )

        # 5. 更新用户头像 URL
        old_avatar_url = await self.user_repo.get_avatar_url(user_id)
        await self.user_repo.update_avatar_url(user_id, avatar_url)

        # 6. 异步清理旧头像
        if old_avatar_url:
            asyncio.create_task(self.storage.delete_old_avatar(
                old_avatar_url, delay_hours=24))

        # 7. 清除缓存
        await self.cache.delete(f"profile_center:{user_id}")

        return avatar_url
```

## 8. 错误处理

### 8.1 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 处理建议 |
|--------|------------|------|----------|
| `PROFILE_NOT_FOUND` | 404 | 学生档案不存在 | 引导用户完善档案 |
| `INVALID_NICKNAME` | 400 | 昵称格式不合法 | 提示修改 |
| `INVALID_AVATAR_URL` | 400 | 头像 URL 不合法 | 重新上传 |
| `INVALID_GRADE_STAGE` | 400 | 学段与年级不匹配 | 提示正确搭配 |
| `INVALID_BIRTHDAY` | 400 | 出生日期不合法 | 提示年龄范围 3-18 |
| `INVALID_FILE_TYPE` | 400 | 文件类型不支持 | 提示支持格式 |
| `FILE_TOO_LARGE` | 400 | 文件超过 5MB | 压缩后重试 |
| `RATE_LIMITED` | 429 | 操作过于频繁 | 等待后重试 |
| `ACTIVE_SUBSCRIPTION_EXISTS` | 400 | 存在有效订阅，无法注销 | 先取消订阅 |
| `VERIFICATION_CODE_ERROR` | 400 | 验证码错误 | 重新获取 |
| `CANCEL_IN_COOLING` | 409 | 注销在冷静期中 | 等待或撤销 |
| `CANCEL_NOT_FOUND` | 404 | 无注销申请 | — |
| `TEEN_MODE_PASSWORD_LOCKED` | 423 | 密码错误次数过多锁定 | 等待 30 分钟 |
| `OAUTH_UNBIND_LAST` | 400 | 最后一个登录方式不可解绑 | 至少保留一种 |
| `LOGOUT_FAILED` | 500 | 退出登录失败 | 重试 |

### 8.2 客户端错误处理策略

```dart
// 统一错误处理
Future<void> _handleError(Object error, StackTrace stack) async {
  if (error is ApiError) {
    switch (error.code) {
      case 'PROFILE_NOT_FOUND':
        // 引导完善档案
        _showProfileSetupDialog();
        break;
      case 'RATE_LIMITED':
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text('操作过于频繁，请稍后再试')));
        break;
      case 'INVALID_GRADE_STAGE':
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text('学段与年级不匹配，请重新选择')));
        break;
      default:
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(content: Text(error.message ?? '操作失败')));
    }
  } else if (error is NetworkError) {
    // 网络错误 — 展示离线提示
    _showOfflineBanner();
  } else {
    // 未知错误 — 上报
    Crashlytics.recordError(error, stack);
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('发生未知错误，请稍后再试')));
  }
}
```

## 9. 安全考虑

### 9.1 敏感数据保护

| 数据 | 保护措施 |
|------|----------|
| 手机号 | 服务端脱敏返回（138\*\*\*\*1234），完整号码仅短信验证时可见 |
| 头像 URL | CDN 防盗链 + 签名 URL（有效期 1 小时） |
| 青少年模式密码 | 不可读取，仅支持验证（哈希比对） |
| 注销验证码 | 60 秒有效期，每天最多发送 5 次 |

### 9.2 防刷策略

| 接口 | 限制 | 策略 |
|------|------|------|
| 头像上传 | 5次/分钟 | 用户维度限流 |
| 个人资料修改 | 10次/分钟 | 用户维度限流 |
| 注销申请 | 3次/天 | 用户维度限流 |
| 退出登录 | 10次/分钟 | 设备维度限流 |

- 订单记录保留（财务合规要求），用户信息脱敏

- 注销全程记录审计日志
