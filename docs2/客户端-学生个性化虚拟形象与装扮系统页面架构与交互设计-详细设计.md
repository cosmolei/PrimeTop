# 客户端-学生个性化虚拟形象与装扮系统页面架构与交互设计-详细设计

## 1. 概述

### 1.1 功能定位

学生个性化虚拟形象与装扮系统是 PrimeTop 学生端的关键用户 engagement 模块，允许学生创建和定制自己的数字分身（Avatar），通过学习行为解锁装扮道具，增强学习成就感和平台归属感。

本模块是 `服务端-学生个性化虚拟形象系统与装扮解锁引擎` 的客户端配套设计，聚焦于页面架构、交互流程、渲染引擎、状态管理和资源管理。

### 1.2 目标用户

| 用户群体 | 特征 | 设计重点 |
| --- | --- | --- |
| 幼儿/小学低年级（3-9岁） | 操作能力弱、视觉偏好鲜明 | 大按钮、语音引导、预设组合 |
| 小学高年级/初中（10-15岁） | 个性化需求强、社交分享欲强 | 丰富搭配选项、社交展示 |
| 高中（15-18岁） | 审美成熟、效率优先 | 快速切换、简洁 UI |

### 1.3 核心价值

1. **学习激励**：装扮道具作为学习里程碑的视觉奖励，驱动持续学习
2. **身份认同**：虚拟形象代表学生在平台中的数字身份
3. **社交连接**：形象出现在排行榜、学习圈、协作学习等社交场景
4. **商业化潜力**：高级装扮可作为会员增值权益或积分商城兑换商品

### 1.4 适用范围

- 学生端 APP（Flutter，iOS/Android 双端）
- 与之交互的服务端 API（见 `服务端-学生个性化虚拟形象系统与装扮解锁引擎-详细设计`）
- 依赖的下游模块：积分系统、会员系统、成就系统、排行榜、学习圈

#### 5.1.3 形象预览渲染引擎

形象预览采用 Flutter Custom Painter + 分层精灵图合成方案：

```dart
class AvatarRenderer extends StatefulWidget {
  final AvatarConfig config;
  final AvatarResourceManager resourceManager;
  final double width;
  final double height;
  final bool interactive;

  @override
  State<AvatarRenderer> createState() => _AvatarRendererState();
}

class _AvatarRendererState extends State<AvatarRenderer>
    with TickerProviderStateMixin {
  late final AnimationController _idleController;
  late final AnimationController _blinkController;
  late final AnimationController _reactionController;
  double _rotationY = 0.0;
  double _scale = 1.0;

  @override
  void initState() {
    super.initState();
    // 待机呼吸动画（持续循环）
    _idleController = AnimationController(
      vsync: this,
      duration: const Duration(seconds: 3),
    )..repeat(reverse: true);

    // 眨眼动画（随机间隔触发）
    _blinkController = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 150),
    );

    _scheduleNextBlink();

    // 互动反应动画（点击时触发）
    _reactionController = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 800),
    );
  }

  void _scheduleNextBlink() {
    final delay = Duration(seconds: Random().nextInt(4) + 2);
    Future.delayed(delay, () {
      if (mounted) {
        _blinkController.forward().then((_) {
          _blinkController.reverse();
          _scheduleNextBlink();
        });
      }
    });
  }

  @override
  void dispose() {
    _idleController.dispose();
    _blinkController.dispose();
    _reactionController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onHorizontalDragUpdate: (details) {
        if (widget.interactive) {
          setState(() {
            _rotationY += details.delta.dx * 0.01;
            _rotationY = _rotationY.clamp(-0.5, 0.5);
          });
        }
      },
      onHorizontalDragEnd: (_) {
        // 弹性回正
        if (_rotationY != 0) {
          setState(() => _rotationY = 0);
        }
      },
      onScaleUpdate: (details) {
        if (widget.interactive) {
          setState(() {
            _scale = (details.scale * _scale).clamp(0.8, 1.5);
          });
        }
      },
      onTap: () {
        _triggerReaction();
      },
      child: AnimatedBuilder(
        animation: Listenable.merge([
          _idleController,
          _blinkController,
          _reactionController,
        ]),
        builder: (context, _) {
          return CustomPaint(
            painter: AvatarCompositePainter(
              config: widget.config,
              resourceManager: widget.resourceManager,
              idleValue: _idleController.value,
              blinkValue: _blinkController.value,
              reactionValue: _reactionController.value,
              rotationY: _rotationY,
              scale: _scale,
            ),
```

#### 5.1.4 分层渲染顺序

渲染采用 Z-Order 分层叠加（从底到顶）：

```
Z-Order（底 → 顶）：
1. background      背景层
2. backItem       背饰层（翅膀/书包）
3. body            身体基础层（肤色/体型）
4. bottom          下装层
5. shoes           鞋子层
6. top             上装层
7. dress           连衣裙层（如穿着）
8. arms            手臂层
9. head            头部基础层（脸型/肤色）
10. face           面部细节层（眼睛/鼻子/嘴巴）
11. hairStyle      发型层
12. eyewear        眼镜层
13. faceAccessory  面饰层
14. headwear       头饰层
15. necklace       项链层
16. emoji          表情/动作叠加层
17. frame          头像框层（最顶层）
```

```dart
class AvatarCompositePainter extends CustomPainter {
  final AvatarConfig config;
  final AvatarResourceManager resourceManager;
  final double idleValue;   // 0.0~1.0 呼吸值
  final double blinkValue;  // 0.0~1.0 眨眼值
  final double reactionValue;
  final double rotationY;
  final double scale;

  @override
  void paint(Canvas canvas, Size size) {
    canvas.save();
    // 应用缩放和旋转
    canvas.translate(size.width / 2, size.height / 2);
    canvas.scale(scale);
    // 模拟Y轴旋转（简化的透视变换）
    final matrix = Matrix4.identity()
      ..setEntry(3, 2, 0.001)
      ..rotateY(rotationY);
    canvas.transform(matrix.storage);
    canvas.translate(-size.width / 2, -size.height / 2);

    // 呼吸效果：整体微幅上下浮动
    final breatheOffset = sin(idleValue * pi) * 2.0;
    canvas.translate(0, -breatheOffset);

    // 按Z-Order分层绘制
    _drawLayer(canvas, size, LayerType.background);
    _drawLayer(canvas, size, LayerType.backItem);
    _drawBody(canvas, size);
    _drawLayer(canvas, size, LayerType.bottom);
    _drawLayer(canvas, size, LayerType.shoes);
    _drawLayer(canvas, size, LayerType.top);
    _drawLayer(canvas, size, LayerType.dress);
    _drawArms(canvas, size);
    _drawHead(canvas, size);
    _drawLayer(canvas, size, LayerType.hair);
    _drawLayer(canvas, size, LayerType.eyewear);
    _drawLayer(canvas, size, LayerType.faceAccessory);
    _drawLayer(canvas, size, LayerType.headwear);
    _drawLayer(canvas, size, LayerType.necklace);
    _drawLayer(canvas, size, LayerType.emoji);
    _drawLayer(canvas, size, LayerType.frame);

    canvas.restore();
  }

  void _drawLayer(Canvas canvas, Size size, LayerType type) {
    final item = _getEquippedItem(type);
    if (item == null) return;

    final image = resourceManager.getCachedImage(item.assetKey, item.variant);
    if (image == null) {
      // 加载占位符
      _drawPlaceholder(canvas, size, type);
      return;
    }

    // 眨眼变换（仅影响眼部图层区域）
    if (type == LayerType.hair && blinkValue > 0) {
      canvas.save();
      final eyeY = size.height * 0.38;
      final eyeHeight = 8.0 * (1.0 - blinkValue);
      canvas.clipRect(Rect.fromCenter(
        center: Offset(size.width / 2, eyeY),
        width: size.width,
        height: eyeHeight * 2,
      ));
    }

    canvas.drawImageRect(
      image,
      Offset.zero & image.size,
      Offset.zero & size,
      Paint()..filterQuality = FilterQuality.high,
    );

    if (type == LayerType.hair && blinkValue > 0) {
      canvas.restore();
    }
  }

  // ... 其他绘制方法
}
```

```dart
    }

      faceShape: option.appliesTo == CustomizeTab.faceShape
          ? option.value as AvatarFaceShape
          : _workingConfig.faceShape,
      // ... 其他字段同理
    );

    _hasUnsavedChanges = true;
    notifyListeners();
  }

  /// 选择颜色变体
  void selectColorVariant(int variantIndex) {
    // 更新当前选中道具的颜色变体
    _hasUnsavedChanges = true;
    notifyListeners();
  }

  /// 保存
  Future<SaveResult> save() async {
    if (!_hasUnsavedChanges) return SaveResult.noChanges;

    _isSaving = true;
    notifyListeners();

    try {
      final result = await _repository.saveConfig(
        config: _workingConfig,
        expectedVersion: _originalConfig.version,
      );

      _originalConfig = _workingConfig.copyWith(version: result.newVersion);
      _hasUnsavedChanges = false;

      return SaveResult.success(result);
    } on VersionConflictException catch (e) {
      return SaveResult.conflict(e.serverConfig);
    } catch (e) {
      return SaveResult.failure(e.toString());
    } finally {
      _isSaving = false;
      notifyListeners();
    }
  }

  /// 随机搭配
  Future<void> randomize() async {
    final randomConfig = await _repository.getRandomConfig();
    _workingConfig = randomConfig;
    _hasUnsavedChanges = true;
    notifyListeners();
  }

  /// 检查是否有未保存的修改（用于返回拦截）
  bool get hasUnsavedChanges => _hasUnsavedChanges;
}
```

```dart
class AvatarPhotoViewModel extends ChangeNotifier {
  final AvatarRepository _repository;
  final ShareService _shareService;

  String _selectedBackground = 'item_bg_library';
  String _selectedPose = 'peace';
  String _selectedFilter = 'none';
  String? _selectedSticker;
  PhotoFormat _format = PhotoFormat.square;
  bool _isGenerating = false;
  String? _generatedImageUrl;

  /// 生成分享图片
  Future<void> generateSnapshot() async {
    _isGenerating = true;
    _generatedImageUrl = null;
    notifyListeners();

    try {
      // 方案A：服务端渲染（高质量）
      final result = await _repository.generateSnapshot(
        background: _selectedBackground,
        pose: _selectedPose,
        filter: _selectedFilter,
        sticker: _selectedSticker,
        format: _format,
      );
      _generatedImageUrl = result.imageUrl;
    } catch (e) {
      // 方案B：降级为客户端本地渲染
      _generatedImageUrl = await _renderLocally();
    } finally {
      _isGenerating = false;
      notifyListeners();
    }
  }

  /// 本地渲染降级方案
  Future<String> _renderLocally() async {
    final recorder = PictureRecorder();
    final canvas = Canvas(recorder);

    // 1. 绘制背景
    final bgImage = await _resourceManager.loadImage(_selectedBackground);
    canvas.drawImageRect(bgImage, Offset.zero & bgImage.size, _targetRect, Paint());

    // 2. 绘制形象（使用当前的 AvatarConfig）
    _drawAvatarOnCanvas(canvas, _targetRect);

    // 3. 应用滤镜
    final filteredImage = _applyFilter(canvas, _selectedFilter);

    // 4. 绘制贴纸
    if (_selectedSticker != null) {
      _drawSticker(filteredImage, _selectedSticker!);
    }

    // 5. 绘制水印/品牌标识
    _drawWatermark(filteredImage);

    // 6. 导出为图片文件
    final picture = recorder.endRecording();
    final image = await picture.toImage(_width, _height);
    final byteData = await image.toByteData(format: ImageByteFormat.png);

    final tempDir = await getTemporaryDirectory();
    final filePath = '${tempDir.path}/avatar_share_${DateTime.now().millisecondsSinceEpoch}.png';
    final file = File(filePath);
    await file.writeAsBytes(byteData!.buffer.asUint8List());

    return filePath;
  }

  /// 分享到外部平台
  Future<void> shareToPlatform(ShareTarget target) async {
    if (_generatedImageUrl == null) {
      await generateSnapshot();
    }

    await _shareService.share(
      target: target,
      imagePath: _generatedImageUrl!,
      text: '来看看我在 PrimeTop 的学习形象！✨',
    );
  }
}
```

```dart
class AvatarResourceManager {
  static final AvatarResourceManager _instance = AvatarResourceManager._();
  factory AvatarResourceManager() => _instance;
  AvatarResourceManager._();

  final Map<String, ui.Image> _imageCache = {};
  final Set<String> _loadingKeys = {};
  final Map<String, String> _assetBundlePaths = {};

  /// 获取道具图片（多层降级策略）
  Future<ui.Image?> getItemImage(String assetKey, {int variant = 0}) async {
    final cacheKey = '${assetKey}_v$variant';

    // 1. 内存缓存命中
    if (_imageCache.containsKey(cacheKey)) {
      return _imageCache[cacheKey];
    }

    // 防止重复加载
    if (_loadingKeys.contains(cacheKey)) {
      await _waitForLoad(cacheKey);
      return _imageCache[cacheKey];
    }

    _loadingKeys.add(cacheKey);

    try {
      ui.Image? image;

      // 2. 检查本地资源包
      image = await _loadFromBundle(assetKey, variant);

      // 3. 检查缓存目录
      if (image == null) {
        image = await _loadFromCache(assetKey, variant);
      }

      // 4. 从CDN下载
      if (image == null) {
        image = await _downloadFromCDN(assetKey, variant);
      }

      if (image != null) {
        _imageCache[cacheKey] = image;
      }

      return image;
    } finally {
      _loadingKeys.remove(cacheKey);
    }
  }

  /// 同步获取已缓存的图片（用于 CustomPainter）
  ui.Image? getCachedImage(String assetKey, {int variant = 0}) {
    return _imageCache['${assetKey}_v$variant'];
  }

  /// 预加载形象所需的所有资源
  Future<void> preloadAvatarAssets(AvatarConfig config) async {
    final futures = <Future<void>>[];

    // 基础外貌资源
    futures.add(_preloadBaseAssets(config));

    // 所有已装备道具
    for (final item in config.equippedItems) {
      futures.add(_preloadItem(item));
    }

    // 背景和框
    futures.add(_preloadSingle(config.backgroundId));
    futures.add(_preloadSingle(config.frameId));

    await Future.wait(futures);
  }

  /// 清理不常用的缓存
  Future<void> cleanupCache({int maxCacheSize = 200}) async {
    if (_imageCache.length <= maxCacheSize) return;

    // 按 LRU 策略清理（简化版：随机清除超出部分）
    final keysToRemove = _imageCache.keys
        .take(_imageCache.length - maxCacheSize)
        .toList();

    for (final key in keysToRemove) {
      _imageCache.remove(key);
    }
  }

  /// 下载资源包
  Future<void> downloadAssetBundle(String bundleId) async {
    final downloadUrl = '${Config.cdnBaseUrl}/avatar/bundles/$bundleId.zip';
    final savePath = '${(await getApplicationDocumentsDirectory()).path}/avatar/downloaded/$bundleId';

    await DownloadManager().downloadAndUnzip(
      url: downloadUrl,
      destination: savePath,
      onProgress: (received, total) {
        // 更新下载进度
      },
    );

    _assetBundlePaths[bundleId] = savePath;
    _loadBundleManifest(savePath);
  }

  Future<ui.Image?> _loadFromBundle(String assetKey, int variant) async {
    // 从本地资源包中加载
    final bundlePath = _findBundleForAsset(assetKey);
    if (bundlePath == null) return null;

    final filePath = '$bundlePath/$assetKey/var_$variant.webp';
    if (!await File(filePath).exists()) return null;

    final bytes = await File(filePath).readAsBytes();
    final codec = await ui.instantiateImageCodec(bytes);
    return (await codec.getNextFrame()).image;
  }

  Future<ui.Image?> _downloadFromCDN(String assetKey, int variant) async {
    final url = '${Config.cdnBaseUrl}/avatar/items/$assetKey/var_$variant.webp';

    try {
      final response = await http.get(Uri.parse(url));
      if (response.statusCode != 200) return null;

      // 保存到缓存目录
      final cachePath = await _getCachePath(assetKey, variant);
      await File(cachePath).create(recursive: true);
      await File(cachePath).writeAsBytes(response.bodyBytes);

      final codec = await ui.instantiateImageCodec(response.bodyBytes);
      return (await codec.getNextFrame()).image;
    } catch (e) {
      return null;
    }
  }
}
```

```dart
class AvatarConfigNotifier extends StateNotifier<AsyncValue<AvatarConfig>> {
  final ApiClient _apiClient;

  AvatarConfigNotifier(this._apiClient) : super(const AsyncValue.loading());

  Future<void> load() async {
    state = const AsyncValue.loading();
    try {
      final config = await _apiClient.get<AvatarConfig>('/api/v1/avatar/config');
      state = AsyncValue.data(config);

      // 预加载资源
      AvatarResourceManager().preloadAvatarAssets(config);
    } catch (e, st) {
      state = AsyncValue.error(e, st);
    }
  }

  /// 装备道具（乐观更新）
  Future<void> equipItem(String slotId, String itemId, {int variant = 0}) async {
    final current = state.valueOrNull;
    if (current == null) return;

    // 乐观更新：立即反映到UI
    final updated = _applyEquip(current, slotId, itemId, variant);
    state = AsyncValue.data(updated);

    try {
      final result = await _apiClient.post<EquipResult>(
        '/api/v1/avatar/equip',
        body: {'slotId': slotId, 'itemId': itemId, 'variant': variant},
      );

      // 处理冲突（如装备上衣时自动卸下连衣裙）
      if (result.conflictResolved.isNotEmpty) {
        final conflictAdjusted = _applyConflicts(updated, result.conflictResolved);
        state = AsyncValue.data(conflictAdjusted);
      }
    } catch (e) {
      // 回滚
      state = AsyncValue.data(current);
      // 通知UI显示错误
      ref.read(errorNotifierProvider.notifier).show(
        message: '装备失败，请重试',
      );
    }
  }

  /// 卸下道具（乐观更新）
  Future<void> unequipItem(String slotId) async {
    final current = state.valueOrNull;
    if (current == null) return;

    final updated = _removeEquip(current, slotId);
    state = AsyncValue.data(updated);

    try {
      await _apiClient.delete('/api/v1/avatar/equip/$slotId');
    } catch (e) {
      state = AsyncValue.data(current);
    }
  }

  AvatarConfig _applyEquip(AvatarConfig config, String slotId, String itemId, int variant) {
    final items = List<EquippedItem>.from(config.equippedItems);

    // 移除同槽位的旧道具
    items.removeWhere((e) => e.slotId == slotId);

    // 检查互斥规则（如上装和连衣裙互斥）
    final mutuallyExclusive = _getMutuallyExclusiveSlots(slotId);
    for (final mutexSlot in mutuallyExclusive) {
      items.removeWhere((e) => e.slotId == mutexSlot);
    }

    // 添加新道具
    items.add(EquippedItem(
      slotId: slotId,
      itemId: itemId,
      category: _inferCategory(slotId),
      variant: variant,
    ));

    return config.copyWith(equippedItems: items);
  }

  /// 互斥规则
  Set<String> _getMutuallyExclusiveSlots(String slotId) {
    return switch (slotId) {
      'top' => {'dress'},      // 穿上装时卸下连衣裙
      'bottom' => {'dress'},   // 穿下装时卸下连衣裙
      'dress' => {'top', 'bottom'}, // 穿连衣裙时卸下上下装
      _ => {},
    };
  }
}
```

```dart
class AvatarErrorHandler {
  /// 处理形象配置加载失败
  Widget handleConfigLoadError(Object error, StackTrace stack) {
    if (error is DioException) {
      switch (error.type) {
        case DioExceptionType.connectionTimeout:
        case DioExceptionType.connectionError:
          // 网络错误：使用本地缓存
          final cached = AvatarLocalCache().getConfig();
          if (cached != null) {
            return AvatarContent(config: cached, isOffline: true);
          }
          return const OfflinePlaceholder();

        case DioExceptionType.badResponse:
          final code = error.response?.statusCode;
          if (code == 401) {
            return const LoginExpiredPlaceholder();
          }
          return ErrorPlaceholder(
            message: '加载失败',
            onRetry: () => AvatarRepository().refreshConfig(),
          );

        default:
          return ErrorPlaceholder(
            message: '网络异常',
            onRetry: () => AvatarRepository().refreshConfig(),
          );
      }
    }
    return const ErrorPlaceholder(message: '未知错误');
  }
}
```

```dart
/// 轻量级形象头像组件（用于排行榜、社交等场景）
class AvatarThumbnail extends StatelessWidget {
  final String userId;
  final double size;
  final bool showFrame;
  final AvatarPose? pose;

  @override
  Widget build(BuildContext context) {
    return FutureBuilder<AvatarConfig>(
      future: _loadConfig(userId),
      builder: (context, snapshot) {
        if (!snapshot.hasData) {
          return _DefaultAvatar(size: size);
        }

        return SizedBox(
          width: size,
          height: size,
          child: CustomPaint(
            painter: AvatarCompositePainter(
              config: snapshot.data!,
              resourceManager: AvatarResourceManager(),
              // 小尺寸不显示动画
              idleValue: 0,
              blinkValue: 0,
              reactionValue: 0,
              rotationY: 0,
              scale: 1.0,
              showFrame: showFrame,
            ),
          ),
        );
      },
    );
  }

  Future<AvatarConfig> _loadConfig(String userId) async {
    // 先查缓存
    final cached = AvatarCacheManager().getUserAvatar(userId);
    if (cached != null) return cached;

    // 懒加载（带超时保护）
    return AvatarCacheManager().loadUserAvatar(userId).timeout(
      const Duration(seconds: 5),
      onTimeout: () => AvatarConfig.default(),
    );
  }
}
```

## 14. 安全与合规

### 14.1 未成年人保护

- 装扮道具不得包含不适宜未成年人的元素（暴露、暴力、不良暗示等）
- 商城不展示真实货币购买的装扮（仅积分兑换/学习奖励/会员权益）
- 不设抽奖/转盘类随机获取机制，避免赌博倾向
- 所有装扮道具需经过内容审核后才能上线

### 14.2 数据隐私

| 数据项 | 处理方式 |
| --- | --- |
| 用户形象配置 | 存储于服务端，本地缓存脱敏 |
| 衣橱拥有记录 | 归属于用户学习数据，支持导出 |
| 形象快照 | CDN 存储，设置过期时间（默认90天） |
| 第三方分享 | 仅分享生成的图片，不包含用户隐私信息 |
