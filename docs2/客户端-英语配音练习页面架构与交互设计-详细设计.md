# 客户端-英语配音练习页面架构与交互设计 详细设计

- 版本: v1.0
- 日期: 2026-11-23
- 状态: 新增初版
- 符号码: DUB-001~014 + DUB-500(与服务端 44600-44630 在用码 1:1 映射,零新增数字段位)
- 服务端契约: 《服务端-英语配音练习引擎》v1.0(2026-11-22)§4 REST 契约 1:1 引用,零发明

## 1. 模块概述

### 1.1 功能定位

本文档是英语配音练习域(Dubbing Practice,内部代号 DBE-UI)的**客户端呈现层权威**,兑现服务端《服务端-英语配音练习引擎》v1.0 契约 R10 声明的"配音练习页面架构(选片段/四步跟做/波形回放/作品卡)列为后续批次客户端文档"缺口。

经全目录关键词扫描确认(2026-11-23,`配音/dubbing`):服务端引擎文档与 README 批次(三十七)记录命中,客户端页面层零覆盖——《客户端-英语专项学习页面架构与交互设计》覆盖词汇/听力/阅读/语法子页,不含配音编排链路;《客户端-晨读打卡页面架构与交互设计》覆盖朗读录音但无剧本跟做/逐句评分/混音作品语义。本文补齐该缺口(模式同批次(三十)听写默写/(三十四)思维训练/(四十)棋类/(四十四)手工美育:服务端已就绪→客户端页面层补全)。

配音页面的核心交互是**剧本约束下的语音复现**:学生选片段→逐句经历"看-听-跟-录"四步跟做(FOLLOW)或盲听直录(CHALLENGE)→提交服务端逐句四维评分→选句合成作品→作品卡家庭内分享。客户端只做呈现与采集:零判分、零评分权重知悉、零本地裁判、音频零留存。

### 1.3 明确不做(本期)

1. 不做自由剧本创作入口(红线 C7,服务端明确不做,客户端无入口);
2. 不做作品公开广场/点赞/评论/关注(visibility 恒 FAMILY,客户端无对应 UI 组件);
3. 不做全服排行榜/班级排名/同龄对比组件(合规 C4/C6,CI 组件白名单扫描);
4. 不做原片视频播放——任何页面不得渲染原片视频或原片画面帧(红线 C2,含分享卡与作品封面选帧);
5. 不做录音本地留存/录音回放历史库/录音导出(音频零留存,与晨读 CLEANUP 同约定);
6. 不做真人在线合配(PvP)入口;
7. 不做幼儿段(3-6 岁)配音入口,路由守卫 fail-closed(服务端 G3 双保险);
8. 不做离线配音模式(评分依赖实时 ASR/GOP,弱网仅诚实提示,无离线伪响应)。

## 3. 页面架构

### 3.1 `/dubbing` 配音首页

**布局**:搜索栏(按标题,客户端本地过滤已拉取页)+ CEFR 筛选 Chips(全部/A1/A2/B1/B2,单选)+ 片段卡列表(两列瀑布,封面 3:2)+ 底部"我的配音档案"入口行。

**片段卡要素**:封面(PrimeImageLoader 委托,禁原片帧,服务端已确保 cover_url 合规)、标题、CEFR 徽标、时长(分:秒)、行数(如"8 句台词")、tags 前 2 个、`bestScore` 角标(历史最高,无历史不渲染)、AIGC 徽标(`aigcLabeled=true` 时常驻不可关闭,合规 C5)。

**交互规约**:
- 服务端已按年龄段过滤(契约 4.1.1),客户端禁自行放宽(G3 双保险);
- 列表下拉刷新;骨架屏三态遵循《客户端-页面状态模式与骨架屏加载空态错误态设计规范》;
- 44608(日限触顶)不打断列表浏览,仅在校验类操作时吐司提示(日限 10 会话为创建级约束);
- 空态:插画+"还没有适合你的配音片段",无引导创建文案(素材归内容管线)。

### 3.2 `/dubbing/clip/:clipId` 片段详情与模式选择

**首屏**:封面横幅(AIGC 徽标叠加)+ 标题/CEFR/时长/行数 + 情景描述 sceneDesc + 版权提示条 copyrightNotice(常驻,禁关闭)+ 行字幕预览(前 3 行,只读)。

**模式选择卡**:
- FOLLOW 跟读模式(默认推荐):"看-听-跟-录 四步引导,适合第一次配这个片段";
- CHALLENGE 盲配模式:"先听后录挑战自己,评分后 reveal 台词"(带锁图标,标注"进阶")。

**开始按钮**:创建会话 POST /sessions(带 Idempotency-Key,UUID v7 幂等键);按钮点击即置 LOADING,防双击幂等由服务端回放保证(G4 守卫)。

**守卫渲染**:
- 44604(素材不可用/已下架):中性话术页"这个片段暂时休息了",禁回显片段任何字段(与手工美育 CRA-002 同约定),1.5s 后自动回首页;
- 44603/44601(适龄闸):适龄提示页,禁回显片段字段;
- 44610(防沉迷):休息引导页,无重试按钮;
- 会话恢复:若服务端报告存在进行中的本会话(经报告接口探测),首屏渲染"继续上次配音"卡,优先于模式选择。

### 3.3 `/dubbing/session/:sessionId` 四步跟做器(核心页)

跟做器为单页全屏结构,顶部为片段标题+进度("第 3/8 句"),主体为行工作台,底部为步骤操作条。FOLLOW 与 CHALLENGE 共用骨架,步骤流不同。

#### 3.3.1 FOLLOW 四步流(每句)

```text
① 看 LOOK    渲染字幕(textEn+textZh)+ 自动播放参考音频,孩子先理解语境
② 听 LISTEN  参考音频可反复重播(播放/停止),波形静态展示
③ 跟 FOLLOW  字幕常驻 + 录音按钮 → 录完即提交评分(带文本跟读)
④ 录 REHEARSE 无字幕预演(字幕区模糊遮罩) → 录音提交评分
步骤①②为准备步,步骤③④各产生一次 attempt;④可跳过(不强制)
```

**CHALLENGE 盲配流**:盲听原句(只播音频,字幕区渲染"?"遮罩)→ 直接录制 → 提交评分 → 评分回显后文本才渲染(reveal)。盲配每句只有一次录制入口,无跟读步骤。

**行内评分卡**(提交后渲染,语义对齐服务端 4.1.5 响应):
- 总分环(overall,服务端权威值)+ 四维条形(发音/完整度/流利度/节奏);
- degraded 维度渲染为灰色"评估中"条,**禁渲染 0 分**(G10 降级诚实透出,与服务端 §7.3 G10 一致);
- `isNewBest=true` → 该行角标"本句最佳"微动效(每日一次彩蛋,防疲劳,同通知域彩蛋约定);
- `masteredHint=true` → 皇冠图标(仅展示,掌握度 SSOT 服务端);
- encourage 话术原样渲染(可空;空时取本地静态鼓励语料包,降级 D3);话术禁含贬义/比较,客户端不做二次加工(合规 C6);
- asrText 识别文本展示("你说的是:...")仅用于孩子核对,**禁进埋点/禁进日志**(隐私白名单 §10)。

**波形对比回放**(跟做器内"对比"Tab):
- 参考音频波形:客户端解码 refAudioUrl 绘制(波形数据客户端计算,缓存 30min,PrimeImageLoader 不适用的自绘组件);
- 我的录音波形:录制过程实时电平采样绘制,提交成功后保留内存波形用于对比;
- 双波形时间轴对齐渲染,高亮起始偏移区(仅视觉,**节奏偏移评分参数不下发不渲染数值**);
- 每次重录覆盖本句内存波形;退出会话波形即弃(零落盘)。

**底部操作条**:上一步/下一步/重录本句(≤ 服务端 attempt 语义,不限本地次数,日限 80 次尝试由服务端 44608 裁决)/跳过本句/放弃会话(二次确认)。

#### 3.3.2 录音管线与零留存

- 录音格式 m4a/单声道,预计时长 ≤30s 硬顶(到点自动停止),大小 ≤2MB 本地预检(超限本地压缩重录,服务端 44607 为兜底);
- 来电/退后台/切路由 → 录音立即停止,临时文件**进入 CLEANUP 通道删除**(与晨读 G1 同约定),回页面后本句从头开始,禁自动续录;
- 上传链路:POST upload-ticket(申请直传凭证)→ OSS 直传(300s 凭证有效期)→ POST attempts 提交评分(audioRef+clientRequestId);
- CLEANUP 断言:录音完成/放弃/异常三路均 finally 删除本地临时文件,CI 集成测试断言零残留;
- 禁相册导入/禁选择已有录音(必须现场录制,同听写 G12 相机强制约定)。

#### 3.3.3 会话内异常呈现

- 提交评分超时(15s):不可取消态等待;服务端评分超时按 D2 返回 degraded 帧,客户端渲染降级评分卡;网络层失败重试复用同一 clientRequestId(幂等回放);
- 44612(评分整体不可用):"这次评估没有成功,不占用练习次数,再试一次吧"(200 话术,不计次语义透出);
- 44620(会话过期):成绩保留页("这次配音的成绩已记入你的档案"),禁继续录制;
- 44604(片段中途下架): Banner 提示"片段暂时休息,已完成的成绩保留",禁新录音,可退出看报告;合成入口按服务端 44615 裁决渲染禁用。

### 3.4 `/dubbing/session/:sessionId/report` 会话报告与选句合成页

**报告头**:全片行网格(每格:行号+当前最佳分+尝试次数+masteredHint 皇冠),总进度"已完成 6/8 句"。

**合成区**:
- `canCompose=false` 时:渲染合成阈值文案(composeThreshold,如"≥85% 行有有效 attempt")与"去补足"按钮,禁渲染合成主按钮(服务端权威,客户端禁本地计算口径 G7);
- `canCompose=true` 时:进入选句列表,默认每行勾选最佳 attempt,可展开该行尝试列表改选;标题输入(默认"我的<片段名>配音",≤20 字);
- 合成提交:POST /sessions/{id}/compose(title+lineAttemptIds+idemKey),幂等键 UUID v7 复用防双击;提交后渲染"合成中"(estimatedSeconds 进度环),就绪双通道:推送召回 + 退避轮询(1.5x 上限 5s);
- 44613(覆盖不足/行归属非法):渲染缺行清单引导回跟做器补足;
- 44614(选中行音频已过期):过期行标红"需要重录",一键跳回该行重录,禁部分合成提示(服务端 G6 裁决);
- 44615(素材下架禁合成):中性话术,成绩与报告保留。

**放弃与恢复**:跟做器与报告页均提供放弃入口(二次确认);放弃后 10min 内回到会话渲染"恢复上次配音"Banner(服务端 4.1.10 宽限语义);超时禁恢复但报告可看。

### 3.5 `/dubbing/works` 与 `/dubbing/works/:workId` 作品页

**作品列表**:作品卡(封面[客户端用片段封面+作品标题合成,禁原片帧]/标题/总分/审核态角标/创建时间);审核五态诚实矩阵:

| 服务端状态 | 客户端角标 | 详情页呈现 |
| --- | --- | --- |
| COMPOSING | "合成中"(进度环) | 预计时长倒计时,禁取消禁重试提示 |
| AUDITING | "审核中" | "作品已保存,正在审核,通过后家长可见"(禁渲染已通过话术) |
| PUBLISHED(FAMILY) | "已通过" | 播放器+作品卡分享入口 |
| REJECTED | "未通过" | 中性话术+"重新配音"入口;驳回原因经消息中心送达家长,客户端不渲染原因明细(R3) |
| DELETED | 列表剔除 | 深链接进入渲染"作品不存在"中性页 |

**作品详情/分享页**:
- 作品音频播放器(委托 R6)+ 四维分数+逐句选中情况(scoreDetail 原样渲染,禁本地重算);
- 分享卡:POST /works/{id}/share-card 取分享数据 → 客户端渲染图片(R4 委托);**版权红线:分享卡禁含原片画面帧/原片截图/角色形象图**(C2),只允许:作品标题+孩子昵称(脱敏)+总分+四维条+App 标识+"家庭内分享"水印;
- 分享行为家长门:发起分享前经家长门校验(C8:8 岁以下禁主动分享,家长默认可见);分享面板渠道矩阵遵循《客户端-分享与邀请好友页面架构与交互设计》家庭内渠道白名单;
- 44618(审核中不可分享):分享入口置灰+"审核通过后就可以分享啦"。

### 3.6 `/dubbing/profile` 配音档案页

## 5. 核心控制器与关键代码

### 5.1 DubPlayController(四步跟做主控制器)

```dart
class DubPlayController extends Notifier<DubPlayState> {
  static const _submitTimeout = Duration(seconds: 15);

  /// 步骤推进:LOOK→LISTEN→FOLLOW→REHEARSE→NEXT_LINE
  /// 约束:步骤只控制交互形态,行进度(currentLineNo)永远以服务端报告为准(R12)
  void advanceStep() {
    final s = state;
    if (s is! DubStepActive) return;
    state = s.next(); // LOOK→LISTEN→FOLLOW;REHEARSE 可跳过
  }

  /// 提交单句:凭证→直传→提交评分,clientRequestId 幂等复用
  Future<void> submitLine({required int lineNo, required String audioPath}) async {
    final clientRequestId = _idempotency.forLine(lineNo); // 同句重试复用同一键
    state = DubSubmitting(lineNo: lineNo);
    try {
      final ticket = await _api.uploadTicket(sessionId, lineNo: lineNo);
      await _uploader.putDirect(ticket.uploadUrl, File(audioPath),
          contentType: 'audio/m4a'); // 委托文件上传服务,300s 凭证
      final score = await _api
          .submitAttempt(sessionId, lineNo,
              audioRef: ticket.audioRef,
              durationMs: await _recorder.durationOf(audioPath),
              clientRequestId: clientRequestId)
          .timeout(_submitTimeout);
      await _recorder.wipe(audioPath); // CLEANUP:评分响应到达即删本地音频(G1)
      _mirror.applyScore(lineNo, score); // best/进度以服务端 report 收敛
      state = DubScored(lineNo: lineNo, score: score);
    } on DubApiException catch (e) {
      await _recorder.wipe(audioPath); // 异常路同样删(C1)
      state = _mapError(e, lineNo);    // DUB-008/013/014 等映射
    }
  }

  /// 降级评分渲染:degraded 维度渲染"评估中",禁 0 分(G10)
  Widget scoreBar(DubLineScore s) => ScoreBarView(
        dims: {
          '发音': s.pronunciation, '完整度': s.completeness,
          '流利度': s.fluency, '节奏': s.rhythm,
        }.map((k, v) => MapEntry(k, v == null ? const DegradedSlot() : ScoreSlot(v))),
        overall: s.overall, // 服务端权威,禁重算
      );
}
```

### 5.2 DubRecorderService(录音零留存)

```dart
class DubRecorderService {
  static const maxDuration = Duration(seconds: 30); // 服务端统一硬顶
  File? _current;

  Future<String> start() async {
    final f = await _engine.start(m4aMono); // 委托录制引擎 R2
    _current = f;
    _timer = Timer(maxDuration, stop);      // 到点自动停止
    return f.path;
  }

  Future<void> stop() async { await _engine.stop(); _timer?.cancel(); }

  /// 三路 CLEANUP:完成/放弃/异常均必经,CI 断言文件不存在
  Future<void> wipe(String path) async {
    final f = File(path);
    if (await f.exists()) await f.delete();
    if (_current?.path == path) _current = null;
  }

  /// 退后台/来电:立即停录并清理,禁自动续录(防误存)
  Future<void> onInterrupt() async {
    await stop();
    final p = _current?.path;
    if (p != null) await wipe(p);
  }
}
```

## 6. 状态机与守卫

### 6.1 客户端镜像状态机

```text
LOADING --(报告拉取成功)--> READY
READY --(步骤激活)--> STEP_ACTIVE(LOOK/LISTEN/FOLLOW/REHEARSE 子态)
STEP_ACTIVE --(录音中)--> RECORDING --(停录)--> UPLOADING --(直传完成)--> SUBMITTING
SUBMITTING --(评分帧)--> SCORED | SCORE_DEGRADED_VIEW
任意非终态 --(退后台/来电)--> PAUSED_LOCAL(录音即清,禁自动续录)
任意非终态 --(报告 resync)--> SYNC_REFRESH(以服务端 status/currentLineNo 收敛)
READY/SYNC_REFRESH --(会话终态/过期)--> FINISHED_UI | EXPIRED_VIEW(成绩保留)
SUBMITTING 为不可取消态(网络失败重试复用 clientRequestId,禁另起新 attempt 请求)
```
