## 1. 模块概述

### 1.1 功能定位

题库质量监控与题目生命周期管理服务（Question Bank Quality & Lifecycle Service，简称 QBQLS）是 PrimeTop 题库生态的**质量保障与治理中枢**。它围绕题目的完整生命周期——从创建、上线、使用到下线——提供持续的质量监控、数据采集、异常预警和运营决策支持，确保题库中的题目始终保持高准确性、合理难度和良好用户体验。

### 1.2 核心问题

| 问题 | 说明 | 本文档解决 |
|------|------|-----------|
| 题目质量参差不齐 | AI生成、人工录入、OCR识别的题目都可能存在错误 | ✅ 多维质量评分引擎 |
| 难度标注不准确 | 初始难度与实际答题正确率偏差大 | ✅ 难度校准漂移检测 |
| 过时题目无法识别 | 教材改版后旧题未及时清理 | ✅ 教材版本关联与过期检测 |
| 用户反馈无闭环 | 点踩/纠错后无人跟进 | ✅ 反馈聚合与工单联动 |
| 题目使用冷热不均 | 高频题被反复推荐，大量题目从未被使用 | ✅ 使用热度追踪与曝光均衡 |
| 题目生命周期混乱 | 无清晰的状态流转和上下线审批 | ✅ 完整生命周期状态机 |

### 1.4 设计原则

1. **数据驱动**：所有质量判断基于实际使用数据，非人工主观评估
2. **渐进式治理**：不追求一次性完美，通过持续监控逐步提升
3. **自动化优先**：异常检测、预警触发尽可能自动化，减少人工巡检
4. **闭环可追溯**：从发现问题到解决问题全程可追溯
5. **不影响线上**：质量治理操作不中断线上题目推荐和答题流程

## 2. 核心概念与术语

### 2.1 题目生命周期状态

```python
class QuestionLifecycle(str, Enum):
    """题目生命周期状态"""
    DRAFT = "draft"              # 草稿：新创建/录入，未审核
    PENDING_REVIEW = "pending_review"  # 待审核：提交审核，等待质量检查
    REVIEWING = "reviewing"      # 审核中：审核员正在检查
    ACTIVE = "active"            # 上线：通过审核，可被推荐和检索
    FLAGGED = "flagged"          # 标记异常：质量监控检测到问题
    UNDER_FIX = "under_fix"      # 修复中：运营/编辑正在修正
    DEPRECATED = "deprecated"    # 已下线：教材改版/内容过时，不再推荐
    ARCHIVED = "archived"        # 已归档：彻底下线，仅保留历史记录
```

### 2.2 题目质量评分维度

| 维度 | 权重 | 数据来源 | 说明 |
|------|------|---------|------|
| 内容准确性 | 30% | 用户反馈 + 专家抽检 | 题干、选项、答案是否正确 |
| 解析完整性 | 20% | 结构化检查 + AI评估 | 解析步骤是否完整、逻辑清晰 |
| 难度匹配度 | 15% | 实际答题数据 | 标注难度与实际正确率是否匹配 |
| 知识点标注 | 15% | 覆盖率检查 | 知识点标注是否准确、完整 |
| 用户满意度 | 10% | 点赞/点踩/反馈 | 用户对题目和解析的综合评价 |
| 格式规范性 | 10% | 自动化检查 | 公式渲染、图片、排版是否正常 |

### 4.3 状态变更副作用

每次状态变更时执行的操作：

```python
class LifecycleSideEffects:
    """生命周期变更副作用处理器"""
    
    async def on_state_change(
        self,
        question_id: int,
        from_state: QuestionLifecycle | None,
        to_state: QuestionLifecycle,
        trigger_type: str,
        operator: Operator,
    ):
        # 1. 记录事件
        await self.record_event(question_id, from_state, to_state, trigger_type, operator)
        
        # 2. 更新题目主表状态
        await self.update_question_state(question_id, to_state)
        
        # 3. 清除相关缓存
        await self.invalidate_cache(question_id)
        
        # 4. 根据目标状态执行特定操作
        match to_state:
            case QuestionLifecycle.ACTIVE:
                await self._on_active(question_id)
            case QuestionLifecycle.FLAGGED:
                await self._on_flagged(question_id, trigger_type)
            case QuestionLifecycle.DEPRECATED:
                await self._on_deprecated(question_id)
            case QuestionLifecycle.ARCHIVED:
                await self._on_archived(question_id)
    
    async def _on_active(self, question_id: int):
        """题目上线：通知推荐引擎可使用"""
        await self.event_bus.publish("question.activated", {"question_id": question_id})
        # 清除旧的"下线"缓存标记
        await self.cache.delete(f"qb:deprecated:{question_id}")
    
    async def _on_flagged(self, question_id: int, trigger_type: str):
        """题目被标记异常：创建告警、通知运营"""
        await self.alert_service.create_alert(
            alert_type=f"question_flagged_{trigger_type}",
            alert_level="warning",
            question_id=question_id,
            title=f"题目 {question_id} 被标记异常",
            description=f"触发原因: {trigger_type}，请尽快处理",
        )
        # 从推荐池中临时移除
        await self.cache.set(f"qb:suspended:{question_id}", "1", ttl=86400 * 7)
    
    async def _on_deprecated(self, question_id: int):
        """题目下线：通知推荐引擎移除"""
        await self.event_bus.publish("question.deprecated", {"question_id": question_id})
        await self.cache.set(f"qb:deprecated:{question_id}", "1", ttl=86400 * 365)
        # 通知练习系统替换已下线题目
        await self.event_bus.publish("question.replace_needed", {"question_id": question_id})
    
    async def _on_archived(self, question_id: int):
        """题目归档：清理缓存"""
        await self.cache.delete(f"qb:quality:{question_id}")
        await self.cache.delete(f"qb:lifecycle:{question_id}")
```

### 5.1 评分计算模型

```python
    accuracy_reports: int          # 累计准确性相关反馈数
    accuracy_negative: int         # 准确性负面反馈数
    expert_accuracy_score: int | None  # 专家抽检评分（0-100），无则为None
    
    # 解析完整性数据
    has_explanation: bool          # 是否有解析
    explanation_steps: int         # 解析步骤数
    explanation_completeness: float  # AI评估完整度 0-1
    
    # 难度匹配数据
    difficulty_drift: Decimal      # 难度漂移分数 0-100
    calibration_sample: int        # 校准样本量
    
    # 知识点标注数据
    knowledge_points_count: int    # 标注的知识点数
    knowledge_coverage: float      # 知识点覆盖率 0-1
    auto_tag_confidence: float     # 自动标注置信度 0-1
    
    # 用户满意度数据
    total_usage: int               # 总使用次数
    likes: int                     # 点赞数
    dislikes: int                  # 点踩数
    reports: int                   # 举报数
    
    # 格式规范性数据
    format_check_passed: bool      # 格式自动检查是否通过
    formula_render_ok: bool        # 公式渲染是否正常
    image_accessible: bool         # 图片是否可访问
    
    # 样本量权重（使用次数少时降低满意度权重）
    sample_weight: float = 1.0


class QualityScoringEngine:
    """题目质量评分引擎"""
    
    DIMENSION_WEIGHTS = {
        "accuracy": 0.30,
        "explanation": 0.20,
        "difficulty_match": 0.15,
        "knowledge": 0.15,
        "satisfaction": 0.10,
        "format": 0.10,
    }
    
    def calculate(self, input_data: QualityScoreInput) -> QualityScoreResult:
        scores = {}
        
        # 1. 内容准确性评分
        scores["accuracy"] = self._score_accuracy(input_data)
        
        # 2. 解析完整性评分
        scores["explanation"] = self._score_explanation(input_data)
        
        # 3. 难度匹配度评分
        scores["difficulty_match"] = self._score_difficulty_match(input_data)
        
        # 4. 知识点标注评分
        scores["knowledge"] = self._score_knowledge(input_data)
        
        # 5. 用户满意度评分
        scores["satisfaction"] = self._score_satisfaction(input_data)
        
        # 6. 格式规范性评分
        scores["format"] = self._score_format(input_data)
        
        # 加权计算总分
        overall = sum(
            scores[dim] * self.DIMENSION_WEIGHTS[dim]
            for dim in scores
        )
        
        # 一票否决：格式严重错误直接降级
        if not input_data.format_check_passed:
            overall = min(overall, 40)
        
        # 一票否决：准确性评分极低
        if scores["accuracy"] < 30 and input_data.accuracy_reports >= 5:
            overall = min(overall, 25)
        
        overall = round(overall)
        health = self._determine_health(overall)
        
        return QualityScoreResult(
            overall_score=overall,
            health_level=health,
            dimension_scores=scores,
        )
    
    def _score_accuracy(self, data: QualityScoreInput) -> int:
        """内容准确性评分"""
        if data.expert_accuracy_score is not None:
            # 有专家评分时，混合专家评分和用户反馈
            expert_weight = 0.7
            if data.accuracy_reports > 0:
                user_accuracy = max(0, 100 - (data.accuracy_negative / data.accuracy_reports) * 100)
                return round(expert_weight * data.expert_accuracy_score + (1 - expert_weight) * user_accuracy)
            return data.expert_accuracy_score
        
        # 无专家评分时，基于用户反馈估算
        if data.accuracy_reports == 0:
            return 70  # 无反馈数据时给默认中等偏上分数
        
        ratio = data.accuracy_negative / data.accuracy_reports
        # ratio 0 → 100分，ratio 0.5 → 50分，ratio 1.0 → 0分
        return round(max(0, 100 * (1 - ratio * 2)))
    
    def _score_explanation(self, data: QualityScoreInput) -> int:
        """解析完整性评分"""
        if not data.has_explanation:
            return 20  # 无解析直接低分
        
        score = 50  # 基础分
        score += min(20, data.explanation_steps * 4)  # 步骤数加分（最多+20）
        score += round(data.explanation_completeness * 30)  # AI评估完整度加分
        
        return min(100, score)
    
    def _score_difficulty_match(self, data: QualityScoreInput) -> int:
        """难度匹配度评分"""
        if data.calibration_sample < 10:
            return 70  # 样本不足，给默认分
        
        # drift_score 越低越好（0 = 完美匹配，100 = 完全不匹配）
        return round(max(0, 100 - data.difficulty_drift))
    
    def _score_knowledge(self, data: QualityScoreInput) -> int:
        """知识点标注评分"""
        if data.knowledge_points_count == 0:
            return 20  # 未标注知识点
        
        score = 30  # 有知识点标注基础分
        score += round(data.knowledge_coverage * 40)  # 覆盖率加分
        score += round(data.auto_tag_confidence * 30)  # 置信度加分
        
        return min(100, score)
    
    def _score_satisfaction(self, data: QualityScoreInput) -> int:
        """用户满意度评分"""
        if data.total_usage < 5:
            return 70  # 使用次数太少，给默认分
        
        total_feedback = data.likes + data.dislikes
        if total_feedback == 0:
            return 75  # 有使用但无反馈，给中等偏上分数
        
        like_ratio = data.likes / total_feedback
        # 举报扣分
        report_penalty = min(30, data.reports * 5)
        
        score = round(like_ratio * 100) - report_penalty
        return max(0, min(100, score))
    
    def _score_format(self, data: QualityScoreInput) -> int:
        """格式规范性评分"""
        score = 100
        if not data.format_check_passed:
            score -= 40
        if not data.formula_render_ok:
            score -= 30
        if not data.image_accessible:
            score -= 30
        return max(0, score)
    
    @staticmethod
    def _determine_health(overall_score: int) -> QuestionHealth:
        if overall_score >= 90:
            return QuestionHealth.EXCELLENT
        elif overall_score >= 70:
            return QuestionHealth.GOOD
        elif overall_score >= 50:
            return QuestionHealth.FAIR
        elif overall_score >= 30:
            return QuestionHealth.POOR
        else:
            return QuestionHealth.CRITICAL
```

## 6. 难度校准引擎

### 6.1 难度漂移检测

当题目实际正确率与标注难度对应的预期正确率偏差超过阈值时，触发难度校准。

```python
class DifficultyCalibrationEngine:
    """难度校准引擎"""
    
    # 标注难度等级对应的预期正确率区间
    EXPECTED_ACCURACY = {
        "easy":       (0.70, 0.90),   # 预期正确率 70%-90%
        "medium":     (0.40, 0.70),   # 预期正确率 40%-70%
        "hard":       (0.20, 0.40),   # 预期正确率 20%-40%
        "expert":     (0.05, 0.20),   # 预期正确率 5%-20%
    }
    
    # 校准触发条件
    MIN_SAMPLE_SIZE = 30        # 最少答题人数
    DRIFT_THRESHOLD = 25        # 漂移分数阈值（超过则触发校准）
    CALIBRATION_WINDOW_DAYS = 30  # 使用最近30天数据
    
    async def detect_and_calibrate(self, question_id: int) -> CalibrationResult | None:
        """检测并校准单个题目"""
        
        # 1. 获取题目原始难度
        question = await self.question_repo.get_by_id(question_id)
        if not question or question.lifecycle_state != QuestionLifecycle.ACTIVE:
            return None
        
        # 2. 获取近期答题统计数据
        stats = await self.usage_repo.get_recent_stats(
            question_id, 
            days=self.CALIBRATION_WINDOW_DAYS
        )
        
        if stats.total_attempts < self.MIN_SAMPLE_SIZE:
            return None  # 样本不足，跳过
        
        # 3. 计算观察正确率
        observed_accuracy = stats.correct_count / stats.total_attempts
        
        # 4. 获取预期正确率范围
        difficulty = question.difficulty_level
        expected_low, expected_high = self.EXPECTED_ACCURACY.get(
            difficulty, (0.30, 0.70)
        )
        expected_mid = (expected_low + expected_high) / 2
        
        # 5. 计算漂移分数
        drift = self._calculate_drift(observed_accuracy, expected_low, expected_high)
        
        if drift < self.DRIFT_THRESHOLD:
            return None  # 漂移在可接受范围内
        
        # 6. 确定校准后难度
        calibrated = self._infer_difficulty(observed_accuracy)
        
        # 7. 记录校准结果
        result = CalibrationResult(
            question_id=question_id,
            original_difficulty=difficulty,
            original_value=question.difficulty_value,
            calibrated_difficulty=calibrated.level,
            calibrated_value=calibrated.value,
            sample_size=stats.total_attempts,
            observed_accuracy=observed_accuracy,
            expected_accuracy=expected_mid,
            drift_score=drift,
            calibration_method="empirical",
        )
        
        await self.calibration_repo.save(result)
        
        # 8. 如果漂移严重，触发告警
        if drift >= 50:
            await self.alert_service.create_alert(
                alert_type="difficulty_drift_severe",
                alert_level="warning",
                question_id=question_id,
                title=f"题目 {question_id} 难度漂移严重",
                description=(
                    f"标注难度: {difficulty}，实际正确率: {observed_accuracy:.1%}，"
                    f"建议校准为: {calibrated.level}，漂移分数: {drift}"
                ),
                metrics={"drift_score": drift, "observed_accuracy": str(observed_accuracy)},
            )
        
        # 9. 自动应用校准（可配置）
        if self.config.auto_apply_calibration and drift >= self.DRIFT_THRESHOLD:
            await self.question_repo.update_difficulty(
                question_id, 
                calibrated.level, 
                calibrated.value
            )
            result.auto_applied = True
        
        return result
    
    def _calculate_drift(
        self, observed: float, expected_low: float, expected_high: float
    ) -> Decimal:
        """计算漂移分数（0-100，越高越不匹配）"""
        if expected_low <= observed <= expected_high:
            return Decimal("0")  # 在预期范围内
        
        if observed < expected_low:
            deviation = expected_low - observed
        else:
            deviation = observed - expected_high
        
        # 将偏差映射为 0-100 的漂移分数
        drift = min(100, round(deviation * 200))  # deviation 0.5 → 满分100
        return Decimal(str(drift))
    
    def _infer_difficulty(self, accuracy: float) -> DifficultyInference:
        """根据实际正确率推断难度"""
        for level, (low, high) in self.EXPECTED_ACCURACY.items():
            if low <= accuracy <= high:
                mid = (low + high) / 2
                return DifficultyInference(
                    level=level,
                    value=round(1 - mid, 2),  # 正确率越高，难度值越低
                )
        
        # 兜底：根据正确率线性映射
        if accuracy > 0.90:
            return DifficultyInference(level="easy", value=0.15)
        elif accuracy < 0.05:
            return DifficultyInference(level="expert", value=0.95)
        else:
            value = round(1 - accuracy, 2)
            level = "medium"  # 默认中等
            return DifficultyInference(level=level, value=value)
```

```python
class ExposureHeatTracker:
    """题目曝光热度追踪器"""
    
    async def record_exposure(self, question_id: int, context: ExposureContext):
        """记录题目曝光事件"""
        date_key = datetime.now().strftime("%Y-%m-%d")
        redis_key = f"qb:daily:{question_id}:{date_key}"
        
        pipe = self.redis.pipeline()
        pipe.hincrby(redis_key, "exposure", 1)
        if context.was_attempted:
            pipe.hincrby(redis_key, "attempt", 1)
            if context.was_correct:
                pipe.hincrby(redis_key, "correct", 1)
        pipe.expire(redis_key, 86400 * 7)  # 7天TTL
        await pipe.execute()
    
    async def get_cold_questions(
        self, 
        subject: str | None = None,
        knowledge_point_id: int | None = None,
        limit: int = 100
    ) -> list[int]:
        """获取冷门题目（从未或极少被使用）"""
        # 从MySQL查询活跃但使用量极低的题目
        query = """
            SELECT q.id
            FROM questions q
            LEFT JOIN question_usage_stats us ON q.id = us.question_id
                AND us.stat_date >= DATE_SUB(CURDATE(), INTERVAL 90 DAY)
            WHERE q.lifecycle_state = 'active'
              AND (:subject IS NULL OR q.subject = :subject)
              AND (:kp_id IS NULL OR EXISTS (
                  SELECT 1 FROM question_knowledge_points qkp
                  WHERE qkp.question_id = q.id AND qkp.knowledge_point_id = :kp_id
              ))
            GROUP BY q.id
            HAVING COALESCE(SUM(us.exposure_count), 0) < 10
            ORDER BY COALESCE(SUM(us.exposure_count), 0) ASC
            LIMIT :limit
        """
        return await self.db.execute(text(query), {
            "subject": subject,
            "kp_id": knowledge_point_id,
            "limit": limit,
        }).scalars().all()
    
    async def get_exposure_balance_recommendation(
        self,
        subject: str,
        knowledge_point_id: int,
        count: int = 5
    ) -> list[int]:
        """获取曝光均衡推荐：混合热门题和冷门题"""
        # 50% 热门优质题 + 30% 中等题 + 20% 冷门题
        hot_count = max(1, round(count * 0.5))
        mid_count = max(1, round(count * 0.3))
        cold_count = count - hot_count - mid_count
        
        hot = await self._get_hot_quality_questions(
            subject, knowledge_point_id, hot_count
        )
        mid = await self._get_mid_questions(
            subject, knowledge_point_id, mid_count, exclude=set(hot)
        )
        cold = await self.get_cold_questions(
            subject=subject,
            knowledge_point_id=knowledge_point_id,
            limit=cold_count
        )
        # 过滤掉已选的
        cold = [q for q in cold if q not in set(hot) | set(mid)][:cold_count]
        
        return hot + mid + cold
```

```python
class QualityAwareRecommendationFilter:

            active_ids = await self._filter_active(candidate_ids)

            active_ids = candidate_ids

            QuestionHealth.GOOD: 70,
            QuestionHealth.FAIR: 50,
            QuestionHealth.POOR: 30,
            QuestionHealth.CRITICAL: 0,
        }

            if quality_map.get(qid, {}).get("overall_score", 0) >= min_score
        ]

        # 先查Redis缓存
        results = []
        uncached = []
        for qid in question_ids:
            state = await self.cache.get(f"qb:lifecycle:{qid}")
            if state == "active":
                results.append(qid)
            elif state is None:
                uncached.append(qid)
        
        if uncached:
            # 查数据库
            rows = await self.db.execute(
                text("SELECT id FROM questions WHERE id IN :ids AND lifecycle_state = 'active'"),
                {"ids": tuple(uncached)}
            ).scalars().all()
            for qid in rows:
                await self.cache.set(f"qb:lifecycle:{qid}", "active", ttl=86400)
                results.append(qid)
        
        return results
```

```python
class QualityAlertService:

    async def check_and_alert(self, question_id: int):

        for rule in AlertRuleDefinitions.RULES:
            try:
                if rule.condition(metrics):
                    # 去重：同类型告警24小时内不重复
                    if await self._is_duplicate_alert(question_id, rule.id):
                        continue
                    
                    await self._create_alert(question_id, rule, metrics)
            except Exception as e:
                logger.error(f"Alert rule check failed: {rule.id}", exc_info=e)
    
    async def _collect_metrics(self, question_id: int) -> dict:
        """收集告警检测所需的指标"""
        pipe = self.redis.pipeline()
        
        # 最近统计
        today = datetime.now().strftime("%Y-%m-%d")
        yesterday = (datetime.now() - timedelta(days=1)).strftime("%Y-%m-%d")
        
        for d in [today, yesterday]:
            pipe.hgetall(f"qb:daily:{question_id}:{d}")
        
        daily_results = await pipe.execute()
        today_data = daily_results[0] or {}
        yesterday_data = daily_results[1] or {}
        
        # 质量评分
        quality = await self.redis.hgetall(f"qb:quality:{question_id}")
        
        # 时间窗口统计（从Redis ZSet或ClickHouse查询）
        reports_1h = await self._count_recent_reports(question_id, hours=1)
        reports_24h = await self._count_recent_reports(question_id, hours=24)
        dislikes_1h = int(today_data.get("dislike", 0))
        
        return {
            "reports_1h": reports_1h,
            "reports_24h": reports_24h,
            "report_rate_24h": reports_24h / max(1, int(today_data.get("attempt", 0)) + int(yesterday_data.get("attempt", 0))),
            "dislikes_1h": dislikes_1h,
            "satisfaction_7d": await self._calc_satisfaction(question_id, days=7),
            "usage_7d": await self._calc_usage(question_id, days=7),
            "usage_30d": await self._calc_usage(question_id, days=30),
            "difficulty_drift": float(quality.get("difficulty_drift", 0)),
            "format_ok": quality.get("format_ok", "1") == "1",
            "avg_time_ms": int(today_data.get("avg_time_ms", 30000)),
            "sample_size": int(today_data.get("attempt", 0)),
            "overall_score": int(quality.get("overall_score", 70)),
            "accuracy_delta": await self._calc_accuracy_delta(question_id),
        }
```

```python
@app.task(name="qbqls.daily_usage_aggregation", time_limit=1800)
def daily_usage_aggregation():
    """将Redis日计数器聚合写入MySQL"""
    
    target_date = (datetime.now() - timedelta(days=1)).strftime("%Y-%m-%d")
    pattern = f"qb:daily:*:{target_date}"
    
    # 扫描所有题目的日计数器
    cursor = 0
    batch = []
    
    while True:
        cursor, keys = redis.scan(cursor, match=pattern, count=500)
        
        for key in keys:
            data = redis.hgetall(key)
            if not data:
                continue
            
            # 从key中提取question_id
            parts = key.split(":")
            question_id = int(parts[2])
            
            batch.append({
                "question_id": question_id,
                "stat_date": target_date,
                "exposure_count": int(data.get("exposure", 0)),
                "attempt_count": int(data.get("attempt", 0)),
                "correct_count": int(data.get("correct", 0)),
                "like_count": int(data.get("like", 0)),
                "dislike_count": int(data.get("dislike", 0)),
                "report_count": int(data.get("report", 0)),
                "avg_answer_time_ms": int(data.get("avg_time_ms", 0)) or None,
            })
            
            # 每500条批量写入
            if len(batch) >= 500:
                _upsert_stats_batch(batch)
                batch = []
        
        if cursor == 0:
            break
    
    # 写入剩余数据
    if batch:
        _upsert_stats_batch(batch)
    
    logger.info(f"Daily usage aggregation completed for {target_date}")


def _upsert_stats_batch(batch: list[dict]):
    """批量写入/更新统计数据"""
    stmt = insert(question_usage_stats).values(batch)
```

## 12. 错误处理

### 12.1 错误码定义

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|-----------|------|---------|
| QBQLS_001 | 400 | 无效的生命周期状态转换 | 检查当前状态和目标状态是否允许 |
| QBQLS_002 | 403 | 角色权限不足 | 联系管理员提升权限 |
| QBQLS_003 | 404 | 题目不存在 | 检查题目ID |
| QBQLS_004 | 409 | 并发状态冲突 | 重试操作 |
| QBQLS_005 | 422 | 评分数据不足（样本量过小） | 等待更多使用数据 |
| QBQLS_006 | 500 | 评分引擎内部错误 | 检查日志，联系技术支持 |
| QBQLS_007 | 500 | 告警检测异常 | 检查告警规则配置 |
| QBQLS_008 | 202 | 批量任务已提交（异步处理中） | 轮询任务状态 |

### 12.2 降级策略

| 场景 | 降级策略 | 影响范围 |
|------|---------|---------|
| 质量评分服务不可用 | 使用上次缓存的质量快照 | 新题目暂时无评分 |
| Redis不可用 | 直接查MySQL统计表，跳过实时计数 | 延迟增加，不影响核心功能 |
| 告警服务不可用 | 降级为日志记录，不影响题目正常使用 | 告警延迟 |
| 难度校准任务失败 | 保留旧难度标注，下次定时任务重试 | 难度精度暂时降低 |
| 批量聚合任务延迟 | 使用Redis实时数据服务查询请求 | 查询性能下降 |
