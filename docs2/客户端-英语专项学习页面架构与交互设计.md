## 1. 模块概述

### 1.1 模块定位

英语专项学习模块是 PrimeTop 面向小学至高中学段用户的独立学习入口，提供单词学习、听力训练、阅读理解、语法练习、口语陪练、作文辅导等英语专项功能。本模块以客户端页面架构与交互设计为核心，定义页面结构、组件复用、状态管理和用户交互流程。

### 1.2 目标用户

| 学段 | 核心需求 | 交互特征 |
|------|----------|----------|
| 小学（3-6年级） | 词汇积累、基础语法、自然拼读、听说启蒙 | 图文并茂、游戏化、短时高频 |
| 初中 | 词汇扩展、语法体系、阅读训练、听力训练、口语表达 | 任务驱动、即时反馈、错题关联 |
| 高中 | 高考词汇、长篇阅读、完形填空、书面表达、听力综合 | 高密度信息、真题导向、计时训练 |

### 1.3 设计原则

1. **分层渐进**：页面按「词汇 → 听力 → 阅读 → 语法 → 口语 → 写作」递进组织
2. **短时高效**：每个练习单元控制在 5-15 分钟，支持碎片化学习
3. **即时反馈**：答题后立即反馈正误、解析和发音
4. **多维联动**：与错题本、学情分析、学习计划模块深度联动
5. **离线优先**：核心练习资源支持离线使用

### 3.2 词汇中心 - 单词学习卡页

#### 3.2.1 页面功能

以卡片滑动方式学习单词，支持发音播放、释义展示、例句、助记法和标记掌握程度。

#### 3.2.2 数据结构

```dart
/// 单词学习卡
class VocabularyCard {
  final String wordId;
  final String word;               // 单词
  final String phonetic;           // 音标
  final String audioUrl;           // 发音音频URL
  final String audioUrlUs;         // 美式发音
  final String audioUrlUk;         // 英式发音
  final List<WordMeaning> meanings; // 释义列表
  final List<String> examples;     // 例句
  final String? mnemonicTip;       // 助记方法
  final String? rootAnalysis;      // 词根词缀分析
  final WordDifficulty difficulty;  // 难度等级
  final List<String> synonyms;     // 同义词
  final List<String> antonyms;     // 反义词
  final String? imageUrl;          // 配图URL（小学阶段）
  final bool isLearned;            // 是否已学
  final MasteryLevel mastery;      // 掌握程度
}

class WordMeaning {
  final String partOfSpeech;  // 词性: n., v., adj., adv., prep., conj.
  final String definitionCn; // 中文释义
  final String definitionEn; // 英文释义（高中阶段）
  final List<String> collocations; // 搭配
}

enum MasteryLevel {
  unknown,    // 未学习
  recognized, // 认识（能识别）
  familiar,   // 熟悉（知道意思）
  mastered,   // 掌握（会运用）
}

enum WordDifficulty {
  basic,    // 基础词汇
  core,     // 核心词汇
  advanced, // 进阶词汇
  extra,    // 拓展词汇
}

/// 单词学习会话
class VocabularySession {
  final String sessionId;
  final VocabularySessionType type; // 学习类型
  final List<String> wordIds;       // 本轮单词ID列表
  final int currentIndex;           // 当前卡片索引
  final Map<String, WordCardResult> results; // 作答结果
  final DateTime startedAt;
  final int totalEstimatedMinutes;  // 预估时长
}

enum VocabularySessionType {
  newWords,    // 新词学习
  review,      // 复习（间隔重复）
  spelling,    // 拼写练习
  quiz,        // 小测验
  examPrep,    // 考试冲刺
}

class WordCardResult {
  final String wordId;
  final bool isCorrect;
  final int responseTimeMs;   // 响应时间
  final MasteryLevel selfAssessment; // 自我评估
  final DateTime answeredAt;
}
```

// lib/features/english/core/english_error_handler.dart

class EnglishErrorHandler {
  static const _maxRetryCount = 3;
  static const _retryDelay = Duration(seconds: 2);

  /// 处理英语模块错误
  static Widget handleError(
    BuildContext context,
    EnglishError error, {
    VoidCallback? onRetry,
  }) {
    switch (error.code) {
      case 'EN_AUDIO_001':
        return _buildAudioError(context, error, onRetry);
      case 'EN_ASR_001':
        return _buildAsrFallback(context);
      case 'EN_VOCAB_001':
        // 静默处理，使用缓存
        return const SizedBox.shrink();
      default:
        return _buildGenericError(context, error, onRetry);
    }
  }

  /// 带重试的网络请求
  static Future<T> withRetry<T>(
    Future<T> Function() request, {
    int maxRetries = _maxRetryCount,
    Duration delay = _retryDelay,
  }) async {
    int attempt = 0;
    while (true) {
      try {
        return await request();
      } catch (e) {
        attempt++;
        if (attempt >= maxRetries) rethrow;
        await Future.delayed(delay * attempt); // 指数退避
      }
    }
  }

  /// 离线优先数据获取
  static Future<T> offlineFirst<T>({
    required Future<T> Function() networkFetch,
    required Future<T> Function() localFetch,
    required Future<void> Function(T) cacheUpdate,
  }) async {
    try {
      final data = await networkFetch();
      await cacheUpdate(data);
      return data;
    } catch (e) {
      // 网络失败，尝试本地缓存
      try {
        return await localFetch();
      } catch (e2) {
        throw EnglishError(
          code: 'EN_OFFLINE_001',
          message: '网络不可用且无本地缓存',
        );
      }
    }
  }
}

    extends Bloc<ListeningPlayerEvent, ListeningPlayerState> {

    on<StartPlayback>(_onStartPlayback);

    on<SeekPlayback>(_onSeekPlayback);
    on<ChangeSpeed>(_onChangeSpeed);
    on<ToggleIntensiveMode>(_onToggleIntensiveMode);
    on<AudioPositionChanged>(_onAudioPositionChanged);
    on<AudioSegmentEnded>(_onAudioSegmentEnded);
  }

  Future<void> _onToggleIntensiveMode(
    ToggleIntensiveMode event,
    Emitter<ListeningPlayerState> emit,
  ) async {
    final current = state as ListeningPlayerActive;
    final newMode = !current.isIntensiveMode;

    if (newMode) {
      // 进入精听模式：跳到当前句子开始位置
      final segment = current.segments[current.currentSegmentIndex];
      await _audioPlayer.seek(Duration(milliseconds: segment.startMs));
    }

    emit(current.copyWith(isIntensiveMode: newMode));
  }

  Future<void> _onAudioSegmentEnded(
    AudioSegmentEnded event,
    Emitter<ListeningPlayerState> emit,
  ) async {
    final current = state as ListeningPlayerActive;
    if (!current.isIntensiveMode) return;

    // 精听模式：当前句子播完后暂停
    await _audioPlayer.pause();
    emit(current.copyWith(isPlaying: false));

    // 自动显示当前句子文本
    emit(current.copyWith(showSegmentText: true));
  }
}
