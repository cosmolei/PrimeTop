# 亲子共学模式与双角色交互设计 - 详细设计

## 1. 概述

### 1.1 功能定位

亲子共学模式（Parent-Child Co-learning Mode）是面向幼儿及小学低年级（3-8岁）阶段的特色学习模式。在该模式下，家长与孩子在同一设备上共同参与学习活动，系统根据当前操作角色动态切换 UI 表现、内容深度和交互方式，实现"家长引导 + 孩子实践"的协同学习体验。

### 1.2 设计目标

1. **双角色感知**：系统能准确识别当前操作者是家长还是孩子，并动态适配界面
2. **安全可控**：家长可随时接管控制权，退出学习需家长确认
3. **低操作门槛**：幼儿端交互以语音、触摸、拖拽为主，最小化文字依赖
4. **学习有效性**：通过家长参与提升学习专注度，系统自动记录双方贡献
5. **情感连接**：设计鼓励家长表扬、互动反馈的机制，强化亲子关系

### 1.3 适用学段

| 学段 | 年龄 | 使用频率 | 典型场景 |
|------|------|----------|----------|
| 幼儿小班 | 3-4岁 | 高频 | 拼音启蒙、识字入门、数字认知 |
| 幼儿中班 | 4-5岁 | 高频 | 识字进阶、简单计算、英语启蒙 |
| 幼儿大班 | 5-6岁 | 中频 | 拼音拼读、基础运算、阅读准备 |
| 小学一年级 | 6-7岁 | 低频 | 拼音巩固、生字学习、口算练习 |
| 小学二年级 | 7-8岁 | 偶尔 | 难点辅导、背诵监督 |

> 小学三年级及以上建议使用独立学习模式，不再启用亲子共学。

### 1.4 与现有模块的关系

```
亲子共学模式
├── 依赖 → 用户账号体系（家长绑定关系）
├── 依赖 → 家长中心（使用管理、内容范围配置）
├── 依赖 → 拼音识字启蒙（核心学习内容）
├── 依赖 → 语音服务 ASR/TTS（语音交互）
├── 依赖 → 护眼模式（时长提醒）
├── 依赖 → 防沉迷系统（使用时长控制）
├── 依赖 → 学习记录与进度追踪（数据写入）
└── 输出 → 学情分析（亲子互动数据指标）
```

## 2. 核心概念与数据模型

### 2.1 核心概念

| 概念 | 说明 |
|------|------|
| 共学会话 (CoLearnSession) | 一次完整的亲子共学活动，从开始到结束 |
| 角色切换 (RoleSwitch) | 当前操作者在家长/孩子之间的切换事件 |
| 共学任务 (CoLearnTask) | 一个具体的学习单元，如"认读5个生字" |
| 家长引导动作 (ParentAction) | 家长在共学中的操作，如提示、鼓励、纠正 |
| 孩子作答 (ChildResponse) | 孩子的学习反馈，包括语音、触摸选择等 |
| 共学评价 (CoLearnEvaluation) | 任务完成后的综合评价 |

### 2.2 数据结构定义

#### 2.2.1 共学会话（CoLearnSession）

```typescript
// 客户端本地数据模型
interface CoLearnSession {
  id: string;                    // 会话唯一ID，UUID v4
  parentUserId: string;          // 家长用户ID
  childUserId: string;           // 孩子用户ID
  startTime: number;             // 开始时间戳 (ms)
  endTime: number | null;        // 结束时间戳，进行中为 null
  status: CoLearnSessionStatus;  // 会话状态
  subject: Subject;              // 学科
  topic: string;                 // 学习主题，如"拼音-声母"
  currentRole: Role;             // 当前操作角色
  settings: CoLearnSettings;     // 本次共学配置
  stats: CoLearnStats;           // 实时统计
  tasks: CoLearnTask[];          // 任务列表
  parentActions: ParentAction[]; // 家长操作记录
  deviceInfo: DeviceInfo;        // 设备信息
}

enum CoLearnSessionStatus {
  ACTIVE = 'active',           // 进行中
  PAUSED = 'paused',           // 已暂停（家长临时离开）
  COMPLETED = 'completed',     // 正常完成
  FORCE_ENDED = 'force_ended', // 家长强制结束
  TIMEOUT = 'timeout',         // 超时自动结束
}

enum Role {
  PARENT = 'parent',
  CHILD = 'child',
}

enum Subject {
  PINYIN = 'pinyin',           // 拼音
  LITERACY = 'literacy',       // 识字
  MATH = 'math',               // 数学
  ENGLISH = 'english',         // 英语
  GENERAL = 'general',         // 综合
}
```

#### 2.2.2 共学配置（CoLearnSettings）

```typescript
interface CoLearnSettings {
  // 时长限制
  maxDurationMin: number;       // 最大共学时长（分钟），默认 20

#### 2.2.4 孩子作答（ChildResponse）

```typescript
interface ChildResponse {
  taskId: string;
  type: ResponseType;
  data: ResponseData;
  isCorrect: boolean | null;     // null 表示需家长判定
  timestamp: number;
  confidence: number;            // AI 判断置信度 0-1
}

enum ResponseType {
  VOICE = 'voice',               // 语音作答
  TAP = 'tap',                   // 点击选择
  DRAG = 'drag',                 // 拖拽操作
  TRACE_PATH = 'trace_path',     // 描写路径
  NONE = 'none',                 // 无响应/超时
}

interface ResponseData {
  // VOICE 类型
  audioUri?: string;             // 录音文件 URI
  recognizedText?: string;       // ASR 识别文本
  pronunciationScore?: number;   // 发音评分 0-100
  
  // TAP 类型
  selectedOptionId?: string;     // 选择的选项ID
  
  // DRAG 类型
  sourceId?: string;             // 拖拽源ID
  targetId?: string;             // 放置目标ID
  
  // TRACE_PATH 类型
  pathPoints?: Array<{ x: number; y: number; t: number }>; // 轨迹点序列
}
```

### 2.3 服务端数据模型

#### 2.3.1 共学会话记录表 (colearn_session)

```sql
CREATE TABLE colearn_session (
  id              VARCHAR(36)    NOT NULL PRIMARY KEY COMMENT '会话UUID',
  parent_user_id  VARCHAR(36)    NOT NULL COMMENT '家长用户ID',
  child_user_id   VARCHAR(36)    NOT NULL COMMENT '孩子用户ID',
  subject         VARCHAR(20)    NOT NULL COMMENT '学科',
  topic           VARCHAR(100)   NOT NULL COMMENT '学习主题',
  status          VARCHAR(20)    NOT NULL DEFAULT 'active' COMMENT '会话状态',
  difficulty      VARCHAR(10)    NOT NULL DEFAULT 'easy' COMMENT '难度',
  max_duration_min INT           NOT NULL DEFAULT 20 COMMENT '最大时长(分)',
  start_time      DATETIME(3)    NOT NULL COMMENT '开始时间',
  end_time        DATETIME(3)    NULL COMMENT '结束时间',
  duration_sec    INT            NULL COMMENT '持续时长(秒)',
  total_tasks     INT            NOT NULL DEFAULT 0 COMMENT '总任务数',
  correct_count   INT            NOT NULL DEFAULT 0 COMMENT '正确数',
  parent_action_count INT        NOT NULL DEFAULT 0 COMMENT '家长引导次数',
  stars_earned    INT            NOT NULL DEFAULT 0 COMMENT '获得星星',
  created_at      DATETIME(3)    NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at      DATETIME(3)    NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  
  INDEX idx_parent_user (parent_user_id, start_time),
  INDEX idx_child_user (child_user_id, start_time),
  INDEX idx_status (status),
  INDEX idx_start_time (start_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='亲子共学会话记录';
```

#### 2.3.2 共学任务明细表 (colearn_task)

```sql

### 3.2 入口与角色验证流程

```
用户进入共学模式
      │
      ├── 首页 → 快捷操作 → "亲子共学"按钮
      ├── 拼音识字模块 → "和家长一起学"按钮
      └── 学习计划 → 今日任务 → 亲子共学任务
      │
      ▼
  检查家长绑定状态
      │
      ├── 未绑定 → 引导家长绑定流程 → 绑定成功后继续
      │
      ▼
  角色验证 ──────────────────────────────────────
      │
      ├── 方式1：家长密码/PIN验证
      │   → 家长输入4位PIN码（非生物识别，方便隔代家长）
      │   → 验证通过 → 进入配置确认
      │
      ├── 方式2：生物识别验证
      │   → 指纹/Face ID
      │   → 验证通过 → 进入配置确认
      │
      └── 方式3：图形验证（家长预设图形）
          → 家长在九宫格绘制预设图案
          → 验证通过 → 进入配置确认
      │
      ▼

      │
      ├── 选择学科和主题
      ├── 选择难度等级
      ├── 确认时长限制
      └── 点击"开始共学"
      │
      ▼
  进入共学主循环（切换到孩子角色界面）
```

### 3.3 角色切换机制

#### 3.3.1 切换触发方式

| 触发场景 | 切换方向 | 触发方式 | UI 表现 |
|---------|---------|---------|---------|
| 任务展示 | 家长→孩子 | 自动 | 角色指示器变蓝（孩子色），放大展示内容 |
| 孩子作答后 | 孩子→家长 | 自动/手动 | 角色指示器变绿（家长色），显示引导工具栏 |
| 家长点击"让孩子来" | 家长→孩子 | 手动 | 过渡动画，内容放大 |
| 孩子长按屏幕3秒 | 孩子→家长 | 手动 | 弹出家长验证，验证后切换 |
| 休息时间 | 双方 | 自动 | 显示休息界面，两端可交互 |
| 紧急切换 | 孩子→家长 | 手势 | 连续点击屏幕5次，直接弹出家长面板 |
