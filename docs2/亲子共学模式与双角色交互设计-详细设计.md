# 亲子共学模式与双角色交互设计 - 详细设计

## 1. 概述

### 1.1 功能定位

亲子共学模式（Parent-Child Co-learning Mode）是面向幼儿及小学低年级（3-8岁）阶段的特色学习模式。在该模式下，家长与孩子在同一设备上共同参与学习活动，系统根据当前操作角色动态切换 UI 表现、内容深度和交互方式，实现"家长引导 + 孩子实践"的协同学习体验。

### 1.2 设计目标

1. **双角色感知**：系统能准确识别当前操作者是家长还是孩子，并动态适配界面
2. **安全可控**：家长可随时接管控制权，退出学习需家长确认
3. **低操作门槛**：幼儿端交互以语音、触摸、拖拽为主，最小化文字依赖
4. **学习有效性**：通过家长参与提升学习专注度，系统自动记录双方贡献
5. **情感连接**：设计鼓励家长表扬、互动反馈的机制，强化亲子关系

### 1.3 适用学段

| 学段 | 年龄 | 使用频率 | 典型场景 |
|------|------|----------|----------|
| 幼儿小班 | 3-4岁 | 高频 | 拼音启蒙、识字入门、数字认知 |
| 幼儿中班 | 4-5岁 | 高频 | 识字进阶、简单计算、英语启蒙 |
| 幼儿大班 | 5-6岁 | 中频 | 拼音拼读、基础运算、阅读准备 |
| 小学一年级 | 6-7岁 | 低频 | 拼音巩固、生字学习、口算练习 |
| 小学二年级 | 7-8岁 | 偶尔 | 难点辅导、背诵监督 |

> 小学三年级及以上建议使用独立学习模式，不再启用亲子共学。

### 1.4 与现有模块的关系

```
亲子共学模式
├── 依赖 → 用户账号体系（家长绑定关系）
├── 依赖 → 家长中心（使用管理、内容范围配置）
├── 依赖 → 拼音识字启蒙（核心学习内容）
├── 依赖 → 语音服务 ASR/TTS（语音交互）
├── 依赖 → 护眼模式（时长提醒）
├── 依赖 → 防沉迷系统（使用时长控制）
├── 依赖 → 学习记录与进度追踪（数据写入）
└── 输出 → 学情分析（亲子互动数据指标）
```

## 2. 核心概念与数据模型

### 2.1 核心概念

| 概念 | 说明 |
|------|------|
| 共学会话 (CoLearnSession) | 一次完整的亲子共学活动，从开始到结束 |
| 角色切换 (RoleSwitch) | 当前操作者在家长/孩子之间的切换事件 |
| 共学任务 (CoLearnTask) | 一个具体的学习单元，如"认读5个生字" |
| 家长引导动作 (ParentAction) | 家长在共学中的操作，如提示、鼓励、纠正 |
| 孩子作答 (ChildResponse) | 孩子的学习反馈，包括语音、触摸选择等 |
| 共学评价 (CoLearnEvaluation) | 任务完成后的综合评价 |

### 2.2 数据结构定义

#### 2.2.1 共学会话（CoLearnSession）

```typescript
// 客户端本地数据模型
interface CoLearnSession {
  id: string;                    // 会话唯一ID，UUID v4
  parentUserId: string;          // 家长用户ID
  childUserId: string;           // 孩子用户ID
  startTime: number;             // 开始时间戳 (ms)
  endTime: number | null;        // 结束时间戳，进行中为 null
  status: CoLearnSessionStatus;  // 会话状态
  subject: Subject;              // 学科
  topic: string;                 // 学习主题，如"拼音-声母"
  currentRole: Role;             // 当前操作角色
  settings: CoLearnSettings;     // 本次共学配置
  stats: CoLearnStats;           // 实时统计
  tasks: CoLearnTask[];          // 任务列表
  parentActions: ParentAction[]; // 家长操作记录
  deviceInfo: DeviceInfo;        // 设备信息
}

enum CoLearnSessionStatus {
  ACTIVE = 'active',           // 进行中
  PAUSED = 'paused',           // 已暂停（家长临时离开）
  COMPLETED = 'completed',     // 正常完成
  FORCE_ENDED = 'force_ended', // 家长强制结束
  TIMEOUT = 'timeout',         // 超时自动结束
}

enum Role {
  PARENT = 'parent',
  CHILD = 'child',
}

enum Subject {
  PINYIN = 'pinyin',           // 拼音
  LITERACY = 'literacy',       // 识字
  MATH = 'math',               // 数学
  ENGLISH = 'english',         // 英语
  GENERAL = 'general',         // 综合
}
```

#### 2.2.2 共学配置（CoLearnSettings）

```typescript
interface CoLearnSettings {
```

#### 2.2.4 孩子作答（ChildResponse）

```typescript
interface ChildResponse {
  taskId: string;
  type: ResponseType;
  data: ResponseData;
  isCorrect: boolean | null;     // null 表示需家长判定
  timestamp: number;
  confidence: number;            // AI 判断置信度 0-1
}

enum ResponseType {
  VOICE = 'voice',               // 语音作答
  TAP = 'tap',                   // 点击选择
  DRAG = 'drag',                 // 拖拽操作
  TRACE_PATH = 'trace_path',     // 描写路径
  NONE = 'none',                 // 无响应/超时
}

interface ResponseData {
  // VOICE 类型
  audioUri?: string;             // 录音文件 URI
  recognizedText?: string;       // ASR 识别文本
  pronunciationScore?: number;   // 发音评分 0-100
  
  // TAP 类型
  selectedOptionId?: string;     // 选择的选项ID
  
  // DRAG 类型
  sourceId?: string;             // 拖拽源ID
  targetId?: string;             // 放置目标ID
  
  // TRACE_PATH 类型
  pathPoints?: Array<{ x: number; y: number; t: number }>; // 轨迹点序列
}
```

### 2.3 服务端数据模型

#### 2.3.1 共学会话记录表 (colearn_session)

```sql
CREATE TABLE colearn_session (
  id              VARCHAR(36)    NOT NULL PRIMARY KEY COMMENT '会话UUID',
  parent_user_id  VARCHAR(36)    NOT NULL COMMENT '家长用户ID',
  child_user_id   VARCHAR(36)    NOT NULL COMMENT '孩子用户ID',
  subject         VARCHAR(20)    NOT NULL COMMENT '学科',
  topic           VARCHAR(100)   NOT NULL COMMENT '学习主题',
  status          VARCHAR(20)    NOT NULL DEFAULT 'active' COMMENT '会话状态',
  difficulty      VARCHAR(10)    NOT NULL DEFAULT 'easy' COMMENT '难度',
  max_duration_min INT           NOT NULL DEFAULT 20 COMMENT '最大时长(分)',
  start_time      DATETIME(3)    NOT NULL COMMENT '开始时间',
  end_time        DATETIME(3)    NULL COMMENT '结束时间',
  duration_sec    INT            NULL COMMENT '持续时长(秒)',
  total_tasks     INT            NOT NULL DEFAULT 0 COMMENT '总任务数',
  correct_count   INT            NOT NULL DEFAULT 0 COMMENT '正确数',
  parent_action_count INT        NOT NULL DEFAULT 0 COMMENT '家长引导次数',
  stars_earned    INT            NOT NULL DEFAULT 0 COMMENT '获得星星',
  created_at      DATETIME(3)    NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at      DATETIME(3)    NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  
  INDEX idx_parent_user (parent_user_id, start_time),
  INDEX idx_child_user (child_user_id, start_time),
  INDEX idx_status (status),
  INDEX idx_start_time (start_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='亲子共学会话记录';
```

### 3.2 入口与角色验证流程

```
用户进入共学模式
      │
      ├── 首页 → 快捷操作 → "亲子共学"按钮
      ├── 拼音识字模块 → "和家长一起学"按钮
      └── 学习计划 → 今日任务 → 亲子共学任务
      │
      ▼
  检查家长绑定状态
      │
      ├── 未绑定 → 引导家长绑定流程 → 绑定成功后继续
      │
      ▼
  角色验证 ──────────────────────────────────────
      │
      ├── 方式1：家长密码/PIN验证
      │   → 家长输入4位PIN码（非生物识别，方便隔代家长）
      │   → 验证通过 → 进入配置确认
      │
      ├── 方式2：生物识别验证
      │   → 指纹/Face ID
      │   → 验证通过 → 进入配置确认
      │
      └── 方式3：图形验证（家长预设图形）

      │
      ▼

      │
      ├── 选择学科和主题
      ├── 选择难度等级
      ├── 确认时长限制
      └── 点击"开始共学"
      │
      ▼
```

### 3.3 角色切换机制

#### 3.3.1 切换触发方式

| 触发场景 | 切换方向 | 触发方式 | UI 表现 |
|---------|---------|---------|---------|
| 任务展示 | 家长→孩子 | 自动 | 角色指示器变蓝（孩子色），放大展示内容 |
| 孩子作答后 | 孩子→家长 | 自动/手动 | 角色指示器变绿（家长色），显示引导工具栏 |
| 家长点击"让孩子来" | 家长→孩子 | 手动 | 过渡动画，内容放大 |
| 孩子长按屏幕3秒 | 孩子→家长 | 手动 | 弹出家长验证，验证后切换 |
| 休息时间 | 双方 | 自动 | 显示休息界面，两端可交互 |
| 紧急切换 | 孩子→家长 | 手势 | 连续点击屏幕5次，直接弹出家长面板 |

#### 3.5.1 休息触发规则

| 触发类型 | 触发条件 | 可否跳过 | 说明 |
|---------|---------|---------|------|
| 时间型休息 | 达到 `breakIntervalMin`（默认 10 分钟） | 可跳过（家长验证后，每会话最多 1 次） | 常规护眼休息 |
| 强制型休息-超时 | 孩子连续 3 次任务超时未响应 | **不可跳过** | 疑似疲劳/走神，强制离屏 |
| 强制型休息-挫折 | 孩子连续 5 次作答错误 | **不可跳过** | 防止挫败情绪累积，休息界面展示鼓励文案 |
| 强制型休息-家长触发 | 家长点击「休息一下」 | 家长可随时结束 | 转为 PAUSED 语义（见 §3.6） |

> **规则依据**：强制型休息跳过禁令（守卫 G11）来自未成年人保护要求——孩子在疲劳/受挫状态下继续学习的边际收益为负，且休息本身是护眼与防沉迷合规链路的组成部分。家长如认为确有必要中断，应走「暂停」或「结束」路径，二者均有完整的进度保存语义。

#### 3.5.2 休息计时口径

1. 休息时长**计入会话最大时长**（`maxDurationMin`），防止通过反复休息无限延长会话；
2. 休息时长**不计入有效学习时长**（学习时长统计引擎消费口径，见 §13 契约对齐第 9 项）；
3. 休息期间任务计时器冻结（`itemTimer.pause()`），作答时限不被休息消耗；
4. 休息倒计时结束后播放 TTS「休息结束啦，我们继续吧~」，伴随 3-2-1 倒数动画回到当前任务；
5. 休息倒计时默认 90 秒，分龄参数见 §4.1。

#### 3.5.3 休息调度器数据流

```
BreakScheduler（客户端）
      │
      ├── 监听 CoLearnFlowController 的事件流
      │     · TaskTimeoutEvent   → 超时连击计数 +1（达到 3 触发强制）
      │     · TaskWrongEvent     → 错误连击计数 +1（达到 5 触发强制）
      │     · TaskCompletedEvent → 两个连击计数清零
      │     · 每分钟 tick        → 学习累计时长达到 breakIntervalMin 触发时间型
      │
      ├── 触发休息
      │     · 调用 API 上报 break 事件（含 reason，clientEventId 幂等）
      │     · 服务端会话状态 ACTIVE → BREAKING（对齐服务端状态机）
      │     · 冻结任务计时器 / 暂停 TTS / 清空 ASR 会话
      │     · 展示休息界面（孩子角色视觉）
      │
      └── 结束休息
            · 倒计时归零 → 上报 break.end → 服务端 BREAKING → ACTIVE
            · 家长跳过（仅时间型）→ 家长验证 → 上报 break.end(reason=parent_skip)
            · 服务端推送 break.end 帧 → 客户端恢复任务展示（防多端不一致）
```

### 3.6 暂停与恢复交互

#### 3.6.1 暂停触发方式

| 触发源 | 触发条件 | 客户端行为 | 服务端状态 |
|-------|---------|-----------|-----------|
| 家长点击 ⏸ | 家长工具栏「暂停」 | 弹出暂停面板（家长角色） | ACTIVE → PAUSED |
| 来电/系统打断 | 电话呼入、闹钟等 AppLifecycleState.inactive | 自动暂停，记录断点 | ACTIVE → PAUSED |
| 切后台 | App 切后台超过 60 秒 | 自动暂停（短暂切换不误伤） | ACTIVE → PAUSED |
| 设备锁屏 | 屏幕熄灭 | 自动暂停 | ACTIVE → PAUSED |

#### 3.6.2 暂停面板设计

```
┌──────────────────────────────────────┐
│                                      │
│        ⏸  学习已暂停                 │
│                                      │
│   已完成：3/10 题    ⏱ 已学 06:12   │
│                                      │
│   ┌────────────────────────┐        │
│   │ ▶  继续学习             │ ← 主按钮，家长点击直接恢复
│   ├────────────────────────┤        │
│   │ 🛑 结束本次共学          │ ← 需家长验证（G1）
│   ├────────────────────────┤        │
│   │ ⚙  调整共学设置          │ ← 难度/语音开关（会话内即时生效）
│   └────────────────────────┘        │

│   ⚠ 暂停超过 30 分钟将自动保存并结束  │
└──────────────────────────────────────┘
```

#### 3.6.3 恢复与超时规则

1. **恢复无需重新验证**（降低打断成本），但「结束」始终需要家长验证（守卫 G1）；
2. 恢复时服务端校验会话状态，若已被超时清理（PAUSED 超 30 分钟 → 服务端 FORCE_ENDED，对齐服务端状态机 §4.2），客户端收 19006，展示「本次学习已保存」+ 本地简版报告；
3. PAUSED 期间孩子的一切作答输入**丢弃且不记录**（守卫 G5）——防止孩子在家长离开的暂停窗口刷任务；
4. 心跳协议：客户端每 30 秒上报心跳（WS ping 帧）；服务端 ACTIVE 状态下 5 分钟无心跳 → FORCE_ENDED(reason=timeout)，客户端重连后同步清理本地会话（守卫 G13）。

### 3.8 角色验证与安全交互

#### 3.8.1 验证方式与设置

验证方式在「家长中心 → 共学设置」中配置，全局复用家长中心的家长验证组件（见《客户端-家长中心页面架构与管控交互设计》），共学侧不另建一套凭据：

| 方式 | 适用 | 说明 |
|------|------|------|
| 4 位 PIN | 默认，隔代家长友好 | 纯数字键盘、大按键；失败 5 次锁定 10 分钟（G7） |
| 生物识别 | 指纹 / Face ID | 设备支持时可选；硬件故障自动回落 PIN（D9） |
| 图形图案 | 九宫格预设图案 | 备选方式 |

#### 3.8.2 验证时效

| 场景 | 是否需要验证 | 说明 |
|------|------------|------|
| 进入共学模式（入口） | **每次必验** | 家长在场确认 |
| 会话内敏感操作（结束/跳过休息/调整设置） | 验证缓存 10 分钟内免验，超时重验 | 缓存仅存在于会话生命周期 |
| 暂停后恢复 | 免验 | 降低打断（见 §3.6.3） |
| 家长工具栏普通操作（提示/鼓励/确认对错） | 免验 | 会话内默认操作者为家长（角色上下文已在家长角色） |
| 孩子长按/5 连击触发切换到家长面板 | 必验 | 防孩子伪造家长操作（G3） |

#### 3.8.3 PIN 防暴力尝试

```dart
/// PIN 验证控制器（客户端）——锁定状态持久化到本地安全存储
class ParentPinVerifier {
  static const int maxAttempts = 5;
  static const Duration lockDuration = Duration(minutes: 10);

  Future<VerifyResult> verify(String pin) async {
    final lockUntil = await _secureStorage.read('colearn.pin.lock_until');
    final now = DateTime.now();
    if (lockUntil != null && now.isBefore(DateTime.parse(lockUntil))) {
      final remain = DateTime.parse(lockUntil).difference(now).inMinutes + 1;
      return VerifyResult.locked(remainMinutes: remain); // 提示「已锁定，请 X 分钟后再试」
    }
    final ok = await _parentAuthService.verifyPin(pin);
    if (ok) {
      await _secureStorage.delete('colearn.pin.attempts');
      _verificationCache = DateTime.now(); // 写入 10 分钟验证缓存
      return VerifyResult.success();
    }
    final attempts = await _bumpAttempts();
    if (attempts >= maxAttempts) {
      final until = now.add(lockDuration).toIso8601String();
      await _secureStorage.write('colearn.pin.lock_until', until);
      _telemetry.track('colearn_pin_locked'); // 监控：暴力尝试信号
    }
    return VerifyResult.wrong(remaining: maxAttempts - attempts);
  }
}
```

> PIN 校验的**权威判定在服务端家长中心**（客户端本地仅做交互态）；锁定状态客户端先行拦截 + 服务端同步锁定，双保险防绕过（脱机暴力尝试后连上网络也被服务端锁定拦截）。

#### 3.8.4 防退出与防切换

1. 共学进行中拦截系统返回键/手势导航：展示「请请家长来操作」气泡，3 秒消失；
2. `requireParentToSwitchApp = true` 时，检测到切后台累计 60 秒 → 自动 PAUSED（而非直接结束，保留恢复可能）；
3. 幼儿端（3-4 岁）隐藏全部可退出 UI 元素（守卫 G12），退出路径只有：家长工具栏结束、时长上限、设备级打断。

### 4.2 幼儿防误触设计

复用《客户端-全局防误触与儿童安全交互保护机制》的通用规范，共学场景追加：

1. **边缘热区**：屏幕四周 12pt 边缘区域不响应点击（防握持误触）；
2. **多指忽略**：3-4 岁段仅响应单指 tap/drag，多指手势全部忽略；
3. **双击/长按节流**：作答类点击 800ms 节流，防止兴奋连点触发多次提交；
4. **拖拽容差**：匹配类任务拖拽落点容差半径 24pt（4-5 岁以上 16pt），落点判定失败不触发错误音效（仅回弹动画）；
5. **语音按钮互斥**：麦克风按钮按下期间屏蔽全部触摸输入，防止按住说话时误触其他区域。

### 4.3 隔代家长适配

1. 家长面板字号不小于 18pt，操作按钮使用「图标 + 文字」双编码；
2. 高危操作（结束、调整设置）采用**两步确认**：点击 → 800ms 后弹出确认气泡 → 再点确认生效；
3. 首次使用共学模式提供 30 秒可跳过的新手引导动画（演示角色切换与工具栏）；
4. 鼓励模板默认提供 3 条预置话术（对齐 E2E §4.1 `encouragementTemplates`），家长免输入即可发送；自定义输入支持语音转文字。

## 5. 双角色状态同步与冲突处理

### 5.1 客户端角色交互阶段机（RolePhase）

客户端 UI 的角色交互阶段是服务端任务/会话状态机的**展示层投影**，独立维护以保证弱网下交互流畅：

```dart
/// 双角色交互阶段（客户端展示层状态）
enum RolePhase {
  presenting,     // 任务展示中（孩子角色，TTS 朗读/动画）
  awaitingAnswer, // 等待孩子作答（孩子角色）
  evaluating,     // AI 评估中（过渡态，双端 loading）
  parentGuide,    // 家长引导中（家长角色，工具栏可用）
  feedback,       // 结果反馈中（孩子角色，庆祝/鼓励动画）
  breaking,       // 休息中（双端，休息界面）
  paused,         // 已暂停（家长角色，暂停面板）
  ended,          // 已结束（报告/庆祝页）
}
```

```
                 │ presenting   │←──────────────┐
                 └──────┬───────┘               │
                        │ TTS朗读完成/3s动画结束  │ parent.hint(重试)
```

### 5.2 三层状态词汇映射表

本档 §2.2.1 的客户端枚举、服务端权威状态、《端到端流程设计》文档状态三者映射如下（**服务端为权威**，客户端仅作展示态）：

| 客户端 CoLearnSessionStatus（§2.2.1） | 客户端 RolePhase（§5.1） | 服务端权威状态（服务端文档 §4.1） | E2E 文档状态 |
|---|---|---|---|
| —（创建中，未落会话对象） | — | CREATED | preparing |
| ACTIVE | presenting/awaitingAnswer/evaluating/parentGuide/feedback | ACTIVE | inProgress |
| ACTIVE | breaking | BREAKING | onBreak |
| PAUSED | paused | PAUSED | inProgress（E2E 未细分，以本表为准） |
| COMPLETED | ended | COMPLETED | ended |
| FORCE_ENDED（家长/清理） | ended | FORCE_ENDED | ended |
| TIMEOUT（§2.2.1 独立枚举） | ended | FORCE_ENDED(reason=timeout) | ended(timeout) |
| —（未开始即退出） | — | —（CREATED 超时清理） | cancelled |

> **口径修正**：§2.2.1 TypeScript 枚举中的 `TIMEOUT` 是客户端展示语义；服务端不设独立 TIMEOUT 状态，超时统一落入 `FORCE_ENDED` 并以 `end_reason` 区分。开发时以服务端状态机为唯一权威，客户端枚举仅驱动 UI 文案（「时间到啦」vs「已结束」）。

### 5.3 冲突与竞态场景

| # | 场景 | 表现 | 裁决规则 |
|---|------|------|---------|
| 1 | 孩子提交作答与家长点击「跳过」同时发生 | 双请求并发 | 服务端按 `colearn:task:{sessionId}:{taskOrder}` 状态 CAS，先到者生效；后到者收 19002，客户端静默丢弃并同步服务端最终态 |
| 2 | 弱网下作答事件乱序到达 | 重试导致事件重复/乱序 | `clientEventId` 幂等去重；事件携带 `taskOrder`+单调 `seq`，服务端按 seq 丢弃过期事件 |
| 3 | 双设备同一孩子同时进共学 | 第二台设备创建会话 | 服务端 19004 拦截；第二台设备引导「恢复现有会话」或由家长在第一台结束 |
| 4 | WS 断开期间服务端已推进任务 | 重连后本地落后 | 重连后先 `GET /sessions/{id}` 全量校准 + `afterSeq` 增量拉取事件，再渲染（本地未上报事件先补报，见 §9.2） |
| 5 | 切后台 60s 触发自动暂停与家长手动暂停叠加 | 重复 pause 请求 | 幂等：服务端 PAUSED 状态再收 pause 请求返回成功（状态未变化），客户端去重 |
| 6 | 来电时孩子正在录音 | ASR 会话中断 | 录音丢弃，本任务回退 awaitingAnswer 并重置该题计时 |
| 7 | 家长验证缓存到期瞬间孩子 5 连击紧急切换 | 弹出验证面板 | 一律走完整验证（缓存仅覆盖会话内敏感操作，紧急切换入口必验，G3） |
| 8 | 服务端 FORCE_ENDED 与客户端继续操作竞态 | 客户端仍在上报事件 | 上报收 19006 → 客户端立刻停止主循环、拉取服务端终态、进入本地简版报告（D7） |

### 5.4 心跳与断线重连协议

```
客户端                              服务端
  │  WS connect /ws/v1/colearn/{sessionId}  │
  │────────────────────────────────────────→│  鉴权（wsToken，创建会话时下发）
  │                                        │
  │  ping {type:"heartbeat"} 每 30s        │
  │────────────────────────────────────────→│  刷新 colearn:active_sessions score
  │  ←──────────────────────────────────────│  pong
  │                                        │
  │  [断线] → 指数退避重连 1s/2s/4s/8s(max)  │
  │────────────────────────────────────────→│
  │  reconnect {lastSeq: 42}               │
  │────────────────────────────────────────→│
  │  ←─ sync.full（会话快照）                │  若 lastSeq 落后过多（>100 事件）
  │  ←─ sync.incremental [43..48]           │  否则增量推送
  │                                        │
  │  [重连失败超 5 分钟]                     │
  │   → 本地继续（D1），事件全部入离线队列    │
```

> 心跳的**权威超时判定在服务端**（5 分钟无心跳 FORCE_ENDED）；客户端不自行判定会话死亡，仅处理服务端推送或 API 错误码驱动的终态（守卫 G13）。

### 7.1 主循环控制器（CoLearnFlowController）

```dart
/// 亲子共学主循环控制器 —— RolePhase 状态机驱动（§5.1）
class CoLearnFlowController extends ChangeNotifier {
  final CoLearnRepository _repo;
  final BreakScheduler _breakScheduler;
  final OfflineEventQueue _offlineQueue;
  final TtsService _tts;

  RolePhase _phase = RolePhase.presenting;
  int _seq = 0;                          // 客户端事件单调序号
  CoLearnSession _session = /* ... */;

  RolePhase get phase => _phase;

  Future<void> onItemPresented(CoLearnTask task) async {
    _setPhase(RolePhase.presenting);
    await _tts.speak(task.ttsScript);     // 幼儿段全量朗读（G12）
    _setPhase(RolePhase.awaitingAnswer);
    _itemTimer = Timer(task.answerTimeLimit, () => onChildTimeout(task));
  }

  /// 孩子作答入口（voice/tap/drag/trace 统一收敛）
  Future<void> onChildResponse(ChildResponse resp) async {
    if (_phase != RolePhase.awaitingAnswer) return;   // G2：非等待态输入忽略
    _itemTimer?.cancel();
    _setPhase(RolePhase.evaluating);

    final result = await _submitWithFallback(
      () => _repo.submitResponse(_session.id, resp.taskOrder,
          clientEventId: resp.clientEventId, seq: _seq++),
    );

    switch (result?.evaluation?.route) {
      case 'AUTO':
        _breakScheduler.onTaskResult(isCorrect: result.isCorrect);
        await _showFeedback(result.isCorrect);
        break;
      case 'PARENT_JUDGE':
      default:                             // 含降级 D3/D4（null 走家长判定）
        _setPhase(RolePhase.parentGuide);   // 切家长角色 UI
        break;
    }
  }

  /// 家长工具栏操作入口
  Future<void> onParentAction(ParentAction action) async {
    if (_phase != RolePhase.parentGuide) return;
    await _submitWithFallback(
      () => _repo.submitParentAction(_session.id, action,
          clientEventId: action.clientEventId, seq: _seq++),
    );
    switch (action.type) {
      case ParentActionType.HINT:
      case ParentActionType.DEMO:
        _setPhase(RolePhase.awaitingAnswer);  // 回到孩子重答，重置该题计时
        _itemTimer = Timer(currentTask.answerTimeLimit,
            () => onChildTimeout(currentTask));
        break;
      case ParentActionType.CONFIRM:
      case ParentActionType.ENCOURAGE:
      case ParentActionType.CORRECT:
        _breakScheduler.onTaskResult(isCorrect: action.resolvedCorrect);
        await _showFeedback(action.resolvedCorrect);
        break;
      case ParentActionType.SKIP:
        await _advanceToNextTask();
        break;
      case ParentActionType.PAUSE:
        await _pause();
        break;
      case ParentActionType./* END */ FORCE_END:
        await _endSession(EndReason.parentManual);
        break;
    }
  }

  Future<void> _showFeedback(bool isCorrect) async {
    _setPhase(RolePhase.feedback);
    await _feedbackPlayer.play(isCorrect);   // 庆祝/鼓励动画+音效
    _breakScheduler.onTickCheck();           // 时间型休息检查
    if (_breakScheduler.shouldBreak) {
      await _enterBreak();
    } else if (_session.allTasksDone) {
      await _endSession(EndReason.normal);
    } else {
      await _advanceToNextTask();
    }
  }

  Future<EvalResult?> _submitWithFallback(Future<EvalResult?> Function() fn) async {
    try {
      return await fn();
    } on NetworkException {
      return null;                            // D1：事件已由 repo 层入离线队列
    } on ApiException catch (e) {
      if (e.code == 19006) await _syncTerminalState();  // §5.3 场景 8
      rethrow;
    }
  }

  void _setPhase(RolePhase p) { _phase = p; notifyListeners(); }
}
```

### 7.2 角色切换管理器（RoleSwitchManager）

```dart
class RoleSwitchManager {
  final ParentAuthGate _authGate;           // 家长中心验证组件（§3.8.1）
  DateTime? _verificationCacheAt;
  static const _cacheTtl = Duration(minutes: 10);

  Role _currentRole = Role.CHILD;
  final _roleStream = StreamController<Role>.broadcast();

  Role get currentRole => _currentRole;

  /// 自动切换（任务阶段驱动，无需验证）
  Future<void> autoSwitch(Role target, RoleSwitchTrigger trigger) async {
    _currentRole = target;
    await _reportSwitch(target, trigger, verified: false);
    _roleStream.add(target);
  }

  /// 手动/紧急切换到家长面板 —— 必须验证（G3）
  Future<bool> requestSwitchToParent(RoleSwitchTrigger trigger) async {
    final ok = await _authGate.verify(reason: 'switch_to_parent');
    if (!ok) return false;
    _verificationCacheAt = DateTime.now();
    _currentRole = Role.PARENT;
    await _reportSwitch(Role.PARENT, trigger, verified: true);
    _roleStream.add(Role.PARENT);
    return true;
  }

  /// 会话内敏感操作验证（缓存 10 分钟，G7）
  Future<bool> verifyForSensitiveAction() async {
    if (_verificationCacheAt != null &&
        DateTime.now().difference(_verificationCacheAt!) < _cacheTtl) {
      return true;
    }
    final ok = await _authGate.verify(reason: 'sensitive_action');
    if (ok) _verificationCacheAt = DateTime.now();
    return ok;
  }

  Future<void> _reportSwitch(Role target, RoleSwitchTrigger t,
      {required bool verified}) async {
    await _repo.reportRoleSwitch(
      clientEventId: _uuid.v4(), seq: _seq++,
      from: _currentRole, to: target,
      trigger: t.name, verified: verified,
    );
  }
}
```

### 7.3 休息调度器（BreakScheduler）

```dart
class BreakScheduler {
  final CoLearnRepository _repo;
  final CoLearnSettings _settings;
  final AgeBand _ageBand;                  // 分龄参数（§4.1）

  int _timeoutStreak = 0;                  // 连续超时计数
  int _wrongStreak = 0;                    // 连续错误计数
  int _continuousLearnSec = 0;             // 距上次休息的连续学习秒数
  int _parentSkipUsed = 0;                 // 家长跳过次数（时间型，上限 1）
  bool get shouldBreak =>
      _timeoutStreak >= 3 || _wrongStreak >= 5 ||
      _continuousLearnSec >= _settings.breakIntervalMin * 60;

  void onTaskResult({required bool isCorrect}) {
    if (isCorrect) { _timeoutStreak = 0; _wrongStreak = 0; }
    else { _wrongStreak += 1; _timeoutStreak = 0; }
  }

  void onChildTimeout() => _timeoutStreak += 1;

  void onTickCheck() { /* 由主循环每秒 tick 累加 _continuousLearnSec */ }

  BreakType get pendingType =>
      (_timeoutStreak >= 3 || _wrongStreak >= 5)
          ? BreakType.FORCED               // 强制型：不可跳过（G11）
          : BreakType.TIMED;

  Duration get breakDuration => _ageBand.breakCountdown;  // 分龄倒计时

  /// 家长请求跳过休息 —— 仅时间型 + 验证 + 每会话一次
  Future<bool> requestSkip(RoleSwitchManager roleMgr) async {
    if (pendingType == BreakType.FORCED) return false;    // G11
    if (_parentSkipUsed >= 1) return false;
    if (!await roleMgr.verifyForSensitiveAction()) return false;
    _parentSkipUsed += 1;
    await _repo.reportBreakEnd(reason: 'parent_skip',
        clientEventId: _uuid.v4());
    _resetCounters();
    return true;
  }

  void _resetCounters() {
    _timeoutStreak = 0; _wrongStreak = 0; _continuousLearnSec = 0;
  }
}
```

## 9. 幂等、并发与离线同步

### 9.1 clientEventId 幂等规则

1. 每个互动事件（response/parent-action/role-switch/break 事件/状态变更）生成唯一 `clientEventId`（UUID v4）；
2. 重试复用同一 `clientEventId`（失败重发不改 ID），服务端 60 秒幂等窗口内去重（对齐服务端 Redis `colearn:idempotent:*` TTL）；
3. 超过幂等窗口的迟到重试由 `seq` 单调序号兜底：服务端按会话丢弃 `seq ≤ 已处理最大 seq` 的事件；
4. 幂等命中返回**首次处理结果**（而非空响应），保证客户端状态机不因重试分叉。

### 9.2 离线事件队列与恢复上报

复用《端到端流程设计-亲子共学模式完整链路》§8.2 的 `OfflineEventQueue`（Hive 本地 box），本档补充恢复时序与顺序约束：

```
网络恢复 / 会话结束
      │
      ▼
flush(sessionId)
      │  1. 按 seq 升序取队列（保证事件顺序 = 交互顺序）
      │  2. 分批上报（每批 ≤ 20 条，批间 500ms 间隔，防突发限流）
      │  3. 批次全部成功 → 清除该批；任一失败 → 保留队列，下轮重试
      │  4. 服务端逐条幂等（clientEventId）+ 顺序校验（seq）
      ▼
flush 完成 → 若会话已 ended：拉取服务端报告校正本地统计
           → 若会话仍 active：GET /sessions/{id} 全量校准阶段
```

**顺序性红线**：作答事件（response）与其后的家长操作（parent-action）必须保序——家长判定依赖对应作答存在，乱序会导致服务端 EVALUATING 悬挂。队列按 seq 严格升序 flush，禁止并行分批。

### 9.3 并发场景处理汇总

| 场景 | 处理 | 关联 |
|------|------|------|
| 重复点击提交（800ms 节流穿透） | clientEventId 幂等 | §4.2/§9.1 |
| 双设备并发 | 服务端 19004 单会话约束 | §5.3 场景 3 |
| 重连事件补报与实时事件交错 | 先补报（flush）后校准（GET）再订阅增量 | §5.3 场景 4 |
| 息屏/来电打断录音 | 录音丢弃，任务回退 awaitingAnswer | §5.3 场景 6 |
| 服务端已终态客户端仍操作 | 19006 → 停止主循环进简版报告 | §5.3 场景 8 |
