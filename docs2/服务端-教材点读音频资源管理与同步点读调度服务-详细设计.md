## 1. 概述

### 1.1 功能定位

教材点读音频资源管理与同步点读调度服务（以下简称 **ReadAloudService**）是支撑客户端“互动教材阅读器”的后端核心服务，负责：

1. **课文音频资源管理**：维护课文文本段落、句子、字词与音频时间轴的映射关系。
2. **同步点读调度**：根据客户端点击位置，快速定位并返回对应音频片段的起止时间。
3. **音频生成与更新**：基于 TTS 或人工录制音频，生成带时间轴标注的标准化点读音频。
4. **播放策略控制**：支持单句循环、逐句跟读、全文连读、调速播放等模式。
5. **学习行为记录**：记录点读行为、跟读评测结果，回流至学习画像与学情分析。

### 1.2 应用场景

| 场景 | 描述 | 触发入口 |
|------|------|----------|
| 课文点读 | 用户点击课文中某句/某词，客户端播放对应音频 | 同步课堂 → 教材阅读器 |
| 逐句跟读 | 播放一句后自动录音，ASR 评分并反馈 | 阅读器 → 跟读模式 |
| 全文朗读 | 按段落顺序连续播放整篇课文 | 阅读器 → 播放全部 |
| 调速播放 | 0.5x / 0.75x / 1.0x / 1.25x / 1.5x | 阅读器播放控制栏 |
| 离线缓存 | 客户端预下载音频与时间点索引 | 阅读器 → 下载课文包 |

### 1.3 非功能性目标

| 指标 | 目标 | 说明 |
|------|------|------|
| 点读响应时间 | ≤ 200ms | 从点击到开始播放（本地缓存命中时） |
| 服务端时间轴查询 | ≤ 50ms | P99 |
| 音频首包时间 | ≤ 1s | CDN/边缘缓存命中 |
| 时间轴精度 | ± 50ms | 字词级对齐误差 |
| 并发支持 | 10,000 QPS | 高峰期点读请求 |
| 可用性 | 99.9% | 核心学习时段 |

## 2. 核心概念与数据模型

### 2.1 术语定义

| 术语 | 说明 |
|------|------|
| 课文 (LessonText) | 一篇完整的教材课文，包含标题、正文、段落、句子、字词层级 |
| 音频切片 (AudioSegment) | 课文音频中对应某一文本单元的连续时间片段 |
| 时间轴 (Timeline) | 文本单元（段落/句子/字词）与音频切片的映射关系集合 |
| 点读单元 (ReadUnit) | 客户端可点击的最小文本单元，通常为句子或字词 |
| 播放模式 (PlayMode) | `sentence` / `word` / `paragraph` / `full` / `follow` |
| 语速 (SpeedRate) | 播放速度系数：0.5 / 0.75 / 1.0 / 1.25 / 1.5 |
| 对齐算法 (Alignment) | 将文本与音频进行时间对齐的算法，如 Forced Alignment、VAD+TTS 时长预测 |

## 5. 关键代码示例

### 5.1 时间轴定位服务

```java
@Service
public class ReadAloudTimelineService {

    @Autowired
    private ReadAloudTimelineRepository timelineRepository;

    @Autowired
    private StringRedisTemplate redisTemplate;

    private static final String TIMELINE_CACHE_KEY = "readaloud:timeline:%d:%s";

    /**
     * 根据 unit_id 定位音频片段
     */
    public AudioSegment locateSegment(Long audioId, String unitType, String unitId) {
        // 1. 优先查询缓存
        String cacheKey = String.format(TIMELINE_CACHE_KEY, audioId, unitType);
        String cached = redisTemplate.opsForHash().get(cacheKey, unitId);
        if (cached != null) {
            return JSON.parseObject(cached, AudioSegment.class);
        }

        // 2. 缓存未命中，查询数据库
        AudioSegment segment = timelineRepository
            .findByAudioIdAndUnitTypeAndUnitId(audioId, unitType, unitId)
            .orElseThrow(() -> new ReadAloudException(
                ReadAloudErrorCode.SEGMENT_NOT_FOUND,
                "未找到对应的点读单元: " + unitId
            ));

        // 3. 写入缓存（异步）
        redisTemplate.opsForHash().put(cacheKey, unitId, JSON.toJSONString(segment));
        redisTemplate.expire(cacheKey, Duration.ofDays(7));

        return segment;
    }

    /**
     * 根据音频时间点反向查找当前所在单元
     */
    public AudioSegment locateByTimestamp(Long audioId, String unitType, int currentMs) {
        String cacheKey = String.format(TIMELINE_CACHE_KEY, audioId, unitType);
        
        // 使用 ZSet 按 start_ms 排序查找
        Set<ZSetOperations.TypedTuple<String>> range = redisTemplate.opsForZSet()
            .rangeByScoreWithScores(cacheKey, 0, currentMs);
        
        if (CollectionUtils.isEmpty(range)) {
            throw new ReadAloudException(ReadAloudErrorCode.SEGMENT_NOT_FOUND,
                "当前播放位置未匹配到文本单元");
        }

        // 取 start_ms 最大的即当前所在单元
        String currentUnitId = range.stream()
            .max(Comparator.comparingDouble(ZSetOperations.TypedTuple::getScore))
            .map(ZSetOperations.TypedTuple::getValue)
            .orElseThrow();

        return locateSegment(audioId, unitType, currentUnitId);
    }

    /**
     * 批量预加载时间轴到缓存
     */
    @Async
    public CompletableFuture<Void> preloadTimeline(Long audioId, String unitType) {
        List<AudioSegment> segments = timelineRepository
            .findByAudioIdAndUnitTypeOrderBySequence(audioId, unitType);
        
        String cacheKey = String.format(TIMELINE_CACHE_KEY, audioId, unitType);
        Map<String, String> hash = segments.stream()
            .collect(Collectors.toMap(
                AudioSegment::getUnitId,
                JSON::toJSONString
            ));
        
        redisTemplate.opsForHash().putAll(cacheKey, hash);
        redisTemplate.expire(cacheKey, Duration.ofDays(7));

        // 同时写入 ZSet 用于时间戳反向查找
        Set<ZSetOperations.TypedTuple<String>> zset = segments.stream()
            .map(s -> ZSetOperations.TypedTuple.of(
                s.getUnitId(),
                (double) s.getStartMs()
            ))
            .collect(Collectors.toSet());
        
        String zsetKey = String.format("readaloud:timeline:%d:%s:zset", audioId, unitType);
        redisTemplate.opsForZSet().add(zsetKey, zset);
        redisTemplate.expire(zsetKey, Duration.ofDays(7));

        return CompletableFuture.completedFuture(null);
    }
}
```

### 5.2 播放调度服务

```java
@Service
public class ReadAloudPlaybackService {

    @Autowired
    private ReadAloudTimelineService timelineService;

    @Autowired
    private ReadAloudAudioRepository audioRepository;

    /**
     * 计算点读播放区间
     */
    public PlaybackSegment calculatePlaybackSegment(PlaybackRequest request) {
        // 1. 校验音频资源状态
        ReadAloudAudio audio = audioRepository
            .findByIdAndStatus(request.getAudioId(), "published")
            .orElseThrow(() -> new ReadAloudException(
                ReadAloudErrorCode.AUDIO_NOT_PUBLISHED,
                "点读音频未发布或不存在"
            ));

        // 2. 定位目标单元
        AudioSegment target = timelineService.locateSegment(
            request.getAudioId(),
            request.getUnitType(),
            request.getUnitId()
        );

        // 3. 根据播放模式决定起止范围
        int startMs = target.getStartMs();
        int endMs = target.getEndMs();
        String nextUnitId = target.getNextUnitId();

        switch (request.getPlayMode()) {
            case "paragraph":
                // 查找段落内所有句子，扩展到段落首尾
                AudioSegment paragraph = timelineService.locateSegment(
                    request.getAudioId(), "paragraph", target.getParentUnitId()
                );
                startMs = paragraph.getStartMs();
                endMs = paragraph.getEndMs();
                nextUnitId = paragraph.getNextUnitId();
                break;
            case "full":
                startMs = 0;
                endMs = audio.getDurationMs();
                nextUnitId = null;
                break;
            case "word":
                // word 模式已经在 target 中是最小单元
                break;
            case "sentence":
            default:
                break;
        }

        // 4. 应用语速系数（服务端只返回时间范围，实际变速由客户端处理）
        // 注：TTS 预生成多语速音频时，可返回对应音频 URL
        return PlaybackSegment.builder()
            .audioUrl(audio.getAudioUrl())
            .startMs(startMs)
            .endMs(endMs)
            .durationMs(endMs - startMs)
            .speedRate(request.getSpeedRate())
            .nextUnitId(nextUnitId)
            .textContent(target.getTextContent())
            .build();
    }
}
```

### 5.3 音频生成任务（异步）

```python
# readaloud_generation_worker.py
import asyncio
from typing import List
from dataclasses import dataclass

@dataclass
class TimelineUnit:
    unit_id: str
    unit_type: str
    text: str
    sequence: int

class ReadAloudGenerationWorker:
    def __init__(self, tts_client, alignment_engine, oss_client):
        self.tts_client = tts_client
        self.alignment_engine = alignment_engine
        self.oss_client = oss_client

    async def generate(self, lesson_id: int, units: List[TimelineUnit], 
                       voice_id: str, speed_rate: float) -> dict:
        """
        1. 调用 TTS 生成完整音频
        2. 使用强制对齐算法生成时间轴
        3. 上传音频到 OSS
        4. 持久化时间轴数据
        """
        # 1. 合并文本
        full_text = " ".join([u.text for u in units])
        
        # 2. 调用 TTS（流式或一次性）
        audio_bytes = await self.tts_client.synthesize(
            text=full_text,
            voice_id=voice_id,
            speed=speed_rate,
            format="mp3"
        )
        
        # 3. 音频强制对齐
        alignment_result = await self.alignment_engine.align(
            audio=audio_bytes,
            transcript=full_text,
            units=units,
            level="word"  # 支持字词级对齐
        )
        
        # 4. 上传音频
        audio_url = await self.oss_client.upload(
            bucket="primetop-audio",
            key=f"readaloud/{lesson_id}/{voice_id}_{speed_rate}.mp3",
            data=audio_bytes,
            content_type="audio/mp3"
        )
        
        # 5. 构建时间轴
        segments = []
        for unit in units:
            aligned = alignment_result.get(unit.unit_id)
            segments.append({
                "unit_id": unit.unit_id,
                "unit_type": unit.unit_type,
                "sequence": unit.sequence,
                "text_content": unit.text,
                "start_ms": aligned.start_ms,
                "end_ms": aligned.end_ms,
                "confidence": aligned.confidence
            })
        
        return {
            "audio_url": audio_url,
            "duration_ms": alignment_result.total_duration_ms,
            "segments": segments
        }

    async def generate_multiple_speeds(self, lesson_id: int, units: List[TimelineUnit],
                                       voice_id: str) -> List[dict]:
        """生成多个语速版本的音频"""
        speeds = [0.75, 1.0, 1.25]
        tasks = [self.generate(lesson_id, units, voice_id, s) for s in speeds]
        return await asyncio.gather(*tasks)
```

```dart
/// 互动教材阅读器 - 点读控制器
class ReadAloudController extends GetxController {
  final AudioPlayer _audioPlayer = AudioPlayer();
  late ReadAloudLesson _lesson;
  ReadAloudTimeline? _timeline;
  String? _currentUnitId;

  /// 初始化课文点读资源
  Future<void> initLesson(int lessonId) async {
    final audioInfo = await _readAloudApi.getLessonAudio(lessonId);
    _timeline = await _readAloudApi.getTimeline(audioInfo.audioId, 'sentence');
    
    // 预缓存音频到本地
    await _audioPlayer.setSourceUrl(audioInfo.audioUrl);

  /// 用户点击句子触发点读
  Future<void> onSentenceTap(String unitId, {double speed = 1.0}) async {
    final segment = _timeline!.findByUnitId(unitId);
    if (segment == null) return;

    _currentUnitId = unitId;
    
    // 客户端本地裁剪播放
    await _audioPlayer.seek(Duration(milliseconds: segment.startMs));
    await _audioPlayer.play();
    
    // 监听播放进度，到达结束位置自动暂停
    _audioPlayer.onPositionChanged.listen((position) {
      if (position.inMilliseconds >= segment.endMs) {
        _audioPlayer.pause();
        // 触发学习行为上报
        _reportReadAction(unitId, segment.startMs, segment.endMs, speed);
      }
    });
  }

  /// 逐句跟读模式
  Future<void> startFollowMode(String unitId) async {
    // 1. 播放原句
    await onSentenceTap(unitId);
    
    // 2. 播放完成后开始录音
    await Future.delayed(const Duration(milliseconds: 500));
    final recorder = AudioRecorder();
    await recorder.start();
    
    // 3. 5秒后停止并上传评测
    await Future.delayed(const Duration(seconds: 5));
    final path = await recorder.stop();
    final result = await _readAloudApi.evaluateFollow(
      audioId: _lesson.audioId,
      unitId: unitId,
      audioFilePath: path,
    );
    
    // 4. 展示评分反馈
    _showFollowFeedback(result);
  }

  Future<void> _reportReadAction(String unitId, int startMs, int endMs, double speed) async {
    await _readAloudApi.reportLearningLog(
      lessonId: _lesson.lessonId,
      audioId: _lesson.audioId,
      unitType: 'sentence',
      unitId: unitId,
      actionType: 'play',
      playStartMs: startMs,
      playEndMs: endMs,
      speedRate: speed,
    );
  }
```

### 7.2 异常场景处理

| 异常场景 | 客户端处理 | 服务端处理 | 降级策略 |
|----------|-----------|-----------|----------|
| 音频文件不存在 | 显示“音频资源维护中”，引导学习其他课文 | 返回 `AUDIO_NOT_FOUND`，触发告警 | 使用 TTS 临时合成音频 |

| CDN 音频加载失败 | 自动重试 3 次，失败后切换备用 CDN | 监控 CDN 可用性 | 回源到对象存储直链 |

```java
public PlaybackSegment fallbackPlayback(FallbackRequest request) {
    try {
        // 优先使用精准时间轴
        return calculatePlaybackSegment(request);
    } catch (ReadAloudException e) {
        if (e.getCode() == ReadAloudErrorCode.SEGMENT_NOT_FOUND) {

            request.setUnitType("paragraph");
            return calculatePlaybackSegment(request);

        if (e.getCode() == ReadAloudErrorCode.AUDIO_NOT_FOUND) {
            // 降级为 TTS 实时合成
            return ttsSynthesizeSegment(request);
        }
        throw e;
    }
}
```

## 8. 性能优化

### 8.1 缓存策略

| 数据 | 缓存层 | TTL | 策略 |
|------|--------|-----|------|
| 音频元数据 | Redis Hash | 7 天 | 发布时预热 |
| 时间轴索引 | Redis Hash + ZSet | 7 天 | 客户端预加载时批量写入 |
| 用户进度 | Redis Hash | 3 天 | 写后即时更新 |
| 热门音频 | CDN 边缘节点 | 30 天 | 按教材版本预推 |
| 时间轴完整数据 | 客户端本地 SQLite | 长期 | 下载课文包时持久化 |

### 8.2 音频分片与 CDN 优化

- 整篇课文音频存储为单个文件，通过 HTTP Range 请求实现客户端本地裁剪播放。
- CDN 配置 `Accept-Ranges: bytes`，支持断点续传。
- 多码率音频：提供 64kbps（移动网络）和 128kbps（Wi-Fi）两种规格。
- 音频文件按教材版本、学期、年级分目录存储，便于批量预热。

### 8.3 数据库查询优化

```sql
-- 查询某课文已发布音频
SELECT * FROM readaloud_lesson_audio 
WHERE lesson_id = ? AND status = 'published' 
ORDER BY timeline_version DESC LIMIT 1;

-- 查询时间轴（覆盖索引）
SELECT * FROM readaloud_timeline_segment 
WHERE audio_id = ? AND unit_type = ? 
ORDER BY sequence;

-- 查询用户最近点读进度
SELECT * FROM readaloud_user_lesson_progress 
WHERE user_id = ? ORDER BY updated_at DESC LIMIT 20;
```

### 8.4 并发控制

- 音频生成任务采用分布式锁（Redis + Redisson），避免同一课文重复生成。
- 用户进度更新使用 `INSERT ... ON DUPLICATE KEY UPDATE`，保证幂等性。
- 时间轴数据发布时为只读，客户端读取无锁。

## 9. 安全与合规

### 9.1 权限控制

- 课文点读资源按教材版本和学段进行访问控制，用户只能访问当前学段及以下内容。
- 会员专享课文（如精品朗读音频）需校验会员权益。
- 管理后台音频生成接口需 `CONTENT_EDITOR` 或 `ADMIN` 角色。

### 9.2 内容安全

- 所有 TTS 生成的音频需经过内容安全审核（语音转文本后审核）。
- 人工录制音频上传后需人工抽检，防止背景噪音、错误读音。
- 语文课文点读严格使用教材原文，禁止 AI 自行改编。

### 9.3 数据隐私

- 用户跟读录音保存 90 天后自动清理，仅保留评分结果。
- 学习行为日志脱敏后用于模型优化。
- 未成年人点读行为数据不与第三方共享。
