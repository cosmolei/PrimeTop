# 答案管控与渐进式提示引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

答案管控与渐进式提示引擎（Answer Control & Progressive Hint Engine，简称 ACPH）是 PrimeTop 的跨模块核心子系统，负责：

1. **答案渐进式展示**：将 AI 回答按"提示→思路→关键步骤→完整答案"逐级展示，引导学生主动思考而非直接抄答案。
2. **答案解锁策略**：根据用户学段、会员等级、学习场景控制答案可见性和解锁条件。
3. **反抄答案机制**：检测并干预用户"只看答案不思考"的行为模式。
4. **学习效果追踪**：记录每级提示的使用情况和对应的答题结果，为学情分析提供数据支撑。

### 1.2 设计动机

原始设计文档多处强调答案管控的重要性：

- "优先引导学生理解思路，再逐步展示答案"（§6.2.2）
- "答案隐藏：默认先显示思路和提示，降低直接抄答案风险"（§6.3.2）
- "引导理解：AI 回答应采用提示、思路、步骤、总结、练习的结构"（§9.1）
- 风险表："用户依赖答案 → 直接抄答案，学习效果弱"（§15）

### 1.3 影响范围

| 受影响模块 | 集成方式 |
|------------|----------|
| AI 智能辅导 | 对话回答的渐进式展示 |
| 拍照搜题与习题答疑 | 解析答案的分步解锁 |
| 练习与测评系统 | 答题后的解析分级展示 |
| 错题整理 | 订正时的引导式提示 |
| 考试模拟 | 真题解析的条件解锁 |
| AI-Prompt 编排 | Prompt 模板中的分级输出指令 |

### 1.4 术语定义

| 术语 | 说明 |
|------|------|
| Answer Tier | 答案层级，从 Hint（提示）到 Full Answer（完整答案）的分级 |
| Reveal Action | 揭示操作，用户主动触发的"查看下一级"行为 |
| Unlock Condition | 解锁条件，访问某一级答案需满足的前提 |
| Copy Risk Score | 抄答案风险分，基于行为模式计算的 0-1 分数 |
| Tier Response | 分级响应，AI 输出按层级拆分后的单级内容 |
| Answer Session | 答案会话，一次完整的渐进式揭示过程 |

## 2. 答案层级模型

### 2.1 层级定义

系统定义 5 个标准答案层级，所有 AI 输出必须映射到此层级体系：

```
┌─────────────────────────────────────────────────┐
│ TIER 0: PROBLEM_UNDERSTANDING  题目理解          │
│   识别题型、知识点、难度，确认解题方向            │
├─────────────────────────────────────────────────┤
│ TIER 1: HINT  思路提示                           │
│   一句话提示解题方向，不涉及具体步骤              │
├─────────────────────────────────────────────────┤
│ TIER 2: KEY_INSIGHT  关键突破                    │
│   核心公式/定理/方法点明，仍不展示完整过程        │
├─────────────────────────────────────────────────┤
│ TIER 3: STEP_BY_STEP  分步详解                   │
│   完整解题步骤展示，含公式推导和计算过程          │
├─────────────────────────────────────────────────┤
│ TIER 4: FULL_ANSWER  完整答案                    │
│   最终答案、验算过程、易错总结、同类题方法        │
└─────────────────────────────────────────────────┘
```

### 2.2 层级映射规则（按场景）

| 场景 | 默认起始层 | 可见层级 | 最终可达层 |
|------|-----------|----------|-----------|
| AI 辅导（文字问答） | TIER 0 | 全部 | TIER 4 |
| 拍题答疑 | TIER 0 | 全部 | TIER 4 |
| 练习作答中 | 无 | 无（禁止查看） | TIER 0（仅题目信息） |
| 练习作答后（正确） | TIER 1 | TIER 1-4 | TIER 4 |
| 练习作答后（错误） | TIER 2 | TIER 2-4 | TIER 4 |
| 考试模拟（进行中） | 无 | 无 | 无 |
| 考试模拟（结束后） | TIER 2 | TIER 2-4 | TIER 4 |
| 错题订正（首次） | TIER 0 | 全部 | TIER 4 |
| 错题订正（复习） | TIER 1 | TIER 1-4 | TIER 4 |

### 2.3 分龄策略

| 学段 | 默认策略 | 说明 |
|------|---------|------|
| 幼儿 | 直接展示 TIER 3-4 | 低龄以理解为先，不强调独立思考 |
| 小学低年级(1-3) | 起始 TIER 1，可逐级查看 | 鼓励思考但不强制等待 |
| 小学高年级(4-6) | 起始 TIER 0，每级停留 5s | 培养独立思考习惯 |
| 初中 | 起始 TIER 0，每级停留 10s | 强化自主解题能力 |
| 高中 | 起始 TIER 0，每级停留 15s，强制思考 | 备考要求独立解题 |

### 3.3 枚举与常量

```python
from enum import IntEnum
from dataclasses import dataclass
from typing import Optional

class AnswerTier(IntEnum):
    """答案层级"""
    PROBLEM_UNDERSTANDING = 0   # 题目理解
    HINT = 1                    # 思路提示
    KEY_INSIGHT = 2             # 关键突破
    STEP_BY_STEP = 3            # 分步详解
    FULL_ANSWER = 4             # 完整答案

class SourceType(str, Enum):
    """来源场景类型"""
    AI_TUTOR = "ai_tutor"
    PHOTO_SEARCH = "photo_search"
    PRACTICE = "practice"
    EXAM = "exam"
    MISTAKE_REVIEW = "mistake_review"
    HOMEWORK = "homework"

class UnlockMethod(str, Enum):
    """解锁方式"""
    FREE = "free"               # 无条件免费
    TIMER = "timer"             # 定时器等待
    TRY_ANSWER = "try_answer"   # 尝试回答
    AD = "ad"                   # 观看广告
    MEMBER = "member"           # 会员特权
    FORCED = "forced"           # 系统强制（如练习后解析）

class TriggerType(str, Enum):
    """触发类型"""
    AUTO = "auto"               # 自动展示（如起始层级）
    MANUAL = "manual"           # 用户主动点击
    FORCED = "forced"           # 系统强制（如考试结束）

@dataclass
class TierConfig:
    """单层级配置"""
    tier: AnswerTier
    unlock_method: UnlockMethod
    timer_seconds: int = 0          # 定时器秒数（0=无定时器）
    require_answer: bool = False    # 是否需要尝试回答
    member_only: bool = False       # 是否仅会员
    ad_supported: bool = False      # 是否支持广告解锁

@dataclass
class SceneConfig:
    """场景配置"""
    source_type: SourceType
    default_start_tier: AnswerTier
    max_tier: AnswerTier
    tier_configs: list[TierConfig]
    stage_overrides: dict[str, list[TierConfig]]  # 学段覆盖配置
```

## 5. 核心业务逻辑

### 5.1 答案会话创建流程

```python
class AnswerSessionService:
    """答案会话服务"""

    def __init__(
        self,
        session_repo: AnswerSessionRepository,
        tier_content_repo: AnswerTierContentRepository,
        config_resolver: SceneConfigResolver,
        ai_service: AIContentGenerator,
        cache: RedisClient,
    ):
        self.session_repo = session_repo
        self.tier_content_repo = tier_content_repo
        self.config_resolver = config_resolver
        self.ai_service = ai_service
        self.cache = cache

    async def create_session(
        self,
        user_id: int,
        source_type: SourceType,
        source_id: str,
        context: dict,
        question_id: int | None = None,
    ) -> AnswerSession:
        """创建答案会话"""

        # 1. 解析场景配置
        scene_config = self.config_resolver.resolve(
            source_type=source_type,
            stage=context.get("stage"),
            subject=context.get("subject"),
            membership_level=context.get("membership_level"),
        )

        # 2. 检查是否已有活跃会话（幂等）
        existing = await self.session_repo.find_active(
            user_id=user_id,
            source_type=source_type,
            source_id=source_id,
        )
        if existing:
            return existing

        # 3. 创建会话记录
        session = AnswerSession(
            user_id=user_id,
            source_type=source_type,
            source_id=source_id,
            question_id=question_id,
            tier_count=scene_config.max_tier + 1,
            current_tier=scene_config.default_start_tier,
            max_allowed_tier=scene_config.max_tier,
        )
        session = await self.session_repo.save(session)

        # 4. 生成所有层级内容（异步，可批量或延迟生成）
        await self._generate_tier_contents(session, context, scene_config)

        # 5. 缓存会话状态
        await self._cache_session_state(session, scene_config)

        return session

    async def _generate_tier_contents(
        self,
        session: AnswerSession,
        context: dict,
        scene_config: SceneConfig,
    ) -> None:
        """生成答案层级内容"""

        # 检查缓存命中（相同题目的内容可复用）
        cache_key = self._build_content_cache_key(context, session.question_id)
        cached_tiers = await self.cache.get(cache_key)

        if cached_tiers and len(cached_tiers) == session.tier_count:
            # 从缓存写入持久层
            for tier_data in cached_tiers:
                await self.tier_content_repo.save(
                    AnswerTierContent(
                        session_id=session.id,
                        tier=tier_data["tier"],
                        tier_type=tier_data["tier_type"],
                        title=tier_data["title"],
                        content=tier_data["content"],
                        content_hash=tier_data["content_hash"],
                        generated_by="ai_cached",
                    )
                )
            return

        # 调用 AI 一次性生成分级内容
        prompt = self._build_tier_generation_prompt(context, scene_config)
        ai_response = await self.ai_service.generate_structured(
            prompt=prompt,
```

### 5.2 揭示控制流程

```python
class RevealService:
    """揭示控制服务"""

    async def reveal(
        self,
        session_id: str,
        user_id: int,
        target_tier: AnswerTier,
        unlock_method: UnlockMethod,
        user_answer: str | None = None,
        time_spent_ms: int = 0,
    ) -> RevealResult:
        """执行揭示操作"""

        # 1. 加载会话状态
        session = await self._load_session(session_id, user_id)
        scene_config = self.config_resolver.resolve(
            source_type=session.source_type,
            # ... context from session
        )

        # 2. 校验目标层级合法性
        if target_tier > session.max_allowed_tier:
            raise ACPHError(
                code=40302,
                message=f"当前场景最高允许层级为 {session.max_allowed_tier}",
            )

        if target_tier <= session.current_tier:
            raise ACPHError(
                code=40901,
                message="该层级已揭示",
            )

        # 3. 逐级校验解锁条件（不能跳过中间层级）
        for tier in range(session.current_tier + 1, target_tier + 1):
            tier_config = scene_config.tier_configs[tier]
            await self._check_unlock_condition(
                session=session,
                tier=tier,
                tier_config=tier_config,
                unlock_method=unlock_method,
                user_answer=user_answer,
                time_spent_ms=time_spent_ms,
            )

        # 4. 获取层级内容
        contents = []
        for tier in range(session.current_tier + 1, target_tier + 1):
            content = await self.tier_content_repo.get_by_session_tier(
                session_id=session.id, tier=tier
            )
            if not content:
                raise ACPHError(code=40401, message=f"层级 {tier} 内容不存在")
            contents.append(content)

        # 5. 记录揭示操作
        for tier in range(session.current_tier + 1, target_tier + 1):
            await self._record_reveal_action(
                session=session,
                from_tier=tier - 1,
                to_tier=tier,
                trigger_type=self._determine_trigger(unlock_method),
                unlock_method=unlock_method,
                time_spent_ms=time_spent_ms if tier == target_tier else 0,
                user_answer=user_answer if tier == target_tier else None,
            )

        # 6. 更新会话状态
        session.current_tier = target_tier
        if target_tier == session.max_allowed_tier:
            session.is_completed = True
            session.completed_at = datetime.utcnow()
        await self.session_repo.save(session)
        await self._cache_session_state(session, scene_config)

        # 7. 异步更新抄答案风险
        background_task(
            self.risk_service.update_risk_score,
            user_id=user_id,
            session_id=session_id,
            skipped=(target_tier - session.current_tier > 1),
        )

        return RevealResult(
            session_id=session_id,
            revealed_tier=target_tier,
            contents=contents,
            is_completed=session.is_completed,
        )

    async def _check_unlock_condition(
        self,
        session: AnswerSession,
        tier: int,
        tier_config: TierConfig,
        unlock_method: UnlockMethod,
        user_answer: str | None,
        time_spent_ms: int,
    ) -> None:
        """检查解锁条件"""

        # 免费解锁
        if tier_config.unlock_method == UnlockMethod.FREE:
            return

        # 定时器解锁
        if tier_config.unlock_method == UnlockMethod.TIMER:
            if time_spent_ms < tier_config.timer_seconds * 1000:
                remaining = tier_config.timer_seconds * 1000 - time_spent_ms
                raise ACPHError(
                    code=40303,
                    message=f"需等待 {tier_config.timer_seconds} 秒",
                    data={"remaining_time_ms": remaining},
                )
            return

        # 尝试回答解锁
        if tier_config.unlock_method == UnlockMethod.TRY_ANSWER:
            if not user_answer or not user_answer.strip():
                raise ACPHError(
                    code=40301,
                    message="需要先尝试回答",
                    data={"required_action": "try_answer"},
                )
            return  # 不判断对错，只要尝试了就解锁

        # 会员解锁
        if tier_config.unlock_method == UnlockMethod.MEMBER:
            if not await self._check_membership(session.user_id):
                raise ACPHError(
                    code=40304,
                    message="该层级仅会员可查看",
                    data={"required_action": "subscribe"},
                )
            return

        # 广告解锁
        if tier_config.unlock_method == UnlockMethod.AD:
            if unlock_method != UnlockMethod.AD:
                raise ACPHError(
                    code=40305,
                    message="需观看广告解锁",
                    data={"required_action": "watch_ad"},
                )
            return

        raise ACPHError(code=40300, message="未知解锁方式")
```

```python
class SkipRevealService:
    """跳级揭示服务"""

    MAX_SKIP_RISK = 0.85  # 风险分上限，超过则强制逐级

    async def skip_reveal(
        self,
        session_id: str,
        user_id: int,
        target_tier: AnswerTier,
        reason: str = "user_initiated",

        """跳级揭示（允许跳过中间层级）"""

        session = await self._load_session(session_id, user_id)
        risk_score = await self.risk_service.get_risk_score(user_id)

        # 风险分过高时拒绝跳级
        if risk_score >= self.MAX_SKIP_RISK:
            raise ACPHError(
                code=40306,
                message="检测到近期频繁跳级查看答案，请先尝试独立思考",
                data={"risk_score": risk_score, "max_allowed": self.MAX_SKIP_RISK},
            )

        skipped_tiers = list(range(session.current_tier + 1, target_tier))

        # 仍然获取所有层级内容（跳过的层级也记录）
        all_contents = []
        for tier in range(session.current_tier + 1, target_tier + 1):
            content = await self.tier_content_repo.get_by_session_tier(
                session_id=session.id, tier=tier
            )
            all_contents.append(content)

        # 只返回目标层级内容
        target_content = all_contents[-1]

        # 记录跳级操作
        await self._record_reveal_action(
            session=session,
            from_tier=session.current_tier,
            to_tier=target_tier,
            trigger_type=TriggerType.MANUAL,
            unlock_method=UnlockMethod.FREE,  # 跳级默认免费但有风险
            time_spent_ms=0,
            is_skip=True,
            skipped_tiers=skipped_tiers,
        )

        # 更新会话
        session.current_tier = target_tier
        if target_tier >= session.max_allowed_tier:
            session.is_completed = True
            session.completed_at = datetime.utcnow()
        await self.session_repo.save(session)

        # 更新风险分
        risk_delta = 0.1 * len(skipped_tiers)
        new_score = await self.risk_service.add_risk_score(
            user_id=user_id,
            delta=risk_delta,
        )

        return SkipRevealResult(
            session_id=session_id,
            revealed_tier=target_tier,
            skipped_tiers=skipped_tiers,
            content=target_content,
            copy_risk_impact=RiskImpact(
                score_delta=f"+{risk_delta:.2f}",
                current_score=new_score,
                warning=self._get_risk_warning(new_score),
            ),
        )
```

## 6. 抄答案风险评估引擎

### 6.1 风险评分模型

抄答案风险分 (Copy Risk Score) 取值范围 [0, 1]，基于以下维度加权计算：

| 维度 | 权重 | 指标 | 数据来源 |
|------|------|------|----------|
| 跳级频率 | 0.25 | 当日跳级操作数 / 当日总会话数 | reveal_actions |
| 停留时间 | 0.25 | 当日平均每级停留时间（越短越可疑） | reveal_actions.time_spent_ms |
| 尝试回答率 | 0.20 | 需要尝试回答时实际提交的比例 | reveal_actions.user_answer |
| 连续跳级天数 | 0.15 | 连续多少天跳级比 > 50% | 聚合计算 |
| 深度阅读率 | 0.15 | 查看到 TIER 4 后的平均阅读时长 | reveal_actions + 客户端埋点 |

### 6.2 风险分计算

```python
class CopyRiskService:
    """抄答案风险评估服务"""

    # 阈值配置
    LOW_THRESHOLD = 0.3    # 低于此值为低风险
    MEDIUM_THRESHOLD = 0.6 # 低于此值为中风险
    HIGH_THRESHOLD = 0.85  # 达到此值强制逐级

    async def calculate_risk_score(self, user_id: int) -> float:
        """计算用户当前风险分"""
        daily_stats = await self._get_daily_stats(user_id)
        weekly_stats = await self._get_weekly_stats(user_id)

        # 维度 1: 跳级频率
        skip_ratio = daily_stats.skip_count / max(daily_stats.total_sessions, 1)
        skip_score = min(skip_ratio, 1.0)

        # 维度 2: 停留时间（中位数15秒为基准）
        avg_time = daily_stats.avg_tier_time_ms / 1000  # 转秒
        time_score = max(0, 1 - avg_time / 15)  # 15秒以上为0，0秒为1

        # 维度 3: 尝试回答率
        attempt_rate = daily_stats.answer_attempts / max(daily_stats.answer_required, 1)
        attempt_score = 1 - attempt_rate  # 越不尝试分越高

        # 维度 4: 连续跳级天数
        streak_score = min(weekly_stats.consecutive_skip_days / 7, 1.0)

        # 维度 5: 深度阅读率
        deep_read_ratio = daily_stats.deep_read_count / max(daily_stats.full_answer_views, 1)
        deep_read_score = 1 - deep_read_ratio

        # 加权计算
        risk_score = (
            0.25 * skip_score +
            0.25 * time_score +
            0.20 * attempt_score +
            0.15 * streak_score +
            0.15 * deep_read_score
        )

        return round(min(risk_score, 1.0), 4)

    def get_risk_level(self, score: float) -> str:
        """风险等级"""
        if score < self.LOW_THRESHOLD:
            return "low"
        elif score < self.MEDIUM_THRESHOLD:
            return "medium"
        elif score < self.HIGH_THRESHOLD:
            return "high"
        else:
            return "critical"
```

### 6.3 干预策略

| 风险等级 | 分值范围 | 干预措施 |
|---------|---------|---------|
| low | 0 - 0.3 | 无干预，正常使用 |
| medium | 0.3 - 0.6 | 温馨提示："试着先自己想想" |
| high | 0.6 - 0.85 | 强制尝试回答后才可查看下一级 |
| critical | 0.85+ | 禁止跳级，强制逐级解锁；通知家长（如已绑定） |

```python
class InterventionEngine:

        return Intervention(
```

### 9.2 配置热更新

配置存储在 `answer_control_configs` 表中，通过配置中心管理：

```python
class AnswerConfigManager:
    """答案管控配置管理器"""

    CACHE_KEY = "acph:config"
    CACHE_TTL = 300  # 5分钟缓存

    async def get_effective_config(
        self,
        source_type: SourceType,
        stage: str,
        subject: str,
        membership_level: str,
    ) -> SceneConfig:
        """获取生效配置（优先级：具体 > 通用）"""

        # 1. 尝试从缓存加载
        cached = await self.cache.get(self.CACHE_KEY)
        if cached:
            return self._resolve_from_cache(cached, source_type, stage, subject)

        # 2. 从数据库加载所有活跃配置
        configs = await self.config_repo.find_active()
        await self.cache.set(self.CACHE_KEY, configs, self.CACHE_TTL)

        # 3. 按优先级解析
        # 优先级: scene+stage+subject > scene+stage > scene > global
        return self._resolve(configs, source_type, stage, subject)
```

## 11. 错误处理

### 11.1 错误码体系

| 错误码 | HTTP 状态码 | 说明 | 客户端处理 |
|--------|-----------|------|-----------|
| 40301 | 403 | 需要尝试回答 | 显示答案输入框 |
| 40302 | 403 | 超出最大允许层级 | 隐藏"查看更多"按钮 |
| 40303 | 403 | 定时器未到期 | 显示倒计时 |
| 40304 | 403 | 需要会员 | 引导会员购买页 |
| 40305 | 403 | 需要观看广告 | 触发广告播放流程 |
| 40306 | 403 | 风险分过高，禁止跳级 | 显示提示，强制逐级 |
| 40401 | 404 | 层级内容不存在 | 重新生成或降级 |
| 40402 | 404 | 答案会话不存在 | 重新创建 |
| 40901 | 409 | 层级已揭示 | 刷新状态 |
| 50001 | 500 | AI 内容生成失败 | 降级到缓存或通用模板 |
| 50002 | 500 | 配置解析失败 | 使用默认配置 |

### 11.2 降级策略

```
ACPH 降级链路:

1. AI 实时生成 (首选)
   ↓ 失败/超时(>10s)
2. 缓存命中 (相同题目的历史生成结果)
   ↓ 缓存未命中
3. 模板降级 (通用分级模板，非个性化)
   ↓ 模板也不可用
4. 直接展示 (绕过分级，完整答案一次性展示)
   + 记录降级事件
   + 触发告警
```

```python
class ACPHDegradationHandler:
    """ACPH 降级处理器"""

    async def get_tier_content_with_fallback(
        self,
        session: AnswerSession,
        tier: int,
    ) -> AnswerTierContent:
        try:
            # Level 1: 正常获取
            content = await self.tier_content_repo.get_by_session_tier(
                session.id, tier
            )
            if content:
                return content

            # Level 2: 尝试缓存
            cache_key = self._build_cache_key(session, tier)
            cached = await self.cache.get(cache_key)
            if cached:
                return AnswerTierContent.from_cache(cached)

            # Level 3: 模板降级
            template = await self.template_service.get_fallback(tier)
            return AnswerTierContent(
                session_id=session.id,
                tier=tier,
                content=template.render(session.context),
                generated_by="template_fallback",
            )

        except Exception as e:
            # Level 4: 直接展示
            logger.error(f"ACPH degraded to direct show: {e}")
            await self.event_bus.publish(Event(
                type="acph.degraded",
                data={"session_id": session.id, "tier": tier, "error": str(e)},
            ))
            return self._build_fallback_content(session, tier)
```

## 12. 性能考量

### 12.1 关键性能指标

| 操作 | 目标延迟 | 说明 |
|------|---------|------|
| 创建会话 | < 200ms | 含首次层级内容返回 |
| 揭示下一级 | < 100ms | 仅获取已生成内容 |
| 跳级揭示 | < 150ms | 含风险分计算 |
| 风险分查询 | < 50ms | Redis 直读 |
| 分级内容生成 | < 5s | AI 异步生成，非阻塞 |

### 12.2 优化策略

1. **预生成**：答案会话创建时一次性生成所有层级内容，揭示时直接读取
2. **缓存复用**：相同题目 + 相同学段的分级内容可跨用户复用（content_hash 匹配）
3. **Redis 热路径**：会话状态、风险分、定时器全部走 Redis，避免 DB 查询
4. **异步风险更新**：风险分计算在后台异步完成，不阻塞揭示操作
5. **批量预加载**：离线场景下可批量预加载多个题目的层级内容

### 12.3 容量估算

| 资源 | 估算依据 | 日增量 |
|------|---------|--------|
| answer_sessions | 50万 DAU × 5 次/人 | 250万条 |
| answer_tier_contents | 250万 × 5 层 | 1250万条 |
| reveal_actions | 250万 × 3 次揭示 | 750万条 |
| Redis 内存 | 250万 session × 1KB | ~2.5GB |

> 历史数据按月归档至 ClickHouse，MySQL 仅保留近 3 个月热数据。
