## 1. 模块概述

### 1.1 功能定位

学习数据实时聚合与统计预计算引擎（Learning Statistics Aggregation Engine，简称 LSAE）是 PrimeTop 的**统计计算基础设施**，位于学习行为记录（LRPS）与上层分析展示（学情分析、首页工作台、学习报告）之间。它负责将海量的细粒度学习行为事件实时或准实时地聚合为可供直接查询的统计指标，避免上层模块每次请求都回溯原始日志进行全量计算。

### 1.2 核心问题

| 问题 | 说明 |
|------|------|
| 实时性 | 首页工作台需要秒级展示"今日学习XX分钟、完成XX题"，不能依赖离线批处理 |
| 高并发 | 高峰期数十万活跃用户同时查看统计数据，直接查询原始日志不可行 |
| 多维度 | 同一份行为数据需要按日/周/月、按学科、按模块、按知识点等多个维度聚合 |
| 一致性 | 离线上报数据可能延迟数小时到达，需要回溯更新已聚合的统计 |
| 成本 | 原始日志量巨大（日增千万级），频繁全量扫描消耗大量计算资源 |

### 1.3 设计目标

| 指标 | 目标值 |
|------|--------|
| 实时计数器写入延迟 | ≤ 50ms（P99） |
| 统计快照查询延迟 | ≤ 100ms（P99） |
| 离线上报数据回溯窗口 | T-7 天内可自动修正 |
| 日聚合批处理耗时 | ≤ 30min（百万DAU规模） |
| 预计算统计表存储膨胀 | 原始日志量的 ≤ 5% |

```
                    ┌─────────────────────────────────┐
                    │        原始事件写入               │
                    │  LRPS → learning_activity_log    │
                    └───────────┬─────────────────────┘

                    │       第二层：预计算快照           │

                    │  日终批处理写入（分钟级）           │

                    └──────────────────────────────────┘

### 2.2 数据流路径

| 场景 | 数据源 | 路径 | 延迟 |
|------|--------|------|------|

| 学情页"本周正确率" | MySQL 日统计快照 | 日终批处理 → 按周聚合 | T+1 |
| 学习报告月度统计 | MySQL 周/月快照 | 日终批处理 → 月聚合 | T+1 |
| 离线数据回溯 | 两者 | 日终对比修正 → 更新快照 + 补计计数器 | T+1 |

## 3. 数据结构设计

### 3.1 Redis 实时计数器

#### 3.1.1 Key 命名规范

```
stat:{user_id}:{date}:{metric}
```

- `{date}` 格式：`yyyyMMdd`（如 `20260523`）
- Key 过期策略：创建后 **8 天**（覆盖回溯窗口 + 1天 buffer）

#### 3.1.2 计数器指标定义

| metric | Redis 类型 | 说明 | 写入时机 |
|--------|-----------|------|----------|
| `study_time` | String (int) | 学习时长（秒） | 每次 session 结束 / 心跳上报 |
| `question_count` | String (int) | 答题总数 | 答题行为写入时 |
| `correct_count` | String (int) | 正确数 | 答题行为写入时（is_correct=1） |
| `ai_chat_count` | String (int) | AI 对话次数 | AI 问答行为写入时 |
| `photo_solve_count` | String (int) | 拍题次数 | 拍题行为写入时 |
| `chapter_completed` | Set | 已完成章节ID集合 | 章节进度达到100%时 |
| `active_modules` | HyperLogLog | 活跃模块去重计数 | 任意行为写入时 |
| `study_sessions` | String (int) | 学习会话数 | session 开始时 |
| `mistake_added` | String (int) | 新增错题数 | 错题收录行为写入时 |
| `mistake_reviewed` | String (int) | 复习错题数 | 错题复习行为写入时 |

#### 3.1.3 学科维度计数器

对于需要按学科拆分的指标，使用 Hash 类型：

```
stat:{user_id}:{date}:subject_time  → Hash
  field: MATH    → 1200  (秒)
  field: CHINESE → 900
  field: ENGLISH → 600

stat:{user_id}:{date}:subject_questions  → Hash
  field: MATH    → 15
  field: CHINESE → 10
  field: ENGLISH → 8

stat:{user_id}:{date}:subject_correct  → Hash
  field: MATH    → 12
  field: CHINESE → 8
  field: ENGLISH → 7
```

#### 3.1.4 连续天数计数器

```
streak:{user_id}  → String (int)
  值：连续学习天数
  过期：永不过期（由服务管理）
  每日首次学习时更新
```

辅助 Key：

```
streak:{user_id}:last_date  → String
  值：最近一次有学习行为的日期 yyyyMMdd
  过期：永不过期
```

## 4. 核心流程设计

### 4.1 实时计数器更新流程

事件写入时同步更新 Redis 计数器，与 LRPS 事件写入在同一事务内。

```python
# aggregation/realtime_counter.py

import redis
from datetime import date
from typing import Optional

class RealtimeCounter:
    """实时统计计数器"""

    def __init__(self, redis_client: redis.Redis):
        self.r = redis_client
        self._today = date.today().strftime("%Y%m%d")

    def _key(self, user_id: int, metric: str) -> str:
        return f"stat:{user_id}:{self._today}:{metric}"

    def _subject_key(self, user_id: int, metric: str) -> str:
        return f"stat:{user_id}:{self._today}:{metric}"

    def incr_study_time(self, user_id: int, seconds: int) -> None:
        """累加学习时长"""
        key = self._key(user_id, "study_time")
        pipe = self.r.pipeline()
        pipe.incrby(key, seconds)
        pipe.expire(key, 8 * 86400)  # 8天过期
        pipe.execute()

    def incr_subject_time(self, user_id: int, subject_code: str, seconds: int) -> None:
        """累加学科学习时长"""
        key = self._subject_key(user_id, "subject_time")
        pipe = self.r.pipeline()
        pipe.hincrby(key, subject_code, seconds)
        pipe.expire(key, 8 * 86400)
        pipe.execute()

    def record_answer(self, user_id: int, subject_code: str,
                      is_correct: bool) -> None:
        """记录一次答题"""
        pipe = self.r.pipeline()
        
        # 总计数
        pipe.incrby(self._key(user_id, "question_count"), 1)
        if is_correct:
            pipe.incrby(self._key(user_id, "correct_count"), 1)
        
        # 学科计数
        q_key = self._subject_key(user_id, "subject_questions")
        c_key = self._subject_key(user_id, "subject_correct")
        pipe.hincrby(q_key, subject_code, 1)
        if is_correct:
            pipe.hincrby(c_key, subject_code, 1)
        
        # 设置过期
        for k in [q_key, c_key]:
            pipe.expire(k, 8 * 86400)
        
        pipe.execute()

    def incr_module_count(self, user_id: int, module: str) -> None:
        """记录模块使用次数"""
        key = self._key(user_id, f"{module}_count")
        pipe = self.r.pipeline()
        pipe.incrby(key, 1)
        pipe.expire(key, 8 * 86400)
        pipe.execute()

    def record_active_module(self, user_id: int, module: str) -> None:
        """记录活跃模块（HyperLogLog 去重）"""
        key = self._key(user_id, "active_modules")
        pipe = self.r.pipeline()
        pipe.pfadd(key, module)
        pipe.expire(key, 8 * 86400)
        pipe.execute()

    def add_completed_chapter(self, user_id: int, chapter_id: int) -> None:
        """记录完成章节（Set 去重）"""
        key = self._key(user_id, "chapter_completed")
        pipe = self.r.pipeline()
        pipe.sadd(key, chapter_id)
        pipe.expire(key, 8 * 86400)
        pipe.execute()

    def update_streak(self, user_id: int) -> int:
        """更新连续学习天数，返回当前连续天数"""
        streak_key = f"streak:{user_id}"
        last_date_key = f"streak:{user_id}:last_date"
        today_str = self._today

        # Lua 脚本保证原子性
        lua_script = """
        local streak_key = KEYS[1]
        local last_date_key = KEYS[2]
        local today = ARGV[1]
        
        local last_date = redis.call('GET', last_date_key)
        
        if last_date == today then
            -- 今天已更新过
            return tonumber(redis.call('GET', streak_key))
        end
        
        redis.call('SET', last_date_key, today)
        
        if last_date == nil then
            -- 首次
            redis.call('SET', streak_key, 1)
            return 1
        end
        
        -- 检查昨天是否有学习（允许1天gap）
        local yesterday = ARGV[2]
        if last_date == yesterday then
            -- 连续
            return redis.call('INCR', streak_key)
        else
            -- 断了，重新计数
            redis.call('SET', streak_key, 1)
            return 1
        end
        """
        
        from datetime import timedelta
        yesterday = (date.today() - timedelta(days=1)).strftime("%Y%m%d")
        
        return self.r.eval(
            lua_script, 2,
            streak_key, last_date_key,
            today_str, yesterday
        )

    def get_today_summary(self, user_id: int) -> dict:
        """获取今日实时统计概要"""
        pipe = self.r.pipeline()
        
        keys = {
            "study_time": self._key(user_id, "study_time"),
            "question_count": self._key(user_id, "question_count"),
            "correct_count": self._key(user_id, "correct_count"),
            "ai_chat_count": self._key(user_id, "ai_chat_count"),
            "photo_solve_count": self._key(user_id, "photo_solve_count"),
            "study_sessions": self._key(user_id, "study_sessions"),
            "mistake_added": self._key(user_id, "mistake_added"),
            "mistake_reviewed": self._key(user_id, "mistake_reviewed"),
        }
        
        for key in keys.values():
            pipe.get(key)
        
        pipe.pfcount(self._key(user_id, "active_modules"))
        pipe.scard(self._key(user_id, "chapter_completed"))
        pipe.get(f"streak:{user_id}")
        
        results = pipe.execute()
        
        values = {}
        for name, result in zip(keys.keys(), results[:len(keys)]):
            values[name] = int(result) if result else 0
        
        values["active_modules"] = results[len(keys)] or 0
        values["chapter_completed"] = results[len(keys) + 1] or 0
        values["streak_days"] = int(results[len(keys) + 2]) if results[len(keys) + 2] else 0
        
        # 计算正确率
        if values["question_count"] > 0:
            values["accuracy_rate"] = round(
                values["correct_count"] / values["question_count"], 4
            )
        else:
            values["accuracy_rate"] = None
        
        return values

```python
# 在 LRPS 的行为写入服务中注入实时计数器更新

class LearningActivityService:
    """学习行为写入服务（LRPS 组件）"""
    
    def __init__(
        self,
        db: Session,
        counter: RealtimeCounter,
        event_bus: EventBus,
    ):
        self.db = db
        self.counter = counter
        self.event_bus = event_bus
    
    async def record_activity(self, activity: LearningActivityCreate) -> LearningActivityLog:
        """记录一条学习行为"""
        # 1. 写入原始日志
        log = LearningActivityLog(**activity.dict())
        self.db.add(log)
        self.db.commit()
        
        # 2. 更新实时计数器（非阻塞，失败不影响主流程）
        try:
            self._update_realtime_counters(activity)
        except Exception as e:
            logger.warning(f"实时计数器更新失败，将由日终批处理补正: {e}")
        
        # 3. 发布事件
        self.event_bus.publish("learning.activity.created", {
            "user_id": activity.user_id,
            "activity_type": activity.activity_type,
            "subject_code": activity.subject_code,
            "duration_sec": activity.duration_sec,
            "is_correct": activity.is_correct,
        })
        
        return log
    
    def _update_realtime_counters(self, activity: LearningActivityCreate) -> None:
        """根据行为类型更新对应的实时计数器"""
        user_id = activity.user_id
        
        # 学习时长
        if activity.duration_sec and activity.duration_sec > 0:
            self.counter.incr_study_time(user_id, activity.duration_sec)
            if activity.subject_code:
                self.counter.incr_subject_time(
                    user_id, activity.subject_code, activity.duration_sec
                )
        
        # 答题统计
        if activity.is_correct is not None:
            self.counter.record_answer(
                user_id,
                activity.subject_code or "UNKNOWN",
                activity.is_correct,
            )
        
        # 模块计数
        module_map = {
            "AI_CHAT": "ai_chat_count",
            "PHOTO_SOLVE": "photo_solve_count",
            "PRACTICE": None,  # 已通过答题统计覆盖
            "REVIEW": "mistake_reviewed",
            "MISTAKE_CORRECT": "mistake_reviewed",
            "SYNC_STUDY": None,
            "ESSAY": None,
        }
        counter_metric = module_map.get(activity.activity_type)
        if counter_metric:
            self.counter.incr_module_count(user_id, counter_metric)
        
        # 活跃模块（HyperLogLog）
        self.counter.record_active_module(user_id, activity.source_module)
        
        # 连续天数
        self.counter.update_streak(user_id)
