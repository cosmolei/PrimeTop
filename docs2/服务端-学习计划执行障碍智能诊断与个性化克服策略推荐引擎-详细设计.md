## 1. 模块概述

### 1.1 功能定位

学习计划执行障碍智能诊断与个性化克服策略推荐引擎（Plan Execution Barrier Diagnosis Engine，以下简称 **PEBDE**）是学习规划子系统的**根因分析核心**。当学生用户的学习计划执行出现偏差（任务积压、完成率下降、连续缺勤、特定学科/任务类型系统性跳过等）时，PEBDE 负责深入分析执行失败的**底层原因**，将偏差归因到具体的障碍类型，并为下游系统输出个性化的障碍消除策略建议。

与已有模块的定位差异：

| 模块 | 解决的问题 | 与本引擎的区别 |
|------|-----------|---------------|
| 计划动态调整与智能重排（PRS） | 计划偏离后**怎么调整** | PRS 关注"做什么调整"，PEBDE 关注"为什么会偏离" |
| 计划质量评估与成功率预测 | 计划**是否合理** | 关注计划本身质量，而非执行过程中的障碍 |
| 每日任务智能生成与执行追踪 | 任务**是否完成** | 关注执行记录，不诊断未执行的根因 |
| 学习目标达成度评估 | 目标**达成了多少** | 度量差距，不分析差距的成因 |
| 学习规划复盘 | 计划执行**事后总结** | 周期性回顾，PEBDE 实时诊断并即时推荐策略 |

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 障碍类型识别准确率 | 与教研专家人工标注一致率 ≥ 75% |
| 诊断响应延迟 | 从异常检测到诊断结论输出 ≤ 30 秒（P95） |
| 策略推荐覆盖率 | 覆盖 6 大类 24 种障碍子类型 |
| 策略有效性 | 推荐策略执行后 7 天内计划完成率提升 ≥ 15% |
| 日均诊断量 | 支持 ≥ 20 万次诊断场景 |
| 覆盖学段 | 小学、初中、高中全学段 |

### 1.3 适用范围

- 学生端学习计划执行异常的实时诊断
- 周报/月报中执行障碍归因分析
- 家长端学情报告中的计划执行障碍说明
- 教师端班级计划执行问题共性分析
- 运营分析：平台级计划执行障碍分布与趋势

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| Plan | 一份学习计划，包含若干 Task |
| Task | 计划中的单个学习任务 |
| 执行偏差（Deviation） | 实际执行情况与计划预期的差距 |
| 障碍（Barrier） | 导致执行偏差的根本原因 |
| 障碍类型（Barrier Type） | 对障碍的分类，如时间管理型、难度型等 |
| 策略（Strategy） | 针对障碍推荐的消除/缓解方案 |
| 诊断会话（Diagnosis Session） | 一次完整的障碍分析过程 |

## 2. 核心概念

### 2.1 执行障碍分类体系

```
学习计划执行障碍
├── A. 时间管理型障碍（Time Management Barrier）
│   ├── A1. 时间不足型 —— 实际可用时间远少于计划预期
│   ├── A2. 时间碎片型 —— 时间被频繁打断，无法形成有效学习块
│   ├── A3. 时间错配型 —— 在低效时段安排了高难度任务
│   └── A4. 拖延型 —— 任务被推迟到截止前才匆忙执行
├── B. 认知与难度型障碍（Cognitive & Difficulty Barrier）
│   ├── B1. 前置知识缺失型 —— 缺少必要的前置知识
│   ├── B2. 任务过载型 —— 任务量超出认知负荷上限
│   ├── B3. 难度跳跃型 —— 任务难度梯度不合理
│   └── B4. 迷思概念型 —— 存在错误的前概念
├── C. 动机与情绪型障碍（Motivation & Emotion Barrier）
│   ├── C1. 目标模糊型 —— 缺乏清晰的学习目标驱动
│   ├── C2. 自我效能感低型 —— 对完成任务缺乏信心
│   ├── C3. 畏难回避型 —— 对困难任务系统性回避
│   └── C4. 兴趣衰减型 —— 对学科/内容形式失去兴趣
├── D. 行为习惯型障碍（Behavioral Habit Barrier）
│   ├── D1. 启动困难型 —— 难以开始学习行为
│   ├── D2. 中断恢复困难型 —— 学习被打断后难以恢复
│   ├── D3. 多任务切换型 —— 频繁切换，深度不足
│   └── D4. 完成质量妥协型 —— 只完成表面任务
├── E. 外部干扰型障碍（External Interference Barrier）
│   ├── E1. 学业冲突型 —— 学校作业/考试冲突
│   ├── E2. 设备技术型 —— 设备/网络问题
│   ├── E3. 环境干扰型 —— 学习环境不适宜
│   └── E4. 社交活动型 —— 社交/课外活动占时
└── F. 计划设计型障碍（Plan Design Barrier）
    ├── F1. 任务粒度不当型 —— 任务过大或过小
    ├── F2. 内容重复型 —— 与学校作业重复
    ├── F3. 节奏不匹配型 —— 计划节奏与实际不符
    └── F4. 灵活度不足型 —— 计划过于刚性
```

### 2.2 诊断信号矩阵

| 信号类别 | 信号名称 | 数据来源 | 指示的障碍类型 |
|----------|---------|---------|--------------|
| 时序信号 | 任务完成时段分布 | 执行追踪服务 | A3、D1 |
| 时序信号 | 任务延迟执行率 | 执行追踪服务 | A4、D2 |
| 完成度信号 | 各学科完成率差异 | 执行追踪服务 | B1/B3、C4 |
| 完成度信号 | 任务类型完成率差异 | 执行追踪服务 | D4、C3 |
| 完成度信号 | 连续缺勤天数 | 执行追踪服务 | C1、E1 |
| 质量信号 | 用时/预估偏差 | 执行追踪+任务复杂度 | B2、B3 |
| 质量信号 | 答题正确率趋势 | 练习记录服务 | B1、B4 |
| 行为信号 | 任务跳过率 | 客户端埋点 | C3、C4 |
| 行为信号 | App启动到学习延迟 | 客户端启动日志 | D1 |
| 行为信号 | 会话中断频率 | 学习会话引擎 | D3、E3 |
| 情绪信号 | AI对话负面情绪分数 | AI对话情感感知引擎 | C2、C3 |
| 知识信号 | 前置知识点掌握度 | 知识追踪模型 | B1 |
| 环境信号 | 日历事件冲突 | 学习日历服务 | E1、E4 |

### 2.3 诊断置信度

| 等级 | 分值 | 含义 | 处理方式 |
|------|------|------|---------|
| 高置信 | 0.80-1.00 | 多信号交叉验证 | 自动执行推荐策略 |
| 中置信 | 0.50-0.79 | 部分信号支持 | 推荐策略+征求反馈 |
| 低置信 | 0.20-0.49 | 信号不足 | 提供假设，引导自评 |

### 4.2 诊断触发层

负责检测计划执行异常并启动诊断流程。支持三种触发方式：

**定时巡检**：每 2 小时执行一次，扫描所有活跃学习计划，按触发规则表评估是否需要诊断。

```python
class TriggerScheduler:
    """诊断触发调度器"""
    
    def __init__(self, trigger_rules: list[TriggerRule]):
        self.rules = trigger_rules
        self.user_cooldown = UserCooldownCache(ttl_seconds=43200)  # 12h
    
    async def scan_active_plans(self):
        """定时扫描活跃计划"""
        active_plans = await self.plan_repo.get_active_plans_with_metrics()
        
        for plan_metrics in active_plans:
            user_id = plan_metrics.user_id
            
            # 冷却检查
            if self.user_cooldown.is_in_cooldown(user_id):
                continue
            
            # 规则匹配
            matched_rule = self._match_rules(plan_metrics)
            if matched_rule:
                await self._trigger_diagnosis(user_id, plan_metrics, matched_rule)
                self.user_cooldown.set_cooldown(user_id, matched_rule.cooldown_hours)
    
    def _match_rules(self, metrics: PlanMetrics) -> TriggerRule | None:
        """匹配触发规则"""
        matched = []
        for rule in self.rules:
            if not rule.enabled:
                continue
            value = getattr(metrics, rule.trigger_metric, None)
            if value is None:
                continue
            if self._check_threshold(value, rule):
                if metrics.meets_consecutive_count(rule.trigger_metric, rule.consecutive_count):
                    matched.append(rule)
        
        return max(matched, key=lambda r: r.priority) if matched else None
```

**事件驱动**：监听 Kafka 中的学习行为事件，当关键指标越过阈值时立即触发。

```python
class EventDrivenTrigger:
    """事件驱动触发器"""
    
    TRIGGER_EVENTS = {
        "task_overdue": "overdue_task_ratio_increase",
        "task_skipped": "task_skip_threshold_reached",
        "session_ended_short": "avg_session_too_short",
        "accuracy_drop": "consecutive_accuracy_decline",
    }
    
    async def on_event(self, event: LearningEvent):
        if event.event_type not in self.TRIGGER_EVENTS:
            return
        
        user_id = event.user_id
        plan_id = event.plan_id
        
        # 快速预检：是否在冷却期内
        if await self.cooldown_service.is_in_cooldown(user_id, "event_trigger"):
            return
        
        # 增量更新用户指标
        metrics = await self.metrics_service.update_incremental(user_id, event)
        
        # 触发诊断
        await self.diagnosis_orchestrator.start_diagnosis(
            user_id=user_id,
            plan_id=plan_id,
            trigger_reason=self.TRIGGER_EVENTS[event.event_type],
            trigger_event=event
        )
```

        self.environment = EnvironmentSignalCollector(data_services.calendar_service, data_services.device_service)
    
    async def collect(self, user_id: int, plan_id: str, time_window: TimeWindow) -> SignalSnapshot:
        """并行采集所有维度信号"""
        tasks = [
            self.temporal.collect(user_id, plan_id, time_window),
            self.completion.collect(user_id, plan_id, time_window),
            self.quality.collect(user_id, plan_id, time_window),
            self.behavior.collect(user_id, plan_id, time_window),
            self.emotion.collect(user_id, plan_id, time_window),
            self.knowledge.collect(user_id, plan_id, time_window),
            self.environment.collect(user_id, plan_id, time_window),
        ]
        
        results = await asyncio.gather(*tasks, return_exceptions=True)
        
        snapshot = SignalSnapshot()
        for i, result in enumerate(results):
            if isinstance(result, Exception):
                logger.warning(f"Signal collection failed for dimension {i}: {result}")
                snapshot.mark_partial(i)
            else:
                snapshot.merge(result)
        
        return snapshot

class DiagnosisReasoner:
    """诊断推理引擎"""
    
    def __init__(self):
        self.rule_engine = RuleEngine()
        self.bayesian = BayesianInferenceEngine()
        self.heuristic = HeuristicAnalyzer()
    
    async def diagnose(self, signals: SignalSnapshot, profile: StudentProfile) -> list[DiagnosisResult]:
        """执行多策略诊断推理"""
        # 并行执行三种推理
        rule_results, bayes_results, heuristic_results = await asyncio.gather(
            self.rule_engine.evaluate(signals, profile),
            self.bayesian.infer(signals, profile),
            self.heuristic.analyze(signals, profile),
        )
        
        # 融合三种推理结果
        return self._fuse_results(rule_results, bayes_results, heuristic_results)
    
    def _fuse_results(self, rule_res, bayes_res, heur_res) -> list[DiagnosisResult]:
        """融合多策略诊断结果"""
        barrier_scores: dict[str, float] = defaultdict(0.0)
        barrier_evidence: dict[str, list[str]] = defaultdict(list)
        
        # 规则引擎权重 0.4，贝叶斯 0.4，启发式 0.2
        weights = {"rule": 0.4, "bayes": 0.4, "heuristic": 0.2}
        
        for results, weight_key in [
            (rule_res, "rule"), (bayes_res, "bayes"), (heur_res, "heuristic")
        ]:
            for r in results:
                barrier_scores[r.barrier_type] += r.confidence * weights[weight_key]
                barrier_scores[r.barrier_type] = min(1.0, barrier_scores[r.barrier_type])
                barrier_evidence[r.barrier_type].extend(r.evidence)
        
        # 生成诊断结果列表
        results = []
        for barrier_type, score in sorted(barrier_scores.items(), key=lambda x: -x[1]):
            if score < 0.20:
                continue
            
            severity = self._determine_severity(score, barrier_type)
            affected = self._determine_affected(barrier_type, signals)
            strategies = self._match_strategies(barrier_type, severity, profile)
            
            results.append(DiagnosisResult(
                barrier_type=barrier_type,
                confidence=round(score, 2),
                evidence=list(set(barrier_evidence[barrier_type])),
                affected_subjects=affected.subjects,
                affected_tasks=affected.tasks,
                severity=severity,
                recommended_strategies=strategies
            ))
        
        return results

class BayesianInferenceEngine:
    """基于贝叶斯网络的障碍推理"""
    
    def __init__(self):
        # 障碍类型的先验概率（基于历史数据统计）
        self.priors = {
            "A1_TIME_INSUFFICIENT": 0.15,
            "A2_TIME_FRAGMENTED": 0.08,
            "A3_TIME_MISMATCH": 0.12,
            "A4_PROCRASTINATION": 0.18,
            "B1_PREREQUISITE_GAP": 0.20,
            "B2_TASK_OVERLOAD": 0.10,
            "B3_DIFFICULTY_JUMP": 0.08,
            "C1_GOAL_AMBIGUOUS": 0.05,
            "C2_LOW_EFFICACY": 0.07,
            "C3_AVOIDANCE": 0.12,
            "D1_START_DIFFICULTY": 0.09,
            "D3_TASK_SWITCHING": 0.06,
            "E1_SCHOOL_CONFLICT": 0.10,
        }
        
        # 条件概率表 (CPT) - 简化表示
        # P(信号=observed | 障碍=barrier_type)
        self.cpts = self._load_cpts()
    
    async def infer(self, signals: SignalSnapshot, profile: StudentProfile) -> list[DiagnosisResult]:
        """执行贝叶斯推理"""
        posteriors = {}
        
        for barrier_type, prior in self.priors.items():
            # 结合学生画像调整先验
            adjusted_prior = self._adjust_prior(prior, barrier_type, profile)
            
            # 计算似然
            likelihood = self._calc_likelihood(signals, barrier_type)
            
            # 贝叶斯更新
            posterior = adjusted_prior * likelihood
            posteriors[barrier_type] = posterior
        
        # 归一化
        total = sum(posteriors.values())
        if total > 0:
            posteriors = {k: v/total for k, v in posteriors.items()}
        
        # 提取Top-K结果
        results = []
        for barrier_type, prob in sorted(posteriors.items(), key=lambda x: -x[1]):
            if prob < 0.05:
                break
            evidence = self._extract_evidence(signals, barrier_type)
            results.append(DiagnosisResult(
                barrier_type=barrier_type,
                confidence=round(prob, 2),
                evidence=evidence,
            ))
        
        return results
    
    def _adjust_prior(self, prior: float, barrier_type: str, profile: StudentProfile) -> float:
        """根据学生画像调整先验概率"""
        adjusted = prior
        
        # 历史完成率低 → 提高所有障碍的先验
        if profile.historical_completion_rate < 0.5:
            adjusted *= 1.3
        
        # 初中生更常见拖延和时间错配
        if profile.grade_level in [7, 8, 9]:
            if barrier_type in ["A4_PROCRASTINATION", "A3_TIME_MISMATCH"]:
                adjusted *= 1.4
        
        # 高中生更常见前置缺失和任务过载
        if profile.grade_level in [10, 11, 12]:
            if barrier_type in ["B1_PREREQUISITE_GAP", "B2_TASK_OVERLOAD"]:
                adjusted *= 1.3
        
        return min(adjusted, 0.5)  # 上限
```

class StrategyRecommender:
    """障碍消除策略推荐器"""
    
    def __init__(self, strategy_repo: StrategyRepository):
        self.repo = strategy_repo
    
    async def recommend(
        self, 
        diagnosis_results: list[DiagnosisResult], 
        profile: StudentProfile,
        existing_plan: Plan
    ) -> list[StrategyRecommendation]:
        
        all_strategies = []
        
        for result in diagnosis_results:
            # 从策略库匹配策略
            candidates = await self.repo.find_by_barrier_type(
                barrier_type=result.barrier_type,
                grade=profile.grade_level,
                subjects=result.affected_subjects,
            )
            
            # 过滤冷却期内的策略
            candidates = await self._filter_cooldown(candidates, profile.user_id)
            
            # 过滤不适用的策略
            candidates = self._filter_inapplicable(candidates, existing_plan)
            
            # 按优先级+效果排序
            candidates.sort(key=lambda s: (s.priority, s.effectiveness_score), reverse=True)
            
            # 取Top策略
            top = candidates[:2]  # 每个障碍最多推荐2个策略
            
            for strategy in top:
                all_strategies.append(StrategyRecommendation(
                    strategy=strategy,
                    target_barrier=result.barrier_type,
                    target_confidence=result.confidence,
                    auto_apply=strategy.action_type == "auto" and result.confidence >= 0.80,
                ))
        
        # 去重和冲突仲裁
        all_strategies = self._arbitrate(all_strategies)
        
        return all_strategies
    
    def _arbitrate(self, strategies: list[StrategyRecommendation]) -> list[StrategyRecommendation]:
        """策略冲突仲裁"""
        # 规则1：如果同时推荐了"前置知识补救"和"难度降低"，两者可共存
        # 规则2：如果同时推荐了"番茄钟"和"任务拆分"，优先任务拆分（更治本）
        # 规则3：每天最多应用3个auto策略，避免过度干预
        # 规则4："家长通知"策略不与其他策略同日应用
        
        auto_count = sum(1 for s in strategies if s.auto_apply)
        if auto_count > 3:
            # 保留置信度最高的3个auto策略
            auto_strategies = sorted(
                [s for s in strategies if s.auto_apply],
                key=lambda s: s.target_confidence,
                reverse=True
            )[:3]
            suggest_strategies = [s for s in strategies if not s.auto_apply]
            strategies = auto_strategies + suggest_strategies
        
        return strategies
```

class DiagnosisOrchestrator:
    """诊断流程编排器"""
    
    def __init__(self, deps: Dependencies):
        self.trigger = TriggerScheduler(deps.trigger_rules)
        self.collector = SignalCollector(deps.data_services)
        self.reasoner = DiagnosisReasoner()
        self.recommender = StrategyRecommender(deps.strategy_repo)
        self.tracker = EffectTracker(deps.log_repo)
    
    async def start_diagnosis(
        self, user_id: int, plan_id: str, trigger_reason: str, **kwargs
    ) -> DiagnosisRecord:
        """执行完整诊断流程"""
        
        # Step 1: 创建诊断记录
        diagnosis = await self._create_record(user_id, plan_id, trigger_reason, kwargs)
        
        try:
            # Step 2: 加载学生画像和计划快照
            profile, plan = await asyncio.gather(
                self._load_profile(user_id),
                self._load_plan(plan_id)
            )
            
            # Step 3: 采集信号（时间窗口：最近7天）
            time_window = TimeWindow(
                start=datetime.now(timezone.utc) - timedelta(days=7),
                end=datetime.now(timezone.utc)
            )
            signals = await self.collector.collect(user_id, plan_id, time_window)
            
            # Step 4: 诊断推理
            results = await self.reasoner.diagnose(signals, profile)
            
            if not results:
                diagnosis.status = "no_barrier"
                await self._save(diagnosis)
                return diagnosis
            
            # Step 5: 策略推荐
            recommendations = await self.recommender.recommend(results, profile, plan)
            
            # Step 6: 生成总体评估
            overall = self._build_overall_assessment(results)
            
            # Step 7: 保存诊断结果
            diagnosis.signal_snapshot = signals
            diagnosis.diagnosis_results = results
            diagnosis.overall_assessment = overall
            diagnosis.recommended_strategies = recommendations
            diagnosis.status = "diagnosed"
            
            await self._save(diagnosis)
            
            # Step 8: 自动应用高置信策略
            auto_strategies = [r for r in recommendations if r.auto_apply]
            for rec in auto_strategies:
                await self._apply_strategy(diagnosis, rec)
            
            # Step 9: 发送通知
            await self._notify_user(diagnosis, recommendations)
            
            # Step 10: 注册效果追踪任务
            await self._schedule_effect_tracking(diagnosis)
            
            return diagnosis
            
        except Exception as e:
            diagnosis.status = "error"
            diagnosis.error = str(e)
            await self._save(diagnosis)
            logger.error(f"Diagnosis failed for user {user_id}: {e}", exc_info=True)
            raise
    
    async def _apply_strategy(self, diagnosis: DiagnosisRecord, rec: StrategyRecommendation):
        """自动应用策略"""
        try:
            strategy = rec.strategy
            
            if strategy.action_payload.get("pauseOriginalPlan"):
                await self.plan_service.pause_plan(diagnosis.plan_id, 
                                                     days=strategy.action_payload.get("pauseDurationDays", 2))
            
            if strategy.strategy_category == "content_adjust":
                await self._apply_content_adjustment(diagnosis, strategy)
            elif strategy.strategy_category == "plan_adjust":
                await self._apply_plan_adjustment(diagnosis, strategy)
            elif strategy.strategy_category == "notification":
                await self._send_notification(diagnosis, strategy)
            elif strategy.strategy_category == "feature_toggle":
                await self._toggle_feature(diagnosis, strategy)
            
            # 记录策略应用
            await self.tracker.log_strategy_applied(diagnosis, strategy)
            
        except Exception as e:
            logger.error(f"Strategy application failed: {e}", exc_info=True)
    
    async def _apply_content_adjustment(self, diagnosis: DiagnosisRecord, strategy):
        """执行内容调整类策略"""
        payload = strategy.action_payload
        
        if "prereview" in strategy.strategy_id:
            # 前置知识补救
            barrier = next(r for r in diagnosis.diagnosis_results 
                         if r.barrier_type == "B1_PREREQUISITE_GAP")
            
            low_mastery_kps = barrier.details.get("lowMasteryPoints", [])
            
            # 生成微学习任务
            micro_tasks = await self.task_generator.generate_prereview_tasks(
                user_id=diagnosis.user_id,
                knowledge_points=low_mastery_kps,
                max_items=payload.get("maxPrereviewItems", 5),
                duration_per_item=payload.get("itemDuration", "5-10min"),
            )
            
            # 插入到计划前部
            await self.plan_service.insert_tasks_before(
                plan_id=diagnosis.plan_id,
                tasks=micro_tasks,
                pause_original=payload.get("pauseOriginalPlan", True)
            )
