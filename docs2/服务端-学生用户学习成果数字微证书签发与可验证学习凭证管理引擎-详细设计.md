# 服务端-学生用户学习成果数字微证书签发与可验证学习凭证管理引擎-详细设计

## 1. 概述

### 1.1 功能定位

本模块是 PrimeTop 教育平台**学习成果资产化**的核心服务，负责将学生在平台上的学习成就转化为**可验证的数字微证书（Verifiable Micro-Credentials）**，基于 W3C Verifiable Credentials 数据标准实现凭证签发、存储、验证和撤销的完整生命周期管理，使学生能够将学习成果以可信、可验证、可携带的方式分享给学校、家长、教育机构等第三方。

与已有模块的关系：

| 已有模块 | 关系说明 |
| --- | --- |
| `学生成就与学习里程碑追踪引擎` | **上游输入**：成就解锁事件触发微证书签发评估 |
| `学习打卡记录与成就解锁计算引擎` | **上游输入**：连续学习打卡等行为成就作为证书签发来源 |
| `知识追踪模型引擎与学生能力动态评估服务` | **上游输入**：知识点掌握度数据作为能力认证的数据依据 |
| `学生电子成长档案与综合素质评价服务` | **互补关系**：成长档案是平台内综合视图，微证书是可外发的可验证凭证 |
| `学习数据导出与账户注销服务` | **下游消费**：数据导出时包含微证书包，账户注销时处理凭证状态 |
| `教育数据标准化与跨平台学习数据交换引擎` | **协议对齐**：微证书遵循统一教育数据交换标准 |

### 1.2 设计目标

1. **成果资产化**：将平台内学习行为和成就转化为具有外部可信价值的标准化数字凭证。
2. **可验证性**：第三方无需访问平台数据库即可独立验证凭证的真实性和有效性。
3. **选择性披露**：学生/家长可精确控制向谁、披露哪些凭证，保护隐私。
4. **跨平台互操作**：遵循 W3C VC / Open Badges 3.0 标准，支持教育生态系统内流通。
5. **防篡改与防伪造**：基于公钥签名体系确保证书不可伪造、不可篡改。
6. **生命周期管理**：支持签发、更新、暂停、撤销、过期续展等完整状态流转。

### 1.3 适用范围

- **凭证持有者**：平台全体学生用户（含家长代为管理的未成年用户）。
- **凭证类型**：知识点掌握认证、技能等级认证、课程完成认证、学习习惯认证、综合素养认证、竞赛/挑战成就认证。
- **验证方**：学校教务系统、校外教育机构、家长、其他 PrimeTop 平台用户。
- **签发主体**：PrimeTop 平台作为 Issuer（发行方），未来支持合作学校/机构作为联合发行方。

## 2. 核心概念与领域模型

### 2.1 领域模型概览

```
CredentialIssuer（凭证发行方）
  └── IssuerKeyPair（签名密钥对）

MicroCredential（微证书模板）
  ├── CredentialTemplateField（模板字段定义）
  ├── CredentialAchievementRule（达成规则）
  └── CredentialVisualDesign（视觉设计配置）

IssuedCredential（已签发凭证）
  ├── CredentialSubject（凭证主体/学生信息）
  ├── CredentialEvidence（证据链）
  ├── CredentialSignatureBlock（签名信息）
  └── CredentialStatusRecord（状态记录）

CredentialShareLink（分享链接）
  └── ShareAccessLog（访问日志）

CredentialVerificationLog（验证日志）

CredentialRevocationEntry（撤销列表条目）
```

### 2.2 核心概念定义

| 概念 | 定义 |
| --- | --- |
| **微证书 (Micro-Credential)** | 对某一具体学习成果的可验证数字认证，如"人教版八年级数学·一次函数·掌握级" |
| **凭证模板 (Credential Template)** | 定义某类证书的颁发标准、字段结构、达成条件和视觉设计 |
| **达成规则 (Achievement Rule)** | 自动判断学生是否符合证书签发条件的业务规则表达式 |
| **证据链 (Evidence Chain)** | 支撑证书签发的学习行为数据快照，如答题记录、掌握度分数、学习时长等 |
| **可验证凭证 (VC)** | 遵循 W3C Verifiable Credentials Data Model 1.1 规范的数据结构 |
| **撤销列表 (Revocation List)** | 已撤销凭证的公开列表，验证方可查询以确认凭证有效性 |
| **分享链接 (Share Link)** | 生成的限时、限次公开访问链接，允许第三方查看和验证凭证 |

### 2.3 凭证类型体系

| 类型ID | 类型名称 | 说明 | 达成条件示例 | 有效期 |
| --- | --- | --- | --- | --- |
| `KNOWLEDGE_MASTERY` | 知识点掌握认证 | 证明对特定知识点的掌握达到指定水平 | 知识追踪掌握度 ≥ 0.85 且有效答题 ≥ 20 题 | 2 年 |
| `SKILL_CERTIFICATION` | 技能等级认证 | 证明某项学习技能达到指定等级 | 计算能力/阅读理解/逻辑推理等维度评分达阈值 | 2 年 |
| `COURSE_COMPLETION` | 课程完成认证 | 完成某教材章节/课程包的全部学习内容 | 章节完成度 ≥ 95% 且综合测评通过 | 永久 |
| `STUDY_HABIT` | 学习习惯认证 | 表现出优秀的学习习惯和坚持力 | 连续打卡 30/60/100 天、日均学习 ≥ 45min | 1 年 |
| `COMPREHENSIVE_LITERACY` | 综合素养认证 | 学期末综合素养评估达标 | 多维度综合评分 ≥ 阈值，含学业+习惯+进步幅度 | 1 学期 |
| `CHALLENGE_ACHIEVEMENT` | 挑战赛/竞赛成就 | 在平台挑战赛或模拟考中取得优异成绩 | 排名前 10% 或分数 ≥ 设定线 | 永久 |
| `SUBJECT_EXCELLENCE` | 单科卓越认证 | 单科学期综合表现卓越 | 单科掌握度均值 ≥ 0.90 + 错题纠正率 ≥ 95% | 1 学年 |

## 3. 数据结构设计

### 3.1 核心表设计

#### 3.1.1 `credential_issuer` — 凭证发行方表

```sql
CREATE TABLE `credential_issuer` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `issuer_id` VARCHAR(64) NOT NULL UNIQUE COMMENT '发行方唯一标识，如 did:primetop:issuer:001',
    `issuer_name` VARCHAR(128) NOT NULL COMMENT '发行方名称',
    `issuer_type` VARCHAR(32) NOT NULL DEFAULT 'PLATFORM' COMMENT 'PLATFORM/COOPERATIVE_SCHOOL/PARTNER_INSTITUTION',
    `description` TEXT COMMENT '发行方简介',
    `verification_public_key` TEXT NOT NULL COMMENT '当前有效的公钥(PEM格式)，用于签名验证',
    `public_key_id` VARCHAR(256) NOT NULL COMMENT '公钥标识，对应 VC proof.verificationMethod',
    `key_algorithm` VARCHAR(32) NOT NULL DEFAULT 'Ed25519' COMMENT '签名算法',
    `key_rotated_at` DATETIME COMMENT '密钥最后轮换时间',
    `status` VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/SUSPENDED/REVOKED',
    `did_document_url` VARCHAR(512) COMMENT 'DID文档URL（可选，用于去中心化身份）',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX `idx_issuer_type_status` (`issuer_type`, `status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='凭证发行方';
```

#### 3.1.2 `credential_issuer_key_history` — 密钥历史表

```sql
CREATE TABLE `credential_issuer_key_history` (

    `public_key_id` VARCHAR(256) NOT NULL,

```

```json

  "version": "1.0",

        "min_count": 20,

    {
      "type": "STUDY_DURATION",

```

## 4. API 接口设计

### 4.1 接口总览

| # | 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 查询凭证模板列表 | GET | `/api/v1/credential-templates` | 按学段/学科/类型筛选可用模板 |
| 2 | 获取模板详情 | GET | `/api/v1/credential-templates/{templateCode}` | 含达成规则和字段定义 |

### 6.2 状态转换规则

| 当前状态 | 目标状态 | 触发条件 | 操作方 |
| --- | --- | --- | --- |
| `ACTIVE` | `EXPIRED` | 到达 expiresAt 时间 | 系统（定时任务） |
| `ACTIVE` | `SUSPENDED` | 发现学术不端 / 异常使用 | 管理后台 |
| `ACTIVE` | `REVOKED` | 严重违规 / 数据错误 / 用户申请注销 | 管理后台/系统 |

| `SUSPENDED` | `REVOKED` | 调查后确认问题 | 管理后台 |
| `EXPIRED` | `ACTIVE`(新凭证) | 重新评估达标，签发新凭证 | 系统（用户申请触发） |

## 7. 关键代码示例

### 7.1 凭证签发服务（Java + Spring Boot）

```java
/**
 * 微证书签发服务
 */
@Service
@Slf4j
public class CredentialIssuanceService {

    @Autowired
    private MicroCredentialTemplateRepository templateRepository;
    @Autowired
    private IssuedCredentialRepository credentialRepository;
    @Autowired
    private CredentialEvidenceCollector evidenceCollector;
    @Autowired
    private CredentialSigner credentialSigner;
    @Autowired
    private RevocationListService revocationListService;
    @Autowired
    private NotificationService notificationService;

    /**
     * 评估并签发凭证（事件驱动触发）
     */
    @Transactional
    public IssuanceResult evaluateAndIssue(Long userId, String templateCode) {
        // 1. 加载模板
        MicroCredentialTemplate template = templateRepository
            .findByCodeAndStatus(templateCode, TemplateStatus.ACTIVE)
            .orElseThrow(() -> new TemplateNotFoundException(templateCode));

        // 2. 检查是否已持有有效凭证
        Optional<IssuedCredential> existing = credentialRepository
            .findActiveByUserAndTemplate(userId, template.getId());
        if (existing.isPresent() && !isUpgradeable(existing.get(), template)) {
            return IssuanceResult.alreadyHeld(existing.get().getCredentialId());
        }

        // 3. 评估达成规则
        AchievementEvaluation evaluation = evaluateAchievementRule(userId, template);
        if (!evaluation.isPassed()) {
            return IssuanceResult.notQualified(evaluation);
        }

        // 4. 收集证据链
        List<CredentialEvidence> evidences = evidenceCollector.collect(
            userId, template, evaluation.getEvaluationContext()
        );
        if (evidences.size() < template.getMinEvidenceCount()) {
            log.warn("证据不足: userId={}, template={}, evidenceCount={}",
                userId, templateCode, evidences.size());
            return IssuanceResult.insufficientEvidence(evidences.size());
        }

        // 5. 构建凭证主体
        CredentialSubject subject = buildCredentialSubject(userId, template, evaluation);
        String credentialId = generateCredentialId();

        // 6. 组装 VC 文档
        VerifiableCredentialDocument vcDoc = VerifiableCredentialDocument.builder()
            .context(buildContext())
            .id(credentialId)
            .type(buildTypes(template))
            .issuer(buildIssuer(template.getIssuerId()))
            .issuanceDate(Instant.now())
            .expirationDate(calculateExpirationDate(template))
            .credentialSubject(subject)
            .evidence(buildEvidenceList(evidences))
            .credentialStatus(buildRevocationStatus(credentialId))
            .build();

        // 7. 签名
        CredentialSignature signature = credentialSigner.sign(vcDoc);
        vcDoc.setProof(signature.toProof());

        // 8. 持久化
        IssuedCredential issued = persistCredential(
            credentialId, userId, template, vcDoc, evaluation, evidences, signature
        );

        // 9. 更新撤销列表索引
        revocationListService.allocateSlot(credentialId, template.getIssuerId());

        // 10. 发送通知
        notificationService.sendCredentialIssuedNotification(userId, issued);

        return IssuanceResult.success(issued);
    }

    /**
     * 执行达成规则DSL评估
     */
    private AchievementEvaluation evaluateAchievementRule(
            Long userId, MicroCredentialTemplate template) {
        AchievementRule rule = AchievementRuleParser.parse(
            template.getAchievementRuleJson()
        );

        AchievementEvaluation.Accumulator accumulator = new AchievementEvaluation.Accumulator();

        for (AchievementCondition condition : rule.getConditions()) {
            ConditionResult result = switch (condition.getType()) {
                case MASTERY_SCORE -> evaluateMasteryCondition(userId, condition);
                case ANSWER_COUNT -> evaluateAnswerCountCondition(userId, condition);
                case STUDY_DURATION -> evaluateStudyDurationCondition(userId, condition);
                case STREAK_DAYS -> evaluateStreakCondition(userId, condition);
                case ASSESSMENT_SCORE -> evaluateAssessmentCondition(userId, condition);
                case COMPREHENSIVE_SCORE -> evaluateComprehensiveCondition(userId, condition);
                default -> throw new UnsupportedConditionTypeException(condition.getType());
            };
            accumulator.addCondition(result);
        }

        // 检查前置证书
        if (template.getPrerequisiteTemplateCodes() != null) {
            for (String prereqCode : template.getPrerequisiteTemplateCodes()) {
                boolean hasPrereq = credentialRepository
                    .existsActiveByUserAndTemplateCode(userId, prereqCode);
                accumulator.addPrerequisite(prereqCode, hasPrereq);
            }
        }

        // 根据逻辑运算符判断最终结果
        boolean passed = switch (rule.getLogic()) {
            case AND -> accumulator.allPassed();
            case OR -> accumulator.anyPassed();
            case WEIGHTED -> accumulator.weightedPassed(rule.getPassThreshold());
        };

        return AchievementEvaluation.builder()
            .passed(passed)
            .conditionResults(accumulator.getResults())
            .evaluationContext(accumulator.getContext())
            .evaluatedAt(Instant.now())
            .build();
    }

    private ConditionResult evaluateMasteryCondition(
            Long userId, AchievementCondition condition) {
        List<String> kpCodes = condition.getParam("knowledge_point_codes");
        double minMastery = condition.getParam("min_mastery");
        int windowDays = condition.getParam("measurement_window_days", 90);

        Map<String, Double> masteryScores = knowledgeTrackingService
            .getBatchMastery(userId, kpCodes, windowDays);

        double avgMastery = masteryScores.values().stream()
            .mapToDouble(Double::doubleValue)
            .average()
            .orElse(0.0);

        return ConditionResult.builder()
            .type(ConditionType.MASTERY_SCORE)
            .passed(avgMastery >= minMastery)
            .current(avgMastery)
            .required(minMastery)
            .detail(masteryScores)
            .build();
    }

    private String generateCredentialId() {
```

### 7.2 凭证签名与验证（密码学层）

```java
/**
 * 基于 Ed25519 的凭证签名器
 */
@Component
public class CredentialSigner {

    private final IssuerKeyManager keyManager;

    /**
     * 对 VC 文档进行 Ed25519 签名
     */
    public CredentialSignature sign(VerifiableCredentialDocument vcDoc) {
        // 1. 获取发行方当前密钥对
        IssuerKeyPair keyPair = keyManager.getCurrentKeyPair(vcDoc.getIssuerId());

        // 2. 构建待签名内容（规范化后的VC文档，不含proof）
        String canonicalDoc = JsonCanonicalizer.canonicalize(vcDoc.withoutProof());

        // 3. Ed25519 签名
        byte[] signatureBytes = Ed25519.sign(
            keyPair.getPrivateKey(),
            canonicalDoc.getBytes(StandardCharsets.UTF_8)
        );

        // 4. 构建 proof 对象
        Proof proof = Proof.builder()
            .type("Ed25519Signature2018")
            .created(Instant.now())
            .verificationMethod(keyPair.getPublicKeyId())
            .proofPurpose("assertionMethod")
            .proofValue(Base58.encode(signatureBytes))
            .build();

        return new CredentialSignature(proof, signatureBytes, keyPair);
    }

    /**
     * 验证 VC 文档的签名（供验证API使用）
     */
    public SignatureVerificationResult verify(VerifiableCredentialDocument vcDoc) {
        try {
            // 1. 提取 proof
            Proof proof = vcDoc.getProof();
            if (proof == null) {
                return SignatureVerificationResult.noProof();
            }

            // 2. 获取发行方公钥
            Optional<IssuerKeyPair> keyPairOpt = keyManager.findByPublicKeyId(
                proof.getVerificationMethod()
            );
            if (keyPairOpt.isEmpty()) {
                return SignatureVerificationResult.unknownIssuer(proof.getVerificationMethod());
            }

            // 3. 规范化文档（去掉proof字段后规范化）
            String canonicalDoc = JsonCanonicalizer.canonicalize(vcDoc.withoutProof());

            // 4. 验证签名
            byte[] signature = Base58.decode(proof.getProofValue());
            boolean valid = Ed25519.verify(
                keyPairOpt.get().getPublicKey(),
                canonicalDoc.getBytes(StandardCharsets.UTF_8),
                signature
            );

            return SignatureVerificationResult.builder()
                .valid(valid)
                .verificationMethod(proof.getVerificationMethod())
                .algorithm(proof.getType())
                .verifiedAt(Instant.now())
                .build();

        } catch (Exception e) {
            return SignatureVerificationResult.error(e.getMessage());
        }
    }
}
```

### 7.3 凭证验证编排服务

```java
/**
 * 凭证综合验证编排服务
 */
@Service
@Slf4j
public class CredentialVerificationOrchestrator {

    @Autowired private CredentialSigner credentialSigner;
    @Autowired private RevocationListService revocationListService;
    @Autowired private CredentialIssuerService issuerService;
    @Autowired private IssuedCredentialRepository credentialRepository;
    @Autowired private CredentialVerificationLogRepository verificationLogRepo;

    /**
     * 综合验证凭证（多步检查管线）
     */
    public VerificationResult verify(VerifiableCredentialDocument vcDoc,
                                      VerificationOptions options) {
        List<VerificationCheck> checks = new ArrayList<>();

        // Step 1: 格式校验
        checks.add(validateFormat(vcDoc));

        // Step 2: 发行方状态检查
        if (options.isCheckIssuerStatus()) {
            checks.add(checkIssuerStatus(vcDoc.getIssuerId()));
        }

        // Step 3: 签名验证
        if (options.isCheckSignature()) {
            checks.add(verifySignature(vcDoc));
        }

        // Step 4: 有效期检查
        if (options.isCheckExpiry()) {
            checks.add(checkExpiry(vcDoc));
        }

        // Step 5: 撤销状态检查
        if (options.isCheckRevocation()) {
            checks.add(checkRevocation(vcDoc));
        }

        // 综合判定
        boolean allPassed = checks.stream().allMatch(c -> c.getResult() == CheckResult.PASS);
        String overallResult = allPassed ? "VALID" : "INVALID";

        // 记录验证日志
        verificationLogRepo.save(buildLog(vcDoc.getId(), overallResult, checks));

        return VerificationResult.builder()
            .credentialId(vcDoc.getId())
            .overallResult(overallResult)
            .checks(checks)
            .verifiedAt(Instant.now())
            .build();
    }

    private VerificationCheck checkRevocation(VerifiableCredentialDocument vcDoc) {
        try {
            CredentialStatus status = vcDoc.getCredentialStatus();
            if (status == null) {
                return VerificationCheck.pass("REVOCATION_STATUS", "无撤销状态声明，视为有效");
            }

            boolean isRevoked = revocationListService.checkStatus(
                status.getRevocationListUrl(),
                status.getRevocationListIndex()
            );

            if (isRevoked) {
                return VerificationCheck.fail("REVOCATION_STATUS", "凭证已被撤销");
            }
            return VerificationCheck.pass("REVOCATION_STATUS", "凭证未被撤销");

        } catch (Exception e) {
            log.error("撤销状态检查失败: credId={}", vcDoc.getId(), e);
            return VerificationCheck.warn("REVOCATION_STATUS",
                "撤销列表暂时不可访问: " + e.getMessage());
        }
    }
}
```

### 7.5 达成规则 DSL 解析器

```java
/**
 * 达成规则 DSL 解析与执行引擎
 */
public class AchievementRuleParser {

    private static final ObjectMapper objectMapper = new ObjectMapper();

    /**
     * 解析规则 JSON 为可执行对象
     */
    public static AchievementRule parse(String ruleJson) {
        try {
            JsonNode root = objectMapper.readTree(ruleJson);

            String version = root.path("version").asText("1.0");
            LogicOperator logic = LogicOperator.valueOf(
                root.path("logic").asText("AND")
            );

            List<AchievementCondition> conditions = new ArrayList<>();
            for (JsonNode condNode : root.path("conditions")) {
                conditions.add(parseCondition(condNode));
            }

            List<String> prerequisites = new ArrayList<>();
            if (root.has("prerequisites")) {
                root.path("prerequisites").forEach(n -> prerequisites.add(n.asText()));
            }

            double passThreshold = root.path("pass_threshold").asDouble(1.0);

            return AchievementRule.builder()
                .version(version)
                .logic(logic)
                .conditions(conditions)
                .prerequisites(prerequisites)
                .passThreshold(passThreshold)
                .build();

        } catch (Exception e) {
            throw new RuleParseException("达成规则解析失败", e);
        }
    }

    private static AchievementCondition parseCondition(JsonNode node) {
        ConditionType type = ConditionType.valueOf(node.path("type").asText());
        Map<String, Object> params = objectMapper.convertValue(
            node.path("params"), new TypeReference<Map<String, Object>>() {}
        );
        return new AchievementCondition(type, params);
    }
}
```

```java
/**
 * 发行方密钥管理器

@Component
public class IssuerKeyManager {

    private static final Duration KEY_MAX_AGE = Duration.ofDays(365);
    private static final Duration KEY_OVERLAP = Duration.ofDays(30);

    /**
     * 轮换发行方签名密钥
     * 轮换后旧密钥保留30天用于验证历史凭证签名
     */
    @Transactional
    public void rotateKey(String issuerId) {
        IssuerKeyPair current = getCurrentKeyPair(issuerId);

        // 1. 生成新密钥对
        KeyPair newKeyPair = Ed25519.generateKeyPair();
        String newPublicKeyId = issuerId + "#key-" + YearMonth.now().format("yyyyMM");
        String newPublicKeyBase58 = Base58.encode(newKeyPair.getPublic().encoded());

        // 2. 旧密钥设为过期（保留30天overlap期）
        keyHistoryRepository.expireKey(current.getPublicKeyId(),
            Instant.now().plus(KEY_OVERLAP));

        // 3. 新密钥设为当前
        issuerRepository.updatePublicKey(issuerId, newPublicKeyBase58, newPublicKeyId);

        // 4. 异步重新签名近3个月内签发的凭证（可选，提升验证体验）
        asyncReSignRecentCredentials(issuerId, current, newKeyPair);

        log.info("密钥轮换完成: issuer={}, newKeyId={}", issuerId, newPublicKeyId);
    }
}
```

### 8.3 安全措施清单

| 安全要求 | 措施 |
| --- | --- |
| **私钥保护** | 存储使用 KMS 加密，运行时仅在内存中解密使用，进程退出即清除 |
| **签名操作隔离** | 签名服务独立部署，仅暴露内部 gRPC 接口，不对外暴露 |
| **密钥轮换** | 每年自动轮换，支持紧急轮换（私钥泄露场景） |

| **验证日志隐私** | 验证日志不记录 VC 完整内容，仅记录 ID 和结果 |

```java
/**
 * 撤销列表使用 Redis Bitmap 存储实现 O(1) 查询
 *
 * 每个发行方维护一个 Bitmap，每一位对应一个凭证的 revocationListIndex
 * 0 = 有效, 1 = 已撤销
 */
@Component
public class RevocationListCache {

    private static final String BITMAP_KEY_PREFIX = "cred:revocation:";

    @Autowired
    private RedisTemplate<String, byte[]> redisTemplate;

    /**
     * 检查凭证是否被撤销
     * 时间复杂度：O(1)
     */
    public boolean isRevoked(String issuerId, int listIndex) {
        String key = BITMAP_KEY_PREFIX + issuerId;
        Boolean bit = redisTemplate.opsForValue().getBit(key, listIndex);
        return Boolean.TRUE.equals(bit);
    }

    /**
     * 标记凭证为已撤销
     */
    public void markRevoked(String issuerId, int listIndex) {
        String key = BITMAP_KEY_PREFIX + issuerId;
        redisTemplate.opsForValue().setBit(key, listIndex, true);
    }

    /**
     * 批量加载撤销列表到Bitmap（服务启动时）
     */
    @PostLoad
    public void warmupRevocationBitmaps() {
        List<String> issuerIds = issuerService.getAllIssuerIds();
        for (String issuerId : issuerIds) {
            List<Integer> revokedIndices = revocationListRepo.findAllIndices(issuerId);
            String key = BITMAP_KEY_PREFIX + issuerId;
            redisTemplate.execute((RedisCallback<Void>) connection -> {
                for (int idx : revokedIndices) {
                    connection.stringCommands().setBit(key.getBytes(), idx, true);
                }
                return null;
            });
        }
    }
}
```
