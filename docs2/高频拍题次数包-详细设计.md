# 高频拍题次数包 - 详细设计

> 版本：v1.0 · 日期：2026-08-31 · 状态：初稿
> 定位：将总体设计 §11.2「增值服务」中明确提及的「高频拍题次数包」拆分为可编码实现的独立商品子系统，覆盖商品配置、购买开通、额度入账、消费扣减、过期清理、售后退款全链路。

## 1. 概述

### 1.1 范围

本文档详细设计「高频拍题次数包」商品，属于 PrimeTop **增值服务（Value-Added Service / ADDON）** 产品线中的「次数包」类目。拍题次数包与会员每日免费额度解耦，用户可一次性购买额外拍题（含拍照识题 + 拍照解题）次数，用完即止；未使用次数支持按退款政策退回。

### 1.2 产品定位

| 维度 | 会员每日额度 | 拍题次数包 |
|------|-------------|-----------|
| 获取方式 | 会员权益按日重置 | 一次性付费购买 |
| 使用优先级 | 先扣每日免费额度 | 每日额度耗尽后扣次数包 |
| 有效期 | 自然日重置，不结转 | 购买后 N 天有效，可配置 |
| 可叠加 | 不可叠加（按最高等级） | 可重复购买叠加 |
| 退款 | 不可退 | 未使用部分可按比例退 |
| 目标用户 | 会员用户日常需求 | 非会员临时冲高、会员超量补充 |

## 3. 数据模型设计

### 3.1 商品配置表 `addon_product`

次数包作为 ADDON 商品的一种，复用平台级商品表（字段节选）。

```sql
CREATE TABLE addon_product (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    product_id          VARCHAR(32) NOT NULL COMMENT '商品唯一ID，如 PQC-50-90',
    product_code        VARCHAR(32) NOT NULL COMMENT '业务编码',
    name                VARCHAR(128) NOT NULL COMMENT '商品名称',
    type                VARCHAR(32) NOT NULL COMMENT 'COUNT_PACK / TIME_PACK / CONTENT_PACK',
    subtype             VARCHAR(32) NOT NULL DEFAULT 'PHOTO_QUESTION' COMMENT '次数包子类型',
    status              VARCHAR(32) NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT/ONLINE/OFFLINE',
    total_quota         INT NOT NULL COMMENT '总次数',
    validity_days       INT NOT NULL DEFAULT 90 COMMENT '有效期天数，0=永久',
    unit_price_cents    INT NOT NULL COMMENT '单价（分）',
    currency            VARCHAR(8) NOT NULL DEFAULT 'CNY',
    stackable           TINYINT NOT NULL DEFAULT 1 COMMENT '是否允许叠加购买',
    daily_purchase_limit INT DEFAULT NULL COMMENT '单用户每日购买上限',
    total_purchase_limit INT DEFAULT NULL COMMENT '单用户累计购买上限',
    applicable_platforms JSON COMMENT '适用平台 ["android","ios"]',
    min_age             INT DEFAULT 3 COMMENT '最低适用年龄',
    max_age             INT DEFAULT 18 COMMENT '最高适用年龄',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_product_id (product_id),
    INDEX idx_type_status (type, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='增值服务商品表';
```

### 3.2 用户权益实例表 `user_entitlement`

每张购买的次数包对应一条权益实例，记录总次数、已用次数、过期时间。

```sql
CREATE TABLE user_entitlement (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    entitlement_id      VARCHAR(32) NOT NULL COMMENT '权益实例ID，全局唯一',
    user_id             BIGINT NOT NULL COMMENT '用户ID',
    product_id          VARCHAR(32) NOT NULL COMMENT '商品ID',
    order_id            VARCHAR(32) NOT NULL COMMENT '来源订单ID',
    total_quota         INT NOT NULL COMMENT '总次数',
    used_quota          INT NOT NULL DEFAULT 0 COMMENT '已用次数',
    available_quota     INT GENERATED ALWAYS AS (total_quota - used_quota) STORED COMMENT '可用次数',
    status              VARCHAR(32) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/EXPIRED/REFUNDED/REVOKED',
    expire_at           DATETIME NOT NULL COMMENT '过期时间',
    refund_amount_cents INT DEFAULT NULL COMMENT '已退款金额（分）',
    refund_quota        INT DEFAULT NULL COMMENT '已退回次数',
    activated_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '生效时间',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_entitlement_id (entitlement_id),
    UNIQUE KEY uk_order_id (order_id),
    INDEX idx_user_status_expire (user_id, status, expire_at),
    INDEX idx_expire_status (expire_at, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户增值服务权益实例';
```

### 3.5 Redis 键设计

| 键名 | 类型 | 说明 |
|------|------|------|
| `pqcp:available:{user_id}` | Hash | 用户可用次数包额度汇总，`total/used/expired` |
| `pqcp:ent:{entitlement_id}` | Hash | 单权益实例缓存，字段 `total/used/expire_at/status` |
| `pqcp:consume_lock:{biz_id}` | String | 消费幂等锁，TTL 24h |
| `pqcp:daily_purchase:{user_id}:{product_id}:{date}` | String | 单日购买计数，TTL 48h |
| `pqcp:stack:{user_id}:{product_id}` | Set | 用户该商品下有效权益ID列表，用于扣减时按 FIFO 遍历 |

## 4. 核心流程设计

### 4.1 购买开通流程

```
用户下单
  │
  ▼
订单系统创建 ADDON 订单（product_id=PQCP-50-90）
  │
  ▼
支付完成回调
  │
  ▼
订单服务调用 EntitlementService.activate(order_id)
  │
  ├─ 幂等校验（order_id 已存在 entitlement 则返回已有）
  ├─ 创建 user_entitlement 记录
  ├─ 计算 expire_at = now + validity_days
  ├─ 写入 Redis 缓存与 pqcp:stack
  ├─ 发布 entitlement.activated 事件
  └─ 返回 entitlement_id
  │
  ▼
客户端收到权益到账，更新「我的增值服务」
```

### 4.2 消费扣减流程

拍照搜题消费时，额度扣减顺序：**每日额度 > 次数包 > 引导购买**。

```
拍照搜题请求
  │
  ▼
额度管控系统 preCheck(user_id, feature=photo_solve)
  │
  ├─ 查询每日额度剩余 daily_left
  ├─ 若 daily_left >= 1：直接扣除每日额度，结束
  │
  └─ 若 daily_left == 0：调用次数包消费服务
       │
       ▼
    EntitlementService.consume(user_id, cost=1, biz_id, biz_type, client_request_id)
       │
       ├─ 幂等：client_request_id 或 biz_id 已存在 log 则直接返回
       ├─ 从 pqcp:stack 按 expire_at 升序取有效权益
       ├─ 对首个权益加分布式锁（entitlement_id）
       ├─ DB 乐观锁 CAS 扣减 used_quota
       ├─ 写入 consumption_log
       ├─ 更新 Redis 缓存
       ├─ 发布 entitlement.consumed 事件
       └─ 返回扣减结果（来源 entitlement_id, 剩余次数）
  │
  ▼
若全部次数包可用额度 == 0：返回 59021 额度耗尽，客户端引导购买
```

### 4.3 过期清理流程

每天 04:00 运行定时任务：

```
扫描 expire_at < now AND status = ACTIVE
  │
  ▼
逐批更新 status = EXPIRED
  │
  ▼
发布 entitlement.expired 事件（用于报表、提醒）
  │
  ▼
清理 Redis pqcp:stack 中已过期权益ID
```

### 4.4 售后退款流程

```
用户申请退款（未使用或部分使用）
  │
  ▼
售后系统校验：购买 7 天内、未被处罚、未成年人需家长门确认
  │
  ▼
计算可退次数 refund_quota = available_quota
计算退款金额 refund_amount = unit_price_cents * refund_quota / total_quota（向下取整到分）
  │
  ▼
调用 EntitlementService.revoke(entitlement_id, refund_quota)
  │
  ├─ 幂等校验 refund_id
  ├─ CAS 将 status 由 ACTIVE → REFUNDED
  ├─ 写入 refund_record
  ├─ 从 Redis pqcp:stack 移除
  ├─ 发布 entitlement.revoked 事件
  └─ 通知退款服务执行原路退款
  │
  ▼
退款完成
```

## 6. 关键代码示例

### 6.1 权益激活服务（Kotlin / Java 风格伪代码）

```kotlin
@Service
class PhotoQuestionPackEntitlementService(
    private val entitlementRepo: EntitlementRepository,
    private val productRepo: AddonProductRepository,
    private val redis: StringRedisTemplate,
    private val eventPublisher: EventPublisher
) {
    @Transactional
    fun activate(orderId: String, userId: Long, productId: String): Entitlement {
        // 幂等：按 order_id 唯一索引保证
        entitlementRepo.findByOrderId(orderId)?.let { return it }

        val product = productRepo.findByProductId(productId)
            ?: throw BizException(59001, "商品不存在")

        if (product.subtype != "PHOTO_QUESTION") {
            throw BizException(59002, "非拍题次数包商品")
        }

        val entitlementId = generateEntitlementId()
        val expireAt = calculateExpireAt(product.validityDays)

        val entitlement = Entitlement(
            entitlementId = entitlementId,
            userId = userId,
            productId = productId,
            orderId = orderId,
            totalQuota = product.totalQuota,
            usedQuota = 0,
            status = ACTIVE,
            expireAt = expireAt
        )

        entitlementRepo.save(entitlement)
        refreshRedisCache(entitlement)
        eventPublisher.publish(EntitlementActivatedEvent(entitlement))
        return entitlement
    }
}
```

### 6.2 消费扣减服务

```kotlin
@Service
class PhotoQuestionPackConsumptionService(
    private val entitlementRepo: EntitlementRepository,
    private val consumptionLogRepo: ConsumptionLogRepository,
    private val redis: StringRedisTemplate,
    private val lockService: DistributedLockService
) {
    @Transactional
    fun consume(userId: Long, cost: Int, bizType: String, bizId: String,
                  clientRequestId: String): ConsumptionResult {
        // 幂等 1：client_request_id 唯一索引
        consumptionLogRepo.findByClientRequestId(clientRequestId)?.let {
            return ConsumptionResult(success = true, entitlementId = it.entitlementId,
                                     consumed = it.cost, remaining = it.afterQuota)
        }

        // 幂等 2：业务单号唯一索引
        consumptionLogRepo.findByBizIdAndBizType(bizId, bizType)?.let {
            return ConsumptionResult(success = true, entitlementId = it.entitlementId,
                                     consumed = it.cost, remaining = it.afterQuota)
        }

        val activeEntitlements = entitlementRepo
            .findActiveByUserIdOrderByExpireAtAsc(userId)
            .filter { it.availableQuota >= cost }

        if (activeEntitlements.isEmpty()) {
            throw BizException(59021, "拍题次数包额度已耗尽")
        }

        val target = activeEntitlements.first()
        lockService.lock("pqcp:consume:${target.entitlementId}", 10) {
            // 重新读取并乐观锁更新
            val fresh = entitlementRepo.findForUpdate(target.entitlementId)
                ?: throw BizException(59003, "权益不存在")

            if (fresh.availableQuota < cost) {
                throw BizException(59021, "拍题次数包额度不足")
            }

            val updatedRows = entitlementRepo.increaseUsedQuota(
                fresh.entitlementId, cost, fresh.version
            )
            if (updatedRows == 0) {
                throw ConcurrentException(59004, "并发扣减冲突，请重试")
            }

            val afterQuota = fresh.availableQuota - cost
            val log = ConsumptionLog(
                logId = generateLogId(),
                entitlementId = fresh.entitlementId,
                userId = userId,
                bizType = bizType,
                bizId = bizId,
                cost = cost,
                beforeQuota = fresh.availableQuota,
                afterQuota = afterQuota,
                clientRequestId = clientRequestId
            )
            consumptionLogRepo.save(log)
            refreshRedisCache(fresh.entitlementId)
            return ConsumptionResult(success = true, entitlementId = fresh.entitlementId,
                                     consumed = cost, remaining = afterQuota)
        }
    }
}
```

### 6.3 过期清理任务

```kotlin
@Component
class EntitlementExpireJob(
    private val entitlementRepo: EntitlementRepository,
    private val eventPublisher: EventPublisher
) {
    @Scheduled(cron = "0 0 4 * * ?")
    fun expire() {
        val now = LocalDateTime.now()
        val cursor = entitlementRepo.findExpiredActive(now, Pageable.ofSize(500))
        cursor.forEach { batch ->
            val ids = batch.map { it.entitlementId }
            entitlementRepo.batchUpdateStatus(ids, EXPIRED)
            batch.forEach { eventPublisher.publish(EntitlementExpiredEvent(it)) }
            clearRedisStack(it.userId, ids)
        }
    }
}
```

## 8. 错误处理

### 8.1 错误码表（59000-59099 段）

| 错误码 | 含义 | HTTP 状态 | 客户端处理 |
|--------|------|-----------|-----------|
| 59001 | 商品不存在 | 404 | 刷新商品列表 |
| 59002 | 非拍题次数包商品 | 400 | 内部错误，上报日志 |
| 59003 | 权益实例不存在 | 404 | 刷新已购服务 |
| 59004 | 并发扣减冲突 | 409 | 自动重试最多 3 次 |
| 59005 | 购买超出单日限制 | 429 | 提示明日再试 |
| 59006 | 购买超出累计限制 | 429 | 推荐其他商品 |
| 59007 | 权益已过期 | 400 | 引导重新购买 |
| 59008 | 权益已退款 | 400 | 不可操作 |
| 59009 | 撤销次数超过可用次数 | 400 | 内部对账异常 |
| 59021 | 拍题次数包额度已耗尽 | 200（业务语义） | 弹出购买引导 |
| 59022 | 未成年人购买需家长授权 | 403 | 调起统一家长门 |
| 59023 | 退款期限已过 | 400 | 提示不可退 |
| 59050 | 服务降级，请使用每日额度 | 200 | 不弹购买引导 |

### 8.2 降级矩阵

| 场景 | 降级策略 | 红线 |
|------|---------|------|
| Redis 不可用 | 直接走 DB 扣减，同步恢复缓存 | 不能因缓存故障拒绝消费 |
| DB 写入超时 | 返回 59050，依赖每日额度放行 | 不能重复扣减 |
| 分布式锁不可用 | 使用 DB 唯一索引兜底幂等 | 不能重复扣减 |
| 消费事件发布失败 | 记录本地 Outbox，定时重试 | 不能丢事件 |
| 过期任务未执行 | 读时过滤 + 定时补偿双保险 | 过期权益禁止消费 |

## 9. 幂等与并发控制

### 9.1 幂等键设计

| 操作 | 幂等键 | 落点 |
|------|--------|------|
| 权益激活 | `order_id` 唯一索引 | user_entitlement |
| 消费扣减 | `client_request_id` + (`biz_id`, `biz_type`) | consumption_log |
| 退款回收 | `refund_id` | refund_record |
| 过期清理 | `(entitlement_id, status=ACTIVE)` 函数唯一索引 | user_entitlement |

### 9.2 并发扣减裁决

1. **分布式锁**：以 `entitlement_id` 为粒度加锁，避免同一权益并发扣减。
2. **乐观锁**：DB 更新 `used_quota` 时携带 `version` 字段，版本不一致则重试。
3. **重试策略**：消费扣减失败时，指数退避重试最多 3 次，仍失败返回 59050 降级。

## 10. 监控与对账

### 10.1 监控指标

| 指标 | 计算方式 | 告警阈值 |
|------|---------|---------|
| 拍题次数包购买转化率 | 购买 UV / 曝光 UV | 低于 2% 连续 3 天 |
| 权益激活成功率 | 激活成功 / 支付回调 | < 99.9% P1 |
| 消费扣减成功率 | 成功扣减 / 总请求 | < 99.95% P1 |
| 平均剩余次数 | SUM(available_quota) / COUNT | 用于库存预警 |
| 过期未使用次数占比 | 过期未用 / 总发放 | > 30% 触发运营提醒 |
| 退款金额占比 | 退款金额 / 销售额 | > 10% P2 |

### 10.2 日终对账四恒等式

1. `SUM(user_entitlement.total_quota)` = `SUM(consumption_log.cost)` + `SUM(available_quota)` + `SUM(refund_quota)`
2. `COUNT(consumption_log)` where status=SUCCESS = `SUM(user_entitlement.used_quota)` 增量
3. `SUM(refund_record.refund_quota)` = `SUM(user_entitlement.refund_quota)`
4. Redis `pqcp:available:{user_id}` = DB `SUM(available_quota)` per user（抽样 1%）

## 11. 合规要点

1. **未成年人保护**：未成年人购买拍题次数包需经过统一家长门授权，单次/累计金额受分龄限额约束。
2. **退款透明**：商品详情页明确标注「未使用部分 7 天内可退」，按剩余可用次数比例计算。
3. **不可诱导**：额度耗尽引导购买时，不得使用恐吓、焦虑式文案。
4. **数据最小化**：消费流水不记录用户拍照原图，仅记录业务单号与次数。
5. **过期提醒**：权益到期前 3 天、1 天各提醒一次，不得营销骚扰。
