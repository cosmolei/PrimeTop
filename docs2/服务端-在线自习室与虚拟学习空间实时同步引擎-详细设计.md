# 服务端 - 在线自习室与虚拟学习空间实时同步引擎 详细设计

> **文档版本**：v1.0
> **创建日期**：2026-06-20
> **关联模块**：学习计时器、学习打卡、学习挑战赛、学习同伴圈、消息推送
> **优先级**：P2（V1.5 阶段社交学习增强）

---

## 1. 概述

### 1.1 功能目标

为学生提供「云端自习室」功能——多名学生以实时同步的方式聚集在虚拟学习空间中，各自独立学习但互相可见学习状态，通过社交陪伴感和群体专注氛围提升学习动力和持续时长。

### 1.2 核心价值

| 价值维度 | 说明 |
| --- | --- |
| 社交陪伴 | "有人一起学"的心理暗示降低孤独感和放弃率 |
| 专注锚定 | 群体可见性带来适度的社交压力，抑制分心行为 |
| 时间积累 | 自习室学习时长自动计入打卡、计时器和学情统计 |
| 兴趣聚合 | 按学科、目标、年级等维度形成学习圈层 |

### 1.3 与相关模块的边界

| 模块 | 边界说明 |
| --- | --- |
| 学习计时器/番茄钟 | 计时器是单人工具；自习室是多人同步空间。自习室内置计时但额外负责状态广播和同步 |
| 学习挑战赛/排行榜 | 挑战赛是异步竞技（比分数/题量）；自习室是同步陪伴（比时长/专注度） |
| 学习同伴圈 | 同伴圈是异步社交动态；自习室是实时在场空间 |
| 协作学习 | 协作学习强调任务分工与合作；自习室强调各自独立学习但互相可见 |
| 直播课堂 | 直播是师生关系的一对多教学；自习室是平级关系的多对多陪伴 |

### 1.4 用户故事

```
US-1: 作为学生，我想进入一个"高三数学冲刺"自习室，看到有20个人正在一起学习，感觉更有动力
US-2: 作为学生，我想创建一个私密自习室，邀请3个好朋友一起晚自习
US-3: 作为学生，我想在自习室里使用番茄钟，25分钟专注+5分钟休息，其他人能看到我的状态
US-4: 作为家长，我想看到孩子今天在自习室学习了2小时，且全程未被标记为"离开"
US-5: 作为学生，自习室结束后我想看到本次自习室的学习总结和排行榜
US-6: 作为运营，我想创建"期末考前冲刺万人自习室"官方活动自习室
```

### 2.2 技术选型

| 组件 | 选型 | 理由 |
| --- | --- | --- |
| 实时通信 | WebSocket + Protobuf | 双向通信、低延迟、二进制紧凑编码 |
| 状态缓存 | Redis Cluster | 房间在线状态、参与者列表的高频读写 |
| 消息广播 | Redis Pub/Sub | 房间内事件广播，支持多实例水平扩展 |
| 持久化 | MySQL | 房间元数据、会话记录、统计数据 |
| 统计分析 | ClickHouse | 海量学习会话记录的聚合查询 |
| 定时任务 | XXL-JOB | 过期房间清理、空闲用户心跳超时检测 |
| 连接管理 | Netty (Spring WebSocket) | 高并发 WS 连接管理 |

### 3.2 Redis 数据结构

#### 3.2.1 房间在线状态

```
# 房间元数据（Hash）
Key:  sr:room:{roomId}:meta
Fields:
  status          = "active"          # 当前状态
  online_count    = 15                # 在线人数
  focus_count     = 12                # 专注中人数
  rest_count      = 3                 # 休息中人数
  host_user_id    = 100023            # 主持人
  updated_at      = 1718845200        # 最后更新时间戳
TTL: 无（随房间生命周期管理）

# 房间在线参与者（Sorted Set）
Key:  sr:room:{roomId}:online
Members: userId
Scores: 最后心跳时间戳
（心跳超时的成员会被 ZREM 并广播离线事件）

# 房间参与者详细状态（Hash per user）
Key:  sr:room:{roomId}:user:{userId}
Fields:
  nick_name    = "小明"
  avatar_url   = "https://..."
  grade_name   = "高三"
  status       = "focus"              # focus / rest / away
  subject_name = "数学"
  timer_mode   = "pomodoro"           # pomodoro / stopwatch / countdown
  timer_start  = 1718845200           # 计时开始时间戳
  timer_target = 1500                 # 目标时长（秒），0=无限
  focus_sec    = 1200                 # 本轮已专注时长
  last_beat    = 1718845300           # 最后心跳时间
TTL: 300s（心跳续期，离线后自动过期）
```

#### 3.2.2 房间事件广播频道

```
# Redis Pub/Sub Channel
Channel: sr:room:{roomId}:events
消息格式（Protobuf 编码后的二进制）:
  event_type  +  user_id  +  timestamp  +  payload
```

#### 3.2.3 用户当前所在房间

```
# 用户 → 房间映射（String）
Key:  sr:user:{userId}:current_room
Value: roomId
TTL:  28800s（8小时，防止僵死）
```

### 3.3 Protobuf 消息定义

```protobuf
syntax = "proto3";

package primetop.studyroom;

// ===== 客户端 → 服务端 (Client → Server) =====

message ClientMessage {
  oneof payload {
    JoinRoomRequest     join_request      = 1;
    LeaveRoomRequest    leave_request     = 2;
    Heartbeat           heartbeat         = 3;
    TimerAction         timer_action      = 4;
    UpdateStatus        update_status     = 5;
    SendChat            send_chat         = 6;
    RoomAction          room_action       = 7;   // 踢人/锁房/改配置等
  }
}

message JoinRoomRequest {
  int64  room_id     = 1;
  string password    = 2;  // 私密房间需要
  string device_info = 3;
}

message LeaveRoomRequest {
  int64 room_id = 1;
  string reason = 2;  // manual / app_background / disconnect
}

message Heartbeat {
  int64 room_id  = 1;
  int32 client_timestamp = 2;
  ClientState state = 3;  // 当前客户端状态
}

message TimerAction {
  int64 room_id   = 1;
  TimerOp op      = 2;    // START / PAUSE / RESUME / COMPLETE / SWITCH_MODE
  TimerMode mode  = 3;
  int32  target_sec = 4;  // 目标时长
  int32  subject_id = 5;  // 学习学科
}

message UpdateStatus {
  int64    room_id     = 1;
  UserStatus status    = 2;
  string   subject_name = 3;
}

message SendChat {
  int64  room_id  = 1;
  string content  = 2;  // 文本内容（经过前端过滤）
  ChatType type   = 3;  // TEXT / EMOJI / STICKER
}

message RoomAction {
  int64 room_id   = 1;
  RoomOp op       = 2;  // KICK_USER / LOCK_ROOM / UNLOCK_ROOM / CHANGE_FOCUS_MODE / TRANSFER_HOST
  int64 target_user_id = 3;  // KICK_USER / TRANSFER_HOST 时需要
}

// ===== 服务端 → 客户端 (Server → Client) =====

message ServerMessage {
  oneof payload {
    JoinRoomResponse      join_response     = 1;
    RoomStateSync         state_sync        = 2;
    ParticipantUpdate     participant_update = 3;
    TimerSync             timer_sync        = 4;
    ChatBroadcast         chat_broadcast    = 5;
    RoomEventNotification room_event        = 6;
    ErrorResponse         error             = 7;
    SessionSummary        session_summary   = 8;
  }
}

message JoinRoomResponse {
  bool   success    = 1;
  string message    = 2;
  RoomInfo room_info = 3;
  repeated ParticipantInfo participants = 4;
}

message RoomStateSync {
  int32 online_count  = 1;
  int32 focus_count   = 2;
  int32 rest_count    = 3;
  int64 sync_timestamp = 4;
}

message ParticipantUpdate {
  UpdateType type      = 1;  // JOIN / LEAVE / STATUS_CHANGE / TIMER_CHANGE
  ParticipantInfo info = 2;
}

message TimerSync {
  int64 user_id    = 1;
  TimerMode mode   = 2;
  TimerState state = 3;  // RUNNING / PAUSED / COMPLETED
  int32 elapsed_sec = 4;
  int32 target_sec  = 5;
}

message ChatBroadcast {
  int64  user_id    = 1;
  string nick_name  = 2;
  string avatar_url = 3;
  string content    = 4;
  ChatType type     = 5;
  int64  timestamp  = 6;
}

message RoomEventNotification {
  EventType event    = 1;
  string   message   = 2;
  int64    from_user = 3;
  int64    timestamp = 4;
}

message ErrorResponse {
  int32  code    = 1;
  string message = 2;
  string trace_id = 3;
}

message SessionSummary {
  int64  session_id   = 1;
  int32  focus_sec    = 2;
  int32  pomodoro_cnt = 3;
  int32  focus_score  = 4;
}

// ===== 共享类型 =====

enum UserStatus {
  FOCUS    = 0;
  REST     = 1;
  AWAY     = 2;
}

enum TimerMode {
  STOPWATCH  = 0;  // 正计时
  POMODORO   = 1;  // 番茄钟（25+5）
  COUNTDOWN  = 2;  // 倒计时
}

enum TimerOp {
  START      = 0;
  PAUSE      = 1;
  RESUME     = 2;
  COMPLETE   = 3;
  SWITCH_MODE = 4;
}

enum TimerState {
  RUNNING   = 0;
  PAUSED    = 1;
  COMPLETED = 2;
}

enum ChatType {
  TEXT    = 0;
  EMOJI   = 1;
  STICKER = 2;
}

enum UpdateType {
  JOIN          = 0;
  LEAVE         = 1;
  STATUS_CHANGE = 2;
  TIMER_CHANGE  = 3;
}

enum EventType {
  ROOM_LOCKED      = 0;
  ROOM_UNLOCKED    = 1;
  HOST_TRANSFERRED = 2;
  USER_KICKED      = 3;
  FOCUS_MODE_ON    = 4;
  FOCUS_MODE_OFF   = 5;
  ROOM_ENDING      = 6;
  POMODORO_PHASE   = 7;  // 番茄钟集体进入休息阶段
}

enum ClientState {
  FOREGROUND   = 0;
  BACKGROUND   = 1;
  SCREEN_OFF   = 2;
}

enum RoomOp {

  UNLOCK_ROOM      = 2;

message RoomInfo {
  int64  room_id      = 1;
  string room_code    = 2;
  string title        = 3;
  string description  = 4;
  string cover_url    = 5;
  int32  room_type    = 6;
  int32  max_capacity = 7;
  int64  host_user_id = 8;
  int32  status       = 9;
  int32  focus_mode   = 10;
  bool   is_locked    = 11;
  int64  scheduled_end = 12;
}

message ParticipantInfo {
  int64  user_id    = 1;
  string nick_name  = 2;
  string avatar_url = 3;
  string grade_name = 4;
  UserStatus status = 5;
  TimerMode timer_mode = 6;
  int32  elapsed_sec = 7;
  int32  target_sec  = 8;
  int32  total_focus_sec = 9;
  int32  role       = 10;
```

### 5.1 连接建立流程

```
客户端                                服务端
  │                                      │
  │  1. POST /join → 获取 ws_url + ticket │
  │ ─────────────────────────────────────→│
  │                                      │
  │  2. WebSocket Connect(ws_url)         │
  │ ─────────────────────────────────────→│
  │                                      │ 验证 ticket + token
  │                                      │ 注册连接 → ConnectionManager
  │                                      │ Redis: ZADD online, HSET user status
  │                                      │ Pub/Sub: 广播 JOIN 事件
  │  3. JoinRoomResponse (全量状态)       │
  │←─────────────────────────────────────│
  │                                      │
  │  4. Heartbeat (每 15s)                │
  │ ─────────────────────────────────────→│
  │                                      │ 更新 Redis 心跳时间戳
  │                                      │
  │  5. TimerAction(START, POMODORO)      │
  │ ─────────────────────────────────────→│
  │                                      │ 创建 study_session 记录
  │                                      │ Redis: 更新用户状态
  │  6. TimerSync → 广播给全房间           │
  │←─────────────────────────────────────│
  │                                      │
  │  7. 心跳超时检测 (后台扫描)            │
  │                                      │ ZRANGEBYSCORE 找超时用户
  │                                      │ 标记离线 → 广播 LEAVE
  │  8. 断开连接                          │
  │←─────────────────────────────────────│
```

### 5.2 心跳机制

```java
// 心跳配置
public class StudyRoomConstants {
    public static final int HEARTBEAT_INTERVAL_SEC = 15;    // 客户端发送间隔
    public static final int HEARTBEAT_TIMEOUT_SEC = 45;     // 服务端容忍超时（3次心跳）
    public static final int AWAY_THRESHOLD_SEC = 120;       // App后台超2分钟标记away
    public static final int DISCONNECT_GRACE_SEC = 30;      // 断线重连宽限期
}
```

**心跳处理逻辑**：

1. 客户端每 15 秒发送 Heartbeat 消息，携带当前 `ClientState`（FOREGROUND / BACKGROUND / SCREEN_OFF）
2. 服务端收到后更新 `sr:room:{roomId}:online` 中该用户的 score（时间戳）
3. 更新 `sr:room:{roomId}:user:{userId}` 的 `last_beat` 字段
4. 如果 `ClientState = BACKGROUND` 持续超过 120 秒，自动将用户状态改为 `AWAY`，广播状态变更
5. 如果心跳超时 45 秒（3 次心跳未收到），标记为"疑似断线"，进入宽限期
6. 宽限期内重连则恢复正常；超宽限期则判定离线

### 5.3 断线重连

```
断线重连流程:
1. 客户端检测到 WS 断开
2. 使用指数退避重连: 1s → 2s → 4s → 8s → 16s (最大)
3. 重连时携带原 session_id + ticket
4. 服务端校验:
   - session_id 仍在宽限期 (30s 内) → 恢复连接，无需重新加入
   - session_id 已过期 → 重新走 /join 流程
5. 恢复后服务端推送全量 RoomStateSync + 最近 10 条聊天
```

```java
/**
 * 自习室 WebSocket 连接管理器
 * 管理所有房间的在线连接，负责消息路由和广播
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class StudyRoomConnectionManager {

    private final RedisTemplate<String, String> redis;
    private final StudyRoomEventBus eventBus;
    private final StudyRoomMetrics metrics;

    // roomId → (userId → WebSocketSession)
    private final ConcurrentHashMap<Long, ConcurrentHashMap<Long, WebSocketSession>> roomConnections =
        new ConcurrentHashMap<>();

    // session → (roomId, userId) 反向映射
    private final ConcurrentHashMap<String, RoomUserPair> sessionIndex =
        new ConcurrentHashMap<>();

    /**
     * 注册新连接
     */
    public void register(Long roomId, Long userId, String sessionId, WebSocketSession session) {
        roomConnections.computeIfAbsent(roomId, k -> new ConcurrentHashMap<>())
                       .put(userId, session);

        sessionIndex.put(sessionId, new RoomUserPair(roomId, userId));

        // Redis: 记录在线状态
        String onlineKey = redisKey("room:%d:online", roomId);
        redis.opsForZSet().add(onlineKey, userId.toString(), System.currentTimeMillis() / 1000);

        // 广播 JOIN 事件
        broadcastParticipantUpdate(roomId, UpdateType.JOIN, userId);
        metrics.incrementOnline(roomId);

        log.info("User {} joined room {}", userId, roomId);
    }

    /**
     * 注销连接
     */
    public void unregister(String sessionId, String reason) {
        RoomUserPair pair = sessionIndex.remove(sessionId);
        if (pair == null) return;

        ConcurrentHashMap<Long, WebSocketSession> roomSessions = roomConnections.get(pair.roomId());
        if (roomSessions != null) {
            WebSocketSession removed = roomSessions.remove(pair.userId());
            if (removed != null && removed.isOpen()) {
                try { removed.close(CloseStatus.NORMAL); } catch (IOException ignored) {}
            }
            // 如果房间空了，清理
            if (roomSessions.isEmpty()) {
                roomConnections.remove(pair.roomId());
            }
        }

        // Redis: 移除在线状态
        String onlineKey = redisKey("room:%d:online", pair.roomId());
        redis.opsForZSet().remove(onlineKey, pair.userId().toString());
        redis.delete(redisKey("room:%d:user:%d", pair.roomId(), pair.userId()));
        redis.delete(redisKey("user:%d:current_room", pair.userId()));

        // 广播 LEAVE 事件
        broadcastParticipantUpdate(pair.roomId(), UpdateType.LEAVE, pair.userId());
        metrics.decrementOnline(pair.roomId());

        log.info("User {} left room {} ({})", pair.userId(), pair.roomId(), reason);
    }

    /**
     * 广播消息给房间内所有在线用户
     */
    public void broadcast(Long roomId, ServerMessage message) {
        ConcurrentHashMap<Long, WebSocketSession> sessions = roomConnections.get(roomId);
        if (sessions == null || sessions.isEmpty()) return;

        byte[] payload = message.toByteArray();
        sessions.forEach((userId, session) -> {
            try {
                if (session.isOpen()) {
                    session.sendMessage(new BinaryMessage(payload));
                }
            } catch (IOException e) {
                log.warn("Failed to send to user {} in room {}", userId, roomId, e);
            }
        });
    }

    /**
     * 发送消息给指定用户
     */
    public void sendToUser(Long roomId, Long userId, ServerMessage message) {
        ConcurrentHashMap<Long, WebSocketSession> sessions = roomConnections.get(roomId);
        if (sessions == null) return;

        WebSocketSession session = sessions.get(userId);
        if (session != null && session.isOpen()) {
            try {
                session.sendMessage(new BinaryMessage(message.toByteArray()));
            } catch (IOException e) {
                log.warn("Failed to send to user {} in room {}", userId, roomId, e);
            }
        }
    }

    /**
     * 获取房间在线人数
     */
    public int getOnlineCount(Long roomId) {
        ConcurrentHashMap<Long, WebSocketSession> sessions = roomConnections.get(roomId);
        return sessions == null ? 0 : sessions.size();
    }

    private void broadcastParticipantUpdate(Long roomId, UpdateType type, Long userId) {
        // 从 Redis 获取用户信息
        String userKey = redisKey("room:%d:user:%d", roomId, userId);
        Map<Object, Object> userInfo = redis.opsForHash().entries(userKey);

        ParticipantInfo info = ParticipantInfo.newBuilder()
            .setUserId(userId)
            .setNickName((String) userInfo.getOrDefault("nick_name", ""))
            .setAvatarUrl((String) userInfo.getOrDefault("avatar_url", ""))
            .setStatus(UserStatus.FOCUS)
            .build();

        ParticipantUpdate update = ParticipantUpdate.newBuilder()
            .setType(type)
            .setInfo(info)
            .build();

        ServerMessage message = ServerMessage.newBuilder()
            .setParticipantUpdate(update)
            .build();

        broadcast(roomId, message);
    }

    private String redisKey(String pattern, Object... args) {
        return "sr:" + String.format(pattern, args);
    }

    private record RoomUserPair(Long roomId, Long userId) {}
}
```

#### 7.1.2 消息处理器

```java
/**
 * 自习室消息处理器
 * 处理客户端 WebSocket 消息并路由到对应业务逻辑
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class StudyRoomMessageHandler {

    private final StudyRoomConnectionManager connectionManager;
    private final StudyRoomService roomService;
    private final StudySessionService sessionService;
    private final StudyRoomChatService chatService;
    private final SensitiveWordFilter sensitiveWordFilter;
    private final StudyRoomRedisOps redisOps;

    /**
     * 处理客户端消息
     */
    public void handle(WebSocketSession session, ClientMessage message) {
        try {
            switch (message.getPayloadCase()) {
                case JOIN_REQUEST    -> handleJoin(session, message.getJoinRequest());
                case LEAVE_REQUEST   -> handleLeave(session, message.getLeaveRequest());
                case HEARTBEAT       -> handleHeartbeat(session, message.getHeartbeat());
                case TIMER_ACTION    -> handleTimerAction(session, message.getTimerAction());
                case UPDATE_STATUS   -> handleUpdateStatus(session, message.getUpdateStatus());
                case SEND_CHAT       -> handleChat(session, message.getSendChat());
                case ROOM_ACTION     -> handleRoomAction(session, message.getRoomAction());
                default              -> log.warn("Unknown message type: {}", message.getPayloadCase());
            }
        } catch (Exception e) {
            log.error("Error handling message", e);
            sendError(session, 500, "处理失败", "N/A");
        }
    }

    /**
     * 处理计时器操作
     */
    private void handleTimerAction(WebSocketSession session, TimerAction action) {
        RoomUserPair pair = getSessionPair(session);
        if (pair == null) return;

        Long roomId = pair.roomId();
        Long userId = pair.userId();

        // 验证用户在房间内且房间处于ACTIVE状态
        if (!roomService.isUserInRoom(roomId, userId)) {
            sendError(session, 302, "连接已失效，请重新加入", null);
            return;
        }

        switch (action.getOp()) {
            case START -> startTimer(roomId, userId, action);
            case PAUSE -> pauseTimer(roomId, userId);
            case RESUME -> resumeTimer(roomId, userId);
            case COMPLETE -> completeTimer(roomId, userId, action);
            case SWITCH_MODE -> switchTimerMode(roomId, userId, action);
        }
    }

    /**
     * 开始计时
     */
    private void startTimer(Long roomId, Long userId, TimerAction action) {
        // 1. 创建学习会话
        StudySession studySession = sessionService.createSession(
            StudySession.builder()
                .roomId(roomId)
                .userId(userId)
                .sessionType(SessionType.FOCUS)
                .subjectId((long) action.getSubjectId())
                .startTime(LocalDateTime.now())
                .build()
        );

        // 2. 更新 Redis 中的用户状态
        redisOps.updateUserStatus(roomId, userId, UserStatus.FOCUS, action.getMode(),
            action.getTargetSec(), 0);

        // 3. 更新房间计数
        redisOps.incrementRoomFocusCount(roomId, 1);

        // 4. 广播 TimerSync
        TimerSync sync = TimerSync.newBuilder()
            .setUserId(userId)
            .setMode(action.getMode())
            .setState(TimerState.RUNNING)
            .setElapsedSec(0)
            .setTargetSec(action.getTargetSec())
            .build();

        connectionManager.broadcast(roomId, ServerMessage.newBuilder()
            .setTimerSync(sync).build());
    }

    /**
     * 计时完成
     */
    private void completeTimer(Long roomId, Long userId, TimerAction action) {
        // 1. 结束学习会话，计算时长
        StudySession session = sessionService.completeActiveSession(roomId, userId);
        int durationSec = session != null ? session.getDurationSec() : 0;

        // 2. 更新参与者累计时长
        roomService.addFocusDuration(roomId, userId, durationSec);

        // 3. 如果是番茄钟模式，增加番茄钟计数
        if (action.getMode() == TimerMode.POMODORO) {
            roomService.incrementPomodoroCount(roomId, userId);

            // 发送成就事件（供成就系统消费）
            eventBus.publish(RoomEvent.pomodoroCompleted(roomId, userId, durationSec));
        }

        // 4. 更新房间累计专注时长
        roomService.addRoomTotalFocus(roomId, durationSec);

        // 5. 广播完成事件
        TimerSync sync = TimerSync.newBuilder()
            .setUserId(userId)
            .setMode(action.getMode())
            .setState(TimerState.COMPLETED)
            .setElapsedSec(durationSec)
            .setTargetSec(action.getTargetSec())
            .build();

        connectionManager.broadcast(roomId, ServerMessage.newBuilder()
            .setTimerSync(sync).build());

        // 6. 发送个人学习会话总结
        SessionSummary summary = SessionSummary.newBuilder()
            .setSessionId(session != null ? session.getId() : 0)
            .setFocusSec(durationSec)
            .setPomodoroCnt(roomService.getPomodoroCount(roomId, userId))
            .setFocusScore(calculateFocusScore(durationSec, roomId, userId))
            .build();

        connectionManager.sendToUser(roomId, userId, ServerMessage.newBuilder()
            .setSessionSummary(summary).build());
    }

    /**
     * 处理聊天消息
     */
    private void handleChat(WebSocketSession session, SendChat chat) {
        RoomUserPair pair = getSessionPair(session);
        if (pair == null) return;

        Long roomId = pair.roomId();
        Long userId = pair.userId();

        // 1. 检查房间是否允许聊天
        if (roomService.isFocusMode(roomId)) {
            sendError(session, 201, "专注模式下不能聊天哦，专心学习吧~", null);
            return;
        }

        // 2. 频率限制（每用户每分钟最多 20 条）
        if (!chatService.rateLimit(userId, roomId)) {
            sendError(session, 202, "消息发送太频繁，请稍后再试", null);
            return;
        }

        // 3. 敏感词过滤
        String filtered = sensitiveWordFilter.filter(chat.getContent());
        if (filtered == null) {
            sendError(session, 202, "消息包含敏感内容，请修改后发送", null);
            return;
        }

        // 4. 获取用户信息
        ParticipantInfo userInfo = redisOps.getParticipantInfo(roomId, userId);

        // 5. 广播聊天消息
        ChatBroadcast broadcast = ChatBroadcast.newBuilder()
            .setUserId(userId)
            .setNickName(userInfo.getNickName())
            .setAvatarUrl(userInfo.getAvatarUrl())
            .setContent(filtered)
            .setType(chat.getType())
            .setTimestamp(System.currentTimeMillis())
            .build();

        connectionManager.broadcast(roomId, ServerMessage.newBuilder()
            .setChatBroadcast(broadcast).build());

        // 6. 异步保存聊天记录（可选，用于审计）
        chatService.saveMessageAsync(roomId, userId, filtered);
    }

    /**
     * 处理心跳
     */
    private void handleHeartbeat(WebSocketSession session, Heartbeat heartbeat) {
        RoomUserPair pair = getSessionPair(session);
        if (pair == null) return;

        long now = System.currentTimeMillis() / 1000;

        // 更新在线 Sorted Set 的时间戳
        redisOps.updateHeartbeat(pair.roomId(), pair.userId(), now);

        // 更新客户端状态
        ClientState clientState = heartbeat.getState();
        if (clientState == ClientState.BACKGROUND || clientState == ClientState.SCREEN_OFF) {
            // App 进入后台，记录后台开始时间
            redisOps.markBackground(pair.roomId(), pair.userId(), now);
        } else {
            // App 回到前台
            redisOps.markForeground(pair.roomId(), pair.userId(), now);
        }

        // 回复心跳
        RoomStateSync stateSync = RoomStateSync.newBuilder()
            .setOnlineCount(connectionManager.getOnlineCount(pair.roomId()))
            .setFocusCount(redisOps.getRoomFocusCount(pair.roomId()))
            .setRestCount(redisOps.getRoomRestCount(pair.roomId()))
            .setSyncTimestamp(now)
            .build();

        connectionManager.sendToUser(pair.roomId(), pair.userId(),
            ServerMessage.newBuilder().setStateSync(stateSync).build());
    }
```

```java
        if (activeRoomIds.isEmpty()) return;

        long now = System.currentTimeMillis() / 1000;
        long timeoutCutoff = now - TIMEOUT_THRESHOLD_SEC;
        long awayCutoff = now - AWAY_THRESHOLD_SEC;
```

```java
/**
 * 自习室智能匹配引擎
 * 根据用户画像、学科偏好、学段、历史行为推荐最合适的自习室
 */
@Service
@RequiredArgsConstructor
public class StudyRoomMatchService {

    private final StudyRoomMapper roomMapper;
    private final RedisTemplate<String, String> redis;
    private final UserProfileService userProfileService;

    /**
     * 为用户推荐自习室
     */
    public List<RoomMatchResult> matchRooms(Long userId, MatchRequest request) {
        // 1. 获取用户画像
        UserProfile profile = userProfileService.getProfile(userId);

        // 2. 构建查询条件
        RoomQueryCondition condition = RoomQueryCondition.builder()
            .gradeLevel(request.getGradeLevel() != null ?
                request.getGradeLevel() : profile.getGradeLevel())
            .subjectId(request.getSubjectId())
            .focusMode(request.getFocusMode())
            .status(RoomStatus.ACTIVE)
            .excludeIds(request.getExcludeRoomIds())
            .excludeFull(true)     // 排除已满房间
            .excludeLocked(true)   // 排除已锁定房间
            .build();

        // 3. 查询候选房间（从 DB + Redis 获取实时数据）
        List<RoomWithOnline> candidates = roomMapper.findCandidateRooms(condition);

        if (candidates.isEmpty()) {
            // 如果没有匹配的公开房间，推荐创建新房间
            return Collections.emptyList();
        }

        // 4. 多维度评分排序
        return candidates.stream()
            .map(room -> {
                double score = calculateMatchScore(room, profile, request);
                String reason = generateMatchReason(room, profile);
                return new RoomMatchResult(room, score, reason);
            })
            .sorted(Comparator.comparingDouble(RoomMatchResult::getMatchScore).reversed())
            .limit(5)
            .collect(Collectors.toList());
    }

    /**
     * 计算匹配分数
     */
    private double calculateMatchScore(RoomWithOnline room, UserProfile profile, MatchRequest req) {
        double score = 0;

        // 学段匹配（权重: 30%）
        if (room.getGradeLevel() != null && room.getGradeLevel().equals(profile.getGradeLevel())) {
            score += 0.30;
        }

        // 学科匹配（权重: 25%）
        if (room.getSubjectId() != null) {
            if (req.getSubjectId() != null && room.getSubjectId().equals(req.getSubjectId())) {
                score += 0.25;
            } else if (profile.getWeakSubjects().contains(room.getSubjectId())) {
                // 推荐薄弱学科的自习室
                score += 0.15;
            }
        }

        // 在线人数热度（权重: 20%）— 适中人数最佳（6~15人）
        int online = room.getOnlineCount();
        if (online >= 6 && online <= 15) {
            score += 0.20;
        } else if (online >= 3 && online <= 20) {
            score += 0.10;
        }

        // 学习时段匹配（权重: 15%）
        int currentHour = LocalTime.now().getHour();
        if (isInUserPreferredSlot(currentHour, profile)) {
            score += 0.15;
        }

        // 同校/同城（权重: 10%）
        if (room.getHostSchoolId() != null && room.getHostSchoolId().equals(profile.getSchoolId())) {
            score += 0.10;
        }

        return score;
    }

    private String generateMatchReason(RoomWithOnline room, UserProfile profile) {
        List<String> reasons = new ArrayList<>();
        if (room.getGradeLevel() != null && room.getGradeLevel().equals(profile.getGradeLevel())) {
            reasons.add("同年级");
        }
        if (room.getSubjectId() != null) {
            reasons.add("同学科");
        }
        if (room.getOnlineCount() >= 6) {
            reasons.add("氛围活跃");
        }
        reasons.add("学习风格相似");

        return String.join("·", reasons);
    }

    private boolean isInUserPreferredSlot(int hour, UserProfile profile) {
        // 检查当前时间是否在用户常用学习时段
        return profile.getPreferredTimeSlots().stream()
            .anyMatch(slot -> hour >= slot.getStart() && hour < slot.getEnd());
    }
}
```

### 11.3 客户端核心类设计 (Flutter)

```dart
/// 自习室 WebSocket 客户端
class StudyRoomWsClient {
  WebSocketChannel? _channel;
  StreamSubscription? _subscription;
  final _messageController = StreamController<ServerMessage>.broadcast();

  Stream<ServerMessage> get messages => _messageController.stream;

  /// 连接自习室
  Future<void> connect(String wsUrl) async {
    _channel = WebSocketChannel.connect(Uri.parse(wsUrl));
    _subscription = _channel!.stream.listen(
      (data) {
        final message = ServerMessage.fromBuffer(data as List<int>);
        _messageController.add(message);
      },
      onError: (e) => _handleError(e),
      onDone: () => _handleDisconnect(),
    );
    _startHeartbeat();
  }

  /// 发送心跳
  void _sendHeartbeat(ClientState state) {
    _channel?.sink.add(ClientMessage(
      heartbeat: Heartbeat(
        clientTimestamp: DateTime.now().millisecondsSinceEpoch ~/ 1000,
        state: state,
      ),
    ).writeToBuffer());
  }

  /// 发送计时器操作
  void sendTimerAction(TimerOp op, {TimerMode? mode, int? targetSec}) {
    _channel?.sink.add(ClientMessage(
      timerAction: TimerAction(
        op: op,
        mode: mode ?? TimerMode.pomodoro,
        targetSec: targetSec ?? 0,
      ),
    ).writeToBuffer());
  }

  /// 发送聊天
  void sendChat(String content) {
    _channel?.sink.add(ClientMessage(
      sendChat: SendChat(content: content, type: ChatType.text),
    ).writeToBuffer());
  }

  /// 断线重连
  Future<void> _reconnect() async {
    // 指数退避重连逻辑
    for (int attempt = 0; attempt < 5; attempt++) {
      final delay = pow(2, attempt).toInt();
      await Future.delayed(Duration(seconds: delay));
      try {
        await connect(_lastWsUrl!);
        return;
      } catch (_) { /* 继续重试 */ }
    }
  }
}

/// 自习室状态管理 (Riverpod)
final studyRoomProvider = StateNotifierProvider<StudyRoomNotifier, StudyRoomState>(
  (ref) => StudyRoomNotifier(ref.read(studyRoomWsClientProvider)),
);

class StudyRoomNotifier extends StateNotifier<StudyRoomState> {
  StudyRoomNotifier(this._client) : super(const StudyRoomState.initial()) {
    _client.messages.listen(_handleMessage);
  }

  final StudyRoomWsClient _client;

  /// 处理服务端消息
  void _handleMessage(ServerMessage message) {
    switch (message.whichPayload()) {
      case ServerMessage_Payload.joinResponse:
        state = StudyRoomState.joined(
          roomInfo: message.joinResponse.roomInfo,
          participants: message.joinResponse.participants.toList(),
        );
      case ServerMessage_Payload.participantUpdate:
        _handleParticipantUpdate(message.participantUpdate);
      case ServerMessage_Payload.timerSync:
        _handleTimerSync(message.timerSync);
      case ServerMessage_Payload.chatBroadcast:
        _handleChat(message.chatBroadcast);
      case ServerMessage_Payload.stateSync:
        state = state.copyWith(
          onlineCount: message.stateSync.onlineCount,
          focusCount: message.stateSync.focusCount,
        );
      case ServerMessage_Payload.roomEvent:
        _handleRoomEvent(message.roomEvent);
      case ServerMessage_Payload.sessionSummary:
        state = state.copyWith(lastSummary: message.sessionSummary);
      case ServerMessage_Payload.error:
        // 错误处理
        break;
      default:
        break;
    }
  }
}
```

### 13.3 优雅停机

```java
/**
 * WS 节点优雅停机
 * 1. 从 LB 摘除，不再接收新连接
 * 2. 向所有连接发送 RECONNECT 提示
 * 3. 等待连接自然关闭或超时
 * 4. 关闭节点
 */
@Component
public class GracefulShutdown implements ApplicationListener<ContextClosedEvent> {

    private final StudyRoomConnectionManager connectionManager;

    @Override
    public void onApplicationEvent(ContextClosedEvent event) {
        // 1. 通知所有连接的客户端重连（会路由到其他节点）
        connectionManager.broadcastToAll(ServerMessage.newBuilder()
            .setRoomEvent(RoomEventNotification.newBuilder()
                .setEvent(EventType.ROOM_ENDING)
                .setMessage("服务器维护中，正在重连...")
                .build())
            .build());

        // 2. 等待 30 秒让客户端重连
        try { Thread.sleep(30000); } catch (InterruptedException ignored) {}

        // 3. 关闭所有连接
        connectionManager.closeAll();
    }
}
```

## 14. 异常处理与边界情况

### 14.1 异常处理矩阵

| 场景 | 处理策略 | 用户感知 |
| --- | --- | --- |
| WS 连接断开 | 指数退避重连（1s/2s/4s/8s/16s） | 显示"网络波动，重连中..." |
| 重连失败（5次） | 提示用户手动重试 | "连接失败，请检查网络后重试" |
| 房间被解散 | 推送 ROOM_ENDING + 跳转列表页 | "自习室已结束，查看其他自习室" |
| 被踢出 | 推送 USER_KICKED + 5分钟禁止加入 | "您已被移出自习室" |
| Redis 不可用 | 降级为本地内存缓存，继续提供服务 | 无感知（可能部分数据不一致） |
| 房间满员 | 返回 409 + 推荐替代房间 | "房间已满，为您推荐相似自习室" |
| 心跳超时 | 自动退出 + 结算已学习时长 | "网络超时，已自动退出" |
| 同时段多处登录 | 新连接踢掉旧连接 | 旧设备收到"账号在其他设备进入自习室" |
| 用户在自习室中升级年级 | 不影响当前会话，下次匹配按新年级 | 无感知 |
| 定时结束时间到达 | 提前 5 分钟提醒，自动结束并结算 | "自习室即将结束，今天辛苦了！" |

### 14.2 数据一致性保障

```
场景：用户专注时长不丢失

1. 计时器开始时：
   - Redis 记录 timer_start 时间戳
   - MySQL 创建 study_session 记录（end_time = NULL）

2. 心跳时：
   - Redis 更新 last_beat
   - 不写 MySQL（降低写入压力）

3. 计时完成/退出时：
   - 计算 duration_sec = now - timer_start
   - MySQL 更新 study_session.end_time 和 duration_sec
   - MySQL 更新 participant.total_focus_sec
   - Redis 更新房间 total_focus_sec

4. 异常断线时：
   - 后台扫描发现心跳超时
   - 自动结算 study_session（end_time = last_beat, duration = last_beat - start）
   - 更新累计统计

5. 对账补偿（每小时执行）：
   - 扫描 end_time IS NULL 且 start_time < now - 1hour 的 session
   - 自动结算
   - 与 Redis 累计值比对，修正差异
```
