# 客户端 - 物理实验模拟与力学分析交互组件 详细设计

## 1. 概述

### 1.1 模块定位

本组件为 PrimeTop 客户端提供面向初高中物理学科的**交互式实验模拟与力学分析**能力，覆盖力学、运动学、电学、光学等核心实验场景。学生可通过可视化拖拽、参数调节实时观察物理过程，理解抽象概念。

### 1.2 设计目标

1. **可视化物理过程**：将抽象的力学、运动学、电学过程转化为可交互的动画模拟
2. **参数可调节**：支持调节质量、速度、角度、摩擦系数等参数，实时观察结果变化
3. **公式联动**：模拟过程同步展示对应公式推导和数值计算
4. **安全实验**：替代危险或需要昂贵器材的实验场景
5. **分龄适配**：初中侧重现象观察，高中侧重定量分析

### 1.3 覆盖实验场景

## 3. 核心物理引擎实现

### 3.1 积分器

采用 **Velocity Verlet** 积分，兼顾精度和稳定性：

```dart
class VelocityVerletIntegrator {
  /// 单步积分
  /// a(t) = F(t) / m
  /// x(t+dt) = x(t) + v(t)*dt + 0.5*a(t)*dt²
  /// a(t+dt) = F(t+dt) / m  (重新计算力)
  /// v(t+dt) = v(t) + 0.5*(a(t) + a(t+dt))*dt
  static void integrate(PhysicsBody body, double dt, Vector2 netForce) {
    final a0 = netForce / body.mass;
    
    // 更新位置
    body.position = body.position 
      + body.velocity * dt 
      + a0 * (0.5 * dt * dt);
    
    // 暂存旧加速度
    final aOld = a0.clone();
    
    // 标记需要重新计算力 (由引擎在下一步处理)
    body.acceleration = aOld; // 临时值，下一步更新
  }
  
  static void integrateVelocity(PhysicsBody body, Vector2 newNetForce, double dt) {
    final aNew = newNetForce / body.mass;
    body.velocity = body.velocity + 0.5 * (body.acceleration + aNew) * dt;
    body.acceleration = aNew;
  }
}
```

### 3.2 碰撞检测与响应

```dart
class CollisionDetector {
  /// 检测两个物体是否碰撞
  static CollisionResult? detect(PhysicsBody a, PhysicsBody b) {
    if (a.type == BodyType.circle && b.type == BodyType.circle) {
      return _circleVsCircle(a, b);
    }
    if (a.type == BodyType.circle && b.type == BodyType.rect) {
      return _circleVsRect(a, b);
    }
    if (a.type == BodyType.rect && b.type == BodyType.rect) {
      return _rectVsRect(a, b);
    }
    // ... 其他组合
    return null;
  }
  
  static CollisionResult? _circleVsCircle(PhysicsBody a, PhysicsBody b) {
    final delta = b.position - a.position;
    final dist = delta.length;
    final minDist = a.radius + b.radius;
    
    if (dist < minDist) {
      final normal = delta.normalized();
      final penetration = minDist - dist;
      return CollisionResult(
        bodyA: a,
        bodyB: b,
        normal: normal,
        penetration: penetration,
        contactPoint: a.position + normal * a.radius,
      );
    }
    return null;
  }
}

class CollisionResolver {
  /// 冲量法碰撞响应
  static void resolve(CollisionResult collision) {
    final a = collision.bodyA;
    final b = collision.bodyB;
    final normal = collision.normal;
    
    // 相对速度
    final relVel = b.velocity - a.velocity;
    final velAlongNormal = relVel.dot(normal);
    
    // 不处理正在分离的物体
    if (velAlongNormal > 0) return;
    
    // 弹性系数取最小
    final e = min(a.restitution, b.restitution);
    
    // 冲量标量
    final j = -(1 + e) * velAlongNormal 
              / (1 / a.mass + 1 / b.mass);
    
    // 施加冲量
    final impulse = normal * j;
    a.velocity = a.velocity - impulse / a.mass;
    b.velocity = b.velocity + impulse / b.mass;
    
    // 位置修正 (防止穿透)
    final correction = normal * (collision.penetration / (a.mass + b.mass)) * 0.8;
    a.position = a.position - correction * b.mass;
    b.position = b.position + correction * a.mass;
  }
}
```

### 3.3 力计算管线

```dart
class ForceAccumulator {
  final List<ForceGenerator> generators = [];
  
  Vector2 computeNetForce(PhysicsBody body, SimulationState state) {
    var netForce = Vector2.zero();
    
    for (final gen in generators) {
      final force = gen.compute(body, state);
      netForce = netForce + force;
    }
    
    return netForce;
  }
}

abstract class ForceGenerator {
  Vector2 compute(PhysicsBody body, SimulationState state);
}

/// 重力
class GravityGenerator extends ForceGenerator {
  final double g; // 重力加速度, 默认 9.8
  
  GravityGenerator({this.g = 9.8});
  
  @override
  Vector2 compute(PhysicsBody body, SimulationState state) {
    return Vector2(0, body.mass * g); // y 轴向下
  }
}

/// 弹簧力 (胡克定律)
class SpringGenerator extends ForceGenerator {
  final PhysicsBody other;
  final double stiffness;
  final double restLength;
  final double damping;
  
  SpringGenerator({
    required this.other,
    required this.stiffness,
    required this.restLength,
    this.damping = 0.1,
  });
  
  @override
  Vector2 compute(PhysicsBody body, SimulationState state) {
    final delta = other.position - body.position;
    final dist = delta.length;
    final direction = delta.normalized();
    
    // 胡克定律: F = -k * (x - x0)
    final springForce = direction * stiffness * (dist - restLength);
    
    // 阻尼力: F_d = -c * v_relative
    final relVel = other.velocity - body.velocity;
    final dampForce = direction * damping * relVel.dot(direction);
    
    return springForce + dampForce;
  }
}

/// 摩擦力
class FrictionGenerator extends ForceGenerator {
  final double mu; // 摩擦系数
  final Vector2 surfaceNormal;
  
  FrictionGenerator({required this.mu, required this.surfaceNormal});
  
  @override
  Vector2 compute(PhysicsBody body, SimulationState state) {
    final speed = body.velocity.length;
    if (speed < 0.001) return Vector2.zero();
    
    final normalForce = body.mass * 9.8; // 简化: 仅支持水平面
    final frictionMag = mu * normalForce;
    final direction = -body.velocity.normalized();
    
    // 静摩擦 vs 动摩擦
    return direction * min(frictionMag, body.mass * speed / 0.016);
  }
}
```

```dart
class InclinedPlaneSimulation implements PhysicsSimulation {
  double angle = 30.0;       // 斜面角度 (°)
  double mass = 2.0;         // 物块质量 (kg)
  double frictionMu = 0.3;   // 摩擦系数
  double initialVelocity = 0; // 初速度 (m/s)
  bool showForceDecomposition = true; // 显示力的分解
  
  // 计算量
  double get gravityComponent => mass * 9.8 * sin(angle * pi / 180);
  double get normalForce => mass * 9.8 * cos(angle * pi / 180);
  double get frictionForce => frictionMu * normalForce;
  double get netForce => gravityComponent - frictionForce;
  double get acceleration => netForce / mass;
}
```

#### 4.1.2 渲染

```dart
class InclinedPlaneRenderer {
  void paint(Canvas canvas, Size size, InclinedPlaneState state) {
    final paint = Paint()..style = PaintingStyle.fill;
    
    // 1. 绘制坐标网格
    _drawGrid(canvas, size);
    
    // 2. 绘制斜面
    final planePath = Path();
    final baseY = size.height * 0.8;
    final planeLength = size.width * 0.7;
    final radians = state.angle * pi / 180;
    
    planePath.moveTo(0, baseY);                                          // 直角点
    planePath.lineTo(planeLength * cos(radians), 
                     baseY - planeLength * sin(radians));                 // 斜面顶点
    planePath.lineTo(planeLength * cos(radians), baseY);                 // 垂足
    planePath.close();
    
    paint.color = const Color(0xFFE8E8E8);
    canvas.drawPath(planePath, paint);
    
    // 3. 绘制物块 (在斜面上)
    final blockX = state.blockPosition * cos(radians);
    final blockY = baseY - state.blockPosition * sin(radians);
    final blockSize = 30.0;
    
    canvas.save();
    canvas.translate(blockX, blockY);
    canvas.rotate(-radians);
    
    paint.color = const Color(0xFF4A90D9);
    canvas.drawRect(
      Rect.fromCenter(center: Offset.zero, width: blockSize, height: blockSize),
      paint,
    );
    
    // 4. 绘制力矢量 (可选)
    if (state.showForceDecomposition) {
      _drawForceArrows(canvas, state, blockSize);
    }
    
    canvas.restore();
    
    // 5. 绘制角度标注
    _drawAngleArc(canvas, Offset.zero, baseY, radians, state.angle);
  }
  
  void _drawForceArrows(Canvas canvas, InclinedPlaneState state, double blockSize) {
    final scale = 3.0; // 像素/牛顿
    
    // 重力 (向下)
    _drawArrow(canvas, Offset.zero, 
      Offset(0, state.mass * 9.8 * scale),
      Colors.red, 'G');
    
    // 重力沿斜面分量
    _drawArrow(canvas, Offset.zero,
      Offset(state.gravityComponent * scale, 0),
      Colors.orange, 'G∥');
    
    // 法向力 (垂直于斜面向外)
    _drawArrow(canvas, Offset.zero,
      Offset(-state.normalForce * scale * sin(0), -state.normalForce * scale),
      Colors.green, 'N');
    
    // 摩擦力 (沿斜面向上)
    _drawArrow(canvas, Offset.zero,
      Offset(-state.frictionForce * scale, 0),
      Colors.purple, 'f');
  }
}
```

#### 4.1.4 公式联动

```
当 angle=30°, mass=2kg, μ=0.3 时:

受力分析:
  G  = mg       = 2 × 9.8 = 19.6 N  ↓
  G∥ = mg sinθ  = 19.6 × sin30° = 9.8 N  (沿斜面向下)
  N  = mg cosθ  = 19.6 × cos30° = 17.0 N  (垂直斜面向外)
  f  = μN       = 0.3 × 17.0 = 5.1 N      (沿斜面向上)
  
  F合 = G∥ - f  = 9.8 - 5.1 = 4.7 N      (沿斜面向下)
  a  = F合/m    = 4.7 / 2 = 2.35 m/s²
```

```dart
class ProjectileSimulation implements PhysicsSimulation {
  double initialSpeed = 20.0;   // 初速度 (m/s)
  double launchAngle = 45.0;    // 发射角度 (°)
  double gravity = 9.8;         // 重力加速度 (m/s²)
  double initialHeight = 0.0;   // 初始高度 (m)
  double airResistance = 0.0;   // 空气阻力系数 (可选)
  
  // 计算量
  double get vx => initialSpeed * cos(launchAngle * pi / 180);
  double get vy => initialSpeed * sin(launchAngle * pi / 180);
  double get timeOfFlight => (vy + sqrt(vy*vy + 2*gravity*initialHeight)) / gravity;
  double get maxRange => vx * timeOfFlight;
  double get maxHeight => initialHeight + vy*vy / (2*gravity);
  
  @override
  void step(double dt) {
    final vx = state.bodies[0].velocity.x;
    final vy = state.bodies[0].velocity.y;
    
    // 无空气阻力: a_x=0, a_y=-g
    state.bodies[0].position.x += vx * dt;
    state.bodies[0].position.y += vy * dt - 0.5 * gravity * dt * dt;
    state.bodies[0].velocity.y -= gravity * dt;
    
    // 记录轨迹
    state.trajectories.add(state.bodies[0].position.clone());
  }
}
```

#### 4.3.2 电路求解 (基尔霍夫定律)

```dart
class CircuitSolver {
  /// 基于改进节点分析法 (MNA) 求解电路
  /// 返回各元件的电压、电流值
  CircuitSolution solve(List<CircuitComponent> components, List<Wire> wires) {
    // 1. 构建拓扑图
    final graph = _buildGraph(components, wires);
    
    // 2. 识别独立回路
    final loops = _findIndependentLoops(graph);
    
    // 3. 建立方程组 (基尔霍夫电压定律 + 电流定律)
    final equations = <List<double>>[];
    final constants = <double>[];
    
    for (final loop in loops) {
      final equation = List.filled(loops.length + 1, 0.0);
      for (final edge in loop.edges) {
        final comp = components.firstWhere((c) => c.id == edge.componentId);
        if (comp.type == ComponentType.battery) {
          constants[loop.index] += comp.emf * (edge.direction ? 1 : -1);
        } else if (comp.type == ComponentType.resistor) {
          equation[loop.index] += comp.resistance;
        }
      }
      equations.add(equation);
    }
    
    // 4. 高斯消元求解
    final currents = _solveLinearSystem(equations, constants);
    
    // 5. 计算各元件的电压、功率
    return _buildSolution(components, currents);
  }
}

class CircuitSolution {
  final Map<String, double> voltages;  // componentId -> 电压 (V)
  final Map<String, double> currents;  // componentId -> 电流 (A)
  final Map<String, double> powers;    // componentId -> 功率 (W)
  final double totalResistance;        // 等效电阻
  final bool isValid;                  // 是否有解 (短路/断路检测)
  final String? errorMessage;          // 错误信息 (如短路)
}
```

#### 4.4.1 弹簧振子

```dart
class SpringOscillatorSimulation implements PhysicsSimulation {
  double mass = 0.5;           // 质量 (kg)
  double stiffness = 50.0;     // 劲度系数 (N/m)
  double damping = 0.05;       // 阻尼系数
  double amplitude = 0.1;      // 初始振幅 (m)

  // 理论值 (用于公式联动校验)
  double get omega => sqrt(stiffness / mass);          // 角频率
  double get period => 2 * pi / omega;                 // 周期
  double get frequency => 1 / period;                  // 频率

  /// x(t) = A·cos(ωt+φ)·e^(-γt), γ = c/2m
  @override
  void step(double dt) {
    final gamma = damping / (2 * mass);
    state.time += dt;
    final t = state.time;
    final x = amplitude * cos(omega * t) * exp(-gamma * t);
    final v = -amplitude * omega * sin(omega * t) * exp(-gamma * t)
              - gamma * x;

    state.bodies[0].position.x = x;
    state.bodies[0].velocity.x = v;

    // 能量计算 (用于能量-时间图表)
    state.computedValues['kinetic'] = 0.5 * mass * v * v;
    state.computedValues['potential'] = 0.5 * stiffness * x * x;
    state.computedValues['total'] =
        state.computedValues['kinetic']! + state.computedValues['potential']!;
  }
}
```

交互要点：

- 拖拽物块改变初始振幅，松手后从静止释放（v=0 相位重置）
- 参数面板调节 m/k/c，公式面板实时更新 T=2π√(m/k) 的理论值
- 图表叠加「理论曲线」与「实测曲线」（阻尼时分离，无阻尼时重合），帮助学生验证模型

```dart
class PendulumSimulation implements PhysicsSimulation {
  double length = 1.0;         // 摆长 (m)
  double gravity = 9.8;        // 重力加速度
  double angle0 = 15.0;        // 初始摆角 (°)

  double get periodSmallAngle => 2 * pi * sqrt(length / gravity);

  @override
  void step(double dt) {
    // 大角度需用椭圆积分或数值积分，此处采用半隐式欧拉
    final body = state.bodies[0];
    final theta = body.rotation;                    // 摆角
    final alpha = -(gravity / length) * sin(theta); // 角加速度

    body.angularVelocity += alpha * dt;
    body.rotation += body.angularVelocity * dt;

    // 摆球位置由约束决定 (刚性杆)
    body.position = Vector2(
      length * sin(body.rotation),
      -length * cos(body.rotation),
    );
  }
}
```

- 小角度（θ<10°）时公式面板展示近似公式 T≈2π√(L/g)，大角度切换为「数值积分模式」标注
- 支持改变重力参数（地球 9.8 / 月球 1.6 / 自定义），直观对比周期变化

### 4.5 碰撞与动量守恒实验

```dart
class CollisionSimulation implements PhysicsSimulation {
  double massA = 1.0, massB = 2.0;
  double vA0 = 3.0, vB0 = -1.0;  // 初速度 (m/s)
  bool elastic = true;            // 弹性/非弹性

  // 理论结果 (弹性碰撞解析解)
  double get vA1 => ((massA - massB) * vA0 + 2 * massB * vB0) / (massA + massB);
  double get vB1 => ((massB - massA) * vB0 + 2 * massA * vA0) / (massA + massB);

  @override
  void step(double dt) {
    super.step(dt); // 位移推进

    final a = state.bodies[0], b = state.bodies[1];
    final collision = CollisionDetector.detect(a, b);
    if (collision != null) {
      if (elastic) {
        CollisionResolver.resolve(collision); // 冲量法，e=1
      } else {
        // 完全非弹性: 碰后共速
        final vCommon = (a.mass * a.velocity.x + b.mass * b.velocity.x)
                        / (a.mass + b.mass);
        a.velocity.x = vCommon;
        b.velocity.x = vCommon;
        a.color = b.color = Colors.grey; // 粘连体视觉反馈
      }
      state.computedValues['momentum_before'] = massA * vA0 + massB * vB0;
      state.computedValues['momentum_after'] =
          a.mass * a.velocity.x + b.mass * b.velocity.x;
    }
  }
}
```

- 三模式切换：弹性 / 完全非弹性 / 自定义恢复系数 (0~1 滑块)
- 数据面板实时显示 p_before、p_after 与相对误差，验证动量守恒
- 质量比极端情况（mA:mB = 1:100）给出「近似不动靶」现象观察任务

```dart
/// 实验会话全局状态
@riverpod
class PhysicsLabController extends _$PhysicsLabController {
  late PhysicsSimulation _simulation;
  PhysicsEngine? _engine;
  AnimationController? _ticker;

  @override
  PhysicsLabState build() {
    ref.onDispose(() {
      _ticker?.dispose();
      _engine?.dispose();
    });
    return const PhysicsLabState.initial();
  }

  /// 加载实验配置 (来自服务端实验数据管理服务)
  Future<void> loadExperiment(String experimentId) async {
    state = state.copyWith(status: LabStatus.loading);
    try {
      final config = await ref
          .watch(physicsLabRepositoryProvider)
          .fetchExperimentConfig(experimentId);
      _simulation = _createSimulation(config);
      _engine = PhysicsEngine(_simulation);
      state = PhysicsLabState.ready(
        config: config,
        parameters: _defaultParams(config),
      );
    } on LabException catch (e) {
      state = state.copyWith(status: LabStatus.error, errorCode: e.code);
    }
  }

  /// 播放/暂停
  void togglePlay() {
    if (state.status != LabStatus.ready && state.status != LabStatus.running
        && state.status != LabStatus.paused) return;

    if (state.status == LabStatus.running) {
      _ticker?.stop();
      state = state.copyWith(status: LabStatus.paused);
    } else {
      _startTicker();
      state = state.copyWith(status: LabStatus.running);
    }
  }

  void _startTicker() {
    _ticker ??= AnimationController(
      vsync: ref.read(vsyncProvider),
      duration: const Duration(days: 1), // 循环由 Timer 驱动
    );

    // 固定步长 120Hz 物理 + 可变帧率渲染
    _engine!.start(
      physicsHz: 120,
      onState: (simState) {
        state = state.copyWith(
          simulationState: simState,
          status: LabStatus.running,
        );
        _maybeRecordDataPoint(simState);
      },
    );
  }

  /// 参数调节 (滑块/输入统一入口)
  void updateParameter(String key, double value) {
    final def = state.config?.parameterDefs
        .firstWhereOrNull((d) => d.key == key);
    if (def == null) return;

    // 钳制到合法范围
    final clamped = value.clamp(def.min, def.max);
    _simulation.updateParameter(key, clamped);

    // 参数变化是否重置模拟由参数定义决定
    if (def.resetsOnChange) {
      reset();
    } else {
      state = state.copyWith(
        parameters: state.parameters.map((k, v) =>
            MapEntry(k, k == key ? clamped : v)),
      );
    }
  }

  void reset() {
    _engine?.stop();
    _simulation.reset(state.parameters);
    state = state.copyWith(
      status: LabStatus.ready,
      simulationState: null,
      recordedPoints: [],
    );
  }
}
```

### 5.2 实验会话状态机

```
                 loadExperiment
   initial ───────────────────────► loading ──成功──► ready
                                       │                │
                                       │失败             │ togglePlay
                                       ▼                ▼
                                     error ◄────── paused ◄────► running
                                      │ ▲               │          │
                                      │ └──── 重试 ──────┘          │
                                      ▼                             │ 完成/停止
                               (展示错误页+重试)                 completed
```

| 状态 | 进入条件 | 退出条件 | UI 表现 |
|------|---------|---------|---------|
| initial | 页面创建 | 调用 loadExperiment | 空白 + 加载动画 |
| loading | 配置拉取中 | 成功→ready / 失败→error | 骨架屏 |
| ready | 配置就绪，模拟未开始 | togglePlay→running | 静态场景 + 参数面板可用 |
| running | 模拟推进中 | togglePlay→paused / 完成→completed | 动画播放中 |
| paused | 用户暂停 | togglePlay→running / reset→ready | 静态冻结帧 + 继续按钮 |
| completed | 模拟完成（如抛体落地/碰撞结束） | reset→ready | 结果摘要 + 数据图表 |
| error | 配置拉取/初始化失败 | 重试→loading | 错误页 + 重试按钮 |

状态守卫：

- G1 `running` 状态下禁止切换实验类型，需先 reset 或确认丢弃当前数据
- G2 `error` 状态下参数面板与画布不可交互，仅保留重试与返回
- G3 页面切后台 (`AppLifecycleState.paused`) 自动转 `paused`，回到前台保持暂停帧不自动续播（防沉迷与省电对齐《客户端-应用生命周期与后台任务调度-详细设计》）
- G4 `completed` 状态下数据已冻结，参数调节需先 reset

### 5.3 物理引擎驱动循环

```dart
class PhysicsEngine {
  final PhysicsSimulation simulation;
  Timer? _timer;
  Duration _accumulator = Duration.zero;
  static const _fixedStep = Duration(microseconds: 8333); // 120Hz

  void start({
    required int physicsHz,
    required void Function(SimulationState) onState,
  }) {
    final step = Duration(microseconds: (1e6 / physicsHz).round());
    var lastTick = DateTime.now();

    _timer = Timer.periodic(const Duration(milliseconds: 8), (_) {
      final now = DateTime.now();
      _accumulator += now.difference(lastTick);
      lastTick = now;

      // 追赶上限: 最多补 4 步，防螺旋死亡
      var steps = 0;
      while (_accumulator >= step && steps < 4) {
        simulation.step(step.inMicroseconds / 1e6);
        _accumulator -= step;
        steps++;
      }
      if (steps == 4) _accumulator = Duration.zero;

      onState(simulation.state);
    });
  }

  void stop() => _timer?.cancel();
}
```

上报成功后由服务端扇出（客户端不直接写其他模块）：

- 实验时长计入学习时长统计（口径归《服务端-学生学习时长跨模块统一归因与对账引擎》）
- 完成事件 `lab.experiment.completed` 驱动知识点掌握度信号（强度 0.5，弱于正式测评，与即时练习引擎口径一致）
- 操作评分（若有评分任务）进入学情分析，权限与可见度归家长端分级管控

## 8. 错误处理与降级

### 8.1 错误码

| 错误码 | 说明 | 客户端处理 |
|--------|------|------------|
| `PHY_EXP_001` | 实验配置不存在 | 提示并返回实验列表 |
| `PHY_EXP_002` | 实验资源未下载 | 引导下载资源包（断点续传） |
| `PHY_EXP_003` | 配置版本不匹配 | 提示更新并拉取新配置 |
| `PHY_CIR_001` | 电路求解失败（奇异矩阵） | 提示检查电路连接，保留编辑现场 |
| `PHY_CIR_002` | 电路短路保护 | 导线变红闪烁 + 提示，不解算电流 |
| `PHY_SIM_001` | 数值发散（NaN/Inf 检测） | 自动暂停并提示减小步长/参数 |
| `PHY_SIM_002` | 模拟超时（运行 >10min） | 自动暂停，提示保存数据后重置 |
| `PHY_QUOTA_001` | 今日实验额度用尽 | 引导会员/明日再来，展示剩余免费实验 |

客户端错误码与服务端实验域 `ExperimentErrorCode`（E2E 文档 §10.2）映射：

| 服务端码 | 客户端码 |
|---------|---------|
| EXPERIMENT_NOT_FOUND(10001) | PHY_EXP_001 |
| RESOURCE_PACKAGE_INVALID(10004) | PHY_EXP_002 |
| CONFIG_VERSION_CONFLICT(10003) | PHY_EXP_003 |
| QUOTA_EXCEEDED_DAILY(14001) | PHY_QUOTA_001 |

### 8.2 降级策略

```text
公式渲染组件异常      → 降级为纯文本公式 (如 "T = 2π√(L/g)")
图表绘制异常          → 降级为数据表格展示
120Hz 物理循环掉帧    → 自动降为 60Hz，再不行暂停数据记录保播放
低端设备 (RAM<3GB)    → 关闭发光/模糊特效，轨迹点上限减半
资源包缺失            → 使用内嵌精简配置（仅 5 个核心实验可用）
网络断开              → 实验可离线进行，记录排队补传
```

## 9. 性能优化

| 优化项 | 策略 | 目标 |
|-------|------|------|
| 渲染 | CustomPainter 局部重绘（ RepaintBoundary 隔离参数面板），力矢量/轨迹分层绘制 | 60fps，帧耗时 P95<12ms |
| 物理循环 | 固定步长 120Hz + 追加上限 4 步，防死亡螺旋 | 单步耗时 P99<2ms |
| 内存 | 轨迹点环形缓冲 (上限 2000 点)，超限丢弃最旧 | 单实验内存 <20MB |
| 电量 | 切后台 500ms 内停止 ticker；静置 5min 自动暂停 | 后台零功耗 |
| 启动 | 实验配置懒加载 + 引擎延迟初始化，首屏仅加载列表 | 列表页首帧 <300ms |

## 12. 开发优先级与验收

| 阶段 | 范围 | 优先级 |
|------|------|--------|
| P0 | 斜面滑块 + 抛体运动 + 基础渲染框架 + 参数面板 | 必做 |
| P1 | 电路搭建与求解 + 公式联动 + 数据记录上报 | 必做 |
| P2 | 弹簧振子/单摆/碰撞 + 图表绘制 + 学习报告联动 | 应做 |
| P3 | 电磁学/波动 + 题目系统集成 + 多轨迹对比 | 可延后 |

### 12.1 验收场景

1. 斜面实验：θ=30°、m=2kg、μ=0.3 时，公式面板显示 a=2.35 m/s²，物块沿斜面加速下滑
2. 参数越界：角度滑块拖至 95°，自动钳制到配置上限 90° 并提示
3. 暂停恢复：播放中切后台再回前台，画面停留在暂停帧，点击继续从原状态恢复
4. 电路短路：电池正负极直连，触发 PHY_CIR_002，导线变红闪烁，无发光动画
5. 弱网上报：飞行模式下完成实验，关闭飞行模式回到前台后记录自动补传且不重复计数
6. 数值发散：将抛体初速度设为 1e6，模拟 2 秒内检测 NaN 并自动暂停提示
7. 低端机降级：RAM 2GB 设备上发光特效关闭，轨迹点上限 1000，播放流畅无掉帧
8. 分龄展示：初中账号进入单摆实验，公式为中文标注卡片；切换高中账号展示 LaTeX 推导
9. 断电保护：播放中杀进程，重启后 pending 记录存在并成功补传
10. 额度用尽：免费用户第 6 次发起实验弹出 PHY_QUOTA_001 引导
