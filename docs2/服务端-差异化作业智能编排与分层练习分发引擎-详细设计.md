## 1. 功能概述

### 1.1 背景与目标

传统作业布置采用"一刀切"模式，所有学生完成相同题目。对于学优生可能过于简单导致效率浪费，对于学困生可能难度过高造成挫败感。差异化作业（Differentiated Homework / 分层作业）是教育领域公认的有效策略，核心思想是：

- **基础层学生**：侧重基础概念巩固和简单应用，夯实根基
- **提高层学生**：侧重知识综合应用和变式训练，提升能力
- **拓展层学生**：侧重深度推理和跨知识综合，挑战难题

本引擎的目标是：**自动评估学生能力层级，根据教师设定的分层规则智能编排差异化作业，实现"因材施教"的个性化练习分发。**

### 1.2 核心功能

| 功能 | 说明 |
|------|------|
| 学生能力分层 | 基于近期答题数据、错题率、知识点掌握度自动划分 A/B/C 三层 |
| 分层规则配置 | 教师可设定每层的题目数量、难度区间、知识点覆盖要求 |
| 智能题目编排 | 从题库中按规则自动抽题组卷，保证同知识点不同难度 |
| 差异化分发 | 按学生所属层级下发对应的作业变体 |
| 完成度分析 | 按层分别统计完成率、正确率、用时分布 |
| 动态调层 | 基于连续多次作业表现自动调整学生层级 |

### 1.3 用户角色

| 角色 | 权限 |
|------|------|
| 教师 | 创建分层作业模板、查看分层分析、手动调整学生层级 |
| 学生 | 接收并完成属于自己层级的作业 |
| 家长 | 查看孩子分层作业完成情况（只读） |
| 教研管理员 | 查看全校/年级分层作业使用统计 |

## 5. 学生能力分层算法

### 5.1 分层综合评分模型

学生能力分层基于多维度信号的综合评分（AbilityScore），范围 `0.0 ~ 1.0`：

```
AbilityScore = w1 × RecentAccuracy       (近30天答题正确率)
             + w2 × KnowledgeMastery     (知识点平均掌握度)
             + w3 × DifficultyScore      (近30天题目平均难度系数)
             + w4 × TrendScore           (成绩趋势分)
             + w5 × ErrorRecoveryRate    (错题订正成功率)
```

**权重默认值：**

| 维度 | 权重 | 说明 |
|------|------|------|
| RecentAccuracy | 0.30 | 近30天所有答题的正确率 |
| KnowledgeMastery | 0.25 | 作业涉及知识点的平均掌握度 |
| DifficultyScore | 0.20 | 近30天答对题目的加权平均难度 |
| TrendScore | 0.15 | 最近7天 vs 前7天的正确率变化 |
| ErrorRecoveryRate | 0.10 | 错题重新作答的正确率 |

### 5.2 分层阈值映射

```java
public class TierClassifier {

    // 默认分层阈值，可通过配置覆盖
    private static final double FOUNDATION_THRESHOLD = 0.40;  // < 0.40 → C层
    private static final double INTERMEDIATE_THRESHOLD = 0.70; // 0.40~0.70 → B层
    // > 0.70 → A层

    /**
     * 根据综合能力分判定层级
     *
     * @param abilityScore 能力分 [0.0, 1.0]
     * @param confidenceLevel 置信度 [0.0, 1.0]，低于阈值时不调层
     * @param currentTier 当前层级
     * @return 建议层级
     */
    public AbilityTier classify(double abilityScore, double confidenceLevel,
                                 AbilityTier currentTier) {
        AbilityTier suggestedTier = doClassify(abilityScore);

        // 置信度不足时保持当前层级
        if (confidenceLevel < MIN_CONFIDENCE_THRESHOLD) {
            return currentTier;
        }

        // 防抖：仅在跨阈值超过 hysteresis 时才调层
        if (suggestedTier != currentTier) {
            double hysteresis = 0.05; // 5% 防抖区间
            double boundary = getBoundary(currentTier, suggestedTier);
            if (Math.abs(abilityScore - boundary) < hysteresis) {
                return currentTier; // 在防抖区间内，不调整
            }
        }

        return suggestedTier;
    }

    private AbilityTier doClassify(double score) {
        if (score < FOUNDATION_THRESHOLD) return AbilityTier.FOUNDATION;
        if (score < INTERMEDIATE_THRESHOLD) return AbilityTier.INTERMEDIATE;
        return AbilityTier.ADVANCED;
    }

    private double getBoundary(AbilityTier from, AbilityTier to) {
        if (from == AbilityTier.FOUNDATION && to == AbilityTier.INTERMEDIATE)
            return FOUNDATION_THRESHOLD;
        if (from == AbilityTier.INTERMEDIATE && to == AbilityTier.ADVANCED)
            return INTERMEDIATE_THRESHOLD;
        if (from == AbilityTier.INTERMEDIATE && to == AbilityTier.FOUNDATION)
            return FOUNDATION_THRESHOLD;
        if (from == AbilityTier.ADVANCED && to == AbilityTier.INTERMEDIATE)
            return INTERMEDIATE_THRESHOLD;
        return 0.5; // 默认
    }
}
```

### 5.3 冷启动策略

新学生（答题样本 < 5 次）的分层策略：

| 策略 | 条件 | 初始层级 |
|------|------|----------|
| 年级默认 | 无任何数据 | INTERMEDIATE (B层) |
| 入学测试 | 注册时完成能力诊断测试 | 根据测试结果分层 |
| 快速评估 | 前3次作业 | INTERMEDIATE，3次后自动评估 |
| 教师指定 | 教师手动设置 | 教师指定值，标记 manual_override |

### 5.4 置信度计算

```java
/**
 * 分层置信度：基于样本量和数据一致性
 *
 * @param sampleSize 近30天答题次数
 * @param scoreVariance 各维度评分方差
 * @return 置信度 [0.0, 1.0]
 */
public double calculateConfidence(int sampleSize, double scoreVariance) {
    // 样本量因子: sigmoid 映射，30题以上趋于饱和
    double sampleFactor = 1.0 - Math.exp(-sampleSize / 10.0);

    // 一致性因子: 方差越小置信度越高
    double consistencyFactor = 1.0 / (1.0 + scoreVariance * 4.0);

    return sampleFactor * 0.6 + consistencyFactor * 0.4;
}
```

### 6.2 题目打分函数

对候选池中的每道题目计算综合适配分数：

```java
/**
 * 题目适配度打分
 * 分数越高，被选中的概率越大
 */
public double scoreQuestion(
        Question question,
        TierTemplate template,
        Set<Long> coveredKnowledgePoints,
        int questionsAnsweredRecently, // 学生最近30天答题次数中该题出现次数
        double targetDifficultyMidpoint) {

    // 1. 难度匹配度 (0-1): 题目难度与目标区间中点的接近程度
    double difficultyFit = 1.0 - Math.abs(
        question.getDifficulty() - targetDifficultyMidpoint
    );
    difficultyFit = Math.max(0, difficultyFit);

    // 2. 知识点覆盖增益 (0-1): 选中该题能覆盖的新知识点比例
    Set<Long> newKps = new HashSet<>(question.getKnowledgePointIds());
    newKps.removeAll(coveredKnowledgePoints);
    double coverageGain = (double) newKps.size() / Math.max(1,
        question.getKnowledgePointIds().size());

    // 3. 新鲜度 (0-1): 未做过的题目得分更高
    double freshness = questionsAnsweredRecently == 0 ? 1.0
        : 1.0 / (1.0 + questionsAnsweredRecently);

    // 4. 题型多样性增益: 若该题型尚未出现则加分
    double typeDiversityBonus = coveredQuestionTypes.contains(question.getType())
        ? 0.0 : 0.15;

    // 加权求和
    return difficultyFit      * 0.40
         + coverageGain       * 0.25
         + freshness          * 0.20
         + typeDiversityBonus * 0.15;
}
```

### 6.3 降级策略

当某一知识点 + 难度组合的题库题目不足时，按以下优先级降级：

```java
public class OrchestrationFallbackHandler {

    /**
     * 降级处理链（按优先级）
     */
    private static final List<FallbackStrategy> STRATEGIES = List.of(
        // 策略1: 扩大难度范围 ±0.1
        new WidenDifficultyStrategy(0.10),
        // 策略2: 允许跨章节同类知识点题目
        new CrossChapterSameKpStrategy(),
        // 策略3: 减少该层题目数量（不少于模板要求量的 70%）
        new ReduceCountStrategy(0.70),
        // 策略4: 使用通用题库（非教材配套题目）
        new UseGenericPoolStrategy(),
        // 策略5: 标记缺题，通知教师补充
        new FlagShortageStrategy()
    );

    public OrchestrationResult applyFallback(
            OrchestrationContext ctx, OrchestrationResult currentResult) {

        for (FallbackStrategy strategy : STRATEGIES) {
            if (currentResult.isSatisfied()) {
                break;
            }
            currentResult = strategy.apply(ctx, currentResult);
            ctx.recordFallback(strategy.getName());
        }
        return currentResult;
    }
}
```

### 8.3 状态机实现

```java
public enum HomeworkStatus {
    DRAFT, PUBLISHED, CLOSED, ARCHIVED, DELETED, CANCELLED
}

public enum AssignmentStatus {
    ASSIGNED, IN_PROGRESS, SUBMITTED, GRADED, EXPIRED, REGRADED
}

/**
 * 作业状态转换校验
 */
public class HomeworkStateMachine {

    private static final Map<HomeworkStatus, Set<HomeworkStatus>> TRANSITIONS = Map.of(
        HomeworkStatus.DRAFT,     EnumSet.of(HomeworkStatus.PUBLISHED, HomeworkStatus.DELETED),
        HomeworkStatus.PUBLISHED, EnumSet.of(HomeworkStatus.CLOSED, HomeworkStatus.CANCELLED),
        HomeworkStatus.CLOSED,    EnumSet.of(HomeworkStatus.ARCHIVED),
        HomeworkStatus.ARCHIVED,  EnumSet.of(),
        HomeworkStatus.CANCELLED, EnumSet.of(),
        HomeworkStatus.DELETED,   EnumSet.of()
    );

    public void validateTransition(HomeworkStatus from, HomeworkStatus to) {
        Set<HomeworkStatus> allowed = TRANSITIONS.getOrDefault(from, EnumSet.noneOf(HomeworkStatus.class));
        if (!allowed.contains(to)) {
            throw new IllegalStateTransitionException(
                String.format("非法状态转换: %s → %s (允许: %s)", from, to, allowed));
        }
    }
}
```

### 10.1 定时评估任务

```java
/**
 * 每天凌晨 02:00 执行学生层级评估
 * 评估频率：每天一次
 * 评估范围：过去30天有答题活动的学生
 */
@XxlJob("studentTierEvaluationJob")
public void evaluateStudentTiers() {
    // 1. 获取需要评估的学生列表
    List<StudentTierEvalTask> tasks = tierProfileRepository
        .findStudentsNeedingEvaluation(LocalDateTime.now().minusDays(30));

    int batchSize = 200;
    Lists.partition(tasks, batchSize).forEach(batch -> {
        // 2. 并行计算每个学生的能力分
        Map<Long, AbilityEvaluation> evaluations = batch.parallelStream()
            .collect(Collectors.toMap(
                StudentTierEvalTask::getStudentId,
                this::evaluateAbility
            ));

        // 3. 判定是否需要调层
        for (StudentTierEvalTask task : batch) {
            AbilityEvaluation eval = evaluations.get(task.getStudentId());
            AbilityTier currentTier = task.getCurrentTier();
            AbilityTier suggestedTier = tierClassifier.classify(
                eval.getAbilityScore(),
                eval.getConfidence(),
                currentTier
            );

            // 手动覆盖的不自动调整
            if (task.isManualOverride()) {
                continue;
            }

            if (suggestedTier != currentTier) {
                // 4. 记录调层历史
                saveTierHistory(task.getStudentId(), task.getSubjectId(),
                    currentTier, suggestedTier, "AUTO_EVALUATION", eval);

                // 5. 更新层级档案
                updateTierProfile(task.getStudentId(), task.getSubjectId(),
                    suggestedTier, eval);

                // 6. 发送通知
                if (suggestedTier.ordinal() > currentTier.ordinal()) {
                    notifyTierUpgrade(task.getStudentId(), task.getSubjectId(), suggestedTier);
                }
            }
        }
    });
}
```

### 10.2 作业完成触发的即时评估

每次学生提交作业后，触发即时评估（事件驱动）：

```java
@EventListener
@Async
public void onHomeworkSubmitted(HomeworkSubmittedEvent event) {
    Long studentId = event.getStudentId();
    Long subjectId = event.getSubjectId();

    // 获取最新能力评估（含本次作业数据）
    AbilityEvaluation eval = evaluateAbility(studentId, subjectId);

    StudentTierProfile profile = tierProfileRepository
        .findByStudentIdAndSubjectId(studentId, subjectId);

    if (profile == null || profile.isManualOverride()) {
        return;
    }

    AbilityTier suggested = tierClassifier.classify(
        eval.getAbilityScore(),
        eval.getConfidence(),
        profile.getCurrentTier()
    );

    if (suggested != profile.getCurrentTier()) {
        // 连续N次评估一致才调层（防抖）
        int consecutiveCount = getConsecutiveSuggestionCount(studentId, subjectId, suggested);
        if (consecutiveCount >= 2) {  // 连续2次建议调层
            applyTierChange(profile, suggested, eval, "POST_HOMEWORK_EVALUATION");
        }
```

### 11.1 编排引擎核心

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class HomeworkOrchestrationEngine {

    private final QuestionService questionService;
    private final AnalyticsService analyticsService;
    private final TierClassifier tierClassifier;
    private final OrchestrationFallbackHandler fallbackHandler;
    private final TierAssignmentRepository assignmentRepo;
    private final OrchestrationLogRepository logRepo;

    /**
     * 为单个学生编排差异化作业
     */
    @Transactional
    public OrchestrationResult orchestrate(Long homeworkId, Long studentId,
                                           AbilityTier tier, TierTemplate template,
                                           List<Long> knowledgePointIds,
                                           List<Long> recentQuestionIds) {
        long startTime = System.currentTimeMillis();

        // 1. 获取学生层级对应的目标难度
        double targetMidpoint = (template.getDifficultyMin() + template.getDifficultyMax()) / 2.0;

        // 2. 从题库检索候选题
        List<Question> candidates = questionService.searchQuestions(
            QuestionSearchRequest.builder()
                .knowledgePointIds(knowledgePointIds)
                .difficultyMin(template.getDifficultyMin())
                .difficultyMax(template.getDifficultyMax())
                .excludeIds(recentQuestionIds)
                .build()
        );

        // 3. 注入必选题
        List<Question> mustInclude = questionService.findByIds(template.getMustIncludeQuestionIds());
        Set<Long> selectedIds = mustInclude.stream()
            .map(Question::getId)
            .collect(Collectors.toSet());

        // 4. 贪心选择剩余题目
        Set<Long> coveredKps = new HashSet<>();
        Set<QuestionType> coveredTypes = new HashSet<>();

        // 先处理必选题的知识点覆盖
        for (Question q : mustInclude) {
            coveredKps.addAll(q.getKnowledgePointIds());
            coveredTypes.add(q.getType());
        }

        List<Question> remaining = new ArrayList<>(mustInclude);
        int remainingSlots = template.getQuestionCount() - mustInclude.size();

        // 打分排序候选题
        List<ScoredQuestion> scored = candidates.stream()
            .filter(q -> !selectedIds.contains(q.getId()))
            .map(q -> new ScoredQuestion(q, scoreQuestion(
                q, template, coveredKps,
                countRecentAnswered(q.getId(), recentQuestionIds),
                targetMidpoint)))
            .sorted(Comparator.comparingDouble(ScoredQuestion::getScore).reversed())
            .collect(Collectors.toList());

        // 贪心选择
        for (ScoredQuestion sq : scored) {
            if (remainingSlots <= 0) break;
            Question q = sq.getQuestion();

            // 检查是否需要更多知识点覆盖
            boolean addsNewKp = q.getKnowledgePointIds().stream()
                .anyMatch(kp -> !coveredKps.contains(kp));

            remaining.add(q);
            selectedIds.add(q.getId());
            coveredKps.addAll(q.getKnowledgePointIds());
            coveredTypes.add(q.getType());
            remainingSlots--;
        }

        // 5. 降级检查
        OrchestrationResult result = new OrchestrationResult(
            remaining, coveredKps, knowledgePointIds);
        if (!result.isSatisfied(template)) {
            OrchestrationContext ctx = OrchestrationContext.builder()
                .studentId(studentId)
                .tier(tier)
                .template(template)
                .knowledgePointIds(knowledgePointIds)
                .excludeIds(recentQuestionIds)
                .build();
            result = fallbackHandler.applyFallback(ctx, result);
        }

        // 6. 构建题目快照
        List<QuestionSnapshot> snapshot = IntStream.range(0, remaining.size())
            .mapToObj(i -> {
                Question q = remaining.get(i);
                int score = distributeScore(q, template.getTotalScore(), remaining.size(), i);
                return new QuestionSnapshot(q.getId(), score, i + 1);
            })
            .collect(Collectors.toList());

        // 7. 保存分配记录
        TierAssignment assignment = TierAssignment.builder()
            .homeworkId(homeworkId)
            .studentId(studentId)
            .assignedTier(tier)
            .questionSnapshot(JsonUtils.toJson(snapshot))
            .status(AssignmentStatus.ASSIGNED)
            .totalScore(template.getTotalScore())
            .build();
        assignmentRepo.save(assignment);

        // 8. 记录编排日志
        logRepo.save(HomeworkOrchestrationLog.builder()
            .homeworkId(homeworkId)
            .studentId(studentId)
            .tier(tier.name())
            .candidateCount(candidates.size())
            .selectedCount(remaining.size())
            .fallbackUsed(result.isFallbackUsed())
            .fallbackReason(result.getFallbackReason())
            .orchestrationTimeMs((int) (System.currentTimeMillis() - startTime))
            .build());

        return result;
    }

    /**
     * 批量编排（班级级别）
     */
    public BatchOrchestrationResult processBatch(OrchestrationTaskMessage msg) {
        Map<Long, AbilityTier> studentTiers = loadStudentTiers(msg.getStudentIds(), msg.getSubjectId());
        Map<AbilityTier, TierTemplate> templateMap = msg.getTierTemplates().stream()
            .collect(Collectors.toMap(TierTemplateMsg::getTier, t -> t));

        List<Long> allKps = knowledgePointService.getByHomeworkId(msg.getHomeworkId());

        BatchOrchestmentResult.Builder resultBuilder = BatchOrchestrationResult.builder()
            .homeworkId(msg.getHomeworkId());

        int success = 0, fallback = 0, failed = 0;
        for (Long studentId : msg.getStudentIds()) {
            try {
                AbilityTier tier = studentTiers.get(studentId);
                TierTemplate template = templateMap.get(tier);

                List<Long> recentIds = analyticsService.getRecentQuestionIds(studentId, 30);

                OrchestrationResult r = orchestrate(
                    msg.getHomeworkId(), studentId, tier, template, allKps, recentIds);

                if (r.isFallbackUsed()) fallback++;
                else success++;
            } catch (Exception e) {
                log.error("编排失败: homework={}, student={}", msg.getHomeworkId(), studentId, e);
                failed++;
            }
        }

        return resultBuilder
            .successCount(success)
            .fallbackCount(fallback)
            .failedCount(failed)
            .build();
    }
}
```

### 11.2 能力评估器

```java
@Service
@RequiredArgsConstructor
public class AbilityEvaluator {

    private final AnalyticsService analyticsService;
    private final KnowledgePointService kpService;

    // 默认权重
    private static final double W_ACCURACY = 0.30;
    private static final double W_MASTERY = 0.25;
    private static final double W_DIFFICULTY = 0.20;
    private static final double W_TREND = 0.15;
    private static final double W_RECOVERY = 0.10;

    /**
     * 综合能力评估
     */
    public AbilityEvaluation evaluate(Long studentId, Long subjectId) {
        // 获取近30天数据
        LearningMetrics30D metrics = analyticsService.getMetrics30D(studentId, subjectId);

        // 计算各维度得分
        double accuracy = metrics.getCorrectRate();           // 正确率
        double mastery = metrics.getAvgKnowledgeMastery();     // 知识点掌握度
        double difficulty = metrics.getWeightedDifficulty();   // 加权平均难度
        double trend = calculateTrend(metrics);               // 趋势分
        double recovery = metrics.getErrorRecoveryRate();     // 错题订正率

        // 加权综合
        double abilityScore = accuracy * W_ACCURACY
            + mastery * W_MASTERY
            + difficulty * W_DIFFICULTY
            + trend * W_TREND
            + recovery * W_RECOVERY;

        abilityScore = clamp(abilityScore, 0.0, 1.0);

        // 计算置信度
        double[] dimensionScores = {accuracy, mastery, difficulty, trend, recovery};
        double variance = calculateVariance(dimensionScores);
        double confidence = calculateConfidence(metrics.getSampleSize(), variance);

        return AbilityEvaluation.builder()
            .abilityScore(abilityScore)
            .confidence(confidence)
            .accuracy(accuracy)
            .mastery(mastery)
            .difficulty(difficulty)
            .trend(trend)
            .recovery(recovery)
            .sampleSize(metrics.getSampleSize())
            .evaluatedAt(Instant.now())
            .build();
    }

    private double calculateTrend(LearningMetrics30D m) {
        double recent7d = m.getCorrectRateLast7Days();
        double previous7d = m.getCorrectRatePrevious7Days();
        double delta = recent7d - previous7d;
        // 映射到 [0, 1]: delta 范围 [-0.3, 0.3] → [0, 1]
        return clamp(0.5 + delta / 0.6, 0.0, 1.0);
    }

    private double calculateVariance(double[] scores) {
        double mean = Arrays.stream(scores).average().orElse(0);
        double sumSq = Arrays.stream(scores)
            .map(s -> (s - mean) * (s - mean))
            .sum();
        return sumSq / scores.length;
    }

    private double clamp(double v, double min, double max) {
        return Math.max(min, Math.min(max, v));
    }
}
```

```java
    @ExceptionHandler(OrchestrationTimeoutException.class)
    public ResponseEntity<ApiResponse<Void>> handleTimeout(
            OrchestrationTimeoutException e) {
        // 编排超时：部分学生可能已完成编排
        log.warn("编排超时 homework={}, completed={}/{}", 
            e.getHomeworkId(), e.getCompleted(), e.getTotal());

        // 未完成的学生标记为重试
        retryService.scheduleRetry(e.getHomeworkId(), e.getPendingStudentIds());

        return ResponseEntity.status(HttpStatus.GATEWAY_TIMEOUT)
            .body(ApiResponse.error("DH-008",
                String.format("编排超时: %d/%d 已完成，%d 将重试",
                    e.getCompleted(), e.getTotal(), e.getPendingStudentIds().size())));
    }
```

### 12.3 边界情况处理

| 场景 | 处理策略 |
|------|----------|
| 班级仅有1-2名学生 | 不自动分层，所有学生使用 INTERMEDIATE 模板 |
| 某知识点题库为空 | 跳过该知识点，记录警告，通知教研补充题目 |

| 教师在编排进行中修改模板 | 拒绝修改（返回 DH-002），需先取消再重新创建 |
| 同一作业重复发布 | 幂等校验：若 homework 状态已是 PUBLISHED，直接返回已有结果 |
| 截止时间早于当前时间+1小时 | 拒绝创建（DH-007）|
| 手动覆盖与自动评估冲突 | 手动覆盖优先级最高，7天内不自动调层 |
| 编排期间学生被移出班级 | 跳过该学生，不影响其他学生编排 |
| 大班级（>100人）编排 | 分批并行处理，每批20人，使用线程池 |
