# 服务端-学生作息健康监测与学习时间生理节律适配优化引擎 详细设计

## 1. 概述

### 1.1 模块定位

学生作息健康监测与学习时间生理节律适配优化引擎（Student Schedule Health & Circadian Optimization Engine，简称 SCHCO 引擎）是 PrimeTop 平台的学生健康保障基础设施。该引擎通过持续采集学生的学习行为时间序列数据，运用时间序列分析、昼夜节律建模和机器学习方法，识别不健康的学习作息模式，预测学生学习效率的高峰时段，并生成个性化的作息优化方案。

### 1.2 核心职责

- **作息模式画像**：基于学生历史学习行为数据，构建个人学习时间分布画像和作息类型（晨型/夜型/中间型）。
- **健康异常检测**：识别熬夜学习、睡眠不足、作息紊乱、过度连续学习等不健康模式。
- **合规校验**：依据教育部《未成年人学校睡眠管理通知》及防沉迷政策，校验学生睡眠达标情况。
- **效率时段识别**：通过学习效果数据关联分析，识别学生个性化高效学习时段。
- **作息优化推荐**：生成个性化的学习时间安排建议，在保障健康的前提下最大化学习效率。
- **干预调度**：当检测到健康风险时，协调通知系统、学习计划系统进行柔性干预。

### 1.3 与现有模块的区别

| 现有模块 | 关注点 | 本引擎区别 |
|---------|--------|-----------|
| 防沉迷与未成年人保护机制 | 总时长限制、宵禁封禁、硬性规则 | 本引擎关注**健康优化**而非**规则封禁**，提供柔性建议而非强制阻断 |
| 学生学习会话疲劳度监测 | 单次会话内的认知疲劳检测和休息提醒 | 本引擎关注**跨天/跨周**的作息模式，而非单次会话 |
| 学生每日学习时间智能分配 | 多学科间的学习时间均衡分配 | 本引擎关注**时间段与健康**的匹配，而非学科间的时间分配 |
| 学习计时器与番茄钟 | 客户端计时和专注管理工具 | 本引擎是服务端的数据分析和推荐引擎 |

## 3. 核心算法设计

### 3.1 昼夜节律类型识别算法（Chronotype Detection）

基于 Horne-Östberg Morningness-Eveningness Questionnaire (MEQ) 简化模型，结合学生实际行为数据进行自适应调整。

#### 3.1.1 算法输入

```python
# 输入：最近30天的每日活动汇总数据
daily_summaries: list[DailyActivitySummary]  # 至少需要14天数据

# 关键字段：
# - earliest_activity: 最早活动时间
# - latest_activity: 最晚活动时间
# - estimated_sleep_start / estimated_sleep_end: 估算睡眠时段
# - study_time_distribution: 24小时学习时间分布
```

#### 3.1.2 核心计算逻辑

```python
class ChronotypeDetector:
    """
    昼夜节律类型检测器
    基于 MEQ 简化模型 + 行为数据自适应修正
    """

    # 教育部规定的各学段最低睡眠时长（分钟）
    SLEEP_REQUIREMENTS = {
        "PRIMARY": 600,    # 小学生 10小时
        "MIDDLE": 540,     # 初中生 9小时
        "HIGH": 480,       # 高中生 8小时
        "KINDERGARTEN": 660 # 幼儿 11小时
    }

    def detect_chronotype(self, daily_summaries: list, user_profile: dict) -> dict:
        """
        检测学生的昼夜节律类型

        Returns:
            {
                "chronotype": "MORNING" | "EVENING" | "INTERMEDIATE",
                "chronotypeScore": int (-100 ~ 100),
                "avgSleepTime": "HH:mm",
                "avgWakeTime": "HH:mm",
                "avgSleepDuration": int (minutes),
                "confidence": float (0~1)
            }
        """
        if len(daily_summaries) < 7:
            return {"chronotype": "UNDETERMINED", "confidence": 0.0}

        # Step 1: 计算平均入睡/起床时间（使用环状统计处理跨天问题）
        sleep_times = [self._time_to_circular(ds.estimated_sleep_start) for ds in daily_summaries]
        wake_times = [self._time_to_circular(ds.estimated_sleep_end) for ds in daily_summaries]

        avg_sleep_circular = self._circular_mean(sleep_times)
        avg_wake_circular = self._circular_mean(wake_times)

        avg_sleep_time = self._circular_to_time(avg_sleep_circular)
        avg_wake_time = self._circular_to_time(avg_wake_circular)

        # Step 2: 计算作息类型评分（修正 MEQ 简化版）
        score = 0

        # 入睡时间评分（越早越高）
        sleep_hour = avg_sleep_time.hour + avg_sleep_time.minute / 60
        if sleep_hour >= 22:  # 22:00前入睡
            score += min(40, (24 - sleep_hour + 21) * 20)  # 越早分越高
        elif sleep_hour < 4:  # 凌晨入睡（夜型）
            score -= min(60, int((sleep_hour + 1) * 15))
        else:  # 22:00-23:59
            score -= int((sleep_hour - 22) * 15)

        # 起床时间评分
        wake_hour = avg_wake_time.hour + avg_wake_time.minute / 60
        if 6 <= wake_hour <= 8:
            score += 20
        elif wake_hour > 9:
            score -= 20

        # 高效时段分布评分
        morning_activity = sum(ds.total_study_duration for ds in daily_summaries
                               if ds.earliest_activity and ds.earliest_activity.hour < 9)
        evening_activity = sum(ds.night_study_minutes for ds in daily_summaries)
        total_activity = sum(ds.total_study_duration for ds in daily_summaries)

        if total_activity > 0:
            morning_ratio = morning_activity / total_activity
            evening_ratio = evening_activity / total_activity
            score += int((morning_ratio - evening_ratio) * 40)

        score = max(-100, min(100, score))

        # Step 3: 分类
        if score >= 25:
            chronotype = "MORNING"
        elif score <= -25:
            chronotype = "EVENING"
        else:
            chronotype = "INTERMEDIATE"

        # Step 4: 计算置信度
        confidence = min(1.0, len(daily_summaries) / 30)

        # Step 5: 计算平均睡眠时长
        durations = [ds.estimated_sleep_duration for ds in daily_summaries
                     if ds.estimated_sleep_duration]
        avg_duration = int(sum(durations) / len(durations)) if durations else 0

        return {
            "chronotype": chronotype,
            "chronotypeScore": score,
            "avgSleepTime": avg_sleep_time.strftime("%H:%M"),
            "avgWakeTime": avg_wake_time.strftime("%H:%M"),
            "avgSleepDuration": avg_duration,
            "confidence": confidence
        }

    def _time_to_circular(self, dt: datetime) -> tuple:
        """将时间转换为单位圆上的角度 (sin, cos)"""
        if dt is None:
            return (0, 1)
        total_minutes = dt.hour * 60 + dt.minute
        angle = 2 * math.pi * total_minutes / (24 * 60)
        return (math.sin(angle), math.cos(angle))

    def _circular_mean(self, values: list) -> tuple:
        """计算环状均值（处理跨天时间数据）"""
        valid = [v for v in values if v is not None]
        if not valid:
            return (0, 1)
        avg_sin = sum(v[0] for v in valid) / len(valid)
        avg_cos = sum(v[1] for v in valid) / len(valid)
        return (avg_sin, avg_cos)

    def _circular_to_time(self, circular: tuple) -> time:
        """将环状坐标转换回时间"""
        angle = math.atan2(circular[0], circular[1])
        if angle < 0:
            angle += 2 * math.pi
        total_minutes = int(angle * 24 * 60 / (2 * math.pi))
        return time(hour=total_minutes // 60, minute=total_minutes % 60)
```

### 3.2 健康异常检测算法

#### 3.2.1 异常类型定义

| 异常类型 | 标识 | 检测条件 | 严重度 |
|---------|------|---------|--------|
| 深夜学习 | LATE_NIGHT_STUDY | 23:30后仍有学习活动，单日>30分钟 | WARNING |
| 熬夜学习 | ALL_NIGHT_STUDY | 00:00-05:00期间有学习活动，单日>15分钟 | URGENT |
| 睡眠不足 | SLEEP_DEFICIT | 估算睡眠时长 < 学段最低标准的80% | WARNING/URGENT |
| 睡眠负债累积 | SLEEP_DEBT | 连续7天累计睡眠负债 > 300分钟(5小时) | URGENT |
| 作息紊乱 | IRREGULAR_SCHEDULE | 入睡时间标准差 > 90分钟（连续7天） | WARNING |
| 超长连续学习 | EXCESSIVE_SESSION | 单次连续学习 > 120分钟且无休息 | WARNING |
| 学习强度骤增 | SUDDEN_INCREASE | 学习时长比过去7天均值增加 > 50% | INFO |

#### 3.2.2 检测引擎实现

```python
class HealthAnomalyDetector:
    """
    学生作息健康异常检测引擎
    采用规则引擎 + 统计异常检测的混合方案
    """

    # 教育部睡眠标准（分钟）
    SLEEP_STANDARDS = {
        "KINDERGARTEN": 660,
        "PRIMARY": 600,
        "MIDDLE": 540,
        "HIGH": 480
    }

    def __init__(self, stage: str):
        self.required_sleep = self.SLEEP_STANDARDS.get(stage, 540)

    def detect_anomalies(self, daily_summary: DailyActivitySummary,
                         history_summaries: list = None) -> list[dict]:
        """
        检测单日 + 历史趋势中的健康异常

        Args:
            daily_summary: 当日活动汇总
            history_summaries: 最近7天的历史汇总（用于趋势分析）

        Returns:
            异常事件列表
        """
        anomalies = []

        # 1. 深夜学习检测
        if daily_summary.deep_night_study_minutes > 30:
            anomalies.append({
                "type": "LATE_NIGHT_STUDY",
                "severity": "WARNING",
                "message": f"今日23:30后学习{daily_summary.deep_night_study_minutes}分钟，"
                           f"建议在此前结束学习以保障睡眠",
                "data": {"minutes": daily_summary.deep_night_study_minutes}
            })

        # 2. 熬夜学习检测
        midnight_minutes = self._calc_midnight_minutes(daily_summary)
        if midnight_minutes > 15:
            anomalies.append({
                "type": "ALL_NIGHT_STUDY",
                "severity": "URGENT",
                "message": f"检测到凌晨0-5点期间仍在学习{midnight_minutes}分钟，"
                           f"严重影响健康和学习效率",
                "data": {"minutes": midnight_minutes}
            })

        # 3. 睡眠不足检测
        if daily_summary.estimated_sleep_duration is not None:
            sleep_ratio = daily_summary.estimated_sleep_duration / self.required_sleep
            if sleep_ratio < 0.7:
                anomalies.append({
                    "type": "SLEEP_DEFICIT",
                    "severity": "URGENT",
                    "message": f"估算睡眠时长{daily_summary.estimated_sleep_duration}分钟，"
                               f"低于推荐标准的70%",
                    "data": {
                        "actual": daily_summary.estimated_sleep_duration,
                        "required": self.required_sleep,
                        "deficit": self.required_sleep - daily_summary.estimated_sleep_duration
                    }
                })
            elif sleep_ratio < 0.85:
                anomalies.append({
                    "type": "SLEEP_DEFICIT",
                    "severity": "WARNING",
                    "message": f"估算睡眠时长{daily_summary.estimated_sleep_duration}分钟，"
                               f"略低于推荐标准",
                    "data": {
                        "actual": daily_summary.estimated_sleep_duration,
                        "required": self.required_sleep
                    }
                })

        # 4. 睡眠负债检测（需要7天历史数据）
        if history_summaries and len(history_summaries) >= 7:
            sleep_debt = self._calculate_sleep_debt(history_summaries)
            if sleep_debt > 300:
                anomalies.append({
                    "type": "SLEEP_DEBT",
                    "severity": "URGENT",
                    "message": f"连续7天累计睡眠负债达{sleep_debt}分钟(约{sleep_debt//60}小时)，"
                               f"建议适当补充睡眠",
                    "data": {"sleepDebt": sleep_debt}
                })

            # 5. 作息紊乱检测
            irregularity = self._calculate_schedule_irregularity(history_summaries)
            if irregularity > 90:
                anomalies.append({
                    "type": "IRREGULAR_SCHEDULE",
                    "severity": "WARNING",
                    "message": f"近期入睡时间波动较大(标准差{irregularity:.0f}分钟)，"
                               f"建议建立规律作息",
                    "data": {"irregularity": irregularity}
                })

        # 6. 超长连续学习检测
        if daily_summary.max_continuous_study > 120:
            anomalies.append({
                "type": "EXCESSIVE_SESSION",
                "severity": "WARNING",
                "message": f"最长连续学习{daily_summary.max_continuous_study}分钟，"
                           f"建议每45-60分钟休息10分钟",
                "data": {"continuousMinutes": daily_summary.max_continuous_study}
            })

        # 7. 学习强度骤增检测
        if history_summaries and len(history_summaries) >= 7:
            recent_avg = sum(h.total_study_duration for h in history_summaries[-7:]) / 7
            if recent_avg > 0:
                increase_ratio = (daily_summary.total_study_duration - recent_avg) / recent_avg
                if increase_ratio > 0.5 and daily_summary.total_study_duration > 120:
                    anomalies.append({
                        "type": "SUDDEN_INCREASE",
                        "severity": "INFO",
                        "message": f"今日学习时长较近期均值增加{increase_ratio*100:.0f}%，"
                                   f"注意劳逸结合",
                        "data": {
                            "today": daily_summary.total_study_duration,
                            "average": recent_avg,
                            "increaseRatio": increase_ratio
                        }
                    })

        return anomalies

    def _calc_midnight_minutes(self, ds: DailyActivitySummary) -> int:
        """计算凌晨0-5点学习时长"""
        midnight = 0
        if ds.study_sessions:
            for session in ds.study_sessions:
                start = datetime.fromisoformat(session["start"])
                end = datetime.fromisoformat(session["end"])
                # 截取 00:00 - 05:00 区间
                night_start = start.replace(hour=0, minute=0, second=0)
                night_end = start.replace(hour=5, minute=0, second=0)
                overlap_start = max(start, night_start)
                overlap_end = min(end, night_end)
                if overlap_end > overlap_start:
                    midnight += int((overlap_end - overlap_start).total_seconds() / 60)
        return midnight

    def _calculate_sleep_debt(self, histories: list) -> int:
        """计算最近7天累计睡眠负债"""
        debt = 0
        for h in histories[-7:]:
            if h.estimated_sleep_duration is not None:
                deficit = self.required_sleep - h.estimated_sleep_duration
                debt += max(0, deficit)
        return debt

    def _calculate_schedule_irregularity(self, histories: list) -> float:
        """计算入睡时间不规则度（环状标准差，分钟）"""
        circular_times = []
        for h in histories[-7:]:
            if h.estimated_sleep_start:
                dt = h.estimated_sleep_start
                minutes = dt.hour * 60 + dt.minute
                angle = 2 * math.pi * minutes / (24 * 60)
                circular_times.append((math.sin(angle), math.cos(angle)))

        if len(circular_times) < 3:
            return 0

        mean_sin = sum(c[0] for c in circular_times) / len(circular_times)
        mean_cos = sum(c[1] for c in circular_times) / len(circular_times)

        R = math.sqrt(mean_sin**2 + mean_cos**2)
        if R == 0:
            return 1440  # 极度不规则

        circular_std = math.sqrt(-2 * math.log(R))
        return circular_std * 24 * 60 / (2 * math.pi)  # 转换为分钟
```

### 3.3 高效时段识别算法

```python
class EfficiencyWindowDetector:
    """
    学习效率高峰时段识别器
    通过关联学习时间与学习效果，找出学生个人最优学习时段
    """

    def calculate_efficiency_slots(
        self,
        answer_records: list,
        session_records: list,
        lookback_days: int = 30
    ) -> list[dict]:
        """
        计算24小时 × 7天的效率热力图

        Args:
            answer_records: 答题记录列表（含时间戳、正确率）
            session_records: 学习会话记录（含时间戳、专注度评分）
            lookback_days: 回溯天数

        Returns:
            效率时段列表，按效率指数降序排列
        """
        # 初始化 7×24 热力图
        heatmap = {}
        for dow in range(7):
            for hour in range(24):
                heatmap[(dow, hour)] = {
                    "correct_sum": 0.0,
                    "correct_count": 0,
                    "focus_sum": 0.0,
                    "focus_count": 0,
                    "duration_sum": 0
                }

        # 聚合答题数据到热力图
        for record in answer_records:
            dt = record.submitted_at
            dow = dt.weekday()
            hour = dt.hour
            if record.is_correct is not None:
                heatmap[(dow, hour)]["correct_sum"] += (1 if record.is_correct else 0)
                heatmap[(dow, hour)]["correct_count"] += 1

        # 聚合会话专注度数据
        for session in session_records:
            dt = session.started_at
            dow = dt.weekday()
            hour = dt.hour
            if session.focus_score is not None:
                heatmap[(dow, hour)]["focus_sum"] += session.focus_score
                heatmap[(dow, hour)]["focus_count"] += 1
            heatmap[(dow, hour)]["duration_sum"] += session.duration_minutes

        # 计算效率综合指数
        results = []
        for (dow, hour), data in heatmap.items():
            if data["correct_count"] < 3:
                continue  # 样本不足

            avg_correct = data["correct_sum"] / data["correct_count"] if data["correct_count"] > 0 else 0
            avg_focus = data["focus_sum"] / data["focus_count"] if data["focus_count"] > 0 else 0.5
            avg_duration = data["duration_sum"] / max(data["correct_count"], 1)

            # 效率指数 = 正确率 × 专注度 / 归一化时长
            # 时长归一化：25分钟为基准（番茄钟一个周期）
            duration_factor = min(1.0, 25 / max(avg_duration, 10))
            efficiency_index = avg_correct * avg_focus * (0.5 + 0.5 * duration_factor)

            # 置信度：基于样本量
            confidence = min(1.0, data["correct_count"] / 20)

            results.append({
                "dayOfWeek": dow,
                "hourSlot": hour,
                "avgCorrectRate": round(avg_correct, 4),
                "avgFocusScore": round(avg_focus, 4),
                "avgEfficiencyIndex": round(efficiency_index, 4),
                "sampleCount": data["correct_count"],
                "confidenceLevel": round(confidence, 3)
            })

        # 按效率降序排列
        results.sort(key=lambda x: x["avgEfficiencyIndex"], reverse=True)

        # 识别连续高效时段窗口
        peak_windows = self._identify_peak_windows(results)

        return results[:50], peak_windows

    def _identify_peak_windows(self, slots: list, threshold_percentile: int = 75) -> list:
        """
        从小时级效率数据中识别连续的高效时段窗口

        Returns:
            [{"start": "09:00", "end": "11:00", "score": 0.92, "dayOfWeek": 0}, ...]
        """
        if not slots:
            return []

        # 计算阈值（P75）
        indices = [s["avgEfficiencyIndex"] for s in slots]
        threshold = sorted(indices)[len(indices) * threshold_percentile // 100]

        # 按星期分组，找出连续高效小时
        by_day = {}
        for s in slots:
            by_day.setdefault(s["dayOfWeek"], []).append(s)

        windows = []
        for dow, day_slots in by_day.items():
            day_slots.sort(key=lambda x: x["hourSlot"])
            current_window = None

            for s in day_slots:
                if s["avgEfficiencyIndex"] >= threshold and s["confidenceLevel"] >= 0.3:
                    if current_window is None:
                        current_window = {
                            "start_hour": s["hourSlot"],
                            "end_hour": s["hourSlot"] + 1,
                            "scores": [s["avgEfficiencyIndex"]],
                            "dayOfWeek": dow
                        }
                    elif s["hourSlot"] == current_window["end_hour"]:
                        current_window["end_hour"] = s["hourSlot"] + 1
                        current_window["scores"].append(s["avgEfficiencyIndex"])
                    else:
                        # 窗口断裂
                        windows.append(self._format_window(current_window))
                        current_window = {
                            "start_hour": s["hourSlot"],
                            "end_hour": s["hourSlot"] + 1,
                            "scores": [s["avgEfficiencyIndex"]],
                            "dayOfWeek": dow
                        }
                else:
                    if current_window:
                        windows.append(self._format_window(current_window))
                        current_window = None

            if current_window:
                windows.append(self._format_window(current_window))

        # 按平均得分降序
        windows.sort(key=lambda w: w["score"], reverse=True)
        return windows[:5]  # 返回Top 5时段

    def _format_window(self, window: dict) -> dict:
        return {
            "start": f"{window['start_hour']:02d}:00",
            "end": f"{window['end_hour']:02d}:00",
            "score": round(sum(window["scores"]) / len(window["scores"]), 3),
            "dayOfWeek": window["dayOfWeek"],
            "durationHours": window["end_hour"] - window["start_hour"]
        }
```

```python
                    if minutes_ago < cooldown:

        for k, v in strategy.items():
            if k.startswith("maxPer"):

                max_count = v

                    recent_interventions, anomaly["type"], period
```

```java
/**
 * 作息画像服务 - 核心服务类

@Service
@Slf4j
public class ScheduleProfileService {

    @Autowired
    private ScheduleProfileRepository profileRepository;

    @Autowired
    private DailySummaryRepository dailySummaryRepository;

    @Autowired
    private ChronotypeDetector chronotypeDetector;

    @Autowired
    private EfficiencyWindowDetector efficiencyDetector;

    @Autowired
    private ScheduleHealthCacheManager cacheManager;

    @Autowired
    private ApplicationEventPublisher eventPublisher;

    @Value("${schco.profile.minDataDays:14}")
    private int minDataDays;

    /**
     * 获取或构建学生作息画像
     */
    @Cacheable(value = "schedule_profile", key = "#userId")
    public ScheduleProfileDTO getProfile(String userId) {
        StudentScheduleProfile profile = profileRepository.findByUserId(userId)
            .orElseGet(() -> createInitialProfile(userId));

        if (!profile.isDataSufficient()) {
            return ScheduleProfileDTO.insufficient(profile);
        }

        return ScheduleProfileDTO.from(profile);
    }

    /**
     * 重建作息画像（由定时任务或事件触发）
     */
    @Transactional
    public void rebuildProfile(String userId) {
        LocalDate endDate = LocalDate.now();
        LocalDate startDate = endDate.minusDays(30);

        List<DailyActivitySummary> summaries = dailySummaryRepository
            .findByUserIdAndDateRange(userId, startDate, endDate);

        if (summaries.size() < minDataDays) {
            log.info("用户 {} 数据不足({}/{}天)，跳过画像重建", userId, summaries.size(), minDataDays);
            return;
        }

        // 获取用户信息以确定学段
        UserProfile user = userService.getUserProfile(userId);
        String stage = user.getStageLevel(); // PRIMARY / MIDDLE / HIGH

        // 检测昼夜节律类型
        ChronotypeResult chronoResult = chronotypeDetector.detect(summaries, user);

        // 计算效率时段
        List<EfficiencySlot> efficiencySlots = efficiencyDetector.detect(userId, startDate, endDate);

        // 计算健康风险评分
        int healthRiskScore = calculateHealthRiskScore(summaries, stage, chronoResult);

        // 更新画像
        StudentScheduleProfile profile = profileRepository.findByUserId(userId)
            .orElseGet(() -> new StudentScheduleProfile(userId));

        profile.updateFromChronotype(chronoResult);
        profile.setPeakEfficiencyWindows(efficiencySlots);
        profile.setHealthRiskScore(healthRiskScore);
        profile.setDataSufficient(true);
        profile.setLastCalculatedAt(LocalDateTime.now());

        profileRepository.save(profile);
        cacheManager.evictProfile(userId);

        // 发布画像更新事件
        eventPublisher.publishEvent(new ScheduleProfileUpdatedEvent(userId, profile));
    }

    /**
     * 综合健康风险评分计算
     */
    private int calculateHealthRiskScore(List<DailyActivitySummary> summaries,
                                          String stage, ChronotypeResult chrono) {
        int requiredSleep = SleepStandardConfig.getRequiredSleep(stage);
        int score = 0;

        // 睡眠不足风险 (权重 40分)
        int deficitDays = 0;
        int totalDeficit = 0;
        for (DailyActivitySummary ds : summaries) {
            if (ds.getEstimatedSleepDuration() != null) {
                int deficit = requiredSleep - ds.getEstimatedSleepDuration();
                if (deficit > 0) {
                    deficitDays++;
                    totalDeficit += deficit;
                }
            }
        }
        double deficitRatio = (double) deficitDays / summaries.size();
        int sleepScore = (int) (deficitRatio * 40);
        score += sleepScore;

        // 深夜学习风险 (权重 25分)
        int nightStudyDays = (int) summaries.stream()
            .filter(ds -> ds.getDeepNightStudyMinutes() > 15)
            .count();
        double nightRatio = (double) nightStudyDays / summaries.size();
        score += (int) (nightRatio * 25);

        // 作息紊乱风险 (权重 20分)
        double irregularity = chrono.getSleepTimeStdDeviation();
        if (irregularity > 90) {
            score += 20;
        } else if (irregularity > 60) {
            score += (int) ((irregularity - 60) / 30.0 * 20);
        }

        // 连续学习过久风险 (权重 15分)
        int longSessionDays = (int) summaries.stream()
            .filter(ds -> ds.getMaxContinuousStudy() > 120)
            .count();
        double longSessionRatio = (double) longSessionDays / summaries.size();
        score += (int) (longSessionRatio * 15);

        return Math.min(100, score);
    }

    private StudentScheduleProfile createInitialProfile(String userId) {
        StudentScheduleProfile profile = new StudentScheduleProfile(userId);
        profile.setChronotype(Chronotype.UNDETERMINED);
        profile.setHealthRiskScore(0);
        profile.setDataSufficient(false);
        return profileRepository.save(profile);
    }
}
```

```java
/**
 * 睡眠估算器 - 从行为数据推断睡眠时段
 */
@Component
@Slf4j
public class SleepEstimator {

    /**
     * 从学习行为事件流估算某日睡眠时段
     *
     * 算法逻辑：
     * 1. 获取当日最后一次学习活动 -> 推断为入睡开始前
     * 2. 获取次日第一次学习活动 -> 推断为醒来后
     * 3. 排除中间短暂唤醒（< 10分钟的活动视为夜醒）
     * 4. 结合设备在线状态（如有）进行修正
     */
    public SleepEstimation estimate(LocalDate date, List<BehaviorEvent> events,
                                     List<BehaviorEvent> nextDayEvents) {
        if (events == null || events.isEmpty()) {
            return SleepEstimation.unknown();
        }

        // 获取当日最后一次有效活动
        BehaviorEvent lastActivity = events.stream()
            .filter(e -> e.getTimestamp().toLocalDate().equals(date))
            .reduce((first, second) -> second)  // 取最后一个
            .orElse(null);

        // 获取次日第一次活动
        BehaviorEvent firstNextDay = null;
        if (nextDayEvents != null && !nextDayEvents.isEmpty()) {
            firstNextDay = nextDayEvents.stream()
                .filter(e -> e.getTimestamp().toLocalDate().equals(date.plusDays(1)))
                .findFirst()
                .orElse(null);
        }

        LocalDateTime sleepStart = null;
        LocalDateTime sleepEnd = null;

        if (lastActivity != null) {
            // 入睡时间 = 最后活动时间 + 缓冲（15分钟）
            sleepStart = lastActivity.getTimestamp().plusMinutes(15);
        }

        if (firstNextDay != null) {
            // 起床时间 = 第一次活动时间 - 缓冲（15分钟）
            sleepEnd = firstNextDay.getTimestamp().minusMinutes(15);
        }

        // 计算睡眠时长
        int durationMinutes = 0;
        if (sleepStart != null && sleepEnd != null) {
            durationMinutes = (int) Duration.between(sleepStart, sleepEnd).toMinutes();
            // 合理性校验：睡眠时长应在 3-14 小时之间
            if (durationMinutes < 180 || durationMinutes > 840) {
                log.warn("估算睡眠时长异常: {} 分钟，用户 {}", durationMinutes, events.get(0).getUserId());
                return SleepEstimation.unknown();
            }
        }

        return SleepEstimation.builder()
            .sleepStart(sleepStart)
            .sleepEnd(sleepEnd)
            .durationMinutes(durationMinutes)
            .confidence(calculateConfidence(events.size(), sleepStart, sleepEnd))
            .build();
    }

    private double calculateConfidence(int eventCount,
                                        LocalDateTime sleepStart,
                                        LocalDateTime sleepEnd) {
        if (sleepStart == null || sleepEnd == null) {
            return 0.0;
        }
        double eventConfidence = Math.min(1.0, eventCount / 20.0);
        double timeConfidence = 0.8; // 基础置信度
        return eventConfidence * timeConfidence;
    }
}
```

```java
@Component
@Slf4j
public class DailySummaryJob {

    /**
     * 每日 02:00 执行，处理前一天的活跃用户数据
     * 分批处理，每批 500 用户
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void execute() {
        LocalDate targetDate = LocalDate.now().minusDays(1);

        // 获取前一天活跃的用户列表
        List<String> activeUserIds = behaviorEventService.getActiveUserIds(targetDate);

        log.info("开始处理 {} 的活动汇总，共 {} 个用户", targetDate, activeUserIds.size());

        // 分批并行处理
        int batchSize = 500;
        IntStream.range(0, (activeUserIds.size() + batchSize - 1) / batchSize)
            .parallel()
            .forEach(batchIndex -> {
                int start = batchIndex * batchSize;
                int end = Math.min(start + batchSize, activeUserIds.size());
                List<String> batch = activeUserIds.subList(start, end);

                for (String userId : batch) {
                    try {
                        processUserDailySummary(userId, targetDate);
                    } catch (Exception e) {
                        log.error("处理用户 {} 的 {} 汇总失败", userId, targetDate, e);
                    }
                }
            });

        log.info("活动汇总完成: {}", targetDate);
    }

    @Transactional
    void processUserDailySummary(String userId, LocalDate date) {
        // 1. 获取学习行为事件
        List<BehaviorEvent> events = behaviorEventService.getEvents(userId, date);
        List<BehaviorEvent> nextDayEvents = behaviorEventService.getEvents(userId, date.plusDays(1));

        if (events.isEmpty()) return;

        // 2. 聚合会话数据
        List<StudySession> sessions = sessionAggregator.aggregate(events, date);
        int totalDuration = sessions.stream().mapToInt(StudySession::getDurationMinutes).sum();
        int maxContinuous = sessions.stream().mapToInt(StudySession::getDurationMinutes).max().orElse(0);
        int nightMinutes = sessions.stream()
            .mapToInt(s -> TimeUtils.minutesInHourRange(s, 22, 24)).sum();
        int deepNightMinutes = sessions.stream()
            .mapToInt(s -> TimeUtils.minutesAfterHour(s, 23, 30)).sum();

        // 3. 估算睡眠
        SleepEstimation sleep = sleepEstimator.estimate(date, events, nextDayEvents);

        // 4. 运行健康检测
        List<DailyActivitySummary> recent7Days = dailySummaryRepository
            .findRecentDays(userId, date.minusDays(7), date.minusDays(1));
        List<HealthAnomaly> anomalies = healthDetector.detect(buildSummary(events, sessions,
            sleep, totalDuration, maxContinuous), recent7Days);

        // 5. 计算健康等级
        HealthLevel level = determineHealthLevel(anomalies, sleep);

        // 6. 存储
        DailyActivitySummary summary = DailyActivitySummary.builder()
            .userId(userId)
            .date(date)
            .studySessions(sessions)
            .totalStudyDuration(totalDuration)
            .totalBreakDuration(calculateBreakDuration(events))
            .earliestActivity(events.get(0).getTimestamp())
            .latestActivity(events.get(events.size() - 1).getTimestamp())
            .estimatedSleepStart(sleep.getSleepStart())
            .estimatedSleepEnd(sleep.getSleepEnd())
            .estimatedSleepDuration(sleep.getDurationMinutes())
            .nightStudyMinutes(nightMinutes)
            .deepNightStudyMinutes(deepNightMinutes)
            .sessionCount(sessions.size())
            .maxContinuousStudy(maxContinuous)
            .healthLevel(level)
            .anomalies(anomalies)
            .build();

        dailySummaryRepository.saveOrUpdate(summary);

        // 7. 触发即时干预（URGENT级别）
        for (HealthAnomaly anomaly : anomalies) {
            if ("URGENT".equals(anomaly.getSeverity())) {
                interventionService.triggerImmediateIntervention(userId, anomaly);
            }
        }
    }
}
```

## 11. 安全与隐私考虑

### 11.1 数据隐私

- **数据最小化**：仅采集学习行为时间戳和时长数据，不采集位置、设备标识等非必要信息。
- **匿名化**：效率时段分析数据在聚合后去除用户标识，仅保留统计结果。
- **数据保留**：每日活动明细数据保留 90 天，90 天后仅保留聚合统计。
- **家长可见度**：家长仅可查看绑定孩子的作息健康摘要，不可查看具体学习内容。

### 11.2 合规校验

```java
/**
 * 教育部睡眠管理合规校验器
 * 依据：《教育部办公厅关于进一步加强中小学生睡眠管理工作的通知》（2021年）
 */
@Component
public class SleepComplianceValidator {

    // 教育部规定的就寝时间上限
    private static final Map<String, LocalTime> BEDTIME_LIMITS = Map.of(
        "PRIMARY", LocalTime.of(21, 20),   // 小学不晚于21:20
        "MIDDLE", LocalTime.of(22, 0),      // 初中不晚于22:00
        "HIGH", LocalTime.of(23, 0)         // 高中不晚于23:00（参考建议）
    );

    // 教育部规定的最低睡眠时长（分钟）
    private static final Map<String, Integer> MIN_SLEEP = Map.of(
        "PRIMARY", 600,   // 10小时
        "MIDDLE", 540,    // 9小时
        "HIGH", 480       // 8小时
    );

    public ComplianceResult validate(String stage, DailyActivitySummary summary) {
        List<String> violations = new ArrayList<>();

        LocalTime bedtimeLimit = BEDTIME_LIMITS.get(stage);
        Integer minSleep = MIN_SLEEP.get(stage);

        // 校验就寝时间
        if (summary.getEstimatedSleepStart() != null && bedtimeLimit != null) {
            LocalTime actualBedtime = summary.getEstimatedSleepStart().toLocalTime();
            if (actualBedtime.isAfter(bedtimeLimit)) {
                violations.add(String.format(
                    "就寝时间 %s 晚于规定时间 %s",
                    actualBedtime, bedtimeLimit
                ));
            }
        }

        // 校验睡眠时长
        if (summary.getEstimatedSleepDuration() != null && minSleep != null) {
            if (summary.getEstimatedSleepDuration() < minSleep * 0.85) {
                violations.add(String.format(
                    "睡眠时长 %d 分钟低于最低标准的85%%(%d分钟)",
                    summary.getEstimatedSleepDuration(), minSleep
                ));
            }
        }

        return new ComplianceResult(violations.isEmpty(), violations);
    }
}
```

## 16. 术语表

| 术语 | 说明 |
|------|------|
| 昼夜节律（Chronotype） | 个体在昼夜周期中表现出偏好的活动时间类型（晨型/夜型/中间型） |
| 睡眠负债（Sleep Debt） | 累计的实际睡眠时长与推荐睡眠时长之间的差值 |
| 环状统计（Circular Statistics） | 处理环形数据（如时钟时间）的统计方法，避免跨天计算偏差 |
| 效率综合指数 | 综合正确率、专注度、时长归一化的学习效率评估指标 |
| 干预（Intervention） | 平台主动向学生或家长发送的健康提醒或建议 |
| MEQ | Morningness-Eveningness Questionnaire，晨昏类型问卷 |
| 睡眠估算 | 基于行为数据（非直接睡眠监测）推断用户睡眠时段的方法 |
