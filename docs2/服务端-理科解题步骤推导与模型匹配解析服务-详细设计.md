## 1. 模块概述

### 1.1 定位

理科解题步骤推导与模型匹配解析服务是 PrimeTop 面向初中、高中学生的核心 P0 服务，负责接收经过 OCR 识别或文字输入的理科题目（数学、物理、化学、生物），完成**题目类型分类 → 条件结构化提取 → 解题模型匹配 → 步骤推导编排 → AI 解题调用 → 结果校验 → 渐进式答案输出**的全链路处理。

本服务是「拍照搜题」和「AI 辅导」两个核心场景的共享后端能力，同时为「错题整理」「练习批改」「同类题推荐」等下游模块提供结构化解题数据。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 题目类型分类 | 将输入题目分类到 80+ 种理科题型（一次方程、二次函数、力学综合、有机推断等） |
| 条件结构化 | 从题干中提取已知条件、隐含条件、求解目标，输出结构化 JSON |
| 解题模型匹配 | 基于题型和条件匹配最优解题策略模板（公式法、图像法、分类讨论等） |
| 步骤推导编排 | 将解题策略拆解为可渐进展示的分步骤序列 |
| AI 解题调用 | 根据题型复杂度选择合适模型（推理增强模型 / 通用模型），组装 Prompt |
| 结果校验 | 对 AI 输出进行格式校验、数值验算、单位检查、逻辑一致性验证 |
| 渐进式输出 | 支持思路提示 → 关键步骤 → 完整解析 → 总结拓展的分阶段输出 |
| 公式渲染支持 | 输出 LaTeX 格式的数学公式，客户端渲染 |

### 1.3 与其他模块的关系

| 关联模块 | 关系 |
|---------|------|
| 拍照搜题请求编排服务 | 上游：调用本服务进行解题 |
| AI对话引擎 | 本服务消费 AI 对话能力进行解题 |
| 多模型调度与成本治理 | 本服务消费模型路由能力，根据题型选择模型 |
| 题目相似度计算与智能去重 | 本服务输出结构化题目信息供去重使用 |
| 错题整理模块 | 下游：消费本服务输出的错因标签和知识点映射 |
| 知识点体系与教材映射引擎 | 本服务消费知识点映射，输出关联知识点 |
| 答案管控与渐进式提示引擎 | 本服务输出分层答案数据，由答案管控引擎控制展示策略 |
| 练习答题实时批改 | 本服务为练习批改提供标准解题步骤参照 |

### 2.2 核心处理流水线

```
输入题目（结构化/文本）
    │
    ▼
[Step 1] 题目预处理 ─── 公式识别、符号标准化、题干清洗
    │
    ▼
[Step 2] 题目分类 ─── 学科 → 题型大类 → 具体题型
    │
    ▼
[Step 3] 条件结构化提取 ─── 已知条件、隐含条件、求解目标
    │
    ▼
[Step 4] 解题模型匹配 ─── 匹配解题策略模板 + 关联公式
    │
    ▼
[Step 5] Prompt 组装 ─── 学段适配 + 题型模板 + RAG 上下文
    │
    ▼
[Step 6] AI 模型调用 ─── 根据复杂度选择推理/通用模型
    │
    ▼
[Step 7] 结果解析与校验 ─── 格式校验、数值验算、逻辑检查
    │    │
    │    ├── 校验通过 → Step 8
    │    └── 校验失败 → 重试（换模型/调整 Prompt）→ 最多 2 次
    │
    ▼
[Step 8] 渐进式分层 ─── 思路提示 / 关键步骤 / 完整解析 / 总结
    │
    ▼
[Step 9] 知识点/易错点标注 ─── 关联知识点、标注常见误区
    │
    ▼
输出结构化解题结果
```

### 3.1 请求模型

```java
/**
 * 理科解题请求
 */
public class ScienceSolutionRequest {

    /** 请求唯一标识，用于幂等和链路追踪 */
    private String requestId;

    /** 用户 ID */
    private Long userId;

    /** 学段：PRIMARY(小学) / JUNIOR(初中) / SENIOR(高中) */
    private StageEnum stage;

    /** 年级 */
    private Integer grade;

    /** 学科：MATH / PHYSICS / CHEMISTRY / BIOLOGY */
    private SubjectEnum subject;

    /** 题目来源：PHOTO_OCR / TEXT_INPUT / PRACTICE / AI_GENERATED */
    private SourceEnum source;

    /** 题目文本内容（经 OCR 后的纯文本） */
    private String questionText;

    /** 题目结构化数据（来自 OCR 后处理） */
    private QuestionStructure structure;

    /** 解题输出模式 */
    private OutputMode outputMode;

    /** 关联的教材版本 ID（用于 RAG 检索范围限定） */
    private String textbookVersionId;

    /** 关联的章节 ID 列表 */
    private List<String> chapterIds;

    /** 是否需要渐进式输出（用于 SSE 流式场景） */
    private boolean progressiveOutput;

    /** 是否在 AI 辅导对话上下文中 */
    private boolean inConversation;

    /** 对话上下文 ID（如果在对话中） */
    private String conversationId;

    /** 最大等待时间（ms） */
    private Long timeoutMs;
}

/**
 * 题目结构化数据
 */
public class QuestionStructure {

    /** 题型：CHOICE / FILL / SHORT_ANSWER / CALCULATION / PROOF / EXPERIMENT */
    private QuestionTypeEnum questionType;

    /** 题干文本 */
    private String stem;

    /** 选项（选择题） */
    private List<String> options;

    /** 题干中的公式列表（LaTeX 格式） */
    private List<String> formulas;

    /** 题干中的图片 URL */
    private List<String> imageUrls;

    /** 图形描述（几何题的图形信息） */
    private DiagramDescription diagram;

    /** 是否含子题 */
    private boolean hasSubQuestions;

    /** 子题列表 */
    private List<QuestionStructure> subQuestions;
}

/**
 * 图形描述
 */
public class DiagramDescription {

    /** 图形类型：TRIANGLE / CIRCLE / RECTANGLE / COORDINATE / CIRCUIT / OTHER */
    private String diagramType;

    /** 已知标注（从图中识别的标注信息） */
    private List<String> annotations;

    /** 图形中的数值标注 */
    private Map<String, String> labeledValues;

    /** OCR 置信度 (0-1) */
    private Double confidence;
}

/**
 * 输出模式
 */
public enum OutputMode {

    /** 完整输出（拍题答疑场景） */
    FULL,

    /** 渐进式输出（先提示后展开） */
    PROGRESSIVE,

    /** 仅思路提示（答案管控模式） */
    HINT_ONLY,

    /** 批改参照模式（练习批改场景，输出标准步骤） */
    REFERENCE
}
```

```java
    /** 分类置信度 (0-1) */
    private Double confidence;

    /** 难度预估：1-5 */
    private Integer estimatedDifficulty;

    /** 是否需要图形理解 */
    private boolean requiresDiagramUnderstanding;

    /** 是否为多步综合题 */
    private boolean isMultiStep;
}

 * 结构化条件

public class StructuredConditions {

    /** 已知条件列表 */
    private List<Condition> givenConditions;

    /** 隐含条件列表（推理得出） */

    /** 求解目标列表 */
    private List<Condition> targets;

    /** 涉及的物理量 / 数学对象 */
    private List<String> entities;

    /** 单位信息 */
    private Map<String, String> units;

 * 条件

public class Condition {

    /** 条件文本 */

    /** 条件类型：GIVEN / IMPLICIT / TARGET */

    private String mathExpression;

    /** 置信度 */
    private Double confidence;
}

/**
 * 解题模型
 */
public class SolutionModel {

    /** 模型 ID */

    /** 适用题型编码 */
    private String applicableTypeCode;

    /** 解题策略描述 */
    private String strategy;

    /** 关键公式列表 */
    private List<String> keyFormulas;

    /** 推荐步骤模板 */
    private List<StepTemplate> stepTemplates;

    /** 常见易错点 */
    private List<String> commonPitfalls;

    /** 建议的 AI 模型层级：REASONING / GENERAL */
    private String recommendedModelTier;

    /** 预估步骤数 */
    private Integer estimatedSteps;
}

/**
 * 步骤模板
 */
public class StepTemplate {

    /** 步骤序号 */
    private Integer order;

    /** 步骤标题 */
    private String title;         // e.g., "设未知数", "列方程", "求解"

    /** 步骤描述 */
    private String description;

    /** 预期输出类型 */
    private String expectedOutputType; // EQUATION / VALUE / CONCLUSION / PROOF_STEP

/**
 * 解题步骤

public class SolutionStep {

    /** 步骤序号 */
    private Integer stepOrder;

    /** 步骤内容（含 LaTeX 公式） */
    private String content;

    /** 步骤类型：SETUP / DERIVATION / CALCULATION / CONCLUSION */
    private StepTypeEnum type;

    /** 关键公式（LaTeX） */
    private List<String> formulas;

    /** 中间结果 */
    private String intermediateResult;

    /** 是否为关键步骤（渐进展示时的分层依据） */
```

```sql
    source          VARCHAR(32) COMMENT '来源：PHOTO_OCR/TEXT_INPUT/PRACTICE',

    final_answer    TEXT COMMENT '最终答案',
    step_count      INT COMMENT '步骤数',
```

## 5. 核心处理逻辑详细设计

### 5.1 Step 1 - 题目预处理 (QuestionPreprocessor)

**职责：** 将 OCR 输出或用户输入的原始文本清洗为标准化题目文本。

```java
@Service
public class QuestionPreprocessor {

    /**
     * 预处理流水线
     */
    public String preprocess(String rawText, QuestionStructure structure) {
        String text = rawText;

        // 1. 清理 OCR 噪音
        text = cleanOcrNoise(text);

        // 2. 标准化数学符号
        text = normalizeMathSymbols(text);

        // 3. 替换常见 OCR 错误
        text = fixCommonOcrErrors(text);

        // 4. 识别并标记公式区域
        text = markFormulaRegions(text, structure.getFormulas());

        // 5. 规范化空白和换行
        text = normalizeWhitespace(text);

        return text;
    }

    private String normalizeMathSymbols(String text) {
        return text
            .replace("×", "\\times ")
            .replace("÷", "\\div ")
            .replace("≠", "\\neq ")
            .replace("≤", "\\leq ")
            .replace("≥", "\\geq ")
            .replace("√", "\\sqrt{}")
            .replace("π", "\\pi ");
    }

    private String fixCommonOcrErrors(String text) {
        // OCR 常见错误修正映射
        Map<String, String> corrections = Map.of(
            "O", "0",    // 字母O → 数字0（在数学上下文中）
            "l", "1",    // 字母l → 数字1（在数学上下文中）
            "S", "5"     // 视情况修正
        );
        // 实际实现需要基于上下文判断
        return text;
    }
}
```

### 5.2 Step 2 - 题目分类 (QuestionClassifier)

**职责：** 将预处理后的题目分类到具体的学科 → 题型大类 → 具体题型。

**分类策略：**

1. **学科确定**：通常由上游（OCR 流程或用户选择）已确定学科，本步骤做二次确认
2. **规则匹配优先**：基于关键词和公式模式匹配题型（快速、确定性高）
3. **AI 分类兜底**：规则未匹配时，调用轻量 AI 模型进行分类

```java
@Service
public class QuestionClassifier {

    @Autowired
    private List<ClassificationRule> rules;

    @Autowired
    private AiClassificationClient aiClassifier;

    public ClassificationResult classify(SolutionContext context) {
        String text = context.getCleanedQuestionText();
        SubjectEnum subject = context.getRequest().getSubject();

        // 1. 规则匹配（优先）
        for (ClassificationRule rule : rules) {
            ClassificationResult result = rule.match(text, subject);
            if (result != null && result.getConfidence() > 0.85) {
                return result;
            }
        }

        // 2. AI 分类（兜底）
        ClassificationResult aiResult = aiClassifier.classify(
            text, subject, context.getRequest().getStage()
        );

        return aiResult;
    }
}
```

**规则匹配示例：**

```java
@Component
public class QuadraticEquationRule implements ClassificationRule {

    // 匹配一元二次方程的模式
    private static final List<Pattern> PATTERNS = List.of(
        Pattern.compile("x\\s*2\\s*[+\\-]\\s*\\d*x\\s*[+\\-]\\s*\\d*\\s*=\\s*\\d*"),
        Pattern.compile("ax\\s*2\\s*\+\\s*bx\\s*\+\\s*c")
    );

    @Override
    public ClassificationResult match(String text, SubjectEnum subject) {
        if (subject != SubjectEnum.MATH) return null;

        for (Pattern p : PATTERNS) {
            if (p.matcher(text).find()) {
                return ClassificationResult.builder()
                    .subject(SubjectEnum.MATH)
                    .categoryCode("MATH_ALGEBRA")
                    .typeCode("MATH_ALGEBRA_QUADRATIC_EQ")
                    .typeName("一元二次方程")
                    .confidence(0.9)
                    .estimatedDifficulty(3)
                    .build();
            }
        }
        return null;
    }
}
```

### 5.4 Step 4 - 解题模型匹配 (SolutionModelMatcher)

```java
@Service
public class SolutionModelMatcher {

    @Autowired
    private SolutionModelConfigRepository modelConfigRepo;

    public SolutionModel match(SolutionContext context) {
        String typeCode = context.getClassification().getTypeCode();
        String categoryCode = context.getClassification().getCategoryCode();

        // 1. 精确匹配题型
        Optional<SolutionModel> exact = modelConfigRepo
            .findActiveByTypeCode(typeCode);
        if (exact.isPresent()) {
            return exact.get();
        }

        // 2. 匹配题型大类
        Optional<SolutionModel> category = modelConfigRepo
            .findActiveByCategoryCode(categoryCode)
            .stream()
            .max(Comparator.comparingInt(SolutionModel::getPriority));
        if (category.isPresent()) {
            return category.get();
        }

        // 3. 学科通用模型
        return modelConfigRepo
            .findGeneralBySubject(context.getRequest().getSubject())
            .orElseThrow(() -> new SolutionException(
                ErrorCode.UNSUPPORTED_QUESTION_TYPE,
                "No solution model found for: " + typeCode
            ));
    }
}
```

### 5.7 Step 7 - 结果校验 (ResultValidator)

**职责：** 对 AI 输出进行多维度校验，确保正确性。

```java
@Service
public class ResultValidator {

    public ValidationResult validate(SolutionContext context) {
        List<ValidationItem> items = new ArrayList<>();

        // 1. 格式校验：JSON 是否可解析、步骤结构是否完整
        items.add(validateFormat(context.getSteps()));

        // 2. 完整性校验：是否有结论步骤、最终答案
        items.add(validateCompleteness(context));

        // 3. 数值验算：将步骤中的数值计算结果重新计算验证
        items.add(validateCalculations(context));

        // 4. 单位检查：物理题中的单位是否一致
        if (context.getRequest().getSubject() == SubjectEnum.PHYSICS) {
            items.add(validateUnits(context));
        }

        // 5. 逻辑一致性：前后步骤是否矛盾
        items.add(validateLogicalConsistency(context));

        // 6. 公式正确性：使用的公式是否正确
        items.add(validateFormulas(context));

        boolean allPassed = items.stream().allMatch(ValidationItem::isPassed);
        double confidence = items.stream()
            .mapToDouble(i -> i.isPassed() ? 1.0 : 0.0)
            .average().orElse(0.0);

        ValidationResult result = new ValidationResult();
        result.setPassed(allPassed);
        result.setItems(items);
        result.setConfidence(confidence);
        context.setValidation(result);

        return result;
    }

    /**
     * 数值验算 - 提取步骤中的计算表达式并验证
     */
    private ValidationItem validateCalculations(SolutionContext context) {
        for (SolutionStep step : context.getSteps()) {
            if (step.getType() == StepTypeEnum.CALCULATION) {
                // 提取等式，重新计算
                List<String> equations = extractEquations(step.getContent());
                for (String eq : equations) {
                    if (!verifyEquation(eq)) {
                        return new ValidationItem(
                            ValidationTypeEnum.NUMERIC,
                            false,
                            "计算验证失败: " + eq,
                            "请检查步骤 " + step.getStepOrder() + " 的计算"
                        );
                    }
                }
            }
        }
        return new ValidationItem(ValidationTypeEnum.NUMERIC, true, "计算验证通过", null);
    }

    /**
     * 简单等式验证（示例：解析 "25 - 24 = 1"）
     */
    private boolean verifyEquation(String equation) {
        try {
            String[] parts = equation.split("=");
            if (parts.length != 2) return true; // 无法验证的格式跳过

            double left = evaluateExpression(parts[0].trim());
            double right = evaluateExpression(parts[1].trim());

            return Math.abs(left - right) < 0.0001;
        } catch (Exception e) {
            return true; // 解析失败时跳过，不做阻断
        }
    }
}
```

```java
@Service
public class SolutionRetryHandler {

    public ScienceSolutionResponse handleRetry(SolutionContext context) {
        if (context.getRetryCount() >= SolutionContext.MAX_RETRY) {
            // 超过最大重试次数，返回部分结果 + 警告
            return buildPartialResponse(context);
        }

        context.setRetryCount(context.getRetryCount() + 1);

        // 根据校验失败原因调整策略
        ValidationResult validation = context.getValidation();
        List<ValidationItem> failures = validation.getItems().stream()
            .filter(i -> !i.isPassed())
            .toList();

        // 策略 1：数值计算错误 → 换推理模型重试
        if (failures.stream().anyMatch(i -> i.getType() == ValidationTypeEnum.NUMERIC)) {
            context.getMatchedModel().setRecommendedModelTier("REASONING");
        }

        // 策略 2：格式错误 → 添加更强的格式约束提示
        if (failures.stream().anyMatch(i -> i.getType() == ValidationTypeEnum.FORMAT)) {
            context.setAssembledPrompt(
                context.getAssembledPrompt() + "\n\n请严格按照 JSON 格式输出，不要添加任何额外文本。"
            );
        }

        // 重新调用 AI
        return solveInternal(context);
    }
}
```
