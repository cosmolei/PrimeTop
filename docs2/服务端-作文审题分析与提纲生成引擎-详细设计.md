## 1. 概述

### 1.1 功能定位

作文审题分析与提纲生成引擎是 PrimeTop 作文辅导模块的**前置智能引擎**，负责在正式写作前帮助学生完成两个关键步骤：

1. **审题分析**：理解作文题目要求，识别文体、关键词、约束条件、立意方向。
2. **提纲生成**：基于审题结果和学生年级，生成可执行、适龄的写作结构框架。

一句话定位：**将作文题目转化为学生可理解的写作任务书和可执行的段落结构。**

### 1.2 核心能力

| 能力域 | 能力项 | 优先级 | 说明 |
|--------|--------|--------|------|
| 题目解析 | 文体识别 | P0 | 判断记叙文、议论文、说明文、应用文等 |
| 题目解析 | 关键词提取 | P0 | 提取题目核心词、限制词、情感词 |
| 题目解析 | 约束条件识别 | P0 | 字数、文体、人称、场景、附加要求 |
| 题目解析 | 题意解读 | P1 | 分析出题意图和深层含义 |
| 立意推荐 | 多方向立意生成 | P0 | 提供 3-5 个适龄立意方向 |
| 立意推荐 | 立意适配性评估 | P1 | 评估每个方向对学生年级的适配度 |
| 提纲生成 | 段落结构生成 | P0 | 按文体生成开头-正文-结尾结构 |
| 提纲生成 | 段落内容建议 | P0 | 每段写什么、怎么写 |
| 提纲生成 | 字数分配 | P1 | 按段落分配建议字数 |
| 素材联动 | 推荐匹配素材 | P1 | 关联素材库，推荐名言、事例、句式 |
| 个性化 | 学段适配 | P0 | 小学/初中/高中生成不同深度提纲 |
| 个性化 | 写作风格偏好 | P2 | 支持学生选择风格（平实/生动/深刻） |

### 1.3 服务边界

| 职责 | 归属 |
|------|------|

## 2. 数据结构设计

### 2.1 核心实体关系

```
EssayTopicAnalysis (审题分析结果)
    │ 1:1
    ▼
EssayTask (作文任务) ──────── 复用作文任务表
    │ 1:N
    ▼
EssayOutline (提纲版本)
    │ 1:N
    ▼
EssayOutlineSection (提纲段落) ──────── 冗余存储于 outline.sections JSON

EssayTopicLibrary (作文题目库)
    │ 1:N
    ▼
EssayTopicAnalysisTemplate (审题分析模板)
```

### 2.2 审题分析结果表 `essay_topic_analysis`

```sql
CREATE TABLE essay_topic_analysis (
    id                    BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '分析ID',
    task_id               BIGINT NOT NULL UNIQUE COMMENT '关联作文任务ID',
    user_id               BIGINT NOT NULL COMMENT '用户ID',
    
    -- 原始题目信息
    raw_title             VARCHAR(500) NOT NULL COMMENT '原始题目文本',
    cleaned_title         VARCHAR(500) NOT NULL COMMENT '清洗后的题目文本',
    
    -- 结构化解析结果
    genre                 VARCHAR(30) NOT NULL COMMENT '文体: narrative/argumentative/expository/descriptive/practical/creative',
    genre_confidence      DECIMAL(4,3) NOT NULL DEFAULT 0.0 COMMENT '文体判断置信度 0-1',
    topic_keywords        JSON NOT NULL COMMENT '关键词 [{"word":"坚持","type":"theme","weight":0.9}]',
    constraint_items      JSON NOT NULL COMMENT '约束条件 [{"type":"word_limit","value":"600","unit":"字"}]',
    
    -- 题意解读
    interpretation        TEXT COMMENT '题意解读文本',
    writing_intent        TEXT COMMENT '出题意图分析',
    
    -- 立意方向
    theme_directions      JSON NOT NULL COMMENT '立意方向 [{"direction":"个人经历","suitability":"high","example":"..."}]',
    suggested_direction     INT DEFAULT 0 COMMENT '推荐默认立意方向索引',
    
    -- 写作建议
    writing_tips          JSON NOT NULL COMMENT '写作建议列表',
    common_pitfalls       JSON COMMENT '常见误区列表',
    
    -- 元数据
    analysis_model        VARCHAR(50) COMMENT '使用的AI模型',
    token_usage           JSON COMMENT 'Token使用量',
    analysis_duration_ms    INT COMMENT '分析耗时(毫秒)',
    status                TINYINT NOT NULL DEFAULT 1 COMMENT '0=失败, 1=成功, 2=部分成功(需确认)',
    created_at            DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at            DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_created (user_id, created_at DESC),
    INDEX idx_genre (genre)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='作文审题分析结果表';
```

### 2.3 提纲表 `essay_outline`

```sql
CREATE TABLE essay_outline (
    id                    BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '提纲ID',
    task_id               BIGINT NOT NULL COMMENT '关联作文任务ID',
    user_id               BIGINT NOT NULL COMMENT '用户ID',
    analysis_id             BIGINT NOT NULL COMMENT '关联审题分析ID',
    
    -- 版本管理
    version               INT NOT NULL DEFAULT 1 COMMENT '版本号',
    is_active             TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否当前使用版本',
    parent_outline_id     BIGINT COMMENT '父提纲ID（用于修改迭代）',
    
    -- 生成参数
    chosen_direction_index INT NOT NULL DEFAULT 0 COMMENT '选用的立意方向索引',
    custom_direction        VARCHAR(200) COMMENT '自定义立意方向',
    style_preference        VARCHAR(20) DEFAULT 'balanced' COMMENT '风格: balanced/emotional/profound/lively',
    grade_stage             TINYINT NOT NULL COMMENT '生成时学段快照',
    grade_level             SMALLINT NOT NULL COMMENT '生成时年级快照',
    
    -- 提纲内容
    title                 VARCHAR(200) NOT NULL COMMENT '作文标题（可修改）',
    total_word_estimate   INT COMMENT '预估总字数',
    sections              JSON NOT NULL COMMENT '段落结构数组',
    
    -- 素材推荐
    recommended_materials JSON COMMENT '推荐素材 [{"material_id":1001,"type":"quote","usage":"开头"}]',
    
    -- 状态
    status                TINYINT NOT NULL DEFAULT 1 COMMENT '0=废弃, 1=有效, 2=已应用（开始写作）',
    
    -- 元数据
    generation_model      VARCHAR(50) COMMENT '使用的AI模型',
    token_usage           JSON COMMENT 'Token使用量',
    generation_duration_ms INT COMMENT '生成耗时(毫秒)',
    created_at            DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at            DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_task_version (task_id, version),
    INDEX idx_user_created (user_id, created_at DESC),
    INDEX idx_active (task_id, is_active)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='作文提纲表';
```

### 2.4 作文题目库 `essay_prompt_library`

```sql
CREATE TABLE essay_prompt_library (
    id                    BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '题目ID',
    title                 VARCHAR(500) NOT NULL COMMENT '题目文本',
    
    -- 结构化属性
    genre                 VARCHAR(30) NOT NULL COMMENT '标准文体',
    subject               VARCHAR(20) NOT NULL DEFAULT 'chinese' COMMENT '学科',
    grade_stage           TINYINT NOT NULL COMMENT '适用学段',
    grade_level_min       SMALLINT COMMENT '最低年级',
    grade_level_max       SMALLINT COMMENT '最高年级',
    
    -- 解析结果（预计算）
    topic_keywords        JSON COMMENT '关键词',
    constraint_items      JSON COMMENT '约束条件',
    theme_directions      JSON COMMENT '标准立意方向',
    
    -- 来源与状态
    source                VARCHAR(30) NOT NULL COMMENT '来源: textbook/exam/curated/ai_generated',
    source_ref            VARCHAR(200) COMMENT '来源引用',
    difficulty            TINYINT DEFAULT 3 COMMENT '难度1-5',
    usage_count           INT DEFAULT 0 COMMENT '使用次数',
    status                TINYINT NOT NULL DEFAULT 1 COMMENT '0=下架, 1=上架',
    
    -- 搜索与向量
    search_text           TEXT COMMENT '搜索文本',
    embedding_vector      BLOB COMMENT '语义向量',
    
    created_at            DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at            DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_genre_stage (genre, grade_stage),
    INDEX idx_subject_stage (subject, grade_stage),
    INDEX idx_source (source),
    FULLTEXT INDEX ft_title (title, search_text)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='作文题目库';
```

## 3. API 接口设计

### 3.1 接口总览

| 方法 | 路径 | 说明 | 优先级 |
|------|------|------|--------|
| POST | `/api/v1/essay/topics/analyze` | 作文题目审题分析 | P0 |
| POST | `/api/v1/essay/outlines/generate` | 基于审题结果生成提纲 | P0 |
| POST | `/api/v1/essay/outlines/regenerate` | 重新生成提纲（换方向/风格） | P1 |
| GET | `/api/v1/essay/outlines/{outlineId}` | 获取提纲详情 | P0 |
| PUT | `/api/v1/essay/outlines/{outlineId}` | 修改提纲（标题/段落） | P1 |
| POST | `/api/v1/essay/outlines/{outlineId}/apply` | 应用提纲开始写作 | P1 |
| GET | `/api/v1/essay/outlines` | 获取某任务下的提纲版本列表 | P1 |
| GET | `/api/v1/essay/prompts/similar` | 相似题目推荐 | P2 |
| GET | `/api/v1/essay/genres` | 获取支持的文体列表 | P0 |

### 4.1 题目解析引擎 (TopicAnalyzer)

```java
@Service
@Slf4j
public class TopicAnalyzer {

    @Autowired private AiModelClient aiClient;
    @Autowired private PromptTemplateService templateService;
    @Autowired private TopicAnalysisRepository analysisRepository;

    private static final Pattern WORD_LIMIT_PATTERN = Pattern.compile(
        "(?:不少于|至少|不少于约|不得低于|以上)(\\d+)[\\s]*(?:字|个字符|字左右)?"
    );
    private static final Pattern GENRE_PATTERN = Pattern.compile(
        "(记叙文|议论文|说明文|描写文|应用文|散文|诗歌|书信|演讲稿|读后感|观后感)"
    );

    /**
     * 主入口：执行审题分析
     */
    public TopicAnalysisResult analyze(AnalyzeTopicRequest request) {
        long startTime = System.currentTimeMillis();
        
        // 1. 题目清洗与规则预处理
        String cleanedTitle = cleanTitle(request.getTitle());
        List<ConstraintItem> constraints = extractConstraintsByRule(cleanedTitle);
        String genreHint = extractGenreHintByRule(cleanedTitle);
        
        // 2. 加载对应模板
        PromptTemplate template = templateService.getTemplate(
            genreHint, request.getGradeStage());
        
        // 3. 调用 AI 进行深度分析
        String prompt = buildAnalysisPrompt(template, request, cleanedTitle, constraints);
        String aiResponse = aiClient.chat(prompt, "essay-topic-analysis");
        
        // 4. 解析并校验
        TopicAnalysisResult result = parseAnalysisResult(aiResponse);
        result.setRawTitle(request.getTitle());
        result.setCleanedTitle(cleanedTitle);
        result.setTaskId(request.getTaskId());
        result.setUserId(request.getUserId());
        result.setAnalysisDurationMs((int)(System.currentTimeMillis() - startTime));
        
        // 5. 合并规则提取与 AI 分析结果
        mergeRuleExtractedConstraints(result, constraints);
        
        // 6. 置信度校验：低于阈值标记需确认
        if (result.getGenreConfidence() < 0.7) {
            result.setStatus(AnalysisStatus.NEEDS_CONFIRMATION);
        }
        
        // 7. 持久化
        analysisRepository.save(result.toEntity());
        
        return result;
    }

    /**
     * 题目文本清洗：去除多余空格、统一标点
     */
    public String cleanTitle(String title) {
        return title
            .replaceAll("\\s+", " ")
            .replaceAll("[，,]", "，")
            .replaceAll("[。.]", "。")
            .replaceAll("[\\?？]", "？")
            .trim();
    }

    /**
     * 基于规则提取约束条件（作为 AI 分析的补充和校验）
     */
    public List<ConstraintItem> extractConstraintsByRule(String title) {
        List<ConstraintItem> constraints = new ArrayList<>();
        
        Matcher wordMatcher = WORD_LIMIT_PATTERN.matcher(title);
        if (wordMatcher.find()) {
            constraints.add(ConstraintItem.builder()
                .type("word_limit")
                .value(wordMatcher.group(1))
                .unit("字")
                .operator("min")
                .rawText(wordMatcher.group(0))
                .build());
        }
        
        Matcher genreMatcher = GENRE_PATTERN.matcher(title);
        if (genreMatcher.find()) {
            constraints.add(ConstraintItem.builder()
                .type("genre")
                .value(genreToCode(genreMatcher.group(1)))
                .rawText(genreMatcher.group(1))
                .build());
        }
        
        // 人称约束
        if (title.contains("我") || title.contains("自己")) {
            constraints.add(ConstraintItem.builder()
                .type("person")
                .value("first")
                .rawText("第一人称")
                .build());
        }
        
        return constraints;
    }

    private String genreToCode(String chineseGenre) {
        return switch (chineseGenre) {
            case "记叙文" -> "narrative";
            case "议论文" -> "argumentative";
            case "说明文" -> "expository";
            case "描写文" -> "descriptive";
            case "应用文" -> "practical";
            case "散文" -> "prose";
            case "诗歌" -> "poetry";
            case "书信" -> "letter";
            case "演讲稿" -> "speech";
            case "读后感", "观后感" -> "reflection";
            default -> "narrative";
        };
    }

    /**
     * 合并规则提取的约束，优先级：规则 > AI
     */
    private void mergeRuleExtractedConstraints(TopicAnalysisResult result, 
                                                  List<ConstraintItem> ruleConstraints) {
        Map<String, ConstraintItem> merged = new HashMap<>();
        
        // 先放入 AI 提取的
        for (ConstraintItem item : result.getConstraintItems()) {
            merged.put(item.getType(), item);
        }
        
        // 规则提取覆盖（更可靠）
        for (ConstraintItem item : ruleConstraints) {
            merged.put(item.getType(), item);
        }
        
        result.setConstraintItems(new ArrayList<>(merged.values()));
    }
}
```

### 4.2 关键词提取与权重计算

```python
from typing import List, Dict
import jieba
import jieba.analyse
import re

class TopicKeywordExtractor:
    """作文题目关键词提取器"""
    
    # 停用词：虚词、助词、常见泛化词
    STOP_WORDS = {
        "请", "以", "为", "题", "写", "一篇", "一篇作文", "作文", "文章",
        "不少于", "字", "要求", "的", "了", "和", "与", "或", "在", "是",
        "有", "我", "你", "他", "她", "它", "我们", "你们", "他们"
    }
    
    # 文体提示词
    GENRE_HINTS = {
        "记叙文": "narrative", "议论文": "argumentative", "说明文": "expository",
        "描写文": "descriptive", "应用文": "practical", "书信": "letter",
        "演讲稿": "speech", "读后感": "reflection", "观后感": "reflection"
    }
    
    def extract(self, title: str, top_k: int = 10) -> List[Dict]:
        """
        提取关键词，包含：
        1. TF-IDF 统计关键词
        2. 题目核心词（引号内、书名号内）
        3. 文体提示词
        """
        keywords = []
        
        # 1. 提取引号/书名号中的核心词
        quoted = re.findall(r'[\"""\'""《》（）]([^\"""\'""《》（）]+)[\"""\'""《》（）]', title)
        for q in quoted:
            keywords.append({
                "word": q,
                "type": "core_quoted",
                "weight": 1.0,
                "is_core": True
            })
        
        # 2. 文体提示词
        for hint, genre in self.GENRE_HINTS.items():
            if hint in title:
                keywords.append({
                    "word": hint,
                    "type": "genre_hint",
                    "weight": 0.95,
                    "is_core": False
                })
        
        # 3. TF-IDF 提取
        title_clean = re.sub(r'[，。！？；：\"""\'""（）《》]', '', title)
        tfidf_keywords = jieba.analyse.extract_tags(
            title_clean, topK=top_k, withWeight=True,
            allowPOS=("n", "v", "a", "ns", "nz", "vn")  # 名词、动词、形容词
        )
        
        for word, weight in tfidf_keywords:
            if word in self.STOP_WORDS or len(word) < 2:
                continue
            # 避免重复
            if not any(k["word"] == word for k in keywords):
                keywords.append({
                    "word": word,
                    "type": "theme" if weight > 0.5 else "auxiliary",
                    "weight": round(weight, 3),
                    "is_core": weight > 0.5
                })
        
        # 4. 重新归一化权重
        max_weight = max(k["weight"] for k in keywords) if keywords else 1.0
        for k in keywords:
            k["weight"] = round(k["weight"] / max_weight, 3)
        
        return sorted(keywords, key=lambda x: x["weight"], reverse=True)[:top_k]

    def classify_keyword_type(self, word: str, title: str) -> str:
        """判断关键词类型"""
        if word in self.GENRE_HINTS:
            return "genre_hint"
        if word in re.findall(r'[\"""\'""]([^\"""\'""]+)[\"""\'""]', title):
            return "core_quoted"
        if re.search(r'[0-9]', word):
            return "numerical"
        return "theme"
```

```java
@Service
@Slf4j
public class OutlineGenerator {

    @Autowired private AiModelClient aiClient;
    @Autowired private OutlineTemplateRepository templateRepository;
    @Autowired private MaterialServiceClient materialService;
    @Autowired private OutlineRepository outlineRepository;

    /**
     * 基于审题分析结果生成写作提纲
     */
    public OutlineResult generate(GenerateOutlineRequest request, TopicAnalysisResult analysis) {
        long startTime = System.currentTimeMillis();
        
        // 1. 校验选用方向
        int directionIndex = request.getChosenDirectionIndex();
        if (directionIndex < 0 || directionIndex >= analysis.getThemeDirections().size()) {
            directionIndex = analysis.getSuggestedDirection();
        }
        ThemeDirection chosenDirection = analysis.getThemeDirections().get(directionIndex);
        
        // 2. 加载对应文体模板
        OutlineTemplate template = templateRepository
            .findByGenreAndStage(analysis.getGenre(), request.getGradeStage())
            .orElseGet(() -> templateRepository.findDefaultTemplate(analysis.getGenre()));
        
        // 3. 计算字数分配
        int wordLimit = resolveWordLimit(analysis.getConstraintItems(), request.getWordLimit());
        List<WordAllocation> allocations = calculateWordAllocation(
            template, wordLimit, request.getGradeStage());
        
        // 4. 构建 Prompt
        String prompt = buildOutlinePrompt(template, analysis, chosenDirection, 
                                            request.getStylePreference(), allocations);
        
        // 5. 调用 AI 生成
        String aiResponse = aiClient.chat(prompt, "essay-outline-generation");
        List<OutlineSection> sections = parseOutlineSections(aiResponse);
        
        // 6. 如果 AI 未返回完整结构，用模板兜底
        if (sections.size() < template.getMinSections()) {
            sections = mergeWithTemplate(sections, template, allocations, chosenDirection);
        }
        
        // 7. 推荐素材
        List<RecommendedMaterial> materials = recommendMaterials(
            analysis.getTopicKeywords(), chosenDirection, request.getGradeStage());
        
        // 8. 组装结果
        int totalEstimate = sections.stream().mapToInt(OutlineSection::getWordEstimate).sum();
        OutlineResult result = OutlineResult.builder()
            .taskId(request.getTaskId())
            .analysisId(analysis.getId())
            .version(1)
            .title(request.getTitle())
            .chosenDirectionIndex(directionIndex)
            .stylePreference(request.getStylePreference())
            .totalWordEstimate(totalEstimate)
            .sections(sections)
            .recommendedMaterials(materials)
            .generationDurationMs((int)(System.currentTimeMillis() - startTime))
            .build();
        
        // 9. 持久化
        outlineRepository.save(result.toEntity());
        
        return result;
    }

    /**
     * 解析字数约束
     */
    private int resolveWordLimit(List<ConstraintItem> constraints, Integer requestLimit) {
        if (requestLimit != null && requestLimit > 0) {
            return requestLimit;
        }
        for (ConstraintItem c : constraints) {
            if ("word_limit".equals(c.getType()) && c.getValue() != null) {
                try {
                    int limit = Integer.parseInt(c.getValue());
                    return "min".equals(c.getOperator()) ? limit + 100 : limit;
                } catch (NumberFormatException e) {
                    log.warn("字数约束解析失败: {}", c.getValue());
                }
            }
        }
        return 600; // 默认600字
    }

    /**
     * 按模板计算各段落字数分配
     */
    private List<WordAllocation> calculateWordAllocation(
            OutlineTemplate template, int wordLimit, int gradeStage) {
        List<WordAllocation> allocations = new ArrayList<>();
        List<SectionTemplate> sectionTemplates = template.getSectionTemplates();
        
        // 按比例分配，初中及以上正文占比更高
        double bodyRatio = gradeStage >= 3 ? 0.75 : 0.70;
        int bodyWords = (int)(wordLimit * bodyRatio);
        int bodySectionCount = sectionTemplates.size() - 2; // 去掉开头和结尾
        int bodyPerSection = bodySectionCount > 0 ? bodyWords / bodySectionCount : bodyWords;
        
        for (int i = 0; i < sectionTemplates.size(); i++) {
            SectionTemplate st = sectionTemplates.get(i);
            int estimate;
            if (i == 0 || i == sectionTemplates.size() - 1) {
                // 开头和结尾
                estimate = (int)(wordLimit * st.getRatio());
            } else {
                estimate = bodyPerSection;
            }
            allocations.add(new WordAllocation(st.getSectionType(), estimate));
        }
        return allocations;
    }

    /**
     * 根据关键词和立意方向推荐素材
     */
    private List<RecommendedMaterial> recommendMaterials(
            List<TopicKeyword> keywords, ThemeDirection direction, int gradeStage) {
        List<String> themes = keywords.stream()
            .filter(k -> k.isCore())
            .map(TopicKeyword::getWord)
            .collect(Collectors.toList());
        
        if (themes.isEmpty()) {
            themes = List.of(direction.getTitle().split("——")[0]);
        }
        
        return materialService.recommendMaterials(
            MaterialRecommendRequest.builder()
                .themes(themes)
                .gradeStage(gradeStage)
                .categories(List.of("quote", "story", "example", "sentence"))
                .limit(5)
                .build()
        );
    }
}
```

```java
@Component
public class DirectionFitnessEvaluator {

    /**
     * 评估每个立意方向对当前学生的适配度
     */
    public List<ThemeDirection> evaluateFitness(
            List<ThemeDirection> directions, int gradeStage, int gradeLevel) {
        
        return directions.stream().map(d -> {
            int fitScore = 0;
            
            // 1. 年级适配
            List<String> gradeFits = d.getGradeFit();
            String currentGrade = gradeStage + "_" + gradeLevel;
            if (gradeFits.contains(currentGrade)) {
                fitScore += 30;
            } else if (gradeFits.stream().anyMatch(g -> g.startsWith(String.valueOf(gradeStage)))) {
                fitScore += 15;
            }
            
            // 2. 难度适配
            int difficulty = d.getDifficulty();
            int expectedDifficulty;
            switch (gradeStage) {
                case 2: expectedDifficulty = gradeLevel <= 2 ? 2 : 3; break; // 小学
                case 3: expectedDifficulty = gradeLevel <= 2 ? 3 : 4; break; // 初中
                case 4: expectedDifficulty = 4; break; // 高中
                default: expectedDifficulty = 2;
            }
            fitScore += Math.max(0, 20 - Math.abs(difficulty - expectedDifficulty) * 5);
            
            // 3. 生活贴近度（个人经历类更高）
            if (d.getTitle().contains("个人经历") || d.getTitle().contains("身边")) {
                fitScore += 20;
            }
            
            // 4. 素材丰富度（历史人物类对低龄学生较低）
            if (d.getTitle().contains("历史人物") && gradeStage <= 2) {
                fitScore -= 15;
            }
            
            String suitability;
            if (fitScore >= 70) suitability = "high";
            else if (fitScore >= 45) suitability = "medium";
            else suitability = "low";
            
            d.setFitnessScore(fitScore);
            d.setSuitability(suitability);
            return d;
        }).sorted((a, b) -> Integer.compare(b.getFitnessScore(), a.getFitnessScore()))
          .collect(Collectors.toList());
    }
```

### 4.6 提纲解析与校验

```java
@Service
public class OutlineParser {

    private static final ObjectMapper MAPPER = new ObjectMapper();

    public List<OutlineSection> parse(String aiResponse) {
        // 1. 提取 JSON 块
        String json = extractJsonBlock(aiResponse);
        
        try {
            JsonNode root = MAPPER.readTree(json);
            JsonNode sectionsNode = root.get("sections");
            if (sectionsNode == null || !sectionsNode.isArray()) {
                throw new OutlineParseException("提纲解析失败：缺少 sections 数组");
            }
            
            List<OutlineSection> sections = new ArrayList<>();
            for (JsonNode node : sectionsNode) {
                OutlineSection section = OutlineSection.builder()
                    .index(node.has("index") ? node.get("index").asInt() : sections.size())
                    .section(getTextOrDefault(node, "section", "段落" + (sections.size() + 1)))
                    .heading(getTextOrDefault(node, "heading", ""))
                    .content(getTextOrDefault(node, "content", ""))
                    .technique(getTextOrDefault(node, "technique", ""))
                    .wordEstimate(node.has("word_estimate") ? node.get("word_estimate").asInt() : 100)
                    .keyPoints(parseStringList(node, "key_points"))
                    .hints(parseStringList(node, "hints"))
                    .build();
                sections.add(section);
            }
            return sections;
        } catch (JsonProcessingException e) {
            throw new OutlineParseException("提纲JSON解析失败: " + e.getMessage());
        }
    }

    /**
     * 校验提纲完整性
     */
    public void validate(List<OutlineSection> sections, int gradeStage) {
        if (sections == null || sections.isEmpty()) {
            throw new OutlineParseException("提纲为空");
        }
        
        // 必须有开头和结尾
        boolean hasOpening = sections.stream().anyMatch(s -> 
            s.getSection().contains("开头") || s.getSection().contains("引言"));
        boolean hasEnding = sections.stream().anyMatch(s -> 
            s.getSection().contains("结尾") || s.getSection().contains("结语"));
        
        if (!hasOpening || !hasEnding) {
            throw new OutlineParseException("提纲缺少开头或结尾段落");
        }
        
        // 高中议论文至少需要 3 个正文论点
        if (gradeStage >= 4 && sections.size() < 4) {
            log.warn("高中提纲正文段落偏少: {}段", sections.size());
        }
    }

    private String extractJsonBlock(String text) {
        // 去除 markdown 代码块标记
        String cleaned = text.replaceAll("```json\\s*", "").replaceAll("```\\s*", "").trim();
        // 如果有多余文本，提取第一个 { 到最后一个 }
        int start = cleaned.indexOf("{");
        int end = cleaned.lastIndexOf("}");
        if (start >= 0 && end > start) {
            return cleaned.substring(start, end + 1);
        }
        return cleaned;
    }
}
```

## 6. 错误处理

### 6.1 业务错误码

| 错误码 | HTTP 状态 | 说明 | 客户端处理 |
|--------|----------|------|-----------|
| `ESSAY_TOPIC_001` | 400 | 题目文本为空 | 提示输入题目 |
| `ESSAY_TOPIC_002` | 400 | 题目文本过长（>500字） | 提示精简题目 |
| `ESSAY_TOPIC_003` | 400 | 学段/年级参数缺失 | 提示选择年级 |
| `ESSAY_TOPIC_004` | 404 | 作文任务不存在 | 刷新任务列表 |
| `ESSAY_TOPIC_005` | 409 | 该任务已有审题分析 | 返回已有分析结果 |
| `ESSAY_TOPIC_010` | 422 | 文体判断置信度低 | 提示用户确认文体 |
| `ESSAY_TOPIC_011` | 422 | 题目类型不支持 | 提示换题或手动输入 |
| `ESSAY_TOPIC_020` | 500 | AI 审题分析失败 | 提示稍后重试 |
| `ESSAY_TOPIC_021` | 500 | AI 返回格式异常 | 重试一次，失败则提示 |
| `ESSAY_TOPIC_030` | 429 | 每日审题次数超限 | 提示升级会员 |
| `ESSAY_OUTLINE_001` | 400 | 未提供审题分析ID | 提示先进行审题分析 |
| `ESSAY_OUTLINE_002` | 400 | 立意方向索引越界 | 提示重新选择 |
| `ESSAY_OUTLINE_003` | 404 | 审题分析结果不存在 | 提示重新分析 |
| `ESSAY_OUTLINE_010` | 500 | 提纲生成失败 | 提示稍后重试 |
| `ESSAY_OUTLINE_011` | 500 | 提纲结构不完整 | 使用模板兜底 |
| `ESSAY_OUTLINE_020` | 429 | 每日提纲生成次数超限 | 提示升级会员 |
| `ESSAY_OUTLINE_030` | 409 | 提纲已被应用，不可修改 | 提示重新生成 |

### 6.2 降级策略

| 异常场景 | 降级方案 |
|----------|----------|
| AI 审题分析超时 | 返回规则提取结果（文体、字数、关键词）+ 通用写作建议 |
| AI 返回格式异常 | 重试 1 次，仍失败则使用模板化输出 |
| 文体判断置信度低 | 标记 `PARTIAL` 状态，让学生确认文体后再生成提纲 |
| 提纲生成结构不完整 | 用预定义文体模板补全段落结构 |
| 素材服务不可用 | 跳过素材推荐，不影响提纲主体 |
| 用户等级/风格参数缺失 | 使用默认配置（balanced、当前学段） |
| 题目库匹配失败 | 不影响分析流程，仅记录日志 |

## 8. 安全与合规

### 8.1 内容安全

- 用户提交的作文题目需经过敏感词过滤，防止恶意内容注入。
- AI 生成的审题分析、立意方向、提纲建议需经过内容安全审核。
- 禁止生成涉及政治、暴力、色情、歧视等内容的写作建议。

### 8.2 数据隐私

- 审题分析结果仅用户本人和绑定家长可见。
- 不将用户作文题目用于模型训练（除非用户明确授权）。
- 作文题目库中的个人数据需脱敏处理。

### 8.3 权限控制

| 操作 | 权限要求 |
|------|----------|
| 审题分析 | 登录用户，每日次数受会员权益限制 |
| 查看自己的分析结果 | 本人或绑定家长 |
| 查看题目库 | 运营人员 |
| 修改模板 | 教研管理员 |
| 查看他人分析结果 | 禁止（教师端后续按需开放） |

### 8.4 防刷限流

| 接口 | 免费用户 | 月度会员 | 年度会员 |
|------|----------|----------|----------|
| 审题分析 | 5次/天 | 无限 | 无限 |
| 提纲生成 | 5次/天 | 50次/天 | 无限 |
| 重新生成 | 3次/天 | 20次/天 | 50次/天 |
| 修改提纲 | 10次/天 | 50次/天 | 无限 |

限流基于 Redis 滑动窗口，key 格式：`essay:rate:{action}:{user_id}:YYYYMMDD`。

## 13. 总结

本文档定义了 PrimeTop 作文审题分析与提纲生成引擎的完整服务端实现方案：

1. **5 张核心数据表**：审题分析结果、提纲、作文题目库、审题模板库、复用作文任务表。
2. **9 个 API 接口**：涵盖审题分析、提纲生成/重新生成/查询/修改/应用、相似题目推荐等。
3. **4 个核心算法模块**：题目解析、关键词提取、提纲生成、立意方向适配性评估。
4. **3 层状态机**：作文任务状态、提纲版本状态、审题分析状态。
5. **完善降级策略**：规则兜底、模板补全、限流、监控告警。
