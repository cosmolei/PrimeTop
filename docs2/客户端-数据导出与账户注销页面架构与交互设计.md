## 1. 概述

### 1.1 设计目标

为 PrimeTop 用户提供清晰、安全、可信赖的数据导出和账户注销交互体验，满足《个人信息保护法》合规要求，同时降低因误操作导致的用户流失。

### 1.2 核心原则

| 原则 | 说明 |
|------|------|
| **透明可控** | 用户清楚知道哪些数据会被导出/删除，每一步都有确认 |
| **可逆优先** | 注销设置 15 天冷静期，导出支持随时取消 |
| **安全兜底** | 关键操作需要身份验证（短信验证码 / 生物识别） |
| **低龄适配** | 未成年用户操作需家长代理确认 |
| **状态可见** | 异步任务提供进度反馈，完成后主动通知 |

### 1.3 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 隐私与数据管理页 | `/settings/privacy` | 入口页，汇聚数据导出和账户注销 |
| 数据导出主页 | `/settings/privacy/export` | 选择导出范围和格式 |
| 导出模块选择页 | `/settings/privacy/export/modules` | 细粒度勾选要导出的数据模块 |
| 导出进度页 | `/settings/privacy/export/progress/:taskId` | 导出任务进度和下载 |
| 导出历史页 | `/settings/privacy/export/history` | 历史导出记录列表 |
| 账户注销引导页 | `/settings/privacy/deactivate` | 注销须知和挽留 |
| 注销身份验证页 | `/settings/privacy/deactivate/verify` | 二次身份验证 |
| 注销权益检查页 | `/settings/privacy/deactivate/check` | 展示未消耗权益 |
| 注销确认页 | `/settings/privacy/deactivate/confirm` | 最终确认（含冷静期说明） |
| 注销状态页 | `/settings/privacy/deactivate/status` | 注销进行中/冷静期状态 |
| 家长代理确认页 | `/settings/privacy/parent-confirm` | 未成年操作的家长授权弹窗 |

```dart
  bool _isLoading = true;

  @override
  void initState() {
    super.initState();
    _loadLastExportDate();
  }

    final result = await DataExportApi.getLastExportSummary();

      setState(() {
        _lastExportDate = result.lastExportDate;
        _isLoading = false;
      });

    // 检查是否未成年 → 需要家长代理
    if (UserScope.isMinor()) {
      _showParentConfirmDialog(
        action: 'DATA_EXPORT',
        onConfirmed: () => context.push('/settings/privacy/export'),
      );
    } else {
      context.push('/settings/privacy/export');
    }
  }

  void _onDeactivateTap() {
    // 注销入口始终需要二次确认
    _showDeactivateWarningDialog();
  }

  void _showDeactivateWarningDialog() {
    showCupertinoDialog(
      context: context,
      builder: (ctx) => CupertinoAlertDialog(
        title: const Text('确认要注销账户？'),
        content: const Text(
          '注销后你的所有学习数据、错题本、会员权益等将被永久删除，'
          '且无法恢复。建议先导出数据备份。',
        ),
        actions: [
          CupertinoDialogAction(
            child: const Text('先导出数据'),
            onPressed: () {
              Navigator.pop(ctx);
              context.push('/settings/privacy/export');
            },
          ),
          CupertinoDialogAction(
            isDestructiveAction: true,
            child: const Text('继续注销'),

              Navigator.pop(ctx);
              if (UserScope.isMinor()) {
                _showParentConfirmDialog(
                  action: 'ACCOUNT_DEACTIVATE',
                  onConfirmed: () => context.push('/settings/privacy/deactivate'),

          CupertinoDialogAction(
            isDefaultAction: true,
            child: const Text('取消'),
            onPressed: () => Navigator.pop(ctx),
```

### 4.3 核心交互

```dart
class DataExportPage extends StatefulWidget {
  @override
  State<DataExportPage> createState() => _DataExportPageState();
}

class _DataExportPageState extends State<DataExportPage> {
  ExportType _type = ExportType.full;
  ExportFormat _format = ExportFormat.html;
  Set<ExportModule> _selectedModules = {};
  bool _isSubmitting = false;

  // 推荐模块（默认选中）
  final _recommendedModules = kExportModules
      .where((m) => m.isRecommended)
      .map((m) => m.module)
      .toSet();

  @override
  void initState() {
    super.initState();
    _selectedModules = {..._recommendedModules};
  }

  Future<void> _startExport() async {
    if (_isSubmitting) return;

    // 前置校验
    if (_type == ExportType.partial && _selectedModules.isEmpty) {
      showToast('请至少选择一个导出模块');
      return;
    }

    setState(() => _isSubmitting = true);

    try {
      final request = ExportRequest(
        exportType: _type,
        selectedModules: _type == ExportType.partial
            ? _selectedModules.toList()
            : null,
        format: _format,
      );

      final task = await DataExportApi.createExportTask(request);

      if (!mounted) return;

      // 跳转到进度页
      context.replace('/settings/privacy/export/progress/${task.taskId}');
    } on ApiException catch (e) {
      _handleExportError(e);
    } finally {
      if (mounted) setState(() => _isSubmitting = false);
    }
  }

  void _handleExportError(ApiException e) {
    // v1.1 修正：错误码对齐 E2E 权威 43xxx 段位（契约 R10），
    // v1.0 符号化码 EXPORT_TASK_LIMIT_EXCEEDED / ACCOUNT_NOT_VERIFIED 废弃。
    switch (e.code) {
      case '43011': // 24h 内已有进行中的导出任务
        showDialog(
          context: context,
          builder: (ctx) => AlertDialog(
            title: const Text('导出任务进行中'),
            content: const Text('你已有正在进行的导出任务，请等待完成后再试。'),
            actions: [
              TextButton(
                onPressed: () {
                  Navigator.pop(ctx);
                  context.push('/settings/privacy/export/history');
                },
                child: const Text('查看导出记录'),
              ),
            ],
          ),
        );
        break;
      case '43012': // 全量导出 30 天限 2 次
        showToast('全量导出每 30 天限 2 次，可选择性导出或稍后再试');
        break;
      case '43010': // 模块列表为空（客户端预校验兜底）
        showToast('请至少选择一个导出模块');
        break;
      default:
        showToast('导出请求失败，请稍后重试');
    }
  }
}
```

```dart
class ExportModuleSelectPage extends StatefulWidget {
  final Set<ExportModule> initialSelection;

  @override
  State<ExportModuleSelectPage> createState() => _State();
}

class _State extends State<ExportModuleSelectPage> {
  late Set<ExportModule> _selected;

  @override
  void initState() {
    super.initState();
    _selected = {...widget.initialSelection};
  }

  @override
  Widget build(BuildContext context) {
    final recommended =
        kExportModules.where((m) => m.isRecommended).toList();
    final optional =
        kExportModules.where((m) => !m.isRecommended).toList();

    return Scaffold(
      appBar: AppBar(title: const Text('选择导出内容')),
      body: Column(
        children: [
          // 计数器
          _buildCounter(),
          // 推荐模块
          Expanded(
            child: ListView(
              children: [
                const SectionHeader(title: '推荐导出'),
                ...recommended.map((m) => _buildModuleTile(m)),
                const SectionHeader(title: '可选导出'),
                ...optional.map((m) => _buildModuleTile(m)),
              ],
            ),
          ),
          // 底部按钮
          _buildBottomBar(),
        ],
      ),
    );
  }

  Widget _buildCounter() {
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 12),
      color: Theme.of(context).colorScheme.surfaceVariant,
      child: Row(
        mainAxisAlignment: MainAxisAlignment.spaceBetween,
        children: [
          Text('已选择 ${_selected.length}/${kExportModules.length} 个模块'),
          if (_selected.isNotEmpty)
            TextButton(
              onPressed: () => setState(() => _selected.clear()),
              child: const Text('清空'),
            ),
        ],
      ),
    );
  }

  Widget _buildModuleTile(ExportModuleItem item) {
    final isSelected = _selected.contains(item.module);
    return CheckboxListTile(
      secondary: Icon(item.icon),
      title: Text(item.title),
      subtitle: Text(item.description),
      value: isSelected,
      onChanged: (v) {
        setState(() {
          if (v == true) {
            _selected.add(item.module);
          } else {
            _selected.remove(item.module);
          }
        });
      },
    );
  }

  Widget _buildBottomBar() {
    return SafeArea(
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: FilledButton(
          onPressed: _selected.isEmpty ? null : () => _confirm(),
          child: Text('确认选择（${_selected.length} 个模块）'),
        ),
      ),
    );
  }

  void _confirm() {
    Navigator.pop(context, _selected);
  }
}
```

```dart
/// 导出任务状态枚举（v1.1 对齐 E2E 权威十态，契约 R10）
///
/// 服务端十态：PENDING / AGGREGATING / PACKAGING / UPLOADING /
///   COMPLETED / DOWNLOADING / DOWNLOADED / EXPIRED / FAILED / CANCELLED
///
/// v1.0 缺陷修正：
///  - 新增 DOWNLOADING / DOWNLOADED（下载行为驱动态，E2E G5）
///  - ENCRYPTING 为展示态细分（服务端加密隶属 PACKAGING 阶段，不落独立态）
///  - QUEUED 展示态对应服务端 PENDING（含排队语义，见 D1/D3 降级）
enum ExportTaskStatus {
  queued,       // 展示态 → 服务端 PENDING（排队/待领取）
  aggregating,  // 服务端 AGGREGATING
  packaging,    // 服务端 PACKAGING（含加密，ENCRYPTING 为其展示细分）
  uploading,    // 服务端 UPLOADING
  completed,    // 服务端 COMPLETED（可下载）
  downloading,  // 服务端 DOWNLOADING（首次下载驱动）
  downloaded,   // 服务端 DOWNLOADED
  expired,      // 服务端 EXPIRED（7 天保留期巡检置位，G6）
  failed,       // 服务端 FAILED
  cancelled,    // 服务端 CANCELLED
}

/// 展示细分态：加密中（渲染层使用，不参与状态机转移）
enum PackagingSubPhase { zipping, encrypting }

/// 单个模块状态（与服务端 module_progress 对齐：PENDING/PROCESSING/DONE/FAILED）
enum ModuleExportStatus {
  pending,    // 等待中
  running,    // 进行中
  completed,  // 已完成
  failed,     // 失败
  skipped,    // 跳过（无数据，展示态；服务端按 DONE 记录）
}
```

### 6.3 轮询与状态管理

```dart
class ExportProgressPage extends StatefulWidget {
  final String taskId;
  const ExportProgressPage({required this.taskId, super.key});

  @override
  State<ExportProgressPage> createState() => _ExportProgressPageState();
}

class _ExportProgressPageState extends State<ExportProgressPage> {
  ExportTaskDetail? _task;
  Timer? _pollTimer;
  bool _isCancelling = false;

  // 轮询间隔策略：5s → 10s → 15s（上限）
  static const _pollIntervals = [5, 10, 15];
  int _pollIndex = 0;

  @override
  void initState() {
    super.initState();
    _loadTask();
  }

  @override
  void dispose() {
    _pollTimer?.cancel();
    super.dispose();
  }

  Future<void> _loadTask() async {
    final task = await DataExportApi.getExportTask(widget.taskId);
    if (!mounted) return;
    setState(() => _task = task);

    if (task.status == ExportTaskStatus.completed) {
      _onExportCompleted(task);
    } else if (task.status == ExportTaskStatus.failed) {
      _onExportFailed(task);
    } else if (_isInProgress(task.status)) {
      _scheduleNextPoll();
    }
  }

  void _scheduleNextPoll() {
    final seconds = _pollIntervals[_pollIndex.clamp(0, _pollIntervals.length - 1)];
    _pollTimer = Timer(Duration(seconds: seconds), () {
      _pollIndex = (_pollIndex + 1).clamp(0, _pollIntervals.length - 1);
      _loadTask();
    });
  }

  bool _isInProgress(ExportTaskStatus s) {
    // v1.1 缺陷修正 F1：删除对不存在的 ExportTaskStatus.encrypting 引用，
    // 加密隶属 packaging 阶段（PackagingSubPhase.encrypting 仅为渲染细分）
    return const [
      ExportTaskStatus.queued,
      ExportTaskStatus.aggregating,
      ExportTaskStatus.packaging,
      ExportTaskStatus.uploading,
    ].contains(s);
  }

  void _onExportCompleted(ExportTaskDetail task) {
    // 展示成功状态 + 下载按钮
    // 发送本地通知
    LocalNotificationService.show(
      title: '数据导出完成',
      body: '你的数据已打包完成，点击下载',
      payload: '/settings/privacy/export/progress/${task.taskId}',
    );
  }

  void _onExportFailed(ExportTaskDetail task) {
    showCupertinoDialog(
      context: context,
      builder: (ctx) => CupertinoAlertDialog(
        title: const Text('导出失败'),
        content: Text(task.errorMessage ?? '数据导出过程中出现错误，请重试。'),
        actions: [
          CupertinoDialogAction(
            child: const Text('重试'),
            onPressed: () {
              Navigator.pop(ctx);
              _retryExport();
            },
          ),
          CupertinoDialogAction(
            isDefaultAction: true,
            child: const Text('确定'),
            onPressed: () => Navigator.pop(ctx),
          ),
        ],
      ),
    );
  }

  Future<void> _cancelExport() async {
    final confirmed = await showConfirmDialog(
      context: context,
      title: '取消导出',
      message: '确定取消当前导出任务？已导出的数据将被丢弃。',
    );
    if (!confirmed) return;

    setState(() => _isCancelling = true);
    try {
      await DataExportApi.cancelExportTask(widget.taskId);
      if (mounted) {
        showToast('已取消导出');
        context.pop();
      }
    } catch (_) {
      if (mounted) showToast('取消失败，请重试');
    } finally {
      if (mounted) setState(() => _isCancelling = false);
    }
  }

  Future<void> _downloadExport() async {
    if (_task?.downloadUrl == null) return;

    // 调用系统分享/下载
    final result = await FileDownloadService.downloadAndSave(
      url: _task!.downloadUrl!,
      fileName: 'PrimeTop_数据导出_${DateTime.now().yyyyMMdd()}.zip',
      passwordHint: '解压密码已发送至你的手机 ${_maskPhone(UserScope.phone)}',
    );

    if (result == DownloadResult.success && mounted) {
      showToast('文件已保存');
    }
  }

  String _maskPhone(String? phone) {
    if (phone == null || phone.length < 7) return '***';
    return '${phone.substring(0, 3)}****${phone.substring(phone.length - 4)}';
  }

  Future<void> _retryExport() async {
    // 重新发起导出（回到导出主页参数复用）
    context.pop();
  }

  @override
  Widget build(BuildContext context) {
    // ... 根据 _task 状态渲染不同 UI
    // 完成态：进度100% + 下载按钮 + 有效期倒计时
    // 进行中：进度动画 + 模块列表 + 取消按钮
    // 失败态：错误信息 + 重试按钮
    return Scaffold(/* ... */);
  }
}
```

```dart
  VerifyMethod _method = VerifyMethod.smsCode; // SMS_CODE | PAY_PASSWORD(有支付记录时)
  final _codeController = TextEditingController();
  int _remainSeconds = 0;   // 重发倒计时 60s

              extra: result.data);
        }
        break;
      case 43024: // 未成年账号需家长确认（G12）

            ? '错误次数过多，请 30 分钟后再试'

        break;
    }
```
```dart
  }

  /// 倒计时以服务端 freezeEndAt 为准，本地仅做展示 tick（契约 R11）
  void _tick() {
    final end = widget.freezeEndAt;
    final remain = end.difference(DateTime.now());
    setState(() => _remain = remain.isNegative ? Duration.zero : remain);
  }

  /// 进入页面与每 5min 静默同步一次注销状态（FREEZING 期间）
  Future<void> _syncStatus() async {
    final status = await AccountApi.getCancellationStatus();
    switch (status.status) {
      case 'FREEZING':
        // 继续倒计时；freezeEndAt 漂移则以服务端值校准本地钟差
        break;
      case 'READY_DELETE':
      case 'DELETING':
        // 冷冻期已过但删除未完成：展示「正在删除数据」终态占位
        break;
      case 'COMPLETED':
        _showDeletedTerminal();
      case 'CANCELLED':
        // 已在其他端撤销：跳回首页
        context.go('/home');
    }
  }

  /// 撤销注销（POST /recover）：需再次身份验证（G13，凭据一次性）
  Future<void> _recover() async {
    final verified = await context.push<bool>('/settings/privacy/deactivate/verify');
    if (verified != true) return;
    final result = await AccountApi.recoverCancellation(
      cancellationId: widget.cancellationId,
      verifyMethod: _verifyMethod,
      verifyCode: _verifyCode,
    );
    if (result.code == 0 && mounted) {
      // 恢复成功：重新建立会话，回首页并展示欢迎回来横幅
      context.go('/home?banner=welcome_back');
    } else if (result.code == 43032 && mounted) {
      // 冷冻期已过，删除不可逆（G13）
      _showDeletedTerminal();
    }
  }
}
```

**要点：**

1. 冷冻期 15 天（服务端 `freezeDays` 下发，前端不硬编码天数）；倒计时为纯展示，是否可撤销以服务端状态机为准（G13）；
2. 冷冻期内用户重新登录任意端 → 登录服务识别 FREEZING 态统一跳转本页，禁止进入学习功能（契约 R13）；
3. `43032`（已过冷冻期）展示终态页：感谢文案 + 「下载最后的数据导出文件」入口（若曾导出且未过期）。

## 9. 家长代理确认页

路由：`/settings/privacy/parent-confirm`（模态页，不压路由栈）

**触发场景（统一家长门入口，契约 R5/R6）：**

| 场景 | 触发错误码 | 确认范围 |
| --- | --- | --- |
| 未成年账号发起注销 | 43024 | accountCancellation |
| 未成年账号导出数据 | 43024 | dataExport |
| 未成年修改家长绑定手机 | 43040（绑定服务） | parentPhoneChange |

**页面结构：**

```dart
class ParentConfirmPage extends StatelessWidget {
  final ParentConfirmScope scope;

  @override
  Widget build(BuildContext context) {
    return ParentGateScaffold(
      scope: scope,
      // 家长门统一由「统一家长门与监护人授权核验引擎」服务端裁决（契约 R6）
      // 客户端仅负责：发起确认请求 → 展示等待/结果 → 回填业务请求
      onApproved: (approvalToken) => Navigator.pop(context, approvalToken),
      onRejected: () {
        showToast('家长未确认该操作');
        Navigator.pop(context, null);
      },
    );
  }
}
```

**交互要点：**

1. 确认方式三选一并由服务端策略决定优先级：家长端推送一键确认（默认）＞ 短信验证码确认 ＞ 人脸核验（高敏操作）；
2. 家长确认结果携带 `approvalToken`（一次性、10 分钟有效），业务请求头透传该 token，服务端二次校验（防重放）；
3. 等待态超时分级：2 分钟未响应展示「已提醒家长，请稍候」；10 分钟未响应自动关闭并提示稍后重试；
4. 家长拒绝后本次业务请求终止，**不自动重试**；客户端展示拒绝原因（家长可选填，如「请先完成今日作业」）。

## 10. 通用能力

### 10.1 错误处理与重试矩阵

| 错误码 | 语义 | 客户端处理 |
| --- | --- | --- |
| 43010 | 导出任务不存在 | 提示「任务已失效」，返回导出主页 |
| 43015 | 导出任务并发超限（每人同时 1 个进行中任务） | 提示「已有进行中的导出任务」并跳转进度页 |
| 43021 | 注销确认缺少知情勾选 | 双确认勾选项强制回显，禁止提交 |
| 43022 | 冷冻期内已有活跃注销单 | 直接跳转注销状态页（G9 幂等语义） |
| 43024 | 未成年需家长确认 | 拉起家长代理确认页（§9） |
| 43025 | 存在阻断性权益 | 权益检查页红色横幅 + 阻断 |
| 43026 | 验证凭据错误/失效 | 剩余次数提示，5 次锁 30 分钟 |
| 43032 | 冷冻期已过不可撤销 | 终态页（§8.5） |
| 网络异常 | 弱网/断网 | 全页骨架屏 + 重试按钮；提交类操作本地防重（按钮 loading 锁定） |

**通用约定：**

1. 所有提交按钮具备防重复点击（loading 态锁），配合服务端幂等键（导出 `requestId`、注销 `uk_user_id`）双保险；
2. 轮询类页面（导出进度/冷冻期状态）退后台自动降级为 60s 慢轮询，回前台立即同步一次；
3. 5xx 与网络错误统一走「系统繁忙」兜底文案，技术错误码仅落日志不上屏。

**合规约束（契约 C1-C3）：**

- 冷冻期倒计时页停留时长**不上报**（避免「挽留时长」被用于运营轰炸，C3）。
