## 1. 模块概述

### 1.1 功能定位

本引擎为错题复习、文科背诵、知识点巩固等场景提供统一的间隔重复调度能力。基于 Ebbinghaus 遗忘曲线理论，结合 SM-2 改良算法与 FSRS（Free Spaced Repetition Scheduler）的教育场景适配参数，为每位学生生成个性化的复习时间表。

**一句话定位：** 所有需要"重复记忆"的内容都通过本引擎管理复习节奏。

### 1.2 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 复习项注册 | 将错题/背诵项/知识点纳入调度引擎 | P0 |
| SM-2 改良调度 | 基于回忆质量评分计算下次复习间隔 | P0 |
| 分学科参数适配 | 不同学科/题型使用不同遗忘参数 | P1 |
| 复习队列编排 | 每日复习任务优先级排序与数量控制 | P0 |
| 滞后补偿 | 错过复习后的智能补排策略 | P1 |
| 掌握度追踪 | 连续通过复习后标记为已掌握 | P0 |
| 批量调度计算 | 定时批量为全体用户生成次日复习计划 | P1 |
| 分龄难度系数 | 根据学段自动调整初始难度和间隔梯度 | P2 |

### 1.3 依赖关系

```
错题整理模块          → 错题收录后触发复习项注册
文科背诵模块          → 背诵材料纳入复习调度
练习与测评系统        → 答题结果反馈至掌握度
学习记录与进度追踪    → 学习时长和活跃度影响调度权重
学习提醒与通知调度    → 复习计划到期触发提醒推送
知识点体系            → 知识点关联影响关联复习推荐
```

## 2. 算法设计

### 2.1 遗忘曲线模型

采用指数衰减模型，记忆保持率 R(t) 公式：

```
R(t) = e^(-t / S)
```

- `t`：距上次复习的时间（天）
- `S`：记忆稳定性（memory stability），即记忆保持率降至 `1/e ≈ 36.8%` 所需天数
- 目标：在 R(t) 降至阈值 `R_target`（默认 0.85）时触发复习

复习间隔计算：

```
interval = -S * ln(R_target)
```

当 `R_target = 0.85` 时：`interval ≈ 0.163 * S`

### 2.2 SM-2 改良算法（FSRS 教育适配版）

#### 2.2.1 输入参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `item_id` | BIGINT | 复习项 ID |
| `user_id` | BIGINT | 用户 ID |
| `review_quality` | ENUM | 本次复习质量评分（0-5） |
| `time_spent_sec` | INT | 本次复习耗时（秒） |
| `hint_used` | BOOLEAN | 是否使用了提示 |
| `review_mode` | ENUM | 复习模式：RECALL / RECOGNITION / PRODUCTION |

#### 2.2.2 复习质量评分体系

| 评分 | 标签 | 含义 | 对应操作 |
|------|------|------|----------|
| 0 | BLACKOUT | 完全没印象，像第一次见 | 重置稳定性，间隔回到 1 天 |
| 1 | WRONG_HESITANT | 想了很久但回忆错误 | 大幅缩短稳定性，间隔缩短至 50% |
| 2 | WRONG_EASY | 错误但感觉很熟悉 | 中度缩短稳定性，间隔缩短至 70% |
| 3 | CORRECT_HARD | 正确但非常费力 | 稳定性小幅增长，间隔按 1.0x 递增 |
| 4 | CORRECT_OK | 正确且有一定把握 | 稳定性正常增长，间隔按 1.3x 递增 |
| 5 | CORRECT_EASY | 瞬间回忆，非常确定 | 稳定性大幅增长，间隔按 1.8x 递增 |

#### 2.2.3 核心计算流程

```python
import math
from datetime import datetime, timedelta
from enum import IntEnum
from typing import Optional


class ReviewQuality(IntEnum):
    BLACKOUT = 0
    WRONG_HESITANT = 1
    WRONG_EASY = 2
    CORRECT_HARD = 3
    CORRECT_OK = 4
    CORRECT_EASY = 5


class MasteryLevel(IntEnum):
    NOT_MASTERED = 0
    PARTIAL = 1
    MASTERED = 2


class ReviewMode:
    RECALL = "RECALL"
    RECOGNITION = "RECOGNITION"
    PRODUCTION = "PRODUCTION"


class ReviewScheduler:
    """
    间隔重复调度核心算法（FSRS 教育适配版）
    
    基于 SM-2 算法改良，引入：
    1. 遗忘曲线理论的目标保持率控制
    2. 学科差异化参数
    3. 答题耗时因子
    4. 提示使用惩罚
    5. 分龄初始参数调整
    """
    
    DEFAULT_PARAMS = {
        "w": 0.4,
        "D0": 1.0,
        "D_min": 1.0,
        "D_max": 10.0,
        "S0_min": 0.5,
        "S_inc_hard": 1.0,
        "S_inc_ok": 1.3,
        "S_inc_easy": 1.8,
        "S_dec_wrong2": 0.7,
        "S_dec_wrong1": 0.5,
        "R_target": 0.85,
        "max_interval": 365,
        "mastery_threshold": 5,
    }
    
    def calculate_next_review(
        self,
        current_stability: float,
        current_difficulty: float,
        current_interval: float,
        review_quality: int,
        time_spent_sec: int,
        hint_used: bool,
        review_count: int,
        consecutive_correct: int,
        params: Optional[dict] = None,
    ) -> dict:
        p = {**self.DEFAULT_PARAMS, **(params or {})}
        
        # Step 1: 更新难度
        delta_d = (5 - review_quality) * 0.1 - (review_quality - 3) * 0.05
        new_difficulty = max(p["D_min"], min(p["D_max"],
            current_difficulty + delta_d))
        
        # Step 2: 更新稳定性
        if review_quality >= 3:
            if review_quality == 3:
                multiplier = p["S_inc_hard"]
            elif review_quality == 4:
                multiplier = p["S_inc_ok"]
            else:
                multiplier = p["S_inc_easy"]
            
            difficulty_factor = 1.0 - (new_difficulty - p["D_min"]) / (
                p["D_max"] - p["D_min"]) * 0.3
            time_factor = self._compute_time_factor(
                time_spent_sec, current_interval)
            
            new_stability = (
                current_stability * multiplier * difficulty_factor * time_factor
            )
        elif review_quality == 2:
            new_stability = current_stability * p["S_dec_wrong2"]
        elif review_quality == 1:
            new_stability = current_stability * p["S_dec_wrong1"]
        else:
            new_stability = p["S0_min"]
        
        # Step 3: 提示惩罚
        if hint_used and review_quality >= 3:
            new_stability *= 0.8
        
        # Step 4: 计算间隔
        next_interval = -new_stability * math.log(p["R_target"])
        
        if review_count == 0:
            next_interval = max(next_interval, 1.0)
        elif review_count == 1:
            next_interval = max(next_interval, 2.0)
        elif review_count == 2:
            next_interval = max(next_interval, 4.0)
        
        next_interval = min(next_interval, p["max_interval"])
        next_interval = round(next_interval, 1)
        
        # Step 5: 掌握度
        if review_quality >= 3:
            consecutive_correct += 1
        else:
            consecutive_correct = 0
        
        if consecutive_correct >= p["mastery_threshold"]:
            mastery_level = MasteryLevel.MASTERED
        elif consecutive_correct >= 2:
            mastery_level = MasteryLevel.PARTIAL
        else:
            mastery_level = MasteryLevel.NOT_MASTERED
        
        # Step 6: 优先级
        priority_score = self._compute_priority(
            new_stability, new_difficulty, mastery_level)
        
        return {
            "next_interval": next_interval,
            "next_stability": round(new_stability, 4),
            "next_difficulty": round(new_difficulty, 2),
            "next_review_at": datetime.utcnow() + timedelta(days=next_interval),
            "mastery_level": mastery_level,
            "priority_score": round(priority_score, 4),
            "consecutive_correct": consecutive_correct,
        }
    
    def _compute_time_factor(self, time_spent_sec: int, interval: float) -> float:
        if time_spent_sec <= 0:
            return 0.9
        if time_spent_sec < 2:
            return 0.85
        if time_spent_sec <= 30:
            return 1.0
        if time_spent_sec <= 120:
            return 0.95
        return 0.85
    
    def _compute_priority(self, stability: float, difficulty: float,
                          mastery_level: int) -> float:
        stability_score = 1.0 / (1.0 + stability)
        difficulty_score = difficulty / 10.0
        mastery_penalty = (2 - mastery_level) * 0.3
        return (stability_score * 0.5
                + difficulty_score * 0.3
                + mastery_penalty * 0.2)
    
    def initialize_new_item(self, subject_code: str, difficulty_tier: int,
                            grade_code: str) -> dict:
        params = self._get_subject_params(subject_code)
        base_stability = params["w"] * 5.0
        difficulty_modifier = 1.0 - (difficulty_tier - 1) * 0.15
        grade_modifier = self._get_grade_modifier(grade_code)
        
        initial_stability = max(
            params["S0_min"],
            base_stability * difficulty_modifier * grade_modifier
        )
        initial_interval = max(1.0,
            -initial_stability * math.log(params["R_target"]))
        
        return {
            "stability": round(initial_stability, 4),
            "difficulty": params["D0"] + (difficulty_tier - 1) * 0.8,
            "interval": round(initial_interval, 1),
            "next_review_at": datetime.utcnow() + timedelta(days=initial_interval),
            "review_count": 0,
            "consecutive_correct": 0,
            "mastery_level": MasteryLevel.NOT_MASTERED,
            "priority_score": round(
                self._compute_priority(initial_stability, params["D0"], 0), 4),
        }
```

## 4. 状态流转

### 4.1 复习项生命周期

```
                  ┌──────────────────────────────────────┐
                  │                                      │
                  ▼                                      │
  [创建] ──► ACTIVE ──► (连续达到掌握阈值) ──► MASTERED ──┘
               │  │                              │     (重新遗忘降回)
               │  │                              │
               │  └──► PAUSED ◄──────────────────┘
               │      (用户暂停/学期结束)        (归档旧内容)
               │
               └──► ARCHIVED
                    (用户归档/学年结束)
```

| 状态 | 触发条件 | 调度行为 |
|------|----------|----------|
| `ACTIVE` | 新注册 / 从 PAUSED 恢复 / 从 MASTERED 降回 | 参与每日调度 |
| `PAUSED` | 用户手动暂停 / 连续30天未登录 | 不参与调度，保留参数 |
| `MASTERED` | 连续 N 次评分 ≥ 4（默认 N=5） | 不参与日常调度，进入90天低频巡检 |
| `ARCHIVED` | 用户归档 / 学年结束自动归档 | 不参与调度，仅保留历史 |

### 4.2 复习会话状态机

```
  ┌──────────────────────────────────────────────────────────────────┐
  │                                                                  │
  ▼                                                                  │
  SESSION_START ──► ITEM_PRESENT ──► USER_RESPOND ──► GRADE ──► UPDATE_SCHEDULER
                       │                  │                            │
                       │                  │(请求提示)                  │
                       │                  ▼                            │
                       │             SHOW_HINT ──────────────────────►│
                       │                                               │
                       │(跳过)                                         │
                       └──► SKIP ────────────────────────────────────►│
                                                                      │
                                        有更多待复习项？               │
                                       ┌─── YES ──┐                   │
                                       │          │                   │
                                       ▼          NO                  │
                                   ITEM_PRESENT   ──────► SESSION_END ┘
```

```python
            if is_overdue else 0.0

                "item_id": item_id,

                "item_source_id": item.item_source_id,

    async def get_today_queue(
        self,
        user_id: int,
        subject_codes: Optional[List[str]] = None,
        limit: int = 20,
        offset: int = 0,
        include_overdue: bool = True,
    ) -> dict:
        """获取今日复习队列"""
        
        now = datetime.utcnow()
        today_end = now.replace(hour=23, minute=59, second=59)
        
        # 构建查询条件
        conditions = [
            ReviewItem.user_id == user_id,
            ReviewItem.status == "ACTIVE",
        ]
        if subject_codes:
            conditions.append(
                ReviewItem.subject_code.in_(subject_codes))
        
        if include_overdue:
            conditions.append(
                ReviewItem.next_review_at <= today_end)
        else:
            conditions.append(
                and_(
                    ReviewItem.next_review_at >= now,
                    ReviewItem.next_review_at <= today_end,
                ))
        
        # 总数
        count_q = select(func.count()).select_from(ReviewItem).where(
            and_(*conditions))
        total = (await self.db.execute(count_q)).scalar()
        
        # 逾期数
        overdue_q = select(func.count()).select_from(ReviewItem).where(
            and_(*conditions, ReviewItem.next_review_at < now))
        overdue_count = (await self.db.execute(overdue_q)).scalar()
        
        # 排序查询
        items_q = (
            select(ReviewItem)
            .where(and_(*conditions))
            .order_by(
                # 逾期优先
                (ReviewItem.next_review_at < now).desc(),
                # 逾期天数降序
                (now - ReviewItem.next_review_at).desc(),
                # 优先级降序
                ReviewItem.priority_score.desc(),
            )
            .limit(limit)
            .offset(offset)
        )
        items = (await self.db.execute(items_q)).scalars().all()
        
        return {
            "total": total,
            "overdue_count": overdue_count,
            "due_today_count": total - overdue_count,
            "items": [self._item_to_queue_dict(i, now) for i in items],
        }
    
    def _item_to_queue_dict(self, item: ReviewItem, now: datetime) -> dict:
        is_overdue = now > item.next_review_at
        return {
            "id": item.id,
            "item_type": item.item_type,
            "item_source_id": item.item_source_id,
            "subject_code": item.subject_code,
            "difficulty": item.difficulty,
            "mastery_level": item.mastery_level,
            "priority_score": item.priority_score,
            "next_review_at": item.next_review_at.isoformat(),
            "is_overdue": is_overdue,
            "overdue_days": (
                (now - item.next_review_at).total_seconds() / 86400
                if is_overdue else 0.0
            ),
        }
```

### 6.3 复习队列编排器 (QueueBuilder)

```python
class ReviewQueueBuilder:
    """
    每日复习队列编排器
    
    负责将到期的复习项按策略排序，并控制每日总量。
    """
    
    # 每日复习总量上限
    DAILY_LIMITS = {
        "K": 10,    # 幼儿
        "G1_G3": 15,  # 小学低年级
        "G4_G6": 20,  # 小学高年级
        "G7_G9": 30,  # 初中
        "G10_G12": 40,  # 高中
    }
    
    async def build_daily_plan(
        self,
        db: AsyncSession,
        user_id: int,
        grade_code: str,
        plan_date: date,
    ) -> DailyReviewPlan:
        """为用户生成某日的复习计划"""
        
        # 检查是否已生成
        existing = await self._get_plan(db, user_id, plan_date)
        if existing:
            return existing
        
        # 获取到期复习项
        due_items = await self._get_due_items(db, user_id, plan_date)
        
        if not due_items:
            return None  # 无需复习
        
        # 计算每日上限
        daily_limit = self._get_daily_limit(grade_code)
        
        # 排序与截断
        ordered = self._order_items(due_items, daily_limit)
        
        # 生成计划
        plan = DailyReviewPlan(
            user_id=user_id,
            plan_date=plan_date,
            total_count=len(ordered),
            subject_distribution=self._calc_subject_dist(ordered),
            item_order=[i.id for i in ordered],
            status="PENDING",
        )
        db.add(plan)
        await db.flush()
        return plan
    
    def _order_items(
        self,
        items: List[ReviewItem],
        limit: int,
    ) -> List[ReviewItem]:
        """
        多维排序策略：
        1. 逾期天数（降序）
        2. 优先级分数（降序）
        3. 学科轮转（避免连续同科疲劳）
        """
        now = datetime.utcnow()
        
        # 按优先级初步排序
        sorted_items = sorted(items, key=lambda i: (
            -(now - i.next_review_at).total_seconds()  # 越逾期越前
            if now > i.next_review_at else 0,
            -i.priority_score,
        ))
        
        # 学科轮转打散
        result = self._round_robin_by_subject(sorted_items)
        
        # 截断到每日上限
        return result[:limit]
    
    def _round_robin_by_subject(
        self,
        items: List[ReviewItem],
    ) -> List[ReviewItem]:
        """按学科轮转排列，避免连续同科"""
        from collections import defaultdict, deque
        
        by_subject = defaultdict(deque)
        for item in items:
            by_subject[item.subject_code].append(item)
        
        result = []
        subjects = list(by_subject.keys())
        idx = 0
        
        while any(by_subject[s] for s in subjects):
            s = subjects[idx % len(subjects)]
            if by_subject[s]:
                result.append(by_subject[s].popleft())
            idx += 1
        
        return result
    
    def _get_daily_limit(self, grade_code: str) -> int:
        prefix = grade_code[0]
        if prefix == "K":
            return self.DAILY_LIMITS["K"]
        num = int(grade_code[1:])
        if num <= 3:
            return self.DAILY_LIMITS["G1_G3"]
        elif num <= 6:
            return self.DAILY_LIMITS["G4_G6"]
        elif num <= 9:
            return self.DAILY_LIMITS["G7_G9"]
        else:
            return self.DAILY_LIMITS["G10_G12"]
    
    def _calc_subject_dist(
        self,
        items: List[ReviewItem],
    ) -> dict:
        from collections import Counter
        counts = Counter(i.subject_code for i in items)
        return dict(counts)
```

```python
        tomorrow = date.today() + timedelta(days=1)

                and_(
                    ReviewItem.status == "ACTIVE",
                    ReviewItem.next_review_at <= tomorrow,

                success += 1
```

```python
    async with get_async_session() as db:

        stmt = (
            update(ReviewItem)
            .where(
                and_(
                    ReviewItem.status == "MASTERED",
                    ReviewItem.next_review_at <= now,
                )
            )
            .values(
                status="ACTIVE",
                stability=ReviewItem.stability * 0.7,
                mastery_level=1,  # 降为部分掌握
                next_review_at=now + timedelta(days=1),
                updated_at=now,
            )
        )
        result = await db.execute(stmt)
        await db.commit()
        
        logger.info(
            "已掌握项巡检完成: %d 项降回ACTIVE", result.rowcount)
```

### 10.2 算法降级策略

```python
class ReviewScheduler:
    
    def calculate_next_review(self, ...):
        try:
            # 正常计算
            return self._calculate_core(...)
        except Exception as e:
            logger.exception("调度算法异常，使用兜底策略")
            return self._fallback_calculation(...)
    
    def _fallback_calculation(self, current_interval, review_quality):
        """兜底策略：简单线性间隔"""
        if review_quality >= 4:
            next_interval = min(current_interval * 1.5, 365)
        elif review_quality >= 3:
            next_interval = current_interval
        else:
            next_interval = max(current_interval * 0.5, 1.0)
        
        return {
            "next_interval": next_interval,
            "next_stability": next_interval / 0.163,
            "next_difficulty": 5.0,  # 中等难度
            "next_review_at": datetime.utcnow() + timedelta(days=next_interval),
            "mastery_level": 0,
            "priority_score": 0.5,
            "consecutive_correct": 0,
        }
```

### 10.3 并发安全

- 同一复习项的并发复习提交使用乐观锁（`updated_at` 版本检查）
- 每日计划生成使用 `SELECT ... FOR UPDATE` 防止重复生成
- Redis 队列缓存使用 `MULTI/EXEC` 保证原子性

```dart
/// 复习调度状态管理
class ReviewSchedulerProvider extends StateNotifier<ReviewSchedulerState> {
  final ReviewApiService _api;
  
  ReviewSchedulerProvider(this._api)
      : super(const ReviewSchedulerState.initial());
  
  /// 加载今日复习队列
  Future<void> loadTodayQueue({List<String>? subjects}) async {
    state = const ReviewSchedulerState.loading();
    try {
      final result = await _api.getReviewQueue(
        subjectCodes: subjects,
        limit: 20,
      );
      state = ReviewSchedulerState.loaded(result);
    } catch (e) {
      state = ReviewSchedulerState.error(e.toString());
    }
  }
  
  /// 提交复习结果
  Future<ReviewResult> submitReview({
    required int itemId,
    required int quality,
    required int timeSpentSec,
    bool hintUsed = false,
    String reviewMode = 'RECALL',
    String? sessionId,
  }) async {
    final result = await _api.submitReview(
      itemId: itemId,
      quality: quality,
      timeSpentSec: timeSpentSec,
      hintUsed: hintUsed,
      reviewMode: reviewMode,
      sessionId: sessionId,
    );
    
    // 更新本地队列状态
    state.when(loaded: (queue) {
      final updated = queue.copyWith(
        items: queue.items
            .where((i) => i.id != itemId)
            .toList(),
        completedCount: queue.completedCount + 1,
      );
      state = ReviewSchedulerState.loaded(updated);
    });
    
    return result;
  }
}
```

```dart
class OfflineReviewCache {
  final Box<BoxedReviewQueue> _box;
  
  /// 缓存今日复习队列
  Future<void> cacheQueue(String userId, ReviewQueue queue) async {
    final key = '${userId}_${DateTime.now().toDateString()}';
    await _box.put(key, BoxedReviewQueue.from(queue));
  }
  
  /// 读取缓存的复习队列
  ReviewQueue? getCachedQueue(String userId) {
    final key = '${userId}_${DateTime.now().toDateString()}';
    return _box.get(key)?.toReviewQueue();
  }
  
  /// 离线复习结果暂存
  final Queue<PendingReview> _pendingReviews = Queue();
  
  void addPendingReview(PendingReview review) {
    _pendingReviews.add(review);
  }
  
  /// 网络恢复后批量上报
  Future<void> flushPendingReviews(ReviewApiService api) async {
    while (_pendingReviews.isNotEmpty) {
      final review = _pendingReviews.removeFirst();
      try {
        await api.submitReview(
          itemId: review.itemId,
          quality: review.quality,
          timeSpentSec: review.timeSpentSec,
          hintUsed: review.hintUsed,
          sessionId: 'offline_${review.id}',
        );
      } catch (e) {
        // 上报失败，重新入队
        _pendingReviews.addFirst(review);
        rethrow;
      }
    }
  }
}
```

## 16. 总结

本引擎围绕 **遗忘曲线理论 + SM-2/FSRS 改良算法** 构建了完整的复习调度体系：

1. **算法层**：支持分学科、分龄、分难度的差异化参数，通过质量评分、耗时、提示使用等多维因子动态调整间隔
2. **服务层**：提供注册、复习、队列、统计全套 API，通过事件总线与错题/背诵/练习等模块松耦合
3. **调度层**：Celery 定时任务批量生成每日计划，支持逾期补偿、掌握度巡检、不活跃自动暂停
4. **客户端**：Flutter Provider + 离线缓存实现流畅的复习体验，网络恢复后自动同步
5. **运维层**：缓存策略、分表方案、监控告警、降级兜底全链路覆盖

开发人员可直接参照本文档的 DDL、API、Service 实现和 Flutter Widget 开始编码。
