# 间隔重复算法与遗忘曲线复习调度引擎 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

本引擎为错题复习、文科背诵、知识点巩固等场景提供统一的间隔重复调度能力。基于 Ebbinghaus 遗忘曲线理论，结合 SM-2 改良算法与教育场景适配参数，为每位学生生成个性化的复习时间表，确保在记忆衰退的关键节点触发复习，用最少的复习次数达到长期记忆保持。

### 1.2 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 复习项注册 | 将错题/背诵项/知识点纳入调度引擎 | P0 |
| SM-2 改良调度 | 基于回忆质量评分计算下次复习间隔 | P0 |
| 分学科参数适配 | 不同学科/题型使用不同遗忘参数 | P1 |
| 复习队列编排 | 每日复习任务优先级排序与数量控制 | P0 |
| 滞后补偿 | 错过复习后的智能补排策略 | P1 |
| 掌握度追踪 | 连续通过复习后标记为已掌握 | P0 |
| 批量调度计算 | 定时批量为全体用户生成次日复习计划 | P1 |
| 分龄难度系数 | 根据学段自动调整初始难度和间隔梯度 | P2 |

### 1.3 依赖关系

```
错题整理模块          → 错题收录后触发复习项注册
文科背诵模块          → 背诵材料纳入复习调度
练习与测评系统        → 答题结果反馈至掌握度
学习记录与进度追踪    → 学习时长和活跃度影响调度权重
学习提醒与通知调度    → 复习计划到期触发提醒推送
知识点体系            → 知识点关联影响关联复习推荐
```

## 2. 算法设计

### 2.1 遗忘曲线模型

采用指数衰减模型，记忆保持率 R(t) 公式：

```
R(t) = e^(-t / S)
```

- `t`：距上次复习的时间（天）
- `S`：记忆稳定性（memory stability），即记忆保持率降至 `1/e ≈ 36.8%` 所需天数
- 目标：在 R(t) 降至阈值 `R_target`（默认 0.85）时触发复习

复习间隔计算：

```
interval = -S * ln(R_target)
```

当 `R_target = 0.85` 时：`interval ≈ 0.163 * S`

### 2.2 SM-2 改良算法（FSRS 教育适配版）

经典 SM-2 算法基于 SuperMemo，本系统在其基础上引入 FSRS（Free Spaced Repetition Scheduler）的教育场景改良。

#### 2.2.1 输入参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `item_id` | BIGINT | 复习项 ID |
| `user_id` | BIGINT | 用户 ID |
| `review_quality` | ENUM | 本次复习质量评分（0-5） |
| `time_spent_sec` | INT | 本次复习耗时（秒） |
| `hint_used` | BOOLEAN | 是否使用了提示 |
| `review_mode` | ENUM | 复习模式：RECALL(回忆)/RECOGNITION(再认)/PRODUCTION(产出) |

#### 2.2.2 复习质量评分体系

| 评分 | 标签 | 含义 | 对应操作 |
|------|------|------|----------|
| 0 | BLACKOUT | 完全没印象，像第一次见 | 重置稳定性，间隔回到 1 天 |
| 1 | WRONG_HESITANT | 想了很久但回忆错误 | 大幅缩短稳定性，间隔缩短至 50% |
| 2 | WRONG_EASY | 错误但感觉很熟悉 | 中度缩短稳定性，间隔缩短至 70% |
| 3 | CORRECT_HARD | 正确但非常费力 | 稳定性小幅增长，间隔按 1.0x 递增 |
| 4 | CORRECT_OK | 正确且有一定把握 | 稳定性正常增长，间隔按 1.3x 递增 |
| 5 | CORRECT_EASY | 瞬间回忆，非常确定 | 稳定性大幅增长，间隔按 1.8x 递增 |

#### 2.2.3 核心计算流程

```python
class ReviewScheduler:
    """
    间隔重复调度核心算法
    """
    
    # 默认参数（可在 subject_params 中按学科覆盖）
    DEFAULT_PARAMS = {
        "w": 0.4,           # 初始稳定性权重
        "D0": 1.0,          # 初始难度
        "D_min": 1.0,       # 难度下限
        "D_max": 10.0,      # 难度上限
        "S0_min": 0.5,      # 最小初始稳定性（天）
        "S_inc_hard": 1.0,  # quality=3 的间隔乘数
        "S_inc_ok": 1.3,    # quality=4 的间隔乘数
        "S_inc_easy": 1.8,  # quality=5 的间隔乘数
        "S_dec_wrong2": 0.7,  # quality=2 的稳定性乘数
        "S_dec_wrong1": 0.5,  # quality=1 的稳定性乘数
        "R_target": 0.85,   # 目标保持率
        "max_interval": 365,  # 最大间隔（天）
        "mastery_threshold": 5, # 连续 correct 次数达此值标记已掌握
    }
    
    def calculate_next_review(
        self,
        current_stability: float,      # 当前记忆稳定性 S（天）
        current_difficulty: float,      # 当前难度 D
        current_interval: float,        # 当前间隔（天）
        review_quality: int,            # 本次复习评分 0-5
        time_spent_sec: int,            # 耗时
        hint_used: bool,                # 是否用提示
        review_count: int,              # 历史复习次数
        consecutive_correct: int,       # 连续正确次数
        params: dict = None,            # 学科特定参数
    ) -> dict:
        """
        计算下次复习参数
        
        返回: {
            "next_interval": float,     # 下次间隔（天）
            "next_stability": float,    # 新稳定性
            "next_difficulty": float,   # 新难度
            "next_review_at": datetime, # 下次复习时间
            "mastery_level": int,       # 更新后的掌握程度
            "priority_score": float,    # 在复习队列中的优先级
        }
        """
        p = {**self.DEFAULT_PARAMS, **(params or {})}
        
        # ---- Step 1: 调整难度 ----
        # 难度根据复习质量上下浮动
        delta_d = (5 - review_quality) * 0.1 - (review_quality - 3) * 0.05
        new_difficulty = max(p["D_min"], min(p["D_max"],
            current_difficulty + delta_d))
        
        # ---- Step 2: 更新稳定性 ----
        if review_quality >= 3:
            # 正确回忆：稳定性增长
            if review_quality == 3:
                multiplier = p["S_inc_hard"]
            elif review_quality == 4:
                multiplier = p["S_inc_ok"]
            else:  # 5
                multiplier = p["S_inc_easy"]
            
            # 考虑难度影响：高难度内容间隔增长更保守
            difficulty_factor = 1.0 - (new_difficulty - p["D_min"]) / (p["D_max"] - p["D_min"]) * 0.3
            # 考虑耗时影响：回答过快可能靠猜，过慢说明不熟练
            time_factor = self._compute_time_factor(time_spent_sec, current_interval)
            
            new_stability = current_stability * multiplier * difficulty_factor * time_factor
        elif review_quality == 2:
            new_stability = current_stability * p["S_dec_wrong2"]
        elif review_quality == 1:
            new_stability = current_stability * p["S_dec_wrong1"]
        else:  # 0 - 完全遗忘
            new_stability = p["S0_min"]
        
        # ---- Step 3: 处理提示使用 ----
        # 使用了提示降低间隔增长
        if hint_used and review_quality >= 3:
            new_stability *= 0.8
        
        # ---- Step 4: 计算下次间隔 ----
        # 基于目标保持率计算
        next_interval = -new_stability * math.log(p["R_target"])
        
        # 应用间隔约束
        if review_count == 0:
            next_interval = max(next_interval, 1.0)   # 至少 1 天
        elif review_count == 1:
            next_interval = max(next_interval, 2.0)   # 至少 2 天
        elif review_count == 2:
            next_interval = max(next_interval, 4.0)   # 至少 4 天
        
        next_interval = min(next_interval, p["max_interval"])
        next_interval = round(next_interval, 1)
        
        # ---- Step 5: 计算掌握度 ----
        if review_quality >= 3:
            consecutive_correct += 1
        else:
            consecutive_correct = 0
        
        if consecutive_correct >= p["mastery_threshold"]:
            mastery_level = 2  # 已掌握
        elif consecutive_correct >= 2:
            mastery_level = 1  # 部分掌握
        else:
            mastery_level = 0  # 未掌握
        
        # ---- Step 6: 计算优先级分数 ----
        # 考虑：紧急程度（越过期越优先）+ 难度权重 + 学科权重
        priority_score = self._compute_priority(
            new_stability, new_difficulty, mastery_level
        )
        
        return {
            "next_interval": next_interval,
            "next_stability": round(new_stability, 4),
            "next_difficulty": round(new_difficulty, 2),
            "next_review_at": datetime.now() + timedelta(days=next_interval),
            "mastery_level": mastery_level,
            "priority_score": round(priority_score, 4),
            "consecutive_correct": consecutive_correct,
        }
    
    def _compute_time_factor(self, time_spent_sec: int, interval: float) -> float:
        """
        根据答题耗时计算调节因子
        理想耗时 = 5~30秒，太快(<2s)或太慢(>120s)降低增长
        """
        if time_spent_sec <= 0:
            return 0.9
        if time_spent_sec < 2:
            return 0.85  # 可能靠猜
        if time_spent_sec <= 30:
            return 1.0   # 理想范围
        if time_spent_sec <= 120:
            return 0.95  # 稍慢
        return 0.85  # 非常慢，说明不熟练
    
    def _compute_priority(self, stability: float, difficulty: float, 
                          mastery_level: int) -> float:
        """
        计算复习队列中的优先级分数（越高越优先）
        """
        # 稳定性低 = 记忆脆弱 = 优先级高
        stability_score = 1.0 / (1.0 + stability)
        # 难度高 = 优先级高
        difficulty_score = difficulty / 10.0
        # 掌握度低 = 优先级高
        mastery_penalty = (2 - mastery_level) * 0.3
        
        return stability_score * 0.5 + difficulty_score * 0.3 + mastery_penalty * 0.2
    
    def initialize_new_item(self, subject_code: str, difficulty_tier: int,
                            grade_code: str) -> dict:
        """
        为新复习项初始化调度参数
        
        Args:
            subject_code: 学科编码
            difficulty_tier: 题目难度 1-5
            grade_code: 年级编码（影响初始参数）
        
        Returns:
            初始调度参数
        """
        params = self._get_subject_params(subject_code)
        
        # 基于题目难度和年级计算初始稳定性
        # 高难度题目初始稳定性更低（遗忘更快）
        base_stability = params["w"] * 5.0  # 基准稳定性约 2 天
        
        difficulty_modifier = 1.0 - (difficulty_tier - 1) * 0.15  # 1.0 ~ 0.4
        grade_modifier = self._get_grade_modifier(grade_code)
        
        initial_stability = max(
            params["S0_min"],
            base_stability * difficulty_modifier * grade_modifier
        )
        
        # 初始间隔 = 稳定性导出的首次复习时间
        initial_interval = max(1.0, -initial_stability * math.log(params["R_target"]))
        
        return {
            "stability": round(initial_stability, 4),
            "difficulty": params["D0"] + (difficulty_tier - 1) * 0.8,
            "interval": round(initial_interval, 1),
            "next_review_at": datetime.now() + timedelta(days=initial_interval),
            "review_count": 0,
            "consecutive_correct": 0,
            "mastery_level": 0,
            "priority_score": round(
                self._compute_priority(initial_stability, params["D0"], 0), 4
            ),
        }
```

## 3. 数据结构定义

### 3.1 复习项 (ReviewItem)

```sql
CREATE TABLE review_items (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT       NOT NULL COMMENT '用户ID',
    
    -- 关联内容
    item_type       VARCHAR(32)  NOT NULL COMMENT '类型: MISTAKE|MEMORIZATION|KNOWLEDGE_POINT',
    item_source_id  BIGINT       NOT NULL COMMENT '来源ID（错题ID/背诵材料ID/知识点ID）',
    subject_code    VARCHAR(16)  NOT NULL COMMENT '学科编码',
    grade_code      VARCHAR(16)  NOT NULL COMMENT '年级编码',
    
    -- 调度参数（算法核心状态）
    stability       FLOAT        NOT NULL DEFAULT 0 COMMENT '当前记忆稳定性 S（天）',
    difficulty      FLOAT        NOT NULL DEFAULT 1.0 COMMENT '当前难度 D',
    interval_days   FLOAT        NOT NULL DEFAULT 1.0 COMMENT '当前复习间隔（天）',
    
    -- 统计
    review_count    INT          NOT NULL DEFAULT 0 COMMENT '累计复习次数',
    consecutive_correct INT      NOT NULL DEFAULT 0 COMMENT '连续正确次数',
    lapse_count     INT          NOT NULL DEFAULT 0 COMMENT '遗忘次数（recall failed）',
    
    -- 掌握度
    mastery_level   TINYINT      NOT NULL DEFAULT 0 COMMENT '0=未掌握 1=部分掌握 2=已掌握',
    
    -- 调度时间
    next_review_at  DATETIME     NOT NULL COMMENT '下次应复习时间',
    last_reviewed_at DATETIME    NULL     COMMENT '上次实际复习时间',
    
    -- 队列优先级
    priority_score  FLOAT        NOT NULL DEFAULT 0 COMMENT '优先级分数（动态计算）',
    
    -- 生命周期
    status          VARCHAR(16)  NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE|PAUSED|MASTERED|ARCHIVED',
    
    -- 元数据
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE INDEX idx_user_source (user_id, item_type, item_source_id),
    INDEX idx_user_next_review (user_id, next_review_at, status),
    INDEX idx_user_status_priority (user_id, status, priority_score DESC),
    INDEX idx_user_subject (user_id, subject_code, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='复习调度项';
```

### 3.4 学科调度参数配置 (SubjectScheduleParams)

```sql
CREATE TABLE subject_schedule_params (
    id              INT PRIMARY KEY AUTO_INCREMENT,
    subject_code    VARCHAR(16)  NOT NULL COMMENT '学科编码',
    
    -- SM-2 改良参数
    initial_stability_weight FLOAT NOT NULL DEFAULT 0.4 COMMENT '初始稳定性权重 w',
    initial_difficulty FLOAT     NOT NULL DEFAULT 1.0 COMMENT '初始难度 D0',
    s_increment_ok  FLOAT        NOT NULL DEFAULT 1.3 COMMENT 'quality=4 间隔乘数',
    s_increment_easy FLOAT       NOT NULL DEFAULT 1.8 COMMENT 'quality=5 间隔乘数',
    s_decrement_wrong2 FLOAT     NOT NULL DEFAULT 0.7 COMMENT 'quality=2 稳定性乘数',
    s_decrement_wrong1 FLOAT     NOT NULL DEFAULT 0.5 COMMENT 'quality=1 稳定性乘数',
    retention_target FLOAT       NOT NULL DEFAULT 0.85 COMMENT '目标保持率',
    max_interval_days INT        NOT NULL DEFAULT 365 COMMENT '最大间隔天数',
    mastery_threshold INT        NOT NULL DEFAULT 5 COMMENT '掌握阈值',
    
    -- 每日复习上限
    daily_review_limit INT       NOT NULL DEFAULT 30 COMMENT '每日该学科最大复习项数',
    
    -- 是否启用
    is_active       TINYINT(1)   NOT NULL DEFAULT 1,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE INDEX idx_subject (subject_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学科调度参数';

## 4. 状态流转

### 4.1 复习项生命周期

```
                  ┌──────────────────────────────────────┐
                  │                                      │
                  ▼                                      │
  [创建] ──► ACTIVE ──► (连续达到掌握阈值) ──► MASTERED ──┘
               │  │                              │     (重新遗忘
               │  │                              │      降回ACTIVE)
               │  │                              │
               │  └──► PAUSED ◄──────────────────┘
               │      (用户暂停/学期结束)        (归档旧内容)
               │
               └──► ARCHIVED
                    (用户主动归档)
```

状态说明：

| 状态 | 触发条件 | 调度行为 |
|------|----------|----------|
| `ACTIVE` | 新注册 / 从其他状态恢复 | 参与每日调度，计入复习队列 |
| `PAUSED` | 用户手动暂停 / 长期未登录（>30天） | 不参与调度，保留参数 |
| `MASTERED` | 连续 N 次评分 ≥ 4 (默认 N=5) | 不参与日常调度，进入低频巡检（每90天验证一次） |
| `ARCHIVED` | 用户归档 / 学年结束自动归档 | 不参与调度，仅保留历史数据 |
