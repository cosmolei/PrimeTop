# 客户端异常监控与崩溃上报系统 - 详细设计

## 1. 概述

### 1.1 设计目标

为 PrimeTop 移动端（Flutter 双端 + Android/iOS 原生层）建立一套独立的**异常监控与崩溃上报系统**（Crash & Exception Reporting System），实现以下目标：

1. **全量捕获**：覆盖 Flutter Dart 层未捕获异常、原生层未捕获异常、ANR（Android）、Watchdog（iOS）、Flutter 渲染异常、Isolate 异常以及业务自定义致命错误。
2. **精准还原**：通过符号文件（Symbol File / dSYM / mapping.txt）对混淆/压缩后的堆栈进行反解，还原可读调用链。
3. **智能聚合**：按异常类型、堆栈签名、设备/版本维度自动分组，避免海量重复日志淹没研发。
4. **实时告警**：对新增崩溃、崩溃率突增、核心路径崩溃进行多渠道告警。
5. **闭环修复**：支持崩溃状态流转（待处理 → 处理中 → 已修复 → 已忽略），并与发布版本、CI/CD 符号上传流程打通。
6. **隐私合规**：崩溃报告中不含敏感业务数据，用户 ID 脱敏，设备信息最小化。

### 1.2 适用范围

| 适用对象 | 说明 |
| --- | --- |
| 客户端 | Flutter 层、Android 原生层、iOS 原生层 |
| 服务端 | 崩溃接入服务、符号化服务、崩溃聚合服务、告警服务、管理后台 |
| CI/CD | 构建阶段自动上传符号文件 |
| 运营后台 | 崩溃趋势看板、版本质量对比、修复闭环跟踪 |

### 1.3 与现有模块的关系

| 相关模块 | 关系 |
| --- | --- |
| 客户端日志采集与远程诊断系统 | 崩溃系统是日志/诊断体系的高优先级子集；崩溃事件同时写入本地日志，并走独立崩溃通道优先上报 |
| 客户端全局异常处理与安全恢复机制 | 全局异常处理器捕获异常后，由本系统封装为崩溃报告并触发上报 |
| 客户端性能监控与用户体验度量系统 | 崩溃率、ANR 率作为核心性能指标被消费 |
| 日志与监控告警体系（服务端） | 崩溃告警接入统一告警通道，崩溃趋势数据进入监控看板 |
| 客户端版本管理与升级策略 | 崩溃数据按版本维度聚合，驱动版本回滚/热修复决策 |
| 数据安全与隐私合规体系 | 崩溃数据脱敏、最小化采集、保留期限遵循隐私合规要求 |
| 客户端应用启动流程与初始化管线 | 崩溃 SDK 需在启动流程中尽早初始化，确保启动期崩溃可被捕获 |

### 2.2 核心组件职责

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `CrashReporter` | 客户端 | 统一崩溃采集入口，负责异常监听、报告组装、本地持久化、优先级上报 |
| `CrashCollector` | 客户端 | 各平台原生捕获器，注册到平台异常处理钩子 |
| `CrashEncoder` | 客户端 | 将崩溃报告序列化为 Protobuf/JSON，压缩并加密 |
| `CrashUploader` | 客户端 | 管理崩溃上报队列，控制频率、重试、失败回退 |
| `Crash Ingest` | 服务端 | 接收客户端上报，做参数校验、版本匹配、基础去重、写入对象存储和消息队列 |
| `Symbolication` | 服务端 | 根据版本/构建号匹配符号文件，对混淆堆栈进行反解 |
| `Aggregation` | 服务端 | 生成堆栈签名，聚合同类崩溃，维护崩溃分组、趋势、状态 |
| `Alert` | 服务端 | 基于崩溃率、新增分组、影响用户数的规则引擎告警 |
| `Admin Dashboard` | 管理后台 | 崩溃列表、分组详情、版本对比、符号文件管理、状态流转 |

## 3. 数据结构定义

### 3.1 崩溃报告模型（CrashReport）

```dart
/// 崩溃报告，客户端组装后上报
class CrashReport {
  /// 报告唯一 ID（UUID v7）
  final String reportId;

  /// 崩溃类型
  final CrashType crashType;

  /// 异常/信号名称，如：FlutterError、java.lang.NullPointerException、SIGSEGV
  final String exceptionName;

  /// 异常消息，需截断并脱敏
  final String? exceptionMessage;

  /// 堆栈帧列表
  final List<StackFrame> stackFrames;

  /// 导致崩溃的线程/Isolate 名称
  final String? threadName;

  /// 是否致命崩溃（true=应用退出；false=被捕获的异常但业务视为严重）
  final bool isFatal;

  /// 发生时间（UTC 毫秒）
  final int timestamp;

  /// 应用信息
  final AppInfo appInfo;

  /// 设备信息
  final DeviceInfo deviceInfo;

  /// 用户上下文（脱敏）
  final UserContext? userContext;

  /// 面包屑（最近用户操作路径，最多 50 条）
  final List<Breadcrumb> breadcrumbs;

  /// 自定义附加数据（如当前页面、路由参数）
  final Map<String, dynamic>? customData;

  /// 本地日志快照（最近 200 条日志内容，Base64 压缩）
  final String? logSnapshot;

  CrashReport({
    required this.reportId,
    required this.crashType,
    required this.exceptionName,
    this.exceptionMessage,
    required this.stackFrames,
    this.threadName,
    required this.isFatal,
    required this.timestamp,
    required this.appInfo,
    required this.deviceInfo,
    this.userContext,
    required this.breadcrumbs,
    this.customData,
    this.logSnapshot,
  });
}

enum CrashType {
  flutterDart,   // Flutter Dart 层异常
  flutterRender, // Flutter 渲染异常
  androidJava,   // Android Java/Kotlin 异常
  androidNative, // Android NDK 信号崩溃
  anr,           // Android ANR
  iosObjectiveC, // iOS Objective-C/Swift 异常
  iosSignal,     // iOS 信号崩溃
  watchdog,      // iOS Watchdog 终止
  businessFatal, // 业务自定义致命错误
}
```

### 3.2 堆栈帧模型（StackFrame）

```dart
/// 单条堆栈帧
class StackFrame {
  /// 帧序号，0 表示栈顶
  final int index;

  /// 原始符号（混淆/压缩后）
  final String? rawSymbol;

  /// 原始文件名
  final String? rawFileName;

  /// 原始行号（可能为 0 或缺失）
  final int? rawLineNumber;

  /// 原始列号（Flutter/Dart 特有）
  final int? rawColumnNumber;

  /// 符号化后函数名
  final String? symbolicatedFunction;

  /// 符号化后文件名
  final String? symbolicatedFileName;

  /// 符号化后行号
  final int? symbolicatedLineNumber;

  /// 符号化后列号
  final int? symbolicatedColumnNumber;

  /// 包名/模块名
  final String? packageName;

  /// 是否属于应用自身代码（非 SDK/框架）
  final bool? isAppFrame;

  StackFrame({
    required this.index,
    this.rawSymbol,
    this.rawFileName,
    this.rawLineNumber,
    this.rawColumnNumber,
    this.symbolicatedFunction,
    this.symbolicatedFileName,
    this.symbolicatedLineNumber,
    this.symbolicatedColumnNumber,
    this.packageName,
    this.isAppFrame,
  });
}
```

## 4. API 接口设计

### 4.1 崩溃上报接口

**POST** `/api/v1/crash/report`

> 客户端调用，支持 JSON 和 Protobuf 两种 Content-Type。生产环境建议使用 Protobuf 减少体积。

#### 请求头

| 头 | 必填 | 说明 |
| --- | --- | --- |
| `Content-Type` | 是 | `application/json` 或 `application/x-protobuf` |
| `X-App-Version` | 是 | 应用版本名 |
| `X-Build-Number` | 是 | 构建号 |
| `X-Platform` | 是 | android / ios |
| `X-Device-Id` | 是 | 设备 ID（匿名化） |
| `X-Sdk-Version` | 是 | 崩溃 SDK 版本 |

#### 请求体（JSON 示例）

```json

  "is_fatal": true,

    "version_name": "1.5.0",
```

### 5.1 Flutter 层异常捕获

```dart
import 'dart:async';
import 'dart:ui';
import 'package:flutter/material.dart';

class CrashReporter {
  static final CrashReporter _instance = CrashReporter._internal();
  factory CrashReporter() => _instance;
  CrashReporter._internal();

  final _breadcrumbBuffer = <Breadcrumb>[];
  final int _maxBreadcrumbs = 50;
  String _sessionId = '';

  void init({required String sessionId}) {
    _sessionId = sessionId;

    // 1. 捕获 Flutter 框架异常（build/layout/paint 等）
    FlutterError.onError = (FlutterErrorDetails details) {
      _handleFlutterError(details);
      // 保留原工厂行为，开发模式继续抛出红屏
      if (kDebugMode) {
        FlutterError.presentError(details);
      }
    };

    // 2. 捕获 Dart Zone 未捕获异常（异步异常）
    runZonedGuarded(
      () => runApp(MyApp()),
      (Object error, StackTrace stack) {
        _handleDartError(error, stack, isFatal: true);
      },
    );

    // 3. 捕获 PlatformDispatcher 级错误（Flutter 3.3+ 推荐）
    PlatformDispatcher.instance.onError = (Object error, StackTrace? stack) {
      _handleDartError(error, stack, isFatal: false);
      return true; // 表示已处理
    };

    // 4. 捕获 Isolate 未处理错误（后台任务）
    Isolate.current.addErrorListener(RawReceivePort((dynamic pair) {
      final error = pair[0] as Object;
      final stack = pair[1] as StackTrace?;
      _handleDartError(error, stack, isFatal: true, threadName: 'Isolate');
    }).sendPort);
  }

  void _handleFlutterError(FlutterErrorDetails details) {
    final report = _buildReport(
      crashType: CrashType.flutterRender,
      exceptionName: details.exception.runtimeType.toString(),
      exceptionMessage: details.exception.toString().substring(0, 500),
      stack: details.stack,
      isFatal: false,
    );
    _persistAndUpload(report);
  }

  void _handleDartError(Object error, StackTrace? stack, {
    required bool isFatal,
    String? threadName,
  }) {
    final report = _buildReport(
      crashType: CrashType.flutterDart,
      exceptionName: error.runtimeType.toString(),
      exceptionMessage: error.toString().substring(0, 500),
      stack: stack,
      isFatal: isFatal,
      threadName: threadName,
    );
    _persistAndUpload(report);
  }

  CrashReport _buildReport({
    required CrashType crashType,
    required String exceptionName,
    String? exceptionMessage,
    StackTrace? stack,
    required bool isFatal,
    String? threadName,
  }) {
    final frames = _parseStackTrace(stack);
    return CrashReport(
      reportId: _generateUuidV7(),
      crashType: crashType,
      exceptionName: exceptionName,
      exceptionMessage: exceptionMessage,
      stackFrames: frames,
      threadName: threadName ?? 'main',
      isFatal: isFatal,
      timestamp: DateTime.now().millisecondsSinceEpoch,
      appInfo: _collectAppInfo(),
      deviceInfo: _collectDeviceInfo(),
      userContext: _collectUserContext(),
      breadcrumbs: List.unmodifiable(_breadcrumbBuffer),
      customData: _collectCustomData(),
      logSnapshot: _captureLogSnapshot(),
    );
  }

  List<StackFrame> _parseStackTrace(StackTrace? stack) {
    if (stack == null) return [];
    final lines = stack.toString().split('\n');
    final frames = <StackFrame>[];
    for (int i = 0; i < lines.length && i < 200; i++) {
      final line = lines[i].trim();
      if (line.isEmpty) continue;
      // 简单解析 Flutter 风格堆栈：#0   _HomePageState.build (package:app/main.dart:128:14)
      final match = RegExp(r'#'
          r'(\d+)\s+\S+\s+\(([^)]+)\)')
          .firstMatch(line);
      if (match != null) {
        final locParts = match.group(2)!.split(':');
        frames.add(StackFrame(
          index: int.parse(match.group(1)!),
          rawSymbol: match.group(0),
          rawFileName: locParts.isNotEmpty ? locParts[0] : null,
          rawLineNumber: locParts.length > 1 ? int.tryParse(locParts[1]) : null,
          rawColumnNumber: locParts.length > 2 ? int.tryParse(locParts[2]) : null,
        ));
      }
    }
    return frames;
  }

  void addBreadcrumb(Breadcrumb crumb) {
    _breadcrumbBuffer.add(crumb);
    if (_breadcrumbBuffer.length > _maxBreadcrumbs) {
      _breadcrumbBuffer.removeAt(0);
    }
  }

  Future<void> _persistAndUpload(CrashReport report) async {
    await CrashStore.save(report);
    CrashUploader.enqueue(report);
  }
}
```

```kotlin
class AndroidCrashCollector private constructor() {
    private val originalHandler = Thread.getDefaultUncaughtExceptionHandler()

    fun install(context: Context) {
        Thread.setDefaultUncaughtExceptionHandler { thread, throwable ->
            handleThrowable(thread, throwable, fatal = true)
            // 可选：交给原 Handler 完成系统崩溃弹窗/退出
            originalHandler?.uncaughtException(thread, throwable)
        }

        // Flutter 引擎异常通过 MethodChannel 回传，此处不再重复注册

        // ANR 监控：监听主线程 Looper 的日志 printer
        val mainLooper = Looper.getMainLooper()
        mainLooper.setMessageLogging(ANRWatchdog())
    }

    private fun handleThrowable(thread: Thread, throwable: Throwable, fatal: Boolean) {
        val report = CrashReport(
            reportId = generateUUIDv7(),
            crashType = if (throwable is OutOfMemoryError) CrashType.ANR else CrashType.ANDROID_JAVA,
            exceptionName = throwable.javaClass.name,
            exceptionMessage = throwable.message?.take(500),
            stackFrames = throwable.stackTrace.mapIndexed { index, element ->
                StackFrame(
                    index = index,
                    rawSymbol = element.className + "." + element.methodName,
                    rawFileName = element.fileName,
                    rawLineNumber = element.lineNumber,
                    packageName = element.className.substringBeforeLast(".")
                )
            },
            threadName = thread.name,
            isFatal = fatal,
            timestamp = System.currentTimeMillis(),
            appInfo = collectAppInfo(),
            deviceInfo = collectDeviceInfo(context)
        )
        CrashStore.save(context, report)
        CrashUploader.enqueue(context, report)
    }

    class ANRWatchdog : Printer {
        private var lastLogTime = 0L

        override fun println(message: String?) {
            if (message?.startsWith(">>> Dispatching") == true) {
                lastLogTime = SystemClock.uptimeMillis()
            } else if (message?.startsWith("<<<< Finished") == true) {
                lastLogTime = 0
            }
        }

        fun isStuck(): Boolean {
            return lastLogTime > 0 && SystemClock.uptimeMillis() - lastLogTime > 5000
        }
    }
}
```

```go
package main

import (

type CrashIngestHandler struct {
    store       CrashStore
    publisher   EventPublisher
    validator   CrashValidator
}

func (h *CrashIngestHandler) Report(c *gin.Context) {
    ctx := c.Request.Context()

    var req CrashReport
    if err := c.ShouldBindJSON(&req); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{"code": 40001, "message": "invalid payload"})
        return
    }

    if err := h.validator.Validate(&req); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{"code": 40002, "message": err.Error()})
        return
    }

    // 幂等：report_id 已存在则直接返回
    if exists, _ := h.store.Exists(ctx, req.ReportID); exists {
        c.JSON(http.StatusOK, gin.H{"code": 0, "data": gin.H{"accepted": true, "duplicate": true}})
        return
    }

    // 生成/复用 group_id（基于原始堆栈签名）
    signature := computeStackSignature(req.StackFrames)
    groupID, _ := h.store.FindGroupBySignature(ctx, signature)
    if groupID == "" {
        groupID = "grp-" + uuid.New().String()[:12]
    }

    // 保存原始 payload 到对象存储
    payloadURL, err := h.store.SaveRawPayload(ctx, req.ReportID, c.GetRawData())
    if err != nil {
        c.JSON(http.StatusInternalServerError, gin.H{"code": 50001, "message": "save payload failed"})
        return
    }

    record := CrashRecord{
        ReportID:       req.ReportID,
        GroupID:        groupID,
        CrashType:      req.CrashType,
        ExceptionName:  req.ExceptionName,
        ExceptionMessage: truncate(req.ExceptionMessage, 2000),
        StackSignature: signature,
        IsFatal:        req.IsFatal,
        OccurredAt:     time.UnixMilli(req.Timestamp),
        AppVersion:     req.AppInfo.VersionName,
        BuildNumber:    req.AppInfo.BuildNumber,
        Platform:       req.AppInfo.Platform,
        Channel:        req.AppInfo.Channel,
        DeviceIDHash:   hashDeviceID(req.DeviceInfo.DeviceID),
        UserIDHash:     hashUserID(req.UserContext.UserIDHash),
        DeviceModel:    req.DeviceInfo.Model,
        OSVersion:      req.DeviceInfo.OSVersion,
        RawPayloadURL:  payloadURL,
        Breadcrumbs:    toJSON(req.Breadcrumbs),
        CustomData:     sanitizeCustomData(req.CustomData),
        Status:         "pending",
    }

    if err := h.store.SaveRecord(ctx, &record); err != nil {
        c.JSON(http.StatusInternalServerError, gin.H{"code": 50002, "message": "save record failed"})
        return
    }

    // 发布事件，驱动符号化和聚合

func computeStackSignature(frames []StackFrame) string {
    if len(frames) == 0 {
        return sha256Short("empty")
    }
    // 取前 8 帧应用代码，忽略 SDK/框架帧，提高聚合准确度
    var sb strings.Builder
    count := 0
    for _, f := range frames {
        if f.IsAppFrame != nil && *f.IsAppFrame {
            sb.WriteString(fmt.Sprintf("%s:%d\n", f.RawSymbol, f.RawLineNumber))
            count++
            if count >= 8 {
                break
            }
        }
    }
    if count == 0 {
        // 兜底：取前 3 帧
        for i := 0; i < min(3, len(frames)); i++ {
            sb.WriteString(fmt.Sprintf("%s:%d\n", frames[i].RawSymbol, frames[i].RawLineNumber))
        }
    }
    return sha256Short(sb.String())
}
```

### 5.5 符号化服务（Python 简化版，处理 mapping.txt）

```python
import json
import re
import hashlib
from typing import List, Optional

class AndroidSymbolicator:
    def __init__(self, mapping_path: str):
        self.mapping = self._load_mapping(mapping_path)

    def _load_mapping(self, path: str) -> dict:
        """解析 ProGuard/R8 mapping.txt 文件，构建 class.method -> original 的映射。"""
        mapping = {}
        with open(path, 'r', encoding='utf-8') as f:
            current_class = None
            for line in f:
                line = line.rstrip()
                # 类映射： com.example.a -> com.example.HomePage:
                class_match = re.match(r'^(\S+) -> (\S+):$', line)
                if class_match:
                    original, obfuscated = class_match.groups()
                    current_class = (original, obfuscated)
                    mapping[obfuscated] = original
                    continue
                # 方法映射： int a() -> int onSubmit()
                method_match = re.match(
                    r'^\s*(\S+)\s+(\S+)\((.*)\)\s*->\s*(\S+)$', line)
                if method_match and current_class:
                    _, orig_method, params, obf_method = method_match.groups()
                    obf_key = f"{current_class[1]}.{obf_method}"
                    mapping[obf_key] = f"{current_class[0]}.{orig_method}"
        return mapping

    def symbolicate(self, frames: List[dict]) -> List[dict]:
        out = []
        for frame in frames:
            raw_symbol = frame.get('raw_symbol', '')
            obf_key = raw_symbol
            if '->' in raw_symbol:
                obf_key = raw_symbol.split('->')[-1].strip()

            symbolicated = self.mapping.get(obf_key, raw_symbol)
            frame['symbolicated_function'] = symbolicated
            frame['symbolicated_file_name'] = frame.get('raw_file_name')
            frame['symbolicated_line_number'] = frame.get('raw_line_number')
            frame['symbolicated_column_number'] = frame.get('raw_column_number')
            out.append(frame)
        return out

# 使用示例
symbolicator = AndroidSymbolicator('mapping-1.5.0-10500.txt')
with open('report.json') as f:
    report = json.load(f)
report['stack_frames'] = symbolicator.symbolicate(report['stack_frames'])
```

### 5.6 崩溃告警规则引擎（Go 伪代码）

```go
type AlertRule struct {
    ID         string
    Name       string
    CrashType  string
    Version    string
    Platform   string
    Condition  string // crash_rate / new_group / count_spike / user_spike
    Threshold  float64
    WindowMin  int
    Channels   []string
}

func (r *AlertRule) Evaluate(stats CrashStats) (bool, string) {
    switch r.Condition {
    case "crash_rate":
        if stats.CrashRate >= r.Threshold {
            return true, fmt.Sprintf("崩溃率 %.2f%% 超过阈值 %.2f%%", stats.CrashRate*100, r.Threshold*100)
        }
    case "new_group":
        if stats.NewGroupsInWindow >= int(r.Threshold) {
            return true, fmt.Sprintf("最近 %d 分钟新增 %d 个崩溃分组", r.WindowMin, stats.NewGroupsInWindow)
        }
    case "count_spike":
        if stats.CrashCount >= int(r.Threshold) {
            return true, fmt.Sprintf("最近 %d 分钟崩溃次数 %d 超过阈值", r.WindowMin, stats.CrashCount)
        }
    case "user_spike":
        if stats.AffectedUsers >= int(r.Threshold) {
            return true, fmt.Sprintf("最近 %d 分钟影响用户 %d 超过阈值", r.WindowMin, stats.AffectedUsers)
        }
    }
    return false, ""
}
```

```text
           ▼               ▼               ▼
    ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
    │    fixed    │  │   ignored   │  │   snoozed   │
    └──────┬──────┘  └──────┬──────┘  └──────┬──────┘
           │               │                │ 到期/复现
           │ 新版本验证失败 │ 重新评估        │
           ▼               ▼                ▼
    ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
    │   closed    │  │    open     │  │    open     │
    └─────────────┘  └─────────────┘  └─────────────┘
```

### 6.3 状态转换规则

| 当前状态 | 目标状态 | 触发条件 | 说明 |
| --- | --- | --- | --- |
| pending | symbolicated | 符号化完成 | 自动 |
| symbolicated | grouped | 聚合完成 | 自动 |
| grouped | open | 新分组首次聚合 | 自动 |
| open | in_progress | 研发在后台认领 | 人工 |
| in_progress | fixed | 提交修复代码 | 人工 |
| fixed | closed | 新版本崩溃归零超过 3 天 | 自动或人工 |
| fixed | open | 新版本仍出现同一签名 | 自动 |
| open | ignored | 非应用问题或无法修复 | 人工 |
| ignored | open | 重新评估 | 人工 |
| open | snoozed | 暂缓处理 | 人工 |
| snoozed | open | 到达暂缓期限或新崩溃 | 自动/人工 |

## 7. 错误处理

### 7.1 客户端侧错误处理

| 场景 | 处理策略 |
| --- | --- |
| 崩溃 SDK 自身异常 | 捕获 SDK 自身异常，记录到本地日志，但不再次触发崩溃上报，避免死循环 |
| 上报失败（无网络） | 本地持久化，网络恢复后按指数退避重试，最多 7 天 |
| 上报失败（服务端 5xx） | 进入退避队列，30 秒/1 分钟/5 分钟/15 分钟梯度重试 |
| 上报失败（4xx 非法数据） | 丢弃当前报告，记录错误日志，避免重复无效上报 |
| 崩溃上报时再次崩溃 | 不阻塞主流程，只保存最近一条，避免级联崩溃 |
| 报告体积过大 | 截断堆栈至 200 帧、截断消息至 500 字符、日志快照至 100KB |
| 隐私字段混入 | 自定义数据 keys 白名单，values 正则脱敏（手机号、身份证、地址） |
| 符号化失败 | 保留原始堆栈，group_id 基于原始堆栈签名生成，后续符号文件补充后触发重试 |

### 7.2 服务端侧错误处理

| 场景 | 处理策略 |
| --- | --- |
| 重复 report_id | 幂等返回，不入库 |
| 版本/构建号不匹配 | 记录但标记为 `unknown_version`，不进入告警规则 |
| 符号文件缺失 | 标记 `symbolication_status = missing_symbol`，人工/CI 补充后触发重跑 |
| 符号文件格式错误 | 记录失败原因，通知构建团队，保留原始堆栈 |
| 聚合算法冲突 | 优先以新报告签名匹配现有 group；如冲突则建立新分组并标记关联 |
| 数据库写入失败 | 写入死信队列，人工介入，同时返回 500 让客户端重试 |
| 告警通道失败 | 告警记录落库，异步补偿发送 |
| 恶意/伪造上报 | 基于 device_id_hash + 时间窗口限流，异常签名加入临时黑名单 |

### 7.3 符号化失败降级

```text
[收到崩溃报告]
       │
       ▼
[查询符号文件]
       │
   不存在/不可用
       │
       ▼
[标记 missing_symbol] ──→ 发送 Slack 通知至构建团队
       │
       ▼
[使用原始堆栈生成 group_id] ──→ 进入聚合
       │
       ▼
[符号文件补充上传后]
       │
       ▼
[重跑该版本所有 pending/symbolication_failed 报告]
       │
       ▼
[更新 group 标题/堆栈/签名]
```

### 7.4 重复/脏数据清理

1. **去重键**：`report_id` 唯一索引。
2. **采样去重**：同一设备同一崩溃签名在 1 小时内只保留首次完整报告，后续只更新计数。
3. **脏数据过滤**：`exception_message` 包含已知第三方 SDK 广告插件崩溃时，自动标记为 `third_party` 并降低优先级。
4. **定期清理**：超过 90 天的明细报告转存冷存储（对象存储归档），MySQL 中保留聚合数据和最近 30 天明细。

## 8. 性能与隐私

### 8.1 性能优化

| 环节 | 优化策略 |
| --- | --- |
| 崩溃采集 | 非主线程/非主 Isolate 完成堆栈解析和序列化，避免卡顿 |
| 本地持久化 | 使用 SQLite/Hive 批量写入，崩溃写入耗时 < 50ms |
| 上报压缩 | 使用 gzip / zstd 压缩，Protobuf 序列化，平均体积 < 20KB |
| 上报频率 | 启动时最多上报 5 条；运行期批量上报，每 10 秒或满 10 条触发一次 |
| 符号化 | 异步 Worker 队列，符号文件懒加载到内存，LRU 缓存 |
| 聚合计算 | 基于 Elasticsearch/ClickHouse 预聚合，管理后台查询走只读副本 |
| 存储分层 | 热数据（7 天）MySQL + 温数据（90 天）对象存储 + 冷数据归档 |

### 8.2 隐私与合规

| 数据项 | 处理方式 |
| --- | --- |
| 用户 ID | 客户端哈希化后上报，服务端不可逆还原 |
| 设备 ID | 生成独立崩溃匿名 ID，与业务设备 ID 隔离 |
| 手机号/身份证 | 自定义数据正则过滤，命中则替换为 `[REDACTED]` |
| 页面参数/题目 ID | 允许上报，但禁止上报用户输入内容、截图、语音原始数据 |
| 日志快照 | 本地脱敏后上报，保留最近 200 条，自动裁剪 |
| 保留期限 | 明细 90 天，聚合 2 年，超期自动删除或匿名化 |
| 未成年人 | 崩溃数据中不区分年龄，仅保留学段年级（初中/高中等）用于分析 |

## 9. 安全与合规

### 9.1 接口安全

| 接口 | 安全措施 |
| --- | --- |
| 崩溃上报 | 不强制登录，但需携带匿名 device_id 和合法 app 签名；限流 10 次/分钟/设备 |
| 符号上传 | 仅允许 CI/CD 白名单 IP + `X-Build-Token` 校验 |
| 管理后台查询 | 需登录 + 角色权限（研发/测试/运营） |
| 崩溃明细下载 | 增加审计日志，记录下载人、时间、IP |

### 9.2 权限模型

| 角色 | 权限 |
| --- | --- |
| 超级管理员 | 全部操作 |
| 研发工程师 | 查看/分派/修改状态/关联工单 |
| 测试工程师 | 查看/标记忽略/添加备注 |
| 运营/产品 | 查看趋势/版本对比/导出报表 |
| 审计员 | 仅查看日志和报表 |

### 9.3 合规要求

1. 崩溃数据中不包含个人敏感信息，符合《个人信息保护法》最小必要原则。
2. 未成年人崩溃数据按学段维度聚合，不精确到个人。
3. 崩溃数据不出境，对象存储部署在国内区域。
4. 符号文件（包含源码行号）仅存储在内部对象存储，不随崩溃报告下发到客户端。
5. 崩溃报告传输使用 TLS 1.3，存储字段级加密可选。
