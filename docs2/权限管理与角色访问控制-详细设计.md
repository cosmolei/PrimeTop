## 1. 概述

### 1.1 设计目标

为 PrimeTop 平台提供统一的权限管理与角色访问控制能力，覆盖学生、家长、教师、运营人员、平台管理员等多种角色，支撑：

- **功能权限**：不同角色可访问的功能模块、API 接口
- **数据权限**：不同角色可查看/操作的数据范围（如教师只看本班学生数据）
- **内容权限**：按学段、学科、功能控制内容可见性
- **设备权限**：家长端对子女设备的时长管控、功能开关

### 1.2 设计原则

1. **默认拒绝**：未明确授权的访问一律拒绝
2. **最小权限**：角色只授予完成工作所需的最低权限
3. **集中管理**：权限策略在服务端集中存储与校验，客户端仅做 UI 层隐藏
4. **可扩展**：支持后续新增角色（如学校管理员、机构管理员）和权限项
5. **审计可追溯**：所有权限变更和越权尝试均有日志记录

### 1.3 适用范围

| 端 | 权限类型 | 说明 |
|---|---|---|
| 客户端（学生/家长） | 功能权限 + 数据权限 | 按角色控制可见功能模块和数据范围 |
| 教师端 | 功能权限 + 数据权限 | 按班级、学科控制可管理的学生数据 |
| 管理后台（Web） | 功能权限 + 数据权限 | 按角色（运营/内容/管理员）控制后台功能 |
| API 网关 | 接口权限 | 统一鉴权、接口级别访问控制 |

### 2.3 用户-角色关联模型

一个用户可以拥有多个角色（如一个教师同时也是家长），但同一会话只激活一个角色上下文。

```sql
-- 角色定义表
CREATE TABLE roles (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    code        VARCHAR(64) NOT NULL UNIQUE COMMENT '角色编码，如 teacher',
    name        VARCHAR(128) NOT NULL COMMENT '角色名称，如 任课教师',
    category    VARCHAR(32) NOT NULL COMMENT '角色分类: platform/education/user',
    description TEXT COMMENT '角色描述',
    is_system   TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否系统内置角色(不可删除)',
    status      TINYINT(1) NOT NULL DEFAULT 1 COMMENT '1-启用 0-禁用',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category (category),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='角色定义表';

-- 权限定义表
CREATE TABLE permissions (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    code        VARCHAR(128) NOT NULL UNIQUE COMMENT '权限编码，如 question:create',
    name        VARCHAR(128) NOT NULL COMMENT '权限名称，如 创建题目',
    module      VARCHAR(64) NOT NULL COMMENT '所属模块，如 question/textbook/ai',
    action      VARCHAR(32) NOT NULL COMMENT '操作类型: create/read/update/delete/approve/export',
    resource    VARCHAR(128) NOT NULL COMMENT '资源标识，如 *, question:own, student:class',
    description TEXT COMMENT '权限描述',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_module (module),
    INDEX idx_action (action)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='权限定义表';

-- 角色-权限关联表
CREATE TABLE role_permissions (
    id             BIGINT PRIMARY KEY AUTO_INCREMENT,
    role_id        BIGINT NOT NULL COMMENT '角色ID',
    permission_id  BIGINT NOT NULL COMMENT '权限ID',
    created_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_role_perm (role_id, permission_id),
    INDEX idx_role (role_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='角色-权限关联表';

-- 用户-角色关联表
CREATE TABLE user_roles (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id     BIGINT NOT NULL COMMENT '用户ID',
    role_id     BIGINT NOT NULL COMMENT '角色ID',
    scope       JSON DEFAULT NULL COMMENT '数据范围，如 {"school_id":1,"class_ids":[3,4],"subject_ids":[2]}',
    granted_by  BIGINT COMMENT '授权人ID',
    status      TINYINT(1) NOT NULL DEFAULT 1 COMMENT '1-生效 0-失效',
    expires_at  DATETIME COMMENT '过期时间，NULL表示永不过期',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_role (user_id, role_id),
    INDEX idx_user (user_id),
    INDEX idx_status (status),
    INDEX idx_expires (expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户-角色关联表';

-- 角色继承表（支持角色层级）
CREATE TABLE role_inheritance (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    parent_role_id  BIGINT NOT NULL COMMENT '父角色ID',
    child_role_id   BIGINT NOT NULL COMMENT '子角色ID',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_inherit (parent_role_id, child_role_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='角色继承关系表';

-- 权限变更审计日志
CREATE TABLE permission_audit_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    operator_id     BIGINT NOT NULL COMMENT '操作人ID',
    target_user_id  BIGINT COMMENT '目标用户ID',
    action_type     VARCHAR(32) NOT NULL COMMENT '操作类型: grant_role/revoke_role/grant_perm/revoke_perm/modify_scope',
    role_id         BIGINT COMMENT '角色ID',
    permission_id   BIGINT COMMENT '权限ID',
    old_value       JSON COMMENT '变更前值',
    new_value       JSON COMMENT '变更后值',
    reason          VARCHAR(512) COMMENT '变更原因',
    ip_address      VARCHAR(45) COMMENT '操作IP',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_operator (operator_id),
    INDEX idx_target (target_user_id),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='权限变更审计日志';
```

## 3. 权限模型

### 3.1 权限编码规范

采用 `模块:操作:范围` 三段式编码：

```text
{module}:{action}:{scope}

示例：
question:create:*           题目模块-创建-所有
question:read:own           题目模块-读取-仅自己创建的
student:read:class          学生模块-读取-仅本班级
report:export:school        报告模块-导出-本校
ai_prompt:update:*          AI提示词模块-更新-所有
```

## 5. 核心服务实现

### 5.1 权限服务架构

```text
┌─────────────────────────────────────────────────────────────┐
│                       API 网关层                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │           AuthMiddleware (JWT 验证)                   │    │
│  │  - 解析 token → user_id, role_context                │    │
│  │  - 注入 X-User-Id, X-Role-Code, X-Scope header      │    │
│  └─────────────────────────────────────────────────────┘    │
│                          │                                   │
│  ┌─────────────────────────────────────────────────────┐    │
│  │          PermissionMiddleware (权限校验)               │    │
│  │  - 从路由配置获取所需权限                              │    │
│  │  - 调用 PermissionService.check()                    │    │
│  │  - 通过 → 放行；拒绝 → 403                           │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                          │
┌─────────────────────────────────────────────────────────────┐
│                     业务服务层                                │
│  ┌──────────────────────────────────────────────────────┐   │
│  │              PermissionService                        │   │
│  │  - check(user_id, permission, context) → bool        │   │
│  │  - get_user_permissions(user_id) → list              │   │
│  │  - get_feature_gates(user_id) → FeatureGates        │   │
│  │  - filter_data_scope(user_id, query) → query         │   │
│  └──────────────────────────────────────────────────────┘   │
│                          │                                   │
│  ┌──────────────────────────────────────────────────────┐   │
│  │              RoleManagementService                    │   │
│  │  - grant_role(user_id, role_id, scope)               │   │
│  │  - revoke_role(user_id, role_id, reason)             │   │
│  │  - update_permissions(role_id, permission_ids)       │   │
│  │  - get_role_tree() → 角色继承树                      │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                          │
┌─────────────────────────────────────────────────────────────┐
│                     缓存层 (Redis)                           │
│  - user_permissions:{user_id}  → Set<permission_code>      │
│  - user_roles:{user_id}        → List<role_with_scope>     │
│  - role_permissions:{role_id}  → Set<permission_code>      │
│  - feature_gates:{user_id}     → FeatureGates JSON         │
│  TTL: 5 分钟（权限变更时主动失效）                            │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 权限服务核心代码

```python
# services/permission_service.py

from dataclasses import dataclass
from typing import Optional
import json
import logging

from cache.permission_cache import PermissionCache
from models.role import UserRole, Role, Permission
from models.user import User

logger = logging.getLogger(__name__)


@dataclass
class PermissionCheckResult:
    allowed: bool
    reason: Optional[str] = None
    matched_scope: Optional[dict] = None


class PermissionService:
    """
    统一权限校验服务。
    
    校验流程：
    1. 从缓存获取用户角色+权限列表（缓存未命中则查库并回填）
    2. 检查用户是否有目标权限编码
    3. 如有数据范围要求，检查 scope 是否匹配
    4. 记录越权尝试日志（用于安全审计）
    """

    def __init__(self, cache: PermissionCache):
        self._cache = cache

    async def check(
        self,
        user_id: int,
        permission_code: str,
        resource_context: Optional[dict] = None,
    ) -> PermissionCheckResult:
        """
        检查用户是否拥有指定权限。
        
        Args:
            user_id: 用户ID
            permission_code: 权限编码，如 "student:read:class"
            resource_context: 资源上下文，如 {"class_id": 3}
        
        Returns:
            PermissionCheckResult(allowed=True/False, reason=...)
        """
        # 获取用户权限集
        permissions = await self._cache.get_user_permissions(user_id)
        if permissions is None:
            permissions = await self._load_and_cache_permissions(user_id)

        # 解析权限编码
        module, action, scope_level = self._parse_permission_code(permission_code)

        # 1. 精确匹配
        if permission_code in permissions:
            return await self._check_data_scope(
                user_id, scope_level, resource_context
            )

        # 2. 通配符匹配 (user:read:* 可覆盖 user:read:class)
        wildcard = f"{module}:{action}:*"
        if wildcard in permissions:
            return PermissionCheckResult(allowed=True, matched_scope={"scope": "*"})

        # 3. 权限不足
        logger.warning(
            "Permission denied",
            extra={
                "user_id": user_id,
                "permission": permission_code,
                "context": resource_context,
            },
        )
        return PermissionCheckResult(
            allowed=False, reason="permission_denied"
        )

    async def check_any(
        self, user_id: int, permission_codes: list[str]
    ) -> bool:
        """检查用户是否拥有任一权限。"""
        permissions = await self._cache.get_user_permissions(user_id)
        if permissions is None:
            permissions = await self._load_and_cache_permissions(user_id)
        return bool(set(permission_codes) & permissions)

    async def filter_by_data_scope(
        self, user_id: int, base_query, resource_type: str
    ) -> object:
        """
        根据用户数据范围自动过滤查询。
        
        示例：教师查看学生列表时，自动追加 class_id IN (...) 条件。
        
        Args:
            user_id: 用户ID
            base_query: SQLAlchemy/ORM 基础查询对象
            resource_type: 资源类型，如 "student", "report"
        
        Returns:
            追加数据范围过滤后的查询对象
        """
        roles = await self._cache.get_user_roles(user_id)
        if roles is None:
            roles = await self._load_and_cache_roles(user_id)

        # 寻找最高权限的数据范围
        for role in roles:
            scope = role.get("scope", {})
            if not scope:
                continue

            if resource_type == "student":
                if "class_ids" in scope:
                    return base_query.filter(
                        base_query.class_id.in_(scope["class_ids"])
                    )
                if "grade_ids" in scope:
                    return base_query.filter(
                        base_query.grade_id.in_(scope["grade_ids"])
                    )
                if "school_id" in scope:
                    return base_query.filter(
                        base_query.school_id == scope["school_id"]
                    )

            elif resource_type == "report":
                # 报告数据范围过滤逻辑类似
                pass

        return base_query

    async def _check_data_scope(
        self, user_id: int, scope_level: str, context: Optional[dict]
    ) -> PermissionCheckResult:
        """检查数据范围是否匹配。"""
        if scope_level == "*":
            return PermissionCheckResult(allowed=True)

        if not context:
            # 权限需要数据范围检查但未提供上下文
            return PermissionCheckResult(allowed=False, reason="missing_context")

        roles = await self._cache.get_user_roles(user_id)
        if roles is None:
            roles = await self._load_and_cache_roles(user_id)

        for role in roles:
            scope = role.get("scope", {})
            if not scope:
                continue

            # 按范围级别检查
            if scope_level == "class" and "class_ids" in scope:
                target_id = context.get("class_id")
                if target_id and target_id in scope["class_ids"]:
                    return PermissionCheckResult(
                        allowed=True, matched_scope=scope
                    )

            elif scope_level == "grade" and "grade_ids" in scope:
                target_id = context.get("grade_id")
                if target_id and target_id in scope["grade_ids"]:
                    return PermissionCheckResult(
                        allowed=True, matched_scope=scope
                    )

            elif scope_level == "school" and "school_id" in scope:
                target_id = context.get("school_id")
                if target_id and target_id == scope["school_id"]:
                    return PermissionCheckResult(
                        allowed=True, matched_scope=scope
                    )

            elif scope_level == "own":
                # "own" 类型直接通过，业务层自行过滤
                return PermissionCheckResult(allowed=True)

        return PermissionCheckResult(allowed=False, reason="data_scope_denied")

    async def _load_and_cache_permissions(self, user_id: int) -> set[str]:
        """从数据库加载用户权限并缓存。"""
        # 查询用户所有角色
        user_roles = await UserRole.filter(user_id=user_id, status=1).all()

        all_permissions = set()
        for ur in user_roles:
            role = await Role.get(id=ur.role_id)
            if role.status != 1:
                continue

            # 获取角色直接权限
            perms = await self._cache.get_role_permissions(role.id)
            if perms is None:
                perms = await self._load_role_permissions(role.id)
            all_permissions.update(perms)

            # 获取继承权限（递归）
            inherited = await self._get_inherited_permissions(role.id)
            all_permissions.update(inherited)

        await self._cache.set_user_permissions(user_id, all_permissions)
        return all_permissions

    async def _load_role_permissions(self, role_id: int) -> set[str]:
        """加载角色的直接权限。"""
        from models.role import RolePermission, Permission as Perm

        rp_ids = await RolePermission.filter(role_id=role_id).values_list(
            "permission_id", flat=True
        )
        codes = await Perm.filter(id__in=rp_ids).values_list("code", flat=True)
        codes_set = set(codes)
        await self._cache.set_role_permissions(role_id, codes_set)
        return codes_set

    async def _get_inherited_permissions(self, role_id: int, visited=None) -> set[str]:
        """递归获取继承的权限。"""
        if visited is None:
            visited = set()
        if role_id in visited:
            return set()
        visited.add(role_id)

        from models.role import RoleInheritance

        parent_ids = await RoleInheritance.filter(
            child_role_id=role_id
        ).values_list("parent_role_id", flat=True)

        all_perms = set()
        for pid in parent_ids:
            perms = await self._cache.get_role_permissions(pid)
            if perms is None:
                perms = await self._load_role_permissions(pid)
            all_perms.update(perms)
            all_perms.update(await self._get_inherited_permissions(pid, visited))

        return all_perms

    @staticmethod
    def _parse_permission_code(code: str) -> tuple[str, str, str]:
        """解析权限编码为 (module, action, scope)。"""
        parts = code.split(":", 2)
        if len(parts) != 3:
            raise ValueError(f"Invalid permission code: {code}")
        return parts[0], parts[1], parts[2]
```

```python
# cache/permission_cache.py

import json
from typing import Optional

import redis.asyncio as redis


class PermissionCache:
    """权限相关 Redis 缓存。"""

    KEY_USER_PERMS = "perm:user:{user_id}"        # Set
    KEY_USER_ROLES = "perm:roles:{user_id}"        # JSON list
    KEY_ROLE_PERMS = "perm:role:{role_id}"         # Set
    KEY_FEATURE_GATES = "perm:gates:{user_id}"     # JSON
    TTL = 300  # 5 分钟

    def __init__(self, redis_client: redis.Redis):
        self._r = redis_client

    # --- User Permissions ---
    async def get_user_permissions(self, user_id: int) -> Optional[set[str]]:
        data = await self._r.smembers(self.KEY_USER_PERMS.format(user_id=user_id))
        return {d.decode() for d in data} if data else None

    async def set_user_permissions(self, user_id: int, perms: set[str]):
        key = self.KEY_USER_PERMS.format(user_id=user_id)
        pipe = self._r.pipeline()
        pipe.delete(key)
        if perms:
            pipe.sadd(key, *perms)
        pipe.expire(key, self.TTL)
        await pipe.execute()

    async def invalidate_user(self, user_id: int):
        """用户权限变更时，清除该用户所有权限缓存。"""
        keys = [
            self.KEY_USER_PERMS.format(user_id=user_id),
            self.KEY_USER_ROLES.format(user_id=user_id),
            self.KEY_FEATURE_GATES.format(user_id=user_id),
        ]
        await self._r.delete(*keys)

    # --- User Roles ---
    async def get_user_roles(self, user_id: int) -> Optional[list[dict]]:
        data = await self._r.get(self.KEY_USER_ROLES.format(user_id=user_id))
        if data is None:
            return None
        return json.loads(data)

    async def set_user_roles(self, user_id: int, roles: list[dict]):
        key = self.KEY_USER_ROLES.format(user_id=user_id)
        await self._r.setex(key, self.TTL, json.dumps(roles, ensure_ascii=False))

    # --- Role Permissions ---
    async def get_role_permissions(self, role_id: int) -> Optional[set[str]]:
        data = await self._r.smembers(self.KEY_ROLE_PERMS.format(role_id=role_id))
        return {d.decode() for d in data} if data else None

    async def set_role_permissions(self, role_id: int, perms: set[str]):
        key = self.KEY_ROLE_PERMS.format(role_id=role_id)
        pipe = self._r.pipeline()
        pipe.delete(key)
        if perms:
            pipe.sadd(key, *perms)
        pipe.expire(key, self.TTL)
        await pipe.execute()

    async def invalidate_role(self, role_id: int):
        """角色权限变更时，清除角色缓存及关联用户缓存。"""
        await self._r.delete(self.KEY_ROLE_PERMS.format(role_id=role_id))
        # 需要异步任务扫描关联用户并清除缓存（见 5.5 缓存失效策略）

    # --- Feature Gates ---
    async def get_feature_gates(self, user_id: int) -> Optional[dict]:
        data = await self._r.get(self.KEY_FEATURE_GATES.format(user_id=user_id))
        return json.loads(data) if data else None

    async def set_feature_gates(self, user_id: int, gates: dict):
        key = self.KEY_FEATURE_GATES.format(user_id=user_id)
        await self._r.setex(key, self.TTL, json.dumps(gates, ensure_ascii=False))
```

### 5.4 API 网关中间件（FastAPI 示例）

```python
# middleware/permission_middleware.py

from functools import wraps
from typing import Optional

from fastapi import HTTPException, Request, Depends
from starlette.middleware.base import BaseHTTPMiddleware

from services.permission_service import PermissionService, PermissionCheckResult


def require_permission(permission_code: str, resource_type: Optional[str] = None):
    """
    权限校验装饰器。
    
    使用示例：
        @router.get("/admin/users")
        @require_permission("user:read:*")
        async def list_users(request: Request):
            ...
    
        @router.get("/classes/{class_id}/students")
        @require_permission("student:read:class")
        async def list_class_students(class_id: int, request: Request):
            ...
    """
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, request: Request = None, **kwargs):
            # 从 request.state 获取当前用户信息（由 AuthMiddleware 注入）
            user_id = getattr(request.state, "user_id", None)
            if not user_id:
                raise HTTPException(status_code=401, detail="not_authenticated")

            # 构建资源上下文
            resource_context = {}
            if resource_type == "class":
                resource_context["class_id"] = kwargs.get("class_id")
            elif resource_type == "school":
                resource_context["school_id"] = kwargs.get("school_id")
            elif resource_type == "student":
                resource_context["student_user_id"] = kwargs.get("student_id")

            # 执行权限检查
            perm_service: PermissionService = request.app.state.permission_service
            result = await perm_service.check(
                user_id, permission_code, resource_context or None
            )

            if not result.allowed:
                raise HTTPException(
                    status_code=403,
                    detail={
                        "code": "PERMISSION_DENIED",
                        "message": f"无权访问: {permission_code}",
                        "reason": result.reason,
                    },
                )

            # 将匹配的数据范围注入 request.state，供业务层使用
            if result.matched_scope:
                request.state.data_scope = result.matched_scope

            return await func(*args, request=request, **kwargs)
        return wrapper
    return decorator


class AuthMiddleware(BaseHTTPMiddleware):
    """
    认证中间件。
    解析 JWT token，提取 user_id、role 信息，注入 request.state。
    """

    # 不需要认证的白名单路径
    WHITE_LIST = {
        "/api/v1/auth/login",
        "/api/v1/auth/register",
        "/api/v1/auth/refresh",
        "/api/v1/auth/verify-code",
        "/health",
        "/docs",
        "/openapi.json",
    }

    async def dispatch(self, request: Request, call_next):
        path = request.url.path

        # 白名单直接放行
        if path in self.WHITE_LIST or path.startswith("/static/"):
            return await call_next(request)

        # 提取 token
        auth_header = request.headers.get("Authorization", "")
        if not auth_header.startswith("Bearer "):
            return await call_next(request)

        token = auth_header[7:]

        try:
            # 解析 JWT（具体实现依赖 JWT 库）
            payload = self._decode_jwt(token)
            request.state.user_id = payload["user_id"]
            request.state.role_code = payload.get("role_code", "guest")
            request.state.session_id = payload.get("session_id")
        except Exception:
            raise HTTPException(status_code=401, detail="invalid_token")

        return await call_next(request)

    @staticmethod
    def _decode_jwt(token: str) -> dict:
        from jose import jwt
        from config.settings import settings
        return jwt.decode(token, settings.JWT_SECRET, algorithms=["HS256"])
```

### 5.5 缓存失效策略

权限变更时的缓存一致性方案：

```python
# services/cache_invalidation.py

import logging
from models.role import UserRole, RoleInheritance

logger = logging.getLogger(__name__)


async def on_role_permissions_changed(role_id: int, cache: PermissionCache):
    """
    角色权限变更时触发。
    1. 清除角色权限缓存
    2. 查找所有拥有该角色的用户
    3. 清除这些用户的权限缓存
    """
    # 清除角色权限缓存
    await cache.invalidate_role(role_id)

    # 查找关联用户
    user_ids = await UserRole.filter(
        role_id=role_id, status=1
    ).values_list("user_id", flat=True)

    # 批量清除用户缓存
    for uid in user_ids:
        await cache.invalidate_user(uid)

    # 检查是否有子角色继承该角色
    child_role_ids = await RoleInheritance.filter(
        parent_role_id=role_id
    ).values_list("child_role_id", flat=True)

    for child_id in child_role_ids:
        await on_role_permissions_changed(child_id, cache)  # 递归失效

    logger.info(
        "Cache invalidated for role %s, affected users: %d",
        role_id, len(user_ids),
    )


async def on_user_role_changed(user_id: int, cache: PermissionCache):
    """用户角色变更时触发。"""
    await cache.invalidate_user(user_id)
    logger.info("Cache invalidated for user %s", user_id)
```

```python
# services/parental_control_service.py

from datetime import time, datetime
from typing import Optional


class ParentalControlService:
    """
    家长管控服务。
    
    职责：
    1. 验证家长对子女的访问权限
    2. 执行时长管控、就寝时间检查
    3. 管理功能白名单
    """

    async def check_access_allowed(
        self, parent_user_id: int, child_user_id: int
    ) -> bool:
        """检查家长是否有权访问子女数据。"""
        binding = await ParentChildBinding.filter(
            parent_user_id=parent_user_id,
            child_user_id=child_user_id,
            status=1,
        ).first()
        return binding is not None

    async def check_time_restriction(
        self, child_user_id: int
    ) -> tuple[bool, Optional[str]]:
        """
        检查子女当前是否在允许使用时间内。
        
        Returns:
            (allowed, reason)
        """
        binding = await self._get_active_binding(child_user_id)
        if not binding:
            return True, None  # 未绑定家长，不限制

        # 就寝时间检查
        now = datetime.now().time()
        if binding.bedtime_start and binding.bedtime_end:
            if binding.bedtime_start <= binding.bedtime_end:
                # 同一天内，如 21:00 ~ 07:00（次日）—— 不对，这是跨天的
                # 标准化：bedtime_start > bedtime_end 表示跨午夜
                pass
            if self._is_in_bedtime(now, binding.bedtime_start, binding.bedtime_end):
                return False, "bedtime_restriction"

        # 每日时长检查
        if binding.daily_time_limit_min:
            today_usage = await self._get_today_usage(child_user_id)
            if today_usage >= binding.daily_time_limit_min:
                return False, "daily_limit_exceeded"

        return True, None

    async def check_feature_allowed(
        self, child_user_id: int, feature_code: str
    ) -> bool:
        """检查子女是否被允许使用某功能。"""
        binding = await self._get_active_binding(child_user_id)
        if not binding or not binding.allowed_features:
            return True  # 未限制
        return feature_code in binding.allowed_features

    async def get_parental_control_status(
        self, child_user_id: int
    ) -> dict:
        """获取子女的家长管控状态（客户端用于展示管控提示）。"""
        binding = await self._get_active_binding(child_user_id)
        if not binding:
            return {"controlled": False}

        time_allowed, time_reason = await self.check_time_restriction(
            child_user_id
        )

        return {
            "controlled": True,
            "time_allowed": time_allowed,
            "time_reason": time_reason,
            "daily_limit_min": binding.daily_time_limit_min,
            "today_usage_min": await self._get_today_usage(child_user_id),
            "bedtime_start": str(binding.bedtime_start) if binding.bedtime_start else None,
            "bedtime_end": str(binding.bedtime_end) if binding.bedtime_end else None,
            "restricted_features": binding.allowed_features,  # NULL = 不限制
        }

    @staticmethod
    def _is_in_bedtime(now: time, start: time, end: time) -> bool:
        """判断当前时间是否在就寝时段内。"""
        if start <= end:
            # 不跨午夜，如 12:00 ~ 14:00
            return start <= now <= end
        else:
            # 跨午夜，如 21:00 ~ 次日 07:00
            return now >= start or now <= end

    async def _get_active_binding(self, child_user_id: int):
        """获取子女的一条有效绑定。"""
        return await ParentChildBinding.filter(
            child_user_id=child_user_id, status=1
        ).first()

    async def _get_today_usage(self, child_user_id: int) -> int:
        """获取今日使用分钟数（从学习记录服务获取）。"""
        from services.learning_record_service import LearningRecordService
        return await LearningRecordService.get_today_duration(child_user_id)
```

```python
from functools import wraps
from fastapi import HTTPException, Request


def data_scope_filter(resource_type: str):
    """
    数据范围过滤装饰器。
    
    自动根据当前用户的数据范围追加过滤条件。
    
    使用示例：
        @router.get("/students")
        @require_permission("student:read:class")
        @data_scope_filter("student")
        async def list_students(request: Request):
            scope = request.state.data_scope
            query = Student.filter(...)
            query = apply_scope_filter(query, scope, "student")
            return await query.all()
    """
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, request: Request = None, **kwargs):
            # 获取当前用户数据范围（由 require_permission 注入）
            scope = getattr(request.state, "data_scope", None)
            if scope and scope.get("scope") != "*":
                request.state.applied_scope = scope
            return await func(*args, request=request, **kwargs)
        return wrapper
    return decorator


def apply_scope_filter(query, scope: dict, resource_type: str):
    """根据数据范围对 ORM 查询追加过滤条件。"""
    if not scope or scope.get("scope") == "*":
        return query

    if resource_type == "student":
        if "class_ids" in scope:
            return query.filter(class_id__in=scope["class_ids"])
        if "grade_ids" in scope:
            return query.filter(grade_id__in=scope["grade_ids"])
        if "school_id" in scope:
            return query.filter(school_id=scope["school_id"])

    elif resource_type == "report":
        if "class_ids" in scope:
            return query.filter(class_id__in=scope["class_ids"])
        if "school_id" in scope:
            return query.filter(school_id=scope["school_id"])

    return query
```

```dart
/// 权限状态模型
class PermissionState {
  final Set<String> permissions;
  final Map<String, FeatureGate> features;
  final List<UserRole> roles;
  final bool isLoading;

  const PermissionState({
    this.permissions = const {},
    this.features = const {},
    this.roles = const [],
    this.isLoading = false,
  });

  bool hasPermission(String code) => permissions.contains(code);

  bool isFeatureEnabled(String featureCode) {
    final gate = features[featureCode];
    return gate?.enabled ?? false;
  }

  bool hasRole(String roleCode) =>
      roles.any((r) => r.code == roleCode);
}

/// 功能开关模型
class FeatureGate {
  final bool enabled;
  final int? dailyLimit;
  final int? dailyUsed;
  final String? reason;

  const FeatureGate({
    required this.enabled,
    this.dailyLimit,
    this.dailyUsed,
    this.reason,
  });

  bool get isLimited => dailyLimit != null;
  bool get isExhausted =>
      dailyLimit != null && dailyUsed != null && dailyUsed! >= dailyLimit!;
  int get remaining =>
      (dailyLimit ?? 0) - (dailyUsed ?? 0);
}

/// 权限 Provider
final permissionProvider =
    StateNotifierProvider<PermissionNotifier, PermissionState>(
  (ref) => PermissionNotifier(ref.read(apiClientProvider)),
);

class PermissionNotifier extends StateNotifier<PermissionState> {
  final Dio _dio;

  PermissionNotifier(this._dio)
      : super(const PermissionState(isLoading: true));

  /// 登录后加载权限
  Future<void> loadPermissions() async {
    state = const PermissionState(isLoading: true);
    try {
      final response = await _dio.get('/api/v1/auth/permissions');
      final data = response.data['data'];

      state = PermissionState(
        permissions: Set<String>.from(data['permissions'] ?? []),
        features: _parseFeatures(data['features'] ?? {}),
        roles: _parseRoles(data['roles'] ?? []),
        isLoading: false,
      );
    } catch (e) {
      state = const PermissionState(isLoading: false);
    }
  }

  /// 刷新功能开关（每次从后台恢复时调用）
  Future<void> refreshFeatureGates() async {
    try {
      final response = await _dio.get('/api/v1/auth/feature-gates');
      final data = response.data['data'];
      state = PermissionState(
        permissions: state.permissions,
        features: _parseFeatures(data['features'] ?? {}),
        roles: state.roles,
        isLoading: false,
      );
    } catch (_) {}
  }

  /// 登出时清除
  void clear() {
    state = const PermissionState();
  }

  Map<String, FeatureGate> _parseFeatures(Map<String, dynamic> json) {
    return json.map((key, value) => MapEntry(
          key,
          FeatureGate(
            enabled: value['enabled'] ?? false,
            dailyLimit: value['daily_limit'],
            dailyUsed: value['daily_used'],
            reason: value['reason'],
          ),
        ));
  }

  List<UserRole> _parseRoles(List json) {
    return json
        .map((r) => UserRole(
              roleId: r['role_id'],
              code: r['role_code'],
              name: r['role_name'],
            ))
        .toList();
  }
}

/// 权限检查 Widget（条件渲染）
class PermissionGuard extends ConsumerWidget {
  final String permission;
  final Widget child;
  final Widget? fallback;

  const PermissionGuard({
    super.key,
    required this.permission,
    required this.child,
    this.fallback,
  });

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final perms = ref.watch(permissionProvider);
    if (perms.hasPermission(permission)) {
      return child;
    }
    return fallback ?? const SizedBox.shrink();

}

  });

    }

  }
}
```

```typescript
// src/router/guards/permissionGuard.ts

import type { Router } from 'vue-router';
import { usePermissionStore } from '@/stores/permission';

const WHITE_LIST = ['/login', '/403', '/404'];

export function setupPermissionGuard(router: Router) {
  router.beforeEach(async (to, _from, next) => {
    const permStore = usePermissionStore();

    // 白名单直接放行
    if (WHITE_LIST.includes(to.path)) {
      return next();
    }

    // 未加载权限则先加载
    if (!permStore.loaded) {
      await permStore.loadPermissions();
    }

    // 检查路由所需权限
    const requiredPermission = to.meta.permission as string | undefined;
    if (!requiredPermission) {
      return next(); // 无权限要求的路由直接放行
    }

    if (permStore.hasPermission(requiredPermission)) {
      return next();
    }

    // 无权限，跳转 403
    return next({ path: '/403', query: { from: to.fullPath } });
  });
}
```

## 11. 错误处理

### 11.1 错误码定义

| 错误码 | HTTP Status | 说明 | 客户端处理 |
|---|---|---|---|
| `PERMISSION_DENIED` | 403 | 无访问权限 | 提示无权限，引导联系管理员 |
| `ROLE_NOT_AUTHORIZED` | 403 | 角色未授权此操作 | 提示需要特定角色 |
| `DATA_SCOPE_DENIED` | 403 | 数据范围越权 | 提示无权访问此数据 |
| `FEATURE_DISABLED` | 403 | 功能未开启 | 展示功能锁定页面 |
| `DAILY_LIMIT_EXCEEDED` | 429 | 每日限额已用完 | 展示剩余额度，引导开通会员 |
| `BEDTIME_RESTRICTED` | 403 | 就寝时间限制 | 展示就寝提示，引导明日再来 |
| `TOKEN_EXPIRED` | 401 | Token 过期 | 自动刷新 token |
| `TOKEN_INVALID` | 401 | Token 无效 | 跳转登录页 |
| `ROLE_EXPIRED` | 403 | 角色已过期 | 提示联系管理员续期 |
| `ACCOUNT_SUSPENDED` | 403 | 账号被封禁 | 提示联系客服 |
| `CONCURRENT_LOGIN_LIMIT` | 401 | 设备登录数超限 | 提示踢出其他设备 |

## 12. 安全考量

### 12.1 安全规则

1. **服务端强制校验**：所有权限检查必须在服务端执行，客户端权限仅用于 UI 展示控制
2. **越权日志**：所有 403 响应记录到安全审计日志，连续多次越权尝试触发告警
3. **角色过期检查**：每次权限校验时检查 `expires_at`，过期角色自动失效
4. **数据范围不依赖客户端**：教师/家长查看数据时，过滤条件由服务端 scope 决定
5. **管理操作二次确认**：角色授权、权限变更等高危操作需要二次确认
6. **超级管理员保护**：`super_admin` 角色至少保留 1 个账号，防止锁定

### 12.2 防御措施

| 场景 | 风险 | 防御 |
|---|---|---|
| 伪造请求修改 role_id | 水平越权 | 角色变更只能通过管理后台接口，需 `role:manage:*` 权限 |
| 教师查看非本班学生 | 垂直越权 | 服务端 scope 过滤，不信任客户端参数 |
| 家长解绑后仍访问 | 权限残留 | 解绑时立即清除缓存，后续请求鉴权失败 |
| Token 泄露 | 身份冒用 | JWT 绑定设备指纹，异常设备自动踢出 |
| 暴力猜权限码 | 枚举攻击 | 权限码不暴露给客户端（只返回 allowed/denied） |

## 13. 性能优化

### 13.1 缓存策略

| 缓存项 | TTL | 更新策略 |

| 角色权限集合 | 5 分钟 | 角色权限变更时失效 + 关联用户级联失效 |

| 家长管控配置 | 5 分钟 | 家长修改后主动失效 |

### 13.2 性能指标

| 指标 | 目标 |
|---|---|
| 单次权限检查延迟 | < 2ms (缓存命中) |
| 权限批量检查延迟 | < 10ms (10 个权限) |
| 功能开关加载延迟 | < 50ms (含网络) |
| 缓存命中率 | > 99% |

### 15.2 事件订阅

```python
# events/permission_event_handlers.py

from bus.event_bus import subscribe
from events.user_events import UserRegistered, UserDeleted
from events.membership_events import MembershipChanged
from services.cache_invalidation import on_user_role_changed


@subscribe(UserRegistered)
async def on_user_registered(event: UserRegistered):
    """新用户注册，自动分配默认角色。"""
    from models.role import UserRole, Role

    # 根据用户类型分配默认角色
    role = await Role.filter(code=event.default_role or "student").first()
    if role:
        await UserRole.create(
            user_id=event.user_id,
            role_id=role.id,
            scope=None,
            granted_by=None,  # 系统自动分配
        )
        # 新用户不需要清缓存（还没有缓存）


@subscribe(UserDeleted)
async def on_user_deleted(event: UserDeleted):
    """用户注销，清除所有角色和缓存。"""
    from models.role import UserRole
    from cache.permission_cache import PermissionCache

    await UserRole.filter(user_id=event.user_id).update(status=0)
    cache = PermissionCache(get_redis())
    await cache.invalidate_user(event.user_id)


@subscribe(MembershipChanged)
async def on_membership_changed(event: MembershipChanged):
    """会员等级变更，刷新功能开关缓存。"""
    from cache.permission_cache import PermissionCache

    cache = PermissionCache(get_redis())
    await cache.invalidate_user(event.user_id)
```
