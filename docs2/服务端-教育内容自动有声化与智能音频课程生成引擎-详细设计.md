# 服务端 - 教育内容自动有声化与智能音频课程生成引擎 详细设计

> 版本：v1.0 | 更新时间：2026-07-04

## 1. 概述

### 1.1 模块定位

教育内容自动有声化引擎是 PrimeTop 内容生产管线的重要补充模块。原始设计文档在第 5.1~5.4 节按学段规划了不同交互方式，其中幼儿阶段明确要求"语音化"交互，小学阶段也需"朗读纠音"能力。同时，第 6.4 节同步课堂学习模块、第 6.5 节拼音识字启蒙模块、第 6.12 节文科背诵模块均存在将文字教材内容转换为音频的实际需求。

现有 `语音服务(ASR-TTS)-详细设计` 解决的是**底层 TTS 能力抽象与供应商对接**问题；现有 `客户端-音频播放器与录制引擎` 解决的是**客户端音频播放与录音**问题。两者之间缺少一个面向**教育内容生产侧**的自动化管线——将章节文本、知识点讲解、题目解析、背诵材料等文字内容批量转换为高质量、分段可导航、带学科特色朗读规则的有声学习材料。

| 上游内容来源 | 有声化场景 |
|-------------|-----------|
| 同步课堂章节 | 课文朗读、知识导读、课后总结音频版 |
| 拼音识字启蒙 | 拼音发音示范、汉字组词造句朗读 |
| 文科背诵 | 古诗文朗诵、英语课文跟读、历史事件叙述 |
| 理科知识讲解 | 概念讲解音频、公式读法示范、实验步骤口述 |
| 错题本 | 错题解析语音版（通勤/休息场景听复习） |
| 学情报告 | 家长端周报/月报语音播报 |

### 1.2 设计目标

1. **教育内容感知**：自动识别内容类型（古诗文/公式/对话/叙述文），应用对应朗读规则
2. **学科发音精准**：数学公式、化学方程式、物理符号、历史人名地名等专业词汇的准确朗读
3. **多角色/多音色**：支持多角色对话场景（英语听力、课文角色朗读），自动分配不同音色
4. **分段与导航**：自动按知识粒度分段，生成音频章节目录，支持跳转播放
5. **批量生产**：支持整章、整册内容批量合成，服务端异步处理
6. **版本联动**：文本内容更新时自动触发重新合成，保持音频与文字版本一致
7. **成本分级**：免费内容用标准音色，精品内容用高保真音色，按会员权益分发
8. **缓存与分发**：合成结果持久化存储，通过 CDN 分发，支持边播边下

### 1.3 核心能力范围

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 文本预处理与朗读标注 | 文本自动分句、多音字消歧、数字/公式转读法 | P0 |
| 学科朗读规则引擎 | 按学科+内容类型应用朗读规则（数学公式读法、古诗文节奏等） | P0 |

## 4. 核心子系统设计

### 4.1 文本预处理与朗读标注引擎

将原始 Markdown / 富文本 / 结构化内容转换为带朗读标注的中间表示 (Annotated Narration Script)。

#### 4.1.1 处理管线

```
原始文本 (Markdown/HTML/结构化JSON)
    │
    ├─ 1. 格式归一化 → 纯文本 + 结构标记
    ├─ 2. 内容类型识别 → 诗歌/公式/对话/叙述/列表
    ├─ 3. 分句与分段 → 按语义和自然停顿拆分
    ├─ 4. 多音字消歧 → 上下文确定读音
    ├─ 5. 数字/符号/单位转换 → "3.14" → "三点一四"
    ├─ 6. 学科术语标注 → 匹配发音词典
    ├─ 7. SSML 生成 → 供应商中性 SSML + 扩展标签
    │
    └─→ Annotated Narration Script (JSON)
```

#### 4.1.3 学科朗读规则详解

**数学公式朗读规则：**

| 原文 | 朗读文本 | SSML 处理 |
|------|---------|-----------|
| `a² + b² = c²` | a 的平方 加 b 的平方 等于 c 的平方 | `<say-as interpret-as="math-expression">` |
| `√2` | 根号二 | 术语词典匹配 |
| `sin 30°` | 三十度的正弦值 | 角度+函数名组合 |
| `f(x) = 2x + 1` | f 关于 x 的函数 等于 二x 加一 | 符号→自然语言 |
| `∑(i=1,n)` | i 从一到n求和 | 数学结构识别 |
| `3.14` | 三点一四 | 数字模式 |
| `1/2` | 二分之一 | 分数模式 |

**古诗文朗读规则：**

| 规则 | 处理 | 示例 |
|------|------|------|
| 节奏停顿 | 按平仄和句式自动插入停顿 | "床前明月光" → 每字间 80ms，句末 600ms |
| 多音字消歧 | 基于上下文确定读音 | "低头思故乡" → "低 tóu"（非 tou） |
| 通假字标注 | 匹配通假字词典 | "说" 通 "悦" → 按 yuè 朗读 |
| 背景说明分离 | 题解/注释/赏析与正文分离 | 正文用标准音色，注释用解说音色 |
| 朗诵风格 | 语速放慢 0.85x，适当拖音 | `speech_rate: 0.85` |

**英语对话朗读规则：**

| 规则 | 处理 |
|------|------|
| 角色识别 | 从 "Tom:" / "—What's your name?" 模式提取角色 |
| 多音色分配 | 男性角色→male voice，女性角色→female voice，旁白→narrator voice |
| 连读/弱读 | 保持 TTS 引擎自然连读，不强制插入停顿 |
| 重音标注 | 关键词加 `<emphasis>` 标签 |
| 中英混排 | 中文部分用中文 TTS，英文部分用英文 TTS，拼接 |

#### 4.1.4 多音字消歧策略

```python
class PolyphoneDisambiguator:
    """多音字消歧引擎"""
    
    POLYPHONE_DICT = {
        "行": {
            "xíng": ["行走", "行为", "不行", "行人", "行驶"],
            "háng": ["银行", "行列", "行业", "行家", "内行"],
            "xìng": ["品行", "德行"],
            "hàng": ["树行子"]
        },
        "长": {
            "cháng": ["长江", "长短", "长久", "长假", "长城"],
            "zhǎng": ["长大", "成长", "班长", "校长", "长辈"]
        },
        # ... 完整多音字词典约 1200 条
    }
    
    def disambiguate(self, text: str, context: str = "") -> list[PhoneAnnotation]:
        """
        对文本中的多音字进行消歧标注
        
        Args:
            text: 待处理文本
            context: 前后文（段落级）
        
        Returns:
            多音字标注列表 [{char, position, pronunciation, confidence}]
        """
        annotations = []
        
        for char, readings in self.POLYPHONE_DICT.items():
            start = 0
            while True:
                pos = text.find(char, start)
                if pos == -1:
                    break
                
                # 策略1: 词组匹配（优先级最高）
                pronunciation = self._match_by_word(text, pos, char, readings)
                
                # 策略2: 上下文统计模型
                if pronunciation is None:
                    pronunciation = self._match_by_context(text, pos, char, readings, context)
                
                # 策略3: 默认读音（最常用读音）
                if pronunciation is None:
                    pronunciation = list(readings.keys())[0]
                
                annotations.append(PhoneAnnotation(
                    char=char,
                    position=pos,
                    pronunciation=pronunciation,
                    confidence=self._calc_confidence(text, pos, char, pronunciation)
                ))
                start = pos + 1
        
        return annotations
```

```python
class NarrationBatchScheduler:
    """异步批量合成调度器"""
    
    MAX_CONCURRENT_JOBS = 20          # 最大并行任务数
    MAX_RETRY = 3                      # 最大重试次数
    BATCH_SEGMENT_SIZE = 50            # 单批次最大分段数
    JOB_TIMEOUT_SECONDS = 1800         # 单任务超时 30 分钟
    
    async def submit_job(
        self,
        source_type: str,
        source_id: str,
        triggered_by: str = "MANUAL",
        priority: int = 0
    ) -> str:
        """提交有声化任务"""
        
        # 1. 幂等检查：同一来源是否有进行中的任务
        existing = await self.job_repo.find_active_by_source(source_type, source_id)
        if existing:
            return existing.id  # 幂等返回
        
        # 2. 获取源内容快照
        content = await self.content_service.get_content(source_type, source_id)
        if not content or not content.text_content.strip():
            raise ContentEmptyError(f"Source {source_type}:{source_id} has no text content")
        
        # 3. 创建音频资产（PENDING 状态）
        asset = AudioAsset(
            id=str(uuid4()),
            source_type=source_type,
            source_id=source_id,
            source_version=content.version,
            title=content.title,
            status="PENDING",
            tts_provider=self._select_provider(content),
            quality_tier=self._select_quality_tier(content),
        )
        await self.asset_repo.create(asset)
        
        # 4. 创建任务
        job = NarrationJob(
            id=str(uuid4()),
            audio_asset_id=asset.id,
            job_type="INITIAL",
            source_snapshot=content.to_snapshot(),
            status="PENDING",
            triggered_by=triggered_by,
        )
        await self.job_repo.create(job)
        
        # 5. 推入任务队列
        await self.task_queue.push(
            queue_name="narration_jobs",
            payload={"job_id": job.id, "asset_id": asset.id, "priority": priority},
            delay_seconds=0,
            priority=priority,
        )
        
        return job.id
    
    async def process_job(self, job_id: str):
        """工作线程执行单个有声化任务"""
        
        job = await self.job_repo.get(job_id)
        asset = await self.asset_repo.get(job.audio_asset_id)
        
        try:
            # 状态流转: PENDING → PROCESSING
            await self._update_job_status(job, "PROCESSING")
            await self._update_asset_status(asset, "PROCESSING")
            
            # Step 1: 文本预处理
            content_snapshot = ContentSnapshot.from_json(job.source_snapshot)
            processed = await self.text_processor.process(
                content_snapshot.text_content,
                subject=content_snapshot.subject,
                content_type=content_snapshot.content_type,
                grade_range=content_snapshot.grade_range,
            )
            await self._update_progress(job, 15)
            
            # Step 2: 朗读规则标注
            annotated_script = await self.rule_engine.annotate(processed, content_snapshot)
            await self._update_progress(job, 25)
            
            # Step 3: 多音色编排
            final_script = await self.voice_assigner.assign_roles(annotated_script, content_snapshot.subject)
            await self._update_progress(job, 30)
            
            # Step 4: 分段批量 TTS 合成
            audio_segments = await self._batch_synthesize(final_script, asset)
            await self._update_progress(job, 70)
            
            # Step 5: 音频后处理（拼接、音量均衡）
            final_audio_url, total_duration = await self._post_process(audio_segments, asset)
            await self._update_progress(job, 85)
            
            # Step 6: 质量评估
            quality_score = await self.quality_evaluator.evaluate(final_audio_url, final_script)
            await self._update_progress(job, 90)
            
            # Step 7: 持久化分段信息
            await self._save_segments(asset.id, audio_segments, total_duration)
            await self._update_progress(job, 95)
            
            # Step 8: 更新资产状态
            asset.storage_url = final_audio_url
            asset.total_duration_ms = total_duration
            asset.segment_count = len(audio_segments)
            asset.quality_score = quality_score
            asset.status = "READY"
            asset.ready_at = datetime.utcnow()
            await self.asset_repo.update(asset)
            
            # 状态流转: PROCESSING → SUCCESS
            await self._update_job_status(job, "SUCCESS")
            await self._update_progress(job, 100)
            
            # 发布事件
            await self.event_bus.publish(AudioAssetReadyEvent(
                asset_id=asset.id,
                source_type=asset.source_type,
                source_id=asset.source_id,
            ))
            
        except Exception as e:
            logger.exception(f"Narration job {job_id} failed")
            job.retry_count += 1
            
            if job.retry_count <= self.MAX_RETRY:
                # 指数退避重试
                delay = 2 ** job.retry_count * 30  # 60s, 120s, 240s
                await self._update_job_status(job, "PENDING")
                await self.task_queue.push(
                    queue_name="narration_jobs",
                    payload={"job_id": job.id, "asset_id": asset.id},
                    delay_seconds=delay,
                )
            else:
                await self._update_job_status(job, "FAILED", error=str(e))
                await self._update_asset_status(asset, "FAILED")
    
    async def _batch_synthesize(self, script: NarrationScript, asset: AudioAsset) -> list[AudioSegmentResult]:
        """分批次调用 TTS 服务"""
        
        results = []
        segments = script.segments
        
        # 分批处理，避免单次请求过大
        for batch_start in range(0, len(segments), self.BATCH_SEGMENT_SIZE):
            batch = segments[batch_start:batch_start + self.BATCH_SEGMENT_SIZE]
            
            # 并发调用 TTS（每批内并发，批次间串行）
            tasks = [
                self.tts_service.synthesize(
                    text=seg.ssml,
                    voice_profile=seg.voice_role,
                    audio_format=asset.audio_format,
                    sample_rate=asset.sample_rate,
                    bitrate=asset.bitrate,
                    provider=asset.tts_provider,
                )
                for seg in batch
            ]
            batch_results = await asyncio.gather(*tasks, return_exceptions=True)
            
            for i, result in enumerate(batch_results):
                if isinstance(result, Exception):
                    # 单段失败：用静音占位，不阻断整体流程
                    logger.warning(f"Segment {batch_start + i} TTS failed: {result}")
                    results.append(AudioSegmentResult(
                        segment_index=batch_start + i,
                        audio_data=SILENCE_1S_DATA,
                        duration_ms=1000,
                        success=False,
                        error=str(result),
                    ))
                else:
                    results.append(AudioSegmentResult(
                        segment_index=batch_start + i,
                        audio_data=result.audio_data,
                        duration_ms=result.duration_ms,
                        success=True,
                    ))
            
            # 批次间进度上报
            batch_progress = 30 + int(40 * (batch_start + len(batch)) / len(segments))
            await self._update_progress_by_id(
                asset.id, batch_progress
            )
        
        return results
```

### 4.4 音频后处理引擎

```python
class AudioPostProcessor:
    """音频后处理：拼接、音量均衡、降噪、分段"""
    
    TARGET_LUFS = -16.0  # 目标响度 (LUFS，参考播客标准)
    SILENCE_THRESHOLD_DB = -60.0
    SECTION_GAP_MS = 800  # 分段间静音时长
    
    async def process(
        self,
        segment_results: list[AudioSegmentResult],
        asset: AudioAsset,
    ) -> tuple[str, int]:
        """
        将分段音频处理为最终音频文件
        
        Returns:
            (cdn_url, total_duration_ms)
        """
        # 1. 将所有分段音频加载为 Pydub AudioSegment
        audio_segments = []
        for result in segment_results:
            seg = AudioSegment.from_file(io.BytesIO(result.audio_data), format=asset.audio_format)
            
            # 2. 单段音量标准化
            seg = self._normalize_loudness(seg)
            
            # 3. 首尾静音裁剪
            seg = self._trim_silence(seg)
            
            audio_segments.append(seg)
        
        # 4. 按分段间静音拼接
        gap = AudioSegment.silent(duration=self.SECTION_GAP_MS)
        
        if len(audio_segments) == 1:
            final = audio_segments[0]
        else:
            final = audio_segments[0]
            for seg in audio_segments[1:]:
                final = final + gap + seg
        
        total_duration_ms = len(final)
        
        # 5. 全局音量均衡
        final = self._normalize_loudness(final)
        
        # 6. 导出为最终格式
        buffer = io.BytesIO()
        final.export(
            buffer,
            format=asset.audio_format,
            bitrate=f"{asset.bitrate // 1000}k",
        )
        buffer.seek(0)
        
        # 7. 上传到对象存储
        storage_path = f"audio/narration/{asset.source_type}/{asset.source_id}/v{asset.source_version}.{asset.audio_format}"
        cdn_url = await self.storage.upload_and_get_cdn_url(
            path=storage_path,
            data=buffer.read(),
            content_type=f"audio/{asset.audio_format}",
            cache_control="public, max-age=31536000, immutable",  # 内容不变，永久缓存
        )
        
        return cdn_url, total_duration_ms
    
    def _normalize_loudness(self, segment: AudioSegment) -> AudioSegment:
        """响度标准化到目标 LUFS"""
        current_lufs = self._measure_lufs(segment)
        if current_lufs is not None:
            adjustment_db = self.TARGET_LUFS - current_lufs
            segment = segment.apply_gain(adjustment_db)
        return segment
    
    def _trim_silence(self, segment: AudioSegment, margin_ms: int = 100) -> AudioSegment:
        """裁剪首尾静音，保留 margin_ms 的余量"""
        start_trim = 0
        silence_chunks = pydub.silence.detect_nonsilent(
            segment, silence_thresh=self.SILENCE_THRESHOLD_DB, min_silence_len=200
        )
        if silence_chunks:
            start_trim = max(0, silence_chunks[0][0] - margin_ms)
            end_trim = min(len(segment), silence_chunks[-1][1] + margin_ms)
            return segment[start_trim:end_trim]
        return segment
```

### 4.6 质量评估引擎

```python
class NarrationQualityEvaluator:
    """合成音频质量自动评估"""
    
    MIN_SCORE = 0.70  # 低于此分数触发告警
    
    async def evaluate(
        self, 
        audio_url: str, 
        script: NarrationScript
    ) -> float:
        """
        评估音频质量，返回 0.00~1.00 综合分
        
        评估维度:
        1. 技术质量 (40%): 信噪比、响度一致性、无截断
        2. 时长合理性 (20%): 各段实际时长 vs 预估时长偏差
        3. 内容完整性 (25%): 分段数与脚本一致、无缺失
        4. 合成成功率 (15%): 静音占位段比例
        """
        
        # 下载音频样本
        audio_data = await self._download_sample(audio_url)
        
        # 1. 技术质量评分
        tech_score = self._eval_technical_quality(audio_data)
        
        # 2. 时长合理性评分
        duration_score = self._eval_duration(audio_data, script)
        
        # 3. 内容完整性评分
        completeness_score = self._eval_completeness(audio_data, script)
        
        # 4. 合成成功率评分
        success_rate_score = self._eval_success_rate(script)
        
        # 加权综合
        total = (
            tech_score * 0.40 +
            duration_score * 0.20 +
            completeness_score * 0.25 +
            success_rate_score * 0.15
        )
        
        # 质量告警
        if total < self.MIN_SCORE:
            await self.alert_service.send(
                level="WARNING",
                title=f"有声化质量低: {script.content_meta.title}",
                message=f"综合评分 {total:.2f}, 技术={tech_score:.2f}, "
                       f"时长={duration_score:.2f}, 完整性={completeness_score:.2f}, "
                       f"成功率={success_rate_score:.2f}",
            )
        
        return round(total, 2)
    
    def _eval_technical_quality(self, audio_data: bytes) -> float:
        """评估音频技术质量"""
        scores = []
        
        # SNR 估算
        snr = self._estimate_snr(audio_data)
        scores.append(min(1.0, snr / 40.0))  # 40dB 以上满分
        
        # 响度一致性
        lufs = self._measure_lufs(audio_data)
        lufs_deviation = abs(lufs - (-16.0))
        scores.append(max(0, 1.0 - lufs_deviation / 6.0))  # 偏差 6dB 以上为 0 分
        
        # 无截断检测（末尾是否有正常衰减）
        ending_ok = self._check_natural_ending(audio_data)
        scores.append(1.0 if ending_ok else 0.5)
        
        return sum(scores) / len(scores)
```

### 6.1 文本预处理器

```python
"""
教育内容文本预处理器
将原始 Markdown / 富文本转换为结构化的朗读脚本
"""

import re
from dataclasses import dataclass, field
from typing import Optional
from enum import Enum


class ContentType(Enum):
    PROSE = "prose"           # 散文/叙述文
    POETRY = "poetry"         # 诗歌/古诗文
    FORMULA = "formula"       # 数学/物理公式
    DIALOGUE = "dialogue"     # 对话
    LIST = "list"             # 列表/枚举
    NARRATION = "narration"   # 一般叙述


@dataclass
class ProcessedSegment:
    text: str
    content_type: ContentType
    segment_index: int
    metadata: dict = field(default_factory=dict)


@dataclass  
class ProcessedContent:
    title: str
    segments: list[ProcessedSegment]
    detected_types: set[ContentType]
    language: str = "zh-CN"


class EducationTextProcessor:
    """教育内容文本预处理器"""
    
    # 数学公式检测正则（LaTeX 行内/行间公式、Unicode 数学符号）
    MATH_PATTERNS = [
        r'\$\$.+?\$\$',                    # $$ ... $$
        r'\$.+?\$',                        # $ ... $
        r'\\\[.+?\\\]',                    # \[ ... \]
        r'\\\(.+?\\\)',                    # \( ... \)
        r'[∑∏∫√≤≥≠≈±×÷∞α-ωΑ-Ω]',         # Unicode 数学符号
    ]
    
    # 古诗文检测特征
    POETRY_PATTERNS = [
        r'[\u4e00-\u9fff]{5,7}[，。！？]',  # 五言/七言
        r'[^\n]{4,8}[，。]',                # 四字/八字短句
    ]
    
    # 对话检测特征
    DIALOGUE_PATTERNS = [
        r'^([A-Za-z\u4e00-\u9fa5]{1,8})[：:]\s',  # "角色名："
        r'^[""].+?[""]\s*[，。]',                    # 中文引号对话
        r'[""].+?[""]',                              # 引号内容
    ]
    
    def process(self, raw_text: str, subject: str, grade_range: str) -> ProcessedContent:
        """
        主处理入口
        
        Args:
            raw_text: 原始文本（可能包含 Markdown、HTML、LaTeX）
            subject: 学科
            grade_range: 学段
        """
        # Step 1: 格式归一化
        normalized = self._normalize_format(raw_text)
        
        # Step 2: 按结构分段
        raw_segments = self._split_sections(normalized)
        
        # Step 3: 每段识别内容类型
        processed = []
        detected_types = set()
        
        for i, seg_text in enumerate(raw_segments):
            seg_text = seg_text.strip()
            if not seg_text:
                continue
            
            ct = self._detect_content_type(seg_text, subject)
            detected_types.add(ct)
            
            processed.append(ProcessedSegment(
                text=seg_text,
                content_type=ct,
                segment_index=len(processed),
                metadata={
                    "subject": subject,
                    "grade_range": grade_range,
                    "char_count": len(seg_text),
                }
            ))
        
        # Step 4: 细分超长段（单段 > 500 字的叙述段拆分）
        processed = self._split_long_segments(processed, max_chars=500)
        
        # Step 5: 重新编号
        for i, seg in enumerate(processed):
            seg.segment_index = i
        
        return ProcessedContent(
            title=self._extract_title(raw_text) or "未命名内容",
            segments=processed,
            detected_types=detected_types,
        )
    
    def _normalize_format(self, text: str) -> str:
        """格式归一化：去除 Markdown/HTML 标签，保留结构标记"""
        # 去除 HTML 标签但保留内容
        text = re.sub(r'<img[^>]*alt="([^"]*)"[^>]*>', r'[图片：\1]', text)
        text = re.sub(r'<[^>]+>', '', text)
        
        # Markdown 标题转换为结构标记
        text = re.sub(r'^#{1,6}\s+(.+)$', r'【\1】', text, flags=re.MULTILINE)
        
        # Markdown 加粗/斜体保留文字
        text = re.sub(r'\*\*(.+?)\*\*', r'\1', text)
        text = re.sub(r'\*(.+?)\*', r'\1', text)
        
        # Markdown 链接只保留文字
        text = re.sub(r'\[(.+?)\]\(.+?\)', r'\1', text)
        
        # 代码块标记（保留内容但标记为公式）
        text = re.sub(r'```(\w*)\n(.+?)\n```', r'\2', text, flags=re.DOTALL)
        
        # 多余空行压缩
        text = re.sub(r'\n{3,}', '\n\n', text)
        
        return text.strip()
    
    def _detect_content_type(self, text: str, subject: str) -> ContentType:
        """识别段落的内容类型"""
        # 检查公式
        for pattern in self.MATH_PATTERNS:
            if re.search(pattern, text):
                return ContentType.FORMULA
        
        # 检查对话
        for pattern in self.DIALOGUE_PATTERNS:
            if re.search(pattern, text, re.MULTILINE):
                return ContentType.DIALOGUE
        
        # 语文学科：检查古诗文
        if subject == "chinese":
            for pattern in self.POETRY_PATTERNS:
                matches = re.findall(pattern, text)
                if len(matches) >= 2:  # 至少两句才算诗文
                    # 进一步检查：行短且押韵
                    lines = [l.strip() for l in text.split('\n') if l.strip()]
                    avg_len = sum(len(l) for l in lines) / max(len(lines), 1)
                    if avg_len <= 10:
                        return ContentType.POETRY
        
        # 检查列表
        if re.match(r'^[\d一二三四五六七八九十]+[.、）)]\s', text, re.MULTILINE):
            return ContentType.LIST
        
        return ContentType.NARRATION
    
    def _split_long_segments(self, segments: list[ProcessedSegment], max_chars: int) -> list[ProcessedSegment]:
        """拆分超长段"""
        result = []
        for seg in segments:
            if len(seg.text) <= max_chars:
                result.append(seg)
            else:
                # 按句号/问号/感叹号拆分
                sentences = re.split(r'(?<=[。！？!?])\s*', seg.text)
                current = ""
                for sent in sentences:
                    if len(current) + len(sent) > max_chars and current:
                        result.append(ProcessedSegment(
                            text=current,
                            content_type=seg.content_type,
                            segment_index=0,  # 重新编号
                            metadata={**seg.metadata, "split_from": seg.segment_index}
                        ))
                        current = sent
                    else:
                        current += sent
                if current:
                    result.append(ProcessedSegment(
                        text=current,
                        content_type=seg.content_type,
                        segment_index=0,
                        metadata={**seg.metadata, "split_from": seg.segment_index}
                    ))
        return result
```

### 6.2 SSML 生成器

```python
"""
SSML (Speech Synthesis Markup Language) 生成器
将标注脚本转换为 TTS 供应商可执行的 SSML
"""

class SSMLGenerator:
    """SSML 生成器"""
    
    def generate(self, segment: ProcessedSegment, rule: NarrationRule) -> str:
        """生成 SSML"""
        text = segment.text
        
        # 根据内容类型应用不同的 SSML 策略
        if segment.content_type == ContentType.FORMULA:
            ssml = self._generate_formula_ssml(text, rule)
        elif segment.content_type == ContentType.POETRY:
            ssml = self._generate_poetry_ssml(text, rule)
        elif segment.content_type == ContentType.DIALOGUE:
            ssml = self._generate_dialogue_ssml(text, rule)
        else:
            ssml = self._generate_narration_ssml(text, rule)
        
        return ssml
    
    def _generate_formula_ssml(self, text: str, rule: NarrationRule) -> str:
        """公式 SSML 生成"""
        # 将数学表达式转换为朗读文本
        spoken = self._formula_to_spoken(text)
        
        return f'''<speak>
            <prosody rate="{rule.speech_rate * 0.9:.2f}">
                <say-as interpret-as="math-expression">{spoken}</say-as>
            </prosody>
        </speak>'''
    
    def _generate_poetry_ssml(self, text: str, rule: NarrationRule) -> str:
        """古诗文 SSML 生成"""
        lines = text.strip().split('\n')
        parts = []
        
        for line in lines:
            line = line.strip()
            if not line:
                continue
            # 每句之间加较长停顿
            parts.append(f'<prosody rate="{rule.speech_rate:.2f}">{line}</prosody>')
            parts.append(f'<break time="{rule.pause_config.get("line_pause", 500)}ms"/>')
        
        inner = ''.join(parts)
        return f'<speak>{inner}</speak>'
    
    def _generate_narration_ssml(self, text: str, rule: NarrationRule) -> str:
        """叙述文 SSML 生成"""
        # 按标点分句
        sentences = re.split(r'(?<=[。！？!?；;])', text)
        
        parts = []
        for sent in sentences:
            sent = sent.strip()
            if not sent:
                continue
            
            # 关键词强调
            sent = self._add_emphasis(sent)
            parts.append(sent)
            
            # 句间停顿
            parts.append(f'<break time="{rule.pause_config.get("sentence_pause", 300)}ms"/>')
        
        inner = ''.join(parts)
        
        return f'''<speak>
            <prosody rate="{rule.speech_rate:.2f}" pitch="{rule.pitch_adjustment:+d}">
                {inner}
            </prosody>
        </speak>'''
    
    def _formula_to_spoken(self, formula: str) -> str:
        """数学公式转朗读文本"""
        replacements = [
            (r'\^(\d+)', r'的\1次方'),           # x^2 → x的2次方
            (r'\^([a-zA-Z])', r'的\1次方'),       # x^n → x的n次方
            (r'sqrt\{([^}]+)\}', r'根号\1'),      # sqrt{x} → 根号x
            (r'\\frac\{([^}]+)\}\{([^}]+)\}', r'\1分之\2'),  # \frac{a}{b} → a分之b
            (r'\\sum', '求和'),
            (r'\\int', '积分'),
            (r'\\times', '乘以'),
            (r'\\div', '除以'),
            (r'\\pm', '正负'),
            (r'\\leq', '小于等于'),
            (r'\\geq', '大于等于'),
            (r'\\neq', '不等于'),
            (r'\\approx', '约等于'),
            (r'\\infty', '无穷'),
            (r'\\alpha', '阿尔法'),
            (r'\\beta', '贝塔'),
            (r'\\gamma', '伽马'),
            (r'\\theta', '西塔'),
            (r'\\pi', '派'),
            (r'°', '度'),
            (r'≤', '小于等于'),
            (r'≥', '大于等于'),
            (r'≠', '不等于'),
            (r'±', '正负'),
            (r'×', '乘以'),
            (r'÷', '除以'),
            (r'√', '根号'),
            (r'∞', '无穷'),
        ]
        
        result = formula
        for pattern, replacement in replacements:
            result = re.sub(pattern, replacement, result)
        
        return result
    
    def _add_emphasis(self, text: str) -> str:
        """对关键词加强调标签"""
        # 教育｜重点词标注词典（示意）
        emphasis_words = ["注意", "关键", "重要", "核心", "首先", "然后", "最后", "因此", "所以", "但是"]
        
        for word in emphasis_words:
            text = text.replace(word, f'<emphasis level="moderate">{word}</emphasis>')
        
        return text
```

```python
from abc import ABC, abstractmethod


class TTSProviderAdapter(ABC):

        ssml: str,

        audio_format: str,
        sample_rate: int,
        bitrate: int,
    ) -> "TTSResult":
        ...

    def supports_ssml(self) -> bool:
        ...
    
    @abstractmethod
    def max_text_length(self) -> int:
        ...


class AzureTTSAdapter(TTSProviderAdapter):
    """Azure Cognitive Services Speech 适配器"""
    
    def __init__(self, config: dict):
        self.subscription_key = config["subscription_key"]
        self.region = config["region"]
        self.endpoint = f"https://{self.region}.tts.speech.microsoft.com/cognitiveservices/v1"
    
    async def synthesize(self, ssml, voice_profile, audio_format, sample_rate, bitrate):
        import aiohttp
        
        headers = {
            "Ocp-Apim-Subscription-Key": self.subscription_key,
            "Content-Type": "application/ssml+xml",
            "X-Microsoft-OutputFormat": self._format_mapping(audio_format, sample_rate, bitrate),
        }
        
        async with aiohttp.ClientSession() as session:
            async with session.post(
                self.endpoint,
                headers=headers,
                data=ssml.encode("utf-8"),
                timeout=aiohttp.ClientTimeout(total=60),
            ) as resp:
                if resp.status != 200:
                    error_text = await resp.text()
                    raise TTSSynthesisError(f"Azure TTS failed: {resp.status} {error_text}")
                
                audio_data = await resp.read()
                # Azure 返回的音频中不含时长元数据，需要额外计算
                duration_ms = self._estimate_duration(audio_data, sample_rate)
                
                return TTSResult(
                    audio_data=audio_data,
                    duration_ms=duration_ms,
                    provider="azure",
                    voice=voice_profile,
                )
    
    def _format_mapping(self, fmt, sample_rate, bitrate):
        """Azure 输出格式映射"""
        if fmt == "mp3":
            return f"audio-{sample_rate // 1000}khz-{bitrate // 1000}kbitrate-mono-mp3"
        elif fmt == "opus":
            return f"ogg-{sample_rate // 1000}khz-{bitrate // 1000}kbitrate-mono-opus"
        return "audio-24khz-48kbitrate-mono-mp3"
    
    def supports_ssml(self) -> bool:
        return True
    
    def max_text_length(self) -> int:
        return 10000  # Azure 单次上限

                    voice=voice_profile,

                    duration_ms=result.duration_ms,
                )
                
                return result
                
            except Exception as e:
                logger.warning(f"TTS provider {provider} failed: {e}, trying next...")
```

```python
class ContentChangeHandler:
    """监听内容变更，自动触发有声化"""
    
    async def on_content_published(self, event: ContentPublishedEvent):
        """内容发布时自动创建音频"""
        
        # 判断内容是否需要有声化
        if not self._should_narrate(event.content_type, event.subject):
            return
        
        # 检查是否已有音频（内容可能是更新）
        existing = await self.asset_repo.find_latest_ready(
            event.source_type, event.source_id
        )
        
        if existing and existing.source_version >= event.version:

        # 提交有声化任务
        await self.narration_scheduler.submit_job(
            source_type=event.source_type,
            source_id=event.source_id,
            triggered_by="AUTO",
        )
    
    def _should_narrate(self, content_type: str, subject: str) -> bool:
        """判断内容是否需要有声化"""
        # 以下内容类型默认开启有声化
        auto_types = {
            "CHAPTER_TEXT",      # 章节正文
            "KNOWLEDGE_POINT",   # 知识点讲解
            "POETRY_TEXT",       # 诗文原文
            "ANCIENT_PROSE",     # 文言文
            "ENGLISH_TEXT",      # 英语课文
            "RECITATION",        # 背诵材料
        }
        return content_type in auto_types
```

```python
class NarrationEntitlementChecker:
    """有声化会员权益校验"""
    
    ENTITLEMENT_MAP = {
        "FREE": {
            "quality_tier": "standard",
            "max_concurrent_preview": 3,    # 每日试听次数
            "available_sources": ["CHAPTER_SUMMARY"],  # 仅章节摘要
            "enable_download": False,
        },
        "MONTHLY": {
            "quality_tier": "standard",
            "max_concurrent_preview": -1,   # 无限
            "available_sources": ["CHAPTER", "KNOWLEDGE_POINT", "QUESTION"],
            "enable_download": True,
        },
        "ANNUAL": {
            "quality_tier": "premium",      # 高保真音色
            "max_concurrent_preview": -1,
            "available_sources": "*",        # 全部
            "enable_download": True,
        },
    }
    
    def check_access(
        self, 
        user_tier: str, 
        source_type: str,
        requested_quality: str,
    ) -> AccessResult:
        entitlement = self.ENTITLEMENT_MAP.get(user_tier, self.ENTITLEMENT_MAP["FREE"])
        
        # 检查内容类型权限
        if entitlement["available_sources"] != "*":
            if source_type not in entitlement["available_sources"]:
                return AccessResult(allowed=False, reason="UPGRADE_REQUIRED")
        
        # 检查音质权限
        actual_quality = requested_quality
        if requested_quality == "premium" and entitlement["quality_tier"] != "premium":
            actual_quality = "standard"  # 降级到标准音质
        
        return AccessResult(
            allowed=True,
            quality_tier=actual_quality,
            enable_download=entitlement["enable_download"],
        )
```

## 8. 错误处理

### 8.1 异常分类

| 异常类型 | 错误码 | 说明 | 处理策略 |
|---------|--------|------|---------|
| `ContentNotFoundError` | NARR_001 | 源内容不存在 | 直接返回 404 |
| `ContentEmptyError` | NARR_002 | 源内容无文本 | 返回 422，提示补充内容 |
| `TTSSynthesisError` | NARR_010 | TTS 合成失败 | 自动重试 → 切换供应商 → 标记失败 |
| `TTSRateLimitError` | NARR_011 | TTS 供应商限流 | 降级到备用供应商，延迟重试 |
| `AudioProcessingError` | NARR_020 | 音频后处理失败 | 重试，不影响已合成分段 |
| `StorageUploadError` | NARR_030 | 对象存储上传失败 | 重试 3 次后标记失败 |
| `QualityCheckFailedError` | NARR_040 | 质量评分过低 | 触发告警，人工审核 |
| `ConcurrentJobLimitError` | NARR_050 | 并发任务超限 | 排队等待 |
| `SSMLGenerationError` | NARR_060 | SSML 生成异常 | 使用纯文本降级合成 |

### 8.2 降级策略

```
正常流程:
  文本预处理 → SSML 生成 → 多供应商 TTS → 音频后处理 → CDN 分发

降级链:
  1. SSML 不可用 → 降级为纯文本 TTS（讯飞等不支持 SSML 的供应商）
  2. 首选 TTS 供应商不可用 → 切换到备用供应商
  3. 所有 TTS 供应商不可用 → 标记任务 PENDING，延迟重试
  4. 音频后处理失败 → 跳过后处理，直接使用原始 TTS 输出
  5. CDN 上传失败 → 使用临时 URL，异步重传
  6. 质量评估失败 → 保留音频，标记质量分待评，触发人工审核
```

### 8.3 告警规则

| 告警条件 | 级别 | 通知方式 |
|---------|------|---------|
| 任务失败率 > 5%（5分钟窗口） | CRITICAL | 钉钉/飞书 + 邮件 |
| TTS 供应商连续 3 次失败 | WARNING | 钉钉/飞书 |
| 质量评分 < 0.70 | WARNING | 运营群通知 |
| 单任务执行 > 30 分钟 | WARNING | 日志记录 |
| 队列积压 > 100 任务 | WARNING | 钉钉/飞书 |

## 10. 安全考虑

### 10.1 音频内容安全

- TTS 合成内容仅来自平台审核通过的教育内容，不接受用户自定义文本合成（预览试听功能限 500 字以内）
- 合成音频不包含用户个人信息
- 音频文件 URL 使用签名鉴权，防止盗链

### 10.2 供应商数据安全

- 发送给 TTS 供应商的内容仅为教育内容文本，不含用户身份信息
- 与供应商签署数据处理协议（DPA），确保文本不被用于供应商模型训练

### 10.3 访问控制

- 有声化任务管理 API 仅限管理后台调用
- 音频资产查询 API 需用户鉴权 + 会员权益校验
- 朗读规则配置修改需管理员权限 + 操作审计日志
