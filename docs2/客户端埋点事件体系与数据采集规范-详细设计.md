# 客户端埋点事件体系与数据采集规范 - 详细设计

> 本文档规范 PrimeTop 客户端埋点事件的命名、参数结构、采集协议、SDK 架构与隐私合规策略，为客户端开发人员提供可直接编码的参考标准。

---

## 1. 设计目标与范围

### 1.1 设计目标

1. **统一规范**：建立全端（Android / iOS / Flutter / Web / 小程序）一致的事件命名与参数结构，消除多团队协作中的歧义。
2. **开发友好**：提供强类型的事件定义与自动补全支持，降低遗漏和拼写错误风险。
3. **高性能采集**：事件采集不得阻塞 UI 线程，不得显著影响应用性能（CPU 增量 < 1%，内存增量 < 5MB）。
4. **隐私合规**：严格遵守《个人信息保护法》和 COPPA 要求，未成年人数据需脱敏/最小化采集。
5. **可靠投递**：支持离线缓冲、断点续传、幂等去重，确保事件丢失率 < 0.1%。

### 1.2 适用范围

| 范围 | 说明 |
|------|------|
| 客户端埋点 SDK | Flutter 层 + 原生平台通道 |
| 事件定义 | 页面、点击、曝光、业务、性能五大类 |
| 数据上报 | HTTP/HTTPS 批量上报协议 |
| 调试工具 | 开发期实时事件查看与校验 |
| 不含 | 服务端日志采集（见"客户端日志采集与远程诊断系统"）、服务端指标聚合（见"学习数据实时聚合与统计预计算引擎"） |

## 2. 事件分类与命名规范

### 2.1 事件分类体系

```
事件 (Event)
├── 页面事件 (Page Event)        — 页面生命周期：进入、离开、停留
├── 点击事件 (Click Event)       — 用户主动操作：按钮、链接、Tab
├── 曝光事件 (Exposure Event)    — 内容展示：卡片、模块、推荐位
├── 业务事件 (Business Event)    — 核心业务流程：答题、辅导、购买
└── 性能事件 (Performance Event) — 技术质量：加载、渲染、崩溃
```

### 2.2 事件命名规范

#### 2.2.1 命名格式

```
{分类前缀}_{模块}_{动作}_{对象}

示例：
page_home_enter           — 页面事件：首页_进入
click_ai_send             — 点击事件：AI模块_发送
expose_recommend_card     — 曝光事件：推荐_卡片
biz_question_answer       — 业务事件：题目_答题
perf_page_load            — 性能事件：页面_加载
```

#### 2.2.2 分类前缀

| 前缀 | 分类 | 说明 |
|------|------|------|
| `page_` | 页面事件 | 页面进入/离开/停留 |
| `click_` | 点击事件 | 用户点击 UI 元素 |
| `expose_` | 曝光事件 | 内容在可视区域展示 |
| `biz_` | 业务事件 | 核心业务流程节点 |

### 2.3 参数命名规范

#### 2.3.1 通用参数（所有事件自动附带）

```typescript
interface CommonParams {
  // ---- 设备信息 ----
  device_id: string;           // 设备唯一标识（非IMEI，使用随机UUID+持久化）
  device_model: string;        // 设备型号，如 "iPhone 15 Pro"
  os: string;                  // 操作系统，如 "iOS 17.4"
  platform: string;            // 平台：android | ios | web | mini_app
  app_version: string;         // APP 版本号，如 "1.2.0"
  app_build: string;           // 构建号，如 "2026052601"
  screen_width: number;        // 屏幕宽度（逻辑像素）
  screen_height: number;       // 屏幕高度（逻辑像素）
  network_type: string;        // 网络类型：wifi | 4g | 5g | 3g | 2g | unknown | offline
  
  // ---- 用户信息 ----
  user_id: string;             // 用户ID（匿名为空）
  session_id: string;          // 会话ID（APP启动到退入后台 >30min 为新会话）
  is_anonymous: boolean;       // 是否匿名用户
  
  // ---- 时间信息 ----
  client_ts: number;           // 客户端时间戳（毫秒）
  client_tz: string;           // 时区，如 "Asia/Shanghai"
  
  // ---- 环境信息 ----
  env: string;                 // 环境：dev | staging | production
  channel: string;             // 渠道：app_store | huawei | xiaomi | official
  flutter_mode: string;        // Flutter 运行模式：debug | profile | release
}
```

#### 2.3.2 参数命名规则

```
1. 全小写 + 下划线分隔（snake_case）
2. 布尔值以 is_ / has_ / can_ / should_ 开头
3. 数值型使用明确单位后缀：_ms（毫秒）、_sec（秒）、_px（像素）、_cnt（数量）
4. ID 类型以 _id 结尾
5. 枚举值使用全小写字符串，不用数字编码
6. 禁止使用含糊名称：用 item_id 而非 id，用 duration_ms 而非 time
```

### 4.2 核心类设计

```dart
/// 事件追踪器主入口
class PrimeTracker {
  static PrimeTracker? _instance;
  static PrimeTracker get instance => _instance ??= PrimeTracker._();
  
  late final EventBuilder _eventBuilder;
  late final PrivacyFilter _privacyFilter;
  late final EventQueue _eventQueue;
  late final UploadManager _uploadManager;
  late final AutoTracker _autoTracker;
  
  PrimeTracker._() {
    _eventBuilder = EventBuilder();
    _privacyFilter = PrivacyFilter();
    _eventQueue = EventQueue(maxMemorySize: 500, persistPath: _persistPath());
    _uploadManager = UploadManager(
      endpoint: '${Env.trackingEndpoint}/api/v1/events/batch',
      batchSize: 50,
      flushInterval: Duration(seconds: 30),
    );
    _autoTracker = AutoTracker(this);
  }
  
  /// 初始化（APP启动时调用一次）
  Future<void> init(TrackerConfig config) async {
    await _eventQueue.init();
    _uploadManager.configure(config);
    _autoTracker.start();
  }
  
  /// 追踪事件（核心方法）
  void track(String eventName, {Map<String, dynamic>? params}) {
    final event = _eventBuilder.build(eventName, params ?? {});
    
    // 隐私过滤
    final filtered = _privacyFilter.filter(event);
    if (filtered == null) return; // 被过滤掉
    
    // 校验
    final validation = EventValidator.validate(filtered);
    if (!validation.isValid) {
      _debugLog('Event validation failed: ${validation.errors}');
      if (kDebugMode) {
        throw TrackerValidationError(validation.errors);
      }
      return; // 线上静默丢弃
    }
    
    // 入队
    _eventQueue.enqueue(filtered);
  }
  
  /// 强制刷新（关键事件后调用）
  void flush() {
    _uploadManager.flush();
  }
  
  /// 设置用户属性
  void setUserProperty(String key, dynamic value) {
    _eventBuilder.setUserProperty(key, value);
  }
  
  /// 用户登入
  void login(String userId) {
    _eventBuilder.setUserId(userId);
    track('biz_login_success', params: {'method': 'normal'});
  }
  
  /// 用户登出
  void logout() {
    track('biz_logout');
    _eventBuilder.clearUserId();
  }
}
```

### 4.4 EventQueue — 事件队列

```dart
class EventQueue {
  final int maxMemorySize;
  final String persistPath;
  
  final List<TrackEvent> _memoryQueue = [];
  late SharedPreferences _prefs;
  
  EventQueue({required this.maxMemorySize, required this.persistPath});
  
  Future<void> init() async {
    _prefs = await SharedPreferences.getInstance();
    // 恢复上次未发送的持久化事件
    await _restorePersistedEvents();
  }
  
  void enqueue(TrackEvent event) {
    _memoryQueue.add(event);
    
    // 超出内存限制，触发即时发送
    if (_memoryQueue.length >= maxMemorySize) {
      UploadManager.instance.flush();
    }
    
    // 定期持久化（每 10 个事件或每 30 秒）
    if (_memoryQueue.length % 10 == 0) {
      _persist();
    }
  }
  
  /// 取出一批事件（发送后从队列移除）
  List<TrackEvent> dequeueBatch(int batchSize) {
    final batch = _memoryQueue.take(batchSize).toList();
    _memoryQueue.removeRange(0, batch.length);
    _persist(); // 更新持久化
    return batch;
  }
  
  /// 持久化到本地（JSON 文件）
  Future<void> _persist() async {
    final json = jsonEncode(_memoryQueue.map((e) => e.toJson()).toList());
    await _prefs.setString('tracking_queue', json);
  }
  
  /// 恢复持久化事件
  Future<void> _restorePersistedEvents() async {
    final json = _prefs.getString('tracking_queue');
    if (json != null) {
      final list = jsonDecode(json) as List;
      for (final item in list) {
        _memoryQueue.add(TrackEvent.fromJson(item));
      }
      // 上次遗留的事件标记为回放
      for (var event in _memoryQueue) {
        event.isReplay = true;
      }
    }
  }
}
```

### 4.5 UploadManager — 上传管理器

```dart
class UploadManager {
  final String endpoint;
  final int batchSize;
  final Duration flushInterval;
  
  Timer? _flushTimer;
  final HttpClient _httpClient = HttpClient();
  
  static const _maxRetries = 3;
  static const _retryDelays = [2000, 5000, 15000]; // 毫秒
  
  void configure(TrackerConfig config) {
    // 启动定时刷新
    _flushTimer?.cancel();
    _flushTimer = Timer.periodic(flushInterval, (_) => flush());
  }
  
  Future<void> flush() async {
    final queue = PrimeTracker.instance._eventQueue;
    if (queue._memoryQueue.isEmpty) return;
    
    final batch = queue.dequeueBatch(batchSize);
    if (batch.isEmpty) return;
    
    await _sendWithRetry(batch);
  }
  
  Future<void> _sendWithRetry(List<TrackEvent> events) async {
    for (var attempt = 0; attempt < _maxRetries; attempt++) {
      try {
        await _sendBatch(events);
        return; // 成功
      } catch (e) {
        if (attempt == _maxRetries - 1) {
          // 最终失败，重新入队等待下次发送
          PrimeTracker.instance._eventQueue._memoryQueue.addAll(events);
          _debugLog('Event upload failed after $_maxRetries retries: $e');
          return;
        }
        await Future.delayed(Duration(milliseconds: _retryDelays[attempt]));
      }
    }
  }
  
  Future<void> _sendBatch(List<TrackEvent> events) async {
    final payload = _buildPayload(events);
    final compressed = gzip.encode(utf8.encode(jsonEncode(payload)));
    
    final request = await _httpClient.postUrl(Uri.parse(endpoint));
    request.headers.set('Content-Encoding', 'gzip');
    request.headers.set('Content-Type', 'application/json');
    request.headers.set('X-Device-Id', payload['device_id']);
    request.headers.set('X-SDK-Version', '1.0.0');
    request.add(compressed);
    
    final response = await request.close();
    if (response.statusCode != 200 && response.statusCode != 202) {
      throw UploadException('Server returned ${response.statusCode}');
    }
  }
  
  Map<String, dynamic> _buildPayload(List<TrackEvent> events) {
    return {
      'sdk_version': '1.0.0',
      'device_id': events.first.common.deviceId,
      'batch_id': '${DateTime.now().millisecondsSinceEpoch}_${Random().nextInt(10000)}',
      'event_count': events.length,
      'events': events.map((e) => e.toJson()).toList(),
    };
  }
}
```

```dart
class PrivacyFilter {
  /// 需要脱敏的字段名模式
  static const _sensitivePatterns = [
    'phone', 'email', 'real_name', 'id_card', 'address',
    'password', 'token', 'ip', 'imei', 'mac',
  ];
  
  /// 禁止采集的字段（直接移除）
  static const _forbiddenFields = [
    'idfa', 'idfv', 'imei', 'meid', 'mac_address',
    'sim_serial', 'android_id', 'ssid', 'bssid',
    'contact_list', 'location_exact',
  ];
  
  TrackEvent? filter(TrackEvent event) {
    final props = Map<String, dynamic>.from(event.eventProperties);
    
    // 1. 移除禁止字段
    for (final field in _forbiddenFields) {
      props.remove(field);
    }
    
    // 2. 脱敏敏感字段
    for (final entry in props.entries.toList()) {
      for (final pattern in _sensitivePatterns) {
        if (entry.key.contains(pattern)) {
          props[entry.key] = _maskValue(entry.value);
        }
      }
    }
    
    // 3. 检查用户是否授权数据采集
    if (!_hasConsent()) {
      // 未授权时只保留性能事件
      if (!event.eventName.startsWith('perf_')) {
        return null;
      }
    }
    
    // 4. 未成年人额外脱敏
    if (_isMinor()) {
      props.removeWhere((key, value) => 
          key.contains('nickname') || key.contains('avatar'));
    }
    
    return event.copyWith(eventProperties: props);
  }
  
  String _maskValue(dynamic value) {
    final str = value.toString();
    if (str.length <= 4) return '****';
    return '${str.substring(0, 2)}****${str.substring(str.length - 2)}';
  }
}
```

## 6. 曝光采集机制

### 6.1 曝光判定算法

```dart
class ExposureDetector {
  final Map<String, bool> _exposedItems = {}; // key: "{page}_{itemId}" 
  final Map<String, int> _visibleStartTimes = {}; // key -> 可见开始时间
  
  static const _minVisibleMs = 500; // 最短可见时长
  static const _minVisibleRatio = 0.5; // 最小可见比例
  
  /// 检查元素曝光状态（绑定到滚动/布局回调）
  void checkExposure({
    required String pageName,
    required String itemId,
    required double visibleRatio,
    required VoidCallback onExposed,
  }) {
    final key = '${pageName}_$itemId';
    final now = DateTime.now().millisecondsSinceEpoch;
    
    if (visibleRatio >= _minVisibleRatio) {
      if (!_exposedItems.containsKey(key)) {
        if (!_visibleStartTimes.containsKey(key)) {
          _visibleStartTimes[key] = now;
        } else if (now - _visibleStartTimes[key]! >= _minVisibleMs) {
          _exposedItems[key] = true;
          _visibleStartTimes.remove(key);
          onExposed();
        }
      }
    } else {
      _visibleStartTimes.remove(key); // 不可见则重置计时
    }
  }
  
  /// 页面离开时重置
  void onPageLeave(String pageName) {
    _exposedItems.removeWhere((key, _) => key.startsWith('${pageName}_'));
    _visibleStartTimes.removeWhere((key, _) => key.startsWith('${pageName}_'));
  }
}
```

### 7.1 EventValidator

```dart
class EventValidator {
  static ValidationResult validate(TrackEvent event) {
    final errors = <String>[];
    
    // 1. 事件名格式校验
    if (!RegExp(r'^[a-z]+_[a-z]+(_[a-z]+)*$').hasMatch(event.eventName)) {
      errors.add('Invalid event name format: ${event.eventName}');
    }
    
    // 2. 事件名长度
    if (event.eventName.length > 64) {
      errors.add('Event name too long: ${event.eventName.length} > 64');
    }
    
    // 3. 参数 key 格式校验
    for (final key in event.eventProperties.keys) {
      if (!RegExp(r'^[a-z][a-z0-9_]*$').hasMatch(key)) {
        errors.add('Invalid param key: $key');
      }
    }
    
    // 4. 参数数量限制
    if (event.eventProperties.length > 50) {
      errors.add('Too many params: ${event.eventProperties.length} > 50');
    }
    
    // 5. 参数值长度限制
    for (final entry in event.eventProperties.entries) {
      if (entry.value is String && (entry.value as String).length > 1024) {
        errors.add('Param value too long: ${entry.key}');
      }
    }
    
    // 6. 已知事件参数 schema 校验
    final schema = EventSchemaRegistry.getSchema(event.eventName);
    if (schema != null) {
      errors.addAll(schema.validate(event.eventProperties));
    }
    
    return ValidationResult(isValid: errors.isEmpty, errors: errors);
  }
}

class ValidationResult {
  final bool isValid;
  final List<String> errors;
  ValidationResult({required this.isValid, required this.errors});
}
```

```dart
class SessionManager {
  String? _sessionId;
  DateTime? _sessionStart;
  DateTime? _backgroundTime;
  int _interactionCount = 0;
  
  static const _sessionTimeout = Duration(minutes: 30);
  
  String get currentSessionId => _sessionId ?? _newSession();
  
  String _newSession() {
    _sessionId = 's_${DateTime.now().millisecondsSinceEpoch}_${Random().nextInt(10000)}';
    _sessionStart = DateTime.now();
    _interactionCount = 0;
    return _sessionId!;
  }
  
  void onForeground() {
    if (_backgroundTime != null) {
      final elapsed = DateTime.now().difference(_backgroundTime!);
      if (elapsed > _sessionTimeout) {
        // 超时，结束旧会话
        _endSession();
        _newSession();
      }
      _backgroundTime = null;
    }
  }
  
  void onBackground() {
    _backgroundTime = DateTime.now();
  }
  
  void onInteraction() {
    _interactionCount++;
  }
  
  void _endSession() {
    if (_sessionStart != null) {
      final duration = DateTime.now().difference(_sessionStart!);
      PrimeTracker.instance.track('biz_study_session', params: {
        'session_id': _sessionId,
        'duration_ms': duration.inMilliseconds,
        'interaction_cnt': _interactionCount,
        'completion_status': 'idle_timeout',
      });
    }
  }
}
```

## 10. 特殊场景处理

### 10.1 弱网与离线

| 场景 | 处理策略 |
|------|----------|
| 网络不可用 | 事件入内存队列，持久化到本地存储 |
| 网络恢复 | 自动触发批量发送，先发离线积压事件 |
| 离线积压 > 1000 条 | 按时间倒序保留最近 1000 条，丢弃更早事件并记录丢弃数量 |
| 长期离线（> 7天） | 丢弃超过 7 天的事件（标记 `is_replay=true` 的优先丢弃） |

### 10.2 用户注销/删除账号

```
biz_account_delete → 触发后：
  1. 立即 flush 所有待发送事件
  2. 清除本地缓存的 user_id、user_properties
  3. 后续事件以匿名身份采集
  4. 服务端收到删除信号后标记该用户所有历史事件进入删除队列
```

```dart
  final consent = await showConsentDialog(
    title: '数据使用授权',
    message: '我们希望收集匿名使用数据来改善产品体验...',
    options: [
      ConsentOption('允许', TrackingConsent.granted),
      ConsentOption('仅分析', TrackingConsent.analytics),
      ConsentOption('拒绝', TrackingConsent.denied),
    ],
  );
  await ConsentStorage.save(consent);
  PrimeTracker.instance.updateConsent(consent);
}
```

## 14. 附录

### 14.1 事件 ID 生成规则

```
event_id = {device_id_prefix_8}_{timestamp_us}_{random_hex_6}

示例：a1b2c3d4_1716748800123456_abc123

特性：
- 全局唯一（device_id + 微秒时间戳 + 随机数）
- 时间有序（时间戳在中间）
- 可溯源（包含设备标识前缀）
- 幂等（相同事件不会重复生成）
```

### 14.2 数据生命周期

```
客户端产生 → 内存队列 → 持久化 → Gzip 压缩 → HTTPS 上报
    ↓                                    ↓
  Debug查看                         服务端接收
                                       ↓
                               Kafka 分发 → 实时计算（Flink）
                                       ↓
                               ClickHouse 存储（热数据 90 天）
                                       ↓
                               数据仓库（Hive/Iceberg 冷数据 2 年）
                                       ↓
                               超期归档或删除
```

### 14.3 新事件添加流程

```
1. 开发者在事件表中添加事件定义
2. 运行代码生成，获得强类型 Dart 类
3. 在业务代码中调用 PrimeTracker.instance.trackEvent(...)
4. 提交 PR，由数据团队 Review 事件定义
5. 合并后自动更新事件字典（CI 集成）
```
