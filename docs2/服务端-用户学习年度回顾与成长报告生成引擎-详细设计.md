# 服务端 - 用户学习年度回顾与成长报告生成引擎

> 细化日期：2026-06-09  
> 关联模块：学习报告生成与交付服务、学生成就与学习里程碑追踪引擎、学习习惯养成与打卡系统、分享与社交裂变系统

## 1. 模块概述

### 1.1 功能定位

用户学习年度回顾与成长报告生成引擎（Annual Learning Review Engine，简称 ALR）是 PrimeTop 在每年年末（12 月中下旬）为全体用户自动生成的个性化年度学习总结。其产品形态参考 Spotify Wrapped、支付宝年度账单、微信年度报告等爆款社交传播产品，以数据驱动的方式呈现用户全年的学习轨迹、成就里程碑和成长故事，并鼓励用户通过社交媒体分享传播，实现品牌曝光和新用户获客。

ALR 与常规学习报告（日报/周报/月报）的核心区别：

| 维度 | 常规学习报告 | 年度回顾报告 |
|------|-------------|-------------|
| 时间跨度 | 日/周/月 | 全年（1月1日-12月31日） |
| 数据深度 | 详细答题记录 | 聚合统计 + 趋势对比 |
| 情感色彩 | 客观、理性 | 温暖、激励、有趣 |
| 社交属性 | 较弱（家长分享为主） | 极强（朋友圈/社群传播） |
| 呈现形式 | 表格、图表为主 | 沉浸式全屏卡片、动画、数据故事 |
| AI 参与 | 生成摘要文本 | 生成个性化评语、学习故事、年度关键词 |
| 商业目标 | 学情反馈 | 用户活跃唤醒 + 社交裂变 + 会员转化 |

### 1.2 核心目标

| 目标 | 指标 |
|------|------|
| 社交传播 | 年度回顾分享率 ≥ 15%（DAU 基数） |
| 用户唤醒 | 沉默用户（30天未登录）通过年度回顾回流率 ≥ 8% |
| 品牌曝光 | 社交媒体曝光量（分享卡片被查看次数）≥ 分享数 × 50 |
| 会员转化 | 年度回顾页面会员转化率 ≥ 常规渠道 2 倍 |
| 用户满意度 | 年度回顾好评率 ≥ 90%（端内反馈） |

### 1.3 适用用户范围

| 用户类型 | 年度回顾内容 | 分享能力 |
|----------|-------------|---------|
| 学生（全年活跃） | 完整年度学习数据 + 成就 + 成长故事 | 全平台分享 |
| 学生（部分活跃） | 活跃时段学习数据 + 温暖激励 | 全平台分享 |
| 学生（新用户<30天） | 入门阶段数据 + 新起点寄语 | 全平台分享 |
| 家长 | 孩子学习年度数据 + 家庭共学回顾 | 家长圈分享 |
| 教师 | 班级年度教学数据 + 学生成长汇总 | 教师圈分享 |

## 2. 数据模型

### 2.1 年度回顾主表

```sql
CREATE TABLE annual_review (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT NOT NULL,                        -- 用户 ID
    review_year     SMALLINT NOT NULL,                      -- 年份，如 2026
    status          VARCHAR(20) NOT NULL DEFAULT 'pending', -- 状态：pending/aggregating/generating/ready/published/expired
    
    -- 数据聚合快照（JSONB，存储原始计算结果）
    data_snapshot   JSONB,
    
    -- 内容生成结果（JSONB，存储卡片序列）
    card_sequence   JSONB,
    
    -- 分享信息
    share_image_url VARCHAR(512),                           -- 分享主图 URL
    share_deep_link VARCHAR(512),                           -- 分享深链接
    share_count     INT NOT NULL DEFAULT 0,                 -- 被分享次数
    view_count      INT NOT NULL DEFAULT 0,                 -- 被查看次数
    
    -- 时间戳
    aggregated_at   TIMESTAMPTZ,                            -- 数据聚合完成时间
    generated_at    TIMESTAMPTZ,                            -- 内容生成完成时间
    published_at    TIMESTAMPTZ,                            -- 对用户发布时间
    first_viewed_at TIMESTAMPTZ,                            -- 用户首次查看时间
    expires_at      TIMESTAMPTZ,                            -- 过期时间（次年 3月1日）
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    CONSTRAINT uk_user_year UNIQUE (user_id, review_year)
);

CREATE INDEX idx_annual_review_status ON annual_review (status, review_year);
CREATE INDEX idx_annual_review_published ON annual_review (published_at) WHERE status = 'published';
```

**聚合 SQL 核心逻辑示例：**

```sql
-- 基础学习统计
SELECT
    l.user_id,
    SUM(l.study_duration_seconds) / 60 AS total_study_minutes,
    COUNT(DISTINCT DATE(l.created_at)) AS total_study_days,
    COUNT(a.id) AS total_questions_answered,
    AVG(CASE WHEN a.is_correct THEN 1.0 ELSE 0.0 END) AS total_correct_rate
FROM learning_sessions l
LEFT JOIN answer_records a ON a.user_id = l.user_id
    AND a.created_at >= '2026-01-01'
    AND a.created_at < '2027-01-01'
WHERE l.created_at >= '2026-01-01'
    AND l.created_at < '2027-01-01'
    AND l.user_id = ANY(:user_ids)
GROUP BY l.user_id;
```

```sql
-- 月度学习时长分布
SELECT
    user_id,
    EXTRACT(MONTH FROM created_at) AS month,
    SUM(study_duration_seconds) / 60 AS monthly_minutes
FROM learning_sessions
WHERE created_at >= '2026-01-01'
    AND created_at < '2027-01-01'
    AND user_id = ANY(:user_ids)
GROUP BY user_id, EXTRACT(MONTH FROM created_at)
ORDER BY user_id, month;
```
