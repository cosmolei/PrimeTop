# 服务端-学生假期学习衰减评估与开学前智能知识唤醒预热引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责量化评估学生在寒暑假等长周期休假期间的知识遗忘程度，并在开学前 2-3 周自动生成个性化的"知识唤醒预热计划"，通过低负担的复习任务激活休眠知识，缩短开学适应期。

### 1.2 问题背景

教育研究表明，学生在长假期（尤其暑假 6-8 周）后会出现显著的学业回退——即"暑期滑坡"（Summer Learning Loss）。具体表现：

- 数学计算能力平均回退 2.6 个月的学习量
- 拼写与阅读理解回退 1-2 个月
- 基础知识遗忘率高达 30%-40%
- 开学后前 2-3 周处于"知识重建期"，课堂吸收效率低

PrimeTop 作为全学段 AI 辅助平台，拥有学生的完整学习数据和知识掌握度模型，具备精准评估和针对性干预的天然优势。

### 1.3 设计目标

| 目标 | 说明 |
| --- | --- |
| 精准评估 | 基于遗忘曲线 + 个人学习特征，量化各知识点衰减程度 |
| 自动触发 | 开学前 14-21 天自动启动唤醒流程，无需用户手动开启 |
| 低负担 | 唤醒任务单日时长 ≤ 20 分钟，避免假期最后变成"第三个学期" |
| 闭环验证 | 开学后通过摸底测评验证唤醒效果，反馈优化衰减模型 |
| 多方协同 | 学生执行、家长可见、教师（若绑定班级）可查看 |

### 1.4 适用范围

- 学段：小学三年级至高中三年级（幼儿及小学低年级以兴趣维持为主，不纳入衰减评估）
- 假期类型：暑假（主要）、寒假、长假（国庆/五一等 ≥ 7 天的假期）
- 前置条件：学生在假期前至少有 30 天的学习记录和 ≥ 50 条答题数据

## 4. 核心算法设计

### 4.1 知识点衰减系数计算

#### 4.1.1 混合个性化衰减模型

衰减系数是本引擎的核心计算结果。单一艾宾浩斯曲线无法体现个体差异和知识点差异，因此采用混合模型：

```python
"""
知识点衰减系数计算
输入: 知识点历史数据 + 用户特征 + 假期活跃数据
输出: 衰减系数 (0~1) 和预估当前掌握度
"""

import math
from datetime import datetime, timedelta

def calculate_decay_coefficient(
    kp_history: dict,
    user_profile: dict,
    vacation_context: dict,
    model_params: dict
) -> dict:
    """
    计算单个知识点的衰减系数
    
    Args:
        kp_history: 知识点历史数据
            - pre_mastery: 假期前掌握度 (0~1)
            - last_review_date: 最后复习日期
            - review_count: 累计复习次数
            - avg_interval_days: 平均复习间隔
            - mastery_trend: 掌握度趋势 (ascending/stable/declining)
            - kp_difficulty: 知识点难度 (1-5)
            - kp_type: 知识点类型
        user_profile: 用户特征
            - memory_capacity: 记忆能力评分 (0~1, 来自知识追踪模型)
            - grade_level: 年级
            - historical_decay_rate: 历史衰减率
        vacation_context: 假期上下文
            - days_since_last_review: 距上次复习天数
            - vacation_active_days: 假期活跃天数
            - has_related_activity: 假期是否有相关学习活动
        model_params: 模型参数
            - alpha: 艾宾浩斯权重 (默认 0.4)
            - beta: 个性化因子权重 (默认 0.35)
            - gamma: 假期活跃因子权重 (默认 0.25)
    
    Returns:
        {
            'decay_coefficient': float,  # 0~1
            'estimated_mastery': float,  # 0~1
            'confidence': float,         # 0~1
            'risk_level': int,           # 0-3
            'factors': dict              # 各因子贡献明细
        }
    """
    alpha = model_params.get('alpha', 0.4)
    beta = model_params.get('beta', 0.35)
    gamma = model_params.get('gamma', 0.25)
    
    # ============ 因子1: 改进艾宾浩斯遗忘曲线 ============
    # 标准艾宾浩斯: R = e^(-t/S)
    # 改进: S (记忆稳定性) 受复习次数和难度影响
    
    days_elapsed = vacation_context['days_since_last_review']
    
    # 记忆稳定性基数
    base_stability = 2.0  # 默认2天
    
    # 根据复习次数调整稳定性 (每多一次复习，稳定性提升)
    review_boost = 1.0
    review_count = kp_history.get('review_count', 0)
    if review_count > 0:
        # 对数增长，避免过多复习的边际收益过高
        review_boost = 1.0 + 0.5 * math.log2(review_count + 1)
    
    # 根据知识点难度调整 (难度越高，遗忘越快)
    difficulty_factor = 1.0
    difficulty = kp_history.get('kp_difficulty', 3)
    if difficulty >= 4:
        difficulty_factor = 0.7  # 高难度知识点遗忘更快
    elif difficulty <= 2:
        difficulty_factor = 1.3  # 低难度知识点遗忘更慢
    
    # 知识点类型因子
    kp_type_factors = {
        'fact': 0.6,       # 事实性知识(年代、定义)最容易遗忘
        'concept': 0.85,   # 概念性知识
        'procedure': 1.0,  # 程序性知识(解题步骤)相对稳定
        'skill': 1.15      # 技能性知识(阅读理解)最稳定
    }
    type_factor = kp_type_factors.get(kp_history.get('kp_type', 'concept'), 0.85)
    
    # 计算记忆稳定性
    stability = base_stability * review_boost * difficulty_factor * type_factor
    
    # 艾宾浩斯衰减
    ebbinghaus_retention = math.exp(-days_elapsed / stability)
    ebbinghaus_decay = 1.0 - ebbinghaus_retention
    
    # ============ 因子2: 个性化因子 ============
    # 基于用户历史衰减率和记忆能力
    
    memory_capacity = user_profile.get('memory_capacity', 0.5)
    historical_rate = user_profile.get('historical_decay_rate', 0.3)
    
    # 掌握度趋势调整
    trend = kp_history.get('mastery_trend', 'stable')
    trend_factor = {
        'ascending': 0.85,   # 上升中的知识遗忘更慢
        'stable': 1.0,
        'declining': 1.2     # 已在下降的知识遗忘更快
    }.get(trend, 1.0)
    
    # 初始掌握度调整 (高掌握度衰减空间更大，但有"缓冲带")
    pre_mastery = kp_history.get('pre_mastery', 0.5)
    if pre_mastery > 0.85:
        mastery_buffer = 1.15  # 高掌握度有缓冲
    elif pre_mastery < 0.4:
        mastery_buffer = 0.90  # 低掌握度本身就脆弱
    else:
        mastery_buffer = 1.0
    
    personal_decay = (
        historical_rate * trend_factor * mastery_buffer 
        * (1.5 - memory_capacity)  # 记忆能力越差，衰减越严重
    )
    personal_decay = min(max(personal_decay, 0.0), 1.0)
    
    # ============ 因子3: 假期活跃因子 ============
    # 假期中是否有相关学习活动
    
    active_days = vacation_context.get('vacation_active_days', 0)
    has_related = vacation_context.get('has_related_activity', False)
    
    # 假期活跃折扣: 活跃天数越多，衰减越少
    active_discount = min(active_days * 0.02, 0.30)  # 最多折扣30%
    
    # 相关活动直接保护
    related_protection = 0.15 if has_related else 0.0
    
    activity_factor = 1.0 - active_discount - related_protection
    activity_factor = max(activity_factor, 0.3)  # 最低保留30%衰减
    
    # 基础活动衰减率
    base_activity_decay = ebbinghaus_decay * 0.8  # 基础值
    activity_decay = base_activity_decay * activity_factor
    
    # ============ 混合衰减系数 ============
    decay_coefficient = (
        alpha * ebbinghaus_decay +
        beta * personal_decay +
        gamma * activity_decay
    )
    
    decay_coefficient = min(max(decay_coefficient, 0.0), 0.95)  # 上限0.95，不完全遗忘
    
    # ============ 预估当前掌握度 ============
    pre_mastery = kp_history.get('pre_mastery', 0.5)
    estimated_mastery = pre_mastery * (1.0 - decay_coefficient)
    
    # 最低地板值：不会低于初始掌握度的10%
    estimated_mastery = max(estimated_mastery, pre_mastery * 0.10)
    
    # ============ 置信度 ============
    # 数据越充分，置信度越高
    confidence = min(
        review_count / 10.0,  # 复习次数贡献
        1.0
    ) * 0.5 + 0.3 + (0.2 if days_elapsed > 0 else 0.0)
    confidence = min(confidence, 0.95)
    
    # ============ 风险等级 ============
    if decay_coefficient < 0.10:
        risk_level = 0  # 稳定
    elif decay_coefficient < 0.25:
        risk_level = 1  # 低风险
    elif decay_coefficient < 0.50:
        risk_level = 2  # 中风险
    else:
        risk_level = 3  # 高风险
    
    return {
        'decay_coefficient': round(decay_coefficient, 4),
        'estimated_mastery': round(estimated_mastery, 4),
        'confidence': round(confidence, 4),
        'risk_level': risk_level,
        'factors': {
            'ebbinghaus_decay': round(ebbinghaus_decay, 4),
            'personal_decay': round(personal_decay, 4),
            'activity_decay': round(activity_decay, 4),
            'stability_days': round(stability, 2),
            'active_discount': round(active_discount, 4)
        }
    }
```

```python
async def run_decay_assessment_batch(
    user_id: int,
    vacation_id: str,
    assess_date: datetime
) -> dict:
    """
    对用户的所有知识点执行批量衰减评估
    
    Returns:
        整体评估摘要
    """
    # 1. 获取假期上下文
    vacation = await get_vacation_info(vacation_id)
    
    # 2. 获取用户假期前所有有记录的知识点
    kp_list = await get_user_knowledge_points_before_vacation(
        user_id, 
        vacation.start_date
    )
    
    # 过滤：只评估掌握度 >= 0.2 的知识点（太低的无需评估）
    kp_list = [kp for kp in kp_list if kp.pre_mastery >= 0.2]
    
    if not kp_list:
        return {'overall_decay_score': 0, 'message': '无足够知识点数据'}
    
    # 3. 获取用户画像特征
    user_profile = await get_user_memory_profile(user_id)
    
    # 4. 获取假期活跃数据
    active_log = await get_vacation_active_log(user_id, vacation_id)
    
    # 5. 获取模型参数 (可A/B测试不同参数)
    model_params = await get_decay_model_params(user_id)
    
    # 6. 并发计算各知识点衰减
    tasks = []
    for kp in kp_list:
        kp_context = build_kp_context(kp, active_log, vacation)
        tasks.append(
            calculate_decay_coefficient(kp, user_profile, kp_context, model_params)
        )
    
    results = await asyncio.gather(*tasks)
    
    # 7. 聚合整体指标
    overall_decay = sum(r['decay_coefficient'] for r in results) / len(results)
    pre_avg = sum(kp.pre_mastery for kp in kp_list) / len(kp_list)
    post_avg = sum(r['estimated_mastery'] for r in results) / len(results)
    
    risk_counts = {0: 0, 1: 0, 2: 0, 3: 0}
    for r in results:
        risk_counts[r['risk_level']] += 1
    
    # 8. 持久化评估结果
    assessment = await save_assessment({
        'user_id': user_id,
        'vacation_id': vacation_id,
        'overall_decay_score': overall_decay,
        'pre_vacation_mastery': pre_avg,
        'estimated_current_mastery': post_avg,
        'high_risk_kp_count': risk_counts[3],
        'medium_risk_kp_count': risk_counts[2],
        'stable_kp_count': risk_counts[0] + risk_counts[1],
        'active_days': active_log.active_days,
        'total_active_minutes': active_log.total_minutes,
        'has_self_study': active_log.has_self_study,
        'model_version': model_params['version'],
        'assess_date': assess_date
    })
    
    # 9. 持久化知识点明细
    kp_details = []
    for kp, result in zip(kp_list, results):
        kp_details.append({
            'assessment_id': assessment.id,
            'user_id': user_id,
            'knowledge_point_id': kp.id,
            'subject': kp.subject,
            **result,
            **kp.to_dict()
        })
    
    await batch_save_kp_details(kp_details)
    
    # 10. 更新缓存
    await update_decay_cache(user_id, vacation_id, assessment, risk_counts)
    
    return {
        'assessment_id': assessment.id,
        'overall_decay_score': round(overall_decay, 4),
        'pre_vacation_mastery': round(pre_avg, 4),
        'estimated_current_mastery': round(post_avg, 4),
        'risk_distribution': risk_counts,
        'total_kp_assessed': len(kp_list)
    }
```

### 4.2 唤醒计划生成算法

```python
async def generate_wakeup_plan(
    user_id: int,
    vacation_id: str,
    latest_assessment_id: int
) -> dict:
    """
    基于衰减评估结果生成个性化唤醒计划
    
    策略:
    1. 按风险等级和知识点重要性筛选目标知识点
    2. 按学科均衡分配，避免一天全是同一学科
    3. 高风险知识点优先安排在前半程
    4. 核心知识点优先于边缘知识点
    5. 参考学生偏好学科顺序
    """
    
    # ---------- 1. 参数获取 ----------
    assessment = await get_assessment(latest_assessment_id)
    vacation = await get_vacation_info(vacation_id)
    
    # 开学前14-21天开始唤醒
    wakeup_start = vacation.end_date - timedelta(days=14)
    wakeup_end = vacation.end_date - timedelta(days=1)
    total_days = (wakeup_end - wakeup_start).days + 1
    
    # ---------- 2. 筛选目标知识点 ----------
    kp_details = await get_kp_details(latest_assessment_id)
    
    # 过滤：只唤醒有衰减的知识点 (risk_level >= 1)
    target_kps = [kp for kp in kp_details if kp.risk_level >= 1]
    
    # 排序优先级: 高风险 > 核心知识点 > 高难度 > 学科分布
    target_kps.sort(key=lambda kp: (
        -kp.risk_level,          # 高风险优先
        -kp.is_core_kp,          # 核心知识点优先
        -kp.kp_difficulty,       # 高难度优先
        kp.estimated_mastery     # 掌握度低的优先
    ))
    
    # 限制知识点总数 (每日上限 × 天数 × 安全系数)
    max_kp = min(
        len(target_kps),
        int(total_days * 5 * 0.8)  # 每日最多5个KP，留20%余量
    )
    target_kps = target_kps[:max_kp]
    
    # ---------- 3. 分配每日知识点 ----------
    daily_limit = get_user_daily_limit(user_id)  # 默认5个/天
    daily_minutes_target = 20  # 每日目标时长(分钟)
    
    # 按学科分组，保证每日学科多样性
    subject_groups = group_by_subject(target_kps)
    subjects = list(subject_groups.keys())
    
    daily_plan = {}  # {date: [task_items]}
    kp_assigned = set()
    current_date = wakeup_start
    day_index = 1
    
    while current_date <= wakeup_end and len(kp_assigned) < len(target_kps):
        daily_items = []
        daily_minutes = 0
        subjects_used_today = set()
        
        # 每日选取: 优先高风险 + 学科轮换
        remaining_kps = [kp for kp in target_kps if kp.id not in kp_assigned]
        
        for kp in remaining_kps:
            if len(daily_items) >= daily_limit:
                break
            if daily_minutes >= daily_minutes_target:
                break
            
            # 同一学科不超过2个知识点/天
            subject_count_today = sum(
                1 for item in daily_items 
                if item['subject'] == kp.subject
            )
            if kp.subject in subjects_used_today and subject_count_today >= 2:
                continue
            
            # 分配任务类型
            task_type = select_task_type(kp, day_index, total_days)
            estimated_min = get_task_estimated_minutes(task_type)
            
            daily_items.append({
                'item_id': f'wakeup_{user_id}_{current_date}_{len(daily_items)+1}',
                'type': task_type.value,
                'knowledge_point_id': kp.knowledge_point_id,
                'knowledge_point_name': kp.knowledge_point_name,
                'subject': kp.subject,
                'estimated_minutes': estimated_min,
                'priority': 'high' if kp.risk_level >= 3 else ('medium' if kp.risk_level >= 2 else 'low'),
                'content_ref': await resolve_content_ref(kp, task_type),
                'mastery_before': kp.estimated_mastery,
                'target_mastery': min(kp.pre_mastery, kp.pre_mastery * 0.95)
            })
            
            daily_minutes += estimated_min
            subjects_used_today.add(kp.subject)
            kp_assigned.add(kp.id)
        
        if daily_items:
            daily_plan[current_date] = daily_items
        
        current_date += timedelta(days=1)
        day_index += 1
    
    # ---------- 4. 持久化计划 ----------
    plan = await create_wakeup_plan({
        'user_id': user_id,
        'vacation_id': vacation_id,
        'assessment_id': latest_assessment_id,
        'wakeup_start_date': wakeup_start,
        'wakeup_end_date': wakeup_end,
        'total_days': len(daily_plan),
        'total_kp_count': len(kp_assigned),
        'total_task_count': sum(len(items) for items in daily_plan.values()),
        'daily_task_limit': daily_limit,
        'daily_minutes_est': daily_minutes_target
    })
    
    # 批量创建每日任务
    for date, items in daily_plan.items():
        await create_daily_task({
            'plan_id': plan.id,
            'user_id': user_id,
            'task_date': date,
            'day_index': (date - wakeup_start).days + 1,
            'task_items': items
        })
    
    return {
        'plan_id': plan.id,
        'wakeup_start': wakeup_start,
        'wakeup_end': wakeup_end,
        'total_days': len(daily_plan),
        'total_kp': len(kp_assigned),
        'total_tasks': sum(len(items) for items in daily_plan.values())
    }


def select_task_type(kp: dict, day_index: int, total_days: int) -> 'WakeupTaskType':
    """
    为知识点选择当日任务类型
    
    策略:
    - 前期(前1/3): 概念回想 + 快速复习 (唤醒记忆)
    - 中期(中1/3): 闪卡 + 迷你测验 (巩固检测)
    - 后期(后1/3): 间隔重复 + 迷你测验 (强化验证)
    """
    progress = day_index / total_days
    
    if progress < 0.33:
        # 唤醒期：轻量回顾
        if kp['kp_type'] == 'fact':
            return WakeupTaskType.FLASHCARD
        elif kp['kp_type'] == 'procedure':
            return WakeupTaskType.QUICK_REVIEW
        else:
            return WakeupTaskType.CONCEPT_RECALL
    elif progress < 0.67:
        # 巩固期：检测+练习
        if kp['risk_level'] >= 3:
            return WakeupTaskType.MINI_QUIZ  # 高风险的要测一测
        else:
            return WakeupTaskType.FLASHCARD
    else:
        # 验证期：强化
        return WakeupTaskType.SPACED_REPETITION
```

### 4.3 效果验证算法

```python
async def evaluate_wakeup_effectiveness(
    plan_id: int,
    post_test_results: dict
) -> dict:
    """
    评估唤醒计划效果
    
    Args:
        plan_id: 唤醒计划ID
        post_test_results: 开学摸底测评结果
            {
                'kp_scores': {kp_id: mastery_score},
                'overall_score': float
            }
    """
    plan = await get_wakeup_plan(plan_id)
    assessment = await get_assessment(plan.assessment_id)
    
    # 获取唤醒前后各知识点掌握度
    pre_mastery = {}   # 唤醒前预估
    post_mastery = {}  # 摸底测评实际
    
    kp_details = await get_kp_details(plan.assessment_id)
    for kp in kp_details:
        if kp.knowledge_point_id in plan.covered_kp_ids:
            pre_mastery[kp.knowledge_point_id] = kp.estimated_mastery
    
    post_mastery = post_test_results['kp_scores']
    
    # 计算各知识点恢复率
    recovery_data = []
    for kp_id, pre in pre_mastery.items():
        post = post_mastery.get(kp_id, pre)  # 若无测评数据，假设无变化
        original = assessment.pre_vacation_mastery  # 假期前原始掌握度
        
        # 恢复率 = (唤醒后 - 唤醒前预估) / (原始 - 唤醒前预估)
        denominator = original - pre
        if abs(denominator) < 0.01:
            recovery_rate = 1.0 if post >= original else post / max(original, 0.01)
        else:
            recovery_rate = (post - pre) / denominator
        recovery_rate = min(max(recovery_rate, 0.0), 1.5)  # 允许超过100%
        
        recovery_data.append({
            'kp_id': kp_id,
            'pre_vacation': original,
            'pre_wakeup': pre,
            'post_wakeup': post,
            'recovery_rate': recovery_rate
        })
    
    # 整体指标
    avg_pre = sum(d['pre_wakeup'] for d in recovery_data) / len(recovery_data)
    avg_post = sum(d['post_wakeup'] for d in recovery_data) / len(recovery_data)
    overall_recovery = (avg_post - avg_pre) / max(assessment.pre_vacation_mastery - avg_pre, 0.01)
    
    # 更新计划效果
    await update_plan_effectiveness(plan_id, {
        'pre_wakeup_avg_mastery': avg_pre,
        'post_wakeup_avg_mastery': avg_post,
        'recovery_rate': overall_recovery
    })
    
    # 反馈校准衰减模型参数
    await feedback_decay_model(
        user_id=plan.user_id,
        predicted_mastery=pre_mastery,
        actual_mastery=post_mastery,
        model_version=assessment.model_version
    )
    
    return {
        'overall_recovery_rate': round(overall_recovery, 4),
        'avg_pre_wakeup_mastery': round(avg_pre, 4),
        'avg_post_wakeup_mastery': round(avg_post, 4),
        'kp_count': len(recovery_data),
        'high_recovery_kps': [d for d in recovery_data if d['recovery_rate'] >= 0.8],
        'low_recovery_kps': [d for d in recovery_data if d['recovery_rate'] < 0.3]
    }
```

### 7.2 核心调度逻辑

```java
/**
 * 每日唤醒计划激活任务
 * 检查所有 PENDING 状态的计划，如果到达开始日期则激活
 */
@Scheduled(cron = "0 0 6 * * ?")
public void activateWakeupPlans() {
    LocalDate today = LocalDate.now();
    
    // 分批查询待激活的计划
    int pageSize = 200;
    int pageNum = 0;
    
    while (true) {
        List<WakeupPlan> plans = wakeupPlanMapper.selectPendingByStartDate(
            today, pageNum * pageSize, pageSize
        );
        if (plans.isEmpty()) break;
        
        for (WakeupPlan plan : plans) {
            try {
                // 激活计划
                plan.setPlanStatus(WakeupPlanStatus.ACTIVE.getCode());
                plan.setActivatedAt(LocalDateTime.now());
                wakeupPlanMapper.updateById(plan);
                
                // 发送通知: "你的开学收心计划已启动！"
                notificationService.sendWakeupActivatedNotification(plan);
                
                // 生成第一天的任务
                wakeupTaskService.generateTodayTasks(plan);
                
            } catch (Exception e) {
                log.error("激活唤醒计划失败 planId={}", plan.getId(), e);
            }
        }
        
        pageNum++;
    }
}
```

### 8.1 错误码定义

| 错误码 | HTTP状态码 | 说明 | 处理方式 |
| --- | --- | --- | --- |
| `DECAY_001` | 400 | 学生假期前数据不足(<30天或<50条答题) | 返回提示，不进行评估 |
| `DECAY_002` | 400 | 学段不在支持范围内 | 幼儿及小学低年级返回"暂不支持" |
| `DECAY_003` | 500 | 知识追踪模型服务不可用 | 降级为纯艾宾浩斯基础模型 |
| `DECAY_004` | 500 | 用户画像数据获取失败 | 使用默认画像参数，记录warning |
| `WAKEUP_001` | 400 | 唤醒计划不存在或无权限 | 返回404 |
| `WAKEUP_002` | 400 | 计划状态不允许此操作 | 返回当前状态和允许的操作 |
| `WAKEUP_003` | 400 | 任务不存在或不属于当前用户 | 返回404 |
| `WAKEUP_004` | 409 | 今日任务已过期(跨日提交) | 提示任务已过期 |
| `WAKEUP_005` | 500 | 内容服务不可用(无法获取复习卡片) | 降级为基础题库随机出题 |
| `WAKEUP_006` | 500 | 掌握度更新失败(知识追踪服务异常) | 任务标记完成但不更新掌握度，记录补偿队列 |

### 8.2 降级策略

```java
/**
 * 衰减评估降级策略链
 */
public class DecayAssessmentFallbackChain {
    
    /**
     * Level 1: 完整混合模型 (正常)
     * - 个性化因子 + 艾宾浩斯 + 假期活跃
     */
    public DecayResult fullModel(KpHistory kp, UserProfile profile, VacationContext ctx) {
        return hybridModel.calculate(kp, profile, ctx);
    }
    
    /**
     * Level 2: 简化模型 (用户画像不可用)
     * - 只用艾宾浩斯 + 假期活跃
     * - 个性化因子使用群体平均值
     */
    public DecayResult simplifiedModel(KpHistory kp, VacationContext ctx) {
        UserProfile defaultProfile = UserProfile.defaultFor(kp.getGradeLevel());
        return hybridModel.calculate(kp, defaultProfile, ctx);
    }
    
    /**
     * Level 3: 基础模型 (知识追踪服务不可用)
     * - 纯改进艾宾浩斯公式
     * - 不使用个性化数据
     */
    public DecayResult basicModel(KpHistory kp, VacationContext ctx) {
        double stability = 2.0 * (1 + 0.5 * Math.log10(kp.getReviewCount() + 1));
        double decay = 1.0 - Math.exp(-ctx.getDaysSinceLastReview() / stability);
        return DecayResult.builder()
            .decayCoefficient(decay)
            .estimatedMastery(kp.getPreMastery() * (1 - decay))
            .confidence(0.4)  // 低置信度
            .modelVersion("basic_fallback")
            .build();
    }
    
    /**
     * Level 4: 最后手段 (数据库不可用)
     * - 返回上次缓存结果
     * - 或返回保守的中等衰减估计
     */
    public DecayResult lastResort(Long userId, Long kpId) {
        DecayResult cached = cacheManager.getDecayCache(userId, kpId);
        if (cached != null) {
            return cached.withStaleFlag(true);
        }
        return DecayResult.conservativeEstimate();
    }
}
```

### 8.3 数据一致性补偿

```java
/**
 * 掌握度更新失败补偿队列
 * 
 * 场景: 用户完成唤醒任务，但知识追踪模型服务不可用，
 * 导致掌握度更新失败。将失败任务放入补偿队列，稍后重试。
 */
@Retryable(
    value = {KnowledgeTrackingException.class},
    maxAttempts = 3,
    backoff = @Backoff(delay = 5000, multiplier = 2)
)
public void updateMasteryAfterTask(Long taskId, BigDecimal masteryAfter) {
    knowledgeTrackingService.updateMastery(taskId, masteryAfter);
}

/**
 * 补偿任务: 每10分钟扫描一次失败队列
 */
@Scheduled(fixedDelay = 600000)
public void compensateMasteryUpdates() {
    List<FailedMasteryUpdate> failures = compensationQueue.getPendingFailures(100);
    
    for (FailedMasteryUpdate failure : failures) {
        try {
            knowledgeTrackingService.updateMastery(
                failure.getTaskId(), 
                failure.getMasteryAfter()
            );
            compensationQueue.markResolved(failure.getId());
        } catch (Exception e) {
            failure.incrementRetryCount();
            if (failure.getRetryCount() >= 5) {
                // 超过5次重试，标记为需要人工处理
                failure.setStatus(FAILED_MANUAL_REQUIRED);
                alertService.sendAlert("掌握度更新补偿失败", failure);
            }
        }
    }
}
```

## 10. 性能优化

### 10.1 评估计算优化

| 优化点 | 策略 | 预期效果 |
| --- | --- | --- |
| 知识点批量计算 | 单用户的知识点评估并发计算，限制并发数50 | 单用户200个KP评估 < 3秒 |
| 增量评估 | 只对距上次评估有变化的知识点重新计算 | 减少约60%计算量 |
| 结果缓存 | 评估结果缓存6小时，假期内每日变化不大 | 减少重复计算 |
| 预计算 | 凌晨低峰期对活跃用户的下一步衰减进行预计算 | 白天响应更快 |

### 10.2 数据量估算

| 维度 | 估算 | 说明 |
| --- | --- | --- |
| 单用户知识点数 | 100-300 个 | 假期前有学习记录的知识点 |
| 单次评估明细行数 | ~200 行 | vacation_decay_kp_detail |
| 假期总评估次数 | 4 轮/假期 | 基线 + 中期 + 预唤醒 + 效果验证 |
| 活跃用户规模 | ~100 万 | 高峰期为暑假结束前2周 |
| 峰值QPS | ~500 | 主要是获取今日任务和提交结果 |
| 单用户计划数据量 | ~14 天 × 5 任务 = 70 条 | wakeup_daily_task |

### 10.3 数据库索引优化

```sql
-- 衰减明细按评估ID查询 (高频)
CREATE INDEX idx_assessment_kp ON vacation_decay_kp_detail(assessment_id, knowledge_point_id);

-- 按用户和风险等级筛选 (计划生成高频)
CREATE INDEX idx_user_risk ON vacation_decay_kp_detail(user_id, risk_level, subject);

-- 每日任务按计划和日期查询 (最高频)
CREATE INDEX idx_plan_date_status ON wakeup_daily_task(plan_id, task_date, status);

-- 用户当日任务查询 (最高频，覆盖索引)
CREATE INDEX idx_user_date_cover ON wakeup_daily_task(user_id, task_date, status, task_items(100));
```

### 11.2 数据脱敏

```java
/**
 * 衰减报告脱敏规则
 * 家长视角: 可看到完整的衰减数据和计划进度
 * 教师视角: 只能看到聚合数据(班级维度)，不可看到单个学生的详细答题记录
 */
public class DecayReportDataMasker {
    
    public DecayReport maskForParent(DecayReport raw) {
        // 家长可见全部，但隐藏具体答题内容
        raw.getSubjectBreakdown().forEach(subject -> {
            subject.getTopRiskPoints().forEach(kp -> {
                kp.setContentRef(null);  // 不暴露具体内容引用
            });
        });
        return raw;
    }
    
    public DecayReport maskForTeacher(DecayReport raw) {
        // 教师只能看到风险等级分布和学科汇总，不可看具体知识点明细
        raw.setKpDetails(null);
        raw.getSubjectBreakdown().forEach(subject -> {
            subject.setTopRiskPoints(null);  // 不可看具体知识点
        });
        return raw;
    }
}
```

- 效果验证的模型校准回流构成"评估 → 干预 → 验证 → 校准"闭环, 是衰减模型持续进化的唯一数据来源(§14)。
