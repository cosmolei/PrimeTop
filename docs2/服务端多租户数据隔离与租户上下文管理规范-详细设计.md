# 服务端多租户数据隔离与租户上下文管理规范 - 详细设计

## 1. 文档概述

### 1.1 目的

本文档定义 PrimeTop 平台多租户架构的技术实现规范，包括数据隔离策略、租户上下文传播机制、租户生命周期管理、安全隔离边界等核心设计。为 V2.0 阶段 B 端合作（学校、教培机构、区域教育平台）提供可直接编码的技术方案。

### 1.2 适用范围

- 服务端所有需要支持多租户的业务服务
- 数据库、缓存、对象存储、搜索引擎等数据层的隔离方案
- 租户感知的 API 网关、鉴权、审计组件
- 租户管理后台与自助服务

### 1.3 术语定义

| 术语 | 说明 |
| --- | --- |
| Tenant（租户） | 一个独立的机构客户（学校、培训机构、区域教育局等），拥有独立的用户空间和数据边界 |
| TenantContext（租户上下文） | 当前请求关联的租户标识与配置信息，在线程/协程间传播 |
| 数据隔离 | 不同租户的数据在存储层面相互不可见 |
| 水平隔离（Schema-per-Tenant） | 每个租户使用独立的数据库 Schema |
| 垂直隔离（Row-Level） | 共享表结构，通过 tenant_id 列实现行级隔离 |
| Hybrid 隔离 | 核心业务数据使用水平隔离，配置/元数据使用共享表 |

## 2. 隔离模型选型与分层策略

### 2.1 隔离模型对比

| 模型 | 隔离强度 | 运维成本 | 扩展性 | 适用场景 |
| --- | --- | --- | --- | --- |
| DB-per-Tenant（独立库） | ★★★★★ | ★★★★★（高） | ★★☆ | 超大租户、合规要求极高（如教育主管部门） |
| Schema-per-Tenant（独立Schema） | ★★★★☆ | ★★★★（中高） | ★★★ | 中大型机构、有定制需求 |
| Row-Level（共享表+tenant_id） | ★★★☆☆ | ★★（低） | ★★★★★ | 小型机构、SaaS 标准版 |
| Hybrid（混合模式） | ★★★★☆ | ★★★（中） | ★★★★ | PrimeTop 推荐方案 |

### 2.2 PrimeTop Hybrid 隔离方案

采用 **按租户规模分级的混合隔离** 策略：

```
┌──────────────────────────────────────────────────────────────┐
│                      隔离策略路由                              │
│                                                              │
│  小型机构（<500人）  ──→  Row-Level 隔离（共享表 + tenant_id） │
│  中型机构（500-5000）──→  Schema-per-Tenant 隔离              │
│  大型/特殊租户（>5000）──→ DB-per-Tenant 隔离                 │
│  C 端个人用户        ──→  默认租户（tenant_id = 0）            │
└──────────────────────────────────────────────────────────────┘
```

**核心决策依据：**

1. **C 端个人用户**不参与多租户隔离，使用 `tenant_id = 0` 标识，保持现有单租户代码路径不变
2. **小型机构**共享表结构，降低资源开销，通过 `tenant_id` 列 + 中间件强制过滤
3. **中型机构**独立 Schema，可在不影响其他租户的情况下做定制化扩展
4. **大型机构**独立数据库，支持私有化部署、物理隔离和合规审计

### 2.3 各数据层隔离方案

| 数据层 | 隔离方式 | 实现机制 |
| --- | --- | --- |
| MySQL/PostgreSQL | Row-Level / Schema / DB 分级 | MyBatis-Plus TenantLineInnerInterceptor + 动态数据源路由 |
| Redis | Key 前缀隔离 | `tenant:{tenantId}:` 前缀 + TenantRedisTemplate |
| Elasticsearch | Index-per-Tenant 或 alias+filter | 小租户共享索引+filter，大租户独立索引 |
| 对象存储（OSS/S3） | Bucket 或路径隔离 | `{bucket}/{tenantId}/` 路径前缀 |
| 向量数据库（Milvus） | Collection 隔离 | 小租户共享 Collection + partition_key，大租户独立 Collection |

## 4. 租户上下文传播机制

### 4.1 TenantContext 定义

```java
/**
 * 租户上下文 - 在请求生命周期内持有当前租户信息
 * 基于 ThreadLocal 实现（异步场景使用 TransmittableThreadLocal）
 */
public class TenantContext {
    
    private static final ThreadLocal<TenantInfo> CONTEXT = 
        new TransmittableThreadLocal<>();
    
    /** 租户ID（0 = C端默认） */
    private Long tenantId;
    
    /** 租户编码 */
    private String tenantCode;
    
    /** 隔离级别 */
    private Integer isolationLevel;
    
    /** Schema名称（isolationLevel=2 时使用） */
    private String schemaName;
    
    /** 动态数据源Key（isolationLevel=3 时使用） */
    private String dataSourceKey;
    
    /** 租户功能开关 */
    private long featuresMask;
    
    /** 租户配置快照（避免频繁查库） */
    private Map<String, String> configSnapshot;
    
    // ========== 静态方法 ==========
    
    public static void set(TenantInfo info) {
        CONTEXT.set(info);
    }
    
    public static TenantInfo get() {
        return CONTEXT.get();
    }
    
    public static Long getTenantId() {
        TenantInfo info = CONTEXT.get();
        return info != null ? info.getTenantId() : 0L;
    }
    
    public static boolean isC端() {
        return getTenantId() == 0L;
    }
    
    public static void clear() {
        CONTEXT.remove();
    }
    
    /**
     * 在指定租户上下文中执行一段逻辑
     * 用于异步任务、定时任务等非请求场景
     */
    public static <T> T runInTenant(Long tenantId, Supplier<T> action) {
        TenantInfo original = CONTEXT.get();
        try {
            // 查询并设置租户信息
            TenantInfo tenantInfo = tenantService.getTenantInfo(tenantId);
            CONTEXT.set(tenantInfo);
            return action.get();
        } finally {
            if (original != null) {
                CONTEXT.set(original);
            } else {
                CONTEXT.remove();
            }
        }
    }
}
```

### 4.2 请求拦截器 - 自动识别租户

```java
/**
 * 租户识别拦截器 - 在 API 网关 / Filter 层自动识别当前请求所属租户
 * 
 * 识别策略（按优先级）：
 * 1. 请求头 X-Tenant-Id（B端API调用）
 * 2. 子域名解析（{tenant}.primetop.cn）
 * 3. URL路径前缀（/t/{tenantCode}/...）
 * 4. 用户Token中的 tenantId 声明
 * 5. 默认为 C端（tenantId = 0）
 */
@Component
public class TenantIdentifyFilter extends OncePerRequestFilter {
    
    @Autowired
    private TenantService tenantService;
    
    @Override
    protected void doFilterInternal(
            HttpServletRequest request, 
            HttpServletResponse response, 
            FilterChain filterChain) throws ServletException, IOException {
        
        try {
            TenantInfo tenantInfo = resolveTenant(request);
            TenantContext.set(tenantInfo);
            
            // 校验租户状态
            if (tenantInfo != null && tenantInfo.getTenantId() != 0L) {
                validateTenantStatus(tenantInfo);
            }
            
            filterChain.doFilter(request, response);
        } finally {
            TenantContext.clear();
        }
    }
    
    private TenantInfo resolveTenant(HttpServletRequest request) {
        // 策略1：请求头
        String tenantIdHeader = request.getHeader("X-Tenant-Id");
        if (StringUtils.hasText(tenantIdHeader)) {
            return tenantService.getTenantInfo(Long.parseLong(tenantIdHeader));
        }
        
        // 策略2：子域名
        String serverName = request.getServerName();
        if (!serverName.equals("www.primetop.cn") 
            && !serverName.equals("primetop.cn")
            && serverName.endsWith(".primetop.cn")) {
            String tenantCode = serverName.replace(".primetop.cn", "");
            return tenantService.getTenantInfoByCode(tenantCode);
        }
        
        // 策略3：URL路径
        String uri = request.getRequestURI();
        Matcher matcher = Pattern.compile("^/t/([a-zA-Z0-9_-]+)(/|$)").matcher(uri);
        if (matcher.find()) {
            String tenantCode = matcher.group(1);
            return tenantService.getTenantInfoByCode(tenantCode);
        }
        
        // 策略4：Token中提取（从JWT中读取 tenantId claim）
        Long tenantIdFromToken = extractTenantIdFromToken(request);
        if (tenantIdFromToken != null && tenantIdFromToken != 0L) {
            return tenantService.getTenantInfo(tenantIdFromToken);
        }
        
        // 策略5：默认C端
        return TenantInfo.c端Default();
    }
}
```

### 4.3 MyBatis-Plus 租户拦截器

```java
/**
 * 基于 MyBatis-Plus TenantLineInnerInterceptor 的行级隔离
 * 自动在 SQL 中注入 tenant_id 过滤条件
 */
@Configuration
public class MybatisPlusTenantConfig {
    
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        
        TenantLineInnerInterceptor tenantInterceptor = new TenantLineInnerInterceptor();
        tenantInterceptor.setTenantLineHandler(new TenantLineHandler() {
            
            @Override
            public Expression getTenantId() {
                Long tenantId = TenantContext.getTenantId();
                return new LongValue(tenantId);
            }
            
            @Override
            public String getTenantIdColumn() {
                return "tenant_id";
            }
            
            @Override
            public boolean ignoreTable(String tableName) {
                // 不需要租户隔离的系统表
                return IGNORE_TABLES.contains(tableName);
            }
        });
        
        interceptor.addInnerInterceptor(tenantInterceptor);
        return interceptor;
    }
    
    /** 不参与租户隔离的系统表 */
    private static final Set<String> IGNORE_TABLES = Set.of(
        "sys_tenant",
        "sys_tenant_config",
        "sys_tenant_plan",
        "sys_tenant_admin",
        "sys_user",           // 用户表（通过关联关系隔离）
        "sys_role",
        "sys_permission",
        "sys_dict",
        "sys_config",
        "flyway_schema_history"
    );
}
```

### 4.4 动态数据源路由（Schema/DB 隔离）

```java
/**
 * 动态数据源路由 - 根据 TenantContext 中的隔离级别
 * 路由到正确的数据源（共享库 / 独立Schema / 独立DB）
 */
public class TenantDynamicDataSource extends AbstractRoutingDataSource {
    
    @Autowired
    private TenantDataSourceManager dataSourceManager;
    
    @Override
    protected Object determineCurrentLookupKey() {
        TenantInfo tenant = TenantContext.get();
        if (tenant == null || tenant.getIsolationLevel() == null) {
            return "default";
        }
        
        switch (tenant.getIsolationLevel()) {
            case 0: // C端默认
            case 1: // Row-Level 共享库
                return "default";
            case 2: // Schema隔离
                return "schema:" + tenant.getSchemaName();
            case 3: // DB隔离
                return "db:" + tenant.getDataSourceKey();
            default:
                return "default";
        }
    }
    
    @Override
    protected DataSource determineTargetDataSource() {
        Object lookupKey = determineCurrentLookupKey();
        String key = (String) lookupKey;
        
        if (key.startsWith("db:")) {
            // 动态创建/获取租户独立数据源
            String dsKey = key.substring(3);
            return dataSourceManager.getOrCreateDataSource(dsKey);
        }
        
        if (key.startsWith("schema:")) {
            // Schema隔离：在连接上设置 schema search_path
            String schema = key.substring(7);
            return dataSourceManager.getSchemaDataSource(schema);
        }
        
        return super.determineTargetDataSource();
    }
}
```

### 4.5 Redis 租户隔离

```java
/**
 * 租户感知的 Redis 操作模板
 * 自动为所有 key 添加 tenant 前缀
 */
@Component
public class TenantRedisTemplate {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    private static final String KEY_PREFIX = "tenant:%d:";
    
    /**
     * 构建带租户前缀的Key
     */
    private String wrapKey(String key) {
        Long tenantId = TenantContext.getTenantId();
        return String.format(KEY_PREFIX, tenantId) + key;
    }
    
    public void set(String key, String value, Duration timeout) {
        redisTemplate.opsForValue().set(wrapKey(key), value, timeout);
    }
    
    public String get(String key) {
        return redisTemplate.opsForValue().get(wrapKey(key));
    }
    
    public Boolean delete(String key) {
        return redisTemplate.delete(wrapKey(key));
    }
    
    /**
     * 清空指定租户的所有缓存
     * 用于租户冻结、数据清理等场景
     */
    public void clearTenantCache(Long tenantId) {
        String pattern = String.format(KEY_PREFIX, tenantId) + "*";
        Set<String> keys = redisTemplate.keys(pattern);
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }
    }
}
```

### 5.2 租户初始化流程

```java
@Service
public class TenantInitService {
    
    /**
     * 租户初始化 - 创建租户后自动执行
     * 
     * 步骤：
     * 1. 根据隔离级别创建数据空间（Schema/DB）
     * 2. 初始化表结构（执行 DDL）
     * 3. 导入种子数据（教材版本、学科、知识点等基础数据）
     * 4. 创建默认管理员账号
     * 5. 初始化Redis缓存命名空间
     * 6. 创建Elasticsearch索引
     * 7. 创建对象存储路径
     * 8. 更新租户状态为"正常"
     */
    @Transactional
    public void initializeTenant(Long tenantId) {
        Tenant tenant = tenantMapper.selectById(tenantId);
        if (tenant == null) {
            throw new BusinessException(ErrorCode.TENANT_NOT_FOUND);
        }
        if (tenant.getStatus() != TenantStatus.PENDING_INIT) {
            throw new BusinessException(ErrorCode.TENANT_ALREADY_INITIALIZED);
        }
        
        try {
            // Step 1-2: 根据隔离级别创建数据空间
            switch (tenant.getIsolationLevel()) {
                case 2: // Schema隔离
                    createSchemaAndTables(tenant);
                    break;
                case 3: // DB隔离
                    createDatabaseAndTables(tenant);
                    break;
                // Row-Level 无需额外创建，共享表结构
            }
            
            // Step 3: 导入种子数据
            importSeedData(tenant);
            
            // Step 4: 创建默认管理员
            createDefaultAdmin(tenant);
            
            // Step 5-7: 初始化存储
            initializeStorage(tenant);
            
            // Step 8: 更新状态
            tenant.setStatus(TenantStatus.ACTIVE);
            tenantMapper.updateById(tenant);
            
            log.info("租户初始化完成: tenantId={}, code={}, level={}", 
                tenantId, tenant.getTenantCode(), tenant.getIsolationLevel());
                
        } catch (Exception e) {
            // 标记初始化异常
            tenant.setStatus(TenantStatus.INIT_ERROR);
            tenantMapper.updateById(tenant);
            
            log.error("租户初始化失败: tenantId={}", tenantId, e);
            throw new BusinessException(ErrorCode.TENANT_INIT_FAILED, e);
        }
    }
    
    /**
     * 创建独立Schema并初始化表结构
     */
    private void createSchemaAndTables(Tenant tenant) {
        String schemaName = "t_" + tenant.getTenantCode();
        
        // 创建Schema
        jdbcTemplate.execute("CREATE SCHEMA " + schemaName);
        
        // 执行DDL（使用Flyway管理Schema级别的迁移）
        Flyway flyway = Flyway.configure()
            .dataSource(dataSource)
            .schemas(schemaName)
            .locations("classpath:db/migration/tenant")
            .load();
        flyway.migrate();
        
        // 回写Schema名称
        tenant.setSchemaName(schemaName);
    }
}
```

### 5.3 租户冻结/解冻

```java
@Service
public class TenantLifecycleService {
    
    /**
     * 冻结租户
     * 效果：
     * - 所有 API 请求返回 403 + "租户已冻结"
     * - 定时任务停止执行
     * - 不影响数据，可随时解冻
     */
    public void freezeTenant(Long tenantId, String reason) {
        Tenant tenant = tenantMapper.selectById(tenantId);
        
        // 更新状态
        tenant.setStatus(TenantStatus.FROZEN);
        tenantMapper.updateById(tenant);
        
        // 清除租户缓存（强制所有在线用户重新鉴权）
        tenantRedisTemplate.clearTenantCache(tenantId);
        
        // 清除 TenantInfo 缓存
        tenantCacheService.evict(tenantId);
        
        // 记录审计日志
        auditLogService.log("TENANT_FREEZE", tenantId, reason);
        
        // 发送通知给租户管理员
        notifyTenantAdmins(tenantId, "您的账户已被冻结，原因：" + reason);
    }
    
    /**
     * 注销租户（软删除 → 数据保留期 → 物理删除）
     */
    @Transactional
    public void cancelTenant(Long tenantId, String reason) {
        Tenant tenant = tenantMapper.selectById(tenantId);
        
        // 1. 立即冻结，禁止访问
        freezeTenant(tenantId, "租户注销中");
        
        // 2. 标记为注销状态
        tenant.setStatus(TenantStatus.CANCELLED);
        tenant.setIsDeleted(1);
        tenantMapper.updateById(tenant);
        
        // 3. 注册延迟删除任务（30天后物理删除数据）
        scheduledTaskService.schedule(
            "TENANT_DATA_PURGE",
            tenantId,
            LocalDateTime.now().plusDays(30),
            Map.of("tenantId", tenantId, "isolationLevel", tenant.getIsolationLevel())
        );
        
        auditLogService.log("TENANT_CANCEL", tenantId, reason);
    }
    
    /**
     * 物理删除租户数据（由定时任务触发）
     */
    public void purgeTenantData(Long tenantId, Integer isolationLevel) {
        // 先二次确认租户已标记删除
        Tenant tenant = tenantMapper.selectById(tenantId);
        if (tenant == null || tenant.getIsDeleted() == 0) {
            log.warn("租户数据清理跳过: tenantId={}, 未标记删除", tenantId);
            return;
        }
        
        switch (isolationLevel) {
            case 1: // Row-Level：删除所有 tenant_id 的数据
                batchDeleteTenantRows(tenantId);
                break;
            case 2: // Schema：删除整个Schema
                jdbcTemplate.execute("DROP SCHEMA " + tenant.getSchemaName() + " CASCADE");
                break;
            case 3: // DB：删除整个数据库
                dropTenantDatabase(tenant.getDataSourceKey());
                break;
        }
        
        // 清理缓存、ES索引、OSS文件
        tenantRedisTemplate.clearTenantCache(tenantId);
        elasticsearchService.deleteTenantIndices(tenantId);
        ossService.deleteTenantFiles(tenantId);
        
        // 最终删除租户记录
        tenantMapper.physicalDelete(tenantId);
        
        log.info("租户数据物理删除完成: tenantId={}", tenantId);
    }
}
```

```json
        }
    }
```

```java
 * 在关键数据操作前校验数据归属

@Component
public class TenantDataGuard {
    
    /**
     * 校验数据是否属于当前租户
     * 用于防越权访问
     */
    public void checkOwnership(Long dataTenantId) {
        Long currentTenantId = TenantContext.getTenantId();
        
        // C端不检查
        if (currentTenantId == 0L) return;
        
        if (!currentTenantId.equals(dataTenantId)) {
            log.warn("租户数据越权访问: currentTenant={}, dataTenant={}", 
                currentTenantId, dataTenantId);
            throw new BusinessException(ErrorCode.CROSS_TENANT_ACCESS_DENIED);
        }
    }
    
    /**
     * 批量数据校验
     */
    public void checkBatchOwnership(List<? extends TenantAware> dataList) {
        Long currentTenantId = TenantContext.getTenantId();
        if (currentTenantId == 0L) return;
        
        boolean hasCrossTenant = dataList.stream()
            .anyMatch(data -> !currentTenantId.equals(data.getTenantId()));
        
        if (hasCrossTenant) {
            throw new BusinessException(ErrorCode.CROSS_TENANT_ACCESS_DENIED);
        }
    }
}
```

```java
@Service
public class TenantCacheService {
    
    private static final String CACHE_KEY = "tenant:info:";
    private static final Duration CACHE_TTL = Duration.ofMinutes(30);
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Autowired
    private TenantMapper tenantMapper;
    
    /**
     * 获取租户信息（多级缓存）
     * L1: 本地 Caffeine（30s TTL，1000条上限）
     * L2: Redis（30min TTL）
     * L3: MySQL
     */
    @Cacheable(value = "tenantInfo", key = "#tenantId", 
        cacheManager = "multiLevelCacheManager")
    public TenantInfo getTenantInfo(Long tenantId) {
        if (tenantId == 0L) {
            return TenantInfo.c端Default();
        }
        
        // 先查Redis
        String json = redisTemplate.opsForValue().get(CACHE_KEY + tenantId);
        if (json != null) {
            return JSON.parseObject(json, TenantInfo.class);
        }
        
        // 查库
        Tenant tenant = tenantMapper.selectById(tenantId);
        if (tenant == null) {
            throw new BusinessException(ErrorCode.TENANT_NOT_FOUND);
        }
        
        TenantInfo info = TenantInfo.from(tenant);
        
        // 写入Redis
        redisTemplate.opsForValue().set(
            CACHE_KEY + tenantId, 
            JSON.toJSONString(info), 
            CACHE_TTL);
        
        return info;
    }
    
    /**
     * 清除租户缓存
     */
    public void evict(Long tenantId) {
        redisTemplate.delete(CACHE_KEY + tenantId);
        // Caffeine 本地缓存也会自动失效
    }
}
```

```java
            .body(ApiResponse.error("TENANT_003", 
                "您的机构账户已过期（到期日：" + e.getExpireDate() + "），请联系管理员续费。"));
    }
    
    @ExceptionHandler(QuotaExceededException.class)
    public ResponseEntity<ApiResponse<QuotaInfo>> handleQuotaExceeded(QuotaExceededException e) {
        QuotaInfo quotaInfo = new QuotaInfo(e.getQuotaType(), e.getUsed(), e.getLimit());
        return ResponseEntity.status(HttpStatus.TOO_MANY_REQUESTS)
            .header("X-RateLimit-Limit", String.valueOf(e.getLimit()))
            .header("X-RateLimit-Used", String.valueOf(e.getUsed()))
            .header("X-RateLimit-Reset", e.getResetTime())
            .body(ApiResponse.error("QUOTA_001", "配额已用完", quotaInfo));
    }
}
```

### 12.2 租户巡检任务

```java
/**
 * 每日租户健康巡检
 * 检查项：
 * 1. 即将到期的租户（7天内）
 * 2. 配额使用率超80%的租户
 * 3. 异常状态的租户
 * 4. 数据源连接可用性
 */
@Component
@Slf4j
public class TenantHealthInspector extends TenantAwareScheduledTask {
    
    @Scheduled(cron = "0 0 8 * * ?")
    public void dailyInspection() {
        // 1. 检查即将到期的租户
        List<Tenant> expiringSoon = tenantService.listExpiringIn(7);
        expiringSoon.forEach(t -> {
            notificationService.notifyTenantOwner(t.getId(),
                "您的服务将在 " + t.getExpireTime() + " 到期，请及时续费。");
        });
        
        // 2. 检查配额告警
        List<QuotaAlert> alerts = quotaService.listHighUsageTenants(0.8);
        alerts.forEach(alert -> {
            log.warn("租户配额告警: tenantId={}, type={}, usage={}%", 
                alert.getTenantId(), alert.getQuotaType(), alert.getUsagePercent());
            monitoringService.recordAlert("QUOTA_HIGH", alert);
        });
        
        // 3. 检查独立数据源连通性
        List<Tenant> dbTenants = tenantService.listByIsolationLevel(3);
        dbTenants.forEach(t -> {
            try {
                dataSourceManager.validateConnection(t.getDataSourceKey());
            } catch (Exception e) {
                log.error("租户数据源不可达: tenantId={}", t.getId(), e);
                alertService.sendCriticalAlert("租户数据源故障: " + t.getTenantName());
            }
        });
    }
}
```

- [ ] Mapper XML 中手写 SQL 必须包含 `AND tenant_id = #{tenantId}`

```java
 * 租户隔离测试基类
 * 所有涉及租户数据的服务都应继承此类编写隔离测试

public abstract class TenantIsolationTestBase {

     */
    @Test

        TenantContext.runInTenant(TENANT_A, () -> {
            Long dataId = createTestData("租户A的数据");
            
            // 切换到租户B的上下文
            TenantContext.runInTenant(TENANT_B, () -> {
                // 尝试读取租户A的数据，应抛出异常
                assertThrows(CrossTenantAccessException.class, () -> {
                    dataService.getById(dataId);
                });
            });
            
            return null;
        });
    }
    
    /**
     * 测试：MyBatis拦截器自动过滤
     */
    @Test
    public void testAutoTenantFilter() {
        // 租户A创建10条数据
        TenantContext.runInTenant(TENANT_A, () -> {
            for (int i = 0; i < 10; i++) {
                createTestData("A-" + i);
            }
        });
        
        // 租户B创建5条数据
        TenantContext.runInTenant(TENANT_B, () -> {
            for (int i = 0; i < 5; i++) {
                createTestData("B-" + i);
            }
        });
        
        // 验证各租户只能看到自己的数据
        TenantContext.runInTenant(TENANT_A, () -> {

        });
        
        TenantContext.runInTenant(TENANT_B, () -> {

        });
    }
```

## 15. 性能考量

### 15.1 Row-Level 隔离性能优化

- **索引设计**：所有查询条件中 `tenant_id` 必须在索引最左前缀，避免全表扫描
- **分区表**：当 Row-Level 租户总数据量超过 5000 万行时，考虑按 `tenant_id` 做 LIST 分区
- **缓存层**：TenantInfo 本地缓存 30s + Redis 缓存 30min，减少库查询
- **批量操作**：批量插入时显式指定 tenant_id，避免逐行拦截器注入

### 15.2 Schema/DB 隔离性能考量

- **连接池管理**：独立DB的连接池按需创建，空闲超时释放（最大保留20个连接/租户）
- **Schema 切换**：使用 PostgreSQL 的 `SET search_path` 而非重建连接
- **DDL 同步**：使用 Flyway 按 Schema 级别管理迁移，新增表结构变更自动应用到所有租户 Schema
- **监控开销**：独立DB的监控指标按租户维度上报，避免指标爆炸
