# 服务端-学生学习行为隐式反馈信号采集与偏好融合建模引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

本引擎负责从学生用户在学习过程中的多维度交互行为中，自动采集隐式反馈信号（如内容停留时长、完成率、重放次数、跳过行为、收藏/分享/笔记触发、滚动深度等），对原始信号进行清洗、归一化、加权融合，输出统一格式的**多维度偏好分数向量**，为下游推荐系统、学情分析、个性化内容编排等模块提供实时、准确的用户偏好数据支撑。

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 信号采集覆盖率 | 覆盖客户端 15+ 类核心学习行为事件 |
| 实时性 | 偏好分数更新延迟 ≤ 5 秒（P95） |
| 扩展性 | 新增信号类型无需修改核心融合逻辑 |
| 准确性 | 偏好预测与用户显式反馈一致率 ≥ 75% |
| 吞吐量 | 支持 10,000+ 事件/秒峰值写入 |

### 1.3 适用范围

- 学生端 APP（iOS/Android）所有学习场景
- Web 端及小程序端学习行为采集
- 为推荐系统、学情画像、内容编排等下游模块提供偏好数据

### 1.4 与已有模块的关系

| 关联模块 | 关系说明 |
|----------|----------|
| 客户端埋点事件体系 | 事件源头，本引擎消费埋点事件流 |
| 用户学习画像与能力维度模型 | 下游消费者，偏好向量作为画像输入特征 |
| 内容推荐与个性化推荐引擎 | 下游消费者，偏好分数驱动推荐召回与排序 |
| 学习行为事件流处理引擎 | 本引擎复用其事件管道基础设施 |
| 学生学习风格识别服务 | 本引擎的偏好向量作为风格识别的输入 |
| 教育内容语义标签体系 | 偏好维度与内容标签维度对齐 |

## 2. 核心概念

### 2.1 隐式反馈信号分类

```
隐式反馈信号
├── 正向信号（Positive Signals）—— 表达兴趣/偏好
│   ├── 深度停留（Dwell ≥ 阈值）
│   ├── 高完成率（Completion ≥ 80%）
│   ├── 主动重放（Replay）
│   ├── 收藏行为（Bookmark）
│   ├── 分享行为（Share）
│   ├── 笔记触发（Note-taking）
│   ├── 点赞/好评（Like）
│   └── 多次回访（Revisit）
│
├── 负向信号（Negative Signals）—— 表达不感兴趣/困难
│   ├── 快速跳过（Skip, Dwell < 阈值）
│   ├── 低完成率（Completion < 30%）
│   ├── 提前退出（Early Exit）
│   ├── 关闭通知/免打扰（Dismiss）
│   └── 低互动率（No Interaction）
│
└── 中性信号（Neutral Signals）—— 辅助上下文
    ├── 学习时段（Time of Day）
    ├── 设备类型（Device Type）
    ├── 网络环境（Network Quality）
    ├── 学习疲劳度（Fatigue Level）
    └── 内容来源渠道（Source Channel）
```

### 2.2 偏好维度体系

偏好向量按以下维度组织，每个维度输出 `[0.0, 1.0]` 区间的分数：

| 维度分类 | 偏好维度 | 说明 |
|----------|----------|------|
| 学科偏好 | chinese / math / english / physics / chemistry / biology / history / geography / politics / it | 各学科兴趣度 |
| 内容类型偏好 | video / article / exercise / flashcard / interactive / audio | 内容形式偏好 |
| 难度偏好 | easy / medium / hard / challenge | 难度倾向 |
| 认知层级偏好 | remember / understand / apply / analyze / evaluate / create | 布鲁姆认知层级 |
| 学习时段偏好 | morning / afternoon / evening / night | 高效学习时段 |
| 学习时长偏好 | short_session(<10min) / medium_session(10-30min) / long_session(>30min) | 单次学习时长倾向 |
| 交互形式偏好 | read / watch / practice / discuss / reflect | 交互方式偏好 |

### 2.3 信号强度

每个信号携带一个 `strength` 值（`[-1.0, 1.0]`），表示该行为对偏好判断的指示强度：

```
strength = -1.0 —— 强负向（快速跳过 + 低完成率）
strength = -0.5 —— 中等负向（提前退出）
strength =  0.0 —— 中性（普通浏览）
strength = +0.5 —— 中等正向（收藏、笔记）
strength = +1.0 —— 强正向（多次重放 + 主动分享）
```

## 5. 偏好融合算法

### 5.1 融合公式

对每个偏好维度 $d$ 的每个取值 $v$，偏好分数计算如下：

$$
Score(d, v) = \frac{\sum_{i=1}^{N} w_i \cdot s_i \cdot \text{decay}(t_i)}{\sum_{i=1}^{N} w_i \cdot |\text{decay}(t_i)|}
$$

其中：
- $N$ = 与维度取值 $v$ 相关的信号数量
- $s_i$ = 第 $i$ 个信号的强度值 $[-1.0, 1.0]$
- $w_i$ = 第 $i$ 个信号的权重（考虑信号类型权重、疲劳度调整）
- $\text{decay}(t_i)$ = 基于时间的时间衰减因子

### 5.2 时间衰减函数

采用指数衰减：

$$
\text{decay}(t) = 2^{-\frac{\Delta t}{T_{1/2}}}
$$

其中 $\Delta t$ 为信号发生距今的时间差，$T_{1/2}$ 为信号类型的半衰期。

### 5.3 置信度计算

$$
\text{Confidence} = \min\left(1.0, \frac{\log(1 + N)}{\log(1 + N_{target})}\right) \times (1 - \frac{\sigma_{scores}}{2})
$$

- $N$ = 有效信号样本量
- $N_{target}$ = 目标样本量（默认 200）
- $\sigma_{scores}$ = 分数标准差（衡量一致性）

### 5.4 上下文调整因子

偏好分数会根据上下文因素进行动态调整：

| 上下文因子 | 调整逻辑 |
|------------|----------|
| 疲劳度 | fatigue > 0.7 时，正向信号强度 × 0.7 |
| 时段匹配 | 当前时段与偏好高峰匹配时，相关维度 × 1.1 |
| 连续负向 | 连续 3 个以上负向信号时，额外 × 1.15 强化负向 |
| 冷启动 | 样本量 < 10 时，注入先验分布（全局均值） |

```java
/**
 * 规则驱动的信号提取器
 * 根据配置的提取规则，从行为事件中提取隐式反馈信号
 */
@Component
public class RuleBasedSignalExtractor implements SignalExtractor {

    private final SignalRuleRegistry ruleRegistry;
    private final ExpressionEvaluator expressionEvaluator; // SpEL or similar

    /**
     * 从行为事件中提取信号
     * @param event 行为事件
     * @return 提取到的信号列表（一个事件可能触发多个信号）
     */
    @Override
    public List<ImplicitSignal> extract(BehaviorEvent event) {
        List<ImplicitSignal> signals = new ArrayList<>();
        
        // 获取与事件类型匹配的所有激活规则
        List<SignalRule> matchingRules = ruleRegistry.getRulesByEventType(
            event.getEventType(), 
            event.getEventCategory()
        );
        
        for (SignalRule rule : matchingRules) {
            // 条件校验
            if (!rule.evaluateConditions(event)) {
                continue;
            }
            
            // 计算信号强度
            double strength = expressionEvaluator.evaluate(
                rule.getStrengthFormula(),
                event.toFormulaContext()
            );
            
            // 上下文调整
            double adjustedStrength = applyContextAdjustments(strength, event);
            
            // 构建信号
            ImplicitSignal signal = ImplicitSignal.builder()
                .signalId(generateSignalId(event, rule))
                .userId(event.getUserId())
                .contentId(event.getContentId())
                .signalType(rule.getSignalType())
                .category(rule.getCategory())
                .strength(clamp(adjustedStrength, -1.0, 1.0))
                .weight(calculateWeight(rule, event))
                .subject(event.getSubject())
                .contentType(event.getContentType())
                .difficulty(event.getDifficulty())
                .cognitiveLevel(event.getCognitiveLevel())
                .timeOfDay(extractTimeOfDay(event.getTimestamp()))
                .sessionBucket(extractSessionBucket(event))
                .fatigueLevel(extractFatigueLevel(event))
                .expiryTs(calculateExpiry(event.getTimestamp(), rule.getDecayHalflifeHours()))
                .createdTs(System.currentTimeMillis())
                .build();
            
            signals.add(signal);
        }
        
        return signals;
    }
    
    /**
     * 上下文调整：疲劳度、连续负向等
     */
    private double applyContextAdjustments(double strength, BehaviorEvent event) {
        double adjusted = strength;
        
        // 疲劳度调整：高疲劳时降低正向信号强度
        Double fatigue = event.getPayloadValue("fatigueLevel");
        if (fatigue != null && fatigue > 0.7 && strength > 0) {
            adjusted *= (1.0 - fatigue * 0.3);
        }
        
        return adjusted;
    }
    
    private double clamp(double value, double min, double max) {
        return Math.max(min, Math.min(max, value));
    }
}
```

### 7.3 偏好融合引擎核心代码

```java
/**
 * 偏好融合引擎
 * 将多条隐式信号融合为统一的偏好分数向量
 */
@Component
public class PreferenceFusionEngine {

    private final SignalRepository signalRepository;
    private final PreferenceRepository preferenceRepository;
    private final TimeDecayCalculator decayCalculator;
    private final ConfidenceCalculator confidenceCalculator;

    /**
     * 增量更新用户偏好向量
     * 在新信号到达时触发，避免全量重算
     *
     * @param userId 用户ID
     * @param newSignals 新到达的信号列表
     */
    @Transactional
    public void updatePreference(Long userId, List<ImplicitSignal> newSignals) {
        if (newSignals.isEmpty()) return;
        
        // 1. 加载当前偏好向量
        PreferenceVector current = preferenceRepository.findById(userId)
            .orElseGet(() -> PreferenceVector.empty(userId));
        
        // 2. 按维度分组新信号
        Map<PreferenceDimension, Map<String, List<ImplicitSignal>>> groupedSignals = 
            groupSignalsByDimension(newSignals);
        
        // 3. 对每个维度进行增量更新
        for (Map.Entry<PreferenceDimension, Map<String, List<ImplicitSignal>>> dimEntry : 
             groupedSignals.entrySet()) {
            PreferenceDimension dimension = dimEntry.getKey();
            
            for (Map.Entry<String, List<ImplicitSignal>> valueEntry : 
                 dimEntry.getValue().entrySet()) {
                String dimensionValue = valueEntry.getKey();
                List<ImplicitSignal> signals = valueEntry.getValue();
                
                // 增量更新该维度取值的分数
                updateDimensionScore(current, dimension, dimensionValue, signals);
            }
        }
        
        // 4. 更新置信度
        current.setConfidenceScore(
            confidenceCalculator.calculate(current.getSampleSize(), current)
        );
        
        // 5. 保存
        current.setUpdatedTs(System.currentTimeMillis());
        current.incrementVersion();
        preferenceRepository.save(current);
        
        // 6. 发布偏好更新事件（供下游消费者订阅）
        publishPreferenceUpdateEvent(userId, current);
    }
    
    /**
     * 增量更新单个维度取值的分数
     * 使用指数移动平均(EMA)进行平滑更新
     */
    private void updateDimensionScore(
            PreferenceVector vector, 
            PreferenceDimension dimension, 
            String value, 
            List<ImplicitSignal> newSignals) {
        
        double currentScore = vector.getScore(dimension, value);
        long now = System.currentTimeMillis();
        
        // 计算新信号的加权平均强度
        double weightedSum = 0;
        double totalWeight = 0;
        for (ImplicitSignal signal : newSignals) {
            double decay = decayCalculator.calculate(signal.getCreatedTs(), now, 
                signal.getDecayHalflifeHours());
            double w = signal.getWeight() * decay;
            weightedSum += signal.getStrength() * w;
            totalWeight += Math.abs(w);
        }
        
        if (totalWeight == 0) return;
        
        double newSignalScore = weightedSum / totalWeight;
        
        // EMA 平滑：alpha 控制新旧分数的混合比例
        // 样本量越大，alpha 越小（历史权重越高，更稳定）
        double alpha = Math.max(0.1, 1.0 / (1.0 + Math.sqrt(vector.getSampleSize())));
        double fusedScore = alpha * newSignalScore + (1 - alpha) * currentScore;
        
        vector.setScore(dimension, value, clamp01(fusedScore));
        vector.addSampleSize(newSignals.size());
    }
    
    private double clamp01(double v) {
        return Math.max(0.0, Math.min(1.0, v));
    }
    
    /**
     * 冷启动处理：样本不足时注入先验
     */
    private void applyColdStartPrior(PreferenceVector vector) {
        if (vector.getSampleSize() < 10) {
            // 注入全局均值作为先验
            Map<String, Double> globalAvg = preferenceRepository.getGlobalAverages();
            double priorWeight = 1.0 - (vector.getSampleSize() / 10.0);
            
            for (PreferenceDimension dim : PreferenceDimension.values()) {
                Map<String, Double> userScores = vector.getScores(dim);
                for (Map.Entry<String, Double> entry : userScores.entrySet()) {
                    double prior = globalAvg.getOrDefault(
                        dim.name() + ":" + entry.getKey(), 0.5
                    );
                    double blended = (1 - priorWeight) * entry.getValue() 
                                   + priorWeight * prior;
                    entry.setValue(blended);
                }
            }
        }
    }
}
```

### 7.4 时间衰减计算器

```java
/**
 * 时间衰减计算器
 * 使用指数衰减模型，信号的影响力随时间递减
 */
@Component
public class TimeDecayCalculator {

    /**
     * 计算时间衰减因子
     * @param signalTimestamp 信号发生时间
     * @param currentTime 当前时间
     * @param halfLifeHours 半衰期（小时）
     * @return 衰减因子 [0, 1]
     */
    public double calculate(long signalTimestamp, long currentTime, int halfLifeHours) {
        long deltaMs = currentTime - signalTimestamp;
        if (deltaMs <= 0) return 1.0;
        
        double deltaHours = deltaMs / (3600.0 * 1000.0);
        return Math.pow(0.5, deltaHours / halfLifeHours);
    }
    
    /**
     * 批量计算衰减并返回有效信号
     */
    public List<WeightedSignal> applyDecay(
            List<ImplicitSignal> signals, long currentTime) {
        return signals.stream()
            .map(s -> {
                double decay = calculate(s.getCreatedTs(), currentTime, 
                    s.getDecayHalflifeHours());
                return new WeightedSignal(s, decay);
            })
            .filter(ws -> ws.getDecayFactor() > 0.01) // 过滤掉衰减殆尽的信号
            .collect(Collectors.toList());
    }
}
```

### 7.5 Kafka 消费者

```java
/**
 * 行为事件消费者
 * 从 Kafka 消费原始行为事件，提取信号，触发偏好融合更新
 */
@Component
@Slf4j
public class BehaviorEventConsumer {

    private final SignalExtractor signalExtractor;
    private final PreferenceFusionEngine fusionEngine;
    private final SignalRepository signalRepository;
    private final EventArchiveRepository eventArchiveRepository;

    @KafkaListener(
        topics = "${preference.kafka.topic:learning-behavior-events}",
        groupId = "${preference.kafka.group:preference-fusion-group}",
        containerFactory = "kafkaListenerContainerFactory"
    )
    public void onEvent(List<ConsumerRecord<String, byte[]>> records, 
                        Acknowledgment ack) {
        // 批量消费，提高吞吐
        Map<Long, List<ImplicitSignal>> signalsByUser = new HashMap<>();
        
        for (ConsumerRecord<String, byte[]> record : records) {
            try {
                BehaviorEvent event = deserialize(record.value());
                
                // 归档原始事件
                eventArchiveRepository.saveAsync(event);
                
                // 提取信号
                List<ImplicitSignal> signals = signalExtractor.extract(event);
                if (!signals.isEmpty()) {
                    // 持久化信号
                    signalRepository.saveAll(signals);
                    
                    // 按用户分组
                    signalsByUser
                        .computeIfAbsent(event.getUserId(), k -> new ArrayList<>())
                        .addAll(signals);
                }
                
            } catch (Exception e) {
                log.error("Failed to process event from partition {} offset {}", 
                    record.partition(), record.offset(), e);
                // 发送到死信队列
                sendToDLQ(record, e);
            }
        }
        
        // 批量触发偏好融合更新
        signalsByUser.forEach((userId, signals) -> {
            try {
                fusionEngine.updatePreference(userId, signals);
            } catch (Exception e) {
                log.error("Failed to update preference for user {}", userId, e);
            }
        });
        
        ack.acknowledge();
    }
}
```

```java
/**
 * 偏好查询服务
 * 提供偏好向量的读取、维度查询、排行榜等API
 */
@Service
@Cacheable(cacheNames = "preference", key = "#userId")
public class PreferenceService {

    private final PreferenceRepository preferenceRepository;
    private final RedisTemplate<String, PreferenceVector> redisTemplate;

    /**
     * 获取用户完整偏好向量
     * 优先从 Redis 缓存读取
     */
    public PreferenceVector getPreference(Long userId) {
        String cacheKey = "pref:user:" + userId;
        PreferenceVector cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return cached;
        }
        
        PreferenceVector pref = preferenceRepository.findById(userId)
            .orElseGet(() -> PreferenceVector.defaultVector(userId));
        
        // 缓存 5 分钟
        redisTemplate.opsForValue().set(cacheKey, pref, Duration.ofMinutes(5));
        return pref;
    }
    
    /**
     * 获取特定维度的偏好排行
     */
    public List<DimensionScore> getRanking(Long userId, String dimension, int topN) {
        PreferenceVector pref = getPreference(userId);
        Map<String, Double> scores = pref.getScores(
            PreferenceDimension.valueOf(dimension.toUpperCase())
        );
        
        return scores.entrySet().stream()
            .sorted(Map.Entry.<String, Double>comparingByValue().reversed())
            .limit(topN)
            .map(e -> new DimensionScore(e.getKey(), e.getValue(), 
                pref.getConfidenceScore()))
            .collect(Collectors.toList());
    }
    
    /**
     * 判断用户对某维度取值的偏好是否显著
     */
    public boolean isSignificantPreference(
            Long userId, String dimension, String value, 
            double threshold) {
        PreferenceVector pref = getPreference(userId);
        double score = pref.getScore(
            PreferenceDimension.valueOf(dimension.toUpperCase()), value
        );
        return score >= threshold && pref.getConfidenceScore() >= 0.5;
    }
}
```

## 9. 错误处理

### 9.1 错误码定义

| 错误码 | HTTP Status | 说明 | 处理建议 |
|--------|-------------|------|----------|
| PREF_001 | 400 | 事件格式不合法 | 客户端修正后重试 |
| PREF_002 | 400 | 事件类型未注册 | 在配置表中注册事件类型 |
| PREF_003 | 404 | 用户偏好不存在 | 返回默认偏好向量 |
| PREF_004 | 409 | 偏好向量版本冲突 | 客户端重试或读取最新 |
| PREF_005 | 422 | 信号规则配置错误 | 校验规则JSON格式 |
| PREF_006 | 429 | 上报频率超限 | 客户端降低上报频率 |
| PREF_500 | 500 | 融合计算内部错误 | 记录日志，降级返回缓存值 |
| PREF_501 | 503 | 依赖服务不可用 | 降级返回上次缓存值 |

```java
/**

@Component
@Slf4j
public class PreferenceFallbackHandler {

    @Autowired
    private RedisTemplate<String, PreferenceVector> redisTemplate;

    /**
     * 降级策略链：
     * 1. 尝试 Redis 缓存（即使过期）
     * 2. 尝试本地缓存（Caffeine）
     * 3. 返回全局默认偏好
     */
    public PreferenceVector fallback(Long userId) {

        String cacheKey = "pref:user:" + userId;

        if (cached != null) {
            log.warn("Returning stale cache for user {} (fallback)", userId);
            return cached.markAsStale();
        }
        
        // 2. 返回默认偏好
        log.warn("Returning default preference for user {} (fallback)", userId);
        return PreferenceVector.defaultVector(userId);
    }
}
```

```java
        eventsConsumed.increment();
    }
    
    public Timer.Sample startFusionTimer() {
        return Timer.start(registry);
    }
    
    public void recordFusionComplete(Timer.Sample sample) {
        sample.stop(fusionLatency);
    }
}
```

## 16. 总结

本详细设计文档描述了**学生学习行为隐式反馈信号采集与偏好融合建模引擎**的完整实现方案。核心设计要点：

1. **规则驱动的信号提取**：通过可配置的规则引擎从行为事件中提取多类型信号，无需修改代码即可扩展新信号类型。

2. **EMA 平滑融合算法**：使用指数移动平均进行增量偏好更新，兼顾历史稳定性和新信号响应速度，冷启动时注入先验分布。

3. **多维度偏好向量**：覆盖学科、内容类型、难度、认知层级、学习时段等 7 大维度，为推荐系统和个性化服务提供丰富输入。

4. **高性能架构**：Kafka 批量消费 + Redis 多级缓存 + 异步写入，支撑万级 QPS 事件处理和毫秒级偏好查询。

5. **隐私与合规**：严格限定学习场景数据采集，支持用户数据查看、导出和删除，符合未成年人保护法规。
