# 服务端-古诗文鉴赏解析与文言文翻译辅助服务 - 详细设计

## 1. 模块概述

### 1.1 功能定位

本服务负责古诗文专项学习模块的后端核心能力，提供古诗文/文言文的结构化解析、逐句翻译、鉴赏批注、背诵检测数据支撑、文学常识关联以及 AI 辅导上下文编排等能力。面向小学至高中全学段，按年级适配鉴赏深度与表达方式。

### 1.2 服务边界

| 范围内 | 范围外 |
|--------|--------|
| 古诗文/文言文元数据管理与检索 | 古诗文页面 UI 渲染（客户端职责） |
| 逐句翻译、注释、赏析批注生成与存储 | 背诵语音识别（ASR 服务职责） |
| 文学常识、作者生平、写作背景关联 | 会员权益校验（用户额度服务职责） |
| AI 辅导 Prompt 上下文编排 | 消息推送（消息服务职责） |
| 背诵进度与掌握度数据维护 | 通用知识点图谱（知识点服务职责） |
| 文言文实词/虚词/句式自动标注 | |

### 3.3 掌握度衰减模型

```python
# 基于艾宾浩斯遗忘曲线的掌握度衰减
# R = e^(-t/S)，其中 t 为距上次复习的天数，S 为记忆稳定性
# 记忆稳定性随复习次数增长：S = S0 * (1 + α * review_count)

MEMORY_STABILITY_BASE = 1.0    # 初始稳定性（天）
MEMORY_STABILITY_GROWTH = 0.5  # 每次复习增加的稳定性
MASTERY_DECAY_THRESHOLD = 70   # 低于此值触发复习

def calculate_mastery(current_mastery, last_review_days_ago, review_count):
    stability = MEMORY_STABILITY_BASE * (1 + MEMORY_STABILITY_GROWTH * review_count)
    retention = math.exp(-last_review_days_ago / stability)
    return current_mastery * retention

def calculate_next_review_date(mastery, review_count):
    stability = MEMORY_STABILITY_BASE * (1 + MEMORY_STABILITY_GROWTH * review_count)
    # 计算掌握度降到阈值所需天数
    if mastery <= 0:
        return datetime.now()
    days_until_threshold = -stability * math.log(MASTERY_DECAY_THRESHOLD / 100 / (mastery / 100))
    days_until_threshold = max(1, min(days_until_threshold, 30))  # 限制在 1-30 天
    return datetime.now() + timedelta(days=days_until_threshold)
```
