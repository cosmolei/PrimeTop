# 客户端无障碍访问与辅助功能系统 - 详细设计

## 1. 概述

### 1.1 背景

启硕 PrimeTop 作为面向 K12 全学段学生的教育产品，其用户群体涵盖广泛的年龄和能力层次。根据《信息技术 互联网内容无障碍可访问性技术要求》（GB/T 37668-2019）及 WCAG 2.1 AA 标准，教育类应用应确保所有学生——包括视力障碍、色觉异常、听力障碍、运动障碍及认知差异的学生——均能有效使用产品核心功能。

本系统基于 Flutter 框架，构建统一的无障碍基础设施层，覆盖屏幕阅读器适配、语义标注、色彩无障碍、字体缩放、动画控制、键盘/开关导航、语音控制等能力。

### 1.2 设计目标

1. **WCAG 2.1 AA 合规**：核心学习流程（AI问答、拍题、错题本、同步课堂）达到 AA 级
2. **平台原生能力集成**：完整支持 Android TalkBack 和 iOS VoiceOver
3. **分龄无障碍策略**：不同学段提供差异化的辅助功能默认配置
4. **渐进增强**：辅助功能不影响普通用户的使用体验
5. **可测试**：提供自动化无障碍检测工具和测试用例

### 1.3 适用范围

- Flutter 客户端（Android / iOS）
- 涉及 UI 组件库、页面路由、渲染引擎、手势系统的全量适配
- 不覆盖 Web 端和小程序端（另行设计）

### 4.1 A11ySettingsProvider

全局辅助功能配置管理，基于 Riverpod。

```dart
/// 全局辅助功能设置 Provider
@riverpod
class A11ySettingsNotifier extends _$A11ySettingsNotifier {
  static const _storageKey = 'a11y_settings';

  @override
  A11ySettings build() {
    _loadFromStorage();
    _detectSystemSettings();
    return const A11ySettings();
  }

  /// 从本地存储恢复设置
  Future<void> _loadFromStorage() async {
    final prefs = await SharedPreferences.getInstance();
    final json = prefs.getString(_storageKey);
    if (json != null) {
      final decoded = jsonDecode(json) as Map<String, dynamic>;
      state = A11ySettings.fromJson(decoded);
    }
  }

  /// 检测系统辅助功能状态
  void _detectSystemSettings() {
    // 监听系统屏幕阅读器状态
    final accessibilityStatus = MediaQuery.of(context).accessibleNavigation;
    // 监听系统字体缩放
    final textScale = MediaQuery.of(context).textScaler;
    // 监听系统减少动画偏好
    final disableAnimations = MediaQuery.of(context).disableAnimations;
    // 监听系统高对比度偏好
    final highContrast = MediaQuery.of(context).highContrast;

    state = state.copyWith(
      screenReaderActive: accessibilityStatus,
      fontScale: textScale.textScaleFactor,
      reduceMotion: disableAnimations,
      highContrastEnabled: highContrast,
    );
  }

  /// 更新设置并持久化
  Future<void> updateSettings(A11ySettings newSettings) async {
    state = newSettings;
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_storageKey, jsonEncode(newSettings.toJson()));
  }

  /// 重置为默认设置
  Future<void> resetToDefaults() async {
    // 保留系统检测的值，仅重置用户自定义项
    final systemDefaults = A11ySettings(
      screenReaderActive: state.screenReaderActive,
      reduceMotion: state.reduceMotion,
      highContrastEnabled: state.highContrastEnabled,
      fontScale: state.fontScale,
    );
    state = systemDefaults;
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(_storageKey);
  }
}
```

### 4.3 FocusManagementSystem

焦点管理系统，控制 Tab 导航顺序和焦点行为。

```dart
/// 焦点管理系统
class A11yFocusManager {
  static final _focusNodes = <String, FocusNode>{};
  static final _focusHistory = <String>[];
  static const _maxHistory = 50;

  /// 注册焦点节点
  static FocusNode register(String key) {
    return _focusNodes.putIfAbsent(key, () => FocusNode(debugLabel: key));
  }

  /// 释放焦点节点
  static void dispose(String key) {
    _focusNodes[key]?.dispose();
    _focusNodes.remove(key);
  }

  /// 请求焦点
  static void requestFocus(String key) {
    _focusHistory.add(key);
    if (_focusHistory.length > _maxHistory) {
      _focusHistory.removeAt(0);
    }
    _focusNodes[key]?.requestFocus();
  }

  /// 恢复上一个焦点
  static void restorePreviousFocus() {
    if (_focusHistory.length >= 2) {
      _focusHistory.removeLast(); // 移除当前
      final previous = _focusHistory.last;
      _focusNodes[previous]?.requestFocus();
    }
  }

  /// 创建有序焦点组（用于表单等需要固定Tab序的场景）
  static List<FocusNode> createOrderedGroup(List<String> keys) {
    return keys.map((key) => register(key)).toList();
  }
}

/// 焦点陷阱（用于模态对话框，防止焦点逃逸）
class FocusTrap extends StatefulWidget {
  final Widget child;
  const FocusTrap({super.key, required this.child});

  @override
  State<FocusTrap> createState() => _FocusTrapState();
}

class _FocusTrapState extends State<FocusTrap> {
  final _focusScopeNode = FocusScopeNode(debugLabel: 'FocusTrap');

  @override
  void dispose() {
    _focusScopeNode.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return FocusScope(
      node: _focusScopeNode,
      autofocus: true,
      child: widget.child,
    );
  }
}
```

```dart
/// 高对比度色彩引擎
class HighContrastEngine {
  /// 标准高对比度调色板
  static const _standardPalette = _HighContrastPalette(
    background: Color(0xFFFFEE58), // 黄底
    foreground: Color(0xFF000000), // 黑字
    primary: Color(0xFF0D47A1),    // 深蓝
    secondary: Color(0xFFB71C1C),  // 深红
    surface: Color(0xFFFFF9C4),    // 浅黄
    error: Color(0xFFD50000),      // 红
    success: Color(0xFF1B5E20),    // 深绿
    focus: Color(0xFF0000FF),      // 蓝（焦点指示器）
  );

  /// 黑底白字调色板
  static const _darkPalette = _HighContrastPalette(
    background: Color(0xFF000000),
    foreground: Color(0xFFFFFFFF),
    primary: Color(0xFF42A5F5),
    secondary: Color(0xFFEF5350),
    surface: Color(0xFF212121),
    error: Color(0xFFFF5252),
    success: Color(0xFF66BB6A),
    focus: Color(0xFFFFFF00),
  );

  /// 获取当前高对比度调色板
  static _HighContrastPalette getPalette(HighContrastTheme theme) {
    switch (theme) {
      case HighContrastTheme.standard:
        return _standardPalette;
      case HighContrastTheme.whiteOnBlack:
      case HighContrastTheme.blackOnWhite:
        return theme == HighContrastTheme.whiteOnBlack
            ? _darkPalette
            : _HighContrastPalette(
                background: const Color(0xFFFFFFFF),
                foreground: const Color(0xFF000000),
                primary: const Color(0xFF1565C0),
                secondary: const Color(0xFFC62828),
                surface: const Color(0xFFF5F5F5),
                error: const Color(0xFFD32F2F),
                success: const Color(0xFF2E7D32),
                focus: const Color(0xFF0000FF),
              );
    }
  }

  /// 对比度检测（WCAG AA 要求 4.5:1）
  static bool meetsWcagAA(Color foreground, Color background) {
    final ratio = _contrastRatio(foreground, background);
    return ratio >= 4.5;
  }

  /// 计算对比度
  static double _contrastRatio(Color a, Color b) {
    final luminanceA = _relativeLuminance(a);
    final luminanceB = _relativeLuminance(b);
    final lighter = luminanceA > luminanceB ? luminanceA : luminanceB;
    final darker = luminanceA > luminanceB ? luminanceB : luminanceA;
    return (lighter + 0.05) / (darker + 0.05);
  }

  static double _relativeLuminance(Color color) {
    // sRGB 转线性 RGB，计算相对亮度
    final r = _linearize(color.red / 255.0);
    final g = _linearize(color.green / 255.0);
    final b = _linearize(color.blue / 255.0);
    return 0.2126 * r + 0.7152 * g + 0.0722 * b;
  }

  static double _linearize(double value) {
    return value <= 0.03928
        ? value / 12.92
        : pow((value + 0.055) / 1.055, 2.4).toDouble();
  }
}
```

### 4.5 ColorBlindnessEngine

色觉异常适配引擎，为不同色觉类型提供颜色映射。

```dart
/// 色觉异常适配引擎
class ColorBlindnessEngine {
  /// 将颜色转换为色觉安全颜色
  static Color adapt(Color original, ColorBlindnessType type) {
    if (type == ColorBlindnessType.none) return original;

    // 使用 Brettel 模拟矩阵进行颜色变换
    final matrix = _simulationMatrices[type]!;
    final r = original.red.toDouble();
    final g = original.green.toDouble();
    final b = original.blue.toDouble();

    final newR = (matrix[0] * r + matrix[1] * g + matrix[2] * b).clamp(0, 255);
    final newG = (matrix[3] * r + matrix[4] * g + matrix[5] * b).clamp(0, 255);
    final newB = (matrix[6] * r + matrix[7] * g + matrix[8] * b).clamp(0, 255);

    return Color.fromARGB(original.alpha, newR.toInt(), newG.toInt(), newB.toInt());
  }

  /// Daltonize 算法：在保持色彩信息的同时增强可辨识度
  static Color daltonize(Color original, ColorBlindnessType type) {
    final simulated = adapt(original, type);
    final error = Color.fromARGB(
      original.alpha,
      (original.red - simulated.red).abs().toInt(),
      (original.green - simulated.green).abs().toInt(),
      (original.blue - simulated.blue).abs().toInt(),
    );

    // 将误差重新分配到可辨识的通道
    final shiftR = (error.red * 0.5 + error.green * 0.5).toInt();
    final shiftG = (error.green * 0.5 + error.blue * 0.5).toInt();

    return Color.fromARGB(
      original.alpha,
      (original.red + shiftR).clamp(0, 255),
      (original.green + shiftG).clamp(0, 255),
      original.blue,
    );
  }

  /// 色盲友好调色板（用于图表和状态指示器）
  static const colorBlindSafePalette = [
    Color(0xFF0072B2), // 蓝
    Color(0xFFE69F00), // 橙
    Color(0xFF009E73), // 绿
    Color(0xFFCC79A7), // 粉
    Color(0xFF56B4E9), // 天蓝
    Color(0xFFD55E00), // 朱红
    Color(0xFFF0E442), // 黄
    Color(0xFF000000), // 黑
  ];

  /// 模拟矩阵（Brettel 1997）
  static const _simulationMatrices = {
    ColorBlindnessType.protanopia: [
      0.152286, 1.052583, -0.204868,
      0.114503, 0.786281, 0.099216,
      -0.003882, -0.048116, 1.051998,
    ],
```

```dart
/// 动画控制引擎
class AnimationControlEngine {
  /// 根据辅助功能设置调整动画时长
  static Duration adjustDuration(
    Duration original,
    A11ySettings settings,
  ) {
    if (settings.reduceMotion) {
      return Duration.zero; // 禁用动画
    }
    return original;
  }

  /// 创建无障碍友好的动画曲线
  static Curve adjustCurve(Curve original, A11ySettings settings) {
    if (settings.reduceMotion) {
      return Curves.linear; // 瞬时完成
    }
    return original;
  }

  /// 包裹动画组件，自动处理减少动画
  static Widget animatedWrapper({
    required Widget Function(AnimationController controller) builder,
    required Duration duration,
    required A11ySettings settings,
    required TickerProvider vsync,
  }) {
    if (settings.reduceMotion) {
      // 直接显示最终状态，无动画
      return builder(
        AnimationController(vsync: vsync, duration: Duration.zero)
          ..value = 1.0,
      );
    }
    return _AnimatedWrapperBuilder(
      builder: builder,
      duration: duration,
      vsync: vsync,
    );
  }
```

### 4.7 A11yAnnouncer

屏幕阅读器播报管理器。

```dart
/// 屏幕阅读器播报管理器
class A11yAnnouncer {
  static final _announcer = SemanticsService();

  /// 播报消息去重缓存（避免重复播报相同内容）
  static final _recentAnnouncements = <String, DateTime>{};
  static const _dedupWindow = Duration(seconds: 3);

  /// 礼貌播报（等待当前播报完成）
  static Future<void> announce(
    String message, {
    String? contextKey,
    A11yAnnouncementPriority priority = A11yAnnouncementPriority.polite,
  }) async {
    // 去重检查
    if (contextKey != null) {
      final lastTime = _recentAnnouncements[contextKey];
      if (lastTime != null &&
          DateTime.now().difference(lastTime) < _dedupWindow) {
        return;
      }
      _recentAnnouncements[contextKey] = DateTime.now();
    }

    await _announcer.announce(
      message,
      textDirection: TextDirection.ltr,
    );
  }

  /// 常用播报方法
  static Future<void> announcePageChange(String pageName) =>
      announce('已进入$pageName');

  static Future<void> announceLoading(String context) =>
      announce('正在加载$context，请稍候');

  static Future<void> announceLoadingComplete(String context) =>
      announce('$context加载完成');

  static Future<void> announceError(String error) =>
      announce('出错了：$error', priority: A11yAnnouncementPriority.assertive);

  static Future<void> announceProgress(int current, int total, String unit) =>
      announce('$unit $current / $total', contextKey: 'progress_$unit');

  static Future<void> announceResult(String description) =>
      announce(description);

  static Future<void> announceToggle(String name, bool value) =>
      announce('$name 已${value ? "开启" : "关闭"}');
}
```

```dart
    return LatexDescriptionGenerator.describe(latex);
```

## 10. 错误处理

### 10.1 错误码定义

| 错误码 | 含义 | 处理策略 |
|--------|------|---------|
| `A11Y_001` | 辅助功能设置保存失败 | 提示用户重试，保留内存中的临时配置 |
| `A11Y_002` | 无障碍描述内容不存在 | 降级为自动生成的描述（标记为自动生成） |
| `A11Y_003` | 屏幕阅读器通信异常 | 静默降级，保留视觉焦点指示 |
| `A11Y_004` | 字体缩放超出安全范围 | 限制在 0.8x~2.0x 范围内 |
| `A11Y_005` | 高对比度主题加载失败 | 降级为系统默认高对比度 |
| `A11Y_006` | 焦点管理器初始化失败 | 使用 Flutter 默认焦点行为 |
| `A11Y_007` | TTS 播报服务不可用 | 静默跳过播报，记录日志 |

### 10.2 降级策略

```dart
/// 无障碍降级管理器
class A11yDegradationManager {
  /// 降级层级
  static const _degradationLevels = [
    'full_a11y',        // 完整无障碍功能
    'reduced_a11y',     // 减少无障碍功能（关闭自定义播报）
    'basic_a11y',       // 基础无障碍（仅语义标注）
    'system_only',      // 仅系统级无障碍（Flutter默认）
  ];

  String _currentLevel = 'full_a11y';

  /// 检测并执行降级
  void checkAndDegrade(String failedComponent) {
    switch (failedComponent) {
      case 'announcer':
        if (_currentLevel == 'full_a11y') {
          _currentLevel = 'reduced_a11y';
          _logDegradation('announcer', 'reduced_a11y');
        }
        break;
      case 'high_contrast':
        // 高对比度降级为系统主题
        _logDegradation('high_contrast', 'system_only');
        break;
      case 'focus_manager':
        // 焦点管理降级为 Flutter 默认
        _currentLevel = 'basic_a11y';
        _logDegradation('focus_manager', 'basic_a11y');
        break;
    }
  }

  void _logDegradation(String component, String newLevel) {
    log.warning('A11y degradation: $component → $newLevel');
    // 上报降级事件到监控
    AnalyticsService.trackEvent('a11y_degradation', {
      'component': component,
      'new_level': newLevel,
    });
  }
}
```

## 13. 跨模块集成规范

### 13.1 与客户端组件库集成

- 所有新组件必须通过 `A11yAuditTool` 检测才能合入
- 组件库基类 `PrimeTopWidget` 内置辅助功能感知能力
- 组件文档必须包含无障碍使用说明

### 13.2 与富文本渲染引擎集成

- 数学公式的 `description` 字段由内容生产管线提供
- 降级方案：自动生成描述（`LatexDescriptionGenerator`）
- 图表渲染后自动附加 `Semantics` 节点

### 13.3 与 SSE 流式响应引擎集成

- AI 流式回答每完成一段，触发 `A11yAnnouncer.announce`
- 流式渲染期间焦点保持在回答区域
- 完成时播报总结信息

### 13.4 与护眼模式系统协同

- 高对比度模式与护眼色温可叠加生效
- 色温调节后的颜色仍需满足 WCAG 对比度
- 护眼模式不覆盖高对比度的焦点指示器颜色

### 13.5 与学习数据可视化引擎集成

- 所有图表提供 `chartDescription` 文本描述
- 色觉安全调色板作为图表默认配色
- 数据变化时播报摘要（如"你的数学正确率从60%提升到75%"）
