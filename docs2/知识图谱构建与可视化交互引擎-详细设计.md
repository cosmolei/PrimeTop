# 知识图谱构建与可视化交互引擎 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

知识图谱构建与可视化交互引擎是 PrimeTop 平台的跨模块基础设施，负责将知识点、考点、教材章节、前置依赖等结构化关系构建为图（Graph）数据模型，并在客户端提供可交互的可视化呈现。该引擎为「考点梳理」「同步课堂」「学情分析」「自适应学习」等上层模块提供统一的图谱数据服务和交互组件。

### 1.2 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 图谱构建 | 从知识点、前置关系、考点频率等数据自动构建知识图谱 | P1 |
| 图谱存储 | 图数据持久化（邻接表 + 属性存储），支持高效查询 | P1 |
| 图谱可视化 | 在 Flutter 端渲染可交互的知识图谱（缩放、平移、节点点击） | P1 |
| 学习进度叠加 | 在图谱上叠加用户掌握度、学习进度等状态信息 | P1 |
| 薄弱点高亮 | 在图谱上标记薄弱知识点及传播路径 | P1 |
| 子图提取 | 按学科、章节、考点范围提取子图，控制渲染规模 | P1 |
| 推荐路径可视化 | 在图谱上展示推荐的学习路径和下一步建议 | P2 |
| 离线图谱缓存 | 图谱数据本地缓存，支持离线浏览 | P2 |

### 1.3 依赖关系

```
知识点体系与教材映射引擎 → 知识点节点数据、前置关系、教材版本映射
考点梳理 → 考点频率、高频标记、易错标记
学情分析 → 用户掌握度、薄弱点数据
自适应学习与个性化推荐引擎 → 推荐路径、下一步建议
学习记录与进度追踪服务 → 学习进度数据
题目与题库服务 → 题目关联的知识点、题目数量统计
```

### 1.4 被依赖关系

| 消费方 | 使用方式 |
|--------|----------|
| 考点梳理模块 | 嵌入知识图谱页面，展示考点关联全景 |
| 同步课堂学习 | 章节学习后展示当前章节在知识图谱中的位置 |
| 学情分析 | 展示掌握度热力图谱、薄弱点传播路径 |
| 自适应学习 | 可视化推荐学习路径 |
| 首页学习工作台 | 薄弱点图谱缩略卡片 |
| 学习报告 | 周报/月报中嵌入阶段性图谱快照 |

## 2. 数据模型设计

### 2.1 图节点 (GraphNode)

知识点在图谱中作为节点，每个节点携带丰富的属性信息。

```sql
-- 图谱节点主表（邻接表模型，基于 MySQL/PostgreSQL）
CREATE TABLE knowledge_graph_nodes (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    kp_id           BIGINT       NOT NULL COMMENT '关联知识点ID (knowledge_points.id)',
    graph_type      VARCHAR(32)  NOT NULL COMMENT '图谱类型: SUBJECT|CHAPTER|EXAM|SKILL',
    
    -- 归属范围
    subject_id      INT          NOT NULL COMMENT '学科ID',
    grade_range     VARCHAR(32)  NULL     COMMENT '适用学段: PRIMARY|JUNIOR|SENIOR',
    chapter_id      BIGINT       NULL     COMMENT '所属章节ID（可为空，跨章节知识点）',
    
    -- 节点属性
    node_weight     FLOAT        DEFAULT 1.0 COMMENT '节点权重（基于考试频率、重要性）',
    exam_frequency  FLOAT        DEFAULT 0.0 COMMENT '考试频率分 [0.0, 1.0]',
    difficulty_avg  FLOAT        DEFAULT 0.5 COMMENT '平均难度 [0.0, 1.0]',
    question_count  INT          DEFAULT 0   COMMENT '关联题目数量',
    
    -- 渲染元数据（服务端预计算）
    display_name    VARCHAR(128) NOT NULL COMMENT '展示名称',
    display_abbr    VARCHAR(16)  NULL     COMMENT '缩写（用于小节点展示）',
    color_tag       VARCHAR(16)  NULL     COMMENT '颜色标签: CORE|IMPORTANT|NORMAL|EXTENSION',
    
    -- 元数据
    created_at      DATETIME     DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_kp_graph (kp_id, graph_type),
    INDEX idx_subject (subject_id, graph_type),
    INDEX idx_chapter (chapter_id),
    INDEX idx_weight (node_weight DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识图谱节点';
```

### 2.2 图边 (GraphEdge)

```sql
CREATE TABLE knowledge_graph_edges (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    source_node_id  BIGINT       NOT NULL COMMENT '起始节点ID',
    target_node_id  BIGINT       NOT NULL COMMENT '目标节点ID',
    edge_type       VARCHAR(32)  NOT NULL COMMENT '边类型: PREREQUISITE|RELATED|CONTAINS|DERIVED',
    edge_weight     FLOAT        DEFAULT 1.0 COMMENT '边权重（关联强度）',
    
    -- 元数据
    is_bidirectional BOOLEAN     DEFAULT FALSE COMMENT '是否双向',
    description     VARCHAR(512) NULL     COMMENT '关系描述',
    created_at      DATETIME     DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_edge (source_node_id, target_node_id, edge_type),
    INDEX idx_source (source_node_id),
    INDEX idx_target (target_node_id),
    
    FOREIGN KEY (source_node_id) REFERENCES knowledge_graph_nodes(id),
    FOREIGN KEY (target_node_id) REFERENCES knowledge_graph_nodes(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识图谱边';
```

### 2.3 边类型说明

| 边类型 | 含义 | 方向 | 示例 |
|--------|------|------|------|
| `PREREQUISITE` | 前置关系：学B需要先掌握A | A → B | 一元二次方程 ← 实数运算 |
| `RELATED` | 关联关系：知识点之间有关联但无先后 | 双向 | 二次函数 ↔ 一元二次方程 |
| `CONTAINS` | 包含关系：父知识点包含子知识点 | 父 → 子 | 代数 → 整式运算 |
| `DERIVED` | 推导关系：A可推导出B | A → B | 勾股定理 → 距离公式 |

## 4. 图谱构建管线

### 4.1 整体构建流程

```
知识点体系数据 ──────────────────────┐
                                     │
考点频率数据 ──────────────────────┤
                                     ├──► 图谱构建管线 ──► 图谱数据 ──► Redis缓存
题目关联统计 ──────────────────────┤
                                     │
手动补充关系（后台运营） ────────┘
```

### 4.2 自动构建服务

```python
class GraphBuilderService:
    """知识图谱自动构建服务"""
    
    def __init__(self, db_session, redis_client):
        self.db = db_session
        self.redis = redis_client
    
    async def build_subject_graph(
        self, subject_id: int, grade_range: str
    ) -> dict:
        """
        为指定学科+学段构建完整知识图谱。
        包含：节点生成、边关系构建、权重计算、聚类。
        """
        # 1. 从知识点体系获取节点
        knowledge_points = await self._fetch_knowledge_points(
            subject_id, grade_range
        )
        
        # 2. 创建或更新图谱节点
        nodes = []
        for kp in knowledge_points:
            node = await self._create_or_update_node(kp)
            nodes.append(node)
        
        # 3. 构建边关系
        edges = []
        # 3a. 前置关系（从知识点体系的 prerequisite 数据）
        edges.extend(await self._build_prerequisite_edges(nodes))
        # 3b. 关联关系（从题目共现频率推导）
        edges.extend(
            await self._build_related_edges(nodes, min_co_occurrence=5)
        )
        # 3c. 包含关系（从知识点层级结构）
        edges.extend(await self._build_contains_edges(nodes))
        
        # 4. 计算节点权重
        await self._calculate_node_weights(nodes)
        
        # 5. 执行聚类（Louvain 社区发现）
        clusters = await self._cluster_nodes(nodes, edges)
        
        # 6. 更新缓存
        cache_key = f"graph:subject:{subject_id}:{grade_range}"
        await self._update_cache(cache_key, nodes, edges, clusters)
        
        return {
            "total_nodes": len(nodes),
            "total_edges": len(edges),
            "total_clusters": len(clusters),
        }
    
    async def _calculate_node_weights(self, nodes: list):
        """
        计算节点权重:
        weight = 0.4 * 考试频率 + 0.3 * 题目数量归一化 + 0.3 * 下游节点数归一化
        """
        max_q_count = max(n.question_count for n in nodes) or 1
        max_downstream = max(
            await self._downstream_count(n.id) for n in nodes
        ) or 1
        
        for node in nodes:
            exam_freq = node.exam_frequency
            q_norm = node.question_count / max_q_count
            d_norm = await self._downstream_count(node.id) / max_downstream
            
            node.node_weight = (
                0.4 * exam_freq + 0.3 * q_norm + 0.3 * d_norm
            )
            # 设置颜色标签
            if node.node_weight >= 0.8:
                node.color_tag = "CORE"
            elif node.node_weight >= 0.6:
                node.color_tag = "IMPORTANT"
            elif node.node_weight >= 0.3:
                node.color_tag = "NORMAL"
            else:
                node.color_tag = "EXTENSION"
            
            await self.db.flush(node)
    
    async def _build_related_edges(
        self, nodes: list, min_co_occurrence: int = 5
    ) -> list:
        """
        基于题目的知识点共现频率推导关联关系。
        如果两个知识点经常出现在同一道题中，说明它们有关联。
        """
        kp_ids = [n.kp_id for n in nodes]
        co_occurrence = await self._query_co_occurrence(kp_ids)
        
        edges = []
        kp_to_node = {n.kp_id: n for n in nodes}
        
        for (kp_a, kp_b), count in co_occurrence.items():
            if count < min_co_occurrence:
                continue
            count_a = await self._question_count_for_kp(kp_a)
            count_b = await self._question_count_for_kp(kp_b)
            jaccard = count / (count_a + count_b - count)
            
            if jaccard >= 0.1:
                edges.append(GraphEdge(
                    source_node_id=kp_to_node[kp_a].id,
                    target_node_id=kp_to_node[kp_b].id,
                    edge_type="RELATED",
                    edge_weight=jaccard,
                    is_bidirectional=True,
                    description=f"共现{count}次，Jaccard={jaccard:.2f}",
                ))
        
        return edges
    
    async def _cluster_nodes(self, nodes: list, edges: list) -> list:
        """
        基于 Louvain 社区发现算法对节点聚类。
        用于渲染时的分组展示和折叠。
        """
        import networkx as nx
        from community import best_partition  # python-louvain
        
        G = nx.Graph()
        for n in nodes:
            G.add_node(n.id)
        for e in edges:
            G.add_edge(
                e.source_node_id, e.target_node_id, weight=e.edge_weight
            )
        
        partition = best_partition(G)  # {node_id: community_id}
        
        # 组织聚类结果
        communities = {}
        for node_id, comm_id in partition.items():
            communities.setdefault(comm_id, []).append(node_id)
        
        clusters = []
        for comm_id, node_ids in communities.items():
            # 选权重最大的节点作为聚类中心
            center = max(node_ids, key=lambda nid: 
                next(n.node_weight for n in nodes if n.id == nid))
            clusters.append({
                "id": f"c{comm_id}",
                "node_ids": node_ids,
                "center_node_id": center,
            })
        
        return clusters
```

## 5. 薄弱点传播算法

### 5.1 传播规则

当一个知识点掌握度低于阈值时，沿 `PREREQUISITE` 边向下游传播薄弱标记，传播强度随距离衰减。

```python
class WeaknessPropagationEngine:
    """薄弱点传播引擎"""
    
    def __init__(self, db_session):
        self.db = db_session
    
    async def propagate(
        self,
        user_id: int,
        subject_id: int,
        threshold: float = 0.4,
        max_depth: int = 3,
        decay_factor: float = 0.7,
    ) -> list[dict]:
        """
        执行薄弱点传播分析。
        
        Args:
            user_id: 用户ID
            subject_id: 学科ID
            threshold: 薄弱阈值（低于此值视为薄弱）
            max_depth: 最大传播深度
            decay_factor: 每层传播的衰减系数
            
        Returns:
            薄弱节点列表（含传播节点）
        """
        # 1. 获取用户在该学科的所有节点状态
        user_states = await self._get_user_states(user_id, subject_id)
        
        # 2. 找出直接薄弱节点（SELF）
        weak_nodes = []
        for state in user_states:
            if state.mastery_level < threshold:
                weak_nodes.append({
                    "node_id": state.node_id,
                    "mastery": state.mastery_level,
                    "source": "SELF",
                    "depth": 0,
                    "propagated_from": [],
                })
        
        # 3. BFS 沿 PREREQUISITE 边向下游传播
        propagated = []
        visited = {wn["node_id"] for wn in weak_nodes}
        queue = [(wn["node_id"], 0, []) for wn in weak_nodes]
        
        while queue:
            current_id, depth, path = queue.pop(0)
            if depth >= max_depth:
                continue
            
            # 查找下游节点（current_id 是 target 的前置）
            downstream = await self._get_downstream_nodes(current_id)
            
            for ds_node_id, edge_weight in downstream:
                if ds_node_id in visited:
                    continue
                visited.add(ds_node_id)
                
                new_path = path + [current_id]
                propagated_mastery = (
                    threshold * (decay_factor ** (depth + 1)) * edge_weight
                )
                
                ds_state = next(
                    (s for s in user_states if s.node_id == ds_node_id), 
                    None
                )
                actual_mastery = ds_state.mastery_level if ds_state else 0.0
                
                # 仅在实际掌握度也偏低时才传播
                if actual_mastery < threshold * 1.2:
                    propagated.append({
                        "node_id": ds_node_id,
                        "mastery": actual_mastery,
                        "source": "PROPAGATED",
                        "depth": depth + 1,
                        "propagated_from": new_path,
                        "propagated_mastery": propagated_mastery,
                    })
                    queue.append((ds_node_id, depth + 1, new_path))
        
        # 4. 合并结果，按影响程度排序
        all_weak = weak_nodes + propagated
        all_weak.sort(key=lambda x: x["mastery"])
        
        # 5. 生成受影响的学习路径
        affected_paths = await self._compute_affected_paths(
            all_weak, subject_id
        )
        
        return {
            "weak_nodes": all_weak,
            "affected_paths": affected_paths,
        }
```

### 5.2 传播参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `threshold` | 0.4 | 掌握度低于此值视为薄弱 |
| `max_depth` | 3 | 最大传播层数 |
| `decay_factor` | 0.7 | 每层衰减系数 |
| `min_edge_weight` | 0.3 | 边权重低于此值不传播 |
| `max_propagation_nodes` | 50 | 单次传播最大节点数（性能保护） |

### 5.3 受影响路径计算

薄弱点传播完成后，计算从薄弱源节点到高权重目标节点（如 CORE 类型）的最短影响路径：

```python
async def _compute_affected_paths(
    self, weak_nodes: list[dict], subject_id: int
) -> list[dict]:
    """
    计算受薄弱点影响的学习路径。
    从每个薄弱源节点出发，找到通往 CORE/IMPORTANT 节点的路径。
    """
    weak_ids = {wn["node_id"] for wn in weak_nodes}
    paths = []

    for wn in weak_nodes:
        if wn["source"] != "SELF":
            continue
        # BFS 找下游 CORE/IMPORTANT 节点
        visited = set()
        queue = [(wn["node_id"], [])]
        while queue:
            current_id, trail = queue.pop(0)
            if current_id in visited or len(trail) >= 5:
                continue
            visited.add(current_id)

            downstream = await self._get_downstream_nodes(current_id)
            for ds_id, _ in downstream:
                node = await self._get_node(ds_id)
                new_trail = trail + [current_id]
                if node.color_tag in ("CORE", "IMPORTANT") and ds_id not in weak_ids:
                    # 发现受影响的高权重节点
                    full_path = new_trail + [ds_id]
                    names = await self._batch_get_names(full_path)
                    paths.append({
                        "path": " → ".join(names),
                        "impact": "HIGH" if node.color_tag == "CORE" else "MEDIUM",
                        "blocked_node_count": len(full_path),
                    })
                else:
                    queue.append((ds_id, new_trail))

    # 去重并按 impact 排序
    seen = set()
    unique_paths = []
    for p in paths:
        if p["path"] not in seen:
            seen.add(p["path"])
            unique_paths.append(p)
    unique_paths.sort(key=lambda x: (0 if x["impact"] == "HIGH" else 1, -x["blocked_node_count"]))
    return unique_paths[:10]  # 最多返回10条
```

### 6.3 布局算法

#### 6.3.1 力导向布局 (Force-Directed)

默认布局算法，适合展示知识点之间的关联关系全景：

```dart
class ForceDirectedLayout {
  final int iterations;
  final double repulsionForce;
  final double attractionForce;
  final double idealEdgeLength;
  final Size canvasSize;
  final double damping;

  ForceDirectedLayout({
    this.iterations = 200,
    this.repulsionForce = 5000.0,
    this.attractionForce = 0.01,
    this.idealEdgeLength = 120.0,
    required this.canvasSize,
    this.damping = 0.9,
  });

  /// 执行力导向布局计算
  List<Offset> compute(GraphData graph) {
    final n = graph.nodes.length;
    final positions = List<Offset>.generate(
      n, (i) => Offset(
        canvasSize.width / 2 + (math.Random().nextDouble() - 0.5) * 200,
        canvasSize.height / 2 + (math.Random().nextDouble() - 0.5) * 200,
      ),
    );
    final velocities = List.generate(n, (_) => Offset.zero);

    // 预计算邻接关系
    final adjacency = <int, Set<int>>{};
    for (final edge in graph.edges) {
      final si = graph.nodes.indexWhere((n) => n.id == edge.sourceId);
      final ti = graph.nodes.indexWhere((n) => n.id == edge.targetId);
      if (si >= 0 && ti >= 0) {
        adjacency.putIfAbsent(si, () => {}).add(ti);
        adjacency.putIfAbsent(ti, () => {}).add(si);
      }
    }

    for (int iter = 0; iter < iterations; iter++) {
      final forces = List.generate(n, (_) => Offset.zero);

      // 斥力（节点间互斥）
      for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
          final delta = positions[i] - positions[j];
          final dist = max(delta.distance, 1.0);
          final force = repulsionForce / (dist * dist);
          final unit = delta / dist;
          forces[i] += unit * force;
          forces[j] -= unit * force;
        }
      }

      // 引力（边连接的节点互相吸引）
      for (final edge in graph.edges) {
        final si = graph.nodes.indexWhere((n) => n.id == edge.sourceId);
        final ti = graph.nodes.indexWhere((n) => n.id == edge.targetId);
        if (si < 0 || ti < 0) continue;
        final delta = positions[ti] - positions[si];
        final dist = delta.distance;
        final force = attractionForce * (dist - idealEdgeLength);
        final unit = dist > 0 ? delta / dist : Offset.zero;
        forces[si] += unit * force;
        forces[ti] -= unit * force;
      }

      // 聚类引力（同一集群的节点向中心聚拢）
      for (final cluster in graph.clusters) {
        final indices = cluster.nodeIds.map(
          (nid) => graph.nodes.indexWhere((n) => n.id == nid),
        ).where((i) => i >= 0).toList();
        if (indices.isEmpty) continue;
        final center = Offset(
          indices.map((i) => positions[i].dx).reduce((a, b) => a + b) / indices.length,
          indices.map((i) => positions[i].dy).reduce((a, b) => a + b) / indices.length,
        );
        for (final i in indices) {
          final delta = center - positions[i];
          forces[i] += delta * 0.005;
        }
      }

      // 应用力并更新位置
      final alpha = 1.0 - (iter / iterations);
      for (int i = 0; i < n; i++) {
        velocities[i] = (velocities[i] + forces[i]) * damping;
        positions[i] = positions[i] + velocities[i] * alpha;
        // 约束在画布范围内
        positions[i] = Offset(
          positions[i].dx.clamp(40.0, canvasSize.width - 40.0),
          positions[i].dy.clamp(40.0, canvasSize.height - 40.0),
        );
      }
    }

    return positions;
  }
}
```

#### 6.3.2 层次布局 (Hierarchical)

适合展示知识点的层级关系（CONTAINS + PREREQUISITE），按拓扑排序分层：

```dart
class HierarchicalLayout {
  final Size canvasSize;
  final double layerSpacing;
  final double nodeSpacing;

  HierarchicalLayout({
    required this.canvasSize,
    this.layerSpacing = 100.0,
    this.nodeSpacing = 80.0,
  });

  List<Offset> compute(GraphData graph) {
    // 1. 拓扑排序确定层级
    final layers = _topologicalLayers(graph);
    final positions = <Offset>[];

    // 2. 按层分配Y坐标，同层内均匀分布X
    for (int layerIdx = 0; layerIdx < layers.length; layerIdx++) {
      final nodesInLayer = layers[layerIdx];
      final y = 60.0 + layerIdx * layerSpacing;
      final totalWidth = (nodesInLayer.length - 1) * nodeSpacing;
      final startX = (canvasSize.width - totalWidth) / 2;

      for (int i = 0; i < nodesInLayer.length; i++) {
        final nodeIdx = graph.nodes.indexWhere((n) => n.id == nodesInLayer[i]);
        positions[nodeIdx] = Offset(startX + i * nodeSpacing, y);
      }
    }
    return positions;
  }

  /// 拓扑分层：入度为0的节点在第一层，依次向上
  List<List<int>> _topologicalLayers(GraphData graph) {
    final inDegree = <int, int>{};
    final adjList = <int, List<int>>{};
    final nodeIds = graph.nodes.map((n) => n.id).toSet();

    for (final id in nodeIds) {
      inDegree[id] = 0;
      adjList[id] = [];
    }
    for (final edge in graph.edges) {
      if (edge.edgeType == 'PREREQUISITE' && nodeIds.contains(edge.sourceId) && nodeIds.contains(edge.targetId)) {
        adjList[edge.sourceId]!.add(edge.targetId);
        inDegree[edge.targetId] = (inDegree[edge.targetId] ?? 0) + 1;
      }
    }

    final layers = <List<int>>[];
    var remaining = Map<int, int>.from(inDegree);

    while (remaining.isNotEmpty) {
      final currentLayer = remaining.entries
        .where((e) => e.value == 0)
        .map((e) => e.key)
        .toList();
      if (currentLayer.isEmpty) break; // 环路保护
      layers.add(currentLayer);
      for (final nid in currentLayer) {
        for (final next in adjList[nid]!) {
          remaining[next] = remaining[next]! - 1;
        }
        remaining.remove(nid);
      }
    }
    // 剩余节点（环路中）放入最后一层
    if (remaining.isNotEmpty) {
      layers.add(remaining.keys.toList());
    }
    return layers;
  }
}
```

#### 6.3.3 径向布局 (Radial)

适合以某个知识点为中心展示其关联网络，常用于「节点详情」视图：

```dart
class RadialLayout {
  final Offset center;
  final double startRadius;
  final double radiusStep;

  RadialLayout({
    required this.center,
    this.startRadius = 80.0,
    this.radiusStep = 90.0,
  });

  List<Offset> compute(GraphData graph, int centerNodeId) {
    final positions = List<Offset>.filled(graph.nodes.length, Offset.zero);
    final centerIdx = graph.nodes.indexWhere((n) => n.id == centerNodeId);
    if (centerIdx < 0) return positions;
    positions[centerIdx] = center;

    // BFS 分层
    final visited = <int>{centerNodeId};
    var frontier = <int>[centerNodeId];
    int ring = 1;

    while (frontier.isNotEmpty) {
      final nextFrontier = <int>[];
      final layerNodes = <int>[];
      for (final nid in frontier) {
        for (final neighborId in graph.neighborsOf(nid)) {
          if (!visited.contains(neighborId)) {
            visited.add(neighborId);
            layerNodes.add(neighborId);
            nextFrontier.add(neighborId);
          }
        }
      }
      // 在当前环上均匀分布
      final angleStep = 2 * math.pi / max(layerNodes.length, 1);
      final r = startRadius + ring * radiusStep;
      for (int i = 0; i < layerNodes.length; i++) {
        final idx = graph.nodes.indexWhere((n) => n.id == layerNodes[i]);
        if (idx >= 0) {
          final angle = angleStep * i - math.pi / 2;
          positions[idx] = Offset(
            center.dx + r * cos(angle),
            center.dy + r * sin(angle),
          );
        }
      }
      frontier = nextFrontier;
      ring++;
    }
    return positions;
  }
}
```

```dart
  Offset _offset = Offset.zero;

  int? _hoveredNodeId;

  void didUpdateWidget(KnowledgeGraphView oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.graphData.cacheVersion != widget.graphData.cacheVersion ||
        oldWidget.layoutType != widget.layoutType) {
      _computeLayout();
    }
  }

  void _computeLayout() {
    final size = MediaQuery.of(context).size;
    switch (widget.layoutType) {
      case GraphLayoutType.forceDirected:
        final positions = ForceDirectedLayout(canvasSize: size).compute(widget.graphData);
        _applyPositions(positions);
        break;
      case GraphLayoutType.hierarchical:
        final positions = HierarchicalLayout(canvasSize: size).compute(widget.graphData);
        _applyPositions(positions);
        break;
      case GraphLayoutType.radial:
        // 径向布局需要中心节点
        final centerId = widget.graphData.nodes.first.id;
        final positions = RadialLayout(center: Offset(size.width/2, size.height/2))
          .compute(widget.graphData, centerId);
        _applyPositions(positions);
        break;
    }
    setState(() {});
  }

  void _applyPositions(List<Offset> positions) {
    for (int i = 0; i < widget.graphData.nodes.length && i < positions.length; i++) {
      widget.graphData.nodes[i].position = positions[i];
      widget.graphData.nodes[i].radius = widget.graphData.nodes[i].computeRadius();
    }
    _laidOutData = widget.graphData;
  }

  @override
  Widget build(BuildContext context) {
    return InteractiveViewer(
      minScale: 0.3,
      maxScale: 3.0,
      boundaryMargin: const EdgeInsets.all(200),
      child: GestureDetector(
        onTapUp: _handleTapUp,
        onLongPressStart: _handleLongPress,
        child: CustomPaint(
          painter: GraphPainter(
            graphData: _laidOutData!,
            selectedNodeId: _selectedNodeId,
            hoveredNodeId: _hoveredNodeId,
            showUserState: widget.showUserState,
            showClusterBoundary: widget.showClusterBoundary,
          ),
          size: Size.infinite,
        ),
      ),
    );
  }

  void _handleTapUp(TapUpDetails details) {
    final localPos = details.localPosition;
    final hitNode = _hitTest(localPos);
    if (hitNode != null) {
      setState(() => _selectedNodeId = hitNode.id);
      widget.onNodeTap?.call(hitNode);
    } else {
      setState(() => _selectedNodeId = null);
      widget.onBackgroundTap?.call();
    }
  }

  GraphNode? _hitTest(Offset position) {
    for (final node in widget.graphData.nodes) {
      if ((position - node.position).distance <= node.radius) {
        return node;
      }
    }
    return null;
  }
```

```dart
class GraphPainter extends CustomPainter {
  final GraphData graphData;
  final int? selectedNodeId;
  final int? hoveredNodeId;
  final bool showUserState;
  final bool showClusterBoundary;

  GraphPainter({
    required this.graphData,
    this.selectedNodeId,
    this.hoveredNodeId,
    required this.showUserState,
    required this.showClusterBoundary,
  });

  @override
  void paint(Canvas canvas, Size size) {
    // 1. 绘制集群边界（虚线圆）
    if (showClusterBoundary) {
      _drawClusterBoundaries(canvas);
    }

    // 2. 绘制边
    for (final edge in graphData.edges) {
      _drawEdge(canvas, edge);
    }

    // 3. 绘制节点
    for (final node in graphData.nodes) {
      _drawNode(canvas, node);
    }
  }

  void _drawEdge(Canvas canvas, GraphEdge edge) {
    final source = graphData.nodeById(edge.sourceId);
    final target = graphData.nodeById(edge.targetId);
    if (source == null || target == null) return;

    final paint = Paint()
      ..color = _edgeColor(edge.edgeType, edge.weight)
      ..strokeWidth = _edgeWidth(edge.weight)
      ..style = PaintingStyle.stroke;

    // PREREQUISITE 和 DERIVED 类型用箭头
    if (edge.edgeType == 'PREREQUISITE' || edge.edgeType == 'DERIVED') {
      _drawArrowLine(canvas, paint, source.position, target.position, target.radius);
    } else {
      canvas.drawLine(source.position, target.position, paint);
    }
  }

  void _drawNode(Canvas canvas, GraphNode node) {
    final isSelected = node.id == selectedNodeId;
    final isHovered = node.id == hoveredNodeId;
    final paint = Paint()
      ..color = node.getRenderColor()
      ..style = PaintingStyle.fill;
    final strokePaint = Paint()
      ..color = isSelected ? Colors.white : Colors.white.withOpacity(0.3)
      ..strokeWidth = isSelected ? 3.0 : 1.0
      ..style = PaintingStyle.stroke;

    // 外圈光晕（选中态）
    if (isSelected) {
      canvas.drawCircle(
        node.position,
        node.radius + 6,
        Paint()..color = Colors.white.withOpacity(0.2),
      );
    }

    // 节点圆
    canvas.drawCircle(node.position, node.radius, paint);
    canvas.drawCircle(node.position, node.radius, strokePaint);

    // 节点文字
    final textPainter = TextPainter(
      text: TextSpan(
        text: node.displayAbbr ?? node.displayName,
        style: TextStyle(
          color: Colors.white,
          fontSize: node.radius > 24 ? 12.0 : 10.0,
          fontWeight: FontWeight.w600,
        ),
      ),
      textDirection: TextDirection.ltr,
    )..layout();
    textPainter.paint(
      canvas,
      node.position - Offset(textPainter.width / 2, textPainter.height / 2),
    );
  }

  void _drawArrowLine(Canvas canvas, Paint paint, Offset from, Offset to, double targetRadius) {
    final delta = to - from;
    final dist = delta.distance;
    if (dist < 1) return;
    final unit = delta / dist;
    final tipOffset = unit * targetRadius;
    final adjustedTo = to - tipOffset;
    canvas.drawLine(from, adjustedTo, paint);
    // 箭头头部
    const arrowSize = 8.0;
    final perp = Offset(-unit.dy, unit.dx);
    final arrowPath = Path()
      ..moveTo(adjustedTo.dx, adjustedTo.dy)
      ..lineTo(adjustedTo.dx - unit.dx * arrowSize + perp.dx * arrowSize / 2,
               adjustedTo.dy - unit.dy * arrowSize + perp.dy * arrowSize / 2)
      ..lineTo(adjustedTo.dx - unit.dx * arrowSize - perp.dx * arrowSize / 2,
               adjustedTo.dy - unit.dy * arrowSize - perp.dy * arrowSize / 2)
      ..close();
    canvas.drawPath(arrowPath, paint..style = PaintingStyle.fill);
  }

  void _drawClusterBoundaries(Canvas canvas) {
    for (final cluster in graphData.clusters) {
      final positions = cluster.nodeIds.map((nid) {
        final n = graphData.nodeById(nid);
        return n?.position;
      }).whereType<Offset>().toList();
      if (positions.isEmpty) continue;

      // 计算包围圆
      final center = Offset(
        positions.map((p) => p.dx).reduce((a, b) => a + b) / positions.length,
        positions.map((p) => p.dy).reduce((a, b) => a + b) / positions.length,
      );
      final maxDist = positions.map((p) => (p - center).distance).reduce(math.max) + 40;

      canvas.drawCircle(
        center,
        maxDist,
        Paint()
          ..color = Colors.blue.withOpacity(0.08)
          ..style = PaintingStyle.fill,
      );
      canvas.drawCircle(
        center,
        maxDist,
        Paint()
          ..color = Colors.blue.withOpacity(0.2)
          ..strokeWidth = 1.0
          ..style = PaintingStyle.stroke,
      );
    }
  }

  Color _edgeColor(String type, double weight) {
    final base = switch (type) {
      'PREREQUISITE' => const Color(0xFF42A5F5),
      'RELATED' => const Color(0xFFAB47BC),
      'CONTAINS' => const Color(0xFF66BB6A),
      'DERIVED' => const Color(0xFFFF7043),
      _ => Colors.grey,
    };
    return base.withOpacity(0.3 + weight * 0.5);
  }

  double _edgeWidth(double weight) => 1.0 + weight * 2.0;

  @override
  bool shouldRepaint(GraphPainter old) =>
    old.selectedNodeId != selectedNodeId ||
    old.hoveredNodeId != hoveredNodeId ||
    old.graphData.cacheVersion != graphData.cacheVersion;
}
```

### 7.1 客户端缓存架构

```dart
class GraphLocalCache {
  final Box _box; // Hive box
  static const _graphDataKey = 'graph_data_';
  static const _userStateKey = 'graph_user_state_';

  GraphLocalCache(this._box);

  /// 保存图谱数据
  Future<void> saveGraphData(String viewKey, GraphData data) async {
    await _box.put('$_graphDataKey$viewKey', {
      'version': data.cacheVersion,
      'nodes': data.nodes.map((n) => _nodeToJson(n)).toList(),
      'edges': data.edges.map((e) => _edgeToJson(e)).toList(),
      'clusters': data.clusters.map((c) => _clusterToJson(c)).toList(),
      'cached_at': DateTime.now().toIso8601String(),
    });
  }

  /// 读取缓存的图谱数据
  GraphData? loadGraphData(String viewKey) {
    final cached = _box.get('$_graphDataKey$viewKey');
    if (cached == null) return null;
    // 检查缓存过期（7天）
    final cachedAt = DateTime.parse(cached['cached_at']);
    if (DateTime.now().difference(cachedAt).inDays > 7) return null;
    return _parseGraphData(viewKey, cached);
  }

  /// 保存用户掌握度状态（更新频率高，单独存储）
  Future<void> saveUserState(int userId, String viewKey, Map<int, UserNodeState> states) async {
    await _box.put('$_userStateKey${userId}_$viewKey', {
      'states': states.map((k, v) => MapEntry(k.toString(), {
        'mastery_level': v.masteryLevel,
        'mastery_status': v.masteryStatus,
        'learn_count': v.learnCount,
        'correct_rate': v.correctRate,
      })),
      'updated_at': DateTime.now().toIso8601String(),
    });
  }

  /// 增量更新：仅更新变化的节点状态
  Future<void> updateUserStates(
    int userId, String viewKey, List<Map<String, dynamic>> updates
  ) async {
    final key = '${_userStateKey}${userId}_$viewKey';
    final existing = _box.get(key) ?? {'states': {}, 'updated_at': ''};
    final states = Map<String, dynamic>.from(existing['states']);
    for (final u in updates) {
      states[u['node_id'].toString()] = {
        'mastery_level': u['mastery_level'],
        'mastery_status': u['mastery_status'],
      };
    }
    existing['states'] = states;
    existing['updated_at'] = DateTime.now().toIso8601String();
    await _box.put(key, existing);
  }
}
```

## 8. 错误处理

### 8.1 错误场景与处理

| 场景 | 客户端处理 | 服务端处理 |
| ---- | ---------- | ---------- |
| 图谱数据加载失败 | 展示本地缓存 + "数据可能不是最新" 提示 | 返回上一次缓存版本 + 错误码 |
| 布局计算超时 (>3s) | 降级为网格布局（Grid），保证可交互 | N/A |
| 节点数超过渲染上限 (>200) | 自动聚合为聚类视图，仅渲染聚类中心 | 服务端分页/限制返回节点数 |
| 用户状态获取失败 | 图谱正常展示，不叠加掌握度颜色 | 返回空 user_state，不阻断 |
| 薄弱传播分析超时 | 展示已计算的直接薄弱点，不等待传播 | 返回部分结果 + 下一页 token |
| 快照生成失败 | 重试1次后提示"快照生成中，请稍后查看" | 异步生成，完成后通过消息推送 |
| 离线访问 | 仅展示缓存数据，搜索走本地索引 | N/A |
| Canvas 渲染异常 | 捕获异常，降级为列表视图 | N/A |

### 8.2 错误码定义

| 错误码 | HTTP 状态 | 含义 | 客户端行为 |
| ------ | --------- | ---- | ---------- |
| GRAPH_001 | 404 | 图谱视图不存在 | 提示并返回选择页 |
| GRAPH_002 | 400 | 参数错误（学科/学段不合法） | 展示错误提示 |
| GRAPH_003 | 503 | 图谱正在构建中 | 展示 "加载中" 骨架屏，30s 后重试 |
| GRAPH_004 | 200 | 节点数为0（学科无数据） | 展示空态插画 + "暂无该学科图谱" |
| GRAPH_005 | 500 | 薄弱传播分析内部错误 | 降级展示直接薄弱点 |
| GRAPH_006 | 429 | 请求过于频繁 | 本地缓存兜底，60s 后重试 |
| GRAPH_007 | 200 | 布局计算数据量过大 | 自动切换聚类折叠视图 |

## 9. 性能要求

### 9.1 服务端性能

| 指标 | 目标值 | 说明 |
| ---- | ------ | ---- |
| 图谱数据接口响应 | ≤ 500ms（命中缓存 ≤ 50ms） | Redis 缓存优先 |
| 节点详情接口 | ≤ 200ms | 含用户状态 |
| 薄弱传播分析 | ≤ 2s（≤ 100 节点） | 异步计算 + 结果缓存 |
| 快照生成 | ≤ 10s | 异步任务，不阻塞请求 |
| 图谱构建全量任务 | ≤ 5min（单个学科） | 定时任务，不影响在线服务 |

### 9.2 客户端性能

| 指标 | 目标值 | 说明 |
| ---- | ------ | ---- |
| 首次渲染（含布局计算） | ≤ 2s（≤ 80 节点） | Isolate 中计算布局 |
| 帧率 | ≥ 30fps（平移/缩放时） | 避免主线程阻塞 |
| 内存占用 | ≤ 50MB（200 节点） | 节点数据复用 |
| 离线打开 | ≤ 500ms | 本地缓存直接渲染 |

### 9.3 大规模图优化策略

当节点数 > 80 时，启用以下优化策略：

1. **聚类折叠**：仅渲染聚类中心节点 + 连线，用户可展开感兴趣的聚类
2. **视口裁剪**：只渲染当前可见区域内的节点，离屏节点跳过绘制
3. **LOD（细节层级）**：缩小到一定比例后，节点仅显示圆点不显示文字
4. **异步布局**：在 Isolate 中执行力导向布局计算，避免阻塞 UI 线程
5. **增量更新**：用户状态变化时仅更新对应节点的渲染属性，不重绘全图

```dart
/// 视口裁剪示例
class ViewportCulling {
  final Rect viewport;
  final double padding; // 额外缓冲区域

  ViewportCulling(this.viewport, {this.padding = 50.0});

  bool isVisible(GraphNode node, double scale) {
    final expanded = viewport.inflate(padding / scale);
    return expanded.contains(node.position);
  }

  List<GraphNode> cullNodes(List<GraphNode> nodes, double scale) {
    return nodes.where((n) => isVisible(n, scale)).toList();
  }
}

/// LOD 策略
class LevelOfDetail {
  static NodeRenderDetail getDetail(double scale, double nodeRadius) {
    if (scale > 1.5) return NodeRenderDetail.full;     // 全部信息
    if (scale > 0.8) return NodeRenderDetail.standard;  // 名称 + 掌握度
    if (scale > 0.4) return NodeRenderDetail.minimal;   // 缩写 + 颜色
    return NodeRenderDetail.dot;                         // 仅圆点
  }
}

enum NodeRenderDetail { full, standard, minimal, dot }
```

| 安全要点 | 措施 |
| -------- | ---- |

| 速率限制 | 图谱数据接口 30次/分钟，薄弱传播 5次/分钟 |
