> 版本：v1.0 | 更新日期：2026-06-20 | 状态：草案

## 1. 模块概述

### 1.1 定位

PrimeTop 作为覆盖全学段的 AI 辅助学习产品，需同时遵守教育行业、未成年人保护、生成式 AI 服务、算法推荐、数据安全等多领域的监管要求。本模块是**跨业务线的合规基础设施**，为所有产品功能提供监管适配能力，确保产品在每个运营阶段均满足中国法律法规要求。

本文档不重复"安全与内容合规系统"的技术安全过滤逻辑，而是聚焦于**教育行业特有的监管合规义务**及其技术实现方案。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **准入合规** | 满足教育移动应用备案、ICP 备案、算法备案等准入条件 |
| **运营合规** | 产品功能设计符合校外培训监管、未成年人保护等政策要求 |
| **AI 合规** | 生成式 AI 服务完成备案，输出内容标识、安全评估、算法透明度达标 |
| **数据合规** | 未成年人数据采集、存储、使用、出境全链路合规 |
| **审计就绪** | 所有合规动作可追溯，随时应对监管检查和审计要求 |
| **敏捷响应** | 监管政策更新时，通过配置化规则快速适配，避免代码级硬编码 |

### 1.3 适用范围

| 端 | 合规职责 |
|----|----------|
| 学生端 APP | 实名认证、青少年模式、AIGC 标识展示、内容投诉入口 |
| 家长端 | 监护人同意确认、管控设置、未成年人数据授权 |
| 管理后台 | 备案信息管理、合规配置、审计报表、监管报送 |
| 服务端 | 算法备案逻辑、AIGC 标识注入、数据分类分级、合规日志 |

### 1.4 与其他模块的边界

| 模块 | 本模块职责 | 关联模块职责 |
|------|-----------|-------------|
| 安全与内容合规系统 | 制定合规规则阈值与策略 | 执行内容过滤、安全检测 |
| 防沉迷与未成年人保护 | 提供年龄分层策略、管控规则配置 | 执行时长管控、消费限制 |
| 数据安全与隐私合规 | 定义未成年人数据特殊处理规则 | 执行数据加密、脱敏、权限控制 |
| 用户实名认证服务 | 定义教育行业实名认证特殊要求 | 执行身份核验流程 |
| AI 对话引擎 | 定义 AIGC 标识、安全评估要求 | 执行 AI 调用、输出处理 |

## 4. 双减政策功能门控引擎

### 4.1 政策要求

双减政策核心约束（针对义务教育阶段，即小学一年级至初中三年级）：

| 约束 | 说明 | 系统影响 |
|------|------|----------|
| 禁止学科类校外培训 | 不得在法定节假日、休息日、寒暑假组织学科培训 | 时段门控：特定时期禁止特定功能 |
| 不得提供直播授课 | 不得以直播形式提供学科类课程 | 功能门控：禁止直播功能 |
| 作业总量控制 | 不得增加作业负担 | 内容门控：练习题数量限制 |
| 禁止拍照搜题替代思考 | 拍照搜题功能需引导独立思考，不能直接给答案 | 答案管控：渐进式提示 |

### 4.2 门控规则 DSL 设计

```typescript
/**
 * 合规规则条件 DSL 定义
 * 使用 JSON 表达复杂的政策合规条件
 */
interface ComplianceRuleDSL {
  // 条件组合
  condition: 'AND' | 'OR' | 'NOT';
  rules?: ComplianceRuleDSL[];
  
  // 原子条件
  field?: string;           // 检查字段
  operator?: 'EQ' | 'NEQ' | 'IN' | 'NOT_IN' | 'GT' | 'LT' | 'GTE' | 'LTE' | 'BETWEEN' | 'PERIOD';
  value?: any;
}

// 示例：双减政策 - 寒暑假期间禁止义务教育阶段用户访问同步课堂新课时
const shuangjianRule: ComplianceRuleDSL = {
  condition: 'AND',
  rules: [
    { field: 'user.age_group', operator: 'IN', value: ['L0', 'L1'] },  // 义务教育阶段
    { field: 'user.stage', operator: 'IN', value: ['PRIMARY', 'JUNIOR_HIGH'] },
    {
      condition: 'OR',
      rules: [
        { field: 'time.period_type', operator: 'EQ', value: 'WINTER_BREAK' },
        { field: 'time.period_type', operator: 'EQ', value: 'SUMMER_BREAK' },
        { field: 'time.period_type', operator: 'EQ', value: 'PUBLIC_HOLIDAY' },
      ]
    },
    { field: 'feature.code', operator: 'EQ', value: 'SYNC_CLASSROOM_NEW_LESSON' },
  ]
};
```

### 4.3 门控引擎核心实现

```java
/**
 * 合规规则门控引擎
 * 在功能执行前检查所有适用规则，决定放行/拦截/降级
 */
@Service
public class ComplianceGateEngine {

    @Autowired
    private ComplianceRuleRepository ruleRepository;
    
    @Autowired
    private ComplianceAuditService auditService;
    
    /**
     * 门控决策
     * @param context 功能请求上下文
     * @return 决策结果
     */
    public ComplianceDecision evaluate(ComplianceContext context) {
        // 1. 查询适用的合规规则（按优先级排序）
        List<ComplianceRule> applicableRules = ruleRepository.findApplicableRules(
            context.getFeatureCode(),
            context.getUserAgeGroup(),
            context.getUserStage(),
            context.getRegion(),
            LocalDate.now()
        );
        
        // 2. 逐条评估规则
        List<RuleEvaluationResult> results = new ArrayList<>();
        for (ComplianceRule rule : applicableRules) {
            if (rule.getStatus() != RuleStatus.ACTIVE) continue;
            
            RuleEvaluationResult result = evaluateRule(rule, context);
            results.add(result);
            
            // 命中强制规则立即返回（按优先级，第一条 MANDATORY 命中即拦截）
            if (result.isMatched() && rule.getRuleLevel() == RuleLevel.MANDATORY) {
                ComplianceDecision decision = ComplianceDecision.blocked(
                    rule, result, "命中强制合规规则: " + rule.getRuleName()
                );
                auditService.logRuleExecution(context, rule, decision);
                return decision;
            }
        }
        
        // 3. 检查是否有推荐级别的告警
        List<RuleEvaluationResult> warnings = results.stream()
            .filter(r -> r.isMatched())
            .collect(Collectors.toList());
        
        if (!warnings.isEmpty()) {
            return ComplianceDecision.warning(warnings);
        }
        
        // 4. 全部通过
        return ComplianceDecision.allowed();
    }
    
    /**
     * 评估单条规则
     */
    private RuleEvaluationResult evaluateRule(ComplianceRule rule, ComplianceContext context) {
        try {
            ComplianceRuleDSL dsl = parseDSL(rule.getRuleCondition());
            boolean matched = evaluateDSL(dsl, context);
            return new RuleEvaluationResult(rule.getRuleCode(), matched, null);
        } catch (Exception e) {
            // 规则解析异常时，保守处理：强制规则视为命中
            log.error("合规规则解析失败: {}", rule.getRuleCode(), e);
            if (rule.getRuleLevel() == RuleLevel.MANDATORY) {
                return new RuleEvaluationResult(rule.getRuleCode(), true, "规则解析异常，保守拦截");
            }
            return new RuleEvaluationResult(rule.getRuleCode(), false, "规则解析异常，放行");
        }
    }
    
    /**
     * DSL 递归求值
     */
    private boolean evaluateDSL(ComplianceRuleDSL dsl, ComplianceContext ctx) {
        if (dsl.condition == 'NOT') {
            return !evaluateDSL(dsl.rules.get(0), ctx);
        }
        if (dsl.condition == 'AND') {
            return dsl.rules.stream().allMatch(r -> evaluateDSL(r, ctx));
        }
        if (dsl.condition == 'OR') {
            return dsl.rules.stream().anyMatch(r -> evaluateDSL(r, ctx));
        }
        // 原子条件
        return evaluateAtomic(dsl, ctx);
    }
    
    private boolean evaluateAtomic(ComplianceRuleDSL atom, ComplianceContext ctx) {
        Object fieldValue = ctx.getFieldValue(atom.field);
        return switch (atom.operator) {
            case 'EQ' -> Objects.equals(fieldValue, atom.value);
            case 'NEQ' -> !Objects.equals(fieldValue, atom.value);
            case 'IN' -> ((Collection<?>) atom.value).contains(fieldValue);
            case 'NOT_IN' -> !((Collection<?>) atom.value).contains(fieldValue);
            case 'GT' -> compare(fieldValue, atom.value) > 0;
            case 'LT' -> compare(fieldValue, atom.value) < 0;
            case 'PERIOD' -> checkPeriod(fieldValue, atom.value, ctx);
            default -> false;
        };
    }
    
    /**
     * 检查日期是否在特定周期内（寒暑假/节假日）
     */
    private boolean checkPeriod(Object dateValue, Object periodSpec, ComplianceContext ctx) {
        LocalDate date = (LocalDate) dateValue;
        String periodType = (String) periodSpec;
        return ctx.getCalendarService().isInPeriod(date, periodType, ctx.getRegion());
    }
}
```

```java
    @Autowired
    private UserService userService;

    public Object checkCompliance(ProceedingJoinPoint joinPoint, 
                                   ComplianceGate complianceGate) throws Throwable {
        Long userId = SecurityContext.getCurrentUserId();
        UserComplianceProfile profile = userService.getComplianceProfile(userId);
        
        ComplianceContext context = ComplianceContext.builder()
            .userId(userId)
            .userAgeGroup(profile.getAgeGroup())
            .userStage(profile.getStage())
            .featureCode(complianceGate.featureCode())
            .build();

            throw new ComplianceBlockException(
                decision.getBlockRuleCode(),
                decision.getUserMessage(),
                decision.getRegulatoryRef()
            );
        }
        
        // 记录告警但不拦截
        if (decision.isHasWarning()) {
            log.warn("合规告警: userId={}, feature={}, warnings={}", 
                userId, complianceGate.featureCode(), decision.getWarningResults());
        }
        
        return joinPoint.proceed();
    }
}
```

```java
/**
 * AIGC 文本标识注入服务
 */
@Service
public class AIGCTextLabelService {
    
    private static final String TEXT_LABEL_SUFFIX = "\n\n---\n⚠️ 本内容由 AI 辅助生成，仅供参考。";
    private static final String TEXT_LABEL_SHORT = "[AI生成]";
    
    /**
     * 注入显式标识
     */
    public String injectVisibleLabel(String content, AIGCSourceType sourceType) {
        if (sourceType == AIGCSourceType.AI_TUTOR) {
            // AI 辅导对话：文末追加完整声明
            return content + TEXT_LABEL_SUFFIX;
        } else if (sourceType == AIGCSourceType.OCR_SOLUTION) {
            // 拍题解析：开头加短标识
            return TEXT_LABEL_SHORT + "\n" + content;
        } else if (sourceType == AIGCSourceType.ESSAY_FEEDBACK) {
            // 作文批改反馈：文末追加
            return content + "\n\n---\n📝 以上批改建议由 AI 辅助生成，请结合实际判断。";
        }
        return content;
    }
    
    /**
     * 嵌入隐式水印（零宽字符方案）
     * 将 content_id 编码为零宽字符插入文本中
     */
    public String embedInvisibleWatermark(String content, String contentId) {
        // 将 contentId 转为二进制
        String binary = contentId.chars()
            .mapToObj(c -> String.format("%16s", Integer.toBinaryString(c))
                .replace(' ', '0'))
            .collect(Collectors.joining());
        
        // 二进制映射为零宽字符: 0→U+200B(ZWSP), 1→U+200C(ZWNJ)
        // 分隔符: U+200D(ZWJ)
        StringBuilder watermark = new StringBuilder();
        watermark.append('\u200D'); // 起始标记
        for (char bit : binary.toCharArray()) {
            watermark.append(bit == '0' ? '\u200B' : '\u200C');
        }
        watermark.append('\u200D'); // 结束标记
        
        // 在文本第一个字符后插入水印
        if (content.length() > 1) {
            return content.substring(0, 1) + watermark.toString() + content.substring(1);
        }
        return watermark.toString() + content;
    }
    
    /**
     * 提取并验证水印
     */
    public WatermarkExtractResult extractWatermark(String content) {
        int start = content.indexOf('\u200D');
        if (start == -1) return WatermarkExtractResult.notFound();
        
        int end = content.indexOf('\u200D', start + 1);
        if (end == -1) return WatermarkExtractResult.notFound();
        
        String binary = content.substring(start + 1, end).chars()
            .mapToObj(c -> {
                if (c == '\u200B') return "0";
                if (c == '\u200C') return "1";
                return "";
            })
            .collect(Collectors.joining());
        
        // 二进制还原为 contentId
        String contentId = decodeBinaryToString(binary);
        return WatermarkExtractResult.found(contentId);
    }
    
    /**
     * 创建 AIGC 标识记录
     */
    public AigcContentLabel createLabelRecord(String contentId, AIGCSourceType sourceType,
                                               String modelId, Long userId, String conversationId) {
        AigcContentLabel label = new AigcContentLabel();
        label.setContentId(contentId);
        label.setContentType("TEXT");
        label.setContentSource(sourceType.name());
        label.setSourceModel(modelId);
        label.setVisibleLabel("AI_GENERATED");
        label.setLabelDisplayText(getDisplayText(sourceType));
        label.setLabelShown(true);
        label.setWatermarkType("TEXT_STEGO");
        label.setWatermarkPayload(encryptWatermark(contentId));
        label.setWatermarkVerified(true);
        label.setUserId(userId);
        label.setConversationId(conversationId);
        return labelRepository.save(label);
    }
    
    private String getDisplayText(AIGCSourceType sourceType) {
        return switch (sourceType) {
            case AI_TUTOR -> "本内容由 AI 辅助生成";
            case OCR_SOLUTION -> "本解析由 AI 辅助生成";
            case ESSAY_FEEDBACK -> "本批改建议由 AI 辅助生成";
            case TRANSLATION -> "本翻译由 AI 辅助生成";
            default -> "本内容由 AI 辅助生成";
        };
    }
}
```

### 11.2 合规状态流转服务

```java
/**
 * 用户合规状态机
 */
@Service
public class ComplianceStateService {
    
    private static final StateMachineSpec<ComplianceState, ComplianceEvent> SPEC =
        StateMachineSpec
            .from(ComplianceState.UNVERIFIED)
            .permit(ComplianceEvent.REAL_NAME_VERIFIED, ComplianceState.VERIFIED)
            
            .from(ComplianceState.VERIFIED)
            .permit(ComplianceEvent.AGE_UNDER_14, ComplianceState.GUARDIAN_PENDING)
            .permit(ComplianceEvent.AGE_14_PLUS, ComplianceState.NORMAL)
            
            .from(ComplianceState.GUARDIAN_PENDING)
            .permit(ComplianceEvent.GUARDIAN_APPROVED, ComplianceState.GUARDIAN_GRANTED)
            .permit(ComplianceEvent.GUARDIAN_REJECTED, ComplianceState.GUARDIAN_DENIED)
            .permit(ComplianceEvent.GUARDIAN_TIMEOUT, ComplianceState.GUARDIAN_DENIED)
            
            .from(ComplianceState.GUARDIAN_GRANTED)
            .permit(ComplianceEvent.GUARDIAN_WITHDRAW, ComplianceState.GUARDIAN_DENIED)
            .permit(ComplianceEvent.AGE_TURN_14, ComplianceState.NORMAL)
            .permit(ComplianceEvent.REQUEST_DELETION, ComplianceState.DELETING)
            
            .from(ComplianceState.GUARDIAN_DENIED)
            .permit(ComplianceEvent.GUARDIAN_RE_APPROVE, ComplianceState.GUARDIAN_PENDING)
            
            .from(ComplianceState.NORMAL)
            .permit(ComplianceEvent.REQUEST_DELETION, ComplianceState.DELETING)
            
            .from(ComplianceState.DELETING)
            .permit(ComplianceEvent.DELETION_COMPLETE, ComplianceState.DELETED)
            .build();
    
    @Transactional
    public void transition(Long userId, ComplianceEvent event) {
        UserComplianceProfile profile = profileRepository.findById(userId)
            .orElseThrow();
        
        ComplianceState currentState = ComplianceState.from(profile);
        
        if (!SPEC.canTransition(currentState, event)) {
            throw new ComplianceStateException(
                currentState, event, 
                "不合法的合规状态流转"
            );
        }
        
        ComplianceState newState = SPEC.transition(currentState, event);
        applyState(profile, newState, event);
        profileRepository.save(profile);
        
        auditService.log(ComplianceAuditEvent.builder()
            .eventType("COMPLIANCE_STATE_TRANSITION")
            .eventCategory("RULE_EXECUTION")
            .userId(userId)
            .actionTaken("LOG")
            .eventDetail(Map.of(
                "fromState", currentState.name(),
                "toState", newState.name(),
                "event", event.name()
            ))
            .build());
    }
    
    private void applyState(UserComplianceProfile profile, ComplianceState state, ComplianceEvent event) {
        switch (state) {
            case GUARDIAN_GRANTED -> {
                profile.setGuardianConsentStatus("GRANTED");
                profile.setGuardianConsentAt(LocalDateTime.now());
            }
            case GUARDIAN_DENIED -> {
                profile.setGuardianConsentStatus("DENIED");
                profile.setComplianceRiskLevel("RESTRICTED");
                profile.setRestrictionFlags(Map.of(
                    "feature_access", "LIMITED",
                    "data_collection", "MINIMAL_ONLY"
                ));
            }
            case NORMAL -> {
                profile.setGuardianConsentStatus("NOT_REQUIRED");
            }
            case DELETING -> {
                profile.setComplianceRiskLevel("RESTRICTED");
                profile.setRestrictionFlags(Map.of(
                    "login", "BLOCKED",
                    "data_access", "BLOCKED"
                ));
            }
            case DELETED -> profile.setRestrictionFlags(Map.of(
                "login", "BLOCKED",
                "data_access", "BLOCKED",
                "anonymized", "TRUE"
            ));
        }
    }
}
```

| `COMPLIANCE_007` | 429 | 投诉提交频率过高 | 请稍后再试，或联系客服 |

```java
 * 全局异常处理器
 */
@RestControllerAdvice
public class ComplianceExceptionHandler {
    
    @ExceptionHandler(ComplianceBlockException.class)
    public ResponseEntity<ApiResponse<Void>> handleBlock(ComplianceBlockException e) {
        return ResponseEntity.status(HttpStatus.FORBIDDEN)
            .body(ApiResponse.error(e.getCode(), e.getMessage(), Map.of(
                "regulatoryRef", e.getRegulatoryRef(),
                "complianceAction", "BLOCKED"
            )));
    }
    
    @ExceptionHandler(ComplianceException.class)
    public ResponseEntity<ApiResponse<Void>> handleCompliance(ComplianceException e) {
        return ResponseEntity.status(HttpStatus.FORBIDDEN)
            .body(ApiResponse.error(e.getCode(), e.getMessage()));
    }
}
```
