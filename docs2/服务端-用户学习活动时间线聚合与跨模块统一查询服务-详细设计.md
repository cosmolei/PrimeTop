# 服务端-用户学习活动时间线聚合与跨模块统一查询服务 - 详细设计

> **模块定位**：PrimeTop 全平台学习活动的统一聚合层与查询入口。负责从 AI 辅导、拍照搜题、同步课堂、错题整理、练习测评、作文辅导、文科背诵、学习规划等各业务模块中收集学习活动事件，聚合为按时间排序的统一活动时间线，提供多视角（学生/家长/教师/AI上下文）的查询能力，支持活动摘要统计、活动流推送和跨模块学习行为回溯。
>
> **优先级**：P1（V1.0 阶段核心基础设施，支撑首页活动流、家长周报、教师班级视图、AI 上下文增强）
>
> **覆盖学段**：全学段

---

## 1. 概述

### 1.1 问题域分析

PrimeTop 学生在一个学习周期内会横跨多个功能模块产生学习行为：

```
早上：同步课堂学习了"二次函数"章节（20分钟）
上午：练习了 15 道函数题，错 3 道
中午：拍照搜题 2 次，AI 追问 5 轮
下午：错题本复习了 3 道之前错题
晚上：作文辅导提交了一篇作文
```

这些活动分散在各模块独立存储，存在以下问题：

| 问题 | 表现 | 影响 |
|------|------|------|
| **活动全景缺失** | 学生/家长想看"今天/本周做了什么"，需要分别进入各模块 | 用户体验割裂，家长难以全面了解孩子学习情况 |
| **跨模块行为断裂** | AI 对话不知道学生上午在练习什么、错在哪里 | AI 回答缺乏上下文连贯性 |
| **活动摘要无源** | 首页"今日学习概览"、家长周报需要跨模块逐个拉取数据聚合 | 性能差，BFF 层逻辑臃肿，N+1 调用 |
| **教师视图空白** | 教师想看某学生最近学习轨迹，无统一接口 | 教师端只能看到作业数据，缺失自主学习行为 |
| **活动流不可订阅** | 家长想实时收到孩子学习活动推送，无统一事件源 | 通知系统需要对接各模块，重复建设 |
| **行为回溯困难** | 想知道学生上周三做了什么，需跨模块查询拼接 | 运营分析和客服排查成本高 |

### 1.2 核心职责

1. **活动采集**：订阅各业务模块的学习行为事件，归一化为统一的活动记录格式
2. **活动存储**：将活动记录持久化到时间线存储，支持高效时间范围查询和分页
3. **多视角查询**：为学生端、家长端、教师端、AI 上下文提供不同维度的活动查询 API
4. **活动摘要**：提供按时间维度（日/周/月）和模块维度的活动统计聚合
5. **实时推送**：支持 WebSocket 订阅模式，家长端可实时收到孩子学习活动通知
6. **活动标签**：自动为活动打标签（学科、知识点、学段、活动强度等），支持标签筛选

### 1.4 设计目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 活动写入延迟 | P95 ≤ 50ms | 从事件到达到可查询 |
| 活动查询延迟 | P95 ≤ 100ms | 单用户时间线分页查询 |
| 摘要查询延迟 | P95 ≤ 200ms | 日/周/月统计聚合 |
| 活动事件吞吐 | ≥ 5000 events/s | 高峰期全平台活动事件 |
| 时间线保留期 | 365 天热数据 | 超过转入冷存储 |
| 实时推送延迟 | P95 ≤ 2s | 从活动产生到 WebSocket 推送 |

### 1.5 术语定义

| 术语 | 定义 |
|------|------|
| ActivityEvent | 活动事件，由业务模块产生的原始学习行为事件 |
| ActivityRecord | 活动记录，经归一化处理后存储到时间线的结构化活动 |
| ActivityTimeline | 活动时间线，按时间排序的活动记录集合 |
| ActivitySummary | 活动摘要，按时间维度或模块维度聚合的统计信息 |
| ActivityFeed | 活动流，面向终端用户展示的活动卡片列表 |
| ViewerRole | 查看者角色（student/parent/teacher/ai），决定可见性范围 |
| ActivityVisibility | 活动可见性等级（private/family/teacher/public） |

```typescript
/**
 * 活动指标 - 按活动类型携带不同的指标数据

interface ActivityMetrics {
    // 练习/考试类活动
    question_count?: number;          // 题目数量
    correct_count?: number;           // 正确数
    correct_rate?: number;            // 正确率
    avg_time_per_question?: number;   // 平均每题用时(秒)

    // AI对话类活动
    message_count?: number;           // 消息轮数
    token_consumed?: number;          // Token消耗量
    satisfaction_rating?: number;     // 用户满意度评分(1-5)

    // 章节学习类活动
    progress_before?: number;         // 学习前进度
    progress_after?: number;          // 学习后进度
    mastery_level?: number;           // 掌握度(0-1)

    // 错题类活动
    mistake_count?: number;           // 涉及错题数
    review_result?: 'correct' | 'wrong' | 'partial'; // 复习结果

    // 作文类活动
    word_count?: number;              // 作文字数
    essay_score?: number;             // 作文评分

    // 语音类活动
```

## 3. 活动采集架构

### 3.1 事件接入方式

采用 **Kafka 消费 + 内部事件总线** 双通道模式：

```
                    ┌─────────────────────────────┐
                    │       Kafka Topic            │
                    │  learning-activity-events    │
                    └──────────┬──────────────────┘
                               │
                    ┌──────────▼──────────────────┐
                    │   ActivityIngestService      │
                    │   (活动采集器)                │
                    │                              │
                    │   ┌────────────────────┐     │
                    │   │ EventNormalizer    │     │  归一化事件格式
```

### 3.4 事件去重与幂等

```typescript
/**
 * 事件去重器 - 基于 event_id 的幂等处理
 */
export class EventDeduplicator {
    private redis: RedisClient;
    private readonly DEDUP_TTL = 86400; // 24小时去重窗口

    /**
     * 检查事件是否已处理
     * 使用 Redis SET NX 实现原子性去重
     */
    async isDuplicate(eventId: string): Promise<boolean> {
        const key = `activity:dedup:${eventId}`;
        const result = await this.redis.set(key, '1', 'EX', this.DEDUP_TTL, 'NX');
        return result === null; // null 表示key已存在，即重复事件
    }
}

/**
 * 活动写入器 - 幂等写入
 */
export class ActivityWriter {
    /**
     * 写入活动记录（幂等）
     * 如果 activity_id 已存在则更新而非重复插入
     */
    async writeActivity(activity: ActivityRecord): Promise<void> {
        await this.db.query(
            `INSERT INTO learning_activity 
             (activity_id, user_id, source_module, activity_type, activity_title, 
              activity_desc, subject_code, chapter_id, knowledge_point_ids,
              activity_duration, activity_metrics, activity_status, visibility,
              device_type, session_id, parent_activity_id, tags, started_at, ended_at)
             VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
             ON DUPLICATE KEY UPDATE
              activity_status = VALUES(activity_status),
              activity_metrics = VALUES(activity_metrics),
              ended_at = VALUES(ended_at),
              updated_at = NOW(3)`,
            [
                activity.activity_id, activity.user_id, activity.source_module,
                activity.activity_type, activity.activity_title, activity.activity_desc,
                activity.subject_code, activity.chapter_id,
                JSON.stringify(activity.knowledge_point_ids),
                activity.activity_duration, JSON.stringify(activity.activity_metrics),
                activity.activity_status, activity.visibility,
                activity.device_type, activity.session_id,
                activity.parent_activity_id, JSON.stringify(activity.tags),
                activity.started_at, activity.ended_at
            ]
        );

        // 更新时间线缓存
        await this.updateTimelineCache(activity.user_id, activity.activity_id, activity.started_at);
        // 更新详情缓存
        await this.updateDetailCache(activity.activity_id, activity);
        // 更新日摘要缓存（增量）
        await this.incrementDailySummary(activity);
    }
}
```

```typescript
/**
 * 活动时间线查询服务
 */
export class ActivityTimelineQueryService {

    /**
     * 分页查询用户活动时间线
     * 优先走缓存，缓存未命中走DB
     */
    async queryTimeline(params: TimelineQueryParams): Promise<TimelineQueryResult> {
        const { userId, cursor, limit, filters } = params;

        // 1. 解析游标
        const { lastTimestamp, lastActivityId } = this.parseCursor(cursor);

        // 2. 尝试缓存查询（仅最近7天的数据走缓存）
        if (this.isWithinCacheWindow(lastTimestamp)) {
            const cached = await this.queryFromCache(userId, lastTimestamp, limit, filters);
            if (cached.activities.length >= limit) {
                return this.buildResult(cached.activities, cached.nextCursor);
            }
        }

        // 3. 缓存未命中，查询数据库
        const dbResult = await this.queryFromDatabase(userId, lastTimestamp, lastActivityId, limit, filters);

        // 4. 异步回填缓存
        if (dbResult.activities.length > 0) {
            this.backfillCache(userId, dbResult.activities).catch(err => 
                this.logger.error('Cache backfill failed', { error: err.message })
            );
        }

        // 5. 补充展示信息（章节名、知识点名等）
        const enriched = await this.enrichActivities(dbResult.activities);

        return this.buildResult(enriched, dbResult.nextCursor);
    }

    /**
     * 数据库查询 - 使用游标分页避免深度翻页
     */
    private async queryFromDatabase(
        userId: number,
        lastTimestamp: Date | null,
        lastActivityId: string | null,
        limit: number,
        filters: ActivityFilters
    ): Promise<{ activities: ActivityRecord[]; nextCursor: string | null }> {
        const conditions = ['user_id = ?'];
        const params: any[] = [userId];

        // 游标条件：started_at < cursor_time OR (started_at = cursor_time AND activity_id < cursor_id)
        if (lastTimestamp && lastActivityId) {
            conditions.push('(started_at < ? OR (started_at = ? AND activity_id < ?))');
            params.push(lastTimestamp, lastTimestamp, lastActivityId);
        }

        // 日期范围
        if (filters.startDate) {
            conditions.push('started_at >= ?');
            params.push(filters.startDate);
        }
        if (filters.endDate) {
            conditions.push('started_at <= ?');
            params.push(filters.endDate);
        }

        // 模块过滤
        if (filters.sourceModules?.length) {
            conditions.push(`source_module IN (${filters.sourceModules.map(() => '?').join(',')})`);
            params.push(...filters.sourceModules);
        }

        // 学科过滤
        if (filters.subjectCode) {
            conditions.push('subject_code = ?');
            params.push(filters.subjectCode);
        }

        // 活动类型过滤
        if (filters.activityTypes?.length) {
            conditions.push(`activity_type IN (${filters.activityTypes.map(() => '?').join(',')})`);
            params.push(...filters.activityTypes);
        }

        // 可见性过滤
        if (filters.viewerRole) {
            const visibilityMap = {
                'student': 'visibility >= 0',     // 自己可见全部
                'parent': 'visibility >= 1',       // family及以上
                'teacher': 'visibility >= 2',      // teacher及以上
                'ai': 'visibility >= 1'            // AI上下文用family级
            };
            conditions.push(visibilityMap[filters.viewerRole] || 'visibility >= 0');
        }

        const sql = `
            SELECT * FROM learning_activity
            WHERE ${conditions.join(' AND ')}
            ORDER BY started_at DESC, activity_id DESC
            LIMIT ${limit + 1}
        `;

        const rows = await this.db.query(sql, params);

        const hasMore = rows.length > limit;
        const activities = hasMore ? rows.slice(0, limit) : rows;
        const nextCursor = hasMore
            ? this.buildCursor(activities[activities.length - 1])
            : null;

        return { activities, nextCursor };
    }
}
```

```typescript
    /**
     * 生成亮点 - 基于当日活动数据自动提取亮点
     */
    private async generateHighlights(
        activities: ActivityRecord[],
        userId: number,
        date: string
    ): Promise<string[]> {
        const highlights: string[] = [];

        // 亮点1: 练习正确率提升
        const practiceActivities = activities.filter(a => a.source_module === 'practice');
        if (practiceActivities.length > 0) {
            const avgRate = this.weightedAvg(practiceActivities, 'correct_rate');
            const yesterdayRate = await this.getYesterdayCorrectRate(userId, date);
            if (yesterdayRate && avgRate > yesterdayRate + 0.05) {
                highlights.push(
                    `练习正确率达到${Math.round(avgRate * 100)}%，较昨日提升${Math.round((avgRate - yesterdayRate) * 100)}%`
                );
            } else if (avgRate >= 0.9) {
                highlights.push(`练习正确率高达${Math.round(avgRate * 100)}%，表现优秀！`);
            }
        }

        // 亮点2: 错题订正完成
        const mistakeActivities = activities.filter(a => a.activity_type === 'mistake_review');
        if (mistakeActivities.length > 0) {
            const corrected = mistakeActivities.reduce(
                (sum, a) => sum + (a.activity_metrics?.review_result === 'correct' ? 1 : 0), 0
            );
            if (corrected > 0) {
                highlights.push(`完成${corrected}道错题订正`);
            }
        }

        // 亮点3: 学习时长达标
        const totalDuration = activities.reduce((s, a) => s + (a.activity_duration || 0), 0);
        const dailyGoal = await this.getDailyGoal(userId);
        if (dailyGoal && totalDuration >= dailyGoal) {
            highlights.push(`完成今日学习目标${this.formatDuration(dailyGoal)}`);
        }

        // 亮点4: 新章节学习
        const chapterComplete = activities.filter(a => a.activity_type === 'chapter_complete');
        if (chapterComplete.length > 0) {
            highlights.push(`完成了${chapterComplete.length}个章节的学习`);
        }

        return highlights;
    }

    /**

        // 查询本周每日摘要
        const dailySummaries = await this.summaryRepository.findByRange(
            userId, 1, weekStart, weekEnd
        );

        // 聚合模块统计
        const moduleStats = this.mergeModuleStats(dailySummaries);

        // 计算学科分布
        const subjectDistribution = this.calculateSubjectDistribution(dailySummaries);

        // 生成每日明细
        const dailyBreakdown = dailySummaries.map(s => ({
            date: s.summary_date,
            duration: s.total_duration,
            activities: s.total_activities
        }));

        // 与上周对比
        const lastWeekStart = this.addDays(weekStart, -7);
        const lastWeekSummaries = await this.summaryRepository.findByRange(
            userId, 1, lastWeekStart, this.addDays(lastWeekStart, 6)
        );
        const comparison = this.compareWeeks(dailySummaries, lastWeekSummaries);

        // 生成周亮点
        const highlights = this.generateWeeklyHighlights(dailySummaries, comparison);

        const summary: WeeklySummary = {
            summary_id: uuidv4(),
            user_id: userId,
            summary_type: 2,
            summary_date: weekStart,
            period_start: weekStart,
            period_end: weekEnd,
            total_activities: dailySummaries.reduce((s, d) => s + d.total_activities, 0),
            total_duration: dailySummaries.reduce((s, d) => s + d.total_duration, 0),

            comparison
        };

    }
```

```typescript
/**
 * 活动推送引擎 - 实时通知订阅者
 */
export class ActivityPushNotifier {

    private redis: RedisClient;
    private wsManager: WebSocketManager;

    /**
     * 推送新活动通知给所有订阅者
     */
    async notifyNewActivity(activity: ActivityRecord): Promise<void> {
        // 1. 查询该学生的所有订阅者（家长、教师）
        const subscribers = await this.getSubscribers(activity.user_id);

        for (const subscriber of subscribers) {
            // 2. 检查可见性
            if (!this.isVisible(activity, subscriber.role)) {
                continue;
            }

            // 3. 增加未读计数
            await this.incrementUnreadCount(subscriber.subscriber_id, activity.user_id);

            // 4. WebSocket 推送
            const pushed = await this.wsManager.sendToUser(subscriber.subscriber_id, {
                type: 'activity_new',
                data: {
                    activity: this.toPushFormat(activity)
                },
                timestamp: new Date().toISOString()
            });

            // 5. 如果 WebSocket 推送失败，评估是否需要离线推送
            if (!pushed && this.shouldSendOfflineNotification(activity, subscriber)) {
                await this.sendOfflineNotification(subscriber, activity);
            }
        }
    }

    /**
     * 离线推送策略 - 避免过度打扰
     */
    private shouldSendOfflineNotification(
        activity: ActivityRecord,
        subscriber: Subscriber
    ): boolean {
        // 1. 检查推送时间窗口（仅 8:00-22:00 推送）
        const hour = new Date().getHours();
        if (hour < 8 || hour > 22) return false;

        // 2. 检查今日推送次数（家长每日最多5条离线推送）
        if (subscriber.today_push_count >= 5) return false;

        // 3. 检查推送类型策略
        const pushableTypes = [
            'achievement_unlock',      // 成就解锁
            'chapter_complete',        // 章节完成
            'exam_session',            // 考试完成
            'essay_review',            // 作文批改完成
        ];

        // 里程碑类活动始终推送
        if (pushableTypes.includes(activity.activity_type)) return true;

        // 学习时长超过2小时时推送一次提醒
        if (activity.activity_duration && activity.activity_duration >= 7200) return true;

        // 默认不推送（避免频繁打扰）
        return false;
    }
}
```

```typescript
export class VisibilityResolver {

    private static readonly DEFAULT_VISIBILITY: Record<string, ActivityVisibility> = {
        'ai_dialogue': ActivityVisibility.FAMILY,           // AI对话默认family（内容不外泄）
        'ai_dialogue_followup': ActivityVisibility.PRIVATE,  // 追问细节仅自己可见
        'photo_search': ActivityVisibility.FAMILY,
        'chapter_study': ActivityVisibility.TEACHER,         // 章节学习教师可见
        'chapter_complete': ActivityVisibility.PUBLIC,       // 章节完成可公开展示
        'practice_session': ActivityVisibility.TEACHER,
        'exam_session': ActivityVisibility.TEACHER,
        'mistake_added': ActivityVisibility.FAMILY,          // 错题仅家庭可见
        'mistake_review': ActivityVisibility.TEACHER,
        'essay_submit': ActivityVisibility.FAMILY,
        'essay_review': ActivityVisibility.FAMILY,
        'recite_check': ActivityVisibility.TEACHER,
        'plan_task_done': ActivityVisibility.TEACHER,
        'achievement_unlock': ActivityVisibility.PUBLIC,
    };

    /**
     * 根据学段调整可见性
     */
    resolve(activityType: string, studentStage: string, explicitVisibility?: string): ActivityVisibility {
        let visibility = explicitVisibility
            ? this.parseVisibility(explicitVisibility)
            : VisibilityResolver.DEFAULT_VISIBILITY[activityType] ?? ActivityVisibility.FAMILY;

        // 初中生及以上：AI对话降级为PRIVATE（保护隐私）
        if (studentStage === 'junior' || studentStage === 'senior') {
            if (activityType === 'ai_dialogue') {
                visibility = ActivityVisibility.PRIVATE;
            }
        }

        return visibility;
    }
}
```

## 8. 性能优化

### 8.1 写入优化

1. **批量写入**：高频活动（如答题过程）先在内存中缓冲，每5秒或满50条批量写入
2. **异步管道**：事件采集 → 归一化 → 写入 → 缓存更新 → 推送 全异步
3. **分区表**：按月分区 `learning_activity` 表，避免单表数据量过大
4. **写入分离**：活动写入走主库，查询走从库

### 8.2 查询优化

1. **游标分页**：避免 `OFFSET` 深度翻页，使用 `(started_at, activity_id)` 复合游标
2. **缓存优先**：最近7天数据走 Redis ZSET 缓存，命中率目标 ≥ 85%
3. **摘要预计算**：日/周/月摘要预计算并缓存，查询时直接读缓存
4. **延迟扩展**：查询活动详情时，章节名、知识点名等扩展信息走独立缓存

### 8.3 缓存策略

```typescript
/**
 * 缓存策略管理
 */
export class ActivityCacheStrategy {

    // 时间线缓存：ZSET，保留最近7天活动ID
    async warmTimelineCache(userId: number): Promise<void> {
        const recentActivities = await this.db.query(
            `SELECT activity_id, started_at FROM learning_activity
             WHERE user_id = ? AND started_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
             ORDER BY started_at DESC LIMIT 200`,
            [userId]
        );

        if (recentActivities.length === 0) return;

        const cacheKey = `activity:timeline:${userId}`;
        const pipeline = this.redis.pipeline();

        // 先清除旧缓存
        pipeline.del(cacheKey);

        // 批量添加
        for (const act of recentActivities) {
            pipeline.zadd(cacheKey, act.started_at.getTime(), act.activity_id);
        }

        // 设置TTL
        pipeline.expire(cacheKey, 3600);

        await pipeline.exec();
    }

    // 日摘要缓存：当天活动结束后缓存有效期至次日1点
    getTTLForDate(date: string): number {
        const now = new Date();
        const target = new Date(date);
        target.setDate(target.getDate() + 1);
        target.setHours(1, 0, 0, 0);
        return Math.max(0, Math.floor((target.getTime() - now.getTime()) / 1000));
    }
}
```

## 9. 错误处理与降级

### 9.1 错误处理策略

| 错误场景 | 处理策略 |
|----------|----------|
| Kafka 消费失败 | 重试3次，仍失败则写入死信队列，告警通知 |
| DB 写入失败 | 重试2次（指数退避），仍失败则写入本地降级队列，后台补偿 |
| Redis 缓存更新失败 | 记录日志但不阻塞主流程，下次查询回源DB |
| 摘要生成失败 | 标记为"待重试"，下次定时任务补偿生成 |
| WebSocket 推送失败 | 降级为离线推送（APNs/FCM） |
| 查询超时 | 返回部分结果 + 降级标记，建议客户端使用缓存数据 |

### 9.2 降级方案

```typescript
/**
 * 降级控制器
 */
export class ActivityDegradationController {

    /**
     * 查询降级：缓存全挂时直接查DB，但降低limit
     */
    async queryWithDegradation(params: TimelineQueryParams): Promise<TimelineQueryResult> {
        try {
            // 正常流程：缓存优先
            return await this.queryService.queryTimeline(params);
        } catch (error) {
            if (this.isCacheError(error)) {
                // 降级：直接查DB，降低limit
                this.logger.warn('Cache unavailable, degrading to DB-only query', { 
                    error: error.message 
                });
                return await this.queryService.queryTimelineFromDB({
                    ...params,
                    limit: Math.min(params.limit, 10) // 降级时降低分页大小
                });
            }
            throw error;
        }
    }

    /**
     * 摘要降级：摘要生成失败时返回简版摘要
     */
    async getSummaryWithDegradation(userId: number, date: string): Promise<DailySummary> {
        try {
            return await this.summaryService.getDailySummary(userId, date);
        } catch (error) {
            // 降级：实时计算简版摘要
            this.logger.warn('Summary cache miss, computing on-the-fly', {
                userId, date, error: error.message
            });
            return await this.summaryService.computeSimpleSummary(userId, date);
        }
    }
}
```
