# 服务端-教师端教学仪表盘数据聚合与教学决策智能辅助引擎-详细设计

## 1. 概述

### 1.1 功能定位

教师端教学仪表盘数据聚合与教学决策智能辅助引擎（以下简称"教学仪表盘引擎"）是 PrimeTop 教师端产品的核心数据中枢，负责将分散在题库服务、作业服务、学情分析服务、考试服务、错题服务、家校沟通等多个微服务中的教学相关数据，按照教师实际教学决策场景进行统一聚合、多维分析和智能洞察提取，为教师提供一站式的教学态势感知与决策辅助支持。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 数据聚合 | 跨 7+ 业务服务的数据统一汇聚，T+0 实时刷新核心指标 |
| 决策支持 | 基于数据自动生成教学建议（如"建议重点讲解二次函数"） |
| 多场景适配 | 日常教学、考前复习、考后讲评、家校沟通四种核心场景 |
| 低延迟 | 首屏加载 ≤ 1.5s，指标查询 ≤ 500ms |
| 分层信息 | 概览 → 详情 → 个体三级渐进式信息展示 |

### 1.3 与已有模块的关系

| 已有模块 | 关系 |
| --- | --- |
| 服务端-班级学情诊断与共性薄弱知识点靶向教学推荐引擎 | 本引擎调用其诊断结果作为"教学建议"数据源 |
| 服务端-考后试卷深度分析与个性化讲评报告生成服务 | 本引擎调用其分析结果作为"考后看板"数据源 |
| 服务端-教师班级管理与作业发布服务 | 本引擎读取班级列表和作业完成数据 |
| 服务端-家校沟通与班级协作消息服务 | 本引擎推送"需关注的家长沟通"到消息服务 |
| 服务端-差异化作业智能编排与分层练习分发引擎 | 本引擎推送"建议布置分层作业"建议 |
| 管理后台-教师与班级数据管理工作台 | 管理后台对教师进行管理，本引擎为教师本人提供数据 |

### 1.4 适用范围

- 服务对象：班级任课教师、班主任、年级组长
- 学段覆盖：小学、初中、高中
- 班级规模：单教师 1-10 个班级，单班级 30-60 名学生

## 2. 整体架构

### 2.1 架构总览

```
┌─────────────────────────────────────────────────────────────────┐
│                    教师端 APP / 教师端 Web                        │
├─────────────────────────────────────────────────────────────────┤
│              BFF 聚合层 (Teacher Dashboard BFF)                   │
│   ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────────┐  │
│   │ 概览卡片  │ │ 班级详情  │ │ 个体追踪  │ │ 教学建议工作台    │  │
│   │ Resolver  │ │ Resolver  │ │ Resolver  │ │ Resolver          │  │
│   └─────┬────┘ └─────┬────┘ └─────┬────┘ └────────┬─────────┘  │
├─────────┼────────────┼────────────┼────────────────┼────────────┤
│         │    教学仪表盘引擎 (本服务)                │            │
│  ┌──────▼──────────────▼──────────────────────────▼──────────┐  │
│  │              数据聚合编排层 (Aggregation Orchestrator)      │  │
│  │  ┌─────────┐ ┌─────────┐ ┌──────────┐ ┌────────────────┐ │  │
│  │  │指标计算 │ │洞察生成 │ │建议决策   │ │场景路由         │ │  │
│  │  │Pipeline │ │Engine   │ │Engine    │ │Engine          │ │  │
│  │  └─────────┘ └─────────┘ └──────────┘ └────────────────┘ │  │
│  └──────────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────────┤
│                    数据源适配层 (Source Adapters)                 │
│  ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐ ┌────────┐ │
│  │作业服务│ │学情服务│ │考试服务│ │错题服务│ │消息服务│ │题库服务│ │
│  └───────┘ └───────┘ └───────┘ └───────┘ └───────┘ └────────┘ │
├─────────────────────────────────────────────────────────────────┤
│                      存储层                                      │
│  ┌───────────┐  ┌──────────────┐  ┌────────────────────────┐  │
│  │ Redis     │  │ MySQL        │  │ ClickHouse             │  │
│  │ (缓存层)   │  │ (配置/元数据) │  │ (聚合指标/趋势分析)     │  │
│  └───────────┘  └──────────────┘  └────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 核心流程

```
教师打开仪表盘 → BFF 并行调用多个 Resolver → Resolver 向引擎请求聚合数据
→ 引擎编排数据源适配器并行拉取 → 指标计算 Pipeline 处理 → 洞察/建议生成
→ 返回结构化看板数据 → BFF 组装为前端友好格式 → 渲染
```

## 3. 数据结构定义

### 3.1 核心数据模型

#### 3.1.1 教师所辖班级关系 (teacher_class_binding)

```sql
CREATE TABLE teacher_class_binding (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    teacher_id      BIGINT NOT NULL COMMENT '教师用户ID',
    class_id        BIGINT NOT NULL COMMENT '班级ID',
    subject_id      BIGINT NOT NULL COMMENT '学科ID',
    role            VARCHAR(20) NOT NULL DEFAULT 'subject_teacher' 
                    COMMENT 'subject_teacher=任课教师, head_teacher=班主任',
    is_active       TINYINT(1) NOT NULL DEFAULT 1,
    academic_year   VARCHAR(9) NOT NULL COMMENT '学年 如2026-2027',
    semester        TINYINT NOT NULL COMMENT '1=上学期, 2=下学期',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_teacher_class_subject (teacher_id, class_id, subject_id, academic_year, semester),
    INDEX idx_class (class_id, academic_year, semester)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教师班级绑定关系';
```

#### 3.1.2 看板指标快照表 (dashboard_metric_snapshot)

```sql
CREATE TABLE dashboard_metric_snapshot (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    teacher_id      BIGINT NOT NULL,
    class_id        BIGINT NOT NULL,
    subject_id      BIGINT NOT NULL,
    snapshot_date   DATE NOT NULL COMMENT '快照日期',
    scope           VARCHAR(20) NOT NULL COMMENT 'class=班级, student=个体',
    target_id       BIGINT COMMENT 'scope=student时为学生ID，否则NULL',
    metric_key      VARCHAR(100) NOT NULL COMMENT '指标键名',
    metric_value    DECIMAL(12,4) NOT NULL COMMENT '指标值',
    metric_extra    JSON COMMENT '附加维度信息',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_snapshot (teacher_id, class_id, subject_id, snapshot_date, scope, target_id, metric_key),
    INDEX idx_teacher_date (teacher_id, snapshot_date),
    INDEX idx_class_date (class_id, snapshot_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='看板指标每日快照';
```

#### 3.1.3 教学建议记录 (teaching_suggestion)

```sql
CREATE TABLE teaching_suggestion (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    teacher_id      BIGINT NOT NULL,
    class_id        BIGINT NOT NULL,
    subject_id      BIGINT NOT NULL,
    suggestion_type VARCHAR(50) NOT NULL COMMENT '建议类型见枚举',
    priority        TINYINT NOT NULL COMMENT '1=紧急 2=重要 3=一般 4=参考',
    title           VARCHAR(200) NOT NULL,
    content         TEXT NOT NULL COMMENT '建议内容(JSON)',
    evidence_data   JSON COMMENT '支撑数据',
    related_task_id BIGINT COMMENT '关联任务ID',
    status          VARCHAR(20) NOT NULL DEFAULT 'pending' 
                    COMMENT 'pending=待处理, accepted=已采纳, dismissed=已忽略, expired=已过期',
    expire_at       DATETIME COMMENT '建议有效期',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_teacher_status (teacher_id, status, priority),
    INDEX idx_class_type (class_id, suggestion_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教学建议记录';
```

#### 3.1.4 看板场景配置 (dashboard_scenario_config)

```sql
CREATE TABLE dashboard_scenario_config (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    scenario_code   VARCHAR(50) NOT NULL UNIQUE COMMENT '场景编码',
    scenario_name   VARCHAR(100) NOT NULL,
    card_modules    JSON NOT NULL COMMENT '卡片模块配置',
    data_freshness  INT NOT NULL DEFAULT 300 COMMENT '数据新鲜度要求(秒)',
    cache_ttl       INT NOT NULL DEFAULT 600 COMMENT '缓存TTL(秒)',
    applicable_stage VARCHAR(50) COMMENT '适用学段(primary/middle/high/all)',
    is_active       TINYINT(1) NOT NULL DEFAULT 1,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='看板场景配置';
```

### 3.2 指标键值定义

| metric_key | 含义 | 单位 | 计算频率 |
| --- | --- | --- | --- |
| `homework.assign_count` | 已布置作业数 | 个 | 每日 |
| `homework.submit_rate` | 作业提交率 | % | 每日 |
| `homework.avg_score` | 作业平均分 | 分 | 每日 |
| `homework.completion_rate` | 作业完成率 | % | 每日 |
| `exercise.total_count` | 学生总练习题数 | 题 | 每日 |
| `exercise.avg_accuracy` | 平均正确率 | % | 每日 |
| `knowledge.mastery_avg` | 知识点平均掌握度 | % | 每日 |
| `knowledge.weak_count` | 薄弱知识点数 | 个 | 每日 |
| `mistake.new_count` | 新增错题数 | 题 | 每日 |
| `mistake.review_rate` | 错题复习率 | % | 每日 |
| `exam.avg_score` | 考试平均分 | 分 | 考试后 |
| `exam.pass_rate` | 考试及格率 | % | 考试后 |
| `exam.score_distribution` | 分数段分布 | JSON | 考试后 |
| `student.active_count` | 活跃学生数 | 人 | 每日 |
| `student.at_risk_count` | 预警学生数 | 人 | 每日 |
| `parent.unread_messages` | 未读家长消息 | 条 | 实时 |

## 5. 核心模块详细设计

### 5.1 数据聚合编排层 (Aggregation Orchestrator)

#### 5.1.1 设计思路

仪表盘一次加载需要聚合来自 5-7 个微服务的数据。采用 **并行扇出 + 结果合并** 模式，利用 CompletableFuture 实现异步编排。

```java
@Service
public class DashboardAggregationOrchestrator {
    
    @Resource
    private HomeworkSourceAdapter homeworkAdapter;
    @Resource
    private LearningAnalyticsAdapter analyticsAdapter;
    @Resource
    private ExamSourceAdapter examAdapter;
    @Resource
    private MistakeSourceAdapter mistakeAdapter;
    @Resource
    private MessageSourceAdapter messageAdapter;
    @Resource
    private KnowledgeGraphAdapter knowledgeAdapter;
    @Resource
    private MetricSnapshotService snapshotService;
    
    // 默认超时时间
    private static final long SOURCE_TIMEOUT_MS = 800;
    
    /**
     * 聚合班级概览数据
     */
    public ClassOverviewDTO aggregateClassOverview(Long teacherId, Long classId, 
                                                    Long subjectId, LocalDate date) {
        // 1. 优先尝试从快照缓存读取
        ClassOverviewDTO cached = snapshotService.tryGetClassOverview(classId, subjectId, date);
        if (cached != null && cached.isFresh(Duration.ofMinutes(10))) {
            return cached;
        }
        
        // 2. 并行扇出拉取各数据源
        CompletableFuture<HomeworkSummaryDTO> homeworkFuture = 
            CompletableFuture.supplyAsync(() -> 
                homeworkAdapter.getClassHomeworkSummary(classId, subjectId, date))
                .orTimeout(SOURCE_TIMEOUT_MS, TimeUnit.MILLISECONDS);
        
        CompletableFuture<LearningAnalyticsDTO> analyticsFuture = 
            CompletableFuture.supplyAsync(() -> 
                analyticsAdapter.getClassAnalytics(classId, subjectId, date, 7))
                .orTimeout(SOURCE_TIMEOUT_MS, TimeUnit.MILLISECONDS);
        
        CompletableFuture<MistakeSummaryDTO> mistakeFuture = 
            CompletableFuture.supplyAsync(() -> 
                mistakeAdapter.getClassMistakeSummary(classId, subjectId, date))
                .orTimeout(SOURCE_TIMEOUT_MS, TimeUnit.MILLISECONDS);
        
        CompletableFuture<Integer> unreadMsgFuture = 
            CompletableFuture.supplyAsync(() -> 
                messageAdapter.getUnreadParentMessageCount(classId, teacherId))
                .orTimeout(SOURCE_TIMEOUT_MS, TimeUnit.MILLISECONDS);
        
        CompletableFuture<KnowledgeMasteryDTO> knowledgeFuture = 
            CompletableFuture.supplyAsync(() -> 
                knowledgeAdapter.getClassKnowledgeMastery(classId, subjectId))
                .orTimeout(SOURCE_TIMEOUT_MS, TimeUnit.MILLISECONDS);
        
        // 3. 合并结果，容忍部分失败
        ClassOverviewDTO overview = new ClassOverviewDTO();
        
        mergeSafe(overview, () -> {
            HomeworkSummaryDTO hw = homeworkFuture.get();
            overview.setHomeworkSubmitRate(hw.getSubmitRate());
            overview.setHomeworkAvgScore(hw.getAvgScore());
            overview.setUnsubmittedCount(hw.getUnsubmittedCount());
        });
        
        mergeSafe(overview, () -> {
            LearningAnalyticsDTO la = analyticsFuture.get();
            overview.setActiveStudentCount(la.getActiveCount());
            overview.setAvgAccuracy(la.getAvgAccuracy());
            overview.setTrend7d(la.getDailyTrends());
        });
        
        mergeSafe(overview, () -> {
            MistakeSummaryDTO ms = mistakeFuture.get();
            overview.setNewMistakeCount(ms.getNewCount());
            overview.setMistakeReviewRate(ms.getReviewRate());
        });
        
        mergeSafe(overview, () -> 
            overview.setUnreadParentMessages(unreadMsgFuture.get()));
        
        mergeSafe(overview, () -> {
            KnowledgeMasteryDTO km = knowledgeFuture.get();
            overview.setWeakKnowledgeCount(km.getWeakCount());
            overview.setAtRiskCount(km.getAtRiskCount());
        });
        
        // 4. 计算告警等级
        overview.setAlertLevel(calculateAlertLevel(overview));
        overview.setAlertSummary(generateAlertSummary(overview));
        
        // 5. 异步写入快照
        snapshotService.asyncSaveClassOverview(classId, subjectId, date, overview);
        
        return overview;
    }
    
    /**
     * 安全合并 - 单数据源失败不影响整体
     */
    private void mergeSafe(ClassOverviewDTO target, Runnable merger) {
        try {
            merger.run();
        } catch (Exception e) {
            log.warn("数据源合并失败，跳过: {}", e.getMessage());
            // 部分失败标记
            target.addPartialFailure(e.getMessage());
        }
    }
    
    /**
     * 告警等级计算
     */
    private AlertLevel calculateAlertLevel(ClassOverviewDTO overview) {
        int riskScore = 0;
        
        if (overview.getHomeworkSubmitRate() < 0.70) riskScore += 3;
        else if (overview.getHomeworkSubmitRate() < 0.85) riskScore += 1;
        
        if (overview.getAvgAccuracy() < 0.60) riskScore += 3;
        else if (overview.getAvgAccuracy() < 0.70) riskScore += 1;
        
        if (overview.getAtRiskCount() >= 8) riskScore += 3;
        else if (overview.getAtRiskCount() >= 5) riskScore += 1;
        
        if (overview.getActiveStudentCount() < overview.getTotalStudents() * 0.8) riskScore += 2;
        
        if (riskScore >= 6) return AlertLevel.RED;
        if (riskScore >= 3) return AlertLevel.YELLOW;
        return AlertLevel.GREEN;
    }
}
```

```java
@Scheduled(cron = "0 0 2 * * ?")
public void dailyMetricPreCompute() {
    List<TeacherClassBinding> bindings = bindingService.getAllActiveBindings();
    LocalDate yesterday = LocalDate.now().minusDays(1);
    
    for (TeacherClassBinding binding : bindings) {
        try {
            // 并行计算班级维度和个体维度指标
            CompletableFuture<ClassMetrics> classMetricsFuture = 
                CompletableFuture.supplyAsync(() -> 
                    computeClassMetrics(binding, yesterday));
            
            CompletableFuture<List<StudentMetrics>> studentMetricsFuture = 
                CompletableFuture.supplyAsync(() -> 
                    computeStudentMetrics(binding, yesterday));
            
            ClassMetrics classMetrics = classMetricsFuture.get(30, TimeUnit.SECONDS);
            List<StudentMetrics> studentMetrics = studentMetricsFuture.get(60, TimeUnit.SECONDS);
            
            // 批量写入快照表
            snapshotRepository.batchInsertClassMetrics(binding, yesterday, classMetrics);
            snapshotRepository.batchInsertStudentMetrics(binding, yesterday, studentMetrics);
            
        } catch (Exception e) {
            log.error("指标预计算失败: teacher={}, class={}, date={}", 
                binding.getTeacherId(), binding.getClassId(), yesterday, e);
            // 发送告警
            alertService.sendMetricComputeFailure(binding, yesterday, e);
        }
    }
}
```

```java
@Service
public class TeachingInsightEngine {
    
    @Resource
    private List<InsightRule> insightRules;
    @Resource
    private AiInsightGenerator aiGenerator;
    @Resource
    private TeachingSuggestionRepository suggestionRepo;
    
    /**
     * 生成教学洞察与建议
     * 每日定时执行，也可由教师主动触发
     */
    public List<TeachingSuggestion> generateInsights(Long teacherId, Long classId, 
                                                      Long subjectId, LocalDate date) {
        // 1. 加载看板数据
        DashboardData data = loadDataForInsight(teacherId, classId, subjectId, date);
        
        // 2. 执行规则引擎
        List<TeachingSuggestion> ruleSuggestions = new ArrayList<>();
        for (InsightRule rule : insightRules) {
            if (rule.matches(data)) {
                TeachingSuggestion suggestion = rule.generate(data);
                if (shouldGenerate(suggestion, data)) { // 去重/频控
                    ruleSuggestions.add(suggestion);
                }
            }
        }
        
        // 3. AI 增强建议（基于规则结果进一步分析）
        if (!ruleSuggestions.isEmpty()) {
            List<TeachingSuggestion> enhanced = aiGenerator.enhanceSuggestions(
                ruleSuggestions, data);
            ruleSuggestions = enhanced;
        }
        
        // 4. 按优先级排序
        ruleSuggestions.sort(Comparator.comparing(TeachingSuggestion::getPriority));
        
        // 5. 限制建议数量（每日最多5条，避免信息过载）
        if (ruleSuggestions.size() > 5) {
            ruleSuggestions = ruleSuggestions.subList(0, 5);
        }
        
        // 6. 持久化
        suggestionRepo.batchInsert(ruleSuggestions);
        
        return ruleSuggestions;
    }
}
```

```java
/**

@Component
public class LowMasteryInsightRule implements InsightRule {
    
    private static final double MASTERY_THRESHOLD = 0.60;
    private static final int MIN_AFFECTED_STUDENTS = 10;
    private static final double MIN_ERROR_CONCENTRATION = 0.40;
    
    @Override
    public boolean matches(DashboardData data) {
        return data.getKnowledgeMasteryList().stream()
            .anyMatch(km -> km.getMasteryAvg() < MASTERY_THRESHOLD 
                && km.getAffectedStudents() >= MIN_AFFECTED_STUDENTS);
    }
    
    @Override
    public TeachingSuggestion generate(DashboardData data) {
        List<KnowledgeMasteryDTO> weakPoints = data.getKnowledgeMasteryList().stream()
            .filter(km -> km.getMasteryAvg() < MASTERY_THRESHOLD 
                && km.getAffectedStudents() >= MIN_AFFECTED_STUDENTS)
            .sorted(Comparator.comparing(KnowledgeMasteryDTO::getMasteryAvg))
            .collect(Collectors.toList());
        
        KnowledgeMasteryDTO weakest = weakPoints.get(0);
        
        return TeachingSuggestion.builder()
            .teacherId(data.getTeacherId())
            .classId(data.getClassId())
            .subjectId(data.getSubjectId())
            .type(TeachingSuggestionType.KNOWLEDGE_RETEACH)
            .priority(calculatePriority(weakest))
            .title(String.format("「%s」掌握度偏低(%.0f%%)", 
                weakest.getKpName(), weakest.getMasteryAvg() * 100))
            .content(buildContent(weakest, weakPoints))
            .evidenceData(buildEvidence(weakest))
            .expireAt(LocalDateTime.now().plusDays(3))
            .build();
    }
    
    private Map<String, Object> buildContent(KnowledgeMasteryDTO weakest, 
                                              List<KnowledgeMasteryDTO> allWeak) {
        Map<String, Object> content = new HashMap<>();
        content.put("knowledge_point", weakest.getKpName());
        content.put("kp_id", weakest.getKpId());
        content.put("current_mastery", weakest.getMasteryAvg());
        content.put("target_mastery", 0.75);
        content.put("affected_students", weakest.getAffectedStudents());
        
        // 错误模式分析
        List<Map<String, Object>> errorPatterns = weakest.getTopErrorPatterns().stream()
            .limit(3)
            .map(ep -> {
                Map<String, Object> p = new HashMap<>();
                p.put("pattern", ep.getPattern());
                p.put("affected_count", ep.getCount());
                return p;
            })
            .collect(Collectors.toList());
        content.put("error_patterns", errorPatterns);
        
        // 建议行动
        List<String> actions = new ArrayList<>();
        if (weakest.getMasteryAvg() < 0.40) {
            actions.add(String.format("安排1课时(%d分钟)重点讲解%s", 
                40, weakest.getKpName()));
        } else {
            actions.add(String.format("安排15-20分钟课堂复习%s", weakest.getKpName()));
        }
        
        // 查找已有的相关课件和练习
        List<ResourceRef> resources = resourceService.findRelatedResources(
            weakest.getKpId(), data.getSubjectId(), data.getStage());
        if (!resources.isEmpty()) {
            actions.add(String.format("使用平台「互动课件」中的「%s」", 
                resources.get(0).getTitle()));
        }
        
        // 查找已有题集
        ExerciseSetRef exerciseSet = exerciseService.findRelatedExerciseSet(
            weakest.getKpId(), weakest.getMasteryAvg());
        if (exerciseSet != null) {
            actions.add(String.format("布置「%s」(题集#%d)", 
                exerciseSet.getTitle(), exerciseSet.getId()));
        }
        
        content.put("suggested_actions", actions);
        content.put("estimated_time", estimateTime(weakest));
        
        return content;
    }
}

@Component
public class StudentDeclineInsightRule implements InsightRule {
    
    @Override
    public boolean matches(DashboardData data) {
        return data.getStudentRadars().stream()
            .anyMatch(s -> s.getImprovement() < -0.10 
                || (s.getActiveDays() < 4 && s.getAccuracy() < 0.60));
    }
    
    @Override
    public TeachingSuggestion generate(DashboardData data) {
        List<StudentRadarDTO> atRisk = data.getStudentRadars().stream()
            .filter(s -> s.getImprovement() < -0.10 
                || (s.getActiveDays() < 4 && s.getAccuracy() < 0.60))
            .collect(Collectors.toList());
        
        // 按严重程度排序
        atRisk.sort((a, b) -> {
            double scoreA = a.getImprovement() * (1 - a.getAccuracy());
            double scoreB = b.getImprovement() * (1 - b.getAccuracy());
            return Double.compare(scoreA, scoreB);
        });
        
        StudentRadarDTO mostAtRisk = atRisk.get(0);
        
        return TeachingSuggestion.builder()
            .type(TeachingSuggestionType.STUDENT_AT_RISK)
            .priority(1) // 紧急
            .title(String.format("%s同学学习状态需关注", mostAtRisk.getName()))
            .content(buildStudentAlertContent(mostAtRisk, atRisk))
            .evidenceData(buildStudentEvidence(mostAtRisk))
            .expireAt(LocalDateTime.now().plusDays(2))
            .build();
    }
}

/**
```
```java
 * 多级缓存读取
 */
@Service
public class DashboardCacheService {
    
    @Resource
    private RedisTemplate<String, Object> redis;
    @Resource
    private CaffeineCacheManager localCache; // 本地一级缓存
    
    /**
     * 读取概览数据 - 二级缓存
     */
    public <T> T getOverview(Long teacherId, Long classId, Long subjectId, 
                              LocalDate date, Class<T> clazz) {
        String key = buildKey(OVERVIEW_KEY, teacherId, classId, subjectId, date);
        
        // L1: 本地缓存（30秒）
        T local = localCache.getIfPresent(key);
        if (local != null) return local;
        
        // L2: Redis（10分钟）
        T redis_val = redis.opsForValue().get(key);
        if (redis_val != null) {
            localCache.put(key, redis_val);
            return redis_val;
        }
        
        return null;
    }
    
    /**
     * 缓存穿透防护 - 空值缓存
     */
    public <T> void cacheOverview(Long teacherId, Long classId, Long subjectId,
                                   LocalDate date, T data) {
        String key = buildKey(OVERVIEW_KEY, teacherId, classId, subjectId, date);
        
        if (data == null || (data instanceof Collection && ((Collection<?>) data).isEmpty())) {
            // 空值短TTL缓存，防止穿透
            redis.opsForValue().set(key, "NULL", 60, TimeUnit.SECONDS);
            return;
        }
        
        redis.opsForValue().set(key, data, OVERVIEW_TTL, TimeUnit.SECONDS);
        localCache.put(key, data);
    }
    
    /**
     * 缓存雪崩防护 - 随机TTL偏移
     */
    private long randomizedTtl(long baseTtl) {
        // 在基准TTL上添加 ±10% 的随机偏移
        long offset = (long)(baseTtl * 0.1 * (ThreadLocalRandom.current().nextDouble() * 2 - 1));
        return baseTtl + offset;
    }
}
```

```java
/**
 * 批量获取多个班级概览 - 减少RPC次数

public List<ClassOverviewDTO> batchAggregateOverviews(Long teacherId, 
    List<Long> classIds, Long subjectId, LocalDate date) {
    
    // 1. 批量读取缓存
    List<String> keys = classIds.stream()
        .map(cid -> buildKey(OVERVIEW_KEY, teacherId, cid, subjectId, date))
        .collect(Collectors.toList());
    List<Object> cached = redis.opsForValue().multiGet(keys);
    
    // 2. 区分命中与未命中
    List<ClassOverviewDTO> results = new ArrayList<>(classIds.size());
    List<Long> missedClassIds = new ArrayList<>();
    
    for (int i = 0; i < classIds.size(); i++) {
        ClassOverviewDTO dto = (ClassOverviewDTO) cached.get(i);
        if (dto != null) {
            results.add(dto);
        } else {
            missedClassIds.add(classIds.get(i));
        }
    }
    
    // 3. 未命中的批量查询各数据源
    if (!missedClassIds.isEmpty()) {
        // 批量查作业
        Map<Long, HomeworkSummaryDTO> homeworkMap = 
            homeworkAdapter.batchGetClassSummary(missedClassIds, subjectId, date);
        
        // 批量查学情
        Map<Long, LearningAnalyticsDTO> analyticsMap = 
            analyticsAdapter.batchGetClassAnalytics(missedClassIds, subjectId, date, 7);
        
        // 批量查错题
        Map<Long, MistakeSummaryDTO> mistakeMap = 
            mistakeAdapter.batchGetClassMistakeSummary(missedClassIds, subjectId, date);
        
        // 组装并缓存
        for (Long classId : missedClassIds) {
            ClassOverviewDTO overview = assembleOverview(
                homeworkMap.get(classId), 
                analyticsMap.get(classId),
                mistakeMap.get(classId));
            results.add(overview);
            cacheOverview(teacherId, classId, subjectId, date, overview);
        }
    }
    
    return results;
}
```
