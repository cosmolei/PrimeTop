# 服务端-学生学习画像全量快照与历史状态回溯引擎-详细设计

## 1. 概述

### 1.1 功能定位

学生学习画像全量快照与历史状态回溯引擎（Student Profile Snapshot & Historical Replay Engine，简称 **SPS**）是 PrimeTop 平台数据分析层的核心基础设施服务。它负责对学生全维度学习状态进行周期性快照采集、版本化存储、时间点回溯查询和跨版本差异分析，为学情报告、家长端展示、教师决策和产品运营提供"学生状态的时间机器"能力。

**与现有模块的区别：**

| 模块 | 关注点 | 与本引擎关系 |
| --- | --- | --- |
| 学习进度快照引擎 | 章节/视频/练习的完成百分比 | 进度只是画像的一个维度 |
| 学习会话状态快照 | 单次学习会话的断点续学 | 会话级快照，不覆盖全量画像 |
| 学习数据时效性治理 | 数据新鲜度和置信度衰减 | 时效性影响快照置信度，但不生成快照 |
| 学生画像特征工程 | 特征计算与统一特征存储 | 特征是快照的输入源 |
| **本引擎（SPS）** | **全维度画像状态的周期性冻结、版本管理、回溯查询** | **汇总以上模块输出，生成完整画像快照** |

### 1.2 问题背景

PrimeTop 平台已有的各子系统（知识追踪、能力评估、错题统计、学习投入度等）各自维护着学生的一部分状态。但缺乏一个统一的时间点状态归档机制，导致以下场景无法实现：

| 场景 | 痛点 | 业务影响 |
| --- | --- | --- |
| 学期对比报告 | 无法回答"这学期 vs 上学期，学生的数学能力提升了多少？" | 家长报告缺乏纵向对比 |
| 干预效果评估 | 采取干预措施（如推送薄弱点训练）后，无法精确对比前后画像 | 无法量化干预 ROI |
| 教师转交接 | 新教师接手班级时，看不到学生历史完整画像 | 交接信息缺失 |
| 异常回溯 | 发现学生当前状态异常时，无法追溯是在哪个时间点开始恶化的 | 预警滞后 |
| 数据恢复 | 某次批量计算出错污染了画像数据，无法回滚到正确版本 | 数据安全事故 |
| 年度回顾 | 年终报告需要按月展示能力变化曲线，缺乏月度快照 | 年度报告数据不全 |
| 跨学段分析 | 升年级后新学段画像与旧学段画像基线对比缺失 | 学段衔接分析断裂 |

### 1.3 设计目标

1. **全维度快照**：覆盖知识掌握度、能力维度、错题统计、学习行为、投入度等 ≥15 个核心维度的状态采集。
2. **多粒度调度**：支持日快照（高频轻量）、周快照（标准全量）、月快照（归档全量+趋势）、学期快照（重大节点）四种粒度。
3. **时间旅行查询**：支持指定任意时间点（精确到天），返回该时间点的完整学生画像。
4. **版本差异分析**：对比两个快照版本，输出各维度的变化量、变化率和变化方向。
5. **批量回溯**：支持按班级、年级、学校等维度批量获取历史画像，用于群体分析。
6. **高性能查询**：单学生时间点查询响应 < 200ms，批量查询 100 学生 < 2s。
7. **低成本存储**：采用列式存储 + 增量差分压缩，单学生年存储成本 < 5MB。

### 1.4 适用范围

| 方向 | 说明 |
| --- | --- |
| 目标读者 | 服务端工程师、数据工程师、数据分析工程师 |
| 核心消费者 | 学情报告服务、家长端报告服务、教师仪表盘、年度回顾服务、干预效果评估 |
| 部署形态 | 独立微服务 + 定时批处理 Spark/Flink 任务 |
| 技术栈 | Java 17 / Spring Boot 3 / PostgreSQL / ClickHouse / Redis |

## 2. 核心概念与领域模型

### 2.1 关键概念定义

| 概念 | 英文 | 定义 |
| --- | --- | --- |
| 画像快照 | Profile Snapshot | 某一时间点学生全维度学习状态的不可变冻结 |
| 快照版本 | Snapshot Version | 同一天内可能因数据修正产生多个版本，用版本号区分 |
| 快照粒度 | Snapshot Granularity | 快照的采集频率等级：DAILY / WEEKLY / MONTHLY / TERM |
| 画像维度 | Profile Dimension | 快照中包含的一类学习状态指标集合（如"知识掌握度"） |
| 维度指标 | Dimension Metric | 维度下的具体指标（如"数学-函数-单调性"的掌握度=0.82） |
| 基线快照 | Baseline Snapshot | 用于后续对比的参照快照（如学期初快照） |
| 差异报告 | Diff Report | 两个快照之间的各维度变化对比报告 |
| 快照链 | Snapshot Chain | 同一学生按时间排列的快照序列 |

### 2.2 快照覆盖维度总览

```
ProfileSnapshot
├── 1. 知识掌握度维度 (KnowledgeMasteryDimension)
│   ├── 各学科 → 各章节 → 各知识点 → 掌握度(0~1) + 置信度 + 最后更新时间
│   └── 来源：知识追踪引擎
├── 2. 能力维度评估 (AbilityDimension)
│   ├── 计算能力 / 逻辑推理 / 阅读理解 / 表达写作 / 空间想象 / 实验探究
│   └── 每项：分值(0~100) + 百分位排名 + 样本量
├── 3. 错题统计维度 (MistakeDimension)
│   ├── 总错题数 / 待复习数 / 已掌握错题数 / 本周期新增错题数
│   ├── 按学科分布 / 按错误原因分布
│   └── 错题复习完成率 / 错题订正成功率
├── 4. 学习行为维度 (BehaviorDimension)
│   ├── 日均学习时长 / 周均学习时长 / 有效学习时间占比
│   ├── 学习时段分布(早/中/晚/夜) / 高效学习时段
│   ├── AI对话次数 / 拍题次数 / 练习题完成量
│   └── 学习连续天数 / 最长连续天数 / 断更次数
├── 5. 学习投入度维度 (EngagementDimension)
│   ├── 专注度评分(0~100) / 番茄钟完成率
│   ├── 学习内容交互深度(停留时长/跳过率/重看率)
│   └── 任务完成率 / 计划执行率 / 作业提交率
├── 6. 学习规划维度 (PlanningDimension)
│   ├── 当前学习目标 / 目标进度 / 目标偏离度
│   ├── 活跃学习计划数 / 计划完成率 / 计划平均执行偏差
│   └── 每日任务完成率 / 过期任务数
├── 7. 学科均衡度维度 (SubjectBalanceDimension)
│   ├── 各学科掌握度偏差 / 偏科指数
│   ├── 各学科学习时间分配比 / 各学科投入产出比
│   └── 学科偏好倾向(基于行为数据推断)
├── 8. 考试与测评维度 (AssessmentDimension)
│   ├── 近期考试成绩 / 历史考试平均分 / 成绩趋势(上升/稳定/下降)
│   ├── 考试焦虑指数 / 备考充分度
│   └── 各题型得分率(选择/填空/解答/作文)
├── 9. 认知特征维度 (CognitiveDimension)
│   ├── 认知负荷指数 / 学习内容难度适配度
│   ├── 认知速度(内容消费速率) / 认知深度(理解度)
│   └── 心流状态频次 / 疲劳度
├── 10. 社交与协作维度 (SocialDimension)
│    ├── 协作学习参与度 / 学习圈活跃度
│    ├── 排名变化趋势(班级/年级)
│    └── 学习挑战赛参与频次与胜率
├── 11. 成长与激励维度 (GrowthDimension)
│    ├── 累计积分 / 累计徽章数 / 当前等级
│    ├── 成就解锁进度 / 近期激励事件
│    └── 学习动力指数(基于行为信号推断)
├── 12. 内容消费维度 (ContentConsumptionDimension)
│    ├── 各内容类型消费量(视频/文章/练习/AI对话/音频)
│    ├── 内容完成率 / 内容重复消费率
│    └── 推荐内容接受率 / 推荐内容完成率
├── 13. 写作能力维度 (WritingDimension)
│    ├── 作文提交数 / 作文平均分 / 写作能力趋势
│    ├── 常见问题分布(立意/结构/语言/标点)
│    └── 写作速度 / 修改次数
├── 14. 多模态学习维度 (MultimodalDimension)
│    ├── 语音学习时长(听力/朗读/口语) / 视频学习时长
│    ├── 拍照搜题使用频率 / 手写提交量
│    └── 多模态偏好分布
└── 15. 环境与设备维度 (EnvironmentDimension)
     ├── 主要学习设备 / 学习地点分布(家/学校/其他)
     ├── 网络环境分布(WiFi/4G/5G) / 弱网学习占比
     └── 多设备切换频率
```

### 2.3 领域实体关系

```
Student ──1:N──→ ProfileSnapshot ──1:1──→ SnapshotPayload
    │                │                         
    │                ├──N:1──→ SnapshotTemplate (定义采集哪些维度)
    │                │
    │                └──1:N──→ DiffReport
    │
    └──1:N──→ BaselineReference (学生级基线配置)
```

## 3. 数据结构设计

### 3.1 PostgreSQL 核心表

#### 3.1.1 快照元数据表 `profile_snapshot_meta`

```sql
CREATE TABLE profile_snapshot_meta (
    id              BIGSERIAL PRIMARY KEY,
    snapshot_id     VARCHAR(64) NOT NULL UNIQUE,   -- 快照唯一ID (snowflake生成)
    student_id      BIGINT NOT NULL,
    granularity     VARCHAR(16) NOT NULL,           -- DAILY / WEEKLY / MONTHLY / TERM
    snapshot_date   DATE NOT NULL,                  -- 快照基准日期
    snapshot_time   TIMESTAMP NOT NULL DEFAULT NOW(), -- 实际生成时间
    version         INT NOT NULL DEFAULT 1,         -- 同日重算版本号
    status          VARCHAR(20) NOT NULL DEFAULT 'COMPLETED', -- PENDING/PROCESSING/COMPLETED/FAILED
    template_id     VARCHAR(64) NOT NULL,           -- 使用的快照模板
    data_source     VARCHAR(20) NOT NULL,           -- SCHEDULED/MANUAL/REPAIR
    payload_format  VARCHAR(20) NOT NULL DEFAULT 'JSON', -- JSON/PROTOBUF
    payload_size    INT,                            -- 负载大小(bytes)
    checksum        VARCHAR(64),                    -- 负载校验和(SHA-256)
    confidence      DECIMAL(3,2) DEFAULT 1.0,      -- 整体置信度(0~1)
    is_baseline     BOOLEAN DEFAULT FALSE,          -- 是否为基线快照
    created_at      TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMP NOT NULL DEFAULT NOW()
);

-- 核心查询索引
CREATE INDEX idx_snapshot_student_date ON profile_snapshot_meta (student_id, snapshot_date DESC, granularity);
CREATE INDEX idx_snapshot_granularity_date ON profile_snapshot_meta (granularity, snapshot_date);
CREATE INDEX idx_snapshot_status ON profile_snapshot_meta (status, snapshot_date) WHERE status != 'COMPLETED';
CREATE INDEX idx_snapshot_baseline ON profile_snapshot_meta (student_id, is_baseline) WHERE is_baseline = TRUE;
```

#### 3.1.2 快照负载表 `profile_snapshot_payload`

```sql
CREATE TABLE profile_snapshot_payload (
    id              BIGSERIAL PRIMARY KEY,
    snapshot_id     VARCHAR(64) NOT NULL UNIQUE REFERENCES profile_snapshot_meta(snapshot_id),
    payload_json    JSONB NOT NULL,                 -- 完整画像JSON
    payload_delta   JSONB,                          -- 与上一版本的增量差分(可选)
    dim_summary     JSONB NOT NULL,                 -- 维度摘要(各维度关键指标)
    created_at      TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_payload_snapshot ON profile_snapshot_payload (snapshot_id);
-- GIN索引用于维度摘要查询
CREATE INDEX idx_payload_dim_summary ON profile_snapshot_payload USING GIN (dim_summary);
```

#### 3.1.4 差异报告表 `snapshot_diff_report`

```sql
CREATE TABLE snapshot_diff_report (
    id              BIGSERIAL PRIMARY KEY,
    report_id       VARCHAR(64) NOT NULL UNIQUE,
    student_id      BIGINT NOT NULL,
    from_snapshot   VARCHAR(64) NOT NULL,
    to_snapshot     VARCHAR(64) NOT NULL,
    diff_type       VARCHAR(20) NOT NULL,           -- PERIOD_OVER_PERIOD / BASELINE / CUSTOM
    diff_payload    JSONB NOT NULL,                 -- 完整差异报告
    summary         JSONB NOT NULL,                 -- 摘要(总体趋势+关键变化)
    significant_changes INT DEFAULT 0,              -- 显著变化数
    created_at      TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_diff_student ON snapshot_diff_report (student_id, created_at DESC);
CREATE INDEX idx_diff_snapshots ON snapshot_diff_report (from_snapshot, to_snapshot);
```

#### 3.1.5 基线配置表 `student_baseline_config`

```sql
CREATE TABLE student_baseline_config (
    id              BIGSERIAL PRIMARY KEY,
    student_id      BIGINT NOT NULL,
    baseline_type   VARCHAR(32) NOT NULL,           -- TERM_START / SEMESTER_START / CUSTOM
    baseline_snapshot_id VARCHAR(64) NOT NULL,
    effective_from  DATE NOT NULL,
    effective_to    DATE,
    notes           TEXT,
    created_at      TIMESTAMP NOT NULL DEFAULT NOW(),
    UNIQUE(student_id, baseline_type, effective_from)
);
```

### 3.2 ClickHouse 时序存储（趋势分析专用）

```sql
-- ClickHouse: 宽表设计，用于高性能时序查询
CREATE TABLE student_profile_timeseries (
    student_id      UInt64,
    snapshot_date   Date,
    granularity     LowCardinality(String),
    -- 知识掌握度摘要
    mastery_overall Float32,         -- 总体掌握度
    mastery_math    Float32,         -- 数学掌握度
    mastery_chinese Float32,         -- 语文掌握度
    mastery_english Float32,         -- 英语掌握度
    mastery_physics Float32,
    mastery_chemistry Float32,
    mastery_biology Float32,
    mastery_history Float32,
    mastery_geo     Float32,
    mastery_politics Float32,
    -- 能力维度
    ability_calc    Float32,         -- 计算能力
    ability_logic   Float32,         -- 逻辑推理
    ability_reading Float32,         -- 阅读理解
    ability_writing Float32,         -- 表达写作
    ability_spatial Float32,         -- 空间想象
    ability_experimental Float32,   -- 实验探究
    -- 错题统计
    mistake_total   UInt32,
    mistake_pending UInt32,
    mistake_mastered UInt32,
    mistake_new_period UInt32,
    -- 学习行为
    study_time_daily_avg UInt32,    -- 日均学习时长(秒)
    ai_query_count UInt32,
    photo_query_count UInt32,
    exercise_count UInt32,
    study_streak_days UInt16,
    -- 投入度
    focus_score Float32,
    task_completion_rate Float32,
    plan_execution_rate Float32,
    -- 综合
    overall_score   Float32,        -- 综合学习评分(0~100)
    confidence      Float32,        -- 数据置信度
    snapshot_id     String,
    created_at      DateTime DEFAULT now()
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(snapshot_date)
ORDER BY (student_id, snapshot_date)
TTL snapshot_date + INTERVAL 3 YEAR
SETTINGS index_granularity = 8192;
```

### 5.2 维度采集器设计

每个维度采集器是一个独立组件，实现统一的 `DimensionCollector` 接口，支持并行采集和失败隔离。

```java
/**
 * 维度采集器接口
 */
public interface DimensionCollector {
    
    /**
     * 采集器标识
     */
    String getDimensionKey();
    
    /**
     * 采集维度数据
     * @param studentId 学生ID
     * @param snapshotDate 快照日期
     * @param periodDays 采集周期（天）
     * @return 维度数据（JSON节点）
     */
    JsonNode collect(Long studentId, LocalDate snapshotDate, int periodDays);
    
    /**
     * 采集超时时间（秒）
     */
    default int getTimeoutSeconds() { return 30; }
    
    /**
     * 是否为关键维度（失败时是否阻塞整体快照）
     */
    default boolean isCritical() { return false; }
    
    /**
     * 重试次数
     */
    default int getMaxRetries() { return 2; }
}
```

### 5.3 知识掌握度采集器实现示例

```java
@Component
public class KnowledgeMasteryCollector implements DimensionCollector {
    
    @Autowired
    private KnowledgeTrackingClient trackingClient;
    
    @Autowired
    private MasteryCacheService masteryCache;
    
    @Override
    public String getDimensionKey() {
        return "knowledge_mastery";
    }
    
    @Override
    public boolean isCritical() {
        return true; // 核心维度，失败时阻塞
    }
    
    @Override
    public JsonNode collect(Long studentId, LocalDate snapshotDate, int periodDays) {
        ObjectMapper mapper = new ObjectMapper();
        ObjectNode root = mapper.createObjectNode();
        
        // 1. 获取学生所有学科的掌握度
        List<SubjectMastery> subjectMasteries = trackingClient
            .getAllSubjectMastery(studentId, snapshotDate);
        
        // 2. 计算总体掌握度
        double overall = subjectMasteries.stream()
            .mapToDouble(SubjectMastery::getOverallMastery)
            .average()
            .orElse(0.0);
        root.put("overall", round(overall, 4));
        
        // 3. 组装各学科详情
        ArrayNode subjectsArray = mapper.createArrayNode();
        for (SubjectMastery sm : subjectMasteries) {
            ObjectNode subjectNode = mapper.createObjectNode();
            subjectNode.put("subject", sm.getSubject().name());
            subjectNode.put("overall_mastery", round(sm.getOverallMastery(), 4));
            subjectNode.put("confidence", round(sm.getConfidence(), 4));
            
            // 获取该学科下知识点详情
            ArrayNode kpArray = mapper.createArrayNode();
            for (KnowledgePointMastery kpm : sm.getKnowledgePoints()) {
                ObjectNode kpNode = mapper.createObjectNode();
                kpNode.put("kp_id", kpm.getKpId());
                kpNode.put("kp_name", kpm.getKpName());
                kpNode.put("mastery", round(kpm.getMastery(), 4));
                kpNode.put("sample_count", kpm.getSampleCount());
                kpNode.put("last_updated", kpm.getLastUpdated().toString());
                kpArray.add(kpNode);
            }
            subjectNode.set("knowledge_points", kpArray);
            subjectsArray.add(subjectNode);
        }
        root.set("subjects", subjectsArray);
        
        return root;
    }
    
    private double round(double value, int scale) {
        BigDecimal bd = BigDecimal.valueOf(value);
        return bd.setScale(scale, RoundingMode.HALF_UP).doubleValue();
    }
}
```

### 5.4 快照采集编排器

```java
@Service
@Slf4j
public class SnapshotOrchestrator {
    
    @Autowired
    private List<DimensionCollector> collectors;
    
    @Autowired
    private SnapshotStorageService storageService;
    
    @Autowired
    private SnapshotMetaRepository metaRepo;
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    /**
     * 执行单个学生的快照采集
     */
    @Transactional
    public SnapshotResult executeSnapshot(SnapshotTask task) {
        long startTime = System.currentTimeMillis();
        String snapshotId = generateSnapshotId(task);
        
        log.info("开始快照采集: student={}, template={}, date={}", 
            task.getStudentId(), task.getTemplateId(), task.getSnapshotDate());
        
        // 1. 创建快照元数据
        ProfileSnapshotMeta meta = ProfileSnapshotMeta.builder()
            .snapshotId(snapshotId)
            .studentId(task.getStudentId())
            .granularity(task.getGranularity())
            .snapshotDate(task.getSnapshotDate())
            .status("PROCESSING")
            .templateId(task.getTemplateId())
            .dataSource(task.getSource().name())
            .build();
        metaRepo.save(meta);
        
        // 2. 并行采集各维度数据
        Map<String, CompletableFuture<DimensionResult>> futures = new HashMap<>();
        List<String> targetDimensions = task.getDimensions();
        
        for (DimensionCollector collector : collectors) {
            if (!targetDimensions.contains(collector.getDimensionKey())) {
                continue;
            }
            
            CompletableFuture<DimensionResult> future = CompletableFuture
                .supplyAsync(() -> collectWithRetry(collector, task))
                .orTimeout(collector.getTimeoutSeconds(), TimeUnit.SECONDS)
                .exceptionally(ex -> handleCollectionFailure(collector, ex));
            
            futures.put(collector.getDimensionKey(), future);
        }
        
        // 3. 等待所有维度完成
        CompletableFuture.allOf(futures.values().toArray(new CompletableFuture[0])).join();
        
        // 4. 组装快照负载
        ObjectNode dimensionsNode = objectMapper.createObjectNode();
        Set<String> failedDimensions = new HashSet<>();
        
        for (Map.Entry<String, CompletableFuture<DimensionResult>> entry : futures.entrySet()) {
            DimensionResult result = entry.getValue().join();
            if (result.isSuccess()) {
                dimensionsNode.set(entry.getKey(), result.getData());
            } else {
                failedDimensions.add(entry.getKey());
                log.warn("维度采集失败: dimension={}, reason={}", 
                    entry.getKey(), result.getErrorMessage());
                
                // 关键维度失败则标记整体失败
                if (result.isCritical()) {
                    meta.setStatus("FAILED");
                    metaRepo.save(meta);
                    return SnapshotResult.failed(snapshotId, "关键维度采集失败: " + entry.getKey());
                }
            }
        }
        
        // 5. 计算整体置信度
        double confidence = calculateOverallConfidence(futures, task.getDimensions());
        
        // 6. 组装完整负载
        ObjectNode payload = buildPayload(task, snapshotId, dimensionsNode, confidence);
        
        // 7. 存储快照
        meta.setStatus("COMPLETED");
        meta.setConfidence(confidence);
        meta.setPayloadSize(payload.toString().getBytes(StandardCharsets.UTF_8).length);
        meta.setChecksum(DigestUtils.sha256Hex(payload.toString()));
        metaRepo.save(meta);
        
        storageService.storePayload(snapshotId, payload);
        
        // 8. 同步到ClickHouse时序表
        storageService.syncToTimeSeries(task, payload, confidence);
        
        // 9. 更新Redis缓存（最新快照）
        String cacheKey = "sps:latest:" + task.getStudentId() + ":" + task.getGranularity();
        redisTemplate.opsForValue().set(cacheKey, payload.toString(), 
            Duration.ofDays(task.getGranularity() == Granularity.DAILY ? 2 : 14));
        
        long elapsed = System.currentTimeMillis() - startTime;
        log.info("快照采集完成: student={}, snapshotId={}, 耗时={}ms, 失败维度={}", 
            task.getStudentId(), snapshotId, elapsed, failedDimensions);
        
        return SnapshotResult.success(snapshotId, failedDimensions);
    }
    
    /**
     * 带重试的维度采集
     */
    private DimensionResult collectWithRetry(DimensionCollector collector, SnapshotTask task) {
        int maxRetries = collector.getMaxRetries();
        Exception lastException = null;
        
        for (int attempt = 0; attempt <= maxRetries; attempt++) {
            try {
                JsonNode data = collector.collect(
                    task.getStudentId(), 
                    task.getSnapshotDate(), 
                    task.getPeriodDays()
                );
                return DimensionResult.success(collector.getDimensionKey(), data);
            } catch (Exception e) {
                lastException = e;
                log.warn("维度采集失败(尝试{}/{}): dimension={}, error={}", 
                    attempt + 1, maxRetries + 1, collector.getDimensionKey(), e.getMessage());
                if (attempt < maxRetries) {
                    sleep(calculateBackoff(attempt));
                }
            }
        }
        return DimensionResult.failure(collector, lastException);
    }
    
    /**
     * 计算整体置信度
     */
    private double calculateOverallConfidence(
            Map<String, CompletableFuture<DimensionResult>> futures, 
            List<String> allDimensions) {
        int totalWeight = 0;
        int successWeight = 0;
        
        for (String dim : allDimensions) {
            int weight = getDimensionWeight(dim); // 核心维度权重更高
            totalWeight += weight;
            DimensionResult result = futures.get(dim).join();
            if (result.isSuccess()) {
                successWeight += weight;
            }
        }
        
        return totalWeight == 0 ? 0.0 : (double) successWeight / totalWeight;
    }
}
```

```java
        int pageSize = 500;
        long lastStudentId = 0;

            if (studentIds.isEmpty()) break;

                .map(sid -> SnapshotTask.builder()
                    .studentId(sid)
                    .templateId(templateId)
                    .granularity(granularity)
                    .snapshotDate(snapshotDate)
                    .dimensions(template.getDimensionList())
                    .source(SnapshotSource.SCHEDULED)
                    .build())
                .collect(Collectors.toList());
            
            // 投入队列，按学生ID hash分配到不同分区实现并行
            for (SnapshotTask task : tasks) {
                taskQueue.enqueue(task, String.valueOf(task.getStudentId() % 16));
            }
            
            totalQueued += tasks.size();
            lastStudentId = studentIds.get(studentIds.size() - 1);
        }
        
        log.info("{}快照调度完成: 共{}个学生入队", granularity, totalQueued);
    }
```

### 6.1 差异计算核心逻辑

```java
@Service
public class SnapshotDiffEngine {
    
    @Autowired
    private SnapshotStorageService storageService;
    
    @Autowired
    private DimensionConfigRegistry dimConfigRegistry;
    
    /**
     * 计算两个快照之间的差异
     */
    public DiffReport calculateDiff(DiffRequest request) {
        // 1. 加载两个快照
        ProfileSnapshot fromSnapshot = storageService.loadSnapshot(request.getFromSnapshotId());
        ProfileSnapshot toSnapshot = storageService.loadSnapshot(request.getToSnapshotId());
        
        // 2. 初始化差异报告
        DiffReport.DiffReportBuilder reportBuilder = DiffReport.builder()
            .reportId(generateReportId(request))
            .studentId(request.getStudentId())
            .fromSnapshot(request.getFromSnapshotId())
            .toSnapshot(request.getToSnapshotId())
            .periodDays(ChronoUnit.DAYS.between(
                fromSnapshot.getSnapshotDate(), 
                toSnapshot.getSnapshotDate()
            ));
        
        List<DimensionDiff> dimensionDiffs = new ArrayList<>();
        int significantCount = 0;
        
        // 3. 逐维度对比
        Set<String> allDimensions = getUnionDimensions(fromSnapshot, toSnapshot);
        
        for (String dimKey : allDimensions) {
            if (!shouldCompare(dimKey, request.getDimensions())) continue;
            
            JsonNode fromData = fromSnapshot.getDimension(dimKey);
            JsonNode toData = toSnapshot.getDimension(dimKey);
            
            DimensionDiff dimDiff = calculateDimensionDiff(dimKey, fromData, toData, 
                request.getSignificanceThreshold());
            
            dimensionDiffs.add(dimDiff);
            significantCount += dimDiff.getSignificantChangeCount();
        }
        
        // 4. 生成摘要
        DiffSummary summary = generateSummary(dimensionDiffs, fromSnapshot, toSnapshot);
        
        return reportBuilder
            .dimensionDiffs(dimensionDiffs)
            .significantChanges(significantCount)
            .summary(summary)
            .build();
    }
    
    /**
     * 递归计算JSON节点差异
     */
    private DimensionDiff calculateDimensionDiff(String dimKey, JsonNode from, JsonNode to, 
                                                  double threshold) {
        DimensionConfig dimConfig = dimConfigRegistry.getConfig(dimKey);
        List<MetricDiff> metricDiffs = new ArrayList<>();
        
        // 根据维度类型选择对比策略
        switch (dimKey) {
            case "knowledge_mastery":
                metricDiffs.addAll(diffKnowledgeMastery(from, to, threshold));
                break;
            case "behavior":
                metricDiffs.addAll(diffFlatMetrics(from, to, threshold, 
                    Map.of(
                        "daily_avg_study_time_sec", "日均学习时长",
                        "weekly_total_study_time_sec", "周总学习时长",
                        "ai_query_count", "AI提问次数",
                        "photo_query_count", "拍题次数",
                        "exercise_count", "练习题数",
                        "study_streak_days", "连续学习天数"
                    )));
                break;
            case "ability":
                metricDiffs.addAll(diffAbilityScores(from, to, threshold));
                break;
            default:
                metricDiffs.addAll(diffGeneric(from, to, threshold));
        }
        
        return DimensionDiff.builder()
            .dimension(dimKey)
            .dimensionLabel(dimConfig.getLabel())
            .metrics(metricDiffs)
            .significantChangeCount((int) metricDiffs.stream()
                .filter(MetricDiff::isSignificant).count())
            .build();
    }
    
    /**
     * 数值型指标差异计算
     */
    private MetricDiff calculateNumericDiff(String metricKey, String label,
                                             double fromValue, double toValue, 
                                             double threshold) {
        double change = toValue - fromValue;
        double changeRate = fromValue != 0 ? change / Math.abs(fromValue) : 0;
        
        ChangeDirection direction;
        if (Math.abs(change) < 0.0001) {
            direction = ChangeDirection.STABLE;
        } else if (change > 0) {
            direction = ChangeDirection.UP;
        } else {
            direction = ChangeDirection.DOWN;
        }
        
        boolean significant = Math.abs(changeRate) >= threshold;
        
        return MetricDiff.builder()
            .metricKey(metricKey)
            .label(label)
            .fromValue(fromValue)
            .toValue(toValue)
            .change(round(change, 4))
            .changeRate(round(changeRate, 4))
            .direction(direction)
            .significant(significant)
            .build();
    }
    
    /**
     * AI驱动的高亮生成
     */
    private DiffSummary generateSummary(List<DimensionDiff> diffs, 
                                        ProfileSnapshot from, ProfileSnapshot to) {
        int improved = 0, declined = 0, stable = 0;
        List<String> highlights = new ArrayList<>();
        List<String> risks = new ArrayList<>();
        
        for (DimensionDiff dim : diffs) {
            for (MetricDiff m : dim.getMetrics()) {
                if (!m.isSignificant()) {
                    stable++;
                    continue;
                }
                
                boolean isImprovement = isPositiveChange(dim.getDimension(), m);
                if (isImprovement) {
                    improved++;
                    if (m.getChangeRate() > 0.1) {
                        highlights.add(formatHighlight(dim, m));
                    }
                } else {
                    declined++;
                    risks.add(formatRisk(dim, m));
                }
            }
        }
        
        return DiffSummary.builder()
            .totalMetricsCompared(improved + declined + stable)
            .improvedMetrics(improved)
            .declinedMetrics(declined)
            .stableMetrics(stable)
            .keyHighlights(highlights)
            .riskAreas(risks)
            .build();
    }
    
    /**
     * 判断某维度下指标变化是否为正面
     */
    private boolean isPositiveChange(String dimension, MetricDiff metric) {
        // 对于"下降为好"的指标（如错题数、风险等级等），方向需要反转
        Set<String> lowerIsBetter = Set.of(
            "mistake.pending_review", 
            "mistake.new_in_period",
            "subject_balance.imbalance_index",
            "assessment.anxiety_index",
            "behavior.break_count"
        );
        
        String fullKey = dimension + "." + metric.getMetricKey();
        boolean lowerIsBetterMetric = lowerIsBetter.contains(fullKey);
        
        if (metric.getDirection() == ChangeDirection.STABLE) return true;
        
        return lowerIsBetterMetric 
            ? metric.getDirection() == ChangeDirection.DOWN
            : metric.getDirection() == ChangeDirection.UP;
    }
}
```

```java
@Component
@Slf4j
public class SnapshotLifecycleManager {
    
    @Autowired
    private SnapshotMetaRepository metaRepo;
    
    @Autowired
    private SnapshotPayloadRepository payloadRepo;
    
    @Autowired
    private TimeSeriesRepository tsRepo;
    
    @Autowired
    private S3ArchiveClient s3Client;
    
    /**
     * 每日凌晨3点执行快照生命周期管理
     */
    @Scheduled(cron = "0 0 3 * * *")
    public void executeLifecycleManagement() {
        // 1. 降采样：90天前的快照，删除全量负载，仅保留摘要
        downgradeOldSnapshots(90);
        
        // 2. 进一步压缩：1年前的快照，仅保留关键指标
        compressOldSnapshots(365);
        
        // 3. 冷归档：3年前的快照，转存S3并删除数据库记录
        archiveOldSnapshots(1095);
    }
    
    private void downgradeOldSnapshots(int ageDays) {
        LocalDate threshold = LocalDate.now().minusDays(ageDays);
        int batchSize = 1000;
        long processed = 0;
        
        while (true) {
            List<ProfileSnapshotMeta> snapshots = metaRepo
                .findByGranularityAndSnapshotDateBeforeAndPayloadKeptTrue(
                    "MONTHLY", threshold, PageRequest.of(0, batchSize));
            
            if (snapshots.isEmpty()) break;
            
            for (ProfileSnapshotMeta meta : snapshots) {
                // 删除全量负载，保留dim_summary
                payloadRepo.deletePayloadJson(meta.getSnapshotId());
                meta.setPayloadKept(false);
                metaRepo.save(meta);
                processed++;
            }
            
            log.info("降采样处理: 已处理{}条快照(>{}天)", processed, ageDays);
        }
    }
    
    private void archiveOldSnapshots(int ageDays) {
        LocalDate threshold = LocalDate.now().minusDays(ageDays);
        
        List<ProfileSnapshotMeta> oldSnapshots = metaRepo
            .findBySnapshotDateBefore(threshold);
        
        if (oldSnapshots.isEmpty()) return;
        
        // 按月分批上传S3
        Map<YearMonth, List<ProfileSnapshotMeta>> byMonth = oldSnapshots.stream()
            .collect(Collectors.groupingBy(
                s -> YearMonth.from(s.getSnapshotDate())));
        
        for (Map.Entry<YearMonth, List<ProfileSnapshotMeta>> entry : byMonth.entrySet()) {
            String s3Key = String.format("snapshots/archive/%s/%s.parquet", 
                entry.getKey().getYear(), entry.getKey().getMonthValue());
            
            // 转为Parquet并上传
            s3Client.uploadParquet(s3Key, entry.getValue());
            
            // 删除数据库记录
            List<String> snapshotIds = entry.getValue().stream()
                .map(ProfileSnapshotMeta::getSnapshotId)
                .collect(Collectors.toList());
            payloadRepo.deleteAllById(snapshotIds);
            metaRepo.deleteAllById(entry.getValue().stream()
                .map(ProfileSnapshotMeta::getId)
                .collect(Collectors.toList()));
        }
        
        // 同步清理ClickHouse过期数据
        tsRepo.deleteBefore(threshold);
        
        log.info("冷归档完成: 归档{}条快照(>{}天)", oldSnapshots.size(), ageDays);
    }
}
```

### 9.1 错误码定义

```java
/**
 * 维度采集失败处理器

@Component
public class DimensionCollectionFailureHandler {
    
    /**
     * 失败处理策略矩阵
     */
    private static final Map<String, FailureStrategy> STRATEGIES = Map.of(
        // 关键维度失败 → 阻塞快照，标记FAILED
        "knowledge_mastery", FailureStrategy.BLOCK_AND_RETRY,
        "ability", FailureStrategy.BLOCK_AND_RETRY,
        
        // 重要维度失败 → 标记维度缺失，继续完成快照
        "behavior", FailureStrategy.SKIP_AND_CONTINUE,
        "engagement", FailureStrategy.SKIP_AND_CONTINUE,
        "mistake", FailureStrategy.SKIP_AND_CONTINUE,
        "assessment", FailureStrategy.SKIP_AND_CONTINUE,
        
        // 辅助维度失败 → 直接跳过
        "social", FailureStrategy.SKIP_SILENTLY,
        "multimodal", FailureStrategy.SKIP_SILENTLY,
        "environment", FailureStrategy.SKIP_SILENTLY
    );
    
    public void handleFailure(String dimension, Exception error, 
                              SnapshotContext context) {
        FailureStrategy strategy = STRATEGIES.getOrDefault(dimension, 
            FailureStrategy.SKIP_AND_CONTINUE);
        
        switch (strategy) {
            case BLOCK_AND_RETRY:
                // 记录失败原因，等待自动重试（最多3次，间隔递增）
                context.markDimensionFailed(dimension, error, true);
                context.recordFailureDetail(dimension, error);
                break;
                
            case SKIP_AND_CONTINUE:
                // 标记维度缺失，降低置信度
                context.markDimensionFailed(dimension, error, false);
                context.reduceConfidence(getDimensionWeight(dimension));
                break;
                
            case SKIP_SILENTLY:
                // 静默跳过
                log.debug("维度{}采集失败，已跳过: {}", dimension, error.getMessage());
                break;
        }
    }
}
```

```yaml
  max_concurrent_students_global: 200            # 全局最多200个学生同时采集
  collector_timeout_seconds: 30                  # 单维度采集超时
  collector_retry_count: 2                       # 重试次数
  collector_retry_backoff_ms: [500, 2000]       # 重试退避间隔
```

### 10.2 查询优化

```sql
-- 优化1: 时间点查询使用覆盖索引
-- 索引 (student_id, snapshot_date DESC, granularity) 已覆盖查询

-- 优化2: 时间序列查询走ClickHouse而非PostgreSQL
-- ClickHouse按月分区，单月查询可利用分区裁剪

-- 优化3: Redis缓存最新快照
-- Key: sps:latest:{studentId}:{granularity}
-- TTL: DAILY=2天, WEEKLY=14天, MONTHLY=35天

-- 优化4: 维度摘要GIN索引支持快速过滤
-- 如查询"数学掌握度低于0.5的学生"
SELECT student_id, snapshot_date 
FROM profile_snapshot_payload 
WHERE dim_summary @> '{"knowledge_mastery": {"math": {"mastery": {"$lt": 0.5}}}}';
```

### 10.3 存储优化

| 优化手段 | 预期效果 | 实现方式 |
| --- | --- | --- |
| 增量差分存储 | 减少30-50%存储空间 | 存储与上一版本的diff，非全量 |
| JSONB TOAST压缩 | 减少20-40%大负载体积 | PostgreSQL TOAST自动压缩 |
| ClickHouse列式压缩 | 10:1压缩率 | LZ4压缩 + 列式存储 |
| 冷数据归档S3 | 降低90%存储成本 | 3年以上数据转Parquet存S3 |
| 负载分表 | 避免单表过大 | 按年分表: profile_snapshot_payload_2026 |

## 12. 安全与合规

### 12.1 访问控制

| 接口分类 | 鉴权方式 | 权限要求 |
| --- | --- | --- |
| 查询自己孩子快照 | 学生/家长Token | 家长绑定关系校验 |
| 查询班级批量快照 | 教师Token | 班级归属校验 |
| 手动触发快照 | 管理员Token | ops:sps:trigger |
| 快照修复 | 管理员Token | ops:sps:repair |
| 内部服务调用 | 服务间Token | service:sps:internal |

### 12.2 数据安全

1. **快照数据脱敏**：对外暴露时，学生ID进行哈希脱敏。
2. **敏感指标过滤**：assessment.anxiety_index 仅对家长和教师可见。
3. **审计日志**：所有快照查询操作记录审计日志，含查询者、查询时间、查询范围。
4. **数据传输加密**：所有API响应通过HTTPS传输，内部服务间通过mTLS。
5. **合规要求**：快照属于学生个人信息，存储期限不超过用户注销后90天。

### 15.1 单元测试

```java
@ExtendWith(MockitoExtension.class)
class SnapshotOrchestratorTest {
    
    @Mock
    private KnowledgeMasteryCollector knowledgeCollector;
    
    @Mock
    private BehaviorCollector behaviorCollector;
    
    @InjectMocks
    private SnapshotOrchestrator orchestrator;
    
    @Test
    @DisplayName("全部维度采集成功 → 生成完整快照")
    void shouldCreateCompleteSnapshotWhenAllDimensionsSucceed() {
        // Given
        SnapshotTask task = createTestTask();
        when(knowledgeCollector.collect(any(), any(), anyInt()))
            .thenReturn(createMockMasteryData());
        when(behaviorCollector.collect(any(), any(), anyInt()))
            .thenReturn(createMockBehaviorData());
        
        // When
        SnapshotResult result = orchestrator.executeSnapshot(task);
        
        // Then
        assertThat(result.isSuccess()).isTrue();
        assertThat(result.getFailedDimensions()).isEmpty();
    }
    
    @Test
    @DisplayName("关键维度失败 → 快照标记为FAILED")
    void shouldFailSnapshotWhenCriticalDimensionFails() {
        // Given
        SnapshotTask task = createTestTask();
        when(knowledgeCollector.collect(any(), any(), anyInt()))
            .thenThrow(new RuntimeException("知识追踪服务不可用"));
        
        // When
        SnapshotResult result = orchestrator.executeSnapshot(task);
        
        // Then
        assertThat(result.isSuccess()).isFalse();
        assertThat(result.getErrorMessage())
            .contains("关键维度采集失败");
    }
    
    @Test
    @DisplayName("非关键维度失败 → 快照完成但标记缺失维度")
    void shouldCompleteWithMissingDimensionWhenNonCriticalFails() {
        // Given
        SnapshotTask task = createTestTask();
        when(knowledgeCollector.collect(any(), any(), anyInt()))
            .thenReturn(createMockMasteryData());
        when(behaviorCollector.collect(any(), any(), anyInt()))
            .thenThrow(new RuntimeException("行为数据查询失败"));
        
        // When
        SnapshotResult result = orchestrator.executeSnapshot(task);
        
        // Then
        assertThat(result.isSuccess()).isTrue();
        assertThat(result.getFailedDimensions()).contains("behavior");
    }
}
```
