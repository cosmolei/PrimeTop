# 服务端-学生家长学习期望差异智能识别与沟通策略推荐引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责**采集、分析、调适家长对学生学习的期望与学生实际学习状态之间的差异**，并生成个性化沟通策略与教育建议，帮助缩小期望差距、减少家庭学习冲突、促进学生健康发展。

### 1.2 设计背景

在中国家庭教育场景中，家长期望与学生实际水平之间存在显著差异是普遍现象：

- **过高期望**：家长期望分数远超学生实际水平，导致学生压力过大、厌学、亲子关系紧张
- **过低期望**：家长对学生潜力认知不足，缺乏有效支持，导致学生动力不足
- **方向偏差**：家长期望的学科方向与学生兴趣/特长不匹配
- **时间期望不合理**：家长期望每日学习时长超出学生年龄适宜范围
- **沟通缺失**：家长缺乏科学方法与学生讨论学习目标和期望

### 1.3 核心目标

| 目标 | 描述 |
|------|------|
| 期望采集 | 结构化采集家长对学生成绩、学科、升学、学习时长的期望 |
| 差异分析 | 多维度对比家长期望与学生实际状态，量化期望差距 |
| 沟通策略生成 | 基于差距类型与程度，生成个性化沟通话术与建议 |
| 期望调适 | 通过周期性反馈与引导，帮助家长逐步调整期望至合理区间 |
| 效果追踪 | 追踪期望差距变化趋势，评估沟通策略效果 |

### 1.4 适用范围

- **学段**：小学至高中全学段（幼儿阶段不适用）
- **用户**：已绑定学生账号的家长用户
- **前置条件**：家长已完成绑定、学生有至少 4 周学习数据

## 5. 核心算法设计

### 5.1 综合差距评分算法

将各维度的差距归一化并加权汇总为 0-100 的综合差距分。

```python
class ExpectationGapCalculator:
    """期望差距综合评分计算器"""

    DIMENSION_WEIGHTS = {
        'score_gap': 0.30,
        'study_time_gap': 0.15,
        'subject_focus_gap': 0.20,
        'school_target_gap': 0.25,
        'behavior_gap': 0.10,
    }

    STAGE_WEIGHT_ADJUSTMENTS = {
        'PRIMARY': {
            'score_gap': 0.8, 'study_time_gap': 1.3, 'behavior_gap': 1.5,
        },
        'JUNIOR': {
            'score_gap': 1.2, 'subject_focus_gap': 1.3,
        },
        'SENIOR': {
            'score_gap': 1.3, 'school_target_gap': 1.4,
        }
    }

    def calculate_overall_gap_score(
        self, dimension_gaps: dict, student_stage: str
    ) -> tuple[float, str]:
        """
        计算综合期望差距分。

        Returns:
            (gap_score 0-100, gap_level)
        """
        stage_adj = self.STAGE_WEIGHT_ADJUSTMENTS.get(student_stage, {})
        total_weight = 0.0
        weighted_score = 0.0

        for dim, base_weight in self.DIMENSION_WEIGHTS.items():
            if dim not in dimension_gaps:
                continue
            adj = stage_adj.get(dim, 1.0)
            final_weight = base_weight * adj
            total_weight += final_weight
            dim_score = self._normalize_dimension_score(dim, dimension_gaps[dim])
            weighted_score += dim_score * final_weight

        overall = weighted_score / total_weight if total_weight > 0 else 0
        level = self._score_to_level(overall)
        return round(overall, 2), level

    def _normalize_dimension_score(self, dim: str, gap_data: dict) -> float:
        if dim == 'score_gap':
            return self._normalize_score_gap(gap_data)
        elif dim == 'study_time_gap':
            return self._normalize_time_gap(gap_data)
        elif dim == 'subject_focus_gap':
            alignment = gap_data.get('alignment_score', 1.0)
            return (1.0 - alignment) * 100
        elif dim == 'school_target_gap':
            probability = gap_data.get('estimated_probability', 1.0)
            if probability > 0.80:
                return (1.0 - probability) / 0.20 * 10
            elif probability > 0.50:
                return 10 + (0.80 - probability) / 0.30 * 20
            elif probability > 0.20:
                return 30 + (0.50 - probability) / 0.30 * 30
            else:
                return min(60 + (0.20 - probability) / 0.20 * 40, 100)
        return 0.0

    def _normalize_score_gap(self, gap_data: dict) -> float:
        """分数差距归一化为 0-100"""
        max_ratio = max(
            abs(d.get('gap_ratio', 0)) for d in gap_data.values()
        ) if gap_data else 0

        if max_ratio <= 0.05:
            return max_ratio / 0.05 * 10
        elif max_ratio <= 0.15:
            return 10 + (max_ratio - 0.05) / 0.10 * 15
        elif max_ratio <= 0.30:
            return 25 + (max_ratio - 0.15) / 0.15 * 25
        else:
            return min(50 + (max_ratio - 0.30) / 0.20 * 50, 100)

    def _normalize_time_gap(self, gap_data: dict) -> float:
        gap_ratio = abs(gap_data.get('gap_ratio', 0))
        base_score = min(gap_ratio * 100, 60)
        age_flag = gap_data.get('age_appropriateness', 'APPROPRIATE')
        if age_flag == 'EXPECTED_TOO_HIGH':
            base_score = min(base_score + 20, 100)
        elif age_flag == 'EXPECTED_TOO_LOW':
            base_score = min(base_score + 10, 100)
        return base_score

    @staticmethod
    def _score_to_level(score: float) -> str:
        if score <= 10: return 'MINIMAL'
        elif score <= 25: return 'MODERATE'
        elif score <= 50: return 'SIGNIFICANT'
        else: return 'SEVERE'
```

### 5.2 风险标记检测

```python
class RiskFlagDetector:
    """风险标记检测器"""

    def detect_risks(self, gap_analysis: dict, student_profile: dict) -> list[str]:
        risks = []

        # 1. 过度压力风险：多个学科同时存在显著差距
        score_gaps = gap_analysis.get('dimension_gaps', {}).get('score_gap', {})
        sig_count = sum(1 for d in score_gaps.values()
                        if d.get('severity') in ('SIGNIFICANT', 'SEVERE'))
        if sig_count >= 2:
            risks.append('OVERPRESSURE')

        # 2. 动力丧失风险：期望明显低于实际
        under_count = sum(1 for d in score_gaps.values()
                          if d.get('gap_value', 0) > 0)
        if score_gaps and under_count / len(score_gaps) >= 0.5:
            risks.append('DEMOTIVATION')

        # 3. 亲子冲突风险：差距大 + 青春期
        if gap_analysis['overall_gap_score'] >= 45:
            age = student_profile.get('age', 0)
            if 12 <= age <= 18:
                risks.append('CONFLICT_RISK')

        # 4. 健康风险：学习时长期望严重超标
        time_gap = gap_analysis.get('dimension_gaps', {}).get('study_time_gap', {})
        if time_gap:
            age = student_profile.get('age', 0)
            expected_min = time_gap.get('expected_daily_minutes', 0)
            age_max = 90 if age < 12 else (150 if age < 15 else 210)
            if expected_min > age_max * 1.5:
                risks.append('HEALTH_RISK')

        # 5. 厌学风险：高压力 + 动力低 + 差距扩大
        if gap_analysis['overall_gap_score'] >= 50:
            motivation = student_profile.get('motivation_level', 0.5)
            widening = any(d.get('trend') == 'WIDENING'
                          for d in score_gaps.values())
            if motivation < 0.3 and widening:
                risks.append('STUDY_BURNOUT')

        return risks
```

### 5.3 沟通策略生成算法

```python
class CommunicationStrategyGenerator:
    """沟通策略生成器"""

    def generate_strategies(
        self, gap_analysis: dict, risk_flags: list,
        student_profile: dict, parent_profile: dict,
        previous_strategies: list
    ) -> list[dict]:
        """基于差距分析生成沟通策略列表"""
        strategies = []

        # Step 1: 紧急风险策略
        if 'HEALTH_RISK' in risk_flags:
            strategies.append(self._gen_urgent_health_strategy(
                gap_analysis, student_profile
            ))

        if 'STUDY_BURNOUT' in risk_flags:
            strategies.append(self._gen_burnout_intervention_strategy(
                gap_analysis, student_profile
            ))

        # Step 2: 常规差距策略
        dims = gap_analysis.get('dimension_gaps', {})

        if 'score_gap' in dims:
            sig = {k: v for k, v in dims['score_gap'].items()
                   if v.get('severity') in ('SIGNIFICANT', 'SEVERE')}
            if sig:
                strategies.append(self._gen_score_adjustment(
                    sig, student_profile, parent_profile
                ))

        if 'study_time_gap' in dims:
            tg = dims['study_time_gap']
            if tg.get('severity') in ('MODERATE', 'SIGNIFICANT', 'SEVERE'):
                strategies.append(self._gen_time_adjustment(tg, student_profile))

        if 'subject_focus_gap' in dims:
            fg = dims['subject_focus_gap']
            if fg.get('alignment_score', 1.0) < 0.5:
                strategies.append(self._gen_subject_redirect(fg, student_profile))

        if 'school_target_gap' in dims:
            sg = dims['school_target_gap']
            if sg.get('gap_level') in ('SIGNIFICANT', 'SEVERE'):
                strategies.append(self._gen_goal_alignment(sg, student_profile))

        # Step 3: 排序 + 去重 + 过滤近期已推荐
        strategies.sort(key=lambda s: s['priority'])
        strategies = self._filter_recently_recommended(
            strategies, previous_strategies
        )

        return strategies
```

## 6. 隐式期望推断引擎

部分家长不会主动填写期望问卷，需要从行为数据中推断隐性期望。

### 6.1 行为信号定义

| 信号编码 | 描述 | 推断维度 | 权重 |
|----------|------|----------|------|
| `FREQUENTLY_CHECKS_SUBJECT_SCORE` | 频繁查看某学科成绩 | SUBJECT_FOCUS | 0.15 |
| `OFTEN_VIEWS_ERROR_BOOK` | 经常浏览某学科错题本 | SUBJECT_FOCUS | 0.12 |
| `PURCHASED_SUBJECT_PACKAGE` | 购买特定学科增值包 | SUBJECT_FOCUS + SCORE | 0.20 |
| `SET_PARENTAL_CONTROL_AT` | 设置使用时长限制 | STUDY_TIME | 0.25 |
| `COMPLAINT_ABOUT_INSUFFICIENT_TIME` | 投诉学习时间不足 | STUDY_TIME | 0.18 |
| `FREQUENTLY_VIEWS_RANK` | 频繁查看排名/百分位 | RANK | 0.15 |
| `SET_HIGH_DAILY_GOAL` | 在系统中设定高目标 | SCORE + SCHOOL_TARGET | 0.20 |
| `DISCUSSES_COMPETITION` | 提及竞赛/拔尖内容 | SCHOOL_TARGET | 0.15 |
| `REPORT_VIEW_FREQUENCY` | 学情报告查看频率 | OVERALL_CONCERN_LEVEL | 0.10 |

### 6.2 推断算法

```python
from collections import defaultdict
from datetime import datetime, timedelta

class ImplicitExpectationInferrer:
    """隐式期望推断引擎"""

    SIGNAL_WEIGHTS = {
        'FREQUENTLY_CHECKS_SUBJECT_SCORE': {
            'dim': 'SUBJECT_FOCUS', 'weight': 0.15},
        'OFTEN_VIEWS_ERROR_BOOK': {
            'dim': 'SUBJECT_FOCUS', 'weight': 0.12},
        'PURCHASED_SUBJECT_PACKAGE': {
            'dim': 'SUBJECT_FOCUS', 'weight': 0.20},
        'SET_PARENTAL_CONTROL_AT': {
            'dim': 'STUDY_TIME', 'weight': 0.25},
        'COMPLAINT_ABOUT_INSUFFICIENT_TIME': {
            'dim': 'STUDY_TIME', 'weight': 0.18},
        'FREQUENTLY_VIEWS_RANK': {
            'dim': 'RANK', 'weight': 0.15},
        'SET_HIGH_DAILY_GOAL': {
            'dim': 'SCORE', 'weight': 0.20},
    }

    def infer_expectations(
        self, parent_user_id: int, student_user_id: int,
        behavior_events: list, analysis_window_days: int = 30
    ) -> list[dict]:
        """
        从家长行为数据推断隐式期望。

        Args:
            behavior_events: 家长行为事件列表
            analysis_window_days: 分析窗口天数

        Returns:
            推断的期望列表
        """
        cutoff = datetime.utcnow() - timedelta(days=analysis_window_days)
        recent_events = [e for e in behavior_events if e['timestamp'] >= cutoff]

        # 按维度聚合信号
        dimension_signals = defaultdict(lambda: defaultdict(float))

        for event in recent_events:
            signal_type = event['event_type']
            if signal_type not in self.SIGNAL_WEIGHTS:
                continue

            config = self.SIGNAL_WEIGHTS[signal_type]
            dim = config['dim']
            weight = config['weight']

            # 带有 subject_code 的事件按学科聚合
            subject = event.get('subject_code', 'GENERAL')
            dimension_signals[dim][subject] += weight

        # 转换为期望
        inferred = []
        for dim, subject_scores in dimension_signals.items():
            if dim == 'SUBJECT_FOCUS':
                top_subjects = sorted(subject_scores.items(),
                                      key=lambda x: -x[1])[:3]
                if top_subjects and top_subjects[0][1] >= 0.3:
                    subjects = [s[0] for s in top_subjects]
                    confidence = min(top_subjects[0][1] / 0.6, 1.0)
                    inferred.append({
                        'expectation_type': 'SUBJECT_FOCUS',
                        'inferred_target_value': subjects,
                        'confidence_score': round(confidence, 2),
                        'inferred_from_signals': [
                            f'{s[0]}(score={s[1]:.2f})' for s in top_subjects
                        ]
                    })

            elif dim == 'STUDY_TIME':
                total_score = sum(subject_scores.values())
                if total_score >= 0.25:
                    # 从 SET_PARENTAL_CONTROL_AT 事件中提取实际设定值
                    control_events = [
                        e for e in recent_events
                        if e['event_type'] == 'SET_PARENTAL_CONTROL_AT'
                    ]
                    if control_events:
                        avg_minutes = sum(
                            e.get('control_minutes', 0)
                            for e in control_events
                        ) / len(control_events)
                        inferred.append({
                            'expectation_type': 'STUDY_TIME',
                            'inferred_target_value': int(avg_minutes),
                            'target_unit': 'MINUTE',
                            'time_frame': 'WEEKLY',
                            'confidence_score': min(total_score / 0.5, 1.0),
                            'inferred_from_signals': [
                                f'{k}(score={v:.2f})'
                                for k, v in subject_scores.items()
                            ]
                        })

            elif dim == 'SCORE':
                total_score = sum(subject_scores.values())
                if total_score >= 0.20:
                    # 从目标设定事件中提取分数
                    goal_events = [
                        e for e in recent_events
                        if e['event_type'] == 'SET_HIGH_DAILY_GOAL'
                        and e.get('subject_code')
                    ]
                    for ge in goal_events:
                        inferred.append({
                            'expectation_type': 'SCORE',
                            'subject_code': ge['subject_code'],
                            'inferred_target_value': ge.get('target_score', 85),
                            'target_unit': 'POINT',
                            'time_frame': 'EXAM',
                            'confidence_score': min(total_score / 0.4, 1.0),
                            'inferred_from_signals': [
                                f'{k}(score={v:.2f})'
                                for k, v in subject_scores.items()
                            ]
                        })

        return inferred
```

| 查看趋势 | 家长本人 或 学生本人（>=14岁） |

### 10.2 数据隐私

- 家长期望数据仅对家长本人和管理后台（脱敏后）可见
- 学生无权查看家长对自己的具体期望值（避免压力）
- 分析结果中的学生数据快照遵循最小化原则
- 沟通话术不包含学生敏感信息（如具体排名）

### 10.3 内容安全

- AI 生成的话术经过内容安全过滤
- 不生成涉及歧视、偏见的建议
- 不会建议家长采取惩罚性教育手段
- 所有建议遵循未成年人保护相关法规

## 13. 测试场景

| 场景 | 输入 | 预期输出 |
|------|------|----------|
| 正常分析 | 家长期望数学90分，学生实际72分 | gap_score显著，生成PRESSURE_RELIEF策略 |
| 健康风险 | 家长期望小学生每日学习240分钟 | 检测到HEALTH_RISK，生成TIME_ADJUSTMENT策略 |
| 学科不匹配 | 家长侧重理科，学生擅长文科 | alignment_score<0.5，生成SUBJECT_REDIRECT策略 |
| 数据不足 | 学生仅使用1周 | 返回EG_DATA_INSUFFICIENT |
| 期望过低 | 家长期望60分，学生实际85分 | 检测到DEMOTIVATION风险 |
| 策略生效 | 家长调整期望后差距缩小40% | 策略状态变为EFFECTIVE |
| 策略无效 | 调整期望后差距反而扩大 | 策略状态变为INEFFECTIVE，推荐新策略 |
| 并发分析 | 同一周期重复触发分析 | 返回已有analysis_id |
| 画像服务不可用 | 学生画像服务超时 | 降级为基础分析，标记degraded=true |
