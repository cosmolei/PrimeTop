# 服务端 - 学习挑战赛与排行榜竞技系统 详细设计

## 1. 模块概述

### 1.1 功能定位

学习挑战赛与排行榜竞技系统是运营活动与成长激励体系的核心子模块，面向全学段学生提供竞技化学习体验。通过好友PK、赛季排行、实时答题对战等机制激发学习动力，将"做题练习"转化为"竞技挑战"，提升用户活跃度和留存率。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 好友PK挑战 | 用户发起/接受一对一答题挑战，限时答题比拼 |
| 排行榜系统 | 支持多维度排行（学科/学段/区域/全校），多时间窗口（日/周/月/赛季） |
| 赛季系统 | 按月或按学习阶段划分赛季，赛季结束时结算奖励 |
| 随机匹配对战 | 匹配实力相近的对手进行实时答题PK |
| 挑战回放与战绩 | 记录对战过程，支持回放查看双方答题详情 |
| 反作弊检测 | 检测异常答题速度、正确率突变等行为 |

### 1.3 设计原则

1. **教育优先**：竞技是手段，学习是目的，题目内容贴合教材课标
2. **适龄匹配**：只匹配同学段、同年级或相近能力值的对手
3. **轻量参与**：单次对局时长控制在 3-10 分钟，避免过度沉迷
4. **正向激励**：参与即有奖励，失败不扣分，避免挫败感
5. **防沉迷联动**：与防沉迷系统集成，超时自动禁止进入对战

## 2. 数据结构设计

### 2.1 数据库表设计

#### 2.1.1 challenge（挑战记录表）

```sql
CREATE TABLE challenge (
    id              BIGSERIAL PRIMARY KEY,
    challenge_no    VARCHAR(32) NOT NULL UNIQUE,       -- 挑战编号，格式：CH20260606xxxxx
    challenge_type  VARCHAR(20) NOT NULL,               -- 挑战类型：FRIEND_PK / RANDOM_MATCH / SEASON_MATCH
    status          VARCHAR(20) NOT NULL DEFAULT 'PENDING', -- 状态见 2.2 节状态机
    subject_code    VARCHAR(10) NOT NULL,               -- 学科编码
    grade_code      VARCHAR(10) NOT NULL,               -- 年级编码
    knowledge_scope VARCHAR(20) NOT NULL DEFAULT 'MIXED', -- 知识范围：CHAPTER / UNIT / SUBJECT / MIXED
    knowledge_tags  JSONB DEFAULT '[]',                 -- 具体知识点标签列表
    difficulty      VARCHAR(10) NOT NULL DEFAULT 'MEDIUM', -- 难度：EASY / MEDIUM / HARD / ADAPTIVE
    question_count  INT NOT NULL DEFAULT 10,            -- 每局题目数
    time_per_question INT NOT NULL DEFAULT 30,          -- 每题限时（秒）
    total_time_limit  INT NOT NULL DEFAULT 300,         -- 总时限（秒）
    season_id       BIGINT,                             -- 所属赛季ID（赛季对战时填写）
    
    -- 发起方
    initiator_id    BIGINT NOT NULL,
    initiator_score INT NOT NULL DEFAULT 0,
    initiator_correct_count INT NOT NULL DEFAULT 0,
    initiator_total_time INT NOT NULL DEFAULT 0,        -- 答题总耗时（毫秒）
    initiator_finished_at TIMESTAMPTZ,
    
    -- 接受方
    opponent_id     BIGINT,                             -- 对手ID（好友PK时可为空，等待接受）
    opponent_score  INT NOT NULL DEFAULT 0,
    opponent_correct_count INT NOT NULL DEFAULT 0,
    opponent_total_time INT NOT NULL DEFAULT 0,
    opponent_finished_at TIMESTAMPTZ,
    
    -- 胜负
    winner_id       BIGINT,                             -- 获胜者ID，平局为 NULL
    is_draw         BOOLEAN NOT NULL DEFAULT FALSE,
    
    -- 时间
    invited_at      TIMESTAMPTZ,                        -- 发出邀请时间
    accepted_at     TIMESTAMPTZ,                        -- 接受挑战时间
    started_at      TIMESTAMPTZ,                        -- 对战开始时间
    finished_at     TIMESTAMPTZ,                        -- 对战结束时间
    expired_at      TIMESTAMPTZ,                        -- 邀请过期时间
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    CONSTRAINT chk_challenge_type CHECK (challenge_type IN ('FRIEND_PK', 'RANDOM_MATCH', 'SEASON_MATCH')),
    CONSTRAINT chk_difficulty CHECK (difficulty IN ('EASY', 'MEDIUM', 'HARD', 'ADAPTIVE')),
    CONSTRAINT chk_status CHECK (status IN ('PENDING', 'ACCEPTED', 'IN_PROGRESS', 'FINISHED', 'EXPIRED', 'CANCELLED'))
);

CREATE INDEX idx_challenge_initiator ON challenge (initiator_id, created_at DESC);
CREATE INDEX idx_challenge_opponent ON challenge (opponent_id, created_at DESC);
CREATE INDEX idx_challenge_season ON challenge (season_id, created_at DESC) WHERE season_id IS NOT NULL;
CREATE INDEX idx_challenge_status ON challenge (status, created_at DESC);
CREATE INDEX idx_challenge_pending ON challenge (opponent_id, status) WHERE status = 'PENDING';
```

#### 2.1.2 challenge_question（挑战题目表）

```sql
CREATE TABLE challenge_question (

    opponent_time_ms    INT,
    opponent_answered_at TIMESTAMPTZ,
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    UNIQUE (challenge_id, sequence_no)
);

CREATE INDEX idx_cq_challenge ON challenge_question (challenge_id);
CREATE INDEX idx_cq_question ON challenge_question (question_id);
```

#### 2.1.3 leaderboard_entry（排行榜条目表）

```sql
CREATE TABLE leaderboard_entry (

    avg_time_ms     INT NOT NULL DEFAULT 0,             -- 平均答题耗时
```

### 2.2 挑战状态机

```
                              ┌─────────────┐
                              │  CANCELLED   │ ◄── 发起方取消
                              └─────────────┘
                                    ▲
┌──────────┐  邀请/匹配成功  ┌──────────┐  对手接受  ┌────────────┐
│ PENDING  │ ───────────── │ ACCEPTED │ ────────── │ IN_PROGRESS│
└──────────┘               └──────────┘            └──────┬─────┘
      │                         │                          │
      │ 邀请超时                │ 拒绝/超时              双方完成
      ▼                         ▼                          │
┌──────────┐               ┌──────────┐                    ▼
│ EXPIRED  │               │ EXPIRED  │              ┌──────────┐
└──────────┘               └──────────┘              │ FINISHED  │
                                                     └──────────┘
```

状态说明：

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| PENDING | 等待匹配/接受 | 好友PK发出邀请，或随机匹配排队中 |
| ACCEPTED | 对手已接受 | 好友点击接受 / 匹配成功 |
| IN_PROGRESS | 对战进行中 | 双方进入答题房间 |
| FINISHED | 对战结束 | 双方答完所有题目或时间到 |
| EXPIRED | 邀请过期 | 超过 `expired_at` 未接受 |
| CANCELLED | 已取消 | 发起方主动取消 |

## 3. API 接口设计

### 3.1 挑战发起与接受

#### 3.1.1 发起好友PK挑战

```
POST /api/v1/challenges/friend-pk
Authorization: Bearer <token>
Content-Type: application/json

Request:
{
  "opponentId": 123456,
  "subjectCode": "MATH",
  "knowledgeScope": "CHAPTER",
  "knowledgeTags": ["quadratic_equation", "vieta_formulas"],
  "difficulty": "ADAPTIVE",
  "questionCount": 10,
  "timePerQuestion": 30
}

Response 201:
{
  "challengeNo": "CH20260606001",
  "challengeId": 100001,
  "status": "PENDING",
  "opponent": {
    "userId": 123456,
    "nickname": "小明",
    "avatar": "https://...",
    "gradeCode": "G9"
  },
  "expiresAt": "2026-06-06T16:00:00.000Z"
}

Response 400 (不能挑战自己):
{
  "code": "CANNOT_CHALLENGE_SELF",
  "message": "不能向自己发起挑战"
}

Response 429 (频率限制):
{
  "code": "CHALLENGE_RATE_LIMITED",
  "message": "今日挑战次数已达上限",
  "retryAfter": "2026-06-07T00:00:00.000Z"
}

Response 403 (对方不在线/不接受挑战):
{
  "code": "OPPONENT_UNAVAILABLE",
  "message": "对方当前无法接受挑战"
}
```

**业务规则：**
- 发起方与接受方必须为好友关系
- 双方学段必须一致
- 每日发起次数受赛季 `daily_challenge_limit` 约束
- 邀请默认 5 分钟过期

#### 3.1.2 接受挑战

```

Authorization: Bearer <token>

Response 200:
```

```java
/**
 * 挑战赛积分计算器
 */
public class ChallengeScoreCalculator {

    // 基础分
    private static final int BASE_CORRECT_SCORE = 10;
    
    // 速度加分阈值（毫秒）
    private static final int[][] TIME_BONUS_THRESHOLDS = {
        {5000, 3},    // 5秒内答对 +3
        {10000, 2},   // 10秒内答对 +2
        {20000, 1}    // 20秒内答对 +1
    };
    
    // 连胜加分
    private static final int[] STREAK_BONUS = {
        0, 0, 0, 5,   // 3连 +5
        0, 10,         // 5连 +10
        0, 0, 0, 0, 0, 15  // 10连 +15
    };
    
    /**
     * 计算单题得分
     * @param isCorrect   是否正确
     * @param timeMs      答题耗时
     * @param questionDifficulty 题目难度权重
     * @return 得分
     */
    public int calculateQuestionScore(boolean isCorrect, int timeMs, 
                                       String questionDifficulty) {
        if (!isCorrect) return 0;
        
        int score = BASE_CORRECT_SCORE;
        
        // 难度加权
        double diffWeight = switch (questionDifficulty) {
            case "EASY" -> 0.8;
            case "MEDIUM" -> 1.0;
            case "HARD" -> 1.3;
            default -> 1.0;
        };
        score = (int) Math.ceil(score * diffWeight);
        
        // 速度加分
        for (int[] threshold : TIME_BONUS_THRESHOLDS) {
            if (timeMs <= threshold[0]) {
                score += threshold[1];
                break;
            }
        }
        
        return score;
    }
    
    /**
     * 计算连续答对加分
     */
    public int calculateStreakBonus(int consecutiveCorrect) {
        if (consecutiveCorrect < STREAK_BONUS.length) {
            return STREAK_BONUS[consecutiveCorrect];
        }
        return 0;
    }
    
    /**
     * 计算对战最终得分
     */
    public ChallengeScoreResult calculateFinalScore(
            List<ChallengeAnswer> answers, List<Question> questions) {
        int totalScore = 0;
        int correctCount = 0;
        int consecutiveCorrect = 0;
        int totalTimeMs = 0;
        
        for (int i = 0; i < answers.size(); i++) {
            ChallengeAnswer answer = answers.get(i);
            Question question = questions.get(i);
            totalTimeMs += answer.getTimeMs();
            
            if (answer.isCorrect()) {
                correctCount++;
                consecutiveCorrect++;
                int qScore = calculateQuestionScore(
                    true, answer.getTimeMs(), question.getDifficulty());
                int streakBonus = calculateStreakBonus(consecutiveCorrect);
                totalScore += qScore + streakBonus;
            } else {
                consecutiveCorrect = 0;
            }
        }
        
        return new ChallengeScoreResult(
            totalScore, correctCount, answers.size(), totalTimeMs);
    }
}
```

### 4.2 匹配算法

```java
/**
 * 对手匹配服务
 * 采用基于能力分的区间匹配策略，逐步扩大搜索范围
 */
public class MatchmakingService {
    
    private static final int INITIAL_ABILITY_RANGE = 50;   // 初始搜索范围
    private static final int MAX_ABILITY_RANGE = 200;      // 最大搜索范围
    private static final int RANGE_EXPAND_INTERVAL_MS = 5000; // 每5秒扩大范围
    private static final int MAX_WAIT_MS = 60000;           // 最大等待60秒
    
    @Autowired
    private MatchQueueRepository matchQueueRepo;
    @Autowired
    private ChallengeService challengeService;
    @Autowired
    private WebSocketNotificationService wsNotifyService;
    
    /**
     * 加入匹配队列
     */
    @Transactional
    public MatchQueueEntry joinQueue(Long userId, String subjectCode, 
                                      String gradeCode, int abilityScore) {
        // 检查是否已在队列中
        Optional<MatchQueueEntry> existing = matchQueueRepo
            .findWaitingByUserId(userId);
        if (existing.isPresent()) {
            throw new BusinessException("ALREADY_IN_QUEUE", "已在匹配队列中");
        }
        
        // 检查防沉迷限制
        antiAddictionService.checkChallengeAllowed(userId);
        
        // 检查每日次数
        int todayCount = challengeService.getTodayChallengeCount(userId);
        Season currentSeason = seasonService.getCurrentSeason();
        if (todayCount >= currentSeason.getDailyChallengeLimit()) {
            throw new BusinessException("DAILY_LIMIT_REACHED", "今日挑战次数已达上限");
        }
        
        MatchQueueEntry entry = MatchQueueEntry.builder()
            .userId(userId)
            .subjectCode(subjectCode)
            .gradeCode(gradeCode)
            .abilityScore(abilityScore)
            .status("WAITING")
            .expiredAt(Instant.now().plusSeconds(60))
            .build();
        
        matchQueueRepo.save(entry);
        
        // 立即尝试匹配
        tryMatch(entry);
        
        return entry;
    }
    
    /**
     * 核心匹配逻辑
     * 1. 先在精确范围内查找
     * 2. 范围逐步扩大
     * 3. 优先匹配等待时间最长的用户
     */
    private void tryMatch(MatchQueueEntry entry) {
        int range = INITIAL_ABILITY_RANGE;
        
        List<MatchQueueEntry> candidates = matchQueueRepo.findCandidates(
            entry.getSubjectCode(),
            entry.getGradeCode(),
            entry.getAbilityScore() - range,
            entry.getAbilityScore() + range,
            entry.getUserId()
        );
        
        if (candidates.isEmpty()) {
            return; // 等待定时任务下次尝试
        }
        
        // 选择等待时间最长的候选者
        MatchQueueEntry opponent = candidates.get(0);
        
        // 双方标记为 MATCHED
        entry.setStatus("MATCHED");
        entry.setMatchedWith(opponent.getUserId());
        opponent.setStatus("MATCHED");
        opponent.setMatchedWith(entry.getUserId());
        
        matchQueueRepo.saveAll(List.of(entry, opponent));
        
        // 创建挑战
        Challenge challenge = challengeService.createMatchedChallenge(
            entry.getUserId(), opponent.getUserId(),
            entry.getSubjectCode(), entry.getGradeCode());
        
        entry.setChallengeId(challenge.getId());
        opponent.setChallengeId(challenge.getId());
        matchQueueRepo.saveAll(List.of(entry, opponent));
        
        // 通过 WebSocket 通知双方
        wsNotifyService.notifyMatchResult(entry.getUserId(), challenge);
        wsNotifyService.notifyMatchResult(opponent.getUserId(), challenge);
    }
}
```

```java
     * 更新单个排行榜
     */
    private void updateLeaderboard(String type, String dimension,
                                    String subjectCode, String gradeCode,
                                    String periodKey) {

        String sql = """
            INSERT INTO leaderboard_entry 
                (leaderboard_type, dimension, subject_code, grade_code, 
                 period_key, user_id, score, challenge_count, 
                 win_count, draw_count, lose_count, correct_rate, avg_time_ms)
            SELECT 
                :type, :dimension, :subjectCode, :gradeCode,
                :periodKey, 
                c.initiator_id AS user_id,
                SUM(CASE WHEN c.winner_id = c.initiator_id THEN 1 ELSE 0 END) * 10
                    + SUM(c.initiator_correct_count) AS score,
                COUNT(*) AS challenge_count,
                SUM(CASE WHEN c.winner_id = c.initiator_id THEN 1 ELSE 0 END) AS win_count,
                SUM(CASE WHEN c.is_draw THEN 1 ELSE 0 END) AS draw_count,
                SUM(CASE WHEN c.winner_id != c.initiator_id AND c.winner_id IS NOT NULL 
                    THEN 1 ELSE 0 END) AS lose_count,
                AVG(c.initiator_correct_count::DECIMAL / c.question_count) AS correct_rate,
                AVG(c.initiator_total_time) AS avg_time_ms
            FROM challenge c
            WHERE c.status = 'FINISHED'
              AND c.finished_at >= :periodStart
              AND c.finished_at < :periodEnd
              AND (:gradeCode IS NULL OR EXISTS (
                  SELECT 1 FROM student_profile sp 
                  WHERE sp.user_id = c.initiator_id 
                  AND sp.grade_code = :gradeCode))
            GROUP BY c.initiator_id
            ON CONFLICT (leaderboard_type, dimension, subject_code, 
                         grade_code, period_key, user_id)
            DO UPDATE SET
                score = EXCLUDED.score,
                challenge_count = EXCLUDED.challenge_count,
                win_count = EXCLUDED.win_count,
                correct_rate = EXCLUDED.correct_rate,
                avg_time_ms = EXCLUDED.avg_time_ms,
                updated_at = NOW()
            """;
        
        jdbcTemplate.update(sql, params);
        
        // 计算排名
        String rankSql = """
            UPDATE leaderboard_entry le
            SET rank_position = subquery.rn
            FROM (
                SELECT id, ROW_NUMBER() OVER (ORDER BY score DESC, avg_time_ms ASC) AS rn
                FROM leaderboard_entry
                WHERE leaderboard_type = :type
                  AND dimension = :dimension
                  AND COALESCE(subject_code, '') = COALESCE(:subjectCode, '')
                  AND COALESCE(grade_code, '') = COALESCE(:gradeCode, '')
                  AND period_key = :periodKey
            ) subquery
            WHERE le.id = subquery.id
            """;
```

```java
/**
 * 对战题目选取引擎
 * 根据学科、年级、难度、知识点范围智能组卷
 */
public class ChallengeQuestionSelector {
    
    /**
     * 为挑战选取题目
     * @param subjectCode  学科
     * @param gradeCode    年级  
     * @param knowledgeScope 知识范围
     * @param knowledgeTags  知识点标签
     * @param difficulty     难度策略
     * @param count          题目数量
     * @param usersAbilityDiff 双方能力差（自适应难度用）
     * @return 题目列表
     */
    public List<Question> selectQuestions(String subjectCode, String gradeCode,
                                           String knowledgeScope,
                                           List<String> knowledgeTags,
                                           String difficulty, int count,
                                           int usersAbilityDiff) {
        
        List<String> targetDifficulties = resolveDifficulty(difficulty, usersAbilityDiff);
        
        // 按难度分配题目数量
        Map<String, Integer> distribution = distributeByDifficulty(count, targetDifficulties);
        
        List<Question> selected = new ArrayList<>();
        
        for (Map.Entry<String, Integer> entry : distribution.entrySet()) {
            String diff = entry.getKey();
            int qty = entry.getValue();
            
            List<Question> pool = questionRepository.findAvailableForChallenge(
                subjectCode, gradeCode, knowledgeScope, knowledgeTags, diff, qty * 3);
            
            // 随机打乱后取所需数量
            Collections.shuffle(pool, new SecureRandom());
            selected.addAll(pool.stream().limit(qty).collect(Collectors.toList()));
        }
        
        // 确保题型多样化（选择题、填空题、判断题混合）
        ensureTypeDiversity(selected, count);
        
        // 如果不够，从相邻难度补充
        if (selected.size() < count) {
            fillWithAdjacentDifficulty(selected, count, subjectCode, gradeCode);
        }
        
        return selected.stream().limit(count).collect(Collectors.toList());
    }
    
    /**
     * 自适应难度：根据双方能力差调整题目分布
     */
    private List<String> resolveDifficulty(String difficulty, int abilityDiff) {
        if (!"ADAPTIVE".equals(difficulty)) {
            return List.of(difficulty);
        }
        
        if (Math.abs(abilityDiff) <= 30) {
            // 能力接近：中等为主，穿插少量难题
            return List.of("EASY", "MEDIUM", "MEDIUM", "MEDIUM", "HARD");
        } else {
            // 能力差距较大：偏向中等，确保双方都有机会
            return List.of("EASY", "EASY", "MEDIUM", "MEDIUM", "MEDIUM");
        }
    }
}
```

```java
/**
 * 竞技反作弊引擎
 */
public class AntiCheatService {
    
    /**
     * 检测答题行为异常
     * 在每次提交答案后异步执行
     */
    public CheatDetectionResult analyze(ChallengeContext context, 
                                          ChallengeAnswerRequest answer) {
        List<String> flags = new ArrayList<>();
        double riskScore = 0.0;
        
        // 1. 检测异常答题速度
        if (answer.getTimeMs() < 1500) {  // 1.5秒内答完
            // 检查题目复杂度
            Question question = context.getQuestion(answer.getSequenceNo());
            if (question.getEstimatedTimeMs() > 10000) {
                flags.add("ABNORMALLY_FAST");
                riskScore += 0.4;
            }
        }
        
        // 2. 检测正确率突变
        UserCheatProfile profile = getCheatProfile(context.getUserId());
        if (profile.getHistoricalCorrectRate() < 0.5 
                && context.getCurrentCorrectRate() > 0.9
                && context.getAnsweredCount() >= 5) {
            flags.add("ACCURACY_SPIKE");
            riskScore += 0.3;
        }
        
        // 3. 检测答题时间模式异常（每题时间几乎相同）
        List<Integer> recentTimes = context.getRecentAnswerTimes(5);
        if (recentTimes.size() >= 5) {
            double stdDev = calculateStdDev(recentTimes);
            double mean = calculateMean(recentTimes);
            if (stdDev < mean * 0.1) {  // 标准差 < 均值的10%
                flags.add("UNIFORM_TIMING");
                riskScore += 0.2;
            }
        }
        
        // 4. 检测多设备/多账号异常
        if (context.getDeviceInfo() != null) {
            boolean deviceShared = checkSharedDevice(context.getDeviceInfo(), 
                                                      context.getOpponentId());
            if (deviceShared) {
                flags.add("SHARED_DEVICE");
                riskScore += 0.5;
            }
        }
        
        return new CheatDetectionResult(riskScore, flags, 
            riskScore >= 0.7 ? CheatAction.QUARANTINE :
            riskScore >= 0.4 ? CheatAction.FLAG_FOR_REVIEW :
            CheatAction.NONE);
    }
    
    /**
     * 反作弊处理动作
     */
    public enum CheatAction {
        NONE,                           // 无异常
        FLAG_FOR_REVIEW,                // 标记待审核（正常结算，记录日志）
        QUARANTINE                      // 隔离（不结算积分，不参与排行）
    }
}
```

```java
/**
 * 赛季结算服务
 * 赛季结束时由定时任务触发
 */
public class SeasonSettlementService {
    
    /**
     * 执行赛季结算
     */
    @Transactional
    public void settleSeason(Long seasonId) {
        Season season = seasonRepository.findById(seasonId)
            .orElseThrow(() -> new BusinessException("SEASON_NOT_FOUND"));
        
        if (!"ACTIVE".equals(season.getStatus())) {
            throw new BusinessException("SEASON_NOT_ACTIVE");
        }
        
        // 1. 更新赛季状态为结算中
        season.setStatus("SETTLING");
        seasonRepository.save(season);
        
        // 2. 计算最终排名
        List<SeasonParticipation> participations = participationRepository
            .findBySeasonIdOrderByTotalScoreDesc(seasonId);
        
        for (int i = 0; i < participations.size(); i++) {
            participations.get(i).setFinalRank(i + 1);
        }
        participationRepository.saveAll(participations);
        
        // 3. 发放奖励（写入奖励队列，用户手动领取）
        SeasonRewardConfig config = parseRewardConfig(season.getRewardConfig());
        
        for (SeasonParticipation p : participations) {
            SeasonReward reward = resolveReward(config, p);
            if (reward != null) {
                rewardQueueService.createReward(seasonId, p.getUserId(), reward);
            }
        }
        
        // 4. 发送结算通知
        for (SeasonParticipation p : participations) {
            if (p.getFinalRank() <= 100) {
                notificationService.sendSeasonResultNotification(
                    p.getUserId(), season, p.getFinalRank());
            }
        }
        
        // 5. 更新赛季状态为已结束
        season.setStatus("ENDED");
        seasonRepository.save(season);
        
        log.info("赛季 {} 结算完成，参与人数：{}", season.getSeasonCode(), 
            participations.size());
    }
    
    /**
     * 根据排名解析奖励
     */
    private SeasonReward resolveReward(SeasonRewardConfig config, 
                                        SeasonParticipation p) {
        // 检查排名奖励
        for (RewardTier tier : config.getTiers()) {
            if (p.getFinalRank() >= tier.getRankRange()[0] 
                    && p.getFinalRank() <= tier.getRankRange()[1]) {
                return tier.getReward();
            }
        }
        
        // 检查参与奖
        if (p.getChallengeCount() >= config.getParticipationReward().getMinChallenges()) {
            return config.getParticipationReward().getReward();
        }
        
        return null;
    }
}
```

## 8. 关键边界条件与注意事项

### 8.1 并发安全

| 场景 | 风险 | 解决方案 |
|------|------|----------|
| 同一用户同时被多人挑战 | 重复接受 | 接受时加分布式锁 `challenge:accept:{challengeId}` |
| 匹配队列重复匹配 | 一方被匹配两次 | 使用 `UPDATE ... WHERE status='WAITING' RETURNING *` 原子匹配 |
| 排行榜并发写入 | 积分计算不一致 | 排行榜由定时任务统一计算，不在实时路径中直接写 |
| 答题并发提交 | 超时后仍提交 | 服务端校验 `answered_at <= started_at + total_time_limit` |

### 8.2 弱网与断连处理

1. **断线重连**：WebSocket 断连后允许 30 秒内重连，重连后恢复对战状态
2. **答题超时**：单题超时未答视为答错，自动进入下一题
3. **结果异步确认**：对战结束后服务端主动结算，不依赖客户端确认
4. **离线判定**：30 秒无心跳视为离线，通知对手并继续计时

### 8.3 题目库存保障

1. 对战前预检查题库可用题目数，不足时拒绝发起新挑战
2. 自适应难度模式下，当某难度题目不足时自动降级到相邻难度
3. 避免短期内重复出同一题目（Redis Set 记录用户近期已做题目）

### 8.4 防沉迷联动

1. 发起挑战前调用防沉迷服务检查
2. 对战过程中如果防沉迷触发（如到达使用时长上限），当前对局正常完成，之后禁止发起新对局
3. 低龄用户（幼儿/小学低年级）限制每日挑战次数上限更低（建议 3 次）

### 8.5 数据一致性

1. 对战结果通过数据库事务保证原子性（更新挑战状态 + 更新排行榜 + 发放积分）
2. 排行榜允许短暂不一致（小时级更新），展示时标注数据更新时间
3. 赛季积分以数据库 `season_participation.total_score` 为准，Redis 仅做展示缓存

## 9. 性能预估

### 9.1 容量估算

| 指标 | 估算值 | 依据 |
|------|--------|------|
| 日活用户 | 10 万 | MVP 阶段 |
| 日挑战参与率 | 15% | 1.5 万用户/天 |
| 每人每日对战次数 | 3 次 | 4.5 万局/天 |
| 匹配并发峰值 | 200/s | 晚间高峰 |
| 排行榜条目数 | ~50 万/维度 | 周活跃用户 |
| WebSocket 并发连接 | 2 万 | 同时在线对战 |

### 9.2 关键优化

1. **排行榜**：使用 Redis Sorted Set，查询 O(log N + M)
2. **匹配队列**：Redis Sorted Set 按能力分排序，范围查询 O(log N + M)
3. **题目预加载**：接受挑战时一次性返回所有题目 ID，答题过程只提交答案
4. **批量排行计算**：定时任务批量 SQL 聚合，避免实时计算
