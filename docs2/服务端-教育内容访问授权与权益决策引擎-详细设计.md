# 服务端-教育内容访问授权与权益决策引擎-详细设计

## 1. 概述

### 1.1 文档目的

本设计文档详细描述 PrimeTop 教育内容访问授权与权益决策引擎（Content Access Authorization & Entitlement Decision Engine，简称 **CADE**）的架构、数据模型、接口设计和实现方案。

CADE 是连接「支付订阅系统」「用户画像系统」「内容管理系统」与「业务服务层」的核心中间件，为所有教育内容的访问提供统一的授权决策。

### 1.2 设计背景

PrimeTop 采用 Freemium + 会员订阅 + 增值服务购买的商业模型。用户可拥有多种权益来源（订阅、增值包、活动赠送、学校授权等），内容也有不同的访问限制（免费/付费/年级限定/教材版本限定等）。现有系统已有：

- **支付与会员订阅系统**：处理支付流程和订阅生命周期
- **用户额度管控与功能门控引擎**：处理 API 调用次数限制和功能开关
- **统一认证授权与令牌管理体系**：处理身份认证和系统级 RBAC
- **权限管理与角色访问控制**：处理管理后台的角色权限

**缺失环节**：没有一个统一引擎来回答核心问题——「**此用户在此刻能否访问此内容？如果不能，原因是什么？应该展示什么引导？**」

CADE 正是填补这一空白的中间决策层。

### 1.3 设计目标

| 目标 | 说明 |
|------|------|
| 统一决策 | 所有内容访问请求经过同一个引擎，决策逻辑集中管理 |
| 高性能 | 单次决策延迟 < 5ms（P99），支持 10,000+ QPS |
| 可扩展 | 新的权益类型和内容策略可通过配置添加，无需修改调用方代码 |
| 降级安全 | 引擎异常时采用 fail-open（付费内容默认拒绝）或 fail-closed（免费内容默认放行）策略 |
| 体验友好 | 拒绝时返回结构化原因和引导建议（如"升级会员"），而非简单的 403 |

### 1.4 核心职责边界

| 职责 | 属于 CADE | 不属于 CADE |
|------|-----------|-------------|
| 判断用户能否访问指定内容 | ✅ | |
| 计算用户当前有效权益 | ✅ | |
| 配额扣减与计数 | ✅ | |
| 支付流程处理 | | ❌（支付服务） |
| 内容实际传输与渲染 | | ❌（内容服务/客户端） |
| 用户身份认证 | | ❌（认证服务） |
| 管理后台角色权限 | | ❌（RBAC 系统） |

### 2.2 核心组件

| 组件 | 职责 |
|------|------|
| **权益聚合层** | 从多个数据源加载用户权益，合并计算当前有效权益集合 |
| **策略评估层** | 基于用户权益 + 内容元数据 + 上下文，执行策略规则，输出决策结果 |
| **配额计算层** | 管理用户实时用量计数，判断是否超出日/周/月配额 |
| **决策缓存层** | 缓存近期决策结果，减少重复计算 |
| **事件订阅器** | 监听权益变更事件（订阅成功、退款、活动赠送等），主动失效缓存 |

### 2.3 部署方案

```
CADE 独立部署为无状态微服务
  - 实例数: 4~8（按 QPS 弹性伸缩）
  - CPU: 2核 / 内存: 4GB
  - 依赖: Redis（用量计数 + 决策缓存）
  - 依赖: MySQL（权益快照表，只读）
  - 依赖: Kafka（权益变更事件订阅）
```

## 4. 权益聚合层

### 4.1 权益聚合流程

```
用户发起内容访问请求
         │
         ▼
    ┌────────────┐
    │ 查询Redis  │ ── 命中 ──→ 返回缓存权益集
    │ 权益缓存   │
    └─────┬──────┘
          │ 未命中
          ▼
    ┌────────────┐
    │ 查询MySQL  │ ── 命中 ──→ 组装权益集 → 写入Redis → 返回
    │ 权益快照表 │
    └─────┬──────┘
          │ 未命中或需刷新
          ▼
    ┌────────────────┐
    │ 向支付/订阅服务 │ ── 同步最新权益 ──→ 写入快照表 → 写入Redis → 返回
    │ 发起权益同步    │
    └────────────────┘
```

### 4.2 权益聚合器实现

```java
/**
 * 用户权益聚合器
 * 从多数据源加载并合并用户当前有效权益
 */
@Service
public class EntitlementAggregator {

    @Resource
    private EntitlementSnapshotMapper snapshotMapper;

    @Resource
    private EntitlementCacheService cacheService;

    @Resource
    private SubscriptionRpcService subscriptionRpcService;

    /**
     * 获取用户当前有效权益集合
     *
     * @param userId 用户ID
     * @param context 决策上下文（含当前时间、设备信息等）
     * @return 聚合后的有效权益集合
     */
    public EffectiveEntitlementSet aggregate(Long userId, DecisionContext context) {
        // 1. 查询本地缓存
        EffectiveEntitlementSet cached = cacheService.get(userId);
        if (cached != null && cached.isValid(context.getNow())) {
            return cached;
        }

        // 2. 查询快照表
        List<EntitlementSnapshot> snapshots = snapshotMapper.selectActiveByUserId(
            userId, context.getNow()
        );

        // 3. 如果快照为空或过期，触发远端同步
        if (snapshots.isEmpty() || isSnapshotStale(snapshots)) {
            snapshots = syncFromSource(userId, snapshots);
        }

        // 4. 合并权益
        EffectiveEntitlementSet entSet = mergeEntitlements(userId, snapshots, context);

        // 5. 写入缓存
        cacheService.put(userId, entSet, CACHE_TTL_SECONDS);

        return entSet;
    }

    /**
     * 合并多条权益记录，解决冲突
     */
    private EffectiveEntitlementSet mergeEntitlements(
            Long userId,
            List<EntitlementSnapshot> snapshots,
            DecisionContext context) {

        EffectiveEntitlementSet result = new EffectiveEntitlementSet();
        result.setUserId(userId);
        result.setComputedAt(context.getNow());

        // 按 (entitlementType + scopeKey) 分组
        Map<String, List<EntitlementSnapshot>> grouped = snapshots.stream()
            .filter(s -> s.getStatus() == EntitlementStatus.ACTIVE.getValue())
            .filter(s -> s.getEffectiveFrom().isBeforeOrEqual(context.getNow()))
            .filter(s -> s.getEffectiveUntil() == null
                      || s.getEffectiveUntil().isAfter(context.getNow()))
            .collect(Collectors.groupingBy(this::buildGroupKey));

        for (Map.Entry<String, List<EntitlementSnapshot>> entry : grouped.entrySet()) {
            List<EntitlementSnapshot> group = entry.getValue();

            // 取该权益下有效期最长的记录作为主权益
            EntitlementSnapshot primary = group.stream()
                .max(Comparator.comparing(this::getEffectiveDuration))
                .orElse(null);

            if (primary != null) {
                EntitlementItem item = EntitlementItem.builder()
                    .type(EntitlementType.valueOf(primary.getEntitlementType()))
                    .scopeKey(primary.getScopeKey())
                    .source(EntitlementSource.valueOf(primary.getSourceType()))
                    .effectiveFrom(primary.getEffectiveFrom())
                    .effectiveUntil(primary.getEffectiveUntil())
                    .build();
                result.addEntitlement(item);
            }
        }

        // 计算权益等级（决定用户看到的体验层级）
        result.setTier(computeUserTier(result));

        return result;
    }

    /**
     * 计算用户综合等级
     * FREE < BASIC_MEMBER < PREMIUM_MEMBER < PREMIUM_ADDON
     */
    private UserEntitlementTier computeUserTier(EffectiveEntitlementSet entSet) {
        if (entSet.hasEntitlement(EntitlementType.FULL_CONTENT_ACCESS, null)) {
            // 检查是否有增值权益
            boolean hasAddon = entSet.getAll().stream()
                .anyMatch(e -> e.getSource() == EntitlementSource.ADDON_PURCHASE);
            return hasAddon ? UserEntitlementTier.PREMIUM_ADDON
                            : UserEntitlementTier.PREMIUM_MEMBER;
        }

        if (!entSet.getAll().isEmpty()) {
            return UserEntitlementTier.BASIC_MEMBER;
        }

        return UserEntitlementTier.FREE;
    }

    private Duration getEffectiveDuration(EntitlementSnapshot s) {
        LocalDateTime end = s.getEffectiveUntil() != null
            ? s.getEffectiveUntil()
            : LocalDateTime.now().plusYears(10); // 永久视为很长
        return Duration.between(s.getEffectiveFrom(), end);
    }

    private boolean isSnapshotStale(List<EntitlementSnapshot> snapshots) {
        LocalDateTime latest = snapshots.stream()
            .map(EntitlementSnapshot::getUpdatedAt)
            .max(LocalDateTime::compareTo)
            .orElse(LocalDateTime.MIN);
        return latest.isBefore(LocalDateTime.now().minusMinutes(5));
    }
}
```

### 4.3 权益同步机制

权益变更通过事件驱动方式同步到 CADE 快照表。

```java
/**
 * 权益变更事件消费者
 * 监听来自支付/订阅/运营系统的事件，更新快照表
 */
@Component
public class EntitlementEventConsumer {

    @Resource
    private EntitlementSnapshotMapper snapshotMapper;

    @Resource
    private EntitlementCacheService cacheService;

    /**
     * 监听权益发放事件（订阅成功、增值购买、活动赠送等）
     */
    @KafkaListener(topics = "entitlement-granted", groupId = "cade-consumer")
    public void onEntitlementGranted(EntitlementGrantedEvent event) {
        EntitlementSnapshot snapshot = EntitlementSnapshot.builder()
            .userId(event.getUserId())
            .sourceType(event.getSource().name())
            .sourceRefId(event.getSourceRefId())
            .entitlementType(event.getEntitlementType().name())
            .scopeKey(event.getScopeKey())
            .grantedAt(event.getGrantedAt())
            .effectiveFrom(event.getEffectiveFrom())
            .effectiveUntil(event.getEffectiveUntil())
            .status(EntitlementStatus.ACTIVE.getValue())
            .metadata(event.getMetadata())
            .build();

        snapshotMapper.upsert(snapshot);

        // 主动失效该用户的权益缓存
        cacheService.invalidate(event.getUserId());
    }

    /**
     * 监听权益撤销事件（退款、退订、管理员撤销等）
     */
    @KafkaListener(topics = "entitlement-revoked", groupId = "cade-consumer")
    public void onEntitlementRevoked(EntitlementRevokedEvent event) {
        snapshotMapper.markRevoked(
            event.getUserId(),
            event.getSource().name(),
```

### 5.2 策略评估器实现

```java
/**
 * 策略评估器
 * 根据内容策略和用户权益做出访问决策
 */
@Service
public class PolicyEvaluator {

    @Resource
    private ContentPolicyMapper policyMapper;

    @Resource
    private ParentalControlService parentalControlService;

    /**
     * 评估访问决策
     *
     * @param request 决策请求
     * @param entitlements 用户有效权益集合
     * @return 决策结果
     */
    public AccessDecision evaluate(DecisionRequest request,
                                    EffectiveEntitlementSet entitlements) {
        ContentMetadata content = request.getContent();
        String action = request.getAction();

        // Step 1: 内容状态检查
        if (content.getStatus() != ContentStatus.AVAILABLE.getValue()) {
            return AccessDecision.deny("CONTENT_UNAVAILABLE",
                "该内容已下架或暂时不可用");
        }

        // Step 2: 免费内容快速通过
        if (content.getAccessLevel() == AccessLevel.FREE.getValue()) {
            AccessDecision decision = checkAdditionalRules(request, entitlements);
            return decision != null ? decision : AccessDecision.allow();
        }

        // Step 3: 匹配内容访问策略
        List<ContentPolicy> policies = policyMapper.selectByContentType(
            content.getContentType(), PolicyStatus.ENABLED.getValue()
        );

        // 按 priority 降序匹配
        for (ContentPolicy policy : policies) {
            if (!matchContentFilter(policy.getContentFilter(), content)) {
                continue;
            }

            // 评估权益条件
            EntitlementCondition condition = EntitlementCondition.fromJson(
                policy.getRequiredEntitlement()
            );
            boolean satisfied = evaluateCondition(condition, entitlements);

            if (satisfied) {
                AccessDecision decision = checkAdditionalRules(request, entitlements);
                return decision != null ? decision : AccessDecision.allow(
                    policy.getPolicyCode()
                );
            }
        }

        // Step 4: 无策略匹配且非免费 → 拒绝
        DenyReason reason = determineDenyReason(content, entitlements);
        return AccessDecision.deny(reason.getCode(), reason.getMessage());
    }

    /**
     * 评估权益条件（支持 AND/OR 嵌套逻辑）
     */
    private boolean evaluateCondition(EntitlementCondition condition,
                                       EffectiveEntitlementSet entitlements) {
        if ("AND".equals(condition.getLogic())) {
            return condition.getConditions().stream()
                .allMatch(c -> evaluateSingleCondition(c, entitlements));
        } else if ("OR".equals(condition.getLogic())) {
            return condition.getConditions().stream()
                .anyMatch(c -> evaluateSingleCondition(c, entitlements));
        }
        return false;
    }

    /**
     * 评估单个权益条件
     */
    private boolean evaluateSingleCondition(EntitlementCondition c,
                                             EffectiveEntitlementSet entitlements) {
        // 复合条件递归评估
        if (c.getConditions() != null && !c.getConditions().isEmpty()) {
            return evaluateCondition(c, entitlements);
        }

        // 简单权益检查
        EntitlementType type = EntitlementType.valueOf(c.getEntitlementType());
        String scopeKey = c.getConstraints() != null
            ? c.getConstraints().get("scopeKey") : null;

        return entitlements.hasEntitlement(type, scopeKey);
    }

    /**
     * 匹配内容过滤条件
     */
    private boolean matchContentFilter(String filterJson, ContentMetadata content) {
        ContentFilter filter = ContentFilter.fromJson(filterJson);
        if (filter == null) return true; // 无过滤 = 匹配所有

        if (filter.getSubjectCode() != null
            && !filter.getSubjectCode().equals(content.getSubjectCode())) {
            return false;
        }
        if (filter.getAccessLevel() != null
            && filter.getAccessLevel() != content.getAccessLevel()) {
            return false;
        }
        if (filter.getContentType() != null
            && !filter.getContentType().equals(content.getContentType())) {
            return false;
        }
        if (filter.getTextbookVersion() != null
            && !filter.getTextbookVersion().equals(content.getTextbookVer())) {
            return false;
        }
        return true;
    }

    /**
     * 附加规则校验（年龄、家长管控、地区）
     */
    private AccessDecision checkAdditionalRules(DecisionRequest request,
                                                 EffectiveEntitlementSet entitlements) {
        ContentMetadata content = request.getContent();
        DecisionContext ctx = request.getContext();

        // 年龄适宜性检查
        if (content.getMinAge() != null || content.getMaxAge() != null) {
            Integer userAge = ctx.getUserAge();
            if (userAge != null) {
                if (content.getMinAge() != null && userAge < content.getMinAge()) {
                    return AccessDecision.deny("AGE_NOT_SUITABLE",
                        "该内容不适用于当前年龄段");
                }
                if (content.getMaxAge() != null && userAge > content.getMaxAge()) {
                    return AccessDecision.deny("AGE_NOT_SUITABLE",
                        "该内容不适用于当前年龄段");
                }
            }
        }

        // 家长管控检查
        ParentalControl pc = ctx.getParentalControl();
        if (pc != null && pc.isEnabled()) {
            // 检查学科限制
            if (pc.getRestrictedSubjects() != null
                && pc.getRestrictedSubjects().contains(content.getSubjectCode())) {
                return AccessDecision.deny("PARENTAL_RESTRICTED",
                    "家长已限制该学科内容访问");
            }
            // 检查内容类型限制
            if (pc.getRestrictedContentTypes() != null
                && pc.getRestrictedContentTypes().contains(content.getContentType())) {
                return AccessDecision.deny("PARENTAL_RESTRICTED",
                    "家长已限制该类型内容访问");
            }
        }

        // 地区限制检查（如中考真题分省）
        if (content.getRegionCodes() != null && !content.getRegionCodes().isEmpty()) {
            String userRegion = ctx.getUserRegion();
            if (userRegion != null && !content.getRegionCodes().contains(userRegion)) {
                return AccessDecision.deny("REGION_RESTRICTED",
                    "该内容不适用于您所在地区");
            }
        }

        return null; // 所有附加规则通过
    }

    /**
     * 智能推断拒绝原因，提供引导建议
     */
    private DenyReason determineDenyReason(ContentMetadata content,
                                            EffectiveEntitlementSet entitlements) {
        AccessLevel level = AccessLevel.fromValue(content.getAccessLevel());

        switch (level) {
            case MEMBERSHIP:
                if (entitlements.getTier() == UserEntitlementTier.FREE) {
                    return new DenyReason("MEMBERSHIP_REQUIRED",
                        "升级会员即可解锁此内容", "UPGRADE_MEMBERSHIP");
                }
                return new DenyReason("MEMBERSHIP_TIER_INSUFFICIENT",
                    "当前会员等级不包含此内容，请升级至更高级别", "UPGRADE_TIER");

            case ADDON_PURCHASE:
                return new DenyReason("ADDON_REQUIRED",
                    "此内容需单独购买或添加增值服务包", "PURCHASE_ADDON");

            case PREMIUM_COURSE:
                return new DenyReason("COURSE_PURCHASE_REQUIRED",
                    "此精品课程需单独购买", "PURCHASE_COURSE");

            default:
                return new DenyReason("ACCESS_DENIED",
                    "暂无权限访问此内容", null);
        }
    }
}
```

### 6.2 用量计数器（Redis 实现）

```java
/**
 * 基于Redis的用量计数器
 * 使用 Redis INCR + EXPIRE 实现滑动窗口计数
 */
@Service
public class UsageCounter {

    @Resource
    private RedisTemplate<String, String> redisTemplate;

    private static final String KEY_PREFIX = "cade:quota:";
    private static final String CONSUME_LOCK_PREFIX = "cade:quota:lock:";

    /**
     * 检查配额是否可用（不扣减）
     *
     * @return QuotaCheckResult
     */
    public QuotaCheckResult checkQuota(Long userId, String featureType,
                                        QuotaLimit quota) {
        if (quota.isUnlimited()) {
            return QuotaCheckResult.allowed(0, -1);
        }
        if (quota.getLimit() == 0) {
            return QuotaCheckResult.denied("QUOTA_ZERO",
                "当前等级不支持此功能", "UPGRADE_MEMBERSHIP");
        }

        String key = buildQuotaKey(userId, featureType, quota.getPeriod());
        String value = redisTemplate.opsForValue().get(key);
        int used = value != null ? Integer.parseInt(value) : 0;

        if (used >= quota.getLimit()) {
            return QuotaCheckResult.denied("QUOTA_EXCEEDED",
                String.format("今日%s已用完（%d/%d次），明日重置",
                    featureLabel(featureType), used, quota.getLimit()),
                "UPGRADE_MEMBERSHIP");
        }

        return QuotaCheckResult.allowed(used, quota.getLimit());
    }

    /**
     * 扣减配额（原子操作）
     *
     * @return true=扣减成功, false=配额不足
     */
    public boolean consume(Long userId, String featureType,
                           QuotaLimit quota) {
        if (quota.isUnlimited()) return true;

        String key = buildQuotaKey(userId, featureType, quota.getPeriod());
        long ttlSeconds = getPeriodSeconds(quota.getPeriod());

        // Lua 原子脚本：检查并递增
        String luaScript = """
            local current = tonumber(redis.call('GET', KEYS[1]) or '0')
            local limit = tonumber(ARGV[1])
            if current >= limit then
                return 0
            end
            local newVal = redis.call('INCR', KEYS[1])
            if newVal == 1 then
                redis.call('EXPIRE', KEYS[1], ARGV[2])
            end
            return 1
        """;

        Long result = redisTemplate.execute(
            new DefaultRedisScript<>(luaScript, Long.class),
            Collections.singletonList(key),
            String.valueOf(quota.getLimit()),
            String.valueOf(ttlSeconds)
        );

        return result != null && result == 1L;
    }

    /**
     * 回退配额（用于失败补偿）
     */
    public void refund(Long userId, String featureType, QuotaPeriod period) {
        String key = buildQuotaKey(userId, featureType, period);
        redisTemplate.opsForValue().decrement(key);
    }

    /**
     * 获取用户当前用量
     */
    public int getUsage(Long userId, String featureType, QuotaPeriod period) {
        String key = buildQuotaKey(userId, featureType, period);
        String value = redisTemplate.opsForValue().get(key);
        return value != null ? Integer.parseInt(value) : 0;
    }

    private String buildQuotaKey(Long userId, String featureType, QuotaPeriod period) {
        String periodKey = formatPeriodKey(period);
        return KEY_PREFIX + userId + ":" + featureType + ":" + periodKey;
    }

    private String formatPeriodKey(QuotaPeriod period) {
        LocalDate now = LocalDate.now();
        return switch (period) {
            case HOURLY  -> now.toString() + "H" + LocalTime.now().getHour();
            case DAILY   -> now.toString();
            case WEEKLY  -> now + "W" + now.get(WeekFields.ISO.weekOfWeekBasedYear());
            case MONTHLY -> now.getYear() + "-" + now.getMonthValue();
        };
    }

    private long getPeriodSeconds(QuotaPeriod period) {
        return switch (period) {
            case HOURLY  -> 3600L;
            case DAILY   -> 86400L;
            case WEEKLY  -> 604800L;
            case MONTHLY -> 2592000L;
        };
    }

    private String featureLabel(String featureType) {
        return switch (featureType) {
            case "AI_CHAT"       -> "AI对话";
            case "PHOTO_SEARCH"  -> "拍照搜题";
            case "ESSAY_GRADING" -> "作文批改";
            default              -> featureType;
        };
    }
}
```

```java
/**
 * 配额配置管理器
 * 支持从配置中心加载动态配额覆盖
 */
@Service
public class QuotaConfigManager {

    @Resource
    private ConfigCenterService configCenter;

    private static final String CONFIG_PREFIX = "cade.quota.";

    // 配置中心覆盖缓存（本地缓存 30s 刷新一次）
    private final Map<String, QuotaLimit> overrideCache = new ConcurrentHashMap<>();
    private volatile long lastRefreshTime = 0;

    /**
     * 获取有效配额（先查覆盖配置，再查默认值）
     */
    public QuotaLimit getEffectiveQuota(Long userId, UserEntitlementTier tier,
                                         String featureType) {
        refreshIfNeeded();

        // 1. 查用户级覆盖
        String userKey = CONFIG_PREFIX + "user." + userId + "." + featureType;
        QuotaLimit userOverride = overrideCache.get(userKey);
        if (userOverride != null) return userOverride;

        // 2. 查等级覆盖
        String tierKey = CONFIG_PREFIX + "tier." + tier.name() + "." + featureType;
        QuotaLimit tierOverride = overrideCache.get(tierKey);
        if (tierOverride != null) return tierOverride;

        // 3. 查全局覆盖
        String globalKey = CONFIG_PREFIX + "global." + featureType;
        QuotaLimit globalOverride = overrideCache.get(globalKey);
        if (globalOverride != null) return globalOverride;

        // 4. 默认值
        return QuotaConfig.getQuota(tier, featureType);
    }

    private void refreshIfNeeded() {
        if (System.currentTimeMillis() - lastRefreshTime < 30_000) return;
        lastRefreshTime = System.currentTimeMillis();

        List<ConfigItem> items = configCenter.listByPrefix(CONFIG_PREFIX);
        Map<String, QuotaLimit> newCache = new ConcurrentHashMap<>();
        for (ConfigItem item : items) {
            QuotaLimit limit = parseQuotaConfig(item.getValue());
            newCache.put(item.getKey(), limit);
        }
        overrideCache.clear();
        overrideCache.putAll(newCache);
    }
}
```

### 7.3 注解式拦截器（AOP）

为业务代码提供声明式访问控制，减少侵入性。

```java
/**
 * @RequireEntitlement 注解
 * 用于业务方法上，声明所需权益
 */
@Target({ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
public @interface RequireEntitlement {
    /** 功能类型 */
    String featureType();

    /** 所需权益类型（默认会员） */
    EntitlementType[] value() default {EntitlementType.FULL_CONTENT_ACCESS};

    /** 逻辑关系 */
    Logic logic() default Logic.OR;

    /** 是否消耗配额 */
    boolean consume() default true;

    enum Logic { AND, OR }
}

/**
 * 拦截器实现
 */
@Aspect
@Component
public class EntitlementAspect {

    @Resource
    private CadeClient cadeClient;

    @Resource
    private RequestContextService requestContextService;

    @Around("@annotation(requireEntitlement)")
    public Object checkEntitlement(ProceedingJoinPoint pjp,
                                    RequireEntitlement requireEntitlement) throws Throwable {
        Long userId = requestContextService.getCurrentUserId();
        DecisionContext ctx = requestContextService.buildContext();

        // 1. 查询配额
        Result<QuotaInfo> quotaResult = cadeClient.getQuota(
            userId, requireEntitlement.featureType()
        );
        QuotaInfo quota = quotaResult.getData();

        if (quota.getRemaining() == 0 && quota.getLimit() != -1) {
            throw new AccessDeniedException(
                "QUOTA_EXCEEDED",
                String.format("今日%s已用完", quota.getFeatureType()),
                "UPGRADE_MEMBERSHIP"
            );
        }

        // 2. 执行业务方法
        try {
            Object result = pjp.proceed();

            // 3. 成功后消费配额
            if (requireEntitlement.consume()) {
                cadeClient.consumeQuota(new ConsumeRequest(
                    userId, requireEntitlement.featureType(),
                    requestContextService.getTraceId()
                ));
            }

            return result;
        } catch (Exception e) {
            // 业务失败不扣配额（配额在成功后才消费）
            throw e;
        }
    }
}
```

## 9. 决策缓存策略

### 9.1 多级缓存架构

```
请求 →  L1 本地缓存    →  L2 Redis缓存    →  计算引擎
         (Caffeine)       (Redis Cluster)
         TTL: 30s          TTL: 5min
```

### 9.2 缓存键设计

| 缓存类型 | Key 格式 | TTL | 说明 |
|---------|----------|-----|------|
| 权益缓存 | `cade:ent:{userId}` | 5min | 用户有效权益聚合集 |
| 决策缓存 | `cade:dec:{userId}:{contentId}:{action}` | 30s | 单次决策结果 |
| 配额计数 | `cade:quota:{userId}:{feature}:{periodKey}` | 按周期 | 用量计数 |
| 内容元数据 | `cade:meta:{contentId}` | 10min | 内容访问控制属性 |

### 9.3 缓存失效策略

```java
/**
 * 缓存失效管理器
 */
@Service
public class CacheInvalidationManager {

    @Resource
    private RedisTemplate<String, String> redisTemplate;

    @Resource
    private CacheManager cacheManager; // Caffeine

    /**
     * 权益变更时，级联失效所有相关缓存
     */
    public void invalidateOnEntitlementChange(Long userId) {
        // 1. 失效权益缓存
        redisTemplate.delete("cade:ent:" + userId);

        // 2. 失效该用户的所有决策缓存
        Set<String> decisionKeys = redisTemplate.keys("cade:dec:" + userId + ":*");
        if (decisionKeys != null && !decisionKeys.isEmpty()) {
            redisTemplate.delete(decisionKeys);
        }

        // 3. 清除本地 L1 缓存
        cacheManager.getCache("decisions").evictIfPresent(userId);
    }

    /**
     * 内容策略变更时，失效所有相关决策缓存
     * 注意：这是全量失效（因为策略变更可能影响大量用户）
     */
    public void invalidateOnPolicyChange(String contentType) {
        // 按内容类型批量清除
        Set<String> keys = redisTemplate.keys("cade:dec:*");
        if (keys != null) {
            redisTemplate.delete(keys);
        }
        // 清除本地缓存
        cacheManager.getCache("decisions").clear();
    }
}
```

## 10. 错误处理与降级策略

### 10.1 降级矩阵

| 故障场景 | 降级策略 | 行为 |
|---------|----------|------|
| Redis 全部不可用 | **Fail-Open for Free, Fail-Closed for Paid** | 免费内容放行，付费内容基于 MySQL 快照做降级决策 |
| MySQL 快照表不可用 | **Fail-Closed** | 拒绝所有非免费内容访问，返回「系统繁忙，请稍后重试」 |
| 支付/订阅 RPC 不可用 | **降级使用快照** | 使用上次成功的权益快照，不做实时同步 |
| Kafka 事件延迟 | **最终一致** | 用户权益变更可能有最多 5min 延迟（缓存 TTL），但不会丢失 |
| CADE 服务整体不可用 | **BFF 层降级** | API 网关配置兜底规则：免费内容放行，付费内容返回友好降级提示 |

### 10.3 降级处理器实现

```java
/**
 * 降级决策器
 * 在依赖组件不可用时提供兜底决策
 */
@Service
public class FallbackDecisionProvider {

    @Resource
    private EntitlementSnapshotMapper snapshotMapper;

    /**
     * Redis 不可用时的降级决策
     */
    public AccessDecision fallbackDecision(Long userId, ContentMetadata content,
                                            DecisionContext ctx) {
        // 免费内容始终放行
        if (content.getAccessLevel() == AccessLevel.FREE.getValue()) {
            return AccessDecision.allow("fallback_free_pass");
        }

        // 付费内容：尝试从 DB 查询权益
        try {
            List<EntitlementSnapshot> snapshots = snapshotMapper.selectActiveByUserId(
                userId, LocalDateTime.now()
            );

            boolean hasAnyEntitlement = snapshots.stream()
                .anyMatch(s -> s.getStatus() == EntitlementStatus.ACTIVE.getValue());

            if (hasAnyEntitlement) {
                // 有权益记录，宽松放行（降级期间宁可放行也不阻断付费用户）
                log.warn("Fallback decision: allowed via DB snapshot for user {}", userId);
                return AccessDecision.allow("fallback_db_snapshot");
            }

            // 无权益记录，拒绝
            return AccessDecision.deny("MEMBERSHIP_REQUIRED",
                "升级会员即可解锁此内容", "UPGRADE_MEMBERSHIP");

        } catch (Exception e) {
            // DB 也不可用，Fail-Closed
            log.error("Fallback decision: DB also unavailable, denying paid content", e);
            return AccessDecision.deny("SYSTEM_ERROR",
                "系统繁忙，请稍后重试", null);
        }
    }
}
```

## 11. 家庭套餐权益处理

### 11.1 家庭套餐权益传播

PrimeTop 支持家庭套餐，一个主账号购买后，绑定的子账号共享权益。CADE 需要处理权益传播。

```java
/**
 * 家庭权益传播处理器
 */
@Service
public class FamilyEntitlementPropagator {

    @Resource
    private FamilyMemberRpcService familyMemberRpcService;

    /**
     * 获取用户有效权益（含家庭套餐传播）
     */
    public List<EntitlementSnapshot> enrichWithFamilyEntitlements(
            Long userId, List<EntitlementSnapshot> personalSnapshots) {

        // 检查用户是否为家庭套餐子账号
        FamilyMemberRelation relation = familyMemberRpcService.getRelation(userId);

        if (relation != null && relation.isChild()) {
            Long parentUserId = relation.getParentUserId();

            // 获取父账号的 FAMILY_PLAN 类型权益
            List<EntitlementSnapshot> parentSnapshots = snapshotMapper.selectByUserIdAndSource(
                parentUserId, EntitlementSource.FAMILY_PLAN.name()
            );

            // 将父账号权益传播给子账号（标记来源为 FAMILY_PLAN）
            List<EntitlementSnapshot> propagated = parentSnapshots.stream()
                .filter(s -> s.getStatus() == EntitlementStatus.ACTIVE.getValue())
                .map(s -> EntitlementSnapshot.builder()
                    .userId(userId)
                    .sourceType(EntitlementSource.FAMILY_PLAN.name())
                    .sourceRefId(s.getSourceRefId())
                    .entitlementType(s.getEntitlementType())
                    .scopeKey(s.getScopeKey())
                    .grantedAt(s.getGrantedAt())
                    .effectiveFrom(s.getEffectiveFrom())
                    .effectiveUntil(s.getEffectiveUntil())
                    .status(EntitlementStatus.ACTIVE.getValue())
                    .metadata(JsonUtil.toJson(Map.of(
                        "propagatedFrom", parentUserId,
                        "originalSourceRef", s.getSourceRefId()
                    )))
                    .build())
                .collect(Collectors.toList());

            // 合并个人权益和传播权益
            List<EntitlementSnapshot> merged = new ArrayList<>(personalSnapshots);
            merged.addAll(propagated);
            return merged;
        }

        return personalSnapshots;
    }
}
```

## 14. 安全与审计

### 14.1 安全要求

| 安全要求 | 实现方式 |
|---------|---------|
| 防绕过 | 所有内容接口必须经过 CADE 决策（通过 AOP 注解强制） |
| 防篡改 | 配额消费使用 Redis Lua 原子脚本，防止并发超扣 |
| 审计追溯 | 每次决策记录审计日志，含完整决策链路 |
| 防刷 | 决策接口本身受 API 网关限流保护 |
| 权益防伪造 | 权益数据仅来自支付系统 Kafka 事件，不接受客户端传入 |

### 14.2 审计日志归档

```java
/**
 * 决策日志异步写入（不影响主流程性能）
 */
@Service
public class DecisionLogWriter {

    @Resource
    private DecisionLogMapper logMapper;

    private final ExecutorService logExecutor = Executors.newFixedThreadPool(2);

    /**
     * 异步记录决策日志
     */
    public void logAsync(AccessDecision decision, DecisionRequest request) {
        logExecutor.submit(() -> {
            try {
                DecisionLog log = DecisionLog.builder()
                    .traceId(request.getContext().getTraceId())
                    .userId(request.getUserId())
                    .contentId(request.getContentId())
                    .contentType(request.getContentType())
                    .action(request.getAction())
                    .decision(decision.getDecision().name())
                    .denyReason(decision.getDenyReasonCode())
                    .denyMessage(decision.getDenyMessage())
                    .matchedPolicy(decision.getMatchedPolicy())
                    .costMs(decision.getCostMs())
                    .cacheHit(decision.isCacheHit() ? 1 : 0)
                    .build();
                logMapper.insert(log);
            } catch (Exception e) {
                // 日志写入失败不影响主流程，仅记录错误
                DecisionLogWriter.log.error("Failed to write decision log", e);
            }
        });
    }
}
```

## 16. 接入指南

### 16.1 新内容接入

当运营/教研团队发布新内容时，需配置该内容的访问控制属性：

```java
/**
 * 内容发布时注册到 CADE
 */
@Service
public class ContentRegistrationService {

    @Resource
    private ContentMetadataMapper metadataMapper;

    /**
     * 内容发布时调用，注册访问控制元数据
     */
    public void registerContent(ContentPublishEvent event) {
        ContentMetadata metadata = ContentMetadata.builder()
            .contentId(event.getContentId())
            .contentType(event.getContentType())
            .subjectCode(event.getSubjectCode())
            .gradeCode(event.getGradeCode())
            .textbookVer(event.getTextbookVersion())
            .chapterCodes(event.getChapterCodes())
            .accessLevel(determineAccessLevel(event)) // 由运营在发布时配置
            .minAge(event.getMinAge())
            .maxAge(event.getMaxAge())
            .isExamContent(event.isExamContent())
            .regionCodes(event.getRegionCodes())
            .status(ContentStatus.AVAILABLE.getValue())
            .build();

        metadataMapper.upsert(metadata);
    }
}
```
