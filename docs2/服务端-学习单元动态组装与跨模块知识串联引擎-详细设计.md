# 学习单元动态组装与跨模块知识串联引擎 — 详细设计

> **文档版本**: v1.0
> **创建日期**: 2026-06-19
> **所属模块**: 学习服务 / 自适应学习
> **关联模块**: 同步课堂、题库、错题本、AI智能辅导、知识点体系、多媒体资源

---

## 1. 概述

### 1.1 设计目标

为学生提供"一站式"个性化学习体验：当学生想学某个知识点时，系统自动从题库、知识库、教材内容、错题本、AI生成、多媒体资源等多个模块中拉取最佳内容，动态组装为一个**结构完整、难度递进、上下文连贯的学习单元（Learning Unit）**，让学生在一个流畅的会话中完成"诊断 → 学习 → 练习 → 纠错 → 总结"全闭环。

### 1.2 与现有模块的边界

| 现有模块/文档 | 定位 | 本引擎差异 |
|---|---|---|
| 同步课堂章节内容聚合 | 按教材章节**静态组织**内容流 | 本引擎是**跨模块动态组装**，不限于教材顺序 |
| 自适应学习与个性化推荐 | 推荐算法与候选集生成 | 本引擎消费推荐结果并**装配为可执行学习流** |
| 学习会话编排与上下文管理 | 管理会话生命周期与上下文传递 | 本引擎产出会话的**内容蓝图** |
| 多源学习任务统一调度 | 任务级优先级仲裁 | 本引擎产出的是**知识点级学习内容包** |

### 1.3 核心价值

- 打破模块孤岛：学生不再需要手动在"同步课堂""错题本""题库"之间切换
- 按需组装：根据学生当前掌握度、学习目标、可用时间，生成最适合的学习路径
- 知识串联：自动建立前置知识回顾 → 核心学习 → 巩固练习 → 拓展提升的完整链路

## 2. 核心概念定义

### 2.1 学习单元（Learning Unit）

一个学习单元是一次完整的知识学习会话，包含 5~8 个有序的教学步骤：

```
┌─────────────────────────────────────────────────────────────────┐
│                     Learning Unit 结构                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐        │
│  │ Step 1  │→ │  Step 2  │→ │  Step 3  │→ │  Step 4  │ → ...  │
│  │ 前置诊断 │  │ 知识讲解 │  │ 典型例题 │  │ 巩固练习 │        │
│  └─────────┘  └──────────┘  └──────────┘  └──────────┘        │
│                                                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                     │
│  │  Step 5  │→ │  Step 6  │→ │  Step 7  │                     │
│  │ 易错警示 │  │ 拓展提升 │  │ 学习总结 │                     │
│  └──────────┘  └──────────┘  └──────────┘                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 教学步骤类型

| StepType | 中文名 | 说明 | 内容来源 |
|---|---|---|---|
| `DIAGNOSE` | 前置诊断 | 1~3道快速测试题，评估当前掌握度 | 题库 |
| `REVIEW` | 旧知回顾 | 回顾前置知识点，激活已有认知 | 知识库 + 教材内容 |
| `EXPLAIN` | 知识讲解 | 核心概念/公式/原理讲解 | 知识库 + AI生成 |
| `EXAMPLE` | 典型例题 | 带完整解析的示范题目 | 题库 + AI生成 |
| `PRACTICE` | 巩固练习 | 交互式练习题，即时反馈 | 题库 |
| `MISTAKE_ALERT` | 易错警示 | 常见错误展示与分析 | 错题本(聚合) + AI |
| `CHALLENGE` | 拓展提升 | 高难度题目/实际应用场景 | 题库 + AI生成 |
| `SUMMARY` | 学习总结 | 知识要点归纳 + 思维导图 | AI生成 |

## 3. 数据结构定义

### 3.1 LearningUnit（学习单元）

```typescript
interface LearningUnit {
  /** 学习单元唯一ID */
  unitId: string;                    // UUID v4
  /** 关联的学习会话ID */
  sessionId: string;
  /** 学生用户ID */
  studentId: number;
  /** 目标知识点ID */
  knowledgePointId: string;          // e.g., "KP_MATH_G8_QUADRATIC"
  /** 学科 */
  subject: Subject;                  // MATH | CHINESE | ENGLISH | ...
  /** 学段年级 */
  gradeLevel: GradeLevel;            // G7 | G8 | G9 | ...
  /** 教材版本 */
  textbookVersion: string;           // PEP_2024 | SUJIAO_2024 | ...
  /** 组装时间戳 */
  assembledAt: number;               // Unix ms
  /** 学习单元状态 */
  status: LearningUnitStatus;        // ASSEMBLED | IN_PROGRESS | COMPLETED | ABANDONED
  /** 教学步骤列表 */
  steps: LearningStep[];
  /** 组装元数据 */
  assemblyMeta: AssemblyMeta;
  /** 预计完成时长(分钟) */
  estimatedDurationMin: number;
  /** 难度目标(0~1, 0最易 1最难) */
  targetDifficulty: number;
  /** 学生当前掌握度快照 */
  masterySnapshot: number;           // 0~1
}

type Subject = 'MATH' | 'CHINESE' | 'ENGLISH' | 'PHYSICS' | 'CHEMISTRY' | 'BIOLOGY' | 'HISTORY' | 'GEOGRAPHY' | 'POLITICS';
type GradeLevel = 'K3' | 'K4' | 'K5' | 'K6' | 'G1' | 'G2' | ... | 'G12';
type LearningUnitStatus = 'ASSEMBLED' | 'IN_PROGRESS' | 'COMPLETED' | 'ABANDONED' | 'EXPIRED';
```

### 3.2 LearningStep（教学步骤）

```typescript

type StepType = 'DIAGNOSE' | 'REVIEW' | 'EXPLAIN' | 'EXAMPLE' | 'PRACTICE' | 'MISTAKE_ALERT' | 'CHALLENGE' | 'SUMMARY';

```

### 3.3 ContentRef（内容引用）

### 3.4 AssemblyMeta（组装元数据）

```typescript
interface AssemblyMeta {
  /** 组装策略 */
  strategy: AssemblyStrategy;        // FULL_UNIT | QUICK_REVIEW | REMEDIAL | EXAM_PREP | CUSTOM

type AssemblyStrategy = 'FULL_UNIT' | 'QUICK_REVIEW' | 'REMEDIAL' | 'EXAM_PREP' | 'CUSTOM';

```

### 3.5 CompletionCriteria & StepResult

```typescript
interface CompletionCriteria {
  /** 完成类型 */
  type: 'ANSWER_COUNT' | 'CORRECT_RATE' | 'TIME_SPENT' | 'VIEW_COMPLETED' | 'MANUAL';
  /** 阈值 */
  threshold: number;
  /** 最小正确率要求(练习类步骤) */
  minCorrectRate?: number;           // 0~1
}

interface StepResult {
  /** 答题结果(练习/诊断类) */
  answerResults?: {
    total: number;
    correct: number;
    wrong: number;
    avgTimeSec: number;
    /** 各题详细记录ID */
    records: string[];
  };
  /** 掌握度变化 */
  masteryDelta?: number;             // 正数=提升, 负数=下降
  /** 学生反馈 */
  feedback?: 'TOO_EASY' | 'JUST_RIGHT' | 'TOO_HARD';
  /** 完成时间戳 */
  completedAt: number;
}
```

## 5. 内容选取与编排算法

### 5.1 内容选取流程

```
输入: knowledgePointId, studentId, strategy, availableTimeMin
  │
  ▼
┌─────────────────────────────────────────┐
│ Phase 1: 知识图谱查询                    │
│ • 查询 KP 的前置知识点 (prerequisites)   │
│ • 查询 KP 的子知识点 (subPoints)         │
│ • 查询 KP 的关联知识点 (relatedPoints)   │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│ Phase 2: 并行内容检索                    │
│ • 题库: 按KP+难度+题型检索候选题          │
│ • 知识库: 按KP检索讲解/总结              │
│ • 教材: 按KP检索章节内容                  │
│ • 错题本: 查询学生该KP的历史错题          │
│ • 聚合错题: 查询全局该KP的高频错误        │
│ • 多媒体: 按KP检索视频/图片               │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│ Phase 3: 内容打分与排序                  │
│ • 对每个候选项计算 relevance_score       │
│ • 考虑: 难度匹配度、学生偏好、内容质量   │
│ • 考虑: 去重(避免与近期学过内容重复)     │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│ Phase 4: 步骤装配                        │
│ • 按策略模板填入内容                     │
│ • 时间预算分配                           │
│ • 生成备选内容(fallback)                 │
└──────────────────┬──────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────┐
│ Phase 5: AI增强(可选)                    │
│ • 缺失内容由AI生成补充                   │
│ • 生成学习总结                           │
│ • 生成易错分析                           │
└─────────────────────────────────────────┘
```

### 5.2 内容相关性评分模型

```java
/**
 * 计算单个内容项的综合匹配分数
 * 
 * @param content    候选内容
 * @param context    组装上下文(学生画像、目标KP、策略)
 * @return           匹配分数 [0, 1]
 */
public double calculateRelevanceScore(ContentItem content, AssemblyContext context) {
    // 1. 难度匹配度 (权重 0.30)
    double difficultyScore = calculateDifficultyMatch(
        content.getDifficulty(), 
        context.getTargetDifficulty(),
        context.getMasteryLevel()
    );
    
    // 2. 知识点覆盖度 (权重 0.25)
    double coverageScore = calculateKnowledgeCoverage(
        content.getKnowledgePointIds(),
        context.getTargetKnowledgePointId(),
        context.getWeakSubPoints()
    );
    
    // 3. 新鲜度惩罚 (权重 0.15)
    // 避免推送学生近期已做过的内容
    double freshnessScore = calculateFreshness(
        content.getContentId(),
        context.getStudentId(),
        recentWindowDays: 14
    );
    
    // 4. 内容质量分 (权重 0.15)
    double qualityScore = content.getQualityRating(); // 来自内容质量评估系统
    
    // 5. 学习风格匹配 (权重 0.10)
    double styleScore = calculateStyleMatch(
        content.getContentType(),  // VIDEO vs TEXT vs INTERACTIVE
        context.getLearningStyle() // VISUAL | AUDITORY | ...
    );
    
    // 6. 时长适配 (权重 0.05)
    double timeFitScore = calculateTimeFit(
        content.getEstimatedDurationSec(),
        context.getStepTimeBudgetSec()
    );
    
    return 0.30 * difficultyScore 
         + 0.25 * coverageScore 
         + 0.15 * freshnessScore 
         + 0.15 * qualityScore 
         + 0.10 * styleScore 
         + 0.05 * timeFitScore;
}
```

**难度匹配度公式：**

```
difficultyScore = 1.0 - |content.difficulty - targetDifficulty|
```

其中 `targetDifficulty` 由学生掌握度和策略共同决定：

```
targetDifficulty = masteryLevel + strategyOffset

strategyOffset:
  REMEDIAL:      -0.15  (略低于当前水平，建立信心)
  FULL_UNIT:     +0.05  (略高于当前水平，舒适区边缘)
  QUICK_REVIEW:  +0.10  (略高，查漏补缺)
  EXAM_PREP:     +0.20  (显著高于，冲刺拔高)

最终值 clamp 到 [0.1, 0.95]
```

## 6. API 接口设计

### 6.1 组装学习单元

```
POST /api/v1/learning-units/assemble
```

**请求体：**
```json
{
  "knowledgePointId": "KP_MATH_G8_QUADRATIC_EQUATION",
  "strategy": "AUTO",
  "availableTimeMin": 30,
  "trigger": "MANUAL",
  "context": {
    "sessionId": "sess_abc123",
    "textbookVersion": "PEP_2024"
  }
}
```

> `strategy: "AUTO"` 表示由系统根据掌握度自动选择策略。
> 也可指定 `FULL_UNIT` | `QUICK_REVIEW` | `REMEDIAL` | `EXAM_PREP` 强制使用。

### 7.3 动态调整触发条件

| 触发条件 | 阈值 | 调整动作 |
|---|---|---|
| 诊断全错 | correctRate = 0 | 在 EXPLAIN 前插入 REVIEW 步骤 |

### 8.3 AI内容兜底策略

```java
/**
 * 获取步骤内容，优先使用题库/知识库已有内容，
 * 当已有内容不足时通过AI生成补充
 */
public List<ContentItem> resolveStepContents(LearningStep step, AssemblyContext ctx) {
    List<ContentItem> contents = new ArrayList<>();
    
    // Phase 1: 从已注册来源获取
    for (ContentRef ref : step.getContentRefs()) {
        if (ref.getSource() == ContentSource.AI_GENERATED) {
            continue; // AI生成的内容稍后处理
        }
        ContentItem item = contentFetcher.fetch(ref);
        if (item != null && item.isAvailable()) {
            contents.add(item);
        } else if (ref.getFallbackContentIds() != null) {
            // 尝试备选内容
            for (String fallbackId : ref.getFallbackContentIds()) {
                ContentItem fallback = contentFetcher.fetchById(fallbackId);
                if (fallback != null && fallback.isAvailable()) {
                    contents.add(fallback);
                    break;
                }
            }
        }
    }
    
    // Phase 2: 处理AI生成内容
    List<ContentRef> aiRefs = step.getContentRefs().stream()
        .filter(r -> r.getSource() == ContentSource.AI_GENERATED)
        .collect(Collectors.toList());
    
    if (!aiRefs.isEmpty()) {
        // 检查缓存：相同上下文是否已有生成结果
        String cacheKey = buildAICacheKey(step, ctx);
        ContentItem cached = aiContentCache.get(cacheKey);
        
        if (cached != null) {
            contents.add(cached);
        } else {
            try {
                ContentItem generated = aiContentGenerator.generate(step, ctx);
                aiContentCache.put(cacheKey, generated, ttl: Duration.ofHours(24));
                contents.add(generated);
            } catch (AIGenerationException e) {
                log.warn("AI内容生成失败，使用静态兜底内容 step={}", step.getOrder(), e);
                ContentItem fallback = staticFallbackProvider.getFallback(step.getStepType(), ctx);
                contents.add(fallback);
            }
        }
    }
    
    return contents;
}
```

## 9. 关键代码实现

### 9.1 组装引擎核心类

```java
/**
 * 学习单元组装引擎
 * <p>
 * 负责根据学生画像、知识点信息和学习策略，
 * 从多个内容模块中选取最佳内容，组装为个性化学习单元。
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class LearningUnitAssemblyEngine {

    private final KnowledgeGraphService knowledgeGraphService;
    private final QuestionBankService questionBankService;
    private final KnowledgeBaseService knowledgeBaseService;
    private final ErrorBookService errorBookService;
    private final MediaLibraryService mediaLibraryService;
    private final AIContentGenerator aiContentGenerator;
    private final StudentProfileService studentProfileService;
    private final LearningUnitRepository unitRepository;
    private final RedisTemplate<String, Object> redisTemplate;

    /** 最近学习内容去重窗口(天) */
    private static final int FRESHNESS_WINDOW_DAYS = 14;
    /** 单次组装超时(ms) */
    private static final long ASSEMBLY_TIMEOUT_MS = 3000;

    /**
     * 组装学习单元
     */
    @Timed(value = "learning.unit.assembly", description = "学习单元组装耗时")
    public LearningUnit assemble(AssemblyRequest request) {
        long startTime = System.currentTimeMillis();
        
        // 1. 加载学生画像与知识点信息
        StudentProfile profile = studentProfileService.getProfile(request.getStudentId());
        KnowledgePoint kp = knowledgeGraphService.getKnowledgePoint(request.getKnowledgePointId());
        double mastery = knowledgeGraphService.getMastery(request.getStudentId(), request.getKnowledgePointId());
        
        // 2. 确定组装策略
        AssemblyStrategy strategy = resolveStrategy(request, mastery);
        log.info("组装学习单元 studentId={} kp={} mastery={} strategy={}", 
            request.getStudentId(), kp.getName(), mastery, strategy);
        
        // 3. 获取策略模板
        StrategyTemplate template = StrategyTemplateFactory.getTemplate(strategy);
        
        // 4. 计算目标难度
        double targetDifficulty = calculateTargetDifficulty(mastery, strategy);
        
        // 5. 并行检索各模块内容
        AssemblyContext context = AssemblyContext.builder()
            .studentId(request.getStudentId())
            .studentProfile(profile)
            .knowledgePoint(kp)
            .masteryLevel(mastery)
            .targetDifficulty(targetDifficulty)
            .availableTimeMin(request.getAvailableTimeMin())
            .textbookVersion(request.getTextbookVersion())
            .build();
        
        Map<ContentSource, List<ContentItem>> contentPool = fetchContentParallel(context);
        
        // 6. 按步骤模板装配内容
        List<LearningStep> steps = assembleSteps(template, context, contentPool);
        
        // 7. 组装完成，持久化
        LearningUnit unit = LearningUnit.builder()
            .unitId(IdGenerator.uuid())
            .sessionId(request.getSessionId())
            .studentId(request.getStudentId())
            .knowledgePointId(request.getKnowledgePointId())
            .subject(kp.getSubject())
            .gradeLevel(profile.getGradeLevel())
            .textbookVersion(request.getTextbookVersion())
            .status(LearningUnitStatus.ASSEMBLED)
            .steps(steps)
            .targetDifficulty(targetDifficulty)
            .masterySnapshot(mastery)
            .estimatedDurationMin(calculateEstimatedDuration(steps))
            .assemblyMeta(buildMeta(strategy, request, contentPool, startTime))
            .build();
        
        unitRepository.save(unit);
        
        // 缓存到Redis，便于会话内快速访问
        redisTemplate.opsForValue().set(
            "learning_unit:" + unit.getUnitId(),
            unit,
            Duration.ofHours(6)
        );
        
        return unit;
    }

    /**
     * 根据掌握度自动选择策略
     */
    private AssemblyStrategy resolveStrategy(AssemblyRequest request, double mastery) {
        if (request.getStrategy() != AssemblyStrategy.AUTO) {
            return request.getStrategy(); // 学生/系统显式指定
        }
        if (mastery < 0.2) return AssemblyStrategy.REMEDIAL;
        if (mastery < 0.5) return AssemblyStrategy.FULL_UNIT;
        if (mastery < 0.8) return AssemblyStrategy.QUICK_REVIEW;
        return AssemblyStrategy.EXAM_PREP;
    }

    /**
     * 并行检索各内容模块
     */
    @Async
    private Map<ContentSource, List<ContentItem>> fetchContentParallel(AssemblyContext ctx) {
        CompletableFuture<List<ContentItem>> questions = CompletableFuture.supplyAsync(() ->
            questionBankService.searchQuestions(QuestionSearchQuery.builder()
                .knowledgePointId(ctx.getKnowledgePoint().getId())
                .subject(ctx.getKnowledgePoint().getSubject())
                .gradeLevel(ctx.getStudentProfile().getGradeLevel())
                .textbookVersion(ctx.getTextbookVersion())
                .difficultyRange(ctx.getTargetDifficulty() - 0.2, ctx.getTargetDifficulty() + 0.2)
                .excludeRecentDays(FRESHNESS_WINDOW_DAYS)
                .limit(30)
                .build())
        );
        
        CompletableFuture<List<ContentItem>> explanations = CompletableFuture.supplyAsync(() ->
            knowledgeBaseService.searchExplanations(
                ctx.getKnowledgePoint().getId(),
                ctx.getTextbookVersion(),
                ctx.getStudentProfile().getGradeLevel(),
                5
            )
        );
        
        CompletableFuture<List<ContentItem>> errorPatterns = CompletableFuture.supplyAsync(() ->
            errorBookService.getAggregateErrors(
                ctx.getKnowledgePoint().getId(),
                ctx.getStudentId(),
                10
            )
        );
        
        CompletableFuture<List<ContentItem>> mediaAssets = CompletableFuture.supplyAsync(() ->
            mediaLibraryService.searchByKnowledgePoint(
                ctx.getKnowledgePoint().getId(),
                MediaType.IMAGE | MediaType.VIDEO,
                5
            )
        );
        
        // 等待全部完成(带超时)
        try {
            CompletableFuture.allOf(questions, explanations, errorPatterns, mediaAssets)
                .get(ASSEMBLY_TIMEOUT_MS, TimeUnit.MILLISECONDS);
        } catch (TimeoutException e) {
            log.warn("内容检索超时，使用已返回结果 kp={}", ctx.getKnowledgePoint().getId());
            // 超时后继续使用已完成的结果
        } catch (Exception e) {
            log.error("内容检索异常", e);
        }
        
        Map<ContentSource, List<ContentItem>> pool = new EnumMap<>(ContentSource.class);
        pool.put(ContentSource.QUESTION_BANK, safeGet(questions));
        pool.put(ContentSource.KNOWLEDGE_BASE, safeGet(explanations));
        pool.put(ContentSource.ERROR_BOOK, safeGet(errorPatterns));
        pool.put(ContentSource.MEDIA_LIBRARY, safeGet(mediaAssets));
        return pool;
    }

    /**
     * 按步骤模板装配内容
     */
    private List<LearningStep> assembleSteps(
            StrategyTemplate template,
            AssemblyContext ctx,
            Map<ContentSource, List<ContentItem>> contentPool) {
        
        List<LearningStep> steps = new ArrayList<>();
        List<StepTemplate> stepTemplates = template.getSteps();
        
        // 根据可用时间裁剪/合并步骤
        stepTemplates = adaptToTimeBudget(stepTemplates, ctx.getAvailableTimeMin());
        
        for (int i = 0; i < stepTemplates.size(); i++) {
            StepTemplate st = stepTemplates.get(i);
            
            // 从内容池中选取该步骤的最佳内容
            List<ContentRef> contentRefs = selectContentsForStep(st, ctx, contentPool);
            
            LearningStep step = LearningStep.builder()
                .order(i + 1)
                .stepType(st.getType())
                .title(generateStepTitle(st, ctx))
                .status(StepStatus.PENDING)
                .contentRefs(contentRefs)
                .config(st.getConfig())
                .completionCriteria(st.getCompletionCriteria())
                .build();
            
            steps.add(step);
        }
        
        return steps;
    }

    /**
     * 为单个步骤选取内容
     */
    private List<ContentRef> selectContentsForStep(
            StepTemplate stepTemplate,
            AssemblyContext ctx,
            Map<ContentSource, List<ContentItem>> contentPool) {
        
        List<ContentRef> refs = new ArrayList<>();
        
        switch (stepTemplate.getType()) {
            case DIAGNOSE:
            case PRACTICE:
            case CHALLENGE:
            case EXAMPLE:
                // 题目类步骤：从题库选取
                List<ContentItem> questions = contentPool.getOrDefault(
                    ContentSource.QUESTION_BANK, Collections.emptyList()
                );
                List<ContentItem> selected = questions.stream()
                    .filter(q -> matchesStepDifficulty(q, stepTemplate, ctx))
                    .sorted(Comparator.comparingDouble(
                        q -> -calculateRelevanceScore(q, ctx) // 降序，最高分在前
                    ))
                    .limit(stepTemplate.getContentCount())
                    .collect(Collectors.toList());
                
                if (selected.size() < stepTemplate.getMinContentCount()) {
                    // 题库内容不足，标记需要AI生成
                    selected = ensureWithAIFallback(selected, stepTemplate, ctx);
                }
                
                for (int i = 0; i < selected.size(); i++) {
                    ContentItem item = selected.get(i);
                    refs.add(ContentRef.builder()
                        .source(item.getSource())
                        .contentType(ContentType.QUESTION)
                        .contentId(item.getContentId())
                        .priority(i + 1)
                        .build());
                }
                break;
                
            case EXPLAIN:
            case REVIEW:
                // 讲解类步骤：优先知识库，其次教材，最后AI
                List<ContentItem> explanations = contentPool.getOrDefault(
                    ContentSource.KNOWLEDGE_BASE, Collections.emptyList()
                );
                if (!explanations.isEmpty()) {
                    ContentItem best = explanations.get(0);
                    refs.add(ContentRef.builder()
                        .source(ContentSource.KNOWLEDGE_BASE)
                        .contentType(ContentType.EXPLANATION)
                        .contentId(best.getContentId())
                        .priority(1)
                        .build());
                }
                // 补充媒体资源
                List<ContentItem> media = contentPool.getOrDefault(
                    ContentSource.MEDIA_LIBRARY, Collections.emptyList()
                );
                if (!media.isEmpty()) {
                    refs.add(ContentRef.builder()
                        .source(ContentSource.MEDIA_LIBRARY)
                        .contentType(ContentType.IMAGE)
                        .contentId(media.get(0).getContentId())
                        .priority(2)
                        .build());
                }
                // 兜底：AI生成
                if (refs.isEmpty()) {
                    refs.add(ContentRef.builder()
                        .source(ContentSource.AI_GENERATED)
                        .contentType(ContentType.EXPLANATION)
                        .contentId("ai_generated_placeholder")
                        .priority(1)
                        .build());
                }
                break;
                
            case MISTAKE_ALERT:
                // 易错分析：基于错题本聚合数据，AI生成
                refs.add(ContentRef.builder()
                    .source(ContentSource.AI_GENERATED)
                    .contentType(ContentType.EXPLANATION)
                    .contentId("ai_generated_placeholder")
                    .priority(1)
                    .build());
                break;
                
            case SUMMARY:
                // 学习总结：AI生成
                refs.add(ContentRef.builder()
                    .source(ContentSource.AI_GENERATED)
                    .contentType(ContentType.SUMMARY)
                    .contentId("ai_generated_placeholder")
                    .priority(1)
                    .build());
                break;
        }
        
        return refs;
    }

    /**
     * 根据可用时间预算适配步骤模板
     */
    private List<StepTemplate> adaptToTimeBudget(List<StepTemplate> templates, int availableMin) {
        int totalEstimate = templates.stream()
            .mapToInt(StepTemplate::getTimeBudgetMin)
            .sum();
        
        if (totalEstimate <= availableMin) {
            return templates; // 时间充足
        }
        
        // 时间不够：按优先级裁剪
        // 保留优先级：EXPLAIN > PRACTICE > EXAMPLE > DIAGNOSE > MISTAKE_ALERT > CHALLENGE > REVIEW > SUMMARY
        List<StepTemplate> sorted = new ArrayList<>(templates);
        sorted.sort(Comparator.comparingInt(StepTemplate::getPriority).reversed());
        
        List<StepTemplate> kept = new ArrayList<>();
        int keptTime = 0;
        for (StepTemplate st : sorted) {
            if (keptTime + st.getTimeBudgetMin() <= availableMin) {
                kept.add(st);
                keptTime += st.getTimeBudgetMin();
            }
        }
        
        // 恢复原始顺序
        kept.sort(Comparator.comparingInt(s -> templates.indexOf(s)));
        return kept;
    }

    /**
     * 动态调整：当步骤完成结果偏离预期时插入补救步骤
     */
    public DynamicAdjustResult adjust(String unitId, int triggerStepOrder, AdjustmentReason reason) {
        LearningUnit unit = unitRepository.findByUnitId(unitId);
        LearningStep triggerStep = unit.getSteps().stream()
            .filter(s -> s.getOrder() == triggerStepOrder)
            .findFirst()
            .orElseThrow(() -> new NotFoundException("步骤不存在"));
        
        List<LearningStep> insertedSteps = new ArrayList<>();
        
        switch (reason) {
            case LOW_ACCURACY:
                // 练习正确率过低：插入补充讲解 + 基础练习
                insertedSteps.add(buildRemediationExplainStep(unit, triggerStep));
                insertedSteps.add(buildRemediationPracticeStep(unit, triggerStep));
                break;
            case ALL_WRONG_DIAGNOSE:
                // 诊断全错：插入前置知识回顾
                insertedSteps.add(buildReviewStep(unit));
                insertedSteps.add(buildBasicExplainStep(unit));
                break;
            case TOO_EASY:
                // 过于简单：后续步骤提升难度
                escalateDifficulty(unit, triggerStepOrder);
                break;
            default:
                break;
        }
        
        if (!insertedSteps.isEmpty()) {
            // 重排后续步骤序号
            reorderSteps(unit, triggerStepOrder, insertedSteps.size());
            // 插入新步骤
            for (int i = 0; i < insertedSteps.size(); i++) {
                unit.getSteps().add(triggerStepOrder + i, insertedSteps.get(i));
            }
            unitRepository.save(unit);
            redisTemplate.delete("learning_unit:" + unitId);
        }
        
        return DynamicAdjustResult.builder()
            .adjusted(!insertedSteps.isEmpty())
            .insertedSteps(insertedSteps)
            .build();
    }

    // ... 其他辅助方法省略
}
```

### 9.2 步骤完成处理器

```java
/**
 * 学习步骤完成处理器
 * 负责处理学生完成步骤后的状态更新、掌握度更新、动态调整判断
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class StepCompletionHandler {

    private final LearningUnitRepository unitRepository;
    private final KnowledgeMasteryService masteryService;
    private final LearningEventPublisher eventPublisher;
    private final LearningUnitAssemblyEngine assemblyEngine;

    /**
     * 处理步骤完成
     */
    @Transactional
    public StepCompletionResult handleComplete(String unitId, int stepOrder, StepCompletionRequest req) {
        LearningUnit unit = unitRepository.findByUnitId(unitId);
        LearningStep step = findStep(unit, stepOrder);
        
        // 1. 更新步骤状态
        step.setStatus(StepStatus.COMPLETED);
        step.setResult(buildStepResult(req));
        step.setActualDurationSec(req.getDurationSec());
        step.setCompletedAt(Instant.now());
        
        // 2. 如果是答题类步骤，更新掌握度
        double masteryDelta = 0;
        if (isAssessmentStep(step.getStepType()) && req.getAnswerResults() != null) {
            masteryDelta = masteryService.updateMastery(
                unit.getStudentId(),
                unit.getKnowledgePointId(),
                req.getAnswerResults(),
                unit.getMasterySnapshot()
            );
            step.getResult().setMasteryDelta(masteryDelta);
        }
        
        // 3. 发布学习行为事件
        eventPublisher.publish(new StepCompletedEvent(
            unitId, unit.getStudentId(), unit.getKnowledgePointId(),
            step, masteryDelta, Instant.now()
        ));
        
        // 4. 检查是否需要动态调整
        AdjustmentSuggestion adjustment = checkDynamicAdjustment(step, unit);
        
        // 5. 更新单元状态
        unit.setActualDurationSec(
            unit.getSteps().stream()
                .mapToInt(s -> s.getActualDurationSec() != null ? s.getActualDurationSec() : 0)
                .sum()
        );
        
        if (isAllStepsCompleted(unit)) {
            unit.setStatus(LearningUnitStatus.COMPLETED);
            unit.setCompletedAt(Instant.now());
            eventPublisher.publish(new UnitCompletedEvent(unit));
        } else {
            unit.setStatus(LearningUnitStatus.IN_PROGRESS);
        }
        
        unitRepository.save(unit);
        
        // 6. 返回下一步信息
        LearningStep nextStep = findNextPendingStep(unit, stepOrder);
        
        return StepCompletionResult.builder()
            .stepStatus(StepStatus.COMPLETED)
            .unitStatus(unit.getStatus())
            .masteryDelta(masteryDelta)
            .nextStep(toNextStepDTO(nextStep))
            .unitProgress(calculateProgress(unit))
            .shouldAdjust(adjustment != null)
            .adjustment(adjustment)
            .build();
    }

    /**
     * 动态调整检查
     */
    private AdjustmentSuggestion checkDynamicAdjustment(LearningStep step, LearningUnit unit) {
        if (step.getResult() == null || step.getResult().getAnswerResults() == null) {
            // 非答题步骤，检查反馈
            if (step.getResult() != null && step.getResult().getFeedback() != null) {
                return handleFeedbackAdjustment(step, unit);
            }
            return null;
        }
        
        var ar = step.getResult().getAnswerResults();
        double correctRate = (double) ar.getCorrect() / ar.getTotal();
        
        // 练习正确率极低
        if (step.getStepType() == StepType.PRACTICE && correctRate < 0.3) {
            return AdjustmentSuggestion.builder()
                .reason(AdjustmentReason.LOW_ACCURACY)
                .detail(Map.of("correctRate", correctRate))
                .action("INSERT_REMEDIATION")
                .build();
        }
        
        // 诊断全错
        if (step.getStepType() == StepType.DIAGNOSE && correctRate == 0) {
            return AdjustmentSuggestion.builder()
                .reason(AdjustmentReason.ALL_WRONG_DIAGNOSE)
                .detail(Map.of("correctRate", correctRate))
                .action("INSERT_REVIEW")
                .build();
        }
        
        // 练习全对且很快
        if (correctRate == 1.0 && step.getActualDurationSec() != null) {
            int expected = step.getConfig().getExpectedDurationSec();
            if (expected > 0 && step.getActualDurationSec() < expected * 0.5) {
                return AdjustmentSuggestion.builder()
                    .reason(AdjustmentReason.TOO_EASY)
                    .detail(Map.of("correctRate", correctRate, "speedRatio", 
                        (double) step.getActualDurationSec() / expected))
                    .action("ESCALATE_DIFFICULTY")
                    .build();
            }
        }
        
        return null; // 无需调整
    }
}
```

## 11. 缓存策略

### 11.1 多级缓存设计

```
请求 → L1: 本地缓存(Caffeine, 5min) 
      → L2: Redis(6h) 
      → DB: PostgreSQL
```

| 缓存对象 | Key | TTL | 淘汰策略 |
|---|---|---|---|
| 学习单元 | `learning_unit:{unitId}` | 6h | 会话结束后失效 |
| 内容池 | `content_pool:{kpId}:{grade}:{difficulty}` | 30min | 定时刷新 |
| AI生成内容 | `ai_content:{stepHash}:{contextHash}` | 24h | 相同上下文复用 |
| 学生掌握度 | `mastery:{studentId}:{kpId}` | 10min | 写入时更新 |
| 策略模板 | `strategy_template:{strategy}` | 永久 | 代码变更时刷新 |

### 11.2 缓存一致性

- **学习单元状态变更**：同步更新Redis，DB写入成功后异步失效本地缓存
- **内容池更新**（题库新增题目等）：通过消息广播失效相关KP的内容池缓存
- **掌握度更新**：写入时双写（DB + Redis），读时以Redis为准

```java
/**
 * 组装降级链
 * 当正常组装流程出现问题时，逐级降级
 */
public LearningUnit assembleWithFallback(AssemblyRequest request) {
    try {
        // Level 0: 完整组装（正常流程）
        return assemble(request);
        
    } catch (AssemblyTimeoutException e) {
        log.warn("组装超时，降级到简化模式");
        // Level 1: 简化组装（仅核心步骤：EXPLAIN + PRACTICE + SUMMARY）
        return assembleMinimal(request);
        
    } catch (ContentInsufficientException e) {
        log.warn("内容不足，降级到AI生成模式");
        // Level 2: AI主导组装（大部分内容由AI生成）
        return assembleAIDriven(request);
        
    } catch (Exception e) {
        log.error("组装完全失败，返回静态学习单元", e);
        // Level 3: 静态预设（预设的通用学习模板）
        return assembleStaticPreset(request);
    }
}
```
