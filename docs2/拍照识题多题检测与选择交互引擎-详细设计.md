# 拍照识题多题检测与选择交互引擎 - 详细设计

> 版本: v1.0 | 创建: 2026-05-27 | 模块优先级: P0

## 1. 模块概述

### 1.1 背景

学生在拍照搜题时，拍摄对象通常是整页作业、试卷或练习册，单张图片中往往包含多道题目。系统需要支持：

1. **自动检测**：识别图片中包含的所有题目区域
2. **结构化切割**：为每道题生成精确的边界框（Bounding Box）
3. **用户选择**：在客户端展示检测到的题目区域，允许用户点选需要解析的题目
4. **区域提取**：对用户选中的题目区域进行裁剪、增强后送入 OCR 解析管线

本模块是"拍照搜题与习题答疑"P0 功能链路中的关键环节，位于 **图片采集 → 多题检测 → 用户选择 → OCR 解析 → AI 解题** 流程的中间位置。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 检测准确率 | 单张图片内题目检测准确率 ≥ 95%（1-10 题场景） |
| 检测速度 | 端侧检测 ≤ 500ms，服务端检测 ≤ 800ms |
| 用户体验 | 从拍照到选择题目 ≤ 3 次点击，总耗时 ≤ 3 秒 |
| 题目数量支持 | 单张图片支持 1-20 道题目检测 |
| 跨学科支持 | 适配语文、数学、英语、物理、化学等不同排版风格 |

### 1.3 与已有模块的关系

## 2. 整体流程

### 2.1 完整交互流程

```
用户拍照/选图
    │
    ▼
图片预处理（客户端压缩、旋转校正）
    │
    ▼
[策略判断] 图片尺寸 & 预估题目数量
    │
    ├── 单题场景（图片小 / 用户手动框选）──▶ 直接进入OCR
    │
    └── 多题场景 ──▶ 调用多题检测服务
                        │
                        ▼
                  返回题目区域列表（BoundingBox[]）
                        │
                        ▼
                  客户端渲染选择界面
                  （原图 + 半透明遮罩 + 题号标注）
                        │
                        ▼
                  用户点选目标题目（支持多选）
                        │
                        ▼
                  客户端裁剪选中区域
                        │
                        ▼
                  选中题目图片 ──▶ OCR管线 ──▶ AI解题
```

### 2.2 检测策略选择

| 策略 | 触发条件 | 检测方式 | 耗时 |
|------|---------|---------|------|
| **跳过检测** | 用户手动框选了单题区域 | 无需检测 | 0ms |
| **端侧检测** | 图片 < 2MB，设备性能等级 ≥ 中等 | 本地 ONNX 模型推理 | 200-500ms |
| **服务端检测** | 图片 ≥ 2MB 或端侧检测失败 | 服务端 API 调用 | 500-800ms |
| **降级策略** | 检测服务不可用 | 提供手动框选模式 | 用户操作 |

## 3. 数据结构定义

### 3.1 题目区域（QuestionRegion）

```typescript
/**
 * 单个检测到的题目区域
 */
interface QuestionRegion {
  /** 区域唯一标识（检测批次内） */
  id: string;
  /** 边界框坐标（相对于原图像素） */
  boundingBox: BoundingBox;
  /** 置信度 0-1 */
  confidence: number;
  /** 检测到的题目类型（可选） */
  type?: QuestionType;
  /** 题号（如检测到 "1." "二、" 等标号） */
  detectedNumber?: string;
  /** 区域内文字预览（前20字） */
  textPreview?: string;
  /** 是否跨栏/跨列 */
  isCrossColumn: boolean;
}

interface BoundingBox {
  /** 左上角 X（像素） */
  x: number;
  /** 左上角 Y（像素） */
  y: number;
  /** 宽度（像素） */
  width: number;
  /** 高度（像素） */
  height: number;
  /** 可选：旋转角度（度），支持倾斜文本 */
  rotation?: number;
}

enum QuestionType {
  MULTIPLE_CHOICE = "multiple_choice",   // 选择题
  FILL_BLANK = "fill_blank",             // 填空题
  SHORT_ANSWER = "short_answer",         // 简答题
  CALCULATION = "calculation",           // 计算题
  COMPREHENSION = "comprehension",       // 阅读理解
  UNKNOWN = "unknown",                    // 未识别
}
```

### 3.2 多题检测结果（MultiQuestionDetectionResult）

```typescript
/**
 * 多题检测服务返回结果
 */
interface MultiQuestionDetectionResult {
  /** 检测请求ID */
  requestId: string;
  /** 检测到的所有题目区域 */
  regions: QuestionRegion[];
  /** 原图尺寸 */
  imageDimension: {
    width: number;
    height: number;
  };
  /** 检测耗时(ms) */
  detectionTimeMs: number;
  /** 检测方式 */
  detectionMethod: "on_device" | "server";
  /** 整体置信度评估 */
  overallConfidence: number;
  /** 是否建议用户手动框选（当置信度较低时） */
  suggestManualCrop: boolean;
  /** 检测模型版本 */
  modelVersion: string;
}
```

### 3.3 用户选择结果（QuestionSelection）

```typescript
/**
 * 用户选择提交数据
 */
interface QuestionSelection {
  /** 关联的检测请求ID */
  requestId: string;
  /** 用户选中的题目区域ID列表 */
  selectedRegionIds: string[];
  /** 选择时间戳 */
  selectedAt: number;
  /** 用户是否修改了自动检测区域（手动调整） */
  hasManualAdjustment: boolean;
}
```

### 3.4 裁剪结果（CroppedQuestion）

```typescript
/**
 * 裁剪后的题目图片
 */
interface CroppedQuestion {
  /** 关联的区域ID */
  regionId: string;
  /** 裁剪后的图片数据（Base64 或本地路径） */
  imageData: string;
  /** 裁剪后的图片尺寸 */
  dimension: { width: number; height: number };
  /** 图片格式 */
  format: "jpeg" | "png";
  /** 文件大小（字节） */
  sizeBytes: number;
  /** 裁剪时是否做了额外增强 */
  enhanced: boolean;
}
```

### 5.3 关键 Flutter 代码示例

#### 5.3.1 多题选择页 Widget

```dart
class MultiQuestionSelectPage extends StatefulWidget {
  final File sourceImage;
  final MultiQuestionDetectionResult detectionResult;

  const MultiQuestionSelectPage({
    Key? key,
    required this.sourceImage,
    required this.detectionResult,
  }) : super(key: key);

  @override
  State<MultiQuestionSelectPage> createState() =>
      _MultiQuestionSelectPageState();
}

class _MultiQuestionSelectPageState extends State<MultiQuestionSelectPage> {
  /// 已选中的题目区域 ID 集合
  final Set<String> _selectedRegionIds = {};
  /// 用户手动调整后的边界框
  final Map<String, BoundingBox> _adjustedBoxes = {};
  /// 图片缩放控制器
  final TransformationController _transformController =
      TransformationController();

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        leading: const BackButton(),
        title: const Text('选择题目'),
        actions: [
          TextButton(
            onPressed: _selectedRegionIds.isEmpty ? null : _onConfirm,
            child: Text('确认(${_selectedRegionIds.length})'),
          ),
        ],
      ),
      body: Column(
        children: [
          Expanded(child: _buildImageWithOverlay()),
          _buildBottomBar(),
        ],
      ),
    );
  }

  /// 构建带题目标注的图片视图
  Widget _buildImageWithOverlay() {
    return InteractiveViewer(
      transformationController: _transformController,
      minScale: 0.5,
      maxScale: 3.0,
      child: Stack(
        children: [
          // 原图
          Image.file(
            widget.sourceImage,
            fit: BoxFit.contain,
          ),
          // 题目区域叠加层
          ...widget.detectionResult.regions.map(
            (region) => _QuestionRegionOverlay(
              region: _adjustedBoxes[region.id] != null
                  ? region.copyWith(boundingBox: _adjustedBoxes[region.id]!)
                  : region,
              imageDimension: widget.detectionResult.imageDimension,
              isSelected: _selectedRegionIds.contains(region.id),
              onTap: () => _toggleSelection(region.id),
              onBoundsAdjusted: (newBox) {
                setState(() {
                  _adjustedBoxes[region.id] = newBox;
                });
              },
            ),
          ),
        ],
      ),
    );
  }

  /// 底部操作栏
  Widget _buildBottomBar() {
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 12),
      decoration: BoxDecoration(
        color: Colors.white,
        boxShadow: [
          BoxShadow(
            color: Colors.black.withOpacity(0.05),
            blurRadius: 8,
            offset: const Offset(0, -2),
          ),
        ],
      ),
      child: Row(
        children: [
          TextButton(onPressed: _selectAll, child: const Text('全选')),
          TextButton(onPressed: _clearSelection, child: const Text('重选')),
          TextButton(onPressed: _switchToManualMode, child: const Text('手动框选')),
          const Spacer(),
          Text('已选 ${_selectedRegionIds.length} 题',
              style: const TextStyle(fontSize: 14, color: Colors.grey)),
        ],
      ),
    );
  }

  void _toggleSelection(String regionId) {
    setState(() {
      if (_selectedRegionIds.contains(regionId)) {
        _selectedRegionIds.remove(regionId);
      } else {
        _selectedRegionIds.add(regionId);
      }
    });
  }

  void _selectAll() {
    setState(() {
      _selectedRegionIds.clear();
      _selectedRegionIds.addAll(
        widget.detectionResult.regions.map((r) => r.id),
      );
    });
  }

  void _clearSelection() {
    setState(() => _selectedRegionIds.clear());
  }

  void _switchToManualMode() {
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(
        builder: (_) => ManualCropPage(sourceImage: widget.sourceImage),
      ),
    );
  }

  Future<void> _onConfirm() async {
    // 裁剪选中区域
    final croppedImages = await _cropSelectedRegions();

    // 提交到 OCR 管线
    final result = await QuestionDetectionApi.batchSubmit(
      requestId: widget.detectionResult.requestId,
      selectedRegionIds: _selectedRegionIds.toList(),
      croppedImages: croppedImages,
    );

    if (!mounted) return;

    // 跳转到解析结果页
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(
        builder: (_) => QuestionParsingResultPage(batchResult: result),
      ),
    );
  }

  /// 裁剪选中区域图片
  Future<List<CroppedQuestion>> _cropSelectedRegions() async {
    final image = img.decodeImage(
      await widget.sourceImage.readAsBytes(),
    )!;
    final List<CroppedQuestion> results = [];

    for (final regionId in _selectedRegionIds) {
      final region = widget.detectionResult.regions.firstWhere(
        (r) => r.id == regionId,
      );
      final box = _adjustedBoxes[regionId] ?? region.boundingBox;

      // 裁剪
      final cropped = img.copyCrop(
        image,
        x: box.x,
        y: box.y,
        width: box.width,
        height: box.height,
      );

      // 增强处理
      final enhanced = _enhanceImage(cropped);

      // 编码为 JPEG
      final jpegBytes = img.encodeJpg(enhanced, quality: 90);

      results.add(CroppedQuestion(
        regionId: regionId,
        imageData: base64Encode(jpegBytes),
        dimension: Dimension(
          width: enhanced.width,
          height: enhanced.height,
        ),
        format: ImageFormat.jpeg,
        sizeBytes: jpegBytes.length,
        enhanced: true,
      ));
    }
    return results;
  }

  /// 图片增强（对比度、锐化）
  img.Image _enhanceImage(img.Image image) {
    var result = img.adjustColor(image, contrast: 1.1);
    result = img.gaussianBlur(result, radius: 0.5); // 轻微去噪
    return result;
  }
}
```

#### 5.3.2 题目区域叠加组件

```dart
class _QuestionRegionOverlay extends StatelessWidget {
  final QuestionRegion region;
  final ImageDimension imageDimension;
  final bool isSelected;
  final VoidCallback onTap;
  final ValueChanged<BoundingBox> onBoundsAdjusted;

  const _QuestionRegionOverlay({
    required this.region,
    required this.imageDimension,
    required this.isSelected,
    required this.onTap,
    required this.onBoundsAdjusted,
  });

  @override
  Widget build(BuildContext context) {
    // 将像素坐标转换为相对比例坐标
    final left = region.boundingBox.x / imageDimension.width;
    final top = region.boundingBox.y / imageDimension.height;
    final widthRatio = region.boundingBox.width / imageDimension.width;
    final heightRatio = region.boundingBox.height / imageDimension.height;

    return Positioned(
      left: left * MediaQuery.of(context).size.width,
      top: top * (MediaQuery.of(context).size.height * 0.6),
      child: GestureDetector(
        onTap: onTap,
        child: Container(
          width: widthRatio * MediaQuery.of(context).size.width,
          height: heightRatio * (MediaQuery.of(context).size.height * 0.6),
          decoration: BoxDecoration(
            border: Border.all(
              color: isSelected ? Colors.blue : Colors.grey.withOpacity(0.5),
              width: isSelected ? 2.5 : 1.0,
            ),
            color: isSelected
                ? Colors.blue.withOpacity(0.08)
                : Colors.black.withOpacity(0.15),
            borderRadius: BorderRadius.circular(4),
          ),
          child: Stack(
            children: [
              // 题号标签
              Positioned(
                top: 4,
                left: 4,
                child: Container(
                  padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
                  decoration: BoxDecoration(
                    color: isSelected ? Colors.blue : Colors.grey,
                    borderRadius: BorderRadius.circular(10),
                  ),
                  child: Text(
                    region.detectedNumber ?? region.id,
                    style: const TextStyle(
                      color: Colors.white,
                      fontSize: 11,
                      fontWeight: FontWeight.bold,
                    ),
                  ),
                ),
              ),
              // 选中标记
              if (isSelected)
                Positioned(
                  top: 4,
                  right: 4,

                    width: 20,
                    height: 20,

                      color: Colors.blue,
                      shape: BoxShape.circle,
                    ),
                    child: const Icon(Icons.check, color: Colors.white, size: 14),

                ),
              // 可拖动的四角调整手柄
              if (isSelected) ..._buildResizeHandles(),
            ],
          ),
        ),
      ),
    );
  }

  List<Widget> _buildResizeHandles() {
    // 四角拖动手柄实现（代码省略，使用 Positioned + GestureDetector + DragUpdate）

}
```

## 6. 服务端检测算法

### 6.1 检测模型架构

```
输入图片 (H × W × 3)
    │
    ▼
┌──────────────────┐
│  预处理层         │  缩放到 640×640、归一化
└──────────────────┘
    │
    ▼
┌──────────────────┐
│  YOLOv8-nano     │  轻量目标检测 backbone
│  Backbone        │  提取多尺度特征 FPN
└──────────────────┘
    │
    ▼
```

### 6.3 后处理流程

```python
def postprocess_detections(
    raw_boxes: List[RawBox],
    image_width: int,
    image_height: int,
    iou_threshold: float = 0.3,
    min_confidence: float = 0.6,
) -> List[QuestionRegion]:
    """检测后处理：NMS + 区域排序 + 过滤"""
    
    # 1. 置信度过滤
    filtered = [b for b in raw_boxes if b.confidence >= min_confidence]
    
    # 2. 非极大值抑制 (NMS) 去除重叠框
    kept = nms(filtered, iou_threshold=iou_threshold)
    
    # 3. 区域扩展（向外扩展 5% padding，避免截断文字）
    expanded = [expand_box(b, padding_ratio=0.05, 
                           max_w=image_width, max_h=image_height) 
                for b in kept]
    
    # 4. 按从上到下、从左到右排序（自然阅读顺序）
    sorted_regions = sort_reading_order(expanded)
    
    # 5. 过滤过小区域（噪点）
    final = [r for r in sorted_regions 
             if r.bbox.width > image_width * 0.1 
             and r.bbox.height > image_height * 0.02]
    
    return final


def sort_reading_order(regions: List[QuestionRegion]) -> List[QuestionRegion]:
    """按阅读顺序排序：先按列分组，再按行排序"""
    # 检测是否为双栏排版
    columns = detect_columns(regions)
    
    result = []
    for col in sorted(columns, key=lambda c: c.x_center):
        # 每列内按 Y 坐标排序
        col_regions = sorted(col.regions, key=lambda r: r.bbox.y)
        result.extend(col_regions)
    
    return result
```

```java
@Service
public class QuestionDetectionService {

    private final DetectionModelClient modelClient;
    private final DetectionResultCache resultCache;

    /**
     * 多题检测主入口
     */
    public MultiQuestionDetectionResult detect(
            byte[] imageData,
            ImageMeta meta,
            DetectionOptions options) {
        
        long startTime = System.currentTimeMillis();
        
        // 1. 图片预处理（服务端可选，端侧已做则跳过）
        byte[] processedImage = preprocessImage(imageData, meta);
        
        // 2. 调用检测模型推理服务
        DetectionModelResult modelResult = modelClient.detect(
            processedImage,
            options.getMaxRegions(),
            options.getMinConfidence()
        );
        
        // 3. 后处理
        List<QuestionRegion> regions = postprocess(modelResult, meta);
        
        // 4. 构建结果
        String requestId = generateRequestId();
        long detectionTimeMs = System.currentTimeMillis() - startTime;
        
        MultiQuestionDetectionResult result = MultiQuestionDetectionResult.builder()
                .requestId(requestId)
                .regions(regions)
                .imageDimension(new ImageDimension(meta.getWidth(), meta.getHeight()))
                .detectionTimeMs(detectionTimeMs)
                .detectionMethod("server")
                .overallConfidence(calculateOverallConfidence(regions))
                .suggestManualCrop(regions.isEmpty() || 
                        calculateOverallConfidence(regions) < 0.5)
                .modelVersion(modelClient.getModelVersion())
                .build();
        
        // 5. 缓存结果（供后续选择提交时校验）
        resultCache.put(requestId, result, Duration.ofMinutes(10));
        
        // 6. 异步记录检测日志
        logDetection(requestId, meta, result, detectionTimeMs);
        
        return result;
    }

    /**
     * 批量提交选中的题目到OCR管线
     */
    @Transactional
    public BatchSubmitResult batchSubmit(
            String requestId,
            List<String> selectedRegionIds,
            List<CroppedImageData> croppedImages,
            QuestionContext context) {
        
        // 1. 校验 requestId 有效
        MultiQuestionDetectionResult cached = resultCache.get(requestId)
                .orElseThrow(() -> new BusinessException(
                        ErrorCode.DETECTION_RESULT_EXPIRED,
                        "检测结果已过期，请重新拍照"));
        
        // 2. 校验选择的区域ID合法性
        Set<String> validIds = cached.getRegions().stream()
                .map(QuestionRegion::getId)
                .collect(Collectors.toSet());
        for (String id : selectedRegionIds) {
            if (!validIds.contains(id)) {
                throw new BusinessException(
                        ErrorCode.INVALID_REGION_ID,
                        "无效的题目区域ID: " + id);
            }
        }
        
        // 3. 创建批量OCR任务
        String batchId = generateBatchId();
        List<OcrTaskInfo> tasks = new ArrayList<>();
        
        for (CroppedImageData cropped : croppedImages) {
            // 提交到OCR管线（异步）
            String ocrTaskId = ocrPipeline.submitAsync(
                    cropped.getImageData(),
                    cropped.getFormat(),
                    context
            );
            tasks.add(new OcrTaskInfo(cropped.getRegionId(), ocrTaskId, "processing"));
        }
        
        // 4. 记录用户选择行为（用于模型优化）
        eventPublisher.publishEvent(new QuestionSelectionEvent(
                requestId, selectedRegionIds,
                croppedImages.size(), System.currentTimeMillis()));
        
        return BatchSubmitResult.builder()
                .batchId(batchId)
                .tasks(tasks)
                .build();
    }
}
```

### 7.1 ONNX 模型集成

```dart
class OnDeviceQuestionDetector {
  static const String _modelPath = 'assets/models/qdet_v2.3.onnx';
  static const int _inputSize = 640;
  
  OrtSession? _session;
  bool _isReady = false;

  /// 初始化模型（App启动时预加载）
  Future<void> initialize() async {
    final sessionOptions = OrtSessionOptions();
    // 限制CPU线程数，避免影响UI
    sessionOptions.setIntraOpNumThreads(2);
    
    _session = await OrtSession.fromAsset(_modelPath, sessionOptions);
    _isReady = true;
  }

  /// 执行检测
  Future<List<QuestionRegion>> detect(Uint8List imageBytes) async {
    if (!_isReady) throw StateError('Detector not initialized');
    
    // 1. 解码图片并缩放到 640×640
    final image = img.decodeImage(imageBytes)!;
    final resized = img.copyResize(image, width: _inputSize, height: _inputSize);
    
    // 2. 转为模型输入张量 [1, 3, 640, 640]
    final inputTensor = _imageToTensor(resized);
    
    // 3. 推理
    final inputs = {'images': inputTensor};
    final outputs = _session!.run(OrtRunOptions(), inputs);
    
    // 4. 解析输出
    final rawBoxes = _parseModelOutput(outputs, image.width, image.height);
    
    // 5. 后处理（NMS + 排序）
    return postprocessDetections(rawBoxes);
  }

  Float32List _imageToTensor(img.Image image) {
    final tensor = Float32List(1 * 3 * _inputSize * _inputSize);
    int idx = 0;
    for (int c = 0; c < 3; c++) {        // RGB channels
      for (int y = 0; y < _inputSize; y++) {
        for (int x = 0; x < _inputSize; x++) {
          final pixel = image.getPixel(x, y);
          // 归一化到 0-1
          final value = c == 0 ? pixel.r / 255.0
                     : c == 1 ? pixel.g / 255.0
                     : pixel.b / 255.0;
          tensor[idx++] = value;
        }
      }
    }
    return tensor;
  }
}
```

### 7.2 设备性能分级

```dart
class DevicePerformanceTier {
  static PerformanceLevel assess() {
    final totalMemory = ProcessInfo.currentRss; // 简化评估
    final cpuCores = Platform.numberOfProcessors;
    
    if (cpuCores >= 6 && totalMemory > 4 * 1024 * 1024 * 1024) {
      return PerformanceLevel.high;    // 端侧检测 + 高质量增强
    } else if (cpuCores >= 4) {
      return PerformanceLevel.medium;  // 端侧检测 + 基础增强
    } else {
      return PerformanceLevel.low;     // 直接走服务端检测
    }
  }
}
```

```dart
class DetectionFallbackHandler {
  /// 执行带降级的检测流程
  Future<MultiQuestionDetectionResult> detectWithFallback(
      File imageFile) async {
    final tier = DevicePerformanceTier.assess();
    
    // 策略1: 端侧检测（高性能设备）
    if (tier == PerformanceLevel.high || tier == PerformanceLevel.medium) {
      try {
        final result = await _onDeviceDetector.detect(imageFile)
            .timeout(const Duration(milliseconds: 1500));
        if (result.regions.isNotEmpty) return result;
      } catch (e) {
        analytics.logEvent('detection_on_device_failed', {'error': e.toString()});
      }
    }
    
    // 策略2: 服务端检测
    try {
      final result = await _serverDetector.detect(imageFile)
          .timeout(const Duration(seconds: 3));
      if (result.regions.isNotEmpty) return result;
    } catch (e) {
      analytics.logEvent('detection_server_failed', {'error': e.toString()});
    }
    
    // 策略3: 降级到手动框选
    return MultiQuestionDetectionResult.empty(suggestManualCrop: true);
  }
}
```

## 13. 安全与合规

1. **图片不落盘**：检测服务内存中处理图片，检测结果不存储原图

3. **频率限制**：每用户每分钟最多 10 次检测请求

5. **隐私保护**：裁剪后的题目图片经过脱敏处理，移除可能的个人信息
