## 1. 模块概述

### 1.1 目标

将知识点之间的前置依赖、同层关联与跨学段演进关系，以可交互的图谱形式呈现，使学生能直观查看知识结构、追溯前置、规划路径、聚焦薄弱，并通过点击、拖拽、筛选等交互完成轻量级导航与学习触发。

### 1.2 核心价值

- 结构化认知：将知识点从线性教材章节中抽离为网络，帮助理解全局与关联。
- 自主规划：支持从目标考点反向推导前置，制定学习顺序。
- 聚焦薄弱：高亮显示掌握度低的节点，便于集中突破。
- 快速跳转：点击节点直接进入对应章节/练习/AI讲解。
- 跨学段延续：展示同一概念在不同学段的演进，利于长期积累。

### 1.3 适用人群

| 角色 | 场景 |
|------|------|
| 学生 | 查看知识体系、定位薄弱、规划复习、追溯前置 |
| 家长 | 了解孩子知识图谱状况，辅助规划 |
| 教师 | 查看班级共性薄弱点，生成讲评图谱 |

## 2. 交互流程总览

```
入口：首页/同步课堂/考点梳理/个人学习报告
  │
  ▼
[图谱概览页]（全图或主题子图）
  │
  ├─ 点击节点 → 节点详情弹窗（名称、掌握度、章节、快速操作）
  │     │
  │     ├─ 跳转章节 → 章节学习页
  │     ├─ 练习关联题 → 练习页
  │     ├─ AI讲解 → 对话页
  │     ├─ 查看前后置 → 切换至“路径视图”并居中
  │     └─ 收藏/笔记 → 记录页
  │
  ├─ 拖拽画布 → 自由漫游
  ├─ 缩放与自适应 → 以选中节点为中心缩放
  ├─ 筛选/搜索 → 高亮匹配节点并展开路径
  ├─ 切换视图层级 → 学段/年级/学科/主题
  ├─ 导出图谱 → 图片/PDF
  │
  ▼
[路径规划页]（起点→终点，显示必经与可选路径）
  │
  ├─ 起点/终点拖动
  ├─ 显示路径难度/预计时长/覆盖考点
  ├─ 一键开始路径学习 → 按路径生成每日任务
  │
  ▼
[实时图谱会话]（与AI对话同步高亮当前话题节点）
```

## 3. 数据结构

### 3.1 节点（Node）

```typescript
interface KnowledgeNode {
  id: string;                    // 全局唯一ID，如 kp_cn_math_frac_001
  name: string;                  // 知识点名称
  type: 'concept' | 'skill' | 'application' | 'meta';
  stage: string;                 // 学段，如 'primary' | 'junior' | 'senior'
  grade: string;                 // 年级，如 'grade_1' ... 'grade_12'
  subject: string;               // 学科，如 'math' | 'physics' | 'chemistry'
  chapter_id?: string;           // 归属章节ID（可多归属）
  tags: string[];                // 标签：如 ['pilot_knowledge', 'core', 'optional']
  mastery_level?: number;        // 当前用户掌握度（0~1），null表示未学
  mastery_updated_at?: string;   // 掌握度最后更新时间
  difficulty?: number;           // 官方难度评估（1~5）
  prerequisites: string[];       // 直接前置节点ID集合
  corequisites: string[];        // 同修节点（建议同时学）
  descendants: string[];         // 直接后继节点ID集合
  is_terminal: boolean;          // 是否为考点终点（如高考考点）
  is_gateway: boolean;           // 是否为重要关口（承上启下）
  color?: string;                // 视图用色（按掌握度或重要程度）
  shape?: 'circle' | 'rect' | 'diamond';
  size?: number;                 // 视觉大小（按重要程度）
  x?: number; y?: number;        // 布局坐标（服务端预计算）
  metadata?: Record<string, any>;
}
```

```typescript
interface KnowledgeEdge {
  id: string;                    // 边ID，可由source+target生成

  type: 'prerequisite' | 'related' | 'same_layer' | 'cross_stage';
  weight?: number;               // 关系权重（用于路径搜索）
  label?: string;                // 边标签，如 '必学' / '建议' / '关联'
  bidirectional?: boolean;
}
```

## 5. 状态流转

### 5.1 状态机定义

```typescript
enum GraphSessionState {
  IDLE = 'idle',
  LOADING = 'loading',
  INTERACTING = 'interacting',
  SEARCHING = 'searching',
  NAVIGATING_PATH = 'navigating_path',
  EXPORTING = 'exporting'
}

class GraphStateMachine {
  private state: GraphSessionState = GraphSessionState.IDLE;

  // 加载图谱
  enterLoading(): boolean {
    if (![GraphSessionState.IDLE, GraphSessionState.INTERACTING].includes(this.state)) {
      return false;
    }
    this.state = GraphSessionState.LOADING;
    return true;
  }

  // 加载完成进入交互态
  enterInteracting(): boolean {
    if (this.state !== GraphSessionState.LOADING) return false;
    this.state = GraphSessionState.INTERACTING;
    return true;
  }

  // 搜索节点
  enterSearching(): boolean {
    if (![GraphSessionState.INTERACTING, GraphSessionState.NAVIGATING_PATH].includes(this.state)) {
      return false;
    }
    this.state = GraphSessionState.SEARCHING;
    return true;
  }

  // 路径规划
  enterNavigatingPath(): boolean {
    if (![GraphSessionState.INTERACTING, GraphSessionState.SEARCHING].includes(this.state)) {
      return false;
    }
    this.state = GraphSessionState.NAVIGATING_PATH;
    return true;
  }

  // 导出
  enterExporting(): boolean {
    if (![GraphSessionState.INTERACTING, GraphSessionState.NAVIGATING_PATH].includes(this.state)) {
      return false;
    }
    this.state = GraphSessionState.EXPORTING;
    return true;
  }

  // 回到交互态
  returnToInteracting(): boolean {
    if (this.state === GraphSessionState.EXPORTING) {
      this.state = GraphSessionState.INTERACTING;
      return true;
    }
    return false;
  }

  getCurrentState(): GraphSessionState {
    return this.state;
  }
}
```

### 5.2 节点选择状态机

```typescript
type NodeSelectionState = 'none' | 'single' | 'multi';

class NodeSelectionStateMachine {
  private selectedIds: Set<string> = new Set();

  getState(): NodeSelectionState {
    if (this.selectedIds.size === 0) return 'none';
    if (this.selectedIds.size === 1) return 'single';
    return 'multi';
  }

  toggle(nodeId: string): void {
    if (this.selectedIds.has(nodeId)) {
      this.selectedIds.delete(nodeId);
    } else {
      this.selectedIds.add(nodeId);
    }
  }

  clear(): void {
    this.selectedIds.clear();
  }

  getSelected(): string[] {
    return Array.from(this.selectedIds);
  }
}
```

## 6. 错误处理

| 场景 | 客户端处理 | 服务端行为 |
|------|-----------|-----------|
| 请求视图不存在 | 提示“该图谱视图不可用”，返回推荐视图 | 返回 404 + 推荐视图ID |
| 节点搜索无结果 | 提示“未找到相关知识点”，提示同义词或范围缩小 | 返回空结果列表，记录搜索词 |
| 路径计算超时（>3秒） | 提示“路径计算耗时较长，请稍后再试” | 异步任务，完成后推送结果 |
| 导出失败 | 提示“导出失败，请重试” | 记录失败原因（队列满/渲染超时） |
| 会话冲突（多端操作） | 强制重置为最新服务端状态 | 最后写入生效 |
| 权限不足（家长查看） | 提示“该功能仅学生可用” | 返回 403 |

## 7. 关键代码示例

### 7.1 前端图谱引擎交互逻辑（伪代码，Dart/Flutter）

```dart
class GraphInteractor {
  final KnowledgeGraphApi _api;
  final GraphStateMachine _stateMachine = GraphStateMachine();
  final NodeSelectionStateMachine _selection = NodeSelectionStateMachine();

  KnowledgeGraphView? _view;
  final Set<String> _highlighted = {};

  Future<void> loadView(String viewId) async {
    if (!_stateMachine.enterLoading()) return;

    try {
      _view = await _api.getView(viewId);
      _stateMachine.enterInteracting();
    } catch (e) {
      // 错误提示与重试逻辑
    }
  }

  void onNodeTap(String nodeId) {
    if (_stateMachine.getCurrentState() != GraphSessionState.INTERACTING) return;

    _selection.toggle(nodeId);
    _highlighted.add(nodeId);
    // 触发侧边详情弹窗
    showNodeDetail(nodeId);
  }

  void onBackgroundTap() {
    _selection.clear();
    _highlighted.clear();
  }

  Future<void> search(String query) async {
    if (!_stateMachine.enterSearching()) return;
    final results = await _api.search(_view!.viewId, query);
    _highlighted.clear();
    results.nodes.forEach((n) => _highlighted.add(n.id));
    // 自动居中第一个匹配节点
    if (results.nodes.isNotEmpty) {
      centerOn(results.nodes.first.id);
    }
    _stateMachine.enterInteracting();
  }

  Future<void> planPath(String startId, String endId) async {
    if (!_stateMachine.enterNavigatingPath()) return;
    final paths = await _api.computePath(
      _view!.viewId, startId, endId);
    // 进入路径视图，渲染路径
    renderPath(paths.first);
  }

  Future<void> export(String format) async {
    if (!_stateMachine.enterExporting()) return;
    try {
      final result = await _api.export(_view!.viewId, format);
      openUrl(result.url);
    } finally {
      _stateMachine.returnToInteracting();
    }
  }
}
```

### 7.2 后端路径计算服务骨架（Java）

```java
@Service
@RequiredArgsConstructor
public class GraphPathService {
    private final KnowledgeGraphRepository graphRepo;
    private final MasteryService masteryService;

    public List<LearningPath> computePaths(String viewId, String startId, String endId,
                                           boolean includeOptional, int maxLength) {
        GraphView view = graphRepo.findById(viewId)
            .orElseThrow(() -> new NotFoundException("view not found"));

        Map<String, KnowledgeNode> nodes = view.getNodes().stream()
            .collect(Collectors.toMap(KnowledgeNode::getId, Function.identity()));
        Map<String, List<KnowledgeEdge>> adjacency = buildAdjacency(view.getEdges());

        // A* 搜索，考虑掌握度作为启发权重
        List<List<String>> rawPaths = aStarSearch(
            startId, endId, adjacency, nodes, includeOptional, maxLength);

        return rawPaths.stream()
            .map(this::toLearningPath)
            .sorted(Comparator.comparingInt(LearningPath::getWeakNodesCount))
            .collect(Collectors.toList());
    }

    private List<String> aStarSearch(...) {
        // 实现带权重的最短路径算法，权重可结合掌握度、边权重
    }

    private LearningPath toLearningPath(List<String> nodeIds) {
        List<PathNode> pathNodes = nodeIds.stream()
            .map(id -> {
                KnowledgeNode n = nodes.get(id);
                return PathNode.builder()
                    .id(id)
                    .name(n.getName())
                    .masteryLevel(masteryService.getMastery(n.getId(), currentUserId()))
                    .build();
            })
            .collect(Collectors.toList());

        int weakCount = (int) pathNodes.stream()
            .filter(n -> n.getMasteryLevel() < 0.6).count();
        double estimatedHours = pathNodes.stream()
            .mapToDouble(n -> ESTIMATE_MINUTES[n.getDifficulty()])
            .sum() / 60.0;

        return LearningPath.builder()
            .nodes(pathNodes)
            .weakNodesCount(weakCount)
            .estimatedHours(estimatedHours)
            .build();
    }
}
```
