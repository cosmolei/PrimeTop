## 1. 模块概述

### 1.1 功能定位

邀请裂变与用户增长服务（Referral & Growth Service）是 PrimeTop 用户增长体系的核心服务端模块，负责邀请码/链接生成、邀请关系绑定、裂变奖励结算、防作弊风控、增长数据归因等全链路能力。本服务为客户端「分享邀请」页面、管理后台「增长看板」和运营「裂变活动配置」提供后端支撑。

### 1.2 与现有模块关系

```

│  分享与社交裂变系统（系统级设计，docs2 已有）                     │
```

#### referral_code（邀请码表）

每个用户拥有唯一邀请码，注册时自动分配。


## 4. 核心业务逻辑

### 4.1 邀请码生成算法

```java
@Service
public class ReferralCodeGenerator {

    // 排除易混淆字符：0/O, 1/I/L
    private static final String CHARS = "ABCDEFGHJKMNPQRSTUVWXYZ23456789";
    private static final int CODE_LENGTH = 6;
    private static final int MAX_RETRY = 10;

    private final Random random = new SecureRandom();

    /**
     * 生成唯一邀请码，冲突时重试
     */
    public String generate() {
        for (int i = 0; i < MAX_RETRY; i++) {
            String code = generateOne();
            if (referralCodeMapper.existsByCode(code)) {
                continue;  // 冲突重试
            }
            return code;
        }
        throw new ServiceException(ErrorCode.REFERRAL_CODE_GENERATE_FAILED);
    }

    private String generateOne() {
        StringBuilder sb = new StringBuilder(CODE_LENGTH);
        for (int i = 0; i < CODE_LENGTH; i++) {
            sb.append(CHARS.charAt(random.nextInt(CHARS.length())));
        }
        return sb.toString();
    }
}
```

### 4.2 邀请绑定核心流程

```java
@Service
@Slf4j
public class ReferralBindService {

    @Transactional
    public ReferralBindResult bind(BindReferralRequest request) {
        Long inviteeUserId = request.getInviteeUserId();
        String code = request.getReferralCode();

        // 1. 查找邀请码
        ReferralCode referralCode = referralCodeMapper.selectByCode(code);
        if (referralCode == null || referralCode.getStatus() != CodeStatus.ACTIVE) {
            log.info("邀请码无效或已冻结: code={}", code);
            return ReferralBindResult.skipped("INVALID_CODE");
        }

        Long inviterUserId = referralCode.getUserId();

        // 2. 不能邀请自己
        if (inviterUserId.equals(inviteeUserId)) {
            return ReferralBindResult.skipped("SELF_INVITE");
        }

        // 3. 检查该用户是否已被邀请过
        if (referralRecordMapper.existsByInviteeUserId(inviteeUserId)) {
            log.info("用户已被邀请过: userId={}", inviteeUserId);
            return ReferralBindResult.skipped("ALREADY_INVITED");
        }

        // 4. 风控检查
        RiskCheckResult riskResult = referralRiskService.check(
            inviteeUserId,
            request.getDeviceFingerprint(),
            inviterUserId
        );
        if (riskResult.isBlocked()) {
            log.warn("邀请风控拦截: inviter={}, invitee={}, tags={}",
                inviterUserId, inviteeUserId, riskResult.getTags());
            // 仍然创建记录，但标记为已拦截
            return createBlockedRecord(referralCode, inviteeUserId, request, riskResult);
        }

        // 5. 查询命中的活动
        ReferralCampaign campaign = campaignService.findActiveCampaign(
            request.getChannel()
        );

        // 6. 创建邀请记录
        ReferralRecord record = new ReferralRecord();
        record.setReferralCodeId(referralCode.getId());
        record.setInviterUserId(inviterUserId);
        record.setInviteeUserId(inviteeUserId);
        record.setSource(request.getSource());
        record.setChannel(request.getChannel());
        record.setCampaignId(campaign != null ? campaign.getId() : null);
        record.setDeviceFingerprint(request.getDeviceFingerprint());
        record.setIpAddress(maskIp(request.getIpAddress()));
        record.setDepth(1);  // MVP 只支持单层
        record.setBindStatus(BindStatus.BOUND);
        record.setInviteeActivated(false);
        record.setInviterRewarded(false);
        record.setInviteeRewarded(false);
        record.setRiskStatus(riskResult.isSuspicious() ? RiskStatus.SUSPICIOUS : RiskStatus.NORMAL);
        record.setRiskTags(riskResult.getTags());
        referralRecordMapper.insert(record);

        // 7. 更新邀请码统计
        referralCodeMapper.incrementTotalInvited(referralCode.getId());

        // 8. 更新缓存
        referralCacheService.refreshInviterStats(inviterUserId);

        // 9. 发布事件
        eventPublisher.publish(new ReferralBoundEvent(
            record.getId(), inviterUserId, inviteeUserId, campaign
        ));

        log.info("邀请绑定成功: inviter={}, invitee={}, campaign={}",
            inviterUserId, inviteeUserId,
            campaign != null ? campaign.getId() : null);

        return ReferralBindResult.success(record, campaign);
    }
}
```

```java
@Component
@Slf4j
public class ReferralRewardConsumer implements EventListener<ReferralBoundEvent> {

    @Override
    @Async("referralExecutor")
    public void onEvent(ReferralBoundEvent event) {
        Long recordId = event.getRecordId();
        ReferralRecord record = referralRecordMapper.selectById(recordId);

        if (record == null || record.getRiskStatus() == RiskStatus.BLOCKED) {
            log.info("跳过奖励发放: recordId={}, riskStatus={}",
                recordId, record != null ? record.getRiskStatus() : "NOT_FOUND");
            return;
        }

        // 1. 确定奖励配置（活动 or 默认）
        RewardConfig rewardConfig = resolveRewardConfig(record);

        // 2. 发放被邀请人即时奖励
        if (rewardConfig.getInviteeImmediateReward() != null) {
            issueReward(record.getId(), record.getInviteeUserId(),
                rewardConfig.getInviteeImmediateReward(), "invitee_reward");
        }

        // 3. 如果无激活条件，直接发放邀请人奖励
        if (rewardConfig.getActivationRule() == null ||
            "none".equals(rewardConfig.getActivationRule().get("type"))) {
            issueReward(record.getId(), record.getInviterUserId(),
                rewardConfig.getInviterReward(), "inviter_reward");
            markInviterRewarded(recordId);
        }
        // 否则等待 ActivationListener 触发
    }

    /**
     * 幂等发放奖励
     */
    private void issueReward(Long recordId, Long userId,
                             RewardDetail reward, String reason) {
        String idempotentKey = "referral:%d:%s:%s".formatted(recordId, userId, reason);

        // 幂等检查
        if (rewardLogMapper.existsByIdempotentKey(idempotentKey)) {
            log.info("奖励已发放，跳过: key={}", idempotentKey);
            return;
        }

        ReferralRewardLog log = new ReferralRewardLog();
        log.setReferralRecordId(recordId);
        log.setUserId(userId);
        log.setRewardType(reward.getType());
        log.setRewardDetail(reward.toJson());
        log.setAmount(reward.getAmount());
        log.setReason(reason);
        log.setStatus(RewardStatus.PENDING);
        log.setIdempotentKey(idempotentKey);
        rewardLogMapper.insert(log);

        // 根据奖励类型调用不同服务
        try {
            switch (reward.getType()) {
                case "points" -> pointsService.addPoints(
                    userId, reward.getAmount(), "REFERRAL_REWARD", idempotentKey);
                case "vip_days" -> membershipService.grantVipDays(
                    userId, reward.getAmount(), "REFERRAL_REWARD", idempotentKey);
                case "quota_pack" -> quotaService.grantQuotaPack(
                    userId, reward.getDetail(), idempotentKey);
                case "coupon" -> couponService.issueCoupon(
                    userId, reward.getDetail(), idempotentKey);
            }
            rewardLogMapper.updateStatus(log.getId(), RewardStatus.ISSUED, LocalDateTime.now());
        } catch (Exception e) {
            log.error("奖励发放失败: recordId={}, userId={}, type={}",
                recordId, userId, reward.getType(), e);
            rewardLogMapper.updateStatus(log.getId(), RewardStatus.FAILED, null);
            retryQueueService.enqueue("referral_reward_retry", log.getId());
        }
    }
}
```

```java
@Component
@Slf4j
public class ActivationListener {

    @EventListener
    @Async("referralExecutor")
    public void onLearningComplete(LearningCompleteEvent event) {
        Long userId = event.getUserId();

        List<ReferralRecord> pendingRecords =
            referralRecordMapper.findPendingActivationByInvitee(userId);

        for (ReferralRecord record : pendingRecords) {
            ReferralCampaign campaign = record.getCampaignId() != null
                ? campaignMapper.selectById(record.getCampaignId()) : null;

            ActivationRule rule = resolveActivationRule(campaign);
            if (checkActivation(rule, event)) {
                referralRecordMapper.markActivated(record.getId(), LocalDateTime.now());

                RewardDetail inviterReward = resolveInviterReward(campaign);
                issueReward(record.getId(), record.getInviterUserId(),
                    inviterReward, "inviter_reward");

                RewardDetail inviteeActivationReward =
                    resolveInviteeActivationReward(campaign);
                if (inviteeActivationReward != null) {
                    issueReward(record.getId(), userId,
                        inviteeActivationReward, "invitee_activation_reward");
                }
            }
        }
    }

    private boolean checkActivation(ActivationRule rule, LearningCompleteEvent event) {
        return switch (rule.getType()) {
            case "first_learning" -> true;
            case "learning_duration" -> event.getDurationMinutes()
                >= rule.getThresholdMinutes();
            case "complete_chapter" -> event.isChapterCompleted();
            case "answer_questions" -> event.getQuestionCount()
                >= rule.getThresholdCount();
            default -> false;
        };
    }
}
```

### 4.4 防作弊风控

```java
@Service
@Slf4j
public class ReferralRiskService {

    public RiskCheckResult check(Long inviteeUserId, String deviceFingerprint,
                                 Long inviterUserId) {
        List<String> riskTags = new ArrayList<>();
        boolean blocked = false;

        // 1. 设备指纹检查：同一设备30天内最多绑定3个邀请码
        if (deviceFingerprint != null) {
            String fpKey = "referral:fp:" + deviceFingerprint;
            Set<String> historicalCodes = cache.get(fpKey);
            if (historicalCodes != null && historicalCodes.size() >= 3) {
                riskTags.add("fp_too_many_binds");
                blocked = true;
            }
        }

        // 2. 邀请人每日频率上限
        String dailyKey = "referral:daily_invite:%d:%s".formatted(
            inviterUserId, LocalDate.now());
        long dailyCount = cache.increment(dailyKey);
        if (dailyCount == 1) cache.expire(dailyKey, Duration.ofDays(1));
        if (dailyCount > MAX_DAILY_INVITES) {
            riskTags.add("high_frequency");
            blocked = true;
        }

        // 3. 同 IP 短时间大量邀请
        long ipCount = referralRecordMapper.countByIpInLast24h(getCurrentIp());
        if (ipCount > MAX_IP_DAILY_INVITES) {
            riskTags.add("ip_aggregation");
            blocked = true;
        }

        // 4. 被邀请人账号特征检查（一次性账号检测）
        UserProfile profile = userService.getProfile(inviteeUserId);
        if (isDisposableAccount(profile)) {
            riskTags.add("disposable_account");
            blocked = true;
        }

        // 5. 互相邀请检测
        if (hasMutualBindingHistory(inviterUserId, inviteeUserId)) {
            riskTags.add("mutual_binding");
            blocked = true;
        }

        return new RiskCheckResult(riskTags, blocked);
    }
}
```

### 7.1 业务异常码

| 异常码 | HTTP | 说明 | 处理策略 |
|--------|------|------|----------|
| `REFERRAL_CODE_NOT_FOUND` | 404 | 邀请码不存在 | 提示用户检查邀请码 |
| `REFERRAL_CODE_FROZEN` | 400 | 邀请码已被冻结 | 提示联系客服 |
| `REFERRAL_SELF_INVITE` | 400 | 不能邀请自己 | 前端拦截 |
| `REFERRAL_ALREADY_INVITED` | 200 | 用户已被邀请 | 静默跳过，不报错 |
| `REFERRAL_RISK_BLOCKED` | 200 | 风控拦截 | 静默跳过，后台记录 |
| `REFERRAL_DAILY_LIMIT` | 429 | 当日邀请次数达上限 | 提示明日再试 |
| `REFERRAL_CAMPAIGN_EXPIRED` | 200 | 活动已结束 | 按默认规则处理 |
| `REFERRAL_REWARD_ISSUE_FAILED` | 500 | 奖励发放失败 | 自动重试3次 |
| `REFERRAL_CODE_GENERATE_FAILED` | 500 | 邀请码生成失败 | 重试 |
| `REFERRAL_FP_LIMIT` | 200 | 设备指纹绑定次数超限 | 静默跳过 |

### 7.2 降级策略

| 场景 | 降级策略 |
|------|----------|
| 活动缓存不可用 | 直接查数据库，不返回活动信息 |
| 积分服务不可用 | 奖励记录标记为待发放，放入重试队列 |
| 消息服务不可用 | 跳过通知，不影响奖励发放 |
| 数据库写入超时 | 返回成功但标记为异步处理，补偿任务校对 |
| Redis 不可用 | 直接查数据库，降级性能但保证正确性 |

```java
@Service
public class InviterRankService {

    private static final int[] RANK_THRESHOLDS = {0, 5, 15, 30, 50, 100};

    public InviterRank getRank(int totalActivated) {
        int level = 0;
        for (int i = RANK_THRESHOLDS.length - 1; i >= 0; i--) {
            if (totalActivated >= RANK_THRESHOLDS[i]) {
                level = i;
                break;
            }
        }
        return InviterRank.of(level);
    }
}
```

## 11. 性能优化

### 11.1 缓存策略

| 数据 | 缓存策略 | TTL | 更新方式 |
|------|----------|-----|----------|
| 邀请码 → user_id | Cache Aside | 永久 | 写时更新 |
| 邀请人统计 | Write Behind | 24h | 事件触发 + 定时刷新 |
| 活动配置 | Cache Aside | 活动结束+7d | 管理后台变更时主动失效 |
| 落地页点击去重 | Set 去重 | 7d | 自动过期 |
| 每日邀请计数 | Counter | 至当日结束 | 自动过期 |

### 11.2 数据库优化

- `referral_record` 表按月分区（PARTITION BY RANGE MONTH(created_at)），便于历史数据归档
- `growth_event` 表写入量大，使用 ClickHouse 替代 MySQL 存储历史数据
- 查询邀请记录列表走 `(inviter_user_id, created_at)` 联合索引
- 管理后台统计查询走预聚合 BI 表，避免实时聚合

### 11.3 并发控制

- 邀请码生成使用数据库唯一索引保证幂等
- 邀请关系绑定使用 `uk_invitee_user_id` 唯一索引防止重复绑定
- 奖励发放使用 `idempotent_key` 保证幂等
- 同一用户的邀请操作使用分布式锁（Redis SETNX，key=`referral:lock:{user_id}`，TTL 3s）

## 12. 安全考虑

### 12.1 数据脱敏

- IP 地址存储时脱敏：`192.168.1.100` → `192.168.*.*`
- 设备指纹不存储原始值，使用 SHA-256 哈希
- 邀请记录不暴露被邀请人手机号等敏感信息

### 12.2 防刷策略

| 维度 | 限制 | 处理 |
|------|------|------|
| 单用户每日邀请上限 | 50次/日 | 超出标记可疑 |
| 同设备绑定次数 | 3次/30天 | 超出拦截 |
| 同IP邀请数 | 20次/24h | 超出拦截 |
| 注册后绑定时间窗口 | 注册后30min内 | 超时不再接受邀请码 |
| 一次性账号特征 | 手机号特征+行为模式 | 拦截 |

### 12.3 接口安全

- `/api/v1/referral/bind` 使用内部调用鉴权，非客户端直连
- `/api/v1/referral/track-click` 限流 100次/IP/分钟
- 管理后台接口需 RBAC 权限校验（`growth:campaign:write`）
- 所有接口日志审计
