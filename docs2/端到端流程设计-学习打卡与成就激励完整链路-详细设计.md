# 端到端流程设计 - 学习打卡与成就激励完整链路

## 1. 概述

### 1.1 文档目的

本文档描述 PrimeTop「学习打卡 → 积分获取 → 成就解锁 → 勋章展示 → 持续激励」的完整端到端链路，覆盖客户端交互、服务端业务逻辑、事件驱动、数据流转和异常处理。开发人员可根据本文档直接进入编码。

### 1.2 边界范围

| 包含 | 不包含 |
| --- | --- |
| 每日学习打卡触发与记录 | 积分商城兑换流程（见积分商城文档） |
| 连续打卡天数计算与断签保护 | 会员订阅与权益（见会员订阅文档） |
| 积分获取规则计算与发放 | 题目推荐逻辑（见题目推荐文档） |
| 成就解锁判定与勋章发放 | 运营活动配置（见运营弹窗文档） |
| 激励通知与展示反馈 | 学习计划生成（见学习规划文档） |
| 学习等级与成长体系 | 第三方分享（见分享裂变文档） |

### 1.3 关联文档

- `学习习惯养成与打卡系统-详细设计.md`
- `积分与虚拟经济体系-详细设计.md`

## 2. 核心业务流程总览

### 2.1 端到端主流程

```text
┌─────────────┐    ┌──────────────┐    ┌─────────────┐    ┌──────────────┐    ┌──────────────┐
│ 1.学习行为   │───▶│ 2.打卡触发    │───▶│ 3.积分计算   │───▶│ 4.成就判定    │───▶│ 5.激励反馈   │
│   发生       │    │   与记录      │    │   与发放     │    │   与解锁      │    │   与展示     │
└─────────────┘    └──────────────┘    └─────────────┘    └──────────────┘    └──────────────┘
       │                  │                   │                   │                   │
  用户完成题目       判定打卡条件          规则引擎匹配        遍历成就规则         弹窗/动画/通知
  学习N分钟         记录打卡记录          增量计算积分        发放勋章/头衔        更新等级进度
  订正错题          更新连续天数          事务性写入          写入成就记录         触发下一轮检查
```

### 2.2 时序概览

```text
客户端                    网关                   学习事件服务              打卡服务              积分服务              成就服务
  │                        │                        │                       │                     │                     │
  │──提交答题结果──────────▶│                        │                       │                     │                     │
  │                        │──异步事件──────────────▶│                       │                     │                     │
  │                        │                        │──学习行为写入──────────▶│                     │                     │
  │                        │                        │                       │──检查打卡条件────────│                     │
  │                        │                        │                       │──打卡成功────────────│                     │
  │                        │                        │                       │──触发积分事件────────│                     │
  │                        │                        │                       │                     │──计算积分───────▶    │
  │                        │                        │                       │                     │◀──积分发放成功───    │
  │                        │                        │                       │                     │──触发成就检查────────▶│
  │                        │                        │                       │                     │                     │──遍历规则
  │◀───────────────────────────────────────────────────SSE推送激励反馈──────────────────────────────────────────────│
```

## 3. 数据结构定义

### 3.1 打卡记录表 `check_in_record`

```sql
CREATE TABLE check_in_record (
    id              BIGINT          NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    user_id         BIGINT          NOT NULL COMMENT '用户ID',
    child_id        BIGINT          DEFAULT NULL COMMENT '孩子ID（家庭账号场景）',
    check_in_date   DATE            NOT NULL COMMENT '打卡日期（本地时区）',
    check_in_type   TINYINT         NOT NULL COMMENT '打卡类型：1=学习时长 2=完成题目 3=错题订正 4=每日任务 5=自定义',
    trigger_event   VARCHAR(64)     NOT NULL COMMENT '触发事件标识',
    streak_days     INT             NOT NULL DEFAULT 0 COMMENT '打卡后连续天数',
    is_make_up      TINYINT(1)      NOT NULL DEFAULT 0 COMMENT '是否补签：0=否 1=是',
    make_up_used_at DATETIME        DEFAULT NULL COMMENT '补签道具使用时间',
    duration_sec    INT             DEFAULT 0 COMMENT '本次学习时长（秒）',
    question_count  INT             DEFAULT 0 COMMENT '本次完成题目数',
    ext_data        JSON            DEFAULT NULL COMMENT '扩展数据',
    created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    
    PRIMARY KEY (id),
    UNIQUE KEY uk_user_child_date_type (user_id, child_id, check_in_date, check_in_type),
    INDEX idx_user_date (user_id, child_id, check_in_date),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='打卡记录表';
```

### 3.2 打卡统计快照表 `check_in_stats`

```sql
CREATE TABLE check_in_stats (
    id              BIGINT          NOT NULL AUTO_INCREMENT,
    user_id         BIGINT          NOT NULL COMMENT '用户ID',
    child_id        BIGINT          DEFAULT NULL COMMENT '孩子ID',
    total_days      INT             NOT NULL DEFAULT 0 COMMENT '累计打卡天数',
    current_streak  INT             NOT NULL DEFAULT 0 COMMENT '当前连续打卡天数',
    max_streak      INT             NOT NULL DEFAULT 0 COMMENT '历史最长连续天数',
    last_check_date DATE            DEFAULT NULL COMMENT '最后打卡日期',
    make_up_quota   INT             NOT NULL DEFAULT 3 COMMENT '本月剩余补签次数',
    month_make_up   INT             NOT NULL DEFAULT 0 COMMENT '本月已使用补签次数',
    updated_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    PRIMARY KEY (id),
    UNIQUE KEY uk_user_child (user_id, child_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='打卡统计快照';
```

### 3.3 积分流水表 `point_transaction`

```sql
CREATE TABLE point_transaction (
    id              BIGINT          NOT NULL AUTO_INCREMENT,
    user_id         BIGINT          NOT NULL COMMENT '用户ID',
    child_id        BIGINT          DEFAULT NULL,
    tx_type         TINYINT         NOT NULL COMMENT '类型：1=获取 2=消费 3=过期 4=系统调整',
    amount          INT             NOT NULL COMMENT '变动数量（正=获取, 负=消费）',
    balance_after   INT             NOT NULL COMMENT '变动后余额',
    source_type     VARCHAR(32)     NOT NULL COMMENT '来源类型：check_in/achievement/daily_task/question/etc',
    source_id       VARCHAR(64)     DEFAULT NULL COMMENT '来源关联ID',
    rule_id         VARCHAR(64)     DEFAULT NULL COMMENT '匹配的规则ID',
    description     VARCHAR(255)    DEFAULT NULL COMMENT '描述',
    created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    PRIMARY KEY (id),
    INDEX idx_user_type (user_id, child_id, tx_type),
    INDEX idx_created (created_at),
    INDEX idx_source (source_type, source_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='积分流水表';
```

#### 4.3.2 领取成就奖励

```
POST /api/v1/gamification/achievements/{achievementId}/claim
```

**响应：**

```json
{
  "code": 0,
  "data": {
    "achievementId": "STREAK_7",
    "pointsReward": 50,
    "newBalance": 1330
  }
}
```

**错误码：**

| 错误码 | 含义 |
| --- | --- |
| `ACHIEVEMENT_NOT_UNLOCKED` | 成就未解锁 |
| `ACHIEVEMENT_ALREADY_CLAIMED` | 奖励已领取 |
| `ACHIEVEMENT_NOT_FOUND` | 成就不存在 |
