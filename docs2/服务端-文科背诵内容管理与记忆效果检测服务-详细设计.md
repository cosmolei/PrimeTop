## 1. 服务概述

### 1.1 功能定位

## 3. 核心算法设计

### 3.1 文本背诵对比引擎 (TextDiffEngine)

#### 3.1.1 算法选型

采用 **LCS（最长公共子序列）+ 编辑距离（Levenshtein Distance）混合算法**：

1. 先用 LCS 确定文本对齐骨架
2. 在 LCS 骨架基础上计算编辑操作序列
3. 将编辑操作映射为 DiffToken 分类

不直接使用标准 diff 算法（如 Myers diff），因为背诵场景中字符的**语义等价性**（如"的/得/地"的误用、"他/她"的混用）需要特殊处理。

#### 3.1.2 算法流程

```
输入: expected (标准文本), actual (用户输入)
输出: DiffToken[], accuracy_score, sequence_score, completeness
```

```
Step 1: 预处理
  ├─ 中文：去除空格、统一全角/半角标点
  ├─ 英文：统一大小写、归并空白
  └─ 拆分为 token 序列 (中文按字、英文按空格分词)

Step 2: 对齐计算
  ├─ 计算 LCS(expected_tokens, actual_tokens)
  ├─ 基于 LCS 确定匹配点 (matched_pairs)
  └─ 对匹配点之间的间隙生成编辑操作

Step 3: 差异分类
  ├─ expected 中存在但 actual 中不存在 → missing
  ├─ actual 中存在但 expected 中不存在 → extra
  ├─ 同位置字符不同 → wrong
  └─ 字符存在但顺序不同 → order

Step 4: 严重度评估
  ├─ 差异字符是否为关键词 → severity=high
  ├─ 差异字符是否为虚词/标点 → severity=low
  └─ 其他 → severity=medium

Step 5: 评分计算
  ├─ accuracy = matched_chars / expected_total_chars × 100
  ├─ sequence = 正确序列连续段长度加权和 / 总长度 × 100
  ├─ completeness = actual_covered_chars / expected_total_chars × 100
  └─ combined = accuracy×0.5 + sequence×0.3 + completeness×0.2
```

#### 3.1.3 关键代码示例

```java
@Service
public class TextDiffEngine {

    /**
     * 执行文本对比，生成字词级差异分析
     */
    public DiffResult diff(String expected, String actual) {
        // Step 1: 预处理与分词
        Token[] expectedTokens = tokenize(expected);
        Token[] actualTokens = tokenize(actual);
        
        // Step 2: LCS 对齐
        int[][] lcsTable = buildLCSTable(expectedTokens, actualTokens);
        List<MatchPair> matches = backtrackLCS(lcsTable, expectedTokens, actualTokens);
        
        // Step 3: 生成差异
        List<DiffToken> diffTokens = generateDiffs(expectedTokens, actualTokens, matches);
        
        // Step 4: 评分
        ScoreResult scores = calculateScores(expectedTokens, actualTokens, matches, diffTokens);
        
        return new DiffResult(diffTokens, scores);
    }

    private Token[] tokenize(String text) {
        List<Token> tokens = new ArrayList<>();
        int pos = 0;
        for (int i = 0; i < text.length(); ) {
            char ch = text.charAt(i);
            if (isChinese(ch)) {
                tokens.add(new Token(String.valueOf(ch), pos++, CharType.CHINESE));
                i++;
            } else if (isEnglish(ch)) {
                // 英文按空格分词
                int start = i;
                while (i < text.length() && isEnglish(text.charAt(i))) i++;
                tokens.add(new Token(text.substring(start, i), pos++, CharType.ENGLISH));
            } else if (isPunctuation(ch)) {
                tokens.add(new Token(String.valueOf(ch), pos++, CharType.PUNCTUATION));
                i++;
            } else {
                i++; // 跳过空白等
            }
        }
        return tokens.toArray(new Token[0]);
    }

    private List<MatchPair> backtrackLCS(int[][] dp, Token[] a, Token[] b) {
        List<MatchPair> matches = new ArrayList<>();
        int i = a.length, j = b.length;
        while (i > 0 && j > 0) {
            if (a[i-1].text.equals(b[j-1].text)) {
                matches.add(new MatchPair(i-1, j-1));
                i--; j--;
            } else if (dp[i-1][j] >= dp[i][j-1]) {
                i--;
            } else {
                j--;
            }
        }
        Collections.reverse(matches);
        return matches;
    }

    private List<DiffToken> generateDiffs(Token[] expected, Token[] actual, 
                                           List<MatchPair> matches) {
        List<DiffToken> diffs = new ArrayList<>();
        int ei = 0, ai = 0;
        
        for (MatchPair m : matches) {
            // 处理匹配点之前的间隙
            while (ei < m.expectedIdx || ai < m.actualIdx) {
                if (ei < m.expectedIdx && ai < m.actualIdx) {
                    // 同位置不同字 → wrong
                    diffs.add(DiffToken.wrong(expected[ei].position, 
                        expected[ei].text, actual[ai].text));
                    ei++; ai++;
                } else if (ei < m.expectedIdx) {
                    // expected 有但 actual 没有 → missing
                    diffs.add(DiffToken.missing(expected[ei].position, expected[ei].text));
                    ei++;
                } else {
                    // actual 有但 expected 没有 → extra
                    diffs.add(DiffToken.extra(actual[ai].position, actual[ai].text));
                    ai++;
                }
            }
            ei = m.expectedIdx + 1;
            ai = m.actualIdx + 1;
        }
        // 处理尾部剩余
        while (ei < expected.length || ai < actual.length) {
            if (ei < expected.length && ai < actual.length) {
                diffs.add(DiffToken.wrong(expected[ei].position, 
                    expected[ei].text, actual[ai].text));
                ei++; ai++;
            } else if (ei < expected.length) {
                diffs.add(DiffToken.missing(expected[ei].position, expected[ei].text));
                ei++;
            } else {
                diffs.add(DiffToken.extra(actual[ai].position, actual[ai].text));
                ai++;
            }
        }
        return diffs;
    }

    private ScoreResult calculateScores(Token[] expected, Token[] actual, 
                                         List<MatchPair> matches, 
                                         List<DiffToken> diffs) {
        int totalExpected = expected.length;
        int matchedCount = matches.size();
        
        // 准确率：匹配字符数 / 标准总字符数
        double accuracy = totalExpected > 0 
            ? (double) matchedCount / totalExpected * 100 : 0;
        
        // 语序正确率：最长连续正确段占整体的比例
        double maxConsecutive = calculateMaxConsecutive(expected, matches);
        double sequence = totalExpected > 0 
            ? maxConsecutive / totalExpected * 100 : 0;
        
        // 完整度：用户输入覆盖了多少标准文本
        long missingCount = diffs.stream()
            .filter(d -> d.type == DiffType.MISSING).count();
        double completeness = totalExpected > 0 
            ? (double)(totalExpected - missingCount) / totalExpected * 100 : 0;
        
        // 综合得分
        double combined = accuracy * 0.5 + sequence * 0.3 + completeness * 0.2;
        
        return new ScoreResult(
            round(accuracy, 2), round(sequence, 2), 
            round(completeness, 2), round(combined, 2));
    }

    private double calculateMaxConsecutive(Token[] expected, List<MatchPair> matches) {
        if (matches.isEmpty()) return 0;
        
        Set<Integer> matchedIndices = matches.stream()
            .map(m -> m.expectedIdx)
            .collect(Collectors.toSet());
        
        double maxLen = 0, curLen = 0;
        for (int i = 0; i < expected.length; i++) {
            if (matchedIndices.contains(i)) {
                curLen++;
                maxLen = Math.max(maxLen, curLen);
            } else {
                curLen = 0;
            }
        }
        return maxLen;
    }
}
```

#### 3.1.4 语义近似判定

对于"的/得/地"等同音异字、英文拼写轻微偏差等场景，引入**容错判定**：

```java
@Component
public class SemanticToleranceChecker {
    
    // 预定义的容错映射表（可配置化）
    private static final Map<String, Set<String>> TOLERANCE_GROUPS = Map.of(
        "的", Set.of("得", "地"),
        "做", Set.of("作"),
        "在", Set.of("再"),
        "他", Set.of("她", "它"),
        "那", Set.of("哪"),
        "象", Set.of("像"),
        "须", Set.of("需")
    );
    
    /**
     * 判断 actual 是否为 expected 的容错变体
     * @return true 表示虽不完全一致但可视为容错通过
     */
    public boolean isTolerable(String expected, String actual) {
        if (expected.equals(actual)) return true;
        
        // 检查容错组
        Set<String> group = TOLERANCE_GROUPS.get(expected);
        if (group != null && group.contains(actual)) {
            return true;
        }
        
        // 英文编辑距离 ≤ 1 视为容错（如 recieve → receive）
        if (isEnglishWord(expected) && isEnglishWord(actual)) {
            return levenshteinDistance(expected, actual) <= 1;
        }
        
        return false;
    }
    
    /**
     * 获取容错级别评分衰减系数
     * 精确匹配 = 1.0, 容错通过 = 0.7, 不匹配 = 0
     */
    public double getScoreMultiplier(String expected, String actual) {
        if (expected.equals(actual)) return 1.0;
        if (isTolerable(expected, actual)) return 0.7;
        return 0.0;
    }
}
```

### 3.2 智能分段算法 (SegmentationEngine)

#### 3.2.1 分段策略

不同学科/内容类型使用不同分段策略：

| 内容类型 | 分段策略 | 说明 |
|----------|----------|------|
| 古诗词 | 按句/联 | "床前明月光，疑是地上霜。" 为一段 |
| 现代文 | 按自然段/语义段 | 每段控制在 50-120 字 |
| 英语课文 | 按句子 | 每句为一段 |
| 历史知识点 | 按条目 | "1. xxx 2. xxx" 每条为一段 |
| 政治概念 | 按要点 | 分号/句号分隔的要点 |

#### 3.2.2 算法实现

```java
@Service
public class SegmentationEngine {
    
    /**
     * 对文本进行智能分段
     * @param text 原始文本
     * @param subject 学科类型
     * @param maxSegmentChars 每段最大字符数（默认 120）
     * @return 分段结果列表
     */
    public List<Segment> segment(String text, String subject, int maxSegmentChars) {
        return switch (subject) {
            case "chinese" -> segmentChinese(text, maxSegmentChars);
            case "english" -> segmentEnglish(text, maxSegmentChars);
            case "history", "politics", "geography" -> segmentSocialScience(text, maxSegmentChars);
            default -> segmentGeneric(text, maxSegmentChars);
        };
    }
    
    private List<Segment> segmentChinese(String text, int maxLen) {
        List<Segment> segments = new ArrayList<>();
        
        // 检测是否为古诗文（通过标点模式判断）
        if (isClassicalChinesePoem(text)) {
            return segmentByPoemLines(text);
        }
        
        // 现代文：按自然段分割
        String[] paragraphs = text.split("\n+");
        int index = 1;
        
        for (String para : paragraphs) {
            para = para.trim();
            if (para.isEmpty()) continue;
            
            if (para.length() <= maxLen) {
                segments.add(new Segment(index++, para));
            } else {
                // 超长段落按语义句号分割
                segments.addAll(splitLongParagraph(para, maxLen, index));
                index += segments.size(); // 简化
            }
        }
        return segments;
    }
    
    private List<Segment> segmentByPoemLines(String text) {
        List<Segment> segments = new ArrayList<>();
        // 古诗词按句号/感叹号/问号分割，每句为一段
        // "床前明月光，疑是地上霜。举头望明月，低头思故乡。"
        // → ["床前明月光，疑是地上霜。", "举头望明月，低头思故乡。"]
        String[] lines = text.split("(?<=[。！？])");
        int index = 1;
        for (String line : lines) {
            line = line.trim();
            if (!line.isEmpty()) {
                segments.add(new Segment(index++, line));
            }
        }
        return segments;
    }
    
    private List<Segment> segmentEnglish(String text, int maxLen) {
        List<Segment> segments = new ArrayList<>();
        // 按句子分割（句号+空格+大写字母）
        String[] sentences = text.split("(?<=[.!?])\\s+(?=[A-Z])");
        int index = 1;
        StringBuilder buffer = new StringBuilder();
        
        for (String sentence : sentences) {
            if (buffer.length() + sentence.length() + 1 > maxLen && buffer.length() > 0) {
                segments.add(new Segment(index++, buffer.toString().trim()));
                buffer = new StringBuilder();
            }
            if (buffer.length() > 0) buffer.append(" ");
            buffer.append(sentence);
        }
        if (buffer.length() > 0) {
            segments.add(new Segment(index++, buffer.toString().trim()));
        }
        return segments;
    }
    
    private List<Segment> segmentSocialScience(String text, int maxLen) {
        // 按编号条目或分号分割
        // "1. 第一次世界大战爆发于1914年；2. ..."
        String[] items = text.split("(?=\\d+[.、)）])|(?<=[；;])");
        if (items.length <= 1) {
            // 无编号条目，按分号/句号分割
            items = text.split("(?<=[；;。])");
        }
        int index = 1;
        List<Segment> segments = new ArrayList<>();
        for (String item : items) {
            item = item.trim();
            if (!item.isEmpty()) {
                segments.add(new Segment(index++, item));
            }
        }
        return segments;
    }
    
    // 判断是否为古诗文：包含典型标点模式、篇幅短、有押韵特征
    private boolean isClassicalChinesePoem(String text) {
        // 启发式判断：篇幅<300字 + 包含句号和逗号交替模式 + 无现代文长句
        if (text.length() > 300) return false;
        long commaCount = text.chars().filter(c -> c == '，' || c == ',').count();
        long periodCount = text.chars().filter(c -> c == '。' || c == '.' ).count();
        return commaCount > 0 && periodCount > 0 && commaCount >= periodCount;
    }
    
    private List<Segment> splitLongParagraph(String para, int maxLen, int startIndex) {
        List<Segment> segments = new ArrayList<>();
        // 在句号/问号/感叹号处断开，保证每段不超过maxLen
        StringBuilder buffer = new StringBuilder();
        int index = startIndex;
        for (int i = 0; i < para.length(); i++) {
            buffer.append(para.charAt(i));
            char c = para.charAt(i);
            if ((c == '。' || c == '？' || c == '！') && buffer.length() >= maxLen * 0.5) {
                segments.add(new Segment(index++, buffer.toString().trim()));
                buffer = new StringBuilder();
            }
        }
        if (buffer.length() > 0) {
            segments.add(new Segment(index, buffer.toString().trim()));
        }
        return segments;
    }
}
```

### 3.3 关键词自动提取 (KeywordExtractor)

#### 3.3.1 提取策略

采用**规则+统计混合方法**，无需依赖外部NLP库即可工作：

| 内容类型 | 提取策略 | 示例 |
|----------|----------|------|
| 古诗文 | 名词+动词+意象词 | "明月光"、"地上霜"、"思故乡" |
| 英语课文 | 实词（名词/动词/形容词） | "revolution", "significant" |
| 历史知识点 | 时间+人名+事件名 | "1914年"、"第一次世界大战" |

#### 3.3.2 代码示例

```java
@Service
public class KeywordExtractor {
    
    // 停用词表（虚词、助词等不需要记忆锚点的词）
    private static final Set<String> CHINESE_STOP_WORDS = Set.of(
        "的", "了", "在", "是", "我", "有", "和", "就", "不", "人", "都", "一",
        "一个", "上", "也", "很", "到", "说", "要", "去", "你", "会", "着",
        "没有", "看", "好", "自己", "这", "那", "之", "其", "以", "为"
    );
    
    // 英语停用词
    private static final Set<String> ENGLISH_STOP_WORDS = Set.of(
        "the", "a", "an", "is", "are", "was", "were", "be", "been", "being",
        "have", "has", "had", "do", "does", "did", "will", "would", "could",
        "should", "may", "might", "shall", "can", "need", "dare", "in", "on",
        "at", "to", "for", "with", "by", "from", "of", "and", "but", "or",
        "not", "no", "if", "then", "than", "so", "as", "it", "he", "she"
    );
    
    public List<KeywordItem> extract(String text, String subject) {
        return switch (subject) {
            case "chinese" -> extractChineseKeywords(text);
            case "english" -> extractEnglishKeywords(text);
            default -> extractGenericKeywords(text);
        };
    }
    
    private List<KeywordItem> extractChineseKeywords(String text) {
        List<KeywordItem> keywords = new ArrayList<>();
        // 使用基于规则的提取：
        // 1. 提取2-4字组合（中文词语多为2-4字）
        // 2. 过滤停用词
        // 3. 按TF排序取Top-N
        Map<String, Integer> freq = new HashMap<>();
        for (int len = 2; len <= 4; len++) {
            for (int i = 0; i <= text.length() - len; i++) {
                String word = text.substring(i, i + len);
                // 去除包含标点的片段
                if (word.chars().anyMatch(c -> isPunctuation((char)c))) continue;
                if (CHINESE_STOP_WORDS.contains(word)) continue;
                freq.merge(word, 1, Integer::sum);
            }
        }
        
        // 取频率最高的词作为关键词，限制每段最多5个
        return freq.entrySet().stream()
            .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
            .limit(10)
            .map(e -> new KeywordItem(e.getKey(), 0, classifyKeyword(e.getKey())))
            .collect(Collectors.toList());
    }
    
    private String classifyKeyword(String word) {
        // 简单启发式分类
        if (word.matches(".*[0-9]+.*")) return "time";       // 含数字→时间相关
        if (word.matches(".*[山水花鸟风月].*")) return "imagery"; // 含自然意象
        return "concept";
    }
}
```

### 3.4 语音背诵处理管线 (VoiceRecitationPipeline)

#### 3.4.1 处理流程

```

        │
        ▼
┌─────────────────────┐
│ 1. 语音预处理        │  ← 降噪、音量归一化、VAD端点检测
│    (AudioPreprocessor)│
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐

└─────────┬───────────┘
          │
          ▼

│ 4. 发音评估(可选)    │  ← 调用语音服务 → 音准/流利度评分

          │

└─────────┬───────────┘

┌─────────────────────┐
│ 6. 生成AI反馈       │  ← 调用大模型生成改进建议
│    (AIFeedbackGen)   │
└─────────────────────┘
```

#### 3.4.2 关键代码

```java
@Service
@Slf4j
public class VoiceRecitationPipeline {
    
    @Autowired private AsrClient asrClient;
    @Autowired private TextDiffEngine textDiffEngine;
    @Autowired private AIFeedbackGenerator feedbackGenerator;
    @Autowired private RecitationEventPublisher eventPublisher;
    
    // 语音背诵最大时长限制
    private static final int MAX_AUDIO_DURATION_SECONDS = 300; // 5分钟
    // 最大文件大小
    private static final long MAX_AUDIO_SIZE_BYTES = 20 * 1024 * 1024; // 20MB
    
    public VoiceRecitationResult process(VoiceRecitationRequest request) {
        long startTime = System.currentTimeMillis();
        
        // 参数校验
        validateAudioFile(request.getAudioFile());
        
        // Step 1: 语音识别
        AsrResult asrResult;
        try {
            asrResult = asrClient.recognize(
                request.getAudioFile(),
                request.getLanguage(),  // "zh" or "en"
                AsrOption.builder()
                    .enablePunctuation(true)
                    .enableIntermediateResult(false)
                    .build()
            );
        } catch (AsrException e) {
            log.warn("ASR识别失败, userId={}, materialId={}, error={}", 
                request.getUserId(), request.getMaterialId(), e.getMessage());
            throw new ServiceException(ErrorCode.ASR_FAILED, 
                "语音识别失败，请重新录制或使用文字模式");
        }
        
        String recognizedText = asrResult.getText();
        
        // 如果ASR返回空文本
        if (StringUtils.isBlank(recognizedText)) {
            return VoiceRecitationResult.builder()
                .status("SILENCE_DETECTED")
                .message("未检测到有效语音内容，请重新录制")
                .build();
        }
        
        // Step 2: 文本对比
        String expectedText = getExpectedText(request.getMaterialId(), 
            request.getSegmentIndex());
        DiffResult diffResult = textDiffEngine.diff(expectedText, recognizedText);
        
        // Step 3: 综合评分
        double contentScore = diffResult.getScores().getCombined();
        double fluencyScore = calculateFluency(asrResult, request.getAudioFile());
        
        double finalScore;
        if (request.isIncludePronunciation()) {
            double pronScore = asrResult.getPronunciationScore(); // ASR服务提供
            finalScore = contentScore * 0.6 + pronScore * 0.2 + fluencyScore * 0.2;
        } else {
            finalScore = contentScore * 0.75 + fluencyScore * 0.25;
        }
        
        // Step 4: 生成AI反馈（异步，不阻塞主流程）
        String feedback = null;
        if (diffResult.getDiffTokens().stream()
                .anyMatch(d -> d.getSeverity() == Severity.HIGH)) {
            // 有关键词错误时生成个性化反馈
            feedback = feedbackGenerator.generateRecitationFeedback(
                expectedText, recognizedText, diffResult, request.getSubject());
        }
        
        long duration = System.currentTimeMillis() - startTime;
        
        return VoiceRecitationResult.builder()
            .recognizedText(recognizedText)
            .diffResult(diffResult)
            .contentScore(contentScore)
            .fluencyScore(fluencyScore)
            .finalScore(round(finalScore, 2))
            .feedback(feedback)
            .processingTimeMs(duration)
            .build();
    }
    
    /**
     * 计算流利度评分
     * 基于ASR返回的时间戳信息：语速、停顿、重复
     */
    private double calculateFluency(AsrResult asrResult, AudioFile audio) {
        // 基准语速：中文 3-4 字/秒，英文 2-3 词/秒
        double durationSeconds = audio.getDurationSeconds();
        if (durationSeconds <= 0) return 0;
        
        double charsPerSecond = (double) asrResult.getText().length() / durationSeconds;
        
        // 语速评分：越接近基准语速分越高
        double optimalRate = 3.5; // 字/秒
        double rateDeviation = Math.abs(charsPerSecond - optimalRate) / optimalRate;
        double rateScore = Math.max(0, 100 - rateDeviation * 100);
        
        // 停顿评分：ASR返回的停顿次数
        int pauseCount = asrResult.getLongPauseCount(); // >500ms的停顿
        double pauseScore = Math.max(0, 100 - pauseCount * 10);
        
        return rateScore * 0.5 + pauseScore * 0.5;
    }
}
```

### 3.5 记忆效果量化模型 (MemoryEffectEvaluator)

#### 3.5.1 单次检测评分模型

```
single_score = accuracy × W_acc + sequence × W_seq + completeness × W_comp

其中:
  W_acc  = 0.5  (内容准确度权重最高)
  W_seq  = 0.3  (语序正确性其次)
  W_comp = 0.2  (完整度最低)
```

#### 3.5.2 跨次记忆强度模型

综合多次背诵记录，量化某篇材料的记忆强度：

```
memory_strength = Σ(last_n_scores × decay_weights) / Σ(decay_weights)

其中:
  last_n_scores: 最近N次检测结果评分
  decay_weights: 衰减权重 [1.0, 0.8, 0.6, 0.4, 0.2] (最近的最大)
  N = min(5, 历史记录数)
```

#### 3.5.3 保持水平判定

```java
@Service
public class MemoryEffectEvaluator {
    
    private static final double[] DECAY_WEIGHTS = {1.0, 0.8, 0.6, 0.4, 0.2};
    
    /**
     * 计算材料级记忆强度
     */
    public MemoryStrengthResult evaluateStrength(Long userId, Long materialId) {
        // 获取最近5次记录
        List<UserRecitationRecord> recentRecords = recordRepository
            .findTop5ByUserIdAndMaterialIdOrderByCreatedAtDesc(userId, materialId);
        
        if (recentRecords.isEmpty()) {
            return MemoryStrengthResult.empty();
        }
        
        // 加权平均
        double weightedSum = 0;
        double weightSum = 0;
        for (int i = 0; i < recentRecords.size() && i < DECAY_WEIGHTS.length; i++) {
            double score = recentRecords.get(i).getMasteryScore();
            weightedSum += score * DECAY_WEIGHTS[i];
            weightSum += DECAY_WEIGHTS[i];
        }
        double strength = round(weightedSum / weightSum, 2);
        
        // 判定保持水平
        RetentionLevel level = determineRetentionLevel(
            strength, recentRecords.get(0).getReviewCount(),
            recentRecords.size()
        );
        
        return MemoryStrengthResult.builder()
            .strength(strength)
            .retentionLevel(level)
            .totalReviews(recentRecords.size())
            .latestScore(recentRecords.get(0).getMasteryScore())
            .trend(calculateTrend(recentRecords))
            .build();
    }
    
    private RetentionLevel determineRetentionLevel(
            double strength, int reviewCount, int totalRecords) {
        if (strength >= 95 && reviewCount >= 3) return RetentionLevel.MASTERED;
        if (strength >= 85 && reviewCount >= 2) return RetentionLevel.LONG_TERM;
        if (strength >= 70 && reviewCount >= 1) return RetentionLevel.MEDIUM_TERM;
        if (strength >= 50) return RetentionLevel.SHORT_TERM;
        return RetentionLevel.NEW;
    }
    
    private String calculateTrend(List<UserRecitationRecord> records) {
        if (records.size() < 2) return "stable";
        double latest = records.get(0).getMasteryScore();
        double previous = records.get(1).getMasteryScore();
        double diff = latest - previous;
        if (diff > 10) return "improving";
        if (diff < -10) return "declining";
        return "stable";
    }
}
```

## 6. 错误处理与降级策略

### 6.1 异常场景与处理

| 场景 | 错误码 | 处理策略 |
|------|--------|----------|
| 材料不存在 | `MATERIAL_NOT_FOUND` | 返回404，提示重新选择 |
| 用户无权限（非会员访问付费内容） | `ACCESS_DENIED` | 返回403，提示升级会员 |
| ASR识别失败 | `ASR_FAILED` | 返回降级提示，建议切换文字模式 |
| ASR识别为空（静音） | `SILENCE_DETECTED` | 返回提示，建议检查麦克风 |
| 音频文件过大 | `FILE_TOO_LARGE` | 返回413，限制20MB |
| 音频时长超限 | `DURATION_EXCEEDED` | 返回400，限制5分钟 |
| 每日检测次数超限 | `DAILY_LIMIT_EXCEEDED` | 返回429，提示明日继续或升级会员 |
| 间隔重复引擎不可用 | `SR_ENGINE_UNAVAILABLE` | 本地降级计算下次复习时间，不阻塞主流程 |
| AI反馈生成超时 | `AI_FEEDBACK_TIMEOUT` | 返回核心检测结果，feedback字段为null |
| Redis缓存穿透 | `CACHE_MISS` | 直接查库并回填缓存 |

### 6.2 降级策略

```
┌─────────────────────────────────────────────────────────┐
│                    降级层级                               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Level 0: 正常服务                                      │
│  ├─ ASR + 文本对比 + AI反馈 + 间隔重复 全部可用        │
```

### 6.3 重试与补偿机制

```java
@Service
public class RecitationCompensationService {
    
    /**
     * 异步补偿任务：处理失败的后续操作
     * 由定时任务每5分钟扫描一次
     */
    @Scheduled(fixedDelay = 300000)
    public void compensatePendingOperations() {
        // 1. 查找未更新复习计划的背诵记录
        List<UserRecitationRecord> pendingRecords = recordRepository
            .findByReviewPlanUpdatedFalseAndCreatedAtAfter(
                LocalDateTime.now().minusHours(1));
        
        for (UserRecitationRecord record : pendingRecords) {
            try {
                spacedRepetitionClient.updateReviewItem(buildRequest(record));
                record.setReviewPlanUpdated(true);
                recordRepository.save(record);
            } catch (Exception e) {
                log.warn("补偿更新复习计划失败, recordId={}, error={}",
                    record.getId(), e.getMessage());
            }
        }
        
        // 2. 查找未更新错误热力图的记录
        List<UserRecitationRecord> heatmapPending = recordRepository
            .findByHeatmapUpdatedFalseAndCreatedAtAfter(
                LocalDateTime.now().minusHours(1));
        
        for (UserRecitationRecord record : heatmapPending) {
            try {
                updateErrorHeatmap(record);
                record.setHeatmapUpdated(true);
                recordRepository.save(record);
            } catch (Exception e) {
                log.warn("补偿更新热力图失败, recordId={}", record.getId());
            }
        }
    }
}
```

## 10. AI反馈生成策略

### 10.1 触发条件

并非每次背诵检测都调用AI生成反馈。触发条件：

1. 存在 high severity 错误（关键词错误）
2. 综合得分低于 60 分
3. 连续两次同一段落未通过
4. 用户主动请求AI指导

### 10.2 Prompt模板

```
你是一位经验丰富的{subject}教师，正在帮助学生提高背诵效果。

【学生信息】
- 学段: {gradeLevel}
- 背诵材料: {materialTitle}

【背诵结果】
- 标准文本: {expectedText}
- 学生输入: {actualText}
- 得分: {score}/100
- 错误详情: {diffSummary}

【任务】
1. 指出学生错误的具体位置
2. 分析错误原因（同音混淆/形近混淆/记忆遗漏）
3. 提供记忆技巧（联想记忆/口诀/场景联想）
4. 给出鼓励性的反馈

【要求】
- 语言风格适配{gradeLevel}学生认知水平
- 反馈简洁，不超过100字
- 不要重复展示标准文本，学生已能看到
- 重点是记忆方法而非简单纠错
```

### 10.3 反馈缓存

相同错误模式的反馈可缓存复用：

```java
@Service
public class AIFeedbackCache {
    
    public String getOrCreateFeedback(String materialId, String errorFingerprint, 
                                       String gradeLevel) {
        String cacheKey = String.format("recitation:feedback:%s:%s:%s",
            materialId, errorFingerprint, gradeLevel);
        
        String cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) return cached;
        
        String feedback = aiClient.generate(prompt);
        redisTemplate.opsForValue().set(cacheKey, feedback, Duration.ofDays(7));
        return feedback;
    }
    
    /**
     * 错误指纹: materialId + segmentIndex + errorType + expectedChar
     * "1001:1:wrong:霜" → 相同位置相同错误可复用反馈
     */
    public String buildErrorFingerprint(List<DiffToken> diffs) {
        return diffs.stream()
            .filter(d -> d.getSeverity() == Severity.HIGH)
            .map(d -> String.format("%d:%s:%s", d.getPosition(), d.getType(), d.getExpected()))
            .collect(Collectors.joining("|"));
    }
}
```

## 11. 安全与合规

### 11.1 内容安全

- 自定义背诵材料需经过文本安全审核（敏感词+AI审核）
- AI生成的反馈需通过安全过滤
- 用户语音文件不长期存储，检测完成后72小时清理

### 11.2 数据隐私

- 语音文件存储使用加密传输(HTTPS) + 加密存储(AES-256)
- 背诵记录仅用户本人和绑定家长可见
- 账户注销时删除所有背诵相关数据

### 11.3 防护机制

- 文本检测接口：每用户每分钟最多30次（防刷）
- 语音检测接口：每用户每分钟最多10次（ASR成本较高）
- 自定义材料创建：每用户每天最多20条
