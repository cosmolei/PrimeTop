# 多模态输入统一处理与智能路由引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

多模态输入统一处理与智能路由引擎（Multimodal Input Router, 以下简称 MIR）是 PrimeTop 客户端与服务端之间的**输入编排层**。所有用户输入——文字提问、语音提问、拍照搜题、混合输入（图片+文字描述）——均由 MIR 统一接收、预处理、意图分类和路由分发。

MIR 不直接处理业务逻辑，而是将输入转化为标准化的内部请求，分发给下游服务（AI对话引擎、OCR管线、ASR服务、题目服务等）。

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 意图分类准确率 | ≥ 96%（纯文字输入），≥ 93%（语音/图片） |
| 路由决策延迟 | ≤ 50ms（不含下游处理时间） |
| 混合输入处理成功率 | ≥ 98% |
| 端到端首 token 延迟 | ≤ 3s（文字），≤ 5s（图片/语音） |
| 降级成功率 | 99.9%（主路由失败时自动切换备选路径） |

### 1.3 解决的核心问题

1. **输入入口多**：AI辅导页、拍题页、同步课堂、错题页等 10+ 个页面均可发起输入
2. **模态组合多**：纯文字、纯语音、纯图片、图片+文字、语音+图片、连续追问等
3. **下游服务多**：LLM对话、OCR管线、ASR、题目匹配、知识库检索等
4. **成本差异大**：文字问答约 ¥0.01/次，图片OCR约 ¥0.05/次，多模型推理约 ¥0.15/次
5. **失败模式多**：网络超时、OCR识别失败、ASR噪声、模型过载等

### 1.4 模块边界

**本模块负责：**
- 输入接收与标准化
- 输入类型检测与预处理调度
- 意图分类（问问题、搜题目、查知识点、闲聊等）
- 路由决策与下游分发
- 多步骤编排（如：图片→OCR→AI解析）
- 配额预检与成本估算
- 降级与容错
- 输入侧埋点与指标

**不在本模块范围：**
- AI对话管理与上下文维护（→ AI对话引擎与会话管理）
- 图片OCR处理（→ 图片处理与OCR识别管线）
- 语音识别与合成（→ 语音服务(ASR-TTS)）
- 题目匹配与解析（→ 拍照搜题与习题答疑）
- Prompt编排与模板（→ AI-Prompt编排与场景模板系统）
- 答案管控策略（→ 答案管控与渐进式提示引擎）

## 3. 意图分类器设计

### 3.1 分类策略

采用**规则优先 + 模型兜底**的两级分类策略，优先使用低延迟的规则匹配，匹配失败时调用轻量分类模型。

```
输入 → [规则引擎(≤5ms)] → 命中? → 返回意图
                          ↓ 未命中
        [轻量分类模型(≤30ms)] → 返回意图
                          ↓ 置信度 < 阈值
        [默认路由(按来源场景)] → 返回兜底意图
```

### 3.2 规则引擎

```python
class IntentRuleEngine:
    """基于规则的意图分类器"""
    
    # 规则优先级：数字越小优先级越高
    RULES: List[IntentRule] = [

            priority=30,

            },
            intent=IntentType.PROBLEM_SOLVING,
            confidence=0.80,
        ),
        
        # ── 图片+文字混合 ──
        IntentRule(
            name="image_text_hybrid",
            priority=25,
            conditions={
                "modality": InputModality.IMAGE_TEXT,
                "text_match_any": [
                    "这道题", "帮我看看", "不明白", "怎么解",

class IntentRule(BaseModel):
    """意图规则定义"""
    name: str
    priority: int
    conditions: Dict[str, Any]
    intent: IntentType
    confidence: float
    
    def match(self, input_data: MultimodalInput) -> bool:
        for key, expected in self.conditions.items():
            if key == "source_scene":
                if input_data.source_scene != expected:
                    return False
            elif key == "source_scene_not":
                if input_data.source_scene in expected:
                    return False
            elif key == "modality":
                if input_data.modality != expected:
                    return False
            elif key == "modality_in":
                if input_data.modality not in expected:
                    return False
            elif key == "text_match_any":
                if not input_data.text_content:
                    return False
                if not any(kw in input_data.text_content for kw in expected):
                    return False
        return True
```

### 4.2 路由决策流程

```python
class RouteDecisionEngine:
    """路由决策引擎"""
    
    def __init__(self):
        self.rule_engine = IntentRuleEngine()
        self.intent_classifier = IntentClassifier()  # 轻量模型
        self.route_table = RouteTable()
        self.quota_checker = QuotaChecker()
    
    async def decide(self, input_data: MultimodalInput) -> RouteDecision:
        """完整路由决策流程"""
        
        # Step 1: 规则匹配意图
        intent, confidence = self.rule_engine.classify(input_data)
        
        # Step 2: 规则未命中则调用模型
        if intent is None or confidence < 0.80:
            model_intent, model_conf = await self.intent_classifier.classify(input_data)
            if model_conf > confidence:
                intent, confidence = model_intent, model_conf
        
        # Step 3: 低置信度兜底
        if confidence < 0.70:
            intent = self._get_default_intent(input_data.source_scene)
            confidence = 0.50
        
        # Step 4: 安全预检（快速关键词过滤）
        safety_result = self._quick_safety_check(input_data)
        if safety_result.is_rejected:
            intent = IntentType.SAFETY_REJECT
            confidence = 1.0
        
        # Step 5: 查路由表
        route_key = (intent, input_data.modality)
        # 尝试精确匹配，失败则降级模态
        route_config = self.route_table.ROUTES.get(route_key)
        if route_config is None:
            # 降级：统一用TEXT模态的路由
            route_key = (intent, InputModality.TEXT)
            route_config = self.route_table.ROUTES.get(route_key)
        if route_config is None:
            # 最终兜底：AI对话
            route_key = (IntentType.PROBLEM_SOLVING, InputModality.TEXT)
            route_config = self.route_table.ROUTES.get(route_key)
        
        # Step 6: 配额预检
        cost_estimate = self._estimate_cost(route_config, input_data)
        quota_result = await self.quota_checker.check(
            user_id=input_data.user_id,
            route_type=route_config.route_type,
            estimated_cost=cost_estimate,
        )
        
        if not quota_result.passed:
            return RouteDecision(
                input_id=input_data.input_id,
                route_type=RouteType.REJECT,
                intent=intent,
                confidence=confidence,
                downstream_services=[],
                estimated_cost=cost_estimate,
                estimated_latency_ms=0,
                metadata={"reject_reason": "quota_exceeded", "quota_message": quota_result.message},
            )
        
        # Step 7: 生成降级预案
        degradation_plan = self._build_degradation_plan(route_config)
        
        # Step 8: 估算延迟
        estimated_latency = sum(s.timeout_ms for s in route_config.pipeline)
        
        return RouteDecision(
            input_id=input_data.input_id,
            route_type=route_config.route_type,
            intent=intent,
            confidence=confidence,
            downstream_services=self._to_service_calls(route_config),
            estimated_cost=cost_estimate,
            estimated_latency_ms=estimated_latency,
            degradation_plan=degradation_plan,
        )
```

## 5. 编排执行器设计

### 5.1 管道执行模型

编排执行器负责按管道定义顺序调用下游服务，管理数据流转和错误处理。

```python
class PipelineExecutor:
    """管道编排执行器"""
    
    def __init__(self):
        self.service_clients: Dict[str, ServiceClient] = {}
        self.transform_registry = TransformRegistry()
    
    async def execute(
        self,
        input_data: MultimodalInput,
        decision: RouteDecision,
    ) -> AsyncIterator[StreamChunk]:
        """执行管道，返回流式结果"""
        
        route_config = self._get_route_config(decision)
        context = PipelineContext(
            input_data=input_data,
            decision=decision,
            step_results={},
        )
        
        for i, step in enumerate(route_config.pipeline):
            context.current_step_index = i
            
            try:
                # 转换输入
                transform_fn = self.transform_registry.get(step.input_transform)
                step_input = transform_fn(context)
                
                # 调用下游服务
                if step.is_streaming:
                    async for chunk in self._call_streaming(step, step_input, context):
                        # 流式结果立即返回给客户端
                        yield StreamChunk(
                            type="stream_data",
                            step_id=step.step_id,
                            data=chunk,
                        )
                        context.append_stream_buffer(step.step_id, chunk)
                else:
                    result = await self._call_sync(step, step_input, context)
                    context.step_results[step.step_id] = result
                    yield StreamChunk(
                        type="step_complete",
                        step_id=step.step_id,
                        data=result,
                    )
                    
            except StepTimeoutError:
                if step.is_optional:
                    logger.warning(f"Optional step {step.step_id} timed out, skipping")
                    context.step_results[step.step_id] = None
                    yield StreamChunk(
                        type="step_skipped",
                        step_id=step.step_id,
                        reason="timeout",
                    )
                    continue
                    
                if step.fallback_service:
                    # 尝试备选服务
                    result = await self._try_fallback(step, step_input, context)
                    if result:
                        context.step_results[step.step_id] = result
                        continue
                
                # 非可选步骤失败，触发降级
                if decision.degradation_plan:
                    async for chunk in self._execute_degradation(
                        decision.degradation_plan, context
                    ):
                        yield chunk
                    return
                
                raise PipelineExecutionError(
                    f"Step {step.step_id} failed, no degradation available"
                )
                
            except StepError as e:
                # 同上的错误处理逻辑
                ...
        
        # 管道完成
        yield StreamChunk(
            type="pipeline_complete",
            data={"input_id": input_data.input_id},
        )

class PipelineContext(BaseModel):
    """管道执行上下文"""
    input_data: MultimodalInput
    decision: RouteDecision
    step_results: Dict[str, Any]
    current_step_index: int = 0
    stream_buffers: Dict[str, List[Any]] = {}
    
    class Config:
        arbitrary_types_allowed = True
    
    def append_stream_buffer(self, step_id: str, chunk: Any):
        if step_id not in self.stream_buffers:
            self.stream_buffers[step_id] = []
        self.stream_buffers[step_id].append(chunk)

class StreamChunk(BaseModel):
    """流式响应块"""
    type: Literal[
        "step_complete",      # 非流式步骤完成
        "step_skipped",       # 可选步骤被跳过
        "stream_data",        # 流式数据块
        "pipeline_complete",  # 整个管道完成
        "degradation",        # 降级通知
        "error",              # 错误信息
    ]
    step_id: Optional[str] = None
    data: Optional[Any] = None
    reason: Optional[str] = None
```

### 6.1 成本估算模型

```python
class CostEstimator:
    """调用成本估算器"""
    
    # 单位成本表 (元)
    UNIT_COSTS = {
        "llm_input_per_1k_tokens": 0.005,    # 平均输入单价
        "llm_output_per_1k_tokens": 0.015,   # 平均输出单价
        "ocr_per_image": 0.03,               # 单张图片OCR
        "asr_per_minute": 0.02,              # 语音转写
        "tts_per_1k_chars": 0.01,            # TTS合成
        "embedding_per_1k_tokens": 0.0005,   # 向量化
        "moderation_per_call": 0.001,        # 内容审核
    }
    
    # 意图预估token表
    INTENT_TOKEN_ESTIMATES = {
        IntentType.PROBLEM_SOLVING: {"input": 800, "output": 600},
        IntentType.CONCEPT_EXPLANATION: {"input": 500, "output": 800},
        IntentType.QUESTION_IDENTIFY: {"input": 600, "output": 500},
        IntentType.COMPOSITION_ASSIST: {"input": 1000, "output": 1200},
        IntentType.KNOWLEDGE_QUERY: {"input": 400, "output": 600},
        IntentType.RECITATION_PRACTICE: {"input": 300, "output": 200},
        IntentType.SIMILAR_QUESTION: {"input": 600, "output": 800},
    }
    
    def estimate(self, decision: RouteDecision, input_data: MultimodalInput) -> EstimatedCost:
        total_cost = 0.0
        llm_tokens = 0
        ocr_calls = 0
        asr_duration = 0.0
        
        # 估算每个管道步骤的成本
        for step in decision.downstream_services:
            if step.service == "ocr_service":
                ocr_calls = len(input_data.image_file_ids or [1])
                total_cost += ocr_calls * self.UNIT_COSTS["ocr_per_image"]
                
            elif step.service == "asr_service":
                asr_duration = (input_data.voice_duration_ms or 5000) / 1000.0
                total_cost += (asr_duration / 60) * self.UNIT_COSTS["asr_per_minute"]
                
            elif step.service == "ai_dialog_engine":
                token_est = self.INTENT_TOKEN_ESTIMATES.get(
                    decision.intent, {"input": 600, "output": 600}
                )
                llm_tokens = token_est["input"] + token_est["output"]
                input_cost = (token_est["input"] / 1000) * self.UNIT_COSTS["llm_input_per_1k_tokens"]
                output_cost = (token_est["output"] / 1000) * self.UNIT_COSTS["llm_output_per_1k_tokens"]
                total_cost += input_cost + output_cost
                
            elif step.service == "tts_service":
                # TTS 大约 200 字
                total_cost += (200 / 1000) * self.UNIT_COSTS["tts_per_1k_chars"]
                
            elif step.service == "rag_service":
                # 向量化检索成本
                total_cost += self.UNIT_COSTS["embedding_per_1k_tokens"] * 2  # query + docs
        
        return EstimatedCost(
            llm_tokens_estimate=llm_tokens,
            ocr_calls=ocr_calls,
            asr_duration_seconds=asr_duration,
            total_estimated_cost_cny=round(total_cost, 4),
            quota_check_passed=True,  # 待配额检查更新
        )
```

```python
class QuotaChecker:
    """用户配额检查器（调用用户额度与API调用管控系统）"""
    
    async def check(
        self,
        user_id: int,
        route_type: RouteType,
        estimated_cost: EstimatedCost,
    ) -> QuotaResult:
        """
        调用额度服务的预检接口。
        注意：此处仅做预检（不扣减），实际扣减在管道执行完成后。
        """
        
        # 映射路由类型到额度类型
        quota_type = self._route_to_quota_type(route_type)
        
        # 调用额度服务预检API
        response = await http_post(
            "/api/v1/quota/precheck",
            {
                "user_id": user_id,
                "quota_type": quota_type,
                "estimated_cost": {
                    "llm_tokens": estimated_cost.llm_tokens_estimate,
                    "ocr_calls": estimated_cost.ocr_calls,
                    "asr_seconds": estimated_cost.asr_duration_seconds,
                },
            },
            timeout_ms=500,
        )
        
        if response["passed"]:
            return QuotaResult(passed=True)
        else:
            return QuotaResult(
                passed=False,
                message=response.get("message", "今日使用次数已达上限"),
                upgrade_hint=response.get("upgrade_hint"),  # 会员升级提示
            )
    
    @staticmethod
    def _route_to_quota_type(route_type: RouteType) -> str:
        mapping = {
            RouteType.AI_DIALOG: "ai_chat",
            RouteType.PHOTO_SEARCH: "photo_search",
            RouteType.VOICE_CHAT: "voice_chat",
            RouteType.KNOWLEDGE_SEARCH: "knowledge_search",
            RouteType.COMPOSITION_HELP: "composition",
            RouteType.RECITATION_CHECK: "recitation",
            RouteType.TOOL_QUERY: "tool_query",  # 工具查询通常免费
        }
        return mapping.get(route_type, "ai_chat")
```

## 7. 降级策略

### 7.1 降级层级

```
Level 0: 正常路由（全功能）
    ↓ 主服务不可用
Level 1: 备选服务（同功能降级模型）
    ↓ 备选也不可用
Level 2: 功能降级（减少处理步骤）
    ↓ 核心步骤失败
Level 3: 兜底响应（缓存/提示重试）
    ↓ 完全不可用
Level 4: 离线模式（客户端本地缓存）
```

### 7.2 降级预案生成

```python
class DegradationPlanner:
    """降级预案生成器"""
    
    def build_plan(self, route_config: RouteConfig) -> DegradationPlan:
        plan = DegradationPlan(
            route_type=route_config.route_type,
            levels=[],
        )
        
        # Level 2: 简化管道（移除可选步骤）
        simplified_pipeline = [
            step for step in route_config.pipeline
            if not step.is_optional
        ]
        if len(simplified_pipeline) < len(route_config.pipeline):
            plan.levels.append(DegradationLevel(
                level=2,
                description="移除非核心步骤（RAG检索、TTS等）",
                pipeline=simplified_pipeline,
            ))
        
        # Level 3: 兜底响应
        plan.levels.append(DegradationLevel(
            level=3,
            description="返回缓存或提示稍后重试",
            action="cache_or_retry_hint",
            fallback_message="学习助手正在休息中，请稍等一会儿再试~",
        ))
        
        return plan

class DegradationPlan(BaseModel):
    route_type: RouteType
    levels: List["DegradationLevel"]

class DegradationLevel(BaseModel):
    level: int
    description: str
    pipeline: Optional[List[PipelineStep]] = None
    action: Optional[str] = None
    fallback_message: Optional[str] = None
```

### 7.3 具体降级场景

| 场景 | 触发条件 | 降级策略 |
|------|----------|----------|
| OCR服务不可用 | 连续3次超时/错误 | 提示"识别服务繁忙"，建议手动输入题目 |
| ASR识别失败 | 语音转写为空或置信度<0.5 | 提示"没听清，请再说一次或打字提问" |
| RAG检索超时 | 检索服务>2s无响应 | 跳过RAG，直接用模型对话（无知识库增强） |
| LLM主模型过载 | 主模型返回429 | 切换备选模型（低成本模型） |
| LLM全部不可用 | 所有模型返回错误 | 返回缓存中相似问题的回答 |
| 图片过大/过暗 | 客户端预检失败 | 提示重新拍照（客户端提示，不经过MIR） |
| 配额不足 | 用户免费额度用完 | 提示升级会员或等待次日重置 |
| 网络断开 | 客户端检测到离线 | 客户端本地缓存答案（仅常见问题） |

```dart
    );
    return _sendInput(input);
  }

  /// 发送语音输入
  Future<Stream<MirEvent>> sendVoice({
    required String voiceFilePath,
    required int durationMs,
    required SourceScene scene,
    String? sessionId,
  }) async {
    // 上传语音文件
    final fileId = await _uploadFile(voiceFilePath);
    
    final input = MultimodalInput(
      inputId: _generateId(),
      modality: InputModality.voice,
      sourceScene: scene,
      clientTimestamp: DateTime.now().millisecondsSinceEpoch,
      userId: _contextProvider.userId,
      studentProfile: await _contextProvider.current,
      voiceFileId: fileId,
      voiceDurationMs: durationMs,
      voiceLanguageHint: 'zh',
      sessionId: sessionId,
      deviceInfo: await _deviceProvider.info,
      networkType: await _networkType,
      appVersion: await _appVersion,
      clientCapabilities: _capabilities,
    );
    return _sendInput(input);
  }

  /// 统一发送：通过SSE接收流式响应
  Stream<MirEvent> _sendInput(MultimodalInput input) async* {
    final response = await _dio.post<ResponseBody>(
      '/api/v1/mir/input',
      data: input.toJson(),
      options: Options(
        responseType: ResponseType.stream,
        headers: {'Accept': 'text/event-stream'},
      ),
    );
    
    yield* _parseSSE(response.data!.stream)
        .map((sse) => _toMirEvent(sse));
  }

  MirEvent _toMirEvent(SSEMessage sse) {
    switch (sse.event) {
      case 'route_decision':
        return MirRouteDecisionEvent.fromJson(sse.data);
      case 'step_complete':
        return MirStepCompleteEvent.fromJson(sse.data);
      case 'stream_data':
        return MirStreamDataEvent.fromJson(sse.data);
      case 'pipeline_complete':
        return MirPipelineCompleteEvent.fromJson(sse.data);
      case 'error':
        return MirErrorEvent.fromJson(sse.data);
      default:
        return MirUnknownEvent(raw: sse);
    }
  }
}

}

  final String intent;
```

### 9.2 客户端状态管理

```dart
/// MIR 输入状态管理 (Riverpod)
final mirInputProvider = StateNotifierProvider<MirInputNotifier, MirInputState>((ref) {
  return MirInputNotifier(ref.read(mirClientProvider));
});

class MirInputState {
  final bool isSending;
  final String? currentInputId;
  final String? displayAction;        // 当前处理阶段提示
  final List<StreamBuffer> buffers;   // 流式数据缓冲
  final String? error;                // 错误信息
  final MirRouteDecisionEvent? lastRoute; // 最近路由决策
  
  const MirInputState({
    this.isSending = false,
    this.currentInputId,
    this.displayAction,
    this.buffers = const [],
    this.error,
    this.lastRoute,
  });
  
  MirInputState copyWith({...}) => MirInputState(...);
}

class MirInputNotifier extends StateNotifier<MirInputState> {
  final MirClient _client;
  
  MirInputNotifier(this._client) : super(const MirInputState());
  
  Future<void> sendText(String text, SourceScene scene) async {
    state = state.copyWith(isSending: true, error: null);
    
    try {
      final eventStream = await _client.sendText(
        text: text, scene: scene,
      );
      
      await for (final event in eventStream) {
        if (event is MirRouteDecisionEvent) {
          state = state.copyWith(
            displayAction: event.displayAction,
            lastRoute: event,
          );
        } else if (event is MirStreamDataEvent) {
          // 追加流式数据
          state = state.copyWith(
            buffers: [...state.buffers, StreamBuffer.fromEvent(event)],
          );
        } else if (event is MirPipelineCompleteEvent) {
          state = state.copyWith(isSending: false);
        } else if (event is MirErrorEvent) {
          state = state.copyWith(
            isSending: false,
            error: event.userMessage,
          );
        }
      }
    } catch (e) {
      state = state.copyWith(
        isSending: false,
        error: '网络不给力，请稍后再试',
      );
    }
  }
}
```

```python
        "MIR-5001": "这个问题我无法回答，请试试学习相关的问题吧",
    }
    
    def get_user_message(
        self,
        error_code: MIRErrorCode,
        student_context: Optional[StudentContext] = None,
        membership_tier: Optional[str] = None,
    ) -> str:
        msg = self.USER_MESSAGES.get(error_code.value, "出了点问题，请稍后再试")
        
        if isinstance(msg, dict):
            # 分龄适配
            stage = student_context.stage if student_context else "default"
            if stage in ("kindergarten", "primary") and "primary" in msg:
                return msg["primary"]
            
            # 会员适配
            if membership_tier and membership_tier in msg:
                return msg[membership_tier]
            
            return msg.get("default", msg.get("free", "出了点问题"))
        
        return msg
```
