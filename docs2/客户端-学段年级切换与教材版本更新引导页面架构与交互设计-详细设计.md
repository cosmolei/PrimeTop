# 客户端-学段年级切换与教材版本更新引导页面架构与交互设计

> **版本**: v1.0 | **日期**: 2026-05-31 | **状态**: 初稿
> **优先级**: P0（首次建档年级选择）+ P1（学期升迁引导）
> **依赖**: 服务端-用户年级升迁与学段转换服务、学期与学年管理服务、客户端-登录注册与入门引导、客户端状态管理架构

---

## 1. 概述

### 1.1 功能边界

**一句话定义**：当学生用户首次建档或学期更迭导致年级/学段发生变化时，客户端通过引导式页面完成年级确认、学段切换、教材版本重选、学科调整和数据迁移预览，确保用户顺利过渡到新学段。

**本文档负责**：

| 职责 | 说明 |
|------|------|
| 升迁检测与触发 | 客户端侧学期切换检测、服务端升迁事件消费 |
| 引导弹窗/全屏引导 | 年级确认→学段切换→教材版本选择→学科确认→完成 |
| 教材版本选择器 | 按学段/年级/学科展示可选教材版本 |
| 学段切换过渡动画 | 升段（小学→初中）特殊视觉反馈 |
| 家长确认流程 | 低龄用户学段变更需家长授权 |
| 引导中断恢复 | 断点续导，已选数据不丢失 |
| 分龄交互适配 | 不同学段引导页面的信息密度与语言风格 |

**本文档不负责**：

| 外部依赖 | 说明 |
|----------|------|
| 服务端升迁逻辑 | 由 `服务端-用户年级升迁与学段转换服务` 处理 |
| 学期日历管理 | 由 `学期与学年管理服务` 提供校历数据 |
| 知识掌握度迁移 | 由服务端升迁服务中的画像迁移引擎处理 |
| 入门引导流程 | 首次注册引导由 `客户端-登录注册与入门引导` 负责 |

### 1.2 设计原则

1. **零感知升级**：同段内年级升级（如 G5→G6）尽量自动化，仅在必要时弹窗确认
2. **仪式感升段**：跨段（小学→初中、初中→高中）通过全屏引导+动画营造里程碑感
3. **渐进采集**：与首次建档复用同一套组件，但跳过已填信息
4. **不阻塞主流程**：引导可跳过/延后（最多提醒3次），不阻碍正常使用
5. **家长共决**：幼儿/小学阶段学段变更需家长确认

## 2. 触发场景与检测机制

### 2.1 触发场景矩阵

| 场景 | 触发方式 | 引导类型 | 是否可跳过 | 优先级 |
|------|---------|---------|-----------|--------|
| 首次建档选年级 | 注册引导流程内 | 全屏引导 | 否（必选） | P0 |
| 新学期年级自动升级 | 客户端启动时检测 | 轻量确认弹窗 | 是（提醒3次） | P1 |
| 跨段升学（小学→初中） | 服务端事件推送/启动检测 | 全屏引导仪式 | 是（提醒3次） | P1 |
| 用户手动切换年级 | 设置页→个人信息→年级 | 全屏引导（精简版） | 取消操作 | P2 |
| 教材版本更新 | 服务端推送/启动检测 | 半屏底部弹窗 | 是 | P2 |
| 服务端强制升迁 | WebSocket 推送 | 全屏引导（不可关闭） | 否 | P1 |

### 2.2 客户端检测流程

```
APP 启动
  │
  ├─ 1. 调用 GET /api/v1/user/profile 获取用户信息
  │     └─ 包含当前 grade, stage, textbook_set_id
  │
  ├─ 2. 调用 GET /api/v1/academic/current-term 获取当前学期
  │     └─ 返回 { term_id, stage, grade, start_date, is_new_term }
  │
  ├─ 3. 本地比对：current_grade != server.grade 或 pending_transition
  │     │
  │     ├─ 不一致 → 4. 调用 GET /api/v1/user/transition/status
  │     │            └─ 返回 { pending: bool, transition_type, ... }
  │     │
  │     └─ 一致 → 正常启动
  │
  └─ 5. 根据 transition_type 决定引导方式
        ├─ INTRA_STAGE_UPGRADE  → showGradeConfirmSheet()
        ├─ CROSS_STAGE_UPGRADE  → showStageTransitionWizard()
        ├─ TEXTBOOK_VERSION_UPDATE → showTextbookUpdateSheet()
        └─ FORCED_TRANSITION   → showStageTransitionWizard(blockDismiss: true)
```

### 2.3 检测时机

| 时机 | 检测内容 | 说明 |
|------|---------|------|
| APP 冷启动 | 全量检测 | 比对本地与服务端年级/学段 |
| APP 从后台恢复 | 增量检测 | 仅检查 `pending_transition` 标记 |
| WebSocket 推送 | 被动触发 | 服务端主动推送 `grade.transition.pending` 事件 |
| 用户手动触发 | 设置页入口 | 用户主动点击"切换年级" |
| 首页定时检查 | 每30分钟 | 轻量级 `transition/status` 接口轮询 |

```dart
// lib/features/grade_transition/providers/grade_confirm_provider.dart

@riverpod
class GradeConfirm extends _$GradeConfirm {
  @override
  Future<GradeConfirmData?> build() async {
    final api = ref.read(apiProvider);
    final response = await api.get('/api/v1/user/transition/status');
    if (!response.data['pending']) return null;
    
    return GradeConfirmData.fromJson(response.data);
  }

  /// 确认年级升级
  Future<void> confirmUpgrade() async {
    final api = ref.read(apiProvider);
    await api.post('/api/v1/user/transition/confirm', data: {
      'action': 'confirm',
      'skip_textbook_reselect': state.value?.textbookChanged == false,
    });
    
    // 更新本地用户信息
    ref.read(userProfileProvider.notifier).refreshProfile();
    state = const AsyncData(null);
  }

  /// 稍后提醒
  Future<void> remindLater() async {
    final api = ref.read(apiProvider);
    await api.post('/api/v1/user/transition/remind-later');
    state = const AsyncData(null);
  }
}
```

```dart
  late final AnimationController _fadeController;

    _lottieController = AnimationController(
```

## 7. 向导控制器实现

```dart
// lib/features/grade_transition/providers/transition_wizard_provider.dart

@riverpod
class TransitionWizard extends _$TransitionWizard {
  @override
  TransitionWizardState build(TransitionInitParams params) {
    return TransitionWizardState(
      transitionType: params.transitionType,
      oldStage: params.oldStage,
      newStage: params.newStage,
      oldGrade: params.oldGrade,
      newGrade: params.newGrade,
      currentStep: TransitionStep.welcome,
    );
  }

  /// 下一步
  void nextStep() {
    final next = _nextStepFor(state.currentStep);
    if (next != null) {
      state = state.copyWith(currentStep: next);
    }
  }

  /// 上一步
  void previousStep() {
    final prev = _previousStepFor(state.currentStep);
    if (prev != null) {
      state = state.copyWith(currentStep: prev);
    }
  }

  /// 计算下一步（跳过不需要的步骤）
  TransitionStep? _nextStepFor(TransitionStep current) {
    switch (current) {
      case TransitionStep.welcome:
        return TransitionStep.gradeConfirm;
      case TransitionStep.gradeConfirm:
        return TransitionStep.textbookSelect;
      case TransitionStep.textbookSelect:
        return TransitionStep.subjectConfirm;
      case TransitionStep.subjectConfirm:
        // 14岁以下需要家长确认
        if (_needsParentAuth()) {
          return TransitionStep.parentAuth;
        }
        return TransitionStep.dataPreview;
      case TransitionStep.parentAuth:
        return TransitionStep.dataPreview;
      case TransitionStep.dataPreview:
        return TransitionStep.complete;
      case TransitionStep.complete:
        return null;
    }
  }

  bool _needsParentAuth() {
    // 14岁以下用户需要家长授权
    final userProfile = ref.read(userProfileProvider).valueOrNull;
    if (userProfile == null) return false;
    final age = _calculateAge(userProfile.birthday);
    return age < 14;
  }

  /// 选择教材版本
  void selectTextbook(String subjectCode, String textbookId) {
    final updated = Map<String, String>.from(state.selectedTextbooks ?? {});
    updated[subjectCode] = textbookId;
    state = state.copyWith(selectedTextbooks: updated);
  }

  /// 加载数据预览
  Future<void> loadDataPreview() async {
    final api = ref.read(apiProvider);
    final response = await api.get('/api/v1/user/transition/preview', 
      queryParameters: {
        'new_stage': state.newStage,
        'new_grade': state.newGrade,
        ...state.selectedTextbooks ?? {},
      },
    );
    state = state.copyWith(
      dataPreview: DataPreviewInfo.fromJson(response.data),
    );
  }

  /// 执行升迁
  Future<bool> executeTransition() async {
    state = state.copyWith(isSubmitting: true, errorMessage: null);
    try {
      final api = ref.read(apiProvider);
      final response = await api.post('/api/v1/user/transition/execute', data: {
        'transition_id': ref.read(transitionIdProvider),
        'new_stage': state.newStage,
        'new_grade': state.newGrade,
        'textbooks': state.selectedTextbooks,
        'subjects': state.confirmedSubjects,
        'parent_auth_token': state.parentAuthToken,
        'migrate_knowledge': true,
      });

      // 更新全局用户信息
      await ref.read(userProfileProvider.notifier).refreshProfile();
      
      // 清除相关缓存
      ref.invalidate(learningPlanProvider);
      ref.invalidate(subjectListProvider);
      ref.invalidate(knowledgeMapProvider);
      
      nextStep(); // → complete
      return true;
    } on ApiException catch (e) {
      state = state.copyWith(
        isSubmitting: false,
        errorMessage: _mapError(e.code),
      );
      return false;
    }
  }

  String? _mapError(String code) {
    switch (code) {
      case 'TRANS_001': return '已有进行中的升迁流程，请继续完成';
      case 'TRANS_002': return '年级与学段不匹配，请重新选择';
      case 'TRANS_003': return '家长尚未授权，请等待确认';
      case 'TRANS_004': return '升迁流程已过期，请重新开始';
      case 'TRANS_005': return '教材版本不存在，请刷新后重试';
      case 'TRANS_006': return '请至少选择一门学科';
      case 'TRANS_007': return '操作过于频繁，请稍后再试';
      default: return '操作失败，请重试';
    }
  }
}
```

## 9. 断点续导机制

### 9.1 进度持久化

引导流程的进度实时保存到本地 Hive 存储，APP 被杀或崩溃后可恢复。

```dart
// lib/features/grade_transition/services/transition_progress_service.dart

class TransitionProgressService {
  static const _boxName = 'grade_transition_progress';
  static const _progressKey = 'wizard_progress';

  late Box _box;

  Future<void> init() async {
    _box = await Hive.openBox(_boxName);
  }

  /// 保存进度
  Future<void> saveProgress(TransitionWizardState state) async {
    await _box.put(_progressKey, state.toJson());
  }

  /// 恢复进度
  TransitionWizardState? loadProgress() {
    final json = _box.get(_progressKey);
    if (json == null) return null;
    try {
      return TransitionWizardState.fromJson(Map<String, dynamic>.from(json));
    } catch (_) {
      return null;
    }
  }

  /// 清除进度（完成或放弃后）
  Future<void> clearProgress() async {
    await _box.delete(_progressKey);
  }
}
```

```dart
      builder: (ctx) => AlertDialog(
        title: const Text('继续未完成的设置'),
        content: const Text('检测到你有未完成的升段设置，是否继续？'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(ctx, false),
            child: const Text('重新开始'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(ctx, true),
            child: const Text('继续'),
          ),
        ],
      ),
    );
    
    if (shouldResume == true) {
      ref.read(transitionWizardProvider.notifier).restoreFromSaved(progress);
    } else {
      ref.read(transitionProgressProvider).clearProgress();
    }
  }
}
```

## 12. 降级策略

| 故障场景 | 降级方案 |
|---------|----------|
| 教材版本列表加载失败 | 使用缓存数据或跳过教材选择，后续在设置页补选 |
| 数据预览接口超时 | 跳过预览步骤，直接进入完成页 |
| 家长授权推送失败 | 提示切换其他授权方式（验证码/链接） |
| 升迁执行接口失败 | 展示错误信息，支持重试；不自动回滚（服务端保证幂等） |
| Hive 持久化失败 | 断点续导不可用，但引导流程仍可正常执行 |
| WebSocket 断开 | 轮询替代方案（5秒间隔，最多60次） |
