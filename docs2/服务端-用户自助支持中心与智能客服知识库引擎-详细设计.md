# 用户自助支持中心与智能客服知识库引擎 - 详细设计

## 1. 概述

### 1.1 模块定位

用户自助支持中心（UserSelfSupport）是 PrimeTop 平台的**用户服务基础设施**，为全体用户（学生、家长、教师）提供一站式的产品帮助、使用指南、常见问题解答和智能故障排查能力。区别于学科知识问答（由 EduFAQ 引擎处理）和 AI 智能客服对话（由 AI 客服引擎处理），本模块聚焦于**产品使用层面的自助服务**——帮助用户快速解决"怎么用""为什么不行""在哪里找"等产品运营问题。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 帮助内容管理 | 统一管理帮助文章、FAQ、使用指南、视频教程等多格式帮助内容 |
| 智能语义检索 | 基于向量嵌入的语义搜索，支持自然语言提问匹配最优帮助内容 |
| 个性化推荐 | 根据用户角色（学生/家长/教师）、学段、设备平台推荐相关帮助内容 |
| 知识缺口发现 | 分析用户搜索无结果和高跳出率查询，自动识别帮助内容缺口 |
| 内容质量反馈 | 用户反馈（有用/无用）驱动的文章质量评分与内容迭代闭环 |
| 智能故障排查 | 针对常见问题（登录失败、支付异常等）提供交互式排查向导 |
| 多渠道分发 | 帮助内容同步至 App 内、Web 端、小程序、微信公众号等多渠道 |
| 客服联动 | 自助未能解决时无缝升级至人工客服，携带用户上下文与排查记录 |

### 1.3 与现有模块的边界

| 模块 | 区别 |
|------|------|
| 教育高频问题智能问答库 (EduFAQ) | EduFAQ 面向**学科知识问题**（如"什么是光合作用"）；本模块面向**产品使用问题**（如"怎么绑定家长账号"） |
| AI 智能客服对话引擎 | AI 客服是**对话式**交互，需要多轮对话理解问题；本模块是**搜索+浏览**式自助服务，用户主动检索内容 |
| 客服与工单系统 | 工单系统管理**人工服务流程**（受理→处理→关闭）；本模块是**自助服务**，目标是在用户接触人工客服前解决问题 |
| 意见反馈系统 | 意见反馈是用户**主动提交**的产品建议/bug 报告；本模块是用户**被动获取**的帮助内容 |

### 1.5 依赖关系

**上游依赖：**
- 用户服务：用户角色、学段、平台信息，用于个性化推荐
- 内容审核服务：帮助内容发布前审核（涉及链接、图片时）
- 统一嵌入服务：文章向量化与查询向量化
- 消息服务：客服升级通知

**下游消费方：**
- 客户端帮助中心页面：直接展示帮助内容
- AI 智能客服对话引擎：引用帮助文章作为回答依据
- 客服工单系统：接收自助未解决的升级工单
- 运营管理后台：内容管理与数据分析

## 2. 数据结构定义

### 2.1 帮助文章表 `help_articles`

```sql
CREATE TABLE `help_articles` (
  `id`                BIGINT       NOT NULL AUTO_INCREMENT COMMENT '文章ID',
  `title`             VARCHAR(200) NOT NULL COMMENT '文章标题',
  `slug`              VARCHAR(200) NOT NULL COMMENT 'URL友好标识（唯一）',
  `summary`           VARCHAR(500) NOT NULL DEFAULT '' COMMENT '摘要（用于列表展示）',
  `content`           MEDIUMTEXT   NOT NULL COMMENT '正文（Markdown格式）',
  `content_html`      MEDIUMTEXT   NULL COMMENT '预渲染HTML（加速前端展示）',
  `category_id`       BIGINT       NOT NULL COMMENT '所属分类ID',
  `sub_category_id`   BIGINT       NULL COMMENT '子分类ID',
  `article_type`      TINYINT      NOT NULL DEFAULT 1 COMMENT '类型: 1=FAQ 2=使用指南 3=视频教程 4=故障排查 5=公告',
  `target_audience`   JSON         NULL COMMENT '目标用户: ["student","parent","teacher","all"]',
  `target_stage`      JSON         NULL COMMENT '适用学段: ["preschool","primary","junior","senior","all"]',
  `target_platform`   JSON         NULL COMMENT '适用平台: ["android","ios","web","miniapp"]',
  `tags`              JSON         NULL COMMENT '标签: ["登录","支付","会员",...]',
  `cover_image`       VARCHAR(500) NULL COMMENT '封面图URL',
  `video_url`         VARCHAR(500) NULL COMMENT '视频URL（type=3时）',
  `attachment_urls`   JSON         NULL COMMENT '附件URL列表',
  `troubleshooting_config` JSON    NULL COMMENT '排查向导配置（type=4时，见2.6节）',
  `view_count`        INT          NOT NULL DEFAULT 0 COMMENT '总浏览次数',
  `helpful_count`     INT          NOT NULL DEFAULT 0 COMMENT '"有用"计数',
  `unhelpful_count`   INT          NOT NULL DEFAULT 0 COMMENT '"无用"计数',
  `bookmark_count`    INT          NOT NULL DEFAULT 0 COMMENT '收藏次数',
  `quality_score`     DECIMAL(4,2) NOT NULL DEFAULT 0.00 COMMENT '质量评分(0-100)',
  `status`            TINYINT      NOT NULL DEFAULT 0 COMMENT '状态: 0=草稿 1=待审 2=已发布 3=已下线 4=已归档',
  `published_at`      DATETIME     NULL COMMENT '发布时间',
  `updated_at`        DATETIME     NULL COMMENT '最后更新时间',
  `expire_at`         DATETIME     NULL COMMENT '过期时间（如活动相关帮助）',
  `author_id`         BIGINT       NOT NULL COMMENT '创建人ID（运营人员）',
  `reviewer_id`       BIGINT       NULL COMMENT '审核人ID',
  `reviewed_at`       DATETIME     NULL COMMENT '审核时间',
  `language`          VARCHAR(10)  NOT NULL DEFAULT 'zh-CN' COMMENT '语言',
  `translation_of`    BIGINT       NULL COMMENT '原文ID（多语言翻译关联）',
  `create_time`       DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time`       DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_deleted`        TINYINT      NOT NULL DEFAULT 0 COMMENT '软删除',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_slug` (`slug`, `language`),
  KEY `idx_category` (`category_id`, `sub_category_id`),
  KEY `idx_status` (`status`, `published_at`),
  KEY `idx_type` (`article_type`, `status`),
  KEY `idx_author` (`author_id`),
  KEY `idx_translation` (`translation_of`),
  KEY `idx_quality` (`quality_score` DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='帮助文章表';
```

### 2.4 搜索日志表 `help_search_logs`

```sql
CREATE TABLE `help_search_logs` (
  `id`              BIGINT       NOT NULL AUTO_INCREMENT,
  `user_id`         BIGINT       NULL COMMENT '用户ID（匿名用户为null）',
  `session_id`      VARCHAR(64)  NOT NULL COMMENT '会话ID',
  `query`           VARCHAR(500) NOT NULL COMMENT '搜索关键词',
  `query_normalized` VARCHAR(500) NOT NULL COMMENT '标准化后的查询（去停用词、同义词扩展后）',
  `search_type`     TINYINT      NOT NULL DEFAULT 1 COMMENT '1=关键词 2=语义 3=混合',
  `result_count`    INT          NOT NULL DEFAULT 0 COMMENT '返回结果数',
  `clicked_article_id` BIGINT    NULL COMMENT '用户点击的文章ID',
  `clicked_position`   TINYINT   NULL COMMENT '点击位置（第几条）',
  `has_result`      TINYINT      NOT NULL DEFAULT 1 COMMENT '0=无结果 1=有结果',
  `user_role`       VARCHAR(20)  NULL COMMENT '用户角色',
  `user_stage`      VARCHAR(20)  NULL COMMENT '用户学段',
  `platform`        VARCHAR(20)  NULL COMMENT '客户端平台',
  `response_time_ms` INT         NOT NULL DEFAULT 0 COMMENT '搜索响应时间(ms)',
  `create_time`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_query` (`query_normalized`(100)),
  KEY `idx_no_result` (`has_result`, `create_time`),
  KEY `idx_user` (`user_id`, `create_time`),
  KEY `idx_session` (`session_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='搜索日志表';
```

### 2.5 文章嵌入向量表 `help_article_embeddings`

```sql
CREATE TABLE `help_article_embeddings` (
  `id`              BIGINT       NOT NULL AUTO_INCREMENT,
  `article_id`      BIGINT       NOT NULL COMMENT '文章ID',
  `embedding_model` VARCHAR(50)  NOT NULL COMMENT '嵌入模型名称',
  `embedding`       JSON         NOT NULL COMMENT '嵌入向量（如768维float数组）',
  `chunk_index`     INT          NOT NULL DEFAULT 0 COMMENT '分块索引（长文章分段嵌入）',
  `chunk_text`      VARCHAR(1000) NOT NULL COMMENT '分块文本（用于展示匹配片段）',
  `token_count`     INT          NOT NULL DEFAULT 0 COMMENT 'Token数',
  `version`         INT          NOT NULL DEFAULT 1 COMMENT '嵌入版本（文章更新后递增）',
  `create_time`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_article_chunk` (`article_id`, `chunk_index`, `version`),
  KEY `idx_model` (`embedding_model`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='文章嵌入向量表';
```

> **说明：** 向量检索主存储使用 Milvus / Qdrant 等专业向量数据库，MySQL 表用于关联查询与元数据回查。嵌入向量以 JSON 存储便于调试，生产环境向量检索走向量数据库。

## 4. 智能语义检索引擎

### 4.1 检索架构

系统采用 **混合检索（Hybrid Search）** 策略，融合关键词检索与语义检索结果：

```
用户查询 "怎么绑定家长账号"

    ┌────┴────┐
    │  预处理  │
    └────┬────┘

    ┌────▼─────────────────────────────────┐

    │                                      │
```

### 4.2 查询预处理管线

```python
class HelpQueryPreprocessor:
    """帮助中心查询预处理器"""

    STOP_WORDS = {"的", "了", "是", "怎么", "如何", "为什么", "在哪", "哪里", "我", "想"}
    SYNONYM_MAP = {
        "绑定": ["关联", "连接", "配对"],
        "家长": ["父母", "监护人"],
        "充值": ["付款", "缴费"],
        "退款": ["退钱", "退费"],
        "闪退": ["崩溃", "自动退出"],
        "登录不上": ["无法登录", "登录失败"],
    }

    async def preprocess(self, raw_query: str, user_context: dict) -> ProcessedQuery:
        # 1. 文本清洗
        query = raw_query.strip().lower()

        # 2. 分词
        tokens = self.tokenizer.tokenize(query)

        # 3. 停用词过滤
        tokens = [t for t in tokens if t not in self.STOP_WORDS]

        # 4. 同义词扩展
        expanded_terms = set(tokens)
        for token in tokens:
            if token in self.SYNONYM_MAP:
                expanded_terms.update(self.SYNONYM_MAP[token])

        # 5. 意图分类（轻量规则匹配）
        intent = self._classify_intent(query)
        # intent: "how_to" | "troubleshoot" | "where_is" | "what_is" | "general"

        # 6. 平台特定术语映射
        if user_context.get("platform") == "ios":
            query = query.replace("返回键", "左滑返回").replace("菜单键", "更多按钮")

        return ProcessedQuery(
            raw_query=raw_query,
            normalized_query=" ".join(tokens),
            expanded_terms=list(expanded_terms),
            intent=intent,
            user_context=user_context,
        )

    def _classify_intent(self, query: str) -> str:
        if any(kw in query for kw in ["怎么", "如何", "怎样", "方法"]):
            return "how_to"
        if any(kw in query for kw in ["不行", "失败", "错误", "闪退", "无法", "不能"]):
            return "troubleshoot"
        if any(kw in query for kw in ["在哪", "哪里找", "入口"]):
            return "where_is"
        if any(kw in query for kw in ["是什么", "什么意思"]):
            return "what_is"
        return "general"
```

```python
class KeywordSearcher:
    """基于 Elasticsearch 的关键词检索"""

    async def search(self, pq: ProcessedQuery, filters: dict, size: int = 20) -> list[SearchHit]:
        must_clauses = [
            {"term": {"status": 2}},  # 已发布
        ]

        # 用户角色过滤
        role = pq.user_context.get("role", "all")
        must_clauses.append({
            "bool": {
                "should": [
                    {"term": {"target_audiences.keyword": role}},
                    {"term": {"target_audiences.keyword": "all"}},
                ]
            }
        })

        # 平台过滤
        platform = pq.user_context.get("platform")
        if platform:
            must_clauses.append({
                "bool": {
                    "should": [
                        {"term": {"target_platforms.keyword": platform}},
                        {"term": {"target_platforms.keyword": "all"}},
                    ]
                }
            })

        query_body = {
            "size": size,
            "query": {
                "bool": {
                    "must": must_clauses,
                    "should": [
                        # 标题精确匹配（最高权重）
                        {"match": {"title": {"query": pq.normalized_query, "boost": 5.0}}},
                        # 标题前缀匹配
                        {"match_phrase_prefix": {"title": {"query": pq.normalized_query, "boost": 3.0}}},
                        # 摘要匹配
                        {"match": {"summary": {"query": pq.normalized_query, "boost": 2.0}}},
                        # 正文匹配
                        {"match": {"content": {"query": pq.normalized_query, "boost": 1.0}}},
                        # 标签匹配
                        {"terms": {"tags.keyword": pq.expanded_terms}},
                    ],
                    "minimum_should_match": 1,
                }
            },
            "highlight": {
                "fields": {
                    "title": {"number_of_fragments": 0},
                    "summary": {"fragment_size": 100, "number_of_fragments": 1},
                    "content": {"fragment_size": 150, "number_of_fragments": 2},
                },
                "pre_tags": ["<em>"],
                "post_tags": ["</em>"],
            },
        }

        result = await self.es_client.search(index="help_articles", body=query_body)
        return [self._to_hit(hit) for hit in result["hits"]["hits"]]
```

### 4.4 语义检索（向量数据库）

```python
class SemanticSearcher:
    """基于向量数据库的语义检索"""

    EMBEDDING_MODEL = "bge-large-zh-v1.5"
    COLLECTION = "help_articles"

    async def search(self, pq: ProcessedQuery, filters: dict, size: int = 20) -> list[SearchHit]:
        # 1. 查询向量化（带缓存）
        query_vector = await self._embed_query(pq.normalized_query)

        # 2. 构建向量数据库过滤条件
        filter_expr = self._build_filter(filters, pq.user_context)

        # 3. 向量检索
        results = await self.vector_db.search(
            collection_name=self.COLLECTION,
            query_vector=query_vector,
            filter=filter_expr,
            limit=size * 2,  # 多取后去重
            output_fields=["article_id", "chunk_text", "title", "category_id"],
        )

        # 4. 去重：同一篇文章的多个 chunk 取最高分
        deduped = {}
        for hit in results:
            article_id = hit["entity"]["article_id"]
            if article_id not in deduped or hit["score"] > deduped[article_id].score:
                deduped[article_id] = SearchHit(
                    article_id=article_id,
                    score=hit["score"],
                    matched_segment=hit["entity"]["chunk_text"],
                    match_type="semantic",
                )

        return sorted(deduped.values(), key=lambda x: x.score, reverse=True)[:size]

    async def _embed_query(self, query: str) -> list[float]:
        # 查询嵌入缓存（Redis，5分钟TTL）
        cache_key = f"help:qemb:{hashlib.md5(query.encode()).hexdigest()}"
        cached = await self.redis.get(cache_key)
        if cached:
            return json.loads(cached)

        # 调用嵌入服务
        embedding = await self.embedding_service.embed(
            model=self.EMBEDDING_MODEL,
            input=query,
        )

        await self.redis.setex(cache_key, 300, json.dumps(embedding))
        return embedding

    def _build_filter(self, filters: dict, user_context: dict) -> str:
        conditions = ['status == 2']

        role = user_context.get("role", "all")
        conditions.append(f'(target_audiences contains "{role}" || target_audiences contains "all")')

        platform = user_context.get("platform")
        if platform:
            conditions.append(
                f'(target_platforms contains "{platform}" || target_platforms contains "all")'
            )

        if filters.get("category_id"):
            conditions.append(f'category_id == {filters["category_id"]}')

        return " && ".join(conditions)
```

### 4.5 融合排序

```python
class HybridRanker:
    """混合检索结果融合排序"""

    # 权重配置（可通过配置中心动态调整）
    DEFAULT_WEIGHTS = {
        "bm25": 0.3,
        "semantic": 0.5,
        "popularity": 0.1,
        "personalization": 0.1,
    }

    async def rank(
        self,
        keyword_hits: list[SearchHit],
        semantic_hits: list[SearchHit],
        user_context: dict,
        weights: dict | None = None,
    ) -> list[RankedResult]:
        w = weights or self.DEFAULT_WEIGHTS

        # 1. 归一化各路得分到 [0, 1]
        kw_scores = self._normalize_scores(keyword_hits)
        sem_scores = self._normalize_scores(semantic_hits)

        # 2. 合并候选集
        all_article_ids = set(kw_scores.keys()) | set(sem_scores.keys())

        # 3. 预取文章元数据（用于人气分和个性化分）
        articles_meta = await self._batch_get_meta(list(all_article_ids))

        ranked = []
        for article_id in all_article_ids:
            kw_score = kw_scores.get(article_id, 0)
            sem_score = sem_scores.get(article_id, 0)
            meta = articles_meta.get(article_id)

            # 人气分：基于浏览量和有用率
            popularity = self._calc_popularity(meta)

            # 个性化分：角色、学段匹配度
            personalization = self._calc_personalization(meta, user_context)

            # 综合得分
            final_score = (
                w["bm25"] * kw_score
                + w["semantic"] * sem_score
                + w["popularity"] * popularity
                + w["personalization"] * personalization
            )

            hit = next(
                (h for h in semantic_hits + keyword_hits if h.article_id == article_id),
                None,
            )
            ranked.append(RankedResult(
                article_id=article_id,
                final_score=final_score,
                match_type=hit.match_type if hit else "hybrid",
                matched_segment=hit.matched_segment if hit else None,
                meta=meta,
            ))

        ranked.sort(key=lambda x: x.final_score, reverse=True)
        return ranked

    def _calc_popularity(self, meta: ArticleMeta) -> float:
        """人气分 = log(view_count) 归一化 × helpful_rate"""
        if not meta:
            return 0
        import math
        view_norm = min(math.log10(max(meta.view_count, 1)) / 5.0, 1.0)  # log10(10000)≈4
        helpful_norm = meta.helpful_rate if meta.helpful_rate else 0.5
        return view_norm * helpful_norm

    def _calc_personalization(self, meta: ArticleMeta, ctx: dict) -> float:
        """个性化匹配分"""
        if not meta:
            return 0
        score = 0.0
        role = ctx.get("role")
        if role and role in meta.target_audiences:
            score += 0.5
        stage = ctx.get("stage")
        if stage and stage in meta.target_stages:
            score += 0.3
        platform = ctx.get("platform")
        if platform and platform in meta.target_platforms:
            score += 0.2
        return min(score, 1.0)
```

## 5. 知识缺口发现引擎

### 5.1 核心逻辑

当用户搜索帮助中心但未找到满意结果时，系统自动记录这些"搜索缺口"，并通过聚类分析发现高频未覆盖问题，为内容运营团队提供文章生产方向。

### 5.2 缺口检测流水线

```python
class KnowledgeGapDetector:
    """知识缺口检测引擎"""

    async def detect_gaps(self, period_days: int = 7) -> list[ContentGap]:
        # 1. 提取无结果/低点击率搜索
        no_result_queries = await self._get_no_result_queries(period_days)
        low_ctr_queries = await self._get_low_ctr_queries(period_days)

        # 2. 合并查询并标准化
        all_gap_queries = no_result_queries + low_ctr_queries
        normalized = [self._normalize_query(q) for q in all_gap_queries]

        # 3. 查询向量化
        embeddings = await self._batch_embed(normalized)

        # 4. 聚类分析（DBSCAN）
        clusters = self._cluster_queries(embeddings, normalized)

        # 5. 为每个聚类生成主题标签
        gaps = []
        for cluster in clusters:
            if len(cluster.queries) < 3:  # 少于3次的不报告
                continue

            topic = await self._generate_topic_label(cluster.queries)

            gap = ContentGap(
                topic=topic,
                query_count=len(cluster.queries),
                sample_queries=cluster.queries[:5],
                affected_users=await self._count_affected_users(cluster.queries),
                severity=self._calc_severity(cluster),
                suggested_action=await self._suggest_action(topic, cluster),
                first_seen=cluster.min_timestamp,
                last_seen=cluster.max_timestamp,
            )
            gaps.append(gap)

        gaps.sort(key=lambda g: (g.severity, g.query_count), reverse=True)
        return gaps

    def _calc_severity(self, cluster: QueryCluster) -> str:
        """计算缺口严重程度"""
        if cluster.affected_user_count >= 100:
            return "critical"
        elif cluster.affected_user_count >= 30:
            return "high"
        elif cluster.affected_user_count >= 10:
            return "medium"
        return "low"

    async def _suggest_action(self, topic: str, cluster: QueryCluster) -> SuggestedAction:
        """为缺口建议行动方案"""
        # 检查是否有相似已有文章（可能只是搜索匹配不佳）
        similar = await self._find_similar_articles(topic)
        if similar:
            return SuggestedAction(
                action_type="optimize_existing",
                reason=f"已有相似文章「{similar[0].title}」，建议优化其关键词和SEO",
                target_article_id=similar[0].id,
            )

        # 检查是否属于产品使用问题（vs Bug报告）
        if self._is_bug_report(cluster.queries):
            return SuggestedAction(
                action_type="escalate_to_dev",
                reason="查询模式暗示存在产品Bug，建议转交开发团队排查",
            )

        return SuggestedAction(
            action_type="create_new",
            reason=f"暂无相关文章，建议创建「{topic}」主题帮助文章",
            suggested_category=self._guess_category(topic),
        )
```

## 6. 文章嵌入向量化管线

### 6.1 文章发布时向量化流程

```python
class ArticleEmbeddingPipeline:
    """帮助文章嵌入向量化管线"""

    MAX_CHUNK_TOKENS = 256  # 每块最大Token数
    OVERLAP_TOKENS = 50     # 重叠Token数（保证语义连续性）

    async def process_article(self, article_id: int):
        """文章创建/更新时调用"""
        article = await self.article_repo.get_by_id(article_id)
        if not article or article.status != 2:  # 非已发布状态，跳过
            return

        # 1. 文本拼接（标题 + 摘要 + 正文 + 标签）
        full_text = self._build_embed_text(article)

        # 2. 分块
        chunks = self._chunk_text(full_text, self.MAX_CHUNK_TOKENS, self.OVERLAP_TOKENS)

        # 3. 批量向量化
        embeddings = await self.embedding_service.batch_embed(
            model="bge-large-zh-v1.5",
            inputs=chunks,
        )

        # 4. 存储嵌入（先删旧版本再写新版本）
        async with self.db.transaction():
            await self.embedding_repo.delete_by_article(article_id)
            for i, (chunk, emb) in enumerate(zip(chunks, embeddings)):
                await self.embedding_repo.create(
                    article_id=article_id,
                    embedding_model="bge-large-zh-v1.5",
                    embedding=emb,
                    chunk_index=i,
                    chunk_text=chunk[:1000],
                    token_count=len(self.tokenizer.encode(chunk)),
                    version=1,
                )

            # 同步写入向量数据库
            await self.vector_db.upsert(
                collection_name="help_articles",
                records=[
                    {
                        "id": f"{article_id}_{i}",
                        "vector": emb,
                        "article_id": article_id,
                        "chunk_index": i,
                        "chunk_text": chunk[:500],
                        "title": article.title,
                        "category_id": article.category_id,
                        "status": 2,
                        "target_audiences": article.target_audience,
                        "target_platforms": article.target_platform,
                    }
                    for i, (chunk, emb) in enumerate(zip(chunks, embeddings))
                ],
            )

        # 5. 清除搜索缓存
        await self._invalidate_search_cache(article_id)

    def _build_embed_text(self, article: HelpArticle) -> str:
        """构建用于嵌入的文本"""
        parts = [article.title]
        if article.summary:
            parts.append(article.summary)
        if article.tags:
            parts.append(" ".join(article.tags))
        parts.append(article.content)
        return "\n\n".join(parts)

    def _chunk_text(self, text: str, max_tokens: int, overlap: int) -> list[str]:
        """按Token数分块"""
        tokens = self.tokenizer.encode(text)
        chunks = []
        start = 0

        while start < len(tokens):
            end = min(start + max_tokens, len(tokens))
            chunk_tokens = tokens[start:end]
            chunk_text = self.tokenizer.decode(chunk_tokens)
            chunks.append(chunk_text)
            start = end - overlap

        return chunks
```

```python
class HelpCacheManager:
    """帮助中心缓存管理器"""

    ARTICLE_CACHE_KEY = "help:art:{id}"
    ARTICLE_LIST_CACHE_KEY = "help:art:list:{category}:{page}"
    SEARCH_CACHE_KEY = "help:search:{hash}"
    CATEGORY_TREE_KEY = "help:categories"
    HOME_CACHE_KEY = "help:home:{role}:{platform}"

    async def invalidate_article(self, article_id: int):
        """文章更新时失效相关缓存"""
        pipe = self.redis.pipeline()

        # 1. 删除文章详情缓存
        pipe.delete(self.ARTICLE_CACHE_KEY.format(id=article_id))

        # 2. 删除该文章所在分类的文章列表缓存
        article = await self.article_repo.get_by_id(article_id)
        if article:
            for page in range(1, 20):  # 清除前20页缓存
                pipe.delete(self.ARTICLE_LIST_CACHE_KEY.format(
                    category=article.category_id, page=page
                ))

        # 3. 清除搜索结果缓存（按模式匹配删除）
        for key in self.redis.scan_iter("help:search:*"):
            pipe.delete(key)

        # 4. 清除首页缓存
        for key in self.redis.scan_iter("help:home:*"):
            pipe.delete(key)

        await pipe.execute()

    async def invalidate_category_tree(self):
        """分类变更时失效分类树缓存"""
        await self.redis.delete(self.CATEGORY_TREE_KEY)
        # 分类变更影响所有列表缓存
        for key in self.redis.scan_iter("help:art:list:*"):
```

```python
class HelpSearchService:
    """帮助搜索服务（带降级）"""

    async def search(self, request: SearchRequest) -> SearchResult:
        try:
            # 正常流程：混合检索
            return await self._hybrid_search(request)

        except VectorDBUnavailableError:
            logger.warning("向量数据库不可用，降级为关键词检索")
            try:
                return await self._keyword_only_search(request)

            except ElasticsearchUnavailableError:
                logger.warning("ES不可用，降级为数据库查询")
                return await self._database_search(request)

        except EmbeddingServiceUnavailableError:
            logger.warning("嵌入服务不可用，降级为关键词检索")
            return await self._keyword_only_search(request)

        except Exception as e:
            logger.error(f"搜索全面失败: {e}", exc_info=True)
            return SearchResult(
                total=0,
                results=[],
                error="搜索服务暂时不可用，请稍后重试或浏览分类",
                fallback_action="browse_category",
            )

    async def _database_search(self, request: SearchRequest) -> SearchResult:
        """数据库兜底搜索（LIKE匹配）"""
        results = await self.article_repo.search_simple(
            keyword=request.query,
            filters=request.filters,
            page=request.page,
            page_size=request.page_size,
        )
        return SearchResult(
            total=results.total,
            results=[self._to_search_result(r) for r in results.items],
            search_meta=SearchMeta(
                mode="database_fallback",
                degraded=True,
                message="搜索功能降级中，结果可能不够精确",
            ),
        )
```

### 11.2 内容安全

- **XSS 防护**：文章内容存储为 Markdown，服务端预渲染 HTML 时使用严格白名单过滤（`<a>`, `<img>`, `<b>`, `<i>`, `<h2>-<h4>`, `<ul>`, `<ol>`, `<table>`, `<code>`, `<blockquote>`）
- **图片安全**：所有上传图片经过内容安全审核（色情/暴力检测）
- **外链安全**：文章中的外部链接自动添加 `rel="nofollow noopener"`，并通过安全检查（检测钓鱼/恶意网站）
- **敏感信息**：文章内容禁止包含手机号、身份证号等敏感信息模式（发布前自动检测）

```python
class ArticleContentSanitizer:
    """文章内容安全清洗"""

    ALLOWED_TAGS = {"a", "img", "b", "i", "strong", "em", "h2", "h3", "h4",
                    "ul", "ol", "li", "table", "thead", "tbody", "tr", "th", "td",
                    "code", "pre", "blockquote", "p", "br", "hr", "span", "div"}

    ALLOWED_ATTRS = {
        "a": {"href", "title"},
        "img": {"src", "alt", "width", "height"},
        "span": {"class"},
        "div": {"class"},
        "code": {"class"},
    }

    SENSITIVE_PATTERNS = [
        (r'1[3-9]\d{9}', '[手机号]'),           # 手机号
        (r'\d{15}|\d{18}', '[身份证号]'),       # 身份证号
        (r'\d{16,19}', '[银行卡号]'),           # 银行卡号
    ]

    def sanitize(self, html: str) -> str:
        # 1. 标签白名单过滤
        clean_html = bleach.clean(
            html,
            tags=self.ALLOWED_TAGS,
            attributes=self.ALLOWED_ATTRS,
            protocols=["https"],
            strip=True,
        )

        # 2. 敏感信息脱敏
        for pattern, replacement in self.SENSITIVE_PATTERNS:
            clean_html = re.sub(pattern, replacement, clean_html)

        # 3. 外链安全处理
        clean_html = self._secure_external_links(clean_html)

        return clean_html

    def _secure_external_links(self, html: str) -> str:
        soup = BeautifulSoup(html, "html.parser")
        for a_tag in soup.find_all("a", href=True):
            href = a_tag["href"]
            if href.startswith("http") and "primetop.com" not in href:
                a_tag["rel"] = "nofollow noopener noreferrer"
                a_tag["target"] = "_blank"
        return str(soup)
```
