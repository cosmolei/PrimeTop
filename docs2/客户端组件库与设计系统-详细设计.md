# 客户端组件库与设计系统 - 详细设计

> **模块定位**：PrimeTop 全平台共享 UI 组件库与设计系统，为 Flutter 移动端、Web 端和小程序端提供统一的视觉语言、交互规范和可复用组件。
> **覆盖学段**：全学段（通过主题变体实现分龄适配）
> **优先级**：P0（MVP 阶段基础设施，影响全产品 UI 一致性和开发效率）

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 视觉一致性 | 全产品视觉语言统一，避免"各页面画风不同" |
| 分龄适配 | 一套组件，通过主题切换适配幼儿/小学/初中/高中四种风格 |
| 开发效率 | 组件开箱即用，减少重复 UI 代码，降低页面开发成本 |
| 可访问性 | 满足无障碍标准（对比度、触控区域、语义标签） |
| 可维护性 | 集中管理设计 Token，视觉调整一处改全局生效 |
| 多端复用 | Flutter 为主，设计 Token 导出供 Web/小程序对齐 |

### 4.3 主题提供者

```dart
/// lib/theme/theme_provider.dart

class PTThemeProvider extends InheritedWidget {
  final PTThemeData theme;
  final void Function(AgeGroup) switchTheme;

  const PTThemeProvider({
    super.key,
    required this.theme,
    required this.switchTheme,
    required super.child,
  });

  static PTThemeProvider of(BuildContext context) {
    final provider = context.dependOnInheritedWidgetOfExactType<PTThemeProvider>();
    assert(provider != null, 'PTThemeProvider not found in widget tree');
    return provider!;
  }

  @override
  bool updateShouldNotify(PTThemeProvider oldWidget) =>
      theme.ageGroup != oldWidget.theme.ageGroup;
}
```

### 5.2 PTButton 组件详细设计

```dart
/// lib/components/base/pt_button.dart

enum PTButtonVariant { primary, secondary, text, danger }
enum PTButtonSize { small, medium, large }

class PTButton extends StatelessWidget {
  final String? text;
  final Widget? icon;
  final Widget? trailing;
  final PTButtonVariant variant;
  final PTButtonSize size;
  final bool loading;
  final bool disabled;
  final bool fullWidth;
  final VoidCallback? onTap;
  final EdgeInsetsGeometry? padding;

  const PTButton({
    super.key,
    this.text,
    this.icon,
    this.trailing,
    this.variant = PTButtonVariant.primary,
    this.size = PTButtonSize.medium,
    this.loading = false,
    this.disabled = false,
    this.fullWidth = false,
    this.onTap,
    this.padding,
  });

  @override
  Widget build(BuildContext context) {
    final theme = PTThemeProvider.of(context).theme;

    return GestureDetector(
      onTap: (disabled || loading) ? null : onTap,
      child: AnimatedContainer(
        duration: PTAnimation.durationNormal,
        curve: PTAnimation.easeOut,
        constraints: BoxConstraints(
          minWidth: fullWidth ? double.infinity : _minWidth,
          minHeight: _height,
        ),
        padding: padding ?? _defaultPadding,
        decoration: BoxDecoration(
          color: _backgroundColor(theme),
          borderRadius: BorderRadius.circular(theme.baseRadius),
          border: _border,
          boxShadow: _hasShadow ? PTShadow.sm : null,
        ),
        child: Row(
          mainAxisSize: fullWidth ? MainAxisSize.max : MainAxisSize.min,
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            if (loading)
              SizedBox(
                width: _iconSize, height: _iconSize,
                child: CircularProgressIndicator(
                  strokeWidth: 2,
                  valueColor: AlwaysStoppedAnimation(_textColor(theme)),
                ),
              )
            else if (icon != null)
              Padding(
                padding: const EdgeInsets.only(right: PTSpacing.sm),
                child: IconTheme(
                  data: IconThemeData(size: _iconSize, color: _textColor(theme)),
                  child: icon!,
                ),
              ),
            if (text != null)
              Flexible(
                child: Text(
                  text!,
                  style: TextStyle(
                    fontFamily: theme.fontFamily,
                    fontSize: _fontSize,
                    fontWeight: PTTypography.weightMedium,
                    color: _textColor(theme),
                    height: 1.2,
                  ),
                  overflow: TextOverflow.ellipsis,
                ),
              ),
            if (trailing != null)
              Padding(
                padding: const EdgeInsets.only(left: PTSpacing.sm),
                child: trailing,
              ),
          ],
        ),
      ),
    );
  }

  double get _minWidth => switch (size) {
    PTButtonSize.small => 64.0,
    PTButtonSize.medium => 80.0,
    PTButtonSize.large => 96.0,
  };

  double get _height => switch (size) {
    PTButtonSize.small => PTSizing.buttonHeightSm,
    PTButtonSize.medium => PTSizing.buttonHeightMd,
    PTButtonSize.large => PTSizing.buttonHeightLg,
  };

  double get _fontSize => switch (size) {
    PTButtonSize.small => PTTypography.fontSizeCaption,
    PTButtonSize.medium => PTTypography.fontSizeBodySm,
    PTButtonSize.large => PTTypography.fontSizeBody,
  };

  double get _iconSize => switch (size) {
    PTButtonSize.small => PTSizing.iconSm,
    PTButtonSize.medium => PTSizing.iconMd,
    PTButtonSize.large => PTSizing.iconLg,
  };

  EdgeInsetsGeometry get _defaultPadding => switch (size) {
    PTButtonSize.small => const EdgeInsets.symmetric(
        horizontal: PTSpacing.md, vertical: PTSpacing.xs),
    PTButtonSize.medium => const EdgeInsets.symmetric(
        horizontal: PTSpacing.lg, vertical: PTSpacing.sm),
    PTButtonSize.large => const EdgeInsets.symmetric(
        horizontal: PTSpacing.xl, vertical: PTSpacing.md),
  };

  bool get _hasShadow => variant == PTButtonVariant.primary && !disabled;

  Color _backgroundColor(PTThemeData theme) {
    if (disabled) return PTColors.gray100;
    return switch (variant) {
      PTButtonVariant.primary => theme.primaryColor,
      PTButtonVariant.secondary => PTColors.gray50,
      PTButtonVariant.text => Colors.transparent,
      PTButtonVariant.danger => PTColors.error,
    };
  }

  Color _textColor(PTThemeData theme) {
    if (disabled) return PTColors.gray400;
    return switch (variant) {
      PTButtonVariant.primary => Colors.white,
      PTButtonVariant.secondary => theme.textColor,
      PTButtonVariant.text => theme.primaryColor,
      PTButtonVariant.danger => Colors.white,
    };
  }

  BoxBorder? get _border {
    if (disabled) return null;
    return switch (variant) {
      PTButtonVariant.secondary => Border.all(color: PTColors.gray300),
      _ => null,
    };
  }
}
```

```dart
class PTCard extends StatelessWidget {
  final Widget child;
  final PTCardVariant variant;
  final EdgeInsetsGeometry? padding;
  final VoidCallback? onTap;
  final Color? customColor;
  final double? customRadius;

    required this.child,
    this.variant = PTCardVariant.elevated,
    this.padding,
    this.onTap,
    this.customColor,
    this.customRadius,

  @override
  Widget build(BuildContext context) {

    return GestureDetector(
      onTap: onTap,
      child: Container(
        padding: padding ??
            EdgeInsets.all(PTSpacing.lg * theme.spacingScale),
        decoration: BoxDecoration(
          color: customColor ?? theme.surfaceColor,
          borderRadius: BorderRadius.circular(customRadius ?? theme.baseRadius),
          border: variant == PTCardVariant.outlined
              ? Border.all(color: PTColors.gray200) : null,
          boxShadow: variant == PTCardVariant.elevated ? PTShadow.sm : null,
        ),
        child: child,
      ),
    );
  }
}
```

```dart
                color: colors.$2,
                height: 1.4,
              )),
          ],

      ),
    );
```

```dart
class _PTSkeletonState extends State<PTSkeleton>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1500),
    )..repeat();
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      builder: (context, child) {
        final opacity = 0.3 + 0.2 * sin(_controller.value * pi * 2);
        return Container(
          width: _width,
          height: _height,
          decoration: BoxDecoration(
            color: PTColors.gray200.withOpacity(opacity),
            borderRadius: _radius,
          ),
        );
      },
    );
  }

    PTSkeletonType.text => double.infinity,
    PTSkeletonType.circle => widget.height ?? 40,
    PTSkeletonType.rect => double.infinity,
    PTSkeletonType.card => double.infinity,

    PTSkeletonType.circle => 40,
    PTSkeletonType.rect => 100,
```

## 8. 组件开发规范

### 8.1 命名规范

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 组件类 | `PT` + PascalCase | `PTButton`, `PTSearchBar` |
| 枚举 | `PT` + PascalCase + Variant/Size/Type | `PTButtonVariant`, `PTTagColor` |
| Token 类 | `PT` + PascalCase 类目 | `PTColors`, `PTSpacing` |
| 文件名 | snake_case，与类名对应 | `pt_button.dart` |

### 8.2 组件 API 设计原则

1. **必选参数用 `required`**：核心内容参数（如 `text`, `child`）标记 required
2. **可选参数提供合理默认值**：变体、尺寸、颜色等枚举参数设置默认值
3. **回调用 `VoidCallback?`**：可选，不强制业务层实现
4. **避免过度封装**：组件通过参数暴露定制点，不通过继承扩展
5. **主题感知**：组件内部自动读取 `PTThemeProvider`，业务层无需手动传主题

### 8.3 可访问性检查清单

每个组件提交前需检查：

- [ ] **触控区域** ≥ 44×44 dp（符合 WCAG 2.5.5）
- [ ] **文字对比度** ≥ 4.5:1（正文）/ 3:1（大文本）
- [ ] **语义标签** 可点击元素有 `Semantics` 标注
- [ ] **字体缩放** 在系统字体放大 200% 下布局不溢出
- [ ] **色盲友好** 不仅依赖颜色传递信息（同时使用图标/文字）
- [ ] **焦点顺序** Tab 键导航顺序符合阅读顺序
- [ ] **禁用态** disabled 组件不响应点击且视觉明确区分

### 8.4 状态管理规范

组件内部状态仅限于 UI 状态（如焦点、悬停、展开/折叠），不持有业务数据。业务数据通过参数传入。

```dart
// ✅ 正确：UI 状态在组件内
final bool _isFocused;
final bool _isExpanded;

// ❌ 错误：业务数据不应在组件内
final List<Question> _questions; // 应通过参数传入
```

```dart
/// test/components/base/pt_button_test.dart

void main() {
  group('PTButton', () {
    testWidgets('渲染文本内容', (tester) async {
      await tester.pumpWidget(
        _testApp(PTButton(text: '开始学习', onTap: () {})),
      );
      expect(find.text('开始学习'), findsOneWidget);
    });

    testWidgets('disabled 时不响应点击', (tester) async {
      var tapped = false;
      await tester.pumpWidget(
        _testApp(PTButton(text: '按钮', disabled: true, onTap: () => tapped = true)),
      );
      await tester.tap(find.byType(PTButton));
      expect(tapped, isFalse);
    });

    testWidgets('loading 状态显示加载指示器', (tester) async {
      await tester.pumpWidget(
        _testApp(PTButton(text: '提交', loading: true)),
      );
      expect(find.byType(CircularProgressIndicator), findsOneWidget);
    });
  });
}

Widget _testApp({PTThemeData? theme, required Widget child}) {
  final t = theme ?? PTThemes.primary;
  return PTThemeProvider(
    theme: t,
    switchTheme: (_) {},
    child: MaterialApp(home: Scaffold(body: child)),
  );
}
```
