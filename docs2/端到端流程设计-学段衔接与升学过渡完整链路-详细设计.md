# 端到端流程设计 - 学段衔接与升学过渡完整链路

## 1. 文档概述

### 1.1 文档目的

本文档详细设计学段衔接与升学过渡的端到端完整链路，覆盖从小学升初中、初中升高中两大关键过渡期的全部流程，包括：学段变更触发、知识缺口检测、桥梁课程推荐、学习进度迁移、新教材版本适配、学习计划重建、UI/UX过渡引导等。目标是让开发人员能直接依据本文档进行编码实现。

### 1.2 范围

| 过渡类型 | 源学段 | 目标学段 | 触发时机 |
|----------|--------|----------|----------|
| 幼升小 | 幼儿园 | 小学一年级 | 自然年9月 / 手动触发 |
| 小升初 | 小学六年级 | 初中一年级 | 自然年9月 / 手动触发 |
| 初升高 | 初中三年级 | 高中一年级 | 自然年9月 / 手动触发 |
| 学段内年级升迁 | 年级N | 年级N+1 | 自然年9月 / 手动触发 |

> 本文档重点覆盖 **小升初** 和 **初升高** 两个最复杂的过渡场景，幼升小和年级升迁作为简化场景处理。

## 3. 各阶段详细设计

### 3.1 阶段一：学段变更触发

#### 3.1.1 自动触发逻辑

```java
/**
 * 学段衔接定时任务 - 每年7月15日 02:00 执行
 * 检测当年9月即将升学的学生
 */
@Scheduled(cron = "0 0 2 15 7 ?")
public void autoDetectTransitionCandidates() {
    // 1. 查询当前处于毕业年级的学生
    //    - 小学六年级（graduatingFrom = "PRIMARY_6"）
    //    - 初中三年级（graduatingFrom = "JUNIOR_3"）
    List<StudentTransitionCandidate> candidates = studentProfileRepository
        .findGraduatingStudents(getCurrentAcademicYear());

    for (StudentTransitionCandidate candidate : candidates) {
        // 2. 创建过渡记录（状态: PENDING）
        TransitionRecord record = TransitionRecord.builder()
            .studentId(candidate.getStudentId())
            .transitionType(determineTransitionType(candidate.getCurrentGrade()))
            .sourceGrade(candidate.getCurrentGrade())
            .targetGrade(candidate.getNextGrade())
            .triggerType(TriggerType.AUTO)
            .state(TransitionState.PENDING)
            .academicYear(getNextAcademicYear())
            .createdAt(Instant.now())
            .build();

        transitionRepository.save(record);

        // 3. 发送过渡准备通知
        notificationService.sendTransitionPreNotice(candidate.getStudentId(), record);
    }
}
```

### 3.3 阶段三：知识缺口检测

#### 3.3.1 检测逻辑

知识缺口检测包含三个维度：

```
┌─────────────────────────────────────────────┐
│            知识缺口检测三维度                 │
├──────────────┬──────────────┬───────────────┤
│  维度1        │  维度2       │  维度3         │
│  基础薄弱点   │  衔接缺口点  │  前置缺失点     │
│              │              │               │
│  源学段内     │  源学段末尾  │  目标学段前置   │
│  掌握度 < 60% │  知识点      │  知识点         │
│  的知识点     │  未覆盖的    │  在源学段未涉及  │
│              │  目标学段    │               │
│              │  前置知识    │               │
└──────────────┴──────────────┴───────────────┘
```

#### 3.3.2 检测服务核心逻辑

```java
/**
 * 知识缺口检测服务
 */
@Service
public class TransitionGapDetectionService {

    /**
     * 执行三维度缺口检测
     */
    public GapDetectionResult detectGaps(String studentId, String sourceGrade, String targetGrade) {
        // 获取学生在源学段的知识掌握度
        Map<String, Double> sourceMastery = knowledgeMasteryService
            .getMasteryMap(studentId, sourceGrade);

        // 获取源学段所有知识点
        List<KnowledgePoint> sourceKPs = knowledgePointRepository
            .findByGrade(sourceGrade);

        // 获取目标学段的前置知识点映射
        List<PrerequisiteMapping> prerequisites = prerequisiteRepository
            .findByTargetGrade(targetGrade);

        // === 维度1：基础薄弱点 ===
        List<KnowledgeGap> weakPoints = sourceMastery.entrySet().stream()
            .filter(e -> e.getValue() < 0.6)
            .map(e -> KnowledgeGap.builder()
                .knowledgePointId(e.getKey())
                .mastery(e.getValue())
                .gapType(GapType.WEAK_FOUNDATION)
                .severity(calculateSeverity(e.getValue()))
                .build())
            .sorted(Comparator.comparing(KnowledgeGap::getMastery))
            .limit(20)  // 最多取TOP20薄弱点
            .collect(Collectors.toList());

        // === 维度2：衔接缺口点 ===
        // 目标学段第一章所需的前置知识，在源学段是否覆盖
        Set<String> sourceKpIds = sourceKPs.stream()
            .map(KnowledgePoint::getId)
            .collect(Collectors.toSet());

        List<KnowledgeGap> bridgeGaps = prerequisites.stream()
            .filter(p -> !sourceKpIds.contains(p.getPrerequisiteKpId()))
            .filter(p -> isCriticalForTargetStart(p, targetGrade))
            .map(p -> KnowledgeGap.builder()
                .knowledgePointId(p.getPrerequisiteKpId())
                .mastery(0.0)
                .gapType(GapType.BRIDGE_GAP)
                .relatedTargetKpId(p.getTargetKpId())
                .severity(Severity.HIGH)
                .build())
            .collect(Collectors.toList());

        // === 维度3：前置缺失点 ===
        List<KnowledgeGap> prerequisiteGaps = prerequisites.stream()
            .filter(p -> sourceKpIds.contains(p.getPrerequisiteKpId()))
            .filter(p -> sourceMastery.getOrDefault(p.getPrerequisiteKpId(), 0.0) < 0.4)
            .map(p -> KnowledgeGap.builder()
                .knowledgePointId(p.getPrerequisiteKpId())
                .mastery(sourceMastery.getOrDefault(p.getPrerequisiteKpId(), 0.0))
                .gapType(GapType.PREREQUISITE_MISSING)
                .relatedTargetKpId(p.getTargetKpId())
                .severity(Severity.CRITICAL)
                .build())
            .collect(Collectors.toList());

        return GapDetectionResult.builder()
            .studentId(studentId)
            .sourceGrade(sourceGrade)
            .targetGrade(targetGrade)
            .weakFoundations(weakPoints)
            .bridgeGaps(bridgeGaps)
            .prerequisiteGaps(prerequisiteGaps)
            .totalGapCount(weakPoints.size() + bridgeGaps.size() + prerequisiteGaps.size())
            .estimatedRemediationDays(calculateEstimatedDays(weakPoints, bridgeGaps, prerequisiteGaps))
            .build();
    }

    private int calculateEstimatedDays(List<KnowledgeGap> weak, List<KnowledgeGap> bridge, List<KnowledgeGap> prereq) {
        // 每个薄弱点预计0.5天，每个缺口预计1天，每个前置缺失预计0.75天
        // 总天数 = max(7, min(30, 计算值))
        double total = weak.size() * 0.5 + bridge.size() * 1.0 + prereq.size() * 0.75;
        return (int) Math.max(7, Math.min(30, Math.ceil(total)));
    }
}
```

#### 3.4.2 桥梁课程推荐算法

```java
/**
 * 桥梁课程推荐服务
 */
@Service
public class BridgeCourseRecommendationService {

    /**
     * 基于缺口报告推荐桥梁课程
     */
    public BridgeRecommendation recommend(String transitionId, GapDetectionResult gapResult) {
        String transitionType = determineTransitionType(
            gapResult.getSourceGrade(), gapResult.getTargetGrade());

        // 1. 获取该过渡类型的所有桥梁课程
        List<BridgeCourse> allCourses = bridgeCourseRepository
            .findByTransitionType(transitionType);

        // 2. 匹配缺口知识点
        Set<String> gapKpIds = new HashSet<>();
        gapResult.getWeakFoundations().forEach(g -> gapKpIds.add(g.getKnowledgePointId()));
        gapResult.getBridgeGaps().forEach(g -> gapKpIds.add(g.getKnowledgePointId()));
        gapResult.getPrerequisiteGaps().forEach(g -> gapKpIds.add(g.getKnowledgePointId()));

        // 3. 计算每门课程与缺口的匹配度
        List<ScoredCourse> scored = allCourses.stream()
            .map(course -> {
                Set<String> courseKps = new HashSet<>(course.getTargetGapKps());
                Set<String> intersection = new HashSet<>(courseKps);
                intersection.retainAll(gapKpIds);

                double relevanceScore = (double) intersection.size() / courseKps.size();
                double coverageScore = (double) intersection.size() / gapKpIds.size();

                // 综合得分 = 相关性*0.6 + 覆盖度*0.4
                double totalScore = relevanceScore * 0.6 + coverageScore * 0.4;

                return new ScoredCourse(course, totalScore, intersection);
            })
            .filter(sc -> sc.getScore() > 0.1)  // 过滤低相关度
            .sorted(Comparator.comparing(ScoredCourse::getScore).reversed())
            .collect(Collectors.toList());

        // 4. 贪心选择：优先选覆盖最多未覆盖缺口的高分课程
        List<BridgeCourse> recommended = greedySelect(scored, gapKpIds);

        // 5. 按学科分组并排序
        Map<String, List<BridgeCourse>> bySubject = recommended.stream()
            .collect(Collectors.groupingBy(BridgeCourse::getSubject));

        // 6. 计算总预计时长
        double totalHours = recommended.stream()
            .mapToDouble(BridgeCourse::getEstimatedHours)
            .sum();

        return BridgeRecommendation.builder()
            .transitionId(transitionId)
            .recommendedCourses(recommended)
            .coursesBySubject(bySubject)
            .totalEstimatedHours(totalHours)
            .gapCoverageRate(calculateCoverage(recommended, gapKpIds))
            .build();
    }
}
```

### 3.5 阶段五：进度数据迁移

#### 3.5.1 迁移策略

| 数据类型 | 迁移策略 | 说明 |
|----------|----------|------|
| 错题记录 | **保留并标记** | 保留全部错题，标记为「源学段」错题，不纳入新学段统计 |
| 学习进度 | **归档并重置** | 源学段进度归档到历史表，新学段从0开始 |
| 知识掌握度 | **降权保留** | 源学段掌握度降权为参考值，仅作为能力画像背景 |
| 成就/积分 | **全量保留** | 成就和积分是永久资产，不过期 |
| 学习计划 | **终止并重建** | 源学段计划标记为「已过期」 |
| AI对话历史 | **只读保留** | 历史对话可查看但不可继续 |
| 收藏/笔记 | **全量保留** | 个人学习资产永久保留 |

```java
/**
 * 学段数据迁移服务

@Service
@Transactional
public class TransitionDataMigrationService {

    public MigrationResult migrate(String transitionId, String studentId,
                                    String sourceGrade, String targetGrade,
                                    Map<String, String> textbookPrefs) {

        MigrationResult result = new MigrationResult();

        // 1. 错题记录：标记为源学段
        int mistakeCount = mistakeRecordRepository.updateStageTag(
            studentId, sourceGrade, "ARCHIVED_SOURCE_STAGE");
        result.setMigratedMistakes(mistakeCount);

        // 2. 学习进度：归档
        List<LearningProgress> progresses = learningProgressRepository
            .findByStudentIdAndGrade(studentId, sourceGrade);
        for (LearningProgress p : progresses) {
            progressArchiveRepository.save(p.toArchive(sourceGrade));
        }
        result.setArchivedProgress(progresses.size());

        // 3. 知识掌握度：降权处理
        knowledgeMasteryService.downgradeWeight(studentId, sourceGrade, 0.3);

        // 4. 学习计划：终止
        int terminatedPlans = studyPlanRepository.terminateByStudentAndGrade(
            studentId, sourceGrade, "STAGE_TRANSITION");
        result.setTerminatedPlans(terminatedPlans);

        // 5. 学生档案：更新年级和教材版本
        StudentProfile profile = studentProfileRepository.findByStudentId(studentId);
        profile.setGrade(targetGrade);
        profile.setStage(extractStage(targetGrade));
        profile.setTextbookPreferences(textbookPrefs);
        profile.setStageTransitionedAt(Instant.now());
        studentProfileRepository.save(profile);

        // 6. AI对话会话：标记只读
        conversationService.markSessionsReadOnly(studentId, sourceGrade);

        // 7. 创建新学段初始能力画像
        abilityProfileService.initializeForNewStage(studentId, targetGrade, sourceGrade);

        // 8. 更新过渡记录状态
        transitionRepository.updateState(transitionId, TransitionState.DATA_MIGRATED);

        return result;
    }
}
```

### 3.6 阶段六：学习计划重建

#### 3.6.1 计划重建逻辑

过渡期的学习计划包含两部分：

1. **桥梁学习计划**（短期，2-4周）：基于缺口检测推荐的桥梁课程
2. **常规学习计划**（长期，按学期）：新学段的日常学习任务

```java
/**
 * 过渡期学习计划重建服务
 */
@Service
public class TransitionPlanRebuildService {

    public RebuiltPlanResult rebuildPlan(String transitionId, String studentId,
                                          String targetGrade,
                                          BridgeRecommendation bridgeRec) {

        // 1. 创建桥梁学习计划（优先级最高）
        StudyPlan bridgePlan = StudyPlan.builder()
            .id(generateId())
            .studentId(studentId)
            .planType(PlanType.BRIDGE_TRANSITION)
            .name("升学衔接学习计划")
            .grade(targetGrade)
            .startDate(Instant.now())
            .endDate(Instant.now().plus(Duration.ofDays(bridgeRec.getEstimatedDays())))
            .priority(100)  // 最高优先级
            .build();

        // 为每门推荐课程创建任务
        for (BridgeCourse course : bridgeRec.getRecommendedCourses()) {
            StudyTask task = StudyTask.builder()
                .planId(bridgePlan.getId())
                .taskType(TaskType.BRIDGE_COURSE)
                .title(course.getTitle())
                .subject(course.getSubject())
                .contentReference(course.getId())
                .estimatedMinutes((int)(course.getEstimatedHours() * 60))
                .build();
            bridgePlan.addTask(task);
        }
        studyPlanRepository.save(bridgePlan);

        // 2. 预创建新学段常规计划模板
        StudyPlan regularPlan = StudyPlan.builder()
            .id(generateId())
            .studentId(studentId)
            .planType(PlanType.REGULAR_SEMESTER)
            .name(extractSemesterName(targetGrade) + "学习计划")
            .grade(targetGrade)
            .startDate(getSemesterStartDate(targetGrade))
            .endDate(getSemesterEndDate(targetGrade))
            .priority(50)
            .status(PlanStatus.PENDING_ACTIVATION)  // 待桥梁计划完成后激活
            .activationCondition("BRIDGE_PLAN_COMPLETED")  // 激活条件
            .build();

        // 3. 根据新教材版本生成章节任务
        Map<String, String> textbooks = studentProfileRepository
            .findTextbookPreferences(studentId);
        for (Map.Entry<String, String> entry : textbooks.entrySet()) {
            String subject = entry.getKey();
            String textbook = entry.getValue();
            List<ChapterOutline> chapters = chapterService
                .getChapterOutline(textbook, targetGrade, subject);

            for (ChapterOutline chapter : chapters) {
                StudyTask task = StudyTask.builder()
                    .planId(regularPlan.getId())
                    .taskType(TaskType.CHAPTER_LEARNING)
                    .title(chapter.getName())
                    .subject(subject)
                    .contentReference(chapter.getId())
                    .estimatedMinutes(chapter.getEstimatedMinutes())
                    .weekNumber(chapter.getSuggestedWeek())
                    .build();
                regularPlan.addTask(task);
            }
        }
        studyPlanRepository.save(regularPlan);

        // 4. 更新过渡记录
        transitionRepository.updateState(transitionId, TransitionState.PLAN_REBUILT);

        return RebuiltPlanResult.builder()
            .bridgePlanId(bridgePlan.getId())
            .regularPlanId(regularPlan.getId())
            .bridgeTaskCount(bridgePlan.getTasks().size())
            .regularTaskCount(regularPlan.getTasks().size())
            .build();
    }
}
```

```java
/**
 * 新学段环境激活服务

@Service
public class StageActivationService {

    public ActivationResult activate(String transitionId, String studentId,
                                      String targetGrade) {

        ActivationChecklist checklist = new ActivationChecklist();

        // 1. 验证桥梁计划完成度（至少80%或用户主动跳过）
        StudyPlan bridgePlan = studyPlanRepository
            .findByTransitionIdAndType(transitionId, PlanType.BRIDGE_TRANSITION);
        boolean bridgeCompleted = bridgePlan == null
            || bridgePlan.getProgress() >= 0.8
            || bridgePlan.getStatus() == PlanStatus.SKIPPED;
        checklist.setBridgeCourseCompleted(bridgeCompleted);

        // 2. 验证学生档案已更新
        StudentProfile profile = studentProfileRepository.findByStudentId(studentId);
        checklist.setProfileUpdated(profile.getGrade().equals(targetGrade));

        // 3. 验证教材版本已配置
        checklist.setTextbooksConfigured(
            profile.getTextbookPreferences() != null
            && !profile.getTextbookPreferences().isEmpty());

        // 4. 验证新学段能力画像已创建
        boolean profileInitialized = abilityProfileService
            .isInitialized(studentId, targetGrade);
        checklist.setAbilityProfileInitialized(profileInitialized);

        // 5. 验证学习计划已就绪
        StudyPlan regularPlan = studyPlanRepository
            .findActiveByStudentAndGrade(studentId, targetGrade);
        checklist.setStudyPlanReady(regularPlan != null);

        // 6. 执行激活
        if (checklist.allPassed()) {
            // 激活常规学习计划
            if (regularPlan != null) {
                regularPlan.setStatus(PlanStatus.ACTIVE);
                studyPlanRepository.save(regularPlan);
            }

            // 更新首页推荐引擎的学段上下文
            homeRecommendationService.refreshContext(studentId);

            // 发送激活通知
            notificationService.sendStageActivatedNotice(studentId, targetGrade);

            // 更新过渡记录
            transitionRepository.updateState(transitionId, TransitionState.ENV_ACTIVATED);

            return ActivationResult.success(checklist);
        } else {
            return ActivationResult.incomplete(checklist);
        }
    }
}
```

### 5.1 异常场景与处理策略

### 5.2 回滚机制

```java
/**
 * 过渡回滚服务
 */
@Service
public class TransitionRollbackService {

    /**
     * 从快照恢复到过渡前状态
     */
    @Transactional
    public void rollback(String transitionId) {
        TransitionRecord record = transitionRepository.findById(transitionId)
            .orElseThrow(() -> new TransitionNotFoundException(transitionId));

        // 只能回滚未完成的过渡
        if (record.getState() == TransitionState.COMPLETED) {
            throw new TransitionAlreadyCompletedException(transitionId);
        }

        String snapshotId = record.getSnapshotId();
        TransitionSnapshot snapshot = snapshotRepository.findById(snapshotId)
            .orElseThrow(() -> new SnapshotNotFoundException(snapshotId));

        String studentId = record.getStudentId();

        // 1. 恢复学生档案
        StudentProfileSnapshot profileSnap = snapshot.getStudentProfile();
        studentProfileRepository.restoreFromSnapshot(studentId, profileSnap);

        // 2. 恢复学习进度
        progressService.restoreFromSnapshot(studentId, snapshot.getLearningProgress());

        // 3. 恢复错题状态
        mistakeRecordRepository.restoreStageTag(studentId, record.getSourceGrade());

        // 4. 恢复学习计划
        studyPlanRepository.restoreTerminatedPlans(studentId, record.getSourceGrade());

        // 5. 删除过渡期间新建的数据
        studyPlanRepository.deleteByTransitionId(transitionId);
        abilityProfileService.deleteNewStageProfile(studentId, record.getTargetGrade());

        // 6. 更新过渡状态
        record.setState(TransitionState.ROLLBACK);
        record.setErrorMessage("User cancelled, rolled back from snapshot");
        transitionRepository.save(record);

        log.info("Transition rolled back: transitionId={}, studentId={}",
            transitionId, studentId);
    }
}
```

## 7. 关键业务规则

### 7.1 过渡前置条件

| 规则 | 说明 |
|------|------|
| 每学年仅允许一次过渡 | 同一学年内，已完成的过渡不可重复触发 |
| 过渡需用户或家长确认 | 12岁以下需家长确认，12岁以上可自行确认 |
| 过渡窗口期限制 | 自动触发仅限每年7-9月，手动触发不限 |
| 回滚窗口限制 | 过渡完成后7天内可回滚，超过则不可回滚 |

### 7.2 桥梁课程规则

| 规则 | 说明 |
|------|------|
| 最少选择 | 建议至少选择与缺口覆盖率最高的TOP3课程 |
| 跳过选项 | 用户可选择跳过桥梁课程直接进入新学段（需确认） |
| 进度要求 | 桥梁课程完成度达到80%即可激活常规计划 |
| 新学科处理 | 新增学科（如小升初的物理）自动包含入门桥梁课程 |

### 7.3 数据保留规则

| 规则 | 说明 |
|------|------|
| 历史可查 | 源学段的所有学习数据保留且可查看 |
| 错题联动 | 源学段错题仍可复习，但不计入新学段错题统计 |
| 成就累积 | 成就和积分跨学段累积，不重置 |
| 对话归档 | 历史AI对话可只读查看，不可继续 |

## 10. 部署与配置

### 10.1 配置项

```yaml
transition:
  # 过渡窗口期（每年可自动触发的月份）
  auto-trigger-months: [7, 8, 9]
  
  # 快照配置
  snapshot:
    max-retry: 3
    async-threshold: 1000  # 超过1000条记录时异步执行
    storage-type: OSS      # OSS / LOCAL
  
  # 缺口检测配置
  gap-detection:
    timeout-minutes: 30
    weak-threshold: 0.6    # 掌握度低于此值为薄弱
    prerequisite-threshold: 0.4  # 掌握度低于此值为前置缺失
    max-weak-points: 20    # 最多返回的薄弱点数
  
  # 桥梁课程配置
  bridge-course:
    min-coverage-rate: 0.7 # 最低覆盖率
    max-recommended: 10    # 最多推荐课程数
    completion-threshold: 0.8  # 桥梁课程完成度达标线
  
  # 回滚配置
  rollback:
    allowed-days: 7        # 过渡完成后可回滚天数
    async-threshold: 2000  # 超过2000条记录时异步回滚
  
  # 并发控制
  concurrency:
    max-concurrent-transitions: 100  # 同时进行的过渡上限
    rate-limit-per-user: 3           # 每用户每天最多触发次数
```
