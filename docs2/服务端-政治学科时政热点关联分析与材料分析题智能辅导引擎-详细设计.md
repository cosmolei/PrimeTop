# 服务端-政治学科时政热点关联分析与材料分析题智能辅导引擎-详细设计

## 1. 概述

### 1.1 模块定位

政治学科（道德与法治/思想政治）是中考和高考的必考科目，具有**时效性强、理论与实际结合紧密、主观题占比高、评分标准灵活**等鲜明特点。当前平台已覆盖语文、数学、英语、物理、化学、生物、地理、历史等学科的智能辅导引擎，政治学科是唯一缺失的学科级深度辅导模块。

本引擎为政治学科提供专属的智能辅导能力，重点解决三大痛点：
1. **时政热点与教材理论的自动关联**——每年中高考政治试题高度依赖近一年时事热点，人工维护效率低
2. **材料分析题的智能辅导**——政治主观题（材料分析题、论述题）占分比重大，学生普遍缺乏答题框架和逻辑链构建能力
3. **主观题评分与反馈**——政治学科评分弹性大，需要"踩关键词+逻辑结构+理论准确性"三维评估

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 时政热点采集与教材理论映射 | 自动采集热点事件，映射到教材知识点和考点 |
| 材料分析题智能理解 | 结构化解析材料分析题的材料文本、设问指向和知识范围 |
| 答题思路智能引导 | 按"理论定位→材料对接→逻辑组织→规范表达"四步引导 |
| 主观题智能评分 | 基于踩分点、关键词覆盖、逻辑完整度的多维度评分 |
| 答案语言规范化检测 | 检测口语化表达、政治术语使用准确性 |
| 易混概念辨析 | 自动识别学生答案中的概念混淆并提供纠正 |

interface CurrentAffairsEvent {
  id: string;                          // 事件唯一ID
  title: string;                       // 事件标题
  summary: string;                     // 事件摘要（200字以内）
  fullText: string;                    // 事件完整描述
  eventDate: Date;                     // 事件发生日期
  publishDate: Date;                   // 采集发布日期
  category: CurrentAffairsCategory;    // 事件分类
  source: string;                      // 信息来源（新华社、人民日报等）
  sourceUrl: string;                   // 原始链接
  keywords: string[];                  // 关键词标签
  relatedKnowledgePoints: {            // 关联教材知识点
    knowledgePointId: string;
    textbookChapter: string;
    module: PoliticalModule;           // 所属模块
    relevanceScore: number;            // 关联度评分 0-1
    mappingReason: string;             // 关联理由说明
  }[];
  examRelevance: ExamRelevanceLevel;   // 考试相关度
  status: ContentStatus;               // 草稿/审核中/已发布/已下线
  reviewScore: number;                 // 审核评分（内容质量）
  expireDate?: Date;                   // 过期日期（时政具有时效性）
  createdAt: Date;
  updatedAt: Date;
}

enum CurrentAffairsCategory {
  ECONOMY = 'economy',                 // 经济类（GDP、新发展理念、共同富裕）

  DIPLOMACY = 'diplomacy',             // 外交类（元首外交、人类命运共同体）
  SOCIETY = 'society',                 // 社会类（民生、法治、教育）
  CULTURE = 'culture',                 // 文化类（文化自信、核心价值观）

  LAW = 'law',                         // 法治类（新法规出台、典型案例）
  NATIONAL_DAY = 'national_day',       // 重要纪念日/节日

  HIGH = 'high',                       // 高度相关（极可能出现在中高考）

interface MaterialAnalysisQuestion {

#### 2.2.3 评分标准（ScoringRubric）

```typescript
interface ScoringRubric {
  totalPoints: number;
  // 踩分点定义
  scoringPoints: {
    index: number;
    description: string;               // 踩分点描述（如"体现新发展理念"）
    keywords: string[];                // 关键词集合（命中即给分）
    alternativeKeywords: string[][];   // 同义替代词组
    points: number;                    // 该点分值
    requiredTheory?: string;           // 必须出现的理论术语
  }[];
  // 逻辑结构评分
  logicStructure: {
    maxPoints: number;
    criteria: {
      hasClearFramework: number;       // 有清晰框架（总分总/并列/递进）
      hasMaterialCitation: number;     // 有材料引用/对接
      hasTheoryApplication: number;    // 有理论应用
      hasLogicalFlow: number;          // 逻辑流畅、层次分明
    };
  };
  // 语言规范评分
  languageNorm: {
    maxPoints: number;
    criteria: {
      correctTerminology: number;      // 政治术语使用准确
      noColloquialism: number;         // 无口语化表达
      conciseExpression: number;       // 表达简练
    };
  };
  // 扣分项
  deductions: {
    conceptualError: number;           // 概念性错误（每处扣分）
    factualError: number;              // 事实性错误
    offTopic: number;                  // 偏题/跑题
    exceeding: number;                 // 超出字数限制
  };
}
```

### 4.4 关键算法

#### 4.4.1 踩分点多层匹配算法

```python
def match_scoring_points(student_answer: str, rubric: ScoringRubric) -> list:
    """
    三层匹配策略：
    1. 精确关键词匹配（快速，高精度）
    2. 模糊匹配 + 同义词组（中等覆盖）
    3. 语义相似度匹配（高覆盖，LLM辅助）
    """
    results = []

    for point in rubric.scoringPoints:
        # 第一层：精确匹配
        exact_hits = []
        for kw in point.keywords:
            if kw in student_answer:
                exact_hits.append(kw)

        if exact_hits:
            results.append({
                'index': point.index,
                'status': 'full' if len(exact_hits) >= len(point.keywords) * 0.6 else 'partial',
                'matchedKeywords': exact_hits,
                'missedKeywords': [k for k in point.keywords if k not in exact_hits],
                'earned': point.points if len(exact_hits) >= len(point.keywords) * 0.6 else point.points * 0.5
            })
            continue

        # 第二层：同义词组匹配
        fuzzy_hits = []
        for alt_group in point.alternativeKeywords:
            for alt in alt_group:
                if alt in student_answer:
                    fuzzy_hits.append(alt)
                    break

        if fuzzy_hits:
            results.append({
                'index': point.index,
                'status': 'partial',
                'matchedKeywords': fuzzy_hits,
                'missedKeywords': point.keywords,
                'earned': point.points * 0.5
            })
            continue

        # 第三层：语义相似度（调用嵌入模型）
        # 仅当前两层未命中时触发，控制成本
        semantic_score = compute_semantic_similarity(
            student_answer,
            point.description + ' ' + ' '.join(point.keywords)
        )

        if semantic_score >= 0.75:
            results.append({
                'index': point.index,
                'status': 'partial',
                'matchedKeywords': [],
                'missedKeywords': point.keywords,
                'earned': point.points * 0.5,
                'semanticMatch': True,
                'confidence': semantic_score
            })
        else:
            results.append({
                'index': point.index,
                'status': 'missed',
                'matchedKeywords': [],
                'missedKeywords': point.keywords,
                'earned': 0
            })

    return results
```

#### 4.4.2 时政热点-知识点关联算法

```python
async def map_affairs_to_knowledge(
    affair: CurrentAffairsEvent,
    knowledge_base: KnowledgePointStore
) -> list:
    """
    将时政事件映射到教材知识点
    采用检索 + LLM校验两阶段策略
    """
    # 阶段一：向量检索候选知识点
    query_text = f"{affair.title} {affair.summary} {' '.join(affair.keywords)}"
    candidates = await knowledge_base.vector_search(
        query=query_text,
        filter={'subject': 'politics', 'grade_range': [affair.target_grade]},
        top_k=15,
        min_score=0.5
    )

    if not candidates:
        return []

    # 阶段二：LLM 精确校验关联性
    candidate_texts = [
        f"知识点：{c.name}\n内容：{c.core_content}\n章节：{c.chapter}"
        for c in candidates
    ]

    prompt = f"""你是政治学科教研专家。请判断以下时政事件与各知识点的关联性。

时政事件：
标题：{affair.title}
摘要：{affair.summary}
关键词：{', '.join(affair.keywords)}

候选知识点：
{chr(10).join(candidate_texts)}

请对每个知识点输出JSON：
{{
  "knowledge_point_id": "ID",
  "relevance_score": 0.0-1.0,
  "mapping_reason": "关联理由（简要说明该知识点如何与时政事件相关）",
  "exam_angle": "可能的考试命题角度"
}}

仅返回 relevance_score >= 0.5 的知识点。"""

    llm_result = await llm_service.complete(
        prompt=prompt,
        model="gpt-4o-mini",  # 使用较快模型控制成本
        temperature=0.1,
        response_format="json"
    )

    mappings = parse_json(llm_result)
    # 合并候选元数据
    id_to_candidate = {c.id: c for c in candidates}
    for m in mappings:
        if m['knowledge_point_id'] in id_to_candidate:
            c = id_to_candidate[m['knowledge_point_id']]
            m['political_module'] = c.module
            m['textbook_chapter'] = c.chapter

    return sorted(mappings, key=lambda x: x['relevance_score'], reverse=True)
```

    public GuideAnswerResponse guideAnswer(GuideAnswerRequest request) {

    /**
     * 主观题智能评分（核心方法）

    @Transactional
    public ScoreAnswerResponse scoreAnswer(ScoreAnswerRequest request) {
        long startTime = System.currentTimeMillis();

        // 1. 加载题目与评分标准
        PoliticalQuestion question = questionRepo.findById(request.getQuestionId())
                .orElseThrow(() -> new BusinessException("QUESTION_NOT_FOUND"));
        ScoringRubric rubric = question.getPrompts().get(0).getScoringRubric();

        // 2. 预处理学生答案
        String normalizedAnswer = AnswerPreprocessor.normalize(request.getAnswerText());

        // 3. 踩分点多层匹配
        List<ScoringPointResult> pointResults = scoringEngine.matchScoringPoints(
                normalizedAnswer, rubric
        );

        // 4. 逻辑结构评分
        LogicScoreResult logicResult = scoringEngine.scoreLogic(
                normalizedAnswer, rubric.getLogicStructure()
        );

        // 5. 语言规范评分
        LanguageScoreResult languageResult = scoringEngine.scoreLanguage(
                normalizedAnswer, rubric.getLanguageNorm()
        );

        // 6. 概念错误检测
        List<ConceptError> conceptErrors = conceptDetector.detect(
                normalizedAnswer, question.getModule()
        );

        // 7. 扣分计算
        BigDecimal deduction = calculateDeductions(conceptErrors, rubric);

        // 8. 汇总分数
        BigDecimal totalScore = calculateTotalScore(
                pointResults, logicResult, languageResult, deduction, rubric
        );

        // 9. 对于低置信度评分（语义匹配占比高），调用LLM复核
        if (shouldLlmReview(pointResults, totalScore)) {
            totalScore = llmReviewScore(
                    normalizedAnswer, question, pointResults, totalScore
            );
        }

        // 10. 生成反馈
        ScoringFeedback feedback = generateFeedback(
                question, normalizedAnswer, pointResults,
                logicResult, languageResult, conceptErrors, request.getScoringMode()
        );

        // 11. 能力维度诊断
        AbilityDimension ability = diagnoseAbility(
                pointResults, logicResult, languageResult, conceptErrors, rubric
        );

        // 12. 持久化
        PoliticalAnswerRecord record = buildRecord(
                request, question, totalScore, rubric,
                pointResults, logicResult, languageResult,
                conceptErrors, feedback, ability
        );
        answerRepo.save(record);

        log.info("政治主观题评分完成 student={} score={}/{} elapsed={}ms",
                request.getStudentId(), totalScore, rubric.getTotalPoints(),
                System.currentTimeMillis() - startTime);

        return ScoreAnswerResponse.builder()
                .recordId(record.getId())
                .score(totalScore)
                .maxScore(rubric.getTotalPoints())
                .scoringPoints(pointResults)
                .logicScore(logicResult)
                .languageScore(languageResult)
                .conceptErrors(conceptErrors)
                .feedback(feedback)
                .abilityDimension(ability)
                .build();
    }

    /**
     * 判断是否需要LLM复核评分
     */
    private boolean shouldLlmReview(List<ScoringPointResult> results, BigDecimal score) {
        // 如果超过40%的踩分点通过语义匹配（非关键词命中），则需要LLM复核
        long semanticMatches = results.stream()
                .filter(r -> r.isSemanticMatch() && r.getStatus() == Partial)
                .count();
        double ratio = (double) semanticMatches / results.size();
        return ratio > 0.4;
    }
}

    @Async
    public void processSingleNews(RawNewsItem news) {
        // 去重检测
        Optional<CurrentAffairsEvent> existing = affairsRepo
                .findSimilar(news.getTitle(), news.getPublishDate(), 30);
        if (existing.isPresent()) {
            // 已有相似事件，跳过或更新
            if (news.getContent().length() > existing.get().getFullText().length()) {
                updateExisting(existing.get(), news);
            }
            return;
        }

        // AI预处理：摘要 + 分类 + 关键词
        PreprocessResult preprocessed = llmService.complete(
                PreprocessPrompt.build(news),
                model = "gpt-4o-mini",
                temperature = 0.1
        );

        // 构建事件对象
        CurrentAffairsEvent event = CurrentAffairsEvent.builder()
                .title(news.getTitle())
                .summary(preprocessed.getSummary())
                .fullText(news.getContent())
                .eventDate(news.getEventDate())
                .publishDate(LocalDateTime.now())
                .category(preprocessed.getCategory())
                .source(news.getSourceName())
                .sourceUrl(news.getUrl())
                .keywords(preprocessed.getKeywords())
                .status(ContentStatus.DRAFT)
                .build();

        // 知识点关联映射
        List<KnowledgeMapping> mappings = mapToKnowledgePoints(event);
        event.setRelatedKnowledgePoints(mappings);

        // 考试相关度评估
        ExamRelevanceLevel relevance = assessExamRelevance(event);
        event.setExamRelevance(relevance);

        // 保存
        CurrentAffairsEvent saved = affairsRepo.save(event);

        // 高相关度事件推送审核队列
        if (relevance == ExamRelevanceLevel.HIGH) {
            notifyReviewQueue(saved);
        }
    }

    /**
     * 知识点关联映射
     */
    private List<KnowledgeMapping> mapToKnowledgePoints(CurrentAffairsEvent event) {

        List<KnowledgePoint> candidates = kpService.vectorSearch(
                queryText, "politics", 15, 0.5
        );

        if (candidates.isEmpty()) return List.of();

        // LLM校验
        String llmResult = llmService.complete(
                KnowledgeMappingPrompt.build(event, candidates),
                model = "gpt-4o-mini",
                temperature = 0.1,
                responseFormat = "json"
        );

        List<KnowledgeMapping> mappings = parseMappingResult(llmResult, candidates);
        return mappings.stream()
                .filter(m -> m.getRelevanceScore() >= 0.5)
                .sorted((a, b) -> Double.compare(
                        b.getRelevanceScore(), a.getRelevanceScore()))
                .toList();
    }

/**

@Component
@Slf4j
public class ConceptErrorDetector {

    @Autowired
    private PoliticalTermDictionary termDictionary;
    @Autowired
    private LLMService llmService;

    // 常见易混术语对（本地规则，快速检测）
    private static final List<ConfusableTermPair> CONFUSABLE_TERMS = List.of(
        new ConfusableTermPair("人民代表大会", "人民代表大会制度",
            "前者是国家权力机关，后者是根本政治制度"),
        new ConfusableTermPair("人民民主专政", "人民当家作主",
            "前者是国体，后者是本质"),
        new ConfusableTermPair("基本政治制度", "根本政治制度",
            "基本=多党合作、民族区域自治、基层群众自治；根本=人民代表大会制度"),
        new ConfusableTermPair("全国人大常委会", "全国人民代表大会",
            "前者是常设机关，后者是国家权力机关"),
        new ConfusableTermPair("国有经济", "公有制经济",
            "国有经济是公有制经济的组成部分"),
        new ConfusableTermPair("按劳分配", "按劳动要素分配",
            "前者是公有制范围内的分配方式，后者是市场经济中的分配方式"),
        new ConfusableTermPair("矛盾的普遍性", "矛盾的特殊性",
            "普遍性=共性，特殊性=个性"),
        new ConfusableTermPair("物质", "意识",
            "物质决定意识，意识对物质有能动的反作用"),
        new ConfusableTermPair("价值规律", "价值观",
            "前者是经济规律，后者是社会意识"),
        new ConfusableTermPair("依法行政", "依法执政",
            "前者是政府的要求，后者是党的要求")
    );

    /**
     * 检测学生答案中的概念错误
     */
    public List<ConceptError> detect(String answerText, PoliticalModule module) {
        List<ConceptError> errors = new ArrayList<>();

        // 第一层：基于本地规则字典的快速检测
        for (ConfusableTermPair pair : CONFUSABLE_TERMS) {
            if (answerText.contains(pair.getWrongInContext())
                    && module == pair.getRelevantModule()) {
                errors.add(ConceptError.builder()
                        .studentText(pair.getWrongInContext())
                        .errorType(ConceptErrorType.TERM_CONFUSION)
                        .correctExpression(pair.getCorrectTerm())
                        .explanation(pair.getExplanation())
                        .severity("moderate")
                        .build());
            }
        }

        // 第二层：LLM深度检测（检测上下文中的概念误用）
        if (answerText.length() > 50) {  // 长答案才走LLM
            List<ConceptError> llmErrors = llmDetectConceptErrors(answerText, module);
            // 去重合并
            for (ConceptError llmError : llmErrors) {
                boolean alreadyDetected = errors.stream()
                        .anyMatch(e -> e.getStudentText().equals(llmError.getStudentText()));
                if (!alreadyDetected) {
                    errors.add(llmError);
                }
            }
        }

        return errors;
    }

    /**
     * 语言规范检测
     */
    public List<LanguageIssue> detectLanguageIssues(String text, PoliticalModule module) {
        List<LanguageIssue> issues = new ArrayList<>();

        // 检测口语化表达
        String[] colloquialisms = {"特别牛", "很厉害", "超级好", "就是说", "然后呢", "反正"};
        for (String colloq : colloquialisms) {
            int idx = text.indexOf(colloq);
            if (idx >= 0) {
                issues.add(LanguageIssue.builder()
                        .type("colloquialism")
                        .originalText(colloq)
                        .suggestion("替换为书面表达")
                        .position(idx)
                        .build());
            }
        }

        // 检测术语不规范（使用术语词典）
        for (PoliticalTerm term : termDictionary.getInformalVariants(module)) {
            if (text.contains(term.getInformalForm())) {
                issues.add(LanguageIssue.builder()
                        .type("wrong_term")
                        .originalText(term.getInformalForm())
                        .suggestion(term.getStandardForm())
                        .position(text.indexOf(term.getInformalForm()))
                        .build());
            }
        }

        return issues;
    }

    private List<ConceptError> llmDetectConceptErrors(
            String answerText, PoliticalModule module) {
        String prompt = """你是政治学科教研专家。请检测以下学生答案中的概念错误。

模块：{module}
学生答案：{answer}

请检测以下类型的错误：
1. 术语混淆（如把"根本政治制度"和"基本政治制度"混用）
2. 原理误用（如把矛盾的普遍性原理用在需要特殊性的语境中）
3. 事实错误（如把人大常委的职权写成全国人大的职权）
4. 知识范围越界（如用经济知识回答政治问题）
5. 逻辑颠倒（如把"物质决定意识"写成"意识决定物质"）

仅输出JSON数组，每项包含：
student_text（学生原文）、error_type、correct_expression、explanation、severity""";

        String result = llmService.complete(
                prompt.replace("{module}", module.name())
                      .replace("{answer}", answerText),
                model = "gpt-4o-mini",
                temperature = 0.1
        );
        return parseConceptErrors(result);
    }
}

| `OCR_QUALITY_LOW` | POL-1003 | 手写答案OCR置信度低 | 提示"识别结果可能不准确，请核对" + 允许手动修正 |
| `LLM_SCORE_TIMEOUT` | POL-2001 | LLM评分超时 | 先返回关键词匹配分数，LLM结果异步更新 |
| `LLM_SCORE_FAILED` | POL-2002 | LLM评分失败 | 降级为纯规则评分 + 标记"评分精度有限" |
| `AFFAIRS_FETCH_FAILED` | POL-3001 | 时政源采集失败 | 使用上次缓存数据 + 告警 |
| `AFFAIRS_MAPPING_EMPTY` | POL-3002 | 知识点映射结果为空 | 标记为"待人工标注" + 不发布 |
| `CONCEPT_DICT_MISSING` | POL-4001 | 概念词典缺失某模块 | 跳过本地检测，仅走LLM |
| `SCORING_RUBRIC_INCOMPLETE` | POL-5001 | 题目缺少评分标准 | 拒绝评分 + 提示"该题尚未配置评分标准" |

### 7.2 降级策略

```java
/**
 * 评分降级策略
 */
public class ScoringFallbackHandler {

    /**
     * 智能评分降级链
     */
    public ScoreAnswerResponse scoreWithFallback(
            ScoreAnswerRequest request, PoliticalQuestion question) {
        try {
            // 正常流程：关键词匹配 + 语义匹配 + LLM反馈
            return fullScoring(request, question);
        } catch (LLMTimeoutException e) {
            log.warn("LLM评分超时，降级为纯规则评分");
            // 降级1：跳过LLM，仅关键词+逻辑规则评分
            return ruleBasedScoring(request, question)
                    .toBuilder()
                    .feedback(Feedback.builder()
                            .overall("评分基于规则匹配完成，详细反馈稍后更新")
                            .build())
                    .degraded(true)
                    .build();
        } catch (LLMException e) {
            log.warn("LLM评分失败，降级为纯规则评分");
            // 同上
            return ruleBasedScoring(request, question)
                    .toBuilder()
                    .degraded(true)
                    .build();
        } catch (Exception e) {
            log.error("评分系统异常", e);
            // 最终兜底：返回0分 + 提示人工评分
            return ScoreAnswerResponse.builder()
                    .score(BigDecimal.ZERO)
                    .degraded(true)
                    .feedback(Feedback.builder()
                            .overall("自动评分暂时不可用，请等待教师评分")
                            .build())
                    .build();
        }
    }
}
```

## 9. 安全考虑

### 9.1 内容安全

- **时政内容审核**：所有自动采集的时政热点必须经过教研审核后才能发布给学生
- **政治敏感性过滤**：确保时政内容不涉及敏感政治话题，与国家教育方针保持一致
- **LLM输出审核**：AI生成的引导内容和反馈必须经过内容安全过滤
- **学生答案安全**：学生作答内容不外泄，评分完成后仅存储脱敏摘要

### 9.2 评分公平性

- **评分一致性**：同一题目同一答案多次评分结果偏差不超过±1分（满分10分制）
- **版本追踪**：每次评分模型版本和规则版本必须记录，便于回溯
- **教师复核覆盖**：对AI评分与教师评分差异超过2分的案例进行回流分析
- **偏差检测**：定期检测AI评分是否存在系统性偏差（如对长答案偏好/短答案偏见）
