# 端到端流程设计 - 虚拟实验模拟操作与数据记录完整链路

> 版本：v1.0 | 创建日期：2026-06-13 | 模块代号：`e2e-virtual-experiment`

## 1. 概述

### 1.1 文档目的

本文档描述学生从**发现并选择实验**→**加载实验场景**→**交互操作与参数调节**→**记录实验数据**→**提交实验报告**→**获得AI反馈与知识点关联**的完整端到端链路。旨在将客户端物理/化学/生物实验组件与服务端实验配置、数据记录、学习行为、学情分析等后端服务串联为一个可编码实现的完整流程。

### 1.2 关联模块

| 模块 | 文档 | 本链路中的角色 |
|------|------|---------------|
| 物理实验模拟组件 | 客户端-物理实验模拟与力学分析交互组件-详细设计.md | 力学/运动学/电学实验交互渲染 |
| 化学实验模拟组件 | 客户端-化学实验模拟与化学反应方程式交互组件-详细设计.md | 化学反应/酸碱中和等实验交互 |
| 生物实验模拟组件 | 客户端-生物实验模拟与生命科学交互组件-详细设计.md | 显微镜/遗传学等实验交互 |
| 实验数据管理服务 | 服务端-实验数据管理与虚拟实验参数配置服务-详细设计.md | 实验配置下发、参数校验、记录存储 |
| 知识点体系引擎 | 知识点体系与教材映射引擎-详细设计.md | 实验与知识点映射 |
| AI辅导对话引擎 | AI对话引擎与会话管理-详细设计.md | 实验AI讲解 |
| 学习行为事件流 | 学习行为事件流与跨模块级联处理引擎-详细设计.md | 实验行为事件发布与消费 |
| 学情分析 | 学情分析-详细设计.md | 实验数据回流至能力画像 |
| 用户额度管控 | 用户额度与API调用管控系统-详细设计.md | 实验使用次数与权限校验 |
| 资源包下载管理器 | 客户端资源包下载管理器-详细设计.md | 实验资源包分发 |

### 3.4 客户端数据结构

```dart
/// 实验列表项模型
class ExperimentListItem {
  final int id;
  final String sceneCode;
  final String name;
  final String subject;
  final String category;
  final String coverImageUrl;
  final int difficultyLevel;
  final int estimatedDuration;
  final List<String> applicablePhases;
  final List<KnowledgePointRef> knowledgePoints;
  final CompletionStatus? completionStatus;
  final LocalCacheStatus localCacheStatus;
  final int resourceSizeBytes;
}

enum LocalCacheStatus {
  upToDate,    // 本地缓存最新
  outdated,    // 本地缓存过期
  notCached,   // 未缓存
  downloading, // 正在下载
}

enum CompletionStatus {
  notStarted,
  inProgress,
  completed,
}
```

## 4. 阶段二：实验场景加载

### 4.1 加载流程

```
用户点击实验卡片
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 1. 额度检查                                      │
│    GET /api/v1/user-quotas/experiment            │
│    → 检查今日实验次数、会员权益                    │
│    → 额度不足 → 弹窗引导开通会员                  │
└──────────────────────┬──────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────┐
│ 2. 获取实验配置                                  │
│    GET /api/v1/experiments/{id}/config            │
│    → 返回参数定义、资源清单、知识点映射            │
│    → 携带本地缓存版本号（If-None-Match）           │
│    → 304 Not Modified → 使用本地缓存              │
└──────────────────────┬──────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────┐
│ 3. 资源包检查与下载                              │
│    → 本地缓存版本 == 服务端版本 → 跳过下载        │

└──────────────────────┬──────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────┐
│ 4. 创建实验会话                                  │
│    POST /api/v1/exp-sessions                     │
│    → 服务端创建 ExperimentSession 记录            │
│    → 返回 session_id + 默认参数                   │
│    → 开始计时                                    │
└──────────────────────┬──────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────┐
│ 5. 初始化客户端实验引擎                          │
│    → 根据学科创建对应 SimulationEngine            │
│    → 加载默认参数值                               │
│    → 初始化渲染画布                               │
│    → 渲染实验场景就绪                             │
└─────────────────────────────────────────────────┘
```

## 5. 阶段三：交互操作与参数调节

### 5.1 操作事件流

学生在实验场景中的操作会产生一系列事件，部分事件需要上报服务端：

```
用户操作事件分类：

┌─────────────────────────────────────────────────────────┐
│                     客户端本地处理                        │
│  - 参数滑块拖动（实时更新渲染）                          │
│  - 模拟运行/暂停/重置                                    │
│  - 画布缩放/平移                                        │
│  - 物体拖拽定位                                         │
│  - 速度调节（0.5x / 1x / 2x）                          │
│  - 图表实时绘制                                         │
└──────────────────────────┬──────────────────────────────┘
                           │ 关键操作上报
                           ▼
┌─────────────────────────────────────────────────────────┐
│                  上报服务端的事件                         │
│  - 参数确认变更（松手/确认）                              │
│  - 模拟运行开始/暂停/结束                                │
│  - 数据快照保存                                         │
│  - 关键现象触发（碰撞、反应完成、细胞分裂完成等）          │
│  - 请求AI辅助讲解                                       │
└─────────────────────────────────────────────────────────┘
```

### 5.3 客户端事件采集器

```dart
/// 实验操作事件采集器
class ExperimentEventCollector {
  final String sessionId;
  final List<ExperimentEvent> _buffer = [];
  Timer? _flushTimer;
  static const int _maxBufferSize = 20;
  static const Duration _flushInterval = Duration(seconds: 10);

  ExperimentEventCollector(this.sessionId) {
    _flushTimer = Timer.periodic(_flushInterval, (_) => flush());
  }

  /// 记录参数变更
  void onParamChanged(String paramCode, double oldValue, double newValue) {
    _addEvent(ExperimentEvent(
      eventTime: DateTime.now(),
      eventType: 'PARAM_CHANGE',
      payload: {
        'paramCode': paramCode,
        'oldValue': oldValue,
        'newValue': newValue,
      },
    ));
  }

  /// 记录模拟开始
  void onSimStart(Map<String, double> params, double speed) {
    _addEvent(ExperimentEvent(
      eventTime: DateTime.now(),
      eventType: 'SIM_START',
      payload: {
        'params': params,
        'simulationSpeed': speed,
      },
    ));
  }

  /// 记录数据快照
  void onDataSnapshot(Map<String, dynamic> snapshotData) {
    _addEvent(ExperimentEvent(
      eventTime: DateTime.now(),
      eventType: 'DATA_SNAPSHOT',
      payload: snapshotData,
    ));
  }

  /// 记录关键现象触发
  void onPhenomenonTriggered(
    String phenomenonCode,
    String description,
    Map<String, dynamic> snapshotData,
  ) {
    _addEvent(ExperimentEvent(
      eventTime: DateTime.now(),
      eventType: 'PHENOMENON_TRIGGERED',
      payload: {
        'phenomenonCode': phenomenonCode,
        'description': description,
        'snapshotData': snapshotData,
      },
    ));
  }

  void _addEvent(ExperimentEvent event) {
    _buffer.add(event);
    if (_buffer.length >= _maxBufferSize) {
      flush();
    }
  }

  /// 批量上报事件到服务端
  Future<void> flush() async {
    if (_buffer.isEmpty) return;
    final events = List<ExperimentEvent>.from(_buffer);
    _buffer.clear();
    try {
      await ExperimentApi.batchReportEvents(sessionId, events);
    } catch (e) {
      // 上报失败，重新放入缓冲区（保留最新N条）
      _buffer.insertAll(0, events.take(_maxBufferSize));
    }
  }

  void dispose() {
    _flushTimer?.cancel();
    flush();
  }
}
```

```dart
class ExperimentDataRow {
  final double time;           // 模拟时间（秒）
  final Map<String, double> values;  // 各物理量数值

  // 例如物理斜面实验：
  // { "position_x": 0.5, "position_y": 0.25,
  //   "velocity": 3.2, "acceleration": 4.9,
  //   "friction_force": 1.96, "normal_force": 9.8 }
}

/// 实验数据记录管理器
class ExperimentDataRecorder {
  final List<ExperimentDataRow> _rows = [];
  double _recordInterval; // 记录间隔（秒）

  ExperimentDataRecorder({double recordInterval = 0.1}) {
    _recordInterval = recordInterval;
  }

  /// 模拟引擎每步调用
  void onSimStep(double time, Map<String, double> currentValues) {
    if (_rows.isEmpty || time - _rows.last.time >= _recordInterval) {
      _rows.add(ExperimentDataRow(
        time: time,
        values: Map.from(currentValues),
      ));
    }
  }

  /// 导出为表格数据
  List<Map<String, dynamic>> exportTable() {
    if (_rows.isEmpty) return [];
    final keys = _rows.first.values.keys.toList();
    return [
      {'time': 0.0, ...Map.fromEntries(keys.map((k) => MapEntry(k, 0.0)))},
      ..._rows.map((r) => {'time': r.time, ...r.values}),
    ];
  }

  /// 导出为图表数据序列
  Map<String, List<FlSpot>> exportChartData(List<String> fields) {
    return {
      for (final field in fields)
        field: _rows
            .where((r) => r.values.containsKey(field))
            .map((r) => FlSpot(r.time, r.values[field]!))
            .toList(),
    };
  }

  int get rowCount => _rows.length;
  void clear() => _rows.clear();
}
```

```java
/**
 * 实验报告评分引擎
 */
@Service
public class ExperimentReportScorer {

    /**
     * 计算实验完成度评分
     * 满分100，由四个维度加权计算
     */
    public ExperimentScore calculateScore(ExperimentSession session, ReportSubmitRequest request) {
        // 维度1：完成率（权重30%） - 是否完成了引导步骤
        double completionRate = calculateCompletionRate(session);
        
        // 维度2：参数探索覆盖率（权重25%） - 是否尝试了不同的参数组合
        double paramExploration = calculateParamExploration(session);
        
        // 维度3：数据记录完整度（权重25%） - 是否记录了足够的数据点
        double dataRecording = calculateDataRecording(session);
        
        // 维度4：结论质量（权重20%） - 用户结论是否覆盖关键知识点
        double conclusionQuality = calculateConclusionQuality(
            request.getConclusion(), session.getSceneCode()
        );
        
        double totalScore = completionRate * 30
            + paramExploration * 25
            + dataRecording * 25
            + conclusionQuality * 20;
        
        return new ExperimentScore(
            (int) Math.round(totalScore),
            new ScoreBreakdown(completionRate, paramExploration, dataRecording, conclusionQuality)
        );
    }

    /**
     * 参数探索覆盖率
     * 基于参数变更记录，计算用户探索了参数空间的多少比例
     */
    private double calculateParamExploration(ExperimentSession session) {
        List<ExperimentParameterDef> paramDefs = paramDefRepo
            .findBySceneId(session.getExperimentId());
        List<ExperimentEvent> paramChanges = eventRepo
            .findBySessionAndType(session.getId(), "PARAM_CHANGE");

        int exploredParams = 0;
        for (ExperimentParameterDef def : paramDefs) {
            boolean explored = paramChanges.stream()
                .anyMatch(e -> {
                    String code = e.getPayload().get("paramCode").asText();
                    return def.getParamCode().equals(code);
                });
            if (explored) exploredParams++;
        }

        return paramDefs.isEmpty() ? 1.0 : (double) exploredParams / paramDefs.size();
    }
}
```

```dart
/// 离线事件同步管理器
class OfflineEventSyncManager {
  final LocalDatabase _db;
  final ExperimentApi _api;

  /// 保存事件到本地
  Future<void> saveEventLocally(String sessionId, ExperimentEvent event) async {
    await _db.insert('offline_exp_events', {
      'session_id': sessionId,
      'event_type': event.eventType,
      'payload': jsonEncode(event.payload),
      'event_time': event.eventTime.toIso8601String(),
      'sync_status': 'PENDING',
      'created_at': DateTime.now().toIso8601String(),
    });
  }

  /// 网络恢复后同步
  Future<void> syncPendingEvents() async {
    final pending = await _db.query(
      'offline_exp_events',
      where: 'sync_status = ?',
      whereArgs: ['PENDING'],
      orderBy: 'event_time ASC',
      limit: 100,
    );

    if (pending.isEmpty) return;

    // 按session分组
    final grouped = groupBy(pending, (e) => e['session_id'] as String);

    for (final entry in grouped.entries) {
      try {
        await _api.batchReportEvents(
          entry.key,
          entry.value.map((e) => ExperimentEvent.fromJson(e)).toList(),
        );
        // 标记为已同步
        await _db.update(
          'offline_exp_events',
          {'sync_status': 'SYNCED'},
          where: 'session_id = ?',
          whereArgs: [entry.key],
        );
      } catch (e) {
        // 同步失败，下次重试
        logger.warning('同步实验事件失败: $e');
      }
    }
  }
}
```

## 14. 安全与合规

### 14.1 参数防篡改

服务端对所有参数变更做范围校验，防止客户端篡改参数产生不合理结果：

```java
/**
 * 参数校验服务
 * 即使客户端已做范围限制，服务端仍需二次校验
 */
@Service
public class ParameterValidationService {

    public ValidationResult validateParams(Long sceneId, Map<String, Double> params) {
        List<ExperimentParameterDef> defs = paramDefRepo.findBySceneId(sceneId);

        List<String> errors = new ArrayList<>();
        for (ExperimentParameterDef def : defs) {
            Double value = params.get(def.getParamCode());
            if (value == null) {
                if (def.isRequired()) {
                    errors.add(def.getParamCode() + ": 必填参数缺失");
                }
                continue;
            }

            // 范围校验
            if (def.getMinValue() != null && value < parseDouble(def.getMinValue())) {
                errors.add(def.getParamCode() + ": 值 " + value + " 低于最小值 " + def.getMinValue());
            }
            if (def.getMaxValue() != null && value > parseDouble(def.getMaxValue())) {
                errors.add(def.getParamCode() + ": 值 " + value + " 超过最大值 " + def.getMaxValue());
            }
        }

        return errors.isEmpty()
            ? ValidationResult.ok()
            : ValidationResult.fail(errors);
    }
}
```
