# 客户端-学情分析页面架构与报告展示交互 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

学情分析客户端模块是学生学习数据在移动端的可视化呈现层，负责将服务端计算出的掌握度、薄弱点、能力画像、学习趋势等数据以分龄适配的方式展示给学生和家长。包含学情概览页、学科详情页、知识点掌握度可视化、能力雷达图、学情报告（日报/周报/月报）展示、学习趋势图表等核心页面。

### 1.2 核心目标

1. **即时可感知**：学生打开学情页即能快速了解自己的学习状态
2. **分龄适配**：幼儿/小学以正向激励和趣味元素为主，初中/高中以数据精准和分析深度为主
3. **报告可读性**：学情报告需让家长一目了然，学生有成就感
4. **离线可用**：最近一份报告和基础学情数据在离线状态下可查看
5. **低刷新成本**：数据变更时增量更新 UI，避免全量重载

### 1.3 依赖关系

| 依赖模块 | 说明 |
|---------|------|
| 学情分析-详细设计 | 提供所有学情 API 接口（概览/学科/掌握度/能力/趋势/报告） |
| 学习数据可视化与图表渲染引擎 | 提供统一图表组件 VizChart（雷达图/折线图/柱状图/热力图等） |
| 分龄UI适配与交互设计规范 | 分龄设计 Token 和组件适配策略 |
| 客户端状态管理架构 | Riverpod Provider 体系 |
| 学习报告生成与交付服务 | 服务端报告生成与推送 |
| 客户端网络请求治理与弱网适配方案 | 请求重试、缓存策略 |
| 客户端页面状态模式与骨架屏加载空态错误态设计规范 | 加载态/空态/错误态 |
| 权限管理与角色访问控制 | 学生 vs 家长的数据可见范围 |

### 1.4 入口场景

| 入口 | 触发方式 | 目标页面 |
|------|---------|---------|
| 底部导航「学习」Tab → 学情概览 | 点击 | 学情概览页 |
| 首页工作台 → 薄弱点提醒卡片 | 点击 | 学情概览页 → 薄弱点详情 |

## 2. 页面结构与导航设计

### 2.1 页面层级

```
学情概览页 (LearningDashboardPage)           ← 主入口
├── 学科详情页 (SubjectDetailPage)            ← 按学科下钻
│   ├── 知识点掌握度页 (MasteryDetailPage)     ← 知识点级详情

│       └── 报告分享页 (ReportSharePage)      ← 分享给家长
├── 薄弱知识点详情页 (WeakPointDetailPage)    ← 薄弱点下钻
```

### 4.2 Repository 实现

```dart
// lib/features/learning/data/repositories/learning_repository.dart

class LearningRepository {
  final ApiClient _api;
  final LearningLocalCache _cache;

  /// 获取概览 — 先返回缓存，同时请求网络刷新
  Future<LearningOverviewDto> getOverview() async {
    final cached = _cache.overview;
    final cachedAt = _cache.overviewCachedAt;

    // 缓存未过期 → 直接返回
    if (cached != null && cachedAt != null &&
        DateTime.now().difference(cachedAt) < LearningCacheConfig.overviewTTL) {
      return cached;
    }

    try {
      final response = await _api.get('/api/v1/learning/overview');
      final dto = LearningOverviewDto.fromJson(response.data);
      // 异步更新缓存
      _cache.overview = dto;
      _cache.overviewCachedAt = DateTime.now();
      return dto;
    } catch (e) {
      // 网络失败但有旧缓存 → 返回旧缓存 + 标记 stale
      if (cached != null) return cached;
      rethrow;
    }
  }

  /// 获取报告详情 — 支持离线
  Future<LearningReportDto> getReportDetail(String reportId) async {
    // 先查本地缓存
    final cached = _cache.recentReports?.where((r) => r.reportId == reportId).firstOrNull;
    if (cached != null) return cached;

    final response = await _api.get('/api/v1/learning/reports/$reportId');
    final dto = LearningReportDto.fromJson(response.data);

    // 加入缓存
    final reports = List<LearningReportDto>.from(_cache.recentReports ?? []);
    reports.removeWhere((r) => r.reportId == reportId);
    reports.insert(0, dto);
    if (reports.length > 10) reports.removeRange(10, reports.length);
    _cache.recentReports = reports;

    return dto;
  }

  // ... 其他方法类似模式
}
```

```dart
class StudySummaryCard extends ConsumerWidget {
  final int totalMinutes;
  final int weeklyMinutes;

  const StudySummaryCard({
    super.key,

    required this.streakDays,
    required this.overallMastery,
    required this.ageGroup,
  });

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    return Card(
      elevation: ageGroup == AgeGroup.primary ? 2 : 1,
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(
          ageGroup == AgeGroup.primary ? 20.0 : 12.0,
        ),
      ),
      child: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // 分龄标题
            Text(
              ageGroup == AgeGroup.primary
                ? '🌟 今日学习'
                : '学习总览',
              style: context.textTheme.titleMedium?.copyWith(
                fontWeight: FontWeight.bold,
              ),
            ),
            const SizedBox(height: 12),

            // 三个指标
            Row(
              children: [
                _MetricChip(
                  icon: ageGroup == AgeGroup.primary ? '⏰' : Icons.timer_outlined,
                  value: _formatDuration(totalMinutes),
                  label: '今日',
                  ageGroup: ageGroup,
                ),
                const SizedBox(width: 12),
                _MetricChip(
                  icon: ageGroup == AgeGroup.primary ? '📅' : Icons.date_range,
                  value: _formatDuration(weeklyMinutes),
                  label: '本周',
                  ageGroup: ageGroup,
                ),
                const SizedBox(width: 12),
                _MetricChip(
                  icon: ageGroup == AgeGroup.primary ? '🔥' : Icons.local_fire_department,
                  value: '$streakDays天',
                  label: '连续',
                  ageGroup: ageGroup,
                ),
              ],
            ),
            const SizedBox(height: 16),

            // 综合掌握度进度条
            Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Row(
                  mainAxisAlignment: MainAxisAlignment.spaceBetween,
                  children: [
                    Text(
                      '综合掌握度',
                      style: context.textTheme.bodySmall,
                    ),
                    Text(
                      '${overallMastery.round()}%',
                      style: context.textTheme.bodySmall?.copyWith(
                        fontWeight: FontWeight.bold,
                        color: _masteryColor(overallMastery),
                      ),
                    ),
                  ],
                ),
                const SizedBox(height: 4),
                ClipRRect(
                  borderRadius: BorderRadius.circular(4),
                  child: LinearProgressIndicator(
                    value: overallMastery / 100,
                    backgroundColor: Colors.grey.shade200,
                    valueColor: AlwaysStoppedAnimation(_masteryColor(overallMastery)),
                    minHeight: 8,
                  ),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }

  Color _masteryColor(double value) {
    if (value >= 90) return const Color(0xFF4CAF50); // 绿 - 精通
    if (value >= 70) return const Color(0xFF2196F3); // 蓝 - 熟练
    if (value >= 40) return const Color(0xFFFF9800); // 橙 - 学习中
    return const Color(0xFFF44336);                   // 红 - 初学
  }

  String _formatDuration(int minutes) {
    if (minutes < 60) return '${minutes}分钟';
    final h = minutes ~/ 60;
    final m = minutes % 60;
    return m > 0 ? '${h}h${m}min' : '${h}h';
  }
```

## 8. 下拉刷新与数据更新策略

### 8.1 刷新触发

| 触发方式 | 刷新范围 | 行为 |
|---------|---------|------|
| 手动下拉 | 概览页全量 | `ref.invalidate(learningOverviewProvider)` |

| 推送触发 | 报告列表 | 收到新报告推送通知 → `ref.invalidate(reportListProvider)` |

### 8.2 增量更新策略

```dart
// 监听学习行为事件，增量更新概览数据
@riverpod
class LearningOverviewNotifier extends _$LearningOverviewNotifier {
  @override
  Future<LearningOverviewDto> build() {
    // 订阅学习行为事件
    final eventBus = ref.read(eventBusProvider);
    eventBus.on<LearningActivityEvent>().listen((event) {
      // 增量更新，不重新请求全量
      _incrementalUpdate(event);
    });
    return _fetchOverview();
  }

  void _incrementalUpdate(LearningActivityEvent event) {
    final current = state.valueOrNull;
    if (current == null) return;

    // 局部更新：增加今日学习时长
    state = AsyncData(current.copyWith(
      totalStudyMinutes: current.totalStudyMinutes + (event.durationSeconds ~/ 60),
    ));
  }
}
```

## 10. 错误处理

### 10.1 错误码映射

| 服务端错误码 | 客户端处理 | 用户提示 |
|------------|----------|---------|
| `LEARNING_001` - 无学习数据 | 显示空态组件 | "还没有学习记录" |
| `LEARNING_002` - 学科未配置 | 引导设置教材版本 | "请先设置学习科目" |
| `LEARNING_003` - 报告生成中 | 轮询等待 + 骨架屏 | "报告正在生成中..." |
| `LEARNING_004` - 数据统计中 | 显示上次数据 | "数据更新中" |
| `LEARNING_010` - 权限不足 | 家长身份校验 | "请使用家长身份查看" |
| HTTP 503 | 离线缓存 + 重试 | "网络异常，显示缓存数据" |

### 10.2 错误处理组件

```dart
class LearningErrorWidget extends StatelessWidget {
  final Object error;
  final VoidCallback onRetry;

  @override
  Widget build(BuildContext context) {
    final errorType = _classifyError(error);

    return Center(
      child: Padding(
        padding: const EdgeInsets.all(32),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Icon(errorType.icon, size: 48, color: Colors.grey),
            const SizedBox(height: 16),
            Text(errorType.title, style: context.textTheme.titleSmall),
            const SizedBox(height: 8),
            Text(errorType.message, style: context.textTheme.bodySmall, textAlign: TextAlign.center),
            const SizedBox(height: 24),
            if (errorType.retryable)
              OutlinedButton.icon(
                icon: const Icon(Icons.refresh),
                label: const Text('重试'),
                onPressed: onRetry,
              ),
          ],
        ),
      ),
    );
  }

  _ErrorType _classifyError(Object error) {
    if (error is DioException && error.type == DioExceptionType.connectionError) {
      return _ErrorType(
        icon: Icons.wifi_off,
        title: '网络连接失败',
        message: '请检查网络后重试',
        retryable: true,
      );
    }
    if (error is ApiException && error.code == 'LEARNING_001') {
      return _ErrorType(
        icon: Icons.analytics_outlined,
        title: '暂无学习数据',
        message: '完成第一次学习后将自动生成学情分析',
        retryable: false,
      );
    }
    return _ErrorType(
      icon: Icons.error_outline,
      title: '加载失败',
      message: '请稍后重试',
      retryable: true,
    );
  }
}
```

## 11. 性能优化

### 11.1 图表渲染优化

| 优化项 | 策略 |
|-------|------|
| 首屏渲染 | 概览页优先加载文字数据，图表延迟 100ms 渲染 |
| 降采样 | 折线图超过 100 个数据点时使用 LTTB 降采样 |
| 图表缓存 | 已渲染图表截图缓存，页面切换回来时先显示缓存图 |
| 懒加载 | 雷达图、趋势图等不在视口内的组件延迟构建 |

### 11.2 数据请求优化

| 优化项 | 策略 |
|-------|------|
| 请求合并 | 概览页一次请求 `/overview` 包含所有子数据，避免多次请求 |
| 预加载 | 概览页加载完成后预加载报告列表和能力画像 |
| 缓存优先 | 所有 API 请求先查本地缓存，缓存有效则直接返回 |
| 增量更新 | 学习行为事件触发局部更新，避免全量重载 |
