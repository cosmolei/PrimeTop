## 1. 模块概述

### 1.1 模块定位

教育内容图片资源智能优化与多端自适应分发管线引擎（以下简称「图片管线引擎」或 **ImagePipe**）是 PrimeTop 服务端的统一图片基础设施层。它负责将教研人员、内容运营、教师和系统自动生成等各类渠道上传的原始图片资源（教材扫描页、理科公式截图、几何图形、物理实验装置图、化学分子结构图、生物解剖图、地图、历史文献照片、手绘插画等），经过**内容感知分析、智能压缩、多分辨率变体生成、现代格式转换、质量校验**等环节，最终通过 CDN 以自适应方式分发给不同设备和网络环境下的客户端。

本服务与现有模块的职责边界：

| 模块 | 职责范围 | 与本引擎的关系 |
| --- | --- | --- |
| 教育内容多媒体转码处理与自适应码率流媒体分发服务 | 视频/音频转码、HLS/DASH 流媒体分发 | 本引擎专注于**静态图片**，不处理流媒体 |
| 图片处理与 OCR 识别管线 | 用户拍照→OCR 文字提取→题目结构化 | 本引擎处理的是**平台内容图片**（运营上传/系统生成），非用户拍照 |
| CDN 内容分发网络与多区域边缘缓存策略 | CDN 节点管理、缓存策略、多供应商调度 | 本引擎的输出上传至 CDN，依赖 CDN 模块分发 |
| 客户端-统一图片加载缓存框架与智能预加载引擎 | 客户端内存/磁盘缓存、预加载、占位图 | 本引擎为客户端提供多分辨率 URL，客户端按策略选取 |
| 教育内容数字版权保护与内容安全分发系统 | DRM 加密、防盗链、水印 | 本引擎支持水印叠加与防盗链 Token 签名 |

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 图片分析准确率 | 内容类型识别准确率 ≥ 96%（6 大类：文本密集型、公式/符号型、线条图型、照片型、混合型、装饰型） |
| 压缩率 | 在肉眼无损感知下，文本/公式类图片体积减少 ≥ 35%；照片/装饰类 ≥ 60% |
| 多分辨率变体 | 每张图片自动生成 4 档：缩略图（thumb）、标清（standard）、高清（hd）、原图（original） |
| 现代格式覆盖 | AVIF + WebP 双格式输出，JPEG/PNG 后备，现代浏览器优先享用 AVIF |
| 处理吞吐 | 单节点 50 张/秒（平均 500KB/张），批量入库 1000 张 ≤ 30s |
| 端到端延迟 | 单张图片从上传到所有变体就绪 ≤ 3s（同步），批量异步 ≤ 5min |
| 质量校验 | 文字区域 PSNR ≥ 40dB（压缩后文字可读性不下降），SSIM ≥ 0.95 |
| 可观测性 | 每张图片全生命周期追踪：上传→分析→压缩→校验→分发→访问统计 |

### 1.3 核心使用场景

| 场景 | 图片类型 | 典型来源 | 特殊要求 |
| --- | --- | --- | --- |
| 同步课堂教材插图 | 混合型（文字+图） | 教材数字化扫描 | 文字清晰、色彩还原 |
| 理科公式渲染图 | 公式/符号型 | LaTeX 渲染 / 截图 | 高对比度、无损、抗锯齿 |
| 几何/物理图示 | 线条图型 | 教研制作 / 自动生成 | 边缘锐利、矢量感 |
| 生物/历史照片 | 照片型 | 运营上传 | 色彩准确、细节保留 |
| 拼音识字卡片 | 混合型 | 美工制作 | 色彩鲜艳、大字清晰 |
| 知识图谱缩略图 | 线条图型 | 系统自动渲染 | 小体积、结构清晰 |
| 学习报告封面/装饰 | 装饰型 | 系统生成 | 可高压缩 |
| 考试试卷扫描图 | 文本密集型 | 试卷数字化 | OCR 友好、文字无损失真 |
| 化学分子结构图 | 线条图型 | ChemDraw / RDKit 渲染 | 原子标签清晰、键线无断裂 |
| 地理地图 | 照片+线条混合 | 运营上传 / GIS 渲染 | 地名标注可读 |

### 1.4 术语约定

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 源图 | Source Image | 原始上传的图片文件 |
| 变体 | Variant | 源图经处理后的一个特定分辨率/格式版本 |
| 内容画像 | Content Profile | 对源图进行内容感知分析后得到的元数据（类型、复杂度、文字区域等） |
| 压缩配方 | Compression Recipe | 基于内容画像生成的差异化压缩策略 |
| 图片清单 | Image Manifest | 一张源图所有变体的 URL 和元数据集合 |
| 处理任务 | Processing Job | 一次图片处理流水线执行 |
| 智能裁剪 | Smart Crop | 基于显著性检测的自动裁剪（不同宽高比适配） |

```python
from enum import Enum

class ContentType(str, Enum):
    """图片内容类型分类"""
    TEXT_DENSE = "text_dense"       # 文本密集型：试卷扫描、教材整页

    DECORATIVE = "decorative"       # 装饰型：背景、封面、分隔图


class ResolutionTier(str, Enum):
    """分辨率档位"""

class ImageFormat(str, Enum):

    JPEG = "jpeg"   # JPEG - 通用后备
    PNG = "png"     # PNG - 无损后备(透明通道)


class JobStatus(str, Enum):
    """任务状态"""

    RUNNING = "running"
    SUCCESS = "success"

class AssetStatus(str, Enum):
    """资产状态"""
    PENDING = "pending"
```

## 4. 核心流程设计

### 4.1 图片上传与处理全链路

```
客户端/管理后台
    │
    │  POST /api/v1/images/upload  (multipart/form-data)
    │  或 SDK putObject()
    │
    ▼
┌─────────────────────────────────────────┐
│  Image Ingress                          │
│  1. 格式校验 (MIME + 魔数双重校验)        │
│  2. 尺寸限制检查 (最大 50MB, 最大 100MP)  │
│  3. EXIF 提取 (DPI, 色彩空间, 方向)      │
│  4. 感知哈希计算 (pHash 64bit)           │
│  5. 精确去重 (MD5 + pHash 双重检查)      │
│  6. 存储源图到对象存储                    │
│  7. 写入 image_assets 记录(status=pending)│
│  8. 投递处理任务到消息队列                 │
│  9. 返回 asset_id 给客户端               │
└──────────────┬──────────────────────────┘
               │
               ▼ MQ: image.process.topic
┌─────────────────────────────────────────┐
│  Image Pipeline Worker                  │
│                                         │
│  Stage 1: 内容感知分析                   │
│    ├─ 图片内容类型分类 (轻量CNN推理)      │
│    ├─ 文字区域检测 (EAST/DB模型)          │
│    ├─ 显著性检测 (导数显著性/深度模型)     │
│    ├─ 主色调提取 (K-means聚类)            │
│    └─ 复杂度计算 (边缘密度+频域熵)        │
```

## 6. 核心算法与关键代码

### 6.1 内容感知分析器

```python
"""
图片内容感知分析器
使用轻量CNN模型进行内容类型分类 + 传统CV进行细节分析
"""
import numpy as np
import cv2
import onnxruntime as ort
from dataclasses import dataclass
from typing import List, Tuple

@dataclass
class TextRegion:
    x: int
    y: int
    w: int
    h: int
    confidence: float

@dataclass 
class ContentProfile:
    content_type: ContentType
    complexity: float           # 0-1
    has_text: bool
    text_regions: List[TextRegion]
    dominant_colors: List[Tuple[str, float]]  # [(hex, ratio), ...]
    saliency_focus: Tuple[float, float]       # (x, y) 0-1
    edge_density: float
    is_transparent: bool


class ContentAnalyzer:
    def __init__(self, model_path: str = "models/content_classifier_v2.onnx"):
        self.session = ort.InferenceSession(model_path, providers=['CUDAExecutionProvider', 'CPUExecutionProvider'])
        self.input_name = self.session.get_inputs()[0].name
        
        # 内容类型标签
        self.labels = [
            ContentType.TEXT_DENSE, ContentType.FORMULA, ContentType.LINE_ART,
            ContentType.PHOTO, ContentType.MIXED, ContentType.DECORATIVE
        ]
    
    def analyze(self, image_path: str) -> ContentProfile:
        # 1. 读取图片
        img = cv2.imread(image_path, cv2.IMREAD_UNCHANGED)
        if img is None:
            raise ValueError(f"Cannot read image: {image_path}")
        
        # 2. 透明通道检测
        is_transparent = img.shape[2] == 4 if len(img.shape) == 3 else False
        
        # 3. CNN 内容类型分类
        rgb = cv2.cvtColor(img[:,:,:3], cv2.COLOR_BGR2RGB)
        input_tensor = self._preprocess(rgb)
        logits = self.session.run(None, {self.input_name: input_tensor})[0]
        probs = self._softmax(logits[0])
        content_type = self.labels[np.argmax(probs)]
        confidence = float(np.max(probs))
        
        # 低置信度时回退到规则判断
        if confidence < 0.7:
            content_type = self._rule_based_classify(rgb)
        
        # 4. 文字区域检测
        text_regions = self._detect_text_regions(rgb)
        
        # 5. 显著性焦点
        saliency_focus = self._compute_saliency_focus(rgb)
        
        # 6. 主色调提取
        dominant_colors = self._extract_dominant_colors(rgb)
        
        # 7. 复杂度计算
        edge_density = self._compute_edge_density(rgb)
        complexity = self._compute_complexity(rgb, edge_density, len(text_regions))
        
        return ContentProfile(
            content_type=content_type,
            complexity=complexity,
            has_text=len(text_regions) > 0,
            text_regions=text_regions,
            dominant_colors=dominant_colors,
            saliency_focus=saliency_focus,
            edge_density=edge_density,
            is_transparent=is_transparent,
        )
    
    def _preprocess(self, rgb: np.ndarray) -> np.ndarray:
        """CNN 输入预处理: resize 224x224, normalize"""
        resized = cv2.resize(rgb, (224, 224))
        normalized = (resized.astype(np.float32) - [0.485, 0.456, 0.406]) / [0.229, 0.224, 0.225]
        transposed = np.transpose(normalized, (2, 0, 1))
        return np.expand_dims(transposed, 0)
    
    def _softmax(self, x):
        e_x = np.exp(x - np.max(x))
        return e_x / e_x.sum()
    
    def _rule_based_classify(self, rgb: np.ndarray) -> ContentType:
        """规则回退分类"""
        gray = cv2.cvtColor(rgb, cv2.COLOR_RGB2GRAY)
        
        # 边缘密度
        edges = cv2.Canny(gray, 50, 150)
        edge_ratio = np.count_nonzero(edges) / edges.size
        
        # 颜色多样性
        pixels = rgb.reshape(-1, 3)
        unique_colors = len(np.unique(pixels // 32 * 32, axis=0))
        
        # 灰度分布
        hist = cv2.calcHist([gray], [0], None, [256], [0, 256])
        hist_norm = hist.ravel() / hist.sum()
        entropy = -np.sum(hist_norm * np.log2(hist_norm + 1e-10))
        
        if edge_ratio > 0.15 and unique_colors < 100:
            return ContentType.LINE_ART
        elif entropy > 7.0:
            return ContentType.TEXT_DENSE
        elif unique_colors > 500:
            return ContentType.PHOTO
        elif edge_ratio > 0.08:
            return ContentType.MIXED
        else:
            return ContentType.DECORATIVE
    
    def _detect_text_regions(self, rgb: np.ndarray) -> List[TextRegion]:
        """文字区域检测 (使用 EAST 或 DB 模型)"""
        gray = cv2.cvtColor(rgb, cv2.COLOR_RGB2GRAY)
        
        # 使用 MSER + 形态学方法快速检测文字候选区域
        mser = cv2.MSER_create()
        mser.setMinArea(100)
        mser.setMaxArea(14400)
        
        regions, _ = mser.detectRegions(gray)
        
        text_regions = []
        for region in regions:
            x, y, w, h = cv2.boundingRect(region.reshape(-1, 1, 2))
            aspect_ratio = w / h
            # 过滤非文字区域
            if 0.1 < aspect_ratio < 15 and h > 8:
                text_regions.append(TextRegion(x, y, w, h, confidence=0.8))
        
        # 合并重叠区域
        text_regions = self._merge_overlapping_regions(text_regions)
        return text_regions
    
    def _merge_overlapping_regions(self, regions: List[TextRegion], iou_threshold: float = 0.3) -> List[TextRegion]:
        if not regions:
            return []
        
        boxes = np.array([[r.x, r.y, r.x + r.w, r.y + r.h] for r in regions])
        indices = cv2.dnn.NMSBoxes(
            boxes.tolist(), 
            [r.confidence for r in regions],
            0.5, iou_threshold
        )
        return [regions[i] for i in indices.flatten()]
    
    def _compute_saliency_focus(self, rgb: np.ndarray) -> Tuple[float, float]:
        """计算显著性焦点 (使用谱残差法)"""
        gray = cv2.cvtColor(rgb, cv2.COLOR_RGB2GRAY).astype(np.float32)
        
        # 谱残差显著性
        saliency = cv2.saliency.StaticSaliencySpectralResidual_create()
        success, sal_map = saliency.computeSaliency(gray.astype(np.uint8))
        
        if not success:
            return (0.5, 0.5)
        
        # 找到权重中心
        rows, cols = sal_map.shape
        total = sal_map.sum()
        if total < 1e-10:
            return (0.5, 0.5)
        
        x_center = np.sum(np.arange(cols) * sal_map.sum(axis=0)) / total
        y_center = np.sum(np.arange(rows) * sal_map.sum(axis=1)) / total
        
        return (float(x_center / cols), float(y_center / rows))
    
    def _extract_dominant_colors(self, rgb: np.ndarray, k: int = 5) -> List[Tuple[str, float]]:
        """K-means 提取主色调"""
        pixels = rgb.reshape(-1, 3).astype(np.float32)
        
        # 采样加速 (大图取10000个采样点)
        if len(pixels) > 10000:
            indices = np.random.choice(len(pixels), 10000, replace=False)
            pixels = pixels[indices]
        
        criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 20, 1.0)
        _, labels, centers = cv2.kmeans(pixels, k, None, criteria, 3, cv2.KMEANS_PP_CENTERS)
        
        result = []
        total = len(labels)
        for i in range(k):
            count = np.sum(labels == i)
            ratio = count / total
            color = centers[i].astype(int)
            hex_color = f"#{color[0]:02x}{color[1]:02x}{color[2]:02x}"
            result.append((hex_color, float(ratio)))
        
        result.sort(key=lambda x: x[1], reverse=True)
        return result
    
    def _compute_edge_density(self, rgb: np.ndarray) -> float:
        """计算边缘密度"""
        gray = cv2.cvtColor(rgb, cv2.COLOR_RGB2GRAY)
        edges = cv2.Canny(gray, 50, 150)
        return float(np.count_nonzero(edges) / edges.size)
    
    def _compute_complexity(self, rgb: np.ndarray, edge_density: float, text_count: int) -> float:
        """计算内容复杂度 (0-1)"""
        gray = cv2.cvtColor(rgb, cv2.COLOR_RGB2GRAY)
        
        # 频域熵
        f = np.fft.fft2(gray)
        f_shift = np.fft.fftshift(f)
        magnitude = np.abs(f_shift)
        magnitude_norm = magnitude / (magnitude.sum() + 1e-10)
        freq_entropy = -np.sum(magnitude_norm * np.log2(magnitude_norm + 1e-10))
        freq_score = min(freq_entropy / 20.0, 1.0)  # 归一化
        
        # 综合复杂度
        complexity = 0.4 * edge_density * 5 + 0.3 * freq_score + 0.3 * min(text_count / 50, 1.0)
        return min(max(complexity, 0.0), 1.0)
```

```python
import os

class VariantGenerator:

    ) -> List[dict]:
        """
        为一张源图生成所有变体
        返回变体元数据列表
        """
        source = pyvips.Image.new_from_file(source_path, access="sequential")
        source_width = source.width
        source_height = source.height
        
        variants = []
        
        for tier, tier_config in self.tiers.items():
            # 计算目标尺寸
            target_w, target_h = self._compute_target_size(
                source_width, source_height, tier_config, recipe
            )
            
            if target_w < source_width or target_h < source_height:
                # 需要缩放
                scaled = source.thumbnail_image(
                    target_w,
                    height=target_h,
                    size=pyvips.Size.DOWN,
                    kernel=pyvips.Kernel.LANCZOS3
                )
            else:
                scaled = source
            
            # 后处理: 锐化
            if recipe.get("sharpen_after_resize", False) and tier != ResolutionTier.ORIGINAL:
                scaled = self._sharpen(scaled)
            
            # 格式转换
            formats = self._select_formats(content_profile, tier, recipe)
            
            for fmt in formats:
                variant = self._encode_variant(
                    scaled, fmt, tier, recipe, output_dir, 
                    source_width, source_height
                )
                variants.append(variant)
        
        return variants
    
    def _compute_target_size(
        self,
        src_w: int, src_h: int,
        tier_config: dict,
        recipe: dict
    ) -> Tuple[int, int]:
        """计算目标尺寸，保持宽高比"""
        max_w = tier_config["max_width"]
        max_h = tier_config["max_height"]
        
        if max_w is None:
            return src_w, src_h
        
        # 应用内容类型缩放限制
        max_downscale = recipe.get("max_downscale", 1.0)
        
        ratio = min(max_w / src_w, max_h / src_h, 1.0, max_downscale)
        target_w = max(1, int(src_w * ratio))
        target_h = max(1, int(src_h * ratio))
        
        return target_w, target_h
    
    def _select_formats(
        self,
        profile: ContentProfile,
        tier: ResolutionTier,
        recipe: dict
    ) -> List[str]:
        """根据内容类型和配方选择输出格式"""
        formats = []
        
        if recipe.get("use_png_for_all", False):
            return ["png", "webp", "avif"]  # PNG 为主，附带现代格式
        
        if tier == ResolutionTier.THUMB and recipe.get("use_png_for_thumb", False):
            return ["png", "webp", "avif"]
        
        if tier == ResolutionTier.STANDARD and recipe.get("use_png_for_standard", False):
            return ["png", "webp", "avif"]
        
        if profile.content_type == ContentType.PHOTO:
            # 照片: JPEG 为主
            return ["jpeg", "webp", "avif"]
        elif profile.content_type == ContentType.DECORATIVE:
            return ["jpeg", "webp", "avif"]
        else:
            # 其他: PNG + 现代格式
            return ["png", "webp", "avif"]
    
    def _encode_variant(
        self,
        image: pyvips.Image,
        fmt: str,
        tier: ResolutionTier,
        recipe: dict,
        output_dir: str,
        src_w: int, src_h: int
    ) -> dict:
        """编码单个变体"""
        quality_key = f"{fmt}_quality"
        quality = recipe.get(quality_key, 80)
        
        # 色度子采样
        chroma = recipe.get("chroma_subsampling", "4:2:0")
        
        suffix = f".{fmt}"
        filename = f"{tier.value}{suffix}"
        filepath = os.path.join(output_dir, filename)
        
        encode_params = {}
        
        if fmt in ("jpeg", "jpg"):
            encode_params = {
                "Q": quality,
                "interlace": True,        # 渐进式JPEG
                "optimize_coding": True,
                "subsample_mode": pyvips.ForeignJpegSubsample.ON if chroma == "4:2:0" else pyvips.ForeignJpegSubsample.OFF,
                "trellis_quant": True,
                "overshoot_deringing": True,
            }
        elif fmt == "webp":
            encode_params = {
                "Q": quality,
                "lossless": quality >= 100,
                "near_lossless": False,
                "smart_subsample": True,
                "reduction_effort": 4,    # 最大压缩努力
            }
        elif fmt == "avif":
            encode_params = {
                "Q": quality,
                "effort": 4,              # AVIF 编码努力 (0-9, 越高越慢但压缩率越好)
                "subsample_mode": pyvips.ForeignJpegSubsample.ON if chroma == "4:2:0" else pyvips.ForeignJpegSubsample.OFF,
            }
        elif fmt == "png":
            encode_params = {
                "compression": 9,
                "palette": recipe.get("palette_optimize", False),
                "colors": 256 if recipe.get("palette_optimize", False) else 0,
                "interlace": True,       # Adam7 隔行扫描
            }
        
        # 确保有 alpha 通道时保留
        if image.hasalpha():
            if fmt == "jpeg":
                # JPEG 不支持透明通道，需要合成白色背景
                background = pyvips.Image.black(image.width, image.height)
                background = background.draw_image([255, 255, 255], 0, 0)
                background = background.bandjoin([255] * (3 - background.bands))
                image = background.composite(image, pyvips.BlendMode.OVER)
        
        buf = image.write_to_buffer(f".{fmt}", **encode_params)
        
        with open(filepath, "wb") as f:
            f.write(buf)
        
        file_size = len(buf)
        
        return {
            "resolution_tier": tier.value,
            "format": fmt,
            "width": image.width,
            "height": image.height,
            "file_size": file_size,
            "filepath": filepath,
            "compression_ratio": round(1 - file_size / (src_w * src_h * 3), 4),  # vs 未压缩RGB
        }
    
    def _sharpen(self, image: pyvips.Image) -> pyvips.Image:
        """使用 Unsharp Mask 锐化"""
        # 卷积核: 中心加强，周围减弱
        kernel = pyvips.Image.new_from_array([
            [0, -1, 0],
            [-1, 5, -1],
            [0, -1, 0]
        ])
        return image.conv(kernel, precision=pyvips.Precision.INTEGER)
```

### 6.3 质量校验器

```python
"""
质量校验器 — 确保压缩后图片质量达标
"""
import cv2
import numpy as np
from typing import Optional

class QualityValidator:
    
    SSIM_THRESHOLD = 0.95   # 整体 SSIM 阈值
    TEXT_PSNR_THRESHOLD = 40.0  # 文字区域 PSNR 阈值(dB)
    
    def validate(
        self,
        source_path: str,
        variant_path: str,
        content_profile: ContentProfile,
        tier: ResolutionTier
    ) -> dict:
        """
        校验单个变体质量
        返回 {passed, ssim, text_psnr, suggestion}
        """
        source = cv2.imread(source_path)
        variant = cv2.imread(variant_path)
        
        if variant is None:
            return {"passed": False, "reason": "cannot_read_variant"}
        
        # 尺寸对齐（变体可能被缩放）
        if source.shape[:2] != variant.shape[:2]:
            variant_resized = cv2.resize(
                variant, (source.shape[1], source.shape[0]),
                interpolation=cv2.INTER_LANCZOS3
            )
        else:
            variant_resized = variant
        
        # 1. 整体 SSIM
        ssim = self._compute_ssim(source, variant_resized)
        
        # 2. 文字区域 PSNR (仅对包含文字的图片)
        text_psnr = None
        if content_profile.has_text and tier in (ResolutionTier.HD, ResolutionTier.ORIGINAL):
            text_psnr = self._compute_text_region_psnr(
                source, variant_resized, content_profile.text_regions
            )
        
        # 3. 判定
        passed = ssim >= self.SSIM_THRESHOLD
        if text_psnr is not None:
            passed = passed and text_psnr >= self.TEXT_PSNR_THRESHOLD
        
        suggestion = None
        if not passed:
            if ssim < self.SSIM_THRESHOLD:
                suggestion = f"increase_quality: ssim={ssim:.4f} < {self.SSIM_THRESHOLD}"
            elif text_psnr and text_psnr < self.TEXT_PSNR_THRESHOLD:
                suggestion = f"lossless_required: text_psnr={text_psnr:.1f}dB < {self.TEXT_PSNR_THRESHOLD}dB"
        
        return {
            "passed": passed,
            "ssim": round(ssim, 4),
            "text_psnr": round(text_psnr, 2) if text_psnr else None,
            "suggestion": suggestion
        }
    
    def _compute_ssim(self, img1: np.ndarray, img2: np.ndarray) -> float:
        """计算结构相似性指数 (SSIM)"""
        # 转灰度
        g1 = cv2.cvtColor(img1, cv2.COLOR_BGR2GRAY)
        g2 = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)
        
        # 使用 C2 = (0.05 * 255)^2 的常数
        C1 = (0.01 * 255) ** 2
        C2 = (0.03 * 255) ** 2
        
        # 高斯模糊计算均值和方差
        mu1 = cv2.GaussianBlur(g1.astype(np.float64), (11, 11), 1.5)
        mu2 = cv2.GaussianBlur(g2.astype(np.float64), (11, 11), 1.5)
        
        mu1_sq = mu1 ** 2
        mu2_sq = mu2 ** 2
        mu1_mu2 = mu1 * mu2
        
        sigma1_sq = cv2.GaussianBlur(g1.astype(np.float64) ** 2, (11, 11), 1.5) - mu1_sq
        sigma2_sq = cv2.GaussianBlur(g2.astype(np.float64) ** 2, (11, 11), 1.5) - mu2_sq
        sigma12 = cv2.GaussianBlur(g1.astype(np.float64) * g2.astype(np.float64), (11, 11), 1.5) - mu1_mu2
        
        ssim_map = ((2 * mu1_mu2 + C1) * (2 * sigma12 + C2)) / \
                   ((mu1_sq + mu2_sq + C1) * (sigma1_sq + sigma2_sq + C2))
        
        return float(ssim_map.mean())
    
    def _compute_text_region_psnR(
        self,
        source: np.ndarray,
        variant: np.ndarray,
        text_regions: List[TextRegion]
    ) -> float:
        """计算文字区域的 PSNR"""
        psnrs = []
        
        for region in text_regions:
            x, y, w, h = region.x, region.y, region.w, region.h
            
            # 裁剪区域
            src_crop = source[y:y+h, x:x+w]
            var_crop = variant[y:y+h, x:x+w]
            
            if src_crop.size == 0 or var_crop.size == 0:
                continue
            
            mse = np.mean((src_crop.astype(np.float64) - var_crop.astype(np.float64)) ** 2)
            if mse < 1e-10:
                psnrs.append(100.0)  # 完全一致
            else:
                psnr = 10 * np.log10((255 ** 2) / mse)
                psnrs.append(psnr)
        
        return float(np.mean(psnrs)) if psnrs else 100.0
```

```python
"""
智能裁剪器 — 基于显著性检测生成不同宽高比的裁剪
"""
import cv2
import numpy as np
from typing import List, Tuple

ASPECT_RATIOS = {
    "1:1": 1.0,
    "16:9": 16/9,
    "4:3": 4/3,
    "3:2": 3/2,
    "9:16": 9/16,
}

class SmartCropper:
    
    def generate_crops(
        self,
        image_path: str,
        saliency_focus: Tuple[float, float],
        source_width: int,
        source_height: int
    ) -> List[dict]:
        """为多种宽高比生成智能裁剪"""
        results = []
        
        for ratio_name, ratio in ASPECT_RATIOS.items():
            crop = self._compute_optimal_crop(
                source_width, source_height, ratio, saliency_focus
            )
            results.append({
                "aspect_ratio": ratio_name,
                **crop
            })
        
        return results
    
    def _compute_optimal_crop(
        self,
        src_w: int, src_h: int,
        target_ratio: float,
        focus: Tuple[float, float]
    ) -> dict:
        """
        计算最优裁剪窗口
        策略: 在保持目标宽高比的前提下，最大化裁剪面积，同时让焦点居中
        """
        src_ratio = src_w / src_h
        
        if target_ratio > src_ratio:
            # 目标更宽 — 以宽度为准，裁剪高度
            crop_w = src_w
            crop_h = int(src_w / target_ratio)
        else:
            # 目标更高 — 以高度为准，裁剪宽度
            crop_h = src_h
            crop_w = int(src_h * target_ratio)
        
        # 以显著性焦点为中心
        focus_x = int(focus[0] * src_w)
        focus_y = int(focus[1] * src_h)
        
        # 计算裁剪起点，确保不越界
        crop_x = max(0, min(focus_x - crop_w // 2, src_w - crop_w))
        crop_y = max(0, min(focus_y - crop_h // 2, src_h - crop_h))
        
        # 边界修正
        if crop_x + crop_w > src_w:
            crop_x = src_w - crop_w
        if crop_y + crop_h > src_h:
            crop_y = src_h - crop_h
        
        return {
            "crop_x": crop_x,
            "crop_y": crop_y,
            "crop_w": crop_w,
            "crop_h": crop_h,
            "focus_x": focus[0],
            "focus_y": focus[1],
        }
    
    def apply_crop(
        self,
        image_path: str,
        crop_info: dict,
        output_path: str,
        target_width: int = 640
    ) -> str:
        """执行裁剪并输出到文件"""
        img = cv2.imread(image_path)
        
        cropped = img[
            crop_info["crop_y"]:crop_info["crop_y"] + crop_info["crop_h"],
            crop_info["crop_x"]:crop_info["crop_x"] + crop_info["crop_w"]
        ]
        
        # 缩放到标准宽度
        if cropped.shape[1] > target_width:
            scale = target_width / cropped.shape[1]
            cropped = cv2.resize(
                cropped, (target_width, int(cropped.shape[0] * scale)),
                interpolation=cv2.INTER_LANCZOS3
            )
        
        cv2.imwrite(output_path, cropped, [cv2.IMWRITE_WEBP_QUALITY, 85])
        return output_path
```

### 6.5 自适应分发决策引擎

```python
"""
自适应分发决策引擎 — 根据设备/网络/场景选择最优变体
"""
from typing import Optional
from dataclasses import dataclass

@dataclass
class ClientContext:
    """客户端上下文信息"""
    dpr: float = 2.0                  # 设备像素比
    viewport_width: int = 375          # 视口宽度(css px)
    accept_formats: list = None        # 接受的格式列表
    save_data: bool = False            # 省流量模式
    downlink_mbps: float = 10.0        # 估算下行带宽
    effective_type: str = "4g"         # 有效连接类型
    is_low_end: bool = False           # 低端设备标记


@dataclass 
class SceneConfig:
    """场景配置"""
    LIST = {"default_tier": "thumb", "allow_upgrade": True}
    DETAIL = {"default_tier": "standard", "allow_upgrade": True}
    FULLSCREEN = {"default_tier": "hd", "allow_upgrade": True}
    PRINT = {"default_tier": "original", "allow_upgrade": False}
    THUMBNAIL = {"default_tier": "thumb", "allow_upgrade": False}


class AdaptiveDeliveryEngine:
    
    def resolve(
        self,
        asset_id: str,
        scene: str,
        explicit_width: Optional[int],
        client: ClientContext,
        content_type: ContentType
    ) -> dict:
        """
        解析最优变体
        返回 {tier, format, variant_key, url}
        """
        # 1. 场景基础决策
        scene_config = self._get_scene_config(scene)
        base_tier = scene_config["default_tier"]
        
        # 2. 设备感知升级
        if scene_config["allow_upgrade"] and explicit_width is None:
            device_tier = self._device_aware_tier(client)
        elif explicit_width:
            device_tier = self._width_to_tier(explicit_width * client.dpr)
        else:
            device_tier = base_tier
        
        # 3. 网络感知降级
        network_tier = self._network_aware_tier(client)
        
        # 4. 合并决策
        # 场景优先级最高，网络可以降级，设备可以升级
        if scene == "thumbnail" or scene == "print":
            final_tier = base_tier  # 这些场景不调整
        else:
            # 取场景和设备中较高的，再受网络限制
            final_tier = self._upgrade_tier(base_tier, device_tier)
            final_tier = self._downgrade_tier(final_tier, network_tier)
        
        # 5. 格式选择
        fmt = self._select_format(client, content_type)
        
        # 6. 查找变体
        variant_key = f"{final_tier.value}_{fmt.value}"
        
        return {
            "tier": final_tier.value,
            "format": fmt.value,
            "variant_key": variant_key,
            "decision_reason": self._explain_decision(
                base_tier, device_tier, network_tier, final_tier, fmt
            )
        }
    
    def _device_aware_tier(self, client: ClientContext) -> ResolutionTier:
        """根据设备DPR和视口确定分辨率档"""
        pixel_width = client.viewport_width * client.dpr
        
        if pixel_width <= 200:
            return ResolutionTier.THUMB
        elif pixel_width <= 640:
            return ResolutionTier.STANDARD
        elif pixel_width <= 1280:
            return ResolutionTier.HD
        else:
            return ResolutionTier.ORIGINAL
    
    def _width_to_tier(self, pixel_width: int) -> ResolutionTier:
        """像素宽度转分辨率档"""
        if pixel_width <= 200:
            return ResolutionTier.THUMB
        elif pixel_width <= 640:
            return ResolutionTier.STANDARD
        elif pixel_width <= 1280:
            return ResolutionTier.HD
        else:
            return ResolutionTier.ORIGINAL
    
    def _network_aware_tier(self, client: ClientContext) -> ResolutionTier:
        """根据网络状况确定可接受的最高分辨率"""
        if client.save_data:
            return ResolutionTier.STANDARD
        
        if client.effective_type in ("slow-2g", "2g"):
            return ResolutionTier.THUMB
        elif client.effective_type == "3g":
            return ResolutionTier.STANDARD
        elif client.downlink_mbps < 1.0:
            return ResolutionTier.STANDARD
        else:
            return ResolutionTier.HD
    
    def _select_format(self, client: ClientContext, content_type: ContentType) -> ImageFormat:
        """选择最优格式"""
        accept = client.accept_formats or []
        
        # AVIF 优先 (最佳压缩率)
        if "avif" in accept and not client.is_low_end:
            return ImageFormat.AVIF
        
        # WebP 次之
        if "webp" in accept:
            return ImageFormat.WEBP
        
        # 内容类型决定后备格式
        if content_type in (ContentType.TEXT_DENSE, ContentType.FORMULA, ContentType.LINE_ART):
            return ImageFormat.PNG  # 无损后备
        else:
            return ImageFormat.JPEG
    
    def _get_scene_config(self, scene: str) -> dict:
        configs = {
            "list": SceneConfig.LIST,
            "detail": SceneConfig.DETAIL,
            "fullscreen": SceneConfig.FULLSCREEN,
            "print": SceneConfig.PRINT,
            "thumbnail": SceneConfig.THUMBNAIL,
        }
        return configs.get(scene, SceneConfig.DETAIL)
    
    def _upgrade_tier(self, base: ResolutionTier, target: ResolutionTier) -> ResolutionTier:
        """取两个档位中较高的"""
        order = [ResolutionTier.THUMB, ResolutionTier.STANDARD, ResolutionTier.HD, ResolutionTier.ORIGINAL]
        base_idx = order.index(base)
        target_idx = order.index(target)
        return order[max(base_idx, target_idx)]
    
    def _downgrade_tier(self, current: ResolutionTier, limit: ResolutionTier) -> ResolutionTier:
        """取两个档位中较低的"""
        order = [ResolutionTier.THUMB, ResolutionTier.STANDARD, ResolutionTier.HD, ResolutionTier.ORIGINAL]
        cur_idx = order.index(current)
        limit_idx = order.index(limit)
        return order[min(cur_idx, limit_idx)]
    
    def _explain_decision(self, base, device, network, final, fmt):
        return f"scene={final.value}, device_suggest={device.value}, network_limit={network.value}, format={fmt.value}"
```

### 7.1 可见水印

```python
"""
可见水印引擎 — 在图片右下角叠加半透明平台标识
"""
import pyvips

class VisibleWatermark:
    def __init__(self, watermark_logo_path: str):
        self.logo = pyvips.Image.new_from_file(watermark_logo_path)
    
    def apply(self, image: pyvips.Image, opacity: float = 0.15) -> pyvips.Image:
        """叠加水印"""
        # 水印缩放到原图宽度的 15%
        wm_width = max(60, int(image.width * 0.15))
        wm = self.logo.thumbnail_image(wm_width)
        
        # 调整透明度
        if wm.hasalpha():
            wm = wm * opacity
        
        # 计算位置 (右下角, 边距 3%)
        margin = int(image.width * 0.03)
        x = image.width - wm.width - margin
        y = image.height - wm.height - margin
        
        # 合成
        result = image.composite(wm, pyvips.BlendMode.OVER, x=x, y=y)
        return result
```

### 7.2 隐含水印 (DCT域)

```python
"""
隐含水印 — 在 DCT 频域嵌入 asset_id 信息
抗压缩、抗裁剪、不可见
"""
import numpy as np
import cv2

class InvisibleWatermark:
    BLOCK_SIZE = 8
    # 使用中频系数对嵌入信息
    
    def embed(self, image: np.ndarray, message: str) -> np.ndarray:
        """
        在图片中嵌入隐含水印
        message: 通常是 asset_id 的哈希值 (32 bit)
        """
        # 转为 YCbCr, 只在 Y 通道操作
        if len(image.shape) == 3:
            ycrcb = cv2.cvtColor(image, cv2.COLOR_BGR2YCrCb)
            y_channel = ycrcb[:,:,0].astype(np.float32)
        else:
            y_channel = image.astype(np.float32)
        
        # 消息转 bit 数组
        bits = self._str_to_bits(message.ljust(32, '\0')[:32])
        
        h, w = y_channel.shape
        bit_idx = 0
        
        # 分块 DCT 嵌入
        for by in range(0, h - self.BLOCK_SIZE, self.BLOCK_SIZE):
            for bx in range(0, w - self.BLOCK_SIZE, self.BLOCK_SIZE):
                if bit_idx >= len(bits):
                    break
                
                block = y_channel[by:by+self.BLOCK_SIZE, bx:bx+self.BLOCK_SIZE]
                dct_block = cv2.dct(block)
                
                # 在中频系数位置嵌入 (3,4) 和 (4,3)
                q = 10.0
                if bits[bit_idx] == 1:
                    dct_block[3, 4] = (abs(dct_block[3, 4]) // q + 1) * q
                else:
                    dct_block[3, 4] = (abs(dct_block[3, 4]) // q) * q
                
                bit_idx += 1
                
                y_channel[by:by+self.BLOCK_SIZE, bx:bx+self.BLOCK_SIZE] = cv2.idct(dct_block)
        
        if len(image.shape) == 3:
            ycrcb[:,:,0] = y_channel.astype(np.uint8)
            return cv2.cvtColor(ycrcb, cv2.COLOR_YCrCb2BGR)
        else:
            return y_channel.astype(np.uint8)
    
    def _str_to_bits(self, s: str) -> list:
        bits = []
        for ch in s:
            for i in range(8):
                bits.append((ord(ch) >> (7 - i)) & 1)
        return bits
```

```python
"""
图片处理 Worker 消费者
"""
import json
import logging
from kafka import KafkaConsumer

logger = logging.getLogger(__name__)

class ImagePipelineWorker:
    def __init__(self):
        self.consumer = KafkaConsumer(
            'image.process.topic',
            bootstrap_servers=['kafka:9092'],
            group_id='image-pipeline-workers',
            value_deserializer=lambda m: json.loads(m.decode('utf-8')),
            max_poll_records=10,
            session_timeout_ms=120000,    # 2min (大图处理需要时间)
            max_poll_interval_ms=300000,  # 5min
        )
        
        self.analyzer = ContentAnalyzer()
        self.generator = VariantGenerator()
        self.validator = QualityValidator()
        self.cropper = SmartCropper()
        self.watermark = VisibleWatermark("assets/watermark_logo.png")
        self.invisible_wm = InvisibleWatermark()
    
    def run(self):
        for message in self.consumer:
            job = message.value
            
            try:
                self._process_job(job)
            except Exception as e:
                logger.error(f"Job {job['job_id']} failed: {e}", exc_info=True)
                self._handle_failure(job, e)
    
    def _process_job(self, job: dict):
        asset_id = job['asset_id']
        source_path = job['source_path']
        
        # 更新状态
        self._update_job_status(job['job_id'], 'running')
        self._update_asset_status(asset_id, 'processing')
        
        # Stage 1: 内容分析
        profile = self.analyzer.analyze(source_path)
        self._save_stage(job['job_id'], 'content_analysis', profile.__dict__)
        
        # Stage 2: 生成压缩配方
        recipe = COMPRESSION_RECIPES[profile.content_type].copy()
        if profile.is_transparent:
            recipe['force_png'] = True
        self._save_stage(job['job_id'], 'recipe_generation', {'recipe': recipe})
        
        # Stage 3-5: 变体生成 (内部包含缩放、格式转换)
        variants = self.generator.generate_variants(
            source_path, profile, recipe, 
            output_dir=f"/tmp/image_processing/{asset_id}/"
        )
        
        # Stage 4: 质量校验 + 自动降级
        for variant in variants:
            validation = self.validator.validate(
                source_path, variant['filepath'], profile,
                ResolutionTier(variant['resolution_tier'])
            )
            variant['quality_score'] = validation['ssim']
            variant['passed'] = validation['passed']
            
            if not validation['passed'] and 'increase_quality' in (validation.get('suggestion') or ''):
                # 自动提升质量重新生成
                improved = self._regenerate_with_higher_quality(
                    source_path, variant, profile, recipe
                )
                variant.update(improved)
        
        # Stage 6: 智能裁剪
        crops = []
        if job.get('enable_smart_crop', True):
            crops = self.cropper.generate_crops(
                source_path, profile.saliency_focus,
                profile.__dict__.get('source_width', 0),
                profile.__dict__.get('source_height', 0)
            )
        
        # Stage 7: 水印 (对最终变体应用)
        if job.get('enable_watermark', True):
            for variant in variants:
                if variant['resolution_tier'] != 'thumb':
                    variant['is_watermarked'] = True
                    # 对文件应用水印后重新写入
        
        # Stage 8: 上传 CDN + 写数据库
        for variant in variants:
            if variant.get('passed', True):
                cdn_url = self._upload_to_cdn(variant['filepath'], asset_id, variant['variant_key'])
                self._save_variant_record(asset_id, variant, cdn_url)
        
        for crop in crops:
            crop_path = self.cropper.apply_crop(source_path, crop, ...)
            crop_url = self._upload_to_cdn(crop_path, asset_id, f"crop_{crop['aspect_ratio']}")
            self._save_crop_record(asset_id, crop, crop_url)
        
        # 更新状态
        self._update_asset_status(asset_id, 'ready')
        self._update_job_status(job['job_id'], 'success')
        
        logger.info(f"Asset {asset_id} processed: {len(variants)} variants, {len(crops)} crops")
```

```python
class DegradationStrategy:
    
    def handle_request(self, asset_id: str, requested_variant: str) -> str:
        """返回可用的URL"""
        
        # Level 0: 正常 — 请求的变体可用
        variant = self._find_variant(asset_id, requested_variant)
        if variant:
            return variant.url
        
        # Level 1: 格式降级 — 降低格式要求
        tier, _ = requested_variant.split('_')
        for fallback_fmt in ['webp', 'jpeg', 'png']:
            fallback_key = f"{tier}_{fallback_fmt}"
            variant = self._find_variant(asset_id, fallback_key)
            if variant:
                return variant.url
        
        # Level 2: 分辨率降级 — 降低分辨率
        tier_order = ['original', 'hd', 'standard', 'thumb']
        tier_idx = tier_order.index(tier)
        for lower_tier in tier_order[tier_idx + 1:]:
            for fmt in ['webp', 'jpeg', 'png']:
                variant = self._find_variant(asset_id, f"{lower_tier}_{fmt}")
                if variant:
                    return variant.url
        
        # Level 3: 原图 — 最后手段
        variant = self._find_variant(asset_id, 'original_jpeg')
        if variant:
            return variant.url
        
        # Level 4: 占位图
        return self._generate_placeholder(asset_id)
```

```python
"""
任务重试策略 — 指数退避 + 分阶段恢复
"""
RETRY_CONFIG = {
    "max_retries": 3,
    "base_delay_seconds": 5,
    "max_delay_seconds": 300,
    "backoff_multiplier": 2,
    
    # 分阶段恢复: 失败后从上一个成功的 stage 继续
    "stage_checkpoints": [
        "content_analysis",
        "variant_generation", 
        "quality_validation",
        "cdn_upload"
    ],
}

def calculate_retry_delay(retry_count: int) -> float:
    """指数退避 + 抖动"""
    base = RETRY_CONFIG["base_delay_seconds"] * (RETRY_CONFIG["backoff_multiplier"] ** retry_count)
    delay = min(base, RETRY_CONFIG["max_delay_seconds"])
    jitter = np.random.uniform(0, delay * 0.1)
    return delay + jitter
```

```python
MAX_MEMORY_MB = 2048  # 单张图片处理最大内存

def safe_process_image(image_path: str, max_dim: int = 10000):
    """安全处理大图，自动降级"""

    with pyvips.Image.new_from_file(image_path, access="sequential") as img:

            # 分块处理 (tile-based)
```

```
  └──────────────┘          └──────────────┘
```

## 16. 附录

### 16.1 技术选型

| 组件 | 选型 | 理由 |
| --- | --- | --- |
| 图片处理库 | libvips (pyvips) | 流式处理、低内存、高性能、支持 AVIF/WebP |
| CNN 推理 | ONNX Runtime | 跨平台、支持 GPU、模型部署简单 |
| 消息队列 | Apache Kafka | 高吞吐、持久化、分区内有序 |
| 缓存 | Redis | 变体决策缓存、防重复处理 |
| 对象存储 | MinIO / AWS S3 | 标准 S3 API、多供应商兼容 |
| CDN | 多供应商(阿里云CDN + 腾讯云CDN) | 主备容灾、区域优化 |
| 格式编码 | libvips + libheif + libavif | 全面支持 AVIF/WebP/JPEG/PNG |

### 16.2 容量规划参考

| 指标 | 估算 |
| --- | --- |
| 日均上传图片量 | 5,000 张 (运营+教研+教师) |
| 平均源图大小 | 500KB |

| 月均存储增量 | ~225GB |
| 年存储需求 | ~2.7TB (含1年保留) |
| 日均处理 CPU 核时 | ~2 核时 (5000张/50张每秒) |
