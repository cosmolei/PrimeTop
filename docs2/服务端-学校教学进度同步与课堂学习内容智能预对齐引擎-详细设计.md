# 服务端-学校教学进度同步与课堂学习内容智能预对齐引擎 详细设计

## 1. 模块概述

### 1.1 功能定位

本引擎负责将学生在学校课堂的实际教学进度与 App 内的学习内容推荐进行**实时对齐**，实现"课前预习 → 课中同步 → 课后巩固 → 考前冲刺"的全链路课堂协同体验。

核心价值：
- 学生打开 App 看到的推荐内容与"明天要上的课"或"今天刚学的课"高度匹配
- 教师发布作业后，App 自动提供相关知识点的辅助学习资源
- 考试周自动切换到复习模式，对齐考试范围
- 多教师、多班级进度独立管理，支持"走班制"等复杂场景

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 进度精准对齐 | App 推荐内容与实际课堂教学进度误差 ≤ 1 个课时 |
| 自动预判 | 根据教学大纲和实际进度，自动预测下一阶段学习内容 |
| 多源融合 | 支持教师手动录入、教务系统对接、AI 推断三种进度来源 |
| 弹性适应 | 支持临时调课、放假、教学进度超前/滞后等动态变化 |
| 隐私安全 | 严格遵守未成年人数据保护，进度数据仅用于个人推荐 |

### 1.3 用户场景

```
场景1：课前预习
小明明天要学"二次函数的图像与性质"，App 在今日学习任务中自动推荐：
- 预习卡片：二次函数基本概念
- 3分钟导入视频
- 基础概念自测题（3道）

场景2：课后巩固
今天老师讲完了"牛顿第二定律"，App 自动推荐：
- 知识总结卡片
- 课后巩固练习（5道分层题）
- 易错点提醒

场景3：考试对齐
下周期中考试，范围是第1-5章。App 自动生成：
- 考试范围复习计划（7天）
- 高频考点专题
- 模拟试卷推荐

场景4：进度偏差
老师这周讲到了第4章，但原计划应该到第5章。App 自动：
- 调整后续推荐节奏
- 将"第5章预习"延后
- 增加第4章巩固内容
```

### 2.2 核心组件

| 组件 | 职责 | 技术选型 |
|------|------|----------|
| 进度录入服务 | 接收和验证教学进度数据 | Spring Boot + PostgreSQL |
| 教学大纲仓库 | 管理各学校/年级/学科的教学计划 | PostgreSQL + Redis |

| 事件总线 | 广播进度变更事件，驱动下游服务 | RabbitMQ |

## 3. 数据模型设计

### 3.1 数据库表设计

#### 3.1.1 学校信息表 `schools`

```sql
CREATE TABLE schools (
    id              BIGINT PRIMARY KEY,
    school_code     VARCHAR(32) NOT NULL UNIQUE,    -- 学校编码（国标/自定义）
    school_name     VARCHAR(128) NOT NULL,
    region_code     VARCHAR(12) NOT NULL,           -- 行政区划编码
    school_type     VARCHAR(20) NOT NULL,            -- PRIMARY/JUNIOR_HIGH/SENIOR_HIGH/NINE_YEAR
    semester_cal    JSONB,                           -- 学期日历配置
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

COMMENT ON TABLE schools IS '学校信息表';
COMMENT ON COLUMN schools.semester_cal IS '学期日历: {"spring_start":"2026-02-15","spring_end":"2026-07-01","autumn_start":"2026-09-01","autumn_end":"2027-01-20"}';
```

#### 3.1.2 教学大纲表 `teaching_syllabi`

```sql
CREATE TABLE teaching_syllabi (
    id                  BIGINT PRIMARY KEY,
    school_id           BIGINT NOT NULL REFERENCES schools(id),
    grade_id            VARCHAR(20) NOT NULL,         -- G1~G12
    subject_code        VARCHAR(20) NOT NULL,          -- CHINESE/MATH/ENGLISH/PHYSICS/...
    textbook_version_id BIGINT,                       -- 教材版本ID
    semester            VARCHAR(20) NOT NULL,          -- 2026-SPRING / 2026-AUTUMN
    syllabus_name       VARCHAR(200) NOT NULL,
    total_periods       INT NOT NULL DEFAULT 0,       -- 总课时数
    weekly_periods      INT NOT NULL DEFAULT 0,       -- 每周课时数
    start_date          DATE NOT NULL,
    end_date            DATE NOT NULL,
    syllabus_type       VARCHAR(20) NOT NULL DEFAULT 'STANDARD', -- STANDARD/EXAM_REVIEW/MAKEUP
    source              VARCHAR(20) NOT NULL DEFAULT 'MANUAL',  -- MANUAL/IMPORTED/AI_INFERRED
    confidence_score    DECIMAL(3,2),                 -- AI推断时的置信度 0.00~1.00
    status              VARCHAR(16) NOT NULL DEFAULT 'DRAFT',    -- DRAFT/PUBLISHED/ARCHIVED
    published_at        TIMESTAMPTZ,
    created_by          BIGINT,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),

CREATE INDEX idx_syllabi_lookup ON teaching_syllabi(school_id, grade_id, semester, status);
```

#### 3.1.6 学生-进度关联视图（物化视图）

```sql
CREATE MATERIALIZED VIEW student_progress_view AS
SELECT
    s.id AS student_id,
    s.class_id,
    csb.syllabus_id,
    csb.subject_code,
    si.id AS syllabus_item_id,
    si.sequence,
    si.chapter_id,
    si.knowledge_point_ids,
    si.period_type,
    si.planned_date,
    COALESCE(tpl.actual_date, si.actual_date) AS resolved_actual_date,
    COALESCE(tpl.status, si.status) AS resolved_status,
    COALESCE(tpl.completion_pct,
        CASE WHEN si.status = 'TAUGHT' THEN 100.00 ELSE 0.00 END
    ) AS resolved_completion_pct,
    CASE
        WHEN COALESCE(tpl.status, si.status) = 'COMPLETED' THEN 'COMPLETED'
        WHEN COALESCE(tpl.status, si.status) = 'PARTIAL' THEN 'PARTIAL'
        WHEN COALESCE(tpl.status, si.status) = 'SKIPPED' THEN 'SKIPPED'
        WHEN si.planned_date < CURRENT_DATE THEN 'OVERDUE'
        WHEN si.planned_date <= CURRENT_DATE + INTERVAL '3 days' THEN 'UPCOMING'
        ELSE 'FUTURE'
    END AS progress_phase
FROM students s
JOIN class_syllabus_bindings csb ON s.class_id = csb.class_id AND csb.is_active = TRUE
JOIN syllabus_items si ON csb.syllabus_id = si.syllabus_id
LEFT JOIN teaching_progress_logs tpl ON si.id = tpl.syllabus_item_id AND tpl.class_id = s.class_id
WITH DATA;

CREATE UNIQUE INDEX idx_spv ON student_progress_view(student_id, syllabus_item_id);
CREATE INDEX idx_spv_phase ON student_progress_view(student_id, progress_phase);
CREATE INDEX idx_spv_chapter ON student_progress_view(student_id, chapter_id);

-- 每小时刷新
-- SELECT cron.schedule('refresh_progress_view', '0 * * * *', 'REFRESH MATERIALIZED VIEW CONCURRENTLY student_progress_view');
```

### 3.2 Redis 数据结构

```text
# 当前进度快照（高频读，每个学生）
KEY: progress:snapshot:{student_id}:{subject_code}
TYPE: Hash
FIELDS:
    current_sequence    # 当前教学进度序号
    current_chapter_id  # 当前章节ID
    current_phase       # COMPLETED/IN_PROGRESS/UPCOMING
    last_updated        # 最后更新时间
    syllabus_id         # 教学大纲ID
TTL: 1小时

# 今日推荐列表缓存
KEY: recommend:today:{student_id}:{subject_code}
TYPE: List<JSON>
TTL: 到当天 23:59:59

# 教学进度更新锁
KEY: progress:lock:{class_id}:{subject_code}
TYPE: String (lock token)
TTL: 30秒

# 对齐策略缓存
KEY: strategies:active
TYPE: Hash
TTL: 10分钟

# 班级进度汇总（用于教师端看板）
KEY: progress:class:summary:{class_id}
TYPE: Hash
FIELDS: subject_code -> JSON{current_seq, completion_pct, deviation_days}
TTL: 5分钟
```

## 5. 核心算法设计

### 5.1 对齐匹配算法

#### 5.1.1 进度阶段判定

核心思路：根据教学进度记录，为每个学生计算每个知识点的"教学阶段"。

```java
/**
 * 进度阶段枚举
 */
public enum ProgressPhase {
    COMPLETED,      // 已完成教学
    IN_PROGRESS,    // 正在教学（部分完成）
    UPCOMING,       // 即将教学（计划日期 ≤ 3天内）
    FUTURE,         // 未来教学
    OVERDUE         // 逾期未教（计划日期已过但未记录）
}

/**
 * 判定单个 syllabus_item 的教学阶段
 *
 * @param item     大纲条目
 * @param progress 进度记录（可为null）
 * @param today    当前日期
 * @return 教学阶段
 */
public ProgressPhase determinePhase(SyllabusItem item,
                                     TeachingProgressLog progress,
                                     LocalDate today) {
    // 1. 如果有进度记录，以记录为准
    if (progress != null) {
        return switch (progress.getStatus()) {
            case COMPLETED -> ProgressPhase.COMPLETED;
            case PARTIAL   -> ProgressPhase.IN_PROGRESS;
            case SKIPPED   -> ProgressPhase.COMPLETED; // 跳过视为已完成
        };
    }

    // 2. 无进度记录，按计划日期推算
    if (item.getPlannedDate() == null) {
        // 无具体日期，按周计算
        int currentWeek = WeekCalculator.getWeekOf(today, item.getSyllabusStartDate());
        if (item.getPlannedWeek() < currentWeek) {
            return ProgressPhase.OVERDUE;
        } else if (item.getPlannedWeek() == currentWeek) {
            return ProgressPhase.UPCOMING;
        } else {
            return ProgressPhase.FUTURE;
        }
    }

    long daysUntil = ChronoUnit.DAYS.between(today, item.getPlannedDate());

    if (daysUntil < 0) {
        return ProgressPhase.OVERDUE;
    } else if (daysUntil <= 3) {
        return ProgressPhase.UPCOMING;
    } else {
        return ProgressPhase.FUTURE;
    }
}
```

#### 5.1.2 对齐推荐生成

```java
/**
 * 对齐推荐生成器
 * 核心流程：确定阶段 → 匹配策略 → 检索内容 → 排序 → 返回
 */
@Service
public class AlignmentRecommendationService {

    @Autowired private StudentProgressService progressService;
    @Autowired private AlignmentStrategyRepository strategyRepo;
    @Autowired private ContentAlignmentRepository contentRepo;
    @Autowired private StudentProfileService profileService;

    /**
     * 生成对齐推荐
     */
    public AlignmentRecommendationVO generateRecommendations(
            Long studentId,
            String subjectCode,
            Set<ProgressPhase> phaseFilter,
            int limit) {

        // 1. 获取学生在指定学科的所有教学进度
        List<StudentProgressDTO> progressList =
            progressService.getStudentProgress(studentId, subjectCode);

        // 2. 获取学生画像（年级、能力水平、偏好）
        StudentProfile profile = profileService.getProfile(studentId);

        // 3. 按阶段分组
        Map<ProgressPhase, List<StudentProgressDTO>> phaseGroups =
            progressList.stream()
                .collect(Collectors.groupingBy(StudentProgressDTO::getPhase));

        // 4. 获取激活的对齐策略
        List<AlignmentStrategy> strategies = strategyRepo.findActiveStrategies();

        // 5. 为每个阶段生成推荐
        List<RecommendationItem> recommendations = new ArrayList<>();

        for (AlignmentStrategy strategy : strategies) {
            List<StudentProgressDTO> candidates = phaseGroups.getOrDefault(
                strategy.getPhase(), Collections.emptyList());

            if (candidates.isEmpty()) continue;
            if (phaseFilter != null && !phaseFilter.contains(strategy.getPhase())) continue;

            // 按优先级和日期排序，取前N个条目
            List<StudentProgressDTO> selected = candidates.stream()
                .sorted(Comparator
                    .comparing(StudentProgressDTO::getPlannedDate,
                              Comparator.nullsLast(Comparator.naturalOrder()))
                    .thenComparing(StudentProgressDTO::getSequence))
                .limit(strategy.getMaxItems())
                .collect(Collectors.toList());

            for (StudentProgressDTO sp : selected) {
                // 检查时间窗口
                if (!isWithinTimeWindow(strategy, sp, LocalDate.now())) {
                    continue;
                }

                // 检查去重（今天已推荐过的不再推荐）
                if (isAlreadyRecommended(studentId, sp, strategy, LocalDate.now())) {
                    continue;
                }

                // 检索匹配的内容
                List<ContentAlignmentTag> contents = contentRepo.findMatchedContents(
                    sp.getChapterId(),
                    sp.getKnowledgePointIds(),
                    strategy.getPhase(),
                    profile.getGradeId(),
                    strategy.getContentTypes()
                );

                // 难度过滤与梯度排序
                List<ContentAlignmentTag> filtered = filterByDifficulty(
                    contents, profile, strategy.getDifficultyRule());

                // 取最优内容（质量分最高 + 难度匹配度最高）
                if (!filtered.isEmpty()) {
                    ContentAlignmentTag best = filtered.get(0);
                    recommendations.add(buildRecommendation(
                        best, sp, strategy, profile));
                }
            }
        }

        // 6. 全局排序：按优先级 → 时间紧迫度 → 内容质量
        recommendations.sort(Comparator
            .comparing(RecommendationItem::getPriority, Comparator.reverseOrder())
            .thenComparing(RecommendationItem::getUrgencyScore,
                          Comparator.reverseOrder())
            .thenComparing(RecommendationItem::getQualityScore,
                          Comparator.reverseOrder()));

        // 7. 截断
        List<RecommendationItem> result = recommendations.stream()
            .limit(limit)
            .collect(Collectors.toList());

        return AlignmentRecommendationVO.builder()
            .studentId(studentId)
            .generatedAt(Instant.now())
            .recommendations(result)
            .summary(buildSummary(result))
            .build();
    }

    /**
     * 时间窗口检查
     */
    private boolean isWithinTimeWindow(AlignmentStrategy strategy,
                                        StudentProgressDTO progress,
                                        LocalDate today) {
        return switch (strategy.getPhase()) {
            case PRE_CLASS -> {
                // 课前N小时开始推荐
                if (progress.getPlannedDate() == null) yield true;
                long hoursUntil = Duration.between(
                    LocalDateTime.now(),
                    progress.getPlannedDate().atTime(8, 0) // 假设上课时间8:00
                ).toHours();
                yield hoursUntil > 0 && hoursUntil <= strategy.getTimeBeforeHours();
            }
            case POST_CLASS -> {
                // 课后N小时内推荐
                if (progress.getResolvedActualDate() == null) yield false;
                long hoursAfter = Duration.between(
                    progress.getResolvedActualDate().atTime(8, 0),
                    LocalDateTime.now()
                ).toHours();
                yield hoursAfter >= 0 && hoursAfter <= 72; // 3天内有效
            }
            case REVIEW -> {
                // 周末或每周日触发
                yield today.getDayOfWeek() == DayOfWeek.SATURDAY
                    || today.getDayOfWeek() == DayOfWeek.SUNDAY;
            }
            case EXAM -> {
                // 考试模式由外部触发
                yield true;
            }
            default -> true;
        };
    }

    /**
     * 难度梯度过滤
     */
    private List<ContentAlignmentTag> filterByDifficulty(
            List<ContentAlignmentTag> contents,
            StudentProfile profile,
            DifficultyRule rule) {

        // 基础难度过滤：不超纲
        int maxDifficulty = rule.isAdaptive()
            ? Math.min(profile.getAbilityLevel() + 1, 5)
            : 5;

        return contents.stream()
            .filter(c -> c.getDifficultyLevel() != null
                      && c.getDifficultyLevel() <= maxDifficulty)
            .sorted(Comparator
                .comparing(ContentAlignmentTag::getQualityScore,
                          Comparator.reverseOrder())
                .thenComparing(c ->
                    Math.abs(c.getDifficultyLevel() - profile.getAbilityLevel())))
            .collect(Collectors.toList());
    }
}
```

### 5.2 AI 推断教学进度

当教师未手动录入进度时，系统可通过学生的学习行为推断教学进度：

```java
/**
 * AI 教学进度推断器
 * 基于班级学生的集体学习行为推断教师的教学进度
 */
@Service
@Slf4j
public class TeachingProgressInferencer {

    /**
     * 推断班级当前教学进度
     *
     * 推断信号（权重）：
     * 1. 班级中 >60% 学生在同一天集中搜索/拍题同一章节的题目（0.35）
     * 2. 教师近期布置的作业章节（0.30）
     * 3. 班级学生答题正确率骤降的知识点（新学知识点特征）（0.15）
     * 4. 班级学生最近新增的错题集中章节（0.15）
     * 5. 日历信号：当前周次对应大纲的预期进度（0.05）
     *
     * @param classId    班级ID
     * @param subjectCode 学科
     * @return 推断结果
     */
    public InferenceResult inferCurrentProgress(Long classId, String subjectCode) {
        Syllabus syllabus = syllabusService.getActiveSyllabus(classId, subjectCode);
        if (syllabus == null) return InferenceResult.notFound();

        List<Long> studentIds = classService.getStudentIds(classId);
        LocalDate analysisWindow = LocalDate.now().minusDays(7); // 最近7天

        // 信号1：拍题/搜题行为聚类
        Map<Long, Integer> chapterSearchCount = searchService
            .batchCountChapterSearches(studentIds, subjectCode, analysisWindow);

        // 信号2：作业章节
        Map<Long, Integer> chapterHomeworkWeight = homeworkService
            .getRecentHomeworkChapterWeights(classId, subjectCode, analysisWindow);

        // 信号3：正确率骤降检测
        Set<Long> newTopicKps = answerRecordService
            .detectAccuracyDropKnowledgePoints(studentIds, subjectCode, analysisWindow);

        // 信号4：错题集中章节
        Map<Long, Integer> chapterMistakeCount = mistakeService
            .batchCountChapterMistakes(studentIds, subjectCode, analysisWindow);

        // 综合评分
        Map<Long, BigDecimal> chapterScores = new HashMap<>();
        Set<Long> allChapters = new HashSet<>();
        allChapters.addAll(chapterSearchCount.keySet());
        allChapters.addAll(chapterHomeworkWeight.keySet());
        allChapters.addAll(chapterMistakeCount.keySet());

        for (Long chapterId : allChapters) {
            BigDecimal score = BigDecimal.ZERO;

            // 信号1
            int searchCount = chapterSearchCount.getOrDefault(chapterId, 0);
            double searchRatio = (double) searchCount / studentIds.size();
            if (searchRatio > 0.6) {
                score = score.add(new BigDecimal("0.35"));
            } else if (searchRatio > 0.3) {
                score = score.add(new BigDecimal("0.20"));
            }

            // 信号2
            int hwWeight = chapterHomeworkWeight.getOrDefault(chapterId, 0);
            score = score.add(new BigDecimal(hwWeight * 0.30)
                .min(new BigDecimal("0.30")));

            // 信号3
            long newKpsInChapter = knowledgePointService
                .countKnowledgePointsInChapter(chapterId, newTopicKps);
            if (newKpsInChapter > 0) {
                score = score.add(new BigDecimal("0.15"));
            }

            // 信号4
            int mistakeCount = chapterMistakeCount.getOrDefault(chapterId, 0);
            double mistakeRatio = (double) mistakeCount / studentIds.size();
            if (mistakeRatio > 1.0) { // 人均1题以上
                score = score.add(new BigDecimal("0.15"));
            }

            chapterScores.put(chapterId, score);
        }

        // 取分数最高的章节作为"当前正在教学的章节"
        Map.Entry<Long, BigDecimal> top = chapterScores.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .orElse(null);

        if (top == null || top.getValue().compareTo(new BigDecimal("0.20")) < 0) {
            // 无足够信号，使用日历预期
            SyllabusItem expected = syllabusService.getExpectedItem(syllabus);
            return InferenceResult.builder()
                .inferred(false)
                .reason("insufficient_signals")
                .calendarExpected(expected)
                .confidenceScore(BigDecimal.ZERO)
                .build();
        }

        // 找到对应的 syllabus_item
        SyllabusItem inferredItem = syllabusService
            .findItemByChapter(syllabus.getId(), top.getKey());

        return InferenceResult.builder()
            .inferred(true)
            .inferredItem(inferredItem)
            .confidenceScore(top.getValue())
            .signalBreakdown(Map.of(
                "search_ratio", chapterSearchCount.getOrDefault(top.getKey(), 0),
                "homework_weight", chapterHomeworkWeight.getOrDefault(top.getKey(), 0),
                "accuracy_drop_kps", newTopicKps.size(),
                "mistake_ratio", chapterMistakeCount.getOrDefault(top.getKey(), 0)
            ))
            .build();
    }
}
```

### 5.3 进度偏差分析与纠偏

```java
/**
 * 进度偏差分析器
 */
@Service
public class ProgressDeviationAnalyzer {

    /**
     * 分析班级教学进度偏差
     */
    public DeviationAnalysis analyze(Long classId, String subjectCode) {
        Syllabus syllabus = syllabusService.getActiveSyllabus(classId, subjectCode);
        List<SyllabusItem> items = syllabusService.getItems(syllabus.getId());
        List<TeachingProgressLog> logs = progressService.getClassLogs(classId);

        // 计算已完成进度
        Set<Long> completedItemIds = logs.stream()
            .filter(l -> l.getStatus() == Status.COMPLETED
                      || l.getStatus() == Status.SKIPPED)
            .map(TeachingProgressLog::getSyllabusItemId)
            .collect(Collectors.toSet());

        // 计算预期完成进度（按日期推算）
        LocalDate today = LocalDate.now();
        long expectedCompleted = items.stream()
            .filter(i -> i.getPlannedDate() != null
                      && !i.getPlannedDate().isAfter(today))
            .count();

        long actualCompleted = completedItemIds.size();
        long deviation = expectedCompleted - actualCompleted;

        // 计算天数偏差
        double weeklyPace = syllabus.getWeeklyPeriods();
        double daysBehind = deviation / weeklyPace * 7.0;

        // 判定严重程度
        SeverityLevel severity;
        if (daysBehind <= 1) severity = SeverityLevel.NONE;
        else if (daysBehind <= 3) severity = SeverityLevel.MINOR;
        else if (daysBehind <= 7) severity = SeverityLevel.MODERATE;
        else severity = SeverityLevel.SEVERE;

        // 趋势分析（对比上周偏差）
        DeviationTrend trend = calculateTrend(classId, syllabus, daysBehind);

        // 生成建议
        List<String> suggestions = generateSuggestions(
            severity, trend, deviation, items, completedItemIds, today);

        return DeviationAnalysis.builder()
            .classId(classId)
            .subjectCode(subjectCode)
            .analysisDate(today)
            .expectedCompleted(expectedCompleted)
            .actualCompleted(actualCompleted)
            .itemsBehind(deviation)
            .daysBehind(daysBehind)
            .severity(severity)
            .trend(trend)
            .suggestions(suggestions)
            .build();
    }

    private List<String> generateSuggestions(
            SeverityLevel severity, DeviationTrend trend,
            long deviation, List<SyllabusItem> items,
            Set<Long> completedIds, LocalDate today) {

        List<String> suggestions = new ArrayList<>();

        if (severity == SeverityLevel.NONE) {
            suggestions.add("教学进度正常，按计划推进即可");
            return suggestions;
        }

        // 找到滞后的具体内容
        List<SyllabusItem> overdueItems = items.stream()
            .filter(i -> i.getPlannedDate() != null
                      && i.getPlannedDate().isBefore(today)
                      && !completedIds.contains(i.getId()))
            .sorted(Comparator.comparing(SyllabusItem::getPlannedDate))
            .collect(Collectors.toList());

        if (!overdueItems.isEmpty()) {
            suggestions.add(String.format("尚有%d个课时的内容未完成教学，最近逾期：「%s」",
                overdueItems.size(),
                overdueItems.get(0).getChapterName()));
        }

        // 根据严重程度给出不同建议
        switch (severity) {
            case MINOR:
                suggestions.add("偏差较小，建议利用1-2次课前10分钟快速补齐");
                break;
            case MODERATE:
                suggestions.add("建议将接下来的复习课改为新授课，或合并相邻章节的练习课");
                // 检查是否有可合并的课
                List<SyllabusItem> upcomingReview = items.stream()
                    .filter(i -> i.getPeriodType() == PeriodType.REVIEW
                              && i.getPlannedDate() != null
                              && i.getPlannedDate().isAfter(today))
                    .limit(3)
                    .collect(Collectors.toList());
                if (!upcomingReview.isEmpty()) {
                    suggestions.add(String.format(
                        "建议将「%s」复习课调整为内容课以追回进度",
                        upcomingReview.get(0).getChapterName()));
                }
                break;
            case SEVERE:
                suggestions.add("严重滞后，建议重新评估教学计划，必要时调整学期目标");
                suggestions.add("考虑与教务沟通调整后续教学安排");
                break;
        }

        if (trend == DeviationTrend.WORSENING) {
            suggestions.add("注意：偏差在扩大，建议及时干预");
        } else if (trend == DeviationTrend.IMPROVING) {
            suggestions.add("偏差在缩小，保持当前节奏即可追回");
        }

        return suggestions;
    }
}
```

```java
                ProgressPhase.COMPLETED, event.getChapterId(), kpIds);

        notificationService.sendClassNotification(
            event.getClassId(),
            NotificationType.POST_CLASS_CONTENT_READY,
            Map.of("subjectCode", event.getSubjectCode(),
                   "chapterId", event.getChapterId()));

        // 5. 更新进度偏差分析
        deviationAnalyzer.scheduleAnalysis(event.getClassId(),
            event.getSubjectCode());
```

## 8. 对齐模式详细设计

### 8.1 课前预习模式（PRE_CLASS）

**触发条件：** 大纲中某个 item 的 `planned_date` 在未来 12~48 小时内。

**推荐内容类型：**

| 内容类型 | 说明 | 难度 | 时长 | 数量 |
|----------|------|------|------|------|
| KNOWLEDGE_CARD | 核心概念卡片（图文） | 1 | 3min | 1 |
| VIDEO | 导入视频/动画讲解 | 1-2 | 3-5min | 1 |
| PRACTICE_BASIC | 基础概念检测题 | 2 | 5min | 2-3题 |

**生成逻辑：**

```java
public List<RecommendationItem> generatePreClassRecommendations(
        StudentProfile profile, SyllabusItem upcomingItem) {

    List<RecommendationItem> items = new ArrayList<>();

    // 1. 预习卡片（必推）
    ContentAlignmentTag card = contentRepo.findBest(
        upcomingItem.getChapterId(),
        upcomingItem.getKnowledgePointIds(),
        "KNOWLEDGE_CARD",
        profile.getGradeId(),
        1  // 最简难度
    );
    if (card != null) {
        items.add(RecommendationItem.builder()
            .phase(ProgressPhase.UPCOMING)
            .strategy("PRE_CLASS_PREVIEW")
            .priority(85)
            .reason("明天将学习「" + upcomingItem.getChapterName() + "」，提前预习")
            .content(buildContentVO(card))
            .build());
    }

    // 2. 导入视频（按学生偏好决定是否推送）
    if (profile.prefersVideoContent()) {
        ContentAlignmentTag video = contentRepo.findBest(
            upcomingItem.getChapterId(),
            upcomingItem.getKnowledgePointIds(),
            "VIDEO",
            profile.getGradeId(),
            2
        );
        if (video != null) {
            items.add(RecommendationItem.builder()
                .phase(ProgressPhase.UPCOMING)
                .strategy("PRE_CLASS_PREVIEW")
                .priority(75)
                .reason("观看导入视频，提前了解核心概念")
                .content(buildContentVO(video))
                .build());
        }
    }

    // 3. 基础自测（可选，低优先级）
    ContentAlignmentTag preQuiz = contentRepo.findBest(
        upcomingItem.getChapterId(),
        null,
        "PRACTICE_BASIC",
        profile.getGradeId(),
        2
    );
    if (preQuiz != null && items.size() < 4) {
        items.add(RecommendationItem.builder()
            .phase(ProgressPhase.UPCOMING)
            .strategy("PRE_CLASS_PREVIEW")
            .priority(60)
            .reason("预习自测：检测预习效果")
            .content(buildContentVO(preQuiz))
            .build());
    }

    return items;
}
```

### 8.3 考试备考模式（EXAM）

**触发条件：** 教师发布考试通知，或系统检测到考试周（学期日历标记）。

**特殊逻辑：**

1. **范围锁定：** 仅推荐考试范围内的内容
2. **优先级覆盖：** EXAM 策略优先级 100，覆盖其他所有策略
3. **模式切换：** 全局推荐进入"备考模式"，首页布局调整
4. **自动生成复习计划：** 根据考试日期、范围、学生掌握度生成倒计时计划

```java
/**
 * 考试模式触发与推荐编排
 */
public ExamModeResult activateExamMode(Long classId, ExamNotification exam) {
    // 1. 确定考试范围
    List<SyllabusItem> scopeItems = syllabusService
        .getItemsByRange(exam.getSyllabusId(),
                         exam.getFromSequence(),
                         exam.getToSequence());

    // 2. 对班级每个学生生成个性化备考推荐
    List<Long> studentIds = classService.getStudentIds(classId);

    for (Long studentId : studentIds) {
        // 获取学生在考试范围内的掌握情况
        Map<Long, MasteryLevel> chapterMastery = masteryService
            .batchGetChapterMastery(studentId,
                scopeItems.stream().map(SyllabusItem::getChapterId).collect(Collectors.toSet()));

        // 按掌握度排序：薄弱章节优先
        List<Long> weakChapters = chapterMastery.entrySet().stream()
            .filter(e -> e.getValue().getLevel() <= MasteryLevel.BASIC.ordinal())
            .sorted(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());

        // 生成备考任务清单
        ExamPrepPlan plan = ExamPrepPlan.builder()
            .studentId(studentId)
            .examId(exam.getId())
            .examDate(exam.getExamDate())
            .daysRemaining(ChronoUnit.DAYS.between(LocalDate.now(), exam.getExamDate()))
            .scopeChapters(scopeItems.stream()
                .map(SyllabusItem::getChapterId).distinct().collect(Collectors.toList()))
            .weakChapters(weakChapters)
            .dailyTasks(generateDailyTasks(
                weakChapters, exam.getExamDate(), studentId))
            .build();

        planService.saveExamPrepPlan(plan);
    }

    return ExamModeResult.builder()
        .classId(classId)
        .studentCount(studentIds.size())
        .scopeChapters(scopeItems.size())
        .build();
}
```

```java
public class AlignmentFallbackHandler {

    /**
     * 推荐生成失败时的降级处理
     */
    public AlignmentRecommendationVO fallback(Long studentId, String subjectCode) {
        // Level 1: 尝试返回缓存
        AlignmentRecommendationVO cached =
            cacheService.getCachedRecommendation(studentId, subjectCode);

                .isAfter(Instant.now().minus(Duration.ofHours(6)))) {
```

```java
@Service
public class ProgressReportService {

    private static final String IDEMPOTENCY_PREFIX = "progress:report:";

    @Transactional
    public ReportResult report(ProgressReportRequest request) {
        // 幂等Key = classId + subjectCode + reportDate + syllabusItemId
        String idempotencyKey = IDEMPOTENCY_PREFIX
            + request.getClassId() + ":"
            + request.getSubjectCode() + ":"
            + request.getReportDate() + ":"
            + request.getReports().stream()
                .map(r -> r.getSyllabusItemId().toString())
                .collect(Collectors.joining(","));

        // Redis SETNX 防重
        Boolean isNew = redisTemplate.opsForValue()
            .setIfAbsent(idempotencyKey, "1", Duration.ofMinutes(10));

        if (Boolean.FALSE.equals(isNew)) {
            return ReportResult.duplicate();
        }

        try {
            // 执行上报逻辑...
            return doReport(request);
        } catch (Exception e) {
            // 失败时清除幂等标记以允许重试
            redisTemplate.delete(idempotencyKey);
            throw e;
        }
    }
}
```

```java
/**
 * 每日凌晨预计算今日推荐
 * Cron: 0 0 6 * * ?
 */
@Scheduled(cron = "0 0 6 * * ?")
public void precomputeDailyRecommendations() {
    // 1. 获取所有激活的大纲
    List<TeachingSyllabus> activeSyllabi = syllabusRepo.findAllActive();

    // 2. 对每个大纲关联的班级
    for (TeachingSyllabus syllabus : activeSyllabi) {
        List<ClassSyllabusBinding> bindings =
            bindingRepo.findBySyllabusId(syllabus.getId());

        for (ClassSyllabusBinding binding : bindings) {
            List<Long> studentIds = classService.getStudentIds(binding.getClassId());

            // 3. 并行计算每个学生的今日推荐
            studentIds.parallelStream().forEach(studentId -> {
                try {
                    AlignmentRecommendationVO rec =
                        recommendationService.generateRecommendations(
                            studentId, syllabus.getSubjectCode(), null, 10);
                    cacheService.cacheDailyRecommendation(studentId,
                        syllabus.getSubjectCode(), rec);
                } catch (Exception e) {
                    log.warn("Failed to precompute for student={}", studentId, e);
                }
            });
        }
    }

    log.info("Daily recommendation precompute completed");
}
```

### 12.2 数据隔离

```java
/**
 * 数据权限拦截器
 */
@Component
public class ProgressDataInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request,
                              HttpServletResponse response,
                              Object handler) {
        Long currentUserId = SecurityContext.getCurrentUserId();
        String role = SecurityContext.getRole();
        String studentIdParam = request.getParameter("studentId");
        String classIdParam = request.getParameter("classId");

        if ("STUDENT".equals(role) && studentIdParam != null) {
            // 学生只能查看自己的进度
            if (!currentUserId.equals(Long.valueOf(studentIdParam))) {
                response.setStatus(403);
                return false;
            }
        }

        if ("PARENT".equals(role) && studentIdParam != null) {
            // 家长只能查看绑定孩子的进度
            if (!bindingService.isBound(currentUserId, Long.valueOf(studentIdParam))) {
                response.setStatus(403);
                return false;
            }
        }

        if ("TEACHER".equals(role) && classIdParam != null) {
            // 教师只能查看自己班级的进度
            if (!classService.isClassTeacher(currentUserId, Long.valueOf(classIdParam))) {
                response.setStatus(403);
                return false;
            }
        }

        return true;
    }
}
```
