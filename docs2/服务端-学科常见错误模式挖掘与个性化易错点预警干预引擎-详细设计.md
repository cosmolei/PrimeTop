# 学科常见错误模式挖掘与个性化易错点预警干预引擎 — 详细设计

> **文档版本**：v1.0  
> **创建日期**：2026-06-22  
> **所属模块**：题目服务 / 学情分析 / AI辅导  
> **关联设计**：原始设计文档 §6.3.2 拍题答疑「易错点提醒」、§6.11.2 理科解题「易错点提示」、§6.12 文科背诵「知识问答检测」

---

## 1. 模块概述

### 1.1 功能目标

从海量学生答题行为数据中挖掘**学科常见错误模式（Common Error Patterns, CEP）**，构建结构化错误模式知识库，并在学生答题、AI辅导、错题复习等场景中提供**个性化易错点预警与干预**，帮助学生主动避开高频陷阱、减少重复犯错。

### 1.2 设计动机

原始设计文档在多处提到「易错点提醒」功能，但该能力横跨拍题答疑、理科解题、文科背诵、错题整理、AI辅导等多个模块，需要一个**统一的错误模式管理引擎**来支撑：

| 原始需求来源 | 具体描述 |
| --- | --- |
| §6.3.2 拍题答疑 | 解题步骤中输出「易错点提醒」 |
| §6.11.2 理科解题 | 提示单位、符号、条件遗漏、计算步骤等问题 |
| §6.6.2 错题整理 | 支持「概念不清、审题错误、计算失误、方法错误」等错因标签 |
| §6.7.2 学情分析 | 识别长期低正确率、高错题率知识点 |
| §6.9.2 考点梳理 | 总结典型误区和命题陷阱 |

### 1.3 核心价值

1. **从被动纠错到主动预防**：在学生犯错前预警，而非犯错后补救。
2. **数据驱动的错误知识库**：基于真实答题大数据挖掘，而非教研人员主观判断。
3. **个性化干预**：根据学生个人错误历史精准推送，避免信息过载。
4. **跨模块协同**：统一服务于 AI 对话、拍题、练习、错题、学情报告等多场景。

### 3.2 错误类别枚举（ErrorCategory）

```typescript
enum ErrorCategory {
  CONCEPT_ERROR = 'CONCEPT_ERROR',        // 概念理解错误
  CALCULATION_ERROR = 'CALCULATION_ERROR', // 计算运算错误
  AUDIT_ERROR = 'AUDIT_ERROR',            // 审题理解错误
  METHOD_ERROR = 'METHOD_ERROR',          // 解题方法错误
  KNOWLEDGE_GAP = 'KNOWLEDGE_GAP',        // 知识盲区/遗漏
  HABITUAL_ERROR = 'HABITUAL_ERROR',      // 习惯性失误
  FORMULA_ERROR = 'FORMULA_ERROR',        // 公式记忆错误
  LOGIC_ERROR = 'LOGIC_ERROR',            // 逻辑推理错误
  EXPRESSION_ERROR = 'EXPRESSION_ERROR',  // 表达书写错误
  CARELESS_ERROR = 'CARELESS_ERROR'       // 粗心大意错误
}

enum ErrorSubCategory {
  // 概念理解类
  CONCEPT_CONFUSION = '概念混淆',
  CONCEPT_INCOMPLETE = '概念不完整',
  CONCEPT_MISAPPLICATION = '概念误用',
  
  // 计算运算类
  SIGN_ERROR = '符号错误',
  UNIT_ERROR = '单位错误',
  ARITHMETIC_ERROR = '四则运算错误',
  PRECISION_ERROR = '精度/有效数字错误',
  
  // 审题理解类
  CONDITION_MISSING = '条件遗漏',
  CONDITION_MISREAD = '条件误读',
  QUESTION_INTENT_MISUNDERSTOOD = '题意理解偏差',
  
  // 解题方法类
  METHOD_MISMATCH = '方法选择不当',
  METHOD_INCOMPLETE = '方法步骤不完整',
  OVER_COMPLICATION = '过度复杂化',
  
  // 公式记忆类
  FORMULA_INCORRECT = '公式记错',
  FORMULA_INCOMPLETE = '公式不全',
  THEOREM_MISAPPLICATION = '定理误用'
}
```

### 3.6 数据库表设计

#### 3.6.1 错误模式表 `t_error_pattern`

```sql
CREATE TABLE t_error_pattern (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    pattern_code        VARCHAR(128) NOT NULL UNIQUE COMMENT '错误模式唯一编码',
    pattern_id          VARCHAR(64) NOT NULL UNIQUE COMMENT '业务ID EP-{SUBJECT}-{YEAR}-{SEQ}',
    title               VARCHAR(256) NOT NULL COMMENT '错误模式标题',
    description         TEXT COMMENT '详细描述',
    subject             VARCHAR(32) NOT NULL COMMENT '学科',
    stage               VARCHAR(32) NOT NULL COMMENT '学段',
    grade_range         JSON COMMENT '适用年级范围',
    knowledge_point_ids JSON COMMENT '关联知识点ID列表',
    question_type_codes JSON COMMENT '关联题型编码列表',
    error_category      VARCHAR(64) NOT NULL COMMENT '错误大类',
    error_sub_category  VARCHAR(64) COMMENT '错误子类',
    trigger_conditions  JSON COMMENT '触发条件配置',
    manifestation_examples JSON COMMENT '典型表现示例',
    root_cause_analysis TEXT COMMENT '根因分析',
    intervention_strategies JSON COMMENT '推荐干预策略ID列表',
    frequency_stats     JSON COMMENT '频率统计信息',
    quality_metrics     JSON COMMENT '质量指标',
    metadata            JSON COMMENT '元数据',
    status              TINYINT DEFAULT 1 COMMENT '1=启用 0=禁用 2=待审核',
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_subject_stage (subject, stage),
    INDEX idx_category (error_category),
    INDEX idx_knowledge_points ((CAST(knowledge_point_ids AS CHAR(512)))),
    INDEX idx_status (status),
    INDEX idx_confidence ((CAST(quality_metrics->>'$.confidenceScore' AS DECIMAL(4,2))))
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='错误模式知识库';
```

## 5. 核心算法设计

### 5.1 错误模式挖掘算法

#### 5.1.1 基于答题日志的频繁错误模式挖掘

采用 **FP-Growth + 语义聚类** 的两阶段挖掘方案：

```
阶段一：频繁项集挖掘（FP-Growth）
─────────────────────────────────
输入：答题日志 <question_id, student_answer, correct_answer, knowledge_points, question_type>
输出：频繁错误项集

1. 从答题日志中筛选 error_records（answer != correct）
2. 按 knowledge_points + question_type 分组
3. 对每组提取错误特征向量：
   - answer_diff_type（答案差异类型：数值/符号/表达式/选项）
   - error_signature（错误签名：如"符号取反"）
4. 使用 FP-Growth 挖掘最小支持度 ≥ min_sup（默认0.02）的频繁项集
5. 输出候选频繁错误模式集

阶段二：语义聚类与命名
─────────────────────────────────
输入：候选频繁错误模式集
输出：结构化错误模式

1. 对候选模式使用 Embedding（text-embedding-3-small）向量化
2. 使用 HDBSCAN 聚类（min_cluster_size=50）
3. 对每个聚类：
   a. 提取聚类中心描述
   b. 使用 LLM 生成人类可读的标题和描述
   c. 分析根因（root_cause_analysis）
   d. 匹配预设错误类别（ErrorCategory 枚举）
4. 质量评估：
   a. 聚类内紧密度（silhouette_score > 0.4）
   b. 错误率显著性检验（chi-square, p < 0.01）
   c. 跨学段/年级的分布合理性
5. 人工审核后入库
```

**Python 参考实现：**

```python
from collections import defaultdict
from typing import List, Dict, Tuple
import numpy as np
from sklearn.cluster import HDBSCAN
from scipy.stats import chi2_contingency

class ErrorPatternMiner:
    """错误模式挖掘引擎"""
    
    def __init__(self, min_support: float = 0.02, 
                 min_cluster_size: int = 50,
                 min_silhouette: float = 0.4):
        self.min_support = min_support
        self.min_cluster_size = min_cluster_size
        self.min_silhouette = min_silhouette
    
    def mine_patterns(self, answer_logs: List[dict]) -> List[dict]:
        """从答题日志中挖掘错误模式"""
        # Step 1: 筛选错误记录
        error_records = [log for log in answer_logs if not log['is_correct']]
        
        # Step 2: 按知识点+题型分组
        grouped = self._group_by_knowledge(error_records)
        
        # Step 3: 提取错误签名
        candidates = []
        for group_key, records in grouped.items():
            if len(records) < self.min_cluster_size:
                continue
            signatures = [self._extract_signature(r) for r in records]
            candidates.extend(signatures)
        
        if len(candidates) < self.min_cluster_size:
            return []
        
        # Step 4: 向量化与聚类
        embeddings = self._compute_embeddings(candidates)
        cluster_labels = self._cluster(embeddings)
        
        # Step 5: 构建错误模式
        patterns = []
        for label in set(cluster_labels):
            if label == -1:  # HDBSCAN 噪声点
                continue
            
            members = [i for i, l in enumerate(cluster_labels) if l == label]
            if len(members) < self.min_cluster_size:
                continue
            
            pattern = self._build_pattern(candidates, members, label)
            if self._validate_pattern(pattern, error_records):
                patterns.append(pattern)
        
        return patterns
    
    def _extract_signature(self, record: dict) -> dict:
        """提取错误签名"""
        diff = self._compute_answer_diff(
            record['student_answer'], 
            record['correct_answer'],
            record.get('question_type', 'UNKNOWN')
        )
        return {
            'question_id': record['question_id'],
            'knowledge_point_ids': record['knowledge_point_ids'],
            'question_type': record['question_type'],
            'subject': record['subject'],
            'stage': record['stage'],
            'diff_type': diff['type'],
            'diff_detail': diff['detail'],
            'error_text': f"{record['subject']}/{record['stage']}/{'/'.join(record['knowledge_point_ids'])}/{diff['type']}/{diff['detail']}"
        }
    
    def _compute_answer_diff(self, student_ans: str, correct_ans: str, 
                              q_type: str) -> dict:
        """计算答案差异类型"""
        # 数值型答案比较
        try:
            s_val = float(student_ans)
            c_val = float(correct_ans)
            if abs(abs(s_val) - abs(c_val)) < 1e-6 and s_val * c_val < 0:
                return {'type': 'SIGN_ERROR', 'detail': f'符号取反: {s_val} vs {c_val}'}
            if abs(s_val - c_val) > 0 and abs(s_val * c_val - c_val * c_val) / max(abs(c_val), 1) < 0.1:
                return {'type': 'CALCULATION_ERROR', 'detail': f'计算偏差: {s_val} vs {c_val}'}
        except ValueError:
            pass
        
        # 表达式/选项型比较
        if q_type == 'SINGLE_CHOICE':
            return {'type': 'CHOICE_MISMATCH', 'detail': f'选项: {student_ans} vs {correct_ans}'}
        
        return {'type': 'EXPRESSION_DIFF', 'detail': f'{student_ans} vs {correct_ans}'}
    
    def _compute_embeddings(self, candidates: List[dict]) -> np.ndarray:
        """计算文本嵌入向量"""
        texts = [c['error_text'] for c in candidates]
        # 调用嵌入模型API（如 OpenAI text-embedding-3-small）
        embeddings = self._call_embedding_api(texts)
        return np.array(embeddings)
    
    def _cluster(self, embeddings: np.ndarray) -> np.ndarray:
        """HDBSCAN 聚类"""
        clusterer = HDBSCAN(
            min_cluster_size=self.min_cluster_size,
            min_samples=max(5, self.min_cluster_size // 10),
            metric='cosine',
            cluster_selection_method='eom'
        )
        return clusterer.fit_predict(embeddings)
    
    def _build_pattern(self, candidates: List[dict], members: List[int], 
                       label: int) -> dict:
        """从聚类结果构建错误模式"""
        member_items = [candidates[i] for i in members]
        
        # 统计分布
        subjects = [m['subject'] for m in member_items]
        stages = [m['stage'] for m in member_items]
        diff_types = [m['diff_type'] for m in member_items]
        
        from collections import Counter
        dominant_subject = Counter(subjects).most_common(1)[0][0]
        dominant_stage = Counter(stages).most_common(1)[0][0]
        dominant_diff = Counter(diff_types).most_common(1)[0][0]
        
        return {
            'subject': dominant_subject,
            'stage': dominant_stage,
            'diff_type': dominant_diff,
            'frequency': len(members),
            'sample_question_ids': list(set(m['question_id'] for m in member_items))[:10],
            'knowledge_point_ids': list(set(
                kp for m in member_items 
                for kp in m['knowledge_point_ids']
            )),
            'cluster_label': int(label),
            'representative_errors': [m['diff_detail'] for m in member_items[:5]]
        }
    
    def _validate_pattern(self, pattern: dict, all_records: List[dict]) -> bool:
        """验证错误模式是否显著"""
        # 卡方检验：该错误模式是否在不同学生中显著非随机出现
        pattern_students = set(r.get('student_id') for r in all_records 
                              if self._matches_pattern(r, pattern))
        total_students = set(r.get('student_id') for r in all_records)
        
        if len(pattern_students) < self.min_cluster_size:
            return False
        
        # 错误率显著性检验
        contingency = [
            [len(pattern_students), len(total_students) - len(pattern_students)],
            [0, 0]  # 期望分布
        ]
        try:
            chi2, p_value, _, _ = chi2_contingency(contingency)
            return p_value < 0.01
        except ValueError:
            return True  # 数据量足够时默认通过
    
    def _matches_pattern(self, record: dict, pattern: dict) -> bool:
        """判断记录是否匹配错误模式"""
        return (record.get('subject') == pattern['subject'] and
                record.get('stage') == pattern['stage'] and
                set(record.get('knowledge_point_ids', [])).issuperset(
                    set(pattern['knowledge_point_ids'][:1])))
    
    def _call_embedding_api(self, texts: List[str]) -> List[List[float]]:
```

### 5.2 实时预警匹配算法

#### 5.2.1 多级匹配策略

```
实时预警匹配流程：
─────────────────────────────────

输入：student_id, question_id, context

Level 1: 直接关联匹配（O(1) 查表）
  → 查询 t_error_pattern_question 中 question_id 关联的错误模式
  → 若命中，直接返回（置信度 0.9-1.0）

Level 2: 知识点+题型匹配（O(K) 查表）
  → 获取题目的知识点集合和题型
  → 在错误模式库中匹配相同知识点+题型的模式
  → 若命中，返回（置信度 0.7-0.9）

Level 3: 语义相似匹配（向量检索）
  → 将题目描述转为向量
  → 在错误模式向量索引中检索 Top-K
  → 若相似度 > 阈值，返回（置信度 0.5-0.7）

Level 4: 学生画像过滤
  → 对匹配到的模式，检查学生错误画像
  → 若学生已标记为「已克服」该模式 → 降权或过滤
  → 若学生匹配度高 → 提升优先级
  → 若学生已频繁收到预警 → 疲劳度控制过滤
```

#### 5.2.2 匹配引擎参考实现

```java
@Service
public class ErrorWarningMatchEngine {
    
    @Autowired
    private ErrorPatternCacheService patternCache;
    
    @Autowired
    private StudentErrorProfileService profileService;
    
    @Autowired
    private InterventionFatigueService fatigueService;
    
    /**
     * 实时预警匹配
     */
    public WarningMatchResult matchWarning(WarningMatchRequest request) {
        String studentId = request.getStudentId();
        String questionId = request.getQuestionId();
        
        // 获取学生画像
        StudentErrorProfile profile = profileService.getProfile(studentId);
        
        // 获取题目元数据
        QuestionMeta questionMeta = patternCache.getQuestionMeta(questionId);
        if (questionMeta == null) {
            return WarningMatchResult.empty();
        }
        
        // 多级匹配
        List<PatternMatch> matches = new ArrayList<>();
        
        // Level 1: 直接关联
        matches.addAll(matchByDirectAssociation(questionId));
        
        // Level 2: 知识点+题型
        if (matches.size() < request.getMaxWarnings()) {
            matches.addAll(matchByKnowledgeAndType(
                questionMeta.getKnowledgePointIds(),
                questionMeta.getQuestionType(),
                questionMeta.getSubject()
            ));
        }
        
        // Level 3: 语义相似（异步预计算，此处读缓存）
        if (matches.size() < request.getMaxWarnings()) {
            matches.addAll(matchBySemanticSimilarity(questionId));
        }
        
        // 去重 + 排序
        List<PatternMatch> dedupedMatches = dedupAndRank(matches);
        
        // 学生画像过滤
        List<PatternMatch> personalized = applyPersonalization(dedupedMatches, profile);
        
        // 疲劳度控制
        List<PatternMatch> filtered = fatigueService.filter(studentId, personalized);
        
        // 选择干预策略
        List<WarningItem> warnings = filtered.stream()
            .limit(request.getMaxWarnings())
            .map(m -> buildWarningItem(m, profile))
            .collect(Collectors.toList());
        
        return new WarningMatchResult(warnings);
    }
    
    /**
     * Level 1: 直接关联匹配
     */
    private List<PatternMatch> matchByDirectAssociation(String questionId) {
        List<ErrorPatternQuestion> associations = 
            patternCache.getPatternsByQuestion(questionId);
        return associations.stream()
            .filter(a -> "TRIGGER".equals(a.getAssociationType()))
            .filter(a -> a.getMatchConfidence() != null)
            .map(a -> PatternMatch.builder()
                .pattern(patternCache.getPattern(a.getErrorPatternId()))
                .confidence(a.getMatchConfidence())
                .matchLevel(1)
                .source("DIRECT_ASSOCIATION")
                .build())
            .collect(Collectors.toList());
    }
    
    /**
     * Level 2: 知识点 + 题型匹配
     */
    private List<PatternMatch> matchByKnowledgeAndType(
            Set<String> knowledgePointIds, String questionType, String subject) {
        List<ErrorPattern> patterns = patternCache
            .getPatternsByKnowledgePoints(knowledgePointIds, subject);
        
        return patterns.stream()
            .filter(p -> p.getQuestionTypeCodes() == null || 
                        p.getQuestionTypeCodes().contains(questionType))
            .map(p -> PatternMatch.builder()
                .pattern(p)
                .confidence(computeKnowledgeMatchScore(p, knowledgePointIds))
                .matchLevel(2)
                .source("KNOWLEDGE_TYPE_MATCH")
                .build())
            .sorted(Comparator.comparingDouble(PatternMatch::getConfidence).reversed())
            .collect(Collectors.toList());
    }
    
    /**
     * 学生画像个性化过滤
     */
    private List<PatternMatch> applyPersonalization(
            List<PatternMatch> matches, StudentErrorProfile profile) {
        if (profile == null) {
            return matches;
        }
        
        return matches.stream()
            .map(m -> {
                // 检查学生是否已克服该错误模式
                PatternProgress progress = profile.getPatternProgress(
                    m.getPattern().getErrorPatternId());
                
                if (progress != null) {
                    if ("RESOLVED".equals(progress.getStatus())) {
                        // 已克服，大幅降权
                        m.setConfidence(m.getConfidence() * 0.1);
                        m.setPersonalizedReason("已克服该错误模式");
                    } else if ("IMPROVING".equals(progress.getTrend())) {
                        // 正在改善，适度降权
                        m.setConfidence(m.getConfidence() * 0.5);
                        m.setPersonalizedReason(
                            String.format("该错误模式正在改善，近%d次中出错%d次",
                                progress.getRecentAttempts(),
                                progress.getRecentErrors()));
                    } else if ("WORSENING".equals(progress.getTrend())) {
                        // 正在恶化，提升权重
                        m.setConfidence(Math.min(1.0, m.getConfidence() * 1.3));
                        m.setPersonalizedReason(
                            String.format("该错误模式近期加剧，最近%d次出错%d次",
                                progress.getRecentAttempts(),
                                progress.getRecentErrors()));
                    }
                }
                return m;
            })
            .filter(m -> m.getConfidence() >= 0.3) // 过滤掉低置信度
            .sorted(Comparator.comparingDouble(PatternMatch::getConfidence).reversed())
            .collect(Collectors.toList());
    }
    
    /**
     * 构建预警项
     */
    private WarningItem buildWarningItem(PatternMatch match, 
                                          StudentErrorProfile profile) {
        ErrorPattern pattern = match.getPattern();
        InterventionStrategy strategy = selectStrategy(pattern, profile);
        
        return WarningItem.builder()
            .warningId(generateWarningId())
            .errorPatternId(pattern.getErrorPatternId())
            .title(pattern.getTitle())
            .level(determineWarningLevel(match, profile))
            .content(renderWarningContent(pattern, strategy))
            .strategyId(strategy.getStrategyId())
            .deliveryPosition(strategy.getStrategyType())
            .matchConfidence(match.getConfidence())
            .personalizedReason(match.getPersonalizedReason())
            .build();
    }
    
    /**
     * 干预策略选择
     */
    private InterventionStrategy selectStrategy(ErrorPattern pattern, 
                                                  StudentErrorProfile profile) {
        List<String> strategyIds = pattern.getInterventionStrategies();
        if (strategyIds == null || strategyIds.isEmpty()) {
            return getDefaultStrategy(pattern);
        }
        
        // 根据学生画像选择最优策略
        InterventionStrategy best = null;
        double bestScore = Double.MIN_VALUE;
        
        for (String strategyId : strategyIds) {
            InterventionStrategy strategy = patternCache.getStrategy(strategyId);
            if (strategy == null) continue;
            
            double score = computeStrategyScore(strategy, pattern, profile);
            if (score > bestScore) {
                bestScore = score;
                best = strategy;
            }
        }
        
        return best != null ? best : getDefaultStrategy(pattern);
    }
    
    private double computeStrategyScore(InterventionStrategy strategy,
                                          ErrorPattern pattern,
                                          StudentErrorProfile profile) {
        double score = strategy.getEffectivenessScore(); // 基础效果分
        
        // 学生偏好加权
        if (profile != null && profile.prefersStrategy(strategy.getStrategyId())) {
            score *= 1.2;
        }
        
        // 优先级加权
        score -= strategy.getPriority() * 0.01;
        
        return score;
    }
}
```

### 5.3 答题后错误分析算法

```python
class PostAnswerErrorAnalyzer:
    """答题后错误模式分析"""
    
    def analyze(self, student_id: str, question_id: str, 
                student_answer: str, correct_answer: str,
                question_meta: dict, answer_behavior: dict) -> dict:
        """分析答错记录属于哪种错误模式"""
        
        # Step 1: 计算答案差异特征
        diff_features = self._extract_diff_features(
            student_answer, correct_answer, question_meta
        )
        
        # Step 2: 获取该题目关联的错误模式
        candidate_patterns = self._get_candidate_patterns(question_id, question_meta)
        
        # Step 3: 逐一匹配
        matches = []
        for pattern in candidate_patterns:
            confidence = self._compute_match_confidence(
                diff_features, pattern, answer_behavior
            )
            if confidence >= 0.5:
                matches.append({
                    'errorPatternId': pattern['errorPatternId'],
                    'title': pattern['title'],
                    'matchConfidence': confidence,
                    'errorCategory': pattern['errorCategory'],
                    'rootCause': pattern.get('rootCauseAnalysis', ''),
                    'suggestedLabel': self._map_to_mistake_label(pattern['errorCategory'])
                })
        
        # Step 4: 排序 + 取 Top-3
        matches.sort(key=lambda x: x['matchConfidence'], reverse=True)
        top_matches = matches[:3]
        
        # Step 5: 如果无匹配，标记为"待人工分析"
        if not top_matches:
            return {
                'matchedPatterns': [],
                'unmatched': True,
                'needsManualReview': True,
                'diffFeatures': diff_features
            }
        
        return {
            'matchedPatterns': top_matches,
            'unmatched': False,
            'needsManualReview': top_matches[0]['matchConfidence'] < 0.7
        }
    
    def _extract_diff_features(self, student_ans: str, correct_ans: str,
                                question_meta: dict) -> dict:
        """提取答案差异特征"""
        features = {
            'question_type': question_meta.get('questionType', 'UNKNOWN'),
            'subject': question_meta.get('subject', ''),
        }
        
        q_type = features['question_type']
        
        if q_type in ('SINGLE_CHOICE', 'MULTI_CHOICE'):
            features['wrong_options'] = list(set(student_ans) - set(correct_ans))
            features['missing_options'] = list(set(correct_ans) - set(student_ans))
            features['diff_type'] = 'OPTION_MISMATCH'
            
        elif q_type == 'FILL_BLANK':
            features['student_tokens'] = self._tokenize(student_ans)
            features['correct_tokens'] = self._tokenize(correct_ans)
            features['edit_distance'] = self._levenshtein(student_ans, correct_ans)
            features['diff_type'] = self._classify_fill_blank_diff(
                student_ans, correct_ans)
            
        elif q_type == 'SOLVE':
            features['student_steps'] = self._parse_solution_steps(student_ans)
            features['correct_steps'] = self._parse_solution_steps(correct_ans)
            features['first_divergence_step'] = self._find_first_divergence(
                features['student_steps'], features['correct_steps'])
            features['diff_type'] = self._classify_solve_diff(
                features['student_steps'], features['correct_steps'],
                features['first_divergence_step'])
        
        return features
    
    def _compute_match_confidence(self, diff_features: dict, pattern: dict,
                                   answer_behavior: dict) -> float:
        """计算错误模式匹配置信度"""
        confidence = 0.0
        
        # 触发条件匹配
        trigger = pattern.get('triggerConditions', {})
        if trigger:
            # 关键词匹配
            if 'requiredKeywords' in trigger:
                keyword_match = sum(1 for kw in trigger['requiredKeywords']
                                   if kw in diff_features.get('subject', ''))
                confidence += keyword_match * 0.15
            
            # 题型匹配
            if 'questionPattern' in trigger:
                if trigger['questionPattern'] == diff_features.get('diff_type'):
                    confidence += 0.3
        
        # 错误类别匹配
        if pattern.get('errorCategory'):
            category_map = {
                'SIGN_ERROR': 'CALCULATION_ERROR',
                'CALCULATION_ERROR': 'CALCULATION_ERROR',
                'CONDITION_MISSING': 'AUDIT_ERROR',
                'CHOICE_MISMATCH': 'CONCEPT_ERROR',
                'EXPRESSION_DIFF': 'METHOD_ERROR'
            }
            mapped = category_map.get(diff_features.get('diff_type'), '')
            if mapped == pattern['errorCategory']:
                confidence += 0.25
        
        # 答题行为特征加权
        if answer_behavior:
            # 快速答题且答错 → 可能是粗心
            if answer_behavior.get('timeSpent', 0) < 15:
                if pattern['errorCategory'] == 'CARELESS_ERROR':
                    confidence += 0.15
            # 多次修改 → 可能是概念模糊
            if answer_behavior.get('revisionCount', 0) >= 2:
                if pattern['errorCategory'] == 'CONCEPT_ERROR':
                    confidence += 0.1
        
        return min(1.0, confidence)
```

### 7.2 疲劳度控制策略

```python
class InterventionFatigueController:
    """干预疲劳度控制器"""
    
    # 每日预警上限
    DAILY_WARNING_LIMIT = {
        'BEFORE_ANSWER': 8,   # 答题前预警：每日最多8次
        'AFTER_WRONG': 12,     # 答错后分析：每日最多12次
        'REVIEW': 5,           # 复习预警：每日最多5次
    }
    
    # 冷却时间（分钟）
    COOLDOWN_SAME_PATTERN = 30  # 同一错误模式30分钟内不重复提醒
    COOLDOWN_SAME_QUESTION = 60 # 同一题目60分钟内不重复提醒
    
    # 最小间隔
    MIN_INTERVAL_BETWEEN_WARNINGS = 3  # 两次预警至少间隔3道题
    
    def should_show_warning(self, student_id: str, 
                            pattern_id: str,
                            question_id: str,
                            delivery_position: str) -> bool:
        """判断是否应该展示预警"""
        
        # 1. 检查每日上限
        daily_count = self._get_daily_count(student_id, delivery_position)
        if daily_count >= self.DAILY_WARNING_LIMIT.get(delivery_position, 10):
            return False
        
        # 2. 检查同模式冷却
        if self._in_cooldown(student_id, pattern_id, self.COOLDOWN_SAME_PATTERN):
            return False
        
        # 3. 检查同题目冷却
        if self._in_cooldown(student_id, question_id, self.COOLDOWN_SAME_QUESTION):
            return False
        
        # 4. 检查最小间隔
        recent_warning_count = self._get_recent_warning_count(student_id, minutes=10)
        last_warning_position = self._get_last_warning_question_index(student_id)
        current_position = self._get_current_question_index(student_id)
        if current_position - last_warning_position < self.MIN_INTERVAL_BETWEEN_WARNINGS:
            return False
        
        # 5. 学生主动关闭检查
        if self._student_disabled_warning(student_id, pattern_id):
            return False
        
        # 6. 优先级过滤：只展示 Top-N 高优先级
        return True
    
    def get_warning_priority_score(self, match: dict, profile: dict) -> float:
        """计算预警优先级分数"""
        score = match.get('confidence', 0) * 100
        
        # 高风险模式加权
        if profile and match['pattern_id'] in profile.get('highRiskPatterns', []):
            score *= 1.5
        
        # 恶化趋势加权
        if profile:
            pattern_progress = profile.get('matchedPatterns', {}).get(
                match['pattern_id'], {})
            if pattern_progress.get('improvementTrend', 0) < 0:
                score *= 1.3  # 正在恶化，提升优先级
        
        # 新出现的错误模式加权
        if profile and match['pattern_id'] in profile.get('newEmergingPatterns', []):
            score *= 1.2
        
        return score
```

```python
class AIConversationOrchestrator:
    
    def build_prompt_context(self, student_id: str, question: str, 
                              knowledge_points: list) -> dict:
        context = {}
        
        # 查询该知识点相关的易错模式
        error_patterns = self.error_warning_client.batch_query(
            knowledge_point_ids=knowledge_points,
            student_id=student_id,
            limit=3,
            filter={'onlyPersonalized': True, 'minConfidence': 0.7}
        )
        
        if error_patterns:
            # 注入到 system prompt 中
            context['common_mistakes'] = [
                {
                    'title': p['title'],
                    'reminder': p.get('manifestationExamples', [''])[0],
                    'root_cause': p.get('rootCauseAnalysis', '')
                }
                for p in error_patterns
            ]
        
        return context
```
