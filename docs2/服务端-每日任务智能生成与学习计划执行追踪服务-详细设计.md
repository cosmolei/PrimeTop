# 服务端-每日任务智能生成与学习计划执行追踪服务-详细设计

## 1. 文档概述

### 1.1 文档目的

本文档详细定义「每日任务智能生成与学习计划执行追踪服务」的服务端设计方案，为开发人员提供可直接编码落地的技术规范。涵盖数据模型、API 接口、核心算法、状态流转、异常处理及与上下游服务的交互协议。

### 1.2 模块定位

本服务是「学习规划」模块的核心执行引擎，承上启下：

- **上游**：学习目标分解服务（产出里程碑与阶段目标）、用户学习画像（能力维度与薄弱点）
- **下游**：题目服务（生成练习题）、错题服务（复习任务）、同步课堂服务（章节学习任务）、AI 服务（讲解任务）
- **横向**：通知服务（任务提醒）、积分服务（完成奖励）、学情分析（行为数据上报）

### 1.3 核心能力

| 能力 | 说明 |
| --- | --- |
| 每日任务生成 | 基于学习计划、薄弱点、遗忘曲线等维度，每日凌晨自动生成个性化任务清单 |
| 任务状态追踪 | 实时追踪任务执行进度，支持开始/暂停/完成/跳过等状态转换 |
| 动态调整 | 根据完成情况实时调整剩余任务难度和数量 |
| 任务模板管理 | 按学段/学科维护可配置的任务模板库 |
| 完成度统计 | 按日/周/月聚合任务完成率，输出给学情分析模块 |

## 2. 数据模型

### 2.1 ER 关系概览

```
StudyPlan (1) ──── (N) DailyTaskBatch
DailyTaskBatch (1) ──── (N) DailyTaskItem
DailyTaskItem (1) ──── (0..1) TaskExecutionRecord
DailyTaskItem (N) ──── (1) TaskTemplate
DailyTaskBatch (1) ──── (0..1) DailyTaskAdjustLog
```

### 2.2 核心表结构

#### 2.2.1 study_plan（学习计划主表）

> 由「学习目标分解服务」创建，本服务只读引用。

```sql
CREATE TABLE study_plan (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    plan_type       TINYINT NOT NULL COMMENT '计划类型: 1=学期计划 2=考试冲刺 3=假期计划 4=自定义',
    title           VARCHAR(128) NOT NULL COMMENT '计划标题',
    target_exam     VARCHAR(64) COMMENT '目标考试(如: 期中考试/中考)',
    target_date     DATE COMMENT '目标日期',
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '1=进行中 2=已完成 3=已放弃 4=已过期',
    total_milestones INT NOT NULL DEFAULT 0 COMMENT '里程碑总数',
    completed_milestones INT NOT NULL DEFAULT 0 COMMENT '已完成里程碑数',
    daily_task_time_min INT NOT NULL DEFAULT 30 COMMENT '每日计划学习时长(分钟)',
    daily_task_count INT NOT NULL DEFAULT 5 COMMENT '每日计划任务数',
    prefer_subjects JSON COMMENT '偏重学科 [{"subject_id":1,"weight":1.2}]',
    enabled         TINYINT NOT NULL DEFAULT 1 COMMENT '是否启用每日任务生成',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_status (user_id, status, enabled)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习计划主表';
```

#### 2.2.2 daily_task_batch（每日任务批次）

```sql
CREATE TABLE daily_task_batch (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL,
    plan_id         BIGINT NOT NULL COMMENT '关联学习计划ID',
    batch_date      DATE NOT NULL COMMENT '任务日期',
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '0=待执行 1=执行中 2=已完成 3=部分完成 4=已跳过',
    total_count     INT NOT NULL DEFAULT 0 COMMENT '总任务数',
    completed_count INT NOT NULL DEFAULT 0 COMMENT '已完成数',
    skipped_count   INT NOT NULL DEFAULT 0 COMMENT '跳过数',
    estimated_min   INT NOT NULL DEFAULT 0 COMMENT '预估总时长(分钟)',
    actual_min      INT NOT NULL DEFAULT 0 COMMENT '实际总时长(分钟)',
    completion_score DECIMAL(5,2) DEFAULT 0 COMMENT '完成质量分 0-100',
    generation_source TINYINT NOT NULL DEFAULT 1 COMMENT '1=自动生成 2=手动触发 3=动态补充',
    generated_at    DATETIME NOT NULL COMMENT '生成时间',
    completed_at    DATETIME COMMENT '批次完成时间',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_date (user_id, batch_date),
    INDEX idx_user_date (user_id, batch_date),
    INDEX idx_status (status, batch_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='每日任务批次';
```

#### 2.2.3 daily_task_item（每日任务项）

```sql
CREATE TABLE daily_task_item (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    batch_id        BIGINT NOT NULL COMMENT '批次ID',
    user_id         BIGINT NOT NULL,
    template_id     BIGINT COMMENT '任务模板ID',
    task_type       TINYINT NOT NULL COMMENT '任务类型(见枚举)',
    task_category   TINYINT NOT NULL COMMENT '1=必做 2=推荐 3=可选',
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '0=待开始 1=进行中 2=已完成 3=已跳过 4=已过期 5=已替换',
    priority        INT NOT NULL DEFAULT 50 COMMENT '优先级 1-100, 越大越优先',
    title           VARCHAR(128) NOT NULL COMMENT '任务标题',
    description     VARCHAR(512) COMMENT '任务描述',
    subject_id      INT COMMENT '学科ID',
    knowledge_ids   JSON COMMENT '关联知识点ID列表',
    estimated_min   INT NOT NULL DEFAULT 10 COMMENT '预估时长(分钟)',
    actual_min      INT NOT NULL DEFAULT 0 COMMENT '实际时长(分钟)',
    difficulty      TINYINT COMMENT '难度等级 1-5',
    
    -- 任务上下文参数(JSON, 不同 task_type 结构不同)
    task_context    JSON NOT NULL COMMENT '任务上下文参数',
    /* 
    示例:
    - 错题复习: {"review_ids":[101,102],"review_source":"mistake","min_correct_rate":0.8}
    - 章节学习: {"chapter_id":201,"textbook_id":1,"learning_mode":"review"}
    - 练习答题: {"question_count":5,"knowledge_ids":[301],"difficulty_range":[2,3]}
    - AI讲解:   {"knowledge_id":401,"subject":"math","prompt_type":"concept_explain"}
    - 背诵检测: {"material_id":501,"check_method":"voice"}
    */
    
    -- 执行结果
    result_data     JSON COMMENT '执行结果({"score":80,"correct_rate":0.8,"detail":...})',
    started_at      DATETIME COMMENT '开始时间',
    completed_at    DATETIME COMMENT '完成时间',
    skipped_reason  VARCHAR(64) COMMENT '跳过原因: too_hard/no_time/not_interested/other',
    
    -- 排序与展示
    sort_order      INT NOT NULL DEFAULT 0 COMMENT '展示排序',
    group_tag       VARCHAR(32) COMMENT '分组标签(如: 晨读/午练/晚复)',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_batch (batch_id, sort_order),
    INDEX idx_user_status (user_id, status, batch_id),
    INDEX idx_type_status (task_type, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='每日任务项';
```

#### 2.2.4 task_template（任务模板库）

```sql
CREATE TABLE task_template (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_code   VARCHAR(64) NOT NULL COMMENT '模板编码(如: mistake_review_daily)',
    task_type       TINYINT NOT NULL COMMENT '对应 task_type',
    name            VARCHAR(64) NOT NULL COMMENT '模板名称',
    description     VARCHAR(256) COMMENT '模板描述',
    
    -- 适用条件
    min_grade       INT COMMENT '最低年级(1=一年级 13=高三)',
    max_grade       INT COMMENT '最高年级',
    subject_ids     JSON COMMENT '适用学科ID列表(null=全部)',
    plan_types      JSON COMMENT '适用计划类型',
    
    -- 生成规则
    gen_rule        JSON NOT NULL COMMENT '生成规则配置',
    /*
    示例 - 错题复习:
    {
      "source": "mistake_service",
      "query": {
        "status": "pending_review",
        "order_by": "due_date ASC",
        "min_count": 3,
        "max_count": 8
      },
      "time_per_item_min": 3,
      "difficulty_match": "adaptive"
    }
    */
    
    -- 展示配置
    default_priority INT NOT NULL DEFAULT 50,
    default_category TINYINT NOT NULL DEFAULT 2 COMMENT '1=必做 2=推荐 3=可选',
    default_estimated_min INT NOT NULL DEFAULT 10,
    icon             VARCHAR(64) COMMENT '展示图标标识',
    color            VARCHAR(16) COMMENT '展示主色',
    
    status           TINYINT NOT NULL DEFAULT 1 COMMENT '1=启用 0=禁用',
    sort_order       INT NOT NULL DEFAULT 0,
    created_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_code (template_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='任务模板库';
```

## 3. API 接口设计

### 3.1 接口总览

| 方法 | 路径 | 说明 | 权限 |
| --- | --- | --- | --- |
| GET | /api/v1/daily-task/today | 获取今日任务清单 | 用户 |
| POST | /api/v1/daily-task/generate | 手动触发生成(缺省时补生成) | 用户 |

| PUT | /api/v1/daily-task/items/{itemId}/skip | 跳过任务 | 用户 |

| GET | /api/v1/daily-task/history | 查询历史任务批次 | 用户 |
| GET | /api/v1/daily-task/statistics | 任务完成度统计 | 用户 |
| GET | /api/v1/daily-task/statistics/weekly | 周报统计 | 用户 |
| GET | /api/v1/daily-task/plan/{planId}/progress | 学习计划执行进度 | 用户 |
| POST | /api/v1/daily-task/feedback | 任务反馈(太难/太简单) | 用户 |

### 4.1 每日任务生成流程

每日凌晨（建议 04:00）由定时任务触发，或用户首次打开 APP 时按需补生成。

### 4.2 任务生成算法伪代码

```java
@Service
public class DailyTaskGenerator {

    /**
     * 为用户生成今日任务
     */
    @Transactional
    public DailyTaskBatchDTO generateTodayTasks(Long userId, boolean forceRefresh) {
        LocalDate today = LocalDate.now();
        
        // 1. 检查是否已存在
        DailyTaskBatch existing = batchMapper.selectByUserAndDate(userId, today);
        if (existing != null && !forceRefresh) {
            return assembleBatchDTO(existing);
        }
        if (existing != null && forceRefresh) {
            invalidatePendingItems(existing.getId());
        }
        
        // 2. 获取活跃学习计划
        StudyPlan plan = planService.getActivePlan(userId);
        if (plan == null) {
            return generateDefaultTasks(userId, today);
        }
        
        // 3. 并行收集上下文
        TaskGenContext ctx = buildContext(userId, plan, today);
        
        // 4. 计算配额
        TaskQuota quota = quotaCalculator.calculate(plan, ctx);
        
        // 5. 生成各类型任务
        List<DailyTaskItem> tasks = new ArrayList<>();
        tasks.addAll(generateMistakeReviewTasks(ctx, quota));
        tasks.addAll(generateChapterLearnTasks(ctx, quota));
        tasks.addAll(generateWeakPointDrillTasks(ctx, quota));
        tasks.addAll(generatePracticeQuizTasks(ctx, quota));
        tasks.addAll(generateReciteEssayTasks(ctx, quota));
        tasks.addAll(generateOptionalTasks(ctx, quota));
        
        // 6. 排序、去重、分组
        tasks = orderOptimizer.optimizeOrder(tasks, ctx);
        tasks = deduplicator.deduplicateByKnowledge(tasks, ctx.getRecentKnowledgeIds());
        
        // 7. 截断到配额上限
        if (tasks.size() > quota.getMaxTotal()) {
            tasks = tasks.subList(0, quota.getMaxTotal());
        }
        
        // 8. 落库
        return assembleBatchDTO(saveBatch(userId, plan.getId(), today, tasks));
    }
    
    /**
     * 并行收集任务生成上下文
     */
    private TaskGenContext buildContext(Long userId, StudyPlan plan, LocalDate today) {
        TaskGenContext ctx = new TaskGenContext();
        ctx.setUserId(userId);
        ctx.setToday(today);
        ctx.setPlan(plan);
        
        CompletableFuture<UserLearningProfile> profileFuture = 
            CompletableFuture.supplyAsync(() -> profileService.getProfile(userId));
        CompletableFuture<List<MistakeReviewItem>> mistakeFuture = 
            CompletableFuture.supplyAsync(() -> mistakeService.getDueReviews(userId, today, 20));
        CompletableFuture<ChapterProgress> chapterFuture = 
            CompletableFuture.supplyAsync(() -> chapterService.getCurrentProgress(userId));
        CompletableFuture<WeeklyCompletionStats> weekStatsFuture = 
            CompletableFuture.supplyAsync(() -> statsService.getWeeklyStats(userId, today));
        CompletableFuture<List<Long>> recentKpFuture = 
            CompletableFuture.supplyAsync(() -> taskItemMapper.selectRecentKnowledgeIds(userId, 2));
        CompletableFuture<List<KnowledgeWeakness>> weakPointsFuture = 
            CompletableFuture.supplyAsync(() -> weaknessService.getTopWeakPoints(userId, 5));
        
        CompletableFuture.allOf(profileFuture, mistakeFuture, chapterFuture,
                                weekStatsFuture, recentKpFuture, weakPointsFuture).join();
        
        ctx.setProfile(profileFuture.join());
        ctx.setDueMistakes(mistakeFuture.join());
        ctx.setChapterProgress(chapterFuture.join());
        ctx.setWeekStats(weekStatsFuture.join());
        ctx.setRecentKnowledgeIds(recentKpFuture.join());
        ctx.setWeakPoints(weakPointsFuture.join());
        
        return ctx;
    }
    
    /**
     * 错题复习任务生成——按学科轮询合并
     */
    private List<DailyTaskItem> generateMistakeReviewTasks(TaskGenContext ctx, TaskQuota quota) {
        List<MistakeReviewItem> dueItems = ctx.getDueMistakes();
        if (CollectionUtils.isEmpty(dueItems)) return Collections.emptyList();
        
        Map<Integer, List<MistakeReviewItem>> bySubject = dueItems.stream()
            .collect(Collectors.groupingBy(MistakeReviewItem::getSubjectId));
        
        List<DailyTaskItem> tasks = new ArrayList<>();
        int remaining = quota.getMistakeReviewSlots();
        
        Iterator<Map.Entry<Integer, List<MistakeReviewItem>>> it = bySubject.entrySet().iterator();
        while (it.hasNext() && remaining > 0) {
            List<MistakeReviewItem> subjectItems = it.next().getValue();
            int take = Math.min(subjectItems.size(), Math.max(3, remaining / bySubject.size()));
            
            DailyTaskItem task = buildMistakeReviewTask(ctx, subjectItems.subList(0, take));
            tasks.add(task);
            remaining -= take;
        }
        return tasks;
    }
}
```

### 4.3 任务状态机

```
                    ┌──────────┐
                    │  PENDING │
                    │ (待开始)  │
                    └────┬─────┘
                         │
              ┌──────────┼──────────┐
              │ start()  │ skip()   │ replace()
              ▼          ▼          ▼
        ┌──────────┐ ┌────────┐ ┌──────────┐
        │IN_PROGRESS│ │SKIPPED │ │ REPLACED │
        │ (进行中)  │ │(已跳过) │ │ (已替换) │
        └────┬─────┘ └────────┘ └──────────┘
             │
     ┌───────┼───────┐
     │complete│pause()│
     ▼        ▼       
  ┌──────────┐ ┌────────┐
  │COMPLETED │ │ PENDING│
  │ (已完成)  │ │(回到待) │
  └──────────┘ └────────┘

过期处理：
  PENDING / IN_PROGRESS ──(T+1 00:00)──→ EXPIRED
```

**状态转换规则：**

| 当前状态 | 动作 | 目标状态 | 前置条件 |
| --- | --- | --- | --- |
| PENDING | start | IN_PROGRESS | 批次未过期 |
| PENDING | skip | SKIPPED | — |
| PENDING | replace | REPLACED | 替换次数 < 3 |
| IN_PROGRESS | complete | COMPLETED | resultData 非空 |
| IN_PROGRESS | pause | PENDING | 暂停次数 < 5 |
| COMPLETED | — | COMPLETED | 终态 |
| SKIPPED | — | SKIPPED | 终态 |
| REPLACED | — | REPLACED | 终态（已有新任务替代） |
| PENDING | expire | EXPIRED | T+1 凌晨定时 |
| IN_PROGRESS | expire | EXPIRED | T+1 凌晨定时 |

```java
@Component
public class TaskStateMachine {
    
    private static final Map<TaskStatus, Set<Action>> ALLOWED_ACTIONS = Map.of(
        TaskStatus.PENDING,      EnumSet.of(Action.START, Action.SKIP, Action.REPLACE),
        TaskStatus.IN_PROGRESS,  EnumSet.of(Action.COMPLETE, Action.PAUSE),
        TaskStatus.COMPLETED,    EnumSet.noneOf(Action.class),
        TaskStatus.SKIPPED,      EnumSet.noneOf(Action.class),
        TaskStatus.REPLACED,     EnumSet.noneOf(Action.class),
        TaskStatus.EXPIRED,      EnumSet.noneOf(Action.class)
    );
    
    public void validateTransition(TaskStatus current, Action action) {
        Set<Action> allowed = ALLOWED_ACTIONS.getOrDefault(current, EnumSet.noneOf(Action.class));
        if (!allowed.contains(action)) {
            throw new BizException(ErrorCode.TASK_STATE_INVALID,
                "任务状态[%s]不允许执行[%s]", current, action);
        }
    }
}
```

### 4.4 动态调整策略

系统根据用户完成表现，在以下场景触发动态调整：

| 触发场景 | 检测条件 | 调整动作 |
| --- | --- | --- |
| 连续跳过同类任务 | 同 task_type 连续跳过 ≥ 2 次 | 降级难度或替换类型 |
| 完成速度过快 | actual_min < estimated_min × 0.3 | 升级剩余任务难度 |
| 完成质量过低 | correctRate < 0.4 | 降级后续同知识点任务难度 |
| 连续完成优秀 | 近 3 次 correctRate > 0.9 | 升级难度或增加挑战任务 |
| 整体完成率低 | 近 3 日完成率 < 0.5 | 减少任务数量 + 增加趣味任务 |
| 单科偏废 | 某学科连续跳过 ≥ 3 次 | 降低该学科占比 + 混入关联学科 |

```java
@Service
public class DynamicAdjustmentEngine {
    
    public void onTaskCompleted(DailyTaskItem completedItem, DailyTaskBatch batch) {
        Long userId = completedItem.getUserId();
        RecentPerformance perf = getRecentPerformance(userId, 3);
        
        // 连续高质量 → 升级
        if (perf.getAvgCorrectRate() > 0.9) {
            upgradeDifficultyForPending(batch, completedItem.getSubjectId());
            logAdjustment(batch.getId(), "difficulty_upgrade",
                "近3次正确率>90%，升级同科目待办任务难度");
        }
        
        // 完成质量低 → 降级
        if (perf.getAvgCorrectRate() < 0.4) {
            downgradeDifficultyForPending(batch, completedItem.getSubjectId());
            logAdjustment(batch.getId(), "difficulty_downgrade",
                "近3次正确率<40%，降低同科目待办任务难度");
        }
        
        // 速度极快 → 追加
        double speedRatio = (double) completedItem.getActualMin() / completedItem.getEstimatedMin();
        if (speedRatio < 0.3 && batch.getCompletedCount() + 2 < batch.getTotalCount()) {
            appendBonusTask(batch, completedItem.getSubjectId());
            logAdjustment(batch.getId(), "task_append",
                "完成速度极快，追加1道拓展任务");
        }
    }
}
```

```java
@Scheduled(cron = "0 10 0 * * *")
public void expireAndSettlePreviousDay() {
    LocalDate yesterday = LocalDate.now().minusDays(1);
    
    List<DailyTaskBatch> batches = batchMapper
        .selectByDateAndStatus(yesterday, BatchStatus.PENDING, BatchStatus.IN_PROGRESS);

            batch.setStatus(BatchStatus.COMPLETED);
        } else if (settlement.getCompletedCount() > 0) {
            batch.setStatus(BatchStatus.PARTIAL_COMPLETED);

            batch.setStatus(BatchStatus.SKIPPED);

        batch.setActualMin(settlement.getTotalActualMin());
        batch.setCompletedAt(LocalDateTime.now());
        batchMapper.updateById(batch);
        
        // 4. 上报事件
        eventPublisher.publishEvent(new BatchSettledEvent(batch, settlement));
        
        // 5. 更新学习计划进度
        planService.updatePlanProgress(batch.getPlanId(), settlement);
        
        // 6. 触发积分/勋章奖励
        rewardService.onDailyBatchSettled(batch.getUserId(), settlement);
    }
```

### 6.1 配额计算

```java
@Service
public class TaskQuotaCalculator {
    
    public TaskQuota calculate(StudyPlan plan, TaskGenContext ctx) {
        TaskQuota quota = new TaskQuota();
        int baseCount = plan.getDailyTaskCount();
        int baseTime = plan.getDailyTaskTimeMin();
        
        // 学段调整
        GradeSegment segment = GradeSegment.fromGrade(ctx.getUserGrade());
        switch (segment) {
            case PRIMARY_LOW:   // 小学低年级
                quota.setRequiredRatio(0.3);
                baseTime = Math.min(baseTime, 30);
                break;
            case PRIMARY_HIGH:  // 小学高年级
                quota.setRequiredRatio(0.4);
                baseTime = Math.min(baseTime, 45);
                break;
            case JUNIOR:        // 初中
                quota.setRequiredRatio(0.45);
                baseTime = Math.min(baseTime, 60);
                break;
            case SENIOR:        // 高中
                quota.setRequiredRatio(0.5);
                baseTime = Math.min(baseTime, 90);
                break;
        }
        
        // 近期完成率调整
        if (ctx.getWeekStats() != null) {
            double rate = ctx.getWeekStats().getCompletionRate();
            if (rate < 0.5) baseCount = Math.max(3, (int)(baseCount * 0.7));
            else if (rate > 0.9) baseCount = Math.min(10, (int)(baseCount * 1.1));
        }
        
        quota.setMaxTotal(baseCount);
        quota.setMaxTotalTimeMin(baseTime);
        // 各类型槽位按比例分配...
        return quota;
    }
}
```

```java
@Service
public class TaskOrderOptimizer {
    
    /**
     * 按学科轮换排列，避免连续相同学科
     */
    private List<DailyTaskItem> interleaveBySubject(List<DailyTaskItem> items) {
        if (items.size() <= 1) return new ArrayList<>(items);
        
        Map<Integer, LinkedList<DailyTaskItem>> bySubject = items.stream()
            .sorted(Comparator.comparingInt(DailyTaskItem::getPriority).reversed())
            .collect(Collectors.groupingBy(
                i -> Optional.ofNullable(i.getSubjectId()).orElse(0),
                Collectors.toCollection(LinkedList::new)));
        
        List<DailyTaskItem> result = new ArrayList<>(items.size());
        while (!bySubject.isEmpty()) {
            Iterator<Map.Entry<Integer, LinkedList<DailyTaskItem>>> it = 
                bySubject.entrySet().iterator();
            while (it.hasNext()) {
                LinkedList<DailyTaskItem> queue = it.next().getValue();
                if (queue.isEmpty()) { it.remove(); }
                else { result.add(queue.pollFirst()); }
            }
        }
        return result;
    }
}
```

| `TASK_008` | 生成服务暂不可用 | 503 | 稍后重试 |
| `TASK_009` | 参数校验失败 | 400 | 修正参数 |

### 9.2 全局异常处理

```java
@RestControllerAdvice
public class DailyTaskExceptionHandler {
    
    @ExceptionHandler(TaskStateException.class)
    public ResponseEntity<ApiResponse<Void>> handleTaskState(TaskStateException e) {
        return ResponseEntity.status(HttpStatus.CONFLICT)
            .body(ApiResponse.error("TASK_002", e.getMessage()));
    }
    
    @ExceptionHandler(TaskGenerationException.class)
    public ResponseEntity<ApiResponse<Void>> handleGeneration(TaskGenerationException e) {
        log.error("任务生成失败: userId={}", e.getUserId(), e);
        return ResponseEntity.status(HttpStatus.SERVICE_UNAVAILABLE)
            .body(ApiResponse.error("TASK_008", "任务生成服务暂不可用，请稍后重试"));
    }
}
```
