# 服务端 - 教育内容个性化难度感知建模与主观难度反馈校准引擎

## 1. 概述

### 1.1 功能定位

本引擎负责采集学生对学习内容的**主观难度反馈**（"觉得太难""刚刚好""太简单"），构建每个学生的**个性化难度感知模型**，并将主观感知与内容客观难度进行**交叉校准**，最终为推荐引擎、自适应学习路径规划等上游模块提供"该学生在当前能力阶段对何种真实难度范围的内容感到舒适"的精确信号。

与现有难度相关系统的关系：

| 现有系统 | 视角 | 本引擎差异 |
|---------|------|-----------|
| 教育内容难度智能分级引擎 | 内容侧客观评级（由专家/算法标注 1-10 级） | 本引擎从**学生感受侧**出发，回答"同样标为 7 级的内容，张三觉得刚好、李四觉得极难" |
| 练习答题自适应难度引擎 | 答题行为驱动选题 | 本引擎为它提供更精准的**个人难度偏好区间**输入 |
| 学生认知负荷监测引擎 | 生理/行为信号推断负荷 | 本引擎获取**显式主观反馈**，与隐式信号互为校验 |
| 学习路径难度梯度平滑性引擎 | 路径全局视角 | 本引擎为它提供"梯度平滑"的**个人感知基准线** |

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 采集覆盖 | 日活学生中 ≥40% 每周至少提交 1 次难度反馈 |
| 模型精度 | 个人难度感知预测 MAE ≤ 0.8（10 分制） |
| 校准时效 | 新反馈提交后 ≤5 分钟内更新个人感知模型 |
| 推荐提升 | 使用感知信号后，内容"中途放弃率"下降 ≥10% |
| 冷启动 | 新用户首次反馈后 ≤3 条即产出初步感知画像 |

### 1.3 适用范围

- **学段**：小学及以上（幼儿段不采集显式难度反馈，仅使用隐式行为信号）
- **内容类型**：视频讲解、图文阅读、互动练习、试卷测评、微课程
- **反馈渠道**：内容消费完成时弹窗、学习总结页、错题复盘页、主动入口

## 2. 核心概念

### 2.1 难度维度定义

```
客观难度 (Objective Difficulty, OD)
├── 内容标注难度：由内容难度分级引擎产出，1-10 分制
├── 知识点难度：知识点基础难度系数
└── 综合认知负荷：认知负荷监测引擎推断值

主观难度 (Subjective Difficulty, SD)
├── 显式反馈难度：学生主动提交的难度感受评分
├── 隐式行为难度：由交互行为推断的感受到的难度
└── 综合主观难度：显式 + 隐式加权融合

感知难度偏差 (Perception Gap, PG)
└── PG = SD - OD
    ├── PG > 0：学生感觉比实际更难（可能基础薄弱 / 状态不佳）
    ├── PG ≈ 0：感知与客观一致（理想状态）
    └── PG < 0：学生感觉比实际更简单（可能已掌握 / 内容过于基础）
```

### 2.2 难度舒适区模型

```
舒适区下界 (ZPD_Lower) = 个人能力基准 - 难度容忍度
舒适区上界 (ZPD_Upper) = 个人能力基准 + 难度容忍度

最优挑战区 (ZPD_Optimal)：
├── 区间中心 = 个人能力基准 + 难度容忍度 × 0.6
├── 区间宽度 = 难度容忍度 × 0.8
└── 此区域内学习投入度最高、放弃率最低

—— 基于维果茨基"最近发展区"(ZPD) 理论适配 ——
```

### 2.3 反馈采集策略矩阵

| 触发场景 | 反馈形式 | 采集时机 | 预估完成率 |
|---------|---------|---------|-----------|
| 视频看完 | 3 档表情（😊😌😣） | 视频结束时底部弹出 | 55-70% |
| 练习提交后 | 5 星滑块 | 答题结果页底部 | 40-55% |
| 章节学习完成 | 1-10 数字选择 | 章节总结页 | 30-45% |
| 错题复盘 | 3 档标签（太基础/有收获/超出能力） | 错题查看页操作栏 | 20-35% |
| 主动入口 | 自定义文本 + 评分 | 设置→反馈 | 2-5% |

## 5. 核心算法设计

### 5.1 个人难度感知模型构建算法

采用 **贝叶斯在线学习** 方案，每条新反馈增量更新模型参数，避免全量重计算。

```python
import numpy as np
from dataclasses import dataclass

@dataclass
class DifficultyPerceptionModel:
    """学生难度感知模型（正态分布假设）"""
    perceived_mean: float        # 主观难度均值 μ
    perceived_precision: float   # 精度 τ = 1/σ²（共轭先验）
    alpha: float                 # 精度的 Gamma 先验参数 α
    beta: float                  # 精度的 Gamma 先验参数 β
    sample_count: int            # 样本数
    perception_gap_mean: float   # 感知偏差均值
    perception_gap_samples: list # 最近N条感知偏差（用于趋势分析）

    def predict(self, objective_difficulty: float) -> float:
        """
        给定客观难度，预测该学生将感受的主观难度。
        基于感知偏差模型: SD = OD + perception_gap
        """
        return objective_difficulty + self.perception_gap_mean

    def update(self, subjective_score: float, objective_difficulty: float) -> 'DifficultyPerceptionModel':
        """
        贝叶斯增量更新（Normal-Gamma 共轭先验）。
        
        参数:
            subjective_score: 学生提交的主观难度评分 1-10
            objective_difficulty: 该内容的客观难度
        """
        gap = subjective_score - objective_difficulty
        
        # Normal-Gamma 后验更新
        new_alpha = self.alpha + 0.5
        new_beta = self.beta + 0.5 * (self.perceived_precision * (gap - self.perception_gap_mean)**2) / (self.perceived_precision + 1)
        
        # 均值更新（加权移动）
        learning_rate = min(0.3, 1.0 / (self.sample_count + 1))  # 衰减学习率
        new_gap_mean = self.perception_gap_mean + learning_rate * (gap - self.perception_gap_mean)
        
        # 精度更新
        posterior_mean_precision = self.perceived_precision + 1
        new_precision = (self.alpha / self.beta)  # Gamma 分布的期望
        
        self.perception_gap_mean = new_gap_mean
        self.alpha = new_alpha
        self.beta = new_beta
        self.perceived_precision = new_precision
        self.perceived_mean = objective_difficulty + new_gap_mean
        self.perceived_std = 1.0 / np.sqrt(new_precision) if new_precision > 0 else 2.0
        self.sample_count += 1
        
        # 维护滑动窗口（最近50条感知偏差）
        self.perception_gap_samples.append(gap)
        if len(self.perception_gap_samples) > 50:
            self.perception_gap_samples.pop(0)
        
        return self

    def compute_zpd(self, ability_estimate: float) -> dict:
        """
        基于感知模型计算个人最近发展区(ZPD)。
        
        参数:
            ability_estimate: 该学生该学科的能力估计值 (1-10 制，与难度对齐)
        """
        tolerance = self.perceived_std * 1.5  # 容忍度 = 1.5σ
        
        return {
            'lower': max(1.0, ability_estimate - tolerance),
            'upper': min(10.0, ability_estimate + tolerance),
            'optimal_center': min(10.0, ability_estimate + tolerance * 0.6),
            'tolerance': tolerance
        }

    def compute_confidence(self) -> float:
        """计算模型置信度 (0-1)"""
        if self.sample_count == 0:
            return 0.0
        if self.sample_count < 5:
            return self.sample_count / 5.0 * 0.3  # 冷启动阶段，最大0.3
        if self.sample_count < 20:
            return 0.3 + (self.sample_count - 5) / 15.0 * 0.4  # 爬坡阶段 0.3-0.7
        # 成熟阶段，基于样本量和方差
        variance = self.perceived_std ** 2
        confidence = 1.0 / (1.0 + variance / 2.0)
        return min(0.95, max(0.7, confidence))
```

### 5.2 隐式信号融合推断

当缺乏显式反馈时，利用行为信号推断主观难度。

```python
class ImplicitDifficultyInferrer:
    """隐式难度信号推断器"""
    
    # 信号到难度的回归系数（通过历史数据训练得到）
    SIGNAL_WEIGHTS = {
        'REPLAY_COUNT':     {'coef': 0.45, 'intercept': 0.5},   # 回放次数 → 难度+
        'PAUSE_FREQUENCY':  {'coef': 0.30, 'intercept': 0.0},   # 暂停频率 → 难度+
        'TIME_RATIO':       {'coef': 0.50, 'intercept': -1.0},  # 实际/预计时长比 → 难度+
        'HESITATION':       {'coef': 0.25, 'intercept': 0.0},   # 犹豫度(答题) → 难度+
        'COMPLETION_RATE':  {'coef': -2.0, 'intercept': 8.0},   # 完成率 → 难度-
        'ABANDONMENT':      {'coef': 3.0, 'intercept': 2.0},    # 放弃 → 难度大幅+
    }
    
    # 每种信号的置信度权重
    SIGNAL_CONFIDENCE = {
        'REPLAY_COUNT': 0.6,
        'PAUSE_FREQUENCY': 0.5,
        'TIME_RATIO': 0.7,
        'HESITATION': 0.4,
        'COMPLETION_RATE': 0.8,
        'ABANDONMENT': 0.9,
    }
    
    def infer(self, signals: list[dict], objective_difficulty: float) -> dict:
        """
        多信号融合推断主观难度。
        
        参数:
            signals: [{'signal_type': 'REPLAY_COUNT', 'signal_value': 3.0}, ...]
            objective_difficulty: 内容客观难度
        
        返回:
            {'inferred_sd': float, 'confidence': float, 'contributions': dict}
        """
        if not signals:
            return {'inferred_sd': objective_difficulty, 'confidence': 0.0, 'contributions': {}}
        
        weighted_sum = 0.0
        total_weight = 0.0
        contributions = {}
        
        for sig in signals:
            sig_type = sig['signal_type']
            sig_val = sig['signal_value']
            
            if sig_type not in self.SIGNAL_WEIGHTS:
                continue
            
            w = self.SIGNAL_WEIGHTS[sig_type]
            c = self.SIGNAL_CONFIDENCE[sig_type]
            
            # 归一化信号值到合理范围
            normalized = self._normalize_signal(sig_type, sig_val)
            
            # 推断难度
            inferred = w['coef'] * normalized + w['intercept']
            inferred = np.clip(inferred, 1.0, 10.0)
            
            weighted_sum += inferred * c
            total_weight += c
            contributions[sig_type] = {'inferred': inferred, 'weight': c}
        
        if total_weight == 0:
            return {'inferred_sd': objective_difficulty, 'confidence': 0.0, 'contributions': {}}
        
        fused = weighted_sum / total_weight
        
        # 与客观难度加权融合（隐式信号置信度不足时向客观靠拢）
        overall_confidence = min(0.85, total_weight / 3.0)  # 归一化，上限0.85
        final_sd = fused * overall_confidence + objective_difficulty * (1 - overall_confidence)
        
        return {
            'inferred_sd': round(float(final_sd), 2),
            'confidence': round(overall_confidence, 2),
            'contributions': contributions
        }
    
    def _normalize_signal(self, sig_type: str, value: float) -> float:
        """信号值归一化"""
        norms = {
            'REPLAY_COUNT': min(value / 5.0, 2.0),      # 0-5次 → 0-2
            'PAUSE_FREQUENCY': min(value / 10.0, 2.0),  # 0-10次 → 0-2
            'TIME_RATIO': min(value, 3.0),               # 0-3倍 → 0-3
            'HESITATION': min(value, 1.0),               # 0-1
            'COMPLETION_RATE': np.clip(value, 0.0, 1.0), # 0-1
            'ABANDONMENT': 1.0 if value > 0 else 0.0,    # 二值
        }
        return norms.get(sig_type, value)
```

### 5.3 内容难度校准算法

```python
class ContentDifficultyCalibrator:
    """内容难度校准器：基于聚合主观反馈校准客观难度标注"""
    
    MIN_FEEDBACK_FOR_CALIBRATION = 10  # 最少反馈数才校准
    SIGNIFICANT_GAP_THRESHOLD = 0.8    # 显著偏差阈值
    
    def calibrate(self, content_id: int, feedbacks: list[dict], 
                  objective_difficulty: float) -> dict:
        """
        校准单个内容的难度。
        
        参数:
            content_id: 内容ID
            feedbacks: [{'difficulty_score': 7, 'difficulty_label': 'JUST_RIGHT', ...}, ...]
            objective_difficulty: 当前客观难度标注
        """
        n = len(feedbacks)
        
        if n < self.MIN_FEEDBACK_FOR_CALIBRATION:
            return {
                'status': 'INSUFFICIENT_DATA',
                'recommended_difficulty': objective_difficulty,
                'reason': f'反馈数 {n} < 最低要求 {self.MIN_FEEDBACK_FOR_CALIBRATION}'
            }
        
        scores = np.array([f['difficulty_score'] for f in feedbacks])
        
        # 统计量计算
        stats = {
            'avg': float(np.mean(scores)),
            'std': float(np.std(scores)),
            'median': float(np.median(scores)),
            'p25': float(np.percentile(scores, 25)),
            'p75': float(np.percentile(scores, 75)),
        }
        
        # 分档统计
        label_counts = {'TOO_EASY': 0, 'JUST_RIGHT': 0, 'TOO_HARD': 0}
        for f in feedbacks:
            label = f.get('difficulty_label')
            if label in label_counts:
                label_counts[label] += 1
        
        gap = stats['avg'] - objective_difficulty
        
        # 校准状态判定
        if abs(gap) < self.SIGNIFICANT_GAP_THRESHOLD:
            status = 'CALIBRATED'
        elif gap > self.SIGNIFICANT_GAP_THRESHOLD:
            status = 'UNDER_RATED'  # 内容被低估（学生觉得更难）
        else:
            status = 'OVER_RATED'   # 内容被高估（学生觉得更简单）
        
        # 建议难度：贝叶斯收缩估计
        # posterior = λ × subjective_avg + (1-λ) × objective
        # λ 随样本量增大而趋近 1
        shrinkage = n / (n + 20)  # 20为先验强度
        recommended = shrinkage * stats['avg'] + (1 - shrinkage) * objective_difficulty
        
        # 异常检测：标准差异常大 → 内容可能对不同水平学生差异极大
        if stats['std'] > 3.0:
            status = 'HIGH_VARIANCE'
        
        return {
            'content_id': content_id,
            'avg_subjective': round(stats['avg'], 2),
            'std_subjective': round(stats['std'], 2),
            'median_subjective': round(stats['median'], 2),
            'p25': round(stats['p25'], 2),
            'p75': round(stats['p75'], 2),
            'label_distribution': label_counts,
            'calibration_gap': round(gap, 2),
            'calibration_status': status,
            'recommended_difficulty': round(recommended, 2),
            'total_count': n
        }
```

```python
class ColdStartStrategy:
    """新用户/新内容冷启动策略"""
    
    def get_initial_profile(self, student_id: int, subject_code: str, 
                            grade_level: int, ability_estimate: float) -> dict:
        """
        新用户初始难度感知画像。
        使用年级先验 + 学科修正。
        """
        # 年级基线偏差
        GRADE_PRIORS = {
            1: 0.8, 2: 0.6, 3: 0.4,   # 低年级：偏觉更难
            4: 0.2, 5: 0.1, 6: 0.0,   # 小学高年级：接近客观
            7: -0.1, 8: -0.1,         # 初中：略偏简单
            9: 0.1, 10: 0.2,          # 初三/高一：课业压力增大，偏觉难
            11: -0.2, 12: -0.1,       # 高二高三：自评趋于准确
        }
        
        # 学科修正（某些学科学生普遍感知偏差）
        SUBJECT_CORRECTION = {
            'MATH': 0.3,      # 数学普遍觉得更难
            'PHYSICS': 0.4,   # 物理更难
            'CHEMISTRY': 0.1,
            'CHINESE': -0.2,  # 语文普遍觉得较容易
            'ENGLISH': 0.0,
            'BIOLOGY': -0.1,
            'HISTORY': -0.2,
            'GEOGRAPHY': -0.1,
            'POLITICS': -0.2,
        }
        
        gap_prior = GRADE_PRIORS.get(grade_level, 0) + SUBJECT_CORRECTION.get(subject_code, 0)
        
        return {
            'perceived_mean': ability_estimate + gap_prior,
            'perceived_std': 2.0,  # 初始标准差较大（不确定性高）
            'perception_gap_mean': gap_prior,
            'perception_gap_std': 1.5,
            'zpd_lower': max(1.0, ability_estimate - 2.5),
            'zpd_upper': min(10.0, ability_estimate + 2.0),
            'zpd_optimal_center': min(10.0, ability_estimate + 1.2),
            'difficulty_tolerance': 2.2,
            'model_confidence': 0.05,  # 极低置信度
            'sample_count': 0,
            'strategy': 'GRADE_PRIOR_INITIALIZED'
        }
    
    def rapid_warmup(self, initial_feedbacks: list[dict], 
                     current_profile: dict) -> dict:
        """
        快速预热：收到前 3 条反馈后的快速画像更新。
        使用更大的学习率快速收敛。
        """
        if not initial_feedbacks:
            return current_profile
        
        gaps = [f['difficulty_score'] - f['objective_difficulty'] 
                for f in initial_feedbacks if f.get('objective_difficulty')]
        
        if not gaps:
            return current_profile
        
        avg_gap = np.mean(gaps)
        
        # 快速更新：使用 0.5 的学习率
        new_gap = 0.5 * current_profile['perception_gap_mean'] + 0.5 * avg_gap
        
        return {
            **current_profile,
            'perception_gap_mean': new_gap,
            'perceived_mean': current_profile['perceived_mean'] + (new_gap - current_profile['perception_gap_mean']),
            'perceived_std': max(1.2, current_profile['perceived_std'] - 0.3),  # 收窄
            'model_confidence': min(0.35, 0.05 + len(initial_feedbacks) * 0.1),
            'sample_count': len(initial_feedbacks),
            'strategy': 'RAPID_WARMUP'
        }
```

### 5.5 难度推荐区间计算

```python
class DifficultyRecommender:
    """基于感知模型生成难度推荐区间"""
    
    def recommend(self, profile: dict, ability_estimate: float, 
                  scenario: str, recent_trend: dict = None) -> dict:
        """
        生成个性化难度推荐。
        
        参数:
            profile: 学生难度感知画像
            ability_estimate: 当前学科能力估值
            scenario: 场景 (PREVIEW/PRACTICE/REVIEW/EXAM_PREP/ERROR_CORRECTION)
            recent_trend: {'perception_gap_trend': 'NARROWING', 'tolerance_trend': 'EXPANDING', ...}
        """
        zpd = {
            'lower': profile['zpd_lower'],
            'upper': profile['zpd_upper'],
            'optimal_center': profile['zpd_optimal_center']
        }
        
        # 场景策略调整
        SCENARIO_ADJUSTMENT = {
            'PREVIEW':            {'shift': -1.0, 'width_factor': 0.7, 'strategy': 'GENTLE_INTRO'},
            'PRACTICE':           {'shift': 0.0,  'width_factor': 1.0, 'strategy': 'ZPD_CENTERED'},
            'REVIEW':             {'shift': -0.5, 'width_factor': 0.6, 'strategy': 'CONFIDENCE_BUILDING'},
            'EXAM_PREP':          {'shift': 0.8,  'width_factor': 1.2, 'strategy': 'GRADUAL_INCREASE'},
            'ERROR_CORRECTION':   {'shift': -0.3, 'width_factor': 0.5, 'strategy': 'TARGETED_PRACTICE'},
        }
        
        adj = SCENARIO_ADJUSTMENT.get(scenario, SCENARIO_ADJUSTMENT['PRACTICE'])
        
        center = zpd['optimal_center'] + adj['shift']
        half_width = (zpd['upper'] - zpd['lower']) / 2 * adj['width_factor']
        
        recommended_range = {
            'min': max(1.0, round(center - half_width, 1)),
            'max': min(10.0, round(center + half_width, 1)),
            'target': max(1.0, min(10.0, round(center, 1)))
        }
        
        # 趋势修正
        strategy = adj['strategy']
        rationale_parts = []
        
        if recent_trend:
            if recent_trend.get('perception_gap_trend') == 'NARROWING':
                rationale_parts.append("感知偏差正在收窄，学生对难度判断趋于准确")
                if recommended_range['target'] < ability_estimate + 1:
                    strategy = 'SLIGHT_CHALLENGE'
                    recommended_range['target'] = min(10.0, recommended_range['target'] + 0.3)
                    
            elif recent_trend.get('perception_gap_trend') == 'WIDENING':
                rationale_parts.append("感知偏差正在扩大，建议降低难度提升速度")
                recommended_range['target'] = max(1.0, recommended_range['target'] - 0.3)
                
            if recent_trend.get('tolerance_trend') == 'EXPANDING':
                rationale_parts.append("难度容忍度在提升，可适当扩大推荐范围")
                recommended_range['min'] = max(1.0, recommended_range['min'] - 0.2)
                recommended_range['max'] = min(10.0, recommended_range['max'] + 0.2)
        
        if not rationale_parts:
            rationale_parts.append(f"基于{profile['sample_count']}条反馈的感知模型推荐")
        
        rationale_parts.append(f"当前场景={scenario}，策略={strategy}")
        
        return {
            **recommended_range,
            'strategy': strategy,
            'rationale': '；'.join(rationale_parts),
            'model_confidence': profile['model_confidence']
        }
```

### 8.2 降级策略

```python
class DifficultyServiceDegradation:
    """降级策略链"""
    
    LEVEL_1_NORMAL = "正常服务：全量功能"
    LEVEL_2_DEGRADED = "降级：仅接收反馈，异步更新模型"
    LEVEL_3_MINIMAL = "最小可用：仅记录反馈，不更新模型"
    LEVEL_4_OFFLINE = "离线：反馈请求暂存客户端，恢复后重试"
    
    @staticmethod
    def check_degradation_level(health_status: dict) -> str:
        """
        根据依赖服务健康状态决定降级等级。
        """
        if not health_status['mysql_available']:
            return DifficultyServiceDegradation.LEVEL_4_OFFLINE
        
        if health_status['pending_feedback_queue_size'] > 10000:
            return DifficultyServiceDegradation.LEVEL_3_MINIMAL
        
        if (not health_status['ability_service_available'] or 
            health_status['model_update_latency_ms'] > 2000):
            return DifficultyServiceDegradation.LEVEL_2_DEGRADED
        
        return DifficultyServiceDegradation.LEVEL_1_NORMAL
```

### 9.3 与推荐引擎的集成接口

推荐引擎在生成候选列表时调用本引擎获取推荐难度区间：

```python
# 推荐引擎侧调用示例
class RecommendationFilter:
    def filter_by_difficulty(self, candidates: list, student_id: int, 
                             subject_code: str, scenario: str) -> list:
        """根据个人难度感知过滤推荐候选"""
        
        # 1. 获取推荐难度区间
        range_resp = self.difficulty_client.get_recommendation(
            student_id=student_id,
            subject_code=subject_code,
            scenario=scenario
        )
        
        if not range_resp or range_resp['model_confidence'] < 0.3:
            # 置信度太低，不过滤，使用原有逻辑
            return candidates
        
        recommended = range_resp
        min_d = recommended['min']
        max_d = recommended['max']
        target_d = recommended['target']
        
        # 2. 过滤 + 排序
        filtered = []
        for item in candidates:
            item_difficulty = item.get('difficulty_score', 5.0)
            if min_d <= item_difficulty <= max_d:
                # 在区间内，按与目标难度的接近程度排序
                distance = abs(item_difficulty - target_d)
                item['difficulty_match_score'] = max(0, 1 - distance / (max_d - min_d + 0.01))
                filtered.append(item)
        
        # 3. 如果过滤后结果太少，逐步扩大区间
        if len(filtered) < 10:
            # 扩大50%区间
            expansion = (max_d - min_d) * 0.25
            min_d = max(1.0, min_d - expansion)
            max_d = min(10.0, max_d + expansion)
            filtered = [item for item in candidates 
                       if min_d <= item.get('difficulty_score', 5.0) <= max_d]
        
        return filtered
```

```python
# 批量获取多个学生的难度推荐（用于班级/群组推荐场景）
async def batch_get_recommendations(student_ids: list[int], subject_code: str, 
                                     scenario: str) -> dict[int, dict]:
    """
    批量获取推荐区间，避免N+1查询。
    """
    # 1. 批量查缓存
    cache_keys = [f"student:difficulty:profile:{sid}:{subject_code}" 
                  for sid in student_ids]
    cached = await redis.mget(cache_keys)
    
    # 2. 找出缓存未命中的
    missing_ids = [sid for sid, val in zip(student_ids, cached) if val is None]
    
    # 3. 批量查数据库
    if missing_ids:
        profiles = await db.batch_get_profiles(missing_ids, subject_code)
        # 批量回填缓存
        pipe = redis.pipeline()
        for sid, profile in zip(missing_ids, profiles):
            pipe.setex(f"student:difficulty:profile:{sid}:{subject_code}", 
                       3600, json.dumps(profile))
        await pipe.execute()
        # 合并结果
        all_profiles = {**dict(zip([sid for sid, v in zip(student_ids, cached) if v], 
                                   [json.loads(v) for v in cached if v])),
                        **dict(zip(missing_ids, profiles))}
    else:
        all_profiles = dict(zip(student_ids, [json.loads(v) for v in cached if v]))
    
    # 4. 批量计算推荐区间
    results = {}
    for sid, profile in all_profiles.items():
        results[sid] = recommender.recommend(profile, profile.get('ability', 5.0), scenario)
    
    return results
```

## 15. 附录

### 15.1 信号权重训练方法

隐式信号融合的回归系数建议通过以下步骤训练：

1. **数据准备**：选取同时具有显式反馈和隐式信号的会话（需 ≥ 10000 条）
2. **特征工程**：将6类隐式信号作为特征，显式难度评分作为标签
3. **模型训练**：使用 Ridge 回归（带正则化的线性回归），防止过拟合
4. **验证**：5折交叉验证，关注 MAE 指标
5. **部署**：将训练好的系数写入配置，支持热更新
6. **监控**：每月用新增数据重训练，对比效果后灰度切换

### 15.2 维果茨基 ZPD 理论适配说明

本引擎的难度舒适区模型基于维果茨基"最近发展区"（Zone of Proximal Development）理论：

- **已掌握区**（低于 ZPD_Lower）：学生已独立掌握，重复练习价值低
- **最近发展区**（ZPD_Lower ~ ZPD_Upper）：在适当辅助下可以掌握，是最高效的学习区间
- **超出能力区**（高于 ZPD_Upper）：即使有辅助也难以掌握，容易导致挫败感

与传统 ZPD 理论的不同之处：
1. **个性化边界**：ZPD 边界由学生主观反馈数据驱动，而非教师观察
2. **动态调整**：随学生能力成长和感知校准自动更新
3. **学科独立**：每个学科维护独立的 ZPD 参数
4. **场景适配**：根据预习/练习/复习/备考等场景调整 ZPD 利用策略
