### 1.1 功能定位

首页与学习工作台是 PrimeTop APP 的第一入口页面，负责：
- 聚合用户学习状态、今日任务、快捷入口
- 按分龄策略呈现差异化 UI
- 作为全局导航枢纽连接各核心模块

### 2.2 页面生命周期

```
App启动
  │
  ▼
初始化管线（AppInitPipeline）
  │
  ├─ 加载用户档案 → UserRepository.getProfile()
  ├─ 预请求首页数据 → HomeRepository.prefetch()
  │   └─ 并行请求：今日任务、错题统计、最近学习、薄弱知识点
  │
  ▼
HomePage.build()
  │
  ├─ 首次渲染：检查缓存 → 有缓存立即渲染 → 无缓存显示骨架屏
  ├─ 网络数据到达 → 合并更新（增量diff，避免闪烁）
  │
  ▼
页面可见（onResume）
  │
  ├─ 检查用户档案变更（切换年级、教材版本）→ 刷新全部卡片
  ├─ 检查会员状态变更（刚完成购买）→ 刷新顶部会员标识
  ├─ 检查学习数据变更（刚完成答题、错题复习）→ 刷新对应卡片
  │
  ▼
页面不可见（onPause）
  │
  └─ 记录页面停留时长 → 埋点上报
```

### 2.3 生命周期管理

```dart
// lib/pages/home/home_page.dart
class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() => _HomePageState();
}

class _HomePageState extends State<HomePage>
    with WidgetsBindingObserver, RouteAware {
  final HomeBloc _bloc = HomeBloc();
  DateTime? _resumedAt;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addObserver(this);
    _bloc.add(HomeLoadRequested());
  }

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    if (state == AppLifecycleState.resumed) {
      _resumedAt = DateTime.now();
      _bloc.add(HomeRefreshRequested(reason: 'app_resumed'));
    } else if (state == AppLifecycleState.paused && _resumedAt != null) {
      final duration = DateTime.now().difference(_resumedAt!);
      AnalyticsService.logPageDuration('home', duration.inSeconds);
    }
  }

  @override
  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    _bloc.close();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return BlocProvider.value(
      value: _bloc,
      child: Scaffold(
        body: RefreshIndicator(
          onRefresh: () => _bloc.refresh(),
          child: BlocBuilder<HomeBloc, HomeState>(
            builder: (context, state) {
              return switch (state) {
                HomeInitial() || HomeLoading() => const HomeSkeleton(),
                HomeError(:final message) => HomeErrorView(
                    message: message,
                    onRetry: () => _bloc.add(HomeLoadRequested()),
                  ),
                HomeLoaded(:final data) => HomeContentView(data: data),
              };
            },
          ),
        ),
      ),
    );
  }
}
```

### 4.2 增量刷新接口

**接口路径：** `GET /api/v1/home/refresh`

**用途：** 从其他页面返回时，只刷新变更过的区域

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `since` | long | 是 | 上次加载的时间戳（毫秒） |
| `areas` | string | 否 | 指定刷新区域：`tasks,mistakes,summary` 等 |

**响应：** 与聚合接口相同的 data 结构，但只包含 `areas` 指定的字段，未指定的字段为 `null`。

### 5.2 BLoC 实现

```dart
// lib/pages/home/bloc/home_bloc.dart

class HomeBloc extends Bloc<HomeEvent, HomeState> {
  final HomeRepository _repository;
  final UserProfileStore _profileStore;

  HomeBloc({
    required HomeRepository repository,
    required UserProfileStore profileStore,
  })  : _repository = repository,
        _profileStore = profileStore,
        super(const HomeInitial()) {
    on<HomeLoadRequested>(_onLoad);
    on<HomeRefreshRequested>(_onRefresh);
    on<HomePartialRefresh>(_onPartialRefresh);
    on<HomeUserProfileChanged>(_onProfileChanged);
    on<HomeTaskStatusUpdated>(_onTaskStatusUpdated);
  }

  Future<void> _onLoad(
    HomeLoadRequested event,
    Emitter<HomeState> emit,
  ) async {
    emit(const HomeLoading());

    // 尝试先读缓存
    final cached = await _repository.getCachedSummary();
    if (cached != null) {
      emit(HomeLoading(cachedData: cached));
    }

    try {
      final data = await _repository.getSummary();
      emit(HomeLoaded(data: data, loadedAt: DateTime.now()));
      await _repository.cacheSummary(data);
    } catch (e) {
      if (cached != null) {
        emit(HomeError(message: '刷新失败，显示缓存数据', cachedData: cached));
      } else {
        emit(HomeError(message: _mapError(e)));
      }
    }
  }

  Future<void> _onRefresh(
    HomeRefreshRequested event,
    Emitter<HomeState> emit,
  ) async {
    final cached = _currentData;
    if (cached != null) {
      emit(HomeLoaded(data: cached, loadedAt: DateTime.now(), isRefreshing: true));
    }

    try {
      final data = await _repository.getSummary();
      emit(HomeLoaded(data: data, loadedAt: DateTime.now()));
      await _repository.cacheSummary(data);
    } catch (e) {
      // 刷新失败，保持当前数据不变
      if (cached != null) {
        emit(HomeLoaded(data: cached, loadedAt: DateTime.now()));
      }
    }
  }

  Future<void> _onPartialRefresh(
    HomePartialRefresh event,
    Emitter<HomeState> emit,
  ) async {
    final current = _currentData;
    if (current == null) return;

    try {
      final since = DateTime.now().subtract(const Duration(minutes: 5));
      final partial = await _repository.refresh(
        since: since.millisecondsSinceEpoch,
        areas: event.areas,
      );
      // 合并部分数据
      final merged = _mergeData(current, partial);
      emit(HomeLoaded(data: merged, loadedAt: DateTime.now()));
      await _repository.cacheSummary(merged);
    } catch (_) {
      // 静默失败，保持当前数据
    }
  }

  void _onProfileChanged(
    HomeUserProfileChanged event,
    Emitter<HomeState> emit,
  ) {
    final current = _currentData;
    if (current == null) return;
    final updated = HomeData(
      userBrief: event.newProfile,
      quickActions: current.quickActions,
      todayTasks: current.todayTasks,
      continueLearning: current.continueLearning,
      weakPoints: current.weakPoints,
      dailySummary: current.dailySummary,
      messages: current.messages,
      ageConfig: current.ageConfig,
    );
    emit(HomeLoaded(data: updated, loadedAt: DateTime.now()));
    // 触发全量刷新（年级/教材版本变了）
    add(const HomeRefreshRequested(reason: 'profile_changed'));
  }

  void _onTaskStatusUpdated(
    HomeTaskStatusUpdated event,
    Emitter<HomeState> emit,
  ) {
    final current = _currentData;
    if (current == null) return;

    final tasks = current.todayTasks.tasks.map((t) {
      if (t.id == event.taskId) {
        return TodayTask(
          id: t.id, type: t.type, title: t.title, subtitle: t.subtitle,
          estimatedMinutes: t.estimatedMinutes, status: event.newStatus,
          route: t.route,
        );
      }
      return t;
    }).toList();

    final newCompleted = tasks.where((t) => t.status == TaskStatus.completed).length;

    final updated = HomeData(
      userBrief: current.userBrief,
      quickActions: current.quickActions,
      todayTasks: TodayTaskSummary(
        totalTasks: current.todayTasks.totalTasks,
        completedTasks: newCompleted,
        estimatedMinutes: current.todayTasks.estimatedMinutes,
        tasks: tasks,
      ),
      continueLearning: current.continueLearning,
      weakPoints: current.weakPoints,
      dailySummary: current.dailySummary,
      messages: current.messages,
      ageConfig: current.ageConfig,
    );
    emit(HomeLoaded(data: updated, loadedAt: DateTime.now()));
  }

  HomeData? get _currentData {
    final s = state;
    if (s is HomeLoaded) return s.data;
    if (s is HomeError) return s.cachedData;
    if (s is HomeLoading) return s.cachedData;
    return null;
  }

  String _mapError(Object e) {
    if (e is NetworkException) return '网络连接失败，请检查网络后重试';
    if (e is TimeoutException) return '请求超时，请稍后重试';
    return '加载失败，请下拉刷新';
  }

  HomeData _mergeData(HomeData base, Map<String, dynamic> partial) {
    return HomeData(
      userBrief: partial['user_brief'] ?? base.userBrief,
      quickActions: partial['quick_actions'] ?? base.quickActions,
      todayTasks: partial['today_tasks'] ?? base.todayTasks,
      continueLearning: partial['continue_learning'] ?? base.continueLearning,
      weakPoints: partial['weak_points'] ?? base.weakPoints,
      dailySummary: partial['daily_summary'] ?? base.dailySummary,
      messages: partial['messages'] ?? base.messages,
```

```dart
class HomeRepository {
  final ApiClient _api;
  final LocalCache _cache;

  static const _cacheKey = 'home_summary';

  Future<HomeData> getSummary() async {
    final response = await _api.get('/api/v1/home/summary');
    return HomeData.fromJson(response.data);
  }

  Future<Map<String, dynamic>> refresh({
    required int since,
    Set<String>? areas,
  }) async {
    final query = <String, String>{
      'since': since.toString(),
      if (areas != null) 'areas': areas.join(','),
    };
    final response = await _api.get('/api/v1/home/refresh', queryParameters: query);
    return response.data as Map<String, dynamic>;
  }

  Future<HomeData?> getCachedSummary() async {
    final json = await _cache.getJson(_cacheKey);
    if (json == null) return null;
    try {
      return HomeData.fromJson(json);
    } catch (_) {
      return null;
    }
  }

  Future<void> cacheSummary(HomeData data) async {
    await _cache.setJson(_cacheKey, data.toJson(), ttl: const Duration(hours: 2));
  }
}
```

```dart
class _HomeBannerMarqueeState extends State<HomeBannerMarquee>
    with SingleTickerProviderStateMixin {
  late final PageController _controller = PageController();
  late final Timer _timer;
  int _index = 0;

  @override
  void initState() {
    super.initState();
    // 单条消息 5s 自动轮换；仅 1 条时不启动定时器
    if (widget.messages.length > 1) {
      _timer = Timer.periodic(const Duration(seconds: 5), (_) {
        _index = (_index + 1) % widget.messages.length;
        if (_controller.hasClients) {
          _controller.animateToPage(
            _index,
            duration: const Duration(milliseconds: 400),
            curve: Curves.easeInOut,
          );
        }
      });
    }
  }

  @override
  void dispose() {
    _timer.cancel();
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Container(
      margin: const EdgeInsets.fromLTRB(16, 0, 16, 12),
      padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
      decoration: BoxDecoration(
        color: context.colorScheme.surfaceVariant,
        borderRadius: BorderRadius.circular(12),
      ),
      child: Row(
        children: [
          Icon(Assets.icons.megaphone, size: 16, color: context.colorScheme.primary),
          const SizedBox(width: 8),
          Expanded(
            child: SizedBox(
              height: 22,
              child: PageView.builder(
                controller: _controller,
                physics: const NeverScrollableScrollPhysics(), // 手势与页面滚动冲突，禁止手动翻页
                itemCount: widget.messages.length,
                itemBuilder: (context, i) {
                  final msg = widget.messages[i];
                  return GestureDetector(
                    behavior: HitTestBehavior.opaque,
                    onTap: () {
                      AnalyticsService.track('home_banner_click', properties: {
                        'msg_id': msg.id,
                        'msg_type': msg.type,
                      });
                      context.push(msg.route ?? '/messages');
                    },
                    child: Align(
                      alignment: Alignment.centerLeft,
                      child: Text(
                        msg.title,
                        maxLines: 1,
                        overflow: TextOverflow.ellipsis,
                        style: context.textTheme.bodySmall,
                      ),
                    ),
                  );
                },
              ),
            ),
          ),
          // 轮播指示点
          if (widget.messages.length > 1)
            Row(
              mainAxisSize: MainAxisSize.min,
              children: [
                for (var i = 0; i < widget.messages.length; i++)
                  Container(
                    width: i == _index ? 12 : 4,
```

**任务状态本地更新的联动机制：**

任务的实际完成发生在目标模块内部（练习交卷、章节学完、错题复习结束）。模块通过全局 `EventBus` 广播事件，首页 Bloc 订阅并做乐观更新：

```dart
// 目标模块完成时广播（如练习交卷后）
EventBus.instance.fire(TaskCompletedEvent(taskId: 'task_002'));

// HomeBloc 构造时订阅
EventBus.instance.on<TaskCompletedEvent>().listen(
  (e) => add(HomeTaskStatusUpdated(e.taskId, TaskStatus.completed)),
);
```

| 联动事件源 | 触发时机 | 首页动作 |
|-----------|---------|---------|
| 练习测评模块 | 交卷且达成任务条件 | 对应任务 → completed，进度 +1 |
| 同步课堂模块 | 章节学习达标 | 对应任务 → completed |
| 错题本模块 | 复习清单完成 | 对应任务 → completed |
| 学习规划模块 | 任务被跳过/删除 | 全量刷新 tasks 区域（`HomePartialRefresh({'tasks'})`） |

乐观更新后 30s 内由 `HomePartialRefresh` 校准；若服务端判定未完成（如练习未达及格线），回滚状态并 Toast 说明。

| 学段 | 展示策略 |

```dart
class CardWidgetRegistry {
  static final Map<String, HomeCardBuilder> _builders = {
    // 学习类（复用固定模块同款视觉，但接受服务端编排插入推荐流）
    'recommended':       RecommendedPracticeCard.new,      // 推荐练习（含题量/知识点标签）

    'ai_helper':         AiHelperCard.new,                 // AI 辅导场景化入口
    // 进度类
    'study_streak':      StudyStreakCard.new,              // 连续学习打卡激励
    'milestone':         MilestoneCard.new,                // 成就/里程碑
    'weekly_report':     WeeklyReportCard.new,             // 周报已生成提醒
    // 运营类
    'banner':            BannerCard.new,                   // 运营 Banner（图片卡）
    'activity':          ActivityCard.new,                 // 运营活动（大图 + 按钮）
    'membership_promo':  MembershipPromoCard.new,          // 会员推广
    // 固定模块同源类型在推荐流中降级为通用卡，避免页面重复模块
    'today_task':        GenericActionCard.new,
    'continue_learn':    GenericActionCard.new,
    'weak_point':        GenericActionCard.new,
    'quick_actions':     IgnoreCard.new,                   // 已由固定模块渲染，丢弃
    'subject_tools':     GenericActionCard.new,
  };

  /// 默认渲染器：标题 + 副标题 + 按钮 + 跳转，任何类型都可兄底
  static const HomeCardBuilder _fallback = GenericActionCard.new;

  static Widget build({
    required BuildContext context,
    required HomeCardData card,
    required int moduleIndex,
    required VoidCallback onTap,
  }) {
    // 权益门控：免费用户看到会员卡时，内容可见但 CTA 锁样式
    final gated = card.membershipRequired != null &&
        !MembershipStore.instance.hasTier(card.membershipRequired!);

    final builder = _builders[card.cardType] ?? _fallback;
    return builder(context: context, card: card, moduleIndex: moduleIndex, onTap: onTap, gated: gated);
  }
}

typedef HomeCardBuilder = Widget Function({
  required BuildContext context,
  required HomeCardData card,
  required int moduleIndex,
  required VoidCallback onTap,
  bool gated,
});
```

**payload 渲染契约（服务端下发必须遵守，客户端容错解析）：**

| card_type | payload 必选字段 | 渲染要点 |
|-----------|----------------|---------|
| `recommended` | `question_count`、`knowledge_points[]`、`estimated_minutes` | 题量/时长/知识点标签，CTA="去练习" |
| `review_reminder` | `due_count`、`subject` | 到期错题数徽标，CTA="去复习" |
| `exam_countdown` | `exam_name`、`days_left`、`exam_date` | 倒计时天数大字号，CTA="查看冲刺计划" |
| `milestone` | `badge_name`、`icon`、`unlocked_at` | 成就徽章图 + 名称，CTA="查看" |
| `banner`/`activity` | `image_url`、`image_ratio` | 图片卡，宽度撑满、高度按 ratio，图加载失败显示标题卡 |
| `membership_promo` | `plan_id`、`discount_label`? | gated=true 时 CTA 为“开通会员查看”，点击 → `/membership` |
| 其余/未知 | — | GenericActionCard：icon+title+subtitle+actionText |

**曝光埋点：** 每张卡进入可视区（Visibility 检测，露出 ≥50% 且停留 ≥500ms）上报 `home_card_expose`（card_id/card_type/module_index），与服务端 `shown_count` 统计口径独立（服务端以响应下发计数，客户端以真实曝光计数，差异供推荐质量分析）。

| 消息轮播 | ✖（不渲染） | ✔ | ✔ | ✔ |
| 快捷操作布局 | `grid_2x2` 大卡 | 低年级 `grid_2x2` / 高年级 `grid_1x4` | `grid_1x4` | `grid_1x4` |
| 今日任务 `maxVisibleTasks` | 1 | 3 | 4 | 4 |
| 继续学习 | ✔（大卡） | ✔ | ✔ | ✔ |
| 薄弱知识点 | ✖（`showWeakPoints=false`） | ✔ | ✔ | ✔ |
| 每日数据摘要 | 简化（时长+星星） | 游戏化版 | 标准版 | 标准版（含答题数） |
| 推荐卡片流 | 仅 milestone/study_streak 类型 | 全类型 | 全类型 | 全类型（弱化运营类） |
| 语音辅助 `enableVoiceAssist` | ✔（默认开） | 可选 | ✖ | ✖ |

> 矩阵为客户端默认规则，服务端 `age_config` 下发值优先（运营可配置覆盖）。

### 7.2 主题映射（与分龄 UI 适配规范对齐）

`AgeAdaptiveConfig.themeKey` 与《分龄UI适配与交互设计规范》主题体系映射：

| ageGroup | 主题 | 圆角/字号/密度 | 暗色模式 |
|---------|------|--------------|---------|
| toddler | candy（糖果） | 大圆角 20px / 大字号 +2sp / 大点击热区 ≥56dp | 强制亮色（护眼红线） |
| primary | fresh（清新） | 圆角 16px / 标准 +1sp / 热区 ≥48dp | 跟随系统 |
| junior | standard（标准） | 圆角 12px / 标准 / 热区 ≥44dp | 跟随系统 |
| senior | pro（专业） | 圆角 10px / 密度更高 / 热区 ≥44dp | 跟随系统 |

主题切换由 ThemeEngine 按学段自动应用（《客户端-主题引擎与动态外观系统》），首页不自行管理颜色，全部走 `context.colorScheme` 语义令牌。

### 7.3 幼儿模式特殊交互

1. **语音优先**：问候语/任务卡/成就卡附带 TTS 播报（音量跟随媒体音量，可在家长中心关闭）；连续播报间隔 ≥2s，防轰炸。
2. **防误触**：所有跳转按钮点击后 300ms 内二次点击无效（节流）；涉及消费/设置类入口不直接可达，需家长门（《服务端-统一家长门与监护人授权核验引擎》）。
3. **正向激励**：完成任务全屏彩带 + 星星飞入动画，失败不出现红叉，统一“再试一次”。
4. **内容极简**：不展示任何百分比、正确率、倒计时数字；薄弱点/考试倒计时类卡片在推荐流中被服务端 `target_grades` 过滤，客户端再按 `ageGroup==toddler` 二次过滤兑底。

### 7.4 学段/年级切换处理

学段升迁或教材版本切换（经《服务端-用户年级升迁与学段转换服务》）后：

```
HomeUserProfileChanged(newProfile)
  → 立即更新 TopBar（避免旧学段标识残窗）
  → HomeRefreshRequested(reason: 'profile_changed')
      → /home/summary 全量拉取（新 ageConfig/任务/薄弱点全部重建）
      → /home/cards 不带 refresh_token 重拉（旧画像卡片全部失效）
      → 本地缓存 cacheSummary 覆盖
      → 骨架屏过渡（新旧 ageConfig 布局差异大，禁止增量 diff，避免错位闪烁）
```

## 8. 交互设计细节

### 8.1 下拉刷新

- 触发位移 80dp（幼儿 100dp，降低误触），触发时轻震动反馈（HapticFeedback.mediumIntensity，幼儿关闭）。
- 刷新范围：`/home/summary` + `/home/cards` 并行；两者独立成败，任一成功即收起 RefreshIndicator。
- 刷新期间页面保持当前数据可交互（`isRefreshing=true` 不锁 UI）。

### 8.2 骨架屏

`HomeSkeleton` 按 §6.1 组件树顺序输出 7 个占位块（顶栏/轮播/快捷区/任务×2/续学/数据卡）， shimmer 周期 1.2s；仅首次无缓存时全屏骨架，其余场景不使用骨架（直接旧数据刷新）。规范遵循《客户端-页面状态模式与骨架屏加载空态错误态设计规范》。

### 8.3 空态设计

| 模块 | 空态表现 |
|------|---------|
| 今日任务（total=0） | 插画 + “今天没有任务，去同步课堂看看吧” + 按钮 → `/sync-class` |
| 继续学习 | `null` 时整卡隐藏（不占位不空态） |
| 薄弱点为空 | 插画 + 成就型文案“暂无薄弱点，继续保持！”（正面框架） |
| 消息为空 | 轮播区隐藏，铃铛角标清零 |
| 推荐流为空 | 隐藏“为你推荐”标题与区块 |
| 新用户首次（无任何数据） | 引导卡：选择年级教材 → 生成首个学习计划（串接《用户引导与新手教程系统》） |

### 8.4 错误态与降级

| 场景 | 表现 |
|------|------|
| 无缓存 + 请求失败 | 全屏错误态（插画+重试按钮），见 HomeErrorView |
| 有缓存 + 刷新失败 | 保留旧数据，顶部轻提示条“数据更新于 20:30 · 点击重试”，不弹 Toast |
| 单区域数据 null（服务端部分降级） | 该模块隐藏，其余模块正常（`HomeContentView` 各模块均有 null 守卫） |
| 推荐流加载失败 | 静默（D-13），保留上次卡片，不提示 |
| Token 过期 (401) | 网络层统一刷新重试（《客户端-网络请求治理》），首页不特殊处理 |

### 8.5 动效规范

| 动效 | 参数 | 说明 |
|------|------|------|
| 模块入场 | 50ms staggered fade+slide（仅首次构建） | 幼儿/小学开启；初中/高中关闭 |
| 进度环/进度条 | 600ms ease-out | 数值变化时从旧值动画到新值 |
| 任务完成 | 打勾 scale 0→1 + 轻震动 | 仅 pending→completed 状态翻转时 |
| 周目标达成 | WeeklyGoalAchievedBadge 入场 800ms | 每周仅首次触发，防重复打扰 |
| 减少动效 | 以上全部尊重系统“减弱动态效果”设置与无障碍开关 | 《客户端-无障碍访问与辅助功能系统》 |

### 8.6 深链接跳转协议

- 固定模块路由：`QuickAction.route` / `TodayTask.route` / `reviewRoute` 均为客户端内路由（`/photo-search` 等），`routeParams`/`reviewParams` 经 `extra` 传递。
- 推荐卡 `action_url`：支持 App 内路由（`/exam/sprint?examId=xxx`）与 H5 链接（`https://`，走 WebView 容器）；未知 App 路由 → 兑底跳转 `/home` 并 Toast“内容不存在”。
- 所有跳转前先上报对应埋点，跳转失败（路由未注册）记录 `home_route_miss`（route 值）供排查。

## 10. 性能优化

| 目标 | 策略 |
|------|------|
| 首帧 ≤ 800ms（缓存命中） | 启动管线预取 + 缓存先行渲染（§2.2）；骨架屏同步首帧绘制 |
| 数据就绪 P90 ≤ 2.5s | summary 与 cards 并行；预取超时 3s 放弃改页面内加载 |
| 滚动 60fps | 全 Sliver 结构；每个模块 `RepaintBoundary` 包裹；列表项 const 构造；无嵌套滚动（快捷区/任务区 shrinkWrap） |
| 图片 | 头像/图标启动期 precacheImage；banner 图按容器尺寸请求 CDN 缩略图（`?w=750&format=webp`）；失败占位纯色块 |
| 内存 | 推荐卡本地最多保留 20 张（超出丢弃最旧）；PageView 复用；退出页面释放 AnimationController |
| 构建 | HomeData 不可变 + copyWith，避免整页 setState；Bloc 粒度更新（TaskStatusUpdated 只重建任务模块） |

监控指标：`home_first_render_ms`（缓存命中首帧）、`home_data_ready_ms`（网络数据到达）、`home_scroll_jank_rate`（帧率采样），接入《客户端-性能监控与用户体验度量系统》。

## 11. 错误处理与降级汇总

| 编号 | 场景 | 处理 |
|------|------|------|
| D-9 | summary 失败无缓存 | 全屏错误态 + 重试 |

## 12. 验收标准（E2E 场景）

| # | 场景 | 预期 |
|---|------|------|
| 1 | 冷启动首次进入（无缓存） | 骨架屏 ≤100ms 出现；数据到达后无闪烁切换 |
| 2 | 二次进入（有缓存） | 直接渲染缓存数据；后台刷新合并后无整页闪烁 |
| 3 | 下拉刷新 | 80dp 触发 + 震动；summary+cards 并行；失败时保留旧数据与提示条 |
| 4 | 幼儿账号登录 | 2x2 大卡布局；无薄弱点模块；任务仅 1 条；语音问候；无百分比 |
| 5 | 高中账号登录 | 1x4 快捷栏；4 条任务显示；数据卡含答题数；无游戏化彩蛋 |
| 6 | 完成练习任务后返回首页 | 对应任务乐观更新打勾 + 进度环 +1；30s 内服务端校准一致 |
| 7 | 任务实际未达成（未及格） | 校准回滚 + Toast“再练一次就达成了” |
| 8 | 点击“去补强”薄弱点 | 进入 weak_point 模式练习；完成后薄弱点列表刷新 |
| 9 | 推荐卡曝光 | 露出≥50%+500ms 上报 home_card_expose；快速滑过不上报 |
| 10 | 推荐卡点击 | 跳转 action_url；POST click 上报；埋点含 card_type |
| 11 | 推荐卡左滑关闭 | 本地立即移除；POST dismiss；下次刷新不重现 |
| 12 | 服务端下发未知 card_type | GenericActionCard 兄底渲染，不白屏不崩溃 |
| 13 | 免费用户收到 membership_promo 卡 | CTA 显示“开通会员”；点击 → 会员中心而非目标内容 |
| 14 | 切换教材版本返回首页 | TopBar 立即更新 → 骨架过渡 → 全量刷新，无旧版本残留 |
| 15 | 快速连续切换孩子账号（家庭多孩） | 最终展示与最后选中孩子一致，无串数据（D-16） |
| 16 | 断网进入首页 | 有缓存：缓存数据 + 提示条；无缓存：全屏错误态，恢复网络重试成功 |
| 17 | 消息轮播 2 条自动轮换 | 5s 切换；点击进入对应路由；仅 1 条时静止 |
| 18 | 系统开启“减弱动态效果” | 所有入场/彩蛋动效关闭，功能不受影响 |
| 19 | 连续打卡 7 天 + 周目标达成（小学段） | 火焰动效 + 周目标徽章彩蛋每周首次出现，二次进入不重复 |
| 20 | 首页停留时长统计 | 前后台切换累计正确，page_home_leave 上报 stay_duration_ms |
