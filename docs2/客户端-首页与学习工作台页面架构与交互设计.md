# 客户端-首页与学习工作台页面架构与交互设计

## 1. 模块概述

### 1.1 功能定位

首页与学习工作台是 PrimeTop APP 的第一入口页面，负责：
- 聚合用户学习状态、今日任务、快捷入口
- 按分龄策略呈现差异化 UI
- 作为全局导航枢纽连接各核心模块
- 支持下拉刷新获取最新数据

### 1.2 优先级

P0 — MVP 核心页面，所有用户首次启动的落地页

### 1.3 前置依赖

| 依赖 | 说明 |
|------|------|
| 客户端架构与前端框架 | 状态管理、路由、主题引擎 |
| 客户端组件库与设计系统 | 通用卡片、按钮、骨架屏、空态组件 |
| 客户端状态管理架构 | 全局状态（用户信息、会员状态） |
| 客户端网络请求治理 | 弱网重试、缓存策略 |
| 客户端应用启动流程与初始化管线 | 启动时预加载首页数据 |
| 客户端页面状态模式 | 骨架屏加载态、空态、错误态 |

### 2.2 页面生命周期

```
App启动
  │
  ▼
初始化管线（AppInitPipeline）
  │
  ├─ 加载用户档案 → UserRepository.getProfile()
  ├─ 预请求首页数据 → HomeRepository.prefetch()
  │   └─ 并行请求：今日任务、错题统计、最近学习、薄弱知识点
  │
  ▼
HomePage.build()
  │
  ├─ 首次渲染：检查缓存 → 有缓存立即渲染 → 无缓存显示骨架屏
  ├─ 网络数据到达 → 合并更新（增量diff，避免闪烁）
  │
  ▼
页面可见（onResume）
  │
  ├─ 检查用户档案变更（切换年级、教材版本）→ 刷新全部卡片
  ├─ 检查会员状态变更（刚完成购买）→ 刷新顶部会员标识
  ├─ 检查学习数据变更（刚完成答题、错题复习）→ 刷新对应卡片
  │
  ▼
页面不可见（onPause）
  │
  └─ 记录页面停留时长 → 埋点上报
```

### 2.3 生命周期管理

```dart
// lib/pages/home/home_page.dart
class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() => _HomePageState();
}

class _HomePageState extends State<HomePage>
    with WidgetsBindingObserver, RouteAware {
  final HomeBloc _bloc = HomeBloc();
  DateTime? _resumedAt;

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addObserver(this);
    _bloc.add(HomeLoadRequested());
  }

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    if (state == AppLifecycleState.resumed) {
      _resumedAt = DateTime.now();
      _bloc.add(HomeRefreshRequested(reason: 'app_resumed'));
    } else if (state == AppLifecycleState.paused && _resumedAt != null) {
      final duration = DateTime.now().difference(_resumedAt!);
      AnalyticsService.logPageDuration('home', duration.inSeconds);
    }
  }

  @override
  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    _bloc.close();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return BlocProvider.value(
      value: _bloc,
      child: Scaffold(
        body: RefreshIndicator(
          onRefresh: () => _bloc.refresh(),
          child: BlocBuilder<HomeBloc, HomeState>(
            builder: (context, state) {
              return switch (state) {
                HomeInitial() || HomeLoading() => const HomeSkeleton(),
                HomeError(:final message) => HomeErrorView(
                    message: message,
                    onRetry: () => _bloc.add(HomeLoadRequested()),
                  ),
                HomeLoaded(:final data) => HomeContentView(data: data),
              };
            },
          ),
        ),
      ),
    );
  }
}
```

### 4.2 增量刷新接口

**接口路径：** `GET /api/v1/home/refresh`

**用途：** 从其他页面返回时，只刷新变更过的区域

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `since` | long | 是 | 上次加载的时间戳（毫秒） |
| `areas` | string | 否 | 指定刷新区域：`tasks,mistakes,summary` 等 |

**响应：** 与聚合接口相同的 data 结构，但只包含 `areas` 指定的字段，未指定的字段为 `null`。

### 5.2 BLoC 实现

```dart
// lib/pages/home/bloc/home_bloc.dart

class HomeBloc extends Bloc<HomeEvent, HomeState> {
  final HomeRepository _repository;
  final UserProfileStore _profileStore;

  HomeBloc({
    required HomeRepository repository,
    required UserProfileStore profileStore,
  })  : _repository = repository,
        _profileStore = profileStore,
        super(const HomeInitial()) {
    on<HomeLoadRequested>(_onLoad);
    on<HomeRefreshRequested>(_onRefresh);
    on<HomePartialRefresh>(_onPartialRefresh);
    on<HomeUserProfileChanged>(_onProfileChanged);
    on<HomeTaskStatusUpdated>(_onTaskStatusUpdated);
  }

  Future<void> _onLoad(
    HomeLoadRequested event,
    Emitter<HomeState> emit,
  ) async {
    emit(const HomeLoading());

    // 尝试先读缓存
    final cached = await _repository.getCachedSummary();
    if (cached != null) {
      emit(HomeLoading(cachedData: cached));
    }

    try {
      final data = await _repository.getSummary();
      emit(HomeLoaded(data: data, loadedAt: DateTime.now()));
      await _repository.cacheSummary(data);
    } catch (e) {
      if (cached != null) {
        emit(HomeError(message: '刷新失败，显示缓存数据', cachedData: cached));
      } else {
        emit(HomeError(message: _mapError(e)));
      }
    }
  }

  Future<void> _onRefresh(
    HomeRefreshRequested event,
    Emitter<HomeState> emit,
  ) async {
    final cached = _currentData;
    if (cached != null) {
      emit(HomeLoaded(data: cached, loadedAt: DateTime.now(), isRefreshing: true));
    }

    try {
      final data = await _repository.getSummary();
      emit(HomeLoaded(data: data, loadedAt: DateTime.now()));
      await _repository.cacheSummary(data);
    } catch (e) {
      // 刷新失败，保持当前数据不变
      if (cached != null) {
        emit(HomeLoaded(data: cached, loadedAt: DateTime.now()));
      }
    }
  }

  Future<void> _onPartialRefresh(
    HomePartialRefresh event,
    Emitter<HomeState> emit,
  ) async {
    final current = _currentData;
    if (current == null) return;

    try {
      final since = DateTime.now().subtract(const Duration(minutes: 5));
      final partial = await _repository.refresh(
        since: since.millisecondsSinceEpoch,
        areas: event.areas,
      );
      // 合并部分数据
      final merged = _mergeData(current, partial);
      emit(HomeLoaded(data: merged, loadedAt: DateTime.now()));
      await _repository.cacheSummary(merged);
    } catch (_) {
      // 静默失败，保持当前数据
    }
  }

  void _onProfileChanged(
    HomeUserProfileChanged event,
    Emitter<HomeState> emit,
  ) {
    final current = _currentData;
    if (current == null) return;
    final updated = HomeData(
      userBrief: event.newProfile,
      quickActions: current.quickActions,
      todayTasks: current.todayTasks,
      continueLearning: current.continueLearning,
      weakPoints: current.weakPoints,
      dailySummary: current.dailySummary,
      messages: current.messages,
      ageConfig: current.ageConfig,
    );
    emit(HomeLoaded(data: updated, loadedAt: DateTime.now()));
    // 触发全量刷新（年级/教材版本变了）
    add(const HomeRefreshRequested(reason: 'profile_changed'));
  }

  void _onTaskStatusUpdated(
    HomeTaskStatusUpdated event,
    Emitter<HomeState> emit,
  ) {
    final current = _currentData;
    if (current == null) return;

    final tasks = current.todayTasks.tasks.map((t) {
      if (t.id == event.taskId) {
        return TodayTask(
          id: t.id, type: t.type, title: t.title, subtitle: t.subtitle,
          estimatedMinutes: t.estimatedMinutes, status: event.newStatus,
          route: t.route,
        );
      }
      return t;
    }).toList();

    final newCompleted = tasks.where((t) => t.status == TaskStatus.completed).length;

    final updated = HomeData(
      userBrief: current.userBrief,
      quickActions: current.quickActions,
      todayTasks: TodayTaskSummary(
        totalTasks: current.todayTasks.totalTasks,
        completedTasks: newCompleted,
        estimatedMinutes: current.todayTasks.estimatedMinutes,
        tasks: tasks,
      ),
      continueLearning: current.continueLearning,
      weakPoints: current.weakPoints,
      dailySummary: current.dailySummary,
      messages: current.messages,
      ageConfig: current.ageConfig,
    );
    emit(HomeLoaded(data: updated, loadedAt: DateTime.now()));
  }

  HomeData? get _currentData {
    final s = state;
    if (s is HomeLoaded) return s.data;
    if (s is HomeError) return s.cachedData;
    if (s is HomeLoading) return s.cachedData;
    return null;
  }

  String _mapError(Object e) {
    if (e is NetworkException) return '网络连接失败，请检查网络后重试';
    if (e is TimeoutException) return '请求超时，请稍后重试';
    return '加载失败，请下拉刷新';
  }

  HomeData _mergeData(HomeData base, Map<String, dynamic> partial) {
    return HomeData(
      userBrief: partial['user_brief'] ?? base.userBrief,
      quickActions: partial['quick_actions'] ?? base.quickActions,
      todayTasks: partial['today_tasks'] ?? base.todayTasks,
      continueLearning: partial['continue_learning'] ?? base.continueLearning,
      weakPoints: partial['weak_points'] ?? base.weakPoints,
      dailySummary: partial['daily_summary'] ?? base.dailySummary,
      messages: partial['messages'] ?? base.messages,
```

```dart
// lib/pages/home/repositories/home_repository.dart

class HomeRepository {
  final ApiClient _api;
  final LocalCache _cache;

  static const _cacheKey = 'home_summary';

  Future<HomeData> getSummary() async {
    final response = await _api.get('/api/v1/home/summary');
    return HomeData.fromJson(response.data);
  }

  Future<Map<String, dynamic>> refresh({
    required int since,
    Set<String>? areas,
  }) async {
    final query = <String, String>{
      'since': since.toString(),
      if (areas != null) 'areas': areas.join(','),
    };
    final response = await _api.get('/api/v1/home/refresh', queryParameters: query);
    return response.data as Map<String, dynamic>;
  }

  Future<HomeData?> getCachedSummary() async {
    final json = await _cache.getJson(_cacheKey);
    if (json == null) return null;
    try {
      return HomeData.fromJson(json);
    } catch (_) {
      return null;
    }
  }

  Future<void> cacheSummary(HomeData data) async {
    await _cache.setJson(_cacheKey, data.toJson(), ttl: const Duration(hours: 2));
  }
}
```
