# 发音陪练服务 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

发音陪练服务是 PrimeTop 启蒙与语文学习模块的核心子服务，面向幼儿、小学低年级及语文朗读场景，提供：

- 标准发音示范（TTS）
- 用户跟读录音采集
- 语音识别（ASR）与拼音/汉字/句子对齐
- 发音准确度、完整度、流利度评分
- 颗粒化反馈（哪个音发错、声调是否正确、漏读/多读）
- 学习记录沉淀与复习推荐

该服务不直接替代教师或家长，而是作为“随时可用的发音伙伴”帮助学生反复听、模仿、纠正。

### 1.2 覆盖场景

| 场景 | 内容类型 | 评分侧重点 |
|------|----------|------------|
| 拼音启蒙 | 声母/韵母/整体认读音节 | 单音素准确度、声调 |
| 汉字认读 | 单字/词语 | 声韵调、整字匹配 |
| 词语跟读 | 2-4 字词语 | 完整度、声调 |
| 句子朗读 | 短句/古诗/课文 | 流利度、停顿、完整度 |
| 英语启蒙 | 字母/单词/短句 | 音素、重音、完整度（复用同一套框架） |

### 1.3 优先级

P1 — 启蒙与小学低年级的核心体验能力，V1.0 阶段实现。

### 1.4 依赖关系

```
语音服务（ASR/TTS） → 提供底层音频识别与合成能力
拼音识字启蒙服务   → 获取练习内容、学习路径
用户账号体系       → 用户身份、学段年级
文件存储服务       → 音频文件上传与持久化
学习记录服务       → 练习结果写入学习画像
```

## 5. 核心业务逻辑

### 5.1 评分计算流程

```python
def evaluate_pronunciation(practice: PronunciationPractice, content: PronunciationContent):
    """
    1. 调用 ASR 获取识别文本与拼音
    2. 将目标文本与识别文本对齐
    3. 计算完整度、准确度、流利度、声调
    4. 生成颗粒化反馈
    5. 给出综合得分与建议动作
    """
    # 1. ASR 识别（若识别失败，返回 FAILED 状态）
    asr_result = asr_client.recognize(practice.user_audio_url, language=content.subject)
    if not asr_result.success:
        raise ASRException(asr_result.error)

    practice.asr_text = asr_result.text
    practice.asr_pinyin = asr_result.pinyin
    practice.asr_confidence = asr_result.confidence

    # 2. 文本对齐（拼音级）
    expected_phonemes = content.phonemes
    actual_phonemes = pinyin_to_phonemes(asr_result.pinyin)
    alignment = phoneme_align(expected_phonemes, actual_phonemes)

    # 3. 完整度：识别出的音素占目标音素比例
    completeness = len([a for a in alignment if a.actual is not None]) / len(expected_phonemes)

    # 4. 准确度：正确音素比例（忽略插入/删除）
    accuracy = len([a for a in alignment if a.correct]) / len(expected_phonemes)

    # 5. 声调：韵母声调匹配（仅中文）
    tone_accuracy = compare_tones(content.phoneme_tones, asr_result.tones) if content.subject == 'chinese' else 1.0

    # 6. 流利度：基于语速、停顿、过短/过长
    fluency = compute_fluency(
        practice.audio_duration_ms,
        content.expected_duration_ms,
        asr_result.silence_ratio,
        asr_result.words_per_minute
    )

    # 7. 综合得分（加权）
    overall = weighted_score(
        accuracy=accuracy * 100,
        completeness=completeness * 100,
        fluency=fluency * 100,
        tone=tone_accuracy * 100,
        weights={
            'accuracy': 0.45,
            'completeness': 0.25,
            'fluency': 0.15,
            'tone': 0.15
        }
    )

    practice.overall_score = overall
    practice.accuracy_score = accuracy * 100
    practice.completeness_score = completeness * 100
    practice.fluency_score = fluency * 100
    practice.tone_score = tone_accuracy * 100
    practice.phoneme_feedback = build_phoneme_feedback(alignment)
    practice.is_passed = overall >= passing_standard.overall_score_threshold
    practice.suggested_action = decide_next_action(practice)
```

### 5.2 音素对齐算法

```python
def phoneme_align(expected: list[str], actual: list[str]) -> list[PhonemeAlignment]:
    """
    使用编辑距离对齐目标音素序列与实际音素序列。
    返回每个目标音素对应的实际音素及是否正确。
    """
    m, n = len(expected), len(actual)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            cost = 0 if expected[i-1] == actual[j-1] else 1
            dp[i][j] = min(
                dp[i-1][j] + 1,      # 删除
                dp[i][j-1] + 1,      # 插入
                dp[i-1][j-1] + cost  # 替换/匹配
            )

    # 回溯得到对齐路径
    alignment = []
    i, j = m, n
    while i > 0 or j > 0:
        if i > 0 and j > 0 and expected[i-1] == actual[j-1]:
            alignment.append(PhonemeAlignment(expected[i-1], actual[j-1], True))
            i -= 1; j -= 1
        elif i > 0 and j > 0 and dp[i][j] == dp[i-1][j-1] + 1:
            alignment.append(PhonemeAlignment(expected[i-1], actual[j-1], False))
            i -= 1; j -= 1
        elif i > 0 and dp[i][j] == dp[i-1][j] + 1:
            alignment.append(PhonemeAlignment(expected[i-1], None, False))
            i -= 1
        else:
            alignment.append(PhonemeAlignment(None, actual[j-1], False))
            j -= 1

    return list(reversed(alignment))
```

### 5.3 声调比对（中文）

```python
def compare_tones(expected_tones: list[int], actual_tones: list[int]) -> float:
    """
    比较目标声调与实际声调序列。
    轻声与一声在某些教材中可视为等价，需配置容错策略。
    """
    if not expected_tones or not actual_tones:
        return 0.0

    matched = 0
    for et, at in zip(expected_tones, actual_tones):
        if et == at:
            matched += 1
        elif et == 0 and at == 1:
            # 轻声可等价于一声
            matched += 1

    return matched / max(len(expected_tones), len(actual_tones))
```

### 5.4 建议动作决策

```python
def decide_next_action(practice: PronunciationPractice) -> str:
    if practice.status == 'FAILED':
        return 'retry'
    if not practice.is_passed:
        if practice.tone_score < 60 and practice.accuracy_score >= 70:
            return 'practice_tone'
        return 'retry'
    if practice.fluency_score < 70:
        return 'listen_again'
    return 'next'
```

## 6. 关键代码示例

### 6.1 ASR 服务适配层

```python
class ASRClient:
    def __init__(self, providers: dict):
        self.providers = providers  # {'primary': A, 'fallback': B}

    def recognize(self, audio_url: str, language: str, timeout: int = 5) -> ASRResult:
        audio_bytes = object_storage.download(audio_url)
        for name, provider in self.providers.items():
            try:
                result = provider.recognize(audio_bytes, language=language, timeout=timeout)
                if result.confidence < 0.3:
                    continue  # 置信度过低，尝试下一个
                return result
            except Exception as e:
                logger.warning(f"ASR provider {name} failed: {e}")
                continue
        raise ASRException("All ASR providers failed")
```

### 6.2 异步评分任务（Celery/Job 模式）

```python
@task(bind=True, max_retries=3, default_retry_delay=5)
def process_pronunciation_evaluation(self, practice_id: int):
    try:
        practice = PronunciationPractice.objects.get(id=practice_id)
        content = PronunciationContent.objects.get(id=practice.content_id)

        practice.status = 'ASR_PROCESSING'
        practice.save()

        evaluate_pronunciation(practice, content)

        practice.status = 'COMPLETED'
        practice.save()

        # 同步写入学习记录
        LearningRecordService.log_pronunciation(practice)

    except ASRException as e:
        practice.status = 'FAILED'
        practice.suggested_action = 'retry'
        practice.save()
        # 仅重试 3 次
        raise self.retry(exc=e, countdown=5)
    except Exception as e:
        logger.error(f"Evaluation failed for practice {practice_id}: {e}")
        practice.status = 'FAILED'
        practice.save()
```

class PronunciationController:

        user_id = request.jwt.user_id
        content_id = request.body.content_id
        practice = PronunciationService.create_practice(user_id, content_id)
        return Response(201, practice.to_dto())

    def upload_audio(self, request, practice_id):
        user_id = request.jwt.user_id
        practice = PronunciationService.get_practice(practice_id)
        if practice.user_id != user_id:
            raise ForbiddenError("MISTAKE_FORBIDDEN")

        audio = request.files['audio']
        duration_ms = request.form['durationMs']

        practice = PronunciationService.submit_audio(practice, audio, duration_ms)
        process_pronunciation_evaluation.delay(practice.id)
        return Response(202, {'status': practice.status, 'estimatedProcessingMs': 1500})

    def get_result(self, request, practice_id):
        user_id = request.jwt.user_id
        practice = PronunciationService.get_practice(practice_id)
        if practice.user_id != user_id:
            raise ForbiddenError("MISTAKE_FORBIDDEN")
        return Response(200, practice.to_result_dto())

## 7. 错误处理

### 7.1 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 客户端处理建议 |
|--------|------------|------|----------------|
| `PRONUNCIATION_CONTENT_NOT_FOUND` | 404 | 练习内容不存在 | 返回内容列表页 |
| `PRACTICE_NOT_FOUND` | 404 | 练习记录不存在 | 重新创建练习 |
| `PRACTICE_FORBIDDEN` | 403 | 无权访问该练习 | 提示用户并返回 |
| `INVALID_AUDIO_FORMAT` | 400 | 音频格式不支持 | 提示使用 mp3/m4a/wav |
| `AUDIO_TOO_LONG` | 400 | 音频超过最大时长（60秒） | 提示缩短录音 |
| `AUDIO_TOO_SHORT` | 400 | 音频过短（< 300ms） | 提示重新录音 |
| `ASR_PROCESSING_TIMEOUT` | 504 | ASR 识别超时 | 自动重试，或引导手动回退 |
| `ASR_LOW_CONFIDENCE` | 200 | 识别置信度过低，评分不可靠 | 提示用户重新朗读 |
| `ASR_UNAVAILABLE` | 503 | ASR 服务全部不可用 | 降级为“自评模式” |
| `EVALUATION_FAILED` | 500 | 评分算法异常 | 记录日志，引导重试 |
| `RATE_LIMITED` | 429 | 单用户请求频率过高 | 提示稍后重试 |

### 7.2 降级策略

| 异常场景 | 降级方案 |
|----------|----------|
| ASR 全部不可用 | 切换到“听音模仿”模式：播放标准音，用户自行判断，不强制评分。 |
| ASR 置信度低（< 0.4） | 返回 `ASR_LOW_CONFIDENCE`，不给出具体分数，仅提示“请再读一次”。 |
| 评分服务异常 | 仅返回 ASR 文本，标记状态为 FAILED，允许用户重试。 |
| 网络中断 | 客户端支持本地缓存音频，恢复后自动上传。 |
| 内容缺失 | 返回默认 TTS 音频，并记录内容缺漏日志。 |

### 7.3 重试策略

- ASR 任务最多重试 3 次，每次间隔 5 秒。
- 上传 Token 过期后，客户端需重新创建练习会话。
- 客户端轮询结果时，建议间隔 500ms，最多 30 次（15 秒）。

## 8. 性能与资源优化

### 8.1 缓存策略

| 缓存对象 | Key | TTL | 说明 |
|----------|-----|-----|------|
| 标准音频文件 | CDN 静态资源 | 长期 | 客户端预加载常用发音 |
| 练习内容元数据 | `pronunciation:content:{content_id}` | 24h | 减少内容库查询 |
| 用户最近练习 | `pronunciation:history:{user_id}` | 1h | 历史列表缓存 |
| ASR 结果 | `pronunciation:asr:{audio_hash}` | 24h | 相同音频避免重复识别 |
| 通过标准配置 | `pronunciation:standard:{subject}:{type}:{difficulty}` | 12h | 配置缓存 |

### 8.2 异步处理

- 音频上传后立即返回 `ASR_PROCESSING` 状态，由后台任务完成评分。
- 避免同步调用大模型/ASR 阻塞主接口。
- 评分完成后通过 WebSocket 或推送通知客户端刷新。

### 8.3 资源限制

- 音频文件最大 5MB，采样率建议 16kHz/16bit。
- 单用户每分钟最多创建 10 次练习（限流）。
- 单音频 ASR 超时 10 秒。

## 9. 安全与隐私

### 9.1 权限控制

- 所有练习记录必须绑定 `user_id`，接口严格校验 JWT 用户身份。
- 不允许 A 用户查询 B 用户的练习记录或音频文件。
- 音频文件 URL 建议使用带签名或短期有效的私有 URL，防止直接遍历。

### 9.2 数据隐私

- 儿童语音数据属于敏感个人信息，须明确告知用户并获取监护人同意。
- 音频文件保存期限默认 90 天，过期后转冷存储或删除（依据合规要求）。
- ASR 服务应选择通过未成年人数据合规认证的供应商。

### 9.3 内容安全

- 对 ASR 识别出的用户文本进行内容安全审核，过滤脏话、敏感信息。
- 如发现违规内容，记录审计日志，不进入反馈展示。

## 10. 客户端交互设计要点

1. **录音引导页**：展示目标文本、拼音、标准音频播放按钮，倒计时 3 秒后开始录音。
2. **录音中界面**：实时音量波形，最长录音倒计时，手动停止按钮。
3. **评分结果页**：
   - 展示总分与四维度得分（雷达图）。
   - 高亮错误音素/字词（红色）。
   - 提供“再听一遍”“跟读一次”“下一题”快捷按钮。
4. **低置信度/失败处理**：提示“没听清，请再读一次”，不打击低龄用户。
5. **家长端可见**：展示今日发音练习次数、平均得分、薄弱音素。

## 11. 测试策略

### 11.1 单元测试

- 音素对齐算法正确性（包含插入、删除、替换场景）。
- 声调比对容错策略（轻声与一声等价）。
- 综合评分加权计算。
- 建议动作决策逻辑。

### 11.2 集成测试

- 音频上传 → ASR 调用 → 评分 → 结果返回完整链路。
- ASR 失败后的降级与重试。
- 权限越界访问拦截。

### 11.3 性能测试

- 模拟 1000 并发上传，验证对象存储与 ASR 队列不阻塞。
- 轮询结果接口 QPS 与延迟。

### 11.4 体验测试

- 不同年龄段儿童录音成功率。
- 环境噪音对 ASR 影响。
- 发音接近但错误时的反馈是否易懂。
