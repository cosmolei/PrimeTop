> 版本：v1.0  
> 最后更新：2026-06-03  
> 模块负责人：后端架构组  

---

## 1. 模块定位与职责

### 1.1 业务背景

完形填空（Cloze Test）与短文改错（Error Correction）是中国初中、高中英语考试中的高频必考题型，在中考约占 10-15 分，高考约占 15-20 分。这两种题型综合性强，要求学生同时具备词汇辨析、语法运用、语篇理解和逻辑推理能力。

目前 `docs2/英语语法专项训练系统-详细设计.md` 覆盖了语法知识点的专项训练，`docs2/英语阅读理解专项训练系统-详细设计.md` 覆盖了阅读理解，但完形填空和短文改错作为"语法+词汇+语篇理解"的交叉题型，其 AI 分析逻辑、评分策略、错误诊断和训练编排有独特的复杂度，需要独立服务支撑。

### 1.2 服务职责

| 职责 | 说明 |
| --- | --- |
| 完形填空出题 | 根据难度、话题、语法考点生成完形填空题目 |
| 完形填空批改 | 对学生答案进行逐空分析，给出正误判定与解析 |
| 短文改错批改 | 识别学生标注的改错位置，评判改错正确性 |
| 错因诊断 | 分析错误背后的词汇/语法/逻辑/语篇理解缺陷 |
| 自适应训练编排 | 根据学生弱项动态推荐练习篇目与难度 |
| 训练数据沉淀 | 向学习画像和知识点掌握度引擎输出训练结果 |

### 1.3 服务边界

- **本服务负责**：完形填空与短文改错的出题、批改、解析、错因诊断和训练编排
- **不负责**：阅读理解出题批改（由阅读理解服务处理）、语法知识点讲解（由语法训练服务处理）、口语朗读评估（由口语服务处理）
- **依赖**：题目服务（题库存储）、知识点服务（考点映射）、学习画像服务（学生能力数据）、AI 对话引擎（大模型调用）、用户额度服务（调用次数管控）

## 3. 数据模型设计

### 3.1 完形填空题目 (cloze_passage)

```sql
CREATE TABLE cloze_passage (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    passage_id      VARCHAR(64) NOT NULL COMMENT '篇目唯一标识',
    title           VARCHAR(255) COMMENT '文章标题',
    source          VARCHAR(64) COMMENT '来源: exam/manual/ai_generated',
    source_exam     VARCHAR(128) COMMENT '来源考试: 2024高考全国I卷',
    
    -- 原文与挖空信息
    original_text   TEXT NOT NULL COMMENT '完整原文(无挖空)',
    blanked_text    TEXT NOT NULL COMMENT '挖空后文本, 用 {{BLANK:n}} 标记空位',
    
    -- 分类与难度
    grade_range     VARCHAR(32) NOT NULL COMMENT '适用学段: junior_high/senior_high',
    difficulty      TINYINT NOT NULL COMMENT '难度 1-5',
    topic_category  VARCHAR(64) COMMENT '话题分类: daily_life/science/society/culture/...',
    word_count      INT COMMENT '文章词数',
    
    -- 质量与状态
    quality_score   DECIMAL(3,2) COMMENT '质量评分 0-1',
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '0=draft, 1=reviewing, 2=published, 3=deprecated',
    review_notes    TEXT COMMENT '审核备注',
    
    -- 元数据
    created_by      VARCHAR(64) COMMENT '创建人',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_grade_difficulty (grade_range, difficulty),
    INDEX idx_topic (topic_category),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.2 完形填空空位 (cloze_blank)

```sql
CREATE TABLE cloze_blank (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    passage_id      VARCHAR(64) NOT NULL COMMENT '关联篇目',
    blank_index     TINYINT NOT NULL COMMENT '空位序号(从1开始)',
    
    -- 正确答案
    correct_answer  VARCHAR(128) NOT NULL COMMENT '正确答案',
    answer_aliases  JSON COMMENT '可接受的其他答案: ["recognize","recognise"]',
    
    -- 考点信息
    blank_type      VARCHAR(32) NOT NULL COMMENT '空位类型: vocabulary/grammar/context_logic/collocation/phrase',
    knowledge_points JSON COMMENT '关联知识点ID列表: [1001, 1002]',
    distractor_type VARCHAR(32) COMMENT '干扰项策略: synonym_confusion/grammar_trap/context_misleading',
    
    -- 选项 (有选项完形)
    options         JSON COMMENT '选项列表: [{"label":"A","text":"answer"},{"label":"B","text":"answer"},...]',
    
    -- 解析
    explanation     TEXT COMMENT '解析文本',
    explanation_steps JSON COMMENT '分步解析',
    
    -- 难度
    blank_difficulty TINYINT COMMENT '单空难度 1-5 (可不同于篇目整体难度)',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE INDEX idx_passage_blank (passage_id, blank_index),
    INDEX idx_type (blank_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.4 短文改错错误点 (error_correction_point)

```sql
CREATE TABLE error_correction_point (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    passage_id      VARCHAR(64) NOT NULL,
    error_index     TINYINT NOT NULL COMMENT '错误序号(从1开始)',
    
    -- 定位
    line_number     TINYINT NOT NULL COMMENT '所在行号',
    char_position   SMALLINT COMMENT '行内字符位置(0-based)',
    error_phrase    VARCHAR(255) NOT NULL COMMENT '错误短语',
    
    -- 正确答案
    correct_phrase  VARCHAR(255) NOT NULL COMMENT '正确短语',
    correction_type VARCHAR(32) NOT NULL COMMENT '改错类型: 
                        spelling/grammar_tense/grammar_agreement/
                        article/preposition/conjunction/pronoun/
                        word_order/redundancy/missing_word/
                        singular_plural/comparative/other',
    
    -- 考点
    knowledge_points JSON COMMENT '关联知识点ID',
    explanation     TEXT COMMENT '解析',
    
    -- 难度
    point_difficulty TINYINT,
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE INDEX idx_passage_error (passage_id, error_index),
    INDEX idx_type (correction_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.5 答题记录 (cloze_error_answer_record)

```sql
CREATE TABLE cloze_error_answer_record (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    record_id           VARCHAR(64) NOT NULL COMMENT '答题记录唯一ID',
    user_id             BIGINT NOT NULL,
    
    -- 题目信息
    question_type       VARCHAR(16) NOT NULL COMMENT 'cloze / error_correction',
    passage_id          VARCHAR(64) NOT NULL,
    
    -- 答题内容
    answers             JSON NOT NULL COMMENT '学生答案详情',
    -- 完形填空: [{"blank_index":1,"answer":"A","time_ms":15000},...]
    -- 短文改错: [{"error_index":1,"line":3,"original":"go","correction":"went","type":"grammar_tense"},...]
    
    -- 评分
    total_score         TINYINT COMMENT '总分(满分)',
    earned_score        TINYINT COMMENT '得分',
    score_details       JSON COMMENT '逐空/逐错评分详情',
    
    -- 错因分析
    error_analysis      JSON COMMENT '错因分析结果',
    
    -- 元数据
    time_spent_ms       INT COMMENT '总耗时(毫秒)',
    attempt_number      TINYINT DEFAULT 1 COMMENT '第几次作答',
    is_practice         TINYINT DEFAULT 1 COMMENT '0=考试模式, 1=练习模式',
    
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_user_type (user_id, question_type),
    INDEX idx_user_created (user_id, created_at),
    INDEX idx_passage (passage_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 6. 批改引擎核心逻辑

### 6.1 完形填空逐空批改

```java
@Service
public class ClozeGradingService {

    /**
     * 批改完形填空答案
     */
    public ClozeGradingResult grade(ClozeSubmission submission, ClozePassage passage) {
        List<BlankResult> results = new ArrayList<>();
        int correctCount = 0;
        
        for (BlankAnswer answer : submission.getAnswers()) {
            ClozeBlank blank = passage.getBlank(answer.getBlankIndex());
            BlankResult result = gradeSingleBlank(answer, blank);
            results.add(result);
            if (result.isCorrect()) {
                correctCount++;
            }
        }
        
        // 计算分数
        int totalBlanks = passage.getTotalBlanks();
        BigDecimal accuracy = BigDecimal.valueOf(correctCount)
            .divide(BigDecimal.valueOf(totalBlanks), 4, RoundingMode.HALF_UP);
        
        // 构建结果
        return ClozeGradingResult.builder()
            .totalScore(totalBlanks)
            .earnedScore(correctCount)
            .accuracy(accuracy)
            .details(results)
            .overallAnalysis(buildOverallAnalysis(results))
            .build();
    }
    
    /**
     * 单空批改 - 支持模糊匹配
     */
    private BlankResult gradeSingleBlank(BlankAnswer answer, ClozeBlank blank) {
        String studentAnswer = normalizeAnswer(answer.getAnswer());
        String correctAnswer = normalizeAnswer(blank.getCorrectAnswer());
        
        // 1. 精确匹配
        if (studentAnswer.equalsIgnoreCase(correctAnswer)) {
            return buildCorrectResult(blank, studentAnswer);
        }
        
        // 2. 别名匹配 (如 recognize/recognise)
        if (blank.getAnswerAliases() != null) {
            for (String alias : blank.getAnswerAliases()) {
                if (studentAnswer.equalsIgnoreCase(normalizeAnswer(alias))) {
                    return buildCorrectResult(blank, studentAnswer);
                }
            }
        }
        
        // 3. 选项标签匹配 (学生可能输入A/B/C/D或完整文本)
        if (blank.getOptions() != null) {
            for (Option opt : blank.getOptions()) {
                if (studentAnswer.equalsIgnoreCase(opt.getLabel()) 
                    || studentAnswer.equalsIgnoreCase(normalizeAnswer(opt.getText()))) {
                    boolean correct = opt.getText().equalsIgnoreCase(correctAnswer);
                    return correct 
                        ? buildCorrectResult(blank, studentAnswer)
                        : buildWrongResult(blank, studentAnswer, opt.getText());
                }
            }
        }
        
        // 4. 标记为错误
        return buildWrongResult(blank, studentAnswer, studentAnswer);
    }
    
    /**
     * 答案标准化
     */
    private String normalizeAnswer(String answer) {
        if (answer == null) return "";
        return answer.trim()
            .replaceAll("\\s+", " ")    // 多空格合并
            .toLowerCase();
    }
}
```

### 6.2 短文改错批改

```java
@Service
public class ErrorCorrectionGradingService {

    /**
     * 批改短文改错答案
     * 
     * 评分规则:
     * - 正确找出并改正: +1分
     * - 找出但改错: 0分
     * - 未找出: 0分
     * - 把对的改错(误改): 按考试规则，通常扣分或不扣分
     */
    public ErrorCorrectionGradingResult grade(
            ErrorCorrectionSubmission submission, 
            ErrorCorrectionPassage passage) {
        
        List<CorrectionDetail> details = new ArrayList<>();
        List<ErrorCorrectionPoint> standards = passage.getErrors();
        
        // 按行号+位置建立标准答案索引
        Map<String, ErrorCorrectionPoint> standardMap = standards.stream()
            .collect(Collectors.toMap(
                p -> buildLocationKey(p.getLineNumber(), p.getCharPosition()),
                p -> p
            ));
        
        // 按行号+位置建立学生答案索引
        Map<String, StudentCorrection> studentMap = submission.getCorrections().stream()
            .collect(Collectors.toMap(
                c -> buildLocationKey(c.getLineNumber(), c.getCharPosition()),
                c -> c
            ));
        
        int correctCount = 0;
        int missedCount = 0;
        int wrongCorrectionCount = 0;
        int falsePositiveCount = 0;
        
        // 1. 评判标准错误点: 学生是否找出并改正
        for (ErrorCorrectionPoint standard : standards) {
            String key = buildLocationKey(standard.getLineNumber(), standard.getCharPosition());
            StudentCorrection student = studentMap.get(key);
            
            if (student == null) {
                // 学生漏改
                missedCount++;
                details.add(buildMissedDetail(standard));
            } else {
                // 学生标出了此位置，判断改错是否正确
                boolean correctionCorrect = isCorrectionCorrect(student, standard);
                if (correctionCorrect) {
                    correctCount++;
                    details.add(buildCorrectDetail(standard, student));
                } else {
                    wrongCorrectionCount++;
                    details.add(buildWrongDetail(standard, student));
                }
            }
        }
        
        // 2. 检查学生多改的位置(误改)
        for (StudentCorrection student : submission.getCorrections()) {
            String key = buildLocationKey(student.getLineNumber(), student.getCharPosition());
            if (!standardMap.containsKey(key)) {
                falsePositiveCount++;
                details.add(buildFalsePositiveDetail(student, passage));
            }
        }
        
        // 3. 计算得分
        int totalScore = standards.size();
        int earnedScore = correctCount;
        
        // 4. 生成错因分析
        Map<String, TypeStats> typeDistribution = buildTypeDistribution(details);
        
        return ErrorCorrectionGradingResult.builder()
            .totalScore(totalScore)
            .earnedScore(earnedScore)
            .foundErrors(correctCount + wrongCorrectionCount)
            .correctCorrections(correctCount)
            .missedErrors(missedCount)
            .falsePositives(falsePositiveCount)
            .details(details)
            .typeDistribution(typeDistribution)
            .build();
    }
    
    /**
     * 判断学生改错是否正确 (支持模糊匹配)
     */
    private boolean isCorrectionCorrect(StudentCorrection student, ErrorCorrectionPoint standard) {
        String studentCorrection = normalizePhrase(student.getCorrectedPhrase());
        String standardCorrection = normalizePhrase(standard.getCorrectPhrase());
        
        // 精确匹配
        if (studentCorrection.equalsIgnoreCase(standardCorrection)) {
            return true;
        }
        
        // 去除多余空格和标点后比较
        String cleaned = studentCorrection.replaceAll("[\\s,.!?;:'\"]", "");
        String standardCleaned = standardCorrection.replaceAll("[\\s,.!?;:'\"]", "");
        if (cleaned.equalsIgnoreCase(standardCleaned)) {
            return true;
        }
        
        // AI辅助判断 (处理同义改写等复杂情况)
        if (requiresAiJudgment(studentCorrection, standardCorrection)) {
            return aiJudgeCorrection(student, standard);
        }
        
        return false;
    }
}
```

```java
@Service
public class ErrorDiagnosisEngine {

    /**
     * 诊断单空错误原因
     */
    public ErrorDiagnosis diagnoseBlankError(
            BlankAnswer answer, 
            ClozeBlank blank,
            StudentProfile profile) {
        
        ErrorDiagnosis diagnosis = new ErrorDiagnosis();
        diagnosis.setBlankIndex(blank.getBlankIndex());
        
        String studentAnswer = answer.getAnswer();
        String correctAnswer = blank.getCorrectAnswer();
        
        // 1. 确定错误大类
        ErrorCategory category = classifyError(studentAnswer, correctAnswer, blank);
        diagnosis.setCategory(category);
        
        // 2. 详细分析
        switch (category) {
            case VOCAB_CONFUSION:
                diagnosis.setDescription(buildVocabConfusionAnalysis(studentAnswer, correctAnswer));
                diagnosis.setRelatedWords(findRelatedConfusingWords(correctAnswer, profile.getGrade()));
                break;
                
            case GRAMMAR_MISMATCH:
                diagnosis.setDescription(buildGrammarAnalysis(blank, studentAnswer, correctAnswer));
                diagnosis.setGrammarRules(findApplicableRules(blank.getBlankType()));
                break;
                
            case CONTEXT_MISREAD:
                diagnosis.setDescription(buildContextAnalysis(blank, answer.getTimeMs()));
                diagnosis.setContextClues(extractContextClues(blank));
                break;
                
            case LOGIC_ERROR:
                diagnosis.setDescription(buildLogicAnalysis(blank));
                break;
                
            case CARELESS:
                diagnosis.setDescription(buildCarelessAnalysis(studentAnswer, correctAnswer));
                break;
                
            default:
                diagnosis.setDescription("知识点盲区，建议复习相关内容");
        }
        
        // 3. 映射知识点
        List<Long> kpIds = resolveKnowledgePoints(blank, category);
        diagnosis.setKnowledgePointIds(kpIds);
        
        // 4. 生成改进建议
        diagnosis.setSuggestions(generateSuggestions(category, blank, profile));
        
        return diagnosis;
    }
    
    /**
     * 错误分类
     */
    private ErrorCategory classifyError(String studentAnswer, String correctAnswer, ClozeBlank blank) {
        // 规则优先级判定
        
        // 1. 拼写接近 → 可能是粗心
        if (isSpellingClose(studentAnswer, correctAnswer)) {
            return ErrorCategory.CARELESS;
        }
        
        // 2. 同根词/同义词 → 词汇混淆
        if (isRelatedWord(studentAnswer, correctAnswer)) {
            return ErrorCategory.VOCAB_CONFUSION;
        }
        
        // 3. 语法变形 (时态/语态/单复数/比较级)
        if (isGrammarVariant(studentAnswer, correctAnswer, blank)) {
            return ErrorCategory.GRAMMAR_MISMATCH;
        }
        
        // 4. 根据空位类型推断
        switch (blank.getBlankType()) {
            case CONTEXT_LOGIC:
                return ErrorCategory.LOGIC_ERROR;
            case COLLOCATION:
                return ErrorCategory.KNOWLEDGE_GAP;
            default:
                return ErrorCategory.VOCAB_CONFUSION;
        }
    }
    
    private boolean isSpellingClose(String a, String b) {
        // Levenshtein距离 <= 2 且长度差 <= 1
        int distance = levenshteinDistance(a.toLowerCase(), b.toLowerCase());
        return distance <= 2 && Math.abs(a.length() - b.length()) <= 1;
    }
    
    private boolean isGrammarVariant(String student, String correct, ClozeBlank blank) {
        // 检查是否是同一词的语法变形
        // 如: go/went/going/gone, big/bigger/biggest
        String studentLemma = getLemma(student);
        String correctLemma = getLemma(correct);
        return studentLemma.equals(correctLemma);
    }
}
```

```java
@Service
public class ClozeGenerationValidator {

    /**
     * 验证AI生成的完形填空题目质量
     */
    public ValidationResult validate(ClozeGenerationResult generated) {
        ValidationResult result = new ValidationResult();
        
        // 1. 格式完整性检查
        if (generated.getBlanks() == null || generated.getBlanks().isEmpty()) {
            result.addError("blanks_empty", "空位列表为空");
            return result;
        }
        
        // 2. 原文与挖空一致性
        String original = generated.getOriginalText();
        String blanked = rebuildBlankedText(generated);
        // 验证挖空后还原与原文一致
        String restored = blanked.replaceAll("\\{\\{BLANK:\\d+\\}\\}", "");
        if (!normalizeText(original).equals(normalizeText(restored))) {
            result.addError("text_mismatch", "原文与挖空文本不一致");
        }
        
        // 3. 选项质量检查
        for (BlankGeneration blank : generated.getBlanks()) {
            // 3a. 选项数量必须为4
            if (blank.getOptions().size() != 4) {
                result.addError("option_count", "空位" + blank.getBlankIndex() + "选项数不为4");
            }
            // 3b. 正确答案必须在选项中
            boolean correctInOptions = blank.getOptions().stream()
                .anyMatch(o -> o.getText().equalsIgnoreCase(blank.getCorrectAnswer()));
            if (!correctInOptions) {
                result.addError("answer_missing", "空位" + blank.getBlankIndex() + "正确答案不在选项中");
            }
            // 3c. 选项不能重复
            long distinctCount = blank.getOptions().stream()
                .map(o -> o.getText().toLowerCase()).distinct().count();
            if (distinctCount < blank.getOptions().size()) {
                result.addError("duplicate_options", "空位" + blank.getBlankIndex() + "选项重复");
            }
            // 3d. 选项语法形式应一致
            if (!isGrammaticallyConsistent(blank.getOptions(), blank.getBlankType())) {
                result.addWarning("inconsistent_forms", "空位" + blank.getBlankIndex() + "选项语法形式不一致");
            }
        }
        
        // 4. 难度合理性
        int expectedBlanks = estimateBlankCount(generated.getWordCount(), generated.getDifficulty());
        if (Math.abs(generated.getBlanks().size() - expectedBlanks) > 3) {
            result.addWarning("blank_count", "空位数与预期偏差较大");
        }
        
        // 5. 首句不挖空检查
        if (isFirstSentenceBlanked(generated)) {
            result.addError("first_sentence_blank", "首句不应挖空");
        }
        
        // 6. 连续挖空检查
        if (hasConsecutiveBlanks(generated, 2)) {
            result.addWarning("consecutive_blanks", "存在连续挖空");
        }
        
        return result;
    }
    
    /**
     * 估算合理的空位数
     */
    private int estimateBlankCount(int wordCount, int difficulty) {
        // 经验公式: 空位数 ≈ 词数 / (25 - difficulty * 2)
        int denominator = Math.max(10, 25 - difficulty * 2);
        return Math.max(8, Math.min(20, wordCount / denominator));
    }
}
```

```java
@Component
public class DifficultyAdjuster {

    // 难度阶梯配置
    private static final Map<Integer, DifficultyConfig> CONFIGS = Map.of(
        1, new DifficultyConfig(1, 80, 120, 8, 10),    // 初中基础
        2, new DifficultyConfig(2, 120, 180, 10, 12),   // 初中提高

        5, new DifficultyConfig(5, 300, 350, 18, 20)    // 高中冲刺
    );

    /**
     * 根据近期表现计算推荐难度
     */
    public int calculateRecommendedDifficulty(
            Long userId, 
            String questionType,
            int currentDifficulty) {
        
        // 获取最近5次训练记录
        List<AnswerRecord> recentRecords = answerRecordRepository
            .findRecentByUserAndType(userId, questionType, 5);
        
        if (recentRecords.size() < 3) {
            return currentDifficulty; // 数据不足，保持当前
        }
        
        // 计算近期平均正确率
        double avgAccuracy = recentRecords.stream()
            .mapToDouble(AnswerRecord::getAccuracy)
            .average()
            .orElse(0.5);
        
        // 计算正确率趋势 (最近3次 vs 之前)
        double recentTrend = calculateTrend(recentRecords);
        
        int recommended = currentDifficulty;
        
        // 升级条件: 正确率持续高于阈值
        if (avgAccuracy >= 0.85 && recentTrend >= 0 && currentDifficulty < 5) {
            recommended = currentDifficulty + 1;
        }
        // 降级条件: 正确率持续低于阈值
        else if (avgAccuracy <= 0.45 && recentTrend <= 0 && currentDifficulty > 1) {
            recommended = currentDifficulty - 1;
        }
        // 快速降级: 连续3次低于30%
        else if (recentRecords.stream()
                .skip(Math.max(0, recentRecords.size() - 3))
                .allMatch(r -> r.getAccuracy() < 0.30)) {
            recommended = Math.max(1, currentDifficulty - 1);
        }
        
        return recommended;
    }
}
```

```java
@Component
public class TrainingIntervalScheduler {

    /**
     * 计算下一次训练间隔（小时）
     * 
     * 基于简化SM-2算法:
     * - 首次训练后: 24小时
     * - 正确率 > 80%: 间隔 × 1.5
     * - 正确率 60-80%: 间隔 × 1.0
     * - 正确率 < 60%: 间隔 × 0.5 (加急复习)
     */
    public int calculateNextIntervalHours(Long userId, String focusArea) {
        TrainingHistory history = trainingHistoryRepository
            .findLatestByUserAndFocusArea(userId, focusArea);
        
        if (history == null) {
            return 24; // 首次训练，24小时后
        }
        
        int currentInterval = history.getIntervalHours();
        double accuracy = history.getLatestAccuracy();
        
        double multiplier;
        if (accuracy >= 0.80) {
            multiplier = 1.5;
        } else if (accuracy >= 0.60) {
            multiplier = 1.0;
        } else {
            multiplier = 0.5;
        }
        
        int nextInterval = (int) (currentInterval * multiplier);
        
        // 边界约束: 最短12小时，最长7天
        return Math.max(12, Math.min(168, nextInterval));
    }
}
```

```java
    public ClozePassage generateWithFallback(ClozeGenerationRequest request) {

        ClozePassage fallback = questionBank.findSimilar(request);
```
