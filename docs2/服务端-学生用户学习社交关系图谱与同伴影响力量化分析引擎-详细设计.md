# 服务端-学生用户学习社交关系图谱与同伴影响力量化分析引擎-详细设计

## 1. 概述

### 1.1 功能定位

学生用户学习社交关系图谱与同伴影响力量化分析引擎是 PrimeTop 平台中专注于**学习社交网络分析与同伴影响力建模**的基础设施服务。该引擎从学生的班级关系、协作任务、学习圈互动、好友关系等多维数据中构建社交图谱，量化同伴之间的学习影响力，识别关键意见领袖学生和社交孤立学生，为个性化推荐、学习干预、同伴匹配等上游服务提供社交维度的数据支撑。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 社交关系建模 | 将学生之间的显式和隐式关系结构化为图数据 |
| 影响力量化 | 计算每个学生对同伴学习行为和成绩的影响力分数 |
| 关键节点识别 | 发现班级/年级中的学习意见领袖和社交桥梁节点 |
| 风险预警 | 检测社交孤立学生和负面影响力传播链路 |
| 数据服务 | 为推荐、匹配、干预等下游提供社交特征数据 |

### 1.3 适用范围

- 适用学段：小学至高中（幼儿阶段不涉及社交图谱）
- 数据来源：班级关系、协作任务、学习圈、直接消息、好友列表、答题行为关联
- 输出消费方：同伴推荐引擎、学习干预引擎、班级学情分析、推荐系统特征平台

### 1.4 与现有模块的关系

| 现有模块 | 关系说明 |
| --- | --- |
| 服务端-学习同伴圈层匹配与协作学习编排引擎 | 圈层匹配消费本引擎的社交关系数据，进行同伴配对 |
| 服务端-学生学习社交动态信息流与学习圈内容分发引擎 | 信息流分发参考社交亲密度的排序权重 |
| 服务端-学生学习成效同伴基准参照与群体对比分析引擎 | 基准参照使用本引擎的社交分组数据 |
| 服务端-学生同伴互评与协作批改任务管理引擎 | 互评分配参考社交关系避免利益冲突 |
| 服务端-学生用户学习断更回归预测与智能唤醒策略引擎 | 断更预警参考社交活跃度作为辅助特征 |
| 服务端-学生画像特征工程平台与统一特征存储计算管线 | 本引擎产出社交特征汇入统一特征存储 |

## 2. 核心概念定义

### 2.1 社交关系类型

```text
┌─────────────────────────────────────────────────────────┐
│                   社交关系类型体系                          │
├─────────────┬─────────────┬───────────────────────────────┤
│   显式关系    │   隐式关系    │         上下文关系             │
├─────────────┼─────────────┼───────────────────────────────┤
│ 好友添加     │ 共同班级     │ 同一教材版本                   │
│ 家长间好友   │ 协作任务同伴  │ 同一考点专题学习               │
│ 学习圈成员   │ 互评参与者   │ 同一时间段活跃（自习室同伴）     │
│ 邀请关系     │ 内容互动    │ 同一区域/学校                  │
│             │ 消息往来     │                               │
│             │ 错题讨论     │                               │
└─────────────┴─────────────┴───────────────────────────────┘
```

### 2.2 关系权重模型

每条社交边携带多维权重，不同维度独立评分：

| 维度 | 符号 | 范围 | 说明 |
| --- | --- | --- | --- |
| 亲密度 | `closeness` | [0, 1] | 互动频率与情感深度 |
| 学习影响度 | `influence` | [-1, 1] | 对学习行为的正向/负向影响 |
| 信任度 | `trust` | [0, 1] | 基于互动质量和持续时间 |
| 结构对等性 | `equivalence` | [0, 1] | 两人在社交网络中的位置相似度 |

### 2.3 影响力传播模型

采用改进的 Independent Cascade Model（独立级联模型）结合时间衰减因子：

```text
影响力传播公式：

    influence_spread(v) = Σ_{u ∈ Neighbors(v)} P(u→v) × weight(u→v) × decay(Δt)

其中：
    P(u→v)    = u 对 v 的激活概率（基于历史互动转换率）
    weight    = 多维关系权重加权综合值
    decay(Δt) = exp(-λ × Δt)，Δt 为距上次互动的时间间隔
    λ         = 衰减系数，默认 0.05（半衰期约 14 天）
```

## 3. 数据结构定义

### 3.1 社交节点表 `social_graph_node`

存储学生用户的社交节点信息。

```sql
CREATE TABLE social_graph_node (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    school_id       BIGINT COMMENT '学校ID',
    grade_id        INT NOT NULL COMMENT '当前年级ID',
    class_id        BIGINT COMMENT '班级ID',
    subject_ids     JSON COMMENT '活跃学科列表 [1,2,3]',
    node_type       VARCHAR(20) NOT NULL DEFAULT 'STUDENT' COMMENT '节点类型: STUDENT/TEACHER/GROUP',
    ref_group_id    BIGINT COMMENT '若为GROUP类型，关联的学习圈ID',
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '1=活跃 0=休眠 -1=已注销',
    influence_score DECIMAL(6,4) COMMENT '最新计算的全局影响力分数 [-1, 1]',
    prestige_score  DECIMAL(6,4) COMMENT '声望分数（PageRank衍生）[0, 1]',
    broker_score    DECIMAL(6,4) COMMENT '中介中心性分数 [0, 1]',
    last_active_at  DATETIME NOT NULL COMMENT '最近活跃时间',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_user_id (user_id),
    INDEX idx_class_grade (class_id, grade_id),
    INDEX idx_school (school_id),
    INDEX idx_influence (influence_score),
    INDEX idx_last_active (last_active_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='社交图谱节点表';
```

### 3.2 社交关系边表 `social_graph_edge`

存储节点之间的关系边，支持多维权重。

```sql
CREATE TABLE social_graph_edge (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    source_user_id  BIGINT NOT NULL COMMENT '关系起点用户ID',
    target_user_id  BIGINT NOT NULL COMMENT '关系终点用户ID',
    edge_type       VARCHAR(30) NOT NULL COMMENT '关系类型，见 3.3',
    closeness       DECIMAL(4,3) NOT NULL DEFAULT 0.0 COMMENT '亲密度 [0, 1]',
    influence       DECIMAL(4,3) NOT NULL DEFAULT 0.0 COMMENT '学习影响度 [-1, 1]',
    trust           DECIMAL(4,3) NOT NULL DEFAULT 0.0 COMMENT '信任度 [0, 1]',
    equivalence     DECIMAL(4,3) NOT NULL DEFAULT 0.0 COMMENT '结构对等性 [0, 1]',
    interaction_count INT NOT NULL DEFAULT 0 COMMENT '历史互动总次数',
    positive_interactions INT NOT NULL DEFAULT 0 COMMENT '正向互动次数（互相帮助、点赞等）',
    negative_interactions INT NOT NULL DEFAULT 0 COMMENT '负向互动次数（举报、拉黑等）',
    first_interaction_at DATETIME COMMENT '首次互动时间',
    last_interaction_at  DATETIME COMMENT '最近互动时间',
    metadata        JSON COMMENT '扩展属性',
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '1=有效 0=已解除',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_edge (source_user_id, target_user_id, edge_type),
    INDEX idx_target (target_user_id, edge_type),
    INDEX idx_influence (influence),
    INDEX idx_closeness (closeness),
    INDEX idx_last_interaction (last_interaction_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='社交图谱关系边表';
```

### 3.3 关系类型枚举

```sql
-- edge_type 枚举值
'FRIEND'           -- 好友关系（显式添加）
'CLASSMATE'        -- 同班同学（系统自动建立）
'STUDY_GROUP'      -- 学习圈成员（同一学习圈）
'COLLABORATION'    -- 协作任务同伴（PBL、互评等）
'CONTENT_INTERACT' -- 内容互动（评论、点赞、转发）
'MESSAGE'          -- 消息往来（私信、讨论区）
'INVITATION'       -- 邀请关系（邀请注册/加入）
'STUDY_ROOM'       -- 自习室同伴（同一在线自习室）
'PARENT_FRIEND'    -- 家长间好友（家长维度社交）
```

### 3.4 影响力传播事件表 `influence_propagation_event`

记录影响力传播事件的追踪表，用于模型校准。

```sql
CREATE TABLE influence_propagation_event (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    source_user_id  BIGINT NOT NULL COMMENT '影响力源用户ID',
    target_user_id  BIGINT NOT NULL COMMENT '被影响用户ID',
    event_type      VARCHAR(40) NOT NULL COMMENT '传播事件类型，见 3.5',
    subject_id      INT COMMENT '关联学科ID',
    knowledge_point_id BIGINT COMMENT '关联知识点ID',
    influence_score DECIMAL(6,4) COMMENT '本次影响力强度 [-1, 1]',
    time_lag_hours  DECIMAL(8,2) COMMENT '从源头行为到跟随行为的时间延迟（小时）',
    confidence      DECIMAL(4,3) NOT NULL DEFAULT 0.5 COMMENT '因果关联置信度 [0, 1]',
    evidence        JSON COMMENT '证据数据快照',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_source (source_user_id, event_type),
    INDEX idx_target (target_user_id, event_type),
    INDEX idx_created (created_at),
    INDEX idx_subject_kp (subject_id, knowledge_point_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='影响力传播事件表';
```

### 3.5 影响力传播事件类型

```text
事件类型                           | 检测逻辑
----------------------------------|----------------------------------
LEARNING_TIME_INCREASE            | 源用户学习时长增加后，目标用户也增加
CONTENT_ADOPTION                  | 源用户收藏/学习某内容后，目标用户也收藏
STUDY_PLAN_FOLLOW                 | 目标用户的学习计划与源用户高度相似
SKILL_IMPROVEMENT_CORRELATION     | 源用户某知识点掌握度提升后，目标用户也提升
ERROR_PATTERN_DIFFUSION           | 源用户的错误模式传播到目标用户
STUDY_STREAK_INFLUENCE            | 源用户连续打卡带动目标用户打卡
TOOL_ADOPTION                     | 源用户使用某学习工具后，目标用户也开始使用
NEGATIVE_DISENGAGEMENT            | 源用户流失后，目标用户活跃度下降
```

### 3.6 班级社交健康度快照表 `class_social_health_snapshot`

```sql
CREATE TABLE class_social_health_snapshot (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    class_id            BIGINT NOT NULL COMMENT '班级ID',
    grade_id            INT NOT NULL COMMENT '年级ID',
    snapshot_date       DATE NOT NULL COMMENT '快照日期',
    total_students      INT NOT NULL COMMENT '班级总人数',
    active_students     INT NOT NULL COMMENT '活跃学生数',
    avg_closeness       DECIMAL(6,4) COMMENT '平均亲密度 [0, 1]',
    cohesion_score      DECIMAL(6,4) COMMENT '凝聚力分数 [0, 1]',
    fragmentation_score DECIMAL(6,4) COMMENT '碎片化分数 [0, 1]，越高越分散',
    isolated_count      INT NOT NULL DEFAULT 0 COMMENT '社交孤立学生数',
    influencer_count    INT NOT NULL DEFAULT 0 COMMENT '关键影响力学生数',
    avg_clustering_coef DECIMAL(6,4) COMMENT '平均聚类系数 [0, 1]',
    modularity_score    DECIMAL(6,4) COMMENT '模块度分数，衡量社区划分质量',
    community_count     INT NOT NULL DEFAULT 0 COMMENT '检测到的社区数量',
    influence_entropy   DECIMAL(6,4) COMMENT '影响力分布熵，越高越均匀',
    metadata            JSON COMMENT '附加指标',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_class_date (class_id, snapshot_date),
    INDEX idx_grade_date (grade_id, snapshot_date),
    INDEX idx_cohesion (cohesion_score),
    INDEX idx_isolated (isolated_count)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='班级社交健康度快照表';
```

### 3.7 图数据缓存结构（Redis）

社交图谱的频繁查询结果缓存到 Redis，使用图邻接表结构：

```text
# 节点邻接表缓存（Hash）
Key:  sg:adj:{user_id}
Field: neighbor_user_id
Value: {"closeness": 0.75, "influence": 0.6, "edge_type": "CLASSMATE", "last_interaction": "2026-08-07T10:30:00"}

TTL: 6小时（低频关系） / 1小时（高频活跃用户）

# 影响力 Top-K 缓存（ZSet）
Key:  sg:influencer:{class_id}
Score: influence_score
Member: user_id

TTL: 12小时

# 社区划分缓存（Hash）
Key:  sg:community:{class_id}
Field: user_id
Value: community_id

TTL: 24小时

# 孤立学生列表缓存（Set）
Key:  sg:isolated:{class_id}
Members: [user_id_1, user_id_2, ...]

TTL: 24小时
```

```python
class SocialGraphBuilder:
    """
    社交图谱增量构建器
    从多源事件流中提取社交关系，增量更新图结构
    """

    EDGE_TYPE_WEIGHTS = {
        'FRIEND': 1.0,
        'CLASSMATE': 0.3,
        'STUDY_GROUP': 0.5,
        'COLLABORATION': 0.7,
        'CONTENT_INTERACT': 0.2,
        'MESSAGE': 0.4,
        'STUDY_ROOM': 0.25,
        'INVITATION': 0.6,
    }

    def build_incremental(self, events: list[SocialEvent], existing_graph: SocialGraph) -> GraphDelta:
        """
        增量构建社交图：
        1. 从事件流提取新的边或更新已有边
        2. 重算受影响节点的局部指标
        3. 标记需要全局重算的节点
        """
        delta = GraphDelta()

        for event in events:
            source_id = event.source_user_id
            target_id = event.target_user_id
            edge_type = event.edge_type

            # 获取或创建边
            edge = existing_graph.get_edge(source_id, target_id, edge_type)
            if edge is None:
                edge = self._create_edge_from_event(event)
                delta.added_edges.append(edge)
            else:
                # 更新现有边权重
                updated_edge = self._update_edge_weight(edge, event)
                delta.updated_edges.append(updated_edge)

            # 记录受影响节点，需重算局部指标
            delta.affected_nodes.add(source_id)
            delta.affected_nodes.add(target_id)

        return delta

    def _update_edge_weight(self, edge: SocialEdge, event: SocialEvent) -> SocialEdge:
        """
        更新边权重：
        - closeness: 基于互动频率（滑动窗口内归一化）
        - influence: 基于行为跟随性（因果分析）
        - trust: 基于互动持续时间和质量
        """
        # 时间衰减系数（互动越久远权重越低）
        decay = math.exp(-0.05 * event.days_since_last_interaction)

        # 更新互动计数
        edge.interaction_count += 1
        if event.is_positive:
            edge.positive_interactions += 1
        else:
            edge.negative_interactions += 1

        # 重新计算 closeness：基于近30天互动频率
        recent_interactions = edge.get_recent_interactions(days=30)
        max_possible = max(100, edge.interaction_count)  # 归一化基准
        edge.closeness = min(1.0, len(recent_interactions) / max_possible * 5) * decay

        # 重新计算 trust：正向互动占比 × 持续时间因子
        if edge.interaction_count > 0:
            positive_ratio = edge.positive_interactions / edge.interaction_count
            duration_factor = min(1.0, (datetime.now() - edge.first_interaction_at).days / 90)
            edge.trust = positive_ratio * duration_factor

        edge.last_interaction_at = event.occurred_at
        return edge
```

#### 5.1.2 边权重综合计算

```python
def compute_composite_weight(edge: SocialEdge, subject_id: int = None) -> float:
    """
    计算边的综合权重，用于图算法遍历时的优先级排序
    """
    type_weight = SocialGraphBuilder.EDGE_TYPE_WEIGHTS.get(edge.edge_type, 0.1)

    # 时间衰减
    days_since = (datetime.now() - edge.last_interaction_at).days
    time_decay = math.exp(-0.03 * days_since)

    # 综合权重 = 类型权重 × 亲密度 × 时间衰减 × (1 + |影响力|)
    composite = (
        type_weight *
        edge.closeness *
        time_decay *
        (1 + abs(edge.influence))
    )

    # 学科维度调整
    if subject_id and edge.metadata.get('subject_id') == subject_id:
        composite *= 1.2  # 同学科关系加权

    return composite
```

### 5.2 影响力评分算法

#### 5.2.1 基于改进 PageRank 的全局影响力

```python
class InfluenceScorer:
    """
    学生影响力评分器
    结合 PageRank 和行为传播分析
    """

    def compute_influence_scores(
        self,
        graph: SocialGraph,
        damping_factor: float = 0.85,
        max_iterations: int = 100,
        convergence_threshold: float = 1e-6
    ) -> dict[int, float]:
        """
        计算所有节点的全局影响力分数
        
        改进点：
        1. 使用加权 PageRank（边权重不等分）
        2. 区分正向和负向影响力
        3. 加入学科维度，支持按学科计算
        """
        nodes = graph.get_all_nodes()
        n = len(nodes)
        if n == 0:
            return {}

        # 初始化影响力分数
        scores = {node.user_id: 1.0 / n for node in nodes}

        for iteration in range(max_iterations):
            new_scores = {}
            max_delta = 0.0

            for node in nodes:
                uid = node.user_id

                # 获取所有指向该节点的入边
                in_edges = graph.get_in_edges(uid)

                # 计算来自邻居的影响力传播
                incoming_sum = 0.0
                for edge in in_edges:
                    source_id = edge.source_user_id
                    source_out_weight_sum = graph.get_out_weight_sum(source_id)

                    if source_out_weight_sum > 0:
                        edge_weight = compute_composite_weight(edge)
                        incoming_sum += (
                            scores[source_id] *
                            edge_weight /
                            source_out_weight_sum
                        )

                # PageRank 公式：带阻尼因子的迭代
                new_score = (1 - damping_factor) / n + damping_factor * incoming_sum
                new_scores[uid] = new_score
                max_delta = max(max_delta, abs(new_score - scores[uid]))

            scores = new_scores

            if max_delta < convergence_threshold:
                break  # 收敛

        # 归一化到 [0, 1] 并应用符号（正/负影响力）
        normalized = self._normalize_with_sign(scores, graph)
        return normalized

    def _normalize_with_sign(
        self,
        raw_scores: dict[int, float],
        graph: SocialGraph
    ) -> dict[int, float]:
        """
        将 PageRank 分数映射到 [-1, 1] 区间
        正向影响力：该学生带动同伴学习进步
        负向影响力：该学生带动同伴学习退步
        """
        if not raw_scores:
            return {}

        max_score = max(raw_scores.values())
        if max_score == 0:
            return {uid: 0.0 for uid in raw_scores}

        normalized = {}
        for uid, score in raw_scores.items():
            magnitude = score / max_score  # [0, 1]

            # 判断影响力方向：基于该节点出边的平均 influence 值
            out_edges = graph.get_out_edges(uid)
            if out_edges:
                avg_influence = sum(e.influence for e in out_edges) / len(out_edges)
                direction = 1 if avg_influence >= 0 else -1
            else:
                direction = 1

            normalized[uid] = magnitude * direction

        return normalized
```

#### 5.2.2 行为跟随性检测（影响力因果分析）

```python
class BehaviorFollowDetector:
    """
    检测学生行为之间的跟随模式，建立因果关系
    
    核心思路：
    - 如果学生 A 做了行为 X（如开始学习某内容）
    - 在之后的时间窗口 Δt 内，与学生 A 有社交关系的学生 B 也做了行为 X
    - 且学生 B 在此之前没有做过行为 X
    - 则认为存在一次潜在的影响力传播事件
    """

    BEHAVIOR_TYPES = [
        'CONTENT_ADOPTION',       # 内容收藏/学习
        'STUDY_STREAK_START',     # 打卡开始
        'TOOL_ADOPTION',          # 工具使用
        'PLAN_TEMPLATE_USE',      # 计划模板使用
        'SUBJECT_INTEREST_SHOW',  # 学科兴趣表达
    ]

    def detect_follow_events(
        self,
        behavior_log: list[BehaviorEvent],
        social_graph: SocialGraph,
        time_window_hours: int = 72
    ) -> list[InfluencePropagationEvent]:
        """
        从行为日志中检测影响力跟随事件
        
        Args:
            behavior_log: 按时间排序的行为事件列表
            social_graph: 社交关系图
            time_window_hours: 跟随行为检测的时间窗口
        """
        propagation_events = []

        # 按行为类型分组
        behavior_groups = defaultdict(list)
        for event in behavior_log:
            behavior_groups[event.behavior_type].append(event)

        for behavior_type, events in behavior_groups.items():
            # 按用户分组
            user_behaviors = defaultdict(list)
            for event in events:
                user_behaviors[event.user_id].append(event)

            # 对每个行为，检查社交邻居是否在时间窗口内跟随
            for event in events:
                source_id = event.user_id
                event_time = event.occurred_at

                # 获取社交邻居
                neighbors = social_graph.get_neighbors(source_id)
                if not neighbors:
                    continue

                for neighbor_id in neighbors:
                    # 检查邻居是否在时间窗口内也做了相同行为
                    neighbor_events = user_behaviors.get(neighbor_id, [])
                    for neighbor_event in neighbor_events:
                        time_lag = neighbor_event.occurred_at - event_time

                        # 必须在源用户之后、时间窗口之内
                        if 0 < time_lag.total_seconds() <= time_window_hours * 3600:
                            # 计算因果置信度
                            confidence = self._compute_confidence(
                                source_id, neighbor_id, behavior_type,
                                event, neighbor_event, social_graph
                            )

                            propagation_events.append(InfluencePropagationEvent(
                                source_user_id=source_id,
                                target_user_id=neighbor_id,
                                event_type=behavior_type,
                                influence_score=confidence * social_graph.get_edge(
                                    source_id, neighbor_id
                                ).influence,
                                time_lag_hours=time_lag.total_seconds() / 3600,
                                confidence=confidence
                            ))

        return propagation_events

    def _compute_confidence(
        self,
        source_id: int,
        target_id: int,
        behavior_type: str,
        source_event: BehaviorEvent,
        target_event: BehaviorEvent,
        social_graph: SocialGraph
    ) -> float:
        """
        计算因果关联置信度 [0, 1]
        
        因子：
        1. 社交亲密度：关系越亲密越可能是被影响
        2. 行为稀有度：越稀有的行为越不可能是偶然
        3. 时间接近度：越快跟随越可能有关联
        4. 历史一致性：过去是否频繁出现跟随模式
        """
        edge = social_graph.get_edge(source_id, target_id)
        if not edge:
            return 0.0

        # 因子1：社交亲密度
        closeness_factor = edge.closeness

        # 因子2：行为稀有度（对数衰减）
        # 如果该行为在全平台只有少数人做，跟随更可能是被影响
        rarity = source_event.global_frequency  # 该行为的全局频率
        rarity_factor = 1.0 / (1.0 + math.log10(max(1, rarity)))

        # 因子3：时间接近度（指数衰减）
        time_lag_hours = (target_event.occurred_at - source_event.occurred_at).total_seconds() / 3600
        time_factor = math.exp(-0.02 * time_lag_hours)

        # 因子4：历史跟随率
        history_factor = edge.metadata.get('historical_follow_rate', 0.5)

        # 加权综合
        confidence = (
            0.30 * closeness_factor +
            0.25 * rarity_factor +
            0.25 * time_factor +
            0.20 * history_factor
        )

        return min(1.0, confidence)
```

### 5.3 社区发现算法

```python
class CommunityDetector:
    """
    社交社区检测器
    使用改进的 Louvain 算法发现学生社交群体
    
    改进点：
    1. 融入学习行为相似性作为额外边权重
    2. 约束社区大小（最小3人，最大不超过班级人数的50%）
    3. 输出社区角色（Leader, Bridge, Peripheral）
    """

    def detect_communities(
        self,
        graph: SocialGraph,
        min_community_size: int = 3,
        max_community_ratio: float = 0.5,
        resolution: float = 1.0
    ) -> dict[int, list[int]]:
        """
        检测社交社区
        
        Returns:
            {community_id: [user_id_1, user_id_2, ...]}
        """
        # Step 1: 构建加权邻接矩阵
        nodes = graph.get_all_nodes()
        node_index = {node.user_id: i for i, node in enumerate(nodes)}
        n = len(nodes)

        # 邻接矩阵（使用稀疏矩阵）
        adj = self._build_weighted_adjacency(graph, node_index, n)

        # Step 2: Louvain 算法迭代
        communities = self._louvain_iterations(
            adj, node_index, nodes,
            resolution=resolution,
            max_iterations=50
        )

        # Step 3: 社区合并/拆分（约束大小）
        communities = self._adjust_community_sizes(
            communities, adj, node_index,
            min_size=min_community_size,
            max_size=int(n * max_community_ratio)
        )

        # Step 4: 为每个成员分配角色
        for comm_id, members in communities.items():
            self._assign_roles(members, graph, adj, node_index)

        return communities

    def _louvain_iterations(
        self,
        adj: SparseMatrix,
        node_index: dict[int, int],
        nodes: list[SocialNode],
        resolution: float,
        max_iterations: int
    ) -> dict[int, list[int]]:
        """
        Louvain 算法核心迭代
        
        每轮：
        1. 每个节点初始为独立社区
        2. 遍历每个节点，尝试将其移到邻居所在社区
        3. 如果移动后模块度增益 ΔQ > 0，执行移动
        4. 重复直到没有节点移动或达到最大迭代次数
        """
        n = len(nodes)
        # 初始化：每个节点自成一个社区
        community = list(range(n))
        degrees = np.array(adj.sum(axis=1)).flatten()
        m = adj.sum()  # 总边权重

        if m == 0:
            return {i: [nodes[i].user_id] for i in range(n)}

        improved = True
        iteration = 0

        while improved and iteration < max_iterations:
            improved = False
            iteration += 1

            for i in range(n):
                current_comm = community[i]

                # 计算从当前社区移除节点 i 的模块度变化
                # Σ_in - (Σ_tot × k_i / 2m) 的变化
                neighbors = adj[i].nonzero()[1]
                neighbor_comms = defaultdict(float)
                for j in neighbors:
                    if i != j:
                        neighbor_comms[community[j]] += adj[i, j]

                # 当前社区内的连接权重
                current_internal = neighbor_comms.get(current_comm, 0)
                k_i = degrees[i]

                # 移除 i 从当前社区的增益
                remove_gain = current_internal - resolution * (k_i * degrees[i]) / (2 * m)

                # 找最佳目标社区
                best_comm = current_comm
                best_gain = 0
                for comm, weight in neighbor_comms.items():
                    gain = weight - resolution * (k_i * degrees[i]) / (2 * m)
                    if gain > best_gain:
                        best_gain = gain
                        best_comm = comm

                # 执行移动（如果总增益 > 0）
                total_gain = best_gain - remove_gain
                if total_gain > 1e-10 and best_comm != current_comm:
                    community[i] = best_comm
                    improved = True

        # 汇总社区
        result = defaultdict(list)
        for i, comm in enumerate(community):
            result[comm].append(nodes[i].user_id)

        return dict(result)

    def _assign_roles(
        self,
        members: list[int],
        graph: SocialGraph,
        adj: SparseMatrix,
        node_index: dict[int, int]
    ):
        """
        为社区成员分配角色：
        - LEADER: 社区内影响力最高的节点
        - BRIDGE: 连接不同社区的关键节点
        - PERIPHERAL: 社区边缘节点
        """
        member_indices = [node_index[uid] for uid in members if uid in node_index]

        # 计算每个成员在社区内的度数
        internal_degrees = {}
        for idx in member_indices:
            internal_degree = 0
            for j in adj[idx].nonzero()[1]:
                if j in member_indices:
                    internal_degree += adj[idx, j]
            internal_degrees[idx] = internal_degree

        # LEADER: 度数最高
        leader_idx = max(internal_degrees, key=internal_degrees.get)

        for uid in members:
            if uid not in node_index:
                continue
            idx = node_index[uid]
            node = graph.get_node(uid)

            if idx == leader_idx:
                node.metadata['community_role'] = 'LEADER'
            elif self._is_bridge(idx, member_indices, adj):
                node.metadata['community_role'] = 'BRIDGE'
            else:
                node.metadata['community_role'] = 'PERIPHERAL'

    def _is_bridge(self, idx: int, community: list[int], adj: SparseMatrix) -> bool:
        """判断节点是否为桥梁（有较多指向社区外的连接）"""
        neighbors = adj[idx].nonzero()[1]
        external = sum(1 for j in neighbors if j not in community)
        internal = sum(1 for j in neighbors if j in community)
        return external > 0 and external >= internal * 0.5
```

### 5.4 社交孤立检测算法

```python
class IsolationDetector:
    """
    学生社交孤立检测器
    
    多维评估：
    1. 网络规模：直接社交关系数量
    2. 网络密度：互动频率和质量
    3. 社区归属：是否被归入某个社交群体
    4. 互动时近性：最近一次社交互动的时间
    5. 互动均衡性：互动是否集中在极少数人
    """

    def compute_isolation_score(
        self,
        user_id: int,
        graph: SocialGraph
    ) -> IsolationAssessment:
        """
        计算学生社交孤立度 [0, 1]
        分数越高越孤立
        """
        node = graph.get_node(user_id)
        if not node:
            return IsolationAssessment(isolation_score=1.0, risk_level='CRITICAL')

        neighbors = graph.get_neighbors(user_id)

        # 维度1: 网络规模（对比班级平均）
        class_avg_network = graph.get_class_avg_network_size(node.class_id)
        network_ratio = len(neighbors) / max(1, class_avg_network)
        size_score = 1.0 - min(1.0, network_ratio)  # 越小越孤立

        # 维度2: 平均亲密度
        if neighbors:
            avg_closeness = statistics.mean(
                graph.get_edge(user_id, n.user_id).closeness
                for n in neighbors
            )
            density_score = 1.0 - avg_closeness
        else:
            avg_closeness = 0
            density_score = 1.0

        # 维度3: 社区归属
        community_id = node.metadata.get('community_id')
        community_score = 0.0 if community_id is not None else 1.0

        # 维度4: 互动时近性
        last_interaction = node.metadata.get('last_social_interaction_at')
        if last_interaction:
            days_since = (datetime.now() - last_interaction).days
            recency_score = 1.0 - math.exp(-0.05 * days_since)
        else:
            recency_score = 1.0

        # 维度5: 互动均衡性（基尼系数）
        if len(neighbors) > 1:
            interactions_per_neighbor = [
                graph.get_edge(user_id, n.user_id).interaction_count
                for n in neighbors
            ]
            gini = self._compute_gini(interactions_per_neighbor)
            balance_score = gini  # 基尼系数越高越不均衡
        else:
            balance_score = 1.0

        # 加权综合
        isolation_score = (
            0.30 * size_score +
            0.25 * density_score +
            0.15 * community_score +
            0.20 * recency_score +
            0.10 * balance_score
        )

        # 风险等级
        if isolation_score >= 0.75:
            risk_level = 'CRITICAL'
        elif isolation_score >= 0.55:
            risk_level = 'HIGH'
        elif isolation_score >= 0.35:
            risk_level = 'MODERATE'
        else:
            risk_level = 'LOW'

        # 风险因素列表
        risk_factors = self._identify_risk_factors(
            size_score, density_score, community_score,
            recency_score, balance_score,
            len(neighbors), avg_closeness, last_interaction
        )

        return IsolationAssessment(
            isolation_score=isolation_score,
            risk_level=risk_level,
            risk_factors=risk_factors,
            network_size=len(neighbors),
            avg_closeness=avg_closeness,
            last_social_interaction=last_interaction,
            recommend_action=self._recommend_action(risk_level, risk_factors)
        )

    def _compute_gini(self, values: list[float]) -> float:
        """计算基尼系数 [0, 1]"""
        sorted_values = sorted(values)
        n = len(sorted_values)
        cumsum = sum((2 * i - n + 1) * v for i, v in enumerate(sorted_values))
        total = sum(sorted_values)
        if total == 0:
            return 0
        return cumsum / (n * total)

    def _recommend_action(self, risk_level: str, risk_factors: list[str]) -> str:
        """根据风险等级和因素推荐干预动作"""
        if risk_level == 'CRITICAL':
            return 'DIRECT_INTERVENTION'  # 直接干预：班主任/心理辅导员
        elif risk_level == 'HIGH':
            return 'PEER_MATCHING'  # 同伴匹配：系统推荐学习伙伴
        elif risk_level == 'MODERATE':
            return 'GROUP_ACTIVITY'  # 群体活动：引导参与学习圈
        else:
            return 'MONITOR_ONLY'  # 仅监控
```

### 6.3 影响力评分计算状态流转

```text
INIT       →  COMPUTING  →  CONVERGED  →  PUBLISHED  →  EXPIRED
(待计算)      (计算中)      (收敛完成)     (已发布)      (过期待重算)

触发条件:
INIT       : 新节点加入或边更新
COMPUTING  : 调度器选中开始计算
CONVERGED  : 迭代收敛达到阈值或达到最大迭代次数
PUBLISHED  : 写入 social_graph_node.influence_score 并更新缓存
EXPIRED    : 超过 TTL（默认 7 天）或检测到显著图结构变化
```

### 9.1 图算法性能优化

```text
策略                        | 说明
---------------------------|--------------------------------------------------
增量计算                    | 仅重算受影响节点，不每次全量重算
班级分片                    | 社交关系以班级为主要范围，按班级独立计算
```

```python
            'compute_frequency': 'NONE',
            'max_query_depth': 0,

        },
    }

    def get_degradation_level(self, system_load: float, error_rate: float) -> str:
        """根据系统负载和错误率决定降级级别"""
        if error_rate > 0.3 or system_load > 0.95:
```

## 11. 安全与隐私

### 11.1 数据访问控制

```text
数据层级                | 可见角色                              | 脱敏规则
-----------------------|--------------------------------------|--------------------------
个人社交画像             | 本人、绑定家长、班主任、系统           | 家长视图隐藏具体同学姓名
班级社交健康度           | 班主任、年级组长、系统管理员           | 不向学生开放
社交孤立名单             | 班主任、心理辅导员、系统管理员          | 高敏感，仅授权访问
影响力排名              | 班主任、年级组长                       | 可向学生展示 Top 5（正向影响力）
两人关系详情            | 仅系统内部使用                        | 不直接暴露给用户
影响力传播事件          | 仅系统内部使用                        | 高敏感，仅用于算法优化
```

### 11.2 隐私保护措施

1. **关系推断边界**：不得基于他人数据推断用户未主动建立的关系
2. **社交数据最小化**：只采集学习场景产生的互动，不分析私人对话内容
3. **影响力隐藏**：不向学生展示"你的学习被某人负面影响"的信息
4. **家长可见性限制**：家长只能看到自己孩子的社交概况，不能看到其他孩子的详细信息
5. **数据保留期限**：
   - 社交边数据：关系解除后保留 90 天，之后匿名化
   - 影响力传播事件：保留 180 天用于模型训练
   - 班级健康度快照：保留 2 年
6. **未成年人保护**：所有社交数据的采集和使用需获得家长同意

```python
def test_edge_weight_update_positive_interaction():

                      positive_interactions=8, negative_interactions=2)

    updated = builder._update_edge_weight(edge, event)
    assert updated.closeness > 0.3
    assert updated.trust > 0.4
    assert updated.positive_interactions == 9

def test_pagerank_convergence_simple_graph():
    """简单图（三角形）应均匀分配影响力"""
    graph = build_triangle_graph()  # 3个节点互相连接
    scores = scorer.compute_influence_scores(graph)
    assert abs(scores[1] - scores[2]) < 0.01
```

## 16. 附录

### 16.1 名词解释

| 术语 | 说明 |
| --- | --- |
| 社交图谱（Social Graph） | 学生之间社交关系的图结构表示 |
| PageRank | 用于衡量节点在图中重要性的经典图算法 |
| Louvain 算法 | 基于模块度优化的社区发现贪心算法 |
| 模块度（Modularity） | 衡量社区划分质量的指标，范围 [-0.5, 1] |
| 聚类系数（Clustering Coefficient） | 节点邻居之间互相连接的程度 |
| 中介中心性（Betweenness Centrality） | 节点处于其他节点最短路径上的频率 |
| 基尼系数（Gini Coefficient） | 衡量分布不均匀程度的指标，范围 [0, 1] |
| 独立级联模型（ICM） | 影响力传播的概率模型 |
| 社交孤立（Social Isolation） | 学生在社交网络中连接极少的状态 |
