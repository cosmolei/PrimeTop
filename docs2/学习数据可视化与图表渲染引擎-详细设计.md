# 学习数据可视化与图表渲染引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

学习数据可视化与图表渲染引擎（以下简称 VizEngine）是 PrimeTop 客户端的跨模块共享图表组件库与数据渲染中间层。它负责将各业务模块的学习数据（掌握度、答题正确率、学习时长趋势、知识点分布、错题归因等）转化为标准化的可视化呈现，提供统一的图表类型注册、主题适配、分龄渲染、动画控制和离线缓存能力。

### 1.2 为什么需要独立引擎

| 问题 | 现状 | 引擎解决方式 |
|------|------|-------------|
| 图表散落各模块 | 学情分析、学习报告、家长中心各自用不同方案渲染图表 | 统一组件库，一处定义多处复用 |
| 主题不统一 | 深色/浅色/护眼模式下图表风格割裂 | 通过 DesignToken 自动适配 |
| 分龄差异未体现 | 高中雷达图直接给小学看，信息密度过高 | 分龄渲染策略降维 |
| 性能瓶颈 | 大量数据点时卡顿（周趋势 52 个点、知识点 200+） | Canvas 渲染 + 虚拟化 + 数据采样 |
| 无障碍缺失 | 纯视觉图表，色盲用户无法区分 | 辅助标签 + 图案填充 + 语音播报 |

### 1.3 消费模块一览

| 消费模块 | 使用场景 | 图表类型 |
|----------|----------|----------|
| 学情分析 | 掌握度雷达图、学科正确率柱状图、学习趋势折线图 | 雷达图、柱状图、折线图 |
| 学习报告生成与交付 | 周报/月报中的学习时长统计、知识点分布饼图、进步曲线 | 折线图、饼图、柱状图、进度条 |
| 学习效果量化追踪 | 学习效果指数 LEI 趋势、归因贡献度、对照组比较 | 折线图、堆叠柱状图、瀑布图 |
| 家长中心 | 孩子学习概览、学科对比、用时分布 | 环形图、柱状图、热力日历 |
| 考试模拟与真题练习 | 得分分布、题型分析、时间分配、历次对比 | 柱状图、饼图、折线图 |
| 错题整理 | 错因分类饼图、错题趋势、知识点热力图 | 饼图、折线图、热力图 |
| 知识图谱构建与可视化 | 知识点关联网络 | 力导向图（本引擎不覆盖，独立实现） |
| 学习数据仓库与BI | 运营后台大盘 | 折线图、柱状图、面积图 |
| 首页与学习工作台 | 今日进度环、连续学习天数、快捷统计 | 环形进度、迷你折线 |

### 1.4 设计目标

| 目标 | 指标 |
|------|------|
| 首次渲染 < 16ms | 单图表帧耗时不超过一帧 |
| 1000 数据点流畅 | 折线图 1000 点无卡顿 |
| 主题切换无闪烁 | 主题切换后图表无缝过渡 |
| 无障碍覆盖率 100% | 所有图表支持语义标签和色盲模式 |
| 分龄自动适配 | 同一数据源在不同学段呈现不同信息密度 |

## 2. 图表类型体系

### 2.1 核心图表类型注册表

```dart
/// 图表类型枚举
enum ChartType {
  /// 折线图 - 学习时长趋势、正确率趋势、排名变化
  line,

  /// 柱状图 - 学科正确率、每日学习时长、题型分布
  bar,

  /// 堆叠柱状图 - 学习时长拆分(各学科)、错因分类对比
  stackedBar,

  /// 饼图 - 错因分布、学科学习占比
  pie,

  radar,

  /// 热力图 - 学习日历(连续打卡)、知识点掌握热力
  heatmap,

  /// 瀑布图 - 学习效果归因(增减变化)
  waterfall,

  /// 面积图 - 累计学习时长、知识覆盖进度
  area,

  /// 迷你折线 (Sparkline) - 首页卡片内嵌趋势
  sparkline,

  progress,

  /// 环形进度 - 今日学习目标完成率
  ringProgress,

  /// 散点图 - 难度 vs 正确率分布
  scatter,

  /// 组合图 - 折线+柱状叠加(学习时长+正确率双轴)
```

#### 3.2.3 服务端预置数据聚合 SQL 示例

```sql
-- 学习时长趋势(日维度)
SELECT
    DATE(la.created_at) AS date_key,
    ROUND(SUM(la.duration_sec) / 60.0, 1) AS study_minutes,
    COUNT(DISTINCT la.id) AS activity_count
FROM learning_activity_log la
WHERE la.user_id = %s
  AND la.created_at BETWEEN %s AND %s
GROUP BY DATE(la.created_at)
ORDER BY date_key;

-- 学科正确率(最近30天)
SELECT
    s.code AS subject_code,
    s.name AS subject_name,
    COUNT(*) AS total_questions,
    SUM(CASE WHEN la.is_correct = 1 THEN 1 ELSE 0 END) AS correct_count,
    ROUND(
        SUM(CASE WHEN la.is_correct = 1 THEN 1 ELSE 0 END) * 100.0 / NULLIF(COUNT(*), 0),
        1
    ) AS accuracy_rate
FROM learning_activity_log la
JOIN knowledge_points kp ON la.knowledge_point_id = kp.id
JOIN subjects s ON kp.subject_id = s.id
WHERE la.user_id = %s
  AND la.is_correct IS NOT NULL
  AND la.created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)
GROUP BY s.code, s.name
ORDER BY accuracy_rate ASC;

-- 错因分布(饼图数据)
SELECT
    mc.error_category,
    mc.label AS category_label,
    COUNT(*) AS count
FROM mistake_records mr
JOIN mistake_classifications mc ON mr.classification_id = mc.id
WHERE mr.user_id = %s
  AND mr.created_at BETWEEN %s AND %s
GROUP BY mc.error_category, mc.label
ORDER BY count DESC;

-- 学习日历热力图(年维度)
SELECT
    DATE(created_at) AS date_key,
    ROUND(SUM(duration_sec) / 60.0) AS total_minutes,
    CASE
        WHEN SUM(duration_sec) / 60.0 >= 120 THEN 4  -- ≥2h 深色
        WHEN SUM(duration_sec) / 60.0 >= 60 THEN 3   -- ≥1h
        WHEN SUM(duration_sec) / 60.0 >= 30 THEN 2   -- ≥30min
        WHEN SUM(duration_sec) / 60.0 > 0 THEN 1     -- >0 浅色
        ELSE 0
    END AS heat_level
FROM learning_activity_log
WHERE user_id = %s
  AND created_at >= DATE_FORMAT(NOW(), '%%Y-01-01')
GROUP BY DATE(created_at);
```

#### 4.2.2 VizPainterFactory — 渲染器注册表

```dart
/// 图表渲染器工厂
class VizPainterFactory {
  static final Map<ChartType, VizPainterBuilder> _registry = {};

  /// 注册渲染器
  static void register(ChartType type, VizPainterBuilder builder) {
    _registry[type] = builder;
  }

  /// 创建渲染器
  static VizCustomPainter create(
    ChartType type,
    VizDataSet dataSet,
    VizRenderContext context,
  ) {
    final builder = _registry[type];
    if (builder == null) {
      throw VizException('未注册的图表类型: $type');
    }
    return builder(dataSet, context);
  }
}

/// 渲染器构建函数签名
typedef VizPainterBuilder = VizCustomPainter Function(
  VizDataSet dataSet,
  VizRenderContext context,
);
```

### 4.3 分龄渲染策略

```dart
/// 分龄可视化配置
class StageVizConfig {
  /// 目标学段
  final SchoolStage stage;

  /// 最大显示维度数（雷达图等）
  final int maxDimensions;

  /// 最大显示图例数
  final int maxLegendItems;

  /// 是否显示数值标签
  final bool showValueLabels;

  /// 是否显示网格线
  final bool showGridLines;

  /// 是否启用缩放/拖拽
  final bool enableZoomPan;

  /// 信息密度级别: low / medium / high
  final String densityLevel;

  /// 默认动画时长(ms)
  final int animationDurationMs;

  /// 迷你图模式阈值（数据点少于此数自动切换迷你图）
  final int sparklineThreshold;

  /// 颜色饱和度系数 (0.0 ~ 1.0)，幼儿偏高，高中偏低
  final double colorSaturation;

  static StageVizConfig forStage(SchoolStage stage) {
    switch (stage) {
      case SchoolStage.preschool:
        return StageVizConfig(
          stage: stage,
          maxDimensions: 3,
          maxLegendItems: 3,
          showValueLabels: false,
          showGridLines: false,
          enableZoomPan: false,
          densityLevel: 'low',
          animationDurationMs: 800,
          sparklineThreshold: 5,
          colorSaturation: 0.9,

      case SchoolStage.primary:
        return StageVizConfig(
          stage: stage,
          maxDimensions: 5,
          maxLegendItems: 5,

          showGridLines: false,
          enableZoomPan: false,
          densityLevel: 'low',
          animationDurationMs: 600,

          colorSaturation: 0.8,

      case SchoolStage.junior:
        return StageVizConfig(
```

#### 5.1.2 数据采样策略

当数据点超过 `maxDataPoints`（默认 300）时触发降采样：

```dart
/// 数据采样器
class VizDataSampler {
  /// LTTB (Largest Triangle Three Buckets) 算法
  /// 保留视觉特征的最佳降采样算法
  static List<VizDataPoint> downsample(
    List<VizDataPoint> data,
    int targetCount,
  ) {
    if (data.length <= targetCount) return data;

    final result = <VizDataPoint>[];
    // 始终保留首尾点
    result.add(data.first);

    final bucketSize = (data.length - 2) / (targetCount - 2);

    int prevIndex = 0;
    for (int i = 1; i < targetCount - 1; i++) {
      final bucketStart = (i * bucketSize).floor() + 1;
      final bucketEnd = min(((i + 1) * bucketSize).floor() + 1, data.length - 1);

      // 在每个桶中选择与三角形面积最大的点
      double maxArea = -1;
      int maxIndex = bucketStart;

      final prevPoint = data[prevIndex];
      final nextAvgX = data[bucketEnd].x is num
          ? data.sublist(bucketStart, bucketEnd)
              .fold<num>(0, (s, p) => s + (p.x as num)) / (bucketEnd - bucketStart)
          : 0;

      for (int j = bucketStart; j < bucketEnd; j++) {
        final area = _triangleArea(
          prevPoint, data[j], _avgPoint(data, bucketEnd, nextAvgX),
        );
        if (area > maxArea) {
          maxArea = area;
          maxIndex = j;
        }
      }

      result.add(data[maxIndex]);
      prevIndex = maxIndex;
    }

    result.add(data.last);
    return result;
  }

  static double _triangleArea(VizDataPoint a, VizDataPoint b, VizDataPoint c) {
    return ((a.x as num).toDouble() - (c.x as num).toDouble()) *
               ((b.y - a.y)).abs() +
           ((a.x as num).toDouble() - (b.x as num).toDouble()) *
               ((c.y - a.y)).abs()).abs() / 2;
  }
}
```

```dart
class LineChartPainter extends VizCustomPainter {
  final VizDataSet dataSet;
  final VizRenderContext context;

  LineChartPainter(this.dataSet, this.context);

  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = 2.0
      ..isAntiAlias = true;

    final chartArea = _calculateChartArea(size);

    // 1. 绘制网格
    _drawGrid(canvas, chartArea);

    // 2. 绘制坐标轴
    _drawAxes(canvas, chartArea);

    for (final series in dataSet.series) {
      final sampledData = VizDataSampler.downsample(
        series.data,
        context.stageConfig.densityLevel == 'high' ? 500 : 300,
      );

      final points = _mapDataToPixels(sampledData, chartArea);

      // 3. 绘制面积填充
      if (series.style?.areaFill == true) {
        _drawAreaFill(canvas, points, chartArea, series);
      }

      // 4. 绘制折线
      paint.color = _getSeriesColor(series);
      paint.strokeWidth = series.style?.lineWidth ?? 2.0;
      if (series.style?.dashArray != null) {
        // 虚线处理
      }
      _drawSmoothLine(canvas, points, paint);

      // 5. 绘制数据点
      _drawDataPoints(canvas, points, series);

      // 6. 绘制数据标签
      if (context.stageConfig.showValueLabels) {
        _drawDataLabels(canvas, points, series);
      }
    }

    // 7. 绘制交互提示
    if (context.interaction.hoveredIndex != null) {
      _drawTooltip(canvas, chartArea, context.interaction);
    }
  }

  List<Offset> _mapDataToPixels(List<VizDataPoint> data, Rect chartArea) {
    // 计算数据范围
    double minY = dataSet.yAxis?.min ?? data.map((p) => p.y).reduce(min);
    double maxY = dataSet.yAxis?.max ?? data.map((p) => p.y).reduce(max);
    // 添加 10% padding
    final range = maxY - minY;
    minY -= range * 0.1;
    maxY += range * 0.1;

    return data.map((point) {
      final x = chartArea.left +
          (chartArea.width * data.indexOf(point) / max(data.length - 1, 1));
      final y = chartArea.bottom -
          (chartArea.height * (point.y - minY) / (maxY - minY));
      return Offset(x, y);
    }).toList();
  }

  void _drawSmoothLine(Canvas canvas, List<Offset> points, Paint paint) {
    if (points.isEmpty) return;
    if (points.length == 1) {
      canvas.drawCircle(points.first, paint.strokeWidth, paint);
      return;
    }

    final path = Path();
    path.moveTo(points.first.dx, points.first.dy);

    for (int i = 1; i < points.length; i++) {
      // Monotone cubic interpolation (Fritsch-Carlson)
      final prev = points[i - 1];
      final curr = points[i];
      final controlOffset = (curr.dx - prev.dx) / 3;
      path.cubicTo(
        prev.dx + controlOffset, prev.dy,
        curr.dx - controlOffset, curr.dy,
        curr.dx, curr.dy,
      );
    }

    canvas.drawPath(path, paint);
  }
}
```

```dart
class BarChartPainter extends VizCustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final chartArea = _calculateChartArea(size);
    final series = dataSet.series;
    final groupCount = series.first.data.length;
    final seriesCount = series.length;

    // 计算柱宽
    final availableWidth = chartArea.width;
    final groupGap = availableWidth / groupCount * 0.3;
    final groupWidth = (availableWidth - groupGap * (groupCount + 1)) / groupCount;
    final barGap = 2.0;
    final barWidth = (groupWidth - barGap * (seriesCount - 1)) / seriesCount;

    final maxY = _calculateMaxY();

    for (int g = 0; g < groupCount; g++) {
      final groupX = chartArea.left + groupGap + g * (groupWidth + groupGap);

      for (int s = 0; s < seriesCount; s++) {
        final point = series[s].data[g];
        final barHeight = (point.y / maxY) * chartArea.height;
        final barX = groupX + s * (barWidth + barGap);
        final barY = chartArea.bottom - barHeight;

        final rect = RRect.fromRectAndCorners(
          Rect.fromLTWH(barX, barY, barWidth, barHeight),
          topLeft: Radius.circular(4),
          topRight: Radius.circular(4),
        );

        final color = _getSeriesColor(series[s]);
        final paint = Paint()
          ..color = _isHighlighted(s, g) ? color : color.withOpacity(0.85)
          ..style = PaintingStyle.fill;

        canvas.drawRRect(rect, paint);

        // 数值标签
        if (context.stageConfig.showValueLabels) {
          _drawBarLabel(canvas, point, barX, barY, barWidth);
        }
      }
    }
  }
```

```dart
class RadarChartPainter extends VizCustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final radius = min(size.width, size.height) / 2 - 40;

    final dimensions = dataSet.series.first.data;
    final axisCount = min(dimensions.length, context.stageConfig.maxDimensions);
    final angleStep = 2 * pi / axisCount;

    // 1. 绘制背景网格
    final ringCount = context.stageConfig.showGridLines ? 4 : 1;
    for (int ring = 1; ring <= ringCount; ring++) {
      final r = radius * ring / ringCount;
      final path = Path();
      for (int i = 0; i <= axisCount; i++) {
        final angle = -pi / 2 + i * angleStep;
        final x = center.dx + r * cos(angle);
        final y = center.dy + r * sin(angle);
        if (i == 0) path.moveTo(x, y);
        else path.lineTo(x, y);
      }
      canvas.drawPath(
        path,
        Paint()
          ..color = context.theme.gridColor.withOpacity(0.3)
          ..style = PaintingStyle.stroke
          ..strokeWidth = 1,
      );
    }

    // 2. 绘制轴线 + 维度标签
    for (int i = 0; i < axisCount; i++) {
      final angle = -pi / 2 + i * angleStep;
      final endX = center.dx + radius * cos(angle);
      final endY = center.dy + radius * sin(angle);
      canvas.drawLine(
        center,
        Offset(endX, endY),
        Paint()
          ..color = context.theme.axisColor.withOpacity(0.3)
          ..strokeWidth = 1,
      );

      // 维度标签
      final labelR = radius + 20;
      final labelX = center.dx + labelR * cos(angle);
      final labelY = center.dy + labelR * sin(angle);
      _drawDimensionLabel(canvas, dimensions[i].x.toString(), labelX, labelY);
    }

    // 3. 绘制数据多边形
    final maxValue = (dataSet.metadata?['maxValue'] as num?)?.toDouble() ?? 100;

    for (final series in dataSet.series) {
      final path = Path();
      final paint = Paint()
        ..color = _getSeriesColor(series)
        ..style = PaintingStyle.fill;

      for (int i = 0; i < axisCount; i++) {
        final value = series.data[i].y;
        final ratio = (value / maxValue).clamp(0.0, 1.0);
        final angle = -pi / 2 + i * angleStep;
        final x = center.dx + radius * ratio * cos(angle);
        final y = center.dy + radius * ratio * sin(angle);
        if (i == 0) path.moveTo(x, y);
        else path.lineTo(x, y);
      }
      path.close();

      // 填充
      canvas.drawPath(path, paint..color = paint.color.withOpacity(0.2));
      // 描边
      canvas.drawPath(
        path,
        Paint()
          ..color = _getSeriesColor(series)
          ..style = PaintingStyle.stroke
          ..strokeWidth = 2,
      );

      // 数据点
      for (int i = 0; i < axisCount; i++) {
        final value = series.data[i].y;
        final ratio = (value / maxValue).clamp(0.0, 1.0);
        final angle = -pi / 2 + i * angleStep;
        final x = center.dx + radius * ratio * cos(angle);
        final y = center.dy + radius * ratio * sin(angle);
        canvas.drawCircle(
          Offset(x, y),
          4,
          Paint()..color = _getSeriesColor(series),
        );
      }
    }
  }
}
```

```dart
class PieChartPainter extends VizCustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final radius = min(size.width, size.height) / 2 - 20;

    final data = dataSet.series.first.data;
    final total = data.fold<double>(0, (sum, p) => sum + p.y);

    // 合并超出 maxSlices 的项为"其他"
    final maxSlices = context.stageConfig.maxLegendItems;
    var processedData = data.toList()
      ..sort((a, b) => b.y.compareTo(a.y));
    if (processedData.length > maxSlices) {
      final othersValue = processedData
          .skip(maxSlices - 1)
          .fold<double>(0, (sum, p) => sum + p.y);
      processedData = processedData.take(maxSlices - 1).toList()
        ..add(VizDataPoint(
          x: '其他',
          y: othersValue,
          label: '其他 ${othersValue.toStringAsFixed(1)}%',
          semanticLabel: '其他类别共${othersValue.toStringAsFixed(1)}%',
        ));
    }

    var startAngle = -pi / 2;
    for (int i = 0; i < processedData.length; i++) {
      final sweepAngle = 2 * pi * (processedData[i].y / total);
      final color = _getSliceColor(i);

      // 悬停偏移
      var offset = Offset.zero;
      if (context.interaction.hoveredIndex == i) {
        final midAngle = startAngle + sweepAngle / 2;
        offset = Offset(6 * cos(midAngle), 6 * sin(midAngle));
      }

      canvas.drawArc(
        Rect.fromCircle(center: center + offset, radius: radius),
        startAngle,
        sweepAngle,
        true,
        Paint()..color = color,
      );

      // 扇区间隙
      canvas.drawLine(
        center + offset,
        Offset(
          center.dx + offset.dx + radius * cos(startAngle),
          center.dy + offset.dy + radius * sin(startAngle),
        ),
        Paint()..color = context.theme.background..strokeWidth = 2,
      );

      startAngle += sweepAngle;
    }

    // 中心镂空（环形饼图）
    if (dataSet.metadata?['innerRadius'] != null) {
      final innerRadius = (dataSet.metadata!['innerRadius'] as num).toDouble();
      canvas.drawCircle(
        center,
        innerRadius,
        Paint()..color = context.theme.background,
      );

      // 中心文字
      if (dataSet.metadata?['centerText'] != null) {
        _drawCenterText(canvas, center, dataSet.metadata!['centerText']);
      }
    }
  }
}
```

```dart
        }
```
```dart
        break;

        final data = dataSet.series.first.data;
        for (final point in data) {
          buffer.writeln('${point.x}占${point.label ?? "${point.y}%"}');
```

### 9.2 缓存管理器

```dart
class VizCacheManager {
  static final _instance = VizCacheManager._();
  factory VizCacheManager() => _instance;
  VizCacheManager._();

  /// L1 内存缓存
  final _memoryCache = LruCache<String, VizCacheEntry>(maxSize: 50);

  /// L2 渲染缓存
  final _renderCache = LruCache<String, ui.Picture>(maxSize: 20);

  /// 获取数据
  Future<VizDataSet?> get(String cacheKey) async {
    // L1 命中？
    final memEntry = _memoryCache.get(cacheKey);
    if (memEntry != null && !memEntry.isExpired) {
      return memEntry.dataSet;
    }

    // L3 SQLite 命中？
    final localData = await _loadFromSqlite(cacheKey);
    if (localData != null) {
      _memoryCache.put(cacheKey, localData);
      return localData.dataSet;
    }

    return null;
  }

  /// 写入缓存
  Future<void> put(String cacheKey, VizDataSet dataSet) async {
    final entry = VizCacheEntry(
      dataSet: dataSet,
      cachedAt: DateTime.now(),
      ttl: dataSet.ttl ?? const Duration(hours: 1),
    );
    _memoryCache.put(cacheKey, entry);

    // 异步写入 SQLite
    unawaited(_saveToSqlite(cacheKey, entry));
  }

  /// 使缓存失效
  void invalidate(String? pattern) {
    if (pattern == null) {
      _memoryCache.clear();
      _renderCache.clear();
    } else {
      _memoryCache.removeWhere((key, _) => key.contains(pattern));
      _renderCache.removeWhere((key, _) => key.contains(pattern));
    }
  }
}

class VizCacheEntry {
  final VizDataSet dataSet;
  final DateTime cachedAt;
  final Duration ttl;

  bool get isExpired => DateTime.now().difference(cachedAt) > ttl;
}
```

### 9.3 性能优化策略

| 策略 | 场景 | 实现方式 |
|------|------|----------|
| 数据降采样 | 折线图 > 300 点 | LTTB 算法保留视觉特征 |
| 惰性渲染 | 不可见图表 | `Visibility` 检测 + 延迟构建 |
| 渲染缓存 | 静态数据图表 | `CustomPaint` + `RepaintBoundary` + `Picture` 复用 |
| 分帧绘制 | 复杂热力图 | 按行分帧，每帧绘制不超过 8ms |
| 预计算 | 频繁访问的聚合数据 | 服务端预计算 + 定时刷新 |
| 数据差异更新 | 实时更新场景 | 只更新变化的数据点，不全量重绘 |

### 13.1 聚合任务注册

图表数据由服务端预计算或实时聚合，通过 Celery 任务统一调度。

```python
# viz/aggregation.py

from celery import shared_task
from datetime import datetime, timedelta
from django.db import connection

@shared_task(name="viz.aggregate_daily_metrics")
def aggregate_daily_metrics(user_id: int, date: str = None):
    """
    每日学习指标聚合（凌晨执行）
    为首页和学情分析预计算常用图表数据
    """
    target_date = date or datetime.now().strftime('%Y-%m-%d')

    with connection.cursor() as cursor:
        # 学习时长
        cursor.execute("""
            SELECT
                subject_code,
                ROUND(SUM(duration_sec) / 60.0, 1) as minutes,
                COUNT(*) as activity_count
            FROM learning_activity_log
            WHERE user_id = %s AND DATE(created_at) = %s
            GROUP BY subject_code
        """, [user_id, target_date])
        duration_by_subject = cursor.fetchall()

        # 正确率
        cursor.execute("""
            SELECT
                subject_code,
                COUNT(*) as total,
                SUM(CASE WHEN is_correct = 1 THEN 1 ELSE 0 END) as correct,
                ROUND(
                    SUM(CASE WHEN is_correct = 1 THEN 1 ELSE 0 END) * 100.0
                    / NULLIF(COUNT(*), 0), 1
                ) as accuracy
            FROM learning_activity_log
            WHERE user_id = %s AND DATE(created_at) = %s AND is_correct IS NOT NULL
            GROUP BY subject_code
        """, [user_id, target_date])
        accuracy_by_subject = cursor.fetchall()

    # 写入预计算表
    VizDailyMetric.objects.update_or_create(
        user_id=user_id,
        date=target_date,
        defaults={
            'duration_by_subject': duration_by_subject,
            'accuracy_by_subject': accuracy_by_subject,
        }
    )
```
