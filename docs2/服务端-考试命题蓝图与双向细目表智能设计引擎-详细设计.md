# 服务端-考试命题蓝图与双向细目表智能设计引擎-详细设计

## 1. 概述

### 1.1 功能定位

考试命题蓝图与双向细目表智能设计引擎是 PrimeTop 考试测评体系中的**命题规划层**核心服务。它位于知识点体系/课标数据库与智能组卷引擎之间，承担"教师在出卷前规划试卷结构"这一关键环节。

在中国教育评估标准中，**双向细目表**（Two-Way Specification Table）是命题工作的基础工具：以知识点为纵轴、认知层次为横轴，形成矩阵，明确每个单元格的题目数量、分值和题型分布。本引擎将该过程数字化、智能化，支持教师和内容团队高效编制标准化试卷蓝图，并驱动后续自动组卷。

### 1.2 核心价值

| 价值维度 | 说明 |
| --- | --- |
| 规范命题流程 | 将传统纸质双向细目表数字化，确保命题有据可依 |
| 知识点覆盖保障 | 直观展示试卷知识点覆盖率和认知层次分布 |
| 智能推荐 | 基于课标、历年真题和学情数据自动推荐细目表结构 |
| 组卷驱动 | 输出结构化蓝图，直接驱动智能组卷引擎生成试卷 |
| 版本管理 | 支持蓝图模板复用、版本对比和迭代优化 |

### 1.3 适用场景

- **教师周测/月考命题**：教师快速生成符合教学进度的试卷蓝图
- **期中/期末考试命题**：教研组协作设计标准化考试蓝图
- **中考/高考模拟卷命题**：对标真题结构和考点分布
- **单元练习/章节测试**：聚焦特定知识范围的微型蓝图
- **自适应测试蓝图池**：为自适应测试引擎预设多套蓝图模板

## 2. 核心概念

### 2.1 双向细目表（Two-Way Specification Table）

以知识点（纵向）× 认知层次（横向）构成的二维矩阵。每个单元格（Cell）定义了该知识点在该认知层次下的题目数量、分值和题型。

**示例（初中数学 一元二次方程 单元测试）：**

| 知识点 \ 认知层次 | 识记(A) | 理解(B) | 应用(C) | 分析(D) | 综合(E) | 评价(F) | 合计 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 一元二次方程概念 | 1题/3分 | 1题/3分 | — | — | — | — | 6分 |
| 解法（公式法/因式分解） | — | 1题/4分 | 2题/8分 | — | — | — | 12分 |
| 根的判别式 | — | 1题/3分 | 1题/5分 | 1题/8分 | — | — | 16分 |
| 实际应用题 | — | — | 1题/6分 | 1题/8分 | — | — | 14分 |
| 综合证明/探究 | — | — | — | — | 1题/12分 | — | 12分 |
| **合计** | **3分** | **10分** | **19分** | **16分** | **12分** | **0分** | **60分** |

### 2.2 布鲁姆认知目标分类

本系统采用修订版布鲁姆认知目标分类法（Anderson & Krathwohl, 2001），并结合中国课标进行本土化调整：

| 代码 | 认知层次 | 中文 | 说明 |
| --- | --- | --- | --- |
| A | Remember | 识记 | 提取、识别、回忆知识 |
| B | Understand | 理解 | 理解含义、解释、比较 |
| C | Apply | 应用 | 在新情境中执行、实施 |
| D | Analyze | 分析 | 分解、组织、归因 |
| E | Evaluate | 评价 | 检查、批判、评判 |
| F | Create | 创造 | 生成、规划、产出 |

> **课标映射**：系统内置课标条目到认知层次的默认映射。例如"了解"→A，"理解"→B，"掌握"→C，"灵活运用"→D~F。

### 2.3 命题蓝图（Test Blueprint）

命题蓝图是双向细目表的**完整封装**，包含：

- 基本信息（学科、年级、考试类型、总分、时长）
- 双向细目表矩阵
- 题型分布配置（选择/填空/解答等占比）
- 难度分布配置（容易/中等/困难占比）
- 知识点权重配置
- 组卷约束条件（重复题目排除、教材版本限定等）

### 2.4 蓝图模板

可复用的蓝图骨架，定义了特定考试类型的标准结构（如"初中数学期中考试标准模板"），教师可基于模板快速生成具体蓝图。

### 3.2 核心数据模型（领域对象）

```java
// ==================== 蓝图聚合根 ====================

public class ExamBlueprint {
    private Long id;
    private String blueprintCode;
    private String title;
    private String description;
    
    // 基本配置
    private String subjectCode;       // 学科
    private String gradeCode;         // 年级
    private String textbookVersion;   // 教材版本
    private ExamType examType;        // 考试类型
    private List<Long> chapterScope;  // 章节范围
    
    // 分值与时长
    private int totalScore;           // 总分
    private int totalDuration;        // 时长(分钟)
    
    // 难度分布
    private BigDecimal easyRatio;     // 容易 30%
    private BigDecimal mediumRatio;   // 中等 50%
    private BigDecimal hardRatio;     // 困难 20%
    
    // 细目表矩阵
    private List<BlueprintCell> cellMatrix;  // 知识点×认知层次
    
    // 题型分布
    private List<QuestionTypeDistribution> typeDistribution;
    
    // 状态
    private BlueprintStatus status;
    
    // 来源
    private SourceType sourceType;
    private Long sourceBlueprintId;
    
    // 审计
    private Long creatorId;
    private String creatorType;
    private int version;
    
    // 时间戳
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
    
    // ===== 领域方法 =====
    
    /**
     * 计算当前蓝图的总分校验
     */
    public int calculateActualTotalScore() {
        return cellMatrix.stream()
            .mapToInt(c -> c.getQuestionCount() * c.getScorePerQuestion().intValue())
            .sum();
    }
    
    /**
     * 验证蓝图一致性
     */
    public BlueprintValidationResult validate() {
        BlueprintValidationResult result = new BlueprintValidationResult();
        
        // 1. 总分校验: 细目表合计 = 配置总分
        int cellTotal = calculateActualTotalScore();
        if (cellTotal != totalScore) {
            result.addError("SCORE_MISMATCH", 
                String.format("细目表合计%d分与配置总分%d分不一致", cellTotal, totalScore));
        }
        
        // 2. 题型分布总分校验
        int typeTotal = typeDistribution.stream()
            .mapToInt(t -> t.getQuestionCount() * t.getScorePerQuestion().intValue())
            .sum();
        if (typeTotal != totalScore) {
            result.addError("TYPE_SCORE_MISMATCH",
                String.format("题型分布合计%d分与配置总分%d分不一致", typeTotal, totalScore));
        }
        
        // 3. 难度比例校验
        BigDecimal sumRatio = easyRatio.add(mediumRatio).add(hardRatio);
        if (sumRatio.compareTo(BigDecimal.ONE) != 0) {
            result.addError("RATIO_SUM_NOT_ONE",
                String.format("难度比例合计%s≠1.0", sumRatio));
        }
        
        // 4. 空单元格检查
        boolean hasEmptyCells = cellMatrix.stream()
            .anyMatch(c -> c.getQuestionCount() == 0);
        if (hasEmptyCells) {
            result.addWarning("EMPTY_CELLS", "存在题目数为0的单元格");
        }
        
        return result;
    }
    
    /**
     * 获取认知层次分值分布
     */
    public Map<CognitiveLevel, Integer> getCognitiveLevelDistribution() {
        return cellMatrix.stream()
            .collect(Collectors.groupingBy(
                BlueprintCell::getCognitiveLevel,
                Collectors.summingInt(c -> c.getQuestionCount() * c.getScorePerQuestion().intValue())
            ));
    }
}
```

## 6. 关键算法

### 6.1 知识点加权算法

```python
def calculate_knowledge_point_weights(
    knowledge_points: list[dict],
    chapter_scope: list[int],
    exam_type: str,
    grade_code: str,
    subject_code: str
) -> dict[int, float]:
    """
    计算范围内各知识点的权重(0-1)，用于智能推荐时分配分值。
    
    权重 = α1 * 课标重要度 + α2 * 历年频率 + α3 * 依赖深度 + α4 * 核心程度
    
    其中:
    - α1 = 0.35: 课标要求权重最高
    - α2 = 0.25: 历年考试频率
    - α3 = 0.20: 知识点被其他知识点依赖的深度(前置知识点)
    - α4 = 0.20: 章节核心程度
    """
    ALPHA = {"curriculum": 0.35, "frequency": 0.25, "dependency": 0.20, "core": 0.20}
    
    weights = {}
    for kp in knowledge_points:
        if kp["chapter_id"] not in chapter_scope:
            continue
            
        # 1. 课标重要度: 了解=0.3, 理解=0.5, 掌握=0.8, 灵活运用=1.0
        curr_score = {
            "understand_basics": 0.3,
            "understand": 0.5,
            "master": 0.8,
            "apply_flexibly": 1.0
        }.get(kp["curriculum_requirement"], 0.5)
        
        # 2. 历年考试频率: 基于历年真题中出现次数归一化
        freq_data = get_historical_frequency(
            kp["id"], subject_code, grade_code, exam_type, years=3
        )
        freq_score = min(freq_data["appearance_ratio"], 1.0)
        
        # 3. 依赖深度: 被多少其他知识点依赖
        dependents = get_knowledge_point_dependents(kp["id"])
        dep_score = min(len(dependents) / 10.0, 1.0)  # 归一化,上限10个依赖
        
        # 4. 章节核心程度: 是否为章节核心知识点
        core_score = 1.0 if kp["is_core_point"] else 0.3
        
        # 综合权重
        weight = (
            ALPHA["curriculum"] * curr_score +
            ALPHA["frequency"] * freq_score +
            ALPHA["dependency"] * dep_score +
            ALPHA["core"] * core_score
        )
        
        weights[kp["id"]] = round(weight, 4)
    
    # 归一化
    total = sum(weights.values())
    if total > 0:
        weights = {k: v / total for k, v in weights.items()}
    
    return weights
```

### 6.2 认知层次分配算法

```python
def assign_cognitive_levels(
    kp_weights: dict[int, float],
    target_distribution: dict[str, float],  # {"A": 0.10, "B": 0.20, ...}
    total_score: int,
    knowledge_points: list[dict]
) -> list[dict]:
    """
    根据知识点权重和目标认知分布，分配每个知识点在各认知层次的分值。
    
    策略:
    1. 对于高权重知识点，分配更多认知层次(C/D/E)
    2. 对于中等权重知识点，侧重中低层次(A/B/C)
    3. 对于低权重知识点，仅分配识记/理解(A/B)
    """
    cells = []
    
    # 按认知层次从高到低分配(F→A)
    level_order = ["F", "E", "D", "C", "B", "A"]
    remaining_score = total_score
    
    # 对知识点按权重排序
    sorted_kps = sorted(kp_weights.items(), key=lambda x: x[1], reverse=True)
    
    for level in level_order:
        level_target_score = int(total_score * target_distribution.get(level, 0))
        if level_target_score <= 0:
            continue
        
        allocated = 0
        for kp_id, weight in sorted_kps:
            if allocated >= level_target_score:
                break
            
            kp_info = next(kp for kp in knowledge_points if kp["id"] == kp_id)
            
            # 检查该知识点是否适合此认知层次
            max_level = get_max_cognitive_level_for_kp(kp_info)
            level_rank = "ABCDEF".index(level)
            max_rank = "ABCDEF".index(max_level)
            
            if level_rank > max_rank:
                continue  # 该知识点不适合此认知层次
            
            # 计算分配分值
            kp_share = min(
                level_target_score - allocated,
                max(3, int(total_score * weight * 2))  # 单知识点单层次上限
            )
            
            if kp_share > 0:
                question_count, score_per_q = optimize_question_split(
                    kp_share, level, kp_info
                )
                cells.append({
                    "knowledge_point_id": kp_id,
                    "cognitive_level": level,
                    "question_count": question_count,
                    "score_per_question": score_per_q,
                    "confidence": calculate_confidence(kp_info, level, kp_share)
                })
                allocated += question_count * score_per_q
                remaining_score -= question_count * score_per_q
    
    return cells


def optimize_question_split(
    target_score: int,
    cognitive_level: str,
    kp_info: dict
) -> tuple[int, float]:
    """
    优化题目数量和单题分值的组合。
    规则:
    - A/B层: 倾向多题少分(选择题/填空题, 3-5分)
    - C层: 中等题(计算题/应用题, 5-8分)
    - D/E/F层: 少题高分(解答题/证明题, 8-15分)
    """
    level_ranges = {
        "A": (2, 5),    # 2-5分/题
        "B": (3, 6),
        "C": (5, 8),
        "D": (8, 12),
        "E": (10, 15),
        "F": (12, 20),
    }
    
    min_score, max_score = level_ranges.get(cognitive_level, (3, 10))
    
    # 寻找最优的 count × score 组合
    best = None
    for score_per_q in range(min_score, max_score + 1):
        count = target_score / score_per_q
        if count == int(count) and int(count) > 0:
            best = (int(count), float(score_per_q))
            break
    
    if not best:
        # 无法整除,取最接近的
        score_per_q = max(min_score, min(max_score, target_score // 2))
        count = max(1, target_score // score_per_q)
        best = (count, float(score_per_q))
    
    return best
```

### 6.3 蓝图覆盖度计算

```python
def calculate_blueprint_coverage(
    blueprint_id: int,
    db_session
) -> CoverageReport:
    """
    计算蓝图的多维覆盖度报告。
    """
    blueprint = db_session.get(ExamBlueprint, blueprint_id)
    cells = db_session.query(BlueprintCell).filter_by(blueprint_id=blueprint_id).all()
    
    # 1. 知识点覆盖度
    all_kps = get_knowledge_points_in_scope(
        blueprint.subject_code,
        blueprint.grade_code,
        blueprint.chapter_scope
    )
    covered_kp_ids = set(c.knowledge_point_id for c in cells if c.question_count > 0)
    all_kp_ids = set(kp["id"] for kp in all_kps)
    
    kp_coverage = {
        "total": len(all_kp_ids),
        "covered": len(covered_kp_ids & all_kp_ids),
        "uncovered": len(all_kp_ids - covered_kp_ids),
        "ratio": len(covered_kp_ids & all_kp_ids) / max(len(all_kp_ids), 1)
    }
    
    # 2. 认知层次分布
    cognitive_dist = {}
    for cell in cells:
        if cell.question_count > 0:
            score = cell.question_count * cell.score_per_question
            cognitive_dist[cell.cognitive_level] = cognitive_dist.get(cell.cognitive_level, 0) + score
    
    # 3. 题库匹配度
    matched_cells = 0
    unmatched_cells = 0
    total_available = 0
    unmatched_details = []
    
    for cell in cells:
        if cell.question_count == 0:
            continue
        
        available = db_session.execute(
            """
            SELECT COUNT(*) as cnt FROM question q
            JOIN question_knowledge_point qkp ON q.id = qkp.question_id
            WHERE qkp.knowledge_point_id = :kp_id
              AND q.subject_code = :subject
              AND q.grade_code = :grade
              AND q.status = 'published'
              AND q.cognitive_level = :level
            """,
            {
                "kp_id": cell.knowledge_point_id,
                "subject": blueprint.subject_code,
                "grade": blueprint.grade_code,
                "level": cell.cognitive_level
            }
        ).scalar()
        
        if available >= cell.question_count:
            matched_cells += 1
            total_available += available
        elif available > 0:
            matched_cells += 1
            total_available += available
            unmatched_details.append({
                "knowledge_point_id": cell.knowledge_point_id,
                "cognitive_level": cell.cognitive_level,
                "needed": cell.question_count,
                "available": available,
                "shortage": cell.question_count - available
            })
        else:
            unmatched_cells += 1
            unmatched_details.append({
                "knowledge_point_id": cell.knowledge_point_id,
                "cognitive_level": cell.cognitive_level,
                "needed": cell.question_count,
                "available": 0,
                "shortage": cell.question_count
            })
    
    # 4. 难度匹配度
    difficulty_match = calculate_difficulty_match(cells, blueprint)
    
    return CoverageReport(
        knowledge_point_coverage=kp_coverage,
        cognitive_distribution=cognitive_dist,
        question_bank_match={
            "matched_cells": matched_cells,
            "unmatched_cells": unmatched_cells,
            "total_available": total_available,
            "unmatched_details": unmatched_details
        },
        difficulty_match=difficulty_match
    )
```

```java
/**
 * 将蓝图转换为智能组卷引擎可消费的约束格式。
 */
public class BlueprintToAssemblyConverter {
    
    public AssemblyRequest convert(ExamBlueprint blueprint) {
        AssemblyRequest req = new AssemblyRequest();
        
        // 基本约束
        req.setSubjectCode(blueprint.getSubjectCode());
        req.setGradeCode(blueprint.getGradeCode());
        req.setTextbookVersion(blueprint.getTextbookVersion());
        req.setTotalScore(blueprint.getTotalScore());
        req.setChapterScope(blueprint.getChapterScope());
        
        // 难度分布约束
        req.setDifficultyConstraints(new DifficultyConstraints(
            blueprint.getEasyRatio(),
            blueprint.getMediumRatio(),
            blueprint.getHardRatio()
        ));
        
        // 单元格约束 → 组卷约束
        List<QuestionConstraint> constraints = new ArrayList<>();
        
        for (BlueprintCell cell : blueprint.getCellMatrix()) {
            if (cell.getQuestionCount() == 0) continue;
            
            QuestionConstraint qc = QuestionConstraint.builder()
                .knowledgePointId(cell.getKnowledgePointId())
                .cognitiveLevel(cell.getCognitiveLevel())
                .requiredCount(cell.getQuestionCount())
                .scorePerQuestion(cell.getScorePerQuestion())
                .allowedQuestionTypes(cell.getQuestionTypes())
                .difficultyHint(cell.getDifficultyHint())
                .build();
            
            constraints.add(qc);
        }
        req.setQuestionConstraints(constraints);
        
        // 题型数量约束
        List<QuestionTypeConstraint> typeConstraints = blueprint.getTypeDistribution()
            .stream()
            .map(t -> new QuestionTypeConstraint(
                t.getQuestionType(),
                t.getQuestionCount(),
                t.getScorePerQuestion()
            ))
            .collect(Collectors.toList());
        req.setQuestionTypeConstraints(typeConstraints);
        
        // 全局约束
        req.setGlobalConstraints(GlobalConstraints.builder()
            .avoidDuplicateQuestions(true)
            .avoidDuplicateStems(true)
            .maxQuestionsFromSameSource(3)
            .requireAnswerExplanation(true)
            .build());
        
        return req;
    }
}
```

### 8.2 校验逻辑

```java
public class BlueprintValidator {
    
    /**
     * 提交审核前的完整校验
     */
    public ValidationResult validateForSubmit(ExamBlueprint blueprint) {
        ValidationResult result = new ValidationResult();
        
        // 1. 必填字段校验
        if (StringUtils.isBlank(blueprint.getTitle())) {
            result.addError("TITLE_REQUIRED", "蓝图标题不能为空");
        }
        if (blueprint.getChapterScope() == null || blueprint.getChapterScope().isEmpty()) {
            result.addError("CHAPTER_SCOPE_REQUIRED", "章节范围不能为空");
        }
        
        // 2. 分值一致性校验
        int cellTotal = blueprint.calculateActualTotalScore();
        if (cellTotal != blueprint.getTotalScore()) {
            result.addError("SCORE_MISMATCH", 
                String.format("细目表合计(%d)≠配置总分(%d)", cellTotal, blueprint.getTotalScore()));
        }
        
        // 3. 题型分布总分校验
        int typeTotal = blueprint.getTypeDistribution().stream()
            .mapToInt(t -> t.getQuestionCount() * t.getScorePerQuestion().intValue())
            .sum();
        if (typeTotal != blueprint.getTotalScore()) {
            result.addError("TYPE_DIST_SCORE_MISMATCH",
                String.format("题型分布合计(%d)≠配置总分(%d)", typeTotal, blueprint.getTotalScore()));
        }
        
        // 4. 难度比例校验
        BigDecimal ratioSum = blueprint.getEasyRatio()
            .add(blueprint.getMediumRatio())
            .add(blueprint.getHardRatio());
        if (ratioSum.compareTo(BigDecimal.ONE) != 0) {
            result.addError("RATIO_SUM_ERROR",
                String.format("难度比例合计(%s)≠1.0", ratioSum));
        }
        
        // 5. 覆盖率校验（建议值）
        CoverageReport coverage = calculateCoverage(blueprint);
        if (coverage.getKnowledgePointCoverage().getRatio() < 0.6) {
            result.addWarning("LOW_COVERAGE",
                String.format("知识点覆盖率仅%.1f%%，建议不低于60%%",
                    coverage.getKnowledgePointCoverage().getRatio() * 100));
        }
        
        // 6. 题库匹配校验
        if (coverage.getQuestionBankMatch().getUnmatchedCells() > 0) {
            result.addWarning("QUESTION_BANK_SHORTAGE",
                String.format("有%d个单元格题库无匹配题目", 
                    coverage.getQuestionBankMatch().getUnmatchedCells()));
        }
        
        // 7. 空蓝图校验
        if (blueprint.getCellMatrix().stream().allMatch(c -> c.getQuestionCount() == 0)) {
            result.addError("EMPTY_BLUEPRINT", "细目表不能为空");
        }
        
        return result;
    }
}
```

### 9.2 查询优化

```sql
-- 蓝图矩阵查询优化：使用单次查询获取完整矩阵
SELECT 
    bp.id, bp.title, bp.total_score,
    kp.id as kp_id, kp.name as kp_name, kp.chapter_id,
    c.cognitive_level, c.question_count, c.score_per_question,
    c.note, c.difficulty_hint

LEFT JOIN blueprint_cell c ON bp.id = c.blueprint_id AND c.question_count > 0

ORDER BY kp.sort_order, c.cognitive_level;
```
