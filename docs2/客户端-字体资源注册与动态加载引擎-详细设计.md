# 客户端-字体资源注册与动态加载引擎 - 详细设计

> **模块定位**：PrimeTop 客户端字体资产统一管理层，负责全 App 字体族注册表（FontFamily Registry）、字体包清单与版本管理、运行时按需加载与卸载、跨字体族回退链（Fallback Chain）、缺字检测（Glyph Coverage Check）、分学段字体档案（Font Profile）以及田字格/拼音等教学专用字体的渲染集成。
> **覆盖学段**：全学段（幼儿启蒙对教学楷体/拼音字体强依赖，高中对高密度正文与数学字体强依赖）
> **优先级**：P1（拼音识字启蒙、笔画练习、理科公式渲染均为 P0/P1 功能，其字体依赖需在本引擎上收敛；MVP 阶段需内置最小字体集）
> **技术栈**：Flutter 3.x + Dart 3.x，原生侧 Android（`FontsContractCompat`）/ iOS（`CTFontManagerRegisterFontsForURL`）按需桥接

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 统一注册 | 全 App 字体通过唯一 `FontRegistry` 注册，禁止业务代码直接硬编码 `fontFamily` 字符串 |
| 按需加载 | 教学楷体、拼音字体、数学字体等非首屏字体包按需下载/加载，降低安装包体积 |
| 缺字可感知 | 任何文本渲染前可查询覆盖情况，缺字自动触发回退或字体包加载，杜绝"口口"豆腐块 |
| 分学段档案 | 学段切换时一键切换默认字体档案（幼儿=大字+楷体，高中=高信息密度黑体） |
| 内存可控 | 字体包引用计数 + LRU 卸载，字体常驻内存预算 ≤ 18 MB |
| 版权合规 | 字体清单含许可证元数据，CI 阻断未登记许可证的字体进入构建 |
| 体验无损 | 字体加载采用"系统字体占位 → 就绪后无感替换"，避免白屏与布局跳变 |

## 2. 与现有模块的职责边界

本引擎是多个已细化模块共同依赖的底层能力，边界如下：

| 模块 | 已覆盖职责 | 本引擎职责 |
|------|-----------|-----------|
| 客户端主题引擎与动态外观系统 | 字号缩放（FontScaleController 0.8x~2.0x）、主题变体 | 字体**族**的选择、加载与回退；字号缩放叠加在本引擎输出的 TextStyle 之上 |
| 客户端应用包体积优化与资源管理策略 | 字体子集化工具链（pyftsubset、分学段字符集 charset/*.txt） | 子集化产物的**消费方**：按清单注册、校验、装载 |
| 客户端资源包下载管理器 | `font_asset` 类型资源包的下载/校验/解压通道 | 向其发起字体包下载请求，管理字体包的**生命周期状态** |
| 富文本与学科内容渲染引擎 | KaTeX/IPA/等宽字体在其渲染管线中的使用 | 为其提供 `resolveRuns()` 分段结果，保证公式、音标文本不缺字 |
| 汉字笔画顺序检测与评估系统 | 笔画轨迹比对、描红交互（基于 SVG 笔画数据） | 提供田字格组件、教学楷体字形与笔画演示用的轮廓字体资源 |
| 分龄UI适配与交互设计规范 | 各学段字号阶梯（sp 定义） | 学段默认字体族档案（FontProfile），与字号阶梯正交组合 |
| 护眼模式与视觉健康管理系统 | 色温/亮度调节 | 护眼阅读字体档案（衬线体可选）与字重克制策略 |

**约定**：业务侧任何 `TextStyle(fontFamily: ...)` 必须来自 `FontRegistry.resolve(...)` 返回的常量，代码评审与 lint 规则强制（见 §13.4）。

### 3.2 字重与变体约定

每个 familyId 下按 Flutter `FontWeight` 暴露变体，变体文件在 manifest 中声明：

```
pt_sans:
  w400: pt_sans_common_w400.woff2
  w500: pt_sans_common_w500.woff2   // 小标题
  w700: pt_sans_common_w700.woff2   // 强调/按钮
pt_kai_edu:
  w400: pt_kai_1500_w400.woff2      // 楷体仅常规字重，不做伪粗
```

规则：
1. 楷体、拼音字体**禁止伪粗**（synthetic bold），缺字重时回退正常字重 + 颜色强调。
2. 变体缺失时 `FontRegistry.resolve()` 自动降级到该族最近可用字重。

### 4.2 字体包清单（FontPackManifest）

字体构建管线输出 `font_manifest.json`，随主包与各字体资源包分发：

```json
{

  "generatedAt": "2026-08-14T10:00:00+08:00",
  "families": [
    {
      "familyId": "pt_kai_edu",
      "displayName": "教学楷体",
```

字段约定：
- `manifestVersion`：整数，破坏性变更（字段删除/语义变化）时 +1，客户端遇不兼容版本拒绝加载并按 §11.4 降级。
- `packId` 与资源包下载管理器的 `font_asset` 包 ID 一一对应，版本号复用资源包版本，不做独立版本线。

## 5. 架构分层

```
┌────────────────────────────────────────────────────────────┐
│  业务消费层：识字卡片 / 田字格组件 / 公式渲染 / 阅读器 / AI对话    │
│      PTFontText / PTTextStyle / TianzigeChar / resolveRuns  │
├────────────────────────────────────────────────────────────┤
│  字体引擎层 (Font Engine)                                    │
│  FontRegistry        字体族注册表与查询                        │
│  FontLoader          运行时加载/卸载（引用计数 + LRU）           │
│  FontCoverageIndex   缺字检测（coverage.bin 二分查询）           │
│  FallbackResolver    回退链解析与文本分段（TextRun 切分）          │
│  FontProfileManager  学段档案管理与切换                          │
├────────────────────────────────────────────────────────────┤
│  基础设施层                                                   │
│  资源包下载管理器(packId)   本地文件与MD5校验   远程配置(profile覆盖) │
│  平台通道：FontNativeApi（Android FontsContract / iOS CTFont） │
│  Flutter services.FontLoader（运行时族注册）                    │
└────────────────────────────────────────────────────────────┘
```

加载路径两条：
1. **bundled/staged 主包子集**：经 `pubspec.yaml` 声明，Flutter 启动时自动注册，本引擎只登记 spec 与 coverage 索引，不重复加载。
2. **pack 路径**：`FontLoader`（`package:flutter/services.dart`）从本地资源包目录读 bytes 动态注册；Android 大字体包（>5MB 全量）可走原生 `FontsContractCompat` 系统字体下载通道，iOS 走 `CTFontManagerRegisterFontsForURL`，经平台通道桥接（§9.3）。

## 6. 关键机制设计

### 6.1 FontRegistry（注册与查询）

```dart
// lib/core/font/font_registry.dart
class FontRegistry {
  FontRegistry._();
  static final FontRegistry instance = FontRegistry._();

  final Map<String, FontFamilySpec> _specs = {};
  final FontCoverageIndex _coverage = FontCoverageIndex();
  final Map<String, String> _loadedFamilies = {}; // familyId -> version token

  /// 启动初始化：读内置 manifest，登记全部 spec
  Future<void> initialize({
    required AssetBundle bundle,
    required FontPackStore packStore,   // 封装资源包下载管理器
  }) async {
    final manifest = FontManifestCodec.decode(
      await bundle.loadString('assets/fonts/font_manifest.json'));
    for (final f in manifest.families) {
      _specs[f.familyId] = f;
    }
    await _coverage.loadBundleIndexes(bundle, manifest);
    // bundled 家族直接视为已加载
    for (final f in manifest.families.where((s) => s.delivery != FontDelivery.pack)) {
      _loadedFamilies[f.familyId] = 'bundled';
    }
  }

  bool isLoaded(String familyId) => _loadedFamilies.containsKey(familyId);

  /// 解析场景→字体族，返回安全的 family 字符串（未加载时回退 profile 链）
  String resolve({
    required FontScene scene,        // body/display/hanziCard/pinyin/formula/reading/code
    FontProfile? profile,
  }) {
    final p = profile ?? FontProfileManager.instance.current;
    final chain = FallbackResolver.buildChain(scene: scene, profile: p);
    for (final family in chain) {
      if (isLoaded(family)) return family;
    }
    return 'system'; // 兜底：null fontFamily → 平台默认字体
  }
}
```

### 6.2 FontCoverageIndex（缺字检测）

**构建期**：`scripts/export_coverage.py` 在子集化同时，用 fontTools 导出每个字体的码点覆盖，压缩为紧凑位图 `coverage.bin`（BMP 全平面 65536 bit = 8KB/字体族，扩展平面按区间段存储）。

**运行期**：`O(1)` 位查询：

```dart
class FontCoverageIndex {
  /// familyId -> BMP 位图（Uint8List 8KB）+ 扩展平面区间表
  final Map<String, (_Bitmap bmp, List<(_Range r)> ext)> _index = {};

  bool covers(String familyId, int codePoint) {
    final e = _index[familyId];
    if (e == null) return false;
    if (codePoint < 0x10000) return e.$1.get(codePoint);
    return e.$2.any((r) => r.contains(codePoint));
  }

  /// 检查一段文本在字体族下的缺字码点（去重）
  List<int> missingCodePoints(String familyId, String text) { ... }
}
```

**触发动作**（由 FallbackResolver 编排）：

| 缺字来源 | 动作 |
|----------|------|
| `pt_sans` 缺字（生僻字、初高中扩展字） | 静默触发 `pt_sans_ext` 资源包下载，就绪前先用系统字体渲染该字 |
| `pt_kai_edu` 缺字（生字表外汉字） | 触发 `pt_kai_ext` 下载，期间该字用 `pt_sans` 显示并弱高亮提示 |
| `pt_math`/`pt_ipa` 缺字 | 上报埋点 `font_glyph_missing`，由内容侧修 charset 后重出包 |
| 任何字体缺 emoji | 直接交给系统 emoji 字体（Flutter 默认回退，不需处理） |

### 6.3 FallbackResolver（回退链与文本分段）

对"混合文本"（如古诗注音排版：`瞳tóng 日rì`、理科题干夹公式 `求 ∠ABC`）按码点切分为 runs，每段绑定首个覆盖它的字体族：

```dart
class TextRun {
  final String text;
  final String family;       // 解析后的 fontFamily
  const TextRun(this.text, this.family);
}

class FallbackResolver {
  /// 核心：将混合文本按字体覆盖切分，输出可直接构造 TextSpan 的段
  static List<TextRun> resolveRuns(String text, {required List<String> chain}) {
    final runs = <TextRun>[];
    final buf = StringBuffer();
    String? currentFamily;
    for (final rune in text.runes) {
      String? family;
      for (final f in chain) {
        if (FontRegistry.instance.isLoaded(f) &&
            FontCoverageIndex.instance.covers(f, rune)) {
          family = f;
          break;
        }
      }
      family ??= 'system'; // 链上全部不覆盖 → 系统/emoji 兜底
      if (currentFamily != null && family != currentFamily) {
        runs.add(TextRun(buf.toString(), currentFamily));
        buf.clear();
      }
      currentFamily = family;
      buf.writeCharCode(rune);
    }
    if (buf.isNotEmpty && currentFamily != null) {
      runs.add(TextRun(buf.toString(), currentFamily));
    }
    return runs;
  }
}
```

### 6.4 FontLoader（运行时加载与卸载）

```dart
// lib/core/font/font_loader.dart
class PtFontLoader {
  PtFontLoader._();
  static final instance = PtFontLoader._();

  final _refCounts = <String, int>{};              // familyId -> 引用计数
  final _loading = <String, Future<bool>>{};       // 去重并发加载
  final _lru = <String>{};                         // 引用归零后的候选淘汰序
  static const memBudgetBytes = 18 * 1024 * 1024;  // 常驻内存预算

  /// 业务方声明依赖（进入识字模块页面时调用）
  Future<bool> acquire(String familyId) async {
    _refCounts[familyId] = (_refCounts[familyId] ?? 0) + 1;
    _lru.remove(familyId);
    return _ensureLoaded(familyId);
  }

  /// 离开页面释放引用；引用归零进入 LRU 候选
  void release(String familyId) {
    final n = (_refCounts[familyId] ?? 1) - 1;
    if (n <= 0) {
      _refCounts.remove(familyId);
      _lru.add(familyId);
      _evictIfNeeded();
    } else {
      _refCounts[familyId] = n;
    }
  }

  Future<bool> _ensureLoaded(String familyId) async {
    if (FontRegistry.instance.isLoaded(familyId)) return true;
    return _loading.putIfAbsent(familyId, () => _doLoad(familyId))
        .whenComplete(() => _loading.remove(familyId));
  }

  Future<bool> _doLoad(String familyId) async {
    final spec = FontRegistry.instance.specOf(familyId);
    // 1. 确保资源包就位（对接资源包下载管理器；内置/主包子集直接跳过）
    if (spec.delivery != FontDelivery.bundled) {
      final ok = await FontPackStore.instance.ensurePack(spec.packId!);
      if (!ok) return false; // 下载失败 → 上层按 §11 降级
    }
    // 2. 校验 MD5 后动态注册（pack 路径的变体文件）
    for (final v in spec.variants) {
      final bytes = await FontPackStore.instance.readVariant(spec, v);
      if (md5Of(bytes) != v.md5) {
        await FontPackStore.instance.invalidatePack(spec.packId!);
        return false; // 损坏 → 删除包，走重下流程
      }
      final loader = services.FontLoader(_flutterFamilyName(familyId, v.weight));
      loader.addFont(Future.value(ByteData.view(bytes.buffer.asByteData())));
      await loader.load();
    }
    await FontCoverageIndex.instance.attachPackIndex(spec.coverageFile);
    FontRegistry.instance.markLoaded(familyId);
    Telemetry.track('font_pack_loaded', {'family': familyId});
    return true;
  }

  /// 内存超预算时从头淘汰 LRU 候选（系统字体兜底，不会空白）
  void _evictIfNeeded() { /* 估算已载入族体积和，超预算则通知引擎降级并释放 */ }
}
```

要点：
- **Flutter 平台限制**：`FontLoader.load()` 注册的族无法真正卸载（引擎缓存 glyph），因此"卸载"实现为：从 Registry 标记 `unloaded`，后续 resolve 不再命中；物理内存依赖引擎 LRU。该限制在 §13.3 监控项中单独观察。
- 变体注册名规则：`_flutterFamilyName('pt_sans', w700)` → `pt_sans`（Flutter 支持 `fontFamilyFallback` 内按 wght 变体声明；动态注册按字重分别建族时输出 `pt_sans_w700`，由 `resolve()` 内聚映射）。

### 6.5 FontProfileManager（学段档案切换）

```dart
class FontProfileManager with ChangeNotifier {
  static final instance = FontProfileManager._();
  FontProfile _current = FontProfiles.primary;

  FontProfile get current => _current;

  /// 学段切换（对接"学段年级切换引导"流程）：切换档案 + 预取目标学段字体包
  Future<void> applyStage(String stageKey /* kid|primary|junior|senior */) async {
    _current = switch (stageKey) {
      'kid' => FontProfiles.kid,
      'primary' => FontProfiles.primary,
      'junior' => FontProfiles.junior,
      'senior' => FontProfiles.senior,
      _ => FontProfiles.primary,
    };
    await persist();
    notifyListeners(); // 全局 TextStyle 重建（主题引擎同款无感刷新方案）
    unawaited(_prefetch(_current)); // 静默预取扩展包，失败不打扰
  }
}
```

远程配置下发档案覆盖：启动配置聚合接口返回 `fontProfileOverride` 时合并（如 A/B 实验给高中用户试衬线正文），本地默认值兜底。

## 7. 业务组件与渲染集成

### 7.1 PTFontText / PTTextStyle（统一出口组件）

```dart
/// 业务侧唯一合法的文本出口：自动处理场景解析、回退分段、字号缩放联动
class PTFontText extends StatelessWidget {
  final String text;
  final FontScene scene;
  final double fontSize;            // 逻辑 sp，由分龄UI字号阶梯常量传入
  final FontWeight? weight;
  final Color? color;

  const PTFontText(this.text, {super.key, required this.scene,
      required this.fontSize, this.weight, this.color});

  @override
  Widget build(BuildContext context) {
    final profile = FontProfileManager.instance.current;
    final chain = FallbackResolver.buildChain(scene: scene, profile: profile);
    final runs = FallbackResolver.resolveRuns(text, chain: chain);
    final scale = ThemeEngine.instance.fontScale; // 主题引擎字号缩放
    return Text.rich(
      TextSpan(children: [
        for (final r in runs)
          TextSpan(
            text: r.text,
            style: TextStyle(
              fontFamily: r.family == 'system' ? null : r.family,
              fontSize: fontSize * scale,
              fontWeight: weight ?? FontWeight.w400,
              color: color,
            ),
          ),
      ]),
    );
  }
}
```

### 7.3 拼音注音排版约定

- 拼音一律使用预组合字符（`ǎ U+01CE`），**禁止** `a` + U+030C 组合序列（部分字体组合标记渲染异常）。
- 内容管线（题库/识字内容生产）输出拼音前经 `PinyinNormalizer.normalize()`（NFC + 预组合映射），该规则同步登记在"教育内容结构化模板引擎"的校验项中。
- 注音排版（字上标注）由识字模块自绘 `Stack` 实现，字体统一 `pt_pinyin`，字回退链 `['pt_pinyin', 'pt_sans', 'system']`。

## 8. API 设计

### 8.1 Dart SDK（客户端内部）

| API | 签名 | 说明 |
|-----|------|------|
| 初始化 | `FontRegistry.instance.initialize({bundle, packStore})` | App 启动管线 `FontsStage`（早于首页渲染，见"客户端应用启动流程与初始化管线"） |

| 档案切换 | `FontProfileManager.instance.applyStage(stageKey)` | 学段升迁流程调用 |
| 预取 | `FontRegistry.instance.prefetchForScene(scene)` | 首页预测下一步场景（衔接"学习内容预加载策略"） |

### 8.3 平台通道（FontNativeApi）

```dart
// 大体积字体（>5MB 全量楷体/扩展黑体）走系统级通道，避免 Flutter 引擎双份缓存
class FontNativeApi {
  static const _ch = MethodChannel('primetop/font');

  /// Android: FontsContractCompat.requestFont / iOS: CTFontManager 下载并注册
  static Future<bool> registerSystemFont({required String query}) =>
      _ch.invokeMethod<bool>('registerSystemFont', {'query': query}) ?? false;

  /// 查询系统已装教学字体（华为/荣耀部分机型预装楷体，可直接复用省流量）
  static Future<List<String>> availableSystemFonts() =>
      _ch.invokeListMethod<String>('availableSystemFonts') ?? [];
}
```

Android `query` 使用 Google Fonts Provider `com.google.android.gms.fonts` 的 cert 流程或厂商字体包名；iOS 使用 `CTFontManagerUIFontType` 可下载字体 API。通道实现放入"Flutter平台通道与原生能力桥接层"注册表。

## 9. 状态流转

### 9.1 字体包生命周期状态机

```
                 ┌────────────┐
                 │ NotInStock │ (pack 未下载)
                 └─────┬──────┘
        acquire()/缺字触发 │  ensurePack()
                 ┌─────▼──────┐  下载失败(可重试)
                 │ Downloading│──────────────┐
                 └─────┬──────┘              │ 重试次数<3
                 校验MD5│                     ├──→ Failed ──(退避重试/用户点重试)──→ Downloading
                 ┌─────▼──────┐  MD5不符      │
                 │ Verifying  │────(删包重下)─┤
                 └─────┬──────┘              │
              FontLoader│注册                 │(重试耗尽)
                 ┌─────▼──────┐         ┌────▼─────┐
                 │  Loading   │────────▶│Degraded* │ 系统字体兜底渲染
                 └─────┬──────┘ 引擎异常  └──────────┘
                 ┌─────▼──────┐
                 │   Ready    │ ⇄ (release→引用0) → Evictable → LRU淘汰→NotInStock
                 └────────────┘
* Degraded 不阻塞业务；对应 PTFontText 自动用回退链渲染，页面展示可重试提示由宿主模块决定
```

状态机事件埋点：`font_pack_state_change {family, from, to, reason}`，对齐"学习行为事件标准化Schema注册中心"的事件规范。

### 9.2 引用计数泄漏防护

- Route 级别封装 `FontScope(familyIds: [...], child: ...)` Widget：`initState` 批量 acquire，`dispose` 批量 release。
- Debug 模式 `FontLeakDetector`：页面 pop 后 5s 仍有计数 >0 输出警告日志（接入"客户端全局异常处理"的 dev 日志通道）。

## 10. 错误处理

| 场景 | 检测点 | 处理策略 | 用户感知 |
|------|--------|----------|----------|
| 字体包下载失败 | 资源包管理器回调 | 指数退避自动重试 3 次；仍失败进入 Degraded | 系统字体显示，无阻断弹窗；识字模块提示"标准字体下载中" |
| MD5 校验失败 | `_doLoad` 步骤2 | 删包重下 1 次；连续失败标记包损坏上报 | 同上 |
| manifest 版本不兼容 | `FontManifestCodec.decode` | 使用内置 manifest 兜底，忽略远端 | 无感 |
| 远端 manifest 拉取失败 | 启动配置聚合 | 本地缓存 manifest 继续运行 | 无感 |
| 缺字（回退链全不覆盖） | `resolveRuns` | 系统/emoji 字体兜底 + 埋点上报码点 | 个别字符字体风格不一致 |
| 内存告警（系统 onMemoryPressure） | 引擎监听 | 立即清空 LRU 候选并降级非当前学段族 | 无感 |
| 商业字体授权到期 | 启动时检查 `license.expireAt` | 停用该族并回退 OFL 备选（霞鹜文楷），管理后台告警 | 字形风格微变 |
| 热更包回滚 | 资源包版本回退 | 本地旧版本字体包保留 2 个版本不删除 | 无感 |

## 12. 版权与许可证合规

1. 所有内置/下发的字体必须在 `font_manifest.json` 登记 `license`，许可证全文打包进 `ABOUT_FONTS.md` 随包分发（OFL 要求保留版权声明）。
2. CI 门禁 `font_license_check`：新增字体未登记许可证或授权文件缺失 → 构建失败。
3. 商业教学楷体若采购：登记授权范围（App 分发）、到期时间；到期前 90 天在"管理后台-系统监控工作台"产生待办。
4. OFL 字体再分发不得改名出售；子集化后的字体保留原 name table 版权字段（子集化脚本 `--name-IDs=*` 已保证，见包体积优化文档 §5.2）。

## 13. 测试要点

1. **覆盖索引一致性**：单测对比 coverage.bin 与实际字体文件 cmap（fontTools 导出金标），防止子集化脚本与索引导出漂移。
2. **混合文本分段**：`瞳tóng 日rì 求∠ABC=30° 😊` 等 fixture 断言 run 切分与族绑定。
3. **弱网加载**：500kbps 限速下进入识字模块，占位渲染正常、无白屏、重试可达。
4. **引用计数**：页面快速进出 100 次，计数归零、无泄漏告警。
5. **学段切换**：kid↔senior 切换后全局默认族正确，A/B override 下发生效与回滚。
6. **lint 门禁**：自定义 dart analyzer plugin 禁止业务代码出现裸 `fontFamily: 'xxx'` 字面量（白名单：本引擎与主题引擎）。
7. **内存压力**：iOS 模拟器 memory warning 后 LRU 生效、无 OOM。
