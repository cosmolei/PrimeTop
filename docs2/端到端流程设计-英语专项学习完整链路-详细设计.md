# 端到端流程设计 - 英语专项学习完整链路 - 详细设计

## 1. 文档定位

### 1.1 目的

本文档描述"英语专项学习"功能的**完整端到端链路**，从用户进入英语学习模块到最终英语能力画像更新的全过程，覆盖客户端、API网关、服务端各微服务的协作流程、数据流转、错误处理和降级策略。

英语专项学习包含 **词汇记忆、听力训练、阅读理解、口语陪练、语法讲解** 五大子能力模块，本文档聚焦这些子模块的**跨模块集成与端到端编排**，以及各子模块间的数据共享和能力联动。

各子模块的内部详细设计请参考对应文档，本文档不重复描述子模块内部实现。

### 3.3 关键数据结构

#### 3.3.1 词汇学习计划响应

```typescript
interface VocabDailyPlanResponse {
  date: string;                           // "2026-06-02"
  newWords: VocabWordItem[];              // 当日新词列表
  reviewWords: VocabReviewItem[];         // 当日复习队列
  stats: {
    totalMastered: number;                // 已掌握总数
    totalLearning: number;                // 学习中总数
    totalNew: number;                     // 待学习总数
    streakDays: number;                   // 连续学习天数
    todayCompleted: number;               // 今日已完成
    todayTarget: number;                  // 今日目标
  };
}

interface VocabWordItem {
  wordId: number;
  word: string;
  phoneticUs: string;
  phoneticUk: string;
  pos: string;                            // 词性
  definitions: Array<{
    pos: string;
    zh: string;
    en?: string;
  }>;
  examples: Array<{
    en: string;
    zh: string;
    audioUrl: string;
  }>;
  audioUrl: string;                       // 标准发音
  difficulty: number;                     // 1-10
  cefrLevel: string;                      // A1-C2
  status: 'NEW' | 'LEARNING' | 'MASTERED' | 'FAILED';
  nextReviewAt?: string;                  // 下次复习时间
}

interface VocabReviewItem extends VocabWordItem {
  reviewCount: number;                    // 已复习次数
  lastResult: 'CORRECT' | 'WRONG' | 'PARTIAL';
  intervalDays: number;                   // 当前间隔天数
}
```

#### 3.3.2 词汇学习结果提交

```typescript
interface VocabLearnResultRequest {
  wordId: number;
  result: 'CORRECT' | 'WRONG' | 'PARTIAL' | 'SKIP';
  responseTimeMs: number;                 // 响应耗时
  practiceType: 'CARD' | 'SPELL' | 'CHOICE' | 'DICTATION' | 'CONTEXT';
  sessionId: string;                      // 学习会话ID
  clientTimestamp: string;
}

interface VocabLearnResultResponse {
  success: boolean;
  wordStatus: string;                     // 更新后的状态
  nextReviewAt: string;                   // 下次复习时间
  masteryProgress: number;                // 掌握度进度 0-100
  earnedPoints: number;                   // 获得积分
  streakUpdated: boolean;                 // 是否更新连续天数
}
```

```java
@Service
public class EnglishHomeAggregationService {

    @Autowired
    private UserProfileClient profileClient;
    @Autowired
    private VocabularyServiceClient vocabClient;
    @Autowired
    private LearningRecordClient recordClient;
    @Autowired
    private StudyAnalysisClient analysisClient;
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    private static final String HOME_CACHE_KEY = "english:home:%d";
    private static final Duration CACHE_TTL = Duration.ofMinutes(5);

    public EnglishHomeResponse getHomePage(Long userId, boolean forceRefresh) {
        // 1. 尝试缓存
        if (!forceRefresh) {
            EnglishHomeResponse cached = (EnglishHomeResponse) redisTemplate
                .opsForValue()
                .get(String.format(HOME_CACHE_KEY, userId));
            if (cached != null) {
                return cached;
            }
        }

        // 2. 并行请求各服务
        CompletableFuture<UserProfile> profileFuture = 
            CompletableFuture.supplyAsync(() -> profileClient.getProfile(userId));
        CompletableFuture<EnglishAbilityProfile> abilityFuture = 
            CompletableFuture.supplyAsync(() -> analysisClient.getEnglishAbility(userId));
        CompletableFuture<VocabDailyPlan> vocabPlanFuture = 
            CompletableFuture.supplyAsync(() -> vocabClient.getDailyPlan(userId));
        CompletableFuture<List<LearningRecord>> recentRecordsFuture = 
            CompletableFuture.supplyAsync(() -> recordClient.getRecentRecords(userId, 7));
        CompletableFuture<List<TodayTask>> tasksFuture = 
            CompletableFuture.supplyAsync(() -> generateTodayTasks(userId));

        // 3. 等待全部完成（设置超时）
        CompletableFuture.allOf(profileFuture, abilityFuture, vocabPlanFuture,
                recentRecordsFuture, tasksFuture)
            .orTimeout(3, TimeUnit.SECONDS)
            .join();

        // 4. 组装响应
        EnglishHomeResponse response = EnglishHomeResponse.builder()
            .profile(buildProfileInfo(profileFuture.join()))
            .abilityOverview(buildAbilityOverview(abilityFuture.join()))
            .todayTasks(tasksFuture.join())
            .recentActivities(buildRecentActivities(recentRecordsFuture.join()))
            .continueLearning(buildContinueLearning(recentRecordsFuture.join()))
            .quickEntries(buildQuickEntries(vocabPlanFuture.join(), abilityFuture.join()))
            .weakPoints(buildWeakPoints(abilityFuture.join()))
            .build();

        // 5. 写入缓存
        redisTemplate.opsForValue().set(
            String.format(HOME_CACHE_KEY, userId), response, CACHE_TTL);

        return response;
    }

    private List<TodayTask> generateTodayTasks(Long userId) {
        List<TodayTask> tasks = new ArrayList<>();
        
        // 从各模块收集待办事项
        VocabDailyPlan vocabPlan = vocabClient.getDailyPlan(userId);
        if (vocabPlan.getReviewCount() > 0) {
            tasks.add(TodayTask.builder()
                .type("VOCAB_REVIEW")
                .title("词汇复习")
                .subtitle(vocabPlan.getReviewCount() + "个单词待复习")
                .estimatedMinutes((int) Math.ceil(vocabPlan.getReviewCount() / 10.0) * 5)
                .priority(100)
                .completed(false)
                .deepLink("/english/vocab/review")
                .build());
        }
        if (vocabPlan.getNewWordCount() > 0) {
            tasks.add(TodayTask.builder()
                .type("VOCAB_NEW")
                .title("学习新词")
                .subtitle(vocabPlan.getNewWordCount() + "个新词待学习")
                .estimatedMinutes((int) Math.ceil(vocabPlan.getNewWordCount() / 5.0) * 3)
                .priority(90)
                .completed(false)
                .deepLink("/english/vocab/learn")
                .build());
        }
        
        // 基于薄弱维度推荐专项练习
        EnglishAbilityProfile ability = analysisClient.getEnglishAbility(userId);
        addWeakPointTasks(tasks, ability);
        
        // 按优先级排序
        tasks.sort(Comparator.comparingInt(TodayTask::getPriority).reversed());
        return tasks;
    }
```

```java
@Service
public class VocabularyLearnResultHandler {

    @Autowired
    private VocabWordRepository wordRepository;
    @Autowired
    private SpacedRepetitionClient srClient;
    @Autowired
    private EventBusClient eventBus;
    @Autowired
    private MistakeServiceClient mistakeClient;
    @Autowired
    private PointsServiceClient pointsClient;

    @Transactional
    public VocabLearnResultResponse handleLearnResult(Long userId, VocabLearnResultRequest request) {
        // 1. 查询单词当前状态
        UserVocabWord userWord = wordRepository.findByUserIdAndWordId(userId, request.getWordId())
            .orElseThrow(() -> new BusinessException(5001, "单词不存在"));

        // 2. 更新掌握度
        int masteryDelta = calculateMasteryDelta(request.getResult(), userWord.getStatus());
        userWord.updateMastery(masteryDelta);
        userWord.updateStatusBasedOnResult(request.getResult());

        // 3. 间隔重复调度
        ScheduleResult scheduleResult = srClient.schedule(
            userWord.getSrCardId(), request.getResult(), request.getResponseTimeMs());
        userWord.setNextReviewAt(scheduleResult.getNextReviewAt());
        userWord.setReviewIntervalDays(scheduleResult.getIntervalDays());

        wordRepository.save(userWord);

        // 4. 异步处理
        CompletableFuture.runAsync(() -> {
            // 4a. 错误时收录错题
            if (request.getResult() == Result.WRONG) {
                mistakeClient.addMistake(MistakeItem.builder()
                    .userId(userId)
                    .sourceModule("VOCAB")
                    .questionType(request.getPracticeType().name())
                    .questionContent(userWord.getWord())
                    .userAnswer("(错误)")
                    .correctAnswer(userWord.getWord() + " - " + userWord.getDefinitionZh())
                    .errorTags(List.of("词汇记忆"))
                    .build());
            }

            // 4b. 发布事件
            eventBus.publish(VocabularyLearnedEvent.builder()
                .userId(userId)
                .wordId(request.getWordId())
                .word(userWord.getWord())
                .result(request.getResult())
                .practiceType(request.getPracticeType().name())
                .masteryDelta(masteryDelta)
                .build());

            // 4c. 积分奖励
            int points = calculatePoints(request.getResult(), request.getPracticeType());
            if (points > 0) {
                pointsClient.earnPoints(userId, "VOCAB_LEARN", points);
            }
        });

        // 5. 构建响应
        return VocabLearnResultResponse.builder()
            .success(true)
            .wordStatus(userWord.getStatus().name())
            .nextReviewAt(userWord.getNextReviewAt().toString())
            .masteryProgress(userWord.getMastery())
            .earnedPoints(calculatePoints(request.getResult(), request.getPracticeType()))
            .streakUpdated(checkStreakUpdate(userId))
            .build();
    }

    private int calculateMasteryDelta(Result result, WordStatus currentStatus) {
        return switch (result) {
            case CORRECT -> currentStatus == WordStatus.NEW ? 30 : 15;
            case PARTIAL -> 5;
            case WRONG -> -10;
            case SKIP -> 0;
        };
    }

    private int calculatePoints(Result result, PracticeType type) {
        if (result == Result.WRONG || result == Result.SKIP) return 0;
        return switch (type) {
            case CARD -> 2;
            case SPELL -> 5;
            case CHOICE -> 3;
            case DICTATION -> 5;
            case CONTEXT -> 4;
        };
    }
}
```

### 14.3 口语对话轮次处理

```java
@Service
public class OralDialogueService {

    @Autowired
    private AsrTtsClient asrTtsClient;
    @Autowired
    private AiDialogueClient aiDialogueClient;
    @Autowired
    private OralSessionRepository sessionRepository;

    @Async
    public CompletableFuture<OralTurnResponse> processTurn(Long userId, OralTurnRequest request) {
        String sessionId = request.getSessionId();
        OralSession session = sessionRepository.findById(sessionId)
            .orElseThrow(() -> new BusinessException(5060, "口语会话不存在"));

        // 1. ASR识别
        AsrResult asrResult = asrTtsClient.recognize(
            request.getAudioBlob(), request.getAudioFormat(), "en-US");
        String recognizedText = asrResult.getText();

        // 2. 并行: 发音评测 + AI回复
        CompletableFuture<PronunciationResult> pronunciationFuture = 
            CompletableFuture.supplyAsync(() -> {
                if (session.getMode() == OralMode.PRONUNCIATION_TEST) {
                    return asrTtsClient.evaluatePronunciation(
                        request.getAudioBlob(), session.getTargetText(), "en-US");
                }
                return asrTtsClient.evaluatePronunciation(
                    request.getAudioBlob(), recognizedText, "en-US");
            });

        CompletableFuture<AiResponse> aiFuture = 
            CompletableFuture.supplyAsync(() -> 
                aiDialogueClient.chat(session.getDialogueId(), recognizedText));

        // 等待AI回复
        AiResponse aiResponse = aiFuture.join();

        // 3. TTS合成AI回复语音
        String audioUrl = asrTtsClient.synthesize(
            aiResponse.getText(), "en-US", "female", "standard");

        // 4. 表达改进建议
        List<ExpressionTip> tips = generateExpressionTips(recognizedText, userId);

        // 5. 保存对话轮次
        session.addTurn(OralTurn.builder()
            .userText(recognizedText)
            .aiText(aiResponse.getText())
            .userAudioDurationMs(request.getAudioDurationMs())
            .build());
        sessionRepository.save(session);

        // 6. 组装响应
        PronunciationResult pronunciation = pronunciationFuture.join();

        return CompletableFuture.completedFuture(OralTurnResponse.builder()
            .recognizedText(recognizedText)
            .asrConfidence(asrResult.getConfidence())
            .pronunciationFeedback(mapPronunciation(pronunciation))
            .aiResponse(OralTurnResponse.AiResponse.builder()
                .text(aiResponse.getText())
                .audioUrl(audioUrl)
                .audioDurationMs(asrTtsClient.getAudioDuration(audioUrl))
                .build())
            .expressionTips(tips)
            .build());
    }

    private List<ExpressionTip> generateExpressionTips(String userText, Long userId) {
        // 调用AI分析用户表达，提供更地道的表达建议
        // 仅在检测到语法错误或非地道表达时返回
        return aiDialogueClient.analyzeExpression(userText, "en");
    }
}
```

## 16. 安全与合规

### 16.1 未成年人保护

| 措施 | 实现方式 |
|------|---------|
| 口语录音隐私 | 录音仅用于当次评测，本地处理优先，不永久存储原始音频 |
| AI对话内容安全 | 英语对话内容经过安全审核，过滤不当引导 |
| 每日学习时长 | 英语模块纳入总时长统计，触发限制时提示休息 |
| 蓝光护眼 | 听力/阅读练习页面支持护眼模式 |

### 16.2 数据安全

| 措施 | 实现方式 |
|------|---------|
| 音频传输加密 | HTTPS + 音频数据AES加密传输 |
| 语音数据留存 | 口语评测原始音频24h后自动删除，仅保留评分结果 |
| 学习数据脱敏 | BI分析时对用户ID脱敏处理 |
| 音频CDN防盗链 | 签名URL + 时效控制 + Referer白名单 |
