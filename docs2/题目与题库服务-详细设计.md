## 1. 概述

### 1.1 文档范围

本文档详细设计 PrimeTop 的**题目与题库服务（Question Service）**，涵盖以下核心能力：

- 题目数据模型与存储设计
- OCR 识别与题目结构化管线
- 题库检索与推荐引擎
- 类题生成与推荐策略
- 题目质量评分与生命周期管理
- 解析生成与多版本解析管理

该服务是拍照搜题、同步练习、错题本、考点梳理等多个业务模块的底层数据支撑。

### 1.2 术语定义

| 术语 | 说明 |
|------|------|
| Question | 题目实体，包含题干、选项、答案、解析等 |
| QuestionBank | 题库集合，按来源（官方录入、AI 生成、用户上传）分类 |
| OCR Pipeline | 图片→结构化题目的识别管线 |
| Similar Question | 基于知识点和语义相似度的同类题推荐 |
| Difficulty | 题目难度等级（1-5 级或自适应区间） |
| ParseTemplate | 解题模板，定义该题型常用的解题步骤结构 |

### 1.3 与其他模块的关系

```
                    ┌──────────────┐
                    │  拍照搜题模块  │
```

## 3. OCR 识别管线设计

### 3.1 管线总览

```
用户拍照
  │
  ▼
[图片预处理] → 旋转校正、裁剪、去噪、二值化
  │
  ▼
[OCR 文字识别] → 调用多模态大模型 / 专用 OCR 服务
  │
  ▼
[题目区域检测] → 单题 / 多题分割
  │
  ▼
[题目结构化] → 提取题干、选项、公式、图形
  │
  ▼
[公式还原] → LaTeX / MathML 格式化
  │
  ▼
[题目匹配] → 在题库中搜索已有题（精确匹配 + 语义匹配）
  │
  ├── 匹配成功 → 返回已有题目 + 解析
  └── 匹配失败 → 结构化入库 + 触发 AI 解析生成
```

**预处理流程代码示例：**

```python
async def preprocess_image(image_bytes: bytes, is_handwritten: bool = False) -> ProcessedImage:
    """图片预处理"""
    img = decode_image(image_bytes)
    
    # 1. 尺寸调整
    img = resize_if_needed(img, max_size=4096)
    
    # 2. 自动旋转（基于文字方向检测）
    angle = detect_text_orientation(img)
    if abs(angle) > 2:
        img = rotate_image(img, angle)
    
    # 3. 去噪
    if is_handwritten:
        img = denoise_handwritten(img)
    else:
        img = denoise_printed(img)
    
    # 4. 对比度增强
    img = enhance_contrast(img)
    
    # 5. 生成预处理后图片
    result_bytes = encode_jpeg(img, quality=85)
    
    return ProcessedImage(
        original_size=img.size,
        processed_bytes=result_bytes,
        is_handwritten=is_handwritten
    )
```

### 3.3 题目区域检测（多题分割）

```python
SPLIT_CONFIG = {
    "min_confidence": 0.7,
    "overlap_threshold": 0.3,
    "min_region_area": 0.02,
    "max_questions_per_image": 10,
    "use_layout_analysis": True,
}

async def split_questions(image: ProcessedImage) -> list[QuestionRegion]:
    """
    从一张图片中检测并分割出多个题目区域。
    
    策略优先级：
    1. 使用多模态大模型直接进行题目区域检测（准确率高）
    2. 备选：基于版面分析 + 规则的题目分割
    """
    # 优先使用多模态模型
    regions = await multimodal_detect_questions(image.processed_bytes)
    
    # 备选方案
    if not regions:
        regions = rule_based_split(image)
    
    # 过滤低置信度区域
    regions = [r for r in regions if r.confidence >= SPLIT_CONFIG["min_confidence"]]
    
    return regions[:SPLIT_CONFIG["max_questions_per_image"]]
```

### 3.4 题目结构化

```python
from dataclasses import dataclass
from enum import Enum

class QuestionType(Enum):
    SINGLE_CHOICE = 1
    MULTI_CHOICE = 2
    FILL_BLANK = 3
    TRUE_FALSE = 4
    SHORT_ANSWER = 5
    CALCULATION = 6
    PROOF = 7
    ESSAY = 8
    ORAL = 9

@dataclass
class Option:
    label: str        # A, B, C, D
    content: str      # 选项内容
    images: list[str] # 选项图片URL

@dataclass
class StructuredQuestion:
    stem: str
    stem_images: list[str]
    question_type: QuestionType
    options: list[Option] | None
    conditions: list[str]
    formulas: list[str]
    target: str
    has_diagram: bool
    diagram_type: str | None
    overall_confidence: float
    low_confidence_fields: list[str]

async def structure_question(region: QuestionRegion) -> StructuredQuestion:
    """将图片区域中的题目结构化。调用多模态大模型，使用结构化输出。"""
    prompt = """请分析图片中的题目，提取以下信息并以 JSON 格式输出：

1. stem: 题干文本（保留换行，公式用 LaTeX 格式 $...$ 包裹）
2. question_type: 题型 (single_choice / multi_choice / fill_blank / true_false / short_answer / calculation / proof / essay)
3. options: 选项列表（仅选择题），每项包含 label 和 content
4. conditions: 已知条件列表（理科题提取）
5. formulas: 出现的公式列表（LaTeX 格式）
6. target: 求解/求证的目标
7. has_diagram: 是否包含图形
8. diagram_type: 图形类型（如有）
9. confidence: 整体识别置信度 0.0-1.0

注意：数学公式用正确的 LaTeX 表示，物理量保留单位，化学方程式用标准格式。"""

    result = await multimodal_model.analyze(
        image=region.image_bytes,
        prompt=prompt,
        response_format="json"
    )
    
    return StructuredQuestion.from_dict(result)
```

## 4. 题目匹配与检索

### 4.1 匹配策略

当用户通过拍照上传题目时，先在题库中搜索是否已有相同或高度相似的题目。

```
用户题目（结构化后）
  │
  ├─ Step 1: 精确匹配
  │   ├─ stem_hash 精确对比（去空格、标点后计算）
  │   └─ 命中 → 直接返回已有题目
  │
  ├─ Step 2: 语义匹配（向量检索）
  │   ├─ 题干文本 Embedding → Top-K 向量检索
  │   ├─ 过滤条件：同学科 + 相似度 > 0.92
  │   └─ 命中 → 返回最相似题目
  │
  └─ Step 3: 未匹配
      ├─ 创建新题目记录（source_type=OCR）
      ├─ 触发 AI 解析生成
      └─ 异步计算 Embedding 写入向量库
```

### 4.3 向量检索策略

```python
VECTOR_SEARCH_CONFIG = {
    "embedding_model": "bge-large-zh-v1.5",

async def search_similar_questions(
    stem: str,
    subject_code: str,
    stage: int,
    top_k: int = 5,
    min_similarity: float = 0.75
) -> list[SimilarQuestion]:
    """向量检索相似题目"""
    query_text = f"{subject_code} {stage} {stem}"
    query_vector = await embed(query_text)
    
    results = await vector_db.search(
        collection="questions",
        vector=query_vector,
        top_k=top_k * 3,
        filter_expr=f'subject_code == "{subject_code}" and stage == {stage}',
        output_fields=["question_id", "subject_code", "stage", "difficulty"]
    )
    
    return [r for r in results if r.score >= min_similarity][:top_k]
```

```python
class SimilarQuestionGenerator:
    """AI 类题生成器"""
    
    LEVEL_HIGH = "high"    # 高度相似（改参数/改数据）
    LEVEL_MEDIUM = "medium" # 中等相似（同知识点不同考法）
    LEVEL_LOW = "low"      # 低相似（同章节拓展题）
    
    async def generate(
        self,
        source_question: Question,
        level: str = "medium",
        count: int = 3
    ) -> list[GeneratedQuestion]:
        """
        根据原题生成类题。
        
        Args:
            source_question: 原题
            level: 相似度级别
            count: 生成数量
        """
        prompt = self._build_prompt(source_question, level)
        
        results = []
        for i in range(count):
            result = await self.llm.generate(
                prompt=prompt,
                temperature=0.7 + i * 0.1,  # 每次略微增加随机性
                response_format="json"
            )
            q = GeneratedQuestion.from_llm_output(result)
            q.source_question_id = source_question.id
            q.generation_level = level
            results.append(q)
        
        return results
    
    def _build_prompt(self, q: Question, level: str) -> str:
        if level == self.LEVEL_HIGH:
            return f"""基于以下原题，生成一道高度相似的题目。

原题：{q.stem}
答案：{q.answer}
知识点：{q.knowledge_ids}
难度：{q.difficulty}

要求：
1. 保持相同题型和解题思路
2. 只修改具体数值、参数或情境
3. 难度相同或相近
4. 必须提供完整解析
5. 输出 JSON：stem, question_type, options, answer, analysis, difficulty"""

        elif level == self.LEVEL_MEDIUM:
            return f"""基于以下知识点，生成一道不同考法的题目。

知识点：{q.knowledge_ids}
学科：{q.subject_code}  学段：{q.stage}

要求：
1. 考查相同知识点但提问方式不同

3. 必须提供分步解析
4. 难度在参考难度±1范围内
5. 输出 JSON：stem, question_type, options, answer, analysis, difficulty"""

        else:  # LEVEL_LOW
            return f"""基于以下章节知识，生成一道拓展练习题。

章节：{q.chapter_ids}
知识点范围：{q.knowledge_ids}
学科：{q.subject_code}  学段：{q.stage}  难度：{q.difficulty}
```

### 5.2 推荐策略组合

```python
class QuestionRecommendationEngine:
    """题目推荐引擎 - 综合多种策略"""
    
    async def recommend(
        self,
        user_id: int,
        context: RecommendationContext
    ) -> list[Question]:
        """
        为用户推荐练习题。
        
        推荐策略优先级：
        1. 薄弱知识点定向推送（权重 40%）
        2. 错题同类强化练习（权重 25%）
        3. 当前章节同步练习（权重 20%）
        4. 已掌握知识点的进阶题（权重 15%）
        """
        recommendations = []
        
        # 策略1：薄弱知识点
        weak_points = await self.get_weak_knowledge_points(user_id)
        weak_questions = await self.search_by_knowledge(
            knowledge_ids=[wp.id for wp in weak_points],
            difficulty_range=(1, 3),  # 薄弱点从基础题开始
            limit=4
        )
        recommendations.extend(weak_questions)
        
        # 策略2：错题同类
        recent_mistakes = await self.get_recent_mistakes(user_id, limit=3)
        for mistake in recent_mistakes:
            similars = await self.get_similar_questions(
                mistake.question_id, count=1
            )
            recommendations.extend(similars)
        
        # 策略3：当前章节同步
        current_chapter = await self.get_current_chapter(user_id)
        chapter_questions = await self.search_by_chapter(
            chapter_id=current_chapter.id,
            limit=3
        )
        recommendations.extend(chapter_questions)
        
        # 去重、打散、限制数量
        return self._deduplicate_and_shuffle(recommendations, limit=10)
```

## 7. 题目质量评分体系

### 7.1 质量评分模型

```python
class QuestionQualityScorer:
    """题目质量自动评分"""
    
    async def score(self, question: Question) -> QualityScore:
        """
        综合评分 = 0.3 × 完整度 + 0.25 × 准确度 + 0.2 × 规范度 + 0.15 × 标签丰富度 + 0.1 × 用户反馈
        
        返回 0.00 ~ 1.00 分
        """
        scores = {}
        
        # 1. 完整度（字段是否齐全）
        scores["completeness"] = self._score_completeness(question)
        
        # 2. 准确度（AI 辅助验证）
        scores["accuracy"] = await self._score_accuracy(question)
        
        # 3. 规范度（格式、公式、单位）
        scores["formatting"] = self._score_formatting(question)
        
        # 4. 标签丰富度
        scores["tag_richness"] = self._score_tag_richness(question)
        
        # 5. 用户反馈
        scores["user_feedback"] = self._score_user_feedback(question)
        
        weights = {
            "completeness": 0.30,
            "accuracy": 0.25,
            "formatting": 0.20,
            "tag_richness": 0.15,
            "user_feedback": 0.10,
        }
        
        total = sum(scores[k] * weights[k] for k in scores)
        
        return QualityScore(
            total=round(total, 2),
            details=scores
        )
    
    def _score_completeness(self, q: Question) -> float:
        """完整度评分"""
        checks = {
            "has_stem": bool(q.stem and len(q.stem.strip()) > 5),
            "has_answer": bool(q.answer),
            "has_analysis": bool(q.analysis),
            "has_subject": bool(q.subject_code),
            "has_stage": q.stage is not None and q.stage > 0,
            "has_knowledge": bool(q.knowledge_ids and len(q.knowledge_ids) > 0),
            "has_difficulty": q.difficulty is not None and q.difficulty > 0,
        }
        return sum(checks.values()) / len(checks)
    
    async def _score_accuracy(self, q: Question) -> float:
        """准确度评分 - 使用 AI 抽检"""
        # 对理科题进行计算验证
        if q.subject_code in ["MATH", "PHY", "CHEM"]:
            verification = await self._verify_calculation(q)
            return verification.confidence
        
        # 对文科题进行常识检查
        return 0.8  # 默认置信度，待人工复核
    
    def _score_formatting(self, q: Question) -> float:
        """规范度评分"""
        score = 1.0
        # 检查公式格式
        if q.stem and "$" not in q.stem and any(
            kw in q.stem for kw in ["f(x)", "方程", "求导"]
        ):
            score -= 0.3  # 含公式但未用 LaTeX
        # 检查选项格式
        if q.question_type in [1, 2] and not q.options:
            score -= 0.5
        return max(0, score)
    
    def _score_tag_richness(self, q: Question) -> float:
        """标签丰富度"""
        tag_count = len(q.tags or [])
        knowledge_count = len(q.knowledge_ids or [])
        return min(1.0, (tag_count * 0.2 + knowledge_count * 0.3))
    
    def _score_user_feedback(self, q: Question) -> float:
        """用户反馈评分"""
        if q.solve_count == 0:
            return 0.5  # 无数据给中间分
        positive_ratio = q.avg_rating / 5.0
        negative_ratio = q.feedback_count / max(q.solve_count, 1)
        return max(0, min(1, positive_ratio - negative_ratio * 0.5))
```

```python
    """OCR 管线错误处理"""
    
    async def handle_preprocess_error(self, error: Exception, image_bytes: bytes):
        """图片预处理失败"""
        # 1. 记录原始图片用于分析
        await self.log_failed_image(image_bytes, stage="preprocess")
        
        # 2. 尝试降级处理（降低质量要求）

            return await preprocess_image(image_bytes, fallback_mode=True)

            raise OCRError(

            )
    
    async def handle_structure_error(self, error: Exception, region: QuestionRegion):
        """题目结构化失败"""
        # 返回部分结构化结果，标记低置信度字段
        return StructuredQuestion(
            stem=region.raw_text,
            stem_images=[],
            question_type=QuestionType.SHORT_ANSWER,  # 默认简答题
            options=None,
            conditions=[],
            formulas=[],
            target="",
            has_diagram=False,
            diagram_type=None,
            overall_confidence=0.3,
            low_confidence_fields=["question_type", "stem"]
        )
    
    async def handle_match_error(self, error: Exception, question: StructuredQuestion):
        """题目匹配失败（向量库不可用）"""
        # 降级到纯文本搜索
        results = await self.text_search_fallback(
            question.stem, 
            subject_code=question.subject_code
        )
        if results:
            return results
        
        # 完全无法匹配，创建新题目
        return await self.create_new_question(question)
```

## 13. 数据迁移与初始化

### 13.1 批量导入方案

```python
class QuestionImporter:
    """题目批量导入器"""
    
    SUPPORTED_FORMATS = ["xlsx", "csv", "json"]
    
    async def import_from_file(self, file_path: str, bank_id: int) -> ImportResult:
        """
        批量导入题目。
        
        流程：
        1. 解析文件格式
        2. 逐条校验数据
        3. 去重检查（stem_hash）
        4. 批量写入数据库
        5. 异步生成 Embedding
        6. 生成导入报告
        """
        records = self._parse_file(file_path)
        
        valid = []
        errors = []
        
        for i, record in enumerate(records):
            # 校验必填字段
            if not self._validate(record):
                errors.append(ImportError(line=i+1, reason="缺少必填字段"))
                continue
            
            # 去重
            stem_hash = md5(normalize_text(record["stem"]))
            if await self._exists_by_hash(stem_hash):
                errors.append(ImportError(line=i+1, reason="题目重复"))
                continue
            
            record["stem_hash"] = stem_hash
            record["source_type"] = 5  # 外部导入
            record["review_status"] = 0  # 待审核
            valid.append(record)
        
        # 批量写入
        if valid:
            await self._batch_insert(valid, bank_id)
            # 异步生成 Embedding
            await self._enqueue_embedding_tasks(valid)
        
        return ImportResult(
            total=len(records),
            imported=len(valid),
            skipped=len(errors),
            errors=errors
        )
```
