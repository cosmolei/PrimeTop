# 端到端流程设计 - 积分商城与奖品兑换完整链路 详细设计

## 1. 文档说明

### 1.1 定位

本文档描述 PrimeTop 积分商城与奖品兑换功能的**端到端完整链路**，从学币获取、商品浏览、兑换下单、权益发放到售后对账，覆盖客户端、BFF、积分服务、商品服务、权益服务、通知服务等全链路交互。让开发人员能清晰理解各环节的调用关系、数据流转和异常处理。

## 3. 阶段 A：学币获取链路

### 3.1 触发场景

学币获取由各业务模块通过事件驱动或直接调用触发：

| 触发源 | 事件/调用 | 学币奖励 | 触发时机 |
|--------|----------|---------|---------|
| 练习服务 | `ExerciseCompletedEvent` | 5/题 | 答题正确且完成当题 |
| 打卡服务 | `DailyCheckinEvent` | 10+连续加成 | 用户签到 |
| AI辅导服务 | `AIQuestionValidEvent` | 2/次 | 有效提问（停留≥10秒） |
| 拍题服务 | `PhotoSolveViewedEvent` | 3/次 | 查看完整解析 |
| 错题服务 | `MistakeReviewedEvent` | 3/次 | 完成订正且答对 |
| 学习服务 | `StudyDurationReachedEvent` | 10/次 | 单次连续≥20分钟 |
| 规划服务 | `DailyPlanCompletedEvent` | 30/次 | 所有任务完成 |

### 3.3 客户端积分变动展示

学币获取后客户端的处理逻辑：

```dart
// 积分变动监听器（全局单例）
class WalletChangeListener {
  final StreamController<WalletChangeEvent> _controller = 
      StreamController.broadcast();
  
  /// 由 BFF 推送或客户端本地监听触发
  void onEarnResult(EarnResult result) {
    if (result.capped) {
      // 达到每日上限，静默忽略
      return;
    }
    
    _controller.add(WalletChangeEvent(
      currencyType: result.currencyType,
      amount: result.amount,
      balanceAfter: result.balanceAfter,
    ));
    
    // 展示积分飘字动画
    _showFloatingAnimation(result);
  }
  
  void _showFloatingAnimation(EarnResult result) {
    // 根据学段选择不同动画风格
    final style = _getAnimationStyle(userGrade);
    OverlayEntry? entry;
    entry = OverlayEntry(
      builder: (ctx) => CoinFloatAnimation(
        amount: '+${result.amount.toInt()}',
        style: style,
        onComplete: () => entry?.remove(),
      ),
    );
    navigatorKey.currentState?.overlay?.insert(entry!);
  }
}
```

### 3.4 异常场景

| 异常 | 处理策略 | 用户感知 |
|------|---------|---------|
| 规则已禁用 | 返回 `EARN_RULE_DISABLED`，不发放 | 无感知（静默跳过） |
| 达到每日上限 | 返回 `EARN_CAPPED`，amount=0 | 无动画，静默跳过 |
| 乐观锁冲突 | 自动重试3次，仍失败则写补偿日志 | 无感知（延迟补发） |
| 积分服务不可用 | 业务模块本地暂存事件，积分服务恢复后重放 | 延迟到账通知 |
| 重复触发 | 幂等键拦截，返回原交易结果 | 无感知 |

### 4.5 客户端缓存策略

```dart
class ShopRepository {
  final ApiClient _api;
  final CacheManager _cache;
  
  static const _homeCacheKey = 'shop:home';
  static const _homeCacheTTL = Duration(minutes: 5);
  
  Future<ShopHomeData> getHome({bool forceRefresh = false}) async {
    if (!forceRefresh) {
      final cached = await _cache.get(_homeCacheKey);
      if (cached != null) {
        return ShopHomeData.fromJson(cached);
      }
    }
    
    final data = await _api.get('/shop/home');
    await _cache.set(_homeCacheKey, data, ttl: _homeCacheTTL);
    return ShopHomeData.fromJson(data);
  }
  
  /// 余额实时性要求高，走独立接口且不缓存
  Future<WalletInfo> getWalletBalance() async {
    return _api.get('/wallet/balance');
  }
}
```

### 5.4 预检阶段详细逻辑

兑换下单前，商品服务执行以下预检：

```java
@Service
public class ExchangePreCheckService {
    
    /**
     * 兑换预检，全部通过才允许创建订单
     * @return PreCheckResult，任意一项失败即返回失败原因
     */
    public PreCheckResult preCheck(Long userId, String itemId, int expectedCost) {
        List<String> errors = new ArrayList<>();
        
        // 1. 商品状态检查
        ShopItem item = itemRepository.findByItemId(itemId);
        if (item == null || item.getStatus() != ItemStatus.ON_SHELF) {
            return PreCheckResult.fail("ITEM_NOT_FOUND", "商品不存在或已下架");
        }
        
        // 2. 价格一致性检查（乐观并发控制）
        if (item.getCurrentPrice().compareTo(BigDecimal.valueOf(expectedCost)) != 0) {
            return PreCheckResult.fail("PRICE_CHANGED", 
                "价格已变动，请刷新后重试");
        }
        
        // 3. 库存检查
        if (item.getStock() != -1 && item.getStock() <= 0) {
            return PreCheckResult.fail("ITEM_OUT_OF_STOCK", "库存不足");
        }
        
        // 4. 用户已购数量检查
        if (item.getDailyPurchaseLimit() > 0) {
            int todayPurchased = exchangeOrderRepository
                .countTodayByUserAndItem(userId, itemId);
            if (todayPurchased >= item.getDailyPurchaseLimit()) {
                return PreCheckResult.fail("DAILY_LIMIT_EXCEEDED", 
                    "今日已购买" + todayPurchased + "次");
            }
        }
        
        // 5. 家长管控检查
        ParentalControl control = parentalService.getControl(userId);
        if (control != null && control.isShopDisabled()) {
            return PreCheckResult.fail("PARENTAL_CONTROL_BLOCKED", 
                "家长已限制兑换功能");
        }
        
        // 6. 会员专属商品检查
        if (item.isMembershipOnly()) {
            Membership membership = membershipService.getActiveMembership(userId);
            if (membership == null) {
                return PreCheckResult.fail("MEMBERSHIP_ONLY", "仅会员可兑换");
            }
        }
        
        // 7. 余额预检（快速失败，避免创建订单后才发现余额不足）
        BigDecimal actualPrice = calculateActualPrice(item, userId);
        WalletInfo wallet = walletService.getBalance(userId, CurrencyType.COIN);
        if (wallet.getBalance().compareTo(actualPrice) < 0) {
            return PreCheckResult.fail("INSUFFICIENT_BALANCE", 
                String.format("余额 %.0f，需要 %.0f", wallet.getBalance(), actualPrice));
        }
        
        return PreCheckResult.ok(actualPrice);
    }
    
    private BigDecimal calculateActualPrice(ShopItem item, Long userId) {
        BigDecimal price = item.getCurrentPrice();
        Membership ms = membershipService.getActiveMembership(userId);
        if (ms != null && item.getMembershipDiscount() != null) {
            price = price.multiply(item.getMembershipDiscount());
        }
        return price;
    }
}
```

### 5.5 订单创建与库存扣减

```java
@Service
public class ExchangeOrderService {
    
    @Transactional
    public ExchangeOrder createOrder(Long userId, String itemId, 
                                      int expectedCost, String idempotentKey) {
        // 幂等检查
        ExchangeOrder existing = orderRepository.findByIdempotentKey(userId, idempotentKey);
        if (existing != null) {
            return existing;
        }
        
        // 预检
        PreCheckResult check = preCheckService.preCheck(userId, itemId, expectedCost);
        if (!check.isPass()) {
            throw new BizException(check.getErrorCode(), check.getErrorMessage());
        }
        
        // 创建订单
        ExchangeOrder order = ExchangeOrder.builder()
            .orderNo(orderNoGenerator.next("XCH"))
            .userId(userId)
            .itemId(itemId)
            .itemSnapshot(buildItemSnapshot(itemId))
            .actualCost(check.getActualPrice())
            .status(OrderStatus.CREATED)
            .idempotentKey(idempotentKey)
            .expiredAt(LocalDateTime.now().plusMinutes(10)) // 10分钟超时
            .build();
        
        orderRepository.save(order);
        
        // 预扣库存
        int affected = itemRepository.decrementStock(itemId, 1);
        if (affected == 0) {
            throw new BizException("ITEM_OUT_OF_STOCK", "库存不足");
        }
        
        // 调用积分消耗
        try {
            WalletConsumeResult consumeResult = walletService.consume(
                WalletConsumeRequest.builder()
                    .userId(userId)
                    .consumeRuleCode("CONSUME_EXCHANGE_ITEM")
                    .targetType("ITEM")
                    .targetId(itemId)
                    .idempotentKey("EXCHANGE:" + order.getOrderNo())
                    .expectedAmount(check.getActualPrice())
                    .build()
            );
            
            order.setWalletTxNo(consumeResult.getTransactionNo());
            order.setStatus(OrderStatus.PAID);
            order.setPaidAt(LocalDateTime.now());
            
        } catch (InsufficientBalanceException e) {
            // 余额不足，回滚库存，取消订单
            itemRepository.incrementStock(itemId, 1);
            order.setStatus(OrderStatus.CANCELLED);
            order.setCancelReason("余额不足");
            orderRepository.save(order);
            throw new BizException("INSUFFICIENT_BALANCE", "学币余额不足");
            
        } catch (Exception e) {
            // 积分服务异常，回滚库存
            itemRepository.incrementStock(itemId, 1);
            order.setStatus(OrderStatus.CANCELLED);
            order.setCancelReason("积分服务异常: " + e.getMessage());
            orderRepository.save(order);
            throw e;
        }
        
        // 发放权益
        order.setStatus(OrderStatus.GRANTING);
        orderRepository.save(order);
        
        try {
            BenefitGrantResult grantResult = benefitService.grant(
                BenefitGrantRequest.builder()
                    .userId(userId)
                    .orderNo(order.getOrderNo())
                    .benefitType(mapBenefitType(itemId))
                    .targetId(itemId)
                    .itemSnapshot(order.getItemSnapshot())
                    .build()
            );
            
            order.setBenefitGrantId(grantResult.getGrantId());
            order.setStatus(OrderStatus.COMPLETED);
            order.setCompletedAt(LocalDateTime.now());
            
        } catch (Exception e) {
            // 权益发放失败 → 触发退回流程
            log.error("权益发放失败，触发退回. orderNo={}", order.getOrderNo(), e);
            order.setStatus(OrderStatus.REFUNDING);
            
            // 异步退回学币
            refundEventPublisher.publish(new RefundEvent(
                order.getOrderNo(), userId, 
                order.getActualCost(), "权益发放失败"
            ));
        }
        
        orderRepository.save(order);
        return order;
    }
}
```

## 7. 风控与安全

### 7.1 兑换风控规则

| 风险类型 | 检测规则 | 处理策略 |
|---------|---------|----------|
| 短时间高频兑换 | 同一用户1分钟内≥3次兑换请求 | 拦截，提示"操作频繁" |
| 余额异常 | 请求消耗金额 > 实际余额 | 拒绝，记录风控日志 |
| 价格篡改 | 客户端传来的 expectedCost ≠ 服务端实际价格 | 拒绝 `PRICE_CHANGED` |
| 设备异常 | 多设备同时兑换同一账户 | 设备指纹校验 + 锁机制 |
| 家长管控绕过 | 未成年人账号尝试受限商品 | 拦截 `PARENTAL_CONTROL_BLOCKED` |

### 7.2 风控检查集成点

```java
@Component
public class ExchangeRiskChecker {
    
    public RiskCheckResult check(Long userId, String itemId, String deviceId) {
        // 1. 频率检查
        String freqKey = "risk:exchange:freq:" + userId;
        Long freq = redis.incr(freqKey);
        if (freq == 1) redis.expire(freqKey, 60, TimeUnit.SECONDS);
        if (freq >= 3) {
            return RiskCheckResult.block("RATE_LIMITED", "操作频繁，请稍后重试");
        }
        
        // 2. 设备指纹检查
        DeviceRiskInfo deviceRisk = deviceRiskService.check(deviceId);
        if (deviceRisk.isBlacklisted()) {
            return RiskCheckResult.block("DEVICE_BLOCKED", "设备异常");
        }
        
        // 3. 账户异常检查
        AccountRiskInfo accountRisk = accountRiskService.check(userId);
        if (accountRisk.hasAbnormalActivity()) {
            return RiskCheckResult.block("ACCOUNT_RISK", "账户异常，请联系客服");
        }
        
        return RiskCheckResult.pass();
    }
}
```

## 10. 数据一致性保障

### 10.1 分布式事务策略

兑换链路涉及3个服务（商品服务、积分服务、权益服务），采用**最终一致性 + 补偿**模式：

```
阶段1: 创建订单 + 预扣库存       → 本地事务
阶段2: 调用积分服务扣减余额       → Feign同步调用
  ├── 成功: 继续阶段3
  └── 失败: 回滚库存，取消订单
阶段3: 调用权益服务发放权益       → Feign同步调用
  ├── 成功: 订单完成
  └── 失败: 异步退回学币 + 恢复库存
```

### 10.2 补偿定时任务

```java
/**
 * 补偿任务1: 处理卡在 GRANTING 状态的订单
 * 场景: 权益发放请求发出后服务端崩溃，未收到确认
 */
@Scheduled(fixedDelay = 30_000)
public void compensateGrantingOrders() {
    List<ExchangeOrder> orders = orderRepository
        .findByStatusAndUpdatedAtBefore(
            OrderStatus.GRANTING, 
            LocalDateTime.now().minusMinutes(2)
        );
    
    for (ExchangeOrder order : orders) {
        // 查询权益服务确认发放状态
        BenefitStatus status = benefitService
            .queryGrantStatus(order.getBenefitGrantId());
        
        switch (status) {
            case GRANTED:
                order.setStatus(OrderStatus.COMPLETED);
                order.setCompletedAt(LocalDateTime.now());
                break;
            case FAILED:
                triggerRefund(order);
                break;
            case PENDING:
                // 重试发放
                benefitService.retryGrant(order);
                break;
        }
        orderRepository.save(order);
    }
}

/**
 * 补偿任务2: 处理卡在 REFUNDING 状态的订单
 */
@Scheduled(fixedDelay = 60_000)
public void compensateRefundingOrders() {
    List<ExchangeOrder> orders = orderRepository
        .findByStatusAndUpdatedAtBefore(
            OrderStatus.REFUNDING,
            LocalDateTime.now().minusMinutes(5)
        );
    
    for (ExchangeOrder order : orders) {
        try {
            walletService.refund(order.getUserId(), order.getWalletTxNo(),
                order.getActualCost(), "权益发放失败退回");
            itemRepository.incrementStock(order.getItemId(), 1);
            order.setStatus(OrderStatus.REFUNDED);
        } catch (Exception e) {
            log.warn("退款重试失败, orderNo={}", order.getOrderNo(), e);
        }
        orderRepository.save(order);
    }
}
```

### 10.3 对账机制

每日凌晨执行积分商城对账任务：

```java
/**
 * 对账逻辑:
 * 1. 统计 exchange_order 中 COMPLETED 订单的学币消耗总和
 * 2. 统计 wallet_transaction 中 CONSUME_EXCHANGE_ITEM 流水的金额总和
 * 3. 两者必须一致
 */
@Scheduled(cron = "0 0 4 * * ?")
public void dailyReconciliation() {
    LocalDate yesterday = LocalDate.now().minusDays(1);
    
    // 订单侧
    BigDecimal orderTotal = orderRepository
        .sumActualCostByDate(yesterday, OrderStatus.COMPLETED);
    
    // 流水侧
    BigDecimal transactionTotal = walletTransactionRepository
        .sumAmountByDateAndType(yesterday, "CONSUME_EXCHANGE_ITEM");
    
    // 权益侧
    int grantedCount = benefitRepository
        .countByDate(yesterday);
    int completedOrderCount = orderRepository
        .countByDateAndStatus(yesterday, OrderStatus.COMPLETED);
    
    ReconciliationReport report = new ReconciliationReport()
        .setDate(yesterday)
        .setOrderTotal(orderTotal)
        .setTransactionTotal(transactionTotal)
        .setGrantedCount(grantedCount)
        .setCompletedOrderCount(completedOrderCount)
        .setOrderTransactionMatch(
            orderTotal.compareTo(transactionTotal) == 0)
        .setOrderBenefitMatch(
            grantedCount == completedOrderCount);
    
    if (!report.isAllMatch()) {
        alertService.sendReconciliationAlert(report);
    }
    
    reconciliationRepository.save(report);
}
```

```java
public boolean deductStock(String itemId, int quantity) {
    String stockKey = "shop:stock:" + itemId;
    Long remaining = redis.decrement(stockKey, quantity);
    
    if (remaining < 0) {
        // 库存不足，回滚
        redis.increment(stockKey, quantity);
        return false;
    }
    
    // 异步同步到DB

    return true;
}

```

| `OFF_SHELF` | 已下架 | 重新上架、归档 |
