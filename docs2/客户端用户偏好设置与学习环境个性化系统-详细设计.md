# 客户端用户偏好设置与学习环境个性化系统 - 详细设计

## 1. 概述

### 1.1 模块定位

用户偏好设置与学习环境个性化系统是 PrimeTop 客户端的基础设施模块，负责管理用户的所有个性化配置项，包括视觉偏好、交互偏好、学习环境参数、通知设置、辅助功能配置等。该模块是跨功能、跨页面的底层支撑系统，直接影响用户体验和学习效率。

### 1.2 设计目标

1. **分龄默认值**：根据用户学段自动设定合理的默认偏好（幼儿大字体、高中紧凑布局等）
2. **实时生效**：偏好修改即时反映到全局，无需重启应用
3. **多端同步**：偏好数据跨设备云端同步，支持离线修改后合并
4. **家长可控**：部分偏好（如使用时长、内容范围）受家长管控覆盖
5. **渐进暴露**：按学段和用户成熟度逐步暴露高级设置项
6. **性能优先**：偏好读取零延迟（本地缓存），批量写入异步化

## 5. 核心流程设计

### 5.1 偏好初始化流程

```
App启动
  │
  ├─→ 本地存在偏好缓存？
  │     │
  │     ├─ YES → 加载本地缓存 → 应用到全局
  │     │
  │     └─ NO  → 根据用户学段生成分龄默认值
  │               │
  │               ├─ 幼儿(3-6)    → VisualDefaults.preschool
  │               ├─ 小学(6-12)   → VisualDefaults.primary
  │               ├─ 初中(12-15)  → VisualDefaults.junior
  │               └─ 高中(15-18)  → VisualDefaults.senior
  │               │
  │               → 写入本地缓存
  │               → 应用到全局
  │
  ├─→ 异步: 拉取云端偏好
  │     │
  │     ├─ 云端有数据 → 执行增量同步（见5.3）
  │     └─ 云端无数据 → 上传本地默认值到云端
  │
  └─→ 监听系统级设置变化
        │
        ├─ 系统字体缩放变化 → 提示用户是否同步
        ├─ 系统暗色模式变化 → 若theme_mode=system，自动跟随
        └─ 系统辅助功能变化 → 自动适配 reduceMotion 等
```

### 5.2 偏好读取流程

```dart
/// 偏好读取采用分层回退策略
T getPreference<T>(String group, String key) {
  // 第1层: 家长管控覆盖值（最高优先级）
  if (_parentOverrides.containsKey('$group.$key')) {
    return _parentOverrides['$group.$key'] as T;
  }

  // 第2层: 用户自定义值
  if (_userPreferences.has(group, key)) {
    return _userPreferences.get<T>(group, key);
  }

  // 第3层: 分龄默认值
  return _ageDefaultsProvider.get<T>(group, key, userStage: currentUserStage);

  // 注意: 不存在null返回，所有偏好项都有默认值
}
```

### 5.3 偏好同步与冲突解决流程

```
客户端发起同步请求
  │
  ├─ 发送: lastSyncTimestamp + 本地变更列表(带本地时间戳)
  │
  ├─ 服务端处理:
  │     │
  │     ├─ 查询 lastSyncTimestamp 之后的所有服务端变更
  │     │
  │     ├─ 对每个本地变更:
  │     │     ├─ 服务端无更新 → 直接应用本地变更
  │     │     ├─ 本地时间戳 > 服务端时间戳 → 本地优先(Last-Write-Win)
  │     │     ├─ 服务端时间戳 > 本地时间戳 → 服务端优先
  │     │     └─ 时间戳冲突 & 改变来源=parent → 家长管控优先(不可覆盖)
  │     │
  │     └─ 返回: 服务端变更 + 冲突列表(如有) + 新同步时间戳
  │
  └─ 客户端处理响应:
        ├─ 应用服务端变更到本地
        ├─ 有冲突 → 记录冲突日志，以服务端版本为准
        └─ 更新 lastSyncTimestamp
```

**冲突解决策略：**

| 场景 | 策略 | 说明 |
|------|------|------|
| 本地改 vs 服务端改（同key） | Last-Write-Win | 较新时间戳胜出 |
| 本地改 vs 家长管控覆盖 | 家长优先 | `changedBy=parent` 不可被用户覆盖 |
| Schema版本升级 | 迁移优先 | 服务端执行迁移脚本后再同步 |
| 离线超过7天 | 全量覆盖 | 拉取服务端全量，本地差异合并后上传 |

### 7.1 PreferenceManager 核心类

```dart
/// 全局偏好管理器 - 单例，应用生命周期内持久存在
class PreferenceManager {
  static PreferenceManager? _instance;
  static PreferenceManager get instance => _instance!;

  late final PreferenceStorage _storage;
  late final PreferenceSyncService _syncService;
  late final AgeDefaultsProvider _defaultsProvider;

  UserPreferences _current = UserPreferences.empty();
  final _changeController = StreamController<PreferenceChangeEvent>.broadcast();

  /// 偏好变更事件流 - UI层可监听以实时响应
  Stream<PreferenceChangeEvent> get onPreferenceChanged => _changeController.stream;

  /// 当前生效的完整偏好快照
  UserPreferences get current => _current;

  /// 初始化（App启动时调用）
  Future<void> init({
    required String userId,
    required StudyStage stage,
    required String deviceId,
  }) async {
    // 1. 从本地存储加载
    final local = await _storage.load(userId);

    if (local != null) {
      _current = local;
    } else {
      // 2. 首次使用：生成分龄默认值
      _current = _defaultsProvider.defaultsFor(stage, userId: userId);
      await _storage.save(_current);
    }

    // 3. 异步从云端同步
    _syncService.syncFromServer(userId, _current).then((synced) {
      if (synced != null && synced.lastModified.isAfter(_current.lastModified)) {
        _current = synced;
        _storage.save(_current);
        _notifyBulkUpdate();
      }
    });

    // 4. 监听系统设置变化
    _observeSystemSettings();
  }

  /// 读取单个偏好值
  T get<T>(String group, String key) {
    // 家长管控优先
    final overrideKey = '$group.$key';
    if (_current.parentOverriddenKeys.contains(overrideKey)) {
      return _getParentOverrideValue<T>(group, key);
    }

    // 用户值
    final value = _current.getTyped<T>(group, key);
    if (value != null) return value;

    // 默认值
    return _defaultsProvider.get<T>(group, key);
  }

  /// 更新单个偏好
  Future<void> set<T>(String group, String key, T value) async {
    // 检查家长管控
    if (_current.parentOverriddenKeys.contains('$group.$key')) {
      throw PreferenceOverrideException(
        '该设置已被家长管控锁定，无法修改',
        key: '$group.$key',
      );
    }

    // 校验值范围
    _validateValue(group, key, value);

    // 应用变更
    final oldValue = _current.getTyped<T>(group, key);
    _current = _current.copyWith(
      group: group,
      key: key,
      value: value,
      lastModified: DateTime.now(),
    );

    // 持久化
    await _storage.save(_current);

    // 通知变更
    _changeController.add(PreferenceChangeEvent(
      group: group,
      key: key,
      oldValue: oldValue,
      newValue: value,
      source: ChangeSource.user,
    ));

    // 异步同步到云端
    _syncService.enqueueChange(group, key, value);
  }

  /// 批量更新偏好
  Future<void> batchUpdate(List<PrefUpdate> updates) async {
    for (final u in updates) {
      if (_current.parentOverriddenKeys.contains('${u.group}.${u.key}')) {
        continue; // 跳过被管控的key
      }
      _validateValue(u.group, u.key, u.value);
    }

    final oldSnapshot = _current;
    _current = _current.applyBatch(updates);
    await _storage.save(_current);

    for (final u in updates) {
      _changeController.add(PreferenceChangeEvent(
        group: u.group,
        key: u.key,
        oldValue: oldSnapshot.getTyped(u.group, u.key),
        newValue: u.value,
        source: ChangeSource.user,
      ));
    }

    _syncService.enqueueBatch(updates);
  }

  void _notifyBulkUpdate() {
    _changeController.add(PreferenceChangeEvent.bulk());
  }
}
```

### 7.2 偏好变更事件

```dart
class PreferenceChangeEvent {
  final String group;
  final String key;
  final dynamic oldValue;
  final dynamic newValue;
  final ChangeSource source;
  final bool isBulkUpdate;

  const PreferenceChangeEvent({
    required this.group,
    required this.key,
    this.oldValue,
    this.newValue,
    this.source = ChangeSource.user,
    this.isBulkUpdate = false,
  });

  const PreferenceChangeEvent.bulk()
      : group = '',
        key = '',
        oldValue = null,
        newValue = null,
        source = ChangeSource.sync,
        isBulkUpdate = true;
}

enum ChangeSource { user, parent, sync, system, migration }
```

```dart
/// 全局偏好响应 Widget - 感知偏好变化并自动重建
class PreferenceBuilder<T> extends StatelessWidget {
  final String group;
  final String key;
  final Widget Function(BuildContext context, T value) builder;

  const PreferenceBuilder({
    super.key,
    required this.group,
    required this.key,
    required this.builder,
  });

  @override
  Widget build(BuildContext context) {
    return StreamBuilder<PreferenceChangeEvent>(
      stream: PreferenceManager.instance.onPreferenceChanged
          .where((e) => e.isBulkUpdate || (e.group == group && e.key == key)),
      initialData: null,
      builder: (context, _) {
        final value = PreferenceManager.instance.get<T>(group, key);
        return builder(context, value);
      },
    );
  }
}

/// 使用示例

      group: 'visual',
      key: 'font_scale',
      builder: (context, fontScale) {
        return Text(
          text,
          style: TextStyle(fontSize: 16 * fontScale),
        );
      },
    );
  }
}
```

```dart
/// 偏好Schema迁移器
class PreferenceSchemaMigrator {
  Future<UserPreferences> migrate(UserPreferences prefs, int fromVersion) async {
    var result = prefs;

    // v1 → v2: 新增 nightStudyMode, 重命名部分key
    if (fromVersion < 2) {
      result = _migrateV1ToV2(result);
    }

    // v2 → v3: 新增辅助功能偏好组（示例）
    if (fromVersion < 3) {
      result = _migrateV2ToV3(result);
    }

    result = result.copyWith(schemaVersion: kCurrentSchemaVersion);
    return result;
  }

  UserPreferences _migrateV1ToV2(UserPreferences prefs) {
    // 重命名: learn.show_hint_first → learn.show_answer_hint_first
    // 新增: learn.night_study_mode = false
    // 新增: data.image_compression = medium
    return prefs.copyWith(
      schemaVersion: 2,
    );
  }
}
```

## 11. 错误处理

### 11.1 客户端错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 本地存储损坏 | 从云端重新拉取；云端也无则生成分龄默认值 |
| 云端同步失败 | 使用本地缓存，下次同步时重试 |
| 云端返回冲突 | 以服务端版本为准，记录冲突日志 |
| 修改被管控的key | Toast提示"该设置由家长管理" |
| 值超出范围 | 拒绝修改，Toast提示合法范围 |
| 网络断开 | 纯本地读写正常，恢复网络后自动同步 |

```
PREF_002  值类型不匹配

PREF_004  该Key已被家长管控覆盖
PREF_005  Schema版本过旧，需升级
PREF_006  同步时间戳冲突
PREF_007  权限不足（非本人/非绑定家长）
PREF_008  批量更新超过上限（最多50项）
```

| 离线修改 | 断网修改偏好，恢复网络后正确同步 |
| 家长端修改 | 家长设置管控，学生端实时锁定 |
| 学段变更迁移 | 升年级后默认值正确更新，用户自定义保留 |
