# 服务端审计日志与操作追溯系统 - 详细设计

## 1. 概述

### 1.1 文档定位

本文档细化 PrimeTop 审计日志与操作追溯系统的完整设计，覆盖审计事件定义、采集管线、存储引擎、查询API、合规对接与告警体系。目标读者为服务端开发与安全运维人员。

### 1.2 设计目标

1. **合规驱动**：满足《儿童个人信息网络保护规定》《个人信息保护法》对操作追溯与审计留痕的强制要求。
2. **全链路覆盖**：管理后台操作、敏感数据访问、权限变更、内容审核、支付操作等均纳入审计范围。
3. **防篡改**：审计日志写入后不可修改、不可删除，确保法律效力。
4. **高效检索**：支持按操作人、时间范围、操作类型、目标对象等多维度快速检索。
5. **低侵入**：通过装饰器/中间件自动采集，业务代码无需显式调用日志接口。

### 1.3 与相关模块的关系

| 相关模块 | 关系说明 |
|---------|---------|
| 权限管理与角色访问控制 | 审计日志记录所有权限变更与角色分配操作 |
| 数据安全与隐私合规体系 | 审计日志是隐私合规审计的核心证据来源 |
| 日志与监控告警体系 | 运行日志(log)面向运维排障，审计日志(audit)面向合规追溯，两者独立存储 |
| API网关与通用接口规范 | API网关自动注入请求级审计上下文(request_id, client_ip 等) |
| 内容与运营后台 | 后台所有写操作均产生审计事件 |
| 用户账号体系 | 敏感操作(登录、密码修改、绑定解绑)产生审计事件 |
| 支付与会员订阅 | 支付操作、退款、权益变更产生审计事件 |

### 4.2 API网关中间件

```python
# server/middleware/audit_context.py

import contextvars
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import Response
import uuid
import time

# 请求级审计上下文
audit_ctx_var: contextvars.ContextVar[AuditContext | None] = \
    contextvars.ContextVar('audit_ctx', default=None)

class AuditContextMiddleware(BaseHTTPMiddleware):
    """
    API网关审计上下文中间件
    自动为每个请求建立审计上下文，注入contextvars
    """
    
    # 不记录审计上下文的路径(健康检查、静态资源等)
    EXCLUDE_PATHS = {
        "/health", "/ready", "/metrics",
        "/favicon.ico", "/robots.txt",
    }
    
    async def dispatch(self, request: Request, call_next) -> Response:
        path = request.url.path
        if any(path.startswith(p) for p in self.EXCLUDE_PATHS):
            return await call_next(request)
        
        # 解析操作人信息
        actor_id = request.state.user_id if hasattr(request.state, 'user_id') else "anonymous"
        actor_type = self._resolve_actor_type(request)
        actor_name = request.state.user_name if hasattr(request.state, 'user_name') else "anonymous"
        actor_roles = request.state.user_roles if hasattr(request.state, 'user_roles') else []
        
        # 解析客户端IP (支持代理链)
        client_ip = self._resolve_client_ip(request)
        
        # 解析来源类型
        source_type = self._resolve_source_type(request)
        
        ctx = AuditContext(
            trace_id=request.headers.get("X-Trace-Id", uuid.uuid4().hex[:32]),
            request_id=str(uuid.uuid4()),
            correlation_id=request.headers.get("X-Correlation-Id"),
            actor_id=str(actor_id),
            actor_type=actor_type,
            actor_name=actor_name,
            actor_roles=list(actor_roles),
            client_ip=client_ip,
            user_agent=request.headers.get("User-Agent", "")[:512],
            source_type=source_type,
            device_id=request.headers.get("X-Device-Id"),
            timestamp=datetime.utcnow(),
            server_region=settings.SERVER_REGION,
        )
        
        audit_ctx_var.set(ctx)
        
        response = await call_next(request)
        
        # 对于写操作，如果没有产生审计事件，记录一条访问日志
        if request.method in ("POST", "PUT", "PATCH", "DELETE"):
            if not getattr(request.state, '_audit_emitted', False):
                # 自动记录低级别访问审计
                pass  # 可选：记录未审计的写操作
        
        return response
    
    @staticmethod
    def _resolve_client_ip(request: Request) -> str:
        """解析真实客户端IP，支持多层代理"""
        # 优先级: X-Real-IP > X-Forwarded-For 第一个 > connection
        real_ip = request.headers.get("X-Real-IP")
        if real_ip:
            return real_ip.split(",")[0].strip()
        
        forwarded_for = request.headers.get("X-Forwarded-For")
        if forwarded_for:
            return forwarded_for.split(",")[0].strip()
        
        return request.client.host if request.client else "unknown"
    
    @staticmethod
    def _resolve_source_type(request: Request) -> SourceType:
        """根据请求特征判断来源"""
        ua = request.headers.get("User-Agent", "").lower()
        referer = request.headers.get("Referer", "")
        
        if "/admin/" in request.url.path or "admin-panel" in ua:
            return SourceType.ADMIN_PANEL
        if "mozilla" in ua or "chrome" in ua:
            if "miniprogram" in ua:
                return SourceType.MINI_PROGRAM
            return SourceType.WEB_APP
        if "primeTop" in ua or "dart" in ua:
            return SourceType.MOBILE_APP
        return SourceType.API


def get_audit_context() -> AuditContext | None:
    """获取当前请求的审计上下文"""
    return audit_ctx_var.get()
```

### 4.3 声明式审计装饰器

```python
# server/core/audit_decorator.py

import functools
import hashlib
import json
from datetime import datetime

def audit_event(
    event_type: AuditEventType,
    target_type: str,
    severity: AuditSeverity = AuditSeverity.MEDIUM,
    description_template: str = "",
    snapshot_fields: list[str] | None = None,
    # 快照策略
    capture_before: bool = True,   # UPDATE/DELETE时捕获before
    capture_after: bool = True,    # CREATE/UPDATE时捕获after
    # 敏感字段处理
    mask_fields: list[str] | None = None,  # 脱敏字段列表
    # 合规标记
    requires_reason: bool = False,  # 是否需要操作理由
):
    """
    声明式审计装饰器
    
    用法:
    @audit_event(
        event_type=AuditEventType.USER_UPDATE,
        target_type="User",
        description_template="更新用户 {target_id} 的信息",
        mask_fields=["phone", "id_card"],
    )
    async def update_user(user_id: str, data: UserUpdate):
        ...
    """
    def decorator(func):
        @functools.wraps(func)
        async def wrapper(*args, **kwargs):
            ctx = get_audit_context()
            if not ctx:
                # 无上下文(内部调用)，创建系统上下文
                ctx = AuditContext(
                    trace_id="internal",
                    request_id=str(uuid.uuid4()),
                    actor_id="system",
                    actor_type=ActorType.SYSTEM,
                    actor_name="System",
                    actor_roles=[],
                    client_ip="127.0.0.1",
                    user_agent="",
                    source_type=SourceType.INTERNAL,
                    timestamp=datetime.utcnow(),
                    server_region="",
                )
            
            # 提取目标ID (约定：第一个参数为target_id，或从kwargs提取)
            target_id = _extract_target_id(func, args, kwargs)
            
            # 操作前快照
            before_snapshot = None
            if capture_before and snapshot_fields:
                before_snapshot = await _capture_snapshot(
                    target_type, target_id, snapshot_fields, mask_fields
                )
            
            # 执行业务逻辑
            result = await func(*args, **kwargs)
            
            # 操作后快照
            after_snapshot = None
            if capture_after:
                after_snapshot = _extract_after_snapshot(
                    result, snapshot_fields, mask_fields
                )
            
            # 计算变更摘要
            diff_summary = None
            if before_snapshot and after_snapshot:
                diff_summary = _compute_diff(before_snapshot, after_snapshot)
            
            # 构建操作描述
            description = description_template.format(
                actor=ctx.actor_name,
                target_id=target_id,
                **kwargs,
            ) if description_template else f"{event_type.value} on {target_type}:{target_id}"
            
            # 发送审计事件
            await audit_bus.emit(AuditEvent(
                event_type=event_type,
                event_category=event_type.split("_")[0] if "_" in event_type.value else "UNKNOWN",
                severity=severity,
                context=ctx,
                target_type=target_type,
                target_id=target_id,
                target_name=_resolve_target_name(target_type, target_id),
                action=_infer_action(event_type),
                description=description,
                before_snapshot=before_snapshot,
                after_snapshot=after_snapshot,
                diff_summary=diff_summary,
                metadata=_extract_metadata(kwargs),
            ))
            
            return result
        return wrapper
    return decorator


async def _capture_snapshot(
    target_type: str,
    target_id: str,
    fields: list[str],
    mask_fields: list[str] | None,
) -> dict:
    """从数据库捕获操作前快照"""
    model_class = MODEL_REGISTRY.get(target_type)
    if not model_class:
        return {}
    
    obj = await model_class.get_or_none(id=target_id)
    if not obj:
        return {}
    
    snapshot = {}
    for field in fields:
        value = getattr(obj, field, None)
        if mask_fields and field in mask_fields:
            value = _mask_value(value)
        snapshot[field] = value
    
    return snapshot


def _compute_diff(before: dict, after: dict) -> dict:
    """计算变更摘要"""
    diff = {}
    all_keys = set(before.keys()) | set(after.keys())
    for key in all_keys:
        old_val = before.get(key)
        new_val = after.get(key)
        if old_val != new_val:
            diff[key] = {"before": old_val, "after": new_val}
    return diff


def _mask_value(value: str | None) -> str:
    """敏感字段脱敏"""
    if not value:
        return "***"
    if len(value) <= 4:
        return "***"
    return value[:2] + "***" + value[-2:]
```

```python
# server/core/audit_writer.py

import hashlib
import json
import asyncio
from collections import deque
from datetime import datetime

class AuditWriter:
    """
    审计日志写入器
    - 批量写入数据库
    - 链式哈希防篡改
    - 写入失败回退文件
    """
    
    BATCH_SIZE = 100
    FLUSH_INTERVAL_SEC = 0.5
    MAX_QUEUE_SIZE = 10000
    
    def __init__(self):
        self._queue: asyncio.Queue[AuditEvent | None] = asyncio.Queue(
            maxsize=self.MAX_QUEUE_SIZE
        )
        self._last_hash: str | None = None
        self._buffer: list[AuditEvent] = []
        self._lock = asyncio.Lock()
        self._running = False
        self._task: asyncio.Task | None = None
        # 启动时从数据库加载最后一条记录的哈希
        self._last_hash_loaded = False
    
    async def start(self):
        """启动写入器"""
        self._running = True
        # 从数据库恢复最后一条哈希
        await self._load_last_hash()
        self._task = asyncio.create_task(self._flush_loop())
    
    async def stop(self):
        """优雅关闭"""
        self._running = False
        await self._queue.put(None)  # sentinel
        if self._task:
            await self._task
        # 最后flush一次
        await self._flush()
    
    async def write(self, event: AuditEvent) -> None:
        """写入审计事件(非阻塞)"""
        try:
            self._queue.put_nowait(event)
        except asyncio.QueueFull:
            # 队列满，回退到文件
            await self._fallback_write([event])
    
    async def _flush_loop(self):
        """定时刷新循环"""
        while self._running:
            try:
                # 等待事件或超时
                event = await asyncio.wait_for(
                    self._queue.get(), 
                    timeout=self.FLUSH_INTERVAL_SEC
                )
                if event is None:
                    break
                self._buffer.append(event)
                
                # 批量收集
                while len(self._buffer) < self.BATCH_SIZE:
                    try:
                        event = self._queue.get_nowait()
                        if event is None:
                            break
                        self._buffer.append(event)
                    except asyncio.QueueEmpty:
                        break
            
            except asyncio.TimeoutError:
                pass
            
            if self._buffer:
                await self._flush()
    
    async def _flush(self):
        """批量写入数据库"""
        if not self._buffer:
            return
        
        async with self._lock:
            events = self._buffer[:]
            self._buffer.clear()
        
        # 计算哈希链
        records = []
        for event in events:
            self._last_hash = self._compute_hash(event, self._last_hash)
            record = self._event_to_record(event, self._last_hash)
            records.append(record)
        
        try:
            # 批量INSERT
            await AuditLog.bulk_create(records)
        except Exception as e:
            logger.error(f"Audit write failed: {e}, falling back to file")
            await self._fallback_write(events)
    
    def _compute_hash(self, event: AuditEvent, prev_hash: str | None) -> str:
        """计算链式哈希"""
        payload = json.dumps({
            "event_id": str(event.event_id),
            "event_type": event.event_type,
            "actor_id": event.context.actor_id,
            "target_type": event.target_type,
            "target_id": event.target_id,
            "timestamp": event.context.timestamp.isoformat(),
            "prev_hash": prev_hash,
        }, sort_keys=True, ensure_ascii=False)
        
        return hashlib.sha256(payload.encode("utf-8")).hexdigest()
    
    async def _fallback_write(self, events: list[AuditEvent]):
        """回退写入本地文件"""
        fallback_path = settings.AUDIT_FALLBACK_DIR / f"audit_{datetime.utcnow():%Y%m%d}.jsonl"
        with open(fallback_path, "a", encoding="utf-8") as f:
            for event in events:
                f.write(event.model_dump_json() + "\n")
    
    async def _load_last_hash(self):
        """从数据库恢复最后一条哈希(重启后)"""
        last = await AuditLog.all().order_by("-id").first()
        if last:
            self._last_hash = last.hash
        self._last_hash_loaded = True
```

### 7.2 实时告警处理

```python
class AuditAlertProcessor:
    """审计告警处理器"""
    
    def __init__(self):
        self._alert_cache: dict[str, datetime] = {}  # rule_id -> last_alert_time
    
    async def process(self, event: AuditEvent):
        """处理审计事件，检查告警规则"""
        for rule in ALERT_RULES:
            if not self._match_event(rule, event):
                continue
            
            # 检查冷却时间
            last_alert = self._alert_cache.get(rule.rule_id)
            if last_alert and (datetime.utcnow() - last_alert).total_seconds() < rule.cooldown_sec:
                continue
            
            # 窗口聚合检查
            if rule.condition.window_sec and rule.condition.threshold:
                count = await self._count_recent_events(
                    rule.condition, event.context.actor_id
                )
                if count < rule.condition.threshold:
                    continue
            
            # 发送告警
            await self._send_alert(rule, event)
            self._alert_cache[rule.rule_id] = datetime.utcnow()
    
    async def _send_alert(self, rule: AuditAlertRule, event: AuditEvent):
        """通过配置的渠道发送告警"""
        alert_payload = AlertPayload(
            rule_id=rule.rule_id,
            rule_name=rule.name,
            description=rule.description,
            event=event,
            timestamp=datetime.utcnow(),
        )
        
        for channel in rule.channels:
            match channel:
```

## 11. 降级策略

### 11.1 分级降级

| 级别 | 触发条件 | 降级行为 |
|------|---------|---------|
| L0 正常 | 写入延迟 < 100ms | 全量采集，完整快照 |
| L1 轻度降级 | 队列使用率 > 70% | 停止采集 LOW 级别事件的 before_snapshot |
| L2 中度降级 | 队列使用率 > 90% 或 DB 写入延迟 > 1s | 仅采集 HIGH+ 级别事件，快照字段仅保留关键字段 |
| L3 重度降级 | DB 不可用 | 所有事件回退到本地文件，仅保留 event_type + actor_id + target_id + timestamp |
| L4 最低保障 | 磁盘空间不足 | 写入共享内存映射文件，系统恢复后回填 |

### 11.2 审计不可关闭

```python
# 审计系统是安全基础设施，不可通过配置关闭
# 即使在 L3 降级下也必须保证审计事件不丢失

AUDIT_SYSTEM_CANNOT_BE_DISABLED = True  # 硬编码，不可配置

# 管理后台中不提供"关闭审计"的开关
# 修改此常量需要安全团队与CTO双重审批
```

## 14. 安全考量

1. **审计数据库独立**：audit_db 与业务数据库物理隔离，业务服务仅拥有 INSERT 权限，无 UPDATE/DELETE 权限。
2. **哈希链防篡改**：每条记录的 hash 依赖前一条记录的 hash，修改任意一条会导致后续所有记录校验失败。
3. **访问控制**：审计日志查询需要 `audit:log:read` 权限，仅安全团队和CTO级别可授予。
4. **快照脱敏**：L4 级别数据(身份证号、银行卡号)在快照中始终脱敏存储，完整快照仅在安全团队审查时通过单独API获取。
5. **导出审批**：涉及L3+数据的导出必须经过双人审批。
6. **日志不可关闭**：审计采集是强制性的，无法通过配置关闭。
7. **定期验证**：每周自动验证哈希链完整性，每月人工抽检。
