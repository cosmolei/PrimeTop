# 服务端-全平台学情宏观态势感知与共性知识薄弱点智能热点地图引擎-详细设计

## 1. 概述

### 1.1 功能定位

全平台学情宏观态势感知与共性知识薄弱点智能热点地图引擎（以下简称"宏观学情引擎"）是 PrimeTop 平台数据智能层的核心分析服务，负责对全平台学生的学习数据进行跨学生、跨班级、跨学校、跨区域的宏级聚合分析，识别共性知识薄弱点，生成多维度知识掌握热力图，为内容生产优先级、运营策略、产品改进和教育研究提供量化决策依据。

### 1.2 与现有系统的关系

| 现有系统 | 关系 |
| --- | --- |
| 学情分析（学生级） | 本引擎消费学生级学情数据，进行宏观聚合 |
| 班级学情诊断引擎 | 班级级诊断是本引擎的一个聚合维度 |
| 同伴基准参照引擎 | 同伴基准关注个体vs群体对比，本引擎关注全平台宏观态势 |
| 管理后台学情驾驶舱 | 驾驶舱是本引擎数据的主要消费方之一 |
| 教育热点追踪引擎 | 外部考试趋势预测，本引擎补充内部平台学情态势 |
| 内容生产运营工作台 | 本引擎的内容缺口分析结果指导生产排期 |

### 1.3 设计目标

1. **宏观态势可见**：提供全平台、分学段、分年级、分学科、分章节、分知识点的多层级学情热力图。
2. **共性薄弱点识别**：自动发现高频出错、低掌握度的知识盲区，按影响面和严重程度排序。
3. **时空演化追踪**：追踪薄弱点的时间演化趋势（改善/恶化/稳定）和季节性波动。
4. **区域差异感知**：按省/市/区维度分析学情差异，支撑区域化内容适配。
5. **内容生产指导**：将薄弱点分析与现有内容覆盖度交叉，输出内容生产优先级建议。
6. **低延迟查询**：管理后台和运营系统查询热力图数据的 P99 延迟 < 500ms。

### 1.4 适用范围

- 管理后台：教育运营驾驶舱的宏观数据卡片
- 内容运营：内容生产优先级决策参考
- 产品决策：功能改进和学科资源分配依据
- B端合作：向合作学校/机构提供区域学情基准报告
- 教研团队：教材章节难度标定和教学策略优化参考

## 3. 核心算法设计

### 3.1 薄弱点综合影响评分算法

用于对全平台薄弱知识点进行排序，综合考虑影响面、严重程度和趋势方向。

```python
import math
from datetime import date
from enum import Enum

class TrendDirection(Enum):
    IMPROVING = "improving"
    DECLINING = "declining"
    STABLE = "stable"
    NEW = "new"

class WeakPointScorer:
    """薄弱点综合影响评分器"""

    # 权重配置（可通过配置中心动态调整）
    DEFAULT_WEIGHTS = {
        "coverage_weight": 0.35,    # 影响面权重
        "severity_weight": 0.35,    # 严重程度权重
        "trend_weight": 0.15,       # 趋势权重
        "content_gap_weight": 0.15, # 内容缺口权重
    }

    def __init__(self, weights: dict = None, weak_threshold: float = 0.4):
        self.weights = weights or self.DEFAULT_WEIGHTS
        self.weak_threshold = weak_threshold

    def compute_score(
        self,
        student_count: int,
        total_platform_students: int,
        avg_mastery: float,
        weak_ratio: float,
        trend_direction: TrendDirection,
        trend_delta: float,
        content_status: str,
        knowledge_point_difficulty: float = 0.5,
    ) -> float:
        """
        计算薄弱点综合影响评分 (0~100)

        参数:
            student_count: 涉及薄弱的学生数
            total_platform_students: 平台总学生数
            avg_mastery: 平均掌握度 (0~1)
            weak_ratio: 薄弱比例 (0~1)
            trend_direction: 趋势方向
            trend_delta: 趋势变化幅度
            content_status: 内容覆盖状态 sufficient/insufficient/gap/unknown
            knowledge_point_difficulty: 知识点本身难度 (0~1)
        """
        # 1. 影响面得分（对数缩放避免头部知识点永远霸榜）
        coverage_rate = student_count / max(total_platform_students, 1)
        coverage_score = math.log10(1 + coverage_rate * 100) / math.log10(101)  # 0~1

        # 2. 严重程度得分（掌握度越低越严重，考虑知识点难度修正）
        severity = (self.weak_threshold - avg_mastery) / self.weak_threshold
        severity = max(0, min(1, severity))
        # 难度修正：高难度知识点的低掌握度适当降权（避免全是难题上榜）
        difficulty_factor = 1.0 - (knowledge_point_difficulty - 0.5) * 0.3
        severity_score = severity * difficulty_factor

        # 3. 趋势得分
        trend_score = self._compute_trend_score(trend_direction, trend_delta)

        # 4. 内容缺口得分
        content_gap_score = self._compute_content_gap_score(content_status)

        # 加权汇总
        total = (
            coverage_score * self.weights["coverage_weight"]
            + severity_score * self.weights["severity_weight"]
            + trend_score * self.weights["trend_weight"]
            + content_gap_score * self.weights["content_gap_weight"]
        )

        return round(total * 100, 2)

    def _compute_trend_score(self, direction: TrendDirection, delta: float) -> float:
        """
        趋势得分:
        - 恶化中: 高分（需要紧急关注）
        - 新出现: 较高分
        - 稳定: 中等分
        - 改善中: 低分（已在好转）
        """
        if direction == TrendDirection.DECLINING:
            return min(1.0, 0.6 + abs(delta) * 2)
        elif direction == TrendDirection.NEW:
            return 0.8
        elif direction == TrendDirection.STABLE:
            return 0.5
        elif direction == TrendDirection.IMPROVING:
            return max(0.1, 0.4 - abs(delta) * 2)
        return 0.5

    def _compute_content_gap_score(self, status: str) -> float:
        """内容缺口得分：内容越少，越需要生产"""
        mapping = {
            "gap": 1.0,         # 完全缺失
            "insufficient": 0.7, # 不足
            "unknown": 0.5,      # 未知
            "sufficient": 0.2,   # 充足（仍可优化但非紧急）
        }
        return mapping.get(status, 0.5)
```

### 3.2 薄弱点自动检测与分类算法

```python
from dataclasses import dataclass
from typing import List, Optional
from datetime import date, timedelta

@dataclass
class KnowledgePointAggregate:
    knowledge_point_id: str
    knowledge_point_name: str
    chapter_id: str
    subject: str
    grade: str
    student_count: int
    avg_mastery: float
    weak_ratio: float
    mastery_p25: float
    mastery_p50: float
    mastery_p75: float
    total_answers: int

@dataclass
class DetectedWeakPoint:
    aggregate: KnowledgePointAggregate
    impact_score: float
    trend_direction: TrendDirection
    trend_delta: float
    weak_type: str  # structural / seasonal / emerging / persistent / crowd-specific
    confidence: float
    content_status: str

class WeakPointDetector:
    """薄弱点自动检测器"""

    WEAK_MASTERY_THRESHOLD = 0.4
    MIN_SAMPLE_SIZE = 30          # 最少样本量
    WEAK_RATIO_THRESHOLD = 0.35   # 薄弱比例阈值
    CONFIDENCE_ALPHA = 0.05       # 统计显著性水平

    def detect_weak_points(
        self,
        aggregates: List[KnowledgePointAggregate],
        scorer: WeakPointScorer,
        historical_data: dict,  # {kp_id: [(week, avg_mastery), ...]}
        content_coverage: dict, # {kp_id: "sufficient"/"insufficient"/"gap"/"unknown"}
        total_platform_students: int,
    ) -> List[DetectedWeakPoint]:
        """检测并分类全平台薄弱知识点"""
        results = []

        for agg in aggregates:
            # 样本量不足跳过
            if agg.student_count < self.MIN_SAMPLE_SIZE:
                continue

            # 掌握度和薄弱比例双重判定
            is_mastery_low = agg.avg_mastery < self.WEAK_MASTERY_THRESHOLD
            is_ratio_high = agg.weak_ratio > self.WEAK_RATIO_THRESHOLD

            if not (is_mastery_low or is_ratio_high):
                continue

            # 计算置信度（基于样本量和效应量）
            confidence = self._compute_confidence(
                agg.student_count, agg.avg_mastery, self.WEAK_MASTERY_THRESHOLD
            )

            # 分析趋势
            trend_direction, trend_delta = self._analyze_trend(
                agg.knowledge_point_id, historical_data, agg.avg_mastery
            )

            # 分类薄弱类型
            weak_type = self._classify_weak_type(
                agg, trend_direction, historical_data.get(agg.knowledge_point_id, [])
            )

            # 计算综合评分
            impact_score = scorer.compute_score(
                student_count=agg.student_count,
                total_platform_students=total_platform_students,
                avg_mastery=agg.avg_mastery,
                weak_ratio=agg.weak_ratio,
                trend_direction=trend_direction,
                trend_delta=trend_delta,
                content_status=content_coverage.get(agg.knowledge_point_id, "unknown"),
            )

            results.append(DetectedWeakPoint(
                aggregate=agg,
                impact_score=impact_score,
                trend_direction=trend_direction,
                trend_delta=trend_delta,
                weak_type=weak_type,
                confidence=confidence,
                content_status=content_coverage.get(agg.knowledge_point_id, "unknown"),
            ))

        # 按影响分排序
        results.sort(key=lambda x: x.impact_score, reverse=True)
        return results

    def _compute_confidence(
        self, sample_size: int, observed_mastery: float, threshold: float
    ) -> float:
        """
        基于样本量和效应量计算置信度 (0~1)
        使用正态近似计算 z-score 和对应 p-value
        """
        import math
        effect = threshold - observed_mastery
        if effect <= 0:
            return 0.5  # 不薄弱

        # 标准误（假设 mastery 服从 Beta 分布近似）
        std_error = math.sqrt(
            observed_mastery * (1 - observed_mastery) / max(sample_size, 1)
        )
        z_score = effect / max(std_error, 0.001)

        # z-score 转 confidence（单侧检验）
        confidence = min(1.0, z_score / 3.0)  # z=3 对应 ~99.87% 置信

        # 样本量修正
        sample_factor = min(1.0, math.log10(max(sample_size, 1)) / math.log10(500))
        return round(confidence * sample_factor, 3)

    def _analyze_trend(
        self,
        kp_id: str,
        historical_data: dict,
        current_mastery: float,
    ) -> tuple:
        """
        分析知识点掌握度趋势
        返回 (TrendDirection, delta)
        """
        history = historical_data.get(kp_id, [])
        if len(history) < 2:
            return TrendDirection.NEW, 0.0

        # 取最近4周的平均值与上4周比较
        recent = [h[1] for h in history[-4:]]
        previous = [h[1] for h in history[-8:-4]] if len(history) >= 8 else [h[1] for h in history[:-4]]

        recent_avg = sum(recent) / len(recent)
        previous_avg = sum(previous) / len(previous) if previous else current_mastery

        delta = recent_avg - previous_avg

        # 趋势判定阈值
        SIGNIFICANT_DELTA = 0.03  # 3% 以上变化视为显著

        if delta < -SIGNIFICANT_DELTA:
            return TrendDirection.DECLINING, delta
        elif delta > SIGNIFICANT_DELTA:
            return TrendDirection.IMPROVING, delta
        elif abs(delta) <= 0.01:
            return TrendDirection.STABLE, delta
        else:
            return TrendDirection.STABLE, delta

    def _classify_weak_type(
        self,
        agg: KnowledgePointAggregate,
        trend: TrendDirection,
        history: list,
    ) -> str:
        """
        薄弱点分类:
        - structural: 结构性薄弱（知识点本身难，全平台普遍弱）
        - persistent: 持续性薄弱（长期存在，无明显改善）
        - emerging: 新兴薄弱（近期突然变弱）
        - seasonal: 季节性薄弱（特定时间周期出现，如期中/期末前）
        - crowd_specific: 人群特征薄弱（特定年级/区域集中）
        """
        # 结构性薄弱：难度高 + 四分位距大（好的好、差的差）
        if agg.avg_mastery < 0.3 and agg.mastery_p75 > 0.6:
            return "structural"

        # 新兴薄弱：趋势恶化 + 历史数据不弱
        if trend == TrendDirection.DECLINING:
            if history and len(history) >= 4:
                old_avg = sum(h[1] for h in history[:4]) / 4
                if old_avg > 0.5:
                    return "emerging"

        # 季节性薄弱：在历史数据中呈现周期性波动
        if self._detect_seasonality(history):
            return "seasonal"

        # 持续性薄弱：长期低于阈值
        if history and len(history) >= 8:
            all_weak = all(h[1] < self.WEAK_MASTERY_THRESHOLD for h in history[-8:])
            if all_weak:
                return "persistent"

        return "crowd_specific"

    def _detect_seasonality(self, history: list) -> bool:
        """简单的季节性检测：检查是否存在周期性模式"""
        if len(history) < 12:
            return False
        values = [h[1] for h in history[-12:]]
        # 计算自相关（lag=4 检测月度周期）
        mean = sum(values) / len(values)
        if mean == 0:
            return False
        numerator = sum(
            (values[i] - mean) * (values[i - 4] - mean)
            for i in range(4, len(values))
        )
        denominator = sum((v - mean) ** 2 for v in values)
        if denominator == 0:
            return False
        autocorr = numerator / denominator
        return autocorr > 0.5
```

### 3.3 区域学情差异分析算法

```python
from dataclasses import dataclass
from typing import List, Dict
import statistics

@dataclass
class RegionalMasteryRecord:
    province: str
    city: str
    subject: str
    grade: str
    chapter_id: str
    avg_mastery: float
    student_count: int

class RegionalMasteryAnalyzer:
    """区域学情差异分析器"""

    def compute_regional_benchmarks(
        self,
        records: List[RegionalMasteryRecord],
    ) -> Dict[str, dict]:
        """
        计算区域学情基准和偏差
        返回 {province: {metrics...}}
        """
        # 1. 计算全平台基准
        platform_avg = statistics.mean([r.avg_mastery for r in records])

        # 2. 按省份分组
        province_groups: Dict[str, List[float]] = {}
        for r in records:
            province_groups.setdefault(r.province, []).append(r.avg_mastery)

        # 3. 计算省份级统计
        province_stats = {}
        for province, masteries in province_groups.items():
            province_avg = statistics.mean(masteries)
            province_stats[province] = {
                "avg_mastery": round(province_avg, 3),
                "deviation": round(province_avg - platform_avg, 3),
                "student_count": sum(
                    r.student_count for r in records if r.province == province
                ),
                "mastery_std": round(statistics.stdev(masteries), 3)
                    if len(masteries) > 1 else 0,
            }

        # 4. 计算四分位排名
        province_avgs = sorted([s["avg_mastery"] for s in province_stats.values()])
        if len(province_avgs) >= 4:
            q1 = province_avgs[len(province_avgs) // 4]
            q2 = province_avgs[len(province_avgs) // 2]
            q3 = province_avgs[len(province_avgs) * 3 // 4]
            for province, stats in province_stats.items():
                avg = stats["avg_mastery"]
                if avg <= q1:
                    stats["quartile_rank"] = 4  # 最弱
                elif avg <= q2:
                    stats["quartile_rank"] = 3
                elif avg <= q3:
                    stats["quartile_rank"] = 2
                else:
                    stats["quartile_rank"] = 1  # 最强

        return province_stats

    def detect_regional_outliers(
        self,
        records: List[RegionalMasteryRecord],
        threshold: float = 0.15,
    ) -> List[dict]:
        """
        检测区域异常值：显著偏离全平台平均的区域
        返回 [{province, subject, chapter_id, deviation, direction, severity}]
        """
        platform_avg = statistics.mean([r.avg_mastery for r in records])

        outliers = []
        for r in records:
            deviation = r.avg_mastery - platform_avg
            if abs(deviation) >= threshold:
                outliers.append({
                    "province": r.province,
                    "city": r.city,
                    "subject": r.subject,
                    "chapter_id": r.chapter_id,
                    "deviation": round(deviation, 3),
                    "direction": "above" if deviation > 0 else "below",
                    "severity": "high" if abs(deviation) >= 0.25 else "medium",
                    "avg_mastery": r.avg_mastery,
                    "platform_avg": round(platform_avg, 3),
                })

        outliers.sort(key=lambda x: abs(x["deviation"]), reverse=True)
        return outliers
```

```python
class MacroAnalysisDailyJob:
    """全平台学情宏观分析日批任务"""

    def __init__(
        self,
        clickhouse_client,
        mysql_client,
        redis_client,
        content_service_client,
        config_manager,
    ):
        self.ch = clickhouse_client
        self.mysql = mysql_client
        self.redis = redis_client
        self.content_api = content_service_client
        self.config = config_manager

    def run(self, target_date: date):
        """主执行入口"""
        try:
            self._log_start(target_date)

            # Step 1: 数据准备 — 从 ClickHouse 读取聚合数据
            platform_aggregates = self._fetch_platform_aggregates(target_date)
            if not platform_aggregates:
                self._log_skip("无有效聚合数据")
                return

            total_students = self._count_active_students(target_date)

            # Step 2: 获取历史数据（用于趋势分析）
            historical_data = self._fetch_historical_data(
                target_date - timedelta(days=84)  # 最近12周
            )

            # Step 3: 获取内容覆盖度
            kp_ids = [a.knowledge_point_id for a in platform_aggregates]
            content_coverage = self._fetch_content_coverage(kp_ids)

            # Step 4: 薄弱点检测
            scorer = WeakPointScorer(
                weights=self.config.get("weak_point_weights")
            )
            detector = WeakPointDetector()
            weak_points = detector.detect_weak_points(
                aggregates=platform_aggregates,
                scorer=scorer,
                historical_data=historical_data,
                content_coverage=content_coverage,
                total_platform_students=total_students,
            )

            # Step 5: 区域分析
            regional_records = self._fetch_regional_aggregates(target_date)
            regional_analyzer = RegionalMasteryAnalyzer()
            regional_benchmarks = regional_analyzer.compute_regional_benchmarks(
                regional_records
            )
            regional_outliers = regional_analyzer.detect_regional_outliers(
                regional_records
            )

            # Step 6: 持久化结果
            self._persist_weak_point_rankings(target_date, weak_points)
            self._persist_regional_benchmarks(target_date, regional_benchmarks)

            # Step 7: 生成内容生产优先级建议
            production_priorities = self._generate_production_priorities(weak_points)
            self._persist_production_priorities(target_date, production_priorities)

            # Step 8: 刷新 Redis 缓存
            self._refresh_cache(target_date, weak_points, regional_benchmarks)

            # Step 9: 清理过期数据（保留90天明细、52周演化）
            self._cleanup_expired_data(target_date)

            self._log_complete(target_date, len(weak_points))

        except Exception as e:
            self._log_error(target_date, e)
            raise

    def _fetch_platform_aggregates(self, target_date: date) -> list:
        """从 ClickHouse 读取全平台知识点聚合"""
        sql = """
        SELECT
            knowledge_point_id,
            any(knowledge_point_name) AS kp_name,
            any(chapter_id) AS chapter_id,
            any(subject) AS subject,
            any(grade) AS grade,
            student_count,
            avg_mastery,
            weak_ratio,
            mastery_p25,
            mastery_p50,
            mastery_p75,
            total_answers
        FROM knowledge_mastery_daily_agg
        WHERE dt = %(dt)s AND stage = %(stage)s
        GROUP BY knowledge_point_id
        HAVING student_count >= 30
        """
        results = []
        for stage in ["primary", "junior", "senior"]:
            rows = self.ch.query(sql, {"dt": target_date, "stage": stage})
            results.extend(self._map_aggregates(rows))
        return results

    def _count_active_students(self, target_date: date) -> int:
        """统计当日活跃学生总数"""
        sql = """
        SELECT countDistinct(student_id)
        FROM knowledge_mastery_detail
        WHERE dt = %(dt)s
        """
        return self.ch.query_one(sql, {"dt": target_date})

    def _refresh_cache(self, target_date: date, weak_points: list, regional: dict):
        """刷新 Redis 缓存"""
        pipe = self.redis.pipeline()

        # 热力图缓存
        for dimension_key, heatmap_data in self._build_heatmap(weak_points):
            pipe.hset(
                f"heatmap:{dimension_key}:{target_date.isoformat()}",
                mapping=heatmap_data,
            )
            pipe.expire(
                f"heatmap:{dimension_key}:{target_date.isoformat()}",
                86400 if target_date < date.today() else 300,
            )

        # 薄弱 TOP 20 缓存
        top_weak = [
            {
                "kp_id": wp.aggregate.knowledge_point_id,
                "kp_name": wp.aggregate.knowledge_point_name,
                "score": wp.impact_score,
                "mastery": wp.aggregate.avg_mastery,
                "trend": wp.trend_direction.value,
            }
            for wp in weak_points[:20]
        ]
        pipe.set(
            f"weak_points:top20:{target_date.isoformat()}",
            json.dumps(top_weak, ensure_ascii=False),
            ex=86400 if target_date < date.today() else 300,
        )

        pipe.execute()

    def _cleanup_expired_data(self, target_date: date):
        """清理过期数据"""
        # ClickHouse 明细数据保留90天
        cutoff = target_date - timedelta(days=90)
        self.ch.execute(
            "ALTER TABLE knowledge_mastery_detail "
            "DELETE WHERE dt < %(cutoff)s",
            {"cutoff": cutoff},
        )

        # MySQL 排行榜保留180天
        self.mysql.execute(
            "DELETE FROM macro_weak_point_ranking WHERE dt < %s",
            (cutoff - timedelta(days=90),),
        )
```

| MACRO_005 | 500 | ClickHouse 查询超时 | 降级到 Redis 缓存（允许返回昨日数据） |
| MACRO_006 | 500 | 数据源连接异常 | 降级到最近可用缓存数据 |

### 6.2 降级策略

```python
class MacroAnalysisService:
    """宏观学情分析服务（含降级策略）"""

    def get_heatmap(self, dimension: str, date: date, **filters) -> dict:
        """
        获取热力图，含三级降级:
        1. 优先查 Redis 缓存（当日）
        2. 降级查 ClickHouse（允许当日数据不完整）
        3. 最终降级返回前一日缓存数据
        """
        # Level 1: Redis 当日缓存
        try:
            cached = self.redis.hgetall(f"heatmap:{dimension}:{date.isoformat()}")
            if cached:
                return self._deserialize_heatmap(cached, source="cache_today")
        except RedisError:
            pass  # 缓存不可用，继续降级

        # Level 2: ClickHouse 实时查询
        try:
            result = self._query_clickhouse_heatmap(dimension, date, **filters)
            if result["heatmap"]:
                return result
        except (ClickHouseError, TimeoutError) as e:
            logger.warning(f"ClickHouse 查询失败，降级到前日缓存: {e}")

        # Level 3: 前一日缓存
        yesterday = date - timedelta(days=1)
        try:
            cached = self.redis.hgetall(f"heatmap:{dimension}:{yesterday.isoformat()}")
            if cached:
                data = self._deserialize_heatmap(cached, source="cache_yesterday")
                data["degraded"] = True
                data["degraded_date"] = yesterday.isoformat()
                return data
        except RedisError:
            pass

        # 最终兜底
        return {
            "code": MACRO_004,
            "message": "数据正在准备中，请稍后重试",
            "retry_after_seconds": 300,
            "data": None,
        }

    def daily_job_with_retry(self, target_date: date, max_retries: int = 3):
        """日批任务带重试"""
        for attempt in range(max_retries):
            try:
                job = MacroAnalysisDailyJob(...)
                job.run(target_date)
                return
            except Exception as e:
                logger.error(
                    f"日批任务第{attempt+1}次执行失败: {e}",
                    exc_info=True,
                )
                if attempt < max_retries - 1:
                    sleep(60 * (attempt + 1))  # 指数退避
                else:
                    # 发送告警
                    self.alert_service.send(
                        level="P1",
                        title=f"宏观学情日批任务失败 {target_date}",
                        message=str(e),
                    )
```

### 6.3 数据质量保障

```python
class DataQualityChecker:
    """数据质量校验器"""

    def validate_daily_aggregates(self, target_date: date) -> dict:
        """
        校验日批聚合数据的质量
        返回 {check_name: {passed: bool, details: str}}
        """
        checks = {}

        # 1. 数据完整性：知识点覆盖率
        total_kps = self._count_total_knowledge_points()
        covered_kps = self._count_covered_kps(target_date)
        coverage_rate = covered_kps / total_kps
        checks["knowledge_point_coverage"] = {
            "passed": coverage_rate >= 0.95,
            "details": f"覆盖率 {coverage_rate:.1%} ({covered_kps}/{total_kps})",
            "metric": coverage_rate,
        }

        # 2. 数据时效性：最新数据延迟
        latest_dt = self._get_latest_data_time(target_date)
        max_delay_hours = 6
        delay_hours = (datetime.now() - latest_dt).total_seconds() / 3600
        checks["data_freshness"] = {
            "passed": delay_hours <= max_delay_hours,
            "details": f"数据延迟 {delay_hours:.1f} 小时",
            "metric": delay_hours,
        }

        # 3. 异常值检测：掌握度异常分布
        avg_mastery = self._get_avg_mastery(target_date)
        expected_range = (0.3, 0.9)  # 全平台平均掌握度应在合理范围
        checks["mastery_sanity"] = {
            "passed": expected_range[0] <= avg_mastery <= expected_range[1],
            "details": f"平台平均掌握度 {avg_mastery:.3f}",
            "metric": avg_mastery,
        }

        # 4. 样本量检测：活跃学生数是否异常
        today_students = self._count_students(target_date)
        yesterday_students = self._count_students(target_date - timedelta(days=1))
        if yesterday_students > 0:
            change_ratio = abs(today_students - yesterday_students) / yesterday_students
            checks["student_count_stability"] = {
                "passed": change_ratio <= 0.3,
                "details": f"日活变化 {change_ratio:.1%}",
                "metric": change_ratio,
            }

        return checks
```

### 7.3 内存控制

```python
class BatchProcessor:
    """批量处理器（控制内存）"""

    BATCH_SIZE = 5000  # 每批处理5000个知识点聚合记录

    def process_all_aggregates(self, target_date: date):
        """分批处理，避免内存溢出"""
        total_processed = 0
        offset = 0

        while True:
            batch = self.ch.query(
                "SELECT * FROM knowledge_mastery_daily_agg "
                "WHERE dt = %(dt)s "
                "ORDER BY knowledge_point_id "
                "LIMIT %(limit)s OFFSET %(offset)s",
                {"dt": target_date, "limit": self.BATCH_SIZE, "offset": offset},
            )

            if not batch:
                break

            weak_points = self.detector.detect_weak_points(
                aggregates=batch,
                scorer=self.scorer,
                historical_data=self.historical_cache,
                content_coverage=self.content_cache,
                total_platform_students=self.total_students,
            )

            self._batch_insert(weak_points)
            total_processed += len(batch)
            offset += self.BATCH_SIZE

            # 显式释放内存
            del batch, weak_points
            gc.collect()

        return total_processed
```
