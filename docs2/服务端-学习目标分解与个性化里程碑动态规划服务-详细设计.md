# 服务端-学习目标分解与个性化里程碑动态规划服务 - 详细设计

## 1. 模块概述

### 1.1 定位与职责

本服务是学习规划子系统的核心引擎，负责将用户设定的**宏观学习目标**（如期中考试、中考冲刺、学期达标）自动分解为可执行的**阶段性里程碑**和**每日学习任务**，并根据实际学习进度动态调整规划。

**与学习规划模块的关系**：学习规划模块（`学习规划-详细设计.md`）定义了目标设定、计划生成、任务管理的整体框架和用户交互；本服务聚焦其**后端核心算法与服务实现**——如何智能分解目标、如何动态规划路径、如何基于实时数据调整里程碑。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 目标解析 | 将自然语言或结构化目标解析为可度量的学习指标 |
| 里程碑生成 | 基于教材章节、知识图谱和考纲自动生成阶段性里程碑 |
| 路径规划 | 综合学生能力画像、剩余时间、章节依赖关系规划最优学习路径 |
| 动态调整 | 根据实际学习进度、掌握度变化、突发事件实时调整计划 |
| 进度预测 | 基于历史学习速率预测目标完成概率和偏差预警 |
| 多目标协调 | 处理学生同时存在多个学科目标时的资源分配和冲突解决 |

### 1.3 设计原则

1. **保守规划**：初始计划偏向保守，预留缓冲时间，避免计划过于激进导致挫败感
2. **渐进细化**：近期里程碑精确到天，远期里程碑精确到周，随时间推移逐步细化
3. **正向激励**：调整计划时优先保留已完成成果，不轻易回退里程碑状态
4. **最小扰动**：动态调整时尽量减少对已有计划的变更幅度
5. **可解释性**：每次调整都生成可理解的调整理由，展示给学生/家长

## 2. 数据模型

### 2.1 核心实体

#### 2.1.1 学习目标（LearningGoal）

```python
class LearningGoal(BaseModel):
    """学习目标 - 用户设定的宏观目标"""
    __tablename__ = "learning_goals"

    id: str                    # 主键, ULID
    user_id: str               # 学生用户ID
    goal_type: str             # 目标类型: exam_preparation | semester_target | skill_improvement | chapter_mastery
    subject_id: str            # 学科ID
    title: str                 # 目标标题, 如 "期末考试数学90+"
    description: str           # 详细描述

    # 目标量化指标
    target_metric: str         # 量化指标类型: score | mastery_rate | completion_rate | ranking
    target_value: float        # 目标值, 如 90.0
    baseline_value: float      # 基线值(当前水平), 如 75.0
    metric_unit: str           # 单位: score_point | percentage | rank

    # 时间范围
    start_date: date           # 目标开始日期
    deadline: date             # 截止日期
    buffer_days: int           # 预留缓冲天数(默认为总天数的10%)
    effective_deadline: date   # 有效截止 = deadline - buffer_days

    # 关联
    textbook_id: str           # 教材版本ID
    grade_id: str              # 年级ID
    semester_id: str           # 学期ID
    exam_type: str             # 考试类型(如适用): midterm | final | zhongkao | gaokao | mock

    # 状态
    status: str                # active | completed | abandoned | expired | paused
    progress_pct: float        # 总体进度百分比 0-100
    completion_probability: float  # 完成概率评估 0-1
    risk_level: str            # 风险等级: low | medium | high | critical

    # 计划参数
    daily_available_minutes: int    # 每日可用学习时间(分钟)
    weekly_available_days: int      # 每周可学习天数
    preferred_time_slots: list      # 偏好时段 ["19:00-21:00"]

    # 元数据
    source: str                # 来源: user_created | ai_suggested | parent_set | teacher_assigned
    ai_generated: bool         # 是否由AI生成
    version: int               # 规划版本号(每次重大调整+1)
    created_at: datetime
    updated_at: datetime
```

#### 2.1.2 里程碑（Milestone）

```python
class Milestone(BaseModel):
    """里程碑 - 目标的阶段性分解"""
    __tablename__ = "learning_milestones"

    id: str                    # 主键
    goal_id: str               # 关联学习目标ID
    user_id: str               # 冗余字段, 方便查询
    milestone_index: int       # 里程碑序号(从1开始)
    phase: str                 # 阶段: foundation | consolidation | breakthrough | sprint | review

    # 里程碑内容
    title: str                 # 如 "第一章 有理数 - 基础掌握"
    description: str
    chapter_ids: list          # 关联教材章节ID列表
    knowledge_point_ids: list  # 关联知识点ID列表

    # 量化目标
    target_mastery_rate: float     # 目标掌握率 0-100
    target_practice_count: int     # 目标练习题数
    target_correct_rate: float     # 目标正确率
    target_study_minutes: int      # 预计学习时长(分钟)

    # 时间规划
    planned_start: date        # 计划开始日期
    planned_end: date          # 计划结束日期
    actual_start: date         # 实际开始日期
    actual_end: date           # 实际完成日期

    # 状态
    status: str                # pending | in_progress | completed | skipped | overdue
    actual_mastery_rate: float     # 实际掌握率
    actual_practice_count: int     # 实际练习题数
    actual_correct_rate: float     # 实际正确率
    actual_study_minutes: int      # 实际学习时长
    completion_pct: float     # 完成百分比 0-100

    # 依赖
    depends_on: list           # 前置里程碑ID列表
    priority: int              # 优先级(越小越优先)

    # 调整记录
    adjustment_count: int      # 被调整次数
    original_planned_end: date # 原始计划结束日期(用于追踪调整)

    created_at: datetime
    updated_at: datetime
```

```python
class DailyTask(BaseModel):
    """每日学习任务 - 里程碑的每日分解"""
    __tablename__ = "learning_daily_tasks"

    id: str                    # 主键
    milestone_id: str          # 关联里程碑ID
    goal_id: str               # 关联目标ID
    user_id: str               # 学生ID
    task_date: date            # 任务日期

    # 任务内容
    task_type: str             # 类型: learn_chapter | practice | review_mistakes | mock_exam | recite | writing
    title: str                 # 如 "学习1.2节 有理数加减法"
    description: str           # 详细说明

    # 任务详情(结构化)
    content_refs: dict         # 关联内容引用
    # 示例:
    # {
    #   "chapter_id": "ch_123",
    #   "knowledge_point_ids": ["kp_1", "kp_2"],
    #   "question_set_id": "qs_456",
    #   "mistake_review_ids": ["mr_1"],
    #   "resource_ids": ["res_1"]
    # }

    # 量化目标
    estimated_minutes: int     # 预计耗时(分钟)
    target_items: int          # 目标完成项数(如做10道题)
    difficulty_level: str      # 难度: easy | medium | hard | adaptive

    # 完成情况
    status: str                # pending | in_progress | completed | partial | skipped | deferred
    actual_minutes: int        # 实际耗时
    completed_items: int       # 完成项数
    performance_score: float   # 表现评分 0-100
    mastery_delta: float       # 掌握度变化

    # 排序
    sort_order: int            # 当日任务排序
    time_slot: str             # 建议时段: morning | afternoon | evening | night

    created_at: datetime
    updated_at: datetime
```

#### 2.1.4 规划调整日志（PlanAdjustmentLog）

```python
class PlanAdjustmentLog(BaseModel):
    """规划调整日志 - 记录每次计划变更"""
    __tablename__ = "plan_adjustment_logs"

    id: str                    # 主键
    goal_id: str               # 关联目标
    user_id: str               # 学生
    adjustment_type: str       # 调整类型: reschedule | reprioritize | add_milestone | remove_milestone | difficulty_change | deadline_change | abandon
    trigger_source: str        # 触发来源: auto_progress | auto_risk | user_request | parent_request | system_event

    # 变更详情
    before_snapshot: dict      # 调整前快照(JSON)
    after_snapshot: dict       # 调整后快照(JSON)
    affected_milestone_ids: list  # 受影响的里程碑
    affected_task_ids: list       # 受影响的任务

    # 原因
    reason_code: str           # 原因码: behind_schedule | ahead_of_schedule | mastery_below_expected | user_absent | exam_date_changed | goal_achieved_early
    reason_description: str    # 可读描述
    ai_reasoning: str          # AI推理过程(如适用)

    # 审计
    created_at: datetime
    created_by: str            # system | user_id | parent_id
```

```python
class LearningPaceModel(BaseModel):
    """学习速率模型 - 每个学生每学科的学习速率追踪"""
    __tablename__ = "learning_pace_models"

    id: str
    user_id: str
    subject_id: str

    # 学习速率统计
    avg_daily_study_minutes: float       # 近30天日均学习时长
    avg_chapter_study_minutes: float     # 平均每章学习时长
    avg_mastery_gain_per_hour: float     # 每小时掌握度提升(百分点)
    avg_practice_correct_rate: float     # 平均练习正确率
    avg_questions_per_session: float     # 每次练习平均做题数

    # 时间模式
    weekday_study_minutes: dict          # {"mon": 45, "tue": 30, ...} 近30天各天均值
    time_slot_preference: dict           # {"morning": 0.1, "afternoon": 0.3, "evening": 0.5, "night": 0.1}
    streak_days: int                     # 连续学习天数
    avg_weekly_active_days: float        # 周均活跃天数

    # 预测模型参数
    pace_trend: str                      # 速率趋势: accelerating | stable | decelerating
    reliability_score: float             # 数据可靠性(0-1, 基于样本量)
    last_7d_pace: float                  # 近7天日均学习分钟
    last_30d_pace: float                 # 近30天日均学习分钟

    # 模型元数据
    sample_days: int                     # 采样天数
    last_updated: datetime
    model_version: int
```

### 2.2 数据库索引

```sql
-- 学习目标查询
CREATE INDEX idx_learning_goals_user_status ON learning_goals(user_id, status);
CREATE INDEX idx_learning_goals_deadline ON learning_goals(deadline) WHERE status = 'active';
CREATE INDEX idx_learning_goals_subject ON learning_goals(user_id, subject_id, status);

-- 里程碑查询
CREATE INDEX idx_milestones_goal_status ON learning_milestones(goal_id, status);
CREATE INDEX idx_milestones_user_date ON learning_milestones(user_id, planned_start, planned_end);
CREATE INDEX idx_milestones_overdue ON learning_milestones(user_id, status)
    WHERE status IN ('in_progress', 'pending') AND planned_end < CURRENT_DATE;

-- 每日任务查询
CREATE INDEX idx_daily_tasks_user_date ON learning_daily_tasks(user_id, task_date);
CREATE INDEX idx_daily_tasks_milestone ON learning_daily_tasks(milestone_id, task_date);
CREATE INDEX idx_daily_tasks_pending ON learning_daily_tasks(user_id, status, task_date)
    WHERE status = 'pending';

-- 调整日志
CREATE INDEX idx_adjustment_logs_goal ON plan_adjustment_logs(goal_id, created_at DESC);
CREATE INDEX idx_adjustment_logs_user ON plan_adjustment_logs(user_id, created_at DESC);

-- 学习速率
CREATE UNIQUE INDEX idx_pace_user_subject ON learning_pace_models(user_id, subject_id);
```

## 4. 核心算法

### 4.1 目标分解算法

```python
class GoalDecompositionEngine:
    """学习目标分解引擎"""

    def __init__(self, knowledge_svc, pace_svc, exam_svc):
        self.knowledge = knowledge_svc
        self.pace = pace_svc
        self.exam = exam_svc

    async def decompose(self, goal: LearningGoal) -> list[Milestone]:
        """将学习目标分解为里程碑序列"""

        # Step 1: 确定学习范围
        scope = await self._determine_scope(goal)

        # Step 2: 构建知识依赖图
        dep_graph = await self._build_dependency_graph(scope.chapter_ids)

        # Step 3: 评估各章节难度和学生基础
        assessments = await self._assess_chapters(goal.user_id, scope.chapter_ids)

        # Step 4: 计算可用学习时间
        available = self._calculate_available_time(goal)

        # Step 5: 分配时间权重(薄弱章节分配更多时间)
        time_alloc = self._allocate_time(assessments, available)

        # Step 6: 拓扑排序生成里程碑序列
        milestones = self._generate_milestones(dep_graph, assessments, time_alloc, goal)

        # Step 7: 插入复习和冲刺里程碑
        milestones = self._insert_review_milestones(milestones, goal)

        # Step 8: 平滑时间线(确保日期连续无间隔)
        milestones = self._smooth_timeline(milestones, goal)

        return milestones
```

#### Step 1: 确定学习范围

```python
    async def _determine_scope(self, goal: LearningGoal) -> Scope:
        if goal.goal_type == "exam_preparation":
            # 考试准备: 根据考纲确定范围
            exam_scope = await self.exam.get_exam_scope(
                goal.exam_type, goal.subject_id, goal.grade_id
            )
            mastered = await self.knowledge.get_mastered_chapters(
                goal.user_id, goal.subject_id
            )
            # 过滤已掌握的章节(掌握率>90%的跳过)
            target = [
                ch for ch in exam_scope.chapter_ids
                if ch.id not in mastered or mastered[ch.id].mastery_rate < 90
            ]
            return Scope(chapters=target, is_exam_driven=True)

        elif goal.goal_type == "semester_target":
            chapters = await self.knowledge.get_semester_chapters(
                goal.textbook_id, goal.semester_id
            )
            return Scope(chapters=chapters, is_exam_driven=False)

        elif goal.goal_type == "chapter_mastery":
            # 单章节掌握: 直接返回指定章节
            return Scope(chapters=[goal.target_chapter_id], is_exam_driven=False)

        elif goal.goal_type == "skill_improvement":
            # 能力提升: 根据能力维度关联知识点反查章节
            kp_ids = await self.knowledge.get_kps_by_dimension(
                goal.target_dimension, goal.subject_id
            )
            chapter_ids = await self.knowledge.get_chapters_by_kps(kp_ids)
            return Scope(chapters=chapter_ids, is_exam_driven=False)


    async def _build_dependency_graph(self, chapter_ids: list[str]) -> DependencyGraph:
        """构建章节间前置依赖图"""
        graph = DependencyGraph()
        for ch_id in chapter_ids:
            prereqs = await self.knowledge.get_prerequisite_chapters(ch_id)
            graph.add_node(ch_id)
            for pre in prereqs:
                if pre in chapter_ids:
                    graph.add_edge(pre, ch_id)
        return graph

    async def _assess_chapters(self, user_id: str, chapter_ids: list[str]) -> dict:
        """评估每个章节的难度和学生当前基础"""
        assessments = {}
        for ch_id in chapter_ids:
            meta = await self.knowledge.get_chapter_meta(ch_id)
            mastery = await self.knowledge.get_chapter_mastery(user_id, ch_id)
            kp_stats = await self.knowledge.get_chapter_kp_stats(ch_id)
            assessments[ch_id] = ChapterAssessment(
                chapter_id=ch_id,
                knowledge_point_count=kp_stats.count,
                avg_difficulty=kp_stats.avg_difficulty,
                current_mastery=mastery.rate if mastery else 0.0,
                mastery_gap=1.0 - (mastery.rate if mastery else 0.0),
                estimated_hours=self._estimate_study_hours(kp_stats, mastery),
            )
        return assessments

    def _estimate_study_hours(self, kp_stats, mastery) -> float:
        base_hours_per_kp = {1: 0.3, 2: 0.5, 3: 0.8, 4: 1.2, 5: 1.8}
        total = sum(base_hours_per_kp.get(kp.difficulty, 0.8) for kp in kp_stats.points)
        mastery_factor = 1.0 - (mastery.rate if mastery else 0.0) * 0.7
        return total * mastery_factor

    def _calculate_available_time(self, goal: LearningGoal) -> TimeBudget:
        total_days = (goal.effective_deadline - goal.start_date).days
        study_days = int(total_days * goal.weekly_available_days / 7)
        total_minutes = study_days * goal.daily_available_minutes
        return TimeBudget(total_days=total_days, study_days=study_days,
                          total_minutes=total_minutes, daily_minutes=goal.daily_available_minutes)

    def _allocate_time(self, assessments: dict, budget: TimeBudget) -> dict:
        total_estimated = sum(a.estimated_hours for a in assessments.values())
        allocations = {}
        for ch_id, assess in assessments.items():
            weight = assess.estimated_hours / total_estimated
            allocated_minutes = int(budget.total_minutes * weight)
            allocations[ch_id] = ChapterTimeAllocation(
                chapter_id=ch_id, allocated_minutes=allocated_minutes,
                allocated_days=max(1, allocated_minutes // budget.daily_minutes), weight=weight)
        return allocations

    def _generate_milestones(self, dep_graph, assessments, time_alloc, goal) -> list:
        sorted_chapters = dep_graph.topological_sort()
        milestones = []
        current_date = goal.start_date
        for ch_id in sorted_chapters:
            assess = assessments[ch_id]
            alloc = time_alloc[ch_id]
            phase = self._determine_phase(assess)
            ms = Milestone(
                goal_id=goal.id, user_id=goal.user_id,
                title=f"{assess.chapter_title} - {phase}",
                phase=phase, chapter_ids=[ch_id],
                planned_start=current_date,
                planned_end=current_date + timedelta(days=alloc.allocated_days - 1),
                target_mastery_rate=self._target_mastery_for_phase(phase),
                depends_on=self._get_predecessor_ids(dep_graph, ch_id, milestones))
            milestones.append(ms)
            current_date = ms.planned_end + timedelta(days=1)
        return milestones

    def _determine_phase(self, assess) -> str:
        if assess.current_mastery < 30: return "foundation"
        elif assess.current_mastery < 60: return "consolidation"
        elif assess.current_mastery < 80: return "breakthrough"
        else: return "review"

    def _insert_review_milestones(self, milestones: list, goal: LearningGoal) -> list:
        result = []
        for i, ms in enumerate(milestones):
            result.append(ms)
            if (i + 1) % 3 == 0 and i < len(milestones) - 1:
                review_days = max(1, (ms.planned_end - ms.planned_start).days // 3)
                result.append(Milestone(
                    title=f"阶段复习", phase="review",
                    planned_start=ms.planned_end + timedelta(days=1),
                    planned_end=ms.planned_end + timedelta(days=review_days)))
        if goal.goal_type == "exam_preparation" and result:
            last = result[-1]
            if (goal.effective_deadline - last.planned_end).days >= 3:
                result.append(Milestone(title="考前冲刺", phase="sprint",
                    planned_start=last.planned_end + timedelta(days=1),
                    planned_end=goal.effective_deadline, target_mastery_rate=95.0))
        return result

    def _smooth_timeline(self, milestones: list, goal: LearningGoal) -> list:
        current = goal.start_date
        for ms in milestones:
            ms.planned_start = current
            duration = max(1, (ms.planned_end - ms.planned_start).days)
            ms.planned_end = current + timedelta(days=duration)
            current = ms.planned_end + timedelta(days=1)
        return milestones
```

### 4.2 每日任务生成算法

每个里程碑在激活时按天拆分为具体任务：

```python
class DailyTaskGenerator:
    async def generate_for_milestone(self, milestone, goal) -> list[DailyTask]:
        days = (milestone.planned_end - milestone.planned_start).days + 1
        daily_minutes = goal.daily_available_minutes
        kps = await self.knowledge.get_chapter_kps(milestone.chapter_ids)
        mistakes = await self.mistake_svc.get_pending_reviews(
            goal.user_id, milestone.knowledge_point_ids, limit=20)
        kp_per_day = self._distribute_kps(kps, days)
        tasks = []
        for day_offset in range(days):
            task_date = milestone.planned_start + timedelta(days=day_offset)
            day_kps = kp_per_day[day_offset]
            remaining = daily_minutes
            # 学习任务 (前60%天数)
            if day_offset < days * 0.6 and day_kps:
                learn = self._create_learn_task(task_date, day_kps, milestone)
                learn.estimated_minutes = min(int(remaining * 0.5), 30)
                remaining -= learn.estimated_minutes
                tasks.append(learn)
            # 练习任务
            if remaining > 15:
                practice = self._create_practice_task(task_date, day_kps, milestone, int(remaining * 0.6))
                remaining -= practice.estimated_minutes
                tasks.append(practice)
            # 错题复习
            if mistakes and remaining > 10:
                review = self._create_review_task(task_date, mistakes, remaining)
                tasks.append(review)
                mistakes = mistakes[review.target_items:]
        return tasks

    def _distribute_kps(self, kps, days):
        if days <= 0: return [kps]
        per_day = max(1, len(kps) // days)
        return [kps[i*per_day:(i+1)*per_day if i<days-1 else len(kps)] for i in range(days)]
```

### 4.3 动态调整算法

```python
class PlanAdjustmentEngine:
    async def evaluate_and_adjust(self, goal):
        milestones = await self._get_active_milestones(goal.id)
        pace = await self.pace_svc.get_model(goal.user_id, goal.subject_id)
        deviation = self._calculate_deviation(goal, pace)
        if abs(deviation.days_behind) <= 1:
            return AdjustmentResult(adjusted=False)
        if deviation.days_behind > 0:
            return await self._adjust_for_behind(goal, milestones, deviation)
        return await self._adjust_for_ahead(goal, milestones, deviation)

    def _calculate_deviation(self, goal, pace):
        elapsed = (date.today() - goal.start_date).days
        total = (goal.effective_deadline - goal.start_date).days
        expected = min(1.0, elapsed / total) if total > 0 else 1.0
        actual = goal.progress_pct / 100.0
        days_behind = int((expected - actual) * total)
        return Deviation(days_behind=days_behind, expected_progress=expected, actual_progress=actual)

    async def _adjust_for_behind(self, goal, milestones, deviation):
        remaining = [m for m in milestones if m.status in ("pending", "in_progress")]
        if not remaining: return AdjustmentResult(adjusted=False)
        available = (goal.effective_deadline - date.today()).days
        total_planned = sum((m.planned_end - m.planned_start).days + 1 for m in remaining)
        # 策略1: 压缩时间线
        if available >= int(total_planned * 0.7):
            ratio = available / total_planned
            current = date.today()
            for ms in remaining:
                new_days = max(1, int(((ms.planned_end - ms.planned_start).days + 1) * ratio))
                ms.planned_start, ms.planned_end = current, current + timedelta(days=new_days - 1)
                ms.adjustment_count += 1
                current = ms.planned_end + timedelta(days=1)
            await self._log_adjustment(goal, "compress", deviation)
            return AdjustmentResult(adjusted=True)
        # 策略2: 降低非核心目标
        for ms in remaining:
            if ms.phase in ("review", "consolidation"):
                ms.target_mastery_rate = max(60, ms.target_mastery_rate - 15)
        await self._log_adjustment(goal, "lower_target", deviation)
        return AdjustmentResult(adjusted=True)
```

### 4.4 完成概率预测

```python
class CompletionProbabilityPredictor:
    def predict(self, goal, pace) -> float:
        if goal.status == "completed": return 1.0
        if goal.status in ("abandoned", "expired"): return 0.0
        elapsed = (date.today() - goal.start_date).days
        total = (goal.effective_deadline - goal.start_date).days
        remaining = (goal.effective_deadline - date.today()).days
        if remaining <= 0: return 0.0
        expected = min(1.0, elapsed / total) if total > 0 else 1.0
        actual = goal.progress_pct / 100.0
        # 四因子加权
        progress_f = max(0.0, 1.0 - (expected - actual) * 2)
        pace_f = min(1.0, pace.avg_daily_study_minutes / max(1, goal.daily_available_minutes))
        budget_hours = remaining * goal.daily_available_minutes / 60
        need_hours = (1.0 - actual) * 100 * pace.avg_chapter_study_minutes / 60 / 100
        budget_f = min(1.0, budget_hours / max(0.1, need_hours))
        streak = min(0.1, pace.streak_days * 0.01)
        trend = {"accelerating": 0.05, "stable": 0.0, "decelerating": -0.05}.get(pace.pace_trend, 0.0)
        history_f = 0.5 + streak + trend
        prob = 0.4*progress_f + 0.3*pace_f + 0.2*budget_f + 0.1*history_f
        return round(max(0.0, min(1.0, prob)), 2)
```

## 5. 状态流转

### 5.1 目标状态机

```
  ┌───────┐  创建成功  ┌────────┐  暂停  ┌────────┐
  │ (new) │──────────▶│ active │──────▶│ paused │
  └───────┘           └───┬────┘       └───┬────┘
                          │                 │ 恢复
               ┌──────────┼──────────┐      │
               ▼          ▼          ▼      │
        ┌──────────┐ ┌────────┐ ┌────────┐ │
        │completed │ │expired │ │abandoned│ │
        └──────────┘ └────────┘ └────────┘ │
            ▲                                │
            └────────────────────────────────┘

规则:
- active → paused: 用户/家长主动暂停
- paused → active: 用户恢复
- active → completed: 进度达标 + 最终测评确认
- active → expired: 截止日已过且未完成
- active → abandoned: 用户主动放弃
```

```
  ┌─────────┐ planned_start到期 ┌─────────────┐ 达成目标 ┌───────────┐
```

## 7. 错误处理

### 7.1 业务异常码

| 异常码 | HTTP | 说明 | 建议 |
|--------|------|------|------|
| `GOAL_001` | 400 | 时间范围不足(< 7天) | 延长截止日期 |
| `GOAL_002` | 400 | 已存在相同学科活跃目标 | 先完成或暂停现有目标 |
| `GOAL_003` | 404 | 目标不存在 | 检查goal_id |
| `GOAL_004` | 409 | 状态不允许此操作 | 检查当前状态 |
| `GOAL_010` | 400 | 里程碑无法跳过(有依赖) | 先处理依赖 |
| `GOAL_011` | 400 | 无法进一步压缩 | 考虑降低目标 |
| `GOAL_020` | 400 | 任务不属于当前用户 | 检查权限 |
| `GOAL_030` | 422 | 分解失败(数据不完整) | 联系运营补充教材 |
| `GOAL_050` | 503 | 依赖服务不可用 | 稍后重试 |

### 7.2 降级策略

| 场景 | 方案 |
|------|------|
| 知识点服务不可用 | 用缓存章节结构生成简化里程碑 |
| 新用户无速率数据 | 使用学段年级默认参数 |
| AI目标解析失败 | 降级为手动表单模式 |
| 进度评估超时 | 跳过自动调整, 下次定时任务处理 |
| 错题服务不可用 | 跳过错题复习, 用额外练习替代 |
