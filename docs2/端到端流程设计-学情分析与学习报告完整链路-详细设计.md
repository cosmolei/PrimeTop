# 端到端流程设计 — 学情分析与学习报告完整链路 详细设计

> 本文档描述 PrimeTop 学情分析与学习报告生成、展示、推送的完整端到端流程，
> 涵盖数据采集 → 实时聚合 → 分析引擎 → 报告生成 → 多端展示 → 家长推送全链路。

## 2. 核心数据结构定义

### 2.1 学习行为事件（LearningBehaviorEvent）

所有模块产生的学习行为统一抽象为事件，写入事件流。

```java
/**
 * 学习行为事件 — 统一事件模型
 */
public class LearningBehaviorEvent {
    /** 事件唯一ID */
    private String eventId;
    /** 学生用户ID */
    private Long studentId;
    /** 租户ID */
    private Long tenantId;
    /** 事件类型枚举 */
    private BehaviorEventType eventType;
    /** 学科ID */
    private Long subjectId;
    /** 发生时间(毫秒时间戳) */
    private Long eventTime;
    /** 学习会话ID，关联 LearningSession */
    private String sessionId;
    /** 关联知识点ID列表 */
    private List<Long> knowledgePointIds;
    /** 关联章节ID */
    private Long chapterId;
    /** 事件详情（JSON，按类型不同结构不同） */
    private Map<String, Object> payload;
    /** 数据来源端 */
    private String sourceClient; // android | ios | web | mini
    /** 设备ID */
    private String deviceId;
}
```

```java
/**
 * 事件类型枚举
 */
public enum BehaviorEventType {
    // === 答题类 ===
    QUESTION_ANSWERED,          // 完成一道题作答
    QUESTION_CORRECT,           // 答对
    QUESTION_WRONG,             // 答错
    QUESTION_SKIP,              // 跳过

    // === 错题类 ===
    MISTAKE_ADDED,              // 加入错题本
    MISTAKE_REVIEWED,           // 复习错题
    MISTAKE_CORRECTED,          // 订正正确

    // === AI对话类 ===
    AI_CONVERSATION_STARTED,    // 开始AI对话
    AI_QUESTION_ASKED,          // 提了一个问题
    AI_HELPFUL_RATED,           // 评价有帮助
    AI_UNHELPFUL_RATED,         // 评价没帮助

    // === 时长类 ===
    STUDY_SESSION_START,        // 学习会话开始
    STUDY_SESSION_END,          // 学习会话结束
    STUDY_PAGE_ENTER,           // 进入学习页面
    STUDY_PAGE_LEAVE,           // 离开学习页面

    // === 计划类 ===
    PLAN_TASK_COMPLETED,        // 完成计划任务
    PLAN_TASK_SKIPPED,          // 跳过计划任务

    // === 拍题类 ===
    PHOTO_QUESTION_SUBMITTED,   // 提交拍照搜题
    PHOTO_QUESTION_RESOLVED,    // 拍照搜题解析完成

    // === 背诵类 ===
    RECITATION_STARTED,         // 开始背诵
    RECITATION_PASSED,          // 背诵通过
    RECITATION_FAILED,          // 背诵未通过
}
```

### 2.2 答题事件 Payload

```java
/**

public class QuestionAnsweredPayload {

    private Integer difficulty;
    /** 学生答案 */
    private String studentAnswer;
    /** 正确答案 */
    private String correctAnswer;

    private Boolean isCorrect;
    /** 答题耗时（秒） */
    private Integer timeCostSeconds;
    /** 答题模式 */
    private AnswerMode answerMode; // practice | exam | review | homework
    /** 练习批次ID */
    private String practiceBatchId;
    /** 题目所属知识点列表 */
    private List<KnowledgePointRef> knowledgePoints;
}

public class KnowledgePointRef {
    private Long knowledgePointId;
    private String knowledgePointName;
    /** 该知识点在题目中的权重 (0-1) */
    private Double weight;
}
```

```sql
    mistake_new_count   INT DEFAULT 0   COMMENT '新增错题数',
    mistake_reviewed_count INT DEFAULT 0 COMMENT '复习错题数',

    -- AI使用统计
    ai_question_count   INT DEFAULT 0   COMMENT 'AI提问次数',

    -- 计划统计
    plan_task_total     INT DEFAULT 0   COMMENT '计划任务总数',
    plan_task_completed INT DEFAULT 0   COMMENT '已完成任务数',
    plan_completion_rate DECIMAL(5,4) DEFAULT 0 COMMENT '计划完成率',
    
    -- 拍题统计
    photo_submit_count  INT DEFAULT 0   COMMENT '拍照搜题次数',
    
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
```

## 4. 状态流转

### 4.1 报告生成状态机

```text
                        ┌───────────┐
                        │ SCHEDULED │ ← 定时任务触发
                        └─────┬─────┘
                              │ 开始生成
                              ▼
                        ┌───────────┐
                   ┌──→ │GENERATING │
                   │    └─────┬─────┘
```

```java
    public void onEvent(LearningBehaviorEvent event) {
        // 1. 参数校验
        if (event.getStudentId() == null || event.getEventTime() == null) {
            log.warn("Invalid event: {}", event.getEventId());
            return;
        }

        LocalDate statDate = Instant.ofEpochMilli(event.getEventTime())
            .atZone(ZoneId.of("Asia/Shanghai")).toLocalDate();

        if (event.getKnowledgePointIds() != null && !event.getKnowledgePointIds().isEmpty()) {
            asyncUpdateKnowledgePointMastery(event);
        }

        // 4. 更新能力维度（异步，批量触发）
        asyncUpdateAbilityDimensions(event);
    }

    private void updateDailyStats(LearningBehaviorEvent event, LocalDate statDate) {
        // 使用 INSERT ON DUPLICATE KEY UPDATE 实现幂等聚合
        switch (event.getEventType()) {
            case QUESTION_ANSWERED, QUESTION_CORRECT, QUESTION_WRONG -> {
                QuestionAnsweredPayload payload = castPayload(event, QuestionAnsweredPayload.class);
                dailyStatsMapper.upsertQuestionStats(
                    event.getTenantId(), event.getStudentId(), statDate, event.getSubjectId(),
                    1,                                          // question_count +1
                    payload.getIsCorrect() ? 1 : 0,            // correct/wrong
                    payload.getTimeCostSeconds(),               // accumulate time
                    payload.getDifficulty()                     // accumulate difficulty
                );
            }
            case STUDY_SESSION_END -> {

                event.getTenantId(), event.getStudentId(), statDate, event.getSubjectId());

        }
    }
```

```java
@Service
public class KnowledgePointMasteryUpdater {

    /**
     * 基于答题事件增量更新知识点掌握度
     * 使用贝叶斯更新：先验 + 新证据 → 后验
     */
    @Async("masteryUpdateExecutor")
    public void updateMastery(LearningBehaviorEvent event) {
        QuestionAnsweredPayload payload = castPayload(event, QuestionAnsweredPayload.class);
        if (payload == null) return;

        for (KnowledgePointRef kpRef : payload.getKnowledgePoints()) {
            KnowledgePointMastery mastery = masteryMapper.selectForUpdate(
                event.getTenantId(), event.getStudentId(), kpRef.getKnowledgePointId());

            if (mastery == null) {
                // 冷启动：创建初始记录
                mastery = createInitialMastery(event, kpRef);
            }

            // 贝叶斯增量更新
            double priorScore = mastery.getMasteryScore();
            boolean isCorrect = Boolean.TRUE.equals(payload.getIsCorrect());
            double weight = kpRef.getWeight();

            // EMA(指数移动平均)更新：α = 0.3
            double alpha = 0.3;
            double evidence = isCorrect ? 100.0 : 0.0;
            double newScore = priorScore * (1 - alpha * weight) + evidence * alpha * weight;
            newScore = Math.max(0, Math.min(100, newScore));

            // 更新统计量
            mastery.setTotalAttemptCount(mastery.getTotalAttemptCount() + 1);
            if (isCorrect) {
                mastery.setCorrectCount(mastery.getCorrectCount() + 1);
            } else {
                mastery.setWrongCount(mastery.getWrongCount() + 1);
            }
            mastery.setAccuracyRate((double) mastery.getCorrectCount() / mastery.getTotalAttemptCount());
            mastery.setMasteryScore(BigDecimal.valueOf(newScore).setScale(2, RoundingMode.HALF_UP));
            mastery.setMasteryLevel(MasteryLevel.fromScore(newScore).name());
            mastery.setLastAttemptAt(LocalDateTime.now());

            // 计算趋势
            calculateTrend(mastery);

            // 设置下次复习时间（基于遗忘曲线）
            scheduleNextReview(mastery);

            masteryMapper.updateById(mastery);
        }
    }

    private void scheduleNextReview(KnowledgePointMastery mastery) {
        double score = mastery.getMasteryScore().doubleValue();
        // 掌握度越低，复习间隔越短
        int baseHours;
        if (score >= 80) baseHours = 72;       // 3天
        else if (score >= 60) baseHours = 48;   // 2天
        else if (score >= 40) baseHours = 24;   // 1天
        else baseHours = 12;                     // 半天

        mastery.setNextReviewAt(LocalDateTime.now().plusHours(baseHours));
    }
}
```

### 5.3 薄弱知识点识别引擎

```java
@Service
public class WeakPointIdentificationEngine {

    /**
     * 识别薄弱知识点 — 综合多维度评分
     * 
     * 维度权重：
     *   正确率 (40%) — 直接反映掌握程度
     *   错误频率 (25%) — 高频错误说明系统性问题
     *   趋势方向 (20%) — 下滑趋势需要关注
     *   时间衰减 (15%) — 长时间未复习也需要关注
     */
    public List<WeakKnowledgePoint> identifyWeakPoints(Long studentId, Long subjectId, int limit) {
        List<KnowledgePointMastery> masteries = masteryMapper.selectByStudentAndSubject(studentId, subjectId);

        return masteries.stream()
            .filter(m -> m.getTotalAttemptCount() >= 3) // 至少3次尝试才有统计意义
            .map(m -> {
                double weaknessScore = calculateWeaknessScore(m);
                return new WeakKnowledgePoint(m, weaknessScore);
            })
            .sorted(Comparator.comparingDouble(WeakKnowledgePoint::getWeaknessScore).reversed())
            .limit(limit)
            .collect(Collectors.toList());
    }

    private double calculateWeaknessScore(KnowledgePointMastery m) {
        // 1. 正确率维度 (40%) — 正确率越低，分数越高
        double accuracyScore = (1 - m.getAccuracyRate()) * 100;

        // 2. 错误频率维度 (25%) — 近7天错误占比
        int recentErrors = getRecentErrorCount(m, 7);
        double errorFreqScore = Math.min(100, recentErrors * 20.0);

        // 3. 趋势维度 (20%) — 下滑幅度
        double trendScore = "DOWN".equals(m.getTrendDirection())
            ? Math.min(100, Math.abs(m.getTrendChange().doubleValue()) * 5)
            : 0;

        // 4. 时间衰减维度 (15%) — 越久没复习分数越高
        long daysSinceReview = m.getLastReviewAt() == null ? 30
            : ChronoUnit.DAYS.between(m.getLastReviewAt(), LocalDateTime.now());
        double timeScore = Math.min(100, daysSinceReview * 5.0);

        return accuracyScore * 0.40 + errorFreqScore * 0.25 + trendScore * 0.20 + timeScore * 0.15;
    }
}
```

### 7.1 趋势对比计算

```java
@Service
public class TrendCalculator {

    /**
     * 计算趋势对比 — 当前周期 vs 上一周期
     */
    public TrendComparison calculate(Long studentId, LocalDate periodStart, LocalDate periodEnd) {
        long periodDays = ChronoUnit.DAYS.between(periodStart, periodEnd) + 1;

        // 当前周期数据
        PeriodStats current = aggregatePeriodStats(studentId, periodStart, periodEnd);

        // 上一周期数据
        LocalDate prevEnd = periodStart.minusDays(1);
        LocalDate prevStart = prevEnd.minusDays(periodDays - 1);
        PeriodStats previous = aggregatePeriodStats(studentId, prevStart, prevEnd);

        return TrendComparison.builder()
            .currentPeriod(PeriodStatsVO.from(current))
            .previousPeriod(PeriodStatsVO.from(previous))
            .changes(calculateChanges(current, previous))
            .build();
    }

    private Map<String, String> calculateChanges(PeriodStats current, PeriodStats previous) {
        Map<String, String> changes = new LinkedHashMap<>();
        changes.put("accuracyRate", formatChange(current.getAccuracyRate(), previous.getAccuracyRate()));
        changes.put("studyMinutes", formatChange(current.getStudyMinutes(), previous.getStudyMinutes()));
        changes.put("planCompletionRate", formatChange(
            current.getPlanCompletionRate(), previous.getPlanCompletionRate()));
        changes.put("mistakeCorrectionRate", formatChange(
            current.getCorrectionRate(), previous.getCorrectionRate()));
        return changes;
    }

    private String formatChange(double current, double previous) {
        if (previous == 0) return current > 0 ? "+∞" : "0";
        double change = (current - previous) / previous * 100;
        return String.format("%+.0f%%", change);
```

### 7.2 能力维度评估更新

```java
@Service
public class AbilityDimensionUpdater {

    /** 能力维度定义映射 */
    private static final Map<String, List<String>> SUBJECT_DIMENSION_MAP = Map.of(
        "MATH", List.of("CALCULATION", "LOGIC", "SPATIAL", "ABSTRACT_REASONING"),
        "CHINESE", List.of("READING_COMPREHENSION", "EXPRESSION", "MEMORY", "LITERARY_ANALYSIS"),
        "ENGLISH", List.of("LISTENING", "SPEAKING", "READING_COMPREHENSION", "WRITING", "GRAMMAR", "VOCABULARY"),
        "PHYSICS", List.of("LOGIC", "CALCULATION", "SPATIAL", "EXPERIMENT_ANALYSIS"),
        "CHEMISTRY", List.of("CALCULATION", "LOGIC", "EXPERIMENT_ANALYSIS", "MEMORY"),
        "BIOLOGY", List.of("MEMORY", "LOGIC", "EXPERIMENT_ANALYSIS", "READING_COMPREHENSION")
    );

    /**
     * 基于答题行为更新能力维度
     * 使用加权滑动窗口：最近N次答题行为加权评估
     */
    @Async
    public void updateDimensions(LearningBehaviorEvent event) {
        QuestionAnsweredPayload payload = castPayload(event, QuestionAnsweredPayload.class);
        if (payload == null) return;

        String subjectCode = getSubjectCode(event.getSubjectId());
        List<String> dimensions = SUBJECT_DIMENSION_MAP.getOrDefault(subjectCode, List.of());

        for (String dimCode : dimensions) {
            // 基于题目类型和知识点映射到能力维度
            double contribution = calculateDimensionContribution(
                dimCode, payload.getQuestionType(), payload.getKnowledgePoints());

            if (contribution > 0) {
                // 获取最近50次相关答题记录，加权计算
                double weightedScore = calculateWeightedScore(
                    event.getStudentId(), event.getSubjectId(), dimCode, 50);

                abilityMapper.upsertScore(
                    event.getTenantId(),
                    event.getStudentId(),
                    event.getSubjectId(),
                    dimCode,
                    weightedScore,
                    LocalDateTime.now()
                );
            }
        }
    }

    /**
     * 加权分数计算 — 近期行为权重更高
     */
    private double calculateWeightedScore(Long studentId, Long subjectId,
                                            String dimCode, int windowSize) {
        List<AnswerRecord> recentRecords = answerRecordMapper.selectRecentByDimension(
            studentId, subjectId, dimCode, windowSize);

        if (recentRecords.isEmpty()) return 0;

        double weightedSum = 0;
        double totalWeight = 0;

        for (int i = 0; i < recentRecords.size(); i++) {
            // 线性衰减：最新的权重为1.0，最旧的为0.2
            double weight = 1.0 - (0.8 * i / recentRecords.size());
            double score = recentRecords.get(i).getIsCorrect() ? 100.0 : 0.0;
            weightedSum += score * weight;
            totalWeight += weight;
        }

        return totalWeight > 0 ? weightedSum / totalWeight : 0;
    }
}
```

## 8. 错误处理与降级策略

### 8.1 错误场景与处理

| 错误场景 | 处理策略 | 降级方案 |
|----------|----------|----------|
| 数据聚合超时 | 超时3s后使用缓存数据 | 展示上次成功聚合的结果 |
| AI建议生成失败 | 捕获异常，使用模板建议 | 基于规则的固定建议文本 |
| 报告生成失败 | 重试≤3次，间隔递增(5/30/120s) | 标记FAILED，下次定时任务补生成 |
| 事件流消息积压 | 监控消费延迟，告警 | 降级为批量定时聚合 |
| 知识点掌握度计算异常 | 跳过该事件，记录日志 | 保持上一次有效计算结果 |
| 家长端报告推送失败 | 记录推送失败状态，稍后重试 | APP内消息中心兜底 |
| 历史统计数据缺失 | 仅使用有数据的周期 | 展示"数据不足"提示 |

```java
    @Around("execution(* com.primetop.service.StudyInsightService.getOverview(..))")

            }

            // 降级2：返回最小化数据
            return StudyInsightOverview.empty(studentId, period);
        }
    }
```

```java
@Component
@Slf4j
public class StatsConsistencyChecker {

    /**
     * 每日凌晨校验统计数据一致性
     * 对比 event明细聚合 vs daily_stats 表数据
     */
    @Scheduled(cron = "0 30 3 * * ?", zone = "Asia/Shanghai")
    public void checkDailyConsistency() {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        List<Long> activeStudents = dailyStatsMapper.selectActiveStudents(yesterday);

        int inconsistencyCount = 0;
        for (Long studentId : activeStudents) {
            // 从事件表重新聚合
            StudentDailyStats recalculated = eventMapper.reaggregateDailyStats(studentId, yesterday);
            // 对比daily_stats表
            StudentDailyStats stored = dailyStatsMapper.selectByDate(studentId, yesterday);

            if (!isConsistent(recalculated, stored)) {
                log.warn("统计数据不一致: studentId={}, date={}, 修正中...", studentId, yesterday);
                // 以重新聚合的结果为准
                dailyStatsMapper.updateConsistency(studentId, yesterday, recalculated);
                inconsistencyCount++;
            }
        }

        if (inconsistencyCount > 0) {
            log.warn("统计数据一致性校验完成: 发现{}条不一致已修正", inconsistencyCount);
            alertService.sendConsistencyAlert(inconsistencyCount);
        }
    }

    private boolean isConsistent(StudentDailyStats a, StudentDailyStats b) {
        if (a == null || b == null) return a == b;
        return Objects.equals(a.getQuestionCount(), b.getQuestionCount())
            && Objects.equals(a.getCorrectCount(), b.getCorrectCount())
            && Math.abs(a.getTotalStudySeconds() - b.getTotalStudySeconds()) < 10;
    }
}
```

```java
@Service
public class StudyInsightCacheManager {

    private static final Duration OVERVIEW_CACHE_TTL = Duration.ofMinutes(10);
    private static final Duration MASTERY_CACHE_TTL = Duration.ofMinutes(30);

        multiLevelCache.evict("insight:overview:" + studentId + ":WEEK");
```

## 12. 安全与隐私

1. **数据隔离**: 所有查询强制带 `tenant_id` 和 `student_id` 过滤，防止越权
2. **家长端权限**: 家长只能查看已绑定孩子的报告，接口层校验绑定关系
3. **报告分享**: 分享卡片仅包含摘要数据，完整报告需登录查看
4. **AI建议脱敏**: 生成建议时使用匿名化数据，不泄露学生个人身份信息
5. **数据保留**: 行为事件保留6个月，统计摘要保留2年，报告永久保留
6. **家长报告推送**: 仅向已认证绑定的家长手机号推送，不泄露给第三方
