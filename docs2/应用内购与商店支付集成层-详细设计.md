# 应用内购与商店支付集成层 — 详细设计

> 版本：v1.1 | 更新日期：2026-08-17 | 状态：正式（v1.0 截断于 §4.4 CONSUMPTION_REQUEST 处理 docstring 中段，本版补全至 §17；并修正三处 v1.0 缺陷：Apple 消费数据响应 SLA 应为 12 小时而非 48 小时、Flutter `completePurchase` 应为 `InAppPurchase` 实例方法、通知处理器缺失 datetime 导入）

## 1. 模块概述

### 1.1 背景

PrimeTop 作为面向未成年人的教育类 APP，需在 Android（Google Play、国内应用商店）和 iOS（Apple App Store）双平台上架并实现付费订阅和增值服务购买。各支付渠道的 SDK 接入、票据验证、订阅管理、合规要求和退款策略差异显著，需要统一封装一层**商店支付集成层**，对上层业务屏蔽底层差异。

### 1.2 设计目标

1. **统一接口**：上层业务（支付与会员订阅模块）通过统一抽象接口调用支付能力，无需关心具体支付渠道。
2. **安全可靠**：所有支付凭据必须经过服务端二次验证，防止伪造和重放攻击。
3. **合规达标**：满足 Apple App Store Review Guidelines、Google Play政策以及国内应用商店对儿童/教育类 APP 的特殊要求。
4. **对账准确**：支持多渠道订单对账，保证服务端订单状态与商店实际状态一致。
5. **优雅降级**：商店接口异常时提供明确错误反馈，避免用户资金损失。

### 1.3 范围与优先级

| 功能 | 渠道 | 优先级 | MVP |
|------|------|--------|-----|
| Apple IAP — 消耗型商品（次数包） | iOS | P0 | ✅ |
| Apple IAP — 自动续期订阅 | iOS | P0 | ✅ |
| Apple IAP — 非消耗型商品（专项包） | iOS | P1 | ❌ |
| Google Play Billing — 一次性购买 | Android | P0 | ✅ |

| 微信支付 APP 支付 | 国内 Android | P0 | ✅ |

| 小米/OPPO/vivo 应用商店支付 | 国内渠道 | P3 | ❌ |

## 2. 核心概念

| 术语 | 定义 |
|------|------|
| IAP | In-App Purchase，苹果应用内购买 |
| SKU / Product ID | 商店中配置的商品标识符，与 PrimeTop 内部商品码映射 |
| Receipt / 票据 | 购买成功后商店返回的凭据数据，需服务端验证 |
| Transaction ID | 商店侧唯一交易标识，用于去重和对账 |
| Original Transaction ID | Apple 订阅的原始交易 ID（续费交易共享同一 original ID） |
| Purchase Token | Google Play 购买令牌，用于服务端 API 查询和确认 |
| Subscription | 自动续期订阅，周期结束自动扣款 |
| One-time Purchase | 一次性购买（消耗型/非消耗型） |
| Grace Period | 宽限期，订阅扣款失败后保留权益的缓冲时间 |
| Billing Retry | 计费重试，Apple/Google 在扣款失败后自动重试 |
| Voided Purchase | 已退款/撤销的购买记录 |

Future<List<ProductDetails>> loadProducts(List<String> internalCodes) async {
  // 1. 根据内部码查询对应 Apple SKU
  final skuMap = await _paymentApi.getSkuMapping(
    store: 'apple',
    internalCodes: internalCodes,
  );
  final appleSkus = skuMap.values.toList();

  // 2. 调用 StoreKit 查询商品信息
  final products = await _inAppPurchase.queryProductDetails(
    Set.from(appleSkus),
  );

  return products.map((p) => ProductDetails(
    internalCode: skuMap.inverse[p.id]!,
    storeSku: p.id,
    title: p.title,
    description: p.description,
    price: p.price,
    priceValue: p.rawPrice,
  )).toList();
}

/// 发起购买
Future<PurchaseResult> initiatePurchase(ProductDetails product) async {
  final completer = Completer<PurchaseResult>();

  // 监听购买流
  _purchaseStream.listen(
    (purchaseDetailsList) async {
      for (final details in purchaseDetailsList) {
        if (details.productID != product.storeSku) continue;

        switch (details.status) {
          case PurchaseStatus.purchased:
            // 3. 提交 Receipt 到服务端验证
            final result = await _verifyAndDeliver(details);
            if (result.success) {
              _inAppPurchase.completePurchase(details); // 告知 StoreKit 交易完成（v1.1 修正：实例方法）
              completer.complete(PurchaseResult.success(result.orderId!));
            } else {
              completer.complete(PurchaseResult.verificationFailed(result.error!));
            }
            break;

          case PurchaseStatus.error:
            completer.complete(PurchaseResult.error(details.error!));
            break;

          case PurchaseStatus.canceled:
            completer.complete(PurchaseResult.canceled);
            break;

          case PurchaseStatus.pending:
            // 需要家长批准（Ask to Buy）或其他审批
            completer.complete(PurchaseResult.pending);
            break;

          default:
            break;
        }
      }
    },
    onDone: () => completer.complete(PurchaseResult.unknown),
  );

  // 发起购买请求
  final purchaseParam = PurchaseParam(
    productDetails: product.storeProduct,
  );
  _inAppPurchase.buyNonConsumable(purchaseParam: purchaseParam);

  return completer.future;
}

#### 4.3.2 Receipt 验证服务实现

```python
# payment/iap/apple_receipt_verifier.py

import base64
import httpx
from dataclasses import dataclass
from enum import Enum
from typing import Optional

class AppleEnvironment(Enum):
    SANDBOX = "sandbox"
    PRODUCTION = "buy"

@dataclass
class ReceiptVerifyResult:
    success: bool
    transaction_id: Optional[str] = None
    original_transaction_id: Optional[str] = None
    product_id: Optional[str] = None
    purchase_date_ms: Optional[int] = None
    expires_date_ms: Optional[int] = None  # 订阅专用
    is_trial: bool = False
    environment: Optional[str] = None
    error: Optional[str] = None
    # App Store Server API V2 JWS 数据
    jws_transaction: Optional[dict] = None

class AppleReceiptVerifier:
    """Apple Receipt 验证器"""

    PRODUCTION_URL = "https://buy.itunes.apple.com/verifyReceipt"
    SANDBOX_URL = "https://sandbox.itunes.apple.com/verifyReceipt"

    def __init__(self, shared_secret: str, bundle_id: str):
        self.shared_secret = shared_secret
        self.bundle_id = bundle_id

    async def verify(
        self,
        receipt_data: str,
        expected_product_id: Optional[str] = None,
    ) -> ReceiptVerifyResult:
        """验证 Receipt 并返回解析结果"""

        # 1. 先尝试生产环境
        result = await self._call_verify(self.PRODUCTION_URL, receipt_data)
        if result is None:
            return ReceiptVerifyResult(success=False, error="APPLE_API_ERROR")

        # 2. 状态码 21007 表示沙盒 Receipt 发到了生产环境，需重试沙盒
        if result.get("status") == 21007:
            result = await self._call_verify(self.SANDBOX_URL, receipt_data)
            if result is None:
                return ReceiptVerifyResult(success=False, error="APPLE_API_ERROR")

        status = result.get("status")
        if status != 0:
            error_map = {
                21000: "APP_STORE_NOT_ACCESSIBLE",
                21002: "RECEIPT_MALFORMED",
                21003: "RECEIPT_AUTHENTICATED_FAILED",
                21004: "SHARED_SECRET_MISMATCH",
                21005: "RECEIPT_SERVER_UNAVAILABLE",
                21006: "RECEIPT_VALID_BUT_SUB_EXPIRED",
                21008: "NOT_PRODUCTION_RECEIPT",
                21009: "RECEIPT_WITHOUT_PURCHASE",
                21010: "RECEIPT_ACCOUNT_NOT_FOUND",
            }
            return ReceiptVerifyResult(
                success=False,
                error=error_map.get(status, f"UNKNOWN_STATUS_{status}"),
            )

        # 3. 解析 latest_receipt_info（订阅）或 receipt（一次性）
        receipt_info = self._extract_latest_transaction(result)
        if not receipt_info:
            return ReceiptVerifyResult(success=False, error="NO_TRANSACTION_FOUND")

        # 4. 校验 bundle_id
        actual_bundle = result.get("receipt", {}).get("bundle_id", "")
        if actual_bundle != self.bundle_id:
            return ReceiptVerifyResult(
                success=False,
                error="BUNDLE_ID_MISMATCH",
            )

        # 5. 校验 product_id
        product_id = receipt_info.get("product_id", "")
        if expected_product_id and product_id != expected_product_id:
            return ReceiptVerifyResult(
                success=False,
                error="PRODUCT_ID_MISMATCH",
            )

        environment = result.get("environment", "Production")

        return ReceiptVerifyResult(
            success=True,
            transaction_id=receipt_info.get("transaction_id"),
            original_transaction_id=receipt_info.get("original_transaction_id"),
            product_id=product_id,
            purchase_date_ms=int(receipt_info.get("purchase_date_ms", 0)),
            expires_date_ms=self._safe_int(receipt_info.get("expires_date_ms")),
            is_trial=receipt_info.get("is_trial_period") == "true",
            environment=environment,
        )

    async def _call_verify(self, url: str, receipt_data: str) -> Optional[dict]:
        """调用 Apple verifyReceipt API"""
        payload = {
            "receipt-data": receipt_data,
            "password": self.shared_secret,
            "exclude-old-transactions": True,
        }
        async with httpx.AsyncClient(timeout=30) as client:
            try:
                resp = await client.post(url, json=payload)
                resp.raise_for_status()
                return resp.json()
            except (httpx.HTTPError, ValueError):
                return None

    def _extract_latest_transaction(self, result: dict) -> Optional[dict]:
        """提取最新交易记录"""
        # 订阅型：取 latest_receipt_info 的最后一条
        latest = result.get("latest_receipt_info", [])
        if latest:
            return max(latest, key=lambda x: int(x.get("purchase_date_ms", 0)))
        # 一次性购买：取 receipt 中的 in_app 最后一条
        in_app = result.get("receipt", {}).get("in_app", [])
        if in_app:
            return max(in_app, key=lambda x: int(x.get("purchase_date_ms", 0)))
        return None

    @staticmethod
    def _safe_int(val) -> Optional[int]:
        if val is None:
            return None
        try:
            return int(val)
        except (TypeError, ValueError):
            return None
```

### 4.4 App Store Server Notification V2

#### 4.4.1 通知类型与处理策略

| Notification Type | 触发场景 | 处理动作 |
|-------------------|----------|----------|
| `DID_RENEW` | 订阅续期成功 | 延长会员到期时间 |
| `DID_FAIL_TO_RENEW` | 续期失败（计费问题） | 进入宽限期，保留权益 N 天 |
| `DID_CHANGE_RENEWAL_STATUS` | 用户关闭/开启自动续期 | 更新订阅状态，发送提醒 |
| `SUBSCRIBED` | 首次订阅或重新订阅 | 激活会员权益 |
| `EXPIRED` | 订阅到期 | 降级处理，触发挽留 |
| `GRACE_PERIOD_EXPIRED` | 宽限期结束仍未续费 | 立即降级 |
| `REVOKE` | 家庭共享撤销 | 检查该用户权益 |
| `REFUND` | 用户获退款 | 撤销权益，标记订单已退款 |
| `CONSUMPTION_REQUEST` | 用户申请退款，Apple 请求消费数据 | 12小时内上报消费数据（v1.1 修正：原 48 为笔误） |
| `PRICE_INCREASE` | 价格上涨，用户需同意 | 更新价格信息 |
| `RENEWAL_EXTENDED` | Apple 延长续期日期 | 更新到期时间 |

#### 4.4.2 通知处理服务

```python
# payment/iap/apple_notification_handler.py

import asyncio
import base64
import hashlib
import hmac
import json
import time
from datetime import datetime, timedelta, timezone
from typing import Dict, Any, Optional

utc = timezone.utc

class AppleNotificationHandler:
    """处理 App Store Server Notification V2"""

    # 宽限期（秒），对应 Apple 配置的 Billing Grace Period
    GRACE_PERIOD_SECONDS = 16 * 24 * 3600  # 16天

    # 消费数据响应超时（Apple 要求收到 CONSUMPTION_REQUEST 后 12 小时内上报，v1.1 修正：原 48 为笔误）
    CONSUMPTION_RESPONSE_DEADLINE_HOURS = 12

    def __init__(
        self,
        signing_key_provider,  # Apple 签名验证密钥提供者
        order_service,         # 订单服务
        membership_service,    # 会员服务
    ):
        self.signing_key_provider = signing_key_provider
        self.order_service = order_service
        self.membership_service = membership_service

    async def handle_notification(self, raw_body: bytes, signature_headers: dict) -> dict:
        """
        处理 Apple Server Notification V2
        Apple 使用 JWS (JSON Web Signature) 格式
        """
        # 1. 验证 JWS 签名
        payload = await self._verify_jws(raw_body, signature_headers)
        if not payload:
            return {"status": "INVALID_SIGNATURE"}

        notification_type = payload.get("notificationType")
        subtype = payload.get("subtype", "")
        transaction_info = payload.get("data", {})

        original_txn_id = transaction_info.get("originalTransactionId")
        product_id = transaction_info.get("productId")

        # 2. 查找关联订单
        order = await self.order_service.find_by_original_transaction_id(
            original_txn_id,
            store="apple",
        )

        if not order:
            # 可能是通知先于客户端确认到达，记录待处理通知
            await self._save_pending_notification(original_txn_id, payload)
            return {"status": "ORDER_NOT_FOUND_PENDING"}

        # 3. 根据类型分发处理
        handler_map = {
            "DID_RENEW": self._handle_renewal,
            "DID_FAIL_TO_RENEW": self._handle_renewal_failure,
            "DID_CHANGE_RENEWAL_STATUS": self._handle_renewal_status_change,
            "SUBSCRIBED": self._handle_subscribed,
            "EXPIRED": self._handle_expired,
            "GRACE_PERIOD_EXPIRED": self._handle_grace_expired,
            "REFUND": self._handle_refund,
            "REVOKE": self._handle_revoke,
            "CONSUMPTION_REQUEST": self._handle_consumption_request,
            "RENEWAL_EXTENDED": self._handle_renewal_extended,
        }

        handler = handler_map.get(notification_type, self._handle_unknown)
        return await handler(order, transaction_info, subtype)

    async def _handle_renewal(self, order, txn_info: dict, subtype: str) -> dict:
        """处理续期成功"""
        expires_date_ms = txn_info.get("expiresDate", 0)
        new_expires_at = datetime.fromtimestamp(expires_date_ms / 1000, tz=utc)

        # 更新订单到期时间
        await self.order_service.update_expiry(order["id"], new_expires_at)
        # 延长会员权益
        await self.membership_service.extend(
            user_id=order["user_id"],
            plan=order["product_code"],
            expires_at=new_expires_at,
            reason="APPLE_RENEWAL",
        )
        return {"status": "OK"}

    async def _handle_renewal_failure(self, order, txn_info: dict, subtype: str) -> dict:
        """处理续期失败 → 进入宽限期"""
        grace_until = datetime.now(tz=utc) + timedelta(seconds=self.GRACE_PERIOD_SECONDS)

        await self.membership_service.enter_grace_period(
            user_id=order["user_id"],
            grace_until=grace_until,
            reason="APPLE_RENEWAL_FAILED",
        )
        # 发送提醒：续期失败，请更新支付方式
        await self._notify_user(order["user_id"], "RENEWAL_FAILED", grace_until)
        return {"status": "OK"}

    async def _handle_refund(self, order, txn_info: dict, subtype: str) -> dict:
        """处理退款通知"""
        refund_time = datetime.now(tz=utc)

        # 撤销会员权益
        await self.membership_service.revoke(
            user_id=order["user_id"],
            reason="APPLE_REFUND",
            effective_at=refund_time,
        )
        # 标记订单已退款
        await self.order_service.mark_refunded(
            order_id=order["id"],
            refund_amount=order["paid_amount"],
            refund_reason="APPLE_STORE_REFUND",
            refund_time=refund_time,
        )
        return {"status": "OK"}

    async def _handle_consumption_request(
        self, order, txn_info: dict, subtype: str
    ) -> dict:
        """
        处理 Apple 退款前消费数据请求（CONSUMPTION_REQUEST）

        Apple 在用户发起退款申请时发送该通知，要求服务端在
        12 小时内通过 App Store Server API
        PUT /inApps/v1/transactions/consumption/{transactionId}
        上报该笔交易的实际消费情况，供 Apple 退款裁决参考。

        本方法仅完成登记与首轮基础字段上报，用量明细（如次数包
        已消耗比例、订阅已使用天数）由延迟任务在截止前二次上报
        修正（见 §12.3），避免阻塞通知响应线程。
        """
        transaction_id = txn_info.get("transactionId")
        deadline = datetime.now(tz=utc) + timedelta(
            hours=self.CONSUMPTION_RESPONSE_DEADLINE_HOURS
        )

        # 1. 登记上报任务（幂等：uk(order_id) 唯一键，重复通知不重复登记）
        await self.order_service.create_consumption_report_task(
            order_id=order["id"],
            store="apple",
            transaction_id=transaction_id,
            deadline_at=deadline,
        )

        # 2. 立即上报基础字段：按发货状态给出消费结论
        #    （未发货 NOT_CONSUMED / 已发货 CONSUMED）
        consumption_status = (
            "CONSUMED" if order["status"] == "DELIVERED" else "NOT_CONSUMED"
        )
        await self._report_consumption(order, transaction_id, consumption_status)
        return {"status": "OK"}

    async def _report_consumption(
        self, order, transaction_id: str, consumption_status: str
    ) -> None:
        """调用 App Store Server API 上报消费数据（ES256 JWT 鉴权）"""
        token = await self.signing_key_provider.store_api_token()  # ES256 JWT
        env_host = (
            "api.storekit.itunes.apple.com"
            if order["environment"] == "Production"
            else "api.storekit-sandbox.itunes.apple.com"
        )
        payload = {
            "consumptionStatus": consumption_status,
            "platform": "APPLE",
            "sampleContentProvided": False,
            "deliveryStatus": "DELIVERED" if order["status"] == "DELIVERED" else "NOT_DELIVERED",
            "appAccountToken": order.get("app_account_token"),  # 客户端匿名 UUID
        }
        payload = {k: v for k, v in payload.items() if v is not None}
        async with httpx.AsyncClient(timeout=15) as client:
            resp = await client.put(
                f"https://{env_host}/inApps/v1/transactions/consumption/{transaction_id}",
                json=payload,
                headers={"Authorization": f"Bearer {token}"},
            )
            if resp.status_code != 200:
                # 非终态：留给延迟任务按截止时间重试（§12.3）
                raise AppleApiError(f"CONSUMPTION_REPORT_{resp.status_code}")

    async def _handle_renewal_status_change(
        self, order, txn_info: dict, subtype: str
    ) -> dict:
        """处理自动续期开关变更（AUTO_RENEW_ENABLED / AUTO_RENEW_DISABLED）"""
        # 从 signedRenewalInfo 解码自动续期标志
        renewal_info = txn_info.get("renewalInfo", {})
        auto_renew = subtype == "AUTO_RENEW_ENABLED"

        await self.membership_service.set_auto_renew_flag(
            user_id=order["user_id"],
            auto_renew=auto_renew,
            reason="APPLE_USER_TOGGLE",
        )
        if not auto_renew:
            # 关闭自动续期：到期不续费，提前 7 天提醒（复用到期提醒链路）
            await self._notify_user(order["user_id"], "AUTO_RENEW_OFF", order["expires_at"])
        return {"status": "OK"}

    async def _handle_subscribed(
        self, order, txn_info: dict, subtype: str
    ) -> dict:
        """处理首次订阅/重新订阅（INITIAL_BUY / RESUBSCRIBE）"""
        # 客户端 verify 链路通常先于此通知到达；此处做兜底激活（幂等）
        await self.order_service.ensure_delivered(
            order_id=order["id"],
            transaction_id=txn_info.get("transactionId"),
            reason="ASSN_SUBSCRIBED_FALLBACK",
        )
        return {"status": "OK"}

    async def _handle_expired(self, order, txn_info: dict, subtype: str) -> dict:
        """处理订阅到期（VOLUNTARY / BILLING_RETRY / PRICE_INCREASE）"""
        expired_at = datetime.now(tz=utc)
        await self.membership_service.expire(
            user_id=order["user_id"],
            expired_at=expired_at,
            reason=f"APPLE_EXPIRED_{subtype or 'UNKNOWN'}",
        )
        # 计费重试到期：进入挽留窗口（对齐 E2E §8.1 降级时间线）
        if subtype == "BILLING_RETRY_PERIOD_ENDED":
            await self._notify_user(order["user_id"], "SUB_EXPIRED_BILLING", None)
        return {"status": "OK"}

    async def _handle_grace_expired(self, order, txn_info: dict, subtype: str) -> dict:
        """宽限期结束仍未恢复扣款 → 立即降级"""
        await self.membership_service.exit_grace_and_downgrade(
            user_id=order["user_id"],
            reason="APPLE_GRACE_EXPIRED",
        )
        return {"status": "OK"}

    async def _handle_revoke(
        self, order, txn_info: dict, subtype: str
    ) -> dict:
        """家庭共享权益被撤销（REVOKE）→ 校验后回收"""
        revoked_at = datetime.fromtimestamp(
            int(txn_info.get("revocationDate", 0)) / 1000, tz=utc
        )
        await self.membership_service.revoke(
            user_id=order["user_id"],
            reason="APPLE_FAMILY_SHARING_REVOKE",
            effective_at=revoked_at,
        )
        await self.order_service.mark_refunded(
            order_id=order["id"],
            refund_amount=0,  # 家庭共享撤销不产生退款流水
            refund_reason="APPLE_FAMILY_SHARING_REVOKE",
            refund_time=revoked_at,
        )
        return {"status": "OK"}

    async def _handle_renewal_extended(
        self, order, txn_info: dict, subtype: str
    ) -> dict:
        """Apple 主动延长续期日期（RENEWAL_EXTENDED / SUMMARY）"""
        expires_date_ms = txn_info.get("expiresDate", 0)
        if not expires_date_ms:
            return {"status": "OK"}  # SUMMARY 汇总通知无单笔字段
        new_expires_at = datetime.fromtimestamp(expires_date_ms / 1000, tz=utc)
        await self.order_service.update_expiry(order["id"], new_expires_at)
        await self.membership_service.extend(
            user_id=order["user_id"],
            plan=order["product_code"],
            expires_at=new_expires_at,
            reason="APPLE_RENEWAL_EXTENDED",
        )
        return {"status": "OK"}

    async def _handle_unknown(
        self, order, txn_info: dict, subtype: str
    ) -> dict:
        """未登记类型：落盘隔离 + 告警，返回 200 避免 Apple 无限重试"""
        await self.order_service.park_unknown_notification(order["id"], txn_info)
        return {"status": "IGNORED_UNKNOWN_TYPE"}

    async def _verify_jws(self, raw_body: bytes, headers: dict) -> Optional[dict]:
        """
        验证 Apple JWS 签名并解出 payload。

        验签规则（x5c 证书链模式）：
        1. 解析 compact JWS header，取 x5c 数组（叶子证书/WWDR 中间证书/Apple 根证书）
        2. 证书链校验必须回溯到预置的 Apple Root CA - G3 根证书
        3. 签名算法必须为 ES256，对 header.payload 段验签
        4. 解出 payload 后，继续用同样流程验证内层
           data.signedTransactionInfo / data.signedRenewalInfo（若有）
        5. 将内层交易字段展平为 transaction_info 一并返回
        """
        try:
            token = json.loads(raw_body).get("signedPayload", "")
            payload = self.jws_verifier.verify_and_decode(token)
        except (ValueError, JwsVerifyError):
            await self._quarantine(raw_body, headers, reason="JWS_VERIFY_FAILED")
            return None

        signed_date = int(payload.get("signedDate", 0))
        # signedDate 早于当前 7 天以上视为陈旧重放，拒绝处理（防重放攻击）
        if signed_date and datetime.now(tz=utc).timestamp() * 1000 - signed_date > 7 * 86400_000:
            await self._quarantine(raw_body, headers, reason="STALE_SIGNED_DATE")
            return None

        data = payload.get("data", {})
        transaction_info = {}
        if data.get("signedTransactionInfo"):
            transaction_info = self.jws_verifier.verify_and_decode(
                data["signedTransactionInfo"]
            )
        renewal_info = {}
        if data.get("signedRenewalInfo"):
            renewal_info = self.jws_verifier.verify_and_decode(
                data["signedRenewalInfo"]
            )

        return {
            "notificationType": payload.get("notificationType"),
            "subtype": payload.get("subtype", ""),
            "notificationUUID": payload.get("notificationUUID"),
            "transaction_info": transaction_info,
            "renewal_info": renewal_info,
        }

    async def _save_pending_notification(
        self, original_txn_id: Optional[str], payload: dict
    ) -> None:
        """订单未创建（通知先到）→ 存入待关联表，由补偿任务回收"""
        await self.order_service.save_pending_notification(
            store="apple",
            dedupe_key=payload["notificationUUID"],
            original_transaction_id=original_txn_id or "",
            payload=json.dumps(payload, ensure_ascii=False),
        )

    async def _quarantine(self, raw_body: bytes, headers: dict, reason: str) -> None:
        """验签失败通知隔离落盘（不处理业务，仅审计与告警）"""
        await self.order_service.quarantine_notification(
            store="apple", reason=reason,
            body_sha256=hashlib.sha256(raw_body).hexdigest(),
            headers=json.dumps({k: str(v) for k, v in headers.items()}),
        )

    async def _notify_user(self, user_id: int, event: str, extra) -> None:
        """发送用户提醒（复用统一通知中心模板，此处只投递事件）"""
        await self.notify_producer.publish(
            "payment.iap.notification", {"user_id": user_id, "event": event, "extra": extra}
        )
```

注意：`handle_notification` 第 2 步查找订单与第 3 步分发处理之间必须先经过 **notificationUUID 去重**（Redis SETNX + 表唯一键双保险，见 §4.4.3），否则 Apple 重试机制会导致续期/退款动作重复执行。

#### 4.4.3 通知幂等、应答与重试规范

| 规范项 | 约定 |
|--------|------|
| 去重键 | `notificationUUID`（表唯一键 `uk_notification_uuid` + Redis `SETNX EX 86400` 双保险） |
| 顺序性 | Apple **不保证**通知顺序，处理前必须以 `signedDate` 与订单当前到期时间做 CAS 比较，仅接受更新数据 |
| 应答码 | 处理成功返回 `200`；业务无法处理（如订单永久缺失）也返回 `200` 并落盘，避免 Apple 无限重试；验签失败返回 `401` |
| Apple 重试 | 非 200 应答 Apple 会周期性重发（最长约 3 天），重试投递走同一去重逻辑 |
| 测试通知 | `Request a Test Notification` 端点独立配置，只写日志不动业务（`TEST` 通知类型标记） |
| 版本兼容 | `version` 字段非 `2.0` 的通知落隔离区并告警，不直接丢弃 |

### 5.2 购买流程与客户端关键代码

Google Play 与 Apple 流程同构（§4.2.1），差异在于：**购买结果必须显式确认（acknowledge）**，3 天未确认将被 Google 自动退款。

Future<PurchaseResult> initiateGooglePurchase(

  required bool consumable,
  String? oldProductSku, // 订阅升降级时的旧 SKU

  final param = GooglePurchaseParam(
    productDetails: product.storeProduct,

        ? null
        : ChangeSubscriptionParam(

  } else if (oldProductSku != null) {

  } else {
    _inAppPurchase.buyNonConsumable(purchaseParam: param);
  }

  // purchaseToken 通过 verify 接口提交服务端，由服务端调用 acknowledge 确认
}

**PENDING 状态处理**：商店支持「先货后款」（如便利店现金付款），此时 `PurchaseStatus.pending`，购买 48 小时内可能变为 `purchased` 或 `canceled`。客户端展示「等待付款中」，服务端订单挂起（不发货），由 RTDN `ONE_TIME_PRODUCT_PURCHASED` / 定时查单推进。

### 5.3 服务端验证与确认

```python
# payment/iap/google_play_verifier.py

from googleapiclient.discovery import build
from google.oauth2 import service_account

class GooglePlayVerifier:
    """Google Play Developer API 票据验证器"""

    def __init__(self, service_account_key: dict, package_name: str):
        creds = service_account.Credentials.from_service_account_info(
            service_account_key,
            scopes=["https://www.googleapis.com/auth/androidpublisher"],
        )
        self.api = build("androidpublisher", "v3", credentials=creds)
        self.package = package_name

    async def verify_product(self, purchase_token: str, product_id: str) -> dict:
        """一次性商品验证 purchases.products.get"""
        res = self.api.purchases().products().get(
            packageName=self.package, productId=product_id, token=purchase_token
        ).execute()
        # 关键校验：purchaseState=0(已购买)、consumptionState、acknowledgementState
        if res.get("purchaseState") != 0:
            raise VerifyError("GOOGLE_PURCHASE_STATE_%s" % res.get("purchaseState"))
        if res.get("obfuscatedExternalAccountId"):
            # 防张冠李戴：票据绑定账号必须与提交账号一致
            self._assert_account(res["obfuscatedExternalAccountId"])
        return {
            "order_id": res["orderId"],
            "purchase_time_ms": int(res["purchaseTimeMillis"]),
            "acknowledged": res.get("acknowledgementState") == 1,
            "quantity": int(res.get("quantity", 1)),
        }

    async def verify_subscription(self, purchase_token: str) -> dict:
        """订阅验证 purchases.subscriptionsv2.get（Billing 6+ 唯一入口）"""
        res = self.api.purchases().subscriptionsv2().get(
            packageName=self.package, token=purchase_token
        ).execute()
        state = res.get("subscriptionState", "")
        line = (res.get("lineItems") or [{}])[0]
        if state not in ("SUBSCRIPTION_STATE_ACTIVE", "SUBSCRIPTION_STATE_IN_GRACE_PERIOD",
                         "SUBSCRIPTION_STATE_PENDING", "SUBSCRIPTION_STATE_ON_HOLD"):
            raise VerifyError(f"GOOGLE_SUB_STATE_{state}")
        return {
            "state": state,
            "expiry_time": line.get("expiryTime"),
            "auto_renew": (line.get("autoRenewingPlan") or {}).get("autoRenewEnabled", False),
            "acknowledgement_state": res.get("acknowledgementState"),
            "linked_purchase_token": res.get("linkedPurchaseToken", ""),  # 升降级迁移关键
        }

    async def acknowledge_product(self, purchase_token: str, product_id: str) -> None:
        """确认一次性购买（服务端集中确认，不依赖客户端）"""
        self.api.purchases().products().acknowledge(
            packageName=self.package, productId=product_id, token=purchase_token,
            body={},
        ).execute()

    async def acknowledge_subscription(self, purchase_token: str) -> None:
        self.api.purchases().subscriptionsv2().acknowledge(
            packageName=self.package, token=purchase_token, body={},
        ).execute()
```

**关键规则**：
1. **服务端集中 acknowledge**：客户端不自行确认；发货成功后由集成层统一调用，把「确认购买」与「权益发放」绑定为同一事务边界（Outbox 双写：发货事件 + acknowledge 调用记录）。
2. **`linkedPurchaseToken` 迁移**：订阅升降级后旧 token 失效，必须立即将旧 purchaseToken 的订单与权益映射迁移到新 token（见 §5.6），否则续费通知丢失。
3. **`obfuscatedExternalAccountId`**：客户端发起购买时注入匿名化的用户 ID（服务端下发），服务端验证时校验一致性，防止票据搬运（一个用户买给另一个用户发货）。

### 5.4 RTDN 实时开发者通知处理

```python
# payment/iap/google_rtdn_handler.py

import base64, json
from google.auth import crypt, jwt as gauth_jwt

class GoogleRtdnHandler:
    """处理 Google Play Pub/Sub RTDN push 消息"""

    def __init__(self, expected_audience: str, notification_processor):
        self.expected_audience = expected_audience  # push 订阅配置的 OIDC audience
        self.processor = notification_processor

    async def handle(self, envelope: dict, authorization: str) -> dict:
        # 1. 验证 OIDC JWT（Google 签名，公钥从其 JWKS 端点获取并缓存）
        try:
            bearer = authorization.removeprefix("Bearer ").strip()
            claims = gauth_jwt.decode(
                bearer, certs=self._cached_jwks(), audience=self.expected_audience
            )
        except Exception:
            return {"status": 401}  # NACK：Pub/Sub 会重投

        # 2. messageId 幂等（表唯一键 + Redis 双保险）
        message = envelope["message"]
        msg_id = message["messageId"]
        if not await self._try_dedupe("google", msg_id):
            return {"status": 200}  # 重复投递直接 ACK

        # 3. 解码 data（base64 的 UTF-8 JSON）
        data = json.loads(base64.b64decode(message["data"]))
        sub_notif = data.get("subscriptionNotification")
        one_time = data.get("oneTimeProductNotification")
        voided = data.get("voidedPurchaseNotification")

        if sub_notif:
            await self.processor.on_subscription_event(
                purchase_token=sub_notif["purchaseToken"],
                subscription_id=sub_notif["subscriptionId"],
                event_type=int(sub_notif["notificationType"]),
                event_time_ms=int(data.get("eventTimeMillis", 0)),
            )
        elif one_time:
            await self.processor.on_one_time_event(
                purchase_token=one_time["purchaseToken"],
                product_id=one_time["productId"],
                event_type=int(one_time["notificationType"]),
            )
        elif voided:
            await self.processor.on_voided(voided)
        return {"status": 200}  # ACK
```

**SubscriptionNotification.type 处理映射**：

| type | 事件 | 处理动作 |
|------|------|---------|
| 1 | RECOVERED（账号保留恢复） | 恢复权益，重算到期时间 |
| 2 | RENEWED（续费成功） | 延长到期时间（以 subscriptionsv2 查询为准） |
| 3 | CANCELED（用户取消续订） | 标记不续费，到期前保留权益 + 提醒 |
| 4 | EXPIRED（已到期） | 降级处理 |
| 5 | IN_GRACE_PERIOD（进入宽限期） | 进入宽限期，提醒更新支付方式 |
| 6 | PAUSED（订阅暂停） | 记录暂停区间，到期冻结权益 |
| 7 | RESTARTED（恢复订阅） | 解除暂停/取消标记 |
| 8 | PRICE_CHANGE_CONFIRMED | 更新价格版本 |
| 9 | DEFERRED（延期生效，如升级按期生效） | 登记新周期生效时间 |
| 10 | REVOKED（ revoked，如家人库撤销） | 立即回收权益 |
| 11 | EXPIRED_VOLUNTARILY | 同 4，标注主动流失 |
| 12 | EXPIRED_BILLING | 同 4，标注计费流失（进入挽留） |
| 13 | EXPIRED_DEVELOPER_CALLED | 同 4，开发者主动取消 |

> RTDN 只作为**触发信号**，所有状态变更必须回查 `subscriptionsv2.get` 以最新数据落库（通知数据可能滞后）。

### 5.5 Voided Purchases API 轮询（P1）

```python
# payment/iap/google_voided_poller.py

class GoogleVoidedPoller:
    """每 4 小时轮询一次退款/撤销清单（服务账号专用权限）"""

    INTERVAL = 4 * 3600

    async def poll(self, since_ms: int) -> None:
        page_token = None
        while True:
            resp = self.api.purchases().voidedpurchases().list(
                packageName=self.package,
                startTime=since_ms,
                type=0,  # 0=商品型，1=订阅型（按 type 分页拉取）
                maxResults=1000,
                pageToken=page_token,
            ).execute()
            for vp in resp.get("voidedPurchases", []):
                # 必须先经服务端仲裁：PENDING 状态误撤销不回收（对齐 §5.2）
                await self.processor.on_voided(
                    purchase_token=vp["purchaseToken"],
                    order_id=vp.get("orderId", ""),
                    voided_time_ms=int(vp["voidedTimeMillis"]),
                )
            page_token = resp.get("nextPageToken")
            if not page_token:
                break
```

轮询与 RTDN `REVOKED` 通知双通道覆盖：轮询兜底 RTDN 丢失（Pub/Sub 只投递一次，不保证送达）。

### 5.6 订阅升降级与 linkedPurchaseToken 迁移

```text
用户从「月度会员」升级「年度会员」
  1. 客户端 buyNonConsumable(ChangeSubscriptionParam.chargeFullPriceImmediately)
  2. 新 purchaseToken 到达 verify 接口，携带 linkedPurchaseToken = 旧token
  3. 服务端在同一事务内：
     a. 旧订单 purchase_token 字段替换为新 token（保留订单号不变）
     b. 旧 token 写入 iap_google_token_link 迁移历史表
     c. 按升级折算规则重算到期时间（对齐 E2E §8.3 升级折算公式）
     d. acknowledge 新 token
  4. 后续 RTDN 一律按新 token 路由到该订单
```

```sql
CREATE TABLE iap_google_token_link (
    id                BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    old_purchase_token VARCHAR(512) NOT NULL,
    new_purchase_token VARCHAR(512) NOT NULL,
    migrated_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    order_id          BIGINT UNSIGNED NOT NULL,
    UNIQUE KEY uk_old_token (old_purchase_token(191)),
    KEY idx_new_token (new_purchase_token(191))
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='Google订阅升降级token迁移史';
```

> **降级场景**：Google 降级（`chargeProratedPrice` / 周期生效）在新周期开始时才产生新 token，旧 token 在当期继续有效；迁移逻辑相同，仅生效时间不同。
