# 服务端通用数据导入服务与批量操作引擎 - 详细设计

## 1. 概述

### 1.1 背景与目标

PrimeTop 作为全学段 AI 辅助学习平台，运营初期及日常运营中存在大量批量数据处理需求：

| 场景 | 数据量 | 来源格式 | 触发方式 |
|------|--------|----------|----------|
| 题库批量导入 | 1000~50000 条/次 | Excel/CSV/JSON | 管理后台运营人员 |
| B端机构学生批量注册 | 100~5000 人/次 | Excel/CSV | 机构管理员 |
| 教材知识点批量导入 | 500~20000 条/次 | Excel/JSON | 内容运营 |
| 错题/学习记录迁移 | 1000~100000 条/次 | JSON/CSV | 系统迁移 |
| 题目标签批量更新 | 500~10000 条/次 | Excel/CSV | 运营后台 |
| 内容批量发布/下架 | 100~5000 条/次 | JSON (API) | 管理后台 |
| 用户权益批量发放 | 100~10000 人/次 | Excel/JSON | 运营活动 |

**目标**：构建一套通用的数据导入与批量操作引擎，支持多格式解析、异步处理、进度追踪、错误汇总、回滚机制，让各业务模块通过声明式配置即可接入，无需重复开发。

### 1.2 设计原则

1. **声明式配置**：业务模块通过 YAML/数据类声明导入规则，无需编写解析逻辑
2. **异步处理**：大数量导入走 Celery 异步队列，不阻塞 API 请求
3. **原子性与幂等**：支持事务级别回滚和幂等重试
4. **错误友好**：逐行校验，收集全部错误而非首错即停
5. **进度可观测**：实时进度查询、WebSocket 推送
6. **安全可控**：文件大小/行数限制、权限校验、操作审计

### 1.3 术语定义

| 术语 | 含义 |
|------|------|
| ImportJob | 一次导入任务实例 |
| ImportTemplate | 导入模板定义（字段映射、校验规则） |
| Batch | 导入任务中的一次批量处理单元（默认 100 条） |
| ImportRow | 单行数据记录，含原始值、校验结果、处理状态 |
| DryRun | 试运行模式，仅校验不实际写入 |

### 3.7 Redis 数据结构

```
# 任务进度 (Hash)  TTL: 24h
import:progress:{job_id}
  ├── total_rows / processed_rows / success_rows / failed_rows / skipped_rows
  ├── current_batch / total_batches
  ├── status / eta_seconds / updated_at

# 去重缓存 (Set) — TTL: 24h
import:dedup:{job_id}

# 任务锁 (String) — TTL: 30s（自动续期）
import:lock:{job_id}

# 并发限制 (Semaphore) — TTL: 无（手动管理）
import:concurrent:{operator_id}  → 当前该操作者并行任务数，上限 3
```

## 5. 状态机设计

### 5.1 ImportJob 状态流转

```
                    ┌──────────────────────────────────┐
                    │           cancelled               │
                    └──────────────▲───────────────────┘
                                   │ (用户主动取消)
                    ┌──────────────┤
                    │              │
  ┌─────────┐   ┌──▼───┐   ┌─────▼────┐   ┌───────────┐
  │ pending │──►│parsing│──►│validating│──►│ importing │
  └─────────┘   └──┬───┘   └────┬─────┘   └─────┬─────┘
                   │              │               │
                   │ 解析失败       │ 校验全失败     │ 全部成功
                   │              │               ▼
                   │              │         ┌──────────┐
                   │              │         │completed │
                   │              │         └────┬─────┘
                   │              │              │ 回滚
                   ▼              ▼              ▼
                ┌──────────────────────┐   ┌───────────────┐
                │       failed         │   │ rolling_back   │
                └──────────────────────┘   └───────┬───────┘
                                                   │
                                                   ▼
                                           ┌──────────────┐
                                           │ rolled_back  │
                                           └──────────────┘

  部分成功时:
  importing ──► partial_completed (success_rows > 0 && failed_rows > 0)
                 partial_completed 可回滚 (仅回滚成功写入的数据)
```

**状态定义**：

| 状态 | 含义 | 可转换到 |
|------|------|----------|
| `pending` | 已创建，等待解析 | parsing, cancelled |
| `parsing` | 正在解析文件 | validating, failed, cancelled |
| `validating` | 正在校验数据 | importing, failed, cancelled |
| `importing` | 正在分批写入 | completed, partial_completed, failed, cancelled |
| `completed` | 全部成功写入 | rolling_back |
| `partial_completed` | 部分成功、部分失败 | rolling_back |
| `failed` | 失败（解析/校验阶段全失败） | — |
| `cancelled` | 用户手动取消 | — |
| `rolling_back` | 正在回滚 | rolled_back, failed |
| `rolled_back` | 已回滚完成 | — |

### 5.2 ImportBatch 状态流转

```
pending ──► running ──┬──► completed (全部成功)
                      ├──► partial (部分失败)
                      └──► failed (全部失败)
```

### 5.3 BatchOperation 状态流转

```
pending ──► running ──┬──► completed
                      ├──► partial_completed
                      ├──► failed
                      └──► cancelled
                                  │
                              rolling_back ──► rolled_back
```

```python
# services/import_engine/parsers.py

from abc import ABC, abstractmethod
from pathlib import Path
import json
import csv
import io
import openpyxl
from typing import AsyncIterator

class BaseParser(ABC):
    """解析器基类"""

    @abstractmethod
    async def parse(self, file_path: str, **kwargs) -> AsyncIterator[list[dict]]:
        """流式解析文件，按 chunk_size 批量返回行"""
        ...

    @abstractmethod
    def supported_extensions(self) -> list[str]:
        ...


class ExcelParser(BaseParser):
    """Excel (.xlsx/.xls) 解析器"""

    def supported_extensions(self) -> list[str]:
        return [".xlsx", ".xls"]

    async def parse(self, file_path: str, chunk_size: int = 200, **kwargs) -> AsyncIterator[list[dict]]:
        wb = openpyxl.load_workbook(file_path, read_only=True, data_only=True)
        ws = wb.active

        headers = None
        chunk = []

        for row_idx, row in enumerate(ws.iter_rows(values_only=True), start=1):
            if row_idx == 1:
                # 首行作为表头
                headers = [str(cell).strip() if cell else f"col_{i}" for i, cell in enumerate(row)]
                continue

            # 跳过空行
            if all(cell is None for cell in row):
                continue

            record = {}
            for i, cell in enumerate(row):
                if i < len(headers):
                    record[headers[i]] = cell
            record["_row_number"] = row_idx
            chunk.append(record)

            if len(chunk) >= chunk_size:
                yield chunk
                chunk = []

        if chunk:
            yield chunk

        wb.close()


class CSVParser(BaseParser):
    """CSV 解析器（支持 GBK/UTF-8 自动检测）"""

    def supported_extensions(self) -> list[str]:
        return [".csv"]

    def _detect_encoding(self, file_path: str) -> str:
        """检测文件编码：尝试 UTF-8，失败则用 GBK"""
        try:
            with open(file_path, "r", encoding="utf-8") as f:
                f.read(1024)
            return "utf-8"
        except UnicodeDecodeError:
            return "gbk"

    async def parse(self, file_path: str, chunk_size: int = 200, **kwargs) -> AsyncIterator[list[dict]]:
        encoding = self._detect_encoding(file_path)
        delimiter = kwargs.get("delimiter", ",")

        with open(file_path, "r", encoding=encoding) as f:
            reader = csv.DictReader(f, delimiter=delimiter)
            chunk = []
            for row_idx, record in enumerate(reader, start=2):  # 第1行是表头
                record["_row_number"] = row_idx
                chunk.append(record)
                if len(chunk) >= chunk_size:
                    yield chunk
                    chunk = []
            if chunk:
                yield chunk


class JSONParser(BaseParser):
    """JSON 解析器（支持数组和换行分隔的 NDJSON）"""

    def supported_extensions(self) -> list[str]:
        return [".json", ".jsonl"]

    async def parse(self, file_path: str, chunk_size: int = 200, **kwargs) -> AsyncIterator[list[dict]]:
        ext = Path(file_path).suffix

        if ext == ".jsonl":
            # NDJSON：每行一个 JSON 对象
            chunk = []
            with open(file_path, "r", encoding="utf-8") as f:
                for row_idx, line in enumerate(f, start=1):
                    line = line.strip()
                    if not line:
                        continue
                    record = json.loads(line)
                    record["_row_number"] = row_idx
                    chunk.append(record)
                    if len(chunk) >= chunk_size:
                        yield chunk
                        chunk = []
                if chunk:
                    yield chunk
        else:
            # 标准JSON数组
            with open(file_path, "r", encoding="utf-8") as f:
                data = json.load(f)

            if isinstance(data, list):
                for i in range(0, len(data), chunk_size):
                    chunk = data[i:i + chunk_size]
                    for j, record in enumerate(chunk):
                        record["_row_number"] = i + j + 1
                    yield chunk
            elif isinstance(data, dict) and "data" in data:
                # 兼容 {"data": [...]} 格式
                records = data["data"]
                for i in range(0, len(records), chunk_size):
                    chunk = records[i:i + chunk_size]
                    for j, record in enumerate(chunk):
                        record["_row_number"] = i + j + 1
                    yield chunk
            else:
                raise ParseError("JSON格式不支持：期望数组或含data字段的对象")


# 解析器注册表
PARSER_REGISTRY: dict[str, BaseParser] = {
    ".xlsx": ExcelParser(),
    ".xls": ExcelParser(),
    ".csv": CSVParser(),
    ".json": JSONParser(),
    ".jsonl": JSONParser(),
}

def get_parser(file_path: str) -> BaseParser:
    ext = Path(file_path).suffix.lower()
    parser = PARSER_REGISTRY.get(ext)
    if not parser:
        raise ParseError(f"不支持的文件格式: {ext}")
    return parser
```

### 7.2 校验引擎（ValidationEngine）

```python
# services/import_engine/validators.py

from dataclasses import dataclass
from typing import Any

@dataclass
class ValidationError:
    row_number: int
    error_type: str          # validation_error / duplicate_error / ref_error
    error_code: str
    field_name: str | None
    field_value: str | None
    error_message: str
    severity: str = "error"  # error / warning


class ValidationEngine:
    """逐行校验引擎"""

    def __init__(self, field_mappings: dict, validation_rules: dict):
        self.fields = field_mappings["fields"]
        self.rules = validation_rules.get("rowRules", [])
        self.max_errors = validation_rules.get("maxErrors", 500)
        self._error_count = 0

    def validate_row(self, row: dict, row_number: int) -> list[ValidationError]:
        """校验单行数据，返回错误列表（收集全部而非首错即停）"""
        errors = []
        if self._error_count >= self.max_errors:
            return errors

        # 1. 字段映射与类型转换
        mapped = self._map_fields(row, row_number, errors)

        # 2. 执行规则校验
        for rule in self.rules:
            if self._error_count >= self.max_errors:
                break
            rule_errors = self._apply_rule(rule, mapped, row_number)
            errors.extend(rule_errors)
            self._error_count += len([e for e in rule_errors if e.severity == "error"])

        return errors

    def _map_fields(self, row: dict, row_number: int, errors: list) -> dict:
        """字段映射 + 类型转换"""
        result = {}
        for field_def in self.fields:
            source = field_def["source"]
            target = field_def["target"]
            value = row.get(source)

            # 默认值
            if value is None or str(value).strip() == "":
                if "defaultValue" in field_def:
                    result[target] = field_def["defaultValue"]
                    continue
                if field_def.get("required"):
                    errors.append(ValidationError(
                        row_number=row_number, error_type="validation_error",
                        error_code="FIELD_REQUIRED", field_name=source,
                        field_value=None, error_message=f"字段 '{source}' 不能为空"
                    ))
                    continue
                result[target] = None
                continue

            # 类型转换
            field_type = field_def.get("type", "string")
            try:
                result[target] = self._convert_type(value, field_type, field_def)
            except (ValueError, TypeError) as e:
                errors.append(ValidationError(
                    row_number=row_number, error_type="validation_error",
                    error_code="TYPE_MISMATCH", field_name=source,
                    field_value=str(value)[:256],
                    error_message=f"字段 '{source}' 类型转换失败: {e}"
                ))

            # 范围校验
            if "range" in field_def and result.get(target) is not None:
                r = field_def["range"]
                val = result[target]
                if isinstance(val, (int, float)):
                    if "min" in r and val < r["min"]:
                        errors.append(ValidationError(
                            row_number=row_number, error_type="validation_error",
                            error_code="VALUE_TOO_SMALL", field_name=source,
                            field_value=str(val), error_message=f"值不能小于 {r['min']}"
                        ))
                    if "max" in r and val > r["max"]:
                        errors.append(ValidationError(
                            row_number=row_number, error_type="validation_error",
                            error_code="VALUE_TOO_LARGE", field_name=source,
                            field_value=str(val), error_message=f"值不能大于 {r['max']}"
                        ))

            # 长度校验
            if "maxLength" in field_def and result.get(target) is not None:
                if len(str(result[target])) > field_def["maxLength"]:
                    errors.append(ValidationError(
                        row_number=row_number, error_type="validation_error",
                        error_code="VALUE_TOO_LONG", field_name=source,
                        field_value=str(result[target])[:50] + "...",
                        error_message=f"长度超过限制 {field_def['maxLength']} 字符"
                    ))

        return result

    def _convert_type(self, value: Any, field_type: str, field_def: dict) -> Any:
        """类型转换"""
        if field_type == "string":
            return str(value).strip()
        elif field_type == "integer":
            return int(float(value))
        elif field_type == "float":
            return float(value)
        elif field_type == "enum":
            enum_map = field_def.get("enumMap", {})
            str_val = str(value).strip()
            if str_val in enum_map:
                return enum_map[str_val]
            raise ValueError(f"'{str_val}' 不在可选值 {list(enum_map.keys())} 中")
        elif field_type == "boolean":
            return str(value).strip().lower() in ("是", "true", "1", "yes")
        else:
            return value

    def _apply_rule(self, rule: dict, mapped: dict, row_number: int) -> list[ValidationError]:
        """应用单条校验规则"""
        errors = []
        rule_type = rule["type"]
        fields = rule.get("fields", [])
        message = rule.get("message", "校验失败")

        if rule_type == "required":
            for f in fields:
                if mapped.get(f) is None:
                    errors.append(ValidationError(
                        row_number=row_number, error_type="validation_error",
                        error_code="FIELD_REQUIRED", field_name=f,
                        field_value=None, error_message=message
                    ))

        # unique 和 relation_exists 在 BatchProcessor 中做批量校验（需查库）
        return errors


class BatchValidator:
    """批次级批量校验（需查库/跨行去重，在批次处理上下文中执行）"""

    def __init__(self, template: ImportTemplate, redis: Redis, db: Session):
        self.template = template
        self.redis = redis
        self.db = db
        self.unique_rules = [
            r for r in template.validation_rules.get("rowRules", [])
            if r["type"] == "unique"
        ]
        self.relation_rules = [
            r for r in template.validation_rules.get("rowRules", [])
            if r["type"] == "relation_exists"
        ]

    async def validate_batch(
        self, rows: list[dict], job_id: str
    ) -> list[ValidationError]:
        errors: list[ValidationError] = []
        seen_in_batch: dict[tuple, int] = {}

        for row in rows:
            if row.get("_skip"):
                continue
            row_number = row["_row_number"]

            # 1. unique 校验：批次内去重 → 任务级 Redis Set（24h TTL）→ 库内查重
            for rule in self.unique_rules:
                key_tuple = tuple(str(row.get(f)) for f in rule["fields"])
                scope = tuple(str(row.get(f)) for f in rule.get("scope", []))
                marker = (key_tuple, scope)

                if marker in seen_in_batch:
                    dup_row = seen_in_batch[marker]
                    errors.append(ValidationError(
                        row_number=row_number, error_type="duplicate_error",
                        error_code="DUP_IN_FILE",
                        field_name=",".join(rule["fields"]),
                        field_value=str(key_tuple)[:256],
                        error_message=rule.get("message", "文件内重复")
                                    .replace("{n}", str(dup_row)),
                    ))
                    continue

                dedup_key = f"import:dedup:{job_id}:{hash(marker) % 10**10}"
                added = await self.redis.sadd(dedup_key, "1")
                await self.redis.expire(dedup_key, 86400)
                if added == 0:
                    errors.append(ValidationError(
                        row_number=row_number, error_type="duplicate_error",
                        error_code="DUP_IN_JOB",
                        field_name=",".join(rule["fields"]),
                        field_value=str(key_tuple)[:256],
                        error_message="与本次任务中已处理行重复",
                    ))
                    continue

                # 库内查重（唯一键命中已有数据）
                if self._exists_in_db(rule, row):
                    strategy = rule.get("dedupStrategy", "skip")
                    if strategy == "skip":
                        row["_skip"] = True  # 执行器跳过，计入 skipped_rows
                        continue
                    errors.append(ValidationError(
                        row_number=row_number, error_type="duplicate_error",
                        error_code="DUP_IN_DB",
                        field_name=",".join(rule["fields"]),
                        field_value=str(key_tuple)[:256],
                        error_message=rule.get("message", "库中已存在相同记录"),
                    ))
                    continue

                seen_in_batch[marker] = row_number

            # 2. relation_exists 校验：查关联表
            for rule in self.relation_rules:
                for f in rule.get("fields", []):
                    value = row.get(f)
                    if value is None:
                        continue
                    exists = self.db.execute(
                        text(f"SELECT 1 FROM {rule['lookupTable']} "
                             f"WHERE {rule['lookupColumn']} = :v LIMIT 1"),
                        {"v": value},
                    ).first()
                    if not exists:
                        errors.append(ValidationError(
                            row_number=row_number, error_type="ref_error",
                            error_code="REF_NOT_FOUND",
                            field_name=f, field_value=str(value)[:256],
                            error_message=rule.get("message", "关联数据不存在"),
                        ))

        return errors

    def _exists_in_db(self, rule: dict, row: dict) -> bool:
        table = self.template.target_table
        if not table:
            return False
        conditions = " AND ".join(f"{f} = :{f}" for f in rule["fields"])
        params = {f: row.get(f) for f in rule["fields"]}
        sql = f"SELECT 1 FROM {table} WHERE {conditions} LIMIT 1"
        return self.db.execute(text(sql), params).first() is not None
```

### 7.3 导入执行器（ImportExecutor）

```python
# services/import_engine/executor.py

import asyncio
from celery import Celery
from sqlalchemy import text
from core.db import get_db_session
from core.redis import get_redis
from .models import ImportJob, ImportBatch, ImportErrorDetail
from .validators import ValidationEngine, BatchValidator
from .rollback import RollbackManager

worker = Celery("import_engine", broker=settings.CELERY_BROKER)

BATCH_SIZE = 100          # 每批次行数
PROGRESS_TTL = 86400      # 进度缓存 24h
LOCK_TTL = 30             # 任务锁 30s，续期


@worker.task(bind=True, max_retries=3, acks_late=True)
def process_import_job(self, job_id: str):
    """导入任务主流程（Celery 编排，批次内并发 4）"""
    asyncio.run(_run_job(job_id, task_id=self.request.id))


async def _run_job(job_id: str, task_id: str):
    redis = get_redis()
    # 0. 抢占执行权：防调度器双跑（CAS pending→parsing）
    acquired = await ImportJob.cas_state(job_id, "pending", "parsing")
    if not acquired:
        return  # 已被其他 worker 抢占或状态不允许

    # 任务锁（自动续期协程）
    lock_key = f"import:lock:{job_id}"
    await redis.set(lock_key, task_id, ex=LOCK_TTL)
    renewer = asyncio.create_task(_renew_lock(redis, lock_key, task_id))

    try:
        job = await ImportJob.get(job_id)
        template = await ImportTemplate.get(job.template_code)

        # 1. 解析文件 → 行迭代器
        parser = get_parser(job.file_path)
        row_iter = parser.parse(job.file_path, chunk_size=BATCH_SIZE)
        total = job.total_rows or parser.count_rows(job.file_path)
        await job.update(total_rows=total, state="validating")

        validator = ValidationEngine(template.field_mappings,
                                     template.validation_rules)
        batch_validator = BatchValidator(template, redis, get_db_session())
        rollback_mgr = RollbackManager(job_id, redis)

        # 2. 分批校验 + 写入（批次内 asyncio 并发 4，DB 写入串行）
        batch_no = 0
        success_rows = failed_rows = skipped_rows = 0
        async for raw_batch in row_iter:
            batch_no += 1
            await ImportBatch.create(job_id=job_id, batch_no=batch_no,
                                     state="running")
            batch = await _process_batch(
                job, template, validator, batch_validator,
                rollback_mgr, raw_batch, batch_no,
            )
            success_rows += batch["success"]
            failed_rows += batch["failed"]
            skipped_rows += batch["skipped"]
            await _update_progress(redis, job_id, total, success_rows,
                                   failed_rows, skipped_rows)

        # 3. 终态判定（completed / partial_completed / failed）
        if failed_rows == 0:
            final_state = "completed"
        elif success_rows == 0:
            final_state = "failed"
        else:
            final_state = "partial_completed"
        await ImportJob.cas_state(job_id, "importing", final_state)
        await _emit_outbox(job_id, f"import.job.{final_state}", {
            "jobId": job_id, "total": total, "success": success_rows,
            "failed": failed_rows, "skipped": skipped_rows,
        })
    except Exception as exc:
        await ImportJob.cas_state(job_id, "*", "failed")
        await _emit_outbox(job_id, "import.job.failed", {
            "jobId": job_id, "reason": str(exc)[:500],
        })
        raise self.retry(exc=exc, countdown=2 ** self.request.retries)
    finally:
        renewer.cancel()
        await redis.delete(lock_key)


async def _process_batch(job, template, validator, batch_validator,
                         rollback_mgr, raw_rows, batch_no) -> dict:
    """单批次：行校验 → 批量校验 → 业务前置 → 事务写入 → 回滚日志"""
    row_errors: list[ValidationError] = []
    valid_rows = []

    # 1. 逐行校验（收集全部错误，超 maxErrors 提前熔断）
    for row in raw_rows:
        errors = validator.validate_row(row, row["_row_number"])
        if errors:
            row_errors.extend(errors)
        else:
            valid_rows.append(row)

    # 2. 批次级校验（去重/关联）
    batch_errors = await batch_validator.validate_batch(valid_rows, job.id)
    error_rows = {e.row_number for e in batch_errors if e.severity == "error"}
    row_errors.extend(batch_errors)
    valid_rows = [r for r in valid_rows if r["_row_number"] not in error_rows]

    # 3. 持久化错误明细（异步批量插入）
    if row_errors:
        await ImportErrorDetail.bulk_create(job.id, batch_no, row_errors)

    # 4. 业务前置处理（生成 hash、补默认字段）
    handler = get_handler(template.handler_class)
    valid_rows = await handler.before_batch_write(valid_rows)
    writable = [r for r in valid_rows if not r.get("_skip")]
    skipped = len(valid_rows) - len(writable)

    # 5. 事务写入 + 回滚日志（同事务）
    inserted_ids: list[int] = []
    failed = len(error_rows)
    if writable:
        try:
            async with get_db_session().begin() as session:
                inserted_ids = await _batch_insert(session, template,
                                                   writable)
                await rollback_mgr.log_batch(session, batch_no,
                                             template.target_table,
                                             inserted_ids)
        except Exception:
            # 整批写入失败：批次回滚标记，行计入 failed
            await ImportBatch.cas_state_by_no(job.id, batch_no,
                                              "running", "failed")
            failed += len(writable)
            writable = []

    # 6. 业务后置处理（向量化/ES 同步，失败不影响主流程）
    if inserted_ids:
        try:
            await handler.after_batch_write(inserted_ids, writable)
        except Exception as exc:
            await _emit_outbox(job.id, "import.post_process.failed", {
                "jobId": job.id, "batchNo": batch_no,
                "ids": inserted_ids[:100], "reason": str(exc)[:300],
            })
        await ImportBatch.cas_state_by_no(
            job.id, batch_no, "running",
            "completed" if failed == 0 else "partial")

    return {"success": len(inserted_ids), "failed": failed,
            "skipped": skipped}


async def _batch_insert(session, template, rows: list[dict]) -> list[int]:
    """批量 INSERT，返回自增 ID 列表（保持与 rows 顺序一致）"""
    columns = list(rows[0].keys())
    placeholders = ", ".join(f":{c}" for c in columns)
    sql = (f"INSERT INTO {template.target_table} "
           f"({', '.join(columns)}) VALUES ({placeholders})")
    result = await session.execute(text(sql), rows)
    first_id = result.lastrowid - len(rows) + 1
    return list(range(first_id, first_id + len(rows)))


async def _update_progress(redis, job_id, total, ok, fail, skip):
    """进度写入 Redis Hash（ProgressAPI / WebSocket 消费），每批次刷新"""
    await redis.hset(f"import:progress:{job_id}", mapping={
        "total": total, "success": ok, "failed": fail, "skipped": skip,
        "percent": round((ok + fail + skip) / max(total, 1) * 100, 1),
        "updatedAt": now_iso(),
    })
    await redis.expire(f"import:progress:{job_id}", PROGRESS_TTL)


async def _renew_lock(redis, key, token):
    """任务锁续期协程（worker 存活期间每 10s 续期）"""
    while True:
        await asyncio.sleep(10)
        if await redis.get(key) == token:
            await redis.expire(key, LOCK_TTL)


def get_handler(class_path: str) -> BaseImportHandler:
    """按类路径加载业务处理器（模板注册表缓存）"""
    if class_path not in _HANDLER_CACHE:
        module_path, cls_name = class_path.rsplit(".", 1)
        mod = importlib.import_module(module_path)
        _HANDLER_CACHE[class_path] = getattr(mod, cls_name)()
    return _HANDLER_CACHE[class_path]


_HANDLER_CACHE: dict = {}
```

### 7.4 回滚管理器（RollbackManager）

```python
# services/import_engine/rollback.py

class RollbackManager:
    """基于 import_rollback_log 的精确回滚：只删除本任务写入的行"""

    def __init__(self, job_id: str, redis: Redis):
        self.job_id = job_id
        self.redis = redis

    async def log_batch(self, session, batch_no: int,
                        table: str, inserted_ids: list[int]):
        """在写入事务内登记回滚日志（同事务，天然一致）"""
        if not inserted_ids:
            return
        await session.execute(text(
            "INSERT INTO import_rollback_log "
            "(job_id, batch_no, target_table, row_ids, created_at) "
            "VALUES (:j, :b, :t, :ids, NOW())"
        ), {"j": self.job_id, "b": batch_no, "t": table,
            "ids": json.dumps(inserted_ids)})

    async def rollback(self, db, job_id: str) -> dict:
        """执行回滚：CAS rolling_back 抢占 → 逐批 DELETE → rolled_back"""
        acquired = await ImportJob.cas_state(
            job_id, ["completed", "partial_completed"], "rolling_back")
        if not acquired:
            raise JobStateConflict(job_id, "当前状态不允许回滚")

        logs = await db.fetch_all(
            "SELECT * FROM import_rollback_log WHERE job_id = :j "
            "ORDER BY batch_no DESC", {"j": job_id})

        deleted, failed_batches = 0, []
        for log in logs:
            row_ids = json.loads(log["row_ids"])
            try:
                async with db.transaction():
                    await db.execute(text(
                        f"DELETE FROM {log['target_table']} WHERE id IN :ids"
                    ), {"ids": tuple(row_ids)})
                    await db.execute(text(
                        "UPDATE import_rollback_log SET rollback_status=1 "
                        "WHERE id = :id"), {"id": log["id"]})
                deleted += len(row_ids)
            except Exception as exc:
                failed_batches.append({"batchNo": log["batch_no"],
                                       "reason": str(exc)[:200]})

        if failed_batches:
            # 部分回滚失败：保持 rolling_back，告警人工介入（禁止自动重试删除）
            await _emit_outbox(job_id, "import.rollback.stuck", {
                "jobId": job_id, "deleted": deleted,
                "failedBatches": failed_batches,
            })
            return {"state": "rolling_back", "deleted": deleted,
                    "failedBatches": failed_batches}

        await ImportJob.cas_state(job_id, "rolling_back", "rolled_back")
        await _emit_outbox(job_id, "import.job.rolled_back", {
            "jobId": job_id, "deletedRows": deleted,
        })
        return {"state": "rolled_back", "deleted": deleted}
```

### 7.5 通用批量操作执行器（BatchOperationExecutor）

面向"批量发布/下架/打标签/发权益"等非文件类批量操作：

```python
# services/import_engine/batch_ops.py

class BatchOperationExecutor:
    """通用批量操作：payload 为 ID 列表 + 动作，分片串行执行"""

    SHARD_SIZE = 200  # 每分片处理 200 个目标 ID

    async def execute(self, operation_id: str):
        op = await BatchOperation.get(operation_id)
        acquired = await BatchOperation.cas_state(
            operation_id, "pending", "running")
        if not acquired:
            return  # 幂等：调度器双跑时只有一个 worker 进入

        targets = op.target_ids  # list[int]
        handler = get_op_handler(op.action_type)  # publish/offline/tag/grant
        total, done, failed = len(targets), 0, 0

        for i in range(0, total, self.SHARD_SIZE):
            shard = targets[i:i + self.SHARD_SIZE]
            try:
                # 单分片事务；handler 内部对单个目标再包 try，单目标失败不拖垮分片
                results = await handler.apply_shard(shard, op.params)
                done += results["success"]
                failed += results["failed"]
            except Exception as exc:
                failed += len(shard)
                await BatchOperationShardError.create(
                    operation_id, i // self.SHARD_SIZE, str(exc)[:300])
            await op.update(processed=done + failed,
                            progress=round((done + failed) / total * 100, 1))

        final = ("completed" if failed == 0 else
                 "failed" if done == 0 else "partial_completed")
        await BatchOperation.cas_state(operation_id, "running", final)
        await _emit_outbox(operation_id, f"batch_op.{final}", {
            "operationId": operation_id, "actionType": op.action_type,
            "total": total, "success": done, "failed": failed,
        })
```

## 8. 并发控制与守卫规则

### 8.1 幂等与并发场景

| 场景 | 风险 | 防护措施 |
|------|------|----------|
| 重复上传同一文件 | 产生重复 ImportJob | 前端上传前计算文件 MD5，`Idempotency-Key = sha256(userId+templateCode+fileMd5)`，30min 幂等窗口直接返回已有 jobId |
| 网络重试导致创建接口重复调用 | 重复任务 | 创建接口幂等键落库 `uk_idempotency_key`，冲突返回原任务 |
| Celery 调度器双跑 | 同一 job 并发执行 | `cas_state(pending→parsing)` 抢占 + `import:lock:{jobId}` 续期锁双保险 |
| worker 执行中崩溃 | 任务悬挂 RUNNING | 看门狗扫描 `parsing/validating/importing` 超 30min 无心跳 → 重置 pending 重跑（去重 Set 保证重跑幂等） |
| 重复点击"开始导入" | 并发触发 | 前端按钮 loading 禁用 + 服务端 `import:semaphore:{templateCode}` 每用户并发 1 |
| 批次写入后进程崩溃 | 回滚日志与业务数据不一致 | 回滚日志与写入**同事务**提交，天然一致 |
| 回滚执行中再次触发回滚 | 并发删除 | `cas_state(completed/partial_completed→rolling_back)` 抢占，重复请求 37507 |
| 批量操作分片重复执行 | 重复发布/重复发权益 | 每分片执行前 `SETNX batch_op:shard:{opId}:{shardNo}`，已存在则跳过；handler 内部业务级幂等（发权益用权益流水 uk） |

### 8.2 守卫规则总表

| 编号 | 规则 | 违反后果 |
|------|------|----------|
| G1 | 文件落 MinIO 前必须校验 magic number（防伪装扩展名），与声明格式不一致直接拒绝 | 拒绝上传，37504 |
| G2 | 解析、校验、写入三阶段状态机单向流转，禁止跳变（如 parsing→completed） | 状态操作抛 JobStateConflict |
| G3 | 批次写入与回滚日志必须同一事务；跨库副作用（ES/向量库）只允许出现在 after_batch_write | 事务不一致风险，代码评审红线 |
| G4 | 错误明细收集达 `maxErrors`（默认 500）后熔断，剩余行整体标记 `not_processed` 并在报告中明示 | 防止 5 万行全错撑爆错误表 |
| G5 | `relation_resolve` 字段 `createIfNotFound=false` 时必须校验目标存在，禁止静默丢弃 | REF_NOT_FOUND 计入错误明细 |
| G6 | 回滚只允许物理删除本任务写入的行（以 rollback_log.row_ids 为唯一依据），禁止按条件 DELETE | 误删存量数据，P0 事故 |
| G7 | 导入数据默认落 `status=draft`，须经内容审核工作流后才能上线（题库内容受题目生命周期管理约束） | 违规内容直达线上 |
| G8 | B端机构导入学生数据前必须校验机构数据配额与授权范围（数据权限行级隔离） | 37502 |
| G9 | 批量发放权益必须走权益流水幂等键（userId+benefitCode+batchNo），重复分片不产生重复到账 | 资损 |
| G10 | dry-run 模式禁止产生任何写副作用（解析缓存除外），落库前断言 `dry_run=True` 贯穿传递 | dry-run 污染线上数据 |
| G11 | 导入任务创建/取消/回滚全部写审计日志（操作人、模板、文件 hash、结果） | 合规审计缺失 |
| G12 | 所有导入接口仅允许 `import:*` 权限角色访问，学生/家长端无任何入口 | 权限绕过，P0 |
| G13 | 任务锁与去重 Set 的 key 必须带 jobId 前缀，禁止全局共享 key | 跨任务互相误杀 |
| G14 | after_batch_write 失败仅记录 outbox 事件并告警，禁止回滚已写入业务数据（后置增强非强一致） | 误回滚 |

## 11. 降级策略

| 编号 | 场景 | 降级措施 |
|------|------|----------|
| D1 | Redis 不可用 | 进度查询降级为直查 `import_batch` 聚合（延迟 ≤5s）；去重 Set 降级为仅批次内去重 + 库内唯一键兜底（冲突行计 failed） |
| D2 | Celery 队列积压 | 新任务进入排队并返回 202 + 预估位置；超大任务（>2 万行）自动切换低优队列，避免阻塞 B 端注册等 P0 导入 |
| D3 | 错误明细表写入压力 | 单任务错误 >5000 时改为只落聚合计数 + 错误样例前 100 条，完整明细写 MinIO CSV |
| D4 | 后置增强（向量化/ES）超时 | 跳过本批后置，入 `import.post_process.failed` 补偿队列，主流程标记 completed |
| D5 | DB 主库压力高 | 批次写入间隔自适应退避（失败率>10% 时 batch_size 100→50→25），写入线程降为串行 |
| D6 | MinIO 不可用时 | 上传接口直接 503，创建任务禁止进入 pending（不产生孤儿任务） |
| D7 | WebSocket 推送断开 | 进度降级为客户端轮询 ProgressAPI（5s 间隔），状态终态时补发一次 |
| D8 | 回滚执行中目标表被锁 | 单次 DELETE 等待 5s 超时则整批标记失败进 37514，禁止无限重试 |
| D9 | dry-run 大文件 | >1 万行 dry-run 只抽样前 1000 行校验并明确标记 `sampled=true` |
| D10 | 所有降级失效 | 熔断：暂停新任务创建（503 + 运维公告），存量 running 任务允许跑完 |

## 13. 安全与合规

1. **上传安全**：文件仅存 MinIO 私有桶，路径含随机 UUID，禁止路径遍历；下载错误报告需鉴权且 15min 临时签名 URL。
2. **权限**：所有接口要求 `import:*` 权限点（G12）；B端导入额外校验机构数据范围（G8，行级隔离）。
3. **审计**：任务创建/取消/回滚/报告下载全量审计（操作人、IP、模板、文件 MD5、结果计数），留存 ≥3 年。
4. **数据最小化**：导入文件处理后 7 天内从 MinIO 删除（错误报告保留 30 天），回滚日志保留 90 天。
5. **PII 保护**：学生注册类导入文件解析后立即脱敏日志（手机号/身份证打码），错误明细中禁止回显完整 PII。
6. **未成年人数据**：B端导入学生须取得机构授权函（编号登记在任务扩展字段），符合《个人信息保护法》委托处理要求。
7. **注入防护**：`_batch_insert` 列名来自模板配置而非用户输入，模板配置变更需走代码评审（G3 关联）。
8. **版权**：题库/教材内容导入须为自有或已授权内容（与内容供应商版权管理对齐），来源字段强制记录。
