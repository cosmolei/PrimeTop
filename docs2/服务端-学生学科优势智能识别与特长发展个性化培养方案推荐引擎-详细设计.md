# 服务端-学生学科优势智能识别与特长发展个性化培养方案推荐引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责从学生多维学习数据中识别**学科优势与认知特长**，构建正向优势画像，并生成个性化特长发展培养方案。与现有的薄弱点诊断、错题分析、偏科干预等"补短"体系形成互补，构建"扬长 + 补短"双轮驱动的新型学习辅助模型。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 优势识别 | 从答题、学习行为、AI对话、知识图谱等多维数据中识别学生学科优势 |
| 特长分级 | 将优势细分为"潜能型 → 稳定型 → 突出型 → 特长型"四级 |
| 培养推荐 | 基于优势等级与兴趣偏好，生成个性化拔高学习方案 |
| 动态追踪 | 持续追踪优势发展趋势，识别优势增长/衰减信号 |
| 正向激励 | 将优势识别结果接入成就系统与家长报告，增强学生自信心 |

### 1.3 适用范围

- **适用学段**：小学三年级及以上（需具备一定答题数据积累）
- **适用学科**：语文、数学、英语、物理、化学、生物、历史、地理、政治
- **数据前提**：学生至少累计 200 条答题记录 + 30 天学习行为数据

### 1.4 与现有系统的关系

| 现有系统 | 关系 |
| --- | --- |
| 薄弱点诊断引擎 | 互补：本系统识别"长板"，薄弱点诊断识别"短板" |
| 学科能力维度评估服务 | 数据来源：能力雷达图作为优势识别输入 |
| 知识追踪模型引擎 | 数据来源：知识点掌握度作为优势识别输入 |
| 学习规划服务 | 下游消费：优势培养方案注入学习计划 |
| 成就与里程碑追踪 | 下游消费：优势解锁成就徽章 |
| 学情分析报告 | 下游消费：优势分析纳入学情报告 |
| 学科竞赛培养引擎 | 上游供给：特长型学生推荐至竞赛培养路径 |

## 4. 优势识别算法

### 4.1 优势等级判定标准

```python
class StrengthLevelClassifier:
    """学生学科优势等级分类器"""
    
    LEVEL_POTENTIAL = 1      # 潜能型
    LEVEL_STABLE = 2         # 稳定型
    LEVEL_OUTSTANDING = 3    # 突出型
    LEVEL_TALENTED = 4       # 特长型
    
    @staticmethod
    def classify(
        mastery_score: float,
        peer_percentile: float,
        consecutive_high_perf: int,
        advantage_dimensions_count: int,
        trend_slope: float,
        sample_count: int
    ) -> int:
        """
        综合判定学科优势等级
        
        参数:
            mastery_score: 学科综合掌握度 0-100
            peer_percentile: 同龄人百分位 0-99.99
            consecutive_high_perf: 连续高表现（>85分）次数
            advantage_dimensions_count: 优势维度数量（advantageRatio≥10的维度数）
            trend_slope: 近30天掌握度变化斜率
            sample_count: 总样本量
        """
        # 样本量不足时降级处理
        if sample_count < 50:
            return 0  # 待评估
        
        # 样本量50-100，置信度打折
        confidence_factor = min(1.0, sample_count / 100)
        adjusted_score = mastery_score * confidence_factor
        adjusted_percentile = peer_percentile * confidence_factor
        
        # 特长型：多项条件需同时满足
        if (adjusted_score >= 90 and 
            adjusted_percentile >= 95 and
            consecutive_high_perf >= 10 and
            advantage_dimensions_count >= 3 and
            trend_slope >= 0):
            return StrengthLevelClassifier.LEVEL_TALENTED
        
        # 突出型
        if (adjusted_score >= 85 and 
            adjusted_percentile >= 90 and
            consecutive_high_perf >= 5 and
            advantage_dimensions_count >= 2):
            return StrengthLevelClassifier.LEVEL_OUTSTANDING
        
        # 稳定型
        if (adjusted_score >= 78 and 
            adjusted_percentile >= 80 and
            consecutive_high_perf >= 3):
            return StrengthLevelClassifier.LEVEL_STABLE
        
        # 潜能型：有优势苗头但尚不稳定
        if (adjusted_score >= 72 and
            adjusted_percentile >= 70 and
            (advantage_dimensions_count >= 1 or trend_slope > 0.05)):
            return StrengthLevelClassifier.LEVEL_POTENTIAL
        
        return 0  # 未达到优势标准
```

### 4.2 多维度优势评分模型

```python
import numpy as np
from typing import List, Dict

class StrengthScoringModel:
    """
    多维度优势综合评分模型
    
    融合信号源:
    1. 答题表现（正确率、难度加权、速度）
    2. 知识点掌握度（掌握深度、覆盖广度）
    3. 学习行为（高难度内容偏好、主动探索）
    4. AI对话质量（提问深度、理解速度）
    5. 同伴对比（百分位、相对优势）
    """
    
    # 信号权重配置（可后台调整）
    DEFAULT_WEIGHTS = {
        'answer_performance': 0.35,
        'knowledge_mastery': 0.25,
        'learning_behavior': 0.15,
        'ai_interaction': 0.10,
        'peer_comparison': 0.15
    }
    
    def compute_subject_score(
        self,
        student_id: int,
        subject_code: str,
        weights: Dict[str, float] = None
    ) -> Dict[str, float]:
        """计算学科综合优势得分"""
        w = weights or self.DEFAULT_WEIGHTS
        
        # 1. 答题表现得分
        answer_score = self._compute_answer_performance(student_id, subject_code)
        
        # 2. 知识掌握度得分
        mastery_score = self._compute_knowledge_mastery(student_id, subject_code)
        
        # 3. 学习行为得分
        behavior_score = self._compute_learning_behavior(student_id, subject_code)
        
        # 4. AI交互质量得分
        ai_score = self._compute_ai_interaction_quality(student_id, subject_code)
        
        # 5. 同伴对比得分
        peer_score = self._compute_peer_comparison(student_id, subject_code)
        
        # 加权综合
        total = (
            answer_score * w['answer_performance'] +
            mastery_score * w['knowledge_mastery'] +
            behavior_score * w['learning_behavior'] +
            ai_score * w['ai_interaction'] +
            peer_score * w['peer_comparison']
        )
        
        return {
            'total_score': round(total, 2),
            'components': {
                'answer_performance': round(answer_score, 2),
                'knowledge_mastery': round(mastery_score, 2),
                'learning_behavior': round(behavior_score, 2),
                'ai_interaction': round(ai_score, 2),
                'peer_comparison': round(peer_score, 2)
            }
        }
    
    def _compute_answer_performance(self, student_id: int, subject: str) -> float:
        """
        答题表现评分
        
        融合: 正确率 + 难度加权 + 速度评分 + 高难度题正确率
        """
        # 从答题记录服务获取近90天数据
        records = self.answer_record_service.query_recent(
            student_id=student_id,
            subject=subject,
            days=90,
            min_count=30
        )
        
        if not records:
            return 0.0
        
        correct_rate = np.mean([r.is_correct for r in records])
        
        # 难度加权正确率：高难度题权重更大
        difficulty_weights = {1: 0.5, 2: 0.8, 3: 1.0, 4: 1.5, 5: 2.0}
        weighted_scores = []
        for r in records:
            dw = difficulty_weights.get(r.difficulty, 1.0)
            weighted_scores.append((1.0 if r.is_correct else 0.0) * dw)
        total_weight = sum(difficulty_weights.get(r.difficulty, 1.0) for r in records)
        difficulty_weighted_rate = sum(weighted_scores) / total_weight if total_weight > 0 else 0
        
        # 高难度题正确率（难度≥4）
        hard_questions = [r for r in records if r.difficulty >= 4]
        hard_correct_rate = (
            np.mean([r.is_correct for r in hard_questions]) 
            if hard_questions else 0.5  # 没有高难度题时给中等分
        )
        
        # 综合得分
        score = (
            correct_rate * 30 +
            difficulty_weighted_rate * 30 +
            hard_correct_rate * 40
        )
        return min(100.0, score)
    
    def _compute_knowledge_mastery(self, student_id: int, subject: str) -> float:
        """
        知识掌握度评分
        
        融合: 平均掌握度 + 高难度知识点覆盖 + 掌握深度
        """
        kp_masteries = self.knowledge_tracking_service.get_subject_masteries(
            student_id, subject
        )
        
        if not kp_masteries:
            return 0.0
        
        avg_mastery = np.mean([m.mastery_value for m in kp_masteries])
        
        # 高难度知识点掌握比例
        hard_kps = [m for m in kp_masteries if m.difficulty >= 4]
        hard_mastery_rate = (
            np.mean([m.mastery_value for m in hard_kps]) 
            if hard_kps else 0.5
        )
        
        # 掌握度方差（越低说明掌握越均衡→更稳定）
        mastery_std = np.std([m.mastery_value for m in kp_masteries])
        consistency_bonus = max(0, 10 - mastery_std * 20)  # 标准差越小bonus越高
        
        score = avg_mastery * 100 * 0.5 + hard_mastery_rate * 100 * 0.4 + consistency_bonus
        return min(100.0, score)
    
    def _compute_learning_behavior(self, student_id: int, subject: str) -> float:
        """
        学习行为优势评分
        
        信号: 主动选择高难度内容、学习深度指标、主动探索行为
        """
        behavior_data = self.behavior_service.get_subject_behavior_summary(
            student_id, subject, days=30
        )
        
        score = 0.0
        
        # 高难度内容主动选择比例
        high_diff_ratio = behavior_data.high_difficulty_content_ratio
        score += high_diff_ratio * 35
        
        # 平均单次学习时长（深度学习指标）
        avg_session_minutes = behavior_data.avg_session_duration_minutes
        depth_score = min(35.0, avg_session_minutes / 25.0 * 35)  # 25分钟为满分
        score += depth_score
        
        # 主动探索行为（查看课外拓展、追问深度问题等）
        exploration_count = behavior_data.exploration_action_count
        exploration_score = min(30.0, exploration_count / 15.0 * 30)  # 15次探索为满分
        score += exploration_score
        
        return min(100.0, score)
    
    def _compute_ai_interaction_quality(self, student_id: int, subject: str) -> float:
        """
        AI对话交互质量评分
        
        信号: 提问深度、追问质量、理解速度（从提问到标记"懂了"的时间）
        """
        ai_data = self.ai_dialogue_service.get_subject_interaction_summary(
            student_id, subject, days=30
        )
        
        if not ai_data or ai_data.total_conversations == 0:
            return 50.0  # 无AI对话数据时给中性分
        
        score = 0.0
        
        # 提问质量评分（由NLP分析提问的认知深度）
        score += ai_data.avg_question_depth_score * 40  # 0-100 → 0-40
        
        # 追问深度（多轮对话中追问的认知层次递进）
        score += ai_data.follow_up_depth_score * 30
        
        # 知识迁移信号（提问中涉及跨章节/跨学科关联的频率）
        score += min(30.0, ai_data.cross_topic_connection_count / 5.0 * 30)
        
        return min(100.0, score)
    
    def _compute_peer_comparison(self, student_id: int, subject: str) -> float:
        """
        同伴对比得分
        
        基于同年级、同学段、同教材版本的学生群体进行对比
        """
        percentile = self.peer_benchmark_service.get_subject_percentile(
            student_id, subject
        )
        
        # 百分位直接映射为得分
        return percentile
```

```python
            ],

        }
    }
    
    def detect_talents(self, student_id: int) -> List[Dict]:
        """检测学生的跨学科优势簇"""
        results = []
        
        for cluster_code, cluster_def in self.TALENT_CLUSTERS.items():
            # 获取相关学科的维度得分
            subject_scores = {}
            for subject in cluster_def['subjects']:
                dims = self.strength_service.get_dimensions(student_id, subject)
                subject_scores[subject] = {
                    d.dimension_code: d.dimension_score 
                    for d in dims if d.dimension_code in cluster_def['shared_dimensions']
                }

            for subject, dim_scores in subject_scores.items():

                avg_score = np.mean(list(dim_scores.values()))
                if avg_score >= 75:  # 学科维度均分≥75视为优势
                    strong_subjects.append(subject)
            
            if len(strong_subjects) >= cluster_def['min_subjects']:

                all_dim_scores = []
                for scores in subject_scores.values():

                synergy = self._compute_synergy(subject_scores)
                
                results.append({
                    'clusterCode': cluster_code,
                    'clusterName': cluster_def['name'],
                    'subjects': strong_subjects,
                    'clusterScore': round(cluster_score, 1),
                    'synergyLevel': synergy,
                    'description': self._generate_description(cluster_def, strong_subjects)
                })
        
        return sorted(results, key=lambda x: x['clusterScore'], reverse=True)
```

### 5.2 内容推荐排序逻辑

```python
class ContentRanker:
    """
    拔高内容推荐排序器
    
    排序因子:
    1. 内容难度与学生当前水平的匹配度（最近发展区理论）
    2. 内容与学生优势维度的契合度
    3. 内容质量评分（历史用户反馈）
    4. 内容新鲜度（近期生产/更新的优先）
    5. 前置依赖满足度
    """
    
    def rank(self, contents: List[Content], student_profile: SubjectStrength) -> List[Content]:
        scored = []
        for content in contents:
            # 难度匹配度：使用最近发展区模型
            zpd_score = self._zpd_match_score(
                content.difficulty,
                student_profile.mastery_score / 20  # 转为1-5尺度
            )
            
            # 维度契合度
            dimension_match = self._dimension_match_score(
                content.tagged_dimensions,
                student_profile.advantage_dimensions
            )
            
            # 内容质量
            quality = content.quality_score or 70.0
            
            # 新鲜度
            freshness = self._freshness_score(content.published_at)
            
            # 综合得分
            total = (
                zpd_score * 0.35 +
                dimension_match * 0.30 +
                quality * 0.20 +
                freshness * 0.15
            )
            scored.append((content, total))
        
        scored.sort(key=lambda x: x[1], reverse=True)
        return [c for c, _ in scored]
    
    @staticmethod
    def _zpd_match_score(content_difficulty: float, student_level: float) -> float:
        """
        最近发展区(Zone of Proximal Development)匹配评分
        
        理想难度 = 学生当前水平 + 0.5~1.5（略有挑战但可达）
        """
        import math
        ideal_low = student_level + 0.3
        ideal_high = student_level + 1.5
        
        if ideal_low <= content_difficulty <= ideal_high:
            return 100.0  # 完美匹配
        
        # 偏离理想区间的惩罚
        if content_difficulty < ideal_low:
            # 过于简单
            diff = ideal_low - content_difficulty
        else:
            # 过于困难
            diff = content_difficulty - ideal_high
        
        return max(0, 100 - diff * 30)  # 线性衰减，每偏离1级扣30分
```

```python
class StrengthProfileUpdateJob:
    """
    每日凌晨2:00执行
    批量更新所有活跃学生的优势画像
    """
    
    SCHEDULE = "0 0 2 * * ?"  # 每天凌晨2点
    BATCH_SIZE = 500
    THREAD_POOL = 8
    
    def execute(self):
        # 1. 获取需要更新的学生列表（近7天有学习行为）
        student_ids = self.user_service.get_active_student_ids(days=7)
        
        logger.info(f"优势画像更新任务启动，共{len(student_ids)}名学生")
        
        # 2. 分批并行处理
        with ThreadPoolExecutor(max_workers=self.THREAD_POOL) as executor:
            for batch in self._chunk(student_ids, self.BATCH_SIZE):
                executor.submit(self._process_batch, batch)
        
        logger.info("优势画像更新任务完成")
    
    def _process_batch(self, student_ids: List[int]):
        for sid in student_ids:
            try:
                self._update_single_student(sid)
            except Exception as e:
                logger.error(f"学生{sid}优势画像更新失败: {e}", exc_info=True)
                self.alert_service.send_ding_alert(
                    title="优势画像更新异常",
                    content=f"学生ID: {sid}, 错误: {str(e)}"
                )
    
    def _update_single_student(self, student_id: int):
        """更新单个学生的优势画像"""
        # 获取所有学科的最新评分
        subjects = self.subject_service.get_student_subjects(student_id)
        subject_scores = {}
        
        for subject in subjects:
            score_data = self.scoring_model.compute_subject_score(student_id, subject.code)
            subject_scores[subject.code] = score_data
        
        if not subject_scores:
            return
        
        # 判定各学科优势等级
        strength_records = []
        for subject_code, scores in subject_scores.items():
            level = StrengthLevelClassifier.classify(
                mastery_score=scores['total_score'],
                peer_percentile=scores['components']['peer_comparison'],
                consecutive_high_perf=self._get_consecutive_high_perf(student_id, subject_code),
                advantage_dimensions_count=self._count_advantage_dimensions(student_id, subject_code),
                trend_slope=self._compute_trend_slope(student_id, subject_code),
                sample_count=self._get_sample_count(student_id, subject_code)
            )
            
            if level > 0:
                strength_records.append({
                    'subject': subject_code,
                    'level': level,
                    'score': scores['total_score']
                })
        
        # 获取跨学科优势
        cross_talents = self.cross_subject_detector.detect_talents(student_id)
        
        # 计算综合等级（取最高学科等级）
        overall_level = max([r['level'] for r in strength_records], default=0)
        
        # 保存快照
        self.strength_repository.save_profile_snapshot(
            student_id=student_id,
            snapshot_date=date.today(),
            overall_level=overall_level,
            confidence_score=self._compute_confidence(subject_scores),
            data_points=sum(s['components'].values() for s in subject_scores).__len__(),
            profile_json=self._build_profile_json(strength_records, cross_talents)
        )
        
        # 触发等级变更事件
        self._check_level_change(student_id, overall_level)
```

```python
class StrengthTrendMonitorJob:
```

```python
class StrengthServiceFallback:
    """优势识别服务降级策略"""
    
    async def get_profile_with_fallback(self, student_id: int):
        try:
            # 正常路径：实时计算
            return await self.scoring_model.compute_full_profile(student_id)
        
        except KnowledgeTrackingServiceUnavailable:
            # 降级1：知识追踪服务不可用，仅使用答题数据
            logger.warning("知识追踪服务不可用，降级为答题数据评分")
            return await self.scoring_model.compute_with_answer_data_only(student_id)
        
        except PeerBenchmarkServiceUnavailable:
            # 降级2：同伴对比服务不可用，使用历史百分位缓存
            logger.warning("同伴对比服务不可用，使用缓存百分位")
            return await self.scoring_model.compute_with_cached_percentile(student_id)
        
        except AIServiceUnavailable:
            # 降级3：AI对话数据不可用，跳过AI维度（权重重分配）
            logger.warning("AI服务不可用，跳过AI交互维度")
            adjusted_weights = {
                'answer_performance': 0.40,
                'knowledge_mastery': 0.30,
                'learning_behavior': 0.20,
                'ai_interaction': 0.00,  # 权重置零
                'peer_comparison': 0.10
            }
            return await self.scoring_model.compute_profile(student_id, weights=adjusted_weights)
        
        except AllDataSourcesFailed:
            # 最终降级：返回最近一次缓存画像
            cached = await self.cache.get(f"strength:profile:{student_id}")
            if cached:
                cached['degraded'] = True
                cached['degradedReason'] = '数据源不可用，显示缓存结果'
                return cached
            raise BizException(5001, "优势评估服务暂时不可用，请稍后重试")
```

```python
class StrengthDataMasker:
    """优势数据脱敏处理"""
    
    def mask_for_peer_view(self, data: dict) -> dict:
        """同伴视图脱敏：隐藏具体分数，只显示等级和百分位区间"""
        data['masteryScore'] = None
        data['peerPercentile'] = self._bucket_percentile(data.get('peerPercentile'))
        return data
    
    @staticmethod
    def _bucket_percentile(p: float) -> str:
        if p >= 95: return "TOP 5%"
        if p >= 90: return "TOP 10%"
        if p >= 80: return "TOP 20%"
        if p >= 70: return "TOP 30%"
        return "—"
    
    def mask_for_class_aggregate(self, records: List[dict]) -> dict:
        """班级聚合视图：只返回统计分布，不暴露个人数据"""
        return {
            'totalStudents': len(records),
            'levelDistribution': self._count_by_level(records),
            'topSubjects': self._aggregate_top_subjects(records),
            'avgScoreBySubject': self._compute_avg_by_subject(records)
```
