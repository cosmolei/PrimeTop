## 1. 概述

### 1.1 功能目标

为小学、初中、高中三个学段的学生提供 **语文阅读理解全链路训练服务**，覆盖：

- **阅读文本管理**：现代文（记叙文、说明文、议论文、散文、小说）、文言文、古诗词鉴赏文本的结构化管理
- **题目体系**：信息提取、词义理解、句段分析、主旨概括、写作手法鉴赏、推断想象、评价探究等 N 个题型维度
- **AI 辅导**：分步引导式讲解，不直接给答案，按"定位→理解→分析→归纳"四步法辅导
- **能力评估**：多维度阅读能力雷达（信息筛选力、理解力、分析力、鉴赏力、评价力）
- **个性化推荐**：基于学生能力画像和弱点推荐适配难度的阅读材料与训练题
- **答题批改**：主观题智能评分 + 采分点匹配 + 结构化反馈

### 1.2 学段差异设计

| 维度 | 小学 | 初中 | 高中 |
|------|------|------|------|
| 文本类型 | 童话、寓言、叙事散文、简单说明文 | 记叙文、说明文、议论文、小说节选、浅易文言文 | 现代散文、小说、论述类、实用类文本、文言文、古诗词 |
| 文本长度 | 300-800 字 | 600-1500 字 | 800-2000 字 |
| 题型重点 | 信息提取、词义理解、简单概括 | 段落作用、写作手法、人物分析、主旨归纳 | 论证分析、推断想象、鉴赏评价、比较阅读、探究 |
| 认知层级 | 布鲁姆 L1-L3（记忆-理解-应用） | 布鲁姆 L2-L4（理解-应用-分析） | 布鲁姆 L3-L6（分析-评价-创造） |
| 反馈方式 | 鼓励式、口语化、示例引导 | 规范术语、分步解析、方法总结 | 专业术语、深度分析、多角度比较 |

## 2. 核心概念与领域模型

### 2.1 领域实体总览

```
ReadingPassage（阅读文本）
  ├── PassageSegment（文本分段）
  ├── PassageAnnotation（文本标注 — 关键句、修辞手法等）
  └── PassageTag（文本标签 — 主题、文体、难度等）

ReadingQuestion（阅读题目）
  ├── QuestionOption（客观题选项）
  ├── ScoringRubric（采分点 / 评分标准）
  └── QuestionKnowledgeMapping（题目-知识点映射）

ReadingExerciseSession（阅读训练会话）
  ├── ExerciseAnswer（学生作答）
  └── GradingResult（批改结果）

ReadingAbilityProfile（学生阅读能力画像）
  └── AbilityDimensionScore（分维度得分）

ReadingRecommendationTask（推荐任务）
```

## 4. 阅读文本管理与难度分级

### 4.1 文本难度自动评估算法

文本难度由多维特征综合计算，**不依赖人工标注**，使用回归模型预测难度分（0-100）。

```java
/**
 * 语文阅读文本难度自动评估器
 * 
 * 难度评估维度:
 * 1. 词汇难度 — 低频词/文言词/专业术语占比
 * 2. 句法复杂度 — 平均句长、长句占比、嵌套深度
 * 3. 语篇结构 — 篇章长度、段落数、结构复杂度
 * 4. 语义密度 — 信息密度、抽象概念占比
 * 5. 文体特征 — 文言文/议论文天然加成
 */
@Component
public class PassageDifficultyAssessor {

    private static final int[] GRADE_WORD_COUNT_BENCHMARK = {
        0, 300, 400, 500, 600, 700, 800,  // 小学 1-6年级
        900, 1000, 1200,                   // 初中 7-9年级
        1500, 1800, 2000                   // 高中 10-12年级
    };
    
    /**
     * 综合难度评估
     */
    public DifficultyAssessmentResult assess(String fullText, PassageGenre genre) {
        DifficultyFeatures features = extractFeatures(fullText);
        
        // 文体难度系数
        double genreCoefficient = getGenreCoefficient(genre);
        
        // 加权综合难度分
        double difficultyScore = 
              features.getVocabularyDifficulty() * 0.25
            + features.getSentenceComplexity() * 0.25
            + features.getDiscourseComplexity() * 0.20
            + features.getSemanticDensity() * 0.15
            + genreCoefficient * 0.15;
        
        // 映射到 L1-L7
        PassageDifficultyLevel level = mapScoreToLevel(difficultyScore);
        
        // 估计阅读时长 (基于字数和难度)
        int readingTimeEst = estimateReadingTime(features.getWordCount(), difficultyScore);
        
        return DifficultyAssessmentResult.builder()
            .difficultyScore(Math.round(difficultyScore * 100.0) / 100.0)
            .difficultyLevel(level)
            .readingTimeEst(readingTimeEst)
            .features(features)
            .build();
    }
    
    /**
     * 提取文本难度特征
     */
    private DifficultyFeatures extractFeatures(String text) {
        // 1. 分句
        List<String> sentences = ChineseTextSplitter.split(text);
        int wordCount = text.length();
        
        // 2. 词汇难度
        List<String> tokens = ChineseTokenizer.tokenize(text);
        double lowFreqRatio = calculateLowFrequencyRatio(tokens);
        double classicalWordRatio = calculateClassicalWordRatio(tokens);
        
        // 3. 句法复杂度
        double avgSentenceLength = wordCount / (double) sentences.size();
        double longSentenceRatio = sentences.stream()
            .filter(s -> s.length() > 40)
            .count() / (double) sentences.size();
        
        // 4. 语篇结构
        int paragraphCount = text.split("\n\n+").length;
        
        return DifficultyFeatures.builder()
            .wordCount(wordCount)
            .vocabularyDifficulty(
                Math.min(100, lowFreqRatio * 300 + classicalWordRatio * 400)
            )
            .sentenceComplexity(
                Math.min(100, avgSentenceLength * 1.5 + longSentenceRatio * 80)
            )
            .discourseComplexity(
                Math.min(100, paragraphCount * 3.0 + wordCount / 20.0)
            )
            .semanticDensity(calculateSemanticDensity(text))
            .build();
    }
    
    /**
     * 低频词比例 — 基于《现代汉语频率词典》词频表
     */
    private double calculateLowFrequencyRatio(List<String> tokens) {
        if (tokens.isEmpty()) return 0;
        long lowFreqCount = tokens.stream()
            .filter(t -> wordFrequencyRanker.getFrequency(t) < 0.0001)
            .count();
        return (double) lowFreqCount / tokens.size();
    }
    
    private PassageDifficultyLevel mapScoreToLevel(double score) {
        if (score < 15) return PassageDifficultyLevel.L1;
        if (score < 25) return PassageDifficultyLevel.L2;
        if (score < 38) return PassageDifficultyLevel.L3;
        if (score < 50) return PassageDifficultyLevel.L4;
        if (score < 62) return PassageDifficultyLevel.L5;
        if (score < 75) return PassageDifficultyLevel.L6;
        return PassageDifficultyLevel.L7;
    }
    
    private int estimateReadingTime(int wordCount, double difficultyScore) {
        // 基础阅读速度: 300字/分钟 (小学) ~ 600字/分钟 (高中)
        int baseSpeed = difficultyScore < 25 ? 300 
                      : difficultyScore < 50 ? 400
                      : difficultyScore < 70 ? 500 
                      : 600;
        return (int) Math.ceil(wordCount * 60.0 / baseSpeed);
    }
    
    private double getGenreCoefficient(PassageGenre genre) {
        return switch (genre) {
            case CLASSICAL_CHINESE -> 75;     // 文言文天然高难度
            case CLASSICAL_POETRY -> 70;
            case ARGUMENTATIVE -> 55;
            case LITERARY_ESSAY -> 50;
            case EXPOSITORY -> 40;
            case LITERARY_FICTION -> 38;
            case NARRATIVE -> 30;
            case NEWS -> 25;
            default -> 35;
        };
    }
}
