## 1. 概述

### 1.1 功能目标

为小学、初中、高中三个学段的学生提供 **语文阅读理解全链路训练服务**，覆盖：

- **阅读文本管理**：现代文（记叙文、说明文、议论文、散文、小说）、文言文、古诗词鉴赏文本的结构化管理
- **题目体系**：信息提取、词义理解、句段分析、主旨概括、写作手法鉴赏、推断想象、评价探究等 N 个题型维度
- **AI 辅导**：分步引导式讲解，不直接给答案，按"定位→理解→分析→归纳"四步法辅导
- **能力评估**：多维度阅读能力雷达（信息筛选力、理解力、分析力、鉴赏力、评价力）
- **个性化推荐**：基于学生能力画像和弱点推荐适配难度的阅读材料与训练题
- **答题批改**：主观题智能评分 + 采分点匹配 + 结构化反馈

### 1.2 学段差异设计

| 维度 | 小学 | 初中 | 高中 |
|------|------|------|------|
| 文本类型 | 童话、寓言、叙事散文、简单说明文 | 记叙文、说明文、议论文、小说节选、浅易文言文 | 现代散文、小说、论述类、实用类文本、文言文、古诗词 |
| 文本长度 | 300-800 字 | 600-1500 字 | 800-2000 字 |
| 题型重点 | 信息提取、词义理解、简单概括 | 段落作用、写作手法、人物分析、主旨归纳 | 论证分析、推断想象、鉴赏评价、比较阅读、探究 |
| 认知层级 | 布鲁姆 L1-L3（记忆-理解-应用） | 布鲁姆 L2-L4（理解-应用-分析） | 布鲁姆 L3-L6（分析-评价-创造） |
| 反馈方式 | 鼓励式、口语化、示例引导 | 规范术语、分步解析、方法总结 | 专业术语、深度分析、多角度比较 |

## 2. 核心概念与领域模型

### 2.1 领域实体总览

```
ReadingPassage（阅读文本）
  ├── PassageSegment（文本分段）
  ├── PassageAnnotation（文本标注 — 关键句、修辞手法等）
  └── PassageTag（文本标签 — 主题、文体、难度等）

ReadingQuestion（阅读题目）
  ├── QuestionOption（客观题选项）
  ├── ScoringRubric（采分点 / 评分标准）
  └── QuestionKnowledgeMapping（题目-知识点映射）

ReadingExerciseSession（阅读训练会话）
  ├── ExerciseAnswer（学生作答）
  └── GradingResult（批改结果）

ReadingAbilityProfile（学生阅读能力画像）
  └── AbilityDimensionScore（分维度得分）

ReadingRecommendationTask（推荐任务）
```

## 4. 阅读文本管理与难度分级

### 4.1 文本难度自动评估算法

文本难度由多维特征综合计算，**不依赖人工标注**，使用回归模型预测难度分（0-100）。

```java
/**
 * 语文阅读文本难度自动评估器
 * 
 * 难度评估维度:
 * 1. 词汇难度 — 低频词/文言词/专业术语占比
 * 2. 句法复杂度 — 平均句长、长句占比、嵌套深度
 * 3. 语篇结构 — 篇章长度、段落数、结构复杂度
 * 4. 语义密度 — 信息密度、抽象概念占比
 * 5. 文体特征 — 文言文/议论文天然加成
 */
@Component
public class PassageDifficultyAssessor {

    private static final int[] GRADE_WORD_COUNT_BENCHMARK = {
        0, 300, 400, 500, 600, 700, 800,  // 小学 1-6年级
        900, 1000, 1200,                   // 初中 7-9年级
        1500, 1800, 2000                   // 高中 10-12年级
    };
    
    /**
     * 综合难度评估
     */
    public DifficultyAssessmentResult assess(String fullText, PassageGenre genre) {
        DifficultyFeatures features = extractFeatures(fullText);
        
        // 文体难度系数
        double genreCoefficient = getGenreCoefficient(genre);
        
        // 加权综合难度分
        double difficultyScore = 
              features.getVocabularyDifficulty() * 0.25
            + features.getSentenceComplexity() * 0.25
            + features.getDiscourseComplexity() * 0.20
            + features.getSemanticDensity() * 0.15
            + genreCoefficient * 0.15;
        
        // 映射到 L1-L7
        PassageDifficultyLevel level = mapScoreToLevel(difficultyScore);
        
        // 估计阅读时长 (基于字数和难度)
        int readingTimeEst = estimateReadingTime(features.getWordCount(), difficultyScore);
        
        return DifficultyAssessmentResult.builder()
            .difficultyScore(Math.round(difficultyScore * 100.0) / 100.0)
            .difficultyLevel(level)
            .readingTimeEst(readingTimeEst)
            .features(features)
            .build();
    }
    
    /**
     * 提取文本难度特征
     */
    private DifficultyFeatures extractFeatures(String text) {
        // 1. 分句
        List<String> sentences = ChineseTextSplitter.split(text);
        int wordCount = text.length();
        
        // 2. 词汇难度
        List<String> tokens = ChineseTokenizer.tokenize(text);
        double lowFreqRatio = calculateLowFrequencyRatio(tokens);
        double classicalWordRatio = calculateClassicalWordRatio(tokens);
        
        // 3. 句法复杂度
        double avgSentenceLength = wordCount / (double) sentences.size();
        double longSentenceRatio = sentences.stream()
            .filter(s -> s.length() > 40)
            .count() / (double) sentences.size();
        
        // 4. 语篇结构
        int paragraphCount = text.split("\n\n+").length;
        
        return DifficultyFeatures.builder()
            .wordCount(wordCount)
            .vocabularyDifficulty(
                Math.min(100, lowFreqRatio * 300 + classicalWordRatio * 400)
            )
            .sentenceComplexity(
                Math.min(100, avgSentenceLength * 1.5 + longSentenceRatio * 80)
            )
            .discourseComplexity(
                Math.min(100, paragraphCount * 3.0 + wordCount / 20.0)
            )
            .semanticDensity(calculateSemanticDensity(text))
            .build();
    }
    
    /**
     * 低频词比例 — 基于《现代汉语频率词典》词频表
     */
    private double calculateLowFrequencyRatio(List<String> tokens) {
        if (tokens.isEmpty()) return 0;
        long lowFreqCount = tokens.stream()
            .filter(t -> wordFrequencyRanker.getFrequency(t) < 0.0001)
            .count();
        return (double) lowFreqCount / tokens.size();
    }
    
    private PassageDifficultyLevel mapScoreToLevel(double score) {
        if (score < 15) return PassageDifficultyLevel.L1;
        if (score < 25) return PassageDifficultyLevel.L2;
        if (score < 38) return PassageDifficultyLevel.L3;
        if (score < 50) return PassageDifficultyLevel.L4;
        if (score < 62) return PassageDifficultyLevel.L5;
        if (score < 75) return PassageDifficultyLevel.L6;
        return PassageDifficultyLevel.L7;
    }
    
    private int estimateReadingTime(int wordCount, double difficultyScore) {
        // 基础阅读速度: 300字/分钟 (小学) ~ 600字/分钟 (高中)
        int baseSpeed = difficultyScore < 25 ? 300 
                      : difficultyScore < 50 ? 400
                      : difficultyScore < 70 ? 500 
                      : 600;
        return (int) Math.ceil(wordCount * 60.0 / baseSpeed);
    }
    
    private double getGenreCoefficient(PassageGenre genre) {
        return switch (genre) {
            case CLASSICAL_CHINESE -> 75;     // 文言文天然高难度
            case CLASSICAL_POETRY -> 70;
            case ARGUMENTATIVE -> 55;
            case LITERARY_ESSAY -> 50;
            case EXPOSITORY -> 40;
            case LITERARY_FICTION -> 38;
            case NARRATIVE -> 30;
            case NEWS -> 25;
            default -> 35;
        };
    }
}
```

**流程说明**

1. **上传与解析**：内容编辑通过管理后台上传 Word / Markdown / 纯文本，服务端进行段落拆分、字符统计、非法词检测。
2. **自动难度评估**：调用 `PassageDifficultyAssessor` 计算难度分与 L1-L7 等级，作为学段匹配与推荐的基础。
3. **AI 自动标注**：调用 LLM（由 **AI 对话引擎 / Prompt 编排模块** 负责）提取主题标签、修辞手法、关键句、情感基调、写作手法等，写入 `passage_annotations`。
4. **AI 出题预生成**：基于文本结构、学段、题型分布策略生成候选题目与参考答案草稿，写入 `reading_questions`（状态 `DRAFT`）。
5. **人工审核**：教研员在后台逐条审核文本内容、难度标签、标注、题目与答案。审核不通过则回退并附修改意见；通过则进入待发布。
6. **发布与版本管理**：发布时生成不可变版本快照 `passage_version`，已发布文本被学生训练引用时锁定版本；后续修改产生新版本，旧版本进入 `ARCHIVED`。

    id              BIGSERIAL PRIMARY KEY,

    version         INT NOT NULL,                       -- 版本号，自增
    version_code    VARCHAR(32) NOT NULL UNIQUE,        -- RP-2026-000001-v3
    snapshot_data   JSONB NOT NULL,                     -- 文本+标注+题目快照

CREATE INDEX idx_passage_version_passage ON passage_versions(passage_id, version);

## 7. 学生阅读能力评估模型

### 7.1 五维能力雷达

阅读能力画像由五个维度构成，对应 `ReadingAbilityDimension`：

| 维度 | 英文名 | 主要考察题型 |
|------|--------|--------------|
| 信息筛选与提取力 | INFORMATION_RETRIEVAL | 信息提取、选择题（信息类） |
| 理解力 | COMPREHENSION | 词义理解、主旨概括、翻译 |
| 分析力 | ANALYSIS | 段落作用、写作手法、人物分析 |
| 鉴赏力 | APPRECIATION | 句子赏析、古诗词鉴赏 |
| 评价探究力 | EVALUATION | 推断、开放性探究、比较阅读 |

### 7.2 维度得分更新公式

采用加权 EMA（指数移动平均）更新能力分，答对加分、答错减分，幅度受题目难度、置信度影响：

```
new_score = old_score + α * impact * (actual - expected)

其中：
- actual：学生实际得分率（0-1）
- expected：基于当前能力预测的预期得分率
- impact：题目对该维度的影响权重
- α：学习率，小学 0.15、初中 0.12、高中 0.10
- expected = 1 / (1 + exp(-k * (ability - questionDifficulty)))
```

```java
@Component
public class AbilityScoreUpdater {

    private static final double K = 0.05;

    public double updateDimension(double oldScore, double questionDifficulty,
                                   double actualRate, double impact, GradeStage stage) {
        double expected = 1.0 / (1.0 + Math.exp(-K * (oldScore - questionDifficulty)));
        double alpha = switch (stage) {
            case ELEMENTARY -> 0.15;
            case MIDDLE -> 0.12;
            case HIGH -> 0.10;
        };
        double delta = alpha * impact * (actualRate - expected);
        return Math.max(0.0, Math.min(100.0, oldScore + delta));
    }
}
```

### 7.3 冷启动处理

新用户未作答或答题不足 5 道时，能力画像处于冷启动：

1. **初始分设置**：所有维度默认 50 分，学段越高默认越接近该学段基准（初中 55、高中 58）。
2. **入学测评**：优先推送 5-8 道覆盖五维的诊断题，快速收敛画像。
3. **题型加权**：前 10 次答题 α 提高 20%，加快学习速度。
4. **置信度标识**：`is_cold_start` 为 `true`，直到累计答题 ≥ 20 题且覆盖 ≥ 3 种题型。

### 7.4 能力等级映射

综合五维得分加权得到 `overallScore`，映射推荐难度等级：

| 综合得分范围 | 推荐等级 | 说明 |
|--------------|----------|------|
| 0-25 | L1-L2 | 以基础信息提取为主 |
| 25-40 | L3-L4 | 加强理解与简单分析 |
| 40-55 | L4-L5 | 标准学段难度 |
| 55-70 | L5-L6 | 提升型，增加鉴赏与评价 |
| 70-100 | L6-L7 | 拔尖训练，开放探究 |

## 8. 个性化阅读推荐引擎

### 8.1 推荐目标与约束

**目标**：为学生推荐“跳一跳够得着”的阅读文本与训练题，兼顾能力成长与学习兴趣。

**约束**：
- 难度匹配：推荐文本难度在 `[profile.level - 1, profile.level + 1]` 区间。
- 学段一致：文本学段与学生当前学段一致或略高。
- 去重：最近 30 天已读文本不再推荐。
- 多样性：同一推荐列表中文体 ≥ 2 种，题型 ≥ 3 种。
- 教材进度：可优先推荐与当前教材章节关联文本。

### 8.2 多路召回策略

| 召回路 | 依据 | 数量 | 说明 |
|--------|------|------|------|
| 能力匹配 | 画像综合等级 + 难度区间 | 15 | 核心召回 |
| 薄弱项补强 | weak_dimensions / weak_question_types | 10 | 针对低分维度 |
| 教材进度 | textbook_chapter_id + 年级 | 8 | 同步课堂 |
| 热度/优质 | usage_count + quality_score | 5 | 流行且高质量 |
| 错题同类 | 错题知识点标签匹配 | 5 | 由 **错题整理模块** 提供 |

### 8.3 排序与多样性控制

排序采用多目标加权公式：

```
score = w1 * difficultyFit + w2 * abilityGrowth + w3 * interest + w4 * freshness

- difficultyFit：难度与画像匹配度，越接近当前等级越高
- abilityGrowth：预计对该维度能力提升幅度
- interest：基于学生历史偏好（主题、文体）
- freshness：未读时间越久得分越高
```

多样性控制使用 **MMR（Maximal Marginal Relevance）**：

```java
public List<PassageCandidate> mmvRerank(List<PassageCandidate> candidates,
                                         int topK, double lambda) {
    List<PassageCandidate> selected = new ArrayList<>();
    Set<PassageCandidate> remaining = new HashSet<>(candidates);
    while (selected.size() < topK && !remaining.isEmpty()) {
        PassageCandidate best = remaining.stream()
            .max(Comparator.comparingDouble(c ->
                lambda * c.relevance() - (1 - lambda) * maxSimilarity(c, selected)))
            .orElseThrow();
        selected.add(best);
        remaining.remove(best);
    }
    return selected;
}
```

| 薄弱项 | “你最近在{weakDimension}上表现较弱，这篇重点训练{questionType}。” |

### 9.2 主观题 AI 评分

主观题评分采用 **采分点匹配 + 关键词覆盖 + 语义相似度** 三层策略：

```java
@Component
public class SubjectiveGrader {

    public GradingResult grade(ReadingQuestion question, String answerText) {
        List<RubricPoint> rubric = parseRubric(question.getScoringRubric());
        double totalEarned = 0.0;
        List<PointMatchDetail> details = new ArrayList<>();

        for (RubricPoint point : rubric) {
            PointMatchDetail match = matchPoint(point, answerText);
            totalEarned += match.getEarnedScore();
            details.add(match);
        }

        // 语义相似度兜底：如果采分点得分率过低，用相似度给出部分分
        double semanticScore = semanticSimilarity(question.getReferenceAnswer(), answerText)
            * question.getFullScore();
        double finalScore = Math.max(totalEarned, semanticScore * 0.3);

        return GradingResult.builder()
            .earnedScore(Math.min(finalScore, question.getFullScore()))
            .fullScore(question.getFullScore())
            .pointDetails(details)
            .build();
    }

    private PointMatchDetail matchPoint(RubricPoint point, String answerText) {
        boolean matched = point.getKeywords().stream().anyMatch(kw ->
            switch (point.getMatchRule()) {
                case EXACT_ANY -> answerText.contains(kw);
                case SEMANTIC -> semanticContains(answerText, kw);
                case REGEX -> Pattern.compile(kw).matcher(answerText).find();
            }
        );
        double earned = matched ? point.getScore() : 0.0;
        return new PointMatchDetail(point.getPoint(), matched, earned);
    }
}
```

### 9.3 反馈生成策略

根据得分率生成不同反馈：

| 得分率 | 反馈策略 |
|--------|----------|
| 0% | 指出缺失要点，给出定位提示，不直接给答案 |
| 1%-49% | 指出部分采分点已命中，提示补充方向 |
| 50%-79% | 肯定已有分析，指出可深化之处 |
| 80%-100% | 表扬并总结优秀答题模板 |

### 9.4 人工复核流程

当满足以下任一条件时，标记为需人工复核：
- 学生或家长申诉。
- AI 评分置信度 < 0.6。
- 题目满分 ≥ 5 分且得分率处于 40%-60% 区间（边界分）。
- 同一文本下同一学生多题得分异常波动。

复核入口由 **练习系统 / 教师工作台** 负责，复核结果覆盖 AI 评分并更新画像。

## 11. 关键代码示例

### 11.1 能力画像更新

```java
@Service
public class ReadingAbilityProfileService {

    @Transactional
    public void updateProfileAfterSession(Long userId, ReadingExerciseSession session) {
        ReadingAbilityProfile profile = profileRepository.findByUserId(userId);
        List<ExerciseAnswer> answers = answerRepository.findBySessionId(session.getId());

        for (ExerciseAnswer answer : answers) {
            ReadingQuestion question = questionRepository.findById(answer.getQuestionId()).orElseThrow();
            double actualRate = answer.getEarnedScore().doubleValue() / question.getFullScore().doubleValue();
            double difficulty = question.getDifficultyScore() != null
                ? question.getDifficultyScore().doubleValue()
                : 50.0;

            for (QuestionKnowledgeMapping mapping : question.getKnowledgeMappings()) {
                double oldScore = profile.getDimensionScore(mapping.getAbilityDimension());
                double newScore = abilityScoreUpdater.updateDimension(
                    oldScore, difficulty, actualRate, mapping.getWeight(), profile.getGradeStage()
                );
                profile.setDimensionScore(mapping.getAbilityDimension(), newScore);
            }
        }

        profile.setOverallLevel(calculateOverallLevel(profile));
        profile.setColdStart(checkColdStart(profile));
        profileRepository.save(profile);
    }
}
```

### 11.2 推荐排序

```java
@Service
public class ReadingRecommendationService {

    public List<PassageRecommendation> recommend(Long userId, int topK) {
        ReadingAbilityProfile profile = profileRepository.findByUserId(userId);
        List<PassageCandidate> candidates = multiChannelRecall(profile);
        candidates = mmvRerank(candidates, Math.min(topK * 3, 30), 0.5);

        return candidates.stream()
            .sorted(Comparator.comparingDouble((PassageCandidate c) ->
                0.4 * difficultyFit(c, profile)
              + 0.3 * abilityGrowth(c, profile)
              + 0.2 * interest(c, profile)
              + 0.1 * freshness(c, profile)
            ).reversed())
            .limit(topK)
            .map(this::toRecommendation)
            .toList();
    }
}
```

## 14. 缓存与性能策略

### 14.1 缓存分层

采用 **本地缓存（Caffeine）+ 分布式缓存（Redis）** 两层：

| 数据类型 | 本地缓存 | Redis 缓存 | TTL |
|----------|----------|------------|-----|
| 已发布文本详情 | 是 | 是 | Redis 1h / 本地 10min |
| 题目列表（按文本） | 是 | 是 | Redis 2h / 本地 20min |
| 能力画像 | 否 | 是 | 30min |
| 推荐结果 | 否 | 是 | 学生维度 2h |
| 难度评估结果 | 否 | 是 | 24h |
| 热门推荐榜单 | 是 | 是 | Redis 1h / 本地 15min |

### 14.2 热点数据预热

- 启动时预热已发布文本、题目的 Redis 缓存。
- 每日凌晨 03:00 预热“热度推荐榜单”与“教材同步推荐”。
- 学生首次登录时异步预热其能力画像与个性化推荐。

### 14.3 查询优化

- 文本库查询使用组合索引 `(grade_stage, difficulty_level, status)`。
- 推荐召回通过 `IN` 与 `UNION ALL` 减少多次回表。
- 主观题批改使用异步线程池，避免阻塞提交接口。
- 能力画像更新采用批量合并：同一会话内多次维度更新合并为一次数据库写。

### 14.4 容量估算

| 数据项 | 估算数量 | 单条大小 | 总容量 |
|--------|----------|----------|--------|
| 阅读文本 | 10 万 | 50 KB | ~5 GB |
| 题目 | 300 万 | 5 KB | ~15 GB |
| 学生作答 | 1 亿/年 | 2 KB | ~200 GB/年 |
| 能力画像 | 500 万 | 2 KB | ~10 GB |
| 推荐缓存 | 500 万 | 1 KB | ~5 GB |
