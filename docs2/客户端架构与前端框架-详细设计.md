# 客户端架构与前端框架 - 详细设计

## 1. 概述

### 1.1 文档目标

本文档细化 PrimeTop 移动端客户端的技术架构、项目结构、核心框架选型、导航体系、状态管理、离线策略、分龄 UI 适配等基础设施设计，为前端/移动端开发人员提供可直接编码落地的技术方案。

### 1.2 技术选型决策

| 决策项 | 选型 | 理由 |
|--------|------|------|
| 跨平台框架 | **Flutter 3.x** | 双端一致性好、Dart 性能接近原生、丰富的 UI 组件、良好的 Canvas/自定义绘制能力 |
| 状态管理 | **Riverpod 2.x** | 编译期安全、支持异步/流式状态、可测试性好、Provider 的演进版 |
| 路由导航 | **GoRouter** | 声明式路由、深链接支持、嵌套路由、守卫机制完善 |
| 本地存储 | Hive + SharedPreferences | Hive 用于结构化离线数据，SharedPreferences 用于简单配置 |
| 网络层 | **Dio** | 拦截器机制强大、支持 SSE 流式响应、CancelToken、重试策略 |
| 国际化 | flutter_localizations + intl | Flutter 官方方案，后期可扩展多语言 |
| DI 框架 | Riverpod 内置 | 避免额外引入 GetIt 等，统一管理依赖 |

### 1.3 最低兼容

| 平台 | 最低版本 |
|------|----------|
| Android | API 24 (Android 7.0) |
| iOS | 13.0 |

## 4. 网络层设计

### 4.1 DioClient 封装

```dart
// core/network/dio_client.dart

class DioClient {
  late final Dio _dio;
  final Ref _ref;

  DioClient(this._ref) {
    _dio = Dio(
      BaseOptions(
        baseUrl: AppConstants.apiBaseUrl,
        connectTimeout: const Duration(seconds: 15),
        receiveTimeout: const Duration(seconds: 30),
        sendTimeout: const Duration(seconds: 15),
        headers: {
          'Content-Type': 'application/json',
          'Accept': 'application/json',
          'X-Platform': Platform.isIOS ? 'ios' : 'android',
          'X-App-Version': _ref.read(appVersionProvider),
        },
      ),
    );

    _dio.interceptors.addAll([
      AuthInterceptor(_ref),
      LogInterceptor(
        requestBody: true,
        responseBody: true,
        logPrint: (o) => logger.d(o),
      ),
    ]);
  }

  // ---------- 普通 REST 请求 ----------

  Future<ApiResult<T>> get<T>(
    String path, {
    Map<String, dynamic>? queryParameters,
    required T Function(Map<String, dynamic>) fromJson,
    CancelToken? cancelToken,
    bool useCache = false,
    Duration cacheDuration = const Duration(minutes: 5),
  }) async {
    try {
      // 缓存逻辑
      if (useCache) {
        final cached = await _ref.read(cacheManagerProvider).get(path, queryParameters);
        if (cached != null) {
          return ApiResult.success(fromJson(cached));
        }
      }

      final response = await _dio.get<dynamic>(
        path,
        queryParameters: queryParameters,
        cancelToken: cancelToken,
      );

      final data = _extractData(response);
      final result = fromJson(data);

      if (useCache) {
        await _ref.read(cacheManagerProvider).set(path, queryParameters, data, cacheDuration);
      }

      return ApiResult.success(result);
    } on DioException catch (e) {
      return ApiResult.failure(_handleDioError(e));
    } catch (e) {
      return ApiResult.failure(ApiError.unknown(e.toString()));
    }
  }

  Future<ApiResult<T>> post<T>(
    String path, {
    dynamic data,
    required T Function(Map<String, dynamic>) fromJson,
    CancelToken? cancelToken,
  }) async {
    try {
      final response = await _dio.post<dynamic>(path, data: data, cancelToken: cancelToken);
      return ApiResult.success(fromJson(_extractData(response)));
    } on DioException catch (e) {
      return ApiResult.failure(_handleDioError(e));
    } catch (e) {
      return ApiResult.failure(ApiError.unknown(e.toString()));
    }
  }

  // PUT, DELETE, PATCH 类似，省略...

  // ---------- SSE 流式请求 ----------

  /// 用于 AI 对话的 SSE 流式请求
  Stream<SseEvent> postSse(
    String path, {
    required Map<String, dynamic> data,
    CancelToken? cancelToken,
  }) {
    return _dio
        .post<ResponseBody>(
          path,
          data: data,
          cancelToken: cancelToken,
          options: Options(
            responseType: ResponseType.stream,
            headers: {'Accept': 'text/event-stream'},
          ),
        )
        .asStream()
        .asyncExpand((response) => _parseSseStream(response.data!));
  }

  // ---------- 内部方法 ----------

  Map<String, dynamic> _extractData(Response response) {
    final body = response.data as Map<String, dynamic>;
    final code = body['code'] as int? ?? 0;
    if (code != 0) {
      throw ApiException(code, body['message'] as String? ?? '未知错误');
    }
    return body['data'] as Map<String, dynamic>? ?? {};
  }

  ApiError _handleDioError(DioException e) {
    switch (e.type) {
      case DioExceptionType.connectionTimeout:
      case DioExceptionType.sendTimeout:
      case DioExceptionType.receiveTimeout:
        return const ApiError.network('网络连接超时，请检查网络后重试');
      case DioExceptionType.connectionError:
        return const ApiError.network('网络连接失败，请检查网络设置');
      case DioExceptionType.badResponse:
        final statusCode = e.response?.statusCode ?? 0;
        if (statusCode == 401) return const ApiError.unauthorized('登录已过期，请重新登录');
        if (statusCode == 429) return const ApiError.rateLimited('操作过于频繁，请稍后再试');
        return ApiError.server('服务器错误 ($statusCode)');
      case DioExceptionType.cancel:
        return const ApiError.cancelled('请求已取消');
      default:
        return ApiError.unknown(e.message ?? '未知错误');
    }
  }

  Stream<SseEvent> _parseSseStream(ResponseBody body) {
    return body.stream
        .transform(utf8.decoder)
        .transform(const LineSplitter())
        .transform(_SseParser());
  }
}
```

### 4.3 鉴权拦截器

```dart
// core/network/api_interceptor.dart

class AuthInterceptor extends Interceptor {
  final Ref _ref;

  AuthInterceptor(this._ref);

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) async {
    // 不需要鉴权的接口
    final publicPaths = ['/auth/login', '/auth/register', '/auth/sms-code', '/auth/refresh'];
    if (publicPaths.any((p) => options.path.endsWith(p))) {
      handler.next(options);
      return;
    }

    final tokenPair = _ref.read(authTokenProvider);
    if (tokenPair == null) {
      handler.reject(DioException(requestOptions: options, error: '未登录'));
      return;
    }

    // 检查 access token 是否即将过期 (提前 5 分钟刷新)
    if (tokenPair.accessTokenExpireAt.isBefore(
      DateTime.now().add(const Duration(minutes: 5)),
    )) {
      try {
        final newToken = await _refreshToken(tokenPair.refreshToken);
        _ref.read(authTokenProvider.notifier).state = newToken;
        options.headers['Authorization'] = 'Bearer ${newToken.accessToken}';
      } catch (_) {
        // 刷新失败，清除登录状态
        _ref.read(authStateProvider.notifier).logout();
        handler.reject(DioException(requestOptions: options, error: '登录已过期'));
        return;
      }
    } else {
      options.headers['Authorization'] = 'Bearer ${tokenPair.accessToken}';
    }

    // 附加设备信息
    final deviceId = _ref.read(deviceIdProvider);
    if (deviceId != null) {
      options.headers['X-Device-Id'] = deviceId;
    }

    handler.next(options);
  }

  @override
  void onError(DioException err, ErrorInterceptorHandler handler) async {
    if (err.response?.statusCode == 401) {
      // Token 过期，尝试刷新
      try {
        final tokenPair = _ref.read(authTokenProvider);
        if (tokenPair == null) throw Exception();
        final newToken = await _refreshToken(tokenPair.refreshToken);
        _ref.read(authTokenProvider.notifier).state = newToken;

        // 重试原请求
        final options = err.requestOptions;
        options.headers['Authorization'] = 'Bearer ${newToken.accessToken}';
        final response = await _ref.read(dioProvider).fetch(options);
        handler.resolve(response);
        return;
      } catch (_) {
        _ref.read(authStateProvider.notifier).logout();
      }
    }
    handler.next(err);
  }

  Future<TokenPair> _refreshToken(String refreshToken) async {
    final dio = _ref.read(dioProvider);
    final response = await dio.post<dynamic>(
      '/auth/refresh',
      data: {'refreshToken': refreshToken},
    );
    return TokenPair.fromJson(response.data['data'] as Map<String, dynamic>);
  }
}
```

```dart
// ---- Data: Repository ----
abstract class AuthRepository {
  Future<ApiResult<TokenPair>> loginWithSms(String phone, String code);
  Future<ApiResult<TokenPair>> loginWithThirdParty(ThirdPartyType type, String token);
  Future<ApiResult<void>> register(RegisterParams params);
  Future<ApiResult<UserProfile>> getProfile();
  Future<void> logout();
}

class AuthRepositoryImpl implements AuthRepository {
  final DioClient _client;
  final SecureStorage _secureStorage;

  AuthRepositoryImpl(this._client, this._secureStorage);

  @override
  Future<ApiResult<TokenPair>> loginWithSms(String phone, String code) {
    return _client.post('/auth/login/sms', data: {
      'phone': phone,
      'code': code,
    }, fromJson: TokenPair.fromJson);
  }

  @override
  Future<ApiResult<UserProfile>> getProfile() {
    return _client.get('/user/profile', fromJson: UserProfile.fromJson);
  }

  @override
  Future<void> logout() async {
    await _secureStorage.delete('auth_tokens');
  }
}

// ---- Presentation: Provider ----

// Repository Provider
@riverpod
AuthRepository authRepository(Ref ref) {
  return AuthRepositoryImpl(ref.watch(dioClientProvider), ref.watch(secureStorageProvider));
}

// 异步数据 Provider
@riverpod
class AuthState extends _$AuthState {
  @override
  FutureOr<AuthStateData> build() async {
    // 启动时从本地恢复 token
    final tokens = await ref.read(authRepositoryProvider).restoreTokens();
    if (tokens == null) return const AuthStateData.unauthenticated();

    final profileResult = await ref.read(authRepositoryProvider).getProfile();
    return profileResult.when(
      success: (profile) => AuthStateData.authenticated(profile: profile, tokens: tokens),
      failure: (_) => const AuthStateData.unauthenticated(),
    );
  }

  Future<void> loginWithSms(String phone, String code) async {
    state = const AsyncLoading();
    state = await AsyncValue.guard(() async {
      final repo = ref.read(authRepositoryProvider);
      final tokenResult = await repo.loginWithSms(phone, code);
      return tokenResult.when(
        success: (tokens) async {
          await repo.saveTokens(tokens);
          final profileResult = await repo.getProfile();
          return profileResult.when(
            success: (profile) => AuthStateData.authenticated(profile: profile, tokens: tokens),
            failure: (e) => throw Exception('获取用户信息失败: ${e.message}'),
          );
        },
        failure: (e) => throw Exception('登录失败: ${e.message}'),
      );
    });
  }

  Future<void> logout() async {
    await ref.read(authRepositoryProvider).logout();
    state = const AsyncData(AuthStateData.unauthenticated());
  }
}

// ---- UI 消费 ----
class LoginPage extends ConsumerWidget {

  Widget build(BuildContext context, WidgetRef ref) {

}
```

```dart
// shared/models/page_state.dart

/// 通用页面状态 — 避免每个页面重复写 loading/error/data 逻辑
@freezed
sealed class PageState<T> with _$PageState<T> {
  const factory PageState.initial() = PageInitial<T>;
  const factory PageState.loading() = PageLoading<T>;
  const factory PageState.data(T data) = PageData<T>;
  const factory PageState.error(String message) = PageError<T>;
}

/// 典型用法：Provider 返回 PageState，Widget 统一分发
extension PageStateWidgetBuilder<T> on PageState<T> {
  Widget when({
    required Widget Function(T data) data,
    Widget Function()? loading,
    Widget Function(String message)? error,
    Widget Function()? initial,
  }) {
    return switch (this) {
      PageInitial<T>() => initial?.call() ?? const SizedBox.shrink(),
      PageLoading<T>() => loading?.call() ?? const Center(child: CircularProgressIndicator()),
      PageData<T>(:final data d) => data(d),
      PageError<T>(:final message) => error?.call(message) ?? ErrorView(message: message),
    };
  }
}
```

### 9.2 离线队列机制

```dart
// core/storage/offline_queue.dart

/// 离线操作队列 — 网络恢复后自动重试
@riverpod
class OfflineQueue extends _$OfflineQueue {
  late final Box<PendingAction> _box;

  @override
  Future<List<PendingAction>> build() async {
    _box = await Hive.openBox<PendingAction>('offline_queue');
    return _box.values.toList();
  }

  /// 入队操作
  Future<void> enqueue(PendingAction action) async {
    await _box.put(action.id, action);
    ref.invalidateSelf();
  }

  /// 网络恢复后刷新队列
  Future<void> flush() async {
    final connectivity = ref.read(connectivityProvider);
    if (connectivity != ConnectivityStatus.online) return;

    final pending = _box.values.toList()
      ..sort((a, b) => a.createdAt.compareTo(b.createdAt));

    for (final action in pending) {
      try {
        await _executeAction(action);
        await _box.delete(action.id);
      } catch (e) {
        action.retryCount++;
        if (action.retryCount >= 3) {
          await _box.delete(action.id); // 超过重试上限，丢弃
        } else {
          await _box.put(action.id, action);
        }
      }
    }
    ref.invalidateSelf();
  }

  Future<void> _executeAction(PendingAction action) async {
    final client = ref.read(dioClientProvider);
    switch (action.type) {
      case 'ai.message':
        await client.post('/ai/conversations/${action.params['conversationId']}/messages',
            data: action.params, fromJson: (_) => <String, dynamic>{});
      case 'mistake.add':
        await client.post('/mistakes',
            data: action.params, fromJson: (_) => <String, dynamic>{});
      case 'study.record':
        await client.post('/study/records',
            data: action.params, fromJson: (_) => <String, dynamic>{});
      default:
        logger.w('Unknown offline action type: ${action.type}');
    }
  }
}

@HiveType(typeId: 10)
@freezed
class PendingAction with _$PendingAction {
  @HiveField(0)
  const factory PendingAction({
    required String id,
    required String type,
    required Map<String, dynamic> params,
    required DateTime createdAt,
    @Default(0) int retryCount,
  }) = _PendingAction;
}
```

```dart
@riverpod
class ConnectivityState extends _$ConnectivityState {
  StreamSubscription? _sub;

  @override
  ConnectivityStatus build() {
    final connectivity = Connectivity();
    _sub = connectivity.onConnectivityChanged.listen((results) {
      final status = _mapResult(results);
      if (state != status) {
        state = status;
        // 网络恢复时触发离线队列刷新
        if (status == ConnectivityStatus.online) {
          ref.read(offlineQueueProvider.notifier).flush();
        }
      }
    });
    ref.onDispose(() => _sub?.cancel());

    // 初始状态
    return ConnectivityStatus.unknown;
  }

  ConnectivityStatus _mapResult(List<ConnectivityResult> results) {
    if (results.contains(ConnectivityResult.wifi) ||
        results.contains(ConnectivityResult.mobile)) {
      return ConnectivityStatus.online;
    }
    if (results.contains(ConnectivityResult.none)) {
      return ConnectivityStatus.offline;
    }
    return ConnectivityStatus.unknown;
  }
}
```

```dart
    var compressed = source;

    for (var i = 0; i < 5; i++) {
      final result = await FlutterImageCompress.compressWithFile(
        source.absolute.path,
        targetPath: targetPath,
        quality: quality,
        minWidth: 1200,
        minHeight: 1200,
        rotate: 0,
      );

      if (result == null) break;
      final sizeKB = result.length / 1024;
      if (sizeKB <= targetKB) {
        compressed = File(targetPath);
        break;
      }
      quality = (quality * 0.7).round();
    }

    return compressed;
  }
}
```

```dart
    } else {
      context.go(AppRoutes.login);
```

### 16.1 命名约定

| 类型 | 约定 | 示例 |
|------|------|------|
| 文件名 | snake_case | `ai_conversation_page.dart` |
| 类名 | PascalCase | `AiConversationPage` |
| Provider | camelCase + Provider 后缀 | `authStateProvider` |
| 路由常量 | camelCase | `AppRoutes.aiConversation` |
| 资源文件 | snake_case + @2x/@3x | `ic_camera@2x.png` |

### 16.2 目录约定

- 每个 feature 内部遵循 `data/ → domain/ → presentation/` 三层架构
- Repository 定义在 data 层，UseCase 定义在 domain 层
- Provider 和 Widget 定义在 presentation 层
- 跨 feature 共享的 Widget 放在 `shared/widgets/`
- 跨 feature 共享的 Model 放在 `shared/models/`

### 16.3 Git 分支策略

| 分支 | 用途 |
|------|------|
| `main` | 生产发布分支 |
| `develop` | 开发集成分支 |
| `feature/xxx` | 功能开发分支 |
| `hotfix/xxx` | 紧急修复分支 |

Commit Message 格式: `type(scope): description`
- type: feat, fix, refactor, style, docs, test, chore
