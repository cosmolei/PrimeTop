# 管理后台 - 内容供应商管理与合作伙伴运营工作台 详细设计

## 1. 概述

### 1.1 模块定位

内容供应商管理与合作伙伴运营工作台是 PrimeTop 管理后台的内容生态管控核心模块，面向平台内容运营人员、商务合作经理、法务合规人员和财务人员，提供内容供应商全生命周期管理、合作合同管控、内容交付监控、质量评估跟踪、版权到期预警、结算对账审批与供应商分级运营能力。该工作台是连接外部内容提供方（出版社、教辅机构、题库厂商、独立教研团队）与平台内部内容生产流水线之间的统一管理中枢。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 供应商全生命周期管理 | 从合作洽谈到上线、运营、续约/终止的完整流程管控 |
| 合同与版权精细管控 | 授权范围、有效期、分成比例、排他条款等结构化管理 |
| 交付质量可视化 | 供应商内容交付的批次、数量、通过率、质量评分一目了然 |
| 结算对账自动化 | 版权费自动核算、对账确认、付款审批全流程在线化 |
| 风险预警主动化 | 版权到期、质量下滑、交付延迟等风险智能预警 |
| 合作伙伴分级运营 | 基于交付质量、内容表现、合作深度对供应商智能分级 |

### 1.3 适用范围

- **商务合作经理**：管理合作渠道、推进供应商接入、维护合作关系。
- **内容运营人员**：监控内容交付进度、审核内容质量、管理上线节奏。
- **法务合规人员**：审核合同条款、管控授权范围、处理版权纠纷。
- **财务人员**：核对结算数据、审批付款、跟踪收款与发票。
- **平台管理员**：审批供应商变更、处理重大合作决策、查看综合运营数据。

## 2. 数据结构定义

### 2.1 供应商扩展信息表 `provider_profile_ext`

> 在 `content_provider` 基础表上扩展运营管理所需的商务与分级信息。

```sql
CREATE TABLE provider_profile_ext (
    id                      BIGINT PRIMARY KEY AUTO_INCREMENT,
    provider_id             BIGINT NOT NULL UNIQUE COMMENT '关联 content_provider.id',
    provider_code           VARCHAR(64) NOT NULL COMMENT '冗余编码，便于查询',
    
    -- 商务信息
    cooperation_level       TINYINT NOT NULL DEFAULT 1 COMMENT '合作等级: 1=普通 2=优选 3=战略 4=独家',
    cooperation_start_date  DATE NOT NULL COMMENT '首次合作日期',
    last_review_date        DATE COMMENT '最近评估日期',
    next_review_date        DATE COMMENT '下次评估日期',
    assigned_bd_user_id     BIGINT COMMENT '负责商务经理用户ID',
    
    -- 分级评分（由质量评估引擎定期写入）
    quality_score           DECIMAL(4,2) DEFAULT 0 COMMENT '内容质量综合评分(0-100)',
    delivery_score          DECIMAL(4,2) DEFAULT 0 COMMENT '交付准时率评分(0-100)',
    usage_score             DECIMAL(4,2) DEFAULT 0 COMMENT '内容使用效果评分(0-100)',
    overall_score           DECIMAL(4,2) DEFAULT 0 COMMENT '综合评分(加权)',
    score_updated_at        DATETIME COMMENT '评分更新时间',
    
    -- 运营标签
    tags                    JSON COMMENT '运营标签: ["重点维护","高音视频占比","待续约"]',
    
    -- 统计快照（由定时任务每日更新）
    total_content_count     INT DEFAULT 0 COMMENT '累计交付内容数',
    online_content_count    INT DEFAULT 0 COMMENT '当前在线内容数',
    total_settlement_amount DECIMAL(14,2) DEFAULT 0 COMMENT '累计结算金额',
    last_delivery_date      DATE COMMENT '最近交付日期',
    
    -- 风险标记
    risk_level              TINYINT DEFAULT 0 COMMENT '风险等级: 0=正常 1=低 2=中 3=高',
    risk_reasons            JSON COMMENT '风险原因: ["版权30天内到期","质量连续下降"]',
    risk_updated_at         DATETIME COMMENT '风险更新时间',
    
    created_at              DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at              DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_cooperation_level (cooperation_level),
    INDEX idx_overall_score (overall_score),
    INDEX idx_risk_level (risk_level),
    INDEX idx_next_review (next_review_date),
    INDEX idx_bd_user (assigned_bd_user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='供应商扩展运营信息表';
```

### 2.3 内容交付批次运营表 `provider_delivery_overview`

```sql
CREATE TABLE provider_delivery_overview (
    id                      BIGINT PRIMARY KEY AUTO_INCREMENT,
    provider_id             BIGINT NOT NULL COMMENT '供应商ID',
    batch_id                BIGINT NOT NULL COMMENT '交付批次ID（关联 content_import_record）',
    batch_no                VARCHAR(64) NOT NULL COMMENT '批次编号',
    
    -- 交付内容概览
    content_type            VARCHAR(32) NOT NULL COMMENT '内容类型: question/material/video/audio/document',
    subject_codes           JSON COMMENT '涉及学科: ["math","physics"]',
    grade_range             VARCHAR(32) COMMENT '年级范围: "7-9"',
    total_items             INT NOT NULL DEFAULT 0 COMMENT '交付内容总数',
    
    -- 质量检测结果
    auto_check_passed       INT DEFAULT 0 COMMENT '自动质检通过数',
    auto_check_failed       INT DEFAULT 0 COMMENT '自动质检失败数',
    manual_review_passed    INT DEFAULT 0 COMMENT '人工审核通过数',
    manual_review_rejected  INT DEFAULT 0 COMMENT '人工审核驳回数',
    online_count            INT DEFAULT 0 COMMENT '最终上线数',
    
    pass_rate               DECIMAL(5,2) GENERATED ALWAYS AS (
        CASE WHEN total_items > 0 
        THEN ROUND(online_count / total_items * 100, 2) 
        ELSE 0 END
    ) STORED COMMENT '上线通过率(%)',
    
    -- 时间节点
    delivered_at            DATETIME COMMENT '交付时间',
    first_pass_at           DATETIME COMMENT '首次通过质检时间',
    all_online_at           DATETIME COMMENT '全部上线完成时间',
    
    -- 状态
    delivery_status         TINYINT NOT NULL DEFAULT 0 COMMENT '0=待交付 1=已交付待质检 2=质检中 3=待人工审 4=审核中 5=已上线 6=已退回 7=已取消',
    exception_flag          TINYINT DEFAULT 0 COMMENT '异常标记: 0=正常 1=质检通过率低 2=交付延迟 3=内容格式问题',
    exception_memo          VARCHAR(500) COMMENT '异常说明',
    
    created_at              DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at              DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_provider_status (provider_id, delivery_status),
    INDEX idx_delivered_at (delivered_at),
    INDEX idx_exception (exception_flag),
    INDEX idx_batch (batch_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='供应商交付批次运营概览表';
```

### 3.4 供应商状态变更

```
POST /api/admin/provider/{providerId}/status
```

**请求体：**

```json
{
  "targetStatus": 2,
  "reason": "连续2个批次质检通过率低于60%，暂停合作冻结处理",
  "evidenceUrls": [
    "https://oss.primetop.com/files/providers/quality-report-202608.pdf"
  ]
}
```

**状态流转规则：**

```text
    ┌────────────────────────────────────────────────────────┐
    │                                                        │
    ▼                                                        │
 待审核(0) ──审核通过──► 正常(1)                            │
    │                       │                                │
    │                       ├── 冻结 ──► 冻结(2) ──解冻──► 正常(1)
    │                       │                                │
    │                       └── 终止 ──► 终止(3)             │
    │                                                        │
    └── 审核驳回 ──► 终止(3)                                 │
    │                                                        │
    └────────────────────────────────────────────────────────┘
```

**校验规则：**

| 当前状态 | 可变更到 | 附加校验 |
| --- | --- | --- |
| 0(待审核) | 1(正常) | 需上传资质审核通过记录 |
| 0(待审核) | 3(终止) | 驳回需填写原因 |
| 1(正常) | 2(冻结) | 需填写冻结原因，影响在线内容展示策略 |
| 2(冻结) | 1(正常) | 需商务经理审批，解冻后恢复内容分发 |
| 1(正常) | 3(终止) | 需确认无在途合同、无待结算款项 |
| 2(冻结) | 3(终止) | 需法务确认终止协议 |

### 6.1 供应商列表查询服务（Java/Spring Boot）

```java
@Service
@RequiredArgsConstructor
public class ProviderMgmtService {

    private final ProviderProfileExtMapper providerExtMapper;
    private final ContentProviderMapper providerMapper;
    private final ProviderContractMapper contractMapper;
    private final ProviderOperationLogMapper logMapper;

    /**
     * 分页查询供应商列表（联表查询基础信息 + 扩展运营信息）
     */
    public PageResult<ProviderListVO> queryProviderList(ProviderListQuery query) {
        // 1. 构建动态查询条件
        LambdaQueryWrapper<ContentProvider> wrapper = new LambdaQueryWrapper<>();
        
        if (StringUtils.isNotBlank(query.getKeyword())) {
            wrapper.and(w -> w.like(ContentProvider::getProviderName, query.getKeyword())
                    .or().eq(ContentProvider::getProviderCode, query.getKeyword()));
        }
        if (query.getProviderType() != null) {
            wrapper.eq(ContentProvider::getProviderType, query.getProviderType());
        }
        if (query.getStatus() != null) {
            wrapper.eq(ContentProvider::getStatus, query.getStatus());
        }
        
        // 2. 分页查询基础信息
        Page<ContentProvider> page = providerMapper.selectPage(
            new Page<>(query.getPage(), query.getPageSize()), wrapper);
        
        if (page.getRecords().isEmpty()) {
            return PageResult.empty(query.getPage(), query.getPageSize());
        }
        
        // 3. 批量查询扩展信息
        List<Long> providerIds = page.getRecords().stream()
                .map(ContentProvider::getId)
                .collect(Collectors.toList());
        
        Map<Long, ProviderProfileExt> extMap = providerExtMapper
                .selectBatchIds(providerIds)
                .stream()
                .collect(Collectors.toMap(ProviderProfileExt::getProviderId, Function.identity()));
        
        // 4. 批量查询有效合同信息
        Map<Long, List<ProviderContract>> contractMap = contractMapper
                .selectActiveContractsByProviderIds(providerIds)
                .stream()
                .collect(Collectors.groupingBy(ProviderContract::getProviderId));
        
        // 5. 组装 VO
        List<ProviderListVO> voList = page.getRecords().stream().map(provider -> {
            ProviderListVO vo = new ProviderListVO();
            vo.setProviderId(provider.getId());
            vo.setProviderCode(provider.getProviderCode());
            vo.setProviderName(provider.getProviderName());
            vo.setProviderType(provider.getProviderType());
            vo.setStatus(provider.getStatus());
            
            ProviderProfileExt ext = extMap.get(provider.getId());
            if (ext != null) {
                vo.setCooperationLevel(ext.getCooperationLevel());
                vo.setOverallScore(ext.getOverallScore());
                vo.setGradeLevel(calculateGrade(ext.getOverallScore()));
                vo.setRiskLevel(ext.getRiskLevel());
                vo.setTotalContentCount(ext.getTotalContentCount());
                vo.setOnlineContentCount(ext.getOnlineContentCount());
                vo.setTotalSettlementAmount(ext.getTotalSettlementAmount());
                vo.setLastDeliveryDate(ext.getLastDeliveryDate());
                vo.setTags(ext.getTags());
            }
            
            List<ProviderContract> contracts = contractMap.get(provider.getId());
            if (contracts != null) {
                vo.setContracts(contracts.stream()
                        .map(this::toContractBriefVO)
                        .collect(Collectors.toList()));
            }
            
            return vo;
        }).collect(Collectors.toList());
        
        // 6. 排序（内存排序，因为涉及多表字段）
        applySort(voList, query.getSortField(), query.getSortOrder());
        
        // 7. 附加风险标签提示
        voList.forEach(this::appendRiskHint);
        
        return PageResult.of(voList, page.getTotal(), query.getPage(), query.getPageSize());
    }
    
    /**
     * 根据综合评分计算等级
     */
    private int calculateGrade(BigDecimal overallScore) {
        if (overallScore == null) return 1;
        double score = overallScore.doubleValue();
        if (score >= 90) return 5;  // SS
        if (score >= 80) return 4;  // S
        if (score >= 70) return 3;  // A
        if (score >= 60) return 2;  // B
        return 1;                        // C
    }
    
    /**
     * 附加风险提示文案
     */
    private void appendRiskHint(ProviderListVO vo) {
        if (vo.getRiskLevel() == null || vo.getRiskLevel() == 0) return;
        
        List<String> hints = new ArrayList<>();
        if (CollectionUtils.isNotEmpty(vo.getContracts())) {
            for (ContractBriefVO contract : vo.getContracts()) {
                long daysToExpiry = ChronoUnit.DAYS.between(
                    LocalDate.now(), contract.getEndDate());
                if (daysToExpiry <= 30) {
                    hints.add(String.format("合同%d天后到期", daysToExpiry));
                }
            }
        }
        vo.setRiskHint(String.join("；", hints));
    }
}
```

### 6.2 合同审批状态机（Spring State Machine）

```java
@Configuration
@EnableStateMachineFactory
public class ContractApprovalStateMachineConfig 
        extends EnumStateMachineConfigurerAdapter<ContractStatus, ContractEvent> {
    
    @Override
    public void configure(StateMachineStateConfigurer<ContractStatus, ContractEvent> states) 
            throws Exception {
        states
            .withStates()
            .initial(ContractStatus.DRAFT)
            .states(EnumSet.allOf(ContractStatus.class))
            .end(ContractStatus.APPROVED)
            .end(ContractStatus.REJECTED);
    }
    
    @Override
    public void configure(StateMachineTransitionConfigurer<ContractStatus, ContractEvent> transitions) 
            throws Exception {
        transitions
            // DRAFT -> PENDING_LEGAL
            .withExternal()
                .source(ContractStatus.DRAFT)
                .target(ContractStatus.PENDING_LEGAL)
                .event(ContractEvent.SUBMIT)
                .action(submitAction())
            .and()
            // PENDING_LEGAL -> PENDING_FINANCE (法务通过)
            .withExternal()
                .source(ContractStatus.PENDING_LEGAL)
                .target(ContractStatus.PENDING_FINANCE)
                .event(ContractEvent.LEGAL_APPROVE)
                .action(legalApproveAction())
            .and()
            // PENDING_LEGAL -> DRAFT (有条件通过，退回修改)
            .withExternal()
                .source(ContractStatus.PENDING_LEGAL)
                .target(ContractStatus.DRAFT)
                .event(ContractEvent.LEGAL_CONDITIONAL)
                .action(conditionalReviseAction())
            .and()
            // PENDING_LEGAL -> REJECTED (法务驳回)
            .withExternal()
                .source(ContractStatus.PENDING_LEGAL)
                .target(ContractStatus.REJECTED)
                .event(ContractEvent.LEGAL_REJECT)
            .and()
            // PENDING_FINANCE -> PENDING_EXECUTIVE / APPROVED
            .withExternal()
                .source(ContractStatus.PENDING_FINANCE)
                .target(ContractStatus.PENDING_EXECUTIVE)
                .event(ContractEvent.FINANCE_APPROVE)
                .guard(needsExecutiveApproval())
                .action(financeApproveAction())
            .and()
            .withExternal()
                .source(ContractStatus.PENDING_FINANCE)
                .target(ContractStatus.APPROVED)
                .event(ContractEvent.FINANCE_APPROVE)
                .guard(noExecutiveApprovalNeeded())
                .action(contractActivateAction())
            .and()
            // PENDING_EXECUTIVE -> APPROVED
            .withExternal()
                .source(ContractStatus.PENDING_EXECUTIVE)
                .target(ContractStatus.APPROVED)
                .event(ContractEvent.EXECUTIVE_APPROVE)
                .action(contractActivateAction())
            .and()
            .withExternal()
                .source(ContractStatus.PENDING_EXECUTIVE)
                .target(ContractStatus.REJECTED)
                .event(ContractEvent.EXECUTIVE_REJECT);
    }
    
    /**
     * Guard: 判断是否需要高管审批
     */
    private Guard<ContractStatus, ContractEvent> needsExecutiveApproval() {
        return context -> {
            Long contractId = context.getMessageHeader("contractId", Long.class);
            ProviderContract contract = contractMapper.selectById(contractId);
            ProviderContractMgmt mgmt = contractMgmtMapper.selectByContractId(contractId);
            
            // 满足任一条件即需高管审批
            return mgmt.getAnnualQuotaAmount() != null 
                    && mgmt.getAnnualQuotaAmount().compareTo(new BigDecimal("1000000")) >= 0
                || contract.getRevenueShareRate() != null
                    && contract.getRevenueShareRate().compareTo(new BigDecimal("0.40")) >= 0
                || mgmt.getAutoRenew() == 1;
        };
    }
}
```

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class ProviderRiskScanTask {
    
    private final ProviderContractMapper contractMapper;
    private final ProviderProfileExtMapper extMapper;
    private final ContentProviderMapper providerMapper;
    private final ProviderDeliveryOverviewMapper deliveryMapper;
    private final NotificationService notificationService;
    
    /**
     * 每日凌晨 02:00 执行风险扫描
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void executeRiskScan() {
        log.info("[供应商风险扫描] 开始执行...");
        
        int scanned = 0;
        int alerted = 0;
        
        // 1. 合同到期扫描
        List<ProviderContract> expiringContracts = contractMapper
                .selectExpiringContracts(90); // 90天内到期
        
        for (ProviderContract contract : expiringContracts) {
            scanned++;
            long daysToExpiry = ChronoUnit.DAYS.between(
                LocalDate.now(), contract.getEndDate());
            
            int riskLevel = daysToExpiry <= 30 ? 3 : daysToExpiry <= 60 ? 2 : 1;
            String alertType = "CONTRACT_EXPIRY";
            
            // 更新供应商风险等级
            updateProviderRisk(contract.getProviderId(), riskLevel, 
                    alertType, daysToExpiry);
            
            // 高风险发送通知
            if (riskLevel >= 2) {
                ProviderProfileExt ext = extMapper
                        .selectByProviderId(contract.getProviderId());
                ContentProvider provider = providerMapper
                        .selectById(contract.getProviderId());
                
                // 统计影响的内容数量
                int affectedCount = countAffectedContent(
                    contract.getProviderId(), contract.getId());
                
                AlertNotification notification = AlertNotification.builder()
                    .title(String.format("供应商合同%d天后到期", daysToExpiry))
                    .content(String.format(
                        "供应商「%s」的合同(%s)将于%s到期(剩余%d天)。" +
                        "该合同关联%d条在线内容，请及时处理。",
                        provider.getProviderName(),
                        contract.getContractNo(),
                        contract.getEndDate(),
                        daysToExpiry,
                        affectedCount))
                    .riskLevel(riskLevel)
                    .providerId(contract.getProviderId())
                    .contractId(contract.getId())
                    .bdUserId(ext != null ? ext.getAssignedBdUserId() : null)
                    .build();
                
                notificationService.sendProviderAlert(notification);
                alerted++;
            }
        }
        
        // 2. 质量下滑扫描
        List<Long> activeProviderIds = providerMapper.selectActiveProviderIds();
        for (Long providerId : activeProviderIds) {
            List<ProviderDeliveryOverview> recentBatches = deliveryMapper
                    .selectRecentBatches(providerId, 3); // 最近3个批次
            
            if (recentBatches.size() >= 3) {
                double avgPassRate = recentBatches.stream()
                        .mapToDouble(b -> b.getPassRate().doubleValue())
                        .average().orElse(100);
                
                if (avgPassRate < 60) {
                    updateProviderRisk(providerId, 3, "QUALITY_DECLINE", 
                            String.format("最近3批次平均通过率%.1f%%", avgPassRate));
                    alerted++;
                } else if (avgPassRate < 70) {
                    updateProviderRisk(providerId, 2, "QUALITY_DECLINE",
                            String.format("最近3批次平均通过率%.1f%%", avgPassRate));
                    alerted++;
                }
            }
        }
        
        // 3. 交付延迟扫描
        List<ProviderDeliveryOverview> delayedDeliveries = deliveryMapper
                .selectDelayedDeliveries(3); // 延迟超过3天
        for (ProviderDeliveryOverview delivery : delayedDeliveries) {
            updateProviderRisk(delivery.getProviderId(), 1, "DELAY",
                    String.format("批次%s交付延迟", delivery.getBatchNo()));
        }
        
        log.info("[供应商风险扫描] 完成。扫描合同:{}, 产生预警:{}",
                scanned, alerted);
    }
    
    private void updateProviderRisk(Long providerId, int riskLevel, 
            String riskType, Object detail) {
        ProviderProfileExt ext = extMapper.selectByProviderId(providerId);
        if (ext == null) return;
        
        // 只升级不降级（降级由定期评估任务处理）
        int currentRisk = ext.getRiskLevel() != null ? ext.getRiskLevel() : 0;
        if (riskLevel <= currentRisk) return;
        
        // 更新风险信息
        List<String> reasons = ext.getRiskReasons() != null 
                ? new ArrayList<>(ext.getRiskReasons()) 
                : new ArrayList<>();
        
        String reasonText = riskType.equals("CONTRACT_EXPIRY") 
                ? "合同" + detail + "天后到期"
                : riskType.equals("QUALITY_DECLINE")
                ? "质量下滑: " + detail
                : "交付延迟: " + detail;
        
        if (!reasons.contains(reasonText)) {
            reasons.add(reasonText);
        }
        
        extMapper.updateRisk(providerId, riskLevel, 
                JSON.toJSONString(reasons), LocalDateTime.now());
    }
}
```

```java
@Service
@RequiredArgsConstructor
public class ProviderScoringService {
    
    private final ProviderProfileExtMapper extMapper;
    private final ProviderScoreHistoryMapper scoreHistoryMapper;
    private final ProviderDeliveryOverviewMapper deliveryMapper;
    private final QuestionMapper questionMapper;
    private final ContentUsageStatMapper usageStatMapper;
    
    /**
     * 定期评分任务（每月1号执行）
     * 汇总上月数据，计算供应商各维度评分
     */
    @Scheduled(cron = "0 0 3 1 * ?")
    public void calculateMonthlyScores() {
        String period = LocalDate.now().minusMonths(1)
                .format(DateTimeFormatter.ofPattern("yyyy-MM"));
        
        List<Long> activeProviderIds = extMapper.selectActiveProviderIds();
        
        for (Long providerId : activeProviderIds) {
            try {
                ProviderScore score = calculateScore(providerId, period);
                saveScore(score);
                updateProviderExtScore(providerId, score);
            } catch (Exception e) {
                log.error("供应商{}评分计算失败", providerId, e);
            }
        }
    }
    
    private ProviderScore calculateScore(Long providerId, String period) {
        // 维度1: 内容质量（30%）- 基于质检通过率
        BigDecimal avgPassRate = deliveryMapper.calculateAvgPassRate(
                providerId, period);
        BigDecimal qualityScore = avgPassRate; // 直接使用通过率作为质量评分
        
        // 维度2: 交付表现（20%）- 基于准时交付率
        BigDecimal onTimeRate = deliveryMapper.calculateOnTimeRate(
                providerId, period);
        BigDecimal deliveryScore = onTimeRate;
        
        // 维度3: 内容使用效果（30%）- 基于用户评分和使用量
        BigDecimal avgUserRating = usageStatMapper.calculateAvgContentRating(
                providerId, period); // 0-5分，需转换为百分制
        BigDecimal usageScore = avgUserRating.multiply(new BigDecimal("20"));
        
        // 维度4: 配合度（20%）- 基于沟通响应速度、问题修复及时性
        BigDecimal cooperationScore = calculateCooperationScore(providerId, period);
        
        // 加权综合评分
        BigDecimal overallScore = qualityScore.multiply(new BigDecimal("0.30"))
                .add(deliveryScore.multiply(new BigDecimal("0.20")))
                .add(usageScore.multiply(new BigDecimal("0.30")))
                .add(cooperationScore.multiply(new BigDecimal("0.20")))
                .setScale(2, RoundingMode.HALF_UP);
        
        return ProviderScore.builder()
                .providerId(providerId)
                .period(period)
                .qualityScore(qualityScore)
                .deliveryScore(deliveryScore)
                .usageScore(usageScore)
                .cooperationScore(cooperationScore)
                .overallScore(overallScore)
                .gradeLevel(calculateGradeLevel(overallScore))
                .build();
    }
    
    private int calculateGradeLevel(BigDecimal score) {
        double s = score.doubleValue();
        if (s >= 90) return 5; // SS
        if (s >= 80) return 4; // S
        if (s >= 70) return 3; // A
        if (s >= 60) return 2; // B
        return 1;              // C
    }
}
```

| PROV_006 | 400 | 供应商被冻结，无法创建新交付批次 | 提示先解冻 |

| PROV_008 | 400 | 合同已过期，无法续操作 | 需新建合同而非续期 |
| PROV_009 | 500 | 评分计算数据不完整 | 跳过本期评分，记录异常日志 |
| PROV_010 | 400 | 批量操作超过最大数量(50) | 限制单次操作上限 |

### 8.2 异常场景处理

**场景1：冻结供应商时有在线内容**

```java
public void freezeProvider(Long providerId, String reason) {
    // 1. 检查是否有进行中的交付批次
    int pendingDeliveries = deliveryMapper.countByProviderAndStatus(
            providerId, DeliveryStatus.PENDING_REVIEW);
    if (pendingDeliveries > 0) {
        throw new BizException("PROV_010", 
            String.format("供应商有%d个待审核交付批次，请先处理后再冻结", 
                    pendingDeliveries));
    }
    
    // 2. 检查在线内容数量，提示运营
    int onlineCount = extMapper.getOnlineContentCount(providerId);
    if (onlineCount > 100) {
        // 记录需关注的下线影响，但不阻止冻结
        log.warn("[供应商冻结] 供应商{}有{}条在线内容，冻结后将停止新分发", 
                providerId, onlineCount);
    }
    
    // 3. 执行冻结
    providerMapper.updateStatus(providerId, ProviderStatus.FROZEN);
    
    // 4. 停止该供应商的内容分发调度
    contentDistributionService.pauseProviderDistribution(providerId);
    
    // 5. 记录操作日志
    logService.recordProviderLog(providerId, "STATUS_CHANGE", 
            String.format("冻结原因: %s, 影响在线内容: %d条", reason, onlineCount));
}
```

```java
@Scheduled(cron = "0 0 10 * * ?") // 每天上午10点检查
public void checkApprovalTimeout() {
    List<ProviderContractMgmt> pendingApprovals = 
            contractMgmtMapper.selectPendingApprovals();
    
    for (ProviderContractMgmt approval : pendingApprovals) {
        long hoursPending = Duration.between(
            approval.getSubmittedAt(), LocalDateTime.now()).toHours();
        
        // 超过24小时未审批，发送提醒
        if (hoursPending > 24 && hoursPending % 24 == 0) {
            Long reviewerId = getCurrentReviewerId(approval);
            notificationService.sendReminder(reviewerId, 
                String.format("合同%s待您审批，已等待%d小时", 
                    approval.getContractId(), hoursPending));
        }
        
        // 超过72小时自动升级
        if (hoursPending > 72) {
            escalateApproval(approval);
        }
    }
}
```

```java
@DataPermission
public class ProviderDataScope {
    
    /**
     * 数据可见范围规则:
     * 
     * 1. 平台管理员: 可见所有供应商
     * 2. 商务经理: 仅可见自己负责的供应商 (assigned_bd_user_id = currentUserId)
     * 3. 内容运营: 可见所有正常状态的供应商（按需扩展）
     * 4. 法务/财务: 仅可见有待审批任务的供应商 + 已审批通过的供应商
     */
    public String buildDataScopeFilter(Long currentUserId, String role) {
        switch (role) {
            case "PLATFORM_ADMIN":
                return ""; // 无限制
            case "BD_MANAGER":
                return String.format("AND ext.assigned_bd_user_id = %d", currentUserId);
            case "CONTENT_OPS":
                return "AND p.status IN (0, 1)"; // 待审核 + 正常
            case "LEGAL":
            case "FINANCE":
                return String.format(
                    "AND (cmg.approval_status IN (1,2,3) " +  // 有待审批任务
                    "  OR cmg.approval_status = 4)",           // 已通过
                    currentUserId);
            default:
                return "AND 1=0"; // 默认不可见
        }
    }
}
```

```java
@Service
@RequiredArgsConstructor
public class ProviderCacheService {
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    private static final String KEY_PROVIDER_DETAIL = "provider:detail:%d";
    private static final String KEY_PROVIDER_DASHBOARD = "provider:dashboard:%s:%s";
    private static final String KEY_EXPIRY_ALERTS = "provider:alerts:%d";
    
    private static final Duration DETAIL_TTL = Duration.ofMinutes(10);
    private static final Duration DASHBOARD_TTL = Duration.ofMinutes(30);
    private static final Duration ALERT_TTL = Duration.ofMinutes(15);
    
    /**
     * 获取供应商详情（带缓存）
     */
    @Cacheable(value = "providerDetail", key = "#providerId", 
               unless = "#result == null")
    public ProviderDetailVO getProviderDetail(Long providerId) {
        // 查询基础信息 + 扩展信息 + 有效合同
        return providerMgmtService.getFullDetail(providerId);
    }
    
    /**
     * 供应商信息更新后清除缓存
     */
    @CacheEvict(value = "providerDetail", key = "#providerId")
    public void evictProviderCache(Long providerId) {
        // 同时清除看板缓存
        redisTemplate.delete(
            String.format(KEY_PROVIDER_DASHBOARD, "*", "*"));
    }
    
    /**
     * 看板数据缓存
     */
    public DashboardVO getDashboard(String dateRange, Integer providerType) {
        String key = String.format(KEY_PROVIDER_DASHBOARD, dateRange, 
                providerType != null ? providerType : "all");
        DashboardVO cached = (DashboardVO) redisTemplate.opsForValue().get(key);
        if (cached != null) return cached;
        
        DashboardVO data = dashboardService.calculate(dateRange, providerType);
        redisTemplate.opsForValue().set(key, data, DASHBOARD_TTL);
        return data;
    }
}
```
