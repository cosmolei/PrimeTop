# 客户端版本管理与升级策略 - 详细设计

## 1. 概述

### 1.1 背景

PrimeTop 作为面向全学段的移动端 APP（Android + iOS），需要一套完善的版本管理与升级策略来应对：
- 多版本客户端并存（用户不主动升级）
- 功能向后兼容（新服务端能力不能破坏旧客户端）
- 紧急修复（安全漏洞、重大 Bug 需要快速推送）
- 分学段差异（不同年龄段用户对更新的接受度不同）
- 合规要求（未成年人相关修复需强制触达）

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **强制更新可控** | 关键修复能在指定范围内强制用户升级 |
| **版本兼容透明** | 服务端能根据客户端版本号做能力降级 |
| **升级体验流畅** | 升级过程不中断学习、不丢失本地数据 |
| **灰度可控** | 新版本可以按比例/规则灰度推送 |
| **回滚迅速** | 出问题时能快速通知降级或回退 |

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| `versionCode` | 整型版本号（Build Number），单调递增，用于程序比较 |
| `versionName` | 语义化版本号，如 `1.2.3`，面向用户展示 |
| `minSupportedVersion` | 服务端支持的最低客户端版本，低于此版本触发强制更新 |
| `targetSDKVersion` | 客户端声明的目标 API Level，用于能力协商 |
| `featureFlag` | 特性开关，服务端按客户端版本控制功能可见性 |
| `hotfix` | 热修复，不经过应用商店审核的动态补丁 |

## 2. 版本号规范

### 2.1 版本号格式

```
versionName = MAJOR.MINOR.PATCH[-PRERELEASE]
versionCode = 递增整数（每次构建 +1）
```

| 字段 | 含义 | 示例 |
|------|------|------|
| MAJOR | 重大版本，包含不兼容变更 | `1` → `2` |
| MINOR | 功能版本，新增功能但向后兼容 | `1.2` → `1.3` |
| PATCH | 补丁版本，Bug 修复 | `1.2.1` → `1.2.2` |
| PRERELEASE | 预发布标识 | `-alpha.1`, `-beta.2`, `-rc.1` |

### 2.2 版本号递增规则

```
MAJOR: 强制更新场景（数据结构不兼容、协议变更）
MINOR: 新功能上线（新学段、新模块）
PATCH: Bug 修复、性能优化、安全补丁
versionCode: 每次构建自动递增，不重复
```

```dart
/// lib/core/version/app_version.dart

class AppVersion {
  /// 语义化版本号，如 "1.2.3"
  final String versionName;

  /// 构建号，单调递增整数
  final int versionCode;

  /// 目标特性集版本，用于与服务端能力协商
  final int targetFeatureSet;

  /// 构建渠道：official | beta | internal
  final String channel;

  /// 构建环境：production | staging | development
  final String environment;

  const AppVersion({
    required this.versionName,
    required this.versionCode,
    required this.targetFeatureSet,
    this.channel = 'official',
    this.environment = 'production',
  });

  /// 从构建信息解析（由构建脚本注入）
  factory AppVersion.fromBuildInfo() {
    return AppVersion(
      versionName: const String.fromEnvironment('APP_VERSION', defaultValue: '0.0.0'),
      versionCode: const int.fromEnvironment('APP_BUILD_NUMBER', defaultValue: 1),
      targetFeatureSet: const int.fromEnvironment('APP_FEATURE_SET', defaultValue: 1),
      channel: const String.fromEnvironment('APP_CHANNEL', defaultValue: 'official'),
      environment: const String.fromEnvironment('APP_ENV', defaultValue: 'production'),
    );
  }

  /// 解析 versionName 为可比较的元组
  (int, int, int) get parsed {
    final parts = versionName.split('+')[0].split('-')[0].split('.');
    return (
      int.parse(parts[0]),
      parts.length > 1 ? int.parse(parts[1]) : 0,
      parts.length > 2 ? int.parse(parts[2]) : 0,
    );
  }

  bool isOlderThan(AppVersion other) => versionCode < other.versionCode;
  bool isNewerThan(AppVersion other) => versionCode > other.versionCode;
  bool isSameOrNewer(AppVersion other) => versionCode >= other.versionCode;
}
```

### 3.2 更新类型判定逻辑

```python
# 服务端 version_check 服务

def determine_update_type(client_version_code: int, platform: str) -> dict:
    """
    判定更新类型：
    - forced: 强制更新，客户端必须升级才能继续使用
    - recommended: 推荐更新，用户可跳过但有次数限制
    - optional: 可选更新，纯提示
    - none: 无更新
    """

    # 获取当前平台最新版本
    latest = get_latest_release(platform)

    if not latest or client_version_code >= latest.version_code:
        return {"updateType": "none", "forced": False}

    # 获取强制更新版本线（可按版本段配置）
    forced_floor = get_forced_floor(platform)

    # 低于强制底线 → 强制更新
    if client_version_code < forced_floor:
        return {
            "updateType": "forced",
            "forced": True,
            "reason": "SECURITY"  # SECURITY | COMPATIBILITY | COMPLIANCE
        }

    # MAJOR 版本差 >= 2 → 强制更新
    client_major = parse_major(client_version_code)
    latest_major = parse_major(latest.version_code)
    if latest_major - client_major >= 2:
        return {
            "updateType": "forced",
            "forced": True,
            "reason": "COMPATIBILITY"
        }

    # MAJOR 版本差 = 1 → 推荐更新
    if latest_major - client_major == 1:
        return {"updateType": "recommended", "forced": False}

    # 同 MAJOR → 可选更新
    return {"updateType": "optional", "forced": False}
```

**管理后台操作：**

运营/开发通过管理后台设置强制更新底线时：
1. 设置 `min_version_code` 和 `reason`
2. 设置 `effective_from`（至少提前 48 小时，给用户缓冲）

4. 生效后，所有低于此版本的客户端将收到强制更新提示

```dart
/// lib/core/version/version_check_service.dart

enum UpdateType { none, optional, recommended, forced }

class VersionCheckResult {
  final UpdateType updateType;
  final bool forced;
  final AppVersion? latestVersion;
  final String? downloadUrl;
  final String? releaseNotes;
  final int? fileSize;
  final String? fileHash;
  final UpdateStrategy strategy;

  const VersionCheckResult({
    required this.updateType,
    this.forced = false,
    this.latestVersion,
    this.downloadUrl,
    this.releaseNotes,
    this.fileSize,
    this.fileHash,
    this.strategy = const UpdateStrategy(),
  });
}

class UpdateStrategy {
  final int retryIntervalHours;
  final int cooldownAfterSkipHours;
  final int maxSkipCount;
  final bool silentDownload;

  const UpdateStrategy({
    this.retryIntervalHours = 24,
    this.cooldownAfterSkipHours = 72,
    this.maxSkipCount = 3,
    this.silentDownload = true,
  });
}

class VersionCheckService {
  final ApiClient _api;
  final LocalStorage _storage;
  final AppVersion _currentVersion;

  VersionCheckService(this._api, this._storage, this._currentVersion);

  /// 检查更新
  Future<VersionCheckResult> checkUpdate() async {
    try {
      final response = await _api.get('/api/v1/app/version/check', params: {
        'platform': Platform.isAndroid ? 'android' : 'ios',
        'versionCode': _currentVersion.versionCode,
        'versionName': _currentVersion.versionName,
        'channel': _currentVersion.channel,
      });

      final data = response.data;

      if (!data['hasUpdate']) {
        return const VersionCheckResult(updateType: UpdateType.none);
      }

      final updateType = _parseUpdateType(data['updateType']);
      final strategy = UpdateStrategy(
        retryIntervalHours: data['strategy']?['retryIntervalHours'] ?? 24,
        cooldownAfterSkipHours: data['strategy']?['cooldownAfterSkipHours'] ?? 72,
        maxSkipCount: data['strategy']?['maxSkipCount'] ?? 3,
        silentDownload: data['strategy']?['silentDownload'] ?? true,
      );

      return VersionCheckResult(
        updateType: updateType,
        forced: data['forced'] ?? false,
        latestVersion: AppVersion(
          versionName: data['latestVersion']['versionName'],
          versionCode: data['latestVersion']['versionCode'],
          targetFeatureSet: 1,
        ),
        downloadUrl: data['latestVersion']['downloadUrl'],
        releaseNotes: data['latestVersion']['releaseNotes'],
        fileSize: data['latestVersion']['fileSize'],
        fileHash: data['latestVersion']['fileHash'],
        strategy: strategy,
      );
    } catch (e) {
      // 版本检查失败不应阻塞用户使用
      _reportCheckError(e);
      return const VersionCheckResult(updateType: UpdateType.none);
    }
  }

  /// 判断是否应该弹出更新提示（考虑冷却和跳过次数）
  Future<bool> shouldShowUpdatePrompt(VersionCheckResult result) async {
    if (result.updateType == UpdateType.none) return false;
    if (result.forced) return true; // 强制更新总是显示

    final skipCount = _storage.getInt('update_skip_count') ?? 0;
    final lastSkipTime = _storage.getInt('update_last_skip_time') ?? 0;

    // 超过最大跳过次数，强制显示
    if (skipCount >= result.strategy.maxSkipCount) return true;

    // 冷却期内不重复提示
    final cooldownMs = result.strategy.cooldownAfterSkipHours * 3600000;
    final now = DateTime.now().millisecondsSinceEpoch;
    if (now - lastSkipTime < cooldownMs) return false;

    return true;
  }

  /// 记录用户跳过
  Future<void> recordSkip() async {
    final count = _storage.getInt('update_skip_count') ?? 0;
    await _storage.setInt('update_skip_count', count + 1);
    await _storage.setInt('update_last_skip_time',
        DateTime.now().millisecondsSinceEpoch);
  }

  /// 清除跳过记录（安装新版本后调用）
  Future<void> clearSkipState() async {
    await _storage.remove('update_skip_count');
    await _storage.remove('update_last_skip_time');
  }

  UpdateType _parseUpdateType(String? type) {
    switch (type) {
      case 'forced': return UpdateType.forced;
      case 'recommended': return UpdateType.recommended;
      case 'optional': return UpdateType.optional;
      default: return UpdateType.none;
    }
  }
}
```

```dart
/// lib/core/version/android_updater.dart

class AndroidUpdater {
  final String _downloadDir;

  AndroidUpdater() : _downloadDir = '${(await getTemporaryDirectory()).path}/updates';

  /// 下载 APK 并校验
  Future<String> downloadApk(VersionCheckResult result) async {
    if (result.downloadUrl == null) {
      throw UpdateException('无下载地址');
    }

    final dio = Dio();
    final savePath = '$_downloadDir/primetop-${result.latestVersion!.versionCode}.apk';

    // 显示下载进度
    await dio.download(
      result.downloadUrl!,
      savePath,
      onReceiveProgress: (received, total) {
        // 通过 Stream 通知 UI 进度
        _progressController.add(
          total > 0 ? received / total : 0.0
        );
      },
    );

    // 校验文件完整性
    if (result.fileHash != null) {
      final hash = await _computeFileHash(savePath);
      if (!hash.startsWith(result.fileHash!.split(':')[1])) {
        await File(savePath).delete();
        throw UpdateException('文件校验失败，请重试');
      }
    }

    return savePath;
  }

  /// 安装 APK（需要 REQUEST_INSTALL_PACKAGES 权限）
  Future<void> installApk(String apkPath) async {
    if (!await _checkInstallPermission()) {
      await _requestInstallPermission();
      return; // 用户授权后通过 onActivityResult 回调重新触发
    }

    final file = XFile(apkPath);
    await OpenFilex.open(apkPath);
  }

  Future<String> _computeFileHash(String path) async {
    final file = File(path);
    final bytes = await file.readAsBytes();
    final digest = sha256.convert(bytes);
    return 'sha256:$digest';
  }
}
```

### 5.2 版本兼容中间件

```python
# 服务端中间件：根据客户端版本做能力适配

class VersionCompatMiddleware:
    """API 版本兼容中间件"""

    async def __call__(self, request: Request, call_next):
        # 从请求头提取客户端版本
        client_vc = int(request.headers.get('X-Client-VersionCode', '0'))
        client_platform = request.headers.get('X-Client-Platform', 'unknown')

        # 注入版本上下文
        request.state.client_version = ClientVersionInfo(
            version_code=client_vc,
            platform=client_platform,
        )

        # 检查是否已过期（不支持的版本）
        if client_vc > 0 and client_vc < get_min_supported_version(client_platform):
            return JSONResponse(
                status_code=426,  # Upgrade Required
                content={
                    "code": 40001,
                    "message": "当前版本已停止服务，请更新至最新版本",
                    "data": {
                        "updateType": "forced",
                        "latestVersion": get_latest_release(client_platform),
                    }
                }
            )

        response = await call_next(request)
        return response
```

```python
        "oral_practice": 10200,
        "pinyin_learning": 10200,
    }

    @classmethod
    def get_available_features(cls, client_version_code: int) -> list[str]:
        """获取客户端可用的功能列表"""
        return [
            feature for feature, min_vc in cls.FEATURES.items()
            if client_version_code >= min_vc
        ]

    @classmethod
    def is_feature_available(cls, feature: str, client_version_code: int) -> bool:
        """判断某功能对指定客户端版本是否可用"""
        min_vc = cls.FEATURES.get(feature)
        if min_vc is None:
            return True  # 未知功能默认可用（新功能旧客户端不会调用）
        return client_version_code >= min_vc
```

### 6.1 静默下载策略

```dart
/// lib/core/version/silent_updater.dart

class SilentUpdateService {
  final VersionCheckService _versionCheck;
  final AndroidUpdater _androidUpdater;

  /// 静默下载条件：
  /// 1. WiFi 环境
  /// 2. 存储空间充足（APK 大小 * 2）
  /// 3. 电量 > 30%
  /// 4. 用户未在活跃学习会话中
  Future<void> trySilentDownload(VersionCheckResult result) async {
    if (!await _canSilentDownload(result)) return;

    try {
      final apkPath = await _androidUpdater.downloadApk(result);
      // 下载完成，标记待安装
      await _storage.setString('pending_update_apk', apkPath);
      await _storage.setInt('pending_update_version', result.latestVersion!.versionCode);
    } catch (e) {
      // 静默下载失败不通知用户
      _logSilentDownloadError(e);
    }
  }

  Future<bool> _canSilentDownload(VersionCheckResult result) async {
    // 仅 Android 支持静默下载
    if (!Platform.isAndroid) return false;

    // 必须是 WiFi
    final connectivity = await Connectivity().checkConnectivity();
    if (connectivity != ConnectivityResult.wifi) return false;

    // 存储空间检查
    if (result.fileSize != null) {
      final available = await _getAvailableStorage();
      if (available < result.fileSize! * 2) return false;
    }

    // 电量检查
    final battery = await Battery().batteryLevel;
    if (battery < 30) return false;

    return true;
  }

  /// 检查是否有已下载待安装的更新
  Future<InstalledUpdate?> checkPendingUpdate(int currentVersionCode) async {
    final pendingVersion = _storage.getInt('pending_update_version');
    if (pendingVersion == null || pendingVersion <= currentVersionCode) {
      return null;
    }

    final apkPath = _storage.getString('pending_update_apk');
    if (apkPath == null || !await File(apkPath).exists()) {
      return null;
    }

    return InstalledUpdate(
      versionCode: pendingVersion,
      apkPath: apkPath,
    );
  }
}
```

```python
            delta_size=os.path.getsize(delta_path),
            delta_url=cdn_url,
            full_size=os.path.getsize(to_apk),
        ))
```

### 7.1 检查时机

| 时机 | 检查类型 | 说明 |
|------|----------|------|
| APP 启动（冷启动） | 完整检查 | 调用版本检查 API |
| APP 从后台恢复 | 轻量检查 | 检查本地缓存，超过 `retryIntervalHours` 才请求 API |
| 首页下拉刷新 | 可选检查 | 如果距上次检查超过 1 小时，附带版本检查 |
| 推送消息触发 | 强制检查 | 收到 `force_update` 类型推送时立即检查 |
| 切换账号 | 完整检查 | 不同账号可能有不同策略 |

### 7.2 触发策略

```dart
/// lib/core/version/update_scheduler.dart

class UpdateScheduler {
  final VersionCheckService _checkService;
  final SilentUpdateService _silentService;
  final LocalStorage _storage;

  /// 启动时检查
  Future<void> onAppStart() async {
    final lastCheckTime = _storage.getInt('last_version_check_time') ?? 0;
    final now = DateTime.now().millisecondsSinceEpoch;

    // 距上次检查不足 30 分钟则跳过
    if (now - lastCheckTime < 30 * 60 * 1000) {
      // 但仍需检查是否有待安装的静默下载
      await _checkPendingInstall();
      return;
    }

    final result = await _checkService.checkUpdate();

    if (result.updateType == UpdateType.none) return;

    // 强制更新 → 立即弹窗
    if (result.forced) {
      _showUpdateDialog(result);
      return;
    }

    // 推荐更新 → 检查是否该提示
    if (await _checkService.shouldShowUpdatePrompt(result)) {
      _showUpdateDialog(result);
    }

    // 尝试静默下载
    if (result.strategy.silentDownload) {
      unawaited(_silentService.trySilentDownload(result));
    }

    _storage.setInt('last_version_check_time', now);
  }

  /// 从后台恢复时检查
  Future<void> onAppResume() async {
    final lastCheckTime = _storage.getInt('last_version_check_time') ?? 0;
    final now = DateTime.now().millisecondsSinceEpoch;

    // 超过 4 小时重新检查
    if (now - lastCheckTime > 4 * 3600 * 1000) {
      final result = await _checkService.checkUpdate();
      if (result.forced) {
        _showUpdateDialog(result);
      }
      _storage.setInt('last_version_check_time', now);
    }

    await _checkPendingInstall();
  }
}
```

```dart
/// lib/core/version/data_migrator.dart

class DataMigrator {
  final LocalDatabase _db;
  final SharedPreferences _prefs;

  /// 当前本地数据版本（存储在 SharedPreferences 中）
  Future<int> get currentDataVersion => _prefs.getInt('local_data_version') ?? 1;

  Future<void> migrate() async {
    final current = await currentDataVersion;
    final target = _latestDataVersion;

    if (current >= target) return;

    for (var v = current + 1; v <= target; v++) {
      await _runMigration(v);
    }

    await _prefs.setInt('local_data_version', target);
  }

  /// 迁移脚本注册表
  static const _migrations = <int, Future<void> Function(DataMigrationContext)>{
    2: _migrateV1ToV2,
    3: _migrateV2ToV3,
    // 新迁移在此追加
  };

  static const _latestDataVersion = 3; // 更新为最新版本

  static Future<void> _migrateV1ToV2(DataMigrationContext ctx) async {
    // 示例：错题表新增 error_category 字段
    await ctx.db.execute('ALTER TABLE mistake_records ADD COLUMN error_category TEXT DEFAULT "unknown"');
  }

  static Future<void> _migrateV2ToV3(DataMigrationContext ctx) async {
    // 示例：学习记录表拆分为会话表和明细表
    await ctx.db.execute('''
      CREATE TABLE IF NOT EXISTS learning_sessions (
        id TEXT PRIMARY KEY,
        user_id TEXT NOT NULL,
        subject TEXT,
        start_time INTEGER NOT NULL,
        end_time INTEGER,
        duration_seconds INTEGER DEFAULT 0,
        session_type TEXT NOT NULL DEFAULT 'general'

    ''');

      SELECT substr(uuid, 1, 36), user_id, subject, start_time, end_time,
             (end_time - start_time) / 1000
```

```dart
class PreUpgradeBackup {
  Future<String?> backup() async {
    final dir = await getApplicationSupportDirectory();
    final backupDir = '${dir.path}/pre_upgrade_backups';
    final timestamp = DateTime.now().millisecondsSinceEpoch;

    // 备份本地数据库

    // 备份 SharedPreferences

    final prefsJson = jsonEncode(prefs.getKeys().fold<Map<String, dynamic>>({}, (m, k) {
      m[k] = prefs.get(k);
      return m;
    }));
    await File('$backupDir/${timestamp}_prefs.json').writeAsString(prefsJson);

    return backupDir;
  }

  /// 备份保留策略：最多保留最近 3 份
  Future<void> cleanup() async {
    final dir = await getApplicationSupportDirectory();
    final backupDir = Directory('${dir.path}/pre_upgrade_backups');
    if (!await backupDir.exists()) return;

    final files = await backupDir.list().toList();
    if (files.length > 6) { // 3 份备份 × 2 个文件
      files.sort((a, b) => b.path.compareTo(a.path));
      for (var i = 6; i < files.length; i++) {
        await files[i].delete();
      }
    }
  }
}
```

```python
# 服务端：灰度版本判断

def get_release_for_device(
    platform: str,
    device_id: str | None,
    channel: str | None,
    user_grade: str | None,
) -> AppRelease | None:
    """获取适用于当前设备的最新版本"""

    releases = get_active_releases(platform)
    if not releases:
        return None

    latest = releases[0]  # 已按 version_code DESC 排序

    if not latest.grayscale_enabled:
        return latest

    # 灰度判断
    rule = GrayscaleRule(**latest.grayscale_rules) if latest.grayscale_rules else GrayscaleRule()

    # 1. 设备白名单优先
    if device_id and rule.device_whitelist and device_id in rule.device_whitelist:
        return latest

    # 2. 渠道白名单
    if channel and rule.channel_whitelist and channel not in rule.channel_whitelist:
        return None

    # 3. 年级过滤
    if user_grade and rule.grade_whitelist and user_grade not in rule.grade_whitelist:
        return None

    # 4. 灰度比例（基于 device_id 哈希）
    if device_id:
        hash_val = int(hashlib.md5(device_id.encode()).hexdigest(), 16) % 100
        if hash_val >= latest.grayscale_percent:
            return None

    return latest
```

```dart
/// lib/core/version/hot_patch_service.dart

class HotPatchService {
  final ApiClient _api;
  final AppVersion _version;

  /// 检查并应用补丁
  Future<bool> checkAndApply() async {
    try {
      final response = await _api.get('/api/v1/app/hot-patch/check', params: {
        'versionCode': _version.versionCode,
        'platform': Platform.isAndroid ? 'android' : 'ios',
      });

      if (response.data == null) return false;

      final patch = response.data;
      final patchUrl = patch['patchUrl'] as String;
      final patchHash = patch['patchHash'] as String;
      final patchSignature = patch['patchSignature'] as String;

      // 下载补丁
      final patchFile = await _downloadPatch(patchUrl, patch['patchSize']);

      // 校验哈希
      final actualHash = await _computeHash(patchFile);
      if (actualHash != patchHash) {
        await patchFile.delete();
        throw HotPatchException('补丁校验失败');
      }

      // 校验签名
      if (!await _verifySignature(patchFile, patchSignature)) {
        await patchFile.delete();
        throw HotPatchException('补丁签名验证失败');
      }

      // 应用补丁（具体实现依赖 Shorebird 或自研方案）
      await _applyPatch(patchFile);

      return true;
    } catch (e) {
      _reportPatchError(e);
      return false;
    }
  }
}
```

| 强更弹窗跳过率 | 强更场景用户跳过 > 50%（异常） | P2 | 检查弹窗是否被遮挡 |

## 13. 异常场景处理

### 13.1 异常场景矩阵

| 场景 | 表现 | 处理策略 |
|------|------|----------|
| 下载中断 | 网络断开导致 APK 下载失败 | 支持断点续传；失败后提示用户检查网络 |
| 存储不足 | 设备空间不够 | 下载前检查空间；提示清理 |
| 安装包损坏 | 哈希校验失败 | 删除本地文件，提示重新下载 |
| 安装失败 | 签名冲突、权限不足 | 清理旧 APK，引导用户手动安装 |
| 安装后崩溃 | 新版本启动失败 | Android: 引导回滚（保留旧 APK）；iOS: 引导卸载重装 |
| 服务端版本回滚 | 新版本被撤回 | 已安装用户走正常版本检查逻辑，不再提示 |
| 版本检查 API 失败 | 网络异常 | 不阻塞使用，下次启动重试 |
| 热更新补丁冲突 | 多个补丁叠加 | 按版本链顺序应用，失败则跳过所有补丁 |

### 13.2 版本检查失败降级

```dart
/// lib/core/version/version_check_service.dart (续)

Future<VersionCheckResult> checkUpdate() async {
  try {
    final response = await _api.get('/api/v1/app/version/check', params: {...});
    // ... 正常处理
  } on TimeoutException {
    // 超时不阻塞
    return const VersionCheckResult(updateType: UpdateType.none);
  } on SocketException {
    // 无网络不阻塞
    return const VersionCheckResult(updateType: UpdateType.none);
  } on ApiException catch (e) {
    if (e.statusCode == 426) {
      // 服务端返回 Upgrade Required
      return VersionCheckResult(
        updateType: UpdateType.forced,
        forced: true,
        latestVersion: AppVersion(
          versionName: e.data?['data']?['latestVersion']?['versionName'] ?? '',
          versionCode: e.data?['data']?['latestVersion']?['versionCode'] ?? 0,
          targetFeatureSet: 1,
        ),
        downloadUrl: e.data?['data']?['latestVersion']?['downloadUrl'],
        releaseNotes: e.data?['data']?['latestVersion']?['releaseNotes'] ?? '请更新至最新版本',
      );
    }
    // 其他 API 错误不阻塞
    return const VersionCheckResult(updateType: UpdateType.none);
  } catch (e) {
    _reportCheckError(e);
    return const VersionCheckResult(updateType: UpdateType.none);
  }
}
```

## 17. 总结

本文档定义了 PrimeTop 客户端版本管理的完整策略，覆盖：

1. **版本号规范** — 语义化版本 + 递增构建号，便于程序比较和用户识别
2. **版本检查 API** — 服务端根据客户端版本返回更新类型和策略
3. **升级流程** — 强制/推荐/可选三级更新，含冷却和跳过限制
4. **兼容策略** — 特性版本矩阵 + 版本兼容中间件，保证多版本共存
5. **静默下载** — WiFi 下自动下载，减少用户等待
6. **数据迁移** — 升级后本地数据自动迁移，含备份保护
7. **灰度发布** — 按比例/规则灰度推送新版本
8. **热更新** — Phase 2 补丁机制，快速修复不经过商店审核
9. **监控告警** — 版本分布、更新漏斗、崩溃率实时监控
