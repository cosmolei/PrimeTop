## 1. 模块概述

### 1.1 功能目标

为平台中所有**主观题 / 开放性题目**提供统一的智能评分与反馈生成能力。覆盖但不限于：

| 题型 | 学科示例 | 特点 |
|------|----------|------|
| 简答题 | 数学证明、物理简答、化学方程式书写 | 有标准答案但表述方式多样 |
| 论述题 | 语文阅读理解、政治分析、历史论述 | 多维度评分，答案开放 |
| 实验探究题 | 生物实验设计、物理实验分析 | 考查科学推理与变量控制 |
| 计算推导题 | 数学综合题、物理计算题 | 需要分步推理，中间步骤可部分得分 |
| 翻译/写作题 | 英语短文翻译、语文微写作 | 语言表达多维度评估 |
| 代码题（预留） | 信息技术 | 逻辑正确性 + 代码质量 |

### 1.2 与现有模块的边界

| 模块 | 覆盖范围 | 本模块区别 |
|------|----------|------------|
| 作文批改评分引擎 | 语文/英语整篇作文 | 本模块处理**非作文类**主观题 |
| 解题过程分步评分服务 | 理科标准解题步骤 | 本模块处理**开放性/非标准化**答案 |
| 练习答题实时批改服务 | 客观题（选择/填空）准实时批改 | 本模块处理需要**语义理解**的题目 |
| 智能作业批改与教师阅卷辅助 | 教师端辅助工具 | 本模块是底层评分引擎，向上供其调用 |

### 1.3 设计原则

1. **评分一致性**：同一答案在不同时间、不同负载下评分结果波动 ≤ ±1 分（满分 10 分制）
2. **可解释性**：每次评分必须输出扣分理由和得分维度明细
3. **人在回路**：低置信度评分自动路由人工复审，不直接返回可疑分数
4. **学科感知**：不同学科采用不同的评分策略与 Prompt 模板
5. **渐进反馈**：优先输出鼓励性、建设性反馈，避免打击学习积极性

### 2.2 核心流程

```
学生提交答案
    │
    ▼
[1. 请求预处理] ──→ 答案归一化、题型识别、历史命中查询
    │
    ▼
[2. 快速通道] ──→ 规则匹配（关键词/正则/精确匹配）
    │                 ├─ 命中 → 输出初步分数 → 进入 [4]
    │                 └─ 未命中 → 进入 [3]
    ▼
[3. 深度通道] ──→ AI 语义评分（组装 Prompt → 调用大模型 → 解析评分）
    │
    ▼
[4. 混合协调] ──→ 融合规则分数与 AI 分数 → 维度拆分 → 部分得分
    │
    ▼
[5. 置信度评估] ──→ 输出置信度分值
    │                 ├─ 置信度 ≥ 0.85 → 直接返回
    │                 ├─ 0.60 ≤ 置信度 < 0.85 → 标记"建议人工确认"
    │                 └─ 置信度 < 0.60 → 路由人工复审队列
    ▼
[6. 反馈生成] ──→ 生成个性化反馈文本 + 知识点关联
    │
    ▼
[7. 结果返回] ──→ 同步返回评分结果 + 异步写入审计日志
```

### 3.3 数据库表设计

#### 3.3.1 评分记录表 `subjective_scoring_records`

```sql
CREATE TABLE subjective_scoring_records (
    id                  BIGSERIAL PRIMARY KEY,
    request_id          VARCHAR(64) NOT NULL UNIQUE,
    question_id         VARCHAR(64) NOT NULL,
    student_id          VARCHAR(64) NOT NULL,
    subject             VARCHAR(20) NOT NULL,
    grade_level         VARCHAR(10) NOT NULL,
    student_answer      TEXT NOT NULL,
    student_answer_hash VARCHAR(64) NOT NULL,
    total_score         DECIMAL(5,2) NOT NULL,
    max_score           DECIMAL(5,2) NOT NULL,
    confidence          DECIMAL(3,2) NOT NULL,
    review_required     BOOLEAN NOT NULL DEFAULT FALSE,
    review_status       VARCHAR(20) NOT NULL DEFAULT 'NONE',
    reviewer_id         VARCHAR(64),
    reviewed_score      DECIMAL(5,2),
    reviewed_at         TIMESTAMPTZ,
    dimension_scores    JSONB NOT NULL,
    feedback            TEXT NOT NULL,
    overall_feedback    TEXT,
    scoring_engine      VARCHAR(50) NOT NULL,
    model_id            VARCHAR(100),
    prompt_version      VARCHAR(20),
    rubric_version      VARCHAR(20),
    processing_time_ms  INTEGER,
    scenario            VARCHAR(20) NOT NULL,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    CONSTRAINT chk_score CHECK (total_score >= 0 AND total_score <= max_score),
    CONSTRAINT chk_confidence CHECK (confidence >= 0 AND confidence <= 1)
);

-- 核心查询索引
CREATE INDEX idx_ssr_student ON subjective_scoring_records(student_id, created_at DESC);
CREATE INDEX idx_ssr_question ON subjective_scoring_records(question_id);
CREATE INDEX idx_ssr_review ON subjective_scoring_records(review_status) WHERE review_status != 'NONE';
CREATE INDEX idx_ssr_hash ON subjective_scoring_records(question_id, student_answer_hash);
CREATE INDEX idx_ssr_subject_score ON subjective_scoring_records(subject, total_score, created_at DESC);
```

## 4. 评分策略模型

### 4.1 策略路由矩阵

系统根据 **题型 × 学科 × 学段** 三维路由到不同评分策略：

```java
public enum ScoringStrategy {
    EXACT_MATCH,         // 精确匹配（填空题、单词翻译）
    KEYWORD_BASED,       // 关键词评分（简答、名词解释）
    SEMANTIC_SIMILARITY, // 语义相似度（阅读理解简答）
    MULTI_DIMENSION_AI,  // 多维度AI评分（论述、实验探究）
    STEP_BASED,          // 分步评分（计算推导、证明）
    CODE_EVALUATION,     // 代码评估（预留）
    HYBRID               // 混合策略（默认）
}
```

### 4.3 评分严格度配置

```java
public enum ScoringStrictness {
    LENIENT,   // 宽松：适合日常练习，鼓励为主，小错不扣分
    NORMAL,    // 标准：适合单元测验，正常评分
    STRICT,    // 严格：适合期中期末/模拟考试，严格扣分
    EXAM       // 考试级：中考/高考标准，扣分最严格
}

// 各严格度下的容差配置
// LENIENT:  小错容差 0.5 分，口语化表述不扣分
// NORMAL:   小错容差 0.3 分
// STRICT:   小错容差 0.1 分
// EXAM:     零容差，按标准答案严格对照
```

## 5. API 接口设计

### 5.1 提交评分请求（同步）

```
POST /api/v1/subjective-scoring/score
```

**Request Body**: [ScoringRequest](#32-评分结果-scoringresult) 结构

**Response Body**:

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "requestId": "ssr_20260616001_a1b2c3",
    "status": "SCORED",
    "totalScore": 8.5,
    "maxScore": 10,
    "confidence": 0.91,
    "reviewRequired": false,
    "dimensionScores": [...],
    "overallFeedback": "...",
    "knowledgePoints": [...],
    "processingTimeMs": 3200
  }
}
```

**特殊响应**:

| HTTP Status | code | 场景 |
|-------------|------|------|
| 200 | 0 | 评分完成 |
| 200 | 0 (status=PROCESSING) | 异步评分中，需轮询 |
| 429 | 4029 | 触发限流 |
| 422 | 4022 | 答案内容无法解析 |

```java
     * 答案归一化处理

    public NormalizedAnswer normalize(String rawAnswer, Subject subject) {
        NormalizedAnswer normalized = new NormalizedAnswer();

        // 1. 基础清洗
        String cleaned = rawAnswer.trim()
            .replaceAll("\\s+", " ")           // 多空格合一
            .replaceAll("[\\u200B-\\u200D]", "") // 零宽字符移除
            .trim();

        // 2. 全角/半角统一
        cleaned = normalizeWidth(cleaned);

        // 3. 学科特定处理
        switch (subject) {
            case MATH:
            case PHYSICS:
                // LaTeX 公式提取与标准化
                cleaned = normalizeLatex(cleaned);
                // 单位标准化 (如 "m/s" vs "米每秒")
                cleaned = normalizeUnits(cleaned);
                break;
            case ENGLISH:
                // 大小写归一化（非句首）
                cleaned = normalizeEnglishCase(cleaned);
                // 标点统一
                cleaned = normalizeEnglishPunctuation(cleaned);
                break;
            case CHINESE:
                // 繁简统一（统一简体）
                cleaned = normalizeChinese(cleaned);
                break;
        }

        normalized.setText(cleaned);
        normalized.setOriginalLength(rawAnswer.length());
        normalized.setNormalizedLength(cleaned.length());

        // 4. 生成答案指纹（用于缓存命中）
        normalized.setHash(sha256(
            cleaned.toLowerCase().replaceAll("[\\p{Punct}，。、；：！？""''（）]", "")
        ));

        return normalized;
    }

    /**
     * LaTeX 标准化：统一公式格式，便于后续匹配
     */
    private String normalizeLatex(String text) {
        // 提取行内公式 $...$ 和块级 $$...$$
        // 统一变量名（如 \vec{F} 和 \overrightarrow{F} 统一）
        // 标准化分数表示
        return text
            .replace("\\overrightarrow", "\\vec")
            .replace("\\overline", "\\bar")
            .replaceAll("\\\\dfrac", "\\\\frac");
```

```java
public class RuleBasedScorer {

    public Optional<RuleScore> evaluate(
            NormalizedAnswer answer,
            ScoringRubric rubric,
            ScoringStrictness strictness) {

        RuleScore score = new RuleScore();

        // 1. 精确匹配检查
        if (rubric.getExactMatches() != null) {
            for (ExactMatchRule rule : rubric.getExactMatches()) {
                if (answer.getText().equalsIgnoreCase(rule.getPattern())) {
                    return Optional.of(score.setTotalScore(rule.getScore())
                        .setMatchType("EXACT")
                        .setConfidence(0.99));
                }
            }
        }

        // 2. 关键词覆盖率评分
        if (rubric.getAnswerKeyPoints() != null) {
            KeyPointResult kpResult = evaluateKeyPoints(
                answer.getText(),
                rubric.getAnswerKeyPoints(),
                strictness
            );

            if (kpResult.getCoverage() >= 0.8) {
                // 关键点覆盖率 ≥ 80%，可以给出较高置信度的分数
                double ruleScore = kpResult.getCoverage() * rubric.getMaxScore();
                return Optional.of(score
                    .setTotalScore(roundScore(ruleScore, strictness))
                    .setMatchType("KEYPOINT")
                    .setConfidence(0.75 + kpResult.getCoverage() * 0.15)
                    .setKeyPointResult(kpResult));
            }
        }

        // 3. 正则规则匹配
        if (rubric.getRegexRules() != null) {
            // ... 正则匹配逻辑
        }

        // 未命中快速通道
        return Optional.empty();
    }

    private KeyPointResult evaluateKeyPoints(
            String answer, List<KeyPoint> keyPoints,
            ScoringStrictness strictness) {

        KeyPointResult result = new KeyPointResult();
        int matched = 0;

        for (KeyPoint kp : keyPoints) {
            boolean isMatched = false;

            // 精确关键词匹配
            for (String keyword : kp.getKeywords()) {
                if (answer.contains(keyword)) {
                    isMatched = true;
                    break;
                }
            }

            // 同义词匹配
            if (!isMatched && kp.getSynonyms() != null) {
                for (String syn : kp.getSynonyms()) {
                    if (answer.contains(syn)) {
                        isMatched = true;
                        break;
                    }
                }
            }

            if (isMatched) {
                matched++;
                result.addMatched(kp);
            } else {
                result.addMissed(kp);
            }
        }

        result.setCoverage((double) matched / keyPoints.size());
        return result;
    }
}
```

```java
public class AIScoringEngine {

    private static final int MAX_RETRIES = 2;
    private static final long TIMEOUT_MS = 15_000;

    @Autowired
    private ModelDispatcher modelDispatcher;

    @Autowired
    private ScoringResponseParser responseParser;

    @Autowired
    private ScoringMetrics metrics;

    public AIScoringResult score(ScoringContext context) {

        // 1. 选择模型（推理增强模型优先）
        ModelConfig modelConfig = selectModel(context);
        // 数学/物理优先使用推理模型，文科使用通用模型
        // 高置信度要求的场景使用更强模型

        // 2. 构建 Prompt
        String prompt = promptBuilder.build(context);

        // 3. 调用大模型（带重试）
        AIResponse response = callWithRetry(modelConfig, prompt, context);
        if (response == null) {
            // AI 调用失败，降级到规则评分
            metrics.recordFallback("AI_UNAVAILABLE");
            throw new ScoringFallbackException("AI model unavailable");
        }

        // 4. 解析响应
        AIScoringResult result = responseParser.parse(response.getText(), context);

        // 5. 结果校验
        validateResult(result, context);

        return result;
    }

    private ModelConfig selectModel(ScoringContext context) {
        // 理科证明/推导 → 推理增强模型（如 o1 / deepseek-r1）
        if (context.requiresDeepReasoning()) {
            return modelDispatcher.getConfig("reasoning_strong");
        }

        // 简单简答题 → 轻量模型（降低成本）
        if (context.getEstimatedComplexity() == Complexity.LOW) {
            return modelDispatcher.getConfig("general_lite");
        }

        // 默认使用通用模型
        return modelDispatcher.getConfig("general_standard");
    }

    private void validateResult(AIScoringResult result, ScoringContext context) {
        // 总分不超过满分
        if (result.getTotalScore() > context.getMaxScore()) {
            log.warn("AI score {} exceeds max {}, clamping",
                result.getTotalScore(), context.getMaxScore());
            result.setTotalScore(context.getMaxScore());
        }

        // 总分不低于0
        if (result.getTotalScore() < 0) {
            result.setTotalScore(0);
        }

        // 维度分数之和应与总分一致（容差 ±0.5）
        double dimSum = result.getDimensionScores().stream()
            .mapToDouble(d -> d.getScore())
            .sum();
        if (Math.abs(dimSum - result.getTotalScore()) > 0.5) {
            log.warn("Dimension sum {} != total {}, marking low confidence",
                dimSum, result.getTotalScore());
            result.setConfidence(Math.min(result.getConfidence(), 0.5));
        }

        // 置信度范围校验
        result.setConfidence(
            Math.max(0, Math.min(1, result.getConfidence()))
        );
    }
}
```

```java
public class HybridScoringCoordinator {

    public ScoringResult coordinate(
            Optional<RuleScore> ruleScore,
            Optional<AIScoringResult> aiScore,
            ScoringContext context) {

        // Case 1: 两者都有 → 加权融合
        if (ruleScore.isPresent() && aiScore.isPresent()) {
            return weightedFusion(ruleScore.get(), aiScore.get(), context);
        }

        // Case 2: 仅有规则评分 → 直接使用（高置信度场景）
        if (ruleScore.isPresent()) {
            return fromRuleScore(ruleScore.get(), context);
        }

        // Case 3: 仅有 AI 评分 → 使用 AI 评分
        if (aiScore.isPresent()) {
            return fromAIScore(aiScore.get(), context);
        }

        // Case 4: 都没有 → 返回错误
        throw new ScoringException("No scoring result available");
    }

    /**
     * 加权融合规则分数与 AI 分数
     */
    private ScoringResult weightedFusion(
            RuleScore ruleScore,
            AIScoringResult aiScore,
            ScoringContext context) {

        double ruleWeight = calculateRuleWeight(ruleScore, context);
        double aiWeight = 1.0 - ruleWeight;

        double fusedScore =
            ruleScore.getTotalScore() * ruleWeight +
            aiScore.getTotalScore() * aiWeight;

        // 如果两者差异过大（>2分），降低置信度
        double scoreDiff = Math.abs(
            ruleScore.getTotalScore() - aiScore.getTotalScore()
        );
        double confidencePenalty = scoreDiff > 2.0 ? 0.15 : 0.0;

        double fusedConfidence =
            (ruleScore.getConfidence() * ruleWeight +
             aiScore.getConfidence() * aiWeight) - confidencePenalty;

        return ScoringResult.builder()
            .totalScore(roundScore(fusedScore, context.getStrictness()))
            .confidence(fusedConfidence)
            .dimensionScores(aiScore.getDimensionScores()) // 维度详情取 AI 结果
            .engineType("HYBRID")
            .build();
    }

    /**
     * 规则评分权重计算
     * - 关键点覆盖率越高，规则评分越可信
     * - 答案越短，规则评分越可信
     * - 题型越标准化，规则评分越可信
     */
    private double calculateRuleWeight(RuleScore ruleScore, ScoringContext ctx) {
        double base = 0.3; // 基础权重 30%

        if ("EXACT".equals(ruleScore.getMatchType())) return 0.95;
        if ("KEYPOINT".equals(ruleScore.getMatchType())) {
            base = 0.45 + ruleScore.getKeyPointResult().getCoverage() * 0.2;
        }

        // 短答案（<100字）提高规则权重
        if (ctx.getAnswerLength() < 100) base += 0.1;

        return Math.min(base, 0.8); // 规则权重上限 80%
    }
}
```

## 8. 置信度评估与人工复审路由

### 8.1 置信度计算模型

```java
public class ConfidenceCalculator {

    /**
     * 综合置信度 = 模型置信度 × 引擎类型权重 × 一致性因子
     */
    public double calculate(ScoringContext ctx, ScoringResult result) {
        // 1. 基础模型置信度（AI 返回的）
        double modelConfidence = result.getRawConfidence();

        // 2. 引擎类型权重
        double engineWeight = switch (result.getEngineType()) {
            case "EXACT_MATCH" -> 1.0;
            case "KEYPOINT" -> 0.90;
            case "AI_ONLY" -> 0.75;
            case "HYBRID" -> 0.85;
            default -> 0.70;
        };

        // 3. 一致性因子（规则与AI评分的一致性）
        double consistencyFactor = 1.0;
        if (ctx.getRuleScore() != null && ctx.getAiScore() != null) {
            double diff = Math.abs(
                ctx.getRuleScore().getTotalScore() -
                ctx.getAiScore().getTotalScore()
            );
            consistencyFactor = Math.max(0.5, 1.0 - diff * 0.1);
        }

        // 4. 答案长度因子（极短或极长答案置信度降低）
        double lengthFactor = 1.0;
        int len = ctx.getNormalizedAnswerLength();
        if (len < 10) lengthFactor = 0.70;       // 过短，信息不足
        else if (len > 2000) lengthFactor = 0.85; // 过长，AI 可能遗漏信息

        // 5. 量规覆盖因子（量规维度越多，置信度越高）
        int dimCount = ctx.getRubric().getDimensions().size();
        double rubricFactor = Math.min(1.0, 0.80 + dimCount * 0.05);

        double finalConfidence = modelConfidence * engineWeight *
            consistencyFactor * lengthFactor * rubricFactor;

        return Math.round(Math.max(0, Math.min(1, finalConfidence)) * 100) / 100.0;
    }
}
```

### 8.2 复审路由规则

```java
public class ReviewRouter {

    // 复审触发条件
    private static final double HIGH_CONFIDENCE_THRESHOLD = 0.85;
    private static final double MEDIUM_CONFIDENCE_THRESHOLD = 0.60;
    private static final double SCORE_DIFF_SUSPICIOUS = 3.0;

    public ReviewDecision evaluate(ScoringResult result, ScoringContext ctx) {

        // 规则1：低置信度 → 必须复审
        if (result.getConfidence() < MEDIUM_CONFIDENCE_THRESHOLD) {
            return ReviewDecision.required("LOW_CONFIDENCE", calculatePriority(ctx));
        }

        // 规则2：满分但置信度不是最高 → 抽检
        if (result.getTotalScore() >= ctx.getMaxScore() &&
            result.getConfidence() < HIGH_CONFIDENCE_THRESHOLD) {
            return ReviewDecision.sampled("PERFECT_SCORE_LOW_CONFIDENCE");
        }

        // 规则3：零分 → 必须复审（防止误判）
        if (result.getTotalScore() == 0) {
            return ReviewDecision.required("ZERO_SCORE", calculatePriority(ctx));
        }

        // 规则4：答案异常（极短但高分，或极长但低分）
        if (isSuspiciousLengthScorePair(ctx, result)) {
            return ReviewDecision.required("SUSPICIOUS_PATTERN", 8);
        }

        // 规则5：中等置信度 → 按比例抽检（10%）
        if (result.getConfidence() < HIGH_CONFIDENCE_THRESHOLD) {
            if (ThreadLocalRandom.current().nextDouble() < 0.10) {
                return ReviewDecision.sampled("MEDIUM_CONFIDENCE_SAMPLING");
            }
            // 未抽中的标记"建议确认"但不强制
            return ReviewDecision.flagged("SUGGEST_CONFIRMATION");
        }

        // 规则6：考试场景下所有评分都需要抽检
        if (ctx.getScenario() == Scenario.EXAM && shouldSampleExam()) {
            return ReviewDecision.sampled("EXAM_ROUTINE_SAMPLING");
        }

        return ReviewDecision.pass();
    }

    private int calculatePriority(ScoringContext ctx) {
        int priority = 5; // 默认优先级
        if (ctx.getScenario() == Scenario.EXAM) priority += 3;
        if (ctx.getScenario() == Scenario.HOMEWORK) priority += 1;
        if (ctx.getStudentGrade() != null && ctx.getStudentGrade() <= 6) priority += 1;
        return Math.min(priority, 10);
    }
}
```

### 10.1 评分服务核心入口

```java
@Service
@Slf4j
public class SubjectiveScoringService {

    @Autowired private ScoringPreprocessor preprocessor;
    @Autowired private RuleBasedScorer ruleScorer;
    @Autowired private AIScoringEngine aiScorer;
    @Autowired private HybridScoringCoordinator coordinator;
    @Autowired private ConfidenceCalculator confidenceCalc;
    @Autowired private ReviewRouter reviewRouter;
    @Autowired private FeedbackGenerator feedbackGen;
    @Autowired private ScoringCacheService cacheService;
    @Autowired private ScoringRecordRepository recordRepo;
    @Autowired private ReviewQueueService reviewQueue;

    // 限流：每学生每天 200 次
    @RateLimit(key = "#req.studentId", limit = 200, window = "1d")
    public ScoringResult score(ScoringRequest req) {

        long startTime = System.currentTimeMillis();
        String requestId = req.getRequestId();

        try {
            // 0. 幂等检查
            Optional<ScoringResult> cached = cacheService.get(requestId);
            if (cached.isPresent()) {
                return cached.get();
            }

            // 1. 预处理
            NormalizedAnswer normalized = preprocessor.normalize(
                req.getStudentAnswer(), req.getContext().getSubject()
            );

            // 2. 答案指纹缓存命中检查
            Optional<CachedScore> fingerCache = cacheService.getByFingerprint(
                req.getQuestionId(), normalized.getHash()
            );
            if (fingerCache.isPresent()) {
                log.info("Cache hit by fingerprint for question {}", req.getQuestionId());
                return adaptCachedResult(fingerCache.get(), req);
            }

            // 3. 快速通道（规则评分）
            Optional<RuleScore> ruleResult = ruleScorer.evaluate(
                normalized, req.getRubric(), req.getOptions().getScoringStrictness()
            );

            // 4. 是否需要深度通道
            boolean needAI = shouldCallAI(ruleResult, req);
            Optional<AIScoringResult> aiResult = Optional.empty();

            if (needAI) {
                try {
                    ScoringContext ctx = buildContext(req, normalized, ruleResult);
                    aiResult = Optional.of(aiScorer.score(ctx));
                } catch (ScoringFallbackException e) {
                    log.warn("AI scoring fallback for request {}: {}", requestId, e.getMessage());
                    metrics.incrementFallback("AI_FAILED");
                }
            }

            // 5. 混合协调
            ScoringContext fullCtx = buildContext(req, normalized, ruleResult);
            ScoringResult result = coordinator.coordinate(ruleResult, aiResult, fullCtx);

            // 6. 置信度计算
            result.setConfidence(confidenceCalc.calculate(fullCtx, result));

            // 7. 复审路由
            ReviewDecision reviewDecision = reviewRouter.evaluate(result, fullCtx);
            result.setReviewRequired(reviewDecision.isRequired());
            if (reviewDecision.isRequired() || reviewDecision.isSampled()) {
                reviewQueue.enqueue(result, reviewDecision, fullCtx);
            }

            // 8. 反馈生成
            String feedback = feedbackGen.generate(
                result,
                req.getOptions().getFeedbackLevel(),
                getStudentProfile(req.getStudentId())
            );
            result.setOverallFeedback(feedback);

            // 9. 持久化
            result.setProcessingTimeMs(System.currentTimeMillis() - startTime);
            recordRepo.save(toEntity(result, req, normalized));
            cacheService.cache(req.getQuestionId(), normalized.getHash(), result);

            // 10. 异步：更新知识点掌握度（仅练习场景）
            if (req.getContext().getScenario() == Scenario.PRACTICE) {
                eventBus.publish(new ScoringCompletedEvent(result, req));
            }

            return result;

        } catch (Exception e) {
            log.error("Scoring failed for request {}", requestId, e);
            metrics.incrementError(e.getClass().getSimpleName());
            throw new ScoringException("评分服务异常: " + e.getMessage(), e);
        }
    }

    /**
     * 判断是否需要调用 AI 深度评分
     */
    private boolean shouldCallAI(Optional<RuleScore> ruleResult, ScoringRequest req) {
        // 无规则结果 → 必须 AI
        if (ruleResult.isEmpty()) return true;

        // 规则置信度足够高 → 可跳过 AI（成本优化）
        RuleScore rs = ruleResult.get();
        if (rs.getConfidence() >= 0.90 && "EXACT".equals(rs.getMatchType())) {
            return false;
        }

        // 论述题/实验探究题 → 必须 AI
        QuestionType qt = req.getContext().getQuestionType();
        if (qt == QuestionType.ESSAY_DISCUSSION ||
            qt == QuestionType.EXPERIMENT_INQUIRY) {
            return true;
        }

        // 其他情况：规则置信度 < 0.85 → 需要 AI
        return rs.getConfidence() < 0.85;
    }
}
```

```java
@Service
public class BatchScoringService {

    @Autowired private SubjectiveScoringService scoringService;
    @Autowired private BatchScoringRepository batchRepo;

    private static final int PARALLELISM = 5;        // 并行度
    private static final int BATCH_SIZE = 3;          // 每批发送数

    @Async("scoringExecutor")
    public void processBatch(BatchScoringTask task) {
        String batchId = task.getBatchId();

        // 按题目分组（同题共享 Prompt 上下文，降低成本）
        Map<String, List<Submission>> grouped = task.getSubmissions().stream()
            .collect(Collectors.groupingBy(Submission::getQuestionId));

        CompletableFuture.allOf(
            grouped.entrySet().stream()
                .map(entry -> CompletableFuture.runAsync(
                    () -> processSameQuestionBatch(
                        batchId,
                        entry.getKey(),
                        entry.getValue(),
                        task.getContext(),
                        task.getRubric()
                    ),
                    scoringExecutor
                ))
                .toArray(CompletableFuture[]::new)
        ).whenComplete((v, ex) -> {
            if (ex != null) {
                batchRepo.updateStatus(batchId, "FAILED", ex.getMessage());
            } else {
                batchRepo.updateStatus(batchId, "COMPLETED", null);
                notifyCallback(task.getCallbackUrl(), batchId);
            }
        });
    }

    /**
     * 同题批量处理：共享 Prompt 前缀，逐个评分
     * 利用 prompt caching 降低 token 消耗

    private void processSameQuestionBatch(

                AIScoringResult aiResult = aiScorer.scoreWithSharedPrefix(

            } catch (Exception e) {
                log.error("Batch scoring failed for student {} in batch {}",
                    sub.getStudentId(), batchId, e);
                // 记录失败，不中断批量
            }
        }
    }
}
```

## 11. 错误处理与降级策略

### 11.1 错误码定义

| 错误码 | HTTP | 描述 | 处理策略 |
|--------|------|------|----------|
| SCORING_001 | 400 | 请求参数缺失/格式错误 | 直接返回错误 |
| SCORING_002 | 422 | 答案内容无法解析（乱码/空内容） | 返回错误，提示重新输入 |
| SCORING_003 | 429 | 触发限流 | 返回 429 + Retry-After |
| SCORING_004 | 500 | AI 模型调用失败 | 降级到规则评分 |
| SCORING_005 | 500 | AI 响应解析失败 | 重试1次→降级 |
| SCORING_006 | 500 | 评分服务内部异常 | 记录日志+返回降级响应 |
| SCORING_007 | 503 | 维护中/服务不可用 | 返回 503 + 预计恢复时间 |

### 11.2 降级链路

```
正常流程：规则匹配 + AI评分 + 混合协调 + 反馈生成
    │
    ▼ (AI 不可用)
降级1：仅规则匹配评分 + 基础反馈
    │
    ▼ (规则也无结果)
降级2：返回"暂时无法自动评分" + 转人工评分队列
    │
    ▼ (服务完全不可用)
降级3：返回友好错误 + 建议稍后重试
```

```java
public class ScoringCostOptimizer {

    /**
     * 成本优化策略矩阵
     */
    /*
    ┌──────────────────┬───────────────────────────────────┬──────────────┐
    │ 策略             │ 实现                               │ 预期节省     │
    ├──────────────────┼───────────────────────────────────┼──────────────┤
    │ 答案指纹缓存     │ 相同答案直接返回历史评分            │ ~30% 调用量  │
    │ 模型分层         │ 简单题用轻量模型，难题用推理模型     │ ~40% 成本    │
    │ Prompt Cache     │ 批量评分共享 Prompt 前缀            │ ~50% token   │
    │ 规则优先         │ 能用规则解决的不调 AI               │ ~25% 调用量  │
    │ 离线预评分       │ 非实时场景异步处理，用便宜模型       │ ~60% 成本    │
    │ 答案聚类         │ 相似答案只评一次，其余复用           │ ~15% 调用量  │
    └──────────────────┴───────────────────────────────────┴──────────────┘
    */

    /**
     * 模型选择：根据复杂度选择模型等级
     */
    public ModelTier selectModelTier(ScoringContext ctx) {
        // 1. 答案长度 < 50 字 + 非论述题 → 轻量模型
        if (ctx.getAnswerLength() < 50 &&
            ctx.getQuestionType() != QuestionType.ESSAY_DISCUSSION) {
            return ModelTier.LITE; // 如 gpt-4o-mini
        }

        // 2. 数学/物理证明题 → 推理模型
        if ((ctx.getSubject() == Subject.MATH ||
             ctx.getSubject() == Subject.PHYSICS) &&
            ctx.getQuestionType() == QuestionType.PROOF_DERIVATION) {
            return ModelTier.REASONING; // 如 o1-mini
        }

        // 3. 实验探究题 → 标准模型
        if (ctx.getQuestionType() == QuestionType.EXPERIMENT_INQUIRY) {
            return ModelTier.STANDARD;
        }

        // 4. 默认 → 标准模型
        return ModelTier.STANDARD;
    }
}
```

```java
public class ScoringFeedbackPipeline {

    /**
     * 教师修正评分后，将样本写入训练数据集
     */
    @EventListener
    public void onTeacherOverride(TeacherOverrideEvent event) {
        ScoringRecord original = event.getOriginalRecord();
        TeacherCorrection correction = event.getCorrection();

        // 1. 记录差异
        double scoreDiff = correction.getFinalScore() - original.getTotalScore();
        feedbackMetrics.recordDiff(original.getSubject(), scoreDiff);

            .questionId(original.getQuestionId())
            .studentAnswer(original.getStudentAnswer())
            .aiScore(original.getTotalScore())

            .teacherScore(correction.getFinalScore())
            .teacherDimensions(correction.getDimensionScores())
            .teacherNotes(correction.getReviewNotes())
            .subject(original.getSubject())
            .gradeLevel(original.getGradeLevel())
            .promptVersion(original.getPromptVersion())
            .build();

        trainingSampleRepository.save(sample);

        // 3. 如果差异较大（>2分），触发 Prompt 审查
        if (Math.abs(scoreDiff) > 2.0) {
            alertService.notifyPromptTeam(
                original.getSubject(),
                original.getQuestionId(),
                scoreDiff
            );
        }

        // 4. 更新该题目的评分校准系数
        calibrationService.updateCalibration(
            original.getQuestionId(),
            original.getTotalScore(),
            correction.getFinalScore()
        );
    }
```
