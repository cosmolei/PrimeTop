# 服务端-学习内容跨模块去重与学生知识曝光度均衡调度引擎-详细设计

## 1. 概述

### 1.1 功能定位

在 PrimeTop 全学段 AI 辅助学习平台中，学生通过多种渠道获取知识：AI 智能辅导对话、同步课堂学习、练习测评、错题复习、个性化推荐 Feed、每日学习任务等。由于各模块独立运行，同一知识点可能在一天内通过多个模块重复推送给学生，导致学习体验冗余、效率下降、用户疲劳感增加。

本引擎作为**跨模块内容调度中间件**，统一追踪学生在各渠道的知识点曝光记录，在内容下发前执行去重判定与均衡调度，确保学生在适当时间窗口内不会重复接触已充分学习的内容，同时保证必要复习的间隔重复不受干扰。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 跨模块知识点曝光去重 | 同一知识点在冷却窗口内重复曝光率 < 5% |
| 曝光判定延迟 | P99 < 30ms（单次查询） |
| 调度决策吞吐 | ≥ 3000 QPS |
| 曝光数据最终一致 | 5 分钟内全模块同步 |
| 间隔重复保护 | 不影响基于遗忘曲线的复习调度 |

### 1.3 适用范围

- **覆盖模块**：AI 智能辅导、同步课堂、练习测评、错题复习、首页推荐、每日任务、考点梳理
- **覆盖学段**：全学段（幼儿/小学/初中/高中）
- **不覆盖**：间隔重复算法（SR）驱动的主动复习——该类复习由遗忘曲线引擎独立调度，本引擎仅标记不干预

### 1.4 术语定义

| 术语 | 定义 |
| --- | --- |
| 知识曝光 | 学生通过任何模块接触到某知识点的教学或练习内容 |
| 冷却窗口 | 某知识点在曝光后的一段时间内不应再次主动推送 |
| 曝光深度 | 曝光的强度等级（浏览/学习/练习/掌握） |
| 曝光来源 | 触发曝光的功能模块 |
| 均衡因子 | 各知识点在推荐池中的权重调节系数 |
| SR 豁免 | 基于间隔重复算法触发的复习请求不受去重约束 |

### 2.3 与其他系统的关系

| 系统 | 关系 |
| --- | --- |
| 间隔重复算法引擎 | SR 触发的复习请求携带 `sr_exempt=true`，本引擎放行不拦截 |
| 个性化推荐引擎 | 推荐候选生成后，调用本引擎进行曝光过滤 |
| 学习规划服务 | 每日任务编排时，调用本引擎进行跨模块去重 |
| AI 辅导对话 | AI 对话涉及的知识点在对话开始时上报曝光 |
| 练习测评服务 | 答题完成后上报知识点曝光（含正确率作为深度） |
| 错题服务 | 错题复习是 SR 驱动，默认豁免；手动浏览触发曝光 |
| 学习行为事件流 | 异步消费行为事件，更新曝光记录 |

### 3.2 Redis 数据结构

#### 3.2.1 曝光索引 — Sorted Set

按用户维度缓存最近 N 天的知识点曝光索引，用于快速去重查询。

```
Key:  exp:idx:{userId}:{yyyymmdd}
Type: ZSET
Member: {knowledgePointId}
Score: {timestamp}

# TTL: 7天（7天后自动过期，由MySQL持久化接管）
# 查询时使用 ZSCORE 判断是否已曝光
# 范围查询使用 ZRANGEBYSCORE 按时间范围过滤
```

#### 3.2.2 曝光详情 — Hash

存储单次曝光的关键详情，用于快速判定冷却规则。

```
Key:  exp:dtl:{userId}:{knowledgePointId}
Type: HASH
Fields:
    last_exposed_at     — 最后曝光时间戳
    last_module         — 最后曝光模块
    last_depth          — 最后曝光深度
    exposure_count_today— 今日曝光次数
    first_exposed_today — 今日首次曝光时间戳
    sr_exempt_until     — SR豁免截止时间(如有)

# TTL: 与索引同步（7天）
```

#### 3.2.3 冷却判定缓存 — String

缓存去重判定结果，减少重复计算。

```
Key:  exp:cool:{userId}:{knowledgePointId}:{targetModule}
Type: STRING
Value: "BLOCK" | "PASS" | {alternativeKPId}
TTL:  对应冷却时长的 1/3（最长 2 小时）
```

#### 3.2.4 学科曝光均衡计数器 — Hash

按学科统计当日各知识点曝光次数，用于均衡调度。

```
Key:  exp:bal:{userId}:{yyyymmdd}
Type: HASH
Field: {subjectCode}:{knowledgePointId}
Value: 曝光次数

# TTL: 48小时
```

```java
/**
 * 知识曝光事件
 */
@Data
@Builder
public class KnowledgeExposureEvent {
    private Long userId;
    private String knowledgePointId;
    private String subjectCode;
    private ModuleSource moduleSource;      // AI_TUTOR, SYNC_CLASSROOM, ...
    private ExposureDepth exposureDepth;    // BROWSE, STUDY, PRACTICE, MASTER
    private ExposureType exposureType;      // ACTIVE, PASSIVE, SR_REVIEW
    private String contentId;
    private String sessionId;
    private BigDecimal masteryIndicator;    // 掌握度(0-100)
    private Integer exposureDuration;       // 秒
    private LocalDateTime exposedAt;
}

/**
 * 曝光深度枚举
 */
public enum ExposureDepth {
    BROWSE(1,    "浏览"),    // 信息流卡片、推荐预览
    STUDY(2,     "学习"),    // 知识讲解、视频学习、教材阅读
    PRACTICE(3,  "练习"),    // 做题、口语练习、作文写作
    MASTER(4,    "掌握");    // 练习正确率≥80%、考核通过

    private final int level;
    private final String label;
}

/**
 * 曝光来源模块枚举
 */
public enum ModuleSource {
    AI_TUTOR("AI智能辅导"),
    SYNC_CLASSROOM("同步课堂"),
    PRACTICE("练习测评"),
    MISTAKE_REVIEW("错题复习"),
    FEED("首页推荐"),
    TASK("每日任务"),
    EXAM_PREP("考点梳理");

    private final String label;
}

/**
 * 去重判定请求
 */
@Data
@Builder
public class DedupCheckRequest {
    private Long userId;
    private String knowledgePointId;
    private String subjectCode;
    private ModuleSource targetModule;       // 目标推送模块
    private ExposureType exposureType;       // 主动 or 被动 or SR
    private boolean srExempt;                // 间隔复习豁免标记
}

/**
 * 去重判定结果
 */
@Data
@Builder
public class DedupCheckResult {
    private DedupDecision decision;          // PASS, BLOCK, REPLACE
    private String reason;                   // 判定原因
    private String originalKnowledgePointId;
    private String alternativeKnowledgePointId; // 替换推荐的知识点
    private LocalDateTime cooldownExpiresAt;     // 冷却到期时间
    private int confidenceScore;                 // 置信度(0-100)

    public enum DedupDecision {
        PASS,       // 放行，允许推送
        BLOCK,      // 拦截，不允许推送
        REPLACE     // 替换为其他知识点
    }
}
```

## 5. 核心算法设计

### 5.1 去重判定算法

```
输入: DedupCheckRequest
输出: DedupCheckResult

function checkDedup(request):
    // 1. SR豁免检查
    if request.srExempt:
        return PASS("SR_REVIEW_EXEMPT")

    // 2. 查询冷却缓存（快速路径）
    cachedResult = cache.get(coolKey(request))
    if cachedResult != null:
        return cachedResult

    // 3. 查询Redis曝光索引
    exposureDetail = redis.hgetall(dtlKey(request))
    
    if exposureDetail == null:
        // 无曝光记录，直接放行
        result = PASS("NO_PRIOR_EXPOSURE")
        cache.set(coolKey(request), result, ttl=300)
        return result

    // 4. 加载匹配的冷却规则
    rules = loadCoolingRules(
        subjectCode = request.subjectCode,
        sourceModule = exposureDetail.last_module,
        targetModule = request.targetModule,
        exposureDepth = exposureDetail.last_depth
    )

    // 5. 规则匹配与冷却计算
    for rule in rules.sortByPriorityDesc():
        if matches(rule, exposureDetail, request):
            elapsedMinutes = now() - exposureDetail.last_exposed_at
            if elapsedMinutes < rule.coolingMinutes:
                remaining = rule.coolingMinutes - elapsedMinutes
                // 尝试查找替代知识点
                alternative = findAlternativeKP(
                    request.userId, 
                    request.subjectCode, 
                    request.knowledgePointId
                )
                if alternative != null:
                    result = REPLACE(alternative, remaining)
                else:
                    result = BLOCK(remaining)
                cache.set(coolKey(request), result, ttl=remaining/3)
                return result

    // 6. 所有规则均不匹配或已过冷却期
    result = PASS("COOLING_EXPIRED")
    cache.set(coolKey(request), result, ttl=300)
    return result
```

### 5.2 替代知识点查找算法

```
function findAlternativeKP(userId, subjectCode, excludeKPId):
    // 从该学科的知识点池中查找替代
    // 优先级：薄弱点 > 未学 > 学过但未掌握 > 已掌握
    
    // 1. 获取用户在该学科的知识掌握度
    masteryMap = getMasterySnapshot(userId, subjectCode)
    
    // 2. 获取用户今日已曝光知识点集合
    exposedToday = getTodayExposureSet(userId, subjectCode)
    
    // 3. 候选筛选
    candidates = knowledgePointService.findBySubject(subjectCode)
        .filter(kp => kp.id != excludeKPId)
        .filter(kp => kp.id not in exposedToday)
        .filter(kp => kp.is_published == true)
    
    if candidates.isEmpty():
        return null
    
    // 4. 评分排序
    scored = candidates.map(kp => {
        mastery = masteryMap.getOrDefault(kp.id, 0)
        score = calculateAlternativeScore(mastery, kp.importance, kp.difficulty)
        return (kp, score)
    })
    
    // 5. 取最高分（加随机扰动避免固定推荐）
    best = scored.sortByScoreDesc()
        .take(5)
        .weightedRandomPick(weightFn = s => s ** 2)
    
    return best.id
```

**替代评分公式：**

```
score = w1 * (1 - mastery/100)      // 掌握度越低优先级越高
      + w2 * kp.importance           // 知识点重要性
      + w3 * (1 - kp.difficulty/5)   // 难度适中优先
      + w4 * recencyDecay(kp)        // 越久没学越优先

默认权重: w1=0.4, w2=0.3, w3=0.1, w4=0.2
```

### 5.3 学科曝光均衡度计算

```
function calculateSubjectBalance(userId, subjectCode, dateRange):
    // 计算学科内知识点曝光分布的均衡度
    // 使用归一化熵作为均衡度指标
    
    exposures = getExposureCounts(userId, subjectCode, dateRange)
    total = sum(exposures.values)
    
    if total == 0:
        return 1.0  // 无曝光，视为均衡
    
    probabilities = exposures.values.map(v => v / total)
    entropy = -sum(p * log2(p) for p in probabilities)
    maxEntropy = log2(len(exposures))
    
    balanceScore = entropy / maxEntropy  // 0=极端不均衡, 1=完全均衡
    
    return balanceScore
```

**均衡度阈值：**
| 均衡度 | 状态 | 调度策略 |
| --- | --- | --- |
| ≥ 0.7 | 均衡 | 正常调度 |
| 0.4 ~ 0.7 | 轻度不均衡 | 提升低曝光知识点的推荐权重 |
| < 0.4 | 严重不均衡 | 强制注入未曝光知识点，抑制高频知识点 |

```java
/**
 * 跨模块去重判定服务
 */
@Service
@Slf4j
public class ExposureDedupService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Autowired
    private ExposureCoolingRuleMapper ruleMapper;
    
    @Autowired
    private KnowledgePointService kpService;
    
    @Autowired
    private MasterySnapshotService masteryService;
    
    private static final String COOL_CACHE_PREFIX = "exp:cool:";
    private static final String DTL_CACHE_PREFIX = "exp:dtl:";
    private static final String IDX_CACHE_PREFIX = "exp:idx:";
    private static final int COOL_CACHE_TTL_SECONDS = 300;
    
    /**
     * 单知识点去重判定
     */
    public DedupCheckResult check(DedupCheckRequest request) {
        // 1. SR豁免
        if (request.isSrExempt()) {
            return DedupCheckResult.builder()
                .decision(DedupCheckResult.DedupDecision.PASS)
                .reason("SR_REVIEW_EXEMPT")
                .confidenceScore(100)
                .build();
        }
        
        // 2. 快速缓存路径
        String coolKey = buildCoolKey(request);
        String cached = redisTemplate.opsForValue().get(coolKey);
        if (cached != null) {
            return deserializeResult(cached, request.getKnowledgePointId());
        }
        
        // 3. 查询曝光详情
        String dtlKey = buildDtlKey(request.getUserId(), request.getKnowledgePointId());
        Map<Object, Object> exposureDetail = redisTemplate.opsForHash().entries(dtlKey);
        
        if (exposureDetail.isEmpty()) {
            DedupCheckResult result = DedupCheckResult.builder()
                .decision(DedupCheckResult.DedupDecision.PASS)
                .reason("NO_PRIOR_EXPOSURE")
                .confidenceScore(100)
                .originalKnowledgePointId(request.getKnowledgePointId())
                .build();
            cacheResult(coolKey, result, COOL_CACHE_TTL_SECONDS);
            return result;
        }
        
        // 4. 加载冷却规则
        String lastModule = (String) exposureDetail.get("last_module");
        int lastDepth = Integer.parseInt((String) exposureDetail.get("last_depth"));
        long lastExposedAt = Long.parseLong((String) exposureDetail.get("last_exposed_at"));
        
        List<ExposureCoolingRule> rules = ruleMapper.findMatchingRules(
            request.getSubjectCode(),
            lastModule,
            request.getTargetModule().name(),
            lastDepth
        );
        
        // 5. 规则匹配
        long nowEpochSeconds = Instant.now().getEpochSecond();
        long elapsedMinutes = (nowEpochSeconds - lastExposedAt) / 60;
        
        for (ExposureCoolingRule rule : rules) {
            if (elapsedMinutes < rule.getCoolingMinutes()) {
                int remainingMinutes = (int) (rule.getCoolingMinutes() - elapsedMinutes);
                
                // 尝试查找替代知识点
                String alternativeKP = findAlternativeKnowledgePoint(
                    request.getUserId(),
                    request.getSubjectCode(),
                    request.getKnowledgePointId()
                );
                
                DedupCheckResult result = DedupCheckResult.builder()
                    .decision(alternativeKP != null ? 
                        DedupCheckResult.DedupDecision.REPLACE : 
                        DedupCheckResult.DedupDecision.BLOCK)
                    .reason(String.format("COOLING_ACTIVE: 知识点[%s]在%d分钟前被[%s]模块曝光，冷却中(剩余%d分钟)",
                        request.getKnowledgePointId(), elapsedMinutes, lastModule, remainingMinutes))
                    .originalKnowledgePointId(request.getKnowledgePointId())
                    .alternativeKnowledgePointId(alternativeKP)
                    .cooldownExpiresAt(LocalDateTime.now().plusMinutes(remainingMinutes))
                    .confidenceScore(calculateConfidence(rule, elapsedMinutes))
                    .build();
                
                int cacheTtl = Math.min(remainingMinutes * 60 / 3, 7200);
                cacheResult(coolKey, result, cacheTtl);
                return result;
            }
        }
        
        // 6. 冷却已过
        DedupCheckResult result = DedupCheckResult.builder()
            .decision(DedupCheckResult.DedupDecision.PASS)
            .reason("COOLING_EXPIRED")
            .confidenceScore(95)
            .originalKnowledgePointId(request.getKnowledgePointId())
            .build();
        cacheResult(coolKey, result, COOL_CACHE_TTL_SECONDS);
        return result;
    }
    
    /**
     * 批量去重判定（用于推荐列表过滤）
     */
    public BatchDedupResult batchCheck(BatchDedupRequest request) {
        // 使用 Redis Pipeline 批量查询，减少网络往返
        String userId = String.valueOf(request.getUserId());
        List<KPRef> knowledgePoints = request.getKnowledgePoints();
        
        // 1. 批量查询所有知识点的曝光详情
        List<String> dtlKeys = knowledgePoints.stream()
            .map(kp -> buildDtlKey(request.getUserId(), kp.getId()))
            .collect(Collectors.toList());
        
        List<Object> results = redisTemplate.executePipelined((RedisCallback<?>) connection -> {
            StringRedisConnection conn = (StringRedisConnection) connection;
            for (String key : dtlKeys) {
                conn.hgetAll(key);
            }
            return null;
        });
        
        // 2. 逐个判定并收集结果
        List<DedupCheckResult> checkResults = new ArrayList<>();
        for (int i = 0; i < knowledgePoints.size(); i++) {
            KPRef kp = knowledgePoints.get(i);
            @SuppressWarnings("unchecked")
            Map<String, String> detail = (Map<String, String>) results.get(i);
            
            DedupCheckResult result = checkInternal(
                request.getUserId(), kp, request.getTargetModule(), 
                request.getExposureType(), detail
            );
            checkResults.add(result);
        }
        
        // 3. 生成推荐排序（通过的排前面）
        List<String> recommendedOrder = checkResults.stream()
            .filter(r -> r.getDecision() == DedupCheckResult.DedupDecision.PASS)
            .map(DedupCheckResult::getOriginalKnowledgePointId)
            .collect(Collectors.toList());
        
        return BatchDedupResult.builder()
            .results(checkResults)
            .recommendedOrder(recommendedOrder)
            .build();
    }
    
    /**
     * 查找替代知识点
     */
    private String findAlternativeKnowledgePoint(Long userId, String subjectCode, String excludeKPId) {
        // 1. 获取掌握度快照
        Map<String, Double> masteryMap = masteryService.getMasterySnapshot(userId, subjectCode);
        
        // 2. 获取今日已曝光集合
        String today = LocalDate.now().format(DateTimeFormatter.BASIC_ISO_DATE);
        String balKey = String.format("exp:bal:%d:%s", userId, today);
        Set<String> exposedToday = redisTemplate.opsForHash()
            .entries(balKey)
            .keySet()
            .stream()
            .map(k -> ((String) k).split(":")[1])
            .collect(Collectors.toSet());
        
        // 3. 候选筛选与评分
        List<KnowledgePoint> candidates = kpService.findBySubject(subjectCode);
        
        List<ScoredKP> scored = candidates.stream()
            .filter(kp -> !kp.getId().equals(excludeKPId))
            .filter(kp -> !exposedToday.contains(kp.getId()))
            .filter(KnowledgePoint::isPublished)
            .map(kp -> {
                double mastery = masteryMap.getOrDefault(kp.getId(), 0.0);
                double score = calculateAlternativeScore(mastery, kp);
                return new ScoredKP(kp.getId(), score);
            })
            .sorted(Comparator.comparingDouble(ScoredKP::getScore).reversed())
            .limit(5)
            .collect(Collectors.toList());
        
        if (scored.isEmpty()) {
            return null;
        }
        
        // 4. 加权随机选择（避免固定推荐）
        return weightedRandomPick(scored);
    }
    
    /**
     * 替代评分计算
     */
    private double calculateAlternativeScore(double mastery, KnowledgePoint kp) {
        double w1 = 0.4;  // 掌握度权重
        double w2 = 0.3;  // 重要性权重
        double w3 = 0.1;  // 难度适中权重
        double w4 = 0.2;  // 近期未学权重
        
        double masteryScore = 1.0 - mastery / 100.0;
        double importanceScore = kp.getImportanceLevel() / 5.0;
        double difficultyScore = 1.0 - Math.abs(kp.getDifficulty() - 3.0) / 5.0;
        double recencyScore = kp.getDaysSinceLastStudy() != null ? 
            Math.min(kp.getDaysSinceLastStudy() / 30.0, 1.0) : 1.0;
        
        return w1 * masteryScore + w2 * importanceScore 
             + w3 * difficultyScore + w4 * recencyScore;
    }
    
    private String buildCoolKey(DedupCheckRequest req) {
        return String.format("%s%d:%s:%s", 
            COOL_CACHE_PREFIX, req.getUserId(), 
            req.getKnowledgePointId(), req.getTargetModule());
    }
    
    private String buildDtlKey(Long userId, String kpId) {
        return String.format("%s%d:%s", DTL_CACHE_PREFIX, userId, kpId);
    }
    
    private void cacheResult(String key, DedupCheckResult result, int ttlSeconds) {
        try {
            redisTemplate.opsForValue().set(key, serializeResult(result), ttlSeconds, TimeUnit.SECONDS);
        } catch (Exception e) {
            log.warn("缓存去重结果失败, key={}", key, e);
        }
    }
    
    private int calculateConfidence(ExposureCoolingRule rule, long elapsedMinutes) {
        // 冷却时间越接近过期，置信度越低
        double ratio = (double) elapsedMinutes / rule.getCoolingMinutes();
        return (int) Math.max(60, 100 - ratio * 40);
    }
    
    @Data
    @AllArgsConstructor
    private static class ScoredKP {
        private String kpId;
        private double score;
    }
}
```

```java
/**
 * 曝光事件上报服务
 */
@Service
@Slf4j
public class ExposureReportService {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Autowired
    private KnowledgeExposureLogMapper exposureLogMapper;
    
    @Autowired
    @Qualifier("exposureTaskExecutor")
    private ThreadPoolTaskExecutor taskExecutor;
    
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    /**
     * 上报单条曝光事件
     */
    @Transactional
    public ExposureReportResponse report(KnowledgeExposureEvent event) {
        // 1. 同步更新Redis索引（保证实时性）
        updateRedisIndex(event);
        
        // 2. 异步写入MySQL
        taskExecutor.submit(() -> {
            try {
                KnowledgeExposureLog logEntry = convertToLog(event);
                exposureLogMapper.insert(logEntry);
            } catch (DuplicateKeyException e) {
                // 唯一键冲突 = 同一session同一KP同一模块已记录，忽略
                log.debug("曝光记录已存在，跳过: user={}, kp={}, module={}", 
                    event.getUserId(), event.getKnowledgePointId(), event.getModuleSource());
            } catch (Exception e) {
                log.error("写入曝光日志失败", e);
                // 失败不阻断主流程，由补偿任务重试
            }
        });
        
        // 3. 发布曝光事件（供其他模块订阅）
        eventPublisher.publishEvent(new ExposureRecordedEvent(event));
        
        // 4. 检查是否过度曝光
        int todayCount = getTodayExposureCount(event.getUserId(), event.getKnowledgePointId());
        boolean overExposed = todayCount >= 4;  // 同一知识点同一天超过4次曝光
        
        return ExposureReportResponse.builder()
            .recorded(true)
            .todayExposureCount(todayCount)
            .isOverExposed(overExposed)
            .build();
    }
    
    /**
     * 更新Redis曝光索引
     */
    private void updateRedisIndex(KnowledgeExposureEvent event) {
        Long userId = event.getUserId();
        String kpId = event.getKnowledgePointId();
        long timestamp = System.currentTimeMillis() / 1000;
        String today = LocalDate.now().format(DateTimeFormatter.BASIC_ISO_DATE);
        
        // 1. 更新Sorted Set索引
        String idxKey = String.format("%s%d:%s", IDX_CACHE_PREFIX, userId, today);
        redisTemplate.opsForZSet().add(idxKey, kpId, timestamp);
        redisTemplate.expire(idxKey, 7, TimeUnit.DAYS);
        
        // 2. 更新曝光详情Hash
        String dtlKey = String.format("%s%d:%s", DTL_CACHE_PREFIX, userId, kpId);
        Map<String, String> detail = new HashMap<>();
        detail.put("last_exposed_at", String.valueOf(timestamp));
        detail.put("last_module", event.getModuleSource().name());
        detail.put("last_depth", String.valueOf(event.getExposureDepth().getLevel()));
        
        // 更新今日曝光次数
        String countKey = "exposure_count_today";
        String currentCountStr = (String) redisTemplate.opsForHash().get(dtlKey, countKey);
        int currentCount = currentCountStr != null ? Integer.parseInt(currentCountStr) : 0;
        
        // 如果今天是新的一天，重置计数
        String firstExposedKey = "first_exposed_today";
        String firstExposedStr = (String) redisTemplate.opsForHash().get(dtlKey, firstExposedKey);
        if (firstExposedStr != null) {
            long firstExposed = Long.parseLong(firstExposedStr);
            if (!isSameDay(firstExposed, timestamp)) {
                currentCount = 0;  // 新的一天，重置
            }
        } else {
            detail.put(firstExposedKey, String.valueOf(timestamp));
        }
        
        detail.put(countKey, String.valueOf(currentCount + 1));
        redisTemplate.opsForHash().putAll(dtlKey, detail);
        redisTemplate.expire(dtlKey, 7, TimeUnit.DAYS);
        
        // 3. 更新学科均衡计数器
        String balKey = String.format("exp:bal:%d:%s", userId, today);
        String balField = String.format("%s:%s", event.getSubjectCode(), kpId);
        redisTemplate.opsForHash().increment(balKey, balField, 1);
        redisTemplate.expire(balKey, 48, TimeUnit.HOURS);
        
        // 4. 使冷却缓存失效
        String coolPattern = String.format("%s%d:%s:*", COOL_CACHE_PREFIX, userId, kpId);
        Set<String> coolKeys = redisTemplate.keys(coolPattern);
        if (coolKeys != null && !coolKeys.isEmpty()) {
            redisTemplate.delete(coolKeys);
        }
    }
    
    private boolean isSameDay(long epochSec1, long epochSec2) {
        LocalDate d1 = Instant.ofEpochSecond(epochSec1)
            .atZone(ZoneId.systemDefault()).toLocalDate();
        LocalDate d2 = Instant.ofEpochSecond(epochSec2)
            .atZone(ZoneId.systemDefault()).toLocalDate();
        return d1.equals(d2);
    }
    
    private int getTodayExposureCount(Long userId, String kpId) {
        String dtlKey = String.format("%s%d:%s", DTL_CACHE_PREFIX, userId, kpId);
        String count = (String) redisTemplate.opsForHash().get(dtlKey, "exposure_count_today");
        return count != null ? Integer.parseInt(count) : 0;
    }
    
    private KnowledgeExposureLog convertToLog(KnowledgeExposureEvent event) {
        KnowledgeExposureLog log = new KnowledgeExposureLog();
        log.setUserId(event.getUserId());
        log.setKnowledgePointId(event.getKnowledgePointId());
        log.setSubjectCode(event.getSubjectCode());
        log.setModuleSource(event.getModuleSource().name());
        log.setExposureDepth(event.getExposureDepth().getLevel());
        log.setExposureType(event.getExposureType().name());
        log.setContentId(event.getContentId());
        log.setSessionId(event.getSessionId());
        log.setMasteryIndicator(event.getMasteryIndicator());
        log.setExposureDuration(event.getExposureDuration());
        log.setExposedAt(event.getExposedAt() != null ? event.getExposedAt() : LocalDateTime.now());
        return log;
    }
```

```java
/**
 * 异步消费学习行为事件，自动记录曝光

@Component
@Slf4j
public class ExposureBehaviorConsumer {
    
    @Autowired
    private ExposureReportService exposureReportService;
    
    @Autowired
    private KnowledgePointResolver kpResolver;
    
    /**
     * 消费学习行为事件流
     */
    @KafkaListener(
        topics = "${exposure.behavior-topic:learning-behavior-events}",
        groupId = "${exposure.consumer-group:exposure-service}"
    )
    public void onBehaviorEvent(LearningBehaviorEvent event, Acknowledgment ack) {
        try {
            // 从行为事件中提取知识点
            List<String> knowledgePointIds = kpResolver.resolveFromBehavior(event);
            
            if (knowledgePointIds.isEmpty()) {
                ack.acknowledge();
                return;
            }
            
            // 根据行为类型确定曝光深度
            ExposureDepth depth = determineDepth(event.getBehaviorType());
            ModuleSource module = mapToModuleSource(event.getSourceModule());
            
            // 逐个上报曝光
            for (String kpId : knowledgePointIds) {
                KnowledgeExposureEvent exposureEvent = KnowledgeExposureEvent.builder()
                    .userId(event.getUserId())
                    .knowledgePointId(kpId)
                    .subjectCode(event.getSubjectCode())
                    .moduleSource(module)
                    .exposureDepth(depth)
                    .exposureType(ExposureType.PASSIVE)
                    .sessionId(event.getSessionId())
                    .masteryIndicator(event.getMasteryIndicator())
                    .exposureDuration(event.getDurationSeconds())
                    .exposedAt(event.getBehaviorTime())
                    .build();
                
                exposureReportService.report(exposureEvent);
            }
            
            ack.acknowledge();
        } catch (Exception e) {
            log.error("消费行为事件失败: event={}", event, e);
            // 不ack，让Kafka重试
        }
    }
    
    private ExposureDepth determineDepth(BehaviorType behaviorType) {
        switch (behaviorType) {
            case VIEW_CARD:
            case SCROLL_FEED:
                return ExposureDepth.BROWSE;
            case READ_LESSON:
            case WATCH_VIDEO:
            case AI_CONVERSATION:
                return ExposureDepth.STUDY;
            case ANSWER_QUESTION:
            case SUBMIT_EXERCISE:
            case ORAL_PRACTICE:
                return ExposureDepth.PRACTICE;
            case PASS_EXERCISE:
                return ExposureDepth.MASTER;
            default:
                return ExposureDepth.BROWSE;
        }
    }
    
    private ModuleSource mapToModuleSource(String source) {
        return ModuleSource.valueOf(source);
    }
}
```

### 7.4 曝光均衡调度过滤器（推荐系统集成）

```java
/**
 * 推荐列表曝光过滤器
 * 在推荐引擎生成候选后、排序前进行曝光去重过滤
 */
@Component
@Slf4j
public class ExposureRecommendationFilter implements RecommendationFilter {
    
    @Autowired
    private ExposureDedupService dedupService;
    
    @Autowired
    private ExposureQueryService exposureQueryService;
    
    @Override
    public String getFilterName() {
        return "EXPOSURE_DEDUP_FILTER";
    }
    
    @Override
    public int getOrder() {
        return 60;  // 在粗排之后、精排之前执行
    }
    
    /**
     * 过滤推荐候选列表
     */
    @Override
    public List<RecommendationItem> filter(RecommendationContext context, 
                                            List<RecommendationItem> candidates) {
        if (candidates.isEmpty()) {
            return candidates;
        }
        
        Long userId = context.getUserId();
        
        // 1. 构建批量去重请求
        List<KPRef> kpRefs = candidates.stream()
            .map(item -> new KPRef(item.getKnowledgePointId(), item.getSubjectCode()))
            .distinct()
            .collect(Collectors.toList());
        
        BatchDedupRequest batchReq = BatchDedupRequest.builder()
            .userId(userId)
            .targetModule(ModuleSource.FEED)
            .exposureType(ExposureType.PASSIVE)
            .knowledgePoints(kpRefs)
            .build();
        
        // 2. 批量去重判定
        BatchDedupResult dedupResult = dedupService.batchCheck(batchReq);
        
        // 3. 过滤与替换
        Map<String, DedupCheckResult> resultMap = dedupResult.getResults().stream()
            .collect(Collectors.toMap(
                DedupCheckResult::getOriginalKnowledgePointId,
                r -> r,
                (a, b) -> a
            ));
        
        List<RecommendationItem> filtered = new ArrayList<>();
        Set<String> addedKPIds = new HashSet<>();
        
        for (RecommendationItem item : candidates) {
            DedupCheckResult result = resultMap.get(item.getKnowledgePointId());
            
            if (result == null || result.getDecision() == DedupCheckResult.DedupDecision.PASS) {
                filtered.add(item);
                addedKPIds.add(item.getKnowledgePointId());
            } else if (result.getDecision() == DedupCheckResult.DedupDecision.REPLACE
                       && result.getAlternativeKnowledgePointId() != null
                       && !addedKPIds.contains(result.getAlternativeKnowledgePointId())) {
                // 用替代知识点创建新推荐项
                RecommendationItem replacement = RecommendationItem.builder()
                    .knowledgePointId(result.getAlternativeKnowledgePointId())
                    .subjectCode(item.getSubjectCode())
                    .contentType(item.getContentType())
                    .score(item.getScore() * 0.85)  // 替换项降权
                    .source("EXPOSURE_REPLACE")
                    .build();
                filtered.add(replacement);
                addedKPIds.add(result.getAlternativeKnowledgePointId());
            }
            // BLOCK的项直接丢弃
        }
        
        // 4. 学科均衡度检查与调整
        double balanceScore = exposureQueryService
            .calculateSubjectBalance(userId, context.getSubjectCode(), 7);
        
        if (balanceScore < 0.4) {
            // 严重不均衡，强制注入未曝光知识点
            List<RecommendationItem> injected = injectUnderExposedItems(
                userId, context.getSubjectCode(), filtered, 3
            );
            filtered.addAll(injected);
        }
        
        log.debug("曝光过滤: 输入{}项, 输出{}项, 均衡度={}", 
            candidates.size(), filtered.size(), balanceScore);
        
        return filtered;
    }
    
    /**
     * 注入低曝光知识点
     */
    private List<RecommendationItem> injectUnderExposedItems(
            Long userId, String subjectCode, 
            List<RecommendationItem> existing, int injectCount) {
        Set<String> existingKPs = existing.stream()
            .map(RecommendationItem::getKnowledgePointId)
            .collect(Collectors.toSet());
        
        List<String> underExposed = exposureQueryService
            .findUnderExposedKnowledgePoints(userId, subjectCode, 7, injectCount * 3);
        
        return underExposed.stream()
            .filter(kpId -> !existingKPs.contains(kpId))
            .limit(injectCount)
            .map(kpId -> RecommendationItem.builder()
                .knowledgePointId(kpId)
                .subjectCode(subjectCode)
                .contentType("KNOWLEDGE_REVIEW")
                .score(0.5)  // 适中分数
                .source("BALANCE_INJECT")
                .build())
            .collect(Collectors.toList());
    }
}
```

```java
    @Autowired
    private KnowledgeExposureSummaryMapper summaryMapper;
    
    /**
     * 每日02:00执行
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void aggregateDailySummary() {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        log.info("开始执行曝光日汇总, date={}", yesterday);
        
        try {
            // 批量聚合写入
            int batchSize = 5000;
            int offset = 0;
            int totalProcessed = 0;
            
            while (true) {
                List<KnowledgeExposureSummary> summaries = 
                    logMapper.aggregateDailySummary(yesterday, offset, batchSize);
                
                if (summaries.isEmpty()) {
                    break;
                }
                
                // 标记过度曝光
                summaries.forEach(s -> {
                    s.setIsOverExposed(s.getExposureCount() >= 4);
                });
                
                // 批量upsert
                summaryMapper.batchUpsert(summaries);
                
                totalProcessed += summaries.size();
                offset += batchSize;
            }
            
            log.info("曝光日汇总完成, date={}, processed={}", yesterday, totalProcessed);
            
        } catch (Exception e) {
            log.error("曝光日汇总失败, date={}", yesterday, e);
            // 发送告警
            alertService.sendCritical("曝光日汇总失败: " + e.getMessage());
        }
    }
```

```java
/**
 * 去重判定降级处理器
 */
@Component
@Slf4j
public class DedupFallbackHandler {
    
    @Autowired
    private KnowledgeExposureLogMapper logMapper;
    
    /**
     * Redis不可用时的MySQL降级查询
     */
    public DedupCheckResult fallbackCheckMySQL(DedupCheckRequest request) {
        try {
            // 查询最近一次曝光记录
            KnowledgeExposureLog lastExposure = logMapper.findLatestExposure(
                request.getUserId(), 
                request.getKnowledgePointId()
            );
            
            if (lastExposure == null) {
                return DedupCheckResult.builder()
                    .decision(DedupCheckResult.DedupDecision.PASS)
                    .reason("FALLBACK: NO_EXPOSURE_RECORD")
                    .confidenceScore(70)
                    .build();
            }
            
            // 使用默认冷却时间（2小时）
            long elapsedMinutes = Duration.between(
                lastExposure.getExposedAt(), 
                LocalDateTime.now()
            ).toMinutes();
            
            if (elapsedMinutes < 120) {
                return DedupCheckResult.builder()
                    .decision(DedupCheckResult.DedupDecision.BLOCK)
                    .reason("FALLBACK: DEFAULT_COOLING")
                    .cooldownExpiresAt(LocalDateTime.now().plusMinutes(120 - elapsedMinutes))
                    .confidenceScore(60)
                    .build();
            }
            
            return DedupCheckResult.builder()
                .decision(DedupCheckResult.DedupDecision.PASS)
                .reason("FALLBACK: COOLING_EXPIRED")
                .confidenceScore(70)
                .build();
            
        } catch (Exception e) {
            log.error("MySQL降级查询也失败", e);
            // 全部失败时，放行（不阻断业务）
            return DedupCheckResult.builder()
                .decision(DedupCheckResult.DedupDecision.PASS)
                .reason("FALLBACK: ALL_SYSTEMS_DOWN")
                .confidenceScore(0)
                .build();
        }
    }
}
```

```java
                DedupCheckResult result = dedupService.check(DedupCheckRequest.builder()
                    .userId(userId)
                    .knowledgePointId(kpId)
                    .targetModule(ModuleSource.FEED)
                    .build());
                
                assertThat(result.getDecision()).isNotEqualTo(DedupCheckResult.DedupDecision.PASS);
            });
    }
}
```
