> **版本**：v1.0 | **日期**：2026-05-31 | **模块归属**：客户端·消息域
> **优先级**：P1 | **关联后端**：通知中心与站内消息系统、消息与推送服务

## 1. 文档概述

### 1.1 文档目的

详细设计 PrimeTop 客户端"通知中心"页面的 UI 架构、交互流程、组件规范、状态管理和离线策略，使开发人员可直接据此实现完整的通知中心模块。

### 1.2 功能范围

| 功能 | 说明 |
|------|------|
| 通知列表 | 按大类分 Tab 展示通知，支持游标分页 |
| 未读管理 | 未读/已读状态展示，支持单条/批量/全量已读 |
| 通知详情 | 展开查看详情内容，支持富文本渲染 |
| 跳转路由 | 点击通知跳转到对应业务页面 |
| 通知聚合 | 相同 group_key 的通知合并展示 |
| 通知删除 | 左滑/长按删除，支持批量删除 |
| 消息偏好 | 通知偏好设置入口 |
| 实时推送 | WebSocket 在线时实时接收新通知 |
| 离线访问 | 本地缓存通知数据，离线可查看 |
| 未读角标 | 底部导航栏 + 应用图标角标同步 |

### 1.3 依赖关系

| 依赖文档 | 关联点 |
|---------|--------|
| 通知中心与站内消息系统 | 后端 API、数据模型、WebSocket 协议 |

| 客户端-底部导航栏与App主框架Shell架构设计 | Tab Badge 角标数据源 |
| 客户端路由与深链接系统 | 通知点击跳转路由映射 |
| 客户端组件库与设计系统 | 基础组件、设计 Token |
| 分龄UI适配与交互设计规范 | 分龄样式策略 |
| 客户端-设置页面与偏好配置交互设计 | 通知偏好设置联动 |
| 客户端通用列表组件与分页加载引擎 | 游标分页列表组件 |
| 客户端状态管理架构 | Riverpod Provider 设计 |
| 客户端网络请求治理与弱网适配方案 | 请求重试与弱网策略 |

### 1.4 设计原则

1. **信息密度可调**：学习/系统类高密度排列，营销类卡片式大图
2. **操作零延迟**：已读/删除操作先本地生效，后台异步同步
3. **实时可达**：在线时新通知 < 2 秒到达列表
4. **分龄适配**：幼儿家长代收模式、小学大图标+语音播报、初高中高信息密度
5. **离线可用**：本地 Hive 缓存，离线可查看历史通知

```dart
@freezed
class NotificationItem with _$NotificationItem {
  const factory NotificationItem({
    required String id,                    // 通知 ID（雪花算法字符串）
    required NotificationCategory category, // 大类
    required String type,                  // 子类型，如 'mistake_review_due'
    required String title,                 // 通知标题
    required String body,                  // 通知正文摘要
    String? content,                       // 富文本详情（Markdown）
    String? iconUrl,                       // 图标 URL
    String? imageUrl,                      // 配图 URL

    // 跳转
    required LinkType linkType,            // 跳转类型
    String? linkTarget,                    // 跳转目标
    @Default({}) Map<String, dynamic> linkParams, // 跳转参数

    // 关联业务
    String? sourceId,                      // 来源业务对象 ID
    String? sourceType,                    // 来源业务类型

    // 聚合
    String? groupKey,                      // 聚合键
    @Default(1) int groupCount,            // 聚合数量

    // 状态
    @Default(false) bool isRead,           // 已读
    @Default(false) bool isPinned,         // 置顶
    @Default(false) bool isDeleted,        // 本地删除（软删除标记）

    // 时间
    required DateTime publishedAt,         // 发布时间
    DateTime? readAt,                      // 已读时间
    DateTime? expireAt,                    // 过期时间

    // 客户端专用
    @Default(false) bool isLocallyRead,    // 本地预标记已读（待同步）
    @Default(false) bool isLocallyDeleted, // 本地预删除（待同步）
  }) = _NotificationItem;

  /// 排序键：置顶优先，其次按发布时间倒序
  int get sortOrder => isPinned ? (1 << 60) + publishedAt.millisecondsSinceEpoch
                                : publishedAt.millisecondsSinceEpoch;
}
```

```dart
/// lib/features/notification/widgets/notification_list.dart

/// 通知列表组件（复用于每个 Tab）
class NotificationListWidget extends ConsumerStatefulWidget {
  final NotificationCategory? category; // null 表示"全部"
  const NotificationListWidget({super.key, this.category});
}

class _NotificationListWidgetState
    extends ConsumerState<NotificationListWidget>
    with AutomaticKeepAliveClientMixin {

  @override
  bool get wantKeepAlive => true; // Tab 切换时保持状态

  @override
  Widget build(BuildContext context) {
    super.build(context);

    final state = ref.watch(notificationListProvider(widget.category));

    return state.when(
      loading: () => const NotificationListSkeleton(),
      error: (e, _) => NotificationListError(
        error: e,
        onRetry: () => ref.invalidate(notificationListProvider(widget.category)),
      ),
      data: (data) => _buildList(data),
    );
  }

  Widget _buildList(NotificationListData data) {
    if (data.items.isEmpty) {
      return const NotificationEmptyState();
    }

    return RefreshIndicator(
      onRefresh: () async {
        // 下拉刷新：重置游标，重新请求第一页
        ref.invalidate(notificationListProvider(widget.category));
      },
      child: PagedListWidget<NotificationItem>(
        items: data.items,
        hasMore: data.hasMore,
        cursor: data.nextCursor,
        onLoadMore: () => ref
            .read(notificationListProvider(widget.category).notifier)
            .loadMore(),
        itemBuilder: (context, item, index) => NotificationTile(
          item: item,
          onTap: () => _handleTap(item),
          onLongPress: () => _handleLongPress(item),
          onSwipeLeft: () => _handleDelete(item),
        ),
        // 置顶区域
        headerBuilder: data.pinnedItems.isNotEmpty
            ? () => PinnedNotificationSection(items: data.pinnedItems)
            : null,
      ),
    );
  }
}
```

```dart
/// lib/features/notification/widgets/notification_tile.dart

class NotificationTile extends ConsumerWidget {
  final NotificationItem item;
  final VoidCallback onTap;
  final VoidCallback onLongPress;
  final VoidCallback onSwipeLeft;

  const NotificationTile({
    super.key,
    required this.item,
    required this.onTap,
    required this.onLongPress,
    required this.onSwipeLeft,
  });

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final theme = Theme.of(context);
    final ageStyle = ref.watch(ageStyleProvider);

    return Dismissible(
      key: ValueKey(item.id),
      direction: DismissDirection.endToStart,
      background: _buildSwipeBackground(context),
      confirmDismiss: (_) async {
        onSwipeLeft();
        return false; // 不真正移除，由状态管理处理动画
      },
      child: InkWell(
        onTap: onTap,
        onLongPress: onLongPress,
        child: AnimatedContainer(
          duration: const Duration(milliseconds: 300),
          color: item.isRead
              ? theme.colorScheme.surface
              : theme.colorScheme.primaryContainer.withOpacity(0.08),
          padding: EdgeInsets.symmetric(
            horizontal: ageStyle.listPaddingH,
            vertical: ageStyle.listItemGapV,
          ),
          child: Row(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              // 左侧：图标 + 未读指示
              _buildIcon(context),
              SizedBox(width: ageStyle.listItemGapH),
              // 中间：内容
              Expanded(child: _buildContent(context)),
              // 右侧：附加信息
              _buildTrailing(context),
            ],
          ),
        ),
      ),
    );
  }

  Widget _buildIcon(BuildContext context) {
    final theme = Theme.of(context);
    return Stack(
      clipBehavior: Clip.none,
      children: [
        // 类型图标容器
        Container(
          width: 44,
          height: 44,
          decoration: BoxDecoration(
            color: _categoryColor.withOpacity(0.12),
            borderRadius: BorderRadius.circular(12),
          ),
          child: Center(
            child: item.iconUrl != null
                ? PTNetworkImage(url: item.iconUrl!, size: 24)
                : Icon(_categoryIcon, size: 24, color: _categoryColor),
          ),
        ),
        // 未读圆点
        if (!item.isRead)
          Positioned(
            top: -2,
            right: -2,
            child: Container(
              width: 10,
              height: 10,
              decoration: BoxDecoration(
                color: theme.colorScheme.error,
                shape: BoxShape.circle,
                border: Border.fromBorderSide(
                  BorderSide(color: theme.colorScheme.surface, width: 2),
                ),
              ),
            ),
          ),
      ],
    );
  }

  Widget _buildContent(BuildContext context) {
    final theme = Theme.of(context);
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        // 标题行
        Row(
          children: [
            Expanded(
              child: Text(
                item.title,
                style: theme.textTheme.bodyMedium?.copyWith(
                  fontWeight: item.isRead ? FontWeight.normal : FontWeight.w600,
                ),
                maxLines: 1,
                overflow: TextOverflow.ellipsis,
              ),
            ),
            // 聚合标记
            if (item.groupCount > 1)
              Container(
                padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
                decoration: BoxDecoration(
                  color: theme.colorScheme.primaryContainer,
                  borderRadius: BorderRadius.circular(8),
                ),
                child: Text(
                  '${item.groupCount}条',
                  style: theme.textTheme.labelSmall?.copyWith(
                    color: theme.colorScheme.onPrimaryContainer,
                  ),
                ),
              ),
          ],
        ),
        const SizedBox(height: 4),
        // 正文摘要
        Text(
          item.body,
          style: theme.textTheme.bodySmall?.copyWith(
            color: theme.colorScheme.onSurfaceVariant,
          ),
          maxLines: 2,
          overflow: TextOverflow.ellipsis,
        ),
        const SizedBox(height: 4),
        // 时间标签
        Text(
          _formatTime(item.publishedAt),
          style: theme.textTheme.labelSmall?.copyWith(
            color: theme.colorScheme.outline,
          ),
        ),
      ],
    );
  }

  Widget _buildTrailing(BuildContext context) {
    if (item.linkType != LinkType.none) {
      return Icon(
        Icons.chevron_right,
        size: 20,
        color: Theme.of(context).colorScheme.outline,
      );
    }
    if (item.imageUrl != null) {
      return ClipRRect(
        borderRadius: BorderRadius.circular(8),
        child: PTNetworkImage(url: item.imageUrl!, width: 56, height: 56),
      );
    }
    return const SizedBox.shrink();
  }

  Color get _categoryColor {
    // 根据 category 返回主题色
    switch (item.category) {
      case NotificationCategory.learning: return const Color(0xFF4F6EF7);
      case NotificationCategory.social:   return const Color(0xFF00B4D8);
      case NotificationCategory.system:   return const Color(0xFF8B95A5);
      case NotificationCategory.marketing: return const Color(0xFFFF9F43);
    }
  }

  IconData get _categoryIcon {
    switch (item.category) {
      case NotificationCategory.learning: return Icons.auto_stories;
      case NotificationCategory.social:   return Icons.group;
      case NotificationCategory.system:   return Icons.info_outline;
      case NotificationCategory.marketing: return Icons.local_offer;
    }
  }

  String _formatTime(DateTime dt) {
    final now = DateTime.now();
    final diff = now.difference(dt);
    if (diff.inMinutes < 1) return '刚刚';
    if (diff.inMinutes < 60) return '${diff.inMinutes}分钟前';
    if (diff.inHours < 24) return '${diff.inHours}小时前';
    if (diff.inDays < 7) return '${diff.inDays}天前';
    return '${dt.month}月${dt.day}日';
  }

  Widget _buildSwipeBackground(BuildContext context) {
    return Container(
      alignment: Alignment.centerRight,
      padding: const EdgeInsets.only(right: 24),
      color: Theme.of(context).colorScheme.error,
      child: const Icon(Icons.delete_outline, color: Colors.white),
    );
  }
}
```

```dart
/// lib/features/notification/widgets/notification_detail_sheet.dart

/// 通知详情底部抽屉（或全屏页面，分龄决定）
class NotificationDetailSheet extends ConsumerWidget {
  final NotificationItem item;
  const NotificationDetailSheet({super.key, required this.item});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final theme = Theme.of(context);
    final ageStyle = ref.watch(ageStyleProvider);

    // 自动标记已读
    ref.read(notificationActionsProvider.notifier).markRead(item.id);

    return DraggableScrollableSheet(
      initialChildSize: 0.7,
      minChildSize: 0.4,
      maxChildSize: 0.95,
      builder: (context, scrollController) {
        return Container(
          decoration: BoxDecoration(
            color: theme.colorScheme.surface,
            borderRadius: const BorderRadius.vertical(top: Radius.circular(20)),
          ),
          child: Column(
            children: [
              // 拖拽把手
              Padding(
                padding: const EdgeInsets.only(top: 12),
                child: Container(
                  width: 40, height: 4,
                  decoration: BoxDecoration(
                    color: theme.colorScheme.outlineVariant,
                    borderRadius: BorderRadius.circular(2),
                  ),
                ),
              ),
              // 头部
              Padding(
                padding: EdgeInsets.all(ageStyle.pagePaddingH),
                child: Row(
                  children: [
                    _buildCategoryIcon(context),
                    const SizedBox(width: 12),
                    Expanded(
                      child: Column(
                        crossAxisAlignment: CrossAxisAlignment.start,
                        children: [
                          Text(item.title,
                            style: theme.textTheme.titleMedium?.copyWith(
                              fontWeight: FontWeight.w600)),
                          Text(_formatFullTime(item.publishedAt),
                            style: theme.textTheme.labelSmall?.copyWith(
                              color: theme.colorScheme.outline)),
                        ],
                      ),
                    ),
                    // 操作菜单
                    PopupMenuButton<String>(
                      onSelected: (action) => _handleAction(context, action),
                      itemBuilder: (_) => [
                        const PopupMenuItem(value: 'delete', child: Text('删除')),
                        if (!item.isPinned)
                          const PopupMenuItem(value: 'pin', child: Text('置顶')),
                        if (item.isPinned)
                          const PopupMenuItem(value: 'unpin', child: Text('取消置顶')),
                      ],
                    ),
                  ],
                ),
              ),
              const Divider(height: 1),
              // 内容区
              Expanded(
                child: ListView(
                  controller: scrollController,
                  padding: EdgeInsets.all(ageStyle.pagePaddingH),
                  children: [
                    // 聚合信息
                    if (item.groupCount > 1)
                      Padding(
                        padding: const EdgeInsets.only(bottom: 12),
                        child: Text('共 ${item.groupCount} 条同类通知',
                          style: theme.textTheme.labelMedium?.copyWith(
                            color: theme.colorScheme.primary)),
                      ),
                    // 富文本内容
                    if (item.content != null)
                      PTRichTextRenderer(
                        content: item.content!,
                        style: RichTextStyle.markdown,
                      )
                    else
                      Text(item.body, style: theme.textTheme.bodyMedium),
                    // 配图
                    if (item.imageUrl != null) ...[
                      const SizedBox(height: 16),
                      ClipRRect(
                        borderRadius: BorderRadius.circular(12),
                        child: PTNetworkImage(url: item.imageUrl!),
                      ),
                    ],
                  ],
                ),
              ),
              // 底部操作栏
              if (item.linkType != LinkType.none)
                SafeArea(
                  child: Padding(
                    padding: EdgeInsets.all(ageStyle.pagePaddingH),
                    child: PTFilledButton(
                      text: _linkActionLabel,
                      onPressed: () => _navigateToTarget(context),
                      size: PTButtonSize.large,
                      expanded: true,
                    ),
                  ),
                ),
            ],
          ),
        );
      },
    );
  }

  void _handleAction(BuildContext context, String action) {
    final notifier = context.read(notificationActionsProvider.notifier);
    switch (action) {
      case 'delete':
        notifier.delete(item.id);
        Navigator.of(context).pop();
        break;
      case 'pin':
        notifier.pin(item.id);
        break;
      case 'unpin':
        notifier.unpin(item.id);
        break;
    }
  }

  void _navigateToTarget(BuildContext context) {
    Navigator.of(context).pop(); // 先关闭详情 sheet
    if (item.linkType == LinkType.internal) {
      context.go(item.linkTarget!, extra: item.linkParams);
    } else if (item.linkType == LinkType.external) {
      // 打开 WebView
      context.push('/webview', extra: {'url': item.linkTarget, 'title': item.title});
    }
  }

  String get _linkActionLabel {
    switch (item.type) {
      case 'mistake_review_due':
      case 'mistake_interval_review':
        return '去复习';
      case 'weekly_report_ready':
        return '查看报告';
      case 'achievement_unlocked':
        return '查看成就';
      case 'study_plan_reminder':
        return '查看任务';
      case 'membership_expiring':
        return '去续费';
      case 'promotion_campaign':
      case 'limited_offer':
        return '查看详情';
      default:
        return '查看详情';
    }
  }
```

```dart
        total: current.total - delta,
        _categoryField(category): catCount - delta,
      ));
    } else {
      state = AsyncData(current.copyWith(total: 0));
    }
    _updateBadge();

  @override
  Future<NotificationListData> build(NotificationCategory? category) async {
    // 先从本地缓存加载
    final cached = await _localCache.getNotifications(category: category, limit: 20);
    if (cached.isNotEmpty) {
      state = AsyncData(NotificationListData(
        items: cached,

        hasMore: true,
        nextCursor: null,
      ));
    }
    // 再请求远端

  }

  Future<void> loadMore() async {
    final current = state.valueOrNull;
    if (current == null || !current.hasMore || _isLoading) return;
    _isLoading = true;

    try {
      final next = await _fetchRemote(
        category: arg,
        cursor: current.nextCursor,
      );
      state = AsyncData(NotificationListData(
        items: [...current.items, ...next.items],
        pinnedItems: next.pinnedItems.isNotEmpty ? next.pinnedItems : current.pinnedItems,
        hasMore: next.hasMore,
        nextCursor: next.nextCursor,
      ));
    } finally {
      _isLoading = false;
    }
  }

  /// 增量插入新通知（WebSocket 推送）
  void insertNew(NotificationItem item) {
    final current = state.valueOrNull;
    if (current == null) return;

    // 检查是否匹配当前 Tab 筛选
    if (arg != null && item.category != arg) return;

    state = AsyncData(current.copyWith(
      items: [item, ...current.items],
    ));
  }

  Future<NotificationListData> _fetchRemote({
    required NotificationCategory? category,
    required String? cursor,

      cursor: cursor,

      pinnedItems: items.where((n) => n.isPinned).toList(),
      hasMore: response.hasMore,

@riverpod
class NotificationActions extends _$NotificationActions {
  @override
  void build() {}

  /// 标记单条已读（乐观更新）
  void markRead(String notificationId) {
    // 本地立即更新
    _updateLocalItem(notificationId, (item) => item.copyWith(
      isRead: true,
      isLocallyRead: true,
      readAt: DateTime.now(),
    ));

    // 异步同步到服务端（Fire-and-forget）
    _api.markRead(notificationIds: [notificationId]).catchError((e) {
      // 失败回滚
      _updateLocalItem(notificationId, (item) => item.copyWith(
        isRead: false,
        isLocallyRead: false,
        readAt: null,
      ));
    });
  }

  /// 批量标记已读
  Future<void> markAllRead({NotificationCategory? category}) async {
    // 乐观更新
    _markAllLocalRead(category: category);

    try {
      await _api.markRead(all: true, category: category?.name);
      ref.read(unreadCountNotifierProvider.notifier)
          .onMarkRead(category: category);
    } catch (e) {
      // 失败回滚 - 重新加载列表
      ref.invalidate(notificationListProvider(category));
    }
  }

  /// 删除通知（乐观更新）
  void delete(String notificationId) {
    _updateLocalItem(notificationId, (item) => item.copyWith(
      isDeleted: true,
      isLocallyDeleted: true,
    ));

    _api.delete(notificationIds: [notificationId]).catchError((e) {
      _updateLocalItem(notificationId, (item) => item.copyWith(
        isDeleted: false,
        isLocallyDeleted: false,
      ));
    });
  }

  /// 批量删除
  Future<void> batchDelete(List<String> ids) async {
    for (final id in ids) {
      _updateLocalItem(id, (item) => item.copyWith(isDeleted: true));
    }
    try {
      await _api.delete(notificationIds: ids);
    } catch (e) {
      // 回滚
      ref.invalidate(notificationListProvider(null));
    }
  }

  void _updateLocalItem(String id, NotificationItem Function(NotificationItem) updater) {
    // 更新所有 Tab 的列表（因为"全部" Tab 包含所有分类）
    for (final cat in [null, ...NotificationCategory.values]) {
      final listState = ref.read(notificationListProvider(cat));
      listState.whenData((data) {
        final updated = data.items.map((item) {
          if (item.id == id) return updater(item);
          return item;
        }).toList();
        ref.read(notificationListProvider(cat).notifier).state = AsyncData(
          data.copyWith(
            items: updated,
            pinnedItems: updated.where((n) => n.isPinned).toList(),
          ),
        );
      });
    }
  }

  void _markAllLocalRead({NotificationCategory? category}) {
    // 遍历所有相关列表，标记为已读
    for (final cat in [null, category]) {
      final listState = ref.read(notificationListProvider(cat));
      listState.whenData((data) {
        final updated = data.items.map((item) =>
          item.copyWith(isRead: true, readAt: DateTime.now())
        ).toList();
        ref.read(notificationListProvider(cat).notifier).state = AsyncData(
          data.copyWith(items: updated),
        );
      });
    }
  }
}
```

```dart
  static const _unreadKey = 'unread_count';

  }

  UnreadCount? getUnreadCount() {
    final json = _box.get(_unreadKey);
    if (json == null) return null;
    return UnreadCount.fromJson(jsonDecode(json));
  }

  Future<void> saveUnreadCount(UnreadCount count) async {
    await _box.put(_unreadKey, jsonEncode(count.toJson()));
  }

  // ---- 通知列表 ----
  List<NotificationItem> getNotifications({
    NotificationCategory? category,
    required int limit,
  }) {
    final key = '${_listPrefix}${category?.name ?? 'all'}';
    final list = _box.get(key);
    if (list == null) return [];
    final items = (jsonDecode(list) as List)
        .map((e) => NotificationItem.fromJson(e))
        .toList();
    return items.take(limit).toList();
  }

  Future<void> saveNotifications(
    List<NotificationItem> items, {
    NotificationCategory? category,
  }) async {
    final key = '${_listPrefix}${category?.name ?? 'all'}';
    await _box.put(key, jsonEncode(items.map((e) => e.toJson()).toList()));
  }

  // ---- 待同步操作队列 ----
  Future<void> enqueuePendingAction(PendingNotificationAction action) async {
    final queue = getPendingActions();
    queue.add(action);
    await _box.put('pending_actions', jsonEncode(queue.map((e) => e.toJson()).toList()));
  }

  List<PendingNotificationAction> getPendingActions() {
    final data = _box.get('pending_actions');
    if (data == null) return [];
    return (jsonDecode(data) as List)
        .map((e) => PendingNotificationAction.fromJson(e))
        .toList();
  }

  Future<void> clearPendingActions() async {
    await _box.delete('pending_actions');
  }
}
```

### 8.1 连接与消息处理

```dart
/// lib/features/notification/services/notification_ws_service.dart

@riverpod
class NotificationWebSocket extends _$NotificationWebSocket {
  WebSocketChannel? _channel;
  Timer? _heartbeatTimer;
  Timer? _reconnectTimer;
  int _reconnectAttempts = 0;

  static const _maxReconnectDelay = Duration(seconds: 30);

  @override
  void build() {
    // 监听认证状态变化
    ref.listen(authStateProvider, (_, authState) {
      if (authState.isAuthenticated) {
        connect();
      } else {
        disconnect();
      }
    });

    ref.onDispose(() {
      disconnect();
    });
  }

  Future<void> connect() async {
    final token = ref.read(authStateProvider).token;
    if (token == null) return;

    try {
      final wsUrl = '${Config.wsBaseUrl}/ws/notifications?token=$token';
      _channel = WebSocketChannel.connect(Uri.parse(wsUrl));

      _channel!.stream.listen(
        _onMessage,
        onError: _onError,
        onDone: _onDone,
      );

      // 启动心跳
      _heartbeatTimer?.cancel();
      _heartbeatTimer = Timer.periodic(const Duration(seconds: 30), (_) {
        _channel?.sink.add(jsonEncode({'type': 'ping'}));
      });

      _reconnectAttempts = 0;
    } catch (e) {
      _scheduleReconnect();
    }
  }

  void _onMessage(dynamic data) {
    try {
      final json = jsonDecode(data as String) as Map<String, dynamic>;
      final type = json['type'] as String;

      switch (type) {
        case 'notification_new':
          _handleNewNotification(json);
          break;
        case 'notification_read_sync':
          // 服务端已读同步（其他设备标记已读）
          _handleReadSync(json);
          break;
        case 'unread_count_update':
          // 服务端主动推送未读计数校正
          _handleUnreadCountUpdate(json);
          break;
        case 'pong':
          break;
      }
    } catch (e) {
      // 忽略解析异常
    }
  }

  void _handleNewNotification(Map<String, dynamic> json) {
    final item = NotificationItem.fromJson(json['notification']);

    // 插入到对应列表
    for (final cat in [null, item.category]) {
      ref.read(notificationListProvider(cat).notifier).insertNew(item);
    }

    // 更新未读计数
    ref.read(unreadCountNotifierProvider.notifier)
        .onNewNotification(item.category);

    // 显示应用内 Toast（非当前通知中心页面时）
    final currentRoute = ref.read(currentRouteProvider);
    if (currentRoute != '/notifications') {
      _showInAppToast(item);
    }
  }

  void _handleReadSync(Map<String, dynamic> json) {
    final notificationIds = (json['notification_ids'] as List).cast<String>();
    for (final id in notificationIds) {
      for (final cat in [null, ...NotificationCategory.values]) {
        final notifier = ref.read(notificationListProvider(cat).notifier);
        // 不触发乐观更新的异步同步
        notifier.state.whenData((data) {
          final updated = data.items.map((item) {
            if (notificationIds.contains(item.id)) {
              return item.copyWith(isRead: true, readAt: DateTime.now());
            }
            return item;
          }).toList();
          notifier.state = AsyncData(data.copyWith(items: updated));
        });
      }
    }
  }

  void _handleUnreadCountUpdate(Map<String, dynamic> json) {
    final count = UnreadCount.fromJson(json['counts']);
    ref.read(unreadCountNotifierProvider.notifier).state = AsyncData(count);
  }

  void _showInAppToast(NotificationItem item) {
    // 使用全局 Overlay 显示顶部通知横幅
    ref.read(inAppToastProvider.notifier).show(
      title: item.title,
      body: item.body,
      icon: _categoryIconForType(item.type),
      onTap: () => context.go('/notifications'),
    );
  }

  void _onError(dynamic error) {
    _scheduleReconnect();
  }

  void _onDone() {
    _scheduleReconnect();
  }

  void _scheduleReconnect() {
    _heartbeatTimer?.cancel();
    _reconnectTimer?.cancel();

    _reconnectAttempts++;
    final delay = Duration(seconds: min(
      pow(2, _reconnectAttempts).toInt(),
      _maxReconnectDelay.inSeconds,
    ));

    _reconnectTimer = Timer(delay, () => connect());
  }

  void disconnect() {
    _heartbeatTimer?.cancel();
    _reconnectTimer?.cancel();
    _channel?.sink.close();
    _channel = null;
  }
}
```

### 8.2 WebSocket 消息协议

**客户端 → 服务端：**

| type | 说明 | payload |
|------|------|---------|
| `ping` | 心跳 | - |
| `subscribe` | 订阅通知（连接后自动） | - |

**服务端 → 客户端：**

| type | 说明 | payload |
|------|------|---------|
| `pong` | 心跳响应 | - |
| `notification_new` | 新通知推送 | `{ notification: NotificationItem }` |
| `notification_read_sync` | 跨设备已读同步 | `{ notification_ids: string[] }` |
| `unread_count_update` | 未读计数校正 | `{ counts: UnreadCount }` |

```dart
/// lib/features/notification/services/badge_service.dart

class BadgeService {
  /// 更新应用图标未读角标
  static Future<void> updateBadge(int count) async {
    if (Platform.isIOS) {
      // iOS: 通过 APNs 后台推送更新角标，或本地 UNUserNotificationCenter
      await FlutterAppBadger.updateBadgeCount(count);
    } else if (Platform.isAndroid) {
      // Android: 各厂商通道不同，使用统一插件
      // 大部分国产 ROM 支持 ShortcutBadger
      try {
        await FlutterAppBadger.updateBadgeCount(count);
      } catch (_) {
        // 部分 ROM 不支持角标，静默忽略
      }
    }
  }

  static Future<void> removeBadge() async {
    await FlutterAppBadger.removeBadge();
  }
}
```

### 12.2 角标更新触发时机

| 触发点 | 操作 |
|--------|------|
| WebSocket 推送新通知 | unreadCount + 1 → updateBadge |

| 删除通知 | 重新计算 unreadCount → updateBadge |
| App 启动 | 拉取最新 unreadCount → updateBadge |
| App 进入前台 | 拉取最新 unreadCount → updateBadge |
| 用户退出登录 | removeBadge |

## 13. 错误处理

### 13.1 错误场景与策略

| 场景 | 错误类型 | 处理策略 |
|------|---------|---------|
| 列表加载失败 | 网络异常 / 5xx | 展示缓存数据 + 错误提示条 + 重试按钮 |
| 标记已读失败 | 网络异常 | 乐观更新保持，加入待同步队列，下次网络恢复重试 |
| 删除失败 | 网络异常 | 同上 |
| WebSocket 断开 | 连接异常 | 指数退避重连（最长 30 秒间隔） |
| 详情加载失败 | 网络异常 | 展示已缓存的摘要信息，隐藏详情部分 |
| 偏好保存失败 | 网络异常 | 本地已生效 + 回滚机制 + Toast 提示 |
| Token 过期 | 401 | 触发全局 Token 刷新流程 |
| 通知过期 | 服务端返回空 | 本地清理过期通知 |

### 13.2 错误 UI

```dart
class NotificationListError extends StatelessWidget {
  final Object error;
  final VoidCallback onRetry;

  const NotificationListError({
    super.key,
    required this.error,
    required this.onRetry,
  });

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(Icons.cloud_off, size: 48, color: Theme.of(context).colorScheme.outline),
          const SizedBox(height: 16),
          Text('加载通知失败', style: Theme.of(context).textTheme.titleMedium),
          const SizedBox(height: 8),
          Text(
            _errorMessage,
            style: Theme.of(context).textTheme.bodySmall?.copyWith(
              color: Theme.of(context).colorScheme.outline,
            ),
            textAlign: TextAlign.center,
          ),
          const SizedBox(height: 16),
          PTFilledButton(text: '重试', onPressed: onRetry, size: PTButtonSize.small),
        ],
      ),
    );
  }

  String get _errorMessage {
    if (error is DioException) {
      final dioErr = error as DioException;
      if (dioErr.type == DioExceptionType.connectionError) {
        return '网络连接失败，请检查网络后重试';
      }
      if (dioErr.type == DioExceptionType.connectionTimeout) {
        return '请求超时，请稍后重试';
      }
    }
    return '发生未知错误，请稍后重试';
  }
}
```
