# 学生学习注意力实时监测与专注力智能恢复干预引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责在学生学习会话期间，通过客户端采集的行为信号实时推断学生的注意力状态，并在注意力分散时触发适当的干预策略，帮助学生恢复专注。

与现有系统的区别：
- **学习疲劳度监测引擎**：关注"累不累"→ 触发休息建议
- **专注力分析引擎**：关注"什么时候最专注"→ 输出高效时段统计
- **学习状态感知引擎**：关注"整体会话质量"→ 会话级评分
- **本引擎**：关注"此刻是否走神"→ 实时检测 + 即时干预

### 1.2 设计目标

| 指标 | 目标值 |
|------|--------|
| 注意力状态判定延迟 | < 3 秒 |
| 行为信号采集开销 | < 1% CPU，< 50KB/min 内存增量 |
| 注意力分散识别准确率 | ≥ 80%（与用户主观反馈对比） |
| 干预正向反馈率 | ≥ 65%（用户标记"有帮助"） |
| 误干预频率 | ≤ 2 次/小时（用户标记"不需要"） |

### 1.3 适用场景

- 同步课堂章节学习（阅读教材内容）
- 练习答题过程（连续做题）
- 知识点视频/音频观看
- AI 辅导对话交互
- **不适用**：拍照搜题、选择题单题作答（单次操作时间太短）

### 2.1 核心设计原则

1. **端云协同**：简单状态推断在端侧完成（低延迟），复杂分析和干预决策在云端完成（准确度高）
2. **最小化采集**：仅采集行为时序信号，不使用摄像头/麦克风等隐私敏感传感器
3. **非侵入式干预**：优先使用轻量视觉提示，避免打断式弹窗
4. **用户可控**：学生或家长可关闭注意力监测功能

## 4. 核心算法设计

### 4.1 注意力评分模型 (AttentionScorer)

采用**加权行为特征评分法**，将多维行为信号融合为 0-100 的连续注意力分数。

#### 4.1.1 特征提取

以 **30 秒滑动窗口** 为单位提取行为特征：

```python
from dataclasses import dataclass
from typing import List, Optional
import numpy as np

@dataclass
class BehaviorFeatures:
    """30秒窗口内提取的行为特征"""
    # 交互频率特征
    interaction_count: int          # 主动交互次数（点击、输入等）
    meaningful_interaction_ratio: float  # 有效交互占比（非误触）

    # 内容进度特征
    content_progress_delta: float   # 内容进度变化量
    progress_direction_consistency: float  # 进度方向一致性（是否反复来回）

    # 时序特征
    avg_idle_duration: float        # 平均停顿时长（秒）
    max_idle_duration: float        # 最大停顿时长
    idle_ratio: float               # 无操作时间占比

    # 行为模式特征
    scroll_pattern_score: float     # 滚动模式评分（正常浏览 vs 无目的快速滚动）
    page_switch_count: int          # 页面跳转次数
    background_duration: float      # 后台停留时长（秒）

    # 答题特征（如适用）
    answer_speed_deviation: Optional[float]  # 答题速度偏离该用户历史均值
    rapid_guessing_score: Optional[float]    # 快速盲猜评分


def extract_features(signals: List[BehaviorSignal], window_start: float, window_end: float) -> BehaviorFeatures:
    """从30秒窗口内的行为信号提取特征"""
    window_signals = [s for s in signals if window_start <= s.timestamp < window_end]

    interaction_types = {'tap', 'text_input', 'answer_submit', 'media_control'}
    interactions = [s for s in window_signals if s.signalType in interaction_types]

    # 有效交互：在内容区域的点击、有内容的输入、答题提交
    meaningful = [s for s in interactions
                  if s.payload.get('tapTarget', '').startswith('content_')
                  or s.payload.get('charCount', 0) > 5
                  or s.signalType == 'answer_submit']

    # 滚动特征
    scroll_signals = [s for s in window_signals if s.signalType == 'scroll']
    scroll_directions = [s.payload.get('scrollDirection') for s in scroll_signals]
    direction_changes = sum(1 for i in range(1, len(scroll_directions))
                           if scroll_directions[i] != scroll_directions[i-1])
    scroll_speeds = [s.payload.get('scrollSpeed', 0) for s in scroll_signals]

    # 快速无目的滚动检测
    fast_scrolls = sum(1 for v in scroll_speeds if v > 2000)  # px/s
    scroll_pattern_score = 1.0 - min(fast_scrolls / 10, 1.0)

    # 方向一致性
    if scroll_directions:
        consistency = 1.0 - min(direction_changes / max(len(scroll_directions), 1), 1.0)
    else:
        consistency = 1.0

    # 停顿检测
    idle_signals = [s for s in window_signals if s.signalType == 'idle']
    idle_durations = [s.payload.get('idleDuration', 0) for s in idle_signals]
    total_idle = sum(idle_durations)
    window_duration = window_end - window_start

    # 后台时间
    bg_signals = [s for s in window_signals if s.signalType == 'app_visibility'
                  and s.payload.get('visibility') == 'background']
    bg_duration = sum(s.payload.get('backgroundDuration', 0) for s in bg_signals)

    return BehaviorFeatures(
        interaction_count=len(interactions),
        meaningful_interaction_ratio=len(meaningful) / max(len(interactions), 1),
        content_progress_delta=sum(s.payload.get('progressDelta', 0) for s in window_signals
                                   if s.signalType == 'content_progress'),
        progress_direction_consistency=consistency,
        avg_idle_duration=np.mean(idle_durations) / 1000 if idle_durations else 0,
        max_idle_duration=max(idle_durations) / 1000 if idle_durations else 0,
        idle_ratio=total_idle / max(window_duration, 1),
        scroll_pattern_score=scroll_pattern_score,
        page_switch_count=sum(1 for s in window_signals if s.signalType == 'page_navigate'),
        background_duration=bg_duration / 1000,
        answer_speed_deviation=None,  # 由调用方填充
        rapid_guessing_score=None,
    )
```

#### 4.1.2 注意力评分计算

```python
class AttentionScorer:
    """注意力评分器 - 将行为特征转化为0-100注意力分数"""

    # 特征权重（可按学段调整）
    DEFAULT_WEIGHTS = {
        'interaction_density': 0.15,      # 交互密度
        'meaningful_ratio': 0.20,         # 有效交互比
        'progress_consistency': 0.15,     # 进度一致性
        'idle_penalty': 0.20,             # 停顿惩罚
        'scroll_quality': 0.10,           # 滚动质量
        'page_stability': 0.10,           # 页面稳定性
        'background_penalty': 0.10,       # 后台惩罚
    }

    # 学段权重调整
    GRADE_WEIGHTS = {
        'primary': {
            'interaction_density': 0.20,
            'idle_penalty': 0.15,
            'meaningful_ratio': 0.15,
        },
        'junior': {
            'interaction_density': 0.15,
            'idle_penalty': 0.20,
            'meaningful_ratio': 0.20,
        },
        'senior': {
            'interaction_density': 0.10,
            'idle_penalty': 0.25,
            'meaningful_ratio': 0.20,
        },
    }

    def score(self, features: BehaviorFeatures, grade_level: str = 'junior') -> tuple[int, list]:
        """
        计算注意力分数
        Returns: (score 0-100, factor_breakdown)
        """
        weights = {**self.DEFAULT_WEIGHTS}
        weights.update(self.GRADE_WEIGHTS.get(grade_level, {}))

        # 归一化各维度到 0-1
        scores = {}

        # 交互密度：期望30秒窗口内至少3次有效交互
        scores['interaction_density'] = min(features.interaction_count / 3.0, 1.0)

        # 有效交互比
        scores['meaningful_ratio'] = features.meaningful_interaction_ratio

        # 进度一致性
        scores['progress_consistency'] = features.progress_direction_consistency

        # 停顿惩罚：超过10秒的停顿开始扣分，30秒停顿归零
        idle_penalty = min(features.avg_idle_duration / 30.0, 1.0)
        scores['idle_penalty'] = 1.0 - idle_penalty

        # 滚动质量
        scores['scroll_quality'] = features.scroll_pattern_score

        # 页面稳定性：30秒内跳转超过2次开始扣分
        scores['page_stability'] = max(0, 1.0 - max(features.page_switch_count - 1, 0) * 0.3)

        # 后台惩罚：后台超过10秒直接归零
        bg_ratio = min(features.background_duration / 30.0, 1.0)
        scores['background_penalty'] = 1.0 - bg_ratio

        # 加权汇总
        total_weight = sum(weights.values())
        weighted_sum = sum(scores[k] * weights.get(k, 0) for k in scores)

        attention_score = int((weighted_sum / total_weight) * 100)

        # 收集低分维度作为分散因素
        factors = []
        for k, v in scores.items():
            if v < 0.4:
                factor_map = {
                    'interaction_density': ('long_idle', '交互频率过低'),
                    'meaningful_ratio': ('erratic_tap', '有效交互比例低'),
                    'progress_consistency': ('rapid_scroll', '内容进度反复'),
                    'idle_penalty': ('long_idle', '长时间停顿'),
                    'scroll_quality': ('rapid_scroll', '快速无目的滚动'),
                    'page_stability': ('frequent_switch', '频繁切换页面'),
                    'background_penalty': ('background_leave', '应用切到后台'),
                }
                if k in factor_map:
                    factor_type, evidence = factor_map[k]
                    factors.append({
                        'factor': factor_type,
                        'weight': 1.0 - v,
                        'evidence': f'{evidence} (score={v:.2f})',
                    })

        return attention_score, factors
```

#### 4.1.3 注意力等级判定

```python
class AttentionClassifier:
    """根据连续多个窗口的注意力分数判定注意力等级"""

    HISTORY_WINDOW = 5  # 使用最近5个窗口（2.5分钟）

    def classify(self, score_history: list[int], current_score: int,
                 idle_duration: float, bg_duration: float) -> AttentionState:
        """
        判定当前注意力状态
        """
        # 后台超过60秒 → absent
        if bg_duration > 60:
            level = AttentionLevel.ABSENT
            confidence = 0.95

        # 无操作超过90秒 → idle
        elif idle_duration > 90:
            level = AttentionLevel.IDLE
            confidence = 0.85

        # 基于分数趋势判定
        elif current_score >= 75:
            level = AttentionLevel.FOCUSED
            confidence = self._calc_confidence(score_history, threshold=75)

        elif current_score >= 50:
            level = AttentionLevel.ENGAGED
            confidence = self._calc_confidence(score_history, threshold=50)

        else:
            level = AttentionLevel.DISTRACTED
            confidence = self._calc_confidence(score_history, threshold=50, below=True)

        # 趋势分析
        if len(score_history) >= 3:
            recent = score_history[-3:]
            if recent[-1] > recent[0] + 10:
                trend = 'improving'
            elif recent[-1] < recent[0] - 10:
                trend = 'declining'
            else:
                trend = 'stable'
        else:
            trend = 'stable'

        return AttentionState(
            currentLevel=level,
            confidence=confidence,
            attentionScore=current_score,
            trend=trend,
            # ... 其他字段
        )

    def _calc_confidence(self, history: list[int], threshold: int,
                         below: bool = False) -> float:
        """基于历史一致性计算置信度"""
        if not history:
            return 0.5
        if below:
            consistent = sum(1 for s in history if s < threshold)
        else:
            consistent = sum(1 for s in history if s >= threshold)
        return min(0.5 + (consistent / len(history)) * 0.5, 0.95)
```

### 4.2 干预决策引擎 (InterventionDecisionEngine)

```python
from datetime import datetime, timedelta

class InterventionDecisionEngine:
    """根据注意力状态决定是否触发干预以及触发哪种干预"""

    def __init__(self, strategy_repo, rate_limiter):
        self.strategy_repo = strategy_repo  # 策略仓库
        self.rate_limiter = rate_limiter    # 频控器

    def decide(self, state: AttentionState,
               session_context: SessionContext,
               user_prefs: UserAttentionPrefs) -> Optional[InterventionStrategy]:
        """
        决策：返回推荐的干预策略，或None（不干预）
        """
        # 0. 用户/家长关闭了注意力监测
        if not user_prefs.enabled:
            return None

        # 1. 仅在分散/漫游/离线状态触发
        if state.currentLevel in ('focused', 'engaged'):
            return None

        # 2. 检查分散持续时间是否达到阈值
        if state.currentLevel == 'distracted':
            min_duration = 60_000  # 60秒
        elif state.currentLevel == 'idle':
            min_duration = 120_000  # 2分钟
        else:
            return None  # absent状态不推送干预（用户不在）

        distraction_duration = datetime.now().timestamp() * 1000 - (state.lastDistractionTime or 0)
        if distraction_duration < min_duration:
            return None

        # 3. 趋势改善中 → 不打断自然恢复
        if state.trend == 'improving' and state.attentionScore > 35:
            return None

        # 4. 获取候选策略
        candidates = self.strategy_repo.find_enabled(
            attention_level=state.currentLevel,
            content_type=session_context.contentType,
            grade_level=session_context.gradeLevel,
        )

        if not candidates:
            return None

        # 5. 频控检查
        filtered = []
        for strategy in candidates:
            if self.rate_limiter.can_trigger(
                user_id=session_context.userId,
                strategy_id=strategy.strategyId,
                cooldown_ms=strategy.cooldownMs,
                max_per_session=strategy.maxTriggersPerSession,
                session_id=session_context.sessionId,
            ):
                filtered.append(strategy)

        if not filtered:
            return None

        # 6. 选择最优策略
        best = max(filtered, key=lambda s: self._score_strategy(s, state, session_context))
        return best

    def _score_strategy(self, strategy: InterventionStrategy,
                        state: AttentionState,
                        context: SessionContext) -> float:
        """为候选策略打分，选择最合适的"""
        score = strategy.priority / 100.0  # 基础分

        # 根据分散程度调整策略级别
        if state.attentionScore < 25 and strategy.level == 'active':
            score += 0.3  # 严重分散时偏向主动干预
        elif state.attentionScore > 40 and strategy.level == 'subtle':
            score += 0.2  # 轻度分散时偏向轻量提示
        elif strategy.level == 'gentle':
            score += 0.1  # 中等分散时默认轻柔

        # 根据会话时长调整
        if context.sessionDuration > 1800_000:  # 超过30分钟
            if 'take_break' in str(strategy.presentation):
                score += 0.15  # 长时间学习更可能需要休息

        return score
```

### 4.3 端侧轻量推断 (OnDeviceInference)

客户端运行的简化版注意力推断，用于低延迟的初步判断。

```dart
/// Flutter 端侧注意力推断引擎
class OnDeviceAttentionInference {
  /// 信号缓冲区（保留最近2分钟）
  final List<SignalEvent> _buffer = [];
  static const int _windowSizeMs = 30000; // 30秒窗口
  static const int _minSignalsForInference = 3;

  /// 上次评分时间
  DateTime? _lastScoreTime;

  /// 当前注意力分数
  int _currentScore = 70;

  /// 推断注意力分数
  /// 返回 null 表示数据不足
  int? infer(List<SignalEvent> newSignals) {
    final now = DateTime.now();

    // 添加新信号到缓冲区
    _buffer.addAll(newSignals);

    // 清理超过2分钟的旧信号
    _buffer.removeWhere((s) =>
      now.difference(s.timestamp).inMilliseconds > 120000);

    // 至少每10秒评分一次
    if (_lastScoreTime != null &&
        now.difference(_lastScoreTime!).inMilliseconds < 10000) {
      return null;
    }

    // 获取最近30秒窗口
    final windowStart = now.subtract(Duration(milliseconds: _windowSizeMs));
    final windowSignals = _buffer.where(
      (s) => s.timestamp.isAfter(windowStart)
    ).toList();

    if (windowSignals.length < _minSignalsForInference) {
      // 信号太少：如果超过30秒几乎没有操作，可能是idle
      final hasRecentActivity = windowSignals.any((s) =>
        s.type != SignalType.idle &&
        s.type != SignalType.appVisibility);
      if (!hasRecentActivity) {
        _currentScore = (_currentScore - 5).clamp(0, 100);
      }
      return _currentScore;
    }

    // 简化评分逻辑
    int score = 70; // 基础分

    // 后台惩罚
    final bgSignals = windowSignals.where((s) =>
      s.type == SignalType.appVisibility &&
      s.payload['visibility'] == 'background');
    if (bgSignals.isNotEmpty) {
      final bgDuration = bgSignals.fold<int>(0,
        (sum, s) => sum + (s.payload['backgroundDuration'] as int? ?? 0));
      if (bgDuration > 10000) {
        return 0; // 后台超过10秒直接归零
      }
      score -= (bgDuration / 200).round();
    }

    // 长停顿惩罚
    final idleSignals = windowSignals.where((s) => s.type == SignalType.idle);
    for (final s in idleSignals) {
      final duration = (s.payload['idleDuration'] as int? ?? 0) / 1000;
      if (duration > 30) {
        score -= 30;
      } else if (duration > 10) {
        score -= 15;
      }
    }

    // 快速滚动惩罚
    final scrollSignals = windowSignals.where((s) => s.type == SignalType.scroll);
    final fastScrolls = scrollSignals.where((s) =>
      (s.payload['scrollSpeed'] as int? ?? 0) > 2000).length;
    score -= fastScrolls * 5;

    // 有效交互加分
    final meaningfulInteractions = windowSignals.where((s) =>
      s.type == SignalType.tap &&
      (s.payload['tapTarget'] as String? ?? '').startsWith('content_'));
    score += meaningfulInteractions.length * 5;

    // 进度前进加分
    final progressSignals = windowSignals.where((s) =>
      s.type == SignalType.contentProgress &&
      (s.payload['progressDelta'] as num? ?? 0) > 0);
    score += progressSignals.length * 8;

    // 平滑处理（避免分数跳变）
    _currentScore = (_currentScore * 0.6 + score.clamp(0, 100) * 0.4).round();

    _lastScoreTime = now;
    return _currentScore;
  }

  /// 获取端侧注意力等级
  AttentionLevel get currentLevel {
    if (_currentScore >= 75) return AttentionLevel.focused;
    if (_currentScore >= 50) return AttentionLevel.engaged;
    if (_currentScore >= 25) return AttentionLevel.distracted;
    return AttentionLevel.idle;
  }
}
```

### 6.3 干预频控器 (RateLimiter)

```java
@Service
public class InterventionRateLimiter {

    @Autowired
    private RedisTemplate<String, String> redis;

    private static final String COOLDOWN_KEY = "attention:cooldown:%s:%s";     // userId:strategyId
    private static final String SESSION_COUNT_KEY = "attention:count:%s:%s:%s"; // userId:strategyId:sessionId

    /**
     * 检查是否可以触发干预
     */
    public boolean canTrigger(Long userId, String strategyId,
                              int cooldownMs, int maxPerSession,
                              String sessionId) {
        // 检查冷却
        String cooldownKey = String.format(COOLDOWN_KEY, userId, strategyId);
        String lastTrigger = redis.opsForValue().get(cooldownKey);
        if (lastTrigger != null) {
            long elapsed = System.currentTimeMillis() - Long.parseLong(lastTrigger);
            if (elapsed < cooldownMs) {
                return false;
            }
        }

        // 检查会话内次数
        String countKey = String.format(SESSION_COUNT_KEY, userId, strategyId, sessionId);
        String countStr = redis.opsForValue().get(countKey);
        int count = countStr != null ? Integer.parseInt(countStr) : 0;

        return count < maxPerSession;
    }

    /**
     * 记录一次干预触发
     */
    public void recordTrigger(Long userId, String strategyId, String sessionId) {
        String cooldownKey = String.format(COOLDOWN_KEY, userId, strategyId);
        redis.opsForValue().set(cooldownKey,
            String.valueOf(System.currentTimeMillis()),
            30, TimeUnit.MINUTES);

        String countKey = String.format(SESSION_COUNT_KEY, userId, strategyId, sessionId);
        redis.opsForValue().increment(countKey);
        // 会话级计数器2小时过期
        redis.expire(countKey, 2, TimeUnit.HOURS);
    }

    /**
     * 会话结束时清理
     */
    public void cleanupSession(Long userId, String sessionId) {
        Set<String> keys = redis.keys(String.format(
            "attention:count:%d:*:%s", userId, sessionId));
        if (keys != null && !keys.isEmpty()) {
            redis.delete(keys);
        }
    }
}
```

### 7.2 干预生命周期状态机

```
状态：PENDING → PRESENTED → RESPONDED → CLOSED

PENDING:   服务端决策触发干预，消息已发送
PRESENTED: 客户端已展示干预UI
RESPONDED: 用户已操作（点击按钮/关闭/忽略超时）
CLOSED:    记录完成，进入冷却期

异常分支:
PENDING → EXPIRED: 消息发送后10秒内未展示（可能网络问题）
PRESENTED → TIMEOUT: 展示超时自动消失（displayDurationMs到期）
PRESENTED → DISMISSED: 用户主动关闭
```

### 7.3 会话级注意力状态变化流程

```
1. 会话开始
   → 初始化 AttentionState (level=engaged, score=70)
   → 启动信号采集器
   → 启动端侧推断引擎

2. 实时监控循环（每10秒）
   → 采集最近30秒行为信号
   → 端侧推断注意力分数
   → 若分数变化>10 或 等级变化 → 上报服务端
   → 服务端返回确认/干预指令

3. 注意力分散检测
   → 连续2个窗口分数<50 → 标记为 distracted
   → 启动分散计时器
   → 分散持续>60s → 触发干预决策

4. 干预触发
   → 决策引擎选择策略
   → 频控检查通过
   → 推送干预消息到客户端
   → 客户端渲染干预UI

5. 干预响应
   → 用户操作 → 上报响应
   → 更新注意力状态（用户操作本身视为恢复信号）
   → 进入策略冷却期

6. 会话结束
   → 生成会话注意力报告
   → 更新日/周趋势统计
   → 清理会话级频控数据
```

### 8.1 行为信号采集器 (SignalCollector)

```dart
class AttentionSignalCollector {
  final WebSocketClient _ws;
  final List<BehaviorSignal> _batch = [];
  Timer? _flushTimer;
  DateTime? _lastActivity;

  static const int _batchSize = 20;
  static const Duration _flushInterval = Duration(seconds: 5);

  /// 初始化信号采集
  void start(String sessionId, SignalContext context) {
    _flushTimer = Timer.periodic(_flushInterval, (_) => _flush());
    _lastActivity = DateTime.now();

    // 启动 idle 检测
    _startIdleDetection(context);
  }

  /// 记录滚动
  void onScroll(String direction, double speed, double delta, SignalContext ctx) {
    _enqueue(BehaviorSignal(
      signalType: 'scroll',
      payload: {
        'scrollDirection': direction,
        'scrollSpeed': speed.round(),
        'scrollDelta': delta.round(),
      },
      context: ctx,
    ));
    _lastActivity = DateTime.now();
  }

  /// 记录点击
  void onTap(String target, SignalContext ctx) {
    _enqueue(BehaviorSignal(
      signalType: 'tap',
      payload: {'tapTarget': target},
      context: ctx,
    ));
    _lastActivity = DateTime.now();
  }

  /// 记录内容进度
  void onContentProgress(String contentType, double percent, double delta, SignalContext ctx) {
    _enqueue(BehaviorSignal(
      signalType: 'content_progress',
      payload: {
        'contentType': contentType,
        'progressPercent': percent,
        'progressDelta': delta,
      },
      context: ctx,
    ));
    _lastActivity = DateTime.now();
  }

  /// 记录答题提交
  void onAnswerSubmit(bool isCorrect, int timeSpentMs, SignalContext ctx) {
    _enqueue(BehaviorSignal(
      signalType: 'answer_submit',
      payload: {
        'isCorrect': isCorrect,
        'timeSpent': timeSpentMs,
      },
      context: ctx,
    ));
    _lastActivity = DateTime.now();
  }

  /// 应用前后台切换
  void onAppVisibilityChanged(bool isForeground, SignalContext ctx) {
    _enqueue(BehaviorSignal(
      signalType: 'app_visibility',
      payload: {
        'visibility': isForeground ? 'foreground' : 'background',
        'backgroundDuration': isForeground ? _calcBackgroundDuration() : 0,
      },
      context: ctx,
    ));
    if (isForeground) _lastActivity = DateTime.now();
  }

  /// idle 检测
  void _startIdleDetection(SignalContext ctx) {
    Timer.periodic(Duration(seconds: 10), (timer) {
      if (_lastActivity == null) return;
      final idleDuration = DateTime.now().difference(_lastActivity!).inMilliseconds;
      if (idleDuration >= 10000) {
        _enqueue(BehaviorSignal(
          signalType: 'idle',
          payload: {'idleDuration': idleDuration},
          context: ctx,
        ));
      }
    });
  }

  /// 批量上报
  void _enqueue(BehaviorSignal signal) {
    _batch.add(signal);
    if (_batch.length >= _batchSize) {
      _flush();
    }
  }

  void _flush() {
    if (_batch.isEmpty) return;
    final signals = List<BehaviorSignal>.from(_batch);
    _batch.clear();
    _ws.send(jsonEncode({
      'type': 'attention_signal',
      'data': {'signals': signals.map((s) => s.toJson()).toList()},
    }));
  }

  void stop() {
    _flushTimer?.cancel();
    _flush();
  }
}
```

## 9. 错误处理与降级策略

### 9.1 错误码定义

| 错误码 | 含义 | 处理方式 |
|--------|------|----------|
| `ATTENTION_001` | WebSocket断连 | 端侧继续独立推断，重连后同步 |
| `ATTENTION_002` | 信号上报失败 | 本地缓存，下次flush时重试 |
| `ATTENTION_003` | 服务端推断超时 | 使用端侧推断结果兜底 |
| `ATTENTION_004` | 干预消息渲染失败 | 降级为简单toast |
| `ATTENTION_005` | 用户关闭了注意力功能 | 停止所有采集和监控 |
| `ATTENTION_006` | 会话数据不完整 | 生成不完整报告 + 标注缺失时段 |

### 9.2 降级策略

```python
class AttentionDegradationManager:
    """注意力引擎降级管理"""

        # 1. 降低信号处理频率（从10秒→30秒）

        # 3. 干预决策延迟到非高峰期

        # 2. 上报间隔从5秒延长到15秒
        # 3. 端侧推断为主
        pass
```

### 9.3 隐私与安全

1. **不采集内容**：行为信号仅记录交互模式（时长、频率、方向），不记录实际学习内容或输入文字
2. **本地优先**：端侧推断不需要将原始信号发送到服务端，仅在等级变化时上报摘要
3. **用户可控**：设置页提供「注意力监测」开关，默认开启但可随时关闭
4. **家长可见性限制**：家长报告仅展示聚合统计（专注比例），不暴露详细的分心时刻
5. **数据保留**：原始行为信号保留7天后自动删除；聚合报告保留90天
6. **合规检查**：未成年人注意力监测功能上线前需通过隐私合规评审

## 10. 性能优化

### 10.1 信号采集优化

- **批量上报**：5秒或20条触发一次flush，减少网络请求
- **信号压缩**：WebSocket消息使用 MessagePack 编码，比 JSON 减少 30% 体积
- **端侧过滤**：无意义的高频信号（如连续微滚动）在端侧合并
- **自适应频率**：高专注状态下降低采集频率（30秒/次），分散状态提高频率（5秒/次）

### 10.2 服务端性能

- **流式处理**：使用响应式编程处理信号流，避免阻塞
- **窗口预聚合**：服务端维护滚动窗口状态，避免每次全量扫描
- **Redis热点缓存**：用户当前会话状态缓存在 Redis，避免 DB 查询
- **异步落盘**：信号先写 Redis/Kafka，批量异步写入 MySQL

### 10.3 容量预估

| 指标 | 估值 |
|------|------|
| 单用户单会话信号量 | ~200-500条/小时 |
| 在线学生并发数 | 50,000 (高峰) |
| 信号吞吐量 | ~10,000-25,000条/秒 |
| WebSocket连接数 | ~50,000 |
| 注意力状态计算QPS | ~5,000 (每10秒一次) |
