# 服务端-学科实验报告生成与数据分析辅助服务 - 详细设计

## 1. 概述

### 1.1 文档目的

本文档为 PrimeTop「学科实验报告生成与数据分析辅助服务」的服务端详细设计，为开发人员提供可直接编码落地的技术方案，涵盖数据模型、API 接口、核心算法、状态流转、错误处理等完整细节。

### 1.2 服务定位

本服务承接虚拟实验模拟操作完成后的数据，为学生提供：

1. **实验报告自动生成**：基于实验操作数据，生成结构化的实验报告初稿
2. **数据分析辅助**：对实验采集数据进行统计分析和可视化建议
3. **科学方法论引导**：引导学生按「假设→变量→步骤→数据→结论」的科学研究范式组织报告
4. **报告评价与反馈**：AI 评估报告质量并给出修改建议
5. **教师审阅批注**：支持教师对实验报告进行批改和批注

### 1.3 设计原则

- **引导式而非替代式**：报告生成后学生必须亲自修改、补充，避免直接代写
- **学科差异化**：物理、化学、生物实验报告结构不同，需按学科模板适配
- **分龄适配**：初中与高中实验报告要求深度不同，生成内容需匹配学段
- **数据安全**：实验数据属于学习行为数据，需遵循隐私保护规范

### 1.4 上下游依赖

```
虚拟实验模拟引擎  ──(实验完成事件)──▶  本服务  ──▶  实验报告存储
       │                                       │
       │                                       ├──▶ AI 对话引擎（报告润色/评价）
       │                                       ├──▶ 学习记录服务（完成记录）
       │                                       └──▶ 通知服务（教师批改通知）
```

| 依赖服务 | 交互方式 | 说明 |
|---------|---------|------|
| 实验数据管理服务 | RPC/内部调用 | 获取实验配置、采集数据、操作日志 |
| AI 对话引擎 | HTTP/SSE | 调用大模型生成报告内容、评价反馈 |
| 学习记录服务 | 事件消息 | 报告提交、批改完成后同步学习记录 |
| 通知服务 | 异步事件 | 教师批改后通知学生 |
| 文件存储服务 | SDK 调用 | 存储图表图片、导出 PDF |
| 用户服务 | RPC | 获取学生学段、年级信息 |

## 2. 数据模型

### 2.1 实验报告主表 `lab_report`

```sql
CREATE TABLE lab_report (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '报告ID',
    report_no       VARCHAR(32) NOT NULL UNIQUE COMMENT '报告编号，格式 LAB-RPT-YYYYMMDD-XXXX',
    student_id      BIGINT NOT NULL COMMENT '学生用户ID',
    experiment_id   BIGINT NOT NULL COMMENT '实验ID（关联虚拟实验）',
    subject_code    VARCHAR(16) NOT NULL COMMENT '学科编码：PHYSICS/CHEMISTRY/BIOLOGY',
    grade_level     VARCHAR(16) NOT NULL COMMENT '学段年级：JUNIOR_1/SENIOR_2 等',
    template_id     BIGINT NOT NULL COMMENT '使用的报告模板ID',
    
    -- 报告状态
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '状态：0-草稿 1-已提交 2-教师批改中 3-已批改 4-需修改',
    submit_count    INT NOT NULL DEFAULT 0 COMMENT '提交次数（允许修改重提）',
    
    -- 实验基础信息快照
    experiment_name VARCHAR(200) NOT NULL COMMENT '实验名称',
    experiment_type TINYINT NOT NULL COMMENT '实验类型：1-验证性 2-探究性 3-测量性 4-模拟性',
    
    -- 报告内容（JSON）
    content         JSON NOT NULL COMMENT '报告结构化内容，详见 2.2',
    
    -- AI 评价
    ai_score        DECIMAL(5,2) DEFAULT NULL COMMENT 'AI 评分（0-100）',
    ai_feedback     JSON DEFAULT NULL COMMENT 'AI 评价反馈，详见 2.5',
    
    -- 教师评价
    teacher_id      BIGINT DEFAULT NULL COMMENT '批改教师ID',
    teacher_score   DECIMAL(5,2) DEFAULT NULL COMMENT '教师评分',
    teacher_comment TEXT DEFAULT NULL COMMENT '教师评语',
    teacher_anns    JSON DEFAULT NULL COMMENT '教师批注列表',
    graded_at       DATETIME DEFAULT NULL COMMENT '批改时间',
    
    -- 时间
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    submitted_at    DATETIME DEFAULT NULL,
    
    -- 索引
    INDEX idx_student (student_id),
    INDEX idx_experiment (experiment_id),
    INDEX idx_teacher (teacher_id),
    INDEX idx_status (status),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='实验报告表';
```

**逻辑：**

1. 校验实验是否存在且学生已完成该实验
2. 检查是否已有该实验的草稿报告（避免重复创建）
3. 根据 `experimentId` 获取实验的学科、类型信息
4. 匹配最合适的报告模板（按学科 → 实验类型 → 年级匹配）
5. 初始化报告内容 JSON，所有章节设为空
6. 返回带模板结构的空报告

### 3.3 自动填充章节

```
POST /api/v1/lab-reports/{id}/auto-fill
Authorization: Bearer <token>
Content-Type: application/json
```

**Request:**

```json
{
  "sectionKeys": ["apparatus", "steps", "data"],
  "options": {
    "overwriteExisting": false
  }
}
```

**Response:**

```json
{
  "code": 0,
  "data": {
    "filledSections": {
      "apparatus": {
        "source": "experiment_config",
        "content": "烧杯(250mL)×3, 温度计(-10~100℃)×1, 量筒(50mL)×1, 试管×5, ...",
        "editable": true
      },
      "steps": {
        "source": "operation_log",
        "content": "1. 准备5支试管，分别标记为20℃、30℃、40℃、50℃、60℃\n2. 向每支试管中加入2mL酶溶液...\n3. ...",
        "editable": true
      },
      "data": {
        "source": "collected_data",
        "content": {
          "tables": [...],
          "charts": [...]
        },
        "editable": false
      }
    },
    "failedSections": [],
    "skippedSections": []
  }
}
```

**逻辑：**

1. 校验报告归属和状态（仅草稿可自动填充）
2. 遍历请求的 sectionKeys，检查模板是否标记 `autoFillable`
3. **器材（apparatus）**：从实验配置服务获取器材清单
4. **步骤（steps）**：从实验操作日志中提取操作序列，转化为自然语言描述
5. **数据（data）**：从实验数据管理服务获取采集数据，生成表格和图表
6. 标记自动填充的内容为 `autoFilled: true`，但允许学生后续编辑
7. 保存快照（snapshot_type=1, AI初稿）

```java
        List<ValidationCheck> checks = new ArrayList<>();
        
        // 1. 必填章节完整性
        for (SectionConfig section : template.getRequiredSections()) {
            boolean filled = report.getSection(section.getKey()).hasStudentInput();
            checks.add(new ValidationCheck("required_sections_filled", filled));
            if (!filled) throw new BusinessException(ErrorCode.REQUIRED_SECTION_EMPTY, section.getTitle());
        }
        
        // 2. 最低字数要求
        int totalWords = report.getMetadata().getTotalWordCount();

        // 3. 数据章节完整性
        boolean dataComplete = report.getDataSection().hasTableData();
        checks.add(new ValidationCheck("data_section_complete", dataComplete));
        
        // 4. 学生编辑比例（防止全篇 AI 代写）
        double studentEditRatio = report.getMetadata().getStudentEditedRatio();
        checks.add(new ValidationCheck("student_edited_ratio", studentEditRatio >= 0.5,

        // 5. 查重检测（与模板/范文的相似度）

        checks.add(new ValidationCheck("no_plagiarism_flag", similarity < 0.7,
            String.format("与范文相似度 %.0f%%", similarity * 100)));
        
        return new ValidationResult(checks.stream().allMatch(ValidationCheck::isPassed), checks);
```

```java
@Service
public class AutoFillEngine {
    
    @Autowired
    private ExperimentDataService experimentDataService;
    @Autowired
    private OperationLogService operationLogService;
    @Autowired
    private LabReportSectionSnapshotRepository snapshotRepo;
    
    /**
     * 自动填充报告章节
     * @param report 报告实体
     * @param sectionKeys 需要填充的章节列表
     * @param overwrite 是否覆盖已有内容
     */
    public AutoFillResult autoFill(LabReport report, List<String> sectionKeys, boolean overwrite) {
        AutoFillResult result = new AutoFillResult();
        
        for (String sectionKey : sectionKeys) {
            try {
                SectionContent section = report.getSection(sectionKey);
                
                // 跳过已有学生编辑内容的章节（除非强制覆盖）
                if (!overwrite && section.hasStudentEdited()) {
                    result.skip(sectionKey, "已有学生编辑内容");
                    continue;
                }
                
                Object filledContent = switch (sectionKey) {
                    case "apparatus" -> fillApparatus(report);
                    case "steps" -> fillSteps(report);
                    case "data" -> fillData(report);
                    default -> throw new BusinessException(
                        ErrorCode.SECTION_NOT_AUTO_FILLABLE, sectionKey);
                };
                
                section.setAutoFilled(filledContent);
                section.setAutoFillSource(getSource(sectionKey));
                
                // 保存快照
                snapshotRepo.save(new SectionSnapshot(
                    report.getId(), sectionKey, 
                    SnapshotType.AUTO_FILL, filledContent
                ));
                
                result.success(sectionKey, filledContent);
                
            } catch (Exception e) {
                log.error("自动填充失败: report={}, section={}", report.getId(), sectionKey, e);
                result.fail(sectionKey, e.getMessage());
            }
        }
        
        return result;
    }
    
    /**
     * 填充实验器材
     */
    private String fillApparatus(LabReport report) {
        ExperimentConfig config = experimentDataService.getConfig(report.getExperimentId());
        return config.getApparatusList().stream()
            .map(a -> String.format("%s(%s)×%d", a.getName(), a.getSpec(), a.getQuantity()))
            .collect(Collectors.joining(", "));
    }
    
    /**
     * 填充实验步骤（基于操作日志）
     */
    private String fillSteps(LabReport report) {
        List<OperationLog> logs = operationLogService.getLogs(
            report.getStudentId(), report.getExperimentId());
        
        // 将操作日志转化为自然语言步骤
        List<String> steps = new ArrayList<>();
        Map<String, Integer> stepCounter = new HashMap<>();
        
        for (OperationLog log : logs) {
            String stepText = OperationLogTranslator.translate(log);
            if (stepText != null) {
                steps.add(stepText);
            }
        }
        
        // 去重和合并相邻相似步骤
        return StepMerger.mergeAndNumber(steps);
    }
    
    /**
     * 填充实验数据（含自动图表生成）
     */
    private DataContent fillData(LabReport report) {
        ExperimentDataSet dataSet = experimentDataService.getDataSet(
            report.getStudentId(), report.getExperimentId());
        
        // 构建表格数据
        List<DataTable> tables = dataTableBuilder.build(dataSet);
        
        // 自动生成关键图表
        List<DataChart> charts = new ArrayList<>();
        for (DataTable table : tables) {
            ChartSuggestion suggestion = chartAdvisor.suggest(table, report.getSubjectCode());
            if (suggestion != null) {
                String chartUrl = chartGenerator.generate(suggestion, table);
                charts.add(new DataChart(suggestion.getType(), 
                    suggestion.getTitle(), chartUrl, 
                    suggestion.getXLabel(), suggestion.getYLabel()));
            }
        }
        
        return new DataContent(tables, charts);
    }
```

```java
@Service
public class ChartAdvisor {
    
    /**
     * 根据数据特征推荐图表类型
     */
    public ChartSuggestion suggest(DataTable table, String subjectCode) {
        List<DataColumn> columns = table.getColumns();
        int numericColumnCount = (int) columns.stream()
            .filter(c -> c.getType() ==ColumnType.NUMERIC).count();
        int categoryColumnCount = columns.size() - numericColumnCount;
        
        // 规则1：一个分类变量 + 一个数值变量 → 柱状图
        if (categoryColumnCount == 1 && numericColumnCount == 1) {
            return new ChartSuggestion("bar", 
                table.getTitle(), columns.get(0).getName(), 
                columns.get(1).getName());
        }
        
        // 规则2：有序数值变量 + 数值变量 → 折线图（判断趋势）
        if (categoryColumnCount == 0 && numericColumnCount == 2) {
            DataColumn xCol = columns.get(0);
            DataColumn yCol = columns.get(1);
            if (isSequential(xCol)) {
                return new ChartSuggestion("line",
                    String.format("%s-%s关系图", xCol.getName(), yCol.getName()),
                    xCol.getName(), yCol.getName());
            }
            return new ChartSuggestion("scatter",
                String.format("%s-%s散点图", xCol.getName(), yCol.getName()),
                xCol.getName(), yCol.getName());
        }
        
        // 规则3：三组以上数据对比 → 分组柱状图
        if (numericColumnCount >= 3 && categoryColumnCount >= 1) {
            return new ChartSuggestion("grouped_bar", 
                table.getTitle(), 
                columns.get(0).getName(), "数值");
        }
        
        // 规则4：占比数据 → 饼图
        if (isPercentageData(columns)) {
            return new ChartSuggestion("pie", table.getTitle(), null, "占比");
        }
        
        // 默认：散点图
        return new ChartSuggestion("scatter", table.getTitle(),
            columns.get(0).getName(), columns.get(1).getName());
    }
}
```

### 4.4 数据分析服务

```java
@Service
public class DataAnalysisService {
    
    /**
     * 趋势分析
     */
    public TrendAnalysisResult analyzeTrend(DataTable table, String xCol, String yCol) {
        double[] x = table.getColumnValues(xCol);
        double[] y = table.getColumnValues(yCol);
        
        // 1. 计算基本统计量
        BasicStats stats = StatisticsCalculator.calcBasic(y);
        
        // 2. 判断趋势方向
        TrendDirection direction = TrendDetector.detect(x, y);
        
        // 3. 寻找极值点
        ExtremumPoint extremum = ExtremumFinder.find(x, y);
        
        // 4. 曲线拟合（尝试多项式拟合，选择最优阶数）
        CurveFitResult fitResult = CurveFitter.fitPolynomial(x, y, 1, 3);
        
        // 5. 生成分析描述
        String description = generateTrendDescription(direction, extremum, stats, fitResult);
        
        return new TrendAnalysisResult(direction, extremum, stats, fitResult, description);
    }
    
    /**
     * 趋势方向检测
     */
    private static class TrendDetector {
        
        public static TrendDirection detect(double[] x, double[] y) {
            // 计算一阶差分
            int posDiffs = 0, negDiffs = 0;
            for (int i = 1; i < y.length; i++) {
                double diff = y[i] - y[i - 1];
                if (diff > 0) posDiffs++;
                else if (diff < 0) negDiffs++;
            }
            
            double posRatio = (double) posDiffs / (y.length - 1);
            double negRatio = (double) negDiffs / (y.length - 1);
            
            // 判断是否有明显极值点（先增后减 或 先减后增）
            if (posRatio > 0.3 && negRatio > 0.3) {
                // 存在拐点
                int peakIdx = findPeakIndex(y);
                if (peakIdx > 0 && peakIdx < y.length - 1) {
                    if (y[peakIdx] > y[0] && y[peakIdx] > y[y.length - 1]) {
                        return TrendDirection.BELL_SHAPED; // 钟形
                    } else {
                        return TrendDirection.U_SHAPED;     // U形
                    }
                }
                return TrendDirection.FLUCTUATING;            // 波动
            }
            
            if (posRatio > 0.7) return TrendDirection.INCREASING;
            if (negRatio > 0.7) return TrendDirection.DECREASING;
            return TrendDirection.FLUCTUATING;
        }
    }
    
    /**
     * 相关性分析
     */
    public CorrelationResult analyzeCorrelation(DataTable table, String col1, String col2) {
        double[] x = table.getColumnValues(col1);
        double[] y = table.getColumnValues(col2);
        
        // 皮尔逊相关系数
        double pearsonR = StatisticsCalculator.pearsonR(x, y);
        
        // 判断相关强度
        CorrelationStrength strength;
        double absR = Math.abs(pearsonR);
        if (absR >= 0.9) strength = CorrelationStrength.VERY_STRONG;
        else if (absR >= 0.7) strength = CorrelationStrength.STRONG;
        else if (absR >= 0.4) strength = CorrelationStrength.MODERATE;
        else if (absR >= 0.2) strength = CorrelationStrength.WEAK;
        else strength = CorrelationStrength.NEGLIGIBLE;
        
        return new CorrelationResult(pearsonR, strength, 
            String.format("%s与%s的皮尔逊相关系数为%.4f，呈%s%s相关",
                col1, col2, pearsonR, strength.getLabel(),
                pearsonR > 0 ? "正" : "负"));
    }
}
```

### 8.2 并发控制

```java
@Service
public class LabReportService {
    
    /**
     * 更新报告内容（乐观锁）
     */
    @Transactional
    public void updateContent(Long reportId, Long studentId, 
                              String sectionKey, Object content, 
                              int expectedVersion) {
        LabReport report = reportRepository.findById(reportId)
            .orElseThrow(() -> new BusinessException(REPORT_NOT_FOUND));
        
        // 权限检查
        if (!report.getStudentId().equals(studentId)) {
            throw new BusinessException(REPORT_NOT_OWNER);
        }
        
        // 状态检查
        if (report.getStatus() != ReportStatus.DRAFT && 
            report.getStatus() != ReportStatus.REVISION_REQUIRED) {
            throw new BusinessException(REPORT_NOT_DRAFT);
        }
        
        // 乐观锁检查
        if (report.getVersion() != expectedVersion) {
            throw new OptimisticLockException("报告已被修改，请刷新后重试");
        }
        
        // 更新章节内容
        report.updateSection(sectionKey, content);
        report.setVersion(expectedVersion + 1);
        
        reportRepository.save(report);
        
        // 异步更新自动保存快照
        eventPublisher.publishEvent(new ReportAutoSaveEvent(reportId, sectionKey, content));
    }
}
```
