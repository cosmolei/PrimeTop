# 客户端国际化与多语言支持 - 详细设计

> **模块定位**：客户端基础设施层 — 为 Flutter 移动端、Web 端和小程序端提供统一的多语言支持能力
> **覆盖学段**：全学段
> **优先级**：P1（V1.0 阶段实现基础中文支持，V1.5 阶段支持多地区方言适配，V2.0 阶段支持国际扩展）
> **原始需求来源**：`docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` §8.3、§12.4

---

## 1. 模块概述

### 1.1 功能定位

客户端国际化与多语言支持（i18n & L10n）模块为 PrimeTop 全平台提供：
1. **多语言文本管理**：中文简体、中文繁体、英语等语言的界面文本
2. **多地区适配**：日期格式、数字格式、货币格式、时区处理
3. **教材版本地区化**：不同地区教材版本的术语和表达方式适配
4. **动态语言切换**：运行时切换语言无需重启应用
5. **增量更新**：支持从服务端下载语言包增量更新
6. **性能优化**：语言资源按需加载、内存缓存策略

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 文本资源管理 | 管理 JSON/ARB 格式的多语言文本资源文件 |
| 翻译文本缓存 | 提供内存缓存，避免频繁文件读取 |
| 动态语言切换 | 支持用户在设置中切换语言，即时生效 |
| 格式化工具 | 提供日期、数字、货币、时区等格式化函数 |
| 插值支持 | 支持带参数的翻译文本（如"你答对${count}道题"） |
| 缺失文本处理 | 提供兜底策略，避免显示原始 key |
| 语言包更新 | 支持从服务端增量更新语言包 |

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 切换响应时间 | 语言切换后 500ms 内完成所有界面更新 |
| 内存占用 | 单语言包 ≤ 500KB，双语言包 ≤ 900KB |
| 首次加载时间 | 默认语言包加载 < 100ms |
| 缓存命中率 | 文本查询缓存命中率 > 95% |
| 翻译覆盖率 | 核心界面文本翻译覆盖率 > 95% |

### 1.4 适用范围

- Flutter 移动端（Android / iOS）
- Web 端（Flutter for Web）
- 微信小程序（可能需要独立实现）
- 管理后台（React/Angular 前端）

## 2. 数据结构设计

### 2.1 语言代码规范

采用 **BCP 47** 语言标签标准（IETF RFC 5646）：

| 代码 | 语言 | 地区 | 说明 |
|------|------|------|------|
| `zh-Hans` | 中文 | 简体 | 中国大陆、新加坡 |
| `zh-Hant` | 中文 | 繁体 | 台湾、香港、澳门 |
| `zh-Hans-SG` | 中文 | 简体新加坡 | 新加坡地区 |
| `zh-Hant-HK` | 中文 | 繁体香港 | 香港地区 |
| `en-US` | 英语 | 美国 | 美国英语 |
| `en-GB` | 英语 | 英国 | 英国英语 |

### 2.2 语言包文件结构

```
lib/l10n/
├── l10n.dart              # 自动生成的入口文件（由 intl_generator 生成）
├── app_en.arb             # 英语资源文件

├── app_zh_Hant.arb        # 繁体中文资源文件
├── messages.dart          # 自动生成的消息类
├── app_localizations.dart # 自动生成的本地化类
└── remote/                # 远程语言包缓存目录
    ├── app_zh_Hans_v1.arb
    └── app_zh_Hant_v1.arb
```

#### 4.2.2 语言缓存管理

```dart
/// lib/l10n/language_cache.dart

import 'package:shared_preferences/shared_preferences.dart';

/// 语言缓存管理器
class LanguageCache {
  LanguageCache._();

  static final LanguageCache instance = LanguageCache._();

  static const String _keyLanguageCode = 'language_code';
  static const String _keyPackageVersion = 'package_version_{lang}';

  /// 当前语言代码
  String? _currentLanguageCode;

  /// 语言包版本映射
  final Map<String, String> _packageVersions = {};

  /// 是否已初始化
  bool _isInitialized = false;

  /// 初始化
  Future<void> initialize() async {
    if (_isInitialized) return;

    final prefs = await SharedPreferences.getInstance();
    _currentLanguageCode = prefs.getString(_keyLanguageCode);

    // 加载所有已下载语言包的版本
    for (final langCode in ['zh-Hans', 'zh-Hant', 'en-US']) {
      final versionKey = _keyPackageVersion.replaceAll('{lang}', langCode);
      final version = prefs.getString(versionKey);
      if (version != null) {
        _packageVersions[langCode] = version;
      }
    }

    _isInitialized = true;
  }

  /// 获取当前语言代码
  String? get currentLanguageCode => _currentLanguageCode;

  /// 获取当前 Locale
  Locale get currentLocale {
    final langCode = _currentLanguageCode ?? 'zh-Hans';
    final parts = langCode.split('-');
    return Locale(parts[0], parts.length > 1 ? parts[1] : '');
  }

  /// 设置语言（会触发 MaterialApp 重建）
  Future<void> setLanguage(String languageCode) async {
    final prefs = await SharedPreferences.getInstance();

    _currentLanguageCode = languageCode;
    await prefs.setString(_keyLanguageCode, languageCode);
  }

  /// 获取语言包版本
  String? getPackageVersion(String languageCode) {
    return _packageVersions[languageCode];
  }

  /// 更新语言包版本
  Future<void> updatePackageVersion(String languageCode, String version) async {
    final prefs = await SharedPreferences.getInstance();

    _packageVersions[languageCode] = version;
    final versionKey = _keyPackageVersion.replaceAll('{lang}', languageCode);
    await prefs.setString(versionKey, version);
  }

  /// 重置缓存（用于调试或切换账号）
  Future<void> clear() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(_keyLanguageCode);

    _currentLanguageCode = null;
    _packageVersions.clear();
    _isInitialized = false;
  }
}
```

#### 4.2.3 语言包管理器

```dart
/// lib/l10n/language_package_manager.dart

import 'dart:convert';
import 'dart:io';
import 'package:flutter/services.dart';
import 'package:http/http.dart' as http;
import 'package:path_provider/path_provider.dart';
import 'package:crypto/crypto.dart';

/// 语言包更新信息
class LanguagePackageUpdate {
  final String languageCode;
  final String currentVersion;
  final String newVersion;
  final int sizeBytes;
  final String downloadUrl;
  final String checksum;
  final List<String> updateNotes;

  LanguagePackageUpdate({
    required this.languageCode,
    required this.currentVersion,
    required this.newVersion,
    required this.sizeBytes,
    required this.downloadUrl,
    required this.checksum,
    required this.updateNotes,
  });

  bool get isUpdate => currentVersion != newVersion;
}

/// 语言包管理器
class LanguagePackageManager {
  LanguagePackageManager._();

  static final LanguagePackageManager instance = LanguagePackageManager._();

  static const String _baseUrl = 'https://api.primetop.com/api/v1/i18n';
  static const String _cacheDir = 'l10n';

  /// 检查所有语言包更新
  Future<List<LanguagePackageUpdate?>> checkUpdates() async {
    final updates = <LanguagePackageUpdate?>[];

    // 检查每个支持的语言
    for (final langCode in ['zh-Hans', 'zh-Hant', 'en-US']) {
      final currentVersion = LanguageCache.instance.getPackageVersion(langCode) ?? '0.0.0';

      try {
        final update = await _checkLanguageUpdate(langCode, currentVersion);
        updates.add(update);
      } catch (e) {
        updates.add(null);
      }
    }

    return updates;
  }

  /// 检查单个语言包更新
  Future<LanguagePackageUpdate?> _checkLanguageUpdate(
    String languageCode,
    String currentVersion,
  ) async {
    final url = Uri.parse('$_baseUrl/language-package')
        .replace(queryParameters: {
      'lang': languageCode,
      'currentVersion': currentVersion,
    });

    final response = await http.get(url);

    if (response.statusCode != 200) {
      return null;
    }

    final json = jsonDecode(utf8.decode(response.bodyBytes));
    final code = json['code'] as int;

    if (code != 0) {
      return null;
    }

    final data = json['data'] as Map<String, dynamic>;
    final hasUpdate = data['hasUpdate'] as bool;

    if (!hasUpdate) {
      return null;
    }

    return LanguagePackageUpdate(
      languageCode: languageCode,
      currentVersion: currentVersion,
      newVersion: data['newVersion'] as String,
      sizeBytes: data['sizeBytes'] as int,
      downloadUrl: data['downloadUrl'] as String,
      checksum: data['checksum'] as String,
      updateNotes: (data['updateNotes'] as List<dynamic>)
          .map((e) => e as String)
          .toList(),
    );
  }

  /// 下载语言包
  Future<bool> downloadLanguagePackage(
    LanguagePackageUpdate update,
    void Function(int downloaded, int total)? onProgress,
  ) async {
    try {
      // 下载文件
      final response = await http.Client().send(
        http.Request('GET', Uri.parse(update.downloadUrl)),
      );

      final totalBytes = response.contentLength ?? 0;
      final bytes = <int>[];

      final stream = response.stream.listen(
        (List<int> chunk) {
          bytes.addAll(chunk);
          onProgress?.call(bytes.length, totalBytes);
        },
        onDone: () async {
          // 校验完整性
          final checksum = sha256.convert(bytes).toString();
          final expectedChecksum = update.checksum.replace('sha256:', '');

          if (checksum != expectedChecksum) {
            throw Exception('Language package checksum mismatch');
          }

          // 保存文件
          final cacheDir = await _getCacheDirectory();
          final fileName = 'app_${update.languageCode.replaceAll('-', '_')}_${update.newVersion}.arb';
          final file = File('${cacheDir.path}/$fileName');

          await file.writeAsBytes(bytes);

          // 更新缓存版本
          await LanguageCache.instance.updatePackageVersion(
            update.languageCode,
            update.newVersion,
          );
        },
        onError: (e) {
          throw e;
        },
        cancelOnError: true,
      );

      await stream.asFuture();
      return true;
    } catch (e) {
      return false;
    }
  }

  /// 获取缓存目录
  Future<Directory> _getCacheDirectory() async {
    final tempDir = await getTemporaryDirectory();
    final cacheDir = Directory('${tempDir.path}/$_cacheDir');

    if (!await cacheDir.exists()) {
      await cacheDir.create(recursive: true);
    }

    return cacheDir;
  }

  /// 加载远程语言包
  Future<Map<String, dynamic>>? loadRemoteLanguagePackage(
    String languageCode,
  ) async {
    try {
      final version = LanguageCache.instance.getPackageVersion(languageCode);

      if (version == null) {
        return null;
      }

      final cacheDir = await _getCacheDirectory();
      final fileName = 'app_${languageCode.replaceAll('-', '_')}_$version.arb';
      final file = File('${cacheDir.path}/$fileName');

      if (!await file.exists()) {
        return null;
      }

      final content = await file.readAsString();
      return jsonDecode(content) as Map<String, dynamic>;
    } catch (e) {
      return null;
    }
  }

  /// 上报翻译缺失
  Future<bool> reportMissingTranslations(
    String languageCode,
    List<String> missingKeys,
  ) async {
    try {
      final url = Uri.parse('$_baseUrl/missing-translation');

      final response = await http.post(
        url,
        headers: {
          'Content-Type': 'application/json',
        },
        body: jsonEncode({
          'languageCode': languageCode,
          'missingKeys': missingKeys,
          'clientVersion': '1.2.3', // 从配置读取
          'platform': Platform.isAndroid ? 'android' : 'ios',
        }),
      );

      return response.statusCode == 200;
    } catch (e) {
      return false;
    }
  }
```

```dart
/// lib/l10n/cache_strategy.dart

/// 翻译缓存项
class _TranslationCacheItem {
  final String value;
  final DateTime timestamp;

  _TranslationCacheItem(this.value) : timestamp = DateTime.now();
}

/// 翻译缓存管理器
class TranslationCacheManager {
  TranslationCacheManager._();

  static final TranslationCacheManager instance = TranslationCacheManager._();

  final Map<String, _TranslationCacheItem> _cache = {};

  /// 最大缓存数量
  static const int _maxCacheSize = 1000;

  /// 缓存有效期（分钟）
  static const int _cacheExpirationMinutes = 30;

  /// 获取缓存
  String? get(String key) {
    final item = _cache[key];
    if (item == null) return null;

    // 检查是否过期
    final now = DateTime.now();
    final age = now.difference(item.timestamp);

    if (age.inMinutes > _cacheExpirationMinutes) {
      _cache.remove(key);
      return null;
    }

    return item.value;
  }

  /// 设置缓存
  void set(String key, String value) {
    // 如果缓存已满，清理最旧的项
    if (_cache.length >= _maxCacheSize) {
      _evictOldest();
    }

    _cache[key] = _TranslationCacheItem(value);
  }

  /// 清理最旧的缓存项
  void _evictOldest() {
    if (_cache.isEmpty) return;

    var oldestKey = _cache.keys.first;
    var oldestTimestamp = _cache[oldestKey]!.timestamp;

    for (final entry in _cache.entries) {
      if (entry.value.timestamp.isBefore(oldestTimestamp)) {
        oldestKey = entry.key;
        oldestTimestamp = entry.value.timestamp;
      }
    }

    _cache.remove(oldestKey);
  }

  /// 清空缓存
  void clear() {
    _cache.clear();
  }

  /// 获取缓存统计
  Map<String, dynamic> getStats() {
    return {
      'size': _cache.length,
      'maxSize': _maxCacheSize,
      'expirationMinutes': _cacheExpirationMinutes,
    };
  }
}
```

```dart
/// lib/l10n/security.dart

import 'dart:convert';
import 'dart:io';
import 'package:crypto/crypto.dart';

/// 语言包校验器
class LanguagePackageValidator {
  /// 校验语言包完整性
  static Future<bool> validatePackage(
    File packageFile,
    String expectedChecksum,
  ) async {
    try {
      final bytes = await packageFile.readAsBytes();
      final actualChecksum = sha256.convert(bytes).toString();
      final expected = expectedChecksum.replace('sha256:', '');

      return actualChecksum == expected;
    } catch (e) {
      return false;
    }
  }

  /// 校验语言包格式
  static bool validateFormat(Map<String, dynamic> package) {
    // 检查必要的字段
    if (!package.containsKey('@@last_modified')) {
      return false;
    }

    // 检查是否有 @ 开头的元数据字段
    final hasMetadata = package.keys.any((key) => key.startsWith('@'));
    if (!hasMetadata) {
      return false;
    }

    // 检查是否有至少一个翻译键
    final hasTranslations = package.keys.any((key) => !key.startsWith('@'));
    if (!hasTranslations) {
      return false;
    }

    return true;
  }

  /// 校验 ARB 文件语法
  static bool validateArbSyntax(String content) {
    try {
      final json = jsonDecode(content);
      return json is Map<String, dynamic>;
    } catch (e) {
      return false;
    }
  }
}
```

   ```json
   "new_feature_desc": "这是一个新功能的描述",
   "@new_feature_title": {
     "description": "新功能页面标题"
   }
   ```

2. 在 `lib/l10n/app_en.arb` 中添加对应的英文翻译：
   ```json
   "new_feature_title": "New Feature",
   "new_feature_desc": "This is a description of a new feature",
   "@new_feature_title": {
     "description": "New feature page title"
   }
   ```

3. 运行代码生成：
   ```bash
   flutter pub run build_runner build --delete-conflicting-outputs
   flutter gen-l10n
   ```

4. 在代码中使用：
   ```dart
   final l10n = AppLocalizations.of(context)!;
   Text(l10n.new_feature_title)
   ```

### 10.2 使用带参数的翻译

1. 在 ARB 文件中定义：
   ```json
   "quiz_result": "你答对 {correct} 题，答错 {wrong} 题",
   "@quiz_result": {
     "placeholders": {
       "correct": {
         "type": "int",
         "example": "5"
       },
       "wrong": {
         "type": "int",
         "example": "2"
       }
     }
   }
   ```

2. 在代码中使用：
   ```dart
   final l10n = AppLocalizations.of(context)!;
   Text(l10n.quizResult(correct: 5, wrong: 2))
   ```

### 10.3 添加复数形式

1. 在 ARB 文件中定义：
   ```json
   "quiz_count_one": "1 题",
   "quiz_count_other": "{count} 题",
   "@quiz_count": {
     "plural": "quiz_count",
     "description": "题目数量",
     "placeholders": {
       "count": {
         "type": "int"
       }
     }
   }
   ```

2. 在代码中使用：
   ```dart
   final l10n = AppLocalizations.of(context)!;
   Text(l10n.quizCount(count))
   ```

### 12.2 常见问题

**Q: 如何添加新的语言支持？**
A: 在 `lib/l10n/` 目录下创建新的 ARB 文件，并在 `MaterialApp` 的 `supportedLocales` 中添加对应的 Locale。

**Q: 语言包更新后，用户需要重启应用吗？**
A: 不需要。语言包下载后，下次启动应用时会自动使用新版本。如果需要立即生效，可以调用 `setState` 触发重建。

**Q: 如何处理特定地区的术语差异？**
A: 可以为不同地区创建独立的语言包（如 `zh-Hans-CN` 和 `zh-Hans-SG`），或使用动态数据服务加载地区化术语。

**Q: 如何调试翻译问题？**
A: 在调试模式下，缺失的翻译会显示为 `⚠️key⚠️`，便于快速定位问题。
