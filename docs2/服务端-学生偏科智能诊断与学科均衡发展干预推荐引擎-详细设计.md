# 服务端-学生偏科智能诊断与学科均衡发展干预推荐引擎-详细设计

## 1. 模块概述

### 1.1 功能定位

偏科是中国基础教育场景中最常见的学习问题之一——学生在某些学科上投入不足或表现明显低于其他学科，长期累积导致综合成绩受限。本引擎负责从多维度学习数据中自动诊断学生的偏科状况，识别偏科根因，并生成个性化的学科均衡发展干预方案。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 偏科检测 | 基于成绩、投入时间、答题正确率、学习活跃度等多维度数据，自动识别偏科学科 |
| 根因分析 | 分析偏科成因（基础薄弱/兴趣缺失/方法不当/时间分配失衡/心理排斥） |
| 风险预警 | 对偏科程度进行分级（轻度/中度/重度），触发不同级别的干预 |
| 干预推荐 | 生成个性化改善方案，包括学习计划调整、内容推荐、激励策略 |
| 进度追踪 | 跟踪干预方案执行效果，动态调整干预力度 |
| 家校联动 | 向家长端、教师端推送偏科预警和改善建议 |

### 1.3 与现有模块的关系

| 关联模块 | 关系说明 |
|----------|----------|
| 学科能力维度评估 | 提供单科能力数据，本引擎做**跨学科对比分析** |
| 每日学习时间智能分配 | 提供时间分配数据，本引擎做**长期趋势分析** |
| 学情分析 | 提供学习记录基础数据，本引擎做**偏科专项诊断** |
| 学习规划 | 接收本引擎输出的干预方案，调整学习计划 |
| 学习推荐 | 接收本引擎输出的偏科内容推荐请求 |
| 家长中心 | 接收偏科预警报告和家庭教育建议 |
| 教师端 | 接收班级偏科统计和共性偏科分析 |

### 1.4 适用学段

| 学段 | 偏科关注点 |
|------|------------|
| 小学 | 关注语数英三科均衡，及时发现早期偏科苗头 |
| 初中 | 全科均衡（含政史地生物），中考导向，偏科影响录取 |
| 高中 | 高考选科前均衡评估，选科后优势聚焦但需防短板拖累 |

### 3.2 四维度评分模型

#### 3.2.1 成绩维度（Performance Score）

```java
/**
 * 成绩维度得分计算
 * 综合考虑：近期答题正确率、阶段测评成绩、错题订正率
 */
public class PerformanceScorer {
    
    private static final double WEIGHT_CORRECT_RATE = 0.4;
    private static final double WEIGHT_EXAM_SCORE = 0.4;
    private static final double WEIGHT_CORRECTION_RATE = 0.2;
    
    /**
     * 计算学科成绩维度得分
     * @param stats 学科周期统计数据
     * @return 0-100 分
     */
    public BigDecimal calculate(SubjectPeriodStats stats) {
        // 1. 答题正确率得分（直接使用百分制）
        double correctRateScore = stats.getCorrectRate().doubleValue();
        
        // 2. 阶段测评得分（如果有，取最近 N 次加权平均）
        double examScore = calculateExamScore(stats.getRecentExams());
        
        // 3. 错题订正率得分
        double correctionScore = stats.getCorrectionRate() != null 
            ? stats.getCorrectionRate().doubleValue() 
            : 50.0; // 无数据时给中性分
        
        double composite = WEIGHT_CORRECT_RATE * correctRateScore 
                         + WEIGHT_EXAM_SCORE * examScore 
                         + WEIGHT_CORRECTION_RATE * correctionScore;
        
        return BigDecimal.valueOf(composite).setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 测评成绩指数衰减加权
     * 越近期的考试权重越高
     */
    private double calculateExamScore(List<ExamResult> exams) {
        if (exams.isEmpty()) return 50.0; // 无数据时给中性分
        
        double weightedSum = 0;
        double totalWeight = 0;
        for (int i = 0; i < exams.size(); i++) {
            double weight = Math.exp(-i * 0.3); // 指数衰减
            weightedSum += exams.get(i).getScore() * weight;
            totalWeight += weight;
        }
        return weightedSum / totalWeight;
    }
}
```

#### 3.2.2 投入维度（Investment Score）

```java
/**
 * 投入维度得分计算
 * 核心思路：比较该学科实际时间占比与理想均衡占比的偏差
 * 偏差越小，得分越高；偏差越大（不管是过多还是过少），得分越低
 */
public class InvestmentScorer {
    
    /**
     * 计算投入维度得分
     * @param subjectStudyMin 该学科学习时长
     * @param totalStudyMin 总学习时长
     * @param subjectCount 学生应学学科总数
     * @return 0-100 分
     */
    public BigDecimal calculate(int subjectStudyMin, int totalStudyMin, int subjectCount) {
        if (totalStudyMin == 0) return new BigDecimal("50.00");
        
        // 实际时间占比
        double actualRatio = (double) subjectStudyMin / totalStudyMin;
        
        // 理想均衡占比（考虑学科权重差异）
        double idealRatio = calculateIdealRatio(subjectCount);
        
        // 计算偏差比例
        double deviation = Math.abs(actualRatio - idealRatio) / idealRatio;
        
        // 偏差越大得分越低，使用指数衰减映射
        // deviation=0 → 100分; deviation=0.5 → ~78分; deviation=1.0 → ~61分; deviation=2.0 → ~37分
        double score = 100 * Math.exp(-0.5 * deviation);
        
        // 特殊处理：投入严重不足（实际占比 < 理想的50%）时额外扣分
        if (actualRatio < idealRatio * 0.5) {
            score *= 0.8;
        }
        
        return BigDecimal.valueOf(score).setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 计算学科理想时间占比
     * 基础学科（语数英）权重略高于其他学科
     */
    private double calculateIdealRatio(int subjectCount) {
        // 简化模型：均分基础上的微调
        // 实际实现中从配置表读取各学科权重
        return 1.0 / subjectCount;
    }
}
```

#### 3.2.3 活跃度维度（Engagement Score）

```java
/**
 * 活跃度维度得分计算
 * 综合考虑：学习频次、互动行为（提问、笔记、收藏）、连续性
 */
public class EngagementScorer {
    
    public BigDecimal calculate(EngagementSignals signals) {
        // 1. 学习频次得分：该学科在周期内的活跃天数占比
        double frequencyScore = Math.min(100, 
            (double) signals.getActiveDays() / signals.getPeriodDays() * 100 * 1.5);
        
        // 2. 互动强度得分：AI提问、笔记、收藏、错题操作等行为频次
        double interactionScore = Math.min(100, 
            signals.getInteractionCount() / signals.getExpectedInteractions() * 100);
        
        // 3. 连续性得分：学习是否断断续续
        double continuityScore = calculateContinuity(
            signals.getStudyDateList(), signals.getPeriodDays());
        
        // 4. 逃避信号检测：是否有回避该学科的明显行为
        double avoidancePenalty = calculateAvoidancePenalty(signals);
        
        double composite = (frequencyScore * 0.35 
                          + interactionScore * 0.30 
                          + continuityScore * 0.35) * (1 - avoidancePenalty);
        
        return BigDecimal.valueOf(Math.max(0, composite))
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 逃避信号检测
     * 检测：跳过该学科任务、快速退出该学科页面、从不主动进入该学科
     */
    private double calculateAvoidancePenalty(EngagementSignals signals) {
        double penalty = 0;
        if (signals.getTaskSkipRate() > 0.5) penalty += 0.15;      // 频繁跳过任务
        if (signals.getAvgSessionDurationSec() < 30) penalty += 0.10; // 极短会话
        if (!signals.isProactiveEntry()) penalty += 0.10;            // 从不主动进入
        if (signals.getQuickExitCount() > 3) penalty += 0.05;        // 多次快速退出
        return Math.min(0.4, penalty);
    }
}
```

```java
/**
 * 掌握度维度得分计算
 * 基于知识追踪模型的知识点掌握率，结合答题正确率和题型覆盖

                         + coverageRate * 100 * 0.25
                         + typeDiversityScore * 0.15
                         + difficultyGradientScore * 0.15;
        
        return BigDecimal.valueOf(composite).setScale(2, RoundingMode.HALF_UP);
```

### 3.3 偏科指数计算

```java
/**
 * 偏科指数计算引擎
 * 综合四维度数据，计算学生的综合偏科指数和各学科的偏科程度
 */
public class ImbalanceIndexCalculator {
    
    // 各维度权重（可按学段调整）
    private static final Map<String, double[]> STAGE_WEIGHTS = Map.of(
        "PRIMARY", new double[]{0.35, 0.15, 0.20, 0.30},  // 小学：重成绩和掌握度
        "JUNIOR",  new double[]{0.35, 0.20, 0.15, 0.30},  // 初中：成绩和掌握度并重
        "SENIOR",  new double[]{0.40, 0.20, 0.10, 0.30}   // 高中：成绩主导
    );
    // weights = [performance, investment, engagement, mastery]
    
    /**
     * 计算单学科综合得分
     */
    public SubjectComposite calculateSubjectScore(
            SubjectBalanceSnapshot snapshot, String stage) {
        double[] weights = STAGE_WEIGHTS.getOrDefault(stage, STAGE_WEIGHTS.get("JUNIOR"));
        
        double score = snapshot.getPerformanceScore().doubleValue() * weights[0]
                     + snapshot.getInvestmentScore().doubleValue() * weights[1]
                     + snapshot.getEngagementScore().doubleValue() * weights[2]
                     + snapshot.getMasteryScore().doubleValue() * weights[3];
        
        SubjectComposite composite = new SubjectComposite();
        composite.setSubjectCode(snapshot.getSubjectCode());
        composite.setCompositeScore(BigDecimal.valueOf(score).setScale(2, RoundingMode.HALF_UP));
        composite.setPerformanceScore(snapshot.getPerformanceScore());
        composite.setInvestmentScore(snapshot.getInvestmentScore());
        composite.setEngagementScore(snapshot.getEngagementScore());
        composite.setMasteryScore(snapshot.getMasteryScore());
        return composite;
    }
    
    /**
     * 计算综合偏科指数
     * 使用各学科综合得分的变异系数（CV）作为偏科指数的核心
     */
    public ImbalanceResult calculateImbalanceIndex(
            List<SubjectComposite> subjects, String stage) {
        
        if (subjects.size() < 2) {
            return ImbalanceResult.normal();
        }
        
        // 1. 提取各学科综合得分
        List<Double> scores = subjects.stream()
            .map(s -> s.getCompositeScore().doubleValue())
            .sorted()
            .collect(Collectors.toList());
        
        // 2. 计算统计量
        double mean = scores.stream().mapToDouble(d -> d).average().orElse(0);
        double stdDev = Math.sqrt(
            scores.stream().mapToDouble(d -> Math.pow(d - mean, 2)).sum() / scores.size());
        double cv = stdDev / mean; // 变异系数
        
        // 3. 计算极差（最强与最弱学科的差距）
        double max = scores.get(scores.size() - 1);
        double min = scores.get(0);
        double range = max - min;
        
        // 4. 综合偏科指数 = CV映射分(60%) + 极差映射分(40%)
        // CV典型范围 0.0~0.5，映射到 0~100
        double cvScore = Math.min(100, cv * 200);
        // 极差典型范围 0~60，映射到 0~100
        double rangeScore = Math.min(100, range * 100 / 60);
        
        double imbalanceIndex = cvScore * 0.6 + rangeScore * 0.4;
        
        // 5. 确定偏科级别
        String level = determineLevel(imbalanceIndex, stage);
        
        // 6. 识别偏科学科
        List<SubjectImbalanceDetail> details = identifyImbalanceSubjects(
            subjects, mean, stdDev);
        
        ImbalanceResult result = new ImbalanceResult();
        result.setImbalanceIndex(BigDecimal.valueOf(imbalanceIndex).setScale(2, RoundingMode.HALF_UP));
        result.setImbalanceLevel(level);
        result.setStrongestSubject(scores.isEmpty() ? null 
            : subjects.stream().max(Comparator.comparing(SubjectComposite::getCompositeScore))
                .get().getSubjectCode());
        result.setWeakestSubject(
            subjects.stream().min(Comparator.comparing(SubjectComposite::getCompositeScore))
                .get().getSubjectCode());
        result.setMaxSubjectGap(BigDecimal.valueOf(range).setScale(2, RoundingMode.HALF_UP));
        result.setImbalanceSubjects(details);
        return result;
    }
    
    /**
     * 偏科级别判定
     */
    private String determineLevel(double index, String stage) {
        // 不同学段阈值不同
        double[] thresholds = switch (stage) {
            case "PRIMARY" -> new double[]{15, 30, 50};  // 小学更严格
            case "JUNIOR"  -> new double[]{20, 35, 55};  // 初中中等
            case "SENIOR"  -> new double[]{25, 40, 60};  // 高中更宽容（选科后自然分化）
            default         -> new double[]{20, 35, 55};
        };
        
        if (index < thresholds[0]) return "NORMAL";
        if (index < thresholds[1]) return "MILD";
        if (index < thresholds[2]) return "MODERATE";
        return "SEVERE";
    }
    
    /**
     * 识别偏科学科
     * 标记得分低于均值-1个标准差的学科为偏科学科
     */
    private List<SubjectImbalanceDetail> identifyImbalanceSubjects(
            List<SubjectComposite> subjects, double mean, double stdDev) {
        
        double weakThreshold = mean - stdDev; // 低于均值1个标准差
        double strongThreshold = mean + stdDev;
        
        return subjects.stream().map(s -> {
            SubjectImbalanceDetail detail = new SubjectImbalanceDetail();
            detail.setSubjectCode(s.getSubjectCode());
            detail.setCompositeScore(s.getCompositeScore());
            detail.setGap(BigDecimal.valueOf(s.getCompositeScore().doubleValue() - mean)
                .setScale(2, RoundingMode.HALF_UP));
            
            if (s.getCompositeScore().doubleValue() < weakThreshold) {
                detail.setCategory("WEAK");
                detail.setTrend("NEEDS_ATTENTION");
            } else if (s.getCompositeScore().doubleValue() > strongThreshold) {
                detail.setCategory("STRONG");
            } else {
                detail.setCategory("AVERAGE");
            }
            return detail;
        }).collect(Collectors.toList());
    }
}
```

### 3.4 根因分析模型

```java
/**
 * 偏科根因分析
 * 通过多维数据交叉分析，推断偏科的具体原因
 */
public class RootCauseAnalyzer {
    
    public enum ImbalanceCause {
        FOUNDATION_WEAK,       // 基础薄弱：前期知识点掌握差导致后续跟不上
        INSUFFICIENT_TIME,     // 时间不足：投入时间明显低于均衡水平
        METHOD_MISMATCH,       // 方法不当：投入了时间但效果差
        INTEREST_DEFICIT,      // 兴趣缺失：活跃度低、逃避行为明显
        CONTENT_GAP,           // 内容缺失：教材版本/资源不匹配
        EXAM_ANXIETY,          // 考试焦虑：平时练习好但考试成绩差
        COGNITIVE_MISMATCH     // 认知不匹配：难度偏好与实际水平差距大
    }
    
    /**
     * 分析单个偏科学科的根因
     */
    public List<CauseAnalysis> analyze(SubjectComposite subject, 
                                        SubjectBalanceSnapshot snapshot,
                                        UserProfile profile) {
        List<CauseAnalysis> causes = new ArrayList<>();
        double perfScore = subject.getPerformanceScore().doubleValue();
        double investScore = subject.getInvestmentScore().doubleValue();
        double engageScore = subject.getEngagementScore().doubleValue();
        double masteryScore = subject.getMasteryScore().doubleValue();
        
        // 规则1：基础薄弱 — 掌握度低 + 正确率低
        if (masteryScore < 50 && perfScore < 50) {
            causes.add(buildCause(FOUNDATION_WEAK, 0.8, 
                "知识点掌握率偏低(%s%%)，基础概念存在明显缺漏".formatted(
                    masteryScore)));
        }
        
        // 规则2：时间不足 — 投入维度低
        if (investScore < 50) {
            causes.add(buildCause(INSUFFICIENT_TIME, 0.7,
                "该学科学习时间占比明显低于均衡水平，建议增加投入"));
        }
        
        // 规则3：方法不当 — 投入高但效果差
        if (investScore >= 60 && masteryScore < 55) {
            causes.add(buildCause(METHOD_MISMATCH, 0.75,
                "学习时间投入尚可但掌握度不高，可能学习方法需要调整"));
        }
        
        // 规则4：兴趣缺失 — 活跃度极低 + 逃避信号
        if (engageScore < 40) {
            causes.add(buildCause(INTEREST_DEFICIT, 0.7,
                "该学科学习活跃度低，互动行为少，建议通过趣味内容激发兴趣"));
        }
        
        // 规则5：内容缺失 — 有学习行为但知识点覆盖低
        if (investScore > 50 && masteryScore < 45 && 
            snapshot.getKnowledgeMasteryRate().doubleValue() < 0.3) {
            causes.add(buildCause(CONTENT_GAP, 0.6,
                "学习内容覆盖不全，可能教材版本不匹配或资源缺失"));
        }
        
        // 规则6：考试焦虑 — 平时练习好但测评差
        if (perfScore > 70 && snapshot.getCorrectRate().doubleValue() > 75 
            && hasLowExamHistory(subject.getSubjectCode(), profile)) {
            causes.add(buildCause(EXAM_ANXIETY, 0.65,
                "平时练习表现良好但考试成绩不理想，可能存在考试焦虑"));
        }
        
        // 规则7：认知不匹配 — 难度偏好异常
        DifficultyPreference pref = getDifficultyPreference(profile.getUserId(), 
            subject.getSubjectCode());
        if (pref != null && pref.hasMismatch()) {
            causes.add(buildCause(COGNITIVE_MISMATCH, 0.55,
                "练习难度与学生实际水平不匹配，%s".formatted(pref.getDescription())));
        }
        
        // 按置信度排序
        causes.sort((a, b) -> Double.compare(b.getConfidence(), a.getConfidence()));
        return causes;
    }
    
    private CauseAnalysis buildCause(ImbalanceCause cause, double confidence, String desc) {
        CauseAnalysis analysis = new CauseAnalysis();
        analysis.setCause(cause.name());
        analysis.setConfidence(BigDecimal.valueOf(confidence)
            .setScale(2, RoundingMode.HALF_UP));
        analysis.setDescription(desc);
        return analysis;
    }
}
```

```java
 * 根据根因分析结果选择干预策略组合

public class StrategySelector {
    
    public List<InterventionStrategy> selectStrategies(
            List<CauseAnalysis> causes, 
            SubjectComposite subject,
            StudentProfile profile) {
        
        Set<InterventionStrategy> strategies = new LinkedHashSet<>();
        
        for (CauseAnalysis cause : causes) {
            switch (cause.getCause()) {
                case "FOUNDATION_WEAK" -> {
                    strategies.add(FOUNDATION_REBUILD);
                    strategies.add(PROGRESSIVE_DIFFICULTY);
                }
                case "INSUFFICIENT_TIME" -> {
                    strategies.add(TIME_REALLOCATION);
                }
                case "METHOD_MISMATCH" -> {
                    strategies.add(METHOD_COACHING);
                    strategies.add(PROGRESSIVE_DIFFICULTY);
                }
                case "INTEREST_DEFICIT" -> {
                    strategies.add(INTEREST_STIMULATION);
                    strategies.add(INCENTIVE_BOOST);
                    strategies.add(PEER_MOTIVATION);
                }
                case "CONTENT_GAP" -> {
                    strategies.add(FOUNDATION_REBUILD);
                }
                case "EXAM_ANXIETY" -> {
                    strategies.add(EXAM_DESENSITIZATION);
                }
                case "COGNITIVE_MISMATCH" -> {
                    strategies.add(PROGRESSIVE_DIFFICULTY);
                    strategies.add(METHOD_COACHING);
                }
            }
        }
        
        // 始终包含时间重新分配作为基础策略
        strategies.add(TIME_REALLOCATION);
        
        return new ArrayList<>(strategies);
    }
```

```java
    /**
     * 为偏科学科匹配推荐内容
     */
    public List<RecommendedContent> match(
            String subjectCode,
            List<InterventionStrategy> strategies,
            StudentProfile profile,
            RootCauseAnalysis rootCause) {

        // 1. 基础重建：找出未掌握的前置知识点对应内容

            List<String> weakPrerequisites = findWeakPrerequisites(

                results.addAll(findContentByKnowledgePoint(
                    kp, ContentDifficulty.BASIC, 3));
            }
        }
        
        // 2. 兴趣激发：推荐互动性强的趣味内容
        if (strategies.contains(INTEREST_STIMULATION)) {
            results.addAll(findInteractiveContent(
                subjectCode, profile.getStage(), 2));
        }
        
        // 3. 渐进难度：从 EASY 开始的练习集
        if (strategies.contains(PROGRESSIVE_DIFFICULTY)) {
            results.add(findProgressiveExerciseSet(
                subjectCode, ContentDifficulty.EASY));
        }
        
        // 4. 方法指导：学法类文章/视频
        if (strategies.contains(METHOD_COACHING)) {
            results.addAll(findMethodGuideContent(subjectCode, 2));
        }
        
        // 5. 考试脱敏：模拟试卷+计时练习
        if (strategies.contains(EXAM_DESENSITIZATION)) {
            results.add(findMockExam(subjectCode, profile.getGrade()));
        }
        
        // 去重、排序、限制数量
        return results.stream()
            .distinct()
            .sorted(Comparator.comparing(RecommendedContent::getPriority))
            .limit(10)
            .collect(Collectors.toList());
    }
```

```java
public class InterventionStatusMachine {
    
    private static final Map<String, Set<String>> TRANSITIONS = Map.of(
        "DRAFT",    Set.of("ACTIVE", "ARCHIVED"),
        "ACTIVE",   Set.of("PAUSED", "COMPLETED", "EXPIRED"),
        "PAUSED",   Set.of("ACTIVE", "EXPIRED"),
        "COMPLETED", Set.of("ARCHIVED"),
        "EXPIRED",  Set.of("ARCHIVED")
    );
    
    public boolean canTransit(String from, String to) {
        return TRANSITIONS.getOrDefault(from, Set.of()).contains(to);
    }
    
    public void transit(InterventionPlan plan, String targetStatus) {
        if (!canTransit(plan.getStatus(), targetStatus)) {
            throw new BusinessException(
                "INVALID_STATUS_TRANSITION",
                "无法从 " + plan.getStatus() + " 转换到 " + targetStatus);
        }
        plan.setStatus(targetStatus);
        plan.setUpdatedAt(LocalDateTime.now());
        
        // 发送状态变更事件
        eventPublisher.publish(new InterventionStatusChangedEvent(
            plan.getId(), plan.getUserId(), plan.getStatus(), targetStatus));
    }
}
```

```java
/**
 * 每日学科均衡快照采集

@Component
public class DailySnapshotTask {
    
    @Scheduled(cron = "0 0 2 * * ?")
    public void execute() {
        // 1. 获取昨日活跃学生列表
        List<Long> activeUserIds = userService.getActiveUserIds(
            LocalDate.now().minusDays(1));
        
        // 2. 分批处理
        int batchSize = 200;
        for (int i = 0; i < activeUserIds.size(); i += batchSize) {
            List<Long> batch = activeUserIds.subList(
                i, Math.min(i + batchSize, activeUserIds.size()));
            
            executor.submit(() -> processBatch(batch));
        }
    }
    
    private void processBatch(List<Long> userIds) {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        for (Long userId : userIds) {
            try {
                // 获取学生应学学科列表
                List<String> subjects = getStudentSubjects(userId);
                
                for (String subject : subjects) {
                    SubjectBalanceSnapshot snapshot = collectSnapshot(
                        userId, subject, yesterday);
                    snapshotRepository.save(snapshot);
                }
            } catch (Exception e) {
                log.warn("生成快照失败 userId={}: {}", userId, e.getMessage());
            }
        }
    }
}

@Component
public class InterventionProgressCheckTask {
    
    @Scheduled(cron = "0 30 8 * * ?")
    public void execute() {
        List<InterventionPlan> activePlans = planRepository
            .findByStatusAndStartDateBefore("ACTIVE", LocalDate.now());
        
        for (InterventionPlan plan : activePlans) {
            try {
                InterventionProgress progress = calculateProgress(plan);
                
                // 检查是否需要自动调整
                if (needsAdjustment(progress)) {
                    adjustmentService.autoAdjust(plan, progress);
                }
                
                // 检查是否达成成功标准
                if (allCriteriaMet(plan, progress)) {
                    statusMachine.transit(plan, "COMPLETED");
                    notificationService.notifyInterventionCompleted(plan);
                }
            } catch (Exception e) {
                log.error("检查干预方案进度失败 planId={}", plan.getId(), e);
            }
        }
    }
    
    /**
     * 判断是否需要自动调整
     */
    private boolean needsAdjustment(InterventionProgress progress) {
        // 完成率低于40%
        if (progress.getOverallCompletionRate() < 0.4) return true;
        
        // 连续3天完成率低于30%
        if (hasConsecutiveLowDays(progress, 3, 0.3)) return true;
        
        // 学生持续负面情绪
        if (hasPersistentNegativeMood(progress, 3)) return true;
        
        return false;
    }
}
```

### 9.2 降级策略实现

```java
@Service
public class ImbalanceDiagnosisService {
    
    public ImbalanceResult diagnose(Long userId, String periodType,
                                     LocalDate start, LocalDate end) {
        // 1. 检查数据充分性
        DataSufficiency sufficiency = checkDataSufficiency(userId, start, end);
        
        if (sufficiency == DataSufficiency.INSUFFICIENT) {
            return ImbalanceResult.insufficientData();
        }
        
        // 2. 尝试四维度计算
        try {
            return diagnoseWithFourDimensions(userId, periodType, start, end);
        } catch (KnowledgeTrackingUnavailable e) {
            // 降级：跳过掌握度维度，使用三维度模型
            log.warn("知识追踪服务不可用，降级为三维度诊断 userId={}", userId);
            return diagnoseWithThreeDimensions(userId, periodType, start, end);
        }
    }
    
    private DataSufficiency checkDataSufficiency(
            Long userId, LocalDate start, LocalDate end) {
        int subjectCount = getStudentSubjectCount(userId);
        if (subjectCount < 2) return DataSufficiency.INSUFFICIENT;
        
        long recordCount = studyRecordRepository.countByUserIdAndDateRange(
            userId, start, end);
        if (recordCount < 10) return DataSufficiency.INSUFFICIENT;
        
        if (recordCount < 30) return DataSufficiency.MARGINAL;
        return DataSufficiency.SUFFICIENT;
    }
}
```

### 11.2 优化策略

1. **快照表按月分区**：`subject_balance_snapshot` 按月做表分区，便于过期数据清理
2. **异步诊断**：诊断请求走消息队列异步处理，避免阻塞调用方
3. **增量计算**：每日快照只计算增量数据，月度诊断复用每日快照
4. **缓存热点用户**：活跃用户的最新报告缓存7天，减少DB查询
5. **批量推送**：家长报告推送合并到周五批量执行，避免高频打扰

### 13.2 偏科级别语义对照

| 级别 | 指数范围 | 语义 | 建议动作 |

### 13.3 术语表

| 术语 | 说明 |
|------|------|
| 偏科指数 | 衡量学生各学科发展不均衡程度的综合指标，0-100分 |
