# 服务端统一响应封装与分页查询规范 - 详细设计

## 1. 文档概述

### 1.1 目的

本文档定义 PrimeTop 服务端所有 API 的统一响应格式、分页查询参数规范、排序约定、动态条件构建模式以及错误响应结构。作为服务端开发的基础规范文档，所有业务模块的 API 设计和实现必须遵循本规范。

### 1.2 适用范围

- 所有 HTTP RESTful API 接口
- BFF 层到客户端的响应格式
- 服务间内部调用（Feign/gRPC）的响应封装
- SSE/WebSocket 流式响应的消息帧格式（本文档仅涉及元数据部分）

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 前后端一致 | 客户端无需为不同接口适配不同解析逻辑 |
| 可扩展 | 新增字段不破坏已有客户端版本 |
| 类型安全 | 泛型封装，编译期可检查 |
| 可追踪 | 每个响应携带 traceId，串联全链路日志 |
| 降级友好 | 异常时仍返回结构化响应，客户端可统一处理 |

## 2. 统一响应封装

### 2.1 标准响应结构

所有 HTTP API 响应体必须遵循以下 JSON 结构：

```json
{
  "code": 0,
  "message": "success",
  "data": { ... },
  "traceId": "a1b2c3d4e5f6",
  "timestamp": 1748500000000
}
```

### 2.2 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `code` | `int` | ✅ | 业务状态码。`0` 表示成功，非零表示失败 |
| `message` | `string` | ✅ | 人类可读的状态描述。成功时为 `"success"`，失败时为错误摘要 |
| `data` | `T \| null` | ✅ | 业务数据载荷。成功时为具体数据，失败时为 `null` 或错误详情对象 |
| `traceId` | `string` | ✅ | 全链路追踪 ID，与 MDC 中的 traceId 一致 |
| `timestamp` | `long` | ✅ | 服务端生成响应时的 Unix 毫秒时间戳 |

### 2.3 业务状态码规范

#### 2.3.1 状态码分段

| 范围 | 含义 | 示例 |
|------|------|------|
| `0` | 成功 | 请求处理成功 |
| `1000-1999` | 通用客户端错误 | 参数校验失败、未登录、无权限 |
| `2000-2999` | 用户模块 | 账号不存在、密码错误、验证码过期 |
| `3000-3999` | 学习模块 | 学习记录不存在、计划已过期 |
| `4000-4999` | AI 模块 | 模型调用失败、内容审核拦截、额度不足 |
| `5000-5999` | 题目/内容模块 | 题目不存在、知识点未映射 |
| `6000-6999` | 支付模块 | 订单超时、支付失败、会员已过期 |
| `7000-7999` | 内容管理模块 | 教材版本不存在、资源未发布 |
| `8000-8999` | 社交/通知模块 | 消息发送失败、分享已过期 |
| `9000-9999` | 系统级错误 | 服务降级、限流、内部错误 |

> **注意：** 业务状态码 `code` 与 HTTP 状态码独立。HTTP 状态码始终由网关/框架层控制（2xx/4xx/5xx），`code` 是业务语义层面的状态。

### 2.4 服务端 Java 实现

#### 2.4.1 统一响应泛型类

```java
package com.primetop.common.model;

import com.fasterxml.jackson.annotation.JsonInclude;
import com.primetop.common.enums.BizCode;
import lombok.Data;

import java.io.Serializable;

/**
 * 统一 API 响应封装
 *
 * @param <T> 业务数据类型
 */
@Data
@JsonInclude(JsonInclude.Include.NON_NULL)
public class ApiResponse<T> implements Serializable {

    private static final long serialVersionUID = 1L;

    /** 业务状态码 */
    private int code;

    /** 状态描述 */
    private String message;

    /** 业务数据 */
    private T data;

    /** 全链路追踪 ID */
    private String traceId;

    /** 响应时间戳（毫秒） */
    private long timestamp;

    // ========== 静态工厂方法 ==========

    public static <T> ApiResponse<T> success(T data) {
        return of(BizCode.SUCCESS, data);
    }

    public static <T> ApiResponse<T> success() {
        return of(BizCode.SUCCESS, null);
    }

    public static <T> ApiResponse<T> error(BizCode bizCode) {
        return of(bizCode, null);
    }

    public static <T> ApiResponse<T> error(BizCode bizCode, String customMessage) {
        ApiResponse<T> resp = new ApiResponse<>();
        resp.setCode(bizCode.getCode());
        resp.setMessage(customMessage);
        resp.setData(null);
        resp.setTraceId(MDC.get("traceId"));
        resp.setTimestamp(System.currentTimeMillis());
        return resp;
    }

    public static <T> ApiResponse<T> error(int code, String message) {
        ApiResponse<T> resp = new ApiResponse<>();
        resp.setCode(code);
        resp.setMessage(message);
        resp.setData(null);
        resp.setTraceId(MDC.get("traceId"));
        resp.setTimestamp(System.currentTimeMillis());
        return resp;
    }

    private static <T> ApiResponse<T> of(BizCode bizCode, T data) {
        ApiResponse<T> resp = new ApiResponse<>();
        resp.setCode(bizCode.getCode());
        resp.setMessage(bizCode.getMessage());
        resp.setData(data);
        resp.setTraceId(MDC.get("traceId"));
        resp.setTimestamp(System.currentTimeMillis());
        return resp;
    }
}
```

#### 2.4.2 全局响应拦截器

确保所有 Controller 返回值自动包装为 `ApiResponse`：

```java
package com.primetop.common.web;

import com.primetop.common.model.ApiResponse;
import org.springframework.core.MethodParameter;
import org.springframework.http.MediaType;
import org.springframework.http.converter.HttpMessageConverter;
import org.springframework.http.server.ServerHttpRequest;
import org.springframework.http.server.ServerHttpResponse;
import org.springframework.web.bind.annotation.ControllerAdvice;
import org.springframework.web.servlet.mvc.method.annotation.ResponseBodyAdvice;

/**
 * 自动包装 Controller 返回值为 ApiResponse
 * 仅处理 /api/** 路径下的接口
 */
@ControllerAdvice(basePackages = "com.primetop")
public class ApiResponseWrapperAdvice implements ResponseBodyAdvice<Object> {

    @Override
    public boolean supports(MethodParameter returnType,
                            Class<? extends HttpMessageConverter<?>> converterType) {
        // 已经是 ApiResponse 的不再包装
        return !ApiResponse.class.isAssignableFrom(returnType.getParameterType());
    }

    @Override
    public Object beforeBodyWrite(Object body, MethodParameter returnType,
                                  MediaType selectedContentType,
                                  Class<? extends HttpMessageConverter<?>> selectedConverterType,
                                  ServerHttpRequest request, ServerHttpResponse response) {
        if (body instanceof ApiResponse) {
            return body;
        }
        // String 类型特殊处理（Spring MVC String 返回值走 StringHttpMessageConverter）
        if (body instanceof String) {
            return ApiResponse.success(body);
        }
        return ApiResponse.success(body);
    }
}
```

> **注意：** 如果 Controller 方法返回 `String`，需配合 Jackson 的 `ObjectMapper` 序列化，否则会抛出 `ClassCastException`。推荐在项目全局配置 `FastJson` 或确保 `StringHttpMessageConverter` 不处理 `application/json`。

#### 2.4.3 全局异常处理器

```java
package com.primetop.common.web;

import com.primetop.common.enums.BizCode;
import com.primetop.common.exception.*;
import com.primetop.common.model.ApiResponse;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.HttpStatus;
import org.springframework.validation.BindException;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.ResponseStatus;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import jakarta.servlet.http.HttpServletRequest;
import java.util.List;
import java.util.stream.Collectors;

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    /**
     * 业务异常 - 最常见的场景
     */
    @ExceptionHandler(BizException.class)
    @ResponseStatus(HttpStatus.OK) // HTTP 200，业务码表示失败
    public ApiResponse<Void> handleBizException(BizException e, HttpServletRequest request) {
        log.warn("业务异常: code={}, message={}, path={}",
                 e.getCode(), e.getMessage(), request.getRequestURI());
        return ApiResponse.error(e.getCode(), e.getMessage());
    }

    /**
     * 参数校验异常 - @Valid/@Validated 触发
     */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public ApiResponse<List<FieldErrorVO>> handleValidation(MethodArgumentNotValidException e) {
        List<FieldErrorVO> errors = e.getBindingResult().getFieldErrors().stream()
            .map(fe -> new FieldErrorVO(fe.getField(), fe.getDefaultMessage(),
                                        fe.getRejectedValue()))
            .collect(Collectors.toList());
        ApiResponse<List<FieldErrorVO>> resp =
            ApiResponse.error(BizCode.PARAM_INVALID, "参数校验失败");
        resp.setData(errors);
        return resp;
    }

    /**
     * 参数绑定异常
     */
    @ExceptionHandler(BindException.class)
    @ResponseStatus(HttpStatus.BAD_REQUEST)
    public ApiResponse<List<FieldErrorVO>> handleBindException(BindException e) {
        List<FieldErrorVO> errors = e.getFieldErrors().stream()
            .map(fe -> new FieldErrorVO(fe.getField(), fe.getDefaultMessage(),
                                        fe.getRejectedValue()))
            .collect(Collectors.toList());
        ApiResponse<List<FieldErrorVO>> resp =
            ApiResponse.error(BizCode.PARAM_INVALID, "参数绑定失败");
        resp.setData(errors);
        return resp;
    }

    /**
     * 未认证
     */
    @ExceptionHandler(UnauthorizedException.class)
    @ResponseStatus(HttpStatus.UNAUTHORIZED)
    public ApiResponse<Void> handleUnauthorized(UnauthorizedException e) {
        return ApiResponse.error(BizCode.UNAUTHORIZED, e.getMessage());
    }

    /**
     * 无权限
     */
    @ExceptionHandler(PermissionDeniedException.class)
    @ResponseStatus(HttpStatus.FORBIDDEN)
    public ApiResponse<Void> handlePermissionDenied(PermissionDeniedException e) {
        return ApiResponse.error(BizCode.PERMISSION_DENIED, e.getMessage());
    }

    /**
     * 限流
     */
    @ExceptionHandler(RateLimitExceededException.class)
    @ResponseStatus(HttpStatus.TOO_MANY_REQUESTS)
    public ApiResponse<Void> handleRateLimit(RateLimitExceededException e) {
        return ApiResponse.error(BizCode.RATE_LIMITED, e.getMessage());
    }

    /**
     * 兜底 - 未预期的异常
     */
    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public ApiResponse<Void> handleUnknown(Exception e, HttpServletRequest request) {
        log.error("未处理异常: path={}", request.getRequestURI(), e);
        return ApiResponse.error(BizCode.INTERNAL_ERROR);
    }
}
```

## 3. 分页查询规范

### 3.1 分页请求参数

所有分页查询接口统一使用以下查询参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | `int` | 否 | `1` | 页码，从 1 开始 |
| `size` | `int` | 否 | `20` | 每页条数 |
| `sort` | `string[]` | 否 | 无 | 排序规则（见 3.3） |

**约束：**
- `page` 最小值：`1`，超出范围返回空列表（不报错）
- `size` 允许范围：`1 ~ 100`，超过 100 按 100 处理，小于 1 按 20 处理
- 单个接口可定义不同的默认 `size`，但最大不超过 100

#### 3.1.1 请求基类

```java
package com.primetop.common.model;

import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import lombok.Data;

@Data
public class PageRequest {

    @Min(value = 1, message = "页码最小为1")
    private int page = 1;

    @Min(value = 1, message = "每页条数最小为1")
    @Max(value = 100, message = "每页条数最大为100")
    private int size = 20;

    /**
     * 计算数据库 offset
     */
    public long getOffset() {
        return (long) (page - 1) * size;
    }
}
```

#### 3.2.1 分页响应类

```java
package com.primetop.common.model;

import lombok.Data;
import java.util.List;

/**
 * 分页数据载荷
 */
@Data
public class PageData<T> {

    /** 当前页数据列表 */
    private List<T> content;

    /** 分页元信息 */
    private Pagination pagination;

    public PageData(List<T> content, Pagination pagination) {
        this.content = content;
        this.pagination = pagination;
    }

    /**
     * 从 Spring Data Page 转换
     */
    public static <T> PageData<T> from(org.springframework.data.domain.Page<T> page) {
        Pagination pagination = new Pagination();
        pagination.setPage(page.getNumber() + 1);  // Spring Page 从0开始，转为从1开始
        pagination.setSize(page.getSize());
        pagination.setTotal(page.getTotalElements());
        pagination.setTotalPages(page.getTotalPages());
        return new PageData<>(page.getContent(), pagination);
    }

    /**
     * 从 MyBatis Plus IPage 转换
     */
    public static <T> PageData<T> from(com.baomidou.mybatisplus.core.metadata.IPage<T> page) {
        Pagination pagination = new Pagination();
        pagination.setPage((int) page.getCurrent());
        pagination.setSize((int) page.getSize());
        pagination.setTotal(page.getTotal());
        pagination.setTotalPages((int) page.getPages());
        return new PageData<>(page.getRecords(), pagination);
    }

    /**
     * 手动构建（用于非 ORM 场景）
     */
    public static <T> PageData<T> of(List<T> content, int page, int size, long total) {
        Pagination pagination = new Pagination();
        pagination.setPage(page);
        pagination.setSize(size);
        pagination.setTotal(total);
        pagination.setTotalPages((int) Math.ceil((double) total / size));
        return new PageData<>(content, pagination);
    }

    @Data
    public static class Pagination {
        /** 当前页码（从1开始） */
        private int page;
        /** 每页条数 */
        private int size;
        /** 总记录数 */
        private long total;
        /** 总页数 */
        private int totalPages;
    }
}
```

### 3.3 排序规范

#### 3.3.1 排序参数格式

`sort` 参数格式为 `字段名,方向`，支持多字段排序（多次传参）：

```
GET /api/v1/questions?subjectCode=MATH&page=1&size=20&sort=difficulty,desc&sort=createdAt,desc
```

| 格式 | 含义 |
|------|------|
| `sort=createdAt,desc` | 按创建时间降序 |
| `sort=difficulty,asc` | 按难度升序 |
| `sort=createdAt,desc&sort=difficulty,asc` | 先按创建时间降序，再按难度升序 |
| `sort=createdAt` | 方向省略时默认升序 |

#### 3.3.2 排序字段白名单

**安全约束：** 排序字段必须为白名单机制，防止 SQL 注入。每个查询请求类需声明允许排序的字段列表。

```java
package com.primetop.common.model;

import org.springframework.data.domain.Sort;
import java.util.Set;

@Data
@EqualsAndHashCode(callSuper = true)
public abstract class SortablePageRequest extends PageRequest {

    /** 排序参数（由 Spring 自动绑定） */
    private String[] sort;

    /**
     * 子类必须实现：声明允许排序的字段白名单
     */
    protected abstract Set<String> allowedSortFields();

    /**
     * 转换为 Spring Data Sort 对象
     * 自动过滤不在白名单中的字段，防止 SQL 注入
     */
    public Sort toSort() {
        if (sort == null || sort.length == 0) {
            return getDefaultSort();
        }

        Set<String> allowed = allowedSortFields();
        List<Sort.Order> orders = new ArrayList<>();

        for (String s : sort) {
            String[] parts = s.split(",", 2);
            String field = parts[0].trim();
            Sort.Direction dir = parts.length > 1
                ? Sort.Direction.fromString(parts[1].trim())
                : Sort.Direction.ASC;

            if (allowed.contains(field)) {
                orders.add(new Sort.Order(dir, field));
            }
        }

        return orders.isEmpty() ? getDefaultSort() : Sort.by(orders);
    }

    /**
     * 默认排序（子类可覆盖）
     */
    protected Sort getDefaultSort() {
        return Sort.by(Sort.Direction.DESC, "id");
    }
}
```

### 3.5 Service 层标准写法

```java
@Service
@RequiredArgsConstructor
public class QuestionService {

    private final QuestionMapper questionMapper;

    public PageData<QuestionVO> listQuestions(QuestionQueryRequest request) {
        // 1. 构建查询条件
        LambdaQueryWrapper<Question> wrapper = buildQueryWrapper(request);

        // 2. 构建分页（使用 MyBatis Plus）
        com.baomidou.mybatisplus.core.metadata.IPage<Question> page =
            new com.baomidou.mybatisplus.extension.plugins.pagination.Page<>(
                request.getPage(), request.getSize());

        // 3. 如果有排序参数
        Sort sort = request.toSort();
        if (sort.isSorted()) {
            // 将 Spring Sort 转为 MyBatis Plus 排序
            for (Sort.Order order : sort) {
                wrapper.orderBy(true, order.isAscending(),
                    com.primetop.common.util.CamelCaseUtil.toUnderline(order.getProperty()));
            }
        }

        // 4. 执行查询
        com.baomidou.mybatisplus.core.metadata.IPage<Question> result =
            questionMapper.selectPage(page, wrapper);

        // 5. 转换 VO 并返回
        List<QuestionVO> voList = result.getRecords().stream()
            .map(this::toVO)
            .collect(Collectors.toList());

        return PageData.of(voList, request.getPage(), request.getSize(), result.getTotal());
    }

    private LambdaQueryWrapper<Question> buildQueryWrapper(QuestionQueryRequest req) {
        LambdaQueryWrapper<Question> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(req.getSubjectCode() != null, Question::getSubjectCode, req.getSubjectCode())
               .eq(req.getStageCode() != null, Question::getStageCode, req.getStageCode())
               .eq(req.getQuestionType() != null, Question::getQuestionType, req.getQuestionType())
               .ge(req.getDifficultyMin() != null, Question::getDifficulty, req.getDifficultyMin())
               .le(req.getDifficultyMax() != null, Question::getDifficulty, req.getDifficultyMax())
               .eq(req.getKnowledgePointId() != null,
                   Question::getKnowledgePointId, req.getKnowledgePointId())
               .and(req.getKeyword() != null,
                    w -> w.like(Question::getTitle, req.getKeyword())
                         .or()
                         .like(Question::getContent, req.getKeyword()));
        return wrapper;
    }
}
```

## 4. 动态查询条件构建规范

### 4.1 条件拼接原则

| 原则 | 说明 |
|------|------|
| 空值忽略 | 请求参数为 `null` 或空字符串时不拼接条件 |
| 精确匹配优先 | ID、编码类字段使用 `eq` |
| 模糊匹配显式声明 | 关键词搜索使用 `like`，需显式在接口文档标注 |
| 范围查询统一 | 数值/时间范围统一用 `min`/`max` 后缀命名 |
| 枚举值字符串化 | 状态、类型等枚举使用大写蛇形字符串传输 |

### 4.2 常用查询模式

#### 4.2.1 精确匹配

```
GET /api/v1/questions?subjectCode=MATH&questionType=CHOICE
```
→ `WHERE subject_code = 'MATH' AND question_type = 'CHOICE'`

#### 4.2.2 模糊匹配

```
GET /api/v1/questions?keyword=函数
```
→ `WHERE title LIKE '%函数%' OR content LIKE '%函数%'`

#### 4.2.3 范围查询

```
GET /api/v1/questions?difficultyMin=3&difficultyMax=7
```
→ `WHERE difficulty >= 3 AND difficulty <= 7`

#### 4.2.4 时间范围

```
GET /api/v1/learning-records?startDate=2026-05-01&endDate=2026-05-31
```

```java
@Data
```

#### 4.2.5 IN 查询（多值匹配）

```
GET /api/v1/questions?subjectCodes=MATH,PHYSICS,CHEMISTRY
```


→ `WHERE subject_code IN ('MATH', 'PHYSICS', 'CHEMISTRY')`

### 4.3 查询条件对象（Criteria 模式）

对于复杂查询场景（超过 6 个筛选条件），推荐使用 Criteria 对象封装：

```java
package com.primetop.common.model;

import lombok.Data;

/**
 * 通用查询条件封装
 * 适用于查询参数较多且需要传递到多层 Service/Mapper 的场景
 */
@Data
public abstract class BaseCriteria {

    /** 将自身转为 MyBatis Plus QueryWrapper */
    public abstract <T> LambdaQueryWrapper<T> toWrapper(Class<T> entityClass);

    /**
     * 安全的 LIKE 参数处理
     * 防止特殊字符导致的 SQL 问题
     */
    protected String safeLike(String value) {
        if (value == null) return null;
        return "%" + value.replace("%", "\\%")
                          .replace("_", "\\_") + "%";
    }
}
```

**业务 Criteria 示例：**

```java
@Data
@EqualsAndHashCode(callSuper = true)
public class QuestionCriteria extends BaseCriteria {

    private String subjectCode;
    private List<String> subjectCodes;
    private String stageCode;
    private String questionType;
    private Integer difficultyMin;
    private Integer difficultyMax;
    private Long knowledgePointId;
    private String keyword;
    private Boolean published;

    @Override
    public <T> LambdaQueryWrapper<T> toWrapper(Class<T> entityClass) {
        LambdaQueryWrapper<T> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(subjectCode != null, "subject_code", subjectCode)
               .in(subjectCodes != null && !subjectCodes.isEmpty(),
                   "subject_code", subjectCodes)
               .eq(stageCode != null, "stage_code", stageCode)
               .eq(questionType != null, "question_type", questionType)
               .ge(difficultyMin != null, "difficulty", difficultyMin)
               .le(difficultyMax != null, "difficulty", difficultyMax)
               .eq(knowledgePointId != null, "knowledge_point_id", knowledgePointId)
               .and(keyword != null,
                    w -> w.like("title", safeLike(keyword))
                         .or()
                         .like("content", safeLike(keyword)))
               .eq(published != null, "published", published);
        return wrapper;
    }
}
```

## 5. 各 HTTP 方法的响应约定

### 5.1 响应格式速查表

| HTTP 方法 | 场景 | 响应 data 类型 | HTTP 状态码 |
|-----------|------|---------------|-------------|
| `GET` 单条 | 查询单个资源 | `T`（资源对象） | 200 |
| `GET` 列表 | 分页查询 | `PageData<T>` | 200 |
| `GET` 无分页 | 全量小列表 | `List<T>` | 200 |
| `POST` 创建 | 创建资源 | `T`（创建后的对象，含 id） | 200 |
| `POST` 操作 | 执行业务操作（如「加入错题本」） | `null` 或操作结果 | 200 |
| `PUT` | 全量更新 | `T`（更新后的对象） | 200 |
| `PATCH` | 局部更新 | `T`（更新后的对象） | 200 |
| `DELETE` | 删除资源 | `null` | 200 |

> **约定：** HTTP 状态码统一由全局异常处理器控制。正常业务返回 HTTP 200，业务失败也返回 HTTP 200（通过 `code` 区分），仅参数校验/认证/限流等使用标准 HTTP 错误码。

```dart
class ApiResponse<T> {
  final int code;
  final String message;
  final T? data;
  final String? traceId;
  final int? timestamp;

  bool get isSuccess => code == 0;

  ApiResponse({
    required this.code,
    required this.message,
    this.data,
    this.traceId,
    this.timestamp,
  });

  factory ApiResponse.fromJson(
    Map<String, dynamic> json,
    T Function(dynamic)? fromJsonT,
  ) {
    return ApiResponse(
      code: json['code'] as int,
      message: json['message'] as String,
      data: json['data'] != null && fromJsonT != null
          ? fromJsonT(json['data'])
          : null,
      traceId: json['traceId'] as String?,
      timestamp: json['timestamp'] as int?,
    );
  }
}

/// 分页数据模型
class PageData<T> {
  final List<T> content;
  final Pagination pagination;

  PageData({required this.content, required this.pagination});

  factory PageData.fromJson(
    Map<String, dynamic> json,
    T Function(dynamic) fromJsonT,
  ) {
    return PageData(
      content: (json['content'] as List)
          .map((e) => fromJsonT(e))
          .toList(),
      pagination: Pagination.fromJson(json['pagination']),
    );
  }
}

  final int page;
  final int size;
  final int total;
  final int totalPages;

    required this.size,
    required this.total,

  });
```

```dart
/// 分页查询参数构建器
class PageQuery {
  final int page;
  final int size;
  final Map<String, String>? extraParams;
  final List<String>? sorts;

  PageQuery({
    this.page = 1,
    this.size = 20,
    this.extraParams,
    this.sorts,
  });

  Map<String, dynamic> toQueryParams() {
    final params = <String, dynamic>{
      'page': page,
      'size': size,
    };
    if (sorts != null) {
      params['sort'] = sorts;
    }
    if (extraParams != null) {
      params.addAll(extraParams!);
    }
    return params;
  }

  /// 生成下一页查询参数
  PageQuery nextPage() {
    return PageQuery(
      page: page + 1,
      size: size,
      extraParams: extraParams,
      sorts: sorts,
    );
  }
}
```

### 6.3 客户端错误统一处理

```dart
/// API 调用统一错误处理
Future<ApiResponse<T>> safeApiCall<T>(
  Future<Response> Function() apiCall,
  T Function(dynamic)? fromJsonT,
) async {
  try {
    final response = await apiCall();
    final apiResponse = ApiResponse.fromJson(
      response.data,
      fromJsonT,
    );

    if (!apiResponse.isSuccess) {
      // 业务错误统一上报
      _handleBizError(apiResponse);
    }

    return apiResponse;
  } on DioException catch (e) {
    // 网络层错误转 ApiResponse
    return ApiResponse(
      code: _mapDioErrorToBizCode(e),
      message: _dioErrorMessage(e),
    );
  }
}

void _handleBizError<T>(ApiResponse<T> resp) {
  switch (resp.code) {
    case 1101: // UNAUTHORIZED
      // 跳转登录页
      AuthManager.instance.logout();
      break;
    case 1103: // TOKEN_EXPIRED
      // 尝试刷新 Token
      AuthManager.instance.refreshToken();
      break;
    case 1301: // TOO_FREQUENT
    case 1302: // RATE_LIMITED
      // 提示用户稍后重试
      Toast.show('请求过于频繁，请稍后再试');
      break;
    default:
      // 通用错误提示
      Toast.show(resp.message);
      break;
  }
}
```

### 7.2 游标分页（无限滚动场景）

对于信息流、AI 对话历史等无限滚动场景，使用游标分页（Cursor-based Pagination）替代偏移分页：

**请求参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `cursor` | `string` | 上一页最后一条记录的游标值，首页不传 |
| `size` | `int` | 每页条数，默认 20 |

**响应结构：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "content": [ ... ],
    "nextCursor": "eyJpZCI6MTAwfQ==",
    "hasMore": true
  }
}
```

```java
@Data
public class CursorPageData<T> {
    private List<T> content;
    private String nextCursor;
    private boolean hasMore;

    public static <T> CursorPageData<T> of(List<T> content, String nextCursor) {
        CursorPageData<T> data = new CursorPageData<>();
        data.setContent(content);
        data.setNextCursor(content.isEmpty() ? null : nextCursor);
        data.setHasMore(content.size() == 20 && nextCursor != null);
        return data;
    }
}
```

**游标生成（基于 ID + 创建时间）：**

```java
public String generateCursor(Long id, LocalDateTime createdAt) {
    String raw = id + ":" + createdAt.format(DateTimeFormatter.ISO_LOCAL_DATE_TIME);
    return Base64.getUrlEncoder().withoutPadding().encodeToString(raw.getBytes());
}
```

**适用场景：**

| 场景 | 分页方式 | 原因 |
|------|---------|------|
| AI 对话历史 | 游标分页 | 数据频繁插入，offset 分页会漏/重复 |
| 学习记录时间线 | 游标分页 | 无限滚动，性能稳定 |
| 错题本列表 | 偏移分页 | 需要跳页和总数展示 |
| 题库管理后台 | 偏移分页 | 需要页码导航和总数 |
