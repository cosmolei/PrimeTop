# 服务端-语文词语辨析专项训练引擎 详细设计

> 版本：v1.0（初版） ｜ 批次：2026-11-22 ｜ 错误码段：`45500-45599`（全库扫描确认空闲，注册进《服务端统一业务异常码与错误分类体系》）

---

## 1. 概述

### 1.1 定位与背景

词语辨析是小学至初中语文基础训练的四大微观能力之一：**近义词辨析、反义词运用、多音字定音、形近字区分**。docs2 全库扫描确认该域零覆盖：

| 子域 | 已有相关模块 | 缺口 |
| --- | --- | --- |
| 近义词 | 《服务端-通用词典与汉字字典查询服务》仅存词条关系数据（`SYNONYM`/`difference_note`） | 无语境选词训练 |
| 反义词 | 同上（`ANTONYM` 关系数据） | 零覆盖（仅干扰项生成引擎顺带引用） |
| 多音字 | 词典存单字多音数据；拼音启蒙覆盖声调 | 无"语境定音"训练链路 |
| 形近字 | 听写默写引擎将"形近字混淆"作为**错误归因分类** | 无 proactive 辨析训练（听写是事后归因，本引擎是事前训练） |

本文档定义 **语文词语辨析专项训练引擎（Word Discrimination Engine，服务名 `word-discrimination-service`）**，为 1~9 年级提供四类辨析型练习的出题、判题、讲解、画像与复习调度闭环。

### 1.2 适用学段与训练梯度

| 学段 | 重点子域 | 题量/会话 | 梯度说明 |
| --- | --- | --- | --- |
| 1-2 年级 | 形近字、反义词（图片辅助） | 6 题 | 选项带拼音；反义词以二选一/图片配对为主 |
| 3-4 年级 | 多音字、反义词、形近字 | 8 题 | 语境四选一为主；反义词引入输入型 |
| 5-6 年级 | 近义词辨析（重点） | 10 题 | 引入"选项皆通顺但只有一个最恰当"的高阶题 |
| 7-9 年级 | 近义词语体色彩辨析 | 10 题 | 引入语体（书面/口语）与搭配对象辨析 |

### 1.3 权威边界（与已有模块分工）

| 模块 | 其权威 | 本引擎边界 |
| --- | --- | --- |
| 通用词典与汉字字典查询服务（47700 段） | 词条正文、近反义关系、多音字读音的**数据权威** | 本引擎**只投影消费**，命题时快照进 `wd_item`，运行时不同步调用词典服务 |
| 语文素养专项训练系统（LIT_*） | 成语、病句、文学常识、名著导读四子域 | 不含词语辨析；本引擎四子域与 LIT 平级互补，画像分表存储 |
| 组词造句启蒙练习引擎（WS_*） | 启蒙阶段（幼儿-1 年级）产出型组词造句 | 本引擎面向 1-9 年级**辨析型选择题**，不做造句 |
| 听写默写引擎 | 书写回忆检测；形近字混淆是其错误归因标签 | 本引擎的形近字子域是**视觉语境辨析**（选择题），不评估书写结果；听写归因"形近字混淆"可反向驱动本引擎加练（见 §10 事件订阅） |
| 间隔重复算法与遗忘曲线复习调度引擎 | 复习间隔计算的**算法权威** | 本引擎只提交复习请求与接收到期队列，不自行实现间隔公式 |
| 拼音识字启蒙 | 拼音/声调认知 | 多音字子域以**已学拼音为前提**，检测的是语境定音能力 |
| AI-Prompt编排与场景模板系统 | Prompt 模板管理 | 本引擎注册的 Prompt 归其管理（R6） |

### 1.4 名词约定

| 名词 | 含义 |
| --- | --- |
| 辨析项（Item） | 一道辨析题的最小内容单元，表 `wd_item` |
| 辨析组（Group） | 构成一道题的词对/字组，如 〔爱戴-爱护〕、〔己-已〕、〔好 hǎo/hào〕；掌握度以 Group 为最小粒度 |
| 子域（SubDomain） | 四类训练的枚举划分，见 §3.1 |
| 快照（Snapshot） | 命题时从词典服务复制进 `content_json` 的关系数据，与词典库解耦 |

### 1.5 非目标（明确不做）

1. 不做词语**书写**训练（归听写默写引擎）与**造句运用**（归组词造句引擎）。
2. 不维护词条正文与近反义关系数据（归词典服务），本引擎仅消费投影。
3. 不实现间隔重复算法（调用底层引擎）。
4. 不做成语/病句辨析（归语文素养系统 LIT）。
5. 不做英语词汇辨析。

## 3. 核心数据结构

### 3.1 枚举定义

```typescript
/** 四大辨析子域 */
enum WdSubDomain {
  SYNONYM      = 'synonym',       // 近义词语境选词
  ANTONYM      = 'antonym',       // 反义词配对/填写
  POLYPHONE    = 'polyphone',     // 多音字语境定音
  SIMILAR_FORM = 'similar_form',  // 形近字语境辨析
}

/** 题型（每子域 1~2 种，判题策略按题型路由） */
enum WdItemType {
  SELECT_IN_CONTEXT = 'select_in_context', // 语境四选一（synonym/similar_form 共用）
  PAIR_MATCH        = 'pair_match',        // 连线配对（antonym，低年级）
  FILL_INPUT        = 'fill_input',        // 输入型填写（antonym，3 年级起）
  PRONOUNCE_SELECT  = 'pronounce_select',  // 读音二/四选一（polyphone）
}

/** 辨析组粒度掌握度等级（画像展示用） */
enum MasteryLevel {
  UNKNOWN    = 'unknown',     // 样本 < 3
  WEAK       = 'weak',        // < 0.5
  EMERGING   = 'emerging',    // 0.5 ~ 0.8
  SECURE     = 'secure',      // >= 0.8
}

enum WdItemStatus {
  DRAFT = 'draft', PENDING_REVIEW = 'pending_review',
  PUBLISHED = 'published', OFFLINE = 'offline',
}

enum WdSessionStatus {
  CREATING = 'CREATING', IN_PROGRESS = 'IN_PROGRESS',
  SUBMITTED = 'SUBMITTED', GRADED = 'GRADED', ARCHIVED = 'ARCHIVED',
}

enum WdJudgeResult { CORRECT = 'CORRECT', WRONG = 'WRONG' }
```

### 3.3 `content_json` 题型载荷结构

四种载荷共享 `schemaVersion=1`，命题时从词典服务投影快照，运行时与词典库解耦。

**（a）SELECT_IN_CONTEXT（近义词/形近字）**

```json
{
  "schemaVersion": 1,
  "sentence": "李老师深受同学们的____。",
  "blankPos": 9,
  "options": [
    { "text": "爱戴", "pinyin": "ài dài" },
    { "text": "爱护", "pinyin": "ài hù" },
    { "text": "爱怜", "pinyin": "ài lián" },
    { "text": "爱惜", "pinyin": "ài xī" }
  ],
  "distractorSource": "dictionary_synonym_projection",
  "diffNoteRef": "dif_8821"
}
```

**（b）PAIR_MATCH（反义词连线，低年级）**

```json
{
  "schemaVersion": 1,
  "left":  [{ "text": "寒冷", "audio": "cdn/.../hanleng.mp3" }, { "text": "安静", "audio": null }],
  "right": [{ "text": "温暖" }, { "text": "热闹" }],
  "rightShuffleSeed": "session-scoped",
  "timeLimitSec": 60
}
```

**（c）FILL_INPUT（反义填写，输入型）**

```json
{
  "schemaVersion": 1,
  "anchorWord": "谦虚",
  "anchorPinyin": "qiān xū",
  "prompt": "写出"谦虚"的反义词",
  "acceptedAnswers": ["骄傲"],
  "acceptedExpansion": ["自满"],
  "expansionSource": "dictionary_antonym_projection",
  "inputHint": "两个字"
}
```

> `acceptedExpansion` 为词典投影的可接受扩展答案（如"自满"），判对但讲解中说明"最佳答案是骄傲"。`acceptedAnswers` 与 `acceptedExpansion` 均在**命题时快照**，运行时不查词典。

**（d）PRONOUNCE_SELECT（多音字定音）**

```json
{
  "schemaVersion": 1,
  "targetChar": "好",
  "sentence": "他很好学，经常到图书馆查阅资料。",
  "blankMode": "char_underline",
  "options": [
    { "pinyin": "hǎo", "tone": 3 },
    { "pinyin": "hào", "tone": 4 }
  ],
  "pronunciationStandard": "putonghua_yidong_2016",
  "minPairCount": 2
}
```

`pronunciationStandard` 固定引用《普通话异读词审音表》，禁止引擎自行裁定异读读音（合规红线 C4）。

## 4. 出题与判题引擎

### 4.1 出题策略（会话装配）

装配顺序与比例护栏（`review_ratio ≤ 0.4`，新组占比 `≥ 0.3`）：

```
输入: studentId, subDomain, itemCount(默认8)
 │
 ▼
[1] 到期复习集合 R = wd_profile.next_review_at <= now
    AND sub_domain 匹配 AND level IN (weak, emerging)
    → 按 mastery 升序取 min(ceil(itemCount*0.4), |R|) 组，复用其错项原题
 │
 ▼
[2] 薄弱未到期集合 W = level=weak AND next_review_at > now
    → 补至 (itemCount - 已选) 的 50%，同组 7 天内不重复出题
 │
 ▼
[3] 新组集合 N = 学生从未作答（sample_count=0）的 published 辨析组
    → 按 grade_range 匹配、difficulty 逼近画像均值补齐剩余
 │
 ▼
[4] 洗牌下发（题目顺序服务端乱序，防位置记忆；pair_match 右列 seed 随会话生成）
```

**跨子域编排**：客户端可请求 `subDomain=mixed`（仅 3 年级起开放），四子域按画像薄弱度加权轮询（缺省权重 synonym 0.3 / antonym 0.25 / polyphone 0.25 / similar_form 0.2，画像中 weak 子域 +0.15）。

### 4.2 SELECT_IN_CONTEXT 判题（近义词/形近字）

```typescript
class SelectInContextJudger implements Judger {
  judge(item: WdItem, submitted: SubmittedAnswer): JudgeOutcome {
    // 确定性下标比对，唯一权威；AI 不参与判分
    const correct = submitted.selectedIndex === item.answerJson.answerIndex;
    return {
      result: correct ? 'CORRECT' : 'WRONG',
      judgeDetail: correct ? null : {
        wrongType: 'WRONG_OPTION',
        expectedIndex: item.answerJson.answerIndex,
        // 错因标注：所选与正确项是否同词典关系组（近义干扰 vs 无关干扰）
        distractorClass: this.classifyDistractor(item, submitted.selectedIndex),
      },
    };
  }
  /** 近义子域：所选项在同义关系投影内 → semantic_near_miss（辨析失败）；
      否则 → random_guess（猜测行为，置信度降权） */
  classifyDistractor(item: WdItem, picked: number): string {
    const pickedText = item.contentJson.options[picked]?.text;
    return item.contentJson.options.some(
      (o, i) => i !== item.answerJson.answerIndex &&
        o.text !== pickedText && this.dictionaryNear(o.text, pickedText)
    ) ? 'semantic_near_miss' : 'random_guess';
  }
}
```

近义词高阶题（5 年级起）允许"两项皆通顺"设计：此时题面必须满足**唯一最优**（编辑命题校验 + AI 复审双道，见 §5.4），`explainBrief` 必须给出可区分的搭配/语体差异说明。

### 4.3 FILL_INPUT 判题（反义填写）

```typescript
class FillInputJudger implements Judger {
  judge(item: WdItem, submitted: SubmittedAnswer): JudgeOutcome {
    const norm = TextNormalize.normalize(submitted.text); // 去空白/全半角归一/简体归一（复用语文素养系统同款工具）
    const ans = item.answerJson; // { acceptedAnswers, acceptedExpansion }
    if (ans.acceptedAnswers.map(TextNormalize.normalize).includes(norm)) {
      return { result: 'CORRECT', judgeDetail: { grade: 'BEST_MATCH' } };
    }
    if ((ans.acceptedExpansion ?? []).map(TextNormalize.normalize).includes(norm)) {
      // 扩展答案判对但降掌握度增益（§4.6 增益系数 0.6）
      return { result: 'CORRECT', judgeDetail: { grade: 'ACCEPTED_ALT' } };
    }
    // 同音字/形近字错误专项标注（喂错因画像）
    const anchor = item.contentJson.anchorWord;
    return {
      result: 'WRONG',
      judgeDetail: {
        wrongType: 'WRONG_ANTONYM',
        homophoneConfusion: isHomophone(norm, anchor),
        nearFormConfusion: isVisuallySimilar(norm, anchor),
      },
    };
  }
}
```

### 4.4 PRONOUNCE_SELECT 判题（多音字）

- 纯确定性下标比对（与 4.2 共用 `SelectJudger`），无 AI。
- **不计错保护**：ASR/TTS 音频资源加载失败（选项音频 404）时该题标记 `EXCLUDED`，不占题数、不计对错、会话结束自动补题；禁止因资源故障惩罚学生（守卫 G6）。
- 多音字最小覆盖：每个 targetChar 至少积累 2 个不同读音语境题后才进入 `published`（`minPairCount=2`，DDL 载荷字段，命题管线校验）。

### 4.5 PAIR_MATCH 判题（反义连线）

```typescript
class PairMatchJudger implements Judger {
  judge(item: WdItem, submitted: SubmittedAnswer): JudgeOutcome {
    // 集合等值判定：与顺序无关，与右列乱序渲染无关
    const expected = new Set(item.answerJson.pairs.map(p => `${p.left}->${p.right}`));
    const actual = new Set(submitted.pairs.map(p => `${p.left}->${p.right}`));
    const correct = expected.size === actual.size &&
      [...expected].every(e => actual.has(e));
    if (correct) return { result: 'CORRECT', judgeDetail: null };
    const wrongPairs = [...actual].filter(a => !expected.has(a)).length;
    return {
      result: 'WRONG',
      judgeDetail: { wrongType: 'PAIR_MISMATCH', wrongPairCount: wrongPairs },
    };
  }
}
```

> 连线题整题一对一错即判 WRONG（低龄不部分给分，避免挫败；3 年级起此题型自动淡出，由 FILL_INPUT 替代）。

```typescript
function nextMastery(prev: number, correct: boolean, gainFactor = 1): number {
  const alpha = 0.3;
  const target = correct ? Math.min(1, 0.55 + 0.35 * gainFactor) : 0.2;
  // 答对收益受增益系数调制（ACCEPTED_ALT 扩展答案 gainFactor=0.6）
  // 答错惩罚不对称（-幅度 > +幅度），防刷分
  return clamp(+(prev + alpha * (target - prev)).toFixed(3), 0.05, 1.0);
}
function toLevel(mastery: number, samples: number): MasteryLevel {
  if (samples < 3) return 'unknown';
  if (mastery < 0.5) return 'weak';
  if (mastery < 0.8) return 'emerging';
  return 'secure';
}
```

- 答错（WRONG）同事务向间隔重复引擎提交复习请求；引擎回写 `next_review_at`（引擎故障时兜底 `+1d`，见 §11.2）。
- `level=secure` 且连续 3 次答对：暂停该组出题（转入间隔维持队列，由复习调度引擎全权接管）。

### 4.7 错因结构 `judge_detail`

| wrongType | 适用子域 | 说明 |
| --- | --- | --- |
| `WRONG_OPTION` + `semantic_near_miss` | synonym | 选了同义关系组内干扰项（核心辨析失败） |
| `WRONG_OPTION` + `random_guess` | synonym/similar_form | 选了无关项 |
| `WRONG_ANTONYM` + `homophone_confusion` | antonym | 同音字误写（如"娇傲"） |
| `WRONG_ANTONYM` + `nearFormConfusion` | antonym | 形近字误写 |
| `PAIR_MISMATCH` + `wrongPairCount` | antonym | 连线错误对数 |
| `WRONG_TONE_OPTION` | polyphone | 定音错误（读错音） |
| `WRONG_FORM_OPTION` | similar_form | 形近字误选（含同音形近细分标签） |

错因汇总（7 日窗口，同因 ≥3 次）写入学生弱项信号，供首页薄弱点提醒服务与《服务端-学科常见错误模式挖掘与个性化易错点预警干预引擎》消费。

### 7.1 会话编排（TypeScript / NestJS 风格）

```typescript
@Injectable()
export class WdSessionService {
  constructor(
    private readonly itemRepo: WdItemRepository,
    private readonly profileRepo: WdProfileRepository,
    private readonly reviewClient: SpacedRepetitionClient,   // 间隔重复引擎 gRPC
    private readonly outbox: OutboxWriter,                    // 统一事件总线
    @Inject(CACHE_MANAGER) private readonly cache: Cache,
  ) {}

  async create(dto: CreateSessionDto, studentId: string): Promise<SessionView> {
    await this.rateLimiter.consume(`wd:rate:create:${studentId}`); // 30/min 超限抛 45505
    const count = Math.min(Math.max(dto.itemCount ?? 8, 5), 15);

    const reviewCap = Math.ceil(count * 0.4);
    const due = await this.profileRepo.findDueGroups(studentId, dto.subDomain, reviewCap);
    const weak = await this.profileRepo.findWeakGroups(studentId, dto.subDomain,
      Math.ceil((count - due.length) * 0.5), { excludeRecentDays: 7 });
    const fresh = await this.itemRepo.pickFreshGroups(studentId, dto.subDomain,
      count - due.length - weak.length, { grade: await this.currentGrade(studentId) });

    // 组 → 题：复习/薄弱组优先复用错项原题，新组抽 published 题
    const queue = await this.assembleQueue([...due, ...weak, ...fresh]);
    const session = await this.sessionRepo.insertWithIdemKey({
      studentId, subDomain: dto.subDomain, itemCount: queue.length,
      reviewRatio: round2(due.length / queue.length),
      idempotentKey: dto.clientRequestId,
      expiresAt: dayjs().add(4, 'hour').toDate(),
    });
    await this.cache.set(`wd:session:${session.id}`, queue, 4 * 3600);
    return this.toView(session, shuffleBySessionSeed(queue, session.id));
  }
}
```

### 7.2 判题路由（策略模式）

```typescript
@Injectable()
export class WdJudgerRouter {
  private readonly strategies: Record<WdItemType, Judger> = {
    select_in_context: new SelectInContextJudger(),
    pair_match:        new PairMatchJudger(),
    fill_input:        new FillInputJudger(),
    pronounce_select:  new SelectInContextJudger(), // 同确定性下标比对
  };

  async judge(session: WdSession, dto: SubmitAnswerDto): Promise<JudgeOutcome> {
    const item = await this.itemRepo.mustGet(dto.itemId);
    if (item.version !== dto.itemVersion) throw new WdException(45503); // 内容已更新，客户端刷新
    if (dayjs().isAfter(session.expiresAt)) throw new WdException(45502);
    const strategy = this.strategies[item.itemType];
    const outcome = strategy.judge(item, dto);

    // 单事务：答题记录(uk clientRequestId) + 画像EMA + 复习排程 + Outbox(mastery_changed)
    await this.tx.run(async () => {
      const inserted = await this.answerRepo.insertIgnoreDuplicate({ ...map(dto, item, outcome) });
      if (!inserted) return outcome; // G4: 重复提交直接返回首判
      const mastery = await this.profileRepo.applyEma(studentId(item), item.groupKey, outcome);
      if (outcome.result === 'WRONG') {
        await this.reviewClient.schedule({
          studentId: studentId(item), bizType: 'WD_GROUP', bizKey: item.groupKey,
        }).catch(() => this.profileRepo.fallbackReviewPlus1d(studentId(item), item.groupKey));
      }
      await this.outbox.write('word_discrimination.mastery_changed', {
        studentId: studentId(item), groupKey: item.groupKey,
        subDomain: item.subDomain, mastery, result: outcome.result,
      });
    });
    return outcome;
  }
}
```

```typescript
      jsonSchema: WD_EXPLAIN_SCHEMA,                   // §5.3
      timeoutMs: 6000, maxRetries: 1,
      onDelta: (d) => res.event('delta', d),
    });
    await cache.set(cacheKey, explain, 24 * 3600);
    res.event('done', { ...explain, explainId: genId('wde_') });
  } catch (e) {
    // 降级：内置静态解析，fail-open 于体验、fail-closed 于安全（§11.2）
    res.event('error', { code: 45510, message: '讲解生成超时，已切换为静态解析' });
    res.event('done', { ...item.explainJson, degraded: true });
    metrics.counter('wd_explain_degraded_total').inc();
  }
}
```

## 8. 状态流转

### 8.1 会话状态机

```
                 ┌────────────┐  创建装配失败   ┌───────────┐
                 │ CREATING   │ ───────────────▶│ (回滚,    │
                 └─────┬──────┘                 │  不落库)  │
                       │ 装配成功                  └───────────┘
                       ▼
   到期未提交     ┌────────────┐  整卷提交(乐观锁)  ┌───────────┐
  ┌──────────────│ IN_PROGRESS │ ─────────────────▶│ SUBMITTED │
  │              └─────┬──────┘                   └─────┬─────┘
  │                    │ 最后一题答完(客户端引导提交)       │ 结算事务
  │                    │ (不自动提交,防弱网半卷)            ▼
  │                    │                          ┌───────────┐
  │                    │                          │  GRADED   │───▶ ARCHIVED(90天)
  │                    ▼                          └───────────┘
  └─────────▶ EXPIRED(调度器批量置,计未完成作业)
```

### 8.2 守卫规则表

| 守卫 | 规则 | 违反后果 |
| --- | --- | --- |
| G1 | 会话仅 `IN_PROGRESS` 可答题/提交 | 45501/45504 |
| G2 | 单题提交必须命中本会话题目队列 | 45503 |
| G3 | `itemVersion` 必须与下发一致 | 45503（客户端刷新重取） |
| G4 | `clientRequestId` 重复 → 返回首判，不重复计掌握度 | uk 兜底 |
| G5 | 音频资源故障题标记 `EXCLUDED` 不计对错 | 自动补题 |
| G6 | `review_ratio ≤ 0.4`，新组占比 ≥ 0.3 | 装配期护栏，越界抛 45500 |
| G7 | 已 `published` 题编辑后 `version+1`；在途会话不受影响（快照作答） | - |
| G8 | AI 生成题未过人工复核不得 `published` | 状态机强制（fail-closed） |
| G9 | 4 小时未提交 `expires_at` 到期 → EXPIRED，不计入学习记录 | 调度器 |
| G10 | `secure` 组不出新题（仅复习队列可调） | 装配期过滤 |

### 8.3 单题判定状态

```
UNANSWERED ──提交──▶ ANSWERED(CORRECT/WRONG) ──答错请求讲解──▶ EXPLAINED
                          │(重复提交,G4 幂等收敛)
                          └──▶ 返回 ANSWERED 原判定
```

## 9. 幂等与并发

| 场景 | 机制 | 说明 |
| --- | --- | --- |
| 创建会话 | `(student_id, idempotent_key)` 唯一键 | 冲突返回已存在会话（同 key 5 分钟窗口） |
| 单题提交 | `(session_id, client_request_id)` 唯一键 + 返回首判 | 弱网重发/双击收敛 |
| 整卷提交 | `status='IN_PROGRESS'` CAS | 影响行数 0 → 返回既有结算 |
| 批量入库 | `dedupe_hash` 唯一键 | 管线重跑安全 |
| 讲解缓存 | `{itemId}:v{version}` 缓存键 | 内容更新自动失效 |
| 并发画像更新 | `INSERT ... ON DUPLICATE KEY UPDATE`（原子） | 同组并发答题串行化为单事务 |
| 会话过期与提交竞态 | 提交前校验 `expires_at`，过期调度器先置 EXPIRED | 过期优先（G1） |

## 11. 错误处理

### 11.1 业务错误码（`45500-45599` 段）

| 错误码 | HTTP | 含义 | 客户端处理 |
| --- | --- | --- | --- |
| 45500 | 400 | 参数校验失败（subDomain/itemCount/review_ratio 越界） | 本地校验后提示 |
| 45501 | 409 | 存在进行中的同子域会话 | 提示继续或放弃旧会话（放弃走关闭接口） |
| 45502 | 410 | 会话已过期/不存在 | 重新创建会话 |
| 45503 | 409 | 题目版本过期或不在会话队列 | 刷新会话重取题目 |
| 45504 | 409 | 整卷重复提交 | 忽略，使用响应中既有结算 |
| 45505 | 429 | 创建/讲解触发限流 | 退避后重试 |
| 45510 | 200* | AI 讲解超时/解析失败，降级静态解析 | 正常展示，标注"简化讲解" |
| 45511 | 200* | AI 命题审核未通过，已换题库题 | 无感知 |
| 45520 | 425 | 画像样本不足（sample_count<3） | 展示"练习中"占位，不展示等级 |
| 45590 | 500 | 系统内部错误 | 重试 1 次后上报 |

\* 业务层正常返回，帧/载荷内标注降级标记。

### 11.2 降级矩阵

| 故障 | 降级行为 | 恢复 |
| --- | --- | --- |
| AI 推理不可用 | 讲解降级 `explain_json` 静态解析（SSE `degraded=true`）；AI 命题管线暂停（存量题充足） | 探测恢复自动续跑 |
| 内容安全服务不可用 | **fail-closed**：AI 题不入库不下发；存量已审题不受影响 | 同左 |
| 间隔重复引擎超时 | `next_review_at = +1d` 本地兜底，事件补报 | 对账任务回填 |
| 词典服务不可用 | 运行时零影响（快照架构）；命题管线阻塞并告警 | 阻塞解除自动恢复 |
| Redis 故障 | 会话状态回源 DB（P99 降级至 200ms 内可接受），限流失效期间按 UID 粗粒度降级为 10 次/分 | 哨兵切换 |

### 11.3 边界条件

| 场景 | 处理 |
| --- | --- |
| 反义词填写输入与锚词相同（如问"谦虚"反义词答"谦虚"） | 判 WRONG，`judgeDetail.selfAnswer=true`，讲解引导"要找意思相反的词" |
| 输入多个词（"骄傲 自满"） | 归一化后整串匹配，多词即错（低龄引导单题单答） |
| 繁体/异体输入 | TextNormalize 简体归一后匹配；异体字不在 acceptedAnswers 即错 |
| 多音字题锚字在句中出现多次 | 命题校验禁止（DDL 层 lint 规则），只允许单出现 |
| 同组同日多会话 | G1 限制同子域单活跃会话；`mixed` 会话与子域会话并行允许 |
| 学生跳级/降年级 | 在途会话完成不强制终止，新会话按新 grade_range 装配 |
| 错题组对应题被下线 | 复习队列剔除该组，画像保留，转同子域其他弱组 |

## 13. 安全与合规

| 编号 | 红线 |
| --- | --- |
| C1 | AI 生成内容**先审后发**，安全审核超时按不通过处理（fail-closed）。 |
| C2 | AI 命题（来源C）必须经人工复核才可 published；`DICT_AUTO` 题仅限无争议配对/二选一。 |
| C3 | 讲解话术先肯定后引导，禁止否定式措辞与超学段术语（未成年人心理保护）。 |
| C4 | 读音裁定以《普通话异读词审音表》为唯一权威，引擎与 Prompt 均不得自创读音。 |
| C5 | 采集数据最小化：不上传作答过程截屏/录音；音频仅限词典授权 TTS 资源。 |
| C6 | 学习内容适龄：题目装配按 `grade_range` 强制过滤，接入《教育内容适龄性评估与分级引擎》。 |
| C7 | 辨析内容涉及文化词语（如谦辞敬辞）时，解释须中性客观，不涉价值评判与敏感议题。 |

## 15. 测试要点

| 类别 | 要点 |
| --- | --- |
| 判题等价类 | 反义词 acceptedAnswers/acceptedExpansion/同音错/形近错/自答/多词/繁体 7 类输入各覆盖 |
| 状态机 | G1-G10 逐条转写为状态机测试（含过期与提交竞态、重复提交 CAS） |
| 幂等 | 同 clientRequestId 并发 10 线程 → 1 条答题记录、掌握度只加一次 |
| 装配护栏 | review_ratio=0.4 边界、新组不足 0.3 时兜底策略、mixed 子域权重归一 |
| 缓存一致性 | 题 v3 讲解缓存与 v4 隔离；会话缓存丢失回源 DB |
| 降级 | AI 超时/安全服务不可用/Redis 宕 三场景 fail-open/fail-closed 行为核对 |
| 快照 | 题被编辑（version+1）后在途会话提交旧版本 → G3 45503 |
| 性能 | 装配 P99 ≤ 250ms 压测（7.5 万 DAU 模型）、到期查询索引命中验证 |

验收场景（摘录）：

- AC01：三年级学生创建 synonym 会话 8 题 → 队列含 2 复习（到期）+ 3 薄弱 + 3 新组，选项已乱序。
- AC02：答错"爱戴/爱护"题 → 同步返回 WRONG + semantic_near_miss，讲解 SSE 首帧 ≤1.2s。
- AC03：弱网重发同一 clientRequestId 3 次 → 仅 1 条 wd_answer_log，mastery 只更新一次。
- AC04：多音字题音频 404 → 该题 EXCLUDED 不计对错，结算补题。
- AC05：AI 讲解连续超时 → 降级静态解析且标注 degraded，监控 M2 计数 +1。
- AC06：同组 7 日 3 错 → 错题本收到辨析错项，易错点预警引擎收到 weak_confirmed。
- AC07：听写归因 visually_similar（己/已）→ 48h 内 wd 形近字装配队列优先出该组题。
- AC08：整卷重复 submit → 45504 且返回首次结算，wd_outbox 无重复事件。
