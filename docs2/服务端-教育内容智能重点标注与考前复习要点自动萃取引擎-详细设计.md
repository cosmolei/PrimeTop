# 服务端 - 教育内容智能重点标注与考前复习要点自动萃取引擎 详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责对平台中的教育内容（教材讲解、知识点详解、例题分析、专题复习材料等）进行自动化 NLP 分析，识别其中的关键段落、核心定义、重要公式、高频考点语句，并生成结构化的"重点标注"数据，供客户端阅读器以高亮、底线、侧边标记等形式渲染，帮助学生在阅读时快速聚焦核心内容。

同时，引擎支持"考前复习要点萃取"模式：从一篇或多篇学习材料中自动提取复习关键点，生成精简的"复习卡片"数据结构，供学生在考前进行高效的碎片化复习。

### 1.2 核心能力

| 能力 | 说明 |
| --- | --- |
| 关键句识别 | 基于 NLP 模型识别教育文本中的定义句、公式推导句、结论句、易错提醒句 |
| 考点关联打分 | 将文本片段与考点库进行语义关联，输出每个片段的"考试重要性"分数 |
| 智能高亮生成 | 根据关键句识别和考点打分结果，生成前端可用的高亮标注数据 |
| 个性化焦点适配 | 根据学生学段、学习目标（日常/期中/期末/中高考）调整高亮策略 |
| 复习要点萃取 | 从内容中提取核心要点，生成结构化的复习卡片数据 |
| 重点变更追踪 | 教材/内容更新时，自动重新分析并标记变更的重点区域 |

### 1.3 适用范围

- 同步课堂章节内容（讲解文本、知识总结）
- 考点梳理专题材料
- 错题解析文本中的知识点讲解部分
- AI 辅导回答中的关键步骤和结论
- 教师发布的课程笔记和学习资料

### 1.4 与其他模块的关系

```
┌─────────────────────────────────────────────────────────┐
│                    本引擎 (Content Highlight Engine)      │
├──────────┬──────────┬──────────┬──────────┬──────────────┤
│ 内容服务  │ 考点库    │ 知识点库  │ 学生画像  │ 阅读器渲染   │
│ (Content) │(ExamPoint)│(Knowledge│(Student  │ (Reader      │
│           │           │ Point)   │ Profile) │ Component)   │
└──────────┴──────────┴──────────┴──────────┴──────────────┘
```

- **内容服务**：提供待分析的原始内容文本和结构化数据
- **考点库**：提供考点频率、考试类型、重要等级等参考数据
- **知识点库**：提供知识点定义、关联关系、认知层级等元数据
- **学生画像**：提供学生学段、目标、薄弱点信息用于个性化适配
- **阅读器组件**：消费高亮标注数据，在内容中渲染视觉标记

## 2. 数据结构定义

### 2.1 核心表设计

#### 2.1.1 `content_highlight_task` - 重点标注分析任务表

```sql
CREATE TABLE content_highlight_task (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '任务ID',
    content_id      VARCHAR(64) NOT NULL COMMENT '关联内容ID',
    content_type    VARCHAR(32) NOT NULL COMMENT '内容类型: CHAPTER_EXPLANATION/EXAM_REVIEW/KNOWLEDGE_POINT/AI_ANSWER/TEACHER_NOTE',
    content_version INT NOT NULL DEFAULT 1 COMMENT '内容版本号',
    status          VARCHAR(20) NOT NULL DEFAULT 'PENDING' COMMENT '任务状态: PENDING/ANALYZING/HIGHLIGHTED/FAILED',
    analysis_mode   VARCHAR(20) NOT NULL DEFAULT 'STANDARD' COMMENT '分析模式: STANDARD/DEEP/REVIEW_EXTRACTION',
    target_stage    VARCHAR(20) COMMENT '目标学段: PRIMARY/JUNIOR/SENIOR',
    target_exam_type VARCHAR(30) COMMENT '目标考试类型: DAILY/MIDTERM/FINAL/ZHONGKAO/GAOKAO',
    highlight_count INT DEFAULT 0 COMMENT '生成的高亮数量',
    review_card_count INT DEFAULT 0 COMMENT '生成的复习卡片数量',
    model_version   VARCHAR(32) COMMENT '分析模型版本',
    error_message   TEXT COMMENT '失败时的错误信息',
    retry_count     INT DEFAULT 0 COMMENT '重试次数',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    completed_at    DATETIME COMMENT '完成时间',
    INDEX idx_content (content_id, content_version),
    INDEX idx_status (status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='重点标注分析任务';
```

#### 2.1.2 `content_highlight` - 内容重点标注表

```sql
CREATE TABLE content_highlight (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '高亮ID',
    task_id         BIGINT NOT NULL COMMENT '关联分析任务ID',
    content_id      VARCHAR(64) NOT NULL COMMENT '关联内容ID',
    content_version INT NOT NULL COMMENT '内容版本',
    -- 定位信息
    segment_index   INT NOT NULL COMMENT '内容分段索引(从0开始)',
    char_start      INT NOT NULL COMMENT '高亮起始字符偏移(段内)',
    char_end        INT NOT NULL COMMENT '高亮结束字符偏移(段内)',
    highlighted_text TEXT NOT NULL COMMENT '被高亮的原文',
    -- 分类信息
    highlight_type  VARCHAR(30) NOT NULL COMMENT '高亮类型: DEFINITION/FORMULA/CONCLUSION/KEY_POINT/EXAM_FOCUS/ERROR_WARNING/EXAMPLE',
    importance_score DECIMAL(5,2) NOT NULL DEFAULT 50.00 COMMENT '重要性分数 0-100',
    exam_relevance_score DECIMAL(5,2) DEFAULT 0.00 COMMENT '考试关联度 0-100',
    -- 关联信息
    knowledge_point_ids JSON COMMENT '关联知识点ID列表 ["kp_001","kp_002"]',
    exam_point_ids  JSON COMMENT '关联考点ID列表 ["ep_001","ep_002"]',
    -- 元数据
    metadata        JSON COMMENT '扩展元数据 {difficulty_level, cognitive_level, ...}',
    -- 审核状态
    review_status   VARCHAR(20) NOT NULL DEFAULT 'AUTO' COMMENT '审核状态: AUTO/MANUAL_VERIFIED/MANUAL_MODIFIED/MANUAL_REJECTED',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_content (content_id, content_version),
    INDEX idx_task (task_id),
    INDEX idx_type_score (highlight_type, importance_score DESC),
    FOREIGN KEY (task_id) REFERENCES content_highlight_task(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容重点标注数据';
```

#### 2.1.3 `review_card` - 考前复习卡片表

```sql
CREATE TABLE review_card (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '复习卡片ID',
    task_id         BIGINT NOT NULL COMMENT '关联萃取任务ID',
    content_id      VARCHAR(64) NOT NULL COMMENT '来源内容ID',
    card_index      INT NOT NULL COMMENT '卡片排序索引',
    -- 卡片内容
    card_title      VARCHAR(200) NOT NULL COMMENT '卡片标题',
    card_content    TEXT NOT NULL COMMENT '卡片正文(精简后的要点)',
    card_type       VARCHAR(20) NOT NULL COMMENT '卡片类型: CONCEPT/FORMULA/METHOD/COMPARISON/CHECKLIST/EXAMPLE',
    front_text      TEXT COMMENT '正面内容(问答卡模式)',
    back_text       TEXT COMMENT '背面内容(问答卡模式)',
    -- 关联信息
    knowledge_point_ids JSON COMMENT '关联知识点ID列表',
    exam_point_ids  JSON COMMENT '关联考点ID列表',
    source_segments JSON COMMENT '来源段落定位 [{segment_index, char_start, char_end}]',
    -- 难度与优先级
    difficulty_level INT DEFAULT 3 COMMENT '难度等级 1-5',
    review_priority INT DEFAULT 50 COMMENT '复习优先级 0-100',
    -- 元数据
    metadata        JSON COMMENT '扩展元数据',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_content (content_id),
    INDEX idx_task (task_id),
    INDEX idx_priority (review_priority DESC),
    FOREIGN KEY (task_id) REFERENCES content_highlight_task(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='考前复习要点卡片';
```

## 4. 核心算法与处理流程

### 4.1 整体处理流程

```
内容输入 → 文本预处理 → 句子级NLP分析 → 类型分类打分 → 考点关联匹配
                                                        ↓
```

### 4.2 文本预处理流程

将输入的教育内容进行结构化分段和句子切分。

```java
/**
 * 内容预处理器：将原始文本切分为可分析的句子级片段
 */
@Component
public class ContentPreprocessor {
    
    private static final Pattern SENTENCE_BOUNDARY = 
        Pattern.compile("[。！？；\n]|(?<=[。！？；\n])");
    private static final Pattern FORMULA_PATTERN = 
        Pattern.compile("[$$].*?[$$]|\\\\[a-zA-Z]+\\{.*?\\}|[fF]\\([a-zA-Z]+\\)");
    
    /**
     * 将内容文本切分为句子级分析单元
     */
    public List<SentenceUnit> preprocess(ContentInput input) {
        List<SentenceUnit> units = new ArrayList<>();
        
        List<ContentSegment> segments = input.getSegments();
        if (CollectionUtils.isEmpty(segments)) {
            // 如果没有预分段，按标题自动分段
            segments = autoSegment(input.getContentText());
        }
        
        for (ContentSegment segment : segments) {
            // 按句子边界切分
            String[] rawSentences = SENTENCE_BOUNDARY.split(segment.getText());
            
            int globalCharOffset = 0;
            for (int i = 0; i < rawSentences.length; i++) {
                String sentence = rawSentences[i].trim();
                if (sentence.length() < 5) continue;
                
                SentenceUnit unit = SentenceUnit.builder()
                    .segmentIndex(segment.getIndex())
                    .sentenceIndex(i)
                    .text(sentence)
                    .charStart(globalCharOffset)
                    .charEnd(globalCharOffset + sentence.length())
                    .heading(segment.getHeading())
                    .knowledgePointIds(segment.getKnowledgePointIds())
                    .build();
                
                // 识别句子中的公式和特殊格式
                List<FormulaMatch> formulas = extractFormulas(sentence);
                unit.setFormulas(formulas);
                
                units.add(unit);
                globalCharOffset += rawSentences[i].length();
            }
        }
        return units;
    }
    
    /**
     * 提取句子中的公式片段
     */
    private List<FormulaMatch> extractFormulas(String sentence) {
        List<FormulaMatch> formulas = new ArrayList<>();
        Matcher matcher = FORMULA_PATTERN.matcher(sentence);
        while (matcher.find()) {
            formulas.add(FormulaMatch.builder()
                .text(matcher.group())
                .start(matcher.start())
                .end(matcher.end())
                .build());
        }
        return formulas;
    }
    
    /**
     * 基于标题层级自动分段
     */
    private List<ContentSegment> autoSegment(String text) {
        List<ContentSegment> segments = new ArrayList<>();
        String[] lines = text.split("\n");
        int index = 0;
        StringBuilder currentText = new StringBuilder();
        String currentHeading = "";
        
        for (String line : lines) {
            if (isHeading(line)) {
                if (currentText.length() > 0) {
                    segments.add(new ContentSegment(index++, currentHeading, 
                        currentText.toString()));
                }
                currentHeading = line.replaceAll("^#+\\s*", "").trim();
                currentText = new StringBuilder();
            } else {
                currentText.append(line).append("\n");
            }
        }
        if (currentText.length() > 0) {
            segments.add(new ContentSegment(index++, currentHeading, 
                currentText.toString()));
        }
        return segments;
    }
}
```

### 4.3 句子级分类与打分模型

对每个句子进行多维度分类，判断是否属于重点内容。

```java
/**
 * 句子分类打分器
 * 基于规则匹配 + 语义模型的双重判定
 */
@Component
public class SentenceClassifier {
    
    @Autowired
    private EmbeddingService embeddingService;
    
    @Autowired
    private ExamPointRepository examPointRepository;
    
    // 定义类关键词
    private static final List<String> DEFINITION_PATTERNS = Arrays.asList(
        "叫做", "称为", "定义为", "是指", "表示", "记作",
        "是.*?的概念", "是.*?的基本", "简称"
    );
    
    // 公式/定理类关键词
    private static final List<String> FORMULA_PATTERNS = Arrays.asList(
        "公式", "定理", "定律", "性质", "法则",
        "=.*?", "f\\(.*?\\)", "≥", "≤", "→"
    );
    
    // 结论类关键词
    private static final List<String> CONCLUSION_PATTERNS = Arrays.asList(
        "因此", "所以", "综上", "由此可得", "结论是",
        "总之", "归纳", "总结", "由上可知"
    );
    
    // 易错提醒关键词
    private static final List<String> WARNING_PATTERNS = Arrays.asList(
        "注意", "易错", "容易混淆", "切记", "务必",
        "不要", "不能", "常见错误", "误区", "陷阱"
    );
    
    /**
     * 对句子进行分类和打分
     */
    public SentenceClassification classify(SentenceUnit unit) {
        String text = unit.getText();
        
        // 1. 规则匹配：快速识别类型
        HighlightType ruleType = matchByRules(text);
        
        // 2. 模型分类：语义级别的分类
        HighlightType modelType = classifyByModel(text);
        
        // 3. 综合判断
        HighlightType finalType = resolveType(ruleType, modelType);
        
        // 4. 重要性打分
        double importance = calculateImportanceScore(unit, finalType);
        
        // 5. 考点关联打分
        double examRelevance = calculateExamRelevance(unit, finalType);
        
        return SentenceClassification.builder()
            .unit(unit)
            .type(finalType)
            .importanceScore(importance)
            .examRelevanceScore(examRelevance)
            .confidence(calculateConfidence(ruleType, modelType))
            .build();
    }
    
    /**
     * 规则匹配分类
     */
    private HighlightType matchByRules(String text) {
        // 检查是否包含公式
        if (containsFormula(text)) return HighlightType.FORMULA;
        
        // 按优先级匹配模式
        for (String pattern : DEFINITION_PATTERNS) {
            if (Pattern.compile(pattern).matcher(text).find()) 
                return HighlightType.DEFINITION;
        }
        for (String pattern : CONCLUSION_PATTERNS) {
            if (text.contains(pattern)) return HighlightType.CONCLUSION;
        }
        for (String pattern : WARNING_PATTERNS) {
            if (text.contains(pattern)) return HighlightType.ERROR_WARNING;
        }
        
        return null; // 规则未匹配
    }
    
    /**
     * 模型分类：使用嵌入向量进行语义分类
     */
    private HighlightType classifyByModel(String text) {
        // 获取各类别的原型文本嵌入
        Map<HighlightType, List<float[]>> prototypes = getPrototypeEmbeddings();
        
        // 计算文本嵌入
        float[] textEmbedding = embeddingService.embed(text);
        
        // 计算与各类别的余弦相似度
        HighlightType bestType = null;
        double bestScore = 0;
        
        for (Map.Entry<HighlightType, List<float[]>> entry : prototypes.entrySet()) {
            double avgSimilarity = entry.getValue().stream()
                .mapToDouble(proto -> cosineSimilarity(textEmbedding, proto))
                .average().orElse(0);
            if (avgSimilarity > bestScore) {
                bestScore = avgSimilarity;
                bestType = entry.getKey();
            }
        }
        
        return bestScore > 0.75 ? bestType : null;
    }
    
    /**
     * 计算重要性分数 (0-100)
     */
    private double calculateImportanceScore(SentenceUnit unit, HighlightType type) {
        double score = 50.0; // 基础分
        
        // 类型权重
        score += type.getBaseWeight(); // DEFINITION: +20, FORMULA: +25, CONCLUSION: +15...
        
        // 句子位置加权：段首段尾更重要
        if (unit.getSentenceIndex() == 0) score += 8;
        if (unit.isLastInSegment()) score += 5;
        
        // 包含数字/数据（如"考查频率87%"）
        if (containsStatisticalData(unit.getText())) score += 5;
        
        // 关联知识点数量加权
        int kpCount = CollectionUtils.size(unit.getKnowledgePointIds());
        score += Math.min(kpCount * 3, 12);
        
        // 标题层级加权：层级越深越可能是重点
        if (unit.getHeadingLevel() <= 2) score += 5;
        
        // 句子长度适中加权（太短或太长可能不是核心结论）
        int textLen = unit.getText().length();
        if (textLen >= 20 && textLen <= 120) score += 4;
        
        return Math.min(score, 100.0);
    }
    
    /**
     * 计算考点关联度分数
     */
    private double calculateExamRelevance(SentenceUnit unit, HighlightType type) {
        if (CollectionUtils.isEmpty(unit.getKnowledgePointIds())) {
            return 0;
        }
        
        // 查询关联考点的频率数据
        List<ExamPoint> examPoints = examPointRepository.findByKnowledgePointIds(
            unit.getKnowledgePointIds());
        
        if (examPoints.isEmpty()) return 0;
        
        // 取最高频考点作为关联度参考
        double maxFrequency = examPoints.stream()
            .mapToDouble(ExamPoint::getExamFrequency)
            .max().orElse(0);
        
        // 考点频率归一化到 0-100
        double normalizedFreq = Math.min(maxFrequency * 100, 100);
        
        // 类型加权：公式和定义类与考点关联更紧密
        double typeBonus = switch (type) {
            case FORMULA -> 10;
            case DEFINITION -> 8;
            case EXAM_FOCUS -> 15;
            case CONCLUSION -> 5;
            default -> 0;
        };
        
        return Math.min(normalizedFreq + typeBonus, 100);
    }
}
```

### 4.4 高亮密度控制算法

根据用户偏好控制高亮密度，避免过度高亮导致阅读体验下降。

```java
/**
 * 高亮密度控制器
 */
@Component
public class HighlightDensityController {
    
    // 密度配置
    private static final Map<String, DensityConfig> DENSITY_CONFIGS = Map.of(
        "MINIMAL", new DensityConfig(0.08, 75, 5),   // 最多标注8%的文本，最低分75，每段最多5个
        "BALANCED", new DensityConfig(0.15, 60, 8),   // 最多标注15%的文本，最低分60，每段最多8个
        "DETAILED", new DensityConfig(0.25, 45, 12)   // 最多标注25%的文本，最低分45，每段最多12个
    );
    
    /**
     * 根据密度偏好过滤高亮候选
     */
    public List<ContentHighlight> applyDensity(
            List<ContentHighlight> candidates, 
            String densityMode,
            String contentText) {
        
        DensityConfig config = DENSITY_CONFIGS.getOrDefault(densityMode, 
            DENSITY_CONFIGS.get("BALANCED"));
        
        // Step 1: 按重要性分数降序排列
        candidates = candidates.stream()
            .sorted(Comparator.comparingDouble(
                (ContentHighlight h) -> h.getImportanceScore()).reversed())
            .collect(Collectors.toList());
        
        // Step 2: 贪心选择，控制总高亮文本比例
        int totalLength = contentText.length();
        int maxHighlightLength = (int)(totalLength * config.maxTextRatio);
        int currentHighlightLength = 0;
        
        List<ContentHighlight> selected = new ArrayList<>();
        Map<Integer, Integer> segmentCount = new HashMap<>(); // 每段高亮计数
        
        for (ContentHighlight candidate : candidates) {
            // 检查最低分数门槛
            if (candidate.getImportanceScore() < config.minScore) continue;
            
            // 检查段落高亮数量限制
            int segIdx = candidate.getSegmentIndex();
            if (segmentCount.getOrDefault(segIdx, 0) >= config.maxPerSegment) continue;
            
            // 检查总文本长度比例
            int hlLen = candidate.getCharEnd() - candidate.getCharStart();
            if (currentHighlightLength + hlLen > maxHighlightLength) continue;
            
            selected.add(candidate);
            currentHighlightLength += hlLen;
            segmentCount.merge(segIdx, 1, Integer::sum);
        }
        
        // Step 3: 按位置排序（方便前端渲染）
        selected.sort(Comparator
            .comparingInt(ContentHighlight::getSegmentIndex)
            .thenComparingInt(ContentHighlight::getCharStart));
        
        return selected;
    }
    
    private record DensityConfig(double maxTextRatio, double minScore, int maxPerSegment) {}
}
```

### 4.5 复习卡片萃取算法

从内容中自动提取和生成结构化的复习要点卡片。

```java
/**
 * 复习卡片萃取器
 */
@Component
public class ReviewCardExtractor {
    
    @Autowired
    private LlmClient llmClient;
    
    @Autowired
    private SentenceClassifier classifier;
    
    @Autowired
    private KnowledgePointRepository kpRepository;
    
    /**
     * 从高亮分析结果中萃取复习卡片
     */
    public List<ReviewCard> extract(
            ContentInput content,
            List<SentenceClassification> classifications,
            ExtractOptions options) {
        
        // Step 1: 按知识点聚类高亮句子
        Map<String, List<SentenceClassification>> kpGrouped = classifications.stream()
            .filter(c -> c.getUnit().getKnowledgePointIds() != null)
            .flatMap(c -> c.getUnit().getKnowledgePointIds().stream()
                .map(kp -> Map.entry(kp, c)))
            .collect(Collectors.groupingBy(
                Map.Entry::getKey,
                Collectors.mapping(Map.Entry::getValue, Collectors.toList())));
        
        List<ReviewCard> cards = new ArrayList<>();
        int cardIndex = 0;
        
        for (Map.Entry<String, List<SentenceClassification>> entry : kpGrouped.entrySet()) {
            if (cards.size() >= options.getMaxCards()) break;
            
            String kpId = entry.getKey();
            List<SentenceClassification> sentences = entry.getValue();
            
            KnowledgePoint kp = kpRepository.findById(kpId);
            if (kp == null) continue;
            
            // Step 2: 检查是否有足够的材料生成卡片
            if (sentences.size() < 2) continue;
            
            // Step 3: 萃取卡片内容
            String combinedText = sentences.stream()
                .map(s -> s.getUnit().getText())
                .collect(Collectors.joining("\n"));
            
            // Step 4: 调用LLM精简提炼
            ReviewCard card = generateCard(combinedText, kp, sentences, cardIndex++);
            if (card != null) {
                cards.add(card);
            }
        }
        
        // Step 5: 按优先级排序
        cards.sort(Comparator.comparingInt(ReviewCard::getReviewPriority).reversed());
        
        // 重新编排索引
        for (int i = 0; i < cards.size(); i++) {
            cards.get(i).setCardIndex(i);
        }
        
        return cards;
    }
    
    /**
     * 使用LLM生成单张复习卡片
     */
    private ReviewCard generateCard(
            String sourceText, 
            KnowledgePoint kp,
            List<SentenceClassification> sourceSentences,
            int index) {
        
        String prompt = buildExtractionPrompt(sourceText, kp);
        
        LlmResponse response = llmClient.chat(ChatRequest.builder()
            .model("glm-4-flash")
            .messages(List.of(
                ChatMessage.system("你是一位教育内容编辑专家。"
                    + "请根据以下教材原文，提炼出一张结构清晰的复习卡片。"
                    + "要求：简洁准确，突出核心，便于记忆。"),
                ChatMessage.user(prompt)
            ))
            .temperature(0.3)
            .build());
        
        // 解析LLM输出
        CardExtractionResult result = parseExtractionResponse(response.getContent());
        if (result == null) return null;
        
        // 构建来源定位
        List<ReviewCardDTO.SourceSegment> sources = sourceSentences.stream()
            .map(s -> ReviewCardDTO.SourceSegment.builder()
                .segmentIndex(s.getUnit().getSegmentIndex())
                .charStart(s.getUnit().getCharStart())
                .charEnd(s.getUnit().getCharEnd())
                .build())
            .collect(Collectors.toList());
        
        return ReviewCard.builder()
            .contentId(sourceSentences.get(0).getUnit().getContentId())
            .cardIndex(index)
            .cardTitle(kp.getName() + " · 复习要点")
            .cardContent(result.getContent())
            .cardType(result.getType())
            .frontText(result.getFrontText())
            .backText(result.getBackText())
            .knowledgePointIds(List.of(kp.getId()))
            .examPointIds(kp.getExamPointIds())
            .sourceSegments(sources)
            .difficultyLevel(kp.getDifficultyLevel())
            .reviewPriority(calculateReviewPriority(kp, sourceSentences))
            .build();
    }
    
    private String buildExtractionPrompt(String text, KnowledgePoint kp) {
        return String.format("""
            知识点：%s（%s）
            
            以下是关于该知识点的教材原文：
            ---
            %s
            ---
            
            请生成一张复习卡片，输出JSON格式：
            {
              "cardTitle": "简洁的卡片标题",
              "cardContent": "结构化的要点内容，使用\\n和•分隔",
              "cardType": "CONCEPT|FORMULA|METHOD|COMPARISON|CHECKLIST|EXAMPLE",
              "frontText": "闪卡正面问题（一句话）",
              "backText": "闪卡背面答案（简洁）"
            }
            """, kp.getName(), kp.getDescription(), text);
    }
    
    /**
     * 计算复习优先级 (0-100)
     */
    private int calculateReviewPriority(
            KnowledgePoint kp, 
            List<SentenceClassification> sentences) {
        double priority = 50;
        
        // 考点频率加权
        priority += Math.min(kp.getExamFrequency() * 30, 30);
        
        // 重要性平均分加权
        double avgImportance = sentences.stream()
            .mapToDouble(SentenceClassification::getImportanceScore)
            .average().orElse(0);
        priority += (avgImportance - 50) * 0.3;
        
        // 难度加权：高难度知识点优先级更高
        priority += (kp.getDifficultyLevel() - 3) * 5;
        
        return (int) Math.max(0, Math.min(priority, 100));
    }
}
```

```java
/**
 * 个性化后处理器

@Component
public class PersonalizationPostProcessor {
    
    @Autowired
    private StudentProfileService profileService;
    
    /**
     * 个性化高亮调整
     */
    public List<HighlightDTO> personalize(
            List<HighlightDTO> highlights,
            String userId,
            HighlightPreference pref) {
        
        StudentProfile profile = profileService.getProfile(userId);
        
        return highlights.stream()
            .map(h -> applyPersonalization(h, profile, pref))
            .filter(h -> shouldKeep(h, pref))
            .collect(Collectors.toList());
    }
    
    private HighlightDTO applyPersonalization(
            HighlightDTO highlight, 
            StudentProfile profile,
            HighlightPreference pref) {
        
        HighlightDTO.HighlightDTOBuilder builder = highlight.toBuilder();
        
        // 考试模式：提升考点类高亮
        if (pref.isExamMode() && "EXAM_FOCUS".equals(highlight.getHighlightType())) {
            builder.importanceScore(highlight.getImportanceScore() + 10);
            HighlightDTO.HighlightRenderInfo render = highlight.getRenderInfo();
            if (render != null) {
                builder.renderInfo(render.toBuilder()
                    .bold(true)
                    .underline(true)
                    .build());
            }
        }
        
        // 薄弱点增强：与用户薄弱知识点相关的高亮提升优先级
        if (pref.isWeakPointBoost() && highlight.getKnowledgePointIds() != null) {
            List<String> weakKps = profile.getWeakKnowledgePointIds();
            List<String> hlKps = highlight.getKnowledgePointIds();
            
            boolean isWeakPoint = hlKps.stream().anyMatch(weakKps::contains);
            if (isWeakPoint) {
                builder.importanceScore(Math.min(highlight.getImportanceScore() + 15, 100));
                builder.personalized(true);
                builder.personalizationReason("关联你的薄弱知识点");
                
                HighlightDTO.HighlightRenderInfo render = highlight.getRenderInfo();
                if (render != null) {
                    builder.renderInfo(render.toBuilder()
                        .icon("🎯")
                        .tooltip("薄弱知识点关联 · " + render.getTooltip())
                        .underline(true)
                        .build());
                }
            }
        }
        
        return builder.build();
    }
    
    private boolean shouldKeep(HighlightDTO highlight, HighlightPreference pref) {
        // 偏好类型过滤
        if (pref.getPreferredTypes() != null && !pref.getPreferredTypes().isEmpty()) {
            if (!pref.getPreferredTypes().contains(highlight.getHighlightType())) {
                return false;
            }
        }
        return true;
    }
}
```

### 5.2 状态转换条件

```java
/**
 * 分析任务状态机
 */
public class HighlightTaskStateMachine {
    
    public enum Event {
        START_ANALYSIS,     // 开始分析
        NLP_COMPLETE,        // NLP分析完成
        HIGHLIGHT_COMPLETE,  // 高亮生成完成
        CARD_COMPLETE,       // 复习卡片生成完成
        ANALYSIS_FAILED,     // 分析失败
        RETRY                // 重试
    }
    
    private static final Map<String, Set<Event>> TRANSITIONS = Map.of(
        "PENDING",     EnumSet.of(Event.START_ANALYSIS),
        "ANALYZING",   EnumSet.of(Event.NLP_COMPLETE, Event.ANALYSIS_FAILED),
        "HIGHLIGHTED", EnumSet.of(Event.CARD_COMPLETE, Event.ANALYSIS_FAILED),
        "FAILED",      EnumSet.of(Event.RETRY)
    );
    
    private static final Map<String, String> EVENT_TARGET = Map.of(
        "START_ANALYSIS",     "ANALYZING",
        "NLP_COMPLETE",       "HIGHLIGHTED",
        "HIGHLIGHT_COMPLETE", "HIGHLIGHTED",
        "CARD_COMPLETE",      "COMPLETED",
        "ANALYSIS_FAILED",    "FAILED",
        "RETRY",              "ANALYZING"
    );
    
    public String transition(String currentStatus, Event event) {
        Set<Event> allowed = TRANSITIONS.get(currentStatus);
        if (allowed == null || !allowed.contains(event)) {
            throw new IllegalStateException(
                String.format("非法状态转换: %s + %s", currentStatus, event));
        }
        return EVENT_TARGET.get(event.name());
    }
}
```

```
                    ↓                                  ↑
              无变更则跳过                       合并原有高亮
```

```java
/**
 * 内容更新后的增量重新分析
 */
public class IncrementalReanalyzer {
    
    /**
     * 内容版本更新后，增量重新分析高亮
     */
    public void reanalyze(String contentId, int oldVersion, int newVersion) {
        // 获取旧版本的高亮数据
        List<ContentHighlight> oldHighlights = 
            highlightRepository.findByContent(contentId, oldVersion);
        
        // 获取新旧版本的文本
        String oldText = contentService.getText(contentId, oldVersion);
        String newText = contentService.getText(contentId, newVersion);
        
        // 计算文本差异
        List<TextDiff> diffs = textDiffCalculator.diff(oldText, newText);
        
        if (diffs.isEmpty()) {
            // 无变化，直接迁移
            migrateHighlights(oldHighlights, oldVersion, newVersion);
            return;
        }
        
        // 找出受影响的高亮
        List<ContentHighlight> affected = findAffectedHighlights(oldHighlights, diffs);
        List<ContentHighlight> unaffected = oldHighlights.stream()
            .filter(h -> !affected.contains(h))
            .collect(Collectors.toList());
        
        // 对受影响区域重新分析
        List<ContentHighlight> newHighlights = reanalyzeAffectedAreas(
            contentId, newVersion, affected, diffs, newText);
        
        // 合并结果
        List<ContentHighlight> merged = new ArrayList<>();
        merged.addAll(unaffected);
        merged.addAll(newHighlights);
        
        // 保存新版本的高亮
        highlightRepository.saveBatch(contentId, newVersion, merged);
    }
}
```

```java
/**

@Service
@Slf4j
public class HighlightService {
    
    @Autowired private ContentPreprocessor preprocessor;
    @Autowired private SentenceClassifier classifier;
    @Autowired private HighlightDensityController densityController;
    @Autowired private ReviewCardExtractor cardExtractor;
    @Autowired private PersonalizationPostProcessor personalizer;
    @Autowired private HighlightTaskRepository taskRepository;
    @Autowired private HighlightRepository highlightRepository;
    @Autowired private ReviewCardRepository cardRepository;
    @Autowired private PreferenceRepository preferenceRepository;
    
    /**
     * 触发内容重点标注分析（异步）
     */
    @Async("highlightExecutor")
    public void analyzeAsync(Long taskId, ContentInput input, AnalyzeOptions options) {
        HighlightTask task = taskRepository.findById(taskId);
        try {
            // 状态流转
            updateTaskStatus(taskId, "ANALYZING");
            
            // Step 1: 预处理
            List<SentenceUnit> sentences = preprocessor.preprocess(input);
            log.info("内容预处理完成: contentId={}, 句子数={}", 
                input.getContentId(), sentences.size());
            
            // Step 2: 分类打分
            List<SentenceClassification> classifications = sentences.stream()
                .map(classifier::classify)
                .filter(c -> c.getType() != null || c.getImportanceScore() >= 50)
                .collect(Collectors.toList());
            
            // Step 3: 生成高亮候选
            List<ContentHighlight> candidates = classifications.stream()
                .map(this::toHighlight)
                .collect(Collectors.toList());
            
            // Step 4: 密度控制
            String density = options.getHighlightDensity() != null ? 
                options.getHighlightDensity() : "BALANCED";
            List<ContentHighlight> filtered = 
                densityController.applyDensity(candidates, density, input.getContentText());
            
            // Step 5: 萃取复习卡片（可选）
            List<ReviewCard> cards = List.of();
            if (options.isGenerateReviewCards()) {
                cards = cardExtractor.extract(input, classifications, 
                    ExtractOptions.builder()
                        .maxCards(options.getMaxReviewCards())
                        .build());
            }
            
            // Step 6: 持久化
            String contentId = input.getContentId();
            int version = input.getContentVersion();
            
            highlightRepository.deleteByContent(contentId, version);
            highlightRepository.saveBatch(filtered);
            
            if (!cards.isEmpty()) {
                cardRepository.deleteByContent(contentId);
                cardRepository.saveBatch(cards);
            }
            
            // 更新任务状态
            task.setStatus("COMPLETED");
            task.setHighlightCount(filtered.size());
            task.setReviewCardCount(cards.size());
            task.setCompletedAt(LocalDateTime.now());
            taskRepository.save(task);
            
            log.info("重点标注分析完成: contentId={}, 高亮={}, 卡片={}", 
                contentId, filtered.size(), cards.size());
            
        } catch (Exception e) {
            log.error("重点标注分析失败: taskId={}", taskId, e);
            task.setStatus("FAILED");
            task.setErrorMessage(e.getMessage());
            task.setRetryCount(task.getRetryCount() + 1);
            taskRepository.save(task);
            
            // 触发重试（最多3次）
            if (task.getRetryCount() < 3) {
                retryQueue.enqueue(taskId, Duration.ofMinutes(2 * task.getRetryCount()));
            }
        }
    }
    
    /**
     * 获取内容高亮
     */
    public HighlightResponse getHighlights(
            String contentId, int version, HighlightQueryParams params) {
        
        List<ContentHighlight> highlights = highlightRepository.findByContent(contentId, version);
        
        // 类型过滤
        if (params.getTypes() != null && !params.getTypes().isEmpty()) {
            highlights = highlights.stream()
                .filter(h -> params.getTypes().contains(h.getHighlightType()))
                .collect(Collectors.toList());
        }
        
        // 分数过滤
        if (params.getMinScore() > 0) {
            highlights = highlights.stream()
                .filter(h -> h.getImportanceScore() >= params.getMinScore())
                .collect(Collectors.toList());
        }
        
        // 段落过滤
        if (params.getSegmentIndex() != null) {
            highlights = highlights.stream()
                .filter(h -> h.getSegmentIndex() == params.getSegmentIndex())
                .collect(Collectors.toList());
        }
        
        // 转换DTO
        List<HighlightDTO> dtos = highlights.stream()
            .map(this::toDTO)
            .collect(Collectors.toList());
        
        // 统计信息
        HighlightStats stats = calculateStats(highlights);
        
        return HighlightResponse.builder()
            .contentId(contentId)
            .contentVersion(version)
            .highlights(dtos)
            .stats(stats)
            .build();
    }
    
    /**
     * 获取个性化高亮
     */
    public PersonalizedHighlightResponse getPersonalizedHighlights(
            String contentId, int version, String userId) {
        
        // 获取基础高亮
        HighlightResponse base = getHighlights(contentId, version, 
            HighlightQueryParams.builder().build());
        
        // 获取用户偏好
        HighlightPreference pref = preferenceRepository.findByUserId(userId);
        if (pref == null) {
            pref = HighlightPreference.defaultPreference();
        }
        
        // 个性化处理
        List<HighlightDTO> personalized = personalizer.personalize(
            base.getHighlights(), userId, pref);
        
        return PersonalizedHighlightResponse.builder()
            .contentId(contentId)
            .userId(userId)
            .personalizationInfo(PersonalizationInfo.from(pref))
            .highlights(personalized)
            .build();
    }
    
    /**
     * 将分类结果转换为高亮实体
     */
    private ContentHighlight toHighlight(SentenceClassification sc) {
        SentenceUnit unit = sc.getUnit();
        return ContentHighlight.builder()
            .contentId(unit.getContentId())
            .segmentIndex(unit.getSegmentIndex())
            .charStart(unit.getCharStart())
            .charEnd(unit.getCharEnd())
            .highlightedText(unit.getText())
            .highlightType(sc.getType().name())
            .importanceScore(sc.getImportanceScore())
            .examRelevanceScore(sc.getExamRelevanceScore())
            .knowledgePointIds(unit.getKnowledgePointIds())
            .examPointIds(sc.getExamPointIds())
            .metadata(buildMetadata(sc))
            .reviewStatus("AUTO")
            .build();
    }
    
    /**
     * 转换为前端DTO（含渲染信息）
     */
    private HighlightDTO toDTO(ContentHighlight entity) {
        HighlightType type = HighlightType.valueOf(entity.getHighlightType());
        
        HighlightDTO.HighlightRenderInfo renderInfo = HighlightDTO.HighlightRenderInfo.builder()
            .color(type.getDefaultColor())
            .icon(getTypeIcon(type))
            .tooltip(buildTooltip(entity, type))
            .underline(shouldUnderline(entity))
            .bold(entity.getImportanceScore() >= 80)
            .build();
        
        return HighlightDTO.builder()
            .id(entity.getId())
            .contentId(entity.getContentId())
            .segmentIndex(entity.getSegmentIndex())
            .charStart(entity.getCharStart())
            .charEnd(entity.getCharEnd())
            .highlightedText(entity.getHighlightedText())
            .highlightType(entity.getHighlightType())
            .importanceScore(entity.getImportanceScore())
            .examRelevanceScore(entity.getExamRelevanceScore())
            .knowledgePointIds(entity.getKnowledgePointIds())
            .examPointIds(entity.getExamPointIds())
            .renderInfo(renderInfo)
            .build();
    }
    
    private String getTypeIcon(HighlightType type) {
        return switch (type) {
            case DEFINITION -> "📖";
            case FORMULA -> "📐";
            case CONCLUSION -> "✅";
            case KEY_POINT -> "⭐";
            case EXAM_FOCUS -> "🎯";
            case ERROR_WARNING -> "⚠️";
            case EXAMPLE -> "💡";
        };
    }
    
    private String buildTooltip(ContentHighlight entity, HighlightType type) {
        StringBuilder sb = new StringBuilder(type.getDisplayName());
        if (entity.getExamRelevanceScore() >= 70) {
            sb.append(" · 高频考点");
        }
        if (entity.getImportanceScore() >= 85) {
            sb.append(" · 必须掌握");
        }
        return sb.toString();
    }
    
    private boolean shouldUnderline(ContentHighlight entity) {
        return "EXAM_FOCUS".equals(entity.getHighlightType()) 
            && entity.getExamRelevanceScore() >= 80;
    }
}
```

```java
            redisTemplate.delete(keys);
        }
        // 删除复习卡片缓存
        redisTemplate.delete(String.format(CARD_KEY, contentId));
    }
```

```java
/**
 * 降级处理器
 */
@Component
@Slf4j
public class HighlightFallbackHandler {
    
    /**
     * NLP模型不可用时的降级：纯规则匹配
     */
    public List<ContentHighlight> fallbackToRuleBased(
            List<SentenceUnit> sentences, String contentId, int version) {
        log.warn("NLP模型不可用，降级为规则匹配模式: contentId={}", contentId);
        
        return sentences.stream()
            .map(unit -> {
                // 仅使用规则匹配
                String text = unit.getText();
                HighlightType type = ruleBasedClassify(text);
                if (type == null) return null;
                
                double importance = ruleBasedScore(text, type);
                return ContentHighlight.builder()
                    .contentId(contentId)
                    .segmentIndex(unit.getSegmentIndex())
                    .charStart(unit.getCharStart())
                    .charEnd(unit.getCharEnd())
                    .highlightedText(text)
                    .highlightType(type.name())
                    .importanceScore(importance)
                    .examRelevanceScore(0) // 无法计算考点关联
                    .reviewStatus("AUTO_FALLBACK")
                    .build();
            })
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
    }
    
    /**
     * 高亮数据不可用时的降级：返回空列表，由前端自行渲染
     */
    public HighlightResponse fallbackToEmpty(String contentId, int version) {
        log.warn("高亮数据不可用，返回空结果: contentId={}", contentId);
        return HighlightResponse.builder()
            .contentId(contentId)
            .contentVersion(version)
            .highlights(List.of())
            .fallback(true)
            .fallbackMessage("重点标注正在生成中，请稍后查看")
            .build();
    }
    
    /**
     * 卡片萃取失败时的降级：基于高亮直接生成简单卡片
     */
    public List<ReviewCard> fallbackCards(List<ContentHighlight> highlights) {
        log.warn("复习卡片萃取失败，降级为简单提取模式");
        
        return highlights.stream()
            .filter(h -> h.getImportanceScore() >= 70)
            .limit(10)
            .map(h -> ReviewCard.builder()
                .contentId(h.getContentId())
                .cardTitle(truncate(h.getHighlightedText(), 30))
                .cardContent(h.getHighlightedText())
                .cardType("KEY_POINT")
                .frontText(truncate(h.getHighlightedText(), 50))
                .backText("") // 无闪卡背面
                .knowledgePointIds(h.getKnowledgePointIds())
                .difficultyLevel(3)
                .reviewPriority((int) h.getImportanceScore())
                .build())
            .collect(Collectors.toList());
    }
    
    private HighlightType ruleBasedClassify(String text) {
        if (text.contains("叫做") || text.contains("称为") || text.contains("是指")) 
            return HighlightType.DEFINITION;
        if (text.contains("因此") || text.contains("所以") || text.contains("综上")) 
            return HighlightType.CONCLUSION;
        if (text.contains("注意") || text.contains("易错")) 
            return HighlightType.ERROR_WARNING;
        if (text.matches(".*[=≥≤].*") || text.contains("公式")) 
            return HighlightType.FORMULA;
        return null;
    }
    
    private double ruleBasedScore(String text, HighlightType type) {
        double score = 50;
        if (text.length() > 20 && text.length() < 100) score += 10;
        if (type == HighlightType.DEFINITION || type == HighlightType.FORMULA) score += 15;
        return Math.min(score, 80); // 规则模式上限80分
    }
}
```

```java
 */
@Component
public class HighlightMetrics {
    
    private final MeterRegistry registry;
    
    // 分析任务计数器
    private final Counter analysisCounter;
    // 分析耗时计时器
    private final Timer analysisTimer;
    // 高亮生成数量
    private final DistributionSummary highlightCountSummary;
    // 卡片生成数量
    private final DistributionSummary cardCountSummary;
    // 降级次数
    private final Counter fallbackCounter;
    
    public HighlightMetrics(MeterRegistry registry) {
        this.registry = registry;
        this.analysisCounter = Counter.builder("highlight.analysis.total")
            .description("重点标注分析任务总数")
            .tag("status", "completed")
            .register(registry);
        this.analysisTimer = Timer.builder("highlight.analysis.duration")
            .description("单次分析耗时")
            .register(registry);
        this.highlightCountSummary = DistributionSummary.builder("highlight.count")
            .description("单篇内容高亮数量分布")
            .register(registry);
        this.cardCountSummary = DistributionSummary.builder("reviewcard.count")
            .description("单篇内容复习卡片数量分布")
            .register(registry);
        this.fallbackCounter = Counter.builder("highlight.fallback.total")
            .description("降级处理次数")
            .register(registry);
    }
    
    public void recordAnalysis(String contentId, int highlightCount, 
            int cardCount, long durationMs, boolean fallback) {
        analysisCounter.increment();
        analysisTimer.record(durationMs, TimeUnit.MILLISECONDS);
        highlightCountSummary.record(highlightCount);
        cardCountSummary.record(cardCount);
        if (fallback) fallbackCounter.increment();
    }
}
```

### 11.2 Flutter 渲染示例

```dart
class HighlightedTextRenderer extends StatelessWidget {
  final String content;
  final List<ContentHighlight> highlights;
  
  @override
  Widget build(BuildContext context) {
    if (highlights.isEmpty) {
      return Text(content);
    }
    
    // 按位置排序高亮
    final sorted = [...highlights]
      ..sort((a, b) => a.charStart.compareTo(b.charStart));
    
    List<InlineSpan> spans = [];
    int lastEnd = 0;
    
    for (final hl in sorted) {
      // 普通文本
      if (hl.charStart > lastEnd) {
        spans.add(TextSpan(text: content.substring(lastEnd, hl.charStart)));
      }
      // 高亮文本
      spans.add(_buildHighlightSpan(hl, 
        content.substring(hl.charStart, hl.charEnd)));
      lastEnd = hl.charEnd;
    }
    
    // 尾部普通文本
    if (lastEnd < content.length) {
      spans.add(TextSpan(text: content.substring(lastEnd)));
    }
    
    return RichText(
      text: TextSpan(
        style: DefaultTextStyle.of(context).style,
        children: spans,
      ),
    );
  }
  
  InlineSpan _buildHighlightSpan(ContentHighlight hl, String text) {
    return WidgetSpan(
      alignment: PlaceholderAlignment.baseline,
      baseline: TextBaseline.alphabetic,
      child: Tooltip(
        message: hl.renderInfo.tooltip,
        child: Container(
          decoration: BoxDecoration(
            color: _parseColor(hl.renderInfo.color),
            borderRadius: BorderRadius.circular(3),
            border: hl.renderInfo.underline 
              ? Border(bottom: BorderSide(color: Colors.purple, width: 2))
              : null,
          ),
          child: Text(
            text,
            style: TextStyle(
              fontWeight: hl.renderInfo.bold ? FontWeight.bold : FontWeight.normal,
            ),
          ),
        ),
      ),
    );
  }
}
```

### 12.4 FAQ

**Q: 内容更新后高亮数据如何处理？**
A: 引擎支持增量重新分析。当内容版本更新时，系统自动计算文本差异，仅对变更区域重新分析，保留未变更区域的原有高亮数据。

**Q: 高亮数据会占用多少额外存储？**
A: 平均一篇 5000 字的教材内容约生成 15-25 条高亮，每条高亮约 200-400 字节，总计约 5-10KB。复习卡片每条约 500-1000 字节，10条约 5-10KB。

**Q: 免费用户能看到高亮吗？**
A: 基础高亮（定义、公式等类型）对所有用户可见。考试模式高亮、个性化高亮和复习卡片为会员特权。

**Q: 教师可以手动修改高亮吗？**
A: 支持。教师可以通过内容编辑后台手动添加、修改或删除高亮标注，手动修改后的高亮标记为 `MANUAL_MODIFIED` 或 `MANUAL_VERIFIED` 状态。
