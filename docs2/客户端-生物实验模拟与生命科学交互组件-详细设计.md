# 客户端 - 生物实验模拟与生命科学交互组件 详细设计

> 版本：1.0 | 日期：2026-06-13 | 模块代号：`bio-tools`

## 1. 模块定位与边界

### 1.1 模块职责

生物学科交互组件是客户端侧的**交互式生物学习组件库**，提供细胞结构观察、遗传概率模拟、生态系统交互、人体系统探索、显微镜模拟等可视化工具，帮助初中和高中学生在解题、复习过程中直观理解抽象的生物学概念。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 微观可视化 | 将细胞、分子级别的微观结构通过交互式动画呈现 |
| 过程模拟 | 模拟有丝分裂、减数分裂、DNA复制等动态过程 |
| 概率实验 | 遗传杂交实验（孟德尔遗传定律）的蒙特卡洛模拟 |
| 生态交互 | 可调控参数的生态系统（食物链/食物网）模拟 |
| 安全替代 | 替代需要显微镜、解剖等昂贵或伦理敏感的实验 |
| 分龄适配 | 初中侧重现象观察与基础概念，高中侧重定量分析与机制理解 |

### 1.3 依赖模块

| 模块 | 依赖方式 |
|------|----------|
| 学科工具与参考资料库（服务端） | 提供生物数据、图谱数据的版本管理与增量更新 |
| 客户端资源包下载管理器 | 生物数据包的下载、缓存、版本校验 |
| 客户端主题引擎 | 分龄主题适配（初中 vs 高中色彩方案） |
| 客户端路由与深链接系统 | 支持从 AI 对话跳转 `primetop://bio/{scene}/{id}` |
| 客户端组件库与设计系统 | 卡片、BottomSheet、滑块、搜索栏等基础组件 |
| 富文本与学科内容渲染引擎 | 生物学术语、化学方程式在 AI 回答中的渲染 |
| 客户端-数学函数图形绘制与交互式几何画板组件 | 遗传图表坐标系复用 |

### 1.4 不负责

- **生物学科内容教学**：由同步课堂和 AI 辅导模块负责
- **生物题库与练习**：由题目服务与练习测评系统负责
- **生物实验视频播放**：由多媒体内容播放与交互引擎负责
- **动物解剖模拟**：涉及伦理敏感，V2.0+ 远期评估，不在当前范围

/// 显微镜模拟状态
@riverpod
class MicroscopeState extends _$MicroscopeState {
  @override
  MicroscopeData build() {
    return MicroscopeData(
      currentSlide: null,
      magnification: 100,  // 默认100x
      focusPosition: 0.5,  // 焦距位置 (0.0~1.0)
      offsetX: 0.0,        // 标本偏移 X
      offsetY: 0.0,        // 标本偏移 Y
      brightness: 1.0,     // 亮度
      labelsVisible: false, // 标注可见性
      isFocused: true,     // 是否对焦
    );
  }

  /// 切换标本
  void changeSlide(SlideData slide) {
    state = state.copyWith(
      currentSlide: slide,
      offsetX: 0.0,
      offsetY: 0.0,
      focusPosition: 0.5,
    );
  }

  /// 调节放大倍数
  void setMagnification(int magnification) {
    // 支持的倍数: 100, 200, 400, 1000
    assert([100, 200, 400, 1000].contains(magnification));
    state = state.copyWith(magnification: magnification);
  }

  /// 移动标本
  void moveSlide(double dx, double dy) {
    // 限制移动范围在标本区域内
    final maxOffset = 1.0 - (100.0 / state.magnification);
    state = state.copyWith(
      offsetX: (state.offsetX + dx).clamp(-maxOffset, maxOffset),
      offsetY: (state.offsetY + dy).clamp(-maxOffset, maxOffset),
    );
  }

  /// 调节焦距
  void setFocus(double position) {
    state = state.copyWith(
      focusPosition: position.clamp(0.0, 1.0),
      isFocused: (position - 0.5).abs() < 0.1,
    );
  }
}

@freezed
class MicroscopeData with _$MicroscopeData {
  const factory MicroscopeData({
    required SlideData? currentSlide,
    required int magnification,
    required double focusPosition,
    required double offsetX,
    required double offsetY,
    required double brightness,
    required bool labelsVisible,
    required bool isFocused,
  }) = _MicroscopeData;
}

#### 4.1.3 显微镜视野渲染

```dart
class MicroscopeViewPainter extends CustomPainter {
  final MicroscopeData state;
  final SlideData slide;

  MicroscopeViewPainter({required this.state, required this.slide});

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final radius = size.width / 2;

    // 1. 绘制圆形视野遮罩
    _drawViewField(canvas, center, radius);

    // 2. 根据焦距计算模糊度
    final blurSigma = _calculateBlur(state.focusPosition);

    // 3. 绘制标本内容（按放大倍数缩放和偏移）
    canvas.save();
    final scale = state.magnification / 100.0;
    canvas.scale(scale, scale);
    canvas.translate(-state.offsetX * size.width, -state.offsetY * size.height);

    if (state.isFocused) {
      _drawSlideContent(canvas, size);
    } else {
      // 未对焦时绘制模糊效果
      _drawBlurredContent(canvas, size, blurSigma);
    }

    canvas.restore();

    // 4. 绘制标注（如果开启）
    if (state.labelsVisible && state.isFocused) {
      _drawLabels(canvas, size, scale);
    }

    // 5. 绘制十字准线
    _drawCrosshair(canvas, center, radius);

    // 6. 绘制放大倍数标识
    _drawMagnificationBadge(canvas, size);
  }

  double _calculateBlur(double focusPosition) {
    // 焦距偏离0.5越大，模糊度越高
    return (focusPosition - 0.5).abs() * 10.0;
  }

  void _drawViewField(Canvas canvas, Offset center, double radius) {
    // 深色背景 + 圆形视野
    final bgPaint = Paint()..color = const Color(0xFF1a1a2e);
    canvas.drawRect(
      Rect.fromLTWH(0, 0, center.dx * 2, center.dy * 2),
      bgPaint,
    );

    // 圆形裁剪区域 - 模拟显微镜视野
    final viewPaint = Paint()
      ..color = const Color(0xFFf5f0e8) // 暖白色背景
      ..style = PaintingStyle.fill;
    canvas.drawCircle(center, radius * 0.9, viewPaint);
  }

  void _drawLabels(Canvas canvas, Size size, double scale) {
    if (slide.labels == null) return;
    for (final label in slide.labels!) {
      final labelX = label.x * size.width / scale;
      final labelY = label.y * size.height / scale;

      // 标注点
      final dotPaint = Paint()
        ..color = Colors.redAccent
        ..style = PaintingStyle.fill;
      canvas.drawCircle(Offset(labelX, labelY), 4 / scale, dotPaint);

      // 引线 + 文字
      final textPainter = TextPainter(
        text: TextSpan(
          text: label.text,
          style: TextStyle(
            color: Colors.redAccent,
            fontSize: 12 / scale,
            fontWeight: FontWeight.bold,
          ),
        ),
        textDirection: TextDirection.ltr,
      )..layout();

      final labelOffset = Offset(labelX + 20 / scale, labelY - 10 / scale);
      textPainter.paint(canvas, labelOffset);

      // 引线
      final linePaint = Paint()
        ..color = Colors.redAccent.withOpacity(0.6)
        ..strokeWidth = 1.0 / scale;
      canvas.drawLine(
        Offset(labelX, labelY),
        Offset(labelX + 18 / scale, labelY - 5 / scale),
        linePaint,
      );
    }
  }

  @override
  bool shouldRepaint(covariant MicroscopeViewPainter oldDelegate) {
    return oldDelegate.state != state || oldDelegate.slide != slide;
  }
}
```

```
[有丝分裂]
  间期 → 前期 → 中期 → 后期 → 末期 → 胞质分裂 → 子细胞

[减数分裂Ⅰ]
  间期 → 减Ⅰ前期(联会/四分体) → 减Ⅰ中期 → 减Ⅰ后期 → 减Ⅰ末期 → 两个子细胞

[减数分裂Ⅱ]
  (减Ⅰ产物直接进入) → 减Ⅱ前期 → 减Ⅱ中期 → 减Ⅱ后期 → 减Ⅱ末期 → 四个子细胞
```

class MitosisPainter extends CustomPainter {
  final CellDivisionData state;
  final DivisionPhase phase;

  MitosisPainter({required this.state, required this.phase});

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final t = state.animationProgress; // 阶段内插值 0.0~1.0

    // 1. 绘制细胞膜（根据阶段变形）
    _drawCellMembrane(canvas, center, size, t);

    // 2. 绘制核膜（如可见）
    if (state.showNuclearEnvelope) {
      _drawNuclearEnvelope(canvas, center, size, t);
    }

    // 3. 绘制纺锤丝（如可见）
    if (state.showSpindle && phase.visual.spindleVisible) {
      _drawSpindleFibers(canvas, center, size, t);
    }

    // 4. 绘制染色体
    _drawChromosomes(canvas, center, size, t);

    // 5. 绘制赤道板标记（中期）
    if (phase.id.contains('metaphase')) {
      _drawEquatorialPlate(canvas, center, size);
    }

    // 6. 绘制标注
    if (state.showLabels) {
      _drawPhaseLabels(canvas, size);
    }
  }

  void _drawCellMembrane(Canvas canvas, Offset center, Size size, double t) {
    final paint = Paint()
      ..color = const Color(0xFFE8F5E9).withOpacity(0.5)
      ..style = PaintingStyle.fill;

    final strokePaint = Paint()
      ..color = const Color(0xFF4CAF50)
      ..style = PaintingStyle.stroke
      ..strokeWidth = 2.0;

    // 根据阶段和进度计算细胞形状
    final phaseName = phase.id;
    Rect cellRect;

    if (phaseName.contains('telophase') || phaseName.contains('cytokinesis')) {
      // 末期/胞质分裂：细胞拉长 → 中间缢缩 → 分裂
      if (t < 0.5) {
        // 拉长阶段
        final stretchFactor = 1.0 + t * 0.8;
        cellRect = Rect.fromCenter(
          center: center,
          width: size.width * 0.4 * stretchFactor,
          height: size.height * 0.35,
        );
      } else {
        // 缢缩阶段
        final pinchProgress = (t - 0.5) * 2.0;
        _drawPinchingCell(canvas, center, size, pinchProgress, paint, strokePaint);
        return;
      }
    } else {
      // 间期~后期：圆形/椭圆
      cellRect = Rect.fromCenter(
        center: center,
        width: size.width * 0.4,
        height: size.height * 0.35,
      );
    }

    canvas.drawOval(cellRect, paint);
    canvas.drawOval(cellRect, strokePaint);
  }

  void _drawPinchingCell(
    Canvas canvas, Offset center, Size size, double progress,
    Paint fillPaint, Paint strokePaint,
  ) {
    // 使用 Path 绘制中间缢缩的细胞形状
    final path = Path();
    final w = size.width * 0.6;
    final h = size.height * 0.35;
    final pinchAmount = progress * h * 0.4; // 缢缩深度

    // 左半圆
    path.moveTo(center.dx, center.dy - h + pinchAmount);
    path.cubicTo(
      center.dx - w / 2, center.dy - h,
      center.dx - w / 2, center.dy + h,
      center.dx, center.dy + h - pinchAmount,
    );

    // 右半圆
    path.cubicTo(
      center.dx + w / 2, center.dy + h,
      center.dx + w / 2, center.dy - h,
      center.dx, center.dy - h + pinchAmount,
    );

    path.close();
    canvas.drawPath(path, fillPaint);
    canvas.drawPath(path, strokePaint);
  }

  void _drawChromosomes(Canvas canvas, Offset center, Size size, double t) {
    final n = state.chromosomeCount;
    final positions = phase.visual.chromosomePositions;

    for (int i = 0; i < min(positions.length, n); i++) {
      final pos = positions[i];
      final x = center.dx + (pos.x - 0.5) * size.width * 0.35;
      final y = center.dy + (pos.y - 0.5) * size.height * 0.3;

      // 根据染色单体数绘制不同形态
      if (pos.chromatids == 2) {
        _drawDuplicatedChromosome(canvas, x, y, pos.rotation, pos.colorTag);
      } else {
        _drawSingleChromatid(canvas, x, y, pos.rotation, pos.colorTag);
      }
    }
  }

  void _drawDuplicatedChromosome(
    Canvas canvas, double x, double y, double rotation, int colorTag,
  ) {
    final paint = Paint()
      ..color = _getChromosomeColor(colorTag)
      ..style = PaintingStyle.stroke
      ..strokeWidth = 3.0
      ..strokeCap = StrokeCap.round;

    canvas.save();
    canvas.translate(x, y);
    canvas.rotate(rotation);

    // X 形状的复制染色体（两条姐妹染色单体）
    const armLength = 12.0;
    const sisterGap = 4.0; // 着丝点间距

    // 左臂
    canvas.drawLine(
      const Offset(-armLength, -sisterGap),
      const Offset(0, 0),
      paint,
    );
    canvas.drawLine(
      const Offset(-armLength, sisterGap),
      const Offset(0, 0),
      paint,
    );

    // 右臂
    canvas.drawLine(
      const Offset(0, 0),
      const Offset(armLength, -sisterGap),
      paint,
    );
    canvas.drawLine(
      const Offset(0, 0),
      const Offset(armLength, sisterGap),
      paint,
    );

    // 着丝点
    final centromerePaint = Paint()
      ..color = _getChromosomeColor(colorTag).withOpacity(0.5)
      ..style = PaintingStyle.fill;
    canvas.drawCircle(Offset.zero, 2.0, centromerePaint);

    canvas.restore();
  }

  void _drawSingleChromatid(
    Canvas canvas, double x, double y, double rotation, int colorTag,
  ) {
    final paint = Paint()
      ..color = _getChromosomeColor(colorTag)
      ..style = PaintingStyle.stroke
      ..strokeWidth = 3.0
      ..strokeCap = StrokeCap.round;

    canvas.save();
    canvas.translate(x, y);
    canvas.rotate(rotation);

    // I 形状的单体染色体
    canvas.drawLine(
      const Offset(0, -10),
      const Offset(0, 10),
      paint,
    );

    // 着丝点
    final centromerePaint = Paint()
      ..color = _getChromosomeColor(colorTag).withOpacity(0.5)
      ..style = PaintingStyle.fill;
    canvas.drawCircle(Offset.zero, 2.0, centromerePaint);

    canvas.restore();
  }

  Color _getChromosomeColor(int colorTag) {
    // 用不同颜色区分同源染色体（父方/母方来源）
    const colors = [
      Color(0xFFE53935), // 红色 - 父方
      Color(0xFF1E88E5), // 蓝色 - 母方
      Color(0xFF43A047), // 绿色 - 父方（第二对）
      Color(0xFFFB8C00), // 橙色 - 母方（第二对）
    ];
    return colors[colorTag % colors.length];
  }

  @override
  bool shouldRepaint(covariant MitosisPainter oldDelegate) {
    return oldDelegate.state != state;
  }
}

@riverpod
class GeneticsSimulatorState extends _$GeneticsSimulatorState {
  @override
  GeneticsSimData build() {
    return GeneticsSimData(
      experiment: GeneticsExperimentStore.defaultExperiment,
      offspringCount: 100,
      results: null,
      isSimulating: false,
      showPunnettSquare: true,
      showPedigreeChart: false,
      animationMode: false,
    );
  }

  /// 选择实验
  void selectExperiment(GeneticsExperiment experiment) {
    state = state.copyWith(
      experiment: experiment,
      results: null,
    );
  }

  /// 设置后代数量
  void setOffspringCount(int count) {
    state = state.copyWith(offspringCount: count.clamp(10, 10000));
  }

  /// 执行模拟
  Future<void> simulate() async {
    state = state.copyWith(isSimulating: true);

    final results = await _runMonteCarloSimulation(
      experiment: state.experiment,
      count: state.offspringCount,
    );

    state = state.copyWith(
      results: results,
      isSimulating: false,
    );
  }

  /// 蒙特卡洛模拟
  GeneticsResult _runMonteCarloSimulation({
    required GeneticsExperiment experiment,
    required int count,
  }) {
    final random = Random();
    final genotypeCounts = <String, int>{};
    final phenotypeCounts = <String, int>{};

    final p1 = experiment.parent1;
    final p2 = experiment.parent2;

    for (int i = 0; i < count; i++) {
      // 模拟配子形成和受精
      final gamete1 = random.nextBool() ? p1.allele1 : p1.allele2;
      final gamete2 = random.nextBool() ? p2.allele1 : p2.allele2;

      // 排序基因型（大写字母在前，保证一致性）
      final alleles = [gamete1, gamete2]..sort((a, b) {
          if (a.toUpperCase() != b.toUpperCase()) {
            return b.compareTo(a); // 大写字母排前面
          }
          return a.compareTo(b);
        });
      final genotype = '${alleles[0]}${alleles[1]}';

      genotypeCounts[genotype] = (genotypeCounts[genotype] ?? 0) + 1;

      // 判定表现型
      final isDominant = genotype.toUpperCase().contains(experiment.dominantAllele);
      final phenotype = isDominant ? experiment.dominantPhenotype : experiment.recessivePhenotype;
      phenotypeCounts[phenotype] = (phenotypeCounts[phenotype] ?? 0) + 1;
    }

    // 计算卡方检验
    final chiSquare = _calculateChiSquare(
      observed: genotypeCounts,
      expected: _getExpectedGenotypeRatio(p1, p2),
      total: count,
    );

    return GeneticsResult(
      experiment: experiment,
      offspringCount: count,
      genotypeDistribution: genotypeCounts,
      phenotypeDistribution: phenotypeCounts,
      theoreticalRatio: _getTheoreticalRatio(p1, p2),
      chiSquare: chiSquare,
    );
  }

  /// 生成 Punnett 方格
  PunnettSquare generatePunnettSquare() {
    final p1 = state.experiment.parent1;
    final p2 = state.experiment.parent2;
    return PunnettSquare(
      parent1Gametes: [p1.allele1, p1.allele2],
      parent2Gametes: [p2.allele1, p2.allele2],
    );
  }
}

  final List<String> parent2Gametes; // 行头

    final a2 = parent1Gametes[col]; // 列
    // 排序：大写在前
    final alleles = [a1, a2]..sort((a, b) => b.toUpperCase().compareTo(a.toUpperCase()));

  }

      ..sort((a, b) => a.key.compareTo(b.key));
    if (genotypes.isEmpty) return;

    final maxCount = genotypes.map((e) => e.value).reduce(max);
    final barWidth = area.width / genotypes.length * 0.6;
    final gap = area.width / genotypes.length * 0.4;

    final colors = [
      const Color(0xFFE53935),
      const Color(0xFF1E88E5),
      const Color(0xFF43A047),
      const Color(0xFFFB8C00),
    ];

    for (int i = 0; i < genotypes.length; i++) {
      final entry = genotypes[i];
      final barHeight = (entry.value / maxCount) * (area.height - 40);
      final x = area.left + i * (barWidth + gap) + gap / 2;
      final y = area.bottom - barHeight;

      final paint = Paint()
        ..color = colors[i % colors.length]
        ..style = PaintingStyle.fill;

      // 绘制圆角柱体
      final barRect = RRect.fromRectAndCorners(
        Rect.fromLTWH(x, y, barWidth, barHeight),
        topLeft: const Radius.circular(4),

      );
      canvas.drawRRect(barRect, paint);

      // 数值标签
      final tp = TextPainter(

          style: const TextStyle(color: Colors.black87, fontSize: 11),
        ),
        textDirection: TextDirection.ltr,
      )..layout();
      tp.paint(canvas, Offset(x + barWidth / 2 - tp.width / 2, y - 16));

      // 基因型标签
      final labelTp = TextPainter(

          text: entry.key,
          style: const TextStyle(color: Colors.black54, fontSize: 10),

  void _drawPhenotypePieChart(Canvas canvas, Rect area) {
    final phenotypes = result.phenotypeDistribution.entries.toList();
    if (phenotypes.isEmpty) return;

    final total = phenotypes.map((e) => e.value).fold(0, (a, b) => a + b);
    final center = Offset(area.center.dx, area.center.dy);
    final radius = min(area.width, area.height) / 2 - 20;

    final colors = [

      const Color(0xFF81C784),

    double startAngle = -pi / 2; // 从12点钟方向开始

      final paint = Paint()

        startAngle,

        true,
        paint,

      final labelRadius = radius * 0.65;

            fontSize: 12,
            fontWeight: FontWeight.bold,
          ),
        ),
        textAlign: TextAlign.center,
        textDirection: TextDirection.ltr,
      )..layout();
      tp.paint(canvas, Offset(labelX - tp.width / 2, labelY - tp.height / 2));

      startAngle += sweepAngle;
    }
  }

  @override
  bool shouldRepaint(covariant GeneticsResultPainter oldDelegate) {
    return oldDelegate.result != result;
  }

### 4.5 生态系统模拟模块

#### 4.5.1 功能描述

模拟简单的生态系统，用户调节初始种群数量、环境参数，系统基于 Lotka-Volterra 模型计算种群数量变化曲线。

#### 4.5.2 Lotka-Volterra 模型引擎

```dart
/// Lotka-Volterra 种群动力学引擎
class LotkaVolterraEngine {
  /// 计算一个时间步的种群变化
  /// dx/dt = αx - βxy  (猎物)
  /// dy/dt = δxy - γy  (捕食者)
  static PopulationStep step({
    required double preyPopulation,      // x: 猎物种群
    required double predatorPopulation,  // y: 捕食者种群
    required double preyGrowthRate,      // α: 猎物增长率
    required double predationRate,       // β: 捕食率
    required double predatorGrowthRate,  // δ: 捕食者增长率（取决于猎物）
    required double predatorDeathRate,   // γ: 捕食者死亡率
    required double dt,                  // 时间步长
    required double carryingCapacity,    // K: 环境容纳量
  }) {
    // 使用 Runge-Kutta 4阶方法提高精度
    final k1x = _preyDerivative(preyPopulation, predatorPopulation,
        preyGrowthRate, predationRate, carryingCapacity);
    final k1y = _predatorDerivative(preyPopulation, predatorPopulation,
        predatorGrowthRate, predatorDeathRate);

    final k2x = _preyDerivative(
        preyPopulation + dt / 2 * k1x,
        predatorPopulation + dt / 2 * k1y,
        preyGrowthRate, predationRate, carryingCapacity);
    final k2y = _predatorDerivative(
        preyPopulation + dt / 2 * k1x,
        predatorPopulation + dt / 2 * k1y,
        predatorGrowthRate, predatorDeathRate);

    final k3x = _preyDerivative(
        preyPopulation + dt / 2 * k2x,
        predatorPopulation + dt / 2 * k2y,
        preyGrowthRate, predationRate, carryingCapacity);
    final k3y = _predatorDerivative(
        preyPopulation + dt / 2 * k2x,
        predatorPopulation + dt / 2 * k2y,
        predatorGrowthRate, predatorDeathRate);

    final k4x = _preyDerivative(
        preyPopulation + dt * k3x,
        predatorPopulation + dt * k3y,
        preyGrowthRate, predationRate, carryingCapacity);
    final k4y = _predatorDerivative(
        preyPopulation + dt * k3x,
        predatorPopulation + dt * k3y,
        predatorGrowthRate, predatorDeathRate);

    final newPrey = (preyPopulation +
        dt / 6 * (k1x + 2 * k2x + 2 * k3x + k4x)).clamp(0.0, carryingCapacity * 1.5);
    final newPredator = (predatorPopulation +
        dt / 6 * (k1y + 2 * k2y + 2 * k3y + k4y)).clamp(0.0, carryingCapacity);

    return PopulationStep(
      prey: newPrey,
      predator: newPredator,
    );
  }

  /// 猎物增长方程（含环境容纳量限制）
  /// dx/dt = αx(1 - x/K) - βxy
  static double _preyDerivative(double x, double y,
      double alpha, double beta, double K) {
    return alpha * x * (1 - x / K) - beta * x * y;
  }

  /// 捕食者增长方程
  /// dy/dt = δxy - γy
  static double _predatorDerivative(double x, double y,
      double delta, double gamma) {
    return delta * x * y - gamma * y;
  }

  /// 批量模拟
  static List<PopulationStep> simulate({
    required double initialPrey,
    required double initialPredator,
    required double preyGrowthRate,
    required double predationRate,
    required double predatorGrowthRate,
    required double predatorDeathRate,
    required double carryingCapacity,
    required int steps,
    required double dt,
  }) {
    final result = <PopulationStep>[];
    double prey = initialPrey;
    double predator = initialPredator;

    for (int i = 0; i < steps; i++) {
      final step = LotkaVolterraEngine.step(
        preyPopulation: prey,
        predatorPopulation: predator,
        preyGrowthRate: preyGrowthRate,
        predationRate: predationRate,
        predatorGrowthRate: predatorGrowthRate,
        predatorDeathRate: predatorDeathRate,
        dt: dt,
        carryingCapacity: carryingCapacity,
      );
      result.add(step);
      prey = step.prey;
      predator = step.predator;

      // 种群灭绝检测
      if (prey < 0.5 && predator < 0.5) break;
    }

    return result;
  }
}

class PopulationStep {
  final double prey;
  final double predator;

  PopulationStep({required this.prey, required this.predator});
}
```

## 6. 错误处理

### 6.1 错误码定义

| 错误码 | 含义 | 处理策略 |
|--------|------|----------|
| `BIO_DATA_LOAD_FAILED` | 本地生物数据加载失败 | 尝试重新从资源包加载，失败后提示用户检查更新 |
| `BIO_RESOURCE_NOT_FOUND` | SVG/图片资源不存在 | 显示占位图，后台静默下载 |
| `BIO_SIMULATION_DIVERGED` | 模拟结果发散（种群趋于无穷） | 自动终止模拟，提示参数不合理 |
| `BIO_SIMULATION_EXTINCT` | 种群灭绝 | 标注灭绝时间点，提示分析原因 |
| `BIO_INVALID_CHROMOSOME` | 染色体数量设置无效 | 回退到默认值 2n=4 |
| `BIO_NETWORK_ERROR` | 网络请求失败（获取远端数据） | 使用本地缓存数据，静默重试 |
| `BIO_VERSION_MISMATCH` | 本地数据版本与服务端不一致 | 提示用户更新资源包 |

### 6.2 容错机制

```dart
/// 全局错误处理
class BioErrorHandler {
  static Widget handleError(Object error, StackTrace stack) {
    if (error is BioDataLoadException) {
      return BioErrorWidget(
        icon: Icons.science_outlined,
        title: '数据加载失败',
        message: '生物学数据加载异常，请尝试重新打开或检查应用更新。',
        actionLabel: '重新加载',
        onAction: () => _retryDataLoad(),
      );
    }

    if (error is BioSimulationException) {
      return BioErrorWidget(
        icon: Icons.warning_amber,
        title: '模拟异常',
        message: _getSimErrorMessage(error.code),
        actionLabel: '重置参数',
        onAction: () => _resetSimulation(),
      );
    }

    // 通用错误兜底
    return BioErrorWidget(
      icon: Icons.error_outline,
      title: '出现错误',
      message: '生物实验组件遇到问题，请稍后重试。',
      actionLabel: '返回',
    );
  }

  static String _getSimErrorMessage(String code) {
    switch (code) {
      case 'BIO_SIMULATION_DIVERGED':
        return '模拟参数导致结果发散，请减小增长率或增大捕食率。';
      case 'BIO_SIMULATION_EXTINCT':
        return '种群已灭绝，请尝试降低初始捕食者数量或增大环境容纳量。';
      default:
        return '模拟过程出现问题，请重置参数后重试。';
    }
  }
}
```
