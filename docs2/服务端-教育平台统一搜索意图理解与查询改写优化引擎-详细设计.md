# 教育平台统一搜索意图理解与查询改写优化引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本模块是 PrimeTop 搜索系统的"智能大脑"，位于用户搜索请求与底层全文检索引擎（Elasticsearch/OpenSearch）之间。负责对用户输入的搜索query进行**意图识别、语义扩展、纠错改写、个性化重排**，最终生成高质量的检索条件，提升搜索召回率和结果精准度。

### 1.2 核心问题

教育场景搜索与传统电商/通用搜索的差异：

| 维度 | 通用搜索 | 教育搜索 |
|------|---------|---------|
| 术语专业性 | 较低 | 高（学科专业词汇密集） |
| 同义/近义关系 | 基础同义词即可 | 需学科知识图谱支撑（如"勾股定理"="毕达哥拉斯定理"） |
| 年级上下文 | 无 | 同一术语在不同年级含义不同（如"函数"在小学/高中） |
| 查询质量 | 用户通常输入清晰 | 学生输入模糊、口语化、甚至有错别字 |
| 意图类型 | 购买/浏览/信息 | 查概念/找题目/看视频/搜课文/找错题 |

### 1.3 设计目标

1. **零结果率 < 2%**：通过query扩展和模糊匹配，将无结果搜索降至极低水平
2. **首条结果点击率 > 45%**：精准的意图识别和重排保证最相关结果排首位
3. **查询延迟 < 50ms**：意图理解和改写在50ms内完成（不含底层检索）
4. **教育术语同义词覆盖 > 10,000 对**：覆盖全学科全学段
5. **支持多语言混合查询**：中英文混合（如"函数 平移"）、纯英文数学术语

### 1.4 适用范围

- 全局搜索（首页搜索栏）
- AI 对话中的知识检索增强（RAG query预处理）
- 题库搜索（教师/学生搜索题目）
- 错题本搜索
- 知识图谱浏览中的节点搜索
- 管理后台内容搜索

### 2.2 模块边界与依赖

```
                    依赖关系
搜索意图理解引擎
    ├── 知识点体系服务 (获取知识点上下文)
    ├── 学科术语词典服务 (同义词/缩写映射)
    ├── 用户画像服务 (获取年级、教材版本、学习历史)
    ├── 搜索日志分析服务 (热门query、点击反馈)
    └── Elasticsearch (底层检索引擎)
```

### 2.3 与现有模块的关系

| 现有模块 | 关系 |
|---------|------|
| `搜索服务与全文检索-详细设计` | 本模块是它的前置处理层，改写后的query传入该服务执行实际检索 |
| `学习场景意图识别与智能路由引擎` | 该模块识别用户学习场景（练习/复习/预习），本模块聚焦搜索query本身的理解 |
| `知识点体系与教材映射引擎` | 提供知识点层次结构，用于query中的知识点识别和扩展 |
| `RAG检索增强生成系统` | RAG的query预处理可复用本模块的改写能力 |
| `客户端-全局搜索与智能发现引擎` | 客户端侧的搜索建议、历史记录、热搜推荐 |

## 3. 数据结构定义

### 3.1 核心数据模型

#### 3.1.1 搜索意图枚举

```java
public enum SearchIntent {
    // 概念查询：查找某个知识点的定义、讲解
    CONCEPT_LOOKUP("概念查询"),
    // 题目搜索：搜索具体的练习题/试题
    QUESTION_SEARCH("题目搜索"),
    // 课文搜索：查找教材课文、章节
    TEXTBOOK_SEARCH("课文搜索"),
    // 视频搜索：查找讲解视频
    VIDEO_SEARCH("视频搜索"),
    // 错题搜索：在错题本中搜索
    MISTAKE_SEARCH("错题搜索"),
    // 知识点图谱浏览：查找知识点的关联关系
    KNOWLEDGE_GRAPH("知识点图谱"),
    // 解题方法搜索：查找某类题型的解题方法
    METHOD_SEARCH("解题方法"),
    // 作文素材搜索
    ESSAY_MATERIAL("作文素材"),
    // 公式/定理搜索
    FORMULA_LOOKUP("公式定理"),
    // 人物/历史事件搜索
    ENTITY_LOOKUP("人物事件"),
    // 模糊探索：无法明确分类
    BROWSE("模糊探索");
}
```

#### 3.1.3 改写后的查询对象

```java
@Data
@Builder
public class RewrittenQuery {
    /** 原始query */
    private String originalQuery;
    
    /** 归一化query */
    private String normalizedQuery;
    
    /** 主query（用于ES的must条件） */
    private String mainQuery;
    
    /** 扩展关键词列表（用于ES的should条件，提升相关性评分） */
    private List<String> expandedTerms;
    
    /** 同义词映射（用于高亮显示） */
    private List<SynonymMapping> synonymMappings;
    
    /** 识别到的实体 */
    private List<RecognizedEntity> entities;
    
    /** 识别到的知识点ID列表 */
    private List<Long> knowledgePointIds;
    
    /** 意图分类结果（带置信度） */
    private List<IntentPrediction> intentPredictions;
    
    /** 主意图 */
    private SearchIntent primaryIntent;
    
    /** 年级上下文（注入到检索条件中） */
    private String gradeContext;
    
    /** ES DSL查询JSON */
    private String esDsl;
    
    /** 排序信号权重 */
    private RankingSignals rankingSignals;
    
    /** 是否进行了拼写纠正 */
    private boolean spellCorrected;
    
    /** 纠正详情 */
    private List<SpellCorrection> corrections;
    
    /** 查询耗时(ms) */
    private long processingTimeMs;
}

@Data
@Builder
public class SynonymMapping {
    private String original;
    private String synonym;
    private String type; // EXACT / RELATED / BROADER / NARROWER
    private String source; // KNOWLEDGE_GRAPH / THESAURUS / USER_MINED
}

@Data
@Builder
public class RecognizedEntity {
    private String text;
    private String entityType; // KNOWLEDGE_POINT / PERSON / FORMULA / SUBJECT_TERM / TEXTBOOK_CHAPTER
    private Long entityId;
    private double confidence;
    private int startPos;
    private int endPos;
}

@Data
@Builder
public class IntentPrediction {
    private SearchIntent intent;
    private double confidence;
}

@Data
@Builder
public class RankingSignals {
    /** 年级匹配权重（同年级内容加分） */
    private double gradeMatchWeight = 1.0;
    /** 教材版本匹配权重 */
    private double textbookMatchWeight = 0.8;
    /** 意图匹配权重（内容类型与意图一致时加分） */
    private double intentMatchWeight = 1.5;
    /** 知识点精确匹配权重 */
    private double knowledgePointMatchWeight = 2.0;
    /** 热度衰减因子 */
    private double popularityDecayFactor = 0.5;
    /** 用户历史偏好权重 */
    private double personalizationWeight = 0.6;
}

@Data
@Builder
public class SpellCorrection {
    private String original;
    private String corrected;
    private int position;
    private double confidence;
    private String correctionType; // TYPO / HOMOPONE / MISSING_CHAR / EXTRA_CHAR / WRONG_CHAR
}
```

### 3.3 Redis 缓存结构

```
# 同义词缓存（按学科+学段分区）
edu:synonym:{subject}:{stage} → Hash<term, JSON<List<SynonymMapping>>>

# 缩写/简称缓存
edu:abbr:{subject} → Hash<abbreviation, fullForm>

# 热门Query缓存（每小时刷新）
edu:hotquery:{stage}:{subject}:{periodType}:{date} → ZSet<queryHash, score>

# Query改写结果缓存（5分钟TTL，减少重复计算）
edu:rewrite:{sha256(normalizedQuery + userId + stage + subject)} → JSON<RewrittenQuery>

# 教育实体词典缓存（用于NER）
edu:entity:dict → Hash<entityText, JSON<EntityInfo>>

# 用户搜索历史（最近20条，用于个性化）
edu:user:search:recent:{userId} → List<queryText> (LRU, TTL 7天)
```

```java
@Service
public class QueryPreprocessor {

    /**
     * Query归一化处理
     * 1. 去首尾空格、中间多余空格压缩
     * 2. 繁体→简体转换
     * 3. 全角→半角转换（数字、字母、标点）
     * 4. 中文标点→英文标点（统一处理）
     * 5. 大小写归一化（保留专有名词）
     */
    public String normalize(String rawQuery) {
        if (rawQuery == null || rawQuery.isBlank()) {
            return "";
        }
        String result = rawQuery.trim();
        
        // 繁简转换
        result = zhConverter.convert(result, ZhConverter.SIMPLIFIED);
        
        // 全角转半角
        result = fullWidthToHalfWidth(result);
        
        // 多空格压缩
        result = result.replaceAll("\\s+", " ");
        
        // 标点统一化（中文逗号在搜索中保留，但统一其他标点）
        result = normalizePunctuation(result);
        
        return result;
    }
    
    /**
     * 全角转半角（保留中文标点中的逗号和句号）
     */
    private String fullWidthToHalfWidth(String text) {
        StringBuilder sb = new StringBuilder();
        for (char c : text.toCharArray()) {
            if (c >= '\uFF01' && c <= '\uFF5E') {
                // 全角ASCII范围 → 半角
                sb.append((char)(c - 0xFEE0));
            } else if (c == '\u3000') {
                // 全角空格 → 半角空格
                sb.append(' ');
            } else {
                sb.append(c);
            }
        }
        return sb.toString();
    }
}
```

### 5.2 意图分类器

```java
@Service
public class SearchIntentClassifier {

    @Autowired
    private IntentRuleMapper intentRuleMapper;
    
    @Autowired
    private EducationNERService nerService;
    
    @Autowired
    private HotQueryService hotQueryService;
    
    /**
     * 意图分类主入口
     * @return 按置信度降序排列的意图列表
     */
    public List<IntentPrediction> classify(SearchContext context, 
                                           List<RecognizedEntity> entities) {
        // 双通道并行
        CompletableFuture<List<IntentPrediction>> ruleFuture = 
            CompletableFuture.supplyAsync(() -> classifyByRules(context, entities));
        CompletableFuture<List<IntentPrediction>> modelFuture = 
            CompletableFuture.supplyAsync(() -> classifyByModel(context, entities));
        
        List<IntentPrediction> ruleResults = ruleFuture.join();
        List<IntentPrediction> modelResults = modelFuture.join();
        
        // 融合结果
        return fusePredictions(ruleResults, modelResults);
    }
    
    /**
     * 规则匹配通道
     * 基于正则、关键词、模板的确定性意图分类
     */
    private List<IntentPrediction> classifyByRules(SearchContext context,
                                                    List<RecognizedEntity> entities) {
        String query = context.getNormalizedQuery();
        List<IntentRule> rules = intentRuleMapper.findActiveRules(
            context.getSubjectContext());
        
        List<IntentPrediction> predictions = new ArrayList<>();
        
        for (IntentRule rule : rules) {
            double score = matchRule(rule, query);
            if (score > 0) {
                predictions.add(IntentPrediction.builder()
                    .intent(SearchIntent.valueOf(rule.getTargetIntent()))
                    .confidence(score * (rule.getPriority() / 100.0))
                    .build());
            }
        }
        
        // 实体驱动的意图推断
        for (RecognizedEntity entity : entities) {
            if ("FORMULA".equals(entity.getEntityType())) {
                predictions.add(IntentPrediction.builder()
                    .intent(SearchIntent.FORMULA_LOOKUP)
                    .confidence(entity.getConfidence() * 0.7)
                    .build());
            }
        }
        
        return predictions.stream()
            .collect(Collectors.groupingBy(IntentPrediction::getIntent))
            .entrySet().stream()
            .map(e -> IntentPrediction.builder()
                .intent(e.getKey())
                .confidence(e.getValue().stream()
                    .mapToDouble(IntentPrediction::getConfidence)
                    .max().orElse(0))
                .build())
            .sorted(Comparator.comparingDouble(IntentPrediction::getConfidence).reversed())
            .collect(Collectors.toList());
    }
    
    /**
     * ML模型通道
     * 使用轻量级FastText/TextCNN模型进行意图分类
     */
    private List<IntentPrediction> classifyByModel(SearchContext context,
                                                    List<RecognizedEntity> entities) {
        // 特征拼接：query文本 + 实体类型 + 学科上下文
        String modelInput = buildModelInput(context, entities);
        
        // 调用模型服务（本地部署的FastText，延迟<5ms）
        Map<String, Double> rawScores = modelClient.predictIntent(modelInput);
        
        return rawScores.entrySet().stream()
            .map(e -> IntentPrediction.builder()
                .intent(SearchIntent.valueOf(e.getKey()))
                .confidence(e.getValue())
                .build())
            .filter(p -> p.getConfidence() > 0.05)
            .sorted(Comparator.comparingDouble(IntentPrediction::getConfidence).reversed())
            .collect(Collectors.toList());
    }
    
    /**
     * 规则 + 模型结果融合
     * 规则通道高精度低召回，模型通道高召回中精度
     * 采用加权融合策略
     */
    private List<IntentPrediction> fusePredictions(
            List<IntentPrediction> ruleResults,
            List<IntentPrediction> modelResults) {
        
        Map<SearchIntent, Double> fused = new EnumMap<>(SearchIntent.class);
        
        // 规则权重0.65（高精度）
        for (IntentPrediction p : ruleResults) {
            fused.merge(p.getIntent(), p.getConfidence() * 0.65, Double::sum);
        }
        
        // 模型权重0.35（高召回）
        for (IntentPrediction p : modelResults) {
            fused.merge(p.getIntent(), p.getConfidence() * 0.35, Double::sum);
        }
        
        return fused.entrySet().stream()
            .map(e -> IntentPrediction.builder()
                .intent(e.getKey())
                .confidence(Math.min(e.getValue(), 1.0)) // cap at 1.0
                .build())
            .filter(p -> p.getConfidence() > 0.05)
            .sorted(Comparator.comparingDouble(IntentPrediction::getConfidence).reversed())
            .collect(Collectors.toList());
    }
    
    /**
     * 内置意图规则示例（数据库维护，此处展示规则范式）
     */
    private static final List<IntentRuleTemplate> BUILTIN_RULES = List.of(
        // 题目搜索规则
        IntentRuleTemplate.of(".*(.+题|试题|练习|真题|试卷).*", "QUESTION_SEARCH", 90),
        IntentRuleTemplate.of(".*(怎么做|怎么解|解题|求.*值|计算).*", "QUESTION_SEARCH", 80),
```

```java
@Service
public class EducationNERService {

    @Autowired
    private KnowledgePointService kpService;
    
    @Autowired
    private EducationEntityDictService entityDictService;
    
    /**
     * 多策略实体识别
     * 策略1: 词典精确匹配（最快，覆盖知识点名称、公式名称等）
     * 策略2: AC自动机多模式匹配（高效的多词匹配）
     * 策略3: 轻量级NLP模型（BiLSTM-CRF或BERT-NER，处理未登录词）
     */
    public List<RecognizedEntity> recognize(String query, SearchContext context) {
        List<RecognizedEntity> entities = new ArrayList<>();
        
        // 策略1: 词典精确匹配
        entities.addAll(matchByDictionary(query, context));
        
        // 策略2: 知识点名称AC自动机匹配
        entities.addAll(matchByKnowledgePoint(query, context));
        
        // 策略3: NLP模型识别（仅在前两种策略结果不足时触发）
        if (entities.size() < 2 && query.length() > 4) {
            entities.addAll(recognizeByModel(query, context));
        }
        
        // 去重 & 冲突解决（选择最长匹配）
        return resolveConflicts(entities);
    }
    
    /**
     * 基于知识点数据库的AC自动机匹配
     */
    private List<RecognizedEntity> matchByKnowledgePoint(String query, 
                                                          SearchContext context) {
        // 获取当前学科+学段的知识点词典
        ACAutomaton automaton = kpService.getACAutomaton(
            context.getSubjectContext(), 
            context.getStageLevel()
        );
        
        List<MatchResult> matches = automaton.search(query);
        
        return matches.stream()
            .map(m -> RecognizedEntity.builder()
                .text(m.getWord())
                .entityType("KNOWLEDGE_POINT")
                .entityId(m.getMetadata().getKpId())
                .confidence(m.getMetadata().getConfidence())
                .startPos(m.getStart())
                .endPos(m.getEnd())
                .build())
            .collect(Collectors.toList());
    }
    
    /**
     * 冲突解决：当多个实体重叠时，选择置信度最高且最长匹配的实体
     */
    private List<RecognizedEntity> resolveConflicts(List<RecognizedEntity> entities) {
        if (entities.size() <= 1) return entities;
        
        // 按起始位置排序
        entities.sort(Comparator.comparingInt(RecognizedEntity::getStartPos));
        
        List<RecognizedEntity> resolved = new ArrayList<>();
        RecognizedEntity current = entities.get(0);
        
        for (int i = 1; i < entities.size(); i++) {
            RecognizedEntity next = entities.get(i);
            
            // 检查重叠
            if (next.getStartPos() < current.getEndPos()) {
                // 重叠：选择更长的匹配，长度相同选置信度更高的
                int currentLen = current.getEndPos() - current.getStartPos();
                int nextLen = next.getEndPos() - next.getStartPos();
                
                if (nextLen > currentLen || 
                    (nextLen == currentLen && next.getConfidence() > current.getConfidence())) {
                    current = next;
                }
            } else {
                resolved.add(current);
                current = next;
            }
        }
        resolved.add(current);
        
        return resolved;
    }
}
```

### 5.4 Query 改写管线

```java
@Service
public class QueryRewritePipeline {

    @Autowired private QueryPreprocessor preprocessor;
    @Autowired private EducationNERService nerService;
    @Autowired private SearchIntentClassifier intentClassifier;
    @Autowired private SynonymExpander synonymExpander;
    @Autowired private SpellCorrector spellCorrector;
    @Autowired private AbbreviationExpander abbreviationExpander;
    @Autowired private QueryCacheService queryCacheService;
    @Autowired private EsDslBuilder dslBuilder;
    
    /**
     * Query改写主流程
     */
    public RewrittenQuery rewrite(SearchContext context) {
        long startTime = System.currentTimeMillis();
        
        // 1. 检查缓存
        String cacheKey = buildCacheKey(context);
        RewrittenQuery cached = queryCacheService.get(cacheKey);
        if (cached != null) {
            return cached;
        }
        
        // 2. Query归一化
        String normalized = preprocessor.normalize(context.getRawQuery());
        context.setNormalizedQuery(normalized);
        
        // 3. 拼写纠错
        List<SpellCorrection> corrections = spellCorrector.correct(normalized, context);
        String correctedQuery = applyCorrections(normalized, corrections);
        
        // 4. 缩写/简称还原
        String expandedQuery = abbreviationExpander.expand(correctedQuery, context);
        
        // 5. 实体识别
        List<RecognizedEntity> entities = nerService.recognize(expandedQuery, context);
        
        // 6. 意图分类
        List<IntentPrediction> intents = intentClassifier.classify(
            context.toBuilder().normalizedQuery(expandedQuery).build(), 
            entities
        );
        SearchIntent primaryIntent = intents.isEmpty() 
            ? SearchIntent.BROWSE : intents.get(0).getIntent();
        
        // 7. 同义词扩展
        List<String> expandedTerms = synonymExpander.expand(
            expandedQuery, entities, context, primaryIntent
        );
        
        // 8. 知识点ID收集
        List<Long> kpIds = entities.stream()
            .filter(e -> "KNOWLEDGE_POINT".equals(e.getEntityType()))
            .map(RecognizedEntity::getEntityId)
            .distinct()
            .collect(Collectors.toList());
        
        // 9. 同义词映射收集
        List<SynonymMapping> synonymMappings = synonymExpander.getSynonymMappings(
            expandedQuery, entities, context);
        
        // 10. 排序信号生成
        RankingSignals signals = buildRankingSignals(context, primaryIntent);
        
        // 11. ES DSL构建
        String esDsl = dslBuilder.build(
            correctedQuery, expandedTerms, entities, kpIds, 
            primaryIntent, context, signals
        );
        
        RewrittenQuery result = RewrittenQuery.builder()
            .originalQuery(context.getRawQuery())
            .normalizedQuery(normalized)
            .mainQuery(expandedQuery)
            .expandedTerms(expandedTerms)
            .synonymMappings(synonymMappings)
            .entities(entities)
            .knowledgePointIds(kpIds)
            .intentPredictions(intents)
            .primaryIntent(primaryIntent)
            .gradeContext(context.getGradeCode())
            .esDsl(esDsl)
            .rankingSignals(signals)
            .spellCorrected(!corrections.isEmpty())
            .corrections(corrections)
            .processingTimeMs(System.currentTimeMillis() - startTime)
            .build();
        
        // 12. 写入缓存
        queryCacheService.put(cacheKey, result, 5, TimeUnit.MINUTES);
        
        return result;
    }
    
    private String buildCacheKey(SearchContext context) {
        String raw = String.join("|",
            context.getNormalizedQuery() != null ? context.getNormalizedQuery() : context.getRawQuery(),
            context.getStageLevel() != null ? context.getStageLevel() : "",
            context.getSubjectContext() != null ? context.getSubjectContext() : "",
            context.getGradeCode() != null ? context.getGradeCode() : "",
            context.getSource() != null ? context.getSource().name() : ""
        );
        return DigestUtils.sha256Hex(raw);
    }
    
    private RankingSignals buildRankingSignals(SearchContext context, 
                                                SearchIntent primaryIntent) {
        RankingSignals.RankingSignalsBuilder builder = RankingSignals.builder();
        
        // 根据意图调整权重
        switch (primaryIntent) {
            case QUESTION_SEARCH:
                builder.intentMatchWeight(2.0);   // 题目类内容加权
                builder.knowledgePointMatchWeight(1.5);
                break;
            case CONCEPT_LOOKUP:
                builder.intentMatchWeight(1.8);   // 讲解类内容加权
                builder.knowledgePointMatchWeight(2.0);
                break;
            case VIDEO_SEARCH:
                builder.intentMatchWeight(2.5);   // 视频类内容强加权
                break;
            case METHOD_SEARCH:
                builder.intentMatchWeight(2.0);
                builder.knowledgePointMatchWeight(1.8);
                break;
            default:
                // 使用默认权重
                break;
        }
        
        return builder.build();
    }
}
```

### 5.5 拼写纠错器

```java
@Service
public class SpellCorrector {

    @Autowired
    private EducationTermDictionary termDict;
    
    /**
     * 教育术语纠错
     * 策略1: 编辑距离纠错（针对单术语的错别字）
     * 策略2: 拼音纠错（同音字错误，如"距离"→"举例"→可能是"距离"）
     * 策略3: 学科专用词纠错（如"牛顿第一定律"打成"牛顿第一定虑"）
     */
    public List<SpellCorrection> correct(String query, SearchContext context) {
        List<SpellCorrection> corrections = new ArrayList<>();
        
        // 分词
        List<String> tokens = tokenize(query);
        
        for (int i = 0; i < tokens.size(); i++) {
            String token = tokens.get(i);
            
            // 跳过数字、英文（非中文术语不纠错）
            if (isNumericOrAlpha(token)) continue;
            
            // 跳过已知的教育术语
            if (termDict.contains(token, context.getSubjectContext())) continue;
            
            // 在术语词典中查找最近邻
            SpellCorrection correction = findClosestTerm(token, context);
            if (correction != null && correction.getConfidence() > 0.7) {
                corrections.add(correction);
            }
        }
        
        return corrections;
    }
    
    /**
     * 基于BK-Tree的高效近似匹配
     */
    private SpellCorrection findClosestTerm(String token, SearchContext context) {
        BKTree bkTree = termDict.getBKTree(context.getSubjectContext());
        
        // 编辑距离≤2的候选
        List<String> candidates = bkTree.search(token, 2);
        
        if (candidates.isEmpty()) return null;
        
        // 选择编辑距离最小且频率最高的术语
        String best = null;
        int bestDist = Integer.MAX_VALUE;
        int bestFreq = 0;
        
        for (String candidate : candidates) {
            int dist = editDistance(token, candidate);
            int freq = termDict.getFrequency(candidate);
            
            if (dist < bestDist || (dist == bestDist && freq > bestFreq)) {
                best = candidate;
                bestDist = dist;
                bestFreq = freq;
            }
        }
        
        if (best == null || bestDist == 0) return null;
        
        // 置信度计算：编辑距离越小、术语频率越高，置信度越高
        double confidence = (1.0 - bestDist * 0.3) * Math.min(1.0, bestFreq / 100.0 + 0.5);
        
        String correctionType = determineCorrectionType(token, best);
        
        return SpellCorrection.builder()
            .original(token)
            .corrected(best)
            .confidence(confidence)
            .correctionType(correctionType)
            .build();
    }
    
    private String determineCorrectionType(String original, String corrected) {
        if (original.length() == corrected.length()) {
            return "WRONG_CHAR";
        } else if (original.length() < corrected.length()) {
            return "MISSING_CHAR";
        } else {
            return "EXTRA_CHAR";
        }
    }
    
    /**
     * 标准编辑距离（Levenshtein Distance）
     */
    private int editDistance(String s1, String s2) {
        int[][] dp = new int[s1.length() + 1][s2.length() + 1];
        
        for (int i = 0; i <= s1.length(); i++) dp[i][0] = i;
        for (int j = 0; j <= s2.length(); j++) dp[0][j] = j;
        
        for (int i = 1; i <= s1.length(); i++) {
            for (int j = 1; j <= s2.length(); j++) {
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = 1 + Math.min(dp[i - 1][j - 1],
                                   Math.min(dp[i - 1][j], dp[i][j - 1]));
                }
            }
        }
        return dp[s1.length()][s2.length()];
    }
}
```

```java
@Service
public class SynonymExpander {

    @Autowired
    private SynonymService synonymService;
    
    @Autowired
    private KnowledgeGraphService knowledgeGraphService;
    
    @Autowired
    private HotQueryService hotQueryService;
    
    /**
     * 同义词扩展
     * 层级1: 数据库同义词表精确匹配
     * 层级2: 知识图谱关联节点扩展
     * 层级3: 历史搜索日志关联query挖掘
     */
    public List<String> expand(String query, List<RecognizedEntity> entities,
                                SearchContext context, SearchIntent intent) {
        Set<String> expanded = new LinkedHashSet<>();
        
        // 层级1: 数据库同义词
        for (RecognizedEntity entity : entities) {
            List<SynonymMapping> synonyms = synonymService.getSynonyms(
                entity.getText(), 
                context.getSubjectContext(),
                context.getStageLevel()
            );
            for (SynonymMapping sm : synonyms) {
                if ("EXACT".equals(sm.getType()) || "RELATED".equals(sm.getType())) {
                    expanded.add(sm.getSynonym());
                }
            }
        }
        
        // 层级2: 知识图谱关联扩展
        for (RecognizedEntity entity : entities) {
            if ("KNOWLEDGE_POINT".equals(entity.getEntityType())) {
                // 获取该知识点的直接前驱和后继节点名称
                List<String> related = knowledgeGraphService.getRelatedTerms(
                    entity.getEntityId(), 1 // 只扩展1层
                );
                expanded.addAll(related);
            }
        }
        
        // 层级3: 热门关联query（当用户搜索A时，也经常搜索B）
        List<String> coOccurred = hotQueryService.getCoOccurredQueries(
            query, context.getStageLevel(), 5
        );
        expanded.addAll(coOccurred);
        
        // 限制扩展词数量（避免过度扩展影响性能和精度）
        return expanded.stream()
            .limit(15)
            .collect(Collectors.toList());
    }
    
    public List<SynonymMapping> getSynonymMappings(String query,
                                                    List<RecognizedEntity> entities,
                                                    SearchContext context) {
        List<SynonymMapping> mappings = new ArrayList<>();
        
        for (RecognizedEntity entity : entities) {
            mappings.addAll(synonymService.getSynonyms(
                entity.getText(),
                context.getSubjectContext(),
                context.getStageLevel()
            ));
        }
        
        return mappings;
    }
```

### 5.7 ES DSL 构建器

```java
@Service
public class EsDslBuilder {

    /**
     * 根据改写后的query构建ES查询DSL
     * 核心策略：must → should → filter 三层结构
     */
    public String build(String mainQuery, List<String> expandedTerms,
                        List<RecognizedEntity> entities, List<Long> kpIds,
                        SearchIntent intent, SearchContext context,
                        RankingSignals signals) {
        
        BoolQueryBuilder boolQuery = QueryBuilders.boolQuery();
        
        // ========== MUST层：核心匹配（必须满足） ==========
        
        // 主query的多字段匹配
        MultiMatchQueryBuilder mainMatch = QueryBuilders.multiMatchQuery(mainQuery)
            .field("title", 3.0f)           // 标题权重最高
            .field("title.pinyin", 1.5f)    // 拼音匹配（容错）
            .field("content", 1.0f)         // 正文标准权重
            .field("tags", 2.0f)            // 标签加权
            .field("knowledge_points.name", 2.5f) // 知识点名称高权重
            .type(MultiMatchQueryBuilder.Type.BEST_FIELDS)
            .tieBreaker(0.3f)
            .minimumShouldMatch("75%");
        
        boolQuery.must(mainQuery);
        
        // ========== SHOULD层：扩展词匹配（加分项） ==========
        
        for (String term : expandedTerms) {
            boolQuery.should(QueryBuilders.matchQuery("content", term)
                .boost(0.5f));
            boolQuery.should(QueryFieldsQueryBuilder.of(
                f -> f.field("knowledge_points.name").query(term)
            )._toQuery().boost(1.0f));
        }
        
        // 知识点精确匹配（强加分）
        if (!kpIds.isEmpty()) {
            for (Long kpId : kpIds) {
                boolQuery.should(QueryBuilders.termQuery(
                    "knowledge_points.id", kpId).boost(2.0f));
            }
        }
        
        // 意图匹配加分（内容类型与意图一致时加分）
        List<String> preferredTypes = getIntentPreferredTypes(intent);
        for (String type : preferredTypes) {
            boolQuery.should(QueryBuilders.termQuery(
                "content_type", type).boost(1.5f));
        }
        
        // ========== FILTER层：硬条件过滤 ==========
        
        // 年级/学段过滤
        if (context.getStageLevel() != null) {
            boolQuery.filter(QueryBuilders.boolQuery()
                .should(QueryBuilders.termQuery("stage_level", context.getStageLevel()))
                .should(QueryBuilders.termQuery("stage_level", "ALL"))
            );
        }
        
        // 学科过滤
        if (context.getSubjectContext() != null) {
            boolQuery.filter(QueryBuilders.termQuery(
                "subject_code", context.getSubjectContext()));
        }
        
        // 用户筛选条件
        if (context.getFilters() != null && 
            context.getFilters().getContentTypes() != null &&
            !context.getFilters().getContentTypes().isEmpty()) {
            boolQuery.filter(QueryBuilders.termsQuery(
                "content_type", context.getFilters().getContentTypes()));
        }
        
        // 状态过滤（只搜已发布内容）
        boolQuery.filter(QueryBuilders.termQuery("status", "PUBLISHED"));
        
        // ========== 构建完整查询 ==========
        
        SearchSourceBuilder sourceBuilder = new SearchSourceBuilder()
            .query(boolQuery)
            .from((context.getPage() - 1) * context.getPageSize())
            .size(context.getPageSize())
            .trackTotalCount(true);
        
        // 高亮配置
        sourceBuilder.highlighter(
            HighlightBuilder.of(h -> h
                .fields("title", HighlightField.of(f -> f.preTags("<em>").postTags("</em>")))
                .fields("content", HighlightField.of(f -> f
                    .preTags("<em>").postTags("</em>")
                    .fragmentSize(150).numberOfFragments(2)))
                .fields("knowledge_points.name", HighlightField.of(f -> f
                    .preTags("<em>").postTags("</em>")))
            )
        );
        
        // 聚合配置
        sourceBuilder.aggregation(
            Aggregation.of(a -> a.terms(TermsAggregation.of(t -> t
                .field("content_type").size(10))).name("by_type"))
        );
        sourceBuilder.aggregation(
            Aggregation.of(a -> a.terms(TermsAggregation.of(t -> t
                .field("subject_code").size(10))).name("by_subject"))
        );
        
        // 排序：综合评分 → 热度 → 更新时间
        sourceBuilder.sort(SortOptions.of(s -> s.score(ScoreSort.of(sc -> sc.order(SortOrder.Desc)))));
        sourceBuilder.sort(SortOptions.of(s -> s.field(FieldSort.of(f -> f
            .field("popularity_score").order(SortOrder.Desc)))));
        sourceBuilder.sort(SortOptions.of(s -> s.field(FieldSort.of(f -> f
            .field("updated_at").order(SortOrder.Desc)))));
        
        return sourceBuilder.toString();
    }
    
    /**
     * 意图对应的首选内容类型
     */
    private List<String> getIntentPreferredTypes(SearchIntent intent) {
        return switch (intent) {
            case QUESTION_SEARCH -> List.of("QUESTION", "QUESTION_BANK");
            case CONCEPT_LOOKUP -> List.of("KNOWLEDGE_POINT", "ARTICLE");
            case VIDEO_SEARCH -> List.of("VIDEO");
            case TEXTBOOK_SEARCH -> List.of("TEXTBOOK_CHAPTER", "COURSEWARE");
            case METHOD_SEARCH -> List.of("ARTICLE", "KNOWLEDGE_POINT", "VIDEO");
            case FORMULA_LOOKUP -> List.of("KNOWLEDGE_POINT", "FORMULA_REFERENCE");
            case ESSAY_MATERIAL -> List.of("ESSAY_TEMPLATE", "MATERIAL");
            case MISTAKE_SEARCH -> List.of("QUESTION");
            default -> List.of();
        };
    }
}
```

### 6.1 重排架构

```java
@Service
public class PersonalizedReranker {

    @Autowired private UserProfileService userProfileService;
    @Autowired private SearchClickHistoryService clickHistoryService;
    @Autowired private LearningProgressService progressService;
    
    /**
     * 个性化重排
     * 在ES返回原始结果后，基于用户画像进行二次排序
     */
    public List<SearchResultItem> rerank(List<SearchResultItem> originalResults,
                                          SearchContext context,
                                          RewrittenQuery rewritten) {
        if (originalResults.size() <= 1) {
            return originalResults;
        }
        
        // 获取用户画像
        UserProfile profile = userProfileService.getProfile(context.getUserId());
        
        // 获取用户近期点击历史（最近30天）
        Set<String> recentClickedContent = clickHistoryService.getRecentClickedContentIds(
            context.getUserId(), 30
        );
        
        // 获取用户学习偏好
        UserLearningPreference pref = profile.getLearningPreference();
        
        // 计算重排分数
        for (SearchResultItem item : originalResults) {
            double rerankScore = calculateRerankScore(
                item, profile, pref, recentClickedContent, context, rewritten
            );
            item.setRerankScore(rerankScore);
        }
        
        // 按重排分数排序
        List<SearchResultItem> reranked = new ArrayList<>(originalResults);
        reranked.sort(Comparator.comparingDouble(SearchResultItem::getRerankScore).reversed());
        
        return reranked;
    }
    
    /**
     * 重排评分计算
     */
    private double calculateRerankScore(SearchResultItem item,
                                         UserProfile profile,
                                         UserLearningPreference pref,
                                         Set<String> recentClicked,
                                         SearchContext context,
                                         RewrittenQuery rewritten) {
        double score = item.getOriginalScore(); // ES原始相关性评分
        
        // 1. 年级精确匹配加分
        if (item.getStageLevel() != null && 
            item.getStageLevel().equals(context.getStageLevel())) {
            score += 2.0;
        }
        
        // 2. 教材版本匹配加分
        if (context.getTextbookEditionId() != null && 
            context.getTextbookEditionId().equals(item.getTextbookEditionId())) {
            score += 1.5;
        }
        
        // 3. 内容类型偏好加分
        if (pref != null && pref.getPreferredContentTypes() != null &&
            pref.getPreferredContentTypes().contains(item.getContentType())) {
            score += 0.8;
        }
        
        // 4. 学习进度相关性加分
        // 如果该内容关联的知识点在用户当前学习范围内
        if (isInCurrentLearningScope(item, context.getUserId())) {
            score += 1.2;
        }
        
        // 5. 已查看内容适当降权（避免重复曝光）
        if (recentClicked.contains(item.getContentId())) {
            score -= 1.5;
        }
        
        // 6. 内容质量评分
        if (item.getQualityScore() > 0) {
            score += item.getQualityScore() * 0.5;
        }
        
        // 7. 难度匹配（用户水平与内容难度匹配时加分）
        if (item.getDifficultyLevel() != null && profile.getAbilityLevel() != null) {
            double difficultyGap = Math.abs(
                difficultyToScore(item.getDifficultyLevel()) - 
                abilityToScore(profile.getAbilityLevel())
            );
            score -= difficultyGap * 0.8; // 难度差距越大，扣分越多
        }
        
        return score;
    }
    
    private boolean isInCurrentLearningScope(SearchResultItem item, Long userId) {
        if (item.getKnowledgePointIds() == null || item.getKnowledgePointIds().isEmpty()) {
            return false;
        }
        Set<Long> userCurrentKps = progressService.getCurrentLearningKnowledgePoints(userId);
        return item.getKnowledgePointIds().stream()
            .anyMatch(userCurrentKps::contains);
    }
}
```

## 7. 零结果处理策略

当用户搜索返回零结果时，系统自动执行降级策略：

```java
@Service
public class ZeroResultHandler {

    /**
     * 零结果自动恢复策略链
     */
    public SearchResponse handleZeroResults(SearchContext context, 
                                             RewrittenQuery rewritten) {
        // 策略1: 放宽匹配条件（minimumShouldMatch降低）
        SearchResponse resp = retryWithRelaxedMatch(rewritten, context);
        if (hasResults(resp)) return resp;
        
        // 策略2: 只使用核心实体词搜索
        resp = retryWithEntityOnly(rewritten, context);
        if (hasResults(resp)) return resp;
        
        // 策略3: 使用拼音搜索（可能是用户不知道具体汉字）
        resp = retryWithPinyin(context.getRawQuery(), context);
        if (hasResults(resp)) return resp;
        
        // 策略4: 使用AI语义搜索（将query转为向量，进行向量近似搜索）
        resp = retryWithVectorSearch(context.getRawQuery(), context);
        if (hasResults(resp)) return resp;
        
        // 策略5: 全网搜索建议（提示用户该内容可能不在当前学段/学科范围内）
        return buildSuggestionResponse(context, rewritten);
    }
    
    /**
     * 策略1: 放宽minimumShouldMatch
     */
    private SearchResponse retryWithRelaxedMatch(RewrittenQuery rewritten,
                                                  SearchContext context) {
        // 将DSL中minimumShouldMatch从75%降低到30%
        String relaxedDsl = rewritten.getEsDsl()
            .replace("\"minimum_should_match\": \"75%\"", 
                     "\"minimum_should_match\": \"30%\"");
        
        return searchService.executeSearch(relaxedDsl, context);
    }
    
    /**
     * 策略4: 向量语义搜索
     * 将query通过Embedding模型转为向量，在向量数据库中进行ANN搜索
     */
    private SearchResponse retryWithVectorSearch(String query, SearchContext context) {
        // 生成query embedding
        float[] queryVector = embeddingService.embed(query);
        
        // 在向量索引中进行近似搜索
        List<VectorSearchHit> hits = vectorSearchService.search(
            queryVector,
            "edu_content_embeddings",
            20,
            Map.of(
                "stage_level", context.getStageLevel(),
                "subject_code", context.getSubjectContext()
            )
        );
        
        return convertVectorHitsToResponse(hits);
    }
    
    /**
     * 策略5: 构建建议响应
     */
    private SearchResponse buildSuggestionResponse(SearchContext context,
                                                    RewrittenQuery rewritten) {
        return SearchResponse.builder()
            .results(Collections.emptyList())
            .total(0)
            .zeroResultSuggestion(ZeroResultSuggestion.builder()
                .message("未找到\"" + context.getRawQuery() + "\"的相关内容")
                .possibleReasons(determinePossibleReasons(context))
                .suggestedQueries(getSuggestedQueries(context, rewritten))
                .build())
            .build();
    }
    
    private List<String> determinePossibleReasons(SearchContext context) {
        List<String> reasons = new ArrayList<>();
        
        if (context.getStageLevel() != null) {
            reasons.add("当前学段范围内暂无此内容，可尝试切换学段");
        }
        if (context.getSubjectContext() != null) {
            reasons.add("当前学科范围内暂无此内容，可尝试切换学科");
        }
        reasons.add("该内容可能尚未收录，试试用更常见的关键词搜索");
        
        return reasons;
    }
}
```

```java
@Service
public class SearchSuggestionEngine {

    /**
     * 搜索框联想
     * 数据源优先级：
     * 1. 知识点精确前缀匹配
     * 2. 热门query前缀匹配
     * 3. 用户历史搜索匹配
     * 4. 同义词/相关词推荐

    public List<SearchSuggestion> suggest(String prefix, SearchContext context) {

            prefix, context.getSubjectContext(), context.getStageLevel(), 3);
        for (KnowledgePoint kp : kps) {

                .text(kp.getName())
                .type("KNOWLEDGE_POINT")
                .knowledgePointId(kp.getId())
                .hotScore(kp.getSearchHotness())
                .build());
        }

        List<HotQuery> hotQueries = hotQueryService.searchByPrefix(
            prefix, context.getStageLevel(), context.getSubjectContext(), 5);
        for (HotQuery hq : hotQueries) {
            suggestions.add(SearchSuggestion.builder()
                .text(hq.getQueryText())
                .type("HOT_QUERY")
                .hotScore(hq.getSearchCount())
                .build());
        }
        
        // 3. 用户搜索历史（如果已登录）
        if (context.getUserId() != null) {
            List<String> history = searchHistoryService.searchByPrefix(
                context.getUserId(), prefix, 3);
            for (String h : history) {
                suggestions.add(SearchSuggestion.builder()
                    .text(h)
                    .type("HISTORY")
                    .build());
            }
        }
        
        // 合并去重 & 排序 & 限制数量
        return suggestions.stream()
            .sorted(Comparator.comparingDouble(SearchSuggestion::getHotScore).reversed())
            .distinct()
            .limit(10)
            .collect(Collectors.toList());
    }
```

### 10.2 降级链路

```java
@Service
public class SearchDegradationManager {

    /**
     * 搜索降级链路
     * 每一级降级保证基本搜索可用
     */
    public SearchResponse searchWithDegradation(SearchContext context) {
        try {
            // 完整搜索（意图理解 + 改写 + 重排）
            return fullSearch(context);
            
        } catch (NERServiceException | IntentServiceException e) {
            log.warn("NER/Intent service degraded, falling back to basic search", e);
            // 降级1: 跳过NER和意图，仅做同义词扩展 + 关键词搜索
            return basicSearch(context);
            
        } catch (SynonymServiceException e) {
            log.warn("Synonym service degraded, falling back to raw search", e);
            // 降级2: 跳过所有预处理，直接用原始query搜索
            return rawSearch(context);
            
        } catch (EsServiceException e) {
            log.error("Elasticsearch unavailable, falling back to cache search", e);
            // 降级3: 从Redis缓存中搜索（仅有热点内容）
            return cacheSearch(context);
            
        } catch (Exception e) {
            log.error("Search completely failed", e);
            // 最终降级: 返回系统错误 + 推荐内容
            return SearchResponse.systemError("搜索服务暂时不可用，请稍后重试");
        }
    }
    
    /**
     * 降级1: 基础搜索（跳过NER和意图分类）
     */
    private SearchResponse basicSearch(SearchContext context) {
        String normalized = preprocessor.normalize(context.getRawQuery());
        
        // 直接构建ES查询（无扩展词、无意图加权）
        String dsl = simpleDslBuilder.build(normalized, context);
        SearchResponse response = searchService.executeSearch(dsl, context);
        
        // 仍然执行重排（如果有用户画像）
        if (response.hasResults() && context.getUserId() != null) {
            List<SearchResultItem> reranked = reranker.rerank(
                response.getResults(), context, 
                RewrittenQuery.builder()
                    .originalQuery(context.getRawQuery())
                    .mainQuery(normalized)
                    .primaryIntent(SearchIntent.BROWSE)
                    .build()
            );
            response.setResults(reranked);
        }
        
        return response;
    }
    
    /**
     * 降级2: 原始搜索（跳过所有预处理）
     */
    private SearchResponse rawSearch(SearchContext context) {
        String dsl = "{\"query\":{\"match\":{\"title\":{\"query\":\"" 
            + escapeJson(context.getRawQuery()) 
            + "\"}}}}";
        return searchService.executeSearch(dsl, context);
    }
    
    /**
     * 降级3: 缓存搜索（ES不可用时的兜底）
     */
    private SearchResponse cacheSearch(SearchContext context) {
        // 从Redis中搜索缓存的搜索结果
        String cacheKey = "edu:search:cache:" + DigestUtils.sha256Hex(
            context.getRawQuery() + context.getStageLevel());
        
        SearchResponse cached = redisSearchCache.get(cacheKey);
        if (cached != null) {
            return cached.toBuilder()
                .fromCache(true)
                .cacheNotice("数据可能不是最新")
                .build();
        }
        
        // 如果缓存也没有，返回推荐内容
        return recommendationService.getFallbackRecommendations(context);
    }
}
```

```java
@Component
public class SearchMetrics {

    private final MeterRegistry metrics;

    private final Counter searchTotal = Counter.builder("edu.search.total")
        .tag("source", "global")
        .register(metrics);
    
    /** 改写耗时分布 */
    private final Timer rewriteTimer = Timer.builder("edu.search.rewrite.duration")
        .publishPercentiles(0.5, 0.9, 0.99)
        .register(metrics);
    
    /** 零结果率 */
    private final Counter zeroResultCount = Counter.builder("edu.search.zero_result")
        .register(metrics);
    
    /** 缓存命中率 */
    private final Counter cacheHit = Counter.builder("edu.search.cache")
        .tag("result", "hit")
        .register(metrics);
    
    /** 拼写纠正确认率（纠错后被点击的比例）*/
    private final Counter spellCorrectionAccepted = Counter.builder("edu.search.spell")
        .tag("result", "accepted")
        .register(metrics);
    
    /** 意图分类分布 */
    private final Map<String, Counter> intentCounters = new ConcurrentHashMap<>();
    
    public void recordIntent(SearchIntent intent) {
        intentCounters.computeIfAbsent(intent.name(), k -> 
            Counter.builder("edu.search.intent")
                .tag("type", k)
                .register(metrics)
        ).increment();
    }
}
```

## 13. 安全与合规

| 安全要点 | 措施 |
|---------|------|
| 搜索内容隔离 | 不同学段的内容搜索结果隔离，低学段用户不应搜到高学段敏感内容 |
| 敏感词过滤 | 搜索query经过敏感词过滤层，拦截违规搜索 |
| 搜索频率限制 | 普通用户 30次/分钟，会员用户 100次/分钟 |
| 隐私保护 | 搜索日志中的用户ID脱敏存储，不记录可识别个人信息 |
| 搜索审计 | 管理后台可查询热门搜索词趋势，用于内容规划 |
| 未成年人保护 | 幼儿/小学低年级搜索结果优先展示图文/视频内容，避免大段文字 |
