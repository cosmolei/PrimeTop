# 服务端-用户反馈数据深度分析与产品改进智能推荐引擎-详细设计

## 1. 概述

### 1.1 模块定位

用户反馈数据深度分析与产品改进智能推荐引擎是 PrimeTop 平台的**产品决策中枢**，负责将分散在多渠道的用户反馈数据（App 内反馈、应用商店评论、客服工单、社交媒体提及等）进行统一采集、智能分类、情感分析、主题挖掘和优先级评估，最终生成可执行的产品改进建议，形成从"听到用户声音"到"推动产品迭代"的完整闭环。

### 1.2 与现有系统的区别

| 现有模块 | 聚焦领域 | 本引擎差异点 |
|---------|---------|-------------|
| 用户反馈与AI质量评估 | AI 回答质量评分 | 聚焦 AI 输出质量，不覆盖全局产品反馈 |
| 客服与工单系统 | 客服处理流程 | 聚焦工单流转，不做深度分析和产品推荐 |
| 教学内容用户纠错反馈 | 内容错误纠正 | 聚焦教学内容准确性，不覆盖功能/UX 反馈 |
| 教育内容用户评价体系 | 内容口碑评分 | 聚焦内容评分，不做跨渠道聚合分析 |

**本引擎核心价值：** 跨渠道反馈聚合 → NLP 深度分析 → 产品改进智能推荐 → 闭环追踪。

### 1.3 设计目标

1. **全渠道汇聚**：统一 App 内反馈、应用商店评论、客服工单、社交媒体等反馈来源
2. **智能分类**：基于 NLP 自动将反馈分为 Bug 报告、功能建议、内容错误、体验问题等类别
3. **情感分析**：识别用户情绪状态，量化情感分值
4. **主题挖掘**：从海量反馈中自动发现高频讨论主题和新兴趋势
5. **优先级评估**：综合反馈频次、严重程度、用户价值、业务影响等多维度计算优先级
6. **产品改进推荐**：结合产品路线图，生成可执行的产品改进建议
7. **闭环追踪**：反馈关联到产品需求/缺陷跟踪系统，追踪改进进度并通知用户

### 1.4 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 主数据库 | PostgreSQL | 结构化反馈数据存储 |
| 搜索引擎 | Elasticsearch | 反馈全文检索与聚合分析 |
| 消息队列 | Kafka | 反馈事件流处理 |
| NLP 模型 | 大模型 API + 本地 BERT | 文本分类、情感分析、主题挖掘 |
| 缓存 | Redis | 热点分析结果缓存 |
| 向量数据库 | pgvector | 反馈语义相似度检索 |
| 任务调度 | XXL-Job | 定时分析任务 |

```java
public enum SentimentLabel {
    VERY_NEGATIVE(-1.0, -0.6, "极负面"),
    NEGATIVE(-0.6, -0.2, "负面"),
    NEUTRAL(-0.2, 0.2, "中立"),
    POSITIVE(0.2, 0.6, "正面"),
    VERY_POSITIVE(0.6, 1.0, "极正面");

    public static SentimentLabel fromScore(double score) {
        for (SentimentLabel label : values()) {
            if (score >= label.min && score < label.max) return label;

        return VERY_POSITIVE;
    }
```

## 4. 核心处理流程

### 4.1 反馈处理全流程状态机

```
用户提交/外部拉取
        │
        ▼
    ┌────────┐     NLP分析      ┌────────────┐
    │  NEW   │ ──────────────→ │ ANALYZING  │
    └────────┘                  └─────┬──────┘
                                      │
                    ┌─────────────────┼─────────────────┐
                    │                 │                 │
                    ▼                 ▼                 ▼
              ┌──────────┐    ┌────────────┐    ┌───────────┐
              │ TRIAGED  │    │ DUPLICATE  │    │  IGNORED  │
              └─────┬────┘    └────────────┘    └───────────┘
                    │
                    ▼
              ┌──────────────┐
              │ IN_PROGRESS  │
              └──────┬───────┘
                     │
                     ▼
              ┌──────────┐
              │ RESOLVED │
              └─────┬────┘
                    │
                    ▼
              ┌────────┐
              │ CLOSED │
              └────────┘
```

**状态转换条件：**

| 源状态 | 目标状态 | 条件 | 触发方式 |
|--------|---------|------|---------|
| NEW | ANALYZING | 反馈进入分析队列 | 系统自动 |
| ANALYZING | TRIAGED | NLP 分析完成 | 系统自动 |
| ANALYZING | ANALYZING | 分析失败重试 | 系统自动（最多3次） |
| TRIAGED | IN_PROGRESS | 人工分配处理 | 管理员操作 |
| TRIAGED | DUPLICATE | 检测到重复反馈 | 系统自动/人工 |
| TRIAGED | IGNORED | 无效反馈 | 管理员操作 |
| IN_PROGRESS | RESOLVED | 问题已修复 | 管理员操作 |
| RESOLVED | CLOSED | 用户确认/7天自动 | 系统/用户 |
| RESOLVED | IN_PROGRESS | 用户反馈未解决 | 用户操作 |

### 4.2 NLP 分析管线

```
反馈原始文本
    │
    ├──→ 文本清洗（去HTML、emoji、多余空格）

    ├──→ 语言检测（中/英/混合）

    ├──→ 分类管线 ──→ feedback_type + sub_type

    │
    ├──→ 情感分析 ──→ sentiment_score + sentiment_label + emotion_tags
    │         ├── 本地 BERT 模型（中文情感分析）
    │         └── 大模型深度情感分析（复杂语境）
    │
    ├──→ 关键词提取 ──→ keywords[]
    │         └── TF-IDF + TextRank 融合
    │
    ├──→ 主题归类 ──→ topic_tags[]
    │         └── 语义相似度匹配已有主题
    │
    ├──→ 模块路由 ──→ related_module + related_feature
    │         └── 基于关键词与模块映射表
    │
    ├──→ 紧急度评估 ──→ urgency_level

    │
    ├──→ 摘要生成 ──→ ai_summary
    │         └── 大模型一句话总结

    └──→ 相似度匹配 ──→ related_feedback_ids
              └── pgvector 向量检索 Top-K
```

### 4.3 优先级评分算法

```java
/**
 * 反馈优先级综合评分
 * 综合考虑：频次、严重度、用户价值、情感强度、时效性、业务影响
 */
public class FeedbackPriorityCalculator {

    // 各因子权重
    private static final double W_FREQUENCY = 0.20;    // 反馈频次
    private static final double W_SEVERITY = 0.25;     // 严重程度
    private static final double W_USER_VALUE = 0.15;   // 用户价值
    private static final double W_SENTIMENT = 0.10;    // 情感强度
    private static final double W_RECENCY = 0.10;      // 时效性
    private static final double W_BUSINESS = 0.20;     // 业务影响

    public double calculate(FeedbackItem feedback, FeedbackContext context) {
        // 1. 频次分：相似反馈出现次数的对数缩放
        double frequencyScore = Math.min(100,
            20 * Math.log1p(context.getSimilarFeedbackCount()));

        // 2. 严重度分：基于反馈类型和紧急度
        double severityScore = calculateSeverity(
            feedback.getFeedbackType(),
            feedback.getUrgencyLevel()
        );

        // 3. 用户价值分：会员等级权重
        double userValueScore = switch (feedback.getUserMemberLevel()) {
            case "YEARLY" -> 90;
            case "MONTHLY" -> 70;
            case "FREE" -> 50;
            default -> 40;
        };

        // 4. 情感强度分：|sentiment_score| * 100，负面权重更高
        double sentimentScore = Math.abs(feedback.getSentimentScore()) * 100;
        if (feedback.getSentimentScore() < 0) {
            sentimentScore = Math.min(100, sentimentScore * 1.2); // 负面加成
        }

        // 5. 时效性分：越新分越高，7天衰减
        long hoursAgo = Duration.between(
            feedback.getSubmittedAt(), LocalDateTime.now()
        ).toHours();
        double recencyScore = Math.max(0, 100 * Math.exp(-hoursAgo / 168.0));

        // 6. 业务影响分：核心模块权重更高
        double businessScore = calculateBusinessImpact(
            feedback.getRelatedModule(),
            context.getActiveUserCount()
        );

        return W_FREQUENCY * frequencyScore +
               W_SEVERITY * severityScore +
               W_USER_VALUE * userValueScore +
               W_SENTIMENT * sentimentScore +
               W_RECENCY * recencyScore +
               W_BUSINESS * businessScore;
    }

    private double calculateSeverity(String type, int urgency) {
        double typeBase = switch (type) {
            case "CRASH" -> 90;
            case "BUG_REPORT" -> 70;
            case "PAYMENT_ISSUE" -> 80;
            case "ACCOUNT_ISSUE" -> 75;
            case "PERFORMANCE" -> 60;
            case "UX_ISSUE" -> 40;
            case "CONTENT_ERROR" -> 50;
            case "FEATURE_REQUEST" -> 30;
            case "PRAISE" -> 10;
            default -> 35;
        };
        return Math.min(100, typeBase + (urgency - 3) * 10);
    }

    private double calculateBusinessImpact(String module, long activeUsers) {
        if (module == null) return 40;
        double moduleWeight = switch (module) {
            case "AI_TUTORING" -> 95;      // 核心功能
            case "PHOTO_SEARCH" -> 90;
            case "SYNCHRONIZED_LEARNING" -> 85;
            case "PAYMENT" -> 88;
            case "ERROR_BOOK" -> 70;
            case "STUDY_PLAN" -> 65;
            case "PARENT_CENTER" -> 55;
            default -> 50;
        };
        return moduleWeight;
    }
}
```

## 5. 主题挖掘与趋势分析

### 5.1 主题发现算法

采用**语义聚类 + 关键词共现**双重策略发现新兴主题：

```java
/**
 * 反馈主题自动发现服务
 * 每日定时执行，从最近7天反馈中发现新主题
 */
@Service
public class FeedbackTopicDiscoveryService {

    private static final double SIMILARITY_THRESHOLD = 0.75;
    private static final int MIN_TOPIC_SIZE = 3;  // 至少3条反馈才能形成主题

    /**
     * 主题发现主流程
     */
    public List<FeedbackTopic> discoverTopics(LocalDate date) {
        // 1. 获取近期未归类反馈
        List<FeedbackItem> recentFeedback = feedbackMapper.selectUnassignedRecent(date, 7);

        if (recentFeedback.size() < MIN_TOPIC_SIZE) {
            return Collections.emptyList();
        }

        // 2. 生成语义向量
        Map<Long, float[]> embeddings = batchEmbed(recentFeedback);

        // 3. 语义聚类（DBSCAN）
        List<List<FeedbackItem>> clusters = dbscanCluster(
            recentFeedback, embeddings, SIMILARITY_THRESHOLD, MIN_TOPIC_SIZE
        );

        // 4. 为每个聚类生成主题
        List<FeedbackTopic> newTopics = new ArrayList<>();
        for (List<FeedbackItem> cluster : clusters) {
            FeedbackTopic topic = generateTopic(cluster, embeddings);
            newTopics.add(topic);
        }

        // 5. 与已有主题匹配/合并
        for (FeedbackTopic newTopic : newTopics) {
            Optional<FeedbackTopic> existing = findSimilarExistingTopic(newTopic);
            if (existing.isPresent()) {
                mergeIntoExisting(newTopic, existing.get());
            } else {
                saveNewTopic(newTopic);
            }
        }

        return newTopics;
    }

    /**
     * 为聚类生成主题名称和描述
     */
    private FeedbackTopic generateTopic(List<FeedbackItem> cluster,
                                        Map<Long, float[]> embeddings) {
        // 提取聚类中心
        float[] centroid = calculateCentroid(cluster, embeddings);

        // 关键词频率统计
        Map<String, Integer> keywordFreq = new HashMap<>();
        for (FeedbackItem item : cluster) {
            if (item.getKeywords() != null) {
                for (String kw : item.getKeywords()) {
                    keywordFreq.merge(kw, 1, Integer::sum);
                }
            }
        }

        // 取 Top-5 关键词
        List<String> topKeywords = keywordFreq.entrySet().stream()
            .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
            .limit(5)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());

        // 使用大模型生成主题名称
        String topicName = llmService.generateTopicName(cluster, topKeywords);

        FeedbackTopic topic = new FeedbackTopic();
        topic.setTopicName(topicName);
        topic.setTopicCategory(determineCategory(cluster));
        topic.setKeywords(topKeywords);
        topic.setFeedbackCount(cluster.size());
        topic.setUniqueUserCount((int) cluster.stream()
            .map(FeedbackItem::getUserId).distinct().count());
        topic.setAvgSentimentScore(cluster.stream()
            .mapToDouble(FeedbackItem::getSentimentScore)
            .average().orElse(0));
        topic.setFirstSeenAt(cluster.stream()
            .map(FeedbackItem::getSubmittedAt).min(Comparator.naturalOrder()).orElse(null));
        topic.setLastSeenAt(cluster.stream()
            .map(FeedbackItem::getSubmittedAt).max(Comparator.naturalOrder()).orElse(null));
        return topic;
    }
}
```

```java
 * 主题趋势分析（周环比）
 * 比较本周与上周的反馈量变化

public TrendAnalysisResult analyzeTrend(Long topicId) {
    LocalDateTime now = LocalDateTime.now();
    LocalDateTime weekAgo = now.minusDays(7);
    LocalDateTime twoWeeksAgo = now.minusDays(14);

    int thisWeekCount = feedbackMapper.countByTopicAndDateRange(topicId, weekAgo, now);
    int lastWeekCount = feedbackMapper.countByTopicAndDateRange(topicId, twoWeeksAgo, weekAgo);

    double changeRate = lastWeekCount == 0 ?
        (thisWeekCount > 0 ? 100.0 : 0) :
        ((double)(thisWeekCount - lastWeekCount) / lastWeekCount * 100);

    String direction;
    if (changeRate > 15) direction = "RISING";
    else if (changeRate < -15) direction = "DECLINING";
    else direction = "STABLE";

    return new TrendAnalysisResult(direction, changeRate, thisWeekCount, lastWeekCount);
}
```

```java
    private static final double MIN_PRIORITY_FOR_SUGGESTION = 60.0;

    @Scheduled(cron = "0 0 2 * * MON")  // 每周一凌晨2点
    public void generateWeeklySuggestions() {

            // 4. 构建生成上下文
            SuggestionContext context = SuggestionContext.builder()
                .topic(topic)
                .topFeedbacks(selectRepresentativeFeedback(relatedFeedback, 5))
                .appVersion(getCurrentAppVersion())
                .knownIssues(getKnownIssues(topic.getRelatedModule()))
                .roadmapStage(getCurrentRoadmapStage())
                .build();

            // 5. 调用大模型生成建议

            // 6. 计算综合优先级
            double priorityScore = calculateSuggestionPriority(draft, topic);

            // 7. 保存建议草稿
            FeedbackImprovementSuggestion suggestion = new FeedbackImprovementSuggestion();
            suggestion.setSuggestionUid(IdGenerator.next());
            suggestion.setTopicId(topic.getId());
            suggestion.setFeedbackIds(relatedFeedback.stream()
                .map(FeedbackItem::getId).collect(Collectors.toList()));
            suggestion.setTitle(draft.getTitle());
            suggestion.setDescription(draft.getDescription());
            suggestion.setSuggestionType(draft.getSuggestionType());
            suggestion.setImpactAnalysis(draft.getImpactAnalysis());
            suggestion.setEstimatedEffort(draft.getEstimatedEffort());
            suggestion.setAffectedUserSegments(draft.getAffectedSegments());
            suggestion.setAffectedUserCount(topic.getUniqueUserCount());
            suggestion.setEstimatedImpactScore(calculateImpactScore(topic));
            suggestion.setPriorityScore(priorityScore);
            suggestion.setPriorityFactors(draft.getPriorityFactors());
            suggestion.setStatus("DRAFT");
            suggestionMapper.insert(suggestion);

            log.info("Generated suggestion {} for topic {}",
                suggestion.getSuggestionUid(), topic.getTopicName());
        }
    }

    /**
     * 计算建议综合优先级
     */
    private double calculateSuggestionPriority(SuggestionDraft draft, FeedbackTopic topic) {
        double userVoiceScore = Math.min(100, topic.getFeedbackCount() * 5);
        double businessScore = getModuleBusinessWeight(topic.getRelatedModule());
        double feasibilityScore = parseEffortToScore(draft.getEstimatedEffort());
        double trendBonus = "RISING".equals(topic.getTrendDirection()) ? 10 : 0;

        return 0.35 * userVoiceScore +
               0.30 * businessScore +
               0.25 * feasibilityScore +
               0.10 * (50 + trendBonus);
    }

    private double parseEffortToScore(String effort) {
        return switch (effort) {
            case "XS" -> 95;
            case "S" -> 80;
            case "M" -> 60;
            case "L" -> 40;
            case "XL" -> 20;
            default -> 50;
        };
    }
}
```

```java
                alertService.sendCollectorError(collector.getSourceCode(), e);

        }
```

## 8. 重复反馈检测与合并

### 8.1 语义去重策略

```java
@Service
public class FeedbackDeduplicationService {

    private final EmbeddingService embeddingService;
    private final FeedbackSimilarityRepository similarityRepo;

    private static final double DUPLICATE_THRESHOLD = 0.88;
    private static final int SEARCH_TOP_K = 10;

    /**
     * 检测并标记重复反馈
     */
    public DeduplicationResult checkDuplicate(FeedbackItem newFeedback) {
        // 1. 生成语义向量
        float[] embedding = embeddingService.embed(newFeedback.getContent());

        // 2. pgvector 检索相似反馈
        List<SimilarityMatch> matches = similarityRepo.searchSimilar(
            embedding, SEARCH_TOP_K, DUPLICATE_THRESHOLD
        );

        if (matches.isEmpty()) {
            return DeduplicationResult.unique();
        }

        // 3. 取最相似的反馈
        SimilarityMatch bestMatch = matches.get(0);

        // 4. 额外规则校验（相同模块、时间窗口）
        FeedbackItem existing = feedbackMapper.selectById(bestMatch.getFeedbackId());
        if (isLikelyDuplicate(newFeedback, existing, bestMatch.getScore())) {
            // 标记为重复
            newFeedback.setMergedIntoId(existing.getId());
            newFeedback.setRelatedFeedbackIds(
                appendToArray(existing.getRelatedFeedbackIds(), newFeedback.getId())
            );
            newFeedback.setStatus("DUPLICATE");

            // 更新主反馈的计数
            feedbackMapper.incrementMergeCount(existing.getId());

            return DeduplicationResult.duplicate(existing, bestMatch.getScore());
        }

        // 5. 记录关联但不标记为重复
        newFeedback.setRelatedFeedbackIds(
            matches.stream().map(SimilarityMatch::getFeedbackId).toArray(Long[]::new)
        );
        return DeduplicationResult.related(matches);
    }

    private boolean isLikelyDuplicate(FeedbackItem newItem, FeedbackItem existing, double score) {
        // 向量相似度 > 0.92 → 强匹配
        if (score > 0.92) return true;

        // 相似度 > 0.85 且相同模块且48小时内
        if (score > 0.85 &&
            Objects.equals(newItem.getRelatedModule(), existing.getRelatedModule()) &&
            Duration.between(existing.getSubmittedAt(), newItem.getSubmittedAt()).toHours() < 48) {
            return true;
        }

        return false;
    }
}
```

```java
@Service
public class FeedbackAnalysisOrchestrator {

    /**
     * NLP 分析降级链：
     * 1. 大模型完整分析（首选）
     * 2. 本地 BERT 快速分析（大模型不可用）
     * 3. 关键词规则匹配（全部模型不可用）
     */
    public AnalysisResult analyzeWithFallback(FeedbackItem feedback) {
        try {
            // 策略1：大模型完整分析
            return llmAnalysisService.fullAnalysis(feedback);
        } catch (LLMUnavailableException e) {
            log.warn("LLM unavailable, falling back to local BERT");
            try {
                // 策略2：本地 BERT
                AnalysisResult partial = bertService.classifyAndSentiment(feedback);
                partial.setAnalysisSource("BERT_FALLBACK");
                return partial;
            } catch (Exception e2) {
                log.error("BERT also failed, using rule-based classification");
                // 策略3：规则匹配
                AnalysisResult fallback = ruleBasedClassification(feedback);
                fallback.setAnalysisSource("RULE_FALLBACK");
                fallback.setNeedsReview(true); // 标记需人工复核
                return fallback;
            }
        }
    }

    /**
     * 关键词规则匹配（兜底分类）
     */
    private AnalysisResult ruleBasedClassification(FeedbackItem feedback) {
        String content = feedback.getContent().toLowerCase();
        AnalysisResult result = new AnalysisResult();

        // Bug/Crash 关键词
        if (containsAny(content, "闪退", "崩溃", "crash", "报错", "错误", "白屏", "黑屏")) {
            result.setFeedbackType("BUG_REPORT");
            result.setUrgencyLevel(4);
        }
        // 支付关键词
        else if (containsAny(content, "充值", "扣款", "退款", "支付", "订阅")) {
            result.setFeedbackType("PAYMENT_ISSUE");
            result.setUrgencyLevel(3);
        }
        // 功能建议
        else if (containsAny(content, "建议", "希望", "能不能", "可以增加")) {
            result.setFeedbackType("FEATURE_REQUEST");
            result.setUrgencyLevel(2);
        }
        // 正面评价
        else if (containsAny(content, "好用", "喜欢", "感谢", "棒", "赞", "不错")) {
            result.setFeedbackType("PRAISE");
            result.setSentimentScore(0.7);
        }
        else {
            result.setFeedbackType("OTHER");
        }

        result.setSentimentScore(estimateSentimentByKeywords(content));
        result.setConfidenceScore(0.5); // 低置信度
        return result;
    }
}
```

### 11.1 批量分析优化

```java
/**
 * 反馈批量异步分析
 * 使用线程池并行处理，每批 20 条
 */
@Service
public class BatchAnalysisService {

    private final ExecutorService analysisPool = Executors.newFixedThreadPool(5);
    private final Semaphore llmRateLimiter = new Semaphore(10); // 大模型并发限制

    @Async("analysisTaskExecutor")
    public CompletableFuture<Void> batchAnalyze(List<Long> feedbackIds) {
        List<CompletableFuture<Void>> futures = feedbackIds.stream()
            .collect(Collectors.groupingBy(s -> feedbackIds.indexOf(s) / 20))
            .values().stream()
            .map(batch -> CompletableFuture.runAsync(() -> {
                for (Long id : batch) {
                    try {
                        llmRateLimiter.acquire();
                        FeedbackItem fb = feedbackMapper.selectById(id);
                        AnalysisResult result = analysisOrchestrator.analyzeWithFallback(fb);
                        applyAnalysisResult(fb, result);
                    } catch (Exception e) {
                        log.error("Analysis failed for feedback {}", id, e);
                        markAsAnalysisFailed(id);
                    }
                }
            }, analysisPool))
            .collect(Collectors.toList());

        return CompletableFuture.allOf(
            futures.toArray(new CompletableFuture[0])
        );
    }
}
```

### 12.2 敏感数据处理

```java
@Service
public class FeedbackDataSanitizer {

    /**
     * 反馈内容脱敏（用于对外展示/分析）
     */
    public String sanitizeContent(String content) {
        if (content == null) return null;
        // 手机号脱敏
        content = content.replaceAll("(1[3-9]\\d)\\d{4}(\\d{4})", "$1****$2");
        // 身份证号脱敏
        content = content.replaceAll("(\\d{4})\\d{10}(\\w{4})", "$1**********$2");
        // 邮箱脱敏
        content = content.replaceAll("(\\w{2})\\w+(@\\w+)", "$1***$2");
        return content;
    }

    /**
     * 用户ID脱敏（用于分析数据集导出）
     */
    public String anonymizeUserId(Long userId) {
        if (userId == null) return "ANONYMOUS";
        return "U" + DigestUtils.md5Hex(String.valueOf(userId)).substring(0, 8);
    }
}
```

## 15. 总结

### 15.1 核心设计要点

1. **全渠道聚合**：通过统一的 FeedbackCollector 接口适配多渠道反馈源，支持热插拔
2. **多级 NLP 降级**：大模型 → 本地 BERT → 关键词规则，保证分析服务可用性
3. **语义级去重**：基于 pgvector 向量相似度检测重复反馈，减少人工处理量
4. **主题自动发现**：DBSCAN 聚类 + 大模型命名，自动识别新兴问题
5. **优先级量化**：六因子加权评分模型，让最重要的问题浮出水面
6. **产品改进闭环**：从反馈 → 分析 → 主题 → 建议 → 产品需求 → 用户通知
