# 全学段知识概念演进追踪与跨学段知识体系统一建模引擎 - 详细设计

## 1. 概述

### 1.1 设计目标

PrimeTop 的核心差异化竞争力是"全学段覆盖"。为使这一承诺落地，需要一套底层引擎，将分散在不同学段、不同教材中的同一知识概念（如"分数→有理数→实数"）建立统一的演进追踪模型，使系统能够：

1. **识别跨学段概念关联**：知道小学三年级的"初步认识分数"和初一的"有理数"和高一的"实数系"是同一条概念演进路径上的节点。
2. **支持螺旋式学习**：当高一学生在"实数运算"上出错时，能追溯到他小学阶段"分数"知识点的薄弱根源。
3. **跨学段知识迁移**：学生升学时，将旧学段的能力评估平滑映射到新学段的知识体系中。
4. **衔接诊断**：在学段衔接期（小升初、初升高）精准识别哪些概念需要补强。

### 1.2 与现有系统的关系

| 现有系统 | 关系 |
| --- | --- |
| `知识点体系与教材映射引擎` | 该引擎处理单教材版本内的知识点↔章节映射；本引擎在其之上构建跨学段的概念演进关系 |
| `教育知识点前置依赖检测与学习路径推荐服务` | 前置依赖处理同一学段内的先修关系；本引擎扩展到跨学段的纵向依赖 |
| `学段衔接知识桥梁课程与过渡期学习指导引擎` | 衔接课程是"内容层"的解决方案；本引擎是"知识模型层"的基础设施 |
| `用户年级升迁与学段转换服务` | 年级升迁处理用户状态切换；本引擎为升迁时的能力评估迁移提供知识模型支撑 |
| `教材版本间知识点映射与学生进度迁移引擎` | 处理同一学段不同教材版本间的映射；本引擎处理不同学段间的概念映射 |

### 1.3 设计原则

- **概念为中心**：以"知识概念"（Concept）为最小建模单位，而非具体教材的"知识点"（KnowledgePoint），一个概念在不同学段有不同表现形式
- **演进路径**：每个概念有一条或多条从低学段到高学段的演进路径
- **能力映射**：同一概念在不同学段的能力评估可以相互映射
- **向后兼容**：不改变现有知识点系统的数据结构，通过映射层建立关联

## 2. 核心领域模型

### 2.1 概念模型层级

```
ConceptDomain（学科领域）
  └── ConceptCluster（概念簇）
       └── Concept（核心概念）
            └── ConceptStage（学段表现型）
                 └── MappedKnowledgePoint（映射知识点）
```

**示例：**

```
ConceptDomain: 数学
  └── ConceptCluster: 数与代数
       └── Concept: 分数/有理数/实数
            ├── ConceptStage: 小学三年级 - "分数的初步认识"
            │    └── MappedKnowledgePoint: 人教版三上第8单元-KP_00321
            ├── ConceptStage: 小学五年级 - "分数的意义和性质"
            │    └── MappedKnowledgePoint: 人教版五下第4单元-KP_00782
            ├── ConceptStage: 小学六年级 - "分数四则混合运算"
            │    └── MappedKnowledgePoint: 人教版六上第3单元-KP_00954
            ├── ConceptStage: 初一 - "有理数及其运算"
            │    └── MappedKnowledgePoint: 人教版七上第1章-KP_01203
            └── ConceptStage: 高一 - "实数系与集合"
                 └── MappedKnowledgePoint: 人教版必修1第1章-KP_01877
```

```sql
    relation_strength   DECIMAL(3,2) DEFAULT 1.00 COMMENT '关联强度 0.00-1.00',

    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
```

**relation_type 说明：**

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| `EVOLVES_INTO` | A 演进为 B（纵向发展） | "分数"概念演进为"有理数"概念 |
| `PREREQUISITE` | A 是 B 的前置（横向依赖） | "方程"是"函数"的前置概念 |
| `CORELATED` | 相关协同（交叉应用） | "比例"与"相似三角形" |
| `PART_OF` | A 是 B 的组成部分 | "因式分解"是"代数变形"的一部分 |
| `APPLIED_IN` | A 应用于 B 的场景 | "向量"应用于"物理力学" |

## 3. 概念演进路径模型

### 3.1 演进路径类型

#### 3.1.1 线性演进（Linear Evolution）

最常见类型：一个概念在不同学段以递进方式深化。

```
小学三年级(认识分数) → 小学五年级(分数性质) → 小学六年级(分数运算) → 初一(有理数) → 高一(实数系)
```

#### 3.1.2 分支演进（Branching Evolution）

一个基础概念在更高学段分裂为多个独立但相关的概念。

```
初中"力的概念"
  ├── 高中"牛顿力学"（力学方向）
  ├── 高中"电磁学"（电磁方向）
  └── 高中"波动"（声光方向）
```

#### 3.1.3 汇合演进（Converging Evolution）

多个基础概念在更高学段合并为一个综合概念。

```
小学"整数运算"  ─┐
                 ├──→ 初中"代数式运算"
小学"字母表示数" ─┘
```

#### 3.1.4 螺旋演进（Spiral Evolution）

同一概念在不同学段反复出现，每次深度递增。

```
小学: "数据的收集与整理（简单统计图）"
  → 初中: "统计与概率（描述性统计）"
    → 高中: "概率与统计（推断性统计、假设检验）"
```

### 3.2 演进路径数据结构

```java
/**
 * 概念演进路径
 */
@Data
public class ConceptEvolutionPath {
    private Long conceptId;
    private String conceptName;
    private String pathType;  // LINEAR / BRANCHING / CONVERGING / SPIRAL
    
    /** 路径上的节点（按sort_order排序） */
    private List<EvolutionNode> nodes;
    
    /** 分支信息（仅BRANCHING类型） */
    private List<EvolutionBranch> branches;
    
    /** 路径元信息 */
    private PathMetadata metadata;
}

@Data
public class EvolutionNode {
    private Long stageId;
    private String stageCode;        // PRIMARY / JUNIOR / SENIOR
    private Integer gradeLevel;      // 1-12
    private String stageName;        // "分数的初步认识"
    private String cognitiveDepth;   // REMEMBER / UNDERSTAND / APPLY / ...
    private Integer abstractionLevel; // 1-5
    
    /** 映射的知识点（按教材版本分组） */
    private Map<String, List<KnowledgePointRef>> textbookMappings;
    
    /** 节点描述 */
    private String description;
    
    /** 预期掌握度（该学段标准要求） */
    private BigDecimal expectedMastery;
}

@Data
public class EvolutionBranch {
    private Long fromNodeId;         // 分支起点节点
    private List<EvolutionPath> branches; // 分支路径
}
```

```java
/**
 * 跨学段概念演进服务

@Service
@Slf4j
public class ConceptEvolutionService {

    @Autowired
    private ConceptRepository conceptRepo;
    @Autowired
    private ConceptStageRepository stageRepo;
    @Autowired
    private ConceptStageKpMappingRepository kpMappingRepo;
    @Autowired
    private StudentConceptMasteryRepository masteryRepo;
    @Autowired
    private KnowledgePointService kpService;
    @Autowired
    private MasteryEstimationEngine masteryEngine;
    @Autowired
    private StageTransitionConfig transitionConfig;

    /**
     * 获取概念的完整演进路径（含学生掌握度）
     */
    @Cacheable(value = "evolution_path", key = "#conceptId + '_' + #studentId + '_' + #textbookVersion")
    public ConceptEvolutionPath getEvolutionPath(Long conceptId, Long studentId, String textbookVersion) {
        // 1. 获取概念基本信息
        Concept concept = conceptRepo.findById(conceptId)
            .orElseThrow(() -> new BusinessException(ErrorCode.CONCEPT_NOT_FOUND, conceptId));

        // 2. 获取所有学段表现型（按年级排序）
        List<ConceptStage> stages = stageRepo.findByConceptIdOrderBySortOrder(conceptId);
        if (stages.isEmpty()) {
            return ConceptEvolutionPath.empty(concept);
        }

        // 3. 构建演进节点
        List<EvolutionNode> nodes = stages.stream()
            .map(stage -> buildEvolutionNode(stage, textbookVersion, studentId))
            .collect(Collectors.toList());

        // 4. 确定路径类型
        String pathType = determinePathType(stages);

        // 5. 如果有学生ID，填充诊断信息
        EvolutionDiagnosis diagnosis = null;
        if (studentId != null) {
            diagnosis = buildDiagnosis(conceptId, studentId, nodes);
        }

        return ConceptEvolutionPath.builder()
            .conceptId(conceptId)
            .conceptName(concept.getName())
            .pathType(pathType)
            .nodes(nodes)
            .diagnosis(diagnosis)
            .metadata(buildPathMetadata(stages))
            .build();
    }

    /**
     * 构建演进节点（含学生掌握度）
     */
    private EvolutionNode buildEvolutionNode(ConceptStage stage, String textbookVersion, Long studentId) {
        EvolutionNode node = EvolutionNode.from(stage);
        
        // 填充教材知识点映射
        List<ConceptStageKpMapping> mappings = kpMappingRepo
            .findByStageIdAndTextbook(stage.getId(), textbookVersion);
        Map<String, List<KnowledgePointRef>> tbMappings = mappings.stream()
            .collect(Collectors.groupingBy(
                ConceptStageKpMapping::getTextbookVersion,
                Collectors.mapping(KnowledgePointRef::from, Collectors.toList())
            ));
        node.setTextbookMappings(tbMappings);

        // 填充学生掌握度
        if (studentId != null) {
            Optional<StudentConceptMastery> mastery = masteryRepo
                .findByStudentIdAndConceptId(studentId, stage.getConceptId());
            
            if (mastery.isPresent()) {
                // 直接获取该stage的掌握度
                BigDecimal stageMastery = extractStageMastery(mastery.get(), stage.getId());
                node.setStudentMastery(stageMastery);
                node.setMasteryLevel(mapMasteryLevel(stageMastery));
            } else {
                // 无直接数据时，通过映射的知识点推断
                BigDecimal inferredMastery = masteryEngine.inferStageMastery(
                    studentId, stage.getId(), textbookVersion
                );
                node.setStudentMastery(inferredMastery);
                node.setMasteryLevel(mapMasteryLevel(inferredMastery));
                node.setInferred(true);
            }
        }

        return node;
    }

    /**
     * 跨学段掌握度迁移
     */
    @Transactional(rollbackFor = Exception.class)
    public CrossStageTransferResult transferMastery(Long studentId, 
                                                     String fromStage, 
                                                     String toStage,
                                                     String textbookVersion) {
        log.info("开始跨学段掌握度迁移: studentId={}, from={}, to={}", 
            studentId, fromStage, toStage);

        // 1. 获取学生当前学段相关的所有概念
        List<StudentConceptMastery> currentMasteries = masteryRepo
            .findByStudentIdAndStageRange(studentId, fromStage);

        // 2. 获取目标学段涉及的概念
        List<Concept> targetConcepts = conceptRepo
            .findConceptsByStageCode(toStage);

        // 3. 逐概念进行掌握度映射
        List<ConceptTransferDetail> details = new ArrayList<>();
        for (Concept targetConcept : targetConcepts) {
            // 找到该概念在源学段和目标学段的stage
            Optional<ConceptStage> sourceStage = stageRepo
                .findByConceptIdAndStageCode(targetConcept.getId(), fromStage);
            Optional<ConceptStage> destStage = stageRepo
                .findByConceptIdAndStageCode(targetConcept.getId(), toStage);

            if (sourceStage.isPresent() && destStage.isPresent()) {
                // 计算迁移掌握度
                BigDecimal sourceMastery = getOrInferMastery(studentId, targetConcept.getId(), sourceStage.get());
                BigDecimal transferredMastery = calculateTransferMastery(
                    sourceMastery, sourceStage.get(), destStage.get()
                );
                
                details.add(new ConceptTransferDetail(
                    targetConcept.getId(),
                    targetConcept.getName(),
                    sourceMastery,
                    transferredMastery,
                    calculateTransferConfidence(sourceStage.get(), destStage.get()),
                    determineTransferStatus(transferredMastery)
                ));
            } else if (destStage.isPresent() && sourceStage.isEmpty()) {
                // 目标学段有此概念，但源学段没有 → 新概念
                details.add(ConceptTransferDetail.newConcept(targetConcept));
            }
        }

        // 4. 持久化迁移结果
        persistTransferResults(studentId, details);

        // 5. 生成推荐动作
        List<RecommendedAction> actions = generateRecommendedActions(details);

        return CrossStageTransferResult.builder()
            .transferId(generateTransferId())
            .studentId(studentId)
            .totalConcepts(targetConcepts.size())
            .transferredConcepts((int) details.stream().filter(d -> d.getStatus() == TransferStatus.TRANSFERRED).count())
            .newConcepts((int) details.stream().filter(d -> d.getStatus() == TransferStatus.NEW).count())
            .weakConcepts((int) details.stream().filter(d -> d.getStatus() == TransferStatus.WEAK_TRANSFER).count())
            .details(details)
            .recommendedActions(actions)
            .build();
    }

    /**
     * 计算迁移掌握度
     * 
     * 核心算法：源学段掌握度 × 认知跨度系数 × 内容重合度系数
     */
    private BigDecimal calculateTransferMastery(BigDecimal sourceMastery, 
                                                  ConceptStage sourceStage,
                                                  ConceptStage destStage) {
        // 认知跨度系数：基于布鲁姆层级差异和抽象程度差异
        double cognitiveSpanFactor = calculateCognitiveSpanFactor(
            sourceStage.getCognitiveDepth(), destStage.getCognitiveDepth(),
            sourceStage.getAbstractionLevel(), destStage.getAbstractionLevel()
        );

        // 内容重合度系数：基于知识点映射的重合程度
        double contentOverlapFactor = calculateContentOverlap(sourceStage, destStage);

        // 学段跨度惩罚：跨学段（如小→初）比同学段内升级惩罚更大
        double stageSpanPenalty = transitionConfig
            .getStageSpanPenalty(sourceStage.getStageCode(), destStage.getStageCode());

        double transferMultiplier = cognitiveSpanFactor * contentOverlapFactor * stageSpanPenalty;
        double transferredMastery = sourceMastery.doubleValue() * transferMultiplier;

        // 迁移后的掌握度不会超过源掌握度
        return BigDecimal.valueOf(Math.min(transferredMastery, sourceMastery.doubleValue()))
            .setScale(2, RoundingMode.HALF_UP);
    }

    /**
     * 认知跨度系数计算
     */
    private double calculateCognitiveSpanFactor(String fromDepth, String toDepth,
                                                 int fromAbstraction, int toAbstraction) {
        // 布鲁姆层级差
        int bloomDiff = BloomTaxonomy.levelDifference(fromDepth, toDepth);
        double bloomFactor = 1.0 - (bloomDiff * 0.08); // 每差一级衰减8%

        // 抽象程度差
        int abstractionDiff = toAbstraction - fromAbstraction;
        double abstractionFactor = 1.0 - (abstractionDiff * 0.06); // 每差一级衰减6%

        return Math.max(0.3, bloomFactor * abstractionFactor); // 最低0.3
    }

    /**
     * 薄弱概念跨学段追溯
     */
    public RetrospectiveDiagnosis retrospectiveDiagnose(Long studentId, 
                                                         Long conceptId,
                                                         Long currentStageId,
                                                         RetrospectiveDepth depth) {
        // 1. 获取当前节点的掌握度
        StudentConceptMastery currentMastery = masteryRepo
            .findByStudentIdAndConceptId(studentId, conceptId)
            .orElseThrow(() -> new BusinessException(ErrorCode.MASTERY_NOT_FOUND));

        // 2. 沿演进路径向前回溯
        List<ConceptStage> allStages = stageRepo
            .findByConceptIdOrderBySortOrder(conceptId);
        
        int currentIndex = findStageIndex(allStages, currentStageId);
        List<RetrospectiveNode> chain = new ArrayList<>();

        // 回溯深度控制
        int lookBack = depth == RetrospectiveDepth.FULL ? 0 : 
                       depth == RetrospectiveDepth.ONE_STEP ? currentIndex - 1 :
                       Math.max(0, currentIndex - 2);

        for (int i = currentIndex - 1; i >= lookBack; i--) {
            ConceptStage stage = allStages.get(i);
            BigDecimal stageMastery = extractStageMastery(currentMastery, stage.getId());
            
            // 如果没有直接数据，通过推断获取
            if (stageMastery == null) {
                stageMastery = masteryEngine.inferStageMastery(studentId, stage.getId(), 
                    kpMappingRepo.findPrimaryTextbookByStageId(stage.getId()));
            }

            BigDecimal expectedMastery = stage.getExpectedMastery();
            BigDecimal gap = expectedMastery.subtract(stageMastery);

            RetrospectiveNode node = RetrospectiveNode.builder()
                .stageId(stage.getId())
                .stageName(stage.getStageName())
                .gradeLevel(stage.getGradeLevel())
                .mastery(stageMastery)
                .masteryLevel(mapMasteryLevel(stageMastery))
                .gapFromExpected(gap.doubleValue())
                .build();

            chain.add(node);
        }

        // 3. 定位根因节点
        RetrospectiveNode rootCause = identifyRootCause(chain);
        
        // 4. 生成根因分析
        if (rootCause != null) {
            rootCause.setIsRootCause(true);
            rootCause.setRootCauseAnalysis(generateRootCauseAnalysis(studentId, rootCause));
            rootCause.setRecommendedReviewKPs(getWeakSubKPs(studentId, rootCause.getStageId()));
        }

        // 5. 生成总结
        RetrospectiveSummary summary = RetrospectiveSummary.builder()
            .rootCauseStageId(rootCause != null ? rootCause.getStageId() : null)
            .rootCauseStageName(rootCause != null ? rootCause.getStageName() : null)
            .chainLength(chain.size())
            .recommendedPlan(generateRecommendedPlan(rootCause))
            .build();

        return RetrospectiveDiagnosis.builder()
            .conceptId(conceptId)
            .currentStage(RetrospectiveNode.fromCurrent(currentMastery, currentStageId))
            .retrospectiveChain(chain)
            .summary(summary)
            .build();
    }

    /**
     * 根因节点识别算法
     * 
     * 策略：找到第一个"掌握度缺口明显增大"的节点
     * 判定标准：gap > 15 且 mastery < 70
     */
    private RetrospectiveNode identifyRootCause(List<RetrospectiveNode> chain) {
        // 从最远端向当前方向搜索，找到第一个严重缺口
        for (int i = chain.size() - 1; i >= 0; i--) {
            RetrospectiveNode node = chain.get(i);
            if (node.getGapFromExpected() > 15.0 && node.getMastery().doubleValue() < 70.0) {
                return node;
            }
        }
        // 如果没有明显的根因，取最薄弱的节点
        return chain.stream()
            .min(Comparator.comparing(RetrospectiveNode::getMastery))
            .orElse(null);
    }
}
```

### 5.2 掌握度推断引擎

```java
/**
 * 学段表现型掌握度推断引擎
 */
@Service
public class MasteryEstimationEngine {

    @Autowired
    private AnswerRecordService answerRecordService;
    @Autowired
    private ConceptStageKpMappingRepository kpMappingRepo;

    /**
     * 通过映射的知识点推断某个学段表现型的掌握度
     * 
     * @param studentId 学生ID
     * @param stageId   学段表现型ID
     * @param textbookVersion 教材版本
     * @return 推断的掌握度 (0-100)
     */
    public BigDecimal inferStageMastery(Long studentId, Long stageId, String textbookVersion) {
        // 1. 获取该stage映射的所有知识点
        List<ConceptStageKpMapping> mappings = kpMappingRepo
            .findByStageIdAndTextbook(stageId, textbookVersion);

        if (mappings.isEmpty()) {
            return BigDecimal.valueOf(50.0); // 无映射数据时返回中等默认值
        }

        // 2. 按映射类型分组计算
        List<BigDecimal> directMasteries = new ArrayList<>();
        List<BigDecimal> correlatedMasteries = new ArrayList<>();

        for (ConceptStageKpMapping mapping : mappings) {
            BigDecimal kpMastery = answerRecordService
                .calculateKPMastery(studentId, mapping.getKnowledgePointId());

            if (kpMastery != null) {
                if (mapping.getMappingType().equals("DIRECT")) {
                    directMasteries.add(kpMastery.multiply(
                        BigDecimal.valueOf(mapping.getMappingConfidence())));
                } else {
                    correlatedMasteries.add(kpMastery.multiply(
                        BigDecimal.valueOf(mapping.getMappingConfidence() * 0.7)));
                }
            }
        }

        // 3. 加权平均
        if (!directMasteries.isEmpty()) {
            BigDecimal avg = directMasteries.stream()
                .reduce(BigDecimal.ZERO, BigDecimal::add)
                .divide(BigDecimal.valueOf(directMasteries.size()), 2, RoundingMode.HALF_UP);
            
            if (!correlatedMasteries.isEmpty()) {
                BigDecimal corrAvg = correlatedMasteries.stream()
                    .reduce(BigDecimal.ZERO, BigDecimal::add)
                    .divide(BigDecimal.valueOf(correlatedMasteries.size()), 2, RoundingMode.HALF_UP);
                // 主映射权重0.7，关联映射权重0.3
                return avg.multiply(BigDecimal.valueOf(0.7))
                    .add(corrAvg.multiply(BigDecimal.valueOf(0.3)))
                    .setScale(2, RoundingMode.HALF_UP);
            }
            return avg;
        }

        // 4. 完全无数据，基于该学生的整体学科平均推断
        return answerRecordService.getSubjectAverageMastery(studentId, stageId);
    }
}
```

```java
public enum BloomTaxonomy {
    REMEMBER(1),     // 记忆
    UNDERSTAND(2),   // 理解
    APPLY(3),        // 运用
    ANALYZE(4),      // 分析
    EVALUATE(5),     // 评价
    CREATE(6);       // 创造

    private final int level;

    BloomTaxonomy(int level) { this.level = level; }

    public static int levelDifference(String from, String to) {
        BloomTaxonomy fromB = BloomTaxonomy.valueOf(from);
        BloomTaxonomy toB = BloomTaxonomy.valueOf(to);
        return Math.abs(toB.level - fromB.level);
    }

    public static int getLevel(String name) {
        return BloomTaxonomy.valueOf(name).level;
    }
}
```

## 6. 跨学段迁移算法详细设计

### 6.1 迁移系数矩阵

不同学段间的迁移存在不同的"认知距离"，系统使用预配置的迁移系数矩阵来建模。

```yaml
# stage-transition-config.yml
stageSpanPenalty:
  PRIMARY__PRIMARY: 0.95    # 小学内升级，几乎无损
  PRIMARY__JUNIOR: 0.75     # 小升初，有较大认知跨度
  JUNIOR__JUNIOR: 0.92      # 初中内升级
  JUNIOR__SENIOR: 0.70      # 初升高，认知跨度最大
  SENIOR__SENIOR: 0.90      # 高中内升级

cognitiveDepthFactor:
  # 目标层级比源层级高的衰减系数
  SAME: 1.0
  ONE_LEVEL_UP: 0.92
  TWO_LEVELS_UP: 0.80
  THREE_LEVELS_UP: 0.65

abstractionGapFactor:
  # 抽象度差异对应的系数
  0: 1.00
  1: 0.94
  2: 0.85
  3: 0.72
  4: 0.60

# 各学科的特殊迁移规则
subjectOverrides:
  MATH:
    PRIMARY__JUNIOR: 0.72    # 数学小升初跨度特别大
    JUNIOR__SENIOR: 0.65     # 数学初升高跨度大
  CHINESE:
    PRIMARY__JUNIOR: 0.82    # 语文跨度相对较小
  ENGLISH:
    PRIMARY__JUNIOR: 0.85    # 英语连续性较强
    JUNIOR__SENIOR: 0.80
  PHYSICS:
    JUNIOR__SENIOR: 0.68     # 物理初升高跨度大
```

### 6.2 迁移算法完整公式

```
transferredMastery = sourceMastery × stageSpanPenalty × cognitiveDepthFactor × abstractionGapFactor × contentOverlapFactor
```

其中：

```
contentOverlapFactor = (共享核心知识点数 / 目标学段总知识点数) × 0.6 
                     + 0.4  (基础保底系数)
```

**边界处理：**
- `transferredMastery` 上限 = `sourceMastery`（不会因为迁移变高）
- `transferredMastery` 下限 = `max(0, sourceMastery - 40)`（不会衰减超过40分）
- 如果 `sourceMastery < 30`，直接以 `sourceMastery × 0.8` 迁移（严重薄弱时简化处理）

```java
public class StageTransitionDiagnosisService {

    public StageTransitionDiagnosis diagnose(Long studentId, 
                                              String transitionType,
                                              String textbookVersion) {
        String[] parts = transitionType.split("_TO_");
        String fromStage = parts[0];  // PRIMARY
        String toStage = parts[1];    // JUNIOR

        // 1. 获取目标学段所有概念簇

            .findByDomainStageCode(toStage);

        List<ConceptReadiness> allConcepts = new ArrayList<>();

                    .getEvolutionPath(concept.getId(), studentId, textbookVersion);

            clusterAnalyses.add(new ClusterAnalysis(cluster.getClusterName(), clusterConcepts));
        }

        // 3. 计算总体就绪度
        BigDecimal overallReadiness = allConcepts.stream()
            .map(ConceptReadiness::getReadiness)
            .reduce(BigDecimal.ZERO, BigDecimal::add)
            .divide(BigDecimal.valueOf(allConcepts.size()), 2, RoundingMode.HALF_UP);

        // 4. 识别优先补强概念
        List<ConceptReadiness> topPriority = allConcepts.stream()
            .filter(c -> c.getReadiness().doubleValue() < 50.0)
            .sorted(Comparator.comparing(ConceptReadiness::getReadiness))
            .limit(5)
            .collect(Collectors.toList());

        // 5. 匹配推荐衔接课程
        List<String> bridgeCourseIds = bridgeCourseService
            .recommendBridgeCourses(studentId, transitionType, topPriority);

        // 6. 估算衔接学习时长
        String estimatedDuration = estimateBridgeDuration(topPriority);

        return StageTransitionDiagnosis.builder()
            .studentId(studentId)
            .transitionType(transitionType)
            .overallReadiness(overallReadiness)
            .readinessLevel(mapReadinessLevel(overallReadiness))
            .conceptAnalysis(clusterAnalyses)
            .topPriorityConcepts(topPriority)
            .recommendedBridgeCourseIds(bridgeCourseIds)
            .estimatedBridgeDuration(estimatedDuration)
            .build();
    }

    /**
     * 就绪度计算
     * 
     * 就绪度 = 源学段掌握度 × 迁移系数
     * 如果源学段无数据，就绪度 = 50（中等默认值）
     */
    private BigDecimal calculateReadiness(ConceptEvolutionPath path, 
                                           String fromStage, String toStage) {
        Optional<EvolutionNode> sourceNode = path.getNodes().stream()
            .filter(n -> n.getStageCode().equals(fromStage))
            .reduce((first, second) -> second); // 取最高年级的源学段节点
        
        Optional<EvolutionNode> targetNode = path.getNodes().stream()
            .filter(n -> n.getStageCode().equals(toStage))
            .findFirst();

        if (sourceNode.isEmpty() || targetNode.isEmpty()) {
            return BigDecimal.valueOf(50.0); // 无演进关系
        }

        BigDecimal sourceMastery = sourceNode.get().getStudentMastery();
        if (sourceMastery == null) {
            return BigDecimal.valueOf(50.0); // 无学习数据
        }

        // 使用迁移系数计算
        return evolutionService.calculateTransferMastery(
            sourceMastery,
            fromStage, sourceNode.get().getGradeLevel(),
            toStage, targetNode.get().getGradeLevel()
        );
    }
}
```

## 8. 事件驱动更新机制

### 8.1 掌握度更新事件流

当学生在某个知识点上有了新的答题记录后，需要级联更新相关概念的跨学段掌握度。

```java
/**
 * 跨学段掌握度事件监听器
 */
@Component
@Slf4j
public class CrossStageMasteryEventListener {

    @Autowired
    private StudentConceptMasteryRepository masteryRepo;
    @Autowired
    private ConceptStageKpMappingRepository kpMappingRepo;
    @Autowired
    private MasteryEstimationEngine masteryEngine;

    /**
     * 监听答题完成事件，触发跨学段掌握度增量更新
     */
    @EventListener
    @Async("masteryUpdateExecutor")
    public void onAnswerRecorded(AnswerRecordedEvent event) {
        Long studentId = event.getStudentId();
        Long kpId = event.getKnowledgePointId();

        // 1. 找到该知识点映射到的所有概念学段表现型
        List<ConceptStageKpMapping> mappings = kpMappingRepo
            .findByKnowledgePointId(kpId);

        for (ConceptStageKpMapping mapping : mappings) {
            Long conceptId = mapping.getConceptId();
            Long stageId = mapping.getConceptStageId();

            try {
                // 2. 重新推断该学段表现型的掌握度
                BigDecimal newMastery = masteryEngine.inferStageMastery(
                    studentId, stageId, mapping.getTextbookVersion()
                );

                // 3. 更新学生概念掌握度
                updateStudentConceptMastery(studentId, conceptId, stageId, newMastery);

                // 4. 检查是否需要触发弱项预警
                if (newMastery.doubleValue() < 40.0) {
                    eventBus.publish(new ConceptWeaknessDetectedEvent(
                        studentId, conceptId, stageId, newMastery.doubleValue()
                    ));
                }

                // 5. 如果该节点在演进路径上，级联影响后续学段的基线预测
                cascadeForwardImpact(studentId, conceptId, stageId, newMastery);

            } catch (Exception e) {
                log.error("掌握度级联更新失败: student={}, concept={}, stage={}", 
                    studentId, conceptId, stageId, e);
            }
        }
    }

    /**
     * 向前级联影响：当前学段掌握度变化，影响后续学段的预期基线
     */
    private void cascadeForwardImpact(Long studentId, Long conceptId, 
                                       Long sourceStageId, BigDecimal newMastery) {
        // 获取该概念在当前stage之后的所有stage
        List<ConceptStage> futureStages = stageRepo
            .findStagesAfter(conceptId, sourceStageId);

        for (ConceptStage futureStage : futureStages) {
            // 计算该futureStage的预测掌握度
            BigDecimal predictedMastery = evolutionService
                .calculateTransferMastery(newMastery, 
                    sourceStageId, futureStage.getId());

            // 更新预测掌握度（标记为推断值）
            masteryRepo.updatePredictedMastery(
                studentId, conceptId, futureStage.getId(), 
                predictedMastery, "FORWARD_INFERENCE"
            );
        }
    }
}
```

```java
/**
 * 概念模型数据校验器
 */
@Component
public class ConceptModelValidator {

    /**
     * 校验演进路径完整性
     */
    public ValidationResult validateEvolutionPath(Long conceptId) {
        List<ConceptStage> stages = stageRepo.findByConceptIdOrderBySortOrder(conceptId);
        List<String> errors = new ArrayList<>();

        // 1. 至少要有2个stage才有演进意义
        if (stages.size() < 2) {
            errors.add("概念[" + conceptId + "]的学段表现型不足2个，无法形成演进路径");
        }

        // 2. 年级必须递增
        for (int i = 1; i < stages.size(); i++) {
            int prevGrade = stages.get(i - 1).getStageCode().equals("KINDERGARTEN") ? 0 
                : stages.get(i - 1).getGradeLevel();
            int currGrade = stages.get(i).getStageCode().equals("KINDERGARTEN") ? 0 
                : stages.get(i).getGradeLevel();
            if (currGrade <= prevGrade) {
                errors.add("学段表现型年级未递增: " + prevGrade + " → " + currGrade);
            }
        }

        // 3. 每个stage至少要有一个primary映射
        for (ConceptStage stage : stages) {
            boolean hasPrimaryMapping = kpMappingRepo
                .existsPrimaryMapping(stage.getId());
            if (!hasPrimaryMapping) {
                errors.add("学段表现型[" + stage.getId() + "]缺少主知识点映射");
            }
        }

        // 4. 抽象程度必须递增或持平
        for (int i = 1; i < stages.size(); i++) {
            if (stages.get(i).getAbstractionLevel() < stages.get(i - 1).getAbstractionLevel()) {
                errors.add("抽象程度不应倒退: " + 
                    stages.get(i - 1).getAbstractionLevel() + " → " + 
                    stages.get(i).getAbstractionLevel());
            }
        }

        return new ValidationResult(errors.isEmpty(), errors);
    }

    /**
     * 校验映射唯一性
     */
    public ValidationResult validateMappingUniqueness(Long stageId) {
        List<ConceptStageKpMapping> mappings = kpMappingRepo.findByStageId(stageId);
        long primaryCount = mappings.stream()
            .filter(m -> m.getIsPrimary() == 1)
            .count();
        
        if (primaryCount > 1) {
            return ValidationResult.fail("学段表现型[" + stageId + "]有多个主映射，每个教材版本只能有一个");
        }
        return ValidationResult.ok();
    }
}
```

## 14. 性能考量

### 14.1 数据量预估

| 数据表 | 预估行数（全量） | 说明 |
| --- | --- | --- |
| `concept_domain` | ~10 | 学科数量 |
| `concept_cluster` | ~100 | 学科内大类 |
| `concept` | ~2,000 | K-12全学段核心概念 |
| `concept_stage` | ~8,000 | 平均每个概念4个学段表现型 |
| `concept_stage_kp_mapping` | ~24,000 | 平均每个stage映射3个知识点，覆盖多教材版本 |
| `student_concept_mastery` | ~200万/100万用户 | 平均每个学生涉及约200个概念 |
| `concept_relation` | ~5,000 | 概念间关联关系 |

### 14.2 查询性能优化

1. **演进路径查询**：单概念查询走 `idx_concept` 索引，预期 <5ms
2. **掌握度推断**：需要查多个知识点的最近答题记录，预期 <50ms（走Redis缓存）
3. **衔接诊断报告**：需遍历目标学段所有概念（约200个），预期 <2s（并行化后 <500ms）
4. **跨学段迁移**：需遍历目标学段所有概念并计算，预期 <3s（批量异步写入）
5. **追溯诊断**：单概念回溯，路径长度一般3-5个节点，预期 <100ms

### 14.3 分库分表策略

`student_concept_mastery` 表在用户量超过100万后需要考虑分表：

- **分表键**：`student_id`
- **分表策略**：按 `student_id % 16` 分16张表
- **查询适配**：所有查询都带有 `student_id`，不需要跨表查询
