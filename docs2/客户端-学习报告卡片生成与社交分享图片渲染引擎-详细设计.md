# 客户端-学习报告卡片生成与社交分享图片渲染引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

将用户学习数据（周报/月报、成就解锁、考试结果、知识掌握度等）渲染为精美的社交分享图片卡片，支持一键分享至微信好友/朋友圈、QQ、微博等第三方平台，驱动社交裂变传播。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 视觉吸引力 | 卡片设计精美，体现品牌调性，激发用户分享欲望 |
| 性能优先 | 卡片生成耗时 < 500ms，不阻塞主线程 |
| 模板灵活 | 运营可后台配置卡片模板，客户端动态渲染 |
| 多端适配 | 输出图片适配不同社交平台尺寸要求 |
| 数据安全 | 分享卡片不泄露敏感个人信息，仅展示脱敏统计数据 |

### 1.3 使用场景

| 场景 | 触发入口 | 卡片类型 |
|------|----------|----------|
| 学习周报/月报 | 学情报告页 -> 分享按钮 | `weekly_report` / `monthly_report` |
| 成就解锁 | 成就弹窗 -> 分享按钮 | `achievement_unlock` |
| 单科掌握度雷达图 | 学情分析页 -> 分享按钮 | `subject_radar` |
| 考试/练习结果 | 考试结果页 -> 分享按钮 | `exam_result` |
| 学习打卡 | 打卡成功弹窗 -> 分享按钮 | `check_in` |
| 知识点突破 | 知识点掌握度提升通知 -> 分享 | `knowledge_breakthrough` |
| 年度学习回顾 | 年度报告页 -> 分享按钮 | `annual_review` |
| 学习挑战赛排名 | 排行榜 -> 分享按钮 | `challenge_rank` |

模板缓存策略：
- 本地内置默认模板作为兜底
- 服务端下发模板覆盖本地缓存，优先使用服务端模板
- 模板带有 `version` 字段，客户端定期检查版本

- 支持运营后台实时更新模板，通过 WebSocket 推送模板更新通知

## 5. 渲染引擎详细设计

### 5.1 渲染流程

```
ShareCardRequest
       │
       ▼
┌─ ShareCardManager.generate() ──────────────────┐
│  1. 根据 cardType 获取 CardTemplate             │
│  2. 根据 platform 确定输出尺寸                   │
│  3. 校验 payload 数据完整性                      │
│  4. 调用 CardRenderEngine.render()              │
│  5. 生成缩略图                                  │
│  6. 保存临时文件                                 │
│  7. 构建 ShareCardResult                        │
└────────────────────────────────────────────────┘
       │
       ▼
┌─ CardRenderEngine.render() ────────────────────┐
│  1. TemplateParser.parse(json) → NodeTree       │
│  2. DataBinder.bind(tree, payload) → 解析表达式  │
│  3. ConditionEvaluator.filter(tree) → 过滤条件节点│
│  4. LayoutEngine.layout(tree, canvasSize)        │
│  5. 创建 Canvas (ui.Canvas)                      │
│  6. 绘制背景层                                   │
│  7. 遍历节点树，绘制各元素                        │
│  8. 图表绘制 (ChartRenderer)                     │
│  9. 绘制品牌栏                                   │
│  10. 编码为 PNG (Uint8List)                      │
└────────────────────────────────────────────────┘
```

### 5.2 核心渲染实现

```dart
class CardRenderEngine {
  final TemplateParser _parser = TemplateParser();
  final LayoutEngine _layoutEngine = LayoutEngine();
  final ChartRenderer _chartRenderer = ChartRenderer();

  /// 主渲染入口
  Future<Uint8List> render(
    CardTemplate template,
    Map<String, dynamic> data,
  ) async {
    final stopwatch = Stopwatch()..start();

    // 1. 解析模板
    final nodeTree = _parser.parse(jsonEncode(template));

    // 2. 数据绑定
    final boundTree = DataBinder.bind(nodeTree, data);

    // 3. 条件过滤
    final filteredTree = ConditionEvaluator.filter(boundTree);

    // 4. 布局计算
    final canvasSize = Size(
      template.canvas.width.toDouble(),
      template.canvas.height.toDouble(),
    );
    final renderBoxes = _layoutEngine.layout(filteredTree, canvasSize);

    // 5. 渲染到 Canvas
    final recorder = ui.PictureRecorder();
    final canvas = ui.Canvas(recorder);
    final logicalSize = canvasSize / _devicePixelRatio;

    // 5a. 绘制背景
    _drawBackground(canvas, canvasSize, template.background);

    // 5b. 绘制各节点
    for (final box in renderBoxes) {
      _drawNode(canvas, box);
    }

    // 5c. 绘制品牌栏
    _drawBrandBar(canvas, canvasSize, template.brandBar, data);

    // 6. 转图片
    final picture = recorder.endRecording();
    final image = await picture.toImage(
      canvasSize.width.toInt(),
      canvasSize.height.toInt(),
    );
    final byteData = await image.toByteData(
      format: ui.ImageByteFormat.png,
    );

    stopwatch.stop();
    _logger.info('Card rendered in ${stopwatch.elapsedMilliseconds}ms');

    return byteData!.buffer.asUint8List();
  }

  void _drawBackground(ui.Canvas canvas, Size size, BackgroundDefinition bg) {
    if (bg.type == 'gradient' && bg.gradientColors != null) {
      final colors = bg.gradientColors!.map(_parseColor).toList();
      final begin = _gradientBegin(bg.gradientDirection ?? 'tl_br', size);
      final end = _gradientEnd(bg.gradientDirection ?? 'tl_br', size);
      final shader = ui.Gradient.linear(begin, end, colors, _colorStops(colors.length));
      canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height),
        ui.Paint()..shader = shader);
    } else if (bg.type == 'solid') {
      canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height),
        ui.Paint()..color = _parseColor(bg.solidColor ?? '#FFFFFF'));
    } else if (bg.type == 'image') {
      // 加载并绘制背景图片（已预加载到内存）
      _drawNetworkImage(canvas, bg.backgroundImageUrl!, size);
    }
  }

  void _drawNode(ui.Canvas canvas, RenderBox box) {
    switch (box.nodeType) {
      case 'text':
        _drawTextNode(canvas, box);
        break;
      case 'image':
        _drawImageNode(canvas, box);
        break;
      case 'chart':
        _drawChartNode(canvas, box);
        break;
      case 'container':
        _drawContainerNode(canvas, box);
        // 递归绘制子节点
        for (final child in box.children) {
          _drawNode(canvas, child);
        }
        break;
      case 'divider':
        _drawDividerNode(canvas, box);
        break;
    }
  }

  void _drawTextNode(ui.Canvas canvas, RenderBox box) {
    final style = box.textStyle!;
    final builder = ui.ParagraphBuilder(ui.ParagraphStyle(
      textAlign: _parseAlign(style.align ?? 'left'),
      fontSize: style.fontSize.toDouble(),
      fontWeight: _parseFontWeight(style.fontWeight),
      fontStyle: style.fontItalic == true ? ui.FontStyle.italic : ui.FontStyle.normal,
    ))
      ..pushStyle(ui.TextStyle(color: _parseColor(style.color)))
      ..addText(style.resolvedContent); // 已绑定数据后的文本

    final paragraph = builder.build()
      ..layout(ui.ParagraphConstraints(width: box.constraints.maxWidth));

    canvas.drawParagraph(paragraph, Offset(box.x, box.y));
  }

  Future<void> _drawChartNode(ui.Canvas canvas, RenderBox box) async {
    final chartStyle = box.chartStyle!;
    switch (chartStyle.chartType) {
      case 'radar':
        final radarImage = await _chartRenderer.renderRadarChart(
          RadarData(
            labels: chartStyle.resolvedLabels,
            values: chartStyle.resolvedValues,
            previousValues: chartStyle.resolvedPreviousValues,
            maxValue: chartStyle.maxValue ?? 100,
          ),
          Size(box.constraints.maxWidth, box.constraints.maxHeight),
          RadarStyle(
            fillColor: _parseColor(chartStyle.fillColor ?? '#FFFFFF44'),
            strokeColor: _parseColor(chartStyle.strokeColor ?? '#FFFFFF'),
            previousStrokeColor: _parseColor(chartStyle.previousStrokeColor ?? '#FFFFFF55'),
            labelColor: _parseColor(chartStyle.labelColor ?? '#FFFFFF'),
            gridColor: _parseColor(chartStyle.gridColor ?? '#FFFFFF22'),
            showGrid: chartStyle.showGrid ?? true,
          ),
        );
        // 绘制雷达图到主 canvas
        canvas.drawImage(radarImage, Offset(box.x, box.y), ui.Paint());
        break;
      // bar, line, pie 类似...
    }
  }
}
```

### 5.3 图表渲染器

```dart
class ChartRenderer {
  /// 渲染雷达图
  Future<ui.Image> renderRadarChart(RadarData data, Size size, RadarStyle style) async {
    final recorder = ui.PictureRecorder();
    final canvas = ui.Canvas(recorder);
    final center = Offset(size.width / 2, size.height / 2);
    final radius = min(size.width, size.height) / 2 - 40; // 留出标签空间
    final sides = data.labels.length;

    // 1. 绘制网格层
    if (style.showGrid) {
      for (int level = 1; level <= 5; level++) {
        final r = radius * level / 5;
        final path = _regularPolygonPath(center, r, sides);
        canvas.drawPath(path, ui.Paint()
          ..color = style.gridColor
          ..style = ui.PaintingStyle.stroke
          ..strokeWidth = 1);
      }
      // 轴线
      for (int i = 0; i < sides; i++) {
        final angle = -pi / 2 + 2 * pi * i / sides;
        canvas.drawLine(
          center,
          Offset(center.dx + radius * cos(angle), center.dy + radius * sin(angle)),
          ui.Paint()..color = style.gridColor,
        );
      }
    }

    // 2. 绘制上一期数据（底层，半透明）
    if (data.previousValues != null) {
      final prevPath = _radarDataPath(center, radius, data.previousValues!, data.maxValue, sides);
      canvas.drawPath(prevPath, ui.Paint()
        ..color = style.previousStrokeColor
        ..style = ui.PaintingStyle.stroke
        ..strokeWidth = 2);
    }

    // 3. 绘制当期数据
    final dataPath = _radarDataPath(center, radius, data.values, data.maxValue, sides);
    canvas.drawPath(dataPath, ui.Paint()
      ..color = style.fillColor
      ..style = ui.PaintingStyle.fill);
    canvas.drawPath(dataPath, ui.Paint()
      ..color = style.strokeColor
      ..style = ui.PaintingStyle.stroke
      ..strokeWidth = 2.5);

    // 4. 绘制数据点
    for (int i = 0; i < sides; i++) {
      final angle = -pi / 2 + 2 * pi * i / sides;
      final r = radius * (data.values[i] / data.maxValue);
      final point = Offset(center.dx + r * cos(angle), center.dy + r * sin(angle));
      canvas.drawCircle(point, 4, ui.Paint()..color = style.strokeColor);
    }

    // 5. 绘制标签
    for (int i = 0; i < sides; i++) {
      final angle = -pi / 2 + 2 * pi * i / sides;
      final labelR = radius + 24;
      final labelPos = Offset(center.dx + labelR * cos(angle), center.dy + labelR * sin(angle));
      _drawLabel(canvas, data.labels[i], labelPos, style.labelColor, 14);
    }

    final picture = recorder.endRecording();
    return picture.toImage(size.width.toInt(), size.height.toInt());
  }

  Path _radarDataPath(Offset center, double radius, List<double> values,
      double maxValue, int sides) {
    final path = Path();
    for (int i = 0; i < sides; i++) {
      final angle = -pi / 2 + 2 * pi * i / sides;
      final r = radius * (values[i].clamp(0, maxValue) / maxValue);
      final point = Offset(center.dx + r * cos(angle), center.dy + r * sin(angle));
      if (i == 0) path.moveTo(point.dx, point.dy);
      else path.lineTo(point.dx, point.dy);
    }
    path.close();
    return path;
  }
}
```

## 8. 分享调度器

### 8.1 分享流程

```dart
class ShareDispatcher {
  final Map<ShareTargetPlatform, ShareAdapter> _adapters = {
    ShareTargetPlatform.wechatMoment: WechatShareAdapter(),
    ShareTargetPlatform.wechatFriend: WechatShareAdapter(),
    ShareTargetPlatform.qq: QQShareAdapter(),
    ShareTargetPlatform.weibo: WeiboShareAdapter(),
    ShareTargetPlatform.generic: SystemShareAdapter(),
  };

  Future<ShareResult> share(ShareCardResult card, ShareTarget target) async {
    final adapter = _adapters[target.platform];
    if (adapter == null) {
      return ShareResult.failure('不支持的平台: ${target.platform}');
    }

    // 检查平台是否已安装
    if (!await adapter.isAvailable()) {
      return ShareResult.failure('${target.platform} 未安装或版本不支持');
    }

    // 埋点：分享开始
    AnalyticsService.track('share_card_start', {
      'card_type': card.cardType,
      'platform': target.platform.name,
    });

    try {
      final result = await adapter.share(card, target);
      // 埋点：分享成功
      AnalyticsService.track('share_card_success', {
        'card_type': card.cardType,
        'platform': target.platform.name,
      });
      return result;
    } catch (e) {
      AnalyticsService.track('share_card_error', {
        'card_type': card.cardType,
        'platform': target.platform.name,
        'error': e.toString(),
      });
      return ShareResult.failure(e.toString());
    }
  }
}
```

## 9. 性能优化策略

### 9.1 渲染性能

| 策略 | 说明 |
|------|------|
| Isolate 渲染 | 将卡片渲染放到独立 Isolate，不阻塞 UI 线程 |
| 模板预编译 | 首次解析模板后缓存 NodeTree，避免重复解析 JSON |
| 图片预加载 | 背景图、成就图标等异步资源提前加载到内存 |
| 图表缓存 | 同一数据集的图表结果可短期缓存（5分钟） |
| 增量渲染 | 模板未变化时仅重新绑定数据，跳过布局计算 |

```dart
    if (!await shareDir.exists()) return;

    await for (final entity in shareDir.list()) {
      if (entity is File) {
        final stat = await entity.stat();
        if (stat.modified.isBefore(expiry)) {
          await entity.delete();
        }
      }
    }
  }
```

```dart
class DataMasker {
  /// 用户名脱敏
  /// "张小明" → "张小***"  |  "Alex" → "Al***"
  static String maskUserName(String name) {
    if (name.isEmpty) return '同学';
    if (name.length <= 2) return '${name[0]}***';
    return '${name.substring(0, 2)}***';
  }

  /// 排名脱敏（仅显示前10具体名次，之后显示百分比）
  static String maskRank(int rank, int total) {
    if (rank <= 10) return '第$rank名';
    final percent = (rank / total * 100).toStringAsFixed(1);
    return '前$percent%';
  }

  /// 学校名脱敏
  static String maskSchool(String school) {
    if (school.length <= 4) return school;
    return '${school.substring(0, 4)}...';
  }
}
```

```dart
class ShareCardSecurityChecker {
  /// 渲染前安全校验
  static SecurityCheckResult check(ShareCardRequest request, Map<String, dynamic> payload) {
    final issues = <String>[];

    // 1. 确保没有明文手机号
    if (_containsPhoneNumber(jsonEncode(payload))) {
      issues.add('payload包含手机号，需要脱敏');
    }

    // 2. 确保用户名已脱敏
    if (payload.containsKey('userName')) {
      final name = payload['userName'] as String;
      if (!name.contains('***')) {
        issues.add('用户名未脱敏');
      }
    }

    // 3. 确保没有完整设备信息
    if (payload.containsKey('deviceId')) {
      issues.add('不应包含设备ID');
    }

    // 4. 二维码中的用户ID必须加密
    // (在二维码生成阶段校验)

    return issues.isEmpty
      ? SecurityCheckResult.pass()
      : SecurityCheckResult.fail(issues);
```

| `SHARE_DATA_INCOMPLETE` | 必要数据字段缺失 | 用默认值填充 + 上报 |
| `SHARE_RENDER_TIMEOUT` | 渲染超时 (>3s) | 降级为纯文字卡片 |
| `SHARE_RENDER_OOM` | 渲染内存溢出 | 降级为低分辨率渲染 |
| `SHARE_IMAGE_ENCODE_ERROR` | PNG 编码失败 | 重试一次，失败则降级 |
| `SHARE_PLATFORM_UNAVAILABLE` | 目标平台未安装 | 提示用户安装 |
| `SHARE_PLATFORM_ERROR` | 平台 SDK 调用失败 | 重试一次 + 回退系统分享 |
| `SHARE_SECURITY_CHECK_FAILED` | 安全检查未通过 | 阻断分享 + 上报 |
| `SHARE_NETWORK_ERROR` | 网络错误（拉取模板） | 使用缓存模板 |
