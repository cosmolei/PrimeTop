# 客户端本地搜索与离线内容检索引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

为 PrimeTop 客户端提供统一的本地搜索能力，支持在无网络或弱网环境下对已缓存的题目、知识点、错题、笔记、学科工具、教材章节等离线内容进行全文检索。本引擎是服务端搜索（Elasticsearch）的客户端侧补充，共同构成"云端+端侧"双层搜索架构。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **离线可用** | 无网络时仍可搜索本地缓存的所有内容 |
| **毫秒响应** | 本地搜索结果返回 ≤ 200ms（千级数据量） |
| **中文友好** | 支持拼音、首字母、模糊匹配和中文分词 |
| **统一接口** | 上层业务通过同一 SearchService 访问，透明切换本地/远程 |
| **增量同步** | 本地索引随数据缓存增量更新，非全量重建 |
| **低开销** | 索引占用存储 ≤ 缓存数据总量的 30%，不影响主业务性能 |

### 1.3 与其他文档的关系

| 文档 | 交叉点 | 本文档侧重点 |
|------|--------|-------------|

## 4. SQLite FTS5 索引设计

### 4.1 统一搜索索引表

采用单张 FTS5 虚拟表作为统一索引，避免多表 JOIN 和跨索引查询的性能开销：

```sql
-- 统一搜索索引（FTS5 虚拟表）
CREATE VIRTUAL TABLE search_index USING fts5(
    content_id,           -- 原始内容 ID
    content_type,         -- question/knowledgePoint/mistake/note/chapter/tool/examPoint/favorite
    title,                -- 标题（中文原始文本）
    title_pinyin,         -- 标题拼音全拼
    title_pinyin_abbr,    -- 标题拼音首字母
    body,                 -- 正文/描述
    body_pinyin,          -- 正文拼音全拼
    keywords,             -- 关键词（空格分隔）
    keywords_pinyin,      -- 关键词拼音
    subject,              -- 学科代码 math/physics/chemistry/...
    stage,                -- 学段 primary/junior/senior
    grade,                -- 年级 G1-G12
    tags,                 -- 标签（空格分隔）
    tokenize='unicode61'  -- Unicode 分词器（支持中文按字符分割）
);

-- content=''' 表示不映射原始表，由应用层手动维护索引内容
-- 使用 content='' 时 FTS5 不会引用原始表，完全由应用控制
```

### 4.2 为什么使用单表而非多表

| 方案 | 优势 | 劣势 |
|------|------|------|
| **单表（选用）** | 一次查询搜全部类型；索引体积小；维护简单 | 字段有冗余（部分类型某字段为空） |
| 多表（每类型一表） | 字段精确无冗余 | 跨表查询需 UNION；索引体积大；维护复杂 |
| 多表 + 统一视图 | 兼顾字段精确和统一查询 | SQLite FTS5 不支持跨虚拟表 VIEW |

### 4.3 索引内容映射规则

每种内容类型写入索引时，字段映射如下：

| content_type | title | body | keywords | subject | tags |
|---|---|---|---|---|---|
| question | 题干前80字 | 选项 + 答案摘要 | 知识点名称列表 | 题目学科 | 题型/难度/来源 |
| knowledgePoint | 知识点名称 | 定义 + 描述 | 同义词/别名 | 所属学科 | 所属章节 |
| mistake | 题干前80字 | 错因标签 + 订正笔记 | 知识点名称 | 学科 | 错因类型 |
| note | 笔记标题 | 笔记正文前500字 | 用户自定义标签 | 关联学科 | - |
| chapter | 章节名称 | 章节概述 | 关键知识点名称 | 学科 | 年级/学期 |
| tool | 工具名称 | 公式LaTeX + 说明 | 别名/缩写 | 学科 | 工具类型 |
| examPoint | 考点名称 | 考点描述 | 关联知识点 | 学科 | 重要度/频率 |
| favorite | 内容标题 | 内容摘要 | - | 学科 | 收藏夹名称 |

### 4.4 拼音索引策略

中文搜索必须支持拼音输入。采用"存储时预计算"策略，在写入索引时同步生成拼音字段：

```dart
/// 拼音处理器
class PinyinProcessor {
  /// 将中文字符串转换为全拼（带声调数字分隔）
  /// 例: "二次方程" → "er ci fang cheng"
  static String toFullPinyin(String chinese) {
    final buffer = StringBuffer();
    for (final char in chinese.runes) {
      final pinyin = _charPinyinMap[char];
      if (pinyin != null) {
        if (buffer.isNotEmpty) buffer.write(' ');
        buffer.write(pinyin);
      } else if (_isChinese(char)) {
        // 未知汉字，保留原字符（FTS5 仍可按字符匹配）
        buffer.writeCharCode(char);
      } else {
        buffer.writeCharCode(char);
      }
    }
    return buffer.toString();
  }

  /// 提取拼音首字母
  /// 例: "二次方程" → "ecfc"
  static String toPinyinAbbr(String chinese) {
    final buffer = StringBuffer();
    for (final char in chinese.runes) {
      final pinyin = _charPinyinMap[char];
      if (pinyin != null && pinyin.isNotEmpty) {
        buffer.write(pinyin[0]);
      }
    }
    return buffer.toString();
  }

  /// 判断是否为中文字符
  static bool _isChinese(int rune) {
    return rune >= 0x4E00 && rune <= 0x9FFF;
  }

  // 常用汉字→拼音映射表（完整版通过本地 JSON 文件加载，约 2MB）
  // 此处仅示例核心条目
  static const _charPinyinMap = <int, String>{
    0x4E00: 'yi',   // 一
    0x4E8C: 'er',   // 二
    0x4E09: 'san',  // 三
    0x56DB: 'si',   // 四
    0x4E94: 'wu',   // 五
    0x516D: 'liu',  // 六
    0x4E03: 'qi',   // 七
    0x516B: 'ba',   // 八
    0x4E5D: 'jiu',  // 九
    0x5341: 'shi',  // 十
    // ... 完整映射通过 assets/pinyin_table.json 加载
  };

  /// 从本地 JSON 文件加载完整拼音表
  static Future<Map<int, String>> loadPinyinTable(String assetPath) async {
    // 加载约 21000 个常用汉字的拼音映射
    // 资源文件随 APP 打包，约 2MB
    final json = await rootBundle.loadString(assetPath);
    final map = jsonDecode(json) as Map<String, dynamic>;
    return map.map((k, v) => MapEntry(int.parse(k, radix: 16), v as String));
  }
}
```

## 5. 本地搜索引擎实现

### 5.1 LocalSearchEngine 核心类

```dart
/// 本地搜索引擎
class LocalSearchEngine {
  final Database _db;
  final PinyinProcessor _pinyinProcessor;
  final Logger _logger;

  LocalSearchEngine({
    required Database db,
    PinyinProcessor? pinyinProcessor,
  })  : _db = db,
        _pinyinProcessor = pinyinProcessor ?? PinyinProcessor(),
        _logger = Logger('LocalSearchEngine');

  /// 执行本地搜索
  Future<List<SearchResultItem>> search(SearchRequest request) async {
    final stopwatch = Stopwatch()..start();

    try {
      // 1. 构建查询条件
      final query = _buildFtsQuery(request);

      // 2. 构建类型过滤
      final typeFilter = _buildTypeFilter(request.types);

      // 3. 构建元数据过滤
      final metaFilter = _buildMetaFilter(request.options);

      // 4. 执行 FTS5 查询
      final sql = '''
        SELECT
          content_id,
          content_type,
          title,
          body,
          subject,
          stage,
          rank,
          snippet(search_index, 2, '⟨', '⟩', '...', 20) AS highlighted_title,
          snippet(search_index, 5, '⟨', '⟩', '...', 40) AS highlighted_body
        FROM search_index
        WHERE search_index MATCH ?
          $typeFilter
          $metaFilter
        ORDER BY rank
        LIMIT ?
      ''';

      final rows = await _db.rawQuery(sql, [query, request.limit * 2]);

      // 5. 转换为 SearchResultItem
      final results = rows.map((row) => _mapToResultItem(row)).toList();

      stopwatch.stop();
      _logger.fine('本地搜索完成: query="${request.query}", '
          'results=${results.length}, '
          'duration=${stopwatch.elapsedMilliseconds}ms');

      return results;
    } catch (e, st) {
      _logger.warning('本地搜索失败: $e', e, st);
      return [];
    }
  }

  /// 构建 FTS5 MATCH 表达式
  String _buildFtsQuery(SearchRequest request) {
    final query = request.query.trim();
    if (query.isEmpty) return '';

    final buffer = StringBuffer();
    final tokens = _tokenize(query);

    for (int i = 0; i < tokens.length; i++) {
      if (i > 0) buffer.write(' AND ');

      final token = tokens[i];

      if (request.options.enablePinyin && _looksLikePinyin(token)) {
        // 拼音匹配：同时搜索原文和拼音字段
        buffer.write('(title:*$token* OR title_pinyin:*$token* '
            'OR title_pinyin_abbr:*$token* '
            'OR keywords_pinyin:*$token*)');
      } else if (_isChinese(token)) {
        // 中文：精确匹配 + 模糊匹配
        buffer.write('(title:*$token* OR body:*$token* '
            'OR keywords:*$token*)');
        if (request.options.enableFuzzy) {
          // FTS5 fuzzy: token 后加 ~ 表示模糊匹配
          // 实际使用 bm25 排序时模糊结果自然靠后
        }
      } else {
        // 英文/数字/符号
        buffer.write('(title:*$token* OR body:*$token* '
            'OR keywords:*$token*)');
      }
    }

    return buffer.toString();
  }

  /// 简单分词：中文按字，英文按空格
  List<String> _tokenize(String query) {
    final tokens = <String>[];
    final buffer = StringBuffer();

    for (final char in query.runes) {
      if (_isChinese(char)) {
        // 中文逐字作为独立 token（FTS5 unicode61 对中文按字符分词）
        if (buffer.isNotEmpty) {
          tokens.add(buffer.toString().toLowerCase());
          buffer.clear();
        }
        tokens.add(String.fromCharCode(char));
      } else if (char == 0x20) {
        // 空格分隔
        if (buffer.isNotEmpty) {
          tokens.add(buffer.toString().toLowerCase());
          buffer.clear();
        }
      } else {
        buffer.writeCharCode(char);
      }
    }
    if (buffer.isNotEmpty) {
      tokens.add(buffer.toString().toLowerCase());
    }

    return tokens;
  }

  /// 判断是否像拼音输入
  bool _looksLikePinyin(String token) {
    return RegExp(r'^[a-zA-Z]+$').hasMatch(token);
  }

  bool _isChinese(int rune) {
    return rune >= 0x4E00 && rune <= 0x9FFF;
  }

  String _buildTypeFilter(Set<SearchContentType>? types) {
    if (types == null || types.isEmpty) return '';
    final typeStrings = types.map((t) => "'${t.name}'").join(',');
    return 'AND content_type IN ($typeStrings)';
  }

  String _buildMetaFilter(SearchOptions options) {
    final conditions = <String>[];
    if (options.subjectFilter != null) {
      conditions.add("subject = '${options.subjectFilter}'");
    }
    if (options.stageFilter != null) {
      conditions.add("stage = '${options.stageFilter}'");
    }
    if (conditions.isEmpty) return '';
    return 'AND ${conditions.join(' AND ')}';
  }

  SearchResultItem _mapToResultItem(Map<String, dynamic> row) {
    final type = SearchContentType.values.firstWhere(
      (t) => t.name == row['content_type'],
      orElse: () => SearchContentType.question,
    );

    // 使用 snippet 高亮结果，去除 FTS5 snippet 标记
    final highlightedTitle = (row['highlighted_title'] as String?)
            ?.replaceAll('⟨', '**')
            .replaceAll('⟩', '**') ??
        (row['title'] as String? ?? '');

    final highlightedBody = (row['highlighted_body'] as String?)
            ?.replaceAll('⟨', '**')
            .replaceAll('⟩', '**');

    return SearchResultItem(
      id: row['content_id'] as String,
      type: type,
      title: highlightedTitle,
      subtitle: highlightedBody,
      relevanceScore: _rankToScore(row['rank'] as double?),
      metadata: {
        'subject': row['subject'],
        'stage': row['stage'],
      },
    );
  }

  /// FTS5 rank 值转换为 0-1 的相关度评分
  double _rankToScore(double? rank) {
    if (rank == null) return 0.5;
    // FTS5 bm25 返回负值，越小越相关
    // 将其映射到 0-1 范围
    final normalized = 1.0 / (1.0 + (-rank).abs());
    return normalized.clamp(0.0, 1.0);
  }
}
```

### 5.2 FTS5 中文分词策略

SQLite FTS5 的 `unicode61` 分词器对中文按单字符分割（逐字分词），这意味着：

- 搜索"方程"会匹配包含"方"或"程"的记录
- 需要通过 AND 连接多个字符实现短语近似匹配

**改进方案：使用 simple 分词器 + 预分词**

对于教育场景中大量专业术语（"一元二次方程"、"光合作用"），采用"写入时预分词到 keywords 字段"的策略：

```dart
/// 预分词器：将中文文本中的专业术语提取为关键词
class KeywordExtractor {
  /// 教育领域专有词库（从服务端同步，本地缓存）
  /// 格: {"一元二次方程": "yi yuan er ci fang cheng"}
  Map<String, String> _termDict = {};

  Future<void> loadTermDict(String assetPath) async {
    final json = await rootBundle.loadString(assetPath);
    final map = jsonDecode(json) as Map<String, dynamic>;
    _termDict = map.map((k, v) => MapEntry(k, v as String));
  }

  /// 从文本中提取关键词（最大正向匹配）
  List<String> extract(String text) {
    final keywords = <String>[];
    int i = 0;
    while (i < text.length) {
      bool matched = false;
      // 最大匹配：从最长可能的词开始尝试
      for (int len = min(8, text.length - i); len >= 2; len--) {
        final substr = text.substring(i, i + len);
        if (_termDict.containsKey(substr)) {
          keywords.add(substr);
          i += len;
          matched = true;
          break;
        }
      }
      if (!matched) i++;
    }
    return keywords;
  }
}
```

### 6.1 索引生命周期

```

                                                    ↓

                                                    ↑

                          ↑                         │
              APP启动时检查索引完整性 ─────────────────┘
```

```dart
/// 索引管理器
class SearchIndexManager {
  final Database _db;
  final PinyinProcessor _pinyinProcessor;
  final Logger _logger;

  // 批量写入缓冲
  final List<IndexEntry> _writeBuffer = [];
  static const _batchSize = 50;
  Timer? _flushTimer;

  SearchIndexManager({
    required Database db,
    required PinyinProcessor pinyinProcessor,
  })  : _db = db,
        _pinyinProcessor = pinyinProcessor,
        _logger = Logger('SearchIndexManager');

  /// 初始化（APP 启动时调用）
  Future<void> init() async {
    // 检查索引表是否存在
    final tables = await _db.rawQuery(
      "SELECT name FROM sqlite_master WHERE type='table' AND name='search_index'",
    );

    if (tables.isEmpty) {
      await _createIndexTable();
      _logger.info('搜索索引表创建完成');
    }

    // 启动定时刷新
    _flushTimer = Timer.periodic(
      const Duration(seconds: 5),
      (_) => flush(),
    );
  }

  /// 创建 FTS5 索引表
  Future<void> _createIndexTable() async {
    await _db.execute('''
      CREATE VIRTUAL TABLE IF NOT EXISTS search_index USING fts5(
        content_id,
        content_type,
        title,
        title_pinyin,
        title_pinyin_abbr,
        body,
        body_pinyin,
        keywords,
        keywords_pinyin,
        subject,
        stage,
        grade,
        tags,
        tokenize='unicode61'
      )
    ''');

    // 索引统计表（用于追踪各类型索引条目数）
    await _db.execute('''
      CREATE TABLE IF NOT EXISTS search_index_stats (
        content_type TEXT PRIMARY KEY,
        count INTEGER NOT NULL DEFAULT 0,
        last_updated TEXT NOT NULL,
        index_version INTEGER NOT NULL DEFAULT 1
      )
    ''');
  }

  /// 添加/更新索引条目
  Future<void> upsertIndex(SearchIndexable item) async {
    final entry = _buildIndexEntry(item);
    _writeBuffer.add(entry);

    if (_writeBuffer.length >= _batchSize) {
      await flush();
    }
  }

  /// 批量添加索引
  Future<void> batchUpsert(List<SearchIndexable> items) async {
    for (final item in items) {
      final entry = _buildIndexEntry(item);
      _writeBuffer.add(entry);
    }

    if (_writeBuffer.length >= _batchSize) {
      await flush();
    }
  }

  /// 删除索引条目
  Future<void> deleteIndex(String contentId, SearchContentType type) async {
    await _db.delete(
      'search_index',
      where: 'content_id = ? AND content_type = ?',
      whereArgs: [contentId, type.name],
    );

    // 更新统计
    await _updateStats(type, -1);
  }

  /// 删除某类型的所有索引
  Future<void> deleteIndexByType(SearchContentType type) async {
    await _db.delete(
      'search_index',
      where: 'content_type = ?',
      whereArgs: [type.name],
    );

    await _updateStats(type, 0, reset: true);
  }

  /// 刷新缓冲区到数据库
  Future<void> flush() async {
    if (_writeBuffer.isEmpty) return;

    final batch = _writeBuffer.toList();
    _writeBuffer.clear();

    try {
      await _db.transaction((txn) async {
        for (final entry in batch) {
          // 先删除旧记录（upsert 语义）
          await txn.delete(
            'search_index',
            where: 'content_id = ? AND content_type = ?',
            whereArgs: [entry.contentId, entry.contentType],
          );

          await txn.insert('search_index', {
            'content_id': entry.contentId,
            'content_type': entry.contentType,
            'title': entry.title,
            'title_pinyin': entry.titlePinyin,
            'title_pinyin_abbr': entry.titlePinyinAbbr,
            'body': entry.body,
            'body_pinyin': entry.bodyPinyin,
            'keywords': entry.keywords,
            'keywords_pinyin': entry.keywordsPinyin,
            'subject': entry.subject,
            'stage': entry.stage,
            'grade': entry.grade,
            'tags': entry.tags,
          });
        }
      });

      // 更新统计
      final typeCounts = <String, int>{};
      for (final entry in batch) {
        typeCounts[entry.contentType] = (typeCounts[entry.contentType] ?? 0) + 1;
      }
      for (final entry in typeCounts.entries) {
        await _updateStats(
          SearchContentType.values.firstWhere((t) => t.name == entry.key),
          entry.value,
        );
      }

      _logger.fine('索引刷新完成: ${batch.length} 条');
    } catch (e, st) {
      _logger.warning('索引刷新失败: $e', e, st);
      // 失败的条目放回缓冲区
      _writeBuffer.insertAll(0, batch);
    }
  }

  /// 构建索引条目
  IndexEntry _buildIndexEntry(SearchIndexable item) {
    final title = item.searchTitle;
    final body = item.searchBody;
    final keywords = item.searchKeywords;

    return IndexEntry(
      contentId: item.searchId,
      contentType: item.searchType.name,
      title: title,
      titlePinyin: _pinyinProcessor.toFullPinyin(title),
      titlePinyinAbbr: _pinyinProcessor.toPinyinAbbr(title),
      body: body,
      bodyPinyin: _pinyinProcessor.toFullPinyin(body),
      keywords: keywords,
      keywordsPinyin: _pinyinProcessor.toFullPinyin(keywords),
      subject: item.searchSubject ?? '',
      stage: item.searchStage ?? '',
      grade: item.searchGrade ?? '',
      tags: item.searchTags?.join(' ') ?? '',
    );
  }

  Future<void> _updateStats(
    SearchContentType type,
    int delta, {
    bool reset = false,
  }) async {
    if (reset) {
      await _db.insert(
        'search_index_stats',
        {
          'content_type': type.name,
          'count': delta,
          'last_updated': DateTime.now().toIso8601String(),
          'index_version': 1,
        },
        conflictAlgorithm: ConflictAlgorithm.replace,
      );
    } else {
      await _db.rawInsert('''
        INSERT INTO search_index_stats (content_type, count, last_updated, index_version)
        VALUES (?, ?, datetime('now'), 1)
        ON CONFLICT(content_type) DO UPDATE SET
          count = count + ?,
          last_updated = datetime('now')
      ''', [type.name, delta, delta]);
    }
  }

  /// 获取索引统计信息
  Future<Map<SearchContentType, int>> getStats() async {
    final rows = await _db.query('search_index_stats');
    return {
      for (final row in rows)
        SearchContentType.values.firstWhere(
          (t) => t.name == row['content_type'],
          orElse: () => SearchContentType.question,
        ): row['count'] as int,
    };
  }

  /// 重建全量索引（数据迁移或索引损坏时调用）
  Future<void> rebuildFullIndex(List<SearchIndexable> allItems) async {
    _logger.info('开始全量重建索引: ${allItems.length} 条');

    // 清空旧索引
    await _db.delete('search_index');

    // 分批重建
    int processed = 0;
    for (int i = 0; i < allItems.length; i += _batchSize) {
      final batch = allItems.sublist(i, min(i + _batchSize, allItems.length));
      await _db.transaction((txn) async {
        for (final item in batch) {
          final entry = _buildIndexEntry(item);
          await txn.insert('search_index', {
            'content_id': entry.contentId,
            'content_type': entry.contentType,
            'title': entry.title,
            'title_pinyin': entry.titlePinyin,
            'title_pinyin_abbr': entry.titlePinyinAbbr,
            'body': entry.body,
            'body_pinyin': entry.bodyPinyin,
            'keywords': entry.keywords,
            'keywords_pinyin': entry.keywordsPinyin,
            'subject': entry.subject,
            'stage': entry.stage,
            'grade': entry.grade,
            'tags': entry.tags,
          });
        }
      });

      processed += batch.length;
      if (processed % 500 == 0) {
        _logger.info('索引重建进度: $processed/${allItems.length}');
      }
    }

    _logger.info('全量索引重建完成');
  }

  /// 清理过期/无效索引
  Future<void> cleanup() async {
    // 删除空内容ID的索引
    await _db.delete('search_index', where: "content_id = ''");
    // 删除超出容量限制的旧数据
    _logger.info('索引清理完成');
  }

  void dispose() {
    _flushTimer?.cancel();
    flush(); // 同步刷新剩余缓冲
  }
}
```

```dart
/// 搜索服务
class SearchService {
  final LocalSearchEngine _localEngine;
  final ApiClient _apiClient;
  final NetworkQuality _networkQuality;
  final SearchHistoryManager _historyManager;

  SearchService({
    required LocalSearchEngine localEngine,
    required ApiClient apiClient,
    required NetworkQuality networkQuality,
    required SearchHistoryManager historyManager,
  })  : _localEngine = localEngine,
        _apiClient = apiClient,
        _networkQuality = networkQuality,
        _historyManager = historyManager;

  /// 统一搜索入口
  Future<SearchResultSet> search(SearchRequest request) async {
    final stopwatch = Stopwatch()..start();

    // 记录搜索历史
    await _historyManager.record(request.query);

    // 根据策略执行搜索
    final strategy = _resolveStrategy(request);

    switch (strategy) {
      case SearchStrategy.localOnly:
        return _searchLocal(request, stopwatch);

      case SearchStrategy.remoteFirst:
        return _searchRemoteFirst(request, stopwatch);

      case SearchStrategy.localFirst:
        return _searchLocalFirst(request, stopwatch);

      case SearchStrategy.parallel:
        return _searchParallel(request, stopwatch);
    }
  }

  /// 解析搜索策略
  SearchStrategy _resolveStrategy(SearchRequest request) {
    final isOffline = _networkQuality == NetworkQuality.offline;

    // 离线时只能本地搜索
    if (isOffline) return SearchStrategy.localOnly;

    // 特定场景的策略
    switch (request.types?.singleOrNull) {
      case SearchContentType.mistake:
      case SearchContentType.note:
      case SearchContentType.tool:
      case SearchContentType.favorite:
        // 这些数据完全在本地
        return SearchStrategy.localOnly;
      case null:
        // 全局搜索：在线时远程优先
        return SearchStrategy.remoteFirst;
      default:
        // 其他类型：本地优先（减少延迟）
        return SearchStrategy.localFirst;
    }
  }

  /// 纯本地搜索
  Future<SearchResultSet> _searchLocal(
    SearchRequest request,
    Stopwatch stopwatch,
  ) async {
    final results = await _localEngine.search(request);
    stopwatch.stop();

    final grouped = _groupByType(results);
    return SearchResultSet(
      query: request.query,
      fromRemote: false,
      results: grouped,
      totalLocal: results.length,
      searchDuration: stopwatch.elapsed,
    );
  }

  /// 远程优先搜索
  Future<SearchResultSet> _searchRemoteFirst(
    SearchRequest request,
    Stopwatch stopwatch,
  ) async {
    try {
      // 先尝试远程搜索
      final remoteResults = await _searchRemote(request);
      stopwatch.stop();

      if (remoteResults.isNotEmpty) {
        final grouped = _groupByType(remoteResults);
        return SearchResultSet(
          query: request.query,
          fromRemote: true,
          results: grouped,
          totalLocal: 0,
          totalRemote: remoteResults.length,
          searchDuration: stopwatch.elapsed,
        );
      }
    } catch (e) {
      // 远程搜索失败，降级到本地
    }

    // 降级到本地搜索
    return _searchLocal(request, stopwatch);
  }

  /// 本地优先搜索
  Future<SearchResultSet> _searchLocalFirst(
    SearchRequest request,
    Stopwatch stopwatch,
  ) async {
    final localResults = await _localEngine.search(request);

    if (localResults.length >= 5) {
      // 本地结果足够，不请求远程
      stopwatch.stop();
      final grouped = _groupByType(localResults);
      return SearchResultSet(
        query: request.query,
        fromRemote: false,
        results: grouped,
        totalLocal: localResults.length,
        searchDuration: stopwatch.elapsed,
      );
    }

    // 本地结果不足，补充远程搜索
    try {
      final remoteResults = await _searchRemote(request);
      final merged = _mergeResults(localResults, remoteResults);
      stopwatch.stop();

      final grouped = _groupByType(merged);
      return SearchResultSet(
        query: request.query,
        fromRemote: true,
        results: grouped,
        totalLocal: localResults.length,
        totalRemote: remoteResults.length,
        searchDuration: stopwatch.elapsed,
      );
    } catch (e) {
      stopwatch.stop();
      final grouped = _groupByType(localResults);
      return SearchResultSet(
        query: request.query,
        fromRemote: false,
        results: grouped,
        totalLocal: localResults.length,
        searchDuration: stopwatch.elapsed,
      );
    }
  }

  /// 并行搜索（同时本地 + 远程）
  Future<SearchResultSet> _searchParallel(
    SearchRequest request,
    Stopwatch stopwatch,
  ) async {
    final results = await Future.wait([
      _localEngine.search(request),
      _searchRemote(request).catchError((_) => <SearchResultItem>[]),
    ]);

    final localResults = results[0] as List<SearchResultItem>;
    final remoteResults = results[1] as List<SearchResultItem>;
    final merged = _mergeResults(localResults, remoteResults);
    stopwatch.stop();

    final grouped = _groupByType(merged);
    return SearchResultSet(
      query: request.query,
      fromRemote: remoteResults.isNotEmpty,
      results: grouped,
      totalLocal: localResults.length,
      totalRemote: remoteResults.length,
      searchDuration: stopwatch.elapsed,
    );
  }

  /// 远程搜索
  Future<List<SearchResultItem>> _searchRemote(SearchRequest request) async {
    final response = await _apiClient.post(
      '/api/v1/search',
      body: {
        'query': request.query,
        'types': request.types?.map((t) => t.name).toList(),
        'limit': request.limit,
        'options': {
          'subject': request.options.subjectFilter,
          'stage': request.options.stageFilter,
        },
      },
    );

    return (response['items'] as List)
        .map((item) => SearchResultItem(
              id: item['id'] as String,
              type: SearchContentType.values.firstWhere(
                (t) => t.name == item['type'],
              ),
              title: item['title'] as String,
              subtitle: item['subtitle'] as String?,
              relevanceScore: (item['score'] as num).toDouble(),
              metadata: item['metadata'] as Map<String, dynamic>? ?? {},
            ))
        .toList();
  }

  /// 合并本地和远程结果（去重 + 排序）
  List<SearchResultItem> _mergeResults(
    List<SearchResultItem> local,
    List<SearchResultItem> remote,
  ) {
    final seen = <String>{};
    final merged = <SearchResultItem>[];

    // 远程结果优先
    for (final item in remote) {
      final key = '${item.type.name}:${item.id}';
      if (seen.add(key)) {
        merged.add(item);
      }
    }

    // 补充本地独有的结果
    for (final item in local) {
      final key = '${item.type.name}:${item.id}';
      if (seen.add(key)) {
        merged.add(item);
      }
    }

    // 按 relevanceScore 降序排列
    merged.sort((a, b) => b.relevanceScore.compareTo(a.relevanceScore));

    return merged;
  }

  Map<SearchContentType, List<SearchResultItem>> _groupByType(
    List<SearchResultItem> items,
  ) {
    final grouped = <SearchContentType, List<SearchResultItem>>{};
    for (final item in items) {
      grouped.putIfAbsent(item.type, () => []).add(item);
    }
    return grouped;
  }
}

/// 搜索策略

  remoteFirst,  // 远程优先，失败降级本地
  localFirst,   // 本地优先，不足时补充远程
  parallel,     // 并行搜索
}
```

```dart
class SearchHistoryManager {
  final Database _db;
  static const _maxHistoryItems = 100;

  SearchHistoryManager(this._db);

  /// 记录搜索历史
  Future<void> record(String query, {String? searchType, int resultCount = 0}) async {
    if (query.trim().isEmpty) return;

    await _db.insert(
      'search_history',
      {
        'query': query.trim(),
        'result_count': resultCount,
        'search_type': searchType,
        'created_at': DateTime.now().toIso8601String(),
      },
      conflictAlgorithm: ConflictAlgorithm.replace,
    );

    // 清理超出上限的旧记录
    await _db.rawDelete('''
      DELETE FROM search_history WHERE id NOT IN (
        SELECT id FROM search_history
        ORDER BY created_at DESC
        LIMIT ?
      )
    ''', [_maxHistoryItems]);
  }

  /// 获取搜索历史（最近 N 条）
  Future<List<SearchHistoryEntry>> getHistory({
    int limit = 20,
    String? searchType,
  }) async {
    var query = 'SELECT * FROM search_history';
    final args = <dynamic>[];
    if (searchType != null) {
      query += ' WHERE search_type = ?';
      args.add(searchType);
    }
    query += ' ORDER BY created_at DESC LIMIT ?';
    args.add(limit);

    final rows = await _db.rawQuery(query, args);
    return rows.map((r) => SearchHistoryEntry(
      id: r['id'] as int,
      query: r['query'] as String,
      resultCount: r['result_count'] as int,
      searchType: r['search_type'] as String?,
      createdAt: DateTime.parse(r['created_at'] as String),
    )).toList();
  }

  /// 搜索建议（基于历史记录前缀匹配）
  Future<List<String>> getSuggestions(String prefix, {int limit = 5}) async {
    if (prefix.isEmpty) {
      // 返回最近搜索
      final history = await getHistory(limit: limit);
      return history.map((h) => h.query).toList();
    }

    final rows = await _db.rawQuery('''
      SELECT DISTINCT query FROM search_history
      WHERE query LIKE ?
      ORDER BY created_at DESC
      LIMIT ?
    ''', ['%$prefix%', limit]);

    return rows.map((r) => r['query'] as String).toList();
  }

  /// 删除单条历史
  Future<void> deleteHistory(int id) async {
    await _db.delete('search_history', where: 'id = ?', whereArgs: [id]);
  }

  /// 清空历史
  Future<void> clearHistory({String? searchType}) async {
    if (searchType != null) {
      await _db.delete(
        'search_history',
        where: 'search_type = ?',
        whereArgs: [searchType],
      );
    } else {
      await _db.delete('search_history');
    }
  }
}
```

```dart
class QuestionIndexable extends SearchIndexable {
  final Question question;

  QuestionIndexable(this.question);

  @override
  String get searchId => 'q_${question.id}';

  @override
  SearchContentType get searchType => SearchContentType.question;

  @override
  String get searchTitle {
    // 题干前 80 字，去除 LaTeX 标记
    final plain = question.stem
        .replaceAll(RegExp(r'\\[a-zA-Z]+(\{[^}]*\})*'), '')
        .replaceAll(RegExp(r'[\$\{\}]'), '')
        .trim();
    return plain.length > 80 ? '${plain.substring(0, 80)}...' : plain;
  }

  @override
  String get searchBody {
    // 选项文本 + 答案摘要
    final buffer = StringBuffer();
    if (question.options != null) {
      for (final opt in question.options!) {
        buffer.write('${opt.label}. ${opt.text} ');
      }
    }
    if (question.answerSummary != null) {
      buffer.write(question.answerSummary!);
    }
    final text = buffer.toString();
    return text.length > 500 ? text.substring(0, 500) : text;
  }

  @override
```

### 10.1 数据缓存时的自动索引更新

本地索引不需要独立的数据同步流程，而是绑定到各模块的数据缓存流程中：

```
远程数据缓存流程（增强版）：
  1. 服务端返回数据
  2. 写入本地 SQLite 业务表
  3. ⭐ 触发 SearchIndexManager.upsertIndex()  ← 新增步骤
  4. 返回数据给 UI 层
```

```dart
class MistakeRepository {

  final SearchIndexManager _searchIndex;

    await _db.transaction((txn) async {
      for (final q in questions) {

            conflictAlgorithm: ConflictAlgorithm.replace);
      }
```

```dart
/// 索引一致性检查（启动时执行）
class SearchIndexIntegrityChecker {
  final Database _db;
  final SearchIndexManager _indexManager;
  final Logger _logger;

  Future<void> checkAndRepair() async {
    _logger.info('开始索引一致性检查');

    // 检查各类型索引数量与业务表数量是否一致
    final checks = [
      _checkType('mistake_record', SearchContentType.mistake),
      _checkType('notes', SearchContentType.note),
      _checkType('cached_questions', SearchContentType.question),
      _checkType('favorite_items', SearchContentType.favorite),
    ];

    final results = await Future.wait(checks);

    for (final result in results) {
      if (result.needsRebuild) {
        _logger.warning(
          '索引不一致: ${result.type}, '
          '业务表=${result.businessCount}, '
          '索引=${result.indexCount}, '
          '触发重建',
        );
        await result.rebuildAction();
      }
    }

    _logger.info('索引一致性检查完成');
  }

  Future<_IntegrityCheckResult> _checkType(
    String businessTable,
    SearchContentType type,
  ) async {
    final businessCount = Sqflite.firstIntValue(
      await _db.rawQuery('SELECT COUNT(*) FROM $businessTable'),
    ) ?? 0;

    final indexCount = Sqflite.firstIntValue(
      await _db.rawQuery(
        "SELECT COUNT(*) FROM search_index WHERE content_type = ?",
        [type.name],
      ),
    ) ?? 0;

    // 允许 5% 的差异（批量写入缓冲延迟）
    final tolerance = (businessCount * 0.05).ceil();
    final needsRebuild = (businessCount - indexCount).abs() > tolerance;

    return _IntegrityCheckResult(
      type: type,
      businessCount: businessCount,
      indexCount: indexCount,
      needsRebuild: needsRebuild,
      rebuildAction: needsRebuild ? () => _rebuildType(type, businessTable) : () async {},
    );
  }

  Future<void> _rebuildType(
    SearchContentType type,
    String businessTable,
  ) async {
    // 删除该类型的所有索引
    await _indexManager.deleteIndexByType(type);

    // 从业务表重新读取并建索引
    final rows = await _db.query(businessTable);
    final items = rows.map((row) => _mapToIndexable(type, row)).toList();
    await _indexManager.rebuildFullIndex(items);
  }

  SearchIndexable _mapToIndexable(SearchContentType type, Map<String, dynamic> row) {
    return switch (type) {
      SearchContentType.mistake => MistakeIndexable(MistakeRecord.fromMap(row)),
      SearchContentType.note => NoteIndexable(Note.fromMap(row)),
      SearchContentType.question => QuestionIndexable(Question.fromMap(row)),
      _ => throw UnimplementedError('未实现 $type 的索引重建'),
    };
  }
}

class _IntegrityCheckResult {
  final SearchContentType type;
  final int businessCount;
  final int indexCount;
  final bool needsRebuild;
  final Future<void> Function() rebuildAction;

  const _IntegrityCheckResult({
    required this.type,
    required this.businessCount,
    required this.indexCount,
    required this.needsRebuild,
    required this.rebuildAction,
  });
}
```

```dart
    int lastEnd = 0;

    for (final match in regex.allMatches(text)) {
      if (match.start > lastEnd) {
        spans.add(TextSpan(text: text.substring(lastEnd, match.start)));
      }
      spans.add(TextSpan(
        text: match.group(1),
        style: TextStyle(
          color: Theme.of(context).primaryColor,
          fontWeight: FontWeight.bold,
        ),
      ));
      lastEnd = match.end;
    }
    if (lastEnd < text.length) {
      spans.add(TextSpan(text: text.substring(lastEnd)));
    }

    return RichText(
      maxLines: 1,
      overflow: TextOverflow.ellipsis,
      text: TextSpan(
        style: Theme.of(context).textTheme.bodyMedium,
        children: spans,
      ),
    );
  }

    final score = (item.relevanceScore * 100).round();
```

### 13.3 优化策略

1. **冷启动优化**：FTS5 索引表不随 APP 冷启动全量加载，按需查询
2. **写入缓冲**：索引更新采用批量写入（50 条/批）+ 定时刷新（5 秒），避免频繁 I/O
3. **拼音预计算**：拼音转换在写入时完成，查询时零开销
4. **连接池复用**：搜索使用同一个 SQLite 连接，复用 prepared statement
5. **结果缓存**：相同查询在 30 秒内直接返回缓存结果

```dart
/// 搜索结果缓存
class SearchCache {
  final _cache = <String, _CacheEntry>{};
  static const _ttl = Duration(seconds: 30);

  SearchResultSet? get(String query) {
    final entry = _cache[query];
    if (entry == null) return null;
    if (DateTime.now().difference(entry.time) > _ttl) {
      _cache.remove(query);
      return null;
    }
    return entry.result;
  }

  void set(String query, SearchResultSet result) {
    _cache[query] = _CacheEntry(result: result, time: DateTime.now());
    // 超出上限时清理最旧的
    if (_cache.length > 50) {
      final sorted = _cache.entries.toList()
        ..sort((a, b) => a.value.time.compareTo(b.value.time));
      _cache.remove(sorted.first.key);
    }
  }
}

class _CacheEntry {
  final SearchResultSet result;
  final DateTime time;
  _CacheEntry({required this.result, required this.time});
}
```

## 14. 错误处理

### 14.1 错误场景与处理策略

| 错误场景 | 检测方式 | 处理策略 |
|---------|---------|---------|
| FTS5 索引表损坏 | 查询抛出 `DatabaseException` | 删除并重建索引表 |
| 拼音表加载失败 | 文件读取异常 | 降级为纯中文搜索，无拼音支持 |
| 索引写入失败 | `insert` 抛出异常 | 放入重试缓冲区，下次 flush 时重试 |
| 搜索超时 | `TimeoutException` | 返回已获取的部分结果 |
| 远程搜索失败 | HTTP 错误/超时 | 静默降级到本地搜索 |
| 结果合并异常 | 类型解析错误 | 仅返回未出错的部分结果 |

### 14.2 错误码定义

| 错误码 | 含义 | 客户端处理 |
|--------|------|-----------|
| `SEARCH_001` | 查询表达式构建失败 | 提示用户简化查询 |
| `SEARCH_002` | FTS5 索引不可用 | 触发索引重建 |
| `SEARCH_003` | 索引写入缓冲区溢出 | 清理最旧的缓冲条目 |
| `SEARCH_004` | 拼音处理器未初始化 | 降级为无拼音搜索 |
| `SEARCH_005` | 远程搜索降级到本地 | UI 显示离线提示 |

### 14.3 降级策略

```
正常模式：远程搜索 + 本地搜索合并
   ↓ (网络异常)
降级模式 1：纯本地搜索，UI 显示"离线模式"提示
   ↓ (索引损坏)
降级模式 2：重建索引 + 纯本地搜索
   ↓ (重建失败)
最终降级：放弃搜索功能，UI 显示"搜索暂不可用"
```

## 17. 初始化集成

### 17.1 APP 启动集成流程

在 `客户端应用启动流程与初始化管线` 的 Stage 3（服务初始化）中添加搜索相关初始化：

```dart
/// 搜索子系统初始化任务
class SearchInitTask extends InitTask {
  @override
  int get priority => 30; // 在数据库初始化（priority=10）之后

  @override
  Future<void> execute(InitContext context) async {
    // 1. 加载拼音表（异步，不阻塞启动）
    final pinyinProcessor = PinyinProcessor();
    // 不 await，后台加载
    pinyinProcessor.loadTable('assets/pinyin_table.json').then((_) {
      context.ref.read(pinyinProcessorProvider.notifier).state = pinyinProcessor;
    });

    // 2. 初始化搜索索引管理器
    final indexManager = context.ref.read(searchIndexManagerProvider);
    await indexManager.init();

    // 3. 初始化内置工具索引（首次启动）
    final stats = await indexManager.getStats();
    if (!stats.containsKey(SearchContentType.tool) ||
        stats[SearchContentType.tool] == 0) {
      await _indexBuiltinTools(indexManager);
    }

    // 4. 后台执行一致性检查（不阻塞启动）
    Future.microtask(() async {
      final checker = context.ref.read(searchIndexIntegrityCheckerProvider);
      await checker.checkAndRepair();
    });
  }

  Future<void> _indexBuiltinTools(SearchIndexManager indexManager) async {
    // 从本地 JSON 加载内置学科工具并建立索引
    final tools = await _loadBuiltinTools();
    await indexManager.batchUpsert(tools);
  }

  Future<List<SearchIndexable>> _loadBuiltinTools() async {
    // 加载打包在 assets 中的学科工具数据
    final json = await rootBundle.loadString('assets/data/subject_tools.json');
    final items = jsonDecode(json) as List;
    return items.map((item) => ToolIndexable(SubjectToolItem.fromJson(item))).toList();
  }
}
```

## 18. 总结

本设计为 PrimeTop 客户端提供了完整的本地搜索解决方案：

1. **SQLite FTS5 统一索引**：单表存储所有可搜索内容，支持中文、拼音、模糊匹配
2. **SearchIndexable 接口**：各业务模块实现统一接口即可接入搜索
3. **双层搜索架构**：本地搜索与服务端搜索透明切换，离线完全可用
4. **自动索引同步**：索引更新绑定到数据缓存流程，无需额外同步任务
5. **低资源开销**：索引总量 ≤ 3MB，搜索响应 ≤ 200ms
6. **完整 UI 组件**：全局搜索页面 + 内嵌搜索栏，开箱即用
