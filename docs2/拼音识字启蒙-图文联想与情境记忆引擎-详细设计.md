# 拼音识字启蒙 - 图文联想与情境记忆引擎 详细设计

## 1. 概述

### 1.1 模块定位

图文联想与情境记忆引擎是 PrimeTop **拼音识字启蒙模块** 的核心子系统之一，面向 3-8 岁幼儿及小学低年级学生。引擎通过“汉字 → 图片 → 词语 → 生活场景”的多维联想，帮助低龄用户在形象化、情境化的记忆中建立对汉字的语义、读音和书写认知，降低纯机械记忆的枯燥感。

### 1.2 核心职责

1. **联想卡片组装**：根据目标汉字，从结构化资源库中检索最佳匹配的图片、词语、例句、场景描述，组装成一张适合当前学段的联想卡片。
2. **多模态内容生成**：当资源库缺失或覆盖率不足时，调用 AIGC/素材服务生成适龄图片、合成语音、补充例句。
3. **个性化排序**：基于学生年龄、已掌握字词、学习偏好、历史正确率，动态调整推荐顺序和例句难度。
4. **学习状态追踪**：记录每张卡片的“初识 → 熟悉 → 掌握 → 复习”状态，为复习调度引擎提供数据。
5. **亲子/课堂场景适配**：支持家长/教师选择主题包（如“水果”、“动物”、“校园”），并支持亲子共学模式下的双端同步。

### 1.3 依赖关系

| 依赖模块 | 说明 |
| --- | --- |
| 拼音识字启蒙教学内容调度与互动练习生成服务 | 提供学习单元、课程路径、练习素材编排 |
| 语音服务（ASR/TTS） | 提供汉字、词语、例句的语音朗读 |
| 图片处理与 OCR 识别管线 | 图片压缩、转码、CDN 分发、图片内容安全审核 |
| 内容审核/安全过滤服务 | 对儿童图片、文本进行适龄性与安全审核 |
| 用户学习画像与能力维度模型 | 提供学生学段、已掌握字词、兴趣标签 |
| 间隔重复算法与遗忘曲线复习调度引擎 | 基于卡片掌握状态触发复习 |
| 成就勋章与奖励展示组件 | 完成卡片学习后触发激励反馈 |

## 2. 数据模型

### 2.1 核心实体

| 实体 | 说明 |
| --- | --- |
| `Character` | 汉字基础信息（字形、拼音、笔画、部首、难度等级） |
| `ImageAsset` | 图片资源（原始图、缩略图、透明图、插画风格标签） |
| `WordExample` | 词语与例句（含适龄分级的文本、TTS 音频、句长） |
| `Scenario` | 生活场景/主题包（如“超市购物”、“动物园”） |
| `AssociationCard` | 组装后的“汉字 + 图 + 词 + 句 + 场景”卡片 |
| `CharacterCardProgress` | 学生对某张卡片的学习进度与状态 |
| `CardGenerationTask` | AIGC 补全任务队列（图片/例句生成） |

### 2.2 数据库表结构

#### 2.2.1 汉字基础表 `character_base`

```sql
CREATE TABLE character_base (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    char_code       VARCHAR(16) NOT NULL COMMENT 'Unicode/统一字符编码',
    character_text  VARCHAR(4) NOT NULL COMMENT '汉字文本，如“苹”',
    pinyin          VARCHAR(64) NOT NULL COMMENT '带声调拼音，如“píng”',
    pinyin_no_tone  VARCHAR(64) NOT NULL COMMENT '无声调拼音，如“ping”',
    stroke_count    TINYINT NOT NULL COMMENT '笔画数',
    radical         VARCHAR(8) COMMENT '部首',
    structure       VARCHAR(16) COMMENT '结构：左右/上下/独体/包围',
    difficulty_level TINYINT NOT NULL DEFAULT 1 COMMENT '难度等级 1-5',
    grade_range     VARCHAR(32) COMMENT '适用年级，如“K1-P2”',
    category_tags   JSON COMMENT '分类标签：["fruit","plant","daily"]',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE INDEX uk_character_text (character_text),
    INDEX idx_difficulty_grade (difficulty_level, grade_range),
    INDEX idx_pinyin (pinyin_no_tone)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='汉字基础信息表';
```

### 2.3 缓存策略

| 缓存Key | 类型 | TTL | 说明 |
| --- | --- | --- | --- |
| `card:assembly:{character_id}:{scenario_id}:{age_level}` | Redis String | 30 min | 已组装卡片内容（JSON） |
| `card:progress:{user_id}:{card_id}` | Redis String | 24 h | 学生单卡片学习进度 |
| `char:assets:{character_id}:{age_level}` | Redis Set/List | 1 h | 可用图片/例句ID列表 |
| `scenario:active:{age_level}` | Redis Set | 10 min | 当前年龄段可用场景列表 |
| `gen:lock:{task_type}:{character_id}:{scenario_id}` | Redis Lock | 5 min | 防止同一资源并发生成 |

### 3.4 推荐下一张卡片

```
GET /api/v1/character-association/cards/next?scenario_id={scenario_id}&age_level=toddler
```

**推荐策略：**

1. 优先选择 `status = 'new'` 且在当前场景中的未学汉字。
2. 其次选择 `status = 'learning'` 且 `next_review_at <= now()` 的卡片。
3. 排除已达到当日学习上限或已被家长禁用时段的内容。
4. 结合学生兴趣标签（如偏好动物/食物）加权排序。

### 3.5 上报学习事件

```
POST /api/v1/character-association/progress/events
```

**请求体：**

```json
{
  "card_id": 12001,
  "event_type": "quiz_answer",
  "payload": {
    "is_correct": true,
    "elapsed_seconds": 5,
    "interaction_type": "image_to_word_match"
  },
  "client_timestamp": 1716123600000
}
```

**事件类型枚举：**

| 事件类型 | 说明 |
| --- | --- |
| `card_viewed` | 卡片被展示 |
| `audio_played` | 播放读音 |
| `trace_completed` | 完成书写/描红 |
| `word_selected` | 在图中选中对应词语 |
| `quiz_answer` | 完成随堂小测验 |
| `card_mastered` | 系统判定已掌握 |

### 3.6 错误码定义

| 错误码 | HTTP 状态 | 说明 | 客户端处理 |
| --- | --- | --- | --- |
| `0` | 200 | 成功 | — |
| `40001` | 400 | 参数错误 | 提示检查输入 |
| `40002` | 400 | 不支持的 age_level | 使用默认年龄段 |
| `40401` | 404 | 汉字不存在 | 展示占位提示 |
| `40402` | 404 | 当前场景下无可用卡片 | 切换其他场景 |
| `40403` | 404 | 图片资源不存在 | 使用文字卡片兜底 |
| `42901` | 429 | 生成任务过于频繁 | 稍后重试 |
| `50001` | 500 | 卡片组装失败 | 降级返回静态卡片 |
| `50002` | 500 | AIGC 服务不可用 | 使用资源库现有内容 |
| `50301` | 503 | 内容审核服务超时 | 返回待审占位图，异步补全 |

## 4. 业务逻辑

### 4.1 卡片组装流程

```
用户请求 card
      │
      ▼
┌──────────────────────┐
│ 1. 参数校验：学段、场景、汉字ID │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 2. 查询缓存 card:assembly  │
│    命中 → 直接返回        │
└──────────┬───────────┘
           ▼ 未命中
┌──────────────────────┐
│ 3. 加载汉字基础信息       │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 4. 选择图片资源：         │
│    a) 优先 scenario_id 精确匹配 │
│    b) 其次按 category_tags 匹配 │
│    c) 最后按 age_level 通用图兜底 │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 5. 选择词语/例句：        │
│    a) 目标字在词首优先       │
│    b) 句长 ≤ 适龄阈值        │
│    c) 已掌握字词覆盖率最高   │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 6. 组合 tips/互动动作     │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 7. 写入缓存并返回卡片     │
└──────────────────────┘
```

### 4.2 资源缺失时的 AIGC 补全流程

```
资源缺失（无图片/无例句）
      │
      ▼
┌──────────────────────┐
│ 检查是否已有 pending 任务 │
│ 有 → 返回占位卡片，订阅完成通知 │
└──────────┬───────────┘
           ▼ 无
┌──────────────────────┐
│ 生成任务入队 card_generation_task │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 异步工人执行：            │
│ 图片：调用文生图API + 安全审核 │
│ 例句：调用LLM生成适龄短句 + 审核 │
└──────────┬───────────┘
           ▼
┌──────────────────────┐
│ 更新资源表与任务状态      │
│ 刷新卡片缓存              │
│ 推送“新卡片已准备好”通知  │
└──────────────────────┘
```

### 4.3 状态流转

```
                    ┌──────────┐
                    │   new    │
                    │  未学习   │
                    └────┬─────┘
                         │ 首次展示卡片
                         ▼
                    ┌──────────┐
             ┌─────│ learning │─────┐
             │     │  学习中   │      │

  < 3 次     │          │ (听/读/练)   │  正确率 >= 80%
             │          ▼              │
             │     ┌──────────┐       │
             └────▶│ reviewing│◀──────┘
                   │  复习中   │
                   └────┬─────┘
                        │ 复习后仍正确
                        ▼
                   ┌──────────┐
                   │ mastered │
                   │  已掌握   │
                   └──────────┘
```

**状态转换规则：**

| 当前状态 | 触发条件 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| new | 卡片首次展示 | learning | 记录 first_seen_at |
| learning | 完成 1 次听/读/描红 | learning | study_count +1 |
| learning | 完成测验且正确率 ≥ 80% | mastered | 触发成就事件 |
| learning | 连续错误 ≥ 3 次 | reviewing | 标记为需重点复习 |
| reviewing | 完成复习且正确 | learning | 重新进入学习循环 |
| reviewing | 复习后仍错 | reviewing | 提升复习频率 |
| mastered | 到达遗忘曲线复习点 | reviewing | 间隔重复调度 |

### 4.4 掌握度评分算法

采用加权指数滑动平均，公式：

```
M_new = α * X + (1 - α) * M_old

其中：
  X = 当前交互得分（正确=1，错误=0，部分正确=0.5）
  α = 学习率，根据题目难度动态调整：
      · 简单题 α=0.3
      · 中等题 α=0.5
      · 困难题 α=0.7
  M_old = 上一次掌握度
```

掌握度阈值：

| 掌握度 | 状态 |
| --- | --- |
| 0.00 - 0.30 | 初学 |
| 0.31 - 0.60 | 熟悉 |
| 0.61 - 0.85 | 基本掌握 |
| 0.86 - 1.00 | 熟练掌握 |

```python
from dataclasses import dataclass
from datetime import datetime
from typing import Optional, List

@dataclass
class AssociationCard:
    card_id: int
    character_id: int
    character: str
    pinyin: str
    image: dict
    word: dict
    sentence: dict
    tips: List[str]

class CardAssemblyService:
    def __init__(
        self,
        character_repo: CharacterRepository,
        image_repo: ImageRepository,
        word_repo: WordExampleRepository,
        cache: RedisCache,
        generator: AIGCGenerator,
    ):
        self.character_repo = character_repo
        self.image_repo = image_repo
        self.word_repo = word_repo
        self.cache = cache
        self.generator = generator

    async def assemble_card(
        self,
        character_id: int,
        age_level: str,
        scenario_id: Optional[int] = None,
    ) -> AssociationCard:
        cache_key = f"card:assembly:{character_id}:{scenario_id}:{age_level}"
        cached = await self.cache.get(cache_key)
        if cached:
            return AssociationCard(**cached)

        char = await self.character_repo.get(character_id)
        if not char:
            raise CardNotFoundError(character_id)

        image = await self.image_repo.select_best(
            character_id=character_id,
            scenario_id=scenario_id,
            age_level=age_level,
            category_tags=char.category_tags,
        )
        if not image:
            image = await self._ensure_image(character_id, scenario_id, age_level)

        word = await self.word_repo.select_best(
            character_id=character_id,
            scenario_id=scenario_id,
            age_level=age_level,
        )
        if not word:
            word = await self._ensure_word_example(character_id, age_level)

        sentence = await self.word_repo.select_sentence(
            word_example_id=word.id,
            age_level=age_level,
        )

        tips = self._generate_tips(char, word, image)

        card = AssociationCard(
            card_id=0,  # 由 DB 生成
            character_id=char.id,
            character=char.text,
            pinyin=char.pinyin,
            image=image.to_dict(),
            word=word.to_dict(),
            sentence=sentence.to_dict(),
            tips=tips,
        )

        await self.cache.set(cache_key, card.to_dict(), ttl=1800)
        return card

    async def _ensure_image(self, character_id, scenario_id, age_level):
        """资源缺失时触发 AIGC 补全，并返回占位图"""
        task_id = await self.generator.submit_image_task(
            character_id=character_id,
            scenario_id=scenario_id,
            age_level=age_level,
        )
        # 返回一个通用占位图，保证前端可立即展示
        return await self.image_repo.get_placeholder(age_level)

    def _generate_tips(self, char, word, image) -> List[str]:
        tips = []
        if char.radical:
            tips.append(f"“{char.character}”字的部首是“{char.radical}”，和{self._radical_meaning(char.radical)}有关。")
        if image and image.alt_text:
            tips.append(f"看到图片里的{image.alt_text}，就能记住“{char.character}”字啦！")
        return tips
```

### 5.2 图片选择策略

```python
class ImageRepository:
    async def select_best(
        self,
        character_id: int,
        scenario_id: Optional[int],
        age_level: str,
        category_tags: List[str],
    ) -> Optional[ImageAsset]:
        # 1. 精确匹配：场景 + 汉字 + 适龄 + 已审核
        if scenario_id:
            exact = await self.db.fetch_one(
                "SELECT * FROM image_asset WHERE character_id=%s AND scenario_id=%s "
                "AND age_level=%s AND audit_status=1 AND is_active=1 ORDER BY priority DESC LIMIT 1",
                character_id, scenario_id, age_level,
            )
            if exact:
                return ImageAsset(**exact)

        # 2. 概念词匹配：用 category_tags 找通用图
        if category_tags:
            concept = category_tags[0]  # 取首个标签作为概念词
            generic = await self.db.fetch_one(
                "SELECT * FROM image_asset WHERE concept_word=%s AND age_level=%s "
                "AND audit_status=1 AND is_active=1 ORDER BY priority DESC LIMIT 1",
                concept, age_level,
            )
            if generic:
                return ImageAsset(**generic)

        # 3. 兜底：适龄通用占位图
        return await self.get_placeholder(age_level)
```

### 5.3 学习进度服务

```python
class CardProgressService:
    def __init__(self, repo: CardProgressRepository, scheduler: ReviewScheduler):
        self.repo = repo
        self.scheduler = scheduler

    async def record_event(self, user_id: int, card_id: int, event: StudyEvent):
        progress = await self.repo.get_or_create(user_id, card_id)

        if event.event_type == "card_viewed" and progress.status == "new":
            progress.status = "learning"
            progress.first_seen_at = datetime.now()

        elif event.event_type == "quiz_answer":
            progress.study_count += 1
            is_correct = event.payload.get("is_correct", False)
            if is_correct:
                progress.correct_count += 1
            else:
                progress.mistake_count += 1

            # 更新掌握度
            x = 1.0 if is_correct else 0.0
            alpha = self._difficulty_to_alpha(event.payload.get("difficulty", 1))
            progress.mastery_score = alpha * x + (1 - alpha) * progress.mastery_score

            # 状态判定
            if progress.mastery_score >= 0.8 and progress.study_count >= 2:
                progress.status = "mastered"
            elif progress.mistake_count >= 3:
                progress.status = "reviewing"

            progress.next_review_at = self.scheduler.next_review_time(
                mastery=progress.mastery_score,
                status=progress.status,
            )

        progress.last_study_at = datetime.now()
        await self.repo.save(progress)
        return progress

    def _difficulty_to_alpha(self, difficulty: int) -> float:
        return {1: 0.3, 2: 0.5, 3: 0.7}.get(difficulty, 0.5)
```

```python
class CardGenerationWorker:
    async def run_image_task(self, task: CardGenerationTask):
        char = await self.character_repo.get(task.character_id)
        prompt = self._build_image_prompt(char, task.age_level)

        try:
            image_url = await self.image_gen.generate(prompt=prompt, style="cartoon")
            # 安全审核
            audit = await self.content_safety.audit_image(image_url)
            if not audit.passed:
                raise ContentSafetyError(audit.reason)

            asset = await self.image_repo.save(
                character_id=task.character_id,
                scenario_id=task.scenario_id,
                age_level=task.age_level,
                cdn_url=image_url,
                source="ai_generate",
                audit_status=1,
            )
            task.status = "success"
            task.result_url = asset.cdn_url
        except Exception as e:
            task.retry_count += 1
            if task.retry_count >= 3:
                task.status = "failed"
                task.error_msg = str(e)
            else:
                task.status = "pending"

        await self.task_repo.save(task)
```

## 6. 错误处理

### 6.1 异常分类

| 异常类型 | 触发场景 | 处理策略 |
| --- | --- | --- |
| `CardNotFoundError` | 请求不存在的汉字 | 返回 40401，前端展示“这个字还没准备好” |
| `ImageNotAvailableError` | 图片资源全部缺失 | 降级为纯文本/拼音卡片，异步生成图片 |
| `AIGCTimeoutError` | 文生图/LLM 超时 | 使用占位图，任务重试，不阻塞用户 |
| `ContentSafetyRejectError` | 生成内容审核不通过 | 丢弃结果，记录日志，触发人工复核 |
| `CacheUnavailableError` | Redis 不可用 | 直读数据库，日志告警，不中断服务 |
| `UserAgeMismatchError` | 请求学段与学生档案不符 | 返回学生真实学段对应的卡片 |

### 6.2 重试策略

| 场景 | 重试次数 | 退避策略 | 说明 |
| --- | --- | --- | --- |
| AIGC 图片生成失败 | 3 | 指数退避 2s/4s/8s | 超过后标记失败，人工介入 |
| AIGC 例句生成失败 | 3 | 线性退避 1s/2s/3s | 使用资源库兜底例句 |
| 内容审核服务超时 | 2 | 立即重试 | 仍失败则进入人工审核队列 |
| 数据库查询失败 | 3 | 固定 100ms | 仍失败返回 500 |

## 7. 性能优化

### 7.1 缓存策略

- **卡片缓存**：单张卡片组装结果缓存 30 分钟，命中率目标 > 80%。
- **进度缓存**：学生进度写入 Redis 后异步刷库，减少写库压力。
- **资源预加载**：根据学习路径，预加载下一课的 5-10 张卡片到 CDN 边缘节点。

### 7.2 并发控制

- 同一资源的 AIGC 生成任务使用 Redis 分布式锁防止重复生成。
- 批量卡片接口限制单次请求最多 20 个汉字，避免大查询。

### 7.3 资源限制

| 资源 | 限制 | 说明 |
| --- | --- | --- |
| 单张图片 | ≤ 200 KB | 保证低端机加载速度 |
| 单条 TTS 音频 | ≤ 100 KB | 控制流量与存储 |
| 批量卡片 | ≤ 20 个/次 | 防止响应体过大 |
| AIGC 并发 | 按供应商限流 | 使用令牌桶控制 |

## 8. 安全考虑

### 8.1 内容安全

1. 所有 AI 生成的图片、例句必须过内容安全审核（涉黄、涉暴、涉政、广告）。
2. 图片需符合国家儿童内容规范，避免出现恐怖、惊悚、危险行为诱导。
3. 例句中不得出现品牌、广告、网络流行语、低俗谐音。

### 8.2 权限控制

1. 学生只能获取自己学段及以下难度的卡片。
2. 家长可设置“可用内容范围”，超出范围的卡片不返回。
3. 管理后台对图片/例句的审核状态变更需记录操作人、时间、原因。

### 8.3 数据隐私

1. 不收集幼儿用户的生物识别信息（如手写笔迹仅本地处理）。
2. 学习进度数据加密存储，不对外共享。
3. 图片 CDN URL 使用带签名的临时链接，避免盗链。

### 8.4 版权合规

1. 图片资源优先使用自研插画或已购版权素材。
2. AI 生成图片需加入 AIGC 水印或元数据标识。
3. 外部采购素材需记录授权范围与到期时间。
