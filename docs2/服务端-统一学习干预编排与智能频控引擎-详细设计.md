# 服务端 - 统一学习干预编排与智能频控引擎

> 版本: v1.0 | 创建日期: 2026-06-16 | 状态: 初稿

## 1. 概述

### 1.1 模块定位

统一学习干预编排与智能频控引擎（Unified Learning Intervention Orchestration & Intelligent Frequency Control Engine，简称 **NEXUS**）是 PrimeTop 学习体验优化层的**干预决策中枢**。它汇聚来自 LSSA（实时会话感知）、学习倦怠预警、流失预警、计划偏离预警、学习风险评估、AI 辅导策略等多源上游系统的干预信号，执行去重、优先级仲裁、频率控制、渠道选择与消息个性化，最终将恰当的干预以恰当的方式在恰当的时机投递给学生。

**核心职责：**
- **信号聚合**：统一接收所有上游引擎发布的干预请求/事件
- **冲突仲裁**：当多个系统同时建议干预时，选择最紧急/最有价值的干预，抑制其余
- **频控管理**：按学生会话级、日级、周级实施干预频率上限，避免干预轰炸
- **渠道决策**：选择最优投递渠道（浮窗提示 / inline 消息 / AI 对话注入 / 推送通知 / 家长通知）
- **消息个性化**：根据学生画像、学段、偏好调整干预措辞、语气和呈现形式
- **效果闭环**：追踪每次干预的接受/忽略/拒绝结果，反馈给上游引擎并优化策略
- **冷却管理**：同类干预设置冷却窗口，避免短期内重复触发

**不在本模块范围内：**
- 干预信号的**生成**（感知/预警本身） → 由各上游引擎负责
- 干预内容的**渲染与展示** → 由客户端 UI 组件层负责
- 具体教学策略选择（启发/提示/降难度） → 由 AI 辅导策略引擎负责
- 长期动机建模与心理画像 → 由心理状态建模引擎负责

### 1.2 为什么需要此引擎

| 现状问题 | 具体表现 | 影响 |
|----------|---------|------|
| **干预碎片化** | LSSA、倦怠预警、流失预警、计划偏离各自独立触发干预 | 学生可能同时收到 3-4 条干预提示，体验极差 |
| **无全局频控** | 各模块只关心自身的触发条件，没有全局频率限制 | 高频预警用户被"干预轰炸"，产生厌烦和免疫 |
| **渠道冲突** | 多个系统同时向推送服务、弹窗服务发送消息 | 消息堆积、互相覆盖、关键信息被淹没 |
| **策略互斥** | A 系统建议"降低难度"，B 系统建议"增加挑战" | 学生收到矛盾指令，无所适从 |
| **效果归因缺失** | 无法区分干预来自哪个上游引擎，无法评估哪个引擎的干预更有效 | 干预策略优化缺乏数据支撑 |
| **个性化不足** | 所有学生收到相同模板的干预消息 | 低龄学生觉得冷漠，高龄学生觉得幼稚 |

**NEXUS 解决的核心矛盾：** 在"及时干预帮助学习"和"不过度打扰影响体验"之间找到每个学生的最佳平衡点。

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 信号处理延迟 | 从上游事件到达到干预决策产出 < 500ms（P95） |
| 冲突仲裁准确率 | 不产生矛盾干预组合，矛盾冲突率 < 0.1% |
| 频控命中率 | 单学生单日干预不超过配置上限（默认 5 次/日），超限抑制率 100% |
| 渠道选择合理性 | 干预渠道与场景匹配度（用户调研评分）≥ 4.0/5.0 |
| 干预接受率 | 非忽略干预（学生有正向响应）占比 ≥ 45% |
| 冷却命中率 | 同类干预冷却窗口内重复抑制率 100% |
| 效果反馈延迟 | 干预后 24h 内完成效果标注率 ≥ 80% |
| 系统可用性 | 99.9%（NEXUS 降级时仅关闭干预投递，不影响核心学习流程） |

## 2. 核心数据结构

### 2.1 干预信号统一模型 (InterventionSignal)

所有上游引擎发送的干预信号必须归一为统一格式：

```typescript
interface InterventionSignal {
  // ─── 标识 ───
  signalId: string;              // 信号唯一ID (UUID)
  sourceEngine: SourceEngine;    // 来源引擎
  sourceEventId?: string;        // 上游原始事件ID（用于溯源）

  // ─── 目标 ───
  studentId: number;             // 目标学生
  sessionId?: string;            // 关联学习会话（如有）
  subject?: Subject;             // 关联学科
  knowledgePointId?: number;     // 关联知识点

  // ─── 干预内容 ───
  interventionCategory: InterventionCategory;  // 干预大类
  interventionType: string;      // 干预子类型（各引擎自定义）
  urgency: Urgency;              // 紧急度
  priority: number;              // NEXUS 仲裁用优先级分（0-100，越高越优先）

  // ─── 上下文 ───
  context: {
    learningMode: LearningMode;  // 当前学习模式
    currentPage?: string;        // 当前页面路由
    currentTask?: string;        // 当前任务标识
    timeInSession: number;       // 本会话已用时间（秒）
    timeOnCurrentItem: number;   // 当前题目/内容停留时间（秒）
    recentErrorCount: number;    // 最近错误次数
    consecutiveErrors: number;   // 连续错误次数
  };

  // ─── 建议干预 ───
  suggestedActions: SuggestedAction[];  // 建议的干预动作列表
  preferredChannel?: Channel;    // 来源引擎建议的渠道

  // ─── 元数据 ───
  metadata: Record<string, any>; // 引擎特定扩展数据
  createdAt: string;             // 信号生成时间 (ISO 8601)
  expiresAt: string;             // 过期时间（超时后不再干预）
}

enum SourceEngine {
  LSSA = 'lssa',                          // 学习状态实时感知
  BURNOUT_WARNING = 'burnout_warning',    // 倦怠预警
  CHURN_RISK = 'churn_risk',              // 流失预警
  GOAL_DEVIATION = 'goal_deviation',      // 目标偏离
  RISK_ASSESSMENT = 'risk_assessment',    // 学习风险
  AI_STRATEGY = 'ai_strategy',            // AI辅导策略
  PSYCHOLOGICAL_MODEL = 'psy_model',      // 心理状态建模
  MISTAKE_TRACKER = 'mistake_tracker',    // 错题追踪
  EXTERNAL_API = 'external_api',          // 外部触发（教师/家长/运营）
}

enum InterventionCategory {
  HINT = 'hint',                        // 提示类（做题卡壳、思路引导）
  BREAK = 'break',                      // 休息类（疲劳、长时间学习）
  DIFFICULTY = 'difficulty',            // 难度调整类
  ENCOURAGEMENT = 'encouragement',      // 鼓励类（连续错误后、考试前）
  REDIRECT = 'redirect',                // 转向类（换内容、换学科）
  PLAN_ADJUST = 'plan_adjust',          // 计划调整类
  REVIEW = 'review',                    // 复习类（遗忘曲线触发）
  WELLBEING = 'wellbeing',              // 身心健康类（过度疲劳、压力过大）
  PARENT_NOTIFICATION = 'parent_notify', // 家长通知类
  OPERATIONAL = 'operational',          // 运营类（活动、权益提醒）
}

enum Urgency {
  IMMEDIATE = 'immediate',  // 立即（秒级）
  HIGH = 'high',            // 高（分钟级）
  NORMAL = 'normal',        // 正常（可排队）
  LOW = 'low',              // 低（可延迟到下次会话）
}

enum LearningMode {
  AI_TUTORING = 'ai_tutoring',
  PRACTICE = 'practice',
  EXAM = 'exam',
  READING = 'reading',
  REVIEW = 'review',
  MEMORIZATION = 'memorization',
  PHOTO_SEARCH = 'photo_search',
  WRITING = 'writing',
  IDLE = 'idle',
}

interface SuggestedAction {
  actionType: ActionType;
  title: string;             // 简短标题
  description: string;       // 描述
  payload: Record<string, any>; // 动作参数
  dismissible: boolean;      // 是否允许学生关闭
  cooldownCategory?: string; // 冷却分类（同分类共享冷却窗口）
}

enum ActionType {
  INLINE_HINT = 'inline_hint',              // 内联提示（当前页面内）
  FLOATING_ASSISTANT = 'floating_assistant', // 浮窗AI助手消息
  AI_MESSAGE = 'ai_message',                 // AI对话消息
  MODAL_DIALOG = 'modal_dialog',             // 模态弹窗
  TOAST = 'toast',                           // 轻提示
  PUSH_NOTIFICATION = 'push_notification',   // 推送通知
  PARENT_MESSAGE = 'parent_message',         // 家长消息
  DIFFICULTY_CHANGE = 'difficulty_change',   // 难度切换
  CONTENT_SWITCH = 'content_switch',         // 内容切换
  BREAK_REMINDER = 'break_reminder',         // 休息提醒
  PLAN_RESHUFFLE = 'plan_reshuffle',         // 计划重排
}

enum Channel {
  INLINE = 'inline',              // 当前页面内联
  FLOATING = 'floating',          // 全局浮窗
  DIALOG = 'dialog',              // 模态弹窗
  AI_CHAT = 'ai_chat',            // AI对话流
  PUSH = 'push',                  // 系统推送
  IN_APP_MESSAGE = 'in_app_msg',  // 站内信
  PARENT_PUSH = 'parent_push',    // 家长端推送
  EMAIL = 'email',                // 邮件
  SMS = 'sms',                    // 短信（仅紧急家长通知）
}
```

### 2.2 干预决策结果 (InterventionDecision)

NEXUS 仲裁后产出的决策：

```typescript
interface InterventionDecision {
  decisionId: string;             // 决策ID
  signalIds: string[];            // 合并的源信号ID列表
  studentId: number;

  // ─── 决策结果 ───
  action: ActionType;             // 最终选择的干预动作
  channel: Channel;               // 最终投递渠道
  message: InterventionMessage;   // 个性化后的消息内容
  priority: number;               // 最终优先级 (0-100)

  // ─── 抑制记录 ───
  suppressedSignals: SuppressedSignal[]; // 被抑制的信号及原因

  // ─── 调度 ───
  scheduledAt: string;            // 计划投递时间
  expiresAt: string;              // 过期时间

  // ─── 策略标记 ───
  strategyId?: string;            // 关联的策略ID（A/B测试用）
  experimentVariant?: string;     // 实验分组

  // ─── 追踪 ───
  status: DecisionStatus;
  deliveredAt?: string;
  acknowledgedAt?: string;        // 学生看到并响应的时间
  outcome?: InterventionOutcome;  // 干预结果
}

enum DecisionStatus {
  PENDING = 'pending',
  DELIVERED = 'delivered',
  ACKNOWLEDGED = 'acknowledged',
  DISMISSED = 'dismissed',        // 学生主动关闭
  EXPIRED = 'expired',
  FAILED = 'failed',
}

interface InterventionMessage {
  title: string;
  body: string;
  ctaButtons: CTAButton[];        // 行动按钮
  tone: MessageTone;              // 语气
  emoji?: string;                 // 表情（低龄学生）
  imageUrl?: string;             // 配图
}

enum MessageTone {
  WARM = 'warm',           // 温暖关怀
  ENCOURAGING = 'encouraging', // 鼓励激励
  NEUTRAL = 'neutral',     // 中性信息
  PLAYFUL = 'playful',     // 活泼有趣（低龄）
  SERIOUS = 'serious',     // 严肃（如家长通知）
}

interface CTAButton {
  label: string;
  action: string;            // 深链接或动作标识
  style: 'primary' | 'secondary' | 'text';
  dismissAfterClick: boolean;
}

interface SuppressedSignal {
  signalId: string;
  reason: SuppressReason;
  rescheduleAt?: string;    // 延迟重新评估的时间
}

enum SuppressReason {
  FREQUENCY_CAP = 'frequency_cap',     // 超出频控
  COOLDOWN_ACTIVE = 'cooldown_active', // 冷却中
  CONFLICT_WINNER = 'conflict_winner', // 被更高优先级干预覆盖
  STRATEGY_MUTUAL_EXCLUSION = 'mutual_exclusion', // 策略互斥
  USER_PREFERENCE = 'user_preference', // 学生偏好不接收此类
  OFF_HOURS = 'off_hours',             // 非允许时段
  RECENTLY_SHOWN = 'recently_shown',   // 最近展示过相似干预
}

interface InterventionOutcome {
  outcomeType: OutcomeType;
  responseTimeSec?: number;     // 从投递到响应的时间
  immediateEffect?: boolean;    // 是否产生即时效果
  followupMetric?: {            // 后续指标变化
    metric: string;
    beforeValue: number;
    afterValue: number;
  };
}

enum OutcomeType {
  ACCEPTED = 'accepted',       // 学生接受了建议（点击CTA）
  DISMISSED = 'dismissed',     // 学生关闭了提示
  IGNORED = 'ignored',         // 学生未做任何响应
  PARTIAL = 'partial',         // 部分接受
  NEGATIVE = 'negative',       // 明确拒绝（如"不要再提醒"）
}
```

### 2.3 频控配置模型 (FrequencyConfig)

```typescript
interface FrequencyConfig {
  studentId: number;
  configType: ConfigType;

  // ─── 会话级频控 ───
  maxInterventionsPerSession: number;     // 单次会话最大干预数（默认 2）
  minIntervalBetweenInterventionsSec: number; // 两次干预最小间隔（默认 120s）

  // ─── 日级频控 ───
  maxInterventionsPerDay: number;         // 每日最大干预数（默认 5）
  maxByCategory: Record<InterventionCategory, number>; // 分类上限

  // ─── 冷却窗口 ───
  cooldowns: CooldownRule[];              // 冷却规则

  // ─── 时间窗口 ───
  allowedTimeWindows: TimeWindow[];       // 允许干预的时段
  quietHours: QuietHours;                 // 免打扰时段

  // ─── 偏好 ───
  channelPreferences: ChannelPreference[];
  categoryPreferences: CategoryPreference[];

  // ─── 自适应 ───
  sensitivityLevel: SensitivityLevel;     // 干预敏感度（影响频率上限）
  autoTuneEnabled: boolean;               // 是否开启自动调优
}

enum ConfigType {
  DEFAULT = 'default',       // 系统默认
  AGE_BASED = 'age_based',   // 按学段预设
  CUSTOM = 'custom',         // 家长/学生自定义
  ADAPTIVE = 'adaptive',     // 系统自适应调整
}

interface CooldownRule {
  category: InterventionCategory;
  cooldownSec: number;       // 冷却时长
  scope: CooldownScope;      // 冷却范围
}

enum CooldownScope {
  SESSION = 'session',       // 当前会话内
  DAILY = 'daily',           // 当天内
  GLOBAL = 'global',         // 跨会话跨天
}

interface TimeWindow {
  dayOfWeek: number[];       // 0=周日, 1-6=周一至周六
  startHour: number;
  endHour: number;
}

interface QuietHours {
  startHour: number;         // 22
  endHour: number;           // 7
  overrideForUrgency: Urgency[]; // 哪些紧急度可突破
}

interface ChannelPreference {
  channel: Channel;
  enabled: boolean;
```

```java
@Component
public class SignalNormalizer {

    /**
     * 将不同来源引擎的事件格式归一化为统一的 InterventionSignal
     */
    public InterventionSignal normalize(JsonNode raw, Headers headers) {
        String source = headers.lastHeader("source-engine").value();

        return switch (source) {
            case "lssa" -> normalizeFromLSSA(raw);
            case "burnout_warning" -> normalizeFromBurnout(raw);
            case "churn_risk" -> normalizeFromChurn(raw);
            case "goal_deviation" -> normalizeFromGoalDeviation(raw);
            case "risk_assessment" -> normalizeFromRisk(raw);
            case "ai_strategy" -> normalizeFromAIStrategy(raw);
            default -> normalizeGeneric(raw, source);
        };
    }

    /**
     * LSSA 事件归一化示例
     * LSSA 发布格式:
     * { "eventType": "lssa.intervention.recommended", "sessionId": "...", "state": "frustrated", ... }
     */
    private InterventionSignal normalizeFromLSSA(JsonNode raw) {
        InterventionSignal signal = new InterventionSignal();
        signal.setSignalId(UUID.randomUUID().toString());
        signal.setSourceEngine(SourceEngine.LSSA);
        signal.setSourceEventId(raw.path("eventId").asText());
        signal.setStudentId(raw.path("studentId").asLong());
        signal.setSessionId(raw.path("sessionId").asText());

        // LSSA 的 interventionType 直接映射
        String lssaType = raw.path("interventionType").asText();
        signal.setInterventionCategory(mapLSSAToCategory(lssaType));
        signal.setInterventionType(lssaType);

        // 紧急度：LSSA 的 frustrated/struggling 状态为 IMMEDIATE
        String state = raw.path("state").asText();
        signal.setUrgency(determineUrgency(state, raw.path("sessionQualityScore").asDouble()));

        // 优先级：LSSA 的 SQS 评分影响优先级
        double sqs = raw.path("sessionQualityScore").asDouble(0.5);
        signal.setPriorityScore(calculatePriority(sqs, signal.getUrgency(), signal.getCategory()));

        // 上下文
        signal.setContext(extractContext(raw));

        // 建议动作
        signal.setSuggestedActions(extractActions(raw));

        // 过期时间：IMMEDIATE 干预 60s 内有效
        Duration ttl = signal.getUrgency() == Urgency.IMMEDIATE
            ? Duration.ofSeconds(60)
            : Duration.ofMinutes(5);
        signal.setExpiresAt(Instant.now().plus(ttl));

        return signal;
    }

    /**
     * 通用归一化：处理未适配来源或外部API触发
     */
    private InterventionSignal normalizeGeneric(JsonNode raw, String source) {
        InterventionSignal signal = new InterventionSignal();
        signal.setSignalId(UUID.randomUUID().toString());
        signal.setSourceEngine(SourceEngine.EXTERNAL_API);
        signal.setStudentId(raw.path("studentId").asLong());
        signal.setInterventionCategory(
            InterventionCategory.valueOf(raw.path("category").asText("encouragement").toUpperCase())
        );
        signal.setInterventionType(raw.path("type").asText("generic"));
        signal.setUrgency(Urgency.valueOf(raw.path("urgency").asText("normal").toUpperCase()));
        signal.setPriorityScore(raw.path("priority").asInt(50));
        signal.setCreatedAt(Instant.now());
        signal.setExpiresAt(Instant.now().plus(Duration.ofMinutes(10)));
        return signal;
    }

    private InterventionCategory mapLSSAToCategory(String lssaType) {
        return switch (lssaType) {
            case "HINT" -> InterventionCategory.HINT;
            case "BREAK" -> InterventionCategory.BREAK;
            case "DIFFICULTY_DOWN", "DIFFICULTY_UP" -> InterventionCategory.DIFFICULTY;
            case "TOPIC_SWITCH" -> InterventionCategory.REDIRECT;
            default -> InterventionCategory.ENCOURAGEMENT;
        };
    }

    private short calculatePriority(double sqs, Urgency urgency, InterventionCategory category) {
        // 基础分：SQS越低优先级越高
        short base = (short)(100 - (int)(sqs * 100));

        // 紧急度加成
        base += switch (urgency) {
            case IMMEDIATE -> 20;
            case HIGH -> 10;
            case NORMAL -> 0;
            case LOW -> -10;
        };

        // 类别权重：身心健康类最高优先级
        base += switch (category) {
            case WELLBEING -> 15;
            case BREAK -> 10;
            case HINT -> 5;
            default -> 0;
        };

        return (short) Math.clamp(base, 0, 100);
    }
}
```

### 4.2 冲突仲裁流程

当多个信号在同一时间窗口（默认 5 秒去抖窗口）内到达时，NEXUS 执行冲突仲裁：

```
┌──────────────────────────────────────────────────────────────────┐
│                      冲突仲裁引擎流程                             │
│                                                                  │
│  Signal A (LSSA, HINT, priority=75, immediate)                   │
│  Signal B (Burnout, BREAK, priority=80, high)         ───┐       │
│  Signal C (GoalDev, PLAN_ADJUST, priority=60, normal)    │       │
│                                                          │       │
│  ┌─────────────────────────────────────────────────┐     │       │
│  │  Step 1: 去抖窗口聚合 (5s tumbling window)       │ ◀───┘       │
│  │  → [A, B, C] 同一批次                              │            │
│  └──────────────────────┬──────────────────────────┘            │
│                         │                                        │
│  ┌──────────────────────▼──────────────────────────┐            │
│  │  Step 2: 互斥策略检测                              │            │
│  │  策略矩阵: HINT ⊥ BREAK (不能同时提示和叫休息)      │            │
│  │  策略矩阵: DIFFICULTY ⊥ ENCOURAGEMENT (矛盾)       │            │
│  │  → 发现冲突: A(HINT) vs B(BREAK)                   │            │
│  └──────────────────────┬──────────────────────────┘            │
│                         │                                        │
│  ┌──────────────────────▼──────────────────────────┐            │
│  │  Step 3: 优先级仲裁                                │            │
│  │  A.priority=75 (immediate+20)  → 实际 95           │            │
│  │  B.priority=80 (high+10)       → 实际 90           │            │
│  │  → 胜出: A (HINT)                                  │            │
│  │  → 抑制: B (BREAK) → reason=CONFLICT_WINNER        │            │
│  │  → 延迟: C (PLAN_ADJUST) → 延迟到会话结束后         │            │
│  └──────────────────────┬──────────────────────────┘            │
│                         │                                        │
│  ┌──────────────────────▼──────────────────────────┐            │
│  │  Step 4: 信号合并 (同类别可合并)                    │            │
│  │  如果 A 和 C 都是 HINT 类，可合并为一条增强提示      │            │
│  └──────────────────────┬──────────────────────────┘            │
│                         │                                        │
│  ┌──────────────────────▼──────────────────────────┐            │
│  │  Step 5: 输出仲裁决策                              │            │
│  │  → 胜出信号 A → 进入频控检查                        │            │
│  │  → 抑制记录写入 suppressed_signals                 │            │
│  └──────────────────────────────────────────────────┘            │
└──────────────────────────────────────────────────────────────────┘
```

```java
@Service
public class ConflictArbitrator {

    private static final Duration DEDOUNCE_WINDOW = Duration.ofSeconds(5);

    private final StrategyMatrixRepository strategyMatrixRepo;

    /**
     * 对一批信号执行冲突仲裁
     * @param signals 同一去抖窗口内的信号列表
     * @return 仲裁结果（胜出信号 + 被抑制信号）
     */
    public ArbitrationResult arbitrate(List<InterventionSignal> signals) {
        ArbitrationResult result = new ArbitrationResult();

        // 1. 按优先级排序（含紧急度加成后的最终分）
        signals.sort((a, b) -> Integer.compare(
            effectivePriority(b), effectivePriority(a)
        ));

        // 2. 获取生效的策略矩阵
        List<StrategyMatrix> activeStrategies = strategyMatrixRepo.findActiveStrategies();

        // 3. 贪心选择：从最高优先级开始，依次检查是否与已选信号冲突
        Set<InterventionCategory> selectedCategories = new HashSet<>();
        List<InterventionSignal> winners = new ArrayList<>();

        for (InterventionSignal signal : signals) {
            if (isExpired(signal)) {
                result.addSuppressed(signal, SuppressReason.EXPIRED, null);
                continue;
            }

            // 检查与已选信号是否互斥
            boolean hasConflict = false;
            for (InterventionSignal winner : winners) {
                if (isMutuallyExclusive(signal, winner, activeStrategies)) {
                    result.addSuppressed(signal, SuppressReason.CONFLICT_WINNER, null);
                    hasConflict = true;
                    break;
                }
            }

            if (!hasConflict) {
                // 检查是否可以与已有信号合并
                boolean merged = false;
                for (InterventionSignal winner : winners) {
                    if (canMerge(signal, winner)) {
                        winner.merge(signal);
                        result.addMerged(signal, winner);
                        merged = true;
                        break;
                    }
                }

                if (!merged) {
                    winners.add(signal);
                    selectedCategories.add(signal.getInterventionCategory());
                }
            }
        }

        result.setWinners(winners);
        return result;
    }

    /**
     * 判断两个信号是否互斥
     */
    private boolean isMutuallyExclusive(InterventionSignal a, InterventionSignal b,
                                         List<StrategyMatrix> strategies) {
        // 规则1: 同类干预互斥（同一学生同一时间不需要两个HINT）
        if (a.getInterventionCategory() == b.getInterventionCategory()
            && !canMerge(a, b)) {
            return true;
        }

        // 规则2: 策略矩阵定义的互斥
        for (StrategyMatrix strategy : strategies) {
            Set<String> mutexSet = new HashSet<>(Arrays.asList(strategy.getMutexWith()));
            String keyA = strategyKey(strategy, a);
            String keyB = strategyKey(strategy, b);

            if (mutexSet.contains(keyA) && keyB != null
                && strategyApplies(strategy, a) && strategyApplies(strategy, b)) {
                return true;
            }
        }

        // 规则3: 语义互斥
        // DIFFICULTY_DOWN ⊥ DIFFICULTY_UP (不能同时升降难度)
        if (isOppositeDifficulty(a, b)) return true;

        // BREAK ⊥ 一切非IMMEDIATE干预（学生休息期间不打扰）
        if ((a.getInterventionCategory() == BREAK && b.getUrgency() != IMMEDIATE)
            || (b.getInterventionCategory() == BREAK && a.getUrgency() != IMMEDIATE)) {
            return true;
        }

        return false;
    }

    /**
     * 判断两个同类信号是否可以合并
     */
    private boolean canMerge(InterventionSignal a, InterventionSignal b) {
        // 同类别 + 同学科 + 同知识点 → 合并
        if (a.getInterventionCategory() == b.getInterventionCategory()
            && Objects.equals(a.getSubject(), b.getSubject())
            && Objects.equals(a.getKnowledgePointId(), b.getKnowledgePointId())) {
            return true;
        }

        // 多来源的 HINT 类信号可合并（LSSA + AI Strategy 都建议提示）
        if (a.getInterventionCategory() == HINT && b.getInterventionCategory() == HINT) {
            return true;
        }

        return false;
    }

    private int effectivePriority(InterventionSignal signal) {
        int base = signal.getPriorityScore();
        base += signal.getUrgency() == IMMEDIATE ? 20
              : signal.getUrgency() == HIGH ? 10 : 0;
        return Math.clamp(base, 0, 100);
    }
}
```

### 4.3 频控与冷却检查流程

```java
@Service
public class FrequencyController {

    private final FrequencyConfigRepository configRepo;
    private final FrequencyStateRepository stateRepo;
    private final CooldownRepository cooldownRepo;
    private final RedisTemplate<String, String> redis;

    /**
     * 检查信号是否通过频控与冷却检查
     * @return 通过返回true，否则返回抑制原因
     */
    public FrequencyCheckResult check(InterventionSignal signal) {
        Long studentId = signal.getStudentId();
        FrequencyConfig config = configRepo.findByStudentId(studentId)
            .orElseGet(() -> getDefaultConfig(studentId));
        FrequencyState state = stateRepo.findByStudentId(studentId)
            .orElseGet(() -> initFrequencyState(studentId));

        // 1. 免打扰时段检查
        if (isInQuietHours(config, signal)) {
            if (!config.getQuietHours().canOverride(signal.getUrgency())) {
                return FrequencyCheckResult.suppress(SuppressReason.OFF_HOURS);
            }
        }

        // 2. 日级频控检查
        ensureDayRollforward(state);
        if (state.getDayCount() >= applySensitivity(config.getMaxPerDay(), config.getSensitivityLevel())) {
            return FrequencyCheckResult.suppress(SuppressReason.FREQUENCY_CAP);
        }

        // 3. 分类频控检查
        int categoryCount = state.getCategoryCount(signal.getInterventionCategory());
        int categoryLimit = config.getCategoryLimit(signal.getInterventionCategory());
        if (categoryCount >= categoryLimit) {
            return FrequencyCheckResult.suppress(SuppressReason.FREQUENCY_CAP);
        }

        // 4. 会话级频控检查
        if (signal.getSessionId() != null
            && signal.getSessionId().equals(state.getSessionId())) {
            if (state.getSessionCount() >= config.getMaxPerSession()) {
                return FrequencyCheckResult.suppress(SuppressReason.FREQUENCY_CAP);
            }
        }

        // 5. 最小间隔检查
        if (state.getLastInterventionAt() != null) {
            long secondsSinceLast = Duration.between(
                state.getLastInterventionAt(), Instant.now()
            ).getSeconds();
            if (secondsSinceLast < config.getMinIntervalSec()) {
                return FrequencyCheckResult.suppress(SuppressReason.RECENTLY_SHOWN);
            }
        }

        // 6. 冷却窗口检查
        Optional<CooldownEntry> activeCooldown = findActiveCooldown(
            studentId, signal.getInterventionCategory(),
            signal.getSuggestedActions().getCooldownCategory(),
            signal.getSessionId()
        );
        if (activeCooldown.isPresent()) {
            return FrequencyCheckResult.suppress(SuppressReason.COOLDOWN_ACTIVE);
        }

        // 7. 偏好检查
        if (!config.isCategoryEnabled(signal.getInterventionCategory())) {
            return FrequencyCheckResult.suppress(SuppressReason.USER_PREFERENCE);
        }

        return FrequencyCheckResult.pass();
    }

    /**
     * 根据学生敏感度调整频率上限
     */
    private int applySensitivity(int baseLimit, SensitivityLevel level) {
        return switch (level) {
            case HIGH -> Math.max(1, (int)(baseLimit * 0.6));    // 减少40%
            case NORMAL -> baseLimit;
            case LOW -> (int)(baseLimit * 1.4);                   // 增加40%
        };
    }

    /**
     * 在 Redis 中执行原子性的频控计数（防止并发突破）
     */
    public boolean tryConsumeQuota(Long studentId, InterventionCategory category,
                                    FrequencyConfig config) {
        String dayKey = nexus:freq:{studentId}:day:{today()}
        String catKey = nexus:freq:{studentId}:cat:{category}:{today()}

        // Lua 脚本保证原子性
        String luaScript = """
            local dayCount = tonumber(redis.call('GET', KEYS[1]) or '0')
            local catCount = tonumber(redis.call('GET', KEYS[2]) or '0')

            if dayCount >= tonumber(ARGV[1]) then
                return 0
            end
            if catCount >= tonumber(ARGV[2]) then
                return 0
            end

            redis.call('INCR', KEYS[1])
            redis.call('EXPIRE', KEYS[1], 86400)
            redis.call('INCR', KEYS[2])
            redis.call('EXPIRE', KEYS[2], 86400)
            return 1
        """;

        Long result = redis.execute(
            new DefaultRedisScript<>(luaScript, Long.class),
            List.of(dayKey, catKey),
            String.valueOf(config.getMaxPerDay()),
            String.valueOf(config.getCategoryLimit(category))
        );

        return result != null && result == 1L;
    }
}
```

### 4.4 渠道选择流程

```java
@Service
public class ChannelSelector {

    /**
     * 为干预决策选择最优投递渠道
     *
     * 决策因子：
     * 1. 干预类型 → 渠道适配度
     * 2. 学生当前状态 → 是否在前台、是否在学习中
     * 3. 紧急度 → 即时渠道 vs 延迟渠道
     * 4. 学生/家长偏好 → 渠道开关
     * 5. 最近渠道使用 → 避免重复渠道轰炸
     */
    public Channel select(InterventionSignal signal, FrequencyConfig config,
                          StudentPresenceState presence) {
        // 候选渠道集合
        Set<Channel> candidates = getCandidateChannels(signal, config);

        // 如果学生在线且在前台学习 → 优先实时渠道
        if (presence.isAppForeground() && presence.isInLearningSession()) {
            return selectFromOnlineChannels(candidates, signal, presence);
        }

        // 如果学生在线但在后台 → 轻量渠道
        if (presence.isAppBackground()) {
            if (signal.getUrgency() == IMMEDIATE) {
                return Channel.PUSH;  // 紧急用推送拉回
            }
            return Channel.IN_APP_MESSAGE;  // 非紧急等回来再看
        }

        // 离线 → 推送/站内信
        if (signal.getUrgency() == IMMEDIATE || signal.getUrgency() == HIGH) {
            return Channel.PUSH;
        }
        return Channel.IN_APP_MESSAGE;
    }

    private Set<Channel> getCandidateChannels(InterventionSignal signal, FrequencyConfig config) {
        Set<Channel> candidates = new HashSet<>();

        // 根据干预类型映射默认渠道
        switch (signal.getInterventionCategory()) {
            case HINT:
                candidates.addAll(List.of(INLINE, FLOATING, AI_CHAT));
                break;
            case BREAK:
                candidates.addAll(List.of(DIALOG, TOAST_TO_FLOATING()));
                break;
            case DIFFICULTY:
                candidates.add(DIALOG);
                break;
            case ENCOURAGEMENT:
                candidates.addAll(List.of(TOAST, FLOATING, AI_CHAT));
                break;
            case WELLBEING:
                candidates.add(DIALOG);  // 身心健康用弹窗确保看到
                break;
            case PARENT_NOTIFICATION:
                candidates.addAll(List.of(PARENT_PUSH, EMAIL));
                break;
            case PLAN_ADJUST:
                candidates.add(AI_CHAT);  // 通过AI对话自然引导
                break;
            case REVIEW:
                candidates.addAll(List.of(INLINE, FLOATING));
                break;
            default:
                candidates.add(IN_APP_MESSAGE);
        }

        // 过滤掉学生关闭的渠道
        candidates = candidates.stream()
            .filter(ch -> config.isChannelEnabled(ch))
            .collect(Collectors.toSet());

        // 尊重来源引擎的建议渠道
        if (signal.getPreferredChannel() != null
            && config.isChannelEnabled(signal.getPreferredChannel())) {
            candidates.add(signal.getPreferredChannel());
        }

        return candidates;
    }

    private Channel selectFromOnlineChannels(Set<Channel> candidates,
                                              InterventionSignal signal,
                                              StudentPresenceState presence) {
        // 优先选择不打断学习的渠道
        if (presence.isInActiveAnswering()) {
            // 正在答题中 → 只用浮窗或inline，不用弹窗
            return candidates.contains(FLOATING) ? FLOATING : INLINE;
        }

        if (presence.isInAIConversation()) {
            // 正在和AI对话 → 优先AI_CHAT渠道
            return candidates.contains(AI_CHAT) ? AI_CHAT : FLOATING;
        }

        // 其他在线状态 → 选最高优先级候选
        if (candidates.contains(DIALOG) && signal.getUrgency() == IMMEDIATE) {
            return DIALOG;
        }
        if (candidates.contains(INLINE)) return INLINE;
        if (candidates.contains(FLOATING)) return FLOATING;
        if (candidates.contains(AI_CHAT)) return AI_CHAT;

        return candidates.iterator().next();
    }
}
```

```java
@Service
public class MessagePersonalizer {

    private final StudentProfileService profileService;

    /**
     * 将通用干预内容个性化为目标学生消息

    public InterventionMessage personalize(InterventionSignal signal, Channel channel) {

    private String buildTemplateKey(InterventionSignal signal, StudentProfile profile) {
        return String.format("%s_%s_%s",
            signal.getInterventionCategory().name().toLowerCase(),
            signal.getInterventionType(),
            profile.getGradeLevel().name().toLowerCase()
        );
        // 示例: hint_stuck_primary, break_fatigue_junior, encouragement_consecutive_errors_senior
    }

    private Map<String, Object> buildVariables(InterventionSignal signal, StudentProfile profile) {
        Map<String, Object> vars = new HashMap<>();
        vars.put("studentName", profile.getNickname());
        vars.put("subject", signal.getSubject() != null ? signal.getSubject().getDisplayName() : "学习");
        vars.put("consecutiveErrors", signal.getContext().getConsecutiveErrors());
        vars.put("timeInSession", formatDuration(signal.getContext().getTimeInSession()));
        vars.put("suggestedAction", signal.getSuggestedActions().get(0));

        // 学段特定变量
        switch (profile.getGradeLevel()) {
            case KINDERGARTEN:
            case PRIMARY_LOW:
                vars.put("emoji", pickRandom("🌱", "⭐", "🌈", "🎈"));
                vars.put("encourager", pickRandom("加油", "你可以的", "慢慢来"));
                break;
            case PRIMARY_HIGH:
            case JUNIOR:
                vars.put("emoji", "💪");
                vars.put("encourager", "坚持一下");
                break;
            case SENIOR:
                vars.put("emoji", "");  // 高中不加emoji
                vars.put("encourager", "");
                break;
        }

        return vars;
    }

    /**
     * 渠道适配：不同渠道对消息长度、格式有不同约束
     */
    private InterventionMessage adaptToChannel(InterventionMessage message, Channel channel) {
        return switch (channel) {
            case TOAST -> message.toBuilder()
                .title(truncate(message.getTitle(), 20))
                .body(truncate(message.getBody(), 40))
                .ctaButtons(List.of())  // TOAST不支持按钮
                .build();

            case PUSH -> message.toBuilder()
                .title(truncate(message.getTitle(), 30))
                .body(truncate(message.getBody(), 80))
                .ctaButtons(limit(message.getCtaButtons(), 1))
                .build();

            case DIALOG -> message.toBuilder()
                .ctaButtons(limit(message.getCtaButtons(), 3))
                .build();

            default -> message;
        };
    }

    private MessageTone determineTone(InterventionSignal signal, StudentProfile profile) {
        if (signal.getInterventionCategory() == WELLBEING) {
            return MessageTone.SERIOUS;
        }
        if (profile.getGradeLevel().ordinal() <= GradeLevel.PRIMARY_LOW.ordinal()) {
            return MessageTone.PLAYFUL;
        }
        if (signal.getInterventionCategory() == ENCOURAGEMENT) {
            return MessageTone.ENCOURAGING;
        }
        return MessageTone.WARM;
    }
}
```

```java
@Service
public class InterventionDispatcher {

    private final ChannelSelector channelSelector;
    private final MessagePersonalizer personalizer;
    private final Map<Channel, DeliveryHandler> deliveryHandlers;
    private final FrequencyStateRepository stateRepo;
    private final CooldownRepository cooldownRepo;

    /**
     * 执行干预投递
     */
    @Transactional
    public DispatchResult dispatch(InterventionSignal signal, FrequencyConfig config) {
        // 1. 获取学生在线状态
        StudentPresenceState presence = getPresenceState(signal.getStudentId());

        // 2. 选择渠道
        Channel channel = channelSelector.select(signal, config, presence);

        // 3. 个性化消息
        InterventionMessage message = personalizer.personalize(signal, channel);

        // 4. 创建决策记录
        InterventionDecision decision = createDecision(signal, channel, message);

        // 5. 通过选定渠道投递
        DeliveryHandler handler = deliveryHandlers.get(channel);
        DeliveryResult deliveryResult = handler.deliver(decision);

        // 6. 更新频控状态
        updateFrequencyState(signal.getStudentId(), signal, decision);

        // 7. 设置冷却
        establishCooldown(signal, config);

        // 8. 记录决策
        decisionRepository.save(decision);

        return new DispatchResult(decision, deliveryResult);
    }

    private void updateFrequencyState(Long studentId, InterventionSignal signal,
                                       InterventionDecision decision) {
        FrequencyState state = stateRepo.findByStudentId(studentId).orElseThrow();

        // 原子更新计数
        state.incrementDayCount();
        state.incrementSessionCount(signal.getSessionId());
        state.incrementCategoryCount(signal.getInterventionCategory());
        state.setLastInterventionAt(Instant.now());

        stateRepo.save(state);
    }

    private void establishCooldown(InterventionSignal signal, FrequencyConfig config) {
        // 获取该类别的冷却配置
        Optional<CooldownRule> rule = config.findCooldownRule(signal.getInterventionCategory());
        if (rule.isEmpty()) return;

        CooldownEntry cooldown = new CooldownEntry();
        cooldown.setStudentId(signal.getStudentId());
        cooldown.setCategory(signal.getInterventionCategory());
        cooldown.setScope(rule.get().getScope());
        cooldown.setStartedAt(Instant.now());
        cooldown.setExpiresAt(Instant.now().plusSeconds(rule.get().getCooldownSec()));
        cooldown.setSessionId(signal.getSessionId());

        cooldownRepo.save(cooldown);
    }
```

```java
public class OutcomeTracker {

        // 更新自适应频控模型

            Instant.now().minus(RESPONSE_WINDOW)

            // 超时未响应 → 标记为 IGNORED
            decision.setOutcomeType(OutcomeType.IGNORED);
            decisionRepo.save(decision);

            publishFeedbackEvent(decision, OutcomeType.IGNORED);
        }
    }

     * 24小时后续效果追踪

    @Scheduled(cron = "0 0 * * * *")  // 每小时
```

```java
@Service
public class AdaptiveFrequencyTuner {

    /**
     * 每天凌晨分析近7天干预效果，自动调整频控参数
     */
    @Scheduled(cron = "0 30 3 * * *")  // 每天03:30
    public void autoTune() {
        List<Long> activeStudents = getActiveStudentsLast7Days();

        for (Long studentId : activeStudents) {
            autoTuneForStudent(studentId);
        }
    }

    private void autoTuneForStudent(Long studentId) {
        // 1. 获取近7天干预数据
        WeeklyInterventionStats stats = getWeeklyStats(studentId);

        FrequencyConfig config = configRepo.findByStudentId(studentId).orElseThrow();

        // 2. 计算调整因子
        double adjustFactor = calculateAdjustFactor(stats);

        // 3. 应用调整
        if (config.isAutoTuneEnabled()) {
            int newDailyMax = applyAdjustment(config.getMaxPerDay(), adjustFactor);
            newDailyMax = Math.clamp(newDailyMax, 1, 10);  // 硬限制 [1, 10]

            int newSessionMax = applyAdjustment(config.getMaxPerSession(), adjustFactor);
            newSessionMax = Math.clamp(newSessionMax, 0, 5);

            config.setMaxPerDay(newDailyMax);
            config.setMaxPerSession(newSessionMax);
            config.setTuningAdjustment(adjustFactor);

            // 更新敏感度等级
            if (adjustFactor < -0.15) {
                config.setSensitivityLevel(SensitivityLevel.HIGH);
            } else if (adjustFactor > 0.15) {
                config.setSensitivityLevel(SensitivityLevel.LOW);
            } else {
                config.setSensitivityLevel(SensitivityLevel.NORMAL);
            }

            configRepo.save(config);
        }
    }

    /**
     * 调整因子计算逻辑：
     * - 接受率高 + 忽略率低 → 适当增加干预频率
     * - 接受率低 + 忽略率高 → 减少干预频率
     * - 明确拒绝率高 → 大幅减少
     */
    private double calculateAdjustFactor(WeeklyInterventionStats stats) {
        double acceptRate = (double) stats.acceptedCount / stats.totalCount;
        double dismissRate = (double) stats.dismissedCount / stats.totalCount;
        double ignoreRate = (double) stats.ignoredCount / stats.totalCount;
        double negativeRate = (double) stats.negativeCount / stats.totalCount;

        // 加权计算
        double score = acceptRate * 1.0 + dismissRate * 0.0
                     - ignoreRate * 0.5 - negativeRate * 1.0;

        // 映射到 [-0.3, +0.3] 范围
        return Math.clamp(score * 0.3, -0.3, 0.3);
    }

    private int applyAdjustment(int current, double factor) {
        return (int) Math.round(current * (1.0 + factor));
    }
}
```

## 9. 错误处理与降级策略

### 9.1 降级矩阵

| 故障场景 | 降级策略 | 用户影响 |
|---------|---------|---------|
| NEXUS 服务不可用 | 上游引擎本地降级：各引擎自行决定是否直接投递简单干预 | 干预可能重复，但不会完全缺失 |
| Redis 不可用（频控失效） | 降级为数据库计数，允许一定程度的并发突破 | 频控可能不够精确，但不会完全失效 |
| 数据库不可用 | 信号写入失败 → 丢弃非IMMEDIATE信号；IMMEDIATE信号走纯内存决策 | 决策记录丢失，可通过客户端日志补偿 |
| Kafka 不可用 | 上游引擎切换为 HTTP 直推模式 | 延迟略增，功能不受影响 |
| WebSocket 推送失败 | 自动降级为下次 App 打开时的 pending 拉取 | 实时性降低 |
| 推送服务不可用 | 降级为站内信，标记 `delivery_failed` 等待重试 | 离线用户延迟收到 |
| AI 对话注入失败 | 降级为浮窗提示 | 展示形式略有不同 |

### 9.2 核心保护逻辑

```java
@Component
public class DegradationManager {

    private final CircuitBreaker circuitBreaker;
    private final AtomicBoolean redisAvailable = new AtomicBoolean(true);
    private final AtomicBoolean dbAvailable = new AtomicBoolean(true);

    /**
     * 主处理入口，包含降级逻辑
     */
    public void processSignal(InterventionSignal signal) {
        try {
            if (!circuitBreaker.isAllowed()) {
                // 熔断状态：仅处理 IMMEDIATE 信号
                if (signal.getUrgency() != Urgency.IMMEDIATE) {
                    return;
                }
                bypassDirectDelivery(signal);
                return;
            }

            // 正常处理流程
            processWithFullPipeline(signal);

        } catch (Exception e) {
            log.error("NEXUS processing failed for signal {}", signal.getSignalId(), e);
            circuitBreaker.recordFailure();

            // 降级：直接简单投递
            bypassDirectDelivery(signal);
        }
    }

    /**
     * 降级模式：跳过仲裁和频控，直接简单投递
     * 仅保留最基础的频控（内存计数器）
     */
    private void bypassDirectDelivery(InterventionSignal signal) {
        // 内存级频控（防爆炸）
        String key = "bypass:" + signal.getStudentId();
        if (memoryRateLimiter.tryAcquire(key, 3, Duration.ofHours(1))) {
            // 直接选最简单的渠道投递
            simpleDeliveryService.deliver(signal);
        }
    }
}
```
