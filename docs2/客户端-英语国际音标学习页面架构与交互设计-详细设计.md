## 1. 模块概述

### 1.1 功能定位

本文档是英语国际音标(IPA,内部代号 IPAE-UI)学习域的**客户端呈现层权威**,兑现服务端引擎 v1.0 交付后客户端页面层的零覆盖缺口。

经全目录关键词扫描确认(2026-11-24,`音标/phonetic symbol/IPA`):服务端 IPAE 引擎文档命中;客户端侧既有《客户端-英语专项学习页面架构与交互设计》仅英语学科入口总览、《客户端-自然拼读学习页面架构与交互设计》覆盖幼儿字母音(Phonics)、发音陪练/朗读评估覆盖词句朗读,均不含 IPA 符号体系的课程学习/辨音/见标拼读/听音写标/中式错音诊断页面。本文补齐该缺口(模式同批次(四十)棋类/(四十六)词语辨析/(五十一)传统语汇:服务端已就绪→客户端页面层补全)。

音标页面的核心交互是**音素级的听说双向训练**:学生进入学习路径(摸底快测定位起点)→ 浏览学习卡(符号/口型/要领/示范音/示例词)→ 六类练习会话(听音辨标/见标拼读/听音写标/音素跟读/最小对立对)→ 语音评测(GOP)即时反馈 → 掌握度全景沉淀 → 到期复习与错音诊断纠偏。客户端只做呈现与采集:零判分、零选项重排、未作答前答案零渲染、**录音与音频全链路零留存**。

### 1.3 明确不做(本期)

1. 不做音标**课程编排与掌握度计算**(归服务端引擎,客户端零推断);
2. 不做 GOP 评分/音素对错判定(归口语评估服务,R1 契约,客户端 CI 禁词表);
3. 不做录音本地留存/回放列表/音频文件管理(红线 G6:录音仅存语音服务临时区、评估后销毁);
4. 不做音标键盘/手写符号输入法(听音写标本期为选择式,书写式为服务端题型扩展预留);
5. 不做幼儿段(学前)入口(边界 R8:Phonics 未毕业学前用户访问 fail-closed,49516 引导自然拼读);
6. 不做全服排行榜/班级排名/同伴发音对比(合规 C9,CI 组件白名单);
7. 不做本地判分预演/选项正误预标记/答案键驻留(CI 禁词表);
8. 不做 free talk/情景对话(归口语陪练域,见服务端 §1.3);
9. 不做 KK 音标体系教学(仅学习卡展示对照字段,不展开课程);
10. 不做英语口音(英音/美音)偏好设置(教材版本权威,服务端 §1.3)。

## 3. 页面架构

### 3.1 `/ipa` 音标首页

**布局**:顶部标题"国际音标"+路径进度环(current_unit/unit_count+当前单元名);摸底快测横幅(assess_done=0 时置顶,展示"先花 5 分钟测一测,从适合你的地方开始");单元网格(12 单元卡:单元名+音标符号行内预览+状态:LOCKED 锁/IN_PROGRESS 高亮/COMPLETED 勾+单元测未过角标);到期复习队列卡(dueReviews>0 时展示,符号 chips+到期数+"去复习");错音诊断卡(弱音类别成长型话术,如"θ 和 s 偶尔会混,有 3 个针对性练习",49513 时不渲染该卡);微训练入口卡("生词音标速练",当日已达上限时置灰并展示"明天再来");底部"掌握度全景"与"错音诊断"入口行。

**交互规约**:
- 单元卡点击→49508(单元门控未满足)→不打断,吐司"先把前面的单元练扎实"并引导补救练习入口(服务端 nextStep 驱动);非锁单元→创建会话(POST /ipa/sessions,Idempotency-Key=UUID v7)→跳练习页;点击即置 LOADING 防双击;
- 49503(幂等在途)→静默等待首次受理结果跳同一会话(无感);
- 到期复习数/弱音数全部服务端原样渲染,客户端零计算(R12);
- 骨架屏/错误重试态遵循《客户端-页面状态模式与骨架屏加载空态错误态设计规范》;练习主链路(单元卡)不依赖画像与诊断摘要,首页分区独立加载互不打断;
- 49516(当前学段无路径)→整页"这个学段先学自然拼读"引导态(幼儿)或"暂未开放"诚实态,禁渲染任何题目/路径数据。

### 3.2 `/ipa/quiz` 摸底快测页

**布局**:顶部倒计时(5 分钟,服务端权威时钟,见 §5.3 时钟对齐)+进度条;题目区(快测题型为听音辨标/见标拼读精简版,题面与选项来自 GET /ipa/path 的 quiz 段);底部"提交快测"。

**交互规约**:
- 倒计时展示值=服务端 deadlineAt-本地时钟+serverOffset(建立会话/进页时校准);倒计时归零客户端不自行收卷,提交请求携带已答内容;服务端 5 分钟自动收卷(49512),客户端收到后展示部分成绩(服务端下发多少渲染多少);
- 语音题(见标拼读)在快测中同样走"录音→临时区→assess"链路;额度不足(49521)→该题标记未评测,快测可继续并正常交卷;
- 快测提交(POST /ipa/entry-quiz/submit,client_request_id=UUID v7)→结果页内嵌展示:起步等级+推荐起始单元;完成后自动解锁正式路径(服务端 assess_done 置位),客户端跳 `/ipa` 并刷新;
- 49510(冷却 3 天)→进入即吐司"测过啦,X 天后再来测"并跳回首页;深链接强制进入同样拦截;
- 快测中退出(返回/杀进程)→不自动恢复题目(快照零落盘 G11),重进时 GET /ipa/path 以服务端为准(assess_done 已置位则不再进快测)。

### 3.3 `/ipa/symbol/:symbolId` 学习卡详情页(RECOGNIZE_CARD)

**布局**:顶部大号音标符号(ipa_display,字体渲染委托《客户端-字体资源注册与动态加载引擎》音标字体槽位);KK 对照小字(美音对照,只展示不展开);名称+类别徽标(单元音/双元音/辅音);口型示意图(mouth_shape_url,图片加载框架委托);发音要领卡(articulation_tip 原文渲染);示范音播放大按钮(demo_audio_url);三示例词卡(word+phonetic+audio 逐词播放);底部"练一练"按钮(为该符号发起 PHONEME_REPEAT 单符号会话)。

**交互规约**:
- 49502(符号未发布)→诚实空态"这个音标还在准备中",禁渲染符号数据;
- 49523(示范音不可用降级,服务端随 path/mastery 摘要下发或本页 200 语义体)→播放按钮置灰+提示条"示范音暂不可用,先看口型图和发音要领";口型图与要领照常渲染(服务端 D2 降级语义);
- 示例词音频单条加载失败→该词条播放按钮置灰,禁整页错误;
- "练一练"→创建单符号会话(target 由服务端 symbolId 上下文装配),走 §3.4 练习页;
- 本页零录音,仅播放(G6 前置)。

### 3.4 `/ipa/session/:sessionId` 练习页(核心页)

单页结构:顶部进度条(qno/总数+练习类型标题+目标音标 chips)、主体题型工作区、底部操作条(提交/下一题,末题为"完成练习")。

**通用规约**:
- 题目数据以创建会话响应 questions 为**内存快照 SSOT**(R1/R12),全程禁回源拉取;
- 未作答前,答案相关字段(correctIndex/verdict)在响应中本就不存在,渲染层无答案数据源(G5);CI 模型扫描禁任何"本地答案表";
- 选项原样渲染(服务端已乱序,R3),客户端禁 reshuffle;
- 提交流程:ANSWERING→SUBMITTING/ASSESSING(不可取消,按钮置灰+菊花)→JUDGED(渲染判定)→下一题;每题 clientRequestId=UUID v7 创建即定,弱网重发/进程恢复重放同一键(G7);
- 语音题提交=两段:先上传录音得 audioRef(委托音频引擎),再 POST /ipa/assess;两段整体算一次 ASSESSING 态,用户不可中途取消(取消会破坏服务端配额预扣,服务端 §4.4 预扣-返还裁决)。

**六题型渲染**(IpaItemRendererRegistry 委托分发):

| 题型 | 渲染 | 提交链路 | 预校验(仅格式,零判定) |
| --- | --- | --- | --- |
| RECOGNIZE_CARD(卡浏览) | 学习卡内嵌精简版(符号+示范音+口型图) | 不产生判定,标记浏览完成 | 播放过示范音或停留≥3s 可下一卡(行为采集,非判分) |
| LISTEN_DISCRIMINATE(听音辨标) | 大播放按钮(目标示范音/示例词音)+符号选项列(4 项) | PUT answers/{qno}(selectedIndex) | 必须选中一项;音频未播放可提交但 UI 建议先听(不强制,G5 服务端判) |
| READ_FROM_SYMBOL(见标拼读) | 大号符号+示例词提示+录音大按钮 | 录音→audioRef→POST assess(word 粒度) | 录音时长≥0.5s 且≤15s 格式拦截(服务端 49515 兜底) |
| LISTEN_WRITE(听音写标) | 播放按钮+符号选项列(4 项,本期选择式) | PUT answers/{qno}(selectedIndex) | 必须选中一项 |
| PHONEME_REPEAT(音素跟读) | 示范音播放+录音按钮+波形纯表现动画 | 录音→audioRef→POST assess(phoneme 粒度) | 录音时长 0.5-10s 格式拦截 |
| MINIMAL_PAIR(最小对立对) | 单词音频播放(二选一听到的词)+两个词选项 | PUT answers/{qno}(selectedIndex) | 必须选中一项;49523 降级时本题型服务端已跳过(服务端 D7),客户端若收到仅渲染无音频态并提示 |

**语音评测反馈(ASSESSING→JUDGED)**:
- 评测成功:分龄呈现(服务端 C10):小学阶段三档("很棒!/很接近!/再试一次吧")+星级,**不露分数与音标级明细**;初中起可露分数(gopOverall)+音素级对错明细(errorPhonemes expected→actual 可视呈现);
- feedback.text 服务端原文渲染(正向话术白名单 R5);errorPhonemes 仅初中+且仅答错时渲染;
- verdict=NEED_CONSOLIDATION→"再试一次"主按钮(同题重录重评,assess 幂等键 (sessionId,qno) 5min 锁内重试按服务端在途/首次结果语义);verdict=通过→下一题主按钮;
- masteryDelta 不回显数值,仅埋点(服务端权威,R2)。

**降级诚实渲染**(200 语义帧,全部走正常 JUDGED 通道,不弹全局错误):

```dart
class IpaPracticeController extends ChangeNotifier {
  final IpaApi api;
  final AudioEngine audio;         // 委托:播放+录音+临时区上传(R4/R6)
  List<IpaQuestionView> _queue = [];  // 内存快照 SSOT,零落盘
  int _current = 0;
  MirrorState _state = MirrorState.ready;
  IpaAssessOutcome? _lastAssess;
  IpaJudgeOutcome? _lastJudge;
  String? _sessionId;
  final Map<int, String> _answerKeys = {}; // qno -> clientRequestId(UUID v7,创建即定)

  IpaQuestionView get current => _queue[_current];

  /// 选择题型提交:PUT /ipa/sessions/{id}/answers/{qno}
  Future<void> submitChoice(int selectedIndex) async {
    if (_state == MirrorState.submitting) return;          // G7 防双击
    _state = MirrorState.submitting;
    notifyListeners();
    final key = _answerKeys.putIfAbsent(_current, () => const Uuid().v7());
    try {
      _lastJudge = await api.submitAnswer(
        sessionId: _sessionId!, questionNo: _current,
        clientRequestId: key, selectedIndex: selectedIndex,
      );
      _state = MirrorState.judged;
    } on IpaException catch (e) {
      if (e.code == 49520 || e.code == 49506 || e.code == 49507) {
        await _refreshSessionSnapshot();                   // 服务端权威重取
      } else if (e.code == 49504) {
        _state = MirrorState.expiredLocal;                 // 诚实页
      } else { _state = MirrorState.judgedError; rethrow; }
    } finally { notifyListeners(); }
  }

  /// 语音题型提交:录音(委托音频引擎)→临时区 audioRef→POST /ipa/assess
  /// 全程 ASSESSING 不可取消:取消会破坏服务端额度预扣-返还契约(§5.3 服务端代理)
  Future<void> submitVoice(IpaPracticeType type) async {
    if (_state == MirrorState.assessing) return;
    _state = MirrorState.assessing;
    notifyListeners();
    final key = _answerKeys.putIfAbsent(_current, () => const Uuid().v7());
    File? tmp;                                             // 录音临时文件,G6 必经 CLEANUP
    try {
      tmp = await audio.record(maxDuration: _maxDurationFor(type)); // 权限/编码归音频引擎
      final audioRef = await audio.uploadToVoiceTempZone(tmp);      // voice-tmp:// 引用
      _lastAssess = await api.assess(
        sessionId: _sessionId!, questionNo: _current,
        targetSymbolId: current.targetSymbolId,
        targetText: current.targetText!,
        granularity: type == IpaPracticeType.phonemeRepeat ? 'phoneme' : 'word',
        audioRef: audioRef, clientRequestId: key,
      );
      _state = MirrorState.judged;                         // 含 200 语义降级帧(49521/49522)
    } on IpaException catch (e) {
      if (e.code == 49515) {                               // 音频引用失效:重录引导
        _state = MirrorState.ready;
      } else { _state = MirrorState.judgedError; rethrow; }
    } finally {
      await _cleanup(tmp);                                 // G6:无论成败删除临时文件
      notifyListeners();
    }
  }

  Future<void> _cleanup(File? f) async {                   // R11:零留存断言
    if (f == null) return;
    if (await f.exists()) { await f.delete(); assert(!(await f.exists())); }
  }

  Future<void> complete() async {
    // SCORING 态禁入(在途评测);49509 幂等回放按成功渲染由调用方处理
    final result = await api.complete(_sessionId!);
    router.go('/ipa/session/$_sessionId/result', extra: result);
  }
}
```

```dart
class IpaQuizController extends ChangeNotifier {
  Duration _offset = Duration.zero;      // serverOffset=serverNow-clientNow
  DateTime? _deadlineAt;
  Timer? _ticker;

  Future<void> enter() async {
    final path = await api.getPath();                    // quiz 题目与 deadlineAt 随 path 下发
    _deadlineAt = DateTime.parse(path.quizDeadlineAt!);
    final serverNow = await api.serverTime();            // 轻量时间接口(全局时钟服务)
    _offset = serverNow.difference(DateTime.now());
    _ticker = Timer.periodic(const Duration(seconds: 1), (_) => _tick());
  }

  void _tick() {
    final remain = _deadlineAt!.add(_offset).difference(DateTime.now());
    if (remain <= Duration.zero) {
      _ticker?.cancel();
      // 不归零自行收卷:提交携带已答内容;服务端自动收卷(49512)后展示部分成绩
      notifyListeners();
    } else { notifyListeners(); }
  }

  Future<void> submit(List<IpaQuizAnswer> answers) async {
    // client_request_id 幂等:弱网重发返回首次结果(服务端 §5.1 总览)
    final result = await api.submitEntryQuiz(
      answers: answers, clientRequestId: const Uuid().v7());
    router.go('/ipa');                                   // assess_done 服务端已置位
  }
}
```

```dart
class IpaRouteGuard extends RouteGuard {
  @override
  Future<String?> canActivate(route, context) async {
    // 闸 1:登录态(未登录→登录页带回跳)
    if (!sessionStore.isLoggedIn) return '/login?redirect=${route.location}';
    // 闸 2:学段闸(小高/初中/高中;学前与低龄 fail-closed,与服务端 stage 过滤双保险 R8)
    final stage = profileStore.stage;
    if (stage.index < StudentStage.primary4) return '/ipa/not-available';
    // 闸 3:会话归属与状态(深链练习页/结算页时)
    if (route.path.contains('/session/')) {
      final s = await api.getSession(route.params['sessionId']!);
      if (s.code == 49501) return '/ipa';                  // 会话不存在回首页
      if (s.code == 49504) return '/ipa';                  // 过期回首页(会话详情诚实提示)
      if (s.status == IpaSessionStatus.completed) {
        return '/ipa/session/${route.params['sessionId']}/result'; // 已结算直达结算页(49505 等价)
      }
    }
    // 闸 4(家长页):家长身份+孩子作用域预检
    if (route.path.startsWith('/parent/') && !sessionStore.isParent) return '/home';
    return null;
  }
```

### 6.3 竞态裁决

| # | 竞态 | 裁决 |
| --- | --- | --- |
| 1 | 双击提交(选择/语音) | SUBMITTING/ASSESSING 拒新提交;双请求同 clientRequestId,服务端返回首判,渲染同一结果 |
| 2 | 弱网重发语音评测 | 同键重放;服务端 (sessionId,qno) 锁返回在途/首次结果,客户端不弹"已提交过" |
