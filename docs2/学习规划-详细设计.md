# 学习规划模块 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

学习规划模块根据学生的学段、年级、学科、学习目标和可用时间，生成可执行的个性化学习计划。支持目标设定、计划自动生成、任务拆解、智能调整、提醒机制和计划复盘，形成"目标 → 计划 → 执行 → 反馈"的完整闭环。

### 1.2 覆盖学段

小学至高中（幼儿阶段暂不涉及）

### 1.3 优先级

P1 — V1.0 阶段核心功能

### 1.4 依赖模块

| 依赖模块 | 依赖说明 |
|----------|----------|
| 用户账号体系 | 获取学生学段、年级、教材版本 |
| 同步课堂学习 | 获取章节目录、知识点、掌握度 |
| 错题整理 | 获取高频错题、薄弱知识点 |
| 学情分析 | 获取能力画像、学科掌握度、学习时长 |
| AI 智能辅导 | 大模型生成计划内容 |

## 2. 核心概念与数据模型

### 2.1 目标（Goal）

学生设定的学习目标，是计划生成的源头。

```json
{
  "goal_id": "string, UUID",
  "user_id": "string, 用户ID",
  "title": "string, 目标名称，如'期末考试数学90分以上'",
  "goal_type": "enum: daily | weekly | monthly | exam_preparation | semester",
  "subject_id": "string, 学科ID，null表示全科",
  "target_exam": "string|null, 目标考试，如'期中考试''中考''高考'",
  "target_date": "date, 目标截止日期",
  "current_level": "string, 当前水平自评或系统评估，如'中等''80分左右'",
  "target_level": "string, 目标水平，如'优秀''90分以上'",
  "status": "enum: active | completed | abandoned | expired",
  "created_at": "datetime",
  "updated_at": "datetime"
}
```

**目标类型枚举说明：**

| goal_type | 说明 | 示例 |
|-----------|------|------|
| daily | 每日学习任务目标 | "今天完成5道数学错题复习" |
| weekly | 本周学习目标 | "本周完成第三章预习和复习" |
| monthly | 本月学习目标 | "月考前完成数学前四章巩固" |
| exam_preparation | 考试备考目标 | "期末考试全科提升20分" |
| semester | 学期目标 | "本学期数学进入班级前十" |

### 2.2 学习计划（StudyPlan）

由目标驱动生成的具体学习计划。

```json
{
  "plan_id": "string, UUID",
  "user_id": "string, 用户ID",
  "goal_id": "string, 关联的目标ID",
  "title": "string, 计划标题",
  "plan_type": "enum: daily | weekly | monthly | sprint",
  "status": "enum: draft | active | paused | completed | cancelled",
  "start_date": "date",
  "end_date": "date",
  "total_tasks": "int, 任务总数",
  "completed_tasks": "int, 已完成任务数",
  "estimated_minutes": "int, 预计总学习时长（分钟）",
  "actual_minutes": "int, 实际学习时长（分钟）",
  "difficulty_level": "enum: easy | moderate | intensive",
  "ai_generated": "boolean, 是否AI生成",
  "metadata": {
    "subjects": ["string, 涉及学科ID列表"],
    "chapters": ["string, 涉及章节ID列表"],
    "knowledge_points": ["string, 重点知识点ID列表"],
    "weak_points": ["string, 薄弱知识点（来自学情分析）"],
    "mistake_sources": ["string, 来源错题的知识点"]
  },
  "created_at": "datetime",
  "updated_at": "datetime"
}
```

**计划状态流转：**

```
draft ──(用户确认/AI生成完成)──▶ active
                                    │
                     (用户暂停) ────▶ paused ──(用户恢复)──▶ active
                                    │
                     (全部任务完成) ▶ completed
                                    │
                     (用户取消) ────▶ cancelled
```

### 2.3 学习任务（StudyTask）

计划中的具体可执行任务。

```json
{
  "task_id": "string, UUID",
  "plan_id": "string, 所属计划ID",
  "user_id": "string, 用户ID",
  "title": "string, 任务标题，如'复习第三章：一元一次方程'",
  "task_type": "enum: chapter_study | exercise | mistake_review | ai_tutoring | mock_test | memorization | essay_practice",
  "subject_id": "string, 学科ID",
  "chapter_id": "string|null, 关联章节ID",
  "knowledge_point_ids": ["string, 关联知识点ID列表"],
  "description": "string, 任务详细说明",
  "scheduled_date": "date, 计划执行日期",
  "scheduled_time_start": "time|null, 建议开始时间",
  "scheduled_time_end": "time|null, 建议结束时间",
  "estimated_minutes": "int, 预计耗时（分钟）",
  "actual_minutes": "int|null, 实际耗时",
  "status": "enum: pending | in_progress | completed | skipped | overdue",
  "priority": "enum: high | medium | low",
  "parent_task_id": "string|null, 父任务ID（子任务拆分）",
  "sort_order": "int, 排序序号",
  "ai_prompt_hint": "string|null, AI辅导时的Prompt提示",
  "result_summary": "string|null, 完成后的结果摘要",
  "completed_at": "datetime|null",
  "created_at": "datetime",
  "updated_at": "datetime"
}
```

**任务类型枚举说明：**

| task_type | 说明 | 生成逻辑 |
|-----------|------|----------|
| chapter_study | 章节学习 | 根据教材进度和计划范围生成 |
| exercise | 练习题 | 根据章节/知识点匹配题库 |
| mistake_review | 错题复习 | 根据错题本中待复习错题 |
| ai_tutoring | AI辅导/答疑 | 针对薄弱知识点的专项辅导 |
| mock_test | 模拟测试 | 考前冲刺阶段的模拟练习 |
| memorization | 背诵任务 | 文科背诵、单词记忆等 |
| essay_practice | 作文练习 | 语文/英语作文练习 |

**任务状态流转：**

```
pending ──(开始执行)──▶ in_progress ──(完成)──▶ completed
   │                        │
   │(时间过期)              │(用户跳过)
   ▼                        ▼
 overdue                 skipped
```

## 3. 数据库表设计

### 3.1 goals 表

```sql
CREATE TABLE goals (
    goal_id         VARCHAR(36) PRIMARY KEY,
    user_id         VARCHAR(36) NOT NULL,
    title           VARCHAR(200) NOT NULL,
    goal_type       ENUM('daily','weekly','monthly','exam_preparation','semester') NOT NULL,
    subject_id      VARCHAR(36),
    target_exam     VARCHAR(100),
    target_date     DATE NOT NULL,
    current_level   VARCHAR(100),
    target_level    VARCHAR(100),
    status          ENUM('active','completed','abandoned','expired') NOT NULL DEFAULT 'active',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_status (user_id, status),
    INDEX idx_target_date (target_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.2 study_plans 表

```sql
CREATE TABLE study_plans (
    plan_id             VARCHAR(36) PRIMARY KEY,
    user_id             VARCHAR(36) NOT NULL,
    goal_id             VARCHAR(36),
    title               VARCHAR(200) NOT NULL,
    plan_type           ENUM('daily','weekly','monthly','sprint') NOT NULL,
    status              ENUM('draft','active','paused','completed','cancelled') NOT NULL DEFAULT 'draft',
    start_date          DATE NOT NULL,
    end_date            DATE NOT NULL,
    total_tasks         INT NOT NULL DEFAULT 0,
    completed_tasks     INT NOT NULL DEFAULT 0,
    estimated_minutes   INT NOT NULL DEFAULT 0,
    actual_minutes      INT NOT NULL DEFAULT 0,
    difficulty_level    ENUM('easy','moderate','intensive') NOT NULL DEFAULT 'moderate',
    ai_generated        TINYINT(1) NOT NULL DEFAULT 0,
    metadata_json       JSON,
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_status (user_id, status),
    INDEX idx_goal (goal_id),
    INDEX idx_dates (start_date, end_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.3 study_tasks 表

```sql
CREATE TABLE study_tasks (
    task_id                 VARCHAR(36) PRIMARY KEY,
    plan_id                 VARCHAR(36) NOT NULL,
    user_id                 VARCHAR(36) NOT NULL,
    title                   VARCHAR(200) NOT NULL,
    task_type               ENUM('chapter_study','exercise','mistake_review','ai_tutoring','mock_test','memorization','essay_practice') NOT NULL,
    subject_id              VARCHAR(36),
    chapter_id              VARCHAR(36),
    knowledge_point_ids     JSON,
    description             TEXT,
    scheduled_date          DATE NOT NULL,
    scheduled_time_start    TIME,
    scheduled_time_end      TIME,
    estimated_minutes       INT NOT NULL DEFAULT 15,
    actual_minutes          INT,
    status                  ENUM('pending','in_progress','completed','skipped','overdue') NOT NULL DEFAULT 'pending',
    priority                ENUM('high','medium','low') NOT NULL DEFAULT 'medium',
    parent_task_id          VARCHAR(36),
    sort_order              INT NOT NULL DEFAULT 0,
    ai_prompt_hint          TEXT,
    result_summary          TEXT,
    completed_at            DATETIME,
    created_at              DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at              DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_plan (plan_id),
    INDEX idx_user_date (user_id, scheduled_date),
    INDEX idx_status (user_id, status, scheduled_date),
    FOREIGN KEY (plan_id) REFERENCES study_plans(plan_id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 4. API 接口设计

### 4.1 目标管理

#### 4.1.1 创建目标

```
POST /api/v1/study-planning/goals
```

**请求体：**
```json
{
  "title": "期末考试数学90分以上",
  "goal_type": "exam_preparation",
  "subject_id": "math",
  "target_exam": "期末考试",
  "target_date": "2026-07-01",
  "current_level": "80分左右",
  "target_level": "90分以上"
}
```

**响应：**
```json
{
  "code": 0,
  "data": {
    "goal_id": "g_20260519_abc123",
    "title": "期末考试数学90分以上",
    "goal_type": "exam_preparation",
    "subject_id": "math",
    "target_exam": "期末考试",
    "target_date": "2026-07-01",
    "current_level": "80分左右",
    "target_level": "90分以上",
    "status": "active",
    "created_at": "2026-05-19T15:00:00+08:00"
  }
}
```

**校验规则：**
- `title` 必填，最长200字
- `target_date` 必填，必须晚于当前日期
- `goal_type` 必填，必须是合法枚举值
- 每个用户同一 `goal_type` + `subject_id` 最多 5 个 `active` 状态目标

#### 4.1.2 获取目标列表

```
GET /api/v1/study-planning/goals?status=active&goal_type=exam_preparation&page=1&page_size=20
```

**响应：**
```json
{
  "code": 0,
  "data": {
    "total": 3,
    "items": [
      {
        "goal_id": "g_20260519_abc123",
        "title": "期末考试数学90分以上",
        "goal_type": "exam_preparation",
        "subject_id": "math",
        "target_date": "2026-07-01",
        "status": "active",
        "has_active_plan": true,
        "progress": 0.35
      }
    ]
  }
}
```

#### 4.1.3 更新目标

```
PUT /api/v1/study-planning/goals/{goal_id}
```

可修改字段：`title`, `target_date`, `current_level`, `target_level`, `status`

#### 4.1.4 删除（放弃）目标

```
DELETE /api/v1/study-planning/goals/{goal_id}
```

软删除：将 status 设为 `abandoned`，关联的 active 计划也设为 `cancelled`。

### 4.2 学习计划管理

#### 4.2.1 AI 生成学习计划

```
POST /api/v1/study-planning/plans/generate
```

**请求体：**
```json
{
  "goal_id": "g_20260519_abc123",
  "plan_type": "weekly",
  "start_date": "2026-05-19",
  "end_date": "2026-05-25",
  "daily_available_minutes": 60,
  "preferred_subjects": ["math", "physics"],
  "difficulty_level": "moderate",
  "constraints": {
    "exclude_dates": ["2026-05-21"],
    "preferred_time_slots": [
      {"day_of_week": 1, "start": "19:00", "end": "21:00"}
    ]
  }
}
```

**响应（异步，返回计划草稿）：**
```json
{
  "code": 0,
  "data": {
    "plan_id": "p_20260519_def456",
    "status": "draft",
    "title": "第21周学习计划 — 数学+物理专项提升",
    "estimated_minutes": 300,
    "total_tasks": 12,
    "tasks_preview": [
      {
        "task_id": "t_001",
        "title": "复习：一元二次方程 — 求根公式",
        "task_type": "chapter_study",
        "scheduled_date": "2026-05-19",
        "estimated_minutes": 30,
        "priority": "high"
      },
      {
        "task_id": "t_002",
        "title": "错题复习：一元二次方程相关错题（5道）",
        "task_type": "mistake_review",
        "scheduled_date": "2026-05-19",
        "estimated_minutes": 20,
        "priority": "high"
      }
    ],
    "generation_status": "completed"
  }
}
```

**AI 计划生成 Prompt 模板：**

```
你是一位专业的学习规划师。请根据以下信息为学生生成一份学习计划：

【学生信息】
- 学段/年级：{grade_level}
- 教材版本：{textbook_version}
- 当前水平：{current_level}
- 目标：{goal_title}
- 目标日期：{target_date}

【学情数据】
- 薄弱知识点：{weak_points}
- 近期错题高频章节：{high_mistake_chapters}
- 各科掌握度：{subject_mastery}
- 近7天平均日学习时长：{avg_daily_minutes}分钟

【计划参数】
- 计划类型：{plan_type}
- 起止日期：{start_date} 至 {end_date}
- 每日可用时长：{daily_available_minutes}分钟
- 难度偏好：{difficulty_level}

【输出要求】
1. 按日期拆分每日任务
2. 每日任务总时长不超过{daily_available_minutes}分钟
3. 优先安排薄弱知识点的复习和练习
4. 理科安排分步推导练习，文科安排记忆和背诵
5. 每日至少包含1项错题复习任务（如有待复习错题）
6. 任务类型要多样，避免连续3个相同类型
7. 每个任务包含：标题、类型、预计时长、关联章节/知识点、优先级
8. 以 JSON 格式输出
```

#### 4.2.2 确认并激活计划

```
POST /api/v1/study-planning/plans/{plan_id}/activate
```

将 `draft` 状态的计划改为 `active`，同时创建关联的提醒配置。


```typescript
// services/plan-generator.service.ts

interface PlanGenerationInput {
  goalId: string;
  userId: string;
  planType: 'daily' | 'weekly' | 'monthly' | 'sprint';
  startDate: string;
  endDate: string;
  dailyAvailableMinutes: number;
  preferredSubjects?: string[];
  difficultyLevel: 'easy' | 'moderate' | 'intensive';
  constraints?: {
    excludeDates?: string[];
    preferredTimeSlots?: Array<{ dayOfWeek: number; start: string; end: string }>;
  };
}

interface GeneratedTask {
  title: string;
  taskType: string;
  subjectId: string;
  chapterId?: string;
  knowledgePointIds?: string[];
  scheduledDate: string;
  scheduledTimeStart?: string;
  scheduledTimeEnd?: string;
  estimatedMinutes: number;
  priority: 'high' | 'medium' | 'low';
  description?: string;
  aiPromptHint?: string;
}

export class PlanGeneratorService {
  constructor(
    private readonly studentProfileRepo: StudentProfileRepository,
    private readonly learningAnalyticsRepo: LearningAnalyticsRepository,
    private readonly mistakeRepo: MistakeRepository,
    private readonly planRepo: StudyPlanRepository,
    private readonly taskRepo: StudyTaskRepository,
    private readonly aiService: AIService,
  private readonly promptTemplateService: PromptTemplateService,
  ) {}

  async generatePlan(input: PlanGenerationInput): Promise<StudyPlan> {
    // 1. 收集学生上下文
    const profile = await this.studentProfileRepo.findByUserId(input.userId);
    const analytics = await this.learningAnalyticsRepo.getSubjectMastery(input.userId);
    const weakPoints = await this.learningAnalyticsRepo.getWeakPoints(input.userId);
    const recentMistakes = await this.mistakeRepo.getHighFrequencyMistakes(
      input.userId, { days: 14, limit: 10 }
    );
    const avgDailyMinutes = await this.learningAnalyticsRepo.getAvgDailyMinutes(
      input.userId, 7
    );

    // 2. 构造 Prompt
    const prompt = this.promptTemplateService.render('plan_generation', {
      gradeLevel: `${profile.stage} ${profile.grade}`,
      textbookVersion: profile.textbookVersion,
      currentLevel: profile.currentLevel || '未评估',
      goalTitle: input.goalId, // 会从 goal 表获取
      targetDate: input.endDate,
      weakPoints: weakPoints.map(wp => wp.name).join('、'),
      highMistakeChapters: recentMistakes.map(m => m.chapterName).join('、'),
      subjectMastery: analytics.map(a => `${a.subjectName}: ${a.masteryLevel}`).join('、'),
      avgDailyMinutes: avgDailyMinutes,
      planType: input.planType,
      startDate: input.startDate,
      endDate: input.endDate,
      dailyAvailableMinutes: input.dailyAvailableMinutes,
      difficultyLevel: input.difficultyLevel,
    });

    // 3. 调用 AI 生成
    const aiResponse = await this.aiService.generateStructured<GeneratedTask[]>({
      prompt,
      outputSchema: PLAN_GENERATION_OUTPUT_SCHEMA,
      temperature: 0.7,
      maxTokens: 4000,
    });

    // 4. 校验 AI 输出
    const validatedTasks = this.validateGeneratedTasks(aiResponse, input);

    // 5. 保存计划草稿
    const plan = await this.planRepo.create({
      userId: input.userId,
      goalId: input.goalId,
      title: this.generatePlanTitle(input, profile),
      planType: input.planType,
      status: 'draft',
      startDate: input.startDate,
      endDate: input.endDate,
      totalTasks: validatedTasks.length,
      estimatedMinutes: validatedTasks.reduce((sum, t) => sum + t.estimatedMinutes, 0),
      difficultyLevel: input.difficultyLevel,
      aiGenerated: true,
      metadata: {
        subjects: [...new Set(validatedTasks.map(t => t.subjectId))],
        weakPoints: weakPoints.map(wp => wp.id),
      },
    });

    // 6. 批量创建任务
    const tasks = await this.taskRepo.bulkCreate(
      validatedTasks.map((t, i) => ({
        ...t,
        planId: plan.planId,
        userId: input.userId,
        status: 'pending',
        sortOrder: i,
      }))
    );

    return { ...plan, tasks };
  }

  private validateGeneratedTasks(
    tasks: GeneratedTask[],
    input: PlanGenerationInput
  ): GeneratedTask[] {
    const excludeDates = new Set(input.constraints?.excludeDates ?? []);
    const dailyMinutes = new Map<string, number>();

    return tasks
      .filter(task => {
        // 过滤掉排除日期的任务
        if (excludeDates.has(task.scheduledDate)) return false;
        return true;
      })
      .map(task => {
        // 确保每日时长不超限
        const currentDaily = dailyMinutes.get(task.scheduledDate) ?? 0;
        if (currentDaily + task.estimatedMinutes > input.dailyAvailableMinutes * 1.2) {
          // 超出20%容差则缩减时长
          task.estimatedMinutes = Math.max(
            10,
            input.dailyAvailableMinutes * 1.2 - currentDaily
          );
        }
        dailyMinutes.set(task.scheduledDate, currentDaily + task.estimatedMinutes);
        return task;
      });
  }
}
```

```typescript
// services/smart-adjustment.service.ts

export class SmartAdjustmentService {
  constructor(
    private readonly taskRepo: StudyTaskRepository,
    private readonly planRepo: StudyPlanRepository,
    private readonly analyticsRepo: LearningAnalyticsRepository,
    private readonly aiService: AIService,
  ) {}

  /**
   * 检查并生成调整建议
   * 由定时任务调用
   */
  async checkAndSuggestAdjustments(): Promise<void> {
    const activePlans = await this.planRepo.findActivePlansNeedingCheck();

    for (const plan of activePlans) {
      const shouldAdjust = await this.evaluateNeedForAdjustment(plan);
      if (shouldAdjust) {
        await this.generateAdjustmentSuggestions(plan);
      }
    }
  }

  private async evaluateNeedForAdjustment(plan: StudyPlan): Promise<boolean> {
    const tasks = await this.taskRepo.findByPlanId(plan.planId);
    const completedTasks = tasks.filter(t => t.status === 'completed');
    const overdueTasks = tasks.filter(t => t.status === 'overdue');

    // 规则1：连续完成率过低
    const completionRate = completedTasks.length / tasks.length;
    if (completionRate < 0.5 && overdueTasks.length >= 3) return true;

    // 规则2：进度严重落后
    const now = new Date();
    const totalDays = daysBetween(plan.startDate, plan.endDate);
    const elapsedDays = daysBetween(plan.startDate, now);
    const expectedProgress = elapsedDays / totalDays;
    if (completionRate < expectedProgress * 0.6) return true;

    // 规则3：知识点正确率持续下降
    const recentAccuracy = await this.analyticsRepo.getRecentAccuracy(
      plan.userId, 7
    );
    const previousAccuracy = await this.analyticsRepo.getRecentAccuracy(
      plan.userId, 7, /* offset */ 7
    );
    if (recentAccuracy < previousAccuracy * 0.8) return true;

    return false;
  }

  private async generateAdjustmentSuggestions(plan: StudyPlan): Promise<void> {
    const context = await this.collectAdjustmentContext(plan);
    const suggestions = await this.aiService.generateStructured<AdjustmentSuggestion[]>({
      prompt: this.buildAdjustmentPrompt(plan, context),
      outputSchema: ADJUSTMENT_OUTPUT_SCHEMA,
      temperature: 0.5,
    });

    // 保存建议，等待用户确认
    await this.planRepo.saveAdjustmentSuggestions(plan.planId, suggestions);
  }
}
```

### 7.3 并发控制

- 同一用户同时只能有 **一个活跃的周计划** 和 **一个活跃的月计划**
- 任务状态变更需检查当前状态，使用乐观锁避免并发冲突
- 计划生成接口加分布式锁（key: `plan_gen:{userId}`），防止重复生成

```typescript
// 使用 Redis 分布式锁
async generatePlan(input: PlanGenerationInput): Promise<StudyPlan> {
  const lockKey = `plan_gen:${input.userId}`;
  const lock = await this.redisLock.acquire(lockKey, 30_000); // 30秒超时

  try {
    // 检查是否已有同日期范围活跃计划
    const existingPlan = await this.planRepo.findActiveByDateRange(
      input.userId, input.planType, input.startDate, input.endDate
    );
    if (existingPlan) {
      throw new BusinessError('PLAN_004', '该日期范围已有活跃计划');
    }

    return await this.doGenerate(input);
  } finally {
    await lock.release();
  }
}
```
