# 服务端 - 学生学习风格识别与自适应内容呈现策略服务 详细设计

## 1. 模块概述

### 1.1 功能定位

学生学习风格识别与自适应内容呈现策略服务（Learning Style Identification & Adaptive Content Presentation Service，简称 LSI）是 PrimeTop 学情分析体系的延伸模块。该服务通过持续采集学生的多维度学习行为数据（答题偏好、内容消费模式、交互方式选择、学习时段特征等），自动识别每位学生的学习风格类型，并输出差异化的内容呈现策略，供 AI 辅导、同步课堂、练习推荐等消费方模块使用。

理论基础：**VARK 学习风格模型**（Visual 视觉型、Auditory 听觉型、Read/Write 读写型、Kinesthetic 动觉型），结合 Felder-Silverman 多维学习风格模型中的**信息加工维度**（主动/反思、序列/全局、感知/直觉、视觉/言语）进行扩展。

### 1.2 核心目标

| 目标 | 指标 |
| --- | --- |
| 风格识别准确率 | 冷启动 50 次交互后，风格置信度 ≥ 0.7 |
| 内容适配效果 | 匹配风格的内容完读率比随机推荐高 20%+ |
| 学习效率提升 | 使用风格适配后的 AI 回答，学生二次追问率降低 15% |
| 识别稳定性 | 风格标签 30 天内变化率 < 10%（非过渡期） |
| 响应延迟 | 风格查询接口 P99 < 15ms |

### 1.3 优先级与迭代规划

| 阶段 | 功能范围 | 版本 |
| --- | --- | --- |
| MVP | 基础 VARK 四分类 + 静态风格画像 + 简单策略映射 | V1.0 |
| V1 | 多维风格模型 + 行为流式计算 + 动态策略权重 | V1.5 |
| V2 | 风格-内容 A/B 实验闭环 + 风格演化追踪 + 跨学科风格差异 | V2.0 |

本文档覆盖 **V1 完整设计**，标注 MVP 裁剪范围。

基于 Felder-Silverman 模型的简化子维度：

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| processing | `active` / `reflective` | 主动型偏好边做边学；反思型偏好先理解再练习 |
| perception | `sensing` / `intuitive` | 感知型偏好具体例子和步骤；直觉型偏好概念和规律 |
| understanding | `sequential` / `global` | 序列型偏好按部就班；全局型偏好先看全貌再深入 |

## 5. 风格计算算法

### 5.1 VARK 增量计算（滑动窗口加权平均）

```python
class StyleCalculator:
    """学习风格增量计算器"""
    
    WINDOW_DAYS = 30          # 滑动窗口：30天
    MIN_SAMPLES_FOR_RESULT = 30  # 最低样本量
    CONFIDENCE_THRESHOLD_LOW = 0.4
    CONFIDENCE_THRESHOLD_MID = 0.6
    CONFIDENCE_THRESHOLD_HIGH = 0.75
    DECAY_FACTOR = 0.95       # 时间衰减因子
    
    @staticmethod
    def calculate_vark_scores(events: list[dict]) -> dict:
        """
        基于行为事件列表计算 VARK 分值。
        使用指数时间衰减加权的累积信号。
        """
        now = datetime.utcnow()
        cutoff = now - timedelta(days=StyleCalculator.WINDOW_DAYS)
        
        # 累积加权信号
        signals = {"V": 0.0, "A": 0.0, "R": 0.0, "K": 0.0}
        total_weight = 0.0
        
        for event in events:
            if event["created_at"] < cutoff:
                continue
                
            # 时间衰减：越近的事件权重越高
            days_ago = (now - event["created_at"]).days
            time_weight = StyleCalculator.DECAY_FACTOR ** days_ago
            
            # 信号权重
            v = event.get("visual_signal", 0) * time_weight
            a = event.get("auditory_signal", 0) * time_weight
            r = event.get("readwrite_signal", 0) * time_weight
            k = event.get("kinesthetic_signal", 0) * time_weight
            
            signals["V"] += v
            signals["A"] += a
            signals["R"] += r
            signals["K"] += k
            total_weight += time_weight
        
        if total_weight == 0:
            return {"V": 0.25, "A": 0.25, "R": 0.25, "K": 0.25, 
                    "confidence": 0.0, "sample_count": 0}
        
        # 归一化
        total_signal = sum(signals.values())
        if total_signal == 0:
            normalized = {k: 0.25 for k in signals}
        else:
            normalized = {k: round(v / total_signal, 4) for k, v in signals.items()}
        
        # 置信度计算：基于样本量和分值区分度
        sample_count = len([e for e in events if e["created_at"] >= cutoff])
        score_spread = max(normalized.values()) - min(normalized.values())
        
        # 置信度 = min(样本充分度, 分值区分度)
        sample_factor = min(1.0, sample_count / 100)  # 100样本达到满值
        spread_factor = min(1.0, score_spread / 0.3)  # 0.3差异达到满值
        confidence = round(sample_factor * spread_factor, 4)
        
        return {
            **{k[0] if k != "R" else "R": v for k, v in normalized.items()},
            "confidence": confidence,
            "sample_count": sample_count
        }
    
    @staticmethod
    def determine_primary_style(vark_scores: dict) -> tuple[str, str | None]:
        """
        判定主/次风格。
        规则：
        - 最高分 ≥ 次高分 * 1.3 → 单一主风格
        - 最高分与次高分差距 < 1.3 倍 → 双风格（MULTIMODAL 或 secondary）
        - 样本不足 → UNKNOWN
        """
        if vark_scores["sample_count"] < StyleCalculator.MIN_SAMPLES_FOR_RESULT:
            return "UNKNOWN", None
        
        sorted_styles = sorted(
            [("VISUAL", vark_scores["V"]), ("AUDITORY", vark_scores["A"]),
             ("READ_WRITE", vark_scores["R"]), ("KINESTHETIC", vark_scores["K"])],
            key=lambda x: x[1], reverse=True
        )
        
        primary, primary_score = sorted_styles[0]
        secondary, secondary_score = sorted_styles[1]
        
        # 如果前三名都很接近 → MULTIMODAL
        if sorted_styles[2][1] >= primary_score * 0.8:
            return "MULTIMODAL", None
        
        # 如果次高风格也比较突出 → 设为 secondary
        if secondary_score >= primary_score * 0.75:
            return primary, secondary
        
        return primary, None
```

### 5.2 扩展维度计算

```python
class DimensionCalculator:
    """Felder-Silverman 简化维度计算"""
    
    @staticmethod
    def calculate_processing(events: list[dict]) -> dict:
        """
        主动/反思维度：
        - 主动型特征：边做边学、快速试错、互动练习频率高、答题速度快
        - 反思型特征：先复习再答题、阅读笔记后练习、答题速度慢但正确率高
        """
        active_signals = 0.0
        reflective_signals = 0.0
        
        for event in events:
            t = event["event_type"]
            if t in ("PRACTICE_TRIAL_AND_ERROR", "INTERACTIVE_EXERCISE_STARTED",
                     "EXPERIMENT_INTERACTED"):
                active_signals += 1.0
            elif t in ("PRACTICE_REVIEW_BEFORE_ANSWER", "NOTE_CREATED",
                       "AI_RESPONSE_READ_FULL", "BOOKMARK_CREATED"):
                reflective_signals += 1.0
        
        total = active_signals + reflective_signals
        if total == 0:
            return {"active": 0.5, "reflective": 0.5, "dominant": "active"}
        
        active_ratio = active_signals / total
        dominant = "active" if active_ratio >= 0.5 else "reflective"
        return {"active": round(active_ratio, 4), "reflective": round(1 - active_ratio, 4),
                "dominant": dominant}
    
    @staticmethod
    def calculate_perception(events: list[dict]) -> dict:
        """
        感知/直觉维度：
        - 感知型：请求具体例子、偏好实际应用、关注细节步骤
        - 直觉型：请求原理解释、偏好抽象概念、关注规律总结
        """
        sensing_signals = 0.0
        intuitive_signals = 0.0
        
        for event in events:
            t = event["event_type"]
            features = event.get("features", {})
            if t == "AI_REQUEST_EXAMPLE" or features.get("requestType") == "EXAMPLE":
                sensing_signals += 1.0
            elif t == "AI_REQUEST_CONCEPT" or features.get("requestType") == "CONCEPT":
                intuitive_signals += 1.0
            elif features.get("focusArea") == "DETAILS":
                sensing_signals += 0.5
            elif features.get("focusArea") == "PATTERN":
                intuitive_signals += 0.5
        
        total = sensing_signals + intuitive_signals
        if total == 0:
            return {"sensing": 0.5, "intuitive": 0.5, "dominant": "sensing"}
        
        sensing_ratio = sensing_signals / total
        dominant = "sensing" if sensing_ratio >= 0.5 else "intuitive"
        return {"sensing": round(sensing_ratio, 4), "intuitive": round(1 - sensing_ratio, 4),
                "dominant": dominant}
    
    @staticmethod
    def calculate_understanding(events: list[dict]) -> dict:
        """
        序列/全局维度：
        - 序列型：按章节顺序学习、逐步解题、偏好分步讲解
        - 全局型：跳跃式浏览、先看概览、搜索特定主题
        """
        sequential_signals = 0.0
        global_signals = 0.0
        
        for event in events:
            t = event["event_type"]
            if t == "SEQUENTIAL_STUDY" or t == "AI_REQUEST_DIAGRAM":
                sequential_signals += 1.0
            elif t == "JUMP_STUDY" or t == "GLOBAL_SEARCH":
                global_signals += 1.0
        
        total = sequential_signals + global_signals
        if total == 0:
            return {"sequential": 0.5, "global": 0.5, "dominant": "sequential"}
        
        sequential_ratio = sequential_signals / total
        dominant = "sequential" if sequential_ratio >= 0.5 else "global"
        return {"sequential": round(sequential_ratio, 4), "global": round(1 - sequential_ratio, 4),
                "dominant": dominant}
```

### 6.2 策略合并算法

当用户存在主风格 + 次风格时，需合并策略：

```python
def merge_strategies(primary: str, secondary: str | None, 
                     primary_confidence: float, secondary_confidence: float | None) -> dict:
    """
    合并主/次风格策略。
    权重分配：primary 占 70%，secondary 占 30%（仅在 confidence >= 0.5 时）
    """
    base = deepcopy(STRATEGY_MAP.get(primary, DEFAULT_STRATEGY))
    
    if secondary and secondary_confidence and secondary_confidence >= 0.5:
        sec = deepcopy(STRATEGY_MAP.get(secondary, {}))
        
        # 合并 contentWeightOverrides
        for key in set(list(base.get("contentWeightOverrides", {}).keys()) + 
                       list(sec.get("contentWeightOverrides", {}).keys())):
            p_val = base["contentWeightOverrides"].get(key, 1.0)
            s_val = sec["contentWeightOverrides"].get(key, 1.0)
            base["contentWeightOverrides"][key] = round(p_val * 0.7 + s_val * 0.3, 2)
        
        # 合并 aiResponseHints（布尔值 OR，字符串取主风格值）
        for key in sec.get("aiResponseHints", {}):
            if key not in base.get("aiResponseHints", {}):
                base["aiResponseHints"][key] = sec["aiResponseHints"][key]
            elif isinstance(base["aiResponseHints"][key], bool):
                base["aiResponseHints"][key] = base["aiResponseHints"][key] or sec["aiResponseHints"][key]
        
        # 合并推荐格式（去重，主风格优先）
        sec_formats = sec.get("recommendedFormats", [])
        for fmt in sec_formats:
            if fmt not in base.get("recommendedFormats", []):
                base["recommendedFormats"].append(fmt)
    
    return base
```

def apply_style_weights(user_id: str, content_items: list[dict], subject: str) -> list[dict]:
    """为内容列表叠加学习风格权重"""
    profile = lsi_cache.get(f"ls:profile:{user_id}")
    if not profile or profile.vark.confidence < 0.5:
        return content_items  # 置信度不足，不调整
    
    weight_overrides = profile.presentation_strategy.get("contentWeightOverrides", {})
    
    for item in content_items:
        content_type = item.get("contentType")  # video|article|interactive|...
        if content_type in weight_overrides:
            original_score = item.get("score", 1.0)
            item["score"] = original_score * weight_overrides[content_type]
    
    return sorted(content_items, key=lambda x: x["score"], reverse=True)

| `LS_SUBJECT_NOT_SUPPORTED` | 400 | 不支持的学科代码 | 忽略学科，使用全局风格 |
| `LS_EVENT_RATE_LIMITED` | 429 | 事件上报频率超限 | 静默丢弃，不重试 |
| `LS_EVENT_TOO_OLD` | 400 | 事件时间戳超过 5 分钟 | 丢弃该条事件 |
| `LS_CALCULATION_IN_PROGRESS` | 202 | 风格正在重算 | 返回缓存的旧画像 |
| `LS_STRATEGY_NOT_FOUND` | 404 | 策略模板不存在 | 返回默认策略 |
| `LS_INSUFFICIENT_DATA` | 200 | 数据不足无法计算 | 返回 UNKNOWN + 默认策略 |

### 11.2 降级策略

```text
降级触发条件：
1. Redis 不可用 → 直查 PostgreSQL（允许性能退化）
2. PostgreSQL 慢查询（>2s）→ 返回 Redis 缓存（允许数据过期）
3. 双存储不可用 → 返回硬编码默认策略
4. 事件刷盘失败 → 事件保留在 Redis，下次重试（TTL 24h）

降级优先级：
  可用性 > 准确性 > 实时性
  即：宁可返回稍旧的画像，也不能阻塞 AI 辅导等核心流程
```

## 14. 安全与隐私

1. **数据最小化**：仅采集学习行为特征，不采集原始对话内容或题目内容
2. **匿名化统计**：管理端统计不暴露个人画像，仅输出聚合数据
3. **家长可见性**：家长端可查看孩子学习风格概述，但不可见详细行为事件
4. **数据保留**：原始行为事件保留 90 天，风格快照保留 2 年
5. **数据删除**：用户注销时，同步删除所有风格相关数据
6. **接口鉴权**：所有接口需 Bearer Token，管理端接口需 `ls:admin` 权限
