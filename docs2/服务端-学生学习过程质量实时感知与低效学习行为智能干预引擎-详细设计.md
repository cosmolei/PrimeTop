# 服务端-学生学习过程质量实时感知与低效学习行为智能干预引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 平台学习质量保障体系的核心服务之一，负责**实时感知学生学习过程质量**，识别浅层学习行为（如冲动答题、表面浏览、被动抄答案、机械刷题等），并通过智能干预策略引导学生向深度学习模式转化。

### 1.2 设计背景与动机

PrimeTop 项目设计文档明确指出："产品应以启发式讲解、分步提示、学习规划和知识巩固为重点，避免仅给出答案导致学生机械抄写。" 现有系统已覆盖学习投入度量化和 AI 对话质量评估，但缺少一个**跨模块、全场景**的学习过程质量感知与主动干预引擎。

| 痛点场景 | 表现 | 危害 |
| --- | --- | --- |
| 冲动答题 | 题目展示后 3 秒内提交答案 | 不读题、不思考，正确率低 |
| 表面浏览 | 学习内容停留时间 < 预估阅读时间的 20% | 知识未内化，复习效率极低 |
| 被动查看 | 直接查看解析/答案，不尝试作答 | 形成依赖，丧失独立解题能力 |
| 机械刷题 | 连续做同一类型题，不看解析，不改错 | 数量虚高，质量极低 |
| 跳跃式学习 | 频繁切换模块/章节，无完整学习会话 | 注意力涣散，学习碎片化 |
| 假性复习 | 错题复习只看不写，无重新作答记录 | 遗忘曲线无效对抗 |

### 1.3 设计目标

1. **实时感知**：在学习行为发生的 1-3 秒内完成质量评估，支撑即时干预
2. **多维度识别**：覆盖答题、阅读、复习、搜索等全场景的低效行为模式
3. **柔性干预**：以引导而非强制的方式改善学习习惯，避免用户体验生硬
4. **习惯追踪**：长期跟踪学生学习模式变化，为学情报告和个性化推荐提供输入
5. **可解释**：每个干预决策附带明确的理由，可供学生和家长理解

### 1.4 与现有模块的关系

| 现有模块 | 关系 |
| --- | --- |
| 服务端-学生学习投入度多维量化与学习效能综合评估引擎 | **输入来源**：投入度指标作为本引擎的参考特征 |
| 服务端-学生AI辅导对话有效学习交互模式识别与低效学习行为智能转化引导引擎 | **范围互补**：该引擎聚焦 AI 对话场景，本引擎覆盖练习、阅读、复习等全场景 |
| 服务端-学生答题过程行为追踪与思维路径可视化引擎 | **数据来源**：答题过程行为数据作为冲动答题检测的输入 |
| 服务端-学生学习会话疲劳度实时监测与自适应休息调度引擎 | **协同**：疲劳可能导致浅层学习，两个引擎需要联动判断 |
| 服务端-统一学习干预编排与智能频控引擎 | **输出通道**：本引擎产出干预决策，通过统一干预引擎执行 |
| 答案管控与渐进式提示引擎 | **协同**：渐进式提示是本引擎干预策略之一 |
| 服务端-学生学习习惯模式分析与科学学习方法指导引擎 | **输出消费者**：本引擎的长期行为模式数据供其分析 |

### 2.2 核心流程

```
学生产生学习行为
    │
    ├─ 行为事件写入 Kafka (learning-behavior-events)
    │
    ├─ Flink CEP 实时处理 → 提取行为特征向量
    │
    ├─ 低效行为检测器并行评估
    │   ├─ 命中规则 → 生成 LowEfficiencyBehaviorEvent
    │   └─ 未命中 → 继续监控
    │
    ├─ 干预决策引擎评估
    │   ├─ 查询用户当前干预疲劳度
    │   ├─ 查询近期干预历史（冷却期检查）
    │   ├─ 选择干预策略 + 干预强度
    │   └─ 生成 InterventionDecision
    │
    ├─ 干预执行
    │   ├─ 实时通道：WebSocket 推送 → 客户端展示干预提示
    │   ├─ 延迟通道：写入干预队列 → 后续自然时机展示
    │   └─ 无干预：仅记录，不打断
    │
    └─ 效果追踪
        ├─ 记录干预后 N 分钟内行为变化
        ├─ 计算干预转化率
        └─ 反馈到策略优化模型
```

## 4. 低效行为识别模型

### 4.1 冲动答题检测 (IMPULSIVE_ANSWER)

#### 4.1.1 检测逻辑

```python
class ImpulsiveAnswerDetector:
    """冲动答题检测器"""
    
    # 默认阈值配置
    DEFAULT_THRESHOLDS = {
        "min_answer_duration_ms": 3000,      # 基础阈值：低于3秒视为快速答题
        "min_read_to_answer_ratio": 0.15,    # 审题时间/总时间 < 15%
        "consecutive_fast_limit": 3,          # 连续3次快速答题触发
        "accuracy_drop_threshold": 0.3,       # 快速答题正确率比整体低30%
    }
    
    def detect(self, event: AnswerEvent, user_profile: StudentHabitProfile) -> Optional[LowEfficiencyEvent]:
        """
        判断单次答题是否为冲动答题。
        
        Args:
            event: 答题事件，包含题目信息、答题耗时、审题时间等
            user_profile: 学生习惯画像，用于个性化阈值
        
        Returns:
            低效行为事件（如果检测到），否则 None
        """
        # 1. 获取个性化阈值（根据学生年级、学科、历史习惯调整）
        thresholds = self._get_personalized_thresholds(event, user_profile)
        
        # 2. 计算各项指标
        answer_duration = event.submit_timestamp - event.display_timestamp
        read_duration = event.first_interaction_timestamp - event.display_timestamp
        read_to_answer_ratio = read_duration / max(answer_duration, 1)
        
        # 3. 题型修正：选择题允许更快，解答题需要更多时间
        question_type_factor = self._get_question_type_factor(event.question_type)
        adjusted_min_duration = thresholds["min_answer_duration_ms"] * question_type_factor
        
        # 4. 难度修正：简单题允许更快
        difficulty_factor = self._get_difficulty_factor(event.difficulty_level)
        adjusted_min_duration *= difficulty_factor
        
        # 5. 综合判断
        is_fast = answer_duration < adjusted_min_duration
        is_low_read_ratio = read_to_answer_ratio < thresholds["min_read_to_answer_ratio"]
        
        if is_fast and is_low_read_ratio:
            severity = self._calculate_severity(
                answer_duration, adjusted_min_duration, read_to_answer_ratio
            )
            confidence = self._calculate_confidence(
                event, thresholds, answer_duration, read_to_answer_ratio
            )
            
            return LowEfficiencyEvent(
                behavior_type="IMPULSIVE_ANSWER",
                severity=severity,
                confidence=confidence,
                trigger_data={
                    "question_id": event.question_id,
                    "answer_duration_ms": answer_duration,
                    "read_duration_ms": read_duration,
                    "threshold_ms": adjusted_min_duration,
                    "read_to_answer_ratio": read_to_answer_ratio,
                    "question_type": event.question_type,
                    "difficulty": event.difficulty_level,
                }
            )
        
        return None
    
    def _get_personalized_thresholds(self, event, profile):
        """根据学生画像调整阈值"""
        base = dict(self.DEFAULT_THRESHOLDS)
        
        # 如果学生历史冲动率高，适当提高阈值（更灵敏检测）
        if profile and profile.impulsive_answer_rate > 0.4:
            base["min_answer_duration_ms"] = int(base["min_answer_duration_ms"] * 1.2)
        
        # 低年级学生允许更短的答题时间
        if event.grade_level <= 3:
            base["min_answer_duration_ms"] = int(base["min_answer_duration_ms"] * 0.7)
        
        return base
    
    def _get_question_type_factor(self, question_type: str) -> float:
        """题型修正因子"""
        factors = {
            "single_choice": 0.6,      # 单选题允许更快
            "multiple_choice": 0.8,    # 多选题
            "fill_blank": 1.0,         # 填空题
            "short_answer": 1.5,       # 简答题需要更多时间
            "essay": 2.0,              # 作文/论述题
            "calculation": 1.8,        # 计算题
            "proof": 2.5,              # 证明题
        }
        return factors.get(question_type, 1.0)
    
    def _get_difficulty_factor(self, difficulty: float) -> float:
        """难度修正因子 (0-1, 越大越难)"""
        if difficulty < 0.3:
            return 0.6  # 简单题
        elif difficulty < 0.6:
            return 1.0  # 中等题
        else:
            return 1.5  # 难题
    
    def _calculate_severity(self, actual_ms, threshold_ms, read_ratio):
        """计算严重程度"""
        speed_ratio = actual_ms / threshold_ms  # 越小越严重
        
        if speed_ratio < 0.2:
            return "HIGH"
        elif speed_ratio < 0.5:
            return "MEDIUM"
        else:
            return "LOW"

class SurfaceReadingDetector:
    """表面浏览检测器"""
    
    def detect(self, event: ContentReadEvent, user_profile) -> Optional[LowEfficiencyEvent]:
        """
        检测学习内容表面浏览行为。
        
        判断维度：
        1. 实际停留时间 vs 预估阅读时间
        2. 滚动深度（是否滚动到底）
        3. 交互信号（是否有高亮、笔记、收藏等）
        4. 后续测验表现（阅读后相关题目正确率）
        """
        # 预估阅读时间 = 内容字数 / 阅读速度
        estimated_read_time_ms = event.content_word_count / event.user_read_speed_wpm * 60_000
        actual_dwell_time_ms = event.leave_timestamp - event.enter_timestamp
        dwell_ratio = actual_dwell_time_ms / max(estimated_read_time_ms, 1000)
        
        # 综合评分
        signals = {
            "dwell_ratio": dwell_ratio,                          # 停留比
            "scroll_depth": event.max_scroll_depth,              # 滚动深度
            "has_interaction": event.has_highlight or event.has_note,  # 交互信号
            "avg_time_per_screen": actual_dwell_time_ms / max(event.screen_count, 1),  # 每屏时间
        }
        
        surface_score = self._compute_surface_score(signals)
        
        if surface_score > 0.7:  # 表面度 > 0.7
            severity = "HIGH" if surface_score > 0.85 else ("MEDIUM" if surface_score > 0.75 else "LOW")
            
            return LowEfficiencyEvent(
                behavior_type="SURFACE_READING",
                severity=severity,
                confidence=surface_score,
                trigger_data={
                    "content_id": event.content_id,
                    "estimated_read_ms": estimated_read_time_ms,
                    "actual_dwell_ms": actual_dwell_time_ms,
                    "dwell_ratio": round(dwell_ratio, 3),
                    "scroll_depth": event.max_scroll_depth,
                    "content_word_count": event.content_word_count,
                    "content_type": event.content_type,  # article/video/exercise
                }
            )
        
        return None
    
    def _compute_surface_score(self, signals: dict) -> float:
        """
        加权计算表面度评分。
        返回 0-1，越高越表面。
        """
        weights = {
            "dwell_ratio": 0.40,       # 停留比最重要
            "scroll_depth": 0.25,      # 滚动深度
            "has_interaction": 0.15,   # 交互信号（反向）
            "avg_time_per_screen": 0.20,  # 每屏停留
        }
        
        # 归一化各信号到 0-1（1 = 表面）
        normalized = {
            "dwell_ratio": 1.0 - min(signals["dwell_ratio"], 1.0),  # 停留比越低越表面
            "scroll_depth": 1.0 - signals["scroll_depth"],
            "has_interaction": 0.0 if signals["has_interaction"] else 1.0,
            "avg_time_per_screen": 1.0 - min(signals["avg_time_per_screen"] / 10_000, 1.0),
        }
        
        score = sum(normalized[k] * weights[k] for k in weights)
        return round(score, 3)

```python
class MechanicalDrillDetector:
    """机械刷题检测器"""
    
    def detect_batch(self, recent_events: List[AnswerEvent], user_id: int) -> Optional[LowEfficiencyEvent]:
        """
        检测机械刷题模式：大量做题但不看解析、不改错。
        
        分析窗口：最近 30 分钟
        判断标准：
        1. 做题数量 >= 15 题
        2. 查看解析率 < 20%
        3. 错题重做率 < 10%
        4. 同一知识点重复做题占比 > 60%
        5. 答题速度均匀且快速（无深度思考波动）
        """
        window_minutes = 30
        questions_answered = len(recent_events)
        
        if questions_answered < 15:
            return None
        
        # 计算指标
        explanation_view_rate = sum(1 for e in recent_events if e.viewed_explanation) / questions_answered
        wrong_retry_rate = self._calc_wrong_retry_rate(recent_events)
        
        knowledge_point_counts = Counter(e.knowledge_point_id for e in recent_events)
        dominant_kp_ratio = knowledge_point_counts.most_common(1)[0][1] / questions_answered
        
        durations = [e.answer_duration_ms for e in recent_events]
        duration_cv = np.std(durations) / np.mean(durations) if np.mean(durations) > 0 else 0  # 变异系数
        
        # 机械刷题评分
        mechanical_score = self._compute_mechanical_score(
            explanation_view_rate, wrong_retry_rate, dominant_kp_ratio, duration_cv
        )
        
        if mechanical_score > 0.65:
            return LowEfficiencyEvent(
                behavior_type="MECHANICAL_DRILL",
                severity="HIGH" if mechanical_score > 0.8 else "MEDIUM",
                confidence=mechanical_score,
                trigger_data={
                    "window_minutes": window_minutes,
                    "questions_answered": questions_answered,
                    "explanation_view_rate": round(explanation_view_rate, 3),
                    "wrong_retry_rate": round(wrong_retry_rate, 3),
                    "dominant_kp_ratio": round(dominant_kp_ratio, 3),
                    "duration_cv": round(duration_cv, 3),
                    "dominant_kp_id": knowledge_point_counts.most_common(1)[0][0],
                }
            )
        
        return None
    
    def _compute_mechanical_score(self, expl_rate, retry_rate, kp_ratio, dur_cv):
        """
        机械刷题评分。
        各指标越极端，分数越高。
        """
        score = 0.0
        score += max(0, 0.35 - expl_rate) / 0.35 * 0.35      # 不看解析
        score += max(0, 0.10 - retry_rate) / 0.10 * 0.25      # 不改错
        score += max(0, kp_ratio - 0.40) / 0.60 * 0.25        # 重复同一知识点
        score += max(0, 0.20 - dur_cv) / 0.20 * 0.15          # 速度均匀无波动
        return round(min(score, 1.0), 3)
```

class PseudoReviewDetector:
    """假性复习检测器"""
    
    def detect(self, review_events: List[ReviewEvent]) -> Optional[LowEfficiencyEvent]:
        """
        检测错题复习中的假性复习行为。
        
        假性复习：只浏览错题不看解析、不重新作答。
        
        判断标准：
        1. 错题复习会话中，浏览比例 > 70%
        2. 重新作答比例 < 20%
        3. 每道错题停留时间 < 10 秒
        4. 复习后无订正记录
        """
        total_reviewed = len(review_events)
        if total_reviewed < 5:
            return None
        
        view_only_count = sum(1 for e in review_events if not e.attempted_reanswer)
        reattempt_count = sum(1 for e in review_events if e.attempted_reanswer)
        correction_count = sum(1 for e in review_events if e.has_correction_record)
        
        view_only_rate = view_only_count / total_reviewed
        reattempt_rate = reattempt_count / total_reviewed
        avg_review_time = np.mean([e.dwell_time_ms for e in review_events])
        
        pseudo_score = (
            max(0, view_only_rate - 0.5) / 0.5 * 0.40 +
            max(0, 0.2 - reattempt_rate) / 0.2 * 0.35 +
            max(0, 10_000 - avg_review_time) / 10_000 * 0.25
        )
        
        if pseudo_score > 0.55:
            return LowEfficiencyEvent(
                behavior_type="PSEUDO_REVIEW",
                severity="HIGH" if pseudo_score > 0.75 else "MEDIUM",
                confidence=min(pseudo_score + 0.1, 1.0),

                    "total_reviewed": total_reviewed,
                    "view_only_rate": round(view_only_rate, 3),
                    "reattempt_rate": round(reattempt_rate, 3),
                    "avg_review_time_ms": round(avg_review_time),

### 5.1 干预策略矩阵

| 低效行为 | SOFT 干预 | MODERATE 干预 | FIRM 干预 |
| --- | --- | --- | --- |
| 冲动答题 | 温和提醒"慢一点读题" | 强制审题3秒后才能提交 | 答错后强制查看解题思路 |
| 表面浏览 | "要不要再看一遍重点？" | 标注核心段落要求阅读 | 设置最低阅读时间才能解锁练习 |

| 机械刷题 | "看看错题解析吧" | 限制连续做题速度 | 强制错题重做才能继续刷题 |
| 跳跃学习 | "专注一个任务效果更好" | 建议完成当前任务 | 模块切换冷却期 |
| 假性复习 | "试着重新做一遍？" | 隐藏解析，先作答 | 强制重新作答3道错题 |

### 5.2 干预决策核心逻辑

```python
class InterventionDecisionEngine:
    """干预决策引擎"""
    
    def __init__(self, strategy_repo, frequency_controller, experiment_service):
        self.strategy_repo = strategy_repo
        self.freq_controller = frequency_controller
        self.experiment_service = experiment_service
    
    def decide(self, behavior_event: LowEfficiencyEvent, 
               user_profile: StudentHabitProfile) -> Optional[InterventionDecision]:
        """
        根据低效行为事件和学生画像，生成干预决策。
        
        Returns:
            干预决策（如果决定干预），否则 None（本次不干预）
        """
        user_id = behavior_event.user_id
        
        # 1. 频控检查：是否在冷却期内
        if not self.freq_controller.can_intervene(
            user_id=user_id,
            behavior_type=behavior_event.behavior_type,
            severity=behavior_event.severity
        ):
            return None
        
        # 2. 干预疲劳度检查
        fatigue_level = user_profile.intervention_fatigue_level if user_profile else 0
        if fatigue_level > 0.8:
            # 疲劳度过高，只记录不干预
            return InterventionDecision(
                user_id=user_id,
                behavior_event_id=behavior_event.event_id,
                intervention_type="NONE",
                intervention_intensity="SOFT",
                delivery_channel="REPORT",
                delivery_status="SKIPPED",
                intervention_content={"reason": "user_fatigue"}
            )
        
        # 3. 获取适用策略
        strategies = self.strategy_repo.find_applicable(
            behavior_type=behavior_event.behavior_type,
            severity=behavior_event.severity,
            stage=user_profile.stage if user_profile else None,
            grade_level=user_profile.grade_level if user_profile else None,
        )
        
        if not strategies:
            return None
        
        # 4. A/B 实验分组
        experiment_group = self.experiment_service.get_user_group(
            user_id, experiment_name="intervention_strategy_v2"
        )
        
        # 5. 选择策略（综合优先级、实验分组、历史效果）
        selected_strategy = self._select_strategy(
            strategies, user_profile, experiment_group, behavior_event
        )
        
        # 6. 确定干预强度
        intensity = self._determine_intensity(
            behavior_event.severity,
            user_profile,
            selected_strategy
        )
        
        # 7. 选择投递通道
        channel = self._determine_channel(behavior_event, intensity, fatigue_level)
        
        # 8. 生成干预内容
        content = self._generate_content(selected_strategy, intensity, behavior_event, user_profile)
        
        return InterventionDecision(
            user_id=user_id,
            behavior_event_id=behavior_event.event_id,
            intervention_type=selected_strategy.strategy_code,
            intervention_intensity=intensity,
            intervention_content=content,
            delivery_channel=channel,
            experiment_group=experiment_group,
        )
    
    def _select_strategy(self, strategies, profile, exp_group, event):
        """选择最优干预策略"""
        scored = []
        for s in strategies:
            score = 0.0
            
            # 基础优先级
            score += (100 - s.priority) * 0.3
            
            # 历史效果
            if profile and s.strategy_code == profile.preferred_intervention:
                score += 30
            
            # 实验分组偏好
            if exp_group == "variant_a" and "HINT" in s.strategy_code:
                score += 15
            elif exp_group == "variant_b" and "NUDGE" in s.strategy_code:
                score += 15
            
            # 严重程度匹配
            if event.severity == "HIGH" and s.strategy_code in ["MANDATORY_READING", "CONTENT_GATE"]:
                score += 20
            
            scored.append((s, score))
        
        scored.sort(key=lambda x: x[1], reverse=True)
        return scored[0][0]
    
    def _determine_intensity(self, severity, profile, strategy):
        """确定干预强度"""
        # 基础强度由严重程度决定
        base = {"LOW": "SOFT", "MEDIUM": "MODERATE", "HIGH": "FIRM"}.get(severity, "SOFT")
        
        # 新用户降级（避免首次就强干预）
        if profile and profile.depth_score_current is None:
            if base == "FIRM":
                base = "MODERATE"
            elif base == "MODERATE":
                base = "SOFT"
        
        # 改善中：降级干预
        if profile and profile.improvement_streak >= 7:
            if base == "FIRM":
                base = "MODERATE"
        
        return base
    
    def _determine_channel(self, event, intensity, fatigue):
        """选择投递通道"""
        if intensity == "FIRM" and fatigue < 0.6:
            return "REALTIME"     # 强干预实时推送
        elif intensity == "MODERATE" and fatigue < 0.7:
            return "REALTIME"     # 中等干预实时推送
        else:
            return "DELAYED"      # 延迟投递（不打断）
    
    def _generate_content(self, strategy, intensity, event, profile):
        """生成干预内容"""
        template = self._get_template(strategy.strategy_code, intensity)
        
        content = template.render({
            "user_name": profile.nickname if profile else "同学",
            "behavior_type": event.behavior_type,
            "trigger_data": event.trigger_data,
            "stage": profile.stage if profile else "junior",
        })
        
        return content
```

```python
class InterventionFrequencyController:
    """干预频控管理器"""
    
    # 默认频控配置
    DEFAULT_CONFIG = {
        "global_cooldown_minutes": 5,        # 全局冷却：两次干预间隔至少5分钟
        "per_type_cooldown": {               # 按行为类型冷却
            "IMPULSIVE_ANSWER": 8,
            "SURFACE_READING": 10,
            "PASSIVE_VIEWING": 8,
            "MECHANICAL_DRILL": 15,
            "JUMP_LEARNING": 12,
            "PSEUDO_REVIEW": 10,
        },
        "daily_max_per_type": {              # 每日同类型干预上限
            "LOW": 2,
            "MEDIUM": 1,
            "HIGH": 1,
        },
        "daily_max_total": 6,                # 每日总干预上限
        "session_max": 3,                    # 单次学习会话干预上限
    }
    
    def __init__(self, redis_client):
        self.redis = redis_client
    
    def can_intervene(self, user_id: int, behavior_type: str, severity: str) -> bool:
        """检查是否可以进行干预（频控通过）"""
        
        # 1. 全局冷却
        last_global = self.redis.get(f"intervene:global:{user_id}")
        if last_global and time.time() - float(last_global) < self.DEFAULT_CONFIG["global_cooldown_minutes"] * 60:
            return False
        
        # 2. 类型冷却
        type_cooldown = self.DEFAULT_CONFIG["per_type_cooldown"].get(behavior_type, 10)
        last_type = self.redis.get(f"intervene:type:{user_id}:{behavior_type}")
        if last_type and time.time() - float(last_type) < type_cooldown * 60:
            return False
        
        # 3. 每日上限
        today = date.today().isoformat()
        daily_type_count = int(self.redis.get(f"intervene:daily:{user_id}:{today}:{behavior_type}:{severity}") or 0)
        if daily_type_count >= self.DEFAULT_CONFIG["daily_max_per_type"].get(severity, 1):
            return False
        
        daily_total = int(self.redis.get(f"intervene:daily:{user_id}:{today}:total") or 0)
        if daily_total >= self.DEFAULT_CONFIG["daily_max_total"]:
            return False
        
        return True
    
    def record_intervention(self, user_id: int, behavior_type: str, severity: str):
        """记录已执行的干预"""
        now = time.time()
        today = date.today().isoformat()
        
        pipe = self.redis.pipeline()
        pipe.set(f"intervene:global:{user_id}", now, ex=3600)
        pipe.set(f"intervene:type:{user_id}:{behavior_type}", now, ex=1800)
        pipe.incr(f"intervene:daily:{user_id}:{today}:{behavior_type}:{severity}")
        pipe.expire(f"intervene:daily:{user_id}:{today}:{behavior_type}:{severity}", 86400 * 2)
        pipe.incr(f"intervene:daily:{user_id}:{today}:total")
        pipe.expire(f"intervene:daily:{user_id}:{today}:total", 86400 * 2)

## 7. 干预效果追踪与反馈闭环

### 7.1 效果追踪流程

```
干预投递 (T=0)
    │
    ├─ 记录基线行为快照 (T-5min ~ T 的行为指标)
    │
    ├─ 观察窗口 (T ~ T+10min)
    │   ├─ 行为是否改善？（如同类型低效行为是否消失）
    │   ├─ 学生是否响应干预？（ACTED / DISMISSED / IGNORED）
    │   └─ 短期效果：干预后答题正确率、阅读深度是否提升
    │
    ├─ 长期观察 (T ~ T+7d)
    │   ├─ 该类型低效行为频率是否下降
    │   ├─ 学习深度评分是否提升
    │   └─ 习惯标签是否向 DEEP_LEARNER 移动
    │
    └─ 效果评分计算
        ├─ 短期效果权重：0.6
        │   ├─ 行为改善：0.35
        │   ├─ 响应速度：0.15
        │   └─ 正确率提升：0.10
        └─ 长期效果权重：0.4
            ├─ 频率下降：0.25
            └─ 评分提升：0.15
```

### 7.2 效果评分计算

```python
class InterventionEffectivenessCalculator:
    """干预效果评分计算器"""
    
    def calculate(self, decision: InterventionDecision, 
                  pre_snapshot: BehaviorSnapshot,
                  post_snapshot: BehaviorSnapshot) -> float:
        """
        计算单次干预的有效性评分。
        
        Args:
            decision: 干预决策
            pre_snapshot: 干预前行为快照
            post_snapshot: 干预后行为快照
        
        Returns:
            有效性评分 (0-1)
        """
        behavior_type = decision.get_behavior_type()
        
        # 1. 行为改善分：该类型低效行为在干预后是否减少
        pre_rate = pre_snapshot.get_behavior_rate(behavior_type)
        post_rate = post_snapshot.get_behavior_rate(behavior_type)
        behavior_improvement = max(0, (pre_rate - post_rate) / max(pre_rate, 0.01))
        
        # 2. 响应速度分：学生响应干预的速度
        if decision.acted_at and decision.delivered_at:
            response_time_s = (decision.acted_at - decision.delivered_at).total_seconds()
            response_score = max(0, 1 - response_time_s / 30)  # 30秒内响应满分
        else:
            response_score = 0.0
        
        # 3. 正确率提升分（仅对答题相关行为）
        accuracy_delta = post_snapshot.accuracy - pre_snapshot.accuracy
        accuracy_improvement = max(0, min(accuracy_delta * 5, 1))  # 放大5%到0-1范围
        
        # 4. 学习深度评分变化
        depth_delta = post_snapshot.depth_score - pre_snapshot.depth_score
        depth_improvement = max(0, min(depth_delta / 20, 1))  # 20分提升满分
        
        # 加权综合
        effectiveness = (
            behavior_improvement * 0.35 +
            response_score * 0.15 +
            accuracy_improvement * 0.10 +
            depth_improvement * 0.40
        )
        
        return round(min(effectiveness, 1.0), 3)
```

### 7.3 策略自动优化

```python
class StrategyOptimizer:
    """基于干预效果数据自动优化策略参数"""
    
    def __init__(self, decision_repo, strategy_repo):
        self.decision_repo = decision_repo
        self.strategy_repo = strategy_repo
    
    def optimize_strategy(self, strategy_code: str, lookback_days: int = 30):
        """
        基于最近30天的干预效果数据，优化策略参数。
        
        优化维度：
        1. 干预强度配比（SOFT/MODERATE/FIRM 的效果对比）
        2. 投递通道效果（REALTIME vs DELAYED）
        3. 干预内容模板效果排名
        4. 最优干预时机分析
        """
        # 获取历史数据
        decisions = self.decision_repo.find_by_strategy(
            strategy_code, days=lookback_days
        )
        
        if len(decisions) < 50:  # 样本不足
            return None
        
        # 按强度分组对比效果
        intensity_performance = {}
        for intensity in ["SOFT", "MODERATE", "FIRM"]:
            subset = [d for d in decisions if d.intervention_intensity == intensity]
            if subset:
                avg_effect = np.mean([d.effectiveness_score for d in subset if d.effectiveness_score])
                intensity_performance[intensity] = {
                    "avg_effectiveness": avg_effect,
                    "sample_size": len(subset),
                    "act_rate": sum(1 for d in subset if d.delivery_status == "ACTED") / len(subset)
                }
        
        # 按投递通道对比
        channel_performance = {}
        for channel in ["REALTIME", "DELAYED"]:
            subset = [d for d in decisions if d.delivery_channel == channel]
            if subset:
                channel_performance[channel] = np.mean([
                    d.effectiveness_score for d in subset if d.effectiveness_score
                ])
        
        # 生成优化建议
        recommendations = self._generate_recommendations(
            intensity_performance, channel_performance
        )
        
        # 自动调整参数（需要人工审核）
        return {
            "strategy_code": strategy_code,
            "current_config": self.strategy_repo.get(strategy_code).to_dict(),
            "performance_analysis": {
                "by_intensity": intensity_performance,
                "by_channel": channel_performance,
            },
            "recommendations": recommendations,
            "auto_apply": False,  # 需要管理员审核

## 9. 学习深度评分模型

### 9.1 综合深度评分算法

```python
class LearningDepthScoreCalculator:
    """学习深度综合评分计算器"""
    
    WEIGHTS = {
        "answer_depth": 0.25,        # 答题深度
        "reading_depth": 0.20,       # 阅读深度
        "review_depth": 0.20,        # 复习深度
        "session_coherence": 0.15,   # 会话连贯性
        "explanation_engagement": 0.15,  # 解析参与度
        "proactive_behavior": 0.05,  # 主动学习行为
    }
    
    def calculate_daily_score(self, user_id: int, date: str) -> float:
        """
        计算学生某日的学习深度综合评分 (0-100)。
        """
        metrics = self._collect_daily_metrics(user_id, date)
        
        # 各维度子评分 (0-100)
        sub_scores = {
            "answer_depth": self._score_answer_depth(metrics),
            "reading_depth": self._score_reading_depth(metrics),
            "review_depth": self._score_review_depth(metrics),
            "session_coherence": self._score_session_coherence(metrics),
            "explanation_engagement": self._score_explanation_engagement(metrics),
            "proactive_behavior": self._score_proactive(metrics),
        }
        
        total = sum(sub_scores[k] * self.WEIGHTS[k] for k in self.WEIGHTS)
        return round(total, 1)
    
    def _score_answer_depth(self, m) -> float:
        """答题深度评分"""
        if m.total_answers == 0:
            return 50.0  # 无数据时给中间分
        
        # 冲动答题率越低越好
        impulsive_penalty = m.impulsive_answer_rate * 60
        
        # 正确率
        accuracy_score = m.answer_accuracy * 40
        
        # 审题充分度
        read_adequacy = min(m.avg_read_time / m.expected_read_time, 1.0) * 30
        
        score = accuracy_score + read_adequacy - impulsive_penalty
        return max(0, min(100, score))
    
    def _score_reading_depth(self, m) -> float:
        """阅读深度评分"""
        if m.total_reads == 0:
            return 50.0
        
        dwell_ratio = m.avg_dwell_ratio  # 实际/预估停留比
        scroll_depth = m.avg_scroll_depth
        
        score = min(dwell_ratio, 1.0) * 60 + scroll_depth * 40
        return max(0, min(100, score))
    
    def _score_review_depth(self, m) -> float:
        """复习深度评分"""
        if m.total_reviews == 0:
            return 50.0
        
        reattempt_rate = m.review_reattempt_rate
        correction_rate = m.review_correction_rate
        
        score = reattempt_rate * 50 + correction_rate * 50
        return max(0, min(100, score))
    
    def _score_session_coherence(self, m) -> float:
        """会话连贯性评分"""
        if m.session_count == 0:
            return 50.0
        
        avg_session_length = m.avg_session_duration_ms
        module_switch_rate = m.module_switches_per_hour
        
        # 会话越长越好（有一定上限）
        length_score = min(avg_session_length / (15 * 60 * 1000), 1.0) * 50  # 15分钟满分
        
        # 切换越少越好
        switch_score = max(0, 1 - module_switch_rate / 10) * 50  # 每小时10次切换为0分
        
        return length_score + switch_score
    
    def _score_explanation_engagement(self, m) -> float:
        """解析参与度评分"""
        if m.total_wrong_answers == 0:
            return 75.0  # 没有答错，给较高分
        
        explanation_view_rate = m.wrong_explanation_view_rate
        full_read_rate = m.explanation_full_read_rate
        
        score = explanation_view_rate * 50 + full_read_rate * 50
        return max(0, min(100, score))
    
    def _score_proactive(self, m) -> float:
        """主动学习行为评分"""
        # 主动追问、主动收藏、主动做笔记等
        proactive_actions = m.proactive_question_count + m.bookmark_count + m.note_count
        score = min(proactive_actions / 10, 1.0) * 100  # 10次主动行为满分
        return score
```
