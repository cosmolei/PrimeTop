# 服务端 - 教育数据匿名化与去标识化处理管线引擎 详细设计

## 1. 模块概述

### 1.1 背景与目标

PrimeTop 作为覆盖幼儿至高中全学段的 AI 辅助学习平台，持续采集大量未成年人学习行为数据、答题记录、学情画像等敏感信息。在以下场景中，需要将原始数据转化为匿名化/去标识化数据集后才能安全使用：

| 场景 | 说明 |
| --- | --- |
| 数据分析与 BI | 学习行为统计、AB 实验效果分析、运营看板 |
| 模型训练 | AI 模型微调训练数据集准备（RLHF 反馈数据等） |
| 学术研究 | 与教育研究机构合作，共享学习行为研究数据 |
| 第三方合作 | B 端合作方向合作方提供脱敏后的学情趋势数据 |
| 数据开放 | 教育行业报告、白皮书中的统计数据生成 |
| 内部测试 | 测试环境使用接近真实的脱敏数据 |

现有 `数据脱敏规则引擎` 负责在线展示场景的动态遮蔽（如手机号显示为 138****5678），`密钥管理` 负责加密密钥生命周期管理。本模块聚焦于**离线/近线批量数据的匿名化处理管线**，解决"如何安全地将生产数据用于分析、研究、训练和共享"的问题。

### 1.2 设计目标

1. **不可逆性保障**：匿名化后的数据无法通过合理手段还原到具体学生个人。
2. **数据可用性**：在匿名化前提下，尽可能保留数据的统计特征和分析价值。
3. **合规对标**：满足《个人信息保护法》（PIPL）、《数据安全法》（DSL）、《未成年人保护法》及《儿童个人信息网络保护规定》的匿名化要求。
4. **风险量化**：对每次匿名化输出提供可量化的重标识风险评估报告。
5. **管线自动化**：支持定时调度和按需触发，自动完成抽取→清洗→匿名→审核→交付的完整链路。
6. **全程审计**：匿名化操作的全链路可追溯，满足合规审计要求。

### 1.3 与现有模块的关系

| 现有模块 | 关系 |
| --- | --- |
| 数据脱敏规则引擎 | 展示层实时脱敏；本模块是数据层批量匿名化，两者互补 |
| 密钥管理与敏感配置安全策略 | 本模块的加密型匿名化操作依赖其密钥管理基础设施 |
| 数据安全与隐私合规体系 | 本模块是该体系在"数据使用"环节的具体落地 |
| 学习数据仓库与BI分析平台 | 本模块为其提供合规的匿名化数据源 |
| 数据血缘追踪与元数据治理平台 | 匿名化数据集的血缘关系注册到该平台 |
| 数据质量监控与异常数据自动检测引擎 | 匿名化后数据的质量校验复用该引擎 |
| 统一审计日志与操作追溯系统 | 匿名化操作日志写入该系统 |

### 1.4 术语定义

| 术语 | 定义 |
| --- | --- |
| **PII**（Personally Identifiable Information） | 可直接或间接识别到自然人的信息 |
| **准标识符**（Quasi-Identifier） | 单独不能识别个体，但组合后可能唯一识别的数据（如年级+学校+出生月份） |
| **K-匿名**（K-Anonymity） | 数据集中每条记录至少与 K-1 条其他记录在准标识符上不可区分 |
| **L-多样性**（L-Diversity） | 在 K-匿名基础上，每个等价类中敏感属性至少有 L 个不同值 |
| **T-贴近**（T-Closeness） | 等价类中敏感属性的分布与整体分布的距离不超过 T |
| **差分隐私**（Differential Privacy） | 在查询结果中注入可控噪声，使得任意单条记录的存在与否对输出影响有界 |
| **重标识风险**（Re-identification Risk） | 匿名化数据被关联攻击还原到具体个体的概率 |
| **假名化**（Pseudonymization） | 用可逆映射替换直接标识符，映射表单独保管 |

from enum import Enum

class AnonymizationTechnique(str, Enum):
    """匿名化技术枚举"""
    
    # ── 不可逆变换 ──
    HASH = "HASH"                          # 单向哈希 (SHA-256 + 盐)
    HASH_WITH_SALT = "HASH_WITH_SALT"      # 加盐哈希 (每次使用不同盐值)
    TRUNCATE = "TRUNCATE"                  # 截断 (保留前 N 位，后面丢弃)
    SUPPRESS = "SUPPRESS"                  # 完全抑制 (直接删除字段)
    RANDOMIZE = "RANDOMIZE"               # 随机替换 (从同分布中随机抽样)
    
    # ── 可逆变换 (假名化) ──
    PSEUDONYMIZE = "PSEUDONYMIZE"          # 假名化 (映射表单独加密保管)
    FORMAT_PRESERVING_ENCRYPT = "FPE"      # 格式保留加密 (密文与明文格式相同)
    
    # ── 泛化与粒度退化 ──
    GENERALIZE = "GENERALIZE"              # 泛化 (如精确年龄→年龄段)
    AGGREGATE = "AGGREGATE"                # 聚合 (多行合并为统计值)
    BINNING = "BINNING"                   # 分箱 (连续值离散化)
    
    # ── 扰动 ──
    PERTURBATION = "PERTURBATION"          # 数值微扰 (加 Laplace/Gaussian 噪声)
    SWAP = "SWAP"                          # 数据交换 (同类记录间交换属性值)
    
    # ── 差分隐私 ──
    DP_LAPLACE = "DP_LAPLACE"             # Laplace 机制 (数值型)
    DP_EXPONENTIAL = "DP_EXPONENTIAL"      # 指数机制 (类别型)
    
    # ── 组合技术 ──
    K_ANONYMIZE = "K_ANONYMIZE"            # K-匿名化 (对准标识符组做泛化+抑制)
```

## 4. 核心算法设计

### 4.1 K-匿名化算法（Mondrian 多维泛化）

K-匿名化的核心目标：确保数据集中任意一条记录在准标识符组合上，至少与 K-1 条其他记录不可区分。采用 **Mondrian** 算法实现多维泛化。

```python
"""
K-匿名化 Mondrian 算法实现

原理：递归地将数据集按准标识符维度做二分分割，
直到每个分区的大小 < 2K 为止，然后将每个分区内的
准标识符值泛化为分区范围内的通用值。
"""

from dataclasses import dataclass, field
from typing import Any
import pandas as pd


@dataclass
class KAnonymityConfig:
    """K-匿名配置"""
    k_value: int = 5                    # K 值，默认 5
    quasi_identifiers: list[str] = field(default_factory=list)  # 准标识符列表
    sensitive_attributes: list[str] = field(default_factory=list)  # 敏感属性
    max_generalization_levels: dict[str, int] = field(default_factory=lambda: {})  # 各字段最大泛化层级


@dataclass  
class Partition:
    """数据分区"""
    data: pd.DataFrame
    qi_ranges: dict[str, tuple]         # 各准标识符的 (min, max) 范围
    
    def can_split(self, k: int) -> bool:
        """是否还能继续分割"""
        return len(self.data) >= 2 * k
    
    def find_best_split_dim(self, k: int) -> str | None:
        """选择使信息损失最小的分割维度"""
        best_dim = None
        best_normalized_width = -1
        
        for dim in self.qi_ranges:
            col = self.data[dim]
            min_val, max_val = self.qi_ranges[dim]
            
            # 连续值：选择中位数分割点
            if pd.api.types.is_numeric_dtype(col):
                median = col.median()
                left_count = (col <= median).sum()
                right_count = (col > median).sum()
                
                if left_count >= k and right_count >= k:
                    # 归一化范围宽度，选最宽的维度分割
                    normalized_width = (max_val - min_val) / (col.max() - col.min() + 1e-9)
                    if normalized_width > best_normalized_width:
                        best_normalized_width = normalized_width
                        best_dim = dim
            else:
                # 类别值：按频次二分
                value_counts = col.value_counts().sort_values(ascending=False)
                if len(value_counts) < 2:
                    continue
                split_point = len(value_counts) // 2
                left_values = set(value_counts.index[:split_point])
                
                left_count = col.isin(left_values).sum()
                right_count = (~col.isin(left_values)).sum()
                
                if left_count >= k and right_count >= k:
                    normalized_width = len(value_counts) / (len(value_counts) + 1)
                    if normalized_width > best_normalized_width:
                        best_normalized_width = normalized_width
                        best_dim = dim
        
        return best_dim
    
    def split(self, dim: str, k: int) -> tuple['Partition', 'Partition']:
        """按指定维度分割"""
        col = self.data[dim]
        
        if pd.api.types.is_numeric_dtype(col):
            median = col.median()
            left_mask = col <= median
        else:
            value_counts = col.value_counts().sort_values(ascending=False)
            split_point = len(value_counts) // 2
            left_values = set(value_counts.index[:split_point])
            left_mask = col.isin(left_values)
        
        left_data = self.data[left_mask].copy()
        right_data = self.data[~left_mask].copy()
        
        left_partition = Partition(
            data=left_data,
            qi_ranges=self._compute_ranges(left_data)
        )
        right_partition = Partition(
            data=right_data,
            qi_ranges=self._compute_ranges(right_data)
        )
        
        return left_partition, right_partition
    
    def generalize(self) -> pd.DataFrame:
        """将分区内数据做泛化处理"""
        generalized = self.data.copy()
        for dim, (min_val, max_val) in self.qi_ranges.items():
            if pd.api.types.is_numeric_dtype(generalized[dim]):
                if min_val == max_val:
                    generalized[dim] = min_val
                else:
                    generalized[dim] = f"[{min_val}, {max_val}]"
            else:
                # 类别值：取所有不同值的组合表示
                unique_vals = generalized[dim].unique()
                if len(unique_vals) == 1:
                    generalized[dim] = unique_vals[0]
                else:
                    generalized[dim] = f"{{{','.join(sorted(unique_vals))}}}"
        return generalized
    
    @staticmethod
    def _compute_ranges(data: pd.DataFrame) -> dict[str, tuple]:
        ranges = {}
        for col in data.columns:
            if pd.api.types.is_numeric_dtype(data[col]):
                ranges[col] = (data[col].min(), data[col].max())
            else:
                ranges[col] = (data[col].min(), data[col].max())  # 字符串的 min/max
        return ranges


class MondrianAnonymizer:
    """Mondrian K-匿名化引擎"""
    
    def __init__(self, config: KAnonymityConfig):
        self.config = config
    
    def anonymize(self, data: pd.DataFrame) -> pd.DataFrame:
        """执行 K-匿名化"""
        if len(data) < self.config.k_value:
            raise ValueError(
                f"数据集行数 {len(data)} 小于 K={self.config.k_value}，无法满足 K-匿名要求"
            )
        
        qi_data = data[self.config.quasi_identifiers + 
                       self.config.sensitive_attributes + 
                       [c for c in data.columns if c not in self.config.quasi_identifiers 
                        and c not in self.config.sensitive_attributes]].copy()
        
        # 初始分区
        initial = Partition(data=qi_data, qi_ranges=Partition._compute_ranges(qi_data))
        
        # 递归分割
        partitions = self._recursive_split(initial)
        
        # 泛化输出
        result_parts = []
        for p in partitions:
            generalized = p.generalize()
            result_parts.append(generalized)
        
        result = pd.concat(result_parts, ignore_index=True)
        return result
    
    def _recursive_split(self, partition: Partition) -> list[Partition]:
        """递归分割直到不可再分"""
        if not partition.can_split(self.config.k_value):
            return [partition]
        
        split_dim = partition.find_best_split_dim(self.config.k_value)
        if split_dim is None:
            return [partition]
        
        left, right = partition.split(split_dim, self.config.k_value)
        
        return (self._recursive_split(left) + self._recursive_split(right))
```

### 4.2 差分隐私 Laplace 机制

对数值型统计查询添加 Laplace 噪声，实现 ε-差分隐私。

```python
"""
差分隐私 Laplace 机制

保证：对于任意两个仅差一条记录的相邻数据集 D 和 D'，
查询结果 f(D) 和 f(D') 的分布比值 ≤ exp(ε)。

敏感度 (Sensitivity)：查询函数在相邻数据集上的最大输出差。
  - 计数查询敏感度 = 1
  - 求和查询敏感度 = |单条记录最大值|
  - 均值查询敏感度 = |单条记录最大值| / |D|
"""

import numpy as np
from dataclasses import dataclass


@dataclass
class DPConfig:
    """差分隐私配置"""
    epsilon: float = 1.0         # 隐私预算 ε (越小越隐私，噪声越大)
    delta: float = 1e-6          # 松弛参数 δ (Gaussian 机制用)
    mechanism: str = "laplace"   # laplace | gaussian
    sensitivity: float = 1.0     # 查询敏感度
    random_state: int | None = None  # 随机种子 (测试用，生产不设)


class DifferentialPrivacyEngine:
    """差分隐私引擎"""
    
    def __init__(self, config: DPConfig):
        self.config = config
        self._rng = np.random.default_rng(config.random_state)
        self._budget_consumed = 0.0  # 已消耗的隐私预算
    
    @property
    def remaining_budget(self) -> float:
        """剩余隐私预算"""
        return max(0.0, self.config.epsilon - self._budget_consumed)
    
    def apply_laplace(self, true_value: float) -> float:
        """
        对单个数值添加 Laplace 噪声
        
        Laplace 噪声: scale = sensitivity / epsilon
        """
        if self.remaining_budget <= 0:
            raise RuntimeError(
                f"隐私预算已耗尽: consumed={self._budget_consumed:.4f}, "
                f"epsilon={self.config.epsilon:.4f}"
            )
        
        scale = self.config.sensitivity / self.config.epsilon
        noise = self._rng.laplace(0, scale)
        result = true_value + noise
        
        self._budget_consumed += self.config.epsilon
        return result
    
    def apply_gaussian(self, true_value: float) -> float:
        """
        对单个数值添加 Gaussian 噪声 (ε, δ)-差分隐私
        
        Gaussian 标准差: σ = sensitivity * sqrt(2 * ln(1.25/δ)) / ε
        """
        if self.remaining_budget <= 0:
            raise RuntimeError("隐私预算已耗尽")
        
        sigma = (self.config.sensitivity * 
                 np.sqrt(2 * np.log(1.25 / self.config.delta)) / 
                 self.config.epsilon)
        noise = self._rng.normal(0, sigma)
        result = true_value + noise
        
        self._budget_consumed += self.config.epsilon
        return result
    
    def apply_to_count(self, true_count: int) -> int:
        """计数查询差分隐私 (敏感度=1)"""
        self.config.sensitivity = 1.0
        noisy = self.apply_laplace(float(true_count))
        return max(0, int(round(noisy)))  # 计数不可能为负
    
    def apply_to_sum(self, values: list[float], 
                     clip_lower: float, clip_upper: float) -> float:
        """求和查询差分隐私 (先裁剪再计算)"""
        # 裁剪以控制敏感度
        clipped = [max(clip_lower, min(clip_upper, v)) for v in values]
        true_sum = sum(clipped)
        self.config.sensitivity = max(abs(clip_lower), abs(clip_upper))
        return self.apply_laplace(true_sum)
    
    def apply_to_mean(self, values: list[float],
                      clip_lower: float, clip_upper: float) -> float:
        """均值查询差分隐私"""
        clipped = [max(clip_lower, min(clip_upper, v)) for v in values]
        n = len(clipped)
        if n == 0:
            return 0.0
        true_mean = sum(clipped) / n
        self.config.sensitivity = max(abs(clip_lower), abs(clip_upper)) / n
        return self.apply_laplace(true_mean)


class PrivacyBudgetManager:
    """
    隐私预算管理器
    
    管理一个数据集在整个生命周期内的总隐私预算，
    防止通过多次查询逐渐消耗隐私保护。
    
    采用串行组合定理 (Serial Composition):
    如果对同一数据集执行 k 次 ε_i-差分隐私查询，
    总隐私保证为 Σε_i。
    """
    
    def __init__(self, total_epsilon: float):
        self.total_epsilon = total_epsilon
        self.consumed = 0.0
        self.query_history: list[dict] = []
    
    def request_budget(self, epsilon: float, query_name: str) -> bool:
        """请求隐私预算"""
        if self.consumed + epsilon > self.total_epsilon:
            remaining = self.total_epsilon - self.consumed
            raise RuntimeError(
                f"隐私预算不足: 请求 {epsilon:.4f}，"
                f"剩余 {remaining:.4f}，"
                f"查询 '{query_name}' 被拒绝"
            )
        
        self.consumed += epsilon
        self.query_history.append({
            'query_name': query_name,
            'epsilon_used': epsilon,
            'cumulative_epsilon': self.consumed,
        })
        return True
    
    def get_budget_report(self) -> dict:
        """获取隐私预算使用报告"""
        return {
            'total_epsilon': self.total_epsilon,
            'consumed_epsilon': round(self.consumed, 4),
            'remaining_epsilon': round(self.total_epsilon - self.consumed, 4),
            'query_count': len(self.query_history),
            'queries': self.query_history,
        }
```

```python
"""
