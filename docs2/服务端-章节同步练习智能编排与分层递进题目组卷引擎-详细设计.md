# 服务端-章节同步练习智能编排与分层递进题目组卷引擎 详细设计

## 1. 概述

### 1.1 模块定位

章节同步练习智能编排引擎是连接"同步课堂学习"与"练习测评"两大核心模块之间的桥梁。当学生完成某个教材章节的学习后，系统需要基于该章节的知识点结构，自动编排一套分层递进的练习集——从基础巩固到综合提升再到挑战拓展——确保学生通过梯度化练习实现对章节内容的深度掌握。

与现有引擎的区别：

| 引擎 | 核心场景 | 与本引擎区别 |
| --- | --- | --- |
| 智能组卷与自适应测试引擎 | 考试场景，生成完整试卷 | 本引擎面向课后练习场景，不追求试卷仿真，而是知识巩固 |
| 题目智能推荐与个性化练习编排服务 | 单题粒度的个性化推荐 | 本引擎以章节为粒度，生成结构化练习集 |
| 练习答题实时自适应难度调节引擎 | 答题过程中动态调题 | 本引擎在答题前生成完整练习集，是自适应调节的前置输入 |

### 1.2 核心职责

1. **章节练习集生成**：根据教材版本、年级、学科、章节，生成结构化分层练习集。
2. **知识点覆盖保障**：确保练习集覆盖该章节所有核心知识点，无遗漏。
3. **难度分层编排**：按"基础→提升→综合→挑战"四级难度递进排列题目。
4. **题型多样化**：根据学科特点和章节内容，混合搭配选择题、填空题、判断题、解答题等。
5. **个性化适配**：基于学生当前掌握度，调整各难度层级的题目比例和数量。
6. **练习模板管理**：支持预习练习、课后巩固、单元复习、章节测试等多种练习场景模板。
7. **时间预估**：根据题目数量和难度，估算预计完成时间。

### 2.1 核心实体定义

#### 2.1.1 PracticeTemplate（练习模板）

```java
/**
 * 练习模板 - 定义不同练习场景的编排规则
 */
@Data
@Entity
@Table(name = "practice_template")
public class PracticeTemplate {
    
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    /** 模板编码 */
    @Column(name = "template_code", unique = true, nullable = false, length = 64)
    private String templateCode;  // PREVIEW_PRACTICE / CONSOLIDATION_PRACTICE / UNIT_REVIEW / CHAPTER_TEST
    
    /** 模板名称 */
    @Column(name = "template_name", nullable = false, length = 128)
    private String templateName;
    
    /** 适用场景描述 */
    @Column(name = "description", length = 512)
    private String description;
    
    /** 总题量范围 - 最小 */
    @Column(name = "min_question_count")
    private Integer minQuestionCount;
    
    /** 总题量范围 - 最大 */
    @Column(name = "max_question_count")
    private Integer maxQuestionCount;
    
    /** 基础题占比(%) */
    @Column(name = "basic_ratio")
    private Integer basicRatio;  // 默认 40
    
    /** 提升题占比(%) */
    @Column(name = "intermediate_ratio")
    private Integer intermediateRatio;  // 默认 30
    
    /** 综合题占比(%) */
    @Column(name = "comprehensive_ratio")
    private Integer comprehensiveRatio;  // 默认 20
    
    /** 挑战题占比(%) */
    @Column(name = "challenge_ratio")
    private Integer challengeRatio;  // 默认 10
    
    /** 预估每题平均用时(秒) */
    @Column(name = "avg_time_per_question_sec")
    private Integer avgTimePerQuestionSec;
    
    /** 是否允许跨章节出题 */
    @Column(name = "cross_chapter_enabled")
    private Boolean crossChapterEnabled;  // 单元复习/章节测试可设为 true
    
    /** 适用学段 (逗号分隔: KINDERGARTEN,PRIMARY,JUNIOR,SENIOR) */
    @Column(name = "applicable_stages", length = 256)
    private String applicableStages;
    
    /** 状态: DRAFT / ACTIVE / DEPRECATED */
    @Column(name = "status", nullable = false, length = 32)
    private String status;
    
    /** 排序权重 */
    @Column(name = "sort_weight")
    private Integer sortWeight;
    
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}
```

#### 2.1.2 PracticeSet（练习集）

```java
/**
 * 练习集 - 一次章节练习编排的产物
 */
@Data
@Entity
@Table(name = "practice_set")
public class PracticeSet {
    
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    /** 练习集唯一标识 */
    @Column(name = "set_uuid", unique = true, nullable = false, length = 36)
    private String setUuid;
    
    /** 学生用户ID */
    @Column(name = "user_id", nullable = false)
    private Long userId;
    
    /** 练习模板ID */
    @Column(name = "template_id")
    private Long templateId;
    
    /** 学科ID */
    @Column(name = "subject_id", nullable = false)
    private Long subjectId;
    
    /** 教材版本ID */
    @Column(name = "textbook_id", nullable = false)
    private Long textbookId;
    
    /** 年级 */
    @Column(name = "grade_level", nullable = false, length = 32)
    private String gradeLevel;  // GRADE_1 ~ GRADE_12
    
    /** 章节ID */
    @Column(name = "chapter_id", nullable = false)
    private Long chapterId;
    
    /** 章节路径 (如 "人教版/七年级上/第三章/一元一次方程") */
    @Column(name = "chapter_path", length = 512)
    private String chapterPath;
    
    /** 练习场景: PREVIEW / CONSOLIDATION / UNIT_REVIEW / CHAPTER_TEST */
    @Column(name = "scenario", nullable = false, length = 32)
    private String scenario;
    
    /** 题目总数 */
    @Column(name = "total_questions", nullable = false)
    private Integer totalQuestions;
    
    /** 基础题数 */
    @Column(name = "basic_count")
    private Integer basicCount;
    
    /** 提升题数 */
    @Column(name = "intermediate_count")
    private Integer intermediateCount;
    
    /** 综合题数 */
    @Column(name = "comprehensive_count")
    private Integer comprehensiveCount;
    
    /** 挑战题数 */
    @Column(name = "challenge_count")
    private Integer challengeCount;
    
    /** 覆盖的知识点ID列表 (JSON数组) */
    @Column(name = "covered_knowledge_points", columnDefinition = "JSON")
    private String coveredKnowledgePoints;  // [1001, 1002, 1003...]
    
    /** 预估完成时长(秒) */
    @Column(name = "estimated_duration_sec")
    private Integer estimatedDurationSec;
    
    /** 状态: GENERATED / IN_PROGRESS / COMPLETED / EXPIRED */
    @Column(name = "status", nullable = false, length = 32)
    private String status;
    
    /** 关联的练习会话ID (PracticeSession ID) */
    @Column(name = "practice_session_id")
    private String practiceSessionId;
    
    /** 个性化参数快照 (JSON) */
    @Column(name = "personalization_snapshot", columnDefinition = "JSON")
    private String personalizationSnapshot;
    // {"masteryLevels": {"kp_1001": 0.3, "kp_1002": 0.7}, "weakPoints": [1001], "adjustmentFactor": 0.8}
    
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
    
    @OneToMany(mappedBy = "practiceSetId", cascade = CascadeType.ALL)
    private List<PracticeSetItem> items;
}
```

```java
    @Column(name = "is_cross_chapter")
    private Boolean isCrossChapter;

    @Column(name = "selection_reason", length = 256)
    private String selectionReason;
```

```sql
-- 练习模板表
CREATE TABLE practice_template (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    min_question_count INT DEFAULT 8,

    textbook_id BIGINT NOT NULL,

    intermediate_count INT DEFAULT 0,

    estimated_duration_sec INT,
    status VARCHAR(32) NOT NULL DEFAULT 'GENERATED',

    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_chapter_textbook (chapter_id, textbook_id),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='练习集';

-- 练习集题目项表
CREATE TABLE practice_set_item (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    practice_set_id BIGINT NOT NULL,
    question_id BIGINT NOT NULL,
    question_uuid VARCHAR(36),

    recommended_count_consolidation INT DEFAULT 12,
    recommended_count_review INT DEFAULT 25,
    recommended_count_test INT DEFAULT 20,
```

```java
/**
 * 缓存键设计
 */
public class PracticeCacheKeys {
    
    // 章节可用题池缓存 (Hash结构: difficulty_tier -> List<questionId>)
    // TTL: 2小时 (题库更新时主动失效)
    public static String chapterQuestionPool(Long textbookId, Long chapterId) {
        return "practice:pool:" + textbookId + ":" + chapterId;
    }
    
    // 学生章节掌握度缓存
    // TTL: 30分钟
    public static String userChapterMastery(Long userId, Long chapterId) {
        return "practice:mastery:" + userId + ":" + chapterId;
    }
    
    // 练习模板列表缓存
    // TTL: 1小时
    public static String templateList() {
        return "practice:templates:active";
    }
    
    // 章节练习画像缓存
    // TTL: 2小时
    public static String chapterProfile(Long textbookId, Long chapterId) {
        return "practice:profile:" + textbookId + ":" + chapterId;
    }
    
    // 练习集详情缓存 (生成后不变, 可长缓存)
    // TTL: 24小时
    public static String practiceSetDetail(String setUuid) {
        return "practice:set:" + setUuid;
    }
    
    // 防重复生成锁
    // TTL: 30秒
    public static String generateLock(Long userId, Long chapterId, String scenario) {
        return "practice:lock:" + userId + ":" + chapterId + ":" + scenario;
    }
}
```

### 3.1 接口列表

### 3.2 核心接口详细定义

#### 3.2.1 生成章节练习集

```
POST /api/v1/practice/sets/generate
Authorization: Bearer {token}
Content-Type: application/json
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| textbookId | Long | 是 | 教材版本ID |
| chapterId | Long | 是 | 章节ID |
| subjectId | Long | 是 | 学科ID |
| gradeLevel | String | 是 | 年级 |
| scenario | String | 是 | 练习场景: PREVIEW/CONSOLIDATION/UNIT_REVIEW/CHAPTER_TEST |
| customConfig | Object | 否 | 自定义配置，覆盖模板默认值 |
| customConfig.totalQuestions | Integer | 否 | 指定题目总数 |
| customConfig.difficultyRatioOverride | Map | 否 | 覆盖默认难度比例 |
| customConfig.questionTypes | List | 否 | 限制题型 |
| customConfig.excludeQuestionIds | List | 否 | 排除已完成/已做错的题目 |
| customConfig.crossChapterEnabled | Boolean | 否 | 是否允许跨章节出题 |
| customConfig.timeLimitMin | Integer | 否 | 限时练习(分钟) |

### 4.2 难度分层与知识点覆盖算法

这是本引擎的核心算法，采用**贪心+回溯**策略在题库中选出一组满足多重约束的题目集合。

```java
/**
 * 分层递进选题算法核心实现
 */
@Service
public class PracticeSetAssemblyEngine {
    
    @Autowired
    private QuestionPoolService questionPoolService;
    
    @Autowired
    private KnowledgePointService kpService;
    
    @Autowired
    private StudentMasteryService masteryService;
    
    /**
     * 组装练习集题目列表
     * 
     * @param context 编排上下文(包含章节、模板、掌握度等)
     * @return 有序题目列表
     */
    public List<PracticeSetItem> assemblePracticeSet(AssemblyContext context) {
        // 1. 解析目标题量和难度分布
        int totalCount = context.getTargetCount();
        DifficultyDistribution dist = context.getResolvedDifficultyDistribution();
        // dist = {BASIC: 6, INTERMEDIATE: 4, COMPREHENSIVE: 1, CHALLENGE: 1}
        
        // 2. 获取章节核心知识点 (按重要性排序)
        List<KnowledgePoint> coreKps = kpService.getCoreKnowledgePoints(
            context.getTextbookId(), context.getChapterId());
        
        // 3. 获取学生各知识点掌握度
        Map<Long, Double> masteryMap = masteryService.getMasteryLevels(
            context.getUserId(), 
            coreKps.stream().map(KnowledgePoint::getId).collect(Collectors.toList()));
        
        // 4. 各难度层级分别选题
        List<Question> selectedQuestions = new ArrayList<>();
        Set<Long> usedQuestionIds = new HashSet<>(context.getExcludeQuestionIds());
        Map<Long, Integer> kpCoverageCount = new HashMap<>(); // 记录每个知识点已被覆盖的次数
        
        // 4.1 基础题层 - 目标：覆盖所有核心知识点的基础概念
        List<Question> basicQuestions = selectBasicTier(
            context, dist.getBasic(), coreKps, masteryMap, usedQuestionIds, kpCoverageCount);
        selectedQuestions.addAll(basicQuestions);
        
        // 4.2 提升题层 - 目标：强化薄弱知识点，引入简单综合
        List<Question> intermediateQuestions = selectIntermediateTier(
            context, dist.getIntermediate(), coreKps, masteryMap, usedQuestionIds, kpCoverageCount);
        selectedQuestions.addAll(intermediateQuestions);
        
        // 4.3 综合题层 - 目标：多知识点交叉，章节内综合应用
        List<Question> comprehensiveQuestions = selectComprehensiveTier(
            context, dist.getComprehensive(), coreKps, masteryMap, usedQuestionIds, kpCoverageCount);
        selectedQuestions.addAll(comprehensiveQuestions);
        
        // 4.4 挑战题层 - 目标：高难度拓展，跨章节或创新题型
        List<Question> challengeQuestions = selectChallengeTier(
            context, dist.getChallenge(), coreKps, masteryMap, usedQuestionIds, kpCoverageCount);
        selectedQuestions.addAll(challengeQuestions);
        
        // 5. 知识点覆盖校验与补题
        List<Long> uncoveredKps = findUncoveredKps(coreKps, kpCoverageCount);
        if (!uncoveredKps.isEmpty()) {
            fillCoverageGaps(context, uncoveredKps, selectedQuestions, usedQuestionIds);
        }
        
        // 6. 题型多样性校验与调整
        adjustQuestionTypeDiversity(selectedQuestions, context);
        
        // 7. 按难度递进排序
        sortByDifficultyAsc(selectedQuestions, context);
        
        // 8. 转换为 PracticeSetItem
        return convertToItems(selectedQuestions, context);
    }
    
    /**
     * 基础题层选题策略
     * 策略：优先为每个核心知识点选1道基础题；薄弱知识点选2道
     */
    private List<Question> selectBasicTier(
            AssemblyContext ctx, int count,
            List<KnowledgePoint> coreKps,
            Map<Long, Double> masteryMap,
            Set<Long> usedIds,
            Map<Long, Integer> kpCoverage) {
        
        List<Question> result = new ArrayList<>();
        int remaining = count;
        
        // 按掌握度从低到高排序知识点
        List<KnowledgePoint> sortedKps = coreKps.stream()
            .sorted(Comparator.comparingDouble(kp -> masteryMap.getOrDefault(kp.getId(), 0.0)))
            .collect(Collectors.toList());
        
        // 第一轮：每个知识点分配1道
        for (KnowledgePoint kp : sortedKps) {
            if (remaining <= 0) break;
            
            int allocation = 1;
            // 掌握度低于0.4的知识点多分配1道
            double mastery = masteryMap.getOrDefault(kp.getId(), 0.0);
            if (mastery < 0.4 && remaining > sortedKps.size()) {
                allocation = 2;
            }
            
            allocation = Math.min(allocation, remaining);
            
            List<Question> candidates = questionPoolService.getQuestionsByKpAndDifficulty(
                kp.getId(), 
                DifficultyRange.BASIC, // difficulty 0.1 - 0.4
                ctx.getQuestionTypes(),
                ctx.getExcludeQuestionIds(),
                allocation + 2 // 多取几个做选择
            );
            
            // 去重并选取
            List<Question> picked = candidates.stream()
                .filter(q -> !usedIds.contains(q.getId()))
                .limit(allocation)
                .collect(Collectors.toList());
            
            result.addAll(picked);
            picked.forEach(q -> {
                usedIds.add(q.getId());
                incrementKpCoverage(kpCoverage, q.getKnowledgePointIds());
            });
            remaining -= picked.size();
        }
        
        // 第二轮：如果还有余额，随机补充基础题
        if (remaining > 0) {
            List<Question> extra = questionPoolService.getRandomQuestionsByChapter(
                ctx.getTextbookId(), ctx.getChapterId(),
                DifficultyRange.BASIC,
                ctx.getQuestionTypes(),
                usedIds,
                remaining);
            result.addAll(extra);
            extra.forEach(q -> {
                usedIds.add(q.getId());
                incrementKpCoverage(kpCoverage, q.getKnowledgePointIds());
            });
        }
        
        return result;
    }
    
    /**
     * 提升题层选题策略
     * 策略：聚焦薄弱知识点，选择中等难度题；引入单知识点变式题
     */
    private List<Question> selectIntermediateTier(
            AssemblyContext ctx, int count,
            List<KnowledgePoint> coreKps,
            Map<Long, Double> masteryMap,
            Set<Long> usedIds,
            Map<Long, Integer> kpCoverage) {
        
        List<Question> result = new ArrayList<>();
        
        // 计算各知识点权重：掌握度越低权重越高
        Map<Long, Double> kpWeights = new HashMap<>();
        for (KnowledgePoint kp : coreKps) {
            double mastery = masteryMap.getOrDefault(kp.getId(), 0.0);
            // 权重 = (1 - mastery) ^ 2，拉大差距
            double weight = Math.pow(1 - mastery, 2);
            kpWeights.put(kp.getId(), weight);
        }
        
        // 按权重分配题量
        Map<Long, Integer> allocation = allocateByWeight(kpWeights, count);
        
        for (Map.Entry<Long, Integer> entry : allocation.entrySet()) {
            Long kpId = entry.getKey();
            int kpCount = entry.getValue();
            if (kpCount == 0) continue;
            
            List<Question> candidates = questionPoolService.getQuestionsByKpAndDifficulty(
                kpId,
                DifficultyRange.INTERMEDIATE, // difficulty 0.4 - 0.65
                ctx.getQuestionTypes(),
                usedIds,
                kpCount + 2);
            
            List<Question> picked = candidates.stream()
                .filter(q -> !usedIds.contains(q.getId()))
                .limit(kpCount)
                .collect(Collectors.toList());
            
            result.addAll(picked);
            picked.forEach(q -> {
                usedIds.add(q.getId());
                incrementKpCoverage(kpCoverage, q.getKnowledgePointIds());
            });
        }
        
        // 余额处理
        while (result.size() < count) {
            List<Question> extra = questionPoolService.getRandomQuestionsByChapter(
                ctx.getTextbookId(), ctx.getChapterId(),
                DifficultyRange.INTERMEDIATE,
                ctx.getQuestionTypes(),
                usedIds,
                count - result.size());
            if (extra.isEmpty()) break;
            result.addAll(extra);
            extra.forEach(q -> {
                usedIds.add(q.getId());
                incrementKpCoverage(kpCoverage, q.getKnowledgePointIds());
            });
        }
        
        return result;
    }
    
    /**
     * 综合题层选题策略
     * 策略：选择多知识点交叉题，模拟真实考试中的综合应用
     */
    private List<Question> selectComprehensiveTier(
            AssemblyContext ctx, int count,
            List<KnowledgePoint> coreKps,
            Map<Long, Double> masteryMap,
            Set<Long> usedIds,
            Map<Long, Integer> kpCoverage) {
        
        List<Question> result = new ArrayList<>();
        
        // 优先选择多知识点标签的题目 (知识点交叉题)
        List<Question> crossKpQuestions = questionPoolService.getMultiKpQuestionsByChapter(
            ctx.getTextbookId(), ctx.getChapterId(),
            DifficultyRange.COMPREHENSIVE, // difficulty 0.65 - 0.8
            ctx.getQuestionTypes(),
            usedIds,
            count + 3);
        
        // 按"覆盖未覆盖知识点"的优先级排序
        List<Long> poorlyCoveredKps = kpCoverage.entrySet().stream()
            .filter(e -> e.getValue() <= 1) // 只被覆盖0或1次的知识点
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
        
        List<Question> sorted = crossKpQuestions.stream()
            .sorted((q1, q2) -> {
                int score1 = calculateCoverageScore(q1, poorlyCoveredKps);
                int score2 = calculateCoverageScore(q2, poorlyCoveredKps);
                return Integer.compare(score2, score1); // 降序
            })
            .limit(count)
            .collect(Collectors.toList());
        
        result.addAll(sorted);
        result.forEach(q -> {
            usedIds.add(q.getId());
            incrementKpCoverage(kpCoverage, q.getKnowledgePointIds());
        });
        
        // 不足则从单知识点综合题中补充
        if (result.size() < count) {
            List<Question> extra = questionPoolService.getRandomQuestionsByChapter(
                ctx.getTextbookId(), ctx.getChapterId(),
                DifficultyRange.COMPREHENSIVE,
                ctx.getQuestionTypes(),
                usedIds,
                count - result.size());
            result.addAll(extra);
            extra.forEach(q -> {
                usedIds.add(q.getId());
                incrementKpCoverage(kpCoverage, q.getKnowledgePointIds());
            });
        }
        
        return result;
    }
    
    /**
     * 挑战题层选题策略
     * 策略：高难度题，可以是跨章节综合题、竞赛题、变式探究题
     */
    private List<Question> selectChallengeTier(
            AssemblyContext ctx, int count,
            List<KnowledgePoint> coreKps,
            Map<Long, Double> masteryMap,
            Set<Long> usedIds,
            Map<Long, Integer> kpCoverage) {
        
        // 如果章节没有挑战级题目，允许从跨章节或变式生成
        List<Question> candidates = questionPoolService.getRandomQuestionsByChapter(
            ctx.getTextbookId(), ctx.getChapterId(),
            DifficultyRange.CHALLENGE, // difficulty 0.8 - 1.0
            ctx.getQuestionTypes(),
            usedIds,
            count);
        
        if (candidates.size() < count && ctx.isCrossChapterEnabled()) {
            // 跨章节补充
            int deficit = count - candidates.size();
            List<Question> crossChapter = questionPoolService.getCrossChapterQuestions(
                ctx.getTextbookId(), ctx.getChapterId(),
                DifficultyRange.CHALLENGE,
                ctx.getQuestionTypes(),
                usedIds,
                deficit);
            candidates.addAll(crossChapter);
        }
        
        candidates.forEach(q -> {
            usedIds.add(q.getId());
            incrementKpCoverage(kpCoverage, q.getKnowledgePointIds());
        });
        
        return candidates;
    }
    
    /**
     * 计算题目对未充分覆盖知识点的覆盖得分
     */
    private int calculateCoverageScore(Question q, List<Long> poorlyCoveredKps) {
        return (int) q.getKnowledgePointIds().stream()
            .filter(poorlyCoveredKps::contains)
            .count();
    }
    
    /**
     * 按权重分配题量
     */
    private Map<Long, Integer> allocateByWeight(Map<Long, Double> weights, int totalCount) {
        Map<Long, Integer> allocation = new HashMap<>();
        double totalWeight = weights.values().stream().mapToDouble(Double::doubleValue).sum();
        
        if (totalWeight <= 0) {
            // 均分
            int per = totalCount / weights.size();
            int remainder = totalCount % weights.size();
            int idx = 0;
            for (Long kpId : weights.keySet()) {
                allocation.put(kpId, per + (idx++ < remainder ? 1 : 0));
            }
            return allocation;
        }
        
        int allocated = 0;
        for (Map.Entry<Long, Double> entry : weights.entrySet()) {
            int count = (int) Math.round(entry.getValue() / totalWeight * totalCount);
            allocation.put(entry.getKey(), count);
            allocated += count;
        }
        
        // 修正舍入误差
        if (allocated != totalCount) {
            Long maxKp = Collections.max(weights.entrySet(), 
                Map.Entry.comparingByValue()).getKey();
            allocation.merge(maxKp, totalCount - allocated, Integer::sum);
        }
        
        return allocation;
    }
    
    // ... 辅助方法省略
}
```

### 4.3 个性化难度比例微调

```java
/**
 * 根据学生掌握度动态微调难度比例
 */
@Service
public class DifficultyRatioAdjuster {
    
    /**
     * 微调难度比例
     * 
     * @param baseRatio 模板默认比例 {BASIC: 40, INTERMEDIATE: 30, COMPREHENSIVE: 20, CHALLENGE: 10}
     * @param avgMastery 学生章节平均掌握度 (0.0-1.0)
     * @param weakKpRatio 薄弱知识点占比
     * @return 调整后的比例
     */
    public DifficultyDistribution adjust(
            DifficultyDistribution baseRatio, 
            double avgMastery, 
            double weakKpRatio) {
        
        int basic = baseRatio.getBasicRatio();
        int intermediate = baseRatio.getIntermediateRatio();
        int comprehensive = baseRatio.getComprehensiveRatio();
        int challenge = baseRatio.getChallengeRatio();
        
        // 掌握度低 → 增加基础题比例
        // 掌握度高 → 增加综合/挑战题比例
        int adjustment = 0;
        
        if (avgMastery < 0.3) {
            // 严重薄弱：大幅增加基础题
            adjustment = 15;
        } else if (avgMastery < 0.5) {
            // 薄弱：适度增加基础题
            adjustment = 10;
        } else if (avgMastery < 0.7) {
            // 中等：轻微增加基础题
            adjustment = 5;
        } else if (avgMastery > 0.85) {
            // 优秀：增加综合和挑战题
            adjustment = -10;
        }
        
        basic = Math.min(70, basic + adjustment);
        
        if (adjustment > 0) {
            // 从综合和挑战中扣除
            int deductFromComp = Math.min(comprehensive, adjustment / 2);
            int deductFromChallenge = Math.min(challenge, adjustment - deductFromComp);
            comprehensive -= deductFromComp;
            challenge -= deductFromChallenge;
            // 如果还不够，从提升中扣
            int remaining = adjustment - deductFromComp - deductFromChallenge;
            if (remaining > 0) {
                intermediate = Math.max(10, intermediate - remaining);
            }
        } else if (adjustment < 0) {
            // 从基础和提升中转移至综合和挑战
            int transfer = -adjustment;
            int fromBasic = Math.min(basic - 20, transfer / 2); // 基础题不低于20%
            int fromIntermediate = Math.min(intermediate - 15, transfer - fromBasic); // 提升不低于15%
            comprehensive += fromBasic;
            challenge += fromIntermediate;
            basic -= fromBasic;
            intermediate -= fromIntermediate;
        }
        
        // 确保比例为100
        int sum = basic + intermediate + comprehensive + challenge;
        if (sum != 100) {
            basic += (100 - sum); // 差额补到基础题
        }
        
        return new DifficultyDistribution(basic, intermediate, comprehensive, challenge);
    }
}
```

### 4.4 题目排序策略

```java
/**
 * 练习集内题目排序 - 实现难度递进+知识点交替
 */
@Service
public class PracticeSetSorter {
    
    /**
     * 排序策略：
     * 1. 先按难度层级分组 (BASIC → INTERMEDIATE → COMPREHENSIVE → CHALLENGE)
     * 2. 层内按"知识点交替"排序，避免连续同知识点
     * 3. 层内首题选最简单/最基础的，建立信心
     */
    public List<PracticeSetItem> sort(List<PracticeSetItem> items) {
        List<PracticeSetItem> result = new ArrayList<>();
        
        // 按难度层级分组
        Map<String, List<PracticeSetItem>> byTier = items.stream()
            .collect(Collectors.groupingBy(PracticeSetItem::getDifficultyTier));
        
        String[] tierOrder = {"BASIC", "INTERMEDIATE", "COMPREHENSIVE", "CHALLENGE"};
        
        for (String tier : tierOrder) {
            List<PracticeSetItem> tierItems = byTier.get(tier);
            if (tierItems == null || tierItems.isEmpty()) continue;
            
            // 层内排序：知识点交替 + 难度系数递增
            tierItems.sort(Comparator
                .comparingDouble(PracticeSetItem::getDifficultyCoefficient));
            
            // 知识点交替排列 (避免连续出现相同知识点)
            List<PracticeSetItem> alternated = alternateByKp(tierItems);
            
            result.addAll(alternated);
        }
        
        // 重新编号
        for (int i = 0; i < result.size(); i++) {
            result.get(i).setSequenceNo(i + 1);
        }
        
        return result;
    }
    
    /**
     * 知识点交替排列算法 (贪心)
     */
    private List<PracticeSetItem> alternateByKp(List<PracticeSetItem> items) {
        if (items.size() <= 1) return new ArrayList<>(items);
        
        List<PracticeSetItem> result = new ArrayList<>();
        List<PracticeSetItem> remaining = new ArrayList<>(items);
        Set<Long> recentKps = new HashSet<>(); // 最近2题的知识点
        
        while (!remaining.isEmpty()) {
            PracticeSetItem best = null;
            int bestScore = Integer.MIN_VALUE;
            
            for (PracticeSetItem item : remaining) {
                // 计算得分：与最近知识点不重叠的优先
                Set<Long> itemKps = parseKpIds(item.getKnowledgePointIds());
                Set<Long> intersection = new HashSet<>(itemKps);
                intersection.retainAll(recentKps);
                int score = -intersection.size();
                
                // 难度系数低的稍微优先 (层内仍保持递增趋势)
                score -= item.getDifficultyCoefficient() != null 
                    ? item.getDifficultyCoefficient().intValue() : 0;
                
                if (score > bestScore) {
                    bestScore = score;
                    best = item;
                }
            }
            
            if (best == null) best = remaining.get(0);
            
            result.add(best);
            remaining.remove(best);
            
            // 更新最近知识点窗口
            recentKps = parseKpIds(best.getKnowledgePointIds());
        }
        
        return result;
    }
    
    private Set<Long> parseKpIds(String json) {
        // JSON数组解析为Set<Long>
        if (json == null || json.isBlank()) return Collections.emptySet();
        return JsonUtils.parseArray(json, Long.class).stream()
            .collect(Collectors.toSet());
    }
}
```

### 6.1 生成练习集核心服务

```java
/**
 * 章节同步练习编排服务
 */
@Service
@Slf4j
public class ChapterPracticeService {
    
    @Autowired private PracticeTemplateRepository templateRepo;
    @Autowired private PracticeSetRepository practiceSetRepo;
    @Autowired private ChapterPracticeProfileRepository profileRepo;
    @Autowired private KnowledgePointService kpService;
    @Autowired private StudentMasteryService masteryService;
    @Autowired private QuestionPoolService questionPoolService;
    @Autowired private PracticeSetAssemblyEngine assemblyEngine;
    @Autowired private DifficultyRatioAdjuster ratioAdjuster;
    @Autowired private PracticeSetSorter sorter;
    @Autowired private PracticeSessionService sessionService;
    @Autowired private RedisTemplate<String, Object> redisTemplate;
    @Autowired private RateLimiter rateLimiter;
    
    /**
     * 生成章节练习集
     */
    @Transactional
    public PracticeSetDTO generatePracticeSet(GeneratePracticeRequest request, Long userId) {
        
        // 1. 防重复检查 - 分布式锁
        String lockKey = PracticeCacheKeys.generateLock(userId, request.getChapterId(), request.getScenario());
        Boolean locked = redisTemplate.opsForValue().setIfAbsent(lockKey, "1", Duration.ofSeconds(30));
        if (Boolean.FALSE.equals(locked)) {
            throw new BusinessException("PRACTICE_005", "练习集生成中，请稍候");
        }
        
        try {
            // 2. 频率限制
            if (!rateLimiter.tryAcquire("practice:gen:" + userId + ":" + request.getChapterId(), 
                    3, 5, TimeUnit.MINUTES)) {
                throw new BusinessException("PRACTICE_005", "生成频率超限，5分钟内最多3次");
            }
            
            // 3. 检查是否有进行中的同场景练习集
            Optional<PracticeSet> existing = practiceSetRepo
                .findByUserIdAndChapterIdAndScenarioAndStatus(
                    userId, request.getChapterId(), request.getScenario(), "IN_PROGRESS");
            if (existing.isPresent() && !request.isForceNew()) {
                throw new BusinessException("PRACTICE_004", 
                    "已有进行中的同场景练习集，请先完成或放弃: " + existing.get().getSetUuid());
            }
            
            // 4. 加载练习模板
            PracticeTemplate template = templateRepo
                .findByTemplateCode(scenarioToTemplateCode(request.getScenario()))
                .orElseThrow(() -> new BusinessException("PRACTICE_003", "不支持的练习场景: " + request.getScenario()));
            
            // 5. 获取章节核心知识点
            List<KnowledgePoint> coreKps = kpService.getCoreKnowledgePoints(
                request.getTextbookId(), request.getChapterId());
            if (coreKps.isEmpty()) {
                throw new BusinessException("PRACTICE_001", "该章节未配置知识点");
            }
            
            // 6. 获取学生掌握度
            Map<Long, Double> masteryMap = masteryService.getMasteryLevels(userId,
                coreKps.stream().map(KnowledgePoint::getId).collect(Collectors.toList()));
            double avgMastery = masteryMap.values().stream()
                .mapToDouble(Double::doubleValue).average().orElse(0.0);
            long weakKpCount = masteryMap.values().stream().filter(m -> m < 0.5).count();
            double weakKpRatio = (double) weakKpCount / coreKps.size();
            
            // 7. 计算最终难度分布
            DifficultyDistribution dist = computeDifficultyDistribution(template, request, avgMastery, weakKpRatio);
            
            // 8. 计算最终题量
            int totalQuestions = computeTotalCount(template, request, coreKps.size(), dist);
            
            // 9. 构建编排上下文
            AssemblyContext context = AssemblyContext.builder()
                .userId(userId)
                .textbookId(request.getTextbookId())
                .chapterId(request.getChapterId())
                .subjectId(request.getSubjectId())
                .gradeLevel(request.getGradeLevel())
                .scenario(request.getScenario())
                .targetCount(totalQuestions)
                .resolvedDifficultyDistribution(dist)
                .questionTypes(request.getCustomConfig() != null ? request.getCustomConfig().getQuestionTypes() : null)
                .excludeQuestionIds(collectExcludeIds(userId, request))
                .crossChapterEnabled(template.getCrossChapterEnabled())
                .masteryMap(masteryMap)
                .coreKps(coreKps)
                .build();
            
            // 10. 组装题目
            List<PracticeSetItem> items = assemblyEngine.assemblePracticeSet(context);
            
            if (items.size() < totalQuestions * 0.8) {
                log.warn("题目数量不足, 目标={}, 实际={}, 章节={}", totalQuestions, items.size(), request.getChapterId());
                // 仍然返回，但标注题库不足
            }
            
            // 11. 排序
            items = sorter.sort(items);
            
            // 12. 持久化
            PracticeSet practiceSet = buildPracticeSet(
                userId, request, template, dist, totalQuestions, items, 
                masteryMap, avgMastery, weakKpRatio);
            practiceSet = practiceSetRepo.save(practiceSet);
            
            // 13. 创建练习会话
            String sessionId = sessionService.createSession(
                userId, practiceSet.getSetUuid(), items, request.getTimeLimitMin());
            practiceSet.setPracticeSessionId(sessionId);
            practiceSetRepo.save(practiceSet);
            
            // 14. 缓存
            PracticeSetDTO dto = PracticeSetDTO.from(practiceSet, items);
            redisTemplate.opsForValue().set(
                PracticeCacheKeys.practiceSetDetail(practiceSet.getSetUuid()),
                dto, Duration.ofHours(24));
            
            return dto;
            
        } finally {
            redisTemplate.delete(lockKey);
        }
    }
    
    /**
     * 计算最终难度分布
     */
    private DifficultyDistribution computeDifficultyDistribution(
            PracticeTemplate template,
            GeneratePracticeRequest request,
            double avgMastery,
            double weakKpRatio) {
        
        DifficultyDistribution base = new DifficultyDistribution(
            template.getBasicRatio(),
            template.getIntermediateRatio(),
            template.getComprehensiveRatio(),
            template.getChallengeRatio());
        
        // 个性化微调
        DifficultyDistribution adjusted = ratioAdjuster.adjust(base, avgMastery, weakKpRatio);
        
        // 用户自定义覆盖
        if (request.getCustomConfig() != null && request.getCustomConfig().getDifficultyRatioOverride() != null) {
            Map<String, Integer> override = request.getCustomConfig().getDifficultyRatioOverride();
            adjusted = new DifficultyDistribution(
                override.getOrDefault("BASIC", adjusted.getBasicRatio()),
                override.getOrDefault("INTERMEDIATE", adjusted.getIntermediateRatio()),
                override.getOrDefault("COMPREHENSIVE", adjusted.getComprehensiveRatio()),
                override.getOrDefault("CHALLENGE", adjusted.getChallengeRatio()));
        }
        
        // 校验比例之和
        if (adjusted.sum() != 100) {
            throw new BusinessException("PRACTICE_010", 
                "难度比例之和必须为100，当前: " + adjusted.sum());
        }
        
        return adjusted;
    }
    
    /**
     * 计算最终题量
     */
    private int computeTotalCount(PracticeTemplate template, GeneratePracticeRequest request,
                                   int coreKpCount, DifficultyDistribution dist) {
        // 用户自定义优先
        if (request.getCustomConfig() != null && request.getCustomConfig().getTotalQuestions() != null) {
            int custom = request.getCustomConfig().getTotalQuestions();
            return Math.max(template.getMinQuestionCount(), 
                   Math.min(template.getMaxQuestionCount(), custom));
        }
        
        // 基于知识点数量和模板默认推荐
        int recommended;
        switch (request.getScenario()) {
            case "PREVIEW":
                recommended = Math.max(5, Math.min(10, coreKpCount + 2));
                break;
            case "CONSOLIDATION":
                // 每个核心知识点至少1道基础+1道提升，再加少量综合/挑战
                recommended = Math.max(template.getMinQuestionCount(),
                    Math.min(template.getMaxQuestionCount(), coreKpCount * 2 + 2));
                break;
            case "UNIT_REVIEW":
                recommended = Math.max(15, Math.min(40, coreKpCount * 3));
                break;
            case "CHAPTER_TEST":
                recommended = Math.max(15, Math.min(30, coreKpCount * 2 + 5));
                break;
            default:
                recommended = 12;
        }
        
        return recommended;
    }
    
    /**
     * 收集需要排除的题目ID (近7天已做过的)
     */
    private List<Long> collectExcludeIds(Long userId, GeneratePracticeRequest request) {
        List<Long> excluded = new ArrayList<>();
        if (request.getCustomConfig() != null && request.getCustomConfig().getExcludeQuestionIds() != null) {
            excluded.addAll(request.getCustomConfig().getExcludeQuestionIds());
        }
        // 从答题记录中获取最近7天已答过的题目
        excluded.addAll(masteryService.getRecentAnsweredQuestionIds(userId, 7));
        return excluded;
    }
    
    private String scenarioToTemplateCode(String scenario) {
        return switch (scenario) {
            case "PREVIEW" -> "PREVIEW_PRACTICE";
            case "CONSOLIDATION" -> "CONSOLIDATION_PRACTICE";
            case "UNIT_REVIEW" -> "UNIT_REVIEW";
            case "CHAPTER_TEST" -> "CHAPTER_TEST";
            default -> throw new BusinessException("PRACTICE_003", "未知场景: " + scenario);
        };
    }
}
```

### 7.2 题库不足降级策略

```java
/**
 * 题库不足时的降级策略
 */
@Service
public class PracticeDegradationHandler {
    
    /**
     * 当某难度层级题目不足时的降级方案
     */
    public DegradationResult handleInsufficientQuestions(
            DifficultyDistribution targetDist,
            Map<String, Integer> actualCounts,
            Long chapterId) {
        
        List<String> warnings = new ArrayList<>();
        Map<String, Integer> adjusted = new HashMap<>(actualCounts);
        
        for (String tier : List.of("BASIC", "INTERMEDIATE", "COMPREHENSIVE", "CHALLENGE")) {
            int target = targetDist.getCount(tier);
            int actual = actualCounts.getOrDefault(tier, 0);
            
            if (actual < target) {
                int deficit = target - actual;
                warnings.add(String.format("%s层题目不足，目标%d题，实际%d题", tier, target, actual));
                
                // 尝试从相邻难度层借题
                String adjacentTier = findAdjacentTierWithSurplus(tier, actualCounts, targetDist);
                if (adjacentTier != null) {
                    // 从相邻层借用
                    int borrowFrom = Math.min(deficit, 
                        actualCounts.get(adjacentTier) - targetDist.getCount(adjacentTier));
                    if (borrowFrom > 0) {
                        adjusted.merge(adjacentTier, -borrowFrom, Integer::sum);
                        adjusted.merge(tier, borrowFrom, Integer::sum);
                        warnings.add(String.format("从%s层借用%d题", adjacentTier, borrowFrom));
                    }
                }
            }
        }
        
        return new DegradationResult(adjusted, warnings);
    }
    
    private String findAdjacentTierWithSurplus(
            String tier, Map<String, Integer> actual, DifficultyDistribution target) {
        // CHALLENGE → 找 COMPREHENSIVE
        // COMPREHENSIVE → 找 INTERMEDIATE 或 CHALLENGE
        // INTERMEDIATE → 找 BASIC 或 COMPREHENSIVE
        // BASIC → 找 INTERMEDIATE
        String[] adjacents = switch (tier) {
            case "CHALLENGE" -> new String[]{"COMPREHENSIVE"};
            case "COMPREHENSIVE" -> new String[]{"INTERMEDIATE", "CHALLENGE"};
            case "INTERMEDIATE" -> new String[]{"BASIC", "COMPREHENSIVE"};
            case "BASIC" -> new String[]{"INTERMEDIATE"};
            default -> new String[]{};
        };
        
        for (String adj : adjacents) {
            int surplus = actual.getOrDefault(adj, 0) - target.getCount(adj);
            if (surplus > 0) return adj;
        }
        return null;
    }
}
```

### 7.3 题目排重兜底

```java
/**
 * 当题库去重后题目严重不足时，逐步放宽排除条件
 */
public List<Long> relaxedExcludeStrategy(Long userId, int targetCount, 
        List<Long> initialExcludeIds, QuestionPoolService pool) {
    
    // 策略1: 排除近7天做题
    List<Long> exclude = new ArrayList<>(initialExcludeIds);
    List<Long> candidates = pool.getCandidates(exclude);
    if (candidates.size() >= targetCount) return candidates;
    
    // 策略2: 只排除近3天做题
    exclude = pool.getRecentAnsweredIds(userId, 3);
    candidates = pool.getCandidates(exclude);
    if (candidates.size() >= targetCount) return candidates;
    
    // 策略3: 只排除近1天做题
    exclude = pool.getRecentAnsweredIds(userId, 1);
    candidates = pool.getCandidates(exclude);
    if (candidates.size() >= targetCount) return candidates;
    
    // 策略4: 不排除任何题
    return pool.getCandidates(Collections.emptyList());
}
```

```java
/**
 * 练习集生成过程中的并行查询
 */
@Service
public class ParallelDataProvider {
    
    @Autowired private KnowledgePointService kpService;
    @Autowired private StudentMasteryService masteryService;
    @Autowired private ChapterPracticeProfileRepository profileRepo;
    
    private final ExecutorService executor = Executors.newFixedThreadPool(
        Runtime.getRuntime().availableProcessors(),
        new ThreadFactoryBuilder().setNameFormat("practice-assembly-%d").build());
    
    /**
     * 并行加载编排所需数据
     */
    public AssemblyContext loadDataParallel(Long userId, Long textbookId, Long chapterId) {
        CompletableFuture<List<KnowledgePoint>> kpFuture = CompletableFuture.supplyAsync(
            () -> kpService.getCoreKnowledgePoints(textbookId, chapterId), executor);
        
        CompletableFuture<ChapterPracticeProfile> profileFuture = CompletableFuture.supplyAsync(
            () -> profileRepo.findByTextbookIdAndChapterId(textbookId, chapterId)
                .orElseGet(() -> buildDefaultProfile(textbookId, chapterId)), executor);
        
        // 知识点拿到后再并行查掌握度
        CompletableFuture<Map<Long, Double>> masteryFuture = kpFuture.thenComposeAsync(kps -> {
            List<Long> kpIds = kps.stream().map(KnowledgePoint::getId).collect(Collectors.toList());
            return CompletableFuture.supplyAsync(() -> 
                masteryService.getMasteryLevels(userId, kpIds), executor);
        });
        
        // 等待全部完成
        CompletableFuture.allOf(kpFuture, profileFuture, masteryFuture).join();
        
        return AssemblyContext.builder()
            .coreKps(kpFuture.join())
            .profile(profileFuture.join())
            .masteryMap(masteryFuture.join())
            .build();
    }
}
```
