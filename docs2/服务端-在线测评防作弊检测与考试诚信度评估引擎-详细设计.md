## 1. 概述

### 1.1 设计目标

为 PrimeTop 的在线考试模拟、真题练习、阶段测评等测评类场景提供端到端的防作弊检测与考试诚信度评估能力，保障在线测评结果的可信度和公平性。

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 非侵入式 | 检测逻辑以旁路事件收集 + 异步分析为主，不阻塞答题主流程 |
| 分层防御 | 客户端行为采集 → 服务端实时风控 → 离线批量分析三层结合 |
| 隐私优先 | 不采集与考试无关的个人隐私数据；摄像头/麦克风仅在未来版本可选启用 |
| 可解释 | 每一条作弊嫌疑记录均附带检测规则、证据链和置信度分数 |
| 可申诉 | 所有作弊判定支持学生/家长申诉与人工复核 |

### 1.3 与现有模块的边界

| 已有模块 | 覆盖范围 | 本模块差异 |
| --- | --- | --- |
| 用户学习行为异常检测与作弊行为识别服务 | 日常学习场景的异常行为（机器人刷题、多开分身等） | **聚焦考试测评场景**，覆盖切屏、复制粘贴、答案雷同、答题节奏异常等考试特有模式 |
| 设备指纹与反作弊风控引擎 | 设备维度的风控（设备指纹、模拟器检测、root/越狱） | **聚焦考试会话维度**，在设备风控基础上叠加考试行为分析 |
| 练习测评会话服务与答题流程状态机 | 答题流程的状态机管理（开始→答题→提交→批改） | 本模块在答题状态机旁路注入作弊检测事件 |

## 4. 行为事件采集协议

### 4.1 客户端采集架构

```dart
/// 客户端行为采集器 (Flutter 伪代码)
class ExamBehaviorCollector {
  final String sessionId;
  final StreamController<ExamBehaviorEvent> _controller = StreamController.broadcast();
  int _sequenceNo = 0;
  Timer? _heartbeatTimer;
  
  /// 初始化采集器，注册系统级回调
  void init() {
    // 监听APP生命周期
    AppLifecycleListener(onStateChange: _onLifecycleChange);
    
    // 监听截屏
    ScreenshotDetector.onScreenshot = () => _emit('screenshot', {});
    
    // 监听剪贴板
    ClipboardObserver.onChange = (text) => _emit('clipboard_paste', {'length': text?.length ?? 0});
    
    // 监听屏幕状态
    ScreenStateObserver.onScreenOff = () => _emit('screen_off', {});
    ScreenStateObserver.onScreenOn = () => _emit('screen_on', {});
    
    // 检测分屏
    MultiWindowDetector.onMultiWindowEnter = () => _emit('multi_window_detect', {});
    
    // 心跳上报（每30秒）
    _heartbeatTimer = Timer.periodic(Duration(seconds: 30), (_) => _sendHeartbeat());
  }
  
  void _emit(String type, Map<String, dynamic> data) {
    final event = ExamBehaviorEvent(
      eventId: Uuid().v4(),
      sessionId: sessionId,
      type: type,
      clientTime: DateTime.now().millisecondsSinceEpoch,
      sequenceNo: ++_sequenceNo,
      data: data,
    );
    _controller.add(event);
    _sendBatch([event]);
  }
  
  /// 批量上报到服务端
  Future<void> _sendBatch(List<ExamBehaviorEvent> events) async {
    try {
      await apiClient.post('/exam/anti-cheat/events/batch', data: {
        'sessionId': sessionId,
        'events': events.map((e) => e.toJson()).toList(),
      });
    } catch (e) {
      // 本地队列缓存，稍后重试
      _localQueue.addAll(events);
    }
  }
}
```

```java
/**
 * 风控规则引擎核心接口
 */
public interface AntiCheatRule {
    
    /** 规则唯一标识 */
    String getRuleId();
    
    /** 规则分类 */
    RuleCategory getCategory();
    
    /** 评估单个事件 */

        return RuleEvalResult.pass();
    }
}

/** 规则评估结果 */
@Data
@Builder
public class RuleEvalResult {
    private boolean triggered;           // 是否触发
    private String ruleId;               // 触发的规则ID

    private double riskWeight;           // 风险权重分

    private Map<String, Object> evidence; // 证据数据
    private IntegrityAction action;       // 建议动作

        return RuleEvalResult.builder()
            .triggered(false)
            .confidence(0)
            .riskWeight(0)
            .action(IntegrityAction.NONE)
            .build();
    }
}

public enum IntegrityAction {
    NONE,           // 无动作
```

#### 5.3.1 APP后台切换检测规则

```java
/**
 * APP后台切换检测规则
 * 检测考生在考试过程中切换到其他应用的行为
 */
@Component
public class AppBackgroundRule implements AntiCheatRule {
    
    private static final String RULE_ID = "R_APP_BG_SERIOUS";
    private static final String RULE_ID_MINOR = "R_APP_BG_WARN";
    
    // 后台时长阈值（毫秒）
    private static final long SHORT_BG_THRESHOLD = 3_000;   // 3秒以内视为短暂
    private static final long LONG_BG_THRESHOLD  = 10_000;  // 10秒以上视为严重
    
    // 累计后台次数阈值
    private static final int MAX_BG_COUNT = 3;
    
    @Override
    public String getRuleId() { return RULE_ID; }
    
    @Override
    public RuleCategory getCategory() { return RuleCategory.APP_SWITCH; }
    
    @Override
    public RuleEvalResult evaluate(ExamBehaviorEvent event, ExamSessionContext ctx) {
        if (event.getType() != ExamBehaviorEventType.APP_FOREGROUND) {
            return RuleEvalResult.pass();
        }
        
        // 查找对应的 APP_BACKGROUND 事件，计算后台时长
        ExamBehaviorEvent bgEvent = ctx.findLastEvent(ExamBehaviorEventType.APP_BACKGROUND);
        if (bgEvent == null) return RuleEvalResult.pass();
        
        long bgDuration = event.getClientTime() - bgEvent.getClientTime();
        int bgCount = ctx.getEventCount(ExamBehaviorEventType.APP_BACKGROUND);
        
        Map<String, Object> evidence = new HashMap<>();
        evidence.put("bgDurationMs", bgDuration);
        evidence.put("bgCount", bgCount);
        evidence.put("currentQuestionId", event.getQuestionId());
        
        // 判定严重程度
        if (bgDuration >= LONG_BG_THRESHOLD || bgCount >= MAX_BG_COUNT) {
            return RuleEvalResult.builder()
                .triggered(true)
                .ruleId(RULE_ID)
                .confidence(Math.min(1.0, (bgDuration / (double) LONG_BG_THRESHOLD) * 0.5 + (bgCount / (double) MAX_BG_COUNT) * 0.5))
                .riskWeight(15)
                .severity("severe")
                .evidence(evidence)
                .action(IntegrityAction.CLIENT_WARNING)
                .build();
        }
        
        // 短暂后台也记录（但风险较低）
        if (bgDuration >= SHORT_BG_THRESHOLD) {
            return RuleEvalResult.builder()
                .triggered(true)
                .ruleId(RULE_ID_MINOR)
                .confidence(0.3 + (bgDuration / (double) LONG_BG_THRESHOLD) * 0.3)
                .riskWeight(3)
                .severity("minor")
                .evidence(evidence)
                .action(IntegrityAction.SILENT_LOG)
                .build();
        }
        
        return RuleEvalResult.pass();
    }
}
```

#### 5.3.2 过快答题检测规则

```java
/**
 * 过快答题检测规则
 * 检测答题速度异常快的情况，可能表示提前知道答案或使用工具
 */
@Component
public class FastAnswerRule implements AntiCheatRule {
    
    private static final String RULE_ID = "R_FAST_ANSWER";
    
    @Override
    public String getRuleId() { return RULE_ID; }
    
    @Override
    public RuleCategory getCategory() { return RuleCategory.ANSWER_BEHAVIOR; }
    
    @Override
    public RuleEvalResult evaluate(ExamBehaviorEvent event, ExamSessionContext ctx) {
        // 只在提交答案时触发
        if (event.getType() != ExamBehaviorEventType.ANSWER_SUBMIT) return RuleEvalResult.pass();
        
        Long questionId = event.getQuestionId();
        if (questionId == null) return RuleEvalResult.pass();
        
        // 获取该题的查看开始时间
        ExamBehaviorEvent viewStart = ctx.findEventMatching(e -> 
            e.getType() == ExamBehaviorEventType.QUESTION_VIEW_START 
            && questionId.equals(e.getQuestionId()));
        if (viewStart == null) return RuleEvalResult.pass();
        
        long answerDuration = event.getClientTime() - viewStart.getClientTime();
        
        // 获取题目预估时间（从题目元数据）
        Integer estimatedTime = ctx.getEstimatedTimeForQuestion(questionId);
        if (estimatedTime == null || estimatedTime <= 0) return RuleEvalResult.pass();
        
        long estimatedMs = estimatedTime * 1000L;
        double ratio = (double) answerDuration / estimatedMs;
        
        // 答题时间小于预估时间 10% 且绝对时间 < 5秒
        if (ratio < 0.1 && answerDuration < 5_000) {
            Map<String, Object> evidence = new HashMap<>();
            evidence.put("answerDurationMs", answerDuration);
            evidence.put("estimatedDurationMs", estimatedMs);
            evidence.put("ratio", ratio);
            evidence.put("questionId", questionId);
            
            return RuleEvalResult.builder()
                .triggered(true)
                .ruleId(RULE_ID)
                .confidence(0.6 + (1 - ratio) * 0.3)
                .riskWeight(8)
                .severity("moderate")
                .evidence(evidence)
                .action(IntegrityAction.SILENT_LOG)
                .build();
        }
        
        return RuleEvalResult.pass();
    }
}
```

#### 5.3.3 答案雷同检测（离线）

```java
/**
 * 答案雷同检测（离线批处理）
 * 通过比较同一套试卷不同考生的答案序列，检测异常相似性
 */
@Component
public class AnswerSimilarityJob {
    
    /**
     * 执行答案雷同分析
     * @param examId 考试ID
     */
    public void analyzeAnswerSimilarity(Long examId) {
        // 1. 获取所有已提交的试卷答案
        List<ExamAnswerSheet> sheets = answerSheetService.getByExamId(examId);
        if (sheets.size() < 2) return;
        
        // 2. 两两比较答案序列
        for (int i = 0; i < sheets.size(); i++) {
            for (int j = i + 1; j < sheets.size(); j++) {
                ExamAnswerSheet s1 = sheets.get(i);
                ExamAnswerSheet s2 = sheets.get(j);
                
                SimilarityResult result = computeSimilarity(s1, s2);
                
                if (result.getSimilarity() > 0.95) {
                    // 高相似度，进一步检查错误模式是否一致
                    double errorPatternMatch = computeErrorPatternSimilarity(s1, s2);
                    
                    if (errorPatternMatch > 0.85) {
                        // 错误模式也高度一致，大概率抄袭
                        createViolationRecords(s1, s2, result, errorPatternMatch);
                    }
                }
            }
        }
    }
    
    /**
     * 计算答案相似度（基于 Jaccard 相似系数 + 字符串编辑距离）
     */
    private SimilarityResult computeSimilarity(ExamAnswerSheet s1, ExamAnswerSheet s2) {
        List<AnswerEntry> answers1 = s1.getAnswers();
        List<AnswerEntry> answers2 = s2.getAnswers();
        
        int totalQuestions = Math.min(answers1.size(), answers2.size());
        if (totalQuestions == 0) return SimilarityResult.empty();
        
        int identical = 0;
        int bothWrong = 0;
        int bothWrongAndSameWrongAnswer = 0;
        
        for (int k = 0; k < totalQuestions; k++) {
            AnswerEntry a1 = answers1.get(k);
            AnswerEntry a2 = answers2.get(k);
            
            boolean isAnswerEqual = Objects.equals(a1.getAnswer(), a2.getAnswer());
            boolean a1Correct = a1.isCorrect();
            boolean a2Correct = a2.isCorrect();
            
            if (isAnswerEqual) {
                identical++;
                if (!a1Correct && !a2Correct) {
                    bothWrongAndSameWrongAnswer++;
                }
            }
            
            if (!a1Correct && !a2Correct) bothWrong++;
        }
        
        double similarity = (double) identical / totalQuestions;
        
        // 关键指标：错误答案也完全一致的比例
        // 正常情况下两个水平差不多的学生错同一题且选同一个错误选项的概率很低
        double wrongAnswerMatchRate = bothWrong > 0 ? 
            (double) bothWrongAndSameWrongAnswer / bothWrong : 0;
        
        return SimilarityResult.builder()
            .similarity(similarity)
            .wrongAnswerMatchRate(wrongAnswerMatchRate)
            .totalQuestions(totalQuestions)
            .identicalCount(identical)
            .build();
    }
    
    private void createViolationRecords(ExamAnswerSheet s1, ExamAnswerSheet s2,
                                         SimilarityResult sim, double errorPattern) {
        // 为两个考生都创建违规记录
        for (ExamAnswerSheet sheet : List.of(s1, s2)) {
            ExamViolationRecord record = ExamViolationRecord.builder()
                .sessionId(sheet.getSessionId())
                .userId(sheet.getUserId())
                .examId(sheet.getExamId())
                .ruleId("R_ANSWER_SIMILARITY")
                .ruleName("答案雷同检测")
                .ruleCategory(RuleCategory.ANSWER_SIMILARITY)
                .severity("severe")
                .confidence(Math.min(1.0, sim.getSimilarity() * 0.5 + errorPattern * 0.5))
                .evidence(Map.of(
                    "similarity", sim.getSimilarity(),
                    "wrongAnswerMatchRate", sim.getWrongAnswerMatchRate(),
                    "errorPatternMatch", errorPattern,
                    "comparedWith", sheet.equals(s1) ? s2.getUserId() : s1.getUserId(),
                    "totalQuestions", sim.getTotalQuestions()
                ))
                .detectedAt(LocalDateTime.now())
                .status("detected")
                .build();
            violationRecordMapper.insert(record);
        }
    }
}
```

### 5.4 风险评分引擎

```java
/**
 * 综合风险评分引擎
 * 将多个规则的触发结果汇总为统一的风险分数和等级
 */
@Component
public class RiskScoringEngine {
    
    // 各分类的权重上限
    private static final Map<RuleCategory, Double> CATEGORY_MAX_WEIGHT = Map.of(
        RuleCategory.ENVIRONMENT,     40.0,  // 环境问题最严重
        RuleCategory.DEVICE_ANOMALY,  35.0,
        RuleCategory.COLLABORATION,   40.0,
        RuleCategory.CONTENT_COPY,    25.0,
        RuleCategory.APP_SWITCH,      20.0,
        RuleCategory.ANSWER_BEHAVIOR, 15.0,
        RuleCategory.TIME_ANOMALY,    20.0,
        RuleCategory.ANSWER_SIMILARITY, 25.0
    );
    
    /**
     * 计算综合风险评分
     */
    public RiskScore computeScore(List<RuleEvalResult> triggeredRules) {
        if (triggeredRules.isEmpty()) {
            return RiskScore.of(0, RiskLevel.CLEAN);
        }
        
        // 按分类分组，每类取最大权重（避免同类规则叠加）
        Map<RuleCategory, Double> categoryScores = new HashMap<>();
        for (RuleEvalResult result : triggeredRules) {
            if (!result.isTriggered()) continue;
            
            AntiCheatRule rule = ruleRegistry.get(result.getRuleId());
            RuleCategory cat = rule.getCategory();
            
            double weighted = result.getRiskWeight() * result.getConfidence();
            categoryScores.merge(cat, weighted, Math::max);
        }
        
        // 各分类分数封顶后求和，总分封顶100
        double totalScore = categoryScores.entrySet().stream()
            .mapToDouble(e -> Math.min(e.getValue(), CATEGORY_MAX_WEIGHT.getOrDefault(e.getKey(), 10.0)))
            .sum();
        
        totalScore = Math.min(totalScore, 100.0);
        
        // 映射到风险等级
        RiskLevel level = mapToLevel(totalScore);
        
        return RiskScore.of(totalScore, level, categoryScores);
    }
    
    private RiskLevel mapToLevel(double score) {
        if (score >= 85) return RiskLevel.CRITICAL;
        if (score >= 65) return RiskLevel.HIGH;
        if (score >= 40) return RiskLevel.MEDIUM;
        if (score >= 20) return RiskLevel.LOW;
        return RiskLevel.CLEAN;
    }
}
```

```java
/**
 * 考试诚信报告生成服务

@Service
public class IntegrityReportGenerator {
    
    /**
     * 生成最终诚信报告（考试结束后调用）
     */
    @Transactional
    public ExamIntegrityReport generate(Long sessionId) {
        // 1. 获取所有违规记录
        List<ExamViolationRecord> violations = violationRecordMapper
            .selectBySessionId(sessionId);
        
        // 2. 获取行为事件统计
        BehaviorStats stats = behaviorEventService.computeStats(sessionId);
        
        // 3. 获取实时风险评分
        RiskScore realtimeScore = riskScoringEngine.getLatestScore(sessionId);
        
        // 4. 等待离线分析结果（最多等待5分钟）
        Optional<OfflineAnalysisResult> offlineResult = 
            offlineAnalysisService.getResultIfReady(sessionId);
        
        // 5. 合并实时 + 离线风险分数
        RiskScore finalScore = mergeScores(realtimeScore, offlineResult);
        
        // 6. 生成违规摘要
        ViolationSummary summary = buildViolationSummary(violations);
        
        // 7. 确定处理建议
        IntegrityRecommendation recommendation = determineRecommendation(
            finalScore, violations, stats);
        
        // 8. 构建报告
        ExamIntegrityReport report = ExamIntegrityReport.builder()
            .reportId(generateReportId(sessionId))
            .sessionId(sessionId)
            .userId(stats.getUserId())
            .examId(stats.getExamId())
            .overallScore(100 - finalScore.getScore())  // 诚信分 = 100 - 风险分
            .riskLevel(finalScore.getLevel())
            .totalViolations(violations.size())
            .violationSummary(summary.toJson())
            .behaviorAnalysis(stats.toJson())
            .recommendation(recommendation)
            .detail(generateDetailText(summary, stats, recommendation))
            .generatedAt(LocalDateTime.now())
            .build();
        
        reportMapper.insert(report);
        
        // 9. 更新会话诚信状态
        updateSessionIntegrityStatus(sessionId, recommendation);
        
        // 10. 发送事件（通知考试系统、通知用户）
        eventPublisher.publishEvent(new IntegrityReportGeneratedEvent(report));
        
        return report;
    }
    
    private IntegrityRecommendation determineRecommendation(
            RiskScore score, 
            List<ExamViolationRecord> violations,
            BehaviorStats stats) {
        
        boolean hasCritical = violations.stream()
            .anyMatch(v -> "critical".equals(v.getSeverity()));
        boolean hasSevere = violations.stream()
            .anyMatch(v -> "severe".equals(v.getSeverity()));
        
        if (hasCritical && score.getLevel() == RiskLevel.CRITICAL) {
            return IntegrityRecommendation.INVALIDATE;
        }
        
        if (score.getLevel() == RiskLevel.HIGH || 
            (hasSevere && score.getLevel() == RiskLevel.MEDIUM)) {
            return IntegrityRecommendation.REVIEW;
        }
        
        if (score.getLevel() == RiskLevel.MEDIUM || score.getLevel() == RiskLevel.LOW) {
            return IntegrityRecommendation.WARNING;
        }
        
        return IntegrityRecommendation.ACCEPT;
    }
}
```

```java
/**
 * 答题时间序列模式分析
 * 检测机械化的答题节奏（如每隔固定时间选一题，可能是脚本自动答题）
 */
public class AnswerTimePatternAnalysis {
    
    public void analyze(Long sessionId) {
        List<ExamBehaviorEvent> submitEvents = behaviorEventMapper
            .selectBySessionAndType(sessionId, ExamBehaviorEventType.ANSWER_SUBMIT);
        
        if (submitEvents.size() < 10) return;  // 题目太少不分析
        
        // 计算相邻答题间隔
        List<Long> intervals = new ArrayList<>();
        for (int i = 1; i < submitEvents.size(); i++) {
            long interval = submitEvents.get(i).getClientTime() 
                          - submitEvents.get(i - 1).getClientTime();
            intervals.add(interval);
        }
        
        // 计算间隔的变异系数 (Coefficient of Variation)
        double mean = intervals.stream().mapToLong(l -> l).average().orElse(0);
        double stdDev = Math.sqrt(
            intervals.stream()
                .mapToDouble(l -> Math.pow(l - mean, 2))
                .average().orElse(0)
        );
        double cv = mean > 0 ? stdDev / mean : 0;
        
        // 变异系数极低 (< 0.1) 说明答题间隔高度规律，疑似脚本
        if (cv < 0.1 && intervals.size() > 20) {
            createViolation(sessionId, "R_TIME_PATTERN", Map.of(
                "coefficientOfVariation", cv,
                "meanInterval", mean,
                "totalQuestions", intervals.size() + 1,
                "intervals", intervals
            ));
        }
        
        // 检测等间隔模式
        long maxDeviation = intervals.stream()
            .mapToLong(l -> Math.abs(l - (long) mean))
            .max().orElse(0);
        if (maxDeviation < 500 && intervals.size() > 15) {  // 最大偏差 < 0.5秒
            createViolation(sessionId, "R_TIME_PATTERN", Map.of(
                "pattern", "fixed_interval",
                "intervalMs", (long) mean,
                "maxDeviationMs", maxDeviation
            ));
        }
    }
}
```

```java
/**
 * 同设备多账号检测
 * 检测同一台设备在同一考试中是否有多个账号登录
 */
public class DeviceCorrelationAnalysis {
    
    public void analyze(Long examId) {
        // 查询同考试所有会话的设备指纹
        List<ExamSessionDevice> devices = examSessionMapper
            .selectDeviceByExamId(examId);
        
        // 按设备指纹分组
        Map<String, List<ExamSessionDevice>> deviceGroups = devices.stream()
            .collect(Collectors.groupingBy(ExamSessionDevice::getDeviceFingerprint));
        
        for (Map.Entry<String, List<ExamSessionDevice>> entry : deviceGroups.entrySet()) {
            if (entry.getValue().size() > 1) {
                // 同一设备多个账号参加同一考试
                List<Long> userIds = entry.getValue().stream()
                    .map(ExamSessionDevice::getUserId)
                    .distinct()
                    .collect(Collectors.toList());
                
                if (userIds.size() > 1) {
                    // 为所有关联账号创建违规记录
                    for (ExamSessionDevice esd : entry.getValue()) {
                        createViolation(esd.getSessionId(), esd.getUserId(), examId, 
                            "R_COLLABORATION", Map.of(
                                "deviceFingerprint", entry.getKey(),
                                "associatedUsers", userIds,
                                "userCount", userIds.size()
                            ));
                    }
                }
            }
        }
        
        // 同一IP段分析（补充）
        analyzeSameIpGroup(devices);
    }
}
```

```dart
/// 安全环境检测器
class SecureEnvDetector {
  
  /// 执行全部环境检测
  Future<EnvCheckResult> runFullCheck() async {
    final checks = await Future.wait([
      _checkRootStatus(),
      _checkEmulator(),
      _checkDebugger(),
      _checkVirtualApp(),
      _checkAccessibilityService(),
      _checkScreenCasting(),
      _checkMultiWindow(),
    ]);
    
    final issues = <EnvIssue>[];
    bool mustFix = false;
    
    for (final check in checks) {
      if (check.issue != null) {
        issues.add(check.issue!);
        if (check.issue!.severity == 'critical' || 
            check.issue!.severity == 'severe') {
          mustFix = true;
        }
      }
    }
    
    return EnvCheckResult(
      passed: !mustFix,
      issues: issues,
      timestamp: DateTime.now().millisecondsSinceEpoch,
    );
  }
  
  /// Root检测 (Android)
  Future<SingleCheck> _checkRootStatus() async {
    if (!Platform.isAndroid) return SingleCheck.clean();
    
    final result = await MethodChannel('prime_top/security')
        .invokeMethod('checkRoot');
    
    if (result['isRooted'] == true) {
      return SingleCheck.withIssue(EnvIssue(
        code: 'DEVICE_ROOTED',
        severity: 'critical',
        message: '检测到设备已获取Root权限，无法参加考试',
        detail: result,
      ));
    }
    return SingleCheck.clean();
  }
  
  /// 模拟器检测
  Future<SingleCheck> _checkEmulator() async {
    final result = await MethodChannel('prime_top/security')
        .invokeMethod('checkEmulator');
    
    if (result['isEmulator'] == true) {
      return SingleCheck.withIssue(EnvIssue(
        code: 'EMULATOR_DETECTED',
        severity: 'critical',
        message: '检测到运行在模拟器环境中，无法参加考试',
        detail: result,
      ));
    }
    return SingleCheck.clean();
  }
  
  /// 分屏检测
  Future<SingleCheck> _checkMultiWindow() async {
    if (!Platform.isAndroid) return SingleCheck.clean();
    
    final isInMultiWindow = await MethodChannel('prime_top/security')
        .invokeMethod('isInMultiWindowMode');
    
    if (isInMultiWindow == true) {
      return SingleCheck.withIssue(EnvIssue(
        code: 'MULTI_WINDOW_MODE',
        severity: 'moderate',
        message: '检测到分屏模式，请退出分屏后继续考试',
      ));
    }
    return SingleCheck.clean();
  }
}
```

## 10. 异常处理与降级策略

### 10.1 采集层降级

| 场景 | 处理策略 |
| --- | --- |
| 网络中断，事件上报失败 | 本地队列缓存（SQLite），网络恢复后批量补传 |
| 本地队列超过 1000 条 | 丢弃低风险事件（type=heartbeat/navigation），保留高风险事件 |
| 客户端时间不准确 | 服务端以接收时间为准，标记 time_skew 事件 |
| 采集SDK崩溃 | 不影响答题主流程，记录错误日志并静默重启采集器 |

### 10.2 服务端降级

| 场景 | 处理策略 |
| --- | --- |
| Kafka 消费延迟 | 实时风控降级为仅检查 critical 级别规则 |
| Redis 连接异常 | 风险评分降级为 MySQL 直读，接受 200ms 延迟 |
| 离线分析任务超时 | 标记报告为 "preliminary"（初步报告），后续补充离线分析 |
| 规则引擎异常 | 降级为仅执行核心规则（设备检测 + APP切换），跳过复杂规则 |

## 11. 性能考量

### 11.1 数据量预估

| 指标 | 预估值 | 说明 |
| --- | --- | --- |
| 单次考试事件数 | 200-800 条/人 | 50题考试约产生500条事件 |
| 事件平均大小 | 0.5-1.5 KB | 含JSON数据 |
| 并发考试人数 | 500-2000 人 | 高峰期同时在线考试 |
| 事件峰值QPS | 5,000-15,000 | 高峰期事件上报 |
| 单场考试违规记录 | 0-20 条/人 | 大多数考生无违规 |

### 11.2 性能优化措施

1. **事件批量上报**：客户端聚合 500ms 或 20 条事件后批量上报，减少请求次数
2. **Kafka 分区**：按 `sessionId` 分区，保证同会话事件顺序消费
3. **Redis 滑动窗口**：实时风控使用 Redis ZSet 维护事件滑动窗口，避免全量扫描
4. **ClickHouse 归档**：行为事件 7 天后从 MySQL 归档至 ClickHouse，MySQL 仅保留近期数据
5. **离线分析延迟**：考试结束后 10 分钟内完成离线分析并生成最终报告

## 12. 安全与合规

### 12.1 数据安全

- 行为事件数据属于用户行为数据，按个保法要求进行保护
- 证据数据（如截图）需加密存储，访问需权限校验
- 违规记录及诚信报告属于敏感个人信息，仅对用户本人和家长（未成年人）可见
- 离线分析结果的原始数据保留 6 个月后自动清理

### 12.2 未成年人保护

- 防作弊检测面向学生用户（多数为未成年人），需确保检测手段不侵犯隐私
- **不采集**摄像头画面、麦克风录音（未来版本如需开启，须单独获取监护人授权）
- **不采集**通讯录、短信、相册等与考试无关的隐私数据
- 检测结果通知未成年人时，措辞应客观、建设性，避免羞辱性表达

### 12.3 申诉与救济

- 所有 `severity >= severe` 的违规记录支持 7 天内申诉
- 申诉需提供文字说明，可附加截图证据
- 申诉由人工审核团队在 3 个工作日内处理
- 审核结果通知用户及家长（如已绑定）
- 申诉成功的违规记录标记为 `dismissed`，不计入诚信评分
