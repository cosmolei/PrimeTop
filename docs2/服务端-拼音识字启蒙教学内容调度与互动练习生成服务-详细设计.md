# 服务端-拼音识字启蒙教学内容调度与互动练习生成服务 - 详细设计

## 1. 模块概述

### 1.1 功能定位

为 PrimeTop 拼音识字启蒙模块提供后端核心服务能力，负责拼音与汉字教学内容的结构化管理、个性化学习路径编排、互动练习动态生成、语音评测集成与学习进度追踪。面向 3-8 岁幼儿及小学低年级学生，是该模块的服务端核心支撑。

### 1.2 设计目标

| 指标 | 目标 |
|------|------|
| 学习内容加载耗时 | ≤500ms（含练习题） |
| 练习题动态生成耗时 | ≤1s |
| 语音评测响应耗时 | ≤2s |
| 日学习进度保存成功率 | ≥99.9% |
| 内容覆盖率 | 覆盖人教版一至二年级全部生字 + 拼音基础 |

### 1.3 服务边界

**本服务负责：**
- 拼音教学内容（声母/韵母/整体认读/声调）的结构化存储与查询
- 汉字教学内容（笔画/偏旁/组词/造句/笔顺动画）的管理与分发
- 个性化学习路径编排（基于年龄/水平/进度动态调度下一学习单元）
- 互动练习题动态生成（听音选字、看图选词、拖拽组词、笔顺描红评测等）
- 语音发音评测集成（对接 ASR 服务，返回发音评分与纠正建议）
- 学习进度与掌握度追踪

**不在本服务范围：**
- 语音 ASR/TTS 引擎本身（由语音服务提供）
- 客户端动画渲染与描红交互（由客户端负责）
- 积分/成就结算（由积分服务负责）
- 家长控制与时长管理（由家长管控服务负责）

### 3.2 核心表定义

#### pinyin_unit（拼音学习单元）

```sql
CREATE TABLE pinyin_unit (
    id              INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    unit_code       VARCHAR(32) NOT NULL COMMENT '单元编码: PY-SHENG-01/PY-YUN-02/PY-ZT-01',
    unit_name       VARCHAR(64) NOT NULL COMMENT '单元名称: 声母第一课/韵母第二课',
    unit_type       VARCHAR(16) NOT NULL COMMENT '单元类型: shengmu/yunmu/zhengti/shengdiao',
    stage_order     INT UNSIGNED NOT NULL COMMENT '学习阶段排序(整体路径中的顺序)',
    
    -- 学习内容
    description     TEXT COMMENT '单元简介(教师/家长可见)',
    learning_objectives JSON NOT NULL COMMENT '学习目标列表',
    
    -- 关联
    textbook_id     INT UNSIGNED DEFAULT NULL COMMENT '关联教材ID',
    grade_code      VARCHAR(16) DEFAULT NULL COMMENT '适用年级: K/g1/g2',
    
    -- 状态
    status          TINYINT UNSIGNED DEFAULT 1 COMMENT '1-启用 2-禁用',
    
    created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    
    UNIQUE KEY uk_code (unit_code),
    INDEX idx_type_order (unit_type, stage_order)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='拼音学习单元';
```

#### pinyin_item（拼音项）

```sql
CREATE TABLE pinyin_item (
    id              INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    unit_id         INT UNSIGNED NOT NULL COMMENT '所属单元ID',
    pinyin          VARCHAR(8) NOT NULL COMMENT '拼音: a/o/e/b/p/m/f',
    pinyin_type     VARCHAR(16) NOT NULL COMMENT 'shengmu/yunmu/zhengti',
    
    -- 发音信息
    pronunciation   VARCHAR(64) NOT NULL COMMENT '发音描述: 嘴巴张大，发"啊"音',
    mouth_shape     VARCHAR(32) NOT NULL COMMENT '口型描述关键词',
    
    -- 排序与分组
    item_order      INT UNSIGNED NOT NULL COMMENT '单元内排序',
    group_tag       VARCHAR(32) DEFAULT NULL COMMENT '分组标签: b-p-m-f为一组',
    
    -- 媒体资源
    audio_url       VARCHAR(512) NOT NULL COMMENT '标准发音音频URL',
    video_url       VARCHAR(512) DEFAULT NULL COMMENT '口型示范视频URL',
    mouth_image_url VARCHAR(512) DEFAULT NULL COMMENT '口型示意图片URL',
    
    -- 关联汉字(示例字)
    example_chars   JSON NOT NULL COMMENT '示例汉字: [{"char":"爸","word":"爸爸","audio_url":"..."}]',
    
    -- 声调信息(韵母适用)
    tones           JSON DEFAULT NULL COMMENT '声调信息: [{"tone":1,"pinyin":"ā","audio_url":"..."},...]',
    
    status          TINYINT UNSIGNED DEFAULT 1 COMMENT '1-启用 2-禁用',
    
    created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    
    INDEX idx_unit (unit_id),
    INDEX idx_type_order (pinyin_type, item_order),
    UNIQUE KEY uk_pinyin (pinyin, pinyin_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='拼音项';
```

## 4. API 接口设计

### 4.1 练习类型枚举

```go
// ExerciseType 练习类型
type ExerciseType string

const (
    // 拼音练习
    ExerciseListenChooseChar   ExerciseType = "listen_choose_char"   // 听音选字：听发音选对应汉字
    ExerciseListenChoosePinyin ExerciseType = "listen_choose_pinyin" // 听音选拼音：听发音选拼音
    ExercisePinyinMatchChar    ExerciseType = "pinyin_match_char"    // 拼音配对汉字
    ExerciseToneIdentify       ExerciseType = "tone_identify"        // 声调辨别
    ExercisePinyinDictation    ExerciseType = "pinyin_dictation"     // 拼音听写

    // 识字练习
    ExerciseCharRecognize      ExerciseType = "char_recognize"       // 看字选读音
    ExerciseImageMatchChar     ExerciseType = "image_match_char"     // 看图选字
    ExerciseCharComponent      ExerciseType = "char_component"       // 拆字组字(偏旁+部件)
    ExerciseWordBuild          ExerciseType = "word_build"           // 组词(拖拽汉字)
    ExerciseSentenceFill       ExerciseType = "sentence_fill"        // 句子填空
    ExerciseStrokeOrder        ExerciseType = "stroke_order"         // 笔顺判断
    ExerciseStrokeTrace        ExerciseType = "stroke_trace"         // 描红评测

    // 语音练习
    ExercisePronunciation      ExerciseType = "pronunciation"        // 发音跟读
    ExerciseReadAloud          ExerciseType = "read_aloud"           // 朗读评测
)
```

## 5. 核心业务逻辑

### 5.1 练习题动态生成算法

练习题生成采用"目标驱动 + 随机组合"策略：

```go
// ExerciseGenerator 练习题生成器
type ExerciseGenerator struct {
    itemRepo      PinyinLiteracyItemRepository
    masteryRepo   UserItemMasteryRepository
    rand          *rand.Rand
}

// GenerateExercises 生成一组练习题
func (g *ExerciseGenerator) GenerateExercises(ctx context.Context, req GenerateRequest) (*ExerciseSession, error) {
    // 1. 加载目标学习项
    items, err := g.itemRepo.FindByIDs(ctx, req.ItemIDs)
    if err != nil {
        return nil, err
    }
    
    // 2. 获取用户对目标项的掌握度
    masteries := g.masteryRepo.FindByUserAndItems(ctx, req.UserID, req.ItemIDs)
    
    // 3. 根据练习类型分配题目数量
    exercisePlan := g.planExerciseDistribution(req, items, masteries)
    
    // 4. 逐个生成练习题
    var exercises []ExerciseItem
    for _, plan := range exercisePlan {
        ex, err := g.generateSingle(ctx, plan, items, masteries)
        if err != nil {
            return nil, err
        }
        exercises = append(exercises, ex)
    }
    
    // 5. 打乱顺序(确保相邻不重复同一项)
    g.shuffleWithNoAdjacentRepeat(exercises)
    
    return &ExerciseSession{
        UserID:        req.UserID,
        SessionType:   req.SessionType,
        ContentType:   req.ContentType,
        Exercises:     exercises,
    }, nil
}

// planExerciseDistribution 规划题目分配
func (g *ExerciseGenerator) planExerciseDistribution(
    req GenerateRequest, items []Item, masteries map[int64]*Mastery,
) []ExercisePlan {
    var plans []ExercisePlan
    remaining := req.Count
    
    for _, exerciseType := range req.ExerciseTypes {
        // 按掌握度加权分配：掌握度低的项获得更多练习
        weights := make(map[int64]float64)
        for _, item := range items {
            m := masteries[item.ID]
            if m == nil || m.MasteryScore < 0.8 {
                weights[item.ID] = 2.0 // 低掌握度权重翻倍
            } else {
                weights[item.ID] = 1.0
            }
        }
        
        count := remaining / len(req.ExerciseTypes)
        for i := 0; i < count; i++ {
            targetItemID := g.weightedSelect(weights)
            plans = append(plans, ExercisePlan{
                ExerciseType: exerciseType,
                TargetItemID: targetItemID,
                Difficulty:   req.Difficulty,
            })
            remaining--
        }
    }
    
    // 剩余名额补充 pronunciation 类型(强化语音)
    for remaining > 0 {
        plans = append(plans, ExercisePlan{
            ExerciseType: ExercisePronunciation,
            TargetItemID: items[g.rand.Intn(len(items))].ID,
            Difficulty:   req.Difficulty,
        })
        remaining--
    }
    
    return plans
}
```

### 5.2 干扰项生成策略

选择题的干扰项质量直接影响练习效果：

```go
// DistractionGenerator 干扰项生成器
type DistractionGenerator struct {
    itemRepo PinyinLiteracyItemRepository
}

// GenerateDistractors 生成干扰项
// 策略：1个形近干扰 + 1个音近干扰 + 1个随机干扰
func (d *DistractionGenerator) GenerateDistractors(
    ctx context.Context,
    targetItem Item,
    exerciseType ExerciseType,
    count int,
) ([]Distractor, error) {
    var distractors []Distractor
    
    switch exerciseType {
    case ExerciseListenChoosePinyin:
        // 形近干扰：b/d, p/q, m/n, ie/ei, iu/ui
        similar := d.findVisualSimilar(ctx, targetItem, 1)
        distractors = append(distractors, similar...)
        
        // 音近干扰：同组声母/韵母
        phonetic := d.findPhoneticSimilar(ctx, targetItem, 1)
        distractors = append(distractors, phonetic...)
        
    case ExerciseListenChooseChar:
        // 同音字/近音字干扰
        homophone := d.findHomophone(ctx, targetItem, 1)
        distractors = append(distractors, homophone...)
        
        // 同偏旁干扰
        sameRadical := d.findSameRadical(ctx, targetItem, 1)
        distractors = append(distractors, sameRadical...)
    }
    
    // 补充随机干扰直到达到数量
    for len(distractors) < count {
        random := d.findRandom(ctx, targetItem, 1)
        distractors = append(distractors, random...)
    }
    
    // 打乱顺序
    rand.Shuffle(len(distractors), func(i, j int) {
        distractors[i], distractors[j] = distractors[j], distractors[i]
    })
    
    return distractors[:count], nil
}
```

### 5.3 掌握度计算引擎

掌握度采用加权滑动窗口模型，近期表现权重更高：

```go
// MasteryCalculator 掌握度计算器
type MasteryCalculator struct{}

// MasteryWeights 掌握度计算权重
type MasteryWeights struct {
    RecognizeWeight  float64 // 识别类题目权重 0.3
    PronunciationWeight float64 // 发音评测权重 0.4
    WritingWeight    float64 // 书写/描红权重 0.3
}

// UpdateMastery 更新单项掌握度
func (mc *MasteryCalculator) UpdateMastery(
    current *Mastery,
    result ExerciseResult,
) *Mastery {
    // 基础增量
    delta := 0.0
    if result.IsCorrect {
        delta = 0.10 + mc.speedBonus(result.ResponseTimeMs)
    } else {
        delta = -0.05
        // 连续错误惩罚加重
        if current.ConsecutiveErrors >= 2 {
            delta = -0.10
        }
    }
    
    // 发音评测单独加权
    if result.PronunciationScore != nil {
        pronDelta := (*result.PronunciationScore - current.MasteryScore) * 0.3
        delta = delta*0.6 + pronDelta*0.4
    }
    
    // 应用衰减(防止不练习导致虚高)
    daysSinceLastPractice := time.Since(current.LastPracticedAt).Hours() / 24
    if daysSinceLastPractice > 3 {
        decayFactor := math.Pow(0.95, daysSinceLastPractice-3)
        current.MasteryScore *= decayFactor
    }
    
    // 更新分数
    newScore := current.MasteryScore + delta
    newScore = math.Max(0.0, math.Min(1.0, newScore))
    current.MasteryScore = newScore
    
    // 更新掌握等级
    current.MasteryLevel = mc.scoreToLevel(newScore)
    
    // 更新复习间隔(SM-2 简化版)
    if result.IsCorrect {
        current.ReviewInterval = mc.calculateNextInterval(
            current.ReviewInterval, current.ConsecutiveCorrect,
        )
        current.ConsecutiveCorrect++
        current.ConsecutiveErrors = 0
    } else {
        current.ConsecutiveErrors++
        current.ConsecutiveCorrect = 0
        current.ReviewInterval = 1 // 错误则回到1天
    }
    
    // 设置下次复习时间
    current.NextReviewAt = time.Now().AddDate(0, 0, current.ReviewInterval)
    current.LastPracticedAt = time.Now()
    
    return current
}

func (mc *MasteryCalculator) scoreToLevel(score float64) string {
    switch {
    case score >= 0.85:
        return "mastered"
    case score >= 0.60:
        return "familiar"
    case score >= 0.30:
        return "learning"
    default:
        return "new"
    }
}

func (mc *MasteryCalculator) calculateNextInterval(currentInterval, consecutiveCorrect int) int {
    // 简化SM-2间隔: 1 -> 2 -> 4 -> 7 -> 12 -> 20 -> 30
    intervals := []int{1, 2, 4, 7, 12, 20, 30}
    idx := 0
    for i, v := range intervals {
        if v <= currentInterval {
            idx = i
        }
    }
    if consecutiveCorrect >= 3 && idx < len(intervals)-1 {
        return intervals[idx+1]
    }
    return currentInterval
}

func (mc *MasteryCalculator) speedBonus(responseTimeMs int) float64 {
    switch {
    case responseTimeMs < 2000:
        return 0.05 // 快速正确额外加分
    case responseTimeMs < 5000:
        return 0.02
    default:
        return 0.0
    }
}
```

### 5.4 语音评测集成

```go
// SpeechEvaluationAdapter 语音评测适配器
type SpeechEvaluationAdapter struct {
    speechService SpeechServiceClient
}

// EvaluatePronunciation 评测发音
func (s *SpeechEvaluationAdapter) EvaluatePronunciation(
    ctx context.Context,
    targetPinyin string,
    audioData []byte,
    userID int64,
) (*PronunciationResult, error) {
    // 1. 调用语音服务ASR
    asrResult, err := s.speechService.Recognize(ctx, &SpeechRequest{
        Audio:       audioData,
        Language:    "zh-CN",
        SampleRate:  16000,
        EnablePhoneLevel: true, // 开启音素级别评测
    })
    if err != nil {
        return nil, fmt.Errorf("ASR识别失败: %w", err)
    }
    
    // 2. 对比目标拼音
    target := s.parseTargetPhonemes(targetPinyin)
    actual := s.parseASRPhonemes(asrResult.PhoneLevel)
    
    // 3. 计算各项评分
    result := &PronunciationResult{
        OverallScore: s.calculateOverallScore(target, actual),
        InitialScore: s.compareInitial(target.Initial, actual.Initial),
        FinalScore:   s.compareFinal(target.Final, actual.Final),
        ToneScore:    s.compareTone(target.Tone, actual.Tone),
        FluencyScore: s.calculateFluency(asrResult),
    }
    
    // 4. 生成反馈
    result.Feedback = s.generateFeedback(result, target, actual)
    
    return result, nil
}

// PronunciationResult 发音评测结果
type PronunciationResult struct {
    OverallScore  float64  // 总评分 0-1
    InitialScore  float64  // 声母评分
    FinalScore    float64  // 韵母评分
    ToneScore     float64  // 声调评分
    FluencyScore  float64  // 流畅度评分
    Feedback      *PronunciationFeedback
}

type PronunciationFeedback struct {
    Level       string   // perfect/good/try_again
    Message     string   // 适合儿童理解的鼓励文案
    Suggestions []string // 具体改进建议
}

// generateFeedback 生成适龄反馈(鼓励为主)
func (s *SpeechEvaluationAdapter) generateFeedback(
    result *PronunciationResult,
    target, actual *Phonemes,

    switch {
    case result.OverallScore >= 0.90:
        return &PronunciationFeedback{
            Level:   "perfect",
            Message: "太棒了！发音非常标准！🌟",
        }
    case result.OverallScore >= 0.70:
        return &PronunciationFeedback{
            Level:       "good",
            Message:     "发音不错！继续加油！👍",
            Suggestions: s.getSpecificTips(result),
        }
    default:
        return &PronunciationFeedback{
            Level:       "try_again",
            Message:     "再试一次吧！你可以的！💪",
```

## 8. 错误处理

### 8.1 错误码定义

| 错误码 | HTTP状态 | 说明 | 客户端处理 |

| LITERACY_004 | 404 | 练习会话不存在 | 创建新会话 |
| LITERACY_005 | 409 | 练习会话已过期(>30min) | 创建新会话 |
| LITERACY_006 | 409 | 已达每日新学上限 | 提示明日继续 |
| LITERACY_007 | 403 | 路径步骤未解锁 | 按序解锁 |
| LITERACY_008 | 413 | 语音文件过大(>5MB) | 提示重新录制 |
| LITERACY_009 | 503 | 语音评测服务不可用 | 降级跳过语音题 |
| LITERACY_010 | 500 | 练习生成内部错误 | 重试或降级 |

### 8.2 降级策略

| 故障场景 | 降级方案 |
|----------|----------|
| 语音评测服务不可用 | 跳过语音题，用识别/选择题替代 |
| Redis不可用 | 直接查询DB，接受延迟增加 |
| CDN图片/音频加载失败 | 返回降级资源URL或本地兜底素材 |
| 练习生成超时(>3s) | 返回预生成的固定练习集 |

## 10. 并发与一致性

### 10.1 并发控制

**练习会话互斥：** 同一用户同时只能有一个活跃的练习会话。

```go
func (s *ExerciseService) CreateSession(ctx context.Context, req CreateSessionRequest) (*ExerciseSession, error) {
    // 分布式锁防并发
    lockKey := fmt.Sprintf("lock:literacy:session:%d", req.UserID)
    lock := s.redis.SetNX(ctx, lockKey, "1", 5*time.Minute)
    if !lock.Val() {
        return nil, NewBusinessError("LITERACY_011", "已有进行中的练习会话")
    }
    defer s.redis.Del(ctx, lockKey)
    
    // ... 创建会话
}
```

### 10.2 掌握度更新幂等性

```go
type SubmitAnswerRequest struct {

    UserAnswer  string `json:"user_answer"`

func (s *ExerciseService) SubmitAnswer(ctx context.Context, req SubmitAnswerRequest) (*SubmitResult, error) {
    // 幂等校验
    idempotencyKey := fmt.Sprintf("literacy:submit:%s:%d", req.SessionID, req.ItemOrder)
    exists, _ := s.redis.SetNX(ctx, idempotencyKey, "1", 10*time.Minute).Result()
    if !exists {
        // 已提交过，返回上次结果
        return s.getCachedSubmitResult(ctx, req.SessionID, req.ItemOrder)
    }
    
    // ... 正常处理
}
```

### 10.3 每日新学数量限制

```go
func (s *LearningPathEngine) CheckDailyLimit(ctx context.Context, userID int64) error {
    key := fmt.Sprintf("literacy:daily:%d:%s:new_count", userID, time.Now().Format("2006-01-02"))
    count, _ := s.redis.Incr(ctx, key).Result()
    if count == 1 {
        s.redis.Expire(ctx, key, 25*time.Hour) // 首次设置过期
    }
    
    limit := s.getDailyNewItemsLimit(userID) // 默认3-5个
    if count > int64(limit) {
        return NewBusinessError("LITERACY_006", "今日新学数量已达上限")
    }
    return nil
}
```
