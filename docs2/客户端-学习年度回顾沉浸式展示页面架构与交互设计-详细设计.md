# 客户端-学习年度回顾沉浸式展示页面架构与交互设计-详细设计

> 细化日期：2026-06-13
> 关联模块：服务端-用户学习年度回顾与成长报告生成引擎、分享与社交裂变系统、客户端-学习报告卡片生成与社交分享图片渲染引擎、客户端手势交互与动画系统

## 1. 概述

### 1.1 文档目标

本文档细化 PrimeTop 客户端「学习年度回顾」沉浸式展示页面的架构设计、交互流程、组件体系、动画规范和开发实现方案，为 Flutter 客户端开发人员提供可直接编码落地的技术方案。

### 1.2 产品定位

年度回顾（Annual Review，下称 AR）是 PrimeTop 在每年年末面向全体用户推出的沉浸式全屏学习数据回顾体验，产品形态对标 Spotify Wrapped、支付宝年度账单、网易云音乐年度听歌报告等社交传播级产品。

与常规学习报告（日报/周报/月报）的核心差异：

| 维度 | 常规报告 | 年度回顾 |
|------|----------|----------|
| 呈现形式 | 表格 + 图表列表页 | 沉浸式全屏卡片 + 动画 + 数据故事 |
| 交互模式 | 纵向滚动浏览 | 上下滑动切页 / 自动播放 |
| 情感色彩 | 客观理性 | 温暖激励、趣味个性化 |
| 社交传播 | 弱（家长分享） | 强（朋友圈/社群裂变） |
| 技术实现 | 标准 ListView | 自定义 PageView + Lottie + 粒子动画 |

### 1.3 与相邻模块关系

| 模块 | 关系 |
|------|------|
| 服务端-用户学习年度回顾与成长报告生成引擎 | 服务端负责数据聚合、AI评语生成、报告 JSON 生成 |
| 客户端-学习报告卡片生成与社交分享图片渲染引擎 | 复用其分享卡片渲染能力 |
| 客户端手势交互与动画系统 | 复用 Lottie 播放器、粒子系统、过渡动画 |
| 分享与社交裂变系统 | AR 页面集成统一分享 SDK |
| 客户端-学习报告详情与分享页面架构与交互设计 | AR 入口位于报告列表页 |
| 客户端主题引擎与动态外观系统 | AR 使用独立主题，不复用全局主题 |

```dart
/// 年度回顾状态
enum AnnualReviewStatus {
  initial,       // 初始状态
  loading,       // 加载中
  ready,         // 数据就绪
  playing,       // 播放中（自动播放模式）
  paused,        // 暂停（手动浏览模式）
  sharing,       // 分享中
  error,         // 加载失败
  notAvailable,  // 数据不可用（新用户/无数据）
}

/// 年度回顾 Riverpod Provider
@riverpod
class AnnualReviewNotifier extends _$AnnualReviewNotifier {
  @override
  AnnualReviewState build(int year) {
    return const AnnualReviewState(status: AnnualReviewStatus.initial);
  }

  /// 加载年度回顾数据
  Future<void> loadReview() async {
    state = state.copyWith(status: AnnualReviewStatus.loading);

    try {
      final response = await _annualReviewRepository.fetchReview(year);

      if (response == null) {
        state = state.copyWith(status: AnnualReviewStatus.notAvailable);
        return;
      }

      state = state.copyWith(
        status: AnnualReviewStatus.ready,
        data: response,
      );
    } on AnnualReviewException catch (e) {
      state = state.copyWith(
        status: AnnualReviewStatus.error,
        errorMessage: e.message,
      );
    }
  }

  /// 记录卡片曝光（埋点）
  void trackCardView(int cardIndex, String cardType) {
    _analyticsService.logEvent(
      eventName: 'annual_review_card_view',
      parameters: {
        'year': year,
        'card_index': cardIndex,
        'card_type': cardType,
        'timestamp': DateTime.now().toIso8601String(),
      },
    );
  }

  /// 记录分享行为
  void trackShare(String shareChannel, int fromCardIndex) {
    _analyticsService.logEvent(
      eventName: 'annual_review_share',
      parameters: {
        'year': year,
        'share_channel': shareChannel,
        'from_card_index': fromCardIndex,
      },
    );
  }
}
```

### 4.3 翻页控制器

```dart
// lib/features/annual_review/controllers/card_page_controller.dart

class AnnualReviewCardController extends ChangeNotifier {
  final PageController _pageController;
  final int totalCards;
  final Duration autoPlayInterval;

  int _currentPage = 0;
  bool _isAutoPlaying = false;
  Timer? _autoPlayTimer;
  bool _isAnimating = false;

  AnnualReviewCardController({
    required this.totalCards,
    this.autoPlayInterval = const Duration(seconds: 5),
  }) : _pageController = PageController();

  PageController get pageController => _pageController;
  int get currentPage => _currentPage;
  bool get isAutoPlaying => _isAutoPlaying;
  bool get isLastPage => _currentPage >= totalCards - 1;
  bool get isFirstPage => _currentPage == 0;
  double get progress => (_currentPage + 1) / totalCards;

  /// 跳转到下一页
  Future<void> nextPage({bool animated = true}) async {
    if (_isAnimating || isLastPage) return;
    _isAnimating = true;
    await _pageController.nextPage(
      duration: const Duration(milliseconds: 600),
      curve: Curves.easeInOutCubic,
    );
    _isAnimating = false;
  }

  /// 跳转到上一页
  Future<void> previousPage({bool animated = true}) async {
    if (_isAnimating || isFirstPage) return;
    _isAnimating = true;
    await _pageController.previousPage(
      duration: const Duration(milliseconds: 600),
      curve: Curves.easeInOutCubic,
    );
    _isAnimating = false;
  }

  /// 开始自动播放
  void startAutoPlay() {
    if (_isAutoPlaying) return;
    _isAutoPlaying = true;
    _scheduleNext();
  }

  /// 暂停自动播放
  void stopAutoPlay() {
    _isAutoPlaying = false;
    _autoPlayTimer?.cancel();
  }

  /// 切换自动播放
  void toggleAutoPlay() {
    if (_isAutoPlaying) {
      stopAutoPlay();
    } else {
      startAutoPlay();
    }
    notifyListeners();
  }

  void _scheduleNext() {
    _autoPlayTimer?.cancel();
    _autoPlayTimer = Timer(autoPlayInterval, () async {
      if (isLastPage) {
        stopAutoPlay();
        return;
      }
      await nextPage();
      if (_isAutoPlaying) _scheduleNext();
    });
  }

  /// 页面变化回调（绑定到 PageView.onPageChanged）
  void onPageChanged(int index) {
    _currentPage = index;
    notifyListeners();
  }

  @override
  void dispose() {
    _autoPlayTimer?.cancel();
    _pageController.dispose();
    super.dispose();
  }
}
```

## 5. 各卡片页面详细设计

### 5.1 Card 1: 封面卡片 (CoverCard)

**交互流程：**
1. 进入后播放 Lottie 开场动画（3 秒，星光粒子汇聚成年份）
2. 动画结束显示用户昵称 + "你的 2026 学习之旅"
3. 底部出现 "开始回顾" 按钮 + 上滑箭头提示
4. 上滑进入下一张卡片

**视觉规范：**
- 背景：渐变深色（#1a1a2e → #16213e）
- 年份文字：72dp，加粗，渐变色填充（品牌色渐变）
- 粒子颜色：与用户学段主题色关联
  - 幼儿/小学：暖黄 + 橙色
  - 初中：蓝色 + 青色
  - 高中：紫色 + 金色

```dart
class CoverCard extends ConsumerStatefulWidget {
  final AnnualReviewData data;
  final VoidCallback onNext;

  const CoverCard({super.key, required this.data, required this.onNext});

  @override
  ConsumerState<CoverCard> createState() => _CoverCardState();
}

class _CoverCardState extends ConsumerState<CoverCard>
    with TickerProviderStateMixin {
  late final AnimationController _entranceController;
  late final Animation<double> _fadeIn;
  late final Animation<double> _scaleUp;
  bool _showCta = false;

  @override
  void initState() {
    super.initState();
    _entranceController = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 3000),
    );

    _fadeIn = Tween<double>(begin: 0, end: 1).animate(
      CurvedAnimation(
        parent: _entranceController,
        curve: const Interval(0.4, 0.7, curve: Curves.easeIn),
      ),
    );

    _scaleUp = Tween<double>(begin: 0.5, end: 1.0).animate(
      CurvedAnimation(
        parent: _entranceController,
        curve: const Interval(0.0, 0.5, curve: Curves.elasticOut),
      ),
    );

    _entranceController.forward().then((_) {
      if (mounted) {
        setState(() => _showCta = true);
      }
    });
  }

  @override
  void dispose() {
    _entranceController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final userNickname = ref.watch(userProfileProvider).nickname;

    return Container(
      decoration: BoxDecoration(
        gradient: LinearGradient(
          begin: Alignment.topCenter,
          end: Alignment.bottomCenter,
          colors: [
            Theme.of(context).colorScheme.primary.darken(0.7),
            Theme.of(context).colorScheme.primary.darken(0.5),
          ],
        ),
      ),
      child: Stack(
        alignment: Alignment.center,
        children: [
          // Lottie 粒子背景
          Lottie.asset(
            'assets/lottie/annual_review_stars.json',
            controller: _entranceController,
            width: double.infinity,
            height: double.infinity,
            fit: BoxFit.cover,
          ),

          // 年份大字
          ScaleTransition(
            scale: _scaleUp,
            child: FadeTransition(
              opacity: _fadeIn,
              child: Column(
                mainAxisSize: MainAxisSize.min,
                children: [
                  ShaderMask(
                    shaderCallback: (bounds) => const LinearGradient(
                      colors: [Color(0xFF667eea), Color(0xFF764ba2)],
                    ).createShader(bounds),
                    child: Text(
                      '${widget.data.year}',
                      style: const TextStyle(
                        fontSize: 72,
                        fontWeight: FontWeight.bold,
                        color: Colors.white,
                      ),
                    ),
                  ),
                  const SizedBox(height: 16),
                  Text(
                    '$userNickname 的学习之旅',
                    style: TextStyle(
                      fontSize: 20,
                      color: Colors.white.withOpacity(0.9),
                    ),
                  ),
                ],
              ),
            ),
          ),

          // 底部 CTA
          if (_showCta)
            Positioned(
              bottom: 80,
              child: Column(
                children: [
                  ElevatedButton(
                    onPressed: widget.onNext,
                    style: ElevatedButton.styleFrom(
                      padding: const EdgeInsets.symmetric(
                        horizontal: 48, vertical: 16,
                      ),
                      shape: RoundedRectangleBorder(
                        borderRadius: BorderRadius.circular(30),
                      ),
                    ),
                    child: const Text('开始回顾'),
                  ),
                  const SizedBox(height: 16),
                  const _SwipeUpHint(),
                ],
              ),
            ),
        ],
      ),
    );
  }
}

/// 上滑提示动画
class _SwipeUpHint extends StatefulWidget {
  const _SwipeUpHint();

  @override
  State<_SwipeUpHint> createState() => _SwipeUpHintState();
}

class _SwipeUpHintState extends State<_SwipeUpHint>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1200),
    )..repeat(reverse: true);
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      builder: (context, child) {
        return Transform.translate(
          offset: Offset(0, -8 * _controller.value),
          child: Icon(
            Icons.keyboard_arrow_up,
            color: Colors.white.withOpacity(0.6),
            size: 28,
          ),
        );
      },
    );
  }
}
```
