# 服务端-学生用户注意力预算管理与平台信息负载智能调控引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 平台**跨模块信息负载统一管控**的核心基础设施。针对教育产品中学生面临的"信息过载"问题——通知轰炸、推荐刷屏、AI 主动对话频繁、运营弹窗打断学习、游戏化元素分散注意力等——提供统一的**注意力预算管理**与**信息负载智能调控**能力。

**核心理念**：平台应是一个**平静的学习环境**，而非注意力收割机。每个学生在每个时间段拥有有限的"注意力预算"，所有模块的信息输出总和不得超过该预算。

### 1.2 与现有模块的区别

| 现有模块 | 管控范围 | 本引擎区别 |
|---------|---------|-----------|
| 多源通知智能合并与用户通知疲劳度管控引擎 | 通知渠道层面的合并与频控 | 本引擎管控的是**全平台所有信息触达**，不限于通知 |
| 教育平台学生用户学习内容曝光统一管控与推荐疲劳智能防护引擎 | 推荐内容的曝光频率 | 本引擎还涵盖 AI 主动对话、运营弹窗、成就提示、社交消息等 |
| 学生认知负荷监测与学习内容难度动态调节引擎 | 学习内容本身的认知难度 | 本引擎关注的是**平台侧输出的信息量和交互请求数量**，而非内容难度 |
| 统一学习干预编排与智能频控引擎 | 学习干预动作的频次控制 | 本引擎在干预编排之上做**全局注意力预算扣减决策** |

### 1.3 适用范围

- **目标用户**：全学段学生用户（幼儿~高中），特别关注低龄用户（自控力弱）
- **覆盖触达渠道**：弹窗、通知、AI 主动消息、推荐卡片、成就提示、社交消息、运营活动、声音提示
- **部署方式**：作为平台级中间件服务，被所有业务模块依赖调用

### 1.4 设计目标

1. **注意力预算量化**：建立可量化的学生注意力预算模型
2. **全链路信息管控**：所有面向学生的信息输出统一经过注意力预算校验
3. **智能优先级仲裁**：当多个模块竞争学生注意力时，基于学习状态、内容重要性和预算余量做出最优投放决策
4. **自适应调节**：根据学生反馈信号（互动率、关闭率、学习中断率）动态调整预算分配
5. **平静学习保障**：确保学生在专注学习时，平台信息输出最小化

## 2. 核心概念与领域模型

### 2.1 核心概念定义

| 概念 | 定义 | 说明 |
|------|------|------|
| **注意力预算 (Attention Budget)** | 学生在指定时间窗口内可接受的信息触达总量上限 | 按学段、时段、学习状态差异化分配 |
| **信息触达 (Information Touch)** | 平台任何面向学生单次信息输出动作 | 弹窗、通知、推荐、AI 主动消息等 |
| **注意力消耗 (Attention Cost)** | 单次信息触达预估消耗的注意力值 | 由触达类型、内容复杂度、打断程度决定 |
| **注意力余量 (Attention Remainder)** | 当前时间窗口内剩余的注意力预算 | = 预算 - 已消耗 - 预留 |
| **触达优先级 (Touch Priority)** | 信息触达的重要性分级 | P0(学习关键) / P1(有价值的增强) / P2(运营推广) / P3(社交互动) |
| **学习沉浸态 (Learning Flow State)** | 学生当前的学习专注状态 | 由心流检测引擎提供，影响预算策略 |
| **信息饥饿度 (Information Appetite)** | 学生当前对新鲜信息的渴望程度 | 高饥饿度时可放宽预算限制 |

## 4. 核心算法设计

### 4.1 注意力预算计算算法

```python
class AttentionBudgetCalculator:
    """注意力预算计算器"""

    # 基础日预算（按学段）
    BASE_DAILY_BUDGET = {
        "kindergarten": 60,   # 幼儿：极低，保护性限制
        "elementary": 100,    # 小学：适中
        "middle": 140,        # 初中：较高
        "high": 160,          # 高中：最高，学生自主性强
    }

    def calculate_daily_budget(
        self,
        student_id: int,
        stage: str,
        date: str,
        learning_state: dict,
        historical_signals: dict,
    ) -> int:
        """
        计算当日注意力预算
        综合考虑：基础预算 + 学习状态修正 + 历史互动反馈 + 特殊日期修正
        """
        base = self.BASE_DAILY_BUDGET.get(stage, 100)

        # 1. 学习状态修正
        state_modifier = self._calc_state_modifier(learning_state)
        # 专注学习中的学生，减少非学习类触达预算
        # idle 状态的学生，适当增加触达预算

        # 2. 历史互动率修正
        interaction_modifier = self._calc_interaction_modifier(historical_signals)
        # 互动率高的学生 → 预算略增（他们对触达更接受）
        # 关闭率高的学生 → 预算减少（他们已经厌烦了）

        # 3. 连续学习天数修正（适度激励，但有上限）
        streak_modifier = self._calc_streak_modifier(historical_signals)
        # 连续学习7天以上 → +10% 预算上限
        # 连续学习30天以上 → +15% 预算上限

        # 4. 特殊日期修正
        special_modifier = self._calc_special_modifier(date, stage)
        # 考试周：减少 P2/P3 触达，增加 P0/P1
        # 假期：适度放宽
        # 开学前一周：收紧触达

        daily_budget = int(base * state_modifier * interaction_modifier * streak_modifier * special_modifier)

        # 硬性上下限
        return max(20, min(daily_budget, 250))

    def _calc_state_modifier(self, learning_state: dict) -> float:
        """学习状态修正系数"""
        flow_state = learning_state.get("flow_state", "idle")
        if flow_state == "flow":
            # 心流状态：大幅减少非关键触达
            return 0.4
        elif flow_state == "focused":
            # 专注状态：减少非学习触达
            return 0.7
        elif flow_state == "distracted":
            # 分心状态：适度增加引导触达
            return 1.1
        else:  # idle
            return 1.0

    def _calc_interaction_modifier(self, signals: dict) -> float:
        """历史互动率修正"""
        recent_click_rate = signals.get("click_rate_7d", 0.3)
        recent_dismiss_rate = signals.get("dismiss_rate_7d", 0.3)

        if recent_dismiss_rate > 0.6:
            # 高关闭率：学生明显感到烦扰，收紧预算
            return 0.7
        elif recent_click_rate > 0.5 and recent_dismiss_rate < 0.2:
            # 高互动低关闭：适度放宽
            return 1.15
        else:
            return 1.0

    def _calc_streak_modifier(self, signals: dict) -> float:
        streak_days = signals.get("learning_streak_days", 0)
        if streak_days >= 30:
            return 1.15
        elif streak_days >= 7:
            return 1.10
        return 1.0

    def _calc_special_modifier(self, date: str, stage: str) -> float:
        """特殊日期修正（简化版）"""
        # 实际实现中查询日历服务
        # holiday = calendar_service.get_date_type(date)
        # exam_week = calendar_service.is_exam_week(date, stage)
        # ...
        return 1.0
```

### 4.2 触达审批决策算法

```python
from enum import Enum
from dataclasses import dataclass
from typing import Optional
from datetime import datetime, timedelta


class TouchDecision(Enum):
    APPROVE = "approve"        # 立即批准
    DEFER = "defer"            # 延迟到指定时间
    REJECT = "reject"          # 拒绝（当日不再展示）
    QUEUE = "queue"            # 排队等待（低优先级批量）


@dataclass
class TouchRequest:
    """信息触达请求"""
    touch_id: str
    student_id: int
    source_module: str          # notification/recommendation/ai_companion/...
    touch_type: str             # popup/notification/banner/ai_message/...
    priority: str               # P0/P1/P2/P3
    content_id: str
    content_summary: str
    target_url: str
    requested_at: datetime
    expire_at: Optional[datetime] = None  # 超过此时间则不再展示


@dataclass
class TouchResponse:
    """信息触达审批结果"""
    decision: TouchDecision
    reason: str
    attention_cost: int
    defer_until: Optional[datetime] = None
    queue_position: Optional[int] = None


class TouchApprovalEngine:
    """触达审批引擎"""

    def __init__(
        self,
        budget_calculator: AttentionBudgetCalculator,
        redis_client,
        config_service,
        learning_state_service,
    ):
        self.budget_calculator = budget_calculator
        self.redis = redis_client
        self.config = config_service
        self.learning_state = learning_state_service

    async def evaluate(self, request: TouchRequest) -> TouchResponse:
        """
        评估信息触达请求，决定是否批准
        """
        # 1. 获取学生注意力上下文
        ctx = await self._get_attention_context(request.student_id)

        # 2. 计算本次触达的注意力消耗
        cost = self._calculate_cost(request, ctx)

        # 3. 检查是否过期
        if request.expire_at and datetime.utcnow() > request.expire_at:
            return TouchResponse(
                decision=TouchDecision.REJECT,
                reason="expired",
                attention_cost=0
            )

        # 4. 检查时段限制
        window_check = self._check_time_window(request, ctx)
        if not window_check.allowed:
            return TouchResponse(
                decision=TouchDecision.DEFER,
                reason=f"blocked_window:{window_check.label}",
                attention_cost=cost,
                defer_until=window_check.next_allowed_time
            )

        # 5. 检查冷却时间
        cooldown_check = self._check_cooldown(request, ctx)
        if not cooldown_check:
            next_time = ctx.last_touch_at + timedelta(
                milliseconds=self._get_cooldown_ms(request)
            )
            return TouchResponse(
                decision=TouchDecision.DEFER,
                reason="cooldown",
                attention_cost=cost,
                defer_until=next_time
            )

        # 6. P0 优先级：学习关键信息，绕过预算检查（但仍受时段和冷却限制）
        if request.priority == "P0":
            return TouchResponse(
                decision=TouchDecision.APPROVE,
                reason="p0_override",
                attention_cost=cost
            )

        # 7. 检查学习沉浸态保护
        if ctx.learning_flow_state in ("flow", "focused"):
            if request.priority not in ("P0", "P1"):
                # 非紧急触达在专注/心流状态下延迟
                defer_time = self._calculate_flow_defer_time(ctx)
                return TouchResponse(
                    decision=TouchDecision.DEFER,
                    reason=f"learning_flow_protect:{ctx.learning_flow_state}",
                    attention_cost=cost,
                    defer_until=defer_time
                )

        # 8. 预算检查
        if ctx.window_remaining < cost:
            # 当前时段预算不足
            if request.priority == "P1" and ctx.daily_remaining >= cost:
                # P1 级别如果日预算够，延迟到下一个时段
                next_window = self._get_next_allowed_window(request, ctx)
                return TouchResponse(
                    decision=TouchDecision.DEFER,
                    reason="window_budget_exhausted",
                    attention_cost=cost,
                    defer_until=next_window
                )
            elif request.priority in ("P2", "P3"):
                if ctx.daily_remaining < cost:
                    return TouchResponse(
                        decision=TouchDecision.REJECT,
                        reason="daily_budget_exhausted",
                        attention_cost=0
                    )
                # 排队等待
                return TouchResponse(
                    decision=TouchDecision.QUEUE,
                    reason="window_budget_insufficient_queued",
                    attention_cost=cost,
                )

        # 9. 检查每日最大次数
        daily_max = self._get_daily_max(request)
        if daily_max and ctx.touch_count_by_type.get(request.touch_type, 0) >= daily_max:
            return TouchResponse(
                decision=TouchDecision.REJECT,
                reason="daily_max_reached",
                attention_cost=0
            )

        # 10. 批准
        return TouchResponse(
            decision=TouchDecision.APPROVE,
            reason="approved",
            attention_cost=cost
        )

    def _calculate_cost(self, request: TouchRequest, ctx) -> int:
        """计算实际注意力消耗"""
        config = self.config.get_touch_cost_config(
            request.touch_type, request.source_module
        )

        base_cost = config["base_cost"]
        stage_modifier = config["stage_modifier"].get(ctx.stage, 1.0)

        cost = int(base_cost * stage_modifier)

        # 内容复杂度修正（如果内容很长，消耗更多注意力）
        content_length = len(request.content_summary)
        if content_length > 200:
            cost = int(cost * 1.3)

        # 重复触达衰减（同一模块短时间内多次触达，消耗递增）
        recent_same_module = ctx.get_recent_module_count(request.source_module, hours=1)
        if recent_same_module > 0:
            cost = int(cost * (1 + 0.2 * recent_same_module))

        return max(1, min(cost, 100))

    def _check_time_window(self, request: TouchRequest, ctx) -> "WindowCheckResult":
        """检查当前时段是否允许该类型触达"""
        current_window = ctx.current_time_window

        if not current_window:
            return WindowCheckResult(allowed=False, label="no_window", 
                                     next_allowed_time=self._next_window_start(ctx))

        blocked = current_window.get("blocked_types", [])
        if "*" in blocked or request.touch_type in blocked:
            return WindowCheckResult(allowed=False, label=current_window["label"],
                                     next_allowed_time=self._next_window_start(ctx))

        return WindowCheckResult(allowed=True, label=current_window["label"])

    def _check_cooldown(self, request: TouchRequest, ctx) -> bool:
        """检查冷却时间"""
        cooldown_ms = self._get_cooldown_ms(request)
        if cooldown_ms == 0:
            return True

        if not ctx.last_touch_at:
            return True

        elapsed = (datetime.utcnow() - ctx.last_touch_at).total_seconds() * 1000
        return elapsed >= cooldown_ms

    def _calculate_flow_defer_time(self, ctx) -> datetime:
        """计算心流保护延迟时间"""
        # 延迟到心流状态结束，或最多延迟30分钟
        flow_end = ctx.flow_estimated_end
        if flow_end and flow_end < datetime.utcnow() + timedelta(minutes=30):
            return flow_end + timedelta(minutes=5)  # 心流结束后5分钟
        else:
            return datetime.utcnow() + timedelta(minutes=30)


@dataclass
class WindowCheckResult:
    allowed: bool
    label: str
    next_allowed_time: Optional[datetime] = None
```

### 4.3 优先级仲裁算法

当多个触达请求同时到达时，进行优先级排序和批量决策。

```python
class TouchPriorityArbiter:
    """触达优先级仲裁器"""

    async def arbitrate_batch(
        self,
        requests: list[TouchRequest],
        ctx: "AttentionContext",
        max_batch_size: int = 3,
    ) -> list[tuple[TouchRequest, TouchResponse]]:
        """
        对一批触达请求进行仲裁，选出最优的展示组合
        """
        # 1. 按优先级排序
        priority_order = {"P0": 0, "P1": 1, "P2": 2, "P3": 3}
        sorted_requests = sorted(requests, key=lambda r: priority_order.get(r.priority, 9))

        results = []
        approved_count = 0
        remaining_window_budget = ctx.window_remaining
        remaining_concurrent = ctx.max_concurrent - ctx.current_showing

        for request in sorted_requests:
            if approved_count >= remaining_concurrent:
                # 达到同时展示上限，其余排队
                results.append((request, TouchResponse(
                    decision=TouchDecision.QUEUE,
                    reason="concurrent_limit",
                    attention_cost=0,
                    queue_position=approved_count + 1
                )))
                continue

            if approved_count >= max_batch_size:
                results.append((request, TouchResponse(
                    decision=TouchDecision.QUEUE,
                    reason="batch_limit",
                    attention_cost=0,
                )))
                continue

            # 估算消耗
            cost = self._estimate_cost(request, ctx)

            if cost <= remaining_window_budget:
                results.append((request, TouchResponse(
                    decision=TouchDecision.APPROVE,
                    reason="batch_approved",
                    attention_cost=cost
                )))
                remaining_window_budget -= cost
                approved_count += 1
            else:
                # 预算不够，延迟
                results.append((request, TouchResponse(
                    decision=TouchDecision.DEFER,
                    reason="batch_budget_insufficient",
                    attention_cost=cost,
                    defer_until=self._next_window(ctx)
                )))

        return results

    def _estimate_cost(self, request: TouchRequest, ctx) -> int:
        """快速估算消耗（不精确，用于批量仲裁）"""
        base_costs = {
            "popup": 30, "notification": 8, "banner": 5,
            "ai_message": 15, "card": 3, "achievement_popup": 10,
            "social_message": 6, "reminder": 5, "sound": 4, "full_screen": 50
        }
        return base_costs.get(request.touch_type, 10)
```

### 4.4 自适应策略优化算法

```python
class AdaptiveStrategyOptimizer:
    """基于学生反馈的自适应策略优化器"""

    def calculate_strategy_adjustment(
        self,
        student_id: int,
        signals_7d: dict,
        current_config: dict,
    ) -> dict:
        """
        基于过去7天的互动信号，调整该学生的注意力策略
        """
        adjustments = {}

        # 1. 互动率分析
        overall_click_rate = signals_7d.get("overall_click_rate", 0.3)
        overall_dismiss_rate = signals_7d.get("overall_dismiss_rate", 0.3)
        avg_dwell_ms = signals_7d.get("avg_dwell_ms", 2000)

        # 2. 高关闭率 → 收紧策略
        if overall_dismiss_rate > 0.5:
            adjustments["daily_budget_modifier"] = 0.8
            adjustments["cooldown_multiplier"] = 1.5
            adjustments["p2_p3_suppression"] = True
        # 3. 高互动率 → 适度放宽
        elif overall_click_rate > 0.5 and overall_dismiss_rate < 0.2:
            adjustments["daily_budget_modifier"] = 1.1
            adjustments["cooldown_multiplier"] = 0.8
        # 4. 低互动低关闭 → 信息不够吸引，尝试调整内容类型
        elif overall_click_rate < 0.15 and overall_dismiss_rate < 0.2:
            adjustments["content_type_rotation"] = True
            adjustments["ai_message_boost"] = True  # 增加 AI 主动对话（更有吸引力）

        # 5. 按触达类型的细粒度分析
        type_performance = signals_7d.get("type_performance", {})
        for touch_type, perf in type_performance.items():
            if perf["dismiss_rate"] > 0.7:
                # 该类型被大量关闭 → 降权
                adjustments.setdefault("type_suppression", {})[touch_type] = 0.5
            elif perf["click_rate"] > 0.6:
                # 该类型互动好 → 提权
                adjustments.setdefault("type_boost", {})[touch_type] = 1.3

        # 6. 学习中断信号分析
        learning_interruption_rate = signals_7d.get("learning_interruption_rate", 0)
        if learning_interruption_rate > 0.3:
            # 30%以上的触达导致学习中断 → 紧急收紧
            adjustments["daily_budget_modifier"] = 0.6
            adjustments["learning_flow_protection"] = "strict"
            adjustments["p1_p2_p3_suppress_in_flow"] = True

        return adjustments
```

## 6. 状态流转

### 6.1 信息触达状态机

```text
                   ┌─────────┐
    请求提交 ────→ │ PENDING │
                   └────┬────┘
                        │
              ┌─────────┼─────────┬───────────┐
              ▼         ▼         ▼           ▼
        ┌─────────┐ ┌────────┐ ┌─────────┐ ┌────────┐
        │APPROVED │ │DEFERRED│ │REJECTED │ │QUEUED  │
        └────┬────┘ └───┬────┘ └─────────┘ └────┬───┘
             │          │                      │
             ▼          │ 定时器到期            │ 批量调度
        ┌─────────┐    │ 重新评估              │
        │IMPRESSED│←───┘                      │
        └────┬────┘                           │
             │                                │
     ┌───────┼───────┐                        │
     ▼       ▼       ▼                        │
 ┌──────┐┌──────┐┌─────────┐                  │
 │CLICKED││DISMISSED││EXPIRED│               │
 └──┬───┘└───┬──┘└─────────┘                 │
    │        │                                │
    ▼        ▼                                │
 ┌──────────┐                                 │
 │CONVERTED │←────────────────────────────────┘
 └──────────┘
```

### 6.2 状态转换条件

| 当前状态 | 目标状态 | 转换条件 |
|---------|---------|---------|
| PENDING | APPROVED | 预算充足 + 时段允许 + 冷却已过 |
| PENDING | DEFERRED | 预算不足 / 心流保护 / 时段限制 |
| PENDING | REJECTED | 日预算耗尽 / 日次数达上限 / 内容已过期 |
| PENDING | QUEUED | 时段预算不足但日预算充足 + 优先级 P2/P3 |
| DEFERRED | PENDING | `defer_until` 时间到达，重新进入评估 |
| APPROVED | IMPRESSED | 客户端回调确认展示 |
| APPROVED | EXPIRED | 超过 `expire_at` 未展示 |
| IMPRESSED | CLICKED | 用户点击触达内容 |
| IMPRESSED | DISMISSED | 用户关闭/滑走触达 |
| CLICKED | CONVERTED | 用户完成触达引导的目标行为 |
| QUEUED | APPROVED | 排队轮到 + 当前预算充足 |
| QUEUED | EXPIRED | 排队期间超过 `expire_at` |

### 6.3 学习沉浸态保护流转

```text
学生状态          允许的触达                行为
────────────────────────────────────────────────
idle（空闲）      全部类型                  正常预算管控
focused（专注）   P0/P1 学习相关            P2/P3 延迟到专注结束
flow（心流）      仅 P0 紧急学习提醒         几乎全部静默
distracted（分心）P0/P1 + 引导性 P2         适度增加引导触达
```

## 7. 关键代码示例

### 7.1 触达审批服务（Service 层）

```java
@Service
public class AttentionTouchService {

    @Autowired
    private AttentionBudgetCalculator budgetCalculator;

    @Autowired
    private TouchApprovalEngine approvalEngine;

    @Autowired
    private TouchPriorityArbiter arbiter;

    @Autowired
    private AttentionStateRepository stateRepository;

    @Autowired
    private TouchLogRepository touchLogRepository;

    @Autowired
    private AdaptiveStrategyOptimizer strategyOptimizer;

    /**
     * 单个触达审批
     */
    public TouchResponse requestTouch(TouchRequest request) {
        // 1. 获取学生注意力上下文
        AttentionContext ctx = stateRepository.getContext(request.getStudentId());

        // 2. 应用学生个性化策略调整
        ctx.applyStrategyAdjustments(
            strategyOptimizer.getStudentAdjustments(request.getStudentId())
        );

        // 3. 引擎评估
        TouchResponse response = approvalEngine.evaluate(request, ctx);

        // 4. 如果批准，扣减预算并记录
        if (response.getDecision() == TouchDecision.APPROVE) {
            stateRepository.deductBudget(
                request.getStudentId(),
                response.getAttentionCost(),
                request.getTouchType()
            );
        }

        // 5. 记录日志
        touchLogRepository.save(TouchLog.from(request, response));

        return response;
    }

    /**
     * 批量触达仲裁
     */
    public BatchArbitrateResponse batchArbitrate(
        long studentId,
        List<TouchRequest> requests
    ) {
        AttentionContext ctx = stateRepository.getContext(studentId);
        ctx.applyStrategyAdjustments(
            strategyOptimizer.getStudentAdjustments(studentId)
        );

        List<Pair<TouchRequest, TouchResponse>> results =
            arbiter.arbitrateBatch(requests, ctx);

        // 批量扣减预算
        int totalCost = results.stream()
            .filter(p -> p.getSecond().getDecision() == TouchDecision.APPROVE)
            .mapToInt(p -> p.getSecond().getAttentionCost())
            .sum();

        if (totalCost > 0) {
            stateRepository.batchDeductBudget(studentId, totalCost);
        }

        // 批量记录日志
        List<TouchLog> logs = results.stream()
            .map(p -> TouchLog.from(p.getFirst(), p.getSecond()))
            .collect(Collectors.toList());
        touchLogRepository.batchSave(logs);

        return BatchArbitrateResponse.from(results, ctx);
    }

    /**
     * 触达结果回调
     */
    public void touchCallback(String touchId, String event, Long studentId) {
        TouchLog log = touchLogRepository.findByTouchId(touchId);
        if (log == null) {
            log.warn("Touch callback for unknown touch_id: {}", touchId);
            return;
        }

        switch (event) {
            case "impressed":
                log.setStatus("IMPRESSION");
                log.setImpressedAt(LocalDateTime.now());
                break;
            case "clicked":
                log.setStatus("CLICKED");
                log.setInteractedAt(LocalDateTime.now());
                stateRepository.recordInteraction(studentId, true);
                break;
            case "dismissed":
                log.setStatus("DISMISSED");
                log.setDismissedAt(LocalDateTime.now());
                stateRepository.recordInteraction(studentId, false);
                // 如果被关闭，退回部分注意力预算（鼓励更好的触达）
                stateRepository.refundBudget(studentId, (int)(log.getAttentionCost() * 0.3));
                break;
            case "converted":
                log.setStatus("CONVERTED");
                log.setInteractedAt(LocalDateTime.now());
                stateRepository.recordConversion(studentId);
                break;
            case "expired":
                log.setStatus("EXPIRED");
                // 未展示的退还全部预算
                stateRepository.refundBudget(studentId, log.getAttentionCost());
                break;
        }

        touchLogRepository.save(log);
    }
}
```

```java
    private static final String KEY_PREFIX = "attention:state:";
    private static final String KEY_DAILY_BUDGET = "attention:budget:";
    private static final int BUDGET_TTL_HOURS = 36; // 预算状态缓存36小时

    /**
     * 获取学生注意力上下文
     */
    public AttentionContext getContext(long studentId) {
        String key = KEY_PREFIX + studentId + ":" + LocalDate.now();

        String json = redis.opsForValue().get(key);
        if (json != null) {
            return JSON.parseObject(json, AttentionContext.class);
        }

        // 初始化当日上下文
        AttentionContext ctx = initializeContext(studentId);
        redis.opsForValue().set(key, JSON.toJSONString(ctx), BUDGET_TTL_HOURS, TimeUnit.HOURS);
        return ctx;
    }

    /**
     * 初始化学生当日注意力上下文
     */
    private AttentionContext initializeContext(long studentId) {
        StudentProfile profile = studentService.getProfile(studentId);

        // 计算日预算
        int dailyBudget = budgetCalculator.calculateDailyBudget(
            studentId,
            profile.getStage(),
            LocalDate.now().toString(),
            learningStateService.getState(studentId),
            signalService.getHistoricalSignals(studentId, 7)
        );

        // 获取时段窗口
        TimeWindow currentWindow = timeWindowService.getCurrentWindow(
            profile.getStage(), LocalTime.now()
        );

        AttentionContext ctx = new AttentionContext();
        ctx.setStudentId(studentId);
        ctx.setDate(LocalDate.now());
        ctx.setStage(profile.getStage());
        ctx.setDailyBudget(dailyBudget);
        ctx.setDailyRemaining(dailyBudget);
        ctx.setDailyConsumed(0);
        ctx.setCurrentTimeWindow(currentWindow);
        ctx.setWindowRemaining(currentWindow != null ? currentWindow.getBudget() : 0);
        ctx.setWindowConsumed(0);
        ctx.setLearningFlowState(learningStateService.getFlowState(studentId));
        ctx.setTouchCountByType(new HashMap<>());
        ctx.setLastTouchAt(null);
        ctx.setMaxConcurrent(1);
        ctx.setCurrentShowing(0);
        ctx.setTouchCountToday(0);
        ctx.setInteractionCount(0);
        ctx.setDismissCount(0);

        return ctx;
    }

    /**
     * 扣减预算
     */
    public void deductBudget(long studentId, int cost, String touchType) {
        String key = KEY_PREFIX + studentId + ":" + LocalDate.now();

        // Lua 脚本保证原子性
        String luaScript = """
            local key = KEYS[1]
            local cost = tonumber(ARGV[1])
            local touch_type = ARGV[2]

            local data = cjson.decode(redis.call('GET', key))
            data['dailyConsumed'] = data['dailyConsumed'] + cost
            data['dailyRemaining'] = data['dailyRemaining'] - cost
            data['windowConsumed'] = data['windowConsumed'] + cost
            data['windowRemaining'] = data['windowRemaining'] - cost
            data['lastTouchAt'] = ARGV[3]
            data['touchCountToday'] = data['touchCountToday'] + 1

            local type_key = 'touchCountByType.' .. touch_type
            local current = data['touchCountByType'][touch_type] or 0
            data['touchCountByType'][touch_type] = current + 1

            redis.call('SET', key, cjson.encode(data))
            return 'OK'
        """;

        redis.execute(
            new DefaultRedisScript<>(luaScript, String.class),
            Collections.singletonList(key),
            String.valueOf(cost),
            touchType,
            LocalDateTime.now().toString()
        );
    }

    /**
     * 退还预算（触达被关闭或未展示时）
     */
    public void refundBudget(long studentId, int refundAmount) {
        String key = KEY_PREFIX + studentId + ":" + LocalDate.now();

        String luaScript = """
            local key = KEYS[1]
            local refund = tonumber(ARGV[1])
            local data = cjson.decode(redis.call('GET', key))
            data['dailyConsumed'] = math.max(0, data['dailyConsumed'] - refund)
            data['dailyRemaining'] = data['dailyRemaining'] + refund
            redis.call('SET', key, cjson.encode(data))
            return 'OK'
        """;

        redis.execute(
            new DefaultRedisScript<>(luaScript, String.class),
            Collections.singletonList(key),
            String.valueOf(refundAmount)
        );
    }
}
```

### 7.3 延迟触达定时恢复调度器

```java
@Component
public class DeferredTouchScheduler {

    @Autowired
    private TouchLogRepository touchLogRepository;

    @Autowired
    private AttentionTouchService touchService;

    /**
     * 每5分钟扫描一次延迟的触达，检查是否可以重新展示
     */
    @Scheduled(fixedRate = 5 * 60 * 1000)
    public void processDeferredTouches() {
        List<TouchLog> deferred = touchLogRepository.findExpiredDeferred(
            LocalDateTime.now()
        );

        for (TouchLog log : deferred) {
            // 检查原始内容是否仍然有效
            if (log.getExpireAt() != null && log.getExpireAt().isBefore(LocalDateTime.now())) {
                log.setStatus("EXPIRED");
                touchLogRepository.save(log);
                continue;
            }

            // 重新提交审批
            TouchRequest request = TouchRequest.fromLog(log);
            TouchResponse response = touchService.requestTouch(request);

            if (response.getDecision() == TouchDecision.APPROVE) {
                // 推送给客户端
                pushService.pushDeferredTouch(
                    log.getStudentId(),
                    log.getTouchId(),
                    log.getContentSummary(),
                    log.getTargetUrl()
                );
            } else if (response.getDecision() == TouchDecision.DEFER) {
                // 更新延迟时间
                log.setDeferUntil(response.getDeferUntil());
                touchLogRepository.save(log);
            } else {
                log.setStatus("REJECTED");
                touchLogRepository.save(log);
            }
        }
    }
}
```

```java
     */
    private boolean isRapidDismissPattern(long studentId) {

        Long count = redis.opsForList().size(key);
        if (count != null && count >= 3) {
            // 检查时间跨度
            List<String> recent = redis.opsForList().range(key, 0, 2);
            if (recent != null && recent.size() >= 3) {
                long firstTs = Long.parseLong(recent.get(recent.size() - 1));
                long lastTs = Long.parseLong(recent.get(0));
                // 3次关闭在60秒内 → 快速关闭模式
                return (lastTs - firstTs) < 60000;
            }
        }
        return false;
    }
```

```dart
class AttentionTouchInterceptor {
  final AttentionApi _api = AttentionApi();

  /// 请求展示信息触达
  Future<TouchResult> requestTouch(TouchRequest request) async {
    final response = await _api.requestTouch(request);

    switch (response.decision) {
      case 'approve':
        return TouchResult.approve(
          impressWindow: response.impressWindowMs,
        );
      case 'defer':
        // 缓存到本地，定时重试
        _deferredCache.add(DeferredTouch(
          request: request,
          deferUntil: response.deferUntil,
        ));
        return TouchResult.defer(response.deferUntil);
      case 'reject':
        return TouchResult.reject(response.reason);
      case 'queue':
        return TouchResult.queue(response.queuePosition);
      default:
        return TouchResult.reject('unknown_decision');
    }
  }

  /// 展示后回调
  Future<void> onImpressed(String touchId) async {
    await _api.touchCallback(touchId, 'impressed');
  }

  Future<void> onClicked(String touchId) async {
    await _api.touchCallback(touchId, 'clicked');
  }

  Future<void> onDismissed(String touchId) async {
    await _api.touchCallback(touchId, 'dismissed');
  }

  /// 延迟触达定时检查
  void startDeferredTimer() {
    Timer.periodic(Duration(minutes: 1), (_) {
      final now = DateTime.now();
      for (final deferred in _deferredCache) {
        if (deferred.deferUntil.isBefore(now)) {
          requestTouch(deferred.request);
          _deferredCache.remove(deferred);
        }
      }
    });
  }
}
```

### 9.3 熔断机制

```java
@Component
public class AttentionCircuitBreaker {

    private final CircuitBreaker circuitBreaker = CircuitBreaker.builder()
        .failureRateThreshold(0.5f)           // 50% 失败率触发熔断
        .slowCallRateThreshold(0.8f)          // 80% 慢调用触发熔断
        .slowCallDurationThreshold(Duration.ofMillis(200))
        .waitDurationInOpenState(Duration.ofSeconds(30))
        .slidingWindowSize(20)
        .minimumNumberOfCalls(10)
        .build();

    public TouchResponse evaluateWithFallback(TouchRequest request, String stage) {
        Supplier<TouchResponse> supplier = () -> 
            attentionService.requestTouch(request);

        // 熔断时使用本地降级配置
        Function<Throwable, TouchResponse> fallback = e -> {
            log.warn("Attention service fallback for student {}: {}", 
                request.getStudentId(), e.getMessage());
            return localFallback(request, stage);
        };

        return circuitBreaker.executeSupplier(supplier, fallback);
    }

    private TouchResponse localFallback(TouchRequest request, String stage) {
        // 使用降级配置做本地决策
        var config = fallbackStrategy.get(stage);

        if (request.getTouchType() in config.blocked_types) {
            return TouchResponse.reject("fallback_blocked_type");
        }

        // 放行但标记为降级模式
        return TouchResponse.approve("fallback_mode", cost=0);
    }
}
```
