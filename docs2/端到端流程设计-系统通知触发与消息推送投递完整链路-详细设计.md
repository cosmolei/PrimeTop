## 1. 文档概述

### 1.1 设计目的

本文档描述 PrimeTop 系统中**一条通知从业务事件产生到用户完成交互的完整端到端链路**。现有文档分别覆盖了通知中心存储、推送服务投递、智能调度引擎和客户端展示四个独立模块，但缺少跨模块的全链路串接视图。本文档将四者串联，明确每一步的数据流转、接口调用、异常处理和性能要求，使开发人员能完整理解通知系统的运作机制。

#### 3.1.2 服务端核心代码

**定时任务入口**

```java
/**
 * 每日学习计划提醒定时任务
 * 按用户设置的提醒时间分桶执行
 */
@Component
@Slf4j
public class DailyStudyReminderJob {

    @Autowired
    private ReminderTargetMapper reminderTargetMapper;
    @Autowired
    private ReminderProcessor reminderProcessor;
    @Autowired
    private ReminderExecutor reminderExecutor;

    /**
     * 每小时整点执行，处理提醒时间在当前小时的用户
     * 例：07:00 执行，查询 reminder_hour=7 的所有用户
     */
    @Scheduled(cron = "0 5 * * * ?") // 每小时第5分钟执行，给系统缓冲时间
    public void execute() {
        int currentHour = LocalTime.now().getHour();
        log.info("开始处理 {}:00 时段的学习计划提醒", currentHour);

        int offset = 0;
        int batchSize = 500;
        List<ReminderTarget> targets;

        do {
            targets = reminderTargetMapper.selectByReminderHour(
                ReminderType.STUDY_PLAN_REMINDER, currentHour, offset, batchSize
            );
            if (targets.isEmpty()) break;

            // 异步提交，不阻塞主线程
            for (ReminderTarget target : targets) {
                reminderExecutor.submit(() -> {
                    try {
                        reminderProcessor.process(target);
                    } catch (Exception e) {
                        log.error("处理提醒失败: userId={}", target.getUserId(), e);
                    }
                });
            }
            offset += batchSize;
        } while (targets.size() == batchSize);

        log.info("{}:00 时段提醒任务提交完成", currentHour);
    }
}
```

**单个提醒处理（含全部检查逻辑）**

```java
@Service
@Slf4j)
public class ReminderProcessor {

    @Autowired private FrequencyChecker frequencyChecker;
    @Autowired private DeduplicationService deduplicationService;
    @Autowired private DoNotDisturbChecker dndChecker;
    @Autowired private TemplateRenderer templateRenderer;
    @Autowired private NotificationPipelineService notificationPipeline;

    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void process(ReminderTarget target) {
        Long userId = target.getUserId();
        String templateCode = target.getTemplateCode();

        // ① 频率管控：检查日发送上限
        if (frequencyChecker.isExceeded(userId, templateCode,
                FrequencyWindow.DAILY, target.getMaxDailyCount())) {
            log.debug("用户{}日频率已达上限", userId);
            return;
        }

        // ② 聚合去重：同类型1小时内不重复
        if (deduplicationService.isDuplicate(userId, templateCode,
                Duration.ofHours(1))) {
            log.debug("用户{}近期已发送同类提醒", userId);
            return;
        }

        // ③ 免打扰检查
        DndCheckResult dndResult = dndChecker.check(userId);
        if (dndResult.isInQuietPeriod()) {
            // 延迟到免打扰结束后发送
            scheduleDelayed(target, dndResult.getNextAvailableTime());
            return;
        }

        // ④ 渲染模板
        Map<String, Object> vars = buildVariables(target);
        NotificationContent content = templateRenderer.render(templateCode, vars);

        // ⑤ 创建并投递通知（统一管道）
        notificationPipeline.createAndDeliver(
            userId,
            target.getNotificationType(),
            target.getCategory(),
            content,
            DeliveryPriority.NORMAL
        );

        log.info("学习计划提醒已发送: userId={}", userId);
    }

    private Map<String, Object> buildVariables(ReminderTarget target) {
        // 从学习计划服务获取今日任务信息
        TodayTaskSummary summary = studyPlanService
            .getTodayTaskSummary(target.getUserId());

        return Map.of(
            "nickname", target.getNickname(),
            "task_count", summary.getTaskCount(),
            "est_minutes", summary.getEstMinutes(),
            "subjects", summary.getSubjectNames(),
            "first_task_title", summary.getFirstTaskTitle()
        );
    }
}
```

**统一通知管道（创建 + 投递一体化）**

```java
@Service
public class NotificationPipelineService {

    @Autowired private NotificationMapper notificationMapper;
    @Autowired private NotificationCounterService counterService;
    @Autowired private DeliveryRouter deliveryRouter;
    @Autowired private DeliveryLogService deliveryLogService;

    /**
     * 统一通知管道：创建通知 → 更新计数 → 路由投递 → 记录日志
     */
    public Notification createAndDeliver(
            Long userId,
            NotificationType type,
            NotificationCategory category,
            NotificationContent content,
            DeliveryPriority priority) {

        // 1. 持久化通知记录
        Notification notification = new Notification();
        notification.setUserId(userId);
        notification.setType(type);
        notification.setCategory(category);
        notification.setTitle(content.getTitle());
        notification.setBody(content.getBody());
        notification.setRichBody(content.getRichBody());
        notification.setImageUrl(content.getImageUrl());
        notification.setDeepLink(content.getDeepLink());
        notification.setGroupKey(content.getGroupKey());
        notification.setMetadata(content.getMetadataJson());
        notification.setIsRead(false);
        notification.setExpireAt(calculateExpireTime(type));
        notification.setCreatedAt(Instant.now());
        notificationMapper.insert(notification);

        // 2. 更新未读计数（Redis 原子操作）
        counterService.incrementUnreadCount(userId, category);

        // 3. 路由投递
        DeliveryContext ctx = deliveryRouter.routeAndDeliver(notification, priority);

        // 4. 记录投递日志
        deliveryLogService.log(ctx);

        return notification;
    }

    private Instant calculateExpireTime(NotificationType type) {
        // 不同类型通知过期时间不同
        return switch (type.getCategory()) {
            case LEARNING -> Instant.now().plus(7, ChronoUnit.DAYS);
            case SOCIAL -> Instant.now().plus(14, ChronoUnit.DAYS);
            case SYSTEM -> Instant.now().plus(30, ChronoUnit.DAYS);
            case MARKETING -> Instant.now().plus(3, ChronoUnit.DAYS);
        };
    }
}
```

#### 3.1.3 推送渠道路由

```java
@Service
public class DeliveryRouter {

    @Autowired private WebSocketSessionManager wsSessionManager;
    @Autowired private PushService pushService;
    @Autowired private SmsService smsService;
    @Autowired private UserPreferenceService preferenceService;
    @Autowired private PushTokenService pushTokenService;

    /**
     * 推送渠道路由策略
     * 在线用户：WebSocket + Push双通道
     * 离线用户：Push → 短信(高优先级) → 仅端内
     */
    public DeliveryContext routeAndDeliver(Notification notification,
            DeliveryPriority priority) {
        Long userId = notification.getUserId();
        DeliveryContext ctx = new DeliveryContext(notification, priority);

        boolean isOnline = wsSessionManager.isOnline(userId);

        if (isOnline) {
            // 在线：WebSocket 实时推送
            wsPushService.pushNotification(userId, notification);
            ctx.addChannel(DeliveryChannel.WEBSOCKET, Instant.now());

            // 同时发 Push（确保后台也能看到）
            if (shouldSendPush(userId, notification.getType())) {
                sendPush(userId, notification, ctx);
            }
        } else {
            // 离线：按优先级选择渠道
            UserMessagePreference pref = preferenceService.getPreference(userId);

            if (pref.isPushEnabled() && pushTokenService.hasValidToken(userId)) {
                sendPush(userId, notification, ctx);
            } else if (pref.isSmsEnabled() && priority == DeliveryPriority.URGENT) {
                // 仅紧急通知走短信
                smsService.send(userId, notification.getBody());
                ctx.addChannel(DeliveryChannel.SMS, Instant.now());
            }
            // 其他情况：仅端内消息，用户上线后拉取
        }

        return ctx;
    }

    private boolean shouldSendPush(Long userId, NotificationType type) {
        UserMessagePreference pref = preferenceService.getPreference(userId);
        return pref.isPushEnabledForType(type);
    }

    private void sendPush(Long userId, Notification notification,
            DeliveryContext ctx) {
        PushPayload payload = PushPayload.builder()
            .notificationId(notification.getId())
            .type(notification.getType())
            .deepLink(notification.getDeepLink())
            .build();

        pushService.send(userId,
            notification.getTitle(),
            notification.getBody(),
            payload);
        ctx.addChannel(DeliveryChannel.PUSH, Instant.now());
    }
}
```

```dart
/// Push 推送点击处理
class PushClickHandler {
  final NotificationStore _store;
  final DeepLinkRouter _router;
  final AnalyticsService _analytics;

  Future<void> handlePushTap(Map<String, dynamic> payload) async {
    final notificationId = payload['notification_id'] as String?;
    final deepLink = payload['deep_link'] as String?;

    if (notificationId != null) {
      await _store.markAsRead(notificationId);
      _analytics.logEvent('notification_opened', params: {
        'notification_id': notificationId,
        'source': 'push',
      });
    }

    if (deepLink != null) {
      await _router.navigate(deepLink);
    } else {
      _router.navigate('/notifications');
    }
  }
}
```

#### 3.2.1 事件发布与监听

```java
/**

@Getter
public class AchievementUnlockedEvent extends DomainEvent {
    private final Long userId;

/**
 * 成就解锁事件监听器
 * 监听 → 渲染 → 创建通知 → 即时推送
 */
@Component
@Slf4j
public class AchievementNotificationListener {

    @Autowired private UserPreferenceService preferenceService;
    @Autowired private TemplateRenderer templateRenderer;
    @Autowired private NotificationPipelineService pipelineService;

    @Async("notificationEventExecutor")
    @EventListener
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void onAchievementUnlocked(AchievementUnlockedEvent event) {
        Long userId = event.getUserId();

        // 用户偏好检查
        if (!preferenceService.isNotificationEnabled(
                userId, NotificationType.ACHIEVEMENT_UNLOCKED)) {
            return;
        }

        // 聚合检查：今日是否已有多条成就通知
        if (shouldAggregate(userId)) {
            aggregateAndDeliver(userId, event);
        } else {
            singleDeliver(userId, event);
        }
    }

    private void singleDeliver(Long userId, AchievementUnlockedEvent event) {
        Map<String, Object> vars = Map.of(
            "nickname", preferenceService.getNickname(userId),
            "achievement_name", event.getAchievementName(),
            "rarity_label", event.getRarity().getLabel(),
            "description", event.getDescription()
        );

        NotificationContent content = templateRenderer.render(
            "achievement_unlocked", vars
        );
        content.setDeepLink("/profile/achievements?id=" + event.getAchievementId());
        content.setGroupKey("achievement_" + userId + "_" + LocalDate.now());

        pipelineService.createAndDeliver(
            userId,
            NotificationType.ACHIEVEMENT_UNLOCKED,
            NotificationCategory.LEARNING,
            content,
            DeliveryPriority.HIGH  // 成就通知高优先级
        );
    }

    /**
     * 聚合策略：同一天第2次起聚合为"今日解锁N个成就"
     */
    private void aggregateAndDeliver(Long userId,
            AchievementUnlockedEvent event) {
        int todayCount = getTodayAchievementCount(userId);
        String names = getTodayAchievementNames(userId);

        Map<String, Object> vars = Map.of(
            "nickname", preferenceService.getNickname(userId),
            "count", todayCount + 1,
            "latest_name", event.getAchievementName(),
            "all_names", names
        );

        NotificationContent content = templateRenderer.render(
            "achievement_unlocked_aggregated", vars
        );
        content.setDeepLink("/profile/achievements?date=today");
        content.setGroupKey("achievement_" + userId + "_" + LocalDate.now());

        // 更新已有聚合通知（而非新建）
        pipelineService.updateOrCreateAggregated(
            userId,
            NotificationType.ACHIEVEMENT_UNLOCKED,
            content
        );
    }
}
```
