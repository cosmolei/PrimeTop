# 题目管理与题库系统 - 详细设计

## 1. 模块概述

题目管理与题库系统是 PrimeTop 的核心基础设施模块，负责统一管理所有学科、年级、教材版本的题目数据，为拍照搜题、错题整理、同步练习、考试模拟等功能提供底层支撑。该模块采用结构化建模、多维度标签、向量检索和智能匹配等策略，构建高质量、可扩展的题库体系。

### 1.1 核心职责

| 职责 | 说明 |
|------|------|
| 题目结构化存储 | 统一题干、选项、答案、解析、标签等数据模型 |
| 题目分类与标签 | 按学科、年级、章节、知识点、题型、难度等多维度分类 |
| 题目相似度计算 | 基于文本相似度和语义向量计算题目相似度 |
| 题目智能匹配 | 支持拍题识别结果与题库的智能匹配 |
| 题目质量评估 | 对题目的完整性、准确性、规范性进行评估 |
| 题目生命周期管理 | 从创建、审核、发布、下架到归档的全流程管理 |
| 题目变式生成 | 基于模板生成参数可变的类似题目 |
| 题目统计与报表 | 题库覆盖率、题型分布、难度分布等统计 |

### 1.2 与其他模块的关系

```
题目管理与题库系统
    ├──→ 拍照搜题（题目匹配与检索）
    ├──→ 错题整理（错题关联题目）
    ├──→ 同步练习（章节题目推荐）
    ├──→ 考试模拟（组卷与选题）
    ├──→ 知识图谱（题目与知识点关联）
    ├──→ 理科解题（题目分步解析）
    ├──→ 练习测评（答题记录关联）
    └──→ 数据分析（题目答题数据统计）
```

## 2. 数据结构设计

### 2.1 核心实体定义

#### 2.1.1 题目表 (questions)

```sql
CREATE TABLE questions (
    -- 主键与基础字段
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '题目ID',
    question_number VARCHAR(50) DEFAULT NULL COMMENT '题目编号（如：RJ-初一-数学-001）',

    -- 分类字段
    subject_id INT UNSIGNED NOT NULL COMMENT '学科ID（关联 subjects 表）',
    grade_id SMALLINT UNSIGNED NOT NULL COMMENT '年级ID（1-12，1为一年级）',
    textbook_id INT UNSIGNED NOT NULL COMMENT '教材版本ID',
    chapter_id INT UNSIGNED DEFAULT NULL COMMENT '章节ID（可选，综合题可为空）',
    knowledge_point_ids JSON NOT NULL COMMENT '关联知识点ID列表 [1, 2, 3]',

    -- 题目内容
    question_type ENUM('choice', 'fill', 'judge', 'short_answer', 'calculation', 'proof', 'application', 'synthesis') NOT NULL COMMENT '题型：选择题、填空题、判断题、简答题、计算题、证明题、应用题、综合题',
    difficulty ENUM('easy', 'medium', 'hard', 'very_hard') NOT NULL DEFAULT 'medium' COMMENT '难度：简单、中等、困难、极难',
    difficulty_score DECIMAL(3,2) DEFAULT NULL COMMENT '难度评分（0.00-1.00，人工标注或模型预测）',
    cognitive_level ENUM('remember', 'understand', 'apply', 'analyze', 'evaluate', 'create') DEFAULT NULL COMMENT '布鲁姆认知层级',

    -- 题目内容（富文本支持）
    question_text TEXT NOT NULL COMMENT '题干（支持 Markdown + LaTeX）',
    question_html TEXT DEFAULT NULL COMMENT '题干渲染后的 HTML',
    question_images JSON DEFAULT NULL COMMENT '题目图片URL列表 ["url1", "url2"]',

    -- 选项（选择题和判断题使用）
    options JSON DEFAULT NULL COMMENT '选项 {"A": "内容", "B": "内容", ...}',
    correct_answer TEXT NOT NULL COMMENT '正确答案（选择题填选项字母，其他填具体内容）',

    -- 解析与知识点
    analysis TEXT DEFAULT NULL COMMENT '解析（支持 Markdown + LaTeX）',
    analysis_html TEXT DEFAULT NULL COMMENT '解析渲染后的 HTML',
    key_points JSON DEFAULT NULL COMMENT '关键考点 ["概念A", "方法B"]',
    common_mistakes JSON DEFAULT NULL COMMENT '常见错误 ["错误1描述", "错误2描述"]',

    -- 题目来源与审核
    source_type ENUM('official', 'textbook', 'exam', 'third_party', 'ai_generated') NOT NULL COMMENT '来源类型：官方题库、教材、考试真题、第三方、AI生成',
    source_detail VARCHAR(255) DEFAULT NULL COMMENT '来源详情（如：2023年北京中考数学第12题）',
    author_id BIGINT UNSIGNED DEFAULT NULL COMMENT '创建者/编辑者ID',
    reviewer_id BIGINT UNSIGNED DEFAULT NULL COMMENT '审核人ID',

    -- 质量指标
    quality_score DECIMAL(3,2) DEFAULT NULL COMMENT '质量评分（0.00-1.00）',
    is_verified BOOLEAN DEFAULT FALSE COMMENT '是否已人工验证',
    has_dispute BOOLEAN DEFAULT FALSE COMMENT '是否有争议（用户反馈不准确）',
    dispute_count INT UNSIGNED DEFAULT 0 COMMENT '争议次数',

    -- 使用统计
    view_count INT UNSIGNED DEFAULT 0 COMMENT '查看次数',
    search_count INT UNSIGNED DEFAULT 0 COMMENT '被搜索次数',
    answer_count INT UNSIGNED DEFAULT 0 COMMENT '答题次数',
    correct_count INT UNSIGNED DEFAULT 0 COMMENT '答对次数',
    mistake_count INT UNSIGNED DEFAULT 0 COMMENT '错误次数',

    -- 状态与时间
    status ENUM('draft', 'reviewing', 'published', 'deprecated', 'archived') NOT NULL DEFAULT 'draft' COMMENT '状态',
    published_at DATETIME DEFAULT NULL COMMENT '发布时间',
    deprecated_at DATETIME DEFAULT NULL COMMENT '下架时间',
    archived_at DATETIME DEFAULT NULL COMMENT '归档时间',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',

    PRIMARY KEY (id),
    UNIQUE KEY uk_question_number (question_number),
    KEY idx_subject_grade (subject_id, grade_id),
    KEY idx_textbook_chapter (textbook_id, chapter_id),
    KEY idx_difficulty (difficulty),
    KEY idx_question_type (question_type),
    KEY idx_status (status),
    KEY idx_published_at (published_at),
    FULLTEXT KEY ft_question_text (question_text)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='题目主表';
```

## 4. 关键代码示例

### 4.1 题目智能匹配服务（Python）

```python
from typing import List, Optional, Dict
from dataclasses import dataclass
import numpy as np
from milvus import connections, Collection
from elasticsearch import Elasticsearch
import re
from difflib import SequenceMatcher

@dataclass
class MatchResult:
    matched: bool
    question_id: Optional[int] = None
    similarity_score: float = 0.0
    question: Optional[Dict] = None
    similar_questions: List[Dict] = None


class QuestionMatcher:
    def __init__(self, es_host: str, milvus_host: str):
        self.es = Elasticsearch(es_host)
        connections.connect(host=milvus_host, port='19530')
        self.collection = Collection("question_vectors")
        self.collection.load()

    def normalize_text(self, text: str) -> str:
        """标准化文本：去除空白、统一大小写、去除特殊符号"""
        text = re.sub(r'\s+', ' ', text.strip())
        text = text.lower()
        text = re.sub(r'[^\w\u4e00-\u9fff]', '', text)  # 保留中文和字母数字
        return text

    def text_similarity(self, text1: str, text2: str) -> float:
        """计算文本相似度（基于词序列）"""
        text1 = self.normalize_text(text1)
        text2 = self.normalize_text(text2)
        return SequenceMatcher(None, text1, text2).ratio()

    def vector_similarity_search(
        self,
        query_embedding: List[float],
        subject_id: int,
        grade_id: int,
        top_k: int = 10
    ) -> List[Dict]:
        """基于向量相似度检索题目"""
        search_params = {"metric_type": "COSINE", "params": {"nprobe": 10}}

        results = self.collection.search(
            data=[query_embedding],
            anns_field="embedding",
            param=search_params,
            limit=top_k,
            expr=f"subject_id == {subject_id} && grade_id == {grade_id}",
            output_fields=["question_id", "subject_id", "grade_id"]
        )

        return [
            {
                "question_id": result.id,
                "distance": result.distance,
                "score": 1 - result.distance  # 转换为相似度
            }
            for result in results[0]
        ]

    def fulltext_search(
        self,
        query: str,
        subject_id: int,
        grade_id: int,
        top_k: int = 10
    ) -> List[Dict]:
        """全文检索题目"""
        query_body = {
            "query": {
                "bool": {
                    "must": [
                        {"match": {"question_text": query}}
                    ],
                    "filter": [
                        {"term": {"subject_id": subject_id}},
                        {"term": {"grade_id": grade_id}}
                    ]
                }
            },
            "size": top_k
        }

        response = self.es.search(index="questions", body=query_body)
        return [
            {
                "question_id": hit["_source"]["id"],
                "score": hit["_score"]
            }
            for hit in response["hits"]["hits"]
        ]

    def hybrid_match(
        self,
        question_text: str,
        options: Optional[Dict] = None,
        subject_id: Optional[int] = None,
        grade_id: Optional[int] = None,
        threshold: float = 0.85
    ) -> MatchResult:
        """混合匹配策略：向量检索 + 全文检索 + 文本相似度"""

        # 1. 构建查询文本
        if options:
            options_text = " ".join([f"{k}: {v}" for k, v in options.items()])
            query_text = f"{question_text} {options_text}"

        # 2. 生成查询向量（假设调用 embedding 服务）

        vector_results = self.vector_similarity_search(
            query_embedding, subject_id, grade_id, top_k=10
        )

        # 4. 全文检索
        fulltext_results = self.fulltext_search(query_text, subject_id, grade_id, top_k=10)

        # 5. 合并和去重
        combined_scores = {}
        for result in vector_results:
            qid = result["question_id"]
            combined_scores[qid] = combined_scores.get(qid, 0) + result["score"] * 0.6

        for result in fulltext_results:
            qid = result["question_id"]
            combined_scores[qid] = combined_scores.get(qid, 0) + result["score"] * 0.4

        # 6. 文本相似度复核
        best_match = None
        best_score = 0.0

        for qid, score in sorted(combined_scores.items(), key=lambda x: x[1], reverse=True):
            question = self._get_question_by_id(qid)
            text_sim = self.text_similarity(question_text, question["question_text"])

            # 综合评分：向量+全文检索 70% + 文本相似度 30%
            final_score = score * 0.7 + text_sim * 0.3

                best_score = final_score
                best_match = question

        if best_match and best_score >= threshold:
            similar_results = self.vector_similarity_search(
                query_embedding, subject_id, grade_id, top_k=5
```

### 4.3 题目质量评估服务（Python）

```python
from typing import Dict, List
from dataclasses import dataclass


@dataclass
class QualityMetrics:
    """题目质量指标"""
    completeness: float  # 完整性（0-1）
    accuracy: float  # 准确性（0-1）
    clarity: float  # 清晰度（0-1）
    consistency: float  # 一致性（0-1）
    overall_score: float  # 总体评分（0-1）


class QuestionQualityAssessor:
    """题目质量评估器"""

    def __init__(self):
        self.completeness_rules = {
            "question_text": {"weight": 0.3, "required": True},
            "correct_answer": {"weight": 0.2, "required": True},
            "analysis": {"weight": 0.2, "required": False},
            "options": {"weight": 0.15, "required_for": ["choice", "judge"]},
            "knowledge_points": {"weight": 0.1, "required": False},
            "source_detail": {"weight": 0.05, "required": False}
        }

    def assess_quality(self, question: Dict) -> QualityMetrics:
        """评估题目质量"""
        completeness = self._assess_completeness(question)
        accuracy = self._assess_accuracy(question)
        clarity = self._assess_clarity(question)
        consistency = self._assess_consistency(question)

        overall_score = (
            completeness * 0.3 +
            accuracy * 0.4 +
            clarity * 0.2 +
            consistency * 0.1
        )

        return QualityMetrics(
            completeness=completeness,
            accuracy=accuracy,
            clarity=clarity,
            consistency=consistency,
            overall_score=overall_score
        )

    def _assess_completeness(self, question: Dict) -> float:
        """评估完整性"""
        score = 0.0
        total_weight = 0.0

        for field, rule in self.completeness_rules.items():
            weight = rule["weight"]
            total_weight += weight

            # 检查必填字段
            if rule.get("required"):
                if question.get(field):
                    score += weight
                else:
                    continue

            # 检查特定题型必填字段
            elif "required_for" in rule:
                question_type = question.get("question_type")
                if question_type in rule["required_for"]:
                    if question.get(field):
                        score += weight
                else:
                    score += weight  # 非必填则给满分

            # 可选字段
            else:
                if question.get(field):
                    score += weight * 0.8  # 有内容给 80% 分
                else:
                    score += weight * 0.5  # 无内容给 50% 分

        return score / total_weight if total_weight > 0 else 0.0

    def _assess_accuracy(self, question: Dict) -> float:
        """评估准确性（需要结合 AI 校验和历史数据）"""
        score = 1.0

        # 1. 检查争议次数
        dispute_count = question.get("dispute_count", 0)
        if dispute_count > 10:
            score -= 0.3
        elif dispute_count > 5:
            score -= 0.1

        # 2. 检查用户反馈的正确率
        answer_count = question.get("answer_count", 0)
        correct_count = question.get("correct_count", 0)
        if answer_count > 0:
            user_correct_rate = correct_count / answer_count
            if user_correct_rate < 0.5:  # 用户正确率过低，可能题目有问题
                score -= 0.2

        # 3. 检查是否已人工验证
        if not question.get("is_verified", False):
            score -= 0.1

        return max(0.0, min(1.0, score))

    def _assess_clarity(self, question: Dict) -> float:
        """评估清晰度"""
        score = 1.0
        question_text = question.get("question_text", "")

        # 1. 检查题干长度
        if len(question_text) < 10:
            score -= 0.3
        elif len(question_text) > 500:
            score -= 0.2  # 题目过长可能不够清晰

        # 2. 检查是否有重复内容
        words = question_text.split()
        if len(words) != len(set(words)):
            score -= 0.1

        # 3. 检查选项是否清晰（选择题）
        if question.get("question_type") == "choice":
            options = question.get("options", {})
            if len(options) < 3:
                score -= 0.2
            else:
                # 检查选项是否有明显重复
                option_texts = list(options.values())
                for i in range(len(option_texts)):
                    for j in range(i + 1, len(option_texts)):
                        if option_texts[i] == option_texts[j]:
                            score -= 0.3
                            break

        # 4. 检查解析是否清晰
        analysis = question.get("analysis", "")
        if len(analysis) < 10:
            score -= 0.2

        return max(0.0, min(1.0, score))

    def _assess_consistency(self, question: Dict) -> float:
        """评估一致性"""
        score = 1.0

        # 1. 检查题型与选项的一致性
        question_type = question.get("question_type")
        options = question.get("options")

        if question_type in ["choice", "judge"]:
            if not options or len(options) < 2:
                score -= 0.4
        else:
            if options:  # 非选择题不应该有选项
                score -= 0.2

        # 2. 检查正确答案与题型的一致性
        correct_answer = question.get("correct_answer", "")
        if question_type == "choice":
            valid_options = list(options.keys()) if options else []
            if correct_answer not in valid_options:
                score -= 0.5  # 严重错误
        elif question_type == "judge":
            if correct_answer not in ["A", "B", "对", "错", "√", "×"]:
                score -= 0.3

        # 3. 检查知识点与年级的一致性
        # 这里需要查询知识点体系，验证知识点是否属于该年级
        # 简化实现：假设知识点 ID 有效
        knowledge_points = question.get("knowledge_point_ids", [])
        if not knowledge_points:
            score -= 0.2

        return max(0.0, min(1.0, score))

    def generate_quality_report(self, question: Dict) -> Dict:
        """生成质量报告"""
        metrics = self.assess_quality(question)

        return {
            "question_id": question.get("id"),
            "overall_score": metrics.overall_score,
            "metrics": {
                "completeness": metrics.completeness,
                "accuracy": metrics.accuracy,
                "clarity": metrics.clarity,
                "consistency": metrics.consistency
            },
            "recommendations": self._generate_recommendations(question, metrics),
            "needs_review": metrics.overall_score < 0.7
        }

    def _generate_recommendations(
        self,
        question: Dict,
        metrics: QualityMetrics
    ) -> List[str]:
        """生成改进建议"""
        recommendations = []

        if metrics.completeness < 0.8:
            if not question.get("analysis"):
                recommendations.append("建议补充题目解析")
            if not question.get("knowledge_point_ids"):
                recommendations.append("建议关联知识点")

        if metrics.accuracy < 0.8:
            recommendations.append("题目存在较多争议，建议人工复核")

        if metrics.clarity < 0.8:
            if len(question.get("question_text", "")) < 10:
                recommendations.append("题干过于简短，建议补充")
            if question.get("question_type") == "choice" and len(question.get("options", {})) < 4:
                recommendations.append("建议增加选项数量至4个")

        if metrics.consistency < 0.8:
            if question.get("question_type") == "choice" and question.get("correct_answer") not in question.get("options", {}).keys():
                recommendations.append("正确答案与选项不匹配，请检查")

        return recommendations
```

1. **来源追踪**：记录每个题目的来源信息（官方题库、教材、考试真题等）
2. **数字水印**：对题目解析和图片添加数字水印，防止盗用
3. **版权声明**：在题目详情页标注来源和版权信息

### 8.3 数据安全

1. **访问控制**：题库数据仅限授权用户访问
2. **审计日志**：记录所有题目查看、编辑、删除操作
3. **备份与恢复**：定期备份题库数据，支持灾难恢复
