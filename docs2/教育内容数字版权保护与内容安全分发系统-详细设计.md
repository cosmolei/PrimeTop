# 教育内容数字版权保护与内容安全分发系统 - 详细设计

> 版本：v1.0 | 日期：2026-05-23 | 状态：初稿

## 1. 模块概述

### 1.1 功能定位

教育内容数字版权保护与内容安全分发系统（Content DRM & Secure Distribution System）负责对 PrimeTop 平台中的教材资源、题库内容、精品课程、试卷资料等数字内容进行全生命周期版权保护，防止未授权复制、截屏录屏泄露、非法二次分发，同时确保正版用户的无障碍访问体验。

### 1.2 背景与问题

| 风险场景 | 具体表现 | 影响 |
|----------|----------|------|
| 截屏/录屏泄露 | 用户截屏后通过社交媒体传播付费内容 | 内容资产流失、付费意愿下降 |
| 账号共享 | 同一账号多人使用，绕过付费限制 | 收入损失、用户数据污染 |
| 离线内容提取 | root/越狱设备直接读取本地缓存文件 | 题库批量泄露 |
| 第三方爬虫 | 自动化抓取接口批量获取题目和解析 | 题库资产被竞品复制 |
| 教材版权纠纷 | 使用未获授权的教材内容 | 法律合规风险 |
| 内部泄露 | 运营/开发人员导出数据 | 核心资产外流 |

### 1.3 设计原则

1. **无感保护**：正版用户几乎感知不到保护措施的存在
2. **分层防护**：不同敏感等级内容采用不同保护强度
3. **可追溯**：泄露内容可定位到具体用户和设备
4. **性能优先**：加解密和水印处理不显著影响加载速度（<50ms 增量）
5. **离线可控**：离线内容仍有时间窗口限制和设备绑定

### 1.4 内容分级

| 等级 | 标识 | 内容类型 | 保护措施 |
|------|------|----------|----------|
| L0 公开 | 🟢 | 免费预览、公开课程简介、宣传内容 | 基础防盗链 |
| L1 标准 | 🟡 | 会员可见题目解析、同步课堂内容 | 动态水印 + 禁止截屏 |
| L2 敏感 | 🟠 | 真题试卷、精品课程、付费专项训练 | 隐形水印 + 端到端加密 + 设备绑定 |
| L3 核心 | 🔴 | 完整题库数据、教材原始文件、内部教研资料 | 服务器端渲染 + 强水印 + 严格访问控制 |

### 2.2 核心服务职责

| 服务 | 职责 | 关键接口 |
|------|------|----------|
| 许可证服务 (License Service) | 管理用户对内容的访问许可，颁发和验证内容许可证 | `issueLicense`, `validateLicense`, `revokeLicense` |
| 水印服务 (Watermark Service) | 为内容生成可见/隐形水印，支持溯源 | `generateVisibleWatermark`, `embedInvisibleWatermark`, `extractWatermark` |
| 加密服务 (Encryption Service) | 内容加密/解密，密钥管理，设备密钥分发 | `encryptContent`, `decryptContent`, `rotateKey` |
| 泄露追踪服务 (Trace Service) | 泄露内容提取水印并定位来源 | `traceContent`, `reportLeak`, `queryLeakHistory` |
| 版权元数据服务 (Metadata Service) | 内容版权信息登记、授权链管理、到期提醒 | `registerCopyright`, `updateLicenseChain`, `checkExpiry` |
| 授权管理服务 (Authorization Service) | 第三方内容授权合同管理、使用量统计 | `createContract`, `recordUsage`, `getQuota` |
| 审计服务 (Audit Service) | 所有敏感操作的审计日志记录和查询 | `logAccess`, `logDecrypt`, `queryAuditTrail` |

## 3. 数据模型

### 3.1 核心表结构

#### content_copyright（内容版权登记表）

```sql
CREATE TABLE content_copyright (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    content_id      VARCHAR(64) NOT NULL COMMENT '内容ID，关联题目/课程/试卷等',
    content_type    VARCHAR(32) NOT NULL COMMENT '内容类型: question/course/exam/textbook_chapter/material',
    protection_level TINYINT NOT NULL DEFAULT 1 COMMENT '保护等级: 0=L0, 1=L1, 2=L2, 3=L3',
    
    -- 版权信息
    copyright_holder VARCHAR(128) COMMENT '版权方名称',
    license_type     VARCHAR(32) COMMENT '授权类型: original/licensed/purchased/free',
    license_start    DATETIME COMMENT '授权开始时间',
    license_end      DATETIME COMMENT '授权结束时间',
    source_ref       VARCHAR(256) COMMENT '原始来源标识(如出版社合同号)',
    
    -- 加密信息
    encryption_key_id VARCHAR(64) COMMENT '当前使用的加密密钥ID',
    encryption_version INT DEFAULT 1 COMMENT '加密版本号',
    encrypted_storage_path VARCHAR(512) COMMENT '加密后的存储路径',
    
    -- 水印配置
    watermark_config JSON COMMENT '水印配置: {visible:bool, invisible:bool, text:string, position:string}',
    
    -- 状态
    status          TINYINT DEFAULT 1 COMMENT '0=下架 1=正常 2=版权到期 3=版权争议',
    
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_content (content_id, content_type),
    INDEX idx_license_end (license_end),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容版权登记表';
```

### 3.2 关键数据流

```
内容请求流程:
  用户点击内容 → 客户端请求许可证 → 验证会员状态/购买记录 
  → 颁发license_token(含设备绑定密钥) → 客户端用token请求加密内容
  → 返回加密数据流 → 客户端本地解密渲染 → 嵌入水印 → 记录审计日志

内容上传流程:
  内容入库 → 版权元数据登记 → 按保护等级加密存储 
  → 配置水印策略 → 生成缩略图(含保护标记) → 内容可用
```

### 4.2 加密内容分发 API

#### 4.2.1 获取加密内容（流式）

```
GET /api/v1/content-secure/{contentId}/stream
Authorization: Bearer <license_token>
X-Device-ID: fp_a3f8d2e1b9c4
X-Key-Version: 3
```

**响应：**
- Content-Type: `application/octet-stream`
- 每个分块(chunk)的格式：

```
┌─────────────────────────────────────────────┐
│ chunk_header (16 bytes)                     │
│   chunk_index    UINT32  (4 bytes)          │
│   data_length    UINT32  (4 bytes)          │
│   iv             BYTE[12] (12 bytes)        │
│   reserved       UINT16  (2 bytes)          │
├─────────────────────────────────────────────┤
│ encrypted_data (variable length)            │
│   AES-256-GCM(plaintext, iv, key, aad)     │
├─────────────────────────────────────────────┤
│ auth_tag (16 bytes)                         │
│   GCM authentication tag                    │
└─────────────────────────────────────────────┘
```

**关键设计：**
- 每个分块独立加密，支持流式传输
- AAD (Additional Authenticated Data) = `contentId + chunk_index`
- 服务端实时嵌入水印元数据到特定分块

### 6.2 密钥管理服务实现

```java
/**
 * 内容密钥管理服务
 * 负责 CEK 的生成、分发、轮换和销毁
 */
@Service
public class ContentKeyService {
    
    @Autowired
    private KmsClient kmsClient;
    
    @Autowired
    private ContentKeyRepository keyRepo;
    
    private static final String KEY_ALGORITHM = "AES";
    private static final int KEY_SIZE = 256; // bits
    private static final String WRAPPING_ALGORITHM = "RSA-OAEP";
    
    /**
     * 为内容生成数据密钥
     */
    public ContentKeyResult generateContentKey(String contentId, int protectionLevel) {
        // 1. 生成 CEK (Content Encryption Key)
        KeyGenerator keyGen = KeyGenerator.getInstance(KEY_ALGORITHM);
        keyGen.init(KEY_SIZE, SecureRandom.getInstanceStrong());
        SecretKey cek = keyGen.generateKey();
        
        // 2. 使用对应等级的 MEK 加密 CEK
        String mekId = "MEK-L" + protectionLevel;
        EncryptedKey encryptedCek = kmsClient.encrypt(
            mekId, 
            cek.getEncoded()
        );
        
        // 3. 存储加密后的 CEK
        ContentKeyRecord record = ContentKeyRecord.builder()
            .contentId(contentId)
            .keyVersion(generateKeyVersion(contentId))
            .encryptedKey(Base64.getEncoder().encodeToString(encryptedCek.getCiphertext()))
            .mekId(mekId)
            .algorithm("AES-256-GCM")
            .createdAt(Instant.now())
            .expiresAt(Instant.now().plus(365, ChronoUnit.DAYS))
            .build();
        
        keyRepo.save(record);
        
        return ContentKeyResult.builder()
            .keyVersion(record.getKeyVersion())
            .encryptedKey(record.getEncryptedKey())
            .algorithm(record.getAlgorithm())
            .build();
    }
    
    /**
     * 为特定设备包装内容密钥
     * 使用设备公钥加密 CEK，确保只有目标设备能解密
     */
    public WrappedKeyResult wrapKeyForDevice(
            String contentId, 
            int keyVersion,
            String devicePublicKeyBase64) {
        
        // 1. 解密 CEK (使用 MEK)
        ContentKeyRecord record = keyRepo.findByContentIdAndKeyVersion(contentId, keyVersion)
            .orElseThrow(() -> new KeyNotFoundException(contentId, keyVersion));
        
        byte[] cekPlaintext = kmsClient.decrypt(
            record.getMekId(),
            Base64.getDecoder().decode(record.getEncryptedKey())
        );
        
        // 2. 使用设备公钥加密 CEK
        byte[] devicePublicKeyBytes = Base64.getDecoder().decode(devicePublicKeyBase64);
        X509EncodedKeySpec keySpec = new X509EncodedKeySpec(devicePublicKeyBytes);
        PublicKey devicePublicKey = KeyFactory.getInstance("RSA").generatePublic(keySpec);
        
        Cipher cipher = Cipher.getInstance(WRAPPING_ALGORITHM);
        cipher.init(Cipher.WRAP_MODE, devicePublicKey);
        byte[] wrappedKey = cipher.wrap(new SecretKeySpec(cekPlaintext, KEY_ALGORITHM));
        
        // 3. 清除内存中的明文密钥
        Arrays.fill(cekPlaintext, (byte) 0);
        
        return WrappedKeyResult.builder()
            .wrappedKey(Base64.getEncoder().encodeToString(wrappedKey))
            .keyVersion(keyVersion)
            .wrappingAlgorithm(WRAPPING_ALGORITHM)
            .contentAlgorithm("AES-256-GCM")
            .build();
    }
    
    /**
     * 密钥轮换：为内容生成新版本密钥
     * 旧密钥保留用于解密已缓存的内容
     */
    @Scheduled(cron = "0 0 3 1 * ?") // 每月1号凌晨3点
    public void rotateKeys() {
        List<String> activeContentIds = keyRepo.findActiveContentIds();
        
        for (String contentId : activeContentIds) {
            try {
                generateContentKey(contentId, getProtectionLevel(contentId));
                log.info("Key rotated for content: {}", contentId);
            } catch (Exception e) {
                log.error("Key rotation failed for content: {}", contentId, e);
            }
        }
    }
}
```

### 6.3 内容加密流程

```java
/**
 * 内容加密服务
 * 处理上传内容的加密存储
 */
@Service
public class ContentEncryptionService {
    
    private static final int CHUNK_SIZE = 16 * 1024; // 16KB per chunk
    private static final String CIPHER_ALGORITHM = "AES/GCM/NoPadding";
    private static final int GCM_TAG_LENGTH = 128; // bits
    private static final int IV_LENGTH = 12; // bytes
    
    @Autowired
    private ContentKeyService keyService;
    
    @Autowired
    private ObjectStorageClient storageClient;
    
    /**
     * 加密内容并存储
     * @return 加密后的元数据
     */
    public EncryptedContentResult encryptAndStore(
            String contentId,
            byte[] plaintext,
            int protectionLevel) {
        
        if (protectionLevel == 0) {
            // L0 不加密，直接存储
            String path = "/public/" + contentId;
            storageClient.upload(path, plaintext);
            return EncryptedContentResult.publicContent(path);
        }
        
        // 1. 获取内容密钥
        SecretKey cek = keyService.getContentKey(contentId);
        int keyVersion = keyService.getCurrentKeyVersion(contentId);
        
        // 2. 分块加密
        List<EncryptedChunk> chunks = new ArrayList<>();
        int totalChunks = (int) Math.ceil((double) plaintext.length / CHUNK_SIZE);
        
        ByteArrayOutputStream encryptedStream = new ByteArrayOutputStream();
        
        for (int i = 0; i < totalChunks; i++) {
            int start = i * CHUNK_SIZE;
            int end = Math.min(start + CHUNK_SIZE, plaintext.length);
            byte[] chunkData = Arrays.copyOfRange(plaintext, start, end);
            
            // 生成随机 IV
            byte[] iv = new byte[IV_LENGTH];
            SecureRandom random = new SecureRandom();
            random.nextBytes(iv);
            
            // AAD = contentId + chunkIndex
            byte[] aad = (contentId + ":" + i).getBytes(StandardCharsets.UTF_8);
            
            // AES-GCM 加密
            Cipher cipher = Cipher.getInstance(CIPHER_ALGORITHM);
            GCMParameterSpec gcmSpec = new GCMParameterSpec(GCM_TAG_LENGTH, iv);
            SecretKeySpec keySpec = new SecretKeySpec(cek.getEncoded(), "AES");
            cipher.init(Cipher.ENCRYPT_MODE, keySpec, gcmSpec);
            cipher.updateAAD(aad);
            
            byte[] encryptedChunk = cipher.doFinal(chunkData);
            
            // 写入 chunk header + encrypted data + auth tag
            ByteBuffer header = ByteBuffer.allocate(16);
            header.putInt(i);           // chunk_index (4 bytes)
            header.putInt(encryptedChunk.length); // data_length (4 bytes)  
            header.put(iv);             // iv (12 bytes)
            
            encryptedStream.write(header.array());
            encryptedStream.write(encryptedChunk);
        }
        
        // 3. 上传加密数据
        String encryptedPath = "/secure/" + contentId + ".enc";
        storageClient.upload(encryptedPath, encryptedStream.toByteArray());
        
        // 4. 计算哈希
        String hash = DigestUtils.sha256Hex(plaintext);
        
        // 5. 清除内存中的明文
        Arrays.fill(plaintext, (byte) 0);
        
        return EncryptedContentResult.builder()
            .encryptedPath(encryptedPath)
            .totalChunks(totalChunks)
            .chunkSize(CHUNK_SIZE)
            .encryptionAlgorithm("AES-256-GCM")
            .keyVersion(keyVersion)
            .totalSize(plaintext.length)
            .hashSha256(hash)
            .build();
    }
}
```

```dart
    final raw = '${fp.hardwareHash}|${fp.systemHash}|${fp.stableId}';
    return sha256.convert('$raw|$serverSalt'.codeUnits).toString();
  }
```

```java
/**
 * 设备绑定管理

@Service
public class DeviceBindingService {
    
    // 设备绑定限制配置
    private static final int MAX_DEVICES_FREE = 1;      // 免费用户1台
    private static final int MAX_DEVICES_MONTHLY = 2;    // 月度会员2台
    private static final int MAX_DEVICES_ANNUAL = 3;     // 年度会员3台
    private static final int BIND_COOLDOWN_DAYS = 30;    // 换绑冷却期
    
    /**
     * 绑定设备到用户
     */
    public BindResult bindDevice(Long userId, String deviceFingerprint, 
                                  String membershipLevel) {
        int maxDevices = getMaxDevices(membershipLevel);
        
        // 1. 查询已绑定设备数
        List<DeviceBinding> bindings = bindingRepo.findByUserId(userId);
        long activeDevices = bindings.stream()
            .filter(b -> b.getStatus() == BindingStatus.ACTIVE)
            .count();
        
        if (activeDevices >= maxDevices) {
            return BindResult.builder()
                .success(false)
                .reason("DEVICE_LIMIT_EXCEEDED")
                .maxDevices(maxDevices)
                .currentDevices((int) activeDevices)
                .boundDevices(bindings.stream()
                    .filter(b -> b.getStatus() == BindingStatus.ACTIVE)
                    .map(this::toDeviceInfo)
                    .collect(Collectors.toList()))
                .build();
        }
        
        // 2. 检查是否已绑定该设备
        Optional<DeviceBinding> existing = bindings.stream()
            .filter(b -> b.getDeviceFingerprint().equals(deviceFingerprint))
            .findFirst();
        
        if (existing.isPresent()) {
            existing.get().setLastActiveAt(Instant.now());
            bindingRepo.save(existing.get());
            return BindResult.alreadyBound(existing.get().getId());
        }
        
        // 3. 检查换绑冷却期
        Optional<DeviceBinding> lastUnbind = bindings.stream()
            .filter(b -> b.getStatus() == BindingStatus.UNBOUND)
            .max(Comparator.comparing(DeviceBinding::getUnboundAt));
        
        if (lastUnbind.isPresent()) {
            Instant cooldownEnd = lastUnbind.get().getUnboundAt()
                .plus(BIND_COOLDOWN_DAYS, ChronoUnit.DAYS);
            if (Instant.now().isBefore(cooldownEnd)) {
                return BindResult.cooldown(cooldownEnd);
            }
        }
        
        // 4. 创建绑定
        DeviceBinding binding = DeviceBinding.builder()
            .userId(userId)
            .deviceFingerprint(deviceFingerprint)
            .boundAt(Instant.now())
            .lastActiveAt(Instant.now())
            .status(BindingStatus.ACTIVE)
            .build();
        
        bindingRepo.save(binding);
        
        // 5. 吊销该设备上的旧许可证（强制重新获取）
        licenseService.revokeByDevice(userId, deviceFingerprint);
        
        return BindResult.success(binding.getId());
    }
}
```

```java
/**
 * 内容安全API签名验证中间件
 */
@Component
public class ContentSignatureFilter implements OncePerRequestFilter {
    
    private static final long REQUEST_VALIDITY_MS = 5 * 60 * 1000; // 5分钟
    private static final Set<String> PROTECTED_PATHS = Set.of(
        "/api/v1/content-secure/",
        "/api/v1/content-license/",
        "/api/v1/watermark/"
    );
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                     HttpServletResponse response,
                                     FilterChain chain) throws ServletException, IOException {
        
        String path = request.getRequestURI();
        
        // 仅对受保护路径验证签名
        if (!PROTECTED_PATHS.stream().anyMatch(path::startsWith)) {
            chain.doFilter(request, response);
            return;
        }
        
        // 1. 提取签名头
        String signature = request.getHeader("X-Signature");
        String timestamp = request.getHeader("X-Timestamp");
        String nonce = request.getHeader("X-Nonce");
        String deviceId = request.getHeader("X-Device-ID");
        
        if (StringUtils.isAnyBlank(signature, timestamp, nonce, deviceId)) {
            reject(response, 401, "MISSING_SIGNATURE_HEADERS");
            return;
        }
        
        // 2. 时间戳验证（防重放）
        long requestTime = Long.parseLong(timestamp);
        long now = System.currentTimeMillis();
        if (Math.abs(now - requestTime) > REQUEST_VALIDITY_MS) {
            reject(response, 401, "REQUEST_EXPIRED");
            return;
        }
        
        // 3. Nonce 去重（防重放）
        if (!nonceService.checkAndReserve(nonce, REQUEST_VALIDITY_MS)) {
            reject(response, 401, "DUPLICATE_NONCE");
            return;
        }
        
        // 4. 验证签名
        String appSecret = getSecretForDevice(deviceId);
        String expectedSignature = computeSignature(request, appSecret);
        
        if (!MessageDigest.isEqual(
                signature.getBytes(), 
                expectedSignature.getBytes())) {
            reject(response, 401, "INVALID_SIGNATURE");
            return;
        }
        
        // 5. 设备指纹一致性校验
        String tokenDeviceId = extractDeviceFromToken(request);
        if (!deviceId.equals(tokenDeviceId)) {
            reject(response, 403, "DEVICE_MISMATCH");
            return;
        }
        
        chain.doFilter(request, response);
    }
}
```

```java
@Service
public class ContentAnomalyDetector {
    
    /**
     * 检测内容爬取行为
     */
    public AnomalyResult detectCrawling(Long userId, String deviceId, 
                                         Instant windowStart) {
        List<ContentAccessAudit> recentAccess = auditRepo
            .findByUserIdAndCreatedAtAfter(userId, windowStart);
        
        AnomalyResult result = new AnomalyResult();
        
        // 1. 高频访问检测
        long accessCount = recentAccess.size();
        if (accessCount > 200) { // 1小时内超过200次
            result.addSignal("HIGH_FREQUENCY", accessCount);
        }
        
        // 2. 顺序访问模式检测（疑似遍历）
        List<String> contentIds = recentAccess.stream()
            .map(ContentAccessAudit::getContentId)
            .collect(Collectors.toList());
        if (hasSequentialPattern(contentIds)) {
            result.addSignal("SEQUENTIAL_PATTERN", null);
        }
        
        // 3. 间隔均匀性检测（疑似自动化脚本）
        List<Long> intervals = getIntervals(recentAccess);
        double stdDev = calculateStdDev(intervals);
        if (stdDev < 500) { // 间隔标准差 < 500ms
            result.addSignal("REGULAR_INTERVALS", stdDev);
        }
        
        // 4. 跨学科无差别访问（正常人不会连续看所有学科）
        long distinctSubjects = recentAccess.stream()
            .map(a -> extractSubject(a.getContentId()))
            .distinct()
            .count();
        if (distinctSubjects > 5) {
            result.addSignal("SUBJECT_SPRAY", distinctSubjects);
        }
        
        // 5. 设备-账号不匹配
        long accountsOnDevice = auditRepo
            .countDistinctUsersByDevice(deviceId, windowStart);
        if (accountsOnDevice > 2) {
            result.addSignal("MULTI_ACCOUNT_DEVICE", accountsOnDevice);
        }
        
        return result;
    }
    
    /**
     * 根据异常等级采取自动措施
     */
    public void handleAnomaly(AnomalyResult result, Long userId, String deviceId) {
        int score = result.calculateRiskScore();
        
        if (score >= 80) {
            // 高风险：临时封禁 + 人工审核
            accountService.temporaryBan(userId, 24, "SUSPECTED_CONTENT_CRAWLING");
            alertService.notifySecurity(userId, deviceId, result);
        } else if (score >= 50) {
            // 中风险：降速 + 验证码
            rateLimitService.addConstraint(userId, "captcha_required", Duration.ofHours(1));
            rateLimitService.throttle(userId, 0.5); // 减半限流
        } else if (score >= 30) {
            // 低风险：加强监控
            monitoringService.flagForReview(userId, deviceId, result);
        }
    }
```

```dart
/// 离线内容保险箱 (Flutter)
/// 使用设备绑定的加密密钥保护离线内容
class OfflineContentVault {
  
  static const _vaultDbName = 'prime_vault.db';
  static const _maxOfflineDays = 7; // 最大离线天数
  
  late Database _db;
  late SecureKeyStore _keyStore;
  
  /// 初始化保险箱
  Future<void> init() async {
    // 使用 SQLCipher 加密数据库
    _db = await openDatabase(
      _vaultDbName,
      version: 1,
      password: await _getVaultKey(),
      onCreate: (db, version) async {
        await db.execute('''
          CREATE TABLE offline_content (
            content_id TEXT PRIMARY KEY,
            content_type TEXT NOT NULL,
            encrypted_data BLOB NOT NULL,
            key_version INTEGER NOT NULL,
            license_token TEXT NOT NULL,
            valid_until INTEGER NOT NULL,
            last_verified INTEGER NOT NULL,
            access_count INTEGER DEFAULT 0,
            created_at INTEGER NOT NULL
          )
        ''');
      },
    );
    
    _keyStore = SecureKeyStore();
  }
  
  /// 获取保险箱密钥（绑定到设备硬件）
  Future<String> _getVaultKey() async {
    // 从设备安全存储(Keystore/Keychain)获取主密钥
    // 密钥由服务端在设备绑定时下发，存储在设备安全区域
    return await _keyStore.getVaultKey();
  }
  
  /// 存储离线内容
  Future<void> storeOfflineContent(
      String contentId,
      String contentType,
      Uint8List encryptedData,
      int keyVersion,
      String licenseToken,
      DateTime validUntil) async {
    
    await _db.insert('offline_content', {
      'content_id': contentId,
      'content_type': contentType,
      'encrypted_data': encryptedData,
      'key_version': keyVersion,
      'license_token': licenseToken,
      'valid_until': validUntil.millisecondsSinceEpoch,
      'last_verified': DateTime.now().millisecondsSinceEpoch,
      'access_count': 0,
      'created_at': DateTime.now().millisecondsSinceEpoch,
    }, conflictAlgorithm: ConflictAlgorithm.replace);
  }
  
  /// 读取离线内容（含有效性验证）
  Future<OfflineContentResult?> readOfflineContent(String contentId) async {
    final rows = await _db.query(
      'offline_content',
      where: 'content_id = ?',
      whereArgs: [contentId],
    );
    
    if (rows.isEmpty) return null;
    
    final row = rows.first;
    final validUntil = DateTime.fromMillisecondsSinceEpoch(row['valid_until'] as int);
    final lastVerified = DateTime.fromMillisecondsSinceEpoch(row['last_verified'] as int);
    
    // 1. 检查有效期
    if (DateTime.now().isAfter(validUntil)) {
      // 内容已过期，删除
      await _db.delete('offline_content', 
        where: 'content_id = ?', whereArgs: [contentId]);
      return OfflineContentResult.expired();
    }
    
    // 2. 检查离线天数
    final offlineDays = DateTime.now().difference(lastVerified).inDays;
    if (offlineDays > _maxOfflineDays) {
      // 超过最大离线天数，需要联网验证
      return OfflineContentResult.needVerification();
    }
    
    // 3. 更新访问计数
    await _db.rawUpdate(
      'UPDATE offline_content SET access_count = access_count + 1 WHERE content_id = ?',
      [contentId],
    );
    
    return OfflineContentResult.success(
      encryptedData: row['encrypted_data'] as Uint8List,
      keyVersion: row['key_version'] as int,
    );
  }
  
  /// 联网同步时验证所有离线内容
  Future<void> verifyOnline() async {
    final rows = await _db.query('offline_content');
    
    for (final row in rows) {
      try {
        // 批量验证许可证有效性
        final valid = await _apiService.verifyLicense(
          row['license_token'] as String,
          row['content_id'] as String,
        );
        
        if (!valid) {
          // 许可证无效，删除离线内容
          await _db.delete('offline_content',
            where: 'content_id = ?', 
            whereArgs: [row['content_id']]);
        } else {
          // 更新验证时间
          await _db.update(
            'offline_content',
            {'last_verified': DateTime.now().millisecondsSinceEpoch},
            where: 'content_id = ?',
            whereArgs: [row['content_id']],
          );
        }
      } catch (e) {
        // 验证失败，保留内容（下次再验证）
      }
    }
  }
}
```

```dart
        _showGenericError(context, error);
    }
  }
  
  /// 自动续期许可证
  static Future<void> _autoRenewLicense(
      BuildContext context, ContentError error) async {
    // 1. 检查网络
    if (!await NetworkChecker.isOnline()) {
      _showOfflineExpiredDialog(context);
      return;
    }
    
    // 2. 静默续期
    try {
      final newLicense = await LicenseService.renew(
        error.contentId,
        error.deviceId,
      );
      // 续期成功，自动重试内容加载
      if (context.mounted) {
        _retryContentLoad(context, newLicense);
      }
    } catch (e) {
      // 续期失败，引导用户操作
      if (context.mounted) {
        _showRenewFailedDialog(context, e);
      }
    }
  }
}
```
