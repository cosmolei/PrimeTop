# 服务端-学生学习数据时效性治理与画像新鲜度保障引擎-详细设计

## 1. 概述

### 1.1 功能定位

学生学习数据时效性治理与画像新鲜度保障引擎（Learning Data Temporal Governance Engine，简称 **TGE**）是 PrimeTop 平台数据基础设施的核心中间件，负责管理所有学习证据的时间维度属性，确保下游分析模块（知识追踪、能力画像、个性化推荐、学情报告等）基于新鲜、准确、时效合理的数据进行决策。

### 1.2 问题背景

PrimeTop 平台中，学生的每一次答题、每一次 AI 对话、每一段学习视频观看都是一条"学习证据"。随着证据不断积累，出现以下问题：

| 问题 | 表现 | 影响 |
| --- | --- | --- |
| 证据老化 | 三个月前的答题数据是否仍能代表学生当前水平？ | 知识掌握度计算偏高/偏低 |
| 冷热不均 | 高频学科数据新鲜，低频学科数据陈旧 | 跨学科能力评估失衡 |
| 过期干扰 | 学生已掌握的知识反复出现旧错误记录 | 推荐系统重复推送已会内容 |
| 遗忘未建模 | 缺乏与遗忘曲线的联动 | 复习提醒时机不准确 |
| 画像置信盲区 | 下游模块不知道数据是否"可信" | 基于低置信数据做错误决策 |
| 学段切换断档 | 升年级后旧数据参考价值骤降 | 新学期推荐混乱 |

### 1.3 设计目标

1. **建立学习证据时间衰减模型**：为不同类型的证据设定合理的"保质期"和衰减曲线。
2. **提供画像置信度评分**：让下游模块知道当前画像数据有多大参考价值。
3. **自动触发刷新机制**：当数据陈旧到影响决策时，主动触发重新评估。
4. **遗忘曲线集成**：将艾宾浩斯遗忘曲线与实际表现数据融合，输出动态掌握度。
5. **跨模块时效一致性**：确保所有消费学习数据的模块使用统一的时效标准。
6. **历史快照与趋势**：支持"时间机器"查询，还原任意时间点的画像状态。

### 1.4 适用范围

| 方向 | 说明 |
| --- | --- |
| 目标读者 | 服务端工程师、数据工程师、AI 工程师 |
| 核心消费者 | 知识追踪引擎、推荐系统、学情分析、错题服务、学习规划 |
| 部署形态 | 独立微服务 + 定时批处理任务 |
| 技术栈 | Java 17 / Spring Boot 3 / Redis / PostgreSQL / ClickHouse |

## 2. 核心概念与领域模型

### 2.1 关键概念定义

| 概念 | 英文 | 定义 |
| --- | --- | --- |
| 学习证据 | Learning Evidence | 学生产生的任意一条可量化学习行为数据（答题、观看视频、AI对话等） |

### 2.3 衰减函数数学定义

#### 2.3.1 指数衰减（默认）

$$
w(t) = w_{base} \times e^{-\lambda t}
$$

其中：
- $w_{base}$ = 证据基础权重
- $\lambda = \frac{\ln(2)}{T_{half}}$，$T_{half}$ 为半衰期（天）
- $t$ = 距证据产生时的天数

当 $w(t) < w_{min}$ 时，证据标记为 **expired**（过期）。

#### 2.3.2 分段阶梯衰减

$$
w(t) = \begin{cases}
w_{base} & 0 \le t < T_1 \\
w_{base} \times 0.7 & T_1 \le t < T_2 \\
w_{base} \times 0.4 & T_2 \le t < T_3 \\
w_{base} \times 0.1 & t \ge T_3
\end{cases}
$$

适用于诊断测试等需要明确"阶段"的证据类型。

#### 2.3.3 自定义衰减（遗忘曲线融合）

结合艾宾浩斯遗忘曲线：

$$
R(t) = e^{-t/S}
$$

其中 $S$ 为记忆强度，由学生个体差异和历史复习表现动态调整。

融合公式：

$$
w(t) = w_{base} \times \left( \alpha \cdot e^{-\lambda t} + (1-\alpha) \cdot R(t) \right)
$$

$\alpha$ 为融合系数（默认 0.6），可通过 A/B 测试调优。

## 4. 核心算法设计

### 4.1 时间衰减权重计算

```java
/**
 * 时间衰减权重计算器
 */
@Component
public class TimeDecayCalculator {

    /**
     * 计算单条证据的当前有效权重
     *
     * @param evidence    证据记录
     * @param config      衰减配置
     * @param currentTime 当前时间
     * @return 当前有效权重（0.0 ~ base_weight）
     */
    public BigDecimal calculateCurrentWeight(
            EvidenceRecord evidence,
            DecayConfig config,
            Instant currentTime) {
        
        long daysElapsed = Duration.between(
            evidence.getOccurredAt(), 
            currentTime
        ).toDays();
        
        if (daysElapsed <= 0) {
            return BigDecimal.valueOf(config.getBaseWeight());
        }
        
        double currentWeight = switch (config.getDecayFunction()) {
            case "exponential" -> calculateExponentialDecay(
                config.getBaseWeight(),
                config.getHalfLifeDays(),
                daysElapsed
            );
            case "step" -> calculateStepDecay(
                config.getBaseWeight(),
                daysElapsed
            );
            case "custom" -> calculateCustomDecayWithForgetting(
                evidence,
                config,
                daysElapsed
            );
            default -> calculateExponentialDecay(
                config.getBaseWeight(),
                config.getHalfLifeDays(),
                daysElapsed
            );
        };
        
        // 不低于最低有效权重
        double minWeight = config.getMinEffectiveWeight();
        return BigDecimal.valueOf(Math.max(currentWeight, minWeight));
    }
    
    /**
     * 指数衰减
     */
    private double calculateExponentialDecay(
            double baseWeight,
            double halfLifeDays,
            long daysElapsed) {
        double lambda = Math.log(2) / halfLifeDays;
        return baseWeight * Math.exp(-lambda * daysElapsed);
    }
    
    /**
     * 分段阶梯衰减
     */
    private double calculateStepDecay(double baseWeight, long daysElapsed) {
        if (daysElapsed < 14) return baseWeight;                    // 2周内：100%
        else if (daysElapsed < 30) return baseWeight * 0.7;         // 2-4周：70%
        else if (daysElapsed < 60) return baseWeight * 0.4;         // 1-2月：40%
        else if (daysElapsed < 90) return baseWeight * 0.15;        // 2-3月：15%
        else return baseWeight * 0.05;                               // 3月+：5%
    }
    
    /**
     * 自定义衰减：遗忘曲线融合
     */
    private double calculateCustomDecayWithForgetting(
            EvidenceRecord evidence,
            DecayConfig config,
            long daysElapsed) {
        
        // 获取该学生的记忆强度参数（个性化）
        double memoryStrength = evidence.getMemoryStrength(); // S 值，默认 5.0
        double alpha = config.getAlpha() != null ? config.getAlpha() : 0.6;
        
        // 指数衰减分量
        double lambda = Math.log(2) / config.getHalfLifeDays();
        double exponentialComponent = Math.exp(-lambda * daysElapsed);
        
        // 遗忘曲线分量
        double forgettingComponent = Math.exp(-(double) daysElapsed / memoryStrength);
        
        // 融合
        return config.getBaseWeight() * (alpha * exponentialComponent + (1 - alpha) * forgettingComponent);
    }
    
    /**
     * 判断证据是否已过期
     */
    public boolean isExpired(EvidenceRecord evidence, DecayConfig config, Instant currentTime) {
        BigDecimal currentWeight = calculateCurrentWeight(evidence, config, currentTime);
        // 当权重衰减到接近最小值，且超过半衰期的3倍时间
        long daysElapsed = Duration.between(evidence.getOccurredAt(), currentTime).toDays();
        return currentWeight.doubleValue() <= config.getMinEffectiveWeight() 
            || daysElapsed > config.getHalfLifeDays() * 4;
    }
}
```

### 4.2 知识点时效评分算法

```java
/**
 * 知识点时效评分计算器
 * 输出：freshness_score (0~100), confidence_level (0.0~1.0)
 */
@Component
public class FreshnessScorer {

    /**
     * 计算某学生某知识点的时效评分
     */
    public FreshnessResult calculate(
            long studentId,
            long knowledgePointId,
            List<EvidenceRecord> activeEvidences,
            Instant currentTime) {
        
        if (activeEvidences.isEmpty()) {
            return FreshnessResult.empty();
        }
        
        // ===== 1. 新鲜度评分 (Freshness Score: 0~100) =====
        double freshnessScore = calculateFreshnessScore(activeEvidences, currentTime);
        
        // ===== 2. 置信度 (Confidence Level: 0.0~1.0) =====
        double confidenceLevel = calculateConfidenceLevel(activeEvidences, currentTime);
        
        // ===== 3. 加权掌握度（时效调整后）=====
        double adjustedMastery = calculateAdjustedMastery(activeEvidences);
        
        // ===== 4. 遗忘曲线保持率 =====
        double forgettingRetention = calculateForgettingRetention(activeEvidences, currentTime);
        
        // ===== 5. 过期等级 =====
        String staleLevel = determineStaleLevel(freshnessScore, confidenceLevel);
        
        // ===== 6. 是否需要刷新 =====
        boolean needsRefresh = staleLevel.equals("STALE") || staleLevel.equals("CRITICAL");
        String refreshReason = determineRefreshReason(freshnessScore, confidenceLevel, activeEvidences);
        
        return FreshnessResult.builder()
            .freshnessScore(freshnessScore)
            .confidenceLevel(confidenceLevel)
            .adjustedMastery(adjustedMastery)
            .forgettingRetention(forgettingRetention)
            .staleLevel(staleLevel)
            .needsRefresh(needsRefresh)
            .refreshReason(refreshReason)
            .activeEvidenceCount(activeEvidences.size())
            .latestEvidenceTime(findLatestTime(activeEvidences))
            .build();
    }
    
    /**
     * 新鲜度评分 = Σ(证据当前权重 × 时间接近因子) / Σ(证据基础权重) × 100
     * 
     * 时间接近因子：越近的证据额外加成
     */
    private double calculateFreshnessScore(List<EvidenceRecord> evidences, Instant now) {
        double weightedSum = 0;
        double maxPossibleSum = 0;
        
        for (EvidenceRecord ev : evidences) {
            long daysElapsed = Duration.between(ev.getOccurredAt(), now).toDays();
            double recencyBoost = Math.exp(-daysElapsed / 30.0); // 30天衰减窗
            
            weightedSum += ev.getCurrentWeight() * (0.7 + 0.3 * recencyBoost);
            maxPossibleSum += ev.getBaseWeight();
        }
        
        if (maxPossibleSum == 0) return 0;
        
        double ratio = weightedSum / maxPossibleSum;
        return Math.round(ratio * 100 * 10) / 10.0; // 保留一位小数
    }
    
    /**
     * 置信度计算
     * 综合考虑：证据数量充足度 × 证据类型多样性 × 时效性 × 一致性
     */
    private double calculateConfidenceLevel(List<EvidenceRecord> evidences, Instant now) {
        // 因子1：证据数量充足度（ sigmoid 函数，5条证据达到0.5，20条接近1.0）
        int count = evidences.size();
        double sufficiency = 1.0 / (1.0 + Math.exp(-(count - 5) / 3.0));
        
        // 因子2：证据类型多样性（有多少种不同类型的证据）
        long typeDiversity = evidences.stream()
            .map(EvidenceRecord::getEvidenceType)
            .distinct()
            .count();
        double diversity = Math.min(typeDiversity / 4.0, 1.0); // 4种类型即满分
        
        // 因子3：时效性（平均当前权重 / 平均基础权重）
        double avgCurrentWeight = evidences.stream()
            .mapToDouble(e -> e.getCurrentWeight())
            .average().orElse(0);
        double avgBaseWeight = evidences.stream()
            .mapToDouble(e -> e.getBaseWeight())
            .average().orElse(1);
        double timeliness = avgBaseWeight > 0 ? avgCurrentWeight / avgBaseWeight : 0;
        
        // 因子4：一致性（证据结论是否一致，如都是"掌握"或都是"未掌握"）
        // 如果正负证据比例接近 50:50，一致性低
        double positiveRatio = evidences.stream()
            .filter(e -> e.getCurrentWeight() > 0.5)
            .count() / (double) count;
        double consistency = 1.0 - 2.0 * Math.abs(0.5 - positiveRatio);
        consistency = Math.max(consistency, 0.3); // 最低0.3
        
        // 加权融合
        double confidence = 0.30 * sufficiency 
                          + 0.25 * diversity 
                          + 0.30 * timeliness 
                          + 0.15 * consistency;
        
        return Math.round(confidence * 1000) / 1000.0; // 保留3位小数
    }
    
    /**
     * 时效调整后的掌握度
     * 不是简单的正确率，而是用时间衰减权重加权后的掌握度
     */
    private double calculateAdjustedMastery(List<EvidenceRecord> evidences) {
        double positiveWeight = 0;
        double totalWeight = 0;
        
        for (EvidenceRecord ev : evidences) {
            double w = ev.getCurrentWeight();
            totalWeight += w;
            // 正面证据（答题正确、完成练习、订正成功等）
            if (isPositiveEvidence(ev.getEvidenceType())) {
                positiveWeight += w;
            }
        }
        
        return totalWeight > 0 ? positiveWeight / totalWeight : 0;
    }
    
    /**
     * 遗忘曲线保持率（基于最近一次学习的记忆强度）
     */
    private double calculateForgettingRetention(List<EvidenceRecord> evidences, Instant now) {
        // 取最近一条证据的 occurredAt 作为"最后学习时间"
        Instant lastLearnTime = findLatestTime(evidences);
        long daysSinceLast = Duration.between(lastLearnTime, now).toDays();
        
        // 估算记忆强度（基于复习次数）
        int reviewCount = (int) evidences.stream()
            .filter(e -> e.getEvidenceType().equals("REVIEW_DONE") 
                       || e.getEvidenceType().equals("ERROR_CORRECTED"))
            .count();
        
        // 记忆强度 S = 基础值 × (1 + 复习次数的log)
        double S = 3.0 * (1.0 + Math.log10(reviewCount + 1));
        S = Math.min(S, 30.0); // 上限30天
        
        return Math.exp(-(double) daysSinceLast / S);
    }
    
    private String determineStaleLevel(double freshness, double confidence) {
        double combined = freshness / 100.0 * 0.6 + confidence * 0.4;
        
        if (combined >= 0.7) return "FRESH";
        if (combined >= 0.4) return "AGING";
        if (combined >= 0.15) return "STALE";
        return "CRITICAL";
    }
    
    private String determineRefreshReason(
            double freshness, double confidence, 
            List<EvidenceRecord> evidences) {
        if (evidences.size() < 3) {
            return "INSUFFICIENT_DATA";
        }
        if (freshness < 30) {
            return "STALE_DATA";
        }
        if (confidence < 0.3) {
            return "LOW_CONFIDENCE";
        }
        return null;
    }
    
    private boolean isPositiveEvidence(String type) {
        return Set.of(
            "ANSWER_CORRECT", "VIDEO_WATCH_COMPLETE", "EXERCISE_COMPLETED",
            "REVIEW_DONE", "ERROR_CORRECTED", "MOCK_EXAM"
        ).contains(type);
    }
    
    private Instant findLatestTime(List<EvidenceRecord> evidences) {
        return evidences.stream()
            .map(EvidenceRecord::getOccurredAt)
            .max(Instant::compareTo)
            .orElse(Instant.now());
    }
}
```

```java
/**
 * 学科级画像时效聚合器
 */
@Component
public class SubjectProfileAggregator {

    /**
     * 从知识点快照聚合到学科级画像
     */
    public SubjectProfile aggregate(
            long studentId,
            String subjectCode,
            String gradeCode,
            List<KnowledgePointSnapshot> kpSnapshots,
            Instant lastActivityTime) {
        
        int totalKp = kpSnapshots.size();
        int activeKp = 0;
        int staleKp = 0;
        int criticalKp = 0;
        
        double freshnessSum = 0;
        double confidenceSum = 0;
        
        for (KnowledgePointSnapshot kp : kpSnapshots) {
            freshnessSum += kp.getFreshnessScore();
            confidenceSum += kp.getConfidenceLevel();
            
            switch (kp.getStaleLevel()) {
                case "FRESH", "AGING" -> activeKp++;
                case "STALE" -> staleKp++;
                case "CRITICAL" -> criticalKp++;
            }
        }
        
        double overallFreshness = totalKp > 0 ? freshnessSum / totalKp : 0;
        double overallConfidence = totalKp > 0 ? confidenceSum / totalKp : 0;
        
        // 计算沉寂天数
        long dormancyDays = lastActivityTime != null
            ? Duration.between(lastActivityTime, Instant.now()).toDays()
            : -1;
        
        // 确定学科画像状态
        String profileStatus = determineSubjectStatus(
            overallFreshness, overallConfidence, totalKp, 
            activeKp, dormancyDays
        );
        
        return SubjectProfile.builder()
            .studentId(studentId)
            .subjectCode(subjectCode)
            .gradeCode(gradeCode)
            .overallFreshness(Math.round(overallFreshness * 10) / 10.0)
            .overallConfidence(Math.round(overallConfidence * 1000) / 1000.0)
            .totalKpCount(totalKp)
            .activeKpCount(activeKp)
            .staleKpCount(staleKp)
            .criticalKpCount(criticalKp)
            .lastActivityAt(lastActivityTime)
            .dormancyDays((int) Math.max(dormancyDays, 0))
            .profileStatus(profileStatus)
            .build();
    }
    
    private String determineSubjectStatus(
            double freshness, double confidence, int totalKp,
            int activeKp, long dormancyDays) {
        
        if (totalKp == 0) return "EMPTY";
        if (dormancyDays > 30) return "DORMANT";
        
        double coverage = (double) activeKp / totalKp;
        double combined = freshness / 100.0 * 0.4 + confidence * 0.3 + coverage * 0.3;
        
        if (combined >= 0.6) return "ACTIVE";
        if (combined >= 0.3) return "STALE";
        return "DORMANT";
    }
}
```

## 6. 核心业务流程

### 6.1 证据注册与实时计算流程

```
┌─────────────┐    ┌──────────────┐    ┌─────────────────┐    ┌──────────────┐
│ 业务模块      │    │ TGE API      │    │ 时效计算引擎     │    │ 存储         │
│(答题/练习等) │───▶│ /evidence    │───▶│ (DecayCalc)     │───▶│              │
└─────────────┘    └──────────────┘    └─────────────────┘    │              │
                           │                    │              │  PostgreSQL  │
                           │                    ▼              │  (证据表)    │
                           │           ┌────────────────┐      │              │
                           │           │ 初始权重计算    │      │  Redis       │
                           │           │ w = baseWeight │      │  (快照缓存)  │
                           │           └────────────────┘      │              │
                           │                    │              └──────────────┘
                           │                    ▼
                           │           ┌────────────────┐
                           │           │ 更新Redis      │
                           │           │ 知识点快照     │
                           │           │ (增量更新)     │
                           │           └────────────────┘
                           │                    │
                           │                    ▼
                           │           ┌────────────────────────┐
                           └──────────▶│ 异步事件发布            │
                                       │ EvidenceRegistered     │
                                       │ → 推荐系统/分析模块     │
                                       └────────────────────────┘
```

**关键步骤说明：**

1. **证据接收**：业务模块（答题服务、练习服务、AI对话等）通过 API 或消息队列异步推送证据到 TGE。
2. **配置查询**：根据证据类型 + 学生年级 + 学科，查询适用的衰减配置（优先级：学生级 > 年级+学科级 > 全局默认）。
3. **初始权重计算**：根据配置设置 `base_weight`，`current_weight` 初始等于 `base_weight`。
4. **持久化**：写入 `tge_evidence_registry` 表。
5. **缓存增量更新**：更新 Redis 中该知识点的快照缓存（重新计算 freshness_score 和 confidence_level）。
6. **事件发布**：发布 `EvidenceRegisteredEvent`，通知知识追踪引擎、推荐系统等下游模块。

### 6.2 定时批量重算流程

```

                    │           每日凌晨 02:00 执行              │
                    └──────────────────────────────────────────┘
                                      │
                                      ▼
                    ┌────────────────────────────────┐
                    │ Step 1: 扫描所有 ACTIVE 证据    │
                    │ 按学生分组                       │
                    └────────────────────────────────┘
                                      │
```

```java
@Service
@Slf4j
public class EvidenceService {

    @Autowired
    private EvidenceRepository evidenceRepo;
    @Autowired
    private DecayConfigService configService;
    @Autowired
    private TimeDecayCalculator decayCalculator;
    @Autowired
    private FreshnessScorer freshnessScorer;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private KafkaTemplate<String, String> kafkaTemplate;

    @Value("${tge.kafka.topic.evidence}")
    private String evidenceTopic;

    /**
     * 注册单条证据
     */
    @Transactional
    public EvidenceRecord register(EvidenceRegisterRequest request) {
        
        // 1. 查询适用的衰减配置
        DecayConfig config = configService.getConfig(
            request.getEvidenceType(),
            request.getStudentId(),
            request.getSubjectCode()
        );
        
        // 2. 构建证据记录
        EvidenceRecord record = EvidenceRecord.builder()
            .evidenceId(request.getEvidenceId())
            .studentId(request.getStudentId())
            .subjectCode(request.getSubjectCode())
            .knowledgePointId(request.getKnowledgePointId())
            .evidenceType(request.getEvidenceType())
            .evidenceSource(request.getEvidenceSource())
            .occurredAt(request.getOccurredAt())
            .recordedAt(Instant.now())
            .baseWeight(config.getBaseWeight())
            .currentWeight(config.getBaseWeight()) // 初始等于 base
            .decayConfig(JsonUtils.toJson(config))
            .status("ACTIVE")
            .refTable(request.getRefTable())
            .refId(request.getRefId())
            .metadata(request.getMetadata())
            .build();
        
        // 3. 计算过期时间预测
        Instant expiredAt = decayCalculator.predictExpiredTime(record, config);
        record.setExpiredAt(expiredAt);
        
        // 4. 持久化
        evidenceRepo.save(record);
        
        // 5. 增量更新 Redis 中的知识点快照
        updateKpSnapshotInCache(record);
        
        // 6. 发布事件
        publishEvidenceEvent(record);
        
        log.debug("Evidence registered: student={}, kp={}, type={}", 
            request.getStudentId(), 
            request.getKnowledgePointId(),
            request.getEvidenceType());
        
        return record;
    }

    /**
     * 批量注册
     */
    @Transactional
    public BatchResult registerBatch(List<EvidenceRegisterRequest> requests) {
        int success = 0;
        int failed = 0;
        List<String> errors = new ArrayList<>();
        
        for (EvidenceRegisterRequest req : requests) {
            try {
                register(req);
                success++;
            } catch (Exception e) {
                failed++;
                errors.add(String.format("Evidence %s: %s", req.getEvidenceId(), e.getMessage()));
            }
        }
        
        return BatchResult.builder()
            .total(requests.size())
            .successCount(success)
            .failedCount(failed)
            .errors(errors)
            .build();
    }

    /**
     * 增量更新缓存中的知识点快照
     */
    private void updateKpSnapshotInCache(EvidenceRecord newEvidence) {
        String cacheKey = String.format("TGE:SNAPSHOT:%d:KP:%d", 
            newEvidence.getStudentId(), 
            newEvidence.getKnowledgePointId());
        
        try {
            // 获取当前缓存中的快照
            String cached = redisTemplate.opsForValue().get(cacheKey);
            KnowledgePointSnapshot snapshot;
            
            if (cached != null) {
                snapshot = JsonUtils.fromJson(cached, KnowledgePointSnapshot.class);
                // 增量更新
                snapshot.setTotalEvidenceCount(snapshot.getTotalEvidenceCount() + 1);
                if ("ACTIVE".equals(newEvidence.getStatus())) {
                    snapshot.setActiveEvidenceCount(snapshot.getActiveEvidenceCount() + 1);
                }
                snapshot.setLatestEvidenceAt(newEvidence.getOccurredAt());
            } else {
                // 缓存不存在，标记需要全量重算
                snapshot = KnowledgePointSnapshot.partial(newEvidence);
            }
            
            // 存回缓存
            redisTemplate.opsForValue().set(cacheKey, JsonUtils.toJson(snapshot), 
                Duration.ofHours(6));
            
        } catch (Exception e) {
            log.warn("Failed to update cache for kp snapshot: {}", e.getMessage());
            // 缓存失败不影响主流程，定时任务会修复
        }
    }

    private void publishEvidenceEvent(EvidenceRecord record) {
        try {
            String message = JsonUtils.toJson(Map.of(
                "event_type", "EVIDENCE_REGISTERED",
                "evidence_id", record.getEvidenceId(),
                "student_id", record.getStudentId(),
                "knowledge_point_id", record.getKnowledgePointId(),
                "evidence_type", record.getEvidenceType(),
                "timestamp", Instant.now().toString()
            ));
            kafkaTemplate.send(evidenceTopic, record.getEvidenceId(), message);
        } catch (Exception e) {
            log.error("Failed to publish evidence event: {}", e.getMessage());
        }
    }
}

@Component
@Slf4j
public class FreshnessBatchJob {

    @Autowired
    private EvidenceRepository evidenceRepo;
    @Autowired
    private TimeDecayCalculator decayCalculator;
    @Autowired
    private FreshnessScorer freshnessScorer;
    @Autowired
    private SubjectProfileAggregator subjectAggregator;
    @Autowired
    private SnapshotRepository snapshotRepo;
    @Autowired
    private SubjectProfileRepository subjectProfileRepo;
    @Autowired
    private RefreshEventRepository refreshEventRepo;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private KafkaTemplate<String, String> kafkaTemplate;

    /**
     * 每日凌晨 2 点执行全量重算
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void dailyRecalculation() {
        log.info("TGE daily recalculation started at {}", Instant.now());
        
        String batchDate = LocalDate.now().toString();
        setBatchProgress(batchDate, "STARTED", 0, 0);
        
        Instant calcTime = Instant.now();
        
        // Step 1: 批量重算所有 ACTIVE 证据的 current_weight
        int processedEvidence = recalculateAllEvidenceWeights(calcTime);
        setBatchProgress(batchDate, "EVIDENCE_DONE", processedEvidence, 0);
        
        // Step 2: 标记过期证据
        int expiredCount = markExpiredEvidence(calcTime);
        log.info("Marked {} evidences as expired", expiredCount);
        
        // Step 3: 按学生×知识点聚合重算
        int processedSnapshots = recalculateKpSnapshots(calcTime);
        setBatchProgress(batchDate, "SNAPSHOT_DONE", processedEvidence, processedSnapshots);
        
        // Step 4: 聚合学科级画像
        int processedSubjects = recalculateSubjectProfiles();
        
        // Step 5: 触发刷新事件
        int refreshTriggered = triggerRefreshEvents();
        
        // Step 6: 更新缓存
        updateRedisCache();
        
        setBatchProgress(batchDate, "COMPLETED", processedEvidence, processedSnapshots);
        log.info("TGE daily recalculation completed: evidence={}, snapshots={}, subjects={}, refreshes={}",
            processedEvidence, processedSnapshots, processedSubjects, refreshTriggered);
    }

    /**
     * 重算所有 ACTIVE 证据的当前权重
     */
    private int recalculateAllEvidenceWeights(Instant calcTime) {
        int pageSize = 5000;
        int processed = 0;
        long lastId = 0;
        
        while (true) {
            List<EvidenceRecord> batch = evidenceRepo.findActiveBatch(lastId, pageSize);
            if (batch.isEmpty()) break;
            
            for (EvidenceRecord ev : batch) {
                DecayConfig config = JsonUtils.fromJson(ev.getDecayConfig(), DecayConfig.class);
                BigDecimal newWeight = decayCalculator.calculateCurrentWeight(ev, config, calcTime);
                ev.setCurrentWeight(newWeight);
                
                // 检查是否过期
                if (decayCalculator.isExpired(ev, config, calcTime)) {
                    ev.setStatus("EXPIRED");
                    ev.setExpiredAt(calcTime);
                }
            }
            
            evidenceRepo.batchUpdateWeights(batch);
            processed += batch.size();
            lastId = batch.get(batch.size() - 1).getId();
        }
        
        return processed;
    }

    /**
     * 按学生×知识点聚合重算快照
     */
    private int recalculateKpSnapshots(Instant calcTime) {
        // 获取所有有 ACTIVE 证据的学生×知识点组合
        List<StudentKpPair> pairs = evidenceRepo.findDistinctStudentKpPairs();
        int processed = 0;
        
        for (StudentKpPair pair : pairs) {
            List<EvidenceRecord> activeEvidences = evidenceRepo
                .findActiveByStudentAndKp(pair.getStudentId(), pair.getKnowledgePointId());
            
            FreshnessResult result = freshnessScorer.calculate(
                pair.getStudentId(),
                pair.getKnowledgePointId(),
                activeEvidences,
                calcTime
            );
            
            // 构建快照
            KnowledgePointSnapshot snapshot = KnowledgePointSnapshot.builder()
                .studentId(pair.getStudentId())
                .knowledgePointId(pair.getKnowledgePointId())
                .subjectCode(pair.getSubjectCode())
                .totalEvidenceCount(activeEvidences.size())
                .activeEvidenceCount((int) activeEvidences.stream()
                    .filter(e -> "ACTIVE".equals(e.getStatus())).count())
                .weightedMasteryAdj(BigDecimal.valueOf(result.getAdjustedMastery()))
                .freshnessScore(BigDecimal.valueOf(result.getFreshnessScore()))
                .confidenceLevel(BigDecimal.valueOf(result.getConfidenceLevel()))
                .latestEvidenceAt(result.getLatestEvidenceTime())
                .staleLevel(result.getStaleLevel())
                .needsRefresh(result.isNeedsRefresh())
                .refreshReason(result.getRefreshReason())
                .forgettingCurveR(BigDecimal.valueOf(result.getForgettingRetention()))
                .nextReviewDueAt(calculateNextReviewTime(result))
                .calculatedAt(calcTime)
                .snapshotVersion(getNextSnapshotVersion(pair.getStudentId(), pair.getKnowledgePointId()))
                .build();
            
            snapshotRepo.save(snapshot);
            processed++;
        }
        
        return processed;
    }

    private Instant calculateNextReviewTime(FreshnessResult result) {
        // 基于遗忘曲线保持率计算建议复习时间
        // R(t) = 0.3 时建议复习（保持率降到30%）
        if (result.getForgettingRetention() < 0.3) {
            return Instant.now(); // 立即需要
        }
        // 否则推算到 R 降到 0.3 的时间
        double daysUntil30Percent = Math.log(0.3) / Math.log(result.getForgettingRetention()) * 7; // 粗略估算
        return Instant.now().plus(Duration.ofDays(Math.max(1, (long) daysUntil30Percent)));
    }
}
```

```java
    public DecayConfig getConfig(EvidenceType evidenceType, Long studentId, String subjectCode) {
        
        // 优先级1: 学生+知识点级别覆盖
        // 优先级2: 学生级别覆盖
        // 优先级3: 年级+学科级别覆盖
        // 优先级4: 全局默认
        
        // 实际实现中会查询数据库的 override 表
        DecayConfigOverride override = overrideRepo.findBestMatch(
            studentId, subjectCode, evidenceType.name()
        );
        
        if (override != null) {
            return mergeWithDefault(override, evidenceType);
        }
        
        return DEFAULT_DECAY_CONFIGS.get(evidenceType);
    }
    
    /**
     * 合并覆盖配置与默认配置
     */
    private DecayConfig mergeWithDefault(DecayConfigOverride override, EvidenceType type) {
        DecayConfig defaults = DEFAULT_DECAY_CONFIGS.get(type);
        return DecayConfig.builder()
            .evidenceType(type)
            .baseWeight(override.getBaseWeight() != null ? override.getBaseWeight() : defaults.getBaseWeight())
            .halfLifeDays(override.getHalfLifeDays() != null ? override.getHalfLifeDays() : defaults.getHalfLifeDays())
            .minEffectiveWeight(override.getMinEffectiveWeight() != null ? override.getMinEffectiveWeight() : defaults.getMinEffectiveWeight())
            .decayFunction(override.getDecayFunction() != null ? override.getDecayFunction() : defaults.getDecayFunction())
            .alpha(override.getAlpha())
            .priority(override.getPriority() != null ? override.getPriority() : defaults.getPriority())
            .build();
    }
}
```

## 9. 错误处理与降级策略

### 9.1 错误码定义

| 错误码 | HTTP | 说明 | 处理方式 |
| --- | --- | --- | --- |
| TGE_4001 | 400 | 证据类型不支持 | 拒绝并返回支持的类型列表 |
| TGE_4002 | 400 | 证据ID重复 | 幂等处理，返回已有记录 |
| TGE_4003 | 400 | 知识点不存在 | 忽略知识点关联，仅存学科级 |
| TGE_4004 | 400 | 时间戳格式错误 | 拒绝并提示正确格式 |
| TGE_4005 | 400 | 衰减配置格式错误 | 使用默认配置并告警 |
| TGE_4041 | 404 | 学生不存在 | 拒绝写入 |
| TGE_4291 | 429 | 写入频率过高 | 限流，引导使用批量接口 |
| TGE_5001 | 500 | 数据库写入失败 | 重试 + 降级写入Kafka待重放 |
| TGE_5002 | 500 | Redis缓存失败 | 忽略缓存，直接走数据库 |
| TGE_5003 | 500 | Kafka发送失败 | 本地队列重试 |
| TGE_5031 | 503 | 批处理正在进行中 | 返回进度信息，引导稍后重试 |

### 9.2 降级策略

```java
/**
 * TGE 降级处理器
 */
@Component
@Slf4j
public class TgeFallbackHandler {

    /**
     * 证据注册降级：API 失败时走 Kafka 异步重放
     */
    public EvidenceRecord fallbackRegister(EvidenceRegisterRequest request, Throwable cause) {
        log.warn("Evidence register failed, falling back to async. evidence_id={}, error={}", 
            request.getEvidenceId(), cause.getMessage());
        
        // 写入 Kafka 重放队列
        // 如果 Kafka 也不可用，写入本地文件队列
        
        return EvidenceRecord.builder()
            .evidenceId(request.getEvidenceId())
            .status("PENDING_REPLAY")
            .build();
    }

    /**
     * 查询降级：Redis 不可用时直接走数据库
     */
    public KpFreshnessResponse fallbackQuery(KpFreshnessQuery query, Throwable cause) {
        log.warn("Cache miss/unavailable, falling back to DB. student_id={}, error={}", 
            query.getStudentId(), cause.getMessage());
        
        // 直接查数据库（可能较慢）
        // 返回带 freshness_source: "DB_FALLBACK" 标记
        return KpFreshnessResponse.fallbackFromDb(query);
    }

    /**
     * 批处理失败降级：部分成功而非全部回滚
     */
    public BatchResult fallbackBatch(List<EvidenceRegisterRequest> requests, Throwable cause) {
        // 已处理的部分保持，未处理的部分标记 PENDING
        // 发出告警，等待人工或自动重试
        return BatchResult.partialFailure(requests.size(), cause);
    }
}
```

## 10. 性能优化

### 10.1 批处理性能优化

| 策略 | 说明 |
| --- | --- |
| 分页处理 | 每次查询 5000 条证据，避免大事务 |
| 批量更新 | 使用 JDBC batch update 而非逐条 save |
| 并行计算 | 按学生ID分片，多线程并行计算快照 |
| 增量优先 | 非全量重算日仅计算有新证据变化的知识点 |
| 读写分离 | 批处理走只读副本查询，写主库 |

### 10.2 缓存策略

| 数据 | 缓存层 | TTL | 更新策略 |
| --- | --- | --- | --- |
| 知识点快照 | Redis | 6h | 写时增量更新 + 每日全量刷新 |
| 学科画像 | Redis | 12h | 每日全量刷新 |
| 衰减配置 | Redis + 本地 | 24h | 配置变更时主动刷新 |
| 学生概览 | Redis | 2h | 每日刷新 + 关键操作触发 |

### 10.3 预估数据量与容量

| 指标 | 估算（10万 DAU） | 估算（100万 DAU） |
| --- | --- | --- |
| 日新增证据 | ~500万条 | ~5000万条 |
| 存储量/月 | ~15GB | ~150GB |
| 活跃知识点快照 | ~200万 | ~2000万 |
| 每日批处理耗时 | ~30分钟 | ~3小时（需分片并行） |
| Redis缓存容量 | ~2GB | ~20GB |

### 10.4 数据归档策略

```sql

SELECT * FROM tge_evidence_registry
```

- 证据中不得包含原始答题内容（仅存引用ID），避免敏感信息泄露
- 家长查询需经过家长绑定授权校验
- 数据导出时包含时效分析结果，需脱敏处理学生ID

```java
class TimeDecayCalculatorTest {
```
