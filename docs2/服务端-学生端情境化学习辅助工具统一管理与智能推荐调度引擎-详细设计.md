# 服务端-学生端情境化学习辅助工具统一管理与智能推荐调度引擎-详细设计

## 1. 概述

### 1.1 功能定位

本模块是 PrimeTop 平台**学科辅助工具的统一管理后台与智能推荐调度引擎**，负责管理全平台所有学科辅助工具（如计算器、词典、元素周期表、公式表、函数画板等）的生命周期、元数据配置、访问权限、以及基于学生当前学习情境的工具智能推荐。

**核心目标：** 让学生在需要时即刻获得最合适的辅助工具，减少手动查找成本，提升学习效率。

### 1.2 设计动机

当前平台已有零散的学科工具入口（如学科工具箱页面、阅读器内查词功能、化学元素周期表组件等），但存在以下问题：

1. **工具入口分散**：不同工具分布在不同页面，学生难以快速发现所需工具
2. **缺乏情境感知**：工具推荐不区分当前学习场景，高数学生看到字典、英语学生看到计算器
3. **工具配置硬编码**：新增工具需要发版，无法通过后台动态配置上线
4. **使用数据割裂**：各工具使用数据独立存储，无法统一分析工具价值和优化推荐

### 1.3 适用范围

| 维度 | 说明 |
| --- | --- |
| 学段 | 全学段（幼儿启蒙 ~ 高中） |
| 学科 | 数学、物理、化学、生物、语文、英语、历史、地理、政治 |
| 客户端 | Flutter APP（主）、Web 端（后续） |
| 使用场景 | 做题、阅读教材、写作文、背诵、复习、实验模拟 |

### 1.4 名词定义

| 术语 | 含义 |
| --- | --- |
| Tool（工具） | 一个独立可调用的学科辅助功能单元，如"科学计算器"、"英语词典" |
| ToolCategory（工具类别） | 工具的逻辑分组，如"数学工具"、"语言工具" |
| Context（学习情境） | 学生当前的学习状态描述，包含学科、内容类型、页面位置、年级等 |
| ToolRecommendation（工具推荐） | 基于学习情境计算出的工具推荐列表 |
| ToolInvocation（工具调用） | 学生实际打开了某个工具的一次行为记录 |

### 5.2 推荐算法设计

推荐引擎采用**多因子加权评分模型**，对每个候选工具计算推荐分数，取 Top-N 返回。

#### 5.2.1 评分公式

```
Score(tool, context) = w1 * SubjectMatch + w2 * SceneMatch + w3 * GradeMatch
                      + w4 * RuleBonus + w5 * UserHistory + w6 * GlobalPopularity
                      - p1 * UserHidden - p2 * RecentUsed
```

**因子说明：**

| 因子 | 权重 | 计算方式 | 说明 |
| --- | --- | --- | --- |
| `SubjectMatch` | w1=0.30 | 工具applicable_subjects包含当前学科 → 1.0，否则 → 0 | 学科匹配是首要条件 |
| `SceneMatch` | w2=0.25 | 工具applicable_scenes包含当前场景 → 1.0，否则 → 0.3 | 场景匹配权重高 |
| `GradeMatch` | w3=0.15 | min_grade ≤ grade ≤ max_grade → 1.0，否则 → 0 | 年级不匹配直接排除 |
| `RuleBonus` | w4=0.15 | 命中推荐规则的weight_bonus之和(归一化到0~1) | 运营规则加成 |
| `UserHistory` | w5=0.10 | 基于用户历史使用频率的归一化值 | 个性化偏好 |
| `GlobalPopularity` | w6=0.05 | 近7天全平台该工具的使用次数归一化值 | 全局热度 |
| `UserHidden` | p1=1.0 | 用户隐藏了该工具 → 直接排除 | 一票否决 |
| `RecentUsed` | p2=0.05 | 最近5分钟内使用过 → 降权 | 避免重复推荐 |

**默认权重配置：**
```json
{
  "w1_subject": 0.30,
  "w2_scene": 0.25,
  "w3_grade": 0.15,
  "w4_rule": 0.15,
  "w5_history": 0.10,
  "w6_popularity": 0.05,
  "p2_recent_penalty": 0.05
}
```

> 权重参数存储在配置中心，支持动态调整和 A/B 测试。

#### 5.2.2 推荐核心代码

```java
/**
 * 情境化工具推荐引擎 - 核心实现
 */
@Service
@Slf4j
public class ToolRecommendationEngine {

    @Autowired
    private EduToolMapper toolMapper;
    @Autowired
    private EduToolRecommendationRuleMapper ruleMapper;
    @Autowired
    private EduUserToolPreferenceMapper preferenceMapper;
    @Autowired
    private ToolPopularityCache popularityCache;
    @Autowired
    private RecommendationWeightConfig weightConfig;

    /**
     * 获取情境化工具推荐列表
     * @param context 学习上下文
     * @param topN 返回数量
     * @return 推荐工具列表
     */
    public List<ToolRecommendationDTO> recommend(LearningContext context, int topN) {
        // 1. 获取候选工具集（已上线、年级匹配、学科匹配或通用的工具）
        List<EduTool> candidates = getCandidateTools(context);
        if (candidates.isEmpty()) {
            return Collections.emptyList();
        }

        // 2. 获取用户偏好
        Map<String, EduUserToolPreference> userPrefs = getUserPreferences(
            context.getUserId());

        // 3. 获取用户最近使用的工具（用于降权）
        Set<String> recentToolCodes = getRecentToolCodes(context.getUserId(), 5);

        // 4. 加载匹配的推荐规则
        List<EduToolRecommendationRule> rules = getMatchingRules(context);

        // 5. 评分排序
        List<ScoredTool> scoredTools = candidates.stream()
            .map(tool -> scoreTool(tool, context, userPrefs, recentToolCodes, rules))
            .filter(Objects::nonNull)
            .sorted(Comparator.comparingDouble(ScoredTool::getScore).reversed())
            .limit(topN)
            .collect(Collectors.toList());

        // 6. 构建返回DTO
        return scoredTools.stream()
            .map(st -> buildRecommendationDTO(st, context))
            .collect(Collectors.toList());
    }

    /**
     * 获取候选工具集 - 初筛
     */
    private List<EduTool> getCandidateTools(LearningContext context) {
        return toolMapper.selectActiveToolsForUser(
            context.getGrade(),
            context.getSubject(),
            context.getScene().name()
        );
    }

    /**
     * 单个工具评分
     */
    private ScoredTool scoreTool(
            EduTool tool,
            LearningContext context,
            Map<String, EduUserToolPreference> userPrefs,
            Set<String> recentToolCodes,
            List<EduToolRecommendationRule> rules) {

        // 用户隐藏的工具直接排除
        EduUserToolPreference pref = userPrefs.get(tool.getToolCode());
        if (pref != null && pref.getIsHidden() == 1) {
            return null;
        }

        double score = 0.0;

        // (1) 学科匹配
        boolean subjectMatch = tool.getApplicableSubjects()
            .contains(context.getSubject());
        score += weightConfig.getW1Subject() * (subjectMatch ? 1.0 : 0.0);

        // (2) 场景匹配
        boolean sceneMatch = tool.getApplicableScenes()
            .contains(context.getScene().name().toLowerCase());
        score += weightConfig.getW2Scene() * (sceneMatch ? 1.0 : 0.3);

        // (3) 年级匹配（已在SQL层过滤，双重校验）
        // Skip - already filtered

        // (4) 规则加成
        double ruleBonus = calculateRuleBonus(tool, context, rules);
        score += weightConfig.getW4Rule() * ruleBonus;

        // (5) 用户历史偏好
        double historyScore = calculateHistoryScore(tool.getToolCode(), pref);
        score += weightConfig.getW5History() * historyScore;

        // (6) 全局热度
        double popularity = popularityCache.getNormalizedPopularity(
            tool.getToolCode());
        score += weightConfig.getW6Popularity() * popularity;

        // 惩罚：最近使用过
        if (recentToolCodes.contains(tool.getToolCode())) {
            score -= weightConfig.getP2RecentPenalty();
        }

        // 学生主动固定的工具，分数提升
        if (pref != null && pref.getIsPinned() == 1) {
            score += 0.5; // 固定加成，确保排在前面
        }

        return new ScoredTool(tool, score);
    }

    /**
     * 规则加成计算
     */
    private double calculateRuleBonus(
            EduTool tool,
            LearningContext context,
            List<EduToolRecommendationRule> rules) {

        double totalBonus = 0.0;
        for (EduToolRecommendationRule rule : rules) {
            if (!rule.getToolCode().equals(tool.getToolCode())) {
                continue;
            }
            // 检查规则是否匹配当前上下文
            boolean matches = true;
            if (rule.getSubject() != null &&
                !rule.getSubject().equals(context.getSubject())) {
                matches = false;
            }
            if (matches && rule.getScene() != null &&
                !rule.getScene().equals(context.getScene().name())) {
                matches = false;
            }
            if (matches && rule.getKnowledgePointIds() != null &&
                context.getKnowledgePointIds() != null) {
                Set<Long> ruleKpIds = new HashSet<>(
                    rule.getKnowledgePointIds());
                boolean hasIntersection = context.getKnowledgePointIds()
                    .stream()
                    .anyMatch(ruleKpIds::contains);
                if (!hasIntersection) {
                    matches = false;
                }
            }
            if (matches) {
                totalBonus += rule.getWeightBonus() / 100.0;
            }
        }
        // 归一化到 0~1
        return Math.min(totalBonus, 1.0);
    }

    /**
     * 用户历史偏好评分
     */
    private double calculateHistoryScore(
            String toolCode,
            EduUserToolPreference pref) {
        if (pref == null || pref.getUseCount() == 0) {
            return 0.0;
        }
        // 对数缩放，避免高频工具永远霸榜
        return Math.min(1.0, Math.log(1 + pref.getUseCount()) / Math.log(20));
    }
}
```

```dart
class _ToolQuickPanelState extends State<ToolQuickPanel> {
  List<ToolRecommendation> _recommendations = [];
  List<ToolRecommendation> _pinnedTools = [];
  bool _expanded = false;
  Timer? _fetchDebounce;

  @override
  void initState() {
    super.initState();
    _fetchRecommendations();
  }

  @override
  void didUpdateWidget(ToolQuickPanel oldWidget) {
    super.didUpdateWidget(oldWidget);
    // 场景或学科变化时重新获取推荐
    if (oldWidget.subject != widget.subject ||
        oldWidget.scene != widget.scene) {

      });

        topN: 5,
      );
      if (mounted) {
        setState(() {
          _recommendations = response.recommendations;
          _pinnedTools = response.pinnedTools;
        });
      }
    } catch (e) {
      // 静默失败，不影响学习体验
      debugPrint('Tool recommendation fetch failed: $e');
    }

    // 上报调用
    ToolApi.reportInvoke(
      toolCode: tool.toolCode,
      sourceScene: widget.scene.name,
      subjectContext: widget.subject,
      invokeType: tool.rank > 0 ? 'recommend' : 'manual',
      recommendRank: tool.rank,

    context.push(tool.clientRoute, extra: tool.clientParams);
  }

  @override
  Widget build(BuildContext context) {
    final allTools = [..._pinnedTools, ..._recommendations];
    if (allTools.isEmpty) return SizedBox.shrink();

    return AnimatedContainer(
      duration: Duration(milliseconds: 200),
      height: _expanded ? 200 : 56,
      decoration: BoxDecoration(
        color: Theme.of(context).colorScheme.surfaceVariant,
        borderRadius: BorderRadius.vertical(top: Radius.circular(16)),
      ),
      child: Column(
        children: [
          _buildToolRow(allTools.take(_expanded ? 8 : 4).toList()),
          if (!_expanded)
            TextButton(
              onPressed: () => setState(() => _expanded = true),
              child: Text('更多工具'),
            ),
        ],
      ),
    );
  }

  Widget _buildToolRow(List<ToolRecommendation> tools) {
    return SingleChildScrollView(
      scrollDirection: Axis.horizontal,
      padding: EdgeInsets.symmetric(horizontal: 12),
      child: Row(
        children: tools.map((tool) => _buildToolButton(tool)).toList(),
      ),
    );
  }

  Widget _buildToolButton(ToolRecommendation tool) {
    return Tooltip(
      message: tool.reason ?? tool.toolName,
      child: GestureDetector(

                width: 32,
                height: 32,

              Text(
                tool.toolName,
                style: TextStyle(fontSize: 10),
                maxLines: 1,
                overflow: TextOverflow.ellipsis,
              ),
            ],
          ),
        ),
      ),
    );
  }
```

```java
/**
 * 离线工具资源包管理服务
 */
@Service
@Slf4j
public class OfflineToolPackageManager {

    /**
     * 获取用户需要的离线工具包列表
     * 策略：
     * 1. 用户当前学段的所有免费工具 → 自动预下载
     * 2. 高频使用工具 → 优先下载
     * 3. 会员专属工具 → 仅在用户是会员时下载
     * 4. 体积过大的工具包 → 仅WiFi下载
     */
    public List<OfflineToolPackage> getRequiredPackages(
            Long userId, Integer grade, String stage,
            boolean isMember, NetworkType network) {

        List<EduTool> offlineTools = toolMapper.selectOfflineTools(
            grade, stage, ToolStatus.ONLINE);

        return offlineTools.stream()
            .filter(tool -> {
                // 会员校验
                if (tool.getRequiredMemberLevel() > 0 && !isMember) {
                    return false;
                }
                // 大包仅WiFi下载
                if (tool.getOfflineResourceSizeKb() > 50_000 &&
                    network != NetworkType.WIFI) {
                    return false;
                }
                return true;
            })
            .map(this::buildPackageInfo)
            .sorted(Comparator
                .comparingInt(OfflineToolPackage::getPriority))
            .collect(Collectors.toList());
    }

    /**
     * 生成离线工具包下载清单
     */
    private OfflineToolPackage buildPackageInfo(EduTool tool) {
        return OfflineToolPackage.builder()
            .toolCode(tool.getToolCode())
            .version(tool.getVersion())
            .downloadUrl(buildDownloadUrl(tool))
            .sizeKb(tool.getOfflineResourceSizeKb())
            .md5Checksum(tool.getChecksum())
            .priority(calculatePriority(tool))
            .build();
    }
}
```

## 10. 缓存策略

### 10.1 多级缓存设计

```text
请求 → L1 客户端内存缓存(5分钟)
     → L2 客户端磁盘缓存(30分钟)
     → L3 服务端 Redis 缓存(10分钟)
     → L4 MySQL 数据库
```

| 缓存层 | 存储内容 | 过期时间 | 失效策略 |
| --- | --- | --- | --- |
| L1 客户端内存 | 推荐结果列表 | 5分钟 | 场景/学科变化时失效 |
| L2 客户端磁盘 | 工具全量列表 + 图标 | 30分钟 | 版本号变化时失效 |
| L3 Redis | 工具元数据、推荐规则、权重 | 10分钟 | 后台修改时主动删除 |
| L4 MySQL | 源数据 | - | - |

### 10.2 Redis 缓存 Key 设计

```
# 工具元数据缓存
tool:meta:{toolCode} → JSON  TTL=3600s

# 按学科+场景的候选工具列表
tool:candidates:{subject}:{scene} → List<toolCode>  TTL=600s

# 全局热度排行（ZSET）
tool:popularity:daily:{date} → ZSET(toolCode, score)  TTL=86400s

# 推荐规则缓存
tool:rules:{subject}:{scene} → JSON  TTL=600s

# 权重配置
tool:recommendation:weights → JSON  TTL=3600s

# 用户工具偏好
tool:pref:{userId} → Hash(toolCode, JSON)  TTL=86400s
```

### 10.3 缓存失效策略

```java
/**
 * 工具缓存事件处理器
 */
@Component
@Slf4j
public class ToolCacheEventHandler {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    /**
     * 工具信息变更时清除相关缓存
     */
    @EventListener
    public void onToolUpdated(ToolUpdatedEvent event) {
        String toolCode = event.getToolCode();

        // 清除工具元数据缓存
        redisTemplate.delete("tool:meta:" + toolCode);

        // 清除所有学科+场景的候选列表缓存（因为工具属性可能变化）
        Set<String> keys = redisTemplate.keys("tool:candidates:*");
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }

        log.info("Cache invalidated for tool: {}", toolCode);
    }

    /**
     * 推荐规则变更时清除缓存
     */
    @EventListener
    public void onRuleUpdated(RuleUpdatedEvent event) {
        if (event.getSubject() != null && event.getScene() != null) {
            redisTemplate.delete(
                "tool:rules:" + event.getSubject() + ":" + event.getScene());
        } else {
            Set<String> keys = redisTemplate.keys("tool:rules:*");
            if (keys != null && !keys.isEmpty()) {
                redisTemplate.delete(keys);
            }
        }
    }
}
```

```java
/**
 * 工具推荐降级处理器
 */
@Component
@Slf4j
public class ToolRecommendationFallbackHandler {

    // 降级方案优先级
    private static final List<FallbackStrategy> STRATEGIES = List.of(
        new CacheFallbackStrategy(),      // 1. 尝试返回缓存结果
        new DefaultRuleStrategy(),        // 2. 使用默认推荐（学科+场景硬编码映射）
        new EmptyResultStrategy()         // 3. 返回空列表，客户端隐藏面板
    );

    /**
     * 推荐服务异常时的降级入口
     */
    public List<ToolRecommendationDTO> handleFallback(
            LearningContext context, Throwable error) {
        log.warn("Tool recommendation failed, applying fallback. userId={}, error={}",
            context.getUserId(), error.getMessage());

        for (FallbackStrategy strategy : STRATEGIES) {
            try {
                List<ToolRecommendationDTO> result = strategy.apply(context);
                if (result != null && !result.isEmpty()) {
                    log.info("Fallback strategy {} succeeded with {} tools",
                        strategy.getClass().getSimpleName(), result.size());
                    return result;
                }
            } catch (Exception e) {
                log.warn("Fallback strategy {} failed", 
                    strategy.getClass().getSimpleName(), e);
            }
        }
        return Collections.emptyList();
    }
}

/**
 * 默认推荐策略（硬编码兜底）
 */
@Component
class DefaultRuleStrategy implements FallbackStrategy {

    );

    @Override
    public List<ToolRecommendationDTO> apply(LearningContext context) {
        String key = context.getSubject() + "#" + context.getScene();
        List<String> toolCodes = DEFAULT_TOOLS.get(key);
        if (toolCodes == null) {
            return Collections.emptyList();
        }
        // 返回工具元数据（从本地缓存或默认配置读取）
        return toolCodes.stream()
            .map(this::buildDefaultDTO)
            .collect(Collectors.toList());
    }
}
```

| 推荐贡献率 | 通过推荐触发的调用/总调用数 | rec_invocations / total_invocations | ≥ 30% |
| 工具使用满意度 | 用户主动好评数/评价总数 | thumbs_up / total_feedback | ≥ 85% |

### 12.2 推荐效果分析查询

```sql
-- 按工具统计推荐命中率（近7天）
SELECT
    tool_code,
    COUNT(*) AS total_impressions,
    SUM(CASE WHEN invoke_type = 'recommend' THEN 1 ELSE 0 END) AS rec_clicks,
    ROUND(
        SUM(CASE WHEN invoke_type = 'recommend' THEN 1 ELSE 0 END) * 100.0
        / NULLIF(COUNT(*), 0), 2
    ) AS rec_ctr_pct,
    AVG(duration_ms) AS avg_duration_ms,
    ROUND(
        SUM(CASE WHEN action_result = 'completed' THEN 1 ELSE 0 END) * 100.0
        / NULLIF(COUNT(*), 0), 2
    ) AS completion_rate_pct
FROM edu_tool_invocation_log
WHERE created_at >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
GROUP BY tool_code
ORDER BY rec_clicks DESC;
```

```java
/**
 * 工具调用权限校验切面
 */
@Aspect
@Component
@Slf4j
public class ToolAccessAspect {

    @Autowired
    private MembershipService membershipService;
    @Autowired
    private EduToolMapper toolMapper;

    @Around("@annotation(RequireToolAccess)")
    public Object checkToolAccess(ProceedingJoinPoint pjp) throws Throwable {
        String toolCode = extractToolCode(pjp);
        Long userId = SecurityContext.getCurrentUserId();

        EduTool tool = toolMapper.selectByToolCode(toolCode);
        if (tool == null || tool.getStatus() != ToolStatus.ONLINE.getCode()) {
            throw new BusinessException(ToolErrorCode.TOOL_NOT_FOUND);
        }

        // 校验APP版本
        if (!VersionUtil.isVersionSufficient(
                SecurityContext.getAppVersion(),
                tool.getMinAppVersion())) {
            throw new BusinessException(ToolErrorCode.TOOL_APP_VERSION_LOW);
        }

        // 校验会员等级
        if (tool.getRequiredMemberLevel() > 0) {
            int userLevel = membershipService.getMemberLevel(userId);
            if (userLevel < tool.getRequiredMemberLevel()) {
                throw new BusinessException(ToolErrorCode.TOOL_PERMISSION_DENIED);
            }
        }

        return pjp.proceed();
    }
}
```

### 14.2 性能优化措施

1. **候选集预计算**：将全量在线工具按 (学科, 场景) 组合预计算候选集存入 Redis，避免每次查 MySQL
2. **用户偏好缓存**：用户偏好数据加载到 Redis Hash，避免频繁查库
3. **异步日志写入**：工具调用日志通过消息队列异步写入 ClickHouse
4. **CDN 图标分发**：工具图标走 CDN，添加版本号防缓存
5. **批量预取**：客户端在首页加载时批量预取各学科的工具推荐结果
