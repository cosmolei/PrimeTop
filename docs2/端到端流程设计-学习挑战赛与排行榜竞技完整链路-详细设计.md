# 端到端流程设计 - 学习挑战赛与排行榜竞技完整链路

> 版本：v1.0 | 更新日期：2026-06-06 | 关联服务端文档：`服务端-学习挑战赛与排行榜竞技系统-详细设计.md`

## 1. 概述

### 1.1 功能定位

学习挑战赛与排行榜竞技是 PrimeTop 运营激励体系的核心模块之一，通过竞技化学习场景（学科挑战赛、好友PK、排行榜）激发学生学习动力，提升平台日活与留存。属于 V1.5 阶段功能，优先覆盖小学高年级至高中用户。

### 1.2 核心用户旅程

```
发现挑战 → 查看规则/奖励 → 报名参加 → 答题竞技 → 查看成绩/排名 → 领取奖励 → 分享炫耀/再来一局
```

### 1.3 关联模块

| 模块 | 关系 |
|------|------|
| 积分与虚拟经济体系 | 挑战赛奖励积分发放、积分消耗（报名费） |
| 用户学习画像 | 根据能力维度匹配对手、推荐适合难度的挑战 |
| 题目与题库服务 | 提供挑战赛题目、智能组卷 |
| 运营活动与成长激励 | 挑战赛作为运营活动的载体 |
| 消息与推送服务 | 挑战赛邀请通知、排名变动提醒 |
| 学习打卡与成就激励 | 挑战赛成就解锁勋章 |
| 收藏与笔记系统 | 挑战赛中错题自动收录 |

## 3. 数据结构设计

### 3.1 核心数据模型

#### Challenge（挑战赛）

```sql
CREATE TABLE challenge (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    challenge_id        VARCHAR(20) NOT NULL UNIQUE COMMENT '挑战赛业务ID: CHL+日期+序号',
    type                TINYINT NOT NULL COMMENT '类型: 1=学科挑战 2=好友PK 3=每日挑战',
    title               VARCHAR(100) NOT NULL COMMENT '挑战赛标题',
    description         TEXT COMMENT '挑战赛描述',
    subject             VARCHAR(20) NOT NULL COMMENT '学科编码',
    grade_range         JSON NOT NULL COMMENT '适用年级: ["G7","G8","G9"]',
    difficulty          TINYINT NOT NULL COMMENT '难度: 1=简单 2=中等 3=困难',
    
    -- 时间相关
    start_time          DATETIME NOT NULL COMMENT '开始时间',
    end_time            DATETIME NOT NULL COMMENT '结束时间',
    enroll_start_time   DATETIME COMMENT '报名开始时间',
    enroll_end_time     DATETIME COMMENT '报名截止时间',
    
    -- 参与限制
    max_participants    INT DEFAULT 0 COMMENT '最大参与人数，0=不限',
    min_participants    INT DEFAULT 0 COMMENT '最少开赛人数',
    
    -- 题目配置
    question_count      INT NOT NULL DEFAULT 15 COMMENT '题目数量',
    time_limit_seconds  INT NOT NULL DEFAULT 1200 COMMENT '答题时限(秒)',
    passing_score       INT DEFAULT 0 COMMENT '及格分数',
    total_score         INT NOT NULL COMMENT '总分',
    
    -- 报名费
    entry_fee_currency  VARCHAR(20) COMMENT '报名费币种: points',
    entry_fee_amount    INT DEFAULT 0 COMMENT '报名费金额',
    
    -- 状态
    status              TINYINT NOT NULL DEFAULT 0 COMMENT '0=草稿 1=即将开始 2=进行中 3=已结束 4=已取消',
    
    -- 运营字段
    cover_image         VARCHAR(500) COMMENT '封面图URL',
    sort_weight         INT DEFAULT 0 COMMENT '排序权重',
    is_featured         TINYINT(1) DEFAULT 0 COMMENT '是否推荐',
    
    -- 审计字段
    created_by          BIGINT COMMENT '创建人',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_type_status (type, status),
    INDEX idx_subject (subject),
    INDEX idx_start_time (start_time),
    INDEX idx_sort_featured (is_featured DESC, sort_weight DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='挑战赛表';
```

#### ChallengeReward（挑战赛奖励规则）

```sql
CREATE TABLE challenge_reward (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    challenge_id        VARCHAR(20) NOT NULL COMMENT '挑战赛ID',
    reward_tier         VARCHAR(20) NOT NULL COMMENT '奖励档位: top1/top10/top30/participation',
    rank_min            INT COMMENT '最低排名',
    rank_max            INT COMMENT '最高排名',
    reward_type         VARCHAR(20) NOT NULL COMMENT '奖励类型: points/badge/coupon',
    reward_value        VARCHAR(100) NOT NULL COMMENT '奖励值: 积分数/badge_id/优惠券ID',
    reward_amount       INT DEFAULT 0 COMMENT '奖励数量',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_challenge_tier (challenge_id, reward_tier),
    INDEX idx_challenge (challenge_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='挑战赛奖励规则';
```

#### ChallengeEnrollment（报名记录）

```sql
CREATE TABLE challenge_enrollment (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    enrollment_id       VARCHAR(20) NOT NULL UNIQUE COMMENT '报名ID: ENR+日期+序号',
    challenge_id        VARCHAR(20) NOT NULL COMMENT '挑战赛ID',
    user_id             BIGINT NOT NULL COMMENT '用户ID',
    status              TINYINT NOT NULL DEFAULT 1 COMMENT '1=已报名 2=已参加 3=已完成 4=已退款 5=已取消',
    fee_charged         INT DEFAULT 0 COMMENT '扣费金额',
    enrolled_at         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '报名时间',
    completed_at        DATETIME COMMENT '完成时间',
    
    UNIQUE INDEX uk_challenge_user (challenge_id, user_id),
    INDEX idx_user (user_id),
    INDEX idx_challenge (challenge_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='挑战赛报名记录';
```

#### ChallengeSession（答题会话）

```sql
CREATE TABLE challenge_session (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,

    -- 答题状态

    current_question    INT DEFAULT 0 COMMENT '当前题号',
    answered_count      INT DEFAULT 0 COMMENT '已答题数',

```

```
leaderboard:{type}:{scope}:{scopeKey}:{subject}:{periodKey}  →  ZSET(score, userId)

# 用户挑战赛次数（限流）
limit:challenge:daily:{userId}  →  INCR  EXPIRE 86400

# 实时PK WebSocket进度同步
pk:progress:{pkId}:{userId}  →  HASH {currentQ, answeredCount, score}
```

### 5.1 挑战赛排名计算（服务端）

```java
@Service
@Slf4j
public class ChallengeRankingService {

    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private ChallengeSessionMapper sessionMapper;

    private static final String RANKING_KEY_PREFIX = "challenge:ranking:";

    /**
     * 更新用户排名分数
     * 排名分数 = totalScore * 100000 - timeSpentSeconds
     * 确保分数相同的情况下，用时少的排名更高
     */
    public void updateRanking(String challengeId, Long userId, int totalScore, int timeSpentSeconds) {
        String key = RANKING_KEY_PREFIX + challengeId;
        double rankScore = totalScore * 100000.0 - timeSpentSeconds;
        redisTemplate.opsForZSet().add(key, userId.toString(), rankScore);
        
        // 设置过期时间：挑战结束后 7 天
        redisTemplate.expire(key, 7, TimeUnit.DAYS);
    }

    /**
     * 获取用户排名
     */
    public RankInfo getUserRank(String challengeId, Long userId) {
        String key = RANKING_KEY_PREFIX + challengeId;
        Long rank = redisTemplate.opsForZSet().reverseRank(key, userId.toString());
        Double score = redisTemplate.opsForZSet().score(key, userId.toString());
        Long total = redisTemplate.opsForZSet().zCard(key);

        if (rank == null) {
            return RankInfo.notRanked(userId);
        }

        return RankInfo.builder()
                .rank(rank.intValue() + 1)  // ZSet rank 从0开始
                .totalParticipants(total != null ? total.intValue() : 0)
                .rankScore(score)
                .percentile(calculatePercentile(rank, total))
                .build();
    }

    /**
     * 获取 Top N 排行
     */
    public List<RankInfo> getTopN(String challengeId, int n) {
        String key = RANKING_KEY_PREFIX + challengeId;
        Set<ZSetOperations.TypedTuple<String>> tuples =
                redisTemplate.opsForZSet().reverseRangeWithScores(key, 0, n - 1);

        List<RankInfo> result = new ArrayList<>();
        if (tuples != null) {
            int rank = 1;
            for (ZSetOperations.TypedTuple<String> tuple : tuples) {
                result.add(RankInfo.builder()
                        .rank(rank++)
                        .userId(Long.parseLong(tuple.getValue()))
                        .rankScore(tuple.getScore())
                        .build());
            }
        }
        return result;
    }

    private double calculatePercentile(Long rank, Long total) {
        if (total == null || total == 0) return 0;
        return 1.0 - (double) rank / total;
    }
}
```

### 5.2 挑战赛答题会话管理

```java
@Service
@Slf4j
public class ChallengeSessionService {

    @Autowired
    private ChallengeSessionMapper sessionMapper;
    @Autowired
    private ChallengeAnswerMapper answerMapper;
    @Autowired
    private ChallengeRankingService rankingService;
    @Autowired
    private ApplicationEventPublisher eventPublisher;

    /**
     * 处理用户提交答案
     */
    @Transactional
    public AnswerResult submitAnswer(String sessionId, String questionId,
                                      UserAnswerDTO userAnswer, int timeSpentSeconds) {
        // 1. 校验会话有效性
        ChallengeSession session = sessionMapper.selectBySessionId(sessionId);
        if (session == null) {
            throw new BusinessException(ErrorCode.CHALLENGE_SESSION_NOT_FOUND);
        }
        if (session.getStatus() != SessionStatus.IN_PROGRESS.getCode()) {
            throw new BusinessException(ErrorCode.CHALLENGE_SESSION_NOT_ACTIVE);
        }
        if (session.getExpiresAt().isBefore(LocalDateTime.now())) {
            expireSession(session);
            throw new BusinessException(ErrorCode.CHALLENGE_SESSION_EXPIRED);
        }

        // 2. 查询正确答案（从预加载的题目集合中）
        Question question = getQuestionFromSessionCache(sessionId, questionId);
        boolean correct = checkAnswer(question, userAnswer);
        int score = correct ? question.getScore() : 0;

        // 3. 保存答题记录
        ChallengeAnswer answer = ChallengeAnswer.builder()
                .sessionId(sessionId)
                .questionId(questionId)
                .userId(session.getUserId())
                .seq(question.getSeq())
                .userAnswer(JsonUtils.toJson(userAnswer))
                .correct(correct)
                .score(score)
                .timeSpentSeconds(timeSpentSeconds)
                .build();
        answerMapper.insert(answer);

        // 4. 更新会话统计
        session.setAnsweredCount(session.getAnsweredCount() + 1);
        session.setCorrectCount(session.getCorrectCount() + (correct ? 1 : 0));
        session.setTotalScore(session.getTotalScore() + score);
        sessionMapper.updateById(session);

        return AnswerResult.builder()
                .questionId(questionId)
                .correct(correct)
                .score(score)
                .correctAnswer(question.getCorrectAnswer())
                .explanation(question.getExplanation())
                .knowledgePointId(question.getKnowledgePointId())
                .runningTotal(session.getTotalScore())
                .progress(session.getAnsweredCount() + "/" + session.getTotalQuestions())
                .build();
    }

    /**
     * 完成挑战赛
     */
    @Transactional
    public ChallengeResult finishSession(String sessionId, List<String> markedQuestions) {
        ChallengeSession session = sessionMapper.selectBySessionId(sessionId);
        if (session.getStatus() != SessionStatus.IN_PROGRESS.getCode()) {
            throw new BusinessException(ErrorCode.CHALLENGE_SESSION_NOT_ACTIVE);
        }

        // 1. 更新会话状态
        LocalDateTime now = LocalDateTime.now();
        session.setStatus(SessionStatus.COMPLETED.getCode());
        session.setCompletedAt(now);
        session.setTimeSpentSeconds(
                (int) Duration.between(session.getStartedAt(), now).getSeconds());
        sessionMapper.updateById(session);

        // 2. 更新排名
        rankingService.updateRanking(
                session.getChallengeId(),
                session.getUserId(),
                session.getTotalScore(),
                session.getTimeSpentSeconds()
        );

        // 3. 获取当前排名
        RankInfo rankInfo = rankingService.getUserRank(
                session.getChallengeId(), session.getUserId());
        session.setFinalRank(rankInfo.getRank());
        session.setPercentile(BigDecimal.valueOf(rankInfo.getPercentile()));
        sessionMapper.updateById(session);

        // 4. 标记错题自动收录
        if (markedQuestions != null && !markedQuestions.isEmpty()) {
            eventPublisher.publishEvent(new MistakeBookEvent(
                    session.getUserId(), sessionId, markedQuestions, SourceType.CHALLENGE));
        }
        // 自动收录所有答错题目
        autoCollectMistakes(session);

        // 5. 发布挑战完成事件（异步处理奖励发放、成就检查等）
        eventPublisher.publishEvent(new ChallengeCompletedEvent(
                session.getChallengeId(), sessionId, session.getUserId(),
                session.getTotalScore(), rankInfo.getRank()));

        return buildChallengeResult(session, rankInfo);
    }
}
```

```java
@Component
@Slf4j
public class PKRealtimeHandler {

    @Autowired
    private SimpMessagingTemplate messagingTemplate;
    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 处理PK中的答题进度同步
     * 实时PK模式下，双方答题进度通过 WebSocket 互相推送
     */
    public void handleAnswerProgress(String pkId, Long userId, PKProgressDTO progress) {
        String roomKey = "pk:room:" + pkId;
        String progressKey = "pk:progress:" + pkId + ":" + userId;

        // 1. 更新自己进度到 Redis
        Map<String, String> progressMap = Map.of(
                "currentQ", String.valueOf(progress.getCurrentQuestion()),
                "answeredCount", String.valueOf(progress.getAnsweredCount()),
                "score", String.valueOf(progress.getScore()),
                "timestamp", String.valueOf(System.currentTimeMillis())
        );
        redisTemplate.opsForHash().putAll(progressKey, progressMap);

        // 2. 获取对手ID
        PKMatch match = pkMatchMapper.selectByPkId(pkId);
        Long opponentId = userId.equals(match.getCreatorId())
                ? match.getAcceptorId() : match.getCreatorId();

        // 3. 推送进度给对手（只推送当前题号和得分，不泄露答案）
        PKOpponentProgressVO opponentProgress = PKOpponentProgressVO.builder()
                .userId(userId)
                .currentQuestion(progress.getCurrentQuestion())
                .score(progress.getScore())
                .answeredCount(progress.getAnsweredCount())
                .build();

        messagingTemplate.convertAndSendToUser(
                opponentId.toString(),
                "/topic/pk/" + pkId + "/opponent",
                opponentProgress
        );

        // 4. 检查是否双方都完成
        checkBothFinished(pkId, match);
    }

    /**
     * 检查双方是否都已完成，自动结算
     */
    private void checkBothFinished(String pkId, PKMatch match) {
        String creatorKey = "pk:progress:" + pkId + ":" + match.getCreatorId();
        String acceptorKey = "pk:progress:" + pkId + ":" + match.getAcceptorId();

        // 通过 session 状态判断是否双方都完成
        boolean creatorDone = isSessionFinished(match.getCreatorSessionId());
        boolean acceptorDone = isSessionFinished(match.getAcceptorSessionId());

        if (creatorDone && acceptorDone) {
            settlePK(pkId, match);
        }
    }
}
```

## 6. 错误处理与边界场景

### 6.1 错误码定义

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|-----------|------|----------|
| 40301 | 403 | 报名条件不满足 | 展示不满足的具体原因 |
| 40302 | 403 | 名额已满 | 推荐其他可参加的挑战赛 |
| 40303 | 403 | 已报名不可重复报名 | 提示直接进入挑战 |
| 40304 | 403 | 积分不足支付报名费 | 引导赚积分或充值 |
| 40401 | 404 | 挑战赛不存在 | 返回列表页 |
| 40402 | 404 | 题目不存在 | 跳过该题，计入异常日志 |
| 40901 | 409 | 挑战赛已结束 | 展示最终排名 |
| 40902 | 409 | 答题会话冲突 | 检查是否有未完成的会话 |
| 41001 | 410 | PK邀请已过期 | 提示发起新PK |
| 41002 | 410 | 题目组卷超时 | 重试或降级到预置题目包 |
| 42901 | 429 | 每日挑战次数达上限 | 展示明日可挑战时间 |
| 50001 | 500 | 排名计算失败 | 展示分数，延迟更新排名 |
| 50002 | 500 | 奖励发放失败 | 入队重试，补偿机制 |

### 6.2 边界场景处理

| 场景 | 处理策略 |
|------|----------|
| **用户中途退出挑战赛** | 保存已答题目，标记会话为「放弃」，已答部分计分但不计入排名 |
| **答题超时** | 未答题目计为0分，自动提交会话完成 |
| **网络断连恢复** | 客户端重连后调用 `GET /session/{id}/progress` 恢复进度 |
| **排名分数完全相同** | 按 `totalScore DESC, timeSpentSeconds ASC, answeredAt ASC` 排序 |
| **PK中一方掉线** | 实时模式：60秒等待，超时后按已有成绩结算；异步模式：不受影响 |
| **题目组卷失败** | 降级使用预置题目包，记录异常日志告警 |
| **并发报名超名额** | 使用 Redis DECR 原子操作，超限则回退报名费 |
| **奖励发放失败** | 入补偿队列表，定时重试，最多3次，仍失败则人工处理 |
| **排行榜数据不一致** | 挑战赛结束后生成快照，快照数据为最终排名依据 |
| **跨年级匹配** | PK模式允许跨年级但需匹配难度区间，学科挑战赛严格限定年级 |

- 已答题目不可修改

```java
/**

                PointsSource.CHALLENGE_PARTICIPATION,
                participationReward.getRewardAmount(),
                "挑战赛参与奖励");
```

## 9. 性能考量

| 场景 | 策略 |
|------|------|
| 高并发报名 | Redis 原子计数器控制名额，消息队列削峰 |
| 实时排名计算 | Redis Sorted Set，按需刷新 top N 缓存 |
| 排行榜查询 | 结果缓存 60s，排行榜页面前端轮询间隔 ≥ 30s |
| 答题记录写入 | 批量写入 + 异步持久化，先写 Redis 后刷 DB |
| PK实时同步 | WebSocket，心跳间隔 15s，断线重连指数退避 |
| 题目组卷 | 提前预组卷，缓存在 Redis，开赛时直接下发 |

## 10. 安全与风控

| 风险 | 防护措施 |
|------|----------|
| 答题作弊（多设备登录） | 同一会话仅允许单一设备连接，WebSocket 强制踢出旧连接 |
| 外挂自动答题 | 答题间隔 < 2s 触发风控，分析答题模式异常 |
| 刷分 | 每日挑战次数限制，同一挑战赛不可重复参加 |
| PK串通 | PK随机匹配模式（非好友模式）使用 ELO 匹配算法 |
| 排行榜攻击 | 排行榜数据服务端生成，客户端只读不可篡改 |
| 未成年消费 | PK赌注积分不超过每日限额，与防沉迷系统联动 |
