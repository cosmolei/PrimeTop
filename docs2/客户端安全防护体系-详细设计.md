# 客户端安全防护体系 - 详细设计

> 版本：v1.0 | 日期：2026-05-23 | 状态：初稿

## 1. 模块概述

### 1.1 功能定位

客户端安全防护体系是 PrimeTop Flutter 客户端的基础安全层，负责通信安全、本地数据保护、运行环境检测、应用完整性校验、内容保护和逆向对抗。作为面向全学段未成年人的教育产品，客户端安全直接关系到用户隐私、支付安全和内容版权保护。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 纵深防御 | 不依赖单一安全措施，多层防护叠加 |
| 安全不降体验 | 安全检测异步执行，不阻塞主流程（P0 功能除外） |
| 渐进式对抗 | 基础防护默认启用，高级对抗按威胁等级激活 |
| 远程可配置 | 安全策略通过配置中心动态下发，无需发版即可调整 |
| 合规优先 | 未成年人相关安全策略不可被用户关闭 |

### 1.3 安全威胁模型

| 威胁类别 | 攻击场景 | 影响等级 | 防护层 |
|----------|----------|----------|--------|
| 中间人攻击 (MITM) | 公共WiFi抓包、伪造证书获取用户数据 | 🔴 高 | 通信安全 |
| 数据窃取 | Root/越狱设备读取本地数据库和缓存 | 🔴 高 | 环境检测+数据加密 |
| 逆向工程 | 反编译APK/IPA获取API密钥、业务逻辑 | 🟡 中 | 代码保护 |
| 内容盗用 | 截屏/录屏获取付费内容、VIP解析 | 🟡 中 | 内容保护 |
| 账号共享 | 多设备同时登录、共享会员账号 | 🟡 中 | 设备绑定 |
| 协议重放 | 拦截并重放API请求绕过限制 | 🟡 中 | 请求签名 |
| 青少年模式绕过 | 未成年人绕过家长控制关闭限制模式 | 🔴 高 | 家长PIN+环境检测 |
| 注入攻击 | 恶意输入注入XSS/SQL（WebView场景） | 🟡 中 | 输入净化 |

## 2. 通信安全

### 2.1 Certificate Pinning

#### 2.1.1 方案设计

采用 **SPKI (Subject Public Key Info)** 方式进行证书固定，支持主备两套公钥，实现零停机证书轮换。

```dart
// lib/core/security/cert_pinning.dart

class CertPinningConfig {
  /// 主公钥 SPKI hash (SHA-256, Base64)
  static const String primaryPin =
      'sha256/YLh1dUR9y6Kja30RrAn7JKnbQG/uEtLMkBgFF2Fuihg=';

  /// 备用公钥 SPKI hash (证书轮换期间使用)
  static const String backupPin =
      'sha256/Vjs8r4z+80wjNcr1YKepWQboSIRi63WsWXhIMN+leWU=';

  /// 远程配置覆盖（从配置中心拉取的最新pin列表）
  static List<String> get dynamicPins =>
      _remotePins ?? [primaryPin, backupPin];

  static List<String>? _remotePins;

  /// 更新远程pins
  static void updateRemotePins(List<String> pins) {
    _remotePins = pins;
  }
}
```

```dart

class CertPinningInterceptor extends Interceptor {
  final SecurityContext _securityContext;
  final CertPinningConfig _config;

  CertPinningInterceptor(this._securityContext, this._config);

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    // Dio 在底层 HttpClient 中验证证书
    // 此处仅做辅助检查：确保连接使用了预期的证书
    handler.next(options);
  }

  /// 初始化 SecurityContext，绑定证书校验
  static Future<SecurityContext> createSecurityContext() async {
    final context = SecurityContext(withTruncatedRoots: true);
    // 使用自定义 badCertificateCallback 进行 pin 验证
    return context;
  }
}

/// 自定义 HttpClient 配置
SecurityContext _createPinnedContext() {
  final context = SecurityContext.defaultContext;
  return context;
}

/// Dio 实例创建时注入证书校验
Dio _createDio() {
  final dio = Dio();

  dio.httpClientAdapter = IOHttpClientAdapter(
    createHttpClient: () {
      final client = HttpClient();
      client.badCertificateCallback = (X509Certificate cert, String host, int port) {
        return _verifyCertificate(cert, host);
      };
      return client;
    },
  );

  return dio;
}

/// 证书验证核心逻辑
bool _verifyCertificate(X509Certificate cert, String host) {
  // 1. 检查是否为API域名
  if (!_isApiHost(host)) return true; // 非API域名不校验

  // 2. 提取证书SPKI并计算SHA-256
  final certHash = _computeSpkiHash(cert);

  // 3. 与配置的pins比对
  final pins = CertPinningConfig.dynamicPins;
  final match = pins.any((pin) {
    final pinHash = pin.replaceFirst('sha256/', '');
    return certHash == pinHash;
  });

  if (!match) {
    _reportSecurityEvent(SecurityEventType.certPinFailure, {
      'host': host,
      'cert_hash': certHash,
    });
  }

  return match;
}

String _computeSpkiHash(X509Certificate cert) {
  // 实现：提取 DER 编码的 SPKI → SHA-256 → Base64
  final spkiDer = cert.spkiDer; // 简化表示
  final digest = sha256.convert(spkiDer);
  return base64Encode(digest.bytes);
}
```

### 2.2 API 请求签名

#### 2.2.1 签名算法

所有API请求（除登录/注册外）均需携带签名，防止请求篡改和重放攻击。

```
签名流程:
1. 构造待签名字符串:
   SIGN_STRING = METHOD + "\n"
                + PATH + "\n"
                + SORTED_QUERY_PARAMS + "\n"
                + TIMESTAMP + "\n"
                + NONCE + "\n"
                + BODY_SHA256_HEX

2. 计算签名:
   SIGNATURE = HMAC-SHA256(API_SIGN_KEY, SIGN_STRING)

3. 附加签名到请求头:
   X-Signature: hmac-sha256 {timestamp}:{nonce}:{signature}
   X-Timestamp: {timestamp}
   X-Nonce: {nonce}
```

#### 2.2.2 Flutter 签名拦截器

```dart
// lib/core/network/interceptors/signing_interceptor.dart

class RequestSigningInterceptor extends Interceptor {
  final String _signKey;
  final Hmac _hmac;

  RequestSigningInterceptor(this._signKey)
      : _hmac = Hmac(sha256, utf8.encode(_signKey));

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    final timestamp = DateTime.now().millisecondsSinceEpoch.toString();
    final nonce = _generateNonce();
    final bodyHash = _computeBodyHash(options.data);

    final signString = _buildSignString(
      method: options.method,
      path: options.path,
      queryParams: options.queryParameters,
      timestamp: timestamp,
      nonce: nonce,
      bodyHash: bodyHash,
    );

    final signature = _computeSignature(signString);

    options.headers['X-Signature'] = 'hmac-sha256 $timestamp:$nonce:$signature';
    options.headers['X-Timestamp'] = timestamp;
    options.headers['X-Nonce'] = nonce;

    handler.next(options);
  }

  String _buildSignString({
    required String method,
    required String path,
    required Map<String, dynamic> queryParams,
    required String timestamp,
    required String nonce,
    required String bodyHash,
  }) {
    final sortedParams = queryParams.entries.toList()
      ..sort((a, b) => a.key.compareTo(b.key));
    final queryString = sortedParams
        .map((e) => '${e.key}=${e.value}')
        .join('&');

    return '$method\n$path\n$queryString\n$timestamp\n$nonce\n$bodyHash';
  }

  String _computeBodyHash(dynamic body) {
    if (body == null) return sha256.convert([]).toString();
    final bodyBytes = utf8.encode(jsonEncode(body));
    return sha256.convert(bodyBytes).toString();
  }

  String _computeSignature(String signString) {
    final digest = _hmac.convert(utf8.encode(signString));
    return hex.encode(digest.bytes);
  }

  String _generateNonce() {
    final random = Random.secure();
    return List.generate(16, (_) => random.nextInt(256).toRadixString(16).padLeft(2, '0')).join();
  }
}
```

#### 2.2.3 服务端验签（参考）

```python
# server/middleware/request_verify.py

class RequestVerifier:
    """服务端请求签名验证"""

    EXPIRY_SECONDS = 300  # 5分钟过期

    def verify(self, request: Request) -> bool:
        sig_header = request.headers.get("X-Signature", "")
        timestamp_str = request.headers.get("X-Timestamp", "")
        nonce = request.headers.get("X-Nonce", "")

        # 1. 解析签名头
        algo, _, sig_payload = sig_header.partition(" ")
        if algo != "hmac-sha256":
            return False

        parts = sig_payload.split(":")
        if len(parts) != 3:
            return False

        req_ts, req_nonce, req_sig = parts

        # 2. 时间窗口检查
        try:
            ts = int(req_ts)
        except ValueError:
            return False
        if abs(time.time() * 1000 - ts) > self.EXPIRY_SECONDS * 1000:
            return False

        # 3. Nonce 去重（Redis，5分钟 TTL）
        nonce_key = f"nonce:{req_nonce}"
        if redis.get(nonce_key):
            return False
        redis.setex(nonce_key, self.EXPIRY_SECONDS, "1")

        # 4. 验证签名
        sign_string = self._build_sign_string(request, req_ts, req_nonce)
        expected = hmac.new(
            self.signKey.encode(), sign_string.encode(), hashlib.sha256
        ).hexdigest()

        return hmac.compare_digest(expected, req_sig)
```

### 2.3 敏感接口加密

对于支付、身份信息等高敏感接口，在TLS之上叠加应用层加密：

```dart
// lib/core/network/interceptors/encryption_interceptor.dart

class EncryptionInterceptor extends Interceptor {
  final String _publicKey; // 服务端RSA公钥

  /// 需要加密的路径匹配
  static const _encryptedPaths = [
    '/api/v1/auth/login',
    '/api/v1/auth/register',
    '/api/v1/payment/',
    '/api/v1/user/phone',
    '/api/v1/user/realname',
  ];

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    if (!_shouldEncrypt(options.path)) {
      handler.next(options);
      return;
    }

    // AES-GCM 加密请求体
    final aesKey = _generateAESKey();
    final encryptedBody = _aesEncrypt(jsonEncode(options.data), aesKey);
    final encryptedKey = _rsaEncrypt(aesKey, _publicKey);

    options.data = {
      'encrypted_key': base64Encode(encryptedKey),
      'encrypted_data': base64Encode(encryptedBody),
      'algorithm': 'AES-256-GCM',
    };
    options.headers['Content-Type'] = 'application/json';

    handler.next(options);
  }

  @override
  void onResponse(Response response, ResponseInterceptorHandler handler) {
    // 解密服务端响应（同理）
    handler.next(response);
  }

  bool _shouldEncrypt(String path) {
    return _encryptedPaths.any((p) => path.startsWith(p));
  }
}
```

```dart
// lib/core/security/secure_storage.dart

class SecureStorageService {
  static SecureStorageService? _instance;
  late final FlutterSecureStorage _storage;

  SecureStorageService._() {
    _storage = const FlutterSecureStorage(
      aOptions: AndroidOptions(
        encryptedSharedPreferences: true,
        keyCipherAlgorithm: KeyCipherAlgorithm.RSA_ECB_OAEPwithSHA_256AndMGF1Padding,
        storageCipherAlgorithm: StorageCipherAlgorithm.AES_GCM_NoPadding,
      ),
      iOptions: IOSOptions(
        accessibility: KeychainAccessibility.first_unlock_this_device,
      ),
    );
  }

  static SecureStorageService get instance =>
      _instance ??= SecureStorageService._();

  /// 存储认证 Token
  Future<void> saveAuthToken({
    required String accessToken,
    required String refreshToken,
    required int expiresAt,
  }) async {
    await _storage.write(key: 'auth_access_token', value: accessToken);
    await _storage.write(key: 'auth_refresh_token', value: refreshToken);
    await _storage.write(key: 'auth_expires_at', value: expiresAt.toString());
  }

  /// 读取认证 Token
  Future<AuthToken?> getAuthToken() async {
    final access = await _storage.read(key: 'auth_access_token');
    final refresh = await _storage.read(key: 'auth_refresh_token');
    final expiresStr = await _storage.read(key: 'auth_expires_at');

    if (access == null || refresh == null) return null;

    return AuthToken(
      accessToken: access,
      refreshToken: refresh,
      expiresAt: int.tryParse(expiresStr ?? '') ?? 0,
    );
  }

  /// 存储 API 签名密钥
  Future<void> saveSignKey(String key) async {
    await _storage.write(key: 'api_sign_key', value: key);
  }

  Future<String?> getSignKey() async {
    return await _storage.read(key: 'api_sign_key');
  }

  /// 安全清除所有数据（登出时调用）
  Future<void> clearAll() async {
    await _storage.deleteAll();
  }

  /// 检查安全存储可用性
  Future<bool> isAvailable() async {
    try {
      await _storage.write(key: '_test', value: 'test');
      final value = await _storage.read(key: '_test');
      await _storage.delete(key: '_test');
      return value == 'test';
    } catch (_) {
      return false;
    }
  }
}
```

```dart
// lib/core/security/encrypted_hive.dart

class EncryptedHiveService {
  static const _encryptionKeyBox = '_enc_keys';

  /// 获取或创建 Hive 加密密钥
  /// 密钥本身存储在 flutter_secure_storage 中
  static Future<Uint8List> _getEncryptionKey(String boxName) async {
    const secureStorage = FlutterSecureStorage();
    final keyKey = 'hive_enc_key_$boxName';
    var keyStr = await secureStorage.read(key: keyKey);

    if (keyStr == null) {
      // 首次使用，生成随机密钥
      final key = Hive.generateSecureKey();
      keyStr = base64Encode(key);
      await secureStorage.write(key: keyKey, value: keyStr);
    }

    return base64Decode(keyStr);
  }

  /// 打开加密 Box
  static Future<Box<T>> openEncryptedBox<T>(String name) async {
    final key = await _getEncryptionKey(name);
    return await Hive.openBox<T>(
      name,
      encryptionCipher: HiveAesCipher(key),
    );
  }
}

/// 使用示例：敏感用户信息
class SecureUserStore {

    _box = await EncryptedHiveService.openEncryptedBox('secure_user');

    await _box.put('phone', {'value': phone, 'updated': DateTime.now().toIso8601String()});
  }

  Future<String?> getPhone() async {
    final data = _box.get('phone');
    return data?['value'] as String?;
  }
}
```

### 3.4 数据安全擦除

```dart
// lib/core/security/data_wipe.dart

class SecureDataWipeService {
  /// 安全登出：擦除所有本地敏感数据
  static Future<void> wipeOnLogout() async {
    final tasks = <Future<void>>[];

    // 1. 清除安全存储
    tasks.add(SecureStorageService.instance.clearAll());

    // 2. 清除加密 Hive boxes
    for (final boxName in _encryptedBoxNames) {
      if (Hive.isBoxOpen(boxName)) {
        tasks.add(Hive.box(boxName).clear());
      }
    }

    // 3. 清除缓存文件
    tasks.add(_clearCacheFiles());

    // 4. 清除 WebView 数据
    tasks.add(_clearWebViewData());

    await Future.wait(tasks);

    // 5. 删除普通 Hive boxes（同步）
    for (final boxName in _clearableBoxNames) {
      await Hive.deleteBoxFromDisk(boxName);
    }
  }

  /// 账号注销：彻底擦除所有本地数据
  static Future<void> wipeOnAccountDeletion() async {
    await wipeOnLogout();

    // 额外清除所有 Hive 数据文件
    final hiveDir = await _getHiveDirectory();
    if (hiveDir != null) {
      final dir = Directory(hiveDir);
      if (await dir.exists()) {
        await dir.delete(recursive: true);
      }
    }
  }

  static const _encryptedBoxNames = [
    'secure_user',
    'payment_cache',
    'auth_state',
  ];

  static const _clearableBoxNames = [
    'user_profile',
    'learning_cache',
    'search_history',
    'recent_questions',
  ];

  static Future<void> _clearCacheFiles() async {
    final cacheDir = await getTemporaryDirectory();
    if (await cacheDir.exists()) {
      await cacheDir.delete(recursive: true);
      await cacheDir.create(recursive: true);
    }
  }

  static Future<void> _clearWebViewData() async {
    // 清除 WebView cookies 和缓存
    await CookieManager.instance().deleteAllCookies();
    await WebviewCookieManager().clearCookies();
  }

  static Future<String?> _getHiveDirectory() async {
    try {
      final dir = await getApplicationDocumentsDirectory();
      return '${dir.path}/hive';
    } catch (_) {
      return null;
    }
  }
}
```

### 4.2 环境检测服务

```dart
// lib/core/security/environment_detector.dart

enum SecurityThreat {
  rootedDevice,      // Root/越狱
  emulator,          // 模拟器
  debugger,          // 调试器
  hookFramework,     // Hook 框架
  clonedApp,         // 多开/分身
  screenSharing,     // 屏幕共享
  vpnActive,         // VPN/代理
}

class EnvironmentDetectionResult {
  final Map<SecurityThreat, bool> threats;
  final int riskScore; // 0-100
  final DateTime detectedAt;

  EnvironmentDetectionResult({
    required this.threats,
    required this.riskScore,
    required this.detectedAt,
  });

  bool get isHighRisk => riskScore >= 70;
  bool get isMediumRisk => riskScore >= 40 && riskScore < 70;

  /// 获取需要执行的策略
  SecurityAction get recommendedAction {
    if (isHighRisk) return SecurityAction.block;
    if (isMediumRisk) return SecurityAction.warn;
    return SecurityAction.allow;
  }
}

enum SecurityAction {
  allow,  // 正常使用

      _detectDebugger(),

    ]);

    threats[SecurityThreat.hookFramework] = results[3] as bool;

    threats[SecurityThreat.screenSharing] = results[5] as bool;

      SecurityThreat.vpnActive: 0,
```
