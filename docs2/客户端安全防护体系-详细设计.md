# 客户端安全防护体系 - 详细设计

> 版本：v1.1 | 日期：2026-11-03 | 状态：补全烂尾后定稿（见 §17 维护记录）

## 1. 模块概述

### 1.1 功能定位

客户端安全防护体系是 PrimeTop Flutter 客户端的基础安全层，负责通信安全、本地数据保护、运行环境检测、应用完整性校验、内容保护和逆向对抗。作为面向全学段未成年人的教育产品，客户端安全直接关系到用户隐私、支付安全和内容版权保护。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 纵深防御 | 不依赖单一安全措施，多层防护叠加 |
| 安全不降体验 | 安全检测异步执行，不阻塞主流程（P0 功能除外） |
| 渐进式对抗 | 基础防护默认启用，高级对抗按威胁等级激活 |
| 远程可配置 | 安全策略通过配置中心动态下发，无需发版即可调整 |
| 合规优先 | 未成年人相关安全策略不可被用户关闭 |

### 1.3 安全威胁模型

| 威胁类别 | 攻击场景 | 影响等级 | 防护层 |
|----------|----------|----------|--------|
| 中间人攻击 (MITM) | 公共WiFi抓包、伪造证书获取用户数据 | 🔴 高 | 通信安全 |
| 数据窃取 | Root/越狱设备读取本地数据库和缓存 | 🔴 高 | 环境检测+数据加密 |
| 逆向工程 | 反编译APK/IPA获取API密钥、业务逻辑 | 🟡 中 | 代码保护 |
| 内容盗用 | 截屏/录屏获取付费内容、VIP解析 | 🟡 中 | 内容保护 |
| 账号共享 | 多设备同时登录、共享会员账号 | 🟡 中 | 设备绑定 |
| 协议重放 | 拦截并重放API请求绕过限制 | 🟡 中 | 请求签名 |
| 青少年模式绕过 | 未成年人绕过家长控制关闭限制模式 | 🔴 高 | 家长PIN+环境检测 |
| 注入攻击 | 恶意输入注入XSS/SQL（WebView场景） | 🟡 中 | 输入净化 |

## 2. 通信安全

### 2.1 Certificate Pinning

#### 2.1.1 方案设计

采用 **SPKI (Subject Public Key Info)** 方式进行证书固定，支持主备两套公钥，实现零停机证书轮换。

```dart
// lib/core/security/cert_pinning.dart

class CertPinningConfig {
  /// 主公钥 SPKI hash (SHA-256, Base64)
  static const String primaryPin =
      'sha256/YLh1dUR9y6Kja30RrAn7JKnbQG/uEtLMkBgFF2Fuihg=';

  /// 备用公钥 SPKI hash (证书轮换期间使用)
  static const String backupPin =
      'sha256/Vjs8r4z+80wjNcr1YKepWQboSIRi63WsWXhIMN+leWU=';

  /// 远程配置覆盖（从配置中心拉取的最新pin列表）
  static List<String> get dynamicPins =>
      _remotePins ?? [primaryPin, backupPin];

  static List<String>? _remotePins;

  /// 更新远程pins
  static void updateRemotePins(List<String> pins) {
    _remotePins = pins;
  }
}
```

#### 2.1.2 Dio Interceptor 集成

```dart
// lib/core/network/interceptors/cert_pinning_interceptor.dart

/// 创建带证书固定的 Dio 实例（唯一入口，替代 v1.0 中未接线的 createSecurityContext）
Dio createSecureDio() {
  final dio = Dio();

  dio.httpClientAdapter = IOHttpClientAdapter(
    createHttpClient: () {
      final client = HttpClient();
      client.badCertificateCallback = (X509Certificate cert, String host, int port) {
        return _verifyCertificate(cert, host);
      };
      return client;
    },
  );

  return dio;
}

/// 证书验证核心逻辑（fail-closed：任何不确定一律拒绝）
bool _verifyCertificate(X509Certificate cert, String host) {
  // 1. 非 API 域名同样拒绝坏证书——v1.0 此处返回 true 等于放行任意自签证书，已修复为 fail-closed
  if (!_isApiHost(host)) return false;

  // 2. 提取证书SPKI并计算SHA-256
  final certHash = _computeSpkiHash(cert);

  // 3. 与配置的pins比对
  final pins = CertPinningConfig.dynamicPins;
  final match = pins.any((pin) {
    final pinHash = pin.replaceFirst('sha256/', '');
    return certHash == pinHash;
  });

  if (!match) {
    _reportSecurityEvent(SecurityEventType.certPinFailure, {
      'host': host,
      'cert_hash': certHash,
    });
  }

  return match;
}

/// 从 X509 DER 证书中提取 SubjectPublicKeyInfo 并计算 SHA-256(SPKI) 的 Base64。
/// v1.0 直接引用不存在的 `cert.spkiDer`（dart:io X509Certificate 不暴露 SPKI），
/// 实际实现须用 pointycastle 解析 ASN.1 结构（F1 修复）。
String _computeSpkiHash(X509Certificate cert) {
  final der = cert.der; // dart:io 暴露的 DER 编码证书（Uint8List）
  final parser = pc.ASN1Parser(der);
  final certSeq = parser.nextObject() as pc.ASN1Sequence;      // Certificate
  final tbs = certSeq.elements![0] as pc.ASN1Sequence;         // tbsCertificate
  final elems = tbs.elements!;
  // tbsCertificate 首元素为可选 version [0]（context-specific），存在则整体后移一位
  final startIndex = (elems[0] is pc.ASN1Integer) ? 0 : 1;
  // 顺序：serial(0) signature(1) issuer(2) validity(3) subject(4) subjectPublicKeyInfo(5)
  final spki = elems[startIndex + 5] as pc.ASN1Sequence;
  final digest = sha256.convert(spki.encoded!);
  return base64Encode(digest.bytes);
}
```

| 场景 | 策略 | 说明 |
|------|------|------|

### 2.2 API 请求签名

#### 2.2.1 签名算法

所有API请求（除登录/注册外）均需携带签名，防止请求篡改和重放攻击。

```
签名流程:
1. 构造待签名字符串:
   SIGN_STRING = METHOD + "\n"
                + PATH + "\n"
                + SORTED_QUERY_PARAMS + "\n"
                + TIMESTAMP + "\n"
                + NONCE + "\n"
                + BODY_SHA256_HEX

2. 计算签名:
   SIGNATURE = HMAC-SHA256(API_SIGN_KEY, SIGN_STRING)

3. 附加签名到请求头:
   X-Signature: hmac-sha256 {timestamp}:{nonce}:{signature}
   X-Timestamp: {timestamp}
   X-Nonce: {nonce}
```

#### 2.2.2 Flutter 签名拦截器

```dart
// lib/core/network/interceptors/signing_interceptor.dart

class RequestSigningInterceptor extends Interceptor {
  final String _signKey;
  final Hmac _hmac;

  RequestSigningInterceptor(this._signKey)
      : _hmac = Hmac(sha256, utf8.encode(_signKey));

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    final timestamp = DateTime.now().millisecondsSinceEpoch.toString();
    final nonce = _generateNonce();
    final bodyHash = _computeBodyHash(options.data);

    final signString = _buildSignString(
      method: options.method,
      path: options.path,
      queryParams: options.queryParameters,
      timestamp: timestamp,
      nonce: nonce,
      bodyHash: bodyHash,
    );

    final signature = _computeSignature(signString);

    options.headers['X-Signature'] = 'hmac-sha256 $timestamp:$nonce:$signature';
    options.headers['X-Timestamp'] = timestamp;
    options.headers['X-Nonce'] = nonce;

    handler.next(options);
  }

  String _buildSignString({
    required String method,
    required String path,
    required Map<String, dynamic> queryParams,
    required String timestamp,
    required String nonce,
    required String bodyHash,
  }) {
    final sortedParams = queryParams.entries.toList()
      ..sort((a, b) => a.key.compareTo(b.key));
    final queryString = sortedParams
        .map((e) => '${e.key}=${e.value}')
        .join('&');

    return '$method\n$path\n$queryString\n$timestamp\n$nonce\n$bodyHash';
  }

  String _computeBodyHash(dynamic body) {
    if (body == null) return sha256.convert([]).toString();
    final bodyBytes = utf8.encode(jsonEncode(body));
    return sha256.convert(bodyBytes).toString();
  }

  String _computeSignature(String signString) {
    final digest = _hmac.convert(utf8.encode(signString));
    return hex.encode(digest.bytes);
  }

  String _generateNonce() {
    final random = Random.secure();
    return List.generate(16, (_) => random.nextInt(256).toRadixString(16).padLeft(2, '0')).join();
  }
}
```

#### 2.2.3 服务端验签（参考）

```python
# server/middleware/request_verify.py

class RequestVerifier:
    """服务端请求签名验证"""

    EXPIRY_SECONDS = 300  # 5分钟过期

    def verify(self, request: Request) -> bool:
        sig_header = request.headers.get("X-Signature", "")
        timestamp_str = request.headers.get("X-Timestamp", "")
        nonce = request.headers.get("X-Nonce", "")

        # 1. 解析签名头
        algo, _, sig_payload = sig_header.partition(" ")
        if algo != "hmac-sha256":
            return False

        parts = sig_payload.split(":")
        if len(parts) != 3:
            return False

        req_ts, req_nonce, req_sig = parts

        # 2. 时间窗口检查
        try:
            ts = int(req_ts)
        except ValueError:
            return False
        if abs(time.time() * 1000 - ts) > self.EXPIRY_SECONDS * 1000:
            return False

        # 3. Nonce 去重（Redis，5分钟 TTL）
        nonce_key = f"nonce:{req_nonce}"
        if redis.get(nonce_key):
            return False
        redis.setex(nonce_key, self.EXPIRY_SECONDS, "1")

        # 4. 验证签名
        sign_string = self._build_sign_string(request, req_ts, req_nonce)
        expected = hmac.new(
            self.signKey.encode(), sign_string.encode(), hashlib.sha256
        ).hexdigest()

        return hmac.compare_digest(expected, req_sig)
```

### 2.3 敏感接口加密

对于支付、身份信息等高敏感接口，在TLS之上叠加应用层加密：

```dart
// lib/core/network/interceptors/encryption_interceptor.dart

class EncryptionInterceptor extends Interceptor {
  final String _publicKey; // 服务端RSA公钥

  /// 需要加密的路径匹配
  static const _encryptedPaths = [
    '/api/v1/auth/login',
    '/api/v1/auth/register',
    '/api/v1/payment/',
    '/api/v1/user/phone',
    '/api/v1/user/realname',
  ];

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    if (!_shouldEncrypt(options.path)) {
      handler.next(options);
      return;
    }

    // AES-GCM 加密请求体
    final aesKey = _generateAESKey();
    final encryptedBody = _aesEncrypt(jsonEncode(options.data), aesKey);
    final encryptedKey = _rsaEncrypt(aesKey, _publicKey);

    options.data = {
      'encrypted_key': base64Encode(encryptedKey),
      'encrypted_data': base64Encode(encryptedBody),
      'algorithm': 'AES-256-GCM',
    };
    options.headers['Content-Type'] = 'application/json';

    handler.next(options);
  }

  @override
  void onResponse(Response response, ResponseInterceptorHandler handler) {
    // 解密服务端响应（同理）
    handler.next(response);
  }

  bool _shouldEncrypt(String path) {
    return _encryptedPaths.any((p) => path.startsWith(p));
  }
}
```

```dart
// lib/core/security/secure_storage.dart

class SecureStorageService {
  static SecureStorageService? _instance;
  late final FlutterSecureStorage _storage;

  SecureStorageService._() {
    _storage = const FlutterSecureStorage(
      aOptions: AndroidOptions(
        encryptedSharedPreferences: true,
        keyCipherAlgorithm: KeyCipherAlgorithm.RSA_ECB_OAEPwithSHA_256AndMGF1Padding,
        storageCipherAlgorithm: StorageCipherAlgorithm.AES_GCM_NoPadding,
      ),
      iOptions: IOSOptions(
        accessibility: KeychainAccessibility.first_unlock_this_device,
      ),
    );
  }

  static SecureStorageService get instance =>
      _instance ??= SecureStorageService._();

  /// 存储认证 Token
  Future<void> saveAuthToken({
    required String accessToken,
    required String refreshToken,
    required int expiresAt,
  }) async {
    await _storage.write(key: 'auth_access_token', value: accessToken);
    await _storage.write(key: 'auth_refresh_token', value: refreshToken);
    await _storage.write(key: 'auth_expires_at', value: expiresAt.toString());
  }

  /// 读取认证 Token
  Future<AuthToken?> getAuthToken() async {
    final access = await _storage.read(key: 'auth_access_token');
    final refresh = await _storage.read(key: 'auth_refresh_token');
    final expiresStr = await _storage.read(key: 'auth_expires_at');

    if (access == null || refresh == null) return null;

    return AuthToken(
      accessToken: access,
      refreshToken: refresh,
      expiresAt: int.tryParse(expiresStr ?? '') ?? 0,
    );
  }

  /// 存储 API 签名密钥
  Future<void> saveSignKey(String key) async {
    await _storage.write(key: 'api_sign_key', value: key);
  }

  Future<String?> getSignKey() async {
    return await _storage.read(key: 'api_sign_key');
  }

  /// 安全清除所有数据（登出时调用）
  Future<void> clearAll() async {
    await _storage.deleteAll();
  }

  /// 检查安全存储可用性
  Future<bool> isAvailable() async {
    try {
      await _storage.write(key: '_test', value: 'test');
      final value = await _storage.read(key: '_test');
      await _storage.delete(key: '_test');
      return value == 'test';
    } catch (_) {
      return false;
    }
  }
}
```

```dart
// lib/core/security/encrypted_hive.dart

class EncryptedHiveService {
  static const _encryptionKeyBox = '_enc_keys';

  /// 获取或创建 Hive 加密密钥
  /// 密钥本身存储在 flutter_secure_storage 中
  static Future<Uint8List> _getEncryptionKey(String boxName) async {
    const secureStorage = FlutterSecureStorage();
    final keyKey = 'hive_enc_key_$boxName';
    var keyStr = await secureStorage.read(key: keyKey);

    if (keyStr == null) {
      // 首次使用，生成随机密钥
      final key = Hive.generateSecureKey();
      keyStr = base64Encode(key);
      await secureStorage.write(key: keyKey, value: keyStr);
    }

    return base64Decode(keyStr);
  }

  /// 打开加密 Box
  static Future<Box<T>> openEncryptedBox<T>(String name) async {
    final key = await _getEncryptionKey(name);
    return await Hive.openBox<T>(
      name,
      encryptionCipher: HiveAesCipher(key),
    );
  }
}

/// 使用示例：敏感用户信息
class SecureUserStore {
  late final Box<Map> _box;

    _box = await EncryptedHiveService.openEncryptedBox('secure_user');

  Future<void> savePhone(String phone) async {
    await _box.put('phone', {'value': phone, 'updated': DateTime.now().toIso8601String()});
  }

  Future<String?> getPhone() async {
    final data = _box.get('phone');
    return data?['value'] as String?;
  }
}
```

### 3.4 数据安全擦除

```dart
// lib/core/security/data_wipe.dart

class SecureDataWipeService {
  /// 安全登出：擦除所有本地敏感数据
  static Future<void> wipeOnLogout() async {
    final tasks = <Future<void>>[];

    // 1. 清除安全存储
    tasks.add(SecureStorageService.instance.clearAll());

    // 2. 清除加密 Hive boxes
    for (final boxName in _encryptedBoxNames) {
      if (Hive.isBoxOpen(boxName)) {
        tasks.add(Hive.box(boxName).clear());
      }
    }

    // 3. 清除缓存文件
    tasks.add(_clearCacheFiles());

    // 4. 清除 WebView 数据
    tasks.add(_clearWebViewData());

    await Future.wait(tasks);

    // 5. 删除普通 Hive boxes（同步）
    for (final boxName in _clearableBoxNames) {
      await Hive.deleteBoxFromDisk(boxName);
    }
  }

  /// 账号注销：彻底擦除所有本地数据
  static Future<void> wipeOnAccountDeletion() async {
    await wipeOnLogout();

    // 额外清除所有 Hive 数据文件
    final hiveDir = await _getHiveDirectory();
    if (hiveDir != null) {
      final dir = Directory(hiveDir);
      if (await dir.exists()) {
        await dir.delete(recursive: true);
      }
    }
  }

  static const _encryptedBoxNames = [
    'secure_user',
    'payment_cache',
    'auth_state',
  ];

  static const _clearableBoxNames = [
    'user_profile',
    'learning_cache',
    'search_history',
    'recent_questions',
  ];

  static Future<void> _clearCacheFiles() async {
    final cacheDir = await getTemporaryDirectory();
    if (await cacheDir.exists()) {
      await cacheDir.delete(recursive: true);
      await cacheDir.create(recursive: true);
    }
  }

  static Future<void> _clearWebViewData() async {
    // 清除 WebView cookies 和缓存
    await CookieManager.instance().deleteAllCookies();
    await WebviewCookieManager().clearCookies();
  }

  static Future<String?> _getHiveDirectory() async {
    try {
      final dir = await getApplicationDocumentsDirectory();
      return '${dir.path}/hive';
    } catch (_) {
      return null;
    }
  }
}
```

### 4.2 环境检测服务

```dart
// lib/core/security/environment_detector.dart

enum SecurityThreat {

class EnvironmentDetectionResult {
  final Map<SecurityThreat, bool> threats;
  final int riskScore; // 0-100
  final DateTime detectedAt;

  EnvironmentDetectionResult({
    required this.threats,
    required this.riskScore,
    required this.detectedAt,
  });

  bool get isHighRisk => riskScore >= 70;
  bool get isMediumRisk => riskScore >= 40 && riskScore < 70;

  /// 获取需要执行的策略
  SecurityAction get recommendedAction {
    if (isHighRisk) return SecurityAction.block;
    if (isMediumRisk) return SecurityAction.warn;
    return SecurityAction.allow;
  }
}

      SecurityThreat.emulator: 20,

      SecurityThreat.clonedApp: 15,
      SecurityThreat.screenSharing: 5,
      SecurityThreat.vpnActive: 0,
```

```kotlin
class SecurityPlugin : MethodCallHandler {
    companion object {

            "detectVPN" -> result.check(detectVPN())
            else -> result.notImplemented()

    // ── Root 检测 ──

    private fun detectRoot(): Boolean {
        return checkRootMethod1() || checkRootMethod2() || checkRootMethod3()
    }

    /** 检查 su 命令是否可用 */
    private fun checkRootMethod1(): Boolean {
        val paths = arrayOf(
            "/system/bin/su", "/system/xbin/su",
            "/sbin/su", "/data/local/xbin/su",
            "/data/local/bin/su", "/system/sd/xbin/su",
            "/system/bin/failsafe/su", "/data/local/su",
            "/su/bin/su",
        )
        return paths.any { File(it).exists() }
    }

    /** 检查 Magisk 相关标识 */
    private fun checkRootMethod2(): Boolean {
        val magiskPaths = arrayOf(
            "/sbin/.magisk", "/cache/.disable_magisk",
            "/dev/.magisk.unblock", "/data/adb/magisk"
        )
        return magiskPaths.any { File(it).exists() }
    }

    /** 尝试执行 which su */
    private fun checkRootMethod3(): Boolean {
        return try {
            val process = Runtime.getRuntime().exec(arrayOf("which", "su"))
            val input = BufferedReader(InputStreamReader(process.inputStream))
            input.readLine() != null
        } catch (_: Exception) {
            false
        }
    }

    // ── 模拟器检测 ──

    private fun detectEmulator(): Boolean {
        return checkEmulatorMethod1() || checkEmulatorMethod2()
    }

    /** 检查系统属性 */
    private fun checkEmulatorMethod1(): Boolean {
        val emulatorIndicators = listOf(
            Build.FINGERPRINT.startsWith("generic"),
            Build.FINGERPRINT.startsWith("unknown"),
            Build.MODEL.contains("google_sdk"),
            Build.MODEL.contains("Emulator"),
            Build.MODEL.contains("Android SDK built for x86"),
            Build.MANUFACTURER.contains("Genymotion"),
            Build.BRAND.startsWith("generic"),
            Build.DEVICE.startsWith("generic"),
            "google_sdk" == Build.PRODUCT,
            Build.HARDWARE.contains("goldfish"),
            Build.HARDWARE.contains("ranchu"),
        )
        return emulatorIndicators.count { it } >= 3
    }

    /** 检查传感器数量（真机通常有更多传感器） */
    private fun checkEmulatorMethod2(): Boolean {
        // 模拟器通常传感器很少
        return try {
            val sensorManager = context.getSystemService(Context.SENSOR_SERVICE) as SensorManager
            val sensorCount = sensorManager.getSensorList(Sensor.TYPE_ALL).size
            sensorCount < 5
        } catch (_: Exception) {
            false
        }
    }

    // ── 调试器检测 ──

    private fun detectDebugger(): Boolean {
        return Debug.isDebuggerConnected() || checkTracerPid()
    }

    /** 检查 /proc/self/status 中的 TracerPid */
    private fun checkTracerPid(): Boolean {
        return try {
            val reader = BufferedReader(InputStreamReader(FileInputStream("/proc/self/status")))
            var line: String? = reader.readLine()
            while (line != null) {
                if (line.startsWith("TracerPid:")) {
                    val tracerPid = line.substringAfter("TracerPid:").trim().toIntOrNull() ?: 0
                    reader.close()
                    return tracerPid != 0
                }
                line = reader.readLine()
            }
            reader.close()
            false
        } catch (_: Exception) {
            false
        }
    }

    // ── Hook 框架检测 ──

    private fun detectHook(): Boolean {
        return checkHookPorts() || checkHookLibs() || checkXposedBridge()
    }

    /** Frida 默认端口探测 */
    private fun checkHookPorts(): Boolean {
        val suspiciousPorts = listOf(27042, 27043)
        return suspiciousPorts.any { port ->
            try {
                Socket("127.0.0.1", port).use { true }
            } catch (_: Exception) {
                false
            }
        }
    }

    /** 扫描 /proc/self/maps 中的注入库 */
    private fun checkHookLibs(): Boolean {
        val hookKeywords = listOf("frida", "gadget", "substrate", "xposed", "cydia")
        return try {
            File("/proc/self/maps").readLines().any { line ->
                hookKeywords.any { keyword -> line.lowercase().contains(keyword) }
            }
        } catch (_: Exception) {
            false
        }
    }

    /** Xposed bridge 类检测 */
    private fun checkXposedBridge(): Boolean {
        return try {
            Class.forName("de.robv.android.xposed.XposedBridge")
            true
        } catch (_: ClassNotFoundException) {
            false
        }
    }

    // ── 多开/分身检测 ──

    private fun detectClone(): Boolean {
        // 1. 进程名与包名不一致（多开容器会改写进程名）
        val processName = getProcessName()
        val packageName = context.packageName
        if (processName.isNotEmpty() && processName != packageName &&
            !processName.startsWith("$packageName:")
        ) {
            return true
        }
        // 2. 双开容器特征路径
        val clonePaths = listOf(
            "/data/user/999",
            "/data/data/$packageName/../${packageName}2",
        )
        return clonePaths.any { File(it).exists() }
    }

    private fun getProcessName(): String {
        return try {
            val reader = BufferedReader(InputStreamReader(FileInputStream("/proc/self/cmdline")))
            val name = reader.readLine()?.trim()?.replace("\u0000", "") ?: ""
            reader.close()
            name
        } catch (_: Exception) {
            ""
        }
    }

    // ── 屏幕共享/投屏检测 ──

    private fun detectScreenSharing(): Boolean {
        // Android 10+：存在非内置 Display 视为投屏/共享（MediaProjection 创建的虚拟屏）
        return try {
            val dm = context.getSystemService(Context.DISPLAY_SERVICE) as DisplayManager
            dm.displays.size > 1
        } catch (_: Exception) {
            false
        }
    }

    // ── VPN/代理检测 ──

    private fun detectVPN(): Boolean {
        return try {
            val interfaces = NetworkInterface.getNetworkInterfaces()?.toList() ?: emptyList()
            interfaces.any { iface ->
                val name = iface.name.lowercase()
                name.startsWith("tun") || name.startsWith("ppp") || name.startsWith("wg")
            }
        } catch (_: Exception) {
            false
        }
    }
}

/** MethodChannel Result 扩展：检测异常统一兜底为 false（不阻塞业务） */
private fun Result.check(block: () -> Boolean) {
    try {
        success(block())
    } catch (_: Exception) {
        success(false)
    }
}
```

```swift
        return true
        #else
        return false
        #endif

    private func checkDebugger() -> Bool {
        var info = kinfo_proc()
        var mib: [Int32] = [CTL_KERN, KERN_PROC, KERN_PROC_PID, getpid()]
        var size = MemoryLayout<kinfo_proc>.stride
        let ret = sysctl(&mib, u_int(mib.count), &info, &size, nil, 0)

            return false
        }
        return scoped.keys.contains { key in
            key.starts(with: "utun") || key.starts(with: "ipsec")
        }
    }
}
```

```dart
// lib/core/security/integrity_guard.dart

class AppIntegrityGuard {
  static const _channel = MethodChannel('com.primetop/security');

  /// 白名单渠道：官方应用商店
  static const _officialInstallers = [
    'com.android.vending',        // Google Play
    'com.xiaomi.market',          // 小米
    'com.huawei.appmarket',       // 华为
    'com.oppo.market',
    'com.bbk.appstore',           // vivo
    'com.apple.testflight',       // iOS TestFlight（iOS installer 恒为空，走另一判断）
  ];

  /// 启动完整性检查：签名 + 安装来源
  /// 返回 null 表示通过，否则为失败原因码（46930/46931）
  Future<String?> verify() async {
    if (kDebugMode || kProfileMode) return null; // 调试包跳过

    final digest = await _channel.invokeMethod<String>('getSignatureDigest');
    if (digest == null) return '46930';

    final expected = await _loadOfficialDigest(); // 从资源/配置中心获取，见 §5.3
    if (digest != expected) return '46930';

    final installer = await _channel.invokeMethod<String>('getInstallerPackageName');
    if (Platform.isAndroid &&
        (installer == null || !_officialInstallers.contains(installer))) {
      return '46931';
    }
    return null;
  }
}
```

### 7.1 策略模型

```dart
    'browse':         const PolicyRule(50, 80),
    'practice':       const PolicyRule(45, 75),
    'exam':           const PolicyRule(30, 60, [SecurityThreat.screenSharing]),
    'payment':        const PolicyRule(1, 30, [SecurityThreat.rootedDevice,
                                                SecurityThreat.emulator,
                                                SecurityThreat.hookFramework]),
    'parent_gate':    const PolicyRule(1, 30, [SecurityThreat.rootedDevice,
                                                SecurityThreat.hookFramework]),
  });

class PolicyDecision {
  final PolicyAction action;
  final String reason;
  const PolicyDecision(this.action, this.reason);
  factory PolicyDecision.allow() => const PolicyDecision(PolicyAction.allow, '');
}

class SecurityPolicyEngine {
  SecurityPolicy _policy = SecurityPolicy.defaults;
  EnvironmentDetectionResult? _lastDetection;
  bool _detectionUnavailable = false;

  void onDetectionResult(EnvironmentDetectionResult r) => _lastDetection = r;

  PolicyDecision evaluate(String scenario) {
    final rule = _policy.rules[scenario] ?? _policy.rules['default']!;

    // 检测不可用：普通场景放行，资金/家长门场景 fail-closed（总红线 D10）
    if (_detectionUnavailable || _lastDetection == null) {
      final sensitive = scenario == 'payment' || scenario == 'parent_gate';
      return sensitive
          ? const PolicyDecision(PolicyAction.block, 'ENV_CHECK_UNAVAILABLE')
          : PolicyDecision.allow();
    }

    final d = _lastDetection!;

    // 硬性威胁命中即阻断（不受阈值保护）
    for (final t in rule.hardBlockThreats) {
      if (d.threats[t] == true) {
        return PolicyDecision(PolicyAction.block, 'HARD_THREAT:${t.name}');
      }
    }
    if (d.riskScore >= rule.blockThreshold) {
      return PolicyDecision(PolicyAction.block, 'RISK_${d.riskScore}');
    }
    if (d.riskScore >= rule.warnThreshold) {
      return PolicyDecision(PolicyAction.warn, 'RISK_${d.riskScore}');
    }
    return PolicyDecision.allow();
  }
}
```

### 7.2 远程策略下发

| 项 | 设计 |
|----|------|
| 接口 | `GET /api/v1/security/policy?version={n}` |
| 响应 | `{ version, effectiveAt, rules: {scenario: {warn, block, hardBlockThreats[]}}, signature }` |
| 签名校验 | 服务端用 RSA 私钥签名，客户端内置公钥验签，验签失败拒收（46941） |
| 缓存 | 本地 Hive `security_policy` 盒存储，冷启动先加载缓存再异步刷新 |
| 版本裁决 | 仅接受 `version > 本地版本` 的配置；回滚由服务端发布更高版本完成，客户端禁止降级 |
| 拉取频率 | 冷启动 + 每 6 小时，配置中心通道（复用《配置中心与动态配置管理》通道，不重复建通道 R7） |

## 9. 状态机与守卫

### 9.1 设备安全状态机

```
                 首检完成,score<warn
        ┌────────────────────────────► SAFE ◄──────────────────┐
        │                            │   ▲                    │
        │                            │   │检测恢复             │ 检测恢复且
        │     score≥warn             ▼   │                    │ 无服务端封锁
        │                   ┌──────── WARNED                  │
        │                   │         │ score≥block           │
 UNKNOWN├───────────────────┘         ▼                       │
 (启动) │                          ┌── BLOCKED ──服务端下发封锁──┤
        │                          │         ▲                  │
        └──────────────────────────┴─────────┘                  │
              检测不可用:sensitive 场景直接进入 BLOCKED(ENV_CHECK_UNAVAILABLE)
```

| 状态 | 含义 | 可执行场景 |
|------|------|-----------|
| UNKNOWN | 尚未完成首次检测（启动后 3s 内） | browse 放行；payment/parent_gate/exam 等待或拦截 |
| SAFE | 风险分低于所有 warn 阈值 | 全部 |
| WARNED | 存在中风险 | browse/practice 可用；payment/exam 按策略 |
| BLOCKED | 高风险或被服务端封锁 | 仅允许浏览公开内容、联系客服 |

### 9.2 守卫规则

| 编号 | 规则 | 违反后果 |
|------|------|----------|
| G1 | 环境检测不得阻塞 UI 线程；启动首检异步执行，敏感场景进入等待态而非跳过检测 | 代码评审拦截项 |
| G2 | 支付发起前必须取得非 UNKNOWN 检测结论（等待窗口 ≤3s，超时按 ENV_CHECK_UNAVAILABLE 拦截） | fail-closed |
| G3 | 周期检测（5min）与远程策略（6h）的变更不得导致状态震荡：WARNED↔SAFE 切换需连续两次检测确认（滞回） | 防误报抖动 |
| G4 | BLOCKED 解除必须同时满足：客户端检测恢复 + 服务端未对该设备下发封锁（服务端权威，契约 R1） | 防客户端绕过服务端处置 |
| G5 | 策略配置验签失败/版本回退时保留旧配置并标记降级，禁止静默应用未验签配置（46941） | fail-closed 于策略本身 |
| G6 | 安全存储密钥不可备份（Android `setIsStrongBoxBacked`/iOS `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`） | 合规要求 |
| G7 | 数据擦除（§3.4）失败不得静默：登出流程标记 wipe_error 并上报（46960），下次启动重试 | 防数据残留 |
| G8 | 所有安全检测项异常一律返回 false（视为未检出），禁止因检测崩溃阻断启动 | 可用性优先 |
| G9 | 受保护页面（§6）进入/离开必须配对调用，路由强制卸载也须触发 leave（Widget dispose 兜底） | 防 FLAG_SECURE 残留 |
| G10 | 安全事件上报不得携带题目内容、用户输入等业务明文（仅检测结论与元数据） | 合规 C3 |

## 10. 错误码

本节使用 **46900-46999** 段位（全库扫描确认空闲；46001-46020 归性能监控、46500 归消息推送、46800-46899 归应用锁，均不冲突）。客户端错误码仅用于埋点与日志诊断，不向用户展示码值。

| 码值 | 标识 | 含义 | 处理 |
|------|------|------|------|
| 46900 | CERT_PIN_MISMATCH | 服务端证书与 pin 不匹配 | 阻断请求，提示网络异常，上报 |
| 46901 | CERT_PIN_VERIFY_FAILED | 证书链校验异常 | 同 46900 |
| 46910 | SIGNATURE_INVALID | 应用签名校验失败 | 支付拦截 + 事件上报 |
| 46911 | REQUEST_EXPIRED | 请求签名时间窗过期 | 校时后重试 |
| 46912 | NONCE_REUSED | 重放检测命中（服务端回执） | 不重试，直接失败 |
| 46920 | ENV_ROOT_DETECTED | 检出 Root/越狱 | 按策略评分计入 |
| 46921 | ENV_EMULATOR_DETECTED | 检出模拟器 | 登录/支付场景阻断 |
| 46922 | ENV_DEBUGGER_DETECTED | 检出调试器 | 计入高风险 |
| 46923 | ENV_HOOK_DETECTED | 检出 Hook 框架 | 支付/家长门硬阻断 |
| 46924 | ENV_CLONE_DETECTED | 检出多开/分身 | 计入中风险 |
| 46930 | INTEGRITY_CHECK_FAILED | 完整性校验失败 | 支付 fail-closed |
| 46931 | PACKAGE_NOT_OFFICIAL | 非官方渠道安装 | 提示 + 事件上报 |
| 46940 | POLICY_FETCH_FAILED | 策略拉取失败 | 用本地缓存/默认策略 |
| 46941 | POLICY_SIGNATURE_INVALID | 策略验签失败 | 拒收，保留旧配置 |
| 46950 | SECURE_STORAGE_UNAVAILABLE | 安全存储不可用 | 敏感数据不落盘（降级） |
| 46951 | KEYSTORE_OPERATION_FAILED | 密钥操作失败 | 同 46950 |
| 46960 | WIPE_PARTIAL_FAILURE | 数据擦除部分失败 | 下次启动重试 + 上报 |

与服务端风控引擎 407xx 段的关系：客户端检出上报后，若服务端决策阻断，客户端收到 40704/40705/40707 回执，本层状态机以 G4 规则并入（服务端权威）。

## 11. 降级矩阵

| 编号 | 故障场景 | 降级行为 |
|------|----------|----------|
| D1 | 原生检测 MethodChannel 不可用 | 全部检测项视为 false，标记 detection_unavailable，sensitive 场景 fail-closed |
| D2 | 远程策略拉取失败 | 使用本地缓存策略；缓存也没有则用内置默认策略（§7.1），标记 policy_degraded 上报 |

| D4 | 证书 pinning 校验服务不可用 | 按 §2.1.3 降级策略执行（有限放行+频控上报），pinning 配置本身不可关闭 |

| D8 | 服务端封锁回执超时 | 本地状态机结论生效；下次同步时以服务端为准纠偏（最终一致，契约 R1） |
| D9 | 模拟器检测在低配真机误报 | 用户可申诉（引导客服），申诉期间临时放行 browse；payment 仍阻断 |
| D10 | **总红线**：支付、家长门、考试诚信相关安全判定**永远 fail-closed**，无任何降级路径可绕过；防沉迷与环境检测冲突时防沉迷优先 | — |

## 13. 合规要点

| 编号 | 要点 |
|------|------|
| C1 | 隐私政策须明确披露安全检测项清单（Root/模拟器/调试器等）与用途（安全防护），首次启动前取得同意（未同意仅运行最基础检测且不上报） |
| C2 | 检测报告与事件**仅上传检测结论与元数据**，不上传设备文件系统细节、进程列表明细（G10） |
| C3 | 环境检测数据仅用于安全防护与风控，禁止用于营销画像、个性化推荐（与画像平台隔离） |
| C4 | 未成年人设备的安全策略（防沉迷联动、家长门）不可被远程配置关闭（§7.2 服务端配置需双人复核） |
| C5 | 数据擦除（注销/登出）响应《数据导出与账户注销》E2E 链路的本地执行要求，擦除结果纳入该链路对账 |
| C6 | 事件与报告存储：服务端留存 180 天后匿名化聚合；客户端 Outbox 上限 1000 条 |
| C7 | 境内存储：安全事件数据不出境（与《数据安全与隐私合规体系》一致） |
| C8 | 家长可见：家长端可查看本设备安全状态（SAFE/WARNED/BLOCKED 三态），明细仅客服可见 |
| C9 | 不针对检测出的 Root 设备做超出告知范围的行为（不收集额外数据、不擅自删除用户内容） |
| C10 | 危机让位：心理危机信号链路优先于一切安全拦截（安全阻断不得阻碍求助通道） |
