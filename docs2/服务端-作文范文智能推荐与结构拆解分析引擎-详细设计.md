# 作文范文智能推荐与结构拆解分析引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

本模块为 PrimeTop 平台作文辅导子系统的核心组成部分，负责为学生提供高质量范文推荐、范文结构拆解分析、写作技巧标注和仿写指导服务。

**原始设计文档引用**（6.10.2 第6点）：
> 范文学习：提供同主题范文和拆解讲解

### 1.2 核心目标

| 目标 | 描述 |
|------|------|
| 范文库建设 | 建立覆盖全学段、全文体、全主题的高质量范文库 |
| 智能推荐 | 根据学生年级、写作水平、当前写作任务推荐匹配范文 |
| 结构拆解 | 自动分析范文篇章结构、段落功能、论证逻辑并可视化标注 |
| 技巧提炼 | 提取范文中的写作技巧、好词好句、修辞手法供学生学习 |
| 仿写指导 | 基于范文特征生成结构化仿写框架，引导学生模仿练习 |
| 对比分析 | 将学生习作与推荐范文进行多维度对比，给出提升建议 |

### 1.3 适用范围

- **学段覆盖**：小学（三年级起）、初中、高中
- **文体覆盖**：记叙文、议论文、说明文、应用文、读后感、散文、诗歌鉴赏
- **使用场景**：日常写作练习、考试作文备考、范文阅读理解、写作技巧学习

## 2. 数据结构设计

### 2.1 范文主表 `essay_examples`

```sql
CREATE TABLE essay_examples (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid            VARCHAR(36) NOT NULL UNIQUE COMMENT 'UUID唯一标识',
    title           VARCHAR(200) NOT NULL COMMENT '范文标题',
    content         MEDIUMTEXT NOT NULL COMMENT '范文正文（Markdown格式）',
    content_html    MEDIUMTEXT COMMENT '范文正文HTML格式（预渲染）',
    word_count      INT NOT NULL DEFAULT 0 COMMENT '字数',
    
    -- 分类属性
    stage           TINYINT NOT NULL COMMENT '学段: 1=小学 2=初中 3=高中',
    grade           VARCHAR(20) COMMENT '适用年级，逗号分隔: "3,4,5"',
    genre           VARCHAR(20) NOT NULL COMMENT '文体: narrative|argumentative|expository|practical|reading_note|prose',
    topic_tags      JSON COMMENT '主题标签: ["亲情","成长","自然"]',
    source_type     TINYINT NOT NULL DEFAULT 0 COMMENT '来源: 0=平台原创 1=授权转载 2=学生优秀习作 3=教师推荐',
    source_ref      VARCHAR(200) COMMENT '来源引用（出处/作者）',
    
    -- 质量属性
    quality_score   DECIMAL(4,2) NOT NULL DEFAULT 0 COMMENT '质量评分 0-100',
    difficulty_level TINYINT NOT NULL DEFAULT 2 COMMENT '阅读难度: 1=简单 2=中等 3=较难',
    is_classic      TINYINT NOT NULL DEFAULT 0 COMMENT '是否经典范文: 0=否 1=是',
    exam_type       VARCHAR(50) COMMENT '关联考试类型:中考|高考|期末|单元',
    
    -- AI分析结果
    structure_analysis JSON COMMENT '结构分析结果（见2.3节）',
    technique_labels  JSON COMMENT '写作技巧标签',
    vocabulary_extracts JSON COMMENT '好词好句提取结果',
    
    -- 关联
    related_knowledge_points JSON COMMENT '关联知识点ID列表',
    related_essay_topics JSON COMMENT '关联作文题目ID列表',
    
    -- 状态
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '状态: 0=草稿 1=待审核 2=已发布 3=已下架',
    review_score    DECIMAL(4,2) COMMENT '审核评分',
    reviewer_id     BIGINT COMMENT '审核人ID',
    reviewed_at     DATETIME COMMENT '审核时间',
    
    -- 统计
    view_count      INT NOT NULL DEFAULT 0 COMMENT '查看次数',
    like_count      INT NOT NULL DEFAULT 0 COMMENT '收藏次数',
    study_count     INT NOT NULL DEFAULT 0 COMMENT '学习次数（完成拆解阅读）',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    created_by      BIGINT NOT NULL,
    
    INDEX idx_stage_genre (stage, genre, status),
    INDEX idx_quality (quality_score DESC, status),
    INDEX idx_topic (topic_tags(128)),
    INDEX idx_source (source_type, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作文范文库';
```

### 2.2 范文分段标注表 `essay_example_segments`

```sql
CREATE TABLE essay_example_segments (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    essay_id        BIGINT NOT NULL COMMENT '范文ID',
    segment_index   INT NOT NULL COMMENT '段落序号（从1开始）',
    segment_type    VARCHAR(30) NOT NULL COMMENT '段落功能类型',
    segment_text    TEXT NOT NULL COMMENT '段落原文',
    start_pos       INT COMMENT '在原文中的起始字符位置',
    end_pos         INT COMMENT '在原文中的结束字符位置',
    
    -- 分析标注
    function_label  VARCHAR(50) COMMENT '段落功能标签',
    technique_tags  JSON COMMENT '本段使用的写作技巧',
    rhetoric_tags   JSON COMMENT '修辞手法标签',
    key_sentences   JSON COMMENT '关键句标注',
    annotation      TEXT COMMENT 'AI批注说明',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_essay_segment (essay_id, segment_index),
    INDEX idx_type (essay_id, segment_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='范文分段标注';

-- segment_type 枚举值:
-- opening        开头/引言
-- body_argument  正文论述段
-- body_example   正文举例段
-- body_analysis  正文分析段
-- transition     过渡段
-- conclusion     结尾段
```

## 3. API 接口设计

### 3.1 接口总览

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 范文推荐列表 | GET | `/api/v1/essay-examples/recommend` | 根据用户画像推荐范文 |
| 范文详情 | GET | `/api/v1/essay-examples/{id}` | 获取范文全文及基础信息 |
| 范文拆解分析 | GET | `/api/v1/essay-examples/{id}/analysis` | 获取范文结构拆解结果 |
| 分段标注列表 | GET | `/api/v1/essay-examples/{id}/segments` | 获取分段详细标注 |
| 好词好句提取 | GET | `/api/v1/essay-examples/{id}/highlights` | 获取好词好句精选 |
| 范文搜索 | GET | `/api/v1/essay-examples/search` | 多维度搜索范文 |
| 仿写框架获取 | GET | `/api/v1/essay-examples/{id}/imitation-template` | 获取仿写引导框架 |
| 习作-范文对比分析 | POST | `/api/v1/essay-examples/compare` | 学生作文与范文对比 |

| 范文评分 | POST | `/api/v1/essay-examples/{id}/rating` | 用户对范文评分 |
| AI生成范文拆解 | POST | `/api/v1/essay-examples/{id}/generate-analysis` | 后台触发AI拆解（管理端） |
| 批量导入范文 | POST | `/api/v1/admin/essay-examples/batch-import` | 管理端批量导入 |
| 范文上下架 | PUT | `/api/v1/admin/essay-examples/{id}/status` | 管理端修改状态 |

## 5. 推荐算法设计

### 5.1 多因子推荐评分模型

```java
/**
 * 范文推荐评分计算
 */
public class EssayRecommendScorer {
    
    /**
     * 计算范文与用户的匹配得分
     * @param essay 候选范文
     * @param userProfile 用户画像
     * @return 匹配得分 [0, 1]
     */
    public double computeMatchScore(EssayExample essay, UserProfile userProfile) {
        // 1. 年级匹配度 (权重: 25%)
        double gradeScore = computeGradeMatch(essay, userProfile);
        
        // 2. 文体偏好匹配度 (权重: 20%)
        double genreScore = computeGenrePreference(essay, userProfile);
        
        // 3. 主题兴趣匹配度 (权重: 20%)
        double topicScore = computeTopicInterest(essay, userProfile);
        
        // 4. 难度适配度 (权重: 15%) - 推荐略高于当前水平
        double difficultyScore = computeDifficultyFit(essay, userProfile);
        
        // 5. 质量得分 (权重: 10%)
        double qualityScore = essay.getQualityScore() / 100.0;
        
        // 6. 新鲜度 (权重: 5%) - 优先推荐未学习过的
        double freshnessScore = computeFreshness(essay, userProfile);
        
        // 7. 热度衰减 (权重: 5%)
        double popularityScore = computePopularityDecay(essay);
        
        return gradeScore * 0.25
             + genreScore * 0.20
             + topicScore * 0.20
             + difficultyScore * 0.15
             + qualityScore * 0.10
             + freshnessScore * 0.05
             + popularityScore * 0.05;
    }
    
    /**
     * 难度适配：推荐略高于当前水平的范文（维果茨基最近发展区）
     */
    private double computeDifficultyFit(EssayExample essay, UserProfile profile) {
        int userLevel = profile.getWritingLevel(); // 1-5
        int essayDifficulty = essay.getDifficultyLevel(); // 1-3
        
        // 理想难度 = 用户水平 + 1
        int idealDifficulty = Math.min(3, (userLevel + 1) / 2 + 1);
        
        if (essayDifficulty == idealDifficulty) return 1.0;
        if (Math.abs(essayDifficulty - idealDifficulty) == 1) return 0.7;
        return 0.3;
    }
    
    /**
     * 主题兴趣匹配：基于用户历史学习记录
     */
    private double computeTopicInterest(EssayExample essay, UserProfile profile) {
        Set<String> essayTopics = essay.getTopicTagSet();
        Map<String, Double> userInterests = profile.getTopicInterests();
        
        if (userInterests.isEmpty()) return 0.5; // 冷启动
        
        double maxScore = 0;
        for (String topic : essayTopics) {
            double score = userInterests.getOrDefault(topic, 0.1);
            maxScore = Math.max(maxScore, score);
        }
        return maxScore;
    }
}
```

### 5.2 多样性保障策略

```java
/**
 * 推荐结果多样性重排
 * 避免同一主题/文体的范文扎堆
 */
public class DiversityReranker {
    
    public List<EssayExample> rerank(List<ScoredEssay> scored, int limit) {
        List<ScoredEssay> result = new ArrayList<>();
        Map<String, Integer> topicCount = new HashMap<>();
        Map<String, Integer> genreCount = new HashMap<>();
        int maxPerTopic = 2;
        int maxPerGenre = limit / 3 + 1;
        
        // 按得分降序遍历
        scored.sort(Comparator.comparingDouble(ScoredEssay::getScore).reversed());
        
        for (ScoredEssay se : scored) {
            String genre = se.getEssay().getGenre();
            Set<String> topics = se.getEssay().getTopicTagSet();
            
            // 检查文体配额
            if (genreCount.getOrDefault(genre, 0) >= maxPerGenre) continue;
            
            // 检查主题配额
            boolean topicFull = topics.stream()
                .anyMatch(t -> topicCount.getOrDefault(t, 0) >= maxPerTopic);
            if (topicFull) continue;
            
            result.add(se);
            genreCount.merge(genre, 1, Integer::sum);
            topics.forEach(t -> topicCount.merge(t, 1, Integer::sum));
            
            if (result.size() >= limit) break;
        }
        
        // 如果数量不够，放宽限制补充
        if (result.size() < limit) {
            Set<Long> selected = result.stream()
                .map(s -> s.getEssay().getId())
                .collect(Collectors.toSet());
            scored.stream()
                .filter(s -> !selected.contains(s.getEssay().getId()))
                .limit(limit - result.size())
                .forEach(result::add);
        }
        
        return result.stream().map(ScoredEssay::getEssay).collect(Collectors.toList());
    }
}
```

```java
/**
 * 范文缓存管理
 */
@Component
public class EssayCacheManager {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String DETAIL_KEY = "essay:detail:";
    private static final String ANALYSIS_KEY = "essay:analysis:";
    private static final String RECOMMEND_KEY = "essay:recommend:";
    
    // 缓存TTL
    private static final Duration DETAIL_TTL = Duration.ofHours(6);
    private static final Duration ANALYSIS_TTL = Duration.ofHours(12);
    private static final Duration RECOMMEND_TTL = Duration.ofHours(1);
    
    /**
     * 范文更新时清除相关缓存
     */
    @CacheEvict(value = "essayDetail", key = "#essayId")
    public void onEssayUpdated(Long essayId) {
        redisTemplate.delete(DETAIL_KEY + essayId);
        redisTemplate.delete(ANALYSIS_KEY + essayId);
        // 推荐列表不立即清除，等自然过期
        
        log.info("Essay cache cleared for id={}", essayId);
    }
    
    /**
     * 范文拆解分析完成时写入缓存
     */
    public void cacheAnalysis(Long essayId, StructureAnalysisResult result) {
        String key = ANALYSIS_KEY + essayId;
        redisTemplate.opsForValue().set(key, result, ANALYSIS_TTL);
    }
    
    /**
     * 用户学习画像更新时清除推荐缓存
     */
    public void invalidateRecommendation(Long userId) {
        redisTemplate.delete(RECOMMEND_KEY + userId);
    }
}
```

```java
public enum AnalysisStatus {
    PENDING,      // 等待分析
    ANALYZING,    // 分析中
    COMPLETED,    // 分析完成
    FAILED,       // 分析失败
    OUTDATED      // 内容已更新，需要重新分析
}

// 状态转换规则：
// PENDING    → ANALYZING   (开始分析)
// ANALYZING  → COMPLETED   (分析成功)
// ANALYZING  → FAILED      (分析失败)
// FAILED     → PENDING     (重试)
// COMPLETED  → OUTDATED    (范文内容更新)
// OUTDATED   → PENDING     (触发重新分析)
```

```java
/**
 * 范文拆解分析降级策略
 */
@Component
public class EssayAnalysisFallbackHandler {
    
    /**
     * AI拆解失败时的降级处理
     */
    public AnalysisResult fallback(Long essayId, Throwable cause) {
        log.warn("Essay AI analysis failed, fallback for essayId={}", essayId, cause);
        
        // 降级1：尝试从相似范文迁移标注
        AnalysisResult migrated = tryMigrateFromSimilar(essayId);
        if (migrated != null) {
            migrated.setFallback(true);
            migrated.setFallbackType("migrated_from_similar");
            return migrated;
        }
        
        // 降级2：基于规则的基础分析（段落切分+词频统计）
        AnalysisResult basic = generateBasicAnalysis(essayId);
        basic.setFallback(true);
        basic.setFallbackType("rule_based_basic");
        return basic;
    }
    
    /**
     * 基础规则分析（无AI依赖）
     */
    private AnalysisResult generateBasicAnalysis(Long essayId) {
        EssayExample essay = essayMapper.selectById(essayId);
        String content = essay.getContent();
        
        // 按空行/缩进分段
        List<String> paragraphs = splitParagraphs(content);
        
        // 词频统计提取高频实词
        Map<String, Integer> wordFreq = extractWordFrequency(content);
        
        // 简单结构判断（基于段落数和首尾段特征）
        String structurePattern = inferStructurePattern(paragraphs);
        
        return AnalysisResult.builder()
            .overallStructure(structurePattern)
            .paragraphCount(paragraphs.size())
            .topWords(extractTopWords(wordFreq, 10))
            .isPartial(true)
            .notice("AI深度分析暂时不可用，当前为基础分析结果")
            .build();
    }
    
    /**
     * 对比分析降级：纯规则匹配
     */
    public ComparisonResult compareFallback(String userEssay, Long targetEssayId) {
        EssayExample target = essayMapper.selectById(targetEssayId);
        
        // 基础文本统计对比
        TextStats userStats = textAnalyzer.analyze(userEssay);
        TextStats targetStats = textAnalyzer.analyze(target.getContent());
        
        return ComparisonResult.builder()
            .overallSimilarity(computeJaccardSimilarity(userStats, targetStats))
            .notice("AI深度对比暂时不可用，当前为基础文本对比")
            .build();
    }
}
```

```java
/**
 * AI拆解异步处理
 */
@Service
public class EssayAnalysisAsyncService {
    
    @Autowired
    private AIModelClient aiClient;
    @Autowired
    private EssayAnalysisMapper analysisMapper;
    
    @Async("essayAnalysisExecutor")
    @Retryable(
        value = {AIModelException.class},
        maxAttempts = 3,
        backoff = @Backoff(delay = 2000, multiplier = 2)
    )
    public CompletableFuture<Void> analyzeAsync(Long essayId) {
        try {
            // 更新状态为分析中
            updateAnalysisStatus(essayId, AnalysisStatus.ANALYZING);
            
            EssayExample essay = essayMapper.selectById(essayId);
            
            // 并行调用多个AI分析任务
            CompletableFuture<StructureAnalysis> structFuture = 
                analyzeStructure(essay);
            CompletableFuture<List<SegmentAnnotation>> segFuture = 
                annotateSegments(essay);
            CompletableFuture<VocabularyExtraction> vocabFuture = 
                extractVocabulary(essay);
            CompletableFuture<QualityScore> scoreFuture = 
                scoreEssay(essay);
            
            // 等待全部完成
            CompletableFuture.allOf(structFuture, segFuture, vocabFuture, scoreFuture).join();
            
            // 汇总结果
            AnalysisResult result = AnalysisResult.builder()
                .structure(structFuture.get())
                .segments(segFuture.get())
                .vocabulary(vocabFuture.get())
                .qualityScore(scoreFuture.get())
                .analyzedAt(LocalDateTime.now())
                .build();
            
            // 持久化
            persistAnalysisResult(essayId, result);
            
            // 自动生成仿写模板
            generateImitationTemplate(essayId, result);
            
            updateAnalysisStatus(essayId, AnalysisStatus.COMPLETED);
            
            return CompletableFuture.completedFuture(null);
            
        } catch (Exception e) {
            log.error("Essay analysis failed for id={}", essayId, e);
            updateAnalysisStatus(essayId, AnalysisStatus.FAILED);
            throw new AnalysisException("AI拆解分析失败", e);
        }
    }
    
    /**
     * 线程池配置
     */
    @Bean("essayAnalysisExecutor")
    public Executor essayAnalysisExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        executor.setCorePoolSize(3);      // AI拆解是重操作，控制并发
        executor.setMaxPoolSize(5);
        executor.setQueueCapacity(50);
        executor.setThreadNamePrefix("essay-analysis-");
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        executor.initialize();
        return executor;
    }
}
```

### 10.3 批量导入优化

```java
/**
 * 范文批量导入（支持Excel/CSV）
 */
@Service
public class EssayBatchImportService {
    
    @Transactional(rollbackFor = Exception.class)
    public BatchImportResult batchImport(MultipartFile file, Long operatorId) {
        // 1. 解析文件
        List<EssayImportDTO> items = parseImportFile(file);
        
        // 2. 去重检查（标题+内容相似度）
        List<EssayImportDTO> unique = deduplicate(items);
        
        // 3. 批量插入（分批，每批50条）
        List<Long> newIds = new ArrayList<>();
        Lists.partition(unique, 50).forEach(batch -> {
            List<EssayExample> entities = batch.stream()
                .map(dto -> convertToEntity(dto, operatorId))
                .collect(Collectors.toList());
            essayMapper.batchInsert(entities);
            entities.forEach(e -> newIds.add(e.getId()));
        });
        
        // 4. 异步触发AI拆解（限流，避免AI服务过载）
        newIds.stream()
            .limit(20)  // 每次导入最多20篇触发AI拆解
            .forEach(id -> {
                try {
                    essayAnalysisAsyncService.analyzeAsync(id);
                    Thread.sleep(500); // 限速：每0.5秒一篇
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    log.warn("Batch AI analysis scheduling interrupted");
                }
            });
        
        return BatchImportResult.builder()
            .totalRead(items.size())
            .duplicatesRemoved(items.size() - unique.size())
            .imported(unique.size())
            .analysisScheduled(Math.min(newIds.size(), 20))
            .build();
    }
}
```

### 11.1 范文推荐服务

```java
@Service
@Slf4j
public class EssayRecommendService {
    
    @Autowired private EssayExampleMapper essayMapper;
    @Autowired private UserProfileService userProfileService;
    @Autowired private EssayRecommendScorer scorer;
    @Autowired private DiversityReranker reranker;
    @Autowired private RecommendReasonGenerator reasonGenerator;
    @Autowired private EssayCacheManager cacheManager;
    
    /**
     * 获取个性化推荐范文列表
     */
    public RecommendResponse recommend(Long userId, RecommendQuery query) {
        // 1. 检查缓存
        String cacheKey = buildCacheKey(userId, query);
        RecommendResponse cached = cacheManager.getRecommendation(cacheKey);
        if (cached != null) return cached;
        
        // 2. 获取用户画像
        UserProfile profile = userProfileService.getWritingProfile(userId);
        
        // 3. 检索候选集
        List<EssayExample> candidates = essayMapper.selectRecommendCandidates(
            profile.getStage(),
            query.getGenre(),
            query.getTopic(),
            query.getScene(),
            100 // 取top100做精排
        );
        
        // 4. 排除已学习的
        Set<Long> studiedIds = essayMapper.selectStudiedEssayIds(userId);
        candidates = candidates.stream()
            .filter(e -> !studiedIds.contains(e.getId()))
            .collect(Collectors.toList());
        
        // 5. 评分排序
        List<ScoredEssay> scored = candidates.stream()
            .map(e -> new ScoredEssay(e, scorer.computeMatchScore(e, profile)))
            .sorted(Comparator.comparingDouble(ScoredEssay::getScore).reversed())
            .collect(Collectors.toList());
        
        // 6. 多样性重排
        List<EssayExample> result = reranker.rerank(scored, query.getLimit());
        
        // 7. 生成推荐理由（仅前3条）
        List<RecommendItem> items = new ArrayList<>();
        for (int i = 0; i < result.size(); i++) {
            EssayExample essay = result.get(i);
            String reason = i < 3 
                ? reasonGenerator.generate(essay, profile)
                : null; // 超过3条不生成理由，节省AI调用
            items.add(buildRecommendItem(essay, reason));
        }
        
        RecommendResponse response = new RecommendResponse(items, candidates.size());
        cacheManager.cacheRecommendation(cacheKey, response);
        
        return response;
    }
    
    private String buildCacheKey(Long userId, RecommendQuery query) {
        return String.format("essay:recommend:%d:%s:%s:%d:%d",
            userId,
            query.getGenre() != null ? query.getGenre() : "all",
            query.getTopic() != null ? query.getTopic() : "all",
            query.getLimit(),
            query.getOffset()
        );
    }
}
```

```java
@Service
@Slf4j
public class EssayComparisonService {
    
    @Autowired private AIModelClient aiClient;
    @Autowired private EssayExampleMapper essayMapper;
    @Autowired private EssayAnalysisFallbackHandler fallbackHandler;
    @Autowired private TextAnalyzer textAnalyzer;
    
    /**
     * 习作与范文对比分析
     */
    public ComparisonResult compare(String userEssay, Long targetEssayId, 
                                     List<String> dimensions, Long userId) {
        // 参数校验
        if (StringUtils.isBlank(userEssay) || userEssay.length() < 50) {
            throw new BusinessException("ESSAY_007", "习作内容过短，请至少输入50字");
        }
        
        EssayExample target = essayMapper.selectById(targetEssayId);
        if (target == null || target.getStatus() != 2) {
            throw new BusinessException("ESSAY_002", "参考范文不可用");
        }
        
        try {
            // 构建Prompt
            Map<String, Object> variables = new HashMap<>();
            variables.put("userEssay", userEssay);
            variables.put("userGrade", getUserGrade(userId));
            variables.put("targetEssay", target.getContent());
            variables.put("targetTitle", target.getTitle());
            variables.put("targetAnalysis", target.getStructureAnalysis());
            
            // 调用AI
            String response = aiClient.invoke(
                "essay_comparison_v2", 
                variables,
                String.class
            );
            
            ComparisonResult result = JsonUtils.parse(response, ComparisonResult.class);
            
            // 保存对比记录
            saveComparisonRecord(userId, userEssay, targetEssayId, result);
            
            // 更新用户写作画像
            updateWritingProfile(userId, result);
            
            return result;
            
        } catch (AIModelException e) {
            log.warn("AI comparison failed, fallback for userId={}, targetId={}", 
                     userId, targetEssayId, e);
            return fallbackHandler.compareFallback(userEssay, targetEssayId);
        }
    }
    
    /**
     * 文本统计分析（本地计算，无AI依赖）
     */
    private TextStats analyzeText(String text) {
        TextStats stats = new TextStats();
        stats.setWordCount(text.length());
        stats.setParagraphCount(countParagraphs(text));
        stats.setAvgSentenceLength(computeAvgSentenceLength(text));
        stats.setUniqueCharRatio(computeUniqueCharRatio(text));
        stats.setRhetoricCount(countRhetoricMarkers(text)); // 简单修辞标记检测
        stats.setTopWords(textAnalyzer.extractTopWords(text, 20));
        return stats;
    }
}
```
