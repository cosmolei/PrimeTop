# 服务端 - 错题订正效果评估与复习成效追踪服务 详细设计

## 1. 模块概述

### 1.1 功能定位

错题订正效果评估与复习成效追踪服务负责对学生的错题订正行为和复习效果进行全链路追踪、量化评估和智能分析。不同于错题收录管理和间隔重复调度算法，本服务聚焦于**"订正之后是否真正掌握"**这一核心教育问题，通过多维指标评估订正质量和复习成效，识别顽固错题、无效复习和表面掌握，并输出个性化的改进建议。

### 1.2 核心问题

| 问题 | 描述 |
|------|------|
| 表面订正 | 学生抄写正确答案但未理解，再次遇到同类题仍会犯错 |
| 顽固错题 | 多次复习订正仍反复出错的题目，需要更换教学策略 |
| 复习间隔不当 | 间隔过短（浪费精力）或过长（已经遗忘再复习等于重新学） |
| 策略不匹配 | 同一订正策略（如重做原题）对不同错因效果差异巨大 |
| 缺乏成效反馈 | 学生和家长不知道复习是否有效，缺少量化数据支撑 |

### 1.3 与周边模块关系

## 3. 核心算法

### 3.1 订正质量评分算法（CorrectionQualityScorer）

订正质量评分从五个维度综合评估单次订正的有效性：

```python
@dataclass
class QualityScoreInput:
    is_correct: bool
    attempt_count: int
    time_spent_ms: int
    hint_used: bool
    hint_level: int | None
    referred_explanation: bool
    correction_type: str
    difficulty: float               # 题目难度 0-1
    previous_round_correct: bool | None


class CorrectionQualityScorer:
    """
    订正质量评分器 - 五维评分模型

    维度与权重：
    1. 正确性（Correctness）    0.35  — 是否做对
    2. 独立性（Independence）   0.25  — 是否依赖提示/解析
    3. 效率性（Efficiency）     0.15  — 尝试次数和耗时
    4. 深度性（Depth）          0.15  — 订正方式的思考深度
    5. 稳定性（Stability）      0.10  — 与上轮对比的趋势

    最终得分 = Σ(维度分 × 权重)，范围 0-100
    """

    WEIGHTS = {
        "correctness": 0.35,
        "independence": 0.25,
        "efficiency": 0.15,
        "depth": 0.15,
        "stability": 0.10,
    }

    DEPTH_BONUS = {
        "redo_original": 0.0,
        "redo_similar": 0.15,
        "explain_then_redo": 0.35,
        "voice_explain": 0.25,
        "written_analysis": 0.40,
        "ai_guided": 0.30,
    }

    def score(self, inp: QualityScoreInput) -> tuple[float, dict]:
        # 1. 正确性
        correctness = 100.0 if inp.is_correct else 0.0

        # 2. 独立性
        independence = 100.0
        if inp.hint_used:
            independence -= min(inp.hint_level or 1, 5) * 15
        if inp.referred_explanation:
            independence -= 30
        independence = max(0, independence)

        # 3. 效率性
        attempt_score = max(0, 100 - (inp.attempt_count - 1) * 30)
        expected_ms = 15000 + inp.difficulty * 60000
        if inp.time_spent_ms <= expected_ms:
            time_score = 100.0
        elif inp.time_spent_ms <= expected_ms * 2:
            time_score = 100 - (inp.time_spent_ms - expected_ms) / expected_ms * 50
        else:
            time_score = max(0, 50 - (inp.time_spent_ms - expected_ms * 2) / expected_ms * 50)
        efficiency = attempt_score * 0.6 + time_score * 0.4

        # 4. 深度性
        depth = min(100, 60.0 + self.DEPTH_BONUS.get(inp.correction_type, 0.0) * 100)

        # 5. 稳定性
        if inp.previous_round_correct is None:
            stability = 70.0
        elif inp.previous_round_correct and inp.is_correct:
            stability = 100.0
        elif inp.previous_round_correct and not inp.is_correct:
            stability = 30.0
        elif not inp.previous_round_correct and inp.is_correct:
            stability = 85.0
        else:
            stability = 40.0

        dimensions = {
            "correctness": correctness,
            "independence": independence,
            "efficiency": efficiency,
            "depth": depth,
            "stability": stability,
        }
        total = sum(dimensions[k] * self.WEIGHTS[k] for k in self.WEIGHTS)
        return round(total, 1), dimensions
```

### 3.2 表面订正检测算法（SurfaceCorrectionDetector）

```python
class SurfaceCorrectionDetector:
    """
    表面订正检测器

    通过行为模式识别疑似"抄答案"或"死记答案"的订正行为。
    检测维度：
    1. 速度异常  — 订正耗时远低于预期
    2. 零尝试    — 直接正确且无思考时间
    3. 非首次    — 非首轮复习时一次做对更可疑
    4. 抄解析    — 查阅解析后立刻做对
    5. 文本相似  — 作答与解析文本高度相似
    """

    SPEED_ANOMALY_RATIO = 0.2
    MIN_THINKING_TIME_MS = 3000
    TEXT_SIMILARITY_THRESHOLD = 0.85

    def detect(
        self,
        record: CorrectionRecord,
        expected_time_ms: int,
        original_explanation: str | None = None,
    ) -> tuple[bool, float, dict]:
        """返回 (是否表面订正, 置信度 0-1, 各维度信号)"""
        signals = {}
        anomaly_count = 0
        total_signals = 5

        # 1. 速度异常
        if expected_time_ms > 0:
            speed_ratio = record.time_spent_ms / expected_time_ms
            signals["speed_anomaly"] = speed_ratio < self.SPEED_ANOMALY_RATIO
            if signals["speed_anomaly"]:
                anomaly_count += 1

        # 2. 时间过短
        signals["too_fast"] = (
            record.time_spent_ms < self.MIN_THINKING_TIME_MS
            and record.is_correct
        )
        if signals["too_fast"]:
            anomaly_count += 1

        # 3. 零尝试直接正确（非首次复习）
        signals["zero_attempt"] = (
            record.attempt_count == 1
            and record.is_correct
            and not record.hint_used
            and record.review_round > 1
        )
        if signals["zero_attempt"]:
            anomaly_count += 1

        # 4. 查阅解析后立刻做对
        signals["copy_explanation"] = (
            record.referred_explanation
            and record.is_correct
            and (record.time_spent_ms < expected_time_ms * 0.3 if expected_time_ms > 0 else False)
        )
        if signals["copy_explanation"]:
            anomaly_count += 1

        # 5. 文本相似度
        text_similarity = 0.0
        if original_explanation and record.answer_content:
            set_a = set(record.answer_content.replace(" ", ""))
            set_b = set(original_explanation.replace(" ", ""))
            if set_a and set_b:
                text_similarity = len(set_a & set_b) / len(set_a | set_b)
            signals["text_similarity"] = text_similarity > self.TEXT_SIMILARITY_THRESHOLD
            if signals["text_similarity"]:
                anomaly_count += 1
        else:
            total_signals = 4

        confidence = anomaly_count / total_signals
        is_surface = confidence >= 0.5
        return is_surface, round(confidence, 3), signals
```

### 3.3 保持信心度预测算法（RetentionConfidencePredictor）

```python
class RetentionConfidencePredictor:
    """
    保持信心度预测器

    confidence = base_retention × depth_factor × trend_factor

    - base_retention: 基于简化 Ebbinghaus 模型
    - depth_factor:   订正深度增强系数
    - trend_factor:   历史趋势调整系数
    """

    def predict(
        self,
        latest_review: ReviewEffectiveness,
        correction_records: list[CorrectionRecord],
        days_until_next: int,
    ) -> float:
        if not correction_records:
            return 0.3

        last_correct = latest_review.first_attempt_correct or False
        if not last_correct:
            return 0.15

        stability = self._estimate_stability(correction_records)
        base_retention = math.exp(-days_until_next / stability)
        depth_factor = self._compute_depth_factor(correction_records)
        trend_factor = self._compute_trend_factor(correction_records)

        confidence = base_retention * depth_factor * trend_factor
        return round(max(0.0, min(1.0, confidence)), 3)

    def _estimate_stability(self, records: list[CorrectionRecord]) -> float:
        """记忆稳定性（天），基于连续正确次数指数增长，封顶60天"""
        consecutive = 0
        for r in reversed(records):
            if r.is_correct:
                consecutive += 1
            else:
                break
        stability = 3.0 * (1.8 ** max(0, consecutive - 1))
        return min(stability, 60.0)

    def _compute_depth_factor(self, records: list[CorrectionRecord]) -> float:
        depth_map = {
            "redo_original": 1.0, "redo_similar": 1.05,
            "ai_guided": 1.10, "voice_explain": 1.10,
            "explain_then_redo": 1.15, "written_analysis": 1.20,
        }
        recent = records[-3:]
        return max(depth_map.get(r.correction_type, 1.0) for r in recent)

    def _compute_trend_factor(self, records: list[CorrectionRecord]) -> float:
        if len(records) < 2:
            return 1.0
        recent_rate = sum(1 for r in records[-3:] if r.is_correct) / min(3, len(records))
        older = records[-6:-3] if len(records) >= 6 else records[:-3]
        if not older:
            return 1.0
        older_rate = sum(1 for r in older if r.is_correct) / len(older)
        diff = recent_rate - older_rate
        if diff > 0:
            return 1.0 + diff * 0.3
        elif diff < 0:
            return 1.0 - abs(diff) * 0.2
        return 1.0
```

### 3.4 顽固错题识别与升级算法

```python
class StubbornMistakeDetector:
    """
    顽固错题识别器

    判定条件（满足任一即标记）：
    1. 连续 N 次复习订正均失败
    2. 总计 M 次复习，正确率 < 30%
    3. 错因一致性 > 0.7

    干预升级：Level 0→1 更换策略 → Level 2 知识点分解 → Level 3 标记求助
    """

    LEVEL_UP_CONDITIONS = {
        1: {"min_reviews": 3, "consecutive_failures": 3},
        2: {"min_reviews": 5, "consecutive_failures": 4},
        3: {"min_reviews": 8, "consecutive_failures": 5},
    }

    def evaluate(
        self,
        tracker: StubbornMistakeTracker,
        correction_records: list[CorrectionRecord],
        error_labels: list[str],
    ) -> tuple[bool, int, str | None]:
        """评估是否应升级干预 → (是否升级, 目标级别, 建议策略)"""
        current_level = tracker.intervention_level
        next_level = current_level + 1
        if next_level > 3:
            return False, current_level, None

        consecutive = tracker.consecutive_failures
        total = tracker.total_reviews
        consistency = self._error_consistency(error_labels)
        conditions = self.LEVEL_UP_CONDITIONS[next_level]

        should_upgrade = (
            consecutive >= conditions["consecutive_failures"]
            or (total >= conditions["min_reviews"]
                and self._failure_rate(correction_records) > 0.7)
            or (consistency > 0.7 and total >= 3)
        )

        if should_upgrade:
            return True, next_level, self._strategy_for_level(next_level, error_labels)
        return False, current_level, None

    @staticmethod
    def _error_consistency(labels: list[str]) -> float:
        if not labels:
            return 0.0
        counter = {}
        for l in labels:
            counter[l] = counter.get(l, 0) + 1
        return max(counter.values()) / len(labels)

    @staticmethod
    def _failure_rate(records: list[CorrectionRecord]) -> float:
        return sum(1 for r in records if not r.is_correct) / len(records) if records else 0.0

    def _strategy_for_level(self, level: int, error_labels: list[str]) -> str:
        if level == 1:
            return "explain_then_redo"
        elif level == 2:
            dominant = max(set(error_labels), key=error_labels.count)
            return {"concept_gap": "break_down", "calculation": "practice_similar",
                    "misread": "visual_aid", "wrong_method": "deepen_concept"}.get(dominant, "break_down")
        return "seek_teacher"
```

### 3.5 复习间隔自适应调整算法

```python
class ReviewIntervalAdjuster:
    """
    复习间隔自适应调整器
    成效好→延长间隔，成效差→缩短间隔，顽固错题→回归短间隔并换策略
    """

    BASE_INTERVALS = {1: 1, 2: 3, 3: 7, 4: 14, 5: 30}

    def adjust(self, review_round: int, effectiveness_score: float,
               retention_confidence: float, is_stubborn: bool) -> int:
        base = self.BASE_INTERVALS.get(review_round + 1, 30)

        if is_stubborn:
            return min(base, self.BASE_INTERVALS[1])

        if effectiveness_score >= 80:
            multiplier = 1.5 + (effectiveness_score - 80) / 100
        elif effectiveness_score >= 50:
            multiplier = 1.0
        elif effectiveness_score >= 30:
            multiplier = 0.6
        else:
            multiplier = 0.3

        if retention_confidence >= 0.8:
            multiplier *= 1.2
        elif retention_confidence < 0.4:
            multiplier *= 0.7

        return min(60, max(1, round(base * multiplier)))
```

### 5.2 日终聚合任务

```python
@app.task(name="review_effectiveness.daily_aggregation")
def daily_aggregation(stat_date: str = None):
    """
    每日凌晨执行，聚合所有用户的复习成效日报。
    流程：
    1. 查询当日有订正行为的活跃用户
    2. 对每个用户异步聚合：first_correct_rate、avg_score、顽固错题变化
    3. 写入 review_effectiveness_daily
    4. 更新 Redis 缓存中的用户概览数据
    """
    target = parse_date(stat_date) or date.today() - timedelta(days=1)
    active_users = db.query(CorrectionRecord.user_id).filter(
        func.date(CorrectionRecord.created_at) == target
    ).distinct().all()
    for (uid,) in active_users:
        _aggregate_user_daily.delay(uid, target.isoformat())
```

### 5.3 延迟回判检测

```python
@app.task(name="review_effectiveness.delayed_validation")
def delayed_validation(correction_id: str, check_delay_hours: int = 72):
    """
    延迟回判：订正后 72 小时检查同类题是否再次犯错。
    若出现同类题错误 → 将之前订正标记为"疑似表面订正"。
    """
    record = db.get(CorrectionRecord, correction_id)
    if not record or not record.is_correct:
        return

    similar_errors = db.query(AnswerRecord).filter(
        AnswerRecord.user_id == record.user_id,
        AnswerRecord.knowledge_point_id == record.knowledge_point_id,
        AnswerRecord.created_at > record.created_at,
        AnswerRecord.created_at <= record.created_at + timedelta(hours=check_delay_hours),
        AnswerRecord.is_correct == False,
    ).limit(5).all()

    if similar_errors:
        record.surface_flag = True
        record.quality_score = max(0, (record.quality_score or 0) - 20)
        # 同步降级 ReviewEffectiveness
        eff = db.query(ReviewEffectiveness).filter(
            ReviewEffectiveness.user_id == record.user_id,
            ReviewEffectiveness.mistake_id == record.mistake_id,
            ReviewEffectiveness.review_round == record.review_round,
        ).first()
        if eff:
            eff.effectiveness_score = max(0, (eff.effectiveness_score or 0) - 15)
            eff.retention_confidence = max(0, (eff.retention_confidence or 0) - 0.2)
        db.commit()
        _revaluate_stubborn.delay(record.user_id, record.mistake_id)
```

| 47102 | 500 | 表面订正检测服务异常 |
| 47103 | 500 | 保持度预测计算失败 |
| 47104 | 500 | 顽固错题评估服务异常 |
| 47105 | 503 | 日终聚合任务排队失败 |

### 8.2 降级策略

| 故障点 | 降级方案 |
|--------|---------|
| 质量评分计算超时 | 简化评分(correctness×0.6+independence×0.4)，异步补偿 |
| 表面订正检测不可用 | 跳过检测，surface_flag=null，异步补偿 |
| 保持度预测失败 | 使用基础 Ebbinghaus 公式 |
| 顽固错题评估失败 | 保持当前干预级别，记录待重试 |
| 日终聚合失败 | 次日补偿执行（检查缺失日期） |
| Redis 不可用 | 直连数据库，不影响核心功能 |
| 数据库写入失败 | 写入本地 WAL，补偿任务回放 |
