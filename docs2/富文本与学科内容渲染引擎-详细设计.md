# 富文本与学科内容渲染引擎 - 详细设计

> 版本：1.0 | 日期：2026-05-20 | 模块代号：`rendering-engine`

## 1. 模块定位与边界

### 1.1 模块职责

富文本与学科内容渲染引擎是客户端侧的**通用内容渲染基础设施**，负责将后端返回的结构化内容（含数学公式、化学方程式、物理图表、英语音标、代码块等）准确、美观、高性能地渲染到 Flutter 界面上。

### 1.2 核心问题

| 问题 | 描述 |
|------|------|
| 数学公式 | LaTeX 语法的行内公式 `$...$` 和块级公式 `$$...$$` 需在 Flutter 中正确渲染 |
| 化学方程式 | 反应方程式 `2H₂ + O₂ → 2H₂O`、结构简式、电子式等 |
| 物理图表 | 力学示意图、电路图、光路图等矢量图形 |
| 几何图形 | 几何题目中的线段、角度、圆、辅助线等 |
| 英语音标 | IPA 国际音标 `英 /ˈæpl/`、重音符号等 |
| 代码与排版 | Python 代码示例、缩进、列表、表格 |
| 混合内容 | 一段 AI 回答可能同时包含文字、公式、图表、代码 |

### 1.3 不负责

- **图片生成**：由后端 AI 服务或资源服务负责
- **题目 OCR 识别**：由拍照搜题模块负责
- **内容安全过滤**：由安全与内容合规系统负责

### 1.4 依赖模块

| 模块 | 依赖方式 |
|------|----------|
| AI 智能辅导 | 消费渲染引擎展示 AI 回答 |
| 拍照搜题与习题答疑 | 消费渲染引擎展示解析步骤 |
| 同步课堂学习 | 消费渲染引擎展示知识讲解 |
| 理科解题 | 消费渲染引擎展示公式推导 |
| 作文辅导 | 消费渲染引擎展示批改标注 |
| 英语专项 | 消费渲染引擎展示音标与语法高亮 |
| 错题整理 | 消费渲染引擎展示题目与解析 |

## 2. 内容格式规范（前后端契约）

### 2.1 内容标记语言选择

后端 AI 生成的回答统一采用 **增强 Markdown** 格式，在标准 Markdown 基础上扩展学科标记：

| 类型 | 语法 | 示例 |
|------|------|------|
| 行内数学公式 | `$...$` | 勾股定理 $a^2 + b^2 = c^2$ |
| 块级数学公式 | `$$...$$` | `$$\frac{-b \pm \sqrt{b^2-4ac}}{2a}$$` |
| 化学方程式 | `$$\ce{...}$$` | `$$\ce{2H2 + O2 -> 2H2O}$$` |
| 几何图形 | `:::geo{json="..."}:::` | 自定义块标记 |
| 物理图表 | `:::physics{json="..."}:::` | 自定义块标记 |
| 英语音标 | `:::ipa{...}:::` | `:::ipa{/ˈæpl/}:::` |
| 代码块 | ` ```lang ` | 标准 Markdown 代码块 |
| 表格 | 标准 Markdown 表格 | — |
| 思考步骤 | `:::step{order="1" title="分析条件"}...:::` | 自定义步骤标记 |
| 重点提示 | `:::tip{type="warning"}...:::` | 提示框 |
| 答案折叠 | `:::spoiler{label="点击查看答案"}...:::` | 折叠区域 |

## 3. 渲染引擎架构

### 3.1 整体架构

```
后端 Markdown 字符串
       │
       ▼
┌──────────────────┐
│  Markdown Parser  │  ← 自定义解析器，识别学科扩展语法
│  (分词 → AST)     │
└────────┬─────────┘
         │ RenderNode Tree
         ▼
┌──────────────────┐
│  Node Transformer │  ← 分龄适配、安全过滤、样式映射
│  (AST 转换)       │
└────────┬─────────┘
         │ Transformed Tree
         ▼
┌──────────────────┐
│  Widget Builder   │  ← 将节点树转为 Flutter Widget 树
│  (节点→Widget)    │
└────────┬─────────┘
         │ Widget Tree
         ▼
┌──────────────────┐
│  Rendered View    │  ← 最终渲染界面
└──────────────────┘
```

### 3.2 解析器设计（Parser）

#### 3.2.1 解析策略

采用**两阶段解析**：

1. **Phase 1 - 标准 Markdown 解析**：使用 `markdown` 包将标准 Markdown 语法解析为基础 AST
2. **Phase 2 - 学科扩展解析**：对自定义块标记 `:::type{...}...:::` 和 LaTeX 公式进行二次解析

```dart
class RichMarkdownParser {
  /// 解析完整内容为渲染节点树
  List<RenderNode> parse(String markdown) {
    // Phase 1: 提取自定义块，替换为占位符
    final placeholders = <String, RenderNode>{};
    final preprocessed = _extractCustomBlocks(markdown, placeholders);

    // Phase 2: 使用标准 Markdown 解析器
    final mdDocument = md.Document(
      inlineSyntaxes: [
        InlineMathSyntax(),  // $...$ 行内公式
      ],
      blockSyntaxes: [
        BlockMathSyntax(),   // $$...$$ 块级公式
      ],
    );
    final nodes = mdDocument.parseLines(preprocessed);

    // Phase 3: 将 AST 转为 RenderNode 树，还原占位符
    return _convertToRenderNodes(nodes, placeholders);
  }

  /// 提取自定义块标记 (:::type{...}...:::)
  String _extractCustomBlocks(
    String markdown,
    Map<String, RenderNode> placeholders,
  ) {
    final regex = RegExp(
      r'^:::(\w+)(?:\{([^}]*)\})?\n(.*?)^:::$',
      multiLine: true,
      dotAll: true,
    );
    return markdown.replaceAllMapped(regex, (match) {
      final blockType = match.group(1)!;
      final attrs = _parseAttributes(match.group(2) ?? '');
      final content = match.group(3)!;
      final placeholder = '\x00BLOCK_${placeholders.length}\x00';
      placeholders[placeholder] = _createCustomNode(blockType, attrs, content);
      return placeholder;
    });
  }

  RenderNode _createCustomNode(
    String type,
    Map<String, String> attrs,
    String content,
  ) {
    switch (type) {
      case 'geo':
        return GeometryNode(
          shapes: GeoShapeData.fromJson(jsonDecode(attrs['json'] ?? '{}')),
        );
      case 'physics':
        return PhysicsNode(
          diagram: PhysicsDiagramData.fromJson(
            jsonDecode(attrs['json'] ?? '{}'),
          ),
        );
      case 'ipa':
        return IPANode(phonetic: attrs['text'] ?? content.trim());
      case 'step':
        return StepNode(
          order: int.parse(attrs['order'] ?? '1'),
          title: attrs['title'] ?? '',
          children: parse(content), // 递归解析步骤内容
        );
      case 'tip':
        return TipNode(
          type: _parseTipType(attrs['type'] ?? 'note'),
          children: parse(content),
        );
      case 'spoiler':
        return SpoilerNode(
          label: attrs['label'] ?? '点击展开',
          children: parse(content),
        );
      default:
        return TextNode(text: content);
    }
  }
}
```

#### 3.2.2 LaTeX 公式提取

```dart
/// 行内公式语法：$...$
class InlineMathSyntax extends md.InlineSyntax {
  InlineMathSyntax() : super(r'\$([^\$]+)\$');

  @override
  bool onMatch(md.InlineParser parser, Match match) {
    parser.addNode(md.Element.text('inline_math', match.group(1)!));
    return true;
  }
}

/// 块级公式语法：$$...$$
class BlockMathSyntax extends md.BlockSyntax {
  @override
  RegExp get pattern => RegExp(r'^\$\$(.*)\$\$$');

  @override
  md.Node? parse(md.BlockParser parser) {
    final match = pattern.firstMatch(parser.current)!;
    parser.advance();
    return md.Element('block_math', [md.Text(match.group(1)!)]);
  }
}
```

### 3.3 节点转换器（Transformer）

#### 3.3.1 分龄适配

```dart
class AgeAdaptiveTransformer {
  final GradeLevel gradeLevel;

  AgeAdaptiveTransformer(this.gradeLevel);

  List<RenderNode> transform(List<RenderNode> nodes) {
    return nodes.map(_transformNode).toList();
  }

  RenderNode _transformNode(RenderNode node) {
    switch (node) {
      case MathNode math:
        // 低年级：简化公式显示，增加注释
        if (gradeLevel <= GradeLevel.grade4) {
          return math.copyWith(
            showAnnotation: true,
            annotation: _generateAnnotation(math.latex),
          );
        }
        return math;

      case StepNode step:
        // 幼儿/低年级：用图示替代文字步骤
        if (gradeLevel <= GradeLevel.grade2) {
          return _convertToVisualStep(step);
        }
        return step;

      case TipNode tip:
        // 幼儿阶段：将 warning 类提示转为更友好的语气
        if (gradeLevel <= GradeLevel.kindergarten) {
          return tip.copyWith(
            type: TipType.note,
            style: TipStyle.friendly,
          );
        }
        return tip;

      default:
        return node;
    }
  }
}
```

#### 3.4.1 渲染引擎核心 Widget

```dart
/// 富文本渲染主 Widget
class RichContentViewer extends ConsumerStatefulWidget {
  final String markdown;
  final GradeLevel gradeLevel;
  final Subject? subject;
  final bool interactive; // 是否允许交互（点击展开、切换步骤等）
  final EdgeInsets padding;
  final VoidCallback? onTapFormula; // 点击公式回调
  final void Function(GeoShapeData)? onTapGeometry; // 点击几何图回调

  const RichContentViewer({
    super.key,
    required this.markdown,
    required this.gradeLevel,
    this.subject,
    this.interactive = true,
    this.padding = EdgeInsets.zero,
    this.onTapFormula,
    this.onTapGeometry,
  });

  @override
  ConsumerState<RichContentViewer> createState() => _RichContentViewerState();
}

class _RichContentViewerState extends ConsumerState<RichContentViewer> {
  late final List<RenderNode> _nodes;
  final _parser = RichMarkdownParser();

  @override
  void initState() {
    super.initState();
    _parseContent();
  }

  @override
  void didUpdateWidget(RichContentViewer oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.markdown != widget.markdown ||
        oldWidget.gradeLevel != widget.gradeLevel) {
      _parseContent();
    }
  }

  void _parseContent() {
    final rawNodes = _parser.parse(widget.markdown);
    final transformer = AgeAdaptiveTransformer(widget.gradeLevel);
    _nodes = transformer.transform(rawNodes);
  }

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: widget.padding,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: _nodes.map((node) => _buildNode(node)).toList(),
      ),
    );
  }

  Widget _buildNode(RenderNode node) {
    switch (node) {
      case TextNode text:
        return _TextWidget(text);
      case MathNode math:
        return _MathWidget(
          math,
          gradeLevel: widget.gradeLevel,
          onTap: widget.onTapFormula,
        );
      case ChemistryNode chemistry:
        return _ChemistryWidget(chemistry);
      case GeometryNode geo:
        return _GeometryWidget(
          geo,
          interactive: widget.interactive,
          onTap: widget.onTapGeometry,
        );
      case StepNode step:
        return _StepWidget(
          step,
          gradeLevel: widget.gradeLevel,
          interactive: widget.interactive,
        );
      case TipNode tip:
        return _TipWidget(tip);
      case SpoilerNode spoiler:
        return _SpoilerWidget(spoiler, interactive: widget.interactive);
      case CodeNode code:
        return _CodeBlockWidget(code);
      case TableNode table:
        return _TableWidget(table);
      default:
        return const SizedBox.shrink();
    }
  }
}
```

## 4. 数学公式渲染方案

### 4.1 方案选型

| 方案 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| `flutter_math_fork` | 纯 Dart 实现原生渲染，无 WebView 依赖 | 对复杂 LaTeX 支持有限 | ✅ 主方案 |
| `mathjax` + WebView | LaTeX 支持最完整 | 性能差，内存高，交互受限 | 降级方案 |
| 预渲染图片 | 性能最好 | 不支持交互、缩放模糊 | 缓存策略补充 |

### 4.2 数学公式 Widget

```dart
class _MathWidget extends StatelessWidget {
  final MathNode node;
  final GradeLevel gradeLevel;
  final VoidCallback? onTap;

  const _MathWidget(
    this.node, {
    required this.gradeLevel,
    this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    final isInline = node.inline;

    if (isInline) {
      // 行内公式：嵌入文本流
      return GestureDetector(
        onTap: onTap,
        child: Math.tex(
          node.latex,
          textStyle: context.textTheme.bodyMedium,
          mathStyle: MathStyle.text,
          onErrorFallback: (err) => _buildFallback(node.latex, err),
        ),
      );
    }

    // 块级公式：居中显示，带可选注释
    return Container(
      width: double.infinity,
      padding: const EdgeInsets.symmetric(vertical: 12, horizontal: 16),
      margin: const EdgeInsets.symmetric(vertical: 8),
      decoration: BoxDecoration(
        color: context.colorScheme.surfaceVariant.withOpacity(0.3),
        borderRadius: BorderRadius.circular(8),
      ),
      child: Column(
        children: [
          Center(
            child: GestureDetector(
              onTap: onTap,
              child: Math.tex(
                node.latex,
                textStyle: context.textTheme.bodyLarge?.copyWith(
                  fontSize: 18,
                ),
                mathStyle: MathStyle.display,
                onErrorFallback: (err) => _buildFallback(node.latex, err),
              ),
            ),
          ),
          if (node.showAnnotation && node.annotation != null)
            Padding(
              padding: const EdgeInsets.only(top: 8),
              child: Text(
                node.annotation!,
                style: context.textTheme.bodySmall?.copyWith(
                  color: context.colorScheme.onSurfaceVariant,
                ),
              ),
            ),
        ],
      ),
    );
  }

  /// 公式渲染失败时的降级显示
  Widget _buildFallback(String latex, Object error) {
    // 记录失败事件
    AnalyticsService.logFormulaRenderFailed(
      latex: latex,
      error: error.toString(),
    );

    return Container(
      padding: const EdgeInsets.all(8),
      decoration: BoxDecoration(
        color: Colors.orange.shade50,
        borderRadius: BorderRadius.circular(4),
        border: Border.all(color: Colors.orange.shade200),
      ),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(Icons.functions, size: 16, color: Colors.orange.shade700),
          const SizedBox(width: 4),
          Flexible(
            child: Text(
              latex,
              style: TextStyle(
                fontFamily: 'monospace',
                color: Colors.orange.shade900,
                fontSize: 13,
              ),
              overflow: TextOverflow.ellipsis,
            ),
          ),
        ],
      ),
    );
  }
}
```

### 4.4 公式预处理器

后端返回的 LaTeX 可能包含 `flutter_math_fork` 不支持的宏，需要预处理：

```dart
class LatexPreprocessor {
  /// 预处理 LaTeX 字符串，替换不兼容的命令
  static String process(String latex) {
    return latex
        // \ce{...} 化学方程式标记 → 由 ChemistryNode 单独处理
        .replaceAllMapped(
          RegExp(r'\\ce\{([^}]*)\}'),
          (m) => _convertChemLatex(m.group(1)!),
        )
        // \text{中文} → 直接输出
        .replaceAllMapped(
          RegExp(r'\\text\{([^}]*)\}'),
          (m) => m.group(1)!,
        )
        // \dfrac → \frac（flutter_math 不支持 \dfrac）
        .replaceAll(r'\dfrac', r'\frac')
        // \begin{aligned} → \begin{align}
        .replaceAll(r'\begin{aligned}', r'\begin{align}')
        .replaceAll(r'\end{aligned}', r'\end{align}')
        // 移除 \displaystyle（已通过 MathStyle.display 处理）
        .replaceAll(r'\displaystyle', '')
        // \xrightarrow{...} → 简化处理
        .replaceAllMapped(
          RegExp(r'\\xrightarrow\{([^}]*)\}'),
          (m) => r'\xrightarrow{${m.group(1)}}',
        );
  }
}
```

## 5. 化学方程式渲染

### 5.1 渲染策略

化学方程式采用**结构化数据 + 自定义 Widget** 方案，而非依赖 LaTeX `\ce{}` 宏（兼容性差）：

```dart
/// 化学方程式数据模型
class ChemicalEquation {
  final List<ChemTerm> reactants;  // 反应物
  final List<ChemTerm> products;   // 生成物
  final EquationConditions conditions; // 反应条件
  final EquationType type;         // 可逆/不可逆

  /// 从 mhchem 语法解析
  factory ChemicalEquation.parse(String mhchem) {
    final parser = MhchemParser();
    return parser.parse(mhchem);
  }
}

class ChemTerm {
  final String formula;  // "H2O"
  final String? coefficient; // "2"
  final String? state;   // "(g)", "(l)", "(s)", "(aq)"
}

class EquationConditions {
  final String? text;    // "加热", "点燃", "催化剂"
  final String? symbol;  // "△", "→", "⇌"
}
```

### 5.2 化学方程式 Widget

```dart
class _ChemistryWidget extends StatelessWidget {
  final ChemistryNode node;

  const _ChemistryWidget(this.node);

  @override
  Widget build(BuildContext context) {
    final equation = ChemicalEquation.parse(node.mhchem);

    return Container(
      padding: const EdgeInsets.symmetric(vertical: 12, horizontal: 16),
      margin: const EdgeInsets.symmetric(vertical: 8),
      decoration: BoxDecoration(
        color: Colors.teal.shade50,
        borderRadius: BorderRadius.circular(8),
        border: Border.all(color: Colors.teal.shade200),
      ),
      child: SingleChildScrollView(
        scrollDirection: Axis.horizontal,
        child: Row(
          mainAxisSize: MainAxisSize.min,
          crossAxisAlignment: CrossAxisAlignment.center,
          children: [
            // 反应物
            ..._buildTerms(equation.reactants, context),
            // 箭头 + 条件
            _buildArrow(equation, context),
            // 生成物
            ..._buildTerms(equation.products, context),
          ],
        ),
      ),
    );
  }

  List<Widget> _buildTerms(List<ChemTerm> terms, BuildContext context) {
    final widgets = <Widget>[];
    for (var i = 0; i < terms.length; i++) {
      if (i > 0) {
        widgets.add(Text(' + ', style: context.textTheme.bodyLarge));
      }
      widgets.add(_ChemFormula(terms[i]));
    }
    return widgets;
  }

  Widget _buildArrow(ChemicalEquation eq, BuildContext context) {
    return Padding(
      padding: const EdgeInsets.symmetric(horizontal: 12),
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          if (eq.conditions.text != null)
            Text(
              eq.conditions.text!,
              style: context.textTheme.labelSmall,
            ),
          Text(
            eq.type == EquationType.reversible ? '⇌' : '→',
            style: context.textTheme.headlineMedium,
          ),
        ],
      ),
    );
  }
}

        if (term.coefficient != null)
          Padding(
            padding: const EdgeInsets.only(right: 2),
            child: Text(
              term.coefficient!,
              style: context.textTheme.bodyLarge,
            ),
          ),
        _buildFormulaSpans(term.formula, context),
        if (term.state != null)
          Padding(
            padding: const EdgeInsets.only(left: 4),
            child: Text(
              term.state!,
              style: context.textTheme.bodySmall?.copyWith(
                color: context.colorScheme.onSurfaceVariant,
              ),
            ),
          ),
      ],
    );
  }

  /// 解析化学式中的数字为下标
  /// "H2SO4" → H₂SO₄
  Widget _buildFormulaSpans(String formula, BuildContext context) {
    final spans = <TextSpan>[];
    final buffer = StringBuffer();

    for (final char in formula.split('')) {
      if (_isDigit(char)) {
        if (buffer.isNotEmpty) {
          spans.add(TextSpan(text: buffer.toString()));
          buffer.clear();
        }
        spans.add(TextSpan(
          text: char,
          style: TextStyle(
            fontSize: (context.textTheme.bodyLarge?.fontSize ?? 16) * 0.7,
            fontFeatures: const [FontFeature.subscripts()],
          ),
        ));
      } else {
        buffer.write(char);
      }
    }
    if (buffer.isNotEmpty) {
      spans.add(TextSpan(text: buffer.toString()));
    }

    return RichText(text: TextSpan(children: spans));
  }
}
```

```dart
/// 几何图形绘制器
class GeometryPainter extends CustomPainter {
  final GeoShapeData data;

  GeometryPainter(this.data);

  @override
  void paint(Canvas canvas, Size size) {
    final scale = _computeScale(size);
    final offset = _computeOffset(size, scale);

    // 绘制网格背景（浅色辅助线）
    _drawGrid(canvas, size, scale, offset);

    for (final shape in data.shapes) {
      switch (shape) {
        case GeoLineSegment line:
          _drawLine(canvas, line, scale, offset);
        case GeoCircle circle:
          _drawCircle(canvas, circle, scale, offset);
        case GeoAngle angle:
          _drawAngle(canvas, angle, scale, offset);
        case GeoTriangle triangle:
          _drawTriangle(canvas, triangle, scale, offset);
        default:
          break;
      }
    }

    // 绘制标签
    for (final label in data.labels) {
      _drawLabel(canvas, label, scale, offset);
    }
  }

  void _drawLine(Canvas canvas, GeoLineSegment line, double scale, Offset offset) {
    final paint = Paint()
      ..color = _parseColor(line.color) ?? Colors.black
      ..strokeWidth = line.strokeWidth
      ..style = PaintingStyle.stroke;

    if (line.dashed) {
      // 虚线（辅助线）
      paint.pathEffect = ui.PathEffect.dash([6, 4]);
    }

    final start = _transform(line.start, scale, offset);
    final end = _transform(line.end, scale, offset);

    canvas.drawLine(start, end, paint);

    // 绘制箭头
    if (line.arrow != GeoArrowType.none) {
      _drawArrowHead(canvas, start, end, paint, line.arrow);
    }
  }

  void _drawAngle(Canvas canvas, GeoAngle angle, double scale, Offset offset) {
    final vertex = _transform(angle.vertex, scale, offset);
    final r1 = _transform(angle.ray1End, scale, offset);
    final r2 = _transform(angle.ray2End, scale, offset);

    final paint = Paint()
      ..color = Colors.blue.shade200
      ..style = PaintingStyle.fill;

    // 绘制角度扇形
    final startAngle = (r1 - vertex).direction;
    final endAngle = (r2 - vertex).direction;
    final radius = 20.0;

    canvas.drawArc(
      Rect.fromCircle(center: vertex, radius: radius),
      startAngle,
      endAngle - startAngle,
      false,
      Paint()
        ..color = Colors.blue.shade400
        ..strokeWidth = 1.5
        ..style = PaintingStyle.stroke,
    );

    // 角度标签
    if (angle.degreeLabel != null) {
      final labelAngle = (startAngle + endAngle) / 2;
      final labelOffset = Offset(
        vertex.dx + (radius + 12) * cos(labelAngle),
        vertex.dy + (radius + 12) * sin(labelAngle),
      );
      final textPainter = TextPainter(
        text: TextSpan(
          text: angle.degreeLabel,
          style: const TextStyle(fontSize: 12, color: Colors.blue),
        ),
        textDirection: TextDirection.ltr,
      )..layout();
      textPainter.paint(canvas, labelOffset);
    }
  }

  Offset _transform(GeoPoint p, double scale, Offset offset) {
    return Offset(
      (p.x - data.viewport.minX) * scale + offset.dx,
      size.height - ((p.y - data.viewport.minY) * scale + offset.dy),
    );
  }

  double _computeScale(Size size) {
    final vw = data.viewport.maxX - data.viewport.minX;
    final vh = data.viewport.maxY - data.viewport.minY;
    final padding = 40.0;
    return min(
      (size.width - padding * 2) / vw,
      (size.height - padding * 2) / vh,
    );
  }

  @override
  bool shouldRepaint(covariant GeometryPainter oldDelegate) =>
      oldDelegate.data != data;
}
```

## 11. 流式渲染（SSE 场景）

### 11.1 流式内容处理

AI 回答通过 SSE（Server-Sent Events）流式返回，渲染引擎需支持**增量渲染**：

```dart
/// 流式渲染控制器
class StreamingRenderController extends ChangeNotifier {
  final StringBuffer _buffer = StringBuffer();
  List<RenderNode> _nodes = [];
  bool _isComplete = false;

  List<RenderNode> get nodes => _nodes;
  bool get isComplete => _isComplete;

  /// 追加 SSE 数据块
  void append(String chunk) {
    _buffer.write(chunk);
    _reparse();
  }

  /// 标记流结束
  void complete() {
    _isComplete = true;
    _reparse(); // 最终完整解析
    notifyListeners();
  }

  /// 增量解析策略：仅解析到最后一个完整块
  void _reparse() {
    final content = _buffer.toString();
    final parser = RichMarkdownParser();

    // 流式中，只解析到最后一个完整标记
    // 未闭合的 :::type 块和 $$ 公式暂不解析
    final safeContent = _truncateToLastCompleteBlock(content);
    _nodes = parser.parse(safeContent);
    notifyListeners();
  }

  /// 截断到最后一个完整的自定义块/公式
  String _truncateToLastCompleteBlock(String content) {
    // 检查未闭合的自定义块
    final openBlocks = ':::'.allMatches(content).length;
    if (openBlocks.isOdd) {
      // 有未闭合的块，截断到最后一个 ::: 之前
      final lastOpen = content.lastIndexOf(':::');
      if (lastOpen > 0) {
        return content.substring(0, lastOpen);
      }
    }

    // 检查未闭合的 $$ 公式
    final dollarCount = '$$'.allMatches(content).length;
    if (dollarCount.isOdd) {
      final lastDollar = content.lastIndexOf('\$\$');
      if (lastDollar > 0) {
        return content.substring(0, lastDollar);
      }
    }

    return content;
  }

  void reset() {
    _buffer.clear();
    _nodes = [];
    _isComplete = false;
    notifyListeners();
  }
}
```

```dart
  /// 公式 → 渲染 Widget 缓存（LRU，最多 200 条）
  static final _mathCache = LruCache<String, Widget>(maxSize: 200);

  /// Markdown → RenderNode 树缓存
  static final _astCache = LruCache<String, List<RenderNode>>(maxSize: 50);

  /// 获取缓存的 AST
  static List<RenderNode>? getCachedAST(String markdownHash) {
    return _astCache.get(markdownHash);
  }

  /// 缓存 AST
  static void cacheAST(String markdownHash, List<RenderNode> nodes) {
    _astCache.put(markdownHash, nodes);
  }

  /// 公式渲染缓存
  static Widget? getCachedMath(String latex) {
    return _mathCache.get(latex);
  }

  static void cacheMath(String latex, Widget widget) {
    _mathCache.put(latex, widget);
  }
}
```

### 12.3 公式预渲染

```dart
/// 后台预渲染常用公式
class MathPreRenderer {
  static final _queue = <String>[];
  static Timer? _timer;

  /// 将常用公式加入预渲染队列
  static void enqueue(String latex) {
    if (!MathRenderCache.isCached(latex) && !_queue.contains(latex)) {
      _queue.add(latex);
      _scheduleBatch();
    }
  }

  static void _scheduleBatch() {
    _timer ??= Timer(const Duration(milliseconds: 100), _renderBatch);
  }

  static void _renderBatch() {
    _timer = null;
    final batch = _queue.take(10).toList();
    _queue.removeRange(0, batch.length);

    for (final latex in batch) {
      // 在后台 isolate 中预渲染
      compute(_renderInIsolate, latex).then((picture) {
        if (picture != null) {
          MathRenderCache.put(latex, MathStyle.display, picture);
        }
      });
    }

    if (_queue.isNotEmpty) {
      _scheduleBatch();
    }
  }
}
```

## 13. 降级策略

### 13.1 渲染降级链

```
flutter_math_fork 原生渲染
    │ 失败 ↓
LaTeX → 图片 URL（后端备选渲染服务）
    │ 失败 ↓
纯文本 Monospace 显示（带公式源码）
```

```dart
class FallbackMathWidget extends StatelessWidget {
  final String latex;
  final String? imageUrl;

  const FallbackMathWidget({
    super.key,
    required this.latex,
    this.imageUrl,
  });

  @override
  Widget build(BuildContext context) {
    // 1. 尝试原生渲染
    try {
      return Math.tex(
        latex,
        textStyle: context.textTheme.bodyLarge,
        onErrorFallback: (err) => throw err,
      );
    } catch (_) {}

    // 2. 尝试图片渲染
    if (imageUrl != null) {
      return CachedNetworkImage(
        imageUrl: imageUrl!,
        errorWidget: (_, __, ___) => _buildPlainText(context),
      );
    }

    // 3. 纯文本降级
    return _buildPlainText(context);
  }

  Widget _buildPlainText(BuildContext context) {
    return Container(
      padding: const EdgeInsets.all(8),
      color: Colors.grey.shade100,
      child: SelectableText(
        latex,
        style: const TextStyle(fontFamily: 'monospace', fontSize: 13),
      ),
    );
  }
}
```

## 20. 错误处理

| 场景 | 错误 | 处理 |
|------|------|------|
| LaTeX 语法错误 | `flutter_math_fork` 抛异常 | 捕获，降级为文本显示 |
| 自定义块标记未闭合 | 解析时找不到结束 `:::` | 截断到上一个完整块，未闭合部分暂不显示 |
| JSON 属性解析失败 | `:::geo{json="..."}:::` 中 JSON 格式错误 | 跳过该块，显示"图形加载失败" |
| 后端图片 URL 404 | `CachedNetworkImage` 加载失败 | 显示占位图 + 重试按钮 |
| 字体未加载 | IPA 字体未就绪时渲染音标 | 使用系统字体 fallback |
| 内存不足 | 大量公式渲染导致内存压力 | 清空 LRU 缓存，启用懒加载 |

```dart
/// 全局错误边界
class RenderErrorBoundary extends StatelessWidget {
  final Widget child;
  final Widget Function(Object error)? errorBuilder;

  const RenderErrorBoundary({
    super.key,
    required this.child,
    this.errorBuilder,
  });

  @override
  Widget build(BuildContext context) {
    return ErrorBoundary(
      builder: (context, error, stackTrace) {
        // 上报渲染错误
        Crashlytics.recordError(error, stackTrace, reason: 'render_error');

        return errorBuilder?.call(error) ??
            Container(
              padding: const EdgeInsets.all(8),
              color: Colors.grey.shade100,
              child: Row(
                children: [
                  Icon(Icons.broken_image, color: Colors.grey.shade400),
                  const SizedBox(width: 8),
                  Text(
                    '内容渲染异常',
                    style: TextStyle(color: Colors.grey.shade500),
                  ),
                ],
              ),
            );
      },
      child: child,
    );
  }
}
```
