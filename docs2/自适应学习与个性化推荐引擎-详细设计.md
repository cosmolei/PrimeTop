# 自适应学习与个性化推荐引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

自适应学习与个性化推荐引擎（Adaptive Learning & Personalized Recommendation Engine，简称 ALP）是 PrimeTop 的核心差异化模块。它消费学情分析、知识点体系、题库服务等模块的数据，通过知识掌握度建模、遗忘曲线追踪、知识依赖图遍历等算法，为每位学生构建个性化的学习路径，并实时推荐适合当前能力水平的学习内容和练习题。

ALP 的核心理念是 **维果斯基"最近发展区"（ZPD）理论**——始终让学生在"跳一跳够得着"的难度区间内学习，既不因太简单而无聊，也不因太难而挫败。

### 1.2 核心目标

| 目标 | 指标 |
| --- | --- |
| 学习效率提升 | 相比固定路径，同等时间掌握更多知识点 |
| 用户黏性增强 | 推荐内容点击率 > 60%，练习完成率 > 75% |
| 学习路径合理 | 前置知识未掌握时不推送进阶内容 |
| 难度自适应 | 连续答对自动升级，连续答错自动降级 |
| 遗忘曲线干预 | 在最佳复习时间点自动推送复习任务 |

### 1.3 优先级与迭代规划

| 阶段 | 功能范围 | 版本 |
| --- | --- | --- |
| MVP | 基础难度自适应 + 薄弱知识点定向推送 | V1.0 |
| V1 | 遗忘曲线复习调度 + 学习路径图 | V1.5 |
| V2 | IRT 模型 + 多维能力画像推荐 | V2.0 |

本文档覆盖 V1 的完整设计，标注 MVP 裁剪范围。

## 2. 核心算法设计

### 2.1 知识掌握度扩展模型

学情分析模块已提供基础掌握度计算（0-100 分），ALP 在此基础上引入 **知识状态机** 和 **稳定性指标**。

#### 2.1.1 知识状态机

```
           首次接触
              │
              ▼
          ┌───────┐
          │  NEW  │  未学习 / 已遗忘
          └───┬───┘
              │ 答对1次 或 学习时长>5min
              ▼
       ┌──────────┐
       │ EXPOSED  │  已接触但未巩固
       └────┬─────┘
            │ 连续2次答对 且 掌握度≥40
            ▼
      ┌───────────┐
      │ LEARNING  │  学习中
      └─────┬─────┘
            │ 掌握度≥70 且 稳定性≥0.6
            ▼
     ┌────────────┐
     │ MASTERED   │  已掌握
     └─────┬──────┘
           │ 30天未复习 且 稳定性降至0.3以下
           ▼
     ┌────────────┐
     │ DECAYING   │  遗忘中（需复习）
     └────────────┘
```

#### 2.1.2 知识稳定性指标（Memory Stability）

基于 SuperMemo SM-2 算法的简化版本，评估记忆的牢固程度：

```python
@dataclass
class KnowledgeState:
    """知识点学习状态（ALP 内部模型）"""
    user_id: int
    knowledge_point_id: int
    status: str                    # NEW / EXPOSED / LEARNING / MASTERED / DECAYING
    mastery_level: float           # 来自学情分析模块 (0-100)
    stability: float               # 记忆稳定性 (0-1)
    difficulty_estimate: float     # 该学生对此知识点的感知难度 (0-5)
    repetition_count: int          # 复习次数
    last_review_at: datetime       # 最后复习时间
    next_review_at: datetime       # 下次建议复习时间
    easiness_factor: float         # 容易度因子 (≥1.3)
    
    def update_after_review(self, quality: int):
        """
        复习后更新状态
        
        Args:
            quality: 回忆质量评分 (0-5)
                5 - 完美回忆
                4 - 犹豫后正确
                3 - 艰难但正确
                2 - 错误但似曾相识
                1 - 错误，毫无印象
                0 - 完全不记得
        
        SM-2 核心逻辑:
        - EF' = EF + (0.1 - (5-q)*(0.08+(5-q)*0.02))
        - interval(n) = interval(n-1) * EF
        """
        # 更新容易度因子
        self.easiness_factor = max(
            1.3,
            self.easiness_factor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
        )
        
        # 根据质量评分调整难度估计
        if quality >= 4:
            self.difficulty_estimate = max(0, self.difficulty_estimate - 0.1)
        elif quality <= 2:
            self.difficulty_estimate = min(5, self.difficulty_estimate + 0.2)
        
        # 更新复习次数和下次间隔
        self.repetition_count += 1
        self.last_review_at = datetime.utcnow()
        
        if quality < 3:
            # 回忆失败，重置间隔
            self.repetition_count = 0
            self.next_review_at = datetime.utcnow() + timedelta(minutes=10)
            self.stability *= 0.5
        else:
            # 计算下次复习间隔
            if self.repetition_count == 1:
                interval_days = 1
            elif self.repetition_count == 2:
                interval_days = 6
            else:
                prev_interval = (self.next_review_at - self.last_review_at).days or 1
                interval_days = round(prev_interval * self.easiness_factor)
            
            self.next_review_at = datetime.utcnow() + timedelta(days=interval_days)
            self.stability = min(1.0, self.stability + 0.1 * (quality / 5))
        
        # 更新状态
        self._update_status()
    
    def _update_status(self):
        """根据指标更新状态"""
        if self.mastery_level < 10 and self.repetition_count == 0:
            self.status = 'NEW'
        elif self.stability < 0.3 and self.repetition_count > 0:
            self.status = 'DECAYING'
        elif self.mastery_level >= 70 and self.stability >= 0.6:
            self.status = 'MASTERED'
        elif self.mastery_level >= 40:
            self.status = 'LEARNING'
        else:
            self.status = 'EXPOSED'
    
    def get_urgency(self) -> float:
        """
        计算该知识点的复习紧急度 (0-100)
        用于排序推荐队列
        """
        now = datetime.utcnow()
        score = 0.0
        
        # 因素1: 是否过了复习时间（权重 40%）
        if self.next_review_at and now > self.next_review_at:
            overdue_hours = (now - self.next_review_at).total_seconds() / 3600
            score += min(overdue_hours / 24 * 100, 100) * 0.4
        elif self.next_review_at:
            hours_until = (self.next_review_at - now).total_seconds() / 3600
            if hours_until < 6:
                score += (1 - hours_until / 6) * 100 * 0.4
        
        # 因素2: 掌握度越低越紧急（权重 30%）
        score += (100 - self.mastery_level) * 0.3
        
        # 因素3: 稳定性越低越紧急（权重 30%）
        score += (1 - self.stability) * 100 * 0.3
        
        return min(100, score)
```

### 2.2 难度自适应算法

#### 2.2.1 学生能力估计（ELO Rating 简化模型）

采用类似 ELO 等级分系统的简化模型来估计学生在每个学科上的能力值，并用于题目难度匹配。

```python
@dataclass
class StudentAbility:
    """学生学科能力值"""
    user_id: int
    subject_code: str
    ability_score: float       # 能力值 (初始 1000)
    confidence: float          # 置信度 (0-1, 题目数越多越高)
    total_attempts: int
    last_updated: datetime

@dataclass
class DifficultyCalibration:
    """题目难度校准值（由系统维护）"""
    question_id: int
    difficulty_score: float    # 难度值 (初始 1000)
    attempt_count: int         # 答题人数
    correct_count: int         # 答对人数
    source: str                # MANUAL / AI_ESTIMATE / CALIBRATED

class DifficultyAdaptiveEngine:
    """难度自适应引擎"""
    
    K_FACTOR = 32              # ELO K因子，控制更新幅度
    TARGET_WIN_RATE = 0.75     # 目标准确率（ZPD上界）
    MIN_WIN_RATE = 0.50        # 最低准确率（ZPD下界）
    
    def update_after_answer(
        self,
        student: StudentAbility,
        question: DifficultyCalibration,
        is_correct: bool
    ) -> tuple[StudentAbility, DifficultyCalibration]:
        """
        答题后双向更新学生能力值和题目难度
        
        Returns:
            更新后的 (学生能力, 题目难度)
        """
        # 期望得分（基于ELO公式）
        expected = 1 / (1 + 10 ** ((question.difficulty_score - student.ability_score) / 400))
        actual = 1.0 if is_correct else 0.0
        
        # K因子随置信度递减
        student_k = self.K_FACTOR * max(0.3, 1 - student.confidence * 0.7)
        question_k = self.K_FACTOR * max(0.3, 1 - min(question.attempt_count / 100, 1) * 0.7)
        
        # 更新学生能力值
        student.ability_score += student_k * (actual - expected)
        student.ability_score = max(200, min(2000, student.ability_score))
        student.total_attempts += 1
        student.confidence = min(1.0, student.total_attempts / 100)
        student.last_updated = datetime.utcnow()
        
        # 更新题目难度
        question.difficulty_score -= question_k * (actual - expected)
        question.difficulty_score = max(200, min(2000, question.difficulty_score))
        question.attempt_count += 1
        if is_correct:
            question.correct_count += 1
        if question.attempt_count >= 50:
            question.source = 'CALIBRATED'
        
        return student, question
    
    def select_difficulty_range(self, student: StudentAbility) -> tuple[float, float]:
        """
        为学生选择合适的题目难度区间
        
        基于目标准确率反推难度范围：
        - 期望正确率 = 50%~75%（ZPD区间）
        - 反推难度：ability - 400*log10(p/(1-p))
        """
        # 下界：期望正确率 75%（较简单）
        lower_bound = student.ability_score - 400 * math.log10(
            self.TARGET_WIN_RATE / (1 - self.TARGET_WIN_RATE)
        )
        # 上界：期望正确率 50%（有挑战）
        upper_bound = student.ability_score
        
        # 置信度低时扩大范围（探索）
        uncertainty_factor = 1 + (1 - student.confidence) * 0.5
        range_center = (lower_bound + upper_bound) / 2
        range_half = (upper_bound - lower_bound) / 2 * uncertainty_factor
        
        return (range_center - range_half, range_center + range_half)
```

#### 2.2.2 难度校准策略

```
题目难度值来源优先级:
1. CALIBRATED   - 已有≥50人作答，通过ELO校准     → 可信度最高
2. MANUAL       - 教研人员手动标注                  → 中等可信度
3. AI_ESTIMATE  - AI 根据知识点、题型预估           → 初始可信度

新题入库流程:
  AI预估难度 → 入库(difficulty_source=AI_ESTIMATE)
  → 积累答题数据 → ≥50人后转为 CALIBRATED
```

### 2.3 学习路径构建算法

#### 2.3.1 知识依赖图与拓扑排序

```python
class LearningPathBuilder:
    """学习路径构建器"""
    
    def __init__(self, knowledge_service, mastery_service):
        self.knowledge_service = knowledge_service
        self.mastery_service = mastery_service
    
    async def build_personalized_path(
        self,
        user_id: int,
        subject_code: str,
        target_knowledge_point_id: int,
        max_depth: int = 20
    ) -> list[PathNode]:
        """
        构建从当前状态到目标知识点的个性化学习路径
        
        算法:
        1. 从目标知识点反向BFS，获取所有前置知识依赖链
        2. 拓扑排序，确保前置知识在前
        3. 标记每个节点的掌握状态
        4. 裁剪已掌握节点，保留需要学习/复习的节点
        5. 在未掌握节点间插入过渡练习
        
        Args:
            target_knowledge_point_id: 目标知识点ID
            max_depth: 路径最大深度限制
        
        Returns:
            排序后的学习路径节点列表
        """
        # Step 1: 获取依赖子图
        dependency_graph = await self.knowledge_service.get_prerequisite_subgraph(
            target_knowledge_point_id, max_depth
        )
        
        # Step 2: 获取用户在各知识点的掌握状态
        kp_ids = [node.id for node in dependency_graph]
        masteries = await self.mastery_service.batch_get_mastery(user_id, kp_ids)
        mastery_map = {m.knowledge_point_id: m for m in masteries}
        
        # Step 3: 拓扑排序
        sorted_nodes = self._topological_sort(dependency_graph)
        
        # Step 4: 构建路径节点
        path = []
        for node in sorted_nodes:
            mastery = mastery_map.get(node.id)
            status = mastery.status if mastery else 'NEW'
            mastery_level = mastery.mastery_level if mastery else 0
            
            # 已掌握且稳定的节点可以跳过
            if status == 'MASTERED' and mastery.stability >= 0.7:
                continue
            
            path_node = PathNode(
                knowledge_point_id=node.id,
                point_name=node.name,
                status=status,
                mastery_level=mastery_level,
                node_type=self._classify_node_type(status, mastery_level),
                estimated_duration_min=self._estimate_duration(status, node),
                prerequisite_ids=node.prerequisite_ids,
                recommended_activities=self._generate_activities(status, node)
            )
            path.append(path_node)
        
        # Step 5: 插入过渡练习
        path = self._insert_transition_practice(path, user_id, subject_code)
        
        return path
    
    def _classify_node_type(self, status: str, mastery_level: float) -> str:
        """分类路径节点类型"""
        if status == 'NEW':
            return 'LEARN'          # 需要学习新知识
        elif status == 'DECAYING':
            return 'REVIEW'         # 需要复习
        elif status in ('EXPOSED', 'LEARNING') and mastery_level < 50:
            return 'PRACTICE'       # 需要练习巩固
        else:
            return 'ADVANCE'        # 可以进阶
    
    def _estimate_duration(self, status: str, node) -> int:
        """估算学习时长（分钟）"""
        base = {
            'NEW': 20,
            'EXPOSED': 15,
            'LEARNING': 10,
            'MASTERED': 5,          # 稳定性不足的已掌握节点
            'DECAYING': 8
        }
        return base.get(status, 15)
    
    def _generate_activities(self, status: str, node) -> list[dict]:
        """为路径节点生成推荐活动"""
        if status == 'NEW':
            return [
                {'type': 'VIDEO', 'desc': f'观看「{node.name}」知识点讲解'},
                {'type': 'AI_TUTOR', 'desc': f'与AI对话学习「{node.name}」'},
                {'type': 'PRACTICE', 'desc': f'完成基础练习题 3 道'},
            ]
        elif status == 'DECAYING':
            return [
                {'type': 'FLASHCARD', 'desc': f'复习「{node.name}」核心概念'},
                {'type': 'PRACTICE', 'desc': f'完成复习题 2 道'},
            ]
        elif status in ('EXPOSED', 'LEARNING'):
            return [
                {'type': 'PRACTICE', 'desc': f'完成巩固练习 3-5 道'},
                {'type': 'AI_TUTOR', 'desc': f'针对性提问解决疑惑'},
            ]
        return [{'type': 'CHALLENGE', 'desc': f'挑战进阶题'}]
    
    def _insert_transition_practice(
        self, path: list, user_id: int, subject_code: str
    ) -> list:
        """
        在学习路径中插入过渡练习
        
        当连续两个 LEARN 节点之间没有 PRACTICE 时，插入一个过渡练习节点，
        帮助巩固前置知识后再学新内容。
        """
        result = []
        for i, node in enumerate(path):
            result.append(node)
            if (node.node_type == 'LEARN' 
                and i + 1 < len(path) 
                and path[i + 1].node_type == 'LEARN'):
                result.append(PathNode(
                    knowledge_point_id=None,
                    point_name='过渡练习',
                    node_type='TRANSITION_PRACTICE',
                    recommended_activities=[
                        {'type': 'PRACTICE', 'desc': '综合练习 2 道'}
                    ]
                ))
        return result
    
    def _topological_sort(self, graph) -> list:
        """拓扑排序，保证前置知识在前"""
        in_degree = {}
        adj = {}
        nodes = {}
        
        for node in graph:
            nodes[node.id] = node
            in_degree.setdefault(node.id, 0)
            adj.setdefault(node.id, [])
            for dep_id in node.prerequisite_ids:
                adj.setdefault(dep_id, []).append(node.id)
                in_degree[node.id] = in_degree.get(node.id, 0) + 1
        
        queue = deque([nid for nid, deg in in_degree.items() if deg == 0])
        result = []
        
        while queue:
            nid = queue.popleft()
            result.append(nodes[nid])
            for neighbor in adj.get(nid, []):
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
        
        return result
```

### 2.4 综合推荐策略

#### 2.4.1 推荐上下文与权重

```python
@dataclass
class RecommendationContext:
    """推荐请求上下文"""
    user_id: int
    subject_code: str | None = None     # 指定学科
    chapter_id: int | None = None       # 指定章节
    scene: str = 'HOME'                 # 场景: HOME / AFTER_ANSWER / REVIEW / FREE_PRACTICE
    time_available_min: int | None = None  # 可用时间
    question_count: int = 10            # 期望推荐数量

class AdaptiveRecommendationService:
    """自适应推荐服务（主入口）"""
    
    # 场景 → 策略权重配置
    SCENE_STRATEGY_WEIGHTS = {
        'HOME': {                    # 首页推荐
            'review': 0.35,          # 遗忘曲线复习
            'weak_point': 0.30,      # 薄弱点强化
            'current_chapter': 0.20, # 当前章节同步
            'advance': 0.15          # 进阶拓展
        },
        'AFTER_ANSWER': {            # 答题后推荐
            'similar': 0.50,         # 同类题
            'weak_point': 0.30,      # 薄弱点
            'next_knowledge': 0.20   # 下个知识点
        },
        'REVIEW': {                  # 复习模式
            'due_review': 0.60,      # 到期复习
            'failing_review': 0.25,  # 稳定性下降
            'random_review': 0.15    # 随机复习
        },
        'FREE_PRACTICE': {           # 自由练习
            'weak_point': 0.30,
            'current_chapter': 0.30,
            'advance': 0.25,
            'random': 0.15
        }
    }
    
    async def recommend(
        self, context: RecommendationContext
    ) -> RecommendationResult:
        """
        综合推荐入口
        
        根据场景选择策略组合，加权融合后返回推荐结果
        """
        weights = self.SCENE_STRATEGY_WEIGHTS.get(
            context.scene, self.SCENE_STRATEGY_WEIGHTS['HOME']
        )
        
        # 获取学生能力值（用于难度匹配）
        ability = await self._get_student_ability(context.user_id, context.subject_code)
        difficulty_range = self.difficulty_engine.select_difficulty_range(ability)
        
        # 并行执行各策略
        tasks = {
            'review': self._strategy_review(context, difficulty_range),
            'weak_point': self._strategy_weak_point(context, difficulty_range),
            'current_chapter': self._strategy_current_chapter(context, difficulty_range),
            'advance': self._strategy_advance(context, difficulty_range),
            'similar': self._strategy_similar(context, difficulty_range),
            'next_knowledge': self._strategy_next_knowledge(context, difficulty_range),
            'due_review': self._strategy_due_review(context, difficulty_range),
            'failing_review': self._strategy_failing_review(context, difficulty_range),
            'random_review': self._strategy_random_review(context, difficulty_range),
            'random': self._strategy_random(context, difficulty_range),
        }
        
        # 只获取当前场景需要的策略结果
        strategy_results = {}
        coros = []
        for strategy_name, weight in weights.items():
            if weight > 0 and strategy_name in tasks:
                coros.append((strategy_name, tasks[strategy_name]))
        
        for name, coro in coros:
            try:
                strategy_results[name] = await coro
            except Exception as e:
                logger.warning(f"Strategy {name} failed: {e}")
                strategy_results[name] = []
        
        # 按权重分配名额
        total = context.question_count
        result_items = []
        
        for strategy_name, weight in sorted(weights.items(), key=lambda x: -x[1]):
            items = strategy_results.get(strategy_name, [])
            quota = max(1, round(total * weight))
            result_items.extend(items[:quota])
        
        # 去重、打散
        result_items = self._deduplicate_and_shuffle(result_items, total)
        
        # 填充不足的名额
        if len(result_items) < total:
            filler = await self._get_filler_questions(
                context, difficulty_range, total - len(result_items),
                exclude_ids={item.question_id for item in result_items}
            )
            result_items.extend(filler)
        
        return RecommendationResult(
            items=result_items[:total],
            ability_snapshot=ability,
            difficulty_range=difficulty_range,
            strategies_used=list(weights.keys())
        )
    
    # --- 各策略实现 ---
    
    async def _strategy_review(
        self, context: RecommendationContext, diff_range: tuple
    ) -> list[RecommendationItem]:
        """遗忘曲线复习策略：获取到期需复习的知识点对应题目"""
        due_states = await self.knowledge_state_repo.get_due_for_review(
            user_id=context.user_id,
            subject_code=context.subject_code,
            limit=20
        )
        if not due_states:
            return []
        
        # 按紧急度排序
        due_states.sort(key=lambda s: s.get_urgency(), reverse=True)
        
        items = []
        for state in due_states[:5]:
            questions = await self.question_service.search(
                knowledge_point_ids=[state.knowledge_point_id],
                difficulty_range=diff_range,
                limit=2,
                exclude_answered=False
            )
            for q in questions:
                items.append(RecommendationItem(
                    question_id=q.id,
                    knowledge_point_id=state.knowledge_point_id,
                    reason='DUE_REVIEW',
                    reason_desc=f'复习「{state.knowledge_point_name}」（到期复习）',
                    priority=state.get_urgency(),
                    difficulty=q.difficulty_score
                ))
        return items
    
    async def _strategy_weak_point(
        self, context: RecommendationContext, diff_range: tuple
    ) -> list[RecommendationItem]:
        """薄弱点强化策略"""
        weak_points = await self.mastery_service.get_weak_points(
            user_id=context.user_id,
            subject_code=context.subject_code,
            limit=5
        )
        
        items = []
        for wp in weak_points:
            # 薄弱点从较低难度开始
            adjusted_range = (
                max(diff_range[0] - 200, 200),
                min(diff_range[0], diff_range[1])
            )
            questions = await self.question_service.search(
                knowledge_point_ids=[wp.knowledge_point_id],
                difficulty_range=adjusted_range,
                limit=2
            )
            for q in questions:
                items.append(RecommendationItem(
                    question_id=q.id,
                    knowledge_point_id=wp.knowledge_point_id,
                    reason='WEAK_POINT',
                    reason_desc=f'强化练习「{wp.point_name}」',
                    priority=wp.urgency_score,
                    difficulty=q.difficulty_score
                ))
        return items
    
    async def _strategy_current_chapter(
        self, context: RecommendationContext, diff_range: tuple
    ) -> list[RecommendationItem]:
        """当前章节同步练习策略"""
        chapter = context.chapter_id or await self._get_current_chapter(
            context.user_id, context.subject_code
        )
        if not chapter:
            return []
        
        questions = await self.question_service.search(
            chapter_id=chapter,
            difficulty_range=diff_range,
            limit=5
        )
        return [
            RecommendationItem(
                question_id=q.id,
                chapter_id=chapter,
                reason='CURRENT_CHAPTER',
                reason_desc='当前章节同步练习',
                difficulty=q.difficulty_score
            ) for q in questions
        ]
    
    async def _strategy_advance(
        self, context: RecommendationContext, diff_range: tuple
    ) -> list[RecommendationItem]:
        """进阶拓展策略：推荐下一个未学习的知识点"""
        next_kps = await self.knowledge_service.get_next_knowledge_points(
            user_id=context.user_id,
            subject_code=context.subject_code,
            mastery_threshold=70,
            limit=3
        )
        
        items = []
        for kp in next_kps:
            questions = await self.question_service.search(
                knowledge_point_ids=[kp.id],
                difficulty_range=(diff_range[0], diff_range[1] - 100),  # 稍简单
                limit=2
            )
            for q in questions:
                items.append(RecommendationItem(
                    question_id=q.id,
                    knowledge_point_id=kp.id,
                    reason='ADVANCE',
                    reason_desc=f'探索新知识「{kp.name}」',
                    difficulty=q.difficulty_score
                ))
        return items
    
    async def _strategy_similar(
        self, context: RecommendationContext, diff_range: tuple
    ) -> list[RecommendationItem]:
        """同类题推荐策略（答题后场景）"""
        # 从上下文获取最近答过的题
        last_question_id = context.extra.get('last_question_id')
        if not last_question_id:
            return []
        
        similar = await self.question_service.get_similar_questions(
            question_id=last_question_id,
            difficulty_range=diff_range,
            count=5
        )
        return [
            RecommendationItem(
                question_id=q.id,
                reason='SIMILAR',
                reason_desc='举一反三练习',
                difficulty=q.difficulty_score
            ) for q in similar
        ]
    
    async def _strategy_due_review(self, context, diff_range):
        return await self._strategy_review(context, diff_range)
    
    async def _strategy_failing_review(self, context, diff_range):
        """稳定性下降复习"""
        failing = await self.knowledge_state_repo.get_decaying_states(
            user_id=context.user_id,
            subject_code=context.subject_code,
            limit=10
        )
        items = []
        for s in failing:
            questions = await self.question_service.search(
                knowledge_point_ids=[s.knowledge_point_id],
                difficulty_range=(diff_range[0] - 100, diff_range[0] + 100),
                limit=2
            )
            for q in questions:
                items.append(RecommendationItem(
                    question_id=q.id,
                    knowledge_point_id=s.knowledge_point_id,
                    reason='FAILING_REVIEW',
                    reason_desc=f'巩固「{s.knowledge_point_name}」防遗忘',
                    difficulty=q.difficulty_score
                ))
        return items
    
    async def _strategy_random_review(self, context, diff_range):
        """随机已学知识点复习"""
        learned = await self.knowledge_state_repo.get_random_learned(
            user_id=context.user_id,
            subject_code=context.subject_code,
            limit=5
        )
        items = []
        for s in learned:
            questions = await self.question_service.search(
                knowledge_point_ids=[s.knowledge_point_id],
                difficulty_range=diff_range,
                limit=1
            )
            for q in questions:
                items.append(RecommendationItem(
                    question_id=q.id,
                    reason='RANDOM_REVIEW',
                    reason_desc='温故知新',
                    difficulty=q.difficulty_score
                ))
        return items
    
    async def _strategy_random(self, context, diff_range):
        """随机推荐"""
        questions = await self.question_service.search(
            subject_code=context.subject_code,
            difficulty_range=diff_range,
            limit=5,
            random_order=True
        )
        return [
            RecommendationItem(
                question_id=q.id,
                reason='RANDOM',
                reason_desc='随机练习',
                difficulty=q.difficulty_score
            ) for q in questions
        ]
    
    async def _strategy_next_knowledge(self, context, diff_range):
        return await self._strategy_advance(context, diff_range)
```

### 5.1 推荐服务主流程（TypeScript）

```typescript
// src/services/alp/RecommendationService.ts

import { Injectable, Logger } from '@nestjs/common';
import { RecommendationContext, RecommendationItem, RecommendationResult } from './types';
import { DifficultyAdaptiveEngine } from './DifficultyEngine';
import { KnowledgeStateRepository } from '../repositories/KnowledgeStateRepository';
import { QuestionServiceClient } from '../clients/QuestionServiceClient';
import { MasteryServiceClient } from '../clients/MasteryServiceClient';

@Injectable()
export class RecommendationService {
  private readonly logger = new Logger(RecommendationService.name);

  constructor(
    private readonly difficultyEngine: DifficultyAdaptiveEngine,
    private readonly knowledgeStateRepo: KnowledgeStateRepository,
    private readonly questionClient: QuestionServiceClient,
    private readonly masteryClient: MasteryServiceClient,
  ) {}

  async recommend(ctx: RecommendationContext): Promise<RecommendationResult> {
    // 1. 获取能力值和难度区间
    const ability = await this.getStudentAbility(ctx.userId, ctx.subjectCode);
    const diffRange = this.difficultyEngine.selectDifficultyRange(ability);

    // 2. 并行拉取各策略候选
    const candidates = await Promise.allSettled([
      this.getReviewCandidates(ctx, diffRange),
      this.getWeakPointCandidates(ctx, diffRange),
      this.getCurrentChapterCandidates(ctx, diffRange),
      this.getAdvanceCandidates(ctx, diffRange),
    ]);

    // 3. 按场景权重分配名额
    const weights = SCENE_WEIGHTS[ctx.scene] ?? SCENE_WEIGHTS.HOME;
    const items = this.allocateAndMerge(
      candidates, weights, ctx.questionCount
    );

    // 4. 记录推荐日志（异步，不阻塞）
    const batchId = uuid();
    this.logRecommendation(ctx, batchId, items, ability).catch(() => {});

    return {
      batchId,
      items: items.slice(0, ctx.questionCount),
      abilitySnapshot: ability,
      difficultyRange: diffRange,
    };
  }

  private allocateAndMerge(
    results: PromiseSettledResult<RecommendationItem[]>[],
    weights: Record<string, number>,
    total: number,
  ): RecommendationItem[] {
    const merged: RecommendationItem[] = [];
    const seen = new Set<number>();

    // 按权重降序处理
    const sorted = Object.entries(weights).sort(([, a], [, b]) => b - a);

    for (const [strategy, weight] of sorted) {
      const idx = STRATEGY_INDEX[strategy];
      const result = results[idx];
      if (result.status !== 'fulfilled') continue;

      const quota = Math.max(1, Math.round(total * weight));
      let count = 0;
      for (const item of result.value) {
        if (!seen.has(item.questionId) && count < quota) {
          seen.add(item.questionId);
          merged.push(item);
          count++;
        }
      }
    }

    // 打乱顺序（避免同类题扎堆）
    return this.shuffleArray(merged);
  }

  /**
   * 答题后回调：更新ELO + 遗忘曲线
   */
  async onAnswerSubmitted(params: {
    userId: number;
    questionId: number;
    subjectCode: string;
    knowledgePointIds: number[];
    isCorrect: boolean;
    durationSec: number;
  }): Promise<void> {
    const { userId, questionId, subjectCode, knowledgePointIds, isCorrect } = params;

    // 1. 更新ELO
    const [student, question] = await Promise.all([
      this.getStudentAbility(userId, subjectCode),
      this.getQuestionDifficulty(questionId),
    ]);
    const [updatedStudent, updatedQuestion] = 
      this.difficultyEngine.updateAfterAnswer(student, question, isCorrect);

    // 2. 异步持久化
    await Promise.all([
      this.saveStudentAbility(updatedStudent),
      this.saveQuestionDifficulty(updatedQuestion),
    ]);

    // 3. 更新知识状态（遗忘曲线）
    const quality = this.inferQuality(isCorrect, params.durationSec);
    for (const kpId of knowledgePointIds) {
      const state = await this.knowledgeStateRepo.getOrCreate(userId, kpId, subjectCode);
      state.updateAfterReview(quality);
      await this.knowledgeStateRepo.save(state);
    }
  }

  private inferQuality(isCorrect: boolean, durationSec: number): number {
    if (!isCorrect) return durationSec > 60 ? 1 : 0;
    if (durationSec < 15) return 5;  // 快速正确
    if (durationSec < 30) return 4;  // 正常正确
    return 3;                        // 慢但正确
  }
}
```

### 5.2 定时任务：遗忘曲线扫描

```typescript
// src/jobs/ReviewReminderJob.ts

import { Injectable, Logger } from '@nestjs/common';
import { Cron, CronExpression } from '@nestjs/schedule';
import { KnowledgeStateRepository } from '../repositories/KnowledgeStateRepository';
import { NotificationService } from '../services/NotificationService';

@Injectable()
export class ReviewReminderJob {
  private readonly logger = new Logger(ReviewReminderJob.name);

  constructor(
    private readonly knowledgeStateRepo: KnowledgeStateRepository,
    private readonly notificationService: NotificationService,
  ) {}

  /**
   * 每天早上 8:00 扫描即将到期的复习任务
   * 生成推送给用户
   */
  @Cron('0 8 * * *', { timeZone: 'Asia/Shanghai' })
  async handleDailyReviewReminder(): Promise<void> {
    this.logger.log('开始扫描到期复习任务...');

    // 分页查询所有到期/即将到期的用户
    let offset = 0;
    const batchSize = 500;

    while (true) {
      const dueReviews = await this.knowledgeStateRepo.findDueReviews({
        dueBefore: new Date(Date.now() + 24 * 3600 * 1000), // 未来24小时内到期
        limit: batchSize,
        offset,
      });

      if (dueReviews.length === 0) break;

      // 按用户分组
      const userMap = new Map<number, DueReview[]>();
      for (const review of dueReviews) {
        if (!userMap.has(review.userId)) userMap.set(review.userId, []);
        userMap.get(review.userId)!.push(review);
      }

      // 生成推送
      for (const [userId, reviews] of userMap) {
        try {
          const topSubjects = this.getTopSubjects(reviews);
          await this.notificationService.sendReviewReminder(userId, {
            totalDue: reviews.length,
            subjects: topSubjects,
          });
        } catch (err) {
          this.logger.warn(`推送复习提醒失败 userId=${userId}: ${err.message}`);
        }
      }

      offset += batchSize;
    }

    this.logger.log('到期复习任务扫描完成');
  }

  /**
   * 每小时检查稳定性下降的知识点
   * 标记为 DECAYING 状态
   */
  @Cron(CronExpression.EVERY_HOUR)
  async handleStabilityDecay(): Promise<void> {
    const affected = await this.knowledgeStateRepo.markDecayingStates();
    this.logger.log(`标记 ${affected} 个知识点为 DECAYING`);
  }

  private getTopSubjects(reviews: DueReview[]): SubjectSummary[] {
    const map = new Map<string, number>();
    for (const r of reviews) {
      map.set(r.subjectCode, (map.get(r.subjectCode) ?? 0) + 1);
    }
    return [...map.entries()]
      .sort(([, a], [, b]) => b - a)
      .slice(0, 3)
      .map(([code, count]) => ({ subjectCode: code, dueCount: count }));
  }
}
```

```typescript
   * 当用户首次进入某学科时，批量初始化学科下所有知识点的状态

    userId: number, subjectCode: string
  ): Promise<void> {

      .filter(kp => !existingKpIds.has(kp.id))

        user_id: userId,
        knowledge_point_id: kp.id,
        subject_code: subjectCode,
        status: 'NEW',
```

### 6.1 首页推荐流程

```
用户打开APP → 首页请求推荐
    │
    ├─▶ 检查缓存 alp:recommend:{userId}:HOME

    │
    ├─▶ 获取学生能力值 (Redis / DB)
    ├─▶ 计算难度区间 (ELO → ZPD)
    │
    ├─▶ 并行执行4个策略:
    │   ├─ 遗忘曲线复习 (Redis ZSET due_review)
    │   ├─ 薄弱点强化 (学情分析API)
    │   ├─ 当前章节同步 (教材映射API)
    │   └─ 进阶拓展 (知识依赖图)
    │
    ├─▶ 加权分配名额 → 去重 → 打乱
    ├─▶ 写入推荐日志 (异步)
    ├─▶ 缓存结果 (30min TTL)
    └─▶ 返回推荐列表
```

### 6.2 答题后自适应流程

```
用户提交答案
    │
    ├─▶ 更新ELO评分 (双向: 学生能力 + 题目难度)
    ├─▶ 更新遗忘曲线 (SM-2 → 计算 next_review_at)
    ├─▶ 更新学情分析掌握度 (调用学情API)
    │
    ├─▶ 判断连续答题结果:
    │   ├─ 连续3题正确 → 提升难度区间 +10%
    │   ├─ 连续2题错误 → 降低难度区间 -15%
    │   └─ 正常 → 维持当前区间
    │
    └─▶ 实时生成下一题推荐 (AFTER_ANSWER场景)
```

### 6.3 学习路径执行流程

```
用户选择学习目标 → 构建学习路径
    │
    ├─▶ 反向BFS获取前置知识依赖链
    ├─▶ 获取各知识点掌握状态
    ├─▶ 拓扑排序 → 裁剪已掌握节点 → 插入过渡练习

    │
    ├─▶ 按节点顺序依次执行
    │   ├─ START → 标记 IN_PROGRESS
    │   ├─ 执行推荐活动（看视频 / AI对话 / 做题）
    │   └─ COMPLETE → 标记 COMPLETED，更新掌握度
    │
    ├─▶ 每完成一个节点，检查下一个节点的前置条件:
    │   ├─ 所有前置节点已完成 → 可以继续
    │   └─ 前置未完成 → 提示先完成前置

    ├─▶ 路径中节点状态变化时，动态调整后续节点:
    │   ├─ 某节点掌握度已达标 → 自动标记 COMPLETED
    │   └─ 某节点久未完成 → 降低难度或插入辅助节点
    │
    └─▶ 所有节点完成 → 路径标记 COMPLETED → 生成总结报告
```

### 7.2 降级策略

```typescript
class RecommendationFallback {
  /**
   * 降级优先级:
   * 1. 返回缓存中的上次推荐结果
   * 2. 返回规则引擎生成的固定推荐
   * 3. 返回热门题目
   */
  async getFallback(ctx: RecommendationContext): Promise<RecommendationResult> {
    // Level 1: 缓存
    const cached = await this.cacheService.get(
      `alp:recommend:${ctx.userId}:${ctx.scene}`
    );
    if (cached) {
      this.logger.warn('使用缓存推荐降级');
      return cached;
    }

    // Level 2: 简单规则
    const chapterId = await this.getCurrentChapterId(ctx.userId, ctx.subjectCode);
    if (chapterId) {
      const questions = await this.questionClient.search({
        chapter_id: chapterId,
        limit: ctx.questionCount,
        random_order: true,
      });
      this.logger.warn('使用章节随机题降级');
      return this.buildFallbackResult(ctx, questions, 'FALLBACK_CHAPTER');
    }

    // Level 3: 热门题
    const popular = await this.questionClient.getPopular({
      subject_code: ctx.subjectCode,
      limit: ctx.questionCount,
    });
    this.logger.warn('使用热门题降级');
    return this.buildFallbackResult(ctx, popular, 'FALLBACK_POPULAR');
  }
}
```

### 8.2 优化策略

- Redis 缓存推荐结果 30 分钟
- 待复习队列使用 Redis ZSET 预排序
- 能力值缓存在 Redis，DB 异步持久化

- `knowledge_learning_state` 按 (user_id, subject_code) 分区

- ELO 更新批量合并（每 10 秒 flush 一次到 DB）
- 推荐日志异步写入（消息队列 → 批量 INSERT）
- 遗忘曲线更新走 Redis 先写 → 定时同步 DB
