# 客户端-学习内容预加载策略与智能预渲染引擎-详细设计

> **文档版本：** v1.0
> **创建日期：** 2026-06-19
> **关联模块：** 同步课堂、练习测评、错题复习、AI对话、首页工作台
> **优先级：** P1（V1.0 阶段）

---

## 1. 概述

### 1.1 背景与目标

PrimeTop 作为全学段 AI 辅助学习 APP，核心场景是学生在 **章节学习 → 练习答题 → 错题复习 → 知识点拓展** 之间连续切换。每一次切换如果都需要等待网络加载，会打断学习心流、降低学习效率。

本模块的目标是：**在用户当前学习活动中，智能预测其下一步可能访问的内容，提前完成数据拉取和页面渲染准备，使内容切换达到"零等待"体验。**

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| **精准预测** | 基于学习流状态机和用户行为模式，预测准确率目标 ≥ 75% |
| **带宽友好** | 预加载总量受控，移动网络下单次预加载不超过 500KB |
| **电池友好** | 预加载操作分批、低优先级执行，不抢占前台渲染资源 |
| **可观测** | 完整的预加载命中率、丢弃率、带宽消耗指标 |
| **优雅降级** | 低端设备、低电量、省流模式下自动关闭或缩减预加载 |

### 1.3 适用场景

| 场景 | 预测目标 | 说明 |
| --- | --- | --- |
| 同步课堂章节学习 | 下一节课/知识点 | 用户读完当前课时，大概率继续下一课时 |
| 练习答题 | 下一道题目 | 答完当前题，必定进入下一题 |
| 错题本复习 | 下一道错题 | 复习场景连续翻页 |
| AI 对话追问 | 无（实时流式） | 不适用预加载，使用缓存复用策略 |
| 首页工作台 | 今日任务详情 | 用户可能点击的任务卡片 |
| 考点梳理专题 | 下一个考点 | 专题学习连续浏览 |
| 拍题结果页 | 解析详情/同类题 | 拍题识别后的下一步 |

### 2.1 引擎分层架构

```
┌─────────────────────────────────────────────────┐

│          预渲染管理层 (PreRenderManager)          │
│   离屏Page构建 │ 视图缓存池 │ 切换动画衔接         │
├─────────────────────────────────────────────────┤
│          预测决策层 (PredictorEngine)             │
│   流状态机分析 │ 行为模式匹配 │ 概率排序 │ 优先级   │
├─────────────────────────────────────────────────┤
│          数据预取层 (PrefetchDispatcher)          │
│   请求队列 │ 批量合并 │ 优先级调度 │ 去重 │ 限流    │
├─────────────────────────────────────────────────┤
│          基础设施层                               │
│   HTTP客户端 │ 本地缓存(Redis/SQLite) │ 网络感知   │
└─────────────────────────────────────────────────┘
```

### 2.2 核心组件职责

| 组件 | 职责 | 生命周期 |
| --- | --- | --- |
| `PredictorEngine` | 根据当前页面上下文 + 用户行为历史，输出预测目标列表 | 单例，APP 全局 |
| `PrefetchDispatcher` | 接收预测目标，调度网络请求，管理去重和优先级 | 单例，APP 全局 |
| `PreRenderManager` | 管理离屏页面构建和缓存池 | 绑定 Navigator |
| `PrefetchPolicy` | 根据网络/电量/设备等级决定预加载策略 | 动态可配 |
| `PrefetchMetrics` | 采集预加载命中/丢弃/带宽指标 | 单例 |

```dart
class PrefetchTarget {
  /// 唯一标识（用于去重）
  final String id;

  /// 内容类型
  final PrefetchContentType contentType;

  /// 业务键（章节ID/题目ID/考点ID等）
  final String contentKey;

  /// 预测概率 [0.0, 1.0]
  final double probability;

  final int priority;

  /// 数据来源URL列表（需要预取的接口）
  final List<PrefetchRequest> requests;

  /// 预估数据大小（KB）
  final int estimatedSizeKB;

  /// 创建时间戳
  final DateTime createdAt;

  /// 过期时间（超过此时间不再需要预加载）
  final DateTime? expireAt;

  /// 关联的预渲染配置（可选）
  final PreRenderConfig? preRenderConfig;
}

  exercise,      // 题目
  exerciseBatch, // 题目批次（一次预加载多道题）
  mistakeReview, // 错题复习
```

## 4. 预测决策层设计

### 4.1 预测引擎核心逻辑

预测引擎是整个系统的"大脑"，负责根据当前上下文判断用户接下来最可能做什么。

```dart
class PredictorEngine {
  final BehaviorHistoryRepository _historyRepo;
  final LearningFlowStateMachine _flowStateMachine;
  final PrefetchPolicy _policy;

  /// 主入口：根据当前上下文生成预测列表
  Future<List<PrefetchTarget>> predict({
    required String currentRoute,
    required Map<String, dynamic> currentParams,
    required LearningContext context,
  }) async {
    // 1. 检查是否允许预加载
    if (!_policy.enabled) return [];

    // 2. 检查网络/电量/设备条件
    if (!_shouldPrefetch()) return [];

    // 3. 从流状态机获取当前学习流位置
    final flowState = _flowStateMachine.currentState;

    // 4. 根据场景获取候选预测
    final candidates = <PrefetchTarget>[];

    // 场景A：同步课堂 → 下一课时
    if (currentRoute == '/lesson/detail') {
      candidates.addAll(_predictNextLessons(context, currentParams));
    }

    // 场景B：练习答题 → 下一题
    if (currentRoute == '/exercise/answer') {
      candidates.add(_predictNextExercise(context, currentParams));
    }

    // 场景C：错题复习 → 下一道错题
    if (currentRoute == '/mistake/review') {
      candidates.add(_predictNextMistake(context, currentParams));
    }

    // 场景D：首页 → 可能点击的任务
    if (currentRoute == '/home') {
      candidates.addAll(_predictHomeTasks(context));
    }

    // 场景E：考点梳理 → 下一个考点
    if (currentRoute == '/exam-point/detail') {
      candidates.add(_predictNextExamPoint(context, currentParams));
    }

    // 5. 结合行为历史调整概率
    candidates = _adjustByBehaviorHistory(candidates);

    // 6. 过滤低概率预测
    candidates = candidates.where((t) => t.probability >= 0.15).toList();

    // 7. 按概率×优先级排序，截取Top-N
    candidates.sort((a, b) =>
      (b.probability * b.priority).compareTo(a.probability * a.priority));

    // 8. 限制总数据量
    return _applyBatchSizeLimit(candidates);
  }
}
```

```dart
/// 同步课堂场景：预测用户接下来可能学习的课时
List<PrefetchTarget> _predictNextLessons(
  LearningContext context,
  Map<String, dynamic> currentParams,
) {
  final chapterId = currentParams['chapterId'] as String;
  final lessonId = currentParams['lessonId'] as String;
  final lessons = context.chapterLessons[chapterId] ?? [];

  final currentIndex = lessons.indexWhere((l) => l.id == lessonId);
  if (currentIndex < 0) return [];

  final targets = <PrefetchTarget>[];

  // P1: 下一课时（概率 0.75）
  if (currentIndex + 1 < lessons.length) {
    final nextLesson = lessons[currentIndex + 1];
    targets.add(PrefetchTarget(
      id: 'lesson_${nextLesson.id}',
      contentType: PrefetchContentType.lesson,
      contentKey: nextLesson.id,
      probability: 0.75,
      priority: 10,
      requests: _buildLessonRequests(nextLesson),
      estimatedSizeKB: nextLesson.estimatedContentKB,
      expireAt: DateTime.now().add(Duration(minutes: 10)),
      preRenderConfig: PreRenderConfig(
        routeName: '/lesson/detail',
        routeParams: {'chapterId': chapterId, 'lessonId': nextLesson.id},
        priority: PreRenderPriority.deferred,
        maxCacheCount: 1,
        autoDataBinding: true,
      ),
    ));
  }

  // P2: 当前课时的练习题（概率 0.45）
  targets.add(PrefetchTarget(
    id: 'lesson_exercise_${lessonId}',
    contentType: PrefetchContentType.exerciseBatch,
    contentKey: lessonId,
    probability: 0.45,
    priority: 7,
    requests: [
      PrefetchRequest(
        url: '/api/v1/exercises/by-lesson',
        method: 'GET',
        params: {'lessonId': lessonId, 'limit': 5},
        cacheTtlSeconds: 300,
        isEssential: true,
        resourceType: PrefetchResourceType.jsonData,
      ),
    ],
    estimatedSizeKB: 30,
    expireAt: DateTime.now().add(Duration(minutes: 5)),
  ));

  // P3: 下一课时+2（概率 0.20，仅在WiFi下预取）
  if (currentIndex + 2 < lessons.length) {
    final nextNextLesson = lessons[currentIndex + 2];
    targets.add(PrefetchTarget(
      id: 'lesson_${nextNextLesson.id}',
      contentType: PrefetchContentType.lesson,
      contentKey: nextNextLesson.id,
      probability: 0.20,
      priority: 3,
      requests: _buildLessonRequests(nextNextLesson),
      estimatedSizeKB: nextNextLesson.estimatedContentKB,
      expireAt: DateTime.now().add(Duration(minutes: 10)),
    ));
  }

  return targets;
}
```

```dart
PrefetchTarget _predictNextExercise(
  LearningContext context,
  Map<String, dynamic> currentParams,
) {
  final batchId = currentParams['batchId'] as String;
  final currentIndex = currentParams['index'] as int;
  final total = context.exerciseBatch!.total;

  // 下一题的序号
  final nextIndex = currentIndex + 1;
  final isLastQuestion = nextIndex >= total;

  if (isLastQuestion) {
    // 如果是最后一题，预测用户会查看答题结果报告
    return PrefetchTarget(
      id: 'exercise_result_$batchId',
      contentType: PrefetchContentType.reportData,
      contentKey: batchId,
      probability: 0.85,
      priority: 10,
      requests: [
        PrefetchRequest(
          url: '/api/v1/exercises/batch-result',
          method: 'GET',
          params: {'batchId': batchId},
          cacheTtlSeconds: 120,
          isEssential: true,
          resourceType: PrefetchResourceType.jsonData,
        ),
      ],
      estimatedSizeKB: 15,
      preRenderConfig: PreRenderConfig(
        routeName: '/exercise/result',
        routeParams: {'batchId': batchId},
        priority: PreRenderPriority.immediate,
        maxCacheCount: 1,
        autoDataBinding: false, // 等数据确认后再绑定
      ),
    );
  }

  // 常规：预取下一题 + 下下题
  return PrefetchTarget(
    id: 'exercise_${batchId}_$nextIndex',
    contentType: PrefetchContentType.exercise,
    contentKey: '$batchId-$nextIndex',
    probability: 0.98, // 几乎必定访问
    priority: 10,
    requests: [
      PrefetchRequest(
        url: '/api/v1/exercises/detail',
        method: 'GET',
        params: {'batchId': batchId, 'index': nextIndex},

        isEssential: true,

      // 附带预取下下题（非essential）

        url: '/api/v1/exercises/detail',

      maxCacheCount: 1,
```

```dart
/// 首页场景：预测用户可能点击的任务卡片
List<PrefetchTarget> _predictHomeTasks(LearningContext context) async {
  final tasks = context.todayTasks;
  final targets = <PrefetchTarget>[];

  // 获取行为历史：用户最常点击的任务类型
  final clickDistribution = await _historyRepo.getTaskClickDistribution();

  // 按用户偏好排序任务
  final sortedTasks = List.of(tasks)
    ..sort((a, b) {
      final scoreA = (clickDistribution[a.type] ?? 0.1) * (a.urgencyScore);
      final scoreB = (clickDistribution[b.type] ?? 0.1) * (b.urgencyScore);
      return scoreB.compareTo(scoreA);
    });

  // 取 Top-3 任务进行预取
  for (var i = 0; i < sortedTasks.length && i < 3; i++) {
    final task = sortedTasks[i];
    final probability = switch (i) {
      0 => 0.50,
      1 => 0.30,
      2 => 0.15,
      _ => 0.05,
    };

    targets.add(PrefetchTarget(
      id: 'home_task_${task.id}',
      contentType: PrefetchContentType.taskDetail,
      contentKey: task.id,
      probability: probability,
      priority: 5 - i,
      requests: _buildTaskRequests(task),
      estimatedSizeKB: task.estimatedSizeKB,
      expireAt: DateTime.now().add(Duration(minutes: 3)),
      // 首页任务不预渲染（类型不确定，预渲染成本高）
      preRenderConfig: null,
    ));
  }

  return targets;
}
```

### 4.6 行为历史概率修正

```dart
/// 基于用户历史行为修正预测概率
List<PrefetchTarget> _adjustByBehaviorHistory(
  List<PrefetchTarget> candidates,
) {
  final patterns = _historyRepo.getRecentPatterns(windowDays: 7);

  return candidates.map((target) {
    var adjustedProb = target.probability;

    // 修正因子1：用户在该场景下的连续学习倾向
    final continuationRate = patterns.getContinuationRate(
      contentType: target.contentType,
    );
    adjustedProb *= (0.5 + 0.5 * continuationRate);
    // continuationRate=1.0 → 不变; continuationRate=0.3 → 减半

    // 修正因子2：时间段偏好
    final hour = DateTime.now().hour;
    final timeSlotPreference = patterns.getTimeSlotPreference(
      contentType: target.contentType,
      hour: hour,
    );
    adjustedProb *= timeSlotPreference;

    // 修正因子3：该内容的访问频率
    final visitFreq = patterns.getVisitFrequency(target.contentKey);
    if (visitFreq > 2) {
      adjustedProb *= 1.15; // 经常访问的内容提升概率
    }

    return target.copyWith(probability: adjustedProb.clamp(0.0, 1.0));
  }).toList();
}
```

## 5. 数据预取层设计

### 5.1 调度器核心实现

```dart
class PrefetchDispatcher {
  final Dio _httpClient;
  final PrefetchCache _cache;
  final PrefetchPolicy _policy;
  final PrefetchMetrics _metrics;

  final _requestQueue = PriorityQueue<PrefetchTask>(_comparePriority);
  final _inFlight = <String, CancelToken>{};
  final _completed = LruCache<String, PrefetchCacheEntry>(maxSize: 200);

  int _currentBatchSizeKB = 0;
  Timer? _dispatchTimer;

  /// 提交预测目标列表
  void submit(List<PrefetchTarget> targets) {
    for (final target in targets) {
      // 去重：已在缓存中且未过期 → 跳过
      if (_completed.containsKey(target.id)) {
        final entry = _completed.get(target.id)!;
        if (entry.status == PrefetchStatus.fetched &&
            !_isExpired(entry)) {
          _metrics.recordHit(target.id);
          continue;
        }
      }

      // 去重：已在队列中 → 更新优先级
      if (_requestQueue.any((t) => t.target.id == target.id)) {
        _requestQueue.updateWhere(
          (t) => t.target.id == target.id,
          (t) => t.copyWith(target: target),
        );
        continue;
      }

      // 检查批次大小限制
      if (_currentBatchSizeKB + target.estimatedSizeKB >
          _policy.currentMaxBatchSizeKB) {
        continue;
      }

      // 入队
      for (final request in target.requests) {
        _requestQueue.add(PrefetchTask(
          target: target,
          request: request,
        ));
        _currentBatchSizeKB += target.estimatedSizeKB;
      }
    }

    _ensureDispatcherRunning();
  }

  /// 调度循环
  void _dispatchLoop() {
    while (_requestQueue.isNotEmpty &&
           _inFlight.length < _policy.maxConcurrentRequests) {
      final task = _requestQueue.removeFirst();

      // 检查过期
      if (task.target.expireAt != null &&
          DateTime.now().isAfter(task.target.expireAt!)) {
        _metrics.recordDiscarded(task.target.id, reason: 'expired');
        continue;
      }

      // 检查网络条件
      if (!_shouldExecuteRequest(task.request)) {
        _metrics.recordSkipped(task.target.id, reason: 'network_policy');
        continue;
      }

      // 执行预取
      _executePrefetch(task);
    }
  }

  Future<void> _executePrefetch(PrefetchTask task) async {
    final cancelToken = CancelToken();
    _inFlight[task.target.id] = cancelToken;

    final stopwatch = Stopwatch()..start();

    try {
      final response = await _httpClient.request(
        task.request.url,
        data: task.request.params,
        options: Options(
          method: task.request.method,
          headers: {
            ...?task.request.headers,
            'X-Prefetch': 'true',
            'X-Prefetch-Priority': task.target.priority.toString(),
          },
          cancelToken: cancelToken,
          receiveTimeout: Duration(seconds: 10),
          sendTimeout: Duration(seconds: 5),
        ),
      );

      stopwatch.stop();

      // 写入缓存
      final entry = PrefetchCacheEntry(
        targetId: task.target.id,
        target: task.target,
        fetchedAt: DateTime.now(),
        status: PrefetchStatus.fetched,
        actualSizeKB: (response.dataSizeBytes ~/ 1024) + 1,
        durationMs: stopwatch.elapsedMilliseconds,
      );

      _cache.put(
        key: _buildCacheKey(task.request),
        data: response.data,
        ttl: Duration(seconds: task.request.cacheTtlSeconds),
      );

      _completed.put(task.target.id, entry);
      _metrics.recordFetched(
        targetId: task.target.id,
        sizeKB: entry.actualSizeKB,
        durationMs: entry.durationMs,
      );

      // 如果配置了预渲染，触发预渲染
      if (task.target.preRenderConfig != null &&
          task.target.preRenderConfig!.priority != PreRenderPriority.skip) {
        _preRenderManager.schedulePreRender(task.target);
      }
    } on DioException catch (e) {
      stopwatch.stop();

      final isCancelled = e.type == DioExceptionType.cancel;

      _completed.put(task.target.id, PrefetchCacheEntry(
        targetId: task.target.id,
        target: task.target,
        fetchedAt: DateTime.now(),
        status: PrefetchStatus.failed,
        actualSizeKB: 0,
        durationMs: stopwatch.elapsedMilliseconds,
        errorMessage: isCancelled ? 'cancelled' : e.message,
      ));

      if (!isCancelled) {
        _metrics.recordFailed(task.target.id, reason: e.type.name);
      }
    } finally {
      _inFlight.remove(task.target.id);
    }
  }

  /// 用户实际导航到某页面时调用，检查是否有命中的预加载
  PrefetchHitResult? tryConsume(String targetId) {
    final entry = _completed.get(targetId);
    if (entry == null || _isExpired(entry)) {
      return null;
    }

    _completed.put(targetId, entry.copyWith(status: PrefetchStatus.consumed));
    _metrics.recordConsumed(targetId);

    return PrefetchHitResult(
      targetId: targetId,
      data: _cache.get(_buildCacheKeyFromTarget(entry.target)),
      preRenderedPage: _preRenderManager.tryGetPreRenderedPage(targetId),
    );
  }

  /// 页面离开时调用，取消不再需要的预加载
  void cancelUnrelated(String currentRoute, String currentTargetId) {
    _inFlight.forEach((id, token) {
      if (id != currentTargetId) {
        token.cancel('unrelated_to_current_navigation');
      }
    });
    _requestQueue.removeWhere(
      (t) => !t.target.id.contains(currentTargetId),
    );
  }
}

class PrefetchHitResult {
  final String targetId;
  final dynamic data;
  final Widget? preRenderedPage;
}
```

```dart
class PrefetchCache {
  final Box _box; // Hive/SQLite 存储

  static const _prefix = 'pf_'; // prefetch 前缀

  void put({
    required String key,
    required dynamic data,
    required Duration ttl,
  }) {
    final cacheKey = '$_prefix$key';
    final wrapper = _CacheWrapper(
      data: data,
      createdAt: DateTime.now(),
      ttl: ttl,
    );
    _box.put(cacheKey, wrapper.toJson());
  }

  dynamic get(String key) {
    final cacheKey = '$_prefix$key';
    final raw = _box.get(cacheKey);
    if (raw == null) return null;

    final wrapper = _CacheWrapper.fromJson(raw);
    if (DateTime.now().difference(wrapper.createdAt) > wrapper.ttl) {
      _box.delete(cacheKey);
      return null;
    }
    return wrapper.data;
  }

  /// 清理所有过期条目
  Future<int> cleanupExpired() async {
    int count = 0;
    for (final key in _box.keys) {
      if (!key.startsWith(_prefix)) continue;
      final wrapper = _CacheWrapper.fromJson(_box.get(key));
      if (DateTime.now().difference(wrapper.createdAt) > wrapper.ttl) {
        await _box.delete(key);
        count++;
      }
    }
    return count;
  }

  /// 获取当前预加载缓存总大小（估算）
  int get estimatedTotalSizeKB {
    // 遍历条目，累计序列化后的大小
    return _box.keys
      .where((k) => k.startsWith(_prefix))
      .map((k) => (_box.get(k) as String).length)
      .fold(0, (a, b) => a + b) ~/ 1024;
  }
}
```

```dart
class NetworkAwareStrategy {
  final Connectivity _connectivity;
  final Battery _battery;
  final DeviceInfo _deviceInfo;

  late NetworkType _currentNetwork;
  late DeviceTier _deviceTier;

  bool shouldPrefetch(PrefetchPolicy policy) {

    if (_batteryLevel < policy.batteryThreshold) return false;
    if (_isLowPowerMode) return false;

    final netConfig = policy.networkConfigs[_currentNetwork];

    return true;

  /// 获取当前最大批次大小
  int get currentMaxBatchSizeKB {
    switch (_currentNetwork) {
      case NetworkType.wifi:
        return 2048; // WiFi: 2MB
      case NetworkType.cellular4G:
        return 500;  // 4G: 500KB
      case NetworkType.cellular3G:
        return 200;  // 3G: 200KB
      case NetworkType.cellular2G:
        return 0;    // 2G: 不预加载
      default:
        return 0;
    }
  }

  /// 获取当前最大并发数
  int get currentMaxConcurrent {
    switch (_currentNetwork) {
      case NetworkType.wifi:
        return _deviceTier == DeviceTier.high ? 4 : 2;
      case NetworkType.cellular4G:
        return 2;
      case NetworkType.cellular3G:
        return 1;
      default:
        return 0;
    }
  }

  /// 判断特定资源类型是否允许预取
  bool shouldFetchResource(PrefetchResourceType type) {
    final netConfig = _currentNetworkConfig;
    switch (type) {
      case PrefetchResourceType.jsonData:
        return true; // JSON 总是允许
      case PrefetchResourceType.image:
        return netConfig.allowImagePrefetch;
      case PrefetchResourceType.audio:
        return netConfig.allowAudioPrefetch && _currentNetwork == NetworkType.wifi;
      case PrefetchResourceType.videoSegment:
        return netConfig.allowVideoPrefetch && _currentNetwork == NetworkType.wifi;
    }
  }
```

### 6.1 预渲染管理器

```dart
class PreRenderManager {
  final NavigatorState _navigator;
  final Map<String, _PreRenderedEntry> _renderPool = {};
  final int _maxPoolSize;

  /// 调度预渲染任务
  void schedulePreRender(PrefetchTarget target) {
    final config = target.preRenderConfig!;

    // 检查池容量
    if (_renderPool.length >= _maxPoolSize) {
      _evictOldest();
    }

    // 根据优先级选择策略
    switch (config.priority) {
      case PreRenderPriority.immediate:
        _buildPageImmediately(target);
      case PreRenderPriority.deferred:
        _scheduleDeferredBuild(target);
      case PreRenderPriority.skip:
        break; // 不预渲染
    }
  }

  /// 立即构建离屏页面
  void _buildPageImmediately(PrefetchTarget target) {
    final config = target.preRenderConfig!;

    // 使用Offstage构建页面，不显示但已完成布局和渲染
    final pageKey = target.id;
    final pageBuilder = _routeRegistry.getBuilder(config.routeName);

    if (pageBuilder == null) return;

    // 创建Offstage widget
    final offstagePage = Offstage(
      offstage: true,
      child: KeyedSubtree(
        key: ValueKey(pageKey),
        child: pageBuilder(config.routeParams),
      ),
    );

    // 插入到Overlay中（离屏渲染）
    _overlayEntry = OverlayEntry(builder: (context) => offstagePage);
    _navigator.context.overlay?.insert(_overlayEntry!);

    // 等待下一帧确认渲染完成
    WidgetsBinding.instance.addPostFrameCallback((_) {
      _renderPool[pageKey] = _PreRenderedEntry(
        widget: offstagePage,
        overlayEntry: _overlayEntry,
        routeParams: config.routeParams,
        createdAt: DateTime.now(),
      );
    });
  }

  /// 延迟构建：在空闲帧执行
  void _scheduleDeferredBuild(PrefetchTarget target) {
    SchedulerBinding.instance.scheduleTask(
      () => _buildPageImmediately(target),
      Priority.idle,
    );
  }

  /// 获取已预渲染的页面
  Widget? tryGetPreRenderedPage(String targetId) {
    final entry = _renderPool.remove(targetId);
    if (entry == null) return null;

    // 移除Offstage包裹，返回已构建的Widget
    entry.overlayEntry?.remove();
    return entry.widget.child;
  }

  /// 淘汰最早的预渲染页面
  void _evictOldest() {
    final sorted = _renderPool.entries.toList()
      ..sort((a, b) => a.value.createdAt.compareTo(b.value.createdAt));

    if (sorted.isNotEmpty) {
      final oldest = sorted.first;
      oldest.value.overlayEntry?.remove();
      _renderPool.remove(oldest.key);
    }
  }

  /// 清理所有预渲染页面（APP进入后台时调用）
  void clearAll() {
    for (final entry in _renderPool.values) {
      entry.overlayEntry?.remove();
    }
    _renderPool.clear();
  }
}
```

```dart
  void didPush(Route route, Route? previousRoute) {
    super.didPush(route, previousRoute);

        currentParams: route.settings.arguments as Map<String, dynamic>,
        context: _buildCurrentContext(),

        _dispatcher.submit(targets);
```

```dart
class PrefetchMetrics {
  final _counters = <String, int>{};
  final _timings = <String, List<int>>{};
  final _sizes = <String, List<int>>{};

  void recordHit(String targetId) {
    _counters['cache_hit'] = (_counters['cache_hit'] ?? 0) + 1;
  }

  void recordConsumed(String targetId) {
    _counters['consumed'] = (_counters['consumed'] ?? 0) + 1;
  }

  void recordDiscarded(String targetId, {required String reason}) {
    _counters['discarded'] = (_counters['discarded'] ?? 0) + 1;
    _counters['discard_reason_$reason'] =
      (_counters['discard_reason_$reason'] ?? 0) + 1;
  }

  void recordFetched({
    required String targetId,
    required int sizeKB,
    required int durationMs,
  }) {
    _counters['fetched'] = (_counters['fetched'] ?? 0) + 1;
    _sizes['fetched']?.add(sizeKB) ?? (_sizes['fetched'] = [sizeKB]);
    _timings['fetch']?.add(durationMs) ?? (_timings['fetch'] = [durationMs]);
  }

  void recordMiss(String targetId) {
    _counters['miss'] = (_counters['miss'] ?? 0) + 1;
  }

  void recordPreRenderHit(String targetId) {
    _counters['pre_render_hit'] = (_counters['pre_render_hit'] ?? 0) + 1;
  }

  void recordFailed(String targetId, {required String reason}) {
    _counters['failed'] = (_counters['failed'] ?? 0) + 1;
    _counters['fail_reason_$reason'] =
      (_counters['fail_reason_$reason'] ?? 0) + 1;
  }

  void recordSkipped(String targetId, {required String reason}) {
    _counters['skipped'] = (_counters['skipped'] ?? 0) + 1;
  }

  /// 生成指标快照（每60秒上报一次）
  Map<String, dynamic> snapshot() {
    final consumed = _counters['consumed'] ?? 0;
    final discarded = _counters['discarded'] ?? 0;
    final hitRate = consumed + discarded > 0
        ? consumed / (consumed + discarded)
        : 0.0;

    return {
      'prefetch_hit_rate': hitRate,
      'counters': Map.from(_counters),
      'avg_fetch_size_kb': _avg(_sizes['fetched']),
      'avg_fetch_duration_ms': _avg(_timings['fetch']),
      'total_bandwidth_kb': _sum(_sizes['fetched']),
      'timestamp': DateTime.now().toIso8601String(),
    };
  }

  double _avg(List<int>? values) =>
    values == null || values.isEmpty
      ? 0.0
      : values.reduce((a, b) => a + b) / values.length;
}
```

## 10. 错误处理与边界情况

### 10.1 错误处理策略

| 错误场景 | 处理方式 | 用户影响 |
| --- | --- | --- |
| 预取请求超时 | 静默丢弃，记录指标，不影响正常请求 | 无感 |
| 预取请求返回 4xx | 不缓存，记录失败指标 | 无感 |
| 预取请求返回 5xx | 不缓存，3分钟后可重试一次 | 无感 |
| 预渲染内存不足 | 清理预渲染池，降级为仅预取数据 | 无感 |
| 缓存空间不足 | LRU淘汰最旧条目 | 预加载命中率下降 |
| 预取数据与实际请求不一致 | 以实际请求结果为准，丢弃预取数据 | 无感（数据新鲜度优先） |
| 网络突然切换 | 暂停所有进行中的预取，重新评估策略 | 无感 |

### 10.2 数据一致性保障

预取的数据可能因为服务端更新而过期。通过以下机制保障一致性：

```dart
class PrefetchConsistencyChecker {
  /// 校验预取数据是否仍然有效
  bool isValid(PrefetchCacheEntry entry, PrefetchRequest request) {
    // 1. TTL 检查
    final age = DateTime.now().difference(entry.fetchedAt);
    if (age.inSeconds > request.cacheTtlSeconds) {
      return false;
    }

    // 2. 版本号检查（如果服务端返回了ETag/版本号）
    final cachedEtag = entry.target.metadata?['etag'];
    if (cachedEtag != null && _serverEtagManager.isStale(cachedEtag)) {
      return false;
    }

    // 3. 敏感数据不使用预加载缓存
    if (_isSensitiveData(request.url)) {
      return false; // 强制走实时请求
    }

    return true;
  }

  bool _isSensitiveData(String url) {
    // 用户隐私数据、实时计费数据等不走预取缓存
    return url.contains('/user/payment') ||
           url.contains('/user/real-name') ||
           url.contains('/exam/live');
  }
}
```

### 12.2 内存压力响应

```dart
class MemoryPressureHandler {
  final PreRenderManager _preRenderManager;
  final PrefetchDispatcher _dispatcher;

  void onMemoryWarning(MemoryPressureLevel level) {
    switch (level) {
      case MemoryPressureLevel.normal:
        // 正常运行
        break;
      case MemoryPressureLevel.warning:
        // 清理50%预渲染页面
        _preRenderManager.evictPercent(0.5);
        break;
      case MemoryPressureLevel.critical:
        // 清理所有预渲染页面，暂停预取
        _preRenderManager.clearAll();
        _dispatcher.pauseAll();
        break;
    }
  }
}
```

## 16. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| 预测准确率不足 | 中 | 浪费带宽 | 设置概率阈值 ≥ 0.15，持续优化模型 |
| 服务端流量激增 | 中 | 成本增加 | 服务端识别 `X-Prefetch` 头，可统一限流/降级 |
| 预渲染内存泄漏 | 低 | APP崩溃 | OverlayEntry 必须配对 remove，内存压力监听兜底 |
| 预取数据不一致 | 低 | 用户看到旧数据 | TTL + ETag 双保险，敏感数据不预取 |
| 用户流量焦虑 | 中 | 用户投诉 | 移动网络预加载控制在 500KB 内，设置用户开关 |

## 附录 A：服务端配合要点

服务端需要识别预取请求并做相应处理：

```
# 客户端预取请求头
X-Prefetch: true
X-Prefetch-Priority: <priority>
```

| 服务端策略 | 说明 |
| --- | --- |
| 低优先级处理 | 预取请求可以在服务端排队低优先级处理 |
| 缓存友好 | 预取请求的响应应设置较长 Cache-Control |
| 统一限流 | 在流量高峰时，可以优先拒绝 `X-Prefetch` 请求 |
| 监控分离 | 预取请求的延迟、错误率与正常请求分开统计 |

```nginx
# Nginx 层示例：预取请求低优先级
map $http_x_prefetch $prefetch_limit_key {
    default "normal";
    "true"   "prefetch";
}

limit_req_zone $prefetch_limit_key zone=prefetch_zone:10m rate=20r/s;
limit_req zone=prefetch_zone burst=10 nodelay;
```
