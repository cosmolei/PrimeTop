## 1. 模块概述

### 1.1 功能定位

积分商城是 PrimeTop 虚拟经济体系面向学生的核心消费出口。学生在学习过程中积累的**学币（COIN）**和**星光（STAR）**可在此兑换虚拟道具、增值服务、学习内容解锁和实物奖品（运营活动限定）。商城以分龄适配的视觉风格呈现，让"努力学习 → 获取积分 → 兑换奖励"的闭环变得直观且有趣。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 即时可达 | 从首页/个人中心 2 步内进入商城 |
| 安全消费 | 家长可限制兑换行为，未成年人实物兑换需家长确认 |
| 分龄体验 | 幼儿→星星商店（卡通）；小学/初中→积分商城；高中→特权兑换 |
| 离线可浏览 | 商品列表本地缓存，兑换操作需网络 |
| 防沉迷 | 不主动推送促销弹窗，兑换流程无赌博/抽卡机制 |
| 数据可审计 | 所有兑换记录可追溯，支持退款纠纷处理 |

### 1.3 适用学段

| 学段 | 入口名称 | 货币 | 商品侧重 |
|------|---------|------|---------|
| 幼儿 | 星星商店 | STAR | 趣味头像框、动画贴纸、故事解锁 |
| 小学 | 积分商城 | COIN | 虚拟道具、学习壁纸、头像装饰、实物小奖品 |
| 初中 | 积分商城 | COIN | 增值服务体验券、专题解锁、学习报告高级版 |
| 高中 | 兑换中心 | COIN | 限时特权、备考资料包、AI 高级功能试用 |

### 1.4 依赖模块

| 依赖 | 说明 |
|------|------|
| 积分与虚拟经济体系 | 定义货币类型、等级、防刷规则 |
| 服务端-积分获取规则计算与虚拟资产交易结算服务 | 提供余额查询、兑换、交易流水 API |
| 客户端-成就勋章与奖励展示组件 | 徽章/等级展示复用 |
| 客户端状态管理架构 | Riverpod Provider 模式 |
| 客户端组件库与设计系统 | PT 基础组件、设计 Token |
| 客户端主题引擎与动态外观系统 | 分龄主题适配 |
| 客户端本地持久层与数据管理 | Hive 本地缓存 |
| 家长中心 | 兑换权限管控 |

/// lib/features/shop/providers/shop_providers.dart

/// === 钱包余额（全局共享，跨多个页面使用） ===

/// 钱包余额 Provider — 网络获取 + 本地缓存兜底
@riverpod
class Wallet extends _$Wallet {
  @override
  FutureOr<UserWallet> build() {
    // 从本地缓存先返回，再发起网络请求
    final cached = _localCache.getWallet();
    if (cached != null) {
      // 立即返回缓存，同时触发后台刷新
      ref.invalidate(_walletRemoteProvider);
      return cached;
    }
    // 无缓存，走网络
    return ref.watch(_walletRemoteProvider.future);
  }

  Future<void> refresh() async {
    ref.invalidate(_walletRemoteProvider);
    await future;
  }

  /// 兑换后本地立即扣减（乐观更新），网络确认后刷新
  void optimisticDeduct(CurrencyType currency, int amount) {
    final current = value;
    if (current == null || !current.hasValue) return;
    final data = current.value;
    state = AsyncData(data.copyWith(
      coinBalance: currency == CurrencyType.COIN
          ? data.coinBalance - amount
          : data.coinBalance,
      starBalance: currency == CurrencyType.STAR
          ? data.starBalance - amount
          : data.starBalance,
    ));
  }
}

@riverpod
Future<UserWallet> _walletRemote(_WalletRemoteRef ref) async {
  final repo = ref.watch(shopRepositoryProvider);
  final wallet = await repo.fetchWallet();
  // 更新本地缓存
  ref.read(shopLocalCacheProvider).saveWallet(wallet);
  return wallet;
}

/// === 商品列表 ===

@riverpod
class ShopItemList extends _$ShopItemList {
  int _page = 0;
  static const _pageSize = 20;

  @override
  FutureOr<List<ShopItem>> build(ShopCategory category) {
    _page = 0;
    return _fetchPage(0);
  }

  Future<List<ShopItem>> _fetchPage(int page) async {
    final repo = ref.read(shopRepositoryProvider);
    return repo.fetchItems(
      category: category,
      page: page,
      pageSize: _pageSize,
    );
  }

  Future<void> loadMore() async {
    final current = value;
    if (current == null || !current.hasValue) return;
    final items = current.value;
    if (items.length < _page * _pageSize) return; // 已到末尾

    _page++;
    try {
      final newItems = await _fetchPage(_page);
      if (newItems.isEmpty) return;
      state = AsyncData([...items, ...newItems]);
    } catch (e) {
      _page--; // 回滚页码
      rethrow;
    }
  }

  Future<void> refresh() async {
    _page = 0;
    ref.invalidateSelf();
  }
}

/// === 兑换操作 ===

@riverpod
class RedeemAction extends _$RedeemAction {
  @override
  AsyncValue<RedeemResult?> build() => const AsyncData(null);

  Future<void> redeem({
    required String itemId,
    required int quantity,
    String? parentConfirmToken,
  }) async {
    state = const AsyncLoading();
    try {
      final repo = ref.read(shopRepositoryProvider);
      final result = await repo.redeemItem(
        itemId: itemId,
        quantity: quantity,
        parentConfirmToken: parentConfirmToken,
      );
      // 乐观更新余额
      ref.read(walletProvider.notifier).optimisticDeduct(
        result.currency, result.amount,
      );
      // 刷新真实余额
      unawaited(ref.read(walletProvider.notifier).refresh());
      // 刷新商品详情（库存/已购数变化）
      ref.invalidate(shopItemDetailProvider(itemId));
      state = AsyncData(result);
    } catch (e, st) {
      state = AsyncError(e, st);
      // 回滚乐观更新
      ref.read(walletProvider.notifier).refresh();
    }
  }
}

### 4.2 状态流转图

```
[商城主页加载]
    │
    ├─ 1. 读取本地缓存（Wallet / ItemSummary）
    │     → 立即渲染骨架屏 → 缓存数据填充
    │
    ├─ 2. 并行发起网络请求
    │     ├─ GET /api/v1/shop/wallet
    │     ├─ GET /api/v1/shop/items?category={tab}
    │     └─ GET /api/v1/shop/earn-tasks
    │
    ├─ 3. 网络响应到达 → 合并更新状态 → UI 过渡动画
    │
    └─ 4. 网络失败 → 保持缓存数据 → 底部提示"离线模式"
    
[兑换操作]
    │
    ├─ 1. 用户点击"兑换" → 检查本地余额是否充足
    │     └─ 不足 → 弹窗提示"学币不足" + 跳转赚积分页
    │
    ├─ 2. 余额充足 → 弹出确认弹窗
    │     ├─ 实物奖品 + 未成年人 → 触发家长确认流程
    │     └─ 其他 → 直接确认
    │
    ├─ 3. 确认 → 乐观扣减本地余额 → UI 立即反馈
    │     ├─ POST /api/v1/shop/redeem
    │     ├─ 成功 → 跳转结果页 + 播放动画
    │     └─ 失败 → 回滚余额 + Toast 提示错误
    │
    └─ 4. 兑换完成 → 刷新商品详情 + 刷新余额
```

  List<ShopCategory> _categoriesForAge(AgeGroup age) {

      case AgeGroup.primary:
      case AgeGroup.middle:
        return ShopCategory.values; // 全部分类
      case AgeGroup.high:
        return [ShopCategory.serviceVoucher, ShopCategory.contentUnlock,
                ShopCategory.exclusive, ShopCategory.physicalGoods];

class _ShopGrid extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final category = ref.watch(shopCategoryProvider);
    final itemsAsync = ref.watch(shopItemListProvider(category));
    // 滚动控制器（上拉加载更多）
    final scrollCtrl = useScrollController();
    useEffect(() {
      scrollCtrl.addListener(() {
        if (scrollCtrl.position.pixels >=
            scrollCtrl.position.maxScrollExtent - 200) {
          ref.read(shopItemListProvider(category).notifier).loadMore();
        }
      });
      return null;
    });

    return itemsAsync.when(
      data: (items) {
        if (items.isEmpty) {
          return const _EmptyShopView();
        }
        return RefreshIndicator(
          onRefresh: () => ref.read(shopItemListProvider(category).notifier)
              .refresh(),
          child: GridView.builder(
            controller: scrollCtrl,
            padding: const EdgeInsets.all(16),
            gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
              crossAxisCount: 2,
              mainAxisSpacing: 12,
              crossAxisSpacing: 12,
              childAspectRatio: 0.72, // 商品卡片宽高比
            ),
            itemCount: items.length + 1, // +1 加载指示器
            itemBuilder: (context, index) {
              if (index == items.length) {
                return const _LoadMoreIndicator();
              }
              return _ShopItemCard(
                item: items[index],
                onTap: () => context.push('/shop/item/${items[index].itemId}'),
              );
            },
          ),
        );
      },

## 7. 关键交互流程

### 7.1 兑换完整流程

```
用户点击商品卡片
    │
    ▼
[商品详情页] 加载详情 + 实时库存
    │
    ├─ 库存=0 → 显示"已兑完"，禁用兑换按钮
    ├─ 等级不足 → 显示"需 Lv.X"，禁用兑换按钮
    ├─ 已达限购上限 → 显示"已达限购上限"
    │
    ▼ (可兑换)
用户点击"立即兑换"
    │
    ├─ 余额不足 → 弹出"学币不足"弹窗
    │     └─ [去赚积分] → 跳转 EarnPointsPage
    │     └─ [取消]
    │
    ▼ (余额充足)
弹出确认弹窗 RedeemConfirmDialog
    │
    ├─ 用户取消 → 关闭弹窗
    │
    ▼ 用户勾选"已了解规则"并确认
    │
    ├─ 实物奖品 + 未成年人 → 进入家长确认流程
    │     ├─ 发送短信验证码到家长手机
    │     ├─ 家长输入验证码 → 生成 parentConfirmToken
    │     └─ 超时/错误 → 提示重新发送
    │
    ▼ (确认完成)
[乐观更新] 本地余额扣减，按钮变为 loading
    │
    ├─ 服务端返回成功
    │     ├→ 关闭弹窗
    │     ├→ 跳转兑换结果页
    │     ├→ 播放 Lottie 庆祝动画 (1.5s)
    │     ├→ 显示"分享"和"去背包查看"按钮
    │     └→ 刷新余额和商品列表
    │
    └─ 服务端返回失败
          ├→ 回滚本地余额
          ├→ Toast 显示错误原因
          └→ 根据错误码引导用户
              ├ STOCK_INSUFFICIENT → "刚刚被抢完了"
              ├ DAILY_CAP_EXCEEDED → "今日兑换次数已用完"
              ├ USER_LIMIT_REACHED → "你已兑换过该商品"
              ├ PARENT_CONFIRM_REQUIRED → "需家长确认"（重试流程）
              └ UNKNOWN → "兑换失败，学币已退回"
```

### 7.2 签到流程

```
用户点击签到FAB / 首页签到入口
    │
    ▼
[签到弹窗] 展示连续签到日历
    │
    ├─ 今日已签到 → 显示"今日已签到 ✓"，展示奖励明细
    │
    ▼ (未签到)
    POST /api/v1/shop/check-in
    │
    ├─ 成功 → 播放签到动画
    │     ├─ 显示获得学币数（带数字飞入动画）
    │     ├─ 连续签到额外奖励提示
    │     ├─ 更新本地钱包数据
    │     └─ 更新签到日历UI
    │
    └─ 失败 → Toast "签到失败，请稍后重试"
```

class ShopThemeResolver {

## 9. 错误处理策略

### 9.1 客户端错误码映射

| 场景 | HTTP状态码 | 业务错误码 | UI处理 |
|------|-----------|-----------|--------|
| 余额不足 | 200 | INSUFFICIENT_BALANCE | 弹窗提示+跳转赚积分页 |
| 库存不足 | 200 | STOCK_INSUFFICIENT | "刚刚被抢完了" Toast + 刷新列表 |
| 达到限购上限 | 200 | USER_LIMIT_REACHED | "每人限兑X件" Toast |
| 等级不足 | 200 | LEVEL_NOT_ENOUGH | 按钮显示"需 Lv.X" |
| 需家长确认 | 403 | PARENT_CONFIRM_REQUIRED | 弹出家}
