## 1. 概述

### 1.1 功能定位

本服务为 PrimeTop 平台提供统一的 **内容发布调度** 与 **章节访问控制** 能力。它是同步课堂、寒暑假专题、考点冲刺、课程连载等多个业务模块的共同基础设施，负责回答一个核心问题：

> **"某个学生在某个时间点，是否有权访问某项教育内容？"**

具体职责包括：

1. **定时发布**: 内容可预设发布时间，到点自动上线。
2. **解锁策略**: 支持按日期、按前置条件、按购买权益、按完成度等多种解锁规则。
3. **访问控制**: 对未发布/未解锁的内容拦截读取请求。
4. **事件广播**: 内容发布/解锁时产生领域事件，通知下游（推送服务、学习计划等）。
5. **管理后台**: 运营人员可配置发布计划、解锁规则，并实时预览效果。

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 解锁判定延迟 | P99 < 10ms（走缓存） |
| 定时发布精度 | ±30 秒 |
| 并发支持 | 10 万 QPS 解锁判定 |
| 可靠性 | 发布任务不丢失，支持重放补偿 |
| 可扩展 | 新增解锁规则类型不需要改动核心引擎 |

### 1.3 业务场景

| 场景 | 典型用法 | 解锁策略 |
|------|----------|----------|
| 同步课堂 | 新学期章节随教学进度逐周解锁 | 按日期 + 按学期周次 |
| 寒暑假专题营 | 每天解锁一个新模块 | 按日期（每日0点） |
| 考点冲刺 | 购买后立即解锁全部，或按阶段逐步开放 | 按购买权益 + 按日期 |
| 课程连载 | 前一章学完才解锁下一章 | 按前置完成度 |
| 限时体验 | 周末免费开放某专题 | 按时间窗口 |
| 预售课程 | 课前预习内容提前3天开放 | 按日期（相对开课日） |

### 2.2 核心术语

| 术语 | 说明 |
|------|------|
| **ContentGroup** | 内容容器，对应一个课程/专题/章节集合，是发布计划绑定的单位 |
| **ContentNode** | 内容节点，ContentGroup 下的具体章节/课时/模块 |
| **PublishPlan** | 发布计划，定义一组解锁规则和发布时间 |
| **UnlockRule** | 解锁规则，定义 ContentNode 在什么条件下可被访问 |
| **AccessContext** | 访问上下文，包含用户身份、时间、权益等判定输入 |
| **AccessDecision** | 访问决策，引擎输出的 允许/拒绝/待解锁 结果 |

## 4. 解锁规则引擎设计

### 4.1 规则类型体系

引擎采用 **策略模式**，每种解锁规则实现统一的 `UnlockRule` 接口：

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from datetime import datetime, timezone
from enum import Enum
from typing import Optional


class UnlockRuleType(str, Enum):
    DATE = "date"                    # 按固定日期解锁
    RELATIVE = "relative"            # 按相对时间解锁
    PREREQUISITE = "prerequisite"    # 按前置完成度解锁
    MEMBERSHIP = "membership"        # 按会员等级解锁
    PURCHASE = "purchase"            # 按购买商品解锁
    MANUAL = "manual"                # 手动解锁
    TIME_WINDOW = "time_window"      # 按每日时间窗口限制


@dataclass
class AccessContext:
    """访问上下文 — 包含判定所需的所有输入"""
    user_id: int
    content_node_id: int
    plan_id: int
    
    # 用户属性
    membership_tier: Optional[str] = None         # 当前会员等级
    purchased_product_ids: Optional[set[int]] = None
    
    # 前置节点完成度 {node_id: progress_percentage}
    prerequisite_progress: Optional[dict[int, int]] = None
    
    # 运营覆盖
    force_unlocked: bool = False
    
    # 当前时间（可注入，方便测试）
    now: datetime = None
    
    def __post_init__(self):
        if self.now is None:
            self.now = datetime.now(timezone.utc)


@dataclass
class AccessDecision:
    """访问决策结果"""
    allowed: bool
    node_id: int
    reason: str                                     # denied_reason 或 granted_reason
    unlocked_by_rule: Optional[str] = None
    unlock_at: Optional[datetime] = None            # 如果是 scheduled 状态，预告解锁时间
    expires_at: Optional[datetime] = None


class UnlockRuleHandler(ABC):
    """解锁规则处理器接口"""
    
    @property
    @abstractmethod
    def rule_type(self) -> UnlockRuleType:
        ...
    
    @abstractmethod
    def evaluate(self, ctx: AccessContext, rule_params: dict) -> AccessDecision:
        """
        评估规则是否满足。
        返回 AccessDecision:
          - allowed=True: 该规则允许通过
          - allowed=False: 该规则拒绝，reason 说明原因
          - 如果规则不适用，返回 allowed=True 并标记 reason="not_applicable"
        """
        ...
```

### 4.2 具体规则实现

#### 4.2.1 日期规则（最常用）

```python
class DateUnlockRule(UnlockRuleHandler):
    """按固定日期或相对日期解锁"""
    
    @property
    def rule_type(self) -> UnlockRuleType:
        return UnlockRuleType.DATE
    
    def evaluate(self, ctx: AccessContext, rule_params: dict) -> AccessDecision:
        # 运营强制解锁优先
        if ctx.force_unlocked:
            return AccessDecision(
                allowed=True, node_id=ctx.content_node_id,
                reason="force_unlocked", unlocked_by_rule="manual"
            )
        
        unlock_at = rule_params.get("unlock_at")
        relative_offset = rule_params.get("relative_offset")
        relative_basis = rule_params.get("relative_basis")
        
        if unlock_at:
            effective_unlock_at = datetime.fromisoformat(unlock_at)
        elif relative_offset is not None and relative_basis:
            basis_time = self._resolve_basis_time(ctx, relative_basis, rule_params)
            if basis_time is None:
                # 基准时间未确定（如学期还没开始），标记为待排期
                return AccessDecision(
                    allowed=False, node_id=ctx.content_node_id,
                    reason="basis_not_determined",
                    unlock_at=None
                )
            effective_unlock_at = basis_time + timedelta(days=relative_offset)
        else:
            # 无日期限制，直接放行
            return AccessDecision(
                allowed=True, node_id=ctx.content_node_id,
                reason="no_date_restriction"
            )
        
        if ctx.now >= effective_unlock_at:
            return AccessDecision(
                allowed=True, node_id=ctx.content_node_id,
                reason="date_reached", unlocked_by_rule="date",
                unlock_at=effective_unlock_at
            )
        else:
            return AccessDecision(
                allowed=False, node_id=ctx.content_node_id,
                reason="not_yet_unlocked",
                unlock_at=effective_unlock_at
            )
    
    def _resolve_basis_time(self, ctx: AccessContext, basis: str, params: dict) -> Optional[datetime]:
        """解析相对时间的基准点"""
        if basis == "plan_start":
            return params.get("plan_start_at")
        elif basis == "semester_start":
            return params.get("semester_start_at")
        elif basis == "purchase_date":
            return params.get("user_purchase_at")
        elif basis == "user_register_date":
            return params.get("user_register_at")
        return None
```

#### 4.2.2 前置完成度规则

```python
class PrerequisiteUnlockRule(UnlockRuleHandler):
    """要求前置节点达到指定完成度才解锁"""
    
    @property
    def rule_type(self) -> UnlockRuleType:
        return UnlockRuleType.PREREQUISITE
    
    def evaluate(self, ctx: AccessContext, rule_params: dict) -> AccessDecision:
        prereq_node_ids = rule_params.get("prerequisite_node_ids", [])
        threshold = rule_params.get("prerequisite_progress", 100)
        
        if not prereq_node_ids:
            return AccessDecision(
                allowed=True, node_id=ctx.content_node_id,
                reason="no_prerequisites"
            )
        
        if ctx.prerequisite_progress is None:
            # 需要查询前置节点完成度（正常应在上层批量注入）
            return AccessDecision(
                allowed=False, node_id=ctx.content_node_id,
                reason="prerequisite_data_missing"
            )
        
        # 检查每个前置节点
        not_met = []
        for node_id in prereq_node_ids:
            progress = ctx.prerequisite_progress.get(node_id, 0)
            if progress < threshold:
                not_met.append({"node_id": node_id, "current": progress, "required": threshold})
        
        if not_met:
            return AccessDecision(
                allowed=False, node_id=ctx.content_node_id,
                reason="prerequisite_not_met",
                unlock_at=None
            )
        
        return AccessDecision(
            allowed=True, node_id=ctx.content_node_id,
            reason="prerequisite_met", unlocked_by_rule="prerequisite"
        )
```

#### 4.2.3 会员/购买权益规则

```python
class MembershipUnlockRule(UnlockRuleHandler):
    """按会员等级或购买商品解锁"""
    
    @property
    def rule_type(self) -> UnlockRuleType:
        return UnlockRuleType.MEMBERSHIP
    
    def evaluate(self, ctx: AccessContext, rule_params: dict) -> AccessDecision:
        required_tier = rule_params.get("required_membership_tier")
        required_product_id = rule_params.get("required_product_id")
        
        # 检查会员等级
        if required_tier:
            tier_hierarchy = {"free": 0, "monthly": 1, "annual": 2, "exam_sprint": 3}
            user_level = tier_hierarchy.get(ctx.membership_tier or "free", 0)
            required_level = tier_hierarchy.get(required_tier, 99)
            if user_level >= required_level:
                return AccessDecision(
                    allowed=True, node_id=ctx.content_node_id,
                    reason="membership_sufficient", unlocked_by_rule="membership"
                )
        
        # 检查商品购买
        if required_product_id:
            if ctx.purchased_product_ids and required_product_id in ctx.purchased_product_ids:
                return AccessDecision(
                    allowed=True, node_id=ctx.content_node_id,
                    reason="product_purchased", unlocked_by_rule="purchase"
                )
        
        return AccessDecision(
            allowed=False, node_id=ctx.content_node_id,
            reason="insufficient_membership_or_purchase"
        )
```

#### 4.2.4 每日时间窗口规则

```python
class TimeWindowUnlockRule(UnlockRuleHandler):
    """限制每日可访问的时间段（防沉迷）"""
    
    @property
    def rule_type(self) -> UnlockRuleType:
        return UnlockRuleType.TIME_WINDOW
    
    def evaluate(self, ctx: AccessContext, rule_params: dict) -> AccessDecision:
        window_start_str = rule_params.get("access_window_start")
        window_end_str = rule_params.get("access_window_end")
        max_daily_minutes = rule_params.get("max_daily_minutes")
        
        if not window_start_str or not window_end_str:
            return AccessDecision(
                allowed=True, node_id=ctx.content_node_id,
                reason="no_time_window"
            )
        
        # 转为用户本地时区判断
        user_tz = pytz.timezone(ctx.user_timezone or "Asia/Shanghai")
        now_local = ctx.now.astimezone(user_tz)
        
        window_start = now_local.replace(
            hour=int(window_start_str[:2]), minute=int(window_start_str[3:5]),
            second=0, microsecond=0
        )
        window_end = now_local.replace(
            hour=int(window_end_str[:2]), minute=int(window_end_str[3:5]),
            second=0, microsecond=0
        )
        
        if not (window_start <= now_local <= window_end):
            return AccessDecision(
                allowed=False, node_id=ctx.content_node_id,
                reason="outside_time_window",
                unlock_at=self._next_window_start(now_local, window_start, window_end)
            )
        
        # 检查每日使用时长（需要查询 Redis 计数器）
        if max_daily_minutes:
            daily_key = f"publish:daily_usage:{ctx.user_id}:{ctx.content_node_id}:{now_local.date()}"
            used_minutes = int(redis.get(daily_key) or 0)
            if used_minutes >= max_daily_minutes:
                return AccessDecision(
                    allowed=False, node_id=ctx.content_node_id,
                    reason="daily_limit_reached"
                )
        
        return AccessDecision(
            allowed=True, node_id=ctx.content_node_id,
            reason="within_time_window"
        )
    
    def _next_window_start(self, now_local, start, end):
        """计算下一次窗口开放时间"""
        if now_local < start:
            return start
        return start + timedelta(days=1)
```

### 4.3 规则编排引擎

多个规则组合时采用 **AND 逻辑**（全部满足才放行），但按优先级短路求值：

```python
class UnlockRuleEngine:
    """解锁规则编排引擎"""
    
    # 规则评估优先级（从高到低）
    RULE_PRIORITY = [
        UnlockRuleType.MANUAL,         # 运营覆盖最高优先级
        UnlockRuleType.DATE,           # 日期规则（快速判定）
        UnlockRuleType.MEMBERSHIP,     # 会员/购买权益
        UnlockRuleType.PURCHASE,
        UnlockRuleType.PREREQUISITE,   # 前置完成度（需查DB）
        UnlockRuleType.TIME_WINDOW,    # 时间窗口（需查Redis）
    ]
    
    def __init__(self):
        self._handlers: dict[UnlockRuleType, UnlockRuleHandler] = {}
        self._register_defaults()
    
    def _register_defaults(self):
        self.register(DateUnlockRule())
        self.register(PrerequisiteUnlockRule())
        self.register(MembershipUnlockRule())
        self.register(TimeWindowUnlockRule())
    
    def register(self, handler: UnlockRuleHandler):
        self._handlers[handler.rule_type] = handler
    
    def evaluate_node_access(
        self,
        ctx: AccessContext,
        node_rules: list[dict]
    ) -> AccessDecision:
        """
        评估用户对某内容节点的访问权限。
        
        Args:
            ctx: 访问上下文
            node_rules: 该节点配置的规则列表，每项含 rule_type 和参数
        
        Returns:
            AccessDecision: 最终决策
        """
        if not node_rules:
            # 无规则 = 自由访问
            return AccessDecision(
                allowed=True, node_id=ctx.content_node_id,
                reason="no_rules_configured"
            )
        
        # 按优先级排序规则
        def priority_key(rule):
            rule_type = UnlockRuleType(rule["rule_type"])
            return self.RULE_PRIORITY.index(rule_type) if rule_type in self.RULE_PRIORITY else 99
        
        sorted_rules = sorted(node_rules, key=priority_key)
        
        # 用于聚合结果
        earliest_unlock = None
        deny_reasons = []
        
        for rule in sorted_rules:
            rule_type = UnlockRuleType(rule["rule_type"])
            handler = self._handlers.get(rule_type)
            if not handler:
                continue
            
            decision = handler.evaluate(ctx, rule)
            
            if decision.allowed:
                continue
            
            # 短路：运营强制解锁以外的拒绝都需要记录
            deny_reasons.append(decision.reason)
            if decision.unlock_at:
                if earliest_unlock is None or decision.unlock_at < earliest_unlock:
                    earliest_unlock = decision.unlock_at
        
        if not deny_reasons:
            return AccessDecision(
                allowed=True, node_id=ctx.content_node_id,
                reason="all_rules_passed"
            )
        
        return AccessDecision(
            allowed=False, node_id=ctx.content_node_id,
            reason=deny_reasons[0],     # 返回最高优先级的拒绝原因
            unlock_at=earliest_unlock
        )
```

### 6.1 定时发布调度流程

```

└──────────┘     └──────────────────┘     └────────┬────────┘
                                                   │
                    ┌──────────────────┐           ▼
                    │ 清除决策缓存      │◄──────────┘
                    │ publish:decision:*│
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │ 发布领域事件      │
                    │ node.unlocked    │
                    └────────┬─────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼

        │ 推送通知  │  │ 学习计划  │  │ 数据统计埋点  │

        └──────────┘  └──────────┘  └──────────────┘
```

#### 定时扫描任务实现

```python
import asyncio
from datetime import datetime, timezone

class PublishScheduler:
    """定时发布调度器"""
    
    def __init__(self, redis, db_pool, event_bus):
        self.redis = redis
        self.db = db_pool
        self.event_bus = event_bus
    
    async def scan_and_unlock(self):
        """每分钟执行：扫描到期节点并执行解锁"""
        now_ts = int(datetime.now(timezone.utc).timestamp())
        
        # 1. 从 ZSet 中取出所有到期的待解锁节点
        due_members = await self.redis.zrangebyscore(
            "publish:pending_unlock", 0, now_ts
        )
        
        if not due_members:
            return {"unlocked": 0}
        
        unlocked_count = 0
        batch_size = 100  # 分批处理，避免单次DB压力过大
        
        for i in range(0, len(due_members), batch_size):
            batch = due_members[i:i + batch_size]
            
            async with self.db.acquire() as conn:
                async with conn.transaction():
                    for member in batch:
                        parts = member.decode().split(":")
                        plan_id, node_id = int(parts[0]), int(parts[1])
                        
                        # 2. 批量更新该节点所有用户的授权状态
                        updated = await conn.execute(
                            """
                            UPDATE content_access_grant 
                            SET grant_status = 'unlocked',
                                unlocked_at = $1,
                                unlock_source = 'auto',
                                unlocked_by_rule = 'date',
                                updated_at = $1
                            WHERE plan_id = $2 
                              AND content_node_id = $3
                              AND grant_status IN ('locked', 'scheduled')
                            """,
                            datetime.now(timezone.utc), plan_id, node_id
                        )
                        
                        # 3. 写入事件日志
                        event_id = f"unlock_{plan_id}_{node_id}_{now_ts}"
                        await conn.execute(
                            """
                            INSERT INTO content_publish_event_log 
                                (event_id, event_type, plan_id, content_node_id, 
                                 affected_user_count, payload, processed)
                            VALUES ($1, 'node_unlocked', $2, $3, $4, $5, FALSE)
                            ON CONFLICT (event_id) DO NOTHING
                            """,
                            event_id, plan_id, node_id, int(updated),
                            asyncio.json.dumps({"unlock_type": "scheduled", "ts": now_ts})
                        )
                        
                        unlocked_count += 1
                        
                        # 4. 批量清除用户的决策缓存
                        await self._invalidate_decision_cache(plan_id, node_id)
        
        # 5. 从 ZSet 中移除已处理的成员
        if due_members:
            await self.redis.zremrangebyscore("publish:pending_unlock", 0, now_ts)
        
        # 6. 异步发布事件
        for member in due_members:
            parts = member.decode().split(":")
            await self.event_bus.publish(
                topic="content.node.unlocked",
                payload={
                    "plan_id": int(parts[0]),
                    "node_id": int(parts[1]),
                    "unlock_type": "scheduled",
                    "timestamp": now_ts
                }
            )
        
        return {"unlocked": unlocked_count}
    
    async def _invalidate_decision_cache(self, plan_id: int, node_id: int):
        """清除与该节点相关的决策缓存"""
        # 使用 SCAN + DEL 批量清除（避免 KEYS 阻塞）
        pattern = f"publish:decision:*:{node_id}"
        async for key in self.redis.scan_iter(match=pattern, count=500):
            await self.redis.delete(key)
        
        # 清除规则缓存（强制下次刷新）
        await self.redis.delete(f"publish:grant:*:{plan_id}")
```

### 6.2 访问检查流程（用户读取内容时）

```
用户请求读取内容节点
        │
        ▼
┌───────────────────┐
│ 1. 查决策缓存      │──── 命中 ────→ 返回缓存结果
│ (Redis, 5min TTL) │
└───────┬───────────┘
        │ 未命中
        ▼
┌───────────────────┐
│ 2. 查用户授权表    │──── 已解锁 ──→ 返回 ALLOW
│ content_access_   │
│ grant             │
└───────┬───────────┘
        │ locked/scheduled
        ▼
┌───────────────────┐
│ 3. 运行规则引擎    │──── 规则通过 ──→ 更新授权表 → 返回 ALLOW

└───────┬───────────┘
        │ 规则未通过
        ▼
┌───────────────────┐

│ + 拒绝原因和解锁   │
│   预告时间         │
└───────────────────┘
```

#### 访问检查实现

```python
class ContentAccessService:
    """内容访问控制服务"""
    
    def __init__(self, redis, db_pool, rule_engine: UnlockRuleEngine, 
                 user_service, learning_service):
        self.redis = redis
        self.db = db_pool
        self.engine = rule_engine
        self.user_service = user_service
        self.learning_service = learning_service
    
    async def check_access(
        self, 
        user_id: int, 
        content_node_id: int, 
        plan_code: str
    ) -> AccessDecision:
        """检查用户是否有权访问内容节点"""
        
        # 1. 查决策缓存
        cache_key = f"publish:decision:{user_id}:{content_node_id}"
        cached = await self.redis.get(cache_key)
        if cached:
            return self._parse_cached_decision(cached, content_node_id)
        
        # 2. 获取计划和节点规则
        plan = await self._get_plan(plan_code)
        if plan["status"] != "active":
            return AccessDecision(
                allowed=False, node_id=content_node_id,
                reason="plan_not_active"
            )
        
        node_rule = await self._get_node_rule(plan["id"], content_node_id)
        if not node_rule:
            # 节点不在计划中 = 无限制
            decision = AccessDecision(
                allowed=True, node_id=content_node_id,
                reason="not_in_plan"
            )
            await self._cache_decision(cache_key, decision)
            return decision
        
        # 3. 查用户授权表
        grant = await self._get_grant(user_id, plan["id"], content_node_id)
        if grant and grant["grant_status"] == "unlocked":
            # 检查是否过期
            if grant["expires_at"] and grant["expires_at"] < datetime.now(timezone.utc):
                await self._update_grant_status(user_id, plan["id"], content_node_id, "expired")
                decision = AccessDecision(
                    allowed=False, node_id=content_node_id,
                    reason="access_expired"
                )
            else:
                decision = AccessDecision(
                    allowed=True, node_id=content_node_id,
                    reason="already_unlocked",
                    unlocked_by_rule=grant.get("unlocked_by_rule")
                )
            await self._cache_decision(cache_key, decision)
            return decision
        
        # 4. 运行规则引擎实时评估
        ctx = await self._build_context(user_id, content_node_id, plan, node_rule)
        rules = self._parse_rules(node_rule)
        decision = self.engine.evaluate_node_access(ctx, rules)
        
        # 5. 如果规则评估通过，更新授权表
        if decision.allowed:
            await self._create_or_update_grant(
                user_id, plan["id"], content_node_id,
                status="unlocked",
                source="auto",
                rule=decision.unlocked_by_rule
            )
        
        # 6. 写入决策缓存
        await self._cache_decision(cache_key, decision)
        
        return decision
    
    async def _build_context(self, user_id, node_id, plan, node_rule) -> AccessContext:
        """构建访问上下文"""
        # 并发获取用户信息和学习进度
        user_info, prereq_progress = await asyncio.gather(
            self.user_service.get_user_membership(user_id),
            self._get_prerequisite_progress(user_id, node_rule)
        )
        
        return AccessContext(
            user_id=user_id,
            content_node_id=node_id,
            plan_id=plan["id"],
            membership_tier=user_info.get("membership_tier"),
            purchased_product_ids=user_info.get("purchased_product_ids", set()),
            prerequisite_progress=prereq_progress,
            force_unlocked=node_rule.get("force_unlocked", False),
            now=datetime.now(timezone.utc)
        )
    
    async def _get_prerequisite_progress(self, user_id, node_rule) -> dict[int, int]:
        """获取前置节点完成度"""
        prereq_ids = node_rule.get("prerequisite_node_ids", [])
        if not prereq_ids:
            return {}
        
        # 批量查询学习记录服务
        progress_map = {}
        for nid in prereq_ids:
            progress = await self.learning_service.get_node_progress(user_id, nid)
            progress_map[nid] = progress
        return progress_map
```

### 6.3 计划激活与授权初始化流程

```
运营点击"激活"
      │
      ▼
┌─────────────────────┐
│ 1. 校验计划完整性    │  ← 检查节点规则是否合法
└────────┬────────────┘
         │ 通过
         ▼
┌─────────────────────┐
│ 2. 计算初始解锁状态  │  ← 按当前时间判断哪些应已解锁
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 3. 批量写入授权表    │  ← 对目标用户群预生成 locked/scheduled/unlocked
│ (异步，分批)         │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 4. 注册定时解锁任务  │  ← 写入 Redis ZSet
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
```

#### 批量授权初始化

```python
class PlanActivationService:
    """发布计划激活服务"""
    
    BATCH_SIZE = 5000  # 每批处理的用户数
    
    async def activate_plan(self, plan_id: int, activated_by: int):
        """激活发布计划，初始化所有目标用户的授权记录"""
        
        plan = await self._get_plan(plan_id)
        if plan["status"] != "draft":
            raise BusinessError(f"计划状态不允许激活: {plan['status']}")
        
        # 1. 获取计划内所有节点规则
        node_rules = await self._get_all_node_rules(plan_id)
        
        # 2. 确定目标用户群体
        target_user_ids = await self._get_target_users(plan)
        total_users = len(target_user_ids)
        
        # 3. 计算每个节点的初始状态
        now = datetime.now(timezone.utc)
        node_initial_states = {}
        
        for rule in node_rules:
            if rule.get("force_unlocked"):
                node_initial_states[rule["content_node_id"]] = "unlocked"
            elif rule.get("unlock_at") and datetime.fromisoformat(rule["unlock_at"]) <= now:
                node_initial_states[rule["content_node_id"]] = "unlocked"
            elif rule.get("unlock_at") and datetime.fromisoformat(rule["unlock_at"]) > now:
                node_initial_states[rule["content_node_id"]] = "scheduled"
            else:
                node_initial_states[rule["content_node_id"]] = "locked"
        
        # 4. 分批写入授权表
        for offset in range(0, total_users, self.BATCH_SIZE):
            batch_user_ids = target_user_ids[offset:offset + self.BATCH_SIZE]
            
            async with self.db.acquire() as conn:
                async with conn.transaction():
                    # 使用批量 INSERT ... ON CONFLICT
                    values = []
                    for uid in batch_user_ids:
                        for node_id, status in node_initial_states.items():
                            values.append((uid, plan_id, node_id, status))
                    
                    await conn.executemany(
                        """
                        INSERT INTO content_access_grant 
                            (user_id, plan_id, content_node_id, grant_status, created_at, updated_at)
                        VALUES ($1, $2, $3, $4, NOW(), NOW())
                        ON CONFLICT (user_id, plan_id, content_node_id) 
                        DO UPDATE SET grant_status = EXCLUDED.grant_status,
                                      updated_at = NOW()
                        """,
                        values
                    )
            
            # 乐观更新进度
            logger.info(f"计划 {plan_id} 激活进度: {offset + len(batch_user_ids)}/{total_users}")
        
        # 5. 注册定时解锁任务到 Redis ZSet
        await self._register_scheduled_unlocks(plan_id, node_rules)
        
        # 6. 更新计划状态
        await self._update_plan_status(plan_id, "active")
        
        return {"plan_id": plan_id, "total_users": total_users, "total_nodes": len(node_rules)}
    
    async def _register_scheduled_unlocks(self, plan_id: int, node_rules: list[dict]):
        """将所有定时解锁任务注册到 Redis ZSet"""
        now_ts = int(datetime.now(timezone.utc).timestamp())
        
        for rule in node_rules:
            unlock_at = rule.get("unlock_at")
            if unlock_at and rule.get("force_unlocked") is False:
                unlock_ts = int(datetime.fromisoformat(unlock_at).timestamp())
                if unlock_ts > now_ts:
                    member = f"{plan_id}:{rule['content_node_id']}"
                    await self.redis.zadd("publish:pending_unlock", {member: unlock_ts})
```

## 7. 状态机定义

### 7.1 发布计划状态流转

```
                    创建
                     │
                     ▼
              ┌───────────┐
              │   draft   │
              └─────┬─────┘
                    │ 激活
                    ▼
              ┌───────────┐
        ┌────→│  active   │←─────┐
        │     └─────┬─────┘      │
        │ 暂停      │            │ 恢复
        │           ▼            │
        │     ┌───────────┐      │
        └─────│  paused   │──────┘
              └─────┬─────┘
                    │ 归档
                    ▼
              ┌───────────┐
              │ archived  │
              └───────────┘
```

| 转换 | 触发条件 | 效果 |
|------|----------|------|
| draft → active | 管理员点击激活 | 初始化授权表，注册定时任务 |
| active → paused | 管理员暂停 | 停止定时扫描，新用户不初始化（已有授权不变） |
| paused → active | 管理员恢复 | 重新注册定时任务，补发期间到期节点 |
| active/paused → archived | 管理员归档 | 所有授权标记为 expired，停止调度 |

```python
class ContentAccessService:
    async def handle_textbook_switch(self, user_id: int, old_plan_id: int, new_plan_id: int):
        """处理用户切换教材版本时的授权迁移"""
        
        # 1. 获取新计划
        new_plan = await self._get_plan_by_id(new_plan_id)
        new_node_rules = await self._get_all_node_rules(new_plan_id)
        
        # 2. 获取旧计划的已完成节点
        old_grants = await self.db.fetch(
            """
            SELECT content_node_id, grant_status FROM content_access_grant
            WHERE user_id = $1 AND plan_id = $2
            """,
            user_id, old_plan_id
        )
        
        # 3. 通过知识点映射找到新旧节点对应关系
        node_mapping = await self.knowledge_service.get_textbook_node_mapping(
            old_plan_id, new_plan_id
        )
        
        # 4. 为新计划初始化授权（已学过的对应节点标记为 unlocked）
        async with self.db.acquire() as conn:
            async with conn.transaction():
                for new_rule in new_node_rules:
                    new_node_id = new_rule["content_node_id"]
                    mapped_old_node = node_mapping.get(new_node_id)
                    
                    if mapped_old_node:
                        old_grant = next(
                            (g for g in old_grants if g["content_node_id"] == mapped_old_node),
                            None
                        )
                        if old_grant and old_grant["grant_status"] == "unlocked":
                            # 已学过 → 直接解锁
                            status = "unlocked"
                        else:
                            status = self._calc_initial_status(new_rule)
                    else:
                        status = self._calc_initial_status(new_rule)
                    
                    await conn.execute(
                        """
                        INSERT INTO content_access_grant (user_id, plan_id, content_node_id, grant_status)
                        VALUES ($1, $2, $3, $4)
                        ON CONFLICT (user_id, plan_id, content_node_id)
                        DO UPDATE SET grant_status = EXCLUDED.grant_status
                        """,
                        user_id, new_plan_id, new_node_id, status
                    )
        
        # 5. 归旧计划授权
        await self.db.execute(
            """
            UPDATE content_access_grant 
            SET grant_status = 'expired', updated_at = NOW()
            WHERE user_id = $1 AND plan_id = $2
            """,
            user_id, old_plan_id
        )
```

```python
class PublishScheduler:
    async def rebuild_pending_unlock_queue(self):
        """从数据库重建 Redis 待解锁队列（故障恢复）"""
        
        # 从数据库查出所有未来到期的定时解锁规则
        rows = await self.db.fetch(
            """
            SELECT r.plan_id, r.content_node_id, r.unlock_at
            FROM content_node_unlock_rule r
            JOIN content_publish_plan p ON r.plan_id = p.id
            WHERE p.status = 'active'
              AND r.unlock_at IS NOT NULL
              AND r.force_unlocked = FALSE
              AND r.unlock_at > NOW()
            ORDER BY r.unlock_at
            """
        )
        
        if not rows:
            return {"rebuilt": 0}
        
        pipe = self.redis.pipeline()
        for row in rows:
            member = f"{row['plan_id']}:{row['content_node_id']}"
            score = int(row["unlock_at"].timestamp())
            pipe.zadd("publish:pending_unlock", {member: score})
        
        await pipe.execute()
        return {"rebuilt": len(rows)}
```

## 10. 性能优化策略

### 10.1 多级缓存架构

```
请求 → L1: 进程内缓存(1min) → L2: Redis(5min) → L3: 数据库
```

| 缓存层 | TTL | 适用场景 | 失效策略 |
|--------|-----|----------|----------|
| 进程内 LRU | 1 分钟 | 高频访问的决策结果 | TTL 过期 |
| Redis 决策 | 5 分钟 | 所有访问决策 | 主动失效（解锁时清除） |
| Redis 授权 | 24 小时 | 用户在某计划下的完整授权状态 | 解锁/过期时更新 |
| Redis 规则 | 10 分钟 | 计划节点规则 | 配置变更时清除 |

### 10.2 批量预加载

首页加载时，一次性预取用户在所有活跃计划中的授权状态：

```python
class ContentAccessService:
    
    async def preload_user_grants(self, user_id: int) -> dict:
        """预加载用户所有活跃计划的授权状态（首页调用）"""
        
        cache_key = f"publish:grants_all:{user_id}"
        cached = await self.redis.get(cache_key)
        if cached:
            return json.loads(cached)
        
        # 一次性查出用户在所有活跃计划中的授权
        rows = await self.db.fetch(
            """
            SELECT g.plan_id, g.content_node_id, g.grant_status, 
                   g.unlocked_at, g.expires_at
            FROM content_access_grant g
            JOIN content_publish_plan p ON g.plan_id = p.id
            WHERE g.user_id = $1 
              AND p.status = 'active'
            """,
            user_id
        )
        
        result = {}
        for row in rows:
            plan_id = str(row["plan_id"])
            if plan_id not in result:
                result[plan_id] = {}
            result[plan_id][str(row["content_node_id"])] = {
                "status": row["grant_status"],
                "unlocked_at": row["unlocked_at"].isoformat() if row["unlocked_at"] else None,
                "expires_at": row["expires_at"].isoformat() if row["expires_at"] else None
            }
        
        await self.redis.setex(cache_key, 300, json.dumps(result))  # 5min
        return result
```

### 10.3 读写分离

- **读操作**（访问检查、列表查询）：走只读副本
- **写操作**（解锁更新、配置变更）：走主库
- 定时扫描任务的 DB 写入在低峰期批量执行

## 14. 附录

### 14.1 数据字典 — grant_status 枚举

| 值 | 含义 | 可见性 |
|----|------|--------|
| `locked` | 锁定，尚未满足任何解锁条件 | 不展示内容 |
| `scheduled` | 已排期，等待定时解锁触发 | 展示标题+倒计时 |
| `unlocked` | 已解锁，可正常访问 | 完整展示 |
| `expired` | 已过期，曾经可访问但已失效 | 展示过期提示+续费引导 |

### 14.2 数据字典 — strategy_type 枚举

| 值 | 含义 | 典型场景 |
|----|------|----------|
| `scheduled` | 一次性定时发布所有节点 | 课程预售 |
| `drip` | 逐个/逐批按时间解锁 | 同步课堂、连载课程 |
| `access_window` | 在指定时间窗口内可访问 | 限时免费体验、周末特惠 |

### 14.3 常见问题处理

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 用户反馈"内容明明买了却打不开" | 购买后授权表未同步初始化 | 补偿任务检查 `order.paid` 事件是否消费成功 |
| 所有用户都看不到新发布的内容 | 计划状态仍是 draft | 管理后台检查并激活 |
| 节点解锁后又被锁定 | 前置节点完成度回退（如重新答题得分降低） | 设计决策：前置完成度回退不撤销已解锁状态 |
| 定时解锁不触发 | Redis ZSet 数据丢失 | 运行 `rebuild_pending_unlock_queue` 重建 |
| 大量用户同时收到解锁推送 | 批量解锁导致推送洪峰 | 推送服务分批发送，每批间隔2-5秒 |
