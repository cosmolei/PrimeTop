# 服务端-反爬虫与内容数据防泄漏防护引擎-详细设计

## 1. 概述与设计目标

### 1.1 背景

PrimeTop 平台沉淀了大量核心教育资产：题库（含解析）、知识点体系、教材结构化内容、考点清单、作文范文、AI 高质量回答等。这些内容是产品核心竞争力，面临以下风险：

- **批量爬取**：竞争对手或第三方通过自动化脚本批量抓取题目和解析
- **接口滥用**：超出正常用户行为的高频 API 调用
- **数据倒卖**：将爬取的结构化内容打包出售
- **AI 训练盗用**：将平台内容用于训练竞品模型
- **账号共享**：少数账号被多人共享用于批量获取内容

### 1.2 设计目标

| 目标 | 描述 |
| --- | --- |
| **接口防护** | 所有核心数据接口具备反爬能力，识别并拦截自动化请求 |
| **内容溯源** | 每份输出内容可溯源到具体用户，支持泄漏追责 |
| **行为识别** | 基于用户行为模式识别异常访问，准确率 ≥ 95% |
| **误伤控制** | 正常用户被误拦截率 < 0.1% |
| **性能可控** | 防护逻辑不增加超过 20ms 的接口延迟 |
| **运营可视** | 提供反爬大盘、拦截统计、误伤申诉闭环 |

### 1.3 设计原则

1. **多层防御**：不依赖单一手段，构建 WAF → 网关 → 业务 → 数据四层防护
2. **动态变化**：防护规则、签名算法、检测策略定期轮换，增加对抗成本
3. **静默拦截**：对疑似爬虫请求优先返回"降质数据"或"延迟响应"，而非直接拒绝，增加对抗难度
4. **不影响体验**：正常用户无感知，仅对高危行为触发验证
5. **合规优先**：数据采集与用户隐私处理符合《个人信息保护法》和《未成年人保护法》

## 3. 核心模块详细设计

### 3.1 接口签名验证体系

#### 3.1.1 签名机制设计

客户端 SDK 在每次请求中附加签名参数，服务端在网关层进行验证。

**签名生成算法（v2 版本）：**

```
signature = HMAC-SHA256(
    key = app_secret + dynamic_salt(timestamp),
    message = method + "\n" +
              path + "\n" +
              sorted_query_string + "\n" +
              body_hash + "\n" +
              timestamp + "\n" +
              nonce + "\n" +
              device_fingerprint
)
```

**请求头参数：**

| Header | 说明 | 示例 |
| --- | --- | --- |
| `X-PT-Sign` | 签名值（Hex） | `a3f2c9b8e1...` |
| `X-PT-Ts` | 时间戳（毫秒） | `1719302400000` |
| `X-PT-Nonce` | 随机串（16位） | `7f3a9c2e8b1d4f60` |
| `X-PT-SigVer` | 签名算法版本 | `v2` |
| `X-PT-Device` | 设备指纹标识 | `dfp_8a7b6c5d4e3f` |

#### 3.1.2 动态盐值设计

```java
/**
 * 动态盐值生成 —— 基于时间窗口 + 版本密钥派生
 * 每 5 分钟切换一次盐值窗口，允许前后 1 个窗口的容差
 */
public class DynamicSaltGenerator {

    private static final long WINDOW_SIZE_MS = 5 * 60 * 1000L; // 5分钟窗口
    private final List<String> rotatingSecrets; // 从配置中心获取，每轮换周期更新

    /**
     * 根据时间戳生成盐值
     */
    public String generateSalt(long timestamp) {
        long windowIndex = timestamp / WINDOW_SIZE_MS;
        int secretIndex = (int)(windowIndex % rotatingSecrets.size());
        String currentSecret = rotatingSecrets.get(secretIndex);
        return SHA256.hash(currentSecret + ":" + windowIndex);
    }

    /**
     * 验证时支持前后窗口容差
     */
    public ValidationResult validateSalt(long timestamp, String providedSalt) {
        long currentWindow = System.currentTimeMillis() / WINDOW_SIZE_MS;
        long requestWindow = timestamp / WINDOW_SIZE_MS;

        if (Math.abs(currentWindow - requestWindow) > 1) {
            return ValidationResult.expired("时间窗口超出容差范围");
        }

        for (int offset = -1; offset <= 1; offset++) {
            String expectedSalt = generateSaltForWindow(requestWindow + offset);
            if (expectedSalt.equals(providedSalt)) {
                return ValidationResult.ok();
            }
        }
        return ValidationResult.invalid("盐值不匹配");
    }
}
```

实际生产中使用 **Redis** 存储（TTL = 签名有效窗口 × 2）：

```java
@Component
public class NonceValidator {

    @Resource
    private RedisTemplate<String, String> redisTemplate;

    private static final long TTL_SECONDS = 600L; // 10分钟

    /**
     * 检查 nonce 是否被重放
     * @return true = 首次使用（已记录）; false = 重复请求
     */
    public boolean checkAndStore(Long userId, String nonce, long timestamp) {
        String key = String.format("anti:crawl:nonce:%d:%s", userId, nonce);
        // SETNX 原子操作
        Boolean firstUse = redisTemplate.opsForValue()
            .setIfAbsent(key, String.valueOf(timestamp), Duration.ofSeconds(TTL_SECONDS));
        return Boolean.TRUE.equals(firstUse);
    }
}
```

#### 3.1.4 签名验证中间件（Spring Cloud Gateway）

```java
@Component
@Order(-100) // 在鉴权之前执行
public class SignatureValidationGatewayFilter implements GlobalFilter {

    @Resource
    private DynamicSaltGenerator saltGenerator;
    @Resource
    private NonceValidator nonceValidator;
    @Resource
    private RiskScoreEngine riskScoreEngine;

    // 白名单路径：不需要签名验证的接口
    private static final Set<String> WHITELIST = Set.of(
        "/api/v1/auth/login",
        "/api/v1/auth/sms-code",
        "/api/v1/health",
        "/api/v1/app/version-check"
    );

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String path = exchange.getRequest().getURI().getPath();

        // 白名单跳过
        if (WHITELIST.contains(path)) {
            return chain.filter(exchange);
        }

        String signature = exchange.getRequest().getHeaders().getFirst("X-PT-Sign");
        String timestampStr = exchange.getRequest().getHeaders().getFirst("X-PT-Ts");
        String nonce = exchange.getRequest().getHeaders().getFirst("X-PT-Nonce");
        String deviceFp = exchange.getRequest().getHeaders().getFirst("X-PT-Device");
        String sigVer = exchange.getRequest().getHeaders().getFirst("X-PT-SigVer");

        // 1. 参数完整性检查
        if (StringUtils.isAnyBlank(signature, timestampStr, nonce, deviceFp)) {
            return reject(exchange, RejectReason.MISSING_PARAMS);
        }

        long timestamp;
        try {
            timestamp = Long.parseLong(timestampStr);
        } catch (NumberFormatException e) {
            return reject(exchange, RejectReason.INVALID_TIMESTAMP);
        }

        // 2. 时间窗口验证（±5分钟）
        long now = System.currentTimeMillis();
        if (Math.abs(now - timestamp) > 5 * 60 * 1000L) {
            return reject(exchange, RejectReason.EXPIRED_TIMESTAMP);
        }

        // 3. 重建签名并比对
        String expectedSig = rebuildSignature(exchange, timestamp, nonce, deviceFp, sigVer);
        if (!HMACUtils.constantTimeEquals(expectedSig, signature)) {
            // 签名错误 → 记录风险事件，不立即拒绝（静默标记）
            riskScoreEngine.addEvent(exchange, RiskEvent.SIGNATURE_FAILURE);
            // 对于低风险用户，降级处理而非直接拒绝
            if (riskScoreEngine.getCurrentScore(exchange) > 70) {
                return reject(exchange, RejectReason.INVALID_SIGNATURE);
            }
            // 低风险用户继续，但标记为可疑
            exchange.getAttributes().put("suspicious_request", true);
        }

        // 4. Nonce 防重放（仅对认证用户）
        Long userId = extractUserId(exchange);
        if (userId != null && !nonceValidator.checkAndStore(userId, nonce, timestamp)) {
            return reject(exchange, RejectReason.REPLAY_DETECTED);
        }

        return chain.filter(exchange);
    }

    private Mono<Void> reject(ServerWebExchange exchange, RejectReason reason) {
        // 静默拦截：返回 200 但 body 为空数据或降质数据
        exchange.getResponse().setStatusCode(HttpStatus.OK);
        exchange.getResponse().getHeaders().setContentType(MediaType.APPLICATION_JSON);
        String body = ApiResponse.error(reason.getCode(), reason.getMessage()).toJson();
        DataBuffer buffer = exchange.getResponse().bufferFactory().wrap(body.getBytes(StandardCharsets.UTF_8));
        // 记录拦截日志
        auditLogger.logReject(exchange, reason);
        return exchange.getResponse().writeWith(Mono.just(buffer));
    }
}
```

```dart
  final buffer = StringBuffer()
    ..write(info.platform)
    ..write('|').write(info.deviceModel)
    ..write('|').write(info.osVersion)
    ..write('|').write(info.screenResolution)
    ..write('|').write(info.cpuCores)
    ..write('|').write(info.totalMemory)
    ..write('|').write(info.installId);
```

```java
@Service
public class DeviceFingerprintAnalyzer {

    /**
     * 检测设备指纹异常
     */
    public FingerprintRisk analyze(Long userId, String fingerprintHash, String deviceInfo) {
        List<RiskSignal> signals = new ArrayList<>();

        // 1. 同一指纹关联过多账号（>3）
        int linkedAccounts = fingerprintMapper.countLinkedAccounts(fingerprintHash);
        if (linkedAccounts > 3) {
            signals.add(RiskSignal.HIGH_ACCOUNT_DENSITY);
        }

        // 2. 同一用户频繁更换设备指纹（24h内 > 2个新指纹）
        int newFingerprintsToday = fingerprintMapper.countNewFingerprints(userId, Duration.ofHours(24));
        if (newFingerprintsToday > 2) {
            signals.add(RiskSignal.FREQUENT_DEVICE_CHANGE);
        }

        // 3. 指纹关联的 IP 分散（跨城市/跨省）
        List<String> recentCities = ipLocationService.getRecentCitiesByFingerprint(fingerprintHash, Duration.ofHours(6));
        if (recentCities.size() > 3) {
            signals.add(RiskSignal.GEO_DISTRIBUTION_ANOMALY);
        }

        // 4. 模拟器/Root 检测
        if (deviceInfoJson.get("isEmulator").asBoolean() ||
            deviceInfoJson.get("isJailbroken").asBoolean()) {
            signals.add(RiskSignal.EMULATOR_OR_ROOT);
        }

        return new FingerprintRisk(signals, calculateScore(signals));
    }

    private int calculateScore(List<RiskSignal> signals) {
        int score = 0;
        for (RiskSignal s : signals) {
            score += s.getWeight();
        }
        return Math.min(score, 100);
    }
}
```

#### 3.3.2 滑动窗口计数器实现（Redis）

```java
/**
 * 基于 Redis ZSET 的滑动窗口频率计数器
 * 相比固定窗口计数器更精确，避免窗口边界突发
 */
@Component
public class SlidingWindowRateCounter {

    @Resource
    private RedisTemplate<String, String> redisTemplate;

    private static final long WINDOW_MS = 60_000L; // 1分钟窗口

    /**
     * 检查是否允许请求
     * @param key       维度 key (如 "anti:crawl:rate:user:12345:/api/v1/questions/detail")
     * @param limit     窗口内最大允许次数
     * @return true = 允许通过; false = 已超限
     */
    public boolean checkAndIncrement(String key, int limit) {
        long now = System.currentTimeMillis();
        long windowStart = now - WINDOW_MS;

        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(
            "redis.call('ZREMRANGEBYSCORE', KEYS[1], 0, ARGV[1])\n" +
            "local count = redis.call('ZCARD', KEYS[1])\n" +
            "if count < tonumber(ARGV[2]) then\n" +
            "    redis.call('ZADD', KEYS[1], ARGV[3], ARGV[4])\n" +
            "    redis.call('EXPIRE', KEYS[1], 120)\n" +
            "    return 1\n" +
            "else\n" +
            "    return 0\n" +
            "end"
        );
        script.setResultType(Long.class);

        String memberId = UUID.randomUUID().toString();
        Long result = redisTemplate.execute(script, List.of(key),
            String.valueOf(windowStart), String.valueOf(limit),
            String.valueOf(now), memberId);

        return result != null && result == 1L;
    }
}
```

#### 3.3.3 用户行为序列分析

基于用户请求的**时序特征**识别爬虫行为。正常用户和爬虫在请求模式上有本质差异：

```java
/**
 * 用户行为序列分析器
 * 维护用户最近 100 次请求的特征向量，计算异常分数
 */
@Service
public class UserBehaviorSequenceAnalyzer {

    // 行为特征维度
    private static final int SEQUENCE_WINDOW = 100; // 最近100次请求

    /**
     * 分析用户行为序列
     */
    public BehaviorAnalysisResult analyze(Long userId) {
        List<RequestLog> recentRequests = requestLogService.getRecentRequests(userId, SEQUENCE_WINDOW);

        if (recentRequests.size() < 10) {
            return BehaviorAnalysisResult.insufficientData();
        }

        BehaviorFeatures features = extractFeatures(recentRequests);
        double anomalyScore = calculateAnomalyScore(features);

        return new BehaviorAnalysisResult(features, anomalyScore);
    }

    private BehaviorFeatures extractFeatures(List<RequestLog> requests) {
        return BehaviorFeatures.builder()
            // 1. 请求间隔统计
            .avgIntervalMs(calculateAvgInterval(requests))
            .intervalStdDev(calculateStdDevInterval(requests))
            .minIntervalMs(findMinInterval(requests))
            // 2. 请求路径熵
            .pathEntropy(calculatePathEntropy(requests))
            // 3. 顺序模式（是否按章节/知识点顺序遍历）
            .sequentialRatio(calculateSequentialRatio(requests))
            // 4. 页面停留时间分布
            .avgDwellTimeMs(calculateAvgDwellTime(requests))
            .dwellTimeStdDev(calculateDwellTimeStd(requests))
            // 5. 请求时段分布
            .nightRatio(calculateNightRatio(requests))
            // 6. 翻页/滚动行为比例（由客户端上报）
            .scrollEventRatio(calculateScrollRatio(requests))
            // 7. 用户交互事件密度（点击、长按等）
            .interactionDensity(calculateInteractionDensity(requests))
            .build();
    }

    /**
     * 异常评分逻辑
     */
    private double calculateAnomalyScore(BehaviorFeatures f) {
        double score = 0;

        // 规则1：请求间隔极低且极均匀 → 爬虫特征
        // 正常用户间隔方差大，爬虫方差小
        if (f.getAvgIntervalMs() < 1500 && f.getIntervalStdDev() < 500) {
            score += 25; // 高度可疑
        } else if (f.getAvgIntervalMs() < 3000 && f.getIntervalStdDev() < 800) {
            score += 12;
        }

        // 规则2：路径熵极低 → 顺序遍历特征
        // 正常用户随机浏览，爬虫倾向于按ID/章节顺序抓取
        if (f.getPathEntropy() < 1.5) {
            score += 20;
        } else if (f.getPathEntropy() < 2.5) {
            score += 10;
        }

        // 规则3：顺序访问比例过高（如题目ID递增遍历）
        if (f.getSequentialRatio() > 0.7) {
            score += 20;
        }

        // 规则4：无滚动事件、无交互事件 → 纯API调用
        if (f.getScrollEventRatio() < 0.05 && f.getInteractionDensity() < 0.1) {
            score += 15;
        }

        // 规则5：深夜高频访问（0:00-6:00）
        if (f.getNightRatio() > 0.5) {
            score += 10;
        }

        // 规则6：极短停留时间（每个内容页 < 2秒）
        if (f.getAvgDwellTimeMs() < 2000 && f.getDwellTimeStdDev() < 500) {
            score += 15;
        }

        return Math.min(score, 100.0);
    }
}
```

### 3.4 风险评分引擎

#### 3.4.1 综合风险评分模型

```java
/**
 * 综合风险评分引擎
 * 汇总签名校验、设备指纹、频率检测、行为分析的信号
 * 输出 0-100 分，分数越高代表风险越大
 */
@Service
public class RiskScoreEngine {

    @Resource private DeviceFingerprintAnalyzer fingerprintAnalyzer;
    @Resource private UserBehaviorSequenceAnalyzer behaviorAnalyzer;
    @Resource private SlidingWindowRateCounter rateCounter;
    @Resource private RiskEventRedisSink eventSink;

    private static final double W_SIGNATURE   = 0.15;
    private static final double W_DEVICE      = 0.20;
    private static final double W_RATE        = 0.25;
    private static final double W_BEHAVIOR    = 0.30;
    private static final double W_HISTORY     = 0.10;

    /**
     * 计算当前请求的综合风险分数
     */
    public RiskAssessment assess(ServerWebExchange exchange, Long userId) {
        RiskDimension signature = assessSignature(exchange);
        RiskDimension device   = assessDevice(userId, exchange);
        RiskDimension rate     = assessRate(userId, exchange);
        RiskDimension behavior = assessBehavior(userId);
        RiskDimension history  = assessHistory(userId);

        double total = signature.getScore() * W_SIGNATURE
                     + device.getScore()   * W_DEVICE
                     + rate.getScore()     * W_RATE
                     + behavior.getScore() * W_BEHAVIOR
                     + history.getScore()  * W_HISTORY;

        return RiskAssessment.builder()
            .totalScore(total)
            .signature(signature)
            .device(device)
            .rate(rate)
            .behavior(behavior)
            .history(history)
            .build();
    }

    /**
     * 历史维度：用户过往是否有违规记录
     */
    private RiskDimension assessHistory(Long userId) {
        UserRiskHistory history = riskHistoryMapper.getRecent(userId, Duration.ofDays(30));
        double score = 0;
        if (history != null) {
            score += Math.min(history.getRejectCount() * 10, 40);
            score += Math.min(history.getCaptchaTriggerCount() * 5, 30);
            if (history.isBlacklisted()) {
                score = 100;
            }
        }
        return new RiskDimension("history", score, history);
    }
}
```

#### 3.4.2 风险分级与处置策略

| 分数区间 | 风险等级 | 处置策略 |
| --- | --- | --- |
| 0-29 | 正常（PASS） | 正常返回数据 |
| 30-49 | 低风险（MONITOR） | 正常返回数据，记录详细日志用于离线分析 |
| 50-69 | 中风险（CHALLENGE） | 触发人机验证（CAPTCHA），验证通过后正常返回 |
| 70-84 | 高风险（DEGRADE） | 静默降级：返回部分数据或模糊化处理 |
| 85-100 | 极高风险（BLOCK） | 静默拦截：返回空数据或误导性数据 |

### 3.5 静默降级策略引擎

对高风险请求不直接返回 403/429（这会暴露防护规则），而是采用**静默降级**策略：

```java
@Service
public class SilentDegradeHandler {

    /**
     * 根据风险等级对响应进行降级处理
     */
    public ResponseEntity<?> degrade(ResponseEntity<?> original, RiskAssessment risk) {
        switch (risk.getLevel()) {
            case DEGRADE:
                return applyDegradeStrategy(original, risk);
            case BLOCK:
                return applyBlockStrategy(original, risk);
            default:
                return original;
        }
    }

    /**
     * 降级策略：数据模糊化
     */
    private ResponseEntity<?> applyDegradeStrategy(ResponseEntity<?> original, RiskAssessment risk) {
        Object body = original.getBody();
        if (body instanceof QuestionDetailDTO) {
            QuestionDetailDTO dto = (QuestionDetailDTO) body;
            // 策略1：隐藏详细解析，仅返回题干
            dto.setAnalysis(null);
            dto.setAnswerHint("登录后查看完整解析");
            // 策略2：图片添加水印并降低分辨率
            if (dto.getImages() != null) {
                dto.setImages(dto.getImages().stream()
                    .map(this::addWatermarkAndDownscale)
                    .collect(Collectors.toList()));
            }
            return ResponseEntity.ok(dto);
        }
        if (body instanceof PageResult<?>) {
            // 策略3：分页结果减少每页数量（如30条→10条）
            return truncatePageResult((PageResult<?>) body);
        }
        // 默认策略：增加响应延迟
        try { Thread.sleep(2000 + ThreadLocalRandom.current().nextInt(3000)); }
        catch (InterruptedException ignored) {}
        return original;
    }

    /**
     * 拦截策略：返回空壳数据（HTTP 200）
     */
    private ResponseEntity<?> applyBlockStrategy(ResponseEntity<?> original, RiskAssessment risk) {
        // 返回与正常接口结构一致但内容为空的数据
        // 让爬虫难以区分是"被拦截"还是"确实无数据"
        Object emptyBody = buildEmptyShell(original.getBody());
        // 随机延迟 5-15 秒，消耗爬虫方资源
        try { Thread.sleep(5000 + ThreadLocalRandom.current().nextInt(10000)); }
        catch (InterruptedException ignored) {}
        return ResponseEntity.ok(emptyBody);
    }
}
```

### 3.6 内容水印与溯源体系

#### 3.6.1 显性水印（可见水印）

应用于图片型内容（题目配图、解析截图、学习报告）：

```java
@Service
public class VisibleWatermarkService {

    /**
     * 为图片添加用户标识水印
     */
    public byte[] addWatermark(byte[] imageBytes, Long userId, WatermarkPosition position) {
        BufferedImage image = ImageIO.read(new ByteArrayInputStream(imageBytes));

        // 生成水印文字：用户ID编码 + 时间戳
        String watermarkText = encodeWatermark(userId);

        Graphics2D g2d = (Graphics2D) image.getGraphics();
        g2d.setRenderingHint(RenderingHints.KEY_ANTIALIASING, RenderingHints.VALUE_ANTIALIAS_ON);
        g2d.setRenderingHint(RenderingHints.KEY_TEXT_ANTIALIASING, RenderingHints.VALUE_TEXT_ANTIALIAS_ON);

        // 半透明白色文字
        g2d.setColor(new Color(255, 255, 255, 60));
        g2d.setFont(new Font("PingFang SC", Font.PLAIN, 12));

        // 根据位置参数绘制（平铺/右下角/居中）
        if (position == WatermarkPosition.TILED) {
            for (int x = 0; x < image.getWidth(); x += 200) {
                for (int y = 30; y < image.getHeight(); y += 100) {
                    g2d.drawString(watermarkText, x, y);
                }
            }
        } else {
            int x = image.getWidth() - g2d.getFontMetrics().stringWidth(watermarkText) - 10;
            int y = image.getHeight() - 10;
            g2d.drawString(watermarkText, x, y);
        }

        g2d.dispose();

        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        ImageIO.write(image, "png", baos);
        return baos.toByteArray();
    }

    /**
     * 编码用户标识：混淆后不可直接读出
     */
    private String encodeWatermark(Long userId) {
        // Base36 编码 + 固定前缀
        String encoded = Long.toString(userId * 7919L + 0xPT_OFFSET, 36);
        return "PT-" + encoded;
    }
}
```

#### 3.6.2 隐性水印（零宽字符/文本水印）

应用于文本型内容（AI 回答、解析文本）：

```java
/**
 * 基于零宽字符的文本隐性水印
 * 在文本中插入不可见的零宽字符序列，编码用户ID
 * 肉眼不可见，但可通过程序提取
 */
public class InvisibleTextWatermark {

    // 零宽字符映射
    private static final char ZWSP = '\u200B'; // Zero Width Space → 0
    private static final char ZWNJ = '\u200C'; // Zero Width Non-Joiner → 1
    private static final char ZWJ  = '\u200D'; // Zero Width Joiner → separator

    /**
     * 在文本中嵌入水印
     */
    public String embed(String text, Long userId) {
        String binary = Long.toBinaryString(userId);
        StringBuilder watermark = new StringBuilder();
        for (char c : binary.toCharArray()) {
            watermark.append(c == '0' ? ZWSP : ZWNJ);
        }
        watermark.append(ZWJ); // 结束分隔符

        // 在文本的第2个字符后插入水印
        if (text.length() < 2) return text;
        return text.substring(0, 2) + watermark.toString() + text.substring(2);
    }

    /**
     * 从文本中提取水印并还原用户ID
     */
    public Long extract(String text) {
        StringBuilder binary = new StringBuilder();
        boolean inWatermark = false;

        for (int i = 0; i < text.length(); i++) {
            char c = text.charAt(i);
            if (c == ZWSP) { inWatermark = true; binary.append('0'); }
            else if (c == ZWNJ) { inWatermark = true; binary.append('1'); }
            else if (c == ZWJ && inWatermark) { break; }
            else if (inWatermark) { break; }
        }

        if (binary.length() == 0) return null;
        return Long.parseLong(binary.toString(), 2);
    }
}
```

```java
@Service
public class SliderCaptchaValidator {

    /**
     * 验证滑块 + 轨迹
     */
    public ValidationResult validate(String challengeId, int answer, List<TracePoint> trace) {
        // 1. 验证 challengeId 是否存在且未过期
        Challenge challenge = challengeCache.get(challengeId);
        if (challenge == null || challenge.isExpired()) {
            return ValidationResult.fail("验证已过期，请重试");
        }

        // 2. 验证偏移量精度（±5px容差）
        if (Math.abs(answer - challenge.getTargetOffset()) > 5) {
            return ValidationResult.fail("位置不正确");
        }

        // 3. 分析滑动轨迹特征（防机器模拟）
        if (!isHumanLikeTrace(trace)) {
            return ValidationResult.fail("验证失败");
        }

        // 4. 删除 challenge，发放 passToken
        challengeCache.remove(challengeId);
        String passToken = generatePassToken(challenge.getUserId());
        return ValidationResult.ok(passToken);
    }

    /**
     * 判断轨迹是否符合人类操作特征
     */
    private boolean isHumanLikeTrace(List<TracePoint> trace) {
        if (trace.size() < 5) return false;

        // 人类特征：先加速后减速，末端微调
        // 机器特征：匀速直线、无微调、时间间隔完全均匀

        // 检查1：时间间隔是否有波动
        List<Long> intervals = extractIntervals(trace);
        double cv = coefficientOfVariation(intervals); // 变异系数
        if (cv < 0.15) return false; // 间隔过于均匀 → 机器

        // 检查2：是否有Y轴偏移（人类滑动会有微小Y方向抖动）
        double yVariance = calculateYVariance(trace);
        if (yVariance < 0.5) return false; // 完美直线 → 机器

        // 检查3：末端是否有减速微调
        double lastSegmentSpeed = avgSpeed(trace, trace.size() - 3, trace.size());
        double midSegmentSpeed = avgSpeed(trace, trace.size() / 2 - 1, trace.size() / 2 + 1);
        if (lastSegmentSpeed > midSegmentSpeed * 0.8) return false; // 末端未减速

        return true;
    }
}
```

## 6. 机器学习辅助识别

### 6.1 在线推理模型

对于规则引擎难以覆盖的复杂模式，使用轻量级 ML 模型辅助判断：

```python
# 反爬虫行为分类模型 —— LightGBM
# 训练数据：历史标注的 正常/爬虫 用户行为特征

import lightgbm as lgb
import numpy as np

class AntiCrawlModel:
    """
    特征列表（27维）：
    - 请求频率特征 (5): 1分钟/5分钟/1小时/24小时/7天请求数
    - 间隔统计特征 (4): 均值/标准差/最小值/中位数
    - 路径特征 (3): 路径熵/唯一路径比/顺序比
    - 时段特征 (3): 夜间比/工作时段比/周末比
    - 交互特征 (4): 滚动事件比/点击密度/输入事件比/页面切换方式比
    - 设备特征 (3): 关联账号数/IP变化频率/设备型号稀有度
    - 历史特征 (5): 历史违规次数/最近违规天数/验证码触发率/平均会话时长/会话时长方差
    """

    FEATURE_COUNT = 27

    def __init__(self, model_path):
        self.model = lgb.Booster(model_file=model_path)

    def predict(self, features: np.ndarray) -> dict:
        """
        :return: {"score": 0.0-1.0, "is_bot": bool, "top_features": [...]}"""
        prob = self.model.predict(features.reshape(1, -1))[0]
        return {
            "score": float(prob),
            "is_bot": prob > 0.65,
            "top_features": self._get_top_features(features)
        }

    def _get_top_features(self, features):
        """返回贡献最大的特征，用于可解释性"""
        importance = self.model.feature_importance(importance_type='gain')
        top_idx = np.argsort(importance)[::-1][:5]
        return [FEATURE_NAMES[i] for i in top_idx]
```

### 6.2 模型更新策略

- **训练频率**：每周离线训练一次
- **标注来源**：运营人工标注 + 高置信度规则自动标注
- **A/B 验证**：新模型先对 5% 流量生效，对比效果
- **回滚机制**：自动监控误伤率，超过 0.15% 立即回滚

### 7.1 签名 SDK 集成（Flutter）

```dart
// lib/security/request_signer.dart

class RequestSigner {
  static const String _appKey = String.fromEnvironment(
    'PT_APP_KEY',
    defaultValue: '', // 编译时注入
  );

  /// 为请求添加签名头
  static Map<String, String> signRequest({
    required String method,
    required String path,
    required Map<String, dynamic>? queryParams,
    required Uint8List? bodyBytes,
  }) {
    final timestamp = DateTime.now().millisecondsSinceEpoch;
    final nonce = _generateNonce();
    final deviceFp = DeviceFingerprint.instance.fingerprint;

    final bodyHash = bodyBytes != null
        ? sha256.convert(bodyBytes).toString()
        : '';

    final sortedQuery = _sortQueryString(queryParams);
    final salt = _generateSalt(timestamp);

    final message = '$method\n$path\n$sortedQuery\n$bodyHash\n$timestamp\n$nonce\n$deviceFp';
    final hmacKey = utf8.encode('$_appKey$salt');
    final signature = Hmac(sha256, hmacKey)
        .convert(utf8.encode(message))
        .toString();

    return {
      'X-PT-Sign': signature,
      'X-PT-Ts': timestamp.toString(),
      'X-PT-Nonce': nonce,
      'X-PT-SigVer': 'v2',
      'X-PT-Device': deviceFp,
    };
  }

  static String _generateNonce() {
    final random = Random.secure();
    final values = List<int>.generate(16, (_) => random.nextInt(256));
    return values.map((b) => b.toRadixString(16).padLeft(2, '0')).join();
  }

  static String _generateSalt(int timestamp) {
    // 与服务端一致的盐值算法
    final windowIndex = timestamp ~/ (5 * 60 * 1000);
    return sha256.convert(utf8.encode('${_appKey}_$windowIndex')).toString().substring(0, 16);
  }

  static String _sortQueryString(Map<String, dynamic>? params) {
    if (params == null || params.isEmpty) return '';
    final keys = params.keys.toList()..sort();
    return keys.map((k) => '$k=${params[k]}').join('&');
  }
}
```

### 7.2 Dio 拦截器集成

```dart
class SignatureInterceptor extends Interceptor {
  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) {
    // 白名单接口跳过签名
    if (_isWhitelisted(options.path)) {
      handler.next(options);
      return;
    }

    final headers = RequestSigner.signRequest(
      method: options.method.toUpperCase(),
      path: options.path,
      queryParams: options.queryParameters,
      bodyBytes: options.data is Uint8List ? options.data : null,
    );

    options.headers.addAll(headers);
    handler.next(options);
  }

  @override
  void onError(DioException err, ErrorInterceptorHandler handler) {
    // 4031 = 需要人机验证
    if (err.response?.statusCode == 200 &&
        err.response?.data?['code'] == 4031) {
      _triggerCaptcha(err.response!.data['data']);
      return;
    }
    handler.next(err);
  }

  void _triggerCaptcha(Map<String, dynamic> challengeData) {
    // 弹出验证码页面
    navigatorKey.currentState?.push(
      MaterialPageRoute(
        builder: (_) => CaptchaPage(challenge: challengeData),
      ),
    );
  }
}
```

### 9.1 引擎自身容错

```java
@Component
public class AntiCrawlFaultHandler {

    /**
     * 当反爬引擎不可用时的降级策略
     */
    public ResponseEntity<?> handleEngineUnavailable(ServerWebExchange exchange) {
        // 1. 记录告警
        alertService.send Alert(":warning: 反爬引擎不可用，业务降级为仅限流模式");

        // 2. 降级为仅基础限流（不执行行为分析/ML推理）
        boolean rateLimited = basicRateLimiter.check(exchange);
        if (rateLimited) {
            return ResponseEntity.ok(ApiResponse.error(429, "请求过于频繁"));
        }

        // 3. 放行请求
        return null; // 继续正常流程
    }
}
```

## 13. 安全与合规注意事项

1. **用户隐私**：设备指纹采集需在隐私政策中明示，不采集 IMEI/MAC 等敏感标识
2. **未成年人保护**：所有行为分析不涉及学习内容本身，仅分析请求模式
3. **数据最小化**：风险事件日志中的请求参数需脱敏（移除具体题目内容）
4. **申诉机制**：被拦截用户必须有申诉渠道，72 小时内响应
5. **误伤补偿**：因误拦截导致会员时长损失的，自动补偿
6. **签名密钥管理**：APP 编译密钥定期轮换，旧版本 APP 设置过渡期
