# 服务端-学生写作思维启发与创作过程智能辅助引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 作文辅导体系中专注于**写作前阶段（Pre-writing）**和**创作过程中（During-writing）**智能辅助的核心服务，解决学生"不知道写什么""不知道怎么开头""写着写着卡住了"三大写作起始与过程障碍。

与现有作文模块的分工边界：

| 现有模块 | 职责 | 与本引擎的关系 |
| --- | --- | --- |
| 作文审题分析与提纲生成 | 审题、立意方向、结构规划 | 本引擎在审题之后、提纲之前介入，提供创意素材 |
| 作文素材库管理 | 主题素材积累、名人事例管理 | 本引擎调用素材库并进行场景化重组 |
| 作文批改评分引擎 | 成文后评分、错别字、标点 | 本引擎服务于写作前/中，不涉及成文评分 |
| 作文润色建议引擎 | 词语替换、句式优化 | 本引擎关注创意激发，润色在成稿后 |
| 学生作文写作技法分析 | 修辞手法、技法识别评估 | 本引擎关注思维过程，技法分析在成稿后 |
| 学生写作过程行为分析 | 写作行为数据采集与画像 | 本引擎消费行为信号进行实时干预 |

### 1.2 设计目标

1. **降低写作启动门槛**：通过多模态启发手段（视觉/听觉/文字/结构化引导）帮助学生克服写作畏惧与空白页焦虑。
2. **分龄适配**：小学（看图说话→简单记叙）、初中（复杂记叙/简单议论）、高中（深度议论/散文/复杂文体）三级启发策略。
3. **实时创作陪伴**：在学生写作过程中，基于停顿、删除、重写等行为信号，提供适时引导而非替代写作。
4. **思维可视化**：将抽象的写作思维过程通过思维导图、鱼骨图、五感图等可视化工具呈现。
5. **启发而非代写**：严格遵循"启发式引导"原则，所有输出均为提示性、引导性内容，绝不生成完整段落替代学生写作。

### 1.3 适用范围

- **学科**：语文（主）、英语（辅）
- **学段**：小学三年级至高中三年级
- **文体覆盖**：记叙文、议论文、说明文、散文、读后感、应用文、想象作文
- **触发场景**：
  - 学生在作文辅导页面点击"开始写作"/"不知道怎么写"
  - 写作过程中长时间停顿（>30秒无输入）触发主动关怀
  - 教师布置作文后学生进入写作准备阶段
  - 写作课/语文课配套写作练习启动

## 3. 数据结构定义

### 3.1 核心数据表

#### 3.1.1 writing_inspiration_session（写作启发会话表）

```sql
CREATE TABLE writing_inspiration_session (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      VARCHAR(64) NOT NULL UNIQUE COMMENT '会话唯一标识',
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    composition_id  BIGINT DEFAULT NULL COMMENT '关联的作文ID（如已创建）',
    grade_stage     TINYINT NOT NULL COMMENT '学段: 1=小学 2=初中 3=高中',
    grade_level     INT NOT NULL COMMENT '具体年级，如 3=三年级',
    subject         VARCHAR(10) NOT NULL DEFAULT 'chinese' COMMENT '学科: chinese/english',
    
    -- 写作任务上下文
    essay_topic     VARCHAR(500) DEFAULT NULL COMMENT '作文题目',
    essay_type      VARCHAR(20) DEFAULT NULL COMMENT '文体: narrative/argumentative/expository/prose/reading_note/practical/imaginative',
    essay_requirement TEXT DEFAULT NULL COMMENT '写作要求（字数/格式/主题限制等）',
    textbook_chapter_id BIGINT DEFAULT NULL COMMENT '关联教材章节ID',
    
    -- 启发过程数据
    barrier_type    VARCHAR(30) DEFAULT NULL COMMENT '诊断的障碍类型: first_time/habitual_block/topic_confusion/perfectionism/idea_empty',
    strategy_used   JSON DEFAULT NULL COMMENT '使用的启发策略记录',
    inspiration_count INT DEFAULT 0 COMMENT '启发请求次数',
    total_duration_ms INT DEFAULT 0 COMMENT '启发会话总时长（毫秒）',
    
    -- 结果
    outcome         TINYINT DEFAULT 0 COMMENT '结果: 0=进行中 1=成功进入写作 2=放弃 3=超时',
    writing_started_at DATETIME DEFAULT NULL COMMENT '学生开始实际写作的时间',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_id (user_id),
    INDEX idx_created_at (created_at),
    INDEX idx_barrier_type (barrier_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作启发会话表';
```

#### 3.1.2 writing_inspiration_log（启发交互日志表）

```sql
CREATE TABLE writing_inspiration_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      VARCHAR(64) NOT NULL COMMENT '关联启发会话ID',
    user_id         BIGINT NOT NULL,
    seq_no          INT NOT NULL COMMENT '启发轮次序号（同一会话内递增）',
    
    -- 启发输入
    trigger_source  VARCHAR(20) NOT NULL COMMENT '触发来源: user_request/auto_block_detection/teacher_assign',
    trigger_context JSON DEFAULT NULL COMMENT '触发上下文（停顿时长/位置/行为信号等）',
    
    -- 启发输出
    inspiration_type VARCHAR(30) NOT NULL COMMENT '启发类型: sensory/mindmap/scenario/dialogue/structure/wordbank',
    inspiration_content JSON NOT NULL COMMENT '启发内容（结构化JSON，类型不同结构不同）',
    ai_model_used   VARCHAR(50) DEFAULT NULL COMMENT '使用的AI模型',
    ai_tokens_used  INT DEFAULT 0 COMMENT 'AI消耗Token数',
    
    -- 学生反馈
    student_action  VARCHAR(20) DEFAULT NULL COMMENT '学生响应: started_writing/requested_more/changed_direction/ignored/left',
    student_feedback TEXT DEFAULT NULL COMMENT '学生文字反馈（如有）',
    response_latency_ms INT DEFAULT NULL COMMENT '学生响应延迟（毫秒）',
    helpfulness_rating TINYINT DEFAULT NULL COMMENT '有用性评分 1-5（学生主动评价）',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_session_id (session_id),
    INDEX idx_user_id (user_id),
    INDEX idx_inspiration_type (inspiration_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作启发交互日志';
```

#### 3.1.3 writing_block_event（写作卡顿事件表）

```sql
CREATE TABLE writing_block_event (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      VARCHAR(64) DEFAULT NULL COMMENT '关联启发会话（如有）',
    user_id         BIGINT NOT NULL,
    composition_id  BIGINT DEFAULT NULL COMMENT '关联作文ID',
    
    -- 卡顿检测
    block_type      VARCHAR(30) NOT NULL COMMENT '卡顿类型: start_pause/mid_pause/high_delete_rate/repeated_rewrite/topic_wander',
    detected_at     DATETIME NOT NULL COMMENT '检测到卡顿的时间',
    pause_duration_ms INT NOT NULL COMMENT '停顿时长（毫秒）',
    cursor_position INT DEFAULT NULL COMMENT '卡顿时的光标位置（字符偏移）',
    
    -- 行为信号
    behavior_signals JSON DEFAULT NULL COMMENT '行为信号快照: {delete_rate, typing_speed, rewrite_count, scroll_count}',
    
    -- 干预
    intervention_triggered TINYINT DEFAULT 0 COMMENT '是否触发了干预: 0=否 1=是',
    intervention_type VARCHAR(30) DEFAULT NULL COMMENT '干预类型: gentle_nudge/suggestion/encouragement',
    intervention_content JSON DEFAULT NULL COMMENT '干预内容',
    intervention_outcome VARCHAR(20) DEFAULT NULL COMMENT '干预结果: resumed/ignored/requested_help/left',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_user_id (user_id),
    INDEX idx_composition_id (composition_id),
    INDEX idx_block_type (block_type),
    INDEX idx_detected_at (detected_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作卡顿事件表';
```

```java
/**
 * 写作启发会话
 */
@Data
public class WritingInspirationSession {
    private String sessionId;
    private Long userId;
    private Long compositionId;
    private GradeStage gradeStage;      // PRIMARY/JUNIOR/SENIOR
    private Integer gradeLevel;         // 1-12
    
    private String essayTopic;
    private EssayType essayType;        // NARRATIVE/ARGUMENTATIVE/EXPOSITORY/...
    private String essayRequirement;
    private Long textbookChapterId;
    
    private BarrierType barrierType;
    private List<StrategyRecord> strategiesUsed;
    private Integer inspirationCount;
    private Long totalDurationMs;
    
    private SessionOutcome outcome;     // IN_PROGRESS/SUCCESS/ABANDONED/TIMEOUT
    private LocalDateTime writingStartedAt;
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}

/**
 * 写作障碍类型
 */
public enum BarrierType {
    FIRST_TIME("首次写作", "学生第一次接触该文体或话题，不知从何下手"),
    HABITUAL_BLOCK("习惯性卡顿", "历史上反复出现写作启动困难"),
    TOPIC_CONFUSION("题目理解困难", "对题目要求、立意方向理解不清"),
    PERFECTIONISM("完美主义阻塞", "想写好但不知哪种切入最优，反复纠结"),
    IDEA_EMPTY("灵感枯竭", "有写作意愿但缺乏素材和想法"),
    EMOTIONAL_RESISTANCE("情绪抗拒", "对写作有厌烦/畏惧情绪");
    
    private final String label;
    private final String description;
}

/**
 * 启发策略
 */
public enum InspirationType {
    SENSORY("五感激发", "通过视觉/听觉/嗅觉/味觉/触觉引导观察"),
    MINDMAP("思维导图", "以中心话题展开联想网络"),
    SCENARIO("情境还原", "构建具体生活场景帮助学生回忆"),
    DIALOGUE("对话式引导", "通过苏格拉底式提问引导思考"),
    STRUCTURE("结构梳理", "提供可视化结构框架"),
    WORDBANK("词汇银行", "提供主题相关词汇和表达激活思维"),
    ROLE_PLAY("角色代入", "让学生代入特定角色视角思考"),
    WHAT_IF("假如式启发", "通过假设性问题拓展想象空间");
    
    private final String label;
    private final String description;
}

/**
 * 启发内容（多态结构，根据 inspirationType 不同有不同的 content）
 */
@Data
public class InspirationContent {
    private InspirationType type;
    private String title;               // 启发卡片标题
    private String introText;           // 引导语（展示给学生）
    
    // 五感激发
    private List<SensoryPrompt> sensoryPrompts;
    
    // 思维导图
    private MindmapNode mindmap;
    
    // 情境还原
    private List<ScenarioCard> scenarioCards;
    
    // 对话引导
    private List<DialogueQuestion> dialogueQuestions;
    
    // 结构框架
    private StructureFrame structureFrame;
    
    // 词汇银行
    private List<WordCategory> wordCategories;
    
    // 通用
    private List<String> tips;          // 写作小贴士
    private String encouragement;       // 鼓励语
}

/**
 * 五感激发提示
 */
@Data
public class SensoryPrompt {
    private String sense;               // sight/sound/smell/taste/touch
    private String senseLabel;          // 视觉/听觉/嗅觉/味觉/触觉
    private String question;            // 引导问题："你看到了什么？"
    private List<String> examples;      // 示例描述
    private String writingHint;         // 写作提示："试着用比喻描述这个画面"
}

/**
 * 思维导图节点
 */
@Data
public class MindmapNode {
    private String center;              // 中心话题
    private List<MindmapBranch> branches; // 分支
    
    @Data
    public static class MindmapBranch {
        private String keyword;          // 分支关键词
        private List<String> subKeywords; // 子关键词
        private String associationHint;   // 联想提示
    }
}

/**
 * 情境还原卡片
 */
@Data
public class ScenarioCard {
    private String sceneTitle;          // 场景标题
    private String sceneDescription;    // 场景描述
    private List<String> sensoryDetails; // 场景中的感官细节
    private List<String> emotionClues;   // 情感线索
    private String connectionQuestion;   // 联想问题："你经历过类似的场景吗？"
}

/**
 * 对话引导问题
 */
@Data
public class DialogueQuestion {
    private String question;            // 问题
    private String purpose;             // 提问目的
    private List<String> followUps;     // 追问方向
    private String expectedDirection;   // 期望引导的思考方向
}

/**
 * 写作结构框架
 */
@Data
public class StructureFrame {
    private String frameName;           // 框架名称（如"总分总""时间顺序"）
    private List<StructureSection> sections;
    
    @Data
    public static class StructureSection {
        private String sectionName;      // 段落名称
        private String purpose;          // 段落作用

/**
 * 词汇分类

@Data
public class WordCategory {

    }
```

### 5.1 写作障碍诊断算法

```python
class WritingBarrierDiagnoser:
    """写作障碍诊断器"""
    
    BARRIER_WEIGHTS = {
        'first_time': {'history_similarity': 0.4, 'topic_familiarity': 0.3, 'grade_level': 0.3},
        'habitual_block': {'history_pattern': 0.6, 'recent_success_rate': 0.4},
        'topic_confusion': {'topic_complexity': 0.4, 'student_level_gap': 0.3, 'requirement_clarity': 0.3},
        'perfectionism': {'personality_trait': 0.5, 'delete_rate_history': 0.3, 'revision_count': 0.2},
        'idea_empty': {'material_coverage': 0.4, 'recent_practice': 0.3, 'reading_volume': 0.3},
        'emotional_resistance': {'recent_failure_count': 0.4, 'negative_feedback': 0.3, 'session_drop_rate': 0.3}
    }
    
    def diagnose(self, user_id: int, context: WritingContext) -> BarrierDiagnosis:
        """
        诊断写作障碍类型
        """
        # 1. 获取学生写作历史画像
        profile = self.writing_profile_service.get_profile(user_id)
        
        # 2. 获取最近10次写作启发记录
        recent_sessions = self.session_repo.find_recent(user_id, limit=10)
        
        # 3. 计算各障碍类型得分
        scores = {}
        evidence = {}
        
        for barrier_type, weights in self.BARRIER_WEIGHTS.items():
            score, ev = self._calculate_barrier_score(
                barrier_type, weights, profile, recent_sessions, context
            )
            scores[barrier_type] = score
            evidence[barrier_type] = ev
        
        # 4. 选择得分最高的障碍类型
        best_type = max(scores, key=scores.get)
        
        return BarrierDiagnosis(
            barrier_type=best_type,
            confidence=scores[best_type],
            evidence=evidence[best_type],
            all_scores=scores
        )
    
    def _calculate_barrier_score(self, barrier_type, weights, profile, sessions, context):
        """计算特定障碍类型的得分"""
        score = 0.0
        evidence = []
        
        if barrier_type == 'first_time':
            # 检查是否首次接触该文体/话题
            essay_types_written = profile.essay_types_practiced
            if context.essay_type not in essay_types_written:
                score += weights['history_similarity']
                evidence.append(f"首次接触{context.essay_type.value}文体")
            
            topic_similarity = self._calc_topic_similarity(context.topic, profile.topics_written)
            if topic_similarity < 0.2:
                score += weights['topic_familiarity']
                evidence.append("话题与历史写作主题相似度低")
            
            if profile.total_essays < 3:
                score += weights['grade_level']
                evidence.append(f"历史写作数量少（{profile.total_essays}篇）")
        
        elif barrier_type == 'habitual_block':
            # 检查是否反复出现写作启动困难
            block_rate = sum(1 for s in sessions if s.outcome == 'abandoned') / max(len(sessions), 1)
            if block_rate > 0.4:
                score += weights['history_pattern']
                evidence.append(f"最近{len(sessions)}次中有{int(block_rate*len(sessions))}次放弃")
            
            recent_success = sum(1 for s in sessions if s.outcome == 'success') / max(len(sessions), 1)
            if recent_success < 0.3:
                score += weights['recent_success_rate']
                evidence.append(f"近期启发成功率低（{recent_success:.0%}）")
        
        elif barrier_type == 'idea_empty':
            # 检查素材储备和阅读量
            material_score = profile.material_coverage_score  # 0-1
            if material_score < 0.4:
                score += weights['material_coverage']
                evidence.append(f"素材库积累不足（覆盖率{material_score:.0%}）")
            
            days_since_last = profile.days_since_last_essay
            if days_since_last > 14:
                score += weights['recent_practice']
                evidence.append(f"距上次写作已{days_since_last}天")
        
        return min(score, 1.0), evidence
```

```python
class InspirationStrategySelector:
    """启发策略选择器"""
    
    # 文体-策略亲和度矩阵
    TYPE_STRATEGY_AFFINITY = {
        'narrative': {       # 记叙文
            'sensory': 0.9, 'scenario': 0.85, 'dialogue': 0.7,
            'mindmap': 0.5, 'structure': 0.4, 'wordbank': 0.5,
            'role_play': 0.6, 'what_if': 0.5
        },
        'argumentative': {   # 议论文
            'structure': 0.9, 'dialogue': 0.8, 'mindmap': 0.7,
            'wordbank': 0.6, 'sensory': 0.2, 'scenario': 0.4,
            'role_play': 0.3, 'what_if': 0.6
        },
        'descriptive': {     # 描写文
            'sensory': 0.95, 'scenario': 0.8, 'wordbank': 0.7,
            'mindmap': 0.5, 'structure': 0.3, 'dialogue': 0.4,
            'role_play': 0.3, 'what_if': 0.5
        },
        'imaginative': {     # 想象作文
            'what_if': 0.9, 'role_play': 0.85, 'scenario': 0.8,
            'mindmap': 0.7, 'sensory': 0.6, 'wordbank': 0.5,
            'structure': 0.3, 'dialogue': 0.6
        },
        # ... 其他文体
    }
    
    # 障碍-策略匹配
    BARRIER_STRATEGY_MATCH = {
        'first_time': ['structure', 'scenario', 'mindmap'],
        'habitual_block': ['sensory', 'scenario', 'what_if'],
        'topic_confusion': ['dialogue', 'structure', 'mindmap'],
        'perfectionism': ['dialogue', 'wordbank', 'scenario'],
        'idea_empty': ['sensory', 'scenario', 'mindmap', 'wordbank'],
        'emotional_resistance': ['scenario', 'role_play', 'what_if']
    }
    
    def select_strategy(
        self,
        barrier_type: str,
        essay_type: str,
        grade_stage: int,
        history: List[InspirationLog],
        student_preference: Optional[str] = None
    ) -> StrategyRecommendation:
        """选择最佳启发策略"""
        
        # 获取文体亲和度
        affinity = self.TYPE_STRATEGY_AFFINITY.get(essay_type, {})
        
        # 获取障碍推荐策略
        barrier_recommended = set(self.BARRIER_STRATEGY_MATCH.get(barrier_type, []))
        
        # 计算综合得分
        strategy_scores = {}
        for strategy, aff_score in affinity.items():
            # 文体亲和度（权重 0.4）
            score = aff_score * 0.4
            
            # 障碍匹配度（权重 0.35）
            barrier_bonus = 0.35 if strategy in barrier_recommended else 0.15
            score += barrier_bonus
            
            # 历史新鲜度：避免重复使用同一策略（权重 0.15）
            recent_types = [log.inspiration_type for log in history[-3:]]
            novelty = 1.0 - (recent_types.count(strategy) / max(len(recent_types), 1))
            score += novelty * 0.15
            
            # 学生偏好（权重 0.1）
            if student_preference == strategy:
                score += 0.1
            
            strategy_scores[strategy] = score
        
        # 排序选择
        sorted_strategies = sorted(strategy_scores.items(), key=lambda x: -x[1])
        primary = sorted_strategies[0][0]
        secondary = sorted_strategies[1][0] if len(sorted_strategies) > 1 else None
        
        return StrategyRecommendation(
            primary_type=primary,
            secondary_type=secondary,
            rationale=self._generate_rationale(primary, essay_type, barrier_type),
            confidence=sorted_strategies[0][1]
        )
```

### 5.4 卡顿检测算法

```python
class WritingBlockDetector:
    """写作卡顿检测器"""
    
    # 卡顿检测阈值配置
    THRESHOLDS = {
        'start_pause': {
            'min_pause_ms': 60000,       # 首次停笔 >60s
            'text_length_threshold': 20,  # 已写字数 <20
            'window_seconds': 120         # 检测窗口
        },
        'mid_pause': {
            'min_pause_ms': 30000,        # 写作中途停顿 >30s
            'text_length_threshold': 50,  # 已写字数 >50
        },
        'high_delete_rate': {
            'delete_ratio_threshold': 0.4, # 删除字符比 >40%
            'window_chars': 100,           # 100字窗口内
            'min_rewrites': 3             # 至少重写3次
        },
        'repeated_rewrite': {
            'rewrite_count_threshold': 5, # 同一段落重写5次以上
            'same_position_range': 20     # 20字符范围内
        },
        'topic_wander': {
            'semantic_drift_threshold': 0.35, # 语义偏移阈值
            'check_interval_chars': 200       # 每200字检查一次
        }
    }
    
    def detect_block(
        self,
        current_text: str,
        behavior_signals: BehaviorSignals,
        session_context: SessionContext
    ) -> Optional[BlockDetection]:
        """
        检测写作卡顿
        """
        text_len = len(current_text)
        pause_ms = behavior_signals.last_input_age * 1000
        
        # 检查各种卡顿类型
        detections = []
        
        # 1. 起始停顿（开始就卡住）
        if (text_len < self.THRESHOLDS['start_pause']['text_length_threshold'] and
            pause_ms > self.THRESHOLDS['start_pause']['min_pause_ms']):
            detections.append(('start_pause', 0.9))
        
        # 2. 中途停顿
        elif (text_len > self.THRESHOLDS['mid_pause']['text_length_threshold'] and
              pause_ms > self.THRESHOLDS['mid_pause']['min_pause_ms']):
            # 根据停顿时长和上下文调整置信度
            confidence = min(pause_ms / 60000, 1.0) * 0.8
            detections.append(('mid_pause', confidence))
        
        # 3. 高删除率
        if behavior_signals.delete_rate > self.THRESHOLDS['high_delete_rate']['delete_ratio_threshold']:
            confidence = behavior_signals.delete_rate * 0.9
            detections.append(('high_delete_rate', confidence))
        
        # 4. 反复重写
        if behavior_signals.rewrite_count >= self.THRESHOLDS['repeated_rewrite']['rewrite_count_threshold']:
            confidence = min(behavior_signals.rewrite_count / 10, 1.0) * 0.85
            detections.append(('repeated_rewrite', confidence))
        
        # 5. 话题偏移（语义检测）
        if text_len > 200:
            drift = self._calculate_semantic_drift(current_text, session_context.essay_topic)
            if drift > self.THRESHOLDS['topic_wander']['semantic_drift_threshold']:
                confidence = drift * 0.7
                detections.append(('topic_wander', confidence))
        
        if not detections:
            return None
        
        # 选择置信度最高的
        best_type, best_conf = max(detections, key=lambda x: x[1])
        
        return BlockDetection(
            block_type=best_type,
            confidence=best_conf,
            text_snapshot=current_text[-200:] if len(current_text) > 200 else current_text,
            behavior_signals=behavior_signals
        )
    
    def _calculate_semantic_drift(self, text: str, topic: str) -> float:
        """计算文本与主题的语义偏移度"""
        # 使用嵌入模型计算当前文本与主题的相似度
        text_embedding = self.embedding_service.embed(text)
        topic_embedding = self.embedding_service.embed(topic)
        similarity = cosine_similarity(text_embedding, topic_embedding)
        return 1.0 - similarity  # 偏移 = 1 - 相似度
```

```python
                'message': "💪 我注意到你在这段话上花了很多心思",
                'suggestion': "这段已经够好了！与其反复修改，不如继续往下写，整体完成后再回来打磨",
                'style': 'inline_bubble',
                'auto_dismiss_ms': 15000
            }
        },
        'topic_wander': {
            'suggestion': {
                'message_fn': lambda ctx: f"📌 等一下，我们看看题目——'{ctx['topic']}'",
                'suggestion': "目前的内容好像偏离了主题。要不要想想怎么把现在写的和题目联系起来？",
                'style': 'inline_bubble',
                'auto_dismiss_ms': 15000
            }
        }
    }
    
    def generate_intervention(
        self,
        block_detection: BlockDetection,
        context: SessionContext
    ) -> InterventionContent:
        """根据卡顿类型生成干预内容"""
        
        block_type = block_detection.block_type
        templates = self.INTERVENTION_TEMPLATES.get(block_type, {})
        
        # 根据学生个性和卡顿严重程度选择干预强度
        if block_detection.confidence > 0.8:
            intensity = 'suggestion' if 'suggestion' in templates else 'gentle_nudge'
        elif block_detection.confidence > 0.5:
            intensity = 'gentle_nudge'
        else:
            intensity = 'gentle_nudge'
        
        template = templates.get(intensity, templates.get('gentle_nudge', {}))
        
        # 构建上下文
        ctx = {
            'word_count': len(block_detection.text_snapshot),
            'topic': context.essay_topic,
            'current_paragraph': block_detection.text_snapshot
        }
        
        # 生成内容
        content = {}
        for key, value in template.items():
            if callable(value):
                content[key] = value(ctx)
            elif isinstance(value, dict) and 'message_fn' in value:
                content[key] = value['message_fn'](ctx)
            else:
                content[key] = value
        
        return InterventionContent(
            intervention_type=block_type,
            content=content,
            display_style=content.get('style', 'inline_bubble'),
            auto_dismiss_after_ms=content.get('auto_dismiss_ms', 10000)
        )
    
    def _generate_continuation_suggestion(self, ctx: dict) -> str:
        """基于当前文本内容生成续写建议"""
        prompt = f"""分析以下学生作文片段，给出一个简短的（15字以内）续写方向建议。
        
当前文本：{ctx['current_paragraph'][-200:]}

要求：
- 只给方向提示，不要给具体内容
- 语气要轻松鼓励
- 例如："接下来可以写写你的心情变化"

建议："""
        
        suggestion = self.ai_service.generate(
            prompt=prompt,
            max_tokens=30,
            temperature=0.7
        )
        return suggestion.strip()
```

### 7.2 状态流转规则

```java
public class InspirationSessionStateMachine {
    
    private static final Map<State, Set<State>> TRANSITIONS = Map.of(
        State.CREATED,      Set.of(State.DIAGNOSED, State.FINISHED),
        State.DIAGNOSED,    Set.of(State.INSPIRING, State.FINISHED),
        State.INSPIRING,    Set.of(State.WRITING_IN_PROGRESS, State.INSPIRING, State.FINISHED),
        State.WRITING_IN_PROGRESS, Set.of(State.INSPIRING, State.FINISHED)
    );
    
    public void transition(InspirationSession session, State target, String reason) {
        State current = session.getState();
        validateTransition(current, target);
        
        switch (target) {
            case INSPIRING:
                session.setInspirationCount(session.getInspirationCount() + 1);
                break;
            case WRITING_IN_PROGRESS:
                if (session.getWritingStartedAt() == null) {
                    session.setWritingStartedAt(LocalDateTime.now());
                }
                break;
            case FINISHED:
                session.setOutcome(determineOutcome(reason));
                break;
        }
        
        session.setState(target);
        session.setUpdatedAt(LocalDateTime.now());
    }
    
    private SessionOutcome determineOutcome(String reason) {
        return switch (reason) {
            case "writing_completed" -> SessionOutcome.SUCCESS;
            case "user_left", "user_gave_up" -> SessionOutcome.ABANDONED;
            case "timeout" -> SessionOutcome.TIMEOUT;
            default -> SessionOutcome.IN_PROGRESS;
        };
    }
}
```

## 8. 错误处理与降级策略

### 8.1 错误码定义

| 错误码 | 含义 | 处理策略 |
| --- | --- | --- |
| WI-4001 | 作文题目为空且无法推断 | 返回提示"请先告诉我你想写什么主题" |
| WI-4002 | 不支持的文体类型 | 使用默认文体（记叙文）策略 |
| WI-4003 | 学段信息缺失 | 使用默认学段（初中）策略 |
| WI-4101 | 启发次数超出限制（>10次/会话） | 提示"也许今天可以先休息，明天再写" |
| WI-4102 | AI生成内容安全过滤未通过 | 重试一次，仍失败则使用预置模板 |
| WI-4103 | AI生成内容不符合启发规范 | 使用规则模板兜底 |
| WI-5001 | AI模型调用失败 | 降级为预置启发模板 |
| WI-5002 | 素材库查询超时 | 跳过素材匹配，纯AI生成 |
| WI-5003 | 行为信号处理延迟 | 放弃实时干预，记录异步处理 |
| WI-5004 | 嵌入服务不可用 | 跳过语义偏移检测 |

### 8.2 降级层次

```
正常流程：
  AI大模型生成个性化启发内容
       │ 失败/超时(3s)
       ▼
第一降级：
  使用预置启发模板 + 素材库匹配
       │ 失败
       ▼
第二降级：
  使用通用启发模板（按文体+学段）
       │ 失败
       ▼
第三降级：
  展示写作步骤引导文字（静态）
```

### 8.3 降级实现

```java
@Service
public class InspirationContentGenerator {
    
    public InspirationContent generate(InspirationRequest request) {
        try {
            // 尝试 AI 生成
            return generateByAI(request);
            
        } catch (AITimeoutException | AIServiceException e) {
            log.warn("AI启发生成失败，降级到模板模式: {}", e.getMessage());
            try {
                // 第一降级：模板 + 素材
                return generateByTemplateWithMaterials(request);
                
            } catch (Exception ex) {
                log.warn("模板启发生成失败，降级到静态模板: {}", ex.getMessage());
                // 第二降级：通用模板
                return generateByStaticTemplate(request);
            }
        }
    }
    
    private InspirationContent generateByAI(InspirationRequest request) {
        String prompt = buildPrompt(request);
        
        // 设置较短超时，确保快速响应
        AIRequest aiRequest = AIRequest.builder()
            .prompt(prompt)
            .maxTokens(800)
            .temperature(0.8)
            .timeout(Duration.ofSeconds(5))
            .build();
        
        String response = aiService.generate(aiRequest);
        
        // 安全校验
        SafetyCheckResult safety = contentSafetyService.check(response);
        if (!safety.isSafe()) {
            throw new AIContentUnsafeException(safety.getReason());
        }
        
        // 格式校验
        try {
            return parseInspirationContent(response, request.getType());
        } catch (ParseException e) {
            throw new AIContentInvalidException("AI输出格式不符合启发内容规范", e);
        }
    }
    
    private InspirationContent generateByStaticTemplate(InspirationRequest request) {
        // 从数据库加载预置模板
        WritingInspirationTemplate template = templateRepo
            .findByTypeAndStage(
                request.getInspirationType(),
                request.getGradeStage(),
                request.getEssayType()
            )
            .orElseThrow(() -> new RuntimeException("无可用启发模板"));
        
        return InspirationContent.fromTemplate(template);
    }
}
```

```java
@Service
public class OptimizedInspirationService {
    
    /**
     * 流式返回启发内容，减少首字节延迟

    public Flux<InspirationChunk> generateStreaming(InspirationRequest request) {
```

## 10. 安全与合规

### 10.1 内容安全

- **AI输出安全过滤**：所有AI生成的启发内容必须经过内容安全管线（敏感词过滤 + 意图检测 + 适龄性检查）。
- **启发内容边界**：启发内容严禁包含完整段落或可直接抄写的句子，仅提供方向性提示。
- **字数限制**：单次启发的引导文字总量不超过200字，避免信息过载。

### 10.2 学生数据保护

- **写作内容隐私**：学生的写作内容和行为数据仅用于个人启发，不展示给其他学生。
- **数据脱敏**：分析报告中的学生文本引用需脱敏处理。
- **家长可见性**：家长可查看"是否使用了启发功能"和"启发次数"，但不可查看具体启发内容交互记录（保护学生创作隐私）。

### 10.3 防滥用机制

```java
@Component
public class InspirationRateLimiter {
    
    // 每次启发会话最多请求10轮启发
    private static final int MAX_INSPIRATIONS_PER_SESSION = 10;
    
    // 每天最多启动20个启发会话
    private static final int MAX_SESSIONS_PER_DAY = 20;
    
    // 同一题目最多启动3个启发会话
    private static final int MAX_SESSIONS_PER_TOPIC = 3;
    
    public void checkLimit(Long userId, String topic) {
        // 检查日限
        int todayCount = sessionRepo.countTodayByUser(userId);
        if (todayCount >= MAX_SESSIONS_PER_DAY) {
            throw new RateLimitException("WI-4101", 
                "今天已经进行了很多次写作练习，也许可以先用启发的内容写写看？");
        }
        
        // 检查题目限
        int topicCount = sessionRepo.countByUserAndTopic(userId, topic);
        if (topicCount >= MAX_SESSIONS_PER_TOPIC) {
            throw new RateLimitException("WI-4101",
                "这个题目已经一起探索过了，试着用之前的灵感开始写吧！");
        }
    }
}
```

### 10.4 未成年人保护

- **鼓励独立完成**：所有启发内容设计遵循"引导思考 > 提供信息 > 代替写作"的优先级。
- **防依赖机制**：当检测到学生频繁使用启发（>15次/周），系统推送温和提醒："你已经很有想法了，试试这次自己先写5分钟？"
- **正向心理引导**：干预内容以鼓励为主，避免"你又卡住了"等负面暗示。

### 15.3 术语表

| 术语 | 说明 |
| --- | --- |
| 写作障碍（Writing Block） | 学生在写作过程中遇到的无法继续创作的心理或认知障碍 |
| 启发（Inspiration） | 通过引导而非替代的方式帮助学生产生写作思路 |
| 微干预（Micro-intervention） | 写作过程中的轻量级提示，不打断写作节奏 |
| 五感启发（Sensory Inspiration） | 通过调动视觉/听觉/嗅觉/味觉/触觉来打开写作思路 |
| 苏格拉底式引导 | 通过提问而非告知答案的方式引导学生自行发现思路 |
| 空白页焦虑（Blank Page Anxiety） | 面对空白文档时产生的畏惧和回避心理 |
| 写作画像（Writing Profile） | 学生历史写作行为和成果的结构化数据画像 |
