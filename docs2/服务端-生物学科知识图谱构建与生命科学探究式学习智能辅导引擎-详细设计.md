# 生物学科知识图谱构建与生命科学探究式学习智能辅导引擎 - 详细设计

## 1. 概述

### 1.1 模块定位

本模块是 PrimeTop 全学段 AI 辅助学习平台中**生物学科**的专用智能辅导引擎，为初中、高中（含高考备考）阶段学生提供生物学科的知识讲解、实验设计辅导、遗传推理训练、图表数据分析、探究式学习引导和个性化薄弱点突破服务。

作为全学科辅导体系的关键拼图（物理、化学、历史、地理、政治均已具备专用引擎），生物引擎聚焦于生命科学的独特认知范式——从微观分子到宏观生态的跨尺度理解、实验观察与逻辑推理的紧密结合、遗传概率的数学化分析以及STSE（科学·技术·社会·环境）素养培养。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 生物知识体系管理 | 构建覆盖初中到高中的生物学知识图谱，包含分子与细胞、遗传与进化、稳态与调节、生物与环境四大领域 |
| 概念关系推理 | 识别生物学概念间的层级、并列、因果、对立等关系，支持概念溯源和知识链条推演 |
| 实验设计辅导 | 引导学生理解实验原理、变量控制、对照设置、预期结果和结论推导 |
| 遗传专题推理 | 系谱分析、概率计算、变异判断的逐步推理与可视化 |
| 图表数据分析 | 细胞图、遗传图、生态数据图、实验结果图的识别、解读和计算 |
| 探究式学习 | 以现象为起点的探究学习路径编排，培养科学思维 |
| 迷思概念纠偏 | 检测常见生物学误解并生成针对性纠正教学策略 |
| STSE素养培养 | 结合社会议题（健康、环境、生物技术）展开跨情境学习 |

### 1.3 依赖关系

```
本引擎
├── 依赖 → 通用知识图谱服务（知识点存储、关系查询）
├── 依赖 → AI编排引擎（大模型调用、Prompt管理、流式响应）
├── 依赖 → RAG检索引擎（教材知识库检索、题目检索）
├── 依赖 → 题目智能推荐服务（练习编排）
├── 依赖 → 学习画像服务（学生能力维度、掌握度数据）
├── 依赖 → 错题服务（错因归集、薄弱点输入）
├── 依赖 → 虚拟实验服务（实验模拟数据交互）
├── 依赖 → 图片处理与OCR识别管线（生物图表识别）
└── 输出 → 学习行为事件流（答题记录、学习进度）
```

### 1.4 学段适配范围

| 学段 | 课程标准 | 核心模块 | 辅导重点 |
| --- | --- | --- | --- |
| 初中（7-8年级） | 义务教育生物学课程标准 | 植物与动物、人体生理、生态系统、生物多样性 | 概念理解、观察描述、基础实验 |

| 高考备考 | 高考生物考试大纲 | 全模块整合复习 | 考点突破、真题训练、综合推理 |

## 2. 数据模型

### 2.1 生物知识图谱核心实体

#### 2.1.1 知识领域（BioKnowledgeDomain）

```typescript
interface BioKnowledgeDomain {
  domainId: string;              // 领域ID，如 "MOLECULAR_CELL"
  name: string;                  // 领域名称，如 "分子与细胞"
  code: string;                  // 领域编码
  description: string;           // 领域描述
  curriculumLevel: 'MIDDLE' | 'HIGH_REQUIRED' | 'HIGH_ELECTIVE';
  knowledgePointCount: number;   // 包含知识点数量
  sortOrder: number;             // 排序序号
}
```

四大核心领域：

| domainId | name | curriculumLevel |
| --- | --- | --- |
| MOLECULAR_CELL | 分子与细胞 | HIGH_REQUIRED |
| HEREDITY_EVOLUTION | 遗传与进化 | HIGH_REQUIRED |
| HOMEOSTASIS_REGULATION | 稳态与调节 | HIGH_ELECTIVE |
| ECOLOGY_ENVIRONMENT | 生物与环境 | HIGH_ELECTIVE |

#### 2.1.2 知识点（BioKnowledgePoint）

```typescript
interface BioKnowledgePoint {
  pointId: string;               // 知识点ID，如 "KP_BIO_001"
  domainId: string;              // 所属领域
  name: string;                  // 知识点名称，如 "光合作用"
  aliases: string[];             // 别名，如 ["photosynthesis"]
  cognitiveLevel: 'KNOW' | 'UNDERSTAND' | 'APPLY' | 'ANALYZE' | 'EVALUATE' | 'CREATE';
                                 // 布鲁姆认知层级
  curriculumStandard: string;    // 课标要求描述
  textbookRefs: TextbookRef[];   // 教材引用（版本+章节）
  prerequisites: string[];       // 前置知识点ID列表
  relatedPoints: string[];       // 关联知识点ID列表
  commonMisconceptions: string[];// 常见迷思概念ID列表
  difficulty: 1 | 2 | 3 | 4 | 5; // 难度等级（1最易，5最难）
  examFrequency: 'LOW' | 'MEDIUM' | 'HIGH' | 'VERY_HIGH'; // 考试出现频率
  description: string;           // 详细描述
  keyTerms: string[];            // 核心术语列表
  experimentRefs: string[];      // 关联实验ID列表
  tags: string[];                // 标签（如 "高考高频"、"实验探究"、"计算题"）
}
```

#### 2.1.3 知识关系（BioKnowledgeRelation）

```typescript
interface BioKnowledgeRelation {
  relationId: string;
  sourcePointId: string;         // 源知识点
  targetPointId: string;         // 目标知识点
  relationType: BioRelationType;
  description: string;           // 关系描述
  strength: number;              // 关联强度 0.0-1.0
}

type BioRelationType =
  | 'PREREQUISITE'        // 前置依赖（学B需先学A）
  | 'PARENT_CHILD'        // 父子层级（A包含B）
  | 'CAUSAL'              // 因果关系（A导致B）
  | 'COMPARISON'          // 对比关系（A与B比较）
  | 'PROCESS_SEQUENCE'    // 过程顺序（A发生在B之前）
  | 'STRUCTURE_FUNCTION'  // 结构功能（A的结构决定B的功能）
  | 'ANALOGY';            // 类比关系
```

### 2.2 实验模型

#### 2.2.1 实验定义（BioExperiment）

```typescript
interface BioExperiment {
  experimentId: string;          // 实验ID
  name: string;                  // 实验名称，如 "探究酵母菌的呼吸方式"
  category: 'MOLECULAR' | 'CELL' | 'GENETIC' | 'PHYSIOLOGICAL' | 'ECOLOGICAL' | 'BIOTECH';
  objective: string;             // 实验目的
  principle: string;             // 实验原理
  materials: string[];           // 实验材料与器材
  reagents: string[];            // 试剂
  procedures: ExperimentStep[];  // 实验步骤
  variables: {
    independent: string;         // 自变量
    dependent: string;           // 因变量
    controlled: string[];        // 无关变量（需控制）
  };
  controlGroup: string;          // 对照组描述
  expectedResults: string;       // 预期结果
  conclusionTemplate: string;    // 结论模板
  points: string[];              // 考查要点
  commonErrors: string[];        // 常见操作错误
  difficulty: 1 | 2 | 3 | 4 | 5;
  curriculumLevel: 'MIDDLE' | 'HIGH_REQUIRED' | 'HIGH_ELECTIVE';
}

interface ExperimentStep {
  stepNumber: number;
  description: string;           // 步骤描述
  purpose: string;               // 该步骤目的
  duration: string;              // 预计时长
  keyOperation: string;          // 关键操作要点
  precautions: string[];         // 注意事项
}
```

#### 2.2.2 遗传推理问题（GeneticsProblem）

```typescript
interface GeneticsProblem {
  problemId: string;
  type: 'PEDIGREE' | 'CROSS' | 'PROBABILITY' | 'MOLECULAR' | 'POPULATION';
  scenario: string;              // 题目情境
  pedigreeImage?: string;        // 系谱图URL（如有）
  givenConditions: string[];     // 已知条件
  questions: GeneticsQuestion[]; // 子问题列表
  difficulty: 1 | 2 | 3 | 4 | 5;
  knowledgePoints: string[];     // 涉及知识点
}

interface GeneticsQuestion {
  questionId: string;
  questionText: string;          // 问题文本
  answerType: 'GENOTYPE' | 'PHENOTYPE' | 'PROBABILITY' | 'JUDGMENT' | 'EXPLANATION';
  correctAnswer: string;         // 标准答案
  reasoningChain: ReasoningStep[]; // 推理步骤链
  scoringCriteria: string;       // 评分标准
}

interface ReasoningStep {
  stepNumber: number;
  description: string;           // 推理描述
  mathematicalBasis?: string;    // 数学依据（如庞纳特方格）
  result: string;                // 本步结论
}
```

### 3.2 核心接口详细设计

  "context": {
    "grade": "高一",
    "textbookVersion": "人教版-2019",
    "curriculumLevel": "HIGH_REQUIRED",
    "sessionMode": "EXPLANATION",
    "priorKnowledgeLevel": 0.45,
    "preferredStyle": "STRUCTURED",
    "language": "zh-CN"
  },
  "options": {
    "includeDiagram": true,
    "includeAnalogy": true,

### 4.4 迷思概念检测算法

```python
def detect_misconception(
    student_response: str,
    point_id: str,
    profile: BioStudentProfile
) -> DetectionResult:
    """
    三阶段检测策略：
    1. 模式匹配（快速初筛）
    2. 语义相似度计算（中度精度）
    3. 大模型深度分析（高精度，异步）
    """
    # Stage 1: 关键词/模式匹配
    misconceptions = get_misconceptions_by_point(point_id)
    pattern_hits = []
    for mc in misconceptions:
        patterns = parse_detection_patterns(mc.detection_pattern)
        for pattern in patterns:
            if pattern_match(pattern, student_response):
                pattern_hits.append((mc, 0.6))  # 基础置信度

    # Stage 2: 语义相似度
    response_embedding = embed(student_response)
    for mc in misconceptions:
        mc_embedding = embed(mc.misconception)
        sim = cosine_similarity(response_embedding, mc_embedding)
        if sim > 0.75:
            # 检查是否已在pattern_hits中
            existing = find_in_hits(pattern_hits, mc.id)
            if existing:
                existing.score = max(existing.score, sim)
            else:
                pattern_hits.append((mc, sim))

    # Stage 3: 如前两阶段命中数<1，触发大模型分析（异步）
    if len(pattern_hits) == 0 and len(student_response) > 20:
        # 异步提交大模型分析任务
        submit_async_llm_analysis(student_response, point_id)

    # 过滤置信度阈值
    confirmed = [h for h in pattern_hits if h[1] >= 0.5]
    confirmed.sort(key=lambda x: x[1], reverse=True)

    return DetectionResult(
        detected=len(confirmed) > 0,
        matched=confirmed[:3],  # 返回top 3
        overall_score=calculate_misconception_score(confirmed)
    )
```

async def update_profile_after_session(

    """
    辅导会话结束后，增量更新学生能力画像。
    采用贝叶斯知识追踪(BKT)变体。
    """
    profile = await get_bio_profile(user_id)
    point_id = session.topic_point_id

    # 1. 更新知识点掌握度（BKT四参数模型简化版）
    prior = profile.point_mastery.get(point_id, 0.5)
    if assessment_result.answered_correctly:
        # 正确回答：掌握度上升
        posterior = prior + (1 - prior) * LEARN_RATE * assessment_result.difficulty_weight
    else:
        # 错误回答：掌握度下降
        posterior = prior * (1 - SLIP_RATE * assessment_result.difficulty_weight)

    posterior = clamp(posterior, 0.01, 0.99)
    profile.point_mastery[point_id] = posterior

    # 2. 更新领域掌握度（取该领域所有知识点均值）
    domain_points = get_points_by_domain(session.domain_id)
    domain_scores = [profile.point_mastery.get(p.id, 0.5) for p in domain_points]
    profile.domain_mastery[session.domain_id] = mean(domain_scores)

    # 3. 更新能力维度（基于会话类型映射）
    skill_map = {
        'CONCEPT': 'concept_understanding',
        'EXPERIMENT': 'experiment_design',
        'GENETICS': 'genetic_reasoning',
        'DIAGRAM': 'diagram_interpretation',
        'INQUIRY': 'inquiry_thinking'
    }
    skill = skill_map.get(session.session_type, 'concept_understanding')
    current = profile.skill_dimensions.get(skill, 0.5)
    delta = assessment_result.understanding_delta or 0
    profile.skill_dimensions[skill] = clamp(current + delta * 0.3, 0.0, 1.0)

    # 4. 更新迷思标签
    if assessment_result.new_misconceptions:
        existing = set(profile.misconception_tags or [])
        existing.update(assessment_result.new_misconceptions)
        profile.misconception_tags = list(existing)

    profile.last_assessed_at = datetime.now()
    profile.version += 1

    await save_bio_profile(user_id, profile)
    invalidate_profile_cache(user_id)

                'related_points': point.related_points_summary,
                'question': question,
                'misconception_warnings': misconception_warnings,
                'difficulty_hint': difficulty_hint
            }
        )

    def _get_difficulty_hint(self, prior_level: float) -> str:
        if prior_level < 0.3:
            return "学生基础薄弱，从基本概念开始，使用大量类比，避免过多术语堆砌"
        elif prior_level < 0.6:
            return "学生有基本了解，适度增加深度，注重概念间的联系"
        else:
            return "学生掌握较好，可以深入拓展，引入更高阶的综合分析"

    def _format_misconception_warnings(
        self, misconceptions: list, prior_level: float
    ) -> str:

            warnings.append(

                f"正确理解是：{mc.correct_concept}"
            )

    private void executeGeneticsTutoring(
        SseEmitter emitter,
        BioGeneticsTutorRequest request
    ) throws IOException {
        GeneticsStateMachine machine = new GeneticsStateMachine();

        // 如果有图片，先进行图表分析
        if (request.getImageUrls() != null && !request.getImageUrls().isEmpty()) {
            machine.fire(GeneticsEvent.IMAGE_PROVIDED);
            BioDiagramAnalysis analysis = analyzeGeneticDiagram(
                request.getImageUrls().get(0));
            emitter.send(SseEmitter.event()
                .name("image_analysis")
                .data(analysis));
            machine.setAnalysisContext(analysis);
        }

        // 逐步推理
        List<ReasoningStep> steps = planGeneticsReasoning(
            request.getScenario(),
            request.getProblemType(),
            machine.getAnalysisContext()
        );

        for (ReasoningStep step : steps) {
            machine.fire(GeneticsEvent.STEP_COMPLETED);
            emitter.send(SseEmitter.event()
                .name("reasoning")
                .data(step));

            // 如果需要庞纳特方格
            if (step.requiresPunnettSquare()) {
                PunnettSquare square = buildPunnettSquare(step);
                emitter.send(SseEmitter.event()
                    .name("punnett_square")
                    .data(square));
            }
        }

        // 输出总结
        GeneticsSummary summary = buildSummary(steps, machine);
        emitter.send(SseEmitter.event()
            .name("complete")
            .data(summary));
        emitter.complete();
    }
}

/**
 * 遗传推理状态机
 */
public class GeneticsStateMachine {

    private GeneticsState currentState = GeneticsState.START;
    private GeneticsType deducedType;
    private Map<String, Object> analysisContext = new HashMap<>();
    private final List<GeneticsState> history = new ArrayList<>();

    public enum GeneticsState {
        START,
        IMAGE_ANALYSIS,
        TYPE_DEDUCTION,
        AUTOSOMAL_DOMINANT,
        AUTOSOMAL_RECESSIVE,
        SEX_LINKED_DOMINANT,
        SEX_LINKED_RECESSIVE,
        GENOTYPE_INFERENCE,
        PROBABILITY_CALC,
        VERIFICATION,
        OUTPUT_FORMAT,
        DONE
    }

    public enum GeneticsEvent {
        IMAGE_PROVIDED,
        ANALYSIS_DONE,
        TYPE_AUTOSOMAL_DOM,
        TYPE_AUTOSOMAL_REC,
        TYPE_SEX_LINKED_DOM,
        TYPE_SEX_LINKED_REC,
        TYPE_COMPLEX,
        GENOTYPE_DONE,
        NEED_PROBABILITY,
        NO_PROBABILITY_NEEDED,
        CALC_DONE,
        VERIFIED,
        INCONSISTENCY_FOUND,
        BACKTRACK,
        FORMATTED
    }

    private static final Map<GeneticsState, Map<GeneticsEvent, GeneticsState>> TRANSITIONS;

    static {
        TRANSITIONS = new EnumMap<>(GeneticsState.class);

        // START
        TRANSITIONS.put(GeneticsState.START, Map.of(
            GeneticsEvent.IMAGE_PROVIDED, GeneticsState.IMAGE_ANALYSIS,
            GeneticsEvent.TYPE_AUTOSOMAL_DOM, GeneticsState.AUTOSOMAL_DOMINANT,
            GeneticsEvent.TYPE_AUTOSOMAL_REC, GeneticsState.AUTOSOMAL_RECESSIVE,
            GeneticsEvent.TYPE_SEX_LINKED_DOM, GeneticsState.SEX_LINKED_DOMINANT,
            GeneticsEvent.TYPE_SEX_LINKED_REC, GeneticsState.SEX_LINKED_RECESSIVE
        ));

        // IMAGE_ANALYSIS
        TRANSITIONS.put(GeneticsState.IMAGE_ANALYSIS, Map.of(
            GeneticsEvent.ANALYSIS_DONE, GeneticsState.TYPE_DEDUCTION
        ));

        // TYPE_DEDUCTION
        TRANSITIONS.put(GeneticsState.TYPE_DEDUCTION, Map.of(
            GeneticsEvent.TYPE_AUTOSOMAL_DOM, GeneticsState.AUTOSOMAL_DOMINANT,
            GeneticsEvent.TYPE_AUTOSOMAL_REC, GeneticsState.AUTOSOMAL_RECESSIVE,
            GeneticsEvent.TYPE_SEX_LINKED_DOM, GeneticsState.SEX_LINKED_DOMINANT,
            GeneticsEvent.TYPE_SEX_LINKED_REC, GeneticsState.SEX_LINKED_RECESSIVE,
            GeneticsEvent.TYPE_COMPLEX, GeneticsState.OUTPUT_FORMAT
        ));

        // 各遗传类型 → 基因型推断
        for (GeneticsState typeState : List.of(
            GeneticsState.AUTOSOMAL_DOMINANT,
            GeneticsState.AUTOSOMAL_RECESSIVE,
            GeneticsState.SEX_LINKED_DOMINANT,
            GeneticsState.SEX_LINKED_RECESSIVE
        )) {
            TRANSITIONS.put(typeState, Map.of(
                GeneticsEvent.GENOTYPE_DONE, GeneticsState.GENOTYPE_INFERENCE
            ));
        }

        // GENOTYPE_INFERENCE
        TRANSITIONS.put(GeneticsState.GENOTYPE_INFERENCE, Map.of(
            GeneticsEvent.NEED_PROBABILITY, GeneticsState.PROBABILITY_CALC,
            GeneticsEvent.NO_PROBABILITY_NEEDED, GeneticsState.VERIFICATION
        ));

        // PROBABILITY_CALC
        TRANSITIONS.put(GeneticsState.PROBABILITY_CALC, Map.of(
            GeneticsEvent.CALC_DONE, GeneticsState.VERIFICATION
        ));

        // VERIFICATION
        TRANSITIONS.put(GeneticsState.VERIFICATION, Map.of(
            GeneticsEvent.VERIFIED, GeneticsState.OUTPUT_FORMAT,
            GeneticsEvent.INCONSISTENCY_FOUND, GeneticsState.GENOTYPE_INFERENCE
        ));

        // OUTPUT_FORMAT
        TRANSITIONS.put(GeneticsState.OUTPUT_FORMAT, Map.of(
            GeneticsEvent.FORMATTED, GeneticsState.DONE
        ));
    }

    public void fire(GeneticsEvent event) {
        Map<GeneticsEvent, GeneticsState> possible = TRANSITIONS.get(currentState);
        if (possible == null || !possible.containsKey(event)) {
            throw new IllegalStateException(
                String.format("Invalid transition: %s + %s", currentState, event));
        }
        history.add(currentState);
        currentState = possible.get(event);
    }

    public void setDeducedType(GeneticsType type) {
        this.deducedType = type;
    }

    public void setAnalysisContext(BioDiagramAnalysis analysis) {
        this.analysisContext.put("recognizedElements", analysis.getRecognizedElements());
        this.analysisContext.put("confidence", analysis.getConfidence());
    }

    public GeneticsState getCurrentState() { return currentState; }
    public List<GeneticsState> getHistory() { return Collections.unmodifiableList(history); }
}

        InquiryStage currentStage,
        String studentResponse
    ) {
        // 1. 评价学生回答
        InquiryResponseEvaluation evaluation = evaluateStudentResponse(
            currentStage, studentResponse);

        // 2. 决定是否推进
        InquiryStage nextStage;
        if (evaluation.isAdequate()) {
            nextStage = NEXT_STAGE.getOrDefault(currentStage, currentStage);
        } else if (evaluation.getRetryCount() >= 2) {
            // 允许跳过
            nextStage = NEXT_STAGE.getOrDefault(currentStage, currentStage);
        } else {
            // 留在当前阶段，提供更多引导
            return InquiryStageResponse.retry(
                currentStage,
                evaluation.getFeedback(),
                evaluation.getAdditionalHints()
            );
        }

        // 3. 如果进入实验设计阶段，且需要虚拟实验
        if (nextStage == InquiryStage.EXPERIMENT_DESIGN) {
            return InquiryStageResponse.advance(
                nextStage,
                generateExperimentGuidance(studentResponse),
                true  // includesVirtualExperiment
            );
        }

        // 4. 生成下一阶段内容
        String stageContent = generateStageContent(nextStage, studentResponse);
        return InquiryStageResponse.advance(nextStage, stageContent, false);
    }

    /**
     * 评价学生在探究各阶段的回答
     */
    private InquiryResponseEvaluation evaluateStudentResponse(
        InquiryStage stage,
        String response
    ) {
        return switch (stage) {
            case QUESTION -> evaluateQuestionQuality(response);
            case HYPOTHESIS -> evaluateHypothesisQuality(response);
            case EXPERIMENT_DESIGN -> evaluateDesignQuality(response);
            case RESULT_PREDICTION -> evaluatePredictionQuality(response);
            case CONCLUSION -> evaluateConclusionQuality(response);
            default -> InquiryResponseEvaluation.adequate("继续");
        };
    }

    private InquiryResponseEvaluation evaluateQuestionQuality(String response) {
        PromptPayload prompt = PromptPayload.builder()
            .templateId("BIO_INQUIRY_EVAL_QUESTION")
            .variable("student_question", response)
            .build();

        AIEvaluationResult result = aiService.evaluate(prompt);
        return InquiryResponseEvaluation.builder()
            .adequate(result.getScore() >= 0.5)
            .score(result.getScore())
            .feedback(result.getFeedback())
            .additionalHints(result.getSuggestions())
            .build();
    }

/**
 * 生物知识图谱服务

@Service
public class BioKnowledgeService {

    @Autowired private BioKnowledgePointRepository pointRepo;
    @Autowired private BioKnowledgeRelationRepository relationRepo;
    @Autowired private CacheManager cacheManager;

    /**
     * 获取完整知识领域树
     */
    @Cacheable(value = "bio:domain:tree", key = "#level")
    public DomainTree getDomainTree(String level) {
        List<BioKnowledgePoint> points = pointRepo.findByCurriculumLevel(level);
        Map<String, List<BioKnowledgePoint>> byDomain = points.stream()
            .collect(Collectors.groupingBy(BioKnowledgePoint::getDomainId));

        List<DomainNode> domains = byDomain.entrySet().stream()
            .map(e -> DomainNode.builder()
                .domainId(e.getKey())
                .domainName(getDomainName(e.getKey()))
                .knowledgePoints(e.getValue().stream()
                    .map(this::toPointNode)
                    .sorted(Comparator.comparing(KnowledgePointNode::getDifficulty))
                    .collect(Collectors.toList()))
                .build())
            .sorted(Comparator.comparing(DomainNode::getDomainId))
            .collect(Collectors.toList());

        return DomainTree.builder().domains(domains).build();
    }

    /**
     * 递归获取前置依赖链
     */
    @Cacheable(value = "bio:point:prereq", key = "#pointId")
    public PrerequisiteChain getPrerequisiteChain(
        String pointId,
        int maxDepth
    ) {
        List<KnowledgePathNode> chain = new ArrayList<>();
        Set<String> visited = new HashSet<>();
        buildPrereqChain(pointId, chain, visited, 0, maxDepth);
        return PrerequisiteChain.builder()
            .targetPointId(pointId)
            .chain(chain)
            .build();
    }

    private void buildPrereqChain(
        String pointId,
        List<KnowledgePathNode> chain,
        Set<String> visited,
        int depth,
        int maxDepth
    ) {
        if (depth >= maxDepth || visited.contains(pointId)) {
            return;
        }
        visited.add(pointId);

        List<BioKnowledgeRelation> prereqs = relationRepo
            .findBySourcePointIdAndRelationType(pointId, "PREREQUISITE");

        for (BioKnowledgeRelation rel : prereqs) {
            BioKnowledgePoint prereqPoint = pointRepo.findById(rel.getTargetPointId());
            chain.add(KnowledgePathNode.builder()
                .pointId(prereqPoint.getPointId())
                .name(prereqPoint.getName())
                .depth(depth + 1)
                .build());
            buildPrereqChain(
                prereqPoint.getPointId(),
                chain, visited,
                depth + 1, maxDepth
            );
        }
    }

    /**
     * 查找两个知识点之间的最短路径
     */
    public List<KnowledgePathNode> findShortestPath(
        String fromPointId,
        String toPointId
    ) {
        // BFS 搜索
        Queue<PathSearchState> queue = new LinkedList<>();
        queue.offer(PathSearchState.start(fromPointId));

        Set<String> visited = new HashSet<>();
        visited.add(fromPointId);

        while (!queue.isEmpty()) {
            PathSearchState current = queue.poll();

            if (current.getPointId().equals(toPointId)) {
                return current.getPath();
            }

            List<BioKnowledgeRelation> relations = relationRepo
                .findAllBySourcePointId(current.getPointId());

            for (BioKnowledgeRelation rel : relations) {
                if (!visited.contains(rel.getTargetPointId())) {
                    visited.add(rel.getTargetPointId());
                    queue.offer(current.extend(rel.getTargetPointId()));
                }
            }
        }

        return Collections.emptyList(); // 无路径
    }
}

### 7.1 异常分类与处理策略

| 异常类型 | 触发场景 | 处理策略 | 用户感知 |
| --- | --- | --- | --- |
| AI模型超时 | 大模型调用超过15秒 | 重试1次 → 切换备用模型 → 提示重试 | "正在思考中…请稍候" → 降级回答 |
| AI模型异常 | 模型返回错误/空响应 | 切换备用模型 → 缓存兜底 | "服务暂时不稳定，请重试" |
| 图表识别失败 | OCR/视觉模型无法识别 | 回退为纯文本模式 → 提示用户手动描述 | "图片不太清晰，你可以描述一下图中的内容吗？" |
| 遗传推理矛盾 | 推理过程中发现逻辑不一致 | 自动回溯 → 重新推断 → 标注回溯点 | "让我重新分析一下…" |
| 迷思检测超时 | 异步大模型分析超时 | 跳过迷思检测，正常返回回答 | 无感知 |
| 知识点缺失 | 请求的pointId不存在 | 返回404 | "该知识点暂未收录" |
| 画像锁定 | 并发更新冲突 | 重试3次（指数退避） → 放弃本次更新 | 无感知 |
| RAG检索为空 | 检索无结果 | 使用纯Prompt回答 → 记录缺失数据 | 回答可能缺少教材引用，无异常提示 |
| 会话超时 | SSE连接超过5分钟 | 优雅关闭，保存已生成内容 | "会话已超时，已为你保存已有内容" |
| 探究阶段无效 | 状态机非法迁移 | 回退到上一有效状态 | 无感知 |
