# 客户端-推送通知通道集成与本地提醒调度引擎-详细设计

## 1. 概述

### 1.1 文档目的

本文档详细设计 PrimeTop 客户端的推送通知接收与本地提醒调度引擎，覆盖 iOS APNs、Android FCM 以及国内主流厂商推送通道（华为 HMS Push、小米 Push、vivo Push、oppo Push、荣耀 Push）的客户端 SDK 集成、推送 Token 全生命周期管理、本地通知调度（学习提醒、复习提醒、计划提醒等）、通知权限管理、通知点击路由跳转及送达回执上报。

### 1.2 设计背景

PrimeTop 作为教育学习类 APP，推送通知是用户留存和学习闭环的关键环节：

- **学习提醒**：每日学习任务提醒、打卡提醒、番茄钟休息提醒
- **复习提醒**：基于间隔重复算法的错题复习提醒、知识点复习提醒
- **计划提醒**：学习计划任务到期提醒、计划偏离预警
- **社交提醒**：学习挑战赛邀请、排行榜变动、好友互动
- **运营提醒**：活动开始、优惠券到期、会员续费预警
- **教师/家长提醒**：作业发布提醒、孩子学习报告推送

国内 Android 生态碎片化严重，各厂商推送通道机制差异大；iOS 与 Android 通知权限模型也不同。需要一个统一的抽象层来管理这些差异。

### 1.3 设计目标

| 目标 | 说明 |
| --- | --- |
| 统一抽象 | 一套 API 屏蔽 iOS/Android 及各厂商推送差异 |
| 高送达率 | 国内 Android 优先使用厂商通道，确保应用被杀后仍可送达 |
| 精准调度 | 本地提醒支持基于日历、间隔重复、自定义规则调度 |
| 低耗电 | 合理设置推送心跳间隔，避免频繁唤醒 |
| 可观测 | Token 变更、推送送达、点击转化全链路追踪 |
| 隐私合规 | 通知内容脱敏处理，遵守未成年人保护要求 |

## 3. 推送通道适配层设计

### 3.1 通道选择策略

Android 设备需要根据厂商自动选择主推送通道：

```dart
/// 推送通道类型
enum PushChannelType {
  apns,        // iOS APNs
  fcm,         // Google FCM (海外/无厂商通道时回退)
  hms,         // 华为 HMS Push
  xiaomi,      // 小米 MiPush
  vivo,        // vivo Push
  oppo,        // OPPO Push (含 realme)
  honor,       // 荣耀 Push
  meizu,       // 魅族 Push (可选)
}

/// 通道选择器
class PushChannelDetector {
  static PushChannelType? _cachedChannel;

  /// 检测当前设备应使用的推送通道
  static PushChannelType detectChannel() {
    if (_cachedChannel != null) return _cachedChannel!;
    
    if (Platform.isIOS) {
      _cachedChannel = PushChannelType.apns;
      return _cachedChannel!;
    }
    
    final manufacturer = DeviceInfo.manufacturer.toLowerCase();
    final channel = _matchManufacturer(manufacturer);
    _cachedChannel = channel;
    return channel;
  }

  static PushChannelType _matchManufacturer(String manufacturer) {
    switch (manufacturer) {
      case 'huawei':
        return PushChannelType.hms;
      case 'xiaomi':
      case 'redmi':
        return PushChannelType.xiaomi;
      case 'vivo':
      case 'iqoo':
        return PushChannelType.vivo;
      case 'oppo':
      case 'realme':
      case 'oneplus':
        return PushChannelType.oppo;
      case 'honor':
        return PushChannelType.honor;
      case 'meizu':
        return PushChannelType.meizu;
      default:
        // 非主流厂商设备，回退到 FCM
        return PushChannelType.fcm;
    }
  }
}
```

### 3.4 Flutter Platform Channel 桥接层

```dart
/// 推送 Platform Channel 桥接
class PushPlatformBridge {
  static const MethodChannel _channel = MethodChannel('primetop/push');
  static const EventChannel _eventChannel = 
      EventChannel('primetop/push/events');
  
  static final StreamController<Map<String, dynamic>> _eventController =
      StreamController.broadcast();
  
  static late StreamSubscription _nativeEventSub;

  /// 初始化桥接
  static void init() {
    _eventChannel.receiveBroadcastStream().listen(
      (event) {
        final data = Map<String, dynamic>.from(event as Map);
        _eventController.add(data);
      },
      onError: (error) {
        _eventController.addError(error);
      },
    );
  }

  /// 原生事件流
  static Stream<Map<String, dynamic>> get events => _eventController.stream;

  /// 调用原生方法
  static Future<T?> invokeMethod<T>(String method, [Map<String, dynamic>? args]) {
    return _channel.invokeMethod<T>(method, args);
  }

  /// 释放
  static void dispose() {
    _nativeEventSub.cancel();
    _eventController.close();
  }
}
```

## 4. Token 管理器

### 4.1 Token 生命周期状态机

```
                    ┌─────────┐
                    │  UNINIT │ ← 初始状态
                    └────┬────┘
                         │ initialize()
                         ▼
                    ┌─────────┐
        ┌───────────│PENDING  │←─── registerToken() 调用后等待回调
        │           └────┬────┘
        │                │ onTokenReceived
        │                ▼
        │           ┌─────────┐
        │   ┌──────│ ACTIVE   │←─── Token 有效，已上报服务端
        │   │       └────┬────┘
        │   │            │ onTokenRefresh / tokenExpired
        │   │            ▼
        │   │       ┌─────────┐
        │   │       │ REFRESH │─────┐ 重新获取 Token 成功
        │   │       └────┬────┘     │ → ACTIVE
        │   │            │          │
        │   │            │ refresh  │ refresh failed
        │   │            │ failed   │
        │   │            ▼          ▼
        │   │       ┌─────────┐  ┌─────────┐
        │   └──────│  EXPIRED │  │ INVALID │
        │           └─────────┘  └─────────┘
        │                │           │
        └────────────────┴───────────┘
              unregisterToken() → UNINIT
```

```dart
/// 推送 Token 信息
class PushTokenInfo {
  final String token;
  final PushChannelType channel;
  final String deviceId;
  final DateTime registeredAt;
  final DateTime? reportedAt;
  final TokenStatus status;

  const PushTokenInfo({
    required this.token,
    required this.channel,
    required this.deviceId,
    required this.registeredAt,
    this.reportedAt,
    this.status = TokenStatus.active,
  });

  Map<String, dynamic> toJson() => {
    'token': token,
    'channel': channel.name.toUpperCase(),
    'deviceId': deviceId,
    'registeredAt': registeredAt.toIso8601String(),
    'reportedAt': reportedAt?.toIso8601String(),
    'status': status.name,
  };

  factory PushTokenInfo.fromJson(Map<String, dynamic> json) => PushTokenInfo(
    token: json['token'] as String,
    channel: PushChannelType.values.firstWhere(
      (e) => e.name.toUpperCase() == json['channel'],
    ),
    deviceId: json['deviceId'] as String,
    registeredAt: DateTime.parse(json['registeredAt'] as String),
    reportedAt: json['reportedAt'] != null 
        ? DateTime.parse(json['reportedAt'] as String) 
        : null,
    status: TokenStatus.values.firstWhere(
      (e) => e.name == json['status'],
      orElse: () => TokenStatus.active,
    ),
  );
}
```

### 4.3 Token 管理器实现

```dart
class PushTokenManager {
  static final PushTokenManager _instance = PushTokenManager._();
  factory PushTokenManager() => _instance;
  PushTokenManager._();

  final PushTokenStorage _storage = PushTokenStorage();
  final PushApiClient _apiClient = PushApiClient();
  
  PushTokenInfo? _currentToken;
  PushChannelAdapter? _adapter;
  
  // Token 变更通知
  final StreamController<PushTokenInfo> _tokenChangedController = 
      StreamController.broadcast();
  Stream<PushTokenInfo> get onTokenChanged => _tokenChangedController.stream;

  /// 初始化 Token 管理
  Future<void> initialize({
    required PushChannelAdapter adapter,
    required String deviceId,
    required String userId,
  }) async {
    _adapter = adapter;
    
    // 1. 加载本地缓存的 Token
    _currentToken = await _storage.loadToken(deviceId: deviceId);
    
    // 2. 注册原生事件监听
    PushPlatformBridge.events
        .where((e) => e['event'] == 'onPushTokenChanged')
        .listen((event) => _handleTokenRefresh(event, deviceId, userId));
    
    PushPlatformBridge.events
        .where((e) => e['event'] == 'onPushTokenError')
        .listen((event) => _handleTokenError(event));
    
    // 3. 触发 Token 注册
    await _registerIfNeeded(deviceId: deviceId, userId: userId);
  }

  /// 注册或复用 Token
  Future<void> _registerIfNeeded({
    required String deviceId,
    required String userId,
  }) async {
    final adapter = _adapter!;
    
    // 检查本地是否已有有效 Token
    if (_currentToken != null && _currentToken!.status == TokenStatus.active) {
      // Token 仍有效，确认服务端是否已记录
      if (_currentToken!.reportedAt == null) {
        await _reportTokenToServer(_currentToken!, userId);
      }
      return;
    }
    
    // 注册获取新 Token
    final token = await adapter.registerToken();
    if (token == null || token.isEmpty) {
      Log.w('Push token registration returned null');
      return;
    }
    
    final newTokenInfo = PushTokenInfo(
      token: token,
      channel: adapter.channelType,
      deviceId: deviceId,
      registeredAt: DateTime.now(),
      status: TokenStatus.active,
    );
    
    // 与旧 Token 对比
    if (_currentToken != null && _currentToken!.token != token) {
      // Token 发生变化，旧 Token 加入历史
      Log.i('Push token changed: ${_currentToken!.token.substring(0, 8)}... → ${token.substring(0, 8)}...');
      await _storage.archiveOldToken(_currentToken!, deviceId: deviceId);
      
      // 通知服务端旧 Token 失效
      await _apiClient.invalidateToken(
        token: _currentToken!.token,
        channel: _currentToken!.channel,
        userId: userId,
      ).catchError((e) => Log.e('Failed to invalidate old token: $e'));
    }
    
    _currentToken = newTokenInfo;
    await _storage.saveToken(newTokenInfo, deviceId: deviceId);
    
    // 上报新 Token 到服务端
    await _reportTokenToServer(newTokenInfo, userId);
    
    _tokenChangedController.add(newTokenInfo);
  }

  /// Token 刷新回调
  Future<void> _handleTokenRefresh(
    Map<String, dynamic> event,
    String deviceId,
    String userId,
  ) async {
    final token = event['token'] as String?;
    if (token == null || token.isEmpty) return;
    
    Log.i('Push token refreshed by system');
    await _registerIfNeeded(deviceId: deviceId, userId: userId);
  }

  /// 上报 Token 到服务端
  Future<void> _reportTokenToServer(
    PushTokenInfo tokenInfo,
    String userId,
  ) async {
    try {
      await _apiClient.registerPushToken(
        userId: userId,
        token: tokenInfo.token,
        channel: tokenInfo.channel.name.toUpperCase(),
        deviceId: tokenInfo.deviceId,
        appVersion: DeviceInfo.appVersion,
        osVersion: DeviceInfo.osVersion,
      );
      
      // 更新上报时间
      final updated = PushTokenInfo(
        token: tokenInfo.token,
        channel: tokenInfo.channel,
        deviceId: tokenInfo.deviceId,
        registeredAt: tokenInfo.registeredAt,
        reportedAt: DateTime.now(),
        status: TokenStatus.active,
      );
      _currentToken = updated;
      await _storage.saveToken(updated, deviceId: tokenInfo.deviceId);
    } catch (e) {
      Log.e('Failed to report push token: $e');
      // 上报失败，设置重试定时器
      _scheduleTokenReportRetry(tokenInfo, userId);
    }
  }

  /// 上报失败重试（指数退避）
  Timer? _reportRetryTimer;
  int _reportRetryCount = 0;
  
  void _scheduleTokenReportRetry(PushTokenInfo tokenInfo, String userId) {
    _reportRetryTimer?.cancel();
    final delay = Duration(seconds: math.min(30 * math.pow(2, _reportRetryCount).toInt(), 3600));
    _reportRetryCount++;
    
    _reportRetryTimer = Timer(delay, () {
      _reportTokenToServer(tokenInfo, userId);
    });
  }

  /// 用户退出登录时调用
  Future<void> onUserLogout({
    required String userId,
    required String deviceId,
  }) async {
    final token = _currentToken;
    if (token == null) return;
    
    // 通知服务端解绑
    await _apiClient.unbindPushToken(
      token: token.token,
      channel: token.channel,
      userId: userId,
    ).catchError((e) => Log.e('Failed to unbind push token: $e'));
    
    _reportRetryTimer?.cancel();
    _currentToken = null;
  }

  /// 获取当前 Token
  PushTokenInfo? get currentToken => _currentToken;
}
```

```dart
class QuietHours {
  final TimeOfDay start;
  final TimeOfDay end;
  final bool muteVibration;
  
  const QuietHours({
    required this.start,
    required this.end,
    this.muteVibration = true,
  });
  
  /// 判断指定时间是否在免打扰时段内
  bool isQuiet(DateTime dateTime) {
    final nowMinutes = dateTime.hour * 60 + dateTime.minute;
    final startMinutes = start.hour * 60 + start.minute;
    final endMinutes = end.hour * 60 + end.minute;
    
    if (startMinutes <= endMinutes) {
      // 同一天：如 12:00-14:00
      return nowMinutes >= startMinutes && nowMinutes < endMinutes;
    } else {
      // 跨天：如 22:00-07:00
      return nowMinutes >= startMinutes || nowMinutes < endMinutes;
    }
  }
  
  Map<String, dynamic> toJson() => {
    'startHour': start.hour, 'startMinute': start.minute,
    'endHour': end.hour, 'endMinute': end.minute,
    'muteVibration': muteVibration,
  };
}
```

```dart
class LocalNotificationScheduler {
  static final LocalNotificationScheduler _instance = LocalNotificationScheduler._();
  factory LocalNotificationScheduler() => _instance;
  LocalNotificationScheduler._();

  final LocalScheduleStorage _storage = LocalScheduleStorage();
  final FlutterLocalNotificationsPlugin _plugin = FlutterLocalNotifications();
  
  // EventBus 监听事件驱动调度
  final EventBus _eventBus = EventBus();
  StreamSubscription? _eventSub;

  /// 初始化
  Future<void> initialize() async {
    // 1. 初始化 flutter_local_notifications
    const initSettings = InitializationSettings(
      android: AndroidInitializationSettings('@mipmap/ic_notification'),
      iOS: DarwinInitializationSettings(
        requestAlertPermission: false,  // 手动请求权限
        requestBadgePermission: false,
        requestSoundPermission: false,
      ),
    );
    await _plugin.initialize(
      initSettings,
      onDidReceiveNotificationResponse: _onNotificationTapped,
      onDidReceiveBackgroundNotificationResponse: _onBackgroundNotificationTapped,
    );
    
    // 2. 恢复所有已调度的通知
    await _restoreSchedules();
    
    // 3. 监听事件驱动调度
    _eventSub = _eventBus.on<ScheduleTriggerEvent>().listen(_handleTriggerEvent);
  }

  /// 创建调度任务
  Future<String> schedule(LocalNotificationSchedule schedule) async {
    // 1. 检查免打扰，计算实际触发时间
    final actualFireTime = _calculateActualFireTime(schedule);
    
    if (actualFireTime == null) {
      Log.w('Schedule ${schedule.id} fire time is always in quiet hours, skipped');
      return '';
    }
    
    // 2. 计算下次触发时间
    final nextFireAt = _calculateNextFireTime(schedule);
    
    // 3. 持久化调度记录
    final updated = LocalNotificationSchedule(
      id: schedule.id,
      title: schedule.title,
      body: schedule.body,
      channelId: schedule.channelId,
      scheduleType: schedule.scheduleType,
      config: schedule.config,
      deepLink: schedule.deepLink,
      payload: schedule.payload,
      enabled: schedule.enabled,
      quietHours: schedule.quietHours,
      createdAt: schedule.createdAt,
      updatedAt: DateTime.now(),
      lastFiredAt: schedule.lastFiredAt,
      nextFireAt: nextFireAt,
    );
    await _storage.save(updated);
    
    // 4. 调用原生通知调度
    await _scheduleNativeNotification(updated, actualFireTime);
    
    return schedule.id;
  }

  /// 取消调度
  Future<void> cancel(String scheduleId) async {
    await _plugin.cancel(scheduleId.hashCode);
    await _storage.delete(scheduleId);
    Log.i('Cancelled schedule: $scheduleId');
  }

  /// 取消某业务模块的所有调度
  Future<void> cancelByPrefix(String prefix) async {
    final schedules = await _storage.getAll();
    final matching = schedules.where((s) => s.id.startsWith(prefix));
    await Future.wait(matching.map((s) => cancel(s.id)));
  }

  /// 更新间隔重复调度（复习完成后调用）
  Future<void> updateSpacedRepetition({
    required String mistakeId,
    required int qualityGrade, // 0-5 评分（SM-2 算法）
  }) async {
    final schedules = await _storage.getByMistakeId(mistakeId);
    if (schedules.isEmpty) return;
    
    final schedule = schedules.first;
    final config = schedule.config as SpacedRepetitionConfig;
    
    // SM-2 算法更新间隔
    final newRepetition = qualityGrade >= 3 ? config.repetition + 1 : 0;
    final newEase = _updateEaseFactor(config.easeFactor, qualityGrade);
    final newInterval = _calculateNewInterval(
      newRepetition,
      newEase,
      config.currentIntervalHours,
    );
    
    // 如果间隔过长，改为远期调度
    final nextFireAt = DateTime.now().add(Duration(hours: newInterval));
    
    // 取消旧的，创建新的
    await cancel(schedule.id);
    
    if (newInterval < 24 * 30) { // 30天内
      // 本地调度
      await this.schedule(LocalNotificationSchedule(
        id: 'review_${mistakeId}_${DateTime.now().millisecondsSinceEpoch}',
        title: '复习提醒',
        body: '你有 ${mistakeId} 相关的错题需要复习',
        channelId: 'review_reminder',
        scheduleType: ScheduleType.spacedRepetition,
        config: SpacedRepetitionConfig(
          mistakeId: mistakeId,
          currentIntervalHours: newInterval,
          easeFactor: newEase,
          repetition: newRepetition,
        ),
        deepLink: 'primetop://mistakeBook/review?mistakeId=$mistakeId',
        payload: {'mistakeId': mistakeId},
        createdAt: DateTime.now(),
        nextFireAt: nextFireAt,
      ));
    }
    // 超过30天的不在本地调度，由服务端远期推送
    
    Log.i('Updated spaced repetition for $mistakeId: interval=${newInterval}h, ease=$newEase, rep=$newRepetition');
  }

  // SM-2 算法：更新难度系数
  double _updateEaseFactor(double ef, int q) {
    final newEf = ef + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02));
    return math.max(1.3, newEf);
  }

  // SM-2 算法：计算新间隔（小时）
  int _calculateNewInterval(int repetition, double ef, int oldIntervalHours) {
    if (repetition <= 1) return 24;       // 第一次：1天
    if (repetition == 2) return 72;       // 第二次：3天
    return (oldIntervalHours * ef).round(); // 后续：间隔 × 难度系数
  }

  /// 计算实际触发时间（处理免打扰）
  DateTime? _calculateActualFireTime(LocalNotificationSchedule schedule) {
    final nextFire = _calculateNextFireTime(schedule);
    if (nextFire == null) return null;
    
    final quiet = schedule.quietHours ?? _getChannelQuietHours(schedule.channelId);
    if (quiet == null) return nextFire;
    
    // 如果在免打扰时段，推迟到免打扰结束
    if (quiet.isQuiet(nextFire)) {
      return _postponeAfterQuiet(nextFire, quiet);
    }
    
    return nextFire;
  }

  DateTime _postponeAfterQuiet(DateTime fireTime, QuietHours quiet) {
    final endMinutes = quiet.end.hour * 60 + quiet.end.minute;
    final postponed = DateTime(
      fireTime.year,
      fireTime.month,
      fireTime.day,
      quiet.end.hour,
      quiet.end.minute,
    );
    // 如果 end < start（跨天），postponed 是当天 end 时间
    // 如果 end 已过，加一天
    if (postponed.isBefore(fireTime)) {
      return postponed.add(Duration(days: 1));
    }
    return postponed;
  }

  /// 计算下次触发时间
  DateTime? _calculateNextFireTime(LocalNotificationSchedule schedule) {
    final now = DateTime.now();
    
    switch (schedule.scheduleType) {
      case ScheduleType.oneTime:
        final config = schedule.config as OneTimeConfig;
        return config.fireAt.isAfter(now) ? config.fireAt : null;
        
      case ScheduleType.dailyRepeating:
        final config = schedule.config as DailyRepeatingConfig;
        var next = DateTime(now.year, now.month, now.day, 
            config.time.hour, config.time.minute);
        if (next.isBefore(now) || next.isAtSameMomentAs(now)) {
          next = next.add(Duration(days: 1));
        }
        return next;
        
      case ScheduleType.weeklyRepeating:
        final config = schedule.config as WeeklyRepeatingConfig;
        for (int i = 0; i <= 7; i++) {
          final candidate = DateTime(now.year, now.month, now.day,
              config.time.hour, config.time.minute).add(Duration(days: i));
          if (config.weekdays.contains(candidate.weekday) && 
              candidate.isAfter(now)) {
            return candidate;
          }
        }
        return null;
        
      case ScheduleType.spacedRepetition:
        final config = schedule.config as SpacedRepetitionConfig;
        return now.add(Duration(hours: config.currentIntervalHours));
        
      case ScheduleType.cronBased:
        // 使用 cron 表达式解析库计算
        // 省略实现
        return null;
        
      case ScheduleType.eventTriggered:
        // 事件驱动型不预先计算触发时间
        return null;
    }
  }
```

```dart
/// 远程推送消息处理器
class RemotePushHandler {
  static final RemotePushHandler _instance = RemotePushHandler._();
  factory RemotePushHandler() => _instance;
  RemotePushHandler._();

  final StreamController<RemotePushMessage> _onMessageController = 
      StreamController.broadcast();
  Stream<RemotePushMessage> get onMessage => _onMessageController.stream;

  /// 初始化
  void initialize() {
    // 监听原生推送事件
    PushPlatformBridge.events.listen((event) {
      final eventType = event['event'] as String;
      switch (eventType) {
        case 'onPushMessageReceived':
          _handleMessageReceived(event);
          break;
        case 'onNotificationArrived':
          _handleNotificationArrived(event);
          break;
        case 'onNotificationClicked':
          _handleNotificationClicked(event);
          break;
      }
    });
  }

  /// 收到透传消息（应用在前台或后台运行时）
  void _handleMessageReceived(Map<String, dynamic> event) {
    final data = Map<String, dynamic>.from(event['data'] ?? {});
    final message = RemotePushMessage.fromPayload(data);
    
    // 上报送达回执
    NotificationAnalytics.trackNotificationReceived(
      messageId: message.msgId,
      channelId: message.channel,
      source: 'remote_passthrough',
    );
    
    if (message.isSilent) {
      // 静默消息：不展示通知，触发后台同步
      _handleSilentPush(message);
    } else {
      // 透传消息：应用可自行决定是否展示前台通知
      if (AppLifecycleManager.instance.isInForeground) {
        _showForegroundNotification(message);
      }
    }
    
    _onMessageController.add(message);
  }

  /// 系统通知栏展示（厂商通道推送的通知）
  void _handleNotificationArrived(Map<String, dynamic> event) {
    final messageId = event['messageId'] as String?;
    if (messageId == null) return;
    
    // 上报到达
    NotificationAnalytics.trackNotificationReceived(
      messageId: messageId,
      channelId: event['channel'] ?? 'unknown',
      source: 'remote_system_tray',
    );
  }

  /// 用户点击系统通知栏通知
  void _handleNotificationClicked(Map<String, dynamic> event) {
    final data = Map<String, dynamic>.from(event['data'] ?? {});
    final messageId = event['messageId'] as String?;
    final message = RemotePushMessage.fromPayload(data);
    
    // 上报点击
    NotificationAnalytics.trackNotificationOpened(
      scheduleId: messageId ?? '',
      channelId: message.channel,
      source: 'remote',
    );
    
    // 处理深链接跳转
    if (message.deepLink != null) {
      // 延迟跳转，等 App 完全恢复前台
      AppLifecycleManager.instance.waitForForeground().then((_) {
        DeepLinkRouter.navigate(message.deepLink!);
      });
    }
    
    // 清除 Badge
    BadgeManager.clearBadge();
  }

  /// 处理静默推送
  void _handleSilentPush(RemotePushMessage message) {
    final action = message.payload['silent_action'] as String?;
    switch (action) {
      case 'sync_mistake_book':
        // 触发错题本同步
        MistakeBookSyncService.instance.triggerSync();
        break;
      case 'sync_study_plan':
        // 触发学习计划同步
        StudyPlanSyncService.instance.triggerSync();
        break;
      case 'refresh_content':
        // 刷新内容缓存
        ContentCacheManager.instance.refresh();
        break;
      case 'invalidate_token':
        // Token 已失效，重新注册
        PushTokenManager().refreshToken();
        break;
      default:
        Log.d('Unknown silent push action: $action');
    }
  }

  /// 前台收到推送时展示本地通知
  void _showForegroundNotification(RemotePushMessage message) {
    // 未成年人内容脱敏
    final title = ContentSanitizer.sanitizeNotificationTitle(
      message.title, 
      isMinor: UserManager.instance.isMinor,
    );
    final body = ContentSanitizer.sanitizeNotificationBody(
      message.body,
      isMinor: UserManager.instance.isMinor,
    );
    
    LocalNotificationShower.show(
      title: title,
      body: body,
      channelId: message.channel,
      payload: message.toPayloadMap(),
      deepLink: message.deepLink,
    );
  }
}

class RemotePushMessage {

  final String msgType;
  final String channel;
  final String title;
  final String body;
  final String? deepLink;
  final Map<String, dynamic> payload;
  final bool isSilent;

    required this.msgId,
    required this.msgType,
    required this.channel,
    required this.title,
    required this.body,

    required this.receivedAt,
```

```dart
  /// 请求通知权限
  /// 带优雅降级的 Rationale 对话框
  Future<PermissionRequestResult> requestWithRationale({
    required String userScenario, // "study_reminder_setup" | "app_launch" | etc.
  }) async {
    // 1. 检查是否已授权
    final status = await checkStatus();
    if (status == NotificationPermissionStatus.granted) {
      return PermissionRequestResult.alreadyGranted;
    }
    
    // 2. 检查是否之前被拒绝且不可再请求
    if (status == NotificationPermissionStatus.permanentlyDenied) {
      // 引导用户去系统设置
      await _showOpenSettingsDialog();
      return PermissionRequestResult.openSettings;
    }
    
    // 3. 首次请求：展示 Rationale 对话框 → 系统权限弹窗
    final shouldShowRationale = await _shouldShowRationale(userScenario);
    if (shouldShowRationale) {
      final userAgreed = await _showRationaleDialog(userScenario);
      if (!userAgreed) {
        return PermissionRequestResult.userDeclinedRationale;
      }
    }
    
    // 4. 触发系统权限请求
    final adapter = PushChannelAdapterManager.currentAdapter;
    final granted = await adapter.requestPermission();
    
    if (granted) {
      Analytics.track('notification_permission_granted', {
        'scenario': userScenario,
      });
      return PermissionRequestResult.granted;
    } else {
      Analytics.track('notification_permission_denied', {
        'scenario': userScenario,
      });
      return PermissionRequestResult.denied;
    }
  }

  Future<bool> _shouldShowRationale(String scenario) async {
```

```dart
    if (!isMinor) return title;

    return title

        .replaceAll(RegExp(r'弱项|差|不及格'), '需要加强');
```

```dart
class AntiAddictionPushFilter {

  Future<PushFilterResult> shouldDeliver({

  }) async {
```

### 10.2 分析上报实现

```dart
class NotificationAnalytics {
  static final NotificationAnalytics _instance = NotificationAnalytics._();
  factory NotificationAnalytics() => _instance;
  NotificationAnalytics._();

  /// 送达回执上报
  Future<void> trackNotificationReceived({
    required String messageId,
    required String channelId,
    required String source,
  }) async {
    // 本地埋点
    Analytics.track('notification_received_remote', {
      'messageId': messageId,
      'channelId': channelId,
      'source': source,
      'receivedAt': DateTime.now().toIso8601String(),
    });
    
    // 服务端送达回执（用于送达率统计）
    unawaited(_sendDeliveryReceipt(
      messageId: messageId,
      status: 'delivered',
    ));
  }

  /// 点击上报
  Future<void> trackNotificationOpened({
    required String scheduleId,
    required String channelId,
    required String source,
  }) async {
    Analytics.track('notification_opened', {
      'scheduleId': scheduleId,
      'channelId': channelId,
      'source': source,
      'openedAt': DateTime.now().toIso8601String(),
    });
    
    unawaited(_sendDeliveryReceipt(
      messageId: scheduleId,
      status: 'opened',
    ));
  }

  /// 送达回执
  Future<void> _sendDeliveryReceipt({
    required String messageId,
    required String status,
  }) async {
    try {
      await ApiClient.post('/api/v1/push/receipt', data: {
        'messageId': messageId,
        'status': status,
        'timestamp': DateTime.now().toIso8601String(),
        'deviceInfo': {
          'appVersion': DeviceInfo.appVersion,
          'osVersion': DeviceInfo.osVersion,
          'network': await NetworkInfo.type,
        },
      }, timeout: Duration(seconds: 5));
    } catch (e) {
      // 回执失败不影响用户体验，静默丢弃
      Log.d('Push receipt failed: $e');
    }
  }
}
```

## 13. 特殊场景处理

### 13.1 多设备登录

当用户在新设备登录时：

1. 服务端收到新设备 Token 注册，将旧设备 Token 标记为 `SECONDARY`
2. 新设备成为主推送目标
3. 旧设备的 Token 不会立即失效，但优先级降低
4. 用户可在设置页查看已绑定设备列表，手动解绑

### 13.2 用户切换

同一设备上有多个用户（如家庭共享设备）：

```dart
class PushUserSwitchHandler {
  /// 切换用户时调用
  Future<void> onUserSwitched({
    required String fromUserId,
    required String toUserId,
  }) async {
    // 1. 取消旧用户的所有本地通知
    await LocalNotificationScheduler().cancelByPrefix('user_${fromUserId}_');
    
    // 2. 更新 Token 绑定关系
    await PushTokenManager().rebindUser(
      fromUserId: fromUserId,
      toUserId: toUserId,
    );
    
    // 3. 重新拉取新用户的通知偏好
    await NotificationPreferenceManager().syncFromServer(toUserId);
    
    // 4. 初始化新用户的本地提醒
    await UserReminderInitializer.initialize(toUserId);
    
    // 5. 清除通知栏中旧用户相关通知
    await _clearNotificationsForUser(fromUserId);
  }
}
```
