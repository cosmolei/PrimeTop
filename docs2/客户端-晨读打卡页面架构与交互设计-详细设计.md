## 1. 概述

### 1.1 模块定位

本文为 **晨读打卡域（MRD）客户端呈现层权威**，承接服务端《服务端-晨读打卡与朗读习惯养成引擎》v1.0 契约 R10 声明的"客户端晨读页面（录音交互/进度可视化/窗口外自由朗读入口）列为后续批次"缺口，覆盖：

| 能力 | 说明 |
|------|------|
| 今日晨读工作台 | 窗口状态、计划条目列表、streak 镜像、晨读寄语、降级诚实透出 |
| 朗读录音交互 | 大字文本展示、录制控制、学段时长硬顶、直传 OSS、秒传、评估轮询 |
| 条目结果展示 | 分数（分龄露分口径）、错字高亮、可重录引导、降级不计分文案 |
| 会话总结 | 达标庆祝（无排名）、统计摘要、streak 镜像刷新 |
| 窗口外自由朗读 | 记时长不打卡的独立模式，全程诚实文案 |
| 家长端报告 | 达标日历、趋势、窗口配置入口（仅可收紧） |

### 1.2 缺口依据

对 docs2 全目录执行关键词扫描（`晨读 / morning`），仅服务端引擎文档与 README 批次记录命中，无任何客户端页面文档；服务端引擎 §13 R10 与 README 2026-11-22 批次（三十八）均显式登记"客户端晨读页面零覆盖，列为后续批次"。本文补齐该缺口。

### 1.3 设计原则

1. **音频零留存（客户端侧同等生效）**：录音临时文件仅存于"录制开始 → 上传终态"之间，完成/放弃/异常三路全部立即物理删除；禁相册保存、禁分享、禁任何形式缓存（合规 C1 对齐服务端 G5）。
2. **零判分**：客户端不实现、不预演任何评分逻辑；分数/达标/时长结论全部服务端权威渲染。
3. **降级诚实透出**：服务端 `degraded[]` 与 200 语义降级码（48207/48208/48214/48215/48219）必须转化为用户可见文案，禁静默吞（D8 对齐）。
4. **防沉迷 fail-closed**：48212 命中即终止录音流程，无任何"仅提示放行"路径。
5. **无社交排名**：全模块无班级榜/全服榜/好友对比，streak 仅本人与家长可见。

### 1.4 职责边界（客户端不做）

| 不做 | 权威归属 |
|------|----------|
| 评分/达标裁决/时长有效性判定 | 服务端引擎 + 评估系统 + 时长引擎 |
| 计划生成与条目选择 | 服务端引擎（纯规则，G4 零 LLM） |
| streak 计算与写 | 打卡系统（本文仅渲染镜像） |
| 录音文件持久化/缓存/上传副本管理 | 禁做（C1 红线） |
| 家长门校验实现 | 统一家长门引擎（本文仅跳转委托） |
| 激励/积分发放 | 用户学习激励中心（事件消费侧） |

## 2. 信息架构与页面地图

### 2.1 路由表

路由注册进《客户端路由与深链接系统》，统一前缀 `/morning-reading`：

| 路由 | 页面 | 入口 | 鉴权/守卫 |
|------|------|------|-----------|
| `/morning-reading` | 晨读首页（今日计划工作台） | 首页工作台"晨读"卡片、学习习惯入口 | 学生登录态 |
| `/morning-reading/record/:itemNo` | 朗读录音页 | 首页条目卡片"开始朗读" | 登录态 + G4 防沉迷预检 + G11 家长门预检 |
| `/morning-reading/record/:itemNo?free=1` | 自由朗读录音页（窗口外模式） | 首页"自由朗读"按钮（窗口外可见） | 登录态 + G4；无打卡视觉元素 |

| `/parent/morning-reading` | 家长端晨读报告 | 家长中心"晨读报告"Tab、周报内嵌 | **家长角色** + 统一家长门 |

### 2.3 页面状态规范

遵循《客户端页面状态模式与骨架屏加载空态错误态设计规范》：

- **晨读首页**：骨架屏（条目卡占位 3 条）→ 正常态/窗口外态；接口失败 → 错误态（重试按钮），**禁整页空白**（D5 红线，对齐服务端 D1"禁给用户空白计划"的客户端侧表达：错误态提供"重试"与"稍后再来"）。
- **录音页**：权限未授予 → 引导态（麦克风权限说明，家长可代操作）；录音中退后台 → 自动停止并保留待上传文件（见 §6.5 竞态裁决 R3）。
- **总结页**：end 接口未完成前禁渲染 eligible 结论，loading 用"正在为你结算…"中性文案。

### 3.1 Dart 数据模型（与服务端 §3 响应 1:1）

```dart

/// 会话状态（服务端 §5.1 镜像）

enum MrItemCategory { textbook, poem, english, review }

class MrWindowInfo {
  final String start;      // "04:30"
  final String end;        // "09:30"

  const MrWindowInfo({required this.start, required this.end, required this.inWindow});

  final int seq;
  final MrItemCategory category;
  final String title;
  final String contentText;   // 文本快照 SSOT，客户端禁回源上游
  final int estDurationMs;
  final MrItemStatus status;
  final double? bestScore;    // 仅 done 条目，可空
  const MrPlanItem({required this.itemNo, required this.seq, required this.category,
```

### 3.3 幂等键生成策略

| 操作 | 幂等键 | 生成与复用规则 |
|------|--------|----------------|
| 创建会话 | `clientRequestId`（uuid v7） | 首页进入时生成一次，当日复用；`created=false` 时静默替换本地会话号 |
| 申请上传 | uuid v7 | 每次录音完成生成新键；同一次录音的重试（网络失败重申请）**复用同键** |
| 提交评估 | uuid v7 | 与上传键配对生成；提交重试复用同键，禁换键防重复评估 |
| 结束会话 | uuid v7 | 每次点击"结束晨读"生成；429/5xx 重试复用同键 |
| 跳过条目 | uuid v7 | 每次跳过生成；服务端超限（G6）后客户端当日禁用该条目跳过按钮 |
| 自由朗读上报 | uuid v7 | 每次上报生成 |

幂等键仅存内存 Map + 应用生命周期内持久（`Hive box 'mr_idem'`，禁存音频/文本内容，仅键值对），应用卸载即清。

## 4. 页面详细设计

### 4.1 晨读首页（/morning-reading）

**布局（自上而下）**：

1. **窗口横幅**（高度 56dp，状态三色）：
   - 窗口中（inWindow=true）：绿色渐变"晨读时间到啦 04:30-09:30"，右侧今日已读时长（服务端 session.totalDurationMs 渲染）。
   - 未开始：中性蓝"晨读 04:30 开始"，按钮置灰不可点（禁本地时间判定开关，仅以服务端 inWindow 为准，R2）。
   - 窗口外：琥珀色"现在是自由朗读时间（不计晨读打卡）"，出现"自由朗读"主按钮（§4.6）。
2. **Streak 卡**：🔥 N 天连读（current）/ 最长 N 天（longest 小字）。`stale=true`（48214）时角标"同步中"，数字降透明度 60%。**禁任何形式的趋势预测与追赶提示**（C4）。
3. **寄语卡**：文本 + 右下"AI 生成"徽标（isAigc=true 时常驻展示，C6/AIGC 标识管理办法）。长度已由服务端按学段截断（§2.5），客户端禁二次裁剪。
4. **条目列表**：每卡片显示 seq、分类图标（TEXTBOOK 课本/POEM 诗/ENGLISH 英文/REVIEW 复习）、title、estDurationMs（"约 1 分钟"）、状态徽标：
   - PENDING → 主按钮"开始朗读"
   - IN_PROGRESS → "继续朗读"
   - DONE → 对勾 + bestScore 按分龄口径显示（§5）；"再读一遍"次级按钮（生成新 attempt，秒传键照常）
   - FAILED → "重新朗读"
   - SKIPPED → 灰色"已跳过"
5. **降级条**：`degraded[]` 非空时条目列表顶部黄色条，文案由 ErrorMessageFactory 映射（如 48215 →"部分内容暂时不可用，今天为你准备了备选朗读"）。**必须可点击展开明细**（G5 诚实透出）。
6. **底部主按钮**："结束晨读"（session 存在且 ACTIVE 时高亮；无 session 时隐藏，禁本地预演可点）。
7. **checkInEligible**：服务端 true 时条目区上方出现"今日晨读已完成 ✓"横幅；客户端**禁在 end 之前**渲染该横幅（G3）。

**交互**：
- 下拉刷新 → 重新 GET /today（带 ETag，304 时仅刷新计时器文案）。
- 每次从录音页返回 → 强制刷新（pull-to-refresh 语义，禁乐观改条目状态，服务端 §5.3 裁决重读）。
- 条目卡片横滑不出现删除/分享操作（音频与文本快照不可流转，C1）。

### 4.2 朗读录音页（/morning-reading/record/:itemNo）

**布局**：
1. 顶部：title + 分类徽标 + 关闭按钮（关闭弹"本次录音将删除"确认，确认后清理临时文件并返回）。
2. **文本区**（可滚动，字号分龄 §5）：contentText 原文快照全文展示（幼儿段若快照含拼音行则双行展示，拼音行来源为服务端 G14 准入内容，客户端禁本地注音）。录音进行中当前行高亮（按朗读进度估算滚动，仅视觉辅助，禁与评分联动）。
3. **波形区**（录制中实时振幅，录音停止即清空，禁截图外任何持久化）。
4. **控制区**（大按钮，幼儿 72dp）：
   - 未录制 → "开始朗读"（圆形主按钮）
   - 录制中 → 计时（mm:ss）+ "完成"按钮 + 红色暂停/继续
   - 完成 → 进入上传管线（按钮转进度环，文案"上传中…"）
5. **结果抽屉**（评估终态后自底部滑出，见 §4.3）。

**录制规则**：
- 时长硬顶按学段（§5：60/120/180/240s），到达硬顶自动停止并提示"这条读得有点长，先提交这一条吧"（中性话术，禁负面评价）。
- 最短 5s，低于 5s 禁提交（本地预校验，提示"再读一小段试试"）。
- 录音仅写应用私有临时目录（`getTemporaryDirectory()/mr_rec/`，随机文件名，禁扩展名外任何元数据文件）。
- 录制完成 → 立即计算 sha256 + 时长 → 走 §7.2 上传管线；**管线任何终态（成功/放弃/失败超限）均删除本地文件**（G1）。

**家长门与防沉迷拦截**：
- 进入页面时若服务端 create/校验返回 48212 → 全屏休息引导（复用防沉迷休息页组件），禁停留录音 UI。
- 48213（幼儿首录设备）→ 跳转统一家长门页，通过后返回本页自动续走（参数带 `?resume=1`，禁重复 create）。

**跳过**：录制页右上角"跳过"（二级按钮），点击弹原因选择（"今天不想读这条/内容不合适/其他"），确认后调 skip 接口；当日已跳 2 次后按钮置灰并提示"今天已经跳过 2 条啦"（G6 预禁用，服务端仍为最终裁决）。

### 4.3 条目结果区（录音页内底部抽屉 + 独立可复用组件）

| 服务端终态 | 客户端渲染 |
|------------|------------|
| SUCCEEDED（reused=false） | 分数按分龄露分口径（§5）+ 错字高亮（文本区 expected/actual 红标，最多展示前 10 处）+"再读一遍"按钮 |

### 4.4 会话总结页（/morning-reading/summary）

- 数据源：仅 end 接口响应（MrSessionSummary），**禁用本地累加渲染**（G3）。
- eligible=true：庆祝动效（彩带 ≤1.5s，低端机降级静态图，委托手势动画系统 confetti 组件）+ "今日晨读达标" + totalDurationMs/avgScore 统计 + streak 卡（重新拉 getStreak 刷新镜像，48214 时展示同步中角标）。
- eligible=false：中性文案"今天读了 X 条，继续加油"（**禁"未达标/失败"字样**，防挫败，对齐服务端合规 C2 正向话术）；展示距门槛差距（minDurationMs - totalDurationMs）仅在差距 ≤60s 时给出"再读一条即可"引导，否则不展示差距数字。
- checkInEventDispatched=false（防沉迷结束等场景）：不出现庆祝元素，仅统计展示。
- 底部按钮："返回首页"（回 /morning-reading 强制刷新）、"查看历史"（/history）。

### 4.5 历史记录页（/morning-reading/history）

- 列表项：日期、doneItems、totalDurationMs、avgScore（分龄口径）、eligible 徽标（✓ 达标）。

- **禁展示**：与他人的任何对比、百分位、排名（G12/C4）。
- 分页：cursor 分页，每页 20 条，滚动到底自动加载；空态插画 + "完成一次晨读就会出现记录"。

### 4.6 窗口外自由朗读（/morning-reading/record/:itemNo?free=1）

- 入口仅窗口外出现（由服务端 inWindow=false 驱动，R2）。
- 页面差异：无条目序号/无 streak 元素/无达标进度；文本区展示兜底池或自由文本（文本框输入 ≥10 字，本地校验，禁敏感内容本地过滤——内容安全归服务端）。

### 4.7 家长端晨读报告页（/parent/morning-reading）

- **多孩子切换**：顶部孩子选择器（家庭账户管理委托，当前孩子 SSOT 归家长中心）。

- **音频零留存说明条**：页底常驻"朗读音频完成评估后立即删除，平台不留存录音"（合规透明度）。

## 6. 状态机

### 6.1 录音管线状态机（客户端本地权威）

```
[IDLE] --点开始--> [COUNTDOWN 3-2-1] --(preschool 可跳)--> [RECORDING]
[RECORDING] --完成/硬顶--> [PROCESSING(转码m4a+sha256)] --> [UPLOADING]
[RECORDING] --退后台--> [STOPPED_BG] --回前台--> [RESUME_PROMPT] --> [RECORDING 新段|放弃]
[UPLOADING] --成功--> [SUBMITTING] --> [POLLING] --终态--> [RESULT]
[UPLOADING] --失败可重试--> [UPLOADING]（换 upload-url，幂等键复用）
[POLLING] --超时--> [RESULT_PENDING_PUSH]（推送召回，见 D7）
任意状态 --放弃/关闭/48212/异常超限--> [CLEANUP] --> [IDLE]
```

CLEANUP 为必经终态前状态：删除临时文件（assert 文件不存在）、释放录音资源、上报埋点（不含音频与文本内容）。

### 6.2 服务端镜像状态机（只读镜像，权威在服务端 §5.1）

客户端以 `MrTodayResponse` 为唯一镜像来源：

- 条目：PENDING/IN_PROGRESS/DONE/SKIPPED/FAILED——**禁本地写**，录音页返回后一律重拉 /today 对齐。
- 会话：ACTIVE/ENDED/EXPIRED——EXPIRED（窗口兜底）时首页会话卡显示"今天的晨读已结束"，"结束晨读"按钮隐藏。
- 尝试：EVALUATING/SUCCEEDED/FAILED/DEGRADED——轮询期间条目卡显示"评估中"骨架点。

### 6.3 轮询状态机

```
[POLL_START] --pollAfterMs--> [WAIT] --GET--> [EVALUATING?] --是--> [WAIT]（间隔×1.5，上限 5s）
                                                  └--终态--> [DELIVER]
[超过 40 次] --> [TIMEOUT] --> [RESULT_PENDING_PUSH]
```

推送召回（morning_reading 通知 topic）→ 重新 getAttempt → DELIVER；30min 未召回转 D7 兜底文案。

| 守卫 | 规则 | 违反后果（客户端自检） |

### 6.5 竞态裁决

| 竞态 | 裁决 |
|------|------|
| R1 放弃 vs 上传完成（用户点放弃瞬间上传成功） | 放弃确认弹窗期间上传完成 → 转结果抽屉展示（评估不浪费）；已 CLEANUP 后放弃 → 直接退出（服务端 attempt 孤儿由服务端超时回收，客户端不重试） |

## 7. 关键代码示例

### 7.1 录音控制器（委托统一音频录制引擎）

```dart
/// 录音管线控制器：只做编排，录制能力委托 UnifiedRecorder（音频引擎）。
/// 红线：任何路径都必须经过 cleanup() 物理删除临时文件（G1）。
class MorningRecordController extends StateNotifier<RecordState> {
  MorningRecordController(this._ref, {required this.itemNo, required this.gradeCapMs})
      : super(const RecordState.idle());
  final Ref _ref;
  final String itemNo;
  final int gradeCapMs; // 学段硬顶 60/120/180/240s（§5）

  File? _tmpFile;
  Timer? _capTimer;

  Future<void> start() async {
    final recorder = _ref.read(unifiedRecorderProvider);
    await recorder.requestPermission(); // 拒绝→引导态（§4.2）
    _tmpFile = File('${(await getTemporaryDirectory()).path}/mr_rec/${const Uuid().v7()}.m4a');
    await recorder.start(_tmpFile!.path, format: RecordFormat.m4a);
    _capTimer = Timer(Duration(milliseconds: gradeCapMs), stopForSubmit);
    state = RecordState.recording(startedAt: DateTime.now());
  }

  Future<void> stopForSubmit() async {
    _capTimer?.cancel();
    final recorder = _ref.read(unifiedRecorderProvider);
    final durationMs = await recorder.stop(); // <5s 由调用方预校验拦截
    state = const RecordState.processing();
    final bytes = await _tmpFile!.readAsBytes();
    final sha256 = await sha256Hex(bytes);
    try {
      await _uploadPipeline(sha256: sha256, durationMs: durationMs);
    } finally {
      await _cleanup(); // G1：成功/失败/异常全路径删除
    }
  }

  Future<void> abandon() async {
    _capTimer?.cancel();
    await _ref.read(unifiedRecorderProvider).cancel();
    await _cleanup();
    state = const RecordState.idle();
  }

  Future<void> _cleanup() async {
    final f = _tmpFile;
    _tmpFile = null;
    if (f != null && await f.exists()) {
      await f.delete(); // assert 后不存在
      assert(!(await f.exists()));
    }
  }
}
```

### 7.2 直传 OSS 上传（禁经服务端中转，C8 对齐）

```dart
/// 上传管线：申请预签名 → 客户端直 PUT → 提交评估。
/// 48211（预签名过期）重申请一次；网络失败整体重试一次后转可重录错误。
Future<MrAttemptResult> _uploadPipeline({required String sha256, required int durationMs}) async {
  final repo = _ref.read(mrRepositoryProvider);
  final idem = _ref.read(idemStoreProvider);

  MrUploadTicket ticket = await repo.requestUploadUrl(
    itemNo: itemNo, audioDurationMs: durationMs, audioSha256: sha256,
  ).withIdem(idem.uploadUrlKey); // 重试复用同幂等键（§3.3）

  try {
    await OssDirectPutter.putWithProgress(
      ticket.uploadUrl, _tmpFile!,
      onProgress: (p) => state = RecordState.uploading(p),
    ); // 取消语义：abandon() 中 OssDirectPutter.cancel(tag)
  } on MrException catch (e) {
    if (e.code == 48211) {
      ticket = await repo.requestUploadUrl(
        itemNo: itemNo, audioDurationMs: durationMs, audioSha256: sha256,
      ).withIdem(idem.uploadUrlKey);
      await OssDirectPutter.put(ticket.uploadUrl, _tmpFile!);
    } else {
      rethrow;
    }
  }
  return repo.submitAttempt(
    itemNo: itemNo, objectKey: ticket.objectKey,
    audioSha256: sha256, audioDurationMs: durationMs,
  ).withIdem(idem.submitKey);
}
```

### 7.3 评估结果轮询（退避 + 推送召回）

```dart
Future<MrAttemptResult> pollAttempt(MorningReadingRepository repo, String attemptNo) async {
  var interval = const Duration(milliseconds: 1500);
  for (var i = 0; i < 40; i++) {
    await Future.delayed(interval);
    final r = await repo.getAttempt(attemptNo);
    switch (r.status) {
      case MrAttemptStatus.evaluating:
        interval = Duration(milliseconds: (interval.inMilliseconds * 1.5).round().clamp(0, 5000));
        break;
      case MrAttemptStatus.succeeded:
      case MrAttemptStatus.failed:
      case MrAttemptStatus.degraded:
        return r; // 终态交 §4.3 渲染
    }
  }
  throw const MrTimeoutException(); // D7 兜底：RESULT_PENDING_PUSH
}
```

```dart
class MorningRouteGuard extends RouteGuard {

    final today = await _ref.read(mrRepositoryProvider).getToday();
```

## 11. 性能设计

- 首页首屏：ETag 缓存命中时本地渲染 <100ms；冷启动接口 P99 目标对齐服务端 <150ms，客户端渲染预算首帧 <300ms。
- 录音页首帧 <200ms（文本快照本地已有，录音引擎懒初始化）。
- sha256 计算下沉 Isolate（≤30MB 文件 <500ms，录制间隙预启动）。
- 心跳与埋点批量合并发送（60s 窗口或 10 条上限），省电对齐《客户端应用生命周期与后台任务调度》。
- 窗口高峰（06:30-07:30）列表滚动 60fps，低端 ≥45fps（波形区 RepaintBoundary）。
