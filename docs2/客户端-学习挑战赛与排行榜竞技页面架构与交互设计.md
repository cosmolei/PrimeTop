# 客户端-学习挑战赛与排行榜竞技页面架构与交互设计

> 版本：v1.0 | 更新日期：2026-06-06 | 模块归属：客户端 → 学习社区与激励

---

## 1. 模块概述

### 1.1 模块定位

学习挑战赛与排行榜竞技模块是 PrimeTop 社交激励体系的核心前端载体，负责将服务端下发的挑战赛配置、排行榜数据、对战匹配结果渲染为可交互界面，驱动学生通过竞技提升学习动力。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| 提升日活与留存 | 限时挑战、每日任务、好友对战提升粘性 |
| 激发学习动力 | 排行榜排名、成就勋章、积分奖励形成正向反馈 |
| 社交裂变获客 | 好友邀请参赛、分享战绩 |
| 分龄体验适配 | 低龄重趣味，高龄重数据与效率 |

### 1.3 设计原则

1. **轻量参与**：3步内进入挑战赛
2. **即时反馈**：答题后200ms内展示对错
3. **安全可控**：排行榜姓名脱敏、无即时通讯
4. **公平竞技**：匹配考虑学段与能力

## 4. API接口设计

### 4.1 GET /api/v1/challenge/hall — 挑战赛大厅

```
Query: gradeCode, subjectCode?, type?, page(1), size(20)
Response 200:
{
  "challenges": [ChallengeCardVO],
  "totalCount": 42,
  "hasMore": true
}
```

### 4.2 POST /api/v1/challenge/{challengeId}/join — 加入挑战

```
Response 200: { "sessionId", "questions", "totalQuestions", "durationSeconds" }
Response 409: { "code": "CHALLENGE_ALREADY_JOINED", "sessionId" }
Response 403: { "code": "CHALLENGE_CONDITION_NOT_MET" }
```

### 4.3 POST /api/v1/challenge/session/{sessionId}/answer — 提交答案

```
Body: { "questionIndex", "selectedOption"?, "fillContent"?, "timeUsedMs" }
Response 200: { "isCorrect", "score", "totalScore", "correctAnswer"?, "streakCount" }
Response 409: { "code": "ANSWER_ALREADY_SUBMITTED" }
```

### 4.4 POST /api/v1/challenge/session/{sessionId}/finish — 完成挑战

```
Response 200:
{
  "sessionId", "score", "correctCount", "totalQuestions",
  "timeUsedSeconds", "rank", "totalParticipants",
  "rewards": { "points": 50, "badge": {...}, "streakBonus": 10 },
  "isNewRecord": true,
  "shareCardUrl": "https://cdn.primetop.app/share/..."
}
```

### 4.5 GET /api/v1/challenge/leaderboard — 排行榜

```
Query: tab, subjectCode?, gradeCode?, cursor?, size(50)
Response 200: { "tab", "topThree", "entries", "myEntry", "totalParticipants", "refreshTime", "nextCursor" }
```

### 4.6 POST /api/v1/challenge/battle/match — 对战匹配

```
Body: { "type": "friend"/"random", "subjectCode", "gradeCode", "inviteUserId"? }
Response 200: { "roomId", "status": "waiting"/"matching", "inviteExpireSeconds"? }
```

### 4.7 WebSocket /ws/v1/battle/{roomId} — 对战实时通信

```
服务端推送:
  opponent_progress → { round, opponentScore, opponentAnswered }
  round_result      → { round, myCorrect, opponentCorrect, myScore, opponentScore }
  battle_finish     → { result, myScore, opponentScore, rewards }

客户端发送:
  submit_answer → { round, selectedOption, timeUsedMs }
```

### 5.2 状态管理

```dart
class ChallengeHallController extends GetxController {
  final RxList<ChallengeCardVO> challenges = <ChallengeCardVO>[].obs;
  final Rx<ChallengeType?> selectedType = Rx(null);
  final RxBool isLoading = false.obs;
  final RxInt currentPage = 1.obs;
  final RxBool hasMore = true.obs;
  final RxInt weeklyScore = 0.obs;
  final RxInt weeklyRank = 0.obs;

  @override
  void onInit() {
    super.onInit();
    loadChallenges(refresh: true);
    loadWeeklySummary();
  }

  Future<void> loadChallenges({bool refresh = false}) async {
    if (isLoading.value) return;
    if (!refresh && !hasMore.value) return;
    isLoading.value = true;
    try {
      final page = refresh ? 1 : currentPage.value + 1;
      final resp = await _api.getChallengeHall(
        gradeCode: UserStore.instance.currentGradeCode,
        type: selectedType.value,
        page: page, size: 20,
      );
      if (refresh) { challenges.assignAll(resp.challenges); currentPage.value = 1; }
      else { challenges.addAll(resp.challenges); currentPage.value = page; }
      hasMore.value = resp.hasMore;
    } catch (e) {
      ToastService.showError('加载失败，请重试');
    } finally {
      isLoading.value = false;
    }
  }

  void onTypeSelected(ChallengeType? type) {
    selectedType.value = type;
    loadChallenges(refresh: true);
  }
}
```

## 6. 每日挑战详情与答题 (DailyChallengePage)

### 6.1 未参与状态

展示封面图、规则摘要（年级/题数/限时）、参与人数、积分奖励、知识点标签、排行榜快照Top3（姓名脱敏）、"开始挑战"主按钮。底部提示"每日挑战只能参与1次"。

### 6.2 答题中状态

顶部：标题 + 倒计时 + 进度(5/10) + 进度条。中部：题干 + 4宫格选项。底部：连击动画 + 导航按钮。选中选项后高亮，确认提交后显示对错。

### 6.3 答题状态机

```
ready →(点击开始)→ playing →(选中/超时)→ answering →(确认)→ submitted →(下一题)→ playing
                                                                                  ↓ (全部答完)
                                                                            finished → reviewing
```

超时未答题目标记为"未答"，自动进入finished。

### 6.4 核心控制器

```dart
class DailyChallengeController extends GetxController with GetTickerProviderSync {
  final String challengeId, sessionId;
  final Rx<PlayPhase> phase = PlayPhase.ready.obs;
  final RxList<ChallengeQuestion> questions = <ChallengeQuestion>[].obs;
  final RxInt currentIndex = 0.obs;
  final RxInt score = 0.obs;
  final RxInt streakCount = 0.obs;
  final RxMap<int, UserAnswer> answers = <int, UserAnswer>{}.obs;
  final Rx<Duration> remainingTime = Duration.zero.obs;
  Timer? _countdownTimer;
  Stopwatch _questionStopwatch = Stopwatch();

  void startChallenge() {
    phase.value = PlayPhase.playing;
    _questionStopwatch.start();
    _countdownTimer = Timer.periodic(Duration(seconds: 1), (t) {
      remainingTime.value -= Duration(seconds: 1);
      if (remainingTime.value <= Duration.zero) { t.cancel(); _autoFinish(); }
    });
  }

  Future<void> submitAnswer({String? selectedOption, String? fillContent}) async {
    _questionStopwatch.stop();
    try {
      final r = await ChallengeApi.submitAnswer(
        sessionId: sessionId,
        questionIndex: currentIndex.value,
        selectedOption: selectedOption,
        fillContent: fillContent,
        timeUsedMs: _questionStopwatch.elapsedMilliseconds,
      );
      answers[currentIndex.value] = UserAnswer(
        selectedOption: selectedOption, fillContent: fillContent,
        isCorrect: r.isCorrect, timeUsedMs: _questionStopwatch.elapsedMilliseconds,
        correctAnswer: r.correctAnswer,
      );
      score.value = r.totalScore;
      if (r.isCorrect) { streakCount.value = r.streakCount; HapticFeedback.mediumImpact(); }
      else { streakCount.value = 0; HapticFeedback.lightImpact(); }
      phase.value = PlayPhase.reviewing;
      Future.delayed(r.isCorrect ? Duration(ms: 800) : Duration(ms: 1500), () => _goNext());
    } catch (e) {
      _cacheOffline(currentIndex.value, selectedOption, fillContent);
      ToastService.showWarning('网络异常，答案已缓存');
    }
  }

  void _goNext() {
    if (currentIndex.value < questions.length - 1) {
      currentIndex.value++;
      phase.value = PlayPhase.playing;
      _questionStopwatch = Stopwatch()..start();
    } else { _finish(); }
  }

  Future<void> _finish() async {
    phase.value = PlayPhase.finished;
    _countdownTimer?.cancel();
    try {
      final result = await ChallengeApi.finishSession(sessionId);
      Get.toNamed('/challenge/result', arguments: result);
    } catch (e) { ToastService.showError('提交失败，请检查网络'); }
  }

  void _autoFinish() {
    for (int i = currentIndex.value; i < questions.length; i++) {
      if (!answers.containsKey(i)) {
        answers[i] = UserAnswer(selectedOption: null, fillContent: null,
          isCorrect: false, timeUsedMs: 0, correctAnswer: null);
      }
    }
    _finish();
  }

  void _cacheOffline(int idx, String? opt, String? fill) {
    OfflineAnswerCache.save(sessionId: sessionId, questionIndex: idx,
      selectedOption: opt, fillContent: fill, timestamp: DateTime.now());
  }

  @override void onClose() { _countdownTimer?.cancel(); super.onClose(); }
}
```

### 7.3 WebSocket连接管理

```dart
class BattleWebSocketManager {
  WebSocketChannel? _channel;
  final Rx<BattleRoomVO> room;
  final RxList<BattleRoundResult> roundResults = [].obs;

  void connect(String roomId, String token) {
    _channel = WebSocketChannel.connect(
      Uri.parse('wss://api.primetop.app/ws/v1/battle/$roomId?token=$token'),
    );
    _channel!.stream.listen(
      (data) {
        final msg = jsonDecode(data);
        switch (msg['type']) {
          case 'opponent_progress':
            _handleOpponentProgress(msg);
            break;
          case 'round_result':
            _handleRoundResult(msg);
            break;
          case 'battle_finish':
            _handleBattleFinish(msg);
            break;
        }
      },
      onError: (e) => _reconnect(roomId, token),
      onDone: () => _reconnect(roomId, token),
    );
  }

  void submitAnswer(int round, String option, int timeUsedMs) {
    _channel?.sink.add(jsonEncode({
      'type': 'submit_answer',
      'round': round,
      'selectedOption': option,
      'timeUsedMs': timeUsedMs,
    }));
  }

  void _handleRoundResult(Map<String, dynamic> msg) {
    roundResults.add(BattleRoundResult.fromJson(msg));
    // 触发UI动画：对/错效果、分数变化动画
  }

  void _handleBattleFinish(Map<String, dynamic> msg) {
    // 关闭WS，跳转结果页
    Get.toNamed('/challenge/battle/result', arguments: msg);
  }

  int _reconnectAttempts = 0;
  void _reconnect(String roomId, String token) {
    if (_reconnectAttempts >= 3) {
      ToastService.showError('连接断开，对战已结束');
      return;
    }
    _reconnectAttempts++;
    Future.delayed(Duration(seconds: 2), () => connect(roomId, token));
  }

  void dispose() {
    _channel?.sink.close();
  }
}
```

class LeaderboardController extends GetxController {

    }

## 11. 离线与弱网处理

### 11.1 离线答案缓存

用户答题时网络中断，答案缓存到本地SQLite，网络恢复后自动同步：

```dart
class OfflineAnswerCache {
  static Future<void> save({
    required String sessionId,
    required int questionIndex,
    String? selectedOption,
    String? fillContent,
    required DateTime timestamp,
  }) async {
    final db = await LocalDB.instance;
    await db.insert('offline_answers', {
      'session_id': sessionId,
      'question_index': questionIndex,
      'selected_option': selectedOption,
      'fill_content': fillContent,
      'timestamp': timestamp.toIso8601String(),
      'synced': 0,
    });
  }

  static Future<void> syncPending() async {
    final db = await LocalDB.instance;
    final pending = await db.query('offline_answers', where: 'synced = 0');
    for (final row in pending) {
      try {
        await ChallengeApi.submitAnswer(
          sessionId: row['session_id'],
          questionIndex: row['question_index'],
          selectedOption: row['selected_option'],
          fillContent: row['fill_content'],
          timeUsedMs: 0, // 离线时无法精确计时
        );
        await db.update('offline_answers', {'synced': 1},
          where: 'id = ?', whereArgs: [row['id']]);
      } catch (_) { break; } // 网络仍不可用，停止重试
    }
  }
}
```

### 11.2 弱网策略

| 场景 | 策略 |
|------|------|
| 提交答案超时(>5s) | 本地缓存，显示"已保存"，后台重试 |

| 分享卡片生成失败 | 降级为文字分享（含链接） |

## 13. 错误处理

### 13.1 错误码映射

| 错误码 | 场景 | 用户提示 | 处理方式 |
|--------|------|----------|----------|
| CHALLENGE_NOT_FOUND | 挑战赛不存在 | "该挑战赛已下线" | 返回大厅 |
| CHALLENGE_ALREADY_JOINED | 重复参与 | "您已参与本次挑战" | 跳转到已有会话 |
| CHALLENGE_NOT_STARTED | 未到开始时间 | "挑战尚未开始，敬请期待" | 显示倒计时 |
| CHALLENGE_ENDED | 已结束 | "该挑战赛已结束" | 展示最终排名 |
| CHALLENGE_CONDITION_NOT_MET | 条件不满足 | "需要先完成前置挑战" | 引导去完成前置 |
| ANSWER_ALREADY_SUBMITTED | 重复提交 | 静默忽略 | 跳到下一题 |
| SESSION_EXPIRED | 会话过期 | "答题会话已超时" | 返回大厅 |
| BATTLE_OPPONENT_LEFT | 对手离开 | "对手已离开对战" | 按当前分数结算 |
| BATTLE_CONNECTION_LOST | WS断开 | "网络连接中断" | 重连或结算 |
| RATE_LIMITED | 频率限制 | "操作过于频繁，请稍后再试" | 倒计时冷却 |

### 13.2 全局异常处理

```dart
class ChallengeErrorHandler {
  static void handle(Object error, {required VoidCallback onRetry}) {
    if (error is ApiException) {
      switch (error.code) {
        case 'CHALLENGE_NOT_FOUND':
        case 'CHALLENGE_ENDED':
          ToastService.showInfo(error.message);
          Get.back(); // 返回大厅
          break;
        case 'SESSION_EXPIRED':
          showDialog(
            context: Get.context!,
            builder: (_) => AlertDialog(
              title: Text('答题超时'),
              content: Text('本次答题会话已过期'),
              actions: [TextButton(onPressed: () => Get.back(), child: Text('确定'))],
            ),
          );
          break;
        case 'RATE_LIMITED':
          ToastService.showWarning(error.message);
          break;
        default:
          ToastService.showError('出错了，请重试');
          onRetry();
      }
    } else if (error is SocketException || error is TimeoutException) {
      ToastService.showWarning('网络不给力，请检查网络连接');
    } else {
      Crashlytics.recordError(error, StackTrace.current);
      ToastService.showError('未知错误');
    }
  }
}
```

## 14. 性能优化

### 14.1 列表虚拟化
