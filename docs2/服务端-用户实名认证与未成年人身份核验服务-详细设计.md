# 服务端 - 用户实名认证与未成年人身份核验服务 详细设计

## 1. 文档说明

### 1.1 文档目的

本文档对启硕 PrimeTop 的用户实名认证与未成年人身份核验服务进行详细设计，为开发人员提供可直接编码的实现方案。

### 1.2 背景

根据中国《未成年人保护法》《个人信息保护法》《关于防止未成年人沉迷网络游戏的通知》等法规要求，教育类 APP 必须对用户进行身份核验，识别未成年人身份并实施相应保护措施（防沉迷、时长限制、付费限制等）。本服务负责：

1. 用户实名认证（身份证信息核验）
2. 未成年人身份识别与年龄判定
3. 监护人关系核验
4. 认证状态管理与全生命周期追踪
5. 与防沉迷、家长中心、支付等模块的联动

### 1.3 设计原则

- **合规优先**：严格遵循国家实名认证与未成年人保护相关法规
- **隐私最小化**：仅采集必要身份信息，敏感数据加密存储
- **渐进式认证**：根据使用场景触发不同级别的认证要求
- **降级容灾**：第三方核验服务异常时提供降级方案
- **审计可追溯**：所有认证操作留存审计日志

## 3. 数据结构定义

### 3.1 用户认证记录表 `user_verification`

```sql
CREATE TABLE user_verification (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL,              -- 关联用户ID
    verification_type   VARCHAR(32) NOT NULL,         -- 认证类型：PHONE/ID_CARD/FACE
    status              VARCHAR(20) NOT NULL,         -- 状态：PENDING/SUBMITTED/VERIFYING/SUCCESS/FAILED/EXPIRED
    
    -- 手机号实名信息
    phone_number        VARCHAR(20),                  -- 脱敏存储：138****1234
    phone_carrier       VARCHAR(10),                  -- 运营商：CMCC/CUCC/CTCC
    phone_verified_at   TIMESTAMPTZ,                  -- 手机号验证时间
    
    -- 身份证实名信息
    id_card_hash        VARCHAR(128),                 -- 身份证号SHA-256哈希（不可逆）
    id_card_masked      VARCHAR(20),                  -- 脱敏展示：310***********1234
    id_card_name_hash   VARCHAR(128),                 -- 姓名SHA-256哈希
    id_card_name_masked VARCHAR(10),                  -- 姓*或**
    id_card_region      VARCHAR(10),                  -- 身份证归属地编码
    id_card_expiry      DATE,                         -- 证件有效期
    
    -- 人脸核验信息
    face_verified       BOOLEAN DEFAULT FALSE,         -- 是否通过人脸核验
    face_verified_at    TIMESTAMPTZ,
    face_score          DECIMAL(5,2),                  -- 人脸相似度评分
    
    -- 年龄与未成年人判定
    birth_date          DATE,                          -- 出生日期（仅存储年月日）
    age                 INT,                           -- 核验时年龄
    is_minor            BOOLEAN,                       -- 是否未成年人（<18周岁）
    minor_age_group     VARCHAR(10),                   -- 未成年分组：INFANT/CHILD/TEEN
    
    -- 第三方核验结果
    vendor_code         VARCHAR(20),                   -- 核验供应商编码
    vendor_request_id   VARCHAR(64),                   -- 供应商请求ID
    vendor_result_code  VARCHAR(20),                   -- 供应商返回码
    vendor_raw_response JSONB,                         -- 原始响应（加密存储）
    
    -- 认证元数据
    client_ip           VARCHAR(45),                   -- 请求IP
    device_fingerprint  VARCHAR(64),                   -- 设备指纹
    app_version         VARCHAR(20),                   -- APP版本
    submitted_at        TIMESTAMPTZ,                   -- 提交时间
    verified_at         TIMESTAMPTZ,                   -- 核验完成时间
    expired_at          TIMESTAMPTZ,                   -- 过期时间
    retry_count         INT DEFAULT 0,                 -- 重试次数
    fail_reason         VARCHAR(200),                  -- 失败原因
    
    -- 审计
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_verification_user_id ON user_verification(user_id);
CREATE INDEX idx_verification_status ON user_verification(status);
CREATE UNIQUE INDEX idx_verification_user_type ON user_verification(user_id, verification_type) 
    WHERE status IN ('SUCCESS', 'VERIFYING');
CREATE INDEX idx_verification_minor ON user_verification(is_minor) WHERE is_minor = TRUE;
CREATE INDEX idx_verification_created_at ON user_verification(created_at);
```

### 3.5 核心枚举定义

```java
// ===== 认证类型 =====
public enum VerificationType {
    PHONE("phone", "手机号实名"),
    ID_CARD("id_card", "身份证实名"),
    FACE("face", "人脸核验");
}

// ===== 认证状态 =====
public enum VerificationStatus {
    PENDING("pending", "待提交"),
    SUBMITTED("submitted", "已提交"),
    VERIFYING("verifying", "核验中"),
    SUCCESS("success", "核验通过"),
    FAILED("failed", "核验失败"),
    EXPIRED("expired", "已过期");
}

// ===== 未成年人年龄段 =====
public enum MinorAgeGroup {
    INFANT("infant", "婴幼儿", 0, 6),
    CHILD("child", "儿童", 6, 12),
    TEEN("teen", "青少年", 12, 18);
    
    private final String code;
    private final String label;
    private final int minAge;
    private final int maxAge;
    
    public static MinorAgeGroup fromAge(int age) {
        if (age < 6) return INFANT;
        if (age < 12) return CHILD;
        return TEEN;
    }
}

// ===== 监护人关系类型 =====
public enum GuardianType {
    PARENT("parent", "父母"),
    GRANDPARENT("grandparent", "祖父母/外祖父母"),
    OTHER("other", "其他法定监护人");
}

// ===== 降级模式 =====
public enum FallbackMode {
    TRUST_WITH_MONITOR,     // 信任放行，加强监控
    BLOCK,                  // 阻断使用
    MANUAL_REVIEW           // 转人工审核
}
```

```sql
--   PENDING_REVIEW          降级放行待补验（E2E 同名状态）
--   MANUAL_REVIEW_REQUIRED  重试耗尽/人工介入（v1.0 图中 BLOCKED 的正式命名）

-- 一号多账号强约束（§6.3 步骤 3 的数据库兜底）：
CREATE UNIQUE INDEX uk_idcard_success ON user_verification(id_card_hash)
    WHERE status = 'SUCCESS' AND id_card_hash IS NOT NULL;

-- 补验任务扫描索引
CREATE INDEX idx_verify_retry ON user_verification(status, pending_review, updated_at)
    WHERE pending_review = TRUE;

-- ===== guardian_relation 增补 =====
ALTER TABLE guardian_relation
    ADD COLUMN relationship     VARCHAR(16),       -- v1.1：FATHER/MOTHER/LEGAL_GUARDIAN/OTHER（对齐 E2E；guardian_type 废弃）
    ADD COLUMN bind_method      VARCHAR(16),       -- v1.1：PHONE_SMS/ID_CARD_VERIFY/QR_SCAN

    ADD COLUMN consent_at       TIMESTAMPTZ,       -- v1.1：同意时间戳
    ADD COLUMN resume_context   JSONB,             -- v1.1：绑定完成后需继续的业务上下文（家长门 §6.7）
    ADD COLUMN status_ext       VARCHAR(20);       -- v1.1：EXPIRED（儿童成年自动解绑）
-- 关系命名迁移：PARENT→LEGAL_GUARDIAN（无法区分父/母时保守归类），GRANDPARENT 保留
UPDATE guardian_relation SET relationship = 'LEGAL_GUARDIAN' WHERE guardian_type = 'PARENT';
UPDATE guardian_relation SET relationship = guardian_type    WHERE guardian_type IN ('GRANDPARENT','OTHER');

-- 年龄段迁移：TEEN→ADOLESCENT，并按出生日期重算 7/14 边界
UPDATE user_verification SET age_group = 'ADOLESCENT' WHERE minor_age_group = 'TEEN';
UPDATE user_verification uv SET age_group = 'CHILD', is_child = TRUE
    WHERE uv.birth_date IS NOT NULL AND uv.birth_date > CURRENT_DATE - INTERVAL '14 years'
      AND uv.age_group = 'ADOLESCENT';

-- ===== Outbox 表（事务性事件发布，见 §7） =====
CREATE TABLE verification_outbox (
    id              BIGSERIAL PRIMARY KEY,
    event_id        VARCHAR(64) NOT NULL UNIQUE,        -- 幂等键（消费方去重）
    aggregate_id    BIGINT NOT NULL,                     -- userId（分区/排序键）
    event_type      VARCHAR(64) NOT NULL,                -- user.verification.*
    payload         JSONB NOT NULL,
    status          VARCHAR(10) NOT NULL DEFAULT 'PENDING',  -- PENDING/SENT/DEAD
    retry_count     INT NOT NULL DEFAULT 0,
    next_retry_at   TIMESTAMPTZ,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    sent_at         TIMESTAMPTZ
);
CREATE INDEX idx_outbox_pending ON verification_outbox(status, next_retry_at);
```

## 4. API 接口设计

### 4.1 触发实名认证（手机号）

用户注册后或触发认证场景时调用。

```
POST /api/v1/verification/phone
Authorization: Bearer <token>
Content-Type: application/json
```

**请求体：**
```json
{
    "phone": "13800138000",
    "sms_code": "123456",
    "scene": "REGISTER"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | string | 是 | 手机号码 |
| sms_code | string | 是 | 短信验证码 |
| scene | string | 是 | 触发场景：REGISTER/FEATURE_ACCESS/PAYMENT/AUTO_CHECK |

**响应体（成功）：**
```json
{
    "code": 0,
    "data": {
        "verification_id": "vf_202606051234567890",
        "status": "SUCCESS",
        "is_minor": false,
        "age": 25,
        "minor_age_group": null,
        "next_step": null,
        "message": "实名认证通过"
    }
}
```

**响应体（未成年人）：**
```json
{
    "code": 0,
    "data": {
        "verification_id": "vf_202606051234567891",
        "status": "SUCCESS",
        "is_minor": true,
        "age": 14,
        "minor_age_group": "TEEN",
        "next_step": "ID_CARD_VERIFICATION",
        "message": "检测到未成年人身份，请完成身份证核验以获得监护人绑定引导"
    }
}
```

**错误码：**
| 错误码 | 说明 |
|--------|------|
| VERIFICATION_PHONE_INVALID | 手机号格式错误 |
| VERIFICATION_SMS_CODE_WRONG | 验证码错误 |
| VERIFICATION_SMS_EXPIRED | 验证码过期 |
| VERIFICATION_VENDOR_UNAVAILABLE | 第三方核验服务不可用 |
| VERIFICATION_RATE_LIMITED | 超过当日重试限制 |

### 4.2 身份证 OCR 识别 + 核验

```
POST /api/v1/verification/id-card
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

**请求参数：**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id_card_front | file | 是 | 身份证正面照片（<5MB） |
| id_card_back | file | 否 | 身份证背面照片（有效期核验） |
| name | string | 是 | 真实姓名 |
| id_number | string | 是 | 身份证号码 |
| ocr_result | json | 否 | 客户端 OCR 预识别结果（辅助校验） |

**响应体（成功）：**
```json
{
    "code": 0,
    "data": {
        "verification_id": "vf_20260605_id_12345",
        "status": "SUCCESS",
        "is_minor": true,
        "age": 14,
        "birth_date": "2012-03-15",
        "minor_age_group": "TEEN",
        "id_card_masked": "310***********1234",
        "name_masked": "张*",
        "next_step": "GUARDIAN_BINDING",
        "message": "身份证核验通过"
    }
}
```

**错误码：**
| 错误码 | 说明 |
|--------|------|
| VERIFICATION_ID_IMAGE_TOO_LARGE | 图片超过5MB |
| VERIFICATION_ID_IMAGE_UNREADABLE | 图片无法识别 |
| VERIFICATION_ID_NUMBER_INVALID | 身份证号校验位不通过 |
| VERIFICATION_ID_NAME_MISMATCH | 姓名与身份证不匹配 |
| VERIFICATION_ID_EXPIRED | 身份证已过期 |
| VERIFICATION_ID_ALREADY_USED | 该身份证已被其他账号认证 |

### 6.2 手机号实名认证实现

```java
@Service
@Slf4j
public class PhoneVerificationServiceImpl {
    
    @Autowired
    private VerificationConfigRepository configRepo;
    
    @Autowired
    private VendorVerificationClient vendorClient;
    
    @Autowired
    private UserRepository userRepo;
    
    @Autowired
    private VerificationAuditService auditService;
    
    @Autowired
    private MinorProtectionService minorProtectionService;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String RATE_LIMIT_PREFIX = "verify:rate:";
    private static final String CACHE_PREFIX = "verify:cache:";
    
    /**
     * 手机号实名认证主流程
     */
    @Transactional
    public VerificationResult verifyByPhone(PhoneVerificationRequest request) {
        Long userId = SecurityContext.getCurrentUserId();
        
        // 1. 检查重试限制
        checkRateLimit(userId);
        
        // 2. 验证短信验证码
        validateSmsCode(request.getPhone(), request.getSmsCode());
        
        // 3. 检查缓存 - 近期内是否已核验过
        String cacheKey = CACHE_PREFIX + "phone:" + DigestUtils.sha256Hex(request.getPhone());
        VerificationResult cached = (VerificationResult) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            log.info("Phone verification cache hit, userId={}", userId);
            return cached;
        }
        
        // 4. 创建认证记录
        UserVerification verification = UserVerification.builder()
            .userId(userId)
            .verificationType(VerificationType.PHONE.getCode())
            .status(VerificationStatus.VERIFYING.getCode())
            .phoneNumber(maskPhone(request.getPhone()))
            .submittedAt(Instant.now())
            .clientIp(request.getClientIp())
            .deviceFingerprint(request.getDeviceFingerprint())
            .build();
        verificationRepo.save(verification);
        
        // 5. 调用第三方手机号实名核验
        VendorVerifyResponse vendorResp;
        try {
            vendorResp = vendorClient.verifyPhoneNumber(
                request.getPhone(), request.getName()
            );
        } catch (VendorException e) {
            return handleVendorFailure(verification, e);
        }
        
        // 6. 处理核验结果
        verification.setVendorCode(vendorResp.getVendorCode());
        verification.setVendorRequestId(vendorResp.getRequestId());
        verification.setVendorResultCode(vendorResp.getResultCode());

        // 6.1 供应商明确返回「不一致 / 无实名记录」：认证失败，计入重试次数
        if (!vendorResp.isMatched()) {
            verification.setStatus(VerificationStatus.FAILED.getCode());
            verification.setFailReason("VENDOR_NOT_MATCHED:" + vendorResp.getResultCode());
            verification.setRetryCount(verification.getRetryCount() + 1);
            verificationRepo.save(verification);
            auditService.log(userId, AuditAction.VERIFY_FAIL, Map.of(
                "type", "PHONE",
                "vendorResult", vendorResp.getResultCode(),
                "retryCount", verification.getRetryCount()));
            incrFailCounter(userId);   // 失败冷却：30 分钟内累计 3 次锁定（Redis）
            throw new BizException(ErrorCode.VERIFICATION_VENDOR_NOT_MATCHED);
        }

        // 7. 年龄判定：运营商二要素仅返回「姓名-号码一致」，出生日期字段（birthDate）
        //    仅部分运营商通道返回。返回 null 时视为「无法判定」，引导补充身份证核验。
        AgeDeterminationResult ageResult = ageService.determine(
            userId, vendorResp.getPhoneDetail() != null
                ? vendorResp.getPhoneDetail().getBirthDate() : null);

        // 8. 落库核验成功 + 计算有效期（成年 2 年 / 未成年人或无法判定 1 年）
        verification.setStatus(VerificationStatus.SUCCESS.getCode());
        verification.setVerifiedAt(Instant.now());
        verification.setIsMinor(ageResult.getIsMinor());          // 允许 null = 无法判定
        verification.setAge(ageResult.getAge());
        verification.setAgeGroup(ageResult.getAgeGroup());        // v1.1 列，见 §3.6
        verification.setValidUntil(ageService.calcValidity(ageResult));
        verificationRepo.save(verification);

        // 9. 写入结果缓存（TTL 来自 verification_config.verification_cache_hours，默认 168h）
        VerificationResult result = buildResult(verification, ageResult);
        redisTemplate.opsForValue().set(cacheKey, result,
            Duration.ofHours(configRepo.getLong("verification_cache_hours", 168L)));

        // 10. 同事务写 Outbox，发布 user.verification.completed（见 §7）
        outboxService.append(verification.getUserId(), OutboxEvents.completed(
            verification, ageResult, "PHONE_ONLY", false));

        // 11. 审计
        auditService.log(userId, AuditAction.VERIFY_SUCCESS, Map.of(
            "type", "PHONE",
            "isMinor", String.valueOf(ageResult.getIsMinor()),
            "vendorCode", vendorResp.getVendorCode()));

        return result;
    }

    /**
     * 供应商调用失败（超时/网络/服务不可用）→ 走降级链（见 §6.8 / §10）
     */
    private VerificationResult handleVendorFailure(UserVerification verification,
                                                    VendorException e) {
        log.warn("Vendor phone verify failed, userId={}, err={}",
            verification.getUserId(), e.getMessage());
        return fallbackService.downgradePhoneVerification(verification, e);
    }

    /** 每日重试限制（verification_config.max_retry_per_day，默认 3 次/日） */
    private void checkRateLimit(Long userId) {
        String key = RATE_LIMIT_PREFIX + "day:" + LocalDate.now() + ":" + userId;
        Long count = redisTemplate.opsForValue().increment(key);
        if (count == 1) redisTemplate.expire(key, Duration.ofDays(1));
        int max = configRepo.getInt("max_retry_per_day", 3);
        if (count > max) {
            throw new BizException(ErrorCode.VERIFICATION_RATE_LIMITED);
        }
        // 失败冷却：连续失败 3 次 → 30 分钟冷却窗口（对齐 E2E §9.1）
        String coolKey = RATE_LIMIT_PREFIX + "cool:" + userId;
        if (Boolean.TRUE.equals(redisTemplate.hasKey(coolKey))) {
            throw new BizException(ErrorCode.VERIFICATION_COOLDOWN);
        }
    }

    private void incrFailCounter(Long userId) {
        String failKey = RATE_LIMIT_PREFIX + "fail:" + userId;
        Long fails = redisTemplate.opsForValue().increment(failKey);
        if (fails == 1) redisTemplate.expire(failKey, Duration.ofMinutes(30));
        if (fails != null && fails >= 3) {
            redisTemplate.opsForValue().set(RATE_LIMIT_PREFIX + "cool:" + userId,
                "1", Duration.ofMinutes(30));
        }
    }
```

> **实现说明（运营商二要素的年龄判定边界）**：手机号二要素核验（姓名+手机号）在多数运营商通道只返回「一致/不一致」，**不返回出生日期**。因此 `verifyByPhone` 的结果分三类：① 姓名号码不一致 → FAILED；② 一致且运营商返回出生日期 → 直接完成年龄判定（§4.1 响应示例中的成年用户即此情形，或该用户已有历史身份证认证）；③ 一致但无出生日期 → `is_minor = null`（无法判定），`next_step = ID_CARD_VERIFICATION`，客户端引导进入身份证核验。**严禁**在无法判定场景下默认按成年处理（宁严勿松原则，见 §12 C7）。

### 6.3 身份证核验实现

#### 6.3.1 主流程

```java
@Service
@Slf4j
public class IdCardVerificationServiceImpl {

    @Autowired private VerificationConfigRepository configRepo;
    @Autowired private VendorVerificationClient vendorClient;
    @Autowired private UserVerificationRepository verificationRepo;
    @Autowired private AgeDeterminationService ageService;
    @Autowired private OcrClient ocrClient;                 // 复用《图片处理与OCR识别管线》
    @Autowired private VerificationOutboxService outboxService;
    @Autowired private VerificationAuditService auditService;

    @Transactional
    public VerificationResult verifyByIdCard(IdCardVerificationRequest request) {
        Long userId = SecurityContext.getCurrentUserId();

        // 1. 本地校验：身份证号格式 + GB11643 校验位（算法见 E2E §15.2）
        if (!IdCardUtils.validateChecksum(request.getIdNumber())) {
            throw new BizException(ErrorCode.VERIFICATION_ID_NUMBER_INVALID);
        }
        // 2. 提取出生日期 / 性别 / 归属地（纯本地计算，不依赖供应商）
        IdCardMeta meta = IdCardUtils.parse(request.getIdNumber());
        if (meta.getBirthDate().isAfter(LocalDate.now())) {
            throw new BizException(ErrorCode.VERIFICATION_ID_NUMBER_INVALID);
        }

        // 3. 一号多账号检测：仅比对 id_card_hash（明文不落库，见 §12 C1）
        String idHash = DigestUtils.sha256Hex(request.getIdNumber());
        Optional<UserVerification> used = verificationRepo.findSuccessByIdCardHash(idHash);
        if (used.isPresent() && !used.get().getUserId().equals(userId)) {
            throw new BizException(ErrorCode.VERIFICATION_ID_ALREADY_USED);  // 解绑流程见 §6.6.4
        }

        // 4. OCR 辅助校验（可选）：证件照识别结果与手输信息比对，防 OCR 误识别
        if (request.getOcrResult() != null && !request.getOcrResult().isBlank()) {
            OcrCompare cmp = ocrClient.compareIdCard(request.getOcrResult(),
                request.getName(), request.getIdNumber());
            if (cmp.getConfidence() < 0.7) {   // 对齐 E2E §9.1 阈值
                throw new BizException(ErrorCode.VERIFICATION_ID_IMAGE_UNREADABLE);
            }
            if (cmp.isMismatch()) {
                throw new BizException(ErrorCode.VERIFICATION_ID_NAME_MISMATCH);
            }
        }

        // 5. 有效期核验（背面照 OCR，可不传；未成年人证件多为长期）
        if (request.getIdCardExpiry() != null
                && request.getIdCardExpiry().isBefore(LocalDate.now())) {
            throw new BizException(ErrorCode.VERIFICATION_ID_EXPIRED);
        }

        // 6. 创建记录（敏感字段仅存 hash + 掩码）
        UserVerification verification = UserVerification.builder()
            .userId(userId)
            .verificationType(VerificationType.ID_CARD.getCode())
            .status(VerificationStatus.VERIFYING.getCode())
            .idCardHash(idHash)
            .idCardMasked(IdCardUtils.mask(request.getIdNumber()))
            .idCardNameHash(DigestUtils.sha256Hex(request.getName()))
            .idCardNameMasked(IdCardUtils.maskName(request.getName()))
            .idCardRegion(meta.getRegionCode())
            .idCardExpiry(request.getIdCardExpiry())
            .submittedAt(Instant.now())
            .build();
        verificationRepo.save(verification);

        // 7. 调用供应商二要素（姓名+身份证号）核验，带故障转移链
        VendorVerifyResponse vendorResp;
        try {
            vendorResp = vendorClient.verifyIdCardWithFailover(
                request.getName(), request.getIdNumber());
        } catch (VendorAllUnavailableException e) {
            return fallbackService.downgradeIdCardVerification(
                verification, request, meta);          // 见 §6.8
        }
        verification.setVendorCode(vendorResp.getVendorCode());
        verification.setVendorRequestId(vendorResp.getRequestId());
        verification.setVendorResultCode(vendorResp.getResultCode());

        if (!vendorResp.isMatched()) {
            verification.setStatus(VerificationStatus.FAILED.getCode());
            verification.setFailReason("VENDOR_NOT_MATCHED:" + vendorResp.getResultCode());
            verificationRepo.save(verification);
            auditService.log(userId, AuditAction.VERIFY_FAIL,
                Map.of("type", "ID_CARD", "vendorResult", vendorResp.getResultCode()));
            throw new BizException(ErrorCode.VERIFICATION_ID_NAME_MISMATCH);
        }

        // 8. 年龄判定与分流（§6.5）
        AgeDeterminationResult ageResult = ageService.determine(userId, meta.getBirthDate());
        verification.setStatus(VerificationStatus.SUCCESS.getCode());
        verification.setBirthDate(meta.getBirthDate());
        verification.setAge(ageResult.getAge());
        verification.setIsMinor(ageResult.getIsMinor());
        verification.setAgeGroup(ageResult.getAgeGroup());
        verification.setIsChild(ageResult.getIsChild());      // <14 岁，v1.1 列
        verification.setVerifiedAt(Instant.now());
        verification.setValidUntil(ageService.calcValidity(ageResult));
        verificationRepo.save(verification);

        // 9. Outbox 发布事件（level=ID_CARD）
        outboxService.append(userId, OutboxEvents.completed(
            verification, ageResult, "ID_CARD", false));
        auditService.log(userId, AuditAction.VERIFY_SUCCESS,
            Map.of("type", "ID_CARD", "isMinor", String.valueOf(ageResult.getIsMinor())));

        // 10. 组装结果：<14 岁强制监护人绑定；14-17 岁建议绑定
        return VerificationResult.builder()
            .verificationId(verification.getVerificationId())
            .status("SUCCESS")
            .isMinor(ageResult.getIsMinor())
            .isChild(ageResult.getIsChild())
            .age(ageResult.getAge())
            .ageGroup(ageResult.getAgeGroup())
            .idCardMasked(verification.getIdCardMasked())
            .nameMasked(verification.getIdCardNameMasked())
            .nextStep(ageResult.getIsChild() ? "GUARDIAN_BINDING"
                : (Boolean.TRUE.equals(ageResult.getIsMinor())
                    ? "GUARDIAN_BINDING_RECOMMENDED" : null))
            .build();
    }
}
```

### 6.4 人脸核验实现（可选增强）

人脸核验仅在两类场景启用：① 用户主动升级认证（`face_verify_enabled=true`）；② 被统一家长门 V4 实名强核验复用（账户注销、单笔 ≥1000 元支付等场景，见《统一家长门》§2.1）。

```java
@Service
public class FaceVerificationServiceImpl {

    private static final BigDecimal PASS_THRESHOLD = new BigDecimal("0.80");
    private static final int MAX_FACE_RETRY = 3;

    @Transactional
    public VerificationResult verifyByFace(FaceVerificationRequest request) {
        Long userId = SecurityContext.getCurrentUserId();

        // 1. 前置：必须已有成功的身份证核验（人脸比对的信任根是实名信息）
        UserVerification idVerified = verificationRepo
            .findLatestSuccess(userId, VerificationType.ID_CARD)
            .orElseThrow(() -> new BizException(ErrorCode.VERIFICATION_ID_REQUIRED_FIRST));

        // 2. 活体检测（静默/动作两种，由客户端 SDK 采集视频流）
        LivenessResult liveness = vendorClient.detectLiveness(request.getVideoBlob());
        if (!liveness.isLive()) {
            throw new BizException(ErrorCode.VERIFICATION_LIVENESS_FAILED);
        }

        // 3. 1:1 比对：与公安权威源或上次认证人脸底片比对
        FaceCompareResult cmp = vendorClient.compareFace1To1(
            liveness.getBestFrame(), idVerified.getFacePhotoHash());
        boolean pass = cmp.getScore().compareTo(PASS_THRESHOLD) >= 0;

        // 4. 重试与转人工（对齐 E2E §9.1：允许重试 3 次，超限转人工）
        UserVerification verification = UserVerification.builder()
            .userId(userId).verificationType(VerificationType.FACE.getCode())
            .status(pass ? VerificationStatus.SUCCESS.getCode()
                         : VerificationStatus.FAILED.getCode())
            .faceVerified(pass).faceScore(cmp.getScore())
            .faceVerifiedAt(pass ? Instant.now() : null)
            .facePhotoHash(pass ? cmp.getFrameHash() : null)   // 仅存 hash，见 §12 C5
            .build();
        verificationRepo.save(verification);

        if (!pass) {
            long fails = verificationRepo.countTodayFaceFail(userId);
            if (fails >= MAX_FACE_RETRY) {
                reviewTaskService.createManualReview(verification, "FACE_RETRY_EXHAUSTED");
                throw new BizException(ErrorCode.VERIFICATION_FACE_MANUAL_REVIEW);
            }
            throw new BizException(ErrorCode.VERIFICATION_FACE_NOT_MATCH);
        }

        // 5. 事件 + 简化续期资格（validUntil 顺延，见 §8）
        outboxService.append(userId, OutboxEvents.completed(
            verification, ageService.current(userId), "FACE_RECOGNITION", false));
        return VerificationResult.pass(verification);
    }

    /** 供统一家长门 V4 调用的内部接口（不对客户端暴露） */
```

### 6.5 年龄判定与分流服务

```java
@Service
public class AgeDeterminationServiceImpl implements AgeDeterminationService {

    /**
     * 精确周岁计算（对齐 E2E §5.1：满 18 周岁为成年，生日当天即变更）
     */
    @Override
    public int calcExactAge(LocalDate birthDate) {
        LocalDate today = LocalDate.now(ZoneId.of("Asia/Shanghai"));
        int age = Period.between(birthDate, today).getYears();
        if (age < 0 || age > 120) {
            throw new BizException(ErrorCode.VERIFICATION_ID_NUMBER_INVALID);
        }
        return age;
    }

    /**
     * 年龄段分组（v1.1 与 E2E §5.1 完全对齐；v1.0 的 TEEN/6-12 划分废弃，见 §3.6 迁移）
     *   INFANT     0-6    幼儿启蒙段
     *   CHILD      7-13   小学段（<14 → isChild=true，触发儿童个人信息保护）
     *   ADOLESCENT 14-17  中学段
     *   ADULT      >=18
     */
    @Override
    public AgeDeterminationResult determine(Long userId, LocalDate birthDate) {
        if (birthDate == null) {
            // 无法判定：不下结论、不放行成年待遇（宁严勿松）
            return AgeDeterminationResult.unknown(userId);
        }
        int age = calcExactAge(birthDate);
        AgeGroup group;
        if (age >= 18)      group = AgeGroup.ADULT;
        else if (age >= 14) group = AgeGroup.ADOLESCENT;
        else if (age >= 7)  group = AgeGroup.CHILD;
        else                group = AgeGroup.INFANT;

        boolean isMinor = group != AgeGroup.ADULT;
        boolean isChild = age < 14;    // 《儿童个人信息网络保护规定》儿童定义
        return AgeDeterminationResult.of(userId, age, group, isMinor, isChild);
    }

    /**
     * 有效期：成年 2 年 / 未成年人及无法判定 1 年（对齐 E2E §10.1）
     */
    @Override
    public Instant calcValidity(AgeDeterminationResult r) {
        boolean adult = Boolean.FALSE.equals(r.getIsMinor()) && r.getAgeGroup() != null;
        return Instant.now().plus(adult ? Duration.ofDays(730) : Duration.ofDays(365));
    }
}
```

#### 6.5.1 年龄段边界日重算任务

用户在认证后仍会跨越 7/14/16/18 岁边界（16 岁是《防沉迷》L1/L2 分层边界）。每日 00:05 执行：

```sql
-- birth_date 精确到日，直接按边界日筛选，避免全表扫描
SELECT user_id, birth_date, age, age_group, is_minor
FROM user_verification
WHERE status = 'SUCCESS' AND verification_type = 'ID_CARD'
  AND ( birth_date = CURRENT_DATE - INTERVAL '7 years'    -- 今日满 7 岁
     OR birth_date = CURRENT_DATE - INTERVAL '14 years'   -- 今日满 14 岁
     OR birth_date = CURRENT_DATE - INTERVAL '16 years'   -- 今日满 16 岁（防沉迷分层）
     OR birth_date = CURRENT_DATE - INTERVAL '18 years'   -- 今日成年
     OR birth_date = CURRENT_DATE - INTERVAL '19 years' ); -- 兜底：补处理昨日漏网
```

命中后处理：CAS 重算 `age/age_group/is_minor/is_child`（乐观锁 version）；发布 `user.verification.age_group_changed` 事件（§7.2）。满 18 岁额外触发：防沉迷配置停用、`guardian_relation` 批量置 EXPIRED（reason=CHILD_OVER_18）、发布 `user.verification.guardian_expired`。

```java
@Service
@Slf4j
public class GuardianBindingServiceImpl implements GuardianBindingService {

    @Autowired private GuardianRelationRepository guardianRepo;
    @Autowired private VendorVerificationClient vendorClient;
    @Autowired private AgeDeterminationService ageService;
    @Autowired private SmsService smsService;               // 《统一短信验证码服务》
    @Autowired private VerificationOutboxService outboxService;
    @Autowired private VerificationAuditService auditService;
    @Autowired private ManualReviewTaskService reviewTaskService;
    @Autowired private RiskSignalClient riskSignalService;

    @Transactional
    public GuardianBindingResult bindGuardian(Long minorUserId, GuardianBindingRequest req) {
        // 1. 前置校验：目标用户必须是儿童（<14 岁）且已完成身份证核验
        UserVerification v = verificationRepo
            .findLatestSuccess(minorUserId, VerificationType.ID_CARD)
            .orElseThrow(() -> new BizException(ErrorCode.VERIFICATION_NOT_VERIFIED));
        if (!Boolean.TRUE.equals(v.getIsChild())) {
            throw new BizException(ErrorCode.VERIFICATION_NOT_A_CHILD);
        }
        // 2. 儿童隐私规则单独同意（《儿童个人信息网络保护规定》要求，证据入库）
        if (!req.isChildPrivacyPolicyAccepted() || !req.isConsentGiven()) {
            throw new BizException(ErrorCode.VERIFICATION_POLICY_NOT_ACCEPTED);
        }
        // 3. 重复绑定幂等返回；一个儿童最多 2 名在效监护人（PENDING 不占位）
        Optional<GuardianRelation> dup = guardianRepo
            .findVerifiedByKey(req.guardianKey(minorUserId));
        if (dup.isPresent()) return GuardianBindingResult.alreadyBound(dup.get());
        if (guardianRepo.countVerified(minorUserId) >= 2) {
            throw new BizException(ErrorCode.VERIFICATION_GUARDIAN_LIMIT_EXCEEDED);
        }

        GuardianRelation rel = GuardianRelation.builder()
            .minorUserId(minorUserId)
            .relationship(req.getRelationship())   // FATHER/MOTHER/LEGAL_GUARDIAN/OTHER
            .bindMethod(req.getBindingMethod())    // PHONE_SMS/ID_CARD_VERIFY/QR_SCAN
            .controlPermissions(JsonUtils.toJson(req.getControlPermissions()))
            .consentVersion(policyRepo.currentVersion("CHILD_PRIVACY"))
            .consentAt(Instant.now())
            .status("PENDING")
            .build();

        // 4. 按绑定方式分派核验
        switch (req.getBindingMethod()) {
            case PHONE_SMS -> {
                // 监护人手机短信验证码（短信服务场景码 GUARDIAN_BIND）
                smsService.verifySceneCode(req.getGuardianPhone(),
                    SceneCode.GUARDIAN_BIND, req.getSmsCode());
                rel.setGuardianPhone(maskPhone(req.getGuardianPhone()));
                verifyGuardianAdult(rel, req);
            }
            case ID_CARD_VERIFY -> verifyGuardianAdult(rel, req);
            case QR_SCAN -> {
                // 家长端扫码：转 PENDING，等家长 App 确认（家长门 §6.7 resumeContext）
                rel.setResumeContext(req.getResumeContext());
                guardianRepo.save(rel);
                notificationService.notifyGuardianConfirm(rel);
                return GuardianBindingResult.pendingQr(rel);  // 客户端轮询/WS 等待
            }
        }
        return activate(rel);
    }

    /** 监护人成年校验：核验必须通过且出生日期满 18 岁（防未成年人互绑绕过管控） */
    private void verifyGuardianAdult(GuardianRelation rel, GuardianBindingRequest req) {
        VendorVerifyResponse resp = vendorClient.verifyIdCardWithFailover(
            req.getGuardianName(), req.getGuardianIdNumber());
        if (!resp.isMatched()) {
            throw new BizException(ErrorCode.VERIFICATION_GUARDIAN_NOT_MATCHED);
        }
        LocalDate birth = IdCardUtils.parse(req.getGuardianIdNumber()).getBirthDate();
        if (ageService.calcExactAge(birth) < 18) {
            auditService.log(req.getMinorUserId(), AuditAction.BYPASS_ATTEMPT,
                Map.of("reason", "GUARDIAN_NOT_ADULT"));   // 审计留痕 + 风控信号
            riskSignalService.report("GUARDIAN_NOT_ADULT", req.getMinorUserId());
            throw new BizException(ErrorCode.VERIFICATION_GUARDIAN_NOT_ADULT);
        }
        rel.setGuardianIdCardHash(DigestUtils.sha256Hex(req.getGuardianIdNumber()));
        rel.setGuardianNameMasked(IdCardUtils.maskName(req.getGuardianName()));
        guardianRepo.save(rel);
    }

    /** 激活：VERIFIED + 事件扇出 */
    private GuardianBindingResult activate(GuardianRelation rel) {
        rel.setStatus("VERIFIED");
        rel.setVerifiedAt(Instant.now());
        guardianRepo.save(rel);
        outboxService.append(rel.getMinorUserId(), OutboxEvents.guardianBound(rel));
        auditService.log(rel.getMinorUserId(), AuditAction.GUARDIAN_BOUND,
            Map.of("method", rel.getBindMethod(), "relation", rel.getRelationship()));
        return GuardianBindingResult.verified(rel);
    }
}
```

```java
/**
 * 供应商 SPI：新增供应商只需实现本接口并注册 Spring Bean

public interface VerificationVendorDriver {
    String code();                                            // aliyun / tencent / minsheng
    VendorVerifyResponse verifyPhone2Elements(String name, String phone);
    VendorVerifyResponse verifyIdCard2Elements(String name, String idNumber);
    LivenessResult detectLiveness(byte[] videoBlob);
    FaceCompareResult compareFace1To1(byte[] frame, String referenceHash);
}

@Component
public class VendorVerificationClient {

    @Autowired private Map<String, VerificationVendorDriver> driverMap;
    @Autowired private VerificationConfigRepository configRepo;

    /** 故障转移链：按 vendor_priority 配置依次尝试，单家熔断（CB_OPEN 直接跳过） */
    public VendorVerifyResponse verifyIdCardWithFailover(String name, String idNumber) {
        List<String> chain = configRepo.getJsonList("vendor_priority");
        VendorException last = null;
        for (String code : chain) {
            VerificationVendorDriver driver = driverMap.get(code);
            if (driver == null || CircuitBreaker.isOpen("vendor:" + code)) continue;
            try {
                VendorVerifyResponse resp = driver.verifyIdCard2Elements(name, idNumber);
                CircuitBreaker.recordSuccess("vendor:" + code);
                return resp;                     // 不一致也是有效响应，直接返回
            } catch (VendorException e) {
                CircuitBreaker.recordFailure("vendor:" + code);
                last = e;                        // 超时/5xx/限流 → 尝试下一家
            }
        }
        throw new VendorAllUnavailableException(chain, last);
    }

    /** 手机号二要素同理（略）；人脸/活体单供应商直连，失败直接抛出 */
}
```

**熔断与重试参数**（Resilience4j，配置中心热更新）：

| 参数 | 值 | 说明 |
|------|-----|------|
| 超时 | 3000ms | 单次供应商调用超时（实名核验属同步阻塞接口，超时必须短） |
| 熔断窗口 | 60s 内 20 次调用 | 失败率 >50% 触发 OPEN |
| 半开探测 | 每 30s 放行 3 次 | HALF_OPEN 渐进恢复 |
| 重试 | 0 次 | 超时/失败直接切换下一家，不做同家重试（用户在等） |

**供应商原始响应处理红线**：`vendor_raw_response` 字段以 KMS 信封加密（AES-256-GCM）存储，仅含错误排查必需字段（脱敏后），不含身份证号/姓名明文回显；保留 180 天后由清理任务物理删除（§12 C2）。

### 6.8 降级与补验服务

对齐 E2E §9.2：所有供应商不可用时，按 `verification_config.fallback_mode` 降级。

```java
@Service
public class VerificationFallbackService {

    @Transactional
    public VerificationResult downgradeIdCardVerification(
            UserVerification verification, IdCardVerificationRequest req, IdCardMeta meta) {
        String mode = configRepo.get("fallback_mode", "TRUST_WITH_MONITOR");

        switch (FallbackMode.valueOf(mode)) {
            case BLOCK -> {     // 监管收紧窗口期：直接拒绝
                verification.setStatus(VerificationStatus.FAILED.getCode());
                verification.setFailReason("VENDOR_UNAVAILABLE_BLOCKED");
                verificationRepo.save(verification);
                throw new BizException(ErrorCode.VERIFICATION_VENDOR_UNAVAILABLE);
            }
            case MANUAL_REVIEW -> {   // 直接转人工
                verification.setStatus(VerificationStatus.PENDING_REVIEW.getCode());
                verification.setPendingReview(true);
                verificationRepo.save(verification);
                reviewTaskService.createManualReview(verification, "VENDOR_UNAVAILABLE");
                return VerificationResult.pendingReview(verification);
            }
            case TRUST_WITH_MONITOR -> {   // 默认：本地校验放行 + 7 天内补验
                // 本地校验链：GB11643 校验位 + OCR 比对 + 出生日期推算（§6.3 已完成）
                AgeDeterminationResult ageResult = ageService.determine(
                    verification.getUserId(), meta.getBirthDate());
                verification.setStatus(VerificationStatus.PENDING_REVIEW.getCode());
                verification.setPendingReview(true);
                verification.setIsMinor(ageResult.getIsMinor());
                verification.setAgeGroup(ageResult.getAgeGroup());
                verification.setValidUntil(Instant.now().plus(Duration.ofDays(7))); // 7 天补验窗
                verificationRepo.save(verification);
                // 关键：降级期间未成年人保护照常生效（事件照发，宁严勿松）
                outboxService.append(verification.getUserId(),
                    OutboxEvents.completed(verification, ageResult, "ID_CARD", true));
                scheduleRetryJob(verification);   // 30 分钟后补验，指数退避最多 16 次
                return VerificationResult.pendingReview(verification);
            }
        }
        throw new IllegalStateException("unknown fallback_mode: " + mode);
    }

    /** 补验任务（对齐 E2E §9.3）：PENDING_REVIEW → 供应商恢复后正式复核 */
    @Scheduled(fixedDelay = 60_000)
    public void retryPendingReview() {
        for (UserVerification v : verificationRepo.findRetryable(50)) {
            try {
                VendorVerifyResponse resp = vendorClient.verifyIdCardWithFailover(
                    decrypt(v.getEncryptedName()), decrypt(v.getEncryptedIdNumber()));
                if (resp.isMatched()) {
                    v.setStatus(VerificationStatus.SUCCESS.getCode());
                    v.setPendingReview(false);
                    v.setValidUntil(ageService.calcValidity(ageService.current(v.getUserId())));
                    verificationRepo.save(v);
                    outboxService.append(v.getUserId(),
                        OutboxEvents.completed(v, ageService.current(v.getUserId()),
                            "ID_CARD", false));   // 复核通过：发正式事件覆盖降级事件
                } else {
                    // 补验不通过：撤销信任，通知重新认证
                    v.setStatus(VerificationStatus.FAILED.getCode());
                    v.setFailReason("THIRD_PARTY_REJECTED");
                    verificationRepo.save(v);
                    notificationService.notifyUser(v.getUserId(), "VERIFICATION_FAILED");
                    // 撤销期间产生的未成年人保护不回滚（保护只增不减）
                }
            } catch (VendorAllUnavailableException e) {
                rescheduleWithBackoff(v);   // 指数退避：30m/1h/2h/4h/... 上限 16 次后转人工
                if (v.getRetryCount() >= 16) {
                    v.setStatus(VerificationStatus.MANUAL_REVIEW_REQUIRED.getCode());
                    verificationRepo.save(v);
                    reviewTaskService.createManualReview(v, "RETRY_EXHAUSTED");
                }
            }
        }
    }
}
```

```java
public FeatureAccessResult checkFeatureAccess(Long userId, String featureCode) {
    VerificationSummary s = getVerificationStatus(userId);     // 带缓存
    FeatureRule rule = featureRules.get(featureCode);
    if (rule == null) return FeatureAccessResult.allow();      // 未注册 = 不门控

    // 1. 认证过期检查：过期后等同未认证（§8 生命周期）
    if (s.isExpired()) {
        return FeatureAccessResult.deny("VERIFICATION_EXPIRED", "REVERIFY");
    }
    // 2. 认证级别检查
    if (s.getCurrentLevel().ordinal() < rule.getMinLevel().ordinal()) {
        return FeatureAccessResult.deny("LEVEL_NOT_ENOUGH", rule.getUpgradeGuide());
    }
    // 3. 年龄段检查（含 -7d 降级期：AI_DIALOG 次数减半由额度服务读取 valid_until 计算）
    if (!rule.getAgeGroups().contains(s.getAgeGroup())) {
        return FeatureAccessResult.deny("AGE_NOT_ALLOWED", null);
    }
    // 4. 监护人约束（<14 儿童高敏功能强制绑定后才可用）
    if (Boolean.TRUE.equals(s.getIsChild()) && rule.isGuardianRequired()
            && !s.isGuardianBound()) {
        return FeatureAccessResult.deny("GUARDIAN_NOT_BOUND", "GUARDIAN_BINDING");
    }
    return FeatureAccessResult.allow();
}
```

### 6.10 认证状态查询与缓存

`getVerificationStatus` 为高频读接口（首页/网关门控/支付前置检查均调用），采用「Redis 聚合快照 + 事件失效」策略：

```java
public VerificationStatusDTO getVerificationStatus(Long userId) {
    String key = "verify:summary:" + userId;
    VerificationStatusDTO cached = (VerificationStatusDTO) redis.get(key);
    if (cached != null) return cached;

    VerificationStatusDTO dto = aggregate(userId);   // 三类认证最新成功记录 + guardian + 规则
    redis.setex(key, 300, dto);                      // 5 分钟快照
    return dto;
}

// 事件发布时同事务删除快照（最终一致窗口 <= 5 分钟，门控场景可接受；
// 支付等强一致场景走 forceRefresh=true 直查库）
public void evictSummary(Long userId) { redis.del("verify:summary:" + userId); }
```

### 7.3 Relay 与对账

- Relay 任务每 500ms 批量拉取 `status=PENDING AND next_retry_at <= now()` 的记录（批量 200），投递 MQ（Topic：`verification-event`），成功后 CAS 置 SENT；失败指数退避，重试 10 次后置 DEAD 并告警。
- 日终对账：`COUNT(status='SENT' AND sent_at > now()-1d)` 与 MQ 消费方 ACK 统计比对，差异 >0.1% 告警（沿用《服务端-统一数据对账》框架）。

```java
public RenewResult renew(RenewRequest req) {
    UserVerification existing = verificationRepo
        .findLatestSuccess(userId, VerificationType.ID_CARD)
        .orElseThrow(() -> new BizException(ErrorCode.VERIFICATION_NOT_VERIFIED));
    if (existing.getValidUntil().isAfter(Instant.now().plus(Duration.ofDays(30)))) {
        throw new BizException(ErrorCode.VERIFICATION_RENEW_TOO_EARLY);  // 未到 T-30d 不可续

    if ("SIMPLIFIED".equals(req.getRenewMethod()) && existing.getFacePhotoHash() != null) {
        // 简化续期：活体 + 与 face_photo_hash 1:1 比对（复用 §6.4）
        // 通过 → 身份信息未变，validUntil 顺延，renew_method=SIMPLIFIED
    } else {
        // 完整续期：走 §6.3 全流程（身份信息可能变更，需重新提交）
    }
    // 身份信息未变但已成年（跨 18 岁边界）→ 按 §6.5.1 重算分组后顺延 2 年
```

## 14. 验收场景

1. 成年用户注册后手机号二要素核验一致且运营商返回出生日期 → SUCCESS，is_minor=false，有效期 730 天，事件 completed(PHONE_ONLY) 被画像消费。
2. 运营商不返回出生日期 → SUCCESS 但 is_minor=null，next_step=ID_CARD_VERIFICATION，客户端进入身份证流程。
3. 身份证校验位错误 → 55509，不创建 VERIFYING 记录（审计 SUBMIT 失败）。
4. 同一身份证第二账号认证 → 55512；原账号人脸确认后解除占用（30 天限 1 次），新账号可绑定。
5. 13 岁身份证核验通过 → is_child=true，next_step=GUARDIAN_BINDING，未绑定前 SOCIAL_PEER 等 guardianRequired 功能被拒。
6. 监护人身份证核验发现 17 岁 → 55521 + BYPASS_ATTEMPT 审计 + 风控信号上报。
7. QR_SCAN 绑定 → PENDING 推送家长；家长 App 确认 → VERIFIED + guardian_bound 事件；家长中心创建绑定、学情报告开通家长视角。
8. 监护人主动解绑未带 grantToken → 家长门 110401 系列拦截；带有效凭证 → REVOKED + guardian_unbound，家长门凭证吊销广播。
9. 未成年人申请解绑 → 55524 转人工，人工审核通过前保护不解除。
10. 全部供应商宕机 + fallback=TRUST_WITH_MONITOR → PENDING_REVIEW 放行 7 天；补验通过后转 SUCCESS 并重发正式事件；补验拒绝则 FAILED 但防沉迷保护不回滚。
