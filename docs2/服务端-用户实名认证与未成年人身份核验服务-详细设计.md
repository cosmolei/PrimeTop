# 服务端 - 用户实名认证与未成年人身份核验服务 详细设计

## 1. 文档说明

### 1.1 文档目的

本文档对启硕 PrimeTop 的用户实名认证与未成年人身份核验服务进行详细设计，为开发人员提供可直接编码的实现方案。

### 1.2 背景

根据中国《未成年人保护法》《个人信息保护法》《关于防止未成年人沉迷网络游戏的通知》等法规要求，教育类 APP 必须对用户进行身份核验，识别未成年人身份并实施相应保护措施（防沉迷、时长限制、付费限制等）。本服务负责：

1. 用户实名认证（身份证信息核验）
2. 未成年人身份识别与年龄判定
3. 监护人关系核验
4. 认证状态管理与全生命周期追踪
5. 与防沉迷、家长中心、支付等模块的联动

### 1.3 设计原则

- **合规优先**：严格遵循国家实名认证与未成年人保护相关法规
- **隐私最小化**：仅采集必要身份信息，敏感数据加密存储
- **渐进式认证**：根据使用场景触发不同级别的认证要求
- **降级容灾**：第三方核验服务异常时提供降级方案
- **审计可追溯**：所有认证操作留存审计日志

## 3. 数据结构定义

### 3.1 用户认证记录表 `user_verification`

```sql
CREATE TABLE user_verification (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL,              -- 关联用户ID
    verification_type   VARCHAR(32) NOT NULL,         -- 认证类型：PHONE/ID_CARD/FACE
    status              VARCHAR(20) NOT NULL,         -- 状态：PENDING/SUBMITTED/VERIFYING/SUCCESS/FAILED/EXPIRED
    
    -- 手机号实名信息
    phone_number        VARCHAR(20),                  -- 脱敏存储：138****1234
    phone_carrier       VARCHAR(10),                  -- 运营商：CMCC/CUCC/CTCC
    phone_verified_at   TIMESTAMPTZ,                  -- 手机号验证时间
    
    -- 身份证实名信息
    id_card_hash        VARCHAR(128),                 -- 身份证号SHA-256哈希（不可逆）
    id_card_masked      VARCHAR(20),                  -- 脱敏展示：310***********1234
    id_card_name_hash   VARCHAR(128),                 -- 姓名SHA-256哈希
    id_card_name_masked VARCHAR(10),                  -- 姓*或**
    id_card_region      VARCHAR(10),                  -- 身份证归属地编码
    id_card_expiry      DATE,                         -- 证件有效期
    
    -- 人脸核验信息
    face_verified       BOOLEAN DEFAULT FALSE,         -- 是否通过人脸核验
    face_verified_at    TIMESTAMPTZ,
    face_score          DECIMAL(5,2),                  -- 人脸相似度评分
    
    -- 年龄与未成年人判定
    birth_date          DATE,                          -- 出生日期（仅存储年月日）
    age                 INT,                           -- 核验时年龄
    is_minor            BOOLEAN,                       -- 是否未成年人（<18周岁）
    minor_age_group     VARCHAR(10),                   -- 未成年分组：INFANT/CHILD/TEEN
    
    -- 第三方核验结果
    vendor_code         VARCHAR(20),                   -- 核验供应商编码
    vendor_request_id   VARCHAR(64),                   -- 供应商请求ID
    vendor_result_code  VARCHAR(20),                   -- 供应商返回码
    vendor_raw_response JSONB,                         -- 原始响应（加密存储）
    
    -- 认证元数据
    client_ip           VARCHAR(45),                   -- 请求IP
    device_fingerprint  VARCHAR(64),                   -- 设备指纹
    app_version         VARCHAR(20),                   -- APP版本
    submitted_at        TIMESTAMPTZ,                   -- 提交时间
    verified_at         TIMESTAMPTZ,                   -- 核验完成时间
    expired_at          TIMESTAMPTZ,                   -- 过期时间
    retry_count         INT DEFAULT 0,                 -- 重试次数
    fail_reason         VARCHAR(200),                  -- 失败原因
    
    -- 审计
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 索引
CREATE INDEX idx_verification_user_id ON user_verification(user_id);
CREATE INDEX idx_verification_status ON user_verification(status);
CREATE UNIQUE INDEX idx_verification_user_type ON user_verification(user_id, verification_type) 
    WHERE status IN ('SUCCESS', 'VERIFYING');
CREATE INDEX idx_verification_minor ON user_verification(is_minor) WHERE is_minor = TRUE;
CREATE INDEX idx_verification_created_at ON user_verification(created_at);
```

### 3.5 核心枚举定义

```java
// ===== 认证类型 =====
public enum VerificationType {
    PHONE("phone", "手机号实名"),
    ID_CARD("id_card", "身份证实名"),
    FACE("face", "人脸核验");
}

// ===== 认证状态 =====
public enum VerificationStatus {
    PENDING("pending", "待提交"),
    SUBMITTED("submitted", "已提交"),
    VERIFYING("verifying", "核验中"),
    SUCCESS("success", "核验通过"),
    FAILED("failed", "核验失败"),
    EXPIRED("expired", "已过期");
}

// ===== 未成年人年龄段 =====
public enum MinorAgeGroup {
    INFANT("infant", "婴幼儿", 0, 6),
    CHILD("child", "儿童", 6, 12),
    TEEN("teen", "青少年", 12, 18);
    
    private final String code;
    private final String label;
    private final int minAge;
    private final int maxAge;
    
    public static MinorAgeGroup fromAge(int age) {
        if (age < 6) return INFANT;
        if (age < 12) return CHILD;
        return TEEN;
    }
}

// ===== 监护人关系类型 =====
public enum GuardianType {
    PARENT("parent", "父母"),
    GRANDPARENT("grandparent", "祖父母/外祖父母"),
    OTHER("other", "其他法定监护人");
}

// ===== 降级模式 =====
public enum FallbackMode {
    TRUST_WITH_MONITOR,     // 信任放行，加强监控
    BLOCK,                  // 阻断使用
    MANUAL_REVIEW           // 转人工审核
}
```

## 4. API 接口设计

### 4.1 触发实名认证（手机号）

用户注册后或触发认证场景时调用。

```
POST /api/v1/verification/phone
Authorization: Bearer <token>
Content-Type: application/json
```

**请求体：**
```json
{
    "phone": "13800138000",
    "sms_code": "123456",
    "scene": "REGISTER"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | string | 是 | 手机号码 |
| sms_code | string | 是 | 短信验证码 |
| scene | string | 是 | 触发场景：REGISTER/FEATURE_ACCESS/PAYMENT/AUTO_CHECK |

**响应体（成功）：**
```json
{
    "code": 0,
    "data": {
        "verification_id": "vf_202606051234567890",
        "status": "SUCCESS",
        "is_minor": false,
        "age": 25,
        "minor_age_group": null,
        "next_step": null,
        "message": "实名认证通过"
    }
}
```

**响应体（未成年人）：**
```json
{
    "code": 0,
    "data": {
        "verification_id": "vf_202606051234567891",
        "status": "SUCCESS",
        "is_minor": true,
        "age": 14,
        "minor_age_group": "TEEN",
        "next_step": "ID_CARD_VERIFICATION",
        "message": "检测到未成年人身份，请完成身份证核验以获得监护人绑定引导"
    }
}
```

**错误码：**
| 错误码 | 说明 |
|--------|------|
| VERIFICATION_PHONE_INVALID | 手机号格式错误 |
| VERIFICATION_SMS_CODE_WRONG | 验证码错误 |
| VERIFICATION_SMS_EXPIRED | 验证码过期 |
| VERIFICATION_VENDOR_UNAVAILABLE | 第三方核验服务不可用 |
| VERIFICATION_RATE_LIMITED | 超过当日重试限制 |

### 4.2 身份证 OCR 识别 + 核验

```
POST /api/v1/verification/id-card
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

**请求参数：**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id_card_front | file | 是 | 身份证正面照片（<5MB） |
| id_card_back | file | 否 | 身份证背面照片（有效期核验） |
| name | string | 是 | 真实姓名 |
| id_number | string | 是 | 身份证号码 |
| ocr_result | json | 否 | 客户端 OCR 预识别结果（辅助校验） |

**响应体（成功）：**
```json
{
    "code": 0,
    "data": {
        "verification_id": "vf_20260605_id_12345",
        "status": "SUCCESS",
        "is_minor": true,
        "age": 14,
        "birth_date": "2012-03-15",
        "minor_age_group": "TEEN",

        "message": "身份证核验通过"
    }

```

**错误码：**
| 错误码 | 说明 |
|--------|------|
| VERIFICATION_ID_IMAGE_TOO_LARGE | 图片超过5MB |
| VERIFICATION_ID_IMAGE_UNREADABLE | 图片无法识别 |
| VERIFICATION_ID_NUMBER_INVALID | 身份证号校验位不通过 |
| VERIFICATION_ID_NAME_MISMATCH | 姓名与身份证不匹配 |

## 5. 状态流转设计

### 5.1 认证状态机

```
                    ┌──────────────────────────────┐
                    │                              │
                    ▼                              │
  ┌──────────┐  submit   ┌───────────┐  verify    │ ┌──────────┐
  │ PENDING  │──────────▶│ SUBMITTED │───────────▶│ │ VERIFYING│
  └──────────┘          └───────────┘             │ └──────────┘
       │                     │                     │      │
       │ cancel              │ cancel              │      │ success
       ▼                     ▼                     │      ▼
  ┌──────────┐          ┌───────────┐              │ ┌──────────┐
  │ EXPIRED  │          │ EXPIRED   │              │ │ SUCCESS  │
  └──────────┘          └───────────┘              │ └──────────┘
                                                   │      │
                                                   │      │ expire (缓存过期)
                                                   │      ▼
                                                   │ ┌──────────┐
                                                   └─│ EXPIRED  │
                                                     └──────────┘
       │                                         
       │ vendor_fail / data_invalid               
       ▼                                         
  ┌──────────┐   retry(< max)   ┌──────────┐     
  │ FAILED   │─────────────────▶│ PENDING  │     
  └──────────┘                  └──────────┘     
       │                                           
       │ retry(>= max)
```

public class PhoneVerificationServiceImpl {

    private static final String RATE_LIMIT_PREFIX = "verify:rate:";
    private static final String CACHE_PREFIX = "verify:cache:";
    
    /**
     * 手机号实名认证主流程
     */
    @Transactional
    public VerificationResult verifyByPhone(PhoneVerificationRequest request) {
        Long userId = SecurityContext.getCurrentUserId();
        
        // 1. 检查重试限制
        checkRateLimit(userId);
        
        // 2. 验证短信验证码
        validateSmsCode(request.getPhone(), request.getSmsCode());
        
        // 3. 检查缓存 - 近期内是否已核验过
        String cacheKey = CACHE_PREFIX + "phone:" + DigestUtils.sha256Hex(request.getPhone());
        VerificationResult cached = (VerificationResult) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            log.info("Phone verification cache hit, userId={}", userId);
            return cached;
        }
        
        // 4. 创建认证记录
        UserVerification verification = UserVerification.builder()
            .userId(userId)
            .verificationType(VerificationType.PHONE.getCode())
            .status(VerificationStatus.VERIFYING.getCode())
            .phoneNumber(maskPhone(request.getPhone()))
            .submittedAt(Instant.now())
            .clientIp(request.getClientIp())
            .deviceFingerprint(request.getDeviceFingerprint())
            .build();
        verificationRepo.save(verification);

        } catch (VendorException e) {
            return handleVendorFailure(verification, e);
        }
        
        // 6. 处理核验结果
