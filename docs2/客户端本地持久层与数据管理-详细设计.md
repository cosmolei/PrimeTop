# 客户端本地持久层与数据管理 - 详细设计

> 版本：v1.0 | 日期：2026-05-22 | 状态：初稿

## 1. 模块概述

### 1.1 定位

客户端本地持久层与数据管理（Client Persistence & Data Management）是 Flutter 客户端的基础设施层，负责定义本地数据存储方案、数据模型、数据访问接口、数据迁移策略、缓存管理和安全存储。本文档为客户端开发人员提供可直接编码落地的本地数据层设计。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 离线可用 | 核心学习数据本地持久化，弱网/断网时仍可浏览 |
| 快速启动 | 冷启动时本地数据立即可用，后台异步同步 |
| 数据安全 | 敏感信息加密存储，防止越权读取 |
| 平滑升级 | App 版本升级时数据库自动迁移，零数据丢失 |
| 统一访问 | Repository 模式封装存储细节，业务层无感知 |

### 1.3 技术选型

| 组件 | 选型 | 用途 |
|------|------|------|
| 结构化存储 | **Hive** (纯 Dart) | 题目、错题、学习记录等结构化离线数据 |
| 键值存储 | **SharedPreferences** | 用户偏好、功能开关、简单配置 |
| 加密存储 | **flutter_secure_storage** | Token、手机号等敏感信息 |
| 文件缓存 | **path_provider** + 自研 | 图片、音频等资源文件缓存 |
| 全文检索 | **Isar** (可选) | 本地错题/笔记搜索（MVP 阶段可暂不引入） |

### 1.4 存储分层架构

```
┌───────────────────────────────────────────────────┐
│                  业务层 (UI/ViewModel)              │
├───────────────────────────────────────────────────┤
│              Repository 层 (统一数据访问)            │
│  ┌─────────┐ ┌─────────┐ ┌──────────┐            │
│  │本地 Repo │ │远程 Repo│ │混合 Repo │            │
│  └────┬────┘ └────┬────┘ └─────┬────┘            │
├───────┼───────────┼────────────┼───────────────────┤
│       │     网络层(Dio)        │                   │
│       │                       │                   │
│  ┌────▼───────────────────────▼────────────────┐  │
│  │            本地持久层 (Persistence)            │  │
│  │  Hive Boxes | SharedPrefs | SecureStorage    │  │
│  │  File Cache | Migration Engine               │  │
│  └─────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────┘
```

## 3. Repository 模式设计

### 3.1 Repository 层次结构

```
┌─────────────────────────────────────────────────┐
│               业务层 (Riverpod Provider)          │
├─────────────────────────────────────────────────┤
│                Repository 接口层                  │
│  IProfileRepo  ILearningRepo  IMistakeRepo  ...  │
├─────────────────────────────────────────────────┤
│              Repository 实现层                    │
│  ┌──────────────────────────────────────────┐   │
│  │          MixedRepository (推荐)           │   │
│  │  1. 读取: 本地优先 → 网络回源             │   │
│  │  2. 写入: 本地立即写 → 队列异步同步       │   │
│  │  3. 冲突: 服务端优先 + 本地合并           │   │
│  └──────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────┐   │
│  │          LocalRepository                  │   │
│  │  纯本地读写（草稿、搜索历史等）           │   │
│  └──────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────┐   │
│  │          RemoteRepository                 │   │
│  │  纯网络读写（实时数据、AI调用等）         │   │
│  └──────────────────────────────────────────┘   │
├─────────────────────────────────────────────────┤
│              数据源层 (DataSource)                │
│  LocalDataSource (Hive) | RemoteDataSource (Dio) │
└─────────────────────────────────────────────────┘
```

### 3.2 基础 Repository 接口

```dart
// ============================================================
// lib/core/repository/base_repository.dart
// ============================================================

/// 基础 Repository 接口 - 所有 Repository 继承此类
abstract class BaseRepository<T, Id> {
  /// 根据 ID 获取单个实体（本地优先）
  Future<T?> getById(Id id);

  /// 获取列表（本地优先，可强制刷新）
  Future<List<T>> getAll({bool forceRefresh = false});

  /// 保存实体（本地立即写入，异步同步服务端）
  Future<T> save(T entity);

  /// 批量保存
  Future<List<T>> saveAll(List<T> entities);

  /// 删除实体
  Future<void> delete(Id id);

  /// 刷新本地数据（从服务端拉取）
  Future<void> refresh();

  /// 获取待同步操作数量
  int get pendingSyncCount;
}

/// 支持分页的 Repository
abstract class PagedRepository<T, Id> extends BaseRepository<T, Id> {
  /// 分页获取
  Future<PagedResult<T>> getPaged({
    int page = 1,
    int pageSize = 20,
    String? sortBy,
    bool ascending = true,
    Map<String, dynamic>? filters,
  });
}

/// 支持搜索的 Repository
abstract class SearchableRepository<T, Id> extends BaseRepository<T, Id> {
  /// 本地搜索
  Future<List<T>> search(String query, {int limit = 20});
}

/// 分页结果
class PagedResult<T> {
  final List<T> items;
  final int page;
  final int pageSize;
  final int total;
  final bool hasMore;

  PagedResult({
    required this.items,
    required this.page,
    required this.pageSize,
    required this.total,
  }) : hasMore = (page * pageSize) < total;
}
```

### 3.3 混合 Repository 实现模板

```dart
// ============================================================
// lib/core/repository/mixed_repository.dart
// ============================================================

/// 混合 Repository：本地优先 + 网络回源 + 离线队列
///
/// 核心策略：
/// - 读：先返回本地数据，同时发起网络请求刷新，通知UI更新
/// - 写：立即写入本地 Hive，将操作加入待同步队列
/// - 冲突：以服务端数据为准，合并本地未同步的变更
class MixedRepository<T extends HiveObject, Id> extends BaseRepository<T, Id> {
  final Box<T> _localBox;
  final RemoteDataSource<T, Id> _remoteDataSource;
  final SyncQueue _syncQueue;
  final CachePolicy _cachePolicy;
  final String _entityType;
  final T Function(Map<String, dynamic>) _fromJson;
  final Map<String, dynamic> Function(T) _toJson;
  final Id Function(T) _getId;

  MixedRepository({
    required Box<T> localBox,
    required RemoteDataSource<T, Id> remoteDataSource,
    required SyncQueue syncQueue,
    required CachePolicy cachePolicy,
    required String entityType,
    required T Function(Map<String, dynamic>) fromJson,
    required Map<String, dynamic> Function(T) toJson,
    required Id Function(T) getId,
  })  : _localBox = localBox,
        _remoteDataSource = remoteDataSource,
        _syncQueue = syncQueue,
        _cachePolicy = cachePolicy,
        _entityType = entityType,
        _fromJson = fromJson,
        _toJson = toJson,
        _getId = getId;

  @override
  Future<T?> getById(Id id) async {
    // 1. 检查本地缓存
    final local = _findLocal(id);
    if (local != null && !_cachePolicy.isExpired(_entityType, id)) {
      // 本地数据有效，先返回，后台静默刷新
      _silentRefreshSingle(id);
      return local;
    }

    // 2. 本地无数据或已过期，尝试网络获取
    try {
      final remote = await _remoteDataSource.getById(id);
      if (remote != null) {
        await _saveToLocal(remote);
        _cachePolicy.touch(_entityType, id);
      }
      return remote;
    } catch (e) {
      // 3. 网络失败，返回过期本地数据（降级）
      if (local != null) {
        _log.warn('Network failed, returning stale local data for $_entityType:$id');
        return local;
      }
      return null;
    }
  }

  @override
  Future<T> save(T entity) async {
    // 1. 立即写入本地
    final id = _getId(entity);
    await _localBox.put(id, entity);

    // 2. 加入待同步队列
    await _syncQueue.enqueue(
      entityType: _entityType,
      entityId: id.toString(),
      operationType: 'create',
      payload: _toJson(entity),
    );

    return entity;
  }

  @override
  Future<void> delete(Id id) async {
    // 1. 本地标记删除（延迟真正删除，等同步成功后清理）
    final local = _findLocal(id);
    if (local != null) {
      await _localBox.delete(id);
    }

    // 2. 加入删除操作队列
    await _syncQueue.enqueue(
      entityType: _entityType,
      entityId: id.toString(),
      operationType: 'delete',
      payload: {},
    );
  }

  // ---- 内部方法 ----

  T? _findLocal(Id id) {
    try {
      return _localBox.get(id);
    } catch (_) {
      return null;
    }
  }

  Future<void> _saveToLocal(T entity) async {
    final id = _getId(entity);
    await _localBox.put(id, entity);
  }

  /// 静默刷新单个实体（不阻塞UI）
  void _silentRefreshSingle(Id id) {
    _remoteDataSource.getById(id).then((remote) {
      if (remote != null) {
        _saveToLocal(remote);
        _cachePolicy.touch(_entityType, id);
      }
    }).catchError((_) {
      // 静默失败，不影响用户
    });
  }
}
```

## 5. 缓存策略与 TTL 管理

### 5.1 CachePolicy 定义

```dart
// ============================================================
// lib/core/storage/cache_policy.dart
// ============================================================

/// 缓存策略配置
class CachePolicy {
  /// 各实体的默认 TTL（秒）
  static const Map<String, int> _defaultTTL = {
    'user_profile':    86400,     // 24小时
    'student_profile': 0,         // 永久（手动刷新）
    'membership':      3600,      // 1小时（权益变化需及时感知）
    'textbooks':       604800,    // 7天
    'chapters':        604800,    // 7天
    'knowledge_points': 604800,   // 7天
    'questions':       259200,    // 3天
    'mistake_records': 0,         // 永久
    'ai_conversations': 0,        // 永久
    'study_plans':     0,         // 永久
    'favorites':       0,         // 永久
    'notes':           0,         // 永久
    'notifications':   604800,    // 7天
    'app_config':      3600,      // 1小时
    'feature_flags':   3600,      // 1小时
  };

  /// 最大缓存条目数
  static const Map<String, int> _maxEntries = {
    'questions':       2000,
    'chapters':        2000,
    'knowledge_points': 5000,
    'ai_conversations': 200,
    'notifications':   200,
    'search_history':  100,
  };

  final Box<CacheMetaBox> _metaBox;

  CachePolicy(this._metaBox);

  /// 检查缓存是否过期
  bool isExpired(String entityType, String entityId) {
    final key = '$entityType:$entityId';
    final meta = _metaBox.get(key);
    if (meta == null) return true;

    final ttl = _defaultTTL[entityType] ?? 0;
    if (ttl == 0) return false; // 永久缓存

    return DateTime.now().isAfter(meta.expireAt);
  }

  /// 更新缓存元数据
  void touch(String entityType, String entityId) {
    final key = '$entityType:$entityId';
    final ttl = _defaultTTL[entityType] ?? 0;
    final now = DateTime.now();

    _metaBox.put(key, CacheMetaBox()
      ..cacheKey = key
      ..entityType = entityType
      ..fetchedAt = now
      ..expireAt = ttl > 0 ? now.add(Duration(seconds: ttl)) : DateTime(2099)
      ..version = 1
      ..sizeBytes = 0
    );
  }

  /// 清理过期缓存
  Future<int> cleanExpired() async {
    final now = DateTime.now();
    int cleaned = 0;

    final toDelete = <String>[];
    for (final key in _metaBox.keys) {
      final meta = _metaBox.get(key);
      if (meta != null && now.isAfter(meta.expireAt)) {
        toDelete.add(key as String);
      }
    }

    for (final key in toDelete) {
      await _metaBox.delete(key);
      cleaned++;
    }

    return cleaned;
  }

  /// 超出容量时执行 LRU 淘汰
  Future<void> enforceCapacity(String entityType, Box<dynamic> dataBox) async {
    final max = _maxEntries[entityType];
    if (max == null) return;

    final current = dataBox.length;
    if (current <= max) return;

    // 按 fetchedAt 排序，淘汰最旧的 10%
    final entries = <MapEntry<dynamic, CacheMetaBox>>[];
    for (final key in _metaBox.keys) {
      final meta = _metaBox.get(key);
      if (meta != null && meta.entityType == entityType) {
        entries.add(MapEntry(key, meta));
      }
    }

    entries.sort((a, b) => a.value.fetchedAt.compareTo(b.value.fetchedAt));
    final toRemove = (current * 0.1).ceil();

    for (var i = 0; i < toRemove && i < entries.length; i++) {
      final entityKey = entries[i].key.toString().split(':')[1];
      await dataBox.delete(entityKey);
      await _metaBox.delete(entries[i].key);
    }
  }
}
```

```dart
// ============================================================
// lib/core/storage/cache_manager.dart
// ============================================================

class CacheManagerImpl implements CacheManager {
  final HiveManager _hiveManager;
  final CachePolicy _cachePolicy;

  CacheManagerImpl({
    required HiveManager hiveManager,
    required Connectivity connectivity,
  })  : _hiveManager = hiveManager,
        _cachePolicy = CachePolicy(hiveManager.cacheMetaBox);

  @override
  Future<T?> getOrFetch<T>(
    String entityType,
    String entityId,
    Future<T?> Function() fetchRemote,
  ) async {
    // 1. 检查本地缓存是否有效
    if (!_cachePolicy.isExpired(entityType, entityId)) {
      final local = _getFromLocalBox(entityType, entityId);
      if (local != null) return local as T;
    }

    // 2. 缓存失效或不存在，走网络
    try {
      final remote = await fetchRemote();
      if (remote != null) {
        await _saveToLocalBox(entityType, entityId, remote);
        _cachePolicy.touch(entityType, entityId);
      }
      return remote;
    } catch (e) {
      // 3. 网络失败，尝试返回过期缓存
      final stale = _getFromLocalBox(entityType, entityId);
      if (stale != null) return stale as T;
      rethrow;
    }
  }

  @override
  Future<void> invalidate(String entityType, [String? entityId]) async {
    if (entityId != null) {
      await _hiveManager.cacheMetaBox.delete('$entityType:$entityId');
    } else {
      // 清除该类型的所有缓存元数据
      final keysToRemove = <dynamic>[];
      for (final key in _hiveManager.cacheMetaBox.keys) {
        final meta = _hiveManager.cacheMetaBox.get(key);
        if (meta != null && meta.entityType == entityType) {
          keysToRemove.add(key);
        }
      }
      for (final key in keysToRemove) {
        await _hiveManager.cacheMetaBox.delete(key);
      }
    }
  }

  @override
  Future<void> invalidateAll() async {
    await _hiveManager.cacheMetaBox.clear();
  }

  @override
  Future<int> cleanExpired() => _cachePolicy.cleanExpired();

  dynamic _getFromLocalBox(String entityType, String entityId) {
    // 根据 entityType 路由到对应 Box
    switch (entityType) {
      case 'chapters':
        return _hiveManager.chaptersBox.get(entityId);
      case 'questions':
        return _hiveManager.questionsBox.get(entityId);
      case 'knowledge_points':
        return _hiveManager.knowledgePointsBox.get(entityId);
      default:
        return null;
    }
  }

  Future<void> _saveToLocalBox(String entityType, String entityId, dynamic data) async {
    switch (entityType) {
      case 'chapters':
        await _hiveManager.chaptersBox.put(entityId, data as ChapterBox);
        break;
      case 'questions':
        await _hiveManager.questionsBox.put(entityId, data as QuestionBox);
        break;
      case 'knowledge_points':
        await _hiveManager.knowledgePointsBox.put(entityId, data as KnowledgePointBox);
        break;
    }
    // 容量检查
    await _cachePolicy.enforceCapacity(entityType, _getBox(entityType));
  }

  Box _getBox(String entityType) {
    switch (entityType) {
      case 'chapters': return _hiveManager.chaptersBox;
      case 'questions': return _hiveManager.questionsBox;
      case 'knowledge_points': return _hiveManager.knowledgePointsBox;
      default: throw ArgumentError('Unknown entity type: $entityType');
    }
  }
}
```

```dart
class SecureStorageImpl implements SecureStorage {
  final FlutterSecureStorage _storage = const FlutterSecureStorage(
    aOptions: AndroidOptions(encryptedSharedPreferences: true),
    iOptions: IOSOptions(accessibility: KeychainAccessibility.first_unlock),
  );

  static const _keyAccessToken = 'auth_access_token';
  static const _keyRefreshToken = 'auth_refresh_token';
  static const _keyTokenExpireAt = 'auth_token_expire_at';
  static const _keyDeviceId = 'device_id';

  // --- 用户敏感信息 ---
  static const _keyPhone = 'user_phone';
  static const _keyEmail = 'user_email';

  @override
  Future<String?> getAccessToken() => _storage.read(key: _keyAccessToken);

  @override
  Future<void> setAccessToken(String token, DateTime expireAt) async {
    await _storage.write(key: _keyAccessToken, value: token);
    await _storage.write(key: _keyTokenExpireAt, value: expireAt.toIso8601String());
  }

  @override
  Future<String?> getRefreshToken() => _storage.read(key: _keyRefreshToken);

  @override
  Future<void> setRefreshToken(String token) =>
      _storage.write(key: _keyRefreshToken, value: token);

  @override
  Future<bool> isTokenValid() async {
    final expireStr = await _storage.read(key: _keyTokenExpireAt);
    if (expireStr == null) return false;
    final expireAt = DateTime.parse(expireStr);
    // 提前5分钟判定过期，避免边界问题
    return DateTime.now().isBefore(expireAt.subtract(const Duration(minutes: 5)));
  }

  @override
  Future<String> getOrCreateDeviceId() async {
    var deviceId = await _storage.read(key: _keyDeviceId);
    if (deviceId == null) {
      deviceId = const Uuid().v4();
      await _storage.write(key: _keyDeviceId, value: deviceId);
    }
    return deviceId;
  }

  @override
  Future<void> clearAll() => _storage.deleteAll();

  /// 安全存储手机号（已脱敏）
  @override
  Future<void> setPhone(String phone) =>
      _storage.write(key: _keyPhone, value: phone);

  @override
  Future<String?> getPhone() => _storage.read(key: _keyPhone);
}
```

```dart
abstract class DataMigration {
  /// 迁移版本号
  int get version;

  /// 迁移描述
  String get description;

  /// 执行迁移
  Future<void> migrate(HiveManager hiveManager);
}

class MigrationEngine {
  final HiveManager _hiveManager;
  final List<DataMigration> _migrations;

  MigrationEngine(this._hiveManager, this._migrations);

  Future<void> run() async {
    final configBox = _hiveManager.appConfigBox;
    final currentVersion = configBox.get('db_version', defaultValue: 0) as int;

    // 按 version 排序
    final sorted = _migrations.toList()
      ..sort((a, b) => a.version.compareTo(b.version));

    for (final migration in sorted) {
      if (migration.version > currentVersion) {
        try {
          await migration.migrate(_hiveManager);
          await configBox.put('db_version', migration.version);
        } catch (e, stack) {
          // 迁移失败：记录日志，不阻塞启动
          // 严重情况下应提示用户重新安装
          throw MigrationException(
            version: migration.version,
            error: e,
            stackTrace: stack,
          );
        }
      }
    }
  }
}

class MigrationException implements Exception {
  final int version;
  final Object error;
  final StackTrace stackTrace;

  MigrationException({
    required this.version,
    required this.error,
    required this.stackTrace,
  });

  @override
  String toString() => 'Migration failed at v$version: $error';
}
```

```dart
class SyncQueueImpl implements SyncQueue {
  final Box<PendingOpBox> _pendingBox;

  SyncQueueImpl(this._pendingBox);

  @override
  Future<void> enqueue({
    required String entityType,
    required String entityId,
    required String operationType,
    required Map<String, dynamic> payload,
  }) async {
    final op = PendingOpBox()
      ..operationId = const Uuid().v4()
      ..operationType = operationType
      ..entityType = entityType
      ..entityId = entityId
      ..payload = payload
      ..retryCount = 0
      ..createdAt = DateTime.now()
      ..lastAttemptAt = null
      ..error = null;

    await _pendingBox.put(op.operationId, op);
  }

  @override
  Future<List<PendingOpBox>> getPendingOps({int limit = 50}) async {
    final ops = _pendingBox.values.toList()
      ..sort((a, b) => a.createdAt.compareTo(b.createdAt));
    return ops.take(limit).toList();
  }

  @override
  Future<void> markSynced(String operationId) async {
    await _pendingBox.delete(operationId);
  }

  @override
  Future<void> markFailed(String operationId, String error) async {
    final op = _pendingBox.get(operationId);
    if (op != null) {
      op.retryCount++;
      op.lastAttemptAt = DateTime.now();
      op.error = error;
      await op.save();

      // 超过最大重试次数，标记为死信
      if (op.retryCount >= 10) {
        await _moveToDeadLetter(op);
      }
    }
  }

  @override
  int get pendingCount => _pendingBox.length;

  Future<void> _moveToDeadLetter(PendingOpBox op) async {
    // 将失败操作移到死信日志（可后续手动处理）
    await _pendingBox.delete(op.operationId);
    // 写入死信日志 Box 或上报服务端
  }
}
```

```dart
class FileCacheManager {
  final String _cacheDir;
  static const int _maxCacheSizeMB = 200; // 最大缓存 200MB
  static const int _cleanupThresholdMB = 160; // 超过 160MB 触发清理

  FileCacheManager() : _cacheDir = '' {
    _init();
  }

  Future<void> _init() async {
    final dir = await getTemporaryDirectory();
    // _cacheDir 将在 init 中设置
  }

  /// 初始化（在 HiveManager.init 之后调用）
  Future<String> get cacheDirectory async {
    final dir = await getTemporaryDirectory();
    return '${dir.path}/file_cache';
  }

  /// 下载并缓存文件
  Future<String> cacheFile(String url, {String? category}) async {
    final cacheDir = await cacheDirectory;
    final fileName = _generateFileName(url);
    final categoryDir = category != null ? '$cacheDir/$category' : cacheDir;
    final filePath = '$categoryDir/$fileName';

    // 检查是否已缓存
    final file = File(filePath);
    if (await file.exists()) {
      // 更新访问时间（LRU）
      await file.setLastAccessed(DateTime.now());
      return filePath;
    }

    // 下载文件
    final dir = Directory(categoryDir);
    if (!await dir.exists()) await dir.create(recursive: true);

    final response = await Dio().get<List<int>>(
      url,
      options: Options(responseType: ResponseType.bytes),
    );
    await file.writeAsBytes(response.data!);

    return filePath;
  }

  /// 获取缓存文件路径（不下载）
  Future<String?> getCachedFilePath(String url, {String? category}) async {
    final cacheDir = await cacheDirectory;
    final fileName = _generateFileName(url);
    final categoryDir = category != null ? '$cacheDir/$category' : cacheDir;
    final filePath = '$categoryDir/$fileName';

    final file = File(filePath);
    return await file.exists() ? filePath : null;
  }

  /// 清理缓存（LRU策略）
  Future<int> cleanCache() async {
    final cacheDir = await cacheDirectory;
    final dir = Directory(cacheDir);
    if (!await dir.exists()) return 0;

    // 计算当前缓存大小
    final totalSize = await _calculateDirectorySize(dir);
    final totalSizeMB = totalSize / (1024 * 1024);

    if (totalSizeMB < _cleanupThresholdMB) return 0;

    // 按最后访问时间排序文件
    final files = await dir.list(recursive: true).where((f) => f is File).toList();
    files.sort((a, b) =>
      File(a.path).lastAccessedSync().compareTo(File(b.path).lastAccessedSync()));

    // 清理最旧的文件，直到低于阈值的70%
    final targetSize = (_maxCacheSizeMB * 0.7 * 1024 * 1024).toInt();
    var cleanedSize = 0;
    var cleanedCount = 0;

    for (final f in files) {
      if (totalSize - cleanedSize <= targetSize) break;
      final file = File(f.path);
      final size = await file.length();
      await file.delete();
      cleanedSize += size;
      cleanedCount++;
    }

    return cleanedCount;
  }

  /// 清除指定类别的缓存
  Future<void> clearCategory(String category) async {
    final cacheDir = await cacheDirectory;
    final dir = Directory('$cacheDir/$category');
    if (await dir.exists()) {
      await dir.delete(recursive: true);
    }
  }

  String _generateFileName(String url) {
    // 使用 URL 的哈希作为文件名，保留扩展名
    final hash = md5.convert(utf8.encode(url)).toString();
    final ext = path.extension(Uri.parse(url).path);
    return '$hash$ext';
  }

  Future<int> _calculateDirectorySize(Directory dir) async {
    var size = 0;
    await for (final entity in dir.list(recursive: true)) {
      if (entity is File) {
        size += await entity.length();
      }
    }
    return size;
  }
}
```

```dart
      boxStats[entry.key] = BoxStats(
        name: entry.key,
        entryCount: box.length,
        isLazy: box is LazyBox,
      );
    }

    return StorageStats(
      boxStats: boxStats,
      timestamp: DateTime.now(),
    );
  }

  /// 检查是否需要清理
  Future<bool> needsCleanup() async {
    final stats = await getStats();
    final totalEntries = stats.boxStats.values
        .fold<int>(0, (sum, s) => sum + s.entryCount);

    // 总条目超过 50000 触发清理
    return totalEntries > 50000;
  }

  /// 执行自动清理
  Future<CleanupResult> autoCleanup() async {
    final result = CleanupResult();

    // 1. 清理过期缓存
    result.cacheCleaned = await CachePolicy(_hiveManager.cacheMetaBox).cleanExpired();

    // 2. 清理超过30天的AI对话
    final convBox = _hiveManager.aiConversationsBox;
    final cutoff = DateTime.now().subtract(const Duration(days: 30));
    int convCleaned = 0;
    for (final key in convBox.keys.toList()) {
      final conv = convBox.get(key);
      if (conv != null && conv.lastMessageAt.isBefore(cutoff) && !conv.isStarred) {
        await convBox.delete(key);
        convCleaned++;
      }
    }
    result.conversationsCleaned = convCleaned;

    // 3. 清理文件缓存
    result.fileCacheCleaned = await FileCacheManager().cleanCache();

    // 4. 压缩 Box
    await _hiveManager.compact();

    return result;
  }
}
```

```dart
class StorageLifecycleObserver extends WidgetsBindingObserver {
  final HiveManager _hiveManager;
  final SyncScheduler _syncScheduler;
  final StorageMonitor _storageMonitor;

  StorageLifecycleObserver({
    required HiveManager hiveManager,
    required SyncScheduler syncScheduler,
    required StorageMonitor storageMonitor,
  })  : _hiveManager = hiveManager,
        _syncScheduler = syncScheduler,
        _storageMonitor = storageMonitor;

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.resumed:
        _onAppResumed();
        break;
      case AppLifecycleState.paused:
        _onAppPaused();
        break;
      case AppLifecycleState.detached:
        _onAppDetached();
        break;
      default:
        break;
    }
  }

  Future<void> _onAppResumed() async {
    // 1. 启动同步调度器
    _syncScheduler.start();

    // 2. 检查是否需要清理
    if (await _storageMonitor.needsCleanup()) {
      await _storageMonitor.autoCleanup();
    }
  }

  Future<void> _onAppPaused() async {
    // 1. 停止同步调度器
    _syncScheduler.stop();

    // 2. 刷新所有脏数据到磁盘
    await _hiveManager.compact();
  }

  Future<void> _onAppDetached() async {
    // 1. 停止同步
    _syncScheduler.stop();

    // 2. 关闭所有 Hive Box
    await Hive.close();
  }
}
```

## 13. 错误处理

### 13.1 存储层异常定义

```dart
// ============================================================
// lib/core/storage/exceptions.dart
// ============================================================

/// 存储层基础异常
sealed class StorageException implements Exception {
  final String message;
  final String? boxName;
  final Object? cause;

  StorageException({required this.message, this.boxName, this.cause});
}

/// Box 打开失败
class BoxOpenException extends StorageException {
  BoxOpenException(String boxName, Object cause)
      : super(message: 'Failed to open box: $boxName', boxName: boxName, cause: cause);
}

/// 数据迁移失败
class MigrationException extends StorageException {
  final int version;

  MigrationException({required this.version, required Object error, required StackTrace stack})
      : super(message: 'Migration v$version failed', cause: error);
}

/// 缓存未命中
class CacheMissException extends StorageException {
  CacheMissException(String entityType, String entityId)
      : super(message: 'Cache miss: $entityType/$entityId');
}

/// 同步冲突
class SyncConflictException extends StorageException {
  final String entityId;
  final Map<String, dynamic> localData;
  final Map<String, dynamic> serverData;

  SyncConflictException({
    required this.entityId,
    required this.localData,
    required this.serverData,
  }) : super(message: 'Sync conflict for entity: $entityId');
}

/// 安全存储操作失败
class SecureStorageException extends StorageException {
  SecureStorageException(String operation, Object cause)
      : super(message: 'Secure storage $operation failed', cause: cause);
}

/// 容量超限
class StorageCapacityException extends StorageException {
  final int currentBytes;
  final int limitBytes;

  StorageCapacityException({required this.currentBytes, required this.limitBytes})
      : super(message: 'Storage capacity exceeded: $currentBytes/$limitBytes bytes');
}
```

### 13.2 降级策略

| 场景 | 降级行为 |
|------|----------|
| Box 打开失败 | 使用内存 Box 降级，记录错误日志，提示用户重启 |
| 迁移失败 | 跳过迁移继续启动，标记为待修复状态，下次重试 |
| 本地数据损坏 | 清除损坏 Box，从服务端重新拉取 |
| 磁盘空间不足 | 停止本地写入，清理缓存，提示用户 |
| SecureStorage 不可用 | 回退到 SharedPreferences（安全性降低） |
| 同步冲突 | 服务端优先，保留本地版本到冲突日志 |
| 网络不可用 | 纯本地模式，操作入队列，恢复后同步 |
