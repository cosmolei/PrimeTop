## 1. 模块概述

### 1.1 一句话定义

为每个学生构建一张**个性化的知识网络图**，追踪其认知结构随学习的动态演化，识别知识孤岛、认知断层和关键桥梁节点，为推荐引擎、学情报告和学习规划提供结构化的拓扑数据支撑。

### 1.2 设计动机

| 现有系统 | 局限性 | 本引擎解决的问题 |
|---------|--------|----------------|
| 知识追踪模型引擎 (KTE) | 输出每个知识点的标量掌握度 (0~1) | 缺少知识点之间的**联结强度**建模 |
| 知识图谱构建引擎 | 描述教材规范的知识点关系（静态） | 不反映学生个人对这些关系的**理解程度** |
| 学习路径效果分析 | 分析行为序列模式（学→练→复） | 未建模学习后形成的**认知拓扑结构** |
| 学情分析 | 展示学科掌握度、薄弱点列表 | 缺少知识点之间的**关联掌握**视角 |

**核心洞察**：两个学生数学平均掌握度都是 0.65，但 A 同学的知识点彼此连接紧密（能综合运用），B 同学的知识点形成孤岛（只会孤立解题），两人的学习需求完全不同。

### 1.3 与现有模块的边界

| 职责 | 归属 | 说明 |
|------|------|------|
| 知识点规范关系定义 | 知识点体系与教材映射引擎 | 教材规定的前置/关联/包含关系 |
| 掌握度标量计算 | 知识追踪模型引擎 (KTE) | P(mastery) ∈ [0,1] |
| 学生知识掌握度查询 | KTE / 多渠道学习数据融合 | 本引擎**消费**掌握度数据 |
| **学生个人知识联结建模** | **本引擎** | 学生对两个关联知识点的**综合掌握**程度 |
| **个人认知拓扑分析** | **本引擎** | 孤岛检测、连通性分析、桥梁节点识别 |
| **认知网络演化追踪** | **本引擎** | 时间序列上的网络变化趋势 |
| 知识图谱可视化(客户端) | 知识图谱浏览页面 + 本引擎提供数据 | 本引擎提供学生个人图谱数据 |

## 2. 核心概念与数据模型

### 2.1 核心概念定义

| 概念 | 定义 | 示例 |
|------|------|------|
| **标准知识边 (Standard Edge)** | 知识点体系中定义的关系 | "一次函数" → 前置 → "二次函数" |
| **认知联结 (Cognitive Link)** | 学生对两个关联知识点的综合掌握状态 | 学生对"方程概念"和"一元一次方程求解"的联结强度 = 0.82 |
| **联结强度 (Link Strength)** | 0~1 的连续值，反映学生能在两个知识点间建立认知关联的程度 | 0.9 表示能灵活在两个知识点间迁移 |
| **知识孤岛 (Knowledge Island)** | 学生已掌握但与其他掌握知识点缺乏强联结的知识点群 | 学生会解二次方程但不理解它与函数图象的关系 |
| **桥梁节点 (Bridge Node)** | 移除后会导致认知网络断裂的关键知识点 | "函数概念"连接着代数和几何两大块 |
| **认知连通度 (Cognitive Connectivity)** | 个人知识网络中最大连通子图占总节点数的比例 | 0.85 表示 85% 的已学知识点相互连通 |

### 2.2 联结强度计算模型

两个存在标准知识边的知识点 A、B，其联结强度 `LS(A,B)` 的计算：

```
LS(A,B) = w1 × min(M_A, M_B)          // 掌握度下限 (0.4)
        + w2 × joint_correct_rate      // 联合正确率 (0.3)
        + w3 × transition_smoothness   // 迁移平滑度 (0.2)
        + w4 × temporal_proximity      // 时间邻近度 (0.1)
```

其中：
- `M_A, M_B`：A、B 的掌握度（来自 KTE）
- `joint_correct_rate`：同时涉及 A 和 B 的题目的正确率
- `transition_smoothness`：从 A 到 B（或反向）学习/练习切换时的正确率变化平滑程度
- `temporal_proximity`：两个知识点最近学习时间的邻近程度（越近越可能形成联结）

## 4. 核心算法

### 4.1 联结强度增量更新算法

当收到 KTE 的掌握度更新事件时，增量更新相关联结：

```kotlin
/**
 * 联结强度增量更新器
 * 触发时机：KTE 掌握度更新事件 / 练习答题事件
 */
class LinkStrengthIncrementalUpdater(
    private val kteClient: KteClient,
    private val knowledgePointClient: KnowledgePointClient,
    private val linkRepo: CognitiveLinkRepository,
    private val answerRecordClient: AnswerRecordClient
) {

    companion object {
        const val W_MASTERY_MIN = 0.40      // 掌握度下限权重
        const val W_JOINT_CORRECT = 0.30    // 联合正确率权重
        const val W_TRANSITION = 0.20       // 迁移平滑度权重
        const val W_TEMPORAL = 0.10         // 时间邻近度权重

        const val LINK_THRESHOLD = 0.15     // 形成联结的最低强度
        const val STRONG_LINK_THRESHOLD = 0.70
        const val MEDIUM_LINK_THRESHOLD = 0.40
    }

    /**
     * 掌握度变更后，增量更新该知识点与其所有邻居的联结强度
     *
     * @param userId 学生ID
     * @param kpId 发生变更的知识点ID
     * @param newMastery 新掌握度
     * @param oldMastery 旧掌握度
     */
    suspend fun onMasteryChanged(
        userId: Long,
        kpId: String,
        newMastery: BigDecimal,
        oldMastery: BigDecimal
    ) {
        // Step 1: 获取该知识点的所有标准邻居
        val neighbors = knowledgePointClient.getRelatedKPs(kpId) // 返回 PREREQUISITE / RELATED / CONTAINS
        if (neighbors.isEmpty()) return

        // Step 2: 获取学生在这些邻居知识点上的掌握度
        val neighborMasteryMap = kteClient.batchGetMastery(
            userId, neighbors.map { it.kpId }
        )

        // Step 3: 获取联合题目正确率（涉及 kpId 和 neighbor 的题目）
        val jointStats = answerRecordClient.getJointAnswerStats(
            userId, kpId, neighbors.map { it.kpId }
        )

        // Step 4: 逐个更新联结
        val updates = mutableListOf<CognitiveLinkUpdate>()
        for (neighbor in neighbors) {
            val neighborMastery = neighborMasteryMap[neighbor.kpId] ?: continue
            if (neighborMastery < 0.05) continue // 邻居完全未接触，跳过

            val oldLink = linkRepo.findLink(userId, kpId, neighbor.kpId)
            val oldStrength = oldLink?.linkStrength ?: BigDecimal.ZERO

            val newStrength = calculateLinkStrength(
                masteryA = newMastery,
                masteryB = neighborMastery,
                jointCorrectRate = jointStats[neighbor.kpId]?.correctRate,
                jointCount = jointStats[neighbor.kpId]?.totalCount ?: 0,
                transitionData = getTransitionData(userId, kpId, neighbor.kpId),
                temporalHours = computeTemporalProximity(kpId, neighbor.kpId)
            )

            // 仅当变化量超过阈值时才写入
            if (kotlin.math.abs(newStrength - oldStrength).toDouble() > 0.03) {
                updates.add(CognitiveLinkUpdate(
                    userId = userId,
                    kpIdA = kpId,
                    kpIdB = neighbor.kpId,
                    edgeType = neighbor.edgeType,
                    oldStrength = oldStrength,
                    newStrength = newStrength,
                    jointCorrectRate = jointStats[neighbor.kpId]?.correctRate,
                    jointQuestionCount = jointStats[neighbor.kpId]?.totalCount ?: 0
                ))
            }
        }

        // Step 5: 批量写入
        if (updates.isNotEmpty()) {
            linkRepo.batchUpsert(updates)

            // Step 6: 发布联结变化事件
            for (update in updates) {
                eventPublisher.publishLinkChangeEvent(update)
            }
        }
    }

    /**
     * 计算两个知识点之间的联结强度
     */
    fun calculateLinkStrength(
        masteryA: BigDecimal,
        masteryB: BigDecimal,
        jointCorrectRate: BigDecimal?,
        jointCount: Int,
        transitionData: TransitionData?,
        temporalHours: BigDecimal
    ): BigDecimal {
        // 分量1: 掌握度下限 (木桶效应)
        val masteryMin = minOf(masteryA, masteryB)

        // 分量2: 联合正确率
        val jointScore = when {
            jointCount < 3 -> masteryMin * 0.8 // 数据不足时降级
            jointCorrectRate != null -> jointCorrectRate
            else -> masteryMin * 0.8
        }

        // 分量3: 迁移平滑度
        val transitionScore = transitionData?.smoothness
            ?: masteryMin.multiply(BigDecimal("0.85"))

        // 分量4: 时间邻近度
        val temporalScore = computeTemporalScore(temporalHours)

        // 加权合成
        val strength = masteryMin * W_MASTERY_MIN +
            jointScore * W_JOINT_CORRECT +
            transitionScore * W_TRANSITION +
            temporalScore * W_TEMPORAL

        return strength.setScale(3, RoundingMode.HALF_UP)
            .coerceIn(0.0.toBigDecimal(), 1.0.toBigDecimal())
    }

    private fun computeTemporalScore(hoursBetween: BigDecimal): BigDecimal {
        // 72小时内学过 → 1.0, 30天外 → 0.3, 线性插值
        return when {
            hoursBetween <= 72.toBigDecimal() -> 1.0.toBigDecimal()
            hoursBetween >= 720.toBigDecimal() -> 0.3.toBigDecimal()
            else -> {
                val ratio = (720.toBigDecimal() - hoursBetween) /
                    (720.toBigDecimal() - 72.toBigDecimal())
                (0.3.toBigDecimal() + ratio * 0.7.toBigDecimal())
            }
        }
    }
}
```

#### 4.2.1 连通分量检测（孤岛识别）

使用改进的 BFS 算法在学生个人知识网络上找连通分量：

```kotlin
/**
 * 连通分量检测器 — 识别知识孤岛
 * 
 * 算法：基于邻接表的 BFS，只遍历 link_strength >= LINK_THRESHOLD 的边
 * 时间复杂度：O(V + E)，V=节点数，E=边数
 */
class ConnectedComponentsDetector(
    private val nodeRepo: KnowledgeNodeRepository,
    private val linkRepo: CognitiveLinkRepository
) {

    data class Component(
        val islandId: String,
        val nodes: Set<String>,
        val size: Int,
        val avgMastery: BigDecimal,
        val isMainComponent: Boolean // 是否是最大连通分量
    )

    /**
     * 检测学生在指定学科的个人知识网络中的连通分量
     */
    suspend fun detect(
        userId: Long,
        subjectCode: String,
        linkThreshold: BigDecimal = BigDecimal("0.15")
    ): List<Component> {
        // Step 1: 加载节点（只选已接触的：mastery > 0.01）
        val nodes = nodeRepo.findByUserAndSubject(userId, subjectCode)
            .filter { it.masteryLevel > 0.01 }
        if (nodes.isEmpty()) return emptyList()

        // Step 2: 构建邻接表（只含 strength >= threshold 的边）
        val adjList = buildAdjacencyList(userId, nodes, linkThreshold)

        // Step 3: BFS 找连通分量
        val visited = mutableSetOf<String>()
        val components = mutableListOf<Component>()

        for (node in nodes) {
            if (node.kpId in visited) continue
            val component = bfs(adjList, node.kpId, visited)
            val avgMastery = component.mapNotNull { kpId ->
                nodes.find { it.kpId == kpId }?.masteryLevel
            }.fold(BigDecimal.ZERO) { acc, v -> acc + v } /
                component.size.toBigDecimal()

            components.add(Component(
                islandId = generateIslandId(userId, subjectCode, components.size),
                nodes = component,
                size = component.size,
                avgMastery = avgMastery,
                isMainComponent = false // 后续标记
            ))
        }

        // Step 4: 标记最大连通分量
        val maxSize = components.maxOf { it.size }
        return components.map { c ->
            c.copy(isMainComponent = c.size == maxSize)
        }.sortedByDescending { it.size }
    }

    private fun buildAdjacencyList(
        userId: Long,
        nodes: List<KnowledgeNode>,
        threshold: BigDecimal
    ): Map<String, MutableList<String>> {
        val nodeIds = nodes.map { it.kpId }.toSet()
        val links = linkRepo.findLinksAbove(userId, threshold)
        val adj = nodes.associate { it.kpId to mutableListOf<String>() }.toMutableMap()

        for (link in links) {
            if (link.kpIdA in nodeIds && link.kpIdB in nodeIds) {
                adj[link.kpIdA]?.add(link.kpIdB)
                adj[link.kpIdB]?.add(link.kpIdA) // 无向图处理
            }
        }
        return adj
    }

    private fun bfs(
        adjList: Map<String, MutableList<String>>,
        start: String,
        visited: MutableSet<String>
    ): Set<String> {
        val component = mutableSetOf<String>()
        val queue: ArrayDeque<String> = ArrayDeque()
        queue.add(start)
        visited.add(start)

        while (queue.isNotEmpty()) {
            val current = queue.removeFirst()
            component.add(current)
            for (neighbor in adjList[current] ?: emptyList()) {
                if (neighbor !in visited) {
                    visited.add(neighbor)
                    queue.add(neighbor)
                }
            }
        }
        return component
    }
}
```

#### 4.2.2 桥梁节点识别（Tarjan 桥算法）

```kotlin
/**
 * 桥梁节点识别器 — 找出认知网络中的关键中介知识点
 * 
 * 使用 betweenness centrality 近似算法
 * 对于小规模图（<500节点）使用精确算法
 * 对于大规模图使用 Brandes 算法的近似版本
 */
class BridgeNodeFinder {

    /**
     * 计算图中所有节点的中介中心性
     *
     * @param adjList 邻接表
     * @return Map<kpId, betweennessScore> 归一化到 [0,1]
     */
    fun computeBetweenness(adjList: Map<String, List<String>>): Map<String, Double> {
        val nodes = adjList.keys.toList()
        val n = nodes.size
        if (n <= 1) return nodes.associateWith { 0.0 }

        val betweenness = nodes.associateWith { 0.0 }.toMutableMap()

        // Brandes 算法
        for (source in nodes) {
            // S: 按到 source 的距离排序的节点栈
            val S = ArrayDeque<String>()
            // P[w]: 从 source 到 w 的最短路径上的前驱列表
            val P = nodes.associateWith { mutableListOf<String>() }
            // sigma[t]: 从 source 到 t 的最短路径数
            val sigma = nodes.associateWith { 0.0 }.toMutableMap()
            sigma[source] = 1.0
            // dist[t]: 从 source 到 t 的距离
            val dist = nodes.associateWith { -1 }.toMutableMap()
            dist[source] = 0

            // BFS
            val Q = ArrayDeque<String>()
            Q.add(source)
            while (Q.isNotEmpty()) {
                val v = Q.removeFirst()
                S.addFirst(v)
                for (w in adjList[v] ?: emptyList()) {
                    if (dist[w]!! < 0) {
                        Q.add(w)
                        dist[w] = dist[v]!! + 1
                    }
                    if (dist[w] == dist[v]!! + 1) {
                        sigma[w] = sigma[w]!! + sigma[v]!!
                        P[w]!!.add(v)
                    }
                }
            }

            // 累加依赖
            val delta = nodes.associateWith { 0.0 }.toMutableMap()
            while (S.isNotEmpty()) {
                val w = S.removeFirst()
                for (v in P[w]!!) {
                    delta[v] = delta[v]!! +
                        (sigma[v]!! / sigma[w]!!) * (1 + delta[w]!!)
                }
                if (w != source) {
                    betweenness[w] = betweenness[w]!! + delta[w]!!
                }
            }
        }

        // 归一化: 除以 ((n-1)(n-2)/2) 对于无向图
        val normFactor = (n - 1).toDouble() * (n - 2).toDouble() / 2.0
        return if (normFactor > 0) {
            betweenness.mapValues { it.value / normFactor }
        } else {
            betweenness
        }
    }

    /**
     * 识别桥梁节点
     * 桥梁 = 中介中心性 > 0.1 或 移除后增加孤岛数的节点
     */
    fun findBridges(
        adjList: Map<String, List<String>>,
        baseComponents: Int = 1
    ): Set<String> {
        val betweenness = computeBetweenness(adjList)
        val highBetweenness = betweenness.filter { it.value > 0.1 }.keys

        // 验证：逐个移除高中心性节点，看是否增加连通分量数
        val bridges = mutableSetOf<String>()
        for (node in highBetweenness) {
            val reducedAdj = adjList.mapValues { (_, neighbors) ->
                neighbors.filter { it != node }
            }.filterKeys { it != node }
            val componentCount = countComponents(reducedAdj)
            if (componentCount > baseComponents) {
                bridges.add(node)
            }
        }
        return bridges
    }

    private fun countComponents(adjList: Map<String, List<String>>): Int {
        val visited = mutableSetOf<String>()
        var count = 0
        for (node in adjList.keys) {
            if (node !in visited) {
                bfsMark(adjList, node, visited)
                count++
            }
        }
        return count
    }

    private fun bfsMark(
        adjList: Map<String, List<String>>,
        start: String,
        visited: MutableSet<String>
    ) {
        val queue = ArrayDeque<String>()
        queue.add(start)
        visited.add(start)
        while (queue.isNotEmpty()) {
            val current = queue.removeFirst()
            for (neighbor in adjList[current] ?: emptyList()) {
                if (neighbor !in visited) {
                    visited.add(neighbor)
                    queue.add(neighbor)
                }
            }
        }
    }
}
```

### 4.3 演化检测算法

```kotlin
/**
 * 演化事件检测器
 * 
 * 每次拓扑重算后，对比新旧状态，检测并记录演化事件
 */
class EvolutionDetector {

    /**
     * 对比前后拓扑快照，识别演化事件
     */
    fun detect(
        userId: Long,
        subjectCode: String,
        before: NetworkState,
        after: NetworkState
    ): List<EvolutionEvent> {
        val events = mutableListOf<EvolutionEvent>()

        // 1. 节点级变化
        val addedNodes = after.nodeIds - before.nodeIds
        val removedNodes = before.nodeIds - after.nodeIds

        for (kpId in addedNodes) {
            events.add(EvolutionEvent(
                userId = userId, subjectCode = subjectCode,
                eventType = EvolutionEventType.NODE_ADDED,
                kpId = kpId,
                newValue = after.nodeMastery[kpId]
            ))
        }

        // 2. 掌握度等级变化
        for (kpId in after.nodeIds.intersect(before.nodeIds)) {
            val beforeTier = before.nodeTier[kpId]
            val afterTier = after.nodeTier[kpId]
            if (beforeTier != afterTier) {
                val isUpgrade = tierRank(afterTier!!) > tierRank(beforeTier!!)
                events.add(EvolutionEvent(
                    userId = userId, subjectCode = subjectCode,
                    eventType = if (isUpgrade)
                        EvolutionEventType.NODE_MASTERY_CHANGED
                    else EvolutionEventType.NODE_DEGRADED,
                    kpId = kpId,
                    oldValue = before.nodeMastery[kpId],
                    newValue = after.nodeMastery[kpId]
                ))
            }
        }

        // 3. 联结级变化
        for ((pair, newStrength) in after.linkStrengths) {
            val oldStrength = before.linkStrengths[pair] ?: BigDecimal.ZERO
            val delta = newStrength - oldStrength

            if (oldStrength < LINK_THRESHOLD && newStrength >= LINK_THRESHOLD) {
                events.add(EvolutionEvent(
                    userId = userId, subjectCode = subjectCode,
                    eventType = EvolutionEventType.LINK_FORMED,
                    kpId = pair.first, kpId_b = pair.second,
                    oldValue = oldStrength, newValue = newStrength, delta = delta
                ))
            } else if (oldStrength >= STRONG_LINK_THRESHOLD &&
                       newStrength < STRONG_LINK_THRESHOLD) {
                events.add(EvolutionEvent(
                    userId = userId, subjectCode = subjectCode,
                    eventType = EvolutionEventType.LINK_WEAKENED,
                    kpId = pair.first, kpId_b = pair.second,
                    oldValue = oldStrength, newValue = newStrength, delta = delta
                ))
            }
        }

        // 4. 拓扑级变化
        if (after.islandCount > before.islandCount) {
            events.add(EvolutionEvent(
                userId = userId, subjectCode = subjectCode,
                eventType = EvolutionEventType.ISLAND_FORMED,
                newValue = after.islandCount.toBigDecimal(),
                oldValue = before.islandCount.toBigDecimal()
            ))
        } else if (after.islandCount < before.islandCount) {
            events.add(EvolutionEvent(
                userId = userId, subjectCode = subjectCode,
                eventType = EvolutionEventType.ISLAND_RESOLVED,
                newValue = after.islandCount.toBigDecimal(),
                oldValue = before.islandCount.toBigDecimal()
            ))
        }

        if (after.connectivity > before.connectivity + 0.05) {
            events.add(EvolutionEvent(
                userId = userId, subjectCode = subjectCode,
                eventType = EvolutionEventType.CONNECTIVITY_INCREASED,
                oldValue = before.connectivity, newValue = after.connectivity
            ))
        }

        // 5. 桥梁节点变化
        val newBridges = after.bridgeNodes - before.bridgeNodes
        val lostBridges = before.bridgeNodes - after.bridgeNodes
        for (kpId in newBridges) {
            events.add(EvolutionEvent(
                userId = userId, subjectCode = subjectCode,
                eventType = EvolutionEventType.BRIDGE_EMERGED,
                kpId = kpId
            ))
        }

        return events
    }

    private fun tierRank(tier: String): Int = when (tier) {
        "UNKNOWN" -> 0
        "WEAK" -> 1
        "BASIC" -> 2
        "PROFICIENT" -> 3
        "MASTERED" -> 4
        else -> 0
    }
}
```

## 7. 缓存策略

### 7.1 Redis 缓存设计

```
# 个人知识图谱完整数据 (JSON)
pkn:graph:{userId}:{subject}      → TTL 6h, 每日重算后刷新

# 网络指标摘要
pkn:metrics:{userId}:{subject}    → TTL 6h

# 孤岛诊断报告
pkn:islands:{userId}:{subject}    → TTL 12h

# 演化趋势 (30天)
pkn:trend:{userId}:{subject}:30d  → TTL 24h

# 桥梁节点推荐
pkn:bridges:{userId}:{subject}    → TTL 12h

# 用户活跃学科集合 (用于定时任务批量处理)
pkn:active_subjects:{userId}      → TTL 7d, 每次学习行为刷新
```

### 7.2 缓存失效策略

| 场景 | 策略 |
|------|------|
| 学生答题 → KTE 更新 | 延迟失效：标记 `pkn:graph:{userId}:{subject}` 为 stale，下次读取时如超过 30 分钟则触发增量更新 |
| 每日定时全量重算 | 直接覆盖写入，重置 TTL |
| 学生切换学科 | 立即加载目标学科数据到缓存 |
| 孤岛状态变更 | 失效 `pkn:islands:{userId}:{subject}` |

## 8. 错误处理与服务降级

### 8.1 异常码定义

| 错误码 | HTTP | 描述 | 处理建议 |
|--------|------|------|---------|
| 30010 | 500 | 图构建失败（数据不完整） | 返回上次缓存数据 |
| 30011 | 500 | 拓扑分析超时 | 降级为简化分析（仅连通分量，跳过中介中心性） |
| 30012 | 404 | 学生无学习数据 | 返回空图谱 + 引导首次学习 |
| 30013 | 503 | KTE 服务不可用 | 使用最近一次缓存的掌握度数据 |
| 30014 | 503 | 知识点体系服务不可用 | 使用本地缓存的标准关系数据 |

### 8.2 降级策略

```kotlin
class PKNServiceDegrade {

    /**
     * 图谱查询降级链
     */
    suspend fun getGraphWithFallback(userId: Long, subject: String): PKNGraph {
        // Level 1: 正常查询
        try {
            return pknRepo.queryGraph(userId, subject)
        } catch (e: Exception) {
            log.warn("图谱查询失败, 降级处理. userId={}, subject={}", userId, subject, e)
        }

        // Level 2: 从缓存读取
        cacheService.get<PKNGraph>("pkn:graph:$userId:$subject")?.let { return it }

        // Level 3: 简化模式 — 返回掌握度列表 + 标准知识边（无联结强度计算）
        val masteryList = kteClient.batchGetAllMastery(userId, subject)
        val standardEdges = knowledgePointClient.getAllEdges(subject)
        return PKNGraph.simplified(masteryList, standardEdges)

        // Level 4: 返回空图谱
        // → PKNGraph.empty()
    }

    /**
     * 拓扑分析降级
     */
    suspend fun analyzeTopologyWithFallback(
        adjList: Map<String, List<String>>
    ): TopologyResult {
        return try {
            // 完整分析：连通分量 + 中介中心性 + 聚类系数
            topologyAnalyzer.fullAnalysis(adjList)
        } catch (e: TimeoutException) {
            log.warn("拓扑分析超时, 降级为简化分析")
            // 简化分析：仅连通分量检测
            topologyAnalyzer.simpleAnalysis(adjList)
        }
    }
}
```

## 9. 性能考量

### 9.1 数据量与性能预估

| 指标 | 估算 | 说明 |
|------|------|------|
| 单学科知识点数 | 80-300 | 取决于学段和学科 |
| 单学生联结数 | 50-500 | 标准边的子集 |
| 单次增量更新延迟 | < 50ms | 单知识点变更影响 5-15 条边 |
| 每日全量重算/学生/学科 | < 200ms | Brandes 算法 O(VE)，V<300,E<500 |
| 每日全量重算/全量学生 | ~40min | 10万活跃学生 × 3学科，并行度=8 |

### 9.2 性能优化

1. **增量优先**：90%+ 场景走增量更新路径，避免全量重算
2. **图稀疏性利用**：学生个人图通常很稀疏（密度 < 0.1），算法可利用稀疏性优化
3. **并行批处理**：每日重算按学生分片并行处理
4. **惰性计算**：桥梁节点中心性计算仅在节点数 > 20 时执行
5. **Redis 预热**：每日重算完成后批量写入 Redis，避免查询时实时计算

## 12. 测试要点

### 12.1 算法正确性测试

| 测试场景 | 预期结果 |
|---------|---------|
| 两个无关联知识点 | 不生成认知联结 |
| 掌握度 = 0 | 该节点不进入网络 |
| 全部知识点掌握度 = 1.0 | 所有标准边成为强联结，连通度 = 1.0 |
| 线性知识链 A→B→C→D，仅 A-D 掌握 | 形成 A→B→C→D 链状孤岛 |
| 星形结构中心节点掌握度骤降 | 该节点被标记为需要关注的桥梁/瓶颈 |
| 新知识点首次学习 | 触发 NODE_ADDED 事件 |
| 桥梁节点被学习后掌握度提升 | 触发 BRIDGE_LOST + CONNECTIVITY_INCREASED |

### 12.2 性能测试

| 场景 | 目标 |
|------|------|
| 增量更新延迟 (P99) | < 100ms |
| 图谱查询延迟 (P95) | < 200ms (含缓存) |
| 每日全量重算 (10万学生) | < 60min |
| Brandes 算法 (300节点) | < 50ms |

### 12.3 边界条件测试

| 边界 | 处理 |
|------|------|
| 新注册学生（零学习数据） | 返回空图谱 |
| 仅学习了1个知识点 | 1节点0边图，无孤岛 |
| 所有知识点完全孤立 | 每个知识点都是独立孤岛 |
| 标准知识边数据缺失 | 跳过缺失边，日志告警 |
| KTE 掌握度服务超时 | 使用最近缓存值，标记降级 |
