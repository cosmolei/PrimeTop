# 学科工具与参考资料库 - 详细设计

> **版本**：v1.0 | **日期**：2026-06-18 | **模块归属**：服务端·内容域
> **优先级**：P1 | **关联模块**：客户端-学科工具箱与参考资料速查、教材内容数字化与结构化生产管线、资源包管理与离线内容分发

---

## 1. 文档概述

### 1.1 设计目的

本文档详细设计 **学科工具与参考资料库** 的服务端实现，为客户端提供学科工具（如计算器、单位转换器）和参考资料（如公式速查表、元素周期表）的数据存储、查询、版本管理和资源打包能力。本文档是客户端页面架构的配套服务端设计，共同构建完整的学科工具基础设施。

### 1.2 核心功能

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 工具分类管理 | 按学科、工具类型（工具/参考资料）分类 | P0 |
| 工具内容 CRUD | 工具基本信息、条目数据的增删改查 | P0 |
| 工具版本管理 | 工具内容版本记录、发布、回滚 | P0 |
| 教材版本映射 | 工具内容与教材版本的对齐关系 | P0 |
| 增量更新 | 计算工具版本差异，支持客户端增量拉取 | P0 |
| 资源包打包 | 将工具内容打包为离线资源包（JSON/SQLite） | P0 |
| 工具审核流程 | 新建/修改工具需通过运营审核 | P1 |
| 工具使用统计 | 工具调用次数、热门工具排行 | P2 |

### 1.3 关联文档

| 文档 | 关联点 |
|------|--------|
| 客户端-学科工具箱与参考资料速查页面架构与交互设计 | 客户端页面设计与交互流程 |
| 教材内容数字化与结构化生产管线-详细设计 | 工具内容与教材版本同步 |
| 资源包管理与离线内容分发服务-详细设计 | 资源包打包、版本校验、CDN 分发 |
| 数据字典与统一枚举体系 | 学科、年级、工具类型枚举 |

## 2. 数据结构设计

### 2.1 核心实体关系图

```
ToolCategory (工具分类)
    │ 1:N
    ├── Tool (工具)
    │       │ 1:N
    │       ├── ToolVersion (工具版本)
    │       │       │ 1:N
    │       │       ├── ToolItem (工具条目)
    │       │       │
    │       │       └── TextbookToolMapping (教材版本映射)
    │       │
    │       └── ToolUsageStats (工具使用统计)
    │
    └── ToolResourcePackage (工具资源包)
            │ 1:N
            └── ToolResourcePackageVersion (资源包版本)
```

### 2.2 数据库表结构

#### 2.2.1 工具分类表（`tool_category`）

```sql
CREATE TABLE tool_category (
    id BIGSERIAL PRIMARY KEY,
    code VARCHAR(50) NOT NULL UNIQUE COMMENT '分类代码，如 MATH_FORMULA',
    name VARCHAR(100) NOT NULL COMMENT '分类名称',
    subject_id VARCHAR(20) NOT NULL COMMENT '学科ID，参考数据字典',
    category_type VARCHAR(20) NOT NULL COMMENT '分类类型：TOOL（工具）/REFERENCE（参考资料）',
    icon_url VARCHAR(512) COMMENT '分类图标URL',
    description TEXT COMMENT '分类描述',
    sort_order INT NOT NULL DEFAULT 0 COMMENT '排序权重',
    is_active BOOLEAN NOT NULL DEFAULT TRUE COMMENT '是否启用',
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    created_by BIGINT COMMENT '创建人ID',
    updated_by BIGINT COMMENT '更新人ID',

    INDEX idx_subject_type (subject_id, category_type),
    INDEX idx_sort_order (sort_order DESC)
) COMMENT '工具分类表';
```

#### 2.2.2 工具表（`tool`）

```sql
CREATE TABLE tool (
    id BIGSERIAL PRIMARY KEY,
    category_id BIGINT NOT NULL COMMENT '所属分类ID',
    code VARCHAR(50) NOT NULL UNIQUE COMMENT '工具代码，如 MATH_FORMULA_ALGEBRA',
    name VARCHAR(100) NOT NULL COMMENT '工具名称',
    display_name VARCHAR(100) NOT NULL COMMENT '显示名称（支持多语言）',
    short_desc VARCHAR(200) COMMENT '简短描述',
    description TEXT COMMENT '详细描述',
    tool_type VARCHAR(20) NOT NULL COMMENT '工具类型：CALCULATOR（计算器）/REFERENCE_TABLE（参考表）/CONVERTER（转换器）',
    适用年级范围
    grade_range_start INT NOT NULL COMMENT '起始年级（1-12）',
    grade_range_end INT NOT NULL COMMENT '结束年级（1-12）',
    是否需要离线
    is_offline_required BOOLEAN NOT NULL DEFAULT TRUE COMMENT '是否需要离线支持',
    离线包大小
    offline_package_size_bytes BIGINT COMMENT '离线包大小（字节）',
    是否启用
    is_active BOOLEAN NOT NULL DEFAULT TRUE COMMENT '是否启用',
    审核状态
    approval_status VARCHAR(20) NOT NULL DEFAULT 'PENDING' COMMENT '审核状态：PENDING/APPROVED/REJECTED',
    审核人
    approved_by BIGINT COMMENT '审核人ID',
    审核时间
    approved_at TIMESTAMP COMMENT '审核时间',
    审核意见
    approval_remark TEXT COMMENT '审核意见',
    当前版本号
    current_version INT NOT NULL DEFAULT 1 COMMENT '当前版本号',
    创建时间
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    更新时间
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    创建人
    created_by BIGINT COMMENT '创建人ID',
    更新人
    updated_by BIGINT COMMENT '更新人ID',

    FOREIGN KEY (category_id) REFERENCES tool_category(id) ON DELETE CASCADE,
    INDEX idx_category (category_id),
    INDEX idx_type_grade (tool_type, grade_range_start, grade_range_end),
    INDEX idx_active (is_active),
    INDEX idx_approval_status (approval_status)
) COMMENT '工具表';
```

#### 2.2.3 工具版本表（`tool_version`）

```sql
CREATE TABLE tool_version (
    id BIGSERIAL PRIMARY KEY,
    tool_id BIGINT NOT NULL COMMENT '工具ID',
    version INT NOT NULL COMMENT '版本号',
    变更说明
    change_log TEXT COMMENT '变更说明',
    是否发布
    is_published BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否已发布',
    发布时间
    published_at TIMESTAMP COMMENT '发布时间',
    创建时间
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    创建人
    created_by BIGINT COMMENT '创建人ID',

    FOREIGN KEY (tool_id) REFERENCES tool(id) ON DELETE CASCADE,
    UNIQUE KEY uk_tool_version (tool_id, version),
    INDEX idx_published (is_published)
) COMMENT '工具版本表';
```

#### 2.2.4 工具条目表（`tool_item`）

```sql
CREATE TABLE tool_item (
    id BIGSERIAL PRIMARY KEY,
    tool_id BIGINT NOT NULL COMMENT '工具ID',
    version_id BIGINT NOT NULL COMMENT '版本ID',
    条目类型
    item_type VARCHAR(20) NOT NULL COMMENT '条目类型：FORMULA（公式）/CONSTANT（常数）/DEFINITION（定义）/EXAMPLE（例题）',
    条目标题
    title VARCHAR(200) COMMENT '条目标题',
    条目内容（富文本/JSON）
    content JSONB NOT NULL COMMENT '条目内容，JSON格式存储，如{"formula":"E=mc²","variables":[...]、"description":"..."}',
    条目标签
    tags TEXT[] COMMENT '标签数组，如["力学","能量"]',
    条目排序
    sort_order INT NOT NULL DEFAULT 0 COMMENT '排序权重',
    所属章节（可选）
    chapter_id VARCHAR(50) COMMENT '所属章节ID（可选，用于与教材章节对齐）',
    创建时间
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    创建人
    created_by BIGINT COMMENT '创建人ID',

    FOREIGN KEY (tool_id) REFERENCES tool(id) ON DELETE CASCADE,
    FOREIGN KEY (version_id) REFERENCES tool_version(id) ON DELETE CASCADE,
    INDEX idx_tool_version (tool_id, version_id),
    INDEX idx_chapter (chapter_id),
    INDEX idx_tags (tags USING GIN)
) COMMENT '工具条目表';
```

#### 2.2.5 教材版本映射表（`textbook_tool_mapping`）

```sql
CREATE TABLE textbook_tool_mapping (
    id BIGSERIAL PRIMARY KEY,
    tool_id BIGINT NOT NULL COMMENT '工具ID',
    tool_version INT NOT NULL COMMENT '工具版本号',
    textbook_id VARCHAR(50) NOT NULL COMMENT '教材ID，如 PEP_MATH_7',
    textbook_version VARCHAR(20) NOT NULL COMMENT '教材版本，如 2024',
    映射类型
    mapping_type VARCHAR(20) NOT NULL COMMENT '映射类型：FULL（全教材）/CHAPTER（章节）/TOPIC（知识点）',
    映射范围
    mapping_scope JSONB COMMENT '映射范围，如{"chapter_ids":["ch1","ch2"]}',
    是否推荐
    is_recommended BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否推荐',
    创建时间
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    创建人
    created_by BIGINT COMMENT '创建人ID',

    FOREIGN KEY (tool_id) REFERENCES tool(id) ON DELETE CASCADE,
    INDEX idx_tool (tool_id),
    INDEX idx_textbook (textbook_id, textbook_version),
    INDEX idx_recommended (is_recommended)
) COMMENT '教材版本映射表';
```

#### 2.2.6 工具资源包表（`tool_resource_package`）

```sql
CREATE TABLE tool_resource_package (
    id BIGSERIAL PRIMARY KEY,
    package_code VARCHAR(50) NOT NULL UNIQUE COMMENT '资源包代码，如 MATH_TOOLS_V1',
    package_name VARCHAR(100) NOT NULL COMMENT '资源包名称',

    文件大小
    file_size_bytes BIGINT COMMENT '文件大小（字节）',
    文件URL
    file_url VARCHAR(512) NOT NULL COMMENT '文件存储URL（CDN）',
    文件MD5
    file_md5 VARCHAR(32) NOT NULL COMMENT '文件MD5校验',
    压缩格式
    compression_format VARCHAR(20) DEFAULT 'GZIP' COMMENT '压缩格式：GZIP/ZSTD/NONE',
    是否启用
    is_active BOOLEAN NOT NULL DEFAULT TRUE COMMENT '是否启用',
    创建时间
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    创建人
    created_by BIGINT COMMENT '创建人ID',

    INDEX idx_code (package_code),
    INDEX idx_textbook (textbook_id),
    INDEX idx_active (is_active)
) COMMENT '工具资源包表';
```

#### 2.2.7 工具资源包版本表（`tool_resource_package_version`）

```sql
CREATE TABLE tool_resource_package_version (

    是否发布
    is_published BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否已发布',
    发布时间
    published_at TIMESTAMP COMMENT '发布时间',

    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
```

#### 2.2.8 工具使用统计表（`tool_usage_stats`）

```sql
CREATE TABLE tool_usage_stats (
    id BIGSERIAL PRIMARY KEY,

    统计日期

    调用次数
    call_count INT NOT NULL DEFAULT 0 COMMENT '调用次数',

    avg_duration_seconds DECIMAL(10,2) COMMENT '平均使用时长（秒）',
```

### 2.3 Redis 缓存设计

| Key | 类型 | TTL | 说明 |
|-----|------|-----|------|
| `tool:category:list:{subject_id}:{type}` | List | 1h | 工具分类列表缓存 |
| `tool:list:{subject_id}:{grade}` | List | 30m | 工具列表缓存（按学科和年级） |
| `tool:detail:{tool_id}` | Hash | 1h | 工具详情缓存 |
| `tool:items:{tool_id}:{version}` | List | 1h | 工具条目列表缓存 |
| `tool:version:latest:{tool_id}` | String | 1h | 工具最新版本号 |
| `tool:package:info:{package_code}` | Hash | 24h | 资源包信息缓存 |

## 3. API 接口设计

### 3.1 工具分类查询接口

**接口**：`GET /api/v1/tool/categories`

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| subject_id | string | 否 | 学科ID，不传则返回全学科 |
| category_type | string | 否 | 分类类型：TOOL/REFERENCE，不传则返回全部 |
| is_active | boolean | 否 | 是否启用，默认 true |

**响应示例**：

```json

  "data": {

    ]
  }
}
```

### 4.3 增量更新计算逻辑

```java
/**
 * 计算工具版本差异（增量更新）
 */
@Service
public class ToolVersionDiffService {

    @Autowired
    private ToolItemMapper toolItemMapper;

    /**
     * 计算两个版本之间的差异
     */
    public VersionDiff calculateDiff(Long toolId, int fromVersion, int toVersion) {
        // 1. 获取两个版本的条目列表
        List<ToolItem> fromItems = toolItemMapper.selectByVersion(toolId, fromVersion);
        List<ToolItem> toItems = toolItemMapper.selectByVersion(toolId, toVersion);

        // 2. 按ID分组
        Map<Long, ToolItem> fromMap = fromItems.stream()
            .collect(Collectors.toMap(ToolItem::getId, Function.identity()));
        Map<Long, ToolItem> toMap = toItems.stream()
            .collect(Collectors.toMap(ToolItem::getId, Function.identity()));

        // 3. 计算差异
        VersionDiff diff = new VersionDiff();

        // 新增的条目
        toMap.keySet().stream()
            .filter(id -> !fromMap.containsKey(id))
            .forEach(id -> {
                diff.getAddedItems().add(toMap.get(id));
            });

        // 删除的条目
        fromMap.keySet().stream()
            .filter(id -> !toMap.containsKey(id))
            .forEach(id -> {
                diff.getRemovedItemIds().add(id);
            });

        // 修改的条目（通过内容哈希对比）
        fromMap.keySet().stream()
            .filter(toMap::containsKey)
            .forEach(id -> {
                ToolItem fromItem = fromMap.get(id);
                ToolItem toItem = toMap.get(id);
                if (!contentEquals(fromItem, toItem)) {
                    diff.getModifiedItems().add(toItem);
                }
            });

        return diff;
    }

    /**
     * 比较两个条目的内容是否相等
     */
    private boolean contentEquals(ToolItem item1, ToolItem item2) {
        return item1.getTitle().equals(item2.getTitle())
            && item1.getContent().equals(item2.getContent())
            && Objects.equals(item1.getTags(), item2.getTags());
    }
}
```

```java
/**
 * 工具资源包打包服务
 */
@Service
public class ToolResourcePackageService {

    @Autowired
    private ToolMapper toolMapper;
    @Autowired
    private ToolItemMapper toolItemMapper;
    @Autowired
    private ObjectStorageService objectStorageService;

    /**
     * 打包工具为JSON格式资源包
     */
    public PackageResult packageAsJson(Long packageId, int version) {
        // 1. 查询资源包配置
        ToolResourcePackage pkg = toolResourcePackageMapper.selectById(packageId);
        List<Long> toolIds = pkg.getToolIds();

        // 2. 查询工具及其最新版本条目
        Map<Long, List<ToolItem>> toolItemsMap = new HashMap<>();
        Map<Long, Integer> toolVersions = new HashMap<>();

        for (Long toolId : toolIds) {
            Tool tool = toolMapper.selectById(toolId);
            int latestVersion = tool.getCurrentVersion();

            List<ToolItem> items = toolItemMapper.selectByVersion(toolId, latestVersion);
            toolItemsMap.put(toolId, items);
            toolVersions.put(toolId, latestVersion);
        }

        // 3. 构建资源包JSON
        JsonObject packageJson = new JsonObject();
        packageJson.addProperty("package_code", pkg.getPackageCode());
        packageJson.addProperty("package_name", pkg.getPackageName());
        packageJson.addProperty("version", version);
        packageJson.addProperty("generated_at", Instant.now().toString());

        JsonArray toolsArray = new JsonArray();
        for (Long toolId : toolIds) {
            Tool tool = toolMapper.selectById(toolId);
            List<ToolItem> items = toolItemsMap.get(toolId);

            JsonObject toolJson = new JsonObject();
            toolJson.addProperty("tool_id", toolId);
            toolJson.addProperty("code", tool.getCode());
            toolJson.addProperty("name", tool.getName());
            toolJson.addProperty("display_name", tool.getDisplayName());
            toolJson.addProperty("tool_type", tool.getToolType());
            toolJson.addProperty("version", toolVersions.get(toolId));

            JsonArray itemsArray = new JsonArray();
            for (ToolItem item : items) {
                JsonObject itemJson = new JsonObject();
                itemJson.addProperty("id", item.getId());
                itemJson.addProperty("item_type", item.getItemType());
                itemJson.addProperty("title", item.getTitle());
                itemJson.add("content", JsonParser.parseString(item.getContent().toString()));
                itemJson.add("tags", new Gson().toJsonTree(item.getTags()));
                itemJson.addProperty("sort_order", item.getSortOrder());
                itemsArray.add(itemJson);
            }
            toolJson.add("items", itemsArray);

            toolsArray.add(toolJson);
        }
        packageJson.add("tools", toolsArray);

        // 4. 序列化为JSON并压缩
        String jsonStr = packageJson.toString();
        byte[] compressed = GzipUtils.compress(jsonStr);

        // 5. 上传到对象存储（CDN）
        String filename = String.format("%s_v%d.json.gz", pkg.getPackageCode(), version);
        String cdnUrl = objectStorageService.upload("tool-packages", filename, compressed);

        // 6. 计算MD5
        String md5 = DigestUtils.md5Hex(compressed);

        // 7. 保存版本记录
        ToolResourcePackageVersion pkgVersion = new ToolResourcePackageVersion();
        pkgVersion.setPackageId(packageId);
        pkgVersion.setVersion(version);
        pkgVersion.setToolVersions(JsonUtils.toJsonMap(toolVersions));
        pkgVersion.setFileUrl(cdnUrl);
        pkgVersion.setFileMd5(md5);
        pkgVersion.setIsPublished(true);
        pkgVersion.setPublishedAt(Instant.now());
        toolResourcePackageVersionMapper.insert(pkgVersion);

        return PackageResult.builder()
            .packageId(packageId)
            .version(version)
            .cdnUrl(cdnUrl)
            .fileSizeBytes(compressed.length)
            .md5(md5)
            .build();
    }
}
```

```java
            request.getSubjectId(),
            request.getGrade());

        // 尝试从缓存获取
        PageResult<Tool> cached = (PageResult<Tool>) redisTemplate.opsForValue().get(cacheKey);

        // 写入缓存（30分钟）
```

### 5.2 版本校验服务

```java
@Service
public class ToolVersionService {

    @Autowired
    private ToolMapper toolMapper;
    @Autowired
    private ToolVersionDiffService diffService;
    @Autowired
    private ToolIncrementalPackageService incrementalPackageService;

    /**
     * 校验工具版本
     */
    public VersionCheckResult checkVersion(Long toolId, int clientVersion) {
        Tool tool = toolMapper.selectById(toolId);
        int serverVersion = tool.getCurrentVersion();

        if (clientVersion == serverVersion) {
            return VersionCheckResult.noUpdate(toolId, clientVersion, serverVersion);
        }

        if (clientVersion < serverVersion) {
            // 需要更新
            VersionDiff diff = diffService.calculateDiff(toolId, clientVersion, serverVersion);

            // 判断更新类型
            UpdateType updateType = determineUpdateType(diff);

            // 生成增量包
            String incrementalUrl = null;
            String incrementalMd5 = null;
            if (updateType == UpdateType.INCREMENTAL) {
                IncrementalPackage pkg = incrementalPackageService.generate(toolId, clientVersion, serverVersion, diff);
                incrementalUrl = pkg.getCdnUrl();
                incrementalMd5 = pkg.getMd5();
            }

            return VersionCheckResult.hasUpdate(toolId, clientVersion, serverVersion, updateType, diff, incrementalUrl, incrementalMd5);
        } else {
            // 客户端版本比服务端新（异常情况）
            log.warn("客户端版本 {} 比服务端版本 {} 更新: toolId={}", clientVersion, serverVersion, toolId);
            return VersionCheckResult.noUpdate(toolId, clientVersion, serverVersion);
        }
    }

    /**
     * 判断更新类型
     */
    private UpdateType determineUpdateType(VersionDiff diff) {
        // 如果差异很小（<10%），则增量更新
        int totalChanges = diff.getAddedItems().size()
            + diff.getModifiedItems().size()
            + diff.getRemovedItemIds().size();

        // 假设总条目数不超过1000，差异<100则增量
        if (totalChanges < 100) {
            return UpdateType.INCREMENTAL;
        } else {
            return UpdateType.FULL;
        }
    }
}
```

## 7. 性能优化

### 7.1 缓存策略

1. **工具分类列表**：缓存1小时，按学科+类型缓存
2. **工具列表**：缓存30分钟，按学科+年级缓存
3. **工具详情**：缓存1小时，按工具ID缓存
4. **工具条目列表**：缓存1小时，按工具ID+版本号缓存

### 7.2 CDN 分发

1. **资源包文件**：上传到对象存储后，通过CDN分发
2. **增量包**：同样通过CDN分发，减少服务器带宽压力

### 7.3 分包策略

1. **按学科分包**：数学工具包、英语工具包等
2. **按年级分包**：小学工具包、初中工具包、高中工具包
3. **按教材版本分包**：人教版工具包、苏教版工具包等

### 7.4 数据库优化

1. **索引优化**：
   - `tool` 表：`(category_id)`, `(tool_type, grade_range_start, grade_range_end)`, `(is_active)`
   - `tool_item` 表：`(tool_id, version_id)`, `(chapter_id)`, `(tags GIN)`
2. **分页查询**：工具列表、工具条目列表均使用分页查询
3. **JSONB 查询**：工具内容使用 JSONB 存储，支持高效查询
