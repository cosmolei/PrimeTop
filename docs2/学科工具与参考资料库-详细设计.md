# 学科工具与参考资料库 - 详细设计

## 1. 模块概述

### 1.1 功能定位

为学生提供快速可用的学科工具箱和参考资料库，涵盖数学公式速查、物理常数表、化学元素周期表、单位换算器、计算器等常用学习工具。支持从首页、AI对话、解题过程等多处入口一键调用。

### 1.2 目标用户

| 学段 | 核心需求 |
|------|----------|
| 小学 | 单位换算、数学公式速查、常见字词表 |
| 初中 | 数理化公式、元素周期表、历史年表 |
| 高中 | 高考公式集、物理常数、化学方程式速查 |

### 1.3 设计原则

1. **秒级触达**：任意页面 2 次点击内进入所需工具
2. **离线可用**：核心工具数据内嵌客户端本地包
3. **学段适配**：根据用户年级自动过滤和排序工具内容
4. **可搜索**：支持拼音、名称、分类等多维度检索
5. **可收藏**：常用工具支持收藏和自定义排序

### 5.2 单位换算器

#### 5.2.1 界面

上方选择换算类别（长度/面积/体积/质量/温度/速度/时间/压强/能量/功率），中间两个输入框+下拉单位选择，实时双向换算。底部展示该类别的常用换算速查。

#### 5.2.2 换算引擎

```typescript
interface ConversionUnit {
  id: string;
  symbol: string;
  name: string;
  stageTags: string[];
  toBase: number | ((v: number) => number);
  fromBase?: number | ((v: number) => number);
}

class UnitConverter {
  static convert(value: number, from: ConversionUnit, to: ConversionUnit): number {
    // 源 → 基准
    const base = typeof from.toBase === 'function' 
      ? from.toBase(value) : value * from.toBase;
    // 基准 → 目标
    if (typeof to.fromBase === 'function') return to.fromBase(base);
    if (typeof to.fromBase === 'number') return base * to.fromBase;
    return base / (to.toBase as number);
  }
}

// 温度示例（非线性）
const tempUnits: ConversionUnit[] = [
  { id:'c', symbol:'°C', name:'摄氏度', stageTags:['junior','senior'], toBase: v=>v, fromBase: v=>v },
  { id:'f', symbol:'°F', name:'华氏度', stageTags:['junior','senior'], toBase: v=>(v-32)*5/9, fromBase: v=>v*9/5+32 },
  { id:'k', symbol:'K', name:'开尔文', stageTags:['senior'], toBase: v=>v-273.15, fromBase: v=>v+273.15 },
];
```

#### 5.4.2 实现方案

```typescript
import { evaluate } from 'mathjs';

function calculate(expression: string): string {
  try {
    const result = evaluate(expression);
    // 格式化：最多保留 10 位有效数字
    return typeof result === 'number' 
      ? parseFloat(result.toPrecision(10)).toString()
      : result.toString();
  } catch (e) {
    return 'ERROR';
  }
}
```

## 7. 客户端本地缓存策略

### 7.1 离线数据包

核心工具数据（公式、常数、元素周期表、换算单位）打包为 JSON 文件，随 APP 安装包发布：

| 数据包 | 大小估算 | 更新频率 |
|--------|----------|----------|
| 数学公式集 | ~200KB | 每学期随教材更新 |
| 物理公式集 | ~100KB | 每学期 |
| 元素周期表 | ~50KB | 极少更新 |
| 换算单位表 | ~20KB | 极少更新 |
| 计算器 | 0（代码内置） | 随 APP 更新 |
| 语文/英语参考表 | ~150KB | 每学期 |

### 7.2 缓存更新机制

```typescript
interface ToolDataPackage {
  packageName: string;     // 如 "math-formulas"
  version: number;         // 数据版本号
  url: string;             // CDN 下载地址
  checksum: string;        // MD5 校验
  size: number;            // 字节大小
  minAppVersion: string;   // 最低 APP 版本要求
}

// 启动时检查更新
async function checkToolDataUpdate(): Promise<void> {
  const localVersions = await getLocalPackageVersions();
  const remoteVersions = await fetch('/api/v1/tools/data-packages');
  
  for (const pkg of remoteVersions) {
    if (pkg.version > (localVersions[pkg.packageName] ?? 0)) {
      await downloadAndUpdate(pkg);
    }
  }
}
```

## 8. 错误处理

### 8.1 错误场景

| 场景 | 处理策略 |
|------|----------|
| 搜索无结果 | 提示"未找到相关工具"，推荐热门工具 |
| 工具详情加载失败 | 展示本地缓存数据，标记"可能非最新" |
| 收藏操作失败 | 本地先缓存操作，网络恢复后同步 |
| 公式渲染失败 | 降级显示 LaTeX 原始文本 |
| 换算溢出/NaN | 显示"数值超出范围"，建议换用科学记数法 |
| 离线访问 | 仅展示本地缓存数据，搜索走本地索引 |

### 8.2 错误码

| 错误码 | 含义 |
|--------|------|
| TOOL_001 | 工具不存在或已下架 |
| TOOL_002 | 分类不存在 |
| TOOL_003 | 搜索关键词过短（<2字符） |
| TOOL_004 | 收藏已达上限（100个） |
| TOOL_005 | 数据包下载校验失败 |

## 9. 与其他模块的集成

### 9.1 与 AI 对话引擎集成

AI 回答中引用公式或知识点时，自动识别并渲染为可交互卡片。点击卡片跳转工具详情页或弹出浮层。

**Prompt 编排侧**：AI 辅导场景的 System Prompt 中注入可用工具列表，让 AI 知道可以引用哪些工具内容。

### 9.2 与知识点体系集成

工具条目的 `relatedKnowledgePoints` 字段关联知识点 ID，用户在工具详情页可跳转到知识点讲解页；反向，知识点页面也可展示相关工具速查。

### 9.3 与首页学习工作台集成

首页"快捷操作区"展示用户最近使用和收藏的工具入口。根据当前学段和学科推荐相关工具。

### 9.4 与学情分析集成

工具使用记录汇入学情分析模块，作为学习行为的补充数据源（如：频繁查阅某学科公式 → 该学科薄弱信号）。
