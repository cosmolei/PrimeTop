# 学科工具与参考资料库 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

学科工具与参考资料库是 PrimeTop 平台面向学生和教师的跨学科辅助工具集与参考资料系统。它将各学科常用工具（公式手册、元素周期表、词典等）与参考资料（教材附录、拓展阅读、图表、推导过程、实验步骤）统一组织，提供快速检索、使用、收藏、笔记和智能推荐能力。该模块服务于“同步课堂”、“理科解题”、“文科背诵”、“作文辅导”等多个模块，提供可嵌入的工具组件和参考内容服务。

### 1.2 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 学科工具集 | 各学科常用工具（数学公式手册、化学元素周期表、物理常数表、英语不规则动词表、语文成语词典、历史时间轴等） | P1 |
| 参考资料库 | 教材附录、拓展阅读、学科图表、公式推导、实验步骤说明等参考资料 | P1 |
| 工具/资料检索 | 关键词搜索、标签筛选、学科过滤、类型过滤、热门推荐 | P1 |
| 工具/资料收藏与笔记 | 用户可收藏常用工具或资料，添加个人笔记、高亮标注 | P2 |
| 学科资料评分与推荐 | 用户可对资料进行评分，基于用户行为和评分进行个性化推荐 | P2 |
| 工具组件嵌入 | 将常用工具组件化，可嵌入到其他模块页面（如理科解题页嵌入公式手册） | P1 |
| 管理后台内容维护 | 支持后台进行工具/资料的增删改、审核、版本管理、标签管理 | P1 |
| 离线缓存 | 支持常用工具和参考资料本地缓存，离线可用 | P2 |

### 1.3 依赖关系

```
用户服务 ——> 学科工具与参考资料库（用户收藏、笔记、评分）
内容与运营后台 ——> 学科工具与参考资料库（工具/资料内容维护）
知识点体系与教材映射引擎 ——> 学科工具与参考资料库（知识点关联）
学情分析 ——> 学科工具与参考资料库（使用行为分析、推荐依据）
同步课堂学习 ——> 学科工具与参考资料库（教材附录、章节图表）
理科解题 ——> 学科工具与参考资料库（公式手册、物理常数表）
作文辅导 ——> 学科工具与参考资料库（成语词典、名言警句）
文科背诵 ——> 学科工具与参考资料库（历史时间轴、地理图表）
```

### 1.4 被依赖关系

| 消费方 | 使用方式 |
|--------|----------|
| 同步课堂学习 | 嵌入章节配套工具（如章节公式、词汇表） |

| 客户端学科工具箱页面 | 作为主页面，聚合所有工具与资料 |

## 2. 数据模型设计

### 2.1 工具/资料类型定义（枚举）

| 类型代码 | 名称 | 说明 |
|---------|------|------|
| `FORMULA_MANUAL` | 公式手册 | 数理化公式、定理、定律 |
| `CONSTANT_TABLE` | 常数表 | 物理常数、化学常数、数学常数 |
| `ELEMENT_PERIODIC` | 元素周期表 | 化学元素周期表及元素详情 |
| `IRREGULAR_VERB` | 不规则动词表 | 英语不规则动词变化表 |
| `IDIOM_DICTIONARY` | 成语词典 | 语文成语及释义 |
| `HISTORY_TIMELINE` | 历史时间轴 | 历史事件时间线 |
| `GEOGRAPHY_MAP` | 地理图表 | 地图、气候图、人口分布图等 |
| `APPENDIX` | 教材附录 | 教材配套附录内容 |
| `EXTENDED_READING` | 拓展阅读 | 课外拓展阅读材料 |
| `EXPERIMENT_GUIDE` | 实验步骤说明 | 理化生实验操作指南 |
| `DERIVATION` | 公式推导 | 数学公式、物理定律的推导过程 |
| `REFERENCE_CHART` | 参考图表 | 学科相关的图表、表格 |

### 2.2 学科工具/资料表（subject_tools）

```sql
CREATE TABLE subject_tools (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    type                VARCHAR(32)  NOT NULL COMMENT '类型，见枚举',
    subject_id          INT          NOT NULL COMMENT '学科ID',
    title               VARCHAR(128) NOT NULL COMMENT '标题',
    description         TEXT         NULL     COMMENT '描述',
    content             JSON         NOT NULL COMMENT '工具/资料内容，结构化存储',
    content_format      VARCHAR(16)  DEFAULT 'json' COMMENT '内容格式：json|html|markdown',
    tags                VARCHAR(255) NULL     COMMENT '逗号分隔的标签',
    difficulty_level    VARCHAR(16)  NULL     COMMENT '难度级别：easy|medium|hard',
    applicable_grades   VARCHAR(64)  NULL     COMMENT '适用年级范围，如 "1-6"',
    knowledge_point_ids JSON         NULL     COMMENT '关联的知识点ID列表',
    related_chapter_ids JSON         NULL     COMMENT '关联的章节ID列表',
    cover_image_url     VARCHAR(512) NULL     COMMENT '封面图URL',
    thumbnail_url       VARCHAR(512) NULL     COMMENT '缩略图URL',
    view_count          INT          DEFAULT 0 COMMENT '浏览次数',
    favorite_count      INT          DEFAULT 0 COMMENT '收藏次数',
    rating_avg          FLOAT        DEFAULT 0 COMMENT '平均评分 [0.0, 5.0]',
    rating_count        INT          DEFAULT 0 COMMENT '评分人数',
    status              VARCHAR(16)  DEFAULT 'draft' COMMENT '状态：draft|published|archived',
    is_offlineable      BOOLEAN      DEFAULT FALSE COMMENT '是否支持离线缓存',
    sort_order          INT          DEFAULT 0 COMMENT '排序，数字越小越靠前',
    created_at          DATETIME     DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    published_at        DATETIME     NULL     COMMENT '发布时间',
    published_by        BIGINT       NULL     COMMENT '发布人ID',

    INDEX idx_type_subject (type, subject_id, status),
    INDEX idx_tags (tags(64)),
    INDEX idx_view_count (view_count DESC),
    INDEX idx_rating_avg (rating_avg DESC),
    INDEX idx_created_at (created_at DESC),
    INDEX idx_knowledge_points (knowledge_point_ids(255)),
    INDEX idx_chapter_ids (related_chapter_ids(255))
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学科工具/资料表';
```

### 2.3 用户收藏表（user_tool_favorites）

```sql
CREATE TABLE user_tool_favorites (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id     BIGINT NOT NULL COMMENT '用户ID',
    tool_id     BIGINT NOT NULL COMMENT '工具/资料ID',
    note        TEXT   NULL COMMENT '用户备注',
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,

    UNIQUE KEY uk_user_tool (user_id, tool_id),
    INDEX idx_user_id (user_id),
    INDEX idx_tool_id (tool_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户工具/资料收藏表';
```

### 2.4 用户笔记表（user_tool_notes）

```sql
CREATE TABLE user_tool_notes (

    content     TEXT   NOT NULL COMMENT '笔记内容',

    INDEX idx_tool_id (tool_id),
    INDEX idx_created_at (created_at DESC)
```

### 2.5 用户评分表（user_tool_ratings）

```sql
CREATE TABLE user_tool_ratings (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id     BIGINT NOT NULL COMMENT '用户ID',
    tool_id     BIGINT NOT NULL COMMENT '工具/资料ID',
    rating      TINYINT NOT NULL CHECK (rating BETWEEN 1 AND 5) COMMENT '评分 [1-5]',
    comment     TEXT   NULL COMMENT '评价内容',

    updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_rating (rating)

```

### 2.6 工具/资料版本表（subject_tool_versions）

```sql
CREATE TABLE subject_tool_versions (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,

```

## 3. API 接口设计

### 3.1 获取工具/资料列表

```
GET /api/v1/subject-tools
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | 否 | 类型筛选 |
| `subject_id` | int | 否 | 学科筛选 |
| `keyword` | string | 否 | 关键词搜索（标题、描述、标签） |
| `difficulty_level` | string | 否 | 难度级别 |
| `grade` | string | 否 | 适用年级筛选 |
| `tags` | string | 否 | 标签筛选（逗号分隔） |
| `sort_by` | string | 否 | 排序字段：view_count|rating_avg|created_at |
| `sort_order` | string | 否 | 排序方向：asc|desc，默认 desc |

```python
class SubjectToolSearchService:
    """学科工具/资料搜索服务"""

    def __init__(self, es_client):
        self.es = es_client
        self.index_name = "subject_tools_index"

    async def search(
        self,
        keyword: str,
        subject_id: int = None,
        tool_type: str = None,
        page: int = 1,
        page_size: int = 20
    ) -> dict:
        """
        执行搜索
        """
        # 构建查询
        must = [
            {"term": {"status": "published"}}
        ]
        
        should = []
        
        # 关键词搜索
        if keyword:
            should.extend([
                {
                    "multi_match": {
                        "query": keyword,
                        "fields": ["title^3", "description^2", "content", "tags"],
                        "type": "best_fields",
                        "fuzziness": "AUTO"
                    }
                },
                {
                    "match_phrase": {
                        "title": keyword
                    }
                }
            ])
        
        # 学科筛选
        if subject_id:
            must.append({"term": {"subject_id": subject_id}})
        
        # 类型筛选
        if tool_type:
            must.append({"term": {"type": tool_type}})
        
        # 组合查询
        query = {
            "bool": {
                "must": must,
                "should": should,
                "minimum_should_match": 1 if should else 0
            }
        }
        
        # 排序
        sort = [{"_score": {"order": "desc"}}]
        
        # 执行查询
        from_pos = (page - 1) * page_size
        response = await self.es.search(
            index=self.index_name,
            body={
                "query": query,
                "from": from_pos,
                "size": page_size,
                "sort": sort
            }
        )
        
        # 解析结果
        hits = response["hits"]["hits"]
        total = response["hits"]["total"]["value"]
        
        items = []
        for hit in hits:
            source = hit["_source"]
            items.append({
                "id": source["id"],
                "type": source["type"],
                "subject_id": source["subject_id"],
                "title": source["title"],
                "description": source["description"],
                "thumbnail_url": source.get("thumbnail_url"),
                "tags": source.get("tags", []),
                "rating_avg": source.get("rating_avg", 0),
                "rating_count": source.get("rating_count", 0),
                "score": hit["_score"]
            })
        
        return {
            "total": total,
            "page": page,
            "page_size": page_size,
            "items": items
        }
```

### 4.2 个性化推荐逻辑

#### 4.2.1 推荐算法

基于用户行为数据进行协同过滤推荐：

```python
class SubjectToolRecommendationService:
    """学科工具/资料推荐服务"""

    def __init__(self, db_session, es_client, redis_client):
        self.db = db_session
        self.es = es_client
        self.redis = redis_client

    async def get_recommendations(
        self,
        user_id: int,
        subject_id: int = None,
        limit: int = 10
    ) -> list:
        """
        获取个性化推荐
        """
        # 1. 查询用户收藏的工具/资料
        favorite_tools = await self._get_user_favorites(user_id)
        if not favorite_tools:
            # 用户无收藏历史，返回热门推荐
            return await self._get_popular_recommendations(
                subject_id, limit
            )

        # 2. 提取用户偏好特征
        user_preferences = self._extract_preferences(favorite_tools)
        
        # 3. 基于协同过滤找相似用户
        similar_users = await self._find_similar_users(
            user_id, user_preferences
        )
        
        # 4. 获取相似用户喜欢但当前用户未收藏的工具/资料
        candidate_tools = await self._get_candidate_tools(
            user_id, similar_users, subject_id
        )
        
        # 5. 重新排序
        recommendations = self._rank_recommendations(
            candidate_tools, user_preferences
        )
        
        return recommendations[:limit]

    async def _get_user_favorites(self, user_id: int) -> list:
        """获取用户收藏的工具/资料"""
        query = """
            SELECT st.id, st.type, st.subject_id, st.tags, st.knowledge_point_ids
            FROM user_tool_favorites utf
            JOIN subject_tools st ON utf.tool_id = st.id
            WHERE utf.user_id = :user_id AND st.status = 'published'
        """
        results = await self.db.fetch_all(query, {"user_id": user_id})
        return results

    def _extract_preferences(self, favorites: list) -> dict:
        """提取用户偏好特征"""
        preferences = {
            "types": Counter(),
            "subjects": Counter(),
            "tags": Counter(),
            "knowledge_points": Counter()
        }
        
        for fav in favorites:
            preferences["types"][fav["type"]] += 1
            preferences["subjects"][fav["subject_id"]] += 1
            
            if fav["tags"]:
                for tag in fav["tags"].split(","):
                    preferences["tags"][tag.strip()] += 1
            
            if fav["knowledge_point_ids"]:
                for kp_id in fav["knowledge_point_ids"]:
                    preferences["knowledge_points"][kp_id] += 1
        
        return preferences

    async def _find_similar_users(
        self,
        user_id: int,
        preferences: dict
    ) -> list:
        """查找相似用户（基于收藏重合度）"""
        # 使用 Redis 存储用户相似度缓存
        cache_key = f"sim_users:{user_id}"
        cached = await self.redis.get(cache_key)
        if cached:
            return json.loads(cached)

        # 查询有共同收藏的用户
        query = """
            SELECT DISTINCT utf2.user_id
            FROM user_tool_favorites utf1
            JOIN user_tool_favorites utf2 ON utf1.tool_id = utf2.tool_id
            WHERE utf1.user_id = :user_id AND utf2.user_id != :user_id
            LIMIT 100
        """
        candidate_users = await self.db.fetch_all(
            query, {"user_id": user_id}
        )
        
        # 计算相似度（Jaccard 相似系数）
        similarities = []
        for cand in candidate_users:
            cand_user_id = cand["user_id"]
            overlap = await self._calculate_overlap(user_id, cand_user_id)
            if overlap > 0:
                similarities.append({
                    "user_id": cand_user_id,
                    "similarity": overlap
                })
        
        # 排序并取前 20 个
        similarities.sort(key=lambda x: x["similarity"], reverse=True)
        similar_users = similarities[:20]
        
        # 缓存 1 小时
        await self.redis.setex(
            cache_key, 3600, json.dumps(similar_users)
        )
        
        return similar_users

    async def _calculate_overlap(
        self,
        user_id_1: int,
        user_id_2: int
    ) -> float:
        """计算两个用户的收藏重合度"""
        query = """
            SELECT
                COUNT(DISTINCT CASE WHEN utf1.user_id = :uid1 THEN utf1.tool_id END) as count1,
                COUNT(DISTINCT CASE WHEN utf2.user_id = :uid2 THEN utf2.tool_id END) as count2,
                COUNT(DISTINCT CASE 
                    WHEN utf1.tool_id = utf2.tool_id 
                    THEN utf1.tool_id 
                END) as intersection
            FROM user_tool_favorites utf1
            JOIN user_tool_favorites utf2 ON utf1.tool_id = utf2.tool_id
            WHERE utf1.user_id IN (:uid1, :uid2) AND utf2.user_id IN (:uid1, :uid2)
        """
        result = await self.db.fetch_one(
            query, {"uid1": user_id_1, "uid2": user_id_2}
        )
        
        if result["intersection"] == 0:
            return 0.0
        
        jaccard = result["intersection"] / (
            result["count1"] + result["count2"] - result["intersection"]
        )
        
        return jaccard

    async def _get_candidate_tools(
        self,
        user_id: int,
        similar_users: list,
        subject_id: int = None
    ) -> list:
        """获取候选工具/资料"""
        user_favorites = await self._get_user_favorites(user_id)
        user_favorite_ids = {fav["id"] for fav in user_favorites}

        # 获取相似用户收藏但当前用户未收藏的工具/资料
        similar_user_ids = [su["user_id"] for su in similar_users]
        
        query = """
            SELECT DISTINCT st.id, st.type, st.subject_id, st.title,
                   st.description, st.tags, st.rating_avg, st.rating_count,
                   COUNT(utf.user_id) as recommend_count
            FROM user_tool_favorites utf
            JOIN subject_tools st ON utf.tool_id = st.id
            WHERE utf.user_id IN :similar_user_ids
              AND st.status = 'published'
              AND st.id NOT IN :user_favorite_ids
        """
        
        params = {
            "similar_user_ids": tuple(similar_user_ids),
            "user_favorite_ids": tuple(user_favorite_ids)
        }
        
        if subject_id:
            query += " AND st.subject_id = :subject_id"
            params["subject_id"] = subject_id
        
        query += " GROUP BY st.id ORDER BY recommend_count DESC LIMIT 50"
        
        candidates = await self.db.fetch_all(query, params)
        return candidates

    def _rank_recommendations(
        self,
        candidates: list,
        user_preferences: dict
    ) -> list:
        """重新排序推荐结果"""
        scored = []
        
        for cand in candidates:
            score = 0.0
            
            # 类型偏好匹配
            if cand["type"] in user_preferences["types"]:
                score += user_preferences["types"][cand["type"]] * 0.3
            
            # 学科偏好匹配
            if cand["subject_id"] in user_preferences["subjects"]:
                score += user_preferences["subjects"][cand["subject_id"]] * 0.2
            
            # 标签偏好匹配
            if cand["tags"]:
                for tag in cand["tags"].split(","):
                    tag = tag.strip()
                    if tag in user_preferences["tags"]:
                        score += user_preferences["tags"][tag] * 0.1
            
            # 评分加权
            if cand["rating_count"] > 0:
                score += cand["rating_avg"] * 0.3
            
            # 推荐人数加权
            score += min(cand["recommend_count"], 10) * 0.1
            
            scored.append({
                **cand,
                "score": score
            })
        
        # 按得分排序
        scored.sort(key=lambda x: x["score"], reverse=True)
        return scored

    async def _get_popular_recommendations(
        self,
        subject_id: int = None,
        limit: int = 10
    ) -> list:
        """获取热门推荐"""
        query = """
            SELECT st.id, st.type, st.subject_id, st.title,
                   st.description, st.thumbnail_url, st.rating_avg, st.rating_count,
                   st.view_count, '热门推荐' as reason
            FROM subject_tools st
            WHERE st.status = 'published'
        """
        
        params = {}
        if subject_id:
            query += " AND st.subject_id = :subject_id"
            params["subject_id"] = subject_id
        
        query += """
            ORDER BY (st.rating_avg * st.rating_count + st.view_count * 0.1) DESC
            LIMIT :limit
        """
        params["limit"] = limit
        
        results = await self.db.fetch_all(query, params)
        return results
```

```python
class SubjectToolRatingService:
    """学科工具/资料评分服务"""

    async def rate_tool(
        self,
        user_id: int,
        tool_id: int,
        rating: int,
        comment: str = None
    ) -> dict:
        """
        提交评分
        """
        # 检查工具/资料是否存在
        tool = await self._get_tool(tool_id)
        if not tool:
            raise ValueError("Tool not found")

        # 检查是否已评分
        existing = await self._get_user_rating(user_id, tool_id)
        if existing:
            # 更新评分
            await self._update_rating(
                user_id, tool_id, rating, comment
            )
        else:
            # 创建评分
            await self._create_rating(
                user_id, tool_id, rating, comment
            )

        # 重新计算平均评分
        await self._recalculate_rating(tool_id)

        return await self._get_user_rating(user_id, tool_id)

    async def _create_rating(
        self,
        user_id: int,
        tool_id: int,
        rating: int,
        comment: str = None
    ):
        """创建评分记录"""
        query = """
            INSERT INTO user_tool_ratings
            (user_id, tool_id, rating, comment)
            VALUES (:user_id, :tool_id, :rating, :comment)
        """
        await self.db.execute(
            query,
            {
                "user_id": user_id,
                "tool_id": tool_id,
                "rating": rating,
                "comment": comment
            }
        )

    async def _update_rating(
        self,
        user_id: int,
        tool_id: int,
        rating: int,
        comment: str = None
    ):
        """更新评分记录"""
        query = """
            UPDATE user_tool_ratings
            SET rating = :rating, comment = :comment, updated_at = NOW()
            WHERE user_id = :user_id AND tool_id = :tool_id
        """
        await self.db.execute(
            query,
            {
                "user_id": user_id,
                "tool_id": tool_id,
                "rating": rating,
                "comment": comment
            }
        )

    async def _recalculate_rating(self, tool_id: int):
        """重新计算平均评分"""
        query = """
            SELECT AVG(rating) as avg_rating, COUNT(*) as count
            FROM user_tool_ratings
            WHERE tool_id = :tool_id
        """
        result = await self.db.fetch_one(query, {"tool_id": tool_id})

        avg_rating = result["avg_rating"] or 0.0
        count = result["count"]

        # 更新工具/资料表
        update_query = """
            UPDATE subject_tools
            SET rating_avg = :avg_rating,
                rating_count = :count,
                updated_at = NOW()
            WHERE id = :tool_id
        """
        await self.db.execute(
            update_query,
            {
                "tool_id": tool_id,
                "avg_rating": avg_rating,
                "count": count
            }
        )

        # 同步到 Elasticsearch
        await self._sync_to_es(tool_id)
```

```python
class SubjectToolService:
    async def get_tool_detail(
        self,
        user_id: int,
        tool_id: int
    ) -> dict:
        try:
            # 查询工具/资料详情
            tool = await self._get_tool(tool_id)
            if not tool:
                raise ToolNotFoundError("Tool not found")

            # 检查状态
            if tool["status"] == "archived":
                raise ToolAccessDeniedError("Tool is archived")

            # 查询用户收藏、评分、笔记
            user_data = await self._get_user_data(user_id, tool_id)

            # 组装响应
            return {
                **tool,
                "user_favorite": user_data["favorite"],
                "user_rating": user_data["rating"],
                "user_notes": user_data["notes"],
            }

        except ToolNotFoundError as e:
            raise ToolServiceError(
                code="TOOL_001",
                message="工具/资料不存在",
            )
        except ToolAccessDeniedError as e:
            raise ToolServiceError(
                code="TOOL_007",
                message="该工具已归档，暂无权限访问",
            )
        except Exception as e:
            logger.error(f"Get tool detail failed: {e}", exc_info=True)
            raise ToolServiceError(
                code="TOOL_008",
                message="服务暂时不可用",
            )
```

## 7. 性能优化

### 7.1 缓存策略

| 数据类型 | 缓存位置 | 过期时间 | 更新策略 |
| -------- | -------- | -------- | -------- |
| 工具/资料详情 | Redis | 1小时 | 内容更新时失效 |
| 工具/资料列表（首页） | Redis | 10分钟 | 定时刷新 |
| 用户收藏列表 | Redis | 5分钟 | 收藏操作后刷新 |
| 热门推荐 | Redis | 30分钟 | 定时刷新 |
| 搜索结果 | Redis | 5分钟 | 缓存热门查询 |

### 7.2 数据库优化

1. **索引优化：**
   - 复合索引：`(type, subject_id, status)`
   - 标签索引：`tags(64)`
   - 排序索引：`view_count DESC`, `rating_avg DESC`

2. **分页优化：**
   - 使用 `LIMIT page_size OFFSET offset` 实现分页
   - 避免大偏移量查询，改用游标分页

3. **读写分离：**
   - 列表查询走从库
   - 写入操作（收藏、评分、笔记）走主库

### 7.3 Elasticsearch 优化

1. **索引优化：**
   - 使用 `ik_max_word` 分词器
   - 字段加权：`title^3`, `description^2`

2. **查询优化：**
   - 使用 `bool` 查询组合多个条件
   - 使用 `should` 查询提高召回率
   - 使用 `fuzziness` 支持模糊搜索

3. **缓存策略：**
   - 缓存热门查询结果
   - 定期清理冷数据

```dart
class IdiomDictionaryData {
  final List<IdiomItem> idioms;

  IdiomDictionaryData({required this.idioms});

  factory IdiomDictionaryData.fromJson(Map<String, dynamic> json) {
    return IdiomDictionaryData(
      idioms: (json['idioms'] as List)
          .map((e) => IdiomItem.fromJson(e))
          .toList(),
    );
  }
}

class IdiomItem {
  final String id;
  final String word;
  final String pinyin;
  final String meaning;
  final String? example;
  final List<String> synonyms;
  final List<String> antonyms;
  final String? source;

  IdiomItem({
    required this.id,
    required this.word,
    required this.pinyin,
    required this.meaning,
    this.example,
    required this.synonyms,
    required this.antonyms,
    this.source,
  });

  factory IdiomItem.fromJson(Map<String, dynamic> json) {
    return IdiomItem(
      id: json['id'],
      word: json['word'],
      pinyin: json['pinyin'],
      meaning: json['meaning'],
      example: json['example'],
      synonyms: json['synonyms'] != null
          ? List<String>.from(json['synonyms'])
          : [],
      antonyms: json['antonyms'] != null
          ? List<String>.from(json['antonyms'])
          : [],
      source: json['source'],
    );
  }
}
```
