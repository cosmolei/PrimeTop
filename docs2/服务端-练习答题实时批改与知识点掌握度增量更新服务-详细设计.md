# 服务端 - 练习答题实时批改与知识点掌握度增量更新服务

> 本文档详细设计练习/测评场景下，学生提交答案后的实时批改、评分、知识点掌握度增量更新及下游事件触发的完整链路。

## 1. 概述

### 1.1 背景

在 PrimeTop 的学习闭环中，练习答题是最核心的学习行为之一。当学生在同步练习、错题重做、考试模拟、专题训练等场景中提交答案后，系统需要：

1. **实时批改**：快速判断答案正误，给出得分
2. **知识点映射**：将题目关联到具体知识点，评估答题行为对知识掌握的影响
3. **掌握度增量更新**：基于答题结果动态调整各知识点的掌握度评分
4. **下游联动**：触发错题收录、推荐调整、学习记录写入、通知推送等一系列后续动作

与 AI 辅导对话场景不同，练习答题场景具有明确的正确答案、结构化的题型、可量化的评分标准，因此需要一套独立的批改与更新引擎。

### 1.2 适用场景

| 场景 | 来源 | 特点 |
|------|------|------|
| 同步课堂练习 | 按教材章节生成 | 题目固定，对应明确知识点 |
| 错题重做 | 错题本触发 | 历史错题再次作答，关注订正效果 |
| 考试模拟 | 组卷引擎生成 | 限时作答，整体评分 |
| 专题训练 | 考点/知识点筛选 | 同一专题多题，关注专题掌握度变化 |
| 智能推荐练习 | 自适应引擎推荐 | 单题推荐，即时反馈 |
| AI 生成同类题 | AI 对话中触发 | AI 生成的类似题，需要动态评分 |

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 批改响应延迟 | P95 < 200ms（客观题）、< 1s（AI 辅助主观题） |
| 掌握度更新一致性 | 最终一致，更新延迟 < 3s |
| 并发处理能力 | 支持单用户多题批量提交 + 全平台高并发 |
| 可扩展性 | 新增题型时只需实现评分策略接口 |
| 降级容错 | 批改失败不影响答题记录保存 |

## 2. 整体架构

### 2.1 系统上下文

```
                    ┌─────────────────────┐
                    │   客户端答题页面      │
                    └──────────┬──────────┘
                               │ 答案提交 (HTTP/gRPC)
                               ▼
                    ┌─────────────────────┐
                    │   练习服务 (Practice) │
                    │   - 接收答案提交       │
                    │   - 触发批改流程       │
                    └──────────┬──────────┘
                               │
                    ┌──────────▼──────────┐
                    │  批改引擎 (Grading)   │
                    │  - 题型路由           │
                    │  - 评分策略执行       │
                    │  - 生成批改结果       │
                    └──────────┬──────────┘
                               │ 批改结果
                    ┌──────────▼──────────┐
                    │ 掌握度引擎 (Mastery)  │
                    │  - 知识点映射         │
                    │  - 增量计算           │
                    │  - 持久化更新         │
                    └──────────┬──────────┘
                               │ 事件发布
                    ┌──────────▼──────────┐
                    │  下游事件处理器       │
                    │  - 错题收录           │
                    │  - 学习记录           │
                    │  - 推荐调整           │
                    │  - 数据统计           │
                    │  - 通知推送           │
                    └─────────────────────┘
```

### 2.2 模块职责

| 模块 | 职责 | 所属服务 |
|------|------|----------|
| **AnswerSubmitController** | 接收答案提交请求，参数校验 | Practice Service |
| **GradingEngine** | 根据题型路由到对应评分策略，执行批改 | Practice Service |
| **MasteryUpdateEngine** | 基于批改结果计算知识点掌握度变化量，执行更新 | Learning Service |
| **AnswerEventPublisher** | 将答题结果发布为领域事件 | Practice Service |
| **AnswerEventHandler** | 消费答题事件，触发下游操作 | 各相关服务 |

## 3. 数据结构定义

### 3.1 核心数据模型

#### 3.1.1 答题提交请求 (AnswerSubmitRequest)

```java
public class AnswerSubmitRequest {

    /** 练习会话 ID */
    @NotNull
    private String practiceSessionId;

    /** 题目 ID */

    private String questionId;

    /** 学生 ID */
    @NotNull
    private Long studentId;

    /** 答案内容 — 根据题型不同格式不同 */
    @NotNull
    private String answerContent;

    @NotNull
```

#### 3.1.4 批改方式 (GradingMethod)

```java
public enum GradingMethod {
    /** 精确匹配 — 选择题、判断题 */
    EXACT_MATCH,
    /** 模糊匹配 — 填空题（忽略空格、大小写等） */
    FUZZY_MATCH,
    /** 数学等价判定 — 数学表达式 */
    MATH_EQUIVALENCE,
    /** 数值精度匹配 — 数值计算题 */
    NUMERIC_TOLERANCE,
    /** AI 辅助批改 — 简答题、论述题 */

    KEYWORD_COVERAGE,

    MANUAL
}
```

### 5.1 答案提交流程

```
客户端提交答案
      │
```

```java
public class ExactMatchStrategy implements GradingStrategy {

    @Override
    public GradingResult grade(GradingContext ctx) {
        String studentAnswer = ctx.getAnswerContent().trim().toUpperCase();
        String correctAnswer = ctx.getQuestion().getCorrectAnswer().trim().toUpperCase();

            .score(score)
            .totalScore(ctx.getQuestion().getTotalScore())

            .correctAnswer(correctAnswer)
            .build();
    }
```

#### 5.3.2 填空题批改（模糊匹配）

```java
public class FuzzyMatchStrategy implements GradingStrategy {

    // 填空题可能有多空，逐空比较
    @Override
    public GradingResult grade(GradingContext ctx) {
        List<String> studentBlanks = parseBlanks(ctx.getAnswerContent());
        List<String> correctBlanks = parseBlanks(ctx.getQuestion().getCorrectAnswer());

        List<BlankResult> results = new ArrayList<>();
        BigDecimal scorePerBlank = ctx.getQuestion().getTotalScore()
            .divide(new BigDecimal(correctBlanks.size()), 2, RoundingMode.HALF_UP);

        for (int i = 0; i < correctBlanks.size(); i++) {
            String expected = i < correctBlanks.size() ? correctBlanks.get(i) : "";
            String actual = i < studentBlanks.size() ? studentBlanks.get(i) : "";
            boolean match = fuzzyEquals(actual, expected);
            results.add(new BlankResult(i, actual, expected, match,
                match ? scorePerBlank : BigDecimal.ZERO));
        }

        BigDecimal totalScore = results.stream()
            .map(BlankResult::getScore)
            .reduce(BigDecimal.ZERO, BigDecimal::add);

        boolean allCorrect = results.stream().allMatch(BlankResult::isCorrect);

        return GradingResult.builder()
            .correct(allCorrect)
            .score(totalScore)
            .totalScore(ctx.getQuestion().getTotalScore())
            .gradingMethod(GradingMethod.FUZZY_MATCH)
            .detail(new GradingDetail().setBlankResults(results))
            .build();
    }

    private boolean fuzzyEquals(String actual, String expected) {
        String a = normalize(actual);  // 去空格、统一标点、小写
        String e = normalize(expected);

        // 1. 精确匹配
        if (a.equals(e)) return true;

        // 2. 同义词/近义词匹配（查配置表）
        if (synonymMatch(a, e)) return true;

        // 3. 数值匹配（忽略前后文字描述）
        if (numericMatch(a, e)) return true;

        return false;
    }
}
```

```java
public class MathEquivalenceStrategy implements GradingStrategy {

    @Override
    public GradingResult grade(GradingContext ctx) {
        String studentExpr = ctx.getAnswerContent();
        String correctExpr = ctx.getQuestion().getCorrectAnswer();

        // 1. 字符串级别比较（快速路径）
        if (normalizeLatex(studentExpr).equals(normalizeLatex(correctExpr))) {
            return buildResult(true, ctx.getQuestion().getTotalScore());
        }

        // 2. 数学等价判定
        try {
            boolean equivalent = MathExpressionComparator.isEquivalent(
                studentExpr, correctExpr, ctx.getQuestion().getVariables()
            );
            return buildResult(equivalent,
                equivalent ? ctx.getQuestion().getTotalScore() : BigDecimal.ZERO);
        } catch (ExpressionParseException e) {
            // 解析失败 → 降级到 AI 辅助批改
            return delegateToAI(ctx);
        }
    }
}
```

## 6. 掌握度增量更新算法

### 6.1 算法概述

采用基于 **贝叶斯知识追踪 (BKT) 简化模型** + **衰减因子** 的混合算法。核心思路：

1. 正确作答 → 掌握度上升，上升幅度随已答次数递减（避免刷分）
2. 错误作答 → 掌握度下降，下降幅度与当前掌握度正相关（高掌握度下犯错影响更大）
3. 长时间未练习 → 掌握度自然衰减（遗忘曲线）
4. 连续正确 → 额外奖励（巩固效果）
5. 首次接触 → 初始分值设定

### 6.2 算法参数

```java
public class MasteryAlgorithmParams {

    /** 答对基础增量（随答题次数衰减） */
    public static final BigDecimal BASE_CORRECT_DELTA = new BigDecimal("8.0");

    /** 答错基础减量 */
    public static final BigDecimal BASE_WRONG_DELTA = new BigDecimal("5.0");

    /** 答对增量衰减系数（每次答对后增量乘以此系数） */
    public static final double CORRECT_DECAY_FACTOR = 0.85;

    /** 答对增量最小值 */
    public static final BigDecimal MIN_CORRECT_DELTA = new BigDecimal("1.0");

    /** 高掌握度犯错惩罚系数（掌握度越高，犯错扣分越多） */
    public static final double HIGH_MASTERY_PENALTY = 1.5;

    /** 连续正确奖励阈值 */
    public static final int CONSECUTIVE_CORRECT_THRESHOLD = 3;

    /** 连续正确奖励增量 */
    public static final BigDecimal CONSECUTIVE_BONUS = new BigDecimal("3.0");

    /** 掌握度上限 */
    public static final BigDecimal MASTERY_MAX = new BigDecimal("100.0");

    /** 掌握度下限 */
    public static final BigDecimal MASTERY_MIN = new BigDecimal("0.0");

    /** 遗忘衰减日阈值（超过此天数未练习开始衰减） */
    public static final int FORGET_THRESHOLD_DAYS = 7;

    /** 每日遗忘衰减率 */
    public static final double DAILY_DECAY_RATE = 0.5;

    /** 算法版本号 */
    public static final String ALGORITHM_VERSION = "v1";
}
```

### 6.3 增量计算核心逻辑

```java
public class MasteryIncrementCalculator {

    /**
     * 计算单次答题引起的掌握度变化量
     *
     * @param currentMastery 当前掌握度 (0-100)
     * @param isCorrect      本次是否正确
     * @param totalAttempts   该知识点累计答题次数
     * @param consecutiveCorrect 连续正确次数
     * @return 变化量（正数=上升，负数=下降）
     */
    public BigDecimal calculateDelta(MasteryCalcContext ctx) {
        // 先计算遗忘衰减
        BigDecimal decayDelta = calculateDecayDelta(ctx);

        if (ctx.isCorrect()) {
            return decayDelta.add(calculateCorrectDelta(ctx));
        } else {
            return decayDelta.add(calculateWrongDelta(ctx));
        }
    }

    /**
     * 答对增量计算
     */
    private BigDecimal calculateCorrectDelta(MasteryCalcContext ctx) {
        // 基础增量 × 衰减系数^已答次数
        double decayFactor = Math.pow(
            MasteryAlgorithmParams.CORRECT_DECAY_FACTOR,
            ctx.getTotalAttempts()
        );
        BigDecimal delta = MasteryAlgorithmParams.BASE_CORRECT_DELTA
            .multiply(new BigDecimal(decayFactor))
            .setScale(2, RoundingMode.HALF_UP);

        // 最小增量保障
        delta = delta.max(MasteryAlgorithmParams.MIN_CORRECT_DELTA);

        // 连续正确奖励
        if (ctx.getConsecutiveCorrect() >= MasteryAlgorithmParams.CONSECUTIVE_CORRECT_THRESHOLD) {
            delta = delta.add(MasteryAlgorithmParams.CONSECUTIVE_BONUS);
        }

        // 距满分越近增量越小（渐进曲线）
        BigDecimal roomToMax = MasteryAlgorithmParams.MASTERY_MAX.subtract(ctx.getCurrentMastery());
        if (roomToMax.compareTo(delta) < 0) {
            delta = roomToMax.max(BigDecimal.ZERO);
        }

        return delta;
    }

    /**
     * 答错减量计算
     */
    private BigDecimal calculateWrongDelta(MasteryCalcContext ctx) {
        BigDecimal delta = MasteryAlgorithmParams.BASE_WRONG_DELTA;

        // 高掌握度犯错惩罚
        if (ctx.getCurrentMastery().compareTo(new BigDecimal("60")) > 0) {
            // 掌握度每超 60 多 10 分，惩罚系数 +0.1
            double extraPenalty = (ctx.getCurrentMastery().doubleValue() - 60) / 100.0;
            delta = delta.multiply(new BigDecimal(1.0 + extraPenalty));
        }

        // 第二次及以上答错同一知识点，惩罚加重
        if (ctx.getTotalWrong() > 0) {
            delta = delta.multiply(new BigDecimal(1.0 + Math.min(ctx.getTotalWrong() * 0.1, 0.5)));
        }

        return delta.negate(); // 返回负数
    }

    /**
     * 遗忘衰减计算
     */
    private BigDecimal calculateDecayDelta(MasteryCalcContext ctx) {
        if (ctx.getDaysSinceLastPractice() <= MasteryAlgorithmParams.FORGET_THRESHOLD_DAYS) {
            return BigDecimal.ZERO;
        }

        long excessDays = ctx.getDaysSinceLastPractice() - MasteryAlgorithmParams.FORGET_THRESHOLD_DAYS;
        // 衰减量 = 掌握度 × 每日衰减率 × 超出天数
        // 但限制衰减不超过掌握度的 50%
        BigDecimal decayAmount = ctx.getCurrentMastery()
            .multiply(new BigDecimal(MasteryAlgorithmParams.DAILY_DECAY_RATE / 100.0))
            .multiply(new BigDecimal(excessDays));

        BigDecimal maxDecay = ctx.getCurrentMastery().multiply(new BigDecimal("0.5"));
        decayAmount = decayAmount.min(maxDecay);

        return decayAmount.negate();
    }
}
```

### 6.4 掌握度更新流程

```java
public class MasteryUpdateEngine {

    /**
     * 处理单次答题引起的掌握度更新
     */
    @Transactional
    public List<MasterySnapshot> updateAfterAnswer(
            Long studentId, GradingResult gradingResult, Question question) {

        // 获取题目关联的知识点列表（按权重排序）
        List<KnowledgePointWeight> kpWeights = question.getKnowledgePoints();
        if (kpWeights.isEmpty()) {
            return Collections.emptyList();
        }

        List<MasterySnapshot> updates = new ArrayList<>();

        for (KnowledgePointWeight kpw : kpWeights) {
            // 获取分布式锁，防止并发更新
            String lockKey = "mastery:lock:" + studentId + ":" + kpw.getKnowledgePointId();
            DistributedLock lock = lockManager.acquire(lockKey, 10, TimeUnit.SECONDS);
            try {
                // 读取当前掌握度（先从缓存，再从DB）
                KnowledgeMastery mastery = getOrInitMastery(studentId, kpw.getKnowledgePointId());

                // 计算变化量（按知识点权重缩放）
                MasteryCalcContext calcCtx = buildCalcContext(mastery, gradingResult);
                BigDecimal rawDelta = masteryCalculator.calculateDelta(calcCtx);

                // 按权重缩放：核心知识点权重高，影响大；边缘知识点影响小
                BigDecimal scaledDelta = rawDelta.multiply(kpw.getWeight());

                // 计算新值
                BigDecimal newValue = mastery.getMasteryValue().add(scaledDelta)
                    .max(MasteryAlgorithmParams.MASTERY_MIN)
                    .min(MasteryAlgorithmParams.MASTERY_MAX)
                    .setScale(2, RoundingMode.HALF_UP);

                // 更新掌握度记录
                mastery.setMasteryValue(newValue);
                mastery.setMasteryLevel(MasteryLevel.fromValue(newValue));
                if (gradingResult.getCorrect()) {
                    mastery.setTotalCorrect(mastery.getTotalCorrect() + 1);
                    mastery.setConsecutiveCorrect(mastery.getConsecutiveCorrect() + 1);
                } else {
                    mastery.setTotalWrong(mastery.getTotalWrong() + 1);
                    mastery.setConsecutiveCorrect(0);
                }
                updateRecentResults(mastery, gradingResult.getCorrect());
                mastery.setLastPracticeAt(LocalDateTime.now());
                mastery.setLastSourceType("PRACTICE");
                mastery.setLastSourceId(gradingResult.getGradingId());

                // 持久化
                masteryRepository.save(mastery);

                // 写更新日志
                masteryUpdateLogRepository.save(MasteryUpdateLog.builder()
                    .studentId(studentId)
                    .knowledgePointId(kpw.getKnowledgePointId())
                    .oldValue(mastery.getMasteryValue().subtract(scaledDelta))
                    .newValue(newValue)
                    .delta(scaledDelta)
                    .direction(scaledDelta.compareTo(BigDecimal.ZERO) > 0 ? "UP" :
                               scaledDelta.compareTo(BigDecimal.ZERO) < 0 ? "DOWN" : "UNCHANGED")
                    .sourceType("PRACTICE")
                    .sourceId(gradingResult.getGradingId())
                    .questionId(question.getQuestionId())
                    .isCorrect(gradingResult.getCorrect())
                    .algorithmVersion(MasteryAlgorithmParams.ALGORITHM_VERSION)
                    .build());

                // 更新缓存
                updateMasteryCache(studentId, kpw.getKnowledgePointId(), mastery);

                // 构建快照
                updates.add(buildSnapshot(mastery, scaledDelta));

            } finally {
                lockManager.release(lock);
            }
        }

        return updates;
    }
}
```

### 6.5 知识点权重说明

一道题目通常关联 1~3 个知识点，每个知识点有不同的权重：

```json
{
  "questionId": "q_math_001234",
  "knowledgePoints": [
    { "id": "kp_quadratic_equation", "name": "一元二次方程", "weight": 0.7 },
    { "id": "kp_factorization", "name": "因式分解", "weight": 0.3 }
  ]
}
```

- **weight 范围**: 0.0 ~ 1.0，同一道题所有权重之和 = 1.0
- **含义**: 核心知识点 weight 高，答对/答错对其掌握度影响大
- **配置方式**: 题目录入时由教研人员标注，或 AI 自动标注

```java
                    .errorCountIncrement(1)
                    .redoStatus(RedoStatus.NOT_REDONE)
                    .lastErrorAt(LocalDateTime.now())
                    .lastErrorType(event.getErrorTags())
                    .build()
            );
        } else {
            // 新增错题记录
            mistakeService.addToMistakeBook(
                MistakeRecord.builder()
                    .studentId(event.getStudentId())
                    .questionId(event.getQuestionId())
                    .source(event.getPracticeType())
                    .sourceSessionId(event.getPracticeSessionId())
                    .studentAnswer(/* 从答题记录获取 */)
                    .errorTags(event.getErrorTags())
                    .status(MistakeStatus.ACTIVE)
                    .build()
            );
        }
    }
}
```

## 8. 批量提交与考试模式特殊处理

### 8.1 批量提交策略

考试模式下，学生可能在考试结束后一次性提交所有答案。需要特殊处理：

```java
public class BatchAnswerSubmitService {

    public BatchGradingResult batchSubmit(BatchSubmitRequest request) {
        List<CompletableFuture<GradingResult>> futures = new ArrayList<>();

        // 并行批改（线程池控制并发度）
        for (AnswerSubmitRequest answer : request.getAnswers()) {
            futures.add(CompletableFuture.supplyAsync(
                () -> gradingEngine.grade(buildContext(answer)),
                gradingExecutor
            ));
        }

        // 等待所有批改完成（超时保护）
        List<GradingResult> results = futures.stream()
            .map(f -> f.exceptionally(this::handleGradingFailure)
                       .orTimeout(5, TimeUnit.SECONDS)
                       .join())
            .collect(Collectors.toList());

        // 批量更新掌握度（合并同一知识点的多次变化）
        Map<String, BigDecimal> mergedDeltas = mergeMasteryDeltas(results);
        List<MasterySnapshot> masteryUpdates = masteryUpdateEngine
            .batchUpdate(request.getStudentId(), mergedDeltas, "EXAM", request.getPracticeSessionId());

        // 批量发布事件
        eventPublisher.publishBatch(results, masteryUpdates);

        return buildBatchResult(results, masteryUpdates);
    }

    /**
     * 合并同一知识点在多次答题中的变化量
     * 避免一道大题关联 3 个知识点时，每个知识点被独立计算 3 次增量
     */
    private Map<String, BigDecimal> mergeMasteryDeltas(List<GradingResult> results) {
        Map<String, BigDecimal> merged = new LinkedHashMap<>();
        // 逐题计算每知识点的原始增量，然后按知识点 ID 累加
        for (GradingResult result : results) {
            for (KnowledgePointWeight kpw : result.getQuestion().getKnowledgePoints()) {
                BigDecimal delta = calculateSingleDelta(result, kpw);
                merged.merge(kpw.getKnowledgePointId(), delta, BigDecimal::add);
            }
        }
        // 对累加后的总变化量做上限裁剪（单次考试对单个知识点的掌握度变化不超过 ±25）
        merged.replaceAll((kpId, totalDelta) ->
            totalDelta.max(new BigDecimal("-25")).min(new BigDecimal("25"))
        );
        return merged;
    }
}
```

## 9. 错误处理与降级策略

### 9.1 错误分级

| 错误级别 | 场景 | 处理策略 |
|----------|------|----------|
| **L1 - 轻微** | 填空题模糊匹配超时 | 降级为精确匹配，返回结果 + 降级标记 |
| **L2 - 中等** | 数学表达式解析失败 | 降级为 AI 辅助批改，返回结果 + 低信心度 |
| **L3 - 严重** | AI 批改服务不可用 | 保存原始答案，标记为"待批改"，返回"答案已提交，稍后查看结果" |
| **L4 - 致命** | 数据库写入失败 | 重试 3 次，失败后写入本地队列异步补偿，返回"系统繁忙" |

### 9.2 降级策略详细设计

```java
public class GradingDegradationChain {

    private final List<GradingStrategy> chain;

    /**
     * 降级链：ExactMatch → FuzzyMatch → MathEquivalence → AIAssisted → PendingManual
     */
    public GradingResult gradeWithFallback(GradingContext ctx) {
        for (GradingStrategy strategy : chain) {
            if (!strategy.supports(ctx.getQuestionType(), ctx.getAnswerType())) {
                continue;
            }
            try {
                GradingResult result = strategy.grade(ctx);
                if (result != null) {
                    return result;
                }
            } catch (GradingException e) {
                log.warn("批改策略 {} 执行失败，尝试降级: {}", strategy.getClass().getSimpleName(), e.getMessage());
                continue;
            }
        }

        // 所有策略都失败 → 标记为待人工批改
        return GradingResult.builder()
            .correct(null)
            .gradingMethod(GradingMethod.MANUAL)
            .gradingTimeMs(0L)
            .build();
    }
}
```

### 9.3 掌握度更新失败处理

```
掌握度更新失败
      │
      ├── 可重试错误（锁超时、DB 连接闪断）
      │     → 重试 3 次，间隔 500ms
      │     → 重试成功：正常返回
      │     → 重试失败：写入 mastery_update_retry_queue
      │
      ├── 不可重试错误（数据异常、算法异常）
      │     → 记录错误日志
      │     → 发送告警
      │     → 跳过掌握度更新，不影响批改结果返回
      │
      └── 重试队列消费（定时任务，每分钟扫描）
            → 重新执行掌握度更新
            → 超过 24h 的旧更新丢弃（避免过期数据干扰）
```

### 9.4 答题记录一致性保障

```java
/**
 * 答案提交流程中的数据一致性保障
 */
public class AnswerSubmitConsistencyGuard {

    /**
     * 方案：先写 DB，后更新缓存/掌握度
     * 如果后续步骤失败，DB 中已有答题记录，通过定时对账修复
     */
    @Transactional
    public AnswerSubmitResponse submitWithConsistency(AnswerSubmitRequest request) {
        // 1. 防重检查（Redis SET NX，TTL 30s）
        String dedupKey = "answer:dedup:" + request.getStudentId() + ":"
            + request.getQuestionId() + ":" + request.getPracticeSessionId();
        if (!redis.setNX(dedupKey, "1", 30)) {
            throw new BusinessException(ErrorCode.DUPLICATE_SUBMISSION, "请勿重复提交");
        }

        try {
            // 2. 保存原始答案（必成功，事务保护）
            AnswerRecord record = saveAnswerRecord(request);

            // 3. 批改（失败不影响答案记录）
            GradingResult gradingResult;
            try {
                gradingResult = gradingEngine.grade(buildContext(request, record));
                updateGradingResult(record.getAnswerId(), gradingResult);
            } catch (Exception e) {
                gradingResult = GradingResult.pending();
                log.error("批改失败，答案已保存待后续处理: answerId={}", record.getAnswerId(), e);
                // 发送异步批改消息
                messaging.send("grading.retry", record.getAnswerId());
            }

            // 4. 掌握度更新（失败不影响批改结果返回）
            List<MasterySnapshot> masteryUpdates = Collections.emptyList();
            try {
                masteryUpdates = masteryUpdateEngine.updateAfterAnswer(
                    request.getStudentId(), gradingResult, getQuestion(request.getQuestionId()));
            } catch (Exception e) {
                log.error("掌握度更新失败: studentId={}, questionId={}",
                    request.getStudentId(), request.getQuestionId(), e);
                // 写入重试队列
                masteryRetryQueue.enqueue(new MasteryRetryTask(
                    request.getStudentId(), record.getAnswerId(), request.getQuestionId()));
            }

            // 5. 异步发布事件
            eventPublisher.publishAsync(buildAnswerGradedEvent(record, gradingResult, masteryUpdates));

            return buildResponse(record, gradingResult, masteryUpdates);

        } finally {
            // 6. 清理防重标记
            redis.del(dedupKey);
        }
    }
}
```

## 10. 性能优化

### 10.1 批改性能优化

| 优化点 | 方案 | 预期效果 |
|--------|------|----------|
| 题目元数据缓存 | Redis 缓存题目信息（标准答案、知识点关联、评分规则），TTL 1h | 减少题目查询延迟 |
| 批改策略预编译 | 选择题/填空题的正则表达式、数学表达式解析器预编译 | 减少批改耗时 |
| 批量提交并行化 | 使用线程池并行批改，限制并发度 = CPU 核数 × 2 | 批量提交响应时间 |
| AI 批改结果缓存 | 相同答案 + 相同题目的批改结果缓存 24h | 避免重复 AI 调用 |

### 10.2 掌握度更新性能优化

| 优化点 | 方案 | 预期效果 |
|--------|------|----------|
| 掌握度缓存优先 | 读取掌握度先查 Redis Hash，miss 时查 DB 并回写 | 减少掌握度读取延迟 |
| 合并更新 | 批量提交时合并同一知识点的多次增量 | 减少数据库写入次数 |
| 异步日志 | 掌握度更新日志异步批量写入 | 减少主流程写入压力 |
| 分片锁 | 掌握度更新锁按 studentId 分片 | 减少锁竞争 |

## 14. 安全与合规

### 14.1 安全措施

| 措施 | 说明 |
|------|------|

- 错题收录采用温和提示（"这道题可以加入错题本巩固一下"），而非强制标记
- 家长端可查看掌握度趋势图，但不展示具体分值
