## 1. 概述

### 1.1 设计目标

为 PrimeTop 教育内容生产管线提供一站式的可视化素材自动生成与管理能力，覆盖：

1. **学科图表程序化生成** — 数学函数图、几何图形、物理受力图、电路图、化学分子结构、生物示意图等
2. **AI 配图智能生成** — 基于知识点和上下文，调用多模态模型生成概念插图、场景图、类比图
3. **授权图库智能检索** — 从已授权教育资源库中匹配最相关的素材
4. **素材资产管理** — 统一存储、标签、版本、检索、生命周期管理
5. **内容嵌入集成** — 与富文本渲染引擎对接，实现素材在内容中的自动嵌入与排版

### 1.2 设计背景

当前内容生产流程中，编辑人员创建课程章节、题目解析、知识点讲解时，需要手动使用专业工具（GeoGebra、ChemDraw、Visio 等）绘制配图，效率低、风格不一致、且难以规模化。本服务旨在将可视化素材生成自动化、标准化、智能化，大幅降低内容生产成本。

### 1.3 用户角色

| 角色 | 使用场景 | 核心诉求 |
|------|----------|----------|
| 内容编辑 | 创建课程/题目时请求配图 | 快速获得高质量、适龄的示意图 |
| 内容审核员 | 审核配图的准确性和适宜性 | 确保图表科学正确、无误导 |
| 教研人员 | 批量生产专题内容 | 模板化批量生成系列素材 |
| 开发人员 | 集成素材生成API | 清晰的接口文档与SDK |
| AI训练人员 | 优化生成质量 | 质量反馈数据与评估指标 |

## 4. 素材路由决策层 (Asset Router)

### 4.1 路由决策流程

Asset Router 是本服务的"大脑"，接收素材请求后，根据意图、学科、学段、知识点等信息，决策使用哪种生成策略。

```
请求输入
    │
    ▼
┌─────────────────┐
│ 1. 意图识别      │ ← NLP解析请求文本 + 结构化参数
│    确定素材类型   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 2. 策略匹配      │ ← 规则引擎：素材类型 → 引擎映射表
│    确定候选引擎   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 3. 缓存检查      │ ← 参数指纹 → Redis查找已有结果
│    命中则直接返回 │
└────────┬────────┘
         │ miss
         ▼
┌─────────────────┐
│ 4. 执行策略选择  │
│    single/       │
│    parallel/     │
│    fallback      │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 5. 生成调度      │ → 调用各引擎，收集结果
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 6. 结果评估      │ ← 质量评分模型 + 规则校验
│    选择最佳结果   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 7. 后处理        │ ← 格式转换、压缩、水印、alt_text生成
│    存储与入库     │
└─────────────────┘
```

### 4.2 引擎映射规则

```java
@Component
public class AssetRouterRules {

    /**
     * 素材类型 → 引擎候选列表（按优先级排序）
     */
    private static final Map<VisualAssetType, List<GenerationEngine>> ENGINE_MAP = Map.of(
        VisualAssetType.FUNCTION_PLOT, 
            List.of(GenerationEngine.MATPLOTLIB, GenerationEngine.MANIM, GenerationEngine.D3),
            
        VisualAssetType.GEOMETRY_FIGURE, 
            List.of(GenerationEngine.TIKZ, GenerationEngine.SVG, GenerationEngine.D3),
            
        VisualAssetType.FORCE_DIAGRAM, 
            List.of(GenerationEngine.SVG, GenerationEngine.TIKZ),
            
        VisualAssetType.CIRCUIT_DIAGRAM, 
            List.of(GenerationEngine.SVG, GenerationEngine.TIKZ),
            
        VisualAssetType.MOLECULE_STRUCTURE, 
            List.of(GenerationEngine.RDKIT, GenerationEngine.INDIGO),
            
        VisualAssetType.REACTION_EQUATION, 
            List.of(GenerationEngine.RDKIT, GenerationEngine.LATEX),
            
        VisualAssetType.CELL_DIAGRAM, 
            List.of(GenerationEngine.LIBRARY_SEARCH, GenerationEngine.AI_DIFFUSION),
            
        VisualAssetType.TIMELINE, 
            List.of(GenerationEngine.D3, GenerationEngine.SVG),
            
        VisualAssetType.DATA_CHART, 
            List.of(GenerationEngine.MATPLOTLIB, GenerationEngine.PLOTLY),
            
        VisualAssetType.CONCEPT_ILLUSTRATION, 
            List.of(GenerationEngine.LIBRARY_SEARCH, GenerationEngine.AI_DIFFUSION, GenerationEngine.AI_DALLE),
            
        VisualAssetType.SCENE_ILLUSTRATION, 
            List.of(GenerationEngine.LIBRARY_SEARCH, GenerationEngine.AI_DALLE, GenerationEngine.AI_DIFFUSION),
            
        VisualAssetType.ANALOGY_DIAGRAM, 
            List.of(GenerationEngine.SVG, GenerationEngine.AI_DIFFUSION),
            
        VisualAssetType.FLOWCHART, 
            List.of(GenerationEngine.D3, GenerationEngine.SVG),
            
        VisualAssetType.COMPARISON_CHART, 
            List.of(GenerationEngine.D3, GenerationEngine.MATPLOTLIB)
    );

    /**
     * 执行策略决策
     */
    public ExecutionStrategy decideStrategy(
            List<GenerationEngine> candidates, 
            GenerationRequest request) {
        
        // 精确类素材（函数图、分子结构等）→ 单引擎即可，程序化渲染准确率高
        if (candidates.get(0).isProgrammatic() && 
            request.getPrecisionRequirement() == PrecisionRequirement.EXACT) {
            return ExecutionStrategy.single(candidates.get(0));
        }
        
        // 概念类素材（插图、场景图）→ 并行调用，选最优
        if (candidates.stream().anyMatch(e -> e.isAI())) {
            return ExecutionStrategy.parallel(
                candidates.stream()
                    .limit(request.getMaxParallelEngines())
                    .toList()
            );
        }
        
        // 图库优先策略 → 先搜图库，miss再走AI
        if (candidates.get(0) == GenerationEngine.LIBRARY_SEARCH) {
            return ExecutionStrategy.fallback(
                GenerationEngine.LIBRARY_SEARCH,
                GenerationEngine.AI_DALLE,
                GenerationEngine.AI_DIFFUSION
            );
        }
        
        return ExecutionStrategy.single(candidates.get(0));
    }
}
```

### 4.3 缓存策略

```java
@Service
public class AssetCacheManager {

    private static final String CACHE_PREFIX = "va:render:";
    private static final Duration CACHE_TTL = Duration.ofDays(30);
    
    /**
     * 生成缓存Key — 基于渲染参数的确定性指纹
     */
    public String buildCacheKey(GenerationRequest request) {
        // 对所有影响渲染结果的参数进行排序+拼接+哈希
        String canonical = canonicalize(request.getParams());
        String hash = DigestUtils.sha256Hex(canonical);
        return CACHE_PREFIX + request.getAssetType() + ":" + hash;
    }
    
    /**
     * 多级缓存查询
     */
    public Optional<VisualAsset> findCached(GenerationRequest request) {
        String key = buildCacheKey(request);
        
        // L1: 本地缓存 (Caffeine, 5min)
        VisualAsset l1 = localCache.getIfPresent(key);
        if (l1 != null) return Optional.of(l1);
        
        // L2: Redis (30天)
        String json = redis.get(key);
        if (json != null) {
            VisualAsset asset = deserialize(json);
            localCache.put(key, asset);
            return Optional.of(asset);
        }
        
        // L3: 数据库 — 查找相同 source_config 的已有素材
        return repository.findBySourceConfigHash(request.getParamsHash());
    }
}
```

## 5. 学科图表渲染引擎

### 5.1 数学函数图像渲染 (Matplotlib引擎)

#### 5.1.1 支持的函数类型

| 函数类别 | 示例 | 渲染参数 |
|----------|------|----------|
| 初等函数 | y = x², y = sin(x) | 函数表达式、定义域、颜色 |
| 复合函数 | y = log₂(x²-1) | 多函数叠加、定义域交集 |
| 参数方程 | x=3cos(t), y=3sin(t) | 参数范围、采样密度 |
| 极坐标 | r = 2(1-cosθ) | θ范围、极轴显示 |
| 导数/积分 | f(x)与f'(x)对比 | 导数曲线、切线、填充区域 |
| 不等式 | y > 2x+1 | 阴影区域、边界线 |
| 数列 | aₙ = 2ⁿ | 离散点、趋势线 |

```python
# render_engines/matplotlib_engine.py

import matplotlib
matplotlib.use('Agg')  # 无头模式
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
import numpy as np
from typing import List, Dict, Any
import json
import hashlib
import os

class MatplotlibFunctionRenderer:
    """数学函数图像渲染器"""
    
    # 安全的求值环境 — 仅允许数学函数
    SAFE_NAMESPACE = {
        'sin': np.sin, 'cos': np.cos, 'tan': np.tan,
        'arcsin': np.arcsin, 'arccos': np.arccos, 'arctan': np.arctan,
        'sinh': np.sinh, 'cosh': np.cosh, 'tanh': np.tanh,
        'exp': np.exp, 'log': np.log, 'log2': np.log2, 
        'log10': np.log10, 'sqrt': np.sqrt,
        'abs': np.abs, 'pi': np.pi, 'e': np.e,
        'floor': np.floor, 'ceil': np.ceil,
        'power': np.power,
    }
    
    def __init__(self):
        # 设置中文字体
        self._setup_chinese_font()
    
    def _setup_chinese_font(self):
        """配置中文字体，确保坐标轴标签正确显示"""
        font_paths = [
            '/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc',
            '/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc',
            'C:/Windows/Fonts/simhei.ttf',
        ]
        for path in font_paths:
            if os.path.exists(path):
                fm.fontManager.addfont(path)
                plt.rcParams['font.sans-serif'] = ['WenQuanYi Zen Hei', 'Noto Sans CJK SC', 'SimHei']
                plt.rcParams['axes.unicode_minus'] = False
                break
    
    def render(self, params: Dict[str, Any]) -> Dict[str, Any]:
        """渲染函数图像"""
        functions = params.get('functions', [])
        domain = params.get('domain', {'xMin': -10, 'xMax': 10})
        range_cfg = params.get('range', {})
        features = params.get('features', {})
        style = params.get('style', {})
        
        # 创建图形
        fig_size = tuple(style.get('figSize', [8, 6]))
        dpi = style.get('dpi', 200)
        fig, ax = plt.subplots(figsize=fig_size, dpi=dpi)
        
        # 设置背景色
        bg_color = style.get('backgroundColor', '#FFFFFF')
        fig.patch.set_facecolor(bg_color)
        ax.set_facecolor(bg_color)
        
        # 绘制每个函数
        x_min, x_max = domain['xMin'], domain['xMax']
        x = np.linspace(x_min, x_max, 1000)
        
        for func in functions:
            try:
                y = self._evaluate(func['expression'], x)
                valid_mask = np.isfinite(y)
                
                ax.plot(
                    x[valid_mask], y[valid_mask],
                    label=func.get('label', ''),
                    color=func.get('color', '#2196F3'),
                    linewidth=func.get('lineWidth', 2),
                    linestyle=func.get('lineStyle', 'solid')
                )
            except Exception as e:
                raise RenderError(f"函数渲染失败: {func['expression']}, 错误: {e}")
        
        # 设置坐标轴范围
        if range_cfg:
            ax.set_ylim(range_cfg.get('yMin'), range_cfg.get('yMax'))
        ax.set_xlim(x_min, x_max)
        
        # 网格
        if features.get('grid', True):
            ax.grid(True, color=style.get('gridColor', '#E0E0E0'), 
                    linewidth=0.5, alpha=0.8)
        
        # 坐标轴
        if features.get('axes', True):
            ax.axhline(y=0, color='#333333', linewidth=1)
            ax.axvline(x=0, color='#333333', linewidth=1)
        
        # 标注特殊点
        for point in features.get('markedPoints', []):
            ax.plot(point['x'], point['y'], 'o', color='#F44336', markersize=8)
            if point.get('label'):
                ax.annotate(
                    point['label'], (point['x'], point['y']),
                    textcoords="offset points", xytext=(10, 10),
                    fontsize=style.get('fontSize', 14) - 2,
                    color='#333333',
                    arrowprops=dict(arrowstyle='->', color='#666666')
                )
        
        # 填充区域
        if 'fillRegion' in features:
            self._fill_region(ax, x, functions, features['fillRegion'])
        
        # 图例
        if features.get('legend', False) and functions:
            ax.legend(fontsize=style.get('fontSize', 14) - 2, loc='best')
        
        # 字体大小
        ax.tick_params(labelsize=style.get('fontSize', 14) - 3)
        
        # 保存
        output_path = self._generate_output_path(params)
        fig.savefig(output_path, bbox_inches='tight', facecolor=bg_color)
        plt.close(fig)
        
        return {
            'filePath': output_path,
            'format': 'png',
            'engine': 'matplotlib',
            'qualityScore': self._calculate_quality(features, functions)
        }
    
    def _evaluate(self, expression: str, x: np.ndarray) -> np.ndarray:
        """安全求值数学表达式"""
        # 安全检查：禁止import/exec/eval等危险操作
        forbidden = ['import', 'exec', 'eval', '__', 'open', 'write', 'read', 'system']
        expr_lower = expression.lower()
        for kw in forbidden:
            if kw in expr_lower:
                raise SecurityError(f"禁止的表达式: {kw}")
        
        # 将 ^ 替换为 ** (学生常用写法)
        expression = expression.replace('^', '**')
        
        try:
            return eval(expression, {"__builtins__": {}}, 
                       {**self.SAFE_NAMESPACE, 'x': x})
        except Exception as e:
            raise RenderError(f"表达式求值失败: {expression}, {e}")
    
    def _fill_region(self, ax, x, functions, fill_cfg):
        """绘制填充区域"""
        curve_idx = fill_cfg.get('curveIndex', 0)
        y = self._evaluate(functions[curve_idx]['expression'], x)
        
        x_start = fill_cfg.get('xStart', x.min())
        x_end = fill_cfg.get('xEnd', x.max())
        mask = (x >= x_start) & (x <= x_end)
        
        ax.fill_between(
            x[mask], y[mask], 0,
            color=fill_cfg.get('color', '#E3F2FD'),
            alpha=fill_cfg.get('alpha', 0.5)
        )
    
    def _generate_output_path(self, params) -> str:
        """生成确定性输出路径"""
        param_hash = hashlib.sha256(
            json.dumps(params, sort_keys=True).encode()
        ).hexdigest()[:16]
        return f"/tmp/render/{param_hash}.png"
    
    def _calculate_quality(self, features, functions) -> float:
        """简单的质量评分"""
        score = 70.0
        if features.get('grid'): score += 5
        if features.get('legend'): score += 5
        if features.get('markedPoints'): score += 8
        if len(functions) > 1: score += 5   # 多函数对比加分
        if features.get('fillRegion'): score += 7
        return min(score, 100.0)
```

```python
from rdkit import Chem
from rdkit.Chem import Draw, AllChem
from rdkit.Chem.Draw import rdMolDraw2D
from typing import Dict, Any, List
import io

class RDKitMoleculeRenderer:
    """化学分子结构渲染器"""
    
    def render(self, params: Dict[str, Any]) -> Dict[str, Any]:
        """渲染分子结构"""
        render_type = params.get('renderType', 'single_molecule')
        
        if render_type == 'single_molecule':
            return self._render_single(params)
        elif render_type == 'reaction':
            return self._render_reaction(params)
        elif render_type == 'comparison':
            return self._render_comparison(params)
        else:
            raise ValueError(f"不支持的渲染类型: {render_type}")
    
    def _render_single(self, params: Dict[str, Any]) -> Dict[str, Any]:
        """渲染单个分子"""
        smiles = params['smiles']  # e.g., "C(=O)(O)" for CO2
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            raise RenderError(f"无效的SMILES: {smiles}")
        
        # 计算2D坐标
        AllChem.Compute2DCoords(mol)
        
        # 渲染配置
        width = params.get('width', 400)
        height = params.get('height', 400)
        drawer = rdMolDraw2D.MolDraw2DCairo(width, height)
        
        # 样式配置
        drawer.SetFontSize(params.get('fontSize', 0.8))
        
        # 高亮原子/键
        highlight_atoms = params.get('highlightAtoms', [])
        highlight_bonds = params.get('highlightBonds', [])
        
        # 原子标注
        atom_labels = params.get('atomLabels', {})
        if atom_labels:
            for atom_idx, label in atom_labels.items():
                mol.GetAtomWithAtomNumber(int(atom_idx)).SetProp('atomNote', label)
        
        drawer.DrawMolecule(
            mol,
            highlightAtoms=highlight_atoms or None,
            highlightBonds=highlight_bonds or None,
            legend=params.get('title', '')
        )
        drawer.FinishDrawing()
        
        # 输出
        output_path = params.get('outputPath', f"/tmp/render/mol_{hash(smiles)}.png")
        with open(output_path, 'wb') as f:
            f.write(drawer.GetDrawingText())
        
        return {
            'filePath': output_path,
            'format': 'png',
            'engine': 'rdkit',
            'smiles': smiles,
            'molecularFormula': Chem.rdMolDescriptors.CalcMolFormula(mol),
            'qualityScore': 90.0  # 程序化渲染准确率高
        }
    
    def _render_reaction(self, params: Dict[str, Any]) -> Dict[str, Any]:
        """渲染化学反应方程式"""
        reactants_smarts = params['reactants']    # ["C(=O)(O)", "O"]  CO2 + H2O
        products_smarts = params['products']      # ["C(=O)(O).[O+]"]  H2CO3
        
        # 构建反应对象
        reactants = [Chem.MolFromSmiles(s) for s in reactants_smarts]
        products = [Chem.MolFromSmiles(s) for s in products_smarts]
        
        rxn = AllChem.ChemicalReaction()
        for mol in reactants:
            rxn.AddReactantTemplate(mol)
        for mol in products:
            rxn.AddProductTemplate(mol)
        
        # 渲染
        width = params.get('width', 800)
        height = params.get('height', 300)
        drawer = rdMolDraw2D.MolDraw2DCairo(width, height)
        drawer.DrawReaction(rxn)
        drawer.FinishDrawing()
        
        output_path = params.get('outputPath', '/tmp/render/reaction.png')
        with open(output_path, 'wb') as f:
            f.write(drawer.GetDrawingText())
        
        return {
            'filePath': output_path,
            'format': 'png',
            'engine': 'rdkit',
            'qualityScore': 90.0
        }
```

```python
        objects = params.get('objects', [])
        for obj in objects:
            shape = obj.get('shape', 'rect')
            if shape == 'rect':
                dwg.add(dwg.rect(

                    size=(obj['width'], obj['height']),
                    fill=obj.get('fill', '#4CAF50'),
                    stroke='#333',
                    stroke_width=2
                ))
                # 标注物体质量

                    dwg.add(dwg.text(

                        insert=(obj['x'] + obj['width']/2, obj['y'] + obj['height']/2),
                        font_size=14, text_anchor='middle',
                        dominant_baseline='middle'
                    ))
        
        # 绘制斜面
        slopes = params.get('slopes', [])
        for slope in slopes:
            points = [(p['x'], p['y']) for p in slope['points']]
            dwg.add(dwg.polyline(
                points, fill='none', stroke='#333', stroke_width=2
            ))
            # 斜面阴影线
            if slope.get('hatch'):
                self._draw_hatch(dwg, points, slope['angle'])
        
        # 绘制力矢量箭头
        forces = params.get('forces', [])
        for force in forces:
            self._draw_force_arrow(dwg, force)
        
        # 绘制角度标注

        for angle in angles:
            self._draw_angle_arc(dwg, angle)

            self._draw_axes(dwg, width, height)

        end = (force['endX'], force['endY'])
        color = force.get('color', '#F44336')
        label = force.get('label', '')
        arrow_size = force.get('arrowSize', 8)
        
        # 主线
        dwg.add(dwg.line(
            start=start, end=end,
            stroke=color, stroke_width=2.5
        ))
        
        # 箭头头部
        angle = math.atan2(end[1] - start[1], end[0] - start[0])
        p1 = (end[0] - arrow_size * math.cos(angle - math.pi/6),
              end[1] - arrow_size * math.sin(angle - math.pi/6))
        p2 = (end[0] - arrow_size * math.cos(angle + math.pi/6),
              end[1] - arrow_size * math.sin(angle + math.pi/6))
        dwg.add(dwg.polygon(
            [end, p1, p2], fill=color
        ))
        
        # 力的标签
        if label:
            label_offset_x = 10 * math.cos(angle + math.pi/2)
            label_offset_y = 10 * math.sin(angle + math.pi/2)
            dwg.add(dwg.text(
                label,
                insert=(end[0] + label_offset_x, end[1] + label_offset_y),
                font_size=13, font_weight='bold',
                fill=color
            ))
```

```java
        // 2. 负面提示词

        // 3. 调用AI模型
        byte[] imageData = callImageModel(prompt, negativePrompt, request.getStyleParams());
        
        // 4. 后处理：裁剪、压缩、格式转换
        byte[] processed = postProcess(imageData, request.getOutputFormat());
        
        // 5. 质量校验
        double score = qualityChecker.check(processed, request);
        
        return GenerationResult.builder()
            .imageData(processed)
            .qualityScore(score)
            .prompt(prompt)
            .build();
    }
    
    private String buildPrompt(IllustrationRequest request) {
        StringBuilder sb = new StringBuilder();
        
        // 核心描述
        sb.append(request.getConcept());
        
        // 学科风格
        sb.append(", ").append(STYLE_SUFFIX.getOrDefault(request.getSubject(), "educational illustration"));
        
        // 学段适配
        String ageAppropriate = switch (request.getGradeBand()) {
            case "kindergarten" -> "colorful, cute, simple shapes, large elements, very child-friendly";
            case "primary" -> "friendly, colorful but organized, cartoon style";
            case "junior" -> "moderately detailed, clear educational style";
            case "senior" -> "professional, precise, textbook quality";
        };
        sb.append(", ").append(ageAppropriate);
        
        // 构图参数
        sb.append(", ").append(request.getCompositionHint());
        
        // 安全约束
        sb.append("\n\n").append(SAFETY_PROMPT.formatted(getAgeRange(request.getGradeBand())));
        
        return sb.toString();
    }
    
    private String buildNegativePrompt(String gradeBand) {
```

### 7.2 图库索引构建

```python
# library_indexer.py

import clip
import torch
from PIL import Image
from typing import List, Dict
import numpy as np

class VisualLibraryIndexer:
    """授权图库多模态索引构建器"""
    
    def __init__(self):
        self.device = "cuda" if torch.cuda.is_available() else "cpu"
        self.model, self.preprocess = clip.load("ViT-B/32", device=self.device)
    
    def index_image(self, image_path: str, metadata: Dict) -> Dict:
        """为图库中的图片建立向量索引"""
        # 图像编码
        image = self.preprocess(Image.open(image_path)).unsqueeze(0).to(self.device)
        with torch.no_grad():
            image_features = self.model.encode_image(image)
        image_features = image_features.cpu().numpy().flatten()
        
        # 文本编码（图片标题+描述+标签）
        text = f"{metadata.get('title', '')} {metadata.get('description', '')} {' '.join(metadata.get('tags', []))}"
        text_tokens = clip.tokenize([text], truncate=True).to(self.device)
        with torch.no_grad():
            text_features = self.model.encode_text(text_tokens)
        text_features = text_features.cpu().numpy().flatten()
        
        # 融合向量 (图像权重0.7 + 文本权重0.3)
        fused = 0.7 * self._normalize(image_features) + 0.3 * self._normalize(text_features)
        
        return {
            'embedding': fused.tolist(),
            'metadata': metadata,
            'imageHash': self._compute_hash(image_path)
        }
    
    def search(self, query: str, subject: str, grade_band: str, 
               top_k: int = 20) -> List[Dict]:
        """多模态向量检索"""
        # 查询编码
        query_tokens = clip.tokenize([query], truncate=True).to(self.device)
        with torch.no_grad():
            query_features = self.model.encode_text(query_tokens)
        query_vec = query_features.cpu().numpy().flatten()
        
        # 向量检索 (Milvus)
        results = self.milvus_collection.search(
            data=[query_vec.tolist()],
            anns_field="embedding",
            param={"metric_type": "IP", "params": {"nprobe": 16}},
            limit=top_k * 3,  # 过取以备过滤
            filter=f'subject == "{subject}" and grade_band == "{grade_band}"',
            output_fields=["asset_id", "title", "file_url", "license_type"]
        )
        
        # 重排序
        scored = []
        for hit in results[0]:
            score = hit.score  # CLIP相似度
            asset = hit.entity
            
            # 元数据加权
            if subject and asset.get('subject') == subject:
                score *= 1.15
            if grade_band and asset.get('grade_band') == grade_band:
                score *= 1.1
            
            # 使用频次惩罚 — 避免同一素材被过度推荐
            usage_count = asset.get('usage_count', 0)
            score *= max(0.5, 1.0 - usage_count * 0.05)
            
            scored.append({
                'asset_id': asset.get('asset_id'),
                'title': asset.get('title'),
                'file_url': asset.get('file_url'),
                'license': asset.get('license_type'),
                'similarity': hit.score,
                'final_score': score
            })
        
        scored.sort(key=lambda x: x['final_score'], reverse=True)
        return scored[:top_k]
    
    def _normalize(self, vec: np.ndarray) -> np.ndarray:
        return vec / (np.linalg.norm(vec) + 1e-8)
```

## 10. 质量评估与校验

### 10.1 多维度质量评分

```java
@Service
public class VisualAssetQualityChecker {
    
    /**
     * 综合质量评分 — 加权多维评估
     */
    public QualityReport evaluate(byte[] imageData, GenerationRequest request) {
        QualityReport report = new QualityReport();
        
        // 1. 技术质量 (30%)
        TechnicalQuality tech = checkTechnicalQuality(imageData);
        report.setTechnical(tech);
        // 分辨率、清晰度、色彩空间、文件大小
        
        // 2. 内容准确性 (30%) — 仅程序化渲染可保证，AI生成需校验
        ContentAccuracy accuracy = checkContentAccuracy(imageData, request);
        report.setAccuracy(accuracy);
        
        // 3. 教育适宜性 (20%)
        EducationalAppropriateness edu = checkEducationalAppropriateness(imageData, request);
        report.setEducational(edu);
        // 学段匹配度、信息负载适宜度、无干扰元素
        
        // 4. 视觉一致性 (10%)
        VisualConsistency consistency = checkVisualConsistency(imageData, request);
        report.setConsistency(consistency);
        // 与学科视觉风格规范一致
        
        // 5. 无障碍性 (10%)
        Accessibility accessibility = checkAccessibility(imageData);
        report.setAccessibility(accessibility);
        // 对比度、alt_text可生成性、缩放可读性
        
        // 综合评分
        double totalScore = tech.getScore() * 0.3 
                          + accuracy.getScore() * 0.3
                          + edu.getScore() * 0.2
                          + consistency.getScore() * 0.1
                          + accessibility.getScore() * 0.1;
        
        report.setTotalScore(totalScore);
        report.setPassed(totalScore >= 60.0 && accuracy.getScore() >= 50.0);
        
        return report;
    }
    
    /**
     * AI生成图片的额外安全校验
     */
    private ContentAccuracy checkContentAccuracy(byte[] imageData, 
                                                  GenerationRequest request) {
        if (request.getSourceType() == SourceType.PROGRAMMATIC) {
            // 程序化渲染天然准确
            return ContentAccuracy.perfect();
        }
        
        // AI生成图片 — 使用多模态模型校验
        if (request.getSourceType() == SourceType.AI_GENERATED) {
            // 1. 调用视觉模型检查图片是否包含禁止元素
            SafetyCheck safety = visionSafetyChecker.check(imageData, request.getGradeBand());
            if (!safety.isSafe()) {
                return ContentAccuracy.failed(safety.getIssues());
            }
            
            // 2. 检查图片与请求概念的语义匹配度
            double semanticMatch = clipSimilarity(imageData, request.getConcept());
            
            return ContentAccuracy.builder()
                .semanticMatch(semanticMatch)
                .safetyPassed(safety.isSafe())
                .score(semanticMatch * 100)
                .build();
        }
        
        // 授权图库 — 默认可信
        return ContentAccuracy.trusted();
    }
}
```
