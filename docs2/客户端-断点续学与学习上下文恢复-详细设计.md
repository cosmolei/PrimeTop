# 客户端-断点续学与学习上下文恢复 - 详细设计

> 版本：v1.0 | 日期：2026-05-26 | 状态：初稿

## 1. 模块概述

### 1.1 功能定位

断点续学与学习上下文恢复是 PrimeTop 客户端的核心体验保障模块。用户在学习过程中随时可能中断——切到微信回消息、锁屏放口袋、从手机换到平板、网络断开——本模块确保用户每次回到 APP 都能无缝恢复到上次的学习位置和状态。

本模块负责客户端侧的学习上下文采集、持久化、恢复和展示，包括首页"继续学习"卡片的完整数据逻辑。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 无感知恢复 | 用户回到 APP 时自动恢复学习状态，无需手动操作 |
| 多场景覆盖 | AI 对话、同步课堂、错题复习、拍照搜题、学习计时器全部支持 |
| 跨设备一致 | 手机上学到一半，平板上能继续 |
| 离线可靠 | 断网时本地保存，联网后自动同步 |
| 性能无感 | 持久化操作不阻塞 UI，恢复操作 < 500ms |

### 1.3 与其他模块的边界

| 模块 | 边界说明 |
|------|----------|
| 学习会话编排与上下文管理引擎 | 它定义服务端的会话生命周期、SessionCheckpoint 机制和模板编排；本模块是其客户端侧的落地实现，负责具体的 Flutter 端持久化、恢复 UI 和首页卡片展示 |
| 多端数据同步与冲突解决策略 | 它定义通用的增量同步引擎和冲突解决框架；本模块定义学习上下文这一特定数据类型的同步规则和冲突策略 |
| 首页与学习工作台 | 它定义首页布局，其中④"继续学习"区域由本模块提供数据源和 Widget |
| 客户端本地持久层与数据管理 | 它提供 Hive Box 和 Repository 基础设施；本模块在其上定义学习上下文专用的数据模型和存储策略 |
| 客户端应用启动流程与初始化管线 | 它定义冷/热启动管线；本模块在初始化管线中注册"学习上下文恢复"阶段 |
| AI对话引擎与会话管理 | 它管理 AI 对话的消息列表和会话状态；本模块从中提取恢复所需的上下文快照 |
| 错题整理 | 它管理错题本数据；本模块从中提取复习中断位置 |

### 1.4 覆盖学段

全学段（幼儿至高中），恢复逻辑无差异，UI 展示通过分龄 UI 策略适配。

## 2. 学习上下文数据模型

### 2.1 核心枚举

```dart
/// 学习场景类型
enum LearningScene {
  aiChat,          // AI 智能辅导对话
  syncCourse,      // 同步课堂章节学习
  mistakeReview,   // 错题复习
  photoSearch,     // 拍照搜题
  practice,        // 练习测评
  pomodoro,        // 番茄钟计时学习
}

/// 学习上下文状态
enum ContextStatus {
  active,      // 活跃：用户正在学习
  paused,      // 暂停：用户主动暂停
  interrupted, // 中断：用户切后台/锁屏/断网
  expired,     // 过期：超过可恢复窗口
  restored,    // 已恢复：用户已回到该上下文
  completed,   // 已完成：学习活动正常结束
}

/// 中断原因
enum InterruptReason {
  appBackground,    // 切到后台
  screenLock,       // 锁屏
  networkLost,      // 断网
  phoneCall,        // 来电
  userSwitch,       // 用户手动切换场景
  systemReclaim,    // 系统回收
  crash,            // 应用崩溃
}
```

```dart
  @HiveField(19) int syncVersion;

```

**索引策略：**
- 主键：`contextId`
- 索引 1：`userId + status`（查询用户活跃/中断的上下文）
- 索引 2：`updatedAt`（按时间排序）
- 索引 3：`scene + status`（按场景查询）

**容量控制：**
- 每用户保留最近 **50 条**上下文记录
- 超出的按 `updatedAt` 清理最旧的
- `status == completed` 且超过 7 天的自动归档删除

## 3. 上下文持久化策略

### 3.1 保存时机

| 时机 | 触发方式 | 保存内容 | 优先级 |
|------|----------|----------|--------|
| 用户切后台 | `WidgetsBindingObserver.didChangeAppLifecycleState(inactive/paused)` | 完整上下文快照 | P0 - 立即同步 |
| 用户锁屏 | 同上 | 完整上下文快照 | P0 - 立即同步 |
| 定期自动保存 | Timer 每 30 秒 | 增量进度更新 | P1 - 异步 |
| 场景切换 | 用户从场景 A 跳转到场景 B | 场景 A 完整快照 | P0 - 立即同步 |
| 关键节点完成 | 答完一题/看完一节/发完一条消息 | 增量进度更新 | P1 - 异步 |
| 网络状态变化 | 从离线恢复在线 | 待同步的上下文队列 | P2 - 批量同步 |
| 应用即将终止 | `dispose()` / `detached` | 最小快照（位置+进度） | P0 - 同步 |

### 3.3 P0 保存（立即/同步）

```dart
Future<void> _saveImmediate(LearningContext context) async {
  // 1. 更新时间戳和状态
  final updated = context.copyWith(
    updatedAt: DateTime.now(),
    status: ContextStatus.interrupted,
    interruptedAt: DateTime.now(),
  );

  // 2. 同步写入 Hive（await，阻塞调用方）
  await _contextBox.put(updated.contextId, _toBoxModel(updated));

  // 3. 更新内存缓存
  _memoryCache[updated.contextId] = updated;

  // 4. 异步上报服务端（fire-and-forget）
  _syncQueue.enqueue(updated);
}
```

### 3.4 防抖保存（P1）

```dart
Timer? _debounceTimer;

void _scheduleDebouncedSave(LearningContext context) {
  _debounceTimer?.cancel();
  _debounceTimer = Timer(const Duration(milliseconds: 500), () {
    _contextBox.put(context.contextId, _toBoxModel(context));
    _syncQueue.enqueue(context);
  });
}
```

## 5. 首页"继续学习"卡片设计

### 5.1 数据聚合逻辑

```dart
class ContinueLearningAggregator {
  /// 聚合可恢复的学习上下文，返回最多 N 条用于卡片展示
  Future<List<ContinueLearningItem>> aggregate({
    required String userId,
    int maxItems = 3,
  }) async {
    // 1. 从本地 Hive 读取所有 interrupted/active 状态的上下文
    final localContexts = await _contextRepo.getByStatus(
      userId: userId,
      statuses: [ContextStatus.interrupted, ContextStatus.active],
    );

    // 2. 尝试从服务端获取（超时 500ms 则用本地数据）
    List<LearningContext> remoteContexts = [];
    try {
      remoteContexts = await _api.getRecentContexts(userId).timeout(
        const Duration(milliseconds: 500),
      );
    } catch (_) {
      // 降级：仅用本地数据
    }

    // 3. 合并去重（以 contextId 为 key，取 syncVersion 较新的）
    final merged = _mergeContexts(localContexts, remoteContexts);

    // 4. 过滤：排除过期的（> 24h）和已完成/已恢复的
    final valid = merged.where((ctx) {
      if (ctx.status == ContextStatus.completed || 
          ctx.status == ContextStatus.restored) return false;
      if (ctx.interruptedAt != null &&
          DateTime.now().difference(ctx.interruptedAt!).inHours > 24) {
        return false;
      }
      return true;
    }).toList();

    // 5. 排序：按优先级排序
    valid.sort((a, b) => _comparePriority(a, b));

    // 6. 转换为展示模型
    return valid.take(maxItems).map(_toCardItem).toList();
  }

  /// 排序优先级
  int _comparePriority(LearningContext a, LearningContext b) {
    // 优先级维度：
    // 1. 状态：active > interrupted
    // 2. 时间：最近更新的优先
    // 3. 场景权重：同步课堂 > AI对话 > 错题复习 > 练习 > 拍照搜题
    // 4. 进度：未完成且进度较高的优先（沉没成本效应）
    int scoreA = _calculatePriorityScore(a);
    int scoreB = _calculatePriorityScore(b);
    return scoreB.compareTo(scoreA);
  }

  int _calculatePriorityScore(LearningContext ctx) {
    int score = 0;
    // 状态权重
    if (ctx.status == ContextStatus.active) score += 100;
    // 时效性：越近越高（分钟数取反）
    final minutesAgo = DateTime.now().difference(ctx.updatedAt).inMinutes;
    score += max(0, 1440 - minutesAgo); // 24h 内线性递减
    // 场景权重
    score += {
      LearningScene.syncCourse: 50,
      LearningScene.aiChat: 40,
      LearningScene.mistakeReview: 30,
      LearningScene.practice: 20,
      LearningScene.photoSearch: 10,
      LearningScene.pomodoro: 5,
    }[ctx.scene] ?? 0;
    // 进度权重（越接近完成越想续完）
    score += (ctx.progress * 30).round();
    return score;
  }
}
```

## 9. 冲突解决

### 9.1 冲突场景

| 场景 | 描述 | 冲突类型 |
|------|------|----------|
| 多设备同场景 | 用户在手机和平板上都学习了数学第三章 | 进度冲突 |
| 离线后冲突 | 设备 A 离线学习后上线，但设备 B 已更新 | 时间戳冲突 |
| 同设备多进入 | 用户在首页看到卡片，点进去学习后返回，卡片没刷新 | UI 状态冲突 |

### 9.2 解决策略

**策略一：Last-Writer-Wins（默认）**

```dart
LearningContext resolveConflict(LearningContext local, LearningContext remote) {
  // 1. 比较 syncVersion（乐观锁）
  if (local.syncVersion > remote.syncVersion) {
    return local;
  }
  if (remote.syncVersion > local.syncVersion) {
    return remote;
  }

  // 2. syncVersion 相同，比较 updatedAt 时间戳
  if (local.updatedAt.isAfter(remote.updatedAt)) {
    return local;
  }

  // 3. 默认以服务端为准
  return remote;
}
```

**策略二：进度合并（适用于同步课堂）**

```dart
SyncCourseSceneContext resolveSyncCourseConflict(
  SyncCourseSceneContext local,
  SyncCourseSceneContext remote,
) {
  // 视频进度取较大的（看了更多）
  final mergedPosition = max(local.playbackPosition, remote.playbackPosition);

  // 电子书页码取较大的
  final mergedPage = max(
    local.ebookPageNumber ?? 0,
    remote.ebookPageNumber ?? 0,
  );

  return SyncCourseSceneContext(
    courseId: local.courseId,
    chapterId: local.chapterId,
    chapterName: local.chapterName,
    sectionId: local.sectionId ?? remote.sectionId,
    playbackPosition: mergedPosition,
    totalDuration: local.totalDuration,
    ebookPageNumber: mergedPage,
    ebookTotalPages: local.ebookTotalPages,
    contentType: local.contentType,
  );
}
```

**策略三：AI 对话不冲突**

AI 对话的上下文仅记录"最后查看位置"，不涉及写入冲突。恢复时以服务端消息列表为准，滚动位置取本地值。

### 9.3 冲突检测流程

```
客户端上报上下文（syncVersion=N）
    │
    ├── 服务端比对：
    │   ├── 服务端 syncVersion == N → 接受，version++
    │   ├── 服务端 syncVersion > N → 冲突！
    │   │   ├── 返回 409 Conflict + 服务端最新数据
    │   │   └── 客户端执行合并策略后重新上报
    │   └── 服务端 syncVersion < N → 异常（数据不一致），以客户端为准
    │
    └── 合并完成后，推送更新到用户其他在线设备
        └── WebSocket 消息：{"type": "context_updated", "contextId": "xxx"}
```

```dart
/// 学习上下文管理器 — 整个模块的入口类
class LearningContextManager extends WidgetsBindingObserver {
  final LearningContextRepository _repo;
  final LearningContextSyncService _syncService;
  final ContinueLearningAggregator _aggregator;

  /// 内存缓存：当前活跃的上下文列表
  final Map<String, LearningContext> _activeContexts = {};

  /// 防抖 Timer
  final Map<String, Timer> _debounceTimers = {};

  LearningContextManager({
    required LearningContextRepository repo,
    required LearningContextSyncService syncService,
    required ContinueLearningAggregator aggregator,
  })  : _repo = repo,
        _syncService = syncService,
        _aggregator = aggregator {
    // 注册 APP 生命周期监听
    WidgetsBinding.instance.addObserver(this);
  }

  // ========== APP 生命周期 ==========

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.inactive:
      case AppLifecycleState.paused:
        _onAppBackground();
        break;
      case AppLifecycleState.resumed:
        _onAppForeground();
        break;
      case AppLifecycleState.detached:
        _onAppDetached();
        break;
      default:
        break;
    }
  }

  /// APP 切到后台：立即保存所有活跃上下文
  Future<void> _onAppBackground() async {
    for (final ctx in _activeContexts.values) {
      if (ctx.status == ContextStatus.active) {
        await _saveContextImmediate(ctx, InterruptReason.appBackground);
      }
    }
  }

  /// APP 回到前台：根据离台时间决定恢复策略
  Future<void> _onAppForeground() async {
    final now = DateTime.now();
    for (final ctx in _activeContexts.values.toList()) {
      if (ctx.interruptedAt == null) continue;

      final awayDuration = now.difference(ctx.interruptedAt!);

      if (awayDuration.inMinutes < 5) {
        // 短暂离开：直接恢复
        _updateContextStatus(ctx.contextId, ContextStatus.active);
      } else if (awayDuration.inMinutes < 30) {
        // 中等时间：刷新数据
        await _refreshContext(ctx);
        _updateContextStatus(ctx.contextId, ContextStatus.active);
      } else {
        // 长时间：标记需要用户确认
        _updateContextStatus(ctx.contextId, ContextStatus.interrupted);
      }
    }
  }

  /// APP 即将终止：最小化保存
  Future<void> _onAppDetached() async {
    for (final ctx in _activeContexts.values) {
      await _saveContextImmediate(ctx, InterruptReason.systemReclaim);
    }
  }

  // ========== 公开 API ==========

  /// 创建新的学习上下文
  LearningContext createContext({
    required LearningScene scene,
    required SceneContext sceneContext,
    String? sessionId,
    String? subjectId,
    String? subjectName,
    String? chapterId,
    String? chapterName,
  }) {
    final ctx = LearningContext(
      contextId: const Uuid().v4(),
      userId: _currentUserId,
      deviceId: _currentDeviceId,
      scene: scene,
      status: ContextStatus.active,
      createdAt: DateTime.now(),
      updatedAt: DateTime.now(),
      sessionId: sessionId,
      subjectId: subjectId,
      subjectName: subjectName,
      chapterId: chapterId,
      chapterName: chapterName,
      progress: 0.0,
      sceneContext: sceneContext,
      elapsedSeconds: 0,
      syncedToServer: false,
      syncVersion: 0,
    );

    _activeContexts[ctx.contextId] = ctx;
    _scheduleSave(ctx);
    return ctx;
  }

  /// 更新上下文（场景内调用）
  void updateContext({
    required String contextId,
    SceneContext? sceneContext,
    double? progress,
    int? additionalSeconds,
  }) {
    final ctx = _activeContexts[contextId];
    if (ctx == null) return;

    final updated = ctx.copyWith(
      sceneContext: sceneContext ?? ctx.sceneContext,
      progress: progress ?? ctx.progress,
      elapsedSeconds: ctx.elapsedSeconds + (additionalSeconds ?? 0),
      updatedAt: DateTime.now(),
    );

    _activeContexts[contextId] = updated;
    _scheduleDebouncedSave(updated);
  }

  /// 恢复上下文
  Future<LearningContext?> restoreContext(String contextId) async {
    // 1. 从本地加载
    var ctx = _activeContexts[contextId] ?? await _repo.getById(contextId);
    if (ctx == null) return null;

    // 2. 尝试从服务端获取最新
    try {
      final remote = await _syncService.fetchLatest(contextId).timeout(
        const Duration(milliseconds: 500),
      );
      if (remote != null) {
        ctx = _resolveConflict(ctx, remote);
      }
    } catch (_) {
      // 降级使用本地数据
    }

    // 3. 更新状态
    final restored = ctx.copyWith(
      status: ContextStatus.restored,
      restoredAt: DateTime.now(),
      updatedAt: DateTime.now(),
    );

    await _repo.save(restored);
    _activeContexts[contextId] = restored;

    // 4. 通知服务端
    _syncService.confirmRestore(contextId);

    return restored;
  }

  /// 完成上下文
  Future<void> completeContext(String contextId) async {
    final ctx = _activeContexts.remove(contextId);
    if (ctx == null) return;

    final completed = ctx.copyWith(
      status: ContextStatus.completed,
      progress: 1.0,
      updatedAt: DateTime.now(),
    );

    await _repo.save(completed);
    _syncService.reportCompleted(completed);
    _cancelDebouncedSave(contextId);
  }

  /// 获取"继续学习"卡片数据
  Future<List<ContinueLearningItem>> getContinueLearningItems() {
    return _aggregator.aggregate(userId: _currentUserId, maxItems: 3);
  }

  // ========== 内部方法 ==========

  Future<void> _saveContextImmediate(
    LearningContext ctx,
    InterruptReason reason,
  ) async {
    final updated = ctx.copyWith(
      status: ContextStatus.interrupted,
      interruptedAt: DateTime.now(),
      interruptReason: reason,
      updatedAt: DateTime.now(),
    );

    _activeContexts[updated.contextId] = updated;
    await _repo.save(updated);
    _syncService.enqueue(updated);
  }

  void _scheduleDebouncedSave(LearningContext ctx) {
    _debounceTimers[ctx.contextId]?.cancel();
    _debounceTimers[ctx.contextId] = Timer(const Duration(milliseconds: 500), () {
      _repo.save(ctx);
      _syncService.enqueue(ctx);
    });
  }

  void _cancelDebouncedSave(String contextId) {
    _debounceTimers[contextId]?.cancel();
    _debounceTimers.remove(contextId);
  }

  LearningContext _resolveConflict(LearningContext local, LearningContext remote) {
    if (local.syncVersion >= remote.syncVersion) return local;
    return remote;
  }
}
```

```dart
  final TextEditingController _inputController = TextEditingController();

  void initState() {
    super.initState();
    _initContext();

  void _initContext() {

    // 检查是否有可恢复的上下文

      scene: LearningScene.aiChat,
      refId: widget.conversationId,
    );

      _learningContext = existing;
      final ctx = existing.sceneContext as AiChatSceneContext;
      _inputController.text = ctx.inputDraft ?? '';
    } else {
      // 创建新上下文
      _learningContext = manager.createContext(
        scene: LearningScene.aiChat,
        sceneContext: AiChatSceneContext(
          conversationId: widget.conversationId,
          lastMessageId: '',
          messageCount: 0,
          scrollPosition: 0.0,
        ),
      );
    }
  }

  void _onMessageSent(String messageId, int totalMessages) {
    if (_learningContext == null) return;
    final manager = ref.read(learningContextManagerProvider);

    manager.updateContext(
      contextId: _learningContext!.contextId,
      sceneContext: AiChatSceneContext(
        conversationId: widget.conversationId,
        lastMessageId: messageId,
        messageCount: totalMessages,
        scrollPosition: _currentScrollPosition,
        inputDraft: _inputController.text,
      ),
    );
  }

  double get _currentScrollPosition {
    if (!_scrollController.hasClients) return 0.0;
    final max = _scrollController.position.maxScrollExtent;
    if (max == 0) return 0.0;
    return _scrollController.offset / max;
  }

  @override
  void dispose() {
    // 保存输入草稿
    if (_learningContext != null) {
      ref.read(learningContextManagerProvider).updateContext(
        contextId: _learningContext!.contextId,
        sceneContext: AiChatSceneContext(
          conversationId: widget.conversationId,
          lastMessageId: (_learningContext!.sceneContext as AiChatSceneContext).lastMessageId,
          messageCount: (_learningContext!.sceneContext as AiChatSceneContext).messageCount,
          scrollPosition: _currentScrollPosition,
          inputDraft: _inputController.text,
        ),
      );
    }
    _scrollController.dispose();
    _inputController.dispose();
    super.dispose();
  }
}
```

## 11. 错误处理与降级策略

### 11.1 错误码定义

| 错误码 | 含义 | 处理策略 |
|--------|------|----------|
| `CONTEXT_NOT_FOUND` | 本地和服务端均无该上下文 | 清除卡片，引导正常入口 |
| `CONTEXT_EXPIRED` | 上下文超过可恢复窗口 | 清除卡片，提示"学习记录已过期" |
| `CONTEXT_CORRUPTED` | 本地存储数据损坏 | 删除损坏数据，降级到正常入口 |
| `SCENE_DATA_MISSING` | 恢复场景所需的关联数据不存在（如视频已下架） | 提示"内容已更新"，引导到新内容 |
| `IMAGE_FILE_MISSING` | 拍照搜题的临时图片已被清理 | 提示"图片已过期"，引导重新拍照 |
| `SYNC_CONFLICT` | 多设备冲突 | 自动合并或提示用户选择 |
| `SYNC_FAILED` | 服务端同步失败 | 本地继续使用，标记待同步 |
| `RESTORE_TIMEOUT` | 恢复操作超时 | 使用本地缓存数据 |

### 11.2 降级矩阵

| 故障场景 | 降级行为 | 用户感知 |
|----------|----------|----------|
| 本地存储不可用 | 跳过上下文保存，仅内存缓存 | 无卡片，重启后丢失 |
| 服务端不可达 | 仅使用本地数据 | 正常恢复，无跨设备 |
| 本地数据损坏 | 忽略损坏条目，使用下一个 | 可能少一张卡片 |
| 服务端数据损坏 | 以本地为准 | 无感知 |
| 合并冲突无法自动解决 | 以服务端为准，记录日志 | 进度可能轻微回退 |
| 上下文中引用的资源已删除 | 清除该上下文，不展示卡片 | 卡片消失 |

## 12. 性能要求

### 12.1 关键性能指标

| 操作 | 目标延迟 | 说明 |
|------|----------|------|
| P0 保存（切后台） | < 50ms | 本地 Hive 写入 |
| P1 防抖保存 | < 100ms | 异步 Hive 写入 |
| 冷启动恢复本地数据加载 | < 200ms | Hive 读取 + 反序列化 |
| 服务端上下文查询 | < 500ms (P99) | 含网络延迟 |
| 首页"继续学习"卡片渲染 | < 100ms | 数据已在内存 |
| 点击卡片跳转恢复 | < 300ms | 路由 + 初始数据加载 |
| 跨设备恢复 | < 1s | 含服务端请求 |

### 12.2 内存控制

| 数据 | 内存占用 | 策略 |
|------|----------|------|
| 活跃上下文对象 | < 10KB/条 | 最多 5 条活跃上下文常驻内存 |
| "继续学习"卡片列表 | < 5KB | 最多 3 条 |
| 同步队列 | < 50KB | 超过 20 条触发批量上报 |
| Hive Box 全量 | < 500KB | 定期清理过期数据 |

### 12.3 存储控制

| 指标 | 限制 | 清理策略 |
|------|------|----------|
| 单用户上下文条目 | ≤ 50 条 | FIFO 清理最旧的 |
| 单条上下文大小 | ≤ 10KB | sceneContext 控制字段数 |
| 临时图片（拍照搜题） | ≤ 20MB | 超过 24h 自动清理 |
| 同步队列 | ≤ 100 条 | 超出时合并同 contextId 的更新 |

### 12.4 网络优化

- **增量同步**：仅上报 `updatedAt` 之后变更的字段
- **批量上报**：积攒最多 10 条或 2 秒后批量发送
- **请求合并**：同一 contextId 的多次更新合并为最后一次
- **压缩**：sceneContext JSON 使用 gzip 压缩（超过 1KB 时）
- **超时控制**：所有同步请求超时 ≤ 2s，不阻塞 UI
