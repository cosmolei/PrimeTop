# 客户端多媒体选取与处理服务 - 详细设计

> 版本: v1.0 | 更新日期: 2026-05-24 | 状态: 初稿

## 1. 概述

### 1.1 模块定位

客户端多媒体选取与处理服务（Media Kit）是 PrimeTop Flutter 客户端的跨模块基础设施层，为拍照搜题、作文提交、头像上传、客服工单附件、语音输入、口语陪练、背诵检测等多个业务场景提供统一的媒体选取、拍摄、裁剪、压缩、格式转换和权限管理能力。

**核心职责：**
- 提供统一的媒体选取器（相机拍摄 / 相册选择 / 文件选择）
- 提供图片裁剪、旋转、压缩、格式转换管线
- 提供音频录制与管理能力
- 统一处理系统权限请求（相机 / 相册 / 麦克风 / 存储）
- 管理临时文件生命周期与存储配额

**不在本模块范围内：**
- OCR 识别 → 见 `图片处理与OCR识别管线-详细设计.md`
- 语音识别（ASR）→ 见 `语音服务(ASR-TTS)-详细设计.md`
- 文件上传至服务器 → 见 `文件与资源存储服务-详细设计.md`
- 富文本渲染 → 见 `富文本与学科内容渲染引擎-详细设计.md`

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 图片压缩率 | 在保持可辨识质量前提下，图片 ≤ 500KB（拍照搜题）、≤ 200KB（头像） |
| 拍摄到可用 | 从点击拍摄到获得处理后的文件 < 2s |
| 权限体验 | 权限拒绝后提供清晰的引导说明，不阻塞用户流程 |
| 内存占用 | 单张图片处理峰值内存 ≤ 50MB（1024px 以内处理） |
| 音频录制 | 支持 AAC/PCM 格式，采样率 16kHz，码率 64kbps 起步 |

### 1.3 使用场景矩阵

| 业务场景 | 输入类型 | 输出要求 | 最大数量 | 特殊处理 |
|----------|----------|----------|----------|----------|

## 2. 技术选型

### 2.1 核心依赖

| 包名 | 版本 | 用途 | 备注 |
|------|------|------|------|
| `image_picker` | ^1.0+ | 相机拍摄 + 相册选取 | Flutter 官方维护 |
| `image_cropper` | ^8.0+ | 图片裁剪 + 旋转 | 支持自定义 UI |
| `image` | ^4.0+ | Dart 纯图片处理（压缩/缩放/格式转换） | 无 native 依赖 |
| `flutter_sound` | ^9.0+ | 音频录制与播放 | 支持 AAC/PCM |
| `permission_handler` | ^11.0+ | 统一权限管理 | 支持 iOS/Android |
| `path_provider` | ^2.0+ | 临时目录/缓存目录路径 | Flutter 官方 |
| `photo_manager` | ^3.0+ | 相册多选（需精细控制时使用） | 替代 image_picker 的多选场景 |
| `uuid` | ^4.0+ | 生成临时文件唯一名称 | |

### 2.2 选型决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 图片压缩 | Dart `image` 包 | 纯 Dart 实现，无 native 依赖，压缩质量可精确控制，跨平台一致 |
| 裁剪方案 | `image_cropper` | 社区维护良好，支持自定义 UI（分龄适配），支持旋转/缩放/自由裁剪 |
| 多选方案 | `image_picker`（≤5张） / `photo_manager`（>5张） | image_picker 简单但不支持多选上限控制；大量多选用 photo_manager |
| 录音格式 | AAC（默认）/ PCM（语音识别场景） | AAC 压缩率高适合上传；PCM 无损适合实时 ASR 流 |
| 临时文件管理 | 自建 TempFileManager | 确保生命周期可控，定时清理，配额限制 |

## 5. 图片处理管线详细设计

### 5.1 ImageProcessor 处理流程

```
输入源（原始图片）
     │
     ▼
┌─────────────┐
│ 1. EXIF 旋转  │  ← 根据方向信息自动旋转
└──────┬──────┘
       ▼
┌─────────────┐
│ 2. 尺寸缩放   │  ← 超过 maxDimension 等比缩放
└──────┬──────┘
       ▼
┌─────────────┐
│ 3. 裁剪       │  ← enableCrop=true 时弹出裁剪 UI
└──────┬──────┘
       ▼
┌─────────────┐
│ 4. 质量压缩   │  ← 迭代压缩直到满足 maxFileSize
└──────┬──────┘
       ▼
┌─────────────┐
│ 5. 格式转换   │  → JPEG / PNG / WebP
└──────┬──────┘
       ▼
┌─────────────┐
│ 6. 缩略图生成  │  ← 64px 宽缩略图（嵌入结果）
└──────┬──────┘
       ▼
  输出 → 临时文件
```

### 5.2 ImageProcessor 实现

```dart
class ImageProcessor {
  /// 处理图片（完整管线）
  Future<ImagePickerResult> process({
    required String inputPath,
    required ImagePickerConfig config,
  }) async {
    var image = img.decodeImage(await File(inputPath).readAsBytes());
    if (image == null) throw MediaException('无法解码图片');

    // Step 1: EXIF 旋转纠正
    image = _fixExifRotation(image, inputPath);

    // Step 2: 尺寸缩放
    image = _resizeIfNeeded(image, config.maxDimension);

    // Step 3: 裁剪（如果配置需要且由调用方传入裁剪区域）
    // 注意：裁剪 UI 由 CropService 在选取阶段完成，
    // 此处仅处理已确定裁剪区域的情况

    // Step 4 & 5: 压缩 + 格式输出
    final outputPath = await _compressAndSave(
      image,
      config.format,
      config.maxFileSize,
    );

    // Step 6: 缩略图
    final thumbnail = _generateThumbnail(image);

    final outputFile = File(outputPath);
    return ImagePickerResult(
      filePath: outputPath,
      fileSize: await outputFile.length(),
      width: image.width,
      height: image.height,
      thumbnailBytes: thumbnail,
      source: MediaSource.camera, // 由调用方覆盖
    );
  }

  /// EXIF 方向纠正
  img.Image _fixExifRotation(img.Image image, String path) {
    // 读取 EXIF 数据
    final bytes = File(path).readAsBytesSync();
    final exif = readExifFromBytes(bytes);

    if (exif == null) return image;

    final orientation = exif['Image Orientation'];
    if (orientation == null) return image;

    // 根据方向值旋转
    switch (orientation.printable) {
      case 'Rotated 90 CCW':
        return img.copyRotate(image, angle: 90);
      case 'Rotated 180':
        return img.copyRotate(image, angle: 180);
      case 'Rotated 90 CW':
        return img.copyRotate(image, angle: -90);
      case 'Rotated 90 CCW + Flipped':
        final rotated = img.copyRotate(image, angle: 90);
        return img.flipVertical(rotated);
      case 'Rotated 90 CW + Flipped':
        final rotated = img.copyRotate(image, angle: -90);
        return img.flipVertical(rotated);
      default:
        return image;
    }
  }

  /// 等比缩放
  img.Image _resizeIfNeeded(img.Image image, int maxDimension) {
    if (image.width <= maxDimension && image.height <= maxDimension) {
      return image;
    }

    final ratio = maxDimension / max(image.width, image.height);
    return img.copyResize(
      image,
      width: (image.width * ratio).round(),
      height: (image.height * ratio).round(),
      interpolation: img.Interpolation.average, // 缩小用平均采样，质量好
    );
  }

  /// 迭代压缩直到满足大小限制
  Future<String> _compressAndSave(
    img.Image image,
    ImageOutputFormat format,
    int maxFileSize,
  ) async {
    final tempDir = await getTemporaryDirectory();
    final fileName = '${const Uuid().v4()}.${_extension(format)}';
    final outputPath = '${tempDir.path}/media_kit/$fileName';

    await Directory(path.dirname(outputPath)).create(recursive: true);

    // 二分查找最优质量
    int quality = 85;
    int low = 10, high = 85;
    Uint8List? bytes;

    // 先试一次高质量
    bytes = _encodeImage(image, format, quality);

    if (bytes.length <= maxFileSize) {
      // 高质量已满足，直接保存
      await File(outputPath).writeAsBytes(bytes);
      return outputPath;
    }

    // 二分搜索满足大小限制的最高质量
    while (low < high) {
      quality = (low + high + 1) ~/ 2;
      bytes = _encodeImage(image, format, quality);
      if (bytes.length <= maxFileSize) {
        low = quality;
      } else {
        high = quality - 1;
      }
    }

    // 使用最终质量重新编码
    quality = low;
    bytes = _encodeImage(image, format, quality);

    // 如果最低质量仍然超限，缩小尺寸后重试
    if (bytes.length > maxFileSize && quality == 10) {
      final scaled = img.copyResize(
        image,
        width: (image.width * 0.75).round(),
        height: (image.height * 0.75).round(),
      );
      bytes = _encodeImage(scaled, format, 75);
    }

    await File(outputPath).writeAsBytes(bytes);
    return outputPath;
  }

  Uint8List _encodeImage(img.Image image, ImageOutputFormat format, int quality) {
    switch (format) {
      case ImageOutputFormat.jpeg:
        return Uint8List.fromList(img.encodeJpg(image, quality: quality));
      case ImageOutputFormat.png:
        return Uint8List.fromList(img.encodePng(image)); // PNG 不支持质量参数
      case ImageOutputFormat.webp:
        return Uint8List.fromList(img.encodeWebp(image, quality: quality));
    }
  }

  /// 生成缩略图（64px 宽）
  Uint8List _generateThumbnail(img.Image image) {
    final thumbnail = img.copyResize(image, width: 64);
    return Uint8List.fromList(img.encodeJpg(thumbnail, quality: 70));
  }

  String _extension(ImageOutputFormat format) => switch (format) {
    ImageOutputFormat.jpeg => 'jpg',
    ImageOutputFormat.png  => 'png',
    ImageOutputFormat.webp => 'webp',
  };
}
```

```dart
class AudioRecorderService {
  final AudioSessionManager _audioSession;
  FlutterSoundRecorder? _recorder;
  bool _isRecording = false;
  String? _currentRecordingPath;

  AudioRecorderService({required AudioSessionManager audioSession})
      : _audioSession = audioSession;

  bool get isRecording => _isRecording;

  /// 当前录音时长流
  Stream<Duration>? get onProgress => _recorder?.onProgress;

  /// 音量流（用于波形可视化）
  Stream<double>? get onLevel => _recorder?.onProgress
      .map((event) => event.decibels ?? 0.0);

  /// 开始录音
  Future<void> start({
    required AudioRecorderConfig config,
  }) async {
    if (_isRecording) throw MediaException('已在录音中');

    // 确保音频会话正确配置
    await _audioSession.configureForRecording(
      config.format == AudioOutputFormat.pcm16
        ? AudioSessionCategory.record
        : AudioSessionCategory.playAndRecord,
    );

    // 检查权限
    final hasPermission = await Permission.microphone.request();
    if (!hasPermission.isGranted) {
      throw MediaPermissionException(Permission.microphone);
    }

    // 初始化录音器
    _recorder = FlutterSoundRecorder();
    await _recorder!.openRecorder();

    // 准备临时文件
    final tempDir = await getTemporaryDirectory();
    final ext = _extension(config.format);
    _currentRecordingPath =
        '${tempDir.path}/media_kit/rec_${const Uuid().v4()}.$ext';
    await Directory(path.dirname(_currentRecordingPath!))
        .create(recursive: true);

    // 开始录音
    await _recorder!.startRecorder(
      toFile: _currentRecordingPath,
      codec: _codec(config.format),
      sampleRate: config.sampleRate,
      bitRate: config.bitRate,
    );

    _isRecording = true;

    // 最大时长自动停止
    if (config.maxDuration.inSeconds > 0) {
      Future.delayed(config.maxDuration, () {
        if (_isRecording) stop();
      });
    }
  }

  /// 停止录音，返回结果
  Future<AudioPickerResult> stop() async {
    if (!_isRecording || _recorder == null) {
      throw MediaException('未在录音中');
    }

    await _recorder!.stopRecorder();
    _isRecording = false;

    final path = _currentRecordingPath!;
    final file = File(path);

    if (!await file.exists()) {
      throw MediaException('录音文件不存在');
    }

    // 获取录音信息
    final duration = await _recorder!.decoderSession?.duration ??
        Duration.zero;

    await _recorder!.closeRecorder();
    _recorder = null;

    return AudioPickerResult(
      filePath: path,
      fileSize: await file.length(),
      source: MediaSource.microphone,
      duration: duration,
      sampleRate: 16000, // 从 config 传入
      format: AudioOutputFormat.aac,
    );
  }

  /// 取消录音（删除临时文件）
  Future<void> cancel() async {
    if (_isRecording) {
      await _recorder?.stopRecorder();
      _isRecording = false;
    }
    if (_currentRecordingPath != null) {
      final file = File(_currentRecordingPath!);
      if (await file.exists()) await file.delete();
    }
    await _recorder?.closeRecorder();
    _recorder = null;
  }

  /// 释放资源
  Future<void> dispose() async {
    await cancel();
  }

  Codec _codec(AudioOutputFormat format) => switch (format) {
    AudioOutputFormat.aac  => Codec.aacADTS,
    AudioOutputFormat.pcm16 => Codec.pcm16,
    AudioOutputFormat.wav  => Codec.pcm16,
  };

  String _extension(AudioOutputFormat format) => switch (format) {
    AudioOutputFormat.aac  => 'aac',
    AudioOutputFormat.pcm16 => 'pcm',
    AudioOutputFormat.wav  => 'wav',
  };
}
```

```dart
class PermissionManager {
  /// 权限状态缓存
  final Map<Permission, PermissionStatus> _cache = {};

  /// 请求权限（带引导流程）
  ///
  /// 流程：
  /// 1. 检查当前状态
  /// 2. 如果未请求过 → 系统权限弹窗
  /// 3. 如果被拒绝 → 显示引导对话框
  /// 4. 如果永久拒绝 → 引导到系统设置
  Future<PermissionStatus> requestWithGuide({
    required BuildContext context,
    required Permission permission,
    required PermissionGuideConfig config,
  }) async {
    // Step 1: 检查当前状态
    final status = await permission.status;
    _cache[permission] = status;

    switch (status) {
      case PermissionStatus.granted:
      case PermissionStatus.limited:
        return status;

      case PermissionStatus.denied:
        // Step 2: 首次请求
        final result = await permission.request();
        _cache[permission] = result;

        if (result.isGranted || result.isLimited) return result;

        // Step 3: 被拒绝 → 显示引导对话框
        if (context.mounted) {
          final shouldOpenSettings = await _showPermissionGuideDialog(
            context: context,
            config: config,
          );

          if (shouldOpenSettings == true) {
            // Step 4: 引导到系统设置
            await openAppSettings();
            // 从设置返回后重新检查
            final afterSettings = await permission.status;
            _cache[permission] = afterSettings;
            return afterSettings;
          }
        }

        return result;

      case PermissionStatus.permanentlyDenied:
        // 直接引导到系统设置
        if (context.mounted) {
          final shouldOpen = await _showPermissionGuideDialog(
            context: context,
            config: config,
          );
          if (shouldOpen == true) {
            await openAppSettings();
            final afterSettings = await permission.status;
            _cache[permission] = afterSettings;
            return afterSettings;
          }
        }
        return status;

      case PermissionStatus.restricted:
        return status;

      case PermissionStatus.provisional:
        return status;
    }
  }

  /// 获取缓存的权限状态
  PermissionStatus? getCachedStatus(Permission permission) => _cache[permission];

  /// 检查是否有权限（不弹窗）
  Future<bool> check(Permission permission) async {
    final status = await permission.status;
    _cache[permission] = status;
    return status.isGranted || status.isLimited;
  }
}
```

### 8.1 TempFileManager

```dart
class TempFileManager {
  final int maxTotalSize;
  final Duration maxFileAge;
  final String _subDir = 'media_kit';

  TempFileManager({
    required this.maxTotalSize,
    required this.maxFileAge,
  });

  /// 获取临时目录
  Future<Directory> get _tempDir async {
    final base = await getTemporaryDirectory();
    final dir = Directory('${base.path}/$_subDir');
    if (!await dir.exists()) await dir.create(recursive: true);
    return dir;
  }

  /// 注册一个临时文件（用于追踪）
  Future<void> registerFile(String filePath, {int? estimatedSize}) async {
    final meta = _TempFileMeta(
      path: filePath,
      registeredAt: DateTime.now(),
      size: estimatedSize ?? await File(filePath).length(),
    );
    await _saveMeta(meta);
  }

  /// 清理过期文件
  Future<int> cleanup() async {
    final dir = await _tempDir;
    if (!await dir.exists()) return 0;

    var deletedCount = 0;
    final now = DateTime.now();

    await for (final entity in dir.list()) {
      if (entity is File) {
        final stat = await entity.stat();
        if (now.difference(stat.modified) > maxFileAge) {
          await entity.delete();
          deletedCount++;
        }
      }
    }

    // 检查总大小配额
    await _enforceQuota();

    return deletedCount;
  }

  /// 强制清理超出配额的旧文件（LRU）
  Future<void> _enforceQuota() async {
    final dir = await _tempDir;
    final files = <File>[];

    await for (final entity in dir.list()) {
      if (entity is File && !entity.path.endsWith('.meta')) {
        files.add(entity);
      }
    }

    // 按修改时间排序（旧→新）
    files.sort((a, b) async {
      final sa = await a.stat();
      final sb = await b.stat();
      return sa.modified.compareTo(sb.modified);
    });

    // 计算总大小
    var totalSize = 0;
    for (final f in files) {
      totalSize += await f.length();
    }

    // 删除最旧的文件直到满足配额
    var index = 0;
    while (totalSize > maxTotalSize && index < files.length) {
      final file = files[index];
      final size = await file.length();
      await file.delete();
      totalSize -= size;
      index++;
    }
  }

  /// 清理所有临时文件（退出登录/切换账号时调用）
  Future<void> clearAll() async {
    final dir = await _tempDir;
    if (await dir.exists()) {
      await dir.delete(recursive: true);
      await dir.create(recursive: true);
    }
  }

  Future<void> _saveMeta(_TempFileMeta meta) async {
    final metaFile = File('${meta.path}.meta');
    await metaFile.writeAsString(jsonEncode({
      'path': meta.path,
      'registeredAt': meta.registeredAt.toIso8601String(),
      'size': meta.size,
    }));
  }
}

class _TempFileMeta {
  final String path;
  final DateTime registeredAt;
  final int size;

  _TempFileMeta({
    required this.path,
    required this.registeredAt,
    required this.size,
  });
}
```

### 10.3 全局错误拦截

```dart
/// MediaKit 统一错误处理包装器
Future<T?> withMediaErrorHandler<T>({
  required BuildContext context,
  required Future<T> Function() action,
  String? fallbackMessage,
}) async {
  try {
    return await action();
  } on MediaPermissionException catch (e) {
    // 权限异常已在 PermissionManager 中引导处理
    return null;
  } on StorageFullException catch (_) {
    if (context.mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('存储空间不足，正在清理...')),
      );
    }
    // 自动清理后可重试
    return null;
  } on ImageProcessException catch (e) {
    if (context.mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text(fallbackMessage ?? '图片处理失败，请重试')),
      );
    }
    // 上报错误
    _reportError('image_process', e.stage, e.originalError);
    return null;
  } on AudioRecordException catch (e) {
    if (context.mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text(fallbackMessage ?? '录音失败，请重试')),
      );
    }
    _reportError('audio_record', e.stage, e.originalError);
    return null;
  } on Exception catch (e) {
    if (context.mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text(fallbackMessage ?? '操作失败，请重试')),
      );
    }
    _reportError('unknown', '', e);
    return null;
  }
}
```

## 12. 性能优化

### 12.1 内存优化

```dart
/// 大图安全解码器 — 分块解码，避免 OOM
class SafeImageDecoder {
  /// 解码图片，带内存保护
  ///
  /// 对于超大图片（> 4096px），先缩放再解码
  static Future<img.Image> decodeSafely(Uint8List bytes) async {
    // 快速检测图片尺寸（不解码完整图片）
    final imageSize = _decodeImageSize(bytes);

    if (imageSize != null &&
        (imageSize.$1 > 4096 || imageSize.$2 > 4096)) {
      // 大图：先缩放到 4096 再解码
      final command = img.Command()
        ..decodeImage(bytes)
        ..copyResize(width: 4096, interpolation: img.Interpolation.average);
      final result = await command.executeQuery();
      return result.image!;
    }

    // 普通图片：直接解码
    return img.decodeImage(bytes)!;
  }

  /// 快速读取图片尺寸（只读头部信息）
  static (int, int)? _decodeImageSize(Uint8List bytes) {
    final image = img.decodeImage(bytes);
    return image != null ? (image.width, image.height) : null;
  }
}
```

```dart
  @override
  Map<String, dynamic> build() => {
    'pick_count_today': 0,
    'process_count_today': 0,
    'error_count_today': 0,
    'avg_process_duration_ms': 0,
    'avg_compression_ratio': 0.0,
    'temp_storage_mb': 0,
  };

  void recordProcess({
    required String scene,
    required int durationMs,
    required int originalSize,
    required int outputSize,
  }) {
    final current = Map<String, dynamic>.from(state);
    current['process_count_today'] =
        (current['process_count_today'] as int) + 1;

    // 更新平均处理时长
    final currentAvg = current['avg_process_duration_ms'] as double;
    final count = current['process_count_today'] as int;
    current['avg_process_duration_ms'] =
        (currentAvg * (count - 1) + durationMs) / count;

    // 更新平均压缩率
    final ratio = outputSize / originalSize;
    final currentRatio = current['avg_compression_ratio'] as double;
```
