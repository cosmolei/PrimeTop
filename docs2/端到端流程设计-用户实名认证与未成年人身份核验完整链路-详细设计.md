# 端到端流程设计 - 用户实名认证与未成年人身份核验完整链路

## 1. 概述

### 1.1 文档目的

详细设计用户从触发实名认证到完成未成年人身份核验、监护人绑定及各下游模块联动的完整链路。涵盖认证触发、信息采集、第三方核验、结果判定、状态同步、异常处理和降级方案的全流程，使开发人员可直接参照编码。

### 1.2 流程范围

| 阶段 | 起点 | 终点 |
|------|------|------|
| 认证触发 | 功能使用/支付/登录等场景判定需实名 | 认证引导页展示 |
| 信息采集 | 用户进入认证页 | 身份信息提交 |
| 第三方核验 | 身份信息提交 | 核验结果返回 |
| 结果判定 | 核验结果返回 | 成年/未成年/核验失败 |
| 监护人绑定 | 判定为未成年 | 监护人关系确认完成 |
| 联动生效 | 认证完成 | 防沉迷/支付限额/家长中心同步 |
| 重新认证 | 认证过期/信息变更/用户主动申请 | 新认证结果生效 |

### 1.3 合规依据

| 法规 | 关键要求 |
|------|----------|
| 《未成年人保护法》 | 网络产品应验证用户年龄，对未成年人实施保护 |
| 《个人信息保护法》 | 处理不满14周岁未成年人信息需监护人同意 |
| 《关于防止未成年人沉迷网络游戏的通知》 | 实名注册、时段控制、时长限制、付费限制 |
| 《儿童个人信息网络保护规定》 | 处理不满14周岁儿童信息需监护人明示同意 |
| 教育部《关于引导规范教育移动互联网应用有序健康发展的意见》 | 教育APP应落实实名认证和内容审核 |

### 1.4 设计原则

1. **渐进式触发**：根据使用场景逐步要求不同级别的认证，避免注册即要求身份证
2. **隐私最小化**：仅采集必要身份信息，敏感数据加密存储、脱敏展示
3. **用户体验友好**：认证流程尽量简短，OCR 辅助减少手动输入
4. **降级容灾**：第三方核验不可用时有降级方案
5. **审计可追溯**：所有认证操作留存完整审计日志

## 4. 分步骤详细设计

### 4.1 LEVEL-1：手机号实名（基础级）

#### 4.1.1 流程说明

手机号实名在注册阶段自动完成，通过运营商三要素验证（手机号 + 姓名 + 身份证号）实现。但由于注册时仅采集手机号（通过验证码），本级别仅表示"手机号已验证"，不构成完整实名。

**关键点：** 手机号验证 ≠ 实名认证。手机号仅作为基础联系方式验证，认证状态为 `PHONE_ONLY`。

#### 4.1.2 数据模型

```sql
-- 用户认证记录表
CREATE TABLE user_verification (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT NOT NULL REFERENCES users(id),
    
    -- 认证级别
    verification_level VARCHAR(20) NOT NULL DEFAULT 'PHONE_ONLY',
    -- 认证状态: PENDING / IN_PROGRESS / VERIFIED / FAILED / EXPIRED
    status          VARCHAR(20) NOT NULL DEFAULT 'PENDING',
    
    -- 手机号信息
    phone_number    VARCHAR(20),
    phone_verified  BOOLEAN DEFAULT FALSE,
    phone_verified_at TIMESTAMPTZ,
    
    -- 身份证信息（加密存储）
    id_card_hash    VARCHAR(128),  -- 身份证号哈希，用于去重校验
    id_card_holder  BYTEA,          -- 姓名 AES 加密
    id_card_number  BYTEA,          -- 身份证号 AES 加密
    id_card_verified_at TIMESTAMPTZ,
    
    -- 人脸识别
    face_verified   BOOLEAN DEFAULT FALSE,
    face_verified_at TIMESTAMPTZ,
    face_photo_hash VARCHAR(128),   -- 人脸照片哈希
    
    -- 年龄判定结果
    birth_date      DATE,           -- 由身份证号推算
    age             INT,            -- 核验时年龄
    is_minor        BOOLEAN,        -- 是否未成年（<18岁）
    is_child        BOOLEAN,        -- 是否儿童（<14岁）
    
    -- 第三方核验
    verification_provider VARCHAR(50),  -- ALIYUN / TENCENT / MINSHENG
    verification_request_id VARCHAR(128),
    verification_raw_result JSONB,      -- 原始返回（脱敏后存储）
    
    -- 审计
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    expired_at      TIMESTAMPTZ,      -- 认证过期时间
    ip_address      INET,
    device_fingerprint VARCHAR(128),
    
    -- 索引
    CONSTRAINT uq_user_verification_user UNIQUE (user_id)
);

CREATE INDEX idx_user_verification_status ON user_verification(status);
CREATE INDEX idx_user_verification_id_card_hash ON user_verification(id_card_hash);
```

**后端处理流程：**

```typescript
async function processIDCardVerification(
  request: IDCardVerificationRequest,
  userId: bigint
): Promise<VerificationResult> {
  const correlationId = generateCorrelationId();
  
  // 1. 基础校验
  // 1.1 协议确认检查
  if (!request.agreementsAccepted) {
    throw new BusinessError('AGREEMENT_NOT_ACCEPTED', '请先同意相关协议');
  }
  
  // 1.2 身份证号格式校验（加权校验码）
  if (!isValidIDCardNumber(request.idCardNumber)) {
    throw new BusinessError('INVALID_ID_FORMAT', '身份证号格式不正确');
  }
  
  // 1.3 身份证有效期检查
  if (request.ocrResult && request.ocrResult.validPeriod) {
    const endDate = request.ocrResult.validPeriod.end;
    if (endDate !== '长期' && new Date(endDate) < new Date()) {
      throw new BusinessError('ID_CARD_EXPIRED', '身份证已过期');
    }
  }
  
  // 1.4 姓名一致性校验（OCR vs 手动输入）
  if (request.ocrResult && request.name !== request.ocrResult.name) {
    throw new BusinessError('NAME_MISMATCH', 
      'OCR识别姓名与输入姓名不一致，请核实');
  }
  
  // 2. 去重校验
  const idCardHash = sha256(request.idCardNumber);
  const existingUser = await verificationRepo.findByIdCardHash(idCardHash);
  if (existingUser && existingUser.userId !== userId) {
    // 同一身份证号已绑定其他账号
    throw new BusinessError('ID_CARD_ALREADY_BOUND', 
      '该身份证号已绑定其他账号，如需更换请先解绑');
  }
  
  // 3. 年龄预判定（由身份证号直接计算，不依赖第三方）
  const birthDate = extractBirthDateFromID(request.idCardNumber);
  const age = calculateAge(birthDate);
  const isMinor = age < 18;
  const isChild = age < 14;
  
  // 4. 调用第三方实名核验（二要素：姓名+身份证号）
  let verifyResult: ThirdPartyVerifyResult;
  try {
    verifyResult = await callThirdPartyVerification({
      name: request.name,
      idNumber: request.idCardNumber,
      // 优先使用阿里云，失败切换腾讯云
      preferredProvider: 'ALIYUN',
    });
  } catch (error) {
    // 第三方服务异常 → 降级方案
    logger.error('Third party verification failed', {
      correlationId, error, userId 
    });
    
    // 降级策略：仅基于格式校验+OCR结果进行初步认证
    // 有效期7天，后续需要补验
    return await downgradeVerification(userId, {
      name: request.name,
      idCardNumber: request.idCardNumber,
      birthDate,
      age,
      isMinor,
      isChild,
      reason: 'THIRD_PARTY_UNAVAILABLE',
      validDays: 7,
    });
  }
  
  // 5. 处理核验结果
  if (!verifyResult.verified) {
    // 核验不通过
    await recordVerificationAttempt(userId, {
      level: 'ID_CARD',
      result: 'FAILED',
      reason: verifyResult.failReason,
      provider: verifyResult.provider,
      correlationId,
    });
    
    throw new BusinessError('VERIFICATION_FAILED', 
      '身份信息核验未通过，请检查姓名和身份证号是否正确');
  }
  
  // 6. 核验通过 → 更新认证状态
  const verification = await verificationRepo.upsert(userId, {
    verificationLevel: 'ID_CARD',
    status: 'VERIFIED',
    idCardHash,
    idCardHolder: encryptAES(request.name),
    idCardNumber: encryptAES(request.idCardNumber),
    idCardVerifiedAt: new Date(),
    birthDate,
    age,
    isMinor,
    isChild,
    verificationProvider: verifyResult.provider,
    verificationRequestId: verifyResult.requestId,
    verificationRawResult: sanitizeResult(verifyResult.raw),
    expiredAt: calculateExpiryDate(isMinor), // 未成年1年，成年2年
    ipAddress: request.ip,
    deviceFingerprint: request.deviceFingerprint,
  });
  
  // 7. 审计日志
  await auditLog.record({
    action: 'ID_CARD_VERIFIED',
    userId,
    details: {
      level: 'ID_CARD',
      isMinor,
      isChild,
      age,
      provider: verifyResult.provider,
    },
    correlationId,
  });
  
  // 8. 异步联动下游模块
  await eventBus.publish('user.verification.completed', {
    userId,
    verificationLevel: 'ID_CARD',
    isMinor,
    isChild,
    age,
    correlationId,
  });
  
  return {
    success: true,
    isMinor,
    isChild,
    age,
    nextStep: isMinor ? 'GUARDIAN_BINDING' : 'COMPLETED',
  };
}
```

```typescript
async function processFaceVerification(
  userId: bigint,
  videoFile: File,
  livenessType: string
): Promise<FaceVerificationResult> {
  // 1. 前置检查：必须已通过身份证核验
  const verification = await verificationRepo.findByUserId(userId);
  if (!verification || verification.verificationLevel === 'PHONE_ONLY') {
    throw new BusinessError('ID_CARD_REQUIRED', 
      '请先完成身份证核验');
  }
  
  // 2. 活体检测
  const livenessResult = await faceService.detectLiveness({
    videoBuffer: await videoFile.arrayBuffer(),
    type: livenessType,
  });
  
  if (!livenessResult.isLive) {
    await recordVerificationAttempt(userId, {
      level: 'FACE',
      result: 'FAILED',
      reason: 'LIVENESS_FAILED',
    });
    throw new BusinessError('LIVENESS_CHECK_FAILED', '活体检测未通过');
  }
  
  // 3. 与身份证照片比对（1:1比对）
  const idCardPhotoKey = await getIDCardPhotoKey(verification.idCardHash);
  const compareResult = await faceService.compare1To1({
    sourceImage: livenessResult.bestFrame,
    targetImageKey: idCardPhotoKey,
  });
  
  // 4. 比对阈值判定
  const THRESHOLD = 0.75; // 相似度阈值
  const passed = compareResult.similarity >= THRESHOLD;
  
  // 5. 更新认证状态
  if (passed) {
    await verificationRepo.updateFaceVerification(userId, {
      faceVerified: true,
      faceVerifiedAt: new Date(),
      facePhotoHash: sha256(livenessResult.bestFrame),
    });
    
    await eventBus.publish('user.verification.face_passed', {
      userId,
      similarity: compareResult.similarity,
    });
  } else {
    await recordVerificationAttempt(userId, {
      level: 'FACE',
      result: 'FAILED',
      reason: 'FACE_MISMATCH',
      details: { similarity: compareResult.similarity },
    });
  }
  
  return {
    success: passed,
    similarity: compareResult.similarity,
    threshold: THRESHOLD,
  };
}
```

```typescript
async function bindGuardian(
  minorUserId: bigint,
  request: GuardianBindingRequest
): Promise<GuardianBindingResult> {
  // 1. 前置校验
  const minorVerification = await verificationRepo.findByUserId(minorUserId);
  if (!minorVerification || !minorVerification.isChild) {
    throw new BusinessError('NOT_A_CHILD', '目标用户不是儿童（<14岁）');
  }
  
  if (!request.childPrivacyPolicyAccepted) {
    throw new BusinessError('POLICY_NOT_ACCEPTED', 
      '请先同意《儿童隐私保护规则》');
  }
  
  // 2. 监护人身份核验
  let guardianVerified = false;
  
  switch (request.bindingMethod) {
    case 'PHONE_SMS': {
      // 验证短信验证码已在前一步完成，此处校验监护人手机号
      const smsVerified = await smsService.verifyCode(
        request.guardianInfo.phone, 
        request.smsCode!
      );
      if (smsVerified) {
        // 进一步：核验监护人身份
        const guardianCheck = await thirdPartyVerify.verify({
          name: request.guardianInfo.name,
          idNumber: request.guardianInfo.idCardNumber,
        });
        guardianVerified = guardianCheck.verified;
      }
      break;
    }
      
    case 'PARENT_APP_SCAN': {
      // 家长端扫码确认，校验家长端传来的 token
      const scanToken = await cacheService.get(
        `guardian_scan:${request.scanToken}`
      );
      if (scanToken && scanToken.parentUserId) {
        // 验证家长端账号本身已实名
        const parentVerification = await verificationRepo.findByUserId(
          scanToken.parentUserId
        );
        guardianVerified = parentVerification?.status === 'VERIFIED';
      }
      break;
    }
      
    case 'ID_CARD': {
      // 监护人现场实名核验
      const guardianCheck = await thirdPartyVerify.verify({
        name: request.guardianInfo.name,
        idNumber: request.guardianInfo.idCardNumber,
      });
      guardianVerified = guardianCheck.verified;
      break;
    }
  }
  
  if (!guardianVerified) {
    throw new BusinessError('GUARDIAN_VERIFICATION_FAILED', 
      '监护人身份核验未通过');
  }
  
  // 3. 创建绑定关系
  const binding = await guardianBindingRepo.create({
    minorUserId,
    guardianName: encryptAES(request.guardianInfo.name),
    guardianPhone: encryptAES(request.guardianInfo.phone),
    guardianIdHash: sha256(request.guardianInfo.idCardNumber),
    relationship: request.guardianInfo.relationship,
    bindingMethod: request.bindingMethod,
    status: 'ACTIVE',
    consentDocument: 'CHILD_PRIVACY_POLICY_V1',
    consentDate: new Date(),
    expiresAt: calculateMinorExpiry(minorVerification.birthDate), // 到成年
  });
  
  // 4. 联动：激活防沉迷（加强版）
  await antiAddictionService.activateStrictMode(minorUserId, {
    dailyLimitMinutes: getDailyLimitByAge(minorVerification.age),
    allowedHours: MINOR_ROUTING[classifyAgeGroup(minorVerification.age)].allowedHours,
  });
  
  // 5. 联动：设置支付限额
  await paymentService.setMinorLimits(minorUserId, {
    dailyLimit: MINOR_ROUTING[classifyAgeGroup(minorVerification.age)].dailyPaymentLimit,
    monthlyLimit: MINOR_ROUTING[classifyAgeGroup(minorVerification.age)].monthlyPaymentLimit,
  });
  
  // 6. 联动：通知家长端
  await notificationService.notifyGuardian(binding.id, {
    type: 'GUARDIAN_BINDING_CONFIRMED',
    minorName: await getMaskedName(minorUserId),
    message: '您的孩子已完成实名认证，监护关系已确认。',
  });
  
  // 7. 审计日志
  await auditLog.record({
    action: 'GUARDIAN_BOUND',
    userId: minorUserId,
    details: {
      guardianIdHash: sha256(request.guardianInfo.idCardNumber),
      relationship: request.guardianInfo.relationship,
      bindingMethod: request.bindingMethod,
    },
  });
  
  return {
    success: true,
    bindingId: binding.id,
    antiAddictionActivated: true,
    paymentLimitsSet: true,
  };
}
```

```typescript
async function antiAddictionInterceptor(
  request: Request,
  userId: bigint

  // 1. 获取用户认证信息
  const verification = await verificationRepo.findByUserId(userId);

  if (rules.allowedHours.start > currentHour || 
      currentHour >= rules.allowedHours.end) {
    return {
      allowed: false,
      reason: 'CURFEW',
      message: `当前时间为${currentHour}点，未成年人允许使用时段为${rules.allowedHours.start}:00-${rules.allowedHours.end}:00`,
      nextAllowedTime: getNextAllowedTime(rules.allowedHours.start),
    };
  }
  
  // 3. 每日时长检查
  const todayUsage = await usageStatsService.getDailyUsage(userId, now);
  const isWeekend = now.getDay() === 0 || now.getDay() === 6;
  const dailyLimit = isWeekend 
    ? rules.weekendLimitMinutes 
    : rules.weekdayLimitMinutes;
    
  if (todayUsage.totalMinutes >= dailyLimit) {
    return {
      allowed: false,
      reason: 'DAILY_LIMIT_EXCEEDED',
      message: `今日学习时长已达${dailyLimit}分钟上限`,
      resetTime: getTomorrowStart(),
    };
  }
  
  // 4. 连续使用提醒
  if (rules.forceBreakReminder && 
      todayUsage.continuousMinutes >= rules.continuousUsageReminderMinutes) {
    return {
      allowed: true,
      warning: {
        type: 'CONTINUOUS_USAGE',
        message: `你已连续学习${rules.continuousUsageReminderMinutes}分钟，建议休息一下`,
        action: 'SHOW_BREAK_DIALOG',
      },
    };
  }
  
  return { allowed: true };
}
```

```typescript
/**
 * 支付限额检查（在支付前拦截）
 */
async function checkPaymentLimit(
  userId: bigint,
  amount: number
): Promise<PaymentLimitResult> {
  const verification = await verificationRepo.findByUserId(userId);
  
  // 成年人无限制（但需要实名认证）
  if (!verification?.isMinor) {
    if (verification?.status !== 'VERIFIED') {
      return {
        allowed: false,
        reason: 'VERIFICATION_REQUIRED',
        message: '请先完成实名认证',
      };
    }
    return { allowed: true };
  }
  
  const ageGroup = classifyAgeGroup(verification.age);
  const strategy = MINOR_ROUTING[ageGroup];
  
  // 查询今日/本月已支付金额
  const todayPaid = await paymentRepo.getDailyPaidAmount(userId);
  const monthPaid = await paymentRepo.getMonthlyPaidAmount(userId);
  
  // 检查日限额
  if (strategy.dailyPaymentLimit >= 0 && 
      todayPaid + amount > strategy.dailyPaymentLimit) {
    return {
      allowed: false,
      reason: 'DAILY_LIMIT_EXCEEDED',
      message: `未成年人每日支付限额${strategy.dailyPaymentLimit}元`,
      remaining: Math.max(0, strategy.dailyPaymentLimit - todayPaid),
    };
  }
  
  // 检查月限额
  if (strategy.monthlyPaymentLimit >= 0 && 
      monthPaid + amount > strategy.monthlyPaymentLimit) {
    return {
      allowed: false,
      reason: 'MONTHLY_LIMIT_EXCEEDED',
      message: `未成年人每月支付限额${strategy.monthlyPaymentLimit}元`,
      remaining: Math.max(0, strategy.monthlyPaymentLimit - monthPaid),
    };
  }
  
  // 需要监护人代付（<14岁）
  if (strategy.dailyPaymentLimit === 0) {
    return {
      allowed: false,
      reason: 'GUARDIAN_PAYMENT_REQUIRED',
      message: '儿童用户需由监护人代为支付',
      alternativePaymentUrl: '/payment/guardian-pay',
    };
  }
  
  return { allowed: true };
}
```

```typescript
 * 降级认证（第三方不可用时）

async function downgradeVerification(
  userId: bigint,
  params: {
    name: string;
    idCardNumber: string;
    birthDate: Date;
    age: number;
    isMinor: boolean;
    isChild: boolean;
    reason: string;
    validDays: number;
  }
): Promise<VerificationResult> {

  // - 身份证号格式+校验码
  // - OCR结果（如有）
  // - 出生日期推算
  
  const idCardHash = sha256(params.idCardNumber);
  
  await verificationRepo.upsert(userId, {
    verificationLevel: 'ID_CARD',
    status: 'PENDING_REVIEW',  // 标记为待复核
    idCardHash,
    idCardHolder: encryptAES(params.name),
    idCardNumber: encryptAES(params.idCardNumber),
    birthDate: params.birthDate,
    age: params.age,
    isMinor: params.isMinor,
    isChild: params.isChild,
    verificationProvider: 'DOWNGRADED',
    expiredAt: addDays(new Date(), params.validDays),
    downgradeReason: params.reason,
  });
  
  // 后台异步补验
  await backgroundJob.schedule('verification.retry_third_party', {

    scheduledAt: addMinutes(new Date(), 30), // 30分钟后重试
    maxRetries: 5,
    retryIntervalMinutes: 30,
  });
  
  return {
    success: true,
    downgraded: true,
    validDays: params.validDays,
    message: '身份信息已初步验证，系统将在后台完成最终核验',
  };
```

### 9.3 认证状态异常恢复

```typescript
/**
 * 后台补验定时任务
 */
@Scheduled('verification.retry_third_party')
async function retryThirdPartyVerification(job: VerificationRetryJob) {
  const verification = await verificationRepo.findByUserId(job.userId);
  
  if (!verification || verification.status !== 'PENDING_REVIEW') {
    return; // 已处理或已取消
  }
  
  try {
    const name = decryptAES(verification.idCardHolder);
    const idNumber = decryptAES(verification.idCardNumber);
    
    const result = await thirdPartyVerify.verify({ name, idNumber });
    
    if (result.verified) {
      // 补验通过 → 正式更新状态
      await verificationRepo.update(job.userId, {
        status: 'VERIFIED',
        verificationProvider: result.provider,
        verificationRequestId: result.requestId,
        expiredAt: calculateExpiryDate(verification.isMinor),
      });
      
      // 触发事件（与正常核验相同的联动）
      await eventBus.publish('user.verification.completed', {
        userId: job.userId,
        verificationLevel: 'ID_CARD',
        isMinor: verification.isMinor,
        isChild: verification.isChild,
        age: verification.age,
        correlationId: generateCorrelationId(),
      });
      
      logger.info('Downgraded verification confirmed', { userId: job.userId });
    } else {
      // 补验不通过 → 标记异常，需要人工审核
      await verificationRepo.update(job.userId, {
        status: 'FAILED',
        failedReason: 'THIRD_PARTY_REJECTED',
      });
      
      await notificationService.notifyUser(job.userId, {
        type: 'VERIFICATION_FAILED',
        message: '身份核验未通过，请重新提交认证信息',
      });
    }
  } catch (error) {
    // 第三方仍然不可用 → 继续重试
    if (job.currentRetry < job.maxRetries) {
      await backgroundJob.reschedule(job.id, {
        scheduledAt: addMinutes(new Date(), job.retryIntervalMinutes),
        currentRetry: job.currentRetry + 1,
      });
    } else {
      // 重试次数耗尽 → 转人工审核
      await verificationRepo.update(job.userId, {
        status: 'MANUAL_REVIEW_REQUIRED',
      });
      logger.warn('Verification retries exhausted, manual review required', {
        userId: job.userId,
      });
    }
  }
}
```

```typescript
async function renewVerification(
  userId: bigint,
  request: RenewRequest
): Promise<RenewResult> {
  const existing = await verificationRepo.findByUserId(userId);
  
  if (!existing || existing.status !== 'VERIFIED') {
    // 无有效认证，走完整流程
    return { needFullVerification: true };
  }
  
  // 简化续期：仅需人脸比对（验证是同一人）
  if (request.renewMethod === 'SIMPLIFIED') {
    // 1. 人脸活体检测
    const livenessResult = await faceService.detectLiveness({
      videoBuffer: Buffer.from(request.faceVerification.videoBlob, 'base64'),
      type: request.faceVerification.livenessType,
    });
    
    if (!livenessResult.isLive) {
      throw new BusinessError('LIVENESS_FAILED', '活体检测未通过');
    }
    
    // 2. 与上次认证照片比对
    const compareResult = await faceService.compare1To1({
      sourceImage: livenessResult.bestFrame,
      referenceHash: existing.facePhotoHash,
    });
    
    if (compareResult.similarity < 0.75) {
      throw new BusinessError('FACE_MISMATCH', 
        '人脸比对未通过，请走完整认证流程');
    }
    
    // 3. 续期
    await verificationRepo.update(userId, {
      status: 'VERIFIED',
      expiredAt: calculateExpiryDate(existing.isMinor),
      faceVerified: true,
      faceVerifiedAt: new Date(),
    });
    
    return { success: true, renewed: true };
  }
  
  // 完整续期：需要重新提交身份信息
  return { needFullVerification: true };
}
```

### 15.2 身份证号校验算法

```typescript
/**
 * 18位身份证号校验（GB 11643-1999）
 */
function isValidIDCardNumber(idNumber: string): boolean {
  if (!/^\d{17}[\dXx]$/.test(idNumber)) return false;
  
  // 加权因子
  const weights = [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2];
  // 校验码对应值
  const checkCodes = ['1', '0', 'X', '9', '8', '7', '6', '5', '4', '3', '2'];
  
  let sum = 0;
  for (let i = 0; i < 17; i++) {
    sum += parseInt(idNumber[i]) * weights[i];
  }
  
  const expectedCheck = checkCodes[sum % 11];
  return idNumber[17].toUpperCase() === expectedCheck;
}

/**
 * 从身份证号提取出生日期
 */
function extractBirthDateFromID(idNumber: string): Date {
  const year = parseInt(idNumber.substring(6, 10));
  const month = parseInt(idNumber.substring(10, 12)) - 1;
  const day = parseInt(idNumber.substring(12, 14));
  return new Date(year, month, day);
}

/**
 * 计算精确年龄
 */
function calculateAge(birthDate: Date): number {
  const today = new Date();
  let age = today.getFullYear() - birthDate.getFullYear();
  const monthDiff = today.getMonth() - birthDate.getMonth();
  if (monthDiff < 0 || (monthDiff === 0 && today.getDate() < birthDate.getDate())) {
    age--;
  }
  return age;
}
```
