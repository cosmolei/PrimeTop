# 端到端流程设计 - 运营活动创建配置与效果归因分析完整链路

> 文档版本：v1.0  
> 创建日期：2026-06-07  
> 模块归属：运营管理平台 + 客户端运营弹窗 + 数据分析服务  
> 优先级：P1（V1.0 阶段核心运营能力）

---

## 1. 概述

### 1.1 流程定位

本链路覆盖运营人员从「创建活动 → 配置规则 → 投放触达 → 用户参与 → 效果归因」的完整生命周期。是连接运营后台、客户端展示、用户行为采集与数据分析四大系统的核心端到端流程。

### 1.2 核心参与方

| 角色 | 职责 |
|------|------|
| 运营人员 | 在管理后台创建/配置/上下架活动 |
| 后端活动引擎 | 解析活动规则、匹配目标用户、控制投放节奏 |
| 客户端运营弹窗系统 | 渲染活动弹窗/卡片/浮层，采集用户交互行为 |
| 数据分析服务 | 聚合参与数据、计算转化漏斗、生成效果报表 |
| BFF 聚合层 | 为客户端聚合活动详情、用户状态与个性化内容 |

### 1.3 流程全景图

```
运营后台创建活动
       │
       ▼
活动规则引擎解析 & 存储
       │
       ▼
目标用户分群匹配（用户标签引擎）
       │
       ▼
活动投放调度（弹窗/卡片/推送）
       │
       ▼
客户端渲染展示 & 用户交互
       │
       ▼
行为埋点上报 → 事件流处理
       │
       ▼
效果归因分析 & 报表生成
```

## 2. 数据结构定义

### 2.1 活动主表 `campaign`

```sql
CREATE TABLE campaign (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '活动ID',
    campaign_key    VARCHAR(64) NOT NULL UNIQUE COMMENT '活动唯一标识（运营自定义）',
    title           VARCHAR(128) NOT NULL COMMENT '活动标题',
    subtitle        VARCHAR(256) COMMENT '活动副标题/描述',
    cover_image_url VARCHAR(512) COMMENT '封面图URL',
    type            TINYINT NOT NULL COMMENT '活动类型：1=限时折扣 2=积分翻倍 3=打卡挑战 4=新人礼包 5=专题学习营 6=自定义',
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '状态：0=草稿 1=待审核 2=审核通过待上架 3=已上架 4=已下架 5=已结束',
    priority        INT NOT NULL DEFAULT 0 COMMENT '投放优先级，数值越大越优先',
    
    -- 时间控制
    start_time      DATETIME NOT NULL COMMENT '活动开始时间',
    end_time        DATETIME NOT NULL COMMENT '活动结束时间',
    
    -- 投放控制
    target_rule     JSON NOT NULL COMMENT '目标用户匹配规则（详见 TargetRule）',
    display_config  JSON NOT NULL COMMENT '展示配置（详见 DisplayConfig）',

    -- 业务内容
    reward_config   JSON COMMENT '奖励配置（详见 RewardConfig）',
    landing_page    JSON COMMENT '落地震性配置（详见 LandingPage）',

    audit_status    TINYINT DEFAULT 0 COMMENT '审核状态：0=未审核 1=审核中 2=通过 3=驳回',
    audit_remark    VARCHAR(512) COMMENT '审核备注',
    auditor_id      BIGINT COMMENT '审核人ID',
    audit_time      DATETIME COMMENT '审核时间',
    
    -- 元信息
    creator_id      BIGINT NOT NULL COMMENT '创建人ID',
    updater_id      BIGINT COMMENT '最后修改人ID',

    INDEX idx_campaign_key (campaign_key)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='运营活动主表';
```

### 2.2 核心JSON结构定义

#### TargetRule - 目标用户匹配规则

```typescript
interface TargetRule {
  // 学段过滤
  gradeLevels?: ('kindergarten' | 'primary' | 'junior' | 'senior')[];
  
  // 年级过滤（精确到年级，如 ['P3','P4','J1']）
  grades?: string[];
  
  // 学科过滤
  subjects?: ('chinese' | 'math' | 'english' | 'physics' | 'chemistry' | 'biology' | 'history' | 'geography' | 'politics')[];
  
  // 会员状态
  membershipFilter?: 'all' | 'free_only' | 'paid_only' | 'expired';
  
  // 用户标签（与用户标签引擎联动）
  userTagGroups?: {
    tagIds: number[];
    matchMode: 'any' | 'all';  // 满足任一/全部
  }[];
  
  // 新老用户
  userTenure?: 'all' | 'new_within_7d' | 'new_within_30d' | 'old_over_30d';
  
  // 注册时间范围
  registerTimeRange?: {
    start: string;  // ISO8601
    end: string;
  };
  
  // 自定义条件（SQL片段，仅限运营后台使用，需审核）
  customCondition?: string;
}
```

#### DisplayConfig - 展示配置

```typescript
interface DisplayConfig {
  // 展示形式
  displayType: 'popup' | 'banner' | 'card' | 'float_button' | 'notification';
  
  // 弹窗配置
  popup?: {
    position: 'center' | 'bottom';
    widthRatio: number;     // 占屏宽度比 0.6~1.0
    dismissible: boolean;   // 是否可关闭
    showCloseAfterMs: number; // N秒后显示关闭按钮
    maskClosable: boolean;  // 点击遮罩关闭
    animation: 'fade' | 'slide_up' | 'scale';
  };
  
  // 触发场景
  triggerScenes: ('app_start' | 'page_enter' | 'after_action' | 'scheduled')[];
  
  // 具体页面（page_enter 时）
  triggerPages?: string[];
  
  // 具体动作后（after_action 时）
  triggerActions?: string[];
  
  // 定时触发（scheduled 时）
  scheduleRules?: {
    timeSlots: { start: string; end: string }[];  // HH:mm
    daysOfWeek: number[];  // 0=周日, 1=周一, ...
  };
  
  // 频次控制
  frequency: {
    maxPerUser: number;         // 每用户总展示上限
    maxPerDay: number;          // 每用户每天上限
    cooldownMinutes: number;    // 同一用户两次展示间隔
    maxGlobalTotal: number;     // 全局总展示上限
  };
  
  // 优先级冲突策略
  conflictStrategy: 'highest_priority' | 'random_one' | 'queue_all';
}
```

#### CapConfig - 限量配置

```typescript
interface CapConfig {
  // 总参与人数上限
  maxParticipants?: number;
  
  // 每日参与人数上限
  maxDailyParticipants?: number;
  
  // 奖励库存上限
  maxRewards?: number;
  
  // 每人参与次数
  maxJoinPerUser?: number;
  
  // 达到上限后的处理
  capExhaustedAction: 'hide' | 'show_but_disable' | 'show_sold_out_label';
}
```

#### RewardConfig - 奖励配置

```typescript
interface RewardConfig {
  rewards: {
    // 奖励类型
    type: 'points' | 'coupon' | 'membership_days' | 'badge' | 'resource_pack';
    
    // 奖励值
    value: number;
    
    // 奖励单位
    unit: string;
    
    // 发放条件：immediate=参与即发, completion=完成后发, manual=手动发放

    // 奖励描述模板
    description: string;
    
    // 关联资源ID（如优惠券模板ID、徽章ID等）
    refId?: string;
  }[];
  
  // 奖励是否可叠加
  stackable: boolean;
  
  // 发放延迟（秒）
  grantDelaySeconds?: number;
}
```

**处理逻辑说明：**

```
1. 从 Redis 缓存获取当前时间在 [start_time, end_time] 范围内的已上架活动列表
2. 对每个活动执行 TargetRule 匹配：
   a. 从用户画像获取 gradeLevel, grade, membership 等属性
   b. 从用户标签引擎获取用户标签

   a. 从 campaign_participation 查询用户当前频次
   b. 对比 displayConfig.frequency 限制
4. 按 priority 降序排列，根据 conflictStrategy 决定最终展示列表
5. 更新 campaign_impression_log（异步）
```

## 4. 关键代码示例

### 4.1 活动匹配引擎（服务端核心）

```java
@Service
@Slf4j
public class CampaignMatchEngine {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private CampaignRepository campaignRepository;
    
    @Autowired
    private UserTagService userTagService;
    
    @Autowired
    private UserProfileService userProfileService;
    
    private static final String ACTIVE_CAMPAIGNS_KEY = "campaign:active:list";
    private static final String USER_FREQUENCY_KEY = "campaign:freq:%d:%d"; // campaignId:userId
    
    /**
     * 为用户匹配当前应展示的活动列表
     */
    public List<MatchedCampaign> matchActiveCampaigns(Long userId, String scene, String page) {
        // 1. 获取当前生效的活动列表（带缓存）
        List<Campaign> activeCampaigns = getActiveCampaigns();
        if (activeCampaigns.isEmpty()) {
            return Collections.emptyList();
        }
        
        // 2. 获取用户画像
        UserProfile profile = userProfileService.getProfile(userId);
        Set<Long> userTagIds = userTagService.getUserTagIds(userId);
        
        // 3. 并行匹配
        List<MatchedCampaign> matched = activeCampaigns.parallelStream()
            .filter(c -> matchTargetRule(c, profile, userTagIds))
            .filter(c -> matchTriggerScene(c, scene, page))
            .filter(c -> checkFrequency(c, userId))
            .map(c -> new MatchedCampaign(c, resolveUserStatus(c, userId, profile)))
            .collect(Collectors.toList());
        
        // 4. 冲突解决
        return resolveConflicts(matched);
    }
    
    /**
     * 目标规则匹配
     */
    private boolean matchTargetRule(Campaign campaign, UserProfile profile, Set<Long> userTagIds) {
        TargetRule rule = JsonUtils.parse(campaign.getTargetRule(), TargetRule.class);
        
        // 学段匹配
        if (rule.getGradeLevels() != null && !rule.getGradeLevels().isEmpty()) {
            if (!rule.getGradeLevels().contains(profile.getGradeLevel())) {
                return false;
            }
        }
        
        // 年级匹配
        if (rule.getGrades() != null && !rule.getGrades().isEmpty()) {
            if (!rule.getGrades().contains(profile.getGrade())) {
                return false;
            }
        }
        
        // 会员状态匹配
        if (rule.getMembershipFilter() != null && !"all".equals(rule.getMembershipFilter())) {
            boolean isPaid = "active".equals(profile.getMembershipStatus());
            if ("free_only".equals(rule.getMembershipFilter()) && isPaid) return false;
            if ("paid_only".equals(rule.getMembershipFilter()) && !isPaid) return false;
        }
        
        // 用户标签匹配
        if (rule.getUserTagGroups() != null) {
            for (TargetRule.TagGroup group : rule.getUserTagGroups()) {
                boolean anyMatch = group.getTagIds().stream().anyMatch(userTagIds::contains);
                boolean allMatch = group.getTagIds().stream().allMatch(userTagIds::contains);
                if ("any".equals(group.getMatchMode()) && !anyMatch) return false;
                if ("all".equals(group.getMatchMode()) && !allMatch) return false;
            }
        }
        
        // 新老用户匹配
        if (rule.getUserTenure() != null && !"all".equals(rule.getUserTenure())) {
            long daysSinceRegister = ChronoUnit.DAYS.between(
                profile.getRegisteredAt().toLocalDate(), LocalDate.now());
            switch (rule.getUserTenure()) {
                case "new_within_7d":  if (daysSinceRegister > 7)  return false; break;
                case "new_within_30d": if (daysSinceRegister > 30) return false; break;
                case "old_over_30d":   if (daysSinceRegister <= 30) return false; break;
            }
        }
        
        return true;
    }
    
    /**
     * 频次检查（Redis 计数器）
     */
    private boolean checkFrequency(Campaign campaign, Long userId) {
        DisplayConfig config = JsonUtils.parse(campaign.getDisplayConfig(), DisplayConfig.class);
        DisplayConfig.Frequency freq = config.getFrequency();
        
        String key = String.format(USER_FREQUENCY_KEY, campaign.getId(), userId);
        
        // 总次数检查
        Long totalCount = redisTemplate.opsForValue().get(key + ":total");
        if (totalCount != null && totalCount >= freq.getMaxPerUser()) {
            return false;
        }
        
        // 每日次数检查
        Long dailyCount = redisTemplate.opsForValue().get(key + ":daily:" + LocalDate.now());
        if (dailyCount != null && dailyCount >= freq.getMaxPerDay()) {
            return false;
        }
        
        // 冷却时间检查
        Long lastDisplayTs = (Long) redisTemplate.opsForValue().get(key + ":last");
        if (lastDisplayTs != null) {
            long elapsedMinutes = (System.currentTimeMillis() - lastDisplayTs) / 60000;
            if (elapsedMinutes < freq.getCooldownMinutes()) {
                return false;
            }
        }
        
        return true;
    }
    
    /**
     * 冲突解决
     */
    private List<MatchedCampaign> resolveConflicts(List<MatchedCampaign> matched) {
        if (matched.size() <= 1) return matched;
        
        // 获取最高优先级活动的 conflictStrategy
        matched.sort(Comparator.comparingInt(m -> -m.getCampaign().getPriority()));
        String strategy = JsonUtils.parse(
            matched.get(0).getCampaign().getDisplayConfig(), DisplayConfig.class
        ).getConflictStrategy();
        
        switch (strategy) {
            case "highest_priority":
                return matched.subList(0, 1);
            case "random_one":
                int idx = ThreadLocalRandom.current().nextInt(matched.size());
                return Collections.singletonList(matched.get(idx));
            case "queue_all":
            default:
                return matched;  // 全部返回，客户端排队展示
        }
    }
}
```

```java
@Service
@Slf4j
public class CampaignParticipationService {
    
    @Autowired
    private CampaignRepository campaignRepository;
    
    @Autowired
    private CampaignParticipationRepository participationRepository;
    
    @Autowired
    private RedissonClient redissonClient;
    
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    /**
     * 用户参与活动（分布式锁保证幂等+限量）
     */
    @Transactional
    public ParticipationResult joinCampaign(Long campaignId, Long userId, String sourceChannel, String deviceId) {
        // 1. 分布式锁防并发
        RLock lock = redissonClient.getLock(
            "campaign:join:" + campaignId + ":" + userId);
        boolean locked = false;
        try {
            locked = lock.tryLock(3, 10, TimeUnit.SECONDS);
            if (!locked) {
                return ParticipationResult.fail("SYSTEM_BUSY", "系统繁忙，请稍后再试");
            }
            
            // 2. 幂等检查
            Optional<CampaignParticipation> existing = 
                participationRepository.findByCampaignIdAndUserId(campaignId, userId);
            if (existing.isPresent()) {
                return ParticipationResult.fromExisting(existing.get());
            }
            
            // 3. 活动校验
            Campaign campaign = campaignRepository.findById(campaignId)
                .orElseThrow(() -> new BizException("CAMPAIGN_NOT_FOUND", "活动不存在"));
            
            if (campaign.getStatus() != 3) { // 已上架
                return ParticipationResult.fail("CAMPAIGN_NOT_AVAILABLE", "活动已下架");
            }
            
            LocalDateTime now = LocalDateTime.now();
            if (now.isBefore(campaign.getStartTime()) || now.isAfter(campaign.getEndTime())) {
                return ParticipationResult.fail("CAMPAIGN_EXPIRED", "活动已过期");
            }
            
            // 4. 限量检查（Redis原子递减）
            CapConfig capConfig = JsonUtils.parse(campaign.getCapConfig(), CapConfig.class);
            if (capConfig != null && capConfig.getMaxParticipants() != null) {
                String countKey = "campaign:count:" + campaignId;
                Long remaining = redissonClient.getAtomicLong(countKey).decrementAndGet();
                if (remaining < 0) {
                    // 回滚计数
                    redissonClient.getAtomicLong(countKey).incrementAndGet();
                    return ParticipationResult.fail("CAP_EXHAUSTED", "活动名额已满");
                }
            }
            
            // 5. 写入参与记录
            CampaignParticipation participation = CampaignParticipation.builder()
                .campaignId(campaignId)
                .userId(userId)
                .status(CampaignParticipationStatus.JOINED.getCode())
                .displayScene(sourceChannel)
                .deviceId(deviceId)
                .joinAt(now)
                .sourceChannel(sourceChannel)
                .build();
            
            participationRepository.save(participation);
            
            // 6. 发布参与事件（异步触发奖励检查、统计更新等）
            eventPublisher.publishEvent(new CampaignJoinEvent(
                campaignId, userId, participation.getId(), sourceChannel, now));
            
            return ParticipationResult.success(participation);
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return ParticipationResult.fail("SYSTEM_BUSY", "系统繁忙");
        } finally {
            if (locked) {
                lock.unlock();
            }
        }
    }
}
```

```java
@Service
@Slf4j
public class CampaignStatsAggregator {
    
    @Autowired
    private ClickHouseTemplate clickHouseTemplate;
    
    @Autowired
    private CampaignStatsRepository statsRepository;
    
    /**
     * 每小时执行一次，聚合当天活动数据
     */
    @Scheduled(cron = "0 5 * * * *")
    public void aggregateHourlyStats() {
        LocalDate today = LocalDate.now();
        
        // 获取当天所有活跃活动
        List<Long> activeCampaignIds = campaignRepository.findActiveCampaignIds(today);
        
        for (Long campaignId : activeCampaignIds) {
            try {
                aggregateForCampaign(campaignId, today);
            } catch (Exception e) {
                log.error("聚合活动统计失败: campaignId={}", campaignId, e);
            }
        }
    }
    
    private void aggregateForCampaign(Long campaignId, LocalDate statDate) {
        // 从 ClickHouse 聚合漏斗数据
        String sql = """
            SELECT 
                action,
                count() as cnt,
                uniq(user_id) as users
            FROM campaign_impression_log
            WHERE campaign_id = :campaignId 
              AND toDate(created_at) = :statDate
            GROUP BY action
            """;
        
        Map<Integer, Long> actionCounts = new HashMap<>();
        Map<Integer, Integer> actionUsers = new HashMap<>();
        
        clickHouseTemplate.query(sql, Map.of(
            "campaignId", campaignId,
            "statDate", statDate
        ), (rs) -> {
            int action = rs.getInt("action");
            actionCounts.put(action, rs.getLong("cnt"));
            actionUsers.put(action, rs.getInt("users"));
        });
        
        // 计算转化率
        long impressions = actionCounts.getOrDefault(1, 0L);
        long clicks = actionCounts.getOrDefault(2, 0L);
        long joins = actionCounts.getOrDefault(4, 0L);
        long completes = actionCounts.getOrDefault(5, 0L);
        
        BigDecimal clickRate = impressions > 0 
            ? BigDecimal.valueOf(clicks).divide(BigDecimal.valueOf(impressions), 4, RoundingMode.HALF_UP) 
            : BigDecimal.ZERO;
        BigDecimal joinRate = clicks > 0 
            ? BigDecimal.valueOf(joins).divide(BigDecimal.valueOf(clicks), 4, RoundingMode.HALF_UP) 
            : BigDecimal.ZERO;
        BigDecimal completeRate = joins > 0 
            ? BigDecimal.valueOf(completes).divide(BigDecimal.valueOf(joins), 4, RoundingMode.HALF_UP) 
            : BigDecimal.ZERO;
        BigDecimal overallRate = impressions > 0 
            ? BigDecimal.valueOf(completes).divide(BigDecimal.valueOf(impressions), 4, RoundingMode.HALF_UP) 
            : BigDecimal.ZERO;
        
        // Upsert统计记录
        CampaignStats stats = CampaignStats.builder()
            .campaignId(campaignId)
            .statDate(statDate)
            .impressionCount(actionCounts.getOrDefault(1, 0L).intValue())
            .impressionUsers(actionUsers.getOrDefault(1, 0))
            .clickCount(actionCounts.getOrDefault(2, 0L).intValue())
            .clickUsers(actionUsers.getOrDefault(2, 0))
            .joinCount(actionCounts.getOrDefault(4, 0L).intValue())
            .joinUsers(actionUsers.getOrDefault(4, 0))
            .completeCount(actionCounts.getOrDefault(5, 0L).intValue())
            .completeUsers(actionUsers.getOrDefault(5, 0))
            .clickRate(clickRate)
            .joinRate(joinRate)
            .completeRate(completeRate)
            .overallConvRate(overallRate)
            .build();
        
        statsRepository.upsert(stats);
    }
}
```

```dart
/// 活动弹窗管理器 - 管理活动弹窗的展示队列和频次控制
class CampaignPopupManager {
  static CampaignPopupManager? _instance;
  factory CampaignPopupManager() => _instance ??= CampaignPopupManager._();
  CampaignPopupManager._();

  final CampaignApiService _apiService = CampaignApiService();
  final CampaignLocalStorage _localStorage = CampaignLocalStorage();
  
  List<CampaignDisplayModel> _pendingCampaigns = [];
  int _currentDisplayIndex = 0;
  
  /// 在指定场景触发活动检查
  Future<void> triggerCheck(String scene, {String? page}) async {
    try {
      final response = await _apiService.getActiveCampaigns(
        scene: scene,
        page: page,
      );
      
      if (response.campaigns.isEmpty) return;
      
      // 按优先级入队
      _pendingCampaigns = response.campaigns
          .where(_shouldDisplay)
          .toList()
        ..sort((a, b) => b.priority.compareTo(a.priority));
      
      if (_pendingCampaigns.isNotEmpty) {
        _showNext();
      }
    } catch (e) {
      debugPrint('活动弹窗检查失败: $e');
    }
  }
  
  /// 判断是否应展示（客户端二次校验）
  bool _shouldDisplay(CampaignDisplayModel campaign) {
    // 1. 检查今日展示次数
    int todayCount = _localStorage.getTodayDisplayCount(campaign.id);
    if (todayCount >= campaign.frequency.maxPerDay) return false;
    
    // 2. 检查冷却时间
    DateTime? lastDisplay = _localStorage.getLastDisplayTime(campaign.id);
    if (lastDisplay != null) {
      int elapsedMinutes = DateTime.now().difference(lastDisplay).inMinutes;
      if (elapsedMinutes < campaign.frequency.cooldownMinutes) return false;
    }
    
    // 3. 检查总展示次数
    int totalCount = _localStorage.getTotalDisplayCount(campaign.id);
    if (totalCount >= campaign.frequency.maxPerUser) return false;
    
    return true;
  }
  
  /// 展示下一个活动弹窗
  void _showNext() {
    if (_currentDisplayIndex >= _pendingCampaigns.length) {
      _currentDisplayIndex = 0;
      _pendingCampaigns.clear();
      return;
    }
    
    final campaign = _pendingCampaigns[_currentDisplayIndex];
    
    // 记录展示时间（上报前先记录，防止重复展示）
    _localStorage.recordDisplay(campaign.id);
    
    // 上报展示事件（异步不阻塞）
    _apiService.reportEvent(CampaignEvent.impression(campaign.id));
    
    // 根据展示类型渲染
    switch (campaign.displayType) {
      case 'popup':
        _showPopupDialog(campaign);
        break;
      case 'banner':
        _showBanner(campaign);
        break;
      case 'float_button':
        _showFloatButton(campaign);
        break;
      default:
        _showPopupDialog(campaign);
    }
  }
  
  void _showPopupDialog(CampaignDisplayModel campaign) {
    final context = AppNavigator.rootContext;
    if (context == null) return;
    
    showDialog(
      context: context,
      barrierDismissible: campaign.popupConfig?.maskClosable ?? true,
      barrierColor: Colors.black54,
      builder: (ctx) => CampaignPopupWidget(
        campaign: campaign,
        onAction: () {
          // 点击参与
          _apiService.reportEvent(CampaignEvent.click(campaign.id));
          _joinCampaign(campaign);
          Navigator.of(ctx).pop();
          _advanceQueue();
        },
        onClose: () {
          // 关闭
          _apiService.reportEvent(CampaignEvent.close(campaign.id));
          Navigator.of(ctx).pop();
          _advanceQueue();
        },
        showCloseAfterMs: campaign.popupConfig?.showCloseAfterMs ?? 0,
        animation: campaign.popupConfig?.animation ?? 'scale',
      ),
    );
  }
  
  void _advanceQueue() {
    _currentDisplayIndex++;
    // 队列模式下延迟展示下一个
    Future.delayed(const Duration(seconds: 2), () {
      _showNext();
    });
  }
  
  Future<void> _joinCampaign(CampaignDisplayModel campaign) async {
    try {
      final result = await _apiService.joinCampaign(campaign.id);
      if (result.status == 'joined' && result.nextAction != null) {
        _executeNextAction(result.nextAction!);
      }
    } catch (e) {
      debugPrint('参与活动失败: $e');
      ToastUtil.showError('参与活动失败，请稍后再试');
    }
  }
  
  void _executeNextAction(NextAction action) {
    switch (action.type) {
      case 'navigate':
        AppNavigator.push(action.route!, arguments: action.params);
        break;
      case 'webview':
        AppNavigator.push('/webview', arguments: {'url': action.url});
        break;
      case 'none':
      default:
        break;
    }
  }
}
```

## 6. 错误处理

### 6.1 错误码定义

| 错误码 | 含义 | 处理方式 |
|--------|------|---------|
| 10400 | 活动参数校验失败 | 返回具体字段错误信息 |
| 10401 | 活动名额已满 | 客户端展示"已售罄" |
| 10402 | 活动已过期 | 隐藏活动入口 |
| 10403 | 活动已下架 | 隐藏活动入口 |
| 10404 | 活动不存在 | 记录日志，隐藏入口 |
| 10405 | 用户不满足参与条件 | 展示具体原因 |
| 10406 | 用户已参与过 | 返回已有参与状态 |
| 10407 | 活动尚未开始 | 展示倒计时 |
| 10408 | 频次已达上限 | 客户端不展示 |
| 10410 | 审核中不可上架 | 提示运营等待审核 |
| 10411 | 审核未通过不可上架 | 提示运营修改后重新提交 |
| 10420 | 奖励发放失败 | 自动重试3次，之后转人工 |
| 10421 | 奖励库存不足 | 标记活动结束 |

### 6.2 降级策略

```
活动匹配引擎降级：
├── Redis 缓存不可用 → 读本地缓存（TTL=5min），仍不可用则跳过活动展示
├── 用户标签服务不可用 → 降级为仅按学段/会员状态匹配
├── ClickHouse 不可用 → 暂停统计聚合，不影响活动展示
└── 数据库不可用 → 活动列表走 Redis 缓存，参与接口返回 SYSTEM_BUSY

客户端降级：
├── 活动列表接口超时(>3s) → 跳过活动展示，不影响正常学习
├── 活动图片加载失败 → 展示默认占位图 + 文字标题
├── 参与接口失败 → 本地缓存参与意图，网络恢复后自动重试
└── 活动弹窗渲染异常 → 捕获异常静默关闭，上报错误日志
```

## 8. 安全与合规

### 8.1 运营后台安全

1. **操作审计**：所有活动创建、修改、上下架操作记录审计日志
2. **审核流程**：活动上架前必须通过内容审核（标题/图片/文案合规）
3. **权限控制**：仅运营和管理员角色可操作活动管理
4. **自定义条件限制**：`targetRule.customCondition` 需 DBA 审核后方可启用

### 8.2 用户侧安全

1. **防刷保护**：同一用户短时间大量参与请求自动限流
2. **设备指纹**：结合设备指纹检测多账号薅羊毛行为
3. **未成年人保护**：活动文案不得含诱导消费、学习焦虑等不当内容
4. **奖励上限**：单用户单活动奖励总量有硬上限，防止积分膨胀

### 8.3 数据合规

1. **展示日志脱敏**：ClickHouse 中不存储用户手机号等敏感信息
2. **数据保留期**：展示日志保留 180 天，统计数据永久保留
3. **统计报表导出**：仅脱敏聚合数据可导出，不包含个人可识别信息

### 9.2 运营数据看板

管理后台活动效果看板应包含：

1. **实时看板**：当前活跃活动数、实时参与人数、今日总转化率
2. **漏斗分析**：展示 → 点击 → 参与 → 完成 → 付费 转化率
3. **趋势对比**：不同活动同期对比、同比环比分析
4. **用户分群效果**：按学段/会员状态/新老用户维度拆解转化率
5. **ROI 计算**：活动成本（奖励发放+资源消耗）vs 收益（新会员收入）

```java
public final class CampaignEvents {
    
    /** 活动展示事件 */
    public record CampaignImpressionEvent(
        Long campaignId, Long userId, String displayType, 
        String displayScene, String displayPage, Instant timestamp) {}
    
    /** 活动参与事件 */
    public record CampaignJoinEvent(
        Long campaignId, Long userId, Long participationId,
        String sourceChannel, Instant timestamp) {}
    
    /** 活动完成事件 */
    public record CampaignCompleteEvent(
        Long campaignId, Long userId, Long participationId,
        Map<String, Object> completionContext, Instant timestamp) {}
    
    /** 奖励发放事件 */
    public record CampaignRewardEvent(
        Long campaignId, Long userId, String rewardType, 
        BigDecimal rewardValue, String grantTrigger, Instant timestamp) {}
    
    /** 活动状态变更事件 */
    public record CampaignStatusChangeEvent(
        Long campaignId, CampaignStatus oldStatus, 
        CampaignStatus newStatus, Long operatorId) {}
}

// 消费者示例：参与事件触发后续流程
@Component
public class CampaignJoinEventConsumer {
    
    @EventListener
    @Async("campaignEventExecutor")
    public void onJoin(CampaignJoinEvent event) {
        // 1. 检查是否达成自动完成条件
        checkAutoCompletion(event.campaignId(), event.participationId());
        
        // 2. 更新实时统计（Redis）
        updateRealtimeStats(event.campaignId());
        
        // 3. 发送欢迎消息（如需）
        sendWelcomeMessage(event.campaignId(), event.userId());
        
        // 4. 记录用户行为日志
        logUserBehavior(event);
    }
}
```
