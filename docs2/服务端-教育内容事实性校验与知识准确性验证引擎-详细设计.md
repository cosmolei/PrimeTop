# 服务端-教育内容事实性校验与知识准确性验证引擎 详细设计

## 1. 概述

### 1.1 模块定位

教育内容事实性校验与知识准确性验证引擎（Fact-Check & Knowledge Accuracy Verification Engine，简称 FCKAV Engine）是 PrimeTop 教育平台的内容质量基础设施组件。它负责对平台内所有教育内容（AI 生成回答、题库解析、教材知识库、课程内容、用户生成内容等）进行自动化的事实性校验与知识准确性验证，确保学生接触到的每一条知识信息都是准确、权威、无误导的。

### 1.2 与已有模块的区别

| 已有模块 | 关注点 | 与本引擎的区别 |
|---------|--------|---------------|
| AI幻觉检测引擎 | 检测AI输出中虚构、捏造内容 | 幻觉检测关注"是否编造"，本引擎关注"是否准确" |
| AI输出质量校验与多模型复核 | 多模型交叉验证输出质量 | 质量校验关注"输出质量好坏"，本引擎关注"知识事实对错" |
| 教育内容质量自动评估 | 内容整体质量评分 | 质量评估是综合维度，本引擎专精事实维度 |
| 教育内容审核工作流 | 内容安全与合规审核 | 审核关注"安全合规"，本引擎关注"知识正确" |
| 知识图谱驱动智能问答增强 | RAG检索增强回答 | 知识图谱提供检索，本引擎做检索结果的事实验证 |

### 1.3 核心职责

1. **事实声明抽取**：从文本内容中自动抽取可验证的事实性声明（factual claims）
2. **权威知识比对**：将抽取的事实声明与权威知识库进行交叉验证
3. **学科规则校验**：对数学公式、物理定律、化学反应、历史年代等领域进行规则化校验
4. **置信度评分**：为每条事实声明生成准确性置信度分数
5. **纠错建议生成**：对检测到的不准确内容提供修正建议
6. **校验报告输出**：生成结构化校验报告，支持人工复核流程

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 校验任务 (verification_task)

```sql
CREATE TABLE verification_task (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    task_id         VARCHAR(64) NOT NULL UNIQUE COMMENT '校验任务唯一标识 UUID',
    source_type     VARCHAR(32) NOT NULL COMMENT '内容来源类型: AI_RESPONSE/QUESTION_EXPLAIN/COURSE_CONTENT/KNOWLEDGE_BASE/UGC',
    source_id       VARCHAR(128) NOT NULL COMMENT '来源内容ID',
    source_snippet  TEXT COMMENT '被校验的内容片段(冗余,便于快速查看)',
    subject         VARCHAR(16) COMMENT '学科: CHINESE/MATH/ENGLISH/PHYSICS/CHEMISTRY/BIOLOGY/HISTORY/GEOGRAPHY/POLITICS',
    grade_level     VARCHAR(16) COMMENT '学段: PRESCHOOL/PRIMARY/JUNIOR/SENIOR',
    priority        TINYINT DEFAULT 5 COMMENT '优先级 1(最高)-9(最低), AI实时回答=1, 批量入库=5',
    status          VARCHAR(24) NOT NULL DEFAULT 'PENDING' COMMENT '状态: PENDING/EXTRACTING/VERIFYING/COMPLETED/FAILED/SKIPPED',
    overall_score   DECIMAL(5,2) COMMENT '整体准确性评分 0-100',
    claim_count     INT DEFAULT 0 COMMENT '抽取到的事实声明数量',
    verified_count  INT DEFAULT 0 COMMENT '已校验完成的数量',
    flagged_count   INT DEFAULT 0 COMMENT '标记为存疑/错误的数量',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    completed_at    DATETIME COMMENT '完成时间',
    error_message   TEXT COMMENT '失败原因(若FAILED)',
    metadata        JSON COMMENT '扩展元数据: 模型版本/教材版本/章节等',

    INDEX idx_source (source_type, source_id),
    INDEX idx_status_priority (status, priority, created_at),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容事实校验任务';
```

#### 2.1.2 事实声明 (fact_claim)

```sql
CREATE TABLE fact_claim (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    claim_id        VARCHAR(64) NOT NULL UNIQUE COMMENT '声明唯一标识 UUID',
    task_id         VARCHAR(64) NOT NULL COMMENT '关联校验任务ID',
    claim_text      TEXT NOT NULL COMMENT '事实声明文本',
    claim_type      VARCHAR(32) NOT NULL COMMENT '声明类型: DATE/NUMBER/FORMULA/DEFINITION/CAUSALITY/CITATION/ENTITY/LOGIC',
    subject_domain  VARCHAR(64) COMMENT '学科子领域: 如"中国古代史"/"牛顿力学"/"有机化学"',
    position_start  INT COMMENT '在原文中的起始字符位置',
    position_end    INT COMMENT '在原文中的结束字符位置',
    status          VARCHAR(24) NOT NULL DEFAULT 'PENDING' COMMENT 'PENDING/VERIFIED/FLAGGED/UNCERTAIN',
    verdict         VARCHAR(16) COMMENT '判定: CORRECT/INCORRECT/PARTIALLY_CORRECT/UNVERIFIABLE',
    confidence      DECIMAL(5,2) COMMENT '置信度 0-100',
    evidence        JSON COMMENT '证据列表: [{source, text, url, score}]',
    correction      TEXT COMMENT '修正建议(若INCORRECT)',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_task (task_id),
    INDEX idx_verdict (verdict),
    INDEX idx_type (claim_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='事实声明记录';
```

#### 2.1.3 权威知识条目 (authoritative_knowledge)

```sql
CREATE TABLE authoritative_knowledge (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    knowledge_id    VARCHAR(64) NOT NULL UNIQUE COMMENT '知识条目唯一标识',
    subject         VARCHAR(16) NOT NULL COMMENT '学科',
    domain          VARCHAR(64) NOT NULL COMMENT '子领域',
    statement       TEXT NOT NULL COMMENT '权威陈述文本',
    statement_type  VARCHAR(32) NOT NULL COMMENT '类型: DEFINITION/THEOREM/FORMULA/HISTORICAL_FACT/SCIENTIFIC_FACT/STATUTE',
    source          VARCHAR(128) NOT NULL COMMENT '来源: 课标/教材/词典/论文/百科',
    source_detail   VARCHAR(256) COMMENT '来源详细信息: 如"人教版八年级物理P123"',
    grade_level     VARCHAR(16) COMMENT '适用学段',
    textbook_version VARCHAR(32) COMMENT '教材版本',
    chapter_code    VARCHAR(64) COMMENT '章节编码',
    review_status   VARCHAR(24) NOT NULL DEFAULT 'APPROVED' COMMENT 'DRAFT/PENDING_REVIEW/APPROVED/DEPRECATED',
    embedding_id    VARCHAR(128) COMMENT '向量索引ID(关联Milvus)',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    created_by      BIGINT COMMENT '创建人ID',

    INDEX idx_subject_domain (subject, domain),
    INDEX idx_type (statement_type),
    INDEX idx_review (review_status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='权威知识条目库';
```

#### 2.1.4 学科校验规则 (subject_verification_rule)

```sql
CREATE TABLE subject_verification_rule (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    rule_id         VARCHAR(64) NOT NULL UNIQUE COMMENT '规则唯一标识',
    rule_name       VARCHAR(128) NOT NULL COMMENT '规则名称',
    subject         VARCHAR(16) NOT NULL COMMENT '学科',
    domain          VARCHAR(64) NOT NULL COMMENT '子领域',
    rule_type       VARCHAR(32) NOT NULL COMMENT '规则类型: FORMULA_CHECK/RANGE_CHECK/UNIT_CHECK/LOGIC_CHECK/DATE_CHECK',
    rule_expression TEXT NOT NULL COMMENT '规则表达式(JSON格式)',
    description     TEXT COMMENT '规则描述',
    priority        TINYINT DEFAULT 5 COMMENT '优先级',
    enabled         TINYINT DEFAULT 1 COMMENT '是否启用',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_subject_domain (subject, domain),
    INDEX idx_enabled (enabled)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学科校验规则';
```

#### 2.1.5 校验反馈记录 (verification_feedback)

```sql
CREATE TABLE verification_feedback (
```

### 2.2 缓存策略

```java
// 缓存Key设计
public class FactCheckCacheKeys {
    // 任务结果缓存 - 7天 (允许相同内容复用校验结果)
    public static String taskResult(String contentHash) {
        return "fckav:task:" + contentHash;  // contentHash = SHA256(原文)
    }

    // 权威知识向量检索缓存 - 24小时
    public static String knowledgeEmbedding(String claimHash) {
        return "fckav:emb:" + claimHash;
    }

    // 学科规则缓存 - 1小时 (规则变更不频繁)
    public static String subjectRules(String subject, String domain) {
        return "fckav:rules:" + subject + ":" + domain;
    }

    // 热点内容校验统计 - 5分钟
    public static String dailyStats(String date) {
        return "fckav:stats:" + date;
    }
}
```

### 3.3 错误码定义

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|-----------|------|---------|
| FCKAV_001 | 400 | 内容为空或过短 | 检查请求内容 |
| FCKAV_002 | 400 | 不支持的学科类型 | 检查subject字段 |
| FCKAV_003 | 400 | 校验选项无效 | 检查options字段 |
| FCKAV_101 | 404 | 校验任务不存在 | 检查taskId |
| FCKAV_102 | 409 | 重复提交相同内容 | 使用已有task_id |
| FCKAV_201 | 422 | 权威知识库为空(该学科) | 需要先导入权威知识 |
| FCKAV_202 | 422 | 规则表达式解析失败 | 检查规则配置 |
| FCKAV_301 | 503 | 大模型服务不可用 | 降级为规则+知识库校验 |
| FCKAV_302 | 503 | 向量检索服务不可用 | 降级为规则校验 |
| FCKAV_303 | 504 | 实时校验超时 | 重试或跳过校验 |
| FCKAV_999 | 500 | 系统内部错误 | 联系运维排查 |

### 4.4 多源校验融合策略

当同一事实声明被多个校验源（知识库、规则引擎、LLM）验证时，采用加权融合策略：

```java
/**
 * 多源校验结果融合
 */
public class VerdictFusion {

    // 各校验源权重配置(可通过动态配置调整)
    private static final double WEIGHT_KB = 0.45;      // 知识库比对
    private static final double WEIGHT_RULE = 0.35;    // 规则引擎
    private static final double WEIGHT_LLM = 0.20;     // LLM推理

    /**
     * 融合多源校验结果，输出最终判定
     */
    public VerdictResult fuse(List<SourceVerdict> verdicts) {
        if (verdicts.isEmpty()) {
            return VerdictResult.unverifiable();
        }

        double weightedScore = 0.0;
        double totalWeight = 0.0;
        List<Evidence> allEvidence = new ArrayList<>();

        for (SourceVerdict v : verdicts) {
            double weight = getWeight(v.getSource());
            weightedScore += v.getScore() * weight;
            totalWeight += weight;
            allEvidence.addAll(v.getEvidence());
        }

        double finalScore = weightedScore / totalWeight;

        // 判定逻辑
        Verdict verdict;
        if (finalScore >= 85) {
            verdict = Verdict.CORRECT;
        } else if (finalScore >= 50) {
            verdict = Verdict.PARTIALLY_CORRECT;
        } else if (finalScore >= 20) {
            verdict = Verdict.UNCERTAIN;
        } else {
            verdict = Verdict.INCORRECT;
        }

        // 冲突检测：如果各源判定差异大，标记为需人工复核
        boolean needsReview = hasSignificantConflict(verdicts);

        return VerdictResult.builder()
            .verdict(verdict)
            .confidence(BigDecimal.valueOf(finalScore)
                .setScale(2, RoundingMode.HALF_UP).doubleValue())
            .evidence(allEvidence)
            .needsHumanReview(needsReview)
            .build();
    }

    private boolean hasSignificantConflict(List<SourceVerdict> verdicts) {
        // 如果最高分和最低分差距超过30分，认为存在显著冲突
        double max = verdicts.stream().mapToDouble(SourceVerdict::getScore).max().orElse(0);
        double min = verdicts.stream().mapToDouble(SourceVerdict::getScore).min().orElse(0);
        return (max - min) > 30.0;
    }
}
```

```java
package com.primetop.factcheck;

/**
 * 事实校验引擎主入口
 */
@Service
@Slf4j
public class FactCheckEngine {

    @Autowired private ClaimExtractor claimExtractor;
    @Autowired private VerificationOrchestrator verificationOrchestrator;
    @Autowired private VerdictFusion verdictFusion;
    @Autowired private ReportGenerator reportGenerator;
    @Autowired private VerificationTaskMapper taskMapper;
    @Autowired private RedisTemplate<String, Object> redisTemplate;

    /**
     * 同步校验入口 (适用于低延迟场景如AI对话)
     */
    public FactCheckResult verifySync(FactCheckRequest request) {
        long start = System.currentTimeMillis();

        // 1. 内容去重检查
        String contentHash = DigestUtils.sha256Hex(request.getContent());
        FactCheckResult cached = checkCache(contentHash);
        if (cached != null) {
            log.debug("Cache hit for content hash: {}", contentHash);
            return cached;
        }

        // 2. 创建校验任务
        VerificationTask task = createTask(request, contentHash);

        try {
            // 3. 事实声明抽取
            task.setStatus(TaskStatus.EXTRACTING);
            taskMapper.updateById(task);

            List<FactClaim> claims = claimExtractor.extract(
                request.getContent(),
                request.getSubject(),
                request.getGradeLevel()
            );

            if (claims.isEmpty()) {
                task.setStatus(TaskStatus.SKIPPED);
                taskMapper.updateById(task);
                return FactCheckResult.skipped(task.getTaskId());
            }

            // 4. 并行校验
            task.setStatus(TaskStatus.VERIFYING);
            taskMapper.updateById(task);

            List<ClaimVerificationResult> results = verificationOrchestrator
                .verifyParallel(claims, request.getOptions());

            // 5. 综合判定
            FactCheckResult result = verdictFusion.fuseAll(results);
            result.setTaskId(task.getTaskId());

            // 6. 持久化 & 缓存
            persistResults(task, result);
            cacheResult(contentHash, result);

            // 7. 生成报告
            reportGenerator.generate(task.getTaskId(), result);

            task.setStatus(TaskStatus.COMPLETED);
            task.setOverallScore(result.getOverallScore());
            task.setCompletedAt(LocalDateTime.now());
            taskMapper.updateById(task);

            long elapsed = System.currentTimeMillis() - start;
            log.info("Fact check completed in {}ms, score={}, claims={}",
                elapsed, result.getOverallScore(), claims.size());

            return result;

        } catch (Exception e) {
            log.error("Fact check failed for task: {}", task.getTaskId(), e);
            task.setStatus(TaskStatus.FAILED);
            task.setErrorMessage(e.getMessage());
            taskMapper.updateById(task);
            throw new FactCheckException("FCKAV_999", "校验过程异常", e);
        }
    }

    /**
     * 异步校验入口 (适用于批量内容入库场景)
     */
    public String verifyAsync(FactCheckRequest request) {
        String contentHash = DigestUtils.sha256Hex(request.getContent());
        VerificationTask task = createTask(request, contentHash);

        // 投递到消息队列异步处理
        kafkaTemplate.send("fact-check-tasks", new FactCheckMessage(
            task.getTaskId(), request
        ));

        return task.getTaskId();
    }
}
```

### 5.2 事实声明抽取器

```java
package com.primetop.factcheck.extractor;

/**
 * 事实声明抽取器
 * 结合大模型和规则模式双重抽取
 */
@Component
@Slf4j
public class ClaimExtractor {

    @Autowired private LlmClient llmClient;
    @Autowired private ClaimPatternRegistry patternRegistry;

    @Value("${factcheck.claim.max-per-content:20}")
    private int maxClaims;

    private static final ObjectMapper MAPPER = new ObjectMapper();

    /**
     * 从教育内容中抽取事实声明
     */
    public List<FactClaim> extract(String content, String subject, String gradeLevel) {
        // Step 1: 规则模式快速抽取(高精度低召回)
        List<FactClaim> ruleClaims = patternRegistry.match(content, subject);

        // Step 2: LLM 深度抽取(高召回)
        List<FactClaim> llmClaims = extractByLlm(content, subject, gradeLevel);

        // Step 3: 合并去重(基于语义相似度)
        List<FactClaim> merged = mergeAndDedup(ruleClaims, llmClaims);

        // Step 4: 限制数量
        if (merged.size() > maxClaims) {
            merged = merged.subList(0, maxClaims);
        }

        // 填充位置信息
        for (FactClaim claim : merged) {
            if (claim.getPositionStart() == null) {
                int pos = content.indexOf(claim.getClaimText());
                if (pos >= 0) {
                    claim.setPositionStart(pos);
                    claim.setPositionEnd(pos + claim.getClaimText().length());
                }
            }
        }

        log.debug("Extracted {} claims (rule={}, llm={}, after_merge={})",
            merged.size(), ruleClaims.size(), llmClaims.size(), merged.size());
        return merged;
    }

    private List<FactClaim> extractByLlm(String content, String subject, String gradeLevel) {
        String prompt = buildExtractionPrompt(content, subject, gradeLevel);

        try {
            LlmResponse response = llmClient.chat(
                LlmRequest.builder()
                    .model("gpt-4o-mini")  // 使用快速模型降低延迟
                    .temperature(0.0)      // 确定性输出
                    .maxTokens(2000)
                    .messages(List.of(
                        Message.system("你是教育内容事实声明抽取专家，只输出JSON。"),
                        Message.user(prompt)
                    ))
                    .responseFormat("json_object")
                    .timeout(Duration.ofSeconds(5))
                    .build()
            );

            JsonNode root = MAPPER.readTree(response.getContent());
            List<FactClaim> claims = new ArrayList<>();

            if (root.has("claims")) {
                for (JsonNode node : root.get("claims")) {
                    FactClaim claim = FactClaim.builder()
                        .claimId(IdGenerator.uuid())
                        .claimText(node.get("text").asText())
                        .claimType(node.get("type").asText())
                        .subjectDomain(node.has("domain") ? node.get("domain").asText() : null)
                        .status("PENDING")
                        .build();
                    claims.add(claim);
                }
            }

            return claims;

        } catch (Exception e) {
            log.warn("LLM claim extraction failed, falling back to rule-only. Error: {}", e.getMessage());
            return Collections.emptyList();
        }
    }

    private String buildExtractionPrompt(String content, String subject, String gradeLevel) {
        return String.format("""
            学科: %s
            学段: %s

            请从以下教育内容中抽取所有可验证的事实性声明。
            输出JSON格式: {"claims": [{"text": "声明文本", "type": "类型", "domain": "子领域"}]}

            类型枚举: DATE, NUMBER, FORMULA, DEFINITION, CAUSALITY, CITATION, ENTITY, LOGIC

            要求:
            1. 每个声明独立可验证
            2. 忽略纯主观评价和修辞
            3. 最多抽取%d个声明

            内容: %s
            """, subject, gradeLevel, maxClaims, content);
    }

    /**
     * 基于语义相似度去重合并
     */
    private List<FactClaim> mergeAndDedup(List<FactClaim>... claimLists) {
        List<FactClaim> all = new ArrayList<>();
        for (List<FactClaim> list : claimLists) {
            all.addAll(list);
        }

        List<FactClaim> result = new ArrayList<>();
        for (FactClaim candidate : all) {
            boolean isDup = false;
            for (FactClaim existing : result) {
                // 简单文本相似度检查(生产环境使用向量相似度)
                double sim = StringSimilarity.jaroWinkler(
                    candidate.getClaimText(),
                    existing.getClaimText()
                );
                if (sim > 0.85) {
                    isDup = true;
                    break;
                }
            }
            if (!isDup) {
                result.add(candidate);
            }
        }
        return result;
    }
}
```

### 5.3 并行校验编排器

```java
package com.primetop.factcheck.orchestrator;

/**
 * 校验编排器 - 并行调度多源校验
 */
@Component
@Slf4j
public class VerificationOrchestrator {

    @Autowired private KnowledgeBaseVerifier kbVerifier;
    @Autowired private RuleEngineVerifier ruleVerifier;
    @Autowired private LlmReasoningVerifier llmVerifier;

    private final ExecutorService verificationPool = Executors.newFixedThreadPool(
        Runtime.getRuntime().availableProcessors() * 2,
        new ThreadFactoryBuilder().setNameFormat("fckav-verify-%d").build()
    );

    /**
     * 并行执行多源校验
     */
    public List<ClaimVerificationResult> verifyParallel(
            List<FactClaim> claims, FactCheckOptions options) {

        // 为每个claim创建并行校验任务
        List<CompletableFuture<ClaimVerificationResult>> futures = claims.stream()
            .map(claim -> CompletableFuture.supplyAsync(
                () -> verifySingleClaim(claim, options),
                verificationPool
            ))
            .toList();

        // 等待全部完成
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();

        return futures.stream()
            .map(CompletableFuture::join)
            .filter(Objects::nonNull)
            .toList();
    }

    private ClaimVerificationResult verifySingleClaim(FactClaim claim, FactCheckOptions options) {
        List<CompletableFuture<SourceVerdict>> sourceFutures = new ArrayList<>();

        // 知识库比对
        if (options.isEnableKbCheck()) {
            sourceFutures.add(CompletableFuture.supplyAsync(
                () -> safeVerify(() -> kbVerifier.verify(claim)),
                verificationPool
            ));
        }

        // 规则引擎校验
        if (options.isEnableRuleCheck()) {
            sourceFutures.add(CompletableFuture.supplyAsync(
                () -> safeVerify(() -> ruleVerifier.verify(claim)),
                verificationPool
            ));
        }

        // LLM推理校验
        if (options.isEnableLlmCheck()) {
            sourceFutures.add(CompletableFuture.supplyAsync(
                () -> safeVerify(() -> llmVerifier.verify(claim)),
                verificationPool
            ));
        }

        // 收集所有源的判定
        List<SourceVerdict> sourceVerdicts = sourceFutures.stream()
            .map(CompletableFuture::join)
            .filter(Objects::nonNull)
            .toList();

        return ClaimVerificationResult.builder()
            .claim(claim)
            .sourceVerdicts(sourceVerdicts)
            .build();
    }

    /**
     * 安全执行校验, 捕获异常避免单源失败影响整体
     */
    private SourceVerdict safeVerify(Supplier<SourceVerdict> verifier) {
        try {
            return verifier.get();
        } catch (Exception e) {
            log.warn("Source verification failed: {}", e.getMessage());
            return SourceVerdict.failed(e.getMessage());
        }
    }
}
```

### 5.4 知识库校验器

```java
package com.primetop.factcheck.verifier;

/**
 * 权威知识库校验器
 * 通过向量检索 + 语义匹配验证事实声明
 */
@Component
@Slf4j
public class KnowledgeBaseVerifier implements SourceVerifier {

    @Autowired private MilvusClient milvusClient;
    @Autowired private EmbeddingService embeddingService;
    @Autowired private AuthoritativeKnowledgeMapper knowledgeMapper;
    @Autowired private RedisTemplate<String, Object> redisTemplate;

    private static final int TOP_K = 5;
    private static final double SIMILARITY_THRESHOLD = 0.75;

    @Override
    public SourceVerdict verify(FactClaim claim) {
        long start = System.currentTimeMillis();

        // 1. 生成声明向量
        float[] embedding = embeddingService.embed(claim.getClaimText());

        // 2. 向量检索权威知识
        SearchResponse searchResponse = milvusClient.search(SearchParam.newBuilder()
            .withCollectionName("authoritative_knowledge_embeddings")
            .withVectors(List.of(embedding))
            .withTopK(TOP_K)
            .withFilter(String.format("subject == \"%s\"", claim.getSubject()))
            .withOutputFields(List.of("knowledge_id", "subject", "domain"))
            .build());

        List<SearchResult> hits = searchResponse.getResults();

        if (hits.isEmpty()) {
            return SourceVerdict.builder()
                .source("KNOWLEDGE_BASE")
                .score(50.0) // 中性分数：无足够信息判定
                .verdict(Verdict.UNVERIFIABLE)
                .evidence(Collections.emptyList())
                .elapsedMs(System.currentTimeMillis() - start)
                .build();
        }

        // 3. 取最相似的条目进行语义匹配
        List<Evidence> evidenceList = new ArrayList<>();
        double bestScore = 0.0;
        AuthoritativeKnowledge bestMatch = null;

        for (SearchResult hit : hits) {
            String knowledgeId = (String) hit.get("knowledge_id").getData();
            AuthoritativeKnowledge knowledge = knowledgeMapper.findByKnowledgeId(knowledgeId);

            if (knowledge == null || !"APPROVED".equals(knowledge.getReviewStatus())) {
                continue;
            }

            double similarity = hit.getScore();
            if (similarity > bestScore) {
                bestScore = similarity;
                bestMatch = knowledge;
            }

            if (similarity >= SIMILARITY_THRESHOLD) {
                evidenceList.add(Evidence.builder()
                    .source(knowledge.getSource())
                    .text(knowledge.getStatement())
                    .sourceDetail(knowledge.getSourceDetail())
                    .score(similarity)
                    .build());
            }
        }

        // 4. 判定
        double score;
        Verdict verdict;

        if (bestScore >= 0.90) {
            // 高相似度：判定为正确
            // 使用NLI模型进一步确认语义一致（非矛盾）
            boolean isEntailment = checkEntailment(claim.getClaimText(), bestMatch.getStatement());
            score = isEntailment ? 95.0 : 40.0;
            verdict = isEntailment ? Verdict.CORRECT : Verdict.INCORRECT;
        } else if (bestScore >= SIMILARITY_THRESHOLD) {
            // 中等相似度：部分正确
            score = 70.0;
            verdict = Verdict.PARTIALLY_CORRECT;
        } else {
            // 低相似度：无法验证
            score = 50.0;
            verdict = Verdict.UNVERIFIABLE;
        }

        return SourceVerdict.builder()
            .source("KNOWLEDGE_BASE")
            .score(score)
            .verdict(verdict)
            .evidence(evidenceList)
            .elapsedMs(System.currentTimeMillis() - start)
            .build();
    }

    /**
     * 使用NLI(自然语言推断)模型检测蕴含/矛盾关系
     * @return true=entailment(蕴含), false=contradiction(矛盾)
     */
    private boolean checkEntailment(String premise, String hypothesis) {
        // 调用轻量级NLI模型(如DeBERTa-v3-large-mnli)
        // 判断 premise 是否蕴含 hypothesis
        // 返回: true=蕴含(语义一致), false=矛盾(语义冲突)
        try {
            NliResult result = nliClient.infer(premise, hypothesis);
            return result.getLabel().equals("ENTAILMENT");
        } catch (Exception e) {
            log.warn("NLI check failed, fallback to similarity only: {}", e.getMessage());
            return true; // 降级：仅依赖向量相似度
        }
    }
}
```

### 5.5 规则引擎校验器

```java
package com.primetop.factcheck.verifier;

/**
 * 学科规则引擎校验器
 * 对公式、常数、日期等结构化事实进行精确校验
 */
@Component
@Slf4j
public class RuleEngineVerifier implements SourceVerifier {

    @Autowired private SubjectVerificationRuleMapper ruleMapper;
    @Autowired private RedisTemplate<String, Object> redisTemplate;

    @Override
    public SourceVerdict verify(FactClaim claim) {
        long start = System.currentTimeMillis();

        // 1. 加载该学科的校验规则(带缓存)
        List<SubjectVerificationRule> rules = loadRulesWithCache(
            claim.getSubject(),
            claim.getSubjectDomain()
        );

        if (rules.isEmpty()) {
            return SourceVerdict.builder()
                .source("RULE_ENGINE")
                .score(50.0)
                .verdict(Verdict.UNVERIFIABLE)
                .evidence(Collections.emptyList())
                .elapsedMs(System.currentTimeMillis() - start)
                .build();
        }

        // 2. 按规则类型分派校验
        for (SubjectVerificationRule rule : rules) {
            RuleCheckResult result = applyRule(rule, claim);
            if (result.isMatched()) {
                return SourceVerdict.builder()
                    .source("RULE_ENGINE")
                    .score(result.getScore())
                    .verdict(result.getVerdict())
                    .evidence(List.of(Evidence.builder()
                        .source("学科规则: " + rule.getRuleName())
                        .text(rule.getRuleExpression())
                        .score(1.0)
                        .build()))
                    .elapsedMs(System.currentTimeMillis() - start)
                    .build();
            }
        }

        // 3. 无规则命中
        return SourceVerdict.builder()
            .source("RULE_ENGINE")
            .score(50.0)
            .verdict(Verdict.UNVERIFIABLE)
            .evidence(Collections.emptyList())
            .elapsedMs(System.currentTimeMillis() - start)
            .build();
    }

    private RuleCheckResult applyRule(SubjectVerificationRule rule, FactClaim claim) {
        return switch (rule.getRuleType()) {
            case "FORMULA_CHECK" -> checkFormula(rule, claim);
            case "RANGE_CHECK" -> checkNumericRange(rule, claim);
            case "DATE_CHECK" -> checkHistoricalDate(rule, claim);
            case "UNIT_CHECK" -> checkUnitConsistency(rule, claim);
            case "LOGIC_CHECK" -> checkLogicalConsistency(rule, claim);
            default -> RuleCheckResult.notMatched();
        };
    }

    /**
     * 公式校验：将文本中的公式与标准公式模式匹配
     */
    private RuleCheckResult checkFormula(SubjectVerificationRule rule, FactClaim claim) {
        try {
            JsonNode expr = new ObjectMapper().readTree(rule.getRuleExpression());
            String pattern = expr.get("pattern").asText();
            String expected = expr.get("expected").asText();

            Pattern p = Pattern.compile(pattern);
            Matcher m = p.matcher(claim.getClaimText());

            if (m.find()) {
                String foundFormula = m.group();
                boolean isCorrect = normalizeFormula(foundFormula)
                    .equals(normalizeFormula(expected));

                return RuleCheckResult.builder()
                    .matched(true)
                    .score(isCorrect ? 98.0 : 20.0)
                    .verdict(isCorrect ? Verdict.CORRECT : Verdict.INCORRECT)
                    .correction(isCorrect ? null : "正确公式: " + expected)
                    .build();
            }
        } catch (Exception e) {
            log.warn("Formula check failed for rule {}: {}", rule.getRuleId(), e.getMessage());
        }
        return RuleCheckResult.notMatched();
    }

    /**
     * 数值范围校验：检查物理常数等是否在容差范围内
     */
    private RuleCheckResult checkNumericRange(SubjectVerificationRule rule, FactClaim claim) {
        try {
            JsonNode expr = new ObjectMapper().readTree(rule.getRuleExpression());
            JsonNode constants = expr.get("constants");

            for (JsonNode constant : constants) {
                String name = constant.get("name").asText();
                double expectedValue = constant.get("value").asDouble();
                double tolerancePct = constant.get("tolerance_pct").asDouble();

                // 从声明中提取数值
                List<Double> numbers = extractNumbers(claim.getClaimText());
                for (Double num : numbers) {
                    double lowerBound = expectedValue * (1 - tolerancePct / 100);
                    double upperBound = expectedValue * (1 + tolerancePct / 100);

                    if (num >= lowerBound && num <= upperBound) {
                        return RuleCheckResult.builder()
                            .matched(true)
                            .score(99.0)
                            .verdict(Verdict.CORRECT)
                            .build();
                    }
                    // 如果数值接近但超出容差，标记为部分正确
                    double deviation = Math.abs(num - expectedValue) / expectedValue * 100;
                    if (deviation < 10) {
                        return RuleCheckResult.builder()
                            .matched(true)
                            .score(45.0)
                            .verdict(Verdict.PARTIALLY_CORRECT)
                            .correction(String.format(
                                "%s的标准值约为%s，偏差%.1f%%",
                                name, expectedValue, deviation
                            ))
                            .build();
                    }
                }
            }
        } catch (Exception e) {
            log.warn("Range check failed: {}", e.getMessage());
        }
        return RuleCheckResult.notMatched();
    }

    /**
     * 历史日期校验
     */
    private RuleCheckResult checkHistoricalDate(SubjectVerificationRule rule, FactClaim claim) {
        try {
            JsonNode expr = new ObjectMapper().readTree(rule.getRuleExpression());
            JsonNode facts = expr.get("known_facts");

            for (JsonNode fact : facts) {
                String event = fact.get("event").asText();
                String correctDate = fact.get("date").asText();
                int toleranceYears = fact.get("tolerance_years").asInt();

                // 检查声明是否提及该事件
                if (claim.getClaimText().contains(event)) {
                    // 提取声明中的日期
                    String extractedDate = extractDate(claim.getClaimText());
                    if (extractedDate != null) {
                        int yearDiff = dateYearDifference(extractedDate, correctDate);
                        if (yearDiff <= toleranceYears) {
                            return RuleCheckResult.builder()
                                .matched(true)
                                .score(99.0)
                                .verdict(Verdict.CORRECT)
                                .build();
                        } else {
                            return RuleCheckResult.builder()
                                .matched(true)
                                .score(15.0)
                                .verdict(Verdict.INCORRECT)
                                .correction(String.format(
                                    "%s的正确时间是%s，而非%s",
                                    event, correctDate, extractedDate
                                ))
                                .build();
                        }
                    }
                }
            }
        } catch (Exception e) {
            log.warn("Date check failed: {}", e.getMessage());
        }
        return RuleCheckResult.notMatched();
    }

    @Cacheable(value = "fckav_rules", key = "#subject + ':' + #domain")
    public List<SubjectVerificationRule> loadRulesWithCache(String subject, String domain) {
        return ruleMapper.findBySubjectAndDomain(subject, domain);
    }
```

```java
package com.primetop.factcheck.consumer;

/**
 * 异步校验任务消费者
 */
@Component
@Slf4j
public class FactCheckTaskConsumer {

    @Autowired private FactCheckEngine engine;
    @Autowired private VerificationTaskMapper taskMapper;

    @KafkaListener(
        topics = "fact-check-tasks",
        groupId = "fckav-worker",
        concurrency = "3"
    )
    public void handle(FactCheckMessage message) {
        log.info("Processing fact check task: {}", message.getTaskId());

        try {
            FactCheckResult result = engine.verifySync(message.getRequest());

            // 如果有回调URL，发送结果
            if (message.getRequest().getCallbackUrl() != null) {
                sendCallback(message.getRequest().getCallbackUrl(), result);
            }

        } catch (Exception e) {
            log.error("Async fact check failed for task: {}", message.getTaskId(), e);
            // 更新任务状态为失败
            VerificationTask task = taskMapper.findByTaskId(message.getTaskId());
            if (task != null) {
                task.setStatus(TaskStatus.FAILED);
                task.setErrorMessage(e.getMessage());
                taskMapper.updateById(task);
            }
            // 重试策略：3次重试后进入死信队列
            throw e;
        }
    }

    private void sendCallback(String url, FactCheckResult result) {
        try {
            webClient.post()
                .uri(url)
                .bodyValue(result)
                .retrieve()
                .bodyToMono(String.class)
                .timeout(Duration.ofSeconds(10))
                .subscribe(
                    r -> log.debug("Callback sent successfully"),
                    e -> log.warn("Callback failed: {}", e.getMessage())
                );
        } catch (Exception e) {
            log.warn("Callback delivery failed for url={}", url, e);
        }
    }
}
```

```java
/**
 * 校验任务重试策略
 */
public class FactCheckRetryPolicy implements RetryPolicy {

    @Override
    public boolean canRetry(RetryContext context) {
        int retryCount = context.getRetryCount();
        Throwable lastError = context.getLastThrowable();

        // 最多重试3次
        if (retryCount >= 3) return false;

        // 超时不重试(实时场景)
        if (lastError instanceof TimeoutException) return false;

        // 参数错误不重试
        if (lastError instanceof IllegalArgumentException) return false;

        // 网络错误/服务不可用 → 重试
        return lastError instanceof ServiceUnavailableException
            || lastError instanceof IOException;
    }

    @Override
    public long getRetryInterval(RetryContext context) {
        // 指数退避: 1s, 3s, 9s
        return (long) Math.pow(3, context.getRetryCount()) * 1000;
    }
}
```

```yaml
    skip-on-llm-failure: false
    skip-on-vector-failure: false
    skip-on-all-failure: true   # 全部失败时跳过校验，不阻塞业务

  # Kafka配置
  kafka:
    topic: fact-check-tasks
    consumer-group: fckav-worker
    concurrency: 3
    retry-max: 3
    dlq-topic: fact-check-dlq
```

```java
                .options(FactCheckOptions.quick())
                .build()
        );

            response.addDisclaimer(

            );
            response.setQualityFlag("FACT_CHECK_WARNING");
        }

        // 异步提交完整校验
        factCheckEngine.verifyAsync(
            FactCheckRequest.builder()
                .content(response.getContent())
                .sourceType("AI_RESPONSE")
                .sourceId(response.getMessageId())
                .subject(ctx.getSubject())
                .build()
        );

        return response;
    }
}
```

```java
// 内容发布前校验门禁
@Component
public class ContentPublishGate {

    @Autowired private FactCheckEngine factCheckEngine;

    public PublishDecision checkBeforePublish(Content content) {
        FactCheckResult result = factCheckEngine.verifySync(
            FactCheckRequest.builder()
                .sourceType(content.getType())
                .sourceId(content.getId())
                .content(content.getBody())
                .subject(content.getSubject())
                .priority(3)
                .build()
        );

        // 发布门禁规则
        if (result.getOverallScore() < 60.0) {
            return PublishDecision.block(
                "内容事实校验未通过(score=" + result.getOverallScore() + ")，" +
                "请修正标记为INCORRECT的内容后重新提交。"
            );
        }

        if (result.getOverallScore() < 80.0) {
            return PublishDecision.warn(
                "内容存在部分待确认声明，建议人工复核后发布。"
            );
        }

        return PublishDecision.approve();
    }
}
```

### 12.1 完整数据字典

**claim_type 枚举：**

| 值 | 说明 | 典型场景 |
|----|------|---------|
| DATE | 日期/时间声明 | 历史事件时间、物理实验时间 |
| NUMBER | 数值声明 | 物理常数、统计数据 |
| FORMULA | 公式声明 | 数学/物理/化学公式 |
| DEFINITION | 定义声明 | 概念定义、定律描述 |
| CAUSALITY | 因果声明 | 科学因果关系 |
| CITATION | 引用声明 | 文献引用、古文出处 |
| ENTITY | 实体声明 | 人物、地点、事件属性 |
| LOGIC | 逻辑声明 | 推理步骤、证明过程 |

**verdict 枚举：**

| 值 | 含义 | 置信度范围 |
|----|------|-----------|
| CORRECT | 事实正确 | ≥ 85 |
| PARTIALLY_CORRECT | 部分正确 | 50-84 |
| INCORRECT | 事实错误 | < 50 |
| UNVERIFIABLE | 无法验证 | N/A |

### 12.2 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|----------|
| 大量UNVERIFIABLE | 权威知识库覆盖不足 | 按学科优先级补充知识条目 |
| 校验结果误报率高 | NLI模型准确性不足 | 调整相似度阈值或更换NLI模型 |
| LLM抽取遗漏声明 | Prompt不够精确 | 迭代优化抽取Prompt模板 |
| 实时校验超时 | 并发量过高 | 扩容线程池或启用降级模式 |
| 知识库检索噪音多 | 向量索引数据质量问题 | 清洗知识库，移除重复/低质条目 |
