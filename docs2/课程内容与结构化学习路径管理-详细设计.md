# 课程内容与结构化学习路径管理 - 详细设计

> 版本：v1.0 | 日期：2026-05-23 | 状态：初稿

## 1. 模块概述

### 1.1 功能定位

课程内容与结构化学习路径管理系统（Course & Learning Path Management，简称 CLPM）负责管理结构化的学习路径（Learning Path）、课程（Course）、课时（Lesson）及其关联内容。为用户提供从"入学测试 → 路径推荐 → 按序学习 → 阶段检测 → 路径调整"的完整学习旅程。

CLPM 是连接"知识点体系"、"题目与题库"、"自适应推荐"、"学情分析"等模块的编排层——**知识点和题目是原材料，课程和路径是菜谱**。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 结构化编排 | 支持灵活的课程树和路径拓扑（线性/分支/条件跳转） |
| 多源聚合 | 一节课可组合 AI 讲解、练习题、知识点卡片、视频、文档等多种资源 |
| 进度可追踪 | 细粒度到课时级别的完成状态、用时、正确率 |
| 门槛与前置 | 支持前置条件、解锁策略、最低通过标准 |
| 动态调整 | 基于学情数据推荐跳级、补弱、换路径 |
| 运营可配 | 课程与路径通过管理后台 CRUD，无需发版 |

### 1.3 与相关模块的关系

```
┌─────────────────────────────────────────────────────────┐
│                  课程内容与学习路径管理 (CLPM)             │
│                                                         │
│  LearningPath ──1:N──> Course ──1:N──> Lesson           │
│      │                   │                │              │
│      │                   │                ├─ AI 讲解      │
│      │                   │                ├─ 练习题组     │
│      │                   │                ├─ 知识点卡片   │
│      │                   │                ├─ 视频/音频    │
│      │                   │                └─ 文档/PDF     │
│      │                   │                               │
│  入学测试 ←──> 自适应推荐引擎 ──> 路径推荐               │
│  完成条件 ←──> 练习与测评系统                              │
│  知识点映射 ←──> 知识点体系与教材映射引擎                  │

│  内容安全 ←──> 安全与内容合规系统                          │
└─────────────────────────────────────────────────────────┘
```

### 1.4 核心术语

| 术语 | 说明 |
|------|------|
| LearningPath（学习路径） | 一组有序课程的集合，代表一个完整学习目标（如"中考数学冲刺"） |
| Course（课程） | 一个独立学习单元，包含若干课时，对应一个或多个知识点 |
| Lesson（课时） | 最小学习单元，包含一种或多种内容类型（讲解/练习/视频等） |
| Enrollment（报名/注册） | 用户加入一条学习路径的记录 |
| Progress（进度） | 用户在某个课程/课时上的完成状态 |
| Gate（关卡/门槛） | 课程之间的解锁条件和通过标准 |
| PathNode（路径节点） | 学习路径拓扑中的一个位置，指向一个 Course |

### 2.2 学习路径表 (learning_paths)

```sql
CREATE TABLE learning_paths (
```

### 2.3 路径节点表 (path_nodes)

```sql
CREATE TABLE path_nodes (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    path_id         BIGINT NOT NULL COMMENT '所属学习路径',
    course_id       BIGINT NOT NULL COMMENT '指向的课程',
    node_type       ENUM('required', 'optional', 'bonus') NOT NULL DEFAULT 'required'
                    COMMENT 'required=必修, optional=选修, bonus=加餐',
    
    -- 拓扑关系（支持分支结构）
    parent_node_id  BIGINT DEFAULT NULL COMMENT '父节点（NULL 表示根节点）',
    branch_group    VARCHAR(32) DEFAULT NULL COMMENT '分支组标识（同组内为选择关系）',
    position        INT NOT NULL DEFAULT 0 COMMENT '同层级排序',
    
    -- 解锁条件
    unlock_type     ENUM('auto', 'sequential', 'gate', 'manual') NOT NULL DEFAULT 'sequential'
                    COMMENT 'auto=自动, sequential=前序完成, gate=通过门槛, manual=管理员解锁',
    gate_config     JSON DEFAULT NULL COMMENT '门槛配置 { "min_score": 60, "required_node_ids": [1,2] }',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_path_position (path_id, parent_node_id, position),
    INDEX idx_path (path_id),
    INDEX idx_course (course_id),
    FOREIGN KEY (path_id) REFERENCES learning_paths(id),
    FOREIGN KEY (course_id) REFERENCES courses(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='路径节点';
```

## 3. 状态流转

### 3.1 学习路径生命周期

```
  ┌──────────┐     审核通过      ┌───────────┐     发布      ┌───────────┐
  │  draft   │ ──────────────→ │  review   │ ──────────→ │ published │
  └──────────┘                  └───────────┘              └───────────┘
       ↑                              │ 驳回                     │
       │                              ↓                          │ 归档
       └────────────────────── draft │                          ↓
                                                            ┌───────────┐
                                                            │ archived  │
                                                            └───────────┘
```

### 3.2 用户报名状态机

```
                    ┌──────────────────────────────┐
                    │                              │
                    ↓                              │
  ┌─────────┐  激活   ┌────────┐  全部完成  ┌──────────┐
  │ active  │ ←───── │ active │ ────────→ │ completed│
  └─────────┘        └────────┘            └──────────┘
       │                 │
       │ 暂停            │ 放弃
       ↓                 ↓
  ┌─────────┐       ┌─────────┐
  │ paused  │       │ dropped │
  └─────────┘       └─────────┘
       │                 ↑
       │ 恢复            │
       └────→ active ────┘
       
  任意状态 ──过期──→ expired
```

### 3.3 课程/课时解锁流程

```
用户查看路径
  │
  ├─ 获取所有 PathNode
  ├─ 检查每个节点的 unlock_type
  │     ├─ auto: 直接 unlocked
  │     ├─ sequential: 前序节点全部 completed → unlocked
  │     ├─ gate: 检查 gate_config
  │     │     ├─ required_node_ids 全部 completed?
  │     │     ├─ min_score 达标?
  │     │     └─ → unlocked / locked
  │     └─ manual: 检查管理员解锁记录
  │
  └─ 返回节点列表 + 各节点状态 (locked/unlocked/in_progress/completed)
```

### 3.4 课时完成判定

```python
def check_lesson_completion(lesson: Lesson, progress: LessonProgress) -> bool:
    """根据课时类型判定是否完成"""
    config = lesson.content_config
    result = progress.result_data or {}
    
    match lesson.lesson_type:
        case 'ai_explain':
            # AI 讲解：浏览完成即算（达到最低浏览时长）
            return progress.time_spent_sec >= config.get('min_view_sec', 30)
            
        case 'practice':
            # 练习：达到通过分数
            score = result.get('score', 0)
            return score >= config.get('passing_score', 60)
            
        case 'video':
            # 视频：观看比例达标
            watch_pct = result.get('watch_pct', 0)
            return watch_pct >= config.get('completion_threshold', 80)
            
        case 'quiz':
            # 小测：达到通过分数
            score = result.get('score', 0)
            return score >= config.get('passing_score', 60)
            
        case 'reading' | 'summary':
            # 阅读/总结：达到最低浏览时长
            return progress.time_spent_sec >= config.get('min_view_sec', 15)
            
        case 'interactive':
            # 互动练习：完成所有互动项
            return result.get('all_interactions_done', False)
            
        case _:
            return progress.time_spent_sec > 0
```

### 5.1 路径推荐引擎

```python
class PathRecommendationEngine:
    """基于学情数据推荐学习路径"""
    
    def recommend(self, user_id: int, limit: int = 5) -> list[dict]:
        user = self.get_user_profile(user_id)
        mastery_map = self.get_knowledge_mastery(user_id)
        
        # 1. 过滤：年级匹配、未报名、已发布
        candidates = self.filter_paths(
            min_grade=user.grade,
            max_grade=user.grade,
            exclude_enrolled=user_id,
            status='published'
        )
        
        # 2. 评分
        scored = []
        for path in candidates:
            score = self._score_path(path, user, mastery_map)
            scored.append((path, score))
        
        # 3. 排序
        scored.sort(key=lambda x: x[1], reverse=True)
        return [{'path': p, 'score': s, 'reason': self._reason(p, user, mastery_map)} 
                for p, s in scored[:limit]]
    
    def _score_path(self, path: LearningPath, user: UserProfile, 
                    mastery_map: dict) -> float:
        score = 0.0
        
        # 薄弱知识点匹配 (权重 0.4)
        path_kps = self.get_path_knowledge_points(path.id)
        weak_kps = [kp for kp, m in mastery_map.items() if m < 0.6]
        overlap = len(set(path_kps) & set(weak_kps))
        score += 0.4 * (overlap / max(len(weak_kps), 1))
        
        # 难度匹配 (权重 0.2)
        difficulty_gap = abs(path.difficulty - self._user_difficulty(user))
        score += 0.2 * (1 - difficulty_gap / 5)
        
        # 时长匹配 (权重 0.2)
        avg_daily = user.avg_daily_study_minutes or 30
        estimated_days = path.estimated_hours * 60 / avg_daily
        if estimated_days <= 30:
            score += 0.2
        elif estimated_days <= 60:
            score += 0.1
        
        # 热度 (权重 0.1)
        score += 0.1 * min(path.enrollment_count / 10000, 1)
        
        # 标签匹配 (权重 0.1)
        if self._tag_match(path.tags, user.interests):
            score += 0.1
        
        return score
```

### 5.2 进度计算引擎

```python
class ProgressEngine:
    """计算和更新学习进度"""
    
    def on_lesson_complete(self, user_id: int, lesson_id: int, 
                           enrollment_id: int, result: dict):
        """课时完成回调"""
        # 1. 更新课时进度
        lp = self.update_lesson_progress(user_id, lesson_id, enrollment_id, result)
        
        # 2. 检查课程是否完成
        cp = self.get_course_progress(user_id, lp.course_id, enrollment_id)
        course = self.get_course(cp.course_id)
        
        completed_lessons = self.count_completed_lessons(cp.id)
        if self._is_course_complete(course, cp, completed_lessons):
            cp.status = 'completed'
            cp.completed_at = datetime.utcnow()
            self.save(cp)
            
            # 3. 检查路径节点解锁
            self._check_node_unlocks(user_id, enrollment_id, cp)
            
            # 4. 更新路径总进度
            self._update_path_progress(enrollment_id)
            
            # 5. 发送事件
            self.event_bus.emit('course.completed', {
                'user_id': user_id,
                'course_id': course.id,
                'enrollment_id': enrollment_id
            })
    
    def _is_course_complete(self, course: Course, cp: CourseProgress,
                            completed_lessons: int) -> bool:
        criteria = course.completion_criteria
        
        match criteria.get('type'):
            case 'all_lessons':
                return completed_lessons >= course.total_lessons
            
            case 'key_lessons':
                key_ids = criteria.get('required_lesson_ids', [])
                return self.all_lessons_completed(cp.id, key_ids)
            
            case 'min_score':
                return (cp.best_score or 0) >= criteria.get('value', 60)
            
            case _:
                return completed_lessons >= course.total_lessons
    
    def _check_node_unlocks(self, user_id: int, enrollment_id: int,
                            completed_cp: CourseProgress):
        """检查并解锁后续节点"""
        enrollment = self.get_enrollment(enrollment_id)
        nodes = self.get_path_nodes(enrollment.path_id)
        
        for node in nodes:
            if node.unlock_type == 'sequential':
                # 检查前序节点是否全部完成
                predecessors = self.get_predecessor_nodes(node.id)
                if all(self.is_node_completed(n.id, enrollment_id) for n in predecessors):
                    self.unlock_node(user_id, enrollment_id, node.id)
                    
            elif node.unlock_type == 'gate':
                gate = node.gate_config
                required = gate.get('required_node_ids', [])
                min_score = gate.get('min_score', 0)
                
                all_required_done = all(
                    self.is_node_completed(nid, enrollment_id) for nid in required
                )
                meets_score = all(
                    self.get_node_best_score(nid, enrollment_id) >= min_score
                    for nid in required
                )
                
                if all_required_done and meets_score:
                    self.unlock_node(user_id, enrollment_id, node.id)
    
    def _update_path_progress(self, enrollment_id: int):
        enrollment = self.get_enrollment(enrollment_id)
        nodes = self.get_path_nodes(enrollment.path_id)
        
        # 只计 required 节点
        required_nodes = [n for n in nodes if n.node_type == 'required']
        completed = sum(1 for n in required_nodes 
                       if self.is_node_completed(n.id, enrollment_id))
        
        enrollment.completed_courses = completed
        enrollment.total_courses = len(required_nodes)
        enrollment.progress_pct = (completed / max(len(required_nodes), 1)) * 100
        enrollment.last_active_at = datetime.utcnow()
        
        if enrollment.progress_pct >= 100:
            enrollment.status = 'completed'
            enrollment.completed_at = datetime.utcnow()
            self.event_bus.emit('path.completed', {
                'user_id': enrollment.user_id,
                'path_id': enrollment.path_id,
                'enrollment_id': enrollment_id
            })
        
        self.save(enrollment)
```

```python
class AdaptivePathAdjuster:
    """基于学习表现动态调整路径"""
    
    def suggest_adjustments(self, enrollment_id: int) -> list[dict]:
        enrollment = self.get_enrollment(enrollment_id)
        user_id = enrollment.user_id
        
        suggestions = []
        
        # 1. 跳级建议：连续高分 → 可跳过简单课程
        recent_scores = self.get_recent_scores(user_id, enrollment_id, limit=5)
        if recent_scores and all(s >= 90 for s in recent_scores):
            skip_candidates = self.find_skippable_nodes(enrollment_id)
            if skip_candidates:
                suggestions.append({
                    'type': 'skip',
                    'reason': 'recent_high_scores',
                    'nodes': skip_candidates,
                    'message': '你最近表现出色！可以跳过部分基础内容。'
                })
        
        # 2. 补弱建议：低分 → 插入补充课程
        weak_nodes = self.get_weak_nodes(enrollment_id, threshold=50)
        for node in weak_nodes:
            remedial_courses = self.find_remedial_courses(node.course_id)
            if remedial_courses:
                suggestions.append({
                    'type': 'reinforce',
                    'reason': 'low_score',
                    'after_node_id': node.id,
                    'courses': remedial_courses,
                    'message': f'建议在继续之前巩固一下这个知识点。'
                })
        
        # 3. 分支推荐：根据兴趣或表现推荐分支
        current_node = self.get_current_node(enrollment_id)
        if current_node and current_node.branch_group:
            siblings = self.get_sibling_nodes(current_node.id)
            if len(siblings) > 1:
                # 推荐最适合的分支
                best_branch = self._rank_branches(siblings, user_id)
                suggestions.append({
                    'type': 'branch_recommend',
                    'reason': 'performance_based',
                    'recommended_node_id': best_branch.id,
                    'alternatives': [s.id for s in siblings if s.id != best_branch.id]
                })
        
        return suggestions
```

```python
# services/course_service.py

from typing import Optional
from fastapi import APIRouter, Depends, HTTPException
from sqlalchemy.orm import Session
from pydantic import BaseModel

router = APIRouter(prefix="/api/v1/courses", tags=["courses"])


class LessonCompleteRequest(BaseModel):
    enrollment_id: int
    time_spent_sec: int
    result_data: Optional[dict] = None
    answer_data: Optional[dict] = None


class LessonCompleteResponse(BaseModel):
    completed: bool
    lesson_progress_id: int
    next_lesson: Optional[dict]
    course_progress: dict


@router.post("/{course_id}/lessons/{lesson_id}/complete", 
             response_model=LessonCompleteResponse)
async def complete_lesson(
    course_id: int,
    lesson_id: int,
    req: LessonCompleteRequest,
    db: Session = Depends(get_db),
    user_id: int = Depends(get_current_user_id)
):
    """完成一个课时"""
    # 1. 校验
    lesson = db.query(Lesson).filter(
        Lesson.id == lesson_id,
        Lesson.course_id == course_id
    ).first()
    if not lesson:
        raise HTTPException(status_code=404, detail="LESSON_NOT_FOUND")
    
    course_progress = db.query(CourseProgress).filter(
        CourseProgress.user_id == user_id,
        CourseProgress.course_id == course_id,
        CourseProgress.enrollment_id == req.enrollment_id
    ).first()
    if not course_progress:
        raise HTTPException(status_code=404, detail="COURSE_PROGRESS_NOT_FOUND")
    
    # 2. 更新课时进度
    lesson_progress = db.query(LessonProgress).filter(
        LessonProgress.user_id == user_id,
        LessonProgress.lesson_id == lesson_id,
        LessonProgress.course_progress_id == course_progress.id
    ).first()
    
    if not lesson_progress:
        raise HTTPException(status_code=404, detail="LESSON_PROGRESS_NOT_FOUND")
    
    lesson_progress.time_spent_sec += req.time_spent_sec
    lesson_progress.attempt_count += 1
    lesson_progress.status = 'completed'
    lesson_progress.completed_at = datetime.utcnow()
    lesson_progress.result_data = req.result_data
    lesson_progress.answer_data = req.answer_data
    
    # 3. 判定课程完成
    progress_engine = ProgressEngine(db)
    completed_lessons = db.query(LessonProgress).filter(
        LessonProgress.course_progress_id == course_progress.id,
        LessonProgress.status == 'completed'
    ).count()
    
    course = db.query(Course).get(course_id)
    is_course_done = progress_engine.is_course_complete(
        course, course_progress, completed_lessons
    )
    
    if is_course_done:
        course_progress.status = 'completed'
        course_progress.completed_at = datetime.utcnow()
        progress_engine.on_course_complete(user_id, course_id, req.enrollment_id)
    
    db.commit()
    
    # 4. 查找下一个课时
    next_lesson = db.query(Lesson).filter(
        Lesson.course_id == course_id,
        Lesson.position > lesson.position,
        Lesson.status == 'published'
    ).order_by(Lesson.position).first()
    
    next_lesson_data = None
    if next_lesson:
        next_lesson_data = {
            "id": next_lesson.id,
            "title": next_lesson.title,
            "status": "unlocked"
        }
    
    return LessonCompleteResponse(
        completed=True,
        lesson_progress_id=lesson_progress.id,
        next_lesson=next_lesson_data,
        course_progress={
            "status": course_progress.status,
            "lessons_completed": completed_lessons,
            "lessons_total": course.total_lessons
        }
    )
```

```dart
        return CustomScrollView(
          slivers: [
            // 路径头部信息
            SliverToBoxAdapter(
              child: _PathHeader(detail: pathDetail),
            ),
            // 进度条
            SliverToBoxAdapter(
              child: _ProgressBar(
                progress: pathDetail.progress?.progressPct ?? 0,
                completed: pathDetail.progress?.completedCourses ?? 0,
                total: pathDetail.progress?.totalCourses ?? 0,
              ),
            ),
            // 节点列表
            SliverList(
              delegate: SliverChildBuilderDelegate(
                (context, index) {
                  final node = pathDetail.nodes[index];
                  return _PathNodeCard(
                    node: node,
                    onTap: () => _onNodeTap(context, ref, node),
                  );
                },
                childCount: pathDetail.nodes.length,
              ),
            ),
          ],
        );
      },
    );
  }

  void _onNodeTap(BuildContext context, WidgetRef ref, PathNode node) {
    if (node.status == 'locked') {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('请先完成前面的课程')),
      );
      return;
    }
    // 导航到课程详情
    context.push('/learning-paths/$pathId/courses/${node.courseId}');
  }
}
```

```dart
final enrollPathProvider = AsyncNotifierProvider<EnrollPathNotifier, AsyncValue>(

class EnrollPathNotifier extends AsyncNotifier<AsyncValue> {
  @override
  AsyncValue build() => const AsyncValue.data(null);

  Future<EnrollmentResult> enroll(int pathId, {
    String source = 'self',
    Map<int, String>? selectedBranches,
  }) async {
    state = const AsyncValue.loading();
    try {
      final api = ref.read(apiServiceProvider);
      final response = await api.post(
        '/api/v1/learning-paths/$pathId/enroll',
        data: {
          'source': source,
          'selected_branches': selectedBranches,
        },
      );
      final result = EnrollmentResult.fromJson(response.data['data']);
      
      // 刷新相关 provider
      ref.invalidate(userEnrollmentsProvider);
      ref.invalidate(learningPathDetailProvider(pathId));
      
      state = const AsyncValue.data(null);
      return result;
    } catch (e, st) {
      state = AsyncValue.error(e, st);
      rethrow;
    }
  }
}
```

## 8. 缓存策略

### 8.1 缓存层级

| 缓存对象 | 缓存层 | TTL | 失效策略 |
|----------|--------|-----|----------|
| 学习路径列表（热门） | Redis | 10 min | 发布/下架时主动失效 |
| 学习路径详情（拓扑） | Redis | 30 min | 内容变更时主动失效 |
| 课程详情（含课时） | Redis | 30 min | 课时增删改时失效 |
| 用户进度 | Redis + DB | 5 min | 每次完成课时时更新 |
| 路径推荐结果 | Redis | 1 hour | 学情数据变更时失效 |
| 课时内容配置 | Redis | 1 hour | 后台编辑时失效 |

## 9. 错误处理

### 9.1 错误码定义

| 错误码 | HTTP | 说明 |
|--------|------|------|
| `PATH_001` | 404 | 学习路径不存在 |
| `PATH_002` | 400 | 学习路径未发布 |
| `PATH_003` | 409 | 用户已报名该路径 |
| `PATH_004` | 403 | 年级不匹配 |
| `PATH_005` | 403 | 需先完成入学测试 |
| `PATH_006` | 403 | 需要会员权限 |
| `PATH_007` | 410 | 路径已过期 |
| `COURSE_001` | 404 | 课程不存在 |
| `COURSE_002` | 403 | 课程已锁定 |
| `COURSE_003` | 400 | 课程未发布 |
| `LESSON_001` | 404 | 课时不存在 |
| `LESSON_002` | 403 | 课时已锁定 |
| `LESSON_003` | 400 | 课时类型不匹配 |
| `LESSON_004` | 429 | 练习重试次数超限 |
| `ENROLLMENT_001` | 404 | 报名记录不存在 |
| `ENROLLMENT_002` | 400 | 报名状态异常 |
| `PROGRESS_001` | 409 | 进度冲突（并发更新） |

### 9.2 降级策略

| 场景 | 降级方案 |
|------|----------|
| 路径推荐服务不可用 | 返回运营配置的固定推荐列表 |
| AI 讲解会话创建失败 | 降级为静态知识点卡片展示 |
| 动态题目生成失败 | 使用固定题池 |
| 进度写入失败 | 客户端本地缓存，延迟重试上报 |
| 入学测试服务不可用 | 允许跳过入学测试，稍后补测 |
| 视频服务不可用 | 展示文字替代内容 |

## 13. 安全与合规

1. **内容安全**：课程描述、课时内容均需经过内容安全审核（接入安全与内容合规系统）
2. **会员权限**：部分路径/课程可设置为会员专享，报名前校验会员状态
3. **年级保护**：低年级用户不可访问超出其学段范围的内容
4. **数据隔离**：B 端机构路径数据与其他数据隔离（参考 B 端合作方案）
5. **操作审计**：管理后台所有路径/课程变更记录审计日志
