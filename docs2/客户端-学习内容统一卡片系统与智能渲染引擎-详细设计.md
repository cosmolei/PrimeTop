# 客户端-学习内容统一卡片系统与智能渲染引擎 详细设计

## 1. 概述

### 1.1 模块定位

学习内容统一卡片系统（Learning Content Card System，简称 LCCS）是 PrimeTop 客户端的**底层内容渲染基础设施**。它将不同类型的学习内容（课程章节、练习题、错题、知识点、学习报告、活动入口等）抽象为统一的卡片数据协议，通过智能渲染引擎实现一次定义、处处可用。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 卡片协议定义 | 统一所有学习内容的卡片数据格式（Card Schema） |
| 卡片类型注册 | 支持卡片类型的动态注册、版本管理和热更新 |
| 智能渲染 | 根据卡片类型自动匹配渲染模板，处理布局差异 |
| 交互统一 | 统一点击、长按、滑动等交互行为与回调链 |
| 状态管理 | 统一处理卡片的加载、空、错误、骨架屏状态 |
| 曝光埋点 | 卡片级曝光、点击、停留时长的自动化埋点 |

### 1.3 与其他模块的边界

| 模块 | 关系 |
|------|------|
| 客户端-组件库与设计系统 | LCCS 基于 UI 组件库构建卡片，组件库提供原子组件，LCCS 提供业务级卡片 |
| 客户端-首页内容卡片推荐与聚合编排服务 | 首页编排服务决定"展示哪些卡片"，LCCS 负责"如何渲染卡片" |
| 客户端-动态化运营活动页面与JSON驱动渲染引擎 | 运营活动页面是独立的 JSON DSL 渲染体系，LCCS 不覆盖全页面动态化 |
| 客户端-通用列表组件与分页加载引擎 | 列表组件提供滚动容器和分页能力，LCCS 提供列表项的卡片渲染 |
| 客户端-埋点事件体系与数据采集规范 | LCCS 遵循统一埋点规范，自动产出卡片级曝光/点击事件 |

### 3.2 CardRegistry — 卡片类型注册中心

`CardRegistry` 是卡片类型的全局注册表。各业务模块在应用初始化阶段注册自己的卡片类型与对应的渲染器。

```dart
/// 卡片渲染器抽象接口
abstract class ICardRenderer {
  /// 卡片类型标识
  String get cardType;

  /// 支持的协议版本范围
  VersionRange get supportedVersions;

  /// 渲染卡片
  Widget build(BuildContext context, CardSchema card, CardRenderConfig config);

  /// 卡片默认尺寸估算（用于瀑布流/网格布局）
  Size estimateSize(CardSchema card, BoxConstraints constraints);

  /// 是否支持此卡片数据（用于版本兼容判断）
  bool canHandle(CardSchema card) {
    return card.cardType == cardType &&
        supportedVersions.contains(card.cardVersion);
  }
}

/// 卡片类型注册中心
class CardRegistry {
  final Map<String, List<ICardRenderer>> _renderers = {};
  final Map<String, CardRendererFactory> _factories = {};

  static final CardRegistry _instance = CardRegistry._();
  factory CardRegistry() => _instance;
  CardRegistry._();

  /// 注册卡片渲染器
  void register(ICardRenderer renderer) {
    final type = renderer.cardType;
    _renderers.putIfAbsent(type, () => []).add(renderer);
    // 按版本优先级排序：高版本优先匹配
    _renderers[type]!.sort((a, b) =>
        b.supportedVersions.max.compareTo(a.supportedVersions.max));
  }

  /// 懒注册（工厂模式，首次使用时创建）
  void registerFactory(String cardType, CardRendererFactory factory) {
    _factories[cardType] = factory;
  }

  /// 解析卡片渲染器
  ICardRenderer? resolve(CardSchema card) {
    final renderers = _renderers[card.cardType];
    if (renderers != null) {
      for (final r in renderers) {
        if (r.canHandle(card)) return r;
      }
    }
    // 尝试工厂创建
    final factory = _factories[card.cardType];
    if (factory != null) {
      final renderer = factory.create();
      register(renderer);
      return renderer;
    }
    return null;
  }
}

typedef CardRendererFactory = ICardRenderer Function();
```

### 3.3 CardResolver — 卡片解析器

负责将服务端返回的原始 JSON 数据解析为 `CardSchema`，并匹配到合适的渲染器。

```dart
class CardResolver {
  final CardRegistry _registry;

  CardResolver(this._registry);

  /// 解析卡片列表
  List<ResolvedCard> resolveBatch(List<Map<String, dynamic>> jsonList) {
    return jsonList.map((json) {
      final card = CardSchema.fromJson(json);
      final renderer = _registry.resolve(card);
      if (renderer == null) {
        return ResolvedCard(
          card: card,
          renderer: null,
          status: CardResolveStatus.unsupported,
        );
      }
      return ResolvedCard(
        card: card,
        renderer: renderer,
        status: CardResolveStatus.ready,
      );
    }).toList();
  }
}

/// 解析后的卡片
class ResolvedCard {
  final CardSchema card;
  final ICardRenderer? renderer;
  final CardResolveStatus status;

  const ResolvedCard({
    required this.card,
    required this.renderer,
    required this.status,
  });
}

enum CardResolveStatus { ready, unsupported, versionMismatch, parseError }
```

### 3.4 CardRenderEngine — 核心渲染引擎

```dart
class CardRenderEngine extends StatefulWidget {
  final List<ResolvedCard> cards;
  final ScrollController? scrollController;
  final CardListLayout layout;          // 列表整体布局
  final ValueChanged<CardSchema>? onCardTap;
  final ValueChanged<CardSchema>? onCardLongPress;
  final String pageSource;              // 当前页面标识（用于埋点）

  const CardRenderEngine({
    super.key,
    required this.cards,
    this.scrollController,
    this.layout = CardListLayout.singleColumn,
    this.onCardTap,
    this.onCardLongPress,
    required this.pageSource,
  });

  @override
  State<CardRenderEngine> createState() => _CardRenderEngineState();
}

class _CardRenderEngineState extends State<CardRenderEngine> {
  final ExposureTracker _exposureTracker = ExposureTracker();

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      controller: widget.scrollController,
      itemCount: widget.cards.length,
      itemBuilder: (context, index) {
        final resolved = widget.cards[index];
        return _buildCardSlot(context, resolved, index);
      },
    );
  }

  Widget _buildCardSlot(BuildContext context, ResolvedCard resolved, int index) {
    // 1. 处理解析失败
    if (resolved.status != CardResolveStatus.ready || resolved.renderer == null) {
      return FallbackCard(card: resolved.card, status: resolved.status);
    }

    // 2. 构建渲染配置
    final config = CardRenderConfig(
      pageSource: widget.pageSource,
      index: index,
      layout: widget.layout,
    );

    // 3. 包裹曝光追踪
    return ExposureTrackerWidget(
      tracker: _exposureTracker,
      tracking: resolved.card.tracking,
      child: _InteractionWrapper(
        card: resolved.card,
        onTap: () => _handleTap(resolved.card),
        onLongPress: () => _handleLongPress(resolved.card),
        child: resolved.renderer!.build(context, resolved.card, config),
      ),
    );
  }

  void _handleTap(CardSchema card) {
    // 1. 发送点击埋点
    AnalyticsService.instance.track(card.tracking.clickKey, {
      'card_type': card.cardType,
      'card_id': card.cardId,
      'source': card.tracking.source,
      'position': card.tracking.position,
    });
    // 2. 执行卡片主操作
    if (card.actions?.primary != null) {
      _executeAction(card.actions!.primary!, card);
    }
    // 3. 回调外部监听
    widget.onCardTap?.call(card);
  }

  void _handleLongPress(CardSchema card) {
    widget.onCardLongPress?.call(card);
  }

  void _executeAction(CardAction action, CardSchema card) {
    switch (action.type) {
      case 'navigate':
        if (action.target != null) {
          AppRouter.instance.push(action.target!, extra: card.content);
        }
        break;
      case 'quick_action':
        CardActionBus.instance.dispatch(action.action!, card);
        break;
      case 'action':
        CardActionBus.instance.dispatch(action.action!, card);
        break;
    }
  }
}
```

### 5.1 曝光判定逻辑

卡片曝光采用"可见面积 + 持续时间"双重判定：

```dart
class ExposureTracker {
  static const double _minVisibleRatio = 0.5;  // 最少 50% 可见
  static const Duration _minVisibleDuration = Duration(milliseconds: 500);

  final Map<String, ExposureRecord> _records = {};
  final List<ExposureEvent> _pendingEvents = [];
  Timer? _flushTimer;

  ExposureTracker() {
    _flushTimer = Timer.periodic(const Duration(seconds: 3), (_) => _flush());
  }

  void onCardVisible(String impressionKey, CardTracking tracking) {
    final now = DateTime.now();
    _records[impressionKey] = ExposureRecord(
      impressionKey: impressionKey,
      firstVisibleAt: now,
      tracking: tracking,
    );
  }

  void onCardHidden(String impressionKey) {
    final record = _records.remove(impressionKey);
    if (record == null) return;

    final visibleDuration = DateTime.now().difference(record.firstVisibleAt);
    if (visibleDuration >= _minVisibleDuration) {
      _pendingEvents.add(ExposureEvent(
        impressionKey: impressionKey,
        source: record.tracking.source,
        position: record.tracking.position,
        visibleDurationMs: visibleDuration.inMilliseconds,
        abTestGroup: record.tracking.abTestGroup,
        timestamp: DateTime.now().millisecondsSinceEpoch,
      ));
    }
  }

  void _flush() {
    if (_pendingEvents.isEmpty) return;
    final events = List<ExposureEvent>.from(_pendingEvents);
    _pendingEvents.clear();
    AnalyticsService.instance.trackBatch('card_impression', events);
  }

  void dispose() {
    _flushTimer?.cancel();
    _flush();
  }
}

class ExposureRecord {
  final String impressionKey;
  final DateTime firstVisibleAt;
  final CardTracking tracking;

  const ExposureRecord({
    required this.impressionKey,
    required this.firstVisibleAt,
    required this.tracking,
  });
}

  final String impressionKey;
  final String source;
  final int position;
  final int visibleDurationMs;

    required this.source,
    required this.position,
    required this.visibleDurationMs,

  Map<String, dynamic> toJson() => {
        'impression_key': impressionKey,
```

## 6. 交互系统与动作总线

### 6.1 CardActionBus — 卡片动作总线

卡片交互不直接调用业务逻辑，而是通过事件总线解耦。各业务模块监听自己关心的动作。

```dart
/// 卡片动作事件总线
class CardActionBus {
  final _controller = StreamController<CardActionEvent>.broadcast();
  final _listeners = <String, Set<void Function(CardSchema)>>{};

  static final CardActionBus _instance = CardActionBus._();
  factory CardActionBus() => _instance;
  CardActionBus._();

  /// 分发动作
  void dispatch(String action, CardSchema card) {
    _controller.add(CardActionEvent(action: action, card: card));
    _listeners[action]?.forEach((fn) => fn(card));
  }

  /// 监听特定动作
  VoidCallback on(String action, void Function(CardSchema) handler) {
    _listeners.putIfAbsent(action, () => <void Function(CardSchema)>{}).add(handler);
    return () => _listeners[action]?.remove(handler);
  }

  /// 全局事件流（用于日志、审计）
  Stream<CardActionEvent> get stream => _controller.stream;

  void dispose() {
    _controller.close();
    _listeners.clear();
  }
}

class CardActionEvent {
  final String action;
  final CardSchema card;

  const CardActionEvent({required this.action, required this.card});
}
```

### 8.2 降级渲染逻辑

当客户端遇到不支持的卡片版本时：

```dart
class CardCompatibilityHandler {
  /// 检查兼容性并可能执行降级
  ResolvedCard checkAndDegrade(CardSchema card) {
    final renderer = CardRegistry().resolve(card);

    if (renderer != null && renderer.canHandle(card)) {
      return ResolvedCard(
        card: card,
        renderer: renderer,
        status: CardResolveStatus.ready,
      );
    }

    // 尝试降级：去掉新版特有字段，使用旧版渲染器
    final downgraded = _downgradeCard(card);
    if (downgraded != null) {
      final downgradedRenderer = CardRegistry().resolve(downgraded);
      if (downgradedRenderer != null) {
        return ResolvedCard(
          card: downgraded,
          renderer: downgradedRenderer,
          status: CardResolveStatus.ready,
        );
      }
    }

    // 最终降级：使用通用兜底卡片
    return ResolvedCard(
      card: card,
      renderer: null,
      status: CardResolveStatus.versionMismatch,
    );
  }

  /// 降级卡片数据
  CardSchema? _downgradeCard(CardSchema card) {
    final currentVersion = card.cardVersion;
    final parts = currentVersion.split('.');
    if (parts.length != 3) return null;

    final major = int.tryParse(parts[0]) ?? 1;
    final minor = int.tryParse(parts[1]) ?? 0;

    // 大版本不一致无法降级
    if (major > 1) return null;

    // 降级到 1.0.x
    return CardSchema(
      cardId: card.cardId,
      cardType: card.cardType,
      cardVersion: '1.0.0',
      tracking: card.tracking,
      meta: card.meta,
      content: _stripNewFields(card.content),  // 移除新版本独有字段
      actions: card.actions,
      style: null,   // 使用默认样式
      extra: {},
    );
  }

  Map<String, dynamic> _stripNewFields(Map<String, dynamic> content) {
    // 移除 1.1+ 版本新增的字段
    final knownFields = {
      'chapterId', 'subject', 'gradeLevel', 'textbookVersion',
      'knowledgePointCount', 'exerciseCount', 'progress',
    };
    return Map.fromEntries(content.entries
        .where((e) => knownFields.contains(e.key)));
  }
}
```

### 8.3 FallbackCard — 兜底卡片

```dart
class FallbackCard extends StatelessWidget {
  final CardSchema card;
  final CardResolveStatus status;

  const FallbackCard({super.key, required this.card, required this.status});

  @override
  Widget build(BuildContext context) {
    return Card(
      margin: const EdgeInsets.symmetric(horizontal: 16, vertical: 4),
      child: ListTile(
        leading: Icon(_getStatusIcon(), color: Colors.grey),
        title: Text(
          card.meta.title,
          maxLines: 1,
          overflow: TextOverflow.ellipsis,
          style: Theme.of(context).textTheme.bodyMedium,
        ),
        subtitle: Text(
          _getStatusMessage(),
          style: Theme.of(context).textTheme.labelSmall,
        ),
        trailing: const Icon(Icons.chevron_right, color: Colors.grey),
        onTap: () => _tryFallbackNavigate(context),
      ),
    );
  }

  IconData _getStatusIcon() {
    switch (status) {
      case CardResolveStatus.unsupported:
        return Icons.extension_outlined;
      case CardResolveStatus.versionMismatch:
        return Icons.system_update_outlined;
      case CardResolveStatus.parseError:
        return Icons.error_outline;
      default:
        return Icons.help_outline;
    }
  }

  String _getStatusMessage() {
    switch (status) {
      case CardResolveStatus.unsupported:
        return '此内容类型暂不支持';
      case CardResolveStatus.versionMismatch:
        return '请更新至最新版本查看';
      case CardResolveStatus.parseError:
        return '内容解析失败';
      default:
        return '无法显示';
    }
  }

  void _tryFallbackNavigate(BuildContext context) {
    // 即使渲染失败，仍尝试通过 navigate action 跳转到原生页面
    final target = card.actions?.primary?.target;
    if (target != null) {
      AppRouter.instance.push(target);
    }
  }
}
```

## 9. 性能优化

### 9.1 卡片缓存与复用

```dart
/// 卡片 Widget 复用池
class CardWidgetPool {
  static final CardWidgetPool _instance = CardWidgetPool._();
  factory CardWidgetPool() => _instance;
  CardWidgetPool._();

  final int _maxPoolSize = 30;
  final Map<String, Queue<Widget>> _pool = {};

  /// 获取复用 Widget
  Widget? acquire(String cardType) {
    final queue = _pool[cardType];
    if (queue != null && queue.isNotEmpty) {
      return queue.removeFirst();
    }
    return null;
  }

  /// 回收 Widget
  void release(String cardType, Widget widget) {
    _pool.putIfAbsent(cardType, () => Queue());
    if (_pool[cardType]!.length < _maxPoolSize) {
      _pool[cardType]!.addLast(widget);
    }
  }

  /// 清空池
  void clear() {
    _pool.clear();
  }
}
```

```dart
class CardImagePrefetcher {
  /// 预加载即将出现的卡片封面图
  static void prefetch(List<CardSchema> upcomingCards) {
    for (final card in upcomingCards) {
      final coverUrl = card.meta.coverImage;
      if (coverUrl != null && coverUrl.isNotEmpty) {
        precacheImage(CachedNetworkImageProvider(coverUrl), 
            AppRouter.instance.navigatorKey.currentContext!);
      }
    }
  }

  /// 在列表滚动时智能预加载
  static void bindToScrollController({
    required ScrollController controller,
    required List<CardSchema> allCards,
    int preloadAhead = 5,
  }) {
    controller.addListener(() {
      final firstVisible = (controller.offset / 100).floor();
      final end = min(firstVisible + preloadAhead, allCards.length);
      for (int i = firstVisible; i < end; i++) {
        final url = allCards[i].meta.coverImage;
        if (url != null) {
          CachedNetworkImageProvider(url).resolve(const ImageConfiguration());
        }
      }
    });
  }
}
```

## 12. 安全与合规

### 12.1 卡片内容安全

| 风险 | 防护措施 |
|------|---------|
| 卡片标题/副标题含敏感词 | 服务端在生成卡片时已做内容过滤；客户端展示前可选做二次校验 |
| 封面图不适宜 | 所有图片 URL 来自白名单 CDN 域名 (`cdn.primetop.com`) |
| 卡片 deeplink 注入 | 所有 navigate target 必须匹配已注册路由白名单 |
| extra 字段数据泄露 | `extra` 字段不含敏感数据，仅用于 AB 测试参数 |

### 12.2 曝光数据隐私

- 曝光事件仅包含 `impressionKey`、`source`、`position` 等行为数据，不包含学生个人信息
- 曝光数据按天聚合并匿名化处理后写入分析仓库
- 未成年用户行为数据存储与使用遵循《儿童个人信息网络保护规定》
