# 客户端-拍照图像采集与预处理引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

客户端拍照图像采集与预处理引擎是连接设备摄像头硬件与服务端 OCR/AI 识别管线的关键桥梁模块。负责从相机取景、拍照捕获、图像裁剪旋转、透视校正、亮度增强、压缩上传等完整链路，为拍题答疑、作文辅导、拍照识题等多场景提供高质量的图像输入。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 相机取景与拍照 | 自定义相机控制器，支持对焦、曝光调节、闪光灯 |
| 多图采集 | 支持单拍、连拍、从相册选取 |
| 图像裁剪与旋转 | 手势驱动的自由裁剪、90°旋转、自由角度旋转 |
| 透视校正 | 四角拖拽校正梯形畸变，自动检测文档边缘 |
| 图像增强 | 亮度/对比度/锐化自适应调整，去阴影 |
| 题目区域选择 | 框选题目区域，支持多题分别框选 |
| 质量评估与提示 | 拍照质量实时反馈（模糊、过暗、倾斜等） |
| 压缩与格式化 | 智能压缩至目标体积，保持文字可识别性 |
| 离线预处理 | 端侧预处理减少上传数据量和重拍率 |

### 2.1 枚举定义

```dart
/// 拍照来源
enum CaptureSource {
  camera,      // 相机实时拍照
  gallery,     // 相册选取
  clipboard,   // 剪贴板粘贴
  screenshot,  // 屏幕截图
}

/// 拍照场景
enum CaptureScene {
  homework,       // 作业拍题
  examPaper,      // 试卷拍题
  essay,          // 作文拍照
  notebook,       // 笔记拍照
  textbook,       // 教材拍照
  generalImage,   // 通用图片
}

/// 图像质量等级
enum ImageQuality {
  excellent,  // 优秀：清晰、光照充足、无倾斜
  good,       // 良好：轻微问题，不影响识别
  fair,       // 一般：有模糊/偏暗，可能影响识别
  poor,       // 较差：严重模糊/过暗/严重倾斜，建议重拍
  unusable,   // 不可用：完全无法识别
}

/// 质量问题类型（可叠加）
enum QualityIssue {
  blurry,          // 模糊
  tooDark,         // 过暗
  tooBright,       // 过曝
  skewed,          // 倾斜
  lowResolution,   // 分辨率过低
  fingerObstacle,  // 手指遮挡
  shadowCover,     // 阴影遮挡
  glare,           // 反光
}

/// 裁剪模式
enum CropMode {
  free,           // 自由裁剪
  rectangle,      // 矩形裁剪
  perspective,    // 透视校正（四角拖拽）
  autoDetect,     // 自动检测边缘
  questionRegion, // 题目区域框选
}

/// 图像预处理动作
enum PreprocessAction {
  rotate,            // 旋转
  crop,              // 裁剪
  perspectiveFix,    // 透视校正
  brightness,        // 亮度调整
  contrast,          // 对比度调整
  sharpen,           // 锐化
  denoise,           // 降噪
  binarize,          // 二值化
  removeShadow,      // 去阴影
  compress,          // 压缩
}

/// 预处理步骤状态
enum PreprocessStepStatus {
  pending,
  processing,
  completed,
  failed,
  skipped,
}
```

### 2.2 核心数据模型

```dart
/// 原始捕获图像
class CapturedImage {
  final String id;                  // 唯一ID
  final CaptureSource source;       // 来源
  final CaptureScene scene;         // 场景
  final String localPath;           // 本地暂存路径
  final int width;                  // 原始宽度(px)
  final int height;                 // 原始高度(px)
  final int fileSizeBytes;          // 文件大小(bytes)
  final DateTime capturedAt;        // 拍摄时间
  final Map<String, dynamic>? exif; // EXIF信息(方向/曝光/ISO等)
  final ImageQuality quality;       // 质量评估
  final Set<QualityIssue> issues;   // 检测到的问题

  CapturedImage({
    required this.id,
    required this.source,
    required this.scene,
    required this.localPath,
    required this.width,
    required this.height,
    required this.fileSizeBytes,
    required this.capturedAt,
    this.exif,
    this.quality = ImageQuality.good,
    this.issues = const {},
  });
}

/// 裁剪区域
class CropRegion {
  final double x;       // 左上角x (0.0~1.0, 相对于原图)
  final double y;       // 左上角y
  final double width;   // 宽度
  final double height;  // 高度
  final double rotation; // 旋转角度(度)

  const CropRegion({
    required this.x,
    required this.y,
    required this.width,
    required this.height,
    this.rotation = 0,
  });

  /// 透视校正四角坐标
  final List<Offset>? perspectiveCorners; // [TL, TR, BR, BL]

  factory CropRegion.perspective({
    required List<Offset> corners,
  }) {
    // 从四角计算包围盒
    final xs = corners.map((c) => c.dx).toList();
    final ys = corners.map((c) => c.dy).toList();
    return CropRegion(
      x: xs.reduce(min),
      y: ys.reduce(min),
      width: xs.reduce(max) - xs.reduce(min),
      height: ys.reduce(max) - ys.reduce(min),
      perspectiveCorners: corners,
    );
  }
}

/// 题目框选区域（多题场景）
class QuestionRegion {
  final String id;
  final int index;           // 题目序号(1-based)
  final CropRegion region;   // 框选区域
  final bool isSelected;     // 是否被选中解析

  QuestionRegion({
    required this.id,
    required this.index,
    required this.region,
    this.isSelected = true,
  });
}

/// 预处理步骤记录
class PreprocessStep {
  final PreprocessAction action;
  final Map<String, dynamic> params; // 动作参数
  final PreprocessStepStatus status;
  final String? inputPath;
  final String? outputPath;
  final Duration? processingTime;
  final String? errorMessage;

  PreprocessStep({
    required this.action,
    this.params = const {},
    this.status = PreprocessStepStatus.pending,
    this.inputPath,
    this.outputPath,
    this.processingTime,
    this.errorMessage,
  });
}

/// 预处理结果
class PreprocessedImage {
  final String id;
  final String sourceImageId;       // 原始图像ID
  final String processedPath;       // 处理后文件路径
  final int width;
  final int height;
  final int fileSizeBytes;
  final List<PreprocessStep> steps; // 执行的预处理步骤
  final CropRegion? appliedCrop;    // 应用的裁剪区域
  final ImageQuality finalQuality;  // 处理后质量
  final DateTime processedAt;

  PreprocessedImage({
    required this.id,
    required this.sourceImageId,
    required this.processedPath,
    required this.width,
    required this.height,
    required this.fileSizeBytes,
    required this.steps,
    this.appliedCrop,
    required this.finalQuality,
    required this.processedAt,
  });
}

/// 完整的拍照会话
class CaptureSession {
  final String id;
  final CaptureScene scene;
  final CaptureSource source;
  final List<CapturedImage> images;       // 原始图像(可能多张)
  final List<PreprocessedImage> results;  // 预处理结果
  final List<QuestionRegion>? questionRegions; // 题目框选(多题场景)
  final CaptureSessionStatus status;
  final DateTime createdAt;
  final DateTime? completedAt;

  CaptureSession({
    required this.id,
    required this.scene,
    required this.source,
    this.images = const [],
    this.results = const [],
    this.questionRegions,
    required this.status,
    required this.createdAt,
    this.completedAt,
  });
}

enum CaptureSessionStatus {
  capturing,       // 采集阶段
  editing,         // 编辑/裁剪阶段
  preProcessing,   // 预处理阶段
  ready,           // 就绪，可上传
  uploading,       // 上传中
  completed,       // 完成
  failed,          // 失败
  cancelled,       // 取消
}
```

## 3. 状态机设计

### 3.1 拍照会话主状态机

```
                 ┌──────────┐
                 │  idle     │ ◄─── 初始状态
                 └────┬─────┘
                      │ startCapture(scene)
                      ▼
              ┌──────────────┐
         ┌──►│  capturing   │ ◄─── 相机取景/拍照/选图
         │   └──────┬───────┘
         │          │ onImageCaptured()
         │          ▼
         │   ┌──────────────┐
         │   │   editing    │ ◄─── 裁剪/旋转/透视校正
         │   └──────┬───────┘
         │          │ applyEdits()
         │          ▼
         │   ┌──────────────┐
         │   │preProcessing │ ◄─── 端侧图像增强
         │   └──────┬───────┘
         │          │ onPreprocessComplete()
         │          ▼
         │   ┌──────────────┐
         │   │    ready     │ ◄─── 可预览/确认/上传
         │   └──────┬───────┘
         │          │ upload() / retake()
         │          ▼              │
         │   ┌──────────────┐     │ reCapture()
         │   │  uploading   │     │
         │   └──────┬───────┘     │
         │     ┌────┴────┐        │
         │     ▼         ▼        │
         │  ┌──────┐  ┌──────┐   │
         │  │completed│ │failed│   │
         │  └──────┘  └──┬───┘   │
         │                 │ retry()
         │                 └───────┘
         │  reEdit()
         └────────────────────┘
```

### 3.2 图像预处理管线状态

```
rawImage ──► rotate ──► crop ──► perspectiveFix ──► enhance ──► compress ──► result
                                                │
                                                ▼
                                          (每步可跳过)
```

每个步骤独立状态管理，失败时记录错误但不阻塞后续步骤（降级跳过）。

## 5. 关键流程设计

### 5.1 拍照采集主流程

```
用户点击拍照按钮
        │
        ▼
┌─ 权限检查 ──────────────────────────┐
│  camera_permission?                   │
│  ├─ granted → 继续                     │
│  ├─ denied → 弹出设置引导对话框          │
│  └─ notDetermined → 请求权限            │
└──────────────────────────────────────┘
        │
        ▼
┌─ 初始化相机 ────────────────────────┐
│  选择后置摄像头                        │
│  设置分辨率(最高4K)                    │
│  配置对焦模式(autoFocus)               │
│  配置曝光模式(autoExposure)            │
│  设置闪光灯(auto)                     │
│  注册质量实时检测回调                   │
└──────────────────────────────────────┘
        │
        ▼
┌─ 取景引导 ──────────────────────────┐
│  根据scene显示取景框                   │
│  homework: A4纸张比例框+居中引导线      │
│  examPaper: 大区域框+提示拍完整页       │
│  essay: 竖向A4框+提示保持水平          │
│  实时质量反馈(模糊/过暗/倾斜检测)       │
│  分龄语音提示(幼儿/小学)                │
└──────────────────────────────────────┘
        │ 用户点击拍照
        ▼
┌─ 捕获图像 ──────────────────────────┐
│  1. 捕获高分辨率JPEG                  │
│  2. 根据EXIF方向自动旋转               │
│  3. 保存到临时目录                     │
│  4. 记录元信息(分辨率/大小/时间)        │
│  5. 触发质量评估                       │
└──────────────────────────────────────┘
        │
        ▼
┌─ 即时质量评估 ──────────────────────┐
│  端侧轻量评估:                        │
│  ├─ Laplacian方差 → 模糊检测           │
│  ├─ 平均亮度 → 过暗/过曝              │
│  ├─ 倾斜角度 → 角度检测               │
│  └─ 分辨率检查 → 是否满足最低要求       │
│                                      │
│  quality >= good → 进入编辑阶段        │
│  quality == fair → 提示建议但仍可继续   │
│  quality <= poor → 建议重拍(可强制继续) │
└──────────────────────────────────────┘
        │
        ▼
  进入编辑/裁剪阶段
```

### 5.2 图像编辑与裁剪流程

```
进入编辑页面
        │
        ▼
┌─ 加载图像 ──────────────────────────┐
│  1. 加载原始图像到内存                 │
│  2. 根据分辨率决定是否先缩放预览        │
│     (超过4096px边长时缩放预览)          │
│  3. 初始化裁剪控制器                   │
└──────────────────────────────────────┘
        │
        ▼
┌─ 自动增强建议 ──────────────────────┐
│  if (检测到倾斜) → 自动建议旋转         │
│  if (检测到文档边缘) → 建议透视校正     │
│  if (过暗) → 建议亮度增强              │
│  (用户可一键应用或忽略)                │
└──────────────────────────────────────┘
        │
        ▼
┌─ 用户编辑交互 ──────────────────────┐
│  模式切换:                            │
│  ├─ [裁剪] 拖拽四角调整裁剪框          │
│  ├─ [旋转] 左右90°或自由旋转           │
│  ├─ [透视] 四角拖拽校正畸变            │
│  ├─ [滤镜] 黑白/增强/去阴影            │
│  └─ [多题框选] 添加/调整题目区域        │
│                                      │
│  操作可叠加、可撤销、可重置             │
│  实时预览处理效果                      │
└──────────────────────────────────────┘
        │ 用户确认
        ▼
┌─ 执行预处理管线 ─────────────────────┐
│  1. EXIF旋转修正                      │
│  2. 用户裁剪                          │
│  3. 透视变换(如启用)                   │
│  4. 自适应增强(亮度/对比度/锐化)       │
```

```dart
class GuideOverlay extends StatelessWidget {

class _GuidePainter extends CustomPainter {
  final CaptureScene scene;
  final AgeGroup ageGroup;

  _GuidePainter({required this.scene, required this.ageGroup});

  @override
  void paint(Canvas canvas, Size size) {
    final guideRect = _getGuideRect(size);

    // 半透明遮罩(框外区域)
    final maskPaint = Paint()..color = Colors.black.withOpacity(0.5);
    final outerPath = Path.combine(
      PathOperation.difference,
      Path()..addRect(Rect.fromLTWH(0, 0, size.width, size.height)),
      Path()..addRRect(RRect.fromRectXY(guideRect, 8, 8)),
    );
    canvas.drawPath(outerPath, maskPaint);

    // 引导框边线
    final borderPaint = Paint()
      ..color = Colors.white.withOpacity(0.8)
      ..strokeWidth = 2
      ..style = PaintingStyle.stroke;
    canvas.drawRRect(RRect.fromRectXY(guideRect, 8, 8), borderPaint);

    // 三分线
    _drawGrid(canvas, guideRect);

    // 角标记(增强可见性)
    _drawCornerMarks(canvas, guideRect);
  }

  Rect _getGuideRect(Size canvasSize) {
    final aspectRatio = switch (scene) {
      CaptureScene.essay => 1.0 / 1.414,   // A4竖向
      CaptureScene.homework => 1.414,       // A4横向
      CaptureScene.examPaper => 1.414,      // A4横向
      _ => 1.0,                             // 1:1
    };
    // 计算框体位置，居中，留边距
    final padding = ageGroup == AgeGroup.preschool ? 0.15 : 0.08;
    final maxWidth = canvasSize.width * (1 - padding * 2);
    final maxHeight = canvasSize.height * (1 - padding * 2);
    // ... 计算保持比例的最大矩形
    return _fitRect(maxWidth, maxHeight, aspectRatio, canvasSize);
  }

  void _drawGrid(Canvas canvas, Rect rect) {
    final gridPaint = Paint()
      ..color = Colors.white.withOpacity(0.3)
      ..strokeWidth = 0.5;
    // 三等分线
    for (int i = 1; i <= 2; i++) {
      final dx = rect.left + rect.width * i / 3;
      final dy = rect.top + rect.height * i / 3;
      canvas.drawLine(Offset(dx, rect.top), Offset(dx, rect.bottom), gridPaint);
      canvas.drawLine(Offset(rect.left, dy), Offset(rect.right, dy), gridPaint);
    }
  }

  void _drawCornerMarks(Canvas canvas, Rect rect) {
    final cornerPaint = Paint()
      ..color = Colors.white
      ..strokeWidth = 3
      ..strokeCap = StrokeCap.round;
    const len = 20.0;
    // 四个角画L形标记
    for (final corner in [rect.topLeft, rect.topRight, rect.bottomLeft, rect.bottomRight]) {
      final dx = corner.dx == rect.left ? 1 : -1;
      final dy = corner.dy == rect.top ? 1 : -1;
      canvas.drawLine(corner, corner.translate(dx * len, 0), cornerPaint);
      canvas.drawLine(corner, corner.translate(0, dy * len), cornerPaint);
    }
  }
}
```

## 7. 图像处理实现

### 7.1 端侧图像处理引擎

```dart
/// 端侧图像预处理引擎
class ImagePreprocessor {
  final EdgeAIManager? _edgeAI; // 端侧AI能力(可选)

  ImagePreprocessor({EdgeAIManager? edgeAI}) : _edgeAI = edgeAI;

  /// 执行完整预处理管线
  Future<PreprocessedImage> process(
    CapturedImage image, {
    CropRegion? cropRegion,
    bool enablePerspectiveFix = false,
    bool enableAutoEnhance = true,
    int targetMaxSize = 2048,
    int targetQuality = 85,
  }) async {
    final steps = <PreprocessStep>[];
    var currentPath = image.localPath;
    final sw = Stopwatch()..start();

    // Step 1: EXIF旋转修正
    final rotateStep = await _applyExifRotation(currentPath);
    steps.add(rotateStep);
    if (rotateStep.outputPath != null) currentPath = rotateStep.outputPath!;

    // Step 2: 裁剪
    if (cropRegion != null) {
      final cropStep = await _applyCrop(currentPath, cropRegion);
      steps.add(cropStep);
      if (cropStep.outputPath != null) currentPath = cropStep.outputPath!;
    }

    // Step 3: 透视校正
    if (enablePerspectiveFix && cropRegion?.perspectiveCorners != null) {
      final perspStep = await _applyPerspectiveCorrection(
        currentPath,
        cropRegion!.perspectiveCorners!,
      );
      steps.add(perspStep);
      if (perspStep.outputPath != null) currentPath = perspStep.outputPath!;
    }

    // Step 4: 自适应增强
    if (enableAutoEnhance) {
      final enhanceStep = await _applyAutoEnhance(currentPath);
      steps.add(enhanceStep);
      if (enhanceStep.outputPath != null) currentPath = enhanceStep.outputPath!;
    }

    // Step 5: 智能压缩
    final compressStep = await _applySmartCompress(
      currentPath,
      targetMaxSize: targetMaxSize,
      targetQuality: targetQuality,
    );
    steps.add(compressStep);
    if (compressStep.outputPath != null) currentPath = compressStep.outputPath!;

    sw.stop();

    // 读取处理后的图像信息
    final resultInfo = await _readImageInfo(currentPath);

    return PreprocessedImage(
      id: const Uuid().v4(),
      sourceImageId: image.id,
      processedPath: currentPath,
      width: resultInfo.width,
      height: resultInfo.height,
      fileSizeBytes: resultInfo.fileSizeBytes,
      steps: steps,
      appliedCrop: cropRegion,
      finalQuality: await _assessFinalQuality(currentPath),
      processedAt: DateTime.now(),
    );
  }

  /// EXIF旋转修正
  Future<PreprocessStep> _applyExifRotation(String inputPath) async {
    try {
      // 使用flutter_image_compress或image包读取EXIF并旋转
      final result = await FlutterImageCompress.compressWithFile(
        inputPath,
        targetPath: '${inputPath}_rotated.jpg',
        keepExif: false, // 修正后移除EXIF旋转标记
        autoCorrectionAngle: true, // 自动根据EXIF旋转
        quality: 100, // 不压缩，仅旋转
      );
      return PreprocessStep(
        action: PreprocessAction.rotate,
        status: PreprocessStepStatus.completed,
        inputPath: inputPath,
        outputPath: result != null ? '${inputPath}_rotated.jpg' : null,
      );
    } catch (e) {
      return PreprocessStep(
        action: PreprocessAction.rotate,
        status: PreprocessStepStatus.failed,
        inputPath: inputPath,
        errorMessage: e.toString(),
      );
    }
  }

  /// 裁剪
  Future<PreprocessStep> _applyCrop(String inputPath, CropRegion region) async {
    try {
      final srcImage = img.decodeImage(await File(inputPath).readAsBytes())!;
      final srcW = srcImage.width;
      final srcH = srcImage.height;

      final cropX = (region.x * srcW).round();
      final cropY = (region.y * srcH).round();
      final cropW = (region.width * srcW).round();
      final cropH = (region.height * srcH).round();

      // 如果有旋转，先旋转
      var working = srcImage;
      if (region.rotation != 0) {
        working = img.copyRotate(working, angle: region.rotation);
      }

      final cropped = img.copyCrop(
        working,
        x: cropX,
        y: cropY,
        width: cropW,
        height: cropH,
      );

      final outputPath = '${inputPath}_cropped.jpg';
      await File(outputPath).writeAsBytes(
        img.encodeJpg(cropped, quality: 95),
      );

      return PreprocessStep(
        action: PreprocessAction.crop,
        params: {'x': region.x, 'y': region.y, 'w': region.width, 'h': region.height},
        status: PreprocessStepStatus.completed,
        inputPath: inputPath,
        outputPath: outputPath,
      );
    } catch (e) {
      return PreprocessStep(
        action: PreprocessAction.crop,
        status: PreprocessStepStatus.failed,
        inputPath: inputPath,
        errorMessage: e.toString(),
      );
    }
  }

  /// 透视校正
  Future<PreprocessStep> _applyPerspectiveCorrection(
    String inputPath,
    List<Offset> corners,
  ) async {
    try {
      final srcImage = img.decodeImage(await File(inputPath).readAsBytes())!;
      final srcW = srcImage.width.toDouble();
      final srcH = srcImage.height.toDouble();

      // 将归一化坐标转为像素坐标
      final srcCorners = corners.map((c) => img.Point(c.dx * srcW, c.dy * srcH)).toList();

      // 计算输出图像尺寸（使用最大边长）
      final topWidth = (srcCorners[1].x - srcCorners[0].x).abs();
      final bottomWidth = (srcCorners[2].x - srcCorners[3].x).abs();
      final leftHeight = (srcCorners[3].y - srcCorners[0].y).abs();
      final rightHeight = (srcCorners[2].y - srcCorners[1].y).abs();

      final outW = max(topWidth, bottomWidth).round();
      final outH = max(leftHeight, rightHeight).round();

      // 目标四角（矩形）
      final dstCorners = [
        img.Point(0, 0),
        img.Point(outW.toDouble(), 0),
        img.Point(outW.toDouble(), outH.toDouble()),
        img.Point(0, outH.toDouble()),
      ];

      // 计算透视变换矩阵并应用
      final corrected = _applyPerspectiveTransform(
        srcImage,
        srcCorners,
        dstCorners,
        outW,
        outH,
      );

      final outputPath = '${inputPath}_perspective.jpg';
      await File(outputPath).writeAsBytes(
        img.encodeJpg(corrected, quality: 95),
      );

      return PreprocessStep(
        action: PreprocessAction.perspectiveFix,
        params: {
          'corners': corners.map((c) => {'x': c.dx, 'y': c.dy}).toList(),
        },
        status: PreprocessStepStatus.completed,
        inputPath: inputPath,
        outputPath: outputPath,
      );
    } catch (e) {
      return PreprocessStep(
        action: PreprocessAction.perspectiveFix,
        status: PreprocessStepStatus.failed,
        inputPath: inputPath,
        errorMessage: e.toString(),
      );
    }
  }

  /// 透视变换核心算法
  img.Image _applyPerspectiveTransform(
    img.Image src,
    List<img.Point> srcPts,
    List<img.Point> dstPts,
    int outW,
    int outH,
  ) {
    // 计算3x3透视变换矩阵 (源坐标到目标坐标)
    final matrix = _computePerspectiveMatrix(srcPts, dstPts);
    final result = img.Image(width: outW, height: outH);

    // 对输出每个像素，反向映射到源图像（双线性插值）
    for (int y = 0; y < outH; y++) {
      for (int x = 0; x < outW; x++) {
        final srcCoord = _applyMatrix(matrix, x.toDouble(), y.toDouble());
        final sx = srcCoord.dx;
        final sy = srcCoord.dy;

        if (sx >= 0 && sx < src.width - 1 && sy >= 0 && sy < src.height - 1) {
          // 双线性插值
          final pixel = img.bilinearInterpolate(src, sx, sy);
          result.setPixel(x, y, pixel);
        }
      }
    }
    return result;
  }

  /// 自适应增强
  Future<PreprocessStep> _applyAutoEnhance(String inputPath) async {
    try {
      final srcImage = img.decodeImage(await File(inputPath).readAsBytes())!;

      // 1. 计算当前亮度
      final avgBrightness = _calculateAvgBrightness(srcImage);

      // 2. 亮度调整
      var enhanced = srcImage;
      if (avgBrightness < 100) {
        // 过暗：提升亮度
        final factor = 1.0 + (100 - avgBrightness) / 200;
        enhanced = img.adjustColor(enhanced, brightness: factor * 0.3);
      }

      // 3. 对比度增强（CLAHE简化版）
      enhanced = img.adjustColor(enhanced, contrast: 1.1);

      // 4. 锐化（Unsharp Mask简化版）
      enhanced = img.convolution(
        enhanced,
        filter: [
          0, -1, 0,
          -1, 5, -1,
          0, -1, 0,
        ],
      );

      // 5. 去阴影（可选，通过端侧AI检测）
      if (_edgeAI != null && await _edgeAI!.isCapabilityAvailable('shadow_removal')) {
        // 使用端侧模型去阴影
        enhanced = await _edgeAI!.removeShadow(enhanced);
      }

      final outputPath = '${inputPath}_enhanced.jpg';
      await File(outputPath).writeAsBytes(
        img.encodeJpg(enhanced, quality: 92),
      );

      return PreprocessStep(
        action: PreprocessAction.contrast,
        status: PreprocessStepStatus.completed,
        inputPath: inputPath,
        outputPath: outputPath,
      );
    } catch (e) {
      return PreprocessStep(
        action: PreprocessAction.contrast,
        status: PreprocessStepStatus.failed,
        inputPath: inputPath,
        errorMessage: e.toString(),
      );
    }
  }

  /// 智能压缩
  Future<PreprocessStep> _applySmartCompress(
    String inputPath, {
    int targetMaxSize = 2048,
    int targetQuality = 85,
  }) async {
    try {
      final srcImage = img.decodeImage(await File(inputPath).readAsBytes())!;

      // 等比缩放到目标最大边长
      var resized = srcImage;
      final maxDim = max(srcImage.width, srcImage.height);
      if (maxDim > targetMaxSize) {
        final scale = targetMaxSize / maxDim;
        resized = img.copyResize(
          srcImage,
          width: (srcImage.width * scale).round(),
          height: (srcImage.height * scale).round(),
          interpolation: img.Interpolation.cubic,
        );
      }

      final outputPath = '${inputPath}_compressed.jpg';

      // 使用flutter_image_compress进行高质量JPEG压缩
      // 先保存为临时PNG
      final tempPng = '${inputPath}_temp.png';
      await File(tempPng).writeAsBytes(img.encodePng(resized));

      final result = await FlutterImageCompress.compressWithFile(
        tempPng,
        targetPath: outputPath,
        quality: targetQuality,
        format: CompressFormat.jpeg,
      );

      // 清理临时文件
      await File(tempPng).delete();

      return PreprocessStep(
        action: PreprocessAction.compress,
        params: {
          'targetMaxSize': targetMaxSize,
          'quality': targetQuality,
        },
        status: PreprocessStepStatus.completed,
        inputPath: inputPath,
        outputPath: outputPath,
      );
    } catch (e) {
      return PreprocessStep(
        action: PreprocessAction.compress,
        status: PreprocessStepStatus.failed,
        inputPath: inputPath,
        errorMessage: e.toString(),
      );
    }
  }

  /// 最终质量评估
  Future<ImageQuality> _assessFinalQuality(String imagePath) async {
    final srcImage = img.decodeImage(await File(imagePath).readAsBytes())!;

    // Laplacian方差（模糊度）
    final laplacianVariance = _calculateLaplacianVariance(srcImage);

    // 亮度
    final avgBrightness = _calculateAvgBrightness(srcImage);

    // 综合评分
    if (laplacianVariance > 500 && avgBrightness > 80 && avgBrightness < 220) {
      return ImageQuality.excellent;
    } else if (laplacianVariance > 200 && avgBrightness > 50 && avgBrightness < 240) {
      return ImageQuality.good;
    } else if (laplacianVariance > 80) {
      return ImageQuality.fair;
    } else if (laplacianVariance > 30) {
      return ImageQuality.poor;
    } else {
      return ImageQuality.unusable;
    }
  }

  /// Laplacian方差计算（模糊检测）
  double _calculateLaplacianVariance(img.Image image) {
    // 缩小到灰度图计算（提升性能）
    final gray = img.grayscale(img.copyResize(image, width: 256, height: 256));
    final w = gray.width;
    final h = gray.height;

    double sum = 0;
    double sumSq = 0;
    int count = 0;

    for (int y = 1; y < h - 1; y++) {
      for (int x = 1; x < w - 1; x++) {
        // Laplacian算子
        final val = -4 * gray.getPixel(x, y).r.toDouble()
            + gray.getPixel(x - 1, y).r.toDouble()
            + gray.getPixel(x + 1, y).r.toDouble()
            + gray.getPixel(x, y - 1).r.toDouble()
            + gray.getPixel(x, y + 1).r.toDouble();
        sum += val;
        sumSq += val * val;
        count++;
      }
    }

    final mean = sum / count;
    final variance = (sumSq / count) - (mean * mean);
    return variance;
  }

  /// 平均亮度计算
  double _calculateAvgBrightness(img.Image image) {
    final sample = img.copyResize(image, width: 64, height: 64);
    double total = 0;
    for (int y = 0; y < sample.height; y++) {
      for (int x = 0; x < sample.width; x++) {
        final p = sample.getPixel(x, y);
        // ITU-R BT.601亮度公式
        total += 0.299 * p.r + 0.587 * p.g + 0.114 * p.b;
      }
    }
    return total / (sample.width * sample.height);
  }
}
```

```dart
/// 端侧边缘检测服务
class EdgeDetectionService {
  final EdgeAIManager? _edgeAI;

  EdgeDetectionService(this._edgeAI);

  /// 自动检测文档边缘
  /// 优先使用端侧模型，降级到启发式算法
  Future<List<Offset>?> detectDocumentEdges(String imagePath) async {
    // 优先级1: 端侧AI模型
    if (_edgeAI != null && await _edgeAI!.isCapabilityAvailable('edge_detection')) {
      try {
        final corners = await _edgeAI!.detectDocumentEdges(imagePath);
        if (corners != null && _validateCorners(corners)) {
          return corners;
        }
      } catch (_) {
        // 降级
      }
    }

    // 优先级2: 启发式算法（基于图像梯度）
    try {
      return await _heuristicEdgeDetection(imagePath);
    } catch (_) {
      return null; // 无法检测，由用户手动操作
    }
  }

  /// 启发式边缘检测
  Future<List<Offset>?> _heuristicEdgeDetection(String imagePath) async {
    final image = img.decodeImage(await File(imagePath).readAsBytes())!;
    final gray = img.grayscale(img.copyResize(image, width: 512, height: 512));
    final w = gray.width;
    final h = gray.height;

    // 1. Canny边缘检测（简化版）
    final edges = _sobelEdgeDetection(gray);

    // 2. 霍夫变换检测直线
    final lines = _houghLines(edges, w, h);

    // 3. 找到4条近似构成矩形的线
    final corners = _findDocumentCorners(lines, w, h);

    if (corners != null) {
      // 归一化到0~1
      return corners.map((c) => Offset(c.dx / w, c.dy / h)).toList();
    }
    return null;
  }

  bool _validateCorners(List<Offset> corners) {
    if (corners.length != 4) return false;
    // 检查四角是否构成合理的凸四边形
    // 面积不应太小（至少占图像20%）
    final area = _polygonArea(corners);
    return area > 0.2;
  }

  double _polygonArea(List<Offset> pts) {
    double area = 0;
    for (int i = 0; i < pts.length; i++) {
      final j = (i + 1) % pts.length;
      area += pts[i].dx * pts[j].dy;
      area -= pts[j].dx * pts[i].dy;
    }
    return (area / 2).abs();
  }
}
```

```dart
/// 端侧文字区域检测服务
class TextRegionDetector {
  final EdgeAIManager? _edgeAI;

  TextRegionDetector(this._edgeAI);

  /// 检测题目区域
  Future<List<QuestionRegion>> detectQuestionRegions(
    String imagePath, {
    int minRegions = 1,
    int maxRegions = 10,
  }) async {
    // 端侧DBNet-Lite检测文字区域
    if (_edgeAI != null && await _edgeAI!.isCapabilityAvailable('text_detection')) {
      try {
        final textRegions = await _edgeAI!.detectTextRegions(imagePath);
        if (textRegions.isNotEmpty) {
          return _clusterToQuestionRegions(textRegions, maxRegions);
        }
      } catch (_) {
        // 降级到基于间距的启发式分割
      }
    }

    // 启发式：基于水平空白行分割
    return await _heuristicSplit(imagePath, maxRegions);
  }

  /// 将文字区域聚类为题目块
  List<QuestionRegion> _clusterToQuestionRegions(
    List<TextRegion> regions,
    int maxRegions,
  ) {
    // 1. 按Y坐标排序
    final sorted = List<TextRegion>.from(regions)
      ..sort((a, b) => a.bounds.top.compareTo(b.bounds.top));

    // 2. 根据Y方向间距聚类
    final clusters = <List<TextRegion>>[];
    var currentCluster = [sorted.first];

    for (int i = 1; i < sorted.length; i++) {
      final gap = sorted[i].bounds.top - currentCluster.last.bounds.bottom;
      final avgHeight = currentCluster
          .map((r) => r.bounds.height)
          .reduce((a, b) => a + b) / currentCluster.length;

      if (gap > avgHeight * 0.5) {
        // 间距较大，视为新题目
        clusters.add(currentCluster);
        currentCluster = [sorted[i]];
      } else {
        currentCluster.add(sorted[i]);
      }
    }
    clusters.add(currentCluster);

    // 3. 生成题目区域
    return clusters.take(maxRegions).toList().asMap().entries.map((entry) {
      final idx = entry.key;
      final cluster = entry.value;
      final bounds = _unionBounds(cluster.map((r) => r.bounds).toList());
      return QuestionRegion(
        id: 'qr_${idx + 1}',
        index: idx + 1,
        region: CropRegion(
          x: bounds.left,
          y: bounds.top,
          width: bounds.width,
          height: bounds.height,
        ),
        isSelected: true,
      );
    }).toList();
  }

  /// 基于水平投影的启发式分割
  Future<List<QuestionRegion>> _heuristicSplit(
    String imagePath,
    int maxRegions,
  ) async {
    final image = img.decodeImage(await File(imagePath).readAsBytes())!;
    final gray = img.grayscale(image);

    // 水平投影：统计每行的暗像素数
    final projection = List<int>.filled(gray.height, 0);
    for (int y = 0; y < gray.height; y++) {
      for (int x = 0; x < gray.width; x++) {
        if (gray.getPixel(x, y).r < 128) {
          projection[y]++;
        }
      }
    }

    // 找到投影的间隙（空白行区域）
    final threshold = gray.width * 0.01; // 最小暗像素阈值
    final gaps = <({int start, int end})>[];
    bool inGap = false;
    int gapStart = 0;

    for (int y = 0; y < projection.length; y++) {
      if (projection[y] < threshold) {
        if (!inGap) {
          gapStart = y;
          inGap = true;
        }
      } else {
        if (inGap) {
          gaps.add((start: gapStart, end: y));
          inGap = false;
        }
      }
    }

    // 按间距大小排序，取最大的N-1个间距作为分割线
    final sortedGaps = List.from(gaps)
      ..sort((a, b) => (b.end - b.start).compareTo(a.end - a.start));

    final splitGaps = sortedGaps.take(maxRegions - 1).toList()
      ..sort((a, b) => a.start.compareTo(b.start));

    // 生成分割区域
    final regions = <QuestionRegion>[];
    int prevEnd = 0;
    for (int i = 0; i <= splitGaps.length; i++) {
      final gapCenter = i < splitGaps.length
          ? (splitGaps[i].start + splitGaps[i].end) ~/ 2
          : gray.height;
      if (gapCenter > prevEnd + 20) {
        // 最小高度20px
        regions.add(QuestionRegion(
          id: 'qr_${i + 1}',
          index: i + 1,
          region: CropRegion(
            x: 0.02,
            y: prevEnd / gray.height,
            width: 0.96,
            height: (gapCenter - prevEnd) / gray.height,
          ),
          isSelected: true,
        ));
      }
      prevEnd = i < splitGaps.length
          ? (splitGaps[i].start + splitGaps[i].end) ~/ 2
          : gray.height;
    }

    return regions.take(maxRegions).toList();
  }
}
```

```dart
/// 拍照临时文件管理
class CaptureTempFileManager {
  static const _tempDir = 'capture_temp';
  static const _maxTempAge = Duration(hours: 24);
  static const _maxTempSize = 200 * 1024 * 1024; // 200MB上限

  /// 创建临时文件路径
  static Future<String> createTempPath({String? suffix}) async {
    final dir = await getTemporaryDirectory();
    final captureDir = Directory('${dir.path}/$_tempDir');
    if (!await captureDir.exists()) {
      await captureDir.create(recursive: true);
    }
    final id = const Uuid().v4().substring(0, 8);
    return '${captureDir.path}/${id}_${suffix ?? 'img'}.jpg';
  }

  /// 清理过期临时文件
  static Future<void> cleanExpired() async {
    final dir = await getTemporaryDirectory();
    final captureDir = Directory('${dir.path}/$_tempDir');
    if (!await captureDir.exists()) return;

    await for (final entity in captureDir.list()) {
      if (entity is File) {
        final stat = await entity.stat();
        if (DateTime.now().difference(stat.modified) > _maxTempAge) {
          await entity.delete();
        }
      }
    }
  }

  /// 检查并清理超出配额的临时文件
  static Future<void> enforceQuota() async {
    final dir = await getTemporaryDirectory();
    final captureDir = Directory('${dir.path}/$_tempDir');
    if (!await captureDir.exists()) return;

    final files = <File>[];
    int totalSize = 0;
    await for (final entity in captureDir.list()) {
      if (entity is File) {
        files.add(entity);
        totalSize += await entity.length();
      }
    }

    if (totalSize > _maxTempSize) {
      // 按修改时间排序，删除最旧的
      files.sort((a, b) async => (await a.stat()).modified.compareTo((await b.stat()).modified));
      for (final file in files) {
        if (totalSize <= _maxTempSize * 0.7) break; // 清理到70%
        totalSize -= await file.length();
        await file.delete();
      }
    }
  }
}
```

```dart
  /// 质量不佳重拍

      'quality': quality.name,
      'issues': issues.map((i) => i.name).join(','),

  /// 编辑操作记录
  static AnalyticsEvent editAction({

    properties: {

  );

  /// 预处理完成

  );

  /// 多题框选
```
