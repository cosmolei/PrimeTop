# 教育学习任务复杂度评估与个性化完成耗时预测引擎 详细设计

## 1. 概述

### 1.1 模块定位

本引擎是 PrimeTop 学习规划、每日任务编排、学习负荷均衡等上层模块的基础预测服务。其核心职责是：

1. **任务复杂度建模**：对题目、知识点学习、阅读材料、作文练习等各类学习任务进行多维度复杂度评分。
2. **个性化耗时预测**：结合学生历史学习速度、学科掌握度、认知能力等因素，预测特定学生完成特定任务的预计耗时。
3. **预测反馈闭环**：采集实际完成耗时，持续校准预测模型，提升后续预测准确度。

### 1.2 核心业务价值

| 价值场景 | 当前痛点 | 本引擎解决方案 |
| --- | --- | --- |
| 每日任务编排 | 任务时长依赖固定配置（如"每题2分钟"），与真实耗时偏差大 | 提供个性化耗时预测，使每日任务总量更合理 |
| 学习计划生成 | 计划排布缺乏对学生个体差异的考量 | 为计划引擎提供学生特异性时间估算 |
| 负荷均衡 | 跨学科时间分配缺乏精确依据 | 预测各科任务实际耗时，避免某天任务过载 |
| 防沉迷时间管控 | 无法预估单次学习是否会超时 | 为防沉迷引擎提供任务时长预估输入 |
| 学习进度预估 | 无法准确告知"还需多久完成本周目标" | 基于任务清单批量预测，输出完成时间区间 |

**上游数据源：**
- 题目服务：题目元数据（题型、学科、年级、难度系数、知识点列表）
- 知识点服务：知识点层级、前置依赖、布鲁姆认知层级
- 教材内容服务：阅读材料字数、视频时长、练习配置
- 学习记录服务：学生历史答题记录、学习会话时长

**下游消费方：**
- 每日任务智能生成服务：用于确定当天任务总量和任务编排
- 学习计划引擎：用于生成可行的周/月计划
- 学习负荷均衡优化引擎：用于跨学科时间分配
- 学习进度快照服务：用于预估剩余完成时间
- 防沉迷系统：用于判断下一任务是否会超出时限

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 任务复杂度档案 (task_complexity_profile)

存储每个学习任务的静态复杂度评估结果。

```sql
CREATE TABLE task_complexity_profile (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id             VARCHAR(64) NOT NULL COMMENT '任务唯一标识',
    task_type           VARCHAR(32) NOT NULL COMMENT '任务类型: QUESTION/READING/VIDEO/EXERCISE/ESSAY/MEMORIZATION',
    subject_code        VARCHAR(16) NOT NULL COMMENT '学科编码',
    grade_level         TINYINT NOT NULL COMMENT '适用年级 1-12',

    -- 复杂度维度评分 (0.0 - 1.0)
    cognitive_load      DECIMAL(4,3) NOT NULL COMMENT '认知负荷: 内容本身的思维难度',
    content_volume      DECIMAL(4,3) NOT NULL COMMENT '内容量: 阅读量/题量/信息量',
    skill_dependency    DECIMAL(4,3) NOT NULL COMMENT '技能依赖: 前置知识依赖程度',
    format_complexity   DECIMAL(4,3) NOT NULL COMMENT '格式复杂度: 公式/图表/多步骤程度',

    -- 综合复杂度分值
    complexity_score    DECIMAL(5,2) NOT NULL COMMENT '综合复杂度评分 0-100',
    difficulty_band     VARCHAR(16) NOT NULL COMMENT '难度档位: EASY/MEDIUM/HARD/CHALLENGING',

    -- 预估基准耗时 (秒) - 面向年级平均水平的学生
    base_duration_secs  INT NOT NULL COMMENT '基准预估耗时(秒)',

    -- 复杂度特征快照
    feature_snapshot    JSON COMMENT '复杂度特征明细JSON',

    -- 元数据
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_task_id (task_id),
    INDEX idx_type_subject (task_type, subject_code, grade_level),
    INDEX idx_difficulty (difficulty_band, complexity_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='任务复杂度档案表';
```

#### 2.1.2 学生学习速度画像 (student_speed_profile)

存储每个学生的学科级学习速度模型。

```sql
CREATE TABLE student_speed_profile (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id          BIGINT NOT NULL COMMENT '学生ID',
    subject_code        VARCHAR(16) NOT NULL COMMENT '学科编码',

    -- 速度系数 (相对于年级平均水平)
    speed_factor        DECIMAL(4,3) NOT NULL DEFAULT 1.000 COMMENT '速度系数: >1表示快于平均, <1表示慢于平均',
    speed_percentile    DECIMAL(5,2) COMMENT '在同年级同学科中的速度百分位 0-100',

    -- 分难度速度系数 (精细化模型)
    easy_speed_factor   DECIMAL(4,3) NOT NULL DEFAULT 1.000 COMMENT '简单题速度系数',
    medium_speed_factor DECIMAL(4,3) NOT NULL DEFAULT 1.000 COMMENT '中等题速度系数',
    hard_speed_factor   DECIMAL(4,3) NOT NULL DEFAULT 1.000 COMMENT '困难题速度系数',

    -- 模型参数
    sample_count        INT NOT NULL DEFAULT 0 COMMENT '样本数(已完成任务数)',
    confidence_score    DECIMAL(4,3) NOT NULL DEFAULT 0.000 COMMENT '模型置信度 0-1, 样本越多越高',
    last_calibrated_at  DATETIME COMMENT '最近一次校准时间',

    -- 趋势
    speed_trend         VARCHAR(16) NOT NULL DEFAULT 'STABLE' COMMENT '速度趋势: IMPROVING/STABLE/DECLINING',

    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_student_subject (student_id, subject_code),
    INDEX idx_student (student_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生学习速度画像表';
```

#### 2.1.3 耗时预测记录 (duration_prediction_log)

记录每次预测及其实际结果，用于模型持续优化。

```sql
CREATE TABLE duration_prediction_log (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    prediction_id       VARCHAR(64) NOT NULL COMMENT '预测请求唯一ID',
    student_id          BIGINT NOT NULL COMMENT '学生ID',
    task_id             VARCHAR(64) NOT NULL COMMENT '任务ID',
    task_type           VARCHAR(32) NOT NULL COMMENT '任务类型',

    -- 预测结果
    predicted_secs      INT NOT NULL COMMENT '预测耗时(秒)',
    predicted_range_low INT NOT NULL COMMENT '预测下限(秒) P15',
    predicted_range_high INT NOT NULL COMMENT '预测上限(秒) P85',
    confidence_level    VARCHAR(16) NOT NULL COMMENT '预测置信度: LOW/MEDIUM/HIGH',

    -- 实际结果 (任务完成后回填)
    actual_secs         INT COMMENT '实际耗时(秒)',
    completion_status   VARCHAR(16) COMMENT '完成状态: COMPLETED/ABANDONED/TIMEOUT/PARTIAL',
    error_secs          INT COMMENT '预测误差(秒) = |predicted - actual|',

    -- 上下文
    session_context     JSON COMMENT '预测时的上下文快照(时间段/设备/连续学习时长等)',

    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_prediction_id (prediction_id),
    INDEX idx_student_task (student_id, task_id),
    INDEX idx_created (created_at),
    INDEX idx_student_type (student_id, task_type, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='耗时预测记录表';
```

### 3.6 错误码定义

| 错误码 | HTTP | 说明 | 处理建议 |
| --- | --- | --- | --- |
| `PRED_001` | 400 | 任务ID不存在 | 检查任务ID是否正确 |
| `PRED_002` | 400 | 不支持的任务类型 | 检查task_type枚举值 |
| `PRED_003` | 400 | 学生不存在或未激活 | 引导用户完成注册 |
| `PRED_004` | 404 | 复杂度档案不存在 | 先调用复杂度评估接口 |
| `PRED_005` | 404 | 学生速度画像不存在(冷启动) | 使用默认速度系数1.0 |
| `PRED_006` | 422 | 预测反馈数据异常(实际耗时为0或超限) | 检查上报数据合法性 |
| `PRED_007` | 429 | 预测请求频率超限 | 降级为本地缓存预测 |
| `PRED_008` | 500 | 预测模型内部错误 | 降级为基准参数估算 |
| `PRED_009` | 400 | 批量预测任务数超限(>200) | 分批请求 |

## 4. 业务逻辑

### 4.1 核心预测公式

#### 4.1.1 任务复杂度评分计算

```
complexityScore = Σ(dimension_i × weight_i) × 100

其中:
- dimension_i ∈ {cognitiveLoad, contentVolume, skillDependency, formatComplexity}
- weight_i 由任务类型权重配置决定
- 各 dimension 值域 [0.0, 1.0]
- 最终 complexityScore 值域 [0, 100]
```

#### 4.1.2 基准耗时计算

```
baseDuration = baseline_median × (1 + α × (complexityScore - 50) / 50)

其中:
- baseline_median: 该任务类型+学科+年级的中位数耗时
- α: 复杂度弹性系数, 默认 0.6
- complexityScore: 综合复杂度评分
```

#### 4.1.3 个性化耗时预测

```
predictedDuration = baseDuration × studentSpeedFactor × fatigueMultiplier × contextAdjustment

其中:
- baseDuration: 任务基准耗时
- studentSpeedFactor: 学生该学科速度系数(分难度)
- fatigueMultiplier: 疲劳系数(基于连续学习时长)
- contextAdjustment: 上下文调整因子(时间段/设备等)
```

#### 4.1.4 预测区间

```
predictedRangeLow  = predictedDuration × (1 - bandWidth × (1 - confidenceScore))
predictedRangeHigh = predictedDuration × (1 + bandWidth × (1 - confidenceScore))

其中:
- bandWidth: 默认 0.3 (可配置)
- confidenceScore: 模型置信度 [0, 1]
- 置信度越高，预测区间越窄
```

#### 4.1.5 疲劳系数模型

基于连续学习时长(分钟)的非线性递增模型：

```python
def calculate_fatigue_multiplier(consecutive_mins: int) -> float:
    """
    连续学习疲劳系数计算
    - 0-15分钟: 1.0 (高效期)
    - 15-30分钟: 1.0 → 1.05 (轻微下降)
    - 30-45分钟: 1.05 → 1.15 (明显下降)
    - 45-60分钟: 1.15 → 1.35 (严重下降)
    - 60+分钟: 1.35+ (建议休息)
    """
    if consecutive_mins <= 15:
        return 1.0
    elif consecutive_mins <= 30:
        # 线性插值 1.0 → 1.05
        return 1.0 + 0.05 * (consecutive_mins - 15) / 15
    elif consecutive_mins <= 45:
        # 线性插值 1.05 → 1.15
        return 1.05 + 0.10 * (consecutive_mins - 30) / 15
    elif consecutive_mins <= 60:
        # 线性插值 1.15 → 1.35
        return 1.15 + 0.20 * (consecutive_mins - 45) / 15
    else:
        # 60分钟以上，每10分钟增加0.05
        excess = consecutive_mins - 60
        return 1.35 + 0.05 * (excess // 10)
```

### 4.3 学生速度画像构建与校准

#### 4.3.1 速度系数计算

采用滑动窗口 + 中位数滤波的方式计算：

```python
import statistics
from collections import defaultdict

def calibrate_speed_factor(
    student_id: int,
    subject_code: str,
    recent_records: list[dict],  # 最近N条已完成任务的预测记录
    difficulty_band: str = None   # None表示计算综合速度系数
) -> dict:
    """
    基于最近的任务完成记录，校准学生速度系数

    recent_records 示例:
    [
        {"taskId": "...", "predictedSecs": 180, "actualSecs": 210, "difficultyBand": "MEDIUM"},
        {"taskId": "...", "predictedSecs": 120, "actualSecs": 110, "difficultyBand": "EASY"},
        ...
    ]
    """
    # 过滤异常值
    valid_records = filter_outliers(recent_records)

    if not valid_records:
        return {"speedFactor": 1.0, "confidence": 0.0, "sampleCount": 0}

    # 按难度分组
    by_difficulty = defaultdict(list)
    for record in valid_records:
        ratio = record["predictedSecs"] / record["actualSecs"]  # >1 表示比预测快
        by_difficulty[record["difficultyBand"]].append(ratio)

    result = {}

    # 计算分难度速度系数
    for band, ratios in by_difficulty.items():
        # 使用中位数避免极端值影响
        median_ratio = statistics.median(ratios)
        result[band] = {
            "factor": round(median_ratio, 3),
            "samples": len(ratios)
        }

    # 计算综合速度系数
    all_ratios = [r for ratios in by_difficulty.values() for r in ratios]
    overall_factor = statistics.median(all_ratios)

    # 置信度: 基于样本量和一致性
    sample_count = len(all_ratios)
    if sample_count >= 50:
        consistency = 1.0 - min(statistics.stdev(all_ratios), 1.0)
        confidence = min(0.95, 0.5 + consistency * 0.5)
    elif sample_count >= 10:
        confidence = min(0.8, sample_count / 50 + 0.3)
    else:
        confidence = sample_count / 50 * 0.5  # 冷启动阶段

    # 趋势判断: 比较前半段和后半段的速度
    trend = "STABLE"
    if sample_count >= 20:
        mid = sample_count // 2
        first_half_avg = statistics.mean(all_ratios[:mid])
        second_half_avg = statistics.mean(all_ratios[mid:])
        improvement_threshold = 0.08  # 8%改善为显著
        if second_half_avg - first_half_avg > improvement_threshold:
            trend = "IMPROVING"
        elif first_half_avg - second_half_avg > improvement_threshold:
            trend = "DECLINING"

    return {
        "speedFactor": round(overall_factor, 3),
        "confidence": round(confidence, 3),
        "sampleCount": sample_count,
        "trend": trend,
        "byDifficulty": result
    }


def filter_outliers(records: list[dict], threshold_std: float = 2.5) -> list[dict]:
    """过滤异常值: 移除偏离均值超过 threshold_std 个标准差的记录"""
    if len(records) < 4:
        return records

    ratios = [r["predictedSecs"] / max(r["actualSecs"], 1) for r in records]
    mean = statistics.mean(ratios)
    std = statistics.stdev(ratios)

    if std == 0:
        return records

    return [
        r for r, ratio in zip(records, ratios)
        if abs(ratio - mean) <= threshold_std * std
    ]
```

#### 4.3.2 增量更新策略

每次收到耗时反馈时，采用指数加权移动平均(EWMA)进行增量更新，避免全量重算：

```python
def incremental_update(
    current_factor: float,
    current_confidence: float,
    current_sample_count: int,
    new_ratio: float,  # predicted / actual
    alpha: float = 0.15  # 平滑因子
) -> tuple[float, float]:
    """
    EWMA增量更新速度系数

    alpha越大，新数据权重越高，适应越快但波动也越大
    alpha越小，历史数据权重越高，越稳定但适应慢
    """
    # 速度系数更新
    updated_factor = current_factor * (1 - alpha) + new_ratio * alpha

    # 置信度更新: 样本数增加，置信度逐步提升
    new_sample_count = current_sample_count + 1
    confidence_cap = min(new_sample_count / 50, 1.0) * 0.95
    updated_confidence = min(
        current_confidence * (1 - alpha * 0.3) + confidence_cap * alpha * 0.3,
        confidence_cap
    )

    return round(updated_factor, 3), round(updated_confidence, 3)
```

### 4.5 冷启动策略

    /**
     * 单任务耗时预测
     */
    @Cached(expire = 600, cacheType = CacheType.REDIS)
    public DurationPredictionResult predict(PredictionRequest request) {
        String studentId = request.getStudentId();
        String taskId = request.getTaskId();

        // 1. 获取任务复杂度档案
        TaskComplexityProfile complexity = getOrCreateComplexity(request);
        if (complexity == null) {
            log.warn("无法评估任务复杂度, 使用基准参数降级预测, taskId={}", taskId);
            return fallbackPredict(request);
        }

        // 2. 获取学生速度画像
        StudentSpeedProfile speedProfile = getSpeedProfile(studentId, complexity.getSubjectCode());

        // 3. 选择分难度速度系数
        BigDecimal speedFactor = selectSpeedFactor(speedProfile, complexity.getDifficultyBand());

        // 4. 计算上下文调整因子
        BigDecimal contextAdjustment = calculateContextAdjustment(request.getContext());

        // 5. 计算疲劳系数
        BigDecimal fatigueMultiplier = calculateFatigueMultiplier(
            request.getContext().getConsecutiveStudyMins()
        );

        // 6. 综合计算
        int baseDuration = complexity.getBaseDurationSecs();
        BigDecimal predictedDecimal = BigDecimal.valueOf(baseDuration)
            .multiply(speedFactor)
            .multiply(fatigueMultiplier)
            .multiply(contextAdjustment);

        int predictedSecs = clamp(predictedDecimal.intValue(),
            getMinDuration(complexity), getMaxDuration(complexity));

        // 7. 计算预测区间
        BigDecimal confidence = speedProfile != null ? speedProfile.getConfidenceScore() : BigDecimal.ZERO;
        int[] range = calculatePredictionRange(predictedSecs, confidence);

        // 8. 构建预测因子明细
        PredictionFactors factors = PredictionFactors.builder()
            .taskComplexityScore(complexity.getComplexityScore().doubleValue())
            .studentSpeedFactor(speedFactor.doubleValue())
            .fatigueAdjustment(fatigueMultiplier.doubleValue())
            .contextAdjustment(contextAdjustment.doubleValue())
            .finalEstimate(predictedSecs)
            .build();

        // 9. 保存预测记录
        String predictionId = generatePredictionId(studentId);
        savePredictionLog(predictionId, request, predictedSecs, range, confidence, factors);

        return DurationPredictionResult.builder()
            .predictionId(predictionId)
            .taskId(taskId)
            .predictedSecs(predictedSecs)
            .predictedRangeLow(range[0])
            .predictedRangeHigh(range[1])
            .confidenceLevel(mapConfidenceLevel(confidence))
            .confidenceScore(confidence.doubleValue())
            .factors(factors)
            .build();
    }

    public BatchPredictionResult predictBatch(BatchPredictionRequest request) {
        List<DurationPredictionResult> results = new ArrayList<>();
        List<FatigueNote> fatigueNotes = new ArrayList<>();

        int cumulativeMins = request.getContext() != null
            ? request.getContext().getConsecutiveStudyMins() : 0;

        for (int i = 0; i < request.getTasks().size(); i++) {
            var taskRequest = request.getTasks().get(i);

            // 动态更新连续学习时长
            var context = PredictionContext.builder()
                .consecutiveStudyMins(cumulativeMins)
                .timeOfDay(request.getContext().getTimeOfDay())
                .deviceId(request.getContext().getDeviceId())
                .build();

            var singleRequest = PredictionRequest.builder()
                .studentId(request.getStudentId())
                .taskId(taskRequest.getTaskId())
                .taskType(taskRequest.getTaskType())
                .subjectCode(taskRequest.getSubjectCode())
                .gradeLevel(taskRequest.getGradeLevel())
                .context(context)
                .build();

            var result = predict(singleRequest);
            results.add(result);

            // 累加预计耗时
            int taskMins = result.getPredictedSecs() / 60;
            cumulativeMins += taskMins;

            // 记录疲劳预警
            if (cumulativeMins > 30 && request.isIncludeFatigueProgression()) {
                fatigueNotes.add(FatigueNote.builder()
                    .taskIndex(i)
                    .fatigueMultiplier(result.getFactors().getFatigueAdjustment())

                        cumulativeMins,
                        (result.getFactors().getFatigueAdjustment() - 1) * 100))
                    .build());
            }
        }

        int totalSecs = results.stream().mapToInt(DurationPredictionResult::getPredictedSecs).sum();

        return BatchPredictionResult.builder()
            .batchId(generateBatchId(request.getStudentId()))
            .totalPredictedSecs(totalSecs)
            .totalPredictedMins(totalSecs / 60)
            .taskPredictions(results)
            .fatigueNotes(fatigueNotes)
            .build();

     * 耗时反馈处理
     */
    @Transactional
    public FeedbackResult acceptFeedback(FeedbackRequest request) {
        // 1. 查找原始预测记录
        DurationPredictionLog log = predictionLogRepository
            .findByPredictionId(request.getPredictionId())
            .orElseThrow(() -> new BusinessException("PRED_006", "预测记录不存在"));

        if (request.getActualSecs() <= 0 || request.getActualSecs() > 14400) {
            throw new BusinessException("PRED_006", "实际耗时数据异常");
        }

        // 3. 更新预测记录
        log.setActualSecs(request.getActualSecs());
        log.setCompletionStatus(request.getCompletionStatus());
        log.setErrorSecs(Math.abs(log.getPredictedSecs() - request.getActualSecs()));
        predictionLogRepository.save(log);

        // 4. EWMA增量校准学生速度画像
        BigDecimal ratio = BigDecimal.valueOf(log.getPredictedSecs())
            .divide(BigDecimal.valueOf(request.getActualSecs()), 4, RoundingMode.HALF_UP);

        StudentSpeedProfile profile = speedProfileRepository
            .findByStudentIdAndSubjectCode(log.getStudentId(), log.getSubjectCode())
            .orElseGet(() -> createDefaultProfile(log.getStudentId(), log.getSubjectCode()));

        BigDecimal previousFactor = selectSpeedFactor(profile, log.getDifficultyBand());
        BigDecimal newFactor = incrementalEwmaUpdate(previousFactor, ratio);

        // 更新对应难度档的速度系数
        updateDifficultyFactor(profile, log.getDifficultyBand(), newFactor);
        profile.setSampleCount(profile.getSampleCount() + 1);
        profile.setConfidenceScore(updateConfidence(profile));
        profile.setLastCalibratedAt(LocalDateTime.now());

        speedProfileRepository.save(profile);

        // 清除缓存
        redisTemplate.delete(String.format("ssp:student:%d:subject:%s",

        return FeedbackResult.builder()

            .calibrationResult(CalibrationResult.builder()
                .previousSpeedFactor(previousFactor.doubleValue())
                .newSpeedFactor(newFactor.doubleValue())
                .adjustmentDelta(newFactor.subtract(previousFactor).doubleValue())
                .sampleCount(profile.getSampleCount())
                .newConfidence(profile.getConfidenceScore().doubleValue())
                .build())
            .build();
    }

    // ==================== 私有方法 ====================

    private BigDecimal selectSpeedFactor(StudentSpeedProfile profile, String difficultyBand) {
        if (profile == null) return BigDecimal.ONE;

        return switch (difficultyBand) {
            case "EASY" -> profile.getEasySpeedFactor();
            case "MEDIUM" -> profile.getMediumSpeedFactor();
            case "HARD" -> profile.getHardSpeedFactor();
            case "CHALLENGING" -> profile.getHardSpeedFactor()
                .multiply(new BigDecimal("0.85")); // 超难题额外减速
            default -> profile.getSpeedFactor();
        };
    }

    private int[] calculatePredictionRange(int predicted, BigDecimal confidence) {
        double bandWidth = modelConfig.getPredictionBandMultiplier(); // 默认0.3
        double adjustment = bandWidth * (1.0 - confidence.doubleValue());

        int low = (int) (predicted * (1 - adjustment));
        int high = (int) (predicted * (1 + adjustment));
        return new int[]{Math.max(low, 10), Math.min(high, 14400)};
    }

    private BigDecimal incrementalEwmaUpdate(BigDecimal current, BigDecimal newRatio) {
        double alpha = 0.15;
        double updated = current.doubleValue() * (1 - alpha) + newRatio.doubleValue() * alpha;
        return BigDecimal.valueOf(updated).setScale(3, RoundingMode.HALF_UP);
    }

    private BigDecimal calculateFatigueMultiplier(Integer consecutiveMins) {
        if (consecutiveMins == null || consecutiveMins <= 15) return BigDecimal.ONE;
        double mins = consecutiveMins.doubleValue();
        double multiplier;
        if (mins <= 30) {
            multiplier = 1.0 + 0.05 * (mins - 15) / 15;
        } else if (mins <= 45) {
            multiplier = 1.05 + 0.10 * (mins - 30) / 15;
        } else if (mins <= 60) {
            multiplier = 1.15 + 0.20 * (mins - 45) / 15;
        } else {
            multiplier = 1.35 + 0.05 * ((mins - 60) / 10);
        }
        return BigDecimal.valueOf(multiplier).setScale(3, RoundingMode.HALF_UP);
    }

    private BigDecimal calculateContextAdjustment(PredictionContext context) {
        if (context == null) return BigDecimal.ONE;
        BigDecimal adjustment = BigDecimal.ONE;

        // 时间段调整
        if (context.getTimeOfDay() != null) {
            adjustment = adjustment.multiply(switch (context.getTimeOfDay()) {
                case "MORNING" -> new BigDecimal("0.95");   // 上午高效
                case "AFTERNOON" -> new BigDecimal("1.00");  // 下午正常
                case "EVENING" -> new BigDecimal("1.05");    // 晚上略慢
                case "NIGHT" -> new BigDecimal("1.15");      // 深夜显著慢
                default -> BigDecimal.ONE;
            });
        }

        // 设备类型调整
        if ("tablet".equals(context.getDeviceId())) {
            adjustment = adjustment.multiply(new BigDecimal("0.97")); // 平板略快
        }

        return adjustment;
    }

    private String mapConfidenceLevel(BigDecimal confidence) {
        double c = confidence.doubleValue();
        if (c >= 0.7) return "HIGH";
        if (c >= 0.4) return "MEDIUM";
        return "LOW";
    }
}

@Service
public class TaskComplexityEvaluator {

    @Autowired
    private KnowledgePointService knowledgePointService;
    @Autowired
    private TaskTypeBaselineRepository baselineRepository;
    @Autowired
    private PredictionModelConfig modelConfig;

    private static final Map<String, BigDecimal> BLOOM_SCORES = Map.of(
        "REMEMBER", new BigDecimal("0.20"),
        "UNDERSTAND", new BigDecimal("0.35"),
        "APPLY", new BigDecimal("0.50"),
        "ANALYZE", new BigDecimal("0.65"),
        "EVALUATE", new BigDecimal("0.80"),
        "CREATE", new BigDecimal("0.90")
    );

    private static final Map<String, BigDecimal> QUESTION_TYPE_BASE = Map.ofEntries(
        Map.entry("TRUE_FALSE", new BigDecimal("0.10")),
        Map.entry("MULTIPLE_CHOICE", new BigDecimal("0.20")),
        Map.entry("FILL_IN_BLANK", new BigDecimal("0.30")),
        Map.entry("SHORT_ANSWER", new BigDecimal("0.35")),
        Map.entry("CALCULATION", new BigDecimal("0.45")),
        Map.entry("PROOF", new BigDecimal("0.60")),
        Map.entry("OPEN_ENDED", new BigDecimal("0.55")),
        Map.entry("EXPERIMENT", new BigDecimal("0.65"))
    );

    /**
     * 评估任务复杂度并生成档案
     */
    public TaskComplexityProfile evaluate(ComplexityEvalRequest request) {
        String taskType = request.getTaskType();
        var weights = modelConfig.getTaskTypeWeights(taskType);

        // 计算四维评分
        BigDecimal cognitiveLoad = evaluateCognitiveLoad(request);
        BigDecimal contentVolume = evaluateContentVolume(request);
        BigDecimal skillDependency = evaluateSkillDependency(request);
        BigDecimal formatComplexity = evaluateFormatComplexity(request);

        // 加权综合评分
        BigDecimal complexityScore = cognitiveLoad.multiply(weights.getCognitiveLoad())
            .add(contentVolume.multiply(weights.getContentVolume()))
            .add(skillDependency.multiply(weights.getSkillDependency()))
            .add(formatComplexity.multiply(weights.getFormatComplexity()))
            .multiply(new BigDecimal("100"))
            .setScale(2, RoundingMode.HALF_UP);

        String difficultyBand = mapDifficultyBand(complexityScore);

        // 计算基准耗时
        int baseDuration = calculateBaseDuration(request, complexityScore);

        return TaskComplexityProfile.builder()
            .taskId(request.getTaskId())
            .taskType(taskType)
            .subjectCode(request.getSubjectCode())
            .gradeLevel(request.getGradeLevel())
            .cognitiveLoad(cognitiveLoad)
            .contentVolume(contentVolume)
            .skillDependency(skillDependency)
            .formatComplexity(formatComplexity)
            .complexityScore(complexityScore)
            .difficultyBand(difficultyBand)
            .baseDurationSecs(baseDuration)
            .featureSnapshot(buildFeatureSnapshot(request))
            .build();
    }

    private int calculateBaseDuration(ComplexityEvalRequest request, BigDecimal complexityScore) {
        TaskTypeBaseline baseline = baselineRepository
            .findByTaskTypeAndSubjectCodeAndGradeLevel(
                request.getTaskType(),
                request.getSubjectCode(),
                request.getGradeLevel()
            )
            .orElseGet(() -> baselineRepository
                .findByTaskTypeAndSubjectCodeAndGradeLevel(
                    request.getTaskType(), "GENERAL", 0
                )
                .orElseThrow());

        double median = baseline.getMedianDurationSecs();
        double alpha = 0.6; // 复杂度弹性系数
        double complexityOffset = (complexityScore.doubleValue() - 50) / 50;

        return (int) Math.max(
            baseline.getMinDurationSecs(),
            Math.min(
                baseline.getMaxDurationSecs(),
                median * (1 + alpha * complexityOffset)
            )
        );
    }

    private String mapDifficultyBand(BigDecimal score) {
        double s = score.doubleValue();
        if (s < 25) return "EASY";
        if (s < 50) return "MEDIUM";
        if (s < 75) return "HARD";
        return "CHALLENGING";
    }

    // evaluateCognitiveLoad / evaluateContentVolume / etc. 省略，见4.2.1节伪代码
}

/**
 * 定时任务: 全量校准学生速度画像
 * 每天凌晨3点执行，处理前一天的预测反馈数据

@Component
@Slf4j
public class DailySpeedCalibrationJob {

    @Autowired
    private DurationPredictionLogRepository predictionLogRepository;
    @Autowired
    private StudentSpeedProfileRepository speedProfileRepository;
    @Autowired
    private SpeedCalibrator calibrator;

    @Scheduled(cron = "0 0 3 * * ?")
    public void executeDailyCalibration() {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        int batchSize = 500;
        int processed = 0;
        int updated = 0;

        // 分页扫描有反馈数据的记录
        Pageable pageable = PageRequest.of(0, batchSize);
        while (true) {
            List<DurationPredictionLog> records = predictionLogRepository
                .findCalibratedRecordsByDate(yesterday, pageable);

            if (records.isEmpty()) break;

            // 按学生+学科分组
            Map<String, List<DurationPredictionLog>> grouped = records.stream()
                .collect(Collectors.groupingBy(
                    r -> r.getStudentId() + ":" + r.getSubjectCode()
                ));

            for (var entry : grouped.entrySet()) {
                String[] key = entry.getKey().split(":");
                Long studentId = Long.parseLong(key[0]);
                String subjectCode = key[1];

                // 获取最近90天的全量记录进行全量校准
                List<DurationPredictionLog> recentRecords = predictionLogRepository
                    .findRecentRecords(studentId, subjectCode, 90);

                var result = calibrator.calibrate(studentId, subjectCode, recentRecords);
                if (result.isChanged()) {
                    speedProfileRepository.save(result.getProfile());
                    updated++;
                }
            }

            processed += records.size();
            pageable = pageable.next();
        }

        log.info("每日速度校准完成: 处理{}条记录, 更新{}个画像", processed, updated);
    }
}

public class DailyTaskPlanner {

    @Autowired
    private DurationPredictionService predictionService;

    public DailyPlan generateDailyPlan(Long studentId, List<LearningTask> candidates) {
        // 1. 批量预测所有候选任务的耗时
        var batchRequest = buildBatchRequest(studentId, candidates);
        var prediction = predictionService.predictBatch(batchRequest);

        // 2. 根据预测总耗时和每日学习时间预算筛选任务
        int dailyBudgetSecs = getDailyStudyBudget(studentId); // 如3600秒(1小时)

            if (accumulatedSecs + pred.getPredictedSecs() <= dailyBudgetSecs * 1.1) {
                selected.add(candidates.get(i));
                accumulatedSecs += pred.getPredictedSecs();
            }
        }

        return DailyPlan.builder()
            .tasks(selected)
            .estimatedTotalMins(accumulatedSecs / 60)
            .build();
    }

            buildBatchRequest(studentId, tasks)
        );

        // 3. 按天分配任务（考虑每天的时间预算和学科均衡）
        Map<DayOfWeek, List<ScheduledTask>> schedule = new HashMap<>();
        int dailyBudget = getDailyBudget(studentId); // 每天学习预算(秒)

        // 贪心分配: 按科目轮流分配，避免某天全是数学
        int dayIndex = 0;
        String lastSubject = null;
        for (var taskPred : prediction.getTaskPredictions()) {
            LearningTask task = findTask(tasks, taskPred.getTaskId());

            // 避免连续同学科
            if (task.getSubjectCode().equals(lastSubject)) {
                dayIndex = (dayIndex + 1) % 7;
            }

            DayOfWeek day = DayOfWeek.values()[dayIndex];
            var dayTasks = schedule.computeIfAbsent(day, k -> new ArrayList<>());
            int dayTotal = dayTasks.stream()
                .mapToInt(st -> st.getEstimatedSecs()).sum();

            if (dayTotal + taskPred.getPredictedSecs() <= dailyBudget) {
                dayTasks.add(ScheduledTask.builder()
                    .task(task)
                    .estimatedSecs(taskPred.getPredictedSecs())
                    .predictedRange(taskPred.getPredictedRangeLow(),
                                   taskPred.getPredictedRangeHigh())
                    .build());
                lastSubject = task.getSubjectCode();
            } else {
                dayIndex = (dayIndex + 1) % 7;
            }
        }

        return WeeklyPlan.builder().schedule(schedule).build();
    }
}

## 附录 B: 常见问题

**Q1: 学生故意拖延（实际耗时远超预测），是否会影响模型？**

A: 异常值过滤器会在校准时移除偏离均值超过2.5个标准差的记录。此外，`completion_status` 为 `ABANDONED` 的记录不参与速度系数校准，仅记录统计。

**Q2: 学生换年级后历史画像是否仍然有效？**

A: 有效但需衰减。系统在学生升年级时会自动应用年级迁移系数(0.92-0.98)，并在新年级积累20条以上记录后完全切换到新年级画像。

**Q3: 如何处理不同教材版本导致的知识点差异？**

A: 复杂度评估在知识点维度上依赖的是知识点服务提供的布鲁姆层级和依赖链深度，这些属性在跨教材版本时基本一致。版本差异主要由题目服务在题目元数据中体现。

**Q4: 预测准确性需要多久才能达到可用水平？**

A: 基于经验数据估算：
- 10条样本：粗略可用（MAPE ~40%）
- 30条样本：基本准确（MAPE ~30%）
- 50条样本：较高准确度（MAPE ~25%）
- 100条样本：稳定准确（MAPE ~20%）

按每天10-20条学习行为计算，新用户约3-5天达到基本准确。
