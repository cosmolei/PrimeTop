# 服务端-学生用户学习资源库与个人数字内容资产管理引擎-详细设计

## 1. 概述

### 1.1 功能定位

学生用户在 PrimeTop 平台的使用过程中，会持续积累各类数字学习资产：购买的课程与题库包、系统奖励的解锁内容、自主收藏的笔记与错题、下载的离线资源包、家长赠送的学习内容、活动获得的限定道具等。当前平台各业务模块各自管理其涉及的资源（如会员系统管权益、收藏系统管书签、积分系统管虚拟物品），但缺少一个**统一的个人数字资产账户层**，将分散在不同业务系统中的用户资源进行聚合管理，为用户提供"我的学习资源库"入口，同时为各业务模块提供统一的资产查询、鉴权与生命周期管理能力。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 统一资产视图 | 聚合来自购买、奖励、创建、赠送等渠道的所有学习资源，提供统一查询接口 |
| 资产权益鉴权 | 为内容访问提供统一的"用户是否拥有此资源"鉴权决策 |
| 资产生命周期 | 管理资源的获取、生效、过期、续期、回收全流程 |
| 资产组织能力 | 支持分类、标签、文件夹等方式对个人资源进行整理 |
| 家庭资产共享 | 支持家庭账户内资源的受控共享与配额管理 |
| 资产迁移 | 支持账号合并、年级升迁等场景下的资产迁移 |

### 1.3 适用范围

- **客户端**："我的资源库"页面、学习内容访问前的权益校验
- **服务端**：各业务模块（会员、支付、积分、活动、内容）的资产变更通知与查询
- **管理后台**：用户资产查询、异常资产处理、资产报表

### 1.4 术语定义

| 术语 | 定义 |
| --- | --- |
| DigitalAsset | 数字资产，用户拥有的一份数字学习资源的所有权记录 |
| AssetType | 资产类型（购买课程、奖励内容、自定义笔记集等） |
| AssetSource | 资产获取渠道（购买、奖励、创建、赠送、活动） |
| AssetEntitlement | 资产权益，资产附带的可执行权利（可阅读、可下载、可分享） |
| AssetLicense | 资产授权许可，定义资产的使用约束（有效期、设备数限制等） |


### 2.2 资产权益类型

| 权益类型 | 说明 | 示例 |
| --- | --- | --- |
| ACCESS | 可访问/阅读内容 | 课程视频观看权 |

## 3. 数据结构设计

### 3.1 核心表设计

#### 3.1.1 `user_digital_asset` — 用户数字资产主表

```sql
CREATE TABLE `user_digital_asset` (
    `id`                BIGINT       NOT NULL AUTO_INCREMENT COMMENT '资产记录ID',
    `user_id`           BIGINT       NOT NULL COMMENT '所属用户ID',
    `asset_code`        VARCHAR(64)  NOT NULL COMMENT '资产唯一编码（业务幂等键）',
    `asset_type`        VARCHAR(32)  NOT NULL COMMENT '资产类型：COURSE/Sub PACK/QUESTION_BANK/REWARD/NOTE_SET/FLASHCARD_SET/...]',
    `asset_source`      VARCHAR(32)  NOT NULL COMMENT '获取渠道：PURCHASE/REWARD/CREATED/GIFT/EVENT/COMPENSATION',
    `resource_id`       VARCHAR(128) NOT NULL COMMENT '关联资源ID（课程ID/题库ID/笔记集ID等）',
    `resource_type`     VARCHAR(32)  NOT NULL COMMENT '资源类型：COURSE/QUESTION_PACK/NOTE_COLLECTION/...',
    `resource_name`     VARCHAR(256) NOT NULL DEFAULT '' COMMENT '资源显示名称（冗余快照）',
    `resource_cover`    VARCHAR(512) NOT NULL DEFAULT '' COMMENT '资源封面图URL（冗余快照）',
    `resource_meta`     JSON         NULL COMMENT '资源元数据快照（学科、学段、章节范围等）',
    
    `entitlements`      JSON         NOT NULL COMMENT '权益列表 ["ACCESS","DOWNLOAD","PRACTICE"]',
    `license_config`    JSON         NOT NULL COMMENT '授权配置（有效期、设备限制、使用次数限制等）',
    
    `status`            TINYINT      NOT NULL DEFAULT 1 COMMENT '资产状态：0-已失效 1-生效中 2-已过期 3-已转移 9-已回收',
    `acquired_at`       DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '获取时间',
    `effective_at`      DATETIME     NOT NULL COMMENT '生效时间',
    `expire_at`         DATETIME     NULL COMMENT '过期时间（NULL=永久）',
    `expired_at`        DATETIME     NULL COMMENT '实际失效时间',
    
    `source_order_id`   VARCHAR(64)  NOT NULL DEFAULT '' COMMENT '来源订单ID（购买类）',
    `source_event_id`   VARCHAR(64)  NOT NULL DEFAULT '' COMMENT '来源事件ID（奖励/活动类）',
    `source_user_id`    BIGINT       NULL COMMENT '来源用户ID（赠送类）',
    
    `folder_id`         BIGINT       NULL COMMENT '所属文件夹ID',
    `sort_order`        INT          NOT NULL DEFAULT 0 COMMENT '排序权重',
    `is_pinned`         TINYINT      NOT NULL DEFAULT 0 COMMENT '是否置顶',
    `is_hidden`         TINYINT      NOT NULL DEFAULT 0 COMMENT '是否隐藏',
    
    `family_shareable`  TINYINT      NOT NULL DEFAULT 1 COMMENT '是否允许家庭共享',
    `device_limit`       INT          NOT NULL DEFAULT 0 COMMENT '设备数量限制（0=不限）',
    
    `created_at`        DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`        DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_asset_code` (`user_id`, `asset_code`),
    KEY `idx_user_type` (`user_id`, `asset_type`, `status`),
    KEY `idx_user_resource` (`user_id`, `resource_id`, `resource_type`),
    KEY `idx_user_folder` (`user_id`, `folder_id`),
    KEY `idx_expire` (`status`, `expire_at`),
    KEY `idx_source_order` (`source_order_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户数字资产主表';
```

### 3.2 Redis 缓存结构

```
# 用户资产列表缓存（按类型分桶）
asset:list:{user_id}:{asset_type} → ZSET (score=sort_order, member=asset_id_json)
  TTL: 30min

# 单个资产详情缓存
asset:detail:{user_id}:{asset_id} → HASH
  TTL: 1h

# 用户资产权益索引（用于快速鉴权）
asset:entitlement:{user_id}:{resource_type}:{resource_id} → SET of asset_ids
  TTL: 10min

# 用户资产统计缓存
asset:stats:{user_id} → HASH { total, by_type, by_status, expiring_soon }
  TTL: 15min

# 设备授权记录（用于设备数限制）
asset:devices:{user_id}:{asset_id} → SET of device_ids
  TTL: align with asset expire_at
```

## 5. 资产状态机

### 5.1 状态流转图

```
                    ┌─────────────────────────────────────┐
                    │                                     │
                    ▼                                     │
    ┌───────┐  grant   ┌─────────┐  expire   ┌─────────┐ │  renew
    │ (init) │ ──────► │ 生效中   │ ────────► │ 已过期   │ ──────┘
    │        │         │ (1)     │           │ (2)     │
    └───────┘         └────┬────┘           └────┬────┘
                           │                     │
                    revoke │              recycle│
                           ▼                     ▼
                     ┌─────────┐          ┌─────────┐
                     │ 已失效   │          │ 已回收   │
                     │ (0)     │          │ (9)     │
                     └─────────┘          └─────────┘
                           │
                    transfer
                           ▼
                     ┌─────────┐
                     │ 已转移   │
                     │ (3)     │
                     └─────────┘
```

### 5.2 状态转换规则

| 当前状态 | 允许的转换 | 触发条件 |
| --- | --- | --- |
| init → 1 (生效中) | grant | 资产发放成功 |
| 1 → 2 (已过期) | 定时任务 | 当前时间 > expire_at |
| 1 → 0 (已失效) | revoke | 退款/取消订单/违规处理 |
| 1 → 3 (已转移) | transfer | 账号合并/资产转移 |
| 2 → 1 (生效中) | renew | 续期成功（重新设置 expire_at） |
| 2 → 9 (已回收) | 定时任务 | 过期超过90天自动回收 |
| 0 → 1 (生效中) | restore | 管理员恢复操作 |

### 5.3 幂等性保障

资产发放使用幂等键防止重复发放：

```java
public AssetGrantResult grantAsset(AssetGrantRequest request) {
    String idempotencyKey = request.getIdempotencyKey();
    
    // 1. 幂等检查
    Optional<UserDigitalAsset> existing = assetRepository
        .findByIdempotencyKey(idempotencyKey);
    if (existing.isPresent()) {
        return AssetGrantResult.alreadyGranted(existing.get());
    }
    
    // 2. 分布式锁防止并发
    String lockKey = "asset:grant:lock:" + idempotencyKey;
    return distributedLockManager.executeWithLock(lockKey, 10, TimeUnit.SECONDS, () -> {
        // 3. 二次检查（锁内）
        Optional<UserDigitalAsset> secondCheck = assetRepository
            .findByIdempotencyKey(idempotencyKey);
        if (secondCheck.isPresent()) {
            return AssetGrantResult.alreadyGranted(secondCheck.get());
        }
        
        // 4. 创建资产记录
        UserDigitalAsset asset = buildAsset(request);
        asset.setAssetCode(generateAssetCode());
        asset.setIdempotencyKey(idempotencyKey);
        asset.setStatus(AssetStatus.ACTIVE.getCode());
        
        assetRepository.insert(asset);
        
        // 5. 记录发放日志
        grantLogService.log(asset, request);
        
        // 6. 刷新缓存
        cacheService.evictAssetList(request.getUserId());
        
        // 7. 发布领域事件
        eventPublisher.publish(new AssetGrantedEvent(asset));
        
        return AssetGrantResult.success(asset);
    });
}
```

```java
public EntitlementCheckResult checkEntitlement(Long userId, String resourceId, 
    String resourceType, String requiredEntitlement, String deviceId) {
    
    // 1. 查权益索引缓存
    Set<Long> assetIds = cacheService.getEntitlementIndex(
        userId, resourceType, resourceId);
    
    if (assetIds == null) {
        // 缓存未命中，查库
        assetIds = assetRepository.findAssetIdsByResource(
            userId, resourceId, resourceType, AssetStatus.ACTIVE);
        cacheService.setEntitlementIndex(
            userId, resourceType, resourceId, assetIds, 10, TimeUnit.MINUTES);
    }
    
    if (assetIds.isEmpty()) {
        return EntitlementCheckResult.noAsset();
    }
    
    // 2. 取最优资产（永久 > 有期限，权益更全的优先）
    UserDigitalAsset bestAsset = selectBestAsset(userId, assetIds);
    
    // 3. 校验权益
    if (!bestAsset.getEntitlements().contains(requiredEntitlement)) {
        return EntitlementCheckResult.noEntitlement(bestAsset);
    }
    
    // 4. 校验License
    LicenseCheckResult licenseResult = checkLicense(bestAsset, deviceId);
    if (!licenseResult.isValid()) {
        return EntitlementCheckResult.licenseInvalid(bestAsset, licenseResult);
    }
    
    // 5. 设备数校验
    if (bestAsset.getDeviceLimit() > 0) {
        boolean deviceOk = deviceRegistryService.registerDevice(
            userId, bestAsset.getId(), deviceId, bestAsset.getDeviceLimit());
        if (!deviceOk) {
            return EntitlementCheckResult.deviceLimitExceeded(bestAsset);
        }
    }
    
    // 6. 记录访问日志（异步）
    asyncLogAccess(userId, bestAsset.getId(), resourceId, "ACCESS", deviceId);
    
    return EntitlementCheckResult.ok(bestAsset);
}
```

```java
@Transactional
public void transferAssetsOnAccountMerge(Long sourceUserId, Long targetUserId) {
    // 1. 查询源账号所有有效资产
    List<UserDigitalAsset> sourceAssets = assetRepository
        .findAllByUserId(sourceUserId, AssetStatus.ACTIVE);
    
    int transferred = 0;
    int deduplicated = 0;
    
    for (UserDigitalAsset sourceAsset : sourceAssets) {
        // 2. 检查目标账号是否已有同资源资产
        boolean exists = assetRepository.existsByResource(
            targetUserId, 
            sourceAsset.getResourceId(), 
            sourceAsset.getResourceType(),
            AssetStatus.ACTIVE
        );
        
        if (exists) {
            // 2a. 去重：标记源资产为"已转移-去重"
            assetRepository.updateStatus(
                sourceAsset.getId(), 
                AssetStatus.TRANSFERRED.getCode(),
                "DEDUP_TARGET_HAS_SAME_RESOURCE"
            );
            deduplicated++;
        } else {
            // 2b. 迁移：更新 user_id，记录迁移日志
            assetRepository.transferOwnership(
                sourceAsset.getId(), 
                sourceUserId, 
                targetUserId
            );
            transferred++;
        }
    }
    
    // 3. 迁移文件夹
    folderService.transferFolders(sourceUserId, targetUserId);
    
    // 4. 迁移共享记录
    familyShareService.transferShares(sourceUserId, targetUserId);
    
    // 5. 清理双方缓存
    cacheService.evictAll(sourceUserId);
    cacheService.evictAll(targetUserId);
    
    // 6. 发布迁移完成事件
    eventPublisher.publish(new AssetTransferCompletedEvent(
        sourceUserId, targetUserId, transferred, deduplicated));
    
    log.info("Asset transfer complete: source={}, target={}, transferred={}, deduplicated={}",
        sourceUserId, targetUserId, transferred, deduplicated);
}
```

### 7.2 资产选择策略（最优权益选择）

```java
public class AssetSelectionStrategy {
    
    /**
     * 从多个匹配资产中选择最优的一个
     * 优先级：永久 > 有期限 > 即将过期；权益更多 > 权益更少
     */
    public UserDigitalAsset selectBest(List<UserDigitalAsset> assets) {
        return assets.stream()
            .filter(a -> a.getStatus() == AssetStatus.ACTIVE.getCode())
            .max(Comparator
                // 永久资产优先
                .comparing((UserDigitalAsset a) -> 
                    a.getExpireAt() == null ? 1 : 0)
                // 其次按过期时间降序（越晚过期越优）
                .thenComparing(a -> a.getExpireAt() == null ? 
                    LocalDateTime.MAX : a.getExpireAt(),
                    Comparator.reverseOrder())
                // 其次按权益数量降序
                .thenComparing(a -> a.getEntitlements().size(),
                    Comparator.reverseOrder())
                // 最后按获取时间降序（最新获取优先）
                .thenComparing(UserDigitalAsset::getAcquiredAt,
                    Comparator.reverseOrder())
            )
            .orElse(null);
    }
}
```

```java
                ownAssets.stream().map(this::toOwnAssetItem),
                sharedAssets.stream().map(this::toSharedAssetItem)
            )

            .skip((query.getPage() - 1) * query.getPageSize())

            .total(ownAssets.size() + sharedAssets.size())
            .page(query.getPage())
            .pageSize(query.getPageSize())
            .items(allItems)
            .build();

            .map(FamilyAssetShare::getAssetId)
            .collect(Collectors.toList());

            .filter(a -> matchesQuery(a, query))
            .collect(Collectors.toList());
```

### 11.3 未成年人保护

- 赠送类资产需验证赠送者与接收者的家庭组关系
- 活动奖励资产发放不受家长使用时长限制影响（已获得的学习资源始终可见）
- 过期资产的数据清理遵循《未成年人数据保护规则》

### 16.2 License 配置模板

```java
public class LicenseTemplates {
    
    // 永久授权
    public static LicenseConfig permanent(int maxDevices) {
        return LicenseConfig.builder()
            .validityType("PERMANENT")
            .maxDevices(maxDevices)
            .build();
    }
    
    // 固定期限授权（如年度订阅）
    public static LicenseConfig fixedPeriod(
        LocalDateTime start, LocalDateTime end, int maxDevices) {
        return LicenseConfig.builder()
            .validityType("FIXED_PERIOD")
            .startAt(start)
            .endAt(end)
            .maxDevices(maxDevices)
            .build();
    }
    
    // 滚动期限授权（从首次使用开始计算）
    public static LicenseConfig rollingPeriod(int days, int maxDevices) {
        return LicenseConfig.builder()
            .validityType("ROLLING_PERIOD")
            .durationDays(days)
            .startTrigger("FIRST_ACCESS")
            .maxDevices(maxDevices)
            .build();
    }
    
    // 使用次数授权（如练习10次）
    public static LicenseConfig usageBased(int maxUsage) {
        return LicenseConfig.builder()
            .validityType("USAGE_BASED")
            .maxUsage(maxUsage)
            .build();
    }
}
```
