## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 学情分析体系中的核心诊断组件，专注于将学生在 App 内的完整学习交互旅程建模为**多级漏斗模型**，量化每个关键节点的转化率、流失率和停留时长，自动诊断学习流程中的体验瓶颈，并生成可执行的产品优化建议。

与现有系统的差异化定位：

| 现有系统 | 分析视角 | 与本引擎区别 |
|---------|---------|-------------|
| 用户转化漏斗分析与增长归因引擎 | **商业转化**：注册→试用→订阅→留存 | 聚焦付费转化，非学习行为深度 |
| 学习路径效果分析与行为序列模式挖掘 | **内容学习路径**：知识点A→知识点B→知识点C | 聚焦学科知识图谱上的学习轨迹 |
| 学生全链路体验质量实时感知与预警 | **实时体验监控**：响应延迟、卡顿、错误 | 聚焦技术质量，非流程设计 |
| **本引擎** | **产品交互流程**：开App→选模块→学内容→做练习→看报告 | 聚焦产品 UX 流程节点的转化效率 |

### 1.2 核心目标

1. **漏斗可视化**：为产品团队提供每个学习流程的转化漏斗全景视图
2. **瓶颈定位**：自动识别转化率异常下降的关键节点
3. **归因分析**：下钻分析流失用户的群体特征与行为模式
4. **优化建议**：基于数据模式生成产品改进策略推荐
5. **效果追踪**：A/B 实验后追踪漏斗指标变化，验证优化效果

### 1.3 适用场景

| 场景 | 漏斗模型示例 |
|-----|-------------|
| 同步课堂学习流 | 首页入口→教材选择→章节浏览→内容学习→课后练习→完成 |
| 拍题答疑流 | 首页→拍照→识别结果→查看解析→理解掌握→加入错题本 |
| AI 辅导对话流 | 首页→AI对话→提问→收到回答→追问→结束会话 |
| 错题复习流 | 错题本入口→筛选错题→开始复习→完成订正→标记掌握 |
| 作文辅导流 | 作文入口→选择题目→上传/输入→等待批改→查看报告→修改提交 |
| 新用户引导流 | 注册→选年级→选教材→首次学习→首次练习→首次错题 |

## 2. 核心概念定义

### 2.1 漏斗模型（Funnel Model）

漏斗模型是描述用户完成某个业务目标所经过的**有序关键节点序列**。每个节点代表一个用户行为事件，节点之间有严格的先后顺序。

```
漏斗模型 = {
    模型ID, 模型名称, 目标场景,
    节点序列 [节点1 → 节点2 → ... → 节点N],
    转化窗口, 归因规则
}
```

### 2.2 漏斗节点（Funnel Step）

| 属性 | 说明 |
|-----|------|
| step_id | 节点唯一标识 |
| step_name | 节点显示名称 |
| event_spec | 匹配事件规格（事件名 + 条件过滤） |
| step_order | 在漏斗中的序号（从1开始） |
| is_required | 是否必须经过此节点（可选节点用 false 标记） |

### 2.3 转化窗口（Conversion Window）

用户从进入漏斗第一个节点到最后一个节点的最大允许时间跨度。超出窗口的转化不计入漏斗转化率。

| 场景 | 推荐窗口 |
|-----|---------|
| 拍题答疑流 | 30 分钟 |
| 同步课堂单次学习 | 2 小时 |
| AI 辅导单次会话 | 1 小时 |
| 错题单次复习 | 1 小时 |
| 新用户引导流 | 7 天 |

### 2.4 归因规则（Attribution Rule）

| 规则 | 说明 |
|-----|------|
| FIRST_TOUCH | 用户在窗口内第一次进入漏斗的那次计入 |
| LAST_TOUCH | 用户在窗口内最后一次进入漏斗的那次计入 |
| CLOSEST_TO_CONVERSION | 取最接近最终转化的那次漏斗入口 |

### 2.5 瓶颈节点（Bottleneck Step）

漏斗中满足以下任一条件的节点被标记为瓶颈：

1. **绝对转化率低**：该节点转化率 < 阈值（默认 40%）
2. **相对下降大**：该节点转化率比上一节点下降幅度 > 阈值（默认 25%）
3. **历史偏离**：该节点转化率偏离历史均值 > 2 个标准差
4. **停留异常**：该节点平均停留时间 > 阈值（场景特定）

## 5. 漏斗匹配引擎设计

### 5.1 事件匹配算法

漏斗匹配的核心是判断一个传入的埋点事件是否命中某个漏斗的下一个预期节点。

```java
/**
 * 漏斗事件匹配器
 * 负责将传入事件与所有活跃漏斗模型进行匹配
 */
@Component
public class FunnelEventMatcher {

    @Autowired
    private FunnelModelCache modelCache;

    @Autowired
    private UserFunnelStateRedis stateRedis;

    /**
     * 处理单个埋点事件
     * 
     * @param event 标准化埋点事件
     */
    public void processEvent(TrackingEvent event) {
        // 1. 获取该事件可能关联的所有漏斗模型
        List<FunnelModel> candidateModels = modelCache.getModelsByEventName(event.getEventName());
        if (candidateModels.isEmpty()) {
            return;
        }

        for (FunnelModel model : candidateModels) {
            // 2. 检查事件是否匹配该漏斗的某个节点
            FunnelStep matchedStep = matchStep(model, event);
            if (matchedStep == null) {
                continue;
            }

            // 3. 获取用户在该漏斗中的当前状态
            UserFunnelState state = stateRedis.getState(model.getModelId(), event.getUserId());

            if (state == null) {
                // 3a. 用户不在漏斗中，检查是否命中第一个节点
                if (matchedStep.getStepOrder() == 1) {
                    handleFunnelEntry(model, event, matchedStep);
                }
            } else {
                // 3b. 用户已在漏斗中，检查是否命中下一个预期节点
                handleFunnelProgress(model, event, matchedStep, state);
            }
        }
    }

    /**
     * 判断事件是否匹配漏斗节点
     */
    private FunnelStep matchStep(FunnelModel model, TrackingEvent event) {
        List<FunnelStep> steps = modelCache.getSteps(model.getModelId());

        for (FunnelStep step : steps) {
            // 事件名必须匹配
            if (!step.getEventName().equals(event.getEventName())) {
                continue;
            }

            // 解析事件过滤条件
            EventFilter filter = EventFilter.parse(step.getEventFilter());
            if (filter == null) {
                return step; // 无过滤条件，事件名匹配即可
            }

            // 检查过滤条件
            if (filter.matches(event.getProperties())) {
                return step;
            }
        }
        return null;
    }

    /**
     * 处理漏斗进入
     */
    private void handleFunnelEntry(FunnelModel model, TrackingEvent event, FunnelStep firstStep) {
        // 检查转化窗口（归因规则）
        if (!shouldAttribute(model, event.getUserId())) {
            return;
        }

        // 创建漏斗实例
        UserFunnelState state = UserFunnelState.builder()
            .modelId(model.getModelId())
            .userId(event.getUserId())
            .enterTime(event.getEventTime())
            .currentStep(firstStep.getStepOrder())
            .stepTimestamps(new HashMap<>())
            .dimensionTags(extractDimensions(event))
            .build();

        state.recordStep(firstStep.getStepOrder(), event.getEventTime());

        // 写入 Redis 和 异步写入 MySQL
        stateRedis.saveState(state);
        asyncPersistSession(state);

        // 发布漏斗进入事件
        eventBus.publish(new FunnelEntryEvent(model.getModelId(), event.getUserId()));
    }

    /**
     * 处理漏斗进度推进
     */
    private void handleFunnelProgress(FunnelModel model, TrackingEvent event,
                                       FunnelStep matchedStep, UserFunnelState state) {
        int expectedStep = state.getCurrentStep() + 1;

        // 检查是否是预期的下一个节点
        if (matchedStep.getStepOrder() == expectedStep) {
            // 正常推进
            state.recordStep(matchedStep.getStepOrder(), event.getEventTime());
            state.setCurrentStep(matchedStep.getStepOrder());

            // 检查是否完成漏斗
            if (matchedStep.getStepOrder() == model.getTotalSteps()) {
                state.setCompleted(true);
                state.setCompletedTime(event.getEventTime());
                eventBus.publish(new FunnelCompletedEvent(model.getModelId(), event.getUserId()));
            }

            stateRedis.saveState(state);
            asyncUpdateSession(state);

        } else if (matchedStep.getStepOrder() <= state.getCurrentStep()) {
            // 命中了已经过的节点，忽略（用户可能重复操作）
            return;

        } else if (matchedStep.getStepOrder() > expectedStep) {
            // 跳跃推进（中间有可选节点被跳过）
            List<FunnelStep> steps = modelCache.getSteps(model.getModelId());
            for (int s = expectedStep; s < matchedStep.getStepOrder(); s++) {
                FunnelStep skipped = steps.get(s - 1);
                if (skipped.getIsRequired()) {
                    // 必须节点被跳过，说明漏斗定义与实际行为不匹配
                    log.warn("用户{}在漏斗{}中跳过了必须节点{}", 
                        event.getUserId(), model.getModelId(), skipped.getStepCode());
                    // 重置漏斗
                    stateRedis.deleteState(model.getModelId(), event.getUserId());
                    return;
                } else {
                    // 可选节点被跳过，标记为 SKIPPED
                    state.recordSkippedStep(s);
                }
            }
            // 继续推进到匹配节点
            state.recordStep(matchedStep.getStepOrder(), event.getEventTime());
            state.setCurrentStep(matchedStep.getStepOrder());
            stateRedis.saveState(state);
            asyncUpdateSession(state);
        }
    }
}
```

```java
    /**
     * 计算到当前为止的各节点停留时长（毫秒）
     */
    public Map<Integer, Long> calculateDwellTimes() {
        Map<Integer, Long> dwellTimes = new LinkedHashMap<>();
        List<Integer> orderedSteps = stepTimestamps.keySet().stream()
            .sorted().collect(Collectors.toList());

        for (int i = 0; i < orderedSteps.size() - 1; i++) {
            int current = orderedSteps.get(i);
            int next = orderedSteps.get(i + 1);
            long dwell = Duration.between(
                stepTimestamps.get(current),
                stepTimestamps.get(next)
            ).toMillis();
            dwellTimes.put(current, dwell);
        }

        // 最后一个节点如果有完成时间，用完成时间算；否则用当前时间
        if (!orderedSteps.isEmpty()) {
            int lastStep = orderedSteps.get(orderedSteps.size() - 1);
            LocalDateTime endTime = completed ? completedTime : LocalDateTime.now();
            dwellTimes.put(lastStep, Duration.between(stepTimestamps.get(lastStep), endTime).toMillis());
        }

        return dwellTimes;
    }
}
```

```sql
-- Spark SQL: 每小时计算漏斗各节点的 UV 和转化率
-- 输入表: funnel_user_session (MySQL/ClickHouse)
-- 输出表: funnel_snapshot

WITH funnel_sessions AS (
    SELECT
        model_id,
        user_id,
        enter_time,
        current_step,
        completed,
        exit_step,
        dimension_tags,
        step_details
    FROM funnel_user_session
    WHERE enter_time >= '${etl_start_time}'
      AND enter_time < '${etl_end_time}'
),
-- 展开每个用户在每个节点的到达情况
step_reach AS (
    SELECT
        s.model_id,
        s.user_id,
        step.step_order,
        -- 是否到达该节点
        CASE 
            WHEN step.step_order <= s.current_step THEN 1
            ELSE 0
        END AS reached,
        -- 是否通过该节点（到达了下一节点或完成）
        CASE
            WHEN step.step_order < s.current_step THEN 1
            WHEN step.step_order = s.current_step AND s.completed = 1 THEN 1
            ELSE 0
        END AS passed,
        -- 该节点停留时长
        CAST(JSON_UNPACK(step_details, CONCAT('$.steps[', step.step_order - 1, '].dwell_ms')) AS BIGINT) AS dwell_ms,
        s.dimension_tags
    FROM funnel_sessions s
    -- 与漏斗定义做笛卡尔积展开节点
    JOIN (
        SELECT model_id, step_order FROM funnel_step WHERE is_required = 1
    ) step ON s.model_id = step.model_id
    WHERE step.step_order <= s.current_step + 1
)
SELECT
    fs.model_id,
    CAST('${snapshot_date}' AS DATE) AS snapshot_date,
    CAST('${snapshot_hour}' AS INT) AS snapshot_hour,
    'OVERALL' AS dimension_type,
    'ALL' AS dimension_value,
    sr.step_order,
    COUNT(DISTINCT CASE WHEN sr.reached = 1 THEN sr.user_id END) AS uv_enter,
    COUNT(DISTINCT CASE WHEN sr.passed = 1 THEN sr.user_id END) AS uv_pass,
    CAST(
        COUNT(DISTINCT CASE WHEN sr.passed = 1 THEN sr.user_id END) AS DOUBLE
        / NULLIF(COUNT(DISTINCT CASE WHEN sr.reached = 1 THEN sr.user_id END), 0)
    AS DECIMAL(8,4)) AS conversion_rate,
    -- 累计转化率在应用层计算（需要第一个节点的uv_enter）
    AVG(sr.dwell_ms) AS avg_dwell_ms,
    APPROX_PERCENTILE(sr.dwell_ms, 0.5) AS median_dwell_ms,
    APPROX_PERCENTILE(sr.dwell_ms, 0.9) AS p90_dwell_ms
FROM step_reach sr
GROUP BY fs.model_id, sr.step_order;
```

```java
/**
 * 多维度漏斗聚合计算
 * 支持：年级、学科、平台(iOS/Android)、用户标签、城市等维度
 */
public class FunnelDimensionAggregator {

    // 维度提取器注册表
    private final Map<String, DimensionExtractor> extractors = new HashMap<>();

    public FunnelDimensionAggregator() {
        registerExtractor("GRADE", new GradeDimensionExtractor());
        registerExtractor("SUBJECT", new SubjectDimensionExtractor());
        registerExtractor("PLATFORM", new PlatformDimensionExtractor());
        registerExtractor("USER_TAG", new UserTagDimensionExtractor());
        registerExtractor("CITY", new CityDimensionExtractor());
        registerExtractor("MEMBERSHIP", new MembershipDimensionExtractor());
    }

    /**
     * 为指定维度生成快照
     */
    public void aggregateForDimension(
            String dimensionType,
            LocalDate snapshotDate,
            Integer snapshotHour,
            List<Long> modelIds) {

        DimensionExtractor extractor = extractors.get(dimensionType);
        if (extractor == null) {
            throw new IllegalArgumentException("不支持的维度类型: " + dimensionType);
        }

        for (Long modelId : modelIds) {
            // 从 ClickHouse 查询明细
            List<FunnelUserSession> sessions = sessionRepository
                .findByModelAndTimeRange(modelId, snapshotDate, snapshotHour);

            // 按维度值分组
            Map<String, List<FunnelUserSession>> grouped = sessions.stream()
                .collect(Collectors.groupingBy(
                    s -> extractor.extract(s.getDimensionTags())
                ));

            // 对每个维度值计算漏斗快照
            for (Map.Entry<String, List<FunnelUserSession>> entry : grouped.entrySet()) {
                String dimensionValue = entry.getKey();
                List<FunnelUserSession> groupSessions = entry.getValue();

                List<FunnelSnapshot> snapshots = computeSnapshots(
                    modelId, snapshotDate, snapshotHour,
                    dimensionType, dimensionValue, groupSessions
                );

                // 批量写入
                snapshotRepository.batchUpsert(snapshots);
            }
        }
    }

    private List<FunnelSnapshot> computeSnapshots(
            Long modelId, LocalDate date, Integer hour,
            String dimType, String dimValue,
            List<FunnelUserSession> sessions) {

        int totalSteps = modelCache.getTotalSteps(modelId);
        List<FunnelSnapshot> results = new ArrayList<>();

        // 漏斗起点 UV
        long funnelEnterUv = sessions.stream()
            .filter(s -> s.getCurrentStep() >= 1)
            .mapToLong(FunnelUserSession::getUserId)
            .distinct().count();

        for (int step = 1; step <= totalSteps; step++) {
            final int stepOrder = step;

            long uvEnter = sessions.stream()
                .filter(s -> s.getCurrentStep() >= stepOrder)
                .mapToLong(FunnelUserSession::getUserId)
                .distinct().count();

            long uvPass = sessions.stream()
                .filter(s -> s.getCurrentStep() > stepOrder 
                          || (s.getCurrentStep() == stepOrder && s.isCompleted()))
                .mapToLong(FunnelUserSession::getUserId)
                .distinct().count();

            // 停留时长统计
            List<Long> dwellTimes = sessions.stream()
                .filter(s -> s.getCurrentStep() >= stepOrder)
                .map(s -> s.getDwellTimeMs(stepOrder))
                .filter(Objects::nonNull)
                .collect(Collectors.toList());

            FunnelSnapshot snapshot = FunnelSnapshot.builder()
                .modelId(modelId)
                .snapshotDate(date)
                .snapshotHour(hour)
                .dimensionType(dimType)
                .dimensionValue(dimValue)
                .stepOrder(stepOrder)
                .uvEnter(uvEnter)
                .uvPass(uvPass)
                .conversionRate(uvEnter > 0 ? (double) uvPass / uvEnter : 0)
                .cumulativeRate(funnelEnterUv > 0 ? (double) uvPass / funnelEnterUv : 0)
                .avgDwellMs(calculateAverage(dwellTimes))
                .medianDwellMs(calculatePercentile(dwellTimes, 50))
                .p90DwellMs(calculatePercentile(dwellTimes, 90))
                .build();

            results.add(snapshot);
        }

        return results;
    }
}
```

### 7.1 瓶颈检测算法

```java
/**
 * 瓶颈检测引擎
 * 基于多维度规则自动识别漏斗中的瓶颈节点
 */
@Component
public class BottleneckDetector {

    @Autowired
    private FunnelSnapshotRepository snapshotRepository;

    @Autowired
    private FunnelModelCache modelCache;

    @Autowired
    private BottleneckConfigRepository configRepository;

    // 每日定时执行
    @Scheduled(cron = "0 0 3 * * *")
    public void dailyBottleneckDetection() {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        List<FunnelModel> activeModels = modelCache.getAllActiveModels();

        for (FunnelModel model : activeModels) {
            detectBottlenecksForModel(model.getModelId(), yesterday);
        }
    }

    public void detectBottlenecksForModel(Long modelId, LocalDate date) {
        // 获取当日 OVERALL 维度的快照
        List<FunnelSnapshot> snapshots = snapshotRepository
            .findOverallSnapshots(modelId, date);

        if (snapshots.isEmpty()) return;

        // 获取配置
        BottleneckConfig config = configRepository.findByModelId(modelId)
            .orElse(BottleneckConfig.defaultConfig());

        // 获取历史基线
        List<FunnelSnapshot> historical = snapshotRepository
            .findHistorySnapshots(modelId, date.minusDays(30), date.minusDays(1));

        List<BottleneckDiagnosisReport> reports = new ArrayList<>();

        for (FunnelSnapshot snapshot : snapshots) {
            List<String> reasons = new ArrayList<>();
            double convRate = snapshot.getConversionRate().doubleValue();
            SeverityLevel severity = SeverityLevel.INFO;

            // 规则1: 绝对转化率低
            if (convRate < config.getAbsoluteThreshold()) {
                reasons.add("ABSOLUTE_LOW");
                severity = severity.max(SeverityLevel.WARNING);
            }

            // 规则2: 相对下降大
            if (snapshot.getStepOrder() > 1) {
                FunnelSnapshot prevStep = snapshots.stream()
                    .filter(s -> s.getStepOrder() == snapshot.getStepOrder() - 1)
                    .findFirst().orElse(null);

                if (prevStep != null) {
                    double prevConvRate = prevStep.getConversionRate().doubleValue();
                    double dropRate = (prevConvRate - convRate) / prevConvRate;

                    if (dropRate > config.getRelativeDropThreshold()) {
                        reasons.add("RELATIVE_DROP");
                        severity = severity.max(SeverityLevel.WARNING);
                    }
                }
            }

            // 规则3: 历史偏离
            if (!historical.isEmpty()) {
                Stats stats = calculateHistoricalStats(historical, snapshot.getStepOrder());
                double sigmaDeviation = Math.abs(convRate - stats.mean) / stats.stddev;

                if (sigmaDeviation > 2.0 && convRate < stats.mean) {
                    reasons.add("HISTORICAL_DEVIATION");
                    severity = severity.max(SeverityLevel.CRITICAL);
                }

                // 规则4: 停留时间异常
                if (snapshot.getAvgDwellMs() != null) {
                    Stats dwellStats = calculateDwellStats(historical, snapshot.getStepOrder());
                    double dwellSigma = (snapshot.getAvgDwellMs() - dwellStats.mean) 
                        / Math.max(dwellStats.stddev, 1);
                    
                    if (dwellSigma > 2.0 && snapshot.getAvgDwellMs() > dwellStats.mean) {
                        reasons.add("DWELL_TIME_ANOMALY");
                        severity = severity.max(SeverityLevel.WARNING);
                    }
                }
            }

            // 标记瓶颈
            snapshot.setIsBottleneck(reasons.isEmpty() ? 0 : 1);
            snapshot.setBottleneckReasons(reasons.isEmpty() ? null : JsonUtil.toJson(reasons));
            snapshotRepository.update(snapshot);

            // 生成诊断报告
            if (!reasons.isEmpty()) {
                BottleneckDiagnosisReport report = generateDiagnosisReport(
                    modelId, snapshot, reasons, severity, historical, date
                );
                reports.add(report);
            }
        }

        // 批量保存报告
        if (!reports.isEmpty()) {
            reportRepository.batchSave(reports);
            // 发送告警
            alertService.sendBottleneckAlerts(reports);
        }
    }

    /**
     * 计算历史统计基线
     */
    private Stats calculateHistoricalStats(List<FunnelSnapshot> historical, int stepOrder) {
        List<Double> rates = historical.stream()
            .filter(s -> s.getStepOrder() == stepOrder)
            .map(s -> s.getConversionRate().doubleValue())
            .collect(Collectors.toList());

        double mean = rates.stream().mapToDouble(d -> d).average().orElse(0);
        double variance = rates.stream()
            .mapToDouble(d -> Math.pow(d - mean, 2))
            .average().orElse(0);
        double stddev = Math.sqrt(variance);

        return new Stats(mean, stddev);
    }

    private record Stats(double mean, double stddev) {}
}
```

### 7.2 瓶颈根因分析

```java
/**
 * 瓶颈根因分析器
 * 对瓶颈节点进行多维下钻，生成根因假设
 */
@Component
public class BottleneckRootCauseAnalyzer {

    /**
     * 对瓶颈节点进行根因分析
     */
    public RootCauseAnalysis analyze(Long modelId, int stepOrder, LocalDate date) {
        RootCauseAnalysis analysis = new RootCauseAnalysis(modelId, stepOrder, date);

        // 1. 维度差异分析：哪个群体转化率最差？
        Map<String, Map<String, Double>> dimensionGaps = analyzeDimensionGaps(
            modelId, stepOrder, date
        );
        analysis.setDimensionGaps(dimensionGaps);

        // 2. 行为模式分析：流失用户 vs 转化用户的行为差异
        BehaviorPatternDiff behaviorDiff = analyzeBehaviorDiff(
            modelId, stepOrder, date
        );
        analysis.setBehaviorDiff(behaviorDiff);

        // 3. 技术因素排查：是否有技术问题导致流失
        TechnicalFactorCheck techCheck = checkTechnicalFactors(
            modelId, stepOrder, date
        );
        analysis.setTechFactors(techCheck);

        // 4. 生成根因假设
        List<RootCauseHypothesis> hypotheses = generateHypotheses(analysis);
        analysis.setHypotheses(hypotheses);

        // 5. 生成优化建议
        List<OptimizationRecommendation> recommendations = generateRecommendations(hypotheses);
        analysis.setRecommendations(recommendations);

        return analysis;
    }

    /**
     * 维度差异分析
     * 找出转化率最低的群体特征
     */
    private Map<String, Map<String, Double>> analyzeDimensionGaps(
            Long modelId, int stepOrder, LocalDate date) {

        Map<String, Map<String, Double>> result = new HashMap<>();
        String[] dimensions = {"GRADE", "PLATFORM", "MEMBERSHIP", "USER_TAG"};

        for (String dim : dimensions) {
            List<FunnelSnapshot> dimSnapshots = snapshotRepository
                .findByModelDateStepDimension(modelId, date, stepOrder, dim);

            if (dimSnapshots.size() < 2) continue;

            // 计算各维度值的转化率，找差异最大的
            Map<String, Double> convRates = dimSnapshots.stream()
                .collect(Collectors.toMap(
                    FunnelSnapshot::getDimensionValue,
                    s -> s.getConversionRate().doubleValue()
                ));

            // 过滤掉样本量太小的维度值
            convRates = filterLowSample(dimSnapshots, convRates, 50);

            if (convRates.size() >= 2) {
                double max = Collections.max(convRates.values());
                double min = Collections.min(convRates.values());
                double gap = max - min;

                // 如果差异超过 15%，标记为显著维度
                if (gap > 0.15) {
                    result.put(dim, convRates);
                }
            }
        }

        return result;
    }

    /**
     * 行为模式差异分析
     * 对比流失用户和转化用户在瓶颈前后的行为
     */
    private BehaviorPatternDiff analyzeBehaviorDiff(
            Long modelId, int stepOrder, LocalDate date) {

        // 获取在该节点流失的用户
        List<Long> lostUserIds = sessionRepository
            .findLostUsers(modelId, stepOrder, date, 1000);

        // 获取通过该节点的用户
        List<Long> passedUserIds = sessionRepository
            .findPassedUsers(modelId, stepOrder, date, 1000);

        BehaviorPatternDiff diff = new BehaviorPatternDiff();

        // 对比流失用户与转化用户的行为特征
        diff.setAvgPreviousDwellMs(
            calculateAvgPreviousDwell(lostUserIds, modelId, stepOrder),
            calculateAvgPreviousDwell(passedUserIds, modelId, stepOrder)
        );

        diff.setAvgSessionDuration(
            calculateAvgSessionDuration(lostUserIds),
            calculateAvgSessionDuration(passedUserIds)
        );

        diff.setRetryRate(
            calculateRetryRate(lostUserIds, modelId),
            calculateRetryRate(passedUserIds, modelId)
        );

        diff.setCommonExitPages(
            findCommonExitPages(lostUserIds),
            findCommonExitPages(passedUserIds)
        );

        diff.setPreviousFunnelStepDwell(
            analyzePreviousStepDwellDistribution(lostUserIds, modelId, stepOrder),
            analyzePreviousStepDwellDistribution(passedUserIds, modelId, stepOrder)
        );

        return diff;
    }

    /**
     * 生成根因假设
     */
    private List<RootCauseHypothesis> generateHypotheses(RootCauseAnalysis analysis) {
        List<RootCauseHypothesis> hypotheses = new ArrayList<>();

        BehaviorPatternDiff diff = analysis.getBehaviorDiff();
        Map<String, Map<String, Double>> dimGaps = analysis.getDimensionGaps();
        TechnicalFactorCheck techCheck = analysis.getTechFactors();

        // 假设模式库
        if (diff != null && diff.getRetryRateLost() > diff.getRetryRatePassed() * 2) {
            hypotheses.add(RootCauseHypothesis.builder()
                .hypothesis("用户在瓶颈节点遇到困难后频繁重试，可能是交互设计不清晰或功能入口隐蔽")
                .confidence(0.7)
                .category("UX_DESIGN")
                .supportingData(Map.of(
                    "lost_retry_rate", diff.getRetryRateLost(),
                    "passed_retry_rate", diff.getRetryRatePassed()
                ))
                .build());
        }

        if (diff != null && diff.getAvgPreviousDwellLost() > diff.getAvgPreviousDwellPassed() * 1.5) {
            hypotheses.add(RootCauseHypothesis.builder()
                .hypothesis("流失用户在上一步停留时间过长，可能对上一步内容理解不充分，导致无法推进到下一步")
                .confidence(0.6)
                .category("CONTENT_DIFFICULTY")
                .supportingData(Map.of(
                    "lost_prev_dwell_ms", diff.getAvgPreviousDwellLost(),
                    "passed_prev_dwell_ms", diff.getAvgPreviousDwellPassed()
                ))
                .build());
        }

        if (dimGaps.containsKey("PLATFORM")) {
            Map<String, Double> platformGaps = dimGaps.get("PLATFORM");
            if (platformGaps.containsKey("ANDROID") && platformGaps.containsKey("IOS")) {
                double androidRate = platformGaps.get("ANDROID");
                double iosRate = platformGaps.get("IOS");
                if (androidRate < iosRate * 0.7) {
                    hypotheses.add(RootCauseHypothesis.builder()
                        .hypothesis("Android 用户转化率显著低于 iOS，可能存在 Android 端兼容性问题或性能瓶颈")
                        .confidence(0.8)
                        .category("TECHNICAL_COMPATIBILITY")
                        .supportingData(Map.of(
                            "android_rate", androidRate,
                            "ios_rate", iosRate
                        ))
                        .build());
                }
            }
        }

        if (dimGaps.containsKey("GRADE")) {
            hypotheses.add(RootCauseHypothesis.builder()
                .hypothesis("不同年级段转化率差异显著，可能是内容难度对各年级适配度不均匀")
                .confidence(0.65)
                .category("CONTENT_ADAPTATION")
                .supportingData(dimGaps.get("GRADE"))
                .build());
        }

        if (techCheck != null && techCheck.hasElevatedErrorRate()) {
            hypotheses.add(RootCauseHypothesis.builder()
                .hypothesis("瓶颈时段接口错误率升高，可能存在服务端不稳定导致用户流失")
                .confidence(0.85)
                .category("SYSTEM_STABILITY")
                .supportingData(Map.of(
                    "error_rate", techCheck.getErrorRate(),
                    "normal_error_rate", techCheck.getNormalErrorRate()
                ))
                .build());
        }

        if (techCheck != null && techCheck.hasElevatedLatency()) {
            hypotheses.add(RootCauseHypothesis.builder()
                .hypothesis("瓶颈节点关联接口响应时间偏高，用户可能因等待时间过长而放弃")
                .confidence(0.75)
                .category("PERFORMANCE")
                .supportingData(Map.of(
                    "p95_latency_ms", techCheck.getP95LatencyMs(),
                    "normal_p95_ms", techCheck.getNormalP95Ms()
                ))
                .build());
        }

        // 按置信度排序
        hypotheses.sort((a, b) -> Double.compare(b.getConfidence(), a.getConfidence()));

        return hypotheses;
    }

    /**
     * 生成优化建议
     */
```

## 10. 错误处理与容灾

### 10.1 错误码定义

| 错误码 | HTTP状态码 | 说明 | 处理方式 |
|-------|-----------|------|---------|
| FUNNEL_001 | 400 | 漏斗模型编码已存在 | 返回错误，提示使用不同编码 |
| FUNNEL_002 | 400 | 漏斗节点事件名为空 | 返回错误，要求填写事件名 |
| FUNNEL_003 | 400 | 漏斗节点顺序不连续 | 返回错误，要求检查 step_order |
| FUNNEL_004 | 404 | 漏斗模型不存在 | 返回 404 |
| FUNNEL_005 | 400 | event_filter JSON 格式错误 | 返回错误，提示 JSON 格式问题 |
| FUNNEL_006 | 403 | 无权限操作该漏斗模型 | 返回 403 |
| FUNNEL_007 | 422 | 转化窗口超出最大值(30天) | 返回错误，提示窗口上限 |
| FUNNEL_008 | 500 | 快照计算异常 | 记录日志，返回 500，自动重试 |
| FUNNEL_009 | 503 | ClickHouse 查询超时 | 降级返回缓存数据，异步重试 |
| FUNNEL_010 | 500 | Redis 状态写入失败 | 降级跳过实时更新，依赖离线补数 |

### 10.2 容灾策略

```java
/**
 * 漏斗查询服务容灾策略
 */
@Component
public class FunnelQueryServiceFallback {

    @Autowired
    private FunnelSnapshotCacheService cacheService;

    /**
     * 查询漏斗快照 - 带降级策略
     */
    @Retryable(maxAttempts = 3, backoff = @Backoff(delay = 500))
    public FunnelSnapshotResponse querySnapshot(Long modelId, LocalDate date, String dimType) {
        try {
            // 正常查询 ClickHouse
            return snapshotRepository.query(modelId, date, dimType);

        } catch (QueryTimeoutException e) {
            log.warn("ClickHouse 查询超时，降级到缓存 modelId={} date={}", modelId, date);

            // 降级1: 查询 Redis 缓存
            FunnelSnapshotResponse cached = cacheService.getCache(modelId, date, dimType);
            if (cached != null) {
                cached.setFromCache(true);
                cached.setCacheWarning("数据来源为缓存，可能存在延迟");
                return cached;
            }

            // 降级2: 查询最近一天的数据
            LocalDate fallbackDate = date.minusDays(1);
            FunnelSnapshotResponse fallback = snapshotRepository.query(modelId, fallbackDate, dimType);
            if (fallback != null) {
                fallback.setFromCache(true);
                fallback.setCacheWarning("使用 " + fallbackDate + " 的数据作为降级");
            }
            return fallback;
        }
    }

    /**
     * 实时事件处理容灾
     */
    public void handleEventWithFallback(TrackingEvent event) {
        try {
            funnelEventMatcher.processEvent(event);

        } catch (RedisConnectionFailureException e) {
            // Redis 不可用时，将事件写入 Kafka 重试队列
            log.error("Redis 连接失败，事件写入重试队列 userId={} eventName={}",
                event.getUserId(), event.getEventName());
            retryQueueProducer.send(event);

        } catch (Exception e) {
            log.error("漏斗事件处理异常 userId={} eventName={}",
                event.getUserId(), event.getEventName(), e);
            // 不影响主流程，吞掉异常
        }
    }
}
```

### 10.3 数据一致性保障

```
数据流向:
  实时: 事件 → Kafka → EventConsumer → Redis状态 → (异步)MySQL session
  离线: 事件明细 → ClickHouse → 快照预计算 → MySQL snapshot

一致性保障:
  1. 每日 04:00 执行数据对账任务，比对 Redis 活跃状态与 MySQL session
  2. 每日 04:30 执行漏斗实例修正，以 ClickHouse 事件明细为准修正 MySQL session
  3. 快照基于修正后的 session 重新计算（如偏差 > 1%）
  4. 对账结果写入 funnel_reconciliation_log 表

对账脚本伪代码:
  for each active model:
    redis_states = redis.getAllStates(model_id)
    mysql_sessions = mysql.findActiveSessions(model_id)
    
    for each redis_state:
        mysql_session = mysql_sessions.find(redis_state.user_id)
        if mysql_session == null:
            mysql.insert(from redis_state)  // Redis有MySQL无 → 补写
        elif mysql_session.currentStep != redis_state.currentStep:
            log.warn("状态不一致 userId={} redis={} mysql={}")
            // 以 MySQL session 为准（因为 MySQL 有更完整的事件时间戳）
    
    for each mysql_session not in redis_states:
        if mysql_session.isRecentlyActive(< 7 days):
            redis.rebuild(mysql_session)  // MySQL有Redis无 → 重建
```

| 用户明细查询 | MySQL session | 分页 + 索引 | < 500ms |
| 趋势分析 | ClickHouse | 时间分区 + 预计算 | < 2s |

### 11.2 事件处理性能

```
吞吐量目标:
  - 峰值事件处理: 50000 events/s
  - 漏斗匹配率（需要匹配的事件占比）: 约 30-40%
  - 实际漏斗处理: ~20000 events/s

优化手段:
  1. Kafka 消费者分区并行（按 user_id hash 分区，保证同用户顺序）
  2. 漏斗模型缓存全量加载到本地内存（Caffeine），避免每次查 DB
  3. Redis Pipeline 批量操作（攒批 100 条更新一次）
  4. event_filter 条件编译为 Predicate 对象，避免每次解析 JSON
  5. 用户状态查询走 Redis 本地缓存（Caffeine 5秒过期）
```

```java
/**
 * 瓶颈告警通知
 */
@Component
public class BottleneckAlertService {

    @Autowired
    private MessageService messageService;

    public void sendBottleneckAlerts(List<BottleneckDiagnosisReport> reports) {
        List<BottleneckDiagnosisReport> critical = reports.stream()
            .filter(r -> r.getSeverityLevel().equals("CRITICAL"))
            .collect(Collectors.toList());

        if (!critical.isEmpty()) {
            // CRITICAL 级别：发送即时通知给产品负责人
            for (BottleneckDiagnosisReport report : critical) {
                messageService.sendDingTalk(
                    config.getProductTeamWebhook(),
                    String.format(
                        "🔴 漏斗瓶颈告警\n模型: %s\n节点: %s（第%d步）\n转化率: %.2f%% (历史均值: %.2f%%)\n流失用户: %d\n建议: %s",
                        report.getModelName(),
                        report.getStepName(),
                        report.getStepOrder(),
                        report.getConversionRate() * 100,
                        report.getHistoricalAvg() * 100,
                        report.getLostUserCount(),
                        report.getRecommendations().stream()
                            .map(OptimizationRecommendation::getTitle)
                            .collect(Collectors.joining("; "))
                    )
                );
            }
        }

        // WARNING 级别：汇总后每天发一次
        List<BottleneckDiagnosisReport> warning = reports.stream()
            .filter(r -> r.getSeverityLevel().equals("WARNING"))
            .collect(Collectors.toList());

        if (!warning.isEmpty()) {
            dailyWarningAccumulator.addAll(warning);
        }
    }

    @Scheduled(cron = "0 0 10 * * *")
    public void sendDailyWarningSummary() {
        if (dailyWarningAccumulator.isEmpty()) return;
        
        String summary = formatDailySummary(dailyWarningAccumulator);
        messageService.sendDingTalk(config.getProductTeamWebhook(), summary);
        dailyWarningAccumulator.clear();
    }
}
```

```java
     * 对比实验组的漏斗表现
     */
    public ExperimentComparison compareGroups(Long modelId, String experimentId, LocalDate date) {
        // 查询实验分组信息
        ExperimentConfig experiment = experimentPlatformClient.getExperiment(experimentId);

        // 分别查询各组的漏斗快照
        FunnelSnapshotResponse control = snapshotRepository
            .queryWithExperimentGroup(modelId, date, experiment.getControlKey());
        
        FunnelSnapshotResponse treatment = snapshotRepository
            .queryWithExperimentGroup(modelId, date, experiment.getTreatmentKey());

        // 计算提升
        return ExperimentComparison.builder()
            .controlGroup(control)
            .treatmentGroup(treatment)
            .uplift(calculateUplift(control, treatment))
            .significance(calculateSignificance(control, treatment))
            .build();
    }
```

## 18. 附录

### 18.1 埋点事件规范要求

本引擎依赖统一埋点平台的标准事件。关键要求：

1. 每个埋点事件必须包含 `user_id`、`event_name`、`event_time`、`properties`
2. `properties` 中应包含页面标识、操作对象、来源等上下文信息
3. 事件需在 5 分钟内到达 Kafka（超出视为延迟事件，可能影响实时漏斗准确性）
4. 同一用户的事件需按 `event_time` 有序到达（通过 Kafka 分区保证）

### 18.2 名词解释

| 术语 | 说明 |
|------|------|
| UV (Unique Visitor) | 独立用户数 |
| 转化率 | 通过某节点的用户数 / 进入该节点的用户数 |
| 累计转化率 | 通过某节点的用户数 / 进入漏斗起点的用户数 |
| 停留时长 (Dwell Time) | 用户在两个相邻节点之间的时间差 |
| 瓶颈节点 | 转化率显著低于预期或历史均值的漏斗节点 |
| 归因 | 确定用户进入漏斗的那次行为计入统计 |
| 转化窗口 | 用户从进入漏斗到完成的最大允许时间 |
