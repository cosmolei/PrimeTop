# 服务端-学生用户学习困难模式智能识别与特殊学习需求个性化支持引擎

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 教育平台面向**包容性教育（Inclusive Education）**的核心服务模块，负责通过学生长期学习行为数据的综合分析，智能识别潜在的特定学习困难模式（如阅读障碍倾向、注意力相关困难、工作记忆薄弱、信息处理速度偏慢等），并据此为不同认知特征的学生提供**个性化的学习内容适配与辅助策略**。

> **重要声明**：本系统**不做医学诊断**。所有识别结果均为"学习特征倾向性提示"，用于教育辅助内容适配和家长参考建议。系统会在检测到高风险模式时，建议家长咨询专业教育心理评估机构。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 早期感知 | 通过日常学习行为数据无感化采集认知特征信号，不增加额外测试负担 |
| 个性化适配 | 根据认知特征自动调整内容呈现方式、交互节奏、难度梯度 |
| 家校协同 | 为家长提供可理解的观察报告和建议，而非冰冷的诊断标签 |
| 隐私保护 | 敏感学习特征数据严格加密，仅用于教育适配，不做他用 |
| 安全合规 | 严格遵守未成年人数据保护法规，所有分析需家长知情同意 |

### 1.3 适用范围

- **学段**：小学至高中（幼儿阶段不纳入分析，仅做正向激励适配）
- **触发条件**：学生在平台累计学习行为数据 ≥ 30 天，且家长已开启"智能学习支持"功能
- **覆盖场景**：文字阅读、答题交互、语音输入、手写识别、AI 对话、学习计划执行

## 2. 学习困难模式分类体系

### 2.1 支持识别的学习困难倾向类型

```text
LearningDifficultyType (枚举)
├── READING_DIFFICULTY          // 阅读困难倾向（如阅读障碍特征）
├── ATTENTION_DIFFICULTY        // 注意力相关困难（如注意力不集中特征）
├── WORKING_MEMORY_WEAK         // 工作记忆薄弱
├── PROCESSING_SPEED_SLOW       // 信息处理速度偏慢
├── VISUAL_SPATIAL_DIFFICULTY   // 视觉空间认知困难
├── MATHEMATICAL_DIFFICULTY     // 数学学习困难（如计算障碍特征）
├── WRITING_DIFFICULTY          // 书面表达困难
├── EXECUTIVE_FUNCTION_WEAK     // 执行功能薄弱（计划/组织/自我监控）
└── NO_SIGNIFICANT_DIFFICULTY   // 未检测到明显困难模式
```

### 2.2 各类型行为信号定义

#### 2.2.1 阅读困难倾向（READING_DIFFICULTY）

| 信号维度 | 观测指标 | 判定逻辑 |
| --- | --- | --- |
| 阅读速度 | 知识点阅读页停留时长 vs 同年级均值 | 中位停留时长 > 年级P75且阅读完成率 < 60% |
| 文字跳读模式 | 阅读滚动行为（跳跃式 vs 线性） | 高频不规则跳跃 + 回看比例 > 40% |
| 朗读错误率 | 语音朗读评估错误率（漏字/换字/停顿异常） | 连续3次评估错误率 > 同年级P90 |
| 文字题理解 | 文科背诵/阅读理解题"未读完即答题"比例 | 比例 > 50% 且正确率 < 40% |
| 拼写错误 | 作文/答题中同音字混淆、形近字错误频率 | 错误率 > 同年级P90且非偶然性错误 |

#### 2.2.2 注意力相关困难（ATTENTION_DIFFICULTY）

| 信号维度 | 观测指标 | 判定逻辑 |
| --- | --- | --- |
| 会话中断频率 | 学习会话中切出App/切换模块频率 | 同年级P90且平均专注时长 < 5min |
| 答题急促性 | 题目展示到首答间隔 vs 题目阅读所需时长 | 间隔 < 预估阅读时间30%且正确率 < 50% |
| 未完成率 | 开始做题后中途放弃比例 | 放弃率 > 30%（控制难度变量后） |
| 指令跟随 | 多步指令题中漏做步骤的比例 | 漏步率 > 40% |
| 重复提问 | AI对话中重复问同一类问题的频率 | 同主题重复率 > 同年级P90 |

#### 2.2.3 工作记忆薄弱（WORKING_MEMORY_WEAK）

| 信号维度 | 观测指标 | 判定逻辑 |
| --- | --- | --- |
| 多步题错误模式 | 前几步正确但后续步骤遗忘前提条件 | "前提遗忘"类错误 > 35% |
| 序列记忆 | 听写/默写中序列顺序错误 | 顺序错误率 > 同年级P85 |
| 指令保持 | 拍照搜题解析后复述关键步骤的准确度 | 关键步骤遗漏 > 50% |
| 长文信息提取 | 阅读理解中远距离信息关联错误 | 远距关联题正确率 < 30% |

#### 2.2.4 信息处理速度偏慢（PROCESSING_SPEED_SLOW）

| 信号维度 | 观测指标 | 判定逻辑 |
| --- | --- | --- |
| 答题响应时 | 排除知识不熟因素后的纯处理时长 | 校正后处理时长 > 同年级P90 |
| 任务切换耗时 | 从一个题型/学科切换到另一个的适应时间 | 适应耗时 > 同年级P90 |
| 批量完成率 | 限定时间内练习题完成数量 | 完成量 < 同年级P15 |

#### 2.2.5 执行功能薄弱（EXECUTIVE_FUNCTION_WEAK）

| 信号维度 | 观测指标 | 判定逻辑 |
| --- | --- | --- |
| 计划执行偏差 | 学习计划完成率 vs 自设目标 | 连续2周完成率 < 40% |
| 任务优先级 | 倾向先做简单题/回避复杂题的模式 | 回避指数 > 同年级P85 |
| 时间估算偏差 | 预估任务耗时 vs 实际耗时偏差 | 系统性低估 > 50% |
| 错误监控 | 重复犯同类错误的频率 | 同类错误重复率 > 60% |

## 5. 核心算法设计

### 5.1 信号归一化与百分位计算

```python
import numpy as np
from typing import Dict, Optional

class SignalNormalizer:
    """行为信号归一化处理器：将原始行为数据转换为同年级百分位"""
    
    def __init__(self, norm_repository: 'GradeNormRepository'):
        self.norm_repo = norm_repository
    
    def normalize(
        self,
        student_id: int,
        signal_type: str,
        raw_value: float,
        grade_level: str,
        subject: Optional[str] = None,
        context: Optional[Dict] = None
    ) -> 'NormalizedSignal':
        """
        将原始信号值归一化为同年级同年级百分位
        """
        # 获取同年级基线分布参数
        baseline = self.norm_repo.get_baseline(
            signal_type=signal_type,
            grade_level=grade_level,
            subject=subject
        )
        
        if baseline is None:
            # 基线数据不足，标记为低置信度
            return NormalizedSignal(
                raw_value=raw_value,
                percentile_rank=None,
                z_score=None,
                confidence=0.3,
                insufficient_baseline=True
            )
        
        # 计算Z分数（使用稳健统计：中位数和MAD）
        median = baseline.robust_median
        mad = baseline.robust_mad  # Median Absolute Deviation
        
        if mad > 0:
            # 使用稳健Z分数，抗异常值干扰
            robust_z = 0.6745 * (raw_value - median) / mad
        else:
            robust_z = 0.0
        
        # 转换为百分位
        percentile = self._z_to_percentile(robust_z)
        
        # 上下文修正：考虑题目难度、时段等混淆变量
        if context:
            percentile = self._context_adjust(percentile, context, baseline)
        
        return NormalizedSignal(
            raw_value=raw_value,
            percentile_rank=percentile,
            z_score=round(robust_z, 3),
            confidence=baseline.sample_adequacy_score,
            insufficient_baseline=False
        )
    
    def _z_to_percentile(self, z: float) -> float:
        """标准正态分布Z值转百分位"""
        from scipy.stats import norm
        return round(float(norm.cdf(z) * 100), 2)
    
    def _context_adjust(
        self,
        percentile: float,
        context: Dict,
        baseline: 'GradeBaseline'
    ) -> float:
        """上下文修正：控制题目难度、时段等混淆变量"""
        adjusted = percentile
        
        # 题目难度修正：如果学生在做高于其水平的题目，适当上调百分位
        if 'item_difficulty' in context:
            diff_ratio = context['item_difficulty'] / baseline.avg_difficulty
            if diff_ratio > 1.2:
                adjusted = min(100, percentile * 1.1)
            elif diff_ratio < 0.8:
                adjusted = max(0, percentile * 0.9)
        
        # 时段修正：晚间时段注意力自然下降
        if 'time_of_day' in context:
            hour = context['time_of_day']
            if hour >= 21 or hour <= 6:
                adjusted = min(100, adjusted * 1.05)  # 给5%宽裕
        
        return round(adjusted, 2)
```

### 5.2 困难模式综合检测算法

```python
from dataclasses import dataclass
from typing import List, Dict, Optional
from enum import Enum
import numpy as np

class RiskLevel(Enum):
    MINIMAL = "MINIMAL"
    LOW = "LOW"
    MODERATE = "MODERATE"
    ELEVATED = "ELEVATED"
    HIGH = "HIGH"

@dataclass
class DifficultyAssessment:
    """困难模式评估结果"""
    difficulty_type: str
    risk_score: float            # 0-100
    risk_level: RiskLevel
    contributing_signals: List[Dict]  # 贡献信号明细
    confidence: float            # 0-1
    data_sufficiency: bool       # 数据量是否充足


class DifficultyPatternDetector:
    """学习困难模式综合检测器"""
    
    # 各维度信号的权重配置
    DETECTION_WEIGHTS = {
        "reading_difficulty": {
            "reading_speed_percentile": 0.25,
            "irregular_scroll_ratio": 0.15,
            "oral_reading_error_rate": 0.25,
            "incomplete_read_before_answer": 0.20,
            "spelling_error_rate": 0.15,
        },
        "attention_difficulty": {
            "session_interruption_freq": 0.25,
            "rushed_answering_ratio": 0.20,
            "task_abandonment_rate": 0.20,
            "multi_step_omission_rate": 0.20,
            "repeated_question_ratio": 0.15,
        },
        "working_memory_weak": {
            "premise_forgetting_error_rate": 0.30,
            "sequence_error_rate": 0.25,
            "key_step_omission_rate": 0.25,
            "distance_association_error": 0.20,
        },
        "processing_speed_slow": {
            "corrected_response_time": 0.40,
            "task_switch_adaptation_time": 0.30,
            "within_time_completion_ratio": 0.30,
        },
        "executive_function_weak": {
            "plan_completion_deviation": 0.25,
            "difficulty_avoidance_index": 0.25,
            "time_estimation_bias": 0.20,
            "repeated_same_type_error": 0.30,
        },
    }
    
    # 风险等级阈值
    RISK_THRESHOLDS = {
        RiskLevel.MINIMAL:  20,   # < 20
        RiskLevel.LOW:      40,   # 20-40
        RiskLevel.MODERATE: 60,   # 40-60
        RiskLevel.ELEVATED: 75,   # 60-75
        RiskLevel.HIGH:     100,  # > 75
    }
    
    def detect_all_patterns(
        self,
        student_id: int,
        signals: List['NormalizedSignal'],
        observation_window_days: int = 30
    ) -> List[DifficultyAssessment]:
        """
        对一个学生的所有行为信号进行全维度困难模式检测
        
        Args:
            student_id: 学生ID
            signals: 归一化后的信号列表
            observation_window_days: 观察窗口天数
            
        Returns:
            各维度的困难评估结果列表
        """
        results = []
        
        for difficulty_type, weight_config in self.DETECTION_WEIGHTS.items():
            assessment = self._detect_single_pattern(
                student_id=student_id,
                difficulty_type=difficulty_type,
                weight_config=weight_config,
                signals=signals,
                window_days=observation_window_days
            )
            results.append(assessment)
        
        return results
    
    def _detect_single_pattern(
        self,
        student_id: int,
        difficulty_type: str,
        weight_config: Dict[str, float],
        signals: List['NormalizedSignal'],
        window_days: int
    ) -> DifficultyAssessment:
        """检测单一困难维度"""
        
        contributing_signals = []
        weighted_risk = 0.0
        total_weight_used = 0.0
        confidence_scores = []
        
        for signal_key, weight in weight_config.items():
            # 从信号列表中提取该类型的信号
            relevant = [s for s in signals if s.signal_type == signal_key]
            
            if not relevant or len(relevant) < 3:
                # 该信号数据不足，跳过（不参与加权）
                contributing_signals.append({
                    "signal_type": signal_key,
                    "status": "INSUFFICIENT_DATA",
                    "sample_count": len(relevant) if relevant else 0
                })
                continue
            
            # 计算该信号的风险分量
            # 取最近窗口内的信号聚合值
            recent_values = [s.percentile_rank for s in relevant[-30:]]  # 最近30个数据点
            
            # 风险分量 = 该指标偏离正常范围的程度
            # 百分位越极端（接近0或100取决于方向），风险越高
            signal_risk = self._calculate_signal_risk(
                signal_key=signal_key,
                percentile_values=recent_values
            )
            
            weighted_risk += signal_risk * weight
            total_weight_used += weight
            confidence_scores.extend([s.confidence for s in relevant])
            
            contributing_signals.append({
                "signal_type": signal_key,
                "status": "ACTIVE",
                "sample_count": len(relevant),
                "avg_percentile": round(float(np.mean(recent_values)), 2),
                "signal_risk_score": round(signal_risk, 2),
                "weight": weight,
                "trend": self._calculate_trend(recent_values)
            })
        
        # 归一化（只用有数据的信号做加权）
        if total_weight_used > 0:
            final_risk_score = (weighted_risk / total_weight_used) * 100
        else:
            final_risk_score = 0.0
        
        # 数据充分性判断
        data_ratio = total_weight_used / sum(weight_config.values())
        data_sufficient = data_ratio >= 0.6  # 至少60%的信号维度有数据
        
        # 置信度计算
        avg_confidence = float(np.mean(confidence_scores)) if confidence_scores else 0.3
        
        # 数据量不足时降低置信度
        if not data_sufficient:
            avg_confidence *= 0.5
        
        # 风险等级判定
        risk_level = self._score_to_level(final_risk_score)
        
        return DifficultyAssessment(
            difficulty_type=difficulty_type,
            risk_score=round(final_risk_score, 2),
            risk_level=risk_level,
            contributing_signals=contributing_signals,
            confidence=round(avg_confidence, 3),
            data_sufficiency=data_sufficient
        )
    
    def _calculate_signal_risk(
        self,
        signal_key: str,
        percentile_values: List[float]
    ) -> float:
        """
        计算单个信号维度的风险分数 (0-1)
        
        逻辑：对于"越低越异常"的指标（如完成率百分位），
        低百分位 = 高风险；对于"越高越异常"的指标（如错误率百分位），
        高百分位 = 高风险
        """
        DIRECTIONAL_SIGNALS = {
            # "正向"信号：低值表示风险（如完成率、正确率）
            "within_time_completion_ratio": "low_is_risk",
            # "反向"信号：高值表示风险（如错误率、中断频率）
            # 默认为 high_is_risk
        }
        
        direction = DIRECTIONAL_SIGNALS.get(signal_key, "high_is_risk")
        avg_pct = float(np.median(percentile_values[-10:]))  # 取最近10个的中位数
        
        if direction == "low_is_risk":
            # 百分位越低，风险越高
            risk = max(0, (50 - avg_pct) / 50)  # P50以下开始计入风险
        else:
            # 百分位越高，风险越高
            risk = max(0, (avg_pct - 50) / 50)  # P50以上开始计入风险
        
        return min(1.0, risk)
    
    def _calculate_trend(self, values: List[float]) -> str:
        """计算趋势：IMPROVING / STABLE / DETERIORATING"""
        if len(values) < 6:
            return "INSUFFICIENT_DATA"
        
        mid = len(values) // 2
        first_half = float(np.mean(values[:mid]))
        second_half = float(np.mean(values[mid:]))
        
        diff = second_half - first_half
        if abs(diff) < 5:
            return "STABLE"
        return "IMPROVING" if diff > 0 else "DETERIORATING"
    
    def _score_to_level(self, score: float) -> RiskLevel:
        """风险分数转风险等级"""
        for level, threshold in self.RISK_THRESHOLDS.items():
            if score < threshold:
                return level
        return RiskLevel.HIGH
```

```python
class AccommodationEffectivenessTracker:
    """适配策略效果追踪器"""
    
    def evaluate_accommodation(
        self,
        student_id: int,
        accommodation_id: int,
        evaluation_window_days: int = 14
    ) -> 'EffectivenessReport':
        """
        评估单个适配策略的效果
        
        对比策略激活前后的关键指标变化，
        判断策略是否有效、是否需要调整或回滚
        """

        before_signals = self._get_signals_in_window(
            student_id=student_id,

            start_date=accommodation.activated_at - timedelta(days=evaluation_window_days),
            end_date=accommodation.activated_at
        )

            student_id=student_id,
            signal_types=self._get_relevant_signals(accommodation.target_difficulty),
            start_date=accommodation.activated_at,
            end_date=datetime.now()
        )
        
        # 计算改善幅度
```

```python
"""
学习行为信号提取管线
消费原始行为事件，提取认知特征信号，写入信号存储
"""

import json
from kafka import KafkaConsumer
from datetime import datetime

class SignalExtractionPipeline:
    
    SIGNAL_EXTRACTORS = {
        "question.answered": "QuestionAnsweredExtractor",
        "content.read": "ContentReadExtractor", 
        "session.lifecycle": "SessionLifecycleExtractor",
        "voice.assessed": "VoiceAssessedExtractor",
        "plan.executed": "PlanExecutedExtractor",
    }
    
    def __init__(self):
        self.consumer = KafkaConsumer(
            'learning-behavior-events',
            bootstrap_servers=['kafka-cluster:9092'],
            group_id='signal-extraction-group',
            value_deserializer=lambda m: json.loads(m.decode('utf-8')),
            enable_auto_commit=False,
            max_poll_records=500
        )
        self.extractors = self._init_extractors()
        self.signal_store = SignalStore()
        self.normalizer = SignalNormalizer(GradeNormRepository())
    
    def run(self):
        """主消费循环"""
        for message in self.consumer:
            try:
                event = message.value
                extractor_class_name = self.SIGNAL_EXTRACTORS.get(event["event_type"])
                
                if not extractor_class_name:
                    continue
                
                extractor = self.extractors[extractor_class_name]
                signals = extractor.extract(event)
                
                for signal in signals:
                    # 归一化
                    normalized = self.normalizer.normalize(
                        student_id=signal.student_id,
                        signal_type=signal.signal_type,
                        raw_value=signal.value,
                        grade_level=signal.grade_level,
                        subject=signal.subject,
                        context=signal.context
                    )
                    
                    # 持久化
                    self.signal_store.save(normalized)
                
                self.consumer.commit()
                
            except Exception as e:
                logger.error(f"Signal extraction failed for message: {message}", exc_info=e)
                # 发送到死信队列
                self._send_to_dlq(message, str(e))


class QuestionAnsweredExtractor:
    """从答题事件中提取认知信号"""
    
    QUESTION_TYPE_TO_SIGNAL = {
        "multi_step": ["premise_forgetting_error_rate", "step_completion_ratio"],
        "reading_comprehension": ["incomplete_read_before_answer", "distance_association_error"],
        "calculation": ["corrected_response_time", "calculation_error_type"],
    }
    
    def extract(self, event: dict) -> List['RawSignal']:
        signals = []
        
        student_id = event["student_id"]
        question_meta = event["question_meta"]
        answer_detail = event["answer_detail"]
        
        # --- 信号1: 答题响应时间（排除知识因素后的纯处理时间） ---
        expected_read_time = self._estimate_read_time(question_meta)
        actual_time = answer_detail.get("time_to_first_action_sec", 0)
        processing_time = max(0, actual_time - expected_read_time)
        
        signals.append(RawSignal(
            student_id=student_id,
            signal_type="corrected_response_time",
            value=processing_time,
            context={
                "question_id": question_meta["id"],
                "subject": question_meta["subject"],
                "difficulty": question_meta.get("difficulty", 0.5),
                "session_id": event.get("session_id"),
                "time_of_day": datetime.fromisoformat(event["timestamp"]).hour
            },
            grade_level=event["grade_level"]
        ))
        
        # --- 信号2: 多步题前提遗忘检测 ---
        if question_meta.get("question_type") == "multi_step":
            steps = answer_detail.get("steps", [])
            premise_forgetting = self._detect_premise_forgetting(steps)
            
            if premise_forgetting is not None:
                signals.append(RawSignal(
                    student_id=student_id,
                    signal_type="premise_forgetting_error_rate",
                    value=1.0 if premise_forgetting else 0.0,
                    context={
                        "question_id": question_meta["id"],
                        "subject": question_meta["subject"],
                        "total_steps": len(steps)
                    },
                    grade_level=event["grade_level"]
                ))
        
        # --- 信号3: 答题急促性检测 ---
        if actual_time < expected_read_time * 0.3:
            signals.append(RawSignal(
                student_id=student_id,
                signal_type="rushed_answering_ratio",
                value=1.0,
                context={
                    "question_id": question_meta["id"],
                    "expected_read_time": expected_read_time,
                    "actual_time": actual_time
                },
                grade_level=event["grade_level"]
            ))
        
        return signals
    
    def _estimate_read_time(self, question_meta: dict) -> float:
        """估算题目阅读所需时间（秒）"""
        text_length = len(question_meta.get("stem", ""))
        # 基础阅读速度: 5字/秒（小学）、7字/秒（初中）、9字/秒（高中）
        grade = question_meta.get("grade_level", "middle")
        speed = {"primary": 5, "middle": 7, "high": 9}.get(grade, 7)
        
        base_time = text_length / speed
        # 加上选项/图表的查看时间
        option_count = len(question_meta.get("options", []))
        return base_time + option_count * 2 + 3  # +3秒基础认知时间
    
    def _detect_premise_forgetting(self, steps: List[dict]) -> Optional[bool]:
        """检测多步题中是否遗忘前提条件"""
        if len(steps) < 3:
            return None
        
        # 检查后续步骤是否使用了前面已推导的条件
        early_conditions = set()
        for i, step in enumerate(steps[:len(steps)//2]):
            if step.get("result"):
                early_conditions.update(step["result"].get("derived_facts", []))
        
        later_steps_use_conditions = False
        for step in steps[len(steps)//2:]:
            used = step.get("used_facts", [])
            if any(fact in early_conditions for fact in used):
                later_steps_use_conditions = True
                break
        
        # 如果前半部分正确推导了条件，但后半部分错误且未使用这些条件
        early_correct = all(s.get("is_correct", False) for s in steps[:len(steps)//2])
        later_wrong = any(not s.get("is_correct", False) for s in steps[len(steps)//2:])
        
        if early_correct and later_wrong and not later_steps_use_conditions:
            return True
        
        return False
```

```python
"""
学习困难模式定时分析任务
"""

from celery import Celery
from datetime import datetime, timedelta

app = Celery('learning_support', broker='redis://redis:6379/0')

@app.task(name='weekly_full_analysis')
def weekly_full_analysis():
    """每周全量分析任务"""
    students = get_eligible_students(
        min_observation_days=30,
        active_since= datetime.now() - timedelta(days=7)
    )
    
    for student_id in students:
        analyze_student_profile.delay(student_id, trigger="SCHEDULED_WEEKLY")


@app.task(name='analyze_student_profile', bind=True, max_retries=3)
def analyze_student_profile(self, student_id: int, trigger: str):
    """单个学生的完整分析流程"""
    try:
        # Step 1: 获取分析窗口内的所有信号
        signals = SignalStore().get_recent_signals(
            student_id=student_id,
            days=30
        )
        
        if len(signals) < 50:
            logger.info(f"Student {student_id}: insufficient signals ({len(signals)}), skipping")
            return
        
        # Step 2: 困难模式检测
        detector = DifficultyPatternDetector()
        assessments = detector.detect_all_patterns(
            student_id=student_id,
            signals=signals,
            observation_window_days=30
        )
        
        # Step 3: 生成/更新认知特征画像
        profile = CognitiveProfileBuilder().build(
            student_id=student_id,
            assessments=assessments
        )
        
        # Step 4: 推荐适配策略
        existing = AccommodationStore().get_active(student_id)
        recommender = AccommodationRecommender()
        new_recommendations = recommender.recommend(assessments, existing)
        
        # Step 5: 激活高优先级策略（自动激活低风险策略）
        auto_activatable = [r for r in new_recommendations 
                          if r.expected_benefit > 0.3 and r.priority <= 3]
        for rec in auto_activatable:
            AccommodationStore().activate(
                student_id=student_id,
                accommodation_type=rec.accommodation_type,
                params=rec.params,
                target_difficulty=rec.target_difficulty
            )
        
        # Step 6: 效果评估（对已有策略）
        tracker = AccommodationEffectivenessTracker()
        for acc in existing:
            report = tracker.evaluate_accommodation(student_id, acc["id"])
            if report.recommended_action == "CONSIDER_ADJUSTMENT":
                AccommodationStore().pause(
                    accommodation_id=acc["id"],
                    reason="Effectiveness evaluation: NOT_EFFECTIVE"
                )
        
        # Step 7: 家长报告生成
        if trigger in ("SCHEDULED_WEEKLY", "TRIGGERED"):
            report = ParentReportGenerator().generate(
                student_id=student_id,
                assessments=assessments,
                active_accommodations=existing + auto_activatable,
                period="weekly"
            )
            
            # 仅在有显著变化时推送通知
            if _has_significant_change(profile, student_id):
                NotificationService().send_parent_notification(
                    student_id=student_id,
                    title="学习支持周报已更新",
                    body=_build_notification_summary(profile, report)
                )
        
        # Step 8: 如果检测到高风险，建议专业评估
        if profile.overall_risk_level in ("ELEVATED", "HIGH"):
            profile.professional_referral_recommended = True
            ProfileStore().save(profile)
        
        logger.info(f"Analysis completed for student {student_id}: {profile.overall_risk_level}")
        
    except Exception as exc:
        logger.error(f"Analysis failed for student {student_id}", exc_info=exc)
        raise self.retry(exc=exc, countdown=300)


def _has_significant_change(profile, student_id) -> bool:
    """判断与上次画像相比是否有显著变化"""
    previous = ProfileStore().get_previous(student_id)
    if not previous:
        return True
    
    # 风险等级变化
    if profile.overall_risk_level != previous.overall_risk_level:
        return True
    
    # 主要困难类型变化
    if profile.primary_difficulty_type != previous.primary_difficulty_type:
        return True
    
    # 风险评分变化超过15分
    for field in ["reading_risk_score", "attention_risk_score", 
                   "working_memory_risk_score", "executive_function_risk_score"]:
        old = getattr(previous, field, 0)
        new = getattr(profile, field, 0)
        if abs(new - old) > 15:
            return True
    
    return False
```

## 10. 错误处理与异常场景

### 10.1 错误码定义

| 错误码 | HTTP | 含义 | 处理策略 |
| --- | --- | --- | --- |
| LS_001 | 400 | 学生数据不足（<30天） | 返回空画像，提示持续使用 |
| LS_002 | 403 | 家长未开启智能学习支持 | 返回引导开启页面 |
| LS_003 | 403 | 无权访问该学生数据 | 鉴权失败 |
| LS_004 | 404 | 学生画像不存在 | 首次使用，返回默认配置 |
| LS_005 | 429 | 分析任务正在执行中 | 返回上次分析结果，提示稍后刷新 |
| LS_006 | 500 | 基线数据缺失 | 降级为全年级通用基线 |
| LS_007 | 500 | 信号归一化异常 | 跳过异常信号，继续处理其余信号 |
| LS_008 | 500 | 适配策略下发失败 | 返回上一次成功配置 |
| LS_009 | 400 | 策略参数非法 | 返回参数校验错误明细 |
| LS_010 | 403 | 专业评估建议已被家长确认 | 不重复推送 |

### 10.2 降级策略

```python
class LearningSupportFallback:
    """学习支持服务降级策略"""
    
    def get_accommodations_with_fallback(self, student_id: int) -> dict:
        """
        获取适配配置（带降级策略）
        """
        try:
            # 优先读取最新画像
            profile = ProfileStore().get_active(student_id)
            if profile:
                return self._build_response(profile)
            
        except DatabaseTimeout:
            # 数据库超时 → 读取缓存
            cached = Cache.get(f"ls_profile_cache:{student_id}")
            if cached:
                logger.warning("Using cached profile due to DB timeout")
                return cached
            
        except Exception as e:
            logger.error("Profile fetch failed", exc_info=e)
        
        # 最终降级：返回空适配（不影响学生学习）
        return {
            "active_accommodations": [],
            "global_settings": {
                "ui_simplify": False,
                "default_font_scale": 1.0
            },
            "fallback": True,
            "message": "个性化学习支持配置暂时不可用，使用默认设置"
        }
```

### 10.3 数据质量保障

| 场景 | 保障措施 |
| --- | --- |
| 基线数据不足 | 当同年级同学科样本 < 100 人时，使用跨年级基线 + 额外10%宽裕度 |
| 信号噪声过大 | 对单个信号值使用滑动中位数滤波（窗口=5），剔除极端异常值 |
| 季节性偏差 | 期末/考试周期间的行为数据降权（权重=0.5），避免考试压力导致的假阳性 |
| 设备差异 | 移动端和PC端的交互信号分别建基线，不做跨设备比较 |
| 数据缺失 | 缺失维度不参与风险评分计算，在置信度中体现 |

## 11. 隐私与安全设计

### 11.1 数据分级

| 数据类别 | 敏感等级 | 存储策略 | 访问控制 |
| --- | --- | --- | --- |
| 原始行为信号 | L2（内部） | 加密存储，保留90天 | 仅分析引擎可读 |
| 认知特征画像 | L3（高敏感） | 字段级加密，永久保留 | 仅学生本人/绑定家长/授权教师可读 |
| 家长观察报告 | L2（内部） | 标准存储，保留2年 | 仅家长可读 |
| 专业评估建议 | L3（高敏感） | 加密存储 | 仅家长可读，不可分享 |
| 适配策略配置 | L1（低） | 标准存储 | 服务内部读写 |

### 11.2 家长知情同意流程

```text
首次启用流程:

   → consent_record: {parent_id, student_id, agreed_at, policy_version}
```

## 15. 开放问题与后续演进

### 15.1 当前版本限制

1. **基线数据冷启动**：新上线时同年级行为基线不足，初期使用专家经验基线，需逐步积累真实数据替换
2. **跨文化适配**：当前行为基线基于中国学生群体，国际化时需重新建立基线
3. **信号覆盖度**：部分信号（如手写识别模式）依赖客户端能力，部分低端设备可能采集精度不足
4. **交互效应**：多种困难模式叠加时（如阅读+注意力），适配策略之间的交互效应尚需数据验证

### 15.2 后续演进方向

| 方向 | 说明 | 优先级 |
| --- | --- | --- |
| ML模型替代规则引擎 | 积累足够标注数据后，训练端到端的风险预测模型 | P2 |
| 教师端协同 | 将脱敏后的特征摘要同步给教师，辅助课堂教学调整 | P1 |
| 语音生物标记 | 分析朗读时的语音特征（停顿、语调），作为额外信号源 | P2 |
| 同伴比较基线 | 在保护隐私前提下，建立匿名化的同伴进步比较基线 | P3 |
| 多模态融合 | 融合表情识别（摄像头）等更多模态信号（需额外合规评估） | P3 |
| 家长教育内容 | 根据识别到的困难类型，为家长推送相关的科普文章和辅导技巧 | P1 |

## 附录A：术语对照表

| 术语 | 说明 |
| --- | --- |
| 困难倾向 (Difficulty Tendency) | 行为模式显示的可能存在某种学习困难，非医学诊断 |
| 适配策略 (Accommodation) | 对学习内容呈现方式的调整，不改变教学内容本身 |
| 行为信号 (Behavioral Signal) | 从学习行为中提取的、可用于认知特征分析的量化指标 |
| 基线 (Baseline) | 同年级同学科学生群体在某项信号上的分布参数 |
| 稳健Z分数 (Robust Z-Score) | 使用中位数和MAD（中位绝对偏差）计算的标准化分数，抗异常值 |
| 认知特征画像 (Cognitive Profile) | 对学生认知维度的综合评估结果快照 |
| 专业评估 (Professional Assessment) | 由持证教育心理学家进行的专业化学习困难诊断 |

## 附录B：风险等级解读指南

| 等级 | 分数范围 | 含义 | 建议动作 |
| --- | --- | --- | --- |
| MINIMAL | 0-20 | 行为模式在正常范围内 | 无需特殊适配 |
| LOW | 21-40 | 轻微倾向，可能是正常个体差异 | 持续观察，可选开启低强度适配 |
| MODERATE | 41-60 | 多个信号维度呈现一致性偏离 | 自动激活适配策略，周报告知家长 |
| ELEVATED | 61-75 | 强烈的困难信号模式 | 建议家长关注，考虑专业教育咨询 |
| HIGH | 76-100 | 极端偏离，高度一致的困难信号 | 强烈建议专业评估 |

> **注意**：ELEVATED/HIGH 不代表学生一定有学习障碍。压力、疲劳、内容不匹配、设备问题等都可能产生类似信号。所有评估都需要结合专业判断。
