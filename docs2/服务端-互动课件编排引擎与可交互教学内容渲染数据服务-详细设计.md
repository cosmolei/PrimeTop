# 服务端-互动课件编排引擎与可交互教学内容渲染数据服务-详细设计

## 1. 概述

### 1.1 功能定位

互动课件编排引擎是 PrimeTop 平台中将教学设计转化为可交互数字学习体验的核心服务。它介于"内容生产"与"客户端渲染"之间，负责将结构化的教学内容（图文、音视频、练习题、实验模拟等多模态素材）编排为有时序、有交互逻辑、有状态流转的**互动课件**（Interactive Courseware），并为客户端提供课件渲染所需的完整数据与运行时交互支持。

与现有模块的协作关系：

| 现有模块 | 关系 |
| --- | --- |
| 教育内容结构化模板引擎 | 提供内容模板定义，课件编排引擎消费模板并填充交互逻辑 |
| 教育互动练习类型注册中心 | 提供练习组件类型，课件编排引擎在课件中嵌入和调度这些组件 |
| 学习单元动态组装与跨模块知识串联引擎 | 负责跨模块单元编排，课件编排引擎聚焦于单课件内部的页面/组件级编排 |
| 客户端-互动教材阅读器与课文点读学习组件 | 客户端渲染层，消费课件编排引擎的输出数据 |
| 学习会话内容编排与学习节奏智能控制引擎 | 负责会话级编排，课件编排引擎负责课件内部的页面级编排 |

### 1.2 设计目标

1. **课件即数据**：课件完全用结构化 JSON 描述，不依赖硬编码页面，实现"一次编排，多端渲染"。
2. **组件化**：课件由可复用的交互组件（展示类、练习类、实验类、反馈类）组合而成，新组件类型可通过插件方式注册。
3. **分支路径**：支持基于学生作答结果或自适应策略的课件内分支跳转，实现"一课多线"。
4. **状态持久化**：课件学习进度精确到页面/组件级，支持跨设备断点续学。
5. **实时交互反馈**：提供课件内练习的即时批改结果、提示解锁、动画触发等运行时数据。
6. **数据回流**：采集课件内每个交互节点的学生行为数据，为学情分析和内容优化提供数据源。

### 1.3 适用范围

| 场景 | 说明 |
| --- | --- |
| 同步课堂互动课件 | 教材章节配套的互动学习内容，包含知识讲解 + 穿插练习 |
| 考前冲刺闯关课件 | 考点专题课件，以闯关/挑战形式组织练习 |
| 拼音识字互动卡 | 低龄段图文卡片 + 发音 + 书写动画 + 趣味互动 |
| 实验操作引导课件 | 虚拟实验步骤引导 + 操作检查点 |
| 课外阅读互动材料 | 分段阅读 + 理解检测 + 笔记批注 |

## 2. 核心概念与领域模型

### 2.1 概念定义

| 概念 | 英文 | 说明 |
| --- | --- | --- |
| 课件 | Courseware | 一个完整的学习单元，包含多个页面，有明确的开始和结束 |
| 课件页面 | Page / Slide | 课件中的一屏内容，包含一个或多个交互组件 |
| 交互组件 | Interactive Component | 课件中最小的可交互单元，如选择题、拖拽题、知识点卡片、视频片段等 |
| 组件插槽 | Component Slot | 页面中预留的组件挂载位置，定义了组件类型约束和尺寸约束 |
| 分支规则 | Branch Rule | 基于学生交互结果决定下一页面跳转的规则 |
| 课件会话 | Courseware Session | 学生一次课件学习过程的运行时实例 |
| 课件状态快照 | State Snapshot | 课件会话在某一时刻的完整状态，用于断点续学 |
| 交互事件 | Interaction Event | 学生在课件中产生的每次交互（答题、点击、拖拽、播放等） |

### 2.2 课件生命周期

```
草案(DRAFT) → 待审核(PENDING_REVIEW) → 审核中(IN_REVIEW) 
    → 已发布(PUBLISHED) → 已下线(OFFLINE) → 归档(ARCHIVED)

特殊状态：
    - 审核驳回(REJECTED)：回到草案修改
    - 紧急冻结(FROZEN)：已发布但因内容问题紧急停用
```

### 2.3 课件结构示意

```
Courseware (课件)
├── metadata (元数据)
│   ├── title, description, coverImage
│   ├── subject, gradeLevel, textbookEdition, chapterIds
│   ├── knowledgePointIds[], examPointIds[]
│   ├── difficulty, estimatedDuration
│   └── adaptiveStrategy (自适应策略配置)
├── pages[] (页面列表)
│   ├── Page 1: 导入页
│   │   ├── slot-1: TextCard (情境引入)
│   │   ├── slot-2: VideoClip (知识导入视频)
│   │   └── slot-3: Hotspot (知识点高亮引导)
│   ├── Page 2: 讲解页
│   │   ├── slot-1: KnowledgeCard (核心知识点)
│   │   ├── slot-2: FormulaRenderer (公式展示)
│   │   └── slot-3: AnimationPlayer (过程动画)
│   ├── Page 3: 检测页
│   │   ├── slot-1: MultipleChoice (概念检测题)
│   │   └── slot-2: ImmediateFeedback (即时反馈区)
│   ├── Page 4: 分支页 (根据Page 3作答结果跳转)
│   │   ├── branchRule: 
│   │   │   ├── correct → Page 5 (进阶)
│   │   │   └── wrong → Page 6 (补救讲解)
│   │   └── slot-1: BranchRouter (路由器组件)
│   ├── Page 5: 进阶练习页
│   │   └── ...
│   └── Page 6: 补救讲解页
│       └── ...
├── conclusion (结课页)
│   ├── summary: 知识要点总结
│   └── achievement: 完成奖励配置
└── analyticsConfig (分析埋点配置)
```

## 3. 数据结构设计

### 3.1 数据库表设计

#### 3.1.1 `courseware` 课件主表

```sql
CREATE TABLE courseware (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    uuid VARCHAR(36) NOT NULL UNIQUE COMMENT '课件UUID',
    title VARCHAR(200) NOT NULL COMMENT '课件标题',
    description TEXT COMMENT '课件描述',
    cover_image_url VARCHAR(500) COMMENT '封面图URL',
    
    -- 学科与学段
    subject_code VARCHAR(20) NOT NULL COMMENT '学科编码',
    grade_level TINYINT NOT NULL COMMENT '学段: 0=幼儿 1=小学 2=初中 3=高中',
    grade_codes JSON COMMENT '适用年级列表 ["G1","G2",...]',
    textbook_edition_code VARCHAR(30) COMMENT '教材版本编码',
    chapter_ids JSON COMMENT '关联章节ID列表',
    
    -- 知识与考点
    knowledge_point_ids JSON COMMENT '知识点ID列表',
    exam_point_ids JSON COMMENT '考点ID列表',
    
    -- 课件属性
    difficulty TINYINT DEFAULT 3 COMMENT '难度 1-5',
    estimated_duration INT DEFAULT 600 COMMENT '预计学习时长(秒)',
    adaptive_strategy JSON COMMENT '自适应策略配置',
    
    -- 状态
    status VARCHAR(20) NOT NULL DEFAULT 'DRAFT' COMMENT '生命周期状态',
    version INT NOT NULL DEFAULT 1 COMMENT '版本号',
    parent_version_id BIGINT COMMENT '上一版本ID(用于版本链)',
    
    -- 创作信息
    author_id BIGINT NOT NULL COMMENT '创建者ID',
    reviewer_id BIGINT COMMENT '审核人ID',
    
    -- 时间戳
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    published_at DATETIME COMMENT '发布时间',
    offline_at DATETIME COMMENT '下线时间',
    
    -- 索引
    INDEX idx_subject_grade (subject_code, grade_level),
    INDEX idx_status (status),
    INDEX idx_chapter ( (CAST(chapter_ids AS CHAR(500))) ),
    INDEX idx_author (author_id),
    INDEX idx_published (published_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课件主表';
```

#### 3.1.2 `courseware_page` 课件页面表

```sql
CREATE TABLE courseware_page (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    courseware_id BIGINT NOT NULL COMMENT '所属课件ID',
    page_index INT NOT NULL COMMENT '页面顺序(从0开始)',
    page_key VARCHAR(50) NOT NULL COMMENT '页面唯一标识(P0, P1, ...)',
    page_type VARCHAR(30) NOT NULL COMMENT '页面类型: INTRO/EXPLAIN/PRACTICE/BRANCH/SUMMARY',
    title VARCHAR(200) COMMENT '页面标题',
    
    -- 布局
    layout_type VARCHAR(20) NOT NULL DEFAULT 'VERTICAL_SCROLL' COMMENT '布局类型: VERTICAL_SCROLL/HORIZONTAL_SLIDE/FREE_FORM',
    background_config JSON COMMENT '背景配置(颜色/图片/动画)',
    
    -- 分支配置
    branch_rules JSON COMMENT '分支跳转规则(仅BRANCH类型)',
    default_next_page_key VARCHAR(50) COMMENT '默认下一页key',
    
    -- 页面元数据
    is_optional TINYINT DEFAULT 0 COMMENT '是否可选页面(可跳过)',
    estimated_duration INT COMMENT '本页预计停留时长(秒)',
    
    -- 时间戳
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_courseware_page_key (courseware_id, page_key),
    INDEX idx_courseware_order (courseware_id, page_index),
    CONSTRAINT fk_page_courseware FOREIGN KEY (courseware_id) 
        REFERENCES courseware(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课件页面表';
```

#### 3.1.3 `courseware_component` 课件交互组件表

```sql
CREATE TABLE courseware_component (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    page_id BIGINT NOT NULL COMMENT '所属页面ID',
    courseware_id BIGINT NOT NULL COMMENT '所属课件ID(冗余,便于查询)',
    
    -- 组件定义
    slot_key VARCHAR(50) NOT NULL COMMENT '插槽标识',
    component_type VARCHAR(50) NOT NULL COMMENT '组件类型(见3.2)',
    component_config JSON NOT NULL COMMENT '组件配置数据',
    
    -- 布局位置
    sort_order INT NOT NULL DEFAULT 0 COMMENT '组件在页面内的排序',
    layout_position JSON COMMENT '自由布局时的坐标与尺寸',
    
    -- 交互行为
    interaction_required TINYINT DEFAULT 0 COMMENT '是否必须交互才能继续(1=必须,如答题)',
    correct_threshold JSON COMMENT '通过条件配置(如正确率>=60%)',
    hint_config JSON COMMENT '提示配置(渐进式提示)',
    
    -- 知识关联
    knowledge_point_id BIGINT COMMENT '关联知识点ID',
    
    -- 状态
    is_active TINYINT DEFAULT 1 COMMENT '是否启用',
    
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_page (page_id),
    INDEX idx_courseware (courseware_id),
    INDEX idx_type (component_type),
    CONSTRAINT fk_component_page FOREIGN KEY (page_id) 
        REFERENCES courseware_page(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课件交互组件表';
```

#### 3.1.4 `courseware_session` 课件学习会话表

```sql
CREATE TABLE courseware_session (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_uuid VARCHAR(36) NOT NULL UNIQUE COMMENT '会话UUID',
    user_id BIGINT NOT NULL COMMENT '学生ID',
    courseware_id BIGINT NOT NULL COMMENT '课件ID',
    courseware_version INT NOT NULL COMMENT '学习时的课件版本',
    
    -- 进度
    current_page_key VARCHAR(50) NOT NULL DEFAULT 'P0' COMMENT '当前页面key',
    completed_page_keys JSON COMMENT '已完成页面key列表',
    total_pages INT NOT NULL COMMENT '课件总页数',
    completed_pages INT NOT NULL DEFAULT 0 COMMENT '已完成页数',
    progress_pct DECIMAL(5,2) DEFAULT 0.00 COMMENT '进度百分比',
    
    -- 分支路径
    branch_path JSON COMMENT '已走的分支路径 ["P0","P1","P3",...]',
    
    -- 成绩
    total_interactions INT DEFAULT 0 COMMENT '总交互次数',
    correct_interactions INT DEFAULT 0 COMMENT '正确交互次数',
    score DECIMAL(5,2) COMMENT '课件得分',
    passed TINYINT DEFAULT NULL COMMENT '是否通过(NULL=未完成)',
    
    -- 时间
    started_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    last_active_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    completed_at DATETIME COMMENT '完成时间',
    total_duration INT DEFAULT 0 COMMENT '累计学习时长(秒)',
    
    -- 设备
    device_id VARCHAR(100) COMMENT '设备标识',
    platform VARCHAR(20) COMMENT '平台: IOS/ANDROID/WEB',
    
    -- 状态快照(用于断点续学)
    state_snapshot JSON COMMENT '完整状态快照JSON',
    
    INDEX idx_user_courseware (user_id, courseware_id),
    INDEX idx_last_active (last_active_at),
    INDEX idx_user_recent (user_id, last_active_at DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课件学习会话表';
```

#### 3.1.5 `courseware_interaction_log` 交互事件日志表

```sql
CREATE TABLE courseware_interaction_log (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id BIGINT NOT NULL COMMENT '会话ID',
    user_id BIGINT NOT NULL COMMENT '学生ID',
    courseware_id BIGINT NOT NULL COMMENT '课件ID',
    
    -- 交互信息
    page_key VARCHAR(50) NOT NULL COMMENT '发生页面',
    component_slot_key VARCHAR(50) NOT NULL COMMENT '发生组件插槽',
    component_type VARCHAR(50) NOT NULL COMMENT '组件类型',
    
    -- 交互详情
    interaction_type VARCHAR(30) NOT NULL COMMENT '交互类型: ANSWER/CHECK/HINT_REQUEST/PLAY/SCROLL/CLICK',
    interaction_payload JSON COMMENT '交互详情(如选择的选项、输入的文本)',
    interaction_result JSON COMMENT '交互结果(如正确/错误、得分)',
    
    -- 反馈
    is_correct TINYINT COMMENT '是否正确(答题类)',
    time_spent_ms INT COMMENT '本次交互耗时(毫秒)',
    hint_used TINYINT DEFAULT 0 COMMENT '是否使用了提示',
    
    -- 时间
    occurred_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    
    INDEX idx_session (session_id),
    INDEX idx_user_time (user_id, occurred_at),
    INDEX idx_courseware_component (courseware_id, component_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课件交互事件日志';
```

> 注：交互日志数据量大，建议按月分表或迁移至 ClickHouse / Elasticsearch 进行分析查询。

### 4.1 课件创作 API（管理端/创作者端）

#### 4.1.1 创建课件

```
POST /api/v1/courseware
Content-Type: application/json

Request:
```

```java
/**

public interface ComponentTypeDefinition {
    
    /** 组件类型编码 */
    String getTypeCode();
    
    /** 组件分类 */
    ComponentCategory getCategory();
    
    /** 组件显示名称 */
    String getDisplayName();

    JsonNode getConfigSchema();
    
    /** 是否需要交互（如选择题需要，纯文本卡片不需要） */

    ComponentInteractionHandler getInteractionHandler();
    
    /** 渲染器标识（客户端据此选择对应的渲染组件） */
    String getRendererKey();
}

/**
 * 组件注册中心
 */
@Service
public class ComponentRegistry {
    
    private final Map<String, ComponentTypeDefinition> registry = new ConcurrentHashMap<>();
    
    /**
     * 注册组件类型
     */
    public void register(ComponentTypeDefinition definition) {
        String typeCode = definition.getTypeCode();
        if (registry.containsKey(typeCode)) {
            throw new IllegalStateException(
                "Component type already registered: " + typeCode);
        }
        registry.put(typeCode, definition);
    }
    
    /**
     * 获取组件类型定义
     */
    public ComponentTypeDefinition getDefinition(String typeCode) {
        ComponentTypeDefinition def = registry.get(typeCode);
        if (def == null) {
            throw new ComponentTypeNotFoundException(typeCode);
        }
        return def;
    }
    
    /**
     * 校验组件配置
     */
    public ValidationResult validateConfig(String typeCode, JsonNode config) {
        ComponentTypeDefinition def = getDefinition(typeCode);
        return JsonSchemaValidator.validate(config, def.getConfigSchema());
    }
    
    /**
     * 获取所有可用组件类型（用于创作者选择）
     */
    public List<ComponentTypeMeta> listAvailableTypes(ComponentCategory category) {
        return registry.values().stream()
            .filter(def -> category == null || def.getCategory() == category)
            .map(ComponentTypeMeta::from)
            .sorted(Comparator.comparing(ComponentTypeMeta::getDisplayName))
            .collect(Collectors.toList());
    }
}
```

### 5.3 分支决策引擎

```java
/**
 * 分支决策引擎 — 根据学生在课件中的表现数据决定分支跳转
 */
@Service
public class BranchDecisionEngine {
    
    private final SessionMetricCalculator metricCalculator;
    
    /**
     * 执行分支决策
     * @param session  当前课件会话
     * @param branchPageKey  分支页key
     * @return 决策结果
     */
    public BranchDecision decide(CoursewareSession session, String branchPageKey) {
        
        // 1. 获取分支规则配置
        List<BranchRule> rules = coursewareLayoutService
            .getBranchRules(session.getCoursewareId(), branchPageKey);
        
        // 2. 计算评估指标
        Map<String, Object> metrics = metricCalculator.calculate(
            session, 
            rules.stream().flatMap(r -> r.getRequiredMetrics().stream())
                .collect(Collectors.toSet())
        );
        
        // 3. 按优先级逐一匹配规则
        for (BranchRule rule : rules) {
            if (evaluateCondition(rule.getCondition(), metrics)) {
                return BranchDecision.builder()
                    .matchedRuleId(rule.getRuleId())
                    .targetPageKey(rule.getTargetPageKey())
                    .label(rule.getLabel())
                    .contextMetrics(metrics)
                    .build();
            }
        }
        
        // 4. 无匹配规则时返回默认页面
        String fallbackPage = coursewareLayoutService
            .getDefaultNextPageKey(session.getCoursewareId(), branchPageKey);
        
        return BranchDecision.defaultDecision(fallbackPage, metrics);
    }
    
    /**
     * 规则条件评估
     */
    private boolean evaluateCondition(BranchCondition condition, 
                                       Map<String, Object> metrics) {
        switch (condition.getType()) {
            case "SCORE_THRESHOLD":
                String metricKey = condition.getMetric(); // e.g., "correct_rate"
                double actualValue = (double) metrics.getOrDefault(metricKey, 0.0);
                double threshold = condition.getThreshold();
                String operator = condition.getOperator();
                return compareOperator(actualValue, threshold, operator);
                
            case "ATTEMPT_COUNT":
                int attempts = (int) metrics.getOrDefault("attempt_count", 0);
                return attempts <= (int) condition.getThreshold();
                
            case "TIME_SPENT":
                long timeSpentSec = (long) metrics.getOrDefault("time_spent_sec", 0L);
                return timeSpentSec >= condition.getThreshold();
                
            case "HINT_USED":
                boolean hintUsed = (boolean) metrics.getOrDefault("hint_used", false);
                return hintUsed == (boolean) condition.getValue();
                
            case "ALWAYS":
                return true;
                
            default:
                log.warn("Unknown branch condition type: {}", condition.getType());
                return false;
        }
    }
    
    private boolean compareOperator(double actual, double threshold, String operator) {
        switch (operator) {
            case ">=": return actual >= threshold;
            case ">":  return actual > threshold;
            case "<=": return actual <= threshold;
            case "<":  return actual < threshold;
            case "==": return Math.abs(actual - threshold) < 0.0001;
            default:   return false;
        }
    }
}
```

```java
/**
 * 组件交互处理器接口 — 不同组件类型实现各自的交互处理逻辑
 */
public interface ComponentInteractionHandler {
    
    /**
     * 处理学生交互
     */
    InteractionResult handle(InteractionContext context);
    
    /**
     * 判断组件是否已完成
     */
    boolean isComponentCompleted(ComponentState state);
}

/**
 * 选择题交互处理器
 */
@Component
public class MultipleChoiceHandler implements ComponentInteractionHandler {
    
    @Override
    public InteractionResult handle(InteractionContext context) {
        MultipleChoiceConfig config = context.getConfig();
        InteractionPayload payload = context.getPayload();
        
        // 获取学生选择的选项
        List<String> selectedKeys = payload.getSelectedOptionKeys();
        
        // 获取正确选项
        List<String> correctKeys = config.getOptions().stream()
            .filter(Option::isCorrect)
            .map(Option::getKey)
            .collect(Collectors.toList());
        
        // 判断正误
        boolean isCorrect = selectedKeys.size() == correctKeys.size()
            && new HashSet<>(selectedKeys).containsAll(correctKeys);
        
        // 计算得分
        double score = calculateScore(selectedKeys, correctKeys, config.getScoringRule());
        
        // 生成反馈
        Feedback feedback = buildFeedback(isCorrect, selectedKeys, config);
        
        // 构建交互结果
        return InteractionResult.builder()
            .isCorrect(isCorrect)
            .score(score)
            .feedback(feedback)
            .componentState(ComponentState.builder()
                .status(isCorrect ? "COMPLETED" : "IN_PROGRESS")
                .attempts(context.getCurrentAttempts() + 1)
                .bestScore(Math.max(score, context.getBestScore()))
                .lastSelectedKeys(selectedKeys)
                .build())
            .build();
    }
    
    private Feedback buildFeedback(boolean isCorrect, List<String> selected, 
                                    MultipleChoiceConfig config) {
        if (isCorrect) {
            return Feedback.success(config.getExplanation().getCorrect());
        }
        
        // 为错误选项提供针对性解释
        List<String> wrongSelections = selected.stream()
            .filter(s -> !config.getCorrectKeys().contains(s))
            .collect(Collectors.toList());
        
        String explanation = wrongSelections.stream()
            .map(key -> config.getExplanation().getWrongMap().get(key))
            .filter(Objects::nonNull)
            .collect(Collectors.joining("\n"));
        
        return Feedback.failure(explanation, config.getHints());
    }
}
```

```java
/**
 * 课件渲染数据组装服务
 * 为客户端提供一次性加载所需的完整课件渲染数据
 */
@Service
public class CoursewareRenderService {
    
    private final CoursewareRepository coursewareRepo;
    private final CoursewareLayoutService layoutService;
    private final ComponentRegistry componentRegistry;
    private final ResourcePreloadService resourcePreloadService;
    
    /**
     * 组装课件渲染数据
     */
    public CoursewareRenderData assembleRenderData(
            Long coursewareId, 
            Integer version,
            Long userId) {
        
        // 1. 获取课件基本信息
        Courseware courseware = coursewareRepo.findByIdAndVersion(coursewareId, version)
            .orElseThrow(() -> new CoursewareNotFoundException(coursewareId));
        
        // 2. 获取页面布局
        List<CoursewarePage> pages = layoutService.getPages(coursewareId);
        
        // 3. 组装每页的组件数据
        List<PageRenderData> pageRenderList = pages.stream()
            .map(page -> assemblePage(page, userId))
            .collect(Collectors.toList());
        
        // 4. 生成资源预加载清单
        ResourceManifest manifest = resourcePreloadService.buildManifest(pageRenderList);
        
        // 5. 根据用户画像做个性化适配
        UserLearningProfile profile = userProfileService.getProfile(userId);
        pageRenderList = applyAdaptiveStrategy(pageRenderList, courseware, profile);
        
        return CoursewareRenderData.builder()
            .courseware(courseware)
            .pages(pageRenderList)
            .adaptiveConfig(courseware.getAdaptiveStrategy())
            .resourceManifest(manifest)
            .build();
    }
    
    /**
     * 组装单个页面的渲染数据
     */
    private PageRenderData assemblePage(CoursewarePage page, Long userId) {
        List<CoursewareComponent> components = layoutService.getComponents(page.getId());
        
        List<ComponentRenderData> componentRenderList = components.stream()
            .filter(CoursewareComponent::isActive)
            .map(comp -> {
                // 校验组件配置
                ComponentTypeDefinition typeDef = componentRegistry.getDefinition(
                    comp.getComponentType());
                
                // 对于练习类组件，如果是随机出题模式，在此处生成题目实例
                JsonNode renderConfig = comp.getComponentConfig();
                if (typeDef.needsGrading() && shouldRandomize(comp)) {
                    renderConfig = questionInstantiationService.instantiate(
                        comp.getComponentConfig(), userId);
                }
                
                return ComponentRenderData.builder()
                    .slotKey(comp.getSlotKey())
                    .type(comp.getComponentType())
                    .config(renderConfig)
                    .interactionRequired(comp.isInteractionRequired())
                    .rendererKey(typeDef.getRendererKey())
                    .build();
            })
            .collect(Collectors.toList());
        
        return PageRenderData.builder()
            .pageKey(page.getPageKey())
            .pageType(page.getPageType())
            .title(page.getTitle())
            .layoutType(page.getLayoutType())
            .background(page.getBackgroundConfig())
            .components(componentRenderList)
            .defaultNextPageKey(page.getDefaultNextPageKey())
            .branchRules(page.getBranchRules())
            .build();
    }
    
    /**
     * 自适应策略应用 — 根据学生画像调整课件配置
     */
    private List<PageRenderData> applyAdaptiveStrategy(
            List<PageRenderData> pages, 
            Courseware courseware,
            UserLearningProfile profile) {
        
        AdaptiveStrategy strategy = courseware.getAdaptiveStrategy();
        if (strategy == null || strategy.isDisabled()) {
            return pages;
        }
        
        // 根据学生水平调整题目难度
        for (PageRenderData page : pages) {
            for (ComponentRenderData comp : page.getComponents()) {
                if (comp.getType().equals("MultipleChoice") 
                        && strategy.shouldAdjustDifficulty(profile)) {
                    adjustQuestionDifficulty(comp, profile.getAbilityLevel());
                }
            }
        }
        
        return pages;
    }
}
```

## 7. 课件校验与质量保障

### 7.1 课件结构校验

在课件编排完成后提交审核前，系统自动执行全面的结构校验：

```java
@Service
public class CoursewareValidator {
    
    private static final int MAX_PAGES = 100;
    private static final int MAX_COMPONENTS_PER_PAGE = 20;
    private static final int MAX_TOTAL_SIZE_MB = 200;
    
    public ValidationResult validate(Long coursewareId) {
        List<ValidationError> errors = new ArrayList<>();
        List<ValidationWarning> warnings = new ArrayList<>();
        
        CoursewareLayout layout = layoutService.getFullLayout(coursewareId);
        
        // 1. 结构完整性校验
        validateStructure(layout, errors, warnings);
        
        // 2. 分支路径可达性校验
        validateBranchPaths(layout, errors, warnings);
        
        // 3. 组件配置校验
        validateComponents(layout, errors, warnings);
        
        // 4. 交互流程闭环校验
        validateInteractionFlow(layout, errors, warnings);
        
        // 5. 资源引用校验
        validateResources(layout, errors, warnings);
        
        // 6. 知识点覆盖率校验
        validateKnowledgeCoverage(layout, errors, warnings);
        
        return new ValidationResult(errors, warnings);
    }
    
    /**
     * 分支路径可达性校验 — 确保所有分支都能到达结课页
     * 使用图遍历算法检查
     */
    private void validateBranchPaths(CoursewareLayout layout, 
                                      List<ValidationError> errors,
                                      List<ValidationWarning> warnings) {
        Map<String, PageNode> graph = buildPageGraph(layout);
        String conclusionKey = layout.getConclusionPageKey();
        
        for (PageNode startNode : graph.values()) {
            if (!canReach(graph, startNode.getKey(), conclusionKey)) {
                errors.add(new ValidationError(
                    "BRANCH_DEAD_END",
                    String.format("页面 %s 无法到达结课页 %s，存在死循环或断路", 
                        startNode.getKey(), conclusionKey)
                ));
            }
        }
        
        // 检查是否存在不可能到达的页面
        for (PageNode page : graph.values()) {
            if (!page.getKey().equals(layout.getStartPageKey()) 
                    && !isReachableFrom(graph, layout.getStartPageKey(), page.getKey())) {
                warnings.add(new ValidationWarning(
                    "UNREACHABLE_PAGE",
                    String.format("页面 %s 从起始页不可达", page.getKey())
                ));
            }
        }
    }
    
    /**
     * 使用 BFS 检查可达性
     */
    private boolean canReach(Map<String, PageNode> graph, 
                             String from, String target) {
        Set<String> visited = new HashSet<>();
        Queue<String> queue = new LinkedList<>();
        queue.offer(from);
        
        while (!queue.isEmpty()) {
            String current = queue.poll();
            if (current.equals(target)) return true;
            if (visited.contains(current)) continue;
            visited.add(current);
            
            PageNode node = graph.get(current);
            if (node != null) {
                queue.addAll(node.getAllReachablePages());
            }
            
            // 防止循环
            if (visited.size() > graph.size()) break;
        }
        return false;
    }
}
```

```java
public class CoursewareCacheService {

        log.info("Evicted render cache for courseware {} v{}", coursewareId, version);
    }
    
    /**
     * 批量预加载热门课件到缓存
     */
    @Scheduled(cron = "0 0 6 * * ?")  // 每天早上6点预热
    public void preloadPopularCourseware() {
        List<Long> hotIds = analyticsService.getHotCoursewareIds(50);

            Integer latestVersion = coursewareRepo.getLatestVersion(id);
            try {
                CoursewareRenderData data = renderService.assembleRenderData(id, latestVersion, null);

                log.warn("Failed to preload courseware {}: {}", id, e.getMessage());
            }
        }
    }
}
```

```java
@Service
public class CoursewareFallbackService {
    
    /**
     * 渲染数据组装失败时的降级
     */
    public CoursewareRenderData fallbackRender(Long coursewareId, Throwable cause) {
        log.error("Render data assembly failed for courseware {}, falling back", 
            coursewareId, cause);
        
        // 尝试从缓存获取上一版本
        CoursewareRenderData cached = cacheService.getLatestCachedVersion(coursewareId);
        if (cached != null) {
            cached.setFallback(true);
            cached.setFallbackReason("SERVER_ERROR_CACHE_FALLBACK");
            return cached;
        }
        
        // 最终降级：返回基础文本版课件
        Courseware basic = coursewareRepo.findById(coursewareId).orElse(null);
        if (basic == null) {
            throw new CoursewareNotFoundException(coursewareId);
        }
        
        return buildBasicTextOnlyVersion(basic);
    }
    
    /**
     * 分支决策失败时的降级
     */
    public BranchDecision fallbackBranch(String currentPageKey, 
                                          String defaultNextPageKey) {
        log.warn("Branch decision service unavailable, using default path");
        return BranchDecision.builder()
            .matchedRuleId("FALLBACK")
            .targetPageKey(defaultNextPageKey)
            .label("默认路径")
            .isFallback(true)
            .build();
    }
    
    /**
     * 构建纯文本降级版课件
     */
    private CoursewareRenderData buildBasicTextOnlyVersion(Courseware courseware) {
        PageRenderData textPage = PageRenderData.builder()
            .pageKey("P0")
            .pageType("CONTENT")
            .layoutType("VERTICAL_SCROLL")
            .components(List.of(
                ComponentRenderData.builder()
                    .slotKey("S1")
                    .type("TextCard")
                    .config(ObjectNode.builder()
                        .put("title", courseware.getTitle())
                        .put("content", courseware.getDescription() != null 
                            ? courseware.getDescription() : "课件内容加载中...")
                        .build())
                    .build()
            ))
            .build();
        
        return CoursewareRenderData.builder()
            .courseware(courseware)
            .pages(List.of(textPage))
            .adaptiveConfig(AdaptiveStrategy.disabled())
            .isFallback(true)
            .build();
    }
```

```java
        List<PageFlowStat> flows = interactionLogMapper
            .getPageFlowStats(coursewareId, start, end);
        
        Map<String, Double> dropOffRates = new LinkedHashMap<>();
        
        for (PageFlowStat flow : flows) {
            long reachedCount = flow.getReachedCount();
            long proceededCount = flow.getProceededCount();
            double dropRate = reachedCount == 0 ? 0 : 
                (double) (reachedCount - proceededCount) / reachedCount;
            dropOffRates.put(flow.getPageKey(), dropRate);
        }
        
        return dropOffRates;
    }
}
```

## 15. 版本管理策略

### 15.1 课件版本控制

```java
@Service
public class CoursewareVersionService {
    
    /**
     * 发布新版本
     * - 从当前 DRAFT 创建新版本
     * - 保留旧版本数据供正在学习中的用户继续使用
     * - 新用户默认使用最新版本
     */
    @Transactional
    public PublishResult publish(Long coursewareId) {
        Courseware draft = coursewareRepo.findByIdAndStatus(coursewareId, "DRAFT")
            .orElseThrow(() -> new IllegalStateException("No draft to publish"));
        
        // 获取当前最新版本
        Integer currentVersion = coursewareRepo.getLatestPublishedVersion(coursewareId);
        Integer newVersion = (currentVersion == null ? 0 : currentVersion) + 1;
        
        // 创建新发布版本
        draft.setVersion(newVersion);
        draft.setStatus("PUBLISHED");
        draft.setPublishedAt(LocalDateTime.now());
        coursewareRepo.save(draft);
        
        // 清除渲染缓存
        cacheService.evictRenderCache(coursewareId, newVersion);
        
        // 发布事件
        eventPublisher.publishEvent(new CoursewarePublishedEvent(
            coursewareId, newVersion, draft.getTitle(),
            draft.getKnowledgePointIds(), draft.getChapterIds()
        ));
        
        return PublishResult.success(newVersion);
    }
    
    /**
     * 版本兼容性策略:
     * 1. 正在学习旧版本的会话不受影响（保持旧版本数据）
     * 2. 新会话默认使用最新版本
     * 3. 如果旧版本已下线，向正在学习的用户展示"内容已更新，可继续学习旧版或切换新版"
     */
    public VersionCompatibility resolveVersion(Long coursewareId, Long userId, 
                                                Long existingSessionId) {
        if (existingSessionId != null) {
            // 恢复已有会话：使用会话记录的版本
            Integer sessionVersion = sessionRepo.findById(existingSessionId)
                .map(CoursewareSession::getCoursewareVersion)
                .orElse(null);
            if (sessionVersion != null) {
                return VersionCompatibility.continueWithVersion(sessionVersion);
            }
        }
        
        // 新会话：使用最新发布版本
        Integer latestVersion = coursewareRepo.getLatestPublishedVersion(coursewareId);
        return VersionCompatibility.useLatest(latestVersion);
    }
}
```

## 16. 总结

互动课件编排引擎是 PrimeTop 平台连接"内容"与"学习体验"的关键枢纽。通过将课件完全数据化（JSON Schema 驱动），实现了：

1. **灵活编排**：创作者通过组合交互组件和分支规则，设计适应不同学段、学科的互动学习体验，无需开发介入。
2. **组件化扩展**：新交互类型通过插件注册即可接入，不影响已有课件。
3. **自适应路径**：基于学生实时表现的分支决策，让同一份课件服务不同水平的学生。
4. **精确追踪**：页面级和组件级的进度追踪与交互日志，为学情分析和内容优化提供高质量数据。
5. **多端一致**：课件即数据，确保 Flutter、Web、小程序端渲染一致。
6. **生产安全**：完整的版本管理、审核流程、校验机制和降级策略，保障内容质量和系统可用性。

本设计文档为开发团队提供了可直接实施的数据模型、API 定义、核心算法和状态流转设计，各子模块可在 MVP 阶段合为单一服务部署，后续按负载情况逐步拆分。
