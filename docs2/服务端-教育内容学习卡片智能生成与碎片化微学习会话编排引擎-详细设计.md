# 服务端-教育内容学习卡片智能生成与碎片化微学习会话编排引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 平台**碎片化学习场景**的核心服务端组件，负责将结构化教育内容（教材章节、知识点解析、题目解析、作文素材等）自动转化为**多类型交互式学习卡片**，并基于学生当前学习状态、间隔重复算法和时间约束，编排出 1~5 分钟可完成的**微学习会话**。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| **内容转化** | 将教材章节/知识点自动拆分为原子级学习卡片，每张卡片聚焦单一知识点 |
| **多类型支持** | 支持概念卡、问答卡、填空卡、对比卡、序列卡、公式卡、图表卡等 ≥ 8 种卡片类型 |
| **自适应编排** | 根据学生掌握度、遗忘曲线、可用时长智能选择并排序卡片 |
| **碎片时间利用** | 支持学生利用 1~5 分钟碎片时间完成有效学习 |
| **数据闭环** | 卡片级别学习行为采集，反哺知识追踪模型和推荐系统 |

### 1.3 适用范围

| 维度 | 范围 |
| --- | --- |
| 学段 | 小学 ~ 高中（幼儿阶段由拼音识字启蒙模块单独处理） |
| 学科 | 全学科（语文、数学、英语、物理、化学、生物、历史、地理、政治） |
| 触发场景 | 主动微学习、间隔复习提醒、章节学后巩固、考前快速回顾 |
| 调用方 | 客户端学习卡片组件、首页推荐、学习计划执行、复习提醒推送 |

### 1.4 与已有模块的边界

| 已有模块 | 边界划分 |
| --- | --- |
| 客户端-学习闪卡记忆系统与间隔复习卡片交互组件 | 客户端负责卡片**渲染与交互**；本引擎负责卡片**生成与编排决策** |
| 服务端-教育内容智能摘要生成与知识要点卡片自动萃取引擎 | 摘要引擎从长文本中**萃取要点**；本引擎将要点**转化为多类型交互卡片**并管理学习闭环 |
| 服务端-间隔重复算法与遗忘曲线复习调度引擎 | 间隔重复引擎提供**调度算法**；本引擎负责**卡片内容选择与会话组装** |
| 服务端-学习会话内容编排与学习节奏智能控制引擎 | 学习会话引擎负责**完整学习 session**（15~45min）；本引擎负责**微学习 session**（1~5min） |

### 3.1 核心数据模型

#### 3.1.1 card_pool（学习卡片池）

```sql
CREATE TABLE card_pool (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    card_uuid       VARCHAR(36) NOT NULL UNIQUE COMMENT '卡片唯一标识UUID',
    source_type     VARCHAR(32) NOT NULL COMMENT '来源类型: CHAPTER/KNOWLEDGE_POINT/QUESTION/ESSAY_MATERIAL/CUSTOM',
    source_id       BIGINT NOT NULL COMMENT '来源ID(章节ID/知识点ID/题目ID等)',
    subject_code    VARCHAR(16) NOT NULL COMMENT '学科编码',
    grade_code      VARCHAR(16) NOT NULL COMMENT '年级编码',
    knowledge_point_ids JSON NOT NULL COMMENT '关联知识点ID列表',
    card_type       VARCHAR(32) NOT NULL COMMENT '卡片类型: CONCEPT/QA/FILL_BLANK/COMPARE/SEQUENCE/FORMULA/CHART/MNEMONIC',
    card_subtype    VARCHAR(64) DEFAULT NULL COMMENT '卡片子类型(如: 定义卡/性质卡/例题卡)',
    
    -- 卡片内容(多语言/多难度)
    front_content   JSON NOT NULL COMMENT '正面内容(问题/提示)',
    back_content    JSON NOT NULL COMMENT '背面内容(答案/解析)',
    metadata        JSON DEFAULT NULL COMMENT '扩展元数据(图片URL/音频URL/公式LaTeX等)',
    
    -- 难度与分级
    difficulty_level TINYINT NOT NULL DEFAULT 3 COMMENT '难度等级 1-5',
    cognitive_level  VARCHAR(32) DEFAULT NULL COMMENT '布鲁姆认知层级: REMEMBER/UNDERSTAND/APPLY/ANALYZE/EVALUATE/CREATE',
    
    -- 生命周期
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' COMMENT 'DRAFT/ACTIVE/DEPRECATED/ARCHIVED',
    version         INT NOT NULL DEFAULT 1 COMMENT '卡片版本号',
    
    -- 统计
    total_reviews   INT NOT NULL DEFAULT 0 COMMENT '累计复习次数',
    avg_recall_rate DECIMAL(4,3) DEFAULT 0.000 COMMENT '平均回忆率(正确回忆次数/总复习次数)',
    avg_time_spent_ms INT NOT NULL DEFAULT 0 COMMENT '平均学习耗时(毫秒)',
    quality_score   DECIMAL(4,3) DEFAULT 0.500 COMMENT '质量评分 0-1(综合准确率/清晰度/有效性)',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    created_by      VARCHAR(64) NOT NULL DEFAULT 'SYSTEM' COMMENT '创建者(SYSTEM/AI/编辑工号)',
    
    INDEX idx_source (source_type, source_id),
    INDEX idx_subject_grade (subject_code, grade_code),
    INDEX idx_kp (CAST(knowledge_point_ids AS CHAR(256))),
    INDEX idx_type_difficulty (card_type, difficulty_level),
    INDEX idx_status_quality (status, quality_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习卡片池';
```

```java
/** 卡片类型 */
public enum CardType {
    CONCEPT("概念卡", "展示一个概念的定义和解释"),
    QA("问答卡", "提问-回答形式"),
    FILL_BLANK("填空卡", "挖空关键信息让用户填写"),
    COMPARE("对比卡", "对比两个易混淆概念"),
    SEQUENCE("序列卡", "按正确顺序排列步骤/事件"),
    FORMULA("公式卡", "展示公式并解释各变量含义"),
    CHART("图表卡", "基于图表/图片提问"),
    MNEMONIC("记忆口诀卡", "辅助记忆的口诀/联想");
}

/** 卡片来源类型 */
public enum CardSourceType {
    CHAPTER,          // 教材章节
    KNOWLEDGE_POINT,  // 知识点
    QUESTION,         // 题目
    ESSAY_MATERIAL,   // 作文素材
    MISTAKE,          // 错题
    CUSTOM            // 自定义
}

/** 微学习会话类型 */
public enum SessionType {
    QUICK_REVIEW,        // 快速复习(今日到期卡片)
    SPACED_REPETITION,   // 间隔重复(严格按SM-2调度)
    CHAPTER_REINFORCE,   // 章节巩固(学完章节后)
    EXAM_PREP,           // 考前回顾(考试前快速回顾)
    RANDOM_EXPLORE,      // 随机探索(自主学习新内容)
    WEAKNESS_DRILL,      // 薄弱知识点专项
}

/** 复习评级(SM-2兼容) */
public enum ReviewRating {
    AGAIN(0, "忘了", "0分——完全忘记，需要重新学习"),
    HARD(3, "困难", "3分——想了很久才回忆起来"),
    GOOD(4, "良好", "4分——经过思考后回忆起来"),
    EASY(5, "简单", "5分——瞬间回忆起来");
}
```

### 4.6 错误码定义

| 错误码 | 含义 | HTTP状态码 |
| --- | --- | --- |
| `ML_001` | 无可用卡片（学生知识点未关联卡片） | 200 (空结果) |
| `ML_002` | 会话不存在或已过期 | 404 |
| `ML_003` | 会话状态不允许操作（如已完成的会话不能再提交） | 409 |
| `ML_004` | 卡片不属于当前会话 | 400 |
| `ML_005` | 卡片生成任务失败（AI超时/内容不足） | 500 |
| `ML_006` | 超出单日新卡学习上限 | 429 |
| `ML_007` | 评分数据格式错误 | 400 |

## 5. 核心流程设计

### 5.1 卡片生成流程

```
┌──────────────┐     ┌─────────────────┐     ┌──────────────────┐
│  内容源       │────▶│  内容预处理      │────▶│  卡片类型路由     │
```

#### 5.1.1 内容分段与原子化

系统首先将原始内容（如一个教材章节）拆分为**原子级学习单元**，每个单元应：
- 聚焦一个单一知识点
- 包含足够的上下文用于生成卡片
- 长度控制在 200~800 字

```java
public class ContentAtomizer {
    
    /**
     * 将章节内容拆分为原子学习单元
     */
    public List<ContentAtom> atomize(ChapterContent chapter) {
        List<ContentAtom> atoms = new ArrayList<>();
        
        // 1. 按教材结构提取自然分段（小节/知识点块）
        List<ContentBlock> blocks = chapter.getStructuredBlocks();
        
        for (ContentBlock block : blocks) {
            // 2. 如果块过长，进一步按语义边界拆分
            if (block.getTextLength() > 800) {
                atoms.addAll(splitBySemanticBoundary(block));
            } else if (block.getTextLength() > 50) {
                atoms.add(toContentAtom(block, chapter));
            }
        }
        
        // 3. 为每个原子标注知识点ID
        atoms.forEach(atom -> 
            atom.setKnowledgePointIds(
                knowledgePointService.matchKnowledgePoints(atom.getText(), 
                    chapter.getSubjectCode())
            )
        );
        
        return atoms;
    }
}
```

```java
public class CardTypeRouter {
    
    public List<CardTypeSpec> route(ContentAtom atom) {
        List<CardTypeSpec> specs = new ArrayList<>();
        String text = atom.getText();
        
        // 规则1: 包含定义/性质 → 概念卡

            specs.add(new CardTypeSpec(CardType.CONCEPT));
        }

        List<String> formulas = extractFormulas(text);
        if (!formulas.isEmpty()) {
            specs.add(new CardTypeSpec(CardType.FORMULA, formulas));
        }
        
        // 规则3: 包含对比/区别 → 对比卡
        if (containsPattern(text, List.of("区别", "不同", "相比", "反之"))) {
            specs.add(new CardTypeSpec(CardType.COMPARE));
        }
        
        // 规则4: 包含步骤/过程 → 序列卡
        if (containsPattern(text, List.of("第一步", "首先", "步骤", "过程")) 
            || hasNumberedSteps(text)) {
            specs.add(new CardTypeSpec(CardType.SEQUENCE));
        }
        
        // 规则5: 关键术语 → 填空卡（挖空关键词）
        List<String> keyTerms = extractKeyTerms(atom);
        if (!keyTerms.isEmpty()) {
            specs.add(new CardTypeSpec(CardType.FILL_BLANK, keyTerms));
        }
        
        // 规则6: 默认生成问答卡
        specs.add(new CardTypeSpec(CardType.QA));
        
        // 限制每段落最多生成 2 种卡片，避免卡片爆炸
        return specs.stream().limit(2).collect(Collectors.toList());
    }
```

```java
public class CardQualityValidator {
    
    private final FactCheckerClient factChecker;
    private final ContentModerationClient contentModeration;
    private final CardDuplicateDetector duplicateDetector;
    
    /**
     * 校验生成的卡片质量
     * @return QualityResult 包含通过/拒绝/修改建议
     */
    public QualityResult validate(Card card, ContentAtom sourceAtom) {
        QualityResult result = new QualityResult();
        
        // 1. 格式校验
        if (!validateFormat(card)) {
            return QualityResult.reject("FORMAT_INVALID", "卡片格式不合法");
        }
        
        // 2. 事实正确性校验（调用事实校验服务）
        FactCheckResult factCheck = factChecker.check(
            card.getBackContentSummary(), 
            sourceAtom.getText()
        );
        if (factCheck.hasErrors()) {
            return QualityResult.reject("FACT_ERROR", factCheck.getErrorMessage());
        }
        
        // 3. 适龄性检查
        AgeAppropriatenessResult ageCheck = checkAgeAppropriateness(
            card, sourceAtom.getGradeCode()
        );
        if (!ageCheck.isAppropriate()) {
            return QualityResult.modify(ageCheck.getSuggestedRevision());
        }
        
        // 4. 去重检查
        DuplicateResult dupCheck = duplicateDetector.check(card);
        if (dupCheck.isDuplicate()) {
            return QualityResult.reject("DUPLICATE", 
                "与已有卡片相似度过高: " + dupCheck.getSimilarCardId());
        }
        
        // 5. 难度合理性检查
        if (!validateDifficultyConsistency(card, sourceAtom)) {
            result.addWarning("DIFFICULTY_MISMATCH", "难度标注可能不合理");
        }
        
        result.pass();
        return result;
    }
    
    private AgeAppropriatenessResult checkAgeAppropriateness(
            Card card, String gradeCode) {
        // 基于年级词汇表和句子复杂度检查
        // 使用预设的年级词汇表和可读性公式
        return ageAppropriatenessService.evaluate(card, gradeCode);
    }
}
```

```java
public class CardSelector {
    
    /**
     * 根据会话类型选择卡片
     */
    public List<Card> select(SessionContext ctx, List<CardCandidate> pool) {
        switch (ctx.getSessionType()) {
            case QUICK_REVIEW:
                return selectForQuickReview(ctx, pool);
            case SPACED_REPETITION:
                return selectForSpacedRepetition(ctx, pool);
            case CHAPTER_REINFORCE:
                return selectForChapterReinforce(ctx, pool);
            case EXAM_PREP:
                return selectForExamPrep(ctx, pool);
            case WEAKNESS_DRILL:
                return selectForWeaknessDrill(ctx, pool);
            case RANDOM_EXPLORE:
                return selectForRandomExplore(ctx, pool);
            default:
                return selectForQuickReview(ctx, pool);
        }
    }
    
    /**
     * 快速复习：优先到期卡片 + 少量新卡
     */
    private List<Card> selectForQuickReview(
            SessionContext ctx, List<CardCandidate> pool) {
        int targetCount = ctx.getMaxCards();
        int newCardBudget = calculateNewCardBudget(ctx);
        
        // 1. 获取到期复习卡片（优先高优先级）
        List<CardCandidate> dueCards = pool.stream()
            .filter(c -> c.getStatus() == CardStatus.REVIEW 
                      && c.isDueToday())
            .sorted(Comparator
                .comparing(CardCandidate::getOverdueDays).reversed()
                .thenComparing(CardCandidate::getPriority))
            .limit(targetCount - newCardBudget)
            .collect(Collectors.toList());
        
        // 2. 补充新卡（不超过每日新卡上限）
        int remainingSlots = targetCount - dueCards.size();
        if (remainingSlots > 0 && newCardBudget > 0) {
            List<CardCandidate> newCards = pool.stream()
                .filter(c -> c.getStatus() == CardStatus.NEW)
                .sorted(Comparator.comparing(CardCandidate::getPriority))
                .limit(Math.min(remainingSlots, newCardBudget))
                .collect(Collectors.toList());
            dueCards.addAll(newCards);
        }
        
        return dueCards.stream()
            .map(CardCandidate::toCard)
            .collect(Collectors.toList());
    }
    
    /**
     * 计算今日新卡预算
     * 基于学生等级和已有表现动态调整
     */
    private int calculateNewCardBudget(SessionContext ctx) {
        int baseBudget = 20; // 默认每日新卡上限
        int todayNewLearned = ctx.getTodayNewCardsLearned();
        
        // 根据掌握度调整: 掌握度高的学生可以学更多新卡
        double masteryFactor = ctx.getAvgMastery() > 0.7 ? 1.5 : 1.0;
        int adjustedBudget = (int) (baseBudget * masteryFactor);
        
        return Math.max(0, adjustedBudget - todayNewLearned);
    }
    
    /**
     * 薄弱知识点专项：选择低掌握度知识点关联的卡片
     */
    private List<Card> selectForWeaknessDrill(
            SessionContext ctx, List<CardCandidate> pool) {
        Set<Long> weakKpIds = ctx.getWeakKnowledgePoints(); // mastery < 0.5
        
        return pool.stream()
            .filter(c -> c.getKnowledgePointIds().stream()
                .anyMatch(weakKpIds::contains))
            .filter(c -> c.getStatus() != CardStatus.MASTERED)
            .sorted(Comparator
                .comparing(CardCandidate::getDifficultyLevel)  // 由易到难
                .thenComparing(c -> c.getMasteryLevel()))       // 低掌握度优先
            .limit(ctx.getMaxCards())
            .map(CardCandidate::toCard)
            .collect(Collectors.toList());
    }
}
```

#### 5.2.2 卡片排序引擎

```java
public class CardSequencer {
    
    /**
     * 最优排序：基于间隔效应、难度递进和注意力曲线
     * 
     * 排序原则：
     * 1. 不同知识点的卡片交替出现（避免同知识点连续）
     * 2. 难度呈波浪式递进（易→中→难→中→易→中→难...）
     * 3. 新卡穿插在复习卡之间（不在开头或结尾连续出现）
     * 4. 相似卡片类型不连续（避免连续填空或连续问答）
     */
    public List<Card> sequence(List<Card> cards, SessionContext ctx) {
        if (cards.size() <= 2) return cards;
        
        // 1. 分组
        Map<Boolean, List<Card>> byNewness = cards.stream()
            .collect(Collectors.partitioningBy(
                c -> c.getStatus() == CardStatus.NEW));
        List<Card> newCards = byNewness.get(true);
        List<Card> reviewCards = byNewness.get(false);
        
        // 2. 按难度排序
        reviewCards.sort(Comparator.comparing(Card::getDifficultyLevel));
        newCards.sort(Comparator.comparing(Card::getDifficultyLevel));
        
        // 3. 波浪式难度编排
        List<Card> sequenced = new ArrayList<>();
        int reviewIdx = 0, newIdx = 0;
        int totalCards = cards.size();
        
        for (int i = 0; i < totalCards; i++) {
            double progress = (double) i / totalCards;
            int targetDifficulty = computeTargetDifficulty(progress, ctx);
            
            // 尝试从复习卡或新卡中选择最接近目标难度的
            Card best = pickClosestDifficulty(
                reviewCards, reviewIdx, 
                newCards, newIdx, 
                targetDifficulty, 
                sequenced  // 避免与上一张同知识点
            );
            
            sequenced.add(best);
            if (reviewCards.contains(best)) reviewIdx++;
            else newIdx++;
        }
        
        return sequenced;
    }
    
    /**
     * 基于学习进度计算目标难度
     * 开头偏简单（热身），中间偏难（核心），结尾偏简单（收尾）
     */
    private int computeTargetDifficulty(double progress, SessionContext ctx) {
        // 钟形曲线：sin函数映射
        double bell = Math.sin(progress * Math.PI);
        int minDiff = ctx.getStudentLevel() == StudentLevel.BEGINNER ? 1 : 2;
        int maxDiff = ctx.getStudentLevel() == StudentLevel.ADVANCED ? 5 : 4;
        
        return (int) Math.round(minDiff + bell * (maxDiff - minDiff));
    }
}
```

### 5.3 复习结果处理与 SM-2 更新流程

```java
public class ReviewResultProcessor {
    
    private final CardStudentStateManager stateManager;
    private final KnowledgeTrackingService ktService;
    private final EventPublisher eventPublisher;
    
    /**
     * 处理单张卡片的复习结果
     */
    @Transactional
    public ReviewResult process(
            Long studentId, Long cardId, 
            ReviewRating rating, int responseMs, 
            Long sessionId) {
        
        // 1. 读取当前状态
        CardStudentState state = stateManager.getOrCreate(studentId, cardId);
        double previousMastery = state.getMasteryLevel();
        
        // 2. SM-2 算法更新间隔
        SM2Result sm2 = sm2Algorithm.update(
            state.getEaseFactor(),
            state.getIntervalDays(),
            state.getRepetitions(),
            rating.getQuality()  // 0, 3, 4, 5
        );
        
        // 3. 更新掌握度（Bayesian知识追踪近似）
        double newMastery = updateMastery(
            previousMastery, 
            rating,
            responseMs,
            state.getRepetitions()
        );
        
        // 4. 持久化状态
        state.setEaseFactor(sm2.getEaseFactor());
        state.setIntervalDays(sm2.getIntervalDays());
        state.setRepetitions(sm2.getRepetitions());
        state.setNextReviewDate(LocalDate.now().plusDays(sm2.getIntervalDays()));
        state.setMasteryLevel(newMastery);
        state.setStatus(determineStatus(sm2, newMastery));
        stateManager.save(state);
        
        // 5. 写入复习日志
        logReview(studentId, cardId, sessionId, rating, 
                  responseMs, previousMastery, newMastery);
        
        // 6. 发布事件（供知识追踪服务等消费）
        eventPublisher.publish(new CardReviewedEvent(
            studentId, cardId, rating, newMastery, sessionId
        ));
        
        // 7. 更新卡片池统计（异步）
        eventPublisher.publish(new CardStatsUpdateEvent(
            cardId, rating, responseMs
        ));
        
        return new ReviewResult(
            newMastery, 
            newMastery - previousMastery,
            state.getNextReviewDate(),
            sm2.getIntervalDays()
        );
    }
    
    /**
     * 掌握度更新公式
     * 结合贝叶斯知识追踪(BKT)与响应时间
     */
    private double updateMastery(
            double prior, ReviewRating rating, 
            int responseMs, int repetitions) {
        
        // BKT参数
        double pTransit = 0.1;   // 学习转移概率
        double pSlip = 0.1;      // 失误概率
        double pGuess = 0.25;    // 猜对概率
        
        double posterior;
        if (rating == ReviewRating.AGAIN) {
            // 回答错误：P(known|wrong) 
            posterior = (prior * pSlip) / 
                        (prior * pSlip + (1 - prior) * (1 - pGuess));
        } else {
            // 回答正确：P(known|correct)
            posterior = (prior * (1 - pSlip)) / 
                        (prior * (1 - pSlip) + (1 - prior) * pGuess);
            // 考虑学习转移
            posterior = posterior + (1 - posterior) * pTransit;
        }
        
        // 响应时间修正：响应过慢降低掌握度增益
        if (rating != ReviewRating.AGAIN && responseMs > 10000) {
            posterior *= 0.9; // 慢速回答降低10%置信度
        }
        
        // 重复次数修正：多次正确后更稳定
        double stabilityBonus = Math.min(0.05, repetitions * 0.01);
        if (rating == ReviewRating.GOOD || rating == ReviewRating.EASY) {
            posterior = Math.min(0.99, posterior + stabilityBonus);
        }
        
        return Math.round(posterior * 1000) / 1000.0;
    }
}
```

## 6. 关键算法设计

### 6.1 SM-2 间隔重复算法（适配教育场景）

```java
public class SM2Algorithm {
    
    /**
     * SM-2 算法核心实现（Anki风格优化版）
     * 
     * @param easeFactor  当前宽松因子 (1.3~2.8)
     * @param intervalDays 当前间隔天数
     * @param repetitions  连续正确次数
     * @param quality      评分质量 (0=AGAIN, 3=HARD, 4=GOOD, 5=EASY)
     * @return SM2Result 包含新的easeFactor, intervalDays, repetitions
     */
    public SM2Result update(double easeFactor, int intervalDays, 
                            int repetitions, int quality) {
        if (quality < 3) {
            // AGAIN: 重置
            return new SM2Result(
                Math.max(1.3, easeFactor - 0.2),  // 降低easeFactor
                1,                                   // 重置间隔为1天
                0                                    // 重置连续次数
            );
        }
        
        // 更新 ease factor
        double newEF = easeFactor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02));
        newEF = Math.max(1.3, Math.min(2.8, newEF));
        
        // 计算新间隔
        int newInterval;
        int newReps = repetitions + 1;
        
        if (repetitions == 0) {
            newInterval = (quality == 5) ? 2 : 1;  // EASY给2天
        } else if (repetitions == 1) {
            newInterval = (quality == 5) ? 6 : 3;
        } else {
            // 后续间隔 = 前次间隔 × easeFactor
            newInterval = (int) Math.round(intervalDays * newEF);
            
            // HARD评级特殊处理：间隔 × 1.2（比GOOD短）
            if (quality == 3) {
                newInterval = Math.max(1, (int) (intervalDays * 1.2));
            }
            // EASY评级特殊处理：额外加成
            if (quality == 5) {
                newInterval = (int) (newInterval * 1.3);
            }
        }
        
        // 加入随机抖动 ±10%，避免卡片扎堆到期
        double jitter = 0.9 + ThreadLocalRandom.current().nextDouble(0.2);
        newInterval = Math.max(1, (int) (newInterval * jitter));
        
        return new SM2Result(newEF, newInterval, newReps);
    }
}
```

### 6.2 卡片多样性保障算法

```java
public class CardDiversifier {
    
    /**
     * 确保会话内卡片多样性
     * - 不连续出现同一知识点
     * - 不连续出现同一卡片类型
     * - 新卡/复习卡交替
     */
    public List<Card> diversify(List<Card> sequenced) {
        if (sequenced.size() <= 3) return sequenced;
        
        List<Card> result = new ArrayList<>();
        result.add(sequenced.get(0));
        
        for (int i = 1; i < sequenced.size(); i++) {
            Card candidate = sequenced.get(i);
            Card prev = result.get(result.size() - 1);
            
            if (sharesKnowledgePoint(candidate, prev) 
                    || candidate.getCardType() == prev.getCardType()) {
                // 尝试找到下一个不冲突的卡片交换
                int swapIdx = findSwapCandidate(sequenced, i + 1, candidate, prev);
                if (swapIdx != -1) {
                    Collections.swap(sequenced, i, swapIdx);
                    candidate = sequenced.get(i);
                }
                // 找不到也接受，不强求
            }
            result.add(candidate);
        }
        
        return result;
    }
    
    private int findSwapCandidate(List<Card> cards, int fromIdx, 
                                   Card current, Card prev) {
        for (int i = fromIdx; i < cards.size(); i++) {
            Card candidate = cards.get(i);
            if (!sharesKnowledgePoint(candidate, prev) 
                    && candidate.getCardType() != prev.getCardType()
                    && !sharesKnowledgePoint(candidate, current)) {
                return i;
            }
        }
        return -1;
    }
}
```

## 8. 异步任务与批处理

### 8.1 卡片批量生成任务

```java
/**
 * 定时/手动触发的卡片批量生成任务
 * 场景：新教材章节上线、知识点体系更新、题库大批量导入后
 */
@Component
public class CardBatchGenerationJob {
    
    @Scheduled(cron = "0 0 2 * * MON")  // 每周一凌晨2点
    public void generateForNewChapters() {
        // 1. 查找缺少卡片的章节
        List<Long> chapterIds = chapterRepository.findChaptersWithoutCards(
            LocalDate.now().minusDays(7));
        
        // 2. 分批提交生成任务
        for (Long chapterId : chapterIds) {
            asyncTaskExecutor.submit(() -> {
                try {
                    generateCardsForChapter(chapterId);
                } catch (Exception e) {
                    log.error("卡片生成失败 chapterId={}", chapterId, e);
                    alertService.send("card_generation_failed", 
                        Map.of("chapterId", chapterId, "error", e.getMessage()));
                }
            });
        }
    }
    
    @Transactional
    void generateCardsForChapter(Long chapterId) {
        ChapterContent chapter = chapterService.getContent(chapterId);
        List<ContentAtom> atoms = contentAtomizer.atomize(chapter);
        
        List<Card> generated = new ArrayList<>();
        for (ContentAtom atom : atoms) {
            List<CardTypeSpec> typeSpecs = cardTypeRouter.route(atom);
            for (CardTypeSpec spec : typeSpecs) {
                // 限流: 控制LLM调用频率
                rateLimiter.acquire();
                
                Card card = cardGenerator.generate(atom, spec);
                QualityResult qr = qualityValidator.validate(card, atom);
                
                if (qr.isPassed()) {
                    card.setStatus(CardStatus.ACTIVE);
                    cardPoolRepository.save(card);
                    generated.add(card);
                } else if (qr.isModifiable()) {
                    Card revised = cardGenerator.revise(card, qr.getSuggestions());
                    cardPoolRepository.save(revised);
                    generated.add(revised);
                }
                // 拒绝的卡片不入库
            }
        }
        
        log.info("章节{}生成{}张卡片", chapterId, generated.size());
        
        // 发布事件通知索引服务
        eventPublisher.publish(new CardsGeneratedEvent(chapterId, 
            generated.stream().map(Card::getId).collect(Collectors.toList())));
    }
}
```

```java
/**
 * 每日凌晨预计算所有学生的到期卡片
 * 避免高峰期实时查询压力
 */
@Component
public class DailyDueCardPrecomputeJob {
    
    @Scheduled(cron = "0 0 3 * * *")  // 每日凌晨3点
    public void precompute() {
        int pageSize = 500;
        long lastStudentId = 0;
        
        while (true) {
            List<Long> studentIds = studentRepository
                .findActiveStudentIdsAfter(lastStudentId, pageSize);
            if (studentIds.isEmpty()) break;
            
            for (Long studentId : studentIds) {
                Set<Long> dueCardIds = cardStudentStateRepository
                    .findDueCardIds(studentId, LocalDate.now());
                
                // 写入Redis，TTL 20小时
                if (!dueCardIds.isEmpty()) {
                    redisTemplate.opsForSet().add(
                        "card:today:due:" + studentId,
                        dueCardIds.toArray()
                    );
                    redisTemplate.expire(
                        "card:today:due:" + studentId,
                        Duration.ofHours(20)
                    );
                }
            }
            
            lastStudentId = studentIds.get(studentIds.size() - 1);
        }
    }
}
```

| 场景 | 错误类型 | 处理策略 |
| --- | --- | --- |

| Redis 缓存不可用 | 缓存异常 | 降级到数据库查询 + 限流 |
| 知识追踪服务不可用 | 依赖服务异常 | 使用缓存的掌握度数据 + 标记为stale |
| 间隔重复引擎不可用 | 依赖服务异常 | 使用简化SM-2本地计算 |
| 学生请求频率过高 | 限流 | 返回429 + 提示"休息一下" |

```java
@Aspect
@Component
public class CardServiceFallbackAspect {
    
    @Around("execution(* ..CardSessionService.*(..))")
    public Object fallback(ProceedingJoinPoint pjp) throws Throwable {
        try {
            return pjp.proceed();
        } catch (LLMTimeoutException e) {
            log.warn("LLM超时，降级到模板生成");
            return generateWithTemplate(pjp.getArgs());

            return queryFromDatabase(pjp.getArgs());
        } catch (KnowledgeTrackingUnavailableException e) {
            log.warn("知识追踪不可用，使用缓存数据");
            return useCachedMastery(pjp.getArgs());
        }
    }
    
    /**
     * 熔断器：当LLM连续失败时，自动切换到模板模式
     */
    @CircuitBreaker(fallbackMethod = "templateFallback", 
                    failureRateThreshold = 50,
                    waitDurationInOpenState = Duration.ofMinutes(5))
    public Card generateCardWithLLM(ContentAtom atom, CardTypeSpec spec) {
        return llmCardGenerator.generate(atom, spec);
    }
    
    public Card templateFallback(ContentAtom atom, CardTypeSpec spec) {
        // 使用预设模板填充，不调用LLM
        return templateCardGenerator.generate(atom, spec);
    }
```
