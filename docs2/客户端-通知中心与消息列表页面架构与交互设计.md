# 客户端-通知中心与消息列表页面架构与交互设计

> 版本：v1.0 | 日期：2026-05-28 | 模块归属：客户端页面层
> 依赖：通知中心与站内消息系统（服务端）、消息与推送服务、客户端路由与深链接系统

## 1. 模块概述

### 1.1 定位与目标

通知中心页面是 PrimeTop 应用内统一的消息收件箱入口，负责将服务端产生的学习提醒、系统公告、互动消息、营销活动等各类通知以清晰、高效、分龄适配的方式呈现给学生、家长和教师用户。

**设计目标：**

1. **一屏可知**：用户打开通知中心后，3 秒内找到最重要的未读消息
2. **分龄适配**：幼儿/小学低年级简化展示，初高中和成人用户提供完整信息密度
3. **即时可达**：应用内实时推送增量通知，Badge 实时同步
4. **高效操作**：批量已读、滑动删除、长按操作等提升处理效率
5. **无障碍友好**：通知内容支持 TTS 朗读，重要通知支持震动提醒

### 1.2 页面入口与导航关系

```
首页（Tab 1）
├── 顶部导航栏 → 通知铃铛图标（Badge 计数） → 点击进入通知中心
│
通知中心页面
├── 四个 Tab：全部 / 学习 / 互动 / 系统
├── 点击通知项 → 跳转目标页面（深链接路由）
│
我的（Tab 5）
├── "消息中心" 菜单项 → 进入通知中心
│
系统推送（APNs/FCM）
├── 点击推送通知 → 唤起应用 → 通知中心（自动定位到对应通知）
```

### 1.3 用户角色视图差异

| 维度 | 学生端 | 家长端 | 教师端 |
|------|--------|--------|--------|
| 默认 Tab | 学习 | 互动 | 互动 |
| 高频通知 | 学习提醒、错题复习、成就解锁 | 孩子学习摘要、时长预警 | 班级动态、学生提问 |
| 隐藏类别 | 营销类（青少年模式关闭时展示） | 无 | 无 |
| Badge 展示 | 全部未读数 | 全部未读数 | 全部未读数 |
| 操作权限 | 标记已读、删除 | 标记已读、删除 | 标记已读、删除、置顶 |

```dart
  /// 通知 ID
  final String id;

  /// 通知大类

  /// 通知子类型

  final String title;

  final List<NotificationAction> actions;

  /// 聚合信息
  final NotificationGroupInfo? groupInfo;

/// 通知聚合信息
class NotificationGroupInfo {
  /// 聚合键
  final String groupKey;

  /// 聚合数量

  final String summaryTemplate;

/// 通知跳转
class NotificationLink {
  /// 跳转类型

  final String target;

  /// 跳转参数
  final Map<String, dynamic>? params;
}

/// 通知行动按钮
class NotificationAction {
  final String id;
  final String label;
  final NotificationActionStyle style; // PRIMARY, SECONDARY, DESTRUCTIVE
  final NotificationLink? link;
}
```

### 4.2 实时推送与增量更新

```dart
/// 通知中心 WebSocket 增量更新流程
///
/// 1. 应用启动时建立 WebSocket 连接（复用全局长连接）
/// 2. 收到 notification:new 事件
/// 3. 解析通知数据
/// 4. 判断当前页面状态：
///    a. 通知中心在前台 → 直接插入列表顶部（带动画）
///    b. 通知中心在后台 → 更新本地缓存 + 更新 Badge
/// 5. 更新各 Tab 未读计数
/// 6. 更新首页铃铛 Badge

class NotificationRealtimeHandler {
  final WebSocketManager _ws;
  final NotificationStore _store;
  final BadgeService _badge;

  /// 处理新通知推送
  void handleNewNotification(Map<String, dynamic> data) {
    final notification = NotificationItem.fromJson(data);

    // 1. 写入本地缓存
    _store.insertToTop(notification);

    // 2. 更新未读计数
    _store.incrementUnreadCount(notification.category);

    // 3. 判断页面是否在前台
    if (_isNotificationCenterVisible) {
      // 前台：直接插入列表，带渐入动画
      _animateInsertToTop(notification);
    } else {
      // 后台：更新首页 Badge
      _badge.updateNotificationBadge(_store.totalUnreadCount);
    }

    // 4. 判断是否需要震动/声音提醒
    if (_shouldAlert(notification)) {
      HapticFeedback.lightImpact();
    }
  }
}
```

## 5. 网络请求设计

### 5.1 API 调用清单

| 接口 | 方法 | 路径 | 触发时机 |
|------|------|------|----------|
| 拉取通知列表 | GET | `/api/v1/notifications` | 进入页面、下拉刷新、加载更多 |
| 标记已读（单条） | PUT | `/api/v1/notifications/{id}/read` | 单击通知 |
| 标记全部已读 | PUT | `/api/v1/notifications/read-all` | 点击"全部已读" |
| 删除通知 | DELETE | `/api/v1/notifications/{id}` | 滑动删除 |
| 批量删除 | POST | `/api/v1/notifications/batch-delete` | 长按批量删除 |
| 获取未读计数 | GET | `/api/v1/notifications/unread-count` | 应用启动、Badge 更新 |
| 聚合通知展开 | GET | `/api/v1/notifications/group/{groupKey}` | 点击聚合项展开 |

### 5.2 请求参数与响应格式

#### 拉取通知列表

### 5.4 乐观更新策略

```dart
/// 乐观更新管理器 - 处理本地与服务端状态同步
class OptimisticUpdateManager {
  final NotificationApiService _api;
  final NotificationStore _store;

  /// 标记已读（乐观更新）
  Future<void> markAsRead(String notificationId, NotificationCategory category) async {
    // 1. 保存快照用于回滚
    final snapshot = _store.getById(notificationId);
    final prevUnreadCount = _store.getUnreadCount(category);

    // 2. 立即更新本地状态
    _store.updateLocalReadState(notificationId, isRead: true);
    _store.decrementUnreadCount(category);
    _badge.updateNotificationBadge(_store.totalUnreadCount);

    // 3. 异步同步服务端
    try {
      await _api.markAsRead(notificationId);
    } catch (e) {
      // 4. 失败回滚
      if (snapshot != null) {
        _store.updateLocalReadState(notificationId, isRead: false);
        _store.setUnreadCount(category, prevUnreadCount);
        _badge.updateNotificationBadge(_store.totalUnreadCount);
      }
      logger.warning('标记已读同步失败: $notificationId', error: e);
    }
  }

  /// 删除通知（乐观更新）
  Future<void> deleteNotification(String notificationId, int index, NotificationCategory category) async {
    // 1. 保存快照
    final snapshot = _store.getById(notificationId);
    final wasRead = snapshot?.isRead ?? true;

    // 2. 立即移除
    _store.removeLocal(notificationId);

    // 3. 更新未读计数
    if (!wasRead) {
      _store.decrementUnreadCount(category);
      _badge.updateNotificationBadge(_store.totalUnreadCount);
    }

    // 4. 异步同步
    try {
      await _api.deleteNotification(notificationId);
    } catch (e) {
      // 5. 失败恢复
      if (snapshot != null) {
        _store.restoreAt(index, snapshot);
        if (!wasRead) {
          _store.incrementUnreadCount(category);
          _badge.updateNotificationBadge(_store.totalUnreadCount);
        }
      }
      _showToast('删除失败，请重试');
    }
  }
}
```

### 10.3 未读计数性能

```dart
/// 未读计数使用增量更新，避免全量拉取
///
/// 增量更新场景：
/// 1. WebSocket 推送新通知 → 未读数 +1
/// 2. 用户标记已读 → 未读数 -1
/// 3. 全部已读 → 未读数归零
/// 4. 定时同步（每 5 分钟） → 以服务端值为准
class UnreadCountManager {
  int _total = 0;
  final Map<NotificationCategory, int> _byCategory = {};

  /// 增量更新（WebSocket 推送时）
  void increment(NotificationCategory category) {
    _byCategory[category] = (_byCategory[category] ?? 0) + 1;
    _total++;
    _notifyListeners();
  }

  /// 标记已读
  void decrement(NotificationCategory category) {
    if ((_byCategory[category] ?? 0) > 0) {
      _byCategory[category] = _byCategory[category]! - 1;
    }
    if (_total > 0) _total--;
    _notifyListeners();
  }

  /// 全量同步（定时与服务端对齐）
  void syncFromServer(UnreadCountResponse response) {
    _total = response.total;
    _byCategory[NotificationCategory.learning] = response.learning;
    _byCategory[NotificationCategory.social] = response.social;
    _byCategory[NotificationCategory.system] = response.system;
    _byCategory[NotificationCategory.marketing] = response.marketing;
    _notifyListeners();
  }
}
```

### 11.1 网络错误处理

| 场景 | 处理策略 | 用户感知 |

### 14.1 页面主 Widget

```dart
class NotificationCenterPage extends StatefulWidget {
  const NotificationCenterPage({super.key});

  @override
  State<NotificationCenterPage> createState() => _NotificationCenterPageState();
}

class _NotificationCenterPageState extends State<NotificationCenterPage>
    with SingleTickerProviderStateMixin {
  late final TabController _tabController;
  late final NotificationBloc _bloc;

  static const _tabs = [
    Tab(text: '全部'),
    Tab(text: '学习'),
    Tab(text: '互动'),
    Tab(text: '系统'),
  ];

  @override
  void initState() {
    super.initState();
    _tabController = TabController(length: _tabs.length, vsync: this);
    _bloc = NotificationBloc(
      apiService: context.read<NotificationApiService>(),
      store: context.read<NotificationStore>(),
      badgeService: context.read<BadgeService>(),
    );
    _bloc.add(const NotificationEvent.loadInitial());
  }

  @override
  void dispose() {
    _tabController.dispose();
    _bloc.close();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: NotificationAppBar(
        onMarkAllRead: () => _bloc.add(const NotificationEvent.markAllRead()),
        onSettings: () => context.push('/notification/settings'),
      ),
      body: Column(
        children: [
          // Tab 栏
          _buildTabBar(),

          // Tab 内容
          Expanded(
            child: BlocBuilder<NotificationBloc, NotificationState>(
              bloc: _bloc,
              builder: (context, state) {
                return TabBarView(
                  controller: _tabController,
                  children: [
                    _buildNotificationList(state, null),
                    _buildNotificationList(state, NotificationCategory.learning),
                    _buildNotificationList(state, NotificationCategory.social),
                    _buildNotificationList(state, NotificationCategory.system),
                  ],
                );
              },
            ),
          ),
        ],
      ),
    );
  }

  Widget _buildTabBar() {
    return BlocBuilder<NotificationBloc, NotificationState>(
      bloc: _bloc,
      buildWhen: (prev, curr) => prev.unreadCounts != curr.unreadCounts,
      builder: (context, state) {
        final counts = state.unreadCounts;
        return NotificationTabBar(
          controller: _tabController,
          tabs: [
            _buildTab('全部', counts.total),
            _buildTab('学习', counts.learning),
            _buildTab('互动', counts.social),
            _buildTab('系统', counts.system),
          ],
        );
      },
    );
  }

  Tab _buildTab(String text, int count) {
    return Tab(
      child: Badge(
        isLabelVisible: count > 0,
        label: Text(count > 99 ? '99+' : '$count'),
        child: Text(text),
      ),
    );
  }

  Widget _buildNotificationList(NotificationState state, NotificationCategory? category) {
    final notifications = category == null
        ? state.allNotifications
        : state.notificationsByCategory[category] ?? [];

    if (state.isLoading && notifications.isEmpty) {
      return const NotificationSkeletonList();
    }

    if (state.error != null && notifications.isEmpty) {
      return NotificationErrorWidget(
        errorType: state.error!,
        onRetry: () => _bloc.add(const NotificationEvent.loadInitial()),
      );
    }

    if (notifications.isEmpty) {
      return const NotificationEmptyState();
    }

    return NotificationListView(
      notifications: notifications,
      onTap: (item) => _handleNotificationTap(item),
      onSwipeAction: (item, action) => _handleSwipeAction(item, action),
      onLongPress: (item) => _showActionSheet(item),
      onLoadMore: () => _bloc.add(NotificationEvent.loadMore(category: category)),
      hasMore: state.hasMore,
      isLoadingMore: state.isLoadingMore,
    );
  }

  void _handleNotificationTap(NotificationItem item) {
    // 标记已读
    _bloc.add(NotificationEvent.markRead(item.id));

    // 执行跳转
    if (item.link != null && item.link!.type != NotificationLinkType.none) {
      NotificationNavigator.navigate(context, item);
    }
  }

  void _showActionSheet(NotificationItem item) {
    showModalBottomSheet(
      context: context,
      builder: (context) => NotificationActionSheet(
        notification: item,
        onMarkRead: () {
          _bloc.add(NotificationEvent.setReadState(
            item.id,
            isRead: !item.isRead,
          ));
          Navigator.pop(context);
        },
        onDelete: () {
          _bloc.add(NotificationEvent.delete(item.id));
          Navigator.pop(context);
        },
        onMuteType: () {
          context.push('/notification/settings?type=${item.type.name}');
          Navigator.pop(context);
        },
      ),
    );
  }
}
```

```dart
// State
class NotificationState {
  final Map<NotificationCategory?, List<NotificationItem>> _data;
  final UnreadCounts unreadCounts;
  final bool isLoading;
  final bool isLoadingMore;
  final bool hasMore;
  final NotificationErrorType? error;

  List<NotificationItem> get allNotifications => _data[null] ?? [];
  Map<NotificationCategory, List<NotificationItem>> get notificationsByCategory => {
    for (final entry in _data.entries)
      if (entry.key != null) entry.key!: entry.value,
  };

  const NotificationState({
    required Map<NotificationCategory?, List<NotificationItem>> data,
    required this.unreadCounts,
    this.isLoading = false,
    this.isLoadingMore = false,
    this.hasMore = true,
    this.error,
  }) : _data = data;
}

class UnreadCounts {
  final int total;
  final int learning;
  final int social;
  final int system;
  final int marketing;

  const UnreadCounts({
    this.total = 0,
    this.learning = 0,
    this.social = 0,
    this.system = 0,
    this.marketing = 0,
  });
}
```
