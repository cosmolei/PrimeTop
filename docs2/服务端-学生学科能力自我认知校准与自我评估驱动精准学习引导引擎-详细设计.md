# 服务端-学生学科能力自我认知校准与自我评估驱动精准学习引导引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 学习画像体系中的**元认知能力评估**核心组件。通过收集学生对自己学科能力的自我评估数据，与系统基于真实答题表现计算出的客观掌握度进行对比分析，识别学生的**自我认知偏差**（过度自信/自信不足），并据此驱动精准的学习引导策略。

本引擎解决的核心问题：
- **过度自信学生**（自评远高于实际）：跳过基础练习，直接挑战难题导致挫败；不愿复习"以为会了"的知识点
- **自信不足学生**（自评远低于实际）：反复练习已掌握的内容，不敢挑战能力范围内的难题，学习效率低下
- **元认知能力薄弱**：缺乏对自身学习状态的准确判断，无法有效规划学习

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 自我评估收集 | 提供结构化的学生自评问卷与实时评估采集机制 |
| 认知偏差量化 | 建立自评-客观对比模型，输出偏差分数与置信区间 |
| 校准等级分类 | 将学生分为过度自信、轻度偏高、校准良好、轻度偏低、严重不自信五级 |
| 精准引导策略 | 根据偏差类型与学科特点生成差异化学习推荐 |
| 元认知成长追踪 | 纵向追踪学生自我评估准确性的改善趋势 |
| 多方报告支持 | 为家长、教师、学生自身提供不同视角的认知校准报告 |

### 1.3 适用范围

- **适用学段**：小学三年级及以上（需具备基本的自我评估认知能力），初中、高中全覆盖
- **适用学科**：语文、数学、英语、物理、化学、生物、历史、地理、政治
- **评估粒度**：学科级 → 章节级 → 知识点级（三级递进）
- **评估频次**：定期评估（学期初/中/末）+ 触发式评估（重大考试后、学习阶段性节点）

### 1.4 核心指标定义

| 指标 | 定义 | 计算方式 |
| --- | --- | --- |
| 自评分数 (SR) | 学生对自己在某知识维度的能力评分 | 0-100 分制，10 分为一档 |
| 客观分数 (OR) | 系统基于答题数据计算的客观掌握度 | 知识追踪模型输出的掌握概率 × 100 |
| 校准偏差 (CD) | 自评与客观的绝对差异 | `CD = SR - OR`，正值=过度自信，负值=自信不足 |
| 校准准确度 (CA) | 自评与客观的接近程度 | `CA = 100 - |CD|`，值越高越准确 |
| 校准等级 (CL) | 偏差程度的分类标签 | 基于CD值和阈值的五级分类 |

## 2. 数据结构定义

### 2.1 自我评估记录表 (self_assessment_record)

存储学生每次自我评估的原始数据。

```sql
CREATE TABLE self_assessment_record (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id      BIGINT NOT NULL COMMENT '学生ID',
    assessment_id   VARCHAR(64) NOT NULL COMMENT '评估批次ID，如2026-S1-INIT',
    assessment_type TINYINT NOT NULL COMMENT '评估类型: 1=学期初, 2=期中, 3=期末, 4=考试后触发, 5=阶段节点',
    subject_code    VARCHAR(20) NOT NULL COMMENT '学科编码: CHN/MATH/ENG/PHY/CHEM/BIO/HIS/GEO/POL',
    chapter_id      BIGINT COMMENT '章节ID，NULL表示学科级评估',
    knowledge_point_ids JSON COMMENT '知识点ID列表，支持知识点级评估',
    self_rating     DECIMAL(5,2) NOT NULL COMMENT '自评分数 0-100',
    rating_dimension VARCHAR(30) NOT NULL COMMENT '评估维度: OVERALL/CONCEPT/APPLICATION/PROBLEM_SOLVING/EXAM',
    confidence_level TINYINT NOT NULL COMMENT '置信感受: 1=非常不确定~5=非常确定',
    estimated_correct_rate DECIMAL(5,2) COMMENT '学生预估的答题正确率 0-100',
    estimated_rank_percentile DECIMAL(5,2) COMMENT '学生预估的班级排名百分位 0-100',
    assessment_context JSON COMMENT '评估上下文: 持续时间/设备/场景等',
    submitted_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_student_subject (student_id, subject_code, assessment_type),
    INDEX idx_assessment_batch (assessment_id, student_id),
    INDEX idx_chapter (chapter_id, student_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生自我评估记录';
```

## 4. 核心算法设计

### 4.1 校准偏差计算算法

```python
import math
from enum import Enum
from typing import Optional

class CalibrationLevel(str, Enum):
    OVERCONFIDENT = "OVERCONFIDENT"       # 严重过度自信
    MILDLY_OVER = "MILDLY_OVER"           # 轻度偏高
    CALIBRATED = "CALIBRATED"             # 校准良好
    MILDLY_UNDER = "MILDLY_UNDER"         # 轻度偏低
    UNDERCONFIDENT = "UNDERCONFIDENT"     # 严重自信不足

class CalibrationCalculator:
    """
    认知校准偏差计算引擎
    
    基于 Brier Score 改进的双向校准模型，
    同时考虑偏差方向（over/under）和偏差幅度。
    """
    
    # 校准等级阈值（可根据学段动态调整）
    THRESHOLDS = {
        "PRIMARY": {   # 小学
            "OVER": 15.0,      # CD > 15 → OVERCONFIDENT
            "MILD_OVER": 8.0,  # 8 < CD ≤ 15 → MILDLY_OVER
            "MILD_UNDER": -8.0,
            "UNDER": -15.0
        },
        "MIDDLE": {    # 初中
            "OVER": 18.0,
            "MILD_OVER": 10.0,
            "MILD_UNDER": -10.0,
            "UNDER": -18.0
        },
        "HIGH": {      # 高中
            "OVER": 20.0,
            "MILD_OVER": 12.0,
            "MILD_UNDER": -12.0,
            "UNDER": -20.0
        }
    }
    
    def __init__(self, stage: str = "MIDDLE"):
        self.thresholds = self.THRESHOLDS.get(stage, self.THRESHOLDS["MIDDLE"])
    
    def calculate_calibration(
        self,
        self_rating: float,
        objective_rating: float,
        sample_size: int,
        confidence_interval: Optional[tuple] = None
    ) -> dict:
        """
        计算单个知识维度的校准结果
        
        Args:
            self_rating: 学生自评分数 (0-100)
            objective_rating: 系统客观掌握度 (0-100)
            sample_size: 客观分数基于的答题样本量
            confidence_interval: 客观分数的置信区间 (low, high)
        
        Returns:
            校准结果字典
        """
        # 1. 计算原始校准偏差
        calibration_delta = self_rating - objective_rating
        
        # 2. 计算校准准确度
        calibration_accuracy = max(0.0, 100.0 - abs(calibration_delta))
        
        # 3. 样本量修正（样本不足时对极端偏差进行缓和）
        sample_weight = self._compute_sample_weight(sample_size)
        adjusted_delta = calibration_delta * sample_weight
        
        # 4. 置信区间感知修正
        if confidence_interval:
            ci_low, ci_high = confidence_interval
            # 如果自评落在客观分数的置信区间内，降低偏差等级
            if ci_low <= self_rating <= ci_high:
                adjusted_delta *= 0.5  # 减半偏差，因为在统计噪声范围内
        
        # 5. 确定校准等级
        level = self._determine_level(adjusted_delta)
        
        # 6. 计算偏差严重度（0-1标准化）
        severity = min(1.0, abs(adjusted_delta) / 50.0)
        
        return {
            "self_rating": self_rating,
            "objective_rating": objective_rating,
            "calibration_delta": round(calibration_delta, 2),
            "adjusted_delta": round(adjusted_delta, 2),
            "calibration_accuracy": round(calibration_accuracy, 2),
            "calibration_level": level.value,
            "sample_weight": round(sample_weight, 3),
            "severity": round(severity, 3),
            "reliable": sample_size >= 5  # 样本量>=5才认为结果可靠
        }
    
    def _compute_sample_weight(self, sample_size: int) -> float:
        """
        根据样本量计算修正权重
        样本越多，结果越可信，偏差修正越小
        """
        if sample_size >= 20:
            return 1.0
        elif sample_size >= 10:
            return 0.85
        elif sample_size >= 5:
            return 0.65
        elif sample_size >= 2:
            return 0.40
        else:
            return 0.20  # 单次答题几乎没有统计意义
    
    def _determine_level(self, delta: float) -> CalibrationLevel:
        """根据调整后偏差值确定校准等级"""
        t = self.thresholds
        if delta > t["OVER"]:
            return CalibrationLevel.OVERCONFIDENT
        elif delta > t["MILD_OVER"]:
            return CalibrationLevel.MILDLY_OVER
        elif delta >= t["MILD_UNDER"]:
            return CalibrationLevel.CALIBRATED
        elif delta >= t["UNDER"]:
            return CalibrationLevel.MILDLY_UNDER
        else:
            return CalibrationLevel.UNDERCONFIDENT
```

### 4.2 元认知能力综合评分算法

```python
class MetacognitionScorer:
    """
    元认知能力综合评分器
    
    从四个维度评估学生的元认知能力：
    1. 校准准确度（自评与实际的吻合度）
    2. 区分能力（能否区分会/不会的知识点）
    3. 一致性（多次评估的稳定性）
    4. 改善趋势（校准能力是否在提升）
    """
    
    def compute_metacognition_score(
        self,
        calibration_results: list[dict],
        historical_trends: list[dict] = None
    ) -> dict:
        """
        计算元认知能力综合得分
        
        Returns:
            {
                "total_score": 0-100,
                "dimensions": {
                    "accuracy": float,
                    "discrimination": float,
                    "consistency": float,
                    "improvement": float
                },
                "level": "EXCELLENT/GOOD/AVERAGE/WEAK",
                "insights": [str]
            }
        """
        # 维度1: 校准准确度（平均校准准确度）
        accuracy_scores = [r["calibration_accuracy"] for r in calibration_results]
        accuracy_dim = sum(accuracy_scores) / len(accuracy_scores) if accuracy_scores else 0
        
        # 维度2: 区分能力（不同知识点间自评分的方差 vs 客观分数的方差）
        discrimination_dim = self._compute_discrimination(calibration_results)
        
        # 维度3: 一致性（相似掌握度知识点的自评波动程度）
        consistency_dim = self._compute_consistency(calibration_results)
        
        # 维度4: 改善趋势
        improvement_dim = self._compute_improvement(historical_trends)
        
        # 加权综合
        weights = {
            "accuracy": 0.35,
            "discrimination": 0.25,
            "consistency": 0.20,
            "improvement": 0.20
        }
        total_score = (
            accuracy_dim * weights["accuracy"] +
            discrimination_dim * weights["discrimination"] +
            consistency_dim * weights["consistency"] +
            improvement_dim * weights["improvement"]
        )
        
        # 等级判定
        if total_score >= 80:
            level = "EXCELLENT"
        elif total_score >= 65:
            level = "GOOD"
        elif total_score >= 45:
            level = "AVERAGE"
        else:
            level = "WEAK"
        
        # 生成洞察
        insights = self._generate_insights(
            accuracy_dim, discrimination_dim, consistency_dim, improvement_dim
        )
        
        return {
            "total_score": round(total_score, 1),
            "dimensions": {
                "accuracy": round(accuracy_dim, 1),
                "discrimination": round(discrimination_dim, 1),
                "consistency": round(consistency_dim, 1),
                "improvement": round(improvement_dim, 1)
            },
            "level": level,
            "insights": insights
        }
    
    def _compute_discrimination(self, results: list[dict]) -> float:
        """
        区分能力：学生能否给自己的不同掌握水平打不同的分数
        计算自评分与客观分数的相关系数
        高正相关 = 区分能力好（知道哪些更会、哪些更不会）
        """
        if len(results) < 3:
            return 50.0  # 数据不足返回默认值
        
        sr = [r["self_rating"] for r in results]
        or_ = [r["objective_rating"] for r in results]
        
        correlation = self._pearson_correlation(sr, or_)
        # 相关系数 [-1, 1] → [0, 100]
        return max(0.0, min(100.0, (correlation + 1) * 50))
    
    def _compute_consistency(self, results: list[dict]) -> float:
        """
        一致性：对掌握度相近的知识点，自评分的波动程度
        波动越小，一致性越高
        """
        if len(results) < 3:
            return 60.0
        
        # 按客观分数分组（每10分一档）
        groups = {}
        for r in results:
            bucket = int(r["objective_rating"] // 10) * 10
            groups.setdefault(bucket, []).append(r["self_rating"])
        
        # 计算组内标准差的平均值
        avg_std = 0.0
        count = 0
        for bucket, ratings in groups.items():
            if len(ratings) >= 2:
                avg_std += self._std_dev(ratings)
                count += 1
        
        if count == 0:
            return 70.0
        
        avg_std /= count
        # 标准差越小，一致性越高。std=0→100分, std=25→0分
        return max(0.0, min(100.0, 100 - avg_std * 4))
    
    def _compute_improvement(self, trends: list[dict]) -> float:
        """改善趋势：对比历史校准准确度的变化"""
        if not trends or len(trends) < 2:
            return 50.0  # 无历史数据返回默认值
        
        # 最近一次 vs 上一次
        recent = trends[-1]
        previous = trends[-2] if len(trends) >= 2 else recent
        
        delta = recent.get("avg_calibration_accuracy", 50) - previous.get("avg_calibration_accuracy", 50)
        
        # 改善→高分，退步→低分
        base = recent.get("avg_calibration_accuracy", 50)
        return max(0.0, min(100.0, base + delta * 2))
    
    def _pearson_correlation(self, x: list[float], y: list[float]) -> float:
        n = len(x)
        sum_x = sum(x)
        sum_y = sum(y)
        sum_xy = sum(xi * yi for xi, yi in zip(x, y))
        sum_x2 = sum(xi ** 2 for xi in x)
        sum_y2 = sum(yi ** 2 for yi in y)
        
        numerator = n * sum_xy - sum_x * sum_y
        denominator = math.sqrt((n * sum_x2 - sum_x ** 2) * (n * sum_y2 - sum_y ** 2))
        
        return numerator / denominator if denominator != 0 else 0
    
    def _std_dev(self, values: list[float]) -> float:
        n = len(values)
        mean = sum(values) / n
        variance = sum((v - mean) ** 2 for v in values) / n
        return math.sqrt(variance)
    
    def _generate_insights(self, acc, disc, cons, imp) -> list[str]:
        insights = []
        if acc < 50:
            insights.append("自我评估与实际表现差距较大，建议加强自我检测练习")
        if disc < 40:
            insights.append("对不同知识点的掌握程度区分不够清晰，建议逐个知识点进行自测")
        if cons < 40:
            insights.append("自评波动较大，建议建立更稳定的自评标准参考体系")
        if imp > 70:
            insights.append("自我认知能力持续进步，继续保持自我反思的习惯")
        elif imp < 35:
            insights.append("自我认知能力有所下降，建议恢复定期的自我评估练习")
        if not insights:
            insights.append("自我认知能力发展良好，可以在更多学科进行校准练习")
        return insights
```

### 7.3 客观掌握度数据获取接口

```python
class ObjectiveMasteryClient:
    """
    调用知识追踪模型引擎获取客观掌握度
    """
    
    async def get_mastery_snapshot(
        self,
        student_id: int,
        subject_code: str,
        chapters: list[int] = None,
        knowledge_points: list[int] = None
    ) -> list[dict]:
        """
        获取学生当前掌握度快照
        调用知识追踪模型引擎的内部API
        """
        # 调用知识追踪服务
        results = []
        for chapter_id in (chapters or []):
            mastery = await self._call_mastery_api(
                student_id, subject_code, chapter_id=chapter_id
            )
            results.append({
                "chapter_id": chapter_id,
                "mastery_score": mastery.score,
                "sample_size": mastery.sample_count,
                "correct_rate": mastery.correct_rate,
                "difficulty_adjusted": mastery.difficulty_adjusted_score,
                "ci_low": mastery.ci_low,
                "ci_high": mastery.ci_high
            })
        
        return results
```

### 8.2 异步处理

校准分析采用异步计算模式，避免阻塞用户请求：

```python
# 评估提交后异步计算
async def submit_assessment(request):
    # 1. 同步：保存评估数据
    assessment = await save_assessment(request)
    
    # 2. 异步：触发校准分析
    await event_bus.publish("calibration.assessment.submitted", {
        "assessment_id": assessment.id,
        "student_id": request.student_id
    })
    
    # 3. 同步：返回受理结果
    return {
        "assessmentId": assessment.id,
        "estimatedCompletionTime": 5,
        "message": "评估已提交，校准分析结果将在5分钟内生成"
    }

# 异步消费者
async def on_assessment_submitted(event):
    """异步执行校准分析流水线"""
    try:
        # Step 1: 获取客观掌握度快照
        snapshots = await objective_mastery_client.get_mastery_snapshot(
            event.student_id, event.subject_code, chapters=event.chapters
        )
        
        # Step 2: 执行校准计算
        results = calibration_calculator.batch_calculate(
            assessment=event.assessment,
            snapshots=snapshots
        )
        
        # Step 3: 计算元认知综合得分
        meta_score = metacognition_scorer.compute(results, historical_trends)
        
        # Step 4: 生成引导策略
        strategies = strategy_generator.generate(results, student_profile)
        
        # Step 5: 持久化结果
        await save_results(results, meta_score, strategies)
        
        # Step 6: 通知客户端
        await notify_service.push(
            student_id=event.student_id,
            title="校准分析完成",
            body="你的自我认知分析报告已生成，点击查看"
        )
        
    except InsufficientDataError:
        await save_fallback_result(event.assessment_id, "INSUFFICIENT_DATA")
    except Exception as e:
        logger.error(f"Calibration failed for assessment {event.assessment_id}: {e}")
        await save_fallback_result(event.assessment_id, "CALCULATION_ERROR")
```

## 9. 安全与合规

### 9.1 数据安全

| 安全措施 | 说明 |
| --- | --- |
| 自评数据加密 | 自评分数属于学生个人教育数据，传输使用HTTPS，存储加密 |
| 访问控制 | 仅学生本人、绑定家长、授权教师可查看校准结果 |
| 数据脱敏 | 家长端报告中学生具体分数在分享场景下做脱敏处理 |
| 数据保留 | 自评原始数据保留至学生注销后180天，汇总统计长期保留 |
| 审计日志 | 所有评估结果查询记录审计日志，防止非授权窥探学生心理数据 |

### 9.3 合规要求

- **《未成年人保护法》**：自评数据不属于强制收集范围，学生有权拒绝评估
- **《个人信息保护法》**：教育敏感数据的处理需告知目的，提供退出机制
- **《未成年人网络保护条例》**：不得利用自评数据进行诱导消费或制造焦虑
- **数据主体权利**：支持学生/家长查询、更正、删除自评数据
