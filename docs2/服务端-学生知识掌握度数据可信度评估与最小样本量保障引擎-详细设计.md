# 服务端-学生知识掌握度数据可信度评估与最小样本量保障引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 平台**跨模块基础设施工具**，负责对所有"知识掌握度"计算结果进行**统计可信度评估**，确保下游服务（推荐、报告、干预、自适应测试等）不会基于不充分的数据做出关键决策。

**核心问题：** 当一个学生只答了 3 道关于"二次函数"的题目，正确 2 道，系统给出 67% 掌握度——这个数字的置信区间是多少？能否据此判断学生已掌握？能否据此跳过该知识点的推荐？

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 可信度量化 | 为每个知识点掌握度附加置信区间和可信等级 |
| 最小样本保障 | 定义不同决策场景所需的最小答题样本量 |
| 低可信数据拦截 | 当数据不足以支撑决策时，向下游返回"数据不足"标识而非虚假精确值 |
| 数据采集引导 | 反向指导题目推荐系统优先补充低可信度知识点的数据 |
| 透明化展示 | 在学情报告中向用户/家长展示可信度提示 |

### 1.3 适用范围

- **直接消费方**：知识追踪模型引擎、题目推荐服务、学情分析服务、学情报告生成服务、自适应测试引擎
- **间接消费方**：所有依赖掌握度数据的业务模块
- **不负责**：掌握度算法本身（BKT/IRT/DKT 等由 `知识追踪模型引擎` 负责），本引擎只负责对其输出做可信度评估和决策护栏

## 2. 核心概念与数据模型

### 2.1 关键概念

#### 2.1.1 掌握度可信等级（Mastery Confidence Level）

| 等级 | 标识 | 含义 | 允许的下游操作 |
|------|------|------|---------------|
| `HIGH` | 🟢 高可信 | 样本充分，置信区间窄 | 可用于精确推荐、报告强声明、自动跳级 |
| `MEDIUM` | 🟡 中可信 | 有一定数据但仍有不确定性 | 可用于一般推荐、趋势分析，报告中需附说明 |
| `LOW` | 🔴 低可信 | 数据严重不足，置信区间过宽 | 仅用于趋势参考，**禁止**据此做跳级/排除决策 |
| `INSUFFICIENT` | ⚪ 数据不足 | 样本量低于绝对最低值 | 返回 `null` 掌握度，触发补采流程 |

#### 2.1.2 贝叶斯后验分布

掌握度 θ ∈ [0, 1] 的后验分布采用 **Beta 分布**建模：

```
先验：  θ ~ Beta(α₀, β₀)
似然：  k 正确 out of n 次作答 ~ Binomial(n, θ)
后验：  θ | data ~ Beta(α₀ + k, β₀ + n - k)
```

- 默认先验参数：`α₀ = 2, β₀ = 2`（弱先验，均值 0.5，适合冷启动）
- 后验均值：`E[θ] = (α₀ + k) / (α₀ + β₀ + n)`
- 后验方差：`Var[θ] = αβ / [(α+β)²(α+β+1)]`
- 95% 置信区间：使用 Beta 分布分位数函数（`scipy.stats.beta.ppf` 或 Java `BetaDistribution`）

## 4. 核心算法设计

### 4.1 可信度等级判定算法

```python
import math
from scipy.stats import beta as beta_dist

# ===== 常量 =====
PRIOR_ALPHA = 2.0   # 默认先验 α
PRIOR_BETA  = 2.0   # 默认先验 β

def calculate_confidence(
    total_attempts: int,
    correct_count: int,
    scene_config: dict
) -> dict:
    """
    计算贝叶斯后验和可信度等级。

    :param total_attempts: 累计作答次数
    :param correct_count:  累计正确次数
    :param scene_config:   场景配置 {min_samples, target_samples, max_ci_width}
    :return: {alpha, beta, mean, ci_lower, ci_upper, ci_width, confidence_level}
    """
    min_samples    = scene_config["min_samples"]
    target_samples = scene_config["target_samples"]
    max_ci_width   = scene_config["max_ci_width"]

    # Step 1: 计算后验参数
    alpha_post = PRIOR_ALPHA + correct_count
    beta_post  = PRIOR_BETA + (total_attempts - correct_count)

    # Step 2: 后验均值和方差
    mean = alpha_post / (alpha_post + beta_post)
    variance = (alpha_post * beta_post) / (
        (alpha_post + beta_post) ** 2 * (alpha_post + beta_post + 1)
    )

    # Step 3: 95% 置信区间（Beta分布分位数）
    ci_lower = beta_dist.ppf(0.025, alpha_post, beta_post)
    ci_upper = beta_dist.ppf(0.975, alpha_post, beta_post)
    ci_width = ci_upper - ci_lower

    # Step 4: 判定可信等级
    if total_attempts < min_samples:
        # 低于绝对最小值
        if total_attempts == 0:
            level = "INSUFFICIENT"
        else:
            level = "INSUFFICIENT"
    elif total_attempts >= target_samples and ci_width <= max_ci_width:
        level = "HIGH"
    elif total_attempts >= min_samples and ci_width <= max_ci_width * 1.4:
        level = "MEDIUM"
    else:
        level = "LOW"

    return {
        "alpha": round(alpha_post, 4),
        "beta": round(beta_post, 4),
        "mean": round(mean, 4),
        "variance": round(variance, 6),
        "ci_lower": round(ci_lower, 4),
        "ci_upper": round(ci_upper, 4),
        "ci_width": round(ci_width, 4),
        "confidence_level": level
    }
```

### 4.2 守卫决策算法

```python
def guard_check(
    user_id: int,
    knowledge_id: int,
    scene_code: str,
    raw_mastery: float,
    confidence_record: dict,
    scene_config: dict
) -> dict:
    """
    场景守卫检查：判断当前数据是否足以支撑特定场景的决策。

    :return: {decision: PASSED|BLOCKED|DOWNGRADED, reason, ...}
    """
    level = confidence_record["confidence_level"]
    ci_width = confidence_record["ci_width"]
    total_attempts = confidence_record["total_attempts"]

    min_samples = scene_config["min_samples"]
    target_samples = scene_config["target_samples"]
    max_ci_width = scene_config["max_ci_width"]

    # 绝对不足：低于最小样本量
    if total_attempts < min_samples:
        gap = target_samples - total_attempts
        return {
            "decision": "BLOCKED",
            "confidence_level": level,
            "reason": (
                f"样本量不足({total_attempts}/{min_samples})，"
                f"需至少再采集{min_samples - total_attempts}个样本"
            ),
            "current_samples": total_attempts,
            "required_samples": min_samples,
            "gap": min_samples - total_attempts
        }

    # 可信度高：样本充分且置信区间窄
    if level == "HIGH":
        return {
            "decision": "PASSED",
            "confidence_level": "HIGH",
            "reason": f"数据充分({total_attempts}/{target_samples})，"
                      f"置信区间满足要求({ci_width:.3f} ≤ {max_ci_width})",
        }

    # 可信度中等：允许但降级处理
    if level == "MEDIUM":
        return {
            "decision": "DOWNGRADED",
            "confidence_level": "MEDIUM",
            "reason": f"数据基本充分({total_attempts}/{target_samples})，"
                      f"但置信区间略宽({ci_width:.3f} > {max_ci_width})，"
                      f"建议附注不确定性说明",
            "suggestion": "可在执行决策的同时附带不确定性提示"
        }

    # 可信度低
    return {
        "decision": "BLOCKED",
        "confidence_level": "LOW",
        "reason": f"置信区间过宽({ci_width:.3f} >> {max_ci_width})，"
                  f"需再采集约{target_samples - total_attempts}个样本",
        "current_samples": total_attempts,
        "required_samples": target_samples,
        "gap": target_samples - total_attempts
    }
```

### 4.3 补采优先级计算

```python
def calculate_collection_priority(
    knowledge_id: int,
    confidence_record: dict,
    knowledge_meta: dict
) -> int:
    """
    计算知识点的数据补采优先级（0-100）。

    优先级考虑因素：
    1. 样本缺口大小（缺口越大越优先）
    2. 知识点重要性（核心/重点知识点优先）
    3. 是否为前置知识点（被其他知识点依赖的优先）
    4. 最近是否有相关答题活动（近期活跃的优先）
    5. 是否在当前学习路径上（当前章节相关知识优先）
    """
    score = 0
    total_attempts = confidence_record.get("total_attempts", 0)
    target = 15  # 默认目标样本量
    gap = max(target - total_attempts, 0)
    gap_ratio = gap / target if target > 0 else 0

    # 因素1: 样本缺口（权重 35）
    score += int(gap_ratio * 35)

    # 因素2: 知识点重要性（权重 25）
    importance = knowledge_meta.get("importance_level", "NORMAL")
    importance_score = {"CORE": 25, "KEY": 18, "NORMAL": 10, "EXTENSION": 5}
    score += importance_score.get(importance, 10)

    # 因素3: 前置依赖数量（权重 20）
    dependent_count = knowledge_meta.get("dependent_count", 0)
    score += min(dependent_count * 4, 20)

    # 因素4: 近期活跃度（权重 10）
    recent_attempts = confidence_record.get("recent_attempts", 0)
    if recent_attempts > 0:
        score += min(recent_attempts * 2, 10)

    # 因素5: 当前学习路径（权重 10）
    in_current_path = knowledge_meta.get("in_current_learning_path", False)
    if in_current_path:
        score += 10

    return min(score, 100)
```

## 5. 核心业务流程

### 5.1 整体数据流

```
┌──────────────────────────────────────────────────────────────────────────┐
```

```java
/**
 * 掌握度可信度评估核心服务
 */
@Service
@Slf4j
public class MasteryConfidenceService {

    @Autowired
    private MasteryConfidenceRepository confidenceRepo;
    @Autowired
    private MinSampleConfigRepository configRepo;
    @Autowired
    private ConfidenceAuditLogRepository auditRepo;
    @Autowired
    private DataCollectionTaskRepository taskRepo;
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    private static final double PRIOR_ALPHA = 2.0;
    private static final double PRIOR_BETA = 2.0;
    private static final long CACHE_TTL_MINUTES = 30;

    /**
     * 答题后增量更新可信度
     */
    @Transactional
    public void updateOnAnswer(AnswerEvent event) {
        Long userId = event.getUserId();
        Long knowledgeId = event.getKnowledgeId();

        MasteryConfidence record = confidenceRepo
            .findByUserIdAndKnowledgeId(userId, knowledgeId)
            .orElse(initialRecord(userId, knowledgeId, event.getSubjectCode()));

        // 增量更新后验参数
        if (event.isCorrect()) {
            record.setAlphaPost(record.getAlphaPost() + 1);
            record.setCorrectCount(record.getCorrectCount() + 1);
        } else {
            record.setBetaPost(record.getBetaPost() + 1);
        }
        record.setTotalAttempts(record.getTotalAttempts() + 1);

        // 重算置信区间
        BetaDistribution beta = new BetaDistribution(
            record.getAlphaPost(), record.getBetaPost());
        double ciLower = beta.inverseCumulativeProbability(0.025);
        double ciUpper = beta.inverseCumulativeProbability(0.975);
        double ciWidth = ciUpper - ciLower;

        record.setCiLower95(round(ciLower, 4));
        record.setCiUpper95(round(ciUpper, 4));
        record.setCiWidth(round(ciWidth, 4));
        record.setRawMastery(event.getRawMastery());

        // 判定等级（取最严格场景）
        String newLevel = determineLevel(
            record.getTotalAttempts(), ciWidth);
        record.setConfidenceLevel(newLevel);

        // 更新近30天计数
        record.setRecentAttempts(calculateRecentAttempts(userId, knowledgeId));
        record.setLastAttemptAt(event.getAnsweredAt());
        record.setCalculatedAt(LocalDateTime.now());
        record.setVersion(record.getVersion() + 1);

        confidenceRepo.save(record);

        // 更新补采任务
        updateCollectionTasks(userId, knowledgeId, record);

        // 清除缓存
        String cacheKey = "mc:" + userId + ":" + knowledgeId;
        redisTemplate.delete(cacheKey);

        // 发布事件
        eventPublisher.publishEvent(new ConfidenceUpdatedEvent(record));
    }

    /**
     * 守卫检查
     */
    public GuardResult guard(Long userId, Long knowledgeId,
                              String sceneCode, double rawMastery) {
        // 查配置
        MinSampleConfig config = configRepo.findBySceneCode(sceneCode)
            .orElseThrow(() -> new BizException("UNKNOWN_SCENE", sceneCode));

        // 查可信度记录（带缓存）
        MasteryConfidence record = getWithCache(userId, knowledgeId);

        if (record == null || record.getTotalAttempts() == 0) {
            return logAndReturn(userId, knowledgeId, sceneCode,
                "BLOCKED", "INSUFFICIENT",
                "无答题记录，无法评估", config, 0);
        }

        // 判定逻辑
        int total = record.getTotalAttempts();
        double ciWidth = record.getCiWidth();
        String level = record.getConfidenceLevel();

        if (total < config.getMinSamples()) {
            return logAndReturn(userId, knowledgeId, sceneCode,
                "BLOCKED", level,
                String.format("样本量不足(%d/%d)", total, config.getMinSamples()),
                config, total);
        }

        if ("HIGH".equals(level) && total >= config.getTargetSamples()
            && ciWidth <= config.getMaxCiWidth()) {
            return logAndReturn(userId, knowledgeId, sceneCode,
                "PASSED", "HIGH",
                "数据充分，决策放行", config, total);
        }

        if ("MEDIUM".equals(level)) {
            return logAndReturn(userId, knowledgeId, sceneCode,
                "DOWNGRADED", "MEDIUM",
                String.format("数据基本充分，但CI偏宽(%.3f > %.3f)，建议附注说明",
                    ciWidth, config.getMaxCiWidth()),
                config, total);
        }

        return logAndReturn(userId, knowledgeId, sceneCode,
            "BLOCKED", "LOW",
            String.format("置信区间过宽(%.3f >> %.3f)", ciWidth, config.getMaxCiWidth()),
            config, total);
    }

    /**
     * 获取补采建议
     */
    public List<CollectionSuggestion> getCollectionSuggestions(
            Long userId, String subjectCode, int limit) {

        // 查询该学生所有低可信度知识点
        List<MasteryConfidence> lowConfidenceRecords = confidenceRepo
            .findLowConfidenceByUserAndSubject(userId, subjectCode);

        // 计算优先级并排序
        return lowConfidenceRecords.stream()
            .map(record -> {
                int priority = calculatePriority(record);
                int gap = DEFAULT_TARGET_SAMPLES - record.getTotalAttempts();
                return new CollectionSuggestion(
                    record.getKnowledgeId(),
                    record.getTotalAttempts(),
                    DEFAULT_TARGET_SAMPLES,
                    Math.max(gap, 0),
                    priority
                );
            })
            .sorted(Comparator.comparingInt(CollectionSuggestion::getPriority)
                .reversed())
            .limit(limit)
            .collect(Collectors.toList());
    }

    // ===== 私有方法 =====

    private String determineLevel(int totalAttempts, double ciWidth) {
        if (totalAttempts == 0) return "INSUFFICIENT";

        // 使用最严格的默认阈值
        if (totalAttempts >= 15 && ciWidth <= 0.250) return "HIGH";
        if (totalAttempts >= 5 && ciWidth <= 0.350) return "MEDIUM";
        if (totalAttempts >= 3) return "LOW";
        return "INSUFFICIENT";
    }

    private MasteryConfidence getWithCache(Long userId, Long knowledgeId) {
        String cacheKey = "mc:" + userId + ":" + knowledgeId;
        Object cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return (MasteryConfidence) cached;
        }
        MasteryConfidence record = confidenceRepo
            .findByUserIdAndKnowledgeId(userId, knowledgeId)
            .orElse(null);
        if (record != null) {
            redisTemplate.opsForValue().set(cacheKey, record,
                CACHE_TTL_MINUTES, TimeUnit.MINUTES);
        }
        return record;
    }

    private GuardResult logAndReturn(Long userId, Long knowledgeId,
            String sceneCode, String decision, String level,
            String reason, MinSampleConfig config, int currentSamples) {

        // 写审计日志
        ConfidenceAuditLog audit = new ConfidenceAuditLog();
        audit.setUserId(userId);
        audit.setKnowledgeId(knowledgeId);
        audit.setSceneCode(sceneCode);
        audit.setActionTaken(decision);
        audit.setConfidenceLevel(level);
        audit.setTotalAttempts(currentSamples);
        audit.setDetail(JSON.toJSONString(Map.of(
            "reason", reason,
            "minSamples", config.getMinSamples(),
            "targetSamples", config.getTargetSamples()
        )));
        auditRepo.save(audit);

        return GuardResult.builder()
            .decision(decision)
            .confidenceLevel(level)
            .reason(reason)
            .currentSamples(currentSamples)
            .requiredSamples(config.getMinSamples())
            .targetSamples(config.getTargetSamples())
            .auditId(audit.getId())
            .build();
    }
}
```

### 6.2 Beta 分布计算工具（无第三方依赖）

```java
/**
 * Beta 分布工具类
 * 使用连分数展开计算不完全 Beta 函数，避免依赖 Apache Commons Math。
 * 精度: 1e-10
 */
public final class BetaDistributionUtil {

    private BetaDistributionUtil() {}

    /**
     * Beta 分布的 CDF 反函数（分位数函数）
     * @param p 概率值 (0, 1)
     * @param alpha 形状参数 α > 0
     * @param beta  形状参数 β > 0
     * @return 分位数值
     */
    public static double inverseCDF(double p, double alpha, double beta) {
        if (p <= 0) return 0.0;
        if (p >= 1) return 1.0;
        if (alpha <= 0 || beta <= 0)
            throw new IllegalArgumentException("Alpha and Beta must be positive");

        // 使用牛顿迭代法 + 二分法混合求解
        double x = alpha / (alpha + beta); // 初始猜测 = 均值
        double lo = 0.0, hi = 1.0;

        for (int i = 0; i < 100; i++) {
            double cdf = regularizedIncompleteBeta(x, alpha, beta);
            double diff = cdf - p;

            if (Math.abs(diff) < 1e-10) return x;

            if (diff > 0) {
                hi = x;
            } else {
                lo = x;
            }

            // 牛顿步
            double pdf = betaPDF(x, alpha, beta);
            if (pdf > 1e-15) {
                double newtonX = x - diff / pdf;
                if (newtonX > lo && newtonX < hi) {
                    x = newtonX;
                    continue;
                }
            }
            // 回退到二分
            x = (lo + hi) / 2;
        }
        return x;
    }

    /**
     * Beta 分布概率密度函数
     */
    public static double betaPDF(double x, double alpha, double beta) {
        if (x <= 0 || x >= 1) return 0;
        double logBeta = logGamma(alpha) + logGamma(beta) - logGamma(alpha + beta);
        return Math.exp(
            (alpha - 1) * Math.log(x) +
            (beta - 1) * Math.log(1 - x) - logBeta
        );
    }

    /**
     * 正则化不完全 Beta 函数 I_x(a, b)
     * 使用连分数展开（Numerical Recipes 算法）
     */
    public static double regularizedIncompleteBeta(
            double x, double a, double b) {
        if (x <= 0) return 0;
        if (x >= 1) return 1;

        double bt = Math.exp(
            logGamma(a + b) - logGamma(a) - logGamma(b) +
            a * Math.log(x) + b * Math.log(1 - x)
        );

        if (x < (a + 1) / (a + b + 2)) {
            return bt * continuedFraction(x, a, b) / a;
        } else {
            return 1 - bt * continuedFraction(1 - x, b, a) / b;
        }
    }

    /**
     * 连分数展开（Lentz 方法）
     */
    private static double continuedFraction(double x, double a, double b) {
        final int MAX_ITER = 300;
        final double EPS = 1e-12;
        final double FPMIN = 1e-300;

        double qab = a + b;
        double qap = a + 1;
        double qam = a - 1;
        double c = 1.0;
        double d = 1.0 - qab * x / qap;
        if (Math.abs(d) < FPMIN) d = FPMIN;
        d = 1.0 / d;
        double h = d;

        for (int m = 1; m <= MAX_ITER; m++) {
            int m2 = 2 * m;
            double aa = m * (b - m) * x / ((qam + m2) * (a + m2));
            d = 1.0 + aa * d;
            if (Math.abs(d) < FPMIN) d = FPMIN;
            c = 1.0 + aa / c;
            if (Math.abs(c) < FPMIN) c = FPMIN;
            d = 1.0 / d;
            h *= d * c;

            aa = -(a + m) * (qab + m) * x / ((a + m2) * (qap + m2));
            d = 1.0 + aa * d;
            if (Math.abs(d) < FPMIN) d = FPMIN;
            c = 1.0 + aa / c;
            if (Math.abs(c) < FPMIN) c = FPMIN;
            d = 1.0 / d;
            double del = d * c;
            h *= del;
            if (Math.abs(del - 1.0) < EPS) break;
        }
        return h;
    }

    /**
     * Lanczos 近似计算 ln(Γ(x))
     */
    public static double logGamma(double x) {
        double[] cof = {
            76.18009172947146, -86.50532032941677,
            24.01409824083091, -1.231739572450155,
            0.1208650973866179e-2, -0.5395239384953e-5
        };
        double y = x;
        double tmp = x + 5.5;
        tmp -= (x + 0.5) * Math.log(tmp);
        double ser = 1.000000000190015;
        for (int j = 0; j < 6; j++) {
            y += 1;
            ser += cof[j] / y;
        }
        return -tmp + Math.log(2.5066282746310005 * ser / x);
    }
}
```

## 8. 性能优化

### 8.1 缓存策略

| 缓存层 | Key | TTL | 场景 |
|--------|-----|-----|------|
| L1 本地缓存 (Caffeine) | `mc:{userId}:{knowledgeId}` | 5 min | 高频查询，容忍短时不一致 |
| L2 Redis | `mc:{userId}:{knowledgeId}` | 30 min | 跨实例共享 |
| L2 Redis | `mc:batch:{userId}:{hash(kids)}` | 10 min | 批量查询结果 |
| L2 Redis | `mc:guard:{userId}:{knowledgeId}:{scene}` | 5 min | 守卫检查结果（答题后失效） |

### 8.2 Beta 分布计算优化

置信区间计算是最重的操作。优化策略：

1. **查表法**：对于常见 `α + β ≤ 50` 的参数组合，预计算分位数表，启动时加载
2. **渐进精度**：先用粗精度（1e-4）快速计算，如接近阈值边界再精算（1e-8）
3. **异步计算**：答题后更新可信度走异步队列，不阻塞用户操作
4. **批量化**：一次答题事件可能涉及多个知识点，批量计算后统一写入

### 9.1 错误码定义

| 错误码 | HTTP | 含义 | 处理建议 |
|--------|------|------|---------|
| `CONFIDENCE_001` | 400 | 参数非法（α ≤ 0 或 β ≤ 0） | 检查上游传入的答题统计 |
| `CONFIDENCE_002` | 404 | 知识点可信度记录不存在 | 返回 INSUFFICIENT 等级 |
| `CONFIDENCE_003` | 400 | 未知场景编码 | 检查 scene_code 拼写 |
| `CONFIDENCE_004` | 409 | 并发更新冲突（乐观锁版本不匹配） | 重试（最多 3 次） |
| `CONFIDENCE_005` | 500 | Beta 分布计算未收敛 | 返回上一次缓存结果 + 告警 |
| `CONFIDENCE_006` | 429 | 查询频率超限（限流） | 使用批量接口替代 |

### 9.2 降级策略

```java
/**
 * 降级处理：当本引擎不可用时，下游服务的兜底逻辑
 */
@Component
public class ConfidenceFallbackHandler {

    /**
     * 守卫接口降级：当引擎不可用时
     * - 对于安全敏感场景（自动进级）：默认 BLOCKED（宁可不做，不可做错）
     * - 对于体验优化场景（推荐排序）：默认 PASSED（允许通过，影响小）
     */
    public GuardResult fallbackGuard(String sceneCode, int totalAttempts) {
        if (isSafetyCritical(sceneCode)) {
            // 安全场景：根据答题次数简单判断
            if (totalAttempts < 5) {
                return GuardResult.blocked(
                    "CONFIDENCE_SERVICE_UNAVAILABLE",
                    "数据不足，暂不执行该操作"
                );
            }
            return GuardResult.degraded("服务暂时不可用，降级为基本判断");
        }
        return GuardResult.passed("服务降级，默认放行");
    }

    private boolean isSafetyCritical(String sceneCode) {
        return Set.of(
            "GRADE_ADVANCEMENT",
            "SKIP_KNOWLEDPOINT",
            "REPORT_STRONG_CLAIM"
        ).contains(sceneCode);
    }
}
```

## 14. 常见问题

**Q1: 为什么用 Beta 分布而不是正态近似？**

当样本量很小时（n < 30），正态近似误差很大。Beta 分布是伯努利试验共轭先验的精确后验，在小样本下仍然准确。

**Q2: 学生换年级后，旧年级知识点的可信度数据如何处理？**

不清除。跨年级知识漏洞追溯（如"服务端-学生跨年级知识漏洞根因追溯与前置薄弱点精准诊断引擎"）需要历史数据。但会在时效性检查中降低超过 1 学期未练习知识点的等级。

**Q3: 多模型/多次计算结果不一致怎么办？**

以最新一次知识追踪模型的输出为准。本引擎关注的是"数据量是否足够"，而非"模型算得准不准"。

**Q4: 如果某知识点本身题目总量就很少（如冷门知识点）怎么办？**

在知识点元数据中维护 `available_question_count`，补采任务的 target_samples 取 `min(默认目标, 可用题目总量 × 0.8)`。如果可用题目不足 5 道，该知识点永久标记为 `MEDIUM` 封顶。

**Q5: 如何处理练习模式 vs 考试模式的数据权重差异？**

当前版本不做区分（所有答题等权）。后续可在增量更新时引入权重系数：考试题正确权重 1.5，练习题权重 1.0，自选题权重 0.8。
