# 服务端-教育内容跨语言自动翻译与多语言教材并行管理引擎

## 1. 概述

### 1.1 功能定位

为 PrimeTop 教育平台提供教育内容的跨语言翻译能力与多语言并行管理体系。支持将平台内的教材章节、知识点解析、题目题干、解析步骤、考点说明等核心教育内容从源语言（简体中文）自动翻译为目标语言（英语、繁体中文、少数民族语言等），并对多语言版本进行统一的版本控制、一致性校验和发布管理。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 多语言内容并行管理 | 同一教育内容支持多种语言版本同步维护 |
| 翻译质量保障 | 术语准确性 ≥ 95%，语义相似度 ≥ 90% |
| 翻译效率提升 | 自动翻译 + 人工校对模式，减少 70% 人工翻译工作量 |
| 术语库统一 | 建立教育学科术语多语言对照库，消除翻译歧义 |
| 按需翻译 | 支持全量翻译、增量翻译、按需实时翻译三种模式 |
| 成本可控 | 翻译任务批量化，缓存复用已有翻译结果 |

### 1.3 适用范围

- 少数民族地区双语教学支持（藏语、维吾尔语、蒙古语等）
- 国际中文学校繁体中文教材需求
- 海外华裔学生中文+英文双语学习场景
- 未来国际版产品英文内容输出
- 双语学校中外教协作教学场景

### 1.4 支持语言矩阵

| 语言代码 | 语言名称 | 优先级 | 覆盖范围 |
| --- | --- | --- | --- |
| zh-CN | 简体中文（源语言） | P0 | 全量内容 |
| zh-TW | 繁体中文 | P1 | 教材、知识点、题目 |
| en | 英语 | P1 | 核心知识点、双语题目 |
| bo | 藏语 | P2 | 小学核心教材 |
| ug | 维吾尔语 | P2 | 小学核心教材 |
| mn | 蒙古语 | P3 | 小学部分教材 |

## 2. 系统架构

### 2.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    管理后台 / 内容编辑器                     │
│          (多语言内容编辑、术语库管理、翻译审核)                │
└──────────────┬──────────────────────┬────────────────────┘
               │                      │
┌──────────────▼──────────────────────▼────────────────────┐
│                  翻译编排服务 (Translation Orchestration)    │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────┐ │
│  │术语预处理│ │翻译任务调度│ │质量校验引擎│ │版本同步管理器  │ │
│  └─────────┘ └──────────┘ └──────────┘ └──────────────┘ │
└──────┬───────────┬───────────────┬──────────────┬───────┘
       │           │               │              │
┌──────▼──┐ ┌──────▼──────┐ ┌─────▼─────┐ ┌──────▼──────┐
│术语库服务│ │翻译引擎适配层│ │内容存储层  │ │事件通知服务  │
│(Term DB)│ │(MT Adapter) │ │(Content)  │ │(Event Bus)  │
└─────────┘ └─────────────┘ └───────────┘ └─────────────┘
```

### 2.2 核心组件

| 组件 | 职责 |
| --- | --- |
| 翻译编排服务 | 接收翻译请求，协调术语预处理、翻译执行、质量校验、结果存储 |
| 术语库服务 | 管理教育学科术语多语言对照库，提供术语查询与替换 |
| 翻译引擎适配层 | 适配多个机器翻译供应商（百度翻译、有道、DeepL、Google），统一接口 |
| 质量校验引擎 | 翻译结果质量评估，包括术语一致性、语义保真度、格式完整性 |
| 版本同步管理器 | 源内容变更时触发增量翻译，管理多语言版本间的一致性 |
| 翻译任务调度器 | 批量翻译任务队列管理，优先级调度，失败重试 |

### 5.2 术语预处理流程

术语预处理是翻译质量的关键环节，确保教育专业术语在翻译前后保持一致。

```python
class TerminologyPreprocessor:
    """术语预处理器：在翻译前对源文本进行术语标记和保护"""
    
    def __init__(self, terminology_service: TerminologyService):
        self.term_service = terminology_service
        self._term_cache = {}  # term_text -> term_metadata
    
    async def extract_terms(
        self, 
        source_text: str, 
        subject: str,
        stage: str
    ) -> TermExtractionResult:
        """
        从源文本中提取术语并生成保护标记
        
        Returns:
            TermExtractionResult: 包含标记后文本、术语映射表、未命中术语
        """
        # 1. 加载该学科+学段的术语库
        terms = await self.term_service.get_terms(subject, stage)
        
        # 2. 长术语优先匹配（避免短术语覆盖长术语）
        sorted_terms = sorted(terms, key=lambda t: len(t.source_term), reverse=True)
        
        marked_text = source_text
        term_map = {}  # placeholder -> term_info
        unmatched = []
        
        for term in sorted_terms:
            if term.source_term in marked_text:
                placeholder = f"[[TERM:{term.term_key}]]"
                # 记录术语上下文（前后各20字符）
                contexts = self._find_contexts(source_text, term.source_term, window=20)
                term_map[placeholder] = {
                    "term_key": term.term_key,
                    "source_term": term.source_term,
                    "contexts": contexts
                }
                marked_text = marked_text.replace(term.source_term, placeholder)
            else:
                # 检查变体/缩写
                if term.alt_expressions:
                    for alt in term.alt_expressions:
                        if alt in source_text:
                            unmatched.append({
                                "term_key": term.term_key,
                                "source": alt,
                                "reason": "ALT_EXPRESSION_FOUND",
                                "suggestion": f"建议统一为标准术语: {term.source_term}"
                            })
        
        # 3. 检测疑似术语但未收录的词组
        suspected = self._detect_suspected_terms(source_text, subject)
        for s in suspected:
            unmatched.append({
                "term_key": None,
                "source": s,
                "reason": "SUSPECTED_UNRECORDED",
                "suggestion": f"疑似专业术语，建议确认是否需收录"
            })
        
        return TermExtractionResult(
            marked_text=marked_text,
            term_map=term_map,
            unmatched_terms=unmatched
        )
    
    async def restore_terms(
        self,
        translated_text: str,
        term_map: dict,
        target_lang: str
    ) -> str:
        """
        将翻译结果中的术语占位符替换为目标语言术语
        """
        for placeholder, term_info in term_map.items():
            term_translations = await self.term_service.get_translation(
                term_info["term_key"], 
                target_lang
            )
            if term_translations:
                preferred = term_translations[0]  # 取首选翻译
                translated_text = translated_text.replace(placeholder, preferred)
            else:
                # 术语无目标语言翻译，保留源语言术语并添加括号注释
                logger.warning(
                    f"Term {term_info['term_key']} has no {target_lang} translation, "
                    f"falling back to source"
                )
                translated_text = translated_text.replace(
                    placeholder, 
                    f"{term_info['source_term']}"
                )
        
        return translated_text
```

### 5.3 源内容变更同步流程

当源语言内容发生变更时，需要自动检测并触发增量翻译。

```python
class ContentChangeListener:
    """监听源内容变更，触发增量翻译"""
    
    def __init__(self, translation_service: TranslationOrchestrator):
        self.translation_service = translation_service
    
    async def on_content_updated(
        self, 
        event: ContentUpdatedEvent
    ) -> None:
        """
        内容更新事件处理
        
        事件来源：
        - 教材内容编辑保存
        - 题库题目修改
        - 知识点内容修订
        - 考点信息更新
        """
        content_id = event.content_id
        content_type = event.content_type
        new_hash = event.content_hash
        
        # 1. 查询该内容所有已存在的翻译版本
        existing_translations = await TranslationRepository.find_by_source(
            source_content_id=content_id,
            content_type=content_type,
            exclude_source_lang=True  # 排除源语言本身
        )
        
        if not existing_translations:
            logger.info(f"Content {content_id} has no translations, skip sync")
            return
        
        # 2. 对比 hash 判断是否需要更新
        needs_update = []
        for translation in existing_translations:
            if translation.source_hash != new_hash:
                # 将旧版本标记为过时
                await TranslationRepository.update_status(
                    translation.id, 
                    TranslationStatus.OUTDATED
                )
                needs_update.append(translation)
        
        if not needs_update:
            return
        
        # 3. 按目标语言去重
        target_langs = list(set(t.target_lang for t in needs_update))
        
        # 4. 创建增量翻译任务
        task = await self.translation_service.create_task(
            source_content_ids=[content_id],
            content_type=content_type,
            target_langs=target_langs,
            task_type=TaskType.INCREMENTAL,
            triggered_by="EVENT_DRIVEN",
            priority=4,  # 增量翻译优先级略低
            options={
                "auto_review": True,
                "quality_threshold": 85,
                "diff_mode": True,  # 差异翻译模式
                "reference_versions": [
                    {"lang": t.target_lang, "version": t.version}
                    for t in needs_update
                ]
            }
        )
        
        logger.info(
            f"Triggered incremental translation for content {content_id}, "
            f"task_id={task.id}, target_langs={target_langs}"
        )
```

### 5.5 翻译引擎适配层

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List, Optional
import asyncio

@dataclass
class TranslationResult:
    translated_text: str
    engine: str
    confidence: float
    detected_terms: List[str]
    raw_response: dict

class TranslationEngine(ABC):
    """翻译引擎抽象接口"""
    
    @abstractmethod
    async def translate(
        self,
        text: str,
        source_lang: str,
        target_lang: str,
        domain: str = "education"
    ) -> TranslationResult:
        ...
    
    @abstractmethod
    async def batch_translate(
        self,
        texts: List[str],
        source_lang: str,
        target_lang: str,
        domain: str = "education"
    ) -> List[TranslationResult]:
        ...
    
    @abstractmethod
    def supports_lang(self, source_lang: str, target_lang: str) -> bool:
        ...
    
    @abstractmethod
    def get_cost_per_char(self, source_lang: str, target_lang: str) -> float:
        ...


class BaiduTranslationEngine(TranslationEngine):
    """百度翻译引擎适配器"""
    
    LANG_MAP = {
        "zh-CN": "zh", "zh-TW": "cht", "en": "en",
        "bo": "wy", "ug": "uga", "mn": "mon"
    }
    
    def __init__(self, api_key: str, secret_key: str):
        self.api_key = api_key
        self.secret_key = secret_key
        self.base_url = "https://fanyi-api.baidu.com/api/trans/vip"
    
    async def translate(
        self, text: str, source_lang: str, target_lang: str, domain: str = "education"
    ) -> TranslationResult:
        from_lang = self.LANG_MAP.get(source_lang)
        to_lang = self.LANG_MAP.get(target_lang)
        
        if not from_lang or not to_lang:
            raise UnsupportedLanguageError(
                f"Baidu Translate does not support {source_lang}->{target_lang}"
            )
        
        # 构建签名
        salt = generate_salt()
        sign = generate_sign(self.api_key, text, salt, self.secret_key)
        
        params = {
            "q": text,
            "from": from_lang,
            "to": to_lang,
            "appid": self.api_key,
            "salt": salt,
            "sign": sign,
            "domain": domain  # 教育领域术语优化
        }
        
        response = await http_post(f"{self.base_url}/iptrans", params=params)
        
        return TranslationResult(
            translated_text=response["trans_result"][0]["dst"],
            engine="BAIDU",
            confidence=response.get("confidence", 0.0),
            detected_terms=[],  # 由术语预处理器单独处理
            raw_response=response
        )
    
    async def batch_translate(
        self, texts: List[str], source_lang: str, target_lang: str, domain: str = "education"
    ) -> List[TranslationResult]:
        # 百度翻译支持 \n 分隔批量翻译
        combined = "\n".join(texts)
        result = await self.translate(combined, source_lang, target_lang, domain)
        
        # 拆分结果
        translated_parts = result.translated_text.split("\n")
        return [
            TranslationResult(
                translated_text=part,
                engine="BAIDU",
                confidence=result.confidence,
                detected_terms=[],
                raw_response=result.raw_response
            )
            for part in translated_parts
        ]
    
    def supports_lang(self, source_lang: str, target_lang: str) -> bool:
        return source_lang in self.LANG_MAP and target_lang in self.LANG_MAP
    
    def get_cost_per_char(self, source_lang: str, target_lang: str) -> float:
        pricing = {
            ("zh-CN", "zh-TW"): 0.0,  # 简繁转换免费（本地处理）
            ("zh-CN", "en"): 0.00005,
            ("zh-CN", "bo"): 0.00008,
            ("zh-CN", "ug"): 0.00008,
        }
        return pricing.get((source_lang, target_lang), 0.0001)


class HybridTranslationEngine(TranslationEngine):
    """
    混合翻译引擎：根据语言对和内容类型选择最优引擎
    - zh-CN → zh-TW: 本地简繁转换（零成本，零延迟）
    - zh-CN → en: 百度/DeepL（术语丰富，教育领域优化）
    - zh-CN → bo/ug/mn: 百度/本地引擎（小语种覆盖）
    """
    
    def __init__(
        self,
        engines: List[TranslationEngine],
        term_service: TerminologyService
    ):
        self.engines = {e.__class__.__name__: e for e in engines}
        self.term_service = term_service
        self._local_zh_converter = OpenCCConverter()  # 简繁本地转换
    
    async def translate(
        self, text: str, source_lang: str, target_lang: str, domain: str = "education"
    ) -> TranslationResult:
        # 特殊处理：简繁转换走本地
        if source_lang == "zh-CN" and target_lang == "zh-TW":
            return await self._local_zh_cn_to_tw(text)
        
        # 选择引擎
        engine = self._select_engine(source_lang, target_lang, domain)
        return await engine.translate(text, source_lang, target_lang, domain)
    
    def _select_engine(
        self, source_lang: str, target_lang: str, domain: str
    ) -> TranslationEngine:
        """根据语言对和领域选择最优翻译引擎"""
        if source_lang == "zh-CN" and target_lang == "en":
            # 英文翻译优先用 DeepL（质量更好）
            if "DeepLTranslationEngine" in self.engines:
                return self.engines["DeepLTranslationEngine"]
        
        if target_lang in ("bo", "ug", "mn"):
            # 小语种优先用百度（覆盖更全）
            if "BaiduTranslationEngine" in self.engines:
                return self.engines["BaiduTranslationEngine"]
        
        # 默认引擎
        return list(self.engines.values())[0]
    
    async def _local_zh_cn_to_tw(self, text: str) -> TranslationResult:
        """简繁本地转换（零 API 调用）"""
        converted = self._local_zh_converter.convert(text)
        return TranslationResult(
            converted,
            engine="LOCAL_OPENCC",
            confidence=1.0,
            detected_terms=[],
            raw_response={"method": "opencc"}
        )
```

## 6. 质量校验引擎

### 6.1 校验维度

| 检查项 | 说明 | 阈值 | 失败处理 |
| --- | --- | --- | --- |
| 术语一致性 | 所有已知术语是否使用了规范翻译 | ≥95% | 自动修正 + 标记 |
| 语义相似度 | 源文本与译文语义保真度（使用多语言嵌入模型） | ≥0.85 | 标记 REVIEWING |
| 格式完整性 | Markdown 格式、HTML 标签、代码块完整性 | 100% | 自动修复 |
| 数学公式完整性 | LaTeX 公式未被翻译引擎破坏 | 100% | 重新翻译 |
| 长度比率 | 译文长度 / 源文长度合理范围 | 0.5-2.5 | 标记检查 |
| 内容安全 | 译文不含敏感/不当内容 | 100% | 驳回 |

### 6.2 质量校验实现

```python
class TranslationQualityChecker:
    """翻译质量校验引擎"""
    
    def __init__(
        self,
        term_service: TerminologyService,
        embedding_service: EmbeddingService,
        safety_service: ContentSafetyService
    ):
        self.term_service = term_service
        self.embedding_service = embedding_service
        self.safety_service = safety_service
    
    async def check(
        self,
        source_text: str,
        translated_text: str,
        source_lang: str,
        target_lang: str,
        subject: str,
        term_map: dict
    ) -> QualityReport:
        """执行全部质量检查"""
        
        checks = await asyncio.gather(
            self._check_term_consistency(translated_text, target_lang, term_map),
            self._check_semantic_similarity(source_text, translated_text, 
                                            source_lang, target_lang),
            self._check_format_integrity(source_text, translated_text),
            self._check_math_formulas(source_text, translated_text),
            self._check_length_ratio(source_text, translated_text),
            self._check_safety(translated_text)
        )
        
        report = QualityReport(
            term_check=checks[0],
            semantic_check=checks[1],
            format_check=checks[2],
            formula_check=checks[3],
            length_check=checks[4],
            safety_check=checks[5]
        )
        
        report.overall_score = self._calculate_overall_score(report)
        report.recommendation = self._get_recommendation(report)
        
        return report
    
    async def _check_term_consistency(
        self, translated_text: str, target_lang: str, term_map: dict
    ) -> CheckResult:
        """术语一致性检查"""
        if not term_map:
            return CheckResult("TERM_CONSISTENCY", "PASS", 100.0, "无术语标记，跳过检查")
        
        total_terms = len(term_map)
        consistent = 0
        inconsistencies = []
        
        for placeholder, term_info in term_map.items():
            expected_translations = await self.term_service.get_translation(
                term_info["term_key"], target_lang
            )
            
            if not expected_translations:
                inconsistencies.append({
                    "term": term_info["source_term"],
                    "issue": "NO_TARGET_TRANSLATION",
                    "term_key": term_info["term_key"]
                })
                continue
            
            # 检查译文中是否包含规范术语
            found = any(
                et.lower() in translated_text.lower() 
                for et in expected_translations
            )
            
            if found:
                consistent += 1
            else:
                inconsistencies.append({
                    "term": term_info["source_term"],
                    "expected": expected_translations,
                    "issue": "TERM_NOT_FOUND",
                    "term_key": term_info["term_key"]
                })
        
        coverage = (consistent / total_terms) * 100 if total_terms > 0 else 100.0
        passed = coverage >= 95.0
        
        return CheckResult(
            check_type="TERM_CONSISTENCY",
            result="PASS" if passed else "WARN",
            score=coverage,
            detail={
                "total_terms": total_terms,
                "consistent": consistent,
                "inconsistencies": inconsistencies
            }
        )
    
    async def _check_semantic_similarity(
        self, source_text: str, translated_text: str,
        source_lang: str, target_lang: str
    ) -> CheckResult:
        """语义相似度检查（跨语言嵌入向量对比）"""
        source_embedding = await self.embedding_service.embed(
            source_text, model="multilingual-e5-large"
        )
        translated_embedding = await self.embedding_service.embed(
            translated_text, model="multilingual-e5-large"
        )
        
        similarity = cosine_similarity(source_embedding, translated_embedding)
        
        threshold = 0.85
        result = "PASS" if similarity >= threshold else ("WARN" if similarity >= 0.70 else "FAIL")
        
        return CheckResult(
            check_type="SEMANTIC_SIMILARITY",
            result=result,
            score=similarity * 100,
            detail={"similarity": similarity, "threshold": threshold}
        )
    
    async def _check_math_formulas(
        self, source_text: str, translated_text: str
    ) -> CheckResult:
        """数学公式完整性检查"""
        import re
        
        # 提取源文本中的 LaTeX 公式
        source_formulas = set(re.findall(r'\$[^$]+\$', source_text))
        source_formulas.update(re.findall(r'\\\[.+?\\\]', source_text))
        source_formulas.update(re.findall(r'\$\$.+?\$\$', source_text, re.DOTALL))
        
        if not source_formulas:
            return CheckResult("MATH_FORMULA", "PASS", 100.0, "无数学公式")
        
        # 检查译文中公式是否完整保留
        translated_formulas = set(re.findall(r'\$[^$]+\$', translated_text))
        translated_formulas.update(re.findall(r'\\\[.+?\\\]', translated_text))
        translated_formulas.update(re.findall(r'\$\$.+?\$\$', translated_text, re.DOTALL))
        
        missing = source_formulas - translated_formulas
        modified = []
        
        for formula in source_formulas & translated_formulas:
            # 检查公式内部是否被翻译引擎修改
            if not self._formula_preserved(formula, translated_text):
                modified.append(formula)
        
        all_issues = list(missing) + modified
        integrity = ((len(source_formulas) - len(all_issues)) / len(source_formulas)) * 100
        
        return CheckResult(
            check_type="MATH_FORMULA",
            result="PASS" if integrity == 100 else "FAIL",
            score=integrity,
            detail={
                "total_formulas": len(source_formulas),
                "missing": list(missing),
                "modified": modified
            }
        )
    
    def _check_format_integrity(
        self, source_text: str, translated_text: str
    ) -> CheckResult:
        """格式完整性检查"""
        import re
        
        issues = []
        
        # 检查 Markdown 标题层级
        source_headings = re.findall(r'^(#+)\s', source_text, re.MULTILINE)
        translated_headings = re.findall(r'^(#+)\s', translated_text, re.MULTILINE)
        
        if len(source_headings) != len(translated_headings):
            issues.append(f"标题数量不匹配: 源{len(source_headings)} vs 译{len(translated_headings)}")
        
        # 检查列表结构
        source_lists = re.findall(r'^[\-\*]\s', source_text, re.MULTILINE)
        translated_lists = re.findall(r'^[\-\*]\s', translated_text, re.MULTILINE)
        
        if abs(len(source_lists) - len(translated_lists)) > 2:
            issues.append(f"列表项数量差异过大: 源{len(source_lists)} vs 译{len(translated_lists)}")
        
        # 检查 HTML 标签闭合
        for tag in ['b', 'i', 'u', 'sub', 'sup', 'span']:
            source_count = source_text.count(f'<{tag}>')
            translated_count = translated_text.count(f'<{tag}>')
            if source_count != translated_count:
                issues.append(f"<{tag}>标签数量不匹配: 源{source_count} vs 译{translated_count}")
        
        score = max(0, 100 - len(issues) * 15)
        result = "PASS" if not issues else "WARN"
        
        return CheckResult(
            check_type="FORMAT_INTEGRITY",
            result=result,
            score=float(score),
            detail={"issues": issues}
        )
```

## 7. 简繁转换特殊处理

简体中文 → 繁体中文不调用外部翻译 API，使用本地 OpenCC 转换，实现零成本零延迟翻译。

```python
import opencc

class OpenCCConverter:
    """简繁本地转换器"""
    
    def __init__(self):
        # s2tw: 简体→台湾繁体
        # s2t: 简体→通用繁体
        # s2hk: 简体→香港繁体
        self._converters = {
            "zh-TW": opencc.OpenCC("s2tw"),
            "zh-HK": opencc.OpenCC("s2hk"),
            "zh-TW-phrase": opencc.OpenCC("s2twp"),  # 含台湾惯用词转换
        }
        
        # 台湾教育领域惯用词补充词典
        self._education_overrides = {
            "软件": "軟體",
            "程序": "程式",
            "数据": "資料",
            "网络": "網路",
            "信息": "資訊",
            "视频": "影片",
            "菜单": "選單",
            "鼠标": "滑鼠",
            "硬盘": "硬碟",
            "对象": "物件",
            "数组": "陣列",
            "变量": "變數",
            "默认": "預設",
            "优化": "最佳化",
        }
    
    def convert(self, text: str, target: str = "zh-TW") -> str:
        """执行简繁转换"""
        converter = self._converters.get(target, self._converters["zh-TW"])
        converted = converter.convert(text)
        
        # 应用教育领域惯用词覆盖
        for simplified, traditional in self._education_overrides.items():
            converted = converted.replace(traditional, traditional)  # 已是繁体则不处理
        
        return converted
```

## 8. 内容类型翻译策略

不同教育内容类型有不同的翻译策略和要求：

| 内容类型 | 翻译策略 | 术语严格度 | 特殊处理 |
| --- | --- | --- | --- |
| CHAPTER（教材章节） | 全量翻译 + 人工审核 | 高 | 保留章节编号、脚注、引用 |
| KNOWLEDGE_POINT（知识点） | 全量翻译 | 高 | 保留数学公式、化学方程式 |
| QUESTION（题目） | 结构化分字段翻译 | 极高 | 题干/选项/答案分翻，公式保护 |
| ANALYSIS（解析） | 全量翻译 + 人工审核 | 高 | 保留步骤编号、推导过程格式 |
| EXAM_POINT（考点） | 全量翻译 | 高 | 保留考纲编号引用 |

### 8.1 题目结构化翻译

题目翻译需要分字段处理，保证题干、选项、答案的对应关系不被破坏。

```python
class QuestionTranslator:
    """题目结构化翻译器"""
    
    async def translate_question(
        self,
        question: Question,
        target_lang: str,
        engine: TranslationEngine,
        term_preprocessor: TerminologyPreprocessor
    ) -> TranslatedQuestion:
        """
        结构化翻译题目，分字段独立翻译后保持关联性
        """
        subject = question.subject
        stage = question.stage
        
        # 1. 术语预处理（统一提取题目中所有术语）
        combined_text = " ".join([
            question.stem,
            " ".question.options or [],
            question.answer or "",
            question.analysis or ""
        ])
        
        term_result = await term_preprocessor.extract_terms(
            combined_text, subject, stage
        )
        
        # 2. 分字段翻译
        translated_stem = await self._translate_field(
            question.stem, target_lang, engine, 
            term_result, question_type=question.type
        )
        
        translated_options = []
        if question.options:
            for option in question.options:
                translated_option = await self._translate_field(
                    option, target_lang, engine, term_result
                )
                translated_options.append(translated_option)
        
        translated_answer = await self._translate_field(
            question.answer, target_lang, engine, term_result
        ) if question.answer else None
        
        translated_analysis = await self._translate_field(
            question.analysis, target_lang, engine, term_result
        ) if question.analysis else None
        
        # 3. 特殊处理：填空题空格位置保持
        if question.type == "FILL_BLANK":
            translated_stem = self._restore_blanks(
                question.stem, translated_stem
            )
        
        # 4. 特殊处理：图片题中的标注文本
        if question.image_annotations:
            translated_annotations = {}
            for key, annotation in question.image_annotations.items():
                translated_annotations[key] = await self._translate_field(
                    annotation, target_lang, engine, term_result
                )
        else:
            translated_annotations = None
        
        return TranslatedQuestion(
            question_id=question.id,
            target_lang=target_lang,
            stem=translated_stem,
            options=translated_options,
            answer=translated_answer,
            analysis=translated_analysis,
            image_annotations=translated_annotations,
            term_coverage=term_result.coverage_rate,
            term_map=term_result.term_map
        )
    
    async def _translate_field(
        self, text: str, target_lang: str,
        engine: TranslationEngine, term_result: TermExtractionResult,
        question_type: str = None
    ) -> str:
        """翻译单个字段，保护公式和特殊标记"""
        if not text:
            return text
        
        # 提取并保护数学公式
        formula_protector = FormulaProtector()
        protected_text = formula_protector.protect(text)
        
        # 应用术语标记
        marked_text = term_result.marked_text
        
        # 翻译
        result = await engine.translate(
            protected_text, "zh-CN", target_lang, domain="education"
        )
        
        # 恢复公式
        restored = formula_protector.restore(result.translated_text)
        
        # 恢复术语
        restored = await term_preprocessor.restore_terms(
            restored, term_result.term_map, target_lang
        )
        
        return restored


class FormulaProtector:
    """数学公式保护器：防止翻译引擎破坏公式"""
    
    PATTERN = re.compile(
        r'(\$[^$]+\$|'           # $...$
        r'\$\$.+?\$\$|'          # $$...$$
        r'\\\(.+?\\\)|'          # \(...\)
        r'\\\[.+?\\\]|'          # \[...\]
        r'\\[a-zA-Z]+\{[^}]*\})', # \frac{...}
        re.DOTALL
    )
    
    def protect(self, text: str) -> str:
        """将公式替换为占位符"""
        self._formulas = []
        
        def replace_match(m):
            self._formulas.append(m.group())
            return f"⟦FORMULA_{len(self._formulas)-1}⟧"
        
        return self.PATTERN.sub(replace_match, text)
    
    def restore(self, text: str) -> str:
        """将占位符恢复为公式"""
        for i, formula in enumerate(self._formulas):
            text = text.replace(f"⟦FORMULA_{i}⟧", formula)
        return text
```

```python
class TranslationCacheManager:
    """翻译结果多级缓存"""
    
    CACHE_TTL = {
        "L1_REDIS": 3600 * 24,      # 24小时
        "L2_DATABASE": None,          # 永久（数据表记录）
        "L3_SEARCH": 3600 * 24 * 7,  # 7天
    }
    
    async def get_cached_translation(
        self,
        source_text_hash: str,
        target_lang: str,
        content_type: str
    ) -> Optional[TranslationResult]:
        """多级缓存查询"""
        
        cache_key = f"trans:{content_type}:{target_lang}:{source_text_hash}"
        
        # L1: Redis 缓存
        cached = await self.redis.get(cache_key)
        if cached:
            return TranslationResult.from_json(cached)
        
        # L2: 数据库查询
        db_record = await TranslationRepository.find_by_hash(
            source_text_hash, target_lang, content_type
        )
        if db_record and db_record.translation_status == "APPROVED":
            # 回填 L1
            await self.redis.setex(
                cache_key, self.CACHE_TTL["L1_REDIS"],
                db_record.to_json()
            )
            return db_record.to_result()
        
        return None
    
    async def set_cache(
        self,
        source_text_hash: str,
        target_lang: str,
        content_type: str,
        result: TranslationResult
    ) -> None:
        """写入多级缓存"""
        cache_key = f"trans:{content_type}:{target_lang}:{source_text_hash}"
        
        # L1: Redis
        await self.redis.setex(
            cache_key, self.CACHE_TTL["L1_REDIS"], result.to_json()
        )
        
        # L2: 数据库（由业务层负责持久化）
```

### 9.2 批量翻译优化

```python
class BatchTranslationOptimizer:
    """批量翻译优化器"""
    
    async def optimize_batch(
        self,
        items: List[TranslationItem],
        target_lang: str
    ) -> List[TranslationBatch]:
        """
        将翻译项分批优化：
        1. 合并相同内容（去重）
        2. 按内容类型分组（同类型可复用Prompt）
        3. 控制单批大小（API限制）
        4. 相似内容聚类（提高缓存命中率）
        """
        # 1. 去重
        unique_items = self._deduplicate(items)
        
        # 2. 按学科和类型分组
        groups = self._group_by(unique_items, key=lambda x: (x.subject, x.content_type))
        
        batches = []
        for group_key, group_items in groups.items():
            # 3. 按文本长度分批（单批不超过 API 限制）
            sub_batches = self._split_by_size(
                group_items,
                max_chars=5000,  # 单批最大字符数
                max_items=50     # 单批最大条目数
            )
            batches.extend(sub_batches)
        
        return batches
    
    def _deduplicate(self, items: List[TranslationItem]) -> List[TranslationItem]:
        """去除完全相同的翻译项"""
        seen = {}
        for item in items:
            text_hash = hashlib.md5(item.source_text.encode()).hexdigest()
            if text_hash not in seen:
                seen[text_hash] = item
        return list(seen.values())
```

```python
class TranslationFallbackHandler:
    """翻译降级策略处理器"""
    
    async def translate_with_fallback(
        self,
        text: str,
        source_lang: str,
        target_lang: str,
        preferred_engine: str
    ) -> TranslationResult:
        """
        多级降级翻译策略：
        Level 0: 使用首选引擎正常翻译
        Level 1: 首选引擎失败，切换到备用引擎
        Level 2: 所有翻译引擎失败，检查缓存
        Level 3: 缓存未命中，返回源语言内容 + 降级标记
        """
        
        engines_to_try = self._get_engine_chain(preferred_engine, target_lang)
        
        for i, engine in enumerate(engines_to_try):
            try:
                result = await engine.translate(text, source_lang, target_lang)
                
                if i > 0:
                    logger.warning(
                        f"Primary engine failed, used fallback: "
                        f"preferred={preferred_engine}, actual={engine.__class__.__name__}"
                    )
                    result.warnings.append(
                        f"Used fallback engine: {engine.__class__.__name__}"
                    )
                
                return result
                
            except EngineUnavailableError:
                logger.warning(f"Engine {engine.__class__.__name__} unavailable")
                continue
            except EngineRateLimitError:
                logger.warning(f"Engine {engine.__class__.__name__} rate limited")
                await asyncio.sleep(2 ** i)  # 指数退避
                continue
            except EngineTimeoutError:
                logger.warning(f"Engine {engine.__class__.__name__} timeout")
                continue
        
        # Level 2: 所有引擎失败，查缓存
        cached = await self.cache_manager.get_cached_translation(
            hashlib.md5(text.encode()).hexdigest(),
            target_lang,
            "FALLBACK"
        )
        if cached:
            cached.warnings.append("All engines failed, using cached translation")
            return cached
        
        # Level 3: 最终降级 - 返回源语言内容
        return TranslationResult(
            translated_text=text,
            engine="NONE",
            confidence=0.0,
            detected_terms=[],
            raw_response={},
            warnings=[
                f"Translation unavailable for {source_lang}->{target_lang}, "
                f"showing source content"
            ]
        )
```
