# 客户端-收藏与笔记管理页面架构与交互设计

> 版本：v1.0 | 日期：2026-05-29 | 模块归属：客户端页面层
> 依赖：收藏与笔记系统（服务端）、客户端路由与深链接系统、客户端富文本编辑器与作文书写引擎、客户端本地持久层与数据管理

## 1. 模块概述

### 1.1 定位与目标

收藏与笔记管理页面是 PrimeTop 应用内统一的内容收藏夹与学习笔记工作台，为用户提供跨模块（AI 对话、题目、知识点、教材章节、考点、作文素材）的收藏浏览、笔记编辑、文件夹管理和全文检索能力。

**设计目标：**

1. **一屏触达**：从任意学习场景一键收藏/记笔记，最多两步到达管理页面
2. **分龄适配**：低龄用户以收藏为主（一键收藏、自动归类），高龄用户提供完整笔记编辑器
3. **离线优先**：收藏和笔记操作支持离线写入，联网后自动同步，弱网不阻塞
4. **统一抽象**：收藏和笔记面向多种内容类型，通过 `targetType` + `targetId` 统一抽象，页面层不感知具体内容类型
5. **快速检索**：支持按学科、标签、关键词、时间范围筛选和全文搜索

### 1.2 页面入口与导航关系

/// 文件夹列表
@riverpod
Future<List<FolderModel>> folderList(FolderListRef ref, {int? parentId}) async {
  final local = ref.watch(collectionLocalDbProvider);
  final api = ref.watch(collectionApiServiceProvider);

  // 优先本地读取，后台同步
  final localFolders = await local.getFolders(parentId: parentId);
  if (localFolders.isNotEmpty) return localFolders;

  // 本地为空时从服务端拉取
  final remoteFolders = await api.getFolders(parentId: parentId);
  await local.upsertFolders(remoteFolders);
  return remoteFolders;
}

/// 指定文件夹内的收藏列表（分页）
@riverpod
Future<CollectionPage> folderCollections(
  FolderCollectionsRef ref, {
  required int folderId,
  int page = 1,
  int pageSize = 20,
}) async {
  final local = ref.watch(collectionLocalDbProvider);
  final api = ref.watch(collectionApiServiceProvider);

  // 分页数据优先走网络
  try {
    final result = await api.getCollections(
      folderId: folderId,
      page: page,
      pageSize: pageSize,
    );
    // 回写本地缓存
    await local.upsertCollections(result.items);
    return result;
  } catch (e) {
    // 网络失败降级到本地
    return local.getCollections(folderId: folderId, page: page, pageSize: pageSize);
  }
}

/// 当前编辑中的笔记（编辑页状态）
@riverpod
class NoteEditorNotifier extends _$NoteEditorNotifier {
  @override
  NoteEditorState build(String? noteId) {
    if (noteId != null) {
      // 加载已有笔记
      _loadNote(noteId);
    }
    return NoteEditorState.empty();
  }

  Future<void> _loadNote(String id) async {
    final local = ref.read(collectionLocalDbProvider);
    final note = await local.getNoteById(id);
    if (note != null) {
      state = state.copyWith(
        content: note.content,
        tags: note.tags,
        subjectCode: note.subjectCode,
      );
    }
  }

  void updateContent(String content) {
    state = state.copyWith(content: content);
    _scheduleAutoSave();
  }

  void addTag(String tag) {
    state = state.copyWith(tags: [...state.tags, tag]);
  }

  void removeTag(String tag) {
    state = state.copyWith(tags: state.tags.where((t) => t != tag).toList());
  }

  Timer? _autoSaveTimer;
  void _scheduleAutoSave() {
    _autoSaveTimer?.cancel();
    _autoSaveTimer = Timer(const Duration(seconds: 3), _autoSave);
  }

  Future<void> _autoSave() async {
    final local = ref.read(collectionLocalDbProvider);
    final api = ref.read(noteApiServiceProvider);
    // 先写本地
    await local.saveNoteDraft(state.toModel(noteId: state.noteId));
    // 再同步服务端
    try {
      await api.saveNote(state.toRequest());
    } catch (_) {
      // 网络失败忽略，等待下次同步
    }
  }
}

### 3.4 离线同步策略

```
操作优先级：
  1. 用户操作 → 立即写本地 SQLite
  2. 本地写入成功 → UI 立即反馈（乐观更新）
  3. 异步队列 → 推送到服务端
  4. 服务端成功 → 更新本地 syncStatus = synced
  5. 服务端失败 → 标记 syncStatus = dirty，等待重试

同步队列结构（本地 SQLite 表）：
  sync_queue (
    id, operation (create/update/delete),
    entity_type (collection/note/folder),
    entity_id, payload_json,
    retry_count, max_retries = 5,
    next_retry_at, created_at
  )

重试策略：指数退避 (1s, 2s, 4s, 8s, 16s)
冲突解决：最后写入胜出 (Last-Write-Wins)，服务端返回冲突数据供用户确认
```

    bool isLoading = false,
  }) {
    return IconButton(
      icon: AnimatedSwitcher(
        duration: const Duration(milliseconds: 300),
        child: isLoading
            ? const SizedBox(
                width: 20,
                height: 20,
                child: CircularProgressIndicator(strokeWidth: 2),
              )
            : Icon(
                isCollected ? Icons.star_rounded : Icons.star_outline_rounded,
                key: ValueKey(isCollected),
                color: isCollected
                    ? AppColors.starFilled
                    : AppColors.starOutline,
                size: 28,
              ),
      ),
      onPressed: () => _handleToggle(context, isCollected),
      onLongPress: stage != UserStage.kindergarten
          ? () => _showCollectionSheet(context)
          : null,
    );
  }

  Future<void> _handleToggle(BuildContext context, bool isCurrentlyCollected) async {
    final stage = ref.read(userStageProvider);

    if (isCurrentlyCollected) {
      // 取消收藏
      final shouldRemove = await _confirmRemove(context);
      if (!shouldRemove) return;

      await ref.read(collectionLocalDbProvider).removeCollection(
        targetType: targetType,
        targetId: targetId,
      );

      // 刷新状态
      ref.invalidate(collectionStatusProvider(targetType, targetId));

      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(content: Text('已取消收藏')),
        );
      }
    } else {
      // 快速收藏
      final defaultFolderId = await _getDefaultFolderId(stage);

      await ref.read(collectionLocalDbProvider).addCollection(
        targetType: targetType,
        targetId: targetId,
        title: title,
        previewContent: previewContent,
        folderId: defaultFolderId,
        subjectCode: subjectCode,
      );

      ref.invalidate(collectionStatusProvider(targetType, targetId));

      if (mounted) {
        _showStarAnimation(context);
      }

        behavior: SnackBarBehavior.floating,
        duration: const Duration(seconds: 2),

class CollectionTimelineList extends ConsumerStatefulWidget {

    super.key,
    this.folderId,

class _CollectionTimelineListState
    extends ConsumerState<CollectionTimelineList> {
  final _scrollController = ScrollController();
  int _currentPage = 1;
  bool _hasMore = true;
  bool _isLoadingMore = false;

  // 多选状态
  final _selectedIds = <String>{};
  bool get _isSelectionMode => _selectedIds.isNotEmpty;

  @override
  void initState() {
    super.initState();
    _scrollController.addListener(_onScroll);
  }

  void _onScroll() {
    if (_scrollController.position.pixels >=
            _scrollController.position.maxScrollExtent - 200 &&
        _hasMore &&
        !_isLoadingMore) {
      _loadMore();
    }
  }

  Future<void> _loadMore() async {
    setState(() => _isLoadingMore = true);
    _currentPage++;
    // 触发 provider 刷新加载下一页
    setState(() {});
    // 实际加载逻辑...
    setState(() => _isLoadingMore = false);
  }

  Future<void> _refresh() async {
    _currentPage = 1;
    _hasMore = true;
    // 刷新 provider
  }

  @override
  Widget build(BuildContext context) {
    final collectionsAsync = widget.folderId != null
        ? ref.watch(folderCollectionsProvider(
            folderId: widget.folderId!, page: _currentPage))
        : ref.watch(collectionTimelineProvider(
            filter: CollectionTimelineFilter(
              subjectCode: widget.subjectCode,
              targetType: widget.targetType,
            ),
            page: _currentPage,
          ));

    return collectionsAsync.when(
      loading: () => const Center(child: CircularProgressIndicator()),
      error: (e, _) => _buildErrorState(e),
      data: (page) {
        _hasMore = page.hasMore;
        return RefreshIndicator(
          onRefresh: _refresh,
          child: _buildGroupedList(page.items),
        );
      },
    );
  }

  Widget _buildGroupedList(List<CollectionModel> items) {
    final groups = _groupByDate(items);

    return ListView.builder(

## 8. 错误处理与降级策略

### 8.1 网络异常处理

```dart
// 统一错误处理封装
Future<T> withOfflineFallback<T>({
  required Future<T> Function() remote,
  required Future<T> Function() local,
  required String operation,
}) async {
  try {
    final result = await remote();
    return result;
  } on DioException catch (e) {
    if (e.type == DioExceptionType.connectionError ||
        e.type == DioExceptionType.connectionTimeout) {
      // 网络不可用，降级到本地
      debugPrint('[$operation] Network unavailable, falling back to local');
      return local();
    }
    rethrow;
  }
}
```

    id          INTEGER PRIMARY KEY AUTOINCREMENT,

    payload     TEXT NOT NULL,             -- JSON payload

);

CREATE INDEX idx_sq_retry ON sync_queue(next_retry_at) WHERE retry_count < max_retries;

### 14.2 本地全文检索（FTS5）

```sql
-- 笔记全文检索虚拟表
CREATE VIRTUAL TABLE local_notes_fts USING fts5(
    plain_text,
    tags,
    content='local_notes',
    content_rowid='rowid'
);

-- 触发器：自动同步 FTS
CREATE TRIGGER notes_fts_insert AFTER INSERT ON local_notes BEGIN
    INSERT INTO local_notes_fts(rowid, plain_text, tags)
    VALUES (new.rowid, new.plain_text, new.tags);
END;

CREATE TRIGGER notes_fts_update AFTER UPDATE ON local_notes BEGIN
    INSERT INTO local_notes_fts(local_notes_fts, rowid, plain_text, tags)
    VALUES ('delete', old.rowid, old.plain_text, old.tags);
    INSERT INTO local_notes_fts(rowid, plain_text, tags)
    VALUES (new.rowid, new.plain_text, new.tags);
END;

CREATE TRIGGER notes_fts_delete AFTER DELETE ON local_notes BEGIN
    INSERT INTO local_notes_fts(local_notes_fts, rowid, plain_text, tags)
    VALUES ('delete', old.rowid, old.plain_text, old.tags);
END;
```
