# 学期与学年管理服务 - 详细设计

## 1. 模块概述

### 1.1 功能定位

学期与学年管理服务是 PrimeTop 的**基础时序服务**，负责管理教育日历、学期定义、校历事件、升年级/升学期切换、寒暑假期间功能调整等。几乎所有业务模块（同步课堂、学习规划、错题复习、学情报告、运营活动）都依赖本服务提供的**时间上下文**来判断用户当前处于哪个学期、哪一周、是否在考试季/假期等。

### 1.2 核心问题

| 问题 | 现状 | 本文档解决 |
|------|------|-----------|
| 学生年级/学期如何随时间自动推进？ | 用户账号体系仅存储静态字段，无过渡逻辑 | ✅ 自动升年级/升学期引擎 |
| 各地区开学/放假日期不同怎么处理？ | 无 | ✅ 校历模板 + 自定义校历 |
| 寒暑假期间学习推荐如何变化？ | 各模块各自判断 | ✅ 统一假期状态查询 API |
| 升年级时旧学期数据如何处理？ | 无 | ✅ 学期归档 + 数据迁移策略 |
| 考试季/非考试季推荐策略不同？ | 无 | ✅ 校历事件标记 + 事件广播 |

### 1.4 设计原则

1. **时间即上下文**：所有业务模块通过本服务获取当前教育时间上下文
2. **地区灵活**：支持不同地区/城市的开学时间差异
3. **渐进推进**：升年级/升学期需要用户确认，不自动强制
4. **数据连续**：旧学期数据归档而非删除，支持跨学期查询
5. **事件驱动**：学期切换、假期开始/结束等通过事件通知下游模块

## 3. 数据结构设计

### 3.1 学年学期定义表 `academic_terms`

```sql
CREATE TABLE academic_terms (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    year_key        CHAR(9) NOT NULL COMMENT '学年标识, 格式: 2025-2026',
    semester        VARCHAR(10) NOT NULL COMMENT 'first=上学期 / second=下学期',
    region_code     VARCHAR(10) NOT NULL DEFAULT 'default' COMMENT '地区编码(省/市), default=全国默认',
    stage           VARCHAR(20) NOT NULL COMMENT '适用学段: preschool/primary/junior/senior',
    start_date      DATE NOT NULL COMMENT '学期开始日期',
    end_date        DATE NOT NULL COMMENT '学期结束日期',
    total_weeks     INT COMMENT '总教学周数',
    week_count_type VARCHAR(20) DEFAULT 'calendar' COMMENT 'calendar=自然周 / teaching=教学周',
    
    -- 元数据
    status          TINYINT DEFAULT 1 COMMENT '1=草稿 2=生效 3=已归档',
    created_by      BIGINT COMMENT '创建人(管理员)',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_term (year_key, semester, region_code, stage),
    INDEX idx_date (start_date, end_date),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学年学期定义';
```

### 3.2 校历事件表 `calendar_events`

```sql
CREATE TABLE calendar_events (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    term_id         BIGINT NOT NULL COMMENT '关联学期ID',
    event_type      VARCHAR(32) NOT NULL COMMENT '事件类型, 见3.3',
    name            VARCHAR(100) NOT NULL COMMENT '事件名称',
    start_date      DATE NOT NULL,
    end_date        DATE NOT NULL,
    affect_type     VARCHAR(20) DEFAULT 'all' COMMENT '影响范围: all/grade_list/stage',
    affect_params   JSON COMMENT '具体影响参数, 如年级列表',
    description     TEXT COMMENT '事件描述',
    
    -- 功能调整标记
    learning_mode   VARCHAR(20) DEFAULT 'normal' COMMENT '学习模式: normal/intensive/relaxed/off',
    push_strategy   VARCHAR(20) DEFAULT 'normal' COMMENT '推送策略: normal/reduced/silent',
    content_theme   VARCHAR(32) COMMENT '内容主题, 如 winter_camp / exam_prep / null',
    
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_term (term_id),
    INDEX idx_date (start_date, end_date),
    INDEX idx_type (event_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='校历事件';
```

### 3.3 事件类型枚举

```python
class CalendarEventType(str, Enum):

    FINAL_EXAM      = "final_exam"       # 期末考试
    MOCK_EXAM       = "mock_exam"        # 模拟考试
    ENTRANCE_EXAM   = "entrance_exam"    # 中考/高考
    WINTER_VACATION = "winter_vacation"  # 寒假
    SUMMER_VACATION = "summer_vacation"  # 暑假
    NATIONAL_DAY    = "national_day"     # 国庆
    LABOR_DAY       = "labor_day"        # 五一
    SPRING_FESTIVAL = "spring_festival"  # 春节
    MID_AUTUMN      = "mid_autumn"       # 中秋
    DRAGON_BOAT     = "dragon_boat"      # 端午
    QINGMING        = "qingming"         # 清明
    MAKEUP_DAY      = "makeup_day"       # 调休补课
    PARENT_MEETING  = "parent_meeting"   # 家长会
    SPORTS_DAY      = "sports_day"       # 运动会
    CUSTOM          = "custom"           # 自定义事件


class LearningMode(str, Enum):
    """学习模式"""
    NORMAL     = "normal"      # 正常学习
    INTENSIVE  = "intensive"   # 考试冲刺（考试季）
    RELAXED    = "relaxed"     # 轻松学习（假期）
    OFF        = "off"         # 不推荐学习（法定假日）


class PushStrategy(str, Enum):
    """推送策略"""
    NORMAL  = "normal"   # 正常推送
    REDUCED = "reduced"  # 减少推送频率（假期）
    SILENT  = "silent"   # 静默推送（法定假日）
```

### 3.4 用户学期状态表 `user_term_states`

记录每个用户每个学期的状态，用于跨学期数据追踪。

```sql
CREATE TABLE user_term_states (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL,
    year_key        CHAR(9) NOT NULL,
    semester        VARCHAR(10) NOT NULL,
    grade           INT NOT NULL COMMENT '该学期所在年级',
    stage           VARCHAR(20) NOT NULL,
    
    -- 学期状态
    status          VARCHAR(20) DEFAULT 'active' COMMENT 'active=进行中 / completed=已完成 / archived=已归档',
    activated_at    DATETIME COMMENT '学期激活时间（用户确认进入该学期）',
    completed_at    DATETIME COMMENT '学期完成时间',
    
    -- 学期学习统计快照（学期结束时写入）
    total_study_minutes  INT DEFAULT 0 COMMENT '本学期总学习时长(分钟)',
    total_questions      INT DEFAULT 0 COMMENT '本学期总答题数',
    total_mistakes       INT DEFAULT 0 COMMENT '本学期总错题数',
    avg_accuracy         DECIMAL(5,2) COMMENT '本学期平均正确率',
    
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_user_term (user_id, year_key, semester),
    INDEX idx_user (user_id),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户学期状态';
```

```sql
    INDEX idx_user (user_id),
```

```python
class GradeTransitionChecker:
    """升年级检查引擎 - 每日定时运行"""
    
    def __init__(self, db: Database, cache: Redis):
        self.db = db
        self.cache = cache
    
    async def check_all_users(self) -> list[TransitionTask]:
        """检查所有用户是否需要升年级"""
        
        today = date.today()
        
        # 1. 查找今天结束的学期
        ending_terms = await self.db.fetch_all(
            "SELECT * FROM academic_terms WHERE end_date = :today AND status = 2",
            {"today": today}
        )
        if not ending_terms:
            return []
        
        # 2. 查找下学期定义
        for term in ending_terms:
            next_term = await self._find_next_term(term)
            if not next_term:
                logger.warning(f"No next term found for {term.year_key}/{term.semester}")
                continue
            
            # 3. 查找该学期内的活跃用户
            users = await self.db.fetch_all(
                """SELECT sp.user_id, sp.grade, sp.stage 
                   FROM student_profiles sp 
                   JOIN user_term_states uts ON sp.user_id = uts.user_id
                   WHERE uts.year_key = :year_key 
                     AND uts.semester = :semester
                     AND uts.status = 'active'""",
                {"year_key": term.year_key, "semester": term.semester}
            )
            
            # 4. 为每个用户创建升年级任务
            tasks = []
            for user in users:
                to_grade = user.grade + 1
                if to_grade > 14:  # 高三毕业，不再升级
                    continue
                
                existing = await self.db.fetch_one(
                    """SELECT id FROM grade_transition_tasks 
                       WHERE user_id = :uid AND from_term = :from_term 
                       AND status IN ('pending', 'confirmed', 'processing')""",
                    {"uid": user.user_id, "from_term": f"{term.year_key}/{term.semester}"}
                )
                if existing:
                    continue  # 已有待处理的任务
                
                is_stage_change = self._is_stage_change(user.grade, to_grade)
                
                task = await self.db.execute_insert(
                    """INSERT INTO grade_transition_tasks 
                       (user_id, from_grade, to_grade, from_term, to_term, status, steps)
                       VALUES (:uid, :fg, :tg, :ft, :tt, 'pending', :steps)""",
                    {
                        "uid": user.user_id,
                        "fg": user.grade,
                        "tg": to_grade,
                        "ft": f"{term.year_key}/{term.semester}",
                        "tt": f"{next_term.year_key}/{next_term.semester}",
                        "steps": json.dumps(self._init_steps(is_stage_change))
                    }
                )
                tasks.append(task)
            
            # 5. 发送通知给用户
            for task in tasks:
                await self._send_transition_notification(task)
        
        return tasks
    
    def _is_stage_change(self, from_grade: int, to_grade: int) -> bool:
        """判断是否发生学段变更"""
        from_stage = GRADE_MAP[from_grade]["stage"]
        to_stage = GRADE_MAP[to_grade]["stage"]
        return from_stage != to_stage
    
    def _init_steps(self, is_stage_change: bool) -> list[dict]:
        """初始化迁移步骤"""
        steps = [
            {"key": "archive_old_term", "name": "归档旧学期数据", "status": "pending"},
            {"key": "update_profile", "name": "更新学生档案（年级+学期）", "status": "pending"},
            {"key": "migrate_textbook", "name": "切换教材版本映射", "status": "pending"},
            {"key": "reset_study_plan", "name": "重置学习计划", "status": "pending"},
            {"key": "preserve_mistakes", "name": "保留错题（标记为新学期未复习）", "status": "pending"},
            {"key": "generate_term_report", "name": "生成上学期学情报告", "status": "pending"},
            {"key": "publish_events", "name": "发布学期切换事件", "status": "pending"},
        ]
        if is_stage_change:
            steps.insert(3, {"key": "migrate_knowledge_points", "name": "切换知识点体系", "status": "pending"})
            steps.insert(4, {"key": "update_ui_mode", "name": "切换UI模式（分龄适配）", "status": "pending"})
        return steps
    
    async def _send_transition_notification(self, task):
        """发送升年级通知"""
        to_info = GRADE_MAP[task.to_grade]
        await event_bus.publish("grade.transition.pending", {
            "user_id": task.user_id,
            "task_id": task.id,
            "to_grade": task.to_grade,
            "to_grade_label": to_info["label"],
            "is_stage_change": self._is_stage_change(task.from_grade, task.to_grade)
        })
```

### 5.2 升年级执行引擎

```python
class GradeTransitionExecutor:
    """升年级执行引擎"""
    
    def __init__(self, db: Database, cache: Redis, event_bus: EventBus):
        self.db = db
        self.cache = cache
        self.event_bus = event_bus
    
    async def execute(self, task_id: int, options: dict) -> None:
        """执行升年级迁移"""
        
        task = await self._load_task(task_id)
        if not task:
            raise NotFoundError(f"Transition task {task_id} not found")
        
        if task.status not in ("confirmed",):
            raise BusinessError(f"Task status is {task.status}, expected 'confirmed'")
        
        # 更新状态为 processing
        await self._update_task_status(task_id, "processing")
        
        steps = json.loads(task.steps)
        
        try:
            for step in steps:
                if step["status"] == "completed":
                    continue
                
                step["status"] = "in_progress"
                step["started_at"] = datetime.utcnow().isoformat()
                await self._update_steps(task_id, steps)
                
                # 执行具体步骤
                handler = self.STEP_HANDLERS.get(step["key"])
                if handler:
                    await handler(self, task, options)
                
                step["status"] = "completed"
                step["completed_at"] = datetime.utcnow().isoformat()
                await self._update_steps(task_id, steps)
            
            # 全部完成
            await self._update_task_status(task_id, "completed")
            
        except Exception as e:
            logger.exception(f"Grade transition failed for task {task_id}")
            await self._update_task_status(task_id, "failed")
            await self._update_task_error(task_id, str(e))
            raise
    
    async def _step_archive_old_term(self, task, options):
        """步骤1：归档旧学期数据"""
        # 写入学期统计快照
        stats = await self._calculate_term_stats(task.user_id, task.from_term)
        await self.db.execute_update(
            """UPDATE user_term_states 
               SET status = 'archived', 
                   total_study_minutes = :sm,
                   total_questions = :tq,
                   total_mistakes = :tm,
                   avg_accuracy = :acc,
                   completed_at = NOW()
               WHERE user_id = :uid 
                 AND year_key = :yk 
                 AND semester = :sem""",
            {
                "uid": task.user_id,
                "yk": task.from_term.split("/")[0],
                "sem": task.from_term.split("/")[1],
                **stats
            }
        )
    
    async def _step_update_profile(self, task, options):
        """步骤2：更新学生档案"""
        new_stage = GRADE_MAP[task.to_grade]["stage"]
        new_semester = task.to_term.split("/")[1]
        new_year = task.to_term.split("/")[0]
        
        await self.db.execute_update(
            """UPDATE student_profiles 
               SET grade = :grade, 
                   stage = :stage, 
                   semester = :semester
               WHERE user_id = :uid""",
            {"grade": task.to_grade, "stage": new_stage, "semester": new_semester, "uid": task.user_id}
        )
        
        # 创建新学期记录
        await self.db.execute_insert(
            """INSERT INTO user_term_states 
               (user_id, year_key, semester, grade, stage, status, activated_at)
               VALUES (:uid, :yk, :sem, :grade, :stage, 'active', NOW())""",
            {"uid": task.user_id, "yk": new_year, "sem": new_semester, 
             "grade": task.to_grade, "stage": new_stage}
        )
    
    async def _step_migrate_textbook(self, task, options):
        """步骤3：切换教材版本"""
        edition = options.get("textbook_edition")
        if edition:
            await self.db.execute_update(
                "UPDATE student_profiles SET textbook_edition = :ed WHERE user_id = :uid",
                {"ed": edition, "uid": task.user_id}
            )
        # 如果学段变了且未指定教材版本，设为null等待用户选择
        elif self._is_stage_change(task.from_grade, task.to_grade):
            await self.db.execute_update(
                "UPDATE student_profiles SET textbook_edition = NULL WHERE user_id = :uid",
                {"uid": task.user_id}
            )
    
    async def _step_reset_study_plan(self, task, options):
        """步骤4：重置学习计划"""
        preserve = options.get("preserve_study_plan", False)
        if not preserve:
            # 将旧计划标记为已完成/归档
            await self.db.execute_update(
                """UPDATE study_plans SET status = 'archived' 
                   WHERE user_id = :uid AND status = 'active'""",
                {"uid": task.user_id}
            )
    
    async def _step_preserve_mistakes(self, task, options):
        """步骤5：保留错题，标记为新学期未复习"""
        await self.db.execute_update(
            """UPDATE mistake_records 
               SET term_review_status = 'new_term_unreviewed',
                   next_review_date = NULL
               WHERE user_id = :uid AND status = 'active'""",
            {"uid": task.user_id}
        )
    
    async def _step_generate_term_report(self, task, options):
        """步骤6：生成上学期学情报告"""
        generate = options.get("generate_term_report", True)
        if generate:
            await self.event_bus.publish("report.term_summary.requested", {
                "user_id": task.user_id,
                "year_key": task.from_term.split("/")[0],
                "semester": task.from_term.split("/")[1],
                "grade": task.from_grade,
            })
    
    async def _step_publish_events(self, task, options):
        """步骤7：发布学期切换事件"""
        await self.event_bus.publish("grade.transition.completed", {
            "user_id": task.user_id,
            "from_grade": task.from_grade,
            "to_grade": task.to_grade,
            "from_term": task.from_term,
            "to_term": task.to_term,
            "is_stage_change": self._is_stage_change(task.from_grade, task.to_grade),
        })
        
        # 清除相关缓存
        await self.cache.delete(f"academic:context:{task.user_id}:*")
        await self.cache.delete(f"student:profile:{task.user_id}")
    
    # 步骤处理器映射
    STEP_HANDLERS = {
        "archive_old_term":       _step_archive_old_term,
        "update_profile":         _step_update_profile,
        "migrate_textbook":       _step_migrate_textbook,
        "migrate_knowledge_points": _step_migrate_knowledge_points,
        "update_ui_mode":         _step_update_ui_mode,
        "reset_study_plan":       _step_reset_study_plan,
        "preserve_mistakes":      _step_preserve_mistakes,
        "generate_term_report":   _step_generate_term_report,
        "publish_events":         _step_publish_events,
    }
    
    async def _step_migrate_knowledge_points(self, task, options):
        """学段变更时：切换知识点体系"""
        new_stage = GRADE_MAP[task.to_grade]["stage"]
        # 重置与新学段无关的知识点掌握度
        await self.db.execute_update(
            """UPDATE knowledge_mastery 
               SET status = 'archived'
               WHERE user_id = :uid 
                 AND knowledge_point_id IN (
                   SELECT kp.id FROM knowledge_points kp 
                   WHERE kp.stage != :new_stage
                 )""",
            {"uid": task.user_id, "new_stage": new_stage}
        )
    
    async def _step_update_ui_mode(self, task, options):
        """学段变更时：通知客户端更新UI模式"""
        new_stage = GRADE_MAP[task.to_grade]["stage"]
        await self.event_bus.publish("ui.mode_change", {
            "user_id": task.user_id,
            "new_stage": new_stage,
            "old_stage": GRADE_MAP[task.from_grade]["stage"],
        })
```

### 5.3 教育时间上下文查询服务

```python
class AcademicContextService:
    """教育时间上下文查询服务"""
    
    def __init__(self, db: Database, cache: Redis):
        self.db = db
        self.cache = cache
    
    async def get_context(self, user_id: int, query_date: date = None) -> AcademicContext:
        """获取用户当前教育时间上下文"""
        
        query_date = query_date or date.today()
        
        # 1. 尝试从缓存获取
        cache_key = f"academic:context:{user_id}:{query_date.isoformat()}"
        cached = await self.cache.get_json(cache_key)
        if cached:
            return AcademicContext.from_dict(cached)
        
        # 2. 获取学生档案
        profile = await self.db.fetch_one(
            "SELECT * FROM student_profiles WHERE user_id = :uid",
            {"uid": user_id}
        )
        if not profile:
            raise NotFoundError(f"Student profile not found for user {user_id}")
        
        # 3. 查找当前学期
        term = await self.db.fetch_one(
            """SELECT * FROM academic_terms 
               WHERE stage = :stage 
                 AND start_date <= :date 
                 AND end_date >= :date
                 AND status = 2
               ORDER BY region_code = 'default' DESC
               LIMIT 1""",
            {"stage": profile.stage, "date": query_date}
        )
        
        # 4. 计算当前周次
        week_number = None
        if term:
            week_number = (query_date - term.start_date).days // 7 + 1
        
        # 5. 查找当前活跃事件
        active_events = await self.db.fetch_all(
            """SELECT * FROM calendar_events 
               WHERE start_date <= :date AND end_date >= :date
               ORDER BY start_date""",
            {"date": query_date}
        )
        
        # 6. 确定学习模式和推送策略
        learning_mode = self._resolve_learning_mode(active_events)
        push_strategy = self._resolve_push_strategy(active_events)
        
        # 7. 查找即将到来的事件
        upcoming_events = await self.db.fetch_all(
            """SELECT * FROM calendar_events 
               WHERE start_date > :date 
               ORDER BY start_date ASC
               LIMIT 5""",
            {"date": query_date}
        )
        
        # 8. 判断假期状态
        vacation_status = self._resolve_vacation_status(active_events, upcoming_events)
        
        # 9. 组装上下文
        context = AcademicContext(
            user=UserInfo(
                user_id=user_id,
                stage=profile.stage,
                grade=profile.grade,
                grade_label=GRADE_MAP[profile.grade]["label"],
                semester=profile.semester,
                year_key=self._resolve_year_key(term, query_date),
                term_label=self._build_term_label(term, profile)
            ),
            term=TermInfo.from_db(term) if term else None,
            timing=TimingInfo(
                current_date=query_date,
                week_number=week_number,
                is_exam_season=any(e.event_type in ("midterm_exam", "final_exam", "mock_exam", "entrance_exam") for e in active_events),
                is_vacation=vacation_status.is_in_vacation,
                is_holiday=any(e.event_type in ("national_day", "labor_day", "spring_festival", "qingming", "dragon_boat", "mid_autumn") for e in active_events),
                learning_mode=learning_mode,
                push_strategy=push_strategy,
                days_until_term_end=(term.end_date - query_date).days if term else None,
                days_until_next_exam=self._days_until_next_exam(active_events, upcoming_events),
                next_exam_name=self._next_exam_name(active_events, upcoming_events),
            ),
            active_events=[EventInfo.from_db(e) for e in active_events],
            upcoming_events=[EventInfo.from_db(e) for e in upcoming_events[:3]],
            vacation_status=vacation_status,
        )
        
        # 10. 写入缓存
        await self.cache.set_json(cache_key, context.to_dict(), ttl=3600)
        
        return context
    
    def _resolve_learning_mode(self, events: list) -> str:
        """根据当前事件确定学习模式（优先级：off > intensive > relaxed > normal）"""
        if not events:
            return "normal"
        
        priority = {"off": 4, "intensive": 3, "relaxed": 2, "normal": 1}
        modes = [e.learning_mode for e in events if e.learning_mode]
        if not modes:
            return "normal"
        return max(modes, key=lambda m: priority.get(m, 0))
    
    def _resolve_push_strategy(self, events: list) -> str:
        """根据当前事件确定推送策略"""
        if not events:
            return "normal"
        for mode in ["silent", "reduced"]:
            if any(e.push_strategy == mode for e in events):
                return mode
        return "normal"
    
    def _resolve_vacation_status(self, active: list, upcoming: list) -> VacationStatus:
        """判断假期状态"""
        # 当前是否在假期中
        current_vacation = None
        for e in active:
            if e.event_type in ("winter_vacation", "summer_vacation"):
                current_vacation = VacationInfo(
                    name=e.name, type=e.event_type,
                    start_date=e.start_date, end_date=e.end_date,
                )
                break
        
        # 下一个假期
        next_vacation = None
        for e in upcoming:
            if e.event_type in ("winter_vacation", "summer_vacation"):
                next_vacation = VacationInfo(
                    name=e.name, type=e.event_type,
                    start_date=e.start_date, end_date=e.end_date,
                )
                break
        
        return VacationStatus(
            is_in_vacation=current_vacation is not None,
            current=current_vacation,
            next=next_vacation,
        )
```

```dart
/// APP 启动时调用
Future<void> checkGradeTransitionOnStartup(WidgetRef ref) async {
  final api = ref.read(apiProvider);
  
  try {
    final response = await api.post('/api/v1/academic/transition/check');
    final data = response.data;
    
    if (data['needs_transition'] == true) {
      final transition = TransitionInfo.fromJson(data['transition']);
      
      // 延迟显示，等首页加载完成
      await Future.delayed(const Duration(seconds: 2));
      
      // 弹出确认弹窗
      final confirmed = await showDialog<bool>(
        context: navigatorKey.currentContext!,
        barrierDismissible: false,
        builder: (_) => GradeTransitionDialog(transition: transition),
      );
      
      if (confirmed == true) {
        // 执行迁移
        final taskId = transition.taskId;
        await _pollTransitionStatus(api, ref, taskId);
      }
    }
  } catch (e) {
    logger.warning('Grade transition check failed: $e');
    // 静默失败，不影响正常使用
  }
}

Future<void> _pollTransitionStatus(ApiService api, WidgetRef ref, int taskId) async {
  // 轮询任务状态
  for (var i = 0; i < 30; i++) {
    await Future.delayed(const Duration(seconds: 1));
    
    final response = await api.get('/api/v1/academic/transition/$taskId');
    final status = response.data['status'];
    
    if (status == 'completed') {
      // 刷新所有上下文
      ref.invalidate(academicContextProvider);
      ref.invalidate(studentProfileProvider);
      ref.invalidate(homeDataProvider);
      
      // 显示成功提示
      ScaffoldMessenger.of(navigatorKey.currentContext!).showSnackBar(
        const SnackBar(content: Text('🎉 升级成功！开始新学期的学习吧！')),
      );
      return;
    }
    
    if (status == 'failed') {
      ScaffoldMessenger.of(navigatorKey.currentContext!).showSnackBar(
        const SnackBar(content: Text('升级遇到问题，请稍后重试')),
      );
      return;
    }
  }
}
```

## 10. 错误处理

### 10.1 错误码

| 错误码 | 说明 | 客户端处理 |
|--------|------|-----------|
| `ACADEMIC_001` | 学期定义不存在 | 提示稍后重试 |
| `ACADEMIC_002` | 升年级任务不存在 | 刷新页面 |
| `ACADEMIC_003` | 升年级任务状态不允许此操作 | 显示当前状态 |
| `ACADEMIC_004` | 学段变更时教材版本不能为空 | 弹出教材选择 |
| `ACADEMIC_005` | 升年级迁移步骤执行失败 | 显示重试按钮 |
| `ACADEMIC_006` | 用户已处于最新学期 | 忽略 |
| `ACADEMIC_007` | 年级已达上限（高三毕业） | 显示毕业祝福 |
| `ACADEMIC_008` | 校历事件日期冲突 | 管理后台提示修改 |
| `ACADEMIC_009` | 学期日期不合法（结束日期早于开始日期） | 管理后台提示修改 |

### 10.2 降级策略

| 故障场景 | 降级策略 |
|----------|----------|
| 学期定义表不可用 | 使用客户端本地缓存的学期信息（上次成功获取的） |
| 升年级迁移失败 | 回滚已执行的步骤，恢复旧学期数据，通知用户稍后重试 |
| 校历事件查询失败 | 降级为只返回假期时段（硬编码全国统一的法定假日） |
| 上下文缓存失效 | 直接查库，性能降级但功能正常 |
| 事件发布失败 | 写入本地重试表，后续补偿发布 |

## 13. 安全与合规

1. **管理后台操作**：学期/校历的创建、修改、删除需管理员权限，操作记录审计日志
2. **升年级操作**：必须用户本人确认（Token验证），不可由家长或管理员代操作
3. **学期数据归档**：归档数据不可修改，仅支持查询，确保历史数据完整性
4. **年龄推算**：根据用户年级和出生日期交叉验证，发现不一致时提醒用户确认
5. **毕业处理**：高三（grade=14）用户不再触发升年级检查，系统发送毕业祝福后归档
