## 2. 完整用户旅程

### 2.1 用户旅程步骤

```
Step 1: 进入计时器首页
    → 用户从首页快捷入口 / 底部导航 / 学习任务卡片进入
    → 展示上次使用记录、今日专注概览、快速开始按钮

Step 2: 配置学习参数
    → 选择科目（必选）
    → 选择教材章节（可选）
    → 关联学习任务（可选，从今日任务列表选择）
    → 选择计时模式（番茄25+5 / 番茄45+10 / 自定义 / 倒计时）
    → 选择白噪音（可选）

Step 3: 开始专注
    → 点击"开始专注"
    → 客户端创建本地会话，同时请求服务端创建会话
    → 屏幕常亮、静音非紧急通知
    → 倒计时动画启动

Step 4: 专注进行中
    → 每秒更新倒计时显示
    → 每30秒本地持久化当前进度（防崩溃恢复）
    → 监测用户是否离开APP（触发中断记录）
    → 到达专注时长后自动结束本轮

Step 5: 番茄钟休息
    → 显示休息界面（轻量互动 / 伸展提醒）
    → 护眼模式联动：休息期间推送护眼提示
    → 休息结束可选择"继续专注"或"结束会话"

Step 6: 会话结束
    → 用户主动结束 或 完成所有预设周期
    → 计算专注得分
    → 展示会话结算页面（专注时长、完成周期数、得分、奖励）
    → 数据上报服务端

Step 7: 后处理
    → 学习记录写入
    → 专注统计聚合更新（Redis → 定期落库）
    → 学习时长有效性判定
    → 成就/XP奖励触发
    → 学习任务完成度更新（如果关联了任务）
    → 学情画像更新
```

## 4. 服务端API详细设计

### 4.1 创建学习会话

```
POST /api/v1/timer/sessions
Authorization: Bearer {token}
Content-Type: application/json
```

**请求体：**
```json
{
  "subjectId": "math_grade8",
  "chapterId": "math_grade8_ch3_2",    // 可选
  "taskId": "task_20260605_001",        // 可选，关联学习计划任务
  "taskType": "SYNC_CLASS_REVIEW",      // 可选
  "mode": "POMODORO_25_5",
  "plannedCycles": 4,                   // 计划完成几个周期，0表示不限
  "clientStartTime": "2026-06-05T18:00:00.000Z",
  "deviceType": "android",
  "appVersion": "1.0.0"
}
```

**响应体（201 Created）：**
```json
{
  "sessionId": "ss_01HXXXXXXXXXXXXX",
  "serverTime": "2026-06-05T18:00:01.234Z",
  "modeConfig": {
    "focusSeconds": 1500,
    "breakSeconds": 300,
    "longBreakSeconds": 900,
    "longBreakInterval": 4
  }
}
```

**校验规则：**
- `subjectId` 必须属于当前用户所在学段的合法科目
- `taskId` 如提供，必须属于当前用户且状态为 `PENDING` 或 `IN_PROGRESS`
- `mode` 必须为系统预设或用户自定义的有效模式
- 同一用户同时只能有一个 `ACTIVE` 状态的会话

**错误码：**

| 错误码 | HTTP状态 | 说明 |
|--------|---------|------|
| `TIMER_ACTIVE_SESSION_EXISTS` | 409 | 已有进行中的会话，需先结束 |
| `INVALID_SUBJECT` | 400 | 科目不属于当前学段 |
| `TASK_NOT_FOUND` | 404 | 关联任务不存在 |
| `TASK_ALREADY_COMPLETED` | 409 | 关联任务已完成 |
| `MEMBER_QUOTA_EXCEEDED` | 403 | 非会员每日专注次数已达上限 |

**服务端校验（防作弊）：**
```java
// 核心校验逻辑伪代码
public void validateCycle(String sessionId, CycleReport report) {
    StudySession session = sessionRepo.findById(sessionId);
    
    // 1. 时序校验：周期时间必须在会话时间范围内
    if (report.focusStartAt.isBefore(session.getStartTime()) 
        || report.focusEndAt.isAfter(Instant.now())) {
        throw new InvalidCycleException("TIMESTAMP_OUT_OF_RANGE");
    }
    
    // 2. 时长校验：专注时长不能超过模式设定时长的 110%
    ModeConfig config = getModeConfig(session.getMode());
    int maxAllowedFocus = (int)(config.focusSeconds * 1.1);
    if (report.focusSeconds > maxAllowedFocus) {
        throw new InvalidCycleException("FOCUS_DURATION_EXCEEDED");
    }
    
    // 3. 连续性校验：相邻周期不能有时间重叠
    PomodoroCycle lastCycle = cycleRepo.findLastBySession(sessionId);
    if (lastCycle != null && !report.focusStartAt.isAfter(lastCycle.getBreakEndAt())) {
        throw new InvalidCycleException("CYCLE_OVERLAP");
    }
    
    // 4. 时钟偏移校验：客户端时间与服务器时间差不超过5分钟
    Duration drift = Duration.between(report.clientTimestamp, Instant.now());
    if (drift.abs().toMinutes() > 5) {
        // 不拒绝，但标记为可疑
        report.setSuspicious(true);
        report.setSuspicionReason("CLOCK_DRIFT_" + drift.toMinutes() + "min");
    }
    
    // 5. 速率校验：周期上报间隔不能短于专注时长的50%
    if (lastCycle != null) {
        Duration sinceLastCycle = Duration.between(
            lastCycle.getCreatedAt(), Instant.now());
        if (sinceLastCycle.toSeconds() < config.focusSeconds * 0.5) {
            throw new InvalidCycleException("CYCLE_TOO_FREQUENT");
        }
    }
}
```

## 5. 数据库设计

### 5.1 study_sessions 表

```sql
CREATE TABLE study_sessions (
    id              VARCHAR(36)     PRIMARY KEY,          -- UUID v7
    user_id         VARCHAR(36)     NOT NULL,
    subject_id      VARCHAR(64)     NOT NULL,
    chapter_id      VARCHAR(64),                          -- 可选
    task_id         VARCHAR(36),                          -- 关联学习任务
    task_type       VARCHAR(32),                          -- SYNC_CLASS_REVIEW / MISTAKE_REVIEW / PRACTICE / FREE_STUDY
    mode            VARCHAR(32)     NOT NULL,             -- POMODORO_25_5 / POMODORO_45_10 / CUSTOM / COUNTDOWN
    status          VARCHAR(16)     NOT NULL DEFAULT 'ACTIVE',  -- ACTIVE / PAUSED / COMPLETED / ABANDONED
    
    start_time      TIMESTAMPTZ     NOT NULL,
    end_time        TIMESTAMPTZ,
    total_focus_seconds   INT       NOT NULL DEFAULT 0,
    total_break_seconds   INT       NOT NULL DEFAULT 0,
    completed_cycles      INT       NOT NULL DEFAULT 0,
    planned_cycles        INT       NOT NULL DEFAULT 0,
    interruption_count    INT       NOT NULL DEFAULT 0,
    total_interruption_seconds INT  NOT NULL DEFAULT 0,
    
    focus_score     SMALLINT,                             -- 0-100, 会话结束时计算
    is_suspicious   BOOLEAN         NOT NULL DEFAULT FALSE, -- 防作弊标记
```

## 6. 状态流转

### 6.1 学习会话状态机

```
                    ┌──────────┐
                    │  START   │
                    └────┬─────┘
                         │ createSession()
                         ▼
┌─────────────────────────────────────────────────────────────────────┐
│                              ACTIVE                                 │
│  专注进行中，可接收：pause / reportCycle / finish / abandon / timeout  │
└──────┬────────────────┬───────────────┬───────────────┬───────────────┘
       │ pause          │ cycle report  │ finish        │ abandon/timeout
       ▼                │               │               │
  ┌─────────┐          │               │               │
  │ PAUSED  │──resume──┤               │               │
  └─────────┘          │               │               │
                       ▼               ▼               ▼
                ┌────────────┐ ┌────────────┐ ┌────────────┐
                │   ACTIVE   │ │  COMPLETED │ │ ABANDONED  │
                │ (next cycle) │ │ 正常结束    │ │ 放弃/超时   │
                └────────────┘ └────────────┘ └────────────┘
```

**状态转移表**

| 当前状态 | 事件 | 新状态 | 守卫条件 |
| --- | --- | --- | --- |
| START | createSession | ACTIVE | 无其他 ACTIVE/PAUSED 会话 |
| ACTIVE | reportCycle | ACTIVE | 周期校验通过 |
| ACTIVE | pause | PAUSED | 专注阶段才可暂停（休息阶段不可暂停） |
| PAUSED | resume | ACTIVE | 恢复后专注阶段继续 |
| PAUSED | finish | COMPLETED | 至少完成一个有效专注周期 |
| PAUSED | abandon | ABANDONED | 无有效周期或用户主动放弃 |
| ACTIVE | finish | COMPLETED | 至少完成一个有效专注周期 |
| ACTIVE | abandon | ABANDONED | 无有效周期或用户主动放弃 |
| ACTIVE | timeout | ABANDONED | 超过最大允许会话时长（8 小时） |

### 6.2 番茄钟周期状态机

```
PENDING ──startFocus──> FOCUS_ACTIVE ──focusComplete──> FOCUS_COMPLETED ──startBreak──> BREAK_ACTIVE ──breakComplete──> BREAK_COMPLETED
                                                             │
                                                             │ skipBreak
                                                             ▼
                                                       CYCLE_COMPLETED
```

**周期阶段说明**

| 阶段 | 含义 | 可触发动作 |
| --- | --- | --- |
| PENDING | 待开始 | startFocus |
| FOCUS_ACTIVE | 专注进行中 | pauseFocus / resumeFocus / focusComplete |
| FOCUS_COMPLETED | 专注完成 | startBreak / skipBreak |
| BREAK_ACTIVE | 休息进行中 | pauseBreak / resumeBreak / breakComplete |
| BREAK_COMPLETED | 休息完成 | 进入下一周期或结束会话 |
| SKIPPED | 跳过休息 | 直接进入下一周期 |

### 6.3 关键状态守卫（G1-G8）

| 守卫 | 规则 | 失败处理 |
| --- | --- | --- |
| G1 | 同一用户同时只能存在一个非终态会话（ACTIVE/PAUSED） | 返回 409 TIMER_ACTIVE_SESSION_EXISTS |
| G2 | 暂停操作只能在专注阶段执行，休息阶段不可暂停 | 返回 400 PAUSE_NOT_ALLOWED_IN_BREAK |
| G3 | 周期时间戳必须在会话起止范围内 | 返回 400 TIMESTAMP_OUT_OF_RANGE |
| G4 | 专注时长不得超过模式设定时长的 110% | 返回 400 FOCUS_DURATION_EXCEEDED |
| G5 | 相邻周期不可有时间重叠 | 返回 409 CYCLE_OVERLAP |
| G6 | 客户端与服务端时钟偏移不得超过 5 分钟 | 标记 suspicious 但不拒绝 |
| G7 | 会话最大时长不超过 8 小时 | 服务端强制标记为 ABANDONED |
| G8 | 每日专注总时长受学段防沉迷硬顶限制 | 返回 403 DAILY_FOCUS_LIMIT_REACHED |

## 9. 降级与异常补偿策略

### 9.1 降级矩阵

| 编号 | 异常场景 | 降级策略 | 红线 |
| --- | --- | --- | --- |
| D1 | Redis 缓存不可用 | 直接查 MySQL，延迟增加但保证可用 | 不拒绝核心计时请求 |
| D2 | 事件总线不可用 | 写入 timer_outbox，待恢复后重试 | 事件不丢失 |
| D3 | 学情分析服务不可用 | 本地累计数据，服务恢复后批量同步 | 不影响计时主流程 |
| D4 | 成就引擎不可用 | XP 与勋章延迟发放，24h 内补发 | 不阻塞会话结束 |
| D5 | 防沉迷查询失败 | 取该学段最严格默认上限 | fail-secure 保护未成年人 |
| D6 | 数据库写入失败 | 客户端本地保留数据，指数退避重试 | 用户数据不丢失 |
| D7 | 护眼模式服务不可用 | 休息提示由客户端本地兜底 | 不影响专注计时 |
| D8 | 服务端时钟漂移过大 | 标记 suspicious，不拒绝但降低成就奖励 | 不中断学习 |

### 9.2 补偿机制

1. **会话恢复补偿**：客户端崩溃后，下次启动时检查本地未同步会话，自动发起 `/timer/sessions/{id}/recover`。
2. **周期漏报补偿**：服务端会话结束时，如周期数与客户端上报不一致，按客户端最后上报时间补齐。
3. **事件重放补偿**：`timer_outbox` 消费失败时按 2^n 退避重试，超过 7 次转死信队列人工处理。
4. **每日摘要补偿**：凌晨 04:00 跑批任务补齐昨日未聚合会话数据。

## 12. 验收场景

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| 1 | 用户开始一个 25 分钟番茄钟 | 服务端创建 ACTIVE 会话，客户端倒计时启动 |
| 2 | 专注完成自动进入休息 | 周期上报成功，服务端返回休息结束时间 |
| 3 | 用户主动暂停后继续 | 会话状态 PAUSED -> ACTIVE，中断时长记录 |
| 4 | 休息期间退出 APP | 休息不计入有效专注时长 |
| 5 | 网络中断后恢复 | 本地数据自动同步，服务端状态一致 |
| 6 | 同时创建两个会话 | 第二个返回 59601，提示已有进行中的会话 |
| 7 | 专注时长超过模式 110% | 返回 59608，标记 suspicious |
| 8 | 相邻周期时间重叠 | 返回 59609，要求修正 |
| 9 | 8 小时未结束 | 服务端自动标记 ABANDONED |
| 10 | 达到学段每日上限 | 返回 59613，提示休息 |
| 11 | 会话结束后成就触发 | XP/勋章正确发放 |
| 12 | 关联任务完成 | 学习计划任务进度更新 |
| 13 | 家长端查看周统计 | 返回聚合数据，不包含单题明细 |
| 14 | 每日目标达成 | 触发 daily_goal.achieved 事件 |
| 15 | 服务端宕机后恢复 | Outbox 事件继续投递，数据一致性可恢复 |
| 16 | 客户端崩溃后重启 | 恢复上次未结束会话 |
| 17 | 自定义非法模式 | 返回 59614，提示参数范围 |
| 18 | 休息时收到护眼提示 | 客户端展示休息引导，不中断倒计时 |
