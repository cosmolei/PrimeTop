## 2. 完整用户旅程

### 2.1 用户旅程步骤

```
Step 1: 进入计时器首页
    → 用户从首页快捷入口 / 底部导航 / 学习任务卡片进入
    → 展示上次使用记录、今日专注概览、快速开始按钮

Step 2: 配置学习参数
    → 选择科目（必选）
    → 选择教材章节（可选）
    → 关联学习任务（可选，从今日任务列表选择）
    → 选择计时模式（番茄25+5 / 番茄45+10 / 自定义 / 倒计时）
    → 选择白噪音（可选）

Step 3: 开始专注
    → 点击"开始专注"
    → 客户端创建本地会话，同时请求服务端创建会话
    → 屏幕常亮、静音非紧急通知
    → 倒计时动画启动

Step 4: 专注进行中
    → 每秒更新倒计时显示
    → 每30秒本地持久化当前进度（防崩溃恢复）
    → 监测用户是否离开APP（触发中断记录）
    → 到达专注时长后自动结束本轮

Step 5: 番茄钟休息
    → 显示休息界面（轻量互动 / 伸展提醒）
    → 护眼模式联动：休息期间推送护眼提示
    → 休息结束可选择"继续专注"或"结束会话"

Step 6: 会话结束
    → 用户主动结束 或 完成所有预设周期
    → 计算专注得分
    → 展示会话结算页面（专注时长、完成周期数、得分、奖励）
    → 数据上报服务端

Step 7: 后处理
    → 学习记录写入
    → 专注统计聚合更新（Redis → 定期落库）
    → 学习时长有效性判定
    → 成就/XP奖励触发
    → 学习任务完成度更新（如果关联了任务）
    → 学情画像更新
```

## 4. 服务端API详细设计

### 4.1 创建学习会话

```
POST /api/v1/timer/sessions
Authorization: Bearer {token}
Content-Type: application/json
```

**请求体：**
```json
{
  "subjectId": "math_grade8",
  "chapterId": "math_grade8_ch3_2",    // 可选
  "taskId": "task_20260605_001",        // 可选，关联学习计划任务
  "taskType": "SYNC_CLASS_REVIEW",      // 可选
  "mode": "POMODORO_25_5",
  "plannedCycles": 4,                   // 计划完成几个周期，0表示不限
  "clientStartTime": "2026-06-05T18:00:00.000Z",
  "deviceType": "android",
  "appVersion": "1.0.0"
}
```

**响应体（201 Created）：**
```json
{
  "sessionId": "ss_01HXXXXXXXXXXXXX",
  "serverTime": "2026-06-05T18:00:01.234Z",
  "modeConfig": {
    "focusSeconds": 1500,
    "breakSeconds": 300,
    "longBreakSeconds": 900,
    "longBreakInterval": 4
  }
}
```

**校验规则：**
- `subjectId` 必须属于当前用户所在学段的合法科目
- `taskId` 如提供，必须属于当前用户且状态为 `PENDING` 或 `IN_PROGRESS`
- `mode` 必须为系统预设或用户自定义的有效模式
- 同一用户同时只能有一个 `ACTIVE` 状态的会话

**错误码：**

| 错误码 | HTTP状态 | 说明 |
|--------|---------|------|
| `TIMER_ACTIVE_SESSION_EXISTS` | 409 | 已有进行中的会话，需先结束 |
| `INVALID_SUBJECT` | 400 | 科目不属于当前学段 |
| `TASK_NOT_FOUND` | 404 | 关联任务不存在 |
| `TASK_ALREADY_COMPLETED` | 409 | 关联任务已完成 |
| `MEMBER_QUOTA_EXCEEDED` | 403 | 非会员每日专注次数已达上限 |

**服务端校验（防作弊）：**
```java
// 核心校验逻辑伪代码
public void validateCycle(String sessionId, CycleReport report) {
    StudySession session = sessionRepo.findById(sessionId);
    
    // 1. 时序校验：周期时间必须在会话时间范围内
    if (report.focusStartAt.isBefore(session.getStartTime()) 
        || report.focusEndAt.isAfter(Instant.now())) {
        throw new InvalidCycleException("TIMESTAMP_OUT_OF_RANGE");
    }
    
    // 2. 时长校验：专注时长不能超过模式设定时长的 110%
    ModeConfig config = getModeConfig(session.getMode());
    int maxAllowedFocus = (int)(config.focusSeconds * 1.1);
    if (report.focusSeconds > maxAllowedFocus) {
        throw new InvalidCycleException("FOCUS_DURATION_EXCEEDED");
    }
    
    // 3. 连续性校验：相邻周期不能有时间重叠
    PomodoroCycle lastCycle = cycleRepo.findLastBySession(sessionId);
    if (lastCycle != null && !report.focusStartAt.isAfter(lastCycle.getBreakEndAt())) {
        throw new InvalidCycleException("CYCLE_OVERLAP");
    }
    
    // 4. 时钟偏移校验：客户端时间与服务器时间差不超过5分钟
    Duration drift = Duration.between(report.clientTimestamp, Instant.now());
    if (drift.abs().toMinutes() > 5) {
        // 不拒绝，但标记为可疑
        report.setSuspicious(true);
        report.setSuspicionReason("CLOCK_DRIFT_" + drift.toMinutes() + "min");
    }
    
    // 5. 速率校验：周期上报间隔不能短于专注时长的50%
    if (lastCycle != null) {
        Duration sinceLastCycle = Duration.between(
            lastCycle.getCreatedAt(), Instant.now());
        if (sinceLastCycle.toSeconds() < config.focusSeconds * 0.5) {
            throw new InvalidCycleException("CYCLE_TOO_FREQUENT");
        }
    }
}
```

## 5. 数据库设计

### 5.1 study_sessions 表

```sql
CREATE TABLE study_sessions (
    id              VARCHAR(36)     PRIMARY KEY,          -- UUID v7
    user_id         VARCHAR(36)     NOT NULL,
    subject_id      VARCHAR(64)     NOT NULL,
    chapter_id      VARCHAR(64),                          -- 可选
    task_id         VARCHAR(36),                          -- 关联学习任务
    task_type       VARCHAR(32),                          -- SYNC_CLASS_REVIEW / MISTAKE_REVIEW / PRACTICE / FREE_STUDY
    mode            VARCHAR(32)     NOT NULL,             -- POMODORO_25_5 / POMODORO_45_10 / CUSTOM / COUNTDOWN
    status          VARCHAR(16)     NOT NULL DEFAULT 'ACTIVE',  -- ACTIVE / PAUSED / COMPLETED / ABANDONED
    
    start_time      TIMESTAMPTZ     NOT NULL,
    end_time        TIMESTAMPTZ,
    total_focus_seconds   INT       NOT NULL DEFAULT 0,
    total_break_seconds   INT       NOT NULL DEFAULT 0,
    completed_cycles      INT       NOT NULL DEFAULT 0,
    planned_cycles        INT       NOT NULL DEFAULT 0,
    interruption_count    INT       NOT NULL DEFAULT 0,
    total_interruption_seconds INT  NOT NULL DEFAULT 0,
    
    focus_score     SMALLINT,                             -- 0-100, 会话结束时计算
    is_suspicious   BOOLEAN         NOT NULL DEFAULT FALSE, -- 防作弊标记
```
