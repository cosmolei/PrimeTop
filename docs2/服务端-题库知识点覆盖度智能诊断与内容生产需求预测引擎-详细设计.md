# 服务端 - 题库知识点覆盖度智能诊断与内容生产需求预测引擎 - 详细设计

> **原始需求来源**: `docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` §6.3（拍照搜题）、§7.3（管理后台-题库管理）、§8.6（数据架构）、§12.1（内容体系迭代）
>
> **关联模块**: 题目与题库服务、知识点体系与教材映射引擎、教育内容布鲁姆认知层级自动分类引擎、题库质量监控与题目生命周期管理服务、AI题目智能生成引擎、教育热点追踪与考试命题趋势预测分析引擎

## 1. 概述

### 1.1 模块定位

题库知识点覆盖度智能诊断与内容生产需求预测引擎（Question Bank Coverage Diagnosis & Content Production Demand Prediction Engine，简称 QBC-CDP）是 PrimeTop 题库内容治理体系的**战略决策中枢**。

现有模块各自关注：
- 题库质量监控（QBQLS）：单题质量、生命周期管理
- 题目知识点自动标注：题目→知识点映射
- 布鲁姆认知层级标注：题目认知深度分类
- 考试命题蓝图：考试维度的知识点覆盖

**但没有任何模块回答以下关键运营问题**：
1. 某教材版本的某一章节，题库中有多少道题？够不够用？
2. 哪些知识点的题目只有单一难度？哪些只有选择题？
3. 按布鲁姆认知层级统计，哪些章节的题目全部停留在"记忆"层，缺乏"分析/评价"题目？
4. 基于考试趋势和用户增长预测，下个季度需要生产多少题目？什么类型？
5. 题库的覆盖盲区在哪里？哪些知识点的题目数量低于最低阈值？

QBC-CDP 正是为填补这一空白而设计。

### 1.2 核心目标

| 目标 | 说明 | 成功标准 |
|------|------|----------|
| 覆盖度全景扫描 | 对题库进行多维度（知识点×难度×题型×认知层级×教材章节）覆盖度统计 | 全量扫描完成率 100%，日增量更新 |
| 盲区智能识别 | 自动发现题目数量低于阈值的维度组合 | 覆盖盲区识别准确率 ≥ 95% |
| 内容生产需求预测 | 基于覆盖度、使用趋势、考试热度预测题目生产需求 | 月度生产建议采纳率 ≥ 60% |
| 生产任务智能分发 | 将生产需求转化为结构化工单，分发到人工教研或AI生成管线 | 工单自动创建率 ≥ 80% |
| 覆盖度看板 | 为运营团队提供可视化覆盖度报告 | 看板数据更新延迟 ≤ 1h |

### 1.3 适用范围

- **服务对象**: 管理后台运营驾驶舱、内容生产管线、AI题目生成引擎、教研团队工单系统
- **数据范围**: 全学段（幼儿~高中）、全学科题库
- **分析维度**: 知识点、教材版本、章节、难度、题型、认知层级、来源类型

## 2. 数据结构定义

### 2.1 覆盖度快照主表 `qbc_coverage_snapshot`

存储每次全量/增量扫描的覆盖度快照结果。

```sql
CREATE TABLE qbc_coverage_snapshot (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    snapshot_no     VARCHAR(64)  NOT NULL COMMENT '快照编号: SS-{yyyyMMddHHmm}',
    scope_type      VARCHAR(20)  NOT NULL COMMENT '范围类型: GLOBAL/TEXTBOOK/CHAPTER/KP/EXAM',
    scope_id        VARCHAR(64)  NULL     COMMENT '范围ID(章节ID/知识点ID等, GLOBAL时为NULL)',
    scope_label     VARCHAR(200) NULL     COMMENT '范围可读名称',

    -- 基础统计
    total_questions INT          NOT NULL DEFAULT 0 COMMENT '题目总数(有效状态)',
    active_questions INT         NOT NULL DEFAULT 0 COMMENT '活跃题目数(近90天有使用)',
    new_questions_30d INT        NOT NULL DEFAULT 0 COMMENT '近30天新增题目数',

    -- 维度覆盖
    kp_coverage_count  INT       NOT NULL DEFAULT 0 COMMENT '已覆盖知识点数',
    kp_total_count     INT       NOT NULL DEFAULT 0 COMMENT '该范围内知识点总数',
    kp_coverage_rate   DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '知识点覆盖率 0-1',

    difficulty_distribution JSON  NULL COMMENT '难度分布: {"easy":120,"medium":85,"hard":30}',
    type_distribution     JSON  NULL COMMENT '题型分布: {"choice":200,"fill":50,"essay":15}',
    cognitive_distribution JSON  NULL COMMENT '认知层级分布: {"L1":150,"L2":80,"L3":40,"L4":15,"L5":5,"L6":3}',
    source_distribution   JSON  NULL COMMENT '来源分布: {"official":100,"textbook":80,"exam":50,"third_party":30,"ai":20}',

    -- 健康度评分
    coverage_score   DECIMAL(5,2) NOT NULL DEFAULT 0 COMMENT '覆盖度综合评分 0-100',
    gap_count        INT          NOT NULL DEFAULT 0 COMMENT '覆盖盲区数量',
    risk_level       VARCHAR(10)  NOT NULL DEFAULT 'GREEN' COMMENT 'RED/YELLOW/GREEN',

    -- 元数据
    scan_type       VARCHAR(10)  NOT NULL COMMENT 'FULL/INCREMENTAL',
    created_at      DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    scan_duration_ms INT         NOT NULL DEFAULT 0 COMMENT '扫描耗时(毫秒)',

    PRIMARY KEY (id),
    UNIQUE KEY uk_snapshot_scope (snapshot_no, scope_type, scope_id),
    KEY idx_scope (scope_type, scope_id, created_at DESC),
    KEY idx_risk (risk_level, coverage_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题库覆盖度快照表';
```

### 2.2 覆盖盲区明细表 `qbc_coverage_gap`

存储识别出的每个覆盖盲区。

```sql
CREATE TABLE qbc_coverage_gap (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    snapshot_id     BIGINT       NOT NULL COMMENT '关联快照ID',

    -- 盲区定位 (维度组合)
    textbook_id     BIGINT       NULL COMMENT '教材版本ID',
    chapter_id      BIGINT       NULL COMMENT '章节ID',
    knowledge_point_id BIGINT    NULL COMMENT '知识点ID',
    subject         VARCHAR(20)  NULL COMMENT '学科',
    grade_level     VARCHAR(20)  NULL COMMENT '学段年级',

    -- 缺口描述
    gap_type        VARCHAR(30)  NOT NULL COMMENT '盲区类型: KP_EMPTY/DIFFICULTY_MISSING/TYPE_MISSING/COGNITIVE_MISSING/QUANTITY_INSUFFICIENT',
    gap_dimension   VARCHAR(30)  NULL COMMENT '维度值: 如 difficulty=hard, type=essay, cognitive=L5',
    current_count   INT          NOT NULL DEFAULT 0 COMMENT '当前题目数量',
    required_count  INT          NOT NULL DEFAULT 0 COMMENT '最低需求数量',
    shortfall       INT          NOT NULL DEFAULT 0 COMMENT '缺口数量 = required - current',

    -- 优先级与紧急度
    priority        VARCHAR(10)  NOT NULL DEFAULT 'P2' COMMENT 'P0/P1/P2/P3',
    urgency_score   DECIMAL(5,2) NOT NULL DEFAULT 0 COMMENT '紧急度评分 0-100',
    exam_relevance  DECIMAL(3,2) NOT NULL DEFAULT 0 COMMENT '考试关联度 0-1',
    usage_frequency INT          NOT NULL DEFAULT 0 COMMENT '近90天该维度被请求次数',

    -- 状态
    status          VARCHAR(20)  NOT NULL DEFAULT 'OPEN' COMMENT 'OPEN/IN_PRODUCTION/FILLED/WONT_FIX',
    assigned_to     VARCHAR(50)  NULL COMMENT '分配给(教研团队/AI生成管线)',
    production_order_id BIGINT   NULL COMMENT '关联生产工单ID',

    created_at      DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at      DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    resolved_at     DATETIME(3)  NULL COMMENT '解决时间',

    PRIMARY KEY (id),
    KEY idx_snapshot (snapshot_id),
    KEY idx_status_priority (status, priority, urgency_score DESC),
    KEY idx_kp (knowledge_point_id, gap_type),
    KEY idx_chapter (chapter_id, gap_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='覆盖盲区明细表';
```

## 4. 核心算法

### 4.1 覆盖度全景扫描算法

```python
class CoverageScanner:
    """题库覆盖度全景扫描器"""

    # 维度定义
    DIMENSIONS = {
        'KNOWLEDGE_POINT': '知识点',
        'DIFFICULTY': '难度 (1-5)',
        'TYPE': '题型',
        'COGNITIVE_LEVEL': '布鲁姆认知层级 (L1-L6)',
        'SOURCE': '来源类型'
    }

    DIFFICULTY_LEVELS = {1: 'easy', 2: 'easy-medium', 3: 'medium',
                         4: 'medium-hard', 5: 'hard'}
    COGNITIVE_LEVELS = ['L1', 'L2', 'L3', 'L4', 'L5', 'L6']

    def scan(self, scan_type: str, scope_type: str, scope_ids: list,
             dimensions: list) -> dict:
        """
        执行覆盖度扫描
        :param scan_type: FULL / INCREMENTAL
        :param scope_type: GLOBAL / TEXTBOOK / CHAPTER / KP
        :param scope_ids: 范围ID列表
        :param dimensions: 要计算的维度
        :return: 扫描结果摘要
        """
        start_time = time.time()
        snapshot_no = f"SS-{datetime.now().strftime('%Y%m%d%H%M')}"

        # Step 1: 确定扫描范围
        scopes = self._resolve_scopes(scope_type, scope_ids)

        results = []
        for scope in scopes:
            # Step 2: 拉取题目数据
            questions = self._load_questions(scope, scan_type)

            # Step 3: 拉取标准知识点集合
            standard_kps = self._load_standard_knowledge_points(scope)

            # Step 4: 多维度交叉统计
            stats = self._compute_multi_dimension_stats(
                questions, standard_kps, dimensions
            )

            # Step 5: 覆盖度评分计算
            score, risk = self._compute_coverage_score(stats, scope)

            # Step 6: 盲区识别
            gaps = self._identify_gaps(stats, scope)

            # Step 7: 持久化
            snapshot = self._save_snapshot(snapshot_no, scope, stats, score, risk, gaps)
            results.append(snapshot)

        duration_ms = int((time.time() - start_time) * 1000)
        return {
            'snapshotNo': snapshot_no,
            'scopeCount': len(results),
            'gapCount': sum(r['gapCount'] for r in results),
            'durationMs': duration_ms
        }

    def _compute_multi_dimension_stats(self, questions: list,
                                       standard_kps: list,
                                       dimensions: list) -> dict:
        """多维度交叉统计"""
        stats = {
            'total_questions': len(questions),
            'active_questions': sum(1 for q in questions if q['last_used_days'] <= 90),
            'new_questions_30d': sum(1 for q in questions if q['created_days'] <= 30),
        }

        # 知识点覆盖统计
        if 'KNOWLEDGE_POINT' in dimensions:
            kp_set = set()
            for q in questions:
                kp_set.update(q.get('knowledge_point_ids', []))
            stats['kp_covered'] = len(kp_set)
            stats['kp_total'] = len(standard_kps)
            stats['kp_coverage_rate'] = len(kp_set) / max(len(standard_kps), 1)
            stats['uncovered_kps'] = set(standard_kps) - kp_set

        # 难度分布
        if 'DIFFICULTY' in dimensions:
            diff_dist = {'easy': 0, 'easy-medium': 0, 'medium': 0,
                         'medium-hard': 0, 'hard': 0}
            for q in questions:
                level = self.DIFFICULTY_LEVELS.get(q.get('difficulty', 3))
                diff_dist[level] = diff_dist.get(level, 0) + 1
            stats['difficulty_distribution'] = diff_dist

        # 题型分布
        if 'TYPE' in dimensions:
            type_dist = {}
            for q in questions:
                qt = q.get('question_type', 'unknown')
                type_dist[qt] = type_dist.get(qt, 0) + 1
            stats['type_distribution'] = type_dist

        # 认知层级分布
        if 'COGNITIVE_LEVEL' in dimensions:
            cog_dist = {level: 0 for level in self.COGNITIVE_LEVELS}
            for q in questions:
                cog = q.get('cognitive_level', 'L2')
                cog_dist[cog] = cog_dist.get(cog, 0) + 1
            stats['cognitive_distribution'] = cog_dist

        return stats

    def _compute_coverage_score(self, stats: dict, scope: dict) -> tuple:
        """
        覆盖度综合评分 (0-100)
        评分模型 = 知识点覆盖率(40%) + 难度完整性(20%) + 题型多样性(15%)
                 + 认知层级完整性(15%) + 数量充足度(10%)
        """
        # 1. 知识点覆盖率 (40%)
        kp_rate = stats.get('kp_coverage_rate', 0)
        kp_score = kp_rate * 40

        # 2. 难度完整性 (20%) — 覆盖的难度等级数 / 5
        diff_dist = stats.get('difficulty_distribution', {})
        diff_covered = sum(1 for v in diff_dist.values() if v > 0)
        diff_score = (diff_covered / 5) * 20

        # 3. 题型多样性 (15%) — min(题型数/4, 1) * 15
        type_dist = stats.get('type_distribution', {})
        type_score = min(len(type_dist) / 4, 1.0) * 15

        # 4. 认知层级完整性 (15%) — 覆盖的认知层级数 / 6
        cog_dist = stats.get('cognitive_distribution', {})
        cog_covered = sum(1 for v in cog_dist.values() if v > 0)
        cog_score = (cog_covered / 6) * 15

        # 5. 数量充足度 (10%) — min(total / required, 1) * 10
        threshold = self._get_threshold(scope)
        total = stats.get('total_questions', 0)
        required = threshold.get('min_questions_per_chapter', 30)
        quantity_score = min(total / required, 1.0) * 10

        total_score = round(kp_score + diff_score + type_score
                           + cog_score + quantity_score, 2)

        if total_score >= 80:
            risk = 'GREEN'
        elif total_score >= 60:
            risk = 'YELLOW'
        else:
            risk = 'RED'

        return total_score, risk
```

```python
class GapIdentifier:
    """覆盖盲区识别器"""

    def identify(self, stats: dict, scope: dict, threshold: dict) -> list:
        """
        识别所有覆盖盲区
        返回盲区列表，按优先级和紧急度排序
        """
        gaps = []

        # 1. 知识点空缺 — 有知识点但题目数为0
        gaps.extend(self._find_kp_empty(stats, scope, threshold))

        # 2. 知识点数量不足 — 有题目但低于阈值
        gaps.extend(self._find_quantity_insufficient(stats, scope, threshold))

        # 3. 难度缺失 — 某难度等级无题
        gaps.extend(self._find_difficulty_missing(stats, scope, threshold))

        # 4. 题型缺失 — 某题型无题
        gaps.extend(self._find_type_missing(stats, scope, threshold))

        # 5. 认知层级缺失 — 某认知层级无题
        gaps.extend(self._find_cognitive_missing(stats, scope, threshold))

        # 计算优先级与紧急度
        for gap in gaps:
            gap['priority'] = self._compute_priority(gap)
            gap['urgency_score'] = self._compute_urgency(gap)

        # 按紧急度排序
        gaps.sort(key=lambda g: g['urgency_score'], reverse=True)
        return gaps

    def _find_kp_empty(self, stats: dict, scope: dict, threshold: dict) -> list:
        """知识点空缺"""
        gaps = []
        uncovered = stats.get('uncovered_kps', set())
        min_required = threshold.get('min_questions_per_kp', 10)

        for kp_id in uncovered:
            kp_info = self.kp_service.get_info(kp_id)
            gaps.append({
                'knowledge_point_id': kp_id,
                'knowledge_point_name': kp_info.name,
                'gap_type': 'KP_EMPTY',
                'gap_dimension': None,
                'current_count': 0,
                'required_count': min_required,
                'shortfall': min_required,
                'exam_relevance': kp_info.exam_relevance,
                'usage_frequency': self._get_usage_frequency(kp_id)
            })
        return gaps

    def _find_difficulty_missing(self, stats: dict, scope: dict,
                                  threshold: dict) -> list:
        """难度缺失"""
        gaps = []
        diff_dist = stats.get('difficulty_distribution', {})
        total = stats.get('total_questions', 1)
        balance_ratio = threshold.get('difficulty_balance_ratio', 0.15)

        for level, count in diff_dist.items():
            if count == 0 or (count / total) < balance_ratio:
                gaps.append({
                    'gap_type': 'DIFFICULTY_MISSING',
                    'gap_dimension': f'difficulty={level}',
                    'current_count': count,
                    'required_count': max(int(total * balance_ratio), 5),
                    'shortfall': max(int(total * balance_ratio), 5) - count,
                    'exam_relevance': self._get_exam_relevance(scope, level),
                    'usage_frequency': self._get_dimension_usage(scope, 'difficulty', level)
                })
        return gaps

    def _compute_priority(self, gap: dict) -> str:
        """计算优先级"""
        urgency = gap.get('urgency_score', 0)
        exam_rel = gap.get('exam_relevance', 0)
        usage = gap.get('usage_frequency', 0)
        shortfall = gap.get('shortfall', 0)

        # P0: 考点完全无题 + 考试高频
        if gap['gap_type'] == 'KP_EMPTY' and exam_rel >= 0.7:
            return 'P0'

        # P0: 某维度完全为空且考试关联度高
        if gap['current_count'] == 0 and exam_rel >= 0.6:
            return 'P0'

        # P1: 缺口大 + 考试相关
        if shortfall >= 5 and exam_rel >= 0.5:
            return 'P1'

        # P1: 使用频率高但数量不足
        if usage >= 100 and shortfall >= 3:
            return 'P1'

        # P2: 一般缺口
        if shortfall >= 3:
            return 'P2'

        return 'P3'

    def _compute_urgency(self, gap: dict) -> float:
        """
        紧急度评分 (0-100)
        = 缺口严重度(40) + 考试关联度(30) + 使用频率(20) + 知识点重要性(10)
        """
        # 缺口严重度
        if gap['current_count'] == 0:
            severity = 40.0
        else:
            severity = min(gap['shortfall'] / gap['required_count'], 1.0) * 40

        # 考试关联度
        exam_score = gap.get('exam_relevance', 0) * 30

        # 使用频率 (归一化到 0-20)
        usage = gap.get('usage_frequency', 0)
        usage_score = min(usage / 200, 1.0) * 20

        # 知识点重要性
        kp_importance = self._get_kp_importance(gap.get('knowledge_point_id'))
        importance_score = kp_importance * 10

        return round(severity + exam_score + usage_score + importance_score, 2)
```

### 4.3 内容生产需求预测算法

```python
class ProductionForecastPredictor:
    """内容生产需求预测器"""

    def predict(self, period: str, scope: dict) -> dict:
        """
        预测指定周期和范围内的题目生产需求
        :param period: 预测周期，如 "2026-Q3"
        :param scope: 预测范围 {subject, grade_level, textbook_id}
        """
        # Step 1: 获取当前覆盖度
        current = self.coverage_service.get_latest(scope)

        # Step 2: 获取目标覆盖率
        target_rate = self._get_target_rate(scope)

        # Step 3: 获取使用趋势数据
        trends = self._get_consumption_trends(scope, days=90)

        # Step 4: 计算各维度需求
        requirements = self._compute_requirements(
            current, target_rate, trends, scope
        )

        # Step 5: 模型预测
        prediction = self._run_prediction_model(requirements, trends, scope)

        # Step 6: 成本估算
        cost = self._estimate_cost(prediction, scope)

        # Step 7: 生产建议
        recommendation = self._recommend_production_source(prediction, scope)

        return {
            'period': period,
            'required_new_questions': prediction['total'],
            'breakdown': prediction['breakdown'],
            'current_coverage_rate': current.kp_coverage_rate,
            'target_coverage_rate': target_rate,
            'user_growth_trend': trends['user_growth_pct'],
            'exam_hotness_trend': trends['exam_hotness_pct'],
            'consumption_rate_30d': trends['consumption_30d'],
            'model_confidence': prediction['confidence'],
            'estimated_cost': cost,
            'recommended_source': recommendation
        }

    def _compute_requirements(self, current, target_rate, trends, scope):
        """计算各维度需补充的题目数量"""
        requirements = {}

        # 按知识点覆盖率缺口计算
        kp_gap = max(target_rate - current.kp_coverage_rate, 0)
        uncovered_kp_count = len(current.uncovered_kps)
        partially_covered = self._get_thinly_covered_kps(scope)

        # 基础需求：为每个未覆盖/薄弱知识点补充题目
        base_per_kp = self.threshold.get('min_questions_per_kp', 10)

        # 按难度分布计算
        diff_gaps = self._compute_difficulty_requirements(
            current.difficulty_distribution, trends, scope
        )

        # 按认知层级计算
        cog_gaps = self._compute_cognitive_requirements(
            current.cognitive_distribution, scope
        )

        # 综合需求量 = max(知识点覆盖需求, 难度补充需求, 认知层级补充需求)
        # + 趋势增量
        trend_multiplier = 1.0 + trends['user_growth_pct'] / 100.0 * 0.5  # 用户增长折半计入
        if trends['exam_hotness_pct'] > 10:
            trend_multiplier *= 1.1  # 考试热度上升10%以上，需求额外加10%

        total_kp_demand = int(uncovered_kp_count * base_per_kp * trend_multiplier)
        total_diff_demand = sum(diff_gaps.values())
        total_cog_demand = sum(cog_gaps.values())

        total = max(total_kp_demand, total_diff_demand + total_cog_demand)

        # 按比例分配到各维度
        requirements['total'] = total
        requirements['by_difficulty'] = diff_gaps
        requirements['by_cognitive'] = cog_gaps
        requirements['by_kp'] = uncovered_kp_count + len(partially_covered)

        return requirements

    def _run_prediction_model(self, requirements, trends, scope):
        """运行预测模型"""
        # MVP: 线性模型
        # TODO: 后续可替换为 ARIMA / Prophet / ML 模型
        base = requirements['total']

        # 季节性调整
        seasonal_factor = self._get_seasonal_factor(scope)
        adjusted = int(base * seasonal_factor)

        # 下限保护
        adjusted = max(adjusted, 20)  # 每周期至少生产20题

        # 置信度
        data_points = trends.get('data_points', 0)
        confidence = min(data_points / 90, 1.0) * 0.8 + 0.2  # 90天数据→满分

        return {
            'total': adjusted,
            'breakdown': {
                'by_difficulty': requirements['by_difficulty'],
                'by_cognitive': requirements['by_cognitive']
            },
            'confidence': round(confidence, 2)
        }

    def _get_seasonal_factor(self, scope) -> float:
        """
        季节性调整因子
        - 开学期(2-3月, 8-9月): 1.2 — 新教材上线，需求增大
        - 考试期(6月, 12月): 1.3 — 考前集中练习
        - 假期(7-8月, 1-2月): 0.9 — 常规维护
        - 其他: 1.0
        """
        month = datetime.now().month
        if month in [2, 3, 8, 9]:
            return 1.2
        elif month in [6, 12]:
            return 1.3
        elif month in [1, 7]:
            return 0.9
        return 1.0

    def _estimate_cost(self, prediction, scope) -> float:
        """成本估算"""
        total = prediction['total']
        recommended = self._recommend_production_source(prediction, scope)

        # 人工教研: ~15元/题
        # AI生成: ~0.5元/题 (含模型调用 + 审核成本)
        # 混合: AI生成 + 人工抽审 ~3元/题
        cost_per_question = {
            'HUMAN': 15.0,
            'AI_GENERATED': 0.5,
            'MIXED': 3.0
        }
        return round(total * cost_per_question.get(recommended, 3.0), 2)

    def _recommend_production_source(self, prediction, scope) -> str:
        """推荐生产来源"""
        total = prediction['total']
        cog_breakdown = prediction.get('breakdown', {}).get('by_cognitive', {})
        high_cog_demand = sum(v for k, v in cog_breakdown.items()
                            if k in ['L4', 'L5', 'L6'])

        # 高认知层级需求 → 人工为主
        if high_cog_demand > total * 0.3:
            return 'HUMAN'

        # 大量基础题 → AI为主
        if total > 100 and high_cog_demand < total * 0.15:
            return 'AI_GENERATED'

        return 'MIXED'
```

```java
/**
 * 题库覆盖度定时扫描调度器
 * - 全量扫描: 每周日凌晨 02:00

@Component
@Slf4j
public class QbcScanScheduler {

    @Autowired private CoverageScanner scanner;
    @Autowired private ProductionForecastPredictor predictor;
    @Autowired private QbcGapRepository gapRepo;
    @Autowired private NotificationService notificationService;

    /**
     * 全量扫描 — 每周日 02:00
     */
    @Scheduled(cron = "0 0 2 * * SUN")
    public void weeklyFullScan() {
        log.info("[QBC] 开始每周全量覆盖度扫描");
        try {
            // 按学科+学段分批扫描，避免单次负载过高
            List<SubjectGradeCombo> combos = getAllSubjectGradeCombos();
            for (SubjectGradeCombo combo : combos) {
                ScanResult result = scanner.scan(
                    "FULL",
                    "TEXTBOOK",
                    combo.getTextbookIds(),
                    Arrays.asList("KNOWLEDGE_POINT", "DIFFICULTY", "TYPE", "COGNITIVE_LEVEL")
                );

                // 检查是否有新增 P0 盲区
                List<CoverageGap> newP0Gaps = gapRepo.findNewGaps(
                    result.getSnapshotId(), "P0"
                );

                if (!newP0Gaps.isEmpty()) {
                    // 通知运营团队
                    notificationService.notifyOpsTeam(
                        "题库覆盖度预警",
                        String.format("发现 %d 个 P0 级覆盖盲区，请及时处理", newP0Gaps.size()),
                        NotificationPriority.HIGH
                    );
                }
            }
            log.info("[QBC] 全量覆盖度扫描完成");
        } catch (Exception e) {
            log.error("[QBC] 全量扫描失败", e);
            notificationService.notifyOpsTeam(
                "覆盖度扫描异常", e.getMessage(), NotificationPriority.CRITICAL
            );
        }
    }

    /**
     * 增量扫描 — 每日 03:00
     * 只扫描近24小时有题目变更的章节
     */
    @Scheduled(cron = "0 0 3 * * *")
    public void dailyIncrementalScan() {
        log.info("[QBC] 开始每日增量覆盖度扫描");

        // 获取近24小时有变更的章节
        Set<Long> changedChapters = questionService.getChaptersWithChanges(
            Instant.now().minus(Duration.ofHours(24))
        );

        if (changedChapters.isEmpty()) {
            log.info("[QBC] 无章节变更，跳过扫描");
            return;
        }

        for (Long chapterId : changedChapters) {
            scanner.scan(
                "INCREMENTAL",
                "CHAPTER",
                List.of(chapterId),
                Arrays.asList("KNOWLEDGE_POINT", "DIFFICULTY", "TYPE", "COGNITIVE_LEVEL")
            );
        }

        log.info("[QBC] 增量扫描完成，扫描 {} 个章节", changedChapters.size());
    }

    /**
     * 月度生产需求预测 — 每月1日 06:00
     */
    @Scheduled(cron = "0 0 6 1 * *")
    public void monthlyForecast() {

        String period = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy-MM"));

        List<SubjectGradeCombo> combos = getAllSubjectGradeCombos();

    private void autoCreateProductionOrders(ForecastResult forecast,
                                            SubjectGradeCombo combo) {
        // 仅对高置信度预测自动创建工单
        for (ChapterForecast cf : forecast.getByChapter()) {
            if (cf.getRequired() >= 10 && cf.getCurrentCoverage() < 0.6) {
                ProductionOrder order = ProductionOrder.builder()
                    .forecastId(forecast.getId())
                    .title(String.format("%s题库补充-%s",
                        combo.getSubjectLabel(), cf.getChapter()))
                    .subject(combo.getSubject())
                    .gradeLevel(combo.getGradeLevel())
                    .targetQuestions(cf.getRequired())
                    .spec(cf.getSpec())
                    .productionType("MIXED")
                    .deadline(LocalDate.now().plusWeeks(4))
                    .build();
                productionOrderRepo.save(order);

                log.info("[QBC] 自动创建生产工单: {}, 目标题目数: {}",
                    order.getOrderNo(), order.getTargetQuestions());
```

### 6.2 生产工单执行与AI生成管线集成

```java
/**
 * 生产工单执行器 — 当工单包含 AI_GENERATED 类型时，
 * 自动调用 AI 题目生成引擎
 */
@Service
@Slf4j
public class ProductionOrderExecutor {

    @Autowired private AiQuestionGenerationEngine aiEngine;
    @Autowired private QuestionService questionService;
    @Autowired private QbcGapRepository gapRepo;

    @Async("productionExecutorPool")
    public CompletableFuture<ProductionResult> executeOrder(Long orderId) {
        ProductionOrder order = orderRepo.findById(orderId).orElseThrow();
        order.setStatus("IN_PROGRESS");
        orderRepo.save(order);

        log.info("[QBC] 开始执行生产工单: {}, 目标: {}题",
            order.getOrderNo(), order.getTargetQuestions());

        ProductionResult result = ProductionResult.init(order);

        if (order.getProductionType().contains("AI")) {
            // AI 生成
            ProductionSpec spec = parseSpec(order.getSpec());
            for (ProductionBatch batch : spec.toBatches(batchSize = 10)) {
                try {
                    List<GeneratedQuestion> questions = aiEngine.generateBatch(batch);
                    int accepted = reviewAndAccept(questions, order);
                    result.addAccepted(accepted);
                    result.addRejected(questions.size() - accepted);
                } catch (Exception e) {
                    log.error("[QBC] AI生成批次失败", e);
                    result.addError(batch, e);
                }
            }
        }

        if (order.getProductionType().contains("HUMAN")) {
            // 人工生产 — 通知教研团队
            notifyEducationTeam(order);
        }

        // 更新工单状态
        order.setProducedCount(result.getAccepted() + result.getRejected());
        order.setAcceptedCount(result.getAccepted());
        order.setRejectedCount(result.getRejected());

        if (result.getAccepted() >= order.getTargetQuestions()) {
            order.setStatus("COMPLETED");
            order.setCompletedAt(Instant.now());

            // 关联的盲区标记为 FILLED
            resolveRelatedGaps(order);
        } else {
            order.setStatus("REVIEW");
        }
        orderRepo.save(order);

        return CompletableFuture.completedFuture(result);
    }

    /**
     * 审核AI生成的题目并入库
     */
    private int reviewAndAccept(List<GeneratedQuestion> questions,
                                 ProductionOrder order) {
        int accepted = 0;
        for (GeneratedQuestion q : questions) {
            // 自动质量校验
            ValidationResult validation = validateQuestion(q, order.getSpec());
            if (!validation.isValid()) {
                log.warn("[QBC] 题目质量校验失败: {}", validation.getErrors());
                continue;
            }

            // 查重
            if (questionService.isDuplicate(q.getContent(), 0.90)) {
                log.warn("[QBC] 题目与已有题目重复度过高，跳过");
                continue;
            }

            // 入库
            Question entity = q.toEntity();
            entity.setSource(SourceType.AI_GENERATED);
            entity.setStatus(QuestionStatus.DRAFT);
            entity.setProductionOrderId(order.getId());
            questionService.save(entity);
            accepted++;
        }
        return accepted;
    }

    /**
     * 工单完成后，将关联盲区标记为已解决
     */
    private void resolveRelatedGaps(ProductionOrder order) {
        List<CoverageGap> relatedGaps = gapRepo.findByProductionOrder(order.getId());
        for (CoverageGap gap : relatedGaps) {
            // 重新检查覆盖度
            int currentCount = coverageService.countQuestionsForGap(gap);
            if (currentCount >= gap.getRequiredCount()) {
                gap.setStatus("FILLED");
                gap.setResolvedAt(Instant.now());
                gapRepo.save(gap);
                log.info("[QBC] 覆盖盲区已解决: gap={}, kp={}",
                    gap.getId(), gap.getKnowledgePointName());
            }
        }
    }
}
```

## 8. 错误处理

### 8.1 错误码定义

| 错误码 | HTTP | 说明 | 处理建议 |
|--------|------|------|----------|
| `QBC_001` | 400 | 扫描范围参数无效 | 检查 scopeType 和 scopeId |
| `QBC_002` | 404 | 指定范围无题目数据 | 先导入题目再扫描 |
| `QBC_003` | 409 | 已有相同范围的扫描正在运行 | 等待当前扫描完成 |
| `QBC_004` | 500 | 扫描过程中下游服务异常 | 自动重试3次，仍失败则标记FAILED |
| `QBC_005` | 422 | 预测数据不足（历史数据<7天） | 返回低置信度结果 + 提示 |
| `QBC_006` | 403 | 无权限查看指定范围数据 | 检查数据权限范围 |
| `QBC_007` | 409 | 生产工单规格与盲区不匹配 | 校验规格参数 |

### 8.2 降级策略

```java
@Component
public class QbcFallbackHandler {

    /**
     * 知识点服务不可用时的降级扫描
     * 仅使用题目自身的知识点标签，不对照标准知识点体系
     */
    public CoverageSnapshot scanWithoutKpService(Scope scope) {
        log.warn("[QBC] 知识点服务不可用，执行降级扫描");

        // 仅基于题目已有标签统计
        List<Question> questions = questionService.findByScope(scope);

        Map<Long, Integer> kpCounts = questions.stream()
            .flatMap(q -> q.getKnowledgePointIds().stream())
            .collect(Collectors.groupingBy(
                Function.identity(),
                Collectors.summingInt(e -> 1)
            ));

        // 无法计算 kp_coverage_rate（缺标准集）
        // 仅返回题目分布，标记降级
        return CoverageSnapshot.degraded(scope, kpCounts);
    }

    /**
     * AI生成引擎不可用时的降级
     * 将工单转为人工生产
     */
    public void fallbackToHumanProduction(ProductionOrder order) {
        log.warn("[QBC] AI生成引擎不可用，工单 {} 转人工", order.getOrderNo());
        order.setProductionType("HUMAN");
        order.setAssignedTeam("紧急教研组");
        order.appendNote("AI生成引擎不可用，自动转人工");
        orderRepo.save(order);
        notifyEducationTeam(order);
    }

    /**
     * 历史数据不足时的预测降级
     */
    public ForecastResult fallbackForecast(Scope scope, String period) {
        // 使用默认参数进行简单估算
        return ForecastResult.builder()
            .period(period)
            .totalRequiredNew(50)  // 默认建议50题
            .modelConfidence(0.3)  // 低置信度
            .note("历史数据不足，使用默认值估算，建议积累更多数据后重新预测")
            .build();
    }
}
```

### 9.3 大规模题库优化

```sql
-- 多维度交叉统计使用物化视图加速 (ClickHouse)
-- 预计算表: 每日自动刷新
CREATE MATERIALIZED VIEW mv_question_stats_by_chapter_kp
ENGINE = SummingMergeTree
ORDER BY (textbook_id, chapter_id, knowledge_point_id, difficulty, question_type, cognitive_level)
AS SELECT
    textbook_id, chapter_id, knowledge_point_id,
    difficulty, question_type, cognitive_level,
    count() AS question_count,
    countIf(status = 'PUBLISHED') AS published_count,
    countIf(last_used_at > now() - INTERVAL 90 DAY) AS active_count
FROM question
WHERE status IN ('PUBLISHED', 'DRAFT_REVIEW')
GROUP BY textbook_id, chapter_id, knowledge_point_id,
         difficulty, question_type, cognitive_level;
```
