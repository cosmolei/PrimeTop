# 服务端-教育直播课堂与实时互动教学流媒体服务 详细设计

## 1. 概述

### 1.1 模块定位

教育直播课堂与实时互动教学流媒体服务是 PrimeTop V2.0 阶段核心基础设施之一，为教师端、学校/机构合作版本提供低延迟、高并发的实时在线教学能力。支持教师在线授课、师生实时互动、屏幕共享、电子白板协作、课堂录制回放等全场景直播教学需求。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 直播推拉流 | 教师端音视频推流，学生端低延迟拉流观看 |
| 实时互动 | 课堂文字聊天、举手发言、实时投票、弹幕提问 |
| 电子白板 | 多人协作白板，支持手写、图形、公式、文档标注 |
| 屏幕共享 | 教师共享桌面/应用窗口，展示课件与操作过程 |
| 课堂录制 | 自动录制直播内容，课后生成回放视频 |
| 房间管理 | 创建/关闭课堂房间、权限控制、人数管理 |
| 质量监控 | 实时监控推拉流质量，自动降级与告警 |
| 数据沉淀 | 课堂参与数据、互动数据、观看时长等学习行为记录 |

### 1.4 技术选型

| 组件 | 选型方案 | 备选方案 | 说明 |
| --- | --- | --- | --- |
| 媒体服务器 | SRS (Simple Realtime Server) | Janus、mediasoup、Jitsi | 国产开源，支持 RTMP/WebRTC/HLS，社区活跃 |
| 信令协议 | WebSocket + JSON | MQTT、gRPC | 简洁可靠，便于客户端实现 |
| 实时音视频 | WebRTC (UDP/SRTP) | RTMP (TCP) | WebRTC 延迟 <500ms，RTMP 用于录制 |
| 白板引擎 | Drawio + Canvas/SVG | tldraw、Excalidraw | 可定制学科图形库 |
| 录制存储 | 对象存储 (MinIO/OSS) + CDN | - | 录制文件分片存储，CDN 加速回放 |
| 消息队列 | Redis Stream / Kafka | RabbitMQ | 课堂内实时消息，Kafka 用于行为日志 |
| 弹幕系统 | Redis Pub/Sub + WebSocket | - | 低延迟弹幕分发 |

#### 2.1.1 直播课堂 (LiveClass)

```java
/**
 * 直播课堂实体
 */
@Entity
@Table(name = "live_class")
public class LiveClass {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    /** 课堂唯一标识，用于房间号 */
    @Column(name = "room_id", unique = true, nullable = false, length = 32)
    private String roomId;          // 如 "LC20260627A1B2"

    /** 课堂标题 */
    @Column(name = "title", nullable = false, length = 200)
    private String title;

    /** 教师 ID */
    @Column(name = "teacher_id", nullable = false)
    private Long teacherId;

    /** 关联班级 ID (可选，机构场景必填) */
    @Column(name = "class_id")
    private Long classId;

    /** 学科 */
    @Column(name = "subject", length = 20)
    private String subject;         // 如 "数学"、"物理"

    /** 学段 */
    @Column(name = "grade_stage", length = 20)
    private String gradeStage;      // 如 "初中"、"高中"

    /** 年级 */
    @Column(name = "grade_level", length = 20)
    private String gradeLevel;      // 如 "初三"、"高二"

    /** 课程内容描述 */
    @Column(name = "description", length = 1000)
    private String description;

    /** 课堂类型 */
    @Enumerated(EnumType.STRING)
    @Column(name = "class_type", nullable = false, length = 20)
    private ClassType classType;

    /** 课堂状态 */
    @Enumerated(EnumType.STRING)
    @Column(name = "status", nullable = false, length = 20)
    private ClassStatus status;

    /** 计划开始时间 */
    @Column(name = "scheduled_start_time", nullable = false)
    private LocalDateTime scheduledStartTime;

    /** 计划结束时间 */
    @Column(name = "scheduled_end_time", nullable = false)
    private LocalDateTime scheduledEndTime;

    /** 实际开始时间 */
    @Column(name = "actual_start_time")
    private LocalDateTime actualStartTime;

    /** 实际结束时间 */
    @Column(name = "actual_end_time")
    private LocalDateTime actualEndTime;

    /** 最大参与人数 */
    @Column(name = "max_participants")
    private Integer maxParticipants = 500;

    /** 推流地址 */
    @Column(name = "push_url", length = 500)
    private String pushUrl;

    /** 拉流地址 (HLS) */
    @Column(name = "pull_url_hls", length = 500)
    private String pullUrlHls;

    /** 拉流地址 (WebRTC) */
    @Column(name = "pull_url_webrtc", length = 500)
    private String pullUrlWebrtc;

    /** 录制回放地址 */
    @Column(name = "replay_url", length = 500)
    private String replayUrl;

    /** 是否开启录制 */
    @Column(name = "recording_enabled")
    private Boolean recordingEnabled = true;

    /** 是否开启弹幕 */
    @Column(name = "danmaku_enabled")
    private Boolean danmakuEnabled = true;

    /** 课件资料 ID 列表 (JSON) */
    @Column(name = "material_ids", columnDefinition = "JSON")
    private String materialIds;     // [123, 456, 789]

    /** 创建者 ID */
    @Column(name = "created_by", nullable = false)
    private Long createdBy;

    /** 创建时间 */
    @Column(name = "created_at", nullable = false, updatable = false)
    private LocalDateTime createdAt;

    /** 更新时间 */
    @Column(name = "updated_at", nullable = false)
    private LocalDateTime updatedAt;

    @TableField(exist = false)
    private Integer currentParticipants;

    public enum ClassType {
        LIVE_COURSE,       // 直播课
        INTERACTIVE_TUTORIAL, // 互动辅导
        EXAM_REVIEW,       // 考试讲评
        STUDY_GROUP,       // 学习小组
        PARENT_MEETING,    // 家长会
        TRAINING_SESSION    // 培训讲座
    }

    public enum ClassStatus {
        DRAFT,            // 草稿/待开始
        SCHEDULED,        // 已预约
        PREPARING,        // 准备中 (教师已进入)
        LIVE,             // 直播中
        PAUSED,           // 暂停
        ENDED,            // 已结束
        CANCELLED,        // 已取消
        REPLAY_AVAILABLE   // 回放可观看
    }
}
```

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课堂投票';

CREATE TABLE live_class_vote_record (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
