## 1. 模块概述

### 1.1 背景与问题

在 PrimeTop 全学段教育产品中，教学内容来自多种来源：教材数字化生产、题库导入、AI 生成解析、教研团队手写、第三方资源接入等。这些内容在 **信息密度、概念难度、语言复杂度** 上参差不齐：

- 同一段面向初二学生的物理讲解，可能塞入了 8 个新概念，远超该年龄段的认知承载力
- 一篇面向小学三年级的语文赏析，使用了过多文言词汇和复杂句式，阅读门槛偏高
- AI 生成的解题步骤有时过于简洁（跳步），有时过于冗长（信息过载）
- 教研人员手动标注"适龄性"耗时且主观，无法覆盖海量内容

**根本问题**：缺乏一套客观、可量化、自动化的 **内容认知适宜性评估体系**，无法在海量内容中快速识别"对这个年级的学生来说太难/太易/信息过载"的内容。

### 1.2 模块目标

构建一个自动化的内容认知评估引擎，对每条进入系统的教育内容进行多维度认知适宜性打分，并给出优化建议：

| 目标 | 说明 |
|------|------|
| **概念密度评估** | 统计单位篇幅内的新概念数量，识别"信息过载"段落 |
| **阅读难度评估** | 基于词汇频率、句法复杂度评估文本阅读难度 |
| **认知负荷估算** | 综合概念密度、难度、篇幅估算认知负荷指数 |
| **适龄性评分** | 将内容认知特征与目标学段认知能力模型进行匹配 |
| **优化建议生成** | 给出可执行的优化建议（拆分、简化、补充示例等） |
| **批量质量筛查** | 对内容库进行批量扫描，标记高认知负荷内容 |

### 1.3 与现有模块的边界

| 现有模块 | 关注点 | 本模块差异 |
|----------|--------|------------|
| 教育内容适龄性评估与分级引擎 | 从内容主题/题材角度判断适合哪个年级 | 本模块从 **认知负荷** 角度评估内容对目标年级是否过于密集/复杂 |
| 教育内容质量自动评估与低质内容智能检测 | 判断内容是否正确、完整、有错 | 本模块不判内容对错，只判 **信息密度是否合理** |
| 教育内容知识切片与微课智能分段生成 | 将长内容拆分为微课段落 | 本模块为拆分提供 **认知负荷依据**，告诉拆分引擎"在哪里断开最合理" |
| 学生认知负荷监测与学习内容难度动态调节 | 从 **学生侧** 监测认知负荷 | 本模块从 **内容侧** 预评估认知负荷，互为因果 |
| 教育内容布鲁姆认知层级自动分类 | 标注内容的认知深度层级 | 本模块关注信息 **量与密度**，而非认知深度 |

## 2. 核心概念与术语

### 2.1 术语表

| 术语 | 定义 |
|------|------|
| **Concept Density (CD)** | 概念密度。每千字中新概念的数量 |
| **New Concept** | 新概念：目标学段学生尚未学习的、超出当前知识体系的专业术语或知识点 |
| **Readability Score (RS)** | 阅读难度分。综合词汇难度、句长、语法复杂度的量化分数 |
| **Cognitive Load Index (CLI)** | 认知负荷指数。综合 CD、RS、内容长度、视觉复杂度等因素的最终评分 |
| **Age Appropriateness Score (AAS)** | 适龄性评分。CLI 与目标学段认知容量模型的匹配程度 |
| **Content Unit** | 内容单元。一篇讲解文本、一段解析、一个练习题题干的完整内容 |
| **Cognitive Capacity Baseline** | 认知容量基线。各学段学生在单次学习中能有效处理的认知负荷上限 |

### 2.2 认知容量基线参考

基于教育心理学研究（Miller's Law, Sweller's Cognitive Load Theory），设定参考值：

| 学段 | 每次学习新概念上限 | 推荐阅读难度区间 | 推荐段落长度 |
|------|-------------------|-----------------|-------------|
| 幼儿（3-6 岁） | 1-2 个 | 30-50（极简单） | ≤ 50 字 |
| 小学低年级（1-3 年级） | 2-3 个 | 50-60（简单） | 50-150 字 |
| 小学高年级（4-6 年级） | 3-5 个 | 60-70（中等偏易） | 150-300 字 |
| 初中（7-9 年级） | 5-7 个 | 70-80（中等） | 300-500 字 |
| 高中（10-12 年级） | 7-10 个 | 80-90（中等偏难） | 500-800 字 |

> ⚠️ 以上数值为初始参考值，应随用户学习数据积累后进行数据驱动的校准。

## 5. 核心算法设计

### 5.1 概念提取算法

从文本中提取学科概念并判断是否为目标学段的"新概念"。

```java
/**
 * 概念提取器：基于词典匹配 + NLP 辅助
 * 
 * 策略：
 * 1. 精确匹配概念知识库中的术语及其别名
 * 2. 使用分词器进行细粒度分词后做术语匹配
 * 3. 对未命中的专有名词（NER）进行 AI 辅助判断
 */
public class ConceptExtractor {
    
    private final ConceptKnowledgeBaseRepository conceptRepo;
    private final Tokenizer tokenizer;           // 学科分词器
    private final NamedEntityRecognizer ner;     // NER 模型
    
    /**
     * 提取文本中的所有概念
     * @param text 输入文本
     * @param subject 学科
     * @param targetStage 目标学段
     * @return 概念提取结果
     */
    public ConceptExtractionResult extract(String text, String subject, String targetStage) {
        // Step 1: 词典精确匹配
        Set<ConceptMatch> matchedConcepts = matchByDictionary(text, subject);
        
        // Step 2: 分词后模糊匹配（处理变形、组合术语）
        Set<ConceptMatch> fuzzyMatches = matchByTokenizer(text, subject, matchedConcepts);
        
        // Step 3: NER 补充提取（识别知识库中未收录的专业术语）
        Set<ConceptMatch> nerConcepts = matchByNER(text, subject, 
            Sets.union(matchedConcepts, fuzzyMatches));
        
        // 合并所有匹配结果
        Set<ConceptMatch> allConcepts = Sets.union(
            Sets.union(matchedConcepts, fuzzyMatches), nerConcepts);
        
        // 判断每个概念对目标学段是否为"新概念"
        List<ConceptOccurrence> occurrences = allConcepts.stream()
            .map(c -> enrichConcept(c, targetStage))
            .toList();
        
        return new ConceptExtractionResult(occurrences);
    }
    
    /**
     * 词典精确匹配：AC自动机多模式匹配
     */
    private Set<ConceptMatch> matchByDictionary(String text, String subject) {
        // 使用 AC 自动机（Aho-Corasick）做高效多模式匹配
        // 概念知识库中的所有术语 + 别名构建 AC 自动机
        ACTrie trie = conceptRepo.getACTrie(subject);
        List<ACTrieMatch> matches = trie.search(text);
        
        return matches.stream()
            .map(m -> new ConceptMatch(
                m.getTerm(), 
                m.getStart(), 
                m.getEnd(), 
                MatchType.DICTIONARY))
            .collect(Collectors.toSet());
    }
    
    /**
     * 判断概念对目标学段是否为新概念
     */
    private ConceptOccurrence enrichConcept(ConceptMatch match, String targetStage) {
        ConceptKnowledge concept = conceptRepo.findByTerm(match.getTerm());
        boolean isNew = concept != null && 
            StageUtil.isAfter(match.getIntroduceStage(), targetStage);
        
        return new ConceptOccurrence(
            match.getTerm(),
            match.getStart(),
            match.getEnd(),
            isNew,
            concept != null ? concept.getDifficulty() : 70, // 未收录概念默认难度
            concept != null && concept.isKeyConcept()
        );
    }
}
```

**关键设计决策**：
- 词典匹配使用 AC 自动机，时间复杂度 O(n + m)，n 为文本长度，m 为匹配数量
- 概念知识库按学科分库，避免跨学科误匹配
- NER 作为补充手段，仅处理词典未命中的候选词
- 概念知识库应定期与教材章节知识点表同步

### 5.2 概念密度计算

```java
/**
 * 概念密度计算器
 */
public class ConceptDensityCalculator {
    
    /**
     * 计算概念密度
     * 
     * @param occurrences 概念出现列表
     * @param textLength 文本总字数
     * @return 密度指标
     */
    public ConceptDensityResult calculate(List<ConceptOccurrence> occurrences, int textLength) {
        int totalConcepts = occurrences.size();
        int newConcepts = (int) occurrences.stream()
            .filter(ConceptOccurrence::isNew).count();
        int keyConcepts = (int) occurrences.stream()
            .filter(ConceptOccurrence::isKey).count();
        
        // 概念密度：每千字新概念数
        double thousandWords = Math.max(textLength / 1000.0, 0.1);
        double density = newConcepts / thousandWords;
        
        // 局部密度：将文本按窗口扫描，检测概念聚集区
        List<ConceptCluster> clusters = detectClusters(occurrences, textLength);
        
        // 概念间隔：相邻新概念之间的平均字数
        double avgGap = calculateAverageGap(occurrences, textLength);
        
        return new ConceptDensityResult(
            density,           // 千字新概念密度
            totalConcepts,     // 总概念数
            newConcepts,       // 新概念数
            keyConcepts,       // 核心概念数
            clusters,          // 概念聚集区
            avgGap             // 平均概念间距(字)
        );
    }
    
    /**
     * 检测概念聚集区（连续出现多个新概念的段落）
     * 使用滑动窗口：100 字窗口内出现 ≥ 3 个新概念即为聚集
     */
    private List<ConceptCluster> detectClusters(List<ConceptOccurrence> occurrences, 
                                                 int textLength) {
        final int WINDOW = 100;
        final int THRESHOLD = 3;
        
        List<ConceptOccurrence> newConcepts = occurrences.stream()
            .filter(ConceptOccurrence::isNew)
            .sorted(Comparator.comparingInt(ConceptOccurrence::getStart))
            .toList();
        
        List<ConceptCluster> clusters = new ArrayList<>();
        int left = 0;
        
        for (int right = 0; right < newConcepts.size(); right++) {
            // 收缩窗口左边界
            while (newConcepts.get(right).getStart() - newConcepts.get(left).getStart() > WINDOW) {
                left++;
            }
            int count = right - left + 1;
            if (count >= THRESHOLD) {
                clusters.add(new ConceptCluster(
                    newConcepts.get(left).getStart(),
                    newConcepts.get(right).getEnd(),
                    count,
                    newConcepts.subList(left, right + 1).stream()
                        .map(ConceptOccurrence::getTerm).toList()
                ));
            }
        }
        
        // 合并重叠的聚集区
        return mergeOverlapping(clusters);
    }
}
```

### 5.3 阅读难度评估算法

```java
/**
 * 阅读难度评估器
 * 
 * 综合维度：
 * 1. 词汇难度（词频等级）
 * 2. 句法复杂度（平均句长、嵌套深度）
 * 3. 学科术语比例
 * 
 * 输出：0-100 分，分数越高表示越难读
 */
public class ReadabilityEvaluator {
    
    // 学科词频等级表 (从教材语料中统计)
    private final WordFrequencyRepository wordFreqRepo;
    
    public ReadabilityScore evaluate(String text, String subject, String targetStage) {
        // --- 维度1: 词汇难度 ---
        List<String> words = tokenizer.tokenize(text);
        double vocabularyScore = calculateVocabularyScore(words, targetStage);
        
        // --- 维度2: 句法复杂度 ---
        List<SentenceInfo> sentences = sentenceSplitter.split(text);
        double syntacticScore = calculateSyntacticScore(sentences);
        
        // --- 维度3: 学科术语比例 ---
        double terminologyRatio = calculateTerminologyRatio(words, subject);
        
        // --- 维度4: 抽象词比例 ---
        double abstractRatio = calculateAbstractWordRatio(words);
        
        // 加权融合
        double score = 0.35 * vocabularyScore 
                     + 0.25 * syntacticScore 
                     + 0.20 * terminologyRatio 
                     + 0.20 * abstractRatio;
        
        // 归一化到 0-100
        score = MathUtils.clamp(score, 0, 100);
        
        return new ReadabilityScore(
            score,
            vocabularyScore,
            syntacticScore,
            terminologyRatio,
            abstractScore,
            buildDetailMetrics(words, sentences)
        );
    }
    
    /**
     * 词汇难度评分
     * 基于词频等级：低频词越多，分数越高
     */
    private double calculateVocabularyScore(List<String> words, String targetStage) {
        // 各学段的词汇等级:
        // preschool:   认识前 500 高频字
        // primary:     认识前 3000 常用字
        // middle:      认识前 8000 常用词
        // high:        认识前 15000 词
        
        int[] thresholds = {500, 3000, 8000, 15000}; // 按学段
        int threshold = thresholds[stageIndex(targetStage)];
        
        double difficultySum = 0;
        int validWords = 0;
        
        for (String word : words) {
            int rank = wordFreqRepo.getRank(word);
            if (rank > threshold) {
                // 超出学段词汇，按超出比例加分
                double difficulty = Math.min(100, (rank - threshold) * 100.0 / threshold);
                difficultySum += difficulty;
            }
            validWords++;
        }
        
        double avgDifficulty = difficultySum / Math.max(validWords, 1);
        // 放大效应：即使只有20%的词超纲，也会显著影响阅读
        double beyondRatio = countBeyondWords(words, threshold) * 100.0 / Math.max(validWords, 1);
        
        return MathUtils.clamp(avgDifficulty * 0.6 + beyondRatio * 2.0, 0, 100);
    }
    
    /**
     * 句法复杂度评分
     */
    private double calculateSyntacticScore(List<SentenceInfo> sentences) {
        if (sentences.isEmpty()) return 0;
        
        double avgLen = sentences.stream()
            .mapToInt(SentenceInfo::getLength)
            .average().orElse(0);
        
        int maxLen = sentences.stream()
            .mapToInt(SentenceInfo::getLength)
            .max().orElse(0);
        
        // 嵌套深度估算（基于标点层次：逗号、分号、冒号的嵌套）
        double avgDepth = sentences.stream()
            .mapToInt(SentenceInfo::getNestingDepth)
            .average().orElse(0);
        
        // 归一化
        // 句长：10字=0分, 80字=100分 (线性映射)
        double lenScore = MathUtils.clamp((avgLen - 10) * 100.0 / 70, 0, 100);
        // 嵌套：1层=0分, 5层=100分
        double depthScore = MathUtils.clamp((avgDepth - 1) * 25, 0, 100);
        
        return lenScore * 0.6 + depthScore * 0.4;
    }
}
```

### 5.4 认知负荷指数计算

```java
/**
 * 认知负荷聚合器
 * 将概念密度、阅读难度、视觉复杂度融合为最终认知负荷指数
 */
public class CognitiveLoadAggregator {
    
    // 各学段认知容量基线
    private static final Map<String, CognitiveCapacity> CAPACITY_BASELINE = Map.of(
        "preschool",      new CognitiveCapacity(2, 40, 50),
        "primary_lower",  new CognitiveCapacity(3, 55, 150),
        "primary_upper",  new CognitiveCapacity(5, 70, 300),
        "middle",         new CognitiveCapacity(7, 80, 500),
        "high",           new CognitiveCapacity(10, 90, 800)
    );
    
    public CognitiveLoadResult aggregate(
            ConceptDensityResult density,
            ReadabilityScore readability,
            VisualComplexityScore visual,
            int textLength,
            String targetStage) {
        
        CognitiveCapacity capacity = CAPACITY_BASELINE.get(targetStage);
        
        // 1. 概念负荷分：概念密度 vs 学段容量
        double conceptLoad = calculateConceptLoad(density, capacity);
        
        // 2. 阅读负荷分：阅读难度 vs 学段推荐难度
        double readingLoad = calculateReadingLoad(readability, capacity);
        
        // 3. 容量负荷分：文本长度 vs 推荐长度
        double lengthLoad = calculateLengthLoad(textLength, capacity);
        
        // 4. 视觉负荷分
        double visualLoad = visual.getScore();
        
        // 加权聚合
        double cli = conceptLoad * 0.40 
                   + readingLoad * 0.30 
                   + lengthLoad * 0.15 
                   + visualLoad * 0.15;
        
        cli = MathUtils.clamp(cli, 0, 100);
        
        // 计算适龄性评分
        double aas = calculateAgeAppropriateness(cli, density, readability, capacity);
        
        return new CognitiveLoadResult(
            cli,
            aas,
            conceptLoad,
            readingLoad,
            lengthLoad,
            visualLoad,
            determineLevel(cli, aas)
        );
    }
    
    /**
     * 概念负荷分计算
     * 
     * 原理：新概念密度超出学段容量基线时，负荷指数增长
     */
    private double calculateConceptLoad(ConceptDensityResult density, 
                                         CognitiveCapacity capacity) {
        // 概念聚集惩罚：有聚集区时负荷额外增加
        double clusterPenalty = density.getClusters().isEmpty() 
            ? 0 
            : Math.min(20, density.getClusters().size() * 5);
        
        // 基础密度分：当前密度 / 推荐密度上限 * 50
        double recommendedDensity = capacity.getMaxNewConcepts() * 1000.0 
            / Math.max(capacity.getRecommendedLength(), 1);
        double densityRatio = density.getDensity() / Math.max(recommendedDensity, 0.1);
        double densityScore = MathUtils.clamp(densityRatio * 50, 0, 100);
        
        return MathUtils.clamp(densityScore + clusterPenalty, 0, 100);
    }
    
    /**
     * 确定评估等级
     */
    private AssessmentLevel determineLevel(double cli, double aas) {
        if (cli <= 40 && aas >= 80) return AssessmentLevel.OPTIMAL;
        if (cli <= 60 && aas >= 60) return AssessmentLevel.ACCEPTABLE;
        if (cli <= 80 && aas >= 40) return AssessmentLevel.HEAVY;
        return AssessmentLevel.OVERLOAD;
    }
}
```

### 5.5 优化建议生成器

```java
/**
 * 优化建议生成器
 * 
 * 根据评估结果中的薄弱维度，生成可执行的优化建议
 */
public class OptimizationAdvisor {
    
    public List<OptimizationTip> generate(
            CognitiveAssessmentResult result,
            ConceptDensityResult density,
            ReadabilityScore readability,
            List<ConceptCluster> clusters) {
        
        List<OptimizationTip> tips = new ArrayList<>();
        
        // 1. 概念聚集 → 建议拆分
        for (ConceptCluster cluster : clusters) {
            tips.add(new OptimizationTip(
                "split",
                "概念聚集区(" + cluster.getStartOffset() + "-" + cluster.getEndOffset() + ")",
                String.format("该区域在%d字内集中出现了%d个新概念(%s)，" +
                    "建议拆分为多个小段落，每个段落先讲解1个概念再引入下一个。",
                    cluster.getLength(),
                    cluster.getConceptCount(),
                    String.join("、", cluster.getConcepts())),
                1,  // 高优先级
                cluster.getStartOffset()
            ));
        }
        
        // 2. 阅读难度过高 → 建议简化语言
        if (readability.getOverallScore() > 85) {
            tips.add(new OptimizationTip(
                "simplify",
                "整体语言复杂度",
                String.format("阅读难度评分%.1f偏高。平均句长%.1f字，" +
                    "建议：1) 将超过%d字的句子拆短；2) 将生僻词汇替换为常用表达或增加括号注释。",
                    readability.getOverallScore(),
                    readability.getAvgSentenceLength(),
                    recommendedSentenceLength(result.targetStage())),
                2,
                -1  // 全文建议
            ));
        }
        
        // 3. 文本过长 → 建议分段
        CognitiveCapacity capacity = CAPACITY_BASELINE.get(result.targetStage());
        if (result.metrics().wordCount() > capacity.getRecommendedLength() * 1.5) {
            int splitPoint = findBestSplitPoint(density, result.metrics().wordCount());
            tips.add(new OptimizationTip(
                "split",
                "内容长度",
                String.format("总字数%d，超出推荐长度(%d字)较多。" +
                    "建议在位置%d附近拆分为两段，可加入过渡引导语如'我们再来回顾一下刚才说的...'。",
                    result.metrics().wordCount(),
                    capacity.getRecommendedLength(),
                    splitPoint),
                2,
                splitPoint
            ));
        }
        
        // 4. 核心概念缺少示例 → 建议补充
        List<ConceptOccurrence> keyConcepts = density.getOccurrences().stream()
            .filter(c -> c.isKey() && c.isNew())
            .toList();
        if (keyConcepts.size() >= 2) {
            for (ConceptOccurrence concept : keyConcepts) {
                tips.add(new OptimizationTip(
                    "add_example",
                    concept.getTerm(),
                    String.format("核心概念'%s'是本学段新概念，" +
                        "建议在引入后立即给出1-2个生活化示例帮助理解。",
                        concept.getTerm()),
                    3,
                    concept.getStart()
                ));
            }
        }
        
        // 5. 公式密度过高 → 建议增加文字解释
        if (result.metrics().formulaCount() > 3 && 
            result.metrics().formulaCount() * 80 > result.metrics().wordCount()) {
            tips.add(new OptimizationTip(
                "reduce_formula",
                "公式密度",
                "公式较为密集，建议在关键公式后增加一句通俗的文字解释，" +
                    "说明公式的物理/数学含义而非仅给出符号推导。",
                2,
                -1
            ));
        }
        
        return tips.stream()
            .sorted(Comparator.comparingInt(OptimizationTip::priority))
            .toList();
    }
    
    /**
     * 寻找最佳分段点：概念密度最低的位置
     */
    private int findBestSplitPoint(ConceptDensityResult density, int textLength) {
        // 在文本中点附近寻找概念间距最大的位置
        int midPoint = textLength / 2;
        int searchRange = textLength / 6; // 中点 ± 1/6
        
        return density.getOccurrences().stream()
            .filter(c -> Math.abs(c.getStart() - midPoint) < searchRange)
            .max(Comparator.comparingInt(ConceptOccurrence::getStart))
            .map(ConceptOccurrence::getStart)
            .orElse(midPoint);
    }
}
```

## 9. 缓存与性能策略

### 9.1 缓存设计

| 缓存键 | TTL | 说明 |
|--------|-----|------|
| `cca:result:{contentId}:{stage}:{hash}` | 7 天 | 评估结果缓存，内容不变(hash一致)时直接返回 |
| `cca:concept:dict:{subject}` | 24 小时 | 学科概念词典 + AC 自动机 |
| `cca:capacity:baseline` | 永久 | 学段认知容量基线（低频变更） |
| `cca:stats:{subject}:{stage}:{date}` | 1 小时 | 统计报表数据 |
| `cca:batch:status:{batchId}` | 24 小时 | 批量任务进度 |

### 9.2 性能优化

**概念提取优化**：
- AC 自动机预构建，按学科缓存，避免每次重建
- 分词器使用增量分词，对长文本分段处理（每 2000 字一段）
- NER 模型仅对词典未命中的候选词触发，减少 AI 调用

**批量评估优化**：
- 批量评估使用消息队列 + Worker 池模式，控制并发
- 大批量任务分片处理，每片 100 条
- 评估结果批量写入数据库，减少 IO

**预期性能指标**：

| 场景 | 指标 |
|------|------|
| 单条内容评估 (< 1000 字) | P99 < 500ms |
| 单条内容评估 (1000-5000 字) | P99 < 2s |
| 单条内容评估 (> 5000 字) | P99 < 5s |
| 批量评估吞吐量 | ≥ 100 条/分钟 |
| 统计报表查询 | P99 < 1s |

## 10. 错误处理与降级策略

### 10.1 错误分级

| 错误类型 | 处理策略 | 是否阻断评估 |
|----------|---------|-------------|
| 文本解析失败（空文本/编码错误） | 返回 422 错误 | 是 |
| 概念词典加载失败 | 降级：仅使用 NER 提取概念 | 否，标记降级 |
| NER 服务不可用 | 降级：仅使用词典匹配 | 否，标记降级 |
| 词频库不可用 | 降级：使用内置默认词频表 | 否，标记降级 |
| AI 模型超时 | 降级：跳过 AI 辅助分析，使用规则计算 | 否，标记降级 |
| 数据库写入失败 | 重试 3 次，仍失败则写入消息队列待后续恢复 | 是，记录错误 |
| 批量评估中部分内容失败 | 跳过失败项，继续处理其他内容 | 否，记录失败列表 |

## 11. 关键代码示例

### 11.1 评估引擎主流程

```java
/**
 * 认知适宜性评估引擎 - 主流程编排
 */
@Service
@RequiredArgsConstructor
@Slf4j
public class CognitiveAssessmentEngine {
    
    private final ContentPreprocessor preprocessor;
    private final ConceptExtractor conceptExtractor;
    private final ConceptDensityCalculator densityCalculator;
    private final ReadabilityEvaluator readabilityEvaluator;
    private final VisualComplexityEvaluator visualEvaluator;
    private final CognitiveLoadAggregator loadAggregator;
    private final OptimizationAdvisor optimizationAdvisor;
    private final CognitiveAssessmentRepository assessmentRepo;
    private final CognitiveAssessmentCache cache;
    private final MeterRegistry metricsRegistry;
    
    /**
     * 评估单条内容
     */
    @Transactional
    public CognitiveAssessmentResult assess(AssessmentRequest request) {
        long startTime = System.nanoTime();
        String contentKey = cache.buildKey(request);
        
        // 1. 缓存命中检查
        Optional<CognitiveAssessmentResult> cached = cache.get(contentKey);
        if (cached.isPresent()) {
            metricsRegistry.counter("cca.cache.hit").increment();
            return cached.get();
        }
        
        // 2. 预处理
        ContentPreprocessResult preprocessed = preprocessor.process(request.getText());
        if (preprocessed.isEmpty()) {
            throw new AssessmentException(42201, "内容文本为空或无法解析");
        }
        
        // 3. 概念提取
        ConceptExtractionResult conceptResult;
        AssessmentDegradation.AssessmentDegradationBuilder degradationBuilder = 
            AssessmentDegradation.builder();
        
        try {
            conceptResult = conceptExtractor.extract(
                preprocessed.getCleanText(), 
                request.getSubject(), 
                request.getTargetStage());
        } catch (ConceptDictUnavailableException e) {
            log.warn("概念词典不可用，降级为纯NER提取", e);
            degradationBuilder.conceptDictDowngraded(true);
            conceptResult = conceptExtractor.extractWithNEROnly(
                preprocessed.getCleanText(), request.getSubject());
        } catch (NerServiceUnavailableException e) {
            log.warn("NER服务不可用，降级为纯词典匹配", e);
            degradationBuilder.nerDowngraded(true);
            conceptResult = conceptExtractor.extractWithDictOnly(
                preprocessed.getCleanText(), request.getSubject(), 
                request.getTargetStage());
        }
        
        // 4. 概念密度计算
        ConceptDensityResult density = densityCalculator.calculate(
            conceptResult.getOccurrences(), preprocessed.getWordCount());
        
        // 5. 阅读难度评估
        ReadabilityScore readability;
        try {
            readability = readabilityEvaluator.evaluate(
                preprocessed.getCleanText(), 
                request.getSubject(), 
                request.getTargetStage());
        } catch (WordFreqUnavailableException e) {
            log.warn("词频库不可用，使用默认值", e);
            degradationBuilder.readabilityDowngraded(true);
            readability = readabilityEvaluator.evaluateWithDefault(
                preprocessed.getCleanText(), request.getSubject());
        }
        
        // 6. 视觉复杂度评估（对纯文本默认0）
        VisualComplexityScore visual = visualEvaluator.evaluate(
            request.getRichText(), request.getContentType());
        
        // 7. 认知负荷聚合
        CognitiveLoadResult loadResult = loadAggregator.aggregate(
            density, readability, visual, 
            preprocessed.getWordCount(), request.getTargetStage());
        
        // 8. 生成优化建议
        List<OptimizationTip> tips = optimizationAdvisor.generate(
            loadResult, density, readability, density.getClusters());
        
        // 9. 构建结果
        CognitiveAssessmentResult result = CognitiveAssessmentResult.builder()
            .contentId(request.getContentId())
            .contentType(request.getContentType())
            .targetStage(request.getTargetStage())
            .targetGrade(request.getTargetGrade())
            .subject(request.getSubject())
            .metrics(buildMetrics(preprocessed, conceptResult))
            .scores(buildScores(density, readability, visual, loadResult))
            .assessmentLevel(loadResult.getLevel())
            .overloadSegments(buildOverloadSegments(density, readability))
            .optimizationTips(tips)
            .degradation(degradationBuilder.build())
            .evaluatorVersion("1.0.0")
            .evaluatedAt(OffsetDateTime.now(ZoneOffset.UTC))
            .build();
        
        // 10. 持久化 + 缓存
        assessmentRepo.save(result);
        cache.put(contentKey, result);
        
        // 11. 指标上报
        long duration = (System.nanoTime() - startTime) / 1_000_000;
        metricsRegistry.timer("cca.assessment.duration")
            .record(duration, TimeUnit.MILLISECONDS);
        metricsRegistry.counter("cca.assessment.level", 
            "level", result.assessmentLevel().name().toLowerCase()).increment();
        
        return result;
    }
    
    /**
     * 批量评估
     */
    public String assessBatch(BatchAssessmentRequest request) {
        // 创建批次记录
        CognitiveAssessmentBatch batch = createBatch(request);
        
        // 查询目标内容列表
        List<String> contentIds = contentService.queryContentIds(request.getScope());
        batch.setTotalCount(contentIds.size());
        batchRepo.save(batch);
        
        // 提交到消息队列，Worker 异步消费
        for (String contentId : contentIds) {
            eventPublisher.publish(new CognitiveAssessmentTaskEvent(
                batch.getId(), contentId, request.getTargetStage()));
        }
        
        return batch.getId();
    }
}
```

### 11.2 AC 自动机概念匹配实现

```java
/**
 * 学科概念 AC 自动机
 * 高效多模式匹配，适用于大文本 + 大量术语场景
 */
@Component
public class SubjectConceptACTrie {
    
    private final Map<String, ACTrie> subjectTries = new ConcurrentHashMap<>();
    private final ConceptKnowledgeBaseRepository conceptRepo;
    
    /**
     * 获取学科的 AC 自动机（按学科缓存）
     */
    public ACTrie getOrCreate(String subject) {
        return subjectTries.computeIfAbsent(subject, this::buildTrie);
    }
    
    private ACTrie buildTrie(String subject) {
        List<ConceptKnowledge> concepts = conceptRepo.findBySubject(subject);
        ACTrieBuilder builder = ACTrie.builder();
        
        for (ConceptKnowledge concept : concepts) {
            // 添加主术语
            builder.addPattern(concept.getConceptTerm(), concept.getConceptTerm());
            
            // 添加别名
            if (concept.getAliases() != null) {
                for (String alias : concept.getAliases()) {
                    if (alias.length() >= 2) { // 过滤过短的别名
                        builder.addPattern(alias, concept.getConceptTerm());
                    }
                }
            }
        }
        
        return builder.build();
    }
    
    /**
     * 定期重建（概念库更新后触发）
     */
    @EventListener
    public void onConceptBaseUpdated(ConceptBaseUpdatedEvent event) {
        subjectTries.remove(event.getSubject());
        log.info("学科 {} 的概念AC自动机已失效，将在下次访问时重建", event.getSubject());
    }
}
```

### 11.3 批量评估 Worker

```java
/**
 * 批量评估 Worker（消息队列消费者）
 */
@Component
@RequiredArgsConstructor
@Slf4j
public class CognitiveAssessmentWorker {
    
    private final CognitiveAssessmentEngine engine;
    private final CognitiveAssessmentBatchRepository batchRepo;
    private final ContentService contentService;
    
    /**
     * 消费评估任务事件
     * 并发控制：每个 Pod 最大 5 个并发消费者
     */
    @RabbitListener(
        queues = "cognitive.assessment.tasks",
        concurrency = "2-5",
        executor = "assessmentTaskExecutor"
    )
    public void handleTask(CognitiveAssessmentTaskEvent event) {
        try {
            // 加载内容
            Content content = contentService.getById(event.getContentId());
            if (content == null) {
                log.warn("内容不存在: {}", event.getContentId());
                batchRepo.incrementFail(event.getBatchId());
                return;
            }
            
            // 检查内容是否变更（hash 比较）
            String currentHash = DigestUtils.sha256Hex(content.getText());
            Optional<CognitiveAssessment> existing = 
                assessmentRepo.findLatest(event.getContentId(), event.getTargetStage());
            
            if (existing.isPresent() && existing.get().getContentHash().equals(currentHash)) {
                // 内容未变更，跳过
                batchRepo.incrementSkip(event.getBatchId());
                return;
            }
            
            // 执行评估
            AssessmentRequest request = AssessmentRequest.builder()
                .contentId(content.getId())
                .contentType(content.getType())
                .text(content.getText())
                .subject(content.getSubject())
                .targetStage(event.getTargetStage())
                .targetGrade(content.getTargetGrade())
                .build();
            
            engine.assess(request);
            batchRepo.incrementSuccess(event.getBatchId());
            
        } catch (Exception e) {
            log.error("批量评估失败, contentId={}", event.getContentId(), e);
            batchRepo.incrementFail(event.getBatchId());
        }
    }
}
```
