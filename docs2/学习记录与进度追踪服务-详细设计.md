# 学习记录与进度追踪服务 详细设计

> 版本：1.0 | 日期：2026-06-29 | 状态：已完成
> 优先级：P0（MVP 阶段核心）

---

## 1. 概述

### 1.1 模块定位

学习记录与进度追踪服务是 PrimeTop 学习闭环中的基础数据服务，负责记录用户在学习过程中的各类行为数据，并基于这些数据计算学习进度、掌握程度等指标，为个性化推荐、学情分析、学习规划等上层服务提供数据支撑。

### 1.2 核心职责

1. **学习行为记录**：记录用户在学习过程中的各类行为事件
2. **进度计算**：基于学习记录计算章节、知识点、学科的学习进度
3. **掌握度评估**：基于答题表现、学习时长等多维度评估知识点掌握度
4. **数据聚合**：提供多维度、多时间粒度的学习数据聚合查询
5. **数据同步**：支持多端数据同步和离线数据恢复
6. **数据归档**：历史数据归档和生命周期管理

### 1.3 依赖关系

```
学习记录与进度追踪服务
    ├── 依赖用户服务（用户信息、年级、教材版本）
    ├── 依赖内容服务（教材章节、知识点信息）
    ├── 依赖题目服务（题目信息、答案数据）
    ├── 依赖AI服务（对话记录、辅导记录）
    ├── 被学情分析服务使用
    ├── 被学习规划服务使用
    ├── 被个性化推荐服务使用
    └── 被客户端直接调用
```

## 2. 数据模型设计

### 2.1 核心实体关系

```
User (用户)
    ├── LearningSession (学习会话)
    │   ├── LearningActivity (学习活动)
    │   │   ├── AnswerRecord (答题记录)
    │   │   ├── ConversationMessage (对话消息)
    │   │   ├── ChapterProgress (章节进度)
    │   │   └── KnowledgePointProgress (知识点进度)
    │   └── SessionSummary (会话摘要)
    └── DailyLearningStats (每日学习统计)
```

### 2.2 核心数据表

#### 2.2.1 学习会话表 (learning_sessions)

```sql
CREATE TABLE learning_sessions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL COMMENT '用户ID',

    -- 会话基本信息
    session_id VARCHAR(64) NOT NULL UNIQUE COMMENT '会话唯一标识',
    session_type ENUM('photo_qa', 'ai_chat', 'sync_course', 'practice', 'mistake_review', 'reading') NOT NULL COMMENT '会话类型',

    grade VARCHAR(16) COMMENT '年级',
    subject VARCHAR(32) COMMENT '学科',
    textbook_version VARCHAR(64) COMMENT '教材版本',

    -- 章节上下文（可选）
    chapter_id BIGINT COMMENT '关联章节ID',
    knowledge_point_ids JSON COMMENT '关联知识点ID列表',

    device_id VARCHAR(128) COMMENT '设备标识',
    platform VARCHAR(32) COMMENT '平台: android/ios/web',
    app_version VARCHAR(32) COMMENT 'APP版本',

    -- 元数据
    metadata JSON COMMENT '扩展元数据',

    -- 时间戳
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_user (user_id),
    INDEX idx_session_type (session_type),
```

## 4. 业务逻辑设计

### 4.1 进度计算算法

#### 4.1.1 章节进度计算

```typescript
class ChapterProgressCalculator {
  /**
   * 计算章节进度
   *
   * 进度 = (已掌握知识点数 + 0.5 * 学习中知识点数) / 总知识点数 * 100
   */
  async calculateChapterProgress(userId: number, chapterId: number): Promise<ChapterProgress> {
    // 1. 获取章节信息
    const chapter = await this.contentService.getChapter(chapterId);
    const totalKnowledgePoints = chapter.knowledgePoints.length;

    // 2. 获取知识点进度
    const knowledgePointProgressList = await this.getKnowledgePointProgress(
      userId,
      chapter.knowledgePoints.map(kp => kp.id)
    );

    // 3. 计算各状态知识点数
    const mastered = knowledgePointProgressList.filter(kp => kp.status === 'mastered').length;
    const inProgress = knowledgePointProgressList.filter(kp => kp.status === 'learning').length;
    const learning = knowledgePointProgressList.filter(kp => kp.status === 'review_needed').length;

    // 4. 计算进度百分比
    const progressPercent = (
      (mastered + 0.5 * inProgress + 0.3 * learning) / totalKnowledgePoints
    ) * 100;

    // 5. 计算掌握度评分
    const masteryScores = knowledgePointProgressList.map(kp => kp.masteryScore);
    const masteryScore = masteryScores.reduce((sum, score) => sum + score, 0) / masteryScores.length;

    // 6. 确定学习状态
    let status: ChapterStatus;
    if (progressPercent === 0) status = 'not_started';
    else if (progressPercent < 100) status = 'in_progress';
    else if (masteryScore >= 80) status = 'mastered';
    else status = 'completed';

    // 7. 获取答题统计
    const answerStats = await this.getAnswerStats(userId, chapterId);

    return {
      userId,
      chapterId,
      status,
      progressPercent: Math.round(progressPercent * 100) / 100,
```

```typescript
class KnowledgePointMasteryCalculator {
  /**
   * 计算知识点掌握度
   *
   * 综合因素：
   * 1. 正确率 (weight: 0.4)
   * 2. 稳定性 (weight: 0.3) - 基于最近表现
   * 3. 练习量 (weight: 0.2) - 考虑尝试次数
   * 4. 时间间隔 (weight: 0.1) - 基于遗忘曲线
   */
  async calculateMastery(kpProgress: KnowledgePointProgress): Promise<MasteryResult> {
    // 1. 计算正确率
    const accuracy = kpProgress.totalAttempts > 0
      ? kpProgress.correctAttempts / kpProgress.totalAttempts
      : 0;

    // 2. 计算稳定性（最近表现）
    const recentAccuracy = kpProgress.recentAttempts > 0
      ? kpProgress.recentCorrect / kpProgress.recentAttempts
      : 0;

    // 3. 计算练习量因子（有最低和最高阈值）
    const practiceFactor = Math.min(
      1,
      kpProgress.totalAttempts / 10  // 假设10次练习为"充分"
    );

    // 4. 计算遗忘曲线因子
    const daysSinceLastReview = kpProgress.lastReviewTime
      ? (Date.now() - kpProgress.lastReviewTime.getTime()) / (1000 * 60 * 60 * 24)
      : 0;
    const forgettingFactor = Math.exp(-0.1 * daysSinceLastReview);

    // 5. 综合计算掌握度
    const masteryScore =
      accuracy * 0.4 +
      recentAccuracy * 0.3 +
      practiceFactor * 0.2 +
      forgettingFactor * 0.1;

    // 6. 计算置信度（基于尝试次数）
    const confidence = Math.min(
      1,
      kpProgress.totalAttempts / 20  // 20次练习达到高置信度
    );

    // 7. 确定掌握等级
    let masteryLevel: MasteryLevel;
    if (masteryScore >= 0.9) masteryLevel = 'expert';
    else if (masteryScore >= 0.8) masteryLevel = 'advanced';
    else if (masteryScore >= 0.6) masteryLevel = 'intermediate';
    else if (masteryScore >= 0.4) masteryLevel = 'novice';
    else masteryLevel = 'beginner';

    // 8. 确定学习状态
    let status: KnowledgePointStatus;
    if (masteryLevel === 'expert' || masteryLevel === 'advanced') status = 'mastered';
    else if (masteryLevel === 'intermediate') status = 'learning';
    else if (kpProgress.totalAttempts > 0) status = 'review_needed';
    else status = 'not_started';

    // 9. 计算稳定性评分
    const stabilityScore = (accuracy + recentAccuracy) / 2;

    return {
      masteryScore: Math.round(masteryScore * 100),
      confidenceScore: Math.round(confidence * 100),
      stabilityScore: Math.round(stabilityScore * 100),
      masteryLevel,
      status
    };
  }
}
```

```typescript
class SpacedRepetitionScheduler {
  /**
   * 基于遗忘曲线计算下次复习时间
   *
   * 使用 SuperMemo SM-2 算法的简化版本
   */
  calculateNextReviewTime(kpProgress: KnowledgePointProgress, performance: number): Date {
    const { reviewCount, spacedRepetitionInterval, lastReviewTime } = kpProgress;

    // 性能评分（0-1）
    const quality = performance;

    // 如果性能不佳，重置间隔
    if (quality < 0.5) {
      return new Date(Date.now() + 24 * 60 * 60 * 1000); // 1天后复习
    }

    // 计算新的间隔
    let newInterval: number;

    if (reviewCount === 0) {
      newInterval = 1; // 第一次复习：1天
    } else if (reviewCount === 1) {
      newInterval = 6; // 第二次复习：6天
    } else {
      // 后续复习：基于上次间隔和性能
      newInterval = spacedRepetitionInterval * quality;
    }

    // 限制间隔范围（1天 - 365天）
    newInterval = Math.max(1, Math.min(365, newInterval));

    // 计算下次复习时间
    const nextReviewTime = new Date(lastReviewTime || new Date());
    nextReviewTime.setDate(nextReviewTime.getDate() + Math.round(newInterval));

    return nextReviewTime;
  }

  /**
   * 更新知识点复习信息
   */
  async updateReviewInfo(
    userId: number,
    knowledgePointId: number,
    performance: number
  ): Promise<void> {
    // 1. 获取当前进度
    const kpProgress = await this.getKnowledgePointProgress(userId, knowledgePointId);

    // 2. 计算下次复习时间
    const nextReviewTime = this.calculateNextReviewTime(kpProgress, performance);

    // 3. 更新复习信息
    const newInterval = Math.round(
      (nextReviewTime.getTime() - (kpProgress.lastReviewTime || new Date()).getTime()) /
      (1000 * 60 * 60 * 24)
    );

    await this.updateKnowledgePointProgress(userId, knowledgePointId, {
      reviewCount: kpProgress.reviewCount + 1,
      lastReviewTime: new Date(),
      nextReviewTime,
      spacedRepetitionInterval: newInterval
    });
  }
}
```

```typescript
    const today = new Date();
    today.setHours(0, 0, 0, 0);

    for (let i = 0; i < dailyStats.length; i++) {
      const statDate = new Date(dailyStats[i].statDate);
      statDate.setHours(0, 0, 0, 0);

      const expectedDate = new Date(today);
      expectedDate.setDate(today.getDate() - i);

      if (statDate.getTime() === expectedDate.getTime()) {
        streak++;
      } else {
        break;
      }
    }

    return streak;
  }
```

```typescript
class DailyStatsUpdater {

  async updateDailyStats(

    if (updates.questionsAnswered) {

      dailyStats.goalCompletionPercent = Math.min(100, goalCompletionPercent);
      dailyStats.dailyGoalCompleted = dailyStats.goalCompletionPercent >= 100;
    }

    // 6. 聚合各学科统计
    const subjectStats = await this.getSubjectStats(userId, statDate);
    dailyStats.subjectStats = subjectStats;

    // 7. 保存更新
    await this.dailyStatsRepository.save(dailyStats);
  }

  private toDate(date: Date): Date {

    d.setHours(0, 0, 0, 0);

      .groupBy('s.subject')
      .setParameter('correct', 'correct')
      .getRawMany();

    const subjectStats: Record<string, SubjectStat> = {};
    activities.forEach(a => {
      subjectStats[a.subject] = {
        activitiesCount: parseInt(a.count),
        timeSpentSeconds: parseInt(a.timeSpent) || 0,
        correctCount: parseInt(a.correct) || 0
      };
    });

    return subjectStats;
  }
```

### 6.1 学习会话状态机

```
        ┌──────────┐
        │ created  │
        └────┬─────┘
             │
             ▼
        ┌──────────┐      ┌───────────┐
        │ ongoing  │─────►│ paused    │
        └────┬─────┘      └─────┬─────┘
             │                  │
             │                  │
             ▼                  ▔──────┐
        ┌──────────┐                   │
        │ completed│◄──────────────────┘
        └──────────┘
             ▲
             │
        ┌────┴─────┐
        │interrupted│
        └──────────┘
```

**状态说明：**
- `created`: 会话已创建但未开始
- `ongoing`: 会话进行中
- `paused`: 用户暂时离开但未完成
- `completed`: 会话正常完成
- `interrupted`: 会话被意外中断（如APP崩溃）

**状态转换规则：**
- `created` → `ongoing`: 用户开始学习
- `ongoing` → `paused`: 用户切换到其他应用
- `ongoing` → `completed`: 用户主动结束会话
- `paused` → `ongoing`: 用户返回继续学习
- `paused` → `completed`: 用户在暂停状态下结束会话
- `ongoing` → `interrupted`: 检测到异常中断

- `mastered` → `review_needed`: 遗忘曲线触发或检测到能力下降

### 8.3 批量处理

```typescript
class BatchProgressUpdater {
  /**
   * 批量更新知识点进度
   */
  async batchUpdateKnowledgePointProgress(
    userId: number,
    kpIds: number[]
  ): Promise<void> {
    // 分批处理，每批50个
    const batchSize = 50;
    for (let i = 0; i < kpIds.length; i += batchSize) {
      const batch = kpIds.slice(i, i + batchSize);

      // 使用批量查询
      const kpProgressList = await this.kpProgressRepository
        .createQueryBuilder('kp')
        .where('kp.userId = :userId', { userId })
        .andWhere('kp.knowledgePointId IN (:...kpIds)', { kpIds: batch })
        .getMany();

      // 批量计算并更新
      const updates = kpProgressList.map(kpProgress =>
        this.calculateAndUpdateProgress(kpProgress)
      );

      await Promise.all(updates);
    }
  }
}
```
