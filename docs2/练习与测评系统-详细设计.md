# 练习与测评系统 - 详细设计

> 版本: v1.0 | 更新日期: 2026-05-20 | 状态: 初稿

## 1. 概述

### 1.1 模块定位

练习与测评系统是 PrimeTop 核心学习闭环的关键环节，连接题目与题库服务、学情分析、自适应推荐引擎、错题整理等模块，为学生提供从"同步练习"到"专题突破"再到"模拟测评"的完整练习体验。

**核心职责：**
- 管理练习会话的完整生命周期（创建→答题→提交→批改→分析）
- 支持多种练习场景：同步练习、专题训练、智能推题、模拟测评
- 实时跟踪答题过程，为自适应难度调整提供数据
- 生成练习报告，驱动学情分析和错题收录

**不在本模块范围内：**
- 题目内容管理 → 见 `题目与题库服务-详细设计.md`
- 自适应推荐算法 → 见 `自适应学习与个性化推荐引擎-详细设计.md`
- 错题后续复习流程 → 见 `错题整理-详细设计.md`

### 1.2 用户场景

| 场景 | 触发方式 | 描述 |
|------|----------|------|
| 章节同步练习 | 学生选择教材章节后点击"开始练习" | 基于当前章节知识点生成一组练习题 |
| 专题训练 | 学生选择专题（如"一次函数"） | 围绕特定专题集中训练 |
| 智能推题 | 首页/学习工作台推荐 | 基于薄弱点和遗忘曲线推荐个性化练习 |
| 模拟测评 | 学生主动选择或考前冲刺计划触发 | 限时、限量的综合性测评 |
| 错题重练 | 错题本中点击"重新练习" | 从错题本抽取错题进行再次作答 |
| 日常打卡 | 学习计划中的每日练习任务 | 计划引擎生成的每日练习 |

## 2. 核心数据结构

### 2.1 练习会话 (PracticeSession)

```sql
CREATE TABLE practice_sessions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    session_type    VARCHAR(32) NOT NULL COMMENT '练习类型: chapter_practice|topic_drill|smart_recommend|mock_exam|mistake_redo|daily_task',
    status          VARCHAR(20) NOT NULL DEFAULT 'created' COMMENT '状态: created|in_progress|submitted|grading|completed|expired',
    
    -- 来源上下文
    source_type     VARCHAR(32) COMMENT '来源: textbook|topic|smart|exam|mistake|plan',
    source_id       VARCHAR(64) COMMENT '来源ID(章节ID/专题ID/计划任务ID等)',
    
    -- 练习配置
    subject_code    VARCHAR(16) NOT NULL COMMENT '学科编码',
    grade_code      VARCHAR(16) NOT NULL COMMENT '年级编码',
    difficulty_mode VARCHAR(20) DEFAULT 'adaptive' COMMENT '难度模式: fixed|adaptive|progressive',
    total_count     INT NOT NULL COMMENT '题目总数',
    time_limit_sec  INT COMMENT '限时(秒), NULL表示不限时',
    
    -- 难度配置（自适应模式）
    initial_difficulty  DECIMAL(3,2) DEFAULT 0.50 COMMENT '初始难度 0.0~1.0',
    current_difficulty  DECIMAL(3,2) DEFAULT 0.50 COMMENT '当前难度',
    difficulty_step     DECIMAL(3,2) DEFAULT 0.05 COMMENT '难度调整步长',
    difficulty_min      DECIMAL(3,2) DEFAULT 0.20 COMMENT '最低难度',
    difficulty_max      DECIMAL(3,2) DEFAULT 0.95 COMMENT '最高难度',
    
    -- 统计（答题完成后更新）
    correct_count   INT DEFAULT 0 COMMENT '正确数',
    wrong_count     INT DEFAULT 0 COMMENT '错误数',
    skip_count      INT DEFAULT 0 COMMENT '跳过数',
    accuracy_rate   DECIMAL(5,4) COMMENT '正确率 0.0000~1.0000',
    total_time_sec  INT COMMENT '总耗时(秒)',
    score           DECIMAL(5,2) COMMENT '得分(仅模拟测评)',
    
    -- 时间戳
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    started_at      DATETIME COMMENT '开始答题时间',
    submitted_at    DATETIME COMMENT '提交时间',
    completed_at    DATETIME COMMENT '批改完成时间',
    expired_at      DATETIME COMMENT '过期时间(限时练习)',
    
    INDEX idx_user_status (user_id, status),
    INDEX idx_user_type_created (user_id, session_type, created_at),
    INDEX idx_source (source_type, source_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='练习会话';
```

### 2.2 练习题目 (PracticeQuestion)

```sql
CREATE TABLE practice_questions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      BIGINT NOT NULL COMMENT '练习会话ID',
    question_id     BIGINT NOT NULL COMMENT '题库题目ID',
    seq_no          INT NOT NULL COMMENT '题目序号(从1开始)',
    
    -- 难度
    difficulty      DECIMAL(3,2) NOT NULL COMMENT '本题难度值',
    knowledge_point_ids JSON COMMENT '关联知识点ID列表',
    
    -- 答题状态
    status          VARCHAR(20) NOT NULL DEFAULT 'pending' COMMENT 'pending|viewed|answered|skipped|timeout',
    answered_at     DATETIME COMMENT '作答时间',
    time_spent_sec  INT COMMENT '答题耗时(秒)',
    
    -- 学生作答
    student_answer  JSON COMMENT '学生答案(结构化)',
    answer_type     VARCHAR(20) COMMENT '答案类型: choice|fill|essay|calculation|voice',
    
    -- 批改结果
    is_correct      TINYINT(1) COMMENT '是否正确: 0=错, 1=对, NULL=待批',
    partial_score   DECIMAL(5,2) COMMENT '部分得分(填空/计算题)',
    ai_grading_result JSON COMMENT 'AI批改详细结果',
    
    -- 关联
    mistake_record_id BIGINT COMMENT '关联的错题记录ID(错误时自动创建)',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_session_seq (session_id, seq_no),
    INDEX idx_question (question_id),
    UNIQUE KEY uk_session_seq (session_id, seq_no),
    FOREIGN KEY (session_id) REFERENCES practice_sessions(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='练习题目';
```

### 2.3 练习报告 (PracticeReport)

```sql
CREATE TABLE practice_reports (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      BIGINT NOT NULL UNIQUE COMMENT '练习会话ID',
    user_id         BIGINT NOT NULL,
    
    -- 总览
    total_count     INT NOT NULL,
    correct_count   INT NOT NULL,
    accuracy_rate   DECIMAL(5,2) NOT NULL COMMENT '正确率%',
    total_time_sec  INT NOT NULL,
    avg_time_per_q  DECIMAL(6,1) COMMENT '平均每题耗时(秒)',
    score           DECIMAL(5,2) COMMENT '百分制得分',
    
    -- 知识点分析
    kp_analysis     JSON NOT NULL COMMENT '知识点维度分析, 见下方结构',
    
    -- 能力维度分析
    ability_analysis JSON COMMENT '能力维度分析(计算能力/理解能力/应用能力等)',
    
    -- 对比分析（与历史对比）
    compared_to_last JSON COMMENT '与上次练习对比',
    
    -- AI 建议
    ai_suggestions  JSON COMMENT 'AI生成的学习建议',
    weak_points     JSON COMMENT '薄弱知识点列表',
    recommended_actions JSON COMMENT '推荐后续行动',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_user_created (user_id, created_at),
    FOREIGN KEY (session_id) REFERENCES practice_sessions(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='练习报告';
```

## 4. 题目选取策略

### 4.1 选取流程

```
创建练习请求
    │
    ▼
┌─────────────────────┐
│ 1. 解析来源上下文    │  章节ID → 知识点列表 → 题目池
│    (source → KP)    │  专题ID → 专题知识点 → 题目池
│                     │  薄弱点 → 弱项知识点 → 题目池
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 2. 确定题目池       │  调用题库服务检索
│    question_pool    │  过滤已做过的题(exclude_recent=7天)
│                     │  过滤用户标记不合适的题
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 3. 按策略选取       │  根据难度模式不同:
│    select questions │  fixed: 按固定难度筛选
│                     │  adaptive: 均匀分布初始难度
│                     │  progressive: 渐进递增难度
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 4. 补充错题重练     │  如果 options.mistake_redo_ratio > 0
│    (可选)           │  从错题本中抽取指定比例的错题
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 5. 去重 & 打乱      │  去除已选重复题
│                     │  按 seq_no 打乱(非模拟测评)
└────────┬────────────┘
```

### 4.3 自适应难度调整算法

在 `adaptive` 模式下，每答完一题实时调整下一题难度：

```python
def calculate_next_difficulty(current_difficulty, is_correct, streak, config):
    """
    自适应难度调整
    
    Args:
        current_difficulty: 当前难度 0.0~1.0
        is_correct: 本题是否正确
        streak: 连续对/错计数 (正数=连续对, 负数=连续错)
        config: 配置参数
    
    Returns:
        next_difficulty: 下一题难度
    """
    step = config.difficulty_step  # 默认 0.05
    
    # 连续对/错时加大调整幅度
    if streak > 0:
        step = min(step * (1 + streak * 0.3), config.difficulty_step * 3)
    elif streak < 0:
        step = min(step * (1 + abs(streak) * 0.3), config.difficulty_step * 3)
    
    if is_correct:
        new_difficulty = current_difficulty + step
    else:
        new_difficulty = current_difficulty - step
    
    # 钳制到允许范围
    new_difficulty = max(config.difficulty_min, min(config.difficulty_max, new_difficulty))
    
    return round(new_difficulty, 2)
```

**难度级别映射：**

| 难度值范围 | 级别 | 说明 |
|-----------|------|------|
| 0.00 ~ 0.29 | easy | 基础概念题 |
| 0.30 ~ 0.49 | medium_easy | 基本应用题 |
| 0.50 ~ 0.69 | medium | 中等难度综合题 |
| 0.70 ~ 0.84 | medium_hard | 较难题目 |
| 0.85 ~ 1.00 | hard | 压轴/竞赛级 |

### 6.3 练习报告生成流程

```python
async def generate_practice_report(session_id: int) -> PracticeReport:
    """
    练习报告生成
    
    包含：总体统计、知识点分析、AI建议、推荐行动
    """
    session = await get_session(session_id)
    questions = await get_session_questions(session_id)
    
    # 1. 基础统计
    total = len(questions)
    correct = sum(1 for q in questions if q.is_correct == True)
    wrong = sum(1 for q in questions if q.is_correct == False)
    skipped = sum(1 for q in questions if q.status == 'skipped')
    accuracy = correct / (total - skipped) if (total - skipped) > 0 else 0
    total_time = sum(q.time_spent_sec or 0 for q in questions)
    
    # 2. 知识点维度分析
    kp_analysis = analyze_by_knowledge_points(questions)
    
    # 3. 能力维度分析
    ability_analysis = analyze_by_ability_dimensions(questions, session.subject_code)
    
    # 4. 与历史对比
    history = await get_recent_sessions(session.user_id, session.subject_code, limit=5)
    comparison = compare_with_history(session, history)
    
    # 5. 识别薄弱点
    weak_points = [kp for kp in kp_analysis['items'] if kp['level'] in ('weak', 'very_weak')]
    
    # 6. AI 生成建议（调用 AI 服务）
    ai_suggestions = await call_ai_for_suggestions(
        session=session,
        kp_analysis=kp_analysis,
        weak_points=weak_points,
        history=history
    )
    
    # 7. 推荐后续行动
    recommended_actions = generate_recommended_actions(weak_points, session)
    
    # 8. 保存报告
    report = PracticeReport(
        session_id=session_id,
        user_id=session.user_id,
        total_count=total,
        correct_count=correct,
        accuracy_rate=round(accuracy * 100, 2),
        total_time_sec=total_time,
        avg_time_per_q=round(total_time / max(total, 1), 1),
        kp_analysis=kp_analysis,
        ability_analysis=ability_analysis,
        compared_to_last=comparison,
        ai_suggestions=ai_suggestions,
        weak_points=weak_points,
        recommended_actions=recommended_actions
    )
    
    # 9. 更新学情数据（异步）
    await publish_event('practice.completed', {
        'user_id': session.user_id,
        'subject_code': session.subject_code,
        'knowledge_point_results': kp_analysis,
        'session_type': session.session_type
    })
    
    return await save_report(report)
```

### 9.2 关键异常处理策略

```python
class PracticeService:
    
    async def submit_answer(self, session_id, seq_no, answer):
        session = await self.get_session(session_id)
        
        # 1. 状态校验
        if session.status not in ('in_progress',):
            raise BusinessException('PRACTICE_005', '当前状态不允许提交答案')
        
        # 2. 题目校验
        question = await self.get_question(session_id, seq_no)
        if question.status == 'answered':
            raise BusinessException('PRACTICE_005', '该题已作答')
        
        # 3. 答案格式校验
        if not self.validate_answer_format(answer, question.type):
            raise BusinessException('PRACTICE_009', '答案格式不合法')
        
        try:
            # 4. 即时批改（选择/判断/填空）
            if question.type in ('choice', 'judge', 'fill'):
                result = await self.instant_grade(question, answer)
                await self.update_question_grade(question, result)
                
                # 5. 自适应难度调整
                if session.difficulty_mode == 'adaptive':
                    new_diff = self.adjust_difficulty(
                        session.current_difficulty,
                        result.is_correct,
                        self.get_streak(session_id)
                    )
                    await self.update_session_difficulty(session_id, new_diff)
                
                # 6. 错题自动收录
                if not result.is_correct:
                    await self.create_mistake_record(session, question, answer, result)
                
                # 7. 更新学情数据
                await self.update_learning_progress(session, question, result)
                
                return result
            else:
                # 解答题/作文等 → 异步批改
                await self.save_answer(question, answer)
                await self.publish_grading_task(session_id, seq_no)
                return {'status': 'grading', 'estimated_time_sec': 10}
                
        except AIServiceException as e:
            # AI服务异常 → 降级处理
            logger.error(f"AI grading failed: {e}")
            await self.save_answer(question, answer)
            await self.mark_grading_pending(question)
            return {'status': 'grading_pending', 'message': '批改服务繁忙，稍后出结果'}
```

# 防止同一练习会话并发提交
DISTRIBUTED_LOCK_KEY = "practice:submit:{session_id}:{seq_no}"

async def submit_answer_with_lock(session_id, seq_no, answer):
    lock = await redis.lock(
        DISTRIBUTED_LOCK_KEY.format(session_id=session_id, seq_no=seq_no),
        timeout=10  # 10秒锁超时
    )
    
    if not lock.acquired:
        raise BusinessException('PRACTICE_005', '正在处理中，请勿重复提交')
    
    try:
        return await do_submit_answer(session_id, seq_no, answer)
    finally:
        await lock.release()
