## 1. 概述

### 1.1 功能定位

PrimeTip 平台覆盖幼儿至高中全学段，其中幼儿启蒙与小学低年级模块（拼音学习、识字朗读、英语口语启蒙、听写默写）高度依赖语音交互。然而，主流 ASR（自动语音识别）引擎均基于成人语料训练，对儿童语音的识别准确率显著下降（通常 WER 高出 2-3 倍）。

本模块作为**语音服务的垂直领域增强层**，构建在通用 `语音服务(ASR-TTS)` 之上，为幼儿与低龄用户提供：

1. **儿童声学模型适配**：针对儿童声道的物理特征优化识别准确率
2. **儿童发音容错处理**：识别儿童常见的发音替代、音节缺失、含糊发音
3. **语音交互安全**：确保儿童语音数据的隐私保护与合规存储
4. **家庭环境降噪**：针对家庭场景（电视声、家人对话、玩具声）的鲁棒降噪
5. **语音内容安全过滤**：防止儿童在语音交互中接触不适宜内容

### 1.2 设计目标

| 指标 | 目标值 |
|------|--------|
| 儿童语音识别 WER（字错率） | ≤ 12%（普通话清晰发音） |
| 儿童语音识别 WER（拼音单音） | ≤ 8% |
| 端到端语音交互延迟 | ≤ 1500ms（采集→识别→反馈） |
| 家庭环境噪声鲁棒性 | SNR ≥ 10dB 时 WER 恶化 ≤ 3% |
| 儿童语音数据留存合规 | 满足《未成年人保护法》《儿童个人信息网络保护规定》 |
| 并发语音会话支持 | ≥ 500 路（单节点） |

### 1.3 适用场景

| 场景 | 学段 | 交互形式 |
|------|------|----------|
| 拼音发音陪练 | 幼儿~小学低年级 | 单音节/词组跟读 |
| 课文朗读评估 | 小学 | 整段/整篇朗读 |
| 英语单词发音 | 幼儿~小学 | 单词跟读 |
| 语音背诵检测 | 小学~初中 | 背诵段落检测 |

| 听写默写 | 小学 | 听写词语/默写句子 |

## 4. 核心算法设计

### 4.1 年龄感知模型路由（Age-Aware Model Router）

根据用户年龄、场景、网络条件，动态选择最优 ASR 模型。

```python
class ChildVoiceModelRouter:
    """儿童语音 ASR 模型智能路由"""
    
    # 年龄段→模型优先级映射
    AGE_MODEL_PRIORITY = {
        "toddler": {          # 3-4 岁
            "pinyin": ["child_acoustic_v3_toddler", "child_acoustic_v2", "general_v4"],
            "read_aloud": ["child_acoustic_v3_toddler", "child_acoustic_v2", "general_v4"],
            "voice_qa": ["child_acoustic_v2", "general_v4"],  # 幼儿QA降级到通用
        },
        "preschool": {        # 5-6 岁
            "pinyin": ["child_acoustic_v3_preschool", "child_acoustic_v2", "general_v4"],
            "read_aloud": ["child_acoustic_v3_preschool", "child_acoustic_v2", "general_v4"],
            "oral_english": ["child_en_v2", "general_en_v3"],
            "voice_qa": ["child_acoustic_v2", "general_v4"],
        },
        "early_primary": {   # 7-8 岁
            "pinyin": ["child_acoustic_v3_primary", "general_v4"],
            "read_aloud": ["child_acoustic_v3_primary", "general_v4"],
            "dictation": ["general_v4"],  # 已可使用通用模型
            "voice_qa": ["general_v4"],
        },
        "standard": {        # 9 岁+，使用通用模型
            "_all": ["general_v4"],
        },
    }
    
    def select_model(
        self,
        user_age: int,
        scenario: str,
        network_quality: str,  # good/medium/poor
        device_capability: str,  # high/medium/low
    ) -> str:
        """选择最优 ASR 模型"""
        
        age_stage = self._get_age_stage(user_age)
        model_list = self._get_model_candidates(age_stage, scenario)
        
        # 根据网络和设备条件筛选
        if network_quality == "poor" or device_capability == "low":
            # 弱网/低端设备：优先本地轻量模型或快速端模型
            model_list = self._prefer_fast_models(model_list)
        
        # 检查模型健康状态
        for model_code in model_list:
            if self._is_model_healthy(model_code):
                return model_code
        
        # 全部不可用时降级到通用模型
        return "general_v4"
    
    def _get_age_stage(self, age: int) -> str:
        if age <= 4:
            return "toddler"
        elif age <= 6:
            return "preschool"
        elif age <= 8:
            return "early_primary"
        else:
            return "standard"
```

### 4.2 儿童声纹检测（Child Voiceprint Detection）

判断输入音频是否来自儿童，用于动态路由决策。

```python
class ChildVoiceprintDetector:
    """
    基于 F0（基频）+ MFCC + 共振峰的轻量级儿童声检测。
    儿童基频范围: 250-400Hz（男童 250-340Hz，女童 280-400Hz）
    成人基频范围: 80-200Hz（男 80-150Hz，女 150-250Hz）
    """
    
    CHILD_F0_RANGE = (220, 450)   # 儿童基频范围(Hz)，放宽边界
    ADULT_F0_RANGE = (70, 260)    # 成人基频范围(Hz)
    
    # 儿童共振峰特征（第一共振峰 F1 普遍高于成人）
    CHILD_F1_MIN = 600  # Hz
    
    def detect(self, audio_samples, sample_rate=16000) -> dict:
        """
        检测音频是否为儿童语音。
        
        Returns:
            {
                "is_child": bool,
                "confidence": float,  # 0-1
                "estimated_age_group": str,  # toddler/preschool/early_primary/older/adult
                "f0_mean": float,
                "f0_std": float,
            }
        """
        # 1. 提取基频 F0
        f0 = self._extract_f0(audio_samples, sample_rate)
        f0_mean = np.mean(f0[f0 > 0]) if np.any(f0 > 0) else 0
        
        # 2. 提取 MFCC 特征
        mfcc = self._extract_mfcc(audio_samples, sample_rate)
        
        # 3. 提取共振峰
        formants = self._extract_formants(audio_samples, sample_rate)
        f1_mean = np.mean([f[0] for f in formants if len(f) > 0]) if formants else 0
        
        # 4. 规则判断
        f0_in_child_range = self.CHILD_F0_RANGE[0] <= f0_mean <= self.CHILD_F0_RANGE[1]
        f1_is_high = f1_mean >= self.CHILD_F1_MIN
        
        # 5. 模型判断（轻量 SVM 分类器）
        features = np.concatenate([
            [f0_mean, np.std(f0[f0 > 0]) if np.any(f0 > 0) else 0],
            np.mean(mfcc, axis=0)[:13],
            [f1_mean]
        ])
        model_score = self._svm_classifier.predict_proba(features.reshape(1, -1))[0]
        
        # 6. 融合决策
        is_child = f0_in_child_range and model_score[1] > 0.5
        confidence = model_score[1] if is_child else model_score[0]
        
        # 7. 年龄段估计
        if is_child:
            if f0_mean > 350:
                estimated_age = "toddler"
            elif f0_mean > 300:
                estimated_age = "preschool"
            elif f0_mean > 250:
                estimated_age = "early_primary"
            else:
                estimated_age = "older"
        else:
            estimated_age = "adult"
        
        return {
            "is_child": is_child,
            "confidence": round(confidence, 4),
            "estimated_age_group": estimated_age,
            "f0_mean": round(f0_mean, 1),
            "f0_std": round(np.std(f0[f0 > 0]) if np.any(f0 > 0) else 0, 1),
        }
```

### 4.3 儿童发音评估算法

#### 4.3.1 拼音单音评估

```python
class PinyinPronunciationEvaluator:
    """
    拼音单音/词组发音质量评估。
    
    评估维度：
    1. 声母准确度（声母是否发准）
    2. 韵母准确度（韵母是否发准）
    3. 声调准确度（声调是否正确）
    4. 整体相似度（与标准音的声学距离）
    """
    
    # 声母分组（按发音部位）
    INITIAL_GROUPS = {
        "bilabial": ["b", "p", "m"],           # 双唇音
        "labiodental": ["f"],                    # 唇齿音
        "alveolar": ["d", "t", "n", "l"],       # 舌尖中音
        "retroflex": ["zh", "ch", "sh", "r"],   # 舌尖后音
        "alveolar_sibilant": ["z", "c", "s"],   # 舌尖前音
        "palatal": ["j", "q", "x"],             # 舌面音
        "velar": ["g", "k", "h"],               # 舌根音
    }
    
    # 儿童常见声母混淆（用于容错判断）
    COMMON_CONFUSIONS = {
        ("zh", "z"), ("ch", "c"), ("sh", "s"),   # 平翘舌不分
        ("r", "l"),                                # r/l 混淆
        ("n", "l"),                                # n/l 混淆（南方常见）
        ("h", "f"),                                # h/f 混淆
        ("j", "z"), ("q", "c"), ("x", "s"),      # 面音与齿音混淆
    }
    
    def evaluate(
        self,
        audio_samples: np.ndarray,
        target_pinyin: str,   # 如 "mā" 或 "zhōng"
        sample_rate: int = 16000,
        user_age: int = 5,
    ) -> dict:
        """
        评估拼音发音。
        
        Returns:
            {
                "overall_score": float,      # 综合评分 0-100
                "initial_score": float,      # 声母评分
                "final_score": float,        # 韵母评分  
                "tone_score": float,         # 声调评分
                "issues": list,              # 具体问题列表
                "is_common_error": bool,     # 是否属于年龄常见错误
                "encouragement": str,        # 鼓励语
            }
        """
        # 解析目标拼音
        initial, final, tone = self._parse_pinyin(target_pinyin)
        
        # 提取标准音频特征（预录制的标准发音库）
        ref_features = self._get_reference_features(target_pinyin)
        
        # 提取用户音频特征
        user_features = self._extract_detailed_features(audio_samples, sample_rate)
        
        # 分维度评分
        initial_score = self._score_initial(user_features, ref_features, initial, user_age)
        final_score = self._score_final(user_features, ref_features, final, user_age)
        tone_score = self._score_tone(user_features, ref_features, tone, user_age)
        
        # 综合评分（加权平均，声母和韵母权重更高）
        weights = {"initial": 0.35, "final": 0.35, "tone": 0.30}
        if user_age <= 4:
            # 幼儿声调容错更高，降低声调权重
            weights = {"initial": 0.40, "final": 0.40, "tone": 0.20}
        
        overall = (
            initial_score * weights["initial"]
            + final_score * weights["final"]
            + tone_score * weights["tone"]
        )
        
        # 检测是否为年龄常见错误
        is_common = self._is_age_appropriate_error(
            initial, user_features, user_age
        )
        
        # 如果是常见错误，适度宽容（加分上限5分）
        if is_common and overall >= 60:
            overall = min(100, overall + 3)
        
        # 生成具体问题反馈
        issues = self._identify_issues(
            initial, final, tone,
            initial_score, final_score, tone_score,
            user_features, ref_features, user_age
        )
        
        # 生成鼓励语
        encouragement = self._generate_encouragement(overall, user_age)
        
        return {
            "overall_score": round(overall, 1),
            "initial_score": round(initial_score, 1),
            "final_score": round(final_score, 1),
            "tone_score": round(tone_score, 1),
            "issues": issues,
            "is_common_error": is_common,
            "encouragement": encouragement,
        }
    
    def _is_age_appropriate_error(
        self, target_initial: str, user_features: dict, age: int
    ) -> bool:
        """判断是否为该年龄段常见发音错误"""
        detected_initial = user_features.get("detected_initial", "")
        
        for correct, confused in self.COMMON_CONFUSIONS:
            if target_initial == correct and detected_initial == confused:
                if age <= 5:
                    return True  # 5岁以下完全容错
                elif age <= 7 and (correct, confused) in [
                    ("zh", "z"), ("ch", "c"), ("sh", "s"), ("r", "l")
                ]:
                    return True  # 7岁以下平翘舌容错
        return False
```

#### 4.3.2 朗读流畅度评估

```python
class ReadingFluencyEvaluator:
    """
    整段/整篇朗读流畅度评估。
    
    评估维度：
    1. 语速（字/分钟）
    2. 停顿合理性（段落间、标点处停顿 vs 不当停顿）
    3. 回读次数（读错后重新读）
    4. 音节清晰度
    5. 整体流畅度
    """
    
    # 年龄段参考语速（字/分钟）
    REFERENCE_SPEED = {
        (6, 7): {"min": 80, "ideal": 120, "max": 160},
        (7, 8): {"min": 100, "ideal": 140, "max": 180},
        (8, 9): {"min": 120, "ideal": 160, "max": 200},
        (9, 99): {"min": 140, "ideal": 180, "max": 240},
    }
    
    def evaluate(
        self,
        audio_samples: np.ndarray,
        reference_text: str,
        alignment_result: dict,  # 来自 ASR 的强制对齐结果
        sample_rate: int = 16000,
        user_age: int = 7,
    ) -> dict:
        """
        评估朗读流畅度。
        
        Args:
            alignment_result: 强制对齐输出，包含每个字的起止时间
        
        Returns:
            {
                "fluency_score": float,
                "speed_score": float,
                "pause_score": float,
                "clarity_score": float,
                "regression_count": int,    # 回读次数
                "words_per_minute": float,
                "details": {...}
            }
        """
        # 1. 计算语速
        total_chars = len(reference_text)
        duration_sec = len(audio_samples) / sample_rate
        wpm = (total_chars / duration_sec) * 60
        
        speed_ref = self._get_speed_reference(user_age)
        speed_score = self._score_speed(wpm, speed_ref)
        
        # 2. 停顿分析
        pauses = self._detect_pauses(alignment_result, audio_samples, sample_rate)
        appropriate_pauses = self._count_appropriate_pauses(pauses, reference_text)
        inappropriate_pauses = len(pauses) - appropriate_pauses
        pause_score = self._score_pauses(
            appropriate_pauses, inappropriate_pauses, total_chars
        )
        
        # 3. 回读检测
        regressions = self._detect_regressions(alignment_result, reference_text)
        
        # 4. 音节清晰度
        clarity = self._assess_syllable_clarity(alignment_result, audio_samples)
        
        # 5. 整体流畅度（综合评分）
        fluency_score = (
            speed_score * 0.25
            + pause_score * 0.35
            + clarity["score"] * 0.25
            + self._regression_penalty(regressions, total_chars) * 0.15
        )
        
        return {
            "fluency_score": round(fluency_score, 1),
            "speed_score": round(speed_score, 1),
            "pause_score": round(pause_score, 1),
            "clarity_score": round(clarity["score"], 1),
            "regression_count": len(regressions),
            "words_per_minute": round(wpm, 1),
            "details": {
                "total_pauses": len(pauses),
                "appropriate_pauses": appropriate_pauses,
                "inappropriate_pauses": inappropriate_pauses,
                "unclear_syllables": clarity["unclear"],
            }
        }
```

### 4.4 家庭环境智能降噪

```python
class HomeEnvironmentDenoiser:
    """
    针对家庭场景的智能降噪。
    常见家庭噪声：电视/手机媒体声、家人交谈、玩具声、宠物声、厨房声、空调声。
    """
    
    # 噪声类型→降噪策略
    DENOISE_STRATEGY = {
        "tv_media": {"method": "spectral_subtraction", "aggression": 0.7},
        "human_speech": {"method": "deep_denoiser", "model": "denoise_v2"},
        "toys": {"method": "highpass_filter", "cutoff": 200},
        "hvac": {"method": "stationary_noise", "aggression": 0.5},
        "transient": {"method": "transient_suppress", "threshold": 0.3},
    }
    
    def process(
        self,
        audio_samples: np.ndarray,
        sample_rate: int = 16000,
    ) -> tuple[np.ndarray, dict]:
        """
        智能降噪处理。
        
        Returns:
            (cleaned_audio, metadata)
            metadata = {
                "noise_types_detected": list,
                "snr_before": float,
                "snr_after": float,
                "processing_ms": int,
            }
        """
        # 1. 噪声分类（轻量 CNN 分类器）
        noise_types = self._classify_noise(audio_samples, sample_rate)
        
        # 2. SNR 估计
        snr_before = self._estimate_snr(audio_samples, sample_rate)
        
        # 3. 根据噪声类型选择策略
        import time
        start = time.time()
        
        cleaned = audio_samples.copy().astype(np.float32)
        
        for noise_type in noise_types:
            strategy = self.DENOISE_STRATEGY.get(noise_type)
            if not strategy:
                continue
            
            cleaned = self._apply_denoise(
                cleaned, sample_rate, strategy
            )
        
        # 4. 语音增强（提升儿童语音清晰度）
        cleaned = self._enhance_child_voice(cleaned, sample_rate)
        
        processing_ms = int((time.time() - start) * 1000)
        snr_after = self._estimate_snr(cleaned, sample_rate)
        
        return cleaned, {
            "noise_types_detected": noise_types,
            "snr_before": round(snr_before, 1),
            "snr_after": round(snr_after, 1),
            "processing_ms": processing_ms,
        }
    
    def _enhance_child_voice(self, audio, sr):
        """儿童语音增强：提升高频（儿童语音高频能量更丰富）"""
        # 高频提升（儿童语音特征频段 300-4000Hz）
        from scipy.signal import butter, sosfilt
        sos = butter(2, [300, 4000], btype='bandpass', fs=sr, output='sos')
        enhanced = sosfilt(sos, audio)
        # 混合原始与增强（避免过度处理）
        return 0.7 * audio + 0.3 * enhanced
```

### 5.2 流式语音识别接口

#### `WSS /api/v1/child-voice/stream/recognize`

建立 WebSocket 连接进行实时流式语音识别，适用于朗读、背诵等长文本场景。

**连接参数（Query String）**：

| 参数 | 必填 | 说明 |
|------|------|------|
| user_id | 是 | 用户 ID |
| scenario | 是 | 场景 |
| target_text | 否 | 对照文本 |
| sample_rate | 否 | 采样率（默认 16000） |

**通信协议**：

```text
Client → Server: 二进制音频帧（Opus 编码，每帧 20ms）
Client → Server: {"type": "end"} — 结束录音
Server → Client: {"type": "partial", "text": "...", "confidence": 0.85} — 中间结果
Server → Client: {"type": "final", "text": "...", "confidence": 0.92} — 最终结果
Server → Client: {"type": "evaluation", ...} — 评估结果（如果启用）
Server → Client: {"type": "safety_warning", "action": "mask"} — 安全告警
```

**客户端示例（Dart/Flutter）**：

```dart
class ChildVoiceStreamClient {
  final String baseUrl = 'wss://api.primetop.edu/api/v1/child-voice/stream/recognize';
  
  /// 启动流式语音识别
  Future<void> startStream({
    required int userId,
    required String scenario,
    String? targetText,
    required VoiceStreamCallback callback,
  }) async {
    final params = {
      'user_id': userId.toString(),
      'scenario': scenario,
      if (targetText != null) 'target_text': targetText,
      'sample_rate': '16000',
    };
    
    final uri = Uri.parse('$baseUrl?${_buildQuery(params)}');
    final channel = WebSocketChannel.connect(uri);
    
    // 发送音频流
    await for (final audioChunk in _audioStreamController.stream) {
      channel.sink.add(audioChunk); // 二进制音频帧
    }
    
    // 发送结束信号
    channel.sink.add(jsonEncode({'type': 'end'}));
    
    // 接收结果
    channel.stream.listen((message) {
      final data = jsonDecode(message);
      switch (data['type']) {
        case 'partial':
          callback.onPartial(data['text'], data['confidence']);
          break;
        case 'final':
          callback.onFinal(data['text'], data['confidence']);
          break;
        case 'evaluation':
          callback.onEvaluation(data);
          break;
        case 'safety_warning':
          callback.onSafetyWarning(data);
          break;
      }
    });
  }
}

abstract class VoiceStreamCallback {
  void onPartial(String text, double confidence);
  void onFinal(String text, double confidence);
  void onEvaluation(Map<String, dynamic> evaluation);
  void onSafetyWarning(Map<String, dynamic> warning);
}
```

## 6. 状态流转设计

### 6.1 语音会话状态机

```text
                    ┌──────────┐
    POST /recognize │ CREATED  │
         ─────────→ └────┬─────┘
                         │ 音频上传完成
                         ▼
                   ┌──────────────┐
                   │  PREPROCESS  │
                   │ (降噪+VAD)   │
                   └──────┬───────┘
                          │ 音频有效
                          ▼
                   ┌──────────────┐    不通过    ┌─────────────┐
                   │ AGE_ROUTING  │────────────→│ FALLBACK    │
                   │ (年龄路由)   │             │ (通用模型)   │
                   └──────┬───────┘             └──────┬──────┘
                          │ 通过                       │
                          ▼                            │
                   ┌──────────────┐                   │
                   │ RECOGNIZING  │←──────────────────┘
                   │ (ASR 推理)   │
                   └──────┬───────┘
                          │ 推理完成
                          ▼
                   ┌──────────────┐
                   │ EVALUATING   │  (enable_evaluation=true)
                   │ (发音评估)   │
                   └──────┬───────┘
                          │
                          ▼
                   ┌──────────────┐
                   │ SAFETY_CHECK │
                   │ (安全过滤)   │
                   └──────┬───────┘
                    ┌─────┴──────┐
                    │安全        │不安全
                    ▼            ▼
              ┌──────────┐  ┌───────────┐
              │ COMPLETED │  │ BLOCKED   │
              │ (返回结果)│  │ (拦截/脱敏) │
              └──────────┘  └───────────┘
```

### 6.2 状态定义

| 状态 | 说明 | 超时 | 超时处理 |
|------|------|------|----------|
| CREATED | 会话已创建，等待音频 | 10s | 自动取消 |
| PREPROCESS | 音频预处理中 | 3s | 跳过降噪 |
| AGE_ROUTING | 模型路由中 | 1s | 使用默认模型 |
| RECOGNIZING | ASR 推理中 | 15s | 降级通用模型 |
| EVALUATING | 发音评估中 | 10s | 跳过评估 |
| SAFETY_CHECK | 安全检查中 | 2s | 放行（fail-open） |
| COMPLETED | 成功完成 | - | - |
| BLOCKED | 安全拦截 | - | - |
| FAILED | 系统错误 | - | - |

### 6.3 模型降级链路

```text
首选: child_acoustic_v3_preschool (WER=8.2%)
  │
  ├─ 不可用/超时(>5s 无首结果) → 次级: child_acoustic_v2 (WER=11.5%)
  │                                 │
  │                                 ├─ 不可用/超时 → 兜底: general_v4 (WER=23.0%*)
  │                                 │                    │
  │                                 │                    ├─ 成功 → 熔断器半开探测
  │                                 │                    └─ 不可用 → FAILED(50001)
  │                                 │                       客户端降级为文字输入
  │                                 └─ 连续 3 次成功 → 熔断器关闭，恢复首选
  └─ 连续 3 次成功 → 熔断器关闭，恢复首选

英语场景:
child_en_v2 (WER=12.0%) → general_en_v3 (WER=21.0%*) → FAILED(50001)

* 注: WER 为成人模型在儿童语料上的实测估值，仅作路由决策参考，
  不向客户端透传，不用于对外宣传口径。
```

**降级决策表**：

| 触发条件 | 降级动作 | 用户感知 | 埋点事件 |
|----------|----------|----------|----------|
| 首选模型单次超时（>5s 无首结果） | 切换次级模型重试一次 | 延迟 +1~2s | `asr.degrade` |
| 首选模型 5 分钟窗口错误率 >30%（≥10 次样本） | 熔断 60s，期间直接路由次级 | 无感 | `asr.circuit_open` |
| 次级模型也失败 | 兜底通用模型，响应带 `degraded: true` | 准确率下降，话术引导"靠近麦克风、一字一句清晰读" | `asr.degrade` |
| 全部模型不可用 | 返回 50001，客户端降级为文字输入 | 显示"语音小助手休息一下，请打字告诉我" | `asr.unavailable` |
| 评估模型不可用 | 仅返回识别文本，`evaluation` 置 null | 不显示评分，显示"这次先帮你听听读得对不对，评分下次补上" | `eval.skip` |
| 降噪模块超时（>3s） | 跳过降噪直接送 ASR | 高噪声场景准确率下降 | `denoise.skip` |

**模型健康度探针**（每 10s 一轮，Redis 共享状态）：

| 健康键 | 内容 |
|--------|------|
| `asr:health:{model_code}` | `{status, latency_ms, success_rate_5m, updated_at}` |

- 探针样本：内置 3s 标准儿童语音"一二三四五，我爱学拼音"，测量延迟与识别置信度
- `status` 取值：`healthy`（正常路由）/ `degraded`（只允许兜底路径使用）/ `down`（跳过）
- 路由选择时先查健康键，`down` 直接跳过，`degraded` 仅当无 `healthy` 可选时启用

### 6.4 状态机守卫与竞态裁决

**守卫规则表（G1-G10）**：

| 编号 | 守卫规则 | 违例处理 |
|------|----------|----------|
| G1 | 会话状态只许向前迁移（CREATED→…→COMPLETED/BLOCKED/FAILED），禁止回退；FAILED 后复用同一 session_id 直接拒绝 | 返回 50001 并要求客户端重建会话 |
| G2 | CREATED→PREPROCESS 必须校验音频上传完整（multipart 完整性校验 + 时长>0） | 40003 |
| G3 | SAFETY_CHECK 是唯一直达 BLOCKED 的路径，其余模块发现疑似不安全内容仅记审计日志，不得直接改会话状态 | 状态写入口集中在 SafetyFilter |
| G4 | SAFETY_CHECK 超时 fail-open 仅放行安全置信度 ≥0.9 的结果；置信度 <0.9 且超时 → 转 BLOCKED 并进人工抽检队列 | 默认不裸放行 |
| G5 | 流式会话 30s 无心跳/音频帧，服务端主动断开 | 发送 close frame（code=4001, reason=idle_timeout） |
| G6 | 同一 user_id 同时只允许 1 路活跃流式会话，新连接挤掉旧连接 | 旧连接收到 close（code=4002, reason=superseded）后关闭；旧会话配额自动返还 |
| G7 | 发音基线（`child_pronunciation_baseline`）更新与评估结果同事务提交，禁止独立落库 | 评估结果整体回滚，重试一次后仍失败走 D9 补偿 |
| G8 | `store_audio=true` 必须同时具备家长语音留存授权标记（`parent_voice_consent=1`），否则强制按 false 处理 | 强制 false + 审计日志 `voice.store_denied` |
| G9 | 日限额在会话 CREATED 时预扣一次，FAILED（系统错误）自动返还；COMPLETED/BLOCKED 不返还 | 返还失败进入日终对账（§9-M8） |
| G10 | 声纹检测 `is_child_voice=false` 但注册年龄 ≤6 岁时，仍按儿童模型路由（低龄误检保护），仅记录检测不一致审计 | 仅审计，不阻断 |

**竞态裁决**：

| 竞态场景 | 裁决 |
|----------|------|
| 客户端网络重试导致同一音频重复提交 | `X-Client-Request-Id` 幂等去重（见 §7.1），重复请求直接回放首次响应 |
| 流式连接中断与最终结果回传竞态 | 以服务端会话终态为准；客户端凭 `resume_token` 断线重连拉取结果，重连窗口 30s |
| 配额预扣与会话失败并发 | 预扣/返还走 Lua 原子脚本（§7.2），杜绝负值 |
| 熔断恢复瞬间的请求洪峰 | 半开状态仅放行 1 个探测请求（SETNX 竞争），其余继续走次级模型 |
| 新连接挤掉旧连接时旧连接正在写基线 | 基线写入按 user_id 行锁串行化，旧会话写入完成后新会话才开始评估 |

## 7. 幂等性与并发控制

### 7.1 客户端请求幂等

所有写接口（`/recognize`、`/practice`、流式建立）支持请求头 `X-Client-Request-Id`（UUID v4）：

```text
首次请求:
  SET idem:cvs:{client_request_id} {status=PROCESSING} NX EX 86400 → OK
      ├─ 命中 PROCESSING → 客户端 202 + retry_after=2s 轮询
      └─ 完成 → 响应缓存至 idem:cvs:resp:{client_request_id}（TTL 24h）
重复请求:
  GET idem:cvs:{client_request_id}
      ├─ 存在 → 直接回放缓存响应（响应头 X-Idempotent-Replay: true）
      └─ 不存在 → 视为首次（例如 Redis 故障后降级路径）
```

- 未携带 `X-Client-Request-Id` 时，以 `(user_id, audio_sha256)` 组成 24h 去重窗口兜底
- 数据库唯一键兜底：`uk_client_request_id`（`child_voice_session.client_request_id`），Redis 失效时由 DB 唯一约束保证幂等

### 7.2 配额扣减原子化（Lua）

```lua
-- KEYS[1] = quota:{user_id}:{yyyyMMdd}  ARGV[1] = ttl_seconds(至当日 24:00 + 缓冲 600s)
local v = redis.call('GET', KEYS[1])
if v and tonumber(v) <= 0 then return -1 end           -- 已耗尽
redis.call('DECR', KEYS[1])
redis.call('EXPIRE', KEYS[1], ARGV[1])
return tonumber(redis.call('GET', KEYS[1]))              -- 返回剩余次数
```

- 预扣时机：会话 CREATED；返还时机：FAILED / G6 被挤掉 / 流式 resume 超时作废
- 返还亦走 Lua（INCR），并记录 `voice:quota:return_log`（zset，日终对账用）

### 7.3 流式会话断线恢复

| 项目 | 规则 |
|------|------|
| resume_token | 建立连接时下发，格式 `{session_id}:{last_seq}`，签名防伪造 |
| 重连窗口 | 断线 30s 内可凭 resume_token 恢复，服务端自 last_seq 重发未确认帧 |
| 窗口过期 | resume_token 作废，按新会话处理；旧会话已扣配额自动返还（G9） |
| 帧确认 | 客户端每收到一帧回 `ack:{seq}`；服务端以最大连续 ack 为确认水位 |

### 7.4 并发场景裁决表

| 场景 | 裁决 |
|------|------|
| 双击连发同一练习 | client_request_id 幂等，第二次回放首次响应 |
| 断线重发 | 命中幂等键直接回放，不重复扣配额 |
| 多端同时发起流式 | G6 挤掉策略，先到先得 |
| 配额服务与会话创建并发 | 先扣配额再建会话；建会话失败必须补偿返还（同事务 Saga 语义） |

## 8. 错误处理与降级策略

### 8.1 错误码汇总（与 §5 各接口一致，无新增数字段位）

| 错误码 | HTTP | 客户端提示（白名单话术） |
|--------|------|--------------------------|
| 40001 | 400 | "音频格式不支持，请重新录音" |
| 40002 | 400 | "录音太长了，请分成小段读给我听" |
| 40003 | 400 | "没有听到声音，请靠近麦克风再试一次" |
| 40301 | 403 | "需要爸爸妈妈先同意语音使用协议哦" |
| 40302 | 403 | "请让爸爸妈妈来帮你开启语音功能" |
| 42901 | 429 | "今天的语音练习次数用完啦，明天再来吧" |
| 50001 | 500 | "语音小助手休息一下，请打字告诉我"（降级文字输入） |
| 50002 | 200* | "这次先不评分，继续加油读"（识别成功，evaluation=null） |

*50002 返回 HTTP 200，仅 `evaluation` 字段为 null，业务上以 `eval.skip` 事件标记。

### 8.2 降级策略矩阵（D1-D10）

| 编号 | 故障点 | 降级动作 | 恢复条件 |
|------|--------|----------|----------|
| D1 | 全部 ASR 模型不可用 | 客户端降级文字输入；服务端返回 50001 | 熔断半开探测成功 |
| D2 | 评估模型不可用 | 仅返回识别文本（50002 语义） | 评估服务探针恢复 |
| D3 | 降噪模块超时 | 跳过降噪直接送 ASR；SNR<5dB 时话术引导换安静环境 | 降噪服务恢复 |
| D4 | 声纹检测服务故障 | 按注册年龄直接路由（跳过检测） | 探针恢复 |
| D5 | 安全过滤超时 | 按 G4 置信度裁决，禁止全量裸放行 | 服务恢复 |
| D6 | 配额服务（Redis）故障 | 按会员等级默认日限放行（免费 20 次/日，会员 200 次/日），日终依据会话流水补扣 | Redis 恢复 + 对账完成 |
| D7 | Redis 整体故障 | 幂等退化为 DB 唯一键 `uk_client_request_id`；配额降级为 D6 静态值 | Redis 恢复 |
| D8 | TTS 反馈播报故障 | 客户端使用本地预置鼓励语音包（含 10 条通用鼓励语） | TTS 探针恢复 |
| D9 | 基线表写入失败 | 评估结果仍正常返回；基线更新进补偿队列，指数退避重试（1m/5m/30m，共 3 次） | 重试成功或转人工 |
| D10 | **总红线** | 内容安全规则禁止整体跳过；仅允许 G4 的置信度裁决与 D5 超时路径，且二者任一触发必须落审计 | 永不自动豁免 |

### 8.3 重试策略

- 客户端对 50001 / 网络超时：指数退避 1s → 2s → 4s，共 3 次，仍失败走 D1 文字降级
- 42901 不重试；40301/40302 不重试，引导家长侧操作
- 服务端内部对 ASR 供应商调用：单模型 1 次重试（换备用 endpoint），禁止多级联重试放大延迟
