# 学生跨年级知识漏洞根因追溯与前置薄弱点精准诊断引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 学情诊断体系中的**深度根因分析层**，区别于已有的"当前薄弱点识别"和"学习卡点诊断"模块，专注于通过知识前置依赖图谱进行**多跳回溯**，将学生当前年级/学科的困难追溯到更低年级的前置知识漏洞，找到真正的认知根因。

**核心价值：** 当一个初三学生在二次函数上反复出错时，本引擎能追溯到根因可能是小学六年级"用字母表示数"或初一"一元一次方程"的认知缺陷，而非二次函数本身的问题。

### 1.2 与现有模块的边界

| 模块 | 关注点 | 与本引擎区别 |
|------|--------|-------------|
| 知识追踪模型引擎 | 当前知识点掌握度动态评估 | 提供**输入数据**，不做事后回溯 |
| 学习卡点诊断引擎 | 当前学习节点的卡点识别与突破 | 聚焦"现在卡在哪"，不做跨年级追溯 |
| 薄弱点识别服务 | 当前学科/章节维度的薄弱点 | 聚焦"面"上薄弱分布，不做链式根因 |
| 前置依赖检测服务 | 向前看：学习新知识前需要哪些基础 | 聚焦"前向预测"，本引擎聚焦"后向回溯" |
| 学科能力诊断测评 | 通过测评定位知识盲区 | 聚焦"当前年级诊断"，不做跨年级穿透 |

### 1.3 适用场景

1. **反复出错场景：** 学生在同一类型题目上持续出错，当前年级的讲解无效
2. **学习进度停滞：** 学生学习新章节异常缓慢，疑似前置基础薄弱
3. **成绩突变下降：** 学生成绩在某时间点后显著下滑，需定位根因
4. **新用户冷启动：** 新注册用户在初始能力评估中暴露多年级漏洞
5. **教师/家长咨询：** 需要解释"为什么孩子在这个知识点上学不会"
6. **精准补弱计划：** 为需要补弱的学生生成跨年级知识弥补路径

## 2. 数据结构定义

### 2.1 核心数据模型

#### 2.1.1 知识前置依赖图 (knowledge_prerequisite_edge)

本引擎依赖全局知识图谱中的前置依赖关系，但需要扩展存储依赖的**强度**与**类型**。

```sql
CREATE TABLE knowledge_prerequisite_edge (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    kp_id           BIGINT NOT NULL COMMENT '当前知识点ID',
    prerequisite_kp_id BIGINT NOT NULL COMMENT '前置知识点ID',
    dependency_type ENUM('STRONG','MEDIUM','WEAK') NOT NULL DEFAULT 'STRONG'
                    COMMENT 'STRONG=必须掌握才能学习;MEDIUM=有助理解;WEAK=相关背景',
    contribution_score DECIMAL(5,2) NOT NULL DEFAULT 0.50
                    COMMENT '前置知识对当前知识掌握的贡献权重 0.0-1.0',
    grade_gap       INT NOT NULL DEFAULT 0 COMMENT '年级跨度（当前年级-前置年级）',
    subject_same    BOOLEAN NOT NULL DEFAULT TRUE COMMENT '是否同学科',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_edge (kp_id, prerequisite_kp_id),
    KEY idx_prereq (prerequisite_kp_id),
    KEY idx_kp_gap (kp_id, grade_gap)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识前置依赖边';
```

#### 2.1.2 根因追溯诊断记录 (diagnosis_root_cause)

```sql
CREATE TABLE diagnosis_root_cause (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    diagnosis_id        VARCHAR(64) NOT NULL COMMENT '诊断唯一标识',
    student_id          BIGINT NOT NULL COMMENT '学生ID',
    trigger_type        ENUM('AUTO','MANUAL','TEACHER','PARENT','COLD_START')
                        NOT NULL DEFAULT 'AUTO' COMMENT '触发方式',
    trigger_kp_id       BIGINT COMMENT '触发的当前知识点ID（学生出错的点）',
    trigger_subject     VARCHAR(20) COMMENT '触发学科',
    trigger_grade       INT COMMENT '触发时学生年级',
    status              ENUM('PENDING','ANALYZING','COMPLETED','FAILED','EXPIRED')
                        NOT NULL DEFAULT 'PENDING',
    total_hops          INT DEFAULT 0 COMMENT '回溯最大跳数',
    root_causes_found   INT DEFAULT 0 COMMENT '发现的根因数量',
    summary             TEXT COMMENT '诊断摘要（自然语言）',
    confidence_score    DECIMAL(5,2) COMMENT '整体诊断置信度 0.0-1.0',
    recommended_action  ENUM('REMEDIAL_PLAN','NOTIFY_TEACHER','ADJUST_LEARNING_PATH',
                        'RE_TEST','NO_ACTION') COMMENT '推荐后续动作',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    completed_at        DATETIME,
    expired_at          DATETIME COMMENT '过期时间（默认30天）',
    KEY idx_student (student_id, status),
    KEY idx_trigger (trigger_kp_id, status),
    KEY idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='根因追溯诊断记录';
```

## 4. 核心算法设计

### 4.1 图遍历回溯算法 (RootCauseGraphTraverser)

引擎的核心是通过知识前置依赖图做多跳回溯遍历。采用**带剪枝的BFS**（广度优先搜索），在每一跳计算前置知识的"嫌疑分数"，优先深入高嫌疑路径。

```python
from collections import deque
from dataclasses import dataclass
from typing import Optional

@dataclass
class TraversalNode:
    """图遍历中的一个节点"""
    kp_id: int
    kp_name: str
    subject: str
    grade: int
    hop_distance: int           # 距触发点的跳数
    path: list[int]             # 路径上的知识点ID序列
    edge_type: str              # 依赖类型 STRONG/MEDIUM/WEAK
    contribution: float         # 从父节点传递到此的贡献系数（衰减后）
    mastery: Optional[float]    # 掌握度（从知识追踪服务获取）
    suspicion_score: float      # 嫌疑分数（越高越可能是根因）
    parent_kp_id: Optional[int] # 父知识点ID


class RootCauseGraphTraverser:
    """根因追溯图遍历器"""

    def __init__(
        self,
        prerequisite_repo,       # 前置依赖仓储
        knowledge_tracing_service, # 知识追踪服务客户端
        config: dict
    ):
        self.prerequisite_repo = prerequisite_repo
        self.kt_service = knowledge_tracing_service
        self.max_hops = config.get("max_hops", 5)
        self.min_contribution = config.get("min_contribution", 0.10)
        self.max_branches_per_node = config.get("max_branches_per_node", 8)
        self.max_total_nodes = config.get("max_total_nodes", 50)
        self.contribution_decay = config.get("contribution_decay", 0.7)

    def traverse(
        self,
        trigger_kp_id: int,
        student_id: int,
        trigger_mastery: float,
        options: dict = None
    ) -> list[TraversalNode]:
        """
        从触发知识点出发，回溯遍历前置依赖图。
        
        Args:
            trigger_kp_id: 学生当前出错的知识点
            student_id: 学生ID
            trigger_mastery: 触发点的当前掌握度
            options: 可选参数（include_cross_subject等）
            
        Returns:
            所有遍历到的节点列表（含嫌疑分数）
        """
        options = options or {}
        include_cross_subject = options.get("include_cross_subject", False)
        max_hops = options.get("max_hops", self.max_hops)

        result_nodes: list[TraversalNode] = []
        visited: set[int] = set()
        queue: deque[TraversalNode] = deque()
        total_nodes = 0

        # 起始节点（触发点本身）
        start = TraversalNode(
            kp_id=trigger_kp_id,
            kp_name="",
            subject="",
            grade=0,
            hop_distance=0,
            path=[trigger_kp_id],
            edge_type="STRONG",
            contribution=1.0,
            mastery=trigger_mastery,
            suspicion_score=1.0 - trigger_mastery,  # 掌握度越低，嫌疑越高
            parent_kp_id=None
        )
        queue.append(start)
        visited.add(trigger_kp_id)

        while queue and total_nodes < self.max_total_nodes:
            current = queue.popleft()
            if current.hop_distance > 0:  # 不收集触发点本身
                result_nodes.append(current)
            total_nodes += 1

            if current.hop_distance >= max_hops:
                continue

            # 获取当前知识点的前置依赖
            prerequisites = self.prerequisite_repo.get_prerequisites(
                kp_id=current.kp_id,
                include_cross_subject=include_cross_subject
            )

            # 按贡献度排序，限制每节点展开的分支数
            prerequisites.sort(key=lambda p: p.contribution_score, reverse=True)
            prerequisites = prerequisites[:self.max_branches_per_node]

            for prereq in prerequisites:
                if prereq.prerequisite_kp_id in visited:
                    continue

                visited.add(prereq.prerequisite_kp_id)

                # 计算衰减后的贡献度
                decayed_contribution = (
                    current.contribution
                    * prereq.contribution_score
                    * self.contribution_decay
                )

                # 剪枝：贡献度太低则不继续
                if decayed_contribution < self.min_contribution:
                    continue

                # 获取前置知识的掌握度
                mastery = self.kt_service.get_mastery(
                    student_id=student_id,
                    kp_id=prereq.prerequisite_kp_id
                )

                # 如果掌握度未知，用启发式推断
                if mastery is None:
                    mastery = self._infer_mastery(prereq, current)

                # 计算嫌疑分数
                suspicion = self._calculate_suspicion(
                    mastery=mastery,
                    contribution=decayed_contribution,
                    edge_type=prereq.dependency_type,
                    grade_gap=prereq.grade_gap
                )

                node = TraversalNode(
                    kp_id=prereq.prerequisite_kp_id,
                    kp_name=prereq.prerequisite_kp_name,
                    subject=prereq.prerequisite_subject,
                    grade=prereq.prerequisite_grade,
                    hop_distance=current.hop_distance + 1,
                    path=current.path + [prereq.prerequisite_kp_id],
                    edge_type=prereq.dependency_type,
                    contribution=decayed_contribution,
                    mastery=mastery,
                    suspicion_score=suspicion,
                    parent_kp_id=current.kp_id
                )
                queue.append(node)

        return result_nodes

    def _calculate_suspicion(
        self,
        mastery: float,
        contribution: float,
        edge_type: str,
        grade_gap: int
    ) -> float:
        """
        计算知识点的嫌疑分数。
        
        嫌疑分数 = (1 - mastery) * contribution * edge_weight * grade_gap_weight
        
        返回值范围 [0, 1]
        """
        mastery_deficit = max(0, 1.0 - mastery)

        edge_weights = {
            "STRONG": 1.0,
            "MEDIUM": 0.7,
            "WEAK": 0.4
        }
        edge_weight = edge_weights.get(edge_type, 0.5)

        # 年级跨度越大，如果是薄弱的，嫌疑越高（因为更可能是遗漏的基础）
        grade_gap_weight = 1.0 + min(grade_gap, 5) * 0.1

        raw = mastery_deficit * contribution * edge_weight * grade_gap_weight
        return min(raw, 1.0)

    def _infer_mastery(self, prereq, current_node) -> float:
        """
        当知识追踪数据缺失时，用启发式推断掌握度。
        
        策略：
        - 如果是2年以上未触及的知识点，默认掌握度衰减至0.4
        - 如果同学科同路径，继承父节点掌握度 - 0.1
        - 否则使用保守默认值0.5
        """
        if prereq.grade_gap >= 3:
            return 0.35  # 长时间未用，假设遗忘显著
        elif prereq.subject_same:
            return max(0.0, (current_node.mastery or 0.5) - 0.15)
        else:
            return 0.5
```

### 4.2 根因判定器 (RootCauseDeterminer)

遍历完成后，对所有节点进行根因判定。

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class RootCauseVerdict:
    """根因判定结果"""
    kp_id: int
    kp_name: str
    is_root_cause: bool
    root_cause_type: str        # KNOWLEDGE_GAP / MISCONCEPTION / SKILL_GAP / UNTAUGHT / FORGOTTEN
    contribution_score: float   # 最终贡献度
    confidence: float           # 判定置信度
    remediation_priority: int   # 弥补优先级 1-10
    evidence_refs: list[dict]   # 关联证据


class RootCauseDeterminer:
    """根因判定器"""

    # 嫌疑分数阈值：超过此值才考虑判定为根因
    SUSPICION_THRESHOLD = 0.15
    # 掌握度阈值：低于此值才认为是"薄弱"
    MASTERY_WEAK_THRESHOLD = 0.50
    # 高置信掌握度阈值：高于此值说明数据可靠
    MASTERY_CONFIDENT_THRESHOLD = 0.80

    def determine(
        self,
        traversal_nodes: list,
        evidence_map: dict,
        trigger_mastery: float
    ) -> list[RootCauseVerdict]:
        """
        对遍历结果进行根因判定。
        
        Args:
            traversal_nodes: 图遍历返回的节点列表
            evidence_map: {kp_id: [evidence_items]} 证据映射
            trigger_mastery: 触发点掌握度
            
        Returns:
            根因判定结果列表
        """
        verdicts = []

        for node in traversal_nodes:
            # 过滤：嫌疑分数不足的直接跳过
            if node.suspicion_score < self.SUSPICION_THRESHOLD:
                continue

            # 过滤：掌握度足够高的跳过
            if node.mastery and node.mastery >= self.MASTERY_CONFIDENT_THRESHOLD:
                continue

            # 判定根因类型
            rc_type = self._classify_root_cause_type(
                node=node,
                evidence=evidence_map.get(node.kp_id, []),
                trigger_mastery=trigger_mastery
            )

            # 计算置信度
            confidence = self._calculate_confidence(
                node=node,
                evidence_count=len(evidence_map.get(node.kp_id, [])),
                mastery_source=getattr(node, 'mastery_source', 'KT_MODEL')
            )

            # 是否判定为根因
            is_root = (
                node.suspicion_score >= self.SUSPICION_THRESHOLD
                and (node.mastery or 0) < self.MASTERY_WEAK_THRESHOLD
                and confidence >= 0.3
            )

            # 计算优先级
            priority = self._calculate_priority(
                contribution=node.contribution,
                mastery=node.mastery or 0.5,
                grade_gap=node.grade if hasattr(node, 'grade') else 0
                                         - (node.grade if hasattr(node, 'grade') else 0),
                hop_distance=node.hop_distance
            )

            verdict = RootCauseVerdict(
                kp_id=node.kp_id,
                kp_name=node.kp_name,
                is_root_cause=is_root,
                root_cause_type=rc_type,
                contribution_score=round(node.contribution, 4),
                confidence=round(confidence, 4),
                remediation_priority=priority,
                evidence_refs=[
                    {"type": e.get("type"), "summary": e.get("summary")}
                    for e in evidence_map.get(node.kp_id, [])[:5]
                ]
            )
            verdicts.append(verdict)

        # 按贡献度*置信度排序
        verdicts.sort(
            key=lambda v: v.contribution_score * v.confidence,
            reverse=True
        )
        return verdicts

    def _classify_root_cause_type(
        self,
        node,
        evidence: list,
        trigger_mastery: float
    ) -> str:
        """分类根因类型"""
        mastery = node.mastery or 0.5

        # 检查是否有迷思概念的证据
        error_types = {e.get("error_pattern_type") for e in evidence}
        if "CONSISTENT_WRONG_PATTERN" in error_types:
            return "MISCONCEPTION"

        # 检查是否是未学过的内容
        if mastery < 0.15 and node.hop_distance >= 3:
            return "UNTAUGHT"

        # 检查是否是遗忘（曾经学过但现在掌握度很低）
        if mastery < 0.30 and node.hop_distance <= 2:
            # 如果有历史数据表明曾经掌握过
            for e in evidence:
                if e.get("historical_mastery", 0) > 0.6:
                    return "FORGOTTEN"

        # 技能不足（理解概念但不能熟练运用）
        if 0.30 <= mastery < 0.50:
            return "SKILL_GAP"

        # 默认：知识缺口
        return "KNOWLEDGE_GAP"

    def _calculate_confidence(
        self,
        node,
        evidence_count: int,
        mastery_source: str
    ) -> float:
        """计算判定置信度"""
        # 基础置信度来自数据来源
        source_weights = {
            "KT_MODEL": 0.6,
            "RECENT_ASSESSMENT": 0.9,
            "INFERRED": 0.3,
            "UNKNOWN": 0.2
        }
        base = source_weights.get(mastery_source, 0.5)

        # 证据加成
        evidence_boost = min(evidence_count * 0.08, 0.3)

        # 嫌疑分数加成
        suspicion_boost = node.suspicion_score * 0.2

        return min(base + evidence_boost + suspicion_boost, 1.0)

    def _calculate_priority(
        self,
        contribution: float,
        mastery: float,
        grade_gap: int,
        hop_distance: int
    ) -> int:
        """计算弥补优先级 1-10"""
        # 贡献度越高，优先级越高
        score = contribution * 5

        # 掌握度越低，优先级越高
        score += (1 - mastery) * 3

        # 跳数越近，优先级越高（直接影响当前学习）
        score += max(0, (3 - hop_distance)) * 0.5

        # 年级跨度适中（1-3年）的优先级最高（最可能是遗漏基础）
        if 1 <= grade_gap <= 3:
            score += 1.5

        return max(1, min(10, round(score)))
```

```python
            patterns = self._detect_error_patterns(wrong_records)
            for pattern_type, pattern_desc in patterns:
                evidence.append({
                    "type": "ERROR_PATTERN",
                    "summary": pattern_desc,
                    "error_pattern_type": pattern_type
                })

        # 2. 错题记录证据
        mistakes = self.mistake_repo.query(
            student_id=student_id,
            kp_id=kp_id,
            since=since
        )
        if mistakes:
            evidence.append({
                "type": "WRONG_ANSWER",
                "summary": f"错题本中相关错题{len(mistakes)}道",
                "mistake_ids": [m.id for m in mistakes][:10],
                "recurring_count": sum(1 for m in mistakes if m.error_count > 1)
            })

        # 3. 学习行为证据
        behavior = self.behavior_repo.get_kp_learning_stats(
            student_id=student_id,
            kp_id=kp_id,
            since=since
        )
        if behavior:
            if behavior.avg_response_time_ms and behavior.peer_avg_response_time_ms:
                if behavior.avg_response_time_ms > behavior.peer_avg_response_time_ms * 1.5:
                    evidence.append({
                        "type": "SLOW_RESPONSE",
                        "summary": (
                            f"平均响应时间{behavior.avg_response_time_ms/1000:.1f}秒，"
                            f"是同龄人{behavior.peer_avg_response_time_ms/1000:.1f}秒的"
                            f"{behavior.avg_response_time_ms/behavior.peer_avg_response_time_ms:.1f}倍"
                        )
                    })

            if behavior.skip_rate and behavior.skip_rate > 0.3:
                evidence.append({
                    "type": "SKIPPED_QUESTION",
                    "summary": f"跳过率{behavior.skip_rate:.0%}，高于平均"
                })

        # 4. 历史掌握度（用于判断是否遗忘）
        historical = self.answer_record_repo.get_historical_mastery_trend(
            student_id=student_id,
            kp_id=kp_id,
            months_back=12

            evidence.append({
                "type": "LEARNING_TRAJECTORY",
                "summary": f"历史最高掌握度{historical.peak_mastery:.0%}（{historical.peak_month}），现已下降",

        patterns = []

        if not wrong_records:
            return patterns

        # 检测：同一错误答案反复出现
        answer_groups = defaultdict(list)
        for r in wrong_records:
            if r.student_answer:
                answer_groups[r.student_answer].append(r)

        for answer, records in answer_groups.items():
            if len(records) >= 2:
                patterns.append((
                    "CONSISTENT_WRONG_PATTERN",
                    f"多次选择相同错误答案'{answer}'（{len(records)}次），可能存在固定迷思概念"
                ))

        # 检测：特定题型集中错误
        type_groups = defaultdict(list)
        for r in wrong_records:
            type_groups[r.question_type].append(r)

        for q_type, records in type_groups.items():
            if len(records) >= 3:
                patterns.append((
                    "TYPE_CONCENTRATION",
                    f"在{q_type}题型上集中出错（{len(records)}次）"
                ))

        return patterns[:3]  # 最多返回3个模式
```

### 6.1 路径编排策略

```python
class RemediationPathBuilder:
    """弥补路径生成器"""

    def build(
        self,
        root_causes: list[RootCauseVerdict],
        student_profile: dict,
        content_catalog: dict
    ) -> dict:
        """
        根据根因判定结果生成弥补学习路径。
        
        策略：
        1. 按优先级排序根因
        2. 为每个根因匹配最佳内容
        3. 考虑内容间的依赖关系（先补最基础的）
        4. 控制总时长（建议不超过180分钟）
        """
        steps = []
        total_time = 0
        max_total_time = 180  # 分钟

        # 只取被判定为根因的节点
        confirmed_roots = [r for r in root_causes if r.is_root_cause]
        # 按优先级降序
        confirmed_roots.sort(key=lambda r: r.remediation_priority, reverse=True)

        for root in confirmed_roots:
            remaining_time = max_total_time - total_time
            if remaining_time < 15:
                break  # 时间不足，停止添加

            # 匹配内容
            content = self._match_content(
                root_cause=root,
                student_profile=student_profile,
                content_catalog=content_catalog,
                time_budget=remaining_time
            )

            if content:
                steps.append({
                    "order": len(steps) + 1,
                    "kpId": root.kp_id,
                    "kpName": root.kp_name,
                    "type": content["type"],
                    "contentId": content["id"],
                    "title": content["title"],
                    "estimatedTimeMin": content["time_min"],
                    "difficulty": content["difficulty"],
                    "reason": self._generate_reason(root)
                })
                total_time += content["time_min"]

        return {
            "totalEstimatedTimeMin": total_time,
            "steps": steps,
            "strategy": "PRIORITY_BASED_SEQUENTIAL"
        }

    def _match_content(
        self,
        root_cause: RootCauseVerdict,
        student_profile: dict,
        content_catalog: dict,
        time_budget: int
    ) -> dict | None:
        """为根因匹配最佳弥补内容"""
        # 根据根因类型选择内容类型
        type_preference = {
            "KNOWLEDGE_GAP": ["MICRO_LESSON", "VIDEO", "PRACTICE_SET"],
            "MISCONCEPTION": ["TUTORIAL_DIALOG", "MICRO_LESSON"],  # 迷思概念优先用AI对话纠正
            "SKILL_GAP": ["PRACTICE_SET", "FLASHCARD"],
            "UNTAUGHT": ["VIDEO", "MICRO_LESSON"],
            "FORGOTTEN": ["FLASHCARD", "PRACTICE_SET"],  # 遗忘优先用闪卡唤醒记忆
        }

        preferred_types = type_preference.get(
            root_cause.root_cause_type,
            ["MICRO_LESSON", "PRACTICE_SET"]
        )

        # 在内容目录中搜索匹配内容
        candidates = content_catalog.search(
            kp_id=root_cause.kp_id,
            content_types=preferred_types,
            grade_range=(student_profile["grade"] - 3, student_profile["grade"]),
            max_time=time_budget
        )

        if not candidates:
            return None

        # 选择最佳匹配（时间适中 + 难度匹配 + 评分最高）
        best = max(candidates, key=lambda c: (
            c.rating * 0.4
            + (1 - abs(c.difficulty - root_cause.remediation_priority / 10.0)) * 0.3
            + (1 - abs(c.time_min - 30) / 60) * 0.3
        ))

        return {
            "id": best.id,
            "title": best.title,
            "type": best.content_type,
            "time_min": min(best.estimated_time, time_budget),
            "difficulty": best.difficulty
        }

    def _generate_reason(self, root: RootCauseVerdict) -> str:
        """生成推荐理由（自然语言）"""
        type_reasons = {
            "KNOWLEDGE_GAP": f"贡献度较高({root.contribution_score:.0%})，且掌握度偏低，是重要基础缺口",
```

```python
class CachedPrerequisiteGraph:
    """带缓存的前置依赖图访问"""

    GRAPH_CACHE_KEY = "kp:prerequisite:graph:all"
    GRAPH_CACHE_TTL = 86400  # 24小时

    def __init__(self, redis_client, db_repo):
        self.redis = redis_client
        self.db = db_repo
        self._local_cache = None  # 进程级缓存

    async def get_prerequisites(self, kp_id: int, include_cross_subject: bool = False) -> list:
        """获取知识点的前置依赖（带多级缓存）"""
        # L1: 进程级缓存
        if self._local_cache is None:
            await self._load_graph_to_local()

        edges = self._local_cache.get(kp_id, [])
        if not include_cross_subject:
            edges = [e for e in edges if e["subject_same"]]
        return edges

    async def _load_graph_to_local(self):
        """加载全图到进程级缓存"""
        # L2: Redis缓存
        cached = await self.redis.get(self.GRAPH_CACHE_KEY)
        if cached:
            import json
            graph_data = json.loads(cached)
        else:
            # L3: 数据库加载
            graph_data = await self._load_from_db()
            # 回填Redis
            await self.redis.setex(
                self.GRAPH_CACHE_KEY,
                self.GRAPH_CACHE_TTL,
                json.dumps(graph_data)
            )

        # 转为邻接表
        self._local_cache = defaultdict(list)
        for edge in graph_data:
            self._local_cache[edge["kp_id"]].append(edge)

    async def invalidate_cache(self):
        """图谱更新时调用"""
        await self.redis.delete(self.GRAPH_CACHE_KEY)
        self._local_cache = None
```

```python
        await lock.release()
```

| RC_50005 | 内容匹配无结果 | 200 | 警告：返回路径为空，建议人工干预 |

### 8.2 降级策略实现

```python
class DiagnosisExecutor:
    """诊断执行器（含降级逻辑）"""

    async def execute(self, diagnosis_id: str, params: dict):
        """执行完整诊断流程"""
        try:
            # 步骤1：证据收集（允许部分失败）
            evidence = await self._collect_evidence_with_fallback(params)
            
            # 步骤2：图遍历（允许超时降级）
            nodes = await self._traverse_with_timeout(params, evidence)
            
            # 步骤3：根因判定（纯计算，不会失败）
            verdicts = self.determiner.determine(
                traversal_nodes=nodes,
                evidence_map=evidence,
                trigger_mastery=params["trigger_mastery"]
            )
            
            # 步骤4：弥补路径生成（允许为空）
            path = await self._build_path_with_fallback(verdicts, params)
            
            # 步骤5：保存结果
            await self._save_result(diagnosis_id, verdicts, path)
            
        except Exception as e:
            await self._handle_failure(diagnosis_id, e)

    async def _traverse_with_timeout(self, params, evidence) -> list:
        """带超时降级的图遍历"""
        try:
            result = await asyncio.wait_for(
                self.traverser.traverse(
                    trigger_kp_id=params["trigger_kp_id"],
                    student_id=params["student_id"],
                    trigger_mastery=params["trigger_mastery"]
                ),
                timeout=20.0  # 20秒超时
            )
            return result
        except asyncio.TimeoutError:
            # 降级：减少最大跳数后重试
            logger.warning("图遍历超时，降级为max_hops=2重试")
            reduced_params = {**params, "max_hops": 2}
            return await asyncio.wait_for(
                self.traverser.traverse(**reduced_params),
                timeout=10.0
            )

    async def _collect_evidence_with_fallback(self, params) -> dict:
        """带降级的证据收集"""
        evidence = {}
        failures = 0
        
        tasks = [
            ("answer_records", self.evidence_collector.collect_from_answers(params)),
            ("mistakes", self.evidence_collector.collect_from_mistakes(params)),
            ("behavior", self.evidence_collector.collect_from_behavior(params)),
        ]
        
        for source_name, task in tasks:
            try:
                result = await asyncio.wait_for(task, timeout=5.0)
                evidence.update(result)
            except Exception as e:
                failures += 1
                logger.warning(f"证据来源{source_name}收集失败: {e}")
                evidence[source_name] = []
        
        if failures == len(tasks):
            raise DiagnosisError(
                code="RC_50004",
                message="所有证据来源均收集失败"
            )
        
        # 标记证据完整度
        evidence["_completeness"] = (len(tasks) - failures) / len(tasks)
        return evidence
```

```python
DIAGNOSIS_QUEUE = "diagnosis.root_cause.tasks"
DIAGNOSIS_RESULT_EXCHANGE = "diagnosis.root_cause.results"

class DiagnosisTaskProducer:
    """诊断任务生产者"""

    async def submit(self, diagnosis_id: str, params: dict):
        """提交诊断任务到队列"""
        message = {
            "diagnosisId": diagnosis_id,
            "studentId": params["student_id"],
            "triggerKpId": params["trigger_kp_id"],
            "maxHops": params.get("max_hops", 5),
            "options": params.get("options", {}),
            "submittedAt": datetime.utcnow().isoformat(),
            "priority": self._calculate_priority(params)
        }
        await self.mq.publish(
            queue=DIAGNOSIS_QUEUE,
            message=json.dumps(message),
            priority=message["priority"]
        )

    def _calculate_priority(self, params) -> int:
        """计算任务优先级"""
        # 教师/家长手动触发 > 冷启动 > 自动触发
        priority_map = {
            "TEACHER": 9,
            "PARENT": 8,
            "COLD_START": 6,
            "MANUAL": 5,
            "AUTO": 3
        }
        return priority_map.get(params.get("trigger_type", "AUTO"), 3)


class DiagnosisTaskConsumer:
    """诊断任务消费者"""

    def __init__(self, executor: DiagnosisExecutor):
        self.executor = executor

    async def start_consuming(self):
        """启动消费循环"""
        async for message in self.mq.consume(DIAGNOSIS_QUEUE):
            try:
                task = json.loads(message.body)
                await self.executor.execute(
                    diagnosis_id=task["diagnosisId"],
                    params=task
                )
                await message.ack()
            except Exception as e:
                logger.error(f"诊断任务执行失败: {e}", exc_info=True)
                # 重试逻辑：最多重试3次，之后进入死信队列
                if task.get("retry_count", 0) < 3:
                    task["retry_count"] = task.get("retry_count", 0) + 1
                    await self.mq.publish(
                        queue=DIAGNOSIS_QUEUE,
                        message=json.dumps(task),
                        delay=30  # 30秒后重试
                    )
                await message.ack()  # 确认原消息（避免阻塞）
```

## 15. 附录

### 15.1 根因类型说明

| 类型 | 含义 | 特征 | 弥补策略 |
|------|------|------|---------|
| KNOWLEDGE_GAP | 知识缺口 | 完全未学过或掌握度极低 | 系统学习微课+练习 |
| MISCONCEPTION | 迷思概念 | 有固定错误模式，不是不会而是理解有误 | AI对话纠偏+对比辨析 |
| SKILL_GAP | 技能缺口 | 概念懂但不能熟练运用 | 大量专项练习 |
| UNTAUGHT | 未学内容 | 低年级跳级/转学/缺课导致 | 补充学习完整课程 |
| FORGOTTEN | 遗忘 | 曾经掌握但随时间衰减 | 闪卡快速唤醒+间隔复习 |

### 15.2 贡献度衰减模型

贡献度沿图路径逐跳衰减，模型如下：

```
contribution(node, hop_n) = contribution(parent) × edge_weight × decay_factor^n

其中：
- edge_weight: 前置依赖边的贡献分数 (0.0-1.0)
- decay_factor: 衰减系数，默认0.7
- hop_n: 第n跳

示例：
触发点 → hop1(STRONG, 0.8) → hop2(MEDIUM, 0.6) → hop3(STRONG, 0.7)
贡献度：1.0 → 0.56 → 0.235 → 0.082
```

衰减系数可根据学科特性调整：
- 数学/物理：0.75（知识链条紧密，前置依赖传递性强）
- 语文/英语：0.65（知识关联较松散）
- 历史/地理：0.60（跨年级关联最弱）

### 15.3 知识追踪数据缺失处理

当学生在某个前置知识点上完全没有答题记录时：

| 情况 | 推断策略 | 置信度调整 |
|------|---------|-----------|
| 年级跨度≥3年且无记录 | 假设掌握度=0.35（显著遗忘） | 置信度×0.5 |
| 同年级但未学过 | 假设掌握度=0.30 | 置信度×0.4 |
| 学过但无数据 | 假设掌握度=0.50 | 置信度×0.3 |
| 有历史但近期无更新 | 使用最近一次掌握度-0.1衰减 | 置信度×0.7 |
