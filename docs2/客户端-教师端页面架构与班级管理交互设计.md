## 1. 模块概述

### 1.1 功能定位

教师端页面架构是 PrimeTop V2.0 面向教师用户的客户端（Web 管理后台 + 小程序）页面体系，负责：
- 教师注册认证与身份管理
- 班级创建、邀请码分发、学生名册管理
- 作业选题、发布、批改与统计
- 班级学情看板与个体学情详情
- 班级通知发布与家长回执追踪
- 教师个人中心与多班级切换

### 1.2 技术选型

| 维度 | 方案 | 说明 |
|------|------|------|
| Web 端 | React 18 + Ant Design Pro | 管理后台场景，信息密度高，PC 大屏为主 |
| 小程序端 | Taro 3 + 自定义组件库 | 移动端轻量操作，查看+简单操作 |
| 状态管理 | Zustand（Web）+ Taro 自有状态（小程序） | 轻量、与现有客户端技术栈统一思路 |
| 路由 | React Router v6（Web）+ Taro Router（小程序） | 路由守卫控制认证和权限 |
| 图表 | ECharts（Web）+ ECharts-Taro（小程序） | 学情看板、答题统计图表 |
| 网络层 | Axios + SWR（Web）+ Taro.request（小程序） | 请求封装、缓存、重试 |

### 1.3 前置依赖

| 依赖 | 说明 |
|------|------|
| 客户端组件库与设计系统 | 通用组件、主题、图标 |
| 客户端路由与深链接系统 | 页面路由、深链接跳转 |
| 客户端网络请求治理 | 请求封装、错误处理、弱网适配 |

```typescript
// pages/login/LoginPage.tsx

interface LoginFormData {
  phone: string;
  password: string;
}

const LoginPage: React.FC = () => {
  const [form, setForm] = useState<LoginFormData>({ phone: '', password: '' });
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const handleLogin = async () => {
    // 1. 前端校验
    if (!validatePhone(form.phone)) {
      setError('请输入正确的手机号');
      return;
    }
    if (form.password.length < 8) {
      setError('密码长度不能少于8位');
      return;
    }

    setLoading(true);
    setError(null);

    try {
      // 2. 调用登录接口
      const result = await authApi.teacherLogin({
        phone: form.phone,
        password: form.password,
        clientType: 'web_teacher',  // 区分教师端
      });

      // 3. 存储 Token
      authStorage.setTokens({
        accessToken: result.accessToken,
        refreshToken: result.refreshToken,
      });

      // 4. 加载教师档案
      const profile = await teacherApi.getProfile();
      teacherStore.auth = {
        token: result.accessToken,
        refreshToken: result.refreshToken,
        certStatus: profile.certStatus,
        teacherId: profile.teacherId,
        name: profile.name,
        school: profile.school,
        subjects: profile.subjects,
      };

      // 5. 根据认证状态路由
      if (profile.certStatus === 'none') {
        navigate('/certification');
      } else {
        navigate('/main/dashboard');
      }

    } catch (err) {
      if (err.code === 'AUTH_003') {
        setError('手机号或密码错误');
      } else if (err.code === 'AUTH_010') {
        setError('该账号未注册为教师，请先注册');
      } else {
        setError('登录失败，请稍后重试');
      }
    } finally {
      setLoading(false);
    }
  };

  // ... render
};
```

**状态码处理：**

| 错误码 | 场景 | 处理 |
|--------|------|------|
| AUTH_003 | 手机号或密码错误 | 提示用户重新输入 |
| AUTH_005 | 账号被冻结 | 提示联系客服 |
| AUTH_010 | 非教师账号 | 引导注册教师身份 |
| AUTH_011 | 账号待审核 | 跳转认证状态页 |

#### 3.2.2 数据加载策略

```typescript
// pages/dashboard/useDashboardData.ts

interface DashboardData {
  todayTasks: {
    pendingGrading: GradingTask[];
    pendingNotices: NoticeTask[];
  };
  overview: {
    classCount: number;
    studentTotal: number;
    weeklyActiveRate: number;
    weakPointAlerts: number;
  };
  weakKnowledgePoints: WeakKnowledgePoint[];
  assignmentTrend: AssignmentTrendPoint[];
}

/** 自定义 Hook：首页数据加载 */
function useDashboardData(classId: string | null) {
  const [data, setData] = useState<DashboardData | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  // 首次加载：并行请求所有数据
  useEffect(() => {
    let cancelled = false;

    async function loadAll() {
      setLoading(true);
      try {
        const [tasks, overview, weakPoints, trend] = await Promise.all([
          teacherApi.getTodayTasks(classId),
          teacherApi.getOverview(classId),
          teacherApi.getWeakKnowledgePoints(classId, { top: 5 }),
          teacherApi.getAssignmentTrend(classId, { limit: 4 }),
        ]);

        if (!cancelled) {
          setData({
            todayTasks: tasks,
            overview,
            weakKnowledgePoints: weakPoints,
            assignmentTrend: trend,
          });
        }
      } catch (err) {
        if (!cancelled) setError(err as Error);
      } finally {
        if (!cancelled) setLoading(false);
      }
    }

    loadAll();
    return () => { cancelled = true; };
  }, [classId]);

  // 自动刷新：每 60s 轮询待办数量（轻量）
  useEffect(() => {
    const timer = setInterval(async () => {
      try {
        const taskCount = await teacherApi.getTaskCounts(classId);
        setData(prev => prev ? {
          ...prev,
          todayTasks: { ...prev.todayTasks, ...taskCount },
        } : prev);
      } catch { /* 静默失败 */ }
    }, 60_000);
    return () => clearInterval(timer);
  }, [classId]);

  return { data, loading, error, refetch: () => loadAll() };
}
```

### 3.4 作业管理 `/main/assignments`

#### 3.4.1 作业列表（跨班级视图）`/main/assignments`

**列表列定义：** 作业标题 / 班级 / 题型构成（选择 N 填空 N 解答 N）/ 发布状态 / 截止时间 / 提交进度（已交/应交）/ 批改进度（已批/已交）。

#### 3.4.2 创建作业 `/main/assignments/create`

**创建流程：**

```
选择班级 → 填写基本信息(标题/截止时间/预计时长)
  → 选题(题库搜索/章节筛选/薄弱点靶向预填/AI智能组卷)
  → 题目排序与分值设置
  → 分层设置(基础/提高/挑战 可选, 按学生标签分发)
  → 预览(学生视角) → 保存草稿 / 立即发布 / 定时发布
```

**关键交互与守卫：**

| 编号 | 守卫 | 说明 |
|------|------|------|
| G1 | 截止时间校验 | 不得早于当前时间 +30 分钟；截止前 2h（可配）触发未交提醒 |
| G2 | 题目有效性 | 发布前逐题校验（题库状态、分值>0），校验失败定位到题目并标红；对应服务端 50301 |
| G3 | 草稿可改、已发布不可改 | 已发布作业仅可追加"补充说明"通知，不可改题（服务端 50300），客户端置灰编辑入口并给出提示文案 |
| G4 | 薄弱点预填 | 从学情看板进入时 URL 携带 `?kpTags=...`，选题面板自动带入筛选条件；离开页面二次确认防误丢草稿 |
| G5 | 发布幂等 | 发布按钮点击后进入 submitting 态防连点；断网重试复用同一 `X-Idempotency-Key` |

**核心 API：**

| 方法 | 路径 | 说明 |

## 4. 全局状态管理

### 4.1 Zustand Store 划分（Web 端）

```typescript
// stores/teacherStore.ts
import { create } from 'zustand';

interface TeacherState {
  // 会话级
  profile: TeacherProfile | null;
  certStatus: 'none' | 'pending' | 'verified' | 'rejected';
  currentClassId: string | null;          // 顶部班级选择器
  semester: string;                       // 当前学期
  // 班级上下文缓存（列表接口顺带返回的摘要，减少详情页二次请求）
  classSummaries: Record<string, ClassSummary>;
  setProfile: (p: TeacherProfile) => void;
  switchClass: (classId: string) => void;
}

export const useTeacherStore = create<TeacherState>((set) => ({
  profile: null,
  certStatus: 'none',
  currentClassId: null,
  semester: '',
  classSummaries: {},
  setProfile: (profile) => set({ profile, certStatus: profile.certStatus }),
  switchClass: (currentClassId) => set({ currentClassId }),
}));
```

**设计原则：**
1. **班级上下文单一来源**：`currentClassId` 只存于本 Store，路由参数 `:id` 变化时同步写入（路由守卫内完成），避免双源漂移
2. **作业草稿本地暂存**：创建作业表单用 sessionStorage 暂存（key 含 classId），切换班级互不清空；提交成功或显式放弃后清除
3. **小程序端对等实现**：Taro 端用全局 `getApp().globalData` + 页面级 state，不做跨端 store 复用强求

### 4.2 路由守卫

```typescript
// router/guards.tsx
export function TeacherRouteGuard({ children }: { children: ReactNode }) {
  const { profile, certStatus } = useTeacherStore();
  const location = useLocation();

  // 1. 未登录 → /login（带 redirect 回跳参数）
  if (!profile) return <Navigate to={`/login?redirect=${encodeURIComponent(location.pathname)}`} replace />;

  // 2. 认证拦截：cert 页本身豁免，避免死循环
  if (certStatus === 'none' && location.pathname !== '/certification') {
    return <Navigate to="/certification" replace />;
  }

  // 3. 班级作用域路由：/main/classes/:id/* 校验教师为班级成员
  const classMatch = location.pathname.match(/^\/main\/classes\/([^/]+)/);
  if (classMatch) {
    const summaries = useTeacherStore.getState().classSummaries;
    if (!summaries[classMatch[1]]) {
      return <ClassScopeChecker classId={classMatch[1]}>{children}</ClassScopeChecker>;
    }
  }
  return <>{children}</>;
}
```

> 班级作用域校验最终权威在服务端（50401），客户端 `ClassScopeChecker` 只做体验级预检：拉取班级摘要失败/无权时渲染 403 页并返回班级列表，不展示任何数据。

## 8. 性能设计

1. **列表分页**：名册/作业/通知统一 pageSize 默认 50，滚动加载复用通用列表组件

4. **图表懒渲染**：ECharts 组件进入视口才 init，离屏 dispose
5. **小程序包体积**：图表库按需引入，教师端专属页面分包加载（对齐应用包体积优化策略）
