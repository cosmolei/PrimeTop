# 客户端-登录注册与入门引导页面架构设计

## 1. 概述

### 1.1 文档目的

本文档详细设计 PrimeTop 客户端的登录注册与入门引导流程，涵盖手机号验证码登录、第三方 OAuth 登录、注册建档、年级学段选择、教材版本配置、兴趣偏好设定和新手教程的完整页面架构与交互设计。使开发人员可直接参照编码。

### 1.2 范围

| 范围 | 说明 |
|------|------|
| 登录页 | 手机号+验证码、第三方登录（微信/QQ/Apple）、协议确认 |
| 注册建档 | 新用户建档、角色选择（学生/家长） |
| 入门引导 | 年级学段选择、教材版本选择、学科偏好、学习目标设定 |
| 新手教程 | 首页功能引导、AI对话引导、拍题引导 |
| 认证恢复 | Token 自动刷新、登录态恢复、设备切换处理 |

### 1.3 设计原则

1. **极简起步**：首次启动到可用状态控制在 3 步以内（核心路径）
2. **渐进采集**：非必要信息延迟采集，不阻塞进入主流程
3. **分龄适配**：引导页面的语言、视觉和复杂度按目标学段自适应
4. **可恢复性**：引导中断后可从断点继续，已填信息不丢失
5. **合规优先**：隐私协议、儿童信息保护规则在采集前完成确认

```dart
    // ...

    // 每秒递减 countdownSeconds
```

```dart
class WechatLoginService {
  static const String _appId = 'wx_app_id';

  /// 检查微信是否安装
  Future<bool> isWechatInstalled() async {
    return await Fluwx.instance.isWeChatInstalled;
  }

  /// 发起微信授权
  Future<WechatAuthResult> authorize() async {
    await Fluwx.instance.auth(
      scope: 'snsapi_userinfo',
      state: _generateState(),
    );

    // 通过 Stream 监听授权结果
    final result = await Fluwx.instance.authResponse.first
        .timeout(const Duration(seconds: 60));

    if (result.errCode == 0) {
      return WechatAuthResult(code: result.code!);
    }
    throw OAuthException(
      provider: 'wechat',
      code: 'AUTH_CANCELLED',
      message: '微信授权已取消',
    );
  }
}
```

#### Apple 登录（iOS 13+ 必须提供）

```dart
class AppleLoginService {
  /// 发起 Apple 授权
  Future<AppleAuthResult> authorize() async {
    if (!await AppleSignIn.isAvailable()) {
      throw OAuthException(
        provider: 'apple',
        code: 'NOT_AVAILABLE',
        message: '当前系统版本不支持 Apple 登录',
      );
    }

    final result = await AppleSignIn.performRequests([
      const AppleIdRequest(requestedScopes: [
        Scope.email,
        Scope.fullName,
      ])
    ]);

    switch (result.status) {
      case AuthorizationStatus.authorized:
        return AppleAuthResult(
          identityToken: result.credential.identityToken,
          authorizationCode: result.credential.authorizationCode,
          fullName: result.credential.fullName,
        );
      case AuthorizationStatus.cancelled:
        throw OAuthException(
          provider: 'apple',
          code: 'AUTH_CANCELLED',
          message: 'Apple 授权已取消',
        );
      case AuthorizationStatus.error:
        throw OAuthException(
          provider: 'apple',
          code: 'AUTH_ERROR',
          message: result.error.localizedDescription,
        );
    }
  }
}
```

## 9. Token管理与登录态恢复

### 9.1 Token 存储策略

```dart
class TokenManager {
  static const _accessTokenKey = 'auth_access_token';
  static const _refreshTokenKey = 'auth_refresh_token';
  static const _expiresAtKey = 'auth_expires_at';
  static const _userIdKey = 'auth_user_id';

  final FlutterSecureStorage _secureStorage;

  /// 保存 Token
  Future<void> saveTokens(AuthTokens tokens) async {
    await _secureStorage.write(key: _accessTokenKey, value: tokens.accessToken);
    await _secureStorage.write(key: _refreshTokenKey, value: tokens.refreshToken);
    await _secureStorage.write(
      key: _expiresAtKey,
      value: tokens.expiresAt.toIso8601String(),
    );
    await _secureStorage.write(key: _userIdKey, value: tokens.userId);
  }

  /// 获取有效 Access Token（自动刷新）
  Future<String?> getValidAccessToken() async {
    final expiresAtStr = await _secureStorage.read(key: _expiresAtKey);
    if (expiresAtStr == null) return null;

    final expiresAt = DateTime.parse(expiresAtStr);
    final now = DateTime.now();

    // 提前5分钟刷新，避免临界过期
    if (now.isAfter(expiresAt.subtract(const Duration(minutes: 5)))) {
      return await _refreshTokens();
    }

    return await _secureStorage.read(key: _accessTokenKey);
  }

  /// 刷新 Token
  Future<String?> _refreshTokens() async {
    final refreshToken = await _secureStorage.read(key: _refreshTokenKey);
    if (refreshToken == null) return null;

    try {
      final response = await _apiClient.post(
        '/api/v1/auth/token/refresh',
        data: {'refresh_token': refreshToken},
      );

      final tokens = AuthTokens.fromJson(response.data);
      await saveTokens(tokens);
      return tokens.accessToken;
    } on ApiException catch (e) {
      if (e.statusCode == 401) {
        // Refresh Token 也过期，清除登录态
        await clearTokens();
        return null;
      }
      rethrow;
    }
  }

  /// 清除 Token
  Future<void> clearTokens() async {
    await _secureStorage.delete(key: _accessTokenKey);
    await _secureStorage.delete(key: _refreshTokenKey);
    await _secureStorage.delete(key: _expiresAtKey);
    await _secureStorage.delete(key: _userIdKey);
  }
}
```

### 9.2 Dio 拦截器（自动刷新）

```dart
class AuthInterceptor extends Interceptor {
  final TokenManager _tokenManager;
  final GlobalKey<NavigatorState> _navigatorKey;

  AuthInterceptor(this._tokenManager, this._navigatorKey);

  @override
  Future<void> onRequest(
    RequestOptions options,
    RequestInterceptorHandler handler,
  ) async {
    // 排除不需要 Token 的接口
    if (_isPublicEndpoint(options.path)) {
      handler.next(options);
      return;
    }

    final token = await _tokenManager.getValidAccessToken();
    if (token != null) {
      options.headers['Authorization'] = 'Bearer $token';
      handler.next(options);
    } else {
      // Token 获取失败，跳转登录
      await _tokenManager.clearTokens();
      _navigateToLogin();
      handler.reject(DioException(
        requestOptions: options,
        error: 'Session expired',
        type: DioExceptionType.cancel,
      ));
    }
  }

  @override
  Future<void> onError(
    DioException err,
    ErrorInterceptorHandler handler,
  ) async {
    if (err.response?.statusCode == 401) {
      // 尝试刷新一次
      final newToken = await _tokenManager.getValidAccessToken();
      if (newToken != null) {
        // 用新 Token 重试
        err.requestOptions.headers['Authorization'] = 'Bearer $newToken';
        try {
          final response = await Dio().fetch(err.requestOptions);
          handler.resolve(response);
          return;
        } catch (_) {
          // 重试也失败，走正常登出
        }
      }
      await _tokenManager.clearTokens();
      _navigateToLogin();
    }
    handler.next(err);
  }

  bool _isPublicEndpoint(String path) {
    return [
      '/api/v1/auth/sms/send',
      '/api/v1/auth/sms/verify',
      '/api/v1/auth/oauth/callback',
      '/api/v1/auth/guest',
      '/api/v1/auth/token/refresh',
    ].any((p) => path.contains(p));
  }

  void _navigateToLogin() {
    _navigatorKey.currentState?.pushNamedAndRemoveUntil(
      '/login',
      (route) => false,
    );
  }
}
```

| OAuth 取消 | AUTH_OAUTH_CANCELLED | （无提示，静默返回） | 恢复登录页 |
| OAuth 授权失败 | AUTH_OAUTH_FAILED | 第三方登录失败，请重试 | 显示其他方式 |
| 网络异常 | NETWORK_ERROR | 网络不给力，请检查网络 | 重试按钮 |
| 服务器异常 | SERVER_ERROR | 服务暂时不可用，请稍后重试 | 重试按钮 |

### 11.2 错误处理组件

```dart
class LoginErrorHandler {
  static String getUserMessage(ApiException error, {LoginMethod? method}) {
    switch (error.code) {
      case 'AUTH_SMS_RATE_LIMIT':
        return '发送过于频繁，请稍后重试';
      case 'AUTH_SMS_CODE_INVALID':
        return '验证码错误，请重新输入';
      case 'AUTH_SMS_CODE_EXPIRED':
        return '验证码已过期，请重新获取';
      case 'AUTH_SMS_DAILY_LIMIT':
        return '今日验证码次数已用完，请明日再试\n或使用其他登录方式';
      case 'AUTH_ACCOUNT_DISABLED':
        return '账号已被禁用';
      case 'AUTH_OAUTH_CANCELLED':
        return ''; // 静默
      case 'AUTH_OAUTH_FAILED':
        return '${method?.displayName ?? '第三方'}登录失败，请重试';
      case 'AUTH_DEVICE_CONFLICT':
        return '该设备已有登录账号，请先退出或切换';
      default:
        if (error.isNetworkError) return '网络不给力，请检查网络连接';
        return '登录遇到问题，请稍后重试';
    }
  }

  static LoginErrorAction getAction(ApiException error) {
    switch (error.code) {
      case 'AUTH_SMS_RATE_LIMIT':
        return LoginErrorAction.showCountdown;
      case 'AUTH_ACCOUNT_DISABLED':
        return LoginErrorAction.showContactSupport;
      case 'AUTH_OAUTH_CANCELLED':
        return LoginErrorAction.silent;
      default:
        return LoginErrorAction.showRetry;
    }
  }
}

enum LoginErrorAction {
  showRetry,         // 显示重试按钮
  showCountdown,     // 显示倒计时
  showContactSupport, // 显示联系客服
  silent,            // 静默处理
}
```
