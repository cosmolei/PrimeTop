# 服务端教材课标对齐度分析与内容覆盖率统计服务 - 详细设计

## 1. 模块概述

### 1.1 功能定位

本服务负责分析 PrimeTop 平台中的教育资源（题目、解析、知识点讲解、教材章节内容等）与国家课程标准（课标）之间的对齐程度，计算内容覆盖率，识别课标空白区域，为内容运营团队提供内容建设优先级数据支撑。

### 1.2 核心价值

| 角色 | 价值 |
|------|------|
| 内容运营 | 快速发现未覆盖的课标要求，指导内容生产方向 |
| 教研团队 | 量化评估已有内容与课标的匹配质量 |
| 产品管理 | 基于覆盖率数据制定版本迭代优先级 |
| B 端合作 | 向合作方展示内容体系的课标对齐度 |
| 合规审计 | 证明产品内容符合教育主管部门要求 |

### 1.3 设计原则

1. **课标为主轴**：以国家课程标准为基准，所有内容围绕课标要求进行对齐分析
2. **多版本兼容**：支持不同教材版本（人教版、苏教版、北师大版等）与同一课标的映射
3. **增量更新**：课标或内容变更时，支持增量分析而非全量重算
4. **人机结合**：AI 自动标注 + 人工审核校准，逐步提升对齐准确度

## 2. 核心概念与数据模型

### 2.1 课标知识点树

```text
课标
├── 学段（小学/初中/高中）
│   ├── 学科
│   │   ├── 模块/领域
│   │   │   ├── 主题
│   │   │   │   ├── 核心素养要求
│   │   │   │   ├── 知识点要求
│   │   │   │   └── 能力要求
```

## 4. 核心流程设计

### 4.1 全量覆盖率分析流程

```text
1.创建批次 → 2.加载课标 → 3.加载内容 → 4.对齐分析 → 5.计算覆盖 → 6.缺口检测 → 7.存储结果 → 8.通知完成
```

**详细步骤：**

1. **创建分析批次**：记录分析范围（学段/学科/教材版本）、触发方式
2. **加载课标条目**：根据范围加载对应课标条目，构建课标树
3. **加载内容数据**：从题库、知识库、教材内容等服务批量拉取待分析内容
4. **对齐分析**（核心步骤，详见 4.3）：
   - 第一层：**规则对齐** — 基于知识点ID直接映射
   - 第二层：**向量检索** — 对未映射内容进行向量相似度匹配
   - 第三层：**AI 语义分析** — 对置信度低于阈值的结果调用 LLM
5. **计算覆盖率**：按学段/学科/领域/主题四级维度计算覆盖率
6. **缺口检测**：识别未覆盖条目，评估缺口严重程度，生成建议
7. **存储结果**：持久化对齐记录、覆盖率快照、缺口报告
8. **通知完成**：通过事件总线通知相关服务和管理后台

### 4.2 增量分析流程

```text
内容变更事件 → 事件过滤与去重 → 增量对齐分析 → 更新受影响快照 → 更新缺口报告
```

### 4.3 三层对齐分析流水线

对齐分析采用三层瀑布式过滤策略，优先使用低成本高确定性的方法：

```text
内容条目 (content_type=QUESTION, content="解方程 2x+5=13", kp_ids=[201,305])
        │
        ▼
┌──────────────────────────────────┐
│ 第一层：规则对齐                   │
│ content.kp_ids ∩ standard.kp_ids │
│ 交集非空 → ALIGNED (置信度 0.95+)  │
│ 耗时：<1ms                        │
└──────────────┬───────────────────┘
               │ 未匹配
               ▼
┌──────────────────────────────────┐
│ 第二层：向量检索                   │
│ content_embedding 相似度匹配       │
│ cosine_sim > 0.85 → ALIGNED      │
│ 置信度：0.7-0.95, 耗时：~10ms     │
└──────────────┬───────────────────┘
               │ 未匹配/低置信
               ▼
┌──────────────────────────────────┐
│ 第三层：AI 语义分析                │
│ LLM 判断内容与课标对齐度           │
│ 输出结构化评估 + 质量评分          │
│ 置信度：模型自评, 耗时：~2-5s      │
└──────────────────────────────────┘
```

**性能优化策略：**

| 策略 | 说明 |
|------|------|
| 批量处理 | 每批 50-100 条内容并行分析 |
| 缓存命中 | 已分析且未修改内容直接复用上次结果 |
| 降级跳过 | AI 不可用时仅执行前两层，标记待补充 |
| 增量优先 | 仅分析新增/变更内容 |

## 5. API 接口设计

### 5.1 分析任务管理

#### POST /api/v1/coverage/analysis

触发覆盖率分析任务（异步执行）。

**请求体：**
```json
{
  "standardVersion": "2022版义务教育课程标准",
  "scope": {
    "stageCodes": ["JUNIOR", "SENIOR"],
    "subjectCodes": ["MATH", "PHYSICS"],
    "textbookVersions": ["人教版"]
  },
  "options": {
    "enableAiAnalysis": true,
    "aiConfidenceThreshold": 0.7,
    "includeQualityScore": true,
    "maxConcurrency": 5
  }
}
```

**响应：**
```json
{
  "code": 0,
  "data": {
    "batchId": "BATCH-20260530-001",
    "status": "RUNNING",
    "estimatedDurationMinutes": 45,
    "totalContentCount": 12580,
    "scopeSummary": "初中+高中 / 数学+物理 / 人教版"

}
```

### 6.1 分析流水线编排器

```java
@Service
@Slf4j
public class CoverageAnalysisOrchestrator {

    @Autowired private AlignmentEngine alignmentEngine;
    @Autowired private CoverageCalcEngine calcEngine;
    @Autowired private GapDetector gapDetector;
    @Autowired private AnalysisBatchRepository batchRepo;
    @Autowired private ApplicationEventPublisher eventPublisher;

    /**
     * 执行全量覆盖率分析
     */
    public AnalysisBatch executeFullAnalysis(AnalysisRequest request) {
        // 1. 创建批次
        AnalysisBatch batch = createBatch(request);
        
        try {
            batch.setStatus("RUNNING");
            batch.setStartedAt(LocalDateTime.now());
            batchRepo.save(batch);
            
            // 2. 加载课标条目树
            List<CurriculumStandardItem> standardItems = loadStandardItems(request);
            log.info("加载课标条目 {} 条", standardItems.size());
            
            // 3. 加载待分析内容
            List<ContentItem> contentItems = loadContentItems(request);
            batch.setTotalContentCount(contentItems.size());
            batchRepo.save(batch);
            
            // 4. 执行三层对齐分析
            List<ContentAlignmentRecord> alignments = alignmentEngine.analyze(
                contentItems, standardItems, request.getOptions()
            );
            
            // 5. 计算覆盖率快照
            List<CoverageSnapshot> snapshots = calcEngine.calculate(
                alignments, standardItems, batch.getBatchId()
            );
            
            // 6. 检测缺口
            List<CoverageGapReport> gaps = gapDetector.detect(
                alignments, standardItems, batch.getBatchId()
            );
            
            // 7. 存储结果
            saveResults(alignments, snapshots, gaps);
            
            // 8. 完成批次
            batch.setStatus("COMPLETED");
            batch.setCompletedAt(LocalDateTime.now());
            batchRepo.save(batch);
            
            // 9. 发布完成事件
            eventPublisher.publishEvent(new AnalysisCompletedEvent(batch.getBatchId()));
            
        } catch (Exception e) {
            log.error("分析批次 {} 执行失败", batch.getBatchId(), e);
            batch.setStatus("FAILED");
            batch.setErrorMessage(e.getMessage());
            batchRepo.save(batch);
        }
        
        return batch;
    }
}
```

### 6.2 三层对齐引擎

```java
@Service
@Slf4j
public class AlignmentEngine {

    @Autowired private RuleBasedAligner ruleAligner;
    @Autowired private VectorSearchAligner vectorAligner;
    @Autowired private AiSemanticAligner aiAligner;
    @Autowired private AlignmentCacheService cacheService;

    public List<ContentAlignmentRecord> analyze(
            List<ContentItem> contentItems,
            List<CurriculumStandardItem> standardItems,
            AnalysisOptions options) {
        
        // 构建课标索引
        StandardItemIndex index = buildIndex(standardItems);
        
        List<ContentAlignmentRecord> results = new ArrayList<>();
        List<ContentItem> unmatchedItems = new ArrayList<>();
        
        // === 第一层：规则对齐 ===
        for (ContentItem content : contentItems) {
            // 检查缓存
            ContentAlignmentRecord cached = cacheService.get(content.getFingerprint());
            if (cached != null) {
                results.add(cached);
                continue;
            }
            
            // 规则对齐：基于知识点ID映射
            List<ContentAlignmentRecord> ruleResults =
                ruleAligner.align(content, index);
            
            if (!ruleResults.isEmpty()) {
                results.addAll(ruleResults);
            } else {
                unmatchedItems.add(content);
            }
        }
        log.info("规则对齐完成：命中 {} / 未命中 {}", 
            results.size(), unmatchedItems.size());
        
        // === 第二层：向量检索对齐 ===
        List<ContentItem> stillUnmatched = new ArrayList<>();
        for (ContentItem content : unmatchedItems) {
            List<ContentAlignmentRecord> vectorResults =
                vectorAligner.align(content, index, 0.85);
            
            if (!vectorResults.isEmpty()) {
                results.addAll(vectorResults);
            } else {
                stillUnmatched.add(content);
            }
        }
        log.info("向量检索完成：命中 {} / 未命中 {}",
            unmatchedItems.size() - stillUnmatched.size(), stillUnmatched.size());
        
        // === 第三层：AI 语义分析（可选） ===
        if (options.isEnableAiAnalysis() && !stillUnmatched.isEmpty()) {
            List<ContentAlignmentRecord> aiResults =
                aiAligner.batchAlign(stillUnmatched, index, options);
            results.addAll(aiResults);
            log.info("AI分析完成：处理 {} 条", aiResults.size());
        }
        
        // 更新缓存
        cacheService.batchUpdate(results);
        
        return results;
    }
}
```

### 6.3 覆盖率计算引擎

```java
@Service
public class CoverageCalcEngine {

    public List<CoverageSnapshot> calculate(
            List<ContentAlignmentRecord> alignments,
            List<CurriculumStandardItem> standardItems,
            String batchId) {
        
        // 按课标条目ID分组
        Map<Long, List<ContentAlignmentRecord>> alignmentMap = alignments.stream()
            .collect(Collectors.groupingBy(ContentAlignmentRecord::getStandardItemId));
        
        // 按四个维度分别计算
        List<CoverageSnapshot> snapshots = new ArrayList<>();
        
        // 按学段
        snapshots.addAll(calcByDimension(standardItems, alignmentMap, batchId,
            "STAGE", item -> item.getStageCode()));
        
        // 按学科
        snapshots.addAll(calcByDimension(standardItems, alignmentMap, batchId,
            "SUBJECT", item -> item.getStageCode() + "_" + item.getSubjectCode()));
        
        // 按领域
        snapshots.addAll(calcByDimension(standardItems, alignmentMap, batchId,
            "DOMAIN", item -> item.getSubjectCode() + "_" + item.getDomainName()));
        
        // 按主题
        snapshots.addAll(calcByDimension(standardItems, alignmentMap, batchId,
            "TOPIC", item -> item.getPath()));
        
        return snapshots;
    }
    
    private List<CoverageSnapshot> calcByDimension(
            List<CurriculumStandardItem> items,
            Map<Long, List<ContentAlignmentRecord>> alignmentMap,
            String batchId,
            String dimension,
            Function<CurriculumStandardItem, String> keyExtractor) {
        
        // 按维度分组课标条目
        Map<String, List<CurriculumStandardItem>> grouped = items.stream()
            .filter(i -> "REQUIREMENT".equals(i.getLevel()))
            .collect(Collectors.groupingBy(keyExtractor));
        
        List<CoverageSnapshot> snapshots = new ArrayList<>();
        
        for (Map.Entry<String, List<CurriculumStandardItem>> entry : grouped.entrySet()) {
            int total = entry.getValue().size();
            int covered = 0, partial = 0, uncovered = 0;
            BigDecimal totalQuality = BigDecimal.ZERO;
            BigDecimal totalAlignment = BigDecimal.ZERO;
            int scoredCount = 0;
            
            for (CurriculumStandardItem stdItem : entry.getValue()) {
                List<ContentAlignmentRecord> records = alignmentMap.get(stdItem.getId());
                if (records == null || records.isEmpty()) {
                    uncovered++;
                } else {
                    // 取最高对齐状态
                    String bestStatus = records.stream()
                        .map(ContentAlignmentRecord::getAlignmentStatus)
                        .max(Comparator.comparingInt(this::statusOrder))
                        .orElse("UNCOVERED");
                    
                    switch (bestStatus) {
                        case "ALIGNED": covered++; break;
                        case "PARTIAL": partial++; break;
                        default: uncovered++; break;
                    }
                    
                    // 累计评分
                    for (ContentAlignmentRecord r : records) {
                        if (r.getQualityScore() != null) {
                            totalQuality = totalQuality.add(r.getQualityScore());
                            totalAlignment = totalAlignment.add(r.getAlignmentScore());
                            scoredCount++;
                        }
                    }
                }
            }
            
            CoverageSnapshot snapshot = new CoverageSnapshot();
            snapshot.setBatchId(batchId);
            snapshot.setDimension(dimension);
            snapshot.setDimensionValue(entry.getKey());
            snapshot.setTotalItems(total);
            snapshot.setCoveredItems(covered);
            snapshot.setPartialItems(partial);
            snapshot.setUncoveredItems(uncovered);
            snapshot.setCoverageRate(calcRate(covered, total));
            snapshot.setEffectiveCoverageRate(
                calcRate(covered + (int)(partial * 0.5), total));
            if (scoredCount > 0) {
                snapshot.setAvgQualityScore(totalQuality.divide(
                    BigDecimal.valueOf(scoredCount), 2, RoundingMode.HALF_UP));
                snapshot.setAvgAlignmentScore(totalAlignment.divide(
                    BigDecimal.valueOf(scoredCount), 2, RoundingMode.HALF_UP));
            }
            snapshot.setAnalyzedAt(LocalDateTime.now());
            snapshots.add(snapshot);
        }
        
        return snapshots;
    }
    
    private int statusOrder(String status) {
        switch (status) {
            case "ALIGNED": return 3;
            case "PARTIAL": return 2;
            case "MISALIGNED": return 1;
            default: return 0;
        }
    }
    
    private BigDecimal calcRate(int numerator, int denominator) {
        if (denominator == 0) return BigDecimal.ZERO;
        return BigDecimal.valueOf(numerator * 100.0 / denominator)
            .setScale(2, RoundingMode.HALF_UP);
    }
}
```

### 6.4 缺口检测器

```java
@Service
@Slf4j
public class GapDetector {

    @Autowired private AiGapAnalysisService aiGapService;

    public List<CoverageGapReport> detect(
            List<ContentAlignmentRecord> alignments,
            List<CurriculumStandardItem> standardItems,
            String batchId) {
        
        // 找出所有 REQUIREMENT 级别条目
        List<CurriculumStandardItem> requirements = standardItems.stream()
            .filter(i -> "REQUIREMENT".equals(i.getLevel()))
            .collect(Collectors.toList());
        
        // 按课标条目ID分组对齐记录
        Map<Long, List<ContentAlignmentRecord>> alignmentMap = alignments.stream()
            .collect(Collectors.groupingBy(ContentAlignmentRecord::getStandardItemId));
        
        List<CoverageGapReport> gaps = new ArrayList<>();
        
        for (CurriculumStandardItem req : requirements) {
            List<ContentAlignmentRecord> records = alignmentMap.get(req.getId());
            
            // 完全无内容
            if (records == null || records.isEmpty()) {
                gaps.add(buildGap(batchId, req, "NO_CONTENT", "HIGH",
                    suggestContentTypes(req),
                    calcPriority(req, 0)));
                continue;
            }
            
            // 检查质量不足
            double avgQuality = records.stream()
                .filter(r -> r.getQualityScore() != null)
                .mapToDouble(r -> r.getQualityScore().doubleValue())
                .average().orElse(0);
            
            if (avgQuality < 60) {
                gaps.add(buildGap(batchId, req, "LOW_QUALITY", "MEDIUM",
                    List.of("EXPLANATION"),
                    calcPriority(req, avgQuality)));
            }
            
            // 检查难度不匹配
            boolean hasDifficultyMismatch = records.stream()
                .anyMatch(r -> r.getDimensionScores() != null
                    && r.getDimensionScores().getDifficultyFit() != null
                    && r.getDimensionScores().getDifficultyFit().doubleValue() < 60);
            if (hasDifficultyMismatch) {
                gaps.add(buildGap(batchId, req, "WRONG_DIFFICULTY", "MEDIUM",
                    List.of("QUESTION"),
                    calcPriority(req, 50)));
            }
        }
        
        // AI 增强分析缺口原因（批量，降低调用次数）
        if (!gaps.isEmpty()) {
            aiGapService.enhanceGapAnalysis(gaps, requirements);
        }
        
        log.info("检测到 {} 个覆盖率缺口", gaps.size());
        return gaps;
    }
    
    private int calcPriority(CurriculumStandardItem req, double qualityHint) {
        int priority = 50; // 基础分
        
        // 要求程度越高优先级越高
        switch (req.getRequirementLevel()) {
            case "COMPREHEND": priority += 30; break;
            case "APPLY": priority += 25; break;
            case "MASTER": priority += 20; break;
            case "KNOW": priority += 10; break;
            default: break;
        }
        
        // 质量越低优先级越高
        if (qualityHint < 40) priority += 15;
        else if (qualityHint < 60) priority += 10;
        
        return Math.min(100, priority);
    }
    
    private List<String> suggestContentTypes(CurriculumStandardItem req) {
        switch (req.getRequirementType()) {
            case "KNOWLEDGE": return List.of("EXPLANATION", "QUESTION");
            case "SKILL": return List.of("QUESTION", "PRACTICE_SET");
            case "ABILITY": return List.of("QUESTION", "EXPLANATION", "PRACTICE_SET");
            case "LITERACY": return List.of("EXPLANATION", "PRACTICE_SET");
            default: return List.of("EXPLANATION", "QUESTION");
        }
    }
}
```
