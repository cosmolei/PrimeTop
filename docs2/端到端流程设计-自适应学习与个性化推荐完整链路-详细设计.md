## 3. S1 数据采集与感知

### 3.1 采集事件清单

自适应推荐依赖以下核心事件流：

| 事件类型 | 事件编码 | 触发时机 | 关键字段 |
|---------|---------|---------|---------|
| 答题完成 | `practice.answer_submitted` | 提交单题答案 | `questionId, kpIds[], isCorrect, timeSpentMs, attemptNo` |
| 练习会话完成 | `practice.session_finished` | 完成整个练习 | `sessionId, totalQuestions, correctRate, totalTimeMs` |
| 知识点学习完成 | `sync_class.section_finished` | 完成章节学习 | `chapterId, kpIds[], durationSec, completionRate` |
| 错题收录 | `mistake.added` | 加入错题本 | `mistakeId, questionId, kpIds[], errorType` |
| 错题订正 | `mistake.corrected` | 订正成功 | `mistakeId, attempts, correctNow` |
| 复习完成 | `review.completed` | 完成复习任务 | `reviewTaskId, kpId, quality, recallMs` |
| AI对话交互 | `ai_chat.message_sent` | 发送AI对话消息 | `sessionId, subject, kpIds[], intentType` |
| 推荐曝光 | `recommend.impression` | 推荐卡片展示 | `recommendId, cardType, position, sourcePage` |
| 推荐点击 | `recommend.click` | 用户点击推荐 | `recommendId, cardType, targetPage` |
| 推荐跳过 | `recommend.dismiss` | 用户关闭/跳过 | `recommendId, cardType, dismissReason` |
| 学习时长心跳 | `learning.heartbeat` | 每5分钟 | `durationSec, currentPage, subject` |

## 4. S2 画像构建与评估

### 4.1 画像更新触发策略

| 触发方式 | 条件 | 延迟 | 适用场景 |
|---------|------|------|---------|
| 实时流处理 | 答题完成、复习完成事件 | < 1s | 掌握度增量更新 |
| 准实时聚合 | 累积 5 个事件或 30s 超时 | < 30s | 能力维度评分更新 |
| 定时批量 | 每日凌晨 2:00 | 次日生效 | 全量画像重算、异常修正 |
| 手动触发 | 用户切换年级/教材版本 | 即时 | 画像冷启动 |

### 4.2 掌握度增量更新流程

```
答题事件流入 Kafka
      │
      ▼
Flink 流处理算子
      │
      ├── 1. 提取知识点映射（questionId → kpIds[]）
      │      来源：题库服务本地缓存
      │
      ├── 2. 计算单题贡献增量
      │      ├── 答对：+Δ（根据题目难度、知识点权重加权）
      │      ├── 答错：-Δ（根据错误类型加权）
      │      └── 超时/跳过：-小Δ
      │
      ├── 3. 合并到知识点掌握度
      │      ├── mastery_new = mastery_old + Δ
      │      ├── mastery_new = clamp(mastery_new, 0, 100)
      │      └── 触发稳定性指标更新
      │
      ├── 4. 更新知识状态机
      │      └── NEW → EXPOSED → LEARNING → MASTERED → DECAYING
      │
      └── 5. 写入 Redis（实时值）+ MySQL（持久化）
             └── 发布画像更新事件 → Kafka: `profile-updated`
```

### 4.3 掌握度增量算法

```python
def compute_mastery_delta(
    current_mastery: float,       # 当前掌握度 0-100
    question_difficulty: float,   # 题目难度 0-1
    is_correct: bool,
    time_spent_ms: int,
    attempt_number: int,          # 第几次尝试
    kp_weight: float = 1.0        # 知识点在题目中的权重
) -> float:
    """
    计算单次答题对掌握度的增量贡献
    """
    # 基础增量（难度越高、贡献越大）
    base_delta = 8.0 if is_correct else -5.0
    difficulty_factor = 0.5 + question_difficulty  # 0.5 ~ 1.5
    
    # 时间惩罚（过快可能乱猜，过慢可能不会）
    if is_correct:
        if time_spent_ms < 5000:       # 5秒内答对简单题
            time_factor = 0.7
        elif time_spent_ms > 120000:   # 2分钟以上才答对
            time_factor = 0.8
        else:
            time_factor = 1.0
    else:
        time_factor = 1.0  # 答错不因时间而减罚
    
    # 尝试次数衰减（第N次才答对，贡献递减）
    attempt_factor = 1.0 / (1 + 0.3 * max(0, attempt_number - 1))
    
    # 掌握度边界效应（接近满分时增长缓慢，接近0分时下降缓慢）
    if is_correct:
        # 越接近100，增长越慢（天花板效应）
        boundary_factor = (100 - current_mastery) / 100
    else:
        # 越接近0，下降越慢（地板效应）
        boundary_factor = current_mastery / 100
    
    delta = (base_delta * difficulty_factor * time_factor 
             * attempt_factor * boundary_factor * kp_weight)
    
    return delta
```

### 4.5 冷启动处理

```python
def handle_cold_start(user_id: int, grade: str, subject: str) -> UserProfile:
    """
    新用户冷启动：根据年级和学科生成初始画像
    
    策略：
    1. 使用同年级群体均值作为初始掌握度
    2. 将本学期前3章知识点标记为 EXPOSED（假设已在学校接触）
    3. 后续章节标记为 NEW
    4. 设置 coldStartPhase = True
    5. 5次练习后退出冷启动
    """
    profile = UserProfile(
        user_id=user_id,
        grade_level=grade,
        cold_start_phase=True,
    )
    
    # 获取本学期知识点列表
    kp_list = knowledge_point_service.get_kps_by_grade_semester(grade, subject)
    
    for idx, kp in enumerate(kp_list):
        if idx < 3:  # 前几个章节假设已接触
            state = KnowledgeState(
                status='EXPOSED',
                mastery_level=30.0,   # 低于随机猜答水平
                stability=0.2,
            )
        else:
            state = KnowledgeState(status='NEW')
        profile.knowledge_mastery[kp.id] = state
    
    return profile
```

### 5.2 推荐决策核心流程

```python
def generate_recommendations(
    user_id: int,
    scene: RecommendScene,
    context: RecommendContext,       # 当前页面、学科、章节等上下文
    count: int = 5                   # 推荐卡片数量
) -> list[RecommendCard]:
    """
    推荐决策主流程
    
    步骤：
    1. 获取用户画像
    2. 根据场景确定候选池生成策略
    3. 对候选集打分排序
    4. 多样性与新鲜度调整
    5. 组装推荐卡片
    """
    # Step 1: 获取画像
    profile = profile_service.get_profile(user_id)
    
    # Step 2: 候选池生成（场景相关）
    candidates = generate_candidates(profile, scene, context)
    
    # Step 3: 多目标打分
    scored = score_candidates(candidates, profile, scene)
    
    # Step 4: 排序 + 多样性调整
    ranked = diversify_and_rank(scored, count, diversity_config={
        'max_same_type': 2,        # 同类型卡片最多连续2张
        'max_same_subject': 3,     # 同学科最多3张
        'ensure_review': True,     # 确保包含1张复习卡片（如有到期）
    })
    
    # Step 5: 组装卡片
    cards = []
    for item in ranked[:count]:
        card = assemble_card(item, profile)
        cards.append(card)
    
    # 记录推荐日志
    log_recommendation(user_id, scene, cards)
    
    return cards
```
