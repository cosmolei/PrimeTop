## 3. S1 数据采集与感知

### 3.1 采集事件清单

自适应推荐依赖以下核心事件流：

| 事件类型 | 事件编码 | 触发时机 | 关键字段 |
|---------|---------|---------|---------|
| 答题完成 | `practice.answer_submitted` | 提交单题答案 | `questionId, kpIds[], isCorrect, timeSpentMs, attemptNo` |
| 练习会话完成 | `practice.session_finished` | 完成整个练习 | `sessionId, totalQuestions, correctRate, totalTimeMs` |
| 知识点学习完成 | `sync_class.section_finished` | 完成章节学习 | `chapterId, kpIds[], durationSec, completionRate` |
| 错题收录 | `mistake.added` | 加入错题本 | `mistakeId, questionId, kpIds[], errorType` |
| 错题订正 | `mistake.corrected` | 订正成功 | `mistakeId, attempts, correctNow` |
| 复习完成 | `review.completed` | 完成复习任务 | `reviewTaskId, kpId, quality, recallMs` |
| AI对话交互 | `ai_chat.message_sent` | 发送AI对话消息 | `sessionId, subject, kpIds[], intentType` |
| 推荐曝光 | `recommend.impression` | 推荐卡片展示 | `recommendId, cardType, position, sourcePage` |
| 推荐点击 | `recommend.click` | 用户点击推荐 | `recommendId, cardType, targetPage` |
| 推荐跳过 | `recommend.dismiss` | 用户关闭/跳过 | `recommendId, cardType, dismissReason` |
| 学习时长心跳 | `learning.heartbeat` | 每5分钟 | `durationSec, currentPage, subject` |

## 4. S2 画像构建与评估

### 4.1 画像更新触发策略

| 触发方式 | 条件 | 延迟 | 适用场景 |
|---------|------|------|---------|
| 实时流处理 | 答题完成、复习完成事件 | < 1s | 掌握度增量更新 |
| 准实时聚合 | 累积 5 个事件或 30s 超时 | < 30s | 能力维度评分更新 |
| 定时批量 | 每日凌晨 2:00 | 次日生效 | 全量画像重算、异常修正 |
| 手动触发 | 用户切换年级/教材版本 | 即时 | 画像冷启动 |

### 4.2 掌握度增量更新流程

```
答题事件流入 Kafka
      │
      ▼
Flink 流处理算子
      │
      ├── 1. 提取知识点映射（questionId → kpIds[]）
      │      来源：题库服务本地缓存
      │
      ├── 2. 计算单题贡献增量
      │      ├── 答对：+Δ（根据题目难度、知识点权重加权）
      │      ├── 答错：-Δ（根据错误类型加权）
      │      └── 超时/跳过：-小Δ
      │
      ├── 3. 合并到知识点掌握度
      │      ├── mastery_new = mastery_old + Δ
      │      ├── mastery_new = clamp(mastery_new, 0, 100)
      │      └── 触发稳定性指标更新
      │
      ├── 4. 更新知识状态机
      │      └── NEW → EXPOSED → LEARNING → MASTERED → DECAYING
      │
      └── 5. 写入 Redis（实时值）+ MySQL（持久化）
             └── 发布画像更新事件 → Kafka: `profile-updated`
```

### 4.3 掌握度增量算法

```python
def compute_mastery_delta(
    current_mastery: float,       # 当前掌握度 0-100
    question_difficulty: float,   # 题目难度 0-1
    is_correct: bool,
    time_spent_ms: int,
    attempt_number: int,          # 第几次尝试
    kp_weight: float = 1.0        # 知识点在题目中的权重
) -> float:
    """
    计算单次答题对掌握度的增量贡献
    """
    # 基础增量（难度越高、贡献越大）
    base_delta = 8.0 if is_correct else -5.0
    difficulty_factor = 0.5 + question_difficulty  # 0.5 ~ 1.5
    
    # 时间惩罚（过快可能乱猜，过慢可能不会）
    if is_correct:
        if time_spent_ms < 5000:       # 5秒内答对简单题
            time_factor = 0.7
        elif time_spent_ms > 120000:   # 2分钟以上才答对
            time_factor = 0.8
        else:
            time_factor = 1.0
    else:
        time_factor = 1.0  # 答错不因时间而减罚
    
    # 尝试次数衰减（第N次才答对，贡献递减）
    attempt_factor = 1.0 / (1 + 0.3 * max(0, attempt_number - 1))
    
    # 掌握度边界效应（接近满分时增长缓慢，接近0分时下降缓慢）
    if is_correct:
        # 越接近100，增长越慢（天花板效应）
        boundary_factor = (100 - current_mastery) / 100
    else:
        # 越接近0，下降越慢（地板效应）
        boundary_factor = current_mastery / 100
    
    delta = (base_delta * difficulty_factor * time_factor 
             * attempt_factor * boundary_factor * kp_weight)
    
    return delta
```

### 4.5 冷启动处理

```python
def handle_cold_start(user_id: int, grade: str, subject: str) -> UserProfile:
    """
    新用户冷启动：根据年级和学科生成初始画像
    
    策略：
    1. 使用同年级群体均值作为初始掌握度
    2. 将本学期前3章知识点标记为 EXPOSED（假设已在学校接触）
    3. 后续章节标记为 NEW
    4. 设置 coldStartPhase = True
    5. 5次练习后退出冷启动
    """
    profile = UserProfile(
        user_id=user_id,
        grade_level=grade,
        cold_start_phase=True,
    )
    
    # 获取本学期知识点列表
    kp_list = knowledge_point_service.get_kps_by_grade_semester(grade, subject)
    
    for idx, kp in enumerate(kp_list):
        if idx < 3:  # 前几个章节假设已接触
            state = KnowledgeState(
                status='EXPOSED',
                mastery_level=30.0,   # 低于随机猜答水平
                stability=0.2,
            )
        else:
            state = KnowledgeState(status='NEW')
        profile.knowledge_mastery[kp.id] = state
    
    return profile
```

| 周末/假期推荐 | 周五/假期开始 | 专项学习营 / 综合复习 | 时段策略 | P2 |

### 5.2 推荐决策核心流程

```python
def generate_recommendations(
    user_id: int,
    scene: RecommendScene,
    context: RecommendContext,       # 当前页面、学科、章节等上下文
    count: int = 5                   # 推荐卡片数量
) -> list[RecommendCard]:
    """
    推荐决策主流程
    
    步骤：
    1. 获取用户画像
    2. 根据场景确定候选池生成策略
    3. 对候选集打分排序
    4. 多样性与新鲜度调整
    5. 组装推荐卡片
    """
    # Step 1: 获取画像
    profile = profile_service.get_profile(user_id)
    
    # Step 2: 候选池生成（场景相关）
    candidates = generate_candidates(profile, scene, context)
    
    # Step 3: 多目标打分
    scored = score_candidates(candidates, profile, scene)
    
    # Step 4: 排序 + 多样性调整
    ranked = diversify_and_rank(scored, count, diversity_config={
        'max_same_type': 2,        # 同类型卡片最多连续2张
        'max_same_subject': 3,     # 同学科最多3张
        'ensure_review': True,     # 确保包含1张复习卡片（如有到期）
    })
    
    # Step 5: 组装卡片
    cards = []
    for item in ranked[:count]:
        card = assemble_card(item, profile)
        cards.append(card)
    
    # 记录推荐日志
    log_recommendation(user_id, scene, cards)
    
    return cards
```

### 5.3 候选池生成策略

```python
def generate_candidates(
    profile: UserProfile,
    scene: RecommendScene,
    context: RecommendContext
) -> list[Candidate]:
    """根据场景生成推荐候选集"""
    candidates = []
    
    # 策略 A: 遗忘曲线复习（最高优先级）
    review_kps = get_overdue_review_kps(
        profile.user_id,
        max_count=10
    )
    for kp_state in review_kps:
        candidates.append(Candidate(
            type='review',
            knowledge_point_id=kp_state.knowledge_point_id,
            priority_boost=100,       # 复习优先级加成
            reason='遗忘曲线复习到期',
            metadata={'overdue_days': kp_state.overdue_days}
        ))
    
    # 策略 B: 薄弱知识点突破
    weak_kps = [kp for kp in profile.knowledge_mastery.values()
                if 10 < kp.mastery_level < 50 and kp.status in ('LEARNING', 'EXPOSED')]
    weak_kps.sort(key=lambda x: x.mastery_level)  # 最薄弱优先
    for kp in weak_kps[:5]:
        candidates.append(Candidate(
            type='weakness_practice',
            knowledge_point_id=kp.knowledge_point_id,
            priority_boost=50,
            reason=f'薄弱知识点（掌握度{kp.mastery_level:.0f}）',
        ))
    
    # 策略 C: 学习路径推进（下一个未学习知识点）
    current_chapter = get_current_chapter(profile)
    next_kps = get_next_kps_in_path(current_chapter, profile)
    for kp in next_kps[:3]:
        candidates.append(Candidate(
            type='new_learning',
            knowledge_point_id=kp.id,
            priority_boost=30,
            reason='学习路径下一站',
            metadata={'chapter': kp.chapter_name}
        ))
    
    # 策略 D: 巩固练习（已学习但未掌握）
    learning_kps = [kp for kp in profile.knowledge_mastery.values()
                    if kp.status == 'LEARNING' and kp.mastery_level >= 40]
    for kp in learning_kps[:3]:
        candidates.append(Candidate(
            type='consolidation',
            knowledge_point_id=kp.knowledge_point_id,
            priority_boost=20,
            reason='巩固已学知识点',
        ))
    
    # 策略 E: 错题重练
    recent_mistakes = mistake_service.get_unrevised_mistakes(
        profile.user_id,
        limit=5
    )
    if recent_mistakes:
        candidates.append(Candidate(
            type='mistake_retry',
            priority_boost=40,
            reason=f'有{len(recent_mistakes)}道错题待复习',
            metadata={'count': len(recent_mistakes)}
        ))
    
    # 场景相关策略
    if scene == RecommendScene.AFTER_PRACTICE:
        # 练习后推荐：基于刚才答错的题推送同类题/前置知识点
        last_session = context.last_practice_session
        if last_session and last_session.incorrect_question_ids:
            for qid in last_session.incorrect_question_ids[:3]:
                similar = question_service.get_similar_questions(qid, limit=2)
                for q in similar:
                    candidates.append(Candidate(
                        type='similar_practice',
                        question_id=q.id,
                        priority_boost=60,
                        reason='举一反三：练习后同类题',
                        metadata={'source_question_id': qid}
                    ))
            # 若正确率低于阈值，追加薄弱前置知识点
            if last_session.correct_rate < 0.5 and last_session.kp_ids:
                pre_kps = knowledge_service.get_prerequisite_kps(
                    last_session.kp_ids, limit=3
                )
                for kp in pre_kps:
                    candidates.append(Candidate(
                        type='prerequisite_gap',
                        knowledge_point_id=kp.id,
                        priority_boost=55,
                        reason='前置知识薄弱，建议回溯',
                        metadata={'source_kp_ids': last_session.kp_ids}
                    ))
    
    elif scene == RecommendScene.AFTER_AI_CHAT:
        # AI 辅导后推荐：基于对话意图与涉及知识点
        kp_ids = context.ai_context.get('kp_ids', [])
        intent = context.ai_context.get('intent', 'explain')
        for kp_id in kp_ids[:3]:
            if intent in ('explain', 'example'):
                candidates.append(Candidate(
                    type='kp_practice',
                    knowledge_point_id=kp_id,
                    priority_boost=45,
                    reason='刚学过的知识点趁热练习',
                ))
            elif intent == 'mistake_reason':
                candidates.append(Candidate(
                    type='weakness_practice',
                    knowledge_point_id=kp_id,
                    priority_boost=60,
                    reason='针对刚讨论的易错点练习',
                ))
    
    elif scene == RecommendScene.AFTER_REVIEW:
        # 复习完成后推荐：下一复习点或进阶巩固
        next_due = get_overdue_review_kps(profile.user_id, max_count=3)
        for kp_state in next_due:
            candidates.append(Candidate(
                type='next_review',
                knowledge_point_id=kp_state.knowledge_point_id,
                priority_boost=90,
                reason='下一个到期复习点',
                metadata={'due_at': kp_state.next_review_at}
            ))
    
    elif scene == RecommendScene.WEAKNESS_BREAKTHROUGH:
        # 薄弱点突破：批量生成专题训练
        weak_kps = [kp for kp in profile.knowledge_mastery.values()
                    if 10 < kp.mastery_level < 50]
        for kp in weak_kps[:5]:
            candidates.append(Candidate(
                type='breakthrough',
                knowledge_point_id=kp.knowledge_point_id,
                priority_boost=80,
                reason='薄弱点专项突破',
            ))
    
    elif scene == RecommendScene.WEEKEND or scene == RecommendScene.HOLIDAY:
        # 周末/假期：综合复习 + 专题学习营
        candidates.append(Candidate(
            type='weekly_review',
            priority_boost=30,
            reason='本周学习内容回顾',
        ))
        hot_topics = topic_service.get_hot_topics(profile.grade_level, limit=2)
        for topic in hot_topics:
            candidates.append(Candidate(
                type='topic_camp',
                topic_id=topic.id,
                priority_boost=35,
                reason=f'推荐专题：{topic.name}',
            ))
    
    elif scene == RecommendScene.GRADE_SWITCH:
        # 学段/年级切换：诊断测评 + 新教材首章
        candidates.append(Candidate(
            type='diagnostic_test',
            priority_boost=100,
            reason='新学段诊断测评',
        ))
        first_chapter = chapter_service.get_first_chapter(
            profile.grade_level, profile.textbook_version, context.subject
        )
        if first_chapter:
            candidates.append(Candidate(
                type='new_chapter_preview',
                chapter_id=first_chapter.id,
                priority_boost=40,
                reason='新学期第一章预习',
            ))
    
    return candidates


def score_candidates(
    candidates: list[Candidate],
    profile: UserProfile,
    scene: RecommendScene
) -> list[ScoredCandidate]:
    """
    多目标综合打分
    
    目标维度：
    - learning_value: 学习价值（薄弱点、到期复习价值高）
    - difficulty_fit: 难度匹配（ZPD 区间内最高）
    - completion_prob: 预计完成概率
    - freshness: 新鲜度（未曝光过加分）
    - diversity: 类型多样性（作为后处理）
    """
    scored = []
    for c in candidates:
        base_score = 0.0
        
        # 学习价值
        if c.type == 'review':
            lv = 95
        elif c.type in ('weakness_practice', 'breakthrough', 'prerequisite_gap'):
            lv = 80
        elif c.type in ('mistake_retry', 'similar_practice'):
            lv = 70
        elif c.type in ('new_learning', 'kp_practice'):
            lv = 55
        else:
            lv = 40
        lv += c.priority_boost * 0.2
        
        # 难度匹配：使用能力值与题目难度的 ELO 式期望
        diff = get_candidate_difficulty(c) or 0.5
        ability = profile.ability_dimensions.get(get_subject_ability_key(c), 50)
        expected = 1 / (1 + 10 ** ((diff * 100 - ability) / 400))
        difficulty_fit = 1 - abs(expected - 0.75)  # 最佳完成概率约 75%
        
        # 完成概率（历史同类型完成率 + 时长匹配）
        type_completion = profile.recommend_stats.get(
            f'{c.type}_completion_rate', 0.5
        )
        duration_ok = 1.0 if estimate_duration(c) <= profile.preferences.avg_session_duration else 0.7
        completion_prob = type_completion * duration_ok
        
        # 新鲜度：同候选近 7 天曝光次数衰减
        impression_count = get_impression_count_7d(profile.user_id, c)
        freshness = 1.0 / (1 + 0.3 * impression_count)
        
        # 场景权重
        scene_weight = get_scene_weight(scene, c.type)
        
        total = (
            lv * 0.45 +
            difficulty_fit * 100 * 0.25 +
            completion_prob * 100 * 0.15 +
            freshness * 100 * 0.10 +
            scene_weight * 100 * 0.05
        )
        
        scored.append(ScoredCandidate(
            candidate=c,
            learning_value=lv,
            difficulty_fit=difficulty_fit,
            completion_prob=completion_prob,
            freshness=freshness,
            score=round(total, 2),
            reason=c.reason,
        ))
    
    return scored


def diversify_and_rank(
    scored: list[ScoredCandidate],
    count: int,
    diversity_config: dict
) -> list[ScoredCandidate]:
    """
    排序 + 多样性重排（MMR 简化版）
    """
    selected = []
    remaining = sorted(scored, key=lambda x: x.score, reverse=True)
    
    type_counts = {}
    subject_counts = {}
    
    while len(selected) < count and remaining:
        best = None
        best_mmr = -1.0
        
        for item in remaining:
            # 类型/学科频控
            if type_counts.get(item.candidate.type, 0) >= diversity_config.get('max_same_type', 2):
                continue
            if subject_counts.get(get_subject(item.candidate), 0) >= diversity_config.get('max_same_subject', 3):
                continue
            
            # 与已选集合的相似度惩罚
            max_sim = 0.0
            for sel in selected:
                sim = candidate_similarity(item.candidate, sel.candidate)
                if sim > max_sim:
                    max_sim = sim
            
            mmr = item.score * 0.7 - max_sim * 30.0
            if mmr > best_mmr:
                best_mmr = mmr
                best = item
        
        if not best:
            break
        
        selected.append(best)
        remaining.remove(best)
        type_counts[best.candidate.type] = type_counts.get(best.candidate.type, 0) + 1
        subject_counts[get_subject(best.candidate)] = subject_counts.get(get_subject(best.candidate), 0) + 1
    
    return selected
```

### 5.6 防信息茧房与探索机制

为避免推荐过度集中，引入 **ε-探索 + 主题轮盘** 策略：

```python
EXPLORATION_CONFIG = {
    'epsilon': 0.15,           # 15% 推荐位用于探索
    'exploration_sources': [
        'random_review',       # 随机已学知识点
        'cross_subject',       # 跨学科轻量内容
        'peer_popular',        # 同年级热门知识点
        'preview_next',        # 下一章节预览
    ],

}

def inject_exploration(cards: list[RecommendCard], profile: UserProfile) -> list[RecommendCard]:
    """在指定位置插入探索卡片，避免干扰最高优先级复习卡片"""
    if len(cards) < 3:
        return cards
    
    # 前 2 张固定保留（通常为到期复习/薄弱点）
    slots = list(range(2, len(cards)))
    random.shuffle(slots)
    
    inserted = 0
    for slot in slots:
        if inserted >= EXPLORATION_CONFIG['min_exploration_per_day']:
            break
        if random.random() < EXPLORATION_CONFIG['epsilon']:
            explore_card = generate_explore_card(profile)
            cards.insert(slot, explore_card)
            inserted += 1
    
    return cards
```

```python
ATTRIBUTION_CONFIG = {
    'click_window_hours': 1,      # 点击后 1h 内完成算推荐效果
    'impression_window_hours': 24,  # 曝光后 24h 内完成算弱归因

}

def attribute_completion(recommend_id: str, user_id: int, event_time: datetime) -> float:
    """返回归因权重，0 表示不归因"""
    log = recommend_log_service.get_latest_interaction(recommend_id, user_id)
    if not log:
        return 0.0
    
    if log.interaction_type == 'click':
        if (event_time - log.created_at).total_seconds() <= ATTRIBUTION_CONFIG['click_window_hours'] * 3600:
            return ATTRIBUTION_CONFIG['credit_click']
    elif log.interaction_type == 'impression':
        if (event_time - log.created_at).total_seconds() <= ATTRIBUTION_CONFIG['impression_window_hours'] * 3600:
            return ATTRIBUTION_CONFIG['credit_impression']
    
    return 0.0
```

## 11. 幂等与并发控制

### 11.1 幂等设计

| 场景 | 幂等键 | 存储 | 过期 |
|------|--------|------|------|
| 推荐请求 | `X-Idempotency-Key` | Redis String | 5min |
| 推荐反馈上报 | `(recommendId, cardId, eventType, userId)` | MySQL UK | 持久 |
| 画像更新 | `(userId, eventId)` | `event_processed` 表 UK | 90天 |
| 缓存失效广播 | `(userId, version)` | Redis Stream | 24h |

```python
# 推荐请求幂等：相同 key 返回相同 recommend_id 与缓存结果
def get_or_create_recommendation(request, idempotency_key):
    cached = redis.get(f"recommend:{idempotency_key}")
    if cached:
        return cached
    
    result = compute_recommendation(request)
    redis.setex(f"recommend:{idempotency_key}", 300, result)
    return result
```

### 11.2 并发控制

- 同一用户并发推荐请求：使用 Redis SETNX `recommend:lock:{user_id}`，TTL=3s，失败则返回缓存或排队。
- 画像更新并发：通过 `profileVersion` 乐观锁，更新失败时重试最多 3 次。
- 推荐日志写入：使用 `recommend_id` 唯一键，重复写入幂等返回成功。

## 13. 错误处理与降级策略

### 13.1 错误码设计

| 错误码 | 场景 | HTTP | 客户端处理 |
|--------|------|------|-----------|
| 0 | 成功 | 200 | - |
| 57001 | 推荐服务内部错误 | 500 | 展示默认首页 |
| 57002 | 画像服务不可用 | 503 | 使用冷启动模板 |
| 57003 | 题库服务超时 | 503 | 减少练习类卡片，增加复习/错题卡片 |
| 57004 | 学情分析超时 | 503 | 使用缓存画像 |
| 57005 | 推荐结果为空 | 200 | 展示「今日无推荐」引导 |
| 57006 | 频繁刷新限流 | 429 | 提示稍后再试 |
| 57007 | 探索题库失败 | 200 | 不插入探索卡片 |

### 13.2 降级矩阵

| 故障点 | 降级行为 | 红线 |
|--------|---------|------|
| ALP 引擎完全不可用 | 返回默认模板：每日复习+继续学习+错题入口 | 首页不白屏 |
| Redis 不可用 | 直连 MySQL 读取画像，延迟增加 | 必须可返回结果 |
| 题库服务超时 | 提高复习/错题/继续学习卡片比例 | 不返回错误页 |
| 画像服务超时 | 使用客户端本地缓存或群体均值模板 | 不阻塞推荐 |
| 学情分析堆积 | 使用 30min 前画像快照 | 不实时重算 |
| A/B 平台不可用 | 全量走 control 组 | 实验不中断 |
| 事件总线不可用 | 推荐结果不落 Outbox，本地日志兜底 | 核心推荐可用 |

## 15. 合规与安全

### 15.1 未成年人保护

- 推荐内容需先经过适龄性过滤，不推送超纲内容。
- 每日推荐任务总量受防沉迷时长限制，不得超过剩余可用时长。
- 21:00 后（学段配置）不推送主动学习提醒 Push。
- 探索卡片中禁止出现营销、社交裂变内容。

### 15.2 数据隐私

- 推荐日志 90 天后脱敏归档，180 天自动清理原始 payload。
- 用户画像不用于站外广告定向。
- 教师端查看班级画像时，个人明细需 k-匿名聚合（班级 ≥ 10 人）。

### 15.3 公平性与透明度

- 推荐理由需向学生展示（如「你上周做错了这类型题」）。
- A/B 实验需避开中高考前 30 天等敏感时段。
- 算法重大调整需留痕，支持回滚到上一版本。
