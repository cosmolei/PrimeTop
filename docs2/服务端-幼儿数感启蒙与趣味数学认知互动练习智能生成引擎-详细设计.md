# 服务端-幼儿数感启蒙与趣味数学认知互动练习智能生成引擎-详细设计

## 1. 概述

### 1.1 模块定位

本引擎是 PrimeTop 幼儿启蒙模块中**数学认知领域**的核心服务端能力，面向 3-6 岁学龄前儿童（K1/K2/K3 三个阶段），提供数感建立、数量认知、简单运算概念和空间逻辑思维的游戏化互动练习智能生成与编排能力。

与已有模块的边界划分：

| 模块 | 适用对象 | 核心能力 | 与本引擎关系 |
| --- | --- | --- | --- |
| `基础计算能力诊断与口算速算自适应训练引擎` | 小学及以上 | 口算、速算、计算准确率与速度训练 | **下游衔接**：本引擎建立数感基础后，由该引擎接力正式算术训练 |
| `幼儿启蒙-详细设计` | 3-6 岁全科 | 数字认知、基础表达、简单常识的总体框架 | **本引擎是其"数字认知"分类的深度细化** |
| `拼音识字启蒙-详细设计` | 3-7 岁语言 | 拼音、识字、朗读 | **并行模块**，共享会话管理和家长控制基础设施 |
| `服务端-教育游戏化学习关卡编排与知识点闯关挑战引擎` | 全学段 | 通用游戏化关卡编排 | **本引擎聚焦幼儿数学特有的游戏化模式**，复用其通用框架能力 |

### 1.2 设计目标

1. **数感建立**：帮助幼儿建立"数"与"量"的直觉关联，理解数字代表的实际含义
2. **个性化练习生成**：根据幼儿当前认知水平和学习历史，动态生成难度适宜的互动练习
3. **游戏化体验**：所有练习均以游戏化形式呈现，确保低龄儿童的参与度和持续性
4. **认知发展追踪**：持续追踪幼儿数学认知能力发展轨迹，为家长提供科学养育建议
5. **安全适龄**：所有内容自动适配幼儿认知特点，零文本依赖、全语音引导、大色彩元素

### 1.3 核心能力概览

```
幼儿数感启蒙引擎
├── 数感认知能力链
```

#### 4.2.1 点数物品模板（counting_objects）

**实例化算法**：
```python
def instantiate_counting_objects(template, user_profile, theme="animal"):
    """
    根据用户能力动态生成点数练习
    """
    # 1. 确定目标数量
    difficulty = user_profile.current_difficulty
    number_range = calculate_range(difficulty, user_profile.stage)
    target_count = random.randint(number_range['min'], number_range['max'])
    
    # 2. 选择主题素材
    assets = get_theme_assets(
        theme=theme,
        count=target_count,
        stage=user_profile.stage
    )
    
    # 3. 生成干扰选项
    distractors = generate_distractors(
        correct=target_count,
        strategy=template['config']['distractor_strategy'],
        count=template['config']['options_count'] - 1,
        difficulty=difficulty
    )
    options = shuffle([target_count] + distractors)
    
    # 4. 生成音频引导
    audio_guide = generate_audio_guide(
        template['audio_template'],
        context={'target': target_count, 'theme': theme}
    )
    
    return {
        "question_id": generate_uuid(),
        "type": "counting_objects",
        "prompt": {
          "instruction_audio": audio_guide['instruction'],
          "instruction_text": f"数一数，这里有几个{assets[0]['display_name']}？",
          "scene": {
            "layout": "grid",
            "items": [{"asset": a, "position": pos} for a, pos in zip(assets, grid_positions)]
          }
        },
        "options": [
          {"value": opt, "display": str(opt), "audio": number_audio(opt)}
          for opt in options
        ],
        "correct_answer": target_count,
        "metadata": {
          "dimension": "counting",
          "sub_skill": "rational_counting",
          "difficulty": difficulty,
          "estimated_duration": 30 + target_count * 2
        }
    }
```

**干扰项生成策略**：
```python
def generate_distractors(correct, strategy, count, difficulty):
    """根据策略生成干扰选项"""
    if strategy == "adjacent_numbers":
        # 相邻数 ±1 ±2
        candidates = [correct - 2, correct - 1, correct + 1, correct + 2]
        candidates = [c for c in candidates if c > 0]
    
    elif strategy == "same_digit":
        # 含相同数字位（如 13 vs 31）
        digits = list(str(correct))
        permutations = list(set(
            int(''.join(p)) for p in itertools.permutations(digits)
            if int(''.join(p)) != correct and int(''.join(p)) > 0
        ))
        candidates = permutations[:count]
    
    elif strategy == "visual_confusion":
        # 视觉相似（6 vs 9, 12 vs 21）
        visual_pairs = {6: [9], 9: [6], 12: [21], 21: [12], 13: [31], 31: [13]}
        candidates = visual_pairs.get(correct, [correct - 1, correct + 1])
    
    else:
        # 随机策略，确保范围合理
        offset_range = max(2, difficulty)
        candidates = [
            correct + random.choice([-1, 1]) * random.randint(1, offset_range)
            for _ in range(count + 2)
        ]
    
    # 去重、过滤、截取
    candidates = list(set(candidates))
    candidates = [c for c in candidates if c > 0 and c != correct]
    random.shuffle(candidates)
    return candidates[:count]
```

#### 4.2.2 数字配对模板（number_matching）

**功能**：将数字符号与对应数量的实物图片进行配对连线

**模板配置**：
```json
{
  "template_code": "number_matching_basic",
  "config": {
    "pair_count": 4,
    "number_range": {"min": 1, "max": 20},
    "left_side": "number",
    "right_side": "quantity_image",
    "interaction": "draw_line",
    "shuffle": true
  }
}
```

**实例化算法**：
```python
def instantiate_number_matching(template, user_profile, theme="fruit"):
    difficulty = user_profile.current_difficulty
    number_range = calculate_range(difficulty, user_profile.stage)
    
    pair_count = min(template['config']['pair_count'], 5)  # 最多 5 对
    
    # 生成不重复的目标数字
    target_numbers = random.sample(
        range(number_range['min'], number_range['max'] + 1),
        pair_count
    )
    
    # 为每个数字选择素材
    pairs = []
    for num in target_numbers:
        assets = get_theme_assets(theme=theme, count=num, stage=user_profile.stage)
        pairs.append({
            "number": num,
            "quantity_asset": assets[0] if assets else None,
            "quantity_display": {
              "type": "image_group",
              "asset_url": assets[0]['file_url'] if assets else None,
              "count": num
            }
        })
    
    # 分别打乱左右两侧顺序
    left_items = shuffle_copy([{"value": p["number"], "display": str(p["number"])} for p in pairs])
    right_items = shuffle_copy([
        {"value": p["number"], "display": p["quantity_display"]}
        for p in pairs
    ])
    
    return {
        "question_id": generate_uuid(),
        "type": "number_matching",
        "prompt": {
            "instruction_audio": "audio/match_number_to_count.mp3",
            "instruction_text": "把数字和对应数量的图片连起来",
            "left_panel": left_items,
            "right_panel": right_items
        },
        "correct_answer": [[p["number"], p["number"]] for p in pairs],
        "metadata": {
```

## 5. 智能编排与自适应难度引擎

### 5.1 练习选择算法

引擎使用**多目标加权选择策略**，在每次需要生成下一道练习时综合考量：

```python
class PracticeSelector:
    """
    多目标加权练习选择器
    """
    
    def __init__(self, user_profile, session_config):
        self.profile = user_profile
        self.session = session_config
        # 记录本次会话中已练习的维度，确保多样性
        self.dimension_history = []
        self.recent_templates = []
    
    def select_next(self) -> dict:
        """选择下一道练习"""
        
        # 1. 确定目标能力维度
        target_dimension = self._select_dimension()
        
        # 2. 确定子能力
        target_subskill = self._select_subskill(target_dimension)
        
        # 3. 确定难度
        difficulty = self._calculate_difficulty(target_dimension)
        
        # 4. 匹配模板
        candidates = self._find_templates(
            dimension=target_dimension,
            sub_skill=target_subskill,
            stage=self.profile.stage,
            difficulty=difficulty
        )
        
        # 5. 过滤已使用的模板（避免连续重复）
        candidates = [t for t in candidates if t['template_code'] not in self.recent_templates[-3:]]
        
        if not candidates:
            candidates = self._find_templates(
                dimension=target_dimension,
                sub_skill=target_subskill,
                stage=self.profile.stage
            )
        
        # 6. 加权选择
        selected = self._weighted_select(candidates)
        
        # 7. 记录历史
        self.dimension_history.append(target_dimension)
        self.recent_templates.append(selected['template_code'])
        
        return selected
    
    def _select_dimension(self) -> str:
        """
        选择下一个练习维度
        策略：弱项优先 + 多样性保障 + 偶尔强化优势项
        """
        dimensions = ['counting', 'number_recognition', 'comparison',
                      'operation_concept', 'space_shape', 'pattern_logic']
        
        scores = {
            'counting': getattr(self.profile, 'counting_score'),
            'number_recognition': getattr(self.profile, 'number_recognition_score'),
            'comparison': getattr(self.profile, 'comparison_score'),
            'operation_concept': getattr(self.profile, 'operation_concept_score'),
            'space_shape': getattr(self.profile, 'space_shape_score'),
            'pattern_logic': getattr(self.profile, 'pattern_logic_score'),
        }
        
        # 计算权重：分数越低权重越高（弱项优先）
        weights = {}
        for dim in dimensions:
            score = scores[dim]
            # 基础权重：弱项权重高
            base_weight = (1.0 - score) * 10
            
            # 多样性加成：本会话未练习过的维度加权
            recent_count = self.dimension_history[-5:].count(dim)
            diversity_bonus = max(0, 3 - recent_count) * 2
            
            # 掌握度<0.1 的维度额外加权（冷启动）
            if score < 0.1:
                base_weight += 5
            
            weights[dim] = base_weight + diversity_bonus
        
        # 加权随机选择
        return weighted_random_choice(dimensions, weights)
    
    def _select_subskill(self, dimension: str) -> str:
        """选择子能力"""
        subskills_map = {
            'counting': ['rote_counting', 'rational_counting', 'skip_counting'],
            'number_recognition': ['symbol_recognition', 'writing', 'number_quantity_mapping'],
            'comparison': ['quantity_comparison', 'size_comparison', 'seriation'],
            'operation_concept': ['decomposition', 'addition_concept', 'subtraction_concept'],
            'space_shape': ['shape_recognition', 'spatial_orientation', 'mental_rotation'],
            'pattern_logic': ['classification', 'seriation', 'pattern_recognition'],
        }
        
        subskills = subskills_map.get(dimension, ['general'])
        
        # 获取子能力掌握度
        subskill_scores = get_subskill_scores(self.profile.user_id, dimension)
        
        # 优先选择掌握度最低的子能力
        if subskill_scores:
            min_score = min(subskill_scores.values())
            # 如果有掌握度低于 0.3 的，优先选
            weak = [s for s in subskills if subskill_scores.get(s, 0) < 0.3]
            if weak:
                return random.choice(weak)
        
        return random.choice(subskills)
    
    def _calculate_difficulty(self, dimension: str) -> int:
        """
        自适应难度计算
        基于：当前维度掌握度 + 最近 5 次正确率 + 难度调节窗口
        """
        dimension_score = getattr(self.profile, f'{dimension}_score')
        
        # 基础难度：根据掌握度映射
        if dimension_score < 0.2:
            base_difficulty = 1
        elif dimension_score < 0.4:
            base_difficulty = 2
        elif dimension_score < 0.6:
            base_difficulty = 4
        elif dimension_score < 0.8:
            base_difficulty = 6
        elif dimension_score < 0.95:
            base_difficulty = 8
        else:
            base_difficulty = 10
        
        # 根据最近表现微调
        recent_results = get_recent_results(self.profile.user_id, dimension, count=5)
        if recent_results:
            accuracy = sum(recent_results) / len(recent_results)
            if accuracy >= 0.8:
                base_difficulty = min(10, base_difficulty + 1)
            elif accuracy <= 0.3:
                base_difficulty = max(1, base_difficulty - 1)
        
        return base_difficulty
    
    def _weighted_select(self, candidates: list) -> dict:
        """从候选模板中加权选择"""
        weights = []
        for t in candidates:
            # 新鲜度：优先选择近期未使用的
            freshness = 1.0 / (1 + get_recent_usage_count(t['template_code'], hours=24))
            # 类型多样性：优先不同练习类型
            type_diversity = 1.0 if t['practice_type'] not in self._recent_types() else 0.3
            weights.append(freshness * type_diversity)
        
        return weighted_random_choice(candidates, weights)
    
    def _recent_types(self) -> list:
        """获取最近使用的练习类型"""
        return [t.get('practice_type') for t in self.recent_templates[-3:]]
```

### 5.2 难度自适应调节器

```python
class DifficultyAdjuster:
    """
    实时难度调节器
    监控连续答题表现，动态调整难度等级
    """
    
    # 调节规则
    RULES = {
        'consecutive_correct_3': {'action': 'increase', 'delta': 1},
        'consecutive_correct_5': {'action': 'increase', 'delta': 2},
        'consecutive_wrong_2': {'action': 'decrease', 'delta': 1},
        'consecutive_wrong_3': {'action': 'decrease', 'delta': 2},
        'slow_correct_3x': {'action': 'maintain', 'note': 'speed_practice_needed'},
    }
    
    @staticmethod
    def adjust(current_difficulty: int, recent_results: list, recent_durations: list) -> int:
        """
        根据最近表现调整难度
        
        Args:
            current_difficulty: 当前难度 1-10
            recent_results: 最近答题结果 [True, False, True, ...]
            recent_durations: 最近答题耗时 [ms, ms, ...]
        
        Returns:
            调整后的难度等级
        """
        new_difficulty = current_difficulty
        consecutive_correct = 0
        consecutive_wrong = 0
        
        # 从最近一次往前数连续
        for result in reversed(recent_results[-10:]):
            if result:
                if consecutive_wrong == 0:
                    consecutive_correct += 1
                else:
                    break
            else:
                if consecutive_correct == 0:
                    consecutive_wrong += 1
                else:
                    break
        
        # 应用规则
        if consecutive_correct >= 5:
            new_difficulty = min(10, current_difficulty + 2)
        elif consecutive_correct >= 3:
            new_difficulty = min(10, current_difficulty + 1)
        elif consecutive_wrong >= 3:
            new_difficulty = max(1, current_difficulty - 2)
        elif consecutive_wrong >= 2:
            new_difficulty = max(1, current_difficulty - 1)
        
        # 检查答题速度异常（太慢但正确 → 可能难度刚好但需提速练习）
        if len(recent_durations) >= 3 and all(
            r and d > 30000 for r, d in zip(recent_results[-3:], recent_durations[-3:])
        ):
            # 连续 3 次正确但都很慢 → 不升难度，加提速提示
            new_difficulty = current_difficulty  # 保持不变
        
        return new_difficulty
```

```python
class MathSessionOrchestrator:
    """
    数学学习会话编排器
    """
    
    async def create_session(self, user_id: str, mode: str, target_dimension: str = None) -> dict:
        """创建学习会话"""
        
        # 1. 加载用户画像
        profile = await self.load_profile(user_id)
        
        # 2. 确定会话配置
        session_config = self._build_session_config(profile, mode, target_dimension)
        
        # 3. 预生成练习池（减少运行时延迟）
        selector = PracticeSelector(profile, session_config)
        item_pool = []
        for i in range(session_config['target_count'] + 2):  # 多生成 2 道备用
            template = selector.select_next()
            theme = self._select_theme(profile)
            question = await self._instantiate_template(template, profile, theme)
            item_pool.append(question)
        
        # 4. 创建会话记录
        session = await self.create_session_record(
            user_id=user_id,
            mode=mode,
            config=session_config,
            item_pool=item_pool,
            target_dimension=target_dimension
        )
        
        # 5. 缓存到 Redis
        await self.cache_session(session)
        
        return {
            "session_id": session['id'],
            "first_item": item_pool[0],
            "total_items": session_config['target_count'],
            "difficulty": profile.current_difficulty,
            "theme": session_config.get('theme'),
            "mode": mode
        }
    
    def _build_session_config(self, profile, mode, target_dimension):
        """构建会话配置"""
        config = {
            'target_count': self._get_target_count(profile.stage, mode),
            'difficulty_start': profile.current_difficulty,
            'max_duration_min': self._get_max_duration(profile.stage),
            'encourage_frequency': 2,  # 每 2 题给一次鼓励
            'celebration_interval': 5,  # 每 5 题一次庆祝动画
        }
        
        if target_dimension:
            config['focus_dimension'] = target_dimension
            config['target_count'] = min(config['target_count'], 6)
        else:
            config['mixed_mode'] = True
        
        # 亲子模式调整
        if mode == 'parent':
            config['parent_interaction'] = True
            config['encourage_frequency'] = 1  # 每题都鼓励
        
        return config
    
    def _get_target_count(self, stage: str, mode: str) -> int:
        """根据阶段和模式确定练习数量"""
        base = {'K1': 5, 'K2': 8, 'K3': 10}.get(stage, 5)
        if mode == 'parent':
            base = max(3, base - 2)  # 亲子模式题数减半
        return base
    
    def _get_max_duration(self, stage: str) -> int:
        """最大时长（分钟）"""
        return {'K1': 5, 'K2': 8, 'K3': 10}.get(stage, 5)
    
    async def submit_answer(self, session_id: str, question_id: str, answer: dict) -> dict:
        """提交答案"""
        session = await self.load_session(session_id)
        question = await self.find_question(session, question_id)
        
        # 判定正确性
        is_correct = self._evaluate_answer(question, answer)
        
        # 记录
        await self.log_practice(session['user_id'], session_id, question, answer, is_correct)
        
        # 更新会话进度
        session = await self.update_session_progress(session_id, question_id, is_correct)
        
        # 更新能力画像
        profile = await self.update_ability_profile(
            session['user_id'],
            dimension=question['metadata']['dimension'],
            sub_skill=question['metadata']['sub_skill'],
            is_correct=is_correct,
            difficulty=question['metadata']['difficulty']
        )
        
        # 检查是否完成
        if session['completed_count'] >= session['target_count']:
            return await self._finish_session(session)
        
        # 返回下一题
        next_item = await self.get_next_item(session)
        
        # 更新推荐
        difficulty = DifficultyAdjuster.adjust(
            profile.current_difficulty,
            await self.get_recent_results(session['user_id'], count=5),
            await self.get_recent_durations(session['user_id'], count=5)
        )
        if difficulty != profile.current_difficulty:
            await self.update_difficulty(session['user_id'], difficulty)
        
        return {
            "feedback": self._generate_feedback(is_correct, profile),
            "stars": self._calculate_stars(is_correct, question),
            "next_item": next_item,
            "progress": {
                "completed": session['completed_count'],
                "total": session['target_count'],
                "correct_rate": session['correct_count'] / max(1, session['completed_count'])
            }
        }
```

```python
def update_ability_score(current_score: float, question_difficulty: int,

        current_score: 当前能力值 (0.00-1.00)
        question_difficulty: 题目难度 (1-10)
        is_correct: 是否答对
        attempt_count: 尝试次数
    
    Returns:
        更新后的能力值
    """
    # 将难度映射到期望概率
    difficulty_normalized = question_difficulty / 10.0  # 0.1-1.0
    ability_normalized = current_score  # 0.0-1.0
    
    # 期望答对概率（ logistic 函数）
    expected = 1.0 / (1.0 + math.exp(-(ability_normalized - difficulty_normalized) * 4))
    actual = 1.0 if is_correct else 0.0
    
    # K 因子：新手变化更快，熟练后变化慢
    K = 0.08 if current_score < 0.3 else 0.05 if current_score < 0.7 else 0.03
    
    # 尝试次数修正：多次尝试才答对，更新幅度减小
    attempt_factor = 1.0 / attempt_count if attempt_count > 1 else 1.0
    
    # 计算 delta
    delta = K * (actual - expected) * attempt_factor
    
    new_score = current_score + delta
    
    # 边界保护
    new_score = max(0.0, min(1.0, new_score))
    
    # 舍入到 2 位小数
    return round(new_score, 2)
```

```python
def calculate_overall_score(profile) -> float:
    """
    计算数学认知综合能力值
    采用加权平均，权重随阶段变化
    """
    stage_weights = {
        'K1': {
            'counting': 0.30, 'number_recognition': 0.20,
            'comparison': 0.15, 'operation_concept': 0.10,
            'space_shape': 0.15, 'pattern_logic': 0.10
        },
        'K2': {
            'counting': 0.20, 'number_recognition': 0.20,
            'comparison': 0.15, 'operation_concept': 0.20,
            'space_shape': 0.15, 'pattern_logic': 0.10
        },
        'K3': {
            'counting': 0.15, 'number_recognition': 0.15,
            'comparison': 0.15, 'operation_concept': 0.25,
            'space_shape': 0.10, 'pattern_logic': 0.20
        }
    }
    
    weights = stage_weights.get(profile.stage, stage_weights['K1'])
    
    scores = {
        'counting': profile.counting_score,
        'number_recognition': profile.number_recognition_score,
        'comparison': profile.comparison_score,
        'operation_concept': profile.operation_concept_score,
        'space_shape': profile.space_shape_score,
        'pattern_logic': profile.pattern_logic_score,
    }
    
    overall = sum(scores[dim] * weights[dim] for dim in scores)
    return round(overall, 2)
```

## 8. 答案评估与判定

### 8.1 多题型统一判定引擎

```python
class AnswerEvaluator:
    """
    多题型答案评估器
    """
    
    def evaluate(self, question: dict, user_answer: dict) -> dict:
        """统一入口"""
        question_type = question['type']
        
        evaluators = {
            'counting_objects': self._eval_counting,
            'number_matching': self._eval_matching,
            'quantity_comparison': self._eval_comparison,
            'pattern_complete': self._eval_pattern,
            'decomposition_decompose': self._eval_decomposition,
            'decomposition_compose': self._eval_decomposition,
            'number_tracing': self._eval_tracing,
            'shape_sorting': self._eval_shape_sort,
            'find_missing': self._eval_find_missing,
        }
        
        evaluator = evaluators.get(question_type, self._eval_default)
        return evaluator(question, user_answer)
    
    def _eval_counting(self, question, user_answer):
        """点数判定"""
        correct = question['correct_answer']
        selected = user_answer.get('value')
        is_correct = selected == correct
        
        return {
            'is_correct': is_correct,
            'correct_answer': correct,
            'attempt_used': user_answer.get('attempt_count', 1),
            'analysis': {
                'error_type': self._classify_counting_error(correct, selected) if not is_correct else None
            }
        }
    
    def _eval_matching(self, question, user_answer):
        """配对判定"""
        correct_pairs = question['correct_answer']  # [[num, num], ...]
        user_pairs = user_answer.get('pairs', [])
        
        correct_count = 0
        for pair in user_pairs:
            if list(pair) in [list(p) for p in correct_pairs]:
                correct_count += 1
        
        total_pairs = len(correct_pairs)
        all_correct = correct_count == total_pairs
        
        return {
            'is_correct': all_correct,
            'partial_score': correct_count / total_pairs,
            'correct_answer': correct_pairs,
            'analysis': {
                'correct_pairs': correct_count,
                'total_pairs': total_pairs
            }
        }
    
    def _eval_tracing(self, question, user_answer):
        """描红判定"""
        # 检查路径覆盖率
        traced_points = user_answer.get('traced_points', [])
        expected_path = question.get('tracing_path', [])
        
        # 计算路径覆盖率
        coverage = self._calculate_path_coverage(traced_points, expected_path)
        # 计算偏离度
        deviation = self._calculate_deviation(traced_points, expected_path)
        
        # 判定标准
        if coverage >= 0.85 and deviation <= 25:
            is_correct = True
            quality = 'excellent'
        elif coverage >= 0.70 and deviation <= 40:
            is_correct = True
            quality = 'good'
        elif coverage >= 0.50:
            is_correct = False
            quality = 'fair'
        else:
            is_correct = False
            quality = 'needs_retry'
        
        return {
            'is_correct': is_correct,
            'quality': quality,
            'coverage': round(coverage, 2),
            'deviation': round(deviation, 2),
            'analysis': {
                'stroke_order_correct': user_answer.get('stroke_order_followed', False)
            }
        }
    
    def _classify_counting_error(self, correct: int, selected: int):
        """分类计数错误类型"""
        if selected == correct + 1 or selected == correct - 1:
            return 'off_by_one'  # 差1错误
        if selected == correct * 2:
            return 'double_count'  # 重复计数
        if abs(selected - correct) >= 3:
            return 'random_guess'  # 猜测
        return 'close_attempt'  # 接近
    
    def _calculate_path_coverage(self, traced, expected):
        """计算描红路径覆盖率"""
        if not expected:
            return 0.0
        # 简化：将路径离散化为点集，计算覆盖率
        expected_set = set((p['x'], p['y']) for p in expected)
        traced_set = set((round(p['x'], 2), round(p['y'], 2)) for p in traced)
        
        covered = len(expected_set & traced_set)
        total = len(expected_set)
        return covered / total if total > 0 else 0.0
```

```python
    幼儿数学引擎降级处理器
    确保在任何异常情况下都能提供可用的练习体验
    """
    
    async def safe_generate_question(self, user_id: str, session_id: str) -> dict:
        """安全的练习生成，带有完整的降级链"""
        
        try:
            # 正常流程
            return await self._normal_generate(user_id, session_id)
        
        except TemplateNotFound:
            # 模板找不到 → 使用预置模板
            return self._fallback_basic_counting(user_id)
        
        except AssetLoadError:
            # 素材加载失败 → 使用纯文本/数字练习
            return self._fallback_text_only(user_id)
        
        except TTSUnavailable:
            # TTS 不可用 → 返回文本，客户端本地 TTS
            question = await self._normal_generate(user_id, session_id)
            question['prompt']['instruction_audio_url'] = None
            question['prompt']['fallback_to_local_tts'] = True
            question['prompt']['instruction_text'] = self._get_text_instruction(question)
            return question
        
        except ProfileNotFound:
            # 画像不存在 → 创建默认画像
            profile = await self.create_default_profile(user_id)

        except Exception as e:
            logger.error(f"Math engine error: {e}", exc_info=True)
            # 最终兜底：返回一道最简单的计数题
            return self._emergency_question()
```

### 12.1 练习预生成与缓存

```python
class PracticePreGenerator:
    """
    练习预生成服务
    在用户完成当前题目的同时，后台预生成下一题
    """
    
    async def on_answer_submitted(self, session_id: str, question_id: str):
        """当用户提交答案时，触发下一题预生成"""
        # 异步预生成，不阻塞当前请求
        asyncio.create_task(self._pregenerate_next(session_id))
    
    async def _pregenerate_next(self, session_id: str):
        """预生成下一题"""
        session = await self.load_session(session_id)
        if session['status'] != 'active':
            return
        
        # 检查是否已有足够的预生成题目
        cached = await self.redis.llen(f"ece:math:pregen:{session_id}")
        if cached >= 2:
            return  # 已有足够的缓存
        
        profile = await self.load_profile(session['user_id'])
        selector = PracticeSelector(profile, session['config'])
        template = selector.select_next()
        question = await self._instantiate_template(template, profile, session['theme'])
        
        # 存入预生成队列
        await self.redis.rpush(
            f"ece:math:pregen:{session_id}",
            json.dumps(question),
            ex=3600
        )
    
    async def get_next_from_cache(self, session_id: str) -> Optional[dict]:
        """从预生成缓存获取下一题"""
        data = await self.redis.lpop(f"ece:math:pregen:{session_id}")
        if data:
            return json.loads(data)
        return None
```

### 13.2 内容安全

所有数学练习内容均为算法生成，无第三方文本输入，因此内容安全风险极低。但需确保：

1. **素材审核**：所有主题素材（图片、音频）经过人工审核后入库

4. **家长授权**：首次使用前需家长同意并完成儿童账号创建流程
