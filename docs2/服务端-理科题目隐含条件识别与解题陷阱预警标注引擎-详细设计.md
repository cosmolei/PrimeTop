# 服务端-理科题目隐含条件识别与解题陷阱预警标注引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 理科解题模块的核心子服务，负责对数学、物理、化学、生物等理科题目进行深度语义分析，自动识别题目中的**隐含条件**、**易忽视的关键信息**和**常见解题陷阱**，并以结构化标注的形式输出给前端展示和下游服务消费。

原始设计文档（`docs/design`）第 6.11.2 节明确提出：
- **条件提取**：识别题目已知条件、隐含条件和求解目标
- **易错点提示**：提示单位、符号、条件遗漏、计算步骤等问题

本引擎将这两项核心能力细化为可编码实现的服务设计。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 隐含条件识别准确率 ≥ 85% | 针对高频题型（函数、力学、电学、化学方程式等） |
| 陷阱标注覆盖率 ≥ 80% | 覆盖各学科 Top-20 常见陷阱模式 |
| 单题处理延迟 ≤ 500ms | 不含 LLM 调用；含 LLM 调用 ≤ 3s |
| 可解释性 | 每条标注必须附带理由和来源依据 |
| 学科可扩展 | 支持通过配置新增学科规则集 |

### 1.3 适用范围

| 学科 | 覆盖范围 | 优先级 |
| --- | --- | --- |
| 初中数学 | 几何、代数、函数、统计 | P0 |
| 高中数学 | 函数导数、解析几何、立体几何、数列 | P0 |
| 初中物理 | 力学、电学、热学、光学 | P0 |
| 高中物理 | 力学、电磁学、热学、近代物理 | P1 |
| 初中化学 | 化学方程式、溶液、酸碱盐 | P1 |
| 高中化学 | 化学反应原理、有机化学、实验化学 | P2 |
| 生物 | 遗传学、生态学、生理学 | P2 |

## 4. 核心算法与处理流程

### 4.1 整体处理管线

```
题目标注请求
    │
    ▼
[1. 预处理] ── 标准化题干、提取公式区域、提取已知量
    │
    ▼
[2. 缓存查询] ── Redis: annotation:{questionId}:{subject}:{ver}
    │ 缓存未命中
    ▼
[3. 规则引擎检测]
    ├─ 3.1 KEYWORD 规则 ── 快速匹配高频陷阱
    ├─ 3.2 REGEX 规则 ── 模式匹配（单位、公式结构）
    ├─ 3.3 STRUCTURE 规则 ── 基于结构化解析结果
    └─ 3.4 合并去重
    │
    ▼
[4. 置信度过滤] ── 过滤低于 minConfidence 的标注
    │
    ▼
[5. LLM增强分析]（可选，enableLLM=true 且规则命中 < 3）
    ├─ 5.1 构建结构化Prompt
    ├─ 5.2 调用推理模型
    ├─ 5.3 解析+校验LLM输出
    └─ 5.4 与规则结果合并
    │
    ▼
[6. 个性化适配] ── 查询学生陷阱画像，调整严重度
    │
    ▼
[7. 排序截断] ── 严重度→置信度→优先级，截取maxAnnotations
    │
    ▼
[8. 缓存写入+返回] ── TTL 24h(规则) / 6h(LLM)
```

#### 4.2.2 规则执行器核心代码

```java
@Service
public class RuleEngineExecutor {

    @Autowired private SubjectDetectionRuleMapper ruleMapper;
    @Autowired private RuleCacheService ruleCache;

    /**
     * 执行规则检测
     */
    public List<Annotation> execute(AnnotationRequest request, QuestionStructure structure) {
        // 1. 加载启用的规则（带缓存）
        List<SubjectDetectionRule> rules = ruleCache.getEnabledRules(
            request.getSubject(), request.getGradeRange()
        );

        // 2. 按类型分组执行
        List<Annotation> results = new ArrayList<>();

        // 2.1 KEYWORD 规则
        results.addAll(executeKeywordRules(rules, request, RuleType.KEYWORD));

        // 2.2 REGEX 规则
        results.addAll(executeRegexRules(rules, request, RuleType.REGEX));

        // 2.3 STRUCTURE 规则（调用对应Detector）
        results.addAll(executeStructureRules(rules, structure));

        // 3. 合并去重（同一trapCategory + 相似description只保留最高置信度）
        return deduplicate(results);
    }

    /**
     * 执行正则匹配规则
     */
    private List<Annotation> executeRegexRules(
            List<SubjectDetectionRule> rules,
            AnnotationRequest request,
            RuleType filterType) {

        List<Annotation> annotations = new ArrayList<>();
        String text = request.getQuestionText();

        for (SubjectDetectionRule rule : rules) {
            if (rule.getRuleType() != filterType.name()) continue;

            RuleExpression expr = parseExpression(rule.getRuleExpression());
            Pattern pattern = Pattern.compile(expr.getPattern(), expr.getFlags());
            Matcher matcher = pattern.matcher(text);

            while (matcher.find()) {
                String captureText = matcher.group(expr.getCaptureGroup());
                if (captureText == null) continue;

                // 检查附加条件
                if (!checkConditions(expr.getConditions(), captureText, text)) continue;

                // 计算文本偏移
                int start = matcher.start();
                int end = matcher.end();

                // 填充模板
                Annotation ann = buildAnnotationFromTemplate(
                    rule, expr.getOutput(), captureText, start, end
                );
                annotations.add(ann);
            }
        }
        return annotations;
    }

    /**
     * 去重：同类别同位置的标注只保留置信度最高的
     */
    private List<Annotation> deduplicate(List<Annotation> annotations) {
        Map<String, Annotation> dedupMap = new LinkedHashMap<>();
        for (Annotation ann : annotations) {
            String key = ann.getTrapCategory() + ":" + ann.getTextRange();
            Annotation existing = dedupMap.get(key);
            if (existing == null || ann.getConfidence() > existing.getConfidence()) {
                dedupMap.put(key, ann);
            }
        }
        return new ArrayList<>(dedupMap.values());
    }
}
```

```java
@Service
public class LLMAnnotationValidator {

    private static final int MAX_LLM_ANNOTATIONS = 5;
    private static final double MIN_LLM_CONFIDENCE = 0.7;

    /**
     * 校验并过滤 LLM 输出的标注
     */
    public List<Annotation> validate(String llmOutput, List<Annotation> existing) {
        List<Annotation> result = new ArrayList<>();

        try {
            JSONArray jsonArray = new JSONArray(llmOutput);
            Set<String> existingTitles = existing.stream()
                .map(a -> normalizeTitle(a.getTitle()))
                .collect(Collectors.toSet());

            for (int i = 0; i < Math.min(jsonArray.length(), MAX_LLM_ANNOTATIONS); i++) {
                JSONObject obj = jsonArray.getJSONObject(i);

                double confidence = obj.optDouble("confidence", 0);
                if (confidence < MIN_LLM_CONFIDENCE) continue;

                String title = obj.getString("title");
                if (existingTitles.contains(normalizeTitle(title))) continue;

                Annotation ann = Annotation.builder()
                    .annotationId(generateId())
                    .type(AnnotationType.valueOf(obj.getString("type")))
                    .title(title)
                    .description(obj.getString("description"))
                    .trapCategory(obj.optString("trapCategory", null))
                    .severityLevel(obj.optInt("severity", 2))
                    .suggestion(obj.optString("suggestion", null))
                    .knowledgePoints(parseKpList(obj))
                    .confidence(confidence)
                    .llmGenerated(true)
                    .build();

                result.add(ann);
            }
        } catch (JSONException e) {
            log.warn("LLM annotation parse error", e);
        }
        return result;
    }

    private String normalizeTitle(String title) {
        return title.replaceAll("\\s+", "").toLowerCase();
    }
}
```

### 4.4 个性化适配

```java
@Service
public class PersonalizationAdapter {

    @Autowired private StudentTrapProfileService profileService;

    /**
     * 根据学生画像调整标注
     */
    public List<Annotation> adapt(List<Annotation> annotations, Long studentId) {
        if (studentId == null) return annotations;

        // 获取学生陷阱画像
        Map<String, StudentTrapProfile> profiles = profileService.getProfiles(studentId);

        List<Annotation> result = new ArrayList<>();
        for (Annotation ann : annotations) {
            if (ann.getTrapCategory() == null) {
                result.add(ann);
                continue;
            }

            StudentTrapProfile profile = profiles.get(ann.getTrapCategory());
            if (profile == null) {
                // 学生从未在此类陷阱上犯错，降低严重度
                ann.setSeverityLevel(Math.max(1, ann.getSeverityLevel() - 1));
                ann.setStudentSpecific(false);
            } else if (profile.getHitCount() >= 3) {
                // 学生在此类陷阱上频繁犯错，提升严重度
                ann.setSeverityLevel(Math.min(3, ann.getSeverityLevel() + 1));
                ann.setStudentSpecific(true);
                ann.setSuggestion(ann.getSuggestion() +
                    "\n\n⚠️ 你在过去" + profile.getHitCount() + "次练习中在此类陷阱上出过错，请特别注意！");
            }
            result.add(ann);
        }
        return result;
    }
}
```

### 6.1 异常处理矩阵

| 异常场景 | 检测方式 | 处理策略 | 用户感知 |

## 8. 性能优化

### 8.1 规则索引优化

将规则按 `priority` 排序后预编译为 `RuleSet`，启动时加载到内存：

```java
@Component
public class RuleSetLoader implements CommandLineRunner {

    @Override
    public void run(String... args) {
        // 按学科+学段预加载规则
        for (Subject subject : Subject.values()) {
            for (GradeRange grade : GradeRange.values()) {
                List<SubjectDetectionRule> rules = ruleMapper.findEnabled(subject, grade);
                List<CompiledRule> compiled = rules.stream()
                    .sorted(Comparator.comparing(SubjectDetectionRule::getPriority))
                    .map(this::compile)
                    .collect(Collectors.toList());
                ruleSetCache.put(subject, grade, compiled);
            }
        }
    }

    private CompiledRule compile(SubjectDetectionRule rule) {
        CompiledRule compiled = new CompiledRule();
        compiled.setRuleId(rule.getRuleId());
        compiled.setRuleType(RuleType.valueOf(rule.getRuleType()));

        RuleExpression expr = JSON.parseObject(rule.getRuleExpression(), RuleExpression.class);
        if (expr.getPattern() != null) {
            compiled.setPattern(Pattern.compile(expr.getPattern(), expr.getFlags()));
        }
        compiled.setOutputTemplate(JSON.parseObject(
            rule.getOutputTemplate(), AnnotationTemplate.class));
        return compiled;
    }
}
```

## 13. 附录

### 13.1 典型用例

**用例1：数学函数定义域**

题目：`求函数 y = √(x-1) / (x²-4) 的定义域`

引擎输出：
- 隐含条件1：`x-1 ≥ 0`（根式定义域）→ `x ≥ 1`
- 隐含条件2：`x²-4 ≠ 0`（分母≠0）→ `x ≠ ±2`
- 陷阱预警：取交集时注意 `x=2` 被排除 → 最终定义域 `[1,2)∪(2,+∞)`

**用例2：物理力学单位陷阱**

题目：`一辆汽车以 72 km/h 的速度行驶，刹车后加速度大小为 5 m/s²，求刹车距离`

引擎输出：
- 陷阱预警：速度单位 `km/h` 需先换算 → `72 km/h = 20 m/s`
- 提示：加速度为减速，公式中应取 `a = -5 m/s²`

**用例3：化学离子共存**

题目：`下列离子组在溶液中能大量共存的是？ A. Fe²⁺, MnO4⁻, H⁺`

引擎输出：
- 陷阱预警：`Fe²⁺`（还原性离子）与 `MnO4⁻`（氧化性离子）在酸性条件下发生氧化还原反应，不能共存

### 13.2 术语表

| 术语 | 说明 |
| --- | --- |
| 隐含条件 | 题目未直接给出但由数学/物理/化学定义自动成立的约束条件 |
| 解题陷阱 | 题目中容易导致学生出错的特定模式或结构 |
| 规则引擎 | 基于预定义规则的模式匹配系统 |
| 陷阱画像 | 学生在不同陷阱类别上的历史表现和敏感度 |
| 标注 | 对题目中特定位置的文本附加的结构化提示信息 |
