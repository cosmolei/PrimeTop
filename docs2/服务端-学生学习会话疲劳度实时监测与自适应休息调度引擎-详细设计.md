# 服务端-学生学习会话疲劳度实时监测与自适应休息调度引擎 详细设计

## 1. 概述

### 1.1 模块定位

本模块负责在学生单次学习会话（Learning Session）期间，通过客户端上报的行为信号与生理特征代理指标，**实时计算学生的学习疲劳度分数**，并基于疲劳度、学习内容类型、剩余学习目标及防沉迷合规要求，智能调度休息时机、休息时长和恢复活动推荐。

与现有模块的边界关系：

| 已有模块 | 关注维度 | 本模块差异 |
|---------|---------|-----------|
| 防沉迷与未成年人保护机制 | 日级别使用时长总量控制 | 关注单次会话内的微观疲劳，而非宏观时间限额 |
| 学习倦怠预警引擎 | 周/月级心理倦怠状态 | 关注分钟级认知疲劳波动 |
| 用户学习专注力分析 | 历史高效时段识别 | 关注当前会话的实时状态 |
| 认知负荷监测 | 内容难度动态调节 | 关注学生自身的生理/认知疲劳，不关心内容难度 |
| 护眼模式 | 屏幕亮度与色温 | 关注大脑认知疲劳，不只是视觉疲劳 |

### 1.2 核心职责

1. **疲劳信号采集与聚合**：接收客户端实时上报的行为信号流，进行清洗、聚合和特征提取。
2. **疲劳度实时评分**：基于多维度信号计算 0-100 的实时疲劳分数（FS, Fatigue Score）。
3. **自适应休息调度**：根据疲劳分数、学习上下文和合规约束，决策是否触发休息、休息时长和恢复活动。
4. **疲劳趋势分析**：存储疲劳曲线数据，支持会话后回放和长期模式分析。
5. **合规联动**：与防沉迷系统联动，确保休息调度满足未成年人保护法规的最低要求。

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 疲劳信号事件 (fatigue_signal_event)

客户端实时上报的原始行为信号事件。

```typescript
interface FatigueSignalEvent {
  /** 全局唯一事件ID */
  eventId: string;
  /** 用户ID */
  userId: string;
  /** 当前学习会话ID */
  sessionId: string;
  /** 信号类型 */
  signalType: FatigueSignalType;
  /** 信号值（不同类型含义不同） */
  signalValue: number;
  /** 会话内时间戳（毫秒，从会话开始计） */
  sessionTimestamp: number;
  /** 墙钟时间戳 */
  timestamp: string; // ISO 8601
  /** 设备信息 */
  deviceInfo: {
    platform: 'android' | 'ios' | 'web';
    screenOn: boolean;
    appForeground: boolean;
  };
  /** 学习上下文 */
  learningContext: {
    subject: string;
    module: 'ai_chat' | 'practice' | 'reading' | 'watching' | 'exam';
    contentId?: string;
  };
}

/** 疲劳信号类型枚举 */
type FatigueSignalType =
  | 'response_latency'      // 答题/交互响应延迟（ms）
  | 'error_rate_window'     // 滑动窗口错误率
  | 'scroll_velocity'       // 滚动速度衰减比
  | 'click_precision'       // 点击精度偏移（px）
  | 'tap_interval_variance'  // 点击间隔方差
  | 'idle_duration'         // 无操作空闲时长（s）
  | 'blink_proxy'           // 眨眼代理指标（通过前置摄像头，可选）
  | 'posture_change'        // 姿势变动频率（通过加速度计，可选）
  | 'backtrack_count'       // 回看/重读次数
  | 'zoom_adjustment'       // 页面缩放调整次数（视力疲劳代理）
  | 'audio_replay_count';   // 音频重播次数（听力疲劳代理）
```

#### 2.1.2 疲劳度评分快照 (fatigue_score_snapshot)

每隔 30 秒生成的疲劳度综合评分。

```typescript
interface FatigueScoreSnapshot {
  /** 快照ID */
  snapshotId: string;
  /** 用户ID */
  userId: string;
  /** 学习会话ID */
  sessionId: string;
  /** 疲劳度分数 0-100（0=精力充沛, 100=极度疲劳） */
  fatigueScore: number;
  /** 疲劳等级 */
  fatigueLevel: FatigueLevel;
  /** 各维度子分数 */
  dimensionScores: FatigueDimensionScores;
  /** 信号质量（0-1，反映信号可信度） */
  signalQuality: number;
  /** 会话内时间戳（秒） */
  sessionElapsedSec: number;
  /** 生成时间 */
  generatedAt: string;
}

/** 疲劳等级 */
type FatigueLevel =
  | 'alert'      // 0-25: 状态良好
  | 'mild'       // 26-50: 轻度疲劳
  | 'moderate'   // 51-75: 中度疲劳
  | 'high'       // 76-90: 高度疲劳
  | 'extreme';   // 91-100: 极度疲劳

/** 疲劳维度子分数 */
interface FatigueDimensionScores {
  /** 认知响应维度（基于响应延迟、错误率） */
  cognitive: number;
  /** 行为活跃度维度（基于滚动速度、点击频率） */
  behavioral: number;
  /** 视觉疲劳维度（基于缩放调整、回看次数） */
  visual: number;
  /** 注意力维度（基于空闲时长、点击间隔方差） */
  attention: number;
}
```

#### 2.1.3 休息调度决策 (rest_schedule_decision)

```typescript
interface RestScheduleDecision {
  /** 决策ID */
  decisionId: string;
  /** 用户ID */
  userId: string;
  /** 学习会话ID */
  sessionId: string;
  /** 决策类型 */
  decisionType: RestDecisionType;
  /** 触发的疲劳分数 */
  triggerScore: number;
  /** 建议休息时长（秒） */
  recommendedRestDurationSec: number;
  /** 建议恢复活动 */
  recommendedActivities: RestActivity[];
  /** 是否强制休息 */
  isMandatory: boolean;
  /** 决策原因 */
  reason: string;
  /** 触发时间 */
  triggeredAt: string;
  /** 决策元数据 */
  metadata: {
    sessionElapsedSec: number;
    continuousLearningSec: number;
    todayTotalLearningSec: number;
    nextContentPriority: 'high' | 'medium' | 'low';
  };
}

/** 休息决策类型 */
type RestDecisionType =
  | 'micro_break'     // 微休息（30s-2min）: 闭眼/深呼吸
  | 'short_break'     // 短休息（3-5min）: 起身活动
  | 'long_break'      // 长休息（10-15min）: 远眺/眼保健操
  | 'session_end'     // 建议结束会话
  | 'no_action';      // 无需干预

/** 恢复活动类型 */
interface RestActivity {
  activityId: string;
  /** 活动类型 */
  type: 'eye_exercise'    // 眼保健操
    | 'stretching'        // 拉伸运动
    | 'deep_breathing'    // 深呼吸
    | 'hydration'         // 喝水提醒
    | 'distant_gazing'    // 远眺
    | 'walking'           // 走动
    | 'micro_nap';        // 微小憩
  /** 活动名称 */
  name: string;
  /** 活动时长（秒） */
  durationSec: number;
  /** 活动描述/引导文案 */
  guide: string;
  /** 活动图标/动画资源URL */
  iconUrl: string;
  /** 适用年龄段 */
  applicableStages: ('preschool' | 'primary' | 'junior' | 'senior')[];
}
```

#### 2.2.2 ClickHouse 行为信号分析（冷数据）

```sql
-- 原始信号事件（高频写入，时效性查询）
CREATE TABLE fatigue_signal_events (
    eventId          String,
    userId           UInt64,
    sessionId        String,
    signalType       LowCardinality(String),
    signalValue      Float64,
    sessionTimestamp UInt32,
    timestamp        DateTime64(3),
    platform         LowCardinality(String),
    subject          LowCardinality(String),
    module           LowCardinality(String),
    contentId        String DEFAULT '',
    eventDate        Date MATERIALIZED toDate(timestamp)
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(eventDate)
ORDER BY (userId, timestamp)
TTL timestamp + INTERVAL 90 DAY
SETTINGS index_granularity = 8192;

-- 物化视图：按会话聚合信号统计
CREATE MATERIALIZED VIEW mv_signal_session_agg
TO signal_session_aggregates
AS
SELECT
    userId,
    sessionId,
    signalType,
    min(signalValue) as minValue,
    max(signalValue) as maxValue,
    avg(signalValue) as avgValue,
    count() as sampleCount,
    min(timestamp) as firstSignalAt,
    max(timestamp) as lastSignalAt
FROM fatigue_signal_events
GROUP BY userId, sessionId, signalType;
```

#### 4.1.2 滑动窗口特征提取

使用 5 分钟滑动窗口（300 秒）对信号进行聚合，窗口步长 30 秒：

```python
class SignalWindowProcessor:
    """
    滑动窗口信号处理器
    - 窗口大小: 300秒（5分钟）
    - 步长: 30秒
    - 每个窗口输出各信号的统计特征
    """

    WINDOW_SIZE_SEC = 300
    STEP_SIZE_SEC = 30

    def extract_features(self, signals: list[FatigueSignalEvent], window_end_sec: int) -> dict:
        window_start = window_end_sec - self.WINDOW_SIZE_SEC
        window_signals = [s for s in signals
                          if window_start <= s.session_timestamp / 1000 <= window_end_sec]

        features = {}

        # --- 响应延迟特征 ---
        response_latencies = [s.signal_value for s in window_signals
                              if s.signal_type == 'response_latency']
        if response_latencies:
            features['response_latency'] = {
                'mean': np.mean(response_latencies),
                'std': np.std(response_latencies),
                'trend': self._calc_trend(response_latencies),  # 线性趋势斜率
                'p90': np.percentile(response_latencies, 90),
                'count': len(response_latencies),
            }

        # --- 错误率特征 ---
        error_rates = [s.signal_value for s in window_signals
                       if s.signal_type == 'error_rate_window']
        if error_rates:
            features['error_rate'] = {
                'current': error_rates[-1] if error_rates else 0,
                'mean': np.mean(error_rates),
                'trend': self._calc_trend(error_rates),
            }

        # --- 滚动速度特征 ---
        scroll_velocities = [s.signal_value for s in window_signals
                             if s.signal_type == 'scroll_velocity']
        if scroll_velocities:
            # 对比会话前2分钟的平均速度，计算衰减比
            early_speed = self._get_baseline_scroll_speed()
            current_speed = np.mean(scroll_velocities[-10:])  # 最近10个采样
            features['scroll_velocity'] = {
                'decay_ratio': 1.0 - (current_speed / max(early_speed, 0.01)),
                'current': current_speed,
                'baseline': early_speed,
            }

        # --- 空闲时长特征 ---
        idle_durations = [s.signal_value for s in window_signals
                          if s.signal_type == 'idle_duration']
        if idle_durations:
            features['idle'] = {
                'max': max(idle_durations),
                'mean': np.mean(idle_durations),
                'count': len(idle_durations),
                'total_idle_sec': sum(idle_durations),
            }

        # --- 点击间隔方差 ---
        tap_intervals = [s.signal_value for s in window_signals
                         if s.signal_type == 'tap_interval_variance']
        if tap_intervals:
            features['tap_variance'] = {
                'current': tap_intervals[-1],
                'trend': self._calc_trend(tap_intervals),
            }

        # --- 回看次数 ---
        backtracks = [s for s in window_signals
                      if s.signal_type == 'backtrack_count']
        features['backtrack'] = {
            'count': len(backtracks),
            'frequency': len(backtracks) / (self.WINDOW_SIZE_SEC / 60),  # 次/分钟
        }

        # --- 缩放调整次数 ---
        zoom_adjustments = [s for s in window_signals
                           if s.signal_type == 'zoom_adjustment']
        features['zoom_adjust'] = {
            'count': len(zoom_adjustments),
            'frequency': len(zoom_adjustments) / (self.WINDOW_SIZE_SEC / 60),
        }

        return features

    def _calc_trend(self, values: list[float]) -> float:
        """计算线性趋势斜率"""
        if len(values) < 3:
            return 0.0
        x = np.arange(len(values))
        slope = np.polyfit(x, values, 1)[0]
        return float(slope)
```

#### 4.1.3 维度评分函数

每个维度输出 0-100 分，分数越高表示疲劳越严重。

```python
import math
from dataclasses import dataclass

@dataclass
class DimensionConfig:
    """维度计算参数配置"""
    # 认知维度
    cognitive: dict = None
    # 行为维度
    behavioral: dict = None
    # 视觉维度
    visual: dict = None
    # 注意力维度
    attention: dict = None


class FatigueDimensionScorer:
    """
    多维度疲劳评分器
    """

    def __init__(self, config: DimensionConfig):
        self.config = config

    def score_cognitive(self, features: dict) -> float:
        """
        认知维度评分
        基于: 响应延迟、错误率、延迟趋势
        """
        score = 0.0
        weights = self.config.cognitive or {
            'response_latency_mean': 0.35,
            'response_latency_trend': 0.20,
            'error_rate': 0.35,
            'error_rate_trend': 0.10,
        }

        rl = features.get('response_latency', {})
        er = features.get('error_rate', {})

        # 响应延迟归一化（基线 2000ms, 100分对应 8000ms）
        rl_mean = rl.get('mean', 2000)
        rl_score = self._normalize_linear(rl_mean, baseline=2000, ceiling=8000)

        # 延迟趋势（斜率 > 0 表示变慢）
        rl_trend = max(0, rl.get('trend', 0))
        rl_trend_score = self._normalize_linear(rl_trend, baseline=0, ceiling=50)

        # 错误率
        er_current = er.get('current', 0.1)
        er_score = self._normalize_linear(er_current, baseline=0.1, ceiling=0.5)

        # 错误率趋势
        er_trend = max(0, er.get('trend', 0))
        er_trend_score = self._normalize_linear(er_trend, baseline=0, ceiling=0.02)

        score = (
            weights['response_latency_mean'] * rl_score +
            weights['response_latency_trend'] * rl_trend_score +
            weights['error_rate'] * er_score +
            weights['error_rate_trend'] * er_trend_score
        )
        return min(100, max(0, score))

    def score_behavioral(self, features: dict) -> float:
        """
        行为维度评分
        基于: 滚动速度衰减、点击频率变化
        """
        sv = features.get('scroll_velocity', {})
        tv = features.get('tap_variance', {})

        # 滚动速度衰减比（0 = 无衰减, 1 = 完全停止）
        decay_ratio = max(0, sv.get('decay_ratio', 0))
        decay_score = self._normalize_linear(decay_ratio, baseline=0, ceiling=0.7)

        # 点击间隔方差增大（反映操作不稳定性增加）
        tap_var = tv.get('current', 0)
        tap_var_score = self._normalize_linear(tap_var, baseline=500, ceiling=3000)

        score = 0.6 * decay_score + 0.4 * tap_var_score
        return min(100, max(0, score))

    def score_visual(self, features: dict) -> float:
        """
        视觉维度评分
        基于: 页面缩放调整频率、回看频率
        """
        za = features.get('zoom_adjust', {})
        bt = features.get('backtrack', {})

        # 缩放频率（次/分钟）
        za_freq = za.get('frequency', 0)
        za_score = self._normalize_linear(za_freq, baseline=0, ceiling=3)

        # 回看频率
        bt_freq = bt.get('frequency', 0)
        bt_score = self._normalize_linear(bt_freq, baseline=0, ceiling=5)

        score = 0.55 * za_score + 0.45 * bt_score
        return min(100, max(0, score))

    def score_attention(self, features: dict) -> float:
        """
        注意力维度评分
        基于: 空闲时长、空闲次数
        """
        idle = features.get('idle', {})

        # 最大空闲时长
        max_idle = idle.get('max', 0)
        max_idle_score = self._normalize_linear(max_idle, baseline=5, ceiling=60)

        # 平均空闲时长
        mean_idle = idle.get('mean', 0)
        mean_idle_score = self._normalize_linear(mean_idle, baseline=3, ceiling=30)

        # 空闲事件密度
        idle_count = idle.get('count', 0)
        idle_density_score = self._normalize_linear(idle_count, baseline=0, ceiling=10)

        score = 0.4 * max_idle_score + 0.3 * mean_idle_score + 0.3 * idle_density_score
        return min(100, max(0, score))

    def _normalize_linear(self, value: float, baseline: float, ceiling: float) -> float:
        """线性归一化到 0-100"""
        if ceiling == baseline:
            return 0
        normalized = (value - baseline) / (ceiling - baseline) * 100
        return min(100, max(0, normalized))
```

#### 4.1.4 综合分数融合

```python
class FatigueScoreFuser:
    """
    多维度疲劳分数融合器
    使用自适应权重 + 非线性增强
    """

    # 默认维度权重（按学段调整）
    DEFAULT_WEIGHTS = {
        'preschool': {'cognitive': 0.30, 'behavioral': 0.35, 'visual': 0.20, 'attention': 0.15},
        'primary':   {'cognitive': 0.35, 'behavioral': 0.25, 'visual': 0.20, 'attention': 0.20},
        'junior':    {'cognitive': 0.40, 'behavioral': 0.20, 'visual': 0.15, 'attention': 0.25},
        'senior':    {'cognitive': 0.45, 'behavioral': 0.15, 'visual': 0.10, 'attention': 0.30},
    }

    def fuse(
        self,
        dimension_scores: dict,  # {cognitive, behavioral, visual, attention}
        user_stage: str,
        session_elapsed_sec: int,
        user_baseline: dict = None,
    ) -> float:
        """
        计算最终疲劳分数
        """
        weights = self.DEFAULT_WEIGHTS.get(user_stage, self.DEFAULT_WEIGHTS['primary'])

        # 1. 加权求和
        weighted_score = sum(
            dimension_scores[dim] * weights[dim]
            for dim in ['cognitive', 'behavioral', 'visual', 'attention']
        )

        # 2. 时间衰减增强（连续学习越久，同分意味着越疲劳）
        time_boost = self._calc_time_boost(session_elapsed_sec)
        enhanced_score = weighted_score * (1 + time_boost)

        # 3. 用户基线校准
        if user_baseline:
            calibration = self._apply_baseline_calibration(enhanced_score, user_baseline)
            enhanced_score = calibration

        # 4. 非线性映射（压缩低分区，拉伸高分区）
        final_score = self._nonlinear_map(enhanced_score)

        return min(100, max(0, final_score))

    def _calc_time_boost(self, elapsed_sec: int) -> float:
        """
        连续学习时间增强因子
        0-15分钟: 0% boost
        15-30分钟: 0-5% boost（线性）
        30-45分钟: 5-15% boost（线性）
        45-60分钟: 15-30% boost（线性）
        60+分钟: 30%+ boost
        """
        minutes = elapsed_sec / 60
        if minutes <= 15:
            return 0.0
        elif minutes <= 30:
            return (minutes - 15) / 15 * 0.05
        elif minutes <= 45:
            return 0.05 + (minutes - 30) / 15 * 0.10
        elif minutes <= 60:
            return 0.15 + (minutes - 45) / 15 * 0.15
        else:
            return min(0.50, 0.30 + (minutes - 60) / 60 * 0.05)

    def _nonlinear_map(self, score: float) -> float:
        """
        Sigmoid 非线性映射
        - 低分区（0-30）：适度压缩，避免假阳性
        - 高分区（70-100）：适度拉伸，放大预警灵敏度
        """
        # 使用调整后的 Sigmoid
        center = 50
        steepness = 0.04
        mapped = 100 / (1 + math.exp(-steeepness * (score - center)))
        return mapped

    def _apply_baseline_calibration(self, score: float, baseline: dict) -> float:
        """
        基于用户历史疲劳模式校准
        """
        avg_peak = baseline.get('avg_peak_score', 70)
        onset_min = baseline.get('fatigue_onset_min', 30)

        # 如果用户通常在较晚时间才出现疲劳（onset_min > 35），降低早期评分
        if onset_min > 35 and score < 50:
            score *= 0.9

        # 如果用户通常峰值较低（avg_peak < 60），整体降低
        if avg_peak < 60:
            score *= 0.95

        return score
```

#### 4.1.5 信号质量评估

当客户端信号不充足（如刚启动、设备传感器不可用）时，降低评分可信度。

```python
class SignalQualityEvaluator:
    """
    评估当前窗口内的信号质量
    """

    MIN_SAMPLES_PER_DIMENSION = 3

    def evaluate(self, features: dict, window_sec: int = 300) -> float:
        """
        返回信号质量 0-1
        """
        quality_factors = []

        # 1. 信号覆盖度：多少维度有数据
        expected_dimensions = ['response_latency', 'scroll_velocity', 'idle', 'backtrack']
        covered = sum(1 for d in expected_dimensions if d in features and features[d])
        coverage = covered / len(expected_dimensions)
        quality_factors.append(('coverage', coverage, 0.4))

        # 2. 信号密度：每分钟采样数
        total_signals = sum(
            f.get('count', 1) if isinstance(f, dict) else 1
            for f in features.values()
        )
        expected_density = window_sec / 30  # 理想每30秒一个信号
        actual_density = total_signals / (window_sec / 60)
        density_score = min(1.0, actual_density / 2)  # 每分钟2个信号为满分
        quality_factors.append(('density', density_score, 0.3))

        # 3. 时间连续性：是否存在大段空白
        # (简化: 如果总采样数 < 预期的50%, 认为连续性差)
        continuity = 1.0 if total_signals >= expected_density * 0.5 else 0.5
        quality_factors.append(('continuity', continuity, 0.3))

        # 加权平均
        final_quality = sum(q * w for _, q, w in quality_factors)
        return final_quality
```

```python
from enum import Enum
from dataclasses import dataclass

class RestDecisionEngine:

        'short_break': 70,     # 70+: 建议短休息
        'long_break': 85,      # 85+: 建议长休息
        'session_end': 95,     # 95+: 建议结束会话
    }

    # 连续学习硬限制（秒）—— 合规底线
    CONTINUOUS_LIMITS = {
        'preschool': 20 * 60,   # 幼儿: 20分钟强制休息
        'primary':   30 * 60,   # 小学: 30分钟强制休息
        'junior':    40 * 60,   # 初中: 40分钟强制休息
        'senior':    50 * 60,   # 高中: 50分钟强制休息
    }

    # 拒绝后冷却时间
    DEFERRED_RETRY_SEC = 300  # 5分钟

    def evaluate(
        self,
        fatigue_score: float,
        fatigue_level: str,
        continuous_learning_sec: int,
        today_total_sec: int,
        user_stage: str,
        user_baseline: dict,
        last_rest_decision: dict = None,
        pending_defer: bool = False,
    ) -> RestScheduleDecision:
        """
        评估并生成休息决策
        """

        # === 规则1: 检查是否有待处理的延迟 ===
        if pending_defer and continuous_learning_sec < (
            (last_rest_decision or {}).get('triggered_at_sec', 0) + self.DEFERRED_RETRY_SEC
        ):
            return self._no_action("休息建议已推迟，将在稍后重新评估")

        # === 规则2: 合规硬性限制检查 ===
        stage_limit = self.CONTINUOUS_LIMITS.get(user_stage, 30 * 60)
        if continuous_learning_sec >= stage_limit:
            return self._create_decision(
                decision_type='long_break',
                fatigue_score=fatigue_score,
                continuous_sec=continuous_learning_sec,
                today_sec=today_total_sec,
                is_mandatory=True,
                reason=f"已连续学习{continuous_learning_sec // 60}分钟，"
                       f"达到{self._stage_label(user_stage)}单次学习时长上限，"
                       f"请立即休息。",
                rest_duration=self._calc_rest_duration(
                    'long_break', fatigue_score, continuous_learning_sec, user_stage
                ),
                user_stage=user_stage,
            )

        # === 规则3: 极端疲劳检查 ===
        if fatigue_score >= self.THRESHOLDS['session_end']:
            return self._create_decision(
                decision_type='session_end',
                fatigue_score=fatigue_score,
                continuous_sec=continuous_learning_sec,
                today_sec=today_total_sec,
                is_mandatory=False,
                reason=f"检测到极度疲劳状态（疲劳分{fatigue_score:.0f}），"
                       f"建议结束本次学习，充分休息后再继续。",
                rest_duration=0,
                user_stage=user_stage,
            )

        # === 规则4: 高疲劳检查 ===
        if fatigue_score >= self.THRESHOLDS['long_break']:
            return self._create_decision(
                decision_type='long_break',
                fatigue_score=fatigue_score,
                continuous_sec=continuous_learning_sec,
                today_sec=today_total_sec,
                is_mandatory=False,
                reason=f"疲劳度较高（{fatigue_score:.0f}），"
                       f"连续学习已{continuous_learning_sec // 60}分钟，"
                       f"建议休息10-15分钟，恢复精力。",
                rest_duration=self._calc_rest_duration(
                    'long_break', fatigue_score, continuous_learning_sec, user_stage
                ),
                user_stage=user_stage,
            )

        # === 规则5: 中度疲劳检查 ===
        if fatigue_score >= self.THRESHOLDS['short_break']:
            # 如果距离上次休息不到10分钟，降级为微休息
            if last_rest_decision:
                time_since = continuous_learning_sec - last_rest_decision.get('triggered_at_sec', 0)
                if time_since < 600:
                    return self._create_decision(
                        decision_type='micro_break',
                        fatigue_score=fatigue_score,
                        continuous_sec=continuous_learning_sec,
                        today_sec=today_total_sec,
                        is_mandatory=False,
                        reason=f"疲劳度有所上升（{fatigue_score:.0f}），"
                               f"建议休息1-2分钟，放松眼睛。",
                        rest_duration=90,
                        user_stage=user_stage,
                    )

            return self._create_decision(
                decision_type='short_break',
                fatigue_score=fatigue_score,
                continuous_sec=continuous_learning_sec,
                today_sec=today_total_sec,
                is_mandatory=False,
                reason=f"检测到中度疲劳（{fatigue_score:.0f}），"
                       f"建议休息5分钟，起身活动一下。",
                rest_duration=self._calc_rest_duration(
                    'short_break', fatigue_score, continuous_learning_sec, user_stage
                ),
                user_stage=user_stage,
            )

        # === 规则6: 轻度疲劳检查 ===
        if fatigue_score >= self.THRESHOLDS['micro_break']:
            # 仅当连续学习超过15分钟才提示
            if continuous_learning_sec >= 900:
                return self._create_decision(
                    decision_type='micro_break',
                    fatigue_score=fatigue_score,
                    continuous_sec=continuous_learning_sec,
                    today_sec=today_total_sec,
                    is_mandatory=False,
                    reason=f"学习状态有所下降（{fatigue_score:.0f}），"
                           f"建议微休息30秒，深呼吸放松。",
                    rest_duration=60,
                    user_stage=user_stage,
                )

        # === 规则7: 无需干预 ===
        return self._no_action("学习状态良好，继续加油！")

    def _calc_rest_duration(
        self,
        break_type: str,
        fatigue_score: float,
        continuous_sec: int,
        user_stage: str,
    ) -> int:
        """根据疲劳分数、连续时长和学段计算休息时长"""
        base_duration = {
            'micro_break': 60,
            'short_break': 300,
            'long_break': 720,
            'session_end': 0,
        }.get(break_type, 60)

        # 疲劳分数越高，休息时间越长
        fatigue_factor = 1.0 + (fatigue_score - 50) / 100 * 0.3

        # 连续学习时间因子
        continuous_factor = 1.0 + max(0, (continuous_sec / 60 - 20) / 40 * 0.2)

        # 学段调整（低龄需要更多休息）
        stage_factor = {
            'preschool': 1.3,
            'primary': 1.15,
            'junior': 1.0,
            'senior': 0.95,
        }.get(user_stage, 1.0)

        duration = int(base_duration * fatigue_factor * continuous_factor * stage_factor)

        # 限制范围
        limits = {
            'micro_break': (30, 120),
            'short_break': (180, 600),
            'long_break': (600, 1200),
        }
        min_dur, max_dur = limits.get(break_type, (30, 300))
        return max(min_dur, min(max_dur, duration))

    def _stage_label(self, stage: str) -> str:
        return {
            'preschool': '幼儿', 'primary': '小学',
            'junior': '初中', 'senior': '高中',
        }.get(stage, '当前')
```

```python
class FatigueSessionSummaryBuilder:
    """
    学习会话结束后生成疲劳维度摘要
    """

    def build(
        self,
        session_id: str,
        user_id: int,
        snapshots: list[FatigueScoreSnapshot],
        rest_decisions: list[RestScheduleDecision],
        total_duration_sec: int,
    ) -> FatigueSessionSummary:
        """生成会话疲劳摘要"""

        if not snapshots:
            return self._empty_summary(session_id, user_id, total_duration_sec)

        # 疲劳曲线
        fatigue_curve = [s.fatigue_score for s in snapshots]

        # 基础统计
        scores = [s.fatigue_score for s in snapshots]
        avg_score = int(np.mean(scores))
        peak_score = max(scores)
        peak_idx = scores.index(peak_score)
        peak_at_sec = snapshots[peak_idx].session_elapsed_sec

        # 维度均分
        avg_cognitive = int(np.mean([s.dimension_scores.cognitive for s in snapshots]))
        avg_behavioral = int(np.mean([s.dimension_scores.behavioral for s in snapshots]))
        avg_visual = int(np.mean([s.dimension_scores.visual for s in snapshots]))
        avg_attention = int(np.mean([s.dimension_scores.attention for s in snapshots]))

        # 休息统计
        accepted_rests = [r for r in rest_decisions if r.client_accepted]
        rest_count = len(accepted_rests)
        total_rest_sec = sum(r.actual_rest_sec or 0 for r in accepted_rests)

        # 恢复率计算
        recovery_rate = self._calc_recovery_rate(snapshots, accepted_rests)

        # 会话质量评级
        session_quality = self._evaluate_quality(
            avg_score, peak_score, total_duration_sec, rest_count, recovery_rate
        )

        return FatigueSessionSummary(
            summary_id=str(uuid.uuid4()),
            user_id=user_id,
            session_id=session_id,
            total_duration_sec=total_duration_sec,
            avg_fatigue_score=avg_score,
            peak_fatigue_score=peak_score,
            peak_fatigue_at_sec=peak_at_sec,
            fatigue_curve=fatigue_curve,
            rest_count=rest_count,
            total_rest_sec=total_rest_sec,
            recovery_rate=recovery_rate,
            avg_cognitive_score=avg_cognitive,
            avg_behavioral_score=avg_behavioral,
            avg_visual_score=avg_visual,
            avg_attention_score=avg_attention,
            session_quality=session_quality,
            generated_at=datetime.utcnow().isoformat(),
        )

    def _calc_recovery_rate(
        self,
        snapshots: list[FatigueScoreSnapshot],
        rests: list[RestScheduleDecision],
    ) -> float:
        """
        计算休息后恢复率
        = (休息前分数 - 休息后5分钟平均分数) / 休息前分数
        """
        if not rests or not snapshots:
            return 0.0

        recovery_rates = []
        for rest in rests:
            rest_time = rest.session_elapsed_sec

            # 休息前最近一个快照
            before = max(
                (s for s in snapshots if s.session_elapsed_sec <= rest_time),
                key=lambda s: s.session_elapsed_sec,
                default=None,
            )

            # 休息后5分钟内的快照
            after_snapshots = [
                s for s in snapshots
                if rest_time < s.session_elapsed_sec <= rest_time + 300
            ]

            if before and after_snapshots:
                after_avg = np.mean([s.fatigue_score for s in after_snapshots])
                before_score = before.fatigue_score
                if before_score > 0:
                    rate = (before_score - after_avg) / before_score
                    recovery_rates.append(max(0, rate))

        return float(np.mean(recovery_rates)) if recovery_rates else 0.0

    def _evaluate_quality(
        self, avg_score, peak_score, duration_sec, rest_count, recovery_rate
    ) -> str:
        """评级标准"""
        if avg_score < 30 and duration_sec <= 3600:
            return 'optimal'
        elif avg_score < 45 and peak_score < 70:
            return 'good'
        elif avg_score < 65 and peak_score < 85:
            return 'fair'
        else:
            return 'poor'
```

```java
// FatigueMonitorService.java — 疲劳监测核心服务

@Service
@RequiredArgsConstructor
@Slf4j
public class FatigueMonitorService {

    private final SignalWindowProcessor signalProcessor;
    private final FatigueDimensionScorer dimensionScorer;
    private final FatigueScoreFuser scoreFuser;
    private final SignalQualityEvaluator qualityEvaluator;
    private final RestDecisionEngine decisionEngine;
    private final RestActivityRecommender activityRecommender;

    private final FatigueScoreSnapshotRepository snapshotRepository;
    private final RestScheduleDecisionRepository decisionRepository;
    private final FatigueRedisService redisService;
    private final UserBaselineService baselineService;
    private final UserContextService userContextService;

    /**
     * 处理客户端批量上报的信号
     */
    @Transactional
    public SignalBatchResponse processSignals(
            Long userId,
            String sessionId,
            List<FatigueSignalEvent> signals
    ) {
        // 1. 写入信号到 Redis 滑动窗口
        redisService.appendSignals(sessionId, signals);

        // 2. 获取窗口内所有信号
        List<FatigueSignalEvent> windowSignals = redisService.getWindowSignals(sessionId, 300);

        // 3. 特征提取
        Map<String, Object> features = signalProcessor.extractFeatures(
                windowSignals,
                getCurrentSessionElapsed(sessionId)
        );

        // 4. 维度评分
        Map<String, Double> dimensionScores = Map.of(
                "cognitive", dimensionScorer.scoreCognitive(features),
                "behavioral", dimensionScorer.scoreBehavioral(features),
                "visual", dimensionScorer.scoreVisual(features),
                "attention", dimensionScorer.scoreAttention(features)
        );

        // 5. 信号质量
        double signalQuality = qualityEvaluator.evaluate(features, 300);

        // 6. 综合评分
        UserContext ctx = userContextService.getUserContext(userId);
        UserBaseline baseline = baselineService.getOrCreateBaseline(userId);
        int sessionElapsed = getCurrentSessionElapsed(sessionId);

        double fatigueScore = scoreFuser.fuse(
                dimensionScores,
                ctx.getStage(),
                sessionElapsed,
                baseline.toMap()
        );

        String fatigueLevel = mapScoreToLevel(fatigueScore);

        // 7. 持久化快照
        FatigueScoreSnapshot snapshot = FatigueScoreSnapshot.builder()
                .snapshotId(UUID.randomUUID().toString())
                .userId(userId)
                .sessionId(sessionId)
                .fatigueScore((int) fatigueScore)
                .fatigueLevel(fatigueLevel)
                .dimensionScores(dimensionScores)
                .signalQuality(signalQuality)
                .sessionElapsedSec(sessionElapsed)
                .generatedAt(Instant.now())
                .build();
        snapshotRepository.save(snapshot);

        // 更新 Redis 缓存
        redisService.setCurrentSnapshot(sessionId, snapshot);
        redisService.appendCurvePoint(sessionId, fatigueScore);

        // 8. 休息决策评估（仅当信号质量 > 0.5 时）
        RestScheduleDecision decision = null;
        if (signalQuality > 0.5) {
            decision = evaluateRestDecision(
                    userId, sessionId, fatigueScore, fatigueLevel,
                    sessionElapsed, ctx, baseline
            );
        }

        // 9. 构建响应
        return SignalBatchResponse.builder()
                .received(signals.size())
                .currentFatigueScore((int) fatigueScore)
                .currentFatigueLevel(fatigueLevel)
                .pendingRestDecision(decision)
                .build();
    }

    /**
     * 评估是否需要触发休息
     */
    private RestScheduleDecision evaluateRestDecision(
            Long userId,
            String sessionId,
            double fatigueScore,
            String fatigueLevel,
            int sessionElapsed,
            UserContext ctx,
            UserBaseline baseline
    ) {
        // 获取会话统计
        SessionStats stats = redisService.getSessionStats(sessionId);
        int continuousSec = stats.getContinuousLearningSec();
        int todayTotalSec = redisService.getDailyLearningSec(userId);

        // 获取上次决策
        RestScheduleDecision lastDecision = decisionRepository
                .findLatestBySessionId(sessionId).orElse(null);

        boolean pendingDefer = lastDecision != null
                && !lastDecision.getClientAcknowledged();

        // 执行决策
        RestScheduleDecision decision = decisionEngine.evaluate(
                fatigueScore,
                fatigueLevel,
                continuousSec,
                todayTotalSec,
                ctx.getStage(),
                baseline.toMap(),
                Map.of("triggered_at_sec", lastDecision != null
                        ? lastDecision.getSessionElapsedSec() : 0),
                pendingDefer
        );

        if (decision.getDecisionType() != RestDecisionType.NO_ACTION) {
            // 填充推荐活动
            List<RestActivity> activities = activityRecommender.recommend(
                    decision.getDecisionType().name(),
                    Map.of(
                            "cognitive", (double) snapshot.getDimensionScores().get("cognitive"),
                            "behavioral", (double) snapshot.getDimensionScores().get("behavioral"),
                            "visual", (double) snapshot.getDimensionScores().get("visual"),
                            "attention", (double) snapshot.getDimensionScores().get("attention")
                    ),
                    ctx.getStage(),
                    decision.getRecommendedRestDurationSec()
            );
            decision.setRecommendedActivities(activities);
            decisionRepository.save(decision);
        }

        return decision.getDecisionType() == RestDecisionType.NO_ACTION ? null : decision;
    }

    /**
     * 处理休息完成回执
     */
    @Transactional
    public RestCompleteResponse completeRest(
            String decisionId,
            String sessionId,
            int actualRestSec
    ) {
        RestScheduleDecision decision = decisionRepository
                .findByDecisionId(decisionId)
                .orElseThrow(() -> new BusinessException(40401, "决策不存在"));

        decision.setClientAcknowledged(true);
        decision.setClientAccepted(true);
        decision.setActualRestSec(actualRestSec);
        decisionRepository.save(decision);

        // 重置连续学习计时
        redisService.resetContinuousLearning(sessionId);

        // 获取休息后新分数
        FatigueScoreSnapshot latest = redisService.getLatestSnapshot(sessionId);
        FatigueScoreSnapshot previous = redisService.getSnapshotBefore(
                sessionId, decision.getSessionElapsedSec()
        );

        int recoveryScore = 0;
        int newScore = latest != null ? latest.getFatigueScore() : 0;
        int previousScore = previous != null ? previous.getFatigueScore() : 0;
        if (previousScore > 0) {
            recoveryScore = previousScore - newScore;
        }

        // 更新用户基线
        baselineService.updateRecoveryRate(decision.getUserId(), Math.max(0, recoveryScore));

        return RestCompleteResponse.builder()
                .completed(true)
                .recoveryScore(Math.max(0, recoveryScore))
                .newFatigueScore(newScore)
                .previousFatigueScore(previousScore)
                .message(recoveryScore > 20 ? "休息效果良好，疲劳度显著下降！" : "休息完成，继续加油！")
                .nextBreakRecommendedIn(calculateNextBreakInterval(newScore))
                .build();
    }

    private int calculateNextBreakInterval(int currentScore) {
        // 疲劳分越低，下次休息间隔越长
        if (currentScore < 30) return 1800;  // 30分钟
        if (currentScore < 50) return 1500;  // 25分钟
        if (currentScore < 70) return 1200;  // 20分钟
        return 600;  // 10分钟
    }

    private String mapScoreToLevel(double score) {
        if (score < 26) return "alert";
        if (score < 51) return "mild";
        if (score < 76) return "moderate";
        if (score < 91) return "high";
        return "extreme";
    }
}
```

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class FatigueEvaluationScheduler {

    private final FatigueMonitorService fatigueService;
    private final LearningSessionRepository sessionRepository;
    private final FatigueRedisService redisService;
    private final PushService pushService;

    /**
     * 每 30 秒对活跃学习会话进行疲劳评估
     */
    @Scheduled(fixedRate = 30_000)
    public void evaluateActiveSessions() {
        // 获取所有活跃会话（最近 5 分钟有信号上报）
        List<LearningSession> activeSessions = sessionRepository.findActiveSessions();

        for (LearningSession session : activeSessions) {
            try {
                // 只用窗口内已有信号计算（不依赖客户端主动上报）
                List<FatigueSignalEvent> signals = redisService.getWindowSignals(
                        session.getSessionId(), 300
                );

                if (signals.isEmpty()) {
                    // 无信号：可能已离开，更新空闲时长
                    handleIdleSession(session);
                    continue;
                }

                // 检查是否需要触发强制休息（合规检查）
                SessionStats stats = redisService.getSessionStats(session.getSessionId());
                checkCompliance(session, stats);

            } catch (Exception e) {
                log.error("疲劳评估异常: sessionId={}", session.getSessionId(), e);
            }
        }
    }

    /**
     * 每分钟检查合规限制
     */
    private void checkCompliance(LearningSession session, SessionStats stats) {
        String stage = session.getUserStage();
        int limit = RestDecisionEngine.CONTINUOUS_LIMITS.getOrDefault(stage, 1800);

        if (stats.getContinuousLearningSec() >= limit) {
            // 已超限：推送强制休息通知
            boolean alreadyNotified = redisService.isComplianceNotified(session.getSessionId());
            if (!alreadyNotified) {
                pushService.sendForceRestNotification(
                        session.getUserId(),
                        session.getSessionId(),
                        stage,
```

```dart
// ============================================================
// fatigue_signal_collector.dart — Flutter 客户端信号采集器
// ============================================================

import 'dart:async';
import 'dart:io';
import 'package:sensors_plus/sensors_plus.dart';

/// 疲劳信号采集器
class FatigueSignalCollector {
  final String sessionId;
  final String userId;

  // 信号缓冲队列
  final List<FatigueSignalEvent> _buffer = [];
  Timer? _flushTimer;
  Timer? _samplingTimer;

  // 基线指标
  double _baselineScrollVelocity = 1.0;
  int _baselineResponseTime = 2000;
  DateTime _lastInteractionTime = DateTime.now();

  // 行为追踪
  final List<Duration> _tapIntervals = [];
  DateTime? _lastTapTime;
  int _scrollCount = 0;
  double _totalScrollDelta = 0;
  int _errorCount = 0;
  int _totalAttempts = 0;

  FatigueSignalCollector({
    required this.sessionId,
    required this.userId,
  });

  /// 启动采集
  void start() {
    // 每 10 秒采样一次行为指标
    _samplingTimer = Timer.periodic(const Duration(seconds: 10), (_) {
      _sampleBehavioralMetrics();
    });

    // 每 30 秒批量上报
    _flushTimer = Timer.periodic(const Duration(seconds: 30), (_) {
      _flush();
    });
  }

  /// 停止采集
  void stop() {
    _samplingTimer?.cancel();
    _flushTimer?.cancel();
    _flush(); // 最后一次上报
  }

  /// 记录答题/交互响应
  void recordResponse({
    required Duration responseTime,
    required bool isCorrect,
    required String subject,
    required String module,
  }) {
    _totalAttempts++;
    if (!isCorrect) _errorCount++;

    _buffer.add(FatigueSignalEvent(
      signalType: 'response_latency',
      signalValue: responseTime.inMilliseconds.toDouble(),
      sessionTimestamp: _sessionTimestamp(),
      timestamp: DateTime.now().toUtc().toIso8601String(),
      learningContext: LearningContext(
        subject: subject,
        module: module,
      ),
    ));

    // 更新基线（前3次取平均）
    if (_totalAttempts <= 3) {
      _baselineResponseTime = (_baselineResponseTime + responseTime.inMilliseconds) ~/ 2;
    }
  }

  /// 记录滚动事件
  void recordScroll(double delta) {
    _scrollCount++;
    _totalScrollDelta += delta.abs();
    _lastInteractionTime = DateTime.now();
  }

  /// 记录点击事件
  void recordTap() {
    final now = DateTime.now();
    if (_lastTapTime != null) {
      _tapIntervals.add(now.difference(_lastTapTime!));
      if (_tapIntervals.length > 20) {
        _tapIntervals.removeAt(0);
      }
    }
    _lastTapTime = now;
    _lastInteractionTime = now;
  }

  /// 记录回看事件
  void recordBacktrack() {
    _buffer.add(FatigueSignalEvent(
      signalType: 'backtrack_count',
      signalValue: 1,
      sessionTimestamp: _sessionTimestamp(),
      timestamp: DateTime.now().toUtc().toIso8601String(),
      learningContext: const LearningContext(subject: '', module: 'reading'),
    ));
  }

  /// 记录页面缩放
  void recordZoomAdjustment() {
    _buffer.add(FatigueSignalEvent(
      signalType: 'zoom_adjustment',
      signalValue: 1,
      sessionTimestamp: _sessionTimestamp(),
      timestamp: DateTime.now().toUtc().toIso8601String(),
      learningContext: const LearningContext(subject: '', module: 'reading'),
    ));
  }

  /// 采样行为指标
  void _sampleBehavioralMetrics() {
    final now = DateTime.now();

    // 1. 空闲时长检测
    final idleDuration = now.difference(_lastInteractionTime).inSeconds;
    if (idleDuration > 5) {
      _buffer.add(FatigueSignalEvent(
        signalType: 'idle_duration',
        signalValue: idleDuration.toDouble(),
        sessionTimestamp: _sessionTimestamp(),
        timestamp: now.toUtc().toIso8601String(),
        learningContext: const LearningContext(subject: '', module: ''),
      ));
    }

    // 2. 滚动速度
    if (_scrollCount > 0) {
      final avgVelocity = _totalScrollDelta / _scrollCount;
      _buffer.add(FatigueSignalEvent(
        signalType: 'scroll_velocity',
        signalValue: avgVelocity,
        sessionTimestamp: _sessionTimestamp(),
        timestamp: now.toUtc().toIso8601String(),
        learningContext: const LearningContext(subject: '', module: ''),
      ));

      // 重置滚动统计
      _scrollCount = 0;
      _totalScrollDelta = 0;
    }

    // 3. 点击间隔方差
    if (_tapIntervals.length >= 3) {
      final intervals = _tapIntervals.map((d) => d.inMilliseconds).toList();
      final variance = _calculateVariance(intervals);
      _buffer.add(FatigueSignalEvent(
        signalType: 'tap_interval_variance',
        signalValue: variance,
        sessionTimestamp: _sessionTimestamp(),
        timestamp: now.toUtc().toIso8601String(),
        learningContext: const LearningContext(subject: '', module: ''),
      ));
    }

    // 4. 错误率
    if (_totalAttempts > 0) {
      _buffer.add(FatigueSignalEvent(
        signalType: 'error_rate_window',
        signalValue: _errorCount / _totalAttempts,
        sessionTimestamp: _sessionTimestamp(),
        timestamp: now.toUtc().toIso8601String(),
        learningContext: const LearningContext(subject: '', module: 'practice'),
      ));
      // 重置窗口
      _errorCount = 0;
      _totalAttempts = 0;
    }
  }

  /// 批量上报
  Future<void> _flush() async {
    if (_buffer.isEmpty) return;

    final signals = List<FatigueSignalEvent>.from(_buffer);
    _buffer.clear();

    try {
      final response = await _apiClient.post(
        '/api/v1/fatigue/signals/batch',
        body: {
          'sessionId': sessionId,
          'signals': signals.map((s) => s.toJson()).toList(),
        },
      );

      // 处理返回的休息决策
      if (response.data?.pendingRestDecision != null) {
        _onRestDecision?.call(response.data!.pendingRestDecision!);
      }
    } catch (e) {
      // 上报失败，放回缓冲区
      _buffer.insertAll(0, signals);
    }
  }

  double _calculateVariance(List<int> values) {
    if (values.length < 2) return 0;
    final mean = values.reduce((a, b) => a + b) / values.length;
    final sumSquaredDiff = values.map((v) => pow(v - mean, 2)).reduce((a, b) => a + b);
    return sumSquaredDiff / values.length;
  }

  int _sessionTimestamp() {
    return DateTime.now().millisecondsSinceEpoch - _sessionStartTime!;
  }

  // 回调
  void Function(RestScheduleDecision)? _onRestDecision;
  int? _sessionStartTime;
}
```

## 6. 错误处理

### 6.1 异常分类与处理策略

| 异常类型 | 场景 | 处理策略 | 用户影响 |
|---------|------|---------|---------|
| 信号上报失败 | 网络异常、服务端不可用 | 客户端缓存信号，指数退避重试，最多缓存 100 条 | 无感知，信号延迟 |
| 信号格式错误 | 客户端版本不一致 | 丢弃非法信号，记录日志 | 疲劳评估精度降低 |
| 信号窗口为空 | 客户端长时间无操作 | 标记空闲状态，触发空闲检测逻辑 | 可能触发休息提醒 |
| 评分计算异常 | 信号不足或算法异常 | 返回上一周期分数 + 信号质量标记 0.3 | 评分暂停更新 |
| 决策引擎异常 | 规则匹配失败 | 降级为基于时间的简单规则 | 休息建议不够精准 |
| Redis 连接异常 | 缓存不可用 | 直接读写 DB，标记降级状态 | 评估延迟增加 |
| 基线数据缺失 | 新用户无历史数据 | 使用学段默认基线参数 | 初始评分精度一般 |

```java
    /**
     * 降级等级1: 信号不足降级
     * 当信号质量 < 0.3 时，仅基于时间规则进行休息调度

                    .isMandatory(false)

                    .build();

                .decisionType(RestDecisionType.NO_ACTION)
```

```java
public class FatigueSignalReactiveHandler {

    private final Sinks.Many<SignalBatch> signalSink = Sinks.many()
            .multicast().onBackpressureBuffer(10000);

    @PostConstruct
    public void initPipeline() {

                ? Mono.fromCallable(() -> processSync(batch))
                : Mono.just(SignalBatchResponse.degraded());
    }
```

```java
     * 信号真实性校验
     */
    public SignalValidationResult validate(List<FatigueSignalEvent> signals) {

        // 1. 信号频率检查（过于均匀 = 脚本）
        double intervalStd = calculateIntervalStd(signals);
        if (intervalStd < 100) {  // 间隔标准差 < 100ms

                .collect(Collectors.toSet());

        }

        // 3. 设备指纹校验
        // (调用设备指纹服务交叉校验)

        return new SignalValidationResult(
                anomalies.isEmpty(),
                anomalies,
                anomalies.isEmpty() ? 1.0 : 0.3
```

### 9.4 信号模拟器（用于测试）

```python
class FatigueSignalSimulator:
    """
    模拟不同疲劳状态下的客户端信号序列
    用于自动化测试和算法调优
    """

    PROFILES = {
        'alert': {
            'response_latency_range': (1500, 2500),
            'error_rate': 0.05,
            'scroll_velocity_range': (0.8, 1.2),
            'idle_frequency': 0.1,
            'idle_duration_range': (3, 8),
        },
        'mild': {
            'response_latency_range': (2500, 4000),
            'error_rate': 0.12,
            'scroll_velocity_range': (0.5, 0.9),
            'idle_frequency': 0.2,
            'idle_duration_range': (5, 15),
        },
        'moderate': {
            'response_latency_range': (4000, 6500),
            'error_rate': 0.25,
            'scroll_velocity_range': (0.3, 0.6),
            'idle_frequency': 0.35,
            'idle_duration_range': (10, 25),
        },
        'exhausted': {
            'response_latency_range': (6000, 9000),
            'error_rate': 0.45,
            'scroll_velocity_range': (0.1, 0.3),
            'idle_frequency': 0.6,
            'idle_duration_range': (20, 60),
        },
    }

    def generate_session(
        self,
        session_id: str,
        user_id: int,
        duration_min: int = 60,
        fatigue_progression: str = 'natural',
    ) -> list[dict]:
        """
        生成一个完整的模拟会话信号序列

        fatigue_progression:
            'natural' - 从alert逐渐过渡到moderate/exhausted
            'constant_alert' - 始终保持alert状态
            'constant_exhausted' - 始终保持exhausted状态
            'recovery' - 从exhausted恢复到alert
        """
        signals = []
        total_sec = duration_min * 60

        for sec in range(0, total_sec, 15):  # 每15秒一个信号
            progress = sec / total_sec

            if fatigue_progression == 'natural':
                profile = self._interpolate_profile(progress)
            elif fatigue_progression == 'constant_alert':
                profile = self.PROFILES['alert']
            elif fatigue_progression == 'constant_exhausted':
                profile = self.PROFILES['exhausted']
            elif fatigue_progression == 'recovery':
                profile = self._interpolate_profile(1 - progress)

            # 生成信号
            signals.append({
                'signalType': 'response_latency',
                'signalValue': random.uniform(*profile['response_latency_range']),
                'sessionTimestamp': sec * 1000,
                'timestamp': f'2026-06-30T08:{sec//60:02d}:{sec%60:02d}.000Z',
            })

            if random.random() < profile['idle_frequency']:
                signals.append({
                    'signalType': 'idle_duration',
                    'signalValue': random.uniform(*profile['idle_duration_range']),
                    'sessionTimestamp': sec * 1000 + 5000,
                    'timestamp': f'2026-06-30T08:{sec//60:02d}:{(sec+5)%60:02d}.000Z',
                })

        return signals

    def _interpolate_profile(self, progress: float) -> dict:
        """在 alert → exhausted 之间线性插值"""
        if progress < 0.33:
            t = progress / 0.33
            return self._blend(self.PROFILES['alert'], self.PROFILES['mild'], t)
        elif progress < 0.66:
            t = (progress - 0.33) / 0.33
            return self._blend(self.PROFILES['mild'], self.PROFILES['moderate'], t)
        else:
            t = (progress - 0.66) / 0.34
            return self._blend(self.PROFILES['moderate'], self.PROFILES['exhausted'], t)

    def _blend(self, p1: dict, p2: dict, t: float) -> dict:
        return {
            'response_latency_range': (
                p1['response_latency_range'][0] * (1-t) + p2['response_latency_range'][0] * t,
                p1['response_latency_range'][1] * (1-t) + p2['response_latency_range'][1] * t,
            ),
            'error_rate': p1['error_rate'] * (1-t) + p2['error_rate'] * t,
            'scroll_velocity_range': (
                p1['scroll_velocity_range'][0] * (1-t) + p2['scroll_velocity_range'][0] * t,
                p1['scroll_velocity_range'][1] * (1-t) + p2['scroll_velocity_range'][1] * t,
            ),
            'idle_frequency': p1['idle_frequency'] * (1-t) + p2['idle_frequency'] * t,
            'idle_duration_range': (
                p1['idle_duration_range'][0] * (1-t) + p2['idle_duration_range'][0] * t,
                p1['idle_duration_range'][1] * (1-t) + p2['idle_duration_range'][1] * t,
            ),
        }
```
