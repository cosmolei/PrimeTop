# 古诗文专项学习系统 - 详细设计

## 1. 模块概述

### 1.1 功能定位

面向小学高年级至高中学生，提供古诗词鉴赏、文言文阅读理解、名句默写检测、诗词创作启蒙等一站式古诗文学习服务。系统依托 AI 大模型进行分级讲解、逐句翻译、意象分析和默写批改，结合教材课标同步进度和考试高频篇目，形成"学-背-练-测-用"完整闭环。

### 1.2 目标用户与需求矩阵

| 学段 | 年级 | 核心需求 | 考试关联 |
|------|------|----------|----------|
| 小学高年级 | 4-6年级 | 古诗词背诵、诗意理解、名句默写 | 小升初素养考查 |
| 初中 | 7-9年级 | 课内古诗精讲、文言文阅读、鉴赏答题技巧 | 中考语文占分20-25% |
| 高中 | 10-12年级 | 文言文实词虚词、古诗词鉴赏、比较阅读、名句名篇 | 高考语文占分15-20% |

### 1.3 设计原则

1. **教材同步**：按教材版本、年级、单元组织篇目，覆盖人教版、苏教版、北师大版等主流教材
2. **分级讲解**：小学用通俗语言，初中增加鉴赏术语，高中引入学术化表达
3. **默写驱动**：以"背得准、写得对"为核心目标，强化易错字辨析
4. **意象串联**：通过常见意象（月、柳、雁、梅等）构建跨篇目知识网络
5. **考试导向**：紧贴中考/高考题型，提供鉴赏题答题模板和训练

## 3. 数据结构设计

### 3.1 篇目主表

```sql
CREATE TABLE poem (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT,
    title             VARCHAR(128) NOT NULL COMMENT '篇名',
    author_id         BIGINT COMMENT '作者ID，关联poem_author表',
    dynasty           VARCHAR(16) NOT NULL COMMENT '朝代：唐/宋/元/明/清/先秦/汉/魏晋/南北朝/现代',
    poem_type         VARCHAR(16) NOT NULL COMMENT 'poem/ci/qu/fu/prose',
    content_original  TEXT NOT NULL COMMENT '原文（繁体或简体原文）',
    content_simplified TEXT NOT NULL COMMENT '简体中文原文',
    content_lines     JSON NOT NULL COMMENT '分行数据，结构见3.2',
    translation       TEXT COMMENT '全文白话译文',
    annotation        JSON COMMENT '注释列表，结构见3.3',
    appreciation      TEXT COMMENT '赏析正文（富文本）',
    background        TEXT COMMENT '写作背景',
    themes            JSON COMMENT '["思乡","爱国","田园"]',
    imagery_tags      JSON COMMENT '意象标签 ["moon","willow","plum"]',
    technique_tags    JSON COMMENT '表达技巧 ["比喻","借景抒情","对仗"]',
    emotion_tags      JSON COMMENT '情感标签 ["悲凉","豪迈","婉约"]',
    difficulty        TINYINT DEFAULT 3 COMMENT '难度等级1-5',
    stage_tags        JSON COMMENT '适用学段 ["primary_high","junior","senior"]',
    source_tags       JSON COMMENT '来源标签 ["textbook","exam_high_freq","classic"]',
    exam_frequency    TINYINT DEFAULT 0 COMMENT '考试出现频率0-5',
    recite_requirement VARCHAR(16) DEFAULT 'none' COMMENT 'none/recommended/required 全篇必背/推荐背诵',
    word_count        INT COMMENT '正文字数',
    status            TINYINT DEFAULT 1,
    version           INT DEFAULT 1,
    created_at        DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at        DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_author (author_id),
    INDEX idx_dynasty (dynasty),
    INDEX idx_type (poem_type),
    INDEX idx_difficulty (difficulty),
    FULLTEXT idx_title_content (title, content_simplified)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='古诗文篇目';
```
