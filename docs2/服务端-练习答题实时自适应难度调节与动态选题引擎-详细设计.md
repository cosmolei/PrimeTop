## 1. 模块概述

### 1.1 背景与目标

PrimeTop 的练习闭环涉及多个环节：课前预习练习、课后巩固练习、错题强化练习、薄弱点专项训练、每日任务练习、自由刷题等。现有系统已覆盖：

- **题目智能推荐与个性化练习编排服务**：负责练习前的题目推荐列表生成（"出哪些题"）
- **智能组卷与自适应测试引擎**：负责考试/测评场景的组卷和 CAT 能力估计（"考哪些题"）
- **练习测评会话服务与答题流程状态机**：负责会话生命周期管理和答题状态流转（"怎么管"）
- **知识追踪模型引擎**：负责知识点掌握度的持续更新（"学得怎么样"）

但缺少一个关键组件——**练习答题进行中的实时决策引擎**。当学生在练习会话中提交了一道题的答案后，系统需要在 **200ms 内**决定：

1. 下一道题应该出什么难度？
2. 下一道题应该覆盖哪个知识点？
3. 是否需要穿插一道复习题？
4. 学生是否已经陷入挫败感，需要降低难度或给予鼓励？
5. 当前知识点的练习是否已经足够，可以切换到下一个？
6. 是否应该提前结束本次会话？

这就是**练习答题实时自适应难度调节与动态选题引擎（Real-time Adaptive Difficulty & Dynamic Question Selection Engine，简称 RTAQS）**的职责。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| 实时难度调节 | 根据学生实时答题表现（正确率、响应时间、求助行为），动态调整下一题难度 |
| 下一题智能选择 | 从候选题库中选出最优的下一道题，平衡学习效果和练习体验 |
| 多目标优化 | 同时兼顾知识覆盖度、学习效率、心流体验、记忆巩固四个维度 |
| 会话质量监控 | 实时感知学生认知负荷和情绪状态，防止挫败或无聊 |
| 优雅降级 | 当候选题不足或模型异常时，降级为预设序列或随机选择 |

### 1.4 适用场景

| 场景 | 是否启用 RTAQS | 说明 |
|------|:---------:|------|
| 同步课堂课后练习 | ✅ | 自适应调节难度，巩固本章知识 |
| 薄弱知识点专项训练 | ✅ | 针对性突破，逐步提难度 |
| 每日任务练习 | ✅ | 多学科混合，自适应分配 |
| 自由练习/刷题 | ✅ | 纯自适应模式，学生自主选学科 |
| 错题强化练习 | ✅ | 围绕错题知识点自适应出题 |
| 模拟考试/真题练习 | ❌ | 使用预设试卷，不进行实时调节 |
| 作业提交 | ❌ | 使用教师预设题目序列 |
| AI 对话跟进练习 | ⚠️ | 轻量模式，仅调节难度不换题 |

## 4. 核心算法设计

### 4.1 整体决策流程

```text
┌─────────────────────────────────────────────────────────────────┐
│                    每次答题提交后的决策流程                        │
└─────────────────────────────────────────────────────────────────┘

步骤1: [信号采集] 收集答题结果 + 行为特征 + 时间特征
         │
         ▼
步骤2: [能力更新] 使用贝叶斯更新模型调整实时能力估计 θ
         │
         ▼
步骤3: [认知状态评估] 综合正确率、响应时间、行为信号 → 判定认知状态
         │
         ▼
步骤4: [难度调节] 基于认知状态和能力估计 → 计算下一题目标难度
         │
         ├─── 挫败/焦虑 → 降难度（最多降2档）
         ├─── 无聊 → 升难度（最多升1档）
         ├─── 心流 → 维持或微调（±0.5档）
         └─── 疲劳 → 维持难度 + 考虑结束
         │
         ▼
步骤5: [知识点决策] 判断是否切换知识点
         │
         ├─── 当前KP掌握度达标(≥0.85) 且 练习≥3题 → 切换到下一个KP
         ├─── 当前KP连续3题全对 且 掌握度提升≥0.15 → 切换
         ├─── 当前KP练习≥8题 仍未改善 → 放弃，切换
         ├─── 间隔重复引擎有到期项 → 穿插1道复习题
         └─── 否则 → 继续当前KP
         │
         ▼
步骤6: [候选检索] 按目标KP+目标难度+题型+排除已用 → 检索候选池
         │
         ▼
步骤7: [选题打分] 对每个候选题计算综合得分 → 选最高分
         │  得分 = w1*知识匹配度 + w2*难度匹配度 + w3*新颖度 
         │        + w4*区分度 + w5*用时预估合适度
         │
         ▼
步骤8: [兜底检查] 候选池为空？
         │
         ├─── 是 → 扩大难度范围 ±1档 → 重试 → 仍空 → 随机出题
         └─── 否 → 继续
         │
         ▼
步骤9: [结束判定] 检查会话结束条件
         │
         ├─── 题数已达上限
         ├─── 全部目标KP已达标
         ├─── 学生疲劳且已达到最小题数
         ├─── 正确率连续5题低于20%（防挫败退出）
         └─── 时间耗尽
         │
         ▼
步骤10: [输出] 返回 NextQuestionResponse
```

### 4.2 实时能力估计 — 贝叶斯在线更新

#### 4.2.1 模型原理

使用简化的贝叶斯在线学习模型，将学生的实时能力建模为 Beta 分布，每次答题后更新分布参数。

```java
/**
 * 学生会话内实时能力估计器
 * 
 * 模型：θ ~ Beta(α, β)
 * - α 初始值：基于学生入学测试或历史掌握度的先验
 * - 每答对一题：α += weight * difficultyFactor
 * - 每答错一题：β += weight * difficultyFactor
 * - 实时能力估计：θ_hat = α / (α + β)
 */
public class SessionAbilityEstimator {
    
    // Beta 分布参数
    private double alpha;
    private double beta;
    
    // 历史窗口（最近N题加权）
    private static final int WINDOW_SIZE = 8;
    private LinkedList<AnswerObservation> recentWindow = new LinkedList<>();
    
    /**
     * 初始化
     * @param priorMastery 先验掌握度（来自知识追踪模型）
     * @param confidence   先验置信度（0~1，来自历史数据量）
     */
    public SessionAbilityEstimator(double priorMastery, double confidence) {
        // 将先验映射为 Beta 分布参数
        // confidence 越高，先验权重越大（伪计数越大）
        double pseudoCount = confidence * 10.0; // 最大伪计数 10
        this.alpha = Math.max(priorMastery * pseudoCount, 0.5);
        this.beta = Math.max((1.0 - priorMastery) * pseudoCount, 0.5);
    }
    
    /**
     * 根据答题结果更新能力估计
     */
    public void update(AnswerObservation obs) {
        // 滑动窗口
        recentWindow.addLast(obs);
        if (recentWindow.size() > WINDOW_SIZE) {
            recentWindow.removeFirst();
        }
        
        // 计算难度加权因子：高难度题的信号权重更大
        double diffWeight = computeDifficultyWeight(obs.getDifficulty());
        
        // 计算时间加权因子：快速正确 = 高能力信号，缓慢错误 = 低能力强信号
        double timeWeight = computeTimeWeight(obs);
        
        double weight = diffWeight * timeWeight;
        
        if (obs.isCorrect()) {
            alpha += weight;
        } else {
            beta += weight;
        }
        
        // 防止参数爆炸（归一化）
        if (alpha + beta > 100.0) {
            double scale = 100.0 / (alpha + beta);
            alpha *= scale;
            beta *= scale;
        }
    }
    
    /**
     * 获取当前能力估计值 [0, 1]
     */
    public double getAbilityEstimate() {
        return alpha / (alpha + beta);
    }
    
    /**
     * 获取能力估计的不确定度（方差）
     */
    public double getUncertainty() {
        double var = (alpha * beta) / ((alpha + beta) * (alpha + beta) * (alpha + beta + 1));
        return Math.sqrt(var);
    }
    
    /**
     * 获取最近窗口正确率
     */
    public double getRecentAccuracy() {
        if (recentWindow.isEmpty()) return 0.5;
        long correct = recentWindow.stream().filter(AnswerObservation::isCorrect).count();
        return (double) correct / recentWindow.size();
    }
    
    private double computeDifficultyWeight(DifficultyTier difficulty) {
        // D1=0.6, D2=0.8, D3=1.0, D4=1.3, D5=1.6
        return switch (difficulty) {
            case D1_BASIC -> 0.6;
            case D2_ELEMENTARY -> 0.8;
            case D3_INTERMEDIATE -> 1.0;
            case D4_ADVANCED -> 1.3;
            case D5_CHALLENGE -> 1.6;
        };
    }
    
    private double computeTimeWeight(AnswerObservation obs) {
        // 快速正确 → 权重略增
        // 缓慢错误 → 权重略增（更强的"不会"信号）
        // 缓慢正确 → 标准权重
        // 快速错误 → 权重略减（可能是猜的或粗心）
        if (obs.isCorrect() && obs.getResponseTimeSeconds() < obs.getExpectedTimeSeconds() * 0.5) {
            return 1.2; // 快速正确
        } else if (!obs.isCorrect() && obs.getResponseTimeSeconds() > obs.getExpectedTimeSeconds() * 1.5) {
            return 1.2; // 缓慢错误
        } else if (!obs.isCorrect() && obs.getResponseTimeSeconds() < obs.getExpectedTimeSeconds() * 0.3) {
            return 0.7; // 快速错误（可能猜的）
        }
        return 1.0;
    }
}

/**
 * 认知状态评估器
 * 综合正确率、响应时间、行为信号判定学生当前认知状态
 */
public class CognitiveStateEvaluator {
    
    private static final int EVAL_WINDOW = 5; // 评估窗口：最近5题
    
    /**
     * 评估认知状态
     */
    public CognitiveStateEvaluation evaluate(
            List<AnswerObservation> recentObservations,
            SessionAbilityEstimator abilityEstimator,
            double cognitiveLoadFromExternal) { // 来自认知负荷监测引擎的信号
        
        if (recentObservations.isEmpty()) {
            return CognitiveStateEvaluation.initial();
        }
        
        // 计算各维度信号
        double recentAccuracy = computeRecentAccuracy(recentObservations);
        double avgResponseTimeRatio = computeAvgResponseTimeRatio(recentObservations);
        double avgModificationRate = computeAvgModificationRate(recentObservations);
        double trendAccuracy = computeAccuracyTrend(recentObservations); // 正/负趋势
        double trendResponseTime = computeResponseTimeTrend(recentObservations);
        
        CognitiveState state;
        double confidence;
        String reason;
        
        // --- 挫败检测 ---
        if (recentAccuracy < 0.30 && trendAccuracy <= 0) {
            state = CognitiveState.FRUSTRATED;
            confidence = 0.85;
            reason = String.format("最近%d题正确率仅%.0f%%，呈下降趋势", 
                recentObservations.size(), recentAccuracy * 100);
        }
        // --- 焦虑检测 ---
        else if (avgModificationRate > 2.0 && avgResponseTimeRatio > 1.5) {
            state = CognitiveState.ANXIOUS;
            confidence = 0.75;
            reason = String.format("平均修改答案%.1f次，响应时间比%.1f，表现犹豫", 
                avgModificationRate, avgResponseTimeRatio);
        }
        // --- 无聊检测 ---
        else if (recentAccuracy > 0.90 && avgResponseTimeRatio < 0.5 
                 && trendResponseTime < 0) {
            state = CognitiveState.BORED;
            confidence = 0.70;
            reason = String.format("正确率%.0f%%且响应极快(%.0f%%正常时间)，可能过于简单", 
                recentAccuracy * 100, avgResponseTimeRatio * 100);
        }
        // --- 疲劳检测 ---
        else if (trendResponseTime > 0.3 && trendAccuracy < -0.1 
                 && abilityEstimator.getUncertainty() > 0.15) {
            state = CognitiveState.FATIGUED;
            confidence = 0.65;
            reason = "响应时间持续增长，正确率下降，能力估计波动增大";
        }
        // --- 心流状态 ---
        else {
            state = CognitiveState.FLOW;
            confidence = 0.80;
            reason = "难度与能力匹配，投入度正常";
        }
        
        // 融合外部认知负荷信号
        double adjustedEngagement = computeEngagement(
            state, recentAccuracy, avgResponseTimeRatio, cognitiveLoadFromExternal);
        
        return new CognitiveStateEvaluation(
            state, confidence, reason, adjustedEngagement, cognitiveLoadFromExternal);
    }
    
    /**
     * 响应时间比 = 实际时间 / 预期时间
     * < 0.6: 很快（可能太简单或猜的）
     * 0.6 ~ 1.5: 正常范围
     * > 1.5: 缓慢（可能太难或犹豫）
     */
    private double computeAvgResponseTimeRatio(List<AnswerObservation> obs) {
        return obs.stream()
            .mapToDouble(o -> (double) o.getResponseTimeSeconds() / o.getExpectedTimeSeconds())
            .average().orElse(1.0);
    }
    
    /**
     * 正确率趋势：前半段 vs 后半段
     * 正值 = 进步，负值 = 退步
     */
    private double computeAccuracyTrend(List<AnswerObservation> obs) {
        if (obs.size() < 4) return 0;
        int mid = obs.size() / 2;
        double firstHalf = obs.subList(0, mid).stream()
            .filter(AnswerObservation::isCorrect).count() / (double) mid;
        double secondHalf = obs.subList(mid, obs.size()).stream()
            .filter(AnswerObservation::isCorrect).count() / (double) (obs.size() - mid);
        return secondHalf - firstHalf;
    }
    
    private double computeResponseTimeTrend(List<AnswerObservation> obs) {
        if (obs.size() < 4) return 0;
        int mid = obs.size() / 2;
        double firstHalf = obs.subList(0, mid).stream()
            .mapToInt(AnswerObservation::getResponseTimeSeconds).average().orElse(0);
        double secondHalf = obs.subList(mid, obs.size()).stream()
            .mapToInt(AnswerObservation::getResponseTimeSeconds).average().orElse(0);
        return (secondHalf - firstHalf) / Math.max(firstHalf, 1);
    }
    
    private double computeAvgModificationRate(List<AnswerObservation> obs) {
        return obs.stream()
            .mapToInt(AnswerObservation::getAnswerModifications)
            .average().orElse(0);
    }
    
    private double computeEngagement(CognitiveState state, double accuracy, 
            double timeRatio, double externalLoad) {
        // 基础投入度
        double engagement = 0.8;
        
        engagement -= switch (state) {
            case FRUSTRATED -> 0.30;
            case ANXIOUS -> 0.20;
            case FATIGUED -> 0.25;
            case BORED -> 0.15;
            case FLOW -> 0.0;
        };
        
        // 外部认知负荷越高，有效投入度越低
        engagement -= externalLoad * 0.2;
        
        return Math.max(0.1, Math.min(1.0, engagement));
    }
}

/**
 * 自适应难度调节器
 */
public class DifficultyAdjuster {
    
    // 难度调节规则
    private static final int MAX_STEP_UP = 1;    // 单次最多升1档
    private static final int MAX_STEP_DOWN = 2;  // 单次最多降2档
    
    /**
     * 计算下一题的目标难度
     */
    public DifficultyAdjustment adjust(
            DifficultyTier currentDifficulty,
            CognitiveStateEvaluation cognitiveState,
            SessionAbilityEstimator ability,
            SessionGoal goal,
            int kpPracticeCount) {
        
        DifficultyTier target;
        String reason;
        
        double theta = ability.getAbilityEstimate();
        
        switch (cognitiveState.getState()) {
            case FLOW:
                // 心流状态：微调
                // 如果能力估计明显高于当前难度，考虑升档
                double difficultyMidpoint = (currentDifficulty.getLowerBound() 
                    + currentDifficulty.getUpperBound()) / 2;
                if (theta > currentDifficulty.getUpperBound() 
                        && kpPracticeCount >= 2
                        && ability.getRecentAccuracy() >= 0.85) {
                    target = DifficultyTier.of(Math.min(
                        currentDifficulty.getCode() + 1, 5));
                    reason = "连续高正确率，能力高于当前难度，升档挑战";
                } else {
                    target = currentDifficulty;
                    reason = "维持当前难度，学生处于心流状态";
                }
                break;
                
            case FRUSTRATED:
                // 挫败：立即降档
                int drop = cognitiveState.getConfidence() > 0.8 ? 2 : 1;
                target = DifficultyTier.of(Math.max(
                    currentDifficulty.getCode() - drop, 1));
                reason = String.format("检测到挫败信号(置信度%.0f%%)，降%d档", 
                    cognitiveState.getConfidence() * 100, 
                    currentDifficulty.getCode() - target.getCode());
                break;
                
            case BORED:
                // 无聊：升档
                target = DifficultyTier.of(Math.min(
                    currentDifficulty.getCode() + 1, 5));
                reason = "正确率过高且响应极快，升档增加挑战";
                break;
                
            case ANXIOUS:
                // 焦虑：降档但不大幅变化
                target = DifficultyTier.of(Math.max(
                    currentDifficulty.getCode() - 1, 1));
                reason = "检测到焦虑信号（犹豫/频繁修改），降1档缓解";
                break;
                
            case FATIGUED:
                // 疲劳：维持难度（降难度会让简单题的疲劳感更强）
                target = currentDifficulty;
                reason = "检测到疲劳信号，维持当前难度";
                break;
                
            default:
                target = currentDifficulty;
                reason = "默认维持";
        }
        
        // 目标导向微调
        if (goal == SessionGoal.BREAKTHROUGH && cognitiveState.getState() == CognitiveState.FLOW) {
            // 薄弱突破模式：在心流时更积极升档
            target = DifficultyTier.of(Math.min(target.getCode() + 0, 5));
        } else if (goal == SessionGoal.REINFORCE && cognitiveState.getState() == CognitiveState.FLOW) {
            // 巩固模式：不急于升档
            if (target.getCode() > currentDifficulty.getCode()) {
                target = currentDifficulty;
                reason = "巩固模式：维持难度反复强化";
            }
        }
        
        return new DifficultyAdjustment(target, reason, 
            target.getCode() - currentDifficulty.getCode());
    }
}

/**
 * 知识点切换决策器
 * 决定是否切换到下一个目标知识点，或穿插复习题
 */
public class KnowledgePointSwitcher {
    
    // 间隔重复穿插频率：每N题穿插1道复习题
    private static final int INTERLEAVE_INTERVAL = 4;
    
    /**
     * 决定下一题的知识点
     */
    public KnowledgePointDecision decide(
            String currentKpId,
            List<TargetKp> targetKps,
            int currentKpIndex,
            Map<String, Integer> kpPracticeCount,
            Map<String, Integer> kpCorrectCount,
            Map<String, Double> kpMasterySnapshot,
            SessionAbilityEstimator ability,
            CognitiveStateEvaluation cognitiveState,
            List<DueReviewItem> dueReviewItems,
            int totalAnswered) {
        
        // --- 1. 间隔重复穿插 ---
        // 每 INTERLEAVE_INTERVAL 题检查是否有到期复习项
        if (totalAnswered > 0 && totalAnswered % INTERLEAVE_INTERVAL == 0 
                && !dueReviewItems.isEmpty()
                && cognitiveState.getState() != CognitiveState.FRUSTRATED) {
            DueReviewItem review = dueReviewItems.get(0);
            return KnowledgePointDecision.interleave(review);
        }
        
        // --- 2. 当前KP完成度检查 ---
        int currCount = kpPracticeCount.getOrDefault(currentKpId, 0);
        int currCorrect = kpCorrectCount.getOrDefault(currentKpId, 0);
        double currMastery = kpMasterySnapshot.getOrDefault(currentKpId, 0.5);
        double currAccuracy = currCount > 0 ? (double) currCorrect / currCount : 0;
        
        // 条件A：掌握度达标
        if (currMastery >= 0.85 && currCount >= 3) {
            return moveToNextKp(currentKpId, targetKps, currentKpIndex, 
                "掌握度达标(≥85%)，切换到下一个知识点");
        }
        
        // 条件B：连续3题全对且掌握度提升明显
        if (currCount >= 3 && currAccuracy == 1.0 
                && currMastery - getInitialMastery(targetKps, currentKpId) >= 0.15) {
            return moveToNextKp(currentKpId, targetKps, currentKpIndex, 
                "连续3题全对且掌握度显著提升，切换知识点");
        }
        
        // 条件C：练习过多仍未改善 → 放弃当前KP
        if (currCount >= 8 && currMastery < 0.4) {
            return moveToNextKp(currentKpId, targetKps, currentKpIndex, 
                "练习8题仍未改善，暂时切换，稍后再回");
        }
        
        // 条件D：严重挫败 → 立即切换到更简单的KP
        if (cognitiveState.getState() == CognitiveState.FRUSTRATED 
                && currAccuracy < 0.2 && currCount >= 3) {
            // 寻找一个掌握度较高的KP来恢复信心
            TargetKp easier = findEasiestRemainingKp(targetKps, currentKpIndex, kpMasterySnapshot);
            if (easier != null) {
                return KnowledgePointDecision.switchTo(
                    easier.getKpId(), "挫败保护：切换到较容易的知识点恢复信心");
            }
        }
        
        // --- 3. 继续当前KP ---
        return KnowledgePointDecision.continueCurrent(currentKpId);
    }
    
    private KnowledgePointDecision moveToNextKp(
            String currentKpId, List<TargetKp> targetKps, 
            int currentIndex, String reason) {
        if (currentIndex + 1 < targetKps.size()) {
            TargetKp next = targetKps.get(currentIndex + 1);
            return KnowledgePointDecision.switchTo(next.getKpId(), reason);
        }
        // 所有目标KP已完成
        return KnowledgePointDecision.allCompleted(reason);
    }
    
    private TargetKp findEasiestRemainingKp(
            List<TargetKp> targetKps, int currentIndex,
            Map<String, Double> masterySnapshot) {
        return targetKps.stream()
            .skip(currentIndex + 1)
            .max(Comparator.comparingDouble(kp -> 
                masterySnapshot.getOrDefault(kp.getKpId(), 0.5)))
            .orElse(null);
    }
    
    private double getInitialMastery(List<TargetKp> targetKps, String kpId) {
        return targetKps.stream()
            .filter(kp -> kp.getKpId().equals(kpId))
            .findFirst()
            .map(TargetKp::getInitialMastery)
            .orElse(0.5);
    }
}

#### 4.6.2 选题打分器

```java
/**
 * 候选题综合打分器
 * 
 * 综合得分 = w1*难度匹配 + w2*区分度 + w3*新颖度 + w4*时间合适度 + w5*KP匹配
 */
public class QuestionScorer {
    
    // 权重配置（可根据会话目标动态调整）
    private final ScoringWeights weights;
    
    public QuestionScore score(CandidateQuestion question, 
            ScoringContext context) {
        
        // 1. 难度匹配度：目标难度对应的难度系数区间得分
        double difficultyScore = computeDifficultyFit(
            question.getDifficultyCoefficient(), 
            context.getTargetDifficulty());
        
        // 2. 区分度：区分度高的题更有诊断价值
        double discriminationScore = Math.min(question.getDiscriminationIndex() / 1.5, 1.0);
        
        // 3. 新颖度：学生近期是否做过（越久没做越好）
        double noveltyScore = computeNovelty(question.getId(), context.getRecentQuestionIds());
        
        // 4. 时间合适度：预估时间与会话剩余时间的契合度
        double timeFitScore = computeTimeFit(
            question.getAvgTimeSeconds(), 
            context.getRemainingTimeSeconds());
        
        // 5. 知识点匹配度：是否是当前正在练习的知识点
        double kpMatchScore = question.getKnowledgePointId()
            .equals(context.getCurrentKpId()) ? 1.0 : 0.3;
        
        // 综合得分
        double total = weights.wDifficulty * difficultyScore
                     + weights.wDiscrimination * discriminationScore
                     + weights.wNovelty * noveltyScore
                     + weights.wTimeFit * timeFitScore
                     + weights.wKpMatch * kpMatchScore;
        
        return new QuestionScore(question, total, 
            difficultyScore, discriminationScore, noveltyScore, timeFitScore, kpMatchScore);
    }
    
    private double computeDifficultyFit(double actualDiff, DifficultyTier target) {
        double targetMid = (target.getLowerBound() + target.getUpperBound()) / 2;
        double distance = Math.abs(actualDiff - targetMid);
        // 高斯衰减
        return Math.exp(-distance * distance / 0.02);
    }
    
    private double computeNovelty(Long questionId, Set<Long> recentIds) {
        if (recentIds == null || !recentIds.contains(questionId)) return 1.0;
        // 近期做过，降分
        return 0.1;
    }
    
    private double computeTimeFit(int estimatedTime, Integer remainingTime) {
        if (remainingTime == null || remainingTime <= 0) return 1.0;
        // 题目时间不应超过剩余时间的50%
        double ratio = (double) estimatedTime / remainingTime;
        if (ratio < 0.5) return 1.0;
        return Math.max(0, 1.0 - (ratio - 0.5) * 2);
    }
    
    /**
     * 权重配置
     */
    public static class ScoringWeights {
        private double wDifficulty = 0.35;
        private double wDiscrimination = 0.15;
        private double wNovelty = 0.20;
        private double wTimeFit = 0.10;
        private double wKpMatch = 0.20;
        
        public static ScoringWeights forGoal(SessionGoal goal) {
            ScoringWeights w = new ScoringWeights();
            switch (goal) {
                case BREAKTHROUGH -> {
                    w.wDifficulty = 0.40; // 薄弱突破更关注难度精确匹配
                    w.wDiscrimination = 0.20;
                    w.wKpMatch = 0.15;
                }
                case REINFORCE -> {
                    w.wKpMatch = 0.30; // 巩固更关注知识点聚焦
                    w.wDifficulty = 0.25;
                }
                case MIXED_REVIEW -> {
                    w.wNovelty = 0.35; // 混合复习更关注多样性
                    w.wKpMatch = 0.05;

                    w.wNovelty = 0.40; // 自由探索最重新颖
                    w.wDifficulty = 0.20;

/**
 * 会话结束判定器
 */
public class SessionEndDetector {
    
    public SessionEndDecision check(NextQuestionRequest request,
            RtaqsSessionContext ctx,
            SessionAbilityEstimator ability,
            CognitiveStateEvaluation cognitiveState) {
        
        // 硬性条件
        if (ctx.getTotalAnswered() >= ctx.getMaxQuestions()) {
            return SessionEndDecision.end("已达到本次练习最大题数");
        }
        
        if (request.getConstraint() != null 
                && request.getConstraint().getRemainingTimeSeconds() != null
                && request.getConstraint().getRemainingTimeSeconds() < 30) {
            return SessionEndDecision.end("剩余时间不足30秒");
        }
        
        // 所有目标知识点已达标
        if (allTargetKpsMastered(ctx)) {
            return SessionEndDecision.end("所有目标知识点已达标，练习完成");
        }
        
        // 保护性退出（仅当已达到最小题数）
        if (ctx.getTotalAnswered() >= ctx.getMinQuestions()) {
            
            // 连续5题正确率低于20%
            if (ability.getRecentAccuracy() < 0.20 
                    && ctx.getTotalAnswered() - ctx.getMinQuestions() >= 5) {
                return SessionEndDecision.end(
                    "连续正确率过低(" + String.format("%.0f%%", ability.getRecentAccuracy() * 100) 
                    + ")，建议先复习基础知识", true /* suggestReview */);
            }
            
            // 严重疲劳
            if (cognitiveState.getState() == CognitiveState.FATIGUED 
                    && cognitiveState.getConfidence() > 0.7
                    && ctx.getTotalAnswered() >= ctx.getMinQuestions() + 3) {
                return SessionEndDecision.end("检测到学习疲劳，建议休息后再练");
            }
            
            // 学生主动退出由客户端控制，此处不处理
        }
        
        return SessionEndDecision.continueSession();
    }
    
    private boolean allTargetKpsMastered(RtaqsSessionContext ctx) {
        Map<String, Double> snapshot = ctx.getKpMasterySnapshot();
        return ctx.getTargetKps().stream()
            .allMatch(kp -> snapshot.getOrDefault(kp.getKpId(), 0.0) >= 0.85);
    }
}

## 6. 服务实现

### 6.1 核心服务类

```java
/**
 * RTAQS 核心服务
 */
@Service
@Slf4j
public class RtaqsService {
    
    @Autowired private RtaqsSessionContextMapper sessionContextMapper;
    @Autowired private RtaqsDecisionLogMapper decisionLogMapper;
    @Autowired private CandidateQuestionRepository candidateRepo;
    @Autowired private KnowledgeTracingClient ktClient;
    @Autowired private SpacedRepetitionClient srClient;
    @Autowired private CognitiveLoadClient cognitiveLoadClient;
    @Autowired private QuestionScorer questionScorer;
    @Autowired private DifficultyAdjuster difficultyAdjuster;
    @Autowired private CognitiveStateEvaluator cognitiveStateEvaluator;
    @Autowired private KnowledgePointSwitcher kpSwitcher;
    @Autowired private SessionEndDetector endDetector;
    
    /**
     * 核心方法：获取下一题（实时选题决策）
     */
    @Transactional
    public NextQuestionResponse getNextQuestion(NextQuestionRequest request) {
        // 1. 加载会话上下文
        RtaqsSessionContext ctx = sessionContextMapper
            .selectBySessionId(request.getSessionId());
        if (ctx == null) {
            throw new BizException(ErrorCode.SESSION_NOT_FOUND);
        }
        if (!"ACTIVE".equals(ctx.getStatus())) {
            throw new BizException(ErrorCode.SESSION_NOT_ACTIVE);
        }
        
        // 2. 重建能力估计器（从持久化状态恢复）
        SessionAbilityEstimator estimator = new SessionAbilityEstimator(
            ctx.getCurrentAbility(), 0.6);
        
        // 3. 如果有答题结果，更新能力估计
        AnswerResult lastResult = request.getLastResult();
        if (lastResult != null) {
            AnswerObservation obs = toObservation(lastResult);
            estimator.update(obs);
            
            // 同步更新知识点掌握度（调用知识追踪模型）
            ktClient.recordAttempt(ctx.getUserId(), 
                lastResult.getKnowledgePointId(), 
                lastResult.getIsCorrect(), 
                lastResult.getQuestionId(),
                request.getSessionId());
        }
        
        // 4. 获取外部信号
        double cognitiveLoad = cognitiveLoadClient
            .getCurrentLoad(ctx.getUserId());
        List<DueReviewItem> dueReviews = srClient
            .getDueReviews(ctx.getUserId(), ctx.getSubjectCode(), 3);
        
        // 5. 认知状态评估
        List<AnswerObservation> recentObs = getRecentObservations(ctx);
        CognitiveStateEvaluation cognitiveState = cognitiveStateEvaluator
            .evaluate(recentObs, estimator, cognitiveLoad);
        
        // 6. 难度调节
        DifficultyAdjustment diffAdjust = difficultyAdjuster.adjust(
            DifficultyTier.of(ctx.getCurrentDifficulty()),
            cognitiveState, estimator, 
            SessionGoal.valueOf(ctx.getSessionGoal()),
            getKpPracticeCount(ctx, ctx.getTargetKps()
                .get(ctx.getCurrentKpIndex()).getKpId()));
        
        // 7. 知识点切换决策
        String currentKpId = ctx.getTargetKps()
            .get(ctx.getCurrentKpIndex()).getKpId();
        KnowledgePointDecision kpDecision = kpSwitcher.decide(
            currentKpId, ctx.getTargetKps(), ctx.getCurrentKpIndex(),
            parseKpCount(ctx.getKpPracticeCount()),
            parseKpCount(ctx.getKpCorrectCount()),
            parseKpMastery(ctx.getKpMasterySnapshot()),
            estimator, cognitiveState, dueReviews,
            ctx.getTotalAnswered());
        
        // 8. 候选检索 + 选题打分
        Long selectedQuestionId = null;
        QuestionSource source = QuestionSource.POOL;
        
        if (kpDecision.isInterleave()) {
            // 穿插复习题
            selectedQuestionId = kpDecision.getReviewItem().getQuestionId();
            source = QuestionSource.INTERLEAVE;
        } else if (kpDecision.isContinue()) {
            // 继续当前KP，从候选池选择
            selectedQuestionId = selectFromPool(
                currentKpId, diffAdjust.getTargetDifficulty(),
                ctx, request.getConstraint());
        } else if (kpDecision.isSwitch()) {
            // 切换到新KP
            selectedQuestionId = selectFromPool(
                kpDecision.getNewKpId(), diffAdjust.getTargetDifficulty(),
                ctx, request.getConstraint());
            if (selectedQuestionId != null) {
                ctx.setCurrentKpIndex(findKpIndex(ctx, kpDecision.getNewKpId()));
            }
        }
        
        // 9. 兜底：种子列表或随机
        if (selectedQuestionId == null) {
            selectedQuestionId = fallbackSelect(ctx);
            source = QuestionSource.FALLBACK;
        }
        
        // 10. 更新会话上下文
        ctx.setCurrentAbility(BigDecimal.valueOf(estimator.getAbilityEstimate()));
        ctx.setCurrentDifficulty(diffAdjust.getTargetDifficulty().getCode());
        ctx.setCognitiveState(cognitiveState.getState().name());
        ctx.setCognitiveLoad(BigDecimal.valueOf(cognitiveState.getExternalLoad()));
        ctx.setEngagementScore(BigDecimal.valueOf(cognitiveState.getEngagement()));
        appendUsedQuestion(ctx, selectedQuestionId);
        incrementKpCount(ctx, 
            kpDecision.isInterleave() ? currentKpId : 
                (kpDecision.getNewKpId() != null ? kpDecision.getNewKpId() : currentKpId),
            lastResult != null && lastResult.getIsCorrect());
        updateKpMasterySnapshot(ctx);
        sessionContextMapper.updateById(ctx);
        
        // 11. 会话结束判定
        SessionEndDecision endDecision = endDetector.check(
            request, ctx, estimator, cognitiveState);
        
        // 12. 记录决策日志
        logDecision(ctx, request, lastResult, estimator, cognitiveState,
            diffAdjust, kpDecision, selectedQuestionId, source);
        
        // 13. 生成自适应反馈语
        String feedback = generateAdaptiveFeedback(
            cognitiveState, lastResult, diffAdjust);
        
        // 14. 构建响应
        return buildResponse(selectedQuestionId, source, 
            kpDecision, diffAdjust, estimator, cognitiveState,
            ctx, endDecision, feedback);
    }
    
    /**
     * 从候选池中选择最优题目
     */
    private Long selectFromPool(String kpId, DifficultyTier targetDiff,
            RtaqsSessionContext ctx, ClientConstraint constraint) {
        // 检索候选
        List<CandidateQuestion> candidates = candidateRepo.findCandidates(
            new CandidateQuery(kpId, ctx.getSubjectCode(),
                targetDiff, getQuestionTypes(constraint),
                parseUsedIds(ctx.getUsedQuestionIds()), 50));
        
        if (candidates.isEmpty()) {
            // 扩大难度范围重试
            candidates = candidateRepo.findCandidates(
                new CandidateQuery(kpId, ctx.getSubjectCode(),
                    DifficultyTier.of(Math.max(1, targetDiff.getCode() - 1)),
                    getQuestionTypes(constraint),
                    parseUsedIds(ctx.getUsedQuestionIds()), 50));
        }
        
        if (candidates.isEmpty()) return null;
        
        // 打分排序
        ScoringWeights weights = ScoringWeights.forGoal(
            SessionGoal.valueOf(ctx.getSessionGoal()));
        ScoringContext scoreCtx = new ScoringContext(
            targetDiff, kpId, parseUsedIds(ctx.getUsedQuestionIds()),
            constraint != null ? constraint.getRemainingTimeSeconds() : null);
        
        return candidates.stream()
            .map(q -> questionScorer.score(q, scoreCtx))
            .max(Comparator.comparingDouble(QuestionScore::getTotalScore))
            .map(qs -> qs.getQuestion().getId())
            .orElse(null);
    }
    
    /**
     * 兜底选题策略
     */
    private Long fallbackSelect(RtaqsSessionContext ctx) {
        // 优先从种子列表中选未用过的
        List<Long> seeds = parseSeedIds(ctx.getSeedQuestionIds());
        Set<Long> used = parseUsedIds(ctx.getUsedQuestionIds());
        
        return seeds.stream()
            .filter(id -> !used.contains(id))
            .findFirst()
            .orElseGet(() -> {
                // 最后兜底：从题库随机选一题
                return candidateRepo.findRandomBySubject(
                    ctx.getSubjectCode(), used);
            });
    }
    
    /**
     * 生成自适应反馈语
     */
    private String generateAdaptiveFeedback(
            CognitiveStateEvaluation state, 
            AnswerResult lastResult,
            DifficultyAdjustment diffAdjust) {
        if (lastResult == null) return null;
        
        // 根据认知状态和答题结果生成鼓励语
        return switch (state.getState()) {
            case FRUSTRATED -> lastResult.getIsCorrect() 
                ? "太棒了！你看，换种思路就对了。继续保持！🌟"
                : "没关系，这道题确实不容易。我们来试一道简单点的，一步步来。💪";
            case BORED -> lastResult.getIsCorrect()
                ? "做得好！看来这个知识点你已经掌握了，我们加点挑战？🚀"
                : null;
            case ANXIOUS -> "深呼吸，慢慢来。每一步思考都在进步。🌿";
            case FATIGUED -> "你已经练习很多了，做一道简单题放松一下吧。😊";
            case FLOW -> lastResult.getIsCorrect()
                ? "答对了！状态很好，继续！✨"
                : "差一点点！再仔细看看条件，你能找到正确答案的。";
        };
    }
    
    // --- 辅助方法 ---
    
    private AnswerObservation toObservation(AnswerResult result) {
        return new AnswerObservation(
            result.getQuestionId(),
            result.getKnowledgePointId(),
            result.getIsCorrect(),
            result.getQuestionDifficulty(),
            result.getResponseTimeSeconds(),
            estimateExpectedTime(result.getQuestionDifficulty()),
            result.getHintUsed(),
            result.getAnswerModifications()
        );
    }
    
    private int estimateExpectedTime(DifficultyTier difficulty) {
        return switch (difficulty) {
            case D1_BASIC -> 30;
            case D2_ELEMENTARY -> 45;
            case D3_INTERMEDIATE -> 60;
            case D4_ADVANCED -> 90;
            case D5_CHALLENGE -> 120;
        };
    }
    
    private void logDecision(RtaqsSessionContext ctx,
            NextQuestionRequest request, AnswerResult lastResult,
            SessionAbilityEstimator estimator,
            CognitiveStateEvaluation cognitiveState,
            DifficultyAdjustment diffAdjust,
            KnowledgePointDecision kpDecision,
            Long selectedQuestionId, QuestionSource source) {
        RtaqsDecisionLog logEntry = new RtaqsDecisionLog();
        logEntry.setSessionId(ctx.getSessionId());
        logEntry.setUserId(ctx.getUserId());
        logEntry.setDecisionSeq(ctx.getTotalAnswered());
        logEntry.setPreAbility(BigDecimal.valueOf(
            lastResult != null ? ctx.getCurrentAbility().doubleValue() : 0.5));
        logEntry.setPreDifficulty(ctx.getCurrentDifficulty());
        logEntry.setPreCognitiveState(ctx.getCognitiveState());
        if (lastResult != null) {
            logEntry.setLastQuestionId(lastResult.getQuestionId());
            logEntry.setLastIsCorrect(lastResult.getIsCorrect() ? 1 : 0);
            logEntry.setLastResponseTime(lastResult.getResponseTimeSeconds());
            logEntry.setLastHintUsed(lastResult.getHintUsed() ? 1 : 0);
            logEntry.setLastModifiedCount(lastResult.getAnswerModifications());
        }
        logEntry.setSelectedQuestionId(selectedQuestionId);
        logEntry.setSelectedDifficulty(diffAdjust.getTargetDifficulty().getCode());
        logEntry.setSelectedSource(source.name());
        logEntry.setDecisionReason(diffAdjust.getReason());
        logEntry.setStrategyUsed("BAYESIAN_DIFFICULTY_ADJUST");
        logEntry.setPostAbility(BigDecimal.valueOf(estimator.getAbilityEstimate()));
        logEntry.setPostDifficulty(diffAdjust.getTargetDifficulty().getCode());
        decisionLogMapper.insert(logEntry);
    }
    
    private List<AnswerObservation> getRecentObservations(RtaqsSessionContext ctx) {
        // 从决策日志中重建最近N次答题观察
        List<RtaqsDecisionLog> recentLogs = decisionLogMapper
            .selectRecentBySession(ctx.getSessionId(), 5);
        return recentLogs.stream()
            .filter(l -> l.getLastQuestionId() != null)
            .map(l -> new AnswerObservation(
                l.getLastQuestionId(),
                l.getPreKpId(),
                l.getLastIsCorrect() != null && l.getLastIsCorrect() == 1,
                DifficultyTier.of(l.getSelectedDifficulty() != null 
                    ? l.getSelectedDifficulty() : l.getPreDifficulty()),
                l.getLastResponseTime() != null ? l.getLastResponseTime() : 60,
                60,
                l.getLastHintUsed() != null && l.getLastHintUsed() == 1,
                l.getLastModifiedCount() != null ? l.getLastModifiedCount() : 0
            ))
            .collect(Collectors.toList());
    }
    
    private NextQuestionResponse buildResponse(
            Long questionId, QuestionSource source,
            KnowledgePointDecision kpDecision,
            DifficultyAdjustment diffAdjust,
            SessionAbilityEstimator estimator,
            CognitiveStateEvaluation cognitiveState,
            RtaqsSessionContext ctx,
            SessionEndDecision endDecision,
            String feedback) {
        NextQuestionResponse resp = new NextQuestionResponse();
        resp.setQuestionId(questionId);
        resp.setSource(source);
        resp.setKnowledgePointId(kpDecision.isInterleave() 
            ? kpDecision.getReviewItem().getKpId()
            : (kpDecision.getNewKpId() != null 
                ? kpDecision.getNewKpId() 
                : ctx.getTargetKps().get(ctx.getCurrentKpIndex()).getKpId()));
        resp.setSuggestedDifficulty(diffAdjust.getTargetDifficulty());
        resp.setKpSwitched(kpDecision.isSwitch());
        resp.setUpdatedAbility(BigDecimal.valueOf(estimator.getAbilityEstimate()));
        resp.setCognitiveState(cognitiveState.getState());
        resp.setEngagementScore(BigDecimal.valueOf(cognitiveState.getEngagement()));
        resp.setAdaptiveFeedback(feedback);
        resp.setRecommendEndSession(endDecision.shouldEnd());
        resp.setEndReason(endDecision.getReason());
        
        // 进度
        SessionProgress progress = new SessionProgress();
        progress.setAnsweredCount(ctx.getTotalAnswered());
        progress.setCorrectCount(ctx.getTotalCorrect());
        progress.setAccuracyRate(ctx.getTotalAnswered() > 0 
            ? (double) ctx.getTotalCorrect() / ctx.getTotalAnswered() : 0);
        progress.setCurrentKpIndex(ctx.getCurrentKpIndex());
        progress.setTotalTargetKps(ctx.getTargetKps().size());
        progress.setElapsedSeconds(ctx.getTotalTimeSeconds());
        resp.setProgress(progress);
        
        return resp;
    }
}

### 6.2 会话初始化服务

```java
/**
 * RTAQS 会话初始化服务
 */
@Service
public class RtaqsInitService {
    
    @Autowired private RtaqsSessionContextMapper sessionContextMapper;
    @Autowired private KnowledgeTracingClient ktClient;
    @Autowired private RtaqsDecisionLogMapper decisionLogMapper;
    
    /**
     * 初始化自适应练习会话
     */
    @Transactional
    public InitResponse initSession(InitRequest request) {
        // 1. 获取各目标知识点的当前掌握度
        List<TargetKp> targetKps = new ArrayList<>();
        for (int i = 0; i < request.getTargetKpIds().size(); i++) {
            String kpId = request.getTargetKpIds().get(i);
            double mastery = ktClient.getMastery(request.getUserId(), kpId);
            double priority = (double) request.getTargetKpIds().size() - i;
            targetKps.add(new TargetKp(kpId, priority / request.getTargetKpIds().size(), mastery));
        }
        
        // 2. 确定初始难度
        double avgMastery = targetKps.stream()
            .mapToDouble(TargetKp::getInitialMastery)
            .average().orElse(0.5);
        DifficultyTier initialDiff = determineInitialDifficulty(avgMastery);
        
        // 3. 创建会话上下文
        RtaqsSessionContext ctx = new RtaqsSessionContext();
        ctx.setSessionId(request.getSessionId());
        ctx.setUserId(request.getUserId());
        ctx.setSubjectCode(request.getSubjectCode());
        ctx.setSessionGoal(request.getSessionGoal().name());
        ctx.setTargetKps(JsonUtils.toJson(targetKps));
        ctx.setSeedQuestionIds(JsonUtils.toJson(request.getSeedQuestionIds()));
        ctx.setCurrentAbility(BigDecimal.valueOf(avgMastery));
        ctx.setCurrentDifficulty(initialDiff.getCode());
        ctx.setDifficultyFloor(request.getDifficultyFloor());
        ctx.setDifficultyCeiling(request.getDifficultyCeiling());
        ctx.setMaxQuestions(request.getMaxQuestions());
        ctx.setMinQuestions(request.getMinQuestions());
        ctx.setStatus("ACTIVE");
        sessionContextMapper.insert(ctx);
        
        // 4. 记录初始决策
        RtaqsDecisionLog initLog = new RtaqsDecisionLog();
        initLog.setSessionId(request.getSessionId());
        initLog.setUserId(request.getUserId());
        initLog.setDecisionSeq(0);
        initLog.setDecisionType("INITIAL");
        initLog.setSelectedQuestionId(request.getSeedQuestionIds().get(0));
        initLog.setSelectedDifficulty(initialDiff.getCode());
        initLog.setStrategyUsed("PRIOR_MASTERY");
        initLog.setDecisionReason(String.format(
            "初始难度基于平均掌握度%.0f%%", avgMastery * 100));
        initLog.setPostAbility(BigDecimal.valueOf(avgMastery));
        initLog.setPostDifficulty(initialDiff.getCode());
        decisionLogMapper.insert(initLog);
        
        return new InitResponse(
            request.getSeedQuestionIds().get(0),
            initialDiff,
            avgMastery,
            targetKps
        );
    }
    
    private DifficultyTier determineInitialDifficulty(double mastery) {
        // 掌握度 < 0.3 → D1
        // 0.3 ~ 0.5 → D2
        // 0.5 ~ 0.7 → D3
        // 0.7 ~ 0.85 → D3（不在初始就给太难）
        // > 0.85 → D4
        if (mastery < 0.3) return DifficultyTier.D1_BASIC;
        if (mastery < 0.5) return DifficultyTier.D2_ELEMENTARY;
        if (mastery < 0.85) return DifficultyTier.D3_INTERMEDIATE;
        return DifficultyTier.D4_ADVANCED;
    }
}
