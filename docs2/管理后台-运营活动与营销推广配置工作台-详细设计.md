# 管理后台 - 运营活动与营销推广配置工作台 详细设计

## 1. 概述

### 1.1 模块定位

运营活动与营销推广配置工作台是 PrimeTop 管理后台的核心运营模块之一，为运营团队、市场团队和增长团队提供统一的可视化操作界面，用于创建、配置、发布和管理各类运营活动、营销推广、优惠券、App 弹窗 Banner、推送通知、增长激励任务及裂变邀请方案。

本工作台是对后端已有运营引擎（运营活动引擎、优惠券引擎、积分引擎、弹窗规则引擎、推送通道适配层、增长自动化引擎）的前端编排层，将分散的服务端能力聚合为运营人员可直接操作的「活动生产线」。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 统一入口 | 将活动、优惠券、Banner、推送、增长任务、裂变配置归入一个工作台 |
| 可视化编排 | 所见即所得的活动页面编辑、Banner 预览、推送文案预览 |
| 安全发布 | 多级审核 + 定时发布 + 一键下线 + 灰度放量 |
| 效果可量化 | 内嵌活动数据看板，ROI、参与率、转化率实时可见 |
| 权限分离 | 运营编辑 → 审核 → 发布 全链路权限管控 |

### 1.3 适用范围

| 角色 | 使用场景 |
| --- | --- |
| 运营专员 | 日常创建活动、配置优惠券、编辑 Banner |
| 运营主管 | 审核活动方案、控制发布节奏 |
| 市场推广 | 配置裂变邀请方案、渠道追踪 |
| 增长产品 | 配置增长任务、A/B 实验方案 |
| 数据分析 | 查看活动效果、导出报表 |

### 1.4 依赖关系

```
本工作台（前端）
    │
    ├── 运营内容管理与活动配置引擎（活动 CRUD + 页面模板）
    ├── 优惠券与促销活动引擎（券生命周期）
    ├── 积分获取规则计算与虚拟资产交易结算服务（积分/奖励发放）
    ├── 运营弹窗规则引擎（弹窗触发规则）
    ├── 统一通知消息模板引擎（推送/短信/站内信）
    ├── 多厂商推送通道适配层（推送投递）
    ├── 邀请裂变与用户增长服务（裂变方案）
    ├── 用户标签与智能分群引擎（目标人群圈选）
    ├── AB测试与实验平台（分流策略）
    └── 统一文件生成与异步报表导出中心服务（报表导出）
```

## 3. 数据模型设计

### 3.1 运营活动 (ops_campaign)

```sql
CREATE TABLE ops_campaign (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    campaign_no     VARCHAR(32) NOT NULL UNIQUE COMMENT '活动编号 OPS+YYYYMMDD+序号',
    title           VARCHAR(128) NOT NULL COMMENT '活动标题',
    subtitle        VARCHAR(256) DEFAULT NULL COMMENT '副标题',
    type            VARCHAR(32) NOT NULL COMMENT '活动类型: LEARNING_CHALLENGE|SEASONAL|EXAM_SPRINT|HOLIDAY_CAMP|PROMOTION|NEW_USER_GUIDE',
    status          VARCHAR(16) NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT|PENDING_REVIEW|APPROVED|SCHEDULED|LIVE|PAUSED|ENDED|ARCHIVED',
    description     TEXT COMMENT '活动描述',
    cover_image     VARCHAR(512) COMMENT '封面图 URL',
    start_at        DATETIME NOT NULL COMMENT '开始时间',
    end_at          DATETIME NOT NULL COMMENT '结束时间',
    target_segment  JSON COMMENT '目标人群标签 JSON: {grade:[], stage:[], tags:[], user_type:[]}',
    page_config     JSON COMMENT '活动页面 JSON 配置（驱动客户端动态渲染）',
    reward_config   JSON COMMENT '奖励配置: {points:Int, coupon_batch_ids:[], badge_id:Int, virtual_items:[]}',
    display_config  JSON COMMENT '展示配置: {banner_positions:[], popup_enabled:Bool, feed_priority:Int}',
    ab_experiment_id BIGINT DEFAULT NULL COMMENT '关联 A/B 实验 ID',
    budget          DECIMAL(12,2) DEFAULT 0 COMMENT '活动预算（元）',
    actual_cost     DECIMAL(12,2) DEFAULT 0 COMMENT '实际消耗（元）',
    priority        INT DEFAULT 50 COMMENT '优先级 1-100, 越大越优先',
    created_by      BIGINT NOT NULL COMMENT '创建人 ID',
    reviewed_by     BIGINT DEFAULT NULL COMMENT '审核人 ID',
    reviewed_at     DATETIME DEFAULT NULL COMMENT '审核时间',
    review_comment  VARCHAR(512) DEFAULT NULL COMMENT '审核意见',
    published_at    DATETIME DEFAULT NULL COMMENT '发布时间',
    published_by    BIGINT DEFAULT NULL COMMENT '发布人 ID',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_status (status),
    INDEX idx_type_start (type, start_at),
    INDEX idx_date_range (start_at, end_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='运营活动表';
```

## 4. 活动状态流转

### 4.1 运营活动状态机

```
    ┌─────────┐  submit   ┌────────────────┐  approve  ┌───────────┐  schedule  ┌───────────┐
    │  DRAFT  │ ────────► │ PENDING_REVIEW │ ────────► │ APPROVED  │ ─────────► │ SCHEDULED │
    └─────────┘           └────────────────┘           └───────────┘            └───────────┘
         │                       │                          │                         │
         │                       │ reject                   │                         │ to=start_at
         │                       ▼                          │ cancel                  ▼
         │                  ┌─────────┐                     │                  ┌───────┐
         │                  │ REJECTED │                    │                  │ LIVE  │
         │                  └─────────┘                     │                  └───────┘
         │                       │                          │                    │   │
         └─── edit ──────────────┘                          │              pause  │   │ to=end_at
                                                          cancel│                  ▼   ▼
                                                                ▼             ┌──────────┐ ┌───────┐
                                                          ┌──────────┐       │  PAUSED  │ │ ENDED │
                                                          │ CANCELLED│       └──────────┘ └───────┘
                                                          └──────────┘            │             │
                                                                 resume           │             │ archive
                                                                 ▼                │             ▼
                                                             ┌───────┐          │      ┌──────────┐
                                                             │ LIVE  │◄─────────┘      │ARCHIVED  │
                                                             └───────┘                └──────────┘
```

| 状态 | 含义 | 允许操作 |
| --- | --- | --- |
| `DRAFT` | 草稿，编辑中 | 编辑、提交审核、删除 |
| `PENDING_REVIEW` | 待审核 | 审核（通过/驳回/要求修改） |
| `REJECTED` | 已驳回 | 修改后重新提交、归档 |
| `APPROVED` | 已审核通过 | 设置定时发布、立即发布、取消 |
| `SCHEDULED` | 已排期 | 取消发布 |
| `LIVE` | 上线中 | 暂停、强制下线 |
| `PAUSED` | 已暂停 | 恢复、强制下线 |
| `ENDED` | 已结束（到达 end_at） | 归档 |
| `CANCELLED` | 已取消 | 归档 |
| `ARCHIVED` | 已归档（只读） | 无 |

### 4.2 优惠券批次状态机

```
DRAFT ──activate──► ACTIVE ──quantity=0──► EXHAUSTED
                       │                       │
                       │ disable            expire
                       ▼                       ▼
                   DISABLED                EXPIRED
```

### 4.3 推送任务状态机

```
DRAFT ──submit──► PENDING_REVIEW ──approve──► APPROVED ──trigger──► SENDING ──done──► SENT
                       │                       │                                              │
                    reject                  cancel                                      cancelled
                       │                       │
                       ▼                       ▼
                   DRAFT                  CANCELLED                              CANCELLED
                                                                              ▲
                                                                       ┌──────┘
                                                                  FAILED ──retry──► SENDING
```

## 5. API 接口设计

### 5.1 通用约定

```
Base URL: /api/admin/v1/ops
Content-Type: application/json
Auth: Bearer {admin_token}
Permission: 需 ops:* 相关权限
```

统一响应格式：

```json
{
    "code": 0,
    "message": "success",
    "data": { ... },
    "timestamp": 1721635200000

```
?page=1&page_size=20&sort=created_at:desc

#### 活动操作

```
POST /campaigns/:id/submit      # 提交审核
POST /campaigns/:id/approve     # 审核通过 (需审核权限)
POST /campaigns/:id/reject      # 驳回 (body: {comment: "..."})
POST /campaigns/:id/publish     # 发布上线 (可指定 {scheduled_at: "..."})
POST /campaigns/:id/pause       # 暂停
POST /campaigns/:id/resume      # 恢复
POST /campaigns/:id/cancel      # 取消
POST /campaigns/:id/archive     # 归档
POST /campaigns/:id/duplicate   # 复制为新草稿
```

#### 活动详情（含实时数据）

```
GET /campaigns/:id/detail
```
