# 客户端-全局运营弹窗与消息浮窗调度系统 - 详细设计

> 版本：v1.0 | 创建日期：2026-05-29 | 状态：初稿

---

## 1. 概述

### 1.1 背景

PrimeTop 作为面向全学段的商业教育 App，在日常运营中需要通过弹窗和浮窗触达用户，传递版本升级提示、运营活动推广、系统公告、学习提醒、会员权益引导、评分邀请等信息。若无统一调度机制，各类弹窗将在页面间无序弹出，造成用户体验混乱、弹窗互相遮挡、关键信息被遗漏等问题。

### 1.2 设计目标

1. **统一管理**：所有弹窗和浮窗由一个调度中心统一管理，确保同一时刻只有一个弹窗/浮窗处于活动状态（或按规则共存）。
2. **优先级可控**：高优先级弹窗（如强制升级）可中断低优先级弹窗（如运营活动）。
3. **展示规则灵活**：支持按用户画像、时间段、频次上限、页面范围、学段等多维度控制展示条件。
4. **服务端可配**：运营人员可在后台动态配置弹窗内容和规则，无需发版。
5. **数据可追踪**：每次弹窗的曝光、点击、关闭均产生埋点，支持效果分析。
6. **性能友好**：弹窗资源预加载，不阻塞主页面渲染。

### 1.3 适用范围

- Flutter 客户端（Android / iOS）
- 配合服务端弹窗配置管理后台使用

## 2. 术语定义

| 术语 | 说明 |
|------|------|
| Popup | 全屏或半屏模态弹窗，阻断用户操作 |
| Float | 非模态浮窗（如右上角消息气泡、底部 Snackbar），不阻断操作 |
| Slot | 弹窗展示的时机槽位（如 App启动后、页面切入后、特定事件触发后） |
| PopupRule | 弹窗展示规则，包含频次、定向、条件等约束 |
| PopupQueue | 弹窗等待队列，按优先级排序 |
| PopupSlot | 弹窗占位，一个 Slot 一次只展示一个 Popup |
| Impression | 曝光事件，弹窗展示给用户即计一次 |

## 3. 弹窗分类体系

### 3.1 按类型分类

```
PopupType (枚举)
├── FORCE_UPGRADE      // 强制升级弹窗（不可关闭，最高优先级）
├── SOFT_UPGRADE       // 建议升级弹窗（可关闭，可设置"不再提醒"）
├── ANNOUNCEMENT       // 系统公告（服务端下发，可设为必读）
├── OPERATION          // 运营活动（促销、打卡活动、限时优惠等）
├── MEMBERSHIP_GUIDE   // 会员引导（试用到期提醒、权益介绍）
├── RATE_APP           // 应用评分邀请
├── PERMISSION_REQUEST // 系统权限申请（相机、麦克风、通知等）
├── TUTORIAL           // 新功能教学引导（首次使用时触发）
├── STUDY_REMINDER     // 学习提醒（今日任务未完成、错题待复习）
└── CUSTOM             // 自定义弹窗（预留扩展）
```

### 3.2 按展示形式分类

| 展示形式 | 说明 | 是否模态 | 示例 |
|----------|------|----------|------|
| FullScreen | 全屏弹窗 | 是 | 活动推广页、首次引导 |
| CenterDialog | 居中对话框 | 是 | 升级提示、确认操作 |
| BottomSheet | 底部弹出面板 | 是 | 权限申请、功能介绍 |
| TopBanner | 顶部横幅 | 否 | 系统公告条 |
| FloatingBubble | 浮动气泡 | 否 | AI助手入口、学习提醒 |
| Snackbar | 底部轻提示 | 否 | 操作反馈、短暂提示 |
| Toast | 居中轻提示 | 否 | 成功/失败/警告 |

### 3.3 按触发时机（Slot）分类

```
PopupSlot (枚举)
├── APP_LAUNCH           // App 启动后（首页加载完成）
├── APP_RESUME           // App 从后台恢复
├── PAGE_ENTER           // 进入指定页面后
├── EVENT_TRIGGER        // 指定业务事件触发后
├── TIMER_SCHEDULE       // 定时触发（如每日首次打开）
├── AFTER_ACTION         // 用户完成某操作后（如完成答题）
└── IDLE_MOMENT          // 用户空闲时（如停留某页面超过 N 秒）
```

### 5.2 核心类设计

```dart
/// 弹窗调度中心 - 全局单例
class PopupScheduler {
  static final PopupScheduler _instance = PopupScheduler._();
  static PopupScheduler get instance => _instance;
  PopupScheduler._();

  final PopupStorage _storage = PopupStorage();
  final RuleEvaluator _ruleEvaluator = RuleEvaluator();
  final PopupQueue _queue = PopupQueue();
  final PopupPreloader _preloader = PopupPreloader();

  /// 当前正在展示的弹窗
  ActivePopup? _currentPopup;

  /// 是否已初始化
  bool _initialized = false;

  /// 初始化（App 启动时调用）
  Future<void> init() async {
    await _storage.init();
    await _loadRemoteConfigs();
    _registerBuiltInPopups();
    _initialized = true;
  }

  /// 触发指定 Slot 的弹窗调度
  Future<void> triggerSlot(PopupSlot slot, {
    Map<String, dynamic>? context,
  }) async {
    if (!_initialized) return;

    // 1. 从配置池中筛选匹配该 slot 的弹窗
    final candidates = _getCandidatesForSlot(slot, context);

    // 2. 对每个候选弹窗执行规则评估
    final qualified = <PopupConfig>[];
    for (final config in candidates) {
      if (await _ruleEvaluator.evaluate(config, context ?? {})) {
        qualified.add(config);
      }
    }

    // 3. 加入优先队列
    for (final config in qualified) {
      _queue.enqueue(config);
    }

    // 4. 尝试展示队列中最高优先级的弹窗
    await _tryShowNext();
  }

  /// 触发事件（EVENT_TRIGGER slot 使用）
  Future<void> triggerEvent(String eventName, {
    Map<String, dynamic>? context,
  }) async {
    await triggerSlot(
      PopupSlot.EVENT_TRIGGER,
      context: {'triggerEvent': eventName, ...?context},
    );
  }

  /// 尝试展示下一个弹窗
  Future<void> _tryShowNext() async {
    if (_currentPopup != null) return; // 有弹窗在展示中

    final config = _queue.dequeue();
    if (config == null) return;

    // 再次校验规则（防止在排队期间条件变化）
    if (!await _ruleEvaluator.evaluate(config, {})) {
      await _tryShowNext(); // 递归尝试下一个
      return;
    }

    // 记录展示
    await _storage.recordImpression(config.popupId);

    // 渲染弹窗
    _currentPopup = ActivePopup(config: config);
    await PopupRenderer.show(config, _onPopupDismissed);

    // 上报曝光埋点
    PopupAnalytics.reportImpression(config);
  }

  /// 弹窗关闭回调
  void _onPopupDismissed(PopupConfig config, PopupDismissReason reason) {
    _currentPopup = null;

    // 上报关闭埋点
    PopupAnalytics.reportDismiss(config, reason);

    // 延迟一小段时间后尝试展示下一个
    Future.delayed(const Duration(milliseconds: 500), () {
      _tryShowNext();
    });
  }

  /// 获取匹配 slot 的候选弹窗
  List<PopupConfig> _getCandidatesForSlot(
    PopupSlot slot,
    Map<String, dynamic>? context,
  ) {
    // 从配置池中筛选
    return _allConfigs
        .where((c) => c.enabled && c.slot == slot)
        .where((c) {
          // 检查时间范围
          final now = DateTime.now();
          if (c.startTime != null && now.isBefore(c.startTime!)) return false;
          if (c.endTime != null && now.isAfter(c.endTime!)) return false;
          return true;
        })
        .where((c) {
          // 检查互斥：如果同一 mutexGroup 中已展示过，跳过
          if (c.rule.mutexGroup != null) {
            return !_storage.isMutexGroupShown(c.rule.mutexGroup!);
          }
          return true;
        })
        .toList();
  }
}
```

### 5.3 规则评估引擎

```dart
/// 弹窗规则评估器
class RuleEvaluator {
  /// 评估弹窗是否满足展示条件
  Future<bool> evaluate(
    PopupConfig config,
    Map<String, dynamic> context,
  ) async {
    final rule = config.rule;
    final impression = await PopupStorage.instance.getImpression(config.popupId);

    // 1. 频次检查
    if (!_checkFrequency(rule, impression)) return false;

    // 2. 间隔检查
    if (!_checkInterval(rule, impression)) return false;

    // 3. "不再提醒"检查
    if (impression?.doNotRemind == true) return false;

    // 4. 定向条件检查
    if (!_checkTargeting(rule, context)) return false;

    // 5. 互斥弹窗检查
    if (!_checkExclusion(rule)) return false;

    // 6. 冷启动次数检查
    if (rule.minLaunchCount != null) {
      final launchCount = await _getLaunchCount();
      if (launchCount < rule.minLaunchCount!) return false;
    }

    return true;
  }

  bool _checkFrequency(PopupRule rule, PopupImpression? impression) {
    if (impression == null) return true;

    // 总次数
    if (rule.maxImpressions > 0 &&
        impression.impressionCount >= rule.maxImpressions) {
      return false;
    }

    // 每日次数
    if (rule.maxDailyImpressions > 0) {
      _resetDailyIfNeeded(impression);
      if (impression.dailyImpressionCount >= rule.maxDailyImpressions) {
        return false;
      }
    }

    return true;
  }

  bool _checkInterval(PopupRule rule, PopupImpression? impression) {
    if (impression?.lastImpressionTime == null) return true;
    if (rule.minIntervalSeconds <= 0) return true;

    final elapsed = DateTime.now()
        .difference(impression!.lastImpressionTime!)
        .inSeconds;
    return elapsed >= rule.minIntervalSeconds;
  }

  bool _checkTargeting(PopupRule rule, Map<String, dynamic> context) {
    final userContext = UserContext.current;

    // 学段定向
    if (rule.targetStages.isNotEmpty &&
        !rule.targetStages.contains(userContext.stage)) {
      return false;
    }

    // 年级定向
    if (rule.targetGrades.isNotEmpty &&
        !rule.targetGrades.contains(userContext.grade)) {
      return false;
    }

    // 会员状态定向
    switch (rule.memberTarget) {
      case MemberTargetType.FREE_ONLY:
        if (userContext.isPaidMember) return false;
        break;
      case MemberTargetType.PAID_ONLY:
        if (!userContext.isPaidMember) return false;
        break;
      case MemberTargetType.EXPIRED:
        if (!userContext.isMemberExpired) return false;
        break;
      case MemberTargetType.ALL:
        break;
    }

    // 注册天数定向
    final regDays = userContext.registerDays;
    if (rule.minRegisterDays != null && regDays < rule.minRegisterDays!) {
      return false;
    }
    if (rule.maxRegisterDays != null && regDays > rule.maxRegisterDays!) {
      return false;
    }

    return true;
  }

  bool _checkExclusion(PopupRule rule) async {
    if (rule.excludeAfterPopupIds.isEmpty) return true;
    for (final excludeId in rule.excludeAfterPopupIds) {
      final imp = await PopupStorage.instance.getImpression(excludeId);
      if (imp != null && imp.impressionCount > 0) return false;
    }
    return true;
  }
}
```

### 5.4 优先队列实现

```dart
/// 弹窗优先队列（基于排序数组，弹窗数量有限无需复杂堆结构）
class PopupQueue {
  final List<PopupConfig> _queue = [];

  /// 入队（按优先级降序插入）
  void enqueue(PopupConfig config) {
    // 去重：同一 popupId 不重复入队
    if (_queue.any((c) => c.popupId == config.popupId)) return;

    // 按优先级降序插入
    int insertIndex = _queue.length;
    for (int i = 0; i < _queue.length; i++) {
      if (config.priority > _queue[i].priority) {
        insertIndex = i;
        break;
      }
    }
    _queue.insert(insertIndex, config);
  }

  /// 出队（返回最高优先级）
  PopupConfig? dequeue() {
    if (_queue.isEmpty) return null;
    return _queue.removeAt(0);
  }

  /// 查看队首（不出队）
  PopupConfig? peek() {
    if (_queue.isEmpty) return null;
    return _queue.first;
  }

  /// 清空队列
  void clear() => _queue.clear();

  /// 队列长度
  int get length => _queue.length;
}
```

```dart
class PopupStorage {
  static PopupStorage get instance => _instance;
  static final PopupStorage _instance = PopupStorage._();
  PopupStorage._();

  late AppDatabase _db;
  late SharedPreferences _prefs;

  Future<void> init() async {
    _db = AppDatabase();
    _prefs = await SharedPreferences.getInstance();
    _incrementLaunchCount();
  }

  /// 记录一次展示
  Future<void> recordImpression(String popupId) async {
    final now = DateTime.now();
    final existing = await getImpression(popupId);

    if (existing == null) {
      await _db.into(_db.popupImpressionTable).insert(
        PopupImpressionTableCompanion.insert(
          popupId: popupId,
          impressionCount: const Value(1),
          dailyImpressionCount: const Value(1),
          lastImpressionTime: Value(now),
          dailyResetDate: Value(DateTime(now.year, now.month, now.day)),
          firstImpressionTime: Value(now),
        ),
      );
    } else {
      final today = DateTime(now.year, now.month, now.day);
      var dailyCount = existing.dailyImpressionCount;
      if (existing.dailyResetDate != today) {
        dailyCount = 0; // 新的一天，重置日计数
      }

      await (_db.update(_db.popupImpressionTable)
            ..where((t) => t.popupId.equals(popupId)))
          .write(
        PopupImpressionTableCompanion(
          impressionCount: Value(existing.impressionCount + 1),
          dailyImpressionCount: Value(dailyCount + 1),
          lastImpressionTime: Value(now),
          dailyResetDate: Value(today),
        ),
      );
    }
  }

  /// 设置"不再提醒"
  Future<void> setDoNotRemind(String popupId) async {
    await (_db.update(_db.popupImpressionTable)
          ..where((t) => t.popupId.equals(popupId)))
        .write(const PopupImpressionTableCompanion(
      doNotRemind: Value(true),
    ));
  }

  /// 检查互斥组是否已展示
  Future<bool> isMutexGroupShown(String mutexGroup) async {
    final result = await (_db.select(_db.mutexGroupShownTable)
          ..where((t) => t.mutexGroup.equals(mutexGroup)))
        .getSingleOrNull();
    return result != null;
  }

  /// 记录互斥组展示
  Future<void> recordMutexGroupShown(String mutexGroup, String popupId) async {
    await _db.into(_db.mutexGroupShownTable).insert(
      MutexGroupShownTableCompanion.insert(
        mutexGroup: mutexGroup,
        shownPopupId: popupId,
        shownTime: DateTime.now(),
      ),
    );
  }

  /// 冷启动计数
  int get launchCount => _prefs.getInt('popup_launch_count') ?? 0;

  Future<void> _incrementLaunchCount() async {
    final count = launchCount + 1;
    await _prefs.setInt('popup_launch_count', count);
  }
}
```

```dart
class PopupPreloader {
  /// 在 App 初始化期间预加载高优先级弹窗的图片资源

    final topConfigs = configs

      unawaited(_precacheImage(url));

      final context = AppNavigator.navigatorKey.currentContext;
      if (context != null) {
        await precacheImage(imageProvider, context);
      }
    } catch (_) {
      // 预加载失败不影响主流程
    }
  }
}
```

```dart
      await _localConfigDao.mergeUpdates(response.configs);
    }

    // 删除已下线的弹窗
    if (response.deletedPopupIds.isNotEmpty) {
      await _localConfigDao.deleteByIds(response.deletedPopupIds);

    // 更新版本号
    await _prefs.setInt('popup_config_version', response.version);
```

| 错误场景 | 处理策略 |
|----------|----------|

| 弹窗渲染异常 | 全局 try-catch，关闭当前弹窗，继续队列中下一个 |
| 弹窗路由跳转失败 | 捕获路由异常，Toast 提示"功能即将上线" |
| 并发触发（多 Slot 同时触发） | 加锁保证串行处理，避免队列竞态 |
| 弹窗 ID 重复 | 新配置覆盖旧配置，日志告警 |
