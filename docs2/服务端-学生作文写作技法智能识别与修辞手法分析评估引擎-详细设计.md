# 服务端-学生作文写作技法智能识别与修辞手法分析评估引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 作文辅导体系中的核心内容分析组件，专注于对学生作文中的**写作技法（Writing Techniques）**和**修辞手法（Rhetorical Devices）**进行细粒度自动识别、分类、评估与改进建议生成。

与现有作文模块的分工边界：

| 现有模块 | 职责 | 与本引擎的关系 |
| --- | --- | --- |
| 作文批改评分引擎 | 整体评分、错别字、标点、语言规范性 | 本引擎提供技法维度评分输入 |
| 作文审题分析与提纲生成 | 审题、立意、结构规划 | 本引擎关注已写内容的技法分析 |
| 作文润色建议引擎 | 词语替换、句式优化 | 本引擎提供修辞层面的深层建议 |
| 作文范文智能推荐 | 范文匹配、结构拆解 | 本引擎可标注范文中的技法供学习 |
| 作文素材库管理 | 素材积累、主题推荐 | 不涉及 |
| 作文抄袭检测 | 原创性检测 | 不涉及 |

### 1.2 设计目标

1. **高精度识别**：对中小学常见 30+ 种修辞手法和 20+ 种写作技法进行准确识别，F1 ≥ 0.82。
2. **分学段适配**：根据学生学段（小学/初中/高中）对技法要求差异提供适配分析。
3. **建设性反馈**：每种技法不仅识别，还要给出使用效果评价和改进建议。
4. **成长追踪**：长期追踪学生技法使用偏好和掌握度变化趋势。
5. **课标对齐**：技法识别与评估标准对齐语文新课标中的"文学阅读与写作"任务群要求。

### 1.3 适用范围

- **学科**：语文（主）、英语（辅，支持英文修辞基础识别）
- **学段**：小学三年级至高中三年级
- **文体**：记叙文、议论文、说明文、散文、读后感、应用文
- **触发场景**：作文批改流程、作文自主诊断、教师讲评准备、范文技法标注

```

    │
    ▼

                 │
                 ▼
┌─────────────────────────────────┐

└────────────────┬────────────────┘
                 │
                 ▼
┌─────────────────────────────────┐

                 │
                 ▼
┌─────────────────────────────────┐
│  4. 写作技法结构化分析            │

                 │
                 ▼
┌─────────────────────────────────┐

                 │
                 ▼

                 │
                 ▼
```

## 3. 数据结构定义

### 3.1 核心数据表

#### 3.1.1 `essay_rhetorical_analysis` — 作文修辞分析结果表

```sql
CREATE TABLE `essay_rhetorical_analysis` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    `essay_id` BIGINT NOT NULL COMMENT '作文ID，关联essay表',
    `student_id` BIGINT NOT NULL COMMENT '学生用户ID',
    `analysis_version` VARCHAR(16) NOT NULL DEFAULT 'v1.0' COMMENT '分析引擎版本',
    `essay_type` VARCHAR(20) NOT NULL COMMENT '文体: narrative/argumentative/expository/prose',
    `grade_stage` VARCHAR(20) NOT NULL COMMENT '学段: primary/junior/senior',
    `total_technique_count` INT NOT NULL DEFAULT 0 COMMENT '识别到的技法总数',
    `rhetorical_count` INT NOT NULL DEFAULT 0 COMMENT '修辞手法数量',
    `writing_technique_count` INT NOT NULL DEFAULT 0 COMMENT '写作技法数量',
    `technique_diversity_score` DECIMAL(4,2) NOT NULL DEFAULT 0 COMMENT '技法多样性评分(0-100)',
    `technique_appropriateness_score` DECIMAL(4,2) NOT NULL DEFAULT 0 COMMENT '技法恰当性评分(0-100)',
    `technique_innovation_score` DECIMAL(4,2) NOT NULL DEFAULT 0 COMMENT '技法创新性评分(0-100)',
    `overall_technique_score` DECIMAL(4,2) NOT NULL DEFAULT 0 COMMENT '技法综合评分(0-100)',
    `ai_model_used` VARCHAR(64) COMMENT '使用的AI模型标识',
    `processing_time_ms` INT COMMENT '处理耗时(毫秒)',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX `idx_essay_id` (`essay_id`),
    INDEX `idx_student_id` (`student_id`),
    INDEX `idx_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作文修辞分析结果表';
```

#### 3.1.2 `essay_technique_detail` — 技法识别明细表

```sql
CREATE TABLE `essay_technique_detail` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `analysis_id` BIGINT NOT NULL COMMENT '关联分析结果ID',
    `essay_id` BIGINT NOT NULL COMMENT '作文ID',
    `technique_category` VARCHAR(30) NOT NULL COMMENT '技法大类: rhetorical/writing',
    `technique_code` VARCHAR(40) NOT NULL COMMENT '技法编码，如 metaphor, parallelism',
    `technique_name` VARCHAR(60) NOT NULL COMMENT '技法中文名，如"比喻"',
    `occurrence_count` INT NOT NULL DEFAULT 1 COMMENT '出现次数',
    `start_positions` JSON COMMENT '文本位置数组: [{"start":120,"end":158,"sentence":"..."}]',
    `effectiveness_score` DECIMAL(3,1) NOT NULL COMMENT '使用效果评分(0-10)',
    `appropriateness` ENUM('excellent','appropriate','forced','incorrect','offensive')
        NOT NULL COMMENT '恰当性评级',
    `analysis_comment` TEXT COMMENT 'AI分析评语',
    `improvement_suggestion` TEXT COMMENT '改进建议',
    `is_highlighted` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否为亮点用法(优秀范例)',
    `is_problematic` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否存在使用问题',
    `curriculum_alignment` VARCHAR(200) COMMENT '课标对应要求描述',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX `idx_analysis_id` (`analysis_id`),
    INDEX `idx_essay_id` (`essay_id`),
    INDEX `idx_technique_code` (`technique_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作文技法识别明细表';
```

#### 3.1.3 `student_technique_mastery` — 学生技法掌握度表

```sql
CREATE TABLE `student_technique_mastery` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `student_id` BIGINT NOT NULL COMMENT '学生ID',
    `technique_code` VARCHAR(40) NOT NULL COMMENT '技法编码',
    `technique_name` VARCHAR(60) NOT NULL COMMENT '技法名称',
    `mastery_level` DECIMAL(3,2) NOT NULL DEFAULT 0 COMMENT '掌握度(0.00-1.00)',
    `usage_count` INT NOT NULL DEFAULT 0 COMMENT '历史使用总次数',
    `excellent_count` INT NOT NULL DEFAULT 0 COMMENT '优秀使用次数',
    `appropriate_count` INT NOT NULL DEFAULT 0 COMMENT '恰当使用次数',
    `forced_count` INT NOT NULL DEFAULT 0 COMMENT '牵强使用次数',
    `incorrect_count` INT NOT NULL DEFAULT 0 COMMENT '错误使用次数',
    `avg_effectiveness` DECIMAL(3,1) NOT NULL DEFAULT 0 COMMENT '平均效果评分',
    `last_used_at` DATETIME COMMENT '最近一次使用时间',
    `first_used_at` DATETIME COMMENT '首次使用时间',
    `mastery_trend` ENUM('rising','stable','declining','new') NOT NULL DEFAULT 'new',
    `grade_stage` VARCHAR(20) NOT NULL COMMENT '当前学段',
    `recommended_level` VARCHAR(20) NOT NULL DEFAULT 'awareness',
    -- awareness → attempt → familiar → proficient → master → creative
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY `uk_student_technique` (`student_id`, `technique_code`),
    INDEX `idx_student_id` (`student_id`),
    INDEX `idx_mastery_level` (`mastery_level`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生技法掌握度表';
```

#### 3.1.4 `technique_knowledge_base` — 技法知识库

```sql
CREATE TABLE `technique_knowledge_base` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `technique_code` VARCHAR(40) NOT NULL UNIQUE COMMENT '技法编码',
    `technique_name` VARCHAR(60) NOT NULL COMMENT '技法中文名',
    `technique_name_en` VARCHAR(80) COMMENT '技法英文名',
    `category` VARCHAR(30) NOT NULL COMMENT '大类: rhetorical/writing',
    `sub_category` VARCHAR(30) NOT NULL COMMENT '子类: figuration/structure/expression...',
    `definition` TEXT NOT NULL COMMENT '技法定义说明',
    `recognition_rules` JSON NOT NULL COMMENT '识别规则(正则+语义特征)',
    `example_excellent` TEXT COMMENT '优秀使用示例',
    `example_forced` TEXT COMMENT '牵强使用示例',
    `example_incorrect` TEXT COMMENT '错误使用示例',
    `min_grade` VARCHAR(20) NOT NULL DEFAULT 'primary_3' COMMENT '最低适用学段',
    `difficulty_level` INT NOT NULL DEFAULT 1 COMMENT '难度等级(1-5)',
    `curriculum_requirement` TEXT COMMENT '课标要求描述',
    `teaching_priority` INT NOT NULL DEFAULT 5 COMMENT '教学优先级(1-10)',
    `is_active` TINYINT(1) NOT NULL DEFAULT 1,
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作技法知识库';
```

### 5.1 文本预处理模块

```python
import re
import jieba
import jieba.posseg as pseg
from dataclasses import dataclass
from typing import List

@dataclass
class Sentence:
    """分句结果"""
    text: str           # 句子文本
    start_pos: int      # 在原文中的起始位置
    end_pos: int        # 结束位置
    words: List[tuple]  # 分词结果 [(word, flag), ...]
    sentence_type: str  # declarative/interrogative/exclamatory/imperative


class EssayTextPreprocessor:
    """作文文本预处理器"""

    # 中文句子分隔符
    SENTENCE_DELIMITERS = r'[。！？；\n]+'
    # 子句分隔符（用于更细粒度分析）
    CLAUSE_DELIMITERS = r'[，、,；：]+'

    def __init__(self):
        # 加载教育领域自定义词典
        jieba.load_userdict('dict/education_terms.txt')
        jieba.load_userdict('dict/rhetorical_terms.txt')

    def preprocess(self, essay_text: str) -> List[Sentence]:
        """
        完整预处理流程：分句 → 分词 → 词性标注 → 句型识别
        """
        # Step 1: 清洗
        cleaned = self._clean_text(essay_text)

        # Step 2: 分句
        sentences = self._split_sentences(cleaned)

        # Step 3: 逐句分词和标注
        result = []
        for sent in sentences:
            words = pseg.cut(sent.text)
            word_list = [(w.word, w.flag) for w in words if w.word.strip()]
            sent.words = word_list
            sent.sentence_type = self._detect_sentence_type(sent.text)
            result.append(sent)

        return result

    def _clean_text(self, text: str) -> str:
        """清洗文本"""
        # 去除多余空白
        text = re.sub(r'\s+', ' ', text)
        # 标准化标点（全角→半角处理由NLP模型负责）
        return text.strip()

    def _split_sentences(self, text: str) -> List[Sentence]:
        """分句，保留位置信息"""
        sentences = []
        last_end = 0

        for match in re.finditer(self.SENTENCE_DELIMITERS, text):
            sent_text = text[last_end:match.start()].strip()
            if sent_text:
                sentences.append(Sentence(
                    text=sent_text,
                    start_pos=last_end,
                    end_pos=match.start(),
                    words=[],
                    sentence_type=''
                ))
            last_end = match.end()

        # 处理最后一段
        if last_end < len(text):
            sent_text = text[last_end:].strip()
            if sent_text:
                sentences.append(Sentence(
                    text=sent_text,
                    start_pos=last_end,
                    end_pos=len(text),
                    words=[],
                    sentence_type=''
                ))

        return sentences

    def _detect_sentence_type(self, text: str) -> str:
        """识别句型"""
        if text.endswith('？') or text.endswith('?'):
            return 'interrogative'
        elif text.endswith('！') or text.endswith('!'):
            return 'exclamatory'
        elif text.endswith('。') or text.endswith('.'):
            return 'declarative'
        return 'declarative'
```

### 5.2 修辞手法识别引擎

采用**三通道并行识别 + 融合决策**架构：

```python
from enum import Enum
from typing import List, Dict, Optional
from dataclasses import dataclass, field
import re
import json

class IdentificationSource(Enum):
    RULE_BASED = "rule"        # 规则匹配
    NLP_FEATURE = "nlp"        # NLP特征
    LLM_INFERENCE = "llm"      # 大模型推理


@dataclass
class TechniqueHit:
    """技法识别命中结果"""
    technique_code: str
    technique_name: str
    category: str
    source: str                     # IdentificationSource
    confidence: float               # 置信度 0-1
    start_pos: int
    end_pos: int
    sentence: str
    extracted_features: Dict = field(default_factory=dict)
    # 如比喻的 vehicle(喻体), tenor(本体), ground(相似点)


class RuleBasedDetector:
    """规则匹配通道：基于模式规则快速识别"""

    # 比喻识别规则
    METAPHOR_PATTERNS = [
        # 明喻：X像/如同/仿佛/好似Y
        {
            'pattern': re.compile(
                r'([\u4e00-\u9fa5]{1,8})'
                r'(?:像|如同|仿佛|好似|宛如|犹如|好似|好比)'
                r'(?:一位|一个|一只|一团|一片|一道|一缕)?'
                r'([\u4e00-\u9fa5]{1,12})'
            ),
            'technique': 'metaphor',
            'extract': lambda m: {
                'tenor': m.group(1),    # 本体
                'vehicle': m.group(2),  # 喻体
                'type': 'simile'        # 明喻
            }
        },
        # 暗喻：X是Y / X成了Y / X变成Y
        {
            'pattern': re.compile(
                r'([\u4e00-\u9fa5]{1,8})'
                r'(?:是|成了|变成了|化为|化作)'
                r'(?:一位|一个|一只|一团|一片|一道|一缕)?'
                r'([\u4e00-\u9fa5]{1,12})'
            ),
            'technique': 'metaphor',
            'extract': lambda m: {
                'tenor': m.group(1),
                'vehicle': m.group(2),
                'type': 'implicit_metaphor'  # 暗喻
            }
        },
    ]

    # 排比识别规则（连续3+句式相似）
    PARALLELISM_PATTERN = re.compile(
        r'((?:[\u4e00-\u9fa5]{2,15}[，,；;]){2,}[\u4e00-\u9fa5]{2,15}[。！？.!?])'
    )

    # 反问识别规则
    RHETORICAL_QUESTION_PATTERN = re.compile(
        r'(?:难道|岂能|怎能|何曾|哪里|怎会|难道说).*?[？?]'
    )

    # 反复识别规则（相同词/短语出现2次以上，间距<20字）
    def detect_repetition(self, sentences: List[Sentence]) -> List[TechniqueHit]:
        hits = []
        for sent in sentences:
            words = [w for w, f in sent.words if len(w) >= 2 and f.startswith(('n', 'v', 'a'))]
            seen = {}
            for i, w in enumerate(words):
                if w in seen:
                    gap = i - seen[w]
                    if gap <= 5:
                        hits.append(TechniqueHit(
                            technique_code='repetition',
                            technique_name='反复',
                            category='rhetorical',
                            source=IdentificationSource.RULE_BASED.value,
                            confidence=0.75,
                            start_pos=sent.start_pos,
                            end_pos=sent.end_pos,
                            sentence=sent.text,
                            extracted_features={'repeated_word': w, 'gap': gap}
                        ))
                    seen[w] = i
                else:
                    seen[w] = i
        return hits

    def detect(self, sentences: List[Sentence]) -> List[TechniqueHit]:
        """执行全部规则检测"""
        all_hits = []

        for sent in sentences:
            text = sent.text

            # 比喻检测
            for pattern_cfg in self.METAPHOR_PATTERNS:
                for match in pattern_cfg['pattern'].finditer(text):
                    all_hits.append(TechniqueHit(
                        technique_code=pattern_cfg['technique'],
                        technique_name='比喻',
                        category='rhetorical',
                        source=IdentificationSource.RULE_BASED.value,
                        confidence=0.70,
                        start_pos=sent.start_pos + match.start(),
                        end_pos=sent.start_pos + match.end(),
                        sentence=match.group(0),
                        extracted_features=pattern_cfg['extract'](match)
                    ))

            # 排比检测
            for match in self.PARALLELISM_PATTERN.finditer(text):
                clauses = re.split(r'[，,；;]', match.group(1))
                clauses = [c for c in clauses if c.strip()]
                if len(clauses) >= 3:
                    # 检查句式相似度
                    similarity = self._clause_similarity(clauses)
                    if similarity > 0.5:
                        all_hits.append(TechniqueHit(
                            technique_code='parallelism',
                            technique_name='排比',
                            category='rhetorical',
                            source=IdentificationSource.RULE_BASED.value,
                            confidence=0.65 + similarity * 0.2,
                            start_pos=sent.start_pos + match.start(),
                            end_pos=sent.start_pos + match.end(),
                            sentence=match.group(0),
                            extracted_features={
                                'clause_count': len(clauses),
                                'clauses': clauses,
                                'similarity': similarity
                            }
                        ))

            # 反问检测
            for match in self.RHETORICAL_QUESTION_PATTERN.finditer(text):
                all_hits.append(TechniqueHit(
                    technique_code='rhetorical_question',
                    technique_name='反问',
                    category='rhetorical',
                    source=IdentificationSource.RULE_BASED.value,
                    confidence=0.80,
                    start_pos=sent.start_pos + match.start(),
                    end_pos=sent.start_pos + match.end(),
                    sentence=match.group(0),
                    extracted_features={}
                ))

        # 反复检测
        all_hits.extend(self.detect_repetition(sentences))

        return all_hits

    @staticmethod
    def _clause_similarity(clauses: List[str]) -> float:
        """计算子句间的句式相似度"""
        if len(clauses) < 2:
            return 0.0
        # 基于字数差异和词性序列相似度
        lengths = [len(c) for c in clauses]
        length_var = max(lengths) - min(lengths)
        length_score = max(0, 1 - length_var / max(lengths))

        # 简化版：基于共有词比例
        word_sets = [set(jieba.cut(c)) for c in clauses]
        common_ratio = len(set.intersection(*word_sets)) / max(len(set.union(*word_sets)), 1)

        return length_score * 0.4 + common_ratio * 0.6
```

### 5.4 融合决策引擎

```python
from collections import defaultdict

class FusionDecisionEngine:
    """三通道融合决策：合并、去重、置信度加权"""

    # 各通道权重
    SOURCE_WEIGHTS = {
        IdentificationSource.RULE_BASED.value: 0.25,
        IdentificationSource.NLP_FEATURE.value: 0.30,
        IdentificationSource.LLM_INFERENCE.value: 0.45,
    }

    def fuse(
        self,
        rule_hits: List[TechniqueHit],
        nlp_hits: List[TechniqueHit],
        llm_hits: List[TechniqueHit]
    ) -> List[TechniqueHit]:
        """
        融合三通道识别结果：
        1. 按位置和技法类型分组
        2. 对同位置同技法的结果进行加权融合
        3. 过滤低置信度结果
        """
        all_hits = rule_hits + nlp_hits + llm_hits

        # 按技法编码分组
        by_technique = defaultdict(list)
        for hit in all_hits:
            by_technique[hit.technique_code].append(hit)

        fused_results = []
        for technique_code, hits in by_technique.items():
            # 进一步按位置重叠分组
            clusters = self._cluster_by_position(hits)

            for cluster in clusters:
                if len(cluster) == 1:
                    # 单通道命中，使用原始置信度
                    hit = cluster[0]
                    if hit.confidence >= 0.5:
                        fused_results.append(hit)
                else:
                    # 多通道命中，加权融合
                    fused = self._merge_hits(cluster)
                    fused_results.append(fused)

        return fused_results

    def _cluster_by_position(self, hits: List[TechniqueHit]) -> List[List[TechniqueHit]]:
        """按文本位置重叠度聚类"""
        clusters = []
        sorted_hits = sorted(hits, key=lambda h: h.start_pos)

        for hit in sorted_hits:
            merged = False
            for cluster in clusters:
                for existing in cluster:
                    if self._positions_overlap(hit, existing):
                        cluster.append(hit)
                        merged = True
                        break
                if merged:
                    break
            if not merged:
                clusters.append([hit])

        return clusters

    @staticmethod
    def _positions_overlap(h1: TechniqueHit, h2: TechniqueHit) -> bool:
        """检查两个命中位置是否重叠"""
        return not (h1.end_pos < h2.start_pos or h2.end_pos < h1.start_pos)

    def _merge_hits(self, hits: List[TechniqueHit]) -> TechniqueHit:
        """合并多个通道的命中结果"""
        # 加权置信度
        total_weight = 0
        weighted_confidence = 0

        for hit in hits:
            weight = self.SOURCE_WEIGHTS.get(hit.source, 0.3)
            weighted_confidence += hit.confidence * weight
            total_weight += weight

        final_confidence = weighted_confidence / total_weight if total_weight > 0 else 0

        # 选择位置范围最大的作为代表
        representative = max(hits, key=lambda h: h.end_pos - h.start_pos)

        return TechniqueHit(
            technique_code=representative.technique_code,
            technique_name=representative.technique_name,
            category=representative.category,
            source='fused',
            confidence=min(final_confidence * 1.15, 1.0),  # 多通道确认，适当提升
            start_pos=representative.start_pos,
            end_pos=representative.end_pos,
            sentence=representative.sentence,
            extracted_features=representative.extracted_features
        )
```

### 5.5 效果评估引擎

```python
class TechniqueEffectivenessEvaluator:
    """技法使用效果评估"""

    # 学段技法期望标准
    GRADE_STANDARDS = {
        'primary': {
            'expected_techniques': ['metaphor', 'personification', 'parallelism', 'detail_description'],
            'diversity_target': 4,   # 期望使用4种以上不同技法
            'min_appropriateness': 0.6,
        },
        'junior': {
            'expected_techniques': ['metaphor', 'personification', 'parallelism', 'contrast',
                                    'quotation', 'detail_description', 'scene_setting',
                                    'contrast_argument', 'example_argument'],
            'diversity_target': 6,
            'min_appropriateness': 0.7,
        },
        'senior': {
            'expected_techniques': ['metaphor', 'personification', 'parallelism', 'contrast',
                                    'quotation', 'synesthesia', 'symbolism', 'virtual_real',
                                    'deduction', 'analogy_argument', 'multi_sensory'],
            'diversity_target': 8,
            'min_appropriateness': 0.75,
        }
    }

    def evaluate(
        self,
        techniques: List[TechniqueHit],
        grade_stage: str,
        essay_type: str,
        essay_length: int
    ) -> dict:
        """
        全面评估技法使用效果
        """
        standards = self.GRADE_STANDARDS.get(
            grade_stage.split('_')[0],
            self.GRADE_STANDARDS['junior']
        )

        return {
            'diversity_score': self._calc_diversity_score(techniques, standards),
            'appropriateness_score': self._calc_appropriateness_score(techniques),
            'innovation_score': self._calc_innovation_score(techniques, grade_stage),
            'density_score': self._calc_density_score(techniques, essay_length),
            'quality_distribution': self._get_quality_distribution(techniques),
        }

    def _calc_diversity_score(self, techniques: List[TechniqueHit], standards: dict) -> float:
        """技法多样性评分"""
        unique_codes = set(t.technique_code for t in techniques)
        target = standards['diversity_target']

        # 基础分：使用技法种类/目标种类
        base_score = min(len(unique_codes) / target, 1.0) * 60

        # 课标对齐加分：使用了课标期望技法
        expected = set(standards['expected_techniques'])
        aligned = unique_codes & expected
        alignment_bonus = min(len(aligned) / len(expected), 1.0) * 40

        return round(base_score + alignment_bonus, 1)

    def _calc_appropriateness_score(self, techniques: List[TechniqueHit]) -> float:
        """技法恰当性评分"""
        if not techniques:
            return 50.0

        weight_map = {
            'excellent': 1.0,
            'appropriate': 0.8,
            'forced': 0.4,
            'incorrect': 0.1,
            'offensive': 0.0
        }

        total_weight = sum(weight_map.get(t.appropriateness, 0.5) for t in techniques)
        # 加权平均
        avg = total_weight / len(techniques)
        return round(avg * 100, 1)

    def _calc_innovation_score(
        self,
        techniques: List[TechniqueHit],
        grade_stage: str
    ) -> float:
        """技法创新性评分"""
        if not techniques:
            return 30.0

        # 统计亮点
        highlight_count = sum(1 for t in techniques if getattr(t, 'is_highlighted', False))

        # 高分技法比例
        high_score_count = sum(
            1 for t in techniques
            if getattr(t, 'effectiveness_score', 0) >= 8.0
        )

        # 基础分50 + 亮点加成 + 高分加成
        score = 50.0
        score += min(highlight_count * 15, 30)
        score += min(high_score_count * 5, 20)

        # 学段调整：高中学段创新要求更高
        if grade_stage.startswith('senior'):
            score *= 0.9  # 提高标准

        return round(min(score, 100), 1)

    def _calc_density_score(
        self,
        techniques: List[TechniqueHit],
        essay_length: int
    ) -> float:
        """技法密度评分（每500字合理技法数量）"""
        if essay_length < 50:
            return 50.0

        density = len(techniques) / (essay_length / 500)

        # 理想密度区间：500字3-8个技法
        if 3 <= density <= 8:
            return 90.0
        elif 2 <= density < 3 or 8 < density <= 10:
            return 75.0
        elif 1 <= density < 2 or 10 < density <= 12:
            return 60.0
        else:
            return 40.0

    @staticmethod
    def _get_quality_distribution(techniques: List[TechniqueHit]) -> dict:
        """技法质量分布"""
        dist = {'excellent': 0, 'appropriate': 0, 'forced': 0, 'incorrect': 0}
        for t in techniques:
            level = getattr(t, 'appropriateness', 'appropriate')
            dist[level] = dist.get(level, 0) + 1
        return dist
```

### 5.6 技法掌握度增量更新

```python
class TechniqueMasteryUpdater:
    """学生技法掌握度增量更新"""

    # 各评级对掌握度的贡献
    APPROPRIATENESS_DELTA = {
        'excellent': 0.04,
        'appropriate': 0.02,
        'forced': -0.01,
        'incorrect': -0.03,
        'offensive': -0.05,
    }

    # 掌握度等级阈值
    LEVEL_THRESHOLDS = [
        (0.85, 'creative'),    # 创造性运用
        (0.70, 'master'),      # 熟练运用
        (0.55, 'proficient'),  # 能够运用
        (0.35, 'familiar'),    # 初步熟悉
        (0.15, 'attempt'),     # 尝试运用
        (0.0, 'awareness'),    # 认知阶段
    ]

    def update_mastery(
        self,
        student_id: int,
        technique_hits: List[TechniqueHit],
        grade_stage: str,
        db_session
    ) -> dict:
        """
        根据本次作文的技法识别结果，增量更新学生技法掌握度
        返回更新摘要
        """
        updates = {}

        # 按技法编码分组
        by_technique = defaultdict(list)
        for hit in technique_hits:
            by_technique[hit.technique_code].append(hit)

        for code, hits in by_technique.items():
            # 计算本次该技法的综合表现
            avg_effectiveness = sum(
                getattr(h, 'effectiveness_score', 5.0) for h in hits
            ) / len(hits)

            best_appropriateness = max(
                hits,
                key=lambda h: self._appropriateness_rank(
                    getattr(h, 'appropriateness', 'appropriate')
                )
            )
            appropriateness = getattr(best_appropriateness, 'appropriateness', 'appropriate')

            # 获取当前掌握度记录
            current = db_session.query(StudentTechniqueMastery).filter_by(
                student_id=student_id,
                technique_code=code
            ).first()

            if current is None:
                # 新技法，创建记录
                current = StudentTechniqueMastery(
                    student_id=student_id,
                    technique_code=code,
                    technique_name=hits[0].technique_name,
                    mastery_level=0.1,
                    grade_stage=grade_stage,
                    first_used_at=datetime.now(),
                    mastery_trend='new'
                )
                db_session.add(current)

            # 记录旧值
            old_level = current.mastery_level
            old_recommended = current.recommended_level

            # 增量更新掌握度
            delta = self.APPROPRIATENESS_DELTA.get(appropriateness, 0)

            # 效果评分调节
            if avg_effectiveness >= 8:
                delta += 0.01
            elif avg_effectiveness < 4:
                delta -= 0.01

            # 新手保护：前5次使用不扣分
            if current.usage_count < 5 and delta < 0:
                delta = 0

            new_level = max(0.0, min(1.0, old_level + delta))

            # 更新统计字段
            current.mastery_level = new_level
            current.usage_count += len(hits)
            current.avg_effectiveness = (
                (current.avg_effectiveness * (current.usage_count - len(hits)) +
                 avg_effectiveness * len(hits)) / current.usage_count
            )
            current.last_used_at = datetime.now()

            # 更新评级计数
            if appropriateness == 'excellent':
                current.excellent_count += 1
            elif appropriateness == 'appropriate':
                current.appropriate_count += 1
            elif appropriateness == 'forced':
                current.forced_count += 1
            elif appropriateness == 'incorrect':
                current.incorrect_count += 1

            # 更新推荐等级
            current.recommended_level = self._get_recommended_level(new_level)

            # 更新趋势
            current.mastery_trend = self._calc_trend(old_level, new_level, current.usage_count)

            updates[code] = {
                'old_level': round(old_level, 2),
                'new_level': round(new_level, 2),
                'change': round(new_level - old_level, 2),
                'old_recommended': old_recommended,
                'new_recommended': current.recommended_level,
            }

        db_session.commit()
        return updates

    @staticmethod
    def _appropriateness_rank(level: str) -> int:
        ranks = {'offensive': 0, 'incorrect': 1, 'forced': 2, 'appropriate': 3, 'excellent': 4}
        return ranks.get(level, 2)

    @classmethod
    def _get_recommended_level(cls, mastery: float) -> str:
        for threshold, level in cls.LEVEL_THRESHOLDS:
            if mastery >= threshold:
                return level
        return 'awareness'

    @staticmethod
    def _calc_trend(old: float, new: float, usage_count: int) -> str:
        if usage_count <= 1:
            return 'new'
        diff = new - old
        if diff > 0.015:
            return 'rising'
        elif diff < -0.015:
            return 'declining'
        return 'stable'
```

```python
import asyncio
import logging
from datetime import datetime
from typing import Optional

logger = logging.getLogger(__name__)


class EssayTechniqueOrchestrator:
    """作文技法分析编排主流程"""

    def __init__(
        self,
        preprocessor: EssayTextPreprocessor,
        rule_detector: RuleBasedDetector,
        llm_detector: LLMTechniqueDetector,
        fusion_engine: FusionDecisionEngine,
        evaluator: TechniqueEffectivenessEvaluator,
        mastery_updater: TechniqueMasteryUpdater,
        db_session,
        cache_client
    ):
        self.preprocessor = preprocessor
        self.rule_detector = rule_detector
        self.llm_detector = llm_detector
        self.fusion_engine = fusion_engine
        self.evaluator = evaluator
        self.mastery_updater = mastery_updater
        self.db = db_session
        self.cache = cache_client

    async def analyze(
        self,
        essay_id: int,
        student_id: int,
        essay_text: str,
        essay_type: str,
        grade_stage: str,
        analysis_depth: str = "full",
        options: Optional[dict] = None
    ) -> dict:
        """
        执行完整的技法分析流程
        """
        start_time = datetime.now()
        options = options or {}

        try:
            # ========== Step 1: 预处理 ==========
            sentences = self.preprocessor.preprocess(essay_text)
            logger.info(f"[TechniqueAnalysis] essay={essay_id} sentences={len(sentences)}")

            # ========== Step 2: 并行多通道识别 ==========
            # 规则通道（同步，快速）
            rule_hits = self.rule_detector.detect(sentences)

            # NLP特征通道（同步，中速）
            nlp_hits = self._nlp_feature_detect(sentences, grade_stage)

            # LLM通道（异步，慢速，设置超时）
            llm_hits = []
            try:
                llm_hits = await asyncio.wait_for(
                    self.llm_detector.detect(
                        essay_text, sentences, grade_stage, essay_type
                    ),
                    timeout=15.0  # 15秒超时
                )
            except asyncio.TimeoutError:
                logger.warning(f"[TechniqueAnalysis] essay={essay_id} LLM timeout, degrading")
            except Exception as e:
                logger.error(f"[TechniqueAnalysis] essay={essay_id} LLM error: {e}")

            # ========== Step 3: 融合决策 ==========
            fused_hits = self.fusion_engine.fuse(rule_hits, nlp_hits, llm_hits)

            # ========== Step 4: 效果评估 ==========
            evaluation = self.evaluator.evaluate(
                techniques=fused_hits,
                grade_stage=grade_stage,
                essay_type=essay_type,
                essay_length=len(essay_text)
            )

            # ========== Step 5: 生成改进建议 ==========
            suggestions = self._generate_suggestions(
                fused_hits, evaluation, grade_stage, options
            )

            # ========== Step 6: 持久化 ==========
            analysis_record = self._save_analysis(
                essay_id=essay_id,
                student_id=student_id,
                fused_hits=fused_hits,
                evaluation=evaluation,
                essay_type=essay_type,
                grade_stage=grade_stage,
                processing_ms=int((datetime.now() - start_time).total_seconds() * 1000)
            )

            # ========== Step 7: 更新学生技法画像 ==========
            mastery_updates = self.mastery_updater.update_mastery(
                student_id=student_id,
                technique_hits=fused_hits,
                grade_stage=grade_stage,
                db_session=self.db
            )

            # ========== 构建返回结果 ==========
            return self._build_response(
                analysis_record, fused_hits, evaluation,
                suggestions, mastery_updates
            )

        except Exception as e:
            logger.exception(f"[TechniqueAnalysis] essay={essay_id} analysis failed: {e}")
            # 兜底降级
            return AnalysisDegradationStrategy.handle_all_channels_fail(essay_text)

    def _nlp_feature_detect(
        self,
        sentences: List[Sentence],
        grade_stage: str
    ) -> List[TechniqueHit]:
        """NLP特征通道：基于依存句法、词向量相似度等特征识别"""
        hits = []

        for sent in sentences:
            # 依存句法分析检测被动句式、状语前置等
            # 词向量相似度检测暗喻（非"像"字比喻）
            # 情感分析检测抒情手法

            # 示例：基于词性序列检测排比（3+连续相同句式）
            words = sent.words
            if len(words) >= 6:
                pos_pattern = ''.join(f[0] for w, f in words)
                # 检测重复的词性模式
                for pattern_len in range(3, 8):
                    for i in range(len(pos_pattern) - pattern_len * 2):
                        seg1 = pos_pattern[i:i+pattern_len]
                        seg2 = pos_pattern[i+pattern_len:i+pattern_len*2]
                        if seg1 == seg2 and seg1.count('v') >= 1:
                            # 可能是排比
                            hits.append(TechniqueHit(
                                technique_code='parallelism',
                                technique_name='排比',
                                category='rhetorical',
                                source=IdentificationSource.NLP_FEATURE.value,
                                confidence=0.55,
                                start_pos=sent.start_pos,
                                end_pos=sent.end_pos,
                                sentence=sent.text,
                                extracted_features={'pos_pattern': seg1}
                            ))
                            break

        return hits

    def _generate_suggestions(
        self,
        hits: List[TechniqueHit],
        evaluation: dict,
        grade_stage: str,
        options: dict
    ) -> list:
        """生成针对性改进建议"""
        suggestions = []
        max_suggestions = options.get('max_suggestions', 5)

        # 1. 牵强/错误技法修正建议（高优先级）
        problematic = [h for h in hits if getattr(h, 'appropriateness', '') in ('forced', 'incorrect')]
        for hit in problematic[:2]:
            suggestions.append({
                'priority': 'high',
                'type': 'fix',
                'target_technique': hit.technique_code,
                'target_sentence': hit.sentence,
                'suggestion': getattr(hit, 'improvement', '该技法的使用略显牵强，建议调整表达方式。'),
                'technique_name': hit.technique_name
            })

                    'missing_techniques': list(missing)[:3],
```

### 10.1 性能目标

| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 分析延迟（P50） | ≤ 2.5s | 不含LLM通道 |

### 10.2 优化措施

1. **通道并行化**：规则检测和NLP特征检测并行执行，与LLM通道也并行。
2. **文本截断**：超过3000字的作文，LLM通道仅分析前3000字，规则通道全量分析。
3. **分句缓存**：相同作文的分句结果缓存复用。
4. **批量推理**：教师批改全班作文时，使用批量LLM推理接口降低延迟。
5. **异步画像更新**：技法画像更新可以异步执行，不阻塞主分析流程返回。
