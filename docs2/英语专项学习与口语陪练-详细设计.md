# 英语专项学习与口语陪练 - 详细设计

> 模块负责人：待定 | 版本：1.0 | 日期：2026-05-19

## 1. 模块概述

### 1.1 定位

英语专项学习与口语陪练模块面向小学至高中全学段学生，提供 **词汇学习、语法讲解、阅读理解、听力训练、口语陪练、发音评测** 六大核心能力。该模块在通用 AI 辅导和语音服务（ASR/TTS）基础上，叠加英语学科专属的教学策略、评测标准和交互模式，形成独立的英语学习闭环。

### 1.2 与其他模块的关系

| 关联模块 | 关系 |
|---------|------|
| 语音服务(ASR-TTS) | 依赖其 ASR 识别、TTS 合成、发音评测（CEFR 打分）能力 |
| AI智能辅导 | 复用多轮对话、Prompt 编排、RAG 检索能力 |
| 文科背诵 | 共享记忆曲线复习引擎，本模块聚焦英语词汇/课文背诵 |
| AI-Prompt编排 | 使用英语专属场景模板（见 §5） |
| 学情分析 | 输出英语学习行为数据，消费能力画像 |
| 同步课堂 | 提供教材英语章节的专项练习入口 |
| 错题整理 | 英语错题收录，增加听力和口语错因标签 |
| RAG与知识库 | 检索英语知识点、语法条目、范文语料 |

### 1.3 覆盖学段与差异

| 学段 | 重点能力 | 难度范围 | 词汇量目标 | 口语要求 |
|------|---------|---------|-----------|---------|
| 小学(3-6年级) | 词汇认知、简单对话、跟读模仿 | CEFR A1-A2 | 600-1500 | 发音清晰、基本语调 |
| 初中 | 语法体系、阅读理解、情景对话 | CEFR A2-B1 | 1500-3000 | 流畅表达、话题讨论 |
| 高中 | 长篇阅读、写作表达、深度讨论 | CEFR B1-B2 | 3000-5000 | 观点陈述、逻辑论述 |

## 3. 数据结构设计

### 3.1 核心实体

#### 3.1.1 英语词汇表 `eng_vocabulary`

```sql
CREATE TABLE eng_vocabulary (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    word            VARCHAR(100) NOT NULL COMMENT '单词',
    phonetic_us     VARCHAR(100) COMMENT '美式音标',
    phonetic_uk     VARCHAR(100) COMMENT '英式音标',
    pos             VARCHAR(20) COMMENT '词性缩写: n/v/adj/adv/prep/conj...',
    definition_zh   VARCHAR(500) NOT NULL COMMENT '中文释义',
    definition_en   VARCHAR(500) COMMENT '英文释义',
    difficulty      TINYINT NOT NULL COMMENT '难度 1-10',
    cefr_level      CHAR(2) COMMENT 'CEFR等级: A1/A2/B1/B2/C1/C2',
    grade_range     VARCHAR(50) COMMENT '适用学段: primary3,primary4,...,senior1,...',
    frequency_rank  INT COMMENT '词频排名',
    audio_url       VARCHAR(500) COMMENT '标准发音音频URL',
    example_sentence TEXT COMMENT '例句JSON数组',
    tags            JSON COMMENT '标签: ["核心词汇","高频词","易混淆"]',
    status          TINYINT DEFAULT 1 COMMENT '1-有效 0-无效',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_word (word),
    INDEX idx_difficulty (difficulty),
    INDEX idx_cefr (cefr_level),
    INDEX idx_grade (grade_range)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='英语词汇表';
```

**example_sentence JSON 格式：**
```json
[
  {
    "en": "She adopted an effective approach to solve the problem.",
    "zh": "她采用了一种有效的方法来解决这个问题。",
    "audio_url": "https://cdn.primetop.com/audio/eng/sent/10001.mp3"
  }
]
```

#### 4.2.2 AI 语法答疑

```
POST /api/v1/eng/grammar/ask
```

**请求体：**
```json
{
  "question": "have been to 和 have gone to 有什么区别？",
  "grade": "junior2",
  "grammar_point_id": 201,
  "context": "用户正在学习现在完成时"
}
```

**响应：** SSE 流式

```
event: message
data: {"type":"text","content":"好问题！这两个表达虽然都用了现在完成时，但意思完全不同：\n\n"}

event: message
data: {"type":"text","content":"**have been to** = 去过（已经回来了）\n"}

event: message
data: {"type":"example","en":"I have been to Beijing twice.","zh":"我去过北京两次。（现在不在北京）"}

event: message
data: {"type":"text","content":"**have gone to** = 去了（还没回来）\n"}

event: message
data: {"type":"example","en":"He has gone to the library.","zh":"他去图书馆了。（现在在图书馆或路上）"}

event: message
data: {"type":"tip","content":"💡 记忆技巧：been 是 be 的过去分词，表示"去过某地"的经历；gone 是 go 的过去分词，表示"去了还没回"的状态。"}

event: done
data: {}
```

## 8. 错误处理设计

### 8.1 错误码

| 错误码 | HTTP状态码 | 说明 |
|--------|-----------|------|
| ENG_001 | 400 | 音频格式不支持 |
| ENG_002 | 400 | 音频时长超限(>60s) |
| ENG_003 | 400 | 音频过短(<0.5s) |
| ENG_004 | 400 | 词汇ID不存在 |
| ENG_005 | 400 | 测试类型无效 |
| ENG_006 | 404 | 口语话题不存在 |
| ENG_007 | 404 | 口语会话不存在 |
| ENG_008 | 409 | 口语会话已结束 |
| ENG_009 | 429 | 今日学习次数已达上限 |
| ENG_010 | 503 | ASR服务暂不可用 |
| ENG_011 | 503 | 发音评测服务暂不可用 |
| ENG_012 | 503 | TTS合成服务暂不可用 |
| ENG_013 | 500 | LLM调用失败 |
| ENG_014 | 400 | ASR识别失败(音频质量差) |
| ENG_015 | 403 | 会员权益不足(需高级会员) |

### 8.2 降级策略

| 场景 | 降级方案 |
|------|---------|
| ASR不可用 | 返回文本输入模式，提示用户切换为打字对话 |
| 发音评测不可用 | 口语陪练继续(跳过评测)，标记 "发音评分暂不可用" |
| TTS不可用 | 口语陪练退化为纯文本对话模式 |
| LLM超时(>15s) | 返回预设回复 + 重试提示 |
| LLM限流 | 排队等待 + SSE通知排队位置 |
| 音频上传失败 | 本地缓存 + 自动重传(最多3次) |
| 网络中断 | 本地录音保存 + 重连后上传 |

### 8.3 客户端容错

```dart
// Flutter 客户端语音提交容错示例
class OralReplyHandler {
  static const int maxRetries = 3;
  
  Future<void> submitReply(File audioFile) async {
    int attempt = 0;
    
    while (attempt < maxRetries) {
      try {
        // 1. 检查网络
        final connectivity = await checkConnectivity();
        if (!connectivity.isConnected) {
          // 保存到本地队列，网络恢复后上传
          await _saveToLocalQueue(audioFile);
          _showToast('网络不可用，录音已保存，将在网络恢复后上传');
          return;
        }
        
        // 2. 上传音频
        final response = await _api.submitOralReply(
          sessionId: _sessionId,
          audioFile: audioFile,
          timeout: Duration(seconds: 30),
        );
        
        // 3. 处理SSE流
        await for (final event in response.stream) {
          _handleSSEEvent(event);
        }
        return; // 成功，退出循环
        
      } on TimeoutException {
        attempt++;
        if (attempt >= maxRetries) {
          _showError('请求超时，请检查网络后重试');
        }
        await Future.delayed(Duration(seconds: 2 * attempt)); // 指数退避
        
      } on SocketException {
        await _saveToLocalQueue(audioFile);
        _showToast('网络中断，录音已保存');
        return;
        
      } on ApiException catch (e) {
        if (e.code == 'ENG_010') {
          // ASR不可用，切换文本模式
          _switchToTextMode();
          return;
        }
        if (e.code == 'ENG_011') {
          // 评测不可用，继续但不评分
          _showInfo('发音评分暂不可用，对话继续');
          _continueWithoutScoring();
          return;
        }
        _showError('出错了：${e.message}');
        return;
      }
    }
  }
}
```

## 11. 安全与合规

### 11.1 内容安全

- 口语对话内容经过内容安全过滤(复用安全模块)
- 用户语音转写文本进行实时内容审核
- AI回复经过安全护栏过滤
- 话题库内容经过人工审核

### 11.2 隐私保护

- 用户录音文件加密存储(OSS服务端加密)
- 录音文件保留30天后自动清理
- 发音评测数据不关联个人身份信息用于分析
- 口语对话记录仅用户本人和家长(已绑定)可见

### 11.3 青少年保护

- 口语陪练话题按学段筛选，不展示超纲内容
- 每日口语练习时长纳入总时长管控
- 不收集不必要的语音生物特征数据
