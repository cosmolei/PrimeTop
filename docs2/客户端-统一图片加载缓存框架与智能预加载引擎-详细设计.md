## 1. 概述

### 1.1 模块定位

统一图片加载缓存框架（PrimeImageLoader）是 PrimeTop Flutter 客户端的**核心视觉基础设施**，为 AI 对话配图、教材插图、题目图形、知识卡片、用户头像、运营 Banner、学情报告图表等全场景提供统一的图片加载、解码、缓存、预加载和展示能力。

**核心职责：**
- 多级缓存（内存 → 磁盘 → CDN → 源站）的透明管理
- 智能预加载：基于学习内容序列提前加载后续图片
- 自适应质量控制：根据网络环境和设备性能动态调整
- 内存安全：在低端设备上自动降级，防止 OOM
- 与富文本渲染引擎、学科内容组件无缝集成

**不在本模块范围内：**
- 图片拍摄与压缩 → 见 `客户端多媒体选取与处理服务-详细设计.md`
- OCR 识别 → 见 `图片处理与OCR识别管线-详细设计.md`
- 富文本中的图文混排 → 见 `富文本与学科内容渲染引擎-详细设计.md`
- CDN 分发架构（服务端） → 见 `服务端-CDN内容分发网络与多区域边缘缓存策略-详细设计.md`

### 1.2 设计目标

| 目标 | 指标 | 说明 |
|------|------|------|
| 缓存命中率 | ≥ 85% | 二次访问同图片命中缓存 |
| 图片加载时间（WiFi） | < 300ms | 从请求到首帧渲染 |
| 图片加载时间（弱网） | < 2s | 3G/边缘网络下 |

| 预加载命中率 | ≥ 70% | 预加载的图片在 5min 内被使用 |

## 2. 数据模型

### 2.1 缓存键设计

每张图片在缓存系统中通过 **CacheKey** 唯一标识。CacheKey 由 URL + 变换参数生成哈希：

```dart
/// 缓存键生成规则
///
/// 格式: <url_hash>__<transform_hash>
/// 示例: a1b2c3d4__w400_q80_webp
class CacheKey {
  /// 原始 URL（含 CDN 查询参数）
  final String sourceUrl;

  /// 请求的变换参数
  final ImageTransform transform;

  /// 生成的缓存键
  late final String key = _computeKey();

  String _computeKey() {
    // URL hash: SHA-256 取前 16 字符
    final urlHash = sha256.convert(utf8.encode(sourceUrl)).toString().substring(0, 16);
    // Transform hash: 由宽度_高度_质量_格式组成
    final tHash = '${transform.targetWidth ?? 'auto'}_'
        '${transform.targetHeight ?? 'auto'}_'
        '${transform.quality}_'
        '${transform.format.name}';
    return '${urlHash}__$tHash';
  }

  /// 磁盘文件路径
  String get diskPath {
    // 分桶: 取 hash 前两位作为一级目录，避免单目录文件过多
    final bucket = key.substring(0, 2);
    return 'image_cache/$bucket/$key.${transform.format.extension}';
  }
}
```

### 3.2 内存缓存设计

```dart
/// 内存缓存：LRU + 弱引用双层设计
///
/// 设计思路：
/// - 强引用层（Strong Cache）：最近高频使用的解码后图片，LRU 淘汰
/// - 弱引用层（Weak Cache）：被淘汰但可能还有引用的图片，GC 可回收
/// - 两层协作保证：热数据快速命中，冷数据不 OOM
class MemoryImageCache {
  /// 强引用 LRU 缓存
  final LinkedHashMap<String, _CacheRecord> _strongCache = LinkedHashMap<>();

  /// 弱引用层惰性清理：访问时发现引用已失效即移除
  /// （不使用 Expando 键控清理，避免键对象生命周期管理的额外复杂度）
  final Map<String, WeakReference<_CacheRecord>> _weakCache = {};

  /// 最大内存占用（字节），MemoryGuard 降级时可下调（G7，只缩容不 dispose）
  late int maxBytes;

  /// 容量基准值（构造时传入，降级恢复用，见 §4.4）
  final int maxBytesBase;

  /// 当前内存占用（字节）
  int _currentBytes = 0;

  /// 最大缓存条目数
  final int maxEntries;

  static const int _defaultMaxBytes = 50 * 1024 * 1024; // 50MB
  static const int _defaultMaxEntries = 200;

  MemoryImageCache({
    int maxBytes = _defaultMaxBytes,
    this.maxEntries = _defaultMaxEntries,
  }) : maxBytesBase = maxBytes {
    this.maxBytes = maxBytes;
  }

  /// 获取图片
  ui.Image? get(String key) {
    // 1. 查强引用层
    final strong = _strongCache[key];
    if (strong != null) {
      // LRU: 移到末尾（最近使用）
      _strongCache.remove(key);
      _strongCache[key] = strong;
      strong.lastAccessed = DateTime.now();
      return strong.image;
    }

    // 2. 查弱引用层
    final weak = _weakCache[key];
    if (weak != null) {
      final record = weak.target;
      if (record != null) {
        // 从弱引用"复活"到强引用
        _promoteToStrong(key, record);
        return record.image;
      } else {
        // 弱引用已被 GC 回收
        _weakCache.remove(key);
      }
    }
    return null;
  }

  /// 写入图片
  void put(String key, ui.Image image, {required int estimatedBytes}) {
    // 如果已存在，先移除旧的
    final existing = _strongCache.remove(key);
    if (existing != null) {
      _currentBytes -= existing.estimatedBytes;
    }

    // 创建新记录
    final record = _CacheRecord(
      image: image,
      estimatedBytes: estimatedBytes,
      createdAt: DateTime.now(),
      lastAccessed: DateTime.now(),
    );

    _strongCache[key] = record;
    _currentBytes += estimatedBytes;

    // 淘汰超出容量的旧条目
    _evictIfNeeded();
  }

  /// LRU 淘汰
  void _evictIfNeeded() {
    while (_currentBytes > maxBytes || _strongCache.length > maxEntries) {
      if (_strongCache.isEmpty) break;

      // 移除最旧的（LinkedHashMap 迭代顺序 = 插入顺序，第一个即最久未使用）
      final oldestKey = _strongCache.keys.first;
      final evicted = _strongCache.remove(oldestKey)!;
      _currentBytes -= evicted.estimatedBytes;

      // 移入弱引用层（如果还有其他 Widget 引用它，不会被立即回收）
      _weakCache[oldestKey] = WeakReference(evicted);
    }
  }

  /// 内存降级：按系数调整容量上限并立即淘汰超出的旧条目（G7）
  void maxBytesDownscale(double factor) {
    maxBytes = (maxBytesBase * factor).round();
    _evictIfNeeded();
  }

  /// 从弱引用提升到强引用
  void _promoteToStrong(String key, _CacheRecord record) {
    _weakCache.remove(key);
    _strongCache[key] = record;
    _currentBytes += record.estimatedBytes;
    _evictIfNeeded();
  }

  /// 清空所有缓存（内存压力大时调用）
  void clearAll() {
    // 将所有强引用降级为弱引用
    for (final entry in _strongCache.entries) {
      _weakCache[entry.key] = WeakReference(entry.value);
    }
    _strongCache.clear();
    _currentBytes = 0;
  }

  /// 按模块清除（切换页面时释放旧页面图片）
  void clearByModule(String module) {
    // 由于 CacheKey 不含 module 信息，需外部传入需清除的 key 列表
    // 通常由 PageLifecycle 调用
  }

  /// 获取当前状态
  MemoryCacheStats get stats => MemoryCacheStats(
    strongEntries: _strongCache.length,
    weakEntries: _weakCache.length,
    currentBytes: _currentBytes,
    maxBytes: maxBytes,
    utilization: _currentBytes / maxBytes,
  );
}
```

```dart
/// 磁盘缓存：SQLite 索引 + 文件系统存储
class DiskImageCache {
  /// 缓存根目录
  final String cacheDir;

  /// SQLite 数据库
  final Database db;

  /// 最大磁盘占用（字节）
  final int maxBytes;

  /// 当前磁盘占用（字节）
  int _currentBytes = 0;

  /// 写入锁（防止同一图片并发写入）
  final Map<String, Future<void>> _writeLocks = {};

  static const int _defaultMaxBytes = 300 * 1024 * 1024; // 300MB

  DiskImageCache({
    required this.cacheDir,
    required this.db,
    this.maxBytes = _defaultMaxBytes,
  });

  /// 初始化：读取已有缓存统计
  Future<void> init() async {
    final result = await db.rawQuery(
      'SELECT SUM(file_size) as total FROM image_cache_entries',
    );
    _currentBytes = Sqflite.firstIntValue(result) ?? 0;

    // 启动时检查并清理过期缓存
    await _cleanExpired();
  }

  /// 读取图片文件
  Future<File?> get(String key) async {
    // 查询缓存索引
    final rows = await db.query(
      'image_cache_entries',
      where: 'key = ?',
      whereArgs: [key],
      limit: 1,
    );

    if (rows.isEmpty) return null;

    final entry = CacheEntry.fromJson(rows.first]);

    // 检查过期
    if (entry.expiresAt != null && DateTime.now().isAfter(entry.expiresAt!)) {
      await _removeEntry(key);
      return null;
    }

    // 检查文件是否存在
    final file = File(p.join(cacheDir, entry.filePath));
    if (!await file.exists()) {
      // 文件丢失（可能被系统清理），删除索引
      await _removeEntry(key);
      return null;
    }

    // 更新访问记录
    await db.update(
      'image_cache_entries',
      {
        'last_accessed_at': DateTime.now().toIso8601String(),
        'hit_count': entry.hitCount + 1,
      },
      where: 'key = ?',
      whereArgs: [key],
    );

    return file;
  }

  /// 写入图片文件
  Future<void> put({
    required String key,
    required String sourceUrl,
    required List<int> data,
    required String module,
    int? width,
    int? height,
    String format = 'webp',
    String? blurHash,
    int? dominantColor,
    Duration? ttl,
  }) async {
    // 检查是否已存在
    final existing = await db.query(
      'image_cache_entries',
      where: 'key = ?',
      whereArgs: [key],
      limit: 1,
    );
    if (existing.isNotEmpty) return;

    // 防止并发写入
    if (_writeLocks.containsKey(key)) {
      return _writeLocks[key]!;
    }

    final completer = Completer<void>();
    _writeLocks[key] = completer.future;

    try {
      // 计算文件路径
      final bucket = key.substring(0, 2);
      final fileName = '$key.$format';
      final relativePath = p.join('image_cache', bucket, fileName);
      final fullPath = p.join(cacheDir, relativePath);

      // 确保目录存在
      final dir = Directory(p.dirname(fullPath));
      if (!await dir.exists()) {
        await dir.create(recursive: true);
      }

      // 写入文件
      final file = File(fullPath);
      await file.writeAsBytes(data, flush: true);

      // 写入索引
      final now = DateTime.now();
      final entry = CacheEntry(
        key: key,
        sourceUrl: sourceUrl,
        filePath: relativePath,
        fileSize: data.length,
        width: width ?? 0,
        height: height ?? 0,
        format: format,
        createdAt: now,
        lastAccessedAt: now,
        expiresAt: ttl != null ? now.add(ttl) : null,
        module: module,
        blurHash: blurHash,
        dominantColor: dominantColor,
      );

      await db.insert(
        'image_cache_entries',
        entry.toJson(),
        conflictAlgorithm: ConflictAlgorithm.ignore,
      );

      _currentBytes += data.length;

      // 触发异步清理（非阻塞，异常吞没防未处理异常，见 §7-D6）
      unawaited(_evictIfNeeded().catchError((Object _) => <void>{}));
    } finally {
      completer.complete();
      _writeLocks.remove(key);
    }
  }

  /// LRU 清理
  Future<void> _evictIfNeeded() async {
    if (_currentBytes <= maxBytes) return;

    // 按最后访问时间升序查询需要清理的条目
    final candidates = await db.rawQuery(
      'SELECT key, file_path, file_size FROM image_cache_entries '
      'ORDER BY last_accessed_at ASC LIMIT ?',
      [100],
    );

    for (final row in candidates) {
      if (_currentBytes <= maxBytes * 0.9) break; // 清理到 90% 以下停止

      final key = row['key'] as String;
      final filePath = row['file_path'] as String;
      final fileSize = row['file_size'] as int;

      // 删除文件
      final file = File(p.join(cacheDir, filePath));
      if (await file.exists()) {
        await file.delete();
      }

      // 删除索引
      await db.delete(
        'image_cache_entries',
        where: 'key = ?',
        whereArgs: [key],
      );

      _currentBytes -= fileSize;
    }
  }

  /// 清理过期缓存
  Future<void> _cleanExpired() async {
    final now = DateTime.now().toIso8601String();
    final expired = await db.query(
      'image_cache_entries',
      where: 'expires_at IS NOT NULL AND expires_at < ?',
      whereArgs: [now],
    );

    for (final row in expired) {
      await _removeEntry(row['key'] as String);
    }
  }

  /// 删除指定缓存条目（公开接口，供解码失败清理等场景使用）
  Future<void> remove(String key) => _removeEntry(key);

  /// 移除单个缓存条目
  Future<void> _removeEntry(String key) async {
    final rows = await db.query(
      'image_cache_entries',
      where: 'key = ?',
      whereArgs: [key],
      limit: 1,
    );
    if (rows.isEmpty) return;

    final entry = CacheEntry.fromJson(rows.first);
    final file = File(p.join(cacheDir, entry.filePath));
    if (await file.exists()) {
      await file.delete();
    }
    await db.delete(
      'image_cache_entries',
      where: 'key = ?',
      whereArgs: [key],
    );
    _currentBytes -= entry.fileSize;
  }

  /// 按模块清理
  Future<int> clearByModule(String module) async {
    final rows = await db.query(
      'image_cache_entries',
      where: 'module = ?',
      whereArgs: [module],
    );

    int cleared = 0;
    for (final row in rows) {
      final entry = CacheEntry.fromJson(row);
      final file = File(p.join(cacheDir, entry.filePath));
      if (await file.exists()) await file.delete();
      _currentBytes -= entry.fileSize;
      cleared++;
    }

    await db.delete(
      'image_cache_entries',
      where: 'module = ?',
      whereArgs: [module],
    );

    return cleared;
  }

  /// 清空全部缓存
  Future<void> clearAll() async {
    final dir = Directory(p.join(cacheDir, 'image_cache'));
    if (await dir.exists()) {
      await dir.delete(recursive: true);
    }
    await db.delete('image_cache_entries');
    _currentBytes = 0;
  }

  /// 获取缓存统计
  Future<DiskCacheStats> getStats() async {
    final totalResult = await db.rawQuery(
      'SELECT COUNT(*) as count, SUM(file_size) as total, '
      'AVG(hit_count) as avg_hits FROM image_cache_entries',
    );
    final row = totalResult.first;
    return DiskCacheStats(
      totalEntries: (row['count'] as int?) ?? 0,
      totalBytes: (row['total'] as int?) ?? 0,
      avgHitCount: (row['avg_hits'] as num?)?.toDouble() ?? 0,
      maxBytes: maxBytes,
    );
  }
}

class DiskCacheStats {
  final int totalEntries;
  final int totalBytes;
  final double avgHitCount;
  final int maxBytes;

  const DiskCacheStats({
    required this.totalEntries,
    required this.totalBytes,
    required this.avgHitCount,
    required this.maxBytes,
  });

  double get utilization => maxBytes > 0 ? totalBytes / maxBytes : 0;
}
```

### 4.1 ImageLoadController - 加载控制器

```dart
/// 图片加载控制器
///
/// 负责协调内存缓存 → 磁盘缓存 → 网络请求的完整加载流程
class ImageLoadController {
  final MemoryImageCache _memoryCache;
  final DiskImageCache _diskCache;
  final NetworkImageLoader _networkLoader;
  final ImageDecoder _decoder;
  final AdaptEngine _adaptEngine;
  final MetricsCollector _metrics;

  /// 进行中的加载请求（去重）
  final Map<String, Future<ImageLoadResult>> _pending = {};

  ImageLoadController({
    required MemoryImageCache memoryCache,
    required DiskImageCache diskCache,
    required NetworkImageLoader networkLoader,
    required ImageDecoder decoder,
    required AdaptEngine adaptEngine,
    required MetricsCollector metrics,
  })  : _memoryCache = memoryCache,
        _diskCache = diskCache,
        _networkLoader = networkLoader,
        _decoder = decoder,
        _adaptEngine = adaptEngine,
        _metrics = metrics;

  /// 加载图片
  ///
  /// [url] 图片 URL
  /// [transform] 期望的变换参数（会被自适应引擎调整）
  /// [module] 业务模块标识
  Future<ImageLoadResult> load({
    required String url,
    ImageTransform transform = ImageTransform.standard,
    required String module,
  }) async {
    final stopwatch = Stopwatch()..start();

    // 1. 生成缓存键（URL + 变换参数）
    final cacheKey = CacheKey(sourceUrl: url, transform: transform);

    // 2. 请求去重：相同 key 的并发加载合并为单个 Future（见 §7 S2）
    final pending = _pending[cacheKey.key];
    if (pending != null) {
      _metrics.recordDedupHit(module);
      return pending;
    }

    final future = _loadInternal(cacheKey, module, stopwatch);
    _pending[cacheKey.key] = future;
    try {
      return await future;
    } finally {
      // 完成后移除去重登记，允许后续重新加载（缓存已写入，下次走缓存）
      _pending.remove(cacheKey.key);
    }
  }

  /// 内部加载流程：内存 → 磁盘 → 网络 三级查询
  Future<ImageLoadResult> _loadInternal(
    CacheKey cacheKey,
    String module,
    Stopwatch stopwatch,
  ) async {
    // ── 第 1 级：内存缓存 ──────────────────────────────────────
    final memHit = _memoryCache.get(cacheKey.key);
    if (memHit != null) {
      stopwatch.stop();
      _metrics.recordHit(
        layer: CacheLayer.memory,
        module: module,
        elapsedMs: stopwatch.elapsedMilliseconds,
      );
      return ImageLoadResult(
        image: memHit,
        source: ImageSource.memory,
        cacheKey: cacheKey.key,
      );
    }

    // ── 第 2 级：磁盘缓存 ──────────────────────────────────────
    final diskBytes = await _diskCache.read(cacheKey);
    if (diskBytes != null) {
      try {
        // 磁盘命中：更新访问元数据 → 解码 → 回填内存缓存
        await _diskCache.touchAccess(cacheKey.key);
        final decoded = await _decoder.decode(
          bytes: diskBytes,
          transform: cacheKey.transform,
        );
        _memoryCache.put(
          cacheKey.key,
          decoded.image,
          estimatedBytes: decoded.estimatedBytes,
        );
        stopwatch.stop();
        _metrics.recordHit(
          layer: CacheLayer.disk,
          module: module,
          elapsedMs: stopwatch.elapsedMilliseconds,
        );
        return ImageLoadResult(
          image: decoded.image,
          source: ImageSource.disk,
          cacheKey: cacheKey.key,
        );
      } on ImageDecodeException catch (e, st) {
        // 磁盘数据损坏：删除坏文件后降级走网络（PIL_006）
        _metrics.recordDecodeFailure(cacheKey.key);
        await _diskCache.remove(cacheKey.key);
        AppLogger.warn('IMG decode failure from disk, fallback to network',
            tag: 'PrimeImageLoader', error: e, stackTrace: st);
      }
    }

    // ── 第 3 级：网络请求（含自适应变换协商） ──────────────────
    // 自适应引擎根据当前网络/设备状态调整变换参数（见 §4.3）
    final effectiveTransform = await _adaptEngine.adjust(cacheKey.transform);
    final effectiveKey = effectiveTransform == cacheKey.transform
        ? cacheKey
        : CacheKey(sourceUrl: cacheKey.sourceUrl, transform: effectiveTransform);

    try {
      final downloaded = await _networkLoader.download(
        url: cacheKey.sourceUrl,
        transform: effectiveTransform,
        timeout: const Duration(seconds: 15),
      );

      // 写入磁盘缓存（异步落盘，不阻塞返回）
      unawaited(_diskCache.write(
        key: effectiveKey.key,
        bytes: downloaded.bytes,
        sourceUrl: cacheKey.sourceUrl,
        transform: effectiveTransform,
        contentType: downloaded.contentType,
        fileSize: downloaded.bytes.length,
      ));

      // 解码并回填内存缓存
      final decoded = await _decoder.decode(
        bytes: downloaded.bytes,
        transform: effectiveTransform,
      );
      _memoryCache.put(
        effectiveKey.key,
        decoded.image,
        estimatedBytes: decoded.estimatedBytes,
      );

      stopwatch.stop();
      _metrics.recordHit(
        layer: CacheLayer.network,
        module: module,
        elapsedMs: stopwatch.elapsedMilliseconds,
        bytes: downloaded.bytes.length,
      );
      return ImageLoadResult(
        image: decoded.image,
        source: ImageSource.network,
        cacheKey: effectiveKey.key,
      );
    } on ImageNetworkException catch (e) {
      stopwatch.stop();
      // 网络失败：上报错误并抛出统一异常（PIL_003/004/005 族）
      _metrics.recordMiss(module, stopwatch.elapsedMilliseconds);
      throw ImageLoadException(
        code: e.isTimeout ? 'PIL_003' : (e.isDnsError ? 'PIL_004' : 'PIL_005'),
        message: '图片加载失败: ${cacheKey.sourceUrl}',
        cause: e,
        retryable: e.retryable,
      );
    }
  }

  /// 预检：当前是否具备发起图片请求的条件（弱网降级场景，见 §10 D3）
  Future<bool> canLoad() => _networkLoader.isReachable();

  /// 主动清理（设置页"清理缓存"入口调用）
  Future<void> clearAll() async {
    _memoryCache.clear();
    await _diskCache.clearAll();
    _metrics.recordManualClear();
  }
}

/// 加载结果
class ImageLoadResult {
  /// 解码后的图片
  final ui.Image image;

  /// 数据来源（决定埋点分层统计）
  final ImageSource source;

  /// 实际命中的缓存键（可能与请求键不同：自适应调整过）
  final String cacheKey;

  const ImageLoadResult({
    required this.image,
    required this.source,
    required this.cacheKey,
  });
}

enum ImageSource { memory, disk, network }
enum CacheLayer { memory, disk, network }
```

**关键设计点：**

1. **去重合并（S2）**：`_pending` Map 以缓存键合并同帧内多个 Widget 对同一图片的请求（列表复用场景常见），避免重复下载。
2. **磁盘命中不阻塞**：`touchAccess` 与解码并行，LRU 访问热度及时更新。
3. **损坏自愈**：磁盘数据解码失败时自动删除坏文件并降级网络重取，不产生永久脏数据（守卫 G4）。
4. **落盘异步化**：`unawaited(_diskCache.write(...))` 使网络→内存→渲染路径不等待磁盘 IO；磁盘写失败仅记录日志不影响本次展示（守卫 G5）。
5. **自适应协商**：网络请求前经 AdaptEngine 调整变换参数，命中后按有效键回写缓存，保证键一致性（守卫 G3）。

### 4.2 SmartPreloader - 智能预加载器

```dart
/// 智能预加载器
///
/// 基于"学习内容的序列可预测性"提前加载后续图片：
/// - 同步课堂：进入章节 A 时预加载章节 A+1 的插图集合
/// - 知识卡片：浏览卡片 i 时预加载 i+1..i+3
/// - 练习测评：加载题目页时预加载下一题配图
class SmartPreloader {
  final ImageLoadController _controller;
  final PreloadQueue _queue;
  final NetworkMonitor _networkMonitor;
  final MemoryGuard _memoryGuard;

  /// 各场景配置（见 §2.5）
  final Map<PreloadScene, PreloadConfig> _configs;

  /// 正在执行的预加载任务数
  int _inflight = 0;

  SmartPreloader({
    required ImageLoadController controller,
    required PreloadQueue queue,
    required NetworkMonitor networkMonitor,
    required MemoryGuard memoryGuard,
    Map<PreloadScene, PreloadConfig>? configs,
  })  : _controller = controller,
        _queue = queue,
        _networkMonitor = networkMonitor,
        _memoryGuard = memoryGuard,
        _configs = configs ?? PreloadConfig.defaults;

  /// 提交一批预加载任务（业务方调用入口）
  ///
  /// [scene] 预加载场景；[urls] 按访问先后顺序排列的图片 URL 列表
  void schedule(PreloadScene scene, List<String> urls) {
    final config = _configs[scene];
    if (config == null || !config.enabled || urls.isEmpty) return;

    // 硬规则 R4：预加载仅在内存水位安全时进行
    if (_memoryGuard.isUnderPressure()) {
      _queue.drop(scene, reason: DropReason.memoryPressure);
      return;
    }
    // 硬规则 R5：wifiOnly 场景下移动网络直接丢弃
    if (config.wifiOnly && !_networkMonitor.isOnWifi) {
      _queue.drop(scene, reason: DropReason.notWifi);
      return;
    }

    final batch = urls
        .take(config.maxBatchSize)
        .map((url) => PreloadTask(
              url: url,
              scene: scene,
              transform: ImageTransform(
                quality: config.preloadQuality,
                format: ImageFormat.webp,
              ),
              expireAt: DateTime.now().add(Duration(minutes: config.expireMinutes)),
            ))
        .toList();

    _queue.enqueueAll(batch);
    _pump(config);
  }

  /// 消费队列（受 maxConcurrent 限流）
  void _pump(PreloadConfig config) {
    while (_inflight < config.maxConcurrent) {
      final task = _queue.dequeue(
        skipExpired: true,
        skipIfCached: (url, transform) =>
            _controller.isCached(url, transform),
      );
      if (task == null) return;

      _inflight++;
      _controller
          .load(url: task.url, transform: task.transform, module: 'preload_${task.scene.name}')
          .then((_) => _queue.markSuccess(task.id))
          .catchError((Object e) => _queue.markFailure(task.id, e))
          .whenComplete(() {
        _inflight--;
        _pump(config);
      });
    }
  }

  /// 取消某场景未开始的预加载（页面退出时调用）
  void cancelScene(PreloadScene scene) => _queue.removeByScene(scene);
}

/// 预加载任务
class PreloadTask {
  final String id;          // ULID，幂等去重键
  final String url;
  final PreloadScene scene;
  final ImageTransform transform;
  final DateTime expireAt;  // 过期任务出队即丢弃（避免陈旧预加载浪费流量）

  const PreloadTask({
    required this.id,
    required this.url,
    required this.scene,
    required this.transform,
    required this.expireAt,
  });
}
```

### 4.3 AdaptEngine - 自适应质量控制引擎

```dart
/// 自适应质量控制引擎
///
/// 输入：请求的变换参数 + 当前环境快照
/// 输出：调整后的变换参数（只降不升，避免与 CDN 协商结果抖动）
class AdaptEngine {
  final NetworkMonitor _network;
  final DeviceCapability _device;

  AdaptEngine({required NetworkMonitor network, required DeviceCapability device})
      : _network = network,
        _device = device;

  /// 决策矩阵（节选，完整矩阵见 §11 配置中心）
  static const _decisionMatrix = {
    // 网络等级 → 最高允许质量
    'excellent': 90,
    'good': 80,
    'moderate': 65,
    'poor': 45,
  };

  Future<ImageTransform> adjust(ImageTransform requested) async {
    // 1. 低端设备（RAM ≤ 3GB 或 CPU 弱核占比高）：强制限制最大边长 1200px
    var result = requested;
    if (_device.isLowEnd) {
      result = _capMaxDimension(result, 1200);
    }

    // 2. 网络自适应：质量只降不升（守卫 G3）
    final networkLevel = await _network.currentLevel();
    final cap = _decisionMatrix[networkLevel] ?? 80;
    if (result.quality > cap) {
      result = ImageTransform(
        targetWidth: result.targetWidth,
        targetHeight: result.targetHeight,
        quality: cap,
        format: result.format,
        borderRadius: result.borderRadius,
        blur: result.blur,
        blurRadius: result.blurRadius,
        cropMode: result.cropMode,
        backgroundColor: result.backgroundColor,
      );
    }

    // 3. 省流模式（用户在设置中开启）：进一步下调并关闭智能裁剪
    if (await _device.isDataSaverEnabled()) {
      result = ImageTransform(
        targetWidth: result.targetWidth,
        targetHeight: result.targetHeight,
        quality: (result.quality * 0.8).round(),
        format: ImageFormat.webp,
        borderRadius: result.borderRadius,
        blur: result.blur,
        blurRadius: result.blurRadius,
        cropMode: CropMode.center, // 省流模式下关闭 smart/face 裁剪（服务端计算成本高）
        backgroundColor: result.backgroundColor,
      );
    }

    return result;
  }

  ImageTransform _capMaxDimension(ImageTransform t, int maxSide) {
    int? w = t.targetWidth;
    int? h = t.targetHeight;
    if (w != null && w > maxSide) w = maxSide;
    if (h != null && h > maxSide) h = maxSide;
    if (w == t.targetWidth && h == t.targetHeight) return t;
    return ImageTransform(
      targetWidth: w,
      targetHeight: h,
      quality: t.quality,
      format: t.format,
      borderRadius: t.borderRadius,
      blur: t.blur,
      blurRadius: t.blurRadius,
      cropMode: t.cropMode,
      backgroundColor: t.backgroundColor,
    );
  }
}
```

### 4.4 MemoryGuard - 内存安全监控器

```dart
/// 内存安全监控器
///
/// 双阈值 + 分级响应：
/// - 预警水位（70%）：停止预加载 + 下调内存缓存容量系数至 0.6
/// - 危险水位（85%）：清空弱引用层 + 内存缓存系数至 0.3 + 通知渲染层暂停大图解码
class MemoryGuard {
  final MemoryImageCache _memoryCache;
  final SmartPreloader? _preloader;
  final void Function(MemoryPressureLevel level)? _onLevelChange;

  static const double _warnRatio = 0.70;
  static const double _dangerRatio = 0.85;

  MemoryPressureLevel _currentLevel = MemoryPressureLevel.normal;

  MemoryGuard({
    required MemoryImageCache memoryCache,
    SmartPreloader? preloader,
    void Function(MemoryPressureLevel level)? onLevelChange,
  })  : _memoryCache = memoryCache,
        _preloader = preloader,
        _onLevelChange = onLevelChange;

  /// 由系统内存压力回调（Android onTrimMemory / iOS didReceiveMemoryWarning）触发
  void onSystemPressure(SystemMemoryLevel level) {
    switch (level) {
      case SystemMemoryLevel.trimMemoryModerate:
      case SystemMemoryLevel.didReceiveMemoryWarning:
        _enterLevel(MemoryPressureLevel.warn);
        break;
      case SystemMemoryLevel.trimMemoryComplete:
      case SystemMemoryLevel.trimMemoryUiHidden:
        _enterLevel(MemoryPressureLevel.danger);
        break;
      default:
        break; // runningLow / runningCritical 不降级，避免误伤前台体验
    }
  }

  void _enterLevel(MemoryPressureLevel target) {
    if (target == _currentLevel) return;
    // 只允许升级立即生效；降级需连续 3 次采样正常（防抖，守卫 G8）
    if (target.index < _currentLevel.index && !_canDegrade()) return;

    _currentLevel = target;
    switch (target) {
      case MemoryPressureLevel.normal:
        _memoryCache.maxBytesRestore();
        break;
      case MemoryPressureLevel.warn:
        _preloader?.pauseAll();
        _memoryCache.maxBytesDownscale(0.6); // G7：只缩容，不 dispose 使用中图片
        break;
      case MemoryPressureLevel.danger:
        _preloader?.pauseAll();
        _memoryCache.maxBytesDownscale(0.3);
        _memoryCache.purgeWeakLayer();
        _onLevelChange?.call(target);
        break;
    }
  }

  // 防抖采样
  int _normalSamples = 0;
  bool _canDegrade() {
    _normalSamples++;
    if (_normalSamples >= 3) {
      _normalSamples = 0;
      return true;
    }
    return false;
  }

  bool isUnderPressure() => _currentLevel != MemoryPressureLevel.normal;

  /// 预估解码后内存（用于大图硬顶拦截，守卫 G6）
  static int estimateDecodedBytes(int width, int height, int bytesPerPixel) {
    return width * height * bytesPerPixel * 4; // 解码缓冲 ×4（位图+双缓冲保守估计）
  }
}

enum MemoryPressureLevel { normal, warn, danger }
enum SystemMemoryLevel {
  runningLow,
  runningModerate,
  runningCritical,
  trimMemoryModerate,
  trimMemoryComplete,
  trimMemoryUiHidden,
  didReceiveMemoryWarning,
}
```

**守卫约束：**
- G6：单图解码后预估内存 > 32MB（如 8000×6000 原图）时拒绝解码，返回 `PIL_008` 并要求业务方使用 `thumbnail` 预设重试；
- G7：降级只调整容量上限并 LRU 淘汰，绝不 `dispose` 仍被 Widget 持有的 `ui.Image`；
- G8：水位降级需连续 3 次正常采样，防止阈值附近抖动导致缓存反复缩容/恢复。

### 4.5 PrimeImage Widget - 统一图片组件

```dart
/// 统一图片组件（业务方唯一入口）
///
/// 状态流转：placeholder → loading → loaded（fadeIn） / error（可重试）
class PrimeImage extends StatefulWidget {
  final String url;
  final ImageTransform transform;
  final double? width;
  final double? height;
  final BoxFit fit;
  final String module;

  /// 占位策略
  final PlaceholderType placeholder;

  /// 错误兜底图（缺省：模块级缺省图）
  final Widget? errorWidget;

  const PrimeImage.network({
    super.key,
    required this.url,
    this.transform = ImageTransform.standard,
    this.width,
    this.height,
    this.fit = BoxFit.cover,
    required this.module,
    this.placeholder = PlaceholderType.shimmer,
    this.errorWidget,
  });

  @override
  State<PrimeImage> createState() => _PrimeImageState();
}

class _PrimeImageState extends State<PrimeImage> {
  ImageLoadResult? _result;
  Object? _error;
  bool _disposed = false;

  @override
  void initState() {
    super.initState();
    _load();
  }

  @override
  void didUpdateWidget(PrimeImage oldWidget) {
    super.didUpdateWidget(oldWidget);
    // URL 或变换参数变化才重新加载（守卫 G1：避免父级 rebuild 导致重复请求）
    if (oldWidget.url != widget.url || oldWidget.transform != widget.transform) {
      _load();
    }
  }

  Future<void> _load() async {
    try {
      final result = await ImageLoaderProvider.of(context).load(
            url: widget.url,
            transform: widget.transform,
            module: widget.module,
          );
      if (!_disposed && mounted) setState(() => _result = result);
    } catch (e) {
      if (!_disposed && mounted) setState(() => _error = e);
    }
  }

  @override
  void dispose() {
    _disposed = true; // 守卫 G2：异步回调不操作已卸载组件
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final result = _result;
    if (result != null) {
      return TweenAnimationBuilder<double>(
        tween: Tween(begin: 0, end: 1),
        duration: const Duration(milliseconds: 250),
        builder: (_, opacity, child) => Opacity(opacity: opacity, child: child),
        child: RawImage(
          image: result.image,
          width: widget.width,
          height: widget.height,
          fit: widget.fit,
        ),
      );
    }
    if (_error != null) {
      return GestureDetector(
        onTap: _load, // 点击重试
        child: widget.errorWidget ??
            ImageLoaderProvider.of(context).defaultErrorWidget(widget.module),
      );
    }
    return widget.placeholder == PlaceholderType.shimmer
        ? const ShimmerPlaceholder()
        : const BlurHashPlaceholder();
  }
}

enum PlaceholderType { shimmer, blurHash }
```

## 13. 合规与安全

1. C1：图片 URL 仅允许 http/https scheme，`file://`、`content://` 由多媒体选取模块处理，不进入本加载器；
2. C2：上报埋点中的 URL 一律记录 SHA-256 前 16 位哈希，不携带完整 URL（防用户敏感信息进入日志）；
3. C3：用户头像等个人图片的磁盘缓存参与"清理缓存"与注销清除流程（与《数据导出与账户注销完整链路》对齐）；
4. C4：CDN 签名 URL 的有效期处理：缓存键基于去签名后的原始 URL 生成，避免签名轮换导致缓存失效；
5. C5：不加载任意业务方传入的不可信域名，域名白名单由配置中心下发。
