# 服务端业务状态机与通用工作流引擎 - 详细设计

## 1. 文档概述

### 1.1 目的

为 PrimeTop 各业务模块（订单、会员、学习计划、任务、内容审核、错题复习等）提供统一的**状态机框架**和**工作流引擎**设计，使开发人员可以：
- 通过声明式配置定义业务状态流转
- 使用统一的 API 驱动状态变更
- 自动记录状态变更审计日志
- 支持条件守卫、超时自动流转、事件触发等高级能力
- 避免各模块各自实现状态管理导致的不一致和维护困难

### 1.2 适用范围

- 服务端所有涉及状态流转的业务模块
- 需要多步骤审批/审核的工作流场景
- 定时任务驱动的自动状态流转

### 1.3 依赖

| 依赖项 | 版本要求 | 说明 |
|--------|---------|------|
| Spring Boot | 3.x | 基础框架 |
| Spring Data JPA | 3.x | 实体与仓储 |
| Redis | 7.x+ | 分布式锁与状态缓存 |
| MySQL | 8.x+ | 状态定义与流转记录持久化 |
| 事件总线 | 内部实现 | 异步事件通知 |

## 2. 核心概念

### 2.1 状态机模型

```
┌──────────────────────────────────────────────────────┐
│                   StateMachine                        │
│  ┌─────────┐    ┌──────────┐    ┌────────────────┐   │
│  │  State  │◄───│Transition│───►│    State       │   │
│  │ (from)  │    │          │    │    (to)        │   │
│  └─────────┘    │ - event  │    └────────────────┘   │
│                 │ - guard  │                          │
│                 │ - action │                          │
│                 └──────────┘                          │
└──────────────────────────────────────────────────────┘
```

| 概念 | 说明 | 示例 |
|------|------|------|
| **StateMachine** | 状态机定义，包含一组状态和转换 | 订单状态机、审核状态机 |
| **State** | 业务实体的某种状态 | `PENDING_PAYMENT`、`ACTIVE` |
| **Transition** | 从一个状态到另一个状态的转换规则 | `PAY` → `PENDING_PAYMENT` → `PAID` |
| **Event** | 触发状态转换的事件 | `USER_PAY`、`SYSTEM_TIMEOUT` |
| **Guard** | 转换前置条件，返回 true 才允许转换 | 余额充足检查 |
| **Action** | 转换成功后执行的副作用 | 发送通知、更新关联数据 |
| **Context** | 转换时携带的上下文数据 | 支付金额、操作人、原因 |

### 2.2 工作流模型

工作流是状态机的上层编排，用于多步骤、多角色的审批/审核流程。

```
┌─────────────────────────────────────────────────────────┐
│                      Workflow                            │
│                                                          │
│  Step1 ──► Step2 ──► Step3 ──► Step4                    │
│  (提交)    (初审)    (复审)    (发布)                     │
│             │                   │                        │
│             ▼                   ▼                        │
│          (驳回)              (驳回)                      │
│             │                   │                        │
│             └──────► Step1      └──────► Step1           │
└─────────────────────────────────────────────────────────┘
```

## 3. 数据结构设计

### 3.1 状态机定义表 `sm_machine_def`

```sql
CREATE TABLE sm_machine_def (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    machine_key     VARCHAR(64) NOT NULL COMMENT '状态机唯一标识，如 order、membership',
    machine_name    VARCHAR(128) NOT NULL COMMENT '状态机名称',
    biz_type        VARCHAR(64) NOT NULL COMMENT '关联业务类型',
    description     VARCHAR(512) COMMENT '描述',
    version         INT NOT NULL DEFAULT 1 COMMENT '定义版本号',
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '1-启用 0-禁用',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_machine_key (machine_key),
    KEY idx_biz_type (biz_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='状态机定义';
```

### 3.2 状态定义表 `sm_state_def`

```sql
CREATE TABLE sm_state_def (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    machine_id      BIGINT NOT NULL COMMENT '关联状态机ID',
    state_key       VARCHAR(64) NOT NULL COMMENT '状态标识，如 PENDING_PAYMENT',
    state_name      VARCHAR(128) NOT NULL COMMENT '状态显示名称',
    state_type      TINYINT NOT NULL COMMENT '1-初始态 2-中间态 3-终态',
    is_transient    TINYINT NOT NULL DEFAULT 0 COMMENT '是否瞬态(自动流出) 0-否 1-是',
    timeout_seconds BIGINT COMMENT '超时秒数，null表示不超时',
    timeout_event   VARCHAR(64) COMMENT '超时后触发的事件',
    sort_order      INT NOT NULL DEFAULT 0 COMMENT '排序',
    description     VARCHAR(512),
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_machine_state (machine_id, state_key),
    KEY idx_machine_id (machine_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='状态定义';
```

### 3.3 转换定义表 `sm_transition_def`

```sql
CREATE TABLE sm_transition_def (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    machine_id      BIGINT NOT NULL COMMENT '关联状态机ID',
    transition_key  VARCHAR(64) NOT NULL COMMENT '转换标识，如 pay、cancel',
    transition_name VARCHAR(128) NOT NULL COMMENT '转换名称',
    from_state_key  VARCHAR(64) NOT NULL COMMENT '源状态',
    to_state_key    VARCHAR(64) NOT NULL COMMENT '目标状态',
    event_key       VARCHAR(64) NOT NULL COMMENT '触发事件标识',
    guard_bean      VARCHAR(128) COMMENT 'Spring Bean 名称，守卫条件实现类',
    action_bean     VARCHAR(128) COMMENT 'Spring Bean 名称，转换后执行动作',
    priority        INT NOT NULL DEFAULT 0 COMMENT '同一事件多转换时优先级',
    description     VARCHAR(512),
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_machine_transition (machine_id, from_state_key, event_key),
    KEY idx_machine_from (machine_id, from_state_key)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='转换定义';
```

### 5.2 核心接口定义

```java
/**
 * 守卫条件接口 - 判断状态转换是否被允许
 */
public interface Guard {

    /**
     * 守卫标识
     */
    String getBeanName();

    /**
     * 检查是否允许转换
     *
     * @param context 转换上下文
     * @return true 允许转换，false 拒绝
     */
    boolean evaluate(TransitionContext context);

    /**
     * 拒绝原因（evaluate 返回 false 时使用）
     */
```

### 5.4 状态机引擎核心实现

```java
/**
 * 状态机引擎 - 核心服务
 */
@Service
@Slf4j
public class StateMachineEngine {

    @Autowired
    private SmMachineDefRepository machineDefRepo;
    @Autowired
    private SmTransitionDefRepository transitionDefRepo;
    @Autowired
    private SmBizStateRepository bizStateRepo;
    @Autowired
    private SmTransitionLogRepository logRepo;
    @Autowired
    private ApplicationContext applicationContext;
    @Autowired
    private RedissonClient redissonClient;
    @Autowired
    private List<StateChangeListener> listeners;

    // 状态机定义本地缓存（定期刷新）
    private final LoadingCache<String, MachineDefinition> machineCache =
        Caffeine.newBuilder()
            .refreshAfterWrite(5, TimeUnit.MINUTES)
            .build(this::loadMachineDefinition);

    /**
     * 触发状态转换（核心方法）
     */
    @Transactional
    public FireResult fire(String machineKey, String bizType, String bizId,
                           String event, String operatorType, String operatorId,
                           Map<String, Object> context) {

        // 1. 获取分布式锁，防止并发状态变更
        RLock lock = redissonClient.getLock(
            "sm:lock:" + bizType + ":" + bizId);
        boolean locked = false;
        try {
            locked = lock.tryLock(5, 30, TimeUnit.SECONDS);
            if (!locked) {
                throw new SmException("获取状态锁失败，请稍后重试");
            }

            // 2. 加载状态机定义
            MachineDefinition machineDef = machineCache.get(machineKey);

            // 3. 查询业务实体当前状态（乐观锁）
            SmBizState bizState = bizStateRepo
                .findByBizTypeAndBizId(bizType, bizId)
                .orElseThrow(() -> new SmException(
                    "业务实体不存在: " + bizType + "/" + bizId));

            String currentState = bizState.getCurrentState();

            // 4. 查找匹配的转换定义
            SmTransitionDef transitionDef = transitionDefRepo
                .findByMachineIdAndFromStateKeyAndEventKey(
                    machineDef.getMachineId(), currentState, event)
                .orElseThrow(() -> new TransitionNotFoundException(
                    machineKey, currentState, event));

            String targetState = transitionDef.getToStateKey();

            // 5. 构建转换上下文
            TransitionContext ctx = TransitionContext.builder()
                .machineKey(machineKey)
                .bizType(bizType)
                .bizId(bizId)
                .fromState(currentState)
                .toState(targetState)
                .eventKey(event)
                .transitionKey(transitionDef.getTransitionKey())
                .operatorType(operatorType)
                .operatorId(operatorId)
                .context(context)
                .stateData(parseStateData(bizState.getStateData()))
                .build();

            long startTime = System.currentTimeMillis();

            // 6. 执行守卫条件检查
            boolean guardPassed = executeGuard(transitionDef, ctx);
            if (!guardPassed) {
                // 记录被拒绝的日志
                saveLog(ctx, false, false, "守卫条件拒绝", 0);
                throw new GuardRejectedException(machineKey, currentState, event);
            }

            // 7. 更新业务状态（乐观锁）
            int updated = bizStateRepo.updateState(
                bizType, bizId, targetState,
                currentState, bizState.getVersion());
            if (updated == 0) {
                throw new StateConflictException(
                    "状态已被其他操作变更，请刷新后重试");
            }

            // 8. 执行转换后动作
            boolean actionSuccess = true;
            String errorMsg = null;
            try {
                executeAction(transitionDef, ctx);
            } catch (Exception e) {
                actionSuccess = false;
                errorMsg = e.getMessage();
                log.error("转换动作执行失败: {}.{} -> {}",
                    machineKey, currentState, targetState, e);
                // 注意：状态已更新，动作失败只记日志，不回滚状态
            }

            long durationMs = System.currentTimeMillis() - startTime;

            // 9. 记录流转日志
            Long logId = saveLog(ctx, true, actionSuccess, errorMsg, durationMs);

            // 10. 发布状态变更事件
            publishEvent(ctx, logId);

            return FireResult.builder()
                .fromState(currentState)
                .toState(targetState)
                .transitionKey(transitionDef.getTransitionKey())
                .transitionLogId(logId)
                .timestamp(LocalDateTime.now())
                .build();

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new SmException("状态转换被中断");
        } finally {
            if (locked && lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    /**
     * 初始化业务实体状态
     */
    @Transactional
    public void initState(String machineKey, String bizType, String bizId,
                          String initialState, Map<String, Object> stateData) {
        SmBizState bizState = new SmBizState();
        bizState.setMachineKey(machineKey);
        bizState.setBizType(bizType);
        bizState.setBizId(bizId);
        bizState.setCurrentState(initialState);
        bizState.setStateData(stateData != null
            ? JsonUtils.toJson(stateData) : null);
        bizState.setVersion(0);
        bizStateRepo.save(bizState);
    }

    /**
     * 执行守卫检查
     */
    private boolean executeGuard(SmTransitionDef transitionDef,
                                  TransitionContext ctx) {
        String guardBean = transitionDef.getGuardBean();
        if (guardBean == null || guardBean.isEmpty()) {
            return true; // 无守卫，直接通过
        }

        Guard guard = applicationContext.getBean(guardBean, Guard.class);
        return guard.evaluate(ctx);
    }

    /**
     * 执行转换后动作
     */
    private void executeAction(SmTransitionDef transitionDef,
                                TransitionContext ctx) {
        String actionBean = transitionDef.getActionBean();
        if (actionBean == null || actionBean.isEmpty()) {
            return; // 无动作
        }

        Action action = applicationContext.getBean(actionBean, Action.class);
        action.execute(ctx);
    }

    /**
     * 发布状态变更事件
     */
    private void publishEvent(TransitionContext ctx, Long logId) {
        StateChangedEvent event = new StateChangedEvent(
            ctx.getMachineKey(), ctx.getBizType(), ctx.getBizId(),
            ctx.getFromState(), ctx.getToState(), ctx.getEventKey(),
            ctx.getTransitionKey(), ctx.getOperatorType(),
            ctx.getOperatorId(), logId);

        // 同步通知监听器
        for (StateChangeListener listener : listeners) {
            String[] concerns = listener.concernMachineKeys();
            if (concerns.length == 0
                || Arrays.asList(concerns).contains(ctx.getMachineKey())) {
                try {
                    listener.onStateChanged(event);
                } catch (Exception e) {
                    log.warn("状态变更监听器异常: {}", listener.getClass(), e);
                }
            }
        }

        // 异步发布 Spring 事件
        applicationContext.publishEvent(event);
    }
}
```

```java
/**
 * 超时状态自动流转扫描器
 * 定期扫描所有超时状态，触发超时事件
 */
@Component
@Slf4j
public class TimeoutScanner {

    @Autowired
    private SmBizStateRepository bizStateRepo;
    @Autowired
    private SmStateDefRepository stateDefRepo;
    @Autowired
    private StateMachineEngine engine;

    /**
     * 每 60 秒扫描一次超时状态
     * 使用分布式锁确保只有一个实例在执行
     */
    @Scheduled(fixedDelay = 60000)
    public void scanTimeout() {
        RLock lock = redissonClient.getLock("sm:timeout:scan");
        boolean locked = false;
        try {
            locked = lock.tryLock(0, 55, TimeUnit.SECONDS);
            if (!locked) return;

            // 查询所有有超时配置的状态
            List<SmStateDef> timeoutStates = stateDefRepo
                .findByIsTransientAndTimeoutSecondsNotNull(1);

            for (SmStateDef stateDef : timeoutStates) {
                processTimeoutState(stateDef);
            }
        } catch (Exception e) {
            log.error("超时扫描异常", e);
        } finally {
            if (locked && lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    private void processTimeoutState(SmStateDef stateDef) {
        LocalDateTime deadline = LocalDateTime.now()
            .minusSeconds(stateDef.getTimeoutSeconds());

        List<SmBizState> expiredStates = bizStateRepo
            .findByCurrentStateAndUpdatedBefore(
                stateDef.getStateKey(), deadline);

        for (SmBizState bizState : expiredStates) {
            try {
                engine.fire(
                    bizState.getMachineKey(),
                    bizState.getBizType(),
                    bizState.getBizId(),
                    stateDef.getTimeoutEvent(),
                    "CRON",
                    "timeout-scanner",
                    Collections.emptyMap()
                );
                log.info("超时状态自动流转: {}/{} {} -> timeout",
                    bizState.getBizType(), bizState.getBizId(),
                    bizState.getCurrentState());
            } catch (Exception e) {
                log.warn("超时流转失败: {}/{} - {}",
                    bizState.getBizType(), bizState.getBizId(),
                    e.getMessage());
            }
        }
    }
}
```

### 5.6 工作流引擎核心实现

```java
/**
 * 工作流引擎
 */
@Service
@Slf4j
public class WorkflowEngine {

    @Autowired
    private WfWorkflowDefRepository workflowDefRepo;
    @Autowired
    private WfStepDefRepository stepDefRepo;
    @Autowired
    private WfInstanceRepository instanceRepo;
    @Autowired
    private WfStepRecordRepository stepRecordRepo;
    @Autowired
    private ApplicationContext applicationContext;

    /**
     * 发起工作流
     */
    @Transactional
    public WfInstance startWorkflow(String workflowKey, String bizType,
            String bizId, String initiatorType, String initiatorId,
            Map<String, Object> context) {

        WfWorkflowDef workflowDef = workflowDefRepo
            .findByWorkflowKey(workflowKey)
            .orElseThrow(() -> new SmException(
                "工作流定义不存在: " + workflowKey));

        // 获取第一个步骤
        WfStepDef firstStep = stepDefRepo
            .findFirstByWorkflowIdOrderBySortOrder(workflowDef.getId())
            .orElseThrow(() -> new SmException(
                "工作流无步骤定义: " + workflowKey));

        // 创建实例
        WfInstance instance = new WfInstance();
        instance.setWorkflowKey(workflowKey);
        instance.setBizType(bizType);
        instance.setBizId(bizId);
        instance.setCurrentStep(firstStep.getStepKey());
        instance.setStatus(WorkflowStatus.IN_PROGRESS.getCode());
        instance.setInitiatorType(initiatorType);
        instance.setInitiatorId(initiatorId);
        instanceRepo.save(instance);

        // 记录提交步骤
        WfStepRecord record = new WfStepRecord();
        record.setInstanceId(instance.getId());
        record.setStepKey(firstStep.getStepKey());
        record.setStepName(firstStep.getStepName());
        record.setAction("SUBMIT");
        record.setOperatorType(initiatorType);
        record.setOperatorId(initiatorId);
        record.setContext(context != null
            ? JsonUtils.toJson(context) : null);
        stepRecordRepo.save(record);

        // 如果是自动处理步骤，立即执行
        if (firstStep.getStepType() == StepType.AUTO.getCode()
            && firstStep.getAutoActionBean() != null) {
            executeAutoStep(instance, firstStep, context);
        }

        return instance;
    }

    /**
     * 审批步骤
     */
    @Transactional
    public void approve(Long instanceId, String stepKey, String action,
            String operatorType, String operatorId, String comment,
            Map<String, Object> context) {

        WfInstance instance = instanceRepo.findById(instanceId)
            .orElseThrow(() -> new SmException(
                "工作流实例不存在: " + instanceId));

        if (instance.getStatus() != WorkflowStatus.IN_PROGRESS.getCode()) {
            throw new SmException("工作流已结束，无法审批");
        }

        if (!instance.getCurrentStep().equals(stepKey)) {
            throw new SmException(
                "当前步骤不匹配: 期望 " + instance.getCurrentStep()
                + " 实际 " + stepKey);
        }

        WfWorkflowDef workflowDef = workflowDefRepo
            .findByWorkflowKey(instance.getWorkflowKey())
            .orElseThrow();
        WfStepDef currentStepDef = stepDefRepo
            .findByWorkflowIdAndStepKey(
                workflowDef.getId(), stepKey)
            .orElseThrow();

        // 记录审批
        WfStepRecord record = new WfStepRecord();
        record.setInstanceId(instanceId);
        record.setStepKey(stepKey);
        record.setStepName(currentStepDef.getStepName());
        record.setAction(action);
        record.setOperatorType(operatorType);
        record.setOperatorId(operatorId);
        record.setComment(comment);
        record.setContext(context != null
            ? JsonUtils.toJson(context) : null);
        stepRecordRepo.save(record);

        // 根据动作推进工作流
        switch (action) {
            case "APPROVE":
                moveToNextStep(instance, currentStepDef);
                break;
            case "REJECT":
                handleReject(instance, currentStepDef);
                break;
            case "WITHDRAW":
                instance.setStatus(WorkflowStatus.WITHDRAWN.getCode());
                instance.setFinishedAt(LocalDateTime.now());
                instanceRepo.save(instance);
                break;
            default:
                throw new SmException("不支持的动作: " + action);
        }
    }

    /**
     * 推进到下一步
     */
    private void moveToNextStep(WfInstance instance, WfStepDef currentStep) {
        String nextStepKey = currentStep.getNextStepKey();
        if (nextStepKey == null || nextStepKey.isEmpty()) {
            // 无下一步，工作流完成
            instance.setStatus(WorkflowStatus.COMPLETED.getCode());
            instance.setFinishedAt(LocalDateTime.now());
            instanceRepo.save(instance);
            return;
        }

        instance.setCurrentStep(nextStepKey);
        instanceRepo.save(instance);

        // 检查下一步是否自动处理
        WfWorkflowDef workflowDef = workflowDefRepo
            .findByWorkflowKey(instance.getWorkflowKey()).orElseThrow();
        WfStepDef nextStepDef = stepDefRepo
            .findByWorkflowIdAndStepKey(
                workflowDef.getId(), nextStepKey).orElseThrow();

        if (nextStepDef.getStepType() == StepType.AUTO.getCode()
            && nextStepDef.getAutoActionBean() != null) {
            executeAutoStep(instance, nextStepDef, null);
        }
    }

    private void handleReject(WfInstance instance, WfStepDef currentStep) {
        String rejectStepKey = currentStep.getRejectStepKey();
        if (rejectStepKey != null && !rejectStepKey.isEmpty()) {
            // 驳回到指定步骤
            instance.setCurrentStep(rejectStepKey);
            instanceRepo.save(instance);
        } else {
            // 直接结束
            instance.setStatus(WorkflowStatus.REJECTED.getCode());
            instance.setFinishedAt(LocalDateTime.now());
            instanceRepo.save(instance);
        }
    }
}
```

```java
/**
 * 退款资格检查
 * 规则：支付后24小时内可自助退款
 */
@Component("refundEligibilityGuard")
public class RefundEligibilityGuard implements Guard {

    @Autowired
    private SmTransitionLogRepository logRepo;

    @Override
    public String getBeanName() {
        return "refundEligibilityGuard";
    }

    @Override
    public boolean evaluate(TransitionContext context) {
        // 查询支付成功的时间
        Optional<SmTransitionLog> payLog = logRepo
            .findFirstByBizTypeAndBizIdAndEventKeyOrderByCreatedAtDesc(
                context.getBizType(),
                context.getBizId(),
                "PAY_SUCCESS");

        if (payLog.isEmpty()) return false;

        LocalDateTime payTime = payLog.get().getCreatedAt();
        LocalDateTime deadline = payTime.plusHours(24);

        return LocalDateTime.now().isBefore(deadline);
    }

    @Override
    public String getRejectReason(TransitionContext context) {
```

### 7.2 订单支付成功动作

```java
/**
 * 订单支付成功后执行动作
 */
@Component("orderPayAction")
public class OrderPayAction implements Action {

    @Autowired
    private MembershipService membershipService;
    @Autowired
    private MessageService messageService;
    @Autowired
    private SmBizStateRepository bizStateRepo;

    @Override
    public String getBeanName() {
        return "orderPayAction";
    }

    @Override
    public void execute(TransitionContext context) {
        String orderId = context.getBizId();
        String userId = context.get("userId", String.class);
        String membershipType = context.get("membershipType", String.class);
        Integer durationDays = context.get("durationDays", Integer.class);

        // 1. 激活会员
        membershipService.activate(userId, membershipType, durationDays);

        // 2. 发送支付成功通知
        messageService.send(userId, "PAYMENT_SUCCESS", Map.of(
            "orderId", orderId,
            "membershipType", membershipType
        ));

        // 3. 更新订单业务数据
        bizStateRepo.updateStateData(
            context.getBizType(), context.getBizId(),
            Map.of("paidAt", LocalDateTime.now().toString())
        );
    }
}
```

```java
/**
```

## 9. 错误处理

### 9.1 异常码定义

| 异常码 | 含义 | 处理建议 |
|--------|------|----------|
| 40301 | 守卫条件拒绝 | 前端展示拒绝原因 |
| 40302 | 当前状态不支持此事件 | 刷新页面获取最新状态 |
| 40303 | 状态机定义不存在 | 检查配置 |
| 40304 | 业务实体状态不存在 | 先初始化状态 |
| 40305 | 乐观锁冲突 | 重试或提示用户 |
| 40306 | 分布式锁获取失败 | 稍后重试 |
| 40307 | 转换动作执行失败 | 记录日志，通知运营 |

### 9.2 并发冲突处理

```
场景：用户在手机和Pad上同时操作同一订单

1. 分布式锁 → 保证同一时刻只有一个请求能处理
2. 乐观锁 → 二次确认状态未被其他请求修改
3. 若冲突 → 返回 40305，前端提示"操作冲突，请刷新"
```

### 9.3 动作失败补偿策略

| 失败类型 | 策略 | 说明 |
|----------|------|------|
| 通知发送失败 | 异步重试 | 不阻塞状态流转 |
| 关联数据更新失败 | 记录补偿任务 | 后台定时重试 |
| 外部服务不可用 | 降级处理 | 记录日志，人工处理 |

## 12. 接入指南（给开发人员）

### 12.1 新业务模块接入步骤

```
1. 在 sm_machine_def 表定义状态机
2. 在 sm_state_def 表定义各状态
3. 在 sm_transition_def 表定义转换规则
4. 如有守卫需求，实现 Guard 接口并注册为 Spring Bean
5. 如有动作需求，实现 Action 接口并注册为 Spring Bean
6. 业务创建时调用 engine.initState() 初始化状态
7. 业务操作时调用 engine.fire() 触发转换
```

### 12.2 代码接入示例

```java
@Service
public class OrderService {

    @Autowired
    private StateMachineEngine smEngine;

    /**
     * 创建订单
     */
    public Order createOrder(CreateOrderRequest req) {
        Order order = saveOrder(req);

        // 初始化状态机
        smEngine.initState(
            "order", "order", order.getId(),
            "CREATED", Map.of("amount", order.getAmount())
        );

        // 触发确认
        smEngine.fire("order", "order", order.getId(),
            "CONFIRM", "USER", req.getUserId(),
            Map.of());

        return order;
    }

    /**
     * 支付成功回调
     */
    public void onPaymentSuccess(String orderId, String paymentMethod,
                                  String transactionId) {
        smEngine.fire("order", "order", orderId,
            "PAY_SUCCESS", "SYSTEM", "payment-service",
            Map.of(
                "paymentMethod", paymentMethod,
                "transactionId", transactionId
            ));
    }

    /**
     * 查询订单状态
     */
    public OrderVO getOrder(String orderId) {
        Order order = orderRepo.findById(orderId);

        // 获取状态机信息
        SmBizStateVO state = smEngine.queryState("order", "order", orderId);

        return OrderVO.builder()
            .order(order)
            .currentState(state.getCurrentState())
            .availableEvents(state.getAvailableEvents())
            .build();
    }
}
```

### 12.3 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| fire 报 40305 | 乐观锁冲突 | 前端刷新后重试 |
| 状态不更新 | 动作抛异常但状态已更新 | 检查 transition_log 中 action_result=0 的记录 |
| 超时未触发 | 扫描器未运行或 Redis 锁冲突 | 检查 TimeoutScanner 日志 |
| 守卫一直拒绝 | Guard Bean 实现逻辑错误 | 检查 Guard 实现类的 evaluate 方法 |
