# 服务端 - 学生升学路径智能规划与高考志愿填报辅助推荐引擎

## 1. 文档概述

### 1.1 文档目的

本文档详细设计 PrimeTop 平台的「升学路径智能规划与高考志愿填报辅助推荐引擎」，为高中学生提供从升学目标设定、大学专业探索、录取概率预测到高考志愿填报策略推荐的完整服务链路。目标是让开发人员能直接依据本文档进行编码实现。

### 1.2 功能定位

| 维度 | 说明 |
|------|------|
| 目标用户 | 高中阶段学生（重点服务高三考生及家长） |
| 核心价值 | 用数据驱动+AI智能分析取代"信息差"驱动的志愿填报，降低决策焦虑 |
| 业务边界 | 提供信息参考与智能推荐，**不承诺**录取结果，不代替省级招生考试机构的正式志愿填报系统 |
| 优先级 | P1（V1.5 阶段上线，高考前3个月开放完整功能） |
| 付费门槛 | 基础院校查询免费；录取概率预测与志愿方案智能生成需年度会员 |

### 1.4 术语表

| 术语 | 含义 |
|------|------|
| 志愿 | 考生填报的院校+专业组合，按优先级排序 |
| 投档线 | 某院校某年在某省的最低录取分数 |
| 位次 (Rank) | 考生成绩在全省同科类考生中的排名 |
| 线差 | 考生分数与省控线（批次线）的差值 |
| 专业级差 | 部分院校专业录取时设置的非第一专业志愿分数扣减规则 |
| 3+3 模式 | 新高考方案：语数外3门必考 + 从6门选考科目中选3门 |
| 3+1+2 模式 | 新高考方案：语数外3门必考 + 物理或历史1门 + 从4门中选2门 |
| 院校专业组 | 新高考模式下，院校按选科要求将专业打包成的报考单元 |
| 征集志愿 | 各批次未完成招生计划时，省级招考机构组织的补充填报 |
| 大类招生 | 院校按学科大类而非具体专业进行招生，入校后分流 |

### 2.2 服务模块划分

| 模块 | 职责 | 部署方式 |
|------|------|----------|
| `admission-data-service` | 院校/专业/录取数据的采集、清洗、存储、查询 | 独立服务 |
| `admission-predict-service` | 录取概率预测模型训练与推理 | 独立服务（可使用GPU） |
| `volunteer-generator-service` | 志愿方案智能生成与优化 | 独立服务 |
| `career-planning-service` | 职业兴趣测评与升学路径规划 | 独立服务 |
| `admission-bff` | 面向客户端的BFF聚合层 | 随API网关部署 |

### 2.3 技术选型

| 层面 | 选型 | 理由 |
|------|------|------|
| 主开发语言 | Python 3.11+ | 数据科学生态丰富，适合统计建模 |
| Web框架 | FastAPI | 异步高性能，自动生成OpenAPI文档 |
| 预测模型 | scikit-learn + XGBoost + LightGBM | 梯度提升树在表格数据上表现优异 |
| 深度学习（可选） | PyTorch | 用于NLP专业匹配和文本相似度计算 |
| 数据存储 | PostgreSQL | 院校专业等结构化数据 |
| 搜索引擎 | Elasticsearch | 院校专业全文检索与多维筛选 |
| 缓存 | Redis | 热门院校数据、预测结果缓存 |
| 消息队列 | RabbitMQ | 数据采集更新异步任务 |
| 定时任务 | APScheduler / Celery Beat | 招生计划更新、模型重训练调度 |

## 3. 数据结构设计

### 3.1 院校数据表 (`pt_university`)

```sql
CREATE TABLE pt_university (
    id              BIGSERIAL PRIMARY KEY,
    code            VARCHAR(10) NOT NULL UNIQUE,      -- 院校代码（教育部统一编码）
    name            VARCHAR(100) NOT NULL,             -- 院校名称
    name_en         VARCHAR(200),                      -- 英文名称
    short_name      VARCHAR(50),                       -- 简称
    aliases         JSONB DEFAULT '[]',                -- 别名列表 ["清华","THU"]
    
    -- 基本属性
    level           VARCHAR(20) NOT NULL,              -- 层次: 985/211/双一流/普通本科/高职专科
    nature          VARCHAR(20) NOT NULL,              -- 办学性质: 公办/民办/中外合作
    type            VARCHAR(20) NOT NULL,              -- 类型: 综合/理工/师范/医药/财经/政法/农林/民族/艺术/体育/军事
    affiliation     VARCHAR(50),                       -- 主管部门
    province        VARCHAR(20) NOT NULL,              -- 所在省份
    city            VARCHAR(30) NOT NULL,              -- 所在城市
    district        VARCHAR(50),                       -- 所在区县
    address         VARCHAR(200),                      -- 详细地址
    zipcode         VARCHAR(10),                       -- 邮编
    
    -- 联系方式
    website         VARCHAR(200),                      -- 官网
    admission_url   VARCHAR(200),                      -- 招生网
    phone           VARCHAR(50),                       -- 招生电话
    email           VARCHAR(100),                      -- 招生邮箱
    
    -- 院校指标
    ranking_cn      INT,                               -- 国内排名（软科/校友会）
    ranking_qs       INT,                               -- QS世界排名
    is_985          BOOLEAN DEFAULT FALSE,
    is_211          BOOLEAN DEFAULT FALSE,
    is_double_first BOOLEAN DEFAULT FALSE,             -- 双一流
    
    -- 学科评估
    discipline_eval JSONB DEFAULT '{}',                -- 学科评估 {"A+": ["计算机"], "A": ["数学"], ...}
    
    -- 附加信息
    tags            JSONB DEFAULT '[]',                -- 标签 ["强基计划","保研率高","就业率高"]
    intro           TEXT,                              -- 院校简介
    logo_url        VARCHAR(500),                      -- 校徽URL
    campus_images   JSONB DEFAULT '[]',                -- 校园图片URL列表
    enrollment_guide JSONB,                            -- 招生章程结构化数据
    
    -- 状态管理
    status          VARCHAR(20) DEFAULT 'active',      -- active/inactive/merged
    merged_into     BIGINT REFERENCES pt_university(id), -- 合并后指向的院校ID
    
    -- 审计
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW(),
    
    INDEX idx_province (province),
    INDEX idx_level (level),
    INDEX idx_type (type),
    INDEX idx_name_trgm ON name USING gin (gin_trgm_ops)  -- 模糊搜索
);
```

### 3.2 专业数据表 (`pt_major`)

```sql
CREATE TABLE pt_major (
    id              BIGSERIAL PRIMARY KEY,
    code            VARCHAR(10) NOT NULL,               -- 专业代码
    name            VARCHAR(100) NOT NULL,               -- 专业名称
    category        VARCHAR(50) NOT NULL,                -- 学科门类: 哲学/经济学/法学/教育学/文学/历史学/理学/工学/农学/医学/管理学/艺术学/军事学
    subcategory     VARCHAR(50) NOT NULL,                -- 专业类: 如"计算机类"
    degree_type     VARCHAR(20) NOT NULL,                -- 学位类型: 学士/硕士(本硕连读)
    study_years     DECIMAL(3,1) DEFAULT 4.0,            -- 学制年限
    
    -- 选科要求（新高考）
    subject_requirement JSONB DEFAULT '{}',              -- 选科要求规则（见3.3节SubjectRequirement）
    
    -- 专业属性
    description     TEXT,                                -- 专业介绍
    core_courses    JSONB DEFAULT '[]',                  -- 核心课程列表
    employment_rate DECIMAL(5,2),                        -- 近三年平均就业率(%)
    avg_salary      INT,                                 -- 毕业一年平均月薪(元)
    career_directions JSONB DEFAULT '[]',               -- 就业方向 ["软件开发","数据分析",...]
    related_careers JSONB DEFAULT '[]',                  -- 关联职业ID列表
    
    -- 热度与评分
    heat_score      INT DEFAULT 0,                       -- 热度分（0-100）
    satisfaction    DECIMAL(3,2),                        -- 学生满意度(0-5.00)
    
    status          VARCHAR(20) DEFAULT 'active',
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW(),
    
    UNIQUE(code, name),
    INDEX idx_category (category),
    INDEX idx_subcategory (subcategory),
    INDEX idx_name_trgm ON name USING gin (gin_trgm_ops)
);
```

### 3.3 院校-专业关联表（含选科要求）(`pt_university_major`)

```sql
CREATE TABLE pt_university_major (
    id                  BIGSERIAL PRIMARY KEY,
    university_id       BIGINT NOT NULL REFERENCES pt_university(id),
    major_id            BIGINT NOT NULL REFERENCES pt_major(id),
    
    -- 专业组信息（新高考模式）
    major_group_code    VARCHAR(20),                    -- 院校专业组代码
    major_group_name    VARCHAR(100),                   -- 院校专业组名称
    
    -- 选科要求（核心字段）
    subject_requirement JSONB NOT NULL DEFAULT '{}',
    /*
    subject_requirement 结构:
    {
        "mode": "3+3" | "3+1+2" | "traditional",   // 高考模式
        "required_first": "physics" | "history" | null,  // 3+1+2 首选科目
        "required_select": ["chemistry", "biology"],     // 必选再选科目（必须全部选）
        "any_of": [["politics", "geography"]],            // 至少选其中一组之一
        "select_count": 2,                                // 再选科目数量要求
        "equivalent": "physics+chemistry",                // 等效要求说明
        "description": "必选物理，再选化学或生物"           -- 人类可读描述
    }
    
    传统高考模式:
    {
        "mode": "traditional",
        "arts_science": "science" | "arts" | "both"
    }
    */
    
    -- 招生属性
    enrollment_type     VARCHAR(30) DEFAULT 'normal',   -- normal/大类专业/中外合作/定向/国防生
    tuition             INT,                             -- 学费(元/年)
    dorm_info           VARCHAR(200),                    -- 住宿信息
    special_requirements TEXT,                           -- 特殊要求（视力/身高等）
    
    -- 历年招生计划（缓存最近一年，历史见 pt_admission_plan 表）
    latest_plan_year    INT,                             -- 最近招生计划年份
    latest_quota        INT,                             -- 最近招生计划人数
    
    status              VARCHAR(20) DEFAULT 'active',
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    updated_at          TIMESTAMPTZ DEFAULT NOW(),
    
    UNIQUE(university_id, major_id, major_group_code),
    INDEX idx_university (university_id),
    INDEX idx_major (major_id),
    INDEX idx_group (major_group_code)
);
```

### 3.4 历史录取数据表 (`pt_admission_history`)

```sql
CREATE TABLE pt_admission_history (
    id                  BIGSERIAL PRIMARY KEY,
    university_id       BIGINT NOT NULL REFERENCES pt_university(id),
    major_id            BIGINT REFERENCES pt_major(id),     -- NULL表示院校整体数据
    major_group_code    VARCHAR(20),                         -- 新高考专业组代码
    
    -- 录取年份与地区
    year                INT NOT NULL,                        -- 录取年份
    province            VARCHAR(20) NOT NULL,                -- 生源省份
    exam_mode           VARCHAR(10) NOT NULL,                -- traditional/3+3/3+1+2
    
    -- 批次
    batch               VARCHAR(20) NOT NULL,                -- 本科一批/本科提前/专科批/强基计划/综合评价
    
    -- 科类/选科
    subject_category    VARCHAR(20) NOT NULL,                -- 理科/文科/物理类/历史类/综合(3+3)
    selected_subjects   JSONB DEFAULT '[]',                  -- 选科组合 ["物理","化学","生物"]
    
    -- 分数数据
    min_score           INT,                                 -- 最低录取分
    min_rank            INT,                                 -- 最低录取位次
    avg_score           INT,                                 -- 平均录取分
    max_score           INT,                                 -- 最高录取分
    plan_count          INT,                                 -- 计划招生人数
    actual_count        INT,                                 -- 实际录取人数
    
    -- 分数线参考
    province_control_line INT,                               -- 当年省控线（批次线）
    score_diff          INT,                                 -- 线差 = min_score - province_control_line
    
    -- 专业级差
    has_grade_difference BOOLEAN DEFAULT FALSE,               -- 是否存在专业级差
    grade_difference_rule  JSONB,                             -- 级差规则 [{"order": 2, "deduct": 3}, ...]
    
    -- 数据来源
    data_source         VARCHAR(50) DEFAULT 'official',      -- official/third_party/user_report
    confidence          DECIMAL(3,2) DEFAULT 1.00,           -- 数据可信度(0-1)
    
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    
    UNIQUE(university_id, major_id, year, province, batch, subject_category),
    INDEX idx_uni_year_prov (university_id, year, province),
    INDEX idx_major_year (major_id, year),
    INDEX idx_province_year (province, year, batch)
);
```

## 4. 选科要求匹配引擎

### 4.1 选科匹配规则

新高考模式下选科匹配是志愿填报的核心前置校验。以下是统一的选科匹配引擎：

```python
"""
选科要求匹配引擎
负责判断学生的选科组合是否满足院校专业的选科要求。
"""
from enum import Enum
from typing import Optional
from pydantic import BaseModel


class ExamMode(str, Enum):
    TRADITIONAL = "traditional"    # 传统文理分科
    NEW_3_3 = "3+3"               # 新高考3+3（浙、沪、京、津、鲁、琼）
    NEW_3_1_2 = "3+1+2"           # 新高考3+1+2（冀、辽、苏、闽、鄂、湘、粤、渝等）


class SubjectRequirement(BaseModel):
    """选科要求规则模型"""
    mode: ExamMode
    
    # 3+1+2 模式
    required_first: Optional[str] = None       # 首选: "physics" | "history" | None(均可)
    required_select: list[str] = []             # 再选必选科目（必须全部已选）
    any_of: list[list[str]] = []                # 再选科目N选一（每组至少选一个）
    select_count: int = 2                       # 再选科目总数要求
    
    # 3+3 模式
    required_subjects_3_3: list[str] = []       # 必选科目（3+3模式下）
    any_of_3_3: list[list[str]] = []            # N选一规则
    
    # 传统模式
    arts_science: Optional[str] = None          # "science" | "arts" | "both"
    
    description: str = ""                       # 人类可读描述
    
    # 物理或历史均可时的等效标识
    equivalent: Optional[str] = None


# 科目常量
SUBJECT_PHYSICS = "physics"
SUBJECT_HISTORY = "history"
SUBJECT_CHEMISTRY = "chemistry"
SUBJECT_BIOLOGY = "biology"
SUBJECT_POLITICS = "politics"
SUBJECT_GEOGRAPHY = "geography"

ALL_SELECT_SUBJECTS = [
    SUBJECT_PHYSICS, SUBJECT_HISTORY, SUBJECT_CHEMISTRY,
    SUBJECT_BIOLOGY, SUBJECT_POLITICS, SUBJECT_GEOGRAPHY
]


class SubjectMatchResult(BaseModel):
    """选科匹配结果"""
    matched: bool
    reason: str = ""
    missing_required: list[str] = []
    missing_any_of: list[list[str]] = []


def check_subject_requirement(
    student_subjects: list[str],
    requirement: SubjectRequirement
) -> SubjectMatchResult:
    """
    核心匹配函数：判断学生选科是否满足要求
    
    Args:
        student_subjects: 学生选科列表，如 ["physics", "chemistry", "biology"]
        requirement: 院校专业的选科要求
    
    Returns:
        SubjectMatchResult: 匹配结果
    """
    student_set = set(student_subjects)
    
    if requirement.mode == ExamMode.TRADITIONAL:
        # 传统高考模式
        if requirement.arts_science == "both" or requirement.arts_science is None:
            return SubjectMatchResult(matched=True, reason="文理兼招")
        
        student_is_science = SUBJECT_PHYSICS in student_set or SUBJECT_CHEMISTRY in student_set
        if requirement.arts_science == "science" and not student_is_science:
            return SubjectMatchResult(matched=False, reason="该专业要求理科")
        if requirement.arts_science == "arts" and student_is_science:
            return SubjectMatchResult(matched=False, reason="该专业要求文科")
        return SubjectMatchResult(matched=True)
    
    elif requirement.mode == ExamMode.NEW_3_1_2:
        # 3+1+2 模式
        # Step 1: 检查首选科目
        if requirement.required_first:
            if requirement.required_first not in student_set:
                other = "历史" if requirement.required_first == SUBJECT_PHYSICS else "物理"
                return SubjectMatchResult(
                    matched=False,
                    reason=f"该专业要求首选{requirement.required_first}，"
                           f"学生首选为{other}",
                    missing_required=[requirement.required_first]
                )
        
        # Step 2: 检查再选必选科目
        missing_required = [
            s for s in requirement.required_select if s not in student_set
        ]
        if missing_required:
            return SubjectMatchResult(
                matched=False,
                reason=f"缺少必选再选科目: {', '.join(missing_required)}",
                missing_required=missing_required
            )
        
        # Step 3: 检查 N 选一规则
        missing_any_of = []
        for group in requirement.any_of:
            if not any(s in student_set for s in group):
                missing_any_of.append(group)
        
        if missing_any_of:
            groups_str = " / ".join(
                "-".join(g) for g in missing_any_of
            )
            return SubjectMatchResult(
                matched=False,
                reason=f"需要从以下科目中至少选一门: {groups_str}",
                missing_any_of=missing_any_of
            )
        
        return SubjectMatchResult(matched=True, reason="选科匹配")
    
    elif requirement.mode == ExamMode.NEW_3_3:
        # 3+3 模式
        # Step 1: 检查必选科目
        missing_required = [
            s for s in requirement.required_subjects_3_3 if s not in student_set
        ]
        if missing_required:
            return SubjectMatchResult(
                matched=False,
                reason=f"缺少必选科目: {', '.join(missing_required)}",
                missing_required=missing_required
            )
        
        # Step 2: 检查 N 选一规则
        missing_any_of = []
        for group in requirement.any_of_3_3:
            if not any(s in student_set for s in group):
                missing_any_of.append(group)
        
        if missing_any_of:
            groups_str = " / ".join("-".join(g) for g in missing_any_of)
            return SubjectMatchResult(
                matched=False,
                reason=f"需要从以下科目中至少选一门: {groups_str}",
                missing_any_of=missing_any_of
            )
        
        return SubjectMatchResult(matched=True, reason="选科匹配")
    
    return SubjectMatchResult(matched=False, reason="未知的高考模式")


# 批量匹配：一次性检查学生选科对所有院校专业的匹配情况
def batch_check_subjects(
    student_subjects: list[str],
    requirements: list[tuple[int, int, SubjectRequirement]]
) -> list[tuple[int, int, SubjectMatchResult]]:
    """
    批量选科匹配
    
    Args:
        student_subjects: 学生选科
        requirements: [(university_major_id, major_id, requirement), ...]
    
    Returns:
        [(university_major_id, major_id, match_result), ...]
    """
    results = []
    for um_id, major_id, req in requirements:
        result = check_subject_requirement(student_subjects, req)
        results.append((um_id, major_id, result))
    return results
```

## 5. 录取概率预测引擎

### 5.1 预测模型设计

```python
"""
录取概率预测引擎
基于历史录取数据、招生计划变化、考生位次等信息，
预测考生被某院校专业录取的概率。
"""
import numpy as np
import pandas as pd
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.preprocessing import StandardScaler
from datetime import date
from pydantic import BaseModel
from typing import Optional


class AdmissionFeatures(BaseModel):
    """录取预测特征"""
    # 考生信息
    student_score: int                  # 考生分数
    student_rank: int                   # 考生全省位次
    province: str                       # 生源省份
    exam_mode: str                      # 高考模式
    selected_subjects: list[str]        # 选科组合
    
    # 院校专业信息
    university_id: int
    major_id: Optional[int] = None      # NULL表示只预测院校整体
    major_group_code: Optional[str] = None
    
    # 目标批次
    batch: str                          # 本科一批/本科提前/...


class AdmissionPredictor:
    """录取概率预测器"""
    
    MODEL_NAME = "admission_predictor"
    MODEL_VERSION = "2.1.0"
    MIN_HISTORY_YEARS = 3               # 至少需要3年历史数据
    CONFIDENCE_THRESHOLD = 0.85         # 模型置信度阈值
    
    def __init__(self, db_session, redis_client):
        self.db = db_session
        self.redis = redis_client
        self.models = {}                # province → model
        self.scalers = {}               # province → scaler
    
    def extract_features(
        self,
        student: AdmissionFeatures,
        university_id: int,
        major_id: Optional[int],
        batch: str,
        province: str,
        target_year: int
    ) -> Optional[np.ndarray]:
        """
        从历史数据中提取预测特征
        
        特征向量维度: 12
        [
            0: student_rank                    # 考生位次
            1: student_score                   # 考生分数
            2: province_control_line           # 当年省控线
            3: avg_min_score_3y                # 近3年平均最低录取分
            4: avg_min_rank_3y                 # 近3年平均最低录取位次
            5: min_score_last_year             # 去年最低录取分
            6: min_rank_last_year              # 去年最低录取位次
            7: score_diff_last_year            # 去年线差
            8: score_trend                     # 分数趋势（线性回归斜率）
            9: rank_trend                      # 位次趋势
            10: plan_count_change_ratio        # 招生计划变化比
            11: university_heat_score          # 院校热度
        ]
        """
        # 查询历史录取数据（近3-5年）
        history = self.db.query_admission_history(
            university_id=university_id,
            major_id=major_id,
            province=province,
            batch=batch,
            years=range(target_year - 5, target_year)
        )
        
        if len(history) < self.MIN_HISTORY_YEARS:
            # 历史数据不足，使用位次法估算
            return self._fallback_feature_extraction(student, history, target_year)
        
        df = pd.DataFrame(history)
        
        # 计算特征
        avg_min_score_3y = df.nlargest(3, 'year')['min_score'].mean()
        avg_min_rank_3y = df.nlargest(3, 'year')['min_rank'].mean()
        
        last_year = df[df['year'] == target_year - 1]
        if last_year.empty:
            return None
        
        last = last_year.iloc[0]
        
        # 趋势计算（简单线性回归斜率）
        recent = df.nlargest(3, 'year').sort_values('year')
        if len(recent) >= 2:
            score_trend = np.polyfit(range(len(recent)), recent['min_score'].values, 1)[0]
            rank_trend = np.polyfit(range(len(recent)), recent['min_rank'].values, 1)[0]
        else:
            score_trend = 0
            rank_trend = 0
        
        # 招生计划变化
        plan_this_year = self.db.query_admission_plan(
            university_id, major_id, target_year, province, batch
        )
        plan_last_year = last.get('plan_count', 0)
        if plan_last_year and plan_last_year > 0 and plan_this_year:
            plan_change_ratio = plan_this_year.quota / plan_last_year
        else:
            plan_change_ratio = 1.0
        
        # 院校热度
        heat = self.db.query_university_heat(university_id)
        
        # 省控线（当年预估）
        control_line = self.db.query_province_control_line(
            province, batch, target_year
        ) or last['province_control_line']
        
        features = np.array([
            student.student_rank,
            student.student_score,
            control_line,
            avg_min_score_3y,
            avg_min_rank_3y,
            last['min_score'],
            last['min_rank'],
            last.get('score_diff', 0),
            score_trend,
            rank_trend,
            plan_change_ratio,
            heat.heat_score if heat else 50,
        ])
        
        return features
    
    def predict(
        self,
        student: AdmissionFeatures,
        university_id: int,
        major_id: Optional[int] = None,
        major_group_code: Optional[str] = None,
        batch: str = "本科一批"
    ) -> "AdmissionPrediction":
        """
        预测录取概率
        
        Returns:
            AdmissionPrediction: 预测结果
        """
        province = student.province
        
        # 缓存Key
        cache_key = f"admission_pred:{student.student_rank}:{university_id}:{major_id}:{batch}:{province}"
        cached = self.redis.get(cache_key)
        if cached:
            return AdmissionPrediction.parse_raw(cached)
        
        # 提取特征
        features = self.extract_features(
            student, university_id, major_id, batch, province,
            target_year=date.today().year
        )
        
        if features is None:
            # 数据不足，使用位次法粗估
            return self._rank_based_estimate(student, university_id, major_id, batch)
        
        # 获取该省份的模型
        model_key = f"{province}_{student.exam_mode}"
        model = self.models.get(model_key)
        scaler = self.scalers.get(model_key)
        
        if model is None or scaler is None:
            # 模型未加载，尝试加载
            model, scaler = self._load_model(model_key)
            if model is None:
                return self._rank_based_estimate(student, university_id, major_id, batch)
        
        # 标准化 + 预测
        features_scaled = scaler.transform(features.reshape(1, -1))
        probability = model.predict_proba(features_scaled)[0][1]  # P(admitted)
        
        # 策略标签
        if probability >= 0.75:
            strategy_tag = "保"
        elif probability >= 0.40:
            strategy_tag = "稳"
        elif probability >= 0.15:
            strategy_tag = "冲"
        else:
            strategy_tag = "险"
        
        result = AdmissionPrediction(
            university_id=university_id,
            major_id=major_id,
            probability=round(probability, 4),
            strategy_tag=strategy_tag,
            confidence=self.CONFIDENCE_THRESHOLD,
            model_version=self.MODEL_VERSION,
            features_summary={
                "student_rank": int(features[0]),
                "last_year_min_rank": int(features[6]),
                "rank_delta": int(features[0] - features[6]),
            }
        )
        
        # 缓存1小时
        self.redis.setex(cache_key, 3600, result.json())
        return result
    
    def _rank_based_estimate(
        self, student, university_id, major_id, batch
    ) -> "AdmissionProbability":
        """
        基于位次法的粗估（模型不可用时的降级方案）
        
        核心逻辑：
        - 考生位次 < 去年最低位次 × 0.85 → 高概率（保）
        - 考生位次 < 去年最低位次 × 0.95 → 中等概率（稳）
        - 考生位次 < 去年最低位次 × 1.10 → 低概率（冲）
        - 考生位次 > 去年最低位次 × 1.10 → 极低概率（险）
        """
        history = self.db.query_admission_history(
            university_id=university_id,
            major_id=major_id,
            province=student.province,
            batch=batch,
            years=[date.today().year - 1]
        )
        
        if not history:
            return AdmissionPrediction(
                university_id=university_id,
                major_id=major_id,
                probability=0.0,
                strategy_tag="未知",
                confidence=0.3,
                model_version="fallback_rank_v1",
                features_summary={"reason": "无历史数据"}
            )
        
        last_rank = history[0]['min_rank']
        student_rank = student.student_rank
        
        ratio = student_rank / last_rank if last_rank > 0 else 999
        
        if ratio < 0.85:
            prob, tag = 0.85, "保"
        elif ratio < 0.95:
            prob, tag = 0.60, "稳"
        elif ratio < 1.10:
            prob, tag = 0.30, "冲"
        elif ratio < 1.25:
            prob, tag = 0.12, "险"
        else:
            prob, tag = 0.03, "险"
        
        return AdmissionPrediction(
            university_id=university_id,
            major_id=major_id,
            probability=prob,
            strategy_tag=tag,
            confidence=0.5,
            model_version="fallback_rank_v1",
            features_summary={
                "student_rank": student_rank,
                "last_year_min_rank": last_rank,
                "rank_ratio": round(ratio, 3),
            }
        )
    
    def _load_model(self, model_key: str):
        """从文件加载训练好的模型"""
        import joblib
        import os
        
        model_path = f"/data/models/admission/{model_key}_v{self.MODEL_VERSION}.joblib"
        if not os.path.exists(model_path):
            return None, None
        
        data = joblib.load(model_path)
        return data['model'], data['scaler']
    
    def train_model(self, province: str, exam_mode: str):
        """
        训练指定省份的录取预测模型
        
        数据源：历年录取记录（正样本）+ 达到分数线但未被录取的记录（负样本）
        """
        # 1. 准备训练数据
        train_data = self.db.query_training_data(province, exam_mode)
        df = pd.DataFrame(train_data)
        
        if len(df) < 1000:
            # 数据量不足，跳过训练
            return False
        
        # 2. 特征工程
        feature_cols = [
            'student_rank', 'student_score', 'province_control_line',
            'avg_min_score_3y', 'avg_min_rank_3y', 'min_score_last_year',
            'min_rank_last_year', 'score_diff_last_year', 'score_trend',
            'rank_trend', 'plan_count_change_ratio', 'university_heat_score'
        ]
        X = df[feature_cols].values
        y = df['admitted'].values  # 1=录取, 0=未录取
        
        # 3. 标准化
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        # 4. 训练
        model = GradientBoostingClassifier(
            n_estimators=200,
            max_depth=5,
            learning_rate=0.1,
            subsample=0.8,
            random_state=42
        )
        model.fit(X_scaled, y)
        
        # 5. 保存模型
        import joblib
        model_key = f"{province}_{exam_mode}"
        model_path = f"/data/models/admission/{model_key}_v{self.MODEL_VERSION}.joblib"
        joblib.dump({'model': model, 'scaler': scaler}, model_path)
        
        # 更新内存
        self.models[model_key] = model
        self.scalers[model_key] = scaler
        
        return True


class AdmissionPrediction(BaseModel):
    """录取预测结果"""
    university_id: int
    major_id: Optional[int] = None
    probability: float                      # 0-1之间的概率值
    strategy_tag: str                       # 冲/稳/保/险
    confidence: float                       # 模型置信度
    model_version: str
```

### 6.1 方案生成算法

```python
"""
志愿方案智能生成引擎
根据考生分数/位次、意向偏好、录取概率预测，智能生成"冲稳保"梯度志愿方案。
"""
import math
from typing import Optional
from pydantic import BaseModel


class VolunteerGenerationStrategy:
    """志愿生成策略"""
    
    # 各策略的冲稳保比例
    STRATEGY_RATIOS = {
        "aggressive":  {"rush": 0.50, "stable": 0.30, "safe": 0.20},   # 冲一冲
        "balanced":    {"rush": 0.25, "stable": 0.45, "safe": 0.30},   # 稳妥
        "conservative": {"rush": 0.10, "stable": 0.35, "safe": 0.55},  # 保底
    }
    
    # 概率区间定义
    PROB_RUSH = (0.10, 0.40)      # 冲: 10%-40%
    PROB_STABLE = (0.40, 0.75)    # 稳: 40%-75%
    PROB_SAFE = (0.75, 0.95)      # 保: 75%-95%
    
    # 志愿总数限制（各省不同，默认96个：新高考本科批）
    DEFAULT_MAX_VOLUNTEERS = 96
    
    def __init__(self, predictor: AdmissionPredictor, db_session):
        self.predictor = predictor
        self.db = db_session
    
    def generate_plan(
        self,
        student_profile: "StudentAdmissionProfile",
        strategy_type: str = "balanced",
        max_volunteers: int = None,
        preferences: "VolunteerPreferences" = None
    ) -> "VolunteerPlan":
        """
        生成志愿方案
        
        Args:
            student_profile: 学生升学档案
            strategy_type: 策略类型
            max_volunteers: 最大志愿数
            preferences: 偏好筛选条件
        
        Returns:
            VolunteerPlan: 完整志愿方案
        """
        max_volunteers = max_volunteers or self.DEFAULT_MAX_VOLUNTEERS
        ratios = self.STRATEGY_RATIOS.get(strategy_type, self.STRATEGY_RATIOS["balanced"])
        
        target_rush = int(max_volunteers * ratios["rush"])
        target_stable = int(max_volunteers * ratios["stable"])
        target_safe = int(max_volunteers * ratios["safe"])
        
        # Step 1: 候选池构建 — 基于偏好筛选院校专业
        candidates = self._build_candidate_pool(student_profile, preferences)
        
        if not candidates:
            return VolunteerPlan(
                user_id=student_profile.user_id,
                plan_name=f"志愿方案_{strategy_type}",
                volunteer_items=[],
                total_choices=0,
                strategy_type=strategy_type,
                model_version=self.predictor.MODEL_VERSION,
                generated_by="ai"
            )
        
        # Step 2: 逐个计算录取概率
        scored_candidates = []
        for uni_major in candidates:
            # 先检查选科匹配
            match = check_subject_requirement(
                student_profile.selected_subjects,
                uni_major.subject_requirement
            )
            if not match.matched:
                continue
            
            # 预测录取概率
            prediction = self.predictor.predict(
                student=AdmissionFeatures(
                    student_score=student_profile.predicted_score,
                    student_rank=student_profile.predicted_rank,
                    province=student_profile.province,
                    exam_mode=student_profile.exam_mode,
                    selected_subjects=student_profile.selected_subjects,
                    university_id=uni_major.university_id,
                ),
                university_id=uni_major.university_id,
                major_id=uni_major.major_id,
                major_group_code=uni_major.major_group_code,
                batch=preferences.batch if preferences else "本科一批"
            )
            
            scored_candidates.append({
                **uni_major.dict(),
                "probability": prediction.probability,
                "strategy_tag": prediction.strategy_tag,
                "prediction": prediction
            })
        
        # Step 3: 分层筛选
        rush_list = self._select_from_tier(scored_candidates, "冲", target_rush, preferences)
        stable_list = self._select_from_tier(scored_candidates, "稳", target_stable, preferences)
        safe_list = self._select_from_tier(scored_candidates, "保", target_safe, preferences)
        
        # Step 4: 排序与去重
        volunteer_items = self._assemble_and_sort(
            rush_list, stable_list, safe_list, preferences
        )
        
        # Step 5: 风险检测
        warnings = self._detect_risks(volunteer_items, student_profile)
        
        return VolunteerPlan(
            user_id=student_profile.user_id,
            plan_name=f"智能志愿方案_{strategy_type}",
            volunteer_items=volunteer_items,
            total_choices=len(volunteer_items),
            rush_count=len(rush_list),
            stable_count=len(stable_list),
            safe_count=len(safe_list),
            strategy_type=strategy_type,
            model_version=self.predictor.MODEL_VERSION,
            generated_by="ai",
            warnings=warnings
        )
    
    def _build_candidate_pool(
        self, 
        student_profile, 
        preferences: "VolunteerPreferences"
    ) -> list:
        """基于偏好构建候选院校专业池"""
        pool = self.db.query_university_majors(
            province=student_profile.province,
            exam_mode=student_profile.exam_mode,
            selected_subjects=student_profile.selected_subjects,
            # 偏好过滤
            target_levels=student_profile.target_level,
            preferred_regions=student_profile.preferred_regions,
            preferred_majors=student_profile.preferred_majors,
            excluded_majors=student_profile.excluded_majors,
            max_tuition=student_profile.max_tuition,
            batch=preferences.batch if preferences else "本科一批",
            # 分数范围：预估分上下浮动80分
            score_min=max(0, student_profile.predicted_score - 80),
            score_max=student_profile.predicted_score + 80,
        )
        return pool
    
    def _select_from_tier(
        self,
        candidates: list[dict],
        tier: str,
        target_count: int,
        preferences
    ) -> list[dict]:
        """
        从候选池中选取指定梯度的院校专业
        
        排序规则：
        1. 冲：按概率降序（越接近40%越优先）
        2. 稳：按概率降序（越接近75%越优先）  
        3. 保：按概率升序（越接近75%越优先，确保保底质量）
        """
        prob_range = {
            "冲": self.PROB_RUSH,
            "稳": self.PROB_STABLE,
            "保": self.PROB_SAFE
        }.get(tier)
        
        if not prob_range:
            return []
        
        # 筛选在该概率区间的候选
        tier_candidates = [
            c for c in candidates
            if prob_range[0] <= c["probability"] < prob_range[1]
        ]
        
        if tier == "冲":
            # 冲：概率从高到低排序（接近40%的优先）
            tier_candidates.sort(key=lambda x: -x["probability"])
        elif tier == "稳":
            # 稳：按综合评分排序
            tier_candidates.sort(key=lambda x: -self._compute_score(x, preferences))
        else:
            # 保：概率从低到高排序（刚过75%的优先，避免浪费）
            tier_candidates.sort(key=lambda x: x["probability"])
        
        # 多样性保障：避免同一院校太多专业
        selected = []
        uni_count = {}  # university_id → count
        max_per_uni = 6  # 每所院校最多选6个专业
        
        for c in tier_candidates:
            if len(selected) >= target_count:
                break
            uid = c["university_id"]
            if uni_count.get(uid, 0) >= max_per_uni:
                continue
            selected.append(c)
            uni_count[uid] = uni_count.get(uid, 0) + 1
        
        return selected
    
    def _compute_score(self, candidate: dict, preferences) -> float:
        """计算候选的综合评分（用于稳档排序）"""
        score = candidate["probability"] * 100
        
        # 地区偏好加分
        if preferences and preferences.preferred_regions:
            uni = self.db.get_university(candidate["university_id"])
            if uni.province in preferences.preferred_regions:
                score += 10
        
        # 专业意向加分
        if preferences and preferences.preferred_majors:
            if candidate["major_id"] in preferences.preferred_majors:
                score += 15
        
        # 院校层次加分
        uni = self.db.get_university(candidate["university_id"])
        if uni.is_985:
            score += 8
        elif uni.is_211:
            score += 5
        
        return score
    
    def _assemble_and_sort(
        self, rush, stable, safe, preferences
    ) -> list[dict]:
        """组装并排序最终志愿列表"""
        items = []
        
        # 排序：冲→稳→保，每档内部保持原排序
        order = 1
        for tier_list in [rush, stable, safe]:
            for item in tier_list:
                items.append({
                    "order": order,
                    "university_id": item["university_id"],
                    "university_name": item.get("university_name", ""),
                    "major_id": item["major_id"],
                    "major_name": item.get("major_name", ""),
                    "major_group_code": item.get("major_group_code"),
                    "batch": item.get("batch", "本科一批"),
                    "admission_probability": round(item["probability"], 4),
                    "strategy_tag": item["strategy_tag"],
                    "min_score_last_year": item.get("min_score_last_year"),
                    "min_rank_last_year": item.get("min_rank_last_year"),
                    "estimated_score": item.get("estimated_score"),
                    "tuition": item.get("tuition"),
                    "subject_match": True,
                    "warnings": []
                })
                order += 1
        
        return items
    
    def _detect_risks(
        self, volunteer_items: list[dict], student_profile
    ) -> list[str]:
        """检测方案中的潜在风险"""
        warnings = []
        
        if not volunteer_items:
            warnings.append("方案为空，请检查分数预估和偏好设置")
            return warnings
        
        # 检查是否有足够的保底
        safe_count = sum(1 for v in volunteer_items if v["strategy_tag"] == "保")
        if safe_count < 3:
            warnings.append(f"保底志愿仅{safe_count}个，建议至少3个以确保录取")
        
        # 检查第一个志愿是否过于保守
        first = volunteer_items[0]
        if first["admission_probability"] > 0.90:
            warnings.append("第一志愿录取概率过高(>90%)，可以考虑将更高目标的院校提前")
        
        # 检查梯度是否合理
        probs = [v["admission_probability"] for v in volunteer_items]
        for i in range(1, len(probs)):
            if probs[i] < probs[i-1] - 0.3:
                warnings.append(f"第{i}到第{i+1}志愿之间概率跳跃过大，建议增加过渡志愿")
                break
        
        # 检查是否有专业级差风险
        for item in volunteer_items:
            um = self.db.get_university_major(
                item["university_id"], item["major_id"]
            )
            if um and um.has_grade_difference:
                item["warnings"].append("该校存在专业级差，非第一专业可能扣减分数")
        
        return warnings
```

```python
"""
霍兰德职业兴趣测评服务
RIASEC六维度测评，匹配职业与专业方向。

HOLLAND_DIMENSIONS = {

    TOTAL_QUESTIONS = 72
    
    def submit_assessment(self, user_id: int, answers: list[dict]) -> "HollandResult":
        """
        提交测评答案，计算结果
        
        answers: [{"question_id": 1, "score": 5}, ...]  score: 1-5
        """

            score = answer["score"] if not q["reverse"] else (6 - answer["score"])
            dimension_scores[q["dimension"]] += score
        
        # 归一化到0-100

            d: round(s / max_possible * 100, 1)
            for d, s in dimension_scores.items()
        }
        
        # 取前三高维度组合为霍兰德码（如 "ISE"）
```

```python
"""
升学路径规划引擎
为非毕业年级学生提供前瞻性升学指导。
"""

class CareerPathPlanner:
    
    def generate_path(
        self,
        user_id: int,
        target_careers: list[int],      # 目标职业ID列表
        current_grade: int,             # 当前年级(10-12)
        province: str
    ) -> "CareerPath":
        """
        生成升学路径规划
        
        返回结构化的升学路径，包括：
        - 选科建议（已关联"选科推荐引擎"）
        - 目标院校梯度
        - 分数目标
        - 关键时间节点
        - 学习侧重建议
        """
        career_infos = self.db.get_careers(target_careers)
        
        path_items = []
        for career in career_infos:
            # 查找该职业关联的专业
            related_majors = self.db.get_related_majors(career.id)
            
            # 查找开设这些专业的优质院校
            universities = self.db.get_universities_by_majors(
                [m.id for m in related_majors],
                province=province,
                min_level="211"
            )
            
            # 按层次分梯度
            tiers = self._classify_university_tiers(universities)
            
            # 生成各梯度分数目标
            score_targets = self._generate_score_targets(tiers, province)
            
            path_items.append(CareerPathItem(
                career=career,
                related_majors=related_majors,
                university_tiers=tiers,
                score_targets=score_targets,
                subject_advice=self._generate_subject_advice(career, province)
            ))
        
        # 关键时间节点
        timeline = self._generate_timeline(current_grade)
        
        return CareerPath(
            user_id=user_id,
            current_grade=current_grade,
            province=province,
            path_items=path_items,
            timeline=timeline,
            created_at=datetime.utcnow()
        )
    
    def _classify_university_tiers(self, universities: list) -> dict:
        """将院校分为冲刺、目标、保底三个梯度"""
        tiers = {"reach": [], "target": [], "safety": []}
        for uni in universities:
            if uni.is_985 or uni.ranking_cn <= 30:
                tiers["reach"].append(uni)
            elif uni.is_211 or uni.ranking_cn <= 100:
                tiers["target"].append(uni)
            else:
                tiers["safety"].append(uni)
        return tiers
    
    def _generate_score_targets(self, tiers: dict, province: str) -> dict:
        """基于历年数据生成各梯度分数目标"""
        targets = {}
        for tier_name, unis in tiers.items():
            if not unis:
                continue
            # 取该梯度院校近3年平均最低分
            scores = []
            for uni in unis[:5]:  # 取前5所参考
                history = self.db.query_admission_history(
                    university_id=uni.id,
                    province=province,
                    years=range(date.today().year - 3, date.today().year)
                )
                if history:
                    avg = sum(h['min_score'] for h in history) / len(history)
                    scores.append(int(avg))
            
            if scores:
                targets[tier_name] = {
                    "score_range": (min(scores), max(scores)),
                    "avg_score": sum(scores) // len(scores)
                }
        return targets
    
    def _generate_timeline(self, current_grade: int) -> list[dict]:
        """生成升学关键时间节点"""
        timeline = [
            {"phase": "高一", "month": "9月", "event": "选科指导启动", "priority": "high"},
            {"phase": "高一", "month": "3月", "event": "选科确定（部分省份）", "priority": "high"},
            {"phase": "高二", "month": "9月", "event": "目标院校研究", "priority": "medium"},
```

### 11.2 降级策略

```python
"""
多层级降级策略
"""

class AdmissionFallbackChain:
    """升学推荐服务降级链"""
    
    LEVEL_1_NORMAL = "normal"           # 正常：ML模型预测
    LEVEL_2_RANK_BASED = "rank_based"   # 降级1：位次法粗估
    LEVEL_3_CACHED = "cached"           # 降级2：返回缓存结果
    LEVEL_4_STATIC = "static"           # 降级3：静态推荐列表
    LEVEL_5_OFFLINE = "offline"         # 最低：展示"稍后再试"
    
    async def get_prediction(self, request):
        try:
            # Level 1: 正常ML预测
            return await self.ml_predictor.predict(request)
        except ModelUnavailableError:
            logger.warning("ML模型不可用，降级到位次法")
            try:
                # Level 2: 位次法
                return await self.rank_estimator.estimate(request)
            except DataNotFoundError:
                logger.warning("历史数据不足，返回缓存")
                # Level 3: 缓存
                cached = await self.redis.get(request.cache_key)
                if cached:
                    cached["degraded"] = True
                    return cached
                # Level 4: 静态推荐
                return self._static_fallback(request)
    
    def _static_fallback(self, request):
        """
        静态降级：返回基于分数段的通用院校推荐列表
        按分数定位到对应层次，返回预制的推荐组合
        """
        score = request.score
        if score >= 650:
            return STATIC_RECOMMENDATIONS["top_universities"]
        elif score >= 580:
            return STATIC_RECOMMENDATIONS["good_universities"]
        elif score >= 500:
            return STATIC_RECOMMENDATIONS["regular_universities"]
        else:
            return STATIC_RECOMMENDATIONS["colleges"]
```

### 12.3 数据质量保障

```python
"""
数据质量监控
"""

class AdmissionDataQualityMonitor:
    
    QUALITY_RULES = [
        # 完整性：每所985院校至少有5年录取数据
        Rule(
            name="985_history_completeness",
            query="SELECT COUNT(*) FROM pt_admission_history h 
                   JOIN pt_university u ON h.university_id = u.id 
                   WHERE u.is_985 AND h.year >= 2021 
                   GROUP BY h.university_id, h.province 
                   HAVING COUNT(*) < 5",
            threshold=0,  # 不允许有任何不符合的记录
            alert_level="critical"
        ),
        # 准确性：录取分数应在省控线±150分范围内
        Rule(
            name="score_range_check",
            query="SELECT * FROM pt_admission_history 
                   WHERE min_score < province_control_line - 150 
                   OR min_score > province_control_line + 150",
            threshold=10,  # 允许少量异常
            alert_level="warning"
        ),
        # 时效性：当年招生计划应在5月底前入库
        Rule(
            name="plan_timeliness",
            query="SELECT province, COUNT(*) as plan_count 
                   FROM pt_admission_plan WHERE year = EXTRACT(YEAR FROM NOW()) 
                   GROUP BY province HAVING COUNT(*) < 100",
            threshold=0,
            alert_level="critical",
            deadline="05-31"
        ),
        # 一致性：同一院校同年同省同批次的分数不应有显著差异
        Rule(
            name="score_consistency",
            query="...",  # 检查不同来源数据的差异
            threshold=5,
            alert_level="warning"
        ),
    ]
    
    async def run_daily_check(self):
        """每日数据质量巡检"""
        results = []
        for rule in self.QUALITY_RULES:
            violations = await self.db.execute(rule.query)
            if len(violations) > rule.threshold:
                await self.alert_service.send(
                    level=rule.alert_level,
                    title=f"数据质量告警: {rule.name}",
                    body=f"发现 {len(violations)} 条违规记录"
                )
                results.append({"rule": rule.name, "status": "fail", "count": len(violations)})
            else:
                results.append({"rule": rule.name, "status": "pass"})
        
        return results
```

### C. 关键风险与免责条款

1. **预测不确定性**：录取概率为统计模型估算，受当年报考人数、招生计划变动等因素影响，不保证结果准确性。
2. **数据时效性**：历史录取数据存在1年滞后，当年招生计划可能临时调整。
3. **政策变化风险**：教育主管部门可能临时调整招生政策（如批次合并、选科要求变更），系统需及时响应。
4. **免责声明**：PrimeTop 升学规划功能仅提供信息参考，考生须通过省级招生考试机构官方系统完成正式志愿填报。
