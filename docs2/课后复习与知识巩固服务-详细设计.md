# 课后复习与知识巩固服务 - 详细设计

## 1. 概述

### 1.1 模块定位

课后复习与知识巩固服务（AfterClassReviewService）是 PrimeTop 同步课堂学习体系的核心子服务，负责在学生学习完某一章节/课时后，为其生成个性化的复习任务：包括知识总结、例题讲解、巩固练习、间隔复习提醒和掌握度评估。该服务上联同步课堂学习进度，下联错题本、学情分析、学习规划和推荐系统，是完成"学习 → 理解 → 巩固 → 掌握"闭环的关键节点。

### 1.2 核心职责

- 根据学生已学章节和当前掌握度，生成课后复习任务清单。
- 提供知识总结卡片、结构化例题、变式练习三种复习内容。
- 管理复习状态机（未开始 / 进行中 / 已完成 / 已跳过 / 已归档）。
- 根据艾宾浩斯遗忘曲线和答题正确率，触发间隔复习提醒。
- 与错题服务联动，将复习中再次答错的题目归入错题本。
- 输出复习完成数据，供学情分析服务更新知识点掌握度。

### 1.3 目标用户

| 用户 | 使用场景 |
|------|----------|
| 学生 | 完成章节学习后，通过复习任务巩固知识 |
| 家长 | 查看孩子课后复习完成率和薄弱点 |
| 教师 | 查看班级学生课后复习整体完成情况 |
| 运营/教研 | 配置复习内容模板、例题库、复习策略 |

### 1.4 依赖关系

**上游依赖：**
- 同步课堂学习服务：获取学生已完成的章节/课时信息。
- 用户服务：获取学生学段、年级、学科、教材版本。
- 教材版本与章节管理服务：获取章节知识点映射和复习资源。
- 题目服务：获取巩固练习题和例题。
- 学习记录与进度追踪服务：获取学习行为数据。

**下游依赖：**
- 错题服务：复习中答错题目需创建或更新错题记录。
- 学情分析服务：根据复习结果更新知识点掌握度。
- 消息服务：发送复习提醒通知。
- 学习规划服务：将复习任务纳入每日学习任务。
- 推荐服务：推荐同类巩固练习。

## 4. 业务逻辑

### 4.1 核心流程：生成复习任务

```
1. 接收章节完成事件 (chapter_completed) / 手动调用
2. 查询用户档案 (学段/年级/学科/教材版本)
3. 查询章节知识点映射
4. 查询每个知识点的当前掌握度
5. 根据掌握度排序，筛选需要复习的知识点
6. 为每个知识点匹配总结卡片、例题和练习题
7. 组装复习任务 (ReviewTask)
8. 写入数据库并设置计划复习时间
9. 创建第一轮复习提醒 (24h 后)
10. 将任务推送至学习规划服务 (纳入每日任务)
11. 发送事件：review_task_created
```

### 4.2 复习任务状态机

```
[PENDING] --(开始复习)--> [IN_PROGRESS] --(完成)--> [COMPLETED]
   |                              |
   |--(跳过)--------------------> [SKIPPED]
   |--(超时未处理 / 已归档)----> [ARCHIVED]
```

状态转换约束：
- PENDING → IN_PROGRESS：用户开始复习会话
- PENDING → SKIPPED：用户主动跳过，记录原因
- PENDING → ARCHIVED：任务过期超过 30 天未处理
- IN_PROGRESS → COMPLETED：会话完成且进度 ≥ 80%
- IN_PROGRESS → PENDING：会话异常中止，可重新复习
- IN_PROGRESS → SKIPPED：复习中用户选择跳过剩余项
- COMPLETED / SKIPPED → ARCHIVED：数据归档任务

### 4.3 复习内容生成策略

| 掌握度 | 复习策略 | 内容配比 |
|--------|----------|----------|
| ≥ 80% | 轻复习 | 总结卡 1 张 + 基础练习 2 道 |
| 50% - 80% | 标准复习 | 总结卡 1 张 + 例题 1 道 + 练习 3 道 |
| 30% - 50% | 强化复习 | 总结卡 1 张 + 例题 2 道 + 练习 5 道 + 变式题 |
| < 30% | 重新学习 | 推送同步课堂重新学习，不生成复习任务 |

### 4.4 间隔复习调度算法

基于艾宾浩斯遗忘曲线，复习任务完成后创建下一轮复习提醒：

```python
REVIEW_INTERVALS = [1, 2, 4, 7, 15, 30]  # 天数

def schedule_next_review(task, round):
    if round >= len(REVIEW_INTERVALS):
        return None
    days = REVIEW_INTERVALS[round - 1]
    planned_time = now + timedelta(days=days)
    # 避开夜间 23:00 - 07:00
    if planned_time.hour < 7:
        planned_time = planned_time.replace(hour=8, minute=0)
    elif planned_time.hour >= 23:
        planned_time = (planned_time + timedelta(days=1)).replace(hour=8, minute=0)
    return planned_time
```

### 4.5 与错题本联动

复习会话中提交的练习项若 `isCorrect=false`：
1. 调用错题服务创建/更新错题记录。
2. 错题记录来源标记为 `REVIEW`。
3. 该错题知识点进入下一轮复习候选池。
4. 如果同一知识点连续 2 次复习答错，任务优先级提升为 5。

### 4.6 与学情分析联动

复习任务完成时：
1. 计算本轮复习知识点正确率。
2. 发送 `review_task_completed` 事件到消息队列。
3. 学情分析服务消费事件，更新知识点掌握度。
4. 如果掌握度 ≥ 85%，标记该知识点为"已掌握"，减少后续复习频次。

### 5.2 复习任务生成服务

```java
@Service
public class ReviewTaskGenerationService {

    @Autowired
    private ReviewTaskRepository reviewTaskRepository;

    @Autowired
    private ChapterClient chapterClient;

    @Autowired
    private MasteryClient masteryClient;

    @Autowired
    private QuestionClient questionClient;

    @Autowired
    private ReviewContentAssembler contentAssembler;

    @Autowired
    private ApplicationEventPublisher eventPublisher;

    @Transactional
    public ReviewTask generateTask(String userId, String chapterId, String lessonId, String source) {
        // 1. 查询用户档案
        UserProfile profile = userService.getProfile(userId);

        // 2. 查询章节知识点
        List<KnowledgePoint> kps = chapterClient.getKnowledgePoints(chapterId);
        if (kps.isEmpty()) {
            throw new ReviewException(ErrorCode.REVIEW_KNOWLEDGE_DATA_MISSING);
        }

        // 3. 查询掌握度，筛选需要复习的知识点
        List<String> kpIds = kps.stream().map(KnowledgePoint::getId).collect(Collectors.toList());
        Map<String, MasteryLevel> masteryMap = masteryClient.batchGet(userId, kpIds);

        List<String> reviewKpIds = kps.stream()
            .filter(kp -> {
                MasteryLevel level = masteryMap.getOrDefault(kp.getId(), MasteryLevel.NONE);
                return level.getScore() >= 30 && level.getScore() < 85; // 需要复习
            })
            .map(KnowledgePoint::getId)
            .collect(Collectors.toList());

        if (reviewKpIds.isEmpty()) {
            // 全部掌握，生成轻量复习任务
            reviewKpIds = List.of(kps.get(0).getId());
        }

        // 4. 根据掌握度计算优先级和任务类型
        double avgMastery = reviewKpIds.stream()
            .mapToInt(id -> masteryMap.get(id).getScore())
            .average()
            .orElse(0);

        TaskType taskType = determineTaskType(avgMastery);
        int priority = determinePriority(avgMastery);

        // 5. 组装复习内容
        ReviewContent content = contentAssembler.assemble(
            chapterId, reviewKpIds, taskType, profile.getStage()
        );

        // 6. 创建任务
        ReviewTask task = new ReviewTask();
        task.setId(IdUtil.uuid());
        task.setUserId(userId);
        task.setChapterId(chapterId);
        task.setLessonId(lessonId);
        task.setSubjectCode(profile.getSubjectCode());
        task.setStage(profile.getStage());
        task.setTaskType(taskType);
        task.setStatus(TaskStatus.PENDING);
        task.setPriority(priority);
        task.setKnowledgePointIds(reviewKpIds);
        task.setContent(content);
        task.setProgress(new ReviewProgress(content.totalItems(), 0, 0, 0));
        task.setScheduledAt(LocalDateTime.now().plusHours(2)); // 课后2小时复习
        task.setReviewRound(1);
        task.setSource(source);

        reviewTaskRepository.save(task);

        // 7. 发布事件
        eventPublisher.publishEvent(new ReviewTaskCreatedEvent(task));

        return task;
    }

    private TaskType determineTaskType(double avgMastery) {
        if (avgMastery >= 80) return TaskType.SUMMARY;
        if (avgMastery >= 60) return TaskType.MIXED;
        return TaskType.PRACTICE;
    }

    private int determinePriority(double avgMastery) {
        if (avgMastery < 40) return 5;
        if (avgMastery < 60) return 4;
        if (avgMastery < 80) return 3;
        return 2;
    }
}
```

```java
@Component
public class ReviewContentAssembler {

    @Autowired
    private SummaryCardRepository summaryCardRepository;

    @Autowired
    private ReviewExampleRepository exampleRepository;

    @Autowired
    private QuestionClient questionClient;

    public ReviewContent assemble(String chapterId, List<String> kpIds, TaskType taskType, String stage) {
        ReviewContent content = new ReviewContent();

        // 1. 每个知识点选 1 张总结卡
        List<String> summaryCardIds = summaryCardRepository
            .findByChapterIdAndKnowledgePointIdInAndStageAndStatus(
                chapterId, kpIds, stage, "ACTIVE"
            )
            .stream()
            .map(ReviewSummaryCard::getId)
            .distinct()
            .collect(Collectors.toList());
        content.setSummaryCardIds(summaryCardIds);

        // 2. 选择例题
        List<String> exampleIds = new ArrayList<>();
        if (taskType != TaskType.SUMMARY) {
            exampleIds = exampleRepository
                .findByChapterIdAndKnowledgePointIdInAndRecommendedStageAndStatus(
                    chapterId, kpIds, stage, "ACTIVE"
                )
                .stream()
                .limit(2)
                .map(ReviewExample::getId)
                .collect(Collectors.toList());
        }
        content.setExampleIds(exampleIds);

        // 3. 选择练习题
        List<String> questionIds = questionClient.recommendForReview(
            chapterId, kpIds, taskType, stage, 5
        );
        content.setPracticeQuestionIds(questionIds);

        // 4. 建议时长
        int estimated = summaryCardIds.size() * 60 + exampleIds.size() * 120 + questionIds.size() * 90;
        content.setRecommendedDurationSeconds(Math.min(estimated, 1200));

        return content;
    }

    public int totalItems(ReviewContent content) {
        return content.getSummaryCardIds().size()
            + content.getExampleIds().size()
            + content.getPracticeQuestionIds().size();
    }
}
```

### 5.4 复习会话服务

```java
@Service
public class ReviewSessionService {

    @Autowired
    private ReviewSessionRepository sessionRepository;

    @Autowired
    private ReviewTaskRepository taskRepository;

    @Autowired
    private AnswerRecordClient answerRecordClient;

    @Transactional
    public ReviewSession startSession(String taskId, String userId) {
        ReviewTask task = taskRepository.findByIdAndUserId(taskId, userId)
            .orElseThrow(() -> new ReviewException(ErrorCode.REVIEW_TASK_NOT_FOUND));

        if (task.getStatus() != TaskStatus.PENDING && task.getStatus() != TaskStatus.IN_PROGRESS) {
            throw new ReviewException(ErrorCode.REVIEW_TASK_STATUS_INVALID);
        }

        // 检查是否已有进行中的会话
        sessionRepository.findByTaskIdAndStatus(taskId, SessionStatus.ACTIVE)
            .ifPresent(s -> { throw new ReviewException(ErrorCode.REVIEW_SESSION_ALREADY_ACTIVE); });

        ReviewSession session = new ReviewSession();
        session.setId(IdUtil.uuid());
        session.setTaskId(taskId);
        session.setUserId(userId);
        session.setStartedAt(LocalDateTime.now());
        session.setStatus(SessionStatus.ACTIVE);
        session.setItemRecords(buildItemRecords(task));

        sessionRepository.save(session);

        task.setStatus(TaskStatus.IN_PROGRESS);
        taskRepository.save(task);

        return session;
    }

    private List<ItemRecord> buildItemRecords(ReviewTask task) {
        List<ItemRecord> records = new ArrayList<>();
        for (String id : task.getContent().getSummaryCardIds()) {
            records.add(new ItemRecord(id, ItemType.SUMMARY, ItemStatus.PENDING));
        }
        for (String id : task.getContent().getExampleIds()) {
            records.add(new ItemRecord(id, ItemType.EXAMPLE, ItemStatus.PENDING));
        }
        for (String id : task.getContent().getPracticeQuestionIds()) {
            records.add(new ItemRecord(id, ItemType.QUESTION, ItemStatus.PENDING));
        }
        return records;
    }

    @Transactional
    public ItemResult submitItem(String sessionId, String userId, ItemSubmission submission) {
        ReviewSession session = sessionRepository.findByIdAndUserId(sessionId, userId)
            .orElseThrow(() -> new ReviewException(ErrorCode.REVIEW_SESSION_NOT_FOUND));

        if (session.getStatus() != SessionStatus.ACTIVE) {
            throw new ReviewException(ErrorCode.REVIEW_SESSION_ALREADY_ENDED);
        }

        ItemRecord record = session.getItemRecords().stream()
            .filter(r -> r.getItemId().equals(submission.getItemId()))
            .findFirst()
            .orElseThrow(() -> new ReviewException(ErrorCode.REVIEW_ITEM_NOT_FOUND));

        if (record.getStatus() != ItemStatus.PENDING) {
            throw new ReviewException(ErrorCode.REVIEW_ITEM_DUPLICATE_SUBMIT);
        }

        record.setStatus(ItemStatus.ANSWERED);
        record.setSpentSeconds(submission.getSpentSeconds());

        if (submission.getItemType() == ItemType.QUESTION) {
            // 调用答题记录服务判题
            AnswerRecordResult result = answerRecordClient.createAndGrade(
                userId, submission.getItemId(), submission.getAnswerContent(), "REVIEW"
            );
            record.setAnswerRecordId(result.getId());
            record.setCorrect(result.isCorrect());

            // 答错则创建错题
            if (!result.isCorrect()) {
                eventPublisher.publishEvent(new ReviewItemWrongEvent(userId, submission.getItemId(), session.getTaskId()));
            }
        } else {
            record.setCorrect(true); // 总结卡/例题默认算正确
        }

        sessionRepository.save(session);

        // 推荐下一项
        String nextItemId = findNextPendingItem(session);
        return new ItemResult(record, nextItemId);
    }

    @Transactional
    public ReviewTask completeSession(String sessionId, String userId) {
        ReviewSession session = sessionRepository.findByIdAndUserId(sessionId, userId)
            .orElseThrow(() -> new ReviewException(ErrorCode.REVIEW_SESSION_NOT_FOUND));

        if (session.getStatus() != SessionStatus.ACTIVE) {
            throw new ReviewException(ErrorCode.REVIEW_SESSION_ALREADY_ENDED);
        }

        session.setEndedAt(LocalDateTime.now());
        session.setDurationSeconds((int) Duration.between(session.getStartedAt(), session.getEndedAt()).getSeconds());
        session.setStatus(SessionStatus.COMPLETED);
        sessionRepository.save(session);

        // 更新任务状态
        ReviewTask task = taskRepository.findById(session.getTaskId()).orElseThrow();
        ReviewProgress progress = calculateProgress(session);
        task.setProgress(progress);

        if (progress.getCompletedItems() >= progress.getTotalItems() * 0.8) {
            task.setStatus(TaskStatus.COMPLETED);
            task.setCompletedAt(LocalDateTime.now());
            scheduleNextRound(task);
        }

        taskRepository.save(task);
        clearCache(task);

        eventPublisher.publishEvent(new ReviewTaskCompletedEvent(task, session));
        return task;
    }

    private ReviewProgress calculateProgress(ReviewSession session) {
        long total = session.getItemRecords().size();
        long completed = session.getItemRecords().stream().filter(r -> r.getStatus() == ItemStatus.ANSWERED).count();
        long correct = session.getItemRecords().stream().filter(r -> Boolean.TRUE.equals(r.getCorrect())).count();
        return new ReviewProgress((int) total, (int) completed, (int) correct, (int) (completed - correct));
    }

    private void scheduleNextRound(ReviewTask task) {
        int nextRound = task.getReviewRound() + 1;
        if (nextRound > 4) return;

        LocalDateTime plannedTime = scheduleNextReview(task, nextRound);
        ReviewTask nextTask = new ReviewTask();
        nextTask.setId(IdUtil.uuid());
        nextTask.setUserId(task.getUserId());
        nextTask.setChapterId(task.getChapterId());
        nextTask.setLessonId(task.getLessonId());
        nextTask.setSubjectCode(task.getSubjectCode());
        nextTask.setStage(task.getStage());
        nextTask.setTaskType(task.getTaskType());
        nextTask.setStatus(TaskStatus.PENDING);
        nextTask.setPriority(task.getPriority());
        nextTask.setKnowledgePointIds(task.getKnowledgePointIds());
        nextTask.setContent(task.getContent());
        nextTask.setProgress(new ReviewProgress(task.getContent().totalItems(), 0, 0, 0));
        nextTask.setScheduledAt(plannedTime);
        nextTask.setReviewRound(nextRound);
        nextTask.setSource("AUTO");
        reviewTaskRepository.save(nextTask);
    }

    private LocalDateTime scheduleNextReview(ReviewTask task, int round) {
        int[] intervals = {1, 2, 4, 7}; // 天
        LocalDateTime planned = LocalDateTime.now().plusDays(intervals[round - 1]);
        int hour = planned.getHour();
        if (hour < 7) planned = planned.withHour(8).withMinute(0);
        if (hour >= 23) planned = planned.plusDays(1).withHour(8).withMinute(0);
        return planned;
    }
}
```

```java
public class ReviewExceptionHandler {

    @ExceptionHandler(ReviewException.class)
    public ResponseEntity<ApiResponse<Void>> handleReviewException(ReviewException e) {
        ErrorCode code = e.getErrorCode();
        HttpStatus status = HttpStatus.BAD_REQUEST;
```

### 6.3 重试策略

| 场景 | 策略 | 说明 |
|------|------|------|
| 调用题目服务失败 | 重试 3 次，指数退避 1s/2s/4s | 生成复习内容时 |
| 调用掌握度服务失败 | 重试 3 次 | 默认掌握度 50 |
| 提交答题记录失败 | 重试 3 次 | 会话保持 ACTIVE |
| 消息发送失败 | 进入死信队列 | 人工处理 |

### 6.4 降级方案

- **掌握度服务不可用**：默认所有知识点掌握度为 50，生成标准复习任务。
- **题目服务不可用**：减少练习题数量，仅返回总结卡和例题。
- **消息队列不可用**：先落库，定时任务补偿重发。
- **高并发场景**：限制用户同时只能有 1 个 ACTIVE 复习会话，超过则返回已有会话。

## 7. 性能优化

### 7.1 缓存策略

- 用户今日复习任务列表使用 Redis 缓存，过期时间 10 分钟，提交/完成时主动失效。
- 知识总结卡片和复习例题内容使用 Redis 缓存，过期 1-2 小时。
- 复习会话状态使用 Redis 缓存，防止会话异常丢失。
- 缓存穿透：使用布隆过滤器拦截不存在的 taskId/sessionId 查询。

### 7.2 数据库优化

- 索引：`idx_user_status`、`idx_user_scheduled`、`idx_chapter` 已覆盖高频查询。
- 复习任务表按 `user_id` 进行水平分表（当单表超过 1000 万行时）。
- 历史已完成任务归档到只读库或对象存储，主库仅保留近 6 个月数据。

### 7.3 并发控制

- 用户维度分布式锁：启动复习会话时，对 `lock:review_session:{userId}` 加锁，防止同时开启多个会话。
- 乐观锁：更新任务状态时基于 `updated_at` 或版本号。

### 7.4 限流

| 接口 | 限流 |
|------|------|
| 生成复习任务 | 每用户每分钟 10 次 |
| 开始复习会话 | 每用户每分钟 5 次 |
| 提交复习项 | 每用户每分钟 60 次 |
| 完成复习会话 | 每用户每分钟 5 次 |

## 8. 安全考虑

### 8.1 权限控制

- 所有接口需 JWT 鉴权，用户只能访问自己的复习任务和会话。
- 管理后台查询接口需管理员角色权限。
- 教师端查询接口需校验教师与学生的班级关系。

### 8.2 数据验证

- 复习任务内容生成时，校验 `knowledgePointIds` 是否属于当前章节。
- 提交复习项时，校验 `itemId` 是否属于当前会话的任务。
- 防止绕过前端，对 `spentSeconds` 做合理范围校验（0-7200 秒）。
- 对 `answerContent` 做长度限制，防止大文本攻击。

### 8.3 审计日志

- 记录复习任务创建、跳过、完成事件。
- 记录管理员/教研人员对复习内容的修改。
- 记录错题联动触发事件。

### 8.4 未成年人保护

- 课后复习任务建议时长不超过 20 分钟，低龄学段（小学及以下）不超过 10 分钟。
- 超过 20 分钟未完成的会话，自动提示休息。
- 复习内容需经过适龄性审核，避免超纲内容。
