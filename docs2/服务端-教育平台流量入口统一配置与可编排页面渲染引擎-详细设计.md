# 服务端-教育平台流量入口统一配置与可编排页面渲染引擎-详细设计

> **文档版本**：v1.0  
> **创建日期**：2026-08-14  
> **关联模块**：运营管理、首页工作台、活动页、着陆页、深链接、AB实验  
> **依赖模块**：统一短链服务、AB实验平台、运营弹窗规则引擎、客户端JSON渲染引擎、统一延迟任务调度

---

## 1. 概述

### 1.1 背景与问题

PrimeTop 平台存在大量「流量入口」——外部广告投放链接、社交媒体分享链接、推送通知落地、二维码扫码、应用内 Banner、搜索联想词、运营弹窗等——每种入口最终需要把用户引导到一个**具体的页面或功能**。

当前痛点：

| 问题 | 影响 |
| --- | --- |
| 入口→页面的映射硬编码在客户端或网关路由中 | 每次修改需要发版或改配置文件 |
| 同一入口对不同用户展示相同内容 | 无法做分群定向、AB测试 |
| 活动页、专题页依赖客户端预埋页面 | 活动上线必须跟版本走 |
| 各业务线各自实现着陆逻辑 | 维护成本高、数据不一致 |
| 缺少入口级别的数据埋点和归因 | 无法量化评估入口ROI |

### 1.2 目标

建设**统一流量入口配置与可编排页面渲染引擎**（以下简称「流量编排引擎」），实现：

1. **入口统一管理**：所有流量入口（深链、短链、推送、Banner、弹窗、扫码等）在后端配置中心统一管理。
2. **页面动态编排**：运营人员通过后台可视化拖拽或 JSON Schema 编排页面结构，客户端动态渲染，无需发版。
3. **分群定向投放**：入口目标和页面内容可按用户标签（年级、学段、会员状态、地域等）差异化展示。
4. **AB实验集成**：任意入口和页面区块均可挂载实验，自动分流和归因。
5. **全链路数据闭环**：从入口曝光→点击→着陆→页面区块交互→转化，全链路埋点和归因分析。

### 1.3 核心概念

| 概念 | 说明 |
| --- | --- |
| **TrafficEntry（流量入口）** | 一次用户访问的来源标识，如一条短链、一个Banner、一次推送 |
| **PageTemplate（页面模板）** | 可复用的页面骨架，定义区块槽位和布局 |
| **PageInstance（页面实例）** | 模板 + 内容配置 + 定向规则 = 一个可渲染的页面 |
| **Slot（区块槽位）** | 页面中的内容容器，可填充卡片、商品、活动、推荐列表等 |
| **Block（内容区块）** | 槽位中的具体内容单元，如学习任务卡片、Banner轮播、商品列表 |
| **RoutingRule（路由规则）** | 入口→页面实例的映射规则，支持条件匹配 |
| **RenderContext（渲染上下文）** | 客户端请求页面时携带的用户、设备、场景信息 |

### 2.1 引擎内部模块职责

| 子服务 | 职责 |
| --- | --- |
| **入口管理服务** | 流量入口的CRUD、入口类型管理、入口状态流转 |
| **页面编排服务** | 页面模板管理、页面实例创建与版本管理、区块组装 |
| **投放引擎服务** | 路由规则评估、用户定向匹配、AB分流、页面实例选择 |

| **归因分析服务** | 入口→页面→转化全链路事件采集、归因计算、报表生成 |

## 3. 数据模型

### 3.1 核心表结构

#### 3.1.1 traffic_entry（流量入口表）

```sql
CREATE TABLE `traffic_entry` (
    `id`             BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
    `entry_code`     VARCHAR(64)  NOT NULL COMMENT '入口唯一编码，如 banner_home_202608',
    `entry_name`     VARCHAR(128) NOT NULL COMMENT '入口名称',
    `entry_type`     VARCHAR(32)  NOT NULL COMMENT '入口类型: DEEP_LINK/SHORT_LINK/PUSH/BANNER/POPUP/QRCODE/SEARCH/AD',
    `source_channel` VARCHAR(64)  DEFAULT NULL COMMENT '来源渠道: WECHAT/DOUYIN/XIAOHONGSHU/APP_INTERNAL/SMS/QR',
    `target_type`    VARCHAR(32)  NOT NULL COMMENT '目标类型: PAGE_INSTANCE/CUSTOM_URL/NATIVE_PAGE/EXTERNAL_URL',
    `target_value`   VARCHAR(512) NOT NULL COMMENT '目标值: 页面实例ID/原生路由路径/外部URL',
    `routing_rule_id` BIGINT      DEFAULT NULL COMMENT '关联的路由规则ID（如有动态路由）',
    `status`         TINYINT      NOT NULL DEFAULT 0 COMMENT '0=草稿 1=待审核 2=生效中 3=已暂停 4=已下线',
    `start_time`     DATETIME     DEFAULT NULL COMMENT '生效开始时间',
    `end_time`       DATETIME     DEFAULT NULL COMMENT '生效结束时间',
    `daily_quota`    INT          DEFAULT NULL COMMENT '每日可承载流量上限（null=不限）',
    `priority`       INT          NOT NULL DEFAULT 0 COMMENT '优先级，数值越大越优先',
    `created_by`     BIGINT       NOT NULL COMMENT '创建人',
    `updated_by`     BIGINT       NOT NULL COMMENT '最后更新人',
    `created_at`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    `deleted_at`     DATETIME     DEFAULT NULL COMMENT '软删除',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_entry_code` (`entry_code`),
    KEY `idx_type_status` (`entry_type`, `status`),
    KEY `idx_channel` (`source_channel`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='流量入口表';
```

### 3.2 实体关系

```
TrafficEntry ──(1:N)──> RoutingRule
RoutingRule  ──(N:1)──> PageInstance

PageInstance ──(1:N)──> Slot配置（存在content_config JSON中）
ContentBlock ──(N:N)──> PageInstance（通过content_config引用）
```

### 6.1 投放引擎 — 条件评估器

```java
/**
 * 路由规则条件评估器
 * 支持 AND/OR/NOT 嵌套逻辑，字段级条件匹配
 */
@Component
public class RoutingRuleEvaluator {

    /**
     * 评估规则是否命中
     * @param condition 规则条件树
     * @param ctx 渲染上下文（包含用户画像、设备信息等）
     * @return 是否命中
     */
    public boolean evaluate(MatchCondition condition, RenderContext ctx) {
        if (condition == null) {
            return true; // 无条件 = 全量命中
        }

        String operator = condition.getOperator();
        switch (operator) {
            case "AND":
                return condition.getConditions().stream()
                        .allMatch(sub -> evaluate(sub, ctx));
            case "OR":
                return condition.getConditions().stream()
                        .anyMatch(sub -> evaluate(sub, ctx));
            case "NOT":
                return !evaluate(condition.getConditions().get(0), ctx);
            default:
                return evaluateLeaf(condition, ctx);
        }
    }

    /**
     * 叶子条件评估
     */
    private boolean evaluateLeaf(MatchCondition cond, RenderContext ctx) {
        Object fieldValue = extractFieldValue(cond.getField(), ctx);
        if (fieldValue == null) {
            return false;
        }

        switch (cond.getOp()) {
            case "EQ":
                return Objects.equals(fieldValue.toString(), cond.getValue().toString());
            case "NEQ":
                return !Objects.equals(fieldValue.toString(), cond.getValue().toString());
            case "IN":
                return cond.getValues().stream()
                        .anyMatch(v -> v.equalsIgnoreCase(fieldValue.toString()));
            case "NOT_IN":
                return cond.getValues().stream()
                        .noneMatch(v -> v.equalsIgnoreCase(fieldValue.toString()));
            case "GT":
                return toBigDecimal(fieldValue).compareTo(toBigDecimal(cond.getValue())) > 0;
            case "GTE":
                return toBigDecimal(fieldValue).compareTo(toBigDecimal(cond.getValue())) >= 0;
            case "LT":
                return toBigDecimal(fieldValue).compareTo(toBigDecimal(cond.getValue())) < 0;
            case "LTE":
                return toBigDecimal(fieldValue).compareTo(toBigDecimal(cond.getValue())) <= 0;
            case "BETWEEN":
                BigDecimal val = toBigDecimal(fieldValue);
                return val.compareTo(toBigDecimal(cond.getValues().get(0))) >= 0
                    && val.compareTo(toBigDecimal(cond.getValues().get(1))) <= 0;
            default:
                return false;
        }
    }

    /**
     * 从渲染上下文中提取字段值
     * 支持 dot 路径: "user.gradeLevel", "context.platform"
     */
    private Object extractFieldValue(String fieldPath, RenderContext ctx) {
        String[] parts = fieldPath.split("\\.");
        Object current = ctx;
        for (String part : parts) {
            current = getFieldValue(current, part);
            if (current == null) return null;
        }
        return current;
    }

    private BigDecimal toBigDecimal(Object val) {
        if (val instanceof Number) return BigDecimal.valueOf(((Number) val).doubleValue());
        return new BigDecimal(val.toString());
    }
}
```

### 6.2 渲染服务 — 页面组装

```java
/**
 * 页面渲染服务
 */
@Service
public class PageRenderService {

    @Autowired
    private TrafficEntryCacheService entryCacheService;

    @Autowired
    private RoutingRuleEvaluator ruleEvaluator;

    @Autowired
    private PageInstanceCacheService pageCacheService;

    @Autowired
    private ABExperimentService abService;

    @Autowired
    private EventPublisher eventPublisher;

    /**
     * 解析入口并返回页面渲染数据
     */
    public RenderResponse resolveEntry(ResolveEntryRequest request, RenderContext ctx) {
        // 1. 加载入口配置（优先走缓存）
        TrafficEntry entry = entryCacheService.getByCode(request.getEntryCode());
        if (entry == null || entry.getStatus() != EntryStatus.ACTIVE) {
            throw new BizException(ErrorCode.ENTRY_NOT_FOUND_OR_INACTIVE);
        }

        // 2. 时间窗口校验
        if (!TimeWindowUtil.isWithinWindow(entry.getStartTime(), entry.getEndTime())) {
            throw new BizException(ErrorCode.ENTRY_OUT_OF_TIME_WINDOW);
        }

        // 3. 日配额校验（使用 Redis 原子计数器）
        if (entry.getDailyQuota() != null) {
            boolean withinQuota = quotaChecker.checkAndIncrement(
                entry.getId(), entry.getDailyQuota()
            );
            if (!withinQuota) {
                throw new BizException(ErrorCode.ENTRY_QUOTA_EXCEEDED);
            }
        }

        // 4. AB实验分流
        ABAssignment abAssignment = abService.assign(
            ctx.getUserId(),
            entry.getExperimentId(),
            ctx
        );

        // 5. 路由决策：确定目标页面实例
        PageInstance pageInstance = routeToPage(entry, ctx, abAssignment);
        if (pageInstance == null) {
            throw new BizException(ErrorCode.NO_PAGE_INSTANCE_MATCHED);
        }

        // 6. 组装渲染数据
        RenderData renderData = buildRenderData(pageInstance, ctx);

        // 7. 生成追踪配置
        TrackingConfig tracking = buildTrackingConfig(entry, pageInstance, abAssignment);

        // 8. 发布入口解析事件
        String resolveId = IdGenerator.nextId("resolve");
        eventPublisher.publish(new EntryResolvedEvent(
            resolveId, entry, pageInstance, ctx, abAssignment
        ));

        return RenderResponse.builder()
            .resolveId(resolveId)
            .entry(RenderResponse.EntryInfo.from(entry))
            .pageInstance(RenderResponse.PageInstanceInfo.builder()
                .instanceCode(pageInstance.getInstanceCode())
                .publishVersion(pageInstance.getPublishVersion())
                .renderData(renderData)
                .trackingConfig(tracking)
                .build())
            .build();
    }

    /**
     * 路由到具体页面实例
     */
    private PageInstance routeToPage(TrafficEntry entry, RenderContext ctx,
                                      ABAssignment abAssignment) {
        // 如果入口直接指向固定页面实例，直接返回
        if (entry.getTargetType() == TargetType.PAGE_INSTANCE && entry.getRoutingRuleId() == null) {
            return pageCacheService.getById(Long.parseLong(entry.getTargetValue()));
        }

        // 如果有路由规则，按优先级评估
        List<RoutingRule> rules = routingRuleService.getByEntryId(entry.getId());
        rules.sort(Comparator.comparing(RoutingRule::getPriority).reversed());

        for (RoutingRule rule : rules) {
            if (rule.getStatus() != 1) continue;

            boolean matched = ruleEvaluator.evaluate(
                rule.getMatchConditions(), ctx
            );
            if (matched) {
                return pageCacheService.getById(rule.getTargetPageInstanceId());
            }
        }

        // 回退到入口默认目标
        if (entry.getTargetType() == TargetType.PAGE_INSTANCE) {
            return pageCacheService.getById(Long.parseLong(entry.getTargetValue()));
        }

        return null;
    }

    /**
     * 构建渲染数据（对静态区块直接返回数据，动态区块返回API端点）
     */
    private RenderData buildRenderData(PageInstance instance, RenderContext ctx) {
        JsonObject contentConfig = instance.getContentConfig();
        JsonObject slots = contentConfig.getAsJsonObject("slots");

        RenderData renderData = new RenderData();
        renderData.setPageType(instance.getTemplateCategory());
        renderData.setLayoutType(instance.getLayoutType());

        for (Map.Entry<String, JsonElement> entry : slots.entrySet()) {
            String slotId = entry.getKey();
            JsonObject slotConfig = entry.getValue().getAsJsonObject();
            String dataSource = slotConfig.getAsJsonPrimitive("dataSource").getAsString();

            SlotRenderData slotData = new SlotRenderData();
            slotData.setSlotId(slotId);
            slotData.setBlockType(slotConfig.getAsJsonPrimitive("blockType").getAsString());

            if ("STATIC".equals(dataSource)) {
                // 静态数据直接内联返回
                slotData.setProps(slotConfig.getAsJsonObject("props"));
            } else {
                // 动态数据：返回API端点，客户端按需加载
                slotData.setProps(slotConfig.getAsJsonObject("props"));
                slotData.setLazyLoad(true);
            }

            renderData.addSlot(slotId, slotData);
        }

        return renderData;
    }
}
```

### 6.3 缓存策略

```java
/**
 * 流量编排引擎多级缓存
 */
// L1: 本地缓存（Caffeine）—— 超高频访问的入口和页面配置
// L2: Redis —— 跨实例共享的配置缓存
// L3: MySQL —— 持久化存储

// 缓存Key设计:
// 入口配置:  traffic:entry:{entryCode}     TTL: 5min
// 页面实例:  traffic:page:{instanceCode}   TTL: 5min
// 路由规则:  traffic:rules:{entryId}       TTL: 5min
// 日配额:    traffic:quota:{entryId}:{date} TTL: 到当天23:59:59

@Component
public class TrafficEntryCacheService {

    @Autowired
    private TrafficEntryMapper entryMapper;

    @Autowired
    private RedisTemplate<String, TrafficEntry> redisTemplate;

    private final Cache<String, TrafficEntry> localCache = Caffeine.newBuilder()
        .maximumSize(10_000)
        .expireAfterWrite(Duration.ofSeconds(30))  // 本地缓存30秒
        .recordStats()
        .build();

    /**
     * 三级缓存查询
     */
    public TrafficEntry getByCode(String entryCode) {
        // L1: 本地缓存
        TrafficEntry entry = localCache.getIfPresent(entryCode);
        if (entry != null) {
            return entry;
        }

        // L2: Redis
        String redisKey = "traffic:entry:" + entryCode;
        entry = redisTemplate.opsForValue().get(redisKey);
        if (entry != null) {
            localCache.put(entryCode, entry);
            return entry;
        }

        // L3: DB + 回填缓存
        entry = entryMapper.selectByCode(entryCode);
        if (entry != null) {
            redisTemplate.opsForValue().set(redisKey, entry, Duration.ofMinutes(5));
            localCache.put(entryCode, entry);
        }
        return entry;
    }

    /**
     * 配置变更时清除缓存（管理后台发布后触发）
     */
    @EventListener
    public void onEntryUpdated(TrafficEntryUpdatedEvent event) {
        String entryCode = event.getEntryCode();
        localCache.invalidate(entryCode);
        redisTemplate.delete("traffic:entry:" + entryCode);
        // 路由规则也需清除
        redisTemplate.delete("traffic:rules:" + event.getEntryId());
    }
}
```

```dart
class TrafficRenderSDK {
  final ApiClient _api;

  Future<RenderResult> resolveAndRender({

    final slots = renderData['slots'] as Map<String, dynamic>;

    final slotWidgets = <Widget>[];
    for (final entry in slots.entries) {
      final slotId = entry.key;
      final slotData = entry.value as Map<String, dynamic>;
      final widget = _buildSlotWidget(slotId, slotData, resolveId);
      slotWidgets.add(widget);

    switch (layoutType) {
      case 'SCROLL':
        return SingleChildScrollView(
          child: Column(children: slotWidgets),
        );
      case 'TAB':
        return DefaultTabController(
          length: slotWidgets.length,
          child: Column(
            children: [
              TabBar(tabs: slotWidgets.map((w) => Tab(text: '...')).toList()),
              Expanded(child: TabBarView(children: slotWidgets)),
            ],
          ),
        );
      case 'GRID':
        return GridView.count(
          crossAxisCount: 2,
          children: slotWidgets,
        );
      default:
        return SingleChildScrollView(child: Column(children: slotWidgets));
    }
  }

  /// 构建单个槽位Widget
  Widget _buildSlotWidget(
    String slotId,
    Map<String, dynamic> slotData,
    String resolveId,
  ) {
    final blockType = slotData['blockType'];
    final props = slotData['props'] as Map<String, dynamic>? ?? {};
    final isLazyLoad = slotData['lazyLoad'] == true;

    // 根据区块类型分发到对应Renderer
    final renderer = BlockRendererRegistry.getRenderer(blockType);
    if (renderer == null) {
      return UnknownBlockWidget(blockType: blockType);
    }

    if (isLazyLoad) {
      return LazyLoadBlockWidget(
        slotId: slotId,
        apiEndpoint: props['apiEndpoint'],
        renderer: renderer,
        props: props,
        onExposure: () => _trackBlockExposure(resolveId, slotId),
        onClick: (extra) => _trackBlockClick(resolveId, slotId, extra),
      );
    } else {
      return renderer.build(props, context: {
        'resolveId': resolveId,
        'slotId': slotId,
        'onExposure': () => _trackBlockExposure(resolveId, slotId),
        'onClick': (extra) => _trackBlockClick(resolveId, slotId, extra),
      });
    }
  }
}

/// 区块渲染器注册中心
class BlockRendererRegistry {
  static final Map<String, BlockRenderer> _renderers = {};

  static void register(String type, BlockRenderer renderer) {
    _renderers[type] = renderer;
  }

  static BlockRenderer? getRenderer(String type) => _renderers[type];
}
```

## 8. 错误处理

### 8.1 错误码定义

| 错误码 | HTTP Status | 说明 | 处理建议 |
| --- | --- | --- | --- |
| `TRAFFIC_001` | 404 | 入口不存在 | 展示默认首页或错误页 |
| `TRAFFIC_002` | 403 | 入口已暂停/已下线 | 展示"活动已结束"提示页 |
| `TRAFFIC_003` | 403 | 入口不在有效时间窗口内 | 展示"活动未开始/已结束" |
| `TRAFFIC_004` | 429 | 入口日配额已满 | 展示"今日名额已满" |
| `TRAFFIC_005` | 404 | 无匹配的页面实例 | 回退到默认页 |
| `TRAFFIC_006` | 500 | 页面实例渲染数据组装失败 | 展示骨架屏+重试 |
| `TRAFFIC_007` | 400 | 区块数据加载参数非法 | 区块降级隐藏 |
| `TRAFFIC_008` | 503 | 区块动态数据源不可用 | 返回缓存数据或降级隐藏 |

### 8.2 客户端降级策略

```dart
class TrafficRenderSDK {
  Widget renderWithFallback(Map<String, dynamic>? renderData) {
    try {
      if (renderData == null) {
        return DefaultHomePage(); // 回退到原生首页
      }
      return _buildPageWidget(renderData, '');

    } catch (e) {

      return SizedBox.shrink(); // 区块级降级：隐藏不展示
    }
  }
}
```

## 9. 归因分析

### 9.1 归因模型

采用**首次触点 + 末次触点 + 线性多触点**三种模型并行计算：

| 模型 | 说明 | 适用场景 |
| --- | --- | --- |
| 首次触点 | 转化归因到用户首次接触的入口 | 品牌认知类评估 |
| 末次触点 | 转化归因到转化前最后一个入口 | 直接转化类评估 |
| 线性多触点 | 所有触点平均分配权重 | 长周期活动评估 |

### 9.2 归因计算SQL（ClickHouse）

```sql
-- 入口转化漏斗（末次触点）
SELECT
    entry_id,
    entry_code,
    entry_type,
    source_channel,
    -- 曝光数
    countIf(event_type = 'EXPOSURE') AS exposure_count,
    -- 独立用户曝光数
    uniqIf(user_id, event_type = 'EXPOSURE') AS exposure_users,
    -- 点击数
    countIf(event_type = 'CLICK') AS click_count,
    -- 点击率
    if(exposure_count > 0, click_count / exposure_count, 0) AS ctr,
    -- 着陆数
    countIf(event_type = 'LANDING') AS landing_count,
    -- 转化数（如：会员购买、课程报名等）
    countIf(event_type = 'CONVERSION') AS conversion_count,
    -- 转化率
    if(landing_count > 0, conversion_count / landing_count, 0) AS cvr,
    -- 单次曝光成本（如对接广告投放）
    any(extra) AS ad_cost,
    -- ROI
    if(ad_cost > 0, conversion_count / ad_cost, 0) AS roi
FROM entry_exposure_log
WHERE event_time BETWEEN '2026-07-01' AND '2026-08-31'
    AND experiment_id IS NULL  -- 排除实验流量（或单独分析）
GROUP BY entry_id, entry_code, entry_type, source_channel
ORDER BY conversion_count DESC;
```

### 9.3 实时大屏指标

| 指标 | 计算 | 刷新频率 |
| --- | --- | --- |
| 当日入口总曝光量 | SUM(exposure) WHERE date=today | 1min |
| 当日入口总点击量 | SUM(click) WHERE date=today | 1min |
| 当前在线页面实例数 | COUNT(page_instance WHERE status=PUBLISHED) | 5min |
| TOP 10 高转化入口 | ORDER BY cvr DESC LIMIT 10 | 5min |
