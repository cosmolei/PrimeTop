## 1. 模块概述

### 1.1 功能定位

本文档是语文词语辨析训练域(Word Discrimination,内部代号 WD-UI)的**客户端呈现层权威**,兑现服务端引擎 v1.0 交付后客户端页面层的零覆盖缺口。

经全目录关键词扫描确认(2026-11-23,`词语辨析/word discrimination`):服务端引擎文档命中,客户端页面层零覆盖——既有《客户端-拼音识字启蒙页面架构与交互设计》覆盖幼儿拼音声调、《客户端-AI听写默写页面架构与交互设计》覆盖书写回忆检测,均不含"近义词/反义词/多音字/形近字"四类语境辨析训练链路;词典查词页仅有词条关系展示,无加练入口。本文补齐该缺口(模式同批次(三十)听写默写/(三十四)思维训练/(四十)棋类/(四十五)配音:服务端已就绪→客户端页面层补全)。

辨析页面的核心交互是**语境中的词义裁决**:学生按子域(近义词/反义词/多音字/形近字)进入练习会话→逐题呈现语境题面→选择/连线/输入/定音→服务端同步判分→答错即时进入 SSE 讲解流→整卷结算→画像沉淀驱动复习队列。客户端只做呈现与采集:零判分、零选项重排、未作答前答案零渲染、题目快照零落盘。

### 1.3 明确不做(本期)

1. 不做词语**书写**训练入口(归听写默写页,边界见服务端 §1.3);
2. 不做造句/运用类练习(归组词造句引擎);
3. 不做成语/病句辨析入口(归语文素养系统 LIT 域,路由命名空间隔离);
4. 不做全服排行榜/班级排名/同龄对比组件(合规,CI 组件白名单扫描);
5. 不做题目内容本地缓存/离线练习模式(题目快照零落盘,弱网诚实提示);
6. 不做录音跟读——多音字子域是"语境定音"选择训练,非发音评估(发音归发音陪练/朗读评估域);
7. 不做幼儿段(学前)入口,路由守卫 fail-closed(服务端 grade_range 过滤为权威,客户端双保险);
8. 不做本地判分预演/选项正误预标记/答案键驻留(CI 禁词表扫描)。

## 3. 页面架构

### 3.1 `/wd` 辨析首页

**布局**:顶部标题"词语辨析"+到期复习数角标;四子域入口卡(2×2 网格):近义词/反义词/多音字/形近字,各卡展示子域等级徽标(weak→"加油中"、emerging→"进步中"、secure→"已掌握"、unknown→不渲染等级)+到期复习数小红点;继续会话卡(探测到 IN_PROGRESS 会话时置顶,展示子域+进度"第 3/8 题");画像摘要卡(四子域迷你条+TOP1 混淆组成长型话术);底部"辨析画像"与"今日复习"入口行。

**交互规约**:
- 子域卡点击→创建会话(POST /wd/sessions,Idempotency-Key=UUID v7,itemCount 按 §3.8 分龄预设)→ 跳练习页;点击即置按钮 LOADING 防双击(幂等由服务端回放保证);
- 45501(存在进行中同子域会话)→ 不打断,直接跳旧会话练习页(继续优先,无"放弃旧会话"按钮:服务端未提供放弃接口,G2 裁决);
- 45505(限流)→ 吐司"手速太快啦,歇一下再试",按钮恢复可点;
- 到期复习数>0 时子域卡红点数=服务端 dueReviews(权威,客户端零计算,R12);
- 骨架屏/错误重试态遵循《客户端-页面状态模式与骨架屏加载空态错误态设计规范》;错误重试仅重试画像与复习两个查询,子域卡静态可点(练习不依赖画像)。

### 3.2 `/wd/session/:sessionId` 练习页(核心页)

单页结构:顶部进度条(seq/总数+子域标题+剩余时间软展示)、主体题型工作区、底部操作条(提交答案/下一题,末题为"完成并交卷")。

**通用规约**:
- 题目数据以创建会话响应 items 为**内存快照 SSOT**(R1/R12),全程禁回源拉取(防 45503 版本分叉);
- 未作答前,答案相关字段(correctIndex/explainBrief)在响应中本就不存在,客户端渲染层无答案数据源(G5);CI 模型扫描禁止任何"本地答案表";
- 选项原样渲染(服务端已乱序,R3),客户端禁 reshuffle;
- 提交按钮流程:ANSWERING→SUBMITTING(不可取消,按钮置灰+菊花)→JUDGED(渲染判分)→下一题;每题 clientRequestId=UUID v7 创建即定,弱网重发/进程恢复重放同一键(G7)。

**四题型渲染**(WdItemRendererRegistry 委托分发):

| 题型 | 渲染 | 提交载荷 | 预校验(仅格式,零判定) |
| --- | --- | --- | --- |
| select_in_context | 句子文本,`____` 占位渲染下划线空白;选项列(文本+pinyin,1-2 年级 pinyin 常显);点击选中态高亮 | `selectedIndex` | 必须选中一项才可提交(未选中按钮置灰) |
| pair_match | 左右两列词卡(左列可带音频播放按钮),点左再点右连一条彩线;已连线可点线撤销;右列顺序为服务端下发顺序 | `pairs`(见 R2) | 全部左项连线后才可提交 |
| fill_input | 锚词大卡(文本+pinyin+点读按钮)+提示语+输入框(inputHint  Placeholder,如"两个字");无选项 | `inputText` | 非空才可提交;**不**做长度/词数拦截(服务端 §11.3 归一化裁决) |
| pronounce_select | 句子文本,目标字 targetChar 高亮下划线;选项为拼音卡(含声调号);音频存在则句首播放按钮 | `selectedIndex` | 必须选中一项 |

**判分反馈(JUDGED 态)**:对/错动画(分龄时长见 §3.8);对→绿色确认+轻音效;错→正确答案位置高亮+explainBrief 一句话点拨(服务端下发原文渲染)+错因成长型话术映射(WRONG_OPTION→"这两个词有点像,听讲解分清它";WRONG_TONE_OPTION→"这个字在这句话里换个读音";自答(selfAnswer)→"要找意思相反的词哦");底部出现"听讲解"主按钮(仅答错)与"下一题"。judgeDetail.distractorClass 不直接展示,仅用于埋点。

**讲解抽屉**:见 §3.3。

**守卫渲染**:
- 45502(会话过期/不存在):诚实页"这次练习已结束",展示已答进度(来自 sessionProgress 最后一次响应),1 个按钮"再练一组"回首页;禁渲染题目内容;
- 45503(版本/队列冲突,单题提交时):自动 GET /wd/sessions/{id} 刷新会话快照,以服务端为准重渲染当前题(已答进度以 sessionProgress 为准),刷新后重试原提交;刷新仍 45503→退出会话回首页并吐司;
- 会话到期与提交竞态:以服务端为准(45502/45504),客户端无本地续期(G8);
- 最后一题答完→操作条变"完成并交卷"(二次确认弹窗:"还有 X 题没做,确定交卷吗?"),**不自动提交**(服务端 §8.1 防弱网半卷裁决);跳题规则:未答题可跳过(标记 skipped,进度条区分色),交卷二次确认文案含未答数。

### 3.3 答错讲解抽屉(SSE)

**触发**:JUDGED=WRONG 时底部"听讲解"→半屏 DraggableScrollableSheet 打开即请求 `GET /wd/sessions/{sessionId}/items/{itemId}/explanations`。

**帧渲染**(协议委托 SSE 引擎 R4):

| 帧 | 客户端行为 |
| --- | --- |
| meta | cacheHit=true→顶部"讲解回顾"角标;false→渲染流式骨架 |
| delta | 字段增量渲染:affirmation→顶部绿色先肯条;differencePoints→差异维度卡片(搭配对象/语体色彩/词义轻重等,分条渐入);按 §5.3 服务端 Schema 字段渲染,未知字段忽略不 crash |
| done | 渲染 explainId 落内存(去重用),展示"记住了,继续练"按钮 |
| error(45510) | 不弹错误:顶部降级条"AI 忙不过来,这是课本版讲解",随后 done 帧静态解析正常渲染(degraded=true 诚实标注) |

**断线与竞态**:SSE 断连 3s 内自动重连一次(携带 since/explainId 由 SSE 引擎管理),重连期间已渲染内容保留;重连失败或超时 8s→静态 explainBrief+本地兜底话术"可以问问老师这两个词的区别",可手动重试一次。同一 itemId 重复打开抽屉:explainId 命中即复用已渲染内容,不重复请求(去重守卫)。讲解中退出抽屉:流继续或取消由 SSE 引擎管理,重进断点续显。

**红线**:讲解渲染零自调 LLM(R5);讲解中禁展示"你错了/太粗心"等否定式措辞(合规 C3,话术白名单制);讲解页 AIGC 徽标常驻(AI 生成讲解,与全局 AIGC 标识约定一致)。

### 3.4 `/wd/session/:sessionId/result` 结算页

**数据源**:submit 响应(幂等重放返回既有结算,45504 语义客户端按成功渲染)。服务端结算字段以响应为准(R1)。

**布局**:成绩头图(分龄呈现见 §3.8:1-2 年级三星档/3 年级以上分数+正确数)+用时+子域标签;逐题回顾列表(题号+对错图标,**禁展示题目原文与答案文本**,仅图标+点击回讲解);薄弱组成长型卡("「爱戴/爱护」还会混淆,已加入复习计划"——groupKey 服务端权威下发才渲染,客户端零推断);两个按钮:"再练一组"(回首页建会话)与"查看画像"。

**激励呈现**:星星/积分动画只消费服务端事件推送(R10);事件到达前按钮可点但奖励区渲染"结算中",事件超时 5s 未达→按无激励渲染,不阻塞任何操作(禁本地预发)。

**守卫**:GRADED 前(提交后结算中)离开页面→回退拦截一次("正在出成绩,马上好");幂等重进 result 页(深链)→直接渲染既有结算(45504 等价语义)。

### 3.5 `/wd/profile` 辨析画像页

**布局**:四子域等级卡(等级名+掌握度条+弱组数+到期复习数);TOP 混淆组列表(topConfusions:groupKey+7 日错次+错因类型话术,成长型白名单);画像说明脚注("练习越多,画像越准")。

**规约**:
- level=unknown 或 45520(样本不足,425)→ 该卡渲染"练习中"占位,**禁渲染等级与掌握度数值**(服务端 §11.1);
- masteryAvg 分龄露分:1-2 年级不展示数值(三档星星映射),3 年级以上展示数值+等级条(呈现参数权威归《分龄UI适配与交互设计规范》,本文只引用);
- topConfusions 渲染白名单话术,禁"错得最多/最差"等标签(G9);
- 零排行/零百分位(G12);下拉刷新重拉画像,本地零缓存画像数据(每次回源,数据量小)。

### 3.6 `/wd/reviews` 今日到期复习页

**布局**:到期组列表(组标识 groupKey 原文渲染+所属子域徽标+建议入口"去复习");按子域分组;空态"今天没有到期复习,保持住!"。

**规约**:列表数据全量来自 GET /wd/reviews/due(R12 零计算);"去复习"→创建对应子域会话(服务端装配自动注入到期组,§4.1 复习优先);到期数为 0 时首页红点数同步清零(同源数据)。

### 3.7 `/parent/wd` 家长端辨析报告页

**布局**:孩子选择器(多孩子);练习概览卡(近 7 日会话数/总题数/平均正确率,服务端聚合);四子域掌握概览条;练习记录列表(时间+子域+题数+正确数,零题目原文零答案);时长分账说明条("词语辨析计入语文学习时长");隐私说明条("本功能不采集孩子输入内容")。

### 5.1 WdPracticeController(练习主控制器)

```dart
class WdPracticeController extends ChangeNotifier {
  final WdApi api;
  final SseEngine sse;               // 委托《SSE流式响应与AI增量渲染引擎》
  List<WdItemView> _queue = [];      // 内存快照 SSOT,零落盘
  int _current = 0;
  MirrorState _state = MirrorState.ready;
  WdJudgeOutcome? _lastJudge;
  String? _sessionId;
  final Map<int, String> _answerKeys = {}; // seq -> clientRequestId(UUID v7,创建即定)

  WdItemView get current => _queue[_current];

  Future<void> submitAnswer({int? selectedIndex, String? inputText, List<WdPair>? pairs}) async {
    if (_state == MirrorState.submitting) return;           // G7 防双击
    _state = MirrorState.submitting;
    notifyListeners();
    final key = _answerKeys.putIfAbsent(_current, () => const Uuid().v7());
    try {
      final outcome = await api.submitAnswer(
        sessionId: _sessionId!,
        itemId: current.itemId,
        itemVersion: current.itemVersion,
        clientRequestId: key,                              // 弱网重发同键,服务端 uk 返回首判
        selectedIndex: selectedIndex,
        inputText: inputText,
        pairs: pairs,
      );
      _lastJudge = outcome;
      _state = MirrorState.judged;
    } on WdException catch (e) {
      if (e.code == 45503) { await _refreshSessionSnapshot(); }   // 版本冲突:服务端权威重取
      else if (e.code == 45502) { _state = MirrorState.expiredLocal; } // 诚实页
      else { _state = MirrorState.judgedError; rethrow; }
    } finally { notifyListeners(); }
  }

  void next() {
    _lastJudge = null;
    _state = _current + 1 >= _queue.length
        ? MirrorState.allAnswered          // 引导交卷,不自动提交(服务端 §8.1)
        : MirrorState.ready;
    if (_state == MirrorState.ready) _current++;
    notifyListeners();
  }
}
```

```dart
class PairMatchController extends ChangeNotifier {
  final List<WdPairSide> left;
  final List<WdPairSide> right;      // 服务端已乱序,零重排(R3)
  final Map<int, int> _links = {};   // leftIndex -> rightIndex
  int? _pendingLeft;

  void tapLeft(int i) { _pendingLeft = (_pendingLeft == i) ? null : i; notifyListeners(); }

  void tapRight(int j) {
    if (_pendingLeft == null) return;
    _links.removeWhere((_, v) => v == j);      // 右项重选:断旧线
    _links[_pendingLeft!] = j;                  // 连线/改线
    _pendingLeft = null;
    notifyListeners();
  }

  void unlink(int leftIndex) { _links.remove(leftIndex); notifyListeners(); }

  bool get submittable => _links.length == left.length;   // 格式预校验,零判定

  List<Map<String, String>> toPayload() => _links.entries
      .map((e) => {'left': left[e.key].text, 'right': right[e.value].text})
      .toList();                 // wire 字段名以服务端判题输入为准(R2)
}
```

### 5.3 WdExplainController(SSE 讲解)

```dart
class WdExplainController extends ChangeNotifier {
  final SseEngine sse;
  final Map<String, WdExplainDoc> _cache = {};   // itemId -> 已渲染讲解(内存,零落盘)

  Future<void> open(String sessionId, WdItemView item) async {
    if (_cache.containsKey(item.itemId)) { notifyListeners(); return; } // explainId 去重
    final ctrl = sse.connect(
      'GET', '/api/v1/wd/sessions/$sessionId/items/${item.itemId}/explanations',
    );
    ctrl.onMeta((m) => _doc.cacheHit = m['cacheHit'] == true);
    ctrl.onDelta((d) => _doc.appendDelta(d));                 // 增量渲染,断线保留
    ctrl.onDone((d) {
      _doc.explainId = d['explainId'];
      _doc.degraded = d['degraded'] == true;
      _cache[item.itemId] = _doc;                             // 去重+复用
    });
    ctrl.onErrorFrame((e) {                                    // 45510 降级帧
      if (e['code'] == 45510) _doc.degradedNotice = e['message'];
    });
    await ctrl.withTimeout(const Duration(seconds: 8)).withOneRetry(); // 断线 3s 重连一次
    // 兜底:超时/重连失败 → 静态 explainBrief + 成长型话术(不弹错误)
  }
}
```

```dart
class WdRouteGuard extends RouteGuard {
  @override
  Future<String?> canActivate(route, context) async {
    // 闸 1:登录态(未登录→登录页带回跳)
    if (!sessionStore.isLoggedIn) return '/login?redirect=${route.location}';
    // 闸 2:学段闸(1-9 年级;学前 fail-closed,与服务端 grade_range 双保险 R8)

    }
    // 闸 4(家长页):家长身份+孩子作用域预检
    if (route.path.startsWith('/parent/') && !sessionStore.isParent) return '/home';
    return null;
```
