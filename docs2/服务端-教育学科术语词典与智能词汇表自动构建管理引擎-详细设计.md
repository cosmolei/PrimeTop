# 服务端-教育学科术语词典与智能词汇表自动构建管理引擎 详细设计

## 1. 概述

### 1.1 模块定位

教育学科术语词典与智能词汇表自动构建管理引擎（Educational Terminology Dictionary & Smart Glossary Engine，简称 **EduGloss**）是 PrimeTop 平台的**基础内容服务层**，负责自动构建、管理和提供全学科、全学段的教育术语词典。

本模块解决的核心问题：平台各业务模块（AI 辅导、内容搜索、知识图谱、题目解析等）需要统一的术语定义和词汇解释能力，但当前各模块各自维护术语数据，存在定义不一致、覆盖不完整、适龄化缺失等问题。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 术语自动抽取 | 从教材内容、题目题干、知识点描述中自动识别学科术语 |
| 术语定义管理 | 为每个术语维护多学段释义、例句、关联知识 |
| 适龄化解释 | 同一术语为不同学段提供不同深度的解释 |
| 跨学科消歧 | 处理多义词在不同学科中的不同含义（如"质量"在物理 vs 日常用语） |
| 术语关系网络 | 管理同义词、反义词、上下位词、关联词关系 |
| 术语标签注入 | 为内容自动标注术语，支持悬浮提示和智能检索 |
| 词汇表生成 | 按章节、单元、专题自动生成生词表/词汇表 |

### 1.4 设计目标

1. **术语覆盖率**：覆盖 K12 全学科核心术语 ≥ 50,000 条
2. **抽取准确率**：AI 自动抽取术语的 F1 值 ≥ 0.85
3. **查询性能**：单术语查询 P99 ≤ 20ms（缓存命中），P99 ≤ 100ms（DB 查询）
4. **批量标注吞吐**：文本术语标注处理速度 ≥ 10,000 字/秒
5. **适龄化覆盖**：核心术语 100% 具备至少 2 个学段的释义

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 Term（术语词条）

```python
from pydantic import BaseModel
from typing import Optional, List
from enum import Enum
from datetime import datetime

class TermStatus(str, Enum):
    DRAFT = "draft"              # 草稿（AI抽取待审核）
    PENDING_REVIEW = "pending"   # 待人工审核
    PUBLISHED = "published"      # 已发布
    DEPRECATED = "deprecated"    # 已废弃
    MERGED = "merged"            # 已合并到其他术语

class PartOfSpeech(str, Enum):
    NOUN = "noun"                # 名词
    VERB = "verb"                # 动词
    ADJECTIVE = "adjective"      # 形容词
    PHRASE = "phrase"            # 词组/短语
    SYMBOL = "symbol"            # 符号/公式
    ABBREVIATION = "abbreviation" # 缩写

class Term(BaseModel):
    id: str                           # 术语ID (如 "term_001")
    canonical_form: str               # 规范形式 (如 "二次函数")
    pinyin: str                       # 拼音 (如 "èr cì hán shù")
    english: Optional[str]            # 英文 (如 "quadratic function")
    subject_code: str                 # 主属学科 (如 "math")
    cross_subjects: List[str]         # 跨学科标记 (如 ["math", "physics"])
    part_of_speech: PartOfSpeech      # 词性
    term_type: str                    # 类型: concept|formula|person|place|event|method
    grade_levels: List[str]           # 适用学段 ["junior_one", "senior_one"]
    difficulty_level: int             # 难度等级 1-12（对应年级）
    status: TermStatus                # 状态
    knowledge_point_ids: List[str]    # 关联知识点ID
    tags: List[str]                   # 标签
    frequency: int                    # 在内容库中出现次数
    created_at: datetime
    updated_at: datetime
    created_by: str                   # 创建者(user_id 或 "ai_extractor")
    reviewed_by: Optional[str]        # 审核人
```

#### 2.1.2 TermDefinition（术语释义）

```python
class DefinitionType(str, Enum):
    STANDARD = "standard"       # 标准定义
    SIMPLE = "simple"           # 简化版（低年级用）
    ADVANCED = "advanced"       # 进阶版（高年级用）
    ENCYCLOPEDIC = "encyclopedic"  # 百科式详解

class TermDefinition(BaseModel):
    id: str
    term_id: str                      # 所属术语
    stage_code: str                   # 学段 (primary|junior|senior)
    definition_type: DefinitionType   # 释义类型
    text: str                         # 释义正文
    plain_explanation: str            # 通俗解释（一句话说清楚）
    examples: List[str]               # 例句
    formula: Optional[str]            # 数学公式（LaTeX，如适用）
    diagram_url: Optional[str]        # 配图URL
    analogy: Optional[str]            # 类比解释（如"函数就像自动售货机"）
    common_mistakes: List[str]        # 常见误解
    is_primary: bool                  # 是否为该学段首选释义
    language: str = "zh-CN"           # 语言
    created_at: datetime
    updated_at: datetime
```

#### 2.1.3 TermRelation（术语关系）

```python
class RelationType(str, Enum):
    SYNONYM = "synonym"             # 同义词
    ANTONYM = "antonym"             # 反义词
    HYPONYM = "hyponym"             # 下位词（更具体）
    HYPERNYM = "hypernym"           # 上位词（更概括）
    MERONYM = "meronym"             # 整体-部分
    DERIVED_FROM = "derived_from"   # 派生自
    OFTEN_CONFUSED = "often_confused"  # 易混淆
    RELATED = "related"             # 一般关联
    TRANSLATION = "translation"     # 翻译等价（中英对照）

class TermRelation(BaseModel):
    id: str
    source_term_id: str               # 源术语
    target_term_id: str               # 目标术语
    relation_type: RelationType       # 关系类型
    weight: float = 1.0               # 关系强度 0-1
    description: Optional[str]        # 关系说明
    subject_context: Optional[str]    # 学科上下文（跨学科消歧用）
    created_at: datetime
```

```python
    updated_at: datetime
```

### 2.3 缓存策略

| 缓存层 | Key 格式 | TTL | 内容 | 失效策略 |
|--------|----------|-----|------|----------|
| L1 进程内缓存 | `term:{term_id}` | 60s | 术语完整对象 | TTL 过期 |
| L1 进程内缓存 | `term:lookup:{subject}:{text}` | 120s | 文本→术语ID映射 | TTL 过期 |
| L2 Redis | `term:detail:{term_id}` | 30min | 术语 + 释义 + 关系 | 修改时主动失效 |
| L2 Redis | `term:stage:{term_id}:{stage}` | 30min | 特定学段释义 | 修改时主动失效 |
| L2 Redis | `term:glossary:{scope_id}` | 1h | 章节词汇表 | 词汇表变更时失效 |
| L2 Redis | `term:hot:{subject}` | 10min | 学科热门术语Top100 | 定时刷新 |
| L2 Redis | `term:alias:{alias_form}` | 2h | 别名→术语映射 | 别名变更时失效 |

### 3.1 接口总览

| # | 接口 | 方法 | 路径 | 说明 |

#### 4.2.2 术语标注核心算法

文本术语标注采用**多策略融合**方案：

```python
class TermAnnotator:
    """术语标注引擎：融合多策略，兼顾速度和准确率"""

    def __init__(
        self,
        ac_automaton: ACAutomaton,      # AC自动机（精确匹配）
        term_embeddings: TermEmbeddings, # 语义向量匹配
        subject_context: SubjectContext, # 学科上下文
        stage_code: str
    ):
        self.ac = ac_automaton
        self.embeddings = term_embeddings
        self.subject = subject_context
        self.stage = stage_code
        self.stop_terms = self._load_stop_terms()

    async def annotate(
        self,
        text: str,
        subject_code: str = None,
        stage_code: str = None,
        max_terms: int = 20,
        include_definitions: bool = False
    ) -> dict:
        """
        对文本进行术语标注。
        策略：AC精确匹配 → 向量近似匹配 → 合并去重 → 置信度排序
        """
        subject = subject_code or self.subject.current
        stage = stage_code or self.stage

        # Step 1: AC自动机精确匹配（快速路径）
        ac_hits = self.ac.search(text, subject=subject)
        # ac_hits: [{"term_id": "term_001", "start": 2, "end": 6, "form": "二次函数"}, ...]

        # Step 2: 向量近似匹配（深度路径，可选）
        # 仅在 annotate_level="deep" 时执行
        vector_hits = []
        if self._should_use_vector(text, len(ac_hits)):
            vector_hits = await self._vector_match(
                text, subject, stage, exclude_ids={h["term_id"] for h in ac_hits}
            )

        # Step 3: 合并与冲突解决
        all_hits = self._merge_hits(ac_hits, vector_hits, text)

        # Step 4: 过滤
        filtered = [
            h for h in all_hits
            if h["term_id"] not in self.stop_terms
            and h["confidence"] >= 0.6
        ]

        # Step 5: 排序（置信度 × 频次权重）
        filtered.sort(key=lambda h: h["confidence"] * 0.7 + h.get("freq_weight", 0.5) * 0.3, reverse=True)

        # Step 6: 截断
        filtered = filtered[:max_terms]

        # Step 7: 补充释义（可选）
        if include_definitions:
            for hit in filtered:
                hit["definition_brief"] = await self._get_brief_definition(
                    hit["term_id"], stage
                )

        return {
            "total_terms": len(filtered),
            "annotations": filtered,
            "processing_time_ms": 0  # 由调用方测量
        }

    def _merge_hits(
        self,
        ac_hits: list[dict],
        vector_hits: list[dict],
        text: str
    ) -> list[dict]:
        """
        合并精确匹配和向量匹配结果，解决重叠冲突。
        规则：同一位置精确匹配优先；重叠区域取最长匹配。
        """
        merged = list(ac_hits)

        for vh in vector_hits:
            overlap = False
            for mh in merged:
                # 检查位置重叠
                if self._is_overlap(vh, mh):
                    overlap = True
                    # 精确匹配置信度通常更高，保留已有的
                    break
            if not overlap:
                merged.append(vh)

        return merged

    @staticmethod
    def _is_overlap(a: dict, b: dict) -> bool:
        """检查两个标注区间是否重叠"""
        return not (a["end"] <= b["start"] or b["end"] <= a["start"])
```

### 4.5 跨学科消歧逻辑

同一术语在不同学科可能含义不同，系统采用**学科上下文优先**策略：

```python
class TermDisambiguator:
    """跨学科术语消歧"""

    DISAMBIGUATION_TABLE = {
        "质量": {
            "physics": "term_05001",     # mass（物理量）
            "chinese": "term_06001",      # 品质、优劣
            "default": "term_06001"       # 日常含义
        },
        "反应": {
            "chemistry": "term_07001",    # chemical reaction
            "biology": "term_08001",      # 生物反应
            "psychology": "term_09001",    # 心理反应
            "default": "term_07001"
        },
        "函数": {
            "math": "term_02310",         # mathematical function
            "programming": "term_10001",   # programming function
            "default": "term_02310"
        }
    }

    def disambiguate(
        self,
        term_form: str,
        subject_context: str = None,
        surrounding_text: str = None
    ) -> str:
        """返回最可能的 term_id"""
        if term_form not in self.DISAMBIGUATION_TABLE:
            return None

        candidates = self.DISAMBIGUATION_TABLE[term_form]

        # 优先使用显式学科上下文
        if subject_context and subject_context in candidates:
            return candidates[subject_context]

        # 使用上下文文本推断学科
        if surrounding_text:
            inferred_subject = self._infer_subject(surrounding_text)
            if inferred_subject in candidates:
                return candidates[inferred_subject]

        # 返回默认
        return candidates.get("default")
```

```python
    chapter_id: str,
    subject_code: str,
    stage_code: str

    """为教材章节自动生成词汇表"""

        stage_code=stage_code,
        max_terms=100,

    term_scores = {}
    for ann in annotations["annotations"]:
        score = (
            ann["confidence"] * 0.4 +
            min(ann.get("frequency", 1) / 10, 1.0) * 0.3 +
            (1.0 if ann.get("is_key_concept") else 0.5) * 0.3

        term_scores[ann["term_id"]] = score

    # 4. 选取 Top-N 术语（章节词汇表通常 15-40 个）
    sorted_terms = sorted(term_scores.items(), key=lambda x: x[1], reverse=True)
```

### 5.1 AC自动机构建（术语精确匹配索引）

```python
import ahocorasick

class TermACAutomaton:
    """基于AC自动机的术语高效匹配引擎"""

    def __init__(self):
        self.automaton = ahocorasick.Automaton()
        self._built = False

    def build(self, terms: list[dict]):
        """
        从术语列表构建AC自动机。
        terms: [{"term_id": "term_001", "form": "二次函数", "subject": "math"}, ...]
        """
        for term in terms:
            form = term["form"]
            self.automaton.add_word(form, {
                "term_id": term["term_id"],
                "form": form,
                "subject": term.get("subject"),
                "length": len(form)
            })

        self.automaton.make_automaton()
        self._built = True
        self.logger.info(f"AC自动机构建完成，包含 {len(terms)} 个术语")

    def search(self, text: str, subject: str = None) -> list[dict]:
        """在文本中搜索所有术语"""
        if not self._built:
            raise RuntimeError("AC自动机尚未构建")

        hits = []
        for end_pos, payload in self.automaton.iter(text):
            start_pos = end_pos - payload["length"] + 1

            # 学科过滤
            if subject and payload["subject"] and payload["subject"] != subject:
                continue

            hits.append({
                "term_id": payload["term_id"],
                "canonical_form": payload["form"],
                "start": start_pos,
                "end": end_pos + 1,
                "confidence": 1.0,
                "match_type": "exact"
            })

        # 解决嵌套冲突：保留最长匹配
        return self._resolve_overlaps(hits)

    @staticmethod
    def _resolve_overlaps(hits: list[dict]) -> list[dict]:
        """处理重叠匹配，保留最长术语"""
        if not hits:
            return []

        # 按起始位置排序
        hits.sort(key=lambda h: (h["start"], -(h["end"] - h["start"])))

        result = [hits[0]]
        for hit in hits[1:]:
            last = result[-1]
            if hit["start"] >= last["end"]:
                # 不重叠
                result.append(hit)
            elif (hit["end"] - hit["start"]) > (last["end"] - last["start"]):
                # 当前匹配更长，替换
                result[-1] = hit

        return result
```

### 5.2 NER 模型术语抽取

```python
import torch
from transformers import AutoTokenizer, AutoModelForTokenClassification

class TermNERExtractor:
    """基于 BERT-BiLSTM-CRF 的学科术语命名实体识别"""

    LABEL_MAP = {
        0: "O",
        1: "B-TERM",   # 术语起始
        2: "I-TERM",   # 术语内部
        3: "B-FORMULA", # 公式起始
        4: "I-FORMULA", # 公式内部
    }

    def __init__(self, model_path: str, device: str = "cpu"):
        self.tokenizer = AutoTokenizer.from_pretrained(model_path)
        self.model = AutoModelForTokenClassification.from_pretrained(model_path)
        self.model.to(device)
        self.model.eval()
        self.device = device
        self.max_length = 512

    @torch.no_grad()
    def extract(self, text: str, subject: str = None) -> list[dict]:
        """
        从文本中抽取候选术语。
        返回: [{"text": "二次函数", "start": 2, "end": 6, "confidence": 0.95}, ...]
        """
        # 分词
        inputs = self.tokenizer(
            text,
            max_length=self.max_length,
            truncation=True,
            return_offsets_mapping=True,
            return_tensors="pt"
        ).to(self.device)

        offset_mapping = inputs.pop("offset_mapping")[0]

        # 推理
        outputs = self.model(**inputs)
        predictions = outputs.logits.argmax(dim=-1)[0]
        scores = outputs.logits.softmax(dim=-1)[0]

        # 解码实体
        entities = []
        current_entity = None

        for idx, (pred_id, offsets) in enumerate(zip(predictions, offset_mapping)):
            label = self.LABEL_MAP[pred_id.item()]
            start, end = offsets[0].item(), offsets[1].item()

            if start == end:  # 特殊token
                continue

            if label.startswith("B-"):
                if current_entity:
                    entities.append(current_entity)
                current_entity = {
                    "text": text[start:end],
                    "start": start,
                    "end": end,
                    "label": label[2:],
                    "confidence": scores[idx][pred_id].item()
                }
            elif label.startswith("I-") and current_entity:
                current_entity["text"] += text[start:end]
                current_entity["end"] = end
                current_entity["confidence"] = min(
                    current_entity["confidence"],
                    scores[idx][pred_id].item()
                )
            else:
                if current_entity:
                    entities.append(current_entity)
                    current_entity = None

        if current_entity:
            entities.append(current_entity)

        return entities
```

## 7. 性能优化

### 7.1 AC自动机内存优化

全量术语（50,000+）加载到 AC 自动机预计占用 ~200MB 内存，采用**分学科构建**策略：

```python
class SubjectAwareACAutomaton:
    """按学科分别构建AC自动机，减少单机内存"""

    def __init__(self):
        self.subject_automatons: dict[str, ahocorasick.Automaton] = {}
        self.general_automaton = ahocorasick.Automaton()  # 跨学科通用术语

    def search(self, text: str, subject: str = None) -> list:
        hits = []

        # 搜索通用术语
        hits.extend(self._search_single(self.general_automaton, text))

        # 搜索学科专属术语
        if subject and subject in self.subject_automatons:
            hits.extend(self._search_single(self.subject_automatons[subject], text))

        return self._resolve_overlaps(hits)
```
