# 服务端 - 学生数字安全防护与上网行为保护引擎

## 1. 概述

### 1.1 模块定位

学生数字安全防护引擎是 PrimeTop 平台面向 K-12 未成年人用户的安全基础设施，负责在平台全链路中检测、拦截、记录和响应各类外部数字安全威胁。区别于平台自身的账号安全与内容合规体系，本模块聚焦于**学生侧的数字安全体验**——确保学生在使用 AI 对话、浏览学习内容、参与社交互动时，不会接触到钓鱼欺诈、恶意软件、色情暴力、网络诈骗等有害信息或危险外部资源。

### 1.2 设计目标

| 目标 | 描述 |
|------|------|
| 外部链接安全 | 对 AI 回答、用户内容、教育素材中出现的所有外部 URL 进行实时安全检测与拦截 |
| 内容分类过滤 | 对外部内容按教育适宜性评级，阻断不适宜未成年人访问的资源 |
| 欺诈防护 | 识别并拦截针对未成年人的网络诈骗、社交工程攻击 |
| 安全浏览守护 | 为 App 内嵌 WebView 提供安全代理与内容过滤 |
 | 家长可见 | 为家长提供安全事件报告与防护策略配置 |
| 合规留痕 | 所有安全事件可追溯、可审计，满足未成年人保护法要求 |

### 1.3 适用场景

```
场景1: AI 对话回答中包含外部链接 → 链接安全检测 → 安全则展示，危险则替换/隐藏
场景2: 用户在社区/讨论区分享链接 → 发帖前 URL 安全扫描 → 拦截恶意链接
场景3: 教育内容引用外部资源 → 内容入库时批量安全审核
场景4: 学生在 App 内 WebView 浏览 → 实时内容过滤与安全代理
场景5: AI 回答中包含可疑联系方式/QQ/微信号 → 欺诈信号检测
场景6: 用户举报外部链接 → 人工审核 → 加入黑名单
```

### 1.4 与现有模块的边界

| 模块 | 职责边界 |
|------|----------|
| 安全与内容合规系统 | 平台级安全策略框架，本模块是其子域的具体执行层 |
| 教育场景敏感词过滤 | 文本层面的敏感词检测，本模块处理 URL/外部资源维度 |
| AI 输入安全护栏 | AI 对话输入侧安全，本模块覆盖 AI 输出侧的链接安全 |
| 用户生成内容安全审核 | UGC 内容审核，本模块提供 URL 维度的安全能力支撑 |
| 防沉迷系统 | 使用时长与频率管控，本模块关注内容与链接安全 |

## 3. 数据结构设计

### 3.1 URL 信誉库 (`url_reputation`)

```sql
CREATE TABLE url_reputation (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    url_hash        VARCHAR(64) NOT NULL COMMENT 'URL的SHA-256哈希',
    normalized_url  VARCHAR(2048) NOT NULL COMMENT '规范化后的URL',
    domain          VARCHAR(255) NOT NULL COMMENT '域名',
    
    -- 安全评级
    safety_level    ENUM('SAFE', 'LOW_RISK', 'MEDIUM_RISK', 'HIGH_RISK', 'BLOCKED') 
                    NOT NULL DEFAULT 'SAFE',
    threat_types    JSON COMMENT '["PHISHING", "MALWARE", "ADULT", "VIOLENCE", "GAMBLING", "FRAUD"]',
    
    -- 教育适宜性
    education_rating ENUM('EDUCATIONAL', 'NEUTRAL', 'CAUTION', 'INAPPROPRIATE')
                    NOT NULL DEFAULT 'NEUTRAL',
    
    -- 来源与置信度
    detection_source ENUM('INTERNAL', 'EXTERNAL_API', 'MANUAL', 'USER_REPORT', 'AUTO_ANALYSIS')
                    NOT NULL DEFAULT 'AUTO_ANALYSIS',
    confidence_score DECIMAL(3,2) NOT NULL DEFAULT 0.00 COMMENT '置信度 0.00-1.00',
    
    -- 时间信息
    first_seen       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    last_checked     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    check_count      INT NOT NULL DEFAULT 1,
    expire_at        DATETIME COMMENT '信誉过期时间，NULL表示不过期',
    
    -- 状态
    status           ENUM('ACTIVE', 'ARCHIVED', 'DISPUTED') NOT NULL DEFAULT 'ACTIVE',
    
    -- 关联信息
    category         VARCHAR(50) COMMENT '网站分类：教育/新闻/社交/购物/游戏等',
    notes            TEXT COMMENT '审核备注',
    reported_by      BIGINT COMMENT '举报用户ID',
    reviewed_by      BIGINT COMMENT '审核人员ID',
    
    UNIQUE KEY uk_url_hash (url_hash),
    INDEX idx_domain (domain),
    INDEX idx_safety_level (safety_level),
    INDEX idx_last_checked (last_checked),
    INDEX idx_education_rating (education_rating)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='URL安全信誉数据库';
```

## 5. 核心检测管线设计

### 5.1 URL 安全检测管线

```python
class URLSafetyPipeline:
    """URL安全检测管线 - 多阶段检测流程"""
    
    def __init__(self):
        self.stages = [
            NormalizationStage(),       # 1. URL规范化
            CacheLookupStage(),         # 2. 缓存查询
            AllowlistCheckStage(),      # 3. 白名单检查
            DenylistCheckStage(),       # 4. 黑名单检查
            DomainAnalysisStage(),      # 5. 域名分析
            ExternalAPICheckStage(),    # 6. 外部安全API查询
            ContentFetchStage(),        # 7. 内容抓取(按需)
            MLClassificationStage(),    # 8. ML分类
            ResultAggregationStage(),   # 9. 结果聚合
        ]
    
    async def scan(self, url: str, context: ScanContext) -> URLScanResult:
        normalized = self.normalize_url(url)
        
        # 阶段1: URL规范化
        normalized_url = self.normalize(url)
        url_hash = hashlib.sha256(normalized_url.encode()).hexdigest()
        
        # 阶段2: 缓存查询
        cached = await self.cache.get(url_hash)
        if cached and not self.is_expired(cached):
            return URLScanResult.from_cache(cached)
        
        # 阶段3: 白名单快速放行
        if await self.allowlist.matches(normalized_url, context.grade_tier):
            return URLScanResult(
                url=url, safety_level="SAFE", action="ALLOW",
                reason="ALLOWLIST_MATCH", cached=False
            )
        
        # 阶段4: 黑名单直接拦截
        deny_match = await self.denylist.matches(normalized_url, context.grade_tier)
        if deny_match:
            return URLScanResult(
                url=url, safety_level="BLOCKED", action="BLOCK",
                threat_types=deny_match.threat_types,
                reason="DENYLIST_MATCH", cached=False
            )
        
        # 阶段5: 域名信誉分析
        domain = self.extract_domain(normalized_url)
        domain_reputation = await self.domain_reputation_service.check(domain)
        
        # 阶段6: 外部安全API查询(并行)
        external_results = await asyncio.gather(
            self.google_safe_browsing.check(normalized_url),
            self.internal_threat_intel.check(normalized_url),
            self.phishing_database.lookup(url_hash),
            return_exceptions=True
        )
        
        # 阶段7: 内容抓取与ML分类(中风险URL)
        content_analysis = None
        if self.needs_deep_analysis(domain_reputation, external_results):
            content_analysis = await self.fetch_and_classify(normalized_url)
        
        # 阶段8: 综合风险评分
        risk_score = self.compute_risk_score(
            domain_reputation, external_results, content_analysis
        )
        
        # 阶段9: 生成结果
        result = URLScanResult(
            url=url,
            url_hash=url_hash,
            safety_level=self.score_to_level(risk_score),
            risk_score=risk_score,
            threat_types=self.extract_threat_types(external_results, content_analysis),
            education_rating=self.compute_education_rating(domain, content_analysis),
            action=self.decide_action(risk_score, context),
            detection_source="AUTO_ANALYSIS",
            confidence_score=self.compute_confidence(external_results, content_analysis),
            checked_at=datetime.utcnow()
        )
        
        # 写入缓存
        await self.cache.set(url_hash, result, ttl=self.get_cache_ttl(result.safety_level))
        
        # 异步入库
        await self.reputation_store.upsert(result)
        
        return result
```

```python
class URLNormalizer:
    """URL规范化处理器"""
    
    def normalize(self, raw_url: str) -> str:
        url = raw_url.strip()
        
        # 协议补全
        if not url.startswith(('http://', 'https://')):
            url = 'https://' + url
        
        # 解析URL
        parsed = urlparse(url)
        
        # 域名小写化
        netloc = parsed.netloc.lower()
        
        # 移除默认端口
        if netloc.endswith(':80') and parsed.scheme == 'http':
            netloc = netloc[:-3]
        elif netloc.endswith(':443') and parsed.scheme == 'https':
            netloc = netloc[:-4]
        
        # 移除 www. 前缀(统一比较)
        if netloc.startswith('www.'):
            netloc = netloc[4:]
        
        # 路径规范化
        path = parsed.path.rstrip('/') or '/'
        
        # 解码并重新编码查询参数(排序)
        params = parse_qs(parsed.query)
        sorted_query = urlencode(sorted(params.items()), doseq=True)
        
        # 移除跟踪参数
        tracking_params = {'utm_source', 'utm_medium', 'utm_campaign', 
                          'utm_content', 'utm_term', 'fbclid', 'gclid'}
        filtered = {k: v for k, v in params.items() if k.lower() not in tracking_params}
        clean_query = urlencode(sorted(filtered.items()), doseq=True)
        
        # 重组
        normalized = urlunparse((
            parsed.scheme, netloc, path, parsed.params, clean_query, ''
        ))
        
        return normalized
    
    def extract_domain(self, url: str) -> str:
        """提取注册域名(去除子域名)"""
        parsed = urlparse(url)
        domain_parts = parsed.netloc.split('.')
        # 简单的注册域名提取(实际应使用tldextract库)
        if len(domain_parts) > 2:
            return '.'.join(domain_parts[-2:])
        return parsed.netloc
    
    def is_short_url(self, url: str) -> bool:
        """检测是否为短链接"""
        short_domains = {
            'bit.ly', 'tinyurl.com', 't.co', 'goo.gl', 'ow.ly',
            'is.gd', 'buff.ly', 'rebrand.ly', 'shorturl.at',
            'dwz.cn', 'url.cn', 'suo.nz', 'mr.baidu.com'
        }
        domain = self.extract_domain(url)
        return domain in short_domains
    
    async def expand_short_url(self, url: str) -> str:
        """展开短链接获取真实URL"""
        async with httpx.AsyncClient(follow_redirects=True) as client:
            response = await client.head(url, timeout=5.0)
            return str(response.url)
```

### 6.1 决策流程

```python
class SafetyDecisionEngine:
    """综合安全决策引擎 - 汇总多管线结果做出最终决策"""
    
    async def decide(
        self,
        url_results: List[URLScanResult],
        fraud_findings: List[FraudFinding],
        education_ratings: List[EducationRating],
        user_context: UserContext,
        parent_policy: ParentSafetyPolicy
    ) -> SafetyDecision:
        
        # 1. 计算综合风险评分
        max_url_risk = max((r.risk_score for r in url_results), default=0)
        max_fraud_risk = max(
            (self.severity_to_score(f.severity) for f in fraud_findings), default=0
        )
        max_education_risk = max(
            (r.score for r in education_ratings), default=0
        )
        
        overall_risk = max(max_url_risk, max_fraud_risk, max_education_risk)
        
        # 2. 应用家长策略覆盖
        overall_risk = self.apply_parent_policy(
            overall_risk, url_results, user_context, parent_policy
        )
        
        # 3. 决策逻辑
        if overall_risk >= 80 or self.has_critical_threat(url_results, fraud_findings):
            action = "BLOCK"
        elif overall_risk >= 60 or self.has_high_severity(fraud_findings):
            action = "WARN"
        elif overall_risk >= 40:
            action = "REVIEW"  # 需要人工审核或延迟展示
        else:
            action = "ALLOW"
        
        # 4. 特殊规则：学段差异化处理
        action = self.adjust_for_grade_tier(action, overall_risk, user_context.grade_tier)
        
        # 5. 生成决策详情
        decision = SafetyDecision(
            action=action,
            risk_score=overall_risk,
            details={
                "url_max_risk": max_url_risk,
                "fraud_max_risk": max_fraud_risk,
                "education_max_risk": max_education_risk,
                "parent_policy_applied": parent_policy is not None,
                "grade_tier": user_context.grade_tier,
            },
            recommendations=self.generate_recommendations(action, url_results, fraud_findings)
        )
        
        # 6. 记录事件
        if action in ("BLOCK", "WARN"):
            await self.event_processor.record(decision, user_context)
        
        return decision
    
    def apply_parent_policy(
        self, risk: float, url_results: List, 
        user_context: UserContext, policy: ParentSafetyPolicy
    ) -> float:
        """应用家长策略调整风险评分"""
        if not policy:
            return risk
        
        # 家长拦截特定域名
        for result in url_results:
            domain = self.extract_domain(result.url)
            if domain in (policy.blocked_domains or []):
                return 100.0  # 强制拦截
            
            # 家长白名单
            if domain in (policy.allowed_domains or []):
                return min(risk, 10.0)  # 强制放行
        
        # 内容过滤级别
        if policy.content_filter_level == "STRICT":
            risk *= 1.3
        elif policy.content_filter_level == "MODERATE":
            risk *= 1.0
        elif policy.content_filter_level == "RELAXED":
            risk *= 0.8
        
        # 外部链接模式
        if policy.external_link_mode == "BLOCK_ALL":
            for result in url_results:
                if not result.is_internal:
                    return 100.0
        elif policy.external_link_mode == "EDUCATIONAL_ONLY":
            for result in url_results:
                if result.education_rating != "EDUCATIONAL":
                    return 90.0
        
        return min(100, risk)
```

        "APPEAL_APPROVED": ["CONFIRMED_SAFE"],
        "APPEAL_REJECTED": ["CONFIRMED_BLOCKED"],
        "MONITORING": ["SCANNING"],         # 定期重新扫描
    }

        return to_state in self.TRANSITIONS.get(from_state, [])

    ):

                f"Cannot transition from {event.status} to {to_state}"
            )

            event_id=event_id,
            status=to_state,
            updated_by=operator_id,
            reason=reason
        )
        
        # 发布状态变更事件
        await self.event_bus.publish(

class InternalThreatIntel:

    async def lookup(self, url_hash: str) -> Optional[ThreatIntel]:

                "SELECT * FROM url_reputation WHERE url_hash = %s AND safety_level IN ('HIGH_RISK', 'BLOCKED')",
                url_hash
            )
            if row:
                # 回填缓存
                await self.redis.hset(f"threat:{url_hash}", mapping=dict(row))
                await self.redis.expire(f"threat:{url_hash}", 3600)
                return ThreatIntel.from_db(row)
        
        return None
    
    async def add_threat(self, url_hash: str, threat_type: str, source: str):
        """添加新威胁到情报库"""
        await self.redis.bf.add("threat:bloom", url_hash)
        await self.redis.hset(
            f"threat:{url_hash}",
            mapping={"threat_type": threat_type, "source": source, 
                     "added_at": datetime.utcnow().isoformat()}
        )
        await self.redis.expire(f"threat:{url_hash}", 86400 * 30)  # 30天
    
    async def bulk_import(self, threat_list: List[Dict]):
        """批量导入威胁情报"""

```python
class AIResponseSafetyFilter:
    """AI回答输出安全后处理器 - 嵌入流式输出管线"""
    
    def __init__(self, safety_engine: SafetyDecisionEngine):
        self.safety = safety_engine
        self.url_extractor = URLExtractor()
        self.fraud_detector = FraudDetectionEngine()
    
    async def post_process_stream(
        self, 
        text_stream: AsyncIterator[str],
        user_context: UserContext
    ) -> AsyncIterator[str]:
        """
        流式处理AI输出，缓冲并检测URL和欺诈内容
        策略：按句/段落缓冲，检测后输出
        """
        buffer = ""
        buffer_size = 0
        MAX_BUFFER = 500  # 最大缓冲字符数
        
        async for chunk in text_stream:
            buffer += chunk
            buffer_size += len(chunk)
            
            # 检测是否有完整URL或段落边界
            has_complete_url = self.has_complete_url(buffer)
            has_sentence_end = any(c in buffer for c in "。！？\n")
            
            if has_complete_url or (has_sentence_end and buffer_size >= MAX_BUFFER):
                # 提取并检测URL
                urls = self.url_extractor.extract(buffer)
                if urls:
                    url_results = await self.safety.scan_urls(urls, user_context)
                    buffer = self.replace_unsafe_urls(buffer, url_results)
                
                # 检测欺诈内容
                fraud_findings = self.fraud_detector.detect(buffer, user_context)
                if fraud_findings:
                    buffer = self.fraud_detector.sanitize(buffer, fraud_findings)
                
                yield buffer
                buffer = ""
                buffer_size = 0
        
        # 处理剩余缓冲
        if buffer:
            urls = self.url_extractor.extract(buffer)
            if urls:
                url_results = await self.safety.scan_urls(urls, user_context)
                buffer = self.replace_unsafe_urls(buffer, url_results)
            
            fraud_findings = self.fraud_detector.detect(buffer, user_context)
            if fraud_findings:
                buffer = self.fraud_detector.sanitize(buffer, fraud_findings)
            
            yield buffer
    
    def replace_unsafe_urls(self, text: str, results: List[URLScanResult]) -> str:
        """替换不安全的URL"""
        for result in results:
            if result.action == "BLOCK":
                text = text.replace(
                    result.url,
                    f"[链接已拦截：检测到{','.join(result.threat_types)}风险]"
                )
            elif result.action == "WARN":
                # 添加风险标记但保留链接
                text = text.replace(
                    result.url,
                    f"⚠️ {result.url}（风险提示：{result.risk_score:.0f}分）"
                )
        return text


class URLExtractor:
    """从文本中提取URL"""
    
    URL_PATTERN = re.compile(
        r'https?://[^\s<>"{}|\\^`\[\]]+'
        r'|www\.[^\s<>"{}|\\^`\[\]]+'
        r'|[a-zA-Z0-9][-a-zA-Z0-9]*\.(?:com|cn|net|org|edu|gov|io|cc|tk|ml|ga|run|club)'
        r'(?:/[^\s<>"{}|\\^`\[\]]*)?'
    )
    
    # 中国常见域名模式
    CN_URL_PATTERN = re.compile(
        r'(?:https?://)?(?:[\w-]+\.)+(?:com\.cn|cn|com|net|org|edu\.cn|gov\.cn)'
        r'(?:/[^\s<>"\'\)\]]*)?'
    )
    
    def extract(self, text: str) -> List[str]:
        urls = set()
        
        # 标准URL
        for match in self.URL_PATTERN.finditer(text):
            url = match.group()
            if not url.startswith('http'):
                url = 'https://' + url
            urls.add(url)
        
        # 中国域名模式
        for match in self.CN_URL_PATTERN.finditer(text):
            url = match.group()
            if not url.startswith('http'):
                url = 'https://' + url
            urls.add(url)
        
        return list(urls)
```

class SafetyCacheManager:
    """安全检测多级缓存管理"""
    
    CACHE_LEVELS = {
        "L1_BLOOM": {
            "description": "布隆过滤器 - 快速判断URL是否可能安全",
            "storage": "Redis BF",
            "ttl": "永久",
            "hit_rate_target": "70%+",
            "latency": "<1ms"
        },
        "L2_RESULT": {
            "description": "URL检测结果缓存",
            "storage": "Redis Hash",
            "ttl": "安全URL:7天 | 高风险:1天 | 中风险:3天",
            "hit_rate_target": "85%+",
            "latency": "<3ms"
        },
        "L3_DB": {
            "description": "MySQL信誉库",
            "storage": "MySQL",
            "ttl": "按expire_at字段",
            "hit_rate_target": "95%+",
            "latency": "<10ms"
        }
    }
    
    async def get(self, url_hash: str) -> Optional[URLScanResult]:
        """多级缓存查询"""
        # L1: 布隆过滤器
        known_threat = await self.redis.bf.exists("threat:bloom", url_hash)
        known_safe = await self.redis.bf.exists("safe:bloom", url_hash)
        
        if known_safe and not known_threat:
            # 大概率安全，返回快速结果
            return URLScanResult.fast_safe(url_hash)
        
        # L2: Redis精确缓存
        cached = await self.redis.hgetall(f"url_safety:{url_hash}")
        if cached:
            result = URLScanResult.from_cache(cached)
            if not self.is_expired(result):
                return result
        
        # L3: MySQL
        result = await self.db.fetchone(
            "SELECT * FROM url_reputation WHERE url_hash = %s",
            url_hash
        )
        if result:
            # 回填Redis
            await self.backfill_cache(url_hash, result)
            return URLScanResult.from_db(result)
        
        return None  # 缓存未命中
    
    async def set(self, url_hash: str, result: URLScanResult):
        """写入多级缓存"""
        ttl = self.get_ttl(result.safety_level)
        
        # L1: 布隆过滤器
        if result.safety_level == "SAFE":
            await self.redis.bf.add("safe:bloom", url_hash)
        elif result.safety_level in ("HIGH_RISK", "BLOCKED"):
            await self.redis.bf.add("threat:bloom", url_hash)
        
        # L2: Redis Hash
        await self.redis.hset(
            f"url_safety:{url_hash}",
            mapping=result.to_cache_dict()
        )
        await self.redis.expire(f"url_safety:{url_hash}", ttl)
        
        # L3: MySQL (异步写入)
        await self.db.execute(
            """INSERT INTO url_reputation 
               (url_hash, normalized_url, domain, safety_level, threat_types, 
                education_rating, detection_source, confidence_score, 
                last_checked, expire_at)
               VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
               ON DUPLICATE KEY UPDATE
               safety_level = VALUES(safety_level),
               threat_types = VALUES(threat_types),
               last_checked = VALUES(last_checked),
               expire_at = VALUES(expire_at)""",
            (url_hash, result.normalized_url, result.domain,
             result.safety_level, json.dumps(result.threat_types),
             result.education_rating, result.detection_source,
             result.confidence_score, datetime.utcnow(),
             datetime.utcnow() + timedelta(seconds=ttl))
        )
    
    def get_ttl(self, safety_level: str) -> int:
        """根据安全等级设置缓存TTL"""
        ttl_map = {
            "SAFE": 7 * 24 * 3600,       # 7天
            "LOW_RISK": 3 * 24 * 3600,    # 3天
            "MEDIUM_RISK": 24 * 3600,     # 1天
            "HIGH_RISK": 12 * 3600,       # 12小时(更频繁复查)
            "BLOCKED": 24 * 3600,         # 1天
        }
        return ttl_map.get(safety_level, 24 * 3600)

### 16.2 安全等级与处置映射

| 风险评分 | 安全等级 | 处置动作 | 说明 |
|----------|----------|----------|------|
| 0-30 | SAFE | ALLOW | 安全，正常展示 |
| 31-50 | LOW_RISK | ALLOW | 低风险，正常展示，记录监控 |
| 51-70 | MEDIUM_RISK | WARN | 中风险，展示但附风险提示 |
| 71-85 | HIGH_RISK | BLOCK | 高风险，拦截并通知 |
| 86-100 | BLOCKED | BLOCK | 确认危险，拦截并记录事件 |
