# 端到端流程设计 - 亲子共学模式完整链路

> **版本**：v1.0 | **日期**：2026-06-06 | **优先级**：P1 | **目标学段**：幼儿（3-6岁）/ 小学低年级（6-8岁）
> **关联模块**：拼音识字启蒙、家长中心、防沉迷与未成年人保护、语音服务(ASR/TTS)、护眼模式、运营活动与成长激励

---

## 1. 概述

### 1.1 什么是亲子共学模式

亲子共学模式是 PrimeTop 面向 **幼儿及小学低年级用户** 设计的双角色协作学习模式。在该模式下，**家长与孩子共同使用同一台设备**，家长负责引导、监督和互动，孩子作为实际学习者完成学习任务。

与普通学习模式的核心区别：
- **双角色同屏**：家长侧控制面板与孩子侧学习内容协同展示
- **家长实时介入**：学习过程中家长可随时调整难度、给予鼓励、切换内容
- **安全边界强化**：时长限制更严格、内容范围更可控、家长可随时终止
- **互动反馈双向**：孩子端反馈传递给家长，家长端操作影响孩子学习

### 1.2 端到端流程范围

本文档覆盖从"进入亲子共学"到"结束并生成学习记录"的完整链路：

```
家长进入/创建共学 → 内容选择与配置 → 共学进行中(互动循环) → 结束共学 → 学习记录与报告 → 家长端查看
```

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 进入共学耗时 | < 3步操作 |
| 互动响应延迟 | < 500ms（本地反馈） |
| 家长操作干扰度 | 不打断孩子学习流 |
| 共学结束报告延迟 | < 5秒 |
| 单次共学时长上限 | 30分钟（可配置，强制提醒） |

## 2. 角色与权限模型

### 2.1 角色定义

```dart
/// 共学角色
enum CoLearnRole {
  parent,   // 家长：控制、引导、监督
  child,    // 孩子：学习、互动、反馈
}

/// 家长操作权限
enum ParentAction {
  pauseLearning,       // 暂停学习
  skipContent,         // 跳过当前内容
  adjustDifficulty,    // 调整难度
  giveEncouragement,   // 发送鼓励
  startBreak,          // 强制休息
  endSession,          // 结束共学
  switchContent,       // 切换学习内容
  adjustVolume,        // 调整音量/语速
  toggleHint,          // 开关提示辅助
}
```

### 2.2 权限矩阵

| 操作 | 家长 | 孩子 | 说明 |
|------|------|------|------|
| 开始/结束共学 | ✅ | ❌ | 家长全程控制 |
| 暂停/继续 | ✅ | ❌ | 孩子可请求暂停 |
| 调整难度 | ✅ | ❌ | 根据孩子状态由家长决定 |
| 发送鼓励 | ✅ | ❌ | 家长→孩子单向 |
| 选择学习内容 | ✅ | 🔸引导式 | 孩子有建议权，家长有决定权 |
| 答题/互动 | ❌ | ✅ | 仅限孩子操作 |
| 请求帮助 | ❌ | ✅ | 孩子→家长 |
| 查看进度报告 | ✅ | 🔸简化版 | 孩子仅看到奖励/勋章 |

## 3. 核心数据结构

### 3.1 共学会话

```sql
-- 共学会话表
CREATE TABLE co_learn_session (
    id                  BIGINT UNSIGNED    NOT NULL COMMENT '会话ID，雪花算法',
    parent_user_id      BIGINT UNSIGNED    NOT NULL COMMENT '家长用户ID',
    child_user_id       BIGINT UNSIGNED    NOT NULL COMMENT '孩子用户ID（同账号或绑定子账号）',
    profile_id          BIGINT UNSIGNED    NOT NULL COMMENT '孩子学习档案ID',
    
    -- 会话状态
    status              TINYINT UNSIGNED   NOT NULL DEFAULT 0 COMMENT '状态: 0=准备中 1=进行中 2=休息中 3=已结束',
    started_at          DATETIME           NULL     COMMENT '开始时间',
    ended_at            DATETIME           NULL     COMMENT '结束时间',
    duration_seconds    INT UNSIGNED       NOT NULL DEFAULT 0 COMMENT '有效学习时长（秒）',
    
    -- 学习配置
    subject             VARCHAR(32)        NOT NULL COMMENT '学科: pinyin/literacy/math/english',
    content_type        VARCHAR(32)        NOT NULL COMMENT '内容类型: flashcard/story/game/practice',
    difficulty_level    TINYINT UNSIGNED   NOT NULL DEFAULT 1 COMMENT '初始难度: 1-5',
    max_duration_min    TINYINT UNSIGNED   NOT NULL DEFAULT 20 COMMENT '最大时长（分钟）',
    
    -- 互动统计
    total_items         INT UNSIGNED       NOT NULL DEFAULT 0 COMMENT '总学习项数',
    completed_items     INT UNSIGNED       NOT NULL DEFAULT 0 COMMENT '完成项数',
    correct_count       INT UNSIGNED       NOT NULL DEFAULT 0 COMMENT '正确数',
    parent_encouragements INT UNSIGNED     NOT NULL DEFAULT 0 COMMENT '家长鼓励次数',
    child_help_requests   INT UNSIGNED     NOT NULL DEFAULT 0 COMMENT '孩子求助次数',
    parent_interventions  INT UNSIGNED     NOT NULL DEFAULT 0 COMMENT '家长干预次数（跳过/调难度）',
    
    -- 环境信息
    device_id           VARCHAR(64)        NULL     COMMENT '设备ID',
    app_version         VARCHAR(32)        NULL     COMMENT 'APP版本',
    break_count         TINYINT UNSIGNED   NOT NULL DEFAULT 0 COMMENT '休息次数',
    
    PRIMARY KEY (id),
    INDEX idx_parent_status (parent_user_id, status),
    INDEX idx_child_time (child_user_id, started_at),
    INDEX idx_profile_time (profile_id, started_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='亲子共学会话';
```

### 3.4 Dart 模型

```dart
/// 共学会话模型
class CoLearnSession {
  final String id;
  final String parentUserId;
  final String childUserId;
  final String profileId;
  
  CoLearnStatus status;
  DateTime? startedAt;
  DateTime? endedAt;
  int durationSeconds;
  
  String subject;
  String contentType;
  int difficultyLevel;
  int maxDurationMin;
  
  int totalItems;
  int completedItems;
  int correctCount;
  int parentEncouragements;
  int childHelpRequests;
  int parentInterventions;
  
  CoLearnSession({
    required this.id,
    required this.parentUserId,
    required this.childUserId,
    required this.profileId,
    this.status = CoLearnStatus.preparing,
    this.durationSeconds = 0,
    required this.subject,
    required this.contentType,
    this.difficultyLevel = 1,
    this.maxDurationMin = 20,
  });
}

/// 共学状态枚举
enum CoLearnStatus {
  preparing,    // 准备中（选内容、调参数）
  inProgress,   // 学习进行中
  onBreak,      // 休息中
  ended,        // 已结束
}

/// 互动事件
class CoLearnInteraction {
  final String sessionId;
  final DateTime eventTime;
  final CoLearnEventType eventType;
  final CoLearnActor actor;
  final String? contentId;
  final int? itemIndex;
  final Map<String, dynamic>? eventData;
  final int? elapsedSeconds;
}

enum CoLearnEventType {
  childAnswer,          // 孩子作答
  childHelpRequest,     // 孩子求助
  parentEncourage,      // 家长鼓励
  parentIntervene,      // 家长干预
  difficultyChange,     // 难度调整
  breakStart,           // 开始休息
  breakEnd,             // 休息结束
  contentSwitch,        // 切换内容
  autoHint,             // 系统自动提示
  sessionTimeout,       // 会话超时
}

enum CoLearnActor { parent, child, system }
```

## 6. 状态流转

### 6.1 共学会话状态机

```
                    家长确认配置
    [preparing] ─────────────────→ [inProgress]
         │                              │  │  │
         │                              │  │  │ 达到最大时长
         │                              │  │  ↓
         │                              │  │  [自动结束]
         │                              │  │     │
         │                   家长点击暂停 │  │     ↓
         │                              │  ↓  [ended]
         │                              │  [onBreak]
         │                              │     │
         │                              │     │ 休息结束 / 家长继续
         │                              │←────┘
         │                              │
         │  家长主动结束                 │  家长主动结束
         │  (未开始就退出)              │  孩子请求结束
         ↓                              ↓
       [cancelled]                  [ended]
```

### 6.2 单题学习项状态流转

```
[展示中] → [等待作答] → [回答正确] → [正确动画] → [下一题]
                │
                ├→ [回答错误] → [显示提示] → [等待重答] → [回答正确/跳过]
                │
                └→ [孩子求助] → [通知家长] → [家长介入] → [继续/跳过]
```

### 6.3 自适应难度调整流程

```
每次作答后检查:
├─ 连续正确 ≥ 3 题 → 建议+1难度 → 弹窗通知家长 → 家长确认/拒绝
├─ 连续错误 ≥ 2 题 → 建议-1难度 → 弹窗通知家长 → 家长确认/拒绝
├─ 单题耗时 > 30s  → 提示家长关注 → 不自动调整
├─ 正确率 > 95% 且已完成 ≥ 8 题 → 建议结束（学得很好） → 家长决定
└─ 正确率 < 50% 且已完成 ≥ 5 题 → 建议换内容或休息 → 家长决定
```

```dart
  }
  
  /// 孩子作答
  Future<AnswerResult> submitChildAnswer({
    required String answer,
    int? itemIndex,
  }) async {
    final index = itemIndex ?? _currentItemIndex;
    final stopwatch = Stopwatch()..start();
    
    // 1. 本地即时反馈（不等网络）
    final isCorrect = _checkAnswerLocally(index, answer);

    // 2. 展示即时反馈动画
    if (isCorrect) {
      await _showCorrectAnimation();
      await _audioPlayer.playEffect('correct_ding');
    } else {
      await _showIncorrectHint(index);
      await _audioPlayer.playEffect('gentle_try_again');
    }
    
    // 3. 异步提交到服务端
    _repository.submitEvent(
      sessionId: _currentSession!.id,
      eventType: CoLearnEventType.childAnswer,
      actor: CoLearnActor.child,
      itemIndex: index,
      eventData: {
        'answer': answer,
        'isCorrect': isCorrect,
        'responseTimeMs': stopwatch.elapsedMilliseconds,
        'attempts': 1,
      },
    ).then((response) {
      // 处理自适应建议
      if (response.adaptiveSuggestion?.difficultyAdjustment != 0) {
        _handleAdaptiveSuggestion(response.adaptiveSuggestion!);
      }
    });
    
    // 4. 更新本地计数
    _currentSession!.completedItems++;
    if (isCorrect) _currentSession!.correctCount++;
    
    // 5. 正确则进入下一题；错误则允许重试
    if (isCorrect) {
      _currentItemIndex++;
      if (_currentItemIndex < _currentSession!.totalItems) {
        _presentItem(_currentItemIndex);
      } else {

      }
    }
    
    notifyListeners();

  }

    await _audioPlayer.playEffect('encouragement_${type.name}');

    _repository.submitEvent(
      sessionId: _currentSession!.id,
      eventType: CoLearnEventType.parentEncourage,
      actor: CoLearnActor.parent,
      itemIndex: _currentItemIndex,
      eventData: {
        'type': type.name,
        'text': text,
        'stickerId': stickerId,

    notifyListeners();

    String? reason,
    int? newDifficulty,
  }) async {
    _repository.submitEvent(
      sessionId: _currentSession!.id,
      eventType: CoLearnEventType.parentIntervene,
      actor: CoLearnActor.parent,

      eventData: {

        'reason': reason,
        'newDifficulty': newDifficulty,

      case 'skip':

          _presentItem(_currentItemIndex);
        }
        break;
      case 'adjustDifficulty':

          _currentSession!.difficultyLevel = newDifficulty;
        }
        break;
```

```java
 * 亲子共学服务

@Service
@Slf4j
public class CoLearnService {
    
    @Autowired
    private CoLearnSessionRepository sessionRepo;
    @Autowired
    private CoLearnEventRepository eventRepo;
    @Autowired
    private CoLearnReportRepository reportRepo;
    @Autowired
    private ContentPlanGenerator contentPlanGenerator;
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    private static final String SESSION_KEY = "colearn:session:";
    private static final String TIMER_KEY = "colearn:timer:";
    
    /**
     * 创建共学会话
     */
    @Transactional
    public CoLearnSessionDTO createSession(CreateCoLearnRequest request, Long parentId) {
        // 1. 校验家长-孩子关系
        validateParentChildRelation(parentId, request.getChildProfileId());
        
        // 2. 检查是否有进行中的会话
        Optional<CoLearnSession> activeSession = sessionRepo
            .findByChildProfileIdAndStatus(request.getChildProfileId(), 1);
        if (activeSession.isPresent()) {
            throw new BusinessException(ErrorCode.CO_LEARN_SESSION_ACTIVE);
        }
        
        // 3. 生成学习内容计划
        ContentPlan plan = contentPlanGenerator.generate(
            request.getSubject(),
            request.getContentType(),
            request.getDifficultyLevel(),
            request.getContentTag(),
            request.getChildProfileId()
        );
        
        // 4. 创建会话
        CoLearnSession session = new CoLearnSession();
        session.setId(idGenerator.nextId());
        session.setParentUserId(parentId);
        session.setChildUserId(getChildUserId(request.getChildProfileId()));
        session.setProfileId(request.getChildProfileId());
        session.setSubject(request.getSubject());
        session.setContentType(request.getContentType());
        session.setDifficultyLevel(request.getDifficultyLevel());
        session.setMaxDurationMin(request.getMaxDurationMin());
        session.setTotalItems(plan.getTotalItems());
        session.setStatus(0); // preparing
        
        sessionRepo.save(session);
        
        // 5. 缓存到 Redis
        redisTemplate.opsForValue().set(
            SESSION_KEY + session.getId(),
            JSON.toJSONString(session),
            Duration.ofHours(2)
        );
        
        return CoLearnSessionDTO.from(session, plan);
    }
    
    /**
     * 开始共学
     */
    @Transactional
    public CoLearnSessionDTO startSession(String sessionId, String deviceId) {
        CoLearnSession session = getAndValidate(sessionId);
        
        if (session.getStatus() != 0) {
            throw new BusinessException(ErrorCode.CO_LEARN_INVALID_STATUS);
        }
        
        session.setStatus(1); // inProgress
        session.setStartedAt(LocalDateTime.now());
        session.setDeviceId(deviceId);
        
        sessionRepo.save(session);
        
        // 注册超时定时器（Redis 键过期 + 定时任务双重保障）
        long expireAt = System.currentTimeMillis() + session.getMaxDurationMin() * 60 * 1000L;
        redisTemplate.opsForValue().set(
            TIMER_KEY + sessionId,
            String.valueOf(expireAt),
            Duration.ofMinutes(session.getMaxDurationMin() + 1)
        );
        
        // 发布事件
        eventPublisher.publishEvent(new CoLearnStartedEvent(session));
        
        return CoLearnSessionDTO.from(session);
    }
    
    /**
     * 记录互动事件
     */
    @Async
    public EventResponseDTO submitEvent(String sessionId, CoLearnEventDTO eventDTO) {
        // 1. 更新 Redis 中的实时状态
        String key = SESSION_KEY + sessionId;
        String json = redisTemplate.opsForValue().get(key);
        if (json == null) {
            log.warn("Session cache miss: {}", sessionId);
        }
        
        // 2. 异步写入事件表
        CoLearnEvent event = new CoLearnEvent();
        event.setSessionId(Long.parseLong(sessionId));
        event.setEventTime(LocalDateTime.now());
        event.setEventType(eventDTO.getEventType());
        event.setActor(eventDTO.getActor());
        event.setContentId(eventDTO.getContentId());
        event.setItemIndex(eventDTO.getItemIndex());
        event.setEventData(JSON.toJSONString(eventDTO.getEventData()));
        event.setElapsedSeconds(eventDTO.getElapsedSeconds());
        
        eventRepo.save(event);
        
        // 3. 返回自适应建议
        AdaptiveSuggestion suggestion = generateAdaptiveSuggestion(sessionId, eventDTO);
        
        return EventResponseDTO.builder()
            .sessionId(sessionId)
            .progress(getCurrentProgress(sessionId))
            .adaptiveSuggestion(suggestion)
            .build();
    }
    
    /**
     * 结束共学并生成报告
     */
    @Transactional
    public CoLearnEndDTO endSession(String sessionId, String endReason) {
        CoLearnSession session = getAndValidate(sessionId);
        
        if (session.getStatus() == 3) {
            throw new BusinessException(ErrorCode.CO_LEARN_ALREADY_ENDED);
        }
        
        LocalDateTime now = LocalDateTime.now();
        session.setStatus(3); // ended
        session.setEndedAt(now);
        session.setDurationSeconds(
            (int) Duration.between(session.getStartedAt(), now).getSeconds()
        );
        
        // 聚合统计数据
        aggregateSessionStats(session);
        sessionRepo.save(session);
        
        // 生成报告
        CoLearnReport report = generateReport(session);
        reportRepo.save(report);
        
        // 清理缓存
        redisTemplate.delete(SESSION_KEY + sessionId);
        redisTemplate.delete(TIMER_KEY + sessionId);
        
        // 发布事件 → 下游：学习记录、成就、推送
        eventPublisher.publishEvent(new CoLearnEndedEvent(session, report));
        
        return CoLearnEndDTO.from(session, report);
    }
    
    /**
     * 自适应建议生成
     */
    private AdaptiveSuggestion generateAdaptiveSuggestion(String sessionId, CoLearnEventDTO event) {
        if (!"child_answer".equals(event.getEventType())) {
            return AdaptiveSuggestion.noChange();
        }
        
        // 查询最近5次的作答情况
        List<CoLearnEvent> recentAnswers = eventRepo
            .findRecentAnswers(sessionId, 5);
        
        long correctCount = recentAnswers.stream()
            .filter(e -> {
                Map<String, Object> data = JSON.parseObject(e.getEventData());
                return Boolean.TRUE.equals(data.get("isCorrect"));
            }).count();
        
        double recentAccuracy = (double) correctCount / recentAnswers.size();
        
        // 连续正确 >= 3 → 建议提难度
        if (recentAnswers.size() >= 3 && isConsecutiveCorrect(recentAnswers, 3)) {
            return AdaptiveSuggestion.builder()
                .difficultyAdjustment(1)
                .message("孩子表现很好，建议提高一点难度")
                .build();
        }
        
        // 连续错误 >= 2 → 建议降难度
        if (recentAnswers.size() >= 2 && isConsecutiveWrong(recentAnswers, 2)) {
            return AdaptiveSuggestion.builder()
                .difficultyAdjustment(-1)
                .message("孩子遇到了困难，建议降低难度或给更多提示")
                .build();
        }
        
        return AdaptiveSuggestion.noChange();
    }
    
    /**
     * 生成学习报告
     */
    private CoLearnReport generateReport(CoLearnSession session) {
        CoLearnReport report = new CoLearnReport();
        report.setId(idGenerator.nextId());
        report.setSessionId(session.getId());
        report.setChildUserId(session.getChildUserId());
        report.setParentUserId(session.getParentUserId());
        
        // 正确率
        double accuracy = session.getTotalItems() > 0 
            ? (double) session.getCorrectCount() / session.getCompletedItems() 
            : 0;
        report.setAccuracy(BigDecimal.valueOf(accuracy * 100).setScale(2, RoundingMode.HALF_UP));
        
        // 参与度评分（基于：完成比例、互动频率、求助次数、家长参与度）
        double completionRatio = (double) session.getCompletedItems() / session.getTotalItems();
        double engagementScore = calculateEngagementScore(session, completionRatio);
        report.setEngagementScore(BigDecimal.valueOf(engagementScore));
        
        // 家长参与度评分
        double parentScore = calculateParentEngagementScore(session);
        report.setParentEngagementScore(BigDecimal.valueOf(parentScore));
        
        // 下次建议
        report.setNextSuggestion(JSON.toJSONString(generateNextSuggestion(session)));
        
        return report;
    }
    
    private Map<String, Object> generateNextSuggestion(CoLearnSession session) {
```

| 场景 | 触发条件 | 处理策略 | 用户感知 |
|------|----------|----------|----------|
| 网络断开 | 共学进行中网络丢失 | 本地继续，事件缓存到队列，恢复后批量上报 | Toast "网络已断开，可继续学习" |
| 设备来电 | 共学进行中收到电话 | 自动暂停，记录断点 | "学习已暂停" |
| 家长离开 | 家长退出APP/切后台 | 保持会话但暂停计时，10分钟后无操作自动结束 | "家长已离开，学习已暂停" |
| 超时强制结束 | 达到最大时长 | 展示结束动画，保存当前进度 | "今天学习时间到啦！" |
| 内容加载失败 | 学习项资源加载失败 | 跳过当前项，加载下一项 | 自动跳过，家长面板提示 |
| 服务端异常 | API调用失败 | 本地模式运行，使用预加载内容 | 无感知 |
| 孩子多次错误 | 连续错误 ≥ 3次 | 建议降低难度，超时30s未操作自动提示 | 提示"需要帮助吗？" |

### 8.2 离线模式

```dart
/// 离线事件队列
class OfflineEventQueue {
  final Box<CoLearnEvent> _eventBox;
  
  /// 缓存事件到本地
  Future<void> enqueue(CoLearnEvent event) async {
    await _eventBox.add(event);
  }
  
  /// 网络恢复后批量上报
  Future<void> flush(String sessionId, CoLearnRepository repository) async {
    final events = _eventBox.values.toList();
    if (events.isEmpty) return;
    
    try {
      await repository.batchSubmitEvents(sessionId, events);
      await _eventBox.clear();
    } catch (e) {
      log.warning('Flush events failed: $e');
      // 保留队列，下次重试
    }
  }
}
```

```dart
/// 家长身份验证门卫
Future<bool> verifyParentIdentity(BuildContext context) async {
  // 1. 检查是否已设置家长验证方式
  final parentAuth = ref.read(parentAuthProvider);
  
  if (parentAuth.method == ParentAuthMethod.pin) {
    // PIN码验证
    final pin = await _showPinDialog(context);
    return parentAuth.verifyPin(pin);
  } else if (parentAuth.method == ParentAuthMethod.biometric) {
    // 生物识别
    return await LocalAuthentication().authenticate(
      localizedReason: '请验证家长身份以进入共学模式',
    );
  }
  
  return false;
}
```
