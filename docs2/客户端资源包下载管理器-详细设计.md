## 1. 模块概述

### 1.1 功能定位

客户端资源包下载管理器（Resource Package Download Manager，简称 RPDM）是 PrimeTop 客户端的基础设施组件，负责管理所有离线内容资源包的全生命周期：发现、下载、校验、解压、存储、更新、清理。

**一句话定位**：为客户端提供统一的资源包下载、更新与存储管理能力，确保离线学习内容的可靠获取和高效管理。

### 1.3 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 资源包版本检查 | 启动时/定期检查可用更新 | P0 |
| 优先级下载队列 | 按优先级和用户行为调度下载 | P0 |
| 断点续传 | 网络中断后自动恢复 | P0 |
| 完整性校验 | MD5/SHA-256 校验防篡改 | P0 |
| 增量更新 | 差分包下载减少流量消耗 | P1 |
| 后台下载 | APP 后台/锁屏时继续下载 | P1 |
| 网络策略 | WiFi 优先、蜂窝限速、离线跳过 | P0 |
| 存储空间管理 | 自动清理、LRU 淘汰、空间预警 | P1 |
| 预下载 | 预测用户行为提前下载 | P2 |

### 1.4 设计原则

1. **不阻塞用户**：下载在后台静默进行，不影响前台学习体验
2. **流量友好**：默认 WiFi 环境下载大包，蜂窝网络需用户确认
3. **渐进可用**：下载完成后立即可用，不需重启 APP
4. **安全可靠**：校验不通过的包绝不使用，保留上一版本
5. **存储可控**：本地缓存总量有上限，超出自动淘汰最久未用内容

## 4. 下载调度引擎

### 4.1 调度策略

```typescript
class DownloadScheduler {
  final _queue = PriorityQueue<DownloadTask>(
    comparator: (a, b) {
      // 1. 按优先级排序（CRITICAL > HIGH > NORMAL > LOW）
      final priCmp = a.priority.index.compareTo(b.priority.index);
      if (priCmp != 0) return priCmp;
      // 2. 同优先级按触发时间排序（FIFO）
      return a.createdAt.compareTo(b.createdAt);
    },
  );

  /// 最大并发下载数
  static const maxConcurrent = 3;

  /// 当前活跃下载数
  int _activeCount = 0;

  /// 入队新任务
  Future<void> enqueue(DownloadTask task) async {
    // 检查去重
    if (_queue.any((t) => t.packageId == task.packageId)) {
      // 已有同包任务：取优先级更高的
      _mergeTask(task);
      return;
    }
    _queue.add(task);
    await _persistQueue();
    _scheduleNext();
  }

  /// 调度下一个任务
  void _scheduleNext() {
    while (_activeCount < maxConcurrent && _queue.isNotEmpty) {
      final task = _queue.removeFirst();

      // 网络策略检查
      if (!_checkNetworkPolicy(task)) {
        // 不满足网络条件，放回队列并暂停
        task.status = DownloadTaskStatus.WAITING_WIFI;
        _persistTask(task);
        continue;
      }

      // 存储空间检查
      if (!_checkStorageSpace(task.totalSize)) {
        task.status = DownloadTaskStatus.FAILED;
        task.lastError = 'INSUFFICIENT_STORAGE';
        _persistTask(task);
        _notifyFailure(task, '存储空间不足');
        continue;
      }

      // 启动下载
      _activeCount++;
      _executeDownload(task);
    }
  }
}
```

### 4.2 网络策略引擎

```typescript
class NetworkPolicyEngine {
  final ConnectivityService _connectivity;

  /// 检查任务是否满足当前网络条件
  bool shouldAllowDownload(DownloadTask task) {
    final networkType = _connectivity.currentType;

    switch (task.priority) {
      case DownloadPriority.CRITICAL:
        // 关键包：任何网络都允许（但蜂窝限速）
        return true;

      case DownloadPriority.HIGH:
        // 高优先级：WiFi 直接允许，蜂窝需检查大小
        if (networkType == NetworkType.wifi) return true;
        if (networkType == NetworkType.cellular) {
          return task.totalSize <= _cellularSizeLimit; // 默认 20MB
        }
        return false; // 无网

      case DownloadPriority.NORMAL:
      case DownloadPriority.LOW:
      case DownloadPriority.BACKGROUND:
        // 常规/低/后台：仅 WiFi
        return networkType == NetworkType.wifi;
    }
  }

  /// 蜂窝网络下载大小限制（可配置）
  int _cellularSizeLimit = 20 * 1024 * 1024; // 20MB

  /// 更新蜂窝网络限制（设置页可调）
  void updateCellularLimit(int bytes) {
    _cellularSizeLimit = bytes;
  }
}
```

### 4.3 断点续传机制

```typescript
class ResumableDownloader {
  /// 下载文件（支持断点续传）
  Future<void> download({
    required String url,
    required String savePath,
    required String expectedChecksum,
    int? startOffset,  // 断点偏移量
    Function(int downloaded, int total)? onProgress,
    CancellationToken? cancellationToken,
  }) async {
    final file = File(savePath);
    final raf = await file.open(mode: FileMode.append);

    try {
      // 构建 Range 请求头
      final headers = <String, String>{};
      int currentOffset = 0;

      if (startOffset != null && startOffset > 0 && await file.exists()) {
        currentOffset = startOffset;
        headers['Range'] = 'bytes=$startOffset-';
      }

      // 发起请求
      final response = await _httpClient.get(
        Uri.parse(url),
        headers: headers,
      );

      final totalSize = response.headers.value('content-length') != null
          ? int.parse(response.headers.value('content-length')!)
          : null;

      // 流式写入文件
      await for (final chunk in response.stream) {
        if (cancellationToken?.isCancelled ?? false) {
          throw DownloadCancelledException();
        }
        await raf.writeFrom(chunk);
        currentOffset += chunk.length;
        onProgress?.call(currentOffset, totalSize ?? 0);
      }
    } finally {
      await raf.close();
    }
  }

  /// 读取已下载进度（用于恢复）
  Future<int?> getDownloadedOffset(String tempFilePath) async {
    final file = File(tempFilePath);
    if (!await file.exists()) return null;
    return await file.length();
  }
}
```

### 5.1 完整性校验

```typescript
class PackageVerifier {
  /// 校验资源包
  Future<VerifyResult> verify({
    required String filePath,
    required String expectedChecksum,
    required String algorithm,
  }) async {
    final file = File(filePath);
    if (!await file.exists()) {
      return VerifyResult.notFound;
    }

    try {
      String actualHash;
      switch (algorithm) {
        case 'md5':
          actualHash = await _computeMd5(file);
          break;
        case 'sha256':
          actualHash = await _computeSha256(file);
          break;
        default:
          return VerifyResult.unsupportedAlgorithm;
      }

      // 去掉算法前缀后比较（服务端格式："sha256:a1b2c3..."）
      final expected = expectedChecksum.split(':').last;
      return actualHash.toLowerCase() == expected.toLowerCase()
          ? VerifyResult.valid
          : VerifyResult.checksumMismatch;
    } catch (e) {
      return VerifyResult.error;
    }
  }

  Future<String> _computeSha256(File file) async {
    final digest = await sha256.bind(file.openRead()).first;
    return digest.toString();
  }

  Future<String> _computeMd5(File file) async {
    final digest = await md5.bind(file.openRead()).first;
    return digest.toString();
  }
}

enum VerifyResult {
  valid,
  checksumMismatch,
  notFound,
  unsupportedAlgorithm,
  error,
}
```

### 5.2 解压与安装流程

```typescript
class PackageInstaller {
  final PackageRegistry _registry;
  final StorageManager _storage;

  /// 安装资源包
  Future<InstalledPackage> install({
    required String archivePath,
    required PackageManifest manifest,
  }) async {
    final installDir = _getInstallDir(manifest.packageId);

    // 1. 如果已有旧版本，先备份
    final existing = await _registry.getInstalled(manifest.packageId);
    String? backupPath;
    if (existing != null && existing.status == InstalledPackageStatus.READY) {
      backupPath = '${existing.installPath}.bak';
      await _moveDirectory(existing.installPath, backupPath);
    }

    try {
      // 2. 清理目标目录
      if (await Directory(installDir).exists()) {
        await Directory(installDir).delete(recursive: true);
      }
      await Directory(installDir).create(recursive: true);

      // 3. 解压
      await _extractArchive(archivePath, installDir);

      // 4. 验证解压内容（检查 manifest 文件）
      await _validateExtractedContent(installDir, manifest);

      // 5. 计算磁盘占用
      final diskUsage = await _calculateDirectorySize(installDir);

      // 6. 注册到本地数据库
      final installed = InstalledPackage(
        packageId: manifest.packageId,
        version: manifest.version,
        versionCode: manifest.versionCode,
        installPath: installDir,
        installedAt: DateTime.now(),
        checksum: manifest.checksum,
        diskUsage: diskUsage,
        lastAccessedAt: DateTime.now(),
        source: _determineSource(manifest),
        status: InstalledPackageStatus.READY,
      );
      await _registry.register(installed);

      // 7. 删除临时下载文件
      await File(archivePath).delete();

      // 8. 删除旧版本备份
      if (backupPath != null) {
        await _safeDeleteDirectory(backupPath);
      }

      // 9. 通知各模块资源包已更新
      _notifyPackageReady(installed);

      return installed;
    } catch (e) {
      // 安装失败：回滚到旧版本
      if (backupPath != null) {
        await _restoreBackup(backupPath, installDir);
      }
      rethrow;
    }
  }

  /// 获取安装目录路径
  String _getInstallDir(String packageId) {
    // 使用 sanitized packageId 作为子目录名
    final safeId = packageId.replaceAll(RegExp(r'[^a-zA-Z0-9_\-]'), '_');
    return '${_storage.packagesRoot}/$safeId';
  }
}
```

```typescript
  final List<PackageAware> _listeners = [];

  Stream<PackageEvent> get stream => _controller.stream;

  void registerListener(PackageAware listener) {
    _listeners.add(listener);
  }

  void emit(PackageEvent event) {
    _controller.add(event);
    for (final listener in _listeners) {
      // 异步通知，不阻塞主流程
      Future.microtask(() => listener.onPackageChanged(event));
    }
  }
```

## 6. 增量更新机制

### 6.1 差分更新流程

```
服务端生成差分包 (bsdiff)：
  旧版本 V1.0 + 新版本 V1.1 → delta.patch (约 10-30% 原包大小)

客户端更新流程：
  1. 检查到新版本 V1.1
  2. 发现存在差分包 (V1.0 → V1.1)
  3. 下载差分包（远小于完整包）
  4. 本地合成：old_package + delta.patch → new_package
  5. 校验新包 checksum
  6. 安装新版本
```

### 6.2 差分合成实现

```typescript
class DeltaPatcher {
  /// 应用差分包
  ///
  /// 注意：Flutter 端通过 FFI 调用原生 bspatch 实现
  /// Android: bsdiff/bspatch native library
  /// iOS: 通过 CocoaPods 集成 bsdiff
  Future<File> applyPatch({
    required File oldFile,
    required File patchFile,
    required String outputPath,
    String algorithm = 'bsdiff',
  }) async {
    switch (algorithm) {
      case 'bsdiff':
        // FFI 调用原生 bspatch
        final result = await BsdiffNative.applyPatch(
          oldPath: oldFile.path,
          patchPath: patchFile.path,
          outputPath: outputPath,
        );
        if (result != 0) {
          throw DeltaPatchException('bspatch failed with code $result');
        }
        return File(outputPath);

      case 'custom':
        // 自定义差分格式（JSON diff 等）
        return await _applyCustomPatch(oldFile, patchFile, outputPath);

      default:
        throw DeltaPatchException('Unsupported algorithm: $algorithm');
    }
  }

  /// 决策：使用差分包还是完整包
  DownloadPlan decideDownloadStrategy({
    required PackageManifest manifest,
    required InstalledPackage? installed,
  }) {
    // 没有已安装版本 → 必须完整包
    if (installed == null) {
      return DownloadPlan.fullDownload(manifest);
    }

    // 有差分包可用
    final delta = manifest.deltaPatch;
    if (delta != null && delta.fromVersionCode == installed.versionCode) {
      // 差分包小于完整包 50% 时才使用差分
      if (delta.patchSize < manifest.size * 0.5) {
        return DownloadPlan.deltaPatch(manifest, delta);
      }
    }

    // 退回完整包下载
    return DownloadPlan.fullDownload(manifest);
  }
}

class DownloadPlan {
  final bool isDelta;
  final String downloadUrl;
  final int downloadSize;
  final String expectedChecksum;
  final DeltaPatch? deltaPatch;

  DownloadPlan.fullDownload(PackageManifest m)
      : isDelta = false,
        downloadUrl = m.downloadUrl,
        downloadSize = m.size,
        expectedChecksum = m.checksum,
        deltaPatch = null;

  DownloadPlan.deltaPatch(PackageManifest m, DeltaPatch d)
      : isDelta = true,
        downloadUrl = d.patchUrl,
        downloadSize = d.patchSize,
        expectedChecksum = d.patchChecksum,
        deltaPatch = d;
}
```

```typescript
class StorageQuotaManager {
  /// 全局缓存配额（默认 2GB）
  int globalQuotaBytes = 2 * 1024 * 1024 * 1024;

  /// 各类型包的保留策略
  final Map<PackageType, RetentionPolicy> retentionPolicies = {
    PackageType.TEXTBOOK_CHAPTER: RetentionPolicy(
      maxAge: Duration(days: 365),     // 1 年内访问过的保留
      minKeep: 3,                       // 至少保留最近 3 个章节
      canEvict: true,
    ),
    PackageType.QUESTION_BANK: RetentionPolicy(
      maxAge: Duration(days: 180),
      minKeep: 1,                       // 至少保留 1 个题库
      canEvict: true,
    ),
    PackageType.TOOL_DATA: RetentionPolicy(
      maxAge: null,                     // 工具数据不淘汰
      minKeep: null,
      canEvict: false,                  // 工具数据永久保留（体积小）
    ),
    PackageType.PRACTICE_PACK: RetentionPolicy(
      maxAge: Duration(days: 30),
      minKeep: 0,
      canEvict: true,
    ),
    PackageType.COURSE_MEDIA: RetentionPolicy(
      maxAge: Duration(days: 14),
      minKeep: 0,
      canEvict: true,                   // 视频优先淘汰
    ),
    PackageType.VOICE_ASSET: RetentionPolicy(
      maxAge: Duration(days: 90),
      minKeep: 1,
      canEvict: true,
    ),
  };

  /// 执行空间回收
  Future<int> performEviction({int? targetFreeBytes}) async {
    final usage = await _calculateTotalUsage();

    // 如果未超限，不执行回收
    if (usage.totalUsed < globalQuotaBytes * 0.85) {
      return 0;
    }

    int freedBytes = 0;
    final target = targetFreeBytes ?? (globalQuotaBytes * 0.2).toInt();

    // 按淘汰优先级排序已安装包
    final candidates = await _getEvictionCandidates();

    for (final pkg in candidates) {
      final policy = retentionPolicies[_getPackageType(pkg.packageId)];
      if (policy?.canEvict != true) continue;
      if (_isProtected(pkg, policy!)) continue;

      // 淘汰此包
      await _removePackage(pkg);
      freedBytes += pkg.diskUsage;

      if (freedBytes >= target) break;
    }

    return freedBytes;
  }

  /// 淘汰候选拆序：按 (最后访问时间升序, 磁盘占用降序) 排序
  Future<List<InstalledPackage>> _getEvictionCandidates() async {
    final packages = await _registry.getAllInstalled();
    packages.sort((a, b) {
      // 优先淘汰最久未用的
      final accessCmp = a.lastAccessedAt.compareTo(b.lastAccessedAt);
      if (accessCmp != 0) return accessCmp;
      // 同样久未用的，优先淘汰大的
      return b.diskUsage.compareTo(a.diskUsage);
    });
    return packages;
  }
}
```

```dart
// lib/services/download/package_download_service.dart

class PackageDownloadService implements PackageAware {
  final DownloadScheduler _scheduler;
  final PackageRegistry _registry;
  final PackageInstaller _installer;
  final StorageQuotaManager _storageQuota;
  final NetworkPolicyEngine _networkPolicy;
  final PackageEventBus _eventBus;
  final ApiClient _apiClient;

  PackageDownloadService({
    required DownloadScheduler scheduler,
    required PackageRegistry registry,
    required PackageInstaller installer,
    required StorageQuotaManager storageQuota,
    required NetworkPolicyEngine networkPolicy,
    required PackageEventBus eventBus,
    required ApiClient apiClient,
  })  : _scheduler = scheduler,
        _registry = registry,
        _installer = installer,
        _storageQuota = storageQuota,
        _networkPolicy = networkPolicy,
        _eventBus = eventBus,
        _apiClient = apiClient;

  /// 初始化：启动时检查更新
  Future<void> initialize() async {
    // 1. 恢复上次未完成的下载任务
    await _restorePendingTasks();

    // 2. 检查是否有已下载但未安装的包
    await _installPendingPackages();

    // 3. 执行存储空间回收
    await _storageQuota.performEviction();

    // 4. 检查更新（静默，不阻塞启动）
    _checkUpdatesSilently();
  }

  /// 静默检查更新
  Future<void> _checkUpdatesSilently() async {
    try {
      final installed = await _registry.getAllInstalled();
      final installedVersions = {
        for (final p in installed) p.packageId: p.version,
      };

      final manifests = await _apiClient.get(
        '/api/v1/packages/manifests',
        queryParameters: {
          'installed_versions': jsonEncode(installedVersions),
          'app_version': await _getAppVersion(),
          'stage': _getCurrentStage(),
        },
      );

      final available = (manifests['data']['available'] as List)
          .cast<Map<String, dynamic>>();

      for (final manifestJson in available) {
        final manifest = PackageManifest.fromJson(manifestJson);
        final installed = await _registry.getInstalled(manifest.packageId);

        if (installed == null || installed.versionCode < manifest.versionCode) {
          // 需要下载
          _scheduleDownload(manifest, DownloadTrigger.AUTO_UPDATE);
        }
      }

      // 处理强制更新
      final required = manifests['data']['requiredUpdates'] as List?;
      if (required != null) {
        for (final req in required) {
          _eventBus.emit(PackageEvent(
            packageId: req['packageId'],
            type: PackageEventType.corrupted,
            version: null,
            timestamp: DateTime.now(),
          ));
        }
      }
    } catch (e) {
      // 静默检查失败不影响启动
      debugPrint('Package update check failed: $e');
    }
  }

  /// 调度下载
  void _scheduleDownload(PackageManifest manifest, DownloadTrigger trigger) {
    final priority = _determinePriority(manifest, trigger);

    final task = DownloadTask(
      taskId: const Uuid().v4(),
      packageId: manifest.packageId,
      targetVersion: manifest.version,
      targetVersionCode: manifest.versionCode,
      status: DownloadTaskStatus.IDLE,
      priority: priority,
      trigger: trigger,
      downloadUrl: manifest.downloadUrl,
      totalSize: manifest.size,
      downloadedSize: 0,
      expectedChecksum: manifest.checksum,
      tempFilePath: _getTempFilePath(manifest.packageId),
      retryCount: 0,
      maxRetries: 3,
      deltaPatch: manifest.deltaPatch,
      createdAt: DateTime.now(),
      updatedAt: DateTime.now(),
    );

    _scheduler.enqueue(task);
  }

  /// 执行下载
  Future<void> _executeDownload(DownloadTask task) async {
    try {
      task.status = DownloadTaskStatus.DOWNLOADING;
      task.startedAt ??= DateTime.now();
      _persistTask(task);

      // 1. 下载
      final archivePath = task.tempFilePath;
      await _downloader.download(
        url: task.downloadUrl,
        savePath: archivePath,
        expectedChecksum: task.expectedChecksum,
        startOffset: task.downloadedSize > 0 ? task.downloadedSize : null,
        onProgress: (downloaded, total) {
          task.downloadedSize = downloaded;
          _notifyProgress(task, downloaded, total);
        },
        cancellationToken: _getCancellationToken(task.taskId),
      );

      // 2. 校验
      task.status = DownloadTaskStatus.VERIFYING;
      _persistTask(task);

      final verifyResult = await _verifier.verify(
        filePath: archivePath,
        expectedChecksum: task.expectedChecksum,
        algorithm: 'sha256',
      );

      if (verifyResult != VerifyResult.valid) {
        throw VerifyException('Checksum mismatch: $verifyResult');
      }

      // 3. 如果是差分包，先合成
      String finalArchivePath = archivePath;
      if (task.deltaPatch != null) {
        final oldPkg = await _registry.getInstalled(task.packageId);
        if (oldPkg == null) {
          throw DeltaPatchException('No old package for delta patching');
        }
        final outputPath = '${archivePath}.patched';
        await _patcher.applyPatch(
          oldFile: File(_getArchivePath(oldPkg)),
          patchFile: File(archivePath),
          outputPath: outputPath,
          algorithm: task.deltaPatch!.algorithm,
        );
        finalArchivePath = outputPath;
      }

      // 4. 解压与安装
      task.status = DownloadTaskStatus.INSTALLING;
      _persistTask(task);

      final manifest = await _getManifest(task.packageId);
      await _installer.install(
        archivePath: finalArchivePath,
        manifest: manifest,
      );

      // 5. 完成
      task.status = DownloadTaskStatus.COMPLETED;
      task.completedAt = DateTime.now();
      _persistTask(task);

      _notifyCompletion(task);
    } catch (e) {
      task.retryCount++;
      task.lastError = e.toString();

      if (task.retryCount >= task.maxRetries) {
        task.status = DownloadTaskStatus.ABANDONED;
        _notifyFailure(task, '超过最大重试次数');
      } else {
        task.status = DownloadTaskStatus.FAILED;
        // 退避重试：指数退避 5s → 30s → 120s
        final delay = Duration(seconds: 5 * pow(2, task.retryCount - 1).toInt());
        Future.delayed(delay, () {
          task.status = DownloadTaskStatus.IDLE;
          _scheduler.enqueue(task);
        });
      }
      _persistTask(task);
    }
  }
}
```

```dart
// 各模块使用资源包数据的标准方式
class SomeModuleService {
  final PackageRegistry _registry;

  /// 读取资源包数据
  Future<PackageData?> loadPackageData(String packageId) async {
    // 1. 检查包是否已安装
    final installed = await _registry.getInstalled(packageId);
    if (installed == null || installed.status != InstalledPackageStatus.READY) {
      return null; // 或抛异常
    }

    // 2. 更新最后访问时间（用于 LRU 淘汰）
    await _registry.touchAccess(packageId);

    // 3. 读取包内数据文件
    final dataFile = File('${installed.installPath}/data.json');
    if (!await dataFile.exists()) {
      return null;
    }

    return PackageData.fromJson(
      jsonDecode(await dataFile.readAsString()),
    );
  }
}
```

## 15. 安全考量

1. **校验防篡改**：所有资源包必须通过 SHA-256 校验，防止 CDN 劫持或中间人注入恶意内容
2. **HTTPS 传输**：下载 URL 必须使用 HTTPS
3. **路径安全**：解压时防止 ZIP 炸弹和路径遍历攻击（`../../` 类路径）
4. **内置降级数据**：APP 安装包内嵌最小化基础数据，确保首次安装即有可用内容
5. **签名校验（P2）**：重要包可增加非对称签名校验，防止客户端被 hook 后替换本地数据

### 15.1 ZIP 炸弹防护

```dart
class SafeExtractor {
  static const maxExtractedSize = 500 * 1024 * 1024; // 500MB
  static const maxFileCount = 10000;
  static const maxSingleFileSize = 100 * 1024 * 1024; // 100MB

  Future<void> extractSafely(String archivePath, String targetDir) async {
    int totalExtracted = 0;
    int fileCount = 0;

    await for (final entry in _readArchive(archivePath)) {
      // 检查路径遍历
      final outputPath = _safeJoinPath(targetDir, entry.name);
      if (!outputPath.startsWith(targetDir)) {
        throw SecurityException('Path traversal detected: ${entry.name}');
      }

      // 检查单文件大小
      if (entry.size > maxSingleFileSize) {
        throw SecurityException('File too large: ${entry.name}');
      }

      // 检查累计大小
      totalExtracted += entry.size;
      if (totalExtracted > maxExtractedSize) {
        throw SecurityException('Archive exceeds size limit');
      }

      // 检查文件数量
      fileCount++;
      if (fileCount > maxFileCount) {
        throw SecurityException('Too many files in archive');
      }

      await entry.extractTo(outputPath);
    }
  }
}
```
