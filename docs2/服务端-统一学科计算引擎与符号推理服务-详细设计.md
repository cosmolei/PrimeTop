# 服务端-统一学科计算引擎与符号推理服务 详细设计

## 1. 概述

### 1.1 模块定位

统一学科计算引擎（Subject Compute Engine, 简称 SCE）是 PrimeTop 平台的**底层学科计算基础设施**，为 AI 辅导、练习批改、题目生成、知识图谱、虚拟实验等上层业务提供统一的数学/物理/化学计算能力。

SCE 是一个**无状态计算服务**，不直接面向用户，而是通过内部 RPC/HTTP 接口为其他业务服务提供：
- 数学表达式解析（LaTeX / MathML / 纯文本 → AST）
- 符号计算（化简、展开、因式分解）
- 方程与方程组求解
- 微积分运算（求导、积分、极限、级数展开）
- 线性代数运算（矩阵、行列式、向量）
- 概率统计计算
- 物理公式计算与单位换算
- 化学方程式配平与计量计算
- 分步解题过程生成

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| **表达式解析** | 将 LaTeX / MathML / 纯文本数学表达式解析为统一的内部 AST 表示 |
| **符号计算** | 对数学表达式进行代数变换：化简、展开、因式分解、合并同类项 |
| **方程求解** | 求解代数方程、方程组、不等式，输出精确解或数值近似解 |
| **微积分** | 求导（偏导）、不定积分、定积分、极限、泰勒展开 |
| **线性代数** | 矩阵运算、行列式、特征值、线性方程组求解 |
| **统计计算** | 均值、方差、标准差、回归、排列组合、概率分布 |
| **物理计算** | 物理公式代入计算、单位制转换、量纲分析 |
| **化学计算** | 化学方程式配平、摩尔质量计算、浓度计算、化学计量 |
| **分步生成** | 为计算过程生成分步推理链，用于 AI 辅导展示 |
| **等价验证** | 判断两个数学表达式是否数学等价（学生答案 vs 标准答案） |
| **表达式渲染** | 将内部 AST 转换为 LaTeX / MathML / 纯文本输出 |

```
└───────────────┘               └─────────────────────┘
```

**上游依赖（被调用方）：**
- AI 辅导对话引擎：需要 SCE 验证 AI 生成的数学计算
- 拍照搜题与题目批改：需要 SCE 判断学生答案等价性
- 题目智能生成引擎：需要 SCE 生成有已知解的题目
- 理科解题步骤推导引擎：需要 SCE 提供分步计算
- 虚拟实验模拟服务：需要 SCE 进行物理/化学参数计算
- 客户端数学函数图形绘制：需要 SCE 提供函数采样数据
- 数学证明题逻辑推理链构建引擎：需要 SCE 验证推导步骤

**下游依赖（依赖方）：**
- SymPy：Python 符号计算核心库
- Redis：计算结果缓存
- NumPy/SciPy：数值计算补充（矩阵、统计）

### 1.4 设计原则

1. **无状态**：所有计算节点对等，支持水平扩展
2. **幂等缓存**：相同表达式 + 操作 = 相同结果，支持 Redis 缓存
3. **超时保护**：每个计算操作设置最大执行时间，防止恶意输入
4. **优雅降级**：精确解不可得时，回退到数值近似解
5. **安全隔离**：计算在受限沙箱中执行，防止资源耗尽
6. **多语言适配**：核心 CAS 基于 SymPy (Python)，通过 gRPC 服务化供 Java/Go 调用

## 2. 数据模型

### 2.1 核心实体

#### 2.1.1 数学表达式 AST 节点（MathNode）

```typescript
/**
 * 数学表达式 AST 统一节点定义
 * 所有解析器（LaTeX / MathML / 纯文本）输出此结构
 */
interface MathNode {
  /** 节点唯一ID（在单次解析中唯一） */
  id: string;
  
  /** 节点类型 */
  type: MathNodeType;
  
  /** 节点值（根据 type 含义不同） */
  value?: string | number;
  
  /** 子节点 */
  children?: MathNode[];
  
  /** 属性（上下标、符号修饰等） */
  attributes?: {
    superscript?: MathNode;    // 上标
    subscript?: MathNode;      // 下标
    prime?: number;            // 撇号 (', '')
    accent?: 'hat' | 'vec' | 'bar' | 'dot' | 'tilde';
  };
}

enum MathNodeType {
  NUMBER = 'number',           // 数字: 3, 3.14, 1/2
  SYMBOL = 'symbol',           // 变量/常量: x, π, e
  OPERATOR = 'operator',       // 运算符: +, -, *, /, ^
  FUNCTION = 'function',       // 函数: sin, cos, log, sqrt
  PARENTHESIS = 'parenthesis', // 括号
  FRACTION = 'fraction',       // 分式
  SQRT = 'sqrt',              // 根号
  POWER = 'power',            // 幂
  INTEGRAL = 'integral',      // 积分
  SUMMATION = 'summation',    // 求和
  LIMIT = 'limit',            // 极限
  MATRIX = 'matrix',          // 矩阵
  PIECEWISE = 'piecewise',    // 分段函数
  DIFFERENTIAL = 'differential', // 微分
  TEXT = 'text',              // 文本标注
}
```

#### 2.1.2 计算请求（ComputeRequest）

```typescript
interface ComputeRequest {
  /** 请求唯一ID */
  requestId: string;
  
  /** 调用方服务标识 */
  callerService: string;
  
  /** 操作类型 */
  operation: ComputeOperation;
  
  /** 输入表达式列表 */
  expressions: ExpressionInput[];
  
  /** 操作参数 */
  params?: ComputeParams;
  
  /** 学生上下文（用于适龄化分步展示） */
  studentContext?: {
    gradeLevel: 'elementary' | 'middle' | 'high';
    subject: string;
    textbookVersion?: string;
  };
  
  /** 超时时间（毫秒），默认 5000 */
  timeoutMs?: number;
}

interface ExpressionInput {
  /** 输入格式 */
  format: 'latex' | 'mathml' | 'plaintext' | 'ast';
  /** 表达式内容 */
  content: string;
  /** 表达式中的变量定义（可选） */
  variables?: Record<string, number>;
}

enum ComputeOperation {
  PARSE = 'parse',                  // 仅解析为 AST
  EVALUATE = 'evaluate',            // 数值计算
  SIMPLIFY = 'simplify',            // 化简
  EXPAND = 'expand',                // 展开
  FACTOR = 'factor',                // 因式分解
  SOLVE = 'solve',                  // 解方程
  SOLVE_SYSTEM = 'solve_system',    // 解方程组
  DIFFERENTIATE = 'differentiate',  // 求导
  INTEGRATE = 'integrate',          // 积分
  LIMIT = 'limit',                  // 极限
  SERIES = 'series',                // 级数展开
  MATRIX_OP = 'matrix_op',          // 矩阵运算
  VERIFY_EQUIVALENCE = 'verify',    // 等价验证
  BALANCE_CHEMICAL = 'balance_chemical', // 化学方程式配平
  PHYSICS_CALC = 'physics_calc',    // 物理公式计算
  UNIT_CONVERT = 'unit_convert',    // 单位换算
  STATISTICS = 'statistics',        // 统计计算
  GENERATE_STEPS = 'generate_steps', // 生成分步解题过程
  PLOT_DATA = 'plot_data',          // 生成绘图采样数据
}

interface ComputeParams {
  /** 求解变量（解方程/求导时使用） */
  variable?: string;
  /** 积分上下限 */
  lowerBound?: string;
  upperBound?: string;
  /** 极限趋近点 */
  approach?: string;
  /** 矩阵运算类型 */
  matrixOperation?: 'determinant' | 'inverse' | 'transpose' | 'eigenvalues' | 'multiply' | 'add' | 'solve';
  /** 统计运算类型 */
  statsOperation?: 'mean' | 'median' | 'std' | 'variance' | 'correlation' | 'regression';
  /** 精度要求 */
  precision?: number;
  /** 是否需要分步过程 */
  withSteps?: boolean;
  /** 绘图参数 */
  plotRange?: { xMin: number; xMax: number; yMin?: number; yMax?: number; samples?: number };
}
```

#### 2.1.3 计算结果（ComputeResult）

```typescript
interface ComputeResult {
  /** 请求ID */
  requestId: string;
  
  /** 执行状态 */
  status: 'success' | 'partial' | 'failed' | 'timeout';
  
  /** 结果类型 */
  resultType: 'exact' | 'numeric' | 'symbolic' | 'steps' | 'boolean' | 'plot_data' | 'chemical';
  
  /** 主要结果（LaTeX 格式） */
  result: string;
  
  /** 结果的纯文本表示 */
  resultPlainText?: string;
  
  /** 结果的 AST（供程序化使用） */
  resultAST?: MathNode;
  
  /** 数值结果（如适用） */
  numericValue?: number | number[];
  
  /** 分步过程（如请求或默认启用） */
  steps?: SolutionStep[];
  
  /** 等价验证结果 */
  equivalent?: boolean;
  
  /** 化学计算结果 */
  chemicalResult?: {
    balanced: boolean;
    coefficients?: Record<string, number>;
    reactants?: string[];
    products?: string[];
  };
  
  /** 绘图采样数据 */
  plotData?: {
    xValues: number[];
    yValues: number[];
    label: string;
  }[];
  
  /** 警告信息 */
  warnings?: ComputeWarning[];
  
  /** 计算耗时（毫秒） */
  durationMs: number;
  
  /** 缓存命中标记 */
  fromCache: boolean;
}

interface SolutionStep {
  /** 步骤序号 */
  stepNumber: number;
  
  /** 步骤标题 */
  title: string;
  
  /** 该步骤的输入表达式（LaTeX） */
  inputExpression: string;
  
  /** 该步骤的输出表达式（LaTeX） */
  outputExpression: string;
  
  /** 操作描述（自然语言） */
  description: string;
  
  /** 使用的规则/公式 */
  ruleApplied?: string;
  
  /** 适龄化提示 */
  hint?: string;
}

interface ComputeWarning {
  code: string;
  message: string;
  severity: 'info' | 'warning' | 'error';
}
```

### 2.2 数据库表结构

SCE 是无状态计算服务，**不直接管理业务数据库表**。但以下缓存表存储在 Redis 中：

#### 2.2.1 表达式缓存（Redis Hash）

```redis

# Type: Hash

  "params":         "{}",

  "steps":          "步骤 JSON",
  "createdAt":      "2026-07-16T11:00:00Z",
  "ttl":            "86400"
}
```

### 2.3 缓存策略

| 缓存类型 | Key 设计 | TTL | 淘汰策略 |
|----------|---------|-----|---------|
| 表达式计算结果 | `sce:cache:expr:{sha256}` | 24h | LRU, 最大 100万条 |
| 公式库 | `sce:formula:{subject}:{grade}:{id}` | 7d | 定时全量刷新 |
| 化学物质 | `sce:chem:substance:{formula}` | 30d | 定时全量刷新 |
| 单位换算表 | `sce:unit:{category}:{from}_to_{to}` | 永久 | 版本更新时刷新 |

**缓存命中率优化**：
- 表达式归一化：在计算 SHA256 前，对表达式做标准化（排序、去空格、统一变量名）
- 常见表达式预计算：系统启动时预热小学/初中高频计算（加减乘除、一元二次方程等）

#### 4.1.3 等价验证算法

等价验证是 SCE 最核心的高频操作（每次学生提交答案都需要调用），采用**三级验证策略**：

```
Level 1: 字符串精确匹配（快速）
    │ 不匹配
    ▼
Level 2: AST 结构比较（中等）
    │ 不匹配
    ▼
Level 3: 符号计算验证（准确但较慢）
    ├── 计算差式 expr1 - expr2
    ├── 化简结果
    └── 结果为零 → 等价
```

```python
def verify_equivalence(expr1_latex: str, expr2_latex: str, 
                       variable: str = 'x', precision: int = 10) -> bool:
    """
    三级等价验证
    """
    # Level 1: 字符串级
    if normalize_latex(expr1_latex) == normalize_latex(expr2_latex):
        return True
    
    # 解析为 SymPy 表达式
    expr1 = latex_to_sympy(expr1_latex)
    expr2 = latex_to_sympy(expr2_latex)
    
    # Level 2: SymPy 精确比较
    try:
        if sympy.simplify(expr1 - expr2) == 0:
            return True
    except Exception:
        pass
    
    # Level 3: 数值采样验证
    import random
    test_values = [random.uniform(-10, 10) for _ in range(20)]
    for val in test_values:
        try:
            v1 = float(expr1.subs(variable, val))
            v2 = float(expr2.subs(variable, val))
            if abs(v1 - v2) > 10 ** (-precision):
                return False
        except Exception:
            continue
    
    # 特殊值测试后再做符号确认
    try:
        diff = sympy.simplify(expr1 - expr2)
        return diff == 0 or (hasattr(diff, 'is_zero') and diff.is_zero)
    except Exception:
        return True  # 数值验证通过，倾向认为等价
```

```python
class CASEngine:
    """CAS 计算引擎 - 封装 SymPy"""
    
    OPERATION_MAP = {
        'evaluate':      lambda expr, **kw: expr.evalf(kw.get('precision', 15)),
        'simplify':      lambda expr, **kw: sympy.simplify(expr),
        'expand':        lambda expr, **kw: sympy.expand(expr),
        'factor':        lambda expr, **kw: sympy.factor(expr),
        'differentiate': lambda expr, **kw: sympy.diff(expr, kw['variable']),
        'integrate':     lambda expr, **kw: sympy.integrate(expr, kw['variable']),
        'limit':         lambda expr, **kw: sympy.limit(expr, kw['variable'], kw['approach']),
    }
    
    def execute(self, operation: str, sympy_expr, params: dict):
        """执行 CAS 操作"""
        if operation not in self.OPERATION_MAP:
            raise SCEError(SCEErrorCode.SCE_UNSUPPORTED_OPERATION,
                          f"Unsupported: {operation}")
        
        func = self.OPERATION_MAP[operation]
        
        # 执行计算，带超时保护
        with timeout_context(params.get('timeoutMs', 5000)):
            try:
                result = func(sympy_expr, **params)
                return result
            except sympy.PolynomialError as e:
                raise SCEError(SCEErrorCode.SCE_TOO_COMPLEX, str(e))
            except sympy.SympifyError as e:
                raise SCEError(SCEErrorCode.SCE_PARSE_ERROR, str(e))
            except RecursionError:
                raise SCEError(SCEErrorCode.SCE_TOO_COMPLEX,
                              "表达式递归深度超限，请简化输入")
            except TimeoutError:
                raise SCEError(SCEErrorCode.SCE_TIMEOUT,
                              "计算超时，请简化表达式或增加超时时间")
```

```python
class ExpressionComplexityChecker:
    """表达式复杂度评估器"""
    
    MAX_NODES = 500           # AST 最大节点数
    MAX_DEPTH = 30            # 最大嵌套深度
    MAX_VARIABLES = 20        # 最大变量数
    MAX_DEGREE = 100          # 多项式最大次数
    MAX_DIGITS = 1000         # 数字最大位数
    
    def check(self, ast: MathNode) -> tuple[bool, str]:
        """检查表达式复杂度是否在允许范围内"""
        node_count = self._count_nodes(ast)
        if node_count > self.MAX_NODES:
            return False, f"表达式节点数 {node_count} 超过上限 {self.MAX_NODES}"
        
        depth = self._max_depth(ast)
        if depth > self.MAX_DEPTH:
            return False, f"嵌套深度 {depth} 超过上限 {self.MAX_DEPTH}"
        
        # 检查多项式次数（防止恶意大数计算）
        degree = self._estimate_degree(ast)
        if degree > self.MAX_DEGREE:
            return False, f"多项式次数 {degree} 超过上限 {self.MAX_DEGREE}"
        
        return True, ""
```

```python
    x_service_id: str = Header(..., alias="X-Service-Id"),
):
    """统一计算入口"""
    start_time = time.monotonic()
    
    try:
        # 1. 校验请求
        _validate_request(request)
        
        # 2. 归一化 + 缓存查询
        cache_key = _build_cache_key(request)
        cached = await app.state.cache.get(cache_key)
        if cached:
            cached.fromCache = True
            return cached
        
        # 3. 复杂度检查
        checker = ExpressionComplexityChecker()
        for expr in request.expressions:
            ast = _parse_to_ast(expr)
            ok, reason = checker.check(ast)
            if not ok:
                return ComputeResult(
                    requestId=request.requestId,
                    status="failed",
                    errorCode="SCE_TOO_COMPLEX",
                    errorMessage=reason,
                    durationMs=int((time.monotonic() - start_time) * 1000),
                    fromCache=False,
                )
        
        # 4. 路由到对应计算模块
        result = await _route_compute(request)
        
        # 5. 缓存写入
        await app.state.cache.set(cache_key, result, ttl=86400)
        
        result.durationMs = int((time.monotonic() - start_time) * 1000)
        result.fromCache = False
        return result
        
    except SCEError as e:
        return ComputeResult(
            requestId=request.requestId,
            status="failed",
            errorCode=e.code,
            errorMessage=e.message,
            durationMs=int((time.monotonic() - start_time) * 1000),
            fromCache=False,
        )
    except Exception as e:
        return ComputeResult(
            requestId=request.requestId,
            status="failed",
            errorCode="SCE_INTERNAL_ERROR",
            errorMessage=str(e),
            durationMs=int((time.monotonic() - start_time) * 1000),
            fromCache=False,
        )


async def _route_compute(request: ComputeRequest) -> ComputeResult:
    """路由到对应的计算模块"""
    operation = request.operation
    
    # CAS 操作
    CAS_OPS = {'evaluate', 'simplify', 'expand', 'factor', 
               'differentiate', 'integrate', 'limit', 'series'}
    if operation in CAS_OPS:
        return await _execute_cas(request)
    
    # 方程求解
    if operation in ('solve', 'solve_system'):
        return await _execute_solve(request)
    
    # 等价验证
    if operation == 'verify_equivalence':
        return await _execute_verify(request)
    
    # 物理/化学
    if operation == 'physics_calc':
        return await _execute_physics(request)
    if operation == 'balance_chemical':
        return await _execute_chemistry(request)
    
    # 绘图/统计
    if operation == 'plot_data':
        return await _execute_plot(request)
    if operation == 'statistics':
        return await _execute_stats(request)
    
    raise SCEError(SCEErrorCode.SCE_UNSUPPORTED_OPERATION, f"Unknown: {operation}")
```

### 5.2 LaTeX 解析器实现

```python
"""
LaTeX 表达式解析器
将 LaTeX 数学表达式解析为 SymPy 表达式和内部 AST
"""
import re
from sympy import sympify, latex, symbols, Rational
from sympy.parsing.latex import parse_latex


class LatexParser:
    """LaTeX → SymPy 表达式"""
    
    # LaTeX 预处理规则
    PREPROCESS_RULES = [
        # 全角→半角
        (r'[＋－×÷＝]', lambda m: {
            '＋': '+', '－': '-', '×': '\\times', 
            '÷': '\\div', '＝': '='
        }[m.group()]),
        # 中文单位
        (r'（(\d+)）', r'_{\1}'),        # （2） → _{2}
        (r'∠', r'\\angle '),
        (r'⊥', r'\\perp '),
        (r'∥', r'\\parallel '),
        (r'≌', r'\\cong '),
        (r'∽', r'\\sim '),
        (r'°', r'^{\\circ}'),
        (r'π', r'\\pi'),
        # 混合运算隐式乘号: 2x → 2*x, 3(a+b) → 3*(a+b)
        (r'(\d)([a-zA-Z])', r'\1*\2'),
        (r'(\d)\(', r'\1*('),
        (r'\)(\d)', r')*\1'),
        (r'\)([a-zA-Z])', r')*\1'),
    ]
    
    def parse(self, latex_str: str):
        """解析 LaTeX 字符串为 SymPy 表达式"""
        # 1. 预处理
        cleaned = self._preprocess(latex_str)
        
        # 2. 使用 SymPy 的 LaTeX 解析器
        try:
            expr = parse_latex(cleaned)
            return expr
        except Exception as e:
            # 3. 降级：尝试 sympify
            try:
                # 手动清理 LaTeX 命令
                plain = self._latex_to_plain(cleaned)
                expr = sympify(plain)
                return expr
            except Exception:
                raise SCEError(
                    SCEErrorCode.SCE_PARSE_ERROR,
                    f"无法解析 LaTeX 表达式: {latex_str}。错误: {e}"
                )
    
    def _preprocess(self, latex_str: str) -> str:
        """预处理 LaTeX 字符串"""
        result = latex_str.strip()
        for pattern, replacement in self.PREPROCESS_RULES:
            result = re.sub(pattern, replacement, result)
        return result
    
    def _latex_to_plain(self, latex_str: str) -> str:
        """将简单 LaTeX 转换为纯文本（降级方案）"""
        replacements = {
            r'\\times': '*', r'\\div': '/', r'\\cdot': '*',
            r'\\frac{([^}]*)}{([^}]*)}': r'(\1)/(\2)',
            r'\\sqrt{([^}]*)}': r'sqrt(\1)',
            r'\^': '**',
        }
        result = latex_str
        for pattern, repl in replacements.items():
            result = re.sub(pattern, repl, result)
        return result
    
    def to_ast(self, latex_str: str) -> 'MathNode':
        """解析为 AST 节点树"""
        expr = self.parse(latex_str)
        return self._sympy_to_ast(expr)
    
    def _sympy_to_ast(self, expr) -> 'MathNode':
        """SymPy 表达式 → MathNode AST"""
        from .models import MathNode, MathNodeType
        
        if expr.is_Number:
            return MathNode(
                type=MathNodeType.NUMBER,
                value=str(expr)
            )
        elif expr.is_Symbol:
            return MathNode(
                type=MathNodeType.SYMBOL,
                value=str(expr)
            )
        elif expr.is_Add:
            children = [self._sympy_to_ast(arg) for arg in expr.args]
            return MathNode(
                type=MathNodeType.OPERATOR,
                value='+',
                children=children
            )
        elif expr.is_Mul:
            children = [self._sympy_to_ast(arg) for arg in expr.args]
            return MathNode(
                type=MathNodeType.OPERATOR,
                value='*',
                children=children
            )
        elif expr.is_Pow:
            base = self._sympy_to_ast(expr.args[0])
            exp = self._sympy_to_ast(expr.args[1])
            return MathNode(
                type=MathNodeType.POWER,
                children=[base, exp]
            )
        # ... 更多类型映射
        else:
            return MathNode(
                type=MathNodeType.FUNCTION,
                value=str(type(expr).__name__),
                children=[self._sympy_to_ast(arg) for arg in expr.args]
            )
```

```python
使用 SHA256 哈希作为 Key，支持 24h TTL

from typing import Optional


class ExpressionCache:
    
    KEY_PREFIX = "sce:cache:expr:"
    DEFAULT_TTL = 86400  # 24 hours
    
    def __init__(self, redis_pool):
        self.redis = redis_pool
    
    async def get(self, request_key: str) -> Optional['ComputeResult']:
        """查询缓存"""
        import redis.asyncio as aioredis
        
        key = f"{self.KEY_PREFIX}{request_key}"
        data = await aioredis.get(key)
        if data:
            from .models import ComputeResult
            return ComputeResult.model_validate_json(data)
        return None
    
    async def set(self, request_key: str, result: 'ComputeResult', ttl: int = None):
        """写入缓存"""
        import redis.asyncio as aioredis
        
        key = f"{self.KEY_PREFIX}{request_key}"
        ttl = ttl or self.DEFAULT_TTL
        await aioredis.set(
            key, 
            result.model_dump_json(),
            ex=ttl
        )
    
    async def invalidate(self, request_key: str):
        """手动失效缓存"""
        import redis.asyncio as aioredis
        await aioredis.delete(f"{self.KEY_PREFIX}{request_key}")


def build_cache_key(operation: str, expressions: list, params: dict) -> str:
    """
    构建缓存 Key
    归一化所有输入后做 SHA256
    """
    normalized_parts = [operation]
    
    for expr in expressions:
        # 归一化表达式：去空格、统一大小写
        normalized = expr.content.strip().replace(' ', '').lower()
        normalized_parts.append(f"{expr.format}:{normalized}")
    
    # 参数排序后序列化
    if params:
        params_str = json.dumps(params, sort_keys=True, ensure_ascii=False)
        normalized_parts.append(params_str)
    
    combined = '|'.join(normalized_parts)
    return hashlib.sha256(combined.encode('utf-8')).hexdigest()
```

```python
"""
计算沙箱：限制资源使用，防止恶意输入导致 DoS
"""
import signal
import threading
from functools import wraps


class TimeoutError(Exception):
    pass


def timeout_context(timeout_ms: int):
    """
    超时上下文管理器
    使用 signal (Unix) 或 threading.Timer (跨平台)
    """
    timeout_sec = timeout_ms / 1000.0
    
    if hasattr(signal, 'SIGALRM'):
        # Unix: 使用 signal.alarm
        def _handler(signum, frame):
            raise TimeoutError(f"计算超时 ({timeout_ms}ms)")
        
        old_handler = signal.signal(signal.SIGALRM, _handler)
        signal.setitimer(signal.ITIMER_REAL, timeout_sec)
        try:
            yield
        finally:
            signal.alarm(0)
            signal.signal(signal.SIGALRM, old_handler)
    else:
        # Windows / 跨平台: 使用 threading.Timer
        timer = threading.Timer(timeout_sec, lambda: (_ for _ in ()).throw(
            TimeoutError(f"计算超时 ({timeout_ms}ms)")
        ))
        timer.start()
        try:
            yield
        finally:
            timer.cancel()


import resource


class ResourceLimiter:
    """资源限制器"""
    
    MAX_MEMORY_MB = 256  # 单次计算最大内存
    
    def apply_limits(self):
        """设置资源限制（Linux）"""
        try:
            mem_bytes = self.MAX_MEMORY_MB * 1024 * 1024
            resource.setrlimit(resource.RLIMIT_AS, (mem_bytes, mem_bytes))
        except (ValueError, AttributeError):
            # Windows 不支持 RLIMIT_AS，跳过
```

```python
        # 限制长度
        if len(latex_str) > 10240:
            raise SCEError(
                SCEErrorCode.SCE_INVALID_SYNTAX,
                "表达式长度超过限制 (10KB)"
            )
        
        return latex_str
```

```python
class AITutorServiceIntegration:
```
