# 学习报告生成与交付服务 - 详细设计

## 1. 模块概述

### 1.1 功能定位

学习报告生成与交付服务负责将分散在各模块的学习数据（学习记录、答题数据、错题统计、知识点掌握度、学习时长等）聚合加工，生成面向不同角色的学习报告，并通过多渠道（端内消息、Push 推送、家长代收、邮件）定时或按需交付给用户。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| 全角色覆盖 | 学生端、家长端、教师端各有独立报告视图 |
| 多周期支持 | 日报、周报、月报、学期报告、考前专项报告 |
| AI 智能摘要 | 大模型自动生成学习总结、趋势分析和建议 |
| 多格式交付 | 端内富文本、PDF 下载、长图分享、邮件 |
| 定时可靠 | 基于异步任务的定时生成管线，失败自动重试 |
| 可控可配 | 报告模板、生成策略、推送策略均可在后台配置 |

### 1.3 依赖关系

```
学习记录与进度追踪服务  ──→ 数据源
学情分析服务           ──→ 掌握度/薄弱点/能力画像
错题整理服务           ──→ 错题统计
知识点体系             ──→ 知识点树与教材映射
练习与测评系统         ──→ 答题记录/正确率
学习规划服务           ──→ 计划完成情况
消息与推送服务         ──→ 报告送达渠道
AI 对话引擎           ──→ AI 摘要生成
家长中心              ──→ 家长报告投递
教师端与班级管理       ──→ 教师/班级报告
异步任务与事件驱动架构 ──→ 定时任务/事件触发
文件与资源存储服务     ──→ PDF/图片存储
```

## 2. 报告类型体系

### 2.1 报告分类总览

| 报告类型 | 周期 | 触发方式 | 目标角色 | 优先级 |
|----------|------|----------|----------|--------|
| 学生日报 | 每日 | 定时(21:00) | 学生 | P1 |
| 学生周报 | 每周 | 定时(周日 20:00) | 学生 | P0 |
| 学生月报 | 每月 | 定时(每月1日 10:00) | 学生 | P1 |
| 家长周报 | 每周 | 定时(周日 21:00) | 家长 | P0 |
| 家长月报 | 每月 | 定时(每月1日 11:00) | 家长 | P1 |
| 教师班级周报 | 每周 | 定时(周五 18:00) | 教师 | P1 |
| 学期总结报告 | 每学期 | 手动/定时 | 学生+家长 | P2 |
| 考前专项报告 | 按需 | 事件触发(考前7天) | 学生 | P1 |
| 知识点专项报告 | 按需 | 手动触发 | 学生+教师 | P2 |

#### 4.2.2 聚合器实现

```python
# report/aggregator.py

import httpx
from datetime import date, timedelta

class ReportDataAggregator:
    """聚合各微服务数据"""

    def __init__(self, config: dict):
        self.http = httpx.AsyncClient(timeout=30.0)
        self.endpoints = config["service_endpoints"]

    async def aggregate(self, user_id: int, period_start: date,
                        period_end: date, template_code: str) -> ReportContext:
        ctx = ReportContext(
            user_id=user_id,
            period_start=period_start,
            period_end=period_end,
            template_code=template_code,
        )

        sections = await self._get_template_sections(template_code)
        required_sources = {s["dataSource"] for s in sections}

        # 并发拉取所有数据源
        import asyncio
        tasks = []

        if "learning_overview" in required_sources:
            tasks.append(self._fetch_overview(ctx))
        if "subject_breakdown" in required_sources:
            tasks.append(self._fetch_subject_breakdown(ctx))
        if "knowledge_mastery" in required_sources:
            tasks.append(self._fetch_mastery(ctx))
        if "weak_knowledge_points" in required_sources:
            tasks.append(self._fetch_weak_points(ctx))
        if "error_stats" in required_sources:
            tasks.append(self._fetch_error_stats(ctx))
        if "plan_completion" in required_sources:
            tasks.append(self._fetch_plan_completion(ctx))

        await asyncio.gather(*tasks, return_exceptions=True)

        # 拉取上周期数据用于对比
        prev_start = period_start - timedelta(days=(period_end - period_start).days + 1)
        prev_end = period_start - timedelta(days=1)
        ctx.previous_period = await self._fetch_overview_raw(
            user_id, prev_start, prev_end
        )

        return ctx

    async def _fetch_overview(self, ctx: ReportContext) -> None:
        resp = await self.http.get(
            f"{self.endpoints['learning_service']}/api/internal/v1/stats/overview",
            params={"user_id": ctx.user_id,
                    "start": ctx.period_start.isoformat(),
                    "end": ctx.period_end.isoformat()}
        )
        resp.raise_for_status()
        ctx.overview = resp.json()["data"]

    async def _fetch_subject_breakdown(self, ctx: ReportContext) -> None:
        resp = await self.http.get(
            f"{self.endpoints['learning_service']}/api/internal/v1/stats/by-subject",
            params={"user_id": ctx.user_id,
                    "start": ctx.period_start.isoformat(),
                    "end": ctx.period_end.isoformat()}
        )
        resp.raise_for_status()
        ctx.subject_breakdown = resp.json()["data"]

    async def _fetch_mastery(self, ctx: ReportContext) -> None:
        resp = await self.http.get(
            f"{self.endpoints['learning_service']}/api/internal/v1/mastery/heatmap",
            params={"user_id": ctx.user_id, "group_by": "chapter"}
        )
        resp.raise_for_status()
        ctx.mastery_data = resp.json()["data"]

    async def _fetch_weak_points(self, ctx: ReportContext) -> None:
        resp = await self.http.get(
            f"{self.endpoints['learning_service']}/api/internal/v1/mastery/weak-points",
            params={"user_id": ctx.user_id, "limit": 5}
        )
        resp.raise_for_status()
        ctx.weak_points = resp.json()["data"]["points"]

    async def _fetch_error_stats(self, ctx: ReportReport) -> None:
        resp = await self.http.get(
            f"{self.endpoints['error_service']}/api/internal/v1/stats/summary",
            params={"user_id": ctx.user_id,
                    "start": ctx.period_start.isoformat(),
                    "end": ctx.period_end.isoformat()}
        )
        resp.raise_for_status()
        ctx.error_stats = resp.json()["data"]

    async def _fetch_plan_completion(self, ctx: ReportContext) -> None:
        resp = await self.http.get(
            f"{self.endpoints['plan_service']}/api/internal/v1/plans/completion",
            params={"user_id": ctx.user_id,
                    "start": ctx.period_start.isoformat(),
                    "end": ctx.period_end.isoformat()}
        )
        resp.raise_for_status()
        ctx.plan_completion = resp.json()["data"]
```

### 4.3 内容渲染层

#### 4.3.1 Section 渲染器

```python
# report/renderer.py

from abc import ABC, abstractmethod
from typing import Any

class SectionRenderer(ABC):
    """区块渲染器基类"""

    @abstractmethod
    def render(self, section_config: dict, context: ReportContext) -> dict:
        """返回渲染后的区块内容"""
        pass

class StatsCardsRenderer(SectionRenderer):
    """统计卡片渲染"""

    def render(self, section_config: dict, context: ReportContext) -> dict:
        metrics = section_config["config"]["metrics"]
        overview = context.overview or {}
        previous = context.previous_period or {}
        compare = section_config["config"].get("compareWithPrevious", False)

        cards = []
        for metric in metrics:
            value = overview.get(metric, 0)
            card = {"metric": metric, "value": value}

            if compare and previous:
                prev_value = previous.get(metric, 0)
                if prev_value > 0:
                    change_pct = round((value - prev_value) / prev_value * 100, 1)
                    card["changePercent"] = change_pct
                    card["trend"] = "up" if change_pct > 0 else "down" if change_pct < 0 else "flat"
                else:
                    card["changePercent"] = None
                    card["trend"] = "new"

            cards.append(card)

        return {
            "code": section_config["code"],
            "title": section_config["title"],
            "type": "stats_cards",
            "data": {"cards": cards}
        }


class BarChartRenderer(SectionRenderer):
    """柱状图渲染"""

    def render(self, section_config: dict, context: ReportContext) -> dict:
        breakdown = context.subject_breakdown or {}
        max_subjects = section_config["config"].get("maxSubjects", 6)

        items = []
        for subject_name, duration in sorted(
            breakdown.get("subjects", {}).items(),
            key=lambda x: x[1], reverse=True
        )[:max_subjects]:
            items.append({
                "label": subject_name,
                "value": duration,
                "percentage": round(duration / max(breakdown.get("total", 1), 1) * 100, 1)
            })

        return {
            "code": section_config["code"],
            "title": section_config["title"],
            "type": "bar_chart",
            "data": {"items": items, "total": breakdown.get("total", 0)}
        }


class HeatmapRenderer(SectionRenderer):
    """热力图渲染"""

    def render(self, section_config: dict, context: ReportContext) -> dict:
        mastery = context.mastery_data or {}
        config = section_config["config"]

        cells = []
        for chapter in mastery.get("chapters", []):
            cells.append({
                "label": chapter["name"],
                "value": chapter["averageMastery"],
                "color": self._mastery_to_color(chapter["averageMastery"], config["colorScale"], config["thresholds"])
            })

        return {
            "code": section_config["code"],
            "title": section_config["title"],
            "type": "heatmap",
            "data": {"cells": cells}
        }

    @staticmethod
    def _mastery_to_color(value: float, colors: dict, thresholds: dict) -> str:
        if value < thresholds["low"]:
            return colors["low"]
        elif value < thresholds["medium"]:
            return colors["medium"]
        else:
            return colors["high"]


class ErrorSummaryRenderer(SectionRenderer):

    def render(self, section_config: dict, context: ReportContext) -> dict:
```

```python
class ReportOrchestrator:
    """报告渲染编排器"""

    def __init__(self, template_repo, renderer_registry):
        self.template_repo = template_repo
        self.renderers = renderer_registry

    async def render(self, context: ReportContext) -> dict:
        template = await self.template_repo.get_by_code(context.template_code)
        sections_config = template["sections"]

        rendered_sections = []
        for section_def in sorted(sections_config, key=lambda s: s.get("order", 99)):
            renderer = self.renderers.get(section_def["type"])
            if not renderer:
                continue
            try:
                rendered = renderer.render(section_def, context)
                rendered_sections.append(rendered)
            except Exception as e:
                if section_def.get("required", False):
                    raise
                # 可选区块失败不影响整体
                rendered_sections.append({
                    "code": section_def["code"],
                    "title": section_def["title"],
                    "type": "fallback",
                    "data": {"message": "数据暂不可用"}
                })

        return {
            "templateCode": context.template_code,
            "period": {
                "start": context.period_start.isoformat(),
                "end": context.period_end.isoformat()
            },
            "sections": rendered_sections
        }
```

```python
# report/ai_summary.py

from typing import Optional

class ReportAISummarizer:
    """使用大模型生成报告 AI 摘要"""

    def __init__(self, llm_client, prompt_service):
        self.llm = llm_client
        self.prompt_service = prompt_service

    async def generate_summary(self, context: ReportContext,
                                rendered_content: dict,
                                ai_config: dict) -> Optional[str]:
        if not ai_config.get("enabled", True):
            return None

        # 构建 Prompt
        prompt_template = await self.prompt_service.get_template(
            ai_config["promptTemplate"]
        )
        variables = self._build_variables(context, rendered_content)
        prompt = self.prompt_service.render(prompt_template, variables)

        try:
            response = await self.llm.chat(
                messages=[{"role": "user", "content": prompt}],
                model_tier=ai_config.get("modelTier", "standard"),
                max_tokens=ai_config.get("maxTokens", 1024),
                temperature=ai_config.get("temperature", 0.6),
                timeout=ai_config.get("timeoutMs", 15000) / 1000,
            )
            return response["content"]
        except Exception as e:
            if ai_config.get("fallbackToTemplate", True):
                # 降级为模板文本
                return self._template_fallback(context)
            raise

    def _build_variables(self, context: ReportContext,
                         rendered: dict) -> dict:
        overview = context.overview or {}
        previous = context.previous_period or {}
        duration = overview.get("total_duration", 0)
        prev_duration = previous.get("total_duration", 0)

        if prev_duration > 0:
            change_pct = (duration - prev_duration) / prev_duration * 100
            if change_pct > 5:
                duration_change = "较上周有所增加"
            elif change_pct < -5:
                duration_change = "较上周有所减少"
            else:
                duration_change = "与上周基本持平"
        else:
            duration_change = "首次生成周报"

        return {
            "stage": self._get_stage_label(context.user_id),
            "total_duration": duration,
            "duration_change": duration_change,
            "question_count": overview.get("question_count", 0),
            "accuracy_rate": overview.get("accuracy_rate", 0),
            "completed_tasks": overview.get("completed_tasks", 0),
            "total_tasks": overview.get("total_tasks", 0),
            "top_subjects": self._format_subjects(context),
            "weak_points": self._format_weak_points(context),
            "error_count": (context.error_stats or {}).get("total", 0),
            "top_error_types": self._format_error_types(context),
            "tone_adjustment": "活泼有趣" if self._is_primary(context.user_id) else "简洁明了",
        }

    def _template_fallback(self, context: ReportContext) -> str:
        """AI 失败时的模板降级文案"""
        overview = context.overview or {}
        duration = overview.get("total_duration", 0)
        accuracy = overview.get("accuracy_rate", 0)

        if accuracy >= 80:
            return f"本周学习{duration}分钟，正确率表现优秀！继续保持这个节奏。"
        elif accuracy >= 60:
            return f"本周学习{duration}分钟，整体表现良好，部分知识点可以再加强练习。"
        else:
            return f"本周学习{duration}分钟，建议重点回顾薄弱知识点，加油！"
```

```python
                    "printBackground": True,
                }
            }
        )
        resp.raise_for_status()

        # 3. 上传到对象存储
        filename = f"reports/{report_id}/report.pdf"
        url = await self.storage_client.upload_bytes(
            filename, resp.content,
            content_type="application/pdf"
        )
        return url

                            rendered_content: dict) -> str:
        """渲染报告为长图，返回文件 URL"""
```

```python
# report/state_machine.py

REPORT_STATES = {
    "pending":        {"next": ["aggregating", "cancelled"]},
    "aggregating":    {"next": ["generating", "failed"]},
    "generating":     {"next": ["ai_processing", "rendering", "failed"]},
    "ai_processing":  {"next": ["rendering", "failed"]},
    "rendering":      {"next": ["delivering", "failed"]},
    "delivering":     {"next": ["completed", "failed"]},
    "completed":      {"next": []},
    "failed":         {"next": ["pending"]},  # 重试回到 pending
    "cancelled":      {"next": []},
}

class ReportStateMachine:
    def __init__(self, report_repo):
        self.repo = report_repo

    async def transition(self, report_id: int, new_state: str,
                          error_message: str = None) -> None:
        report = await self.repo.get(report_id)
        current = report["status"]
        allowed = REPORT_STATES.get(current, {}).get("next", [])

        if new_state not in allowed:
            raise ValueError(
                f"Invalid transition: {current} → {new_state}, "
                f"allowed: {allowed}"
            )

        update = {"status": new_state, "current_step": new_state}
        if error_message:
            update["error_message"] = error_message
        if new_state == "failed":
            update["retry_count"] = report.get("retry_count", 0) + 1
        if new_state == "completed":
            update["generated_at"] = datetime.utcnow()

        await self.repo.update(report_id, **update)
```

```python
# report/scheduler.py

import uuid
from datetime import date, timedelta

class ReportScheduler:
    """批量报告调度器"""

    def __init__(self, user_repo, task_repo, template_repo):
        self.user_repo = user_repo
        self.task_repo = task_repo
        self.template_repo = template_repo

    def generate_batch(self, template_code: str, period_type: str,
                        target_role: str) -> str:
        template = self.template_repo.get_by_code(template_code)
        batch_id = str(uuid.uuid4())

        period_start, period_end = self._calc_period(period_type)

        # 查询目标用户列表
        if target_role == "student":
            users = self._get_active_students(period_start, period_end)
        elif target_role == "parent":
            users = self._get_subscribed_parents(template_code)
        elif target_role == "teacher":
            users = self._get_active_teachers()
        else:
            users = []

        # 创建批量任务
        tasks = []
        for user in users:
            tasks.append({
                "task_type": f"{period_type}_{target_role}",
                "batch_id": batch_id,
                "target_user_id": user["id"],
                "template_id": template["id"],
                "period_start": period_start,
                "period_end": period_end,
                "status": "pending",
                "scheduled_at": datetime.utcnow(),
            })

        self.task_repo.bulk_create(tasks)

        # 分发到 Celery 队列（控制并发）
        from report.tasks import generate_single_report
        for i, task in enumerate(tasks):
            # 用 countdown 实现错峰，每 0.5 秒分发一个
            generate_single_report.apply_async(
                args=[task["id"]],
                countdown=i * 0.5,
                queue="report_generation"
            )

        return batch_id

    def _calc_period(self, period_type: str) -> tuple[date, date]:
        today = date.today()
        if period_type == "daily":
            return today - timedelta(days=1), today - timedelta(days=1)
        elif period_type == "weekly":
            # 上周一到上周日
            end = today - timedelta(days=today.weekday() + 1)
            start = end - timedelta(days=6)
            return start, end
        elif period_type == "monthly":
            # 上月
            first_of_this_month = today.replace(day=1)
            end = first_of_this_month - timedelta(days=1)
            start = end.replace(day=1)
            return start, end
        else:
            raise ValueError(f"Unknown period_type: {period_type}")

    def _get_active_students(self, start: date, end: date) -> list:
        """获取周期内有学习活动的学生"""
        return self.user_repo.find_active_in_period(start, end, role="student")
```

```python
        self.orchestrator = ReportOrchestrator(template_repo, RENDERER_REGISTRY)
        self.ai_summarizer = ReportAISummarizer(llm_client, prompt_service)
        self.file_renderer = ReportFileRenderer(config)
        self.delivery_service = ReportDeliveryService(config)
        self.state_machine = ReportStateMachine(report_repo)

    async def generate_report(self, task_id: int) -> None:
        task = await self.task_repo.get(task_id)
        report_id = None

        try:
            # 0. 创建报告记录
            report_id = await self.report_repo.create(
                template_id=task["template_id"],
                user_id=task["target_user_id"],
                target_role=task["target_role"],
                period_type=task["period_type"],
                period_start=task["period_start"],
                period_end=task["period_end"],
                report_code=self._gen_report_code(task),
                status="aggregating",
            )

            # 1. 数据聚合
            await self.state_machine.transition(report_id, "aggregating")
            context = await self.aggregator.aggregate(
                user_id=task["target_user_id"],
                period_start=task["period_start"],
                period_end=task["period_end"],
                template_code=task["template_code"],
            )
            await self.report_repo.update(report_id, aggregated_data=context.__dict__)

            # 2. 内容渲染
            await self.state_machine.transition(report_id, "generating")
            rendered = await self.orchestrator.render(context)
            await self.report_repo.update(report_id, rendered_content=rendered)

            # 3. AI 摘要
            await self.state_machine.transition(report_id, "ai_processing")
            ai_summary = await self.ai_summarizer.generate_summary(
                context, rendered,
                task["ai_summary_config"]
            )
            if ai_summary:
                # 将 AI 摘要插入到 rendered_content 的 ai_summary section
                await self._inject_ai_summary(rendered, ai_summary)
                await self.report_repo.update(
                    report_id,
                    ai_summary=ai_summary,
                    rendered_content=rendered,
                )

            # 4. 文件渲染（PDF + 长图）
            await self.state_machine.transition(report_id, "rendering")
            pdf_url = await self.file_renderer.render_pdf(report_id, rendered)
            image_url = await self.file_renderer.render_image(report_id, rendered)
            await self.report_repo.update(report_id, pdf_url=pdf_url, image_url=image_url)

            # 5. 交付推送
            await self.state_machine.transition(report_id, "delivering")
            await self.delivery_service.deliver(report_id, task)

            # 6. 完成
            await self.state_machine.transition(report_id, "completed")
            logger.info(f"Report generated: {report_id}")

        except Exception as e:
            logger.error(f"Report generation failed: task={task_id}, error={e}")
            if report_id:
                await self.state_machine.transition(
                    report_id, "failed", error_message=str(e)
                )
            # 更新任务状态
            await self.task_repo.update(task_id, status="failed",
                                         error_message=str(e))
            raise
```

## 10. 交付与推送

### 10.1 交付服务

```python
# report/delivery.py

class ReportDeliveryService:
    """报告交付服务"""

    async def deliver(self, report_id: int, task: dict) -> None:
        report = await self.report_repo.get(report_id)
        template = await self.template_repo.get(report["template_id"])
        delivery_config = template["delivery_config"]

        target_user_id = report["user_id"]
        channels = delivery_config["channels"]

        # 特殊处理：家长报告需要发给绑定的家长
        if report["target_role"] == "parent":
            parent_subs = await self._get_parent_subscriptions(
                report["user_id"]  # student_id
            )
            for sub in parent_subs:
                await self._deliver_to_user(
                    report, sub["parent_id"], sub["channels"], delivery_config
                )
        else:
            await self._deliver_to_user(
                report, target_user_id, channels, delivery_config
            )

        await self.report_repo.update(report_id, delivered_at=datetime.utcnow())

    async def _deliver_to_user(self, report: dict, user_id: int,
                                 channels: list, config: dict) -> None:
        for channel in channels:
            try:
                if channel == "in_app":
                    await self._send_in_app(report, user_id, config)
                elif channel == "push":
                    await self._send_push(report, user_id, config)
                elif channel == "email":
                    await self._send_email(report, user_id, config)
            except Exception as e:
                logger.error(f"Delivery failed: report={report['id']}, "
                            f"channel={channel}, user={user_id}: {e}")
                await self._log_delivery(
                    report["id"], channel, user_id, "failed", str(e)
                )

    async def _send_push(self, report: dict, user_id: int,
                          config: dict) -> None:
        push_config = config.get("pushConfig", {})
        if not push_config.get("enabled"):
            return

        # 静默时段检查
        if self._in_quiet_hours(config.get("quietHours")):
            # 延迟到次日早晨
            return

        title = push_config["titleTemplate"]
        body = push_config["bodyTemplate"].replace(
            "{{total_duration}}",
            str(report.get("aggregated_data", {}).get("overview", {}).get("total_duration", ""))
        )

        await self.push_service.send(
            user_id=user_id,
            title=title,
            body=body,
            data={"action": "report_detail", "report_id": report["id"]},
            click_action=push_config.get("clickAction"),
        )

        await self._log_delivery(report["id"], "push", user_id, "sent")

    async def _send_in_app(self, report: dict, user_id: int,
                            config: dict) -> None:
        in_app_config = config.get("inAppConfig", {})
        await self.message_service.create(
            user_id=user_id,
            type="report",
            title=f"📊 你的{report['period_type']}学习报告已生成",
            content=report.get("ai_summary", ""),
            data={"report_id": report["id"]},
            badge=in_app_config.get("badge", True),
            persistent=in_app_config.get("persistent", True),
        )

        await self._log_delivery(report["id"], "in_app", user_id, "sent")
```

## 12. 错误处理

### 12.1 错误场景与策略

| 场景 | 策略 | 降级方案 |
|------|------|----------|
| 数据聚合超时 | 单数据源超时 10s，整体超时 30s | 使用部分数据生成报告，缺失区块显示"暂无数据" |
| AI 摘要生成失败 | 重试 1 次 | 使用模板降级文案 |
| PDF 渲染失败 | 重试 1 次 | 仅提供端内查看，不生成 PDF |
| 长图渲染失败 | 跳过 | 不影响报告查看 |
| Push 推送失败 | 记录日志，不重试 | 用户打开 APP 时看到端内消息 |
| 整体生成失败 | 重试最多 3 次，间隔 5min | 记录失败原因，后台可手动触发 |
| 报告重复生成 | report_code 唯一约束 | 跳过已存在且状态为 completed 的报告 |
| 并发生成冲突 | 乐观锁（version 字段） | 只允许一个实例执行 |

### 12.2 错误码

| 错误码 | 含义 |
|--------|------|
| REPORT_001 | 报告不存在 |
| REPORT_002 | 报告生成中，尚未完成 |
| REPORT_003 | 报告生成失败 |
| REPORT_004 | 无权限查看（家长未绑定/教师非本班） |
| REPORT_005 | 分享链接已过期 |
| REPORT_006 | 反馈类型无效 |
| REPORT_007 | 订阅配置无效 |
| REPORT_008 | 模板配置错误 |
| REPORT_009 | 数据聚合失败 |
| REPORT_010 | AI 摘要生成超时 |
| REPORT_011 | PDF 渲染失败 |
| REPORT_012 | 重复生成（report_code 冲突） |
