## 1. 模块概述

### 1.1 功能定位

客户端页面状态模式规范定义了 APP 内所有页面在**加载中（Loading）、骨架屏（Skeleton）、空态（Empty State）、错误态（Error State）、无网络（Offline）**等非正常内容状态下的统一 UI 表现、交互行为、组件架构和状态流转规则。

**一句话定位：** 为开发人员提供"拿来即用"的页面状态组件库，确保全 APP 每个页面的加载、空态、错误表现一致且符合分龄适配要求。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **零配置默认** | 页面仅需声明数据源，自动获得完整的 5 态切换 |
| **分龄适配** | 幼儿/小学空态插画可爱，初中/高中简约专业 |
| **可操作性** | 所有错误态和空态必须提供可操作的下一步（重试、刷新、引导） |
| **性能优先** | 骨架屏渲染 < 16ms，不依赖网络数据 |
| **无障碍** | 状态切换需配合语义化朗读（TalkBack/VoiceOver） |

### 1.3 页面状态枚举

```dart
/// 页面内容状态枚举
enum PageState {
  /// 首次加载中（显示骨架屏）
  loading,

  /// 骨架屏加载中（首次进入，数据尚未到达）
  skeleton,

  /// 下拉刷新中（已有数据，顶部刷新指示器）
  refreshing,

  /// 正常内容
  content,

  /// 数据为空
  empty,

  /// 网络错误（无连接）
  networkError,

  /// 服务端错误（4xx/5xx）
  serverError,

  /// 超时
  timeout,

  /// 需要登录
  unauthorized,

  /// 功能未开放/维护中
  maintenance,

  /// 禁用（如家长控制）
  restricted,
}
```

### 1.4 与其他模块的关系

| 关联模块 | 关系 |
|----------|------|
| 客户端组件库与设计系统 | 本规范定义的状态组件是该组件库的一部分 |
| 客户端网络请求治理与弱网适配 | 网络层触发 loading → networkError 状态转换 |
| 客户端全局异常处理与安全恢复机制 | 异常捕获后展示统一错误态 |
| 分龄UI适配与交互设计规范 | 空态/错误态的插画风格和文案需按学段适配 |
| 客户端主题引擎与动态外观系统 | 状态组件需支持深色模式 |
| 客户端无障碍访问与辅助功能系统 | 状态组件需提供语义化标注 |

## 2. 状态流转模型

### 2.1 通用状态机

```
                    ┌─────────────────────────────────────────┐
                    ▼                                         │
  ┌──────────┐  success   ┌─────────┐  数据为空  ┌───────┐   │
  │ skeleton │ ──────────→ │ content │ ─────────→ │ empty │   │
  └──────────┘             └────┬────┘            └───┬───┘   │
       │                       │ pull-to-refresh      │       │
       │ timeout               ▼                      │       │
       ▼                  ┌────────────┐              │       │
  ┌─────────┐            │ refreshing │──────────────┘       │
  │ timeout │            └────────────┘  (空结果)             │
  └────┬────┘                 │                               │
       │                      │ error                         │
       │ error                ▼                               │
       ▼               ┌──────────────┐                       │
  ┌─────────────┐      │ serverError  │──── retry ────────────┘
  │ networkError│      │ timeout      │
  │ serverError │      └──────────────┘
  │ timeout     │
  └──────┬──────┘
         │ retry / network restored
         └───────────────────→ skeleton
```

### 2.2 状态流转规则

```dart
/// 状态流转规则表
class PageStateTransition {
  /// 判断是否允许从 [from] 转换到 [to]
  static bool canTransit(PageState from, PageState to) {
    return _transitions[from]?.contains(to) ?? false;
  }

  static const _transitions = <PageState, Set<PageState>>{
    PageState.skeleton: {
      PageState.content,
      PageState.empty,
      PageState.networkError,
      PageState.serverError,
      PageState.timeout,
      PageState.unauthorized,
      PageState.maintenance,
    },
    PageState.loading: {
      PageState.content,
      PageState.empty,
      PageState.networkError,
      PageState.serverError,
      PageState.timeout,
    },
    PageState.refreshing: {
      PageState.content,
      PageState.empty,
      PageState.networkError,
      PageState.serverError,
      PageState.timeout,
    },
    PageState.content: {
      PageState.refreshing,
      PageState.networkError,
      PageState.serverError,
      PageState.timeout,
      PageState.unauthorized,
    },
    PageState.empty: {
      PageState.refreshing,
      PageState.loading,
      PageState.networkError,
      PageState.serverError,
    },
    PageState.networkError: {
      PageState.skeleton,
      PageState.loading,
    },
    PageState.serverError: {
      PageState.skeleton,
      PageState.loading,
    },
    PageState.timeout: {
      PageState.skeleton,
      PageState.loading,
    },
    PageState.unauthorized: {
      PageState.skeleton, // 登录后重新加载
    },
    PageState.maintenance: {
      PageState.skeleton, // 维护结束后刷新
    },
    PageState.restricted: {
      PageState.content, // 家长解除限制后
    },
  };
}

## 3. 骨架屏（Skeleton）设计

### 3.1 设计规范

骨架屏是页面首次加载时的占位视图，模拟内容布局结构，给用户"即将呈现"的感知。

| 参数 | 幼儿/小学 | 初中/高中 |
|------|-----------|-----------|
| 基色 | `#F0F0F0` (浅灰) | `#E8E8E8` (中灰) |
| 高光色 | `#FAFAFA` (白色高光) | `#F5F5F5` |
| 动画 | 左→右扫光，1200ms | 左→右扫光，800ms |
| 圆角 | 16px (圆润) | 8px (简洁) |
| 深色模式基色 | `#2A2A2A` | `#333333` |
| 深色模式高光 | `#3A3A3A` | `#444444` |

### 3.2 组件架构

```dart
/// 骨架屏基础组件
class SkeletonBox extends StatefulWidget {
  final double width;
  final double height;
  final double borderRadius;
  final bool isCircle; // 用于头像等圆形占位

  const SkeletonBox({
    super.key,
    this.width = double.infinity,
    this.height = 16,
    this.borderRadius = 8,
    this.isCircle = false,
  });

  @override
  State<SkeletonBox> createState() => _SkeletonBoxState();
}

class _SkeletonBoxState extends State<SkeletonBox>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controller;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1200),
    )..repeat();
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    final isDark = theme.brightness == Brightness.dark;
    final baseColor = isDark ? const Color(0xFF2A2A2A) : const Color(0xFFF0F0F0);
    final highlightColor =
        isDark ? const Color(0xFF3A3A3A) : const Color(0xFFFAFAFA);

    return AnimatedBuilder(
      animation: _controller,
      builder: (context, child) {
        return Shimmer.fromColors(
          baseColor: baseColor,
          highlightColor: highlightColor,
          period: const Duration(milliseconds: 1200),
          child: Container(
            width: widget.width,
            height: widget.height,
            decoration: BoxDecoration(
              color: baseColor,
              borderRadius: widget.isCircle
                  ? null
                  : BorderRadius.circular(widget.borderRadius),
              shape: widget.isCircle ? BoxShape.circle : BoxShape.rectangle,
            ),
          ),
        );
      },
    );
  }
}
```

## 4. 加载态（Loading）设计

### 4.1 加载类型分类

| 类型 | 触发场景 | UI 表现 | 可中断 |
|------|----------|---------|--------|
| 全屏加载 | 页面首次进入 | 骨架屏 | 否 |
| 局部加载 | 页面内某个区域刷新 | 区域内 Spinner + 半透明遮罩 | 否 |
| 操作加载 | 提交表单、收藏、点赞等 | 按钮变为 loading + 全局 hud | 可取消（超时 30s 自动取消） |
| 下拉刷新 | 用户下拉手势 | 顶部刷新指示器 | 松手即停 |
| 上拉加载更多 | 列表滚动到底部 | 底部加载指示器 | 滚走即停 |
| 后台同步 | 数据静默同步 | 底部/顶部轻量进度条 | 否 |

### 4.3 AI 思考动画

AI 对话场景使用专用思考动画，避免用户因等待而焦虑：

```dart
class _AIThinkingIndicator extends StatefulWidget {
  final String? message;
  const _AIThinkingIndicator({this.message});

  @override
  State<_AIThinkingIndicator> createState() => _AIThinkingIndicatorState();
}

class _AIThinkingIndicatorState extends State<_AIThinkingIndicator>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controller;
  int _dotCount = 0;
  int _messageIndex = 0;

  /// 思考提示消息轮播
  static const _thinkMessages = [
    '正在分析题目...',
    '正在整理知识点...',
    '正在组织讲解思路...',
    '马上就好...',
  ];

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 500),
    )..addStatusListener((status) {
        if (status == AnimationStatus.completed) {
          _controller.reverse();
        } else if (status == AnimationStatus.dismissed) {
          _controller.forward();
          setState(() {
            _dotCount = (_dotCount + 1) % 4;
          });
        }
      });

    // 每 3 秒切换思考提示
    Future.delayed(const Duration(seconds: 3), _cycleMessage);
    _controller.forward();
  }

  void _cycleMessage() {
    if (!mounted) return;
    setState(() {
      _messageIndex = (_messageIndex + 1) % _thinkMessages.length;
    });
    Future.delayed(const Duration(seconds: 3), _cycleMessage);
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 12),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          // 脑袋图标 + 脉冲动画
          AnimatedBuilder(
            animation: _controller,
            builder: (context, child) {
              return Transform.scale(
                scale: 1.0 + _controller.value * 0.1,
                child: child,
              );
            },
            child: Icon(
              Icons.psychology_outlined,
              size: 20,
              color: theme.colorScheme.primary,
            ),
          ),
          const SizedBox(width: 8),
          Text(
            '${widget.message ?? _thinkMessages[_messageIndex]}${'.' * _dotCount}',
            style: theme.textTheme.bodySmall?.copyWith(
              color: theme.colorScheme.onSurfaceVariant,
            ),
          ),
        ],
      ),
    );
  }
}

### 7.1 PageStateBuilder 核心组件

这是所有页面的统一状态容器，管理 skeleton → content/empty/error 的完整生命周期：

```dart
/// 页面状态容器 — 所有页面的统一状态管理入口
///
/// 使用方式：
/// ```dart
/// PageStateBuilder<MyData>(
///   controller: myController,
///   skeleton: SkeletonTemplate.homeWorkspace,
///   emptyConfig: EmptyStateType.noStudyRecords,
///   builder: (context, data) => MyContentWidget(data: data),
/// )
/// ```
class PageStateBuilder<T> extends StatelessWidget {
  /// 页面状态控制器
  final PageStateController<T> controller;

  /// 骨架屏模板
  final SkeletonTemplate skeleton;

  /// 空态类型（数据为空时显示）
  final EmptyStateType? emptyConfig;

  /// 内容构建器
  final Widget Function(BuildContext context, T data) builder;

  /// 自定义错误处理
  final Widget Function(BuildContext context, PageState error)? errorBuilder;

  /// 下拉刷新回调
  final Future<void> Function()? onRefresh;

  /// 是否支持下拉刷新（默认 true）
  final bool enablePullToRefresh;

  /// 当前学段（用于分龄适配空态/骨架屏）
  final AgeGroup? ageGroup;

  const PageStateBuilder({
    super.key,
    required this.controller,
    required this.skeleton,
    required this.builder,
    this.emptyConfig,
    this.errorBuilder,
    this.onRefresh,
    this.enablePullToRefresh = true,
    this.ageGroup,
  });

  @override
  Widget build(BuildContext context) {
    final group = ageGroup ?? context.read<UserProfile>().ageGroup;

    return AnimatedSwitcher(
      duration: const Duration(milliseconds: 300),
      switchInCurve: Curves.easeInOut,
      switchOutCurve: Curves.easeInOut,
      child: ListenableBuilder(
        listenable: controller,
        builder: (context, _) {
          return switch (controller.state) {
            PageState.skeleton || PageState.loading => _wrapRefresh(
                context,
                SkeletonFactory.create(skeleton, ageGroup: group),
              ),
            PageState.content => _wrapRefresh(
                context,
                builder(context, controller.data!),
              ),
            PageState.empty => _wrapRefresh(
                context,
                _buildEmpty(context, group),
              ),
            PageState.refreshing => _wrapRefresh(
                context,
                builder(context, controller.data!),
              ),
            PageState.networkError ||
            PageState.serverError ||
            PageState.timeout ||
            PageState.unauthorized ||
            PageState.maintenance ||
            PageState.restricted =>
              errorBuilder?.call(context, controller.state) ??
                  ErrorStateView(
                    errorType: controller.state,
                    onRetry: controller.retry,
                  ),
          };
        },
      ),
    );
  }

  Widget _buildEmpty(BuildContext context, AgeGroup group) {
    if (emptyConfig == null) {
      return const EmptyStateView(
        config: EmptyStateConfig(
          type: EmptyStateType.generic,
          // ... generic default config
        ),
        ageGroup: AgeGroup.juniorHigh,
      );
    }
    final config = EmptyStateRegistry.getConfig(emptyConfig!);
    if (config == null) return const SizedBox.shrink();
    return EmptyStateView(config: config, ageGroup: group);
  }

  Widget _wrapRefresh(BuildContext context, Widget child) {
    if (!enablePullToRefresh) return child;
    return RefreshIndicator(
      onRefresh: onRefresh ?? controller.refresh,
      child: child,
    );
  }
}

### 7.2 PageStateController

```dart
/// 页面状态控制器
class PageStateController<T> extends ChangeNotifier {
  PageState _state = PageState.skeleton;
  T? _data;
  Object? _error;
  StackTrace? _stackTrace;
  int _retryCount = 0;

  static const int _maxRetries = 3;

  PageState get state => _state;
  T? get data => _data;
  Object? get error => _error;
  StackTrace? get stackTrace => _stackTrace;

  /// 数据加载器（由页面注入）
  Future<T> Function()? _loader;

  /// 初始化控制器，设置数据加载函数
  void init(Future<T> Function() loader) {
    _loader = loader;
    load();
  }

  /// 触发首次加载
  Future<void> load() async {
    if (_loader == null) return;
    _state = PageState.skeleton;
    _error = null;
    notifyListeners();

    try {
      _data = await _loader!();
      _state = _isEmpty(_data) ? PageState.empty : PageState.content;
      _retryCount = 0;
    } catch (e, st) {
      _error = e;
      _stackTrace = st;
      _state = _mapErrorToState(e);
    }
    notifyListeners();
  }

  /// 下拉刷新
  Future<void> refresh() async {
    if (_loader == null) return;
    _state = PageState.refreshing;
    notifyListeners();

    try {
      _data = await _loader!();
      _state = _isEmpty(_data) ? PageState.empty : PageState.content;
      _retryCount = 0;
    } catch (e, st) {
      _error = e;
      _stackTrace = st;
      _state = _mapErrorToState(e);
    }
    notifyListeners();
  }

  /// 重试（从错误态恢复）
  Future<void> retry() async {
    if (_retryCount >= _maxRetries) {
      // 超过最大重试次数，引导用户反馈
      return;
    }
    _retryCount++;
    await load();
  }

  /// 外部强制设置状态（用于特殊场景）
  void setState(PageState newState, {T? newData}) {
    _state = newState;
    if (newData != null) _data = newData;
    notifyListeners();
  }

  bool _isEmpty(T? data) {
    if (data == null) return true;
    if (data is List) return data.isEmpty;
    if (data is Map) return data.isEmpty;
    if (data is String) return data.isEmpty;
    return false;
  }

  PageState _mapErrorToState(Object error) {
    if (error is DioException) {
      switch (error.type) {
        case DioExceptionType.connectionError:
          return PageState.networkError;
        case DioExceptionType.connectionTimeout:
        case DioExceptionType.receiveTimeout:
        case DioExceptionType.sendTimeout:
          return PageState.timeout;
        case DioExceptionType.badResponse:
          final statusCode = error.response?.statusCode;
          if (statusCode == 401) return PageState.unauthorized;
          if (statusCode == 503) return PageState.maintenance;
          return PageState.serverError;
        default:
          return PageState.serverError;
      }
    }
    if (error is UnauthorizedException) return PageState.unauthorized;
    if (error is MaintenanceException) return PageState.maintenance;
    if (error is RestrictedException) return PageState.restricted;
    return PageState.serverError;
  }
}

    _hudOverlayEntry = OverlayEntry(

    );

        dismiss();
        config.onDismiss?.call();

/// 骨架屏到内容的平滑过渡
class SkeletonTransition extends StatefulWidget {
  final bool showSkeleton;
  final Widget skeleton;
  final Widget child;

  const SkeletonTransition({
    super.key,
    required this.showSkeleton,
    required this.skeleton,
    required this.child,
  });

  @override
  State<SkeletonTransition> createState() => _SkeletonTransitionState();
}

class _SkeletonTransitionState extends State<SkeletonTransition>
    with TickerProviderStateMixin {
  late final AnimationController _controller;
  late final Animation<double> _opacity;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 300),
    );
    _opacity = CurvedAnimation(
      parent: _controller,
      curve: Curves.easeInOut,
    );

    if (!widget.showSkeleton) {
      _controller.value = 1.0;
    }
  }

  @override
  void didUpdateWidget(SkeletonTransition oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.showSkeleton && !widget.showSkeleton) {
      // 骨架屏 → 内容：交叉淡入
      _controller.forward();
    } else if (!oldWidget.showSkeleton && widget.showSkeleton) {
      _controller.reverse();
    }
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Stack(
      children: [
        FadeTransition(
          opacity: _opacity,
          child: widget.child,
        ),
        FadeTransition(
          opacity: Tween<double>(begin: 1.0, end: 0.0).animate(_opacity),
          child: IgnorePointer(
            ignoring: !_controller.isDismissed,
            child: widget.skeleton,
          ),
        ),
      ],
    );
  }
}
