# 课程资源管理-详细设计

## 1. 概述

### 1.1 功能定位

课程资源管理（Course Resource Management）是 PrimeTop 同步课堂与内容交付体系的核心子模块，负责将微课、讲义、习题集、图文、音频、视频、H5 互动素材等学习内容以结构化方式组织起来，并精确挂载到教材章节/课时节点，为客户端同步学习、AI 辅导上下文检索、学习进度追踪和内容推荐提供可消费的内容资产。

本模块向下依赖文件存储服务、对象存储、消息服务，向上为同步课堂服务、AI 服务、推荐服务、学习服务、家长端学情报告提供数据与接口支撑。

### 1.2 设计目标

1. **统一内容资产模型**：支持多种资源类型，统一元数据、文件资产、版本、状态与权限管理。
2. **章节精确挂载**：一个资源可挂载到多个章节，一个章节可挂载多个资源；支持按资源用途（预习、讲解、练习、复习、拓展）分类。
3. **生命周期可管可控**：资源从草稿、审核、发布到下架、作废的全状态流转可追溯。
4. **版本可追溯**：内容更新时保留历史版本，已发布学习记录不漂移。
5. **权益可感知**：资源访问与会员等级、学段、年级、B 端授权、学校授权绑定。
6. **进度可同步**：音视频类资源支持跨端播放进度、完成度同步与离线续播。

### 1.3 依赖关系

```text
课程资源管理
  ├─ 依赖：文件存储服务（上传、转码、缩略图、CDN URL）
  ├─ 依赖：内容服务（教材、章节、知识点、考点元数据）
  ├─ 依赖：权限/权益服务（访问授权、会员、B 端学校）
  ├─ 依赖：消息服务（资源变更事件、缓存失效）
  ├─ 被依赖：同步课堂服务（章节资源聚合、学习流编排）
  ├─ 被依赖：学习服务（播放进度、完成度、学习记录）
  ├─ 被依赖：AI 服务（RAG 检索素材、辅导上下文）
  ├─ 被依赖：推荐服务（首页卡片、个性化推荐）
  └─ 被依赖：管理后台（内容生产、审核、上下架）
```

## 3. 状态流转

### 3.1 资源生命周期状态机

```text
                    ┌──────────────┐
        ┌──────────▶│   DRAFT      │◀────────────┐
        │  编辑退回  │  （草稿）     │   新建/复制   │
        │           └──────┬───────┘               │
        │                  │ 提交审核               │
        │                  ▼                       │
        │           ┌──────────────┐               │
        │  重新提交  │  IN_REVIEW   │  审核不通过     │
        └───────────│  （审核中）   │───────────────┘
                    └──────┬───────┘
                           │ 审核通过
                           ▼
                    ┌──────────────┐
         定时发布/手动发布 ───▶│  APPROVED    │
                    │  （已通过）   │
                    └──────┬───────┘
                           │ 发布
                           ▼
                    ┌──────────────┐
         下架/失效 ───▶│  PUBLISHED   │◀── 重新发布
                    │  （已发布）   │
                    └──────┬───────┘
                           │ 下架
                           ▼
                    ┌──────────────┐
                    │   OFFLINE    │
                    │  （已下架）   │
                    └──────┬───────┘
                           │ 归档
                           ▼
                    ┌──────────────┐
                    │  ARCHIVED    │
                    │  （已归档）   │
                    └──────────────┘
```

### 3.2 状态转换规则

| 当前状态 | 操作 | 目标状态 | 触发条件 | 权限 |
| --- | --- | --- | --- | --- |
| DRAFT | submitReview | IN_REVIEW | 内容填写完整、至少一个资源文件 | 教研/运营 |
| IN_REVIEW | approve | APPROVED | 审核通过 | 审核员 |
| IN_REVIEW | reject | DRAFT | 审核不通过，需填写原因 | 审核员 |
| APPROVED | publish | PUBLISHED | 手动或到达生效时间 | 运营/系统 |
| PUBLISHED | offline | OFFLINE | 运营手动下架或到达失效时间 | 运营/系统 |
| OFFLINE | republish | PUBLISHED | 重新上架（需重新审核） | 运营 |
| OFFLINE | archive | ARCHIVED | 长期不用，归档后不可恢复 | 运营 |
| PUBLISHED | archive | ARCHIVED | 资源版本过期 | 系统 |

### 3.3 版本发布规则

- 每次发布均生成一条 `resource_version` 快照，版本号 +1。
- 已发布版本的内容正文与资产做快照保留，防止后续编辑影响已发布版本。
- 正在学习中的用户看到已发布版本；编辑中的草稿不影响在线资源。
- 资源下架后，已缓存的 CDN 资源需通过缓存失效消息清理。

## 4. API 接口设计

### 4.1 管理后台接口（B2B）

#### 4.1.1 创建资源

```http
POST /api/v1/admin/resources
Content-Type: application/json
Authorization: Bearer {admin_token}
```

Request:

```json
{
  "title": "人教版七年级上册 第一章 有理数 微课",
  "resourceType": "VIDEO",
  "subjectCode": "MATH",
  "phase": "JUNIOR_HIGH",
  "gradeRange": [7],
  "semesterRange": [1],
  "contentAbstract": "介绍有理数概念、数轴表示与相反数...",
  "difficulty": "EASY",
  "estimatedDurationSec": 480,
  "accessLevel": "MEMBER",
  "tags": ["有理数", "数轴", "相反数"],
  "allowDownload": true,
  "extraProperties": {
    "subtitles": ["zh-CN", "en"]
  }
}
```

Response:

```json
{
  "code": 0,
  "data": {
    "id": 10001,
    "resourceCode": "RES-MATH-7A-20260728001",
    "status": "DRAFT",
    "version": 1,
    "createdAt": "2026-07-28T00:36:00+08:00"
  }
}
```

### 5.1 资源访问权限校验

```java
@Service
public class ResourceAccessService {

    @Autowired
    private ResourceRepository resourceRepository;
    @Autowired
    private MembershipClient membershipClient;
    @Autowired
    private SchoolAuthClient schoolAuthClient;

    /**
     * 判断用户是否可以访问指定资源
     */
    public AccessCheckResult checkAccess(Long userId, Long resourceId, Long schoolId) {
        LearningResource resource = resourceRepository.findById(resourceId)
            .orElseThrow(() -> new ResourceNotFoundException(resourceId));

        // 1. 状态检查：只有 PUBLISHED 且未过期的资源可访问
        if (resource.getStatus() != ResourceStatus.PUBLISHED) {
            return AccessCheckResult.denied(ResourceAccessError.RESOURCE_NOT_PUBLISHED);
        }
        if (isExpired(resource)) {
            return AccessCheckResult.denied(ResourceAccessError.RESOURCE_EXPIRED);
        }

        // 2. 学段年级匹配
        StudentProfile profile = UserContext.getStudentProfile();
        if (!gradeMatches(resource, profile)) {
            return AccessCheckResult.denied(ResourceAccessError.GRADE_NOT_MATCH);
        }

        // 3. 权益校验
        AccessLevel accessLevel = resource.getAccessLevel();
        switch (accessLevel) {
            case FREE:
                return AccessCheckResult.allowed();
            case MEMBER:
                if (!membershipClient.hasActiveMembership(userId)) {
                    return AccessCheckResult.denied(ResourceAccessError.MEMBERSHIP_REQUIRED);
                }
                return AccessCheckResult.allowed();
            case PAID:
                if (!orderClient.hasPaidResource(userId, resourceId)) {
                    return AccessCheckResult.denied(ResourceAccessError.PURCHASE_REQUIRED);
                }
                return AccessCheckResult.allowed();
            case SCHOOL:
                if (schoolId == null || !schoolAuthClient.isAuthorized(userId, schoolId, resourceId)) {
                    return AccessCheckResult.denied(ResourceAccessError.SCHOOL_AUTH_REQUIRED);
                }
                return AccessCheckResult.allowed();
            case BETA:
                if (!userTagService.isBetaUser(userId)) {
                    return AccessCheckResult.denied(ResourceAccessError.BETA_ONLY);
                }
                return AccessCheckResult.allowed();
            default:
                return AccessCheckResult.denied(ResourceAccessError.UNKNOWN_ACCESS_LEVEL);
        }
    }

    private boolean gradeMatches(LearningResource resource, StudentProfile profile) {
        return resource.getPhase() == profile.getPhase()
            && resource.getGradeRange().contains(profile.getGrade());
    }

    private boolean isExpired(LearningResource resource) {
        LocalDateTime now = LocalDateTime.now();
        return resource.getEffectiveTime() != null && now.isBefore(resource.getEffectiveTime())
            || resource.getExpiryTime() != null && now.isAfter(resource.getExpiryTime());
    }
}
```

### 5.2 资源发布工作流

```java
@Service
public class ResourceLifecycleService {

    @Autowired
    private ResourceRepository resourceRepository;
    @Autowired
    private ResourceVersionRepository versionRepository;
    @Autowired
    private ResourceReviewRepository reviewRepository;
    @Autowired
    private ApplicationEventPublisher eventPublisher;

    @Transactional
    public LearningResource publish(Long resourceId, PublishRequest request) {
        LearningResource resource = resourceRepository.findById(resourceId)
            .orElseThrow(() -> new ResourceNotFoundException(resourceId));

        // 只有 APPROVED 或 OFFLINE 状态可发布
        if (resource.getStatus() != ResourceStatus.APPROVED
            && resource.getStatus() != ResourceStatus.OFFLINE) {
            throw new InvalidResourceStatusException("当前状态不允许发布: " + resource.getStatus());
        }

        // 校验资产：视频必须有转码成功的视频资产
        if (resource.getResourceType() == ResourceType.VIDEO) {
            boolean hasReadyVideo = resource.getAssets().stream()
                .anyMatch(a -> a.getAssetType() == AssetType.VIDEO
                    && a.getTranscodeStatus() == TranscodeStatus.SUCCESS);
            if (!hasReadyVideo) {
                throw new ResourceAssetNotReadyException("视频转码未完成，不可发布");
            }
        }

        // 生成新版本快照
        int newVersion = resource.getVersion() + 1;
        ResourceVersion snapshot = new ResourceVersion();
        snapshot.setResourceId(resourceId);
        snapshot.setVersionNo(newVersion);
        snapshot.setTitle(resource.getTitle());
        snapshot.setContentBodySnapshot(resource.getContentBody());
        snapshot.setAssetSnapshot(serializeAssets(resource.getAssets()));
        snapshot.setChangeSummary(request.getComment());
        snapshot.setStatus(VersionStatus.PUBLISHED);
        snapshot.setPublisherId(UserContext.getUserId());
        snapshot.setPublishTime(LocalDateTime.now());
        versionRepository.save(snapshot);

        // 更新主表
        resource.setVersion(newVersion);
        resource.setPublishedVersionId(snapshot.getId());
        resource.setStatus(ResourceStatus.PUBLISHED);
        resource.setPublishTime(LocalDateTime.now());
        resource.setEffectiveTime(request.getEffectiveTime());
        resource.setExpiryTime(request.getExpiryTime());
        resource.setPublisherId(UserContext.getUserId());
        resourceRepository.save(resource);

        // 记录审核流水
        reviewRepository.save(buildReviewRecord(resourceId, newVersion, "PUBLISH", request.getComment()));

        // 发送资源变更事件，通知缓存失效、推荐重算
        eventPublisher.publishEvent(new ResourceChangedEvent(resourceId, newVersion, ChangeType.PUBLISHED));

        return resource;
    }
}
```

### 5.3 章节资源聚合查询

```java
@Service
public class ChapterResourceQueryService {

    @Autowired
    private ChapterResourceBindingRepository bindingRepository;
    @Autowired
    private ResourceRepository resourceRepository;
    @Autowired
    private ResourceAccessService accessService;
    @Autowired
    private ProgressService progressService;
    @Autowired
    private StringRedisTemplate redisTemplate;

    private static final String CACHE_KEY = "chapter:resources:%d:%s";

    public List<ChapterResourceView> listChapterResources(Long chapterId, BindingType type, Long userId) {
        String cacheKey = String.format(CACHE_KEY, chapterId, type == null ? "ALL" : type.name());

        // 1. 读取缓存（缓存仅包含资源ID列表与元数据，不缓存用户权限结果）
        String cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            List<ChapterResourceBinding> bindings = JSON.parseArray(cached, ChapterResourceBinding.class);
            return enrich(bindings, userId);
        }

        // 2. 查询数据库
        List<ChapterResourceBinding> bindings = bindingRepository
            .findByChapterIdAndStatusOrderByDisplayOrder(chapterId, ResourceStatus.PUBLISHED);
        if (type != null) {
            bindings = bindings.stream()
                .filter(b -> b.getBindingType() == type)
                .collect(Collectors.toList());
        }

        // 3. 写入缓存，TTL 10 分钟
        redisTemplate.opsForValue().set(cacheKey, JSON.toJSONString(bindings), Duration.ofMinutes(10));

        return enrich(bindings, userId);
    }

    private List<ChapterResourceView> enrich(List<ChapterResourceBinding> bindings, Long userId) {
        List<ChapterResourceView> result = new ArrayList<>();
        for (ChapterResourceBinding binding : bindings) {
            LearningResource resource = resourceRepository.findById(binding.getResourceId()).orElse(null);
            if (resource == null || resource.getDeleted()) continue;

            AccessCheckResult access = accessService.checkAccess(userId, resource.getId(), null);
            ResourcePlaybackProgress progress = progressService.getProgress(userId, resource.getId());

            ChapterResourceView view = new ChapterResourceView();
            view.setResourceId(resource.getId());
            view.setResourceCode(resource.getResourceCode());
            view.setTitle(resource.getTitle());
            view.setResourceType(resource.getResourceType());
            view.setBindingType(binding.getBindingType());
            view.setIsRequired(binding.getIsRequired());
            view.setEstimatedDurationSec(resource.getEstimatedDurationSec());
            view.setAccessLevel(resource.getAccessLevel());
            view.setIsAccessible(access.isAllowed());
            view.setAccessDeniedReason(access.getReason());
            view.setCoverImageUrl(resource.getCoverImageUrl());
            view.setProgress(progress);
            result.add(view);
        }
        return result;
    }
}
```

### 5.4 播放进度上报与完成判定

```java
@Service
public class PlaybackProgressService {

    @Autowired
    private PlaybackProgressRepository progressRepository;
    @Autowired
    private ResourceAccessLogRepository accessLogRepository;
    @Autowired
    private LearningEventPublisher eventPublisher;

    private static final BigDecimal COMPLETION_THRESHOLD = new BigDecimal("0.90");

    @Transactional
    public ProgressUpdateResult updateProgress(Long userId, Long resourceId, Long assetId, ProgressUpdateRequest request) {
        // 1. 幂等：基于 (userId, resourceId, assetId) 唯一键，UPDATE 即覆盖
        ResourcePlaybackProgress progress = progressRepository
            .findByUserIdAndResourceIdAndAssetId(userId, resourceId, assetId)
            .orElse(new ResourcePlaybackProgress());

        progress.setUserId(userId);
        progress.setResourceId(resourceId);
        progress.setAssetId(assetId);
        progress.setChapterId(request.getChapterId());
        progress.setTotalDurationSec(request.getTotalDurationSec());
        progress.setLastPositionMs(request.getLastPositionMs());
        progress.setProgressSec(request.getProgressSec());
        progress.setPlaybackDeviceId(request.getPlaybackDeviceId());

        // 2. 计算完成率（取进度与总时长的比值，但不超过 1.0）
        BigDecimal completionRate = calculateCompletionRate(request.getProgressSec(), request.getTotalDurationSec());
        progress.setCompletionRate(completionRate);

        // 3. 完成判定：完成率 >= 90% 或显式 isCompleted=true
        boolean justCompleted = false;
        if (!Boolean.TRUE.equals(progress.getIsCompleted())
            && (request.getIsCompleted() || completionRate.compareTo(COMPLETION_THRESHOLD) >= 0)) {
            progress.setIsCompleted(true);
            progress.setCompletedAt(LocalDateTime.now());
            justCompleted = true;
        }

        progressRepository.save(progress);

        // 4. 记录访问日志
        accessLogRepository.save(buildAccessLog(userId, resourceId, request.getChapterId(),
            justCompleted ? "COMPLETE" : "PLAY", request.getClientType()));

        // 5. 完成时发送学习事件，触发积分、成就、学习记录更新
        if (justCompleted) {
            eventPublisher.publish(new ResourceCompletedEvent(userId, resourceId, assetId, request.getChapterId()));
        }

        return ProgressUpdateResult.builder()
            .completionRate(completionRate)
            .isCompleted(progress.getIsCompleted())
            .justCompleted(justCompleted)
            .build();
    }

    private BigDecimal calculateCompletionRate(int progressSec, int totalDurationSec) {
        if (totalDurationSec <= 0) return BigDecimal.ZERO;
        BigDecimal rate = new BigDecimal(progressSec)
            .divide(new BigDecimal(totalDurationSec), 4, RoundingMode.HALF_UP);
        return rate.min(BigDecimal.ONE);
    }
}
```

## 7. 错误处理

### 7.1 错误码设计

| 错误码 | 错误说明 | HTTP 状态 | 处理建议 |
| --- | --- | --- | --- |
| 0 | 成功 | 200 | - |
| 600101 | 资源不存在 | 404 | 提示资源已下架或不存在 |
| 600102 | 资源未发布 | 403 | 前端隐藏入口，后台不可访问 |
| 600103 | 资源已过期 | 403 | 提示资源已失效，推荐相似资源 |
| 600104 | 资源下载失败 | 502 | 重试 CDN 链接或降级到 file_url |
| 600105 | 视频转码未完成 | 422 | 提示资源准备中，稍后重试 |
| 600106 | 年级学段不匹配 | 403 | 提示当前资源不适合当前学段 |
| 600107 | 需要会员权益 | 402 | 引导开通会员 |
| 600108 | 需要购买资源 | 402 | 跳转购买页面 |
| 600109 | 学校授权不足 | 403 | 提示联系学校管理员 |
| 600110 | 资源审核未通过 | 422 | 运营后台修改后重新提交 |
| 600111 | 挂载关系已存在 | 409 | 提示该资源已挂载到当前章节 |
| 600112 | 播放进度保存失败 | 500 | 客户端本地缓存，稍后重试 |
| 600113 | 资源文件缺失 | 500 | 运营后台补传文件 |

### 7.2 常见异常场景处理

| 场景 | 异常类型 | 处理方式 |
| --- | --- | --- |
| 资源发布时视频转码失败 | ResourceAssetNotReadyException | 禁止发布，通知运营重新上传或转码 |
| 资源下架后仍有用户访问 | 缓存未失效 | 通过 ResourceChangedEvent 通知缓存失效，CDN 链接设置短 TTL |
| 播放进度上报时网络中断 | 客户端离线 | 客户端本地缓存进度，恢复网络后批量上报 |
| 资源挂载到不存在的章节 | DataIntegrityException | 事务回滚，返回 400 并提示检查章节ID |
| 同一资源多次挂载到同一章节 | DuplicateBindingException | 幂等返回已有绑定，或提示更新绑定类型 |
| 用户越权访问其他学校资源 | UnauthorizedAccessException | 返回 403，记录审计日志 |
| 完成判定完成率异常（>100%） | 数据校验 | 服务端强制截断到 1.0，并记录异常日志 |

## 8. 性能与缓存策略

### 8.1 缓存设计

| 缓存对象 | 缓存层 | Key 设计 | TTL | 更新策略 |
| --- | --- | --- | --- | --- |
| 章节资源列表 | Redis | `chapter:resources:{chapterId}:{bindingType}` | 10 min | 资源发布/下架/绑定时失效 |
| 资源详情 | Redis | `resource:detail:{resourceId}` | 15 min | 资源编辑/发布时失效 |
| 资源权限结果 | 本地 Caffeine | `resource:access:{userId}:{resourceId}` | 5 min | 会员状态变更时失效 |
| 播放进度 | Redis | `progress:{userId}:{resourceId}:{assetId}` | 24 h | 每次上报更新，定时落库 |
| CDN 资源 | CDN 边缘 | 按 URL 哈希 | 按文件类型 | 资源更新时刷新 CDN |

### 8.2 查询优化

- `chapter_resource_binding` 表建立 `(chapter_id, status, display_order)` 联合索引。
- `learning_resource` 表对 `resource_code` 建立唯一索引，`title` 建立全文索引（ngram）。
- 资源列表查询避免返回 `content_body` 大字段，详情接口再加载正文。
- 播放进度批量上报：客户端每 30 秒或暂停时上报一次，服务端合并写库。
- 高并发读场景使用 Redis 缓存，写操作通过消息队列异步落库审计日志。

## 9. 安全与合规

### 9.1 权限控制

- 管理后台接口按角色鉴权：教研可创建/编辑草稿，审核员可审核，运营可发布/下架。
- 所有客户端资源访问必须经过 `ResourceAccessService.checkAccess`。
- 学段年级不匹配时即使资源已发布也不允许访问，防止高中生看到幼儿内容或反之。
- 学校授权资源需校验 `schoolId` 与 `userId` 的绑定关系。

### 9.2 内容安全

- 资源正文 `content_body` 富文本/HTML 需经过 XSS 过滤和敏感内容审核。
- 上传的音视频、PDF 需经过内容审核服务扫描，审核未通过不可进入 IN_REVIEW 状态。
- 用户不可上传资源，仅运营/教研/审核员通过管理后台上传。

### 9.3 审计与日志

- 资源创建、编辑、提交、审核、发布、下架、归档操作均写入 `resource_review_record`。
- 用户对资源的访问（VIEW/PLAY/DOWNLOAD/COMPLETE）写入 `resource_access_log`。
- 未成年用户访问记录保留期限不少于 3 年，按隐私合规要求处理。

### 9.4 数据隐私

- 播放进度、完成记录等学习数据属于用户个人数据，仅本人、绑定家长、授权教师可见。
- 对外接口返回的进度信息需遵循用户数据共享可见度分级策略。
- 资源访问日志中 `ip` 字段需脱敏后存储，禁止明文保存用户真实 IP。
