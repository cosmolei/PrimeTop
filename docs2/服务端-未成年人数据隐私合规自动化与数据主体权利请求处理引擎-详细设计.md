# 服务端-未成年人数据隐私合规自动化与数据主体权利请求处理引擎 详细设计

## 1. 模块概述

### 1.1 功能定位

本引擎是 PrimeTop 平台数据隐私合规体系的核心执行组件，负责自动化处理《个人信息保护法》(PIPL)、《未成年人保护法》及相关法规要求的数据主体权利请求，管理用户同意生命周期，并维护全链路隐私审计能力。

由于 PrimeTop 服务的核心用户群体为 3-18 岁未成年人，本引擎需满足 PIPL 第三十一条（不满十四周岁未成年人个人信息处理需取得监护人同意）等特殊合规要求。

### 1.2 与已有模块的边界

| 模块 | 职责边界 |
| --- | --- |
| 数据安全与隐私合规体系 | 全局安全策略框架、加密存储规范、数据分类分级 |
| 学习数据导出与账户注销服务 | 具体数据导出与账户删除的业务逻辑实现 |
| 数据脱敏规则引擎 | 敏感字段动态遮蔽、展示层脱敏规则 |
| 用户协议与法律文档管理服务 | 隐私政策、用户协议的版本管理与展示 |
| **本引擎（隐私合规自动化）** | **数据主体权利请求工作流、同意生命周期管理、合规审计自动化、未成年人特殊保护逻辑** |

### 1.3 设计目标

1. **请求处理自动化**：数据主体权利请求从提交到响应全流程 ≤ 15 个工作日（PIPL 法定要求）
2. **同意管理精细化**：按数据处理活动粒度管理用户/监护人同意，支持独立撤回
3. **审计可追溯**：所有隐私相关操作留痕，支持按用户、时间、操作类型多维检索
4. **未成年人优先保护**：自动识别未成年人身份，触发增强保护策略
5. **跨服务编排**：统一调度用户服务、学习服务、AI 服务、支付服务等多方数据的收集与清除

#### 3.1.1 同意检查流程（核心拦截器）

```java
/**
 * 隐私同意拦截器 - 在需要用户同意的功能调用前执行
 * 
 * 使用方式：在 Controller 方法上添加 @RequireConsent(ProcessingActivity.AI_TUTORING)
 */
@Component
public class PrivacyConsentInterceptor implements HandlerInterceptor {

    @Autowired
    private PrivacyConsentService consentService;
    @Autowired
    private MinorProtectionService minorService;

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, 
                             Object handler) throws Exception {
        if (!(handler instanceof HandlerMethod hm)) return true;
        
        RequireConsent annotation = hm.getMethodAnnotation(RequireConsent.class);
        if (annotation == null) return true;

        Long userId = SecurityContext.getUserId();
        ProcessingActivity activity = annotation.value();

        // 1. 检查用户年龄，确定是否需要监护人同意
        UserInfo user = userService.getUser(userId);
        MinorProtectionRule rule = minorService.getRuleForAge(user.getAge());
        
        ConsentTemplate template = consentService.getTemplate(activity);
        boolean needsGuardian = template.isRequiresGuardian() 
                && user.getAge() < template.getMinorAgeThreshold();

        // 2. 检查同意状态
        ConsentStatus status = consentService.checkConsent(userId, activity);
        
        if (needsGuardian && !status.hasGuardianConsent()) {
            // 未获得监护人同意
            throw new ConsentRequiredException(
                ConsentRequiredException.Type.GUARDIAN_CONSENT_NEEDED,
                activity,
                "该功能需要监护人同意后方可使用"
            );
        }
        
        if (!needsGuardian && !status.hasSelfConsent()) {
            if (rule.isRequiresGuardian_consent()) {
                throw new ConsentRequiredException(
                    ConsentRequiredException.Type.GUARDIAN_CONSENT_NEEDED,
                    activity, null
                );
            }
            throw new ConsentRequiredException(
                ConsentRequiredException.Type.SELF_CONSENT_NEEDED,
                activity, null
            );
        }

        // 3. 检查是否已过期
        if (status.isExpired()) {
            throw new ConsentRequiredException(
                ConsentRequiredException.Type.CONSENT_EXPIRED,
                activity, "同意已过期，请重新确认"
            );
        }

        // 4. 检查未成年人保护限制（如每日使用时长）
        if (user.isMinor()) {
            minorService.checkUsageLimit(userId, activity, rule);
        }

        // 5. 记录审计日志
        auditLogger.log(PrivacyAction.CONSENT_CHECK_PASSED, userId, activity, null);
        
        return true;
    }
}
```

#### 3.1.2 监护人同意授权流程

```java
@Service
public class GuardianConsentService {

    /**
     * 监护人授权同意（异步流程）
     * 
     * 流程：
     * 1. 学生端发起授权请求
     * 2. 系统生成授权链接/二维码，发送至已绑定的监护人
     * 3. 监护人在 App 内或 H5 页面查看活动详情并确认
     * 4. 系统记录同意证据（IP、设备指纹、时间戳、操作截图）
     * 5. 激活对应功能权限
     */
    public ConsentResult grantGuardianConsent(
            Long studentId, 
            Long guardianId, 
            ProcessingActivity activity,
            String guardianVerifyToken) {
        
        // 1. 验证监护人身份
        GuardianBinding binding = guardianService.verifyBinding(studentId, guardianId);
        if (!binding.isActive()) {
            return ConsentResult.fail("监护人绑定关系无效");
        }

        // 2. 验证监护人操作令牌（二次验证）
        if (!tokenService.verify(guardianId, guardianVerifyToken)) {
            return ConsentResult.fail("监护人身份验证失败");
        }

        // 3. 获取同意模板
        ConsentTemplate template = consentService.getTemplate(activity);
        
        // 4. 记录同意
        PrivacyConsent consent = PrivacyConsent.builder()
            .userId(studentId)
            .subjectType(SubjectType.STUDENT)
            .processingActivity(activity.name())
            .consentStatus(ConsentStatus.GRANTED)
            .grantedBy(GrantedBy.GUARDIAN)
            .guardianId(guardianId)
            .policyVersion(policyService.getCurrentVersion())
            .evidenceRef(saveConsentEvidence(studentId, guardianId, activity))
            .grantedAt(Instant.now())
            .expiresAt(calculateExpiry(template))
            .build();
        
        consentRepository.save(consent);

        // 5. 记录审计日志（包含完整的证据链）
        auditLogger.log(PrivacyAction.CONSENT_GRANT, studentId, activity, Map.of(
            "guardianId", guardianId,
            "guardianPhone", maskPhone(binding.getGuardianPhone()),
            "evidenceRef", consent.getEvidenceRef(),
            "policyVersion", consent.getPolicyVersion()
        ));

        // 6. 发送通知给学生
        notificationService.notify(studentId, NotificationType.CONSENT_ACTIVATED, 
            Map.of("activity", activity.getActivityName()));

        return ConsentResult.success(consent);
    }

    /**
     * 同意撤回（用户/监护人随时可撤回）
     */
    @Transactional
    public void withdrawConsent(Long userId, ProcessingActivity activity, 
                                 WithdrawReason reason) {
        PrivacyConsent consent = consentRepository
            .findActiveConsent(userId, activity.name())
            .orElseThrow(() -> new BusinessException("未找到有效的同意记录"));

        consent.setConsentStatus(ConsentStatus.WITHDRAWN);
        consent.setWithdrawnAt(Instant.now());
        consentRepository.save(consent);

        // 立即生效：停止相关数据处理活动
        eventPublisher.publishEvent(new ConsentWithdrawnEvent(userId, activity, reason));

        // 对于 ERASURE 类活动撤回，触发数据停止收集
        // 对于 RECOMMENDATION 类活动撤回，停止个性化推荐，降级为通用内容
        
        auditLogger.log(PrivacyAction.CONSENT_WITHDRAW, userId, activity, 
            Map.of("reason", reason.name()));
    }
```

#### 3.2.1 DSR 状态机

```java
/**
 * 数据主体权利请求状态机
 *
 *  PENDING ──verify──▶ VERIFYING ──pass──▶ PROCESSING ──all_done──▶ COMPLETED
 *     │                     │                   │                       │
 *     │                  fail                partial                   │
 *     │                     ▼                   ▼                       │
 *                  ◀──REJECTED          (人工介入)                       │
 *                                                                     │
 *  用户取消 ◀──────────────────────────────────────────── CANCELLED     │
 *                                                                     │
 *  申诉 ────────────────────────────────────────────────▶ (重新处理)    │
 */
public enum DSRStatus {
    PENDING,       // 待提交验证
    VERIFYING,     // 身份验证中
    PROCESSING,    // 处理中（已分发至各服务）
    COMPLETED,     // 已完成
    REJECTED,      // 已拒绝（验证失败或请求无效）
    CANCELLED      // 用户取消
}

@Component
public class DSRStateMachine {
    
    private static final Map<DSRStatus, Set<DSRStatus>> TRANSITIONS = Map.of(
        DSRStatus.PENDING,    Set.of(DSRStatus.VERIFYING, DSRStatus.CANCELLED),
        DSRStatus.VERIFYING,  Set.of(DSRStatus.PROCESSING, DSRStatus.REJECTED, DSRStatus.CANCELLED),
        DSRStatus.PROCESSING, Set.of(DSRStatus.COMPLETED, DSRStatus.CANCELLED),
        DSRStatus.COMPLETED,  Set.of(), // 终态，可通过申诉重开
        DSRStatus.REJECTED,   Set.of(DSRStatus.VERIFYING), // 可补充材料后重新验证
        DSRStatus.CANCELLED,  Set.of()  // 终态
    );

    public void validateTransition(DSRStatus from, DSRStatus to) {
        Set<DSRStatus> allowed = TRANSITIONS.getOrDefault(from, Set.of());
        if (!allowed.contains(to)) {
            throw new IllegalStateException(
                String.format("非法状态转换: %s -> %s (允许: %s)", from, to, allowed)
            );
        }
    }
}
```

#### 3.2.2 DSR 处理编排器

```java
@Service
public class DSR orchestrator {

    @Autowired private DSREventPublisher eventPublisher;
    @Autowired private DataInventoryService inventoryService;
    @Autowired private PrivacyAuditLogger auditLogger;
    @Autowired private DSRTaskExecutor taskExecutor;

    /**
     * 提交 DSR 请求
     */
    public DataSubjectRequest submitRequest(DSRRequest req) {
        // 1. 计算法定截止日期（15 个工作日）
        LocalDate deadline = calculateWorkingDayDeadline(15);

        // 2. 生成请求编号
        String requestCode = generateRequestCode();

        // 3. 创建 DSR 记录
        DataSubjectRequest dsr = DataSubjectRequest.builder()
            .requestCode(requestCode)
            .userId(req.getUserId())
            .requestType(req.getType())
            .status(DSRStatus.PENDING)
            .priority(req.isMinor() ? Priority.HIGH : Priority.NORMAL)
            .deadline(deadline)
            .description(req.getDescription())
            .submittedAt(Instant.now())
            .build();
        dsrRepository.save(dsr);

        // 4. 触发身份验证流程
        eventPublisher.publish(new DSRSubmittedEvent(dsr));

        // 5. 审计日志
        auditLogger.log(PrivacyAction.DSR_SUBMITTED, req.getUserId(), null, Map.of(
            "requestCode", requestCode,
            "requestType", req.getType().name(),
            "deadline", deadline.toString()
        ));

        return dsr;
    }

    /**
     * 身份验证通过后，开始处理
     */
    @EventListener
    @Async("dsrExecutor")
    public void onVerificationPassed(DSRVerifiedEvent event) {
        DataSubjectRequest dsr = event.getDsr();
        dsrStateMachine.validateTransition(dsr.getStatus(), DSRStatus.PROCESSING);
        
        dsr.setStatus(DSRStatus.PROCESSING);
        dsr.setProcessingStartedAt(Instant.now());
        dsrRepository.save(dsr);

        // 根据数据资产清单，为每个涉及的服务创建子任务
        List<DataInventory> inventories = inventoryService.getRelevantInventories(dsr.getUserId());
        
        List<DSRItem> items = inventories.stream()
            .map(inv -> DSRItem.builder()
                .dsrId(dsr.getId())
                .serviceName(inv.getServiceName())
                .itemStatus(DSRItemStatus.PENDING)
                .build())
            .collect(Collectors.toList());
        dsrItemRepository.saveAll(items);

        // 并行分发子任务到各服务
        for (DSRItem item : items) {
            taskExecutor.dispatch(dsr, item);
        }

        // 设置超时监控
        scheduleTimeoutCheck(dsr);
    }

    /**
     * 子任务完成回调
     */
    @EventListener
    public void onItemCompleted(DSRItemCompletedEvent event) {
        DSRItem item = event.getItem();
        dsrItemRepository.save(item);

        // 检查所有子任务是否完成
        boolean allDone = dsrItemRepository.findAllByDsrId(item.getDsrId())
            .stream()
            .allMatch(i -> i.getItemStatus().isTerminal());

        if (allDone) {
            completeDSR(item.getDsrId());
        }
    }

    /**
     * 汇总所有子任务结果，完成 DSR
     */
    private void completeDSR(Long dsrId) {
        DataSubjectRequest dsr = dsrRepository.findById(dsrId).orElseThrow();
        List<DSRItem> items = dsrItemRepository.findAllByDsrId(dsrId);

        DSRResult result = DSRAssembler.assemble(dsr, items);

        // 对于访问/可携带性请求：生成数据包并上传
        if (dsr.getRequestType() == DSRType.ACCESS || 
            dsr.getRequestType() == DSRType.PORTABILITY) {
            String artifactUrl = packageAndUpload(dsr, result);
            dsr.setResultArtifactUrl(artifactUrl);
        }

        // 对于删除请求：验证所有数据已清除
        if (dsr.getRequestType() == DSRType.ERASURE) {
            ErasureVerification verification = verifyErasure(dsr, items);
            if (!verification.allPassed()) {
                log.warn("删除验证未完全通过: {}", verification.getFailures());
                // 触发人工处理
                escalateToHuman(dsr, verification);
                return;
            }
        }

        dsr.setStatus(DSRStatus.COMPLETED);
        dsr.setCompletedAt(Instant.now());
        dsr.setResultSummary(result.getSummary());
        dsrRepository.save(dsr);

        // 通知用户
        notificationService.notify(dsr.getUserId(), 
            NotificationType.DSR_COMPLETED, Map.of(
                "requestCode", dsr.getRequestCode(),
                "requestType", dsr.getRequestType().name()
            ));

        // 审计
        auditLogger.log(PrivacyAction.DSR_COMPLETED, dsr.getUserId(), null, Map.of(
            "requestCode", dsr.getRequestCode(),
            "itemCount", items.size(),
            "totalRecords", result.getTotalRecords()
        ));
    }
}
```

### 3.3 数据删除（被遗忘权）实现策略

```java
/**
 * 分层数据删除策略
 * 
 * 对于 ERASURE 类型的 DSR，根据数据资产清单执行分层数据清除：
 * - HOT 数据（MySQL/PostgreSQL）：硬删除或匿名化
 * - WARM 数据（Redis）：删除缓存键
 * - COLD 数据（ClickHouse/ES）：标记删除或匿名化
 * - 对象存储（OSS）：删除文件
 * - 向量数据库：删除嵌入向量
 * - 备份：标记为待清理（下次备份覆盖时自动消失，不超过 30 天）
 */
@Service
public class ErasureExecutor {

    /**
     * 执行数据清除（各微服务通过 DSR 处理器调用）
     */
    public ErasureResult execute(Long userId, String serviceName, 
                                  List<DataInventory> inventories) {
        ErasureResult result = new ErasureResult(serviceName);
        
        for (DataInventory inv : inventories) {
            try {
                ErasureMethod method = inv.getDeletionMethod();
                int affected = switch (method) {
                    case HARD     -> hardDelete(inv, userId);
                    case SOFT     -> softDelete(inv, userId);
                    case ANONYMIZE -> anonymize(inv, userId);
                };
                
                result.addSuccess(inv, affected);
                
                // 记录每个数据类别的清除证据
                auditLogger.log(PrivacyAction.DATA_DELETE, userId, null, Map.of(
                    "service", serviceName,
                    "category", inv.getDataCategory(),
                    "method", method.name(),
                    "affected", affected,
                    "storage", inv.getStorageLocation()
                ));
                
            } catch (Exception e) {
                result.addFailure(inv, e.getMessage());
                log.error("数据清除失败 userId={} category={} error={}", 
                    userId, inv.getDataCategory(), e.getMessage(), e);
            }
        }
        return result;
    }

    /**
     * 硬删除：直接 DELETE FROM
     */
    private int hardDelete(DataInventory inv, Long userId) {
        String tableName = inv.getTableName();
        String userIdField = getUserIdField(tableName);
        
        // 执行前先统计
        int count = jdbcTemplate.queryForObject(
            "SELECT COUNT(*) FROM " + tableName + " WHERE " + userIdField + " = ?",
            Integer.class, userId);
        
        // 执行删除
        jdbcTemplate.update(
            "DELETE FROM " + tableName + " WHERE " + userIdField + " = ?", userId);
        
        // 清除相关缓存
        cacheEvictService.evictUserData(userId, tableName);
        
        // 清除搜索引擎索引
        searchIndexService.deleteByUser(userId, tableName);
        
        return count;
    }

    /**
     * 匿名化：保留数据用于统计分析但去除身份关联
     * 适用于：学习行为统计、答题正确率分析等聚合数据
     */
    private int anonymize(DataInventory inv, Long userId) {
        String tableName = inv.getTableName();
        
        // 将 user_id 替换为匿名 ID，清除姓名、手机号等直接标识
        String sql = """
            UPDATE %s 
            SET user_id = NULL,
                user_name = NULL,
                user_phone = NULL,
                anonymized = TRUE,
                anonymized_at = NOW()
            WHERE user_id = ?
            """.formatted(tableName);
        
        return jdbcTemplate.update(sql, userId);
    }

    /**
     * 软删除：标记 deleted_at，30 天后物理清除
     * 适用于：需要保留审计追溯的交易记录
     */
    private int softDelete(DataInventory inv, Long userId) {
        String tableName = inv.getTableName();
        return jdbcTemplate.update(
            "UPDATE " + tableName + " SET deleted_at = NOW() WHERE user_id = ? AND deleted_at IS NULL",
            userId);
    }

    /**
     * 删除后验证：确认用户数据已被完全清除
     */
    public ErasureVerification verify(Long userId) {
        ErasureVerification verification = new ErasureVerification();
        
        List<DataInventory> allInventories = inventoryService.getAllInventories();
        
        for (DataInventory inv : allInventories) {
            // 扫描所有数据存储位置
            int remaining = scanRemaining(inv, userId);
            if (remaining > 0) {
                verification.addFailure(inv, remaining);
            }
        }
        
        // 检查向量数据库
        int vectorRemaining = vectorSearchService.countByUser(userId);
        if (vectorRemaining > 0) {
            verification.addFailure("vector_db", vectorRemaining);
        }
        
        // 检查搜索引擎
        int esRemaining = searchService.countByUser(userId);
        if (esRemaining > 0) {
            verification.addFailure("elasticsearch", esRemaining);
        }
        
        // 检查对象存储
        int ossRemaining = storageService.countUserFiles(userId);
        if (ossRemaining > 0) {
            verification.addFailure("object_storage", ossRemaining);
        }
        
        return verification;
    }
}
```

### 4.1 年龄识别与分级保护

```java
/**
 * 未成年人分级保护服务
 * 
 * 根据 PIPL 第三十一条，处理不满十四周岁未成年人个人信息
 *应当取得未成年人的父母或者其他监护人的同意。

@Service
public class MinorProtectionService {

    /**
     * 年龄分段与对应保护级别
     */
    public ProtectionLevel getProtectionLevel(Date birthDate) {
        int age = calculateAge(birthDate);
        
        if (age < 7)  return ProtectionLevel.LEVEL_1; // 学龄前：最严格
        if (age < 14) return ProtectionLevel.LEVEL_2; // 小学：严格
        if (age < 18) return ProtectionLevel.LEVEL_3; // 中学：适度
        return ProtectionLevel.LEVEL_4;                // 成人：标准
    }

    /**
     * 检查功能使用限制
     */
    public void checkUsageLimit(Long userId, ProcessingActivity activity, 
                                 MinorProtectionRule rule) {
        // 1. 检查受限活动
        if (rule.getRestrictedActivities().contains(activity.name())) {
            throw new MinorProtectionException(
                "当前年龄段不支持此功能: " + activity.getActivityName()
            );
        }

        // 2. 检查每日使用时长
        if (rule.getMaxDailyUsageMinutes() != null) {
            int usedToday = usageTracker.getTodayUsageMinutes(userId);
            if (usedToday >= rule.getMaxDailyUsageMinutes()) {
                throw new MinorProtectionException(
                    String.format("今日使用时长已达上限（%d分钟）", 
                        rule.getMaxDailyUsageMinutes())
                );
            }
        }

        // 3. 检查画像推荐权限
        if (activity == ProcessingActivity.RECOMMENDATION 
            && !rule.isProfilingAllowed()) {
            throw new MinorProtectionException(
                "当前年龄段不支持个性化推荐，将展示通用内容"
            );
        }

        // 4. 检查营销推送权限
        if (activity == ProcessingActivity.MARKETING_COMMUNICATION 
            && !rule.isMarketingAllowed()) {
            throw new MinorProtectionException("未成年人不接收营销信息");
        }
    }

    /**
     * 自动数据最小化处理
     * 对未成年人的数据采集遵循最小必要原则
     */
    public <T> T minimizeData(T data, ProtectionLevel level) {
        if (level == ProtectionLevel.LEVEL_1 || level == ProtectionLevel.LEVEL_2) {
            DataMinimizer.minimize(data); // 清除精确位置、设备指纹等非必要字段
        }

            req.setPendingGuardianBinding(true);
        }
    }
```

### 4.2 防沉迷自动干预

```java
/**
 * 防沉迷自动干预引擎
 * 
 * 与 MinorProtectionRule 配合，实现自动化的使用时长监控和干预
 */
@Service
public class AntiAddictionEngine {

    @Scheduled(fixedRate = 60000) // 每分钟检查
    public void checkAllActiveMinors() {
        List<ActiveSession> sessions = sessionService.getActiveMinorSessions();
        
        Map<Integer, List<ActiveSession>> grouped = sessions.stream()
            .collect(Collectors.groupingBy(s -> 
                minorService.getProtectionLevel(s.getBirthDate()).getLevel()));
        
        for (Map.Entry<Integer, List<ActiveSession>> entry : grouped.entrySet()) {
            MinorProtectionRule rule = ruleService.getByLevel(entry.getKey());
            if (rule.getMaxDailyUsageMinutes() == null) continue;
            
            for (ActiveSession session : entry.getValue()) {
                int todayMinutes = usageTracker.getTodayUsageMinutes(session.getUserId());
                
                // 接近上限时发送提醒
                if (todayMinutes == rule.getMaxDailyUsageMinutes() - 5) {
                    notificationService.notify(session.getUserId(), 
                        NotificationType.USAGE_WARNING_5MIN, null);
                    // 同时通知监护人
                    guardianService.notifyGuardians(session.getUserId(),
                        NotificationType.CHILD_USAGE_WARNING, Map.of(
                            "remaining", 5,
                            "limit", rule.getMaxDailyUsageMinutes()
                        ));
                }
                
                // 达到上限强制退出
                if (todayMinutes >= rule.getMaxDailyUsageMinutes()) {
                    forceLogout(session.getUserId(), "达到每日使用时长上限");
                }
            }
        }
    }
    
    private void forceLogout(Long userId, String reason) {

        // 记录审计
```

```java
/**
 * 同意变更事件（通过 Kafka/RabbitMQ 广播）
 */
public record ConsentChangedEvent(
    Long userId,
    ProcessingActivity activity,
    ConsentAction action,    // GRANTED / WITHDRAWN / EXPIRED
    Instant timestamp,
    Map<String, String> metadata
) {}

// 各服务监听并处理
@KafkaListener(topics = "privacy-consent-changed")
public class ConsentEventListener {

    @Autowired private RecommendationEngine recommendationEngine;
    @Autowired private MarketingService marketingService;
    @Autowired private AIService aiService;

    @EventListener
    public void onConsentChanged(ConsentChangedEvent event) {
        switch (event.activity()) {
            case RECOMMENDATION:
                if (event.action() == ConsentAction.WITHDRAWN) {
                    // 停止个性化推荐，降级为热门内容
                    recommendationEngine.disablePersonalization(event.userId());
                }
                break;
                
            case MARKETING_COMMUNICATION:
                if (event.action() == ConsentAction.WITHDRAWN) {
                    // 从所有营销推送列表中移除
                    marketingService.unsubscribeAll(event.userId());
                }
                break;
                
            case AI_TUTORING:
                if (event.action() == ConsentAction.WITHDRAWN) {
                    // 禁用 AI 对话功能，保留历史记录但停止新对话
                    aiService.disableNewConversations(event.userId());
                }
                break;
                
            case BEHAVIORAL_ANALYTICS:
                if (event.action() == ConsentAction.WITHDRAWN) {
                    // 停止行为数据采集
                    analyticsService.stopTracking(event.userId());
                }
                break;
        }
    }
}
```

### 8.2 审计日志完整性验证

```java
/**
 * 审计日志防篡改验证（使用哈希链）
 * 
 * 每条审计日志包含前一条的哈希值，形成链式结构。
 * 任何篡改都会导致后续哈希不匹配。
 */
@Service
public class AuditLogIntegrityService {

    private static final String HASH_ALGORITHM = "SHA-256";

    /**
     * 写入审计日志时计算哈希链
     */
    public PrivacyAuditLog write(PrivacyAuditLog log) {
        // 获取前一条日志的哈希
        PrivacyAuditLog prev = auditRepository.findLatest();
        String prevHash = (prev != null) ? prev.getHashChain() : GENESIS_HASH;
        
        // 计算当前日志的哈希
        String currentData = prevHash + "|" + log.toString();
        String currentHash = Hashing.sha256().hashString(currentData, UTF_8).toString();
        
        log.setHashChain(currentHash);
        log.setPrevHash(prevHash);
        
        return auditRepository.save(log);
    }

    /**
     * 验证审计日志完整性
     */
    public IntegrityResult verify(LocalDate from, LocalDate to) {
        List<PrivacyAuditLog> logs = auditRepository.findByDateRange(from, to);
        
        String expectedPrevHash = null;
        int verified = 0;
        List<IntegrityViolation> violations = new ArrayList<>();
        
        for (PrivacyAuditLog log : logs) {
            if (expectedPrevHash != null && !expectedPrevHash.equals(log.getPrevHash())) {
                violations.add(new IntegrityViolation(log.getId(), "哈希链断裂"));
            }
            
            // 重新计算哈希验证
            String recomputed = recomputeHash(log);
            if (!recomputed.equals(log.getHashChain())) {
                violations.add(new IntegrityViolation(log.getId(), "哈希不匹配，可能被篡改"));
            }
            
            expectedPrevHash = log.getHashChain();
            verified++;
        }
        
        return new IntegrityResult(verified, violations);
    }
}
```

## 10. 性能与容量考量

### 10.1 性能指标

| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 同意检查延迟 | < 5ms (P99) | 每次功能调用前的拦截器开销 |
| DSR 提交响应 | < 500ms | 不含异步处理 |
| 数据导出生成 | < 30min (10万条记录) | 异步处理 |
| 数据清除执行 | < 2h (全量清除) | 跨所有服务 |
| 审计日志写入 | < 10ms | 异步写入，不阻塞主流程 |
| 合规报告生成 | < 5min | 月度定时任务 |

### 10.2 优化策略

1. **同意状态缓存**：用户同意状态高频读取，使用 Redis 缓存，TTL 1 小时，同意变更时主动刷新
2. **审计日志异步写入**：使用消息队列异步写入审计日志，避免阻塞业务线程
3. **DSR 并行处理**：各服务的 DSR 子任务并行执行，通过 CountDownLatch 或 CompletableFuture 等待全部完成
4. **审计日志分区**：按月分区，避免单表数据量过大影响查询性能
5. **数据资产清单缓存**：全量扫描只在低峰期执行，日常使用缓存

## 11. 安全考量

1. **审计日志防篡改**：使用哈希链技术，每条日志包含前一条日志的哈希值
2. **同意证据保全**：监护人同意的截图/日志上传至独立 OSS Bucket，开启 WORM（Write Once Read Many）策略
3. **DSR 身份验证**：所有 DSR 请求必须通过 OTP 或身份证明验证，防止冒充
4. **数据导出安全**：导出文件加密存储，下载链接有效期 7 天，需要独立密码
5. **内部访问控制**：合规人员查看用户数据需要额外审批，记录访问审计
6. **未成年人特殊保护**：年龄判定基于身份证信息（不可自行修改），系统自动触发对应保护级别

| DSR 处理超时 | 距截止日 ≤ 3 天且未完成 | 升级优先级 + 通知处理人 |
| DSR 处理失败 | 子任务 FAILED | 自动重试 3 次后人工介入 |
| 同意检查失败率 | > 1% | 检查缓存与模板配置 |
| 审计日志写入延迟 | > 5 秒 | 检查消息队列积压 |
| 审计日志完整性异常 | 哈希链验证失败 | 紧急安全告警 |
| 未成年人使用超限 | 每日触发次数 > 1000 | 检查防沉迷规则是否需要调整 |
| 数据清除验证失败 | 任何用户清除后仍存在数据 | 立即排查遗漏的数据存储 |

### 14.2 术语表
