> **文档版本**: v1.0  
> **细化日期**: 2026-06-14  
> **所属模块**: 教师端 / 家长端 / 消息系统  
> **优先级**: P1（V1.0 阶段）  
> **依赖模块**: 用户服务、教师班级管理、家长中心、通知中心、消息推送

---

## 1. 模块概述

### 1.1 功能目标

为教师、家长、学生三类角色提供班级级别的沟通协作消息服务，支持：

- **教师 → 家长**：班级公告、作业通知、成绩通知、行为评语、个性化沟通
- **家长 → 教师**：留言咨询、请假申请、回复确认
- **系统 → 家长/学生**：基于班级事件触发的自动通知（作业发布、考试安排等）
- **家长 ↔ 家长**：受限的班级群组互动（点赞、接龙等轻量互动，可选开启）

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 角色隔离 | 教师消息与家长消息有明确的发起方标识和权限边界 |
| 隐私保护 | 家长间不可见对方手机号，仅显示学生姓名+关系 |
| 消息可控 | 教师可撤回、置顶、关闭评论；管理员可审计所有消息 |
| 通知降噪 | 家长可设置接收偏好（全部、仅重要、免打扰时段） |
| 留痕审计 | 所有消息发送、撤回、阅读记录可追溯 |

## 2. 角色与权限模型

### 2.1 角色定义

| 角色 Code | 角色名称 | 权限说明 |
|-----------|----------|----------|
| `TEACHER` | 教师 | 发送公告/通知/私聊，撤回自己的消息，管理消息评论 |
| `HEAD_TEACHER` | 班主任 | 在教师权限基础上，可管理班级消息频道、设置消息置顶 |
| `PARENT` | 家长 | 接收消息，回复评论（如开启），发起与教师的私聊，提交请假 |
| `STUDENT` | 学生 | 只读接收消息（根据学段策略，低年级可能不可见） |
| `ADMIN` | 平台管理员 | 审计查看所有消息，处理投诉举报 |

### 2.2 权限矩阵

| 操作 | TEACHER | HEAD_TEACHER | PARENT | STUDENT | ADMIN |
|------|---------|--------------|--------|---------|-------|
| 发送班级公告 | ✅ | ✅ | ❌ | ❌ | ❌ |

## 3. 数据结构设计

### 3.1 PostgreSQL 表结构

#### 3.1.1 `home_school_channel` — 班级消息频道

```sql
CREATE TABLE home_school_channel (
    id              BIGSERIAL PRIMARY KEY,
    class_id        BIGINT       NOT NULL,          -- 关联 class.id
    channel_type    VARCHAR(20)  NOT NULL,          -- ANNOUNCEMENT / HOMEWORK / GRADE / BEHAVIOR
    name            VARCHAR(100) NOT NULL,          -- 频道显示名称
    description     VARCHAR(500),
    is_active       BOOLEAN      NOT NULL DEFAULT TRUE,
    created_by      BIGINT       NOT NULL,          -- 创建人 user_id
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),

    CONSTRAINT uk_channel_class_type UNIQUE (class_id, channel_type)
);

CREATE INDEX idx_channel_class ON home_school_channel (class_id) WHERE is_active = TRUE;
```

#### 3.1.2 `home_school_message` — 消息主表

```sql
CREATE TABLE home_school_message (
    id              BIGSERIAL PRIMARY KEY,
    channel_id      BIGINT       NOT NULL,          -- 关联 home_school_channel.id
    class_id        BIGINT       NOT NULL,          -- 冗余, 便于查询
    sender_id       BIGINT       NOT NULL,          -- 发送人 user_id
    sender_role     VARCHAR(20)  NOT NULL,          -- TEACHER / HEAD_TEACHER / SYSTEM
    message_type    VARCHAR(20)  NOT NULL,          -- TEXT / RICH_TEXT / IMAGE / VOICE / EVENT_CARD
    title           VARCHAR(200),                   -- 消息标题（公告/通知必填）
    content         TEXT         NOT NULL,          -- 消息正文（富文本/纯文本）
    content_summary VARCHAR(500),                   -- 消息摘要（用于推送通知）
    attachments     JSONB        DEFAULT '[]',      -- 附件列表 [{type, url, name, size}]
    ref_type        VARCHAR(30),                    -- 关联业务类型: HOMEWORK / EXAM / PLAN
    ref_id          BIGINT,                         -- 关联业务 ID
    is_pinned       BOOLEAN      NOT NULL DEFAULT FALSE,
    is_commentable  BOOLEAN      NOT NULL DEFAULT TRUE,
    comment_mode    VARCHAR(20)  NOT NULL DEFAULT 'OPEN', -- OPEN / CLOSED / TEACHER_ONLY
    status          VARCHAR(20)  NOT NULL DEFAULT 'PUBLISHED', -- PUBLISHED / WITHDRAWN / DRAFT
    withdraw_reason VARCHAR(200),
    published_at    TIMESTAMPTZ,                    -- 发布时间（草稿可为 NULL）
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    withdrawn_at    TIMESTAMPTZ,

    CONSTRAINT chk_message_status CHECK (status IN ('DRAFT', 'PUBLISHED', 'WITHDRAWN'))
);

-- 核心查询索引
CREATE INDEX idx_msg_channel_status ON home_school_message (channel_id, status, published_at DESC);
CREATE INDEX idx_msg_class_status ON home_school_message (class_id, status, published_at DESC);
CREATE INDEX idx_msg_sender ON home_school_message (sender_id, created_at DESC);
CREATE INDEX idx_msg_ref ON home_school_message (ref_type, ref_id) WHERE ref_type IS NOT NULL;
```

#### 3.1.3 `home_school_message_read` — 消息已读记录

```sql
CREATE TABLE home_school_message_read (
    id              BIGSERIAL PRIMARY KEY,
    message_id      BIGINT       NOT NULL,
    user_id         BIGINT       NOT NULL,
    read_at         TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    read_channel    VARCHAR(20)  NOT NULL,          -- APP / PUSH / WEB

    CONSTRAINT uk_msg_user_read UNIQUE (message_id, user_id)
);

CREATE INDEX idx_read_user ON home_school_message_read (user_id);
```

#### 3.1.4 `home_school_comment` — 消息评论/回复

```sql
CREATE TABLE home_school_comment (
    id              BIGSERIAL PRIMARY KEY,
    message_id      BIGINT       NOT NULL,
    parent_id       BIGINT,                         -- 父评论 ID（支持二级回复）
    author_id       BIGINT       NOT NULL,
    author_role     VARCHAR(20)  NOT NULL,          -- TEACHER / PARENT
    content         VARCHAR(500) NOT NULL,          -- 评论内容（限制 500 字）
    author_name     VARCHAR(50)  NOT NULL,          -- 冗余：展示用名称
    like_count      INT          NOT NULL DEFAULT 0,
    status          VARCHAR(20)  NOT NULL DEFAULT 'NORMAL', -- NORMAL / DELETED / HIDDEN
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_comment_message ON home_school_comment (message_id, status, created_at);
```

#### 3.1.5 `home_school_private_session` — 师友私聊会话

```sql
CREATE TABLE home_school_private_session (
    id              BIGSERIAL PRIMARY KEY,
    class_id        BIGINT       NOT NULL,
    teacher_id      BIGINT       NOT NULL,
    parent_id       BIGINT       NOT NULL,
    student_id      BIGINT       NOT NULL,          -- 关联学生（一个家长可能多个孩子）
    last_message_at TIMESTAMPTZ,
    last_message_sn VARCHAR(100),                   -- 最后一条消息摘要
    unread_by_teacher  INT  NOT NULL DEFAULT 0,
    unread_by_parent   INT  NOT NULL DEFAULT 0,
    status          VARCHAR(20)  NOT NULL DEFAULT 'ACTIVE', -- ACTIVE / ARCHIVED
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),

    CONSTRAINT uk_session UNIQUE (class_id, teacher_id, parent_id, student_id)
);

CREATE INDEX idx_session_teacher ON home_school_private_session (teacher_id, status, last_message_at DESC);
CREATE INDEX idx_session_parent ON home_school_private_session (parent_id, status, last_message_at DESC);
```

#### 3.1.6 `home_school_private_message` — 私聊消息

```sql
CREATE TABLE home_school_private_message (
    id              BIGSERIAL PRIMARY KEY,
    session_id      BIGINT       NOT NULL,
    sender_id       BIGINT       NOT NULL,
    sender_role     VARCHAR(20)  NOT NULL,          -- TEACHER / PARENT
    content         TEXT         NOT NULL,
    message_type    VARCHAR(20)  NOT NULL DEFAULT 'TEXT', -- TEXT / IMAGE / VOICE / SYSTEM
    attachments     JSONB        DEFAULT '[]',
    status          VARCHAR(20)  NOT NULL DEFAULT 'SENT', -- SENT / READ / WITHDRAWN
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    read_at         TIMESTAMPTZ,

    CONSTRAINT chk_pm_status CHECK (status IN ('SENT', 'READ', 'WITHDRAWN'))
);

CREATE INDEX idx_pm_session ON home_school_private_message (session_id, created_at);
CREATE INDEX idx_pm_sender ON home_school_private_message (sender_id, created_at DESC);
```

#### 3.1.7 `home_school_leave_request` — 请假申请

```sql
CREATE TABLE home_school_leave_request (
    id              BIGSERIAL PRIMARY KEY,
    class_id        BIGINT       NOT NULL,
    student_id      BIGINT       NOT NULL,
    parent_id       BIGINT       NOT NULL,          -- 提交人
    leave_type      VARCHAR(20)  NOT NULL,          -- SICK / PERSONAL / FAMILY / OTHER
    start_date      DATE         NOT NULL,
    end_date        DATE         NOT NULL,
    reason          VARCHAR(500) NOT NULL,
    attachment_url  VARCHAR(500),                   -- 病假证明等附件
    status          VARCHAR(20)  NOT NULL DEFAULT 'PENDING', -- PENDING / APPROVED / REJECTED / CANCELLED
    reviewer_id     BIGINT,                         -- 审批人（教师）
    review_comment  VARCHAR(200),
    reviewed_at     TIMESTAMPTZ,
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),

    CONSTRAINT chk_leave_status CHECK (status IN ('PENDING', 'APPROVED', 'REJECTED', 'CANCELLED')),
    CONSTRAINT chk_leave_dates CHECK (end_date >= start_date)
);

CREATE INDEX idx_leave_class_status ON home_school_leave_request (class_id, status, created_at DESC);
CREATE INDEX idx_leave_parent ON home_school_leave_request (parent_id, created_at DESC);
```

#### 3.1.8 `home_school_preference` — 用户消息偏好

```sql
CREATE TABLE home_school_preference (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT       NOT NULL UNIQUE,
    class_id        BIGINT,                         -- NULL 表示全局设置
    receive_level   VARCHAR(20)  NOT NULL DEFAULT 'ALL', -- ALL / IMPORTANT_ONLY / MUTE
    mute_start      TIME,                            -- 免打扰开始时间
    mute_end        TIME,                            -- 免打扰结束时间
    channels        JSONB        DEFAULT '["ANNOUNCEMENT","HOMEWORK","GRADE","BEHAVIOR"]',
    push_enabled    BOOLEAN      NOT NULL DEFAULT TRUE,
    digest_mode     BOOLEAN      NOT NULL DEFAULT FALSE, -- 汇总推送模式
    digest_time     TIME         DEFAULT '18:00:00',
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE UNIQUE INDEX uk_pref_user_class ON home_school_preference (user_id, COALESCE(class_id, 0));
```

### 3.2 Redis 数据结构

#### 3.2.1 未读消息计数

```redis
# 班级频道未读计数
HSET hs:unread:class:{class_id}:{user_id} {channel_type} {count}

# 私聊未读计数
SET hs:unread:pm:{user_id} {total_count}
EXPIRE hs:unread:pm:{user_id} 604800  ;  7天过期

# 全局未读汇总（用于首页小红点）
SET hs:unread:total:{user_id} {total}
EXPIRE hs:unread:total:{user_id} 86400
```

#### 3.2.2 消息发布扇出队列

```redis
# 班级消息发布任务
LPUSH hs:fanout:queue {task_json}

# 格式：
# {"message_id": 123, "class_id": 456, "channel_type": "ANNOUNCEMENT", "recipient_count": 48}
```

#### 3.2.3 消息发布频率限制

```redis
# 教师每日发送限制
INCR hs:daily_limit:{teacher_id}:{date}
EXPIRE hs:daily_limit:{teacher_id}:{date} 90000  ;  25小时
```

## 4. API 接口设计

### 4.1 班级消息（公告/通知）

#### 4.1.1 发送班级消息

```
POST /api/v1/home-school/classes/{classId}/messages
```

**请求体:**
```json
{
  "channelType": "ANNOUNCEMENT",
  "messageType": "RICH_TEXT",
  "title": "关于下周二期中考试的通知",
  "content": "<p>各位家长好，下周二（X月X日）将进行期中考试...</p>",
  "contentSummary": "下周二期中考试通知，请家长督促孩子复习",
  "attachments": [
    {
      "type": "IMAGE",
      "url": "https://cdn.primetop.com/edu/exam-notice.png",
      "name": "考试安排表",
      "size": 102400
    }
  ],
  "refType": "EXAM",
  "refId": 10086,
  "commentMode": "OPEN",
  "publishNow": true
}
```

**响应体 (201 Created):**
```json
{
  "code": 0,
  "data": {
    "messageId": 20001,
    "channelId": 301,
    "status": "PUBLISHED",
    "publishedAt": "2026-06-14T15:00:00.000Z",
    "recipientCount": 48
  }
}
```

**校验规则:**
- `title`: 1~200 字符，公告和成绩通知必填
- `content`: 1~10000 字符
- `contentSummary`: 自动截取前 200 字符（如未传）
- `attachments`: 最多 9 个附件，单个 ≤ 20MB
- 教师每日发送上限：50 条/班级（防误操作/刷屏）

**错误码:**
| 错误码 | 说明 |
|--------|------|
| `HS_001` | 无权对该班级发送消息 |
| `HS_002` | 频道不存在或已关闭 |
| `HS_003` | 超出当日发送限制 |
| `HS_004` | 内容包含敏感词 |
| `HS_005` | 附件大小超限 |

#### 4.1.4 撤回消息

```
PUT /api/v1/home-school/messages/{messageId}/withdraw
```

**请求体:**
```json
{
  "reason": "内容有误，已更新"
}
```

**业务规则:**
- 仅发送人或班主任可撤回
- 撤回后消息内容不可见，但保留撤回记录
- 撤回时间限制：发布后 48 小时内
- 撤回后触发推送通知「XX老师撤回了一条消息」

#### 4.1.5 置顶/取消置顶消息

```
PUT /api/v1/home-school/messages/{messageId}/pin

```

### 4.2 消息评论

#### 4.2.1 发表评论

```
POST /api/v1/home-school/messages/{messageId}/comments
```

**请求体:**
```json
{
  "content": "收到，会提醒孩子好好复习",
  "parentId": null
}
```

**业务规则:**
- 校验消息 `commentMode`：
  - `OPEN`: 所有人可评论
  - `TEACHER_ONLY`: 仅教师可评论
  - `CLOSED`: 不可评论
- 评论内容 1~500 字符
- 敏感词过滤
- 最多支持二级回复（parent_id 只能指向一级评论）

#### 4.2.2 查询评论列表

```
GET /api/v1/home-school/messages/{messageId}/comments?page=1&size=50
```

#### 4.2.3 删除评论

```
DELETE /api/v1/home-school/comments/{commentId}
```

**权限**: 评论作者本人、班主任、管理员可删除

### 5.2 消息扇出（Fan-out）异步处理

```java
/**
 * 消息扇出消费者 — 处理班级消息的批量投递
 */
@Component
public class MessageFanoutConsumer {

    @RabbitListener(queues = "hs.fanout.queue")
    public void handleFanoutTask(MessageFanoutTask task) {
        Long messageId = task.getMessageId();
        Long classId = task.getClassId();

        // 1. 获取班级成员列表（家长）
        List<ClassMember> members = classService.getClassParents(classId);

        // 2. 批量初始化未读计数（Redis Hash）
        String key = String.format("hs:unread:class:%d", classId);
        for (ClassMember m : members) {
            redisTemplate.opsForHash().increment(
                key + ":" + m.getUserId(),
                task.getChannelType(),
                1
            );
        }

        // 3. 更新全局未读汇总
        for (ClassMember m : members) {
            redisTemplate.opsForValue().increment(
                String.format("hs:unread:total:%d", m.getUserId())
            );
        }

        // 4. 按用户偏好过滤后调用推送服务
        List<PushTarget> pushTargets = members.stream()
            .filter(m -> shouldPush(m.getUserId(), task))
            .map(m -> buildPushTarget(m, task))
            .collect(Collectors.toList());

        pushService.batchSend(pushTargets);

        // 5. 更新消息接收人数
        messageMapper.updateRecipientCount(messageId, members.size());

        log.info("Fanout completed: messageId={}, recipients={}", messageId, members.size());
    }

    /**
     * 判断是否需要推送（根据用户偏好）
     */
    private boolean shouldPush(Long userId, MessageFanoutTask task) {
        HomeSchoolPreference pref = getPreference(userId);
        if (pref == null) return true; // 默认推送

        if ("MUTE".equals(pref.getReceiveLevel())) return false;

        // 检查免打扰时段
        if (isInMuteTime(pref)) {
            // 重要消息（成绩、行为评语）仍然推送
            if ("IMPORTANT_ONLY".equals(pref.getReceiveLevel())
                && !isImportantChannel(task.getChannelType())) {
                return false;
            }
        }

        // 检查是否订阅了该频道
        if (!pref.getChannels().contains(task.getChannelType())) {
            return false;
        }

        return pref.isPushEnabled();
    }
}
```

### 5.3 消息撤回流程

```java
/**
 * 撤回消息
 */
@Transactional
public void withdrawMessage(Long messageId, Long operatorId, String reason) {
    HomeSchoolMessage message = messageMapper.selectById(messageId);
    if (message == null || !"PUBLISHED".equals(message.getStatus())) {
        throw new BizException("HS_010", "消息不存在或非发布状态");
    }

    // 权限校验：发送人或班主任
    if (!message.getSenderId().equals(operatorId)) {
        boolean isHeadTeacher = classService.isHeadTeacher(message.getClassId(), operatorId);
        if (!isHeadTeacher) {
            throw new BizException("HS_011", "无权撤回他人消息");
        }
    }

    // 时间校验：48小时内
    Duration since = Duration.between(message.getPublishedAt(), Instant.now());
    if (since.toHours() >= 48) {
        throw new BizException("HS_012", "超过48小时不可撤回");
    }

    // 更新消息状态
    message.setStatus("WITHDRAWN");
    message.setWithdrawReason(reason);
    message.setWithdrawnAt(Instant.now());
    messageMapper.updateById(message);

    // 发送撤回通知（不携带原消息内容）
    sendWithdrawNotification(message);

    // 记录审计日志
    auditLogService.log(
        operatorId, "MESSAGE_WITHDRAW",
        Map.of("messageId", messageId, "reason", reason)
    );
}
```

/**

@Transactional
public PrivateSessionVO createOrGetSession(Long parentId, Long teacherId, Long studentId) {

    if (!parentService.isParentOf(parentId, studentId)) {

    }

    }

    // 3. 查找或创建会话
    HomeSchoolPrivateSession session = sessionMapper.findBy(
        classInfo.getId(), teacherId, parentId, studentId
    );

    if (session == null) {
        session = new HomeSchoolPrivateSession();
        session.setClassId(classInfo.getId());
        session.setTeacherId(teacherId);
        session.setParentId(parentId);
        session.setStudentId(studentId);
        session.setStatus("ACTIVE");
        sessionMapper.insert(session);
    }

    // 4. 若会话被归档，重新激活
    if ("ARCHIVED".equals(session.getStatus())) {
        session.setStatus("ACTIVE");
        sessionMapper.updateById(session);
    }

    return toVO(session);
}

## 7. 安全与合规

### 7.1 敏感词过滤

消息发送前必须经过敏感词过滤，采用多级过滤策略：

```java
/**
 * 多级敏感词过滤
 */
@Component
public class MessageContentFilter {

    @Autowired
    private TrieFilter politicalFilter;   // 政治敏感词
    @Autowired
    private TrieFilter profanityFilter;   // 脏话/不当言论
    @Autowired
    private TrieFilter contactFilter;     // 联系方式（手机号、微信号等）

    public FilterResult filter(String content, Long senderId) {
        // 1. 政治敏感词 → 直接拦截
        if (politicalFilter.contains(content)) {
            return FilterResult.blocked("包含违规内容");
        }

        // 2. 脏话/不当言论 → 替换为 ***
        String filtered = profanityFilter.replace(content, "***");

        // 3. 联系方式检测（家长间不可交换联系方式）
        if (contactFilter.contains(filtered)) {
            // 私聊中允许（师友间），公告中拦截
            return FilterResult.warn("检测到可能的联系方式");
        }

        return FilterResult.pass(filtered);
    }
}
```

### 7.2 隐私保护

- 家长在班级消息中展示名}- 家长在班级消息中展示名称为 `{学生姓名}+{关系}`（如"张小明妈妈"），不展示手机号
- 私聊双方仅可见对方的昵称和头像，不展示真实手机号
- 教师可查看家长绑定的学生列表，但不可查看其他学生信息
- 所有消息数据保留 2 年，超期自动归档冷存储
- 家长退出班级后，历史消息变为不可见，但数据保留审计

### 7.3 审计要求

| 审计事件 | 记录内容 | 保留期限 |
|----------|----------|----------|
| 消息发送 | senderId, messageId, channelType, contentHash | 2年 |

| 评论删除 | operatorId, commentId, originalHash | 1年 |
| 请假审批 | reviewerId, requestId, action | 5年 |
| 举报投诉 | reporterId, targetId, reason, handleResult | 3年 |

### 14.2 数据脱敏规则

| 字段 | 存储形式 | 展示形式 | 说明 |
|------|----------|----------|------|
| 家长手机号 | 加密存储 | 不展示 | 仅后台管理员可见 |
| 家长名称 | 不存储真实姓名 | `{学生名}+{关系}` | 隐私保护 |
| 教师手机号 | 加密存储 | 不展示 | 仅管理员可见 |
| 私聊内容 | 明文存储 | 原文展示 | 仅会话双方可见 |
| 请假原因 | 明文存储 | 仅教师和管理员可见 | 家长自己可见 |
