## 1. 模块概述

### 1.1 定位

请求参数校验与数据清洗是 PrimeTop 服务端的**横切基础设施**，位于 HTTP 请求处理管线的最前端，负责：

1. **参数校验（Validation）**：验证请求参数的类型、格式、范围、长度、业务约束，拒绝不合法请求
2. **数据清洗（Sanitization）**：对合法参数进行标准化、去噪、转义处理，消除安全隐患
3. **统一错误响应**：校验失败时返回结构化的字段级错误信息，帮助客户端快速定位问题
4. **业务规则前置**：将部分跨模块的业务约束（如学段-年级-学科合法性）封装为可复用的校验器

### 1.2 为什么需要统一规范

| 痛点 | 影响 | 解决方案 |
|------|------|---------|
| 各服务校验逻辑不一致 | A 服务返回 400 + 字符串，B 服务返回 200 + 错误码 | 统一校验框架 + 标准错误响应 |
| SQL 注入 / XSS 残留 | 手动拼接 SQL 的地方容易遗漏转义 | 自动清洗管道 + ORM 参数化 |
| 业务校验散落在 Service 层 | Controller 臃肿，重复代码多 | 声明式校验注解 + 校验器注册表 |
| 字段级错误信息不明确 | 客户端只收到 "参数错误"，无法定位哪个字段 | 字段级错误码 + 描述 |
| 嵌套对象 / 列表校验遗漏 | 批量接口中部分项无效导致整体失败 | 递归校验 + 部分失败模式 |
| 测试覆盖不足 | 校验逻辑散落各处，难以统一测试 | 校验器单元测试 + 集成测试矩阵 |

### 1.3 设计原则

1. **声明式优先**：用 Pydantic Field / 自定义注解声明约束，避免手写 if-else
2. **清洗先于校验**：先 trim / normalize，再校验规则，避免空格或大小写导致误拒
3. **快速失败 + 聚合错误**：单个请求收集所有字段错误后一次返回，而非逐字段报错
4. **最小暴露原则**：校验错误消息不泄露内部结构（表名、列名、堆栈）
5. **可扩展**：自定义校验器通过注册表接入，不修改框架代码

### 1.4 技术选型

| 组件 | 选择 | 理由 |
|------|------|------|
| 请求模型 | Pydantic V2 BaseModel | FastAPI 原生集成，自动 JSON Schema，高性能 Rust 内核 |
| 校验框架 | Pydantic Validator + 自定义 Annotated 类型 | 声明式、可组合、类型安全 |
| 清洗管线 | Pydantic model_validator + field_validator | 在模型层面统一处理 |
| 错误格式 | RFC 7807 (Problem Details) 扩展 | 业界标准，可扩展字段级详情 |

## 3. 基础模型与通用清洗

### 3.1 BaseModel 基类

所有请求模型继承 `RequestBaseModel`，自动获得通用清洗能力。

```python
# app/schemas/base.py
from pydantic import BaseModel, ConfigDict
from typing import Any


class RequestBaseModel(BaseModel):
    """所有 API 请求模型的基类。

    - 自动拒绝未知字段（防止注入额外参数）
    - 自动 trim 所有字符串字段
    - JSON 输出使用 camelCase（匹配前端规范）
    """

    model_config = ConfigDict(
        extra="forbid",           # 禁止传入未定义字段
        str_strip_whitespace=True, # 自动 trim 字符串
        str_min_length=1,          # 空字符串视为无效（除非字段 Optional）
        populate_by_name=True,     # 允许通过字段名或 alias 赋值
        # 前端使用 camelCase，后端使用 snake_case
        alias_generator=lambda field_name: _to_camel(field_name),
    )


class ResponseBaseModel(BaseModel):
    """所有 API 响应模型的基类。"""

    model_config = ConfigDict(
        alias_generator=lambda field_name: _to_camel(field_name),
        populate_by_name=True,
    )


def _to_camel(name: str) -> str:
    """snake_case → camelCase"""
    parts = name.split("_")
    return parts[0] + "".join(word.capitalize() for word in parts[1:])
```

### 3.2 通用清洗函数

```python
# app/core/validation/cleaners.py
import re
import html
from typing import Optional


def trim(value: Optional[str]) -> Optional[str]:
    """去除首尾空白字符（包括 Unicode 空白）"""
    if value is None:
        return None
    return value.strip()


def normalize_whitespace(value: Optional[str]) -> Optional[str]:
    """将连续空白字符合并为单个空格"""
    if value is None:
        return None
    return re.sub(r"\s+", " ", value.strip())


def sanitize_html(value: Optional[str]) -> Optional[str]:
    """转义 HTML 特殊字符，防止 XSS"""
    if value is None:
        return None
    return html.escape(value, quote=True)


def sanitize_sql_like(value: Optional[str]) -> Optional[str]:
    """转义 SQL LIKE 通配符（用于搜索场景）"""
    if value is None:
        return None
    # 转义 % _ \ 等特殊字符
    return value.replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_")


def normalize_phone(value: Optional[str]) -> Optional[str]:
    """手机号标准化：去除所有非数字字符"""
    if value is None:
        return None
    return re.sub(r"[^\d+]", "", value)


def normalize_grade_code(value: Optional[str]) -> Optional[str]:
    """年级代码标准化：大写 + 去空格"""
    if value is None:
        return None
    return value.strip().upper()


def sanitize_path(value: Optional[str]) -> Optional[str]:
    """路径清洗：防止路径遍历攻击"""
    if value is None:
        return None
    # 去除 ../ 和 ..\ 等路径遍历
    cleaned = re.sub(r"\.\.", "", value)
    # 去除连续斜杠
    cleaned = re.sub(r"[/\\]+", "/", cleaned)
    return cleaned.strip("/")


def clamp(value: int, min_val: int, max_val: int) -> int:
    """将数值限制在指定范围内"""
    return max(min_val, min(max_val, value))


def truncate(value: Optional[str], max_length: int) -> Optional[str]:
    """截断超长字符串"""
    if value is None:
        return None
    if len(value) <= max_length:
        return value
    return value[:max_length]
```

## 4. 自定义校验类型（Annotated Types）

### 4.1 设计思路

通过 `Annotated[base_type, ...]` 将校验规则编码到类型系统中，实现声明式校验。开发者只需用类型标注即可获得完整的校验 + 清洗能力。

### 4.2 通用类型

```python
# app/core/validation/types.py
from typing import Annotated, Optional
from pydantic import (
    Field,
    StringConstraints,
    BeforeValidator,
    AfterValidator,
    PlainValidator,
)
import re
from .cleaners import (
    normalize_phone,
    normalize_whitespace,
    sanitize_html,
    truncate,
)

# ============================================================
# 通用字符串类型
# ============================================================

# 非空字符串（自动 trim，1-255 字符）
NonEmptyStr = Annotated[
    str,
    StringConstraints(strip_whitespace=True, min_length=1, max_length=255),
]

# 短文本（1-50 字符，如用户名、标题）
ShortStr = Annotated[
    str,
    StringConstraints(strip_whitespace=True, min_length=1, max_length=50),
]

# 长文本（1-10000 字符，如问题描述、作文内容）
LongStr = Annotated[
    str,
    StringConstraints(strip_whitespace=True, min_length=1, max_length=10000),
]

# 超长文本（1-50000 字符，如作文全文）
ExtraLongStr = Annotated[
    str,
    StringConstraints(strip_whitespace=True, min_length=1, max_length=50000),
]

# HTML 安全字符串（自动转义 HTML）
SafeHtmlStr = Annotated[
    str,
    StringConstraints(strip_whitespace=True, min_length=1, max_length=10000),
    AfterValidator(sanitize_html),
]

# 搜索关键词（清洗后 1-100 字符）
SearchKeyword = Annotated[
    str,
    BeforeValidator(lambda v: normalize_whitespace(v)),
    StringConstraints(min_length=1, max_length=100),
]

# ============================================================
# 手机号类型
# ============================================================

def _validate_phone_cn(v: str) -> str:
    """中国大陆手机号校验"""
    normalized = normalize_phone(v)
    pattern = r"^(\+?86)?1[3-9]\d{9}$"
    if not re.match(pattern, normalized):
        raise ValueError("手机号格式不正确，请输入11位中国大陆手机号")
    # 标准化为纯 11 位
    if normalized.startswith("+86"):
        normalized = normalized[3:]
    elif normalized.startswith("86"):
        normalized = normalized[2:]
    return normalized

PhoneCn = Annotated[str, BeforeValidator(_validate_phone_cn)]

# 可选手机号
OptionalPhoneCn = Annotated[Optional[str], BeforeValidator(lambda v: _validate_phone_cn(v) if v else None)]

# ============================================================
# 邮箱类型
# ============================================================

from pydantic import EmailStr  # Pydantic 内置邮箱校验

# ============================================================
# 身份证号类型
# ============================================================

def _validate_id_card(v: str) -> str:
    """中国大陆身份证号校验（18 位）"""
    v = v.strip().upper()
    if not re.match(r"^\d{17}[\dX]$", v):
        raise ValueError("身份证号格式不正确")
    # 校验位验证
    weights = [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2]
    check_codes = "10X98765432"
    total = sum(int(v[i]) * weights[i] for i in range(17))
    if check_codes[total % 11] != v[17]:
        raise ValueError("身份证号校验位不正确")
    return v

IdCardCn = Annotated[str, BeforeValidator(_validate_id_card)]

# ============================================================
# URL 类型
# ============================================================

def _validate_safe_url(v: str) -> str:
    """安全 URL 校验（防止 javascript: / data: 等协议注入）"""
    v = v.strip()
    lower = v.lower()
    blocked_protocols = ["javascript:", "data:", "vbscript:", "file:"]
    for proto in blocked_protocols:
        if lower.startswith(proto):
            raise ValueError(f"不允许的 URL 协议: {proto}")
    if not re.match(r"^https?://", lower):
        raise ValueError("URL 必须以 http:// 或 https:// 开头")
    return v

SafeUrl = Annotated[str, BeforeValidator(_validate_safe_url)]

# ============================================================
# 分页类型
# ============================================================

PageNum = Annotated[int, Field(ge=1, description="页码，从1开始")]
PageSize = Annotated[int, Field(ge=1, le=100, description="每页数量，最大100")]

# ============================================================
# ID 类型
# ============================================================

# 正整数 ID
PositiveId = Annotated[int, Field(gt=0, description="正整数 ID")]

# 可选正整数 ID
OptionalPositiveId = Annotated[Optional[int], Field(default=None, gt=0)]
```

```python
# 枚举类型通用构造器

from enum import Enum
from typing import Type

def enum_type(enum_cls: Type[Enum], *, case_sensitive: bool = False) -> type:
    """为任意 Enum 类生成 Annotated 校验类型。

    用法:
        MyEnumType = enum_type(MyEnum, case_sensitive=False)
        field: MyEnumType
    """
    valid_values = [e.value for e in enum_cls]
    
    def _validate(v):
        check = v if case_sensitive else v.lower()
        for e in enum_cls:
            ev = e.value if case_sensitive else e.value.lower()
            if check == ev:
                return e.value  # 返回原始枚举值
        raise ValueError(
            f"无效值: '{v}'，可选值: {', '.join(str(x) for x in valid_values)}"
        )
    
    return Annotated[str, BeforeValidator(lambda v: v.strip()), PlainValidator(_validate)]
```

## 5. 校验错误响应规范

### 5.1 错误响应模型

```python
# app/core/validation/exceptions.py
from typing import Optional
from pydantic import BaseModel, Field
from fastapi import Request
from fastapi.responses import JSONResponse
from fastapi.exceptions import RequestValidationError


class FieldError(BaseModel):
    """单个字段的校验错误详情"""
    field: str = Field(..., description="字段路径（dot notation），如 'address.city'")
    code: str = Field(..., description="错误码，如 'required', 'min_length', 'invalid_format'")
    message: str = Field(..., description="面向开发者的错误描述（中文）")
    rejected_value: Optional[str] = Field(
        None,
        description="被拒绝的值（脱敏后），帮助调试。敏感字段不返回",
    )


class ValidationErrorResponse(BaseModel):
    """校验错误标准响应体（兼容 RFC 7807 Problem Details 扩展）"""
    type: str = "https://primtop.com/errors/validation"
    title: str = "请求参数校验失败"
```

```python
# app/core/validation/exceptions.py (续)

import logging
from pydantic_core import ValidationError as PydanticValidationError

logger = logging.getLogger(__name__)

# 字段路径映射：Pydantic 的字段名 → 前端 camelCase
_ALIAS_MAP_CACHE: dict[str, str] = {}


def _pydantic_error_to_field_error(error: dict) -> FieldError:
    """将 Pydantic 的单个错误转换为 FieldError"""
    loc = error.get("loc", ())
    msg = error.get("msg", "")
    error_type = error.get("type", "")
    input_val = error.get("input")
    
    # 构建字段路径（dot notation）
    # loc 示例: ('body', 'student_profile', 'grade_code')
    field_parts = [str(p) for p in loc if p != "body" and not isinstance(p, int)]
    field_path = ".".join(field_parts) if field_parts else "root"
    
    # 映射错误类型到错误码
    code = _map_error_type_to_code(error_type, msg)
    
    # 脱敏被拒绝的值
    rejected = _safe_repr(input_val, field_path)
    
    return FieldError(
        field=field_path,
        code=code,
        message=msg,
        rejected_value=rejected,
    )


def _map_error_type_to_code(error_type: str, msg: str) -> str:
    """将 Pydantic 错误类型映射到业务错误码"""
    mapping = {
        "missing": "required",
        "value_error": "invalid_format",
        "string_type": "type_error",
        "int_type": "type_error",
        "float_type": "type_error",
        "bool_type": "type_error",
        "list_type": "type_error",
        "string_too_short": "min_length",
        "string_too_long": "max_length",
        "string_pattern_mismatch": "pattern",
        "too_short": "min_length",
        "too_long": "max_length",
        "greater_than": "gt",
        "greater_than_equal": "ge",
        "less_than": "lt",
        "less_than_equal": "le",
        "multiple_of": "multiple_of",
        "frozen_field": "unknown_field",
        "extra_forbidden": "unknown_field",
        "enum": "invalid_enum_value",
        "value_error": "invalid_format",
    }
    
    # 先按 msg 关键词匹配业务错误
    msg_lower = msg.lower()
    business_keywords = {
        "手机号": "invalid_phone",
        "身份证": "invalid_id_card",
        "邮箱": "invalid_email",
        "url": "invalid_url",
        "学段": "invalid_stage",
        "年级": "invalid_grade",
        "学科": "invalid_subject",
        "教材": "invalid_textbook",
        "题目类型": "invalid_question_type",
        "不安全": "unsafe_content",
        "路径": "path_traversal",
    }
    for kw, code in business_keywords.items():
        if kw in msg_lower or kw in msg:
            return code
    
    return mapping.get(error_type, "invalid_format")


def _safe_repr(value, field_path: str) -> Optional[str]:
    """脱敏后的值表示（最多展示 50 字符，敏感字段完全隐藏）"""
    if value is None:
        return None
    
    # 敏感字段不返回值
    sensitive_fields = {"password", "phone", "id_card", "token", "secret"}
    if any(sf in field_path.lower() for sf in sensitive_fields):
        return "***"
    
    repr_val = str(value)
    if len(repr_val) > 50:
        return repr_val[:50] + "..."
    return repr_val


async def validation_exception_handler(
    request: Request,
    exc: RequestValidationError,
) -> JSONResponse:
    """FastAPI 全局校验异常处理器"""
    errors = exc.errors()
    field_errors = [_pydantic_error_to_field_error(e) for e in errors]
    
    # 获取 trace_id（从中间件注入）
    trace_id = getattr(request.state, "trace_id", None)
    
    response = ValidationErrorResponse(
        detail=f"{len(field_errors)}个字段校验失败",
        errors=field_errors,
        trace_id=trace_id,
    )
    
    logger.warning(
        "Validation failed: %s [%s] errors=%s",
        request.method,
        request.url.path,
        [{"field": e.field, "code": e.code} for e in field_errors],
    )
    
    return JSONResponse(
        status_code=422,
        content=response.model_dump(by_alias=True, exclude_none=True),
    )
```

```python
# app/core/validation/rules.py
from pydantic import model_validator


class StageGradeMixin:
    """学段-年级合法性校验 Mixin。
    
    用于所有包含 stage + gradeCode 字段的请求模型。
    """

    @model_validator(mode="after")
    def validate_stage_grade_consistency(self) -> "StageGradeMixin":
        stage = getattr(self, "stage", None)
        grade_code = getattr(self, "grade_code", None)
        
        if stage and grade_code:
            from .types import STAGE_GRADE_MAP
            
            valid_grades = STAGE_GRADE_MAP.get(stage, set())
            if grade_code not in valid_grades:
                raise ValueError(
                    f"年级 '{grade_code}' 不属于学段 '{stage}'，"
                    f"该学段可选年级: {', '.join(sorted(valid_grades))}"
                )
        return self


class SubjectStageMixin:
    """学科-学段合法性校验 Mixin。
    
    某些学科仅在特定学段有效（如物理仅在初中及以上）。
    """

    # 学科 → 最低学段
    SUBJECT_MIN_STAGE = {
        "physics": "junior",
        "chemistry": "junior",
        "history": "junior",
        "geography": "junior",
        "politics": "junior",
        "biology": "junior",
        "science": "primary",
    }
    
    STAGE_ORDER = {"kindergarten": 0, "primary": 1, "junior": 2, "senior": 3}

    @model_validator(mode="after")
    def validate_subject_stage(self) -> "SubjectStageMixin":
        stage = getattr(self, "stage", None)
        subject = getattr(self, "subject", None)
        
        if stage and subject:
            min_stage = self.SUBJECT_MIN_STAGE.get(subject)
            if min_stage and self.STAGE_ORDER.get(stage, 0) < self.STAGE_ORDER.get(min_stage, 0):
                raise ValueError(
                    f"学科 '{subject}' 仅在 {min_stage} 及以上学段提供"
                )
        return self


class PaginationOrderMixin:
    """分页排序字段合法性校验 Mixin。"""

    # 子类定义：允许排序的字段白名单
    ALLOWED_SORT_FIELDS: set[str] = set()

    @model_validator(mode="after")
    def validate_sort_field(self) -> "PaginationOrderMixin":
        sort_field = getattr(self, "sort_field", None)
        if sort_field and self.ALLOWED_SORT_FIELDS:
            if sort_field not in self.ALLOWED_SORT_FIELDS:
                raise ValueError(
                    f"不允许的排序字段: '{sort_field}'，"
                    f"可选: {', '.join(sorted(self.ALLOWED_SORT_FIELDS))}"
                )
        return self
```

## 8. 安全清洗策略

### 8.1 注入防护矩阵

| 攻击类型 | 防护层 | 实现方式 |
|---------|--------|---------|
| SQL 注入 | ORM 参数化 | SQLAlchemy 2.0 全部使用参数化查询，禁止拼接 SQL |
| XSS | 输入清洗 + 输出转义 | `SafeHtmlStr` 类型自动转义；API 响应 Content-Type 为 JSON |
| 路径遍历 | `sanitize_path` | 去除 `..` 和连续斜杠 |
| CRLF 注入 | Header 清洗 | FastAPI 自动处理；自定义 Header 值过滤 `\r\n` |
| JSON 注入 | Pydantic 反序列化 | 严格类型校验，拒绝未知字段 |
| NoSQL 注入 | N/A（不使用 MongoDB） | — |
| SSRF | URL 白名单 | `SafeUrl` 仅允许 http/https 协议；内网 IP 检测 |
| 命令注入 | 禁止 os.system | 使用 subprocess 时参数列表化，禁止 shell=True |

## 9. 校验器注册表（运行时扩展）

### 9.1 注册表设计

```python
# app/core/validation/registry.py
from typing import Callable, Any
from pydantic import BeforeValidator, AfterValidator
import logging

logger = logging.getLogger(__name__)


class ValidatorRegistry:
    """自定义校验器注册表。
    
    允许在运行时通过配置或插件注册新的校验器，
    无需修改核心框架代码。
    """
    
    def __init__(self):
        self._cleaners: dict[str, Callable] = {}       # name → cleaner
        self._validators: dict[str, Callable] = {}     # name → validator
        self._rules: dict[str, Callable] = {}           # name → model_validator
    
    def register_cleaner(self, name: str, func: Callable) -> None:
        """注册清洗函数"""
        if name in self._cleaners:
            logger.warning("Cleaner '%s' already registered, overwriting", name)
        self._cleaners[name] = func
        logger.info("Registered cleaner: %s", name)
    
    def register_validator(self, name: str, func: Callable) -> None:
        """注册字段校验器"""
        if name in self._validators:
            logger.warning("Validator '%s' already registered, overwriting", name)
        self._validators[name] = func
        logger.info("Registered validator: %s", name)
    
    def register_rule(self, name: str, func: Callable) -> None:
        """注册跨字段规则校验器"""
        if name in self._rules:
            logger.warning("Rule '%s' already registered, overwriting", name)
        self._rules[name] = func
        logger.info("Registered rule: %s", name)
    
    def get_cleaner(self, name: str) -> Callable:
        return self._cleaners[name]
    
    def get_validator(self, name: str) -> Callable:
        return self._validators[name]
    
    def get_rule(self, name: str) -> Callable:
        return self._rules[name]
    
    def list_all(self) -> dict[str, list[str]]:
        """列出所有已注册的校验器（管理后台可调用）"""
        return {
            "cleaners": sorted(self._cleaners.keys()),
            "validators": sorted(self._validators.keys()),
            "rules": sorted(self._rules.keys()),
        }


# 全局单例
registry = ValidatorRegistry()

# ============================================================

    """注册内置校验器"""
```

## 12. 性能考量

### 12.1 性能预算

| 操作 | 预算 | 说明 |
|------|------|------|
| 简单字段校验（类型+长度） | < 0.1ms | Pydantic Rust 内核，几乎无开销 |
| 正则校验（手机号等） | < 0.5ms | 编译缓存正则 |
| 跨字段 model_validator | < 1ms | 避免数据库查询 |
| 批量 100 项校验 | < 10ms | — |

### 12.2 注意事项

1. **校验中禁止数据库查询**：字段校验和模型校验只做格式和内存中的规则检查，数据库唯一性等校验放在 Service 层
2. **正则编译缓存**：所有正则使用模块级变量或 `re.compile`，避免每次请求重新编译
3. **避免复杂嵌套校验**：嵌套层级不超过 3 层，深层结构使用扁平化请求模型
4. **批量校验短路**：`fail_fast=True` 时遇到第一个错误即中断

**告警规则**：
- 某接口校验失败率 > 5%：可能存在客户端版本兼容问题，通知前端排查
- 某接口校验耗时 P99 > 50ms：可能有复杂正则或 N+1 校验，需优化
- 批量请求 items 数量 > 80（接近上限 100）：评估是否需要调大限制

## 15. 总结

本文档定义了 PrimeTop 服务端的统一请求参数校验与数据清洗规范，核心要点：

1. **基于 Pydantic V2 Annotated 类型**实现声明式校验，零侵入、类型安全
2. **四层校验架构**：类型清洗 → 格式校验 → 自定义域校验 → 业务规则校验
3. **标准化错误响应**：RFC 7807 扩展格式，字段级错误码，敏感值脱敏
4. **安全清洗管线**：HTML 转义、SQL 通配符转义、路径遍历防护、内容安全预检
5. **运行时可扩展**：注册表模式支持插件式新增校验器
6. **完整测试策略**：单元测试 + 集成测试模板，覆盖正常和边界场景
