# 学生知识体系健康度评估与学习生态平衡度诊断引擎 - 详细设计

## 1. 概述

### 1.1 模块定位

本引擎是 PrimeTop 学情分析体系中的**元级评估服务（Meta-Evaluation Service）**。区别于已有的单维度诊断引擎（偏科诊断、知识漏洞追溯、认知负荷监测等），本系统将各维度信号**融合为一个统一的知识生态健康模型**，对学生的整体学习状态进行"全身体检"式的综合诊断。

**核心价值：**
- 为学生/家长提供一目了然的"学习健康分数"和具体改善建议
- 为教师提供班级整体生态健康概览
- 为平台其他推荐/规划引擎提供全局健康度约束信号
- 实现从"发现问题"到"解释为什么"再到"给出怎么办"的完整闭环

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 多维融合 | 综合 ≥ 8 个维度的信号，输出统一健康评分 |
| 实时性 | 健康分数每日增量更新，不依赖批量离线计算 |
| 可解释 | 每个分数变化都可追溯到具体信号变化 |
| 个性化 | 健康标准根据学段、地区、学习目标动态调整 |
| 预警性 | 在生态恶化前发出预警，而非事后报告 |

### 1.3 适用范围

- 学段：小学三年级及以上（需积累至少 2 周学习数据）
- 学科：全学科覆盖
- 用户：学生端（自我诊断）、家长端（了解孩子状态）、教师端（班级概览）

## 2. 核心概念与模型

### 2.1 知识生态健康度模型（KEH Model）

知识生态健康度（Knowledge Ecosystem Health, KEH）由 **6 个一级维度 + 24 个二级指标** 构成：

```
KEH Score = Σ(Wi × Di)  (i = 1..6)
```

其中 `Wi` 为维度权重（动态调整），`Di` 为维度得分（0-100）。

### 2.2 一级维度定义

| 编号 | 维度 | 说明 | 默认权重 |
|------|------|------|----------|
| D1 | **覆盖广度** (Coverage Breadth) | 课标要求知识点的覆盖比例 | 0.20 |
| D2 | **深度均衡** (Depth Balance) | 各知识点掌握深度的均匀程度 | 0.20 |
| D3 | **关联密度** (Connection Density) | 知识点间关联的丰富度和路径多样性 | 0.15 |
| D4 | **技能平衡** (Skill Balance) | 认知、计算、表达、推理等技能维度平衡度 | 0.15 |
| D5 | **时序健康** (Temporal Health) | 学习节奏的规律性和持续性 | 0.15 |
| D6 | **成长速度** (Growth Velocity) | 多维度的进步速率和趋势方向 | 0.15 |

### 2.3 二级指标详表

#### D1 - 覆盖广度

| 指标ID | 指标名称 | 计算方式 | 数据来源 |
|--------|----------|----------|----------|
| D1-01 | 课标覆盖率 | 已学习知识点数 / 课标要求知识点总数 × 100 | 知识点追踪表 |
| D1-02 | 章节接触率 | 已触达章节数 / 当前学期章节总数 × 100 | 学习记录表 |
| D1-03 | 题型覆盖度 | 已练习题型种类 / 该学段适用题型种类 × 100 | 答题记录表 |
| D1-04 | 盲区比例 | 识别为"学习空白"的知识点占比 | 覆盖度诊断服务 |

#### D2 - 深度均衡

| 指标ID | 指标名称 | 计算方式 | 数据来源 |
|--------|----------|----------|----------|
| D2-01 | 掌握度方差 | 各知识点掌握分数的方差（越低越均衡） | 知识追踪模型 |
| D2-02 | 极端薄弱比 | 掌握度 < 0.3 的知识点占比 | 知识追踪模型 |
| D2-03 | 强项集中度 | 掌握度 > 0.85 的知识点集中程度 | 知识追踪模型 |
| D2-04 | 深度递进率 | 进入"应用/分析"层级的知识点比例 | 布鲁姆分类引擎 |

#### D3 - 关联密度

| 指标ID | 指标名称 | 计算方式 | 数据来源 |
|--------|----------|----------|----------|
| D3-01 | 前置完备率 | 学习某知识点时，其前置知识点已掌握的比例 | 知识图谱服务 |
| D3-02 | 跨科关联度 | 跨学科知识关联被激活的次数 | 学习行为日志 |
| D3-03 | 路径多样性 | 到达同一知识点的不同学习路径数量 | 学习路径引擎 |
| D3-04 | 关联应用率 | 在解题中主动调用关联知识点的频率 | 答题行为分析 |

#### D4 - 技能平衡

| 指标ID | 指标名称 | 计算方式 | 数据来源 |
|--------|----------|----------|----------|
| D4-01 | 认知技能均衡 | 记忆/理解/应用/分析/评价/创造六层级分布均衡度 | 布鲁姆分类 |
| D4-02 | 学科投入均衡 | 各学科学习时间分布的均衡度（基尼系数） | 学习时长统计 |
| D4-03 | 输入输出比 | 学习（输入）vs 练习（输出）的时间比 | 会话分析 |
| D4-04 | 难度适配电率 | 当前练习难度与学生能力匹配的比例 | 自适应推荐 |

#### D5 - 时序健康

| 指标ID | 指标名称 | 计算方式 | 数据来源 |
|--------|----------|----------|----------|
| D5-01 | 学习规律性 | 每日学习开始时间的标准差（越小越规律） | 学习会话日志 |
| D5-02 | 连续性指数 | 最近14天内有学习活动的天数比例 | 学习记录 |
| D5-03 | 突击学习比 | 单日学习时长 > 日均2倍的天数占比 | 学习时长统计 |
| D5-04 | 时段效率比 | 高效时段学习时间 / 低效时段学习时间 | 专注力分析 |

#### D6 - 成长速度

| 指标ID | 指标名称 | 计算方式 | 数据来源 |
|--------|----------|----------|----------|
| D6-01 | 掌握度增速 | 最近30天知识点掌握度的平均提升速率 | 知识追踪模型 |
| D6-02 | 正确率趋势 | 最近30天答题正确率的变化斜率 | 答题记录 |
| D6-03 | 新知识拓展率 | 每周首次接触新知识点的数量趋势 | 知识点追踪 |
| D6-04 | 综合能力提升 | 学科能力雷达图面积月环比变化 | 学科能力评估 |

## 3. 数据结构定义

### 3.1 核心表结构

#### 3.1.1 `keh_assessment` - 健康度评估记录表

```sql
CREATE TABLE keh_assessment (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id      BIGINT NOT NULL COMMENT '学生ID',
    assessment_date DATE NOT NULL COMMENT '评估日期',
    keh_score       DECIMAL(5,2) NOT NULL COMMENT '综合健康分数 0-100',
    grade_level     VARCHAR(20) NOT NULL COMMENT '评估时学段年级',

    -- 一级维度得分
    d1_score        DECIMAL(5,2) COMMENT '覆盖广度得分',
    d2_score        DECIMAL(5,2) COMMENT '深度均衡得分',
    d3_score        DECIMAL(5,2) COMMENT '关联密度得分',
    d4_score        DECIMAL(5,2) COMMENT '技能平衡得分',
    d5_score        DECIMAL(5,2) COMMENT '时序健康得分',
    d6_score        DECIMAL(5,2) COMMENT '成长速度得分',

    -- 权重快照
    weights_snapshot JSON COMMENT '本次评估使用的维度权重',

    -- 趋势
    score_delta     DECIMAL(5,2) COMMENT '与前次评估的分差',
    trend_direction ENUM('UP','FLAT','DOWN') DEFAULT 'FLAT',

    -- 诊断
    health_level    ENUM('EXCELLENT','GOOD','NORMAL','WARNING','CRITICAL') NOT NULL,
    top_issues      JSON COMMENT 'Top 3 问题维度及指标 [{dimension, metric, value, suggestion}]',
    top_strengths   JSON COMMENT 'Top 3 优势维度',

    -- 元数据
    data_completeness DECIMAL(3,2) DEFAULT 0 COMMENT '数据完整度 0-1（样本量不足时降低）',
    calc_version    VARCHAR(20) NOT NULL COMMENT '计算版本号',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_student_date (student_id, assessment_date),
    INDEX idx_date_score (assessment_date, keh_score),
    INDEX idx_level (health_level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识生态健康度评估记录';
```

#### 3.1.2 `keh_metric_detail` - 二级指标明细表

```sql
CREATE TABLE keh_metric_detail (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,

    student_id      BIGINT NOT NULL,
    assessment_date DATE NOT NULL,

    metric_code     VARCHAR(10) NOT NULL COMMENT '指标编码 如 D1-01',
    metric_name     VARCHAR(50) NOT NULL COMMENT '指标名称',
    dimension_code  CHAR(2) NOT NULL COMMENT '一级维度编码 D1-D6',

    raw_value       DECIMAL(10,4) COMMENT '原始值',
    normalized_score DECIMAL(5,2) COMMENT '归一化得分 0-100',
    benchmark_value DECIMAL(10,4) COMMENT '同级用户基准值',
    percentile      DECIMAL(5,2) COMMENT '百分位排名',

    status          ENUM('EXCELLENT','GOOD','NORMAL','WEAK','CRITICAL') NOT NULL,
    delta_from_last DECIMAL(10,4) COMMENT '与前次评估的变化值',

    detail_data     JSON COMMENT '指标计算的明细数据',

    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_assessment (assessment_id),
    INDEX idx_student_metric (student_id, metric_code, assessment_date)

```

```sql
CREATE TABLE keh_weight_config (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
```

#### 3.1.4 `keh_alert` - 健康度预警表

```sql
CREATE TABLE keh_alert (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,

    threshold_value DECIMAL(10,4) COMMENT '阈值',
    previous_value  DECIMAL(10,4) COMMENT '上次值',

    resolved_at     DATETIME,

    INDEX idx_student_status (student_id, status),
    INDEX idx_triggered (triggered_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='健康度预警记录';
```

### 3.2 数据模型（Java 实体）

```java
/**
 * 知识生态健康度评估结果
 */
@Data
@Builder
public class KehAssessment {
    private Long studentId;
    private LocalDate assessmentDate;
    private BigDecimal kehScore;
    private String gradeLevel;

    // 维度得分
    private Map<String, BigDecimal> dimensionScores;  // D1-D6

    // 健康等级
    private HealthLevel healthLevel;

    // 问题与优势
    private List<KehIssue> topIssues;
    private List<String> topStrengths;

    // 数据质量
    private BigDecimal dataCompleteness;
    private String calcVersion;

    public enum HealthLevel {
        EXCELLENT(90, 100, "优秀"),
        GOOD(75, 89, "良好"),
        NORMAL(60, 74, "正常"),
        WARNING(40, 59, "需关注"),
        CRITICAL(0, 39, "需干预");

        public final int min;
        public final int max;
        public final String label;

        HealthLevel(int min, int max, String label) {
            this.min = min;
            this.max = max;
            this.label = label;
        }

        public static HealthLevel fromScore(BigDecimal score) {
            int s = score.intValue();
            for (HealthLevel level : values()) {
                if (s >= level.min && s <= level.max) return level;
            }
            return NORMAL;
        }
    }
}

/**
 * 健康问题项
 */
@Data
@Builder
public class KehIssue {
    private String dimensionCode;     // D1-D6
    private String dimensionName;
    private String metricCode;        // 如 D1-04
    private String metricName;
    private BigDecimal currentValue;
    private BigDecimal benchmarkValue;
    private String severity;          // CRITICAL / WEAK
    private String suggestion;        // 改善建议
    private List<String> actionItems; // 具体动作
}

/**
 * 单个指标的计算上下文
 */
@Data
@Builder
public class MetricCalcContext {
    private Long studentId;
    private String metricCode;
    private LocalDate assessmentDate;
    private int lookbackDays;           // 回溯天数
    private StudentProfile profile;     // 学生画像
    private Map<String, Object> rawData; // 原始数据
    private BigDecimal benchmarkValue;  // 基准值
}
```

```java
@Component
public class ExtremeWeakRatioCalculator implements MetricCalculator {

    @Override
    public String getMetricCode() {
        return "D2-02";
    }

    @Override
    public List<String> getRequiredDataKeys() {
        return List.of("knowledge_mastery_map", "tracked_kp_count");
    }

    @Override
    public MetricResult calculate(MetricCalcContext context) {
        @SuppressWarnings("unchecked")
        Map<String, BigDecimal> masteryMap =
            (Map<String, BigDecimal>) context.getRawData().get("knowledge_mastery_map");

        int totalTracked = masteryMap.size();
        if (totalTracked == 0) {
            return MetricResult.builder()
                .metricCode(getMetricCode())
                .rawValue(null)
                .normalizedScore(null)
                .status("INSUFFICIENT_DATA")
                .dataConfidence(BigDecimal.ZERO)
                .build();
        }

        // 统计掌握度 < 0.3 的知识点
        long weakCount = masteryMap.values().stream()
            .filter(m -> m.compareTo(new BigDecimal("0.3")) < 0)
            .count();

        BigDecimal weakRatio = BigDecimal.valueOf(weakCount)
            .divide(BigDecimal.valueOf(totalTracked), 4, RoundingMode.HALF_UP);

        // 归一化得分：0%薄弱=100分，50%薄弱=0分
        BigDecimal normalizedScore = normalizeWeakRatio(weakRatio, context.getProfile());

        // 识别具体薄弱知识点
        List<Map<String, Object>> weakPoints = masteryMap.entrySet().stream()
            .filter(e -> e.getValue().compareTo(new BigDecimal("0.3")) < 0)
            .sorted(Map.Entry.comparingValue())
            .limit(10) // Top 10 最薄弱
            .map(e -> {
                Map<String, Object> point = new HashMap<>();
                point.put("kpId", e.getKey());
                point.put("mastery", e.getValue());
                return point;
            })
            .collect(Collectors.toList());

        String status = determineStatus(normalizedScore);

        return MetricResult.builder()
            .metricCode(getMetricCode())
            .rawValue(weakRatio)
            .normalizedScore(normalizedScore)
            .status(status)
            .dataConfidence(calculateConfidence(totalTracked))
            .detail(Map.of(
                "weakCount", weakCount,
                "totalTracked", totalTracked,
                "weakKnowledgePoints", weakPoints
            ))
            .build();
    }

    private BigDecimal normalizeWeakRatio(BigDecimal weakRatio, StudentProfile profile) {
        // 根据学段调整阈值
        BigDecimal idealMax = profile.getGradeLevel().startsWith("高中")
            ? new BigDecimal("0.08")   // 高中：理想状态下薄弱<8%
            : new BigDecimal("0.10");  // 初中及以下：理想状态下薄弱<10%

        BigDecimal criticalMax = new BigDecimal("0.50"); // 50%以上=0分

        if (weakRatio.compareTo(idealMax) <= 0) {
            // 理想区间：85-100
            BigDecimal ratio = weakRatio.divide(idealMax, 4, RoundingMode.HALF_UP);
            return new BigDecimal("100").subtract(ratio.multiply(new BigDecimal("15")));
        } else if (weakRatio.compareTo(criticalMax) >= 0) {
            return BigDecimal.ZERO;
        } else {
            // 线性映射
            BigDecimal range = criticalMax.subtract(idealMax);
            BigDecimal offset = weakRatio.subtract(idealMax);
            BigDecimal ratio = offset.divide(range, 4, RoundingMode.HALF_UP);
            return new BigDecimal("85").subtract(ratio.multiply(new BigDecimal("85")));
        }
    }

    private BigDecimal calculateConfidence(int sampleSize) {
        // 最少需要50个追踪知识点才能高置信
        if (sampleSize >= 100) return BigDecimal.ONE;
        if (sampleSize >= 50) return new BigDecimal("0.85");
        if (sampleSize >= 20) return new BigDecimal("0.60");
        return new BigDecimal("0.30");
    }

    private String determineStatus(BigDecimal score) {
        if (score.compareTo(new BigDecimal("80")) >= 0) return "EXCELLENT";
        if (score.compareTo(new BigDecimal("65")) >= 0) return "GOOD";
        if (score.compareTo(new BigDecimal("50")) >= 0) return "NORMAL";
        if (score.compareTo(new BigDecimal("30")) >= 0) return "WEAK";
        return "CRITICAL";
    }
}
```

```java
@Component
public class SubjectBalanceCalculator implements MetricCalculator {

    @Override
    public String getMetricCode() {
        return "D4-02";
    }

    @Override
    public List<String> getRequiredDataKeys() {
        return List.of("subject_time_distribution");
    }

    @Override
    public MetricResult calculate(MetricCalcContext context) {
        @SuppressWarnings("unchecked")
        Map<String, Long> subjectTime =
            (Map<String, Long>) context.getRawData().get("subject_time_distribution");

        if (subjectTime == null || subjectTime.isEmpty()) {
            return MetricResult.builder()
                .metricCode(getMetricCode())
                .status("INSUFFICIENT_DATA")
                .dataConfidence(BigDecimal.ZERO)
                .build();
        }

        // 计算基尼系数衡量学科投入均衡度
        BigDecimal gini = calculateGiniCoefficient(subjectTime.values());

        // 归一化：Gini=0 完全均衡=100分，Gini=0.8 极度不均=0分
        BigDecimal normalizedScore = BigDecimal.valueOf(100)
            .subtract(gini.multiply(BigDecimal.valueOf(125)));

        // 识别投入最多和最少的学科
        Map.Entry<String, Long> maxSubject = subjectTime.entrySet().stream()
            .max(Map.Entry.comparingByValue()).orElse(null);
        Map.Entry<String, Long> minSubject = subjectTime.entrySet().stream()
            .min(Map.Entry.comparingByValue()).orElse(null);

        return MetricResult.builder()
            .metricCode(getMetricCode())
            .rawValue(gini)
            .normalizedScore(normalizedScore.max(BigDecimal.ZERO))
            .status(determineStatus(normalizedScore))
            .dataConfidence(BigDecimal.ONE)
            .detail(Map.of(
                "giniCoefficient", gini,
                "mostInvestedSubject", maxSubject != null ? maxSubject.getKey() : null,
                "leastInvestedSubject", minSubject != null ? minSubject.getKey() : null,
                "subjectDistribution", subjectTime
            ))
            .build();
    }

    /**
     * 计算基尼系数
     */
    private BigDecimal calculateGiniCoefficient(Collection<Long> values) {
        List<Long> sorted = values.stream().sorted().collect(Collectors.toList());
        long sum = sorted.stream().mapToLong(Long::longValue).sum();
        if (sum == 0) return BigDecimal.ZERO;

        int n = sorted.size();
        BigDecimal cumulativeSum = BigDecimal.ZERO;
        BigDecimal weightedSum = BigDecimal.ZERO;

        for (int i = 0; i < n; i++) {
            BigDecimal value = BigDecimal.valueOf(sorted.get(i));
            BigDecimal weight = BigDecimal.valueOf(i + 1);
            weightedSum = weightedSum.add(weight.multiply(value));
            cumulativeSum = cumulativeSum.add(value);
        }

        // Gini = (2 * Σ(i * xi)) / (n * Σ(xi)) - (n + 1) / n
        BigDecimal numerator = weightedSum.multiply(new BigDecimal("2"));
        BigDecimal denominator = BigDecimal.valueOf(n).multiply(cumulativeSum);
        BigDecimal gini = numerator.divide(denominator, 4, RoundingMode.HALF_UP)
            .subtract(BigDecimal.valueOf(n + 1).divide(BigDecimal.valueOf(n), 4, RoundingMode.HALF_UP));

        return gini.max(BigDecimal.ZERO);
    }
}
```

### 5.4 维度聚合与健康分数计算

```java
@Service
public class KehScoreAggregator {

    @Autowired
    private KehWeightConfigRepository weightConfigRepository;

    /**
     * 聚合维度得分为最终KEH分数
     */
    public KehAssessment aggregate(Long studentId, LocalDate assessmentDate,
                                   Map<String, List<MetricResult>> dimensionMetrics,
                                   StudentProfile profile) {

        // 1. 获取维度权重
        Map<String, BigDecimal> weights = getDimensionWeights(profile.getGradeLevel());

        // 2. 计算每个维度的加权得分
        Map<String, BigDecimal> dimensionScores = new LinkedHashMap<>();
        for (Map.Entry<String, List<MetricResult>> entry : dimensionMetrics.entrySet()) {
            String dimCode = entry.getKey();
            List<MetricResult> metrics = entry.getValue();

            // 过滤无效数据
            List<MetricResult> validMetrics = metrics.stream()
                .filter(m -> m.getNormalizedScore() != null)
                .collect(Collectors.toList());

            if (validMetrics.isEmpty()) {
                dimensionScores.put(dimCode, null);
                continue;
            }

            // 简单平均（可扩展为子指标加权）
            BigDecimal dimScore = validMetrics.stream()
                .map(MetricResult::getNormalizedScore)
                .reduce(BigDecimal.ZERO, BigDecimal::add)
                .divide(BigDecimal.valueOf(validMetrics.size()), 2, RoundingMode.HALF_UP);

            dimensionScores.put(dimCode, dimScore);
        }

        // 3. 加权聚合
        BigDecimal kehScore = BigDecimal.ZERO;
        BigDecimal totalWeight = BigDecimal.ZERO;

        for (Map.Entry<String, BigDecimal> entry : weights.entrySet()) {
            String dimCode = entry.getKey();
            BigDecimal weight = entry.getValue();
            BigDecimal dimScore = dimensionScores.get(dimCode);

            if (dimScore != null) {
                kehScore = kehScore.add(weight.multiply(dimScore));
                totalWeight = totalWeight.add(weight);
            }
        }

        if (totalWeight.compareTo(BigDecimal.ZERO) > 0) {
            kehScore = kehScore.divide(totalWeight, 2, RoundingMode.HALF_UP);
        }

        // 4. 确定健康等级
        HealthLevel healthLevel = HealthLevel.fromScore(kehScore);

        // 5. 计算数据完整度
        BigDecimal dataCompleteness = calculateDataCompleteness(dimensionMetrics);

        // 6. 识别问题和优势
        List<KehIssue> topIssues = identifyTopIssues(dimensionMetrics, profile);
        List<String> topStrengths = identifyTopStrengths(dimensionMetrics, profile);

        return KehAssessment.builder()
            .studentId(studentId)
            .assessmentDate(assessmentDate)
            .kehScore(kehScore)
            .gradeLevel(profile.getGradeLevel())
            .dimensionScores(dimensionScores)
            .healthLevel(healthLevel)
            .topIssues(topIssues)
            .topStrengths(topStrengths)
            .dataCompleteness(dataCompleteness)
            .calcVersion("v1.0")
            .build();
    }

    /**
     * 动态权重获取：允许根据学段和学习目标调整
     */
    private Map<String, BigDecimal> getDimensionWeights(String gradeLevel) {
        List<KehWeightConfig> configs = weightConfigRepository
            .findActiveWeights(gradeLevel, LocalDate.now());

        if (configs.isEmpty()) {
            // 返回默认权重
            return Map.of(
                "D1", new BigDecimal("0.20"),
                "D2", new BigDecimal("0.20"),
                "D3", new BigDecimal("0.15"),
                "D4", new BigDecimal("0.15"),
                "D5", new BigDecimal("0.15"),
                "D6", new BigDecimal("0.15")
            );
        }

        return configs.stream()
            .collect(Collectors.toMap(
                KehWeightConfig::getDimensionCode,
                KehWeightConfig::getWeight
            ));
    }
}
```

```java
@Service
public class KehDiagnosisEngine {

    /**
     * 基于评估结果生成诊断建议
     */
    public DiagnosisReport diagnose(KehAssessment assessment,
                                     Map<String, List<MetricResult>> metrics,
                                     StudentProfile profile,
                                     KehAssessment previousAssessment) {

        List<KehIssue> issues = new ArrayList<>();
        List<String> strengths = new ArrayList<>();

        // 1. 遍历所有指标，识别问题和优势
        for (Map.Entry<String, List<MetricResult>> entry : metrics.entrySet()) {
            for (MetricResult metric : entry.getValue()) {
                if (metric.getStatus() == null) continue;

                switch (metric.getStatus()) {
                    case "CRITICAL":
                    case "WEAK":
                        issues.add(buildIssue(metric, profile));
                        break;
                    case "EXCELLENT":
                        strengths.add(buildStrength(metric));
                        break;
                }
            }
        }

        // 2. 排序：严重度优先，然后按改善潜力
        issues.sort(Comparator
            .comparing(KehIssue::getSeverity).reversed()
            .thenComparing(i -> calculateImprovementPotential(i, profile)).reversed());

        // 3. 生成整体建议
        OverallSuggestion suggestion = generateOverallSuggestion(
            assessment, issues, strengths, profile, previousAssessment);

        return DiagnosisReport.builder()
            .topIssues(issues.stream().limit(3).collect(Collectors.toList()))
            .topStrengths(strengths.stream().limit(3).collect(Collectors.toList()))
            .overallSuggestion(suggestion)
            .build();
    }

    private OverallSuggestion generateOverallSuggestion(KehAssessment assessment,
                                                         List<KehIssue> issues,
                                                         List<String> strengths,
                                                         StudentProfile profile,
                                                         KehAssessment previous) {

        // 识别主要矛盾
        String primaryFocus = determinePrimaryFocus(issues, assessment);

        // 生成周计划建议
        List<String> weeklyPlan = generateWeeklyPlan(issues, profile);

        // 估计改善预期
        String estimatedImprovement = estimateImprovement(assessment, issues, profile);

        return OverallSuggestion.builder()
            .priority(primaryFocus)
            .summary(buildSummaryText(assessment, issues, strengths))
            .weeklyPlan(weeklyPlan)
            .estimatedImprovement(estimatedImprovement)
            .build();
    }

    /**
     * 确定首要关注方向
     */
    private String determinePrimaryFocus(List<KehIssue> issues, KehAssessment assessment) {
        if (issues.isEmpty()) return "MAINTAIN";

        KehIssue worst = issues.get(0);
        return switch (worst.getDimensionCode()) {
            case "D1" -> "EXPAND_COVERAGE";   // 扩大覆盖
            case "D2" -> "FOCUS_DEPTH";       // 深度攻克
            case "D3" -> "BUILD_CONNECTIONS"; // 建立关联
            case "D4" -> "BALANCE_SKILLS";    // 平衡技能
            case "D5" -> "FIX_SCHEDULE";      // 调整节奏
            case "D6" -> "BOOST_GROWTH";      // 提速成长
            default -> "MAINTAIN";
        };
    }
}
```

```java
@Configuration
public class KehAlertRules {

    /**
     * 预警规则集 - 使用规则引擎模式
     */
    public List<AlertRule> getRules() {
        return List.of(

            // 规则1: 综合分数骤降
            AlertRule.builder()
                .alertType("SCORE_DROP")
                .severity("URGENT")
                .condition((current, previous) ->
                    previous != null &&
                    current.getKehScore().subtract(previous.getKehScore())
                        .compareTo(new BigDecimal("-10")) < 0)
                .descriptionTemplate("健康分数从{prev}骤降至{curr}，降幅{delta}")
                .suggestedActions(List.of("查看近期学习记录变化", "检查是否有外部因素影响"))
                .build(),

            // 规则2: 某维度进入CRITICAL
            AlertRule.builder()
                .alertType("DIMENSION_CRITICAL")
                .severity("URGENT")
                .condition((current, previous) -> {
                    if (previous == null) return false;
                    for (String dimCode : current.getDimensionScores().keySet()) {
                        BigDecimal currScore = current.getDimensionScores().get(dimCode);
                        BigDecimal prevScore = previous.getDimensionScores().get(dimCode);
                        if (currScore != null && currScore.compareTo(new BigDecimal("40")) < 0
                            && (prevScore == null || prevScore.compareTo(new BigDecimal("40")) >= 0)) {
                            return true;
                        }
                    }
                    return false;
                })
                .descriptionTemplate("维度{dimension}进入危急状态（分数{score}）")
                .suggestedActions(List.of("紧急干预建议", "联系家长/教师"))
                .build(),

            // 规则3: 连续3周下降趋势
            AlertRule.builder()
                .alertType("TREND_REVERSAL")
                .severity("WARNING")
                .condition((current, history) -> {
                    if (history.size() < 3) return false;
                    // 检查最近3次评估是否持续下降
                    for (int i = 0; i < 3; i++) {
                        if (history.get(i).getScoreDelta() != null
                            && history.get(i).getScoreDelta().compareTo(BigDecimal.ZERO) >= 0) {
                            return false;
                        }
                    }
                    return true;
                })
                .descriptionTemplate("健康分数已连续3周下降，从{start}降至{end}")
                .suggestedActions(List.of("分析下降原因", "调整学习策略", "必要时降低学习强度"))
                .build(),

            // 规则4: 单指标异常突变
            AlertRule.builder()
                .alertType("METRIC_ANOMALY")
                .severity("WARNING")
                .condition((current, previous) -> {
                    if (previous == null) return false;
                    // 检查任一指标变化幅度 > 30%
                    return current.getMetrics().stream()
                        .anyMatch(m -> {
                            MetricResult prevMetric = previous.findMetric(m.getMetricCode());
                            return prevMetric != null
                                && m.getRawValue() != null
                                && prevMetric.getRawValue() != null
                                && calculateChangeRate(m.getRawValue(), prevMetric.getRawValue())
                                    .compareTo(new BigDecimal("0.3")) > 0;
                        });
                })
                .descriptionTemplate("指标{metric}出现异常变化（{changeRate}）")
                .suggestedActions(List.of("检查数据源是否异常", "关注相关学习行为"))
```

```java
@Service
public class KehAlertProcessor {

    @Autowired
    private KehAlertRepository alertRepository;

    @Autowired
    private NotificationService notificationService;

    @Autowired
    private List<AlertRule> alertRules;

    /**
     * 检查并触发预警
     */
    public void checkAndTriggerAlerts(KehAssessment current,
                                       KehAssessment previous,
                                       List<KehAssessment> recentHistory) {

        List<KehAlert> newAlerts = new ArrayList<>();

        for (AlertRule rule : alertRules) {
            if (rule.getCondition().test(
                    new AlertEvaluationContext(current, previous, recentHistory))) {

                KehAlert alert = KehAlert.builder()
                    .studentId(current.getStudentId())
                    .alertType(rule.getAlertType())
                    .severity(rule.getSeverity())
                    .description(renderDescription(rule, current, previous))
                    .currentValue(current.getKehScore())
                    .previousValue(previous != null ? previous.getKehScore() : null)
                    .suggestedActions(rule.getSuggestedActions())
                    .status("ACTIVE")
                    .triggeredAt(LocalDateTime.now())
                    .build();

                newAlerts.add(alert);
            }
        }

        if (!newAlerts.isEmpty()) {
            alertRepository.batchInsert(newAlerts);

            // 发送通知（仅URGENT级别立即推送）
            newAlerts.stream()
                .filter(a -> "URGENT".equals(a.getSeverity()))
                .forEach(this::sendUrgentNotification);
        }
    }

    private void sendUrgentNotification(KehAlert alert) {
        notificationService.send(
            NotificationRequest.builder()
                .userId(alert.getStudentId())
                .type("KEH_ALERT_URGENT")
                .title("学习健康度预警")
                .content(alert.getDescription())
                .priority(NotificationPriority.HIGH)
                .build()
        );
    }
}
```

## 8. 增量计算与调度

### 8.1 增量计算策略

为避免每日全量重算带来的性能开销，采用**增量计算 + 定期全量校准**策略：

| 计算类型 | 触发时机 | 计算范围 | 耗时预估 |
|----------|----------|----------|----------|
| 实时增量 | 关键学习事件后（如完成一次答题会话） | 仅更新受影响的指标 | < 500ms |
| 每日增量 | 每日凌晨 02:00 | 全部24个指标，仅使用当日新数据 | ~2s/学生 |
| 每周全量 | 每周日凌晨 03:00 | 全部指标，使用7天完整数据重算 | ~5s/学生 |
| 手动触发 | 运营/用户请求 | 全量计算 | ~5s/学生 |

```java
    private static final String LATEST_ASSESSMENT = "keh:latest:{studentId}";
    private static final String DIMENSION_DETAIL  = "keh:dim:{studentId}:{dimCode}";
    private static final String TREND_DATA         = "keh:trend:{studentId}:{granularity}";
    private static final String CLASS_OVERVIEW     = "keh:class:{classId}:{date}";

    // TTL配置
    private static final Duration LATEST_TTL   = Duration.ofHours(25);  // 略大于日更新周期
    private static final Duration DIMENSION_TTL = Duration.ofHours(25);
    private static final Duration TREND_TTL     = Duration.ofHours(12);
    private static final Duration CLASS_TTL     = Duration.ofHours(6);

    public KehAssessment getLatest(Long studentId) {
        return (KehAssessment) redisTemplate.opsForValue()
            .get(LATEST_ASSESSMENT.replace("{studentId}", String.valueOf(studentId)));
    }

    public void cacheLatest(Long studentId, KehAssessment assessment) {
        redisTemplate.opsForValue().set(
            LATEST_ASSESSMENT.replace("{studentId}", String.valueOf(studentId)),
            assessment,
            LATEST_TTL
        );
    }

    /**
     * 失效指定学生的所有缓存
     */
    public void invalidateStudent(Long studentId) {
        Set<String> keys = redisTemplate.keys("keh:*:" + studentId + ":*");
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }
        // 同时删除最新评估缓存
        redisTemplate.delete(LATEST_ASSESSMENT.replace("{studentId}", String.valueOf(studentId)));
    }
}
```

### 10.2 降级策略

```java
@Service
public class KehCalculationExecutor {

    /**
     * 容错计算：即使部分数据源不可用也能输出结果
     */
    public KehAssessment calculateWithFallback(Long studentId, LocalDate date) {
        try {
            // 正常全量计算
            return fullCalculation(studentId, date);
        } catch (DataUnavailableException e) {
            log.warn("部分数据源不可用，降级计算 studentId={}, missing={}", studentId, e.getMissingSources());

            // 降级1：使用缓存的上次数据补充缺失维度
            KehAssessment cached = cacheManager.getLatest(studentId);
            if (cached != null) {
                return partialCalculationWithCache(studentId, date, cached, e.getMissingSources());
            }

            // 降级2：仅计算可计算的维度，其余标记为数据不足
            return degradedCalculation(studentId, date, e.getMissingSources());

        } catch (Exception e) {
            log.error("KEH计算严重错误 studentId={}", studentId, e);

            // 降级3：直接返回缓存数据
            KehAssessment cached = cacheManager.getLatest(studentId);
            if (cached != null) {
                cached.setNote("数据源异常，展示上次评估结果");
                return cached;
            }

            // 降级4：返回不可用状态
            return KehAssessment.unavailable(studentId, date, "系统暂时无法完成评估，请稍后重试");
        }
    }

    /**
     * 部分降级计算
     */
    private KehAssessment degradedCalculation(Long studentId, LocalDate date,
                                               Set<String> missingSources) {
        // 跳过依赖不可用数据源的指标
        Map<String, List<MetricResult>> availableMetrics = new HashMap<>();
        Set<String> skippedMetrics = new HashSet<>();

        for (MetricCalculator calculator : metricCalculators) {
            if (calculator.getRequiredDataKeys().stream().anyMatch(missingSources::contains)) {
                skippedMetrics.add(calculator.getMetricCode());
            } else {
                try {
                    MetricResult result = calculator.calculate(buildContext(studentId, date));
                    availableMetrics.computeIfAbsent(
                        result.getMetricCode().substring(0, 2),
                        k -> new ArrayList<>()
                    ).add(result);
                } catch (Exception ignored) {
                    skippedMetrics.add(calculator.getMetricCode());
                }
            }
        }

        KehAssessment assessment = scoreAggregator.aggregate(
            studentId, date, availableMetrics, getProfile(studentId));

        // 降低数据完整度
        int totalMetrics = 24;
        int availableCount = totalMetrics - skippedMetrics.size();
        assessment.setDataCompleteness(
            BigDecimal.valueOf(availableCount).divide(BigDecimal.valueOf(totalMetrics), 2, RoundingMode.HALF_UP)
        );

        // 添加降级说明
        if (assessment.getDataCompleteness().compareTo(new BigDecimal("0.7")) < 0) {
            assessment.setNote("部分数据暂时不可用，当前评估基于" + availableCount + "/" + totalMetrics + "个指标");
        }

        return assessment;
    }
}
```

## 12. 安全与权限

### 12.1 数据访问控制

```java
/**
 * KEH数据访问权限校验

@Component
public class KehAccessChecker {

    public void checkAccess(Long requesterId, Long targetStudentId, AccessType type) {
        User requester = userService.getById(requesterId);

        // 1. 本人直接允许
        if (requesterId.equals(targetStudentId)) {
            return;
        }

        // 2. 家长检查
        if (requester.getUserType() == UserType.PARENT) {
            ParentBinding binding = parentBindingService
                .findByParentAndStudent(requesterId, targetStudentId);
            if (binding != null && binding.canViewHealthReport()) {
                return;
            }
            throw new ForbiddenException("未绑定该学生或无权查看健康报告");
        }

        // 3. 教师检查
        if (requester.getUserType() == UserType.TEACHER) {
            // 教师只能查看本班学生的概览
            if (type == AccessType.CLASS_OVERVIEW) {
                return; // 班级概览在Controller层校验classId归属
            }
            // 教师查看单个学生详情需要额外权限
            if (teacherService.canViewStudentDetail(requesterId, targetStudentId)) {
                return;
            }
            throw new ForbiddenException("无权查看该学生的详细健康数据");
        }

        // 4. 管理员
        if (requester.hasRole("ADMIN")) {
            return;
        }

        throw new ForbiddenException("无权访问");
    }
}
```

### 14.3 事件发布

```java
/**
 * KEH评估完成后发布领域事件
 */
@EventListener
public void onAssessmentCompleted(KehAssessmentCompletedEvent event) {
    KehAssessment assessment = event.getAssessment();

    // 发布到Kafka供下游消费
    kafkaTemplate.send("keh-events", KehEvent.builder()
        .eventType("ASSESSMENT_COMPLETED")
        .studentId(assessment.getStudentId())
        .kehScore(assessment.getKehScore())
        .healthLevel(assessment.getHealthLevel().name())
        .topIssueDimension(assessment.getTopIssues().isEmpty()
            ? null : assessment.getTopIssues().get(0).getDimensionCode())
        .timestamp(LocalDateTime.now())
        .build());

    // 如果分数变化超过阈值，单独发布变化事件
    if (assessment.getScoreDelta() != null
        && assessment.getScoreDelta().abs().compareTo(new BigDecimal("5")) >= 0) {
        kafkaTemplate.send("keh-events", KehEvent.builder()
            .eventType("SIGNIFICANT_SCORE_CHANGE")
            .studentId(assessment.getStudentId())
            .delta(assessment.getScoreDelta())
            .timestamp(LocalDateTime.now())
            .build());
    }
}
```
