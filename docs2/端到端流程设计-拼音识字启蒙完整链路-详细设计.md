## 1. 链路概述

### 1.1 核心场景

拼音识字启蒙模块覆盖以下核心学习场景，每个场景构成一条独立但相互衔接的端到端链路：

| 链路编号 | 场景 | 触发入口 | 核心路径 |
|----------|------|----------|----------|
| L01 | 拼音声韵母学习 | 启蒙主页 → 拼音入口 | 选拼音 → 发音演示 → 跟读录音 → 评分反馈 → 下一个 |
| L02 | 拼读组合练习 | 拼音学习 → 拼读练习 | 选声母+韵母 → 拼读动画 → 跟读 → 评分 |
| L03 | 声调练习 | 拼音学习 → 声调练习 | 听音 → 选调/标调 → 反馈 |
| L04 | 汉字卡片识记 | 启蒙主页 → 识字入口 | 浏览字库 → 卡片翻转 → 笔画动画 → 跟读 → 掌握标记 |
| L05 | 笔画描红练习 | 汉字卡片 → 描红 | 笔顺演示 → 描红书写 → 笔画检测 → 评分 |
| L06 | 配对连线小游戏 | 启蒙主页 → 游戏入口 | 选游戏类型 → 配对 → 计时计分 → 结算奖励 |
| L07 | 发音评测与纠音 | 跟读练习入口 | 朗读 → 录音 → ASR评分 → 纠音建议 → 重试 |
| L08 | 每日任务打卡 | 启蒙主页/每日任务卡片 | 查看任务 → 完成学习 → 打卡 → 奖励发放 |
| L09 | 家长查看报告 | 家长入口 | 身份验证 → 查看进度报告 → 调整学习计划 |

### 2.2 客户端关键交互

```dart
/// 拼音学习页面控制器
class PinyinLearningController extends GetxController {
  final PinyinItem currentPinyin;
  final AudioPlayer _audioPlayer = AudioPlayer();
  final PronunciationEvaluator _evaluator = PronunciationEvaluator();

  // 状态：idle / playing / recording / evaluating / result
  final state = LearningState.idle.obs;
  final score = 0.obs;
  final retryCount = 0.obs;
  final maxRetry = 3;

  /// 步骤1: 播放标准发音
  Future<void> playDemo() async {
    state.value = LearningState.playing;
    await _audioPlayer.play(UrlSource(currentPinyin.audioUrl));
    state.value = LearningState.idle;
  }

  /// 步骤2: 开始跟读录音
  Future<void> startRecording() async {
    state.value = LearningState.recording;
    await _evaluator.startRecording(maxDuration: const Duration(seconds: 5));
  }

  /// 步骤3: 停止录音并上传评测
  Future<void> stopAndEvaluate() async {
    state.value = LearningState.evaluating;
    final audioPath = await _evaluator.stopRecording();
    final result = await _literacyApi.evaluatePronunciation(
      pinyinId: currentPinyin.id,
      audioFilePath: audioPath,
      expectedPinyin: currentPinyin.pinyin,
    );
    score.value = result.score;
    state.value = LearningState.result;
  }

  /// 步骤4: 处理评分结果
  Future<void> handleResult() async {
    if (score.value >= 80) {
      // 标记掌握，播放成功动画
      await _literacyApi.markMastered(
        pinyinId: currentPinyin.id,
        score: score.value,
        retryCount: retryCount.value,
      );
      _showSuccessAnimation();
    } else {
      retryCount.value++;
      if (retryCount.value >= maxRetry) {
        // 超过重试次数，降低难度提示后继续
        _showEncouragement();
        await _literacyApi.markNeedsReview(pinyinId: currentPinyin.id);
      }
    }
  }
}
```

### 2.6 异常处理

| 异常场景 | 客户端处理 | 服务端处理 |
|----------|-----------|-----------|
| 录音权限被拒 | 引导到系统设置页开启权限 | 不涉及 |
| 录音超时（>10s） | 自动停止录音，提示"时间到" | 服务端超时限制 15s |
| 音频上传失败 | 本地缓存，离线队列稍后重试 | 返回 `AUDIO_UPLOAD_FAILED` |
| ASR 服务不可用 | 降级为本地基础评分（仅音量/时长判断） | 返回 `ASR_SERVICE_UNAVAILABLE`，降级标记 |
| 评分接口超时 | 显示"评测中..."超时提示，允许重试 | 30s 超时，超时返回 `EVALUATION_TIMEOUT` |
| 用户学段不匹配 | 禁止访问，提示"该内容不适合当前年级" | BFF 层校验学段，拒绝请求 |
| 亲子模式时长耗尽 | 弹窗提示"今天的学习时间到啦～" | 服务端校验每日学习时长 |

### 3.3 拼读评测逻辑

```java
/**
 * 拼读评测服务 - 处理声韵母组合的发音评测
 */
@Service
public class PinyinBlendEvaluationService {

    @Autowired
    private AsrEvaluationClient asrClient;

    @Autowired
    private LiteracyLearningLogRepository logRepo;

    @Autowired
    private ApplicationEventPublisher eventPublisher;

    /**
     * 评测拼读发音
     *
     * @param request 包含音频、声母、韵母、声调信息
     * @return 评测结果
     */
    public PinyinBlendEvalResult evaluate(PinyinBlendEvalRequest request) {
        // 1. 参数校验
        validateRequest(request);

        // 2. 调用ASR评测
        AsrEvalResult asrResult = asrClient.evaluatePronunciation(
            AsrEvalRequest.builder()
                .audioUrl(request.getAudioUrl())
                .expectedText(request.getExpectedSyllable()) // 如 "bā"
                .language("zh-CN")
                .mode("pinyin_blend")          // 拼读评测专用模式
                .gradeLevel(request.getGradeLevel())
                .build()
        );

        // 3. 计算综合评分
        int totalScore = calculateBlendScore(asrResult, request);

        // 4. 生成适龄反馈
        String feedback = generateFeedback(totalScore, request.getGradeLevel());

        // 5. 记录学习日志
        LiteracyLearningLog log = LiteracyLearningLog.builder()
            .userId(request.getUserId())
            .learnType("pinyin_blend")
            .targetId(request.getShengmuId() + "_" + request.getYunmuId())
            .score(totalScore)
            .timeSpentMs(request.getTimeSpentMs())
            .detail(buildDetail(asrResult, request))
            .build();
        logRepo.save(log);

        // 6. 发布学习事件（异步处理下游）
        eventPublisher.publishEvent(new PinyinLearnedEvent(
            request.getUserId(), "blend",
            request.getShengmuId(), request.getYunmuId(),
            totalScore
        ));

        return PinyinBlendEvalResult.builder()
            .score(totalScore)
            .level(getScoreLevel(totalScore))
            .feedback(feedback)
            .pronunciationAccuracy(asrResult.getAccuracy())
            .toneAccuracy(asrResult.getToneAccuracy())
            .blendSmoothness(asrResult.getFluency())
            .build();
    }

    /**
     * 拼读综合评分算法
     * 声母清晰度 30% + 韵母准确度 30% + 声调 20% + 拼读流畅度 20%
     */
    private int calculateBlendScore(AsrEvalResult asrResult,
                                     PinyinBlendEvalRequest request) {
        double shengmuScore = asrResult.getInitialConsonantScore() * 0.30;
        double yunmuScore = asrResult.getVowelScore() * 0.30;
        double toneScore = asrResult.getToneAccuracy() * 0.20;
        double fluencyScore = asrResult.getFluency() * 0.20;
        return (int) Math.round(shengmuScore + yunmuScore + toneScore + fluencyScore);
    }

    private String generateFeedback(int score, String gradeLevel) {
        if ("K".equals(gradeLevel)) {
            // 幼儿版反馈：更多鼓励性语言
            if (score >= 80) return "太好啦！你读得真好听！🌟";
            if (score >= 60) return "很棒哦！再来一次就更厉害啦！💪";
            return "加油加油！听听声音再试试～🎵";
        } else {
            // 小学版反馈：更有指导性
            if (score >= 80) return "发音很标准！继续保持！";
            if (score >= 60) return "不错！注意声调会更好哦";
            return "再仔细听一遍示范，然后试着跟读";
        }
    }
}
```

```
                  ┌────────────┐
   创建会话 ───→ │  GENERATED  │ 练习集已生成，未开始
                  └─────┬──────┘
                        │ 客户端提交首题答案
```

守卫规则：

| 编号 | 规则 |
|------|------|
| G1 | 会话内题目顺序固定，断线重连按已答进度续答，不重新出题 |
| G2 | 同一题目最多重试 2 次，第三次直接收题记弱项，防挫败 |
| G3 | read 模式录音评测失败不判错，该题标记 `EVAL_FAILED` 不计入正确率 |
| G4 | 结算以服务端判定为准，客户端不得本地累计星星后直传总数 |
| G5 | mark 模式汉字必须带词语文本，单字多音字按词语语境取音（服务端词表裁决） |

### 4.4 声调判定与弱项诊断逻辑

```java
/**
 * 声调判定服务：听音/标调即时判定 + 二声三声混淆专项诊断
 */
@Service
public class ToneJudgementService {

    /** 声调混淆对定义：key 为作答声调，value 为常见误选目标 */
    private static final Map<Integer, List<Integer>> CONFUSION_PAIRS = Map.of(
        2, List.of(3),   // 二声←误为三声（阳平/上声混淆，最高频）
        3, List.of(2),   // 三声←误为二声
        1, List.of(4),   // 一声←误为四声（较少见）
        4, List.of(1)
    );

    public ToneAnswerResult judge(ToneAnswerRequest req, ToneQuestion q) {
        boolean correct = req.getAnswerTone() == q.getTargetTone();

        ToneAnswerResult result = new ToneAnswerResult();
        result.setCorrect(correct);
        result.setTargetTone(q.getTargetTone());
        result.setAnsweredTone(req.getAnswerTone());

        if (!correct) {
            // 仅当作答声调属于该目标的常见混淆对时才给出专项提示
            boolean isConfusion = CONFUSION_PAIRS
                .getOrDefault(q.getTargetTone(), List.of())
                .contains(req.getAnswerTone());
            result.setConfusionType(isConfusion
                ? "tone" + q.getTargetTone() + "_tone" + req.getAnswerTone()
                : "random");
            result.setFeedback(isConfusion
                ? TONE_CONFUSION_FEEDBACK.get(q.getTargetTone(), req.getAnswerTone())
                : TONE_GENERIC_FEEDBACK.get(q.getTargetTone()));
            result.setRetryAllowed(req.getRetryCount() < 2); // G2
        }
        return result;
    }

    /**
     * 会话结算：按 confusionType 聚合，写入声调弱项画像
     * 同一混淆对出现 ≥3 次 → 生成专项巩固练习集（下次优先 mark 模式）
     */
    @Transactional
    public void settle(String sessionId, long userId) {
        List<TonePracticeLog> logs = logRepo.findBySessionId(sessionId);
        Map<String, Long> confusionCount = logs.stream()
            .filter(l -> !l.isCorrect() && l.getConfusionType() != null)
            .collect(Collectors.groupingBy(
                TonePracticeLog::getConfusionType, Collectors.counting()));

        confusionCount.forEach((type, cnt) -> {
            if (cnt >= 3) {
                weaknessProfileRepo.upsert(userId, "tone", type,
                    WeaknessLevel.FOCUSED_REVIEW);
            }
        });
    }
}
```

### 4.6 异常处理

| 异常场景 | 客户端处理 | 服务端处理 |
|----------|-----------|-----------|
| 音频加载失败（listen） | 重试下载 2 次后跳过该题并上报 `AUDIO_404` | 题目快照含音频 URL 失效监控，单 URL 失败率 >5% 告警 |

| ASR 不可用（read） | 该题标记"待评测"，练习集照常结算，弱项不计 | 评测任务入延迟队列，10min 内补偿一次，仍失败按 G3 记 `EVAL_FAILED` |

| 二/三声混淆连续 ≥3 次 | 无感 | 写入弱项画像，下次练习集 40% 题目为该混淆对专项 |

### 5.2 客户端关键交互

```dart
/// 汉字卡片控制器：翻转 + 笔顺动画 + 认读检测
class CharacterCardController extends GetxController {
  final CharacterCard card;
  final FlipCardController _flip = FlipCardController();
  final StrokeAnimationPlayer _strokePlayer = StrokeAnimationPlayer();
  final PronunciationEvaluator _evaluator = PronunciationEvaluator();

  final flipped = false.obs;          // 是否翻到背面
  final strokeStep = (-1).obs;        // -1 未开始，0..n-1 分步
  final evalState = EvalState.idle.obs;

  /// 翻转卡片（正面：图+字；背面：拼音+词+句）
  Future<void> flip() async {
    if (evalState.value == EvalState.recording) return; // 录音中禁翻
    flipped.value = !flipped.value;
    _flip.toggleCard();
  }

  /// 笔顺动画：先分步演示一次，再连播一次
  Future<void> playStrokes() async {
    strokeStep.value = 0;
    for (var i = 0; i < card.strokes.length; i++) {
      strokeStep.value = i;
      await _strokePlayer.playStroke(
          card.strokes[i].svgPath, card.strokes[i].durationMs);
    }
    strokeStep.value = -1;
  }

  /// 认读检测：跟读 → 上传 → 判定
  Future<RecognizeResult> checkRecognize() async {
    evalState.value = EvalState.recording;
    final audioPath = await _evaluator.record(maxDuration: Duration(seconds: 5));
    evalState.value = EvalState.evaluating;
    final result = await _literacyApi.evaluateCharacterRecognize(
      characterId: card.id,
      audioFilePath: audioPath,
      expectedPinyin: card.pinyin,
    );
    evalState.value = EvalState.idle;
    return result;
  }

  /// 掌握上报（含客户端幂等键）
  Future<void> reportMastery(RecognizeResult r) async {
    await _literacyApi.reportCharacterMastery(
      characterId: card.id,
      recognizeCorrect: r.recognized == card.charText,
      pronunciationScore: r.score,
      clientRequestId: Uuid().v4(),   // 每次点击生成，重试复用
    );
  }
}
```

交互红线（幼儿防误触，详见 `客户端-全局防误触与儿童安全交互保护机制-详细设计.md`）：

- 卡片翻转响应区 ≥ 96dp，连点 300ms 防抖；
- 笔顺动画播放中切换卡片不打断音频，先停再放；
- 认读录音按钮需长按 300ms 启动（防手掌误触），最长 5s 自动停止。

### 5.4 服务端内部处理流程

```
上报请求
   │
   ▼
BFF：参数校验 → 学段校验 → 亲子时长校验
   │
   ▼
CharacterMasteryService.report()
   ├── 1. 幂等检查：uk(user, character, clientRequestId) 命中 → 返回缓存结果
   ├── 2. 更新 user_item_mastery（事务内）：
   │      ├── recognize_streak：正确 +1 / 错误清零
   │      ├── status 迁移：streak ≥ 2 → mastered（CAS，见 5.5）
   │      ├── pronunciation_mastered：score ≥ 80 置 1（只升不降）
   │      └── last_practiced_at / 弱项字段更新
   ├── 3. 写 literacy_learning_log
   ├── 4. Outbox 同事务落事件：
   │      ├── literacy.character.mastered（扇出：成就/复习计划/画像/家长报告）
   │      └── literacy.pronunciation.evaluated（扇出：发音陪练服务）
   ├── 5. 异步：间隔重复引擎回写 next_review_at（mastered 后 2 天首复习）
   └── 6. 返回掌握状态 + 奖励（星星按维度：认读 1 + 发音 2）
```

### 5.5 数据库操作

```sql
-- 掌握度更新（user_item_mastery 为掌握度 SSOT，其他模块禁止双写）
UPDATE user_item_mastery
SET recognize_streak = IF(? = 1, recognize_streak + 1, 0),
    status = CASE
        WHEN ? = 1 AND recognize_streak + 1 >= 2 THEN 'mastered'
        WHEN status = 'mastered' THEN 'mastered'   -- 已掌握不回退（遗忘由复习引擎裁决）
        ELSE 'learning'
    END,
    pronunciation_mastered = GREATEST(pronunciation_mastered, ? >= 80),
    best_pronunciation_score = GREATEST(best_pronunciation_score, ?),
    last_practiced_at = NOW(),
    version = version + 1
WHERE user_id = ? AND item_type = 'character' AND item_id = ?;
```

已掌握后答错不降级，由复习链路按遗忘曲线裁决（详见 `端到端流程设计-错题整理与复习巩固完整链路-详细设计.md` 的 G7 复活规则同款设计）。

### 5.6 异常处理

| 异常场景 | 客户端处理 | 服务端处理 |
|----------|-----------|-----------|
| 笔顺 SVG 加载失败 | 降级为静态田字格 + 笔顺序号文字提示 | CDN 失败率监控，单字降级计数 |
| 认读 ASR 结果与目标字不符（识别为其他字） | 展示"你读的是 X，再试试"（不出目标字答案） | 返回 `recognizedText` 供鼓励式反馈 |
| 掌握上报重复 | 无感 | 幂等键命中，返回首次结果，奖励不重复 |
| 内容下架（character 状态变更） | 卡片列表刷新跳过该字 | 返回 `EL_4006`，详情接口 410 Gone |
| 离线浏览卡片 | 本地缓存展示，掌握上报入离线队列 | 恢复网络后客户端批量补报（每请求幂等键唯一） |

## 6. 链路衔接与事件扇出

三条链路（L01/L02/L03/L04）结算统一走 `user_item_mastery`（item_type = pinyin / character）作为掌握度 SSOT，事件经 Outbox 发布：

| 事件 | 生产者 | 主要消费方 |
|------|--------|-----------|
| `literacy.pinyin.mastered` | L01 结算 | 成就引擎、间隔重复引擎、学习画像（幼儿版）、家长日报 |
| `literacy.blend.mastered` | L02 结算 | 成就引擎、学习画像、首页薄弱点提醒 |
| `literacy.tone.mastered` | L03 结算 | 弱项画像、推荐编排（声调专项巩固集） |
| `literacy.character.mastered` | L04 结算 | 成就引擎、间隔重复引擎、家长日报、单元进度 |

跨链路编排规则：

1. L02 拼读组合只推荐 `user_item_mastery` 中声母/韵母均已 mastered 的组合，未掌握组合前端置灰并提示"先去学 b 和 ā"；
2. L03 练习集生成优先取声调弱项画像中的 `confusion_type`，无弱项时按教材顺序；
3. L04 智能推荐字库取"已学拼音覆盖范围内未掌握汉字"∩ 教材当前单元；
4. 所有链路共享亲子模式时长校验（BFF 统一门控，返回 `EL_4004`）。
