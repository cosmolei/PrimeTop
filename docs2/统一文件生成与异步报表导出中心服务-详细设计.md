# 统一文件生成与异步报表导出中心服务 详细设计

## 1. 概述

### 1.1 模块定位

统一文件生成与异步报表导出中心（以下简称"导出中心"或 ExportHub）是 PrimeTop 平台的基础设施层服务，为各业务模块提供统一的文件生成、格式转换、异步导出和分发能力。

**解决的核心问题：** 当前平台中学习报告生成、错题打印、学习数据导出、学情报告交付等多个业务场景都需要生成文件（PDF/Excel/CSV/图片等）。如果每个模块各自实现文件生成逻辑，会导致：
- 重复造轮子，模板和渲染逻辑分散
- 大文件生成阻塞主线程，影响接口响应时间
- 存储管理和临时文件清理策略不一致
- 导出任务的进度追踪和失败重试机制缺失
- 权限控制和敏感数据脱敏规则不统一

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 模板管理 | 管理各类报表/文件的模板（PDF模板、Excel模板、邮件模板等） |
| 异步任务调度 | 接收导出请求，异步执行文件生成，支持优先级队列 |
| 多格式渲染 | 支持 PDF、Excel(xlsx)、CSV、JSON、PNG/JPG 图片等格式输出 |
| 存储与分发 | 生成文件上传至对象存储，返回预签名下载URL |
| 进度追踪 | 实时追踪导出任务状态，支持前端轮询或WebSocket推送 |
| 生命周期管理 | 临时文件过期清理、配额管理、审计日志 |

### 1.3 依赖关系

```
┌─────────────────────────────────────────────────────────┐
│                    业务调用方                             │
│  学习报告服务  错题服务  学情分析  数据导出  运营后台      │
└─────────────┬───────────────────────────────────────────┘
              │ 提交导出请求 (HTTP / 消息队列)
              ▼
┌─────────────────────────────────────────────────────────┐
│              ExportHub 导出中心服务                       │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌─────────┐ │
│  │ 任务调度  │  │ 模板引擎  │  │ 渲染引擎  │  │ 存储管理 │ │
│  └──────────┘  └──────────┘  └──────────┘  └─────────┘ │
└──────┬──────────────┬──────────────┬────────────────────┘
       │              │              │
       ▼              ▼              ▼
  Redis(队列)    模板存储(DB)   对象存储(OSS/S3)
  MySQL(任务表)  文件服务器      CDN
```

**上游依赖（调用方）：**
- 学习报告生成与交付服务 → 生成 PDF 学习报告
- 错题整理服务 → 生成错题打印 PDF
- 学情分析服务 → 生成学情分析报告
- 学习数据导出与账户注销服务 → 导出用户数据 JSON/CSV
- 运营管理后台 → 导出运营数据 Excel
- 支付对账服务 → 导出对账单 Excel

**下游依赖（被依赖）：**
- Redis — 任务队列、状态缓存
- MySQL — 任务元数据、模板配置
- 对象存储（OSS/S3/MinIO）— 文件存储
- CDN — 文件分发加速
- PDF 渲染库（Puppeteer / iText / wkhtmltopdf）
- Excel 生成库（Apache POI / EasyExcel）
- 消息队列 — 任务状态变更通知

```sql
    `biz_type`          VARCHAR(50)  NOT NULL COMMENT '业务类型：LEARNING_REPORT, MISTAKE_PRINT, ANALYTICS_EXPORT, DATA_EXPORT, SETTLEMENT_SHEET等',
    `biz_ref_id`        VARCHAR(128) NULL COMMENT '业务关联ID（如报告ID、错题本ID等）',
    `template_id`       VARCHAR(64)  NULL COMMENT '使用的模板ID',
    
    `file_format`       VARCHAR(20)  NOT NULL COMMENT '输出格式：PDF, XLSX, CSV, JSON, PNG',

    `progress`          TINYINT      NOT NULL DEFAULT 0 COMMENT '进度百分比 0-100',
    `priority`          TINYINT      NOT NULL DEFAULT 5 COMMENT '优先级：1-最高 5-普通 9-最低',
    
    `params_json`       TEXT         NULL COMMENT '导出参数JSON（业务自定义参数）',
    `result_json`       TEXT         NULL COMMENT '导出结果JSON（页数、数据条数等元信息）',
    `error_code`        VARCHAR(50)  NULL COMMENT '失败错误码',
    `error_msg`         TEXT         NULL COMMENT '失败错误描述',
    `retry_count`       INT          NOT NULL DEFAULT 0 COMMENT '已重试次数',
    `max_retry`         INT          NOT NULL DEFAULT 3 COMMENT '最大重试次数',
    
    `callback_url`      VARCHAR(512) NULL COMMENT '完成后回调通知URL',
    `callback_status`   TINYINT      NULL COMMENT '回调状态：0-未回调 1-回调成功 2-回调失败',
    
    `estimated_seconds` INT          NULL COMMENT '预计完成耗时（秒）',

    `expires_at`        DATETIME     NULL COMMENT '文件过期时间（过期后自动清理）',
    `started_at`        DATETIME     NULL COMMENT '开始处理时间',
    `completed_at`      DATETIME     NULL COMMENT '完成处理时间',
    `created_at`        DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at`        DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_task_no` (`task_no`),
    KEY `idx_user_id` (`user_id`, `status`),
    KEY `idx_biz_type` (`biz_type`, `status`),
    KEY `idx_status_priority` (`status`, `priority`, `created_at`),
    KEY `idx_expires_at` (`expires_at`, `status`)
```

### 2.2 Redis 数据结构

```redis
# 任务队列（有序集合，score=优先级权重）
ZSET: exporthub:queue:pending
  member: task_no
  score: priority_score (priority * 1000000000 + timestamp)

# 处理中队列（Hash，用于故障恢复）
HASH: exporthub:queue:processing
  field: task_no
  value: JSON{worker_id, started_at, heartbeat_at}

# 任务进度缓存
STRING: exporthub:progress:{task_no}
  value: JSON{status, progress, estimated_seconds, current_step}
  TTL: 3600s

# 用户导出配额计数（日维度）
STRING: exporthub:quota:{user_id}:daily:{date}
  value: count
  TTL: 172800s (48小时)

# 模板缓存
STRING: exporthub:template:{template_id}
  value: JSON{template config}
  TTL: 3600s

# 分布式锁（防止同一用户重复提交相同导出）
STRING: exporthub:lock:{user_id}:{biz_type}:{params_hash}
  value: task_no
  TTL: 300s
```

## 3. API 接口设计

### 3.1 接口列表

| # | 接口 | 方法 | 路径 | 说明 |
|---|------|------|------|------|
| 1 | 提交导出任务 | POST | `/api/v1/export/tasks` | 创建异步导出任务 |

### 3.2 提交导出任务

```
POST /api/v1/export/tasks
Authorization: Bearer {access_token}
Content-Type: application/json
```

**请求体：**

```json
{
    "bizType": "LEARNING_REPORT",
    "bizRefId": "report_20260615_001",
    "fileFormat": "PDF",
    "templateId": "TPL_LEARNING_REPORT_V2",
    "fileName": "学习报告-张三-2026年6月.pdf",
    "priority": 5,
    "params": {
        "studentId": 100001,
        "studentName": "张三",
        "grade": "初一",
        "semester": "2026春季",
        "startDate": "2026-02-01",
        "endDate": "2026-06-30",
        "subjects": ["语文", "数学", "英语"],
        "includeCharts": true,
        "includeSuggestions": true,
        "watermark": {
            "text": "PrimeTop",
            "opacity": 0.1
        }
    },
    "callbackUrl": "https://api.primetop.com/internal/report/notify",
    "expiresInHours": 168
}
```

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| bizType | String | 是 | 业务类型枚举 |
| bizRefId | String | 否 | 业务关联ID，便于追溯 |
| fileFormat | String | 是 | 输出格式：PDF/XLSX/CSV/JSON/PNG |
| templateId | String | 否 | 指定模板ID，不指定则按 bizType 取默认模板 |
| fileName | String | 是 | 输出文件名 |
| priority | Integer | 否 | 优先级 1-9，默认5 |
| params | Object | 是 | 业务参数，结构由 bizType 决定 |
| callbackUrl | String | 否 | 完成后回调通知URL |
| expiresInHours | Integer | 否 | 文件有效期（小时），默认168（7天） |

**响应：**

```json
{
    "code": 0,
    "message": "success",
    "data": {
        "taskNo": "EXP20260615143022001",
        "status": "PENDING",
        "estimatedSeconds": 30,
        "queryInterval": 3,
        "expiresAt": "2026-06-22T14:30:22+08:00"
    }
}
```

**业务类型枚举 `bizType`：**

| 枚举值 | 说明 | 默认格式 | 典型大小 | 预计耗时 |
|--------|------|----------|----------|----------|
| LEARNING_REPORT | 学习报告 | PDF | 2-10MB | 15-60s |
| MISTAKE_PRINT | 错题打印 | PDF | 1-20MB | 10-90s |
| ANALYTICS_EXPORT | 学情分析 | PDF | 1-5MB | 10-30s |
| DATA_EXPORT | 用户数据导出 | JSON | 1-50MB | 5-120s |
| OPERATION_DATA | 运营数据导出 | XLSX | 1-30MB | 10-60s |
| SETTLEMENT_SHEET | 对账单 | XLSX | <1MB | 3-10s |
| QUESTION_BANK | 题库导出 | XLSX | 1-50MB | 10-120s |
| EXAM_PAPER | 试卷生成 | PDF | 1-5MB | 10-30s |
| KNOWLEDGE_MAP | 知识图谱导出 | PNG | 1-5MB | 5-15s |
| CUSTOM | 自定义 | 视参数 | - | - |

### 3.3 同步导出（小文件快通道）

```
POST /api/v1/export/sync
Authorization: Bearer {access_token}
Content-Type: application/json
```

用于生成小文件（<1MB）或简单格式的快速导出，超时时间10秒。

**请求体：** 与异步接口相同，增加 `timeout` 参数。

**响应（成功）：** 直接返回文件流。

```
HTTP/1.1 200 OK
Content-Type: application/pdf
Content-Disposition: attachment; filename="report.pdf"
Content-Length: 524288

[文件二进制数据]
```

**响应（超时）：** 自动降级为异步任务。

```json
{
    "code": 0,
    "data": {
        "taskNo": "EXP20260615143022001",
        "status": "PENDING",
        "message": "同步导出超时，已自动转异步处理"
    }
}
```

### 3.5 错误码定义

| 错误码 | HTTP状态码 | 说明 |
|--------|-----------|------|
| EXPORT_001 | 400 | 参数校验失败 |
| EXPORT_002 | 400 | 不支持的文件格式 |
| EXPORT_003 | 400 | 不支持的业务类型 |
| EXPORT_004 | 400 | 模板ID不存在或已禁用 |
| EXPORT_005 | 403 | 无权限导出此数据 |
| EXPORT_006 | 403 | 导出次数已达配额上限 |
| EXPORT_007 | 409 | 存在相同的导出任务正在处理 |
| EXPORT_008 | 404 | 任务不存在 |
| EXPORT_009 | 409 | 任务状态不允许此操作 |
| EXPORT_010 | 413 | 导出数据量超过最大限制 |
| EXPORT_101 | 500 | 模板渲染失败 |
| EXPORT_102 | 500 | 文件生成失败 |
| EXPORT_103 | 500 | 对象存储上传失败 |
| EXPORT_104 | 500 | 回调通知失败 |
| EXPORT_201 | 503 | 系统繁忙，导出队列已满 |

## 4. 业务逻辑

### 4.1 核心流程 — 异步导出全链路

```
客户端                      API网关                ExportHub              Worker              对象存储
  │                           │                      │                     │                    │
  │  1. POST /export/tasks    │                      │                     │                    │
  ├──────────────────────────►│                      │                     │                    │
  │                           │  2. 转发请求          │                     │                    │
  │                           ├─────────────────────►│                     │                    │
  │                           │                      │ 3. 校验参数          │                    │
  │                           │                      │ 4. 检查配额          │                    │
  │                           │                      │ 5. 检查幂等(防重复)   │                    │
  │                           │                      │ 6. 创建任务记录       │                    │
  │                           │                      │ 7. 推入优先级队列     │                    │
  │                           │  8. 返回taskNo       │                     │                    │
  │                           │◄─────────────────────┤                     │                    │
  │  9. 返回taskNo + 预估时间  │                      │                     │                    │
```

| SUCCESS | 2 | 文件生成成功 | EXPIRED |

### 4.3 优先级调度策略

```java
/**
 * 优先级权重计算：
 * score = priority * 1_000_000_000 + (currentTimeMillis - epoch)
 * 
 * 优先级越低(score越小)越先被消费
 * 同优先级按 FIFO 排序
 * 
 * 特殊规则：
 * - VIP用户/付费会员自动提升1级优先级
 * - 管理后台导出固定为优先级2
 * - 数据导出(账户注销)固定为优先级1(法定要求)
 * - 运营批量导出降为优先级8
 */
public double calculateScore(ExportTask task) {
    int effectivePriority = task.getPriority();
    
    // 会员优先级提升
    if (membershipService.isPremium(task.getUserId())) {
        effectivePriority = Math.max(1, effectivePriority - 1);
    }
    
    // 账户注销数据导出最高优先级
    if ("DATA_EXPORT".equals(task.getBizType())) {
        effectivePriority = 1;
    }
    
    long timeWeight = System.currentTimeMillis() / 1000;
    return effectivePriority * 1_000_000_000L + timeWeight;
}
```

```java
public ExportTask createTask(ExportRequest request, Long userId) {
    // 1. 计算请求参数指纹
    String paramsHash = DigestUtils.md5Hex(JSON.toJSONString(request.getParams()));
    
    // 2. 获取分布式锁
    String lockKey = String.format("exporthub:lock:%d:%s:%s", 
        userId, request.getBizType(), paramsHash);
    
    Boolean locked = redisTemplate.opsForValue()
        .setIfAbsent(lockKey, "LOCKED", 10, TimeUnit.SECONDS);
    
    if (Boolean.FALSE.equals(locked)) {
        // 3. 锁获取失败，说明有相同请求正在处理
        String existingTaskNo = redisTemplate.opsForValue().get(lockKey);
        ExportTask existing = taskRepository.findByTaskNo(existingTaskNo);
        if (existing != null && existing.isInProgress()) {
            throw new BusinessException("EXPORT_007", 
                "存在相同的导出任务正在处理，请稍后查看");
        }
    }
    
    try {
        // 4. 检查是否有最近完成的相同导出（5分钟内）
        ExportTask recent = taskRepository.findRecentCompleted(
            userId, request.getBizType(), paramsHash, 
            LocalDateTime.now().minusMinutes(5));
        if (recent != null && recent.getFileUrl() != null) {
            // 直接返回已有结果
            return recent;
        }
        
        // 5. 创建新任务
        ExportTask task = buildTask(request, userId, paramsHash);
        taskRepository.save(task);
        
        // 6. 推入队列
        double score = priorityCalculator.calculateScore(task);
        redisTemplate.opsForZSet().add("exporthub:queue:pending", 
            task.getTaskNo(), score);
        
        // 7. 设置任务锁，关联task_no
        redisTemplate.opsForValue().set(lockKey, task.getTaskNo(), 
            5, TimeUnit.MINUTES);
        
        return task;
    } finally {
        // 注意：不立即释放锁，保留5分钟防止重复提交
    }
}
```

```java
/**
 * 定时任务：每小时执行一次
 * 1. 扫描已过期(SUCCESS状态且expires_at < now)的任务
 * 2. 从对象存储删除文件
 * 3. 更新任务状态为EXPIRED
 * 4. 记录审计日志
 */
@Scheduled(cron = "0 0 * * * ?")
public void cleanupExpiredFiles() {
    int batchSize = 100;
    int totalCleaned = 0;
    
    while (true) {
        List<ExportTask> expired = taskRepository.findExpiredTasks(
            ExportStatus.SUCCESS, LocalDateTime.now(), batchSize);
        
        if (expired.isEmpty()) break;
        
        for (ExportTask task : expired) {
            try {
                // 批量删除对象存储文件
                storageService.deleteFile(task.getStoragePath());
                
                // 更新状态
                task.setStatus(ExportStatus.EXPIRED);
                task.setFileUrl(null);
                taskRepository.save(task);
                
                // 审计日志
                auditLogger.log(task.getTaskNo(), AuditAction.EXPIRE, 
                    "文件过期自动清理");
                
                totalCleaned++;
            } catch (Exception e) {
                log.warn("清理过期文件失败: {}", task.getTaskNo(), e);
                // 即使删除失败也标记为过期，避免反复尝试
                task.setStatus(ExportStatus.EXPIRED);
                taskRepository.save(task);
            }
        }
        
        if (expired.size() < batchSize) break;
    }
    
    log.info("过期文件清理完成，共清理 {} 个文件", totalCleaned);
}
```

```java
@Component
@ConditionalOnProperty(name = "exporthub.render.pdf.engine", havingValue = "puppeteer")
public class PuppeteerPdfRenderer implements RenderStrategy {
    
    @Value("${exporthub.render.pdf.browser-path}")
    private String browserPath;
    
    @Value("${exporthub.render.pdf.timeout-seconds:120}")
    private int timeoutSeconds;
    
    @Override
    public String supportedFormat() {
        return "PDF";
    }
    
    @Override
    public RenderResult render(RenderContext context) throws RenderException {
        ExportTemplate template = context.getTemplate();
        Map<String, Object> data = context.getData();
        PageConfig pageConfig = context.getPageConfig();
        
        try {
            // 1. 渲染HTML模板（使用Thymeleaf/Freemarker）
            String htmlContent = htmlTemplateEngine.render(
                template.getTemplateContent(), data);
            
            // 2. 注入CSS样式
            String fullHtml = wrapHtmlWithStyles(htmlContent, 
                template.getCssContent(), pageConfig);
            
            // 3. 调用Puppeteer生成PDF
            File pdfFile = generatePdfViaPuppeteer(fullHtml, pageConfig);
            
            // 4. 构建结果
            RenderResult result = new RenderResult();
            result.setFile(pdfFile);
            result.setFileSize(pdfFile.length());
            result.setFileHash(DigestUtils.md5Hex(pdfFile));
            result.setMetadata(Map.of(
                "pages", countPdfPages(pdfFile),
                "engine", "puppeteer"
            ));
            
            return result;
            
        } catch (TemplateRenderException e) {
            throw new RenderException("PDF_TEMPLATE_RENDER_FAILED", 
                "模板渲染失败: " + e.getMessage(), e);
        } catch (Exception e) {
            throw new RenderException("PDF_GENERATION_FAILED", 
                "PDF生成失败: " + e.getMessage(), e);
        }
    }
    
    /**
     * 通过Puppeteer生成PDF
     */
    private File generatePdfViaPuppeteer(String html, PageConfig config) throws Exception {
        Path tempHtml = Files.createTempFile("export_", ".html");
        Path tempPdf = Files.createTempFile("export_", ".pdf");
        
        try {
            Files.writeString(tempHtml, html, StandardCharsets.UTF_8);
            
            // 构建Puppeteer CLI命令
            List<String> command = List.of(
                "node", "/app/scripts/pdf-generator.js",
                "--input", tempHtml.toString(),
                "--output", tempPdf.toString(),
                "--format", config.getPaperSize(),        // A4 / A3 / Letter
                "--orientation", config.getOrientation(),  // portrait / landscape
                "--margin-top", config.getMarginTop(),     // "20mm"
                "--margin-bottom", config.getMarginBottom(),
                "--margin-left", config.getMarginLeft(),
                "--margin-right", config.getMarginRight(),
                "--print-background", "true",
                "--timeout", String.valueOf(timeoutSeconds * 1000)
            );
            
            // 添加Header/Footer模板
            if (StringUtils.isNotBlank(config.getHeaderTemplate())) {
                command.addAll(List.of("--header-template", config.getHeaderTemplate()));
            }
            if (StringUtils.isNotBlank(config.getFooterTemplate())) {
                command.addAll(List.of("--footer-template", config.getFooterTemplate()));
            }
            
            // 执行命令
            ProcessExecutor.execute(command, timeoutSeconds);
            
            return tempPdf.toFile();
            
        } finally {
            Files.deleteIfExists(tempHtml);
        }
    }
    
    @Override
    public int estimateDuration(RenderContext context) {
        // 根据数据量和页数预估
        int dataItems = context.getIntParam("dataCount", 50);
        return Math.max(5, dataItems / 20 + 10);
    }
}
```

### 5.3 Worker 消费与心跳机制

```java
/**
 * 导出任务Worker
 * 多实例部署，每个实例运行多个Worker线程
 */
@Component
public class ExportWorker implements Runnable {
    
    private static final int HEARTBEAT_INTERVAL_SECONDS = 10;
    private static final int TASK_TIMEOUT_MINUTES = 30;
    
    @Autowired
    private ExportTaskRepository taskRepository;
    @Autowired
    private ExportTemplateService templateService;
    @Autowired
    private RenderStrategyFactory renderStrategyFactory;
    @Autowired
    private StorageService storageService;
    @Autowired
    private ExportCallbackService callbackService;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    private final String workerId = "worker-" + hostname + "-" + threadId;
    private volatile boolean running = true;
    
    @Override
    public void run() {
        log.info("ExportWorker {} started", workerId);
        
        // 启动心跳线程
        ScheduledExecutorService heartbeat = Executors.newSingleThreadScheduledExecutor();
        heartbeat.scheduleAtFixedRate(this::heartbeat, 
            0, HEARTBEAT_INTERVAL_SECONDS, TimeUnit.SECONDS);
        
        try {
            while (running) {
                processOneTask();
            }
        } finally {
            heartbeat.shutdown();
            log.info("ExportWorker {} stopped", workerId);
        }
    }
    
    private void processOneTask() {
        // 1. 从优先级队列获取任务（阻塞式，超时5秒）
        Set<ZSetOperations.TypedTuple<String>> tasks = redisTemplate.opsForZSet()
            .rangeWithScores("exporthub:queue:pending", 0, 0);
        
        if (tasks == null || tasks.isEmpty()) {
            SleepUtil.sleep(Duration.ofSeconds(1));
            return;
        }
        
        ZSetOperations.TypedTuple<String> tuple = tasks.iterator().next();
        String taskNo = tuple.getValue();
        
        // 2. 原子性取出任务（防止其他Worker重复消费）
        Double score = tuple.getScore();
        Long removed = redisTemplate.opsForZSet()
            .removeRangeByScore("exporthub:queue:pending", score, score);
        
        if (removed == null || removed == 0) {
            return; // 被其他Worker抢走了
        }
        
        // 3. 加锁到processing队列
        String processingKey = "exporthub:queue:processing:" + taskNo;
        ProcessingInfo info = new ProcessingInfo(workerId, Instant.now(), Instant.now());
        redisTemplate.opsForHash().put("exporthub:queue:processing", 
            taskNo, JSON.toJSONString(info));
        
        ExportTask task = taskRepository.findByTaskNo(taskNo);
        if (task == null) {
            log.warn("Task not found: {}", taskNo);
            redisTemplate.opsForHash().delete("exporthub:queue:processing", taskNo);
            return;
        }
        
        // 4. 更新任务状态
        task.setStatus(ExportStatus.PROCESSING);
        task.setStartedAt(LocalDateTime.now());
        taskRepository.save(task);
        
        // 5. 执行渲染
        try {
            RenderResult result = executeRender(task);
            
            // 6. 上传到对象存储
            String storagePath = buildStoragePath(task, result.getFile());
            String fileUrl = storageService.upload(
                result.getFile(), storagePath, task.getFileFormat());
            
            // 7. 更新任务为成功
            task.setStatus(ExportStatus.SUCCESS);
            task.setFileUrl(fileUrl);
            task.setStoragePath(storagePath);
            task.setFileSize(result.getFileSize());
            task.setFileHash(result.getFileHash());
            task.setProgress(100);
            task.setCompletedAt(LocalDateTime.now());
            task.setActualSeconds((int) Duration.between(
                task.getStartedAt(), task.getCompletedAt()).getSeconds());
            task.setResultJson(JSON.toJSONString(result.getMetadata()));
            taskRepository.save(task);
            
            // 8. 发送回调通知
            callbackService.notifyCallback(task);
            
            // 9. 清理本地临时文件
            cleanupTempFile(result.getFile());
            
            log.info("Export task completed: {} in {}s", 
                taskNo, task.getActualSeconds());
            
        } catch (Exception e) {
            handleTaskFailure(task, e);
        } finally {
            // 10. 从processing队列移除
            redisTemplate.opsForHash().delete("exporthub:queue:processing", taskNo);
        }
    }
    
    /**
     * 执行渲染
     */
    private RenderResult executeRender(ExportTask task) throws RenderException {
        // 加载模板
        ExportTemplate template = templateService.getById(task.getTemplateId());
        
        // 准备渲染上下文
        RenderContext context = RenderContext.builder()
            .task(task)
            .template(template)
            .data(task.getParamsAsMap())
            .pageConfig(PageConfig.from(template))
            .watermarkConfig(WatermarkConfig.from(task.getParamsAsMap()))
            .progressCallback(progress -> updateProgress(task.getTaskNo(), progress))
            .build();
        
        // 选择渲染策略
        RenderStrategy strategy = renderStrategyFactory.getStrategy(task.getFileFormat());
        
        // 执行渲染
        return strategy.render(context);
    }
    
    /**
     * 心跳上报
     */
    private void heartbeat() {
        // 更新所有当前Worker正在处理的任务的心跳时间
        Map<Object, Object> processing = redisTemplate.opsForHash()
            .entries("exporthub:queue:processing");
        
        for (Map.Entry<Object, Object> entry : processing.entrySet()) {
            String taskNo = (String) entry.getKey();
            ProcessingInfo info = JSON.parseObject(
                (String) entry.getValue(), ProcessingInfo.class);
            
            if (workerId.equals(info.getWorkerId())) {
                info.setHeartbeatAt(Instant.now());
                redisTemplate.opsForHash().put("exporthub:queue:processing", 
                    taskNo, JSON.toJSONString(info));
            }
        }
    }
    
    /**
     * 处理任务失败
     */
    private void handleTaskFailure(ExportTask task, Exception e) {
        log.error("Export task failed: {}", task.getTaskNo(), e);
        
        task.setRetryCount(task.getRetryCount() + 1);
        
        if (task.getRetryCount() < task.getMaxRetry()) {
            // 可重试：重新入队
            task.setStatus(ExportStatus.PENDING);
            task.setErrorMsg("第" + task.getRetryCount() + "次失败: " + e.getMessage());
            
            // 指数退避：延迟重新入队
            long delaySeconds = (long) Math.pow(2, task.getRetryCount()) * 5;
            scheduler.schedule(() -> requeueTask(task), delaySeconds, TimeUnit.SECONDS);
            
        } else {
            // 重试耗尽：标记为失败
            task.setStatus(ExportStatus.FAILED);
            task.setErrorCode(determineErrorCode(e));
            task.setErrorMsg(e.getMessage());
            task.setCompletedAt(LocalDateTime.now());
            
            // 通知回调失败
            callbackService.notifyCallbackFailed(task);
        }
        
        taskRepository.save(task);
    }
    
    /**
     * 更新进度
     */
    private void updateProgress(String taskNo, int progress) {
        String key = "exporthub:progress:" + taskNo;
        String value = JSON.toJSONString(Map.of(
            "status", "PROCESSING",
            "progress", progress,
            "updatedAt", Instant.now().toString()
        ));
        redisTemplate.opsForValue().set(key, value, 1, TimeUnit.HOURS);
    }
}
```

```java
@Component
public class ExportRecoveryService {
    
    private static final int HEARTBEAT_TIMEOUT_SECONDS = 60;
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private ExportTaskRepository taskRepository;
    
    /**
     * 每30秒执行一次
     */
    @Scheduled(fixedDelay = 30_000)
    public void detectStaleTasks() {
        Map<Object, Object> processing = redisTemplate.opsForHash()
            .entries("exporthub:queue:processing");
        
        Instant threshold = Instant.now().minusSeconds(HEARTBEAT_TIMEOUT_SECONDS);
        
        for (Map.Entry<Object, Object> entry : processing.entrySet()) {
            String taskNo = (String) entry.getKey();
            ProcessingInfo info = JSON.parseObject(
                (String) entry.getValue(), ProcessingInfo.class);
            
            if (info.getHeartbeatAt().isBefore(threshold)) {
                log.warn("检测到心跳超时任务: {}, worker: {}, 最后心跳: {}", 
                    taskNo, info.getWorkerId(), info.getHeartbeatAt());
                
                // 1. 从processing队列移除
                redisTemplate.opsForHash().delete("exporthub:queue:processing", taskNo);
                
                // 2. 任务重入待处理队列（减少retry_count由Worker处理）
                ExportTask task = taskRepository.findByTaskNo(taskNo);
                if (task != null && task.getStatus() == ExportStatus.PROCESSING) {
                    task.setStatus(ExportStatus.PENDING);
                    taskRepository.save(task);
                    
                    // 重新入队
                    double score = priorityCalculator.calculateScore(task);
                    redisTemplate.opsForZSet()
                        .add("exporthub:queue:pending", taskNo, score);
                    
                    log.info("任务已重新入队: {}", taskNo);
                }
            }
        }
    }
}
```

```java
/**
 * 导出完成回调通知
 * 支持HTTP Webhook回调和内部消息队列通知

@Service
public class ExportCallbackService {
    
    @Autowired
    private RestTemplate restTemplate;
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    private static final int MAX_CALLBACK_RETRY = 3;
    private static final long[] CALLBACK_DELAYS = {0, 30_000, 120_000}; // 立即、30秒、2分钟
    
    /**
     * 异步通知回调URL
     */
    @Async("exportCallbackExecutor")
    public void notifyCallback(ExportTask task) {
        if (StringUtils.isBlank(task.getCallbackUrl())) {
            return;
        }
        
        CallbackPayload payload = CallbackPayload.builder()
            .taskNo(task.getTaskNo())
            .bizType(task.getBizType())
            .status("SUCCESS")
            .fileUrl(task.getFileUrl())
            .fileName(task.getFileName())
            .fileSize(task.getFileSize())
            .completedAt(task.getCompletedAt())
            .expiresAt(task.getExpiresAt())
            .build();
        
        executeCallbackWithRetry(task, payload, 0);
    }
    
    private void executeCallbackWithRetry(ExportTask task, CallbackPayload payload, 
            int attempt) {
        try {
            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            headers.set("X-Export-Signature", generateSignature(payload));
            
            HttpEntity<CallbackPayload> entity = new HttpEntity<>(payload, headers);
            
            ResponseEntity<String> response = restTemplate.postForEntity(
                task.getCallbackUrl(), entity, String.class);
            
            if (response.getStatusCode().is2xxSuccessful()) {
                task.setCallbackStatus(1);
                taskRepository.save(task);
                log.info("回调成功: {}", task.getTaskNo());
            } else {
                throw new RuntimeException("回调返回非2xx: " + response.getStatusCode());
            }
            
        } catch (Exception e) {
            log.warn("回调失败(第{}次): {}, error: {}", 
                attempt + 1, task.getTaskNo(), e.getMessage());
            
            if (attempt < MAX_CALLBACK_RETRY - 1) {
                // 延迟重试
                scheduler.schedule(() -> 
                    executeCallbackWithRetry(task, payload, attempt + 1),
                    CALLBACK_DELAYS[attempt + 1], TimeUnit.MILLISECONDS);
            } else {
                task.setCallbackStatus(2);
                taskRepository.save(task);
                log.error("回调重试耗尽: {}", task.getTaskNo());
                
                // 发送内部告警
                alertService.sendAlert("导出回调失败", 
                    "任务 " + task.getTaskNo() + " 回调3次失败: " + e.getMessage());
            }
        }
    }
    
    /**
     * 生成签名（HMAC-SHA256）
     */
    private String generateSignature(CallbackPayload payload) {
        String data = payload.getTaskNo() + payload.getStatus() 
            + payload.getCompletedAt();
        return HmacUtils.hmacSha256Hex(callbackSecretKey, data);
    }
}
```

```java
        if (dailyCount != null && Integer.parseInt(dailyCount) >= dailyLimit) {
            throw new QuotaExceededException("EXPORT_006", 
                String.format("今日导出次数已达上限(%d次)，%s", 
                    dailyLimit, isPremium ? "" : "升级会员可享更多次数"));
        }

        int monthlyUsed = taskRepository.countByUserIdAndBizTypeAndCreatedAtBetween(
            userId, bizType, 
            LocalDateTime.now().withDayOfMonth(1).withHour(0).withMinute(0),
            LocalDateTime.now());

                String.format("本月导出次数已达上限(%d次)", monthlyLimit));

    }
```

```java
/**
 * 大文件导出内存优化

@Component
public class ExportMemoryManager {
    
    @Value("${exporthub.render.max-memory-mb:2048}")
    private int maxMemoryMb;
    
    /**
     * 检查内存是否充足
     */
    public boolean checkMemoryAvailable(int estimatedSizeMb) {
        Runtime runtime = Runtime.getRuntime();
        long usedMemory = runtime.totalMemory() - runtime.freeMemory();
        long maxMemory = runtime.maxMemory();
        long availableMb = (maxMemory - usedMemory) / (1024 * 1024);
        
        if (availableMb < estimatedSizeMb + 200) { // 留200MB安全余量
            log.warn("内存不足: available={}MB, needed={}MB", 
                availableMb, estimatedSizeMb);
            return false;
        }
        return true;
    }
    
    /**
     * 估算导出内存需求
     */
    public int estimateMemoryNeeded(ExportTask task) {
        int baseMb = 100; // 基础内存
        
        switch (task.getFileFormat()) {
            case "PDF":
                // PDF渲染需要额外内存（Puppeteer Chrome实例）
                return baseMb + 256;
            case "XLSX":
                // Excel按数据量估算
                int dataCount = task.getIntParam("dataCount", 1000);
                return baseMb + Math.min(500, dataCount / 100);
            default:
                return baseMb;
        }
    }
    
    /**
     * 强制GC（在任务完成后）
     */
    public void cleanupAfterTask() {
        System.gc();
        System.runFinalization();
    }
}
```

```java
/**
```

```java
@Service
public class FileDownloadService {
    
    private static final int DEFAULT_URL_EXPIRE_HOURS = 2;
    private static final int MAX_URL_EXPIRE_HOURS = 24;
    
    /**
     * 生成预签名下载URL
     */
    public String generateDownloadUrl(ExportTask task, Long userId, int expireHours) {
        // 权限校验
        permissionChecker.checkDownloadPermission(userId, userIdType, task);
        
        // 检查文件是否过期
        if (task.getExpiresAt() != null && 
            task.getExpiresAt().isBefore(LocalDateTime.now())) {
            throw new BusinessException("EXPORT_009", "文件已过期，请重新生成");
        }
        
        // 限制有效期
        int actualExpireHours = Math.min(expireHours, MAX_URL_EXPIRE_HOURS);
        if (task.getExpiresAt() != null) {
            long remainingHours = Duration.between(LocalDateTime.now(), 
                task.getExpiresAt()).toHours();
            actualExpireHours = (int) Math.min(actualExpireHours, remainingHours);
        }
        
        // 生成预签名URL
        String url = storageService.generatePresignedUrl(
            task.getStoragePath(), actualExpireHours, TimeUnit.HOURS);
        
        // 审计日志
        auditLogger.log(task.getTaskNo(), AuditAction.DOWNLOAD, userId,
            Map.of("expireHours", actualExpireHours));
        
        return url;
    }
}
```

```java
            .userId(userId)
            .bizType("DATA_EXPORT")
            .fileFormat("JSON")
            .reason(reason) // "ACCOUNT_DELETION" 或 "USER_REQUEST"
            .priority(1)    // 最高优先级
            .expiresInHours(720) // 30天（法规要求）
            .build();
        
        rabbitTemplate.convertAndSend("export.exchange", 
            "export.task.create", message);
    }
}
```

### 12.2 新增业务类型接入流程

1. 在 `export_templates` 表注册新模板
2. 在 ExportHub 注册新的 bizType 枚举
3. 实现数据获取接口（通过回调或直接API调用获取业务数据）
4. 配置该 bizType 的默认配额
5. 在权限矩阵中配置访问规则

```java
// 新增业务类型注册示例
@Component
public class ExportBizTypeRegistry {
    
    private static final Map<String, BizTypeConfig> REGISTRY = new HashMap<>();
    
    static {
        register(BizTypeConfig.builder()
            .bizType("LEARNING_REPORT")
            .defaultFormat("PDF")
            .defaultTemplateId("TPL_LEARNING_REPORT_V2")
            .dataFetcher("learningReportDataFetcher")
            .maxDataSizeMb(10)
            .build());
        
        register(BizTypeConfig.builder()
            .bizType("EXAM_PAPER")
            .defaultFormat("PDF")
            .defaultTemplateId("TPL_EXAM_PAPER_V1")
            .dataFetcher("examPaperDataFetcher")
            .maxDataSizeMb(5)
            .build());
    }
    
    public static void register(BizTypeConfig config) {
        REGISTRY.put(config.getBizType(), config);
    }
    
    public static BizTypeConfig get(String bizType) {
        return REGISTRY.get(bizType);
    }
}

/**
 * 数据获取器接口（各业务模块实现）
```
