# 首页与学习工作台 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

首页与学习工作台是 PrimeTop APP 的核心入口和调度中心，承载用户每日学习的启动、导航和状态总览功能。它将 AI 辅导、拍照搜题、同步课堂、错题本、学习规划、学情分析等各模块的关键入口和实时状态聚合到一个页面，让用户打开 APP 即可快速进入学习状态。

### 1.2 覆盖学段

全学段（幼儿至高中），通过分龄 UI 策略展示不同内容布局和交互模式。

### 1.3 优先级

P0 — MVP 阶段核心页面

### 1.4 依赖模块

| 依赖模块 | 依赖说明 |
|----------|----------|
| 用户账号体系 | 获取学生档案（学段、年级、教材版本、昵称、头像） |
| 学习规划 | 获取今日任务列表、任务完成状态 |
| 错题整理 | 获取待复习错题数、最近错题科目分布 |
| 学情分析 | 获取薄弱知识点、学习时长统计、连续学习天数 |
| 同步课堂学习 | 获取最近学习章节、章节进度 |
| AI 智能辅导 | 获取最近对话记录（继续学习入口） |
| 拍照搜题 | 快捷入口 |
| 会员订阅 | 会员状态展示、权益引导 |
| 消息与推送 | 未读消息数 |

## 2. 页面结构与布局设计

### 2.1 整体结构

首页采用 **垂直滚动 + 分区卡片** 布局，从上到下分为以下区域：

```
┌──────────────────────────────────┐
│ ① 顶部状态栏                      │  ← 用户信息 + 会员标识 + 消息入口
├──────────────────────────────────┤
│ ② 快捷操作区                      │  ← 拍题答疑 / 问AI / 同步课堂 / 错题复习
├──────────────────────────────────┤
│ ③ 今日学习任务                    │  ← 学习规划模块驱动的任务卡片
├──────────────────────────────────┤
│ ④ 继续学习                       │  ← 最近学习章节 / 最近AI对话
├──────────────────────────────────┤
│ ⑤ 薄弱知识点提醒                  │  ← 学情分析驱动的知识盲点卡片
├──────────────────────────────────┤
│ ⑥ 学习数据概览                    │  ← 今日学习时长 / 连续天数 / 本周统计
├──────────────────────────────────┤
│ ⑦ 底部导航栏                      │  ← 首页 / AI辅导 / 同步学习 / 错题计划 / 我的
└──────────────────────────────────┘
```

## 3. API 接口设计

### 3.1 首页数据聚合接口

首页数据涉及多个模块的聚合，为减少客户端请求次数，提供统一聚合接口。

#### `GET /api/v1/home/dashboard`

**描述：** 获取首页工作台全部数据

**请求头：**

```
Authorization: Bearer {access_token}
X-Device-Id: {device_id}
```

**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| include | string | 否 | 需要包含的区域，逗号分隔。默认全部。可选值：`brief,actions,tasks,continue,weak_points,summary` |
| grade_id | string | 否 | 指定年级（用于家长查看多孩子时切换） |

**响应：**

```json
{
  "code": 0,
  "data": {
    "user_brief": {
      "nickname": "小明",
      "avatar_url": "https://cdn.primetop.com/avatars/u123.jpg",
      "grade_label": "五年级",
      "textbook_label": "人教版",
      "membership_type": "monthly",
      "membership_expire_date": "2026-06-19",
      "unread_message_count": 3
    },
    "quick_actions": [ /* 见 2.2.2 */ ],
    "daily_tasks": { /* 见 2.2.3 */ },
    "continue_learning": { /* 见 2.2.4 */ },
    "weak_points": [ /* 见 2.2.5 */ ],
    "study_summary": { /* 见 2.2.6 */ },
    "meta": {
      "server_time": "2026-05-19T17:11:00+08:00",
      "cache_ttl_seconds": 300,
      "config_version": "v2.3"
    }
  }
}
```

**错误码：**

| code | 含义 | 客户端处理 |
|------|------|-----------|
| 0 | 成功 | 正常渲染 |
| 40101 | Token 过期 | 触发 Token 刷新 |
| 40102 | Token 无效 | 跳转登录页 |
| 40301 | 账号被冻结 | 展示封禁提示 |
| 40401 | 学生档案未完善 | 跳转档案设置页 |
| 50001 | 服务端错误 | 展示重试 UI |

### 3.2 首页数据缓存策略

**客户端缓存：**

| 数据区域 | 缓存时间 | 缓存 Key | 刷新触发 |
|----------|----------|----------|----------|
| user_brief | 30 min | `home:brief:{user_id}` | 进入前台 / 会员状态变更 |
| quick_actions | 24 h | `home:actions:{grade_id}` | 学段变更 / APP 更新 |
| daily_tasks | 5 min | `home:tasks:{user_id}:{date}` | 完成任务 / 进入前台 |
| continue_learning | 5 min | `home:continue:{user_id}` | 完成学习 / 进入前台 |
| weak_points | 30 min | `home:weak:{user_id}` | 完成练习 / 错题变更 |
| study_summary | 5 min | `home:summary:{user_id}` | 学习时长变更 |

**服务端缓存（Redis）：**

```
Key:   dashboard:{user_id}
Value: JSON 序列化的完整响应
TTL:   120 秒
```

**缓存失效策略：**

- 学习行为事件（完成任务、提交错题、AI 对话）通过消息队列触发缓存失效
- 客户端 `pull-to-refresh` 强制绕过客户端缓存，携带 `If-Modified-Since` 头
- 服务端通过事件驱动部分刷新，不重建整个缓存

## 4. 状态流转

### 4.1 首页加载状态机

```
                    ┌──────────┐
                    │  initial  │
                    └─────┬────┘
                          │ onEnter
                          ▼
                    ┌──────────┐
              ┌─────│  loading  │
              │     └─────┬────┘
              │           │
              │     ┌─────┴──────┐
              │     │            │
              │     ▼            ▼
              │ ┌────────┐ ┌─────────┐
              │ │ success │ │  error  │
              │ └────┬───┘ └────┬────┘
              │      │          │
              │      │          ├─ onRetry → loading
              │      │          ├─ onOffline → offline_stale
              │      │          └─ onFatal → error_fatal
              │      │
              │      ├─ onPullRefresh → loading (silent)
              │      ├─ onForeground → loading (if cache expired)
              │      └─ onConfigChange → loading
              │
              │ ┌──────────────┐
              └─│ offline_stale │ ← 有本地缓存数据，展示旧数据 + 离线提示
                └──────────────┘
```

**状态说明：**

| 状态 | UI 表现 | 数据来源 |
|------|---------|----------|
| initial | 空白/骨架屏 | 无 |
| loading | 骨架屏（首次）/ 下拉刷新动画 | 请求网络 |
| success | 正常渲染所有区域 | 网络响应 + 本地缓存 |
| error | 全页错误视图 + 重试按钮 | 无 |
| offline_stale | 展示缓存数据 + 顶部离线提示条 | 本地缓存 |
| error_fatal | 致命错误（账号封禁等） | 错误信息 |

### 4.2 今日任务状态流转

```
┌──────────┐  开始学习  ┌─────────────┐  完成  ┌───────────┐
│ pending  │──────────→│ in_progress │───────→│ completed │
└──────────┘           └──────┬──────┘        └───────────┘
     │                        │                     │
     │ skip                   │ pause               │ undo (24h内)
     ▼                        ▼                     ▼
┌──────────┐           ┌──────────┐          ┌──────────┐
│ skipped  │           │ pending  │          │ pending  │
└──────────┘           └──────────┘          └──────────┘
```

### 4.3 下拉刷新与增量更新

```
用户下拉刷新
    │
    ├─ 发送 GET /dashboard，携带 If-None-Match: {etag}
    │
    ├─ 304 Not Modified → 保持当前数据，关闭刷新动画
    │
    ├─ 200 OK → 合并新数据到现有状态
    │   ├─ 逐区域 diff，仅更新有变化的区域
    │   └─ 动画过渡：淡入新数据
    │
    └─ 网络错误 → 保持当前数据，Toast 提示"网络不给力"
```

```dart
  @override
  DashboardState build() {
    // 初始化时自动加载
    Future.microtask(() => loadDashboard());
    return const DashboardInitial();

  Future<void> loadDashboard({bool silent = false}) async {
    state = DashboardLoading(isSilent: silent);

    try {
      final result = await _repository.getDashboard(
        etag: (state is DashboardLoaded) ? (state as DashboardLoaded).etag : null,
      );

      if (result.isNotModified) {
        // 304 - 数据未变化
        return;
      }

      state = DashboardLoaded(
        userBrief: result.userBrief,
        quickActions: result.quickActions,
        dailyTasks: result.dailyTasks,
        continueLearning: result.continueLearning,
        weakPoints: result.weakPoints,
        studySummary: result.studySummary,
        loadedAt: DateTime.now(),
        etag: result.etag,
      );

      // 写入本地缓存
      await _localCache.saveDashboard(result);

    } on ApiException catch (e) {
      if (e.isAuthError) {
        // 鉴权错误交给全局处理
        rethrow;
      }

      // 尝试使用缓存
      final cached = await _localCache.getDashboard();
      if (cached != null) {
        state = DashboardOffline(DashboardLoaded(
          userBrief: cached.userBrief,
          quickActions: cached.quickActions,
          dailyTasks: cached.dailyTasks,
          continueLearning: cached.continueLearning,
          weakPoints: cached.weakPoints,
          studySummary: cached.studySummary,
          loadedAt: cached.loadedAt,
        ));
      } else {
        state = DashboardError(
          message: e.userMessage,
          errorCode: e.code,
        );
      }
    }
  }

  /// 局部刷新某个区域（如完成任务后刷新任务列表）
  Future<void> refreshSection(String sectionId) async {
    if (state is! DashboardLoaded) return;
    final current = state as DashboardLoaded;

    final updated = await _repository.refreshSection(sectionId);
    
    // 合并更新
    state = current.copyWith(
      dailyTasks: sectionId == 'tasks' ? updated.dailyTasks : current.dailyTasks,
      studySummary: sectionId == 'summary' ? updated.studySummary : current.studySummary,
      weakPoints: sectionId == 'weak_points' ? updated.weakPoints : current.weakPoints,
    );
  }
}
```

```python
# services/home_service.py

class HomeDashboardService:
    """首页聚合服务 - 并发调用各子服务，组装首页数据"""

    def __init__(self, container: ServiceContainer):
        self.user_svc = container.user_service
        self.plan_svc = container.study_plan_service
        self.course_svc = container.sync_course_service
        self.ai_svc = container.ai_tutor_service
        self.analytics_svc = container.learning_analytics_service
        self.mistake_svc = container.mistake_service
        self.msg_svc = container.message_service
        self.membership_svc = container.membership_service
        self.cache = container.cache

    async def get_dashboard(
        self,
        user_id: str,
        student_profile_id: str,
        include_sections: list[str] | None = None,
        etag: str | None = None,
    ) -> DashboardResponse:
        """获取首页数据，支持 ETag 缓存和按需加载"""

        # 检查 Redis 缓存
        cache_key = f"dashboard:{user_id}"
        cached = await self.cache.get(cache_key)
        if cached and etag and cached.get("etag") == etag:
            return DashboardResponse.not_modified()

        # 并发调用所有子服务
        tasks = {
            "user_brief": self._get_user_brief(user_id, student_profile_id),
            "daily_tasks": self._get_daily_tasks(student_profile_id),
            "continue_learning": self._get_continue_learning(student_profile_id),
            "weak_points": self._get_weak_points(student_profile_id),
            "study_summary": self._get_study_summary(student_profile_id),
            "unread_count": self.msg_svc.get_unread_count(user_id),
            "membership": self.membership_svc.get_status(user_id),
        }

        # 设置各子服务超时，单个失败不影响整体
        results = await self._gather_with_timeout(tasks, timeout=3.0)

        # 组装响应
        dashboard = self._assemble_dashboard(user_id, results)

        # 写入缓存
        new_etag = generate_etag(dashboard)
        dashboard.etag = new_etag
        await self.cache.set(cache_key, dashboard.to_dict(), ttl=120)

        return dashboard

    async def _gather_with_timeout(
        self,
        tasks: dict[str, Coroutine],
        timeout: float = 3.0,
    ) -> dict[str, Any]:
        """并发执行多个子服务调用，单次失败返回 None 而不中断"""
        async def safe_call(name: str, coro: Coroutine) -> tuple[str, Any]:
            try:
                result = await asyncio.wait_for(coro, timeout=timeout)
                return (name, result)
            except Exception as e:
                logger.warning(f"Dashboard sub-service failed: {name}", exc_info=e)
                return (name, None)

        gathered = await asyncio.gather(*[
            safe_call(name, coro) for name, coro in tasks.items()
        ])
        return dict(gathered)

    async def refresh_section(
        self,
        user_id: str,
        student_profile_id: str,
        section_id: str,
    ) -> dict[str, Any]:
        """局部刷新指定区域"""
        section_loaders = {
            "tasks": lambda: self._get_daily_tasks(student_profile_id),
            "continue": lambda: self._get_continue_learning(student_profile_id),
            "weak_points": lambda: self._get_weak_points(student_profile_id),
            "summary": lambda: self._get_study_summary(student_profile_id),
        }

        loader = section_loaders.get(section_id)
        if not loader:
            raise InvalidSectionError(f"Unknown section: {section_id}")

        return await loader()
```

## 7. 性能设计

### 7.1 响应时间目标

| 指标 | 目标 | 策略 |
|------|------|------|
| 首屏渲染 | ≤ 2s | 骨架屏 + 并发子请求 |
| 下拉刷新 | ≤ 1.5s | ETag 缓存 + 局部更新 |
| 骨架屏出现 | ≤ 200ms | 本地缓存先渲染 |
| 子服务超时 | 3s | 单服务超时不阻塞整体 |

### 7.2 并发优化策略

```
首页数据加载时序（目标 < 2s 总响应）:

0ms ──────────────────────────────────── 2000ms
│                                           │
├─ 检查本地缓存 (< 10ms)                     │
│   ├─ 命中 → 立即渲染骨架屏                 │
│   └─ 未命中 → 请求网络                     │
│                                           │
├─ 并发 7 个子服务调用 (0-1500ms)            │
│   ├─ getUserBrief          ── 50ms       │
│   ├─ getDailyTasks         ── 200ms      │
│   ├─ getRecentChapters     ── 300ms      │
│   ├─ getRecentConversations── 150ms      │
│   ├─ getWeakPoints         ── 500ms      │
│   ├─ getStudySummary       ── 400ms      │
│   └─ getUnreadCount        ── 50ms       │
│                                           │
├─ 组装 + 序列化 (50ms)                      │
│                                           │
└─ 客户端渲染 (100-300ms)                    │
```

### 7.3 客户端渲染优化

- **骨架屏分级：** 先展示静态骨架 → user_brief 到达后渲染顶部 → 其他区域逐个填充
- **图片预加载：** 头像和 Banner 图片使用 `cached_network_image`，APP 启动时预加载
- **懒加载：** 首屏可视区域外的区域延迟加载（如 study_summary 在滚动到时才请求）
- **动画优化：** 区域更新使用 `AnimatedSwitcher` 过渡，避免整页闪烁

```dart
// 全局错误处理
class DashboardErrorHandler {
  static DashboardState handleError(Object error, DashboardLoaded? lastData) {
    if (error is TokenExpiredException) {
      // Token 过期 → 自动刷新
      throw error; // 交给全局 AuthInterceptor 处理
    }

    if (error is SocketException || error is TimeoutException) {
      // 网络错误 → 使用缓存
      if (lastData != null) {
        return DashboardOffline(lastData);
      }
      return DashboardError(
        message: '网络不给力，请检查网络设置',
        staleData: lastData,
      );
    }

    if (error is ApiException) {
      switch (error.code) {
        case 40401:
          // 学生档案未完善 → 引导设置
          throw ProfileIncompleteException();
        case 40301:
          return DashboardError(message: '账号已被冻结');
        default:
          return DashboardError(
            message: '加载失败，请稍后重试',
            errorCode: error.code,
            staleData: lastData,
          );
      }
    }

    return DashboardError(
      message: '未知错误',
      staleData: lastData,
    );
  }
}
```

### 9.1 首页数据更新触发

首页数据在用户学习过程中会频繁变化，通过事件机制保持实时性：

```python
# events/home_events.py

class DashboardEventHandler:
    """监听学习行为事件，触发首页缓存失效"""

    @listen(TaskCompletedEvent)
    async def on_task_completed(self, event: TaskCompletedEvent):
        # 使任务列表和学习概览缓存失效
        await self.cache.delete(f"dashboard:{event.user_id}")
        await self.cache.delete(f"home:tasks:{event.user_id}:*")
        await self.cache.delete(f"home:summary:{event.user_id}")

    @listen(MistakeAddedEvent)
    async def on_mistake_added(self, event: MistakeAddedEvent):
        await self.cache.delete(f"home:weak:{event.user_id}")

    @listen(ChapterProgressEvent)
    async def on_chapter_progress(self, event: ChapterProgressEvent):
        await self.cache.delete(f"home:continue:{event.user_id}")

    @listen(AIConversationEvent)
    async def on_conversation_updated(self, event: AIConversationEvent):
        await self.cache.delete(f"home:continue:{event.user_id}")

    @listen(MembershipChangedEvent)
    async def on_membership_changed(self, event: MembershipChangedEvent):
        await self.cache.delete(f"home:brief:{event.user_id}")
        await self.cache.delete(f"dashboard:{event.user_id}")
```

### 9.2 客户端实时刷新

```dart
// 客户端通过 EventBus 监听关键事件，触发局部刷新

class HomeRefreshManager {
  final EventBus _eventBus;
  final Ref _ref;

  HomeRefreshManager(this._eventBus, this._ref) {
    _setupListeners();
  }

  void _setupListeners() {
    // 任务完成 → 刷新任务列表和学习概览
    _eventBus.on<TaskCompletedEvent>().listen((_) {
      _ref.read(dashboardNotifierProvider.notifier)
          .refreshSection('tasks');
      _ref.read(dashboardNotifierProvider.notifier)
          .refreshSection('summary');
    });

    // 错题变化 → 刷新薄弱知识点和错题数
    _eventBus.on<MistakeChangedEvent>().listen((_) {
      _ref.read(dashboardNotifierProvider.notifier)
          .refreshSection('weak_points');
    });

    // 学习进度变化 → 刷新继续学习
    _eventBus.on<StudyProgressEvent>().listen((_) {
      _ref.read(dashboardNotifierProvider.notifier)
          .refreshSection('continue');
    });
  }
}
```
