# 知识点重要性评估与核心考点智能识别引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 知识图谱分析层的核心组件，负责对知识图谱中的节点（知识点）进行多维度重要性评估，自动识别核心考点、枢纽知识点和高影响知识点，为学习路径规划、推荐系统、学情诊断、备考冲刺等下游服务提供**知识点权重数据支撑**。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 图结构重要性计算 | 基于 PageRank、介数中心性、特征向量中心性等图算法计算知识点在图结构中的枢纽程度 |
| 考试热度评估 | 结合历年真题出现频次、考试大纲权重、近期考试趋势计算考点热度 |
| 学习影响度量化 | 评估某知识点的掌握程度对后续学习和整体成绩的影响范围 |
| 综合重要性评分 | 融合多维度信号输出统一的知识点重要性得分（0-100） |
| 动态更新 | 随题库数据增长、考试趋势变化、用户学习数据积累定期重算 |
| 实时查询 | 为下游服务提供低延迟的重要性查询 API |

### 1.3 适用范围

- **学段**：小学、初中、高中
- **学科**：数学、物理、化学、生物、语文、英语、历史、地理、政治
- **消费方**：学习路径规划引擎、备考冲刺规划、题目推荐引擎、学情诊断报告、考点梳理页面、管理后台

## 2. 核心概念定义

### 2.1 知识点重要性维度模型

知识点的重要性由四个主维度和一个动态调节维度构成：

```
综合重要性 = w₁ × 图结构中心性 + w₂ × 考试热度 + w₃ × 学习影响度 + w₄ · 教学大纲权重 + Δ(趋势调节)
```

| 维度 | 代号 | 含义 | 数据来源 | 取值范围 |
| --- | --- | --- | --- | --- |
| 图结构中心性 | G | 知识点在知识图谱中的拓扑枢纽程度 | 图数据库 | [0, 1] |
| 考试热度 | E | 知识点在考试中的出现频率和分值占比 | 题库 + 历年真题 | [0, 1] |
| 学习影响度 | L | 前置/后续知识点数量与掌握度影响范围 | 图结构 + 学习数据 | [0, 1] |
| 教学大纲权重 | C | 课标/考纲对该知识点的要求层级 | 课标数据库 | [0, 1] |
| 趋势调节 | Δ | 近期考试趋势、政策变化的动态修正 | 运营配置 + 热点分析 | [-0.2, +0.2] |

权重默认值（可配置）：

```json
{
  "weights": {
    "graph_centrality": 0.25,
    "exam_hotness": 0.35,
    "learning_impact": 0.20,
    "curriculum_weight": 0.20
  },
  "trend_delta_range": 0.20,
  "score_range": [0, 100]
}
```

### 2.2 知识点分类标签

基于综合重要性得分，知识点被自动分类为四个层级：

| 层级 | 标签 | 得分区间 | 含义 |
| --- | --- | --- | --- |
| S | 核心考点 | [85, 100] | 必考、高影响、高枢纽——备考最高优先级 |
| A | 重要考点 | [70, 85) | 常考、中等影响——日常学习重点 |
| B | 一般考点 | [50, 70) | 偶考、影响有限——基础掌握即可 |
| C | 拓展知识 | [0, 50) | 低频、低影响——学有余力时拓展 |

## 4. 算法设计

### 4.1 图结构中心性计算（Graph Centrality, G）

采用三种经典图中心性算法，加权融合：

```
G(kp) = α × PageRank(kp) + β × Betweenness(kp) + γ × Eigenvector(kp)
```

默认权重：α=0.4, β=0.35, γ=0.25

### 4.1.1 PageRank

衡量知识点被其他知识点"指向"的频率。在知识图谱中，被大量后续知识依赖的节点 PageRank 值高，表示其为**基础枢纽知识点**。

```python
import networkx as nx

def compute_pagerank(graph: nx.DiGraph, alpha: float = 0.85) -> dict:
    """
    计算知识图谱中各知识点的 PageRank 值。
    图的边方向：前置知识 -> 后续知识（表示"学到A才能学B"）

    Args:
        graph: 有向图，节点为知识点ID，边权重为依赖强度
        alpha: 阻尼系数，默认0.85

    Returns:
        {kp_id: pagerank_value} 字典，值已归一化到 [0, 1]
    """
    # 使用边权重作为转移概率
    personalized = None
    pr_scores = nx.pagerank(
        graph,
        alpha=alpha,
        weight='strength',       # 使用依赖强度作为边权重
        max_iter=1000,
        tol=1e-06,
        personalization=personalized
    )

    # 归一化到 [0, 1]
    max_pr = max(pr_scores.values()) if pr_scores else 1.0
    return {kp: min(score / max_pr, 1.0) for kp, score in pr_scores.items()}
```

### 4.1.2 介数中心性（Betweenness Centrality）

衡量知识点出现在最短路径上的频率。高介数中心性的知识点是**知识图谱中的"桥梁"**，一旦缺失会影响大量后续学习。

```python
def compute_betweenness(graph: nx.DiGraph) -> dict:
    """
    计算介数中心性，识别知识桥梁节点。

    对于大型图谱（>10000节点），采用采样近似计算。
    """
    node_count = graph.number_of_nodes()

    if node_count <= 5000:
        # 精确计算
        bc = nx.betweenness_centrality(
            graph,
            weight='strength',
            normalized=True
        )
    else:
        # 采样近似计算，平衡精度与性能
        k = min(500, node_count)
        bc = nx.betweenness_centrality(
            graph,
            k=k,
            weight='strength',
            normalized=True
        )

    # 归一化到 [0, 1]
    max_bc = max(bc.values()) if bc else 1.0
    return {kp: min(score / max_bc, 1.0) if max_bc > 0 else 0.0
            for kp, score in bc.items()}
```

### 4.1.3 特征向量中心性（Eigenvector Centrality）

衡量知识点连接的其他知识点本身的重要性。与重要知识点关联的知识点得分更高。

```python
def compute_eigenvector(graph: nx.DiGraph) -> dict:
    """
    计算特征向量中心性。
    使用无向化图进行计算（将双向边合并）。
    """
    # 转为无向图
    undirected = graph.to_undirected()

    try:
        ec = nx.eigenvector_centrality(
            undirected,
            weight='strength',
            max_iter=1000,
            tol=1e-06
        )
    except nx.PowerIterationFailedConvergence:
        # 如果不收敛，降级使用度中心性
        ec = nx.degree_centrality(undirected)

    max_ec = max(ec.values()) if ec else 1.0
    return {kp: min(score / max_ec, 1.0) if max_ec > 0 else 0.0
            for kp, score in ec.items()}
```

### 4.1.4 图结构中心性融合

```python
def compute_graph_centrality(
    graph: nx.DiGraph,
    alpha: float = 0.4,
    beta: float = 0.35,
    gamma: float = 0.25
) -> dict[str, float]:
    """
    融合三种中心性算法，输出知识点的图结构重要性得分。

    Args:
        graph: 知识图谱有向图
        alpha: PageRank 权重
        beta: Betweenness 权重
        gamma: Eigenvector 权重

    Returns:
        {kp_id: graph_score} 字典，值域 [0, 1]
    """
    pr_scores = compute_pagerank(graph)
    bc_scores = compute_betweenness(graph)
    ec_scores = compute_eigenvector(graph)

    all_nodes = set(pr_scores) | set(bc_scores) | set(ec_scores)
    result = {}

    for node in all_nodes:
        pr = pr_scores.get(node, 0.0)
        bc = bc_scores.get(node, 0.0)
        ec = ec_scores.get(node, 0.0)
        result[node] = alpha * pr + beta * bc + gamma * ec

    return result
```

### 4.2 考试热度计算（Exam Hotness, E）

```
E(kp) = e₁ × 频次得分 + e₂ × 分值得分 + e₃ × 趋势得分 + e₄ × 考纲权重
```

默认权重：e₁=0.35, e₂=0.30, e₃=0.15, e₄=0.20

```python
import math
from datetime import datetime, timedelta

class ExamHotnessCalculator:
    """考试热度计算器"""

    def __init__(self, db_session, redis_client):
        self.db = db_session
        self.redis = redis_client

    def calculate(
        self,
        kp_id: str,
        subject: str,
        grade: int,
        lookback_years: int = 5,
        reference_date: datetime = None
    ) -> float:
        """
        计算单个知识点的考试热度得分。

        Args:
            kp_id: 知识点ID
            subject: 学科
            grade: 年级
            lookback_years: 回溯年数
            reference_date: 基准日期（默认当前）

        Returns:
            考试热度得分 [0, 1]
        """
        if reference_date is None:
            reference_date = datetime.now()

        start_year = reference_date.year - lookback_years

        # 1. 频次得分：该知识点在历年考试题目中的出现频次
        freq_score = self._calc_frequency_score(kp_id, subject, grade, start_year)

        # 2. 分值得分：该知识点在考试中的平均分值占比
        score_weight = self._calc_score_weight(kp_id, subject, grade, start_year)

        # 3. 趋势得分：近年出现频率的变化趋势（上升=高分）
        trend_score = self._calc_trend_score(kp_id, subject, grade, start_year)

        # 4. 考纲权重：课标/考纲中该知识点的层级权重
        curriculum_weight = self._get_curriculum_weight(kp_id)

        # 加权融合
        hotness = (
            0.35 * freq_score +
            0.30 * score_weight +
            0.15 * trend_score +
            0.20 * curriculum_weight
        )

        return min(max(hotness, 0.0), 1.0)

    def _calc_frequency_score(self, kp_id, subject, grade, start_year) -> float:
        """
        频次得分 = min(1.0, 出现次数 / 频次基准值)
        频次基准值按学科+学段配置，如数学初中为30次/5年
        """
        # 查询历年考试中出现该知识点的次数
        appear_count = self.db.query(
            """
            SELECT COUNT(DISTINCT q.question_id) as cnt
            FROM question_kp_mapping qkm
            JOIN questions q ON q.question_id = qkm.question_id
            JOIN exam_papers ep ON q.paper_id = ep.paper_id
            WHERE qkm.kp_id = ?
              AND ep.subject = ?
              AND ep.grade = ?
              AND ep.exam_year >= ?
              AND ep.exam_type IN ('midterm', 'final', 'mock', 'college_entrance')
            """,
            kp_id, subject, grade, start_year
        ).scalar() or 0

        # 获取频次基准值
        baseline = self._get_freq_baseline(subject, grade)

        # 使用对数缩放避免极端值主导
        if appear_count == 0:
            return 0.0

        return min(1.0, math.log(1 + appear_count) / math.log(1 + baseline))

    def _calc_score_weight(self, kp_id, subject, grade, start_year) -> float:
        """
        分值得分 = min(1.0, 平均分值占比 / 基准占比)
        """
        avg_ratio = self.db.query(
            """
            SELECT AVG(qkm.score_weight) as avg_ratio
            FROM question_kp_mapping qkm
            JOIN questions q ON q.question_id = qkm.question_id
            JOIN exam_papers ep ON q.paper_id = ep.paper_id
            WHERE qkm.kp_id = ?
              AND ep.subject = ?
              AND ep.grade = ?
              AND ep.exam_year >= ?
            """,
            kp_id, subject, grade, start_year
        ).scalar()

        if not avg_ratio:
            return 0.0

        # 分值占比超过15%即为满分
        return min(1.0, avg_ratio / 0.15)

    def _calc_trend_score(self, kp_id, subject, grade, start_year) -> float:
        """
        趋势得分：对比近2年与之前3年的出现频率
        上升趋势 → 高分；下降趋势 → 低分
        """
        recent = self.db.query(
            """
            SELECT COUNT(DISTINCT q.question_id)
            FROM question_kp_mapping qkm
            JOIN questions q ON q.question_id = qkm.question_id
            JOIN exam_papers ep ON q.paper_id = ep.paper_id
            WHERE qkm.kp_id = ? AND ep.subject = ? AND ep.grade = ?
              AND ep.exam_year >= YEAR(NOW()) - 2
            """,
            kp_id, subject, grade
        ).scalar() or 0

        historical = self.db.query(
            """
            SELECT COUNT(DISTINCT q.question_id)
            FROM question_kp_mapping qkm
            JOIN questions q ON q.question_id = qkm.question_id
            JOIN exam_papers ep ON q.paper_id = ep.paper_id
            WHERE qkm.kp_id = ? AND ep.subject = ? AND ep.grade = ?
              AND ep.exam_year >= ? AND ep.exam_year < YEAR(NOW()) - 2
            """,
            kp_id, subject, grade, start_year
        ).scalar() or 0

        if recent == 0 and historical == 0:
            return 0.0

        # 近2年频次相对历史的变化比率
        if historical == 0:
            # 全新热点
            return min(1.0, recent / 5.0)

        ratio = recent / max(historical, 1) * (3 / 2)  # 归一化（2年vs3年）
        return min(1.0, max(0.0, math.log(ratio + 1) / math.log(3)))

    def _get_curriculum_weight(self, kp_id) -> float:
        """
        从课标数据库获取该知识点的考纲权重。
        了解=0.3, 理解=0.6, 掌握=0.8, 灵活运用=1.0
        """
        level = self.redis.hget(f"kp:meta:{kp_id}", "curriculum_level")
        level_map = {
            '了解': 0.3,
            '认识': 0.4,
            '理解': 0.6,
            '掌握': 0.8,
            '灵活运用': 1.0,
            '应用': 0.9
        }
        return level_map.get(level, 0.5)

    def _get_freq_baseline(self, subject, grade) -> int:
        """获取频次基准值"""
        # 默认配置，可通过配置中心动态调整
        baselines = {
            ('数学', '初中'): 40,
            ('数学', '高中'): 50,
            ('物理', '初中'): 25,
            ('物理', '高中'): 35,
            ('化学', '初中'): 20,
            ('化学', '高中'): 30,
            ('语文', '初中'): 30,
            ('语文', '高中'): 35,
            ('英语', '初中'): 35,
            ('英语', '高中'): 45,
        }
        stage = '初中' if grade <= 9 else '高中' if grade >= 10 else '小学'
        return baselines.get((subject, stage), 25)
```

### 4.3 学习影响度计算（Learning Impact, L）

衡量一个知识点的掌握与否对整体学习链路的影响程度。

```
L(kp) = 0.4 × 后续影响深度 + 0.3 × 后续影响广度 + 0.3 × 掌握度波动关联度
```

```python
class LearningImpactCalculator:
    """学习影响度计算器"""

    def __init__(self, neo4j_driver, db_session):
        self.driver = neo4j_driver
        self.db = db_session

    def calculate(self, kp_id: str) -> float:
        """计算知识点的学习影响度"""

        # 1. 后续影响深度：沿前置依赖边可达的最大路径长度
        depth = self._calc_descendant_depth(kp_id)

        # 2. 后续影响广度：直接和间接依赖的知识点总数
        breadth = self._calc_descendant_breadth(kp_id)

        # 3. 掌握度波动关联度：该知识点掌握度变化时，
        #    下游知识点掌握度的平均变化幅度
        correlation = self._calc_mastery_correlation(kp_id)

        # 归一化
        depth_score = min(1.0, depth / 10.0)      # 最大10层依赖
        breadth_score = min(1.0, breadth / 50.0)   # 最大50个下游节点

        return 0.4 * depth_score + 0.3 * breadth_score + 0.3 * correlation

    def _calc_descendant_depth(self, kp_id: str) -> int:
        """计算从该知识点出发可达的最长路径长度"""
        with self.driver.session() as session:
            result = session.run(
                """
                MATCH path = (kp:KnowledgePoint {kp_id: $kp_id})
                      -[:PREREQUISITE*1..15]->(downstream:KnowledgePoint)
                RETURN MAX(length(path)) as max_depth
                """,
                kp_id=kp_id
            )
            record = result.single()
            return record['max_depth'] if record and record['max_depth'] else 0

    def _calc_descendant_breadth(self, kp_id: str) -> int:
        """计算该知识点影响的所有后续知识点总数"""
        with self.driver.session() as session:
            result = session.run(
                """
                MATCH (kp:KnowledgePoint {kp_id: $kp_id})
                      -[:PREREQUISITE*1..15]->(downstream:KnowledgePoint)
                RETURN COUNT(DISTINCT downstream) as count
                """,
                kp_id=kp_id
            )
            record = result.single()
            return record['count'] if record else 0

    def _calc_mastery_correlation(self, kp_id: str) -> float:
        """
        分析历史学习数据，计算该知识点掌握度变化
        与下游知识点掌握度变化的皮尔逊相关系数。
        """
        # 获取该知识点及直接后续知识点的历史掌握度数据
        rows = self.db.query(
            """
            WITH downstream_kps AS (
                SELECT downstream_id FROM kp_prerequisite_edges
                WHERE upstream_id = ?
            )
            SELECT
                DATE_FORMAT(ar.answered_at, '%Y-%m') as month,
                AVG(CASE WHEN ar.kp_id = ? THEN ar.mastery_delta ELSE NULL END) as self_mastery,
                AVG(CASE WHEN ar.kp_id IN (SELECT downstream_id FROM downstream_kps)
                         THEN ar.mastery_delta ELSE NULL END) as downstream_mastery
            FROM answer_records ar
            WHERE ar.kp_id = ?
               OR ar.kp_id IN (SELECT downstream_id FROM downstream_kps)
            GROUP BY DATE_FORMAT(ar.answered_at, '%Y-%m')
            ORDER BY month
            LIMIT 24
            """,
            kp_id, kp_id, kp_id
        ).all()

        if len(rows) < 6:
            # 数据不足，返回中性值
            return 0.5

        self_scores = [r.self_mastery or 0 for r in rows]
        downstream_scores = [r.downstream_mastery or 0 for r in rows]

        correlation = self._pearson_correlation(self_scores, downstream_scores)
        # 相关系数 [-1, 1] 映射到 [0, 1]
        return (correlation + 1) / 2

    @staticmethod
    def _pearson_correlation(x: list[float], y: list[float]) -> float:
        """计算皮尔逊相关系数"""
        n = len(x)
        if n != len(y) or n == 0:
            return 0.0

        sum_x = sum(x)
        sum_y = sum(y)
        sum_xy = sum(xi * yi for xi, yi in zip(x, y))
        sum_x2 = sum(xi ** 2 for xi in x)
        sum_y2 = sum(yi ** 2 for yi in y)

        numerator = n * sum_xy - sum_x * sum_y
        denominator = ((n * sum_x2 - sum_x ** 2) * (n * sum_y2 - sum_y ** 2)) ** 0.5

        if denominator == 0:
            return 0.0

        return numerator / denominator
```

### 4.4 综合评分融合

```python
class ImportanceScoreFusion:
    """知识点重要性综合评分融合器"""

    DEFAULT_WEIGHTS = {
        'graph_centrality': 0.25,
        'exam_hotness': 0.35,
        'learning_impact': 0.20,
        'curriculum_weight': 0.20
    }

    TIER_THRESHOLDS = {
        'S': 85,
        'A': 70,
        'B': 50
    }

    def __init__(self, config_client):
        self.config = config_client

    def compute_composite(
        self,
        kp_id: str,
        graph_score: float,
        exam_score: float,
        impact_score: float,
        curriculum_score: float,
        trend_delta: float = 0.0
    ) -> dict:
        """
        融合各维度得分，输出综合重要性评分。

        Returns:
            {
                'composite_score': float,    # [0, 100]
                'tier': str,                 # S/A/B/C
                'dimension_scores': {...},
                'trend_delta': float
            }
        """
        # 从配置中心获取权重（支持动态调整）
        weights = self.config.get(
            'kp_importance.weights',
            default=self.DEFAULT_WEIGHTS
        )

        # 加权求和
        raw_score = (
            weights['graph_centrality'] * graph_score +
            weights['exam_hotness'] * exam_score +
            weights['learning_impact'] * impact_score +
            weights['curriculum_weight'] * curriculum_score
        )

        # 应用趋势调节
        adjusted = raw_score + max(-0.2, min(0.2, trend_delta))
        adjusted = max(0.0, min(1.0, adjusted))

        # 映射到 [0, 100]
        composite_score = round(adjusted * 100, 2)

        # 确定层级
        tier = self._determine_tier(composite_score)

        return {
            'composite_score': composite_score,
            'tier': tier,
            'dimension_scores': {
                'graph_score': round(graph_score, 4),
                'exam_score': round(exam_score, 4),
                'impact_score': round(impact_score, 4),
                'curriculum_score': round(curriculum_score, 4),
            },
            'trend_delta': round(trend_delta, 4)
        }

    def _determine_tier(self, score: float) -> str:
        """根据综合得分确定层级"""
        thresholds = self.config.get(
            'kp_importance.tier_thresholds',
            default=self.TIER_THRESHOLDS
        )
        if score >= thresholds['S']:
            return 'S'
        elif score >= thresholds['A']:
            return 'A'
        elif score >= thresholds['B']:
            return 'B'
        else:
            return 'C'
```

```python
import asyncio
import logging
from datetime import datetime
from typing import Optional
from dataclasses import dataclass

logger = logging.getLogger(__name__)


@dataclass
class CalculationJob:
    """重要性评估计算任务"""
    job_id: str
    scope: str                          # full / incremental / subject
    subject: Optional[str] = None
    stage: Optional[str] = None
    grade: Optional[int] = None
    status: str = 'pending'
    total_kp: int = 0
    processed_kp: int = 0
    failed_kp: int = 0
    started_at: Optional[datetime] = None
    completed_at: Optional[datetime] = None
    error_message: Optional[str] = None


class ImportanceBatchCalculator:
    """知识点重要性批量计算引擎"""

    BATCH_SIZE = 200                    # 每批处理知识点数
    PARALLEL_WORKERS = 4                # 并发计算协程数

    def __init__(
        self,
        neo4j_driver,
        db_session,
        redis_client,
        mq_producer,
        config_client
    ):
        self.neo4j = neo4j_driver
        self.db = db_session
        self.redis = redis_client
        self.mq = mq_producer
        self.config = config_client

        self.graph_calc = GraphCentralityCalculator(neo4j_driver)
        self.exam_calc = ExamHotnessCalculator(db_session, redis_client)
        self.impact_calc = LearningImpactCalculator(neo4j_driver, db_session)
        self.fusion = ImportanceScoreFusion(config_client)

    async def run_full_calculation(self, triggered_by: str = "system") -> str:
        """
        全量计算所有学科所有学段的知识点重要性。
        通常每月或每季度执行一次。

        Returns:
            job_id: 任务ID
        """
        job = self._create_job(scope='full')

        try:
            job.status = 'running'
            job.started_at = datetime.now()
            self._update_job(job)

            # 1. 按学科+学段分组计算
            subject_stage_pairs = await self._get_all_subject_stage_pairs()
            job.total_kp = await self._count_all_kps()
            self._update_job(job)

            for subject, stage in subject_stage_pairs:
                await self._calculate_subject_stage(
                    job, subject, stage, grade=None
                )

            # 2. 完成处理
            job.status = 'completed'
            job.completed_at = datetime.now()
            self._update_job(job)

            # 3. 发布完成事件
            await self._publish_completion_event(job)

            logger.info(
                f"Full calculation completed: job={job.job_id}, "
                f"total={job.total_kp}, processed={job.processed_kp}, "
                f"failed={job.failed_kp}"
            )
            return job.job_id

        except Exception as e:
            job.status = 'failed'
            job.error_message = str(e)
            job.completed_at = datetime.now()
            self._update_job(job)
            logger.error(f"Full calculation failed: {e}", exc_info=True)
            raise

    async def run_incremental_calculation(
        self,
        subject: str,
        stage: str,
        kp_ids: list[str] = None
    ) -> str:
        """
        增量计算指定学科+学段的知识点重要性。
        通常每周执行一次，或在新教材/新题目入库后触发。

        Args:
            subject: 学科
            stage: 学段
            kp_ids: 指定知识点ID列表（None=该学科学段全部重算）
        """
        job = self._create_job(
            scope='incremental',
            subject=subject,
            stage=stage
        )

        try:
            job.status = 'running'
            job.started_at = datetime.now()
            self._update_job(job)

            if kp_ids is None:
                kp_ids = await self._get_kps_for_subject_stage(subject, stage)

            job.total_kp = len(kp_ids)
            self._update_job(job)

            await self._calculate_batch(job, subject, stage, kp_ids)

            job.status = 'completed'
            job.completed_at = datetime.now()
            self._update_job(job)
            await self._publish_completion_event(job)

            return job.job_id

        except Exception as e:
            job.status = 'failed'
            job.error_message = str(e)
            job.completed_at = datetime.now()
            self._update_job(job)
            raise

    async def _calculate_subject_stage(
        self,
        job: CalculationJob,
        subject: str,
        stage: str,
        grade: int = None
    ):
        """计算指定学科+学段的所有知识点"""
        kp_ids = await self._get_kps_for_subject_stage(subject, stage, grade)
        await self._calculate_batch(job, subject, stage, kp_ids)

    async def _calculate_batch(
        self,
        job: CalculationJob,
        subject: str,
        stage: str,
        kp_ids: list[str]
    ):
        """批量计算知识点重要性"""
        if not kp_ids:
            return

        # Step 1: 构建学科子图并计算图结构中心性（需整图计算）
        graph = await self._load_subject_graph(subject, stage)
        graph_scores = self.graph_calc.compute_all(graph)

        # Step 2: 分批计算热度和影响度
        semaphore = asyncio.Semaphore(self.PARALLEL_WORKERS)

        async def process_one(kp_id: str):
            async with semaphore:
                try:
                    return await self._calculate_single(
                        kp_id, subject, stage, graph_scores
                    )
                except Exception as e:
                    logger.warning(f"Failed to calculate kp={kp_id}: {e}")
                    return None

        # 分批处理，避免内存峰值
        for i in range(0, len(kp_ids), self.BATCH_SIZE):
            batch = kp_ids[i:i + self.BATCH_SIZE]
            results = await asyncio.gather(
                *[process_one(kp) for kp in batch],
                return_exceptions=True
            )

            # 持久化结果
            success_count = 0
            for kp_id, result in zip(batch, results):
                if isinstance(result, Exception) or result is None:
                    job.failed_kp += 1
                else:
                    await self._persist_result(kp_id, subject, stage, result)
                    success_count += 1
                job.processed_kp += 1

            # 更新进度
            self._update_job(job)
            logger.info(
                f"Job {job.job_id} progress: {job.processed_kp}/{job.total_kp} "
                f"(batch success: {success_count}/{len(batch)})"
            )

    async def _calculate_single(
        self,
        kp_id: str,
        subject: str,
        stage: str,
        graph_scores: dict[str, float]
    ) -> dict:
        """计算单个知识点的所有维度得分"""
        grade = await self._get_kp_grade(kp_id)

        # 各维度并行计算
        graph_score = graph_scores.get(kp_id, 0.0)
        exam_score = await asyncio.to_thread(
            self.exam_calc.calculate, kp_id, subject, grade
        )
        impact_score = await asyncio.to_thread(
            self.impact_calc.calculate, kp_id
        )

        # 课标权重
        curriculum_score = self.exam_calc._get_curriculum_weight(kp_id)

        # 趋势调节（从配置或运营后台获取）
        trend_delta = await self._get_trend_delta(kp_id, subject)

        # 融合
        return self.fusion.compute_composite(
            kp_id=kp_id,
            graph_score=graph_score,
            exam_score=exam_score,
            impact_score=impact_score,
            curriculum_score=curriculum_score,
            trend_delta=trend_delta
        )

    async def _persist_result(
        self,
        kp_id: str,
        subject: str,
        stage: str,
        result: dict
    ):
        """持久化计算结果到 MySQL 和 Redis"""
        # 1. 旧版本标记为非激活
        await asyncio.to_thread(
            self.db.execute,
            """
            UPDATE kp_importance_score SET is_active = 0
            WHERE kp_id = ? AND is_active = 1
            """,
            kp_id
        )

        # 2. 写入新版本
        grade = await self._get_kp_grade(kp_id)
        await asyncio.to_thread(
            self.db.execute,
            """
            INSERT INTO kp_importance_score
                (kp_id, subject, stage, grade,
                 graph_score, exam_score, impact_score, curriculum_score, trend_delta,
                 composite_score, importance_tier,
                 calculation_version, calculated_at, is_active)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, NOW(), 1)
            """,
            kp_id, subject, stage, grade,
            result['dimension_scores']['graph_score'],
            result['dimension_scores']['exam_score'],
            result['dimension_scores']['impact_score'],
            result['dimension_scores']['curriculum_score'],
            result['trend_delta'],
            result['composite_score'],
            result['tier'],
            f"v{datetime.now().strftime('%Y.%m.%d')}"
        )

        # 3. 写入历史趋势
        prev_score = await self._get_previous_score(kp_id)
        score_delta = result['composite_score'] - (prev_score or 0)
        await asyncio.to_thread(
            self.db.execute,
            """
            INSERT INTO kp_importance_history
                (kp_id, composite_score, importance_tier, calculated_at, score_delta)
            VALUES (?, ?, ?, NOW(), ?)
            """,
            kp_id, result['composite_score'], result['tier'], score_delta
        )

        # 4. 更新 Redis 缓存
        cache_data = {
            'kp_id': kp_id,
            'subject': subject,
            'stage': stage,
            'composite_score': result['composite_score'],
            'tier': result['tier'],
            'dimensions': result['dimension_scores'],
            'calculated_at': datetime.now().isoformat()
        }
        await asyncio.to_thread(
            self.redis.setex,
            f"kp:importance:{kp_id}",
            86400,  # 24h
            json.dumps(cache_data)
        )

        # 5. 更新排行缓存
        ranking_key = f"kp:ranking:{subject}:{stage}:{grade}"
        await asyncio.to_thread(
            self.redis.zadd,
            ranking_key,
            {kp_id: result['composite_score']}
        )

        # 更新层级集合
        tier_key = f"kp:tier:{subject}:{stage}:{grade}:{result['tier']}"
        await asyncio.to_thread(self.redis.sadd, tier_key, kp_id)
```

        """
        weak_kps = self.mastery_service.get_weak_kps(student_id, subject)

                'mastery': mastery,
                'composite_score': importance.composite_score,
                'risk_level': self._assess_risk(importance.tier, mastery),
                'downstream_impact': importance.downstream_count,
            })

        # 按风险等级排序
        report_items.sort(
            key=lambda x: (-x['risk_level'], -x['composite_score'])
        )

        return {
            'critical_weaknesses': [
                item for item in report_items
                if item['risk_level'] >= 3
            ],
            'moderate_weaknesses': [
                item for item in report_items
                if item['risk_level'] == 2
            ],
            'minor_weaknesses': [
                item for item in report_items
                if item['risk_level'] <= 1
            ],
        }

    @staticmethod
    def _assess_risk(tier: str, mastery: float) -> int:
        """风险评估：层级越高且掌握度越低 = 风险越大"""
        tier_weight = {'S': 3, 'A': 2, 'B': 1, 'C': 0}
        base = tier_weight.get(tier, 0)
        if mastery < 0.4:
            return min(base + 1, 4)
        elif mastery < 0.7:
            return base
        else:
            return max(base - 1, 0)

```python
class ImportanceServiceWithFallback:
    """带降级策略的重要性查询服务"""

    def __init__(self, primary_service, cache_client, config_client):
        self.primary = primary_service
        self.cache = cache_client
        self.config = config_client

    async def get_importance(self, kp_id: str) -> dict:
        """
        多级降级查询策略：
        1. Redis 缓存 -> 返回
        2. MySQL 最新版本 -> 返回 + 回填缓存
        3. 默认估算值 -> 返回 + 标记 is_estimated
        """
        # Level 1: Redis 缓存
        cached = await self.cache.get(f"kp:importance:{kp_id}")
        if cached:
            return {**json.loads(cached), 'source': 'cache'}

        # Level 2: MySQL 查询
        try:
            result = await self.primary.query_db(kp_id)
            if result:
                # 异步回填缓存
                await self.cache.setex(
                    f"kp:importance:{kp_id}",
                    86400,
                    json.dumps(result)
                )
                return {**result, 'source': 'database'}
        except Exception as e:
            logger.warning(f"Database query failed for kp={kp_id}: {e}")

        # Level 3: 估算值降级
        estimated = self._estimate_importance(kp_id)
        return {**estimated, 'source': 'estimated', 'is_estimated': True}

    def _estimate_importance(self, kp_id: str) -> dict:
        """
        在无评估数据时，基于课标层级快速估算重要性。
        """
        curriculum_level = self.cache.hget(
            f"kp:meta:{kp_id}", 'curriculum_level'
        ) or '理解'

        level_scores = {
            '灵活运用': 90, '应用': 82, '掌握': 75,
            '理解': 60, '认识': 45, '了解': 35
        }

        score = level_scores.get(curriculum_level, 50)
        tier = (
            'S' if score >= 85 else
            'A' if score >= 70 else
            'B' if score >= 50 else 'C'
        )

        return {
            'kp_id': kp_id,
            'composite_score': score,
            'tier': tier,
            'estimated': True
        }
```

import redis

class CalculationLock:
    def __init__(self, redis_client):
        self.redis = redis_client

    async def acquire(self, scope: str, subject: str = None) -> bool:
        """获取计算锁"""
        lock_key = f"kp:calc:lock:{scope}:{subject or 'all'}"
        # SET NX EX 7200 (2小时自动释放)
        acquired = await self.redis.set(
            lock_key,
            value=f"locked_at:{datetime.now().isoformat()}",
            nx=True,
            ex=7200
        )
        if not acquired:
            existing = await self.redis.get(lock_key)
            logger.warning(
                f"Cannot acquire lock {lock_key}, "
                f"existing: {existing}"
            )
        return bool(acquired)

    async def release(self, scope: str, subject: str = None):
        """释放计算锁"""
        lock_key = f"kp:calc:lock:{scope}:{subject or 'all'}"
        await self.redis.delete(lock_key)

### 16.2 集成测试场景

| 场景 | 步骤 | 预期 |
| --- | --- | --- |
| 全量计算 | 触发full scope计算 | 所有active知识点生成新版本评分 |

| 降级查询 | Redis+MySQL同时不可用 | 返回估算值，标记is_estimated |
| 并发计算锁 | 同时触发两个full计算 | 第二个返回409冲突 |
| 影响链查询 | 查询枢纽知识点影响链 | 返回多层级下游节点 |
| 空数据学段 | 查询无题库数据的学段 | 返回空列表或默认估算值 |
