# 服务端-作文批改评分引擎与写作能力评估服务 - 详细设计

> 本文档基于 `docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` 第 6.10 节（作文辅导模块）进行细化，聚焦服务端作文批改评分引擎的实现细节，为开发人员提供可直接编码的设计方案。

---

## 1. 概述

### 1.1 文档目的

定义 PrimeTop 作文批改评分引擎的服务端架构、数据模型、API 接口、批改流水线、评分维度体系、写作能力追踪及与其他模块的集成方式，确保开发人员能够据此实现完整的作文批改与写作能力评估服务。

### 1.2 范围

| 范围内 | 范围外 |
| --- | --- |
| 作文提交与预处理 | 客户端富文本编辑器（见《客户端-富文本编辑器与作文书写引擎》） |
| 多维度评分引擎 | 作文辅导页面交互（见《客户端-作文辅导页面架构与批改交互设计》） |
| AI 批改流水线编排 | 通用 AI 对话引擎（见《AI对话引擎与会话管理》） |
| 批改反馈生成与结构化 | Prompt 模板管理（见《AI-Prompt编排与场景模板系统》） |
| 写作能力画像追踪 | 拍照 OCR 流水线 |
| 好词好句提取与素材库 | 搜索服务与全文检索 |
| 范文推荐与匹配 | 客户端 UI 渲染与排版 |
| 写作历史趋势分析 | 支付与会员权益校验 |
| 错误模式识别与同类错文推荐 | 消息推送通道 |

### 1.3 术语定义

| 术语 | 含义 |
| --- | --- |
| Essay | 作文，用户提交的写作内容 |
| Evaluation | 批改评估，对作文的多维度评价结果 |
| Rubric | 评分量表，定义各维度的评分标准和等级描述 |
| Dimension | 评分维度，如内容、结构、语言、创意等 |
| WritingProfile | 写作能力画像，用户写作能力的长期追踪模型 |
| GoodPhrase | 好词好句，从作文中提取的优秀表达素材 |
| ReferenceEssay | 范文，用于对照学习的优秀作文 |
| CorrectionRound | 批改轮次，一次作文可经历多轮修改和批改 |

### 1.4 设计原则

1. **多维度精细评价**：不止给分数，更要给出具体的维度分析和改进方向
2. **分龄差异化**：小学低年级侧重基础表达和想象力，高年级侧重结构和深度，初高中侧重逻辑和文采
3. **启发式反馈**：指出问题的同时引导修改，避免直接重写
4. **能力追踪**：跨作文追踪写作能力趋势，形成长期写作画像
5. **素材积累**：自动提取好词好句，建设个人写作素材库
6. **渐进批改**：支持多轮修改-批改循环，追踪每次修改的进步

## 2. 系统架构

### 2.1 服务定位

作文批改评分引擎是学习服务域的子服务，在整体架构中的位置如下：

```
┌──────────────────────────────────────────────────────────┐
│                      API 网关层                           │
├──────────────────────────────────────────────────────────┤
│  BFF 聚合层  ──→  作文批改评分引擎 (EssayEvaluationService) │
│                      │                                    │
│                      ├─── 作文预处理模块                    │
│                      ├──   (EssayPreprocessor)             │
│                      │                                    │
│                      ├─── 批改流水线编排器                   │
│                      ├──   (EvaluationPipeline)            │
│                      │                                    │
│                      ├─── 多维度评分引擎                    │
│                      ├──   (ScoringEngine)                 │
│                      │                                    │
│                      ├──   反馈生成模块                     │
│                      ├──   (FeedbackGenerator)             │
│                      │                                    │
│                      ├──   好词好句提取器                   │
│                      ├──   (GoodPhraseExtractor)           │
│                      │                                    │
│                      ├──   范文匹配引擎                     │
│                      ├──   (ReferenceMatcher)              │
│                      │                                    │
│                      └─── 写作能力追踪模块                  │
│                          (WritingProfileTracker)           │
├──────────────────────────────────────────────────────────┤
│  AI 能力层  (LLM / Embedding)                             │
├──────────────────────────────────────────────────────────┤
│  数据层  (MySQL / Redis / ES / OSS)                       │
└──────────────────────────────────────────────────────────┘
```

### 2.2 内部模块职责

| 模块 | 职责 | 关键类 |
| --- | --- | --- |
| EssayPreprocessor | 作文提交预处理：字数统计、段落分割、格式清洗、文体识别 | `EssayPreprocessor` |
| EvaluationPipeline | 批改流水线编排：顺序/并行调用各评分模块，汇总结果 | `EvaluationPipelineOrchestrator` |
| ScoringEngine | 多维度评分：按评分量表计算各维度得分和总分 | `DimensionalScoringEngine` |
| FeedbackGenerator | 反馈生成：将评分结果转化为结构化反馈文本 | `StructuredFeedbackGenerator` |
| GoodPhraseExtractor | 好词好句提取：识别优秀表达并分类归档 | `GoodPhraseExtractor` |
| ReferenceMatcher | 范文匹配：基于主题和难度推荐范文 | `ReferenceEssayMatcher` |
| WritingProfileTracker | 写作能力追踪：更新用户写作画像和趋势 | `WritingProfileTracker` |

### 2.3 依赖关系

```
EssayEvaluationService
  ├──→ AI 服务 (LLM 调用：批改、评分、反馈生成)
  ├──→ 用户服务 (获取学生年级、学段信息)
  ├──→ 知识点服务 (学科知识点关联)
  ├──→ 学习记录服务 (写入学习行为)
  ├──→ 对象存储服务 (作文文件和图片存储)
  ├──→ 缓存服务 (批改结果缓存、评分量表缓存)
  └──→ 搜索服务 (范文检索)
```

#### 3.1.1 作文提交表 `essay_submission`

```sql
CREATE TABLE essay_submission (
    id                    BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '作文ID',

    essay_type            VARCHAR(30) NOT NULL COMMENT '文体(narrative/descriptive/argumentative/expository/practical/creative)',
    grade_stage           TINYINT NOT NULL COMMENT '学段(1=幼儿,2=小学,3=初中,4=高中)',
```

## 4. API 接口设计

### 4.1 作文提交接口

```
POST /api/v1/essay/submissions
```

**请求体：**
```json
{
  "title": "春天的脚步",
  "contentText": "春天来了，万物复苏...",
  "contentRich": "<p>春天来了，<strong>万物复苏</strong>...</p>",
  "subject": "chinese",
  "essayType": "narrative",
  "promptId": 10042,
  "images": ["https://oss.example.com/essay/img_xxx.jpg"]
}
```

**响应体：**
```json
{
  "code": 0,
  "data": {
    "submissionId": 20250531001,
    "status": "submitted",
    "wordCount": 658,
    "paragraphCount": 5,
    "correctionRound": 1,
    "estimatedWaitSeconds": 15
  }
}
```

**业务规则：**
- 从用户 Profile 自动填充 `gradeStage` 和 `gradeLevel`
- 若指定 `promptId`，自动拉取题目要求和文体建议
- 字数不足/超出时给出警告但不拒绝提交
- 校验用户当日批改次数是否超限（免费用户 3 次/日，会员 20 次/日）

### 4.2 触发批改接口

```
POST /api/v1/essay/submissions/{submissionId}/evaluate
```

**请求体：**
```json
{
  "evaluationMode": "full",
  "dimensions": ["content", "structure", "language", "creativity"],
  "needGoodPhrases": true,
  "needReferenceMatch": true,
  "needParagraphFeedback": true
}
```

**响应体：**
```json
{
  "code": 0,
  "data": {
    "evaluationId": 30501,
    "status": "processing",
    "estimatedWaitSeconds": 20
  }
}
```

**说明：**
- `evaluationMode`: `full`(完整批改) / `quick`(快速点评，仅总评+主要问题) / `partial`(仅指定维度)
- 批改为异步处理，通过 SSE 或轮询获取结果
- 同一作文同时只允许一个批改任务

## 5. 批改流水线设计

### 5.1 流水线总览

```
作文提交
  │
  ▼
[Step 1] 预处理 ─── 文本清洗 / 段落分割 / 文体识别 / 字数统计
  │
  ▼
[Step 2] 评分量表加载 ─── 按学科+学段+文体选择对应 Rubric
  │
  ▼
[Step 3] 并行维度评分 (各维度独立调用 AI 评分)
  │         ├── 内容与立意评分
  │         ├── 结构与逻辑评分
  │         ├── 语言与表达评分
  │         └── 创意与想象评分
  │
  ▼
[Step 4] 汇总计算 ─── 加权总分 / 等级判定
  │
  ▼
[Step 5] 并行附加任务
  │         ├── 段落级反馈生成
  │         ├── 错误标注与纠错建议
  │         ├── 好词好句提取
  │         └── 范文相似度匹配
  │
  ▼
[Step 6] 总评生成 ─── 综合各维度生成总评语
  │
  ▼
[Step 7] 写作画像更新 ─── 增量更新用户写作能力画像（异步）
  │
  ▼
[Step 8] 结果持久化 ─── 写入数据库 + 缓存
  │
  ▼
[Step 9] 通知推送 ─── SSE 推送 / 消息通知
```

### 5.2 流水线关键实现

```java
@Service
public class EvaluationPipelineOrchestrator {

    @Autowired private EssayPreprocessor preprocessor;
    @Autowired private RubricService rubricService;
    @Autowired private DimensionalScoringEngine scoringEngine;
    @Autowired private StructuredFeedbackGenerator feedbackGenerator;
    @Autowired private GoodPhraseExtractor phraseExtractor;
    @Autowired private ReferenceEssayMatcher referenceMatcher;
    @Autowired private EssayEvaluationRepository evaluationRepo;
    @Autowired private ApplicationEventPublisher eventPublisher;

    /**
     * 执行完整批改流水线
     */
    public EssayEvaluationResult execute(EssaySubmission submission, EvaluationRequest request) {
        long startTime = System.currentTimeMillis();

        // Step 1: 预处理
        PreprocessedEssay preprocessed = preprocessor.process(submission);

        // Step 2: 加载评分量表
        ScoringRubric rubric = rubricService.getRubric(
            submission.getSubject(), submission.getGradeStage(), submission.getEssayType());

        // Step 3: 并行维度评分
        List<DimensionScore> dimensionScores = scoringEngine
            .scoreAllDimensions(preprocessed, rubric, request.getDimensions())
            .block();

        // Step 4: 汇总计算
        OverallScoreResult overall = scoringEngine.calculateOverallScore(dimensionScores, rubric);

        // Step 5: 并行附加任务
        var combined = Mono.zip(
            feedbackGenerator.generateParagraphFeedback(preprocessed, request),
            feedbackGenerator.detectErrors(preprocessed),
            phraseExtractor.extract(preprocessed),
            referenceMatcher.match(preprocessed, 3)
        ).block();

        // Step 6: 总评生成
        String summary = feedbackGenerator.generateSummary(
            preprocessed, dimensionScores, overall, combined.getT1());

        // Step 7: 写作画像更新 (异步)
        eventPublisher.publishEvent(new EvaluationCompletedEvent(
            submission.getUserId(), submission.getSubject(),
            dimensionScores, overall));

        // Step 8: 持久化
        EssayEvaluation evaluation = buildEvaluation(
            submission, request, dimensionScores, overall, summary, combined);
        evaluation.setEvalDurationMs((int)(System.currentTimeMillis() - startTime));
        evaluationRepo.save(evaluation);

        return EssayEvaluationResult.from(evaluation);
    }
}
```

### 6.4 评分引擎核心代码

```java
@Service
public class DimensionalScoringEngine {

    private final AiService aiService;
    private final PromptTemplateService promptTemplateService;

    /**
     * 并行评估所有维度
     */
    public Flux<DimensionScore> scoreAllDimensions(
            PreprocessedEssay essay, ScoringRubric rubric,
            List<String> targetDimensions) {

        Map<String, DimensionConfig> dims = rubric.getDimensionConfigs();
        List<Map.Entry<String, DimensionConfig>> targets = dims.entrySet().stream()
            .filter(e -> targetDimensions == null || targetDimensions.contains(e.getKey()))
            .toList();

        return Flux.fromIterable(targets)
            .flatMap(entry -> scoreDimension(essay, entry.getKey(), entry.getValue()));
    }

    /**
     * 计算加权总分
     */
    public OverallScoreResult calculateOverallScore(
            List<DimensionScore> scores, ScoringRubric rubric) {

        Map<String, Double> weights = rubric.getDimensionWeights();
        double weightedSum = scores.stream()
            .mapToDouble(ds -> ds.getScore() * weights.getOrDefault(ds.getDimensionKey(), 0.0))
            .sum();
        double totalWeight = scores.stream()
            .mapToDouble(ds -> weights.getOrDefault(ds.getDimensionKey(), 0.0))
            .sum();

        double overall = totalWeight > 0 ? weightedSum / totalWeight : 0;
        return new OverallScoreResult(
            BigDecimal.valueOf(overall).setScale(2, RoundingMode.HALF_UP),
            determineGrade(overall));
    }

    private String determineGrade(double score) {
        if (score >= 90) return "A";
        if (score >= 85) return "A-";
        if (score >= 80) return "B+";
        if (score >= 75) return "B";
        if (score >= 70) return "B-";
        if (score >= 65) return "C+";
        if (score >= 60) return "C";
        return "D";
    }
}
```

## 9. 写作能力画像追踪

```java
@Service
public class WritingProfileTracker {

    private final WritingProfileRepository profileRepo;

    @Async
    @EventListener
    public void onEvaluationCompleted(EvaluationCompletedEvent event) {
        updateProfile(event.getUserId(), event.getSubject(),
            event.getDimensionScores(), event.getOverallScore());
    }

    @Transactional
    public void updateProfile(Long userId, String subject,
            List<DimensionScore> dimensionScores, OverallScoreResult overall) {

        WritingProfile profile = profileRepo
            .findByUserIdAndSubject(userId, subject)
            .orElseGet(() -> createNewProfile(userId, subject));

        profile.setTotalEssays(profile.getTotalEssays() + 1);
        updateRunningAverage(profile, overall.getScore());

        // 增量更新各维度平均分
        Map<String, Double> dimAvg = profile.getDimensionAverages();
        for (DimensionScore ds : dimensionScores) {
            double old = dimAvg.getOrDefault(ds.getDimensionKey(), 0.0);
            int n = profile.getTotalEssays();
            dimAvg.put(ds.getDimensionKey(), Math.round((old * (n-1) + ds.getScore()) / n * 100.0) / 100.0);
        }
        profile.setDimensionAverages(dimAvg);

        // 识别强弱项
        var sorted = dimAvg.entrySet().stream().sorted(Map.Entry.comparingByValue()).toList();
        profile.setStrengths(sorted.subList(sorted.size()-2, sorted.size()).stream().map(Map.Entry::getKey).toList());
        profile.setWeaknesses(sorted.subList(0, Math.min(2, sorted.size())).stream().map(Map.Entry::getKey).toList());

        // 判定写作等级
        profile.setWritingLevel(determineWritingLevel(profile.getAvgScore()));
        profile.setImprovementTrend(calculateTrend(userId, subject));

        profileRepo.save(profile);
    }

    private String determineWritingLevel(double avg) {
        if (avg >= 90) return "excellent";
        if (avg >= 80) return "proficient";
        if (avg >= 70) return "competent";
        if (avg >= 60) return "developing";
        return "beginner";
    }
}
```

## 10. 错误处理与降级策略

### 10.1 异常分类

| 异常类型 | 异常码 | 处理策略 |
| --- | --- | --- |

| 用户批改次数超限 | `ESSAY_RATE_LIMITED` | 返回 429，提示升级会员 |
| 范文匹配不可用 | `ESSAY_REF_UNAVAILABLE` | 跳过范文推荐，批改继续 |
| 好词好句提取失败 | `ESSAY_PHRASE_FAIL` | 跳过提取，批改继续 |

### 10.2 降级策略

```java
@Service
public class EssayEvaluationDegradationHandler {

    public DegradationPlan decide(List<EvaluationError> errors) {
        boolean criticalFailure = errors.stream()
            .anyMatch(e -> e.getType() == ErrorType.DIMENSION_SCORING
                        && e.getDimension().equals("content"));

        if (criticalFailure) {
            return DegradationPlan.builder()
                .mode(DegradationMode.QUICK_REVIEW)
                .fallbackAction("使用轻量级 Prompt 生成简短总评")
                .build();
        }

        List<String> skipped = errors.stream()
            .filter(e -> e.getType() == ErrorType.GOOD_PHRASE
                      || e.getType() == ErrorType.REFERENCE_MATCH)
            .map(EvaluationError::getTaskName).toList();

        return DegradationPlan.builder()
            .mode(DegradationMode.PARTIAL)
            .skippedTasks(skipped).build();
    }
}
```

### 10.3 重试策略

- AI 调用失败：指数退避重试，最多 2 次
- 维度评分失败：仅重试失败维度
- 总评生成失败：重试 1 次，使用降级 Prompt
- 所有重试均失败：标记 `failed`，通知用户稍后重试
