# 教育游戏化学习关卡编排与知识点闯关挑战引擎 — 详细设计

> **文档版本**：v1.0  
> **创建日期**：2026-06-23  
> **所属模块**：学习服务 / 游戏化引擎  
> **优先级**：P1（V1.5 阶段）  
> **依赖模块**：知识点体系、题目服务、学情分析、积分与成就系统、用户学习画像

---

## 1. 概述

### 1.1 设计目标

将结构化教育内容（教材章节、知识点、考点）自动编排为**关卡式闯关学习路径**，为不同学段学生提供游戏化的单人参闯体验。系统负责关卡生成、难度调节、解锁逻辑、星级评定、进度追踪与奖励发放，使学习过程具备目标感、节奏感和成就感。

### 1.2 设计背景

原设计文档明确要求：
- **幼儿段**："图像化、语音化、卡片化、亲子共学"，"完成练习后给予徽章、星星、成长记录等反馈"
- **小学段**："操作简单、奖励反馈明显"，"基础巩固、兴趣保持"
- **整体设计原则**："引导理解"、"数据可见"、"轻量高效"

当前平台已有积分体系、成就系统和打卡系统，但这些系统各自独立，缺少一个将**学习内容本身**游戏化的中间层——即把"学完本章→做对练习→解锁下一关"这一核心循环产品化的引擎。

### 1.3 与现有系统的边界

| 现有系统 | 职责 | 本引擎的关系 |
|---------|------|------------|
| 积分与虚拟经济体系 | 积分获取/消费/余额管理 | 本引擎调用积分服务发放闯关奖励 |
| 学生成就与学习里程碑追踪引擎 | 成就解锁/徽章颁发 | 本引擎触发成就事件（如"通关某专题"） |
| 学习打卡与成就激励 | 每日打卡/连续登录 | 互不干涉，打卡是行为层，闯关是内容层 |
| 运营活动与成长激励体系 | 时间限定的运营活动 | 运营活动可引用关卡作为活动任务，但独立运作 |
| 学习挑战赛与排行榜竞技系统 | 多人实时/异步竞技 | 完全不同：本引擎是单人 PVE 闯关 |
| 学习规划与每日任务 | 学习计划生成/执行 | 每日任务可将"闯关"作为一种任务类型 |
| 题目智能推荐与个性化练习编排 | 自适应题目推荐 | 本引擎从题目服务获取推荐题组装关卡 |
| 知识点掌握度/知识追踪模型 | 学生能力评估 | 本引擎读取掌握度决定关卡难度和解锁条件 |

### 1.4 核心术语

| 术语 | 定义 |
|------|------|
| **关卡地图（Map）** | 一个完整的闯关学习路径，通常对应一个教材章节或专题 |
| **关卡（Stage）** | 地图中的一个节点，包含一组学习/练习任务 |
| **节点（Node）** | 关卡内的最小学习单元，如一道题、一个知识点讲解、一段视频 |
| **星级（Star Rating）** | 关卡完成质量评定，1-3 星 |
| **解锁条件（Unlock Condition）** | 进入某关卡必须满足的前置条件 |
| **闯关会话（Run Session）** | 学生从进入关卡到完成/退出的完整交互过程 |
| **完美通关（Perfect Clear）** | 获得满星（3 星）的通关记录 |

### 2.2 服务定位

本引擎是**业务编排层**服务，不直接拥有题目内容或用户能力数据，而是通过调用下游服务组装闯关体验。

### 2.3 技术选型

| 层面 | 选型 | 说明 |
|------|------|------|
| 服务框架 | Spring Boot 3.x | 与主技术栈一致 |
| 数据库 | MySQL 8.x | 关卡模板、会话、进度记录 |
| 缓存 | Redis 7.x | 会话状态、排行榜、限时挑战 |
| 消息队列 | RocketMQ | 通关事件广播 |
| 配置中心 | Nacos | 关卡参数动态调整 |

### 3.4 `unlock_config` 结构定义

```json
{
    "conditions": [
        {
            "type": "STAGE_CLEAR",
            "stageId": 10042,
            "minStars": 1
        },
        {
            "type": "KP_MASTERY",
            "kpId": "KP_5001",
            "minMastery": 0.5
        },
        {
            "type": "MAP_PROGRESS",
            "minProgressPct": 60
        }
    ],
    "logic": "AND",
    "altCondition": {
        "type": "VIP_UNLOCK",
        "tier": "MONTHLY"
    }

```

| 条件类型 | 说明 |
|---------|------|
| `STAGE_CLEAR` | 通过指定关卡 |
| `KP_MASTERY` | 指定知识点掌握度达标 |
| `MAP_PROGRESS` | 地图整体进度达标 |
| `VIP_UNLOCK` | 特定会员等级直接解锁 |
| `DATE_UNLOCK` | 指定日期后解锁（运营控制） |

## 5. 核心流程设计

### 5.1 关卡地图自动生成流程

当教研团队新建一章的教学内容后，系统可以基于章节的知识点结构自动生成关卡地图。

```
教研后台 → 触发"生成关卡地图" → 选择章节 + 选择模板 → 引擎自动生成

```

**详细步骤：**

1. **选择章节**：教研人员选择某教材章节（如"人教版七年级数学第三章"）
2. **选择模板**：从 `game_stage_template` 中选择适合的模板（如7关标准型）
3. **知识点获取**：调用知识点服务获取本章所有知识点及其前置依赖关系
4. **关卡蓝图匹配**：按模板 `stageBlueprint` 分配知识点到各关卡
   - LEARNING 关：分配该章的核心知识点，按教学顺序排列
   - PRACTICE 关：从分配到的知识点范围中自动拉取推荐题目
   - CHECKPOINT 关：覆盖此前所有 LEARNING 关的知识点
   - BOSS 关：综合本章所有知识点，选取中高难度题
5. **题目预填充**：调用题目推荐服务，按 `difficultyRange` 和 `questionTypes` 预填题目池
6. **奖励配置**：按 `rewardTier` 自动设置各关奖励（章节级/单元级/学期级）
7. **生成草稿**：写入 `game_stage_map`（status=0）和 `game_stage` 记录
8. **人工审核**：教研人员可在后台预览关卡，手动调整题目和参数后发布

### 5.2 闯关主流程状态机

```
                     ┌──────────────────────────────────┐
                     │           IDLE (未开始)            │
                     └──────────┬───────────────────────┘
                                │ start()
                     ┌──────────▼───────────────────────┐
                     │        IN_PROGRESS (进行中)        │
                     │  ┌─────────────────────────────┐ │
                     │  │  逐题循环：                   │ │
                     │  │  answer() → CORRECT/WRONG    │ │
                     │  │  hint()   → 给提示(可选)      │ │
                     │  └─────────────────────────────┘ │
                     └─────┬──────┬──────┬──────┬───────┘
                           │      │      │      │
          all done  ───────┘      │      │      └────── user quit
          boss defeated ──────────┘      │             
          boss hp = 0 ───────────────────┘             
                     │      │      │      │
              ┌──────▼──┐ ┌─▼──┐ ┌▼────┐ ┌▼────────┐
              │ CLEARED │ │FAIL│ │TIME-│ │ABANDONED│
              │ (结算)  │ │    │ │OUT  │ │         │
              └─────────┘ └────┘ └─────┘ └─────────┘
```

**状态流转说明：**

| 当前状态 | 事件 | 目标状态 | 动作 |
|---------|------|---------|------|
| IDLE | start() | IN_PROGRESS | 创建会话、生成题目池、写入 Redis |
| IN_PROGRESS | answer(CORRECT) | IN_PROGRESS | 记录正确、更新连击、BOSS战扣BOSS血 |
| IN_PROGRESS | answer(WRONG) | IN_PROGRESS | 记录错误、重置连击、BOSS战扣玩家血 |
| IN_PROGRESS | hint() | IN_PROGRESS | 返回提示、增加 hint 计数、BOSS战扣玩家血 |
| IN_PROGRESS | 所有题目完成 | CLEARED | 结算星数、发放奖励、更新进度 |
| IN_PROGRESS | BOSS HP = 0 | CLEARED | 同上 |
| IN_PROGRESS | 玩家 HP = 0 | FAILED | 记录失败、不结算星数、可重试 |
| IN_PROGRESS | 超时 | TIMEOUT | 强制结算，按已答题目计算星数 |
| IN_PROGRESS | 用户退出 | ABANDONED | 保存会话快照，允许续跑 |
| CLEARED/FAILED | start() (retry) | IN_PROGRESS | 创建新会话 |

### 5.3 BOSS 战流程

BOSS 战是本引擎的亮点设计，将传统答题包装为回合制对抗：

```
开始 → 分配阶段(phase) → 逐题对抗 → 判定胜负

每题流程：
  1. 展示题目（附带 BOSS 立绘 + 对话）
  2. 玩家作答（可使用提示，但扣血）
  3. 判定：
     ├─ 正确：BOSS 受伤 (correctDamage + comboBonus)
     │   └─ 连击 ≥ comboThreshold → 触发 comboBonusDamage
     └─ 错误：玩家受伤 (wrongDamageToPlayer)
  4. 检查 BOSS HP ≤ 0 → CLEARED
  5. 检查玩家 HP ≤ 0 → FAILED
  6. 检查阶段切换（如第4题进入 Phase 2）→ 播放对话
  7. 继续下一题
```

### 5.4 星级评定流程

```java
/**
 * 星级评定器
 */
public class StarRatingCalculator {
    
    public StarResult calculate(RunSession session, StarCriteria criteria) {
        double correctRate = (double) session.getCorrectCount() / session.getTotalAnswered();
        int timeUsed = session.getTimeUsedSec();
        int hintsUsed = session.getHintsUsed();
        boolean noWrong = session.getWrongCount() == 0;
        
        int stars = 0;
        Map<String, String> missed = new LinkedHashMap<>();
        
        // 3星判定
        if (meetCriteria(criteria.getThreeStar(), correctRate, timeUsed, hintsUsed, noWrong)) {
            stars = 3;
        } else if (meetCriteria(criteria.getTwoStar(), correctRate, timeUsed, hintsUsed, true)) {
            stars = 2;
            if (correctRate < criteria.getThreeStar().getMinCorrectRate()) {
                missed.put("threeStar", String.format("正确率%.0f%%未达标(需%.0f%%)",
                    correctRate * 100, criteria.getThreeStar().getMinCorrectRate() * 100));
            }
        } else if (meetCriteria(criteria.getOneStar(), correctRate, timeUsed, hintsUsed, true)) {
            stars = 1;
        }
        
        return StarResult.builder()
            .stars(stars)
            .missedCriteria(missed)
            .build();
    }
    
    private boolean meetCriteria(StarThreshold t, double cr, int time, int hints, boolean noWrong) {
        if (t == null) return false;
        if (cr < t.getMinCorrectRate()) return false;
        if (t.getMaxTimeSec() != null && time > t.getMaxTimeSec()) return false;
        if (t.getMaxHintsUsed() != null && hints > t.getMaxHintsUsed()) return false;
        if (t.isNoWrongAnswer() && !noWrong) return false;
        return true;
    }
}
```

### 5.6 解锁判定流程

```java
public class UnlockChecker {
    
    /**
     * 检查关卡是否解锁
     */
    public UnlockResult check(Long userId, Stage stage) {
        if (stage.getUnlockConfig() == null) {
            return UnlockResult.unlocked();
        }
        
        UnlockConfig config = stage.getUnlockConfig();
        List<ConditionResult> results = new ArrayList<>();
        
        for (UnlockCondition cond : config.getConditions()) {
            boolean met = switch (cond.getType()) {
                case STAGE_CLEAR -> progressService
                    .getProgress(userId, cond.getStageId())
                    .getStars() >= cond.getMinStars();
                case KP_MASTERY -> masteryService
                    .getMastery(userId, cond.getKpId()) >= cond.getMinMastery();
                case MAP_PROGRESS -> summaryService
                    .getProgressPct(userId, stage.getMapId()) >= cond.getMinProgressPct();
                case VIP_UNLOCK -> membershipService
                    .getTier(userId).ordinal() >= cond.getVipTier().ordinal();
                case DATE_UNLOCK -> LocalDateTime.now()
                    .isAfter(cond.getUnlockDate());
            };
            results.add(new ConditionResult(cond, met));
        }
        
        boolean unlocked = config.getLogic() == Logic.AND
            ? results.stream().allMatch(ConditionResult::isMet)
            : results.stream().anyMatch(ConditionResult::isMet);
        
        // VIP 备用解锁
        if (!unlocked && config.getAltCondition() != null) {
            unlocked = checkAltCondition(userId, config.getAltCondition());
        }
        
        return unlocked
            ? UnlockResult.unlocked()
            : UnlockResult.locked(results);
    }
}
```

```java
@Service
@RequiredArgsConstructor
public class StageEngineService {
    
    private final StageRepository stageRepo;
    private final RunSessionRepository sessionRepo;
    private final UserStageProgressRepository progressRepo;
    private final UserMapSummaryRepository summaryRepo;
    private final RedissonClient redisson;
    private final QuizRecommendService quizRecommendSvc;
    private final PointsService pointsSvc;
    private final AchievementEventPublisher achievementPublisher;
    private final MasteryService masterySvc;
    
    private static final String SESSION_KEY = "game:session:%s";
    private static final String SESSION_LOCK = "game:session:lock:%s";
    
    /**
     * 开始闯关
     */
    @Transactional
    public StartRunResponse startStage(Long userId, Long stageId, String continueCode) {
        Stage stage = stageRepo.findById(stageId)
            .orElseThrow(() -> new BizException("GAME_STAGE_NOT_FOUND"));
        
        // 续跑已有会话
        if (continueCode != null) {
            return resumeSession(userId, continueCode);
        }
        
        // 检查解锁
        UnlockResult unlock = unlockChecker.check(userId, stage);
        if (!unlock.isUnlocked()) {
            throw new BizException("GAME_STAGE_LOCKED", unlock.getLockedReason());
        }
        
        // 检查每日次数限制
        int todayAttempts = sessionRepo.countTodayByUserAndStage(userId, stageId);
        if (todayAttempts >= stage.getDailyAttemptLimit()) {
            throw new BizException("GAME_DAILY_ATTEMPT_LIMIT");
        }
        
        // 生成题目池
        List<Long> questionIds = assembleQuestions(stage);
        
        // 创建会话
        RunSession session = RunSession.builder()
            .sessionCode(generateSessionCode())
            .userId(userId)
            .mapId(stage.getMapId())
            .stageId(stageId)
            .status(SessionStatus.IN_PROGRESS)
            .currentNodeIdx(0)
            .totalNodes(questionIds.size())
            .questionIds(questionIds)
            .correctCount(0)
            .wrongCount(0)
            .hintsUsed(0)
            .comboMax(0)
            .timeUsedSec(0)
            .expireAt(LocalDateTime.now().plusSeconds(stage.getTimeLimitSec()))
            .build();
        
        // BOSS 战初始化 HP
        if (stage.getStageType() == StageType.BOSS) {
            BossConfig boss = stage.getNodeConfig().getBossConfig();
            session.setPlayerHp(boss.getHpSystem().getPlayerHp());
            session.setBossHp(boss.getHpSystem().getBossHp());
        }
        
        sessionRepo.save(session);
        
        // 缓存会话到 Redis
        cacheSession(session);
        
        return buildStartResponse(session, stage);
    }
    
    /**
     * 提交答案
     */
    @Transactional
    public AnswerResponse submitAnswer(Long userId, String sessionCode, AnswerRequest req) {
        RLock lock = redisson.getLock(String.format(SESSION_LOCK, sessionCode));
        
        try {
            if (!lock.tryLock(5, 10, TimeUnit.SECONDS)) {
                throw new BizException("GAME_SESSION_BUSY");
            }
            
            RunSession session = getSessionFromCache(sessionCode);
            validateSession(session, userId, req.getNodeIndex());
            
            // 获取题目并判定
            Long questionId = session.getQuestionIds().get(req.getNodeIndex());
            Question question = quizService.getById(questionId);
            boolean correct = quizService.judge(question, req.getAnswer());
            
            // 更新会话状态
            session.set currentNodeIdx(req.getNodeIndex() + 1);
            session.setTimeUsedSec(session.getTimeUsedSec() + req.getTimeUsedSec());
            
            if (correct) {
                session.setCorrectCount(session.getCorrectCount() + 1);
                session.setCurrentCombo(session.getCurrentCombo() + 1);
                session.setComboMax(Math.max(session.getComboMax(), session.getCurrentCombo()));
            } else {
                session.setWrongCount(session.getWrongCount() + 1);
                session.setCurrentCombo(0);
            }
            
            // BOSS 战 HP 计算
            BossDelta bossDelta = null;
            if (session.getBossHp() != null) {
                bossDelta = calculateBossDelta(stage, session, correct);
                session.setBossHp(Math.max(0, session.getBossHp() + bossDelta.bossDelta()));
                session.setPlayerHp(Math.max(0, session.getPlayerHp() + bossDelta.playerDelta()));
            }
            
            // 检查是否结束
            CompletionCheck check = checkCompletion(session, stage);
            if (check.isComplete()) {
                session.setStatus(check.getStatus());
                session.setFinishedAt(LocalDateTime.now());
            }
            
            sessionRepo.save(session);
            cacheSession(session);
            
            // 异步更新知识点掌握度
            masterySvc.recordAnswerAsync(userId, questionId, correct);
            
            return buildAnswerResponse(session, stage, question, correct, bossDelta, check);
            
        } finally {
            lock.unlock();
        }
    }
    
    /**
     * 结算
     */
    @Transactional
    public FinishResponse finishRun(Long userId, String sessionCode, FinishRequest req) {
        RunSession session = sessionRepo.findByCode(sessionCode)
            .orElseThrow(() -> new BizException("GAME_SESSION_NOT_FOUND"));
        
        if (session.getStatus() != SessionStatus.IN_PROGRESS) {
            throw new BizException("GAME_SESSION_FINISHED");
        }
        
        Stage stage = stageRepo.findById(session.getStageId()).orElseThrow();
        
        // 超时/退出：标记状态
        if (req.getReason() == FinishReason.TIME_OUT) {
            session.setStatus(SessionStatus.TIMEOUT);
        } else if (req.getReason() == FinishReason.USER_QUIT) {
            session.setStatus(SessionStatus.ABANDONED);
            sessionRepo.save(session);
            return buildAbandonResponse(session);
        }
        
        session.setFinishedAt(LocalDateTime.now());
        session.setStatus(determineResult(session, stage));
        sessionRepo.save(session);
        
        // 星级评定
        StarResult starResult = starCalculator.calculate(session, stage.getStarCriteria());
        session.setStarsEarned(starResult.getStars());
        
        // 奖励结算
        Rewards rewards = calculateRewards(userId, session, stage, starResult);
        
        // 更新进度
        updateProgress(userId, session, stage, starResult);
        
        // 发布事件
        eventPublisher.publish(new GameStageClearedEvent(userId, session, stage, starResult, rewards));
        
        return buildFinishResponse(session, stage, starResult, rewards);
    }
    
    /**
     * 组装题目池
     */
    private List<Long> assembleQuestions(Stage stage) {
        StageNodeConfig config = stage.getNodeConfig();
        
        if (config.getSourceType() == SourceType.MANUAL) {
            // 手动指定题目
            return config.getManualQuestionIds();
        }
        
        // 自动推荐
        QuizRecommendRequest recommendReq = QuizRecommendRequest.builder()
            .kpIds(config.getKpIds())
            .count(config.getTotalQuestions())
            .difficultyRange(config.getDifficultyRange())
            .questionTypes(config.getQuestionTypes())
            .shuffle(config.isShuffleOrder())
            .excludeAskedQuestionIds(null) // 新会话无需排除
            .build();
        
        List<Long> questionIds = quizRecommendSvc.recommend(recommendReq);
        
        if (questionIds.size() < config.getTotalQuestions()) {
            log.warn("题目池不足: 需要{}题, 实际获得{}题, stageId={}",
                config.getTotalQuestions(), questionIds.size(), stage.getId());
            // 降级：放宽难度范围或题型限制
            questionIds = quizRecommendSvc.recommendWithRelaxedCriteria(recommendReq);
        }
        
        return questionIds;
    }
}
```

```java
private BossDelta calculateBossDelta(Stage stage, RunSession session, boolean correct) {
    BossConfig.HpSystem hp = stage.getNodeConfig().getBossConfig().getHpSystem();
    
    int bossDelta = 0;
    int playerDelta = 0;
    
    if (correct) {
        bossDelta -= hp.getCorrectDamage(); // 负值 = 扣血
        
        // 连击加成
        if (session.getCurrentCombo() >= hp.getComboThreshold()) {
            bossDelta -= hp.getComboBonusDamage();
        }
    } else {
        playerDelta -= hp.getWrongDamageToPlayer();
    }
    
    return new BossDelta(bossDelta, playerDelta);
}
```

```java
@Transactional
public void updateProgress(Long userId, RunSession session, Stage stage, StarResult starResult) {
    // 更新关卡进度（保留历史最佳）
    UserStageProgress progress = progressRepo
        .findByUserIdAndStageId(userId, stage.getId())
        .orElseGet(() -> UserStageProgress.init(userId, stage.getMapId(), stage.getId()));
    
    progress.setAttemptCount(progress.getAttemptCount() + 1);
    progress.setLastPlayAt(LocalDateTime.now());
    
    if (session.getStatus() == SessionStatus.CLEARED) {
        boolean firstClear = progress.getFirstClearAt() == null;
        if (firstClear) {
            progress.setFirstClearAt(LocalDateTime.now());
        }
        // 取最佳星数
        if (starResult.getStars() > progress.getStars()) {
            progress.setStars(starResult.getStars());
        }
        // 取最佳正确率
        double currentRate = (double) session.getCorrectCount() / session.getTotalAnswered();
        if (progress.getBestCorrectRate() == null || currentRate > progress.getBestCorrectRate()) {
            progress.setBestCorrectRate(currentRate);
        }
        // 取最短用时
        if (progress.getBestTimeSec() == null || session.getTimeUsedSec() < progress.getBestTimeSec()) {
            progress.setBestTimeSec(session.getTimeUsedSec());
        }
        if (starResult.getStars() == 3) {
            progress.setStatus(StageStatus.PERFECT_CLEAR);
        } else {
            progress.setStatus(StageStatus.CLEARED);
        }
    }
    
    progressRepo.save(progress);
    
    // 更新地图汇总
    updateMapSummary(userId, stage.getMapId());
}

private void updateMapSummary(Long userId, Long mapId) {
    List<UserStageProgress> all = progressRepo.findByUserIdAndMapId(userId, mapId);
    int cleared = (int) all.stream().filter(p -> p.getStatus() >= StageStatus.CLEARED.getCode()).count();
    int perfect = (int) all.stream().filter(p -> p.getStatus() == StageStatus.PERFECT_CLEAR).count();
    int totalStars = all.stream().mapToInt(UserStageProgress::getStars).sum();
    int maxStars = stageRepo.countByMapId(mapId) * 3;
    
    UserMapSummary summary = summaryRepo.findByUserIdAndMapId(userId, mapId)
        .orElseGet(() -> UserMapSummary.init(userId, mapId, maxStars / 3));
    
    summary.setClearedStages(cleared);
    summary.setPerfectStages(perfect);
    summary.setTotalStars(totalStars);
    summary.setProgressPct(BigDecimal.valueOf(cleared * 100.0 / summary.getTotalStages())
        .setScale(2, RoundingMode.HALF_UP));
    summary.setCompleted(cleared == summary.getTotalStages());
    if (summary.isCompleted() && summary.getCompletedAt() == null) {
        summary.setCompletedAt(LocalDateTime.now());
        // 触发地图完成奖励
        eventPublisher.publish(new GameMapCompletedEvent(userId, mapId));
    }
    summaryRepo.save(summary);
}
```

## 10. 错误处理与容灾

### 10.1 异常分类

| 异常 | 处理策略 |
|------|---------|
| 题目池不足 | 降级：放宽难度范围/题型限制；仍不足则标记该关卡为"维护中"并通知教研 |
| 推荐服务超时 | 降级：使用预生成的默认题目池（存储在 stage 本身的 fallbackQuestionIds 中） |
| 积分服务不可用 | 降级：先写本地消息表，异步补偿发放奖励；前端正常展示结算结果 |
| Redis 不可用 | 降级：会话状态直接走 DB 查询，性能下降但功能不中断 |
| 会话锁竞争失败 | 返回 `GAME_SESSION_BUSY`，客户端引导重试 |

### 10.2 数据一致性保障

- **会话状态双写**：Redis（实时读写） + MySQL（持久化），以 MySQL 为准
- **进度更新幂等**：基于 (userId, stageId) 唯一键，重试不会产生重复记录
- **奖励发放幂等**：积分服务通过 `idempotencyKey = sessionCode + rewardType` 保证不重复发放
- **超时会话清理**：定时任务每 5 分钟扫描过期会话，自动标记为 TIMEOUT 并结算

### 10.3 降级方案

```
正常模式：完整游戏化体验（BOSS战、连击、动画）
  ↓ 题目服务 P95 > 3s
预热模式：题目提前批量拉取，减少实时调用
  ↓ 题目服务不可用
降级模式：使用 fallbackQuestionIds，只支持基础答题
  ↓ 题目服务和 fallback 都不可用
熔断模式：返回 "关卡维护中"，引导用户去其他功能
```

```json
}
```
