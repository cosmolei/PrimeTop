## 1. 模块概述

### 1.1 功能定位

本模块是 PrimeTop 英语学科词汇能力评估的核心服务，负责**动态评估学生英语词汇量、追踪词汇能力增长趋势、预测学生对具体单词的掌握概率**，为词汇推荐、阅读难度匹配和个性化学习路径提供底层数据支撑。

**一句话定位：** 从"猜你知道多少词"到"精确知道你认识哪些词"，为每个学生建立动态的词汇能力数字孪生。

### 1.2 与现有模块的区别

| 模块 | 职责 | 与本模块的关系 |
|------|------|---------------|
| 英语词汇记忆与单词本系统 | 单词卡片学习、单词本管理、词汇练习、复习调度 | **消费方**：从本模块获取词汇能力等级和推荐生词 |
| 知识追踪模型引擎 | 学科知识点掌握度建模（BKT/DKT） | **类比参考**：本模块是知识追踪在词汇领域的特化实现 |
| 用户学习画像 | 汇聚各维度能力数据形成综合画像 | **数据上游**：本模块输出词汇能力维度数据 |
| 英语阅读理解专项训练 | 阅读文章推荐与答题分析 | **消费方**：根据词汇能力匹配文章难度 |

## 2. 核心概念与算法

### 2.1 核心概念

#### 2.1.1 词汇量（Vocabulary Size）

词汇量指学生能识别或理解的最少单词数量。本系统区分两种口径：

| 口径 | 定义 | 用途 |
|------|------|------|
| **识别词汇量**（Recognition Vocabulary） | 看到英文单词能选对中文释义的词数 | 阅读理解基础 |
| **产出词汇量**（Production Vocabulary） | 能正确拼写并在语境中使用的词数 | 写作与表达 |

默认测评识别词汇量，产出词汇量通过练习正确率间接推算。

#### 2.1.2 词频与难度

每个词在词库中有两个关键属性：

- **词频排名 `frequency_rank`**：基于 COCA（美国当代英语语料库）和 BNC（英国国家语料库）的综合排名。排名越小，词越常用。
- **难度等级 `difficulty`**：1-10 整数，综合词频、词长、多义性、拼写复杂度、形近词干扰等因素。

词频与词汇量估计的关系：如果学生认识排名前 N 的词，其词汇量估计约为 N（经曲率校正后）。

#### 2.1.3 单词掌握概率（Word Knowledge Probability）

对词库中的每个词，系统维护学生对其的掌握概率 `P(known)`，取值 `[0, 1]`：

| 概率范围 | 状态 | 说明 |
|---------|------|------|
| ≥ 0.95 | KNOWN | 已掌握，无需再测 |
| 0.6 - 0.95 | LIKELY_KNOWN | 很可能掌握，需偶尔验证 |
| 0.4 - 0.6 | UNCERTAIN | 不确定，优先选题 |
| 0.05 - 0.4 | LIKELY_UNKNOWN | 很可能未掌握 |
| < 0.05 | UNKNOWN | 未掌握 |

### 2.2 自适应测评算法

#### 2.2.1 算法选型：IRT + CAT

本系统采用 **项目反应理论（Item Response Theory, IRT）** 结合 **计算机化自适应测验（Computerized Adaptive Testing, CAT）** 框架。

**为什么选 IRT 而非经典测量理论（CTT）：**
- IRT 将被试能力和题目难度放在同一量尺上，适合自适应选题
- IRT 支持被试间题目不同仍可比，天然适配自适应场景
- IRT 的信息函数能指导选题，在最少题目下达到最大测量精度

#### 2.2.2 IRT 模型：2PL

采用两参数逻辑斯蒂模型（Two-Parameter Logistic Model, 2PL）：

$$P(\text{correct} \mid \theta, b_i, a_i) = \frac{1}{1 + e^{-a_i(\theta - b_i)}}$$

其中：
- `θ`：被试词汇能力（潜在特质），取值范围 `[-3, 3]`（标准分），对应词汇量 `[0, V_max]`
- `b_i`：题目 i 的难度参数，等同于词的难度转换值
- `a_i`：题目 i 的区分度参数，反映题目对能力差异的敏感程度

**题目信息函数：**

$$I_i(\theta) = a_i^2 \cdot P_i \cdot (1 - P_i)$$

在当前能力估计值 `θ̂` 处信息量最大的题目就是最优下一题。

#### 2.2.3 能力估计：贝叶斯后验更新

初始先验 + 逐题更新：

**先验分布** `N(μ₀, σ₀²)`：
- `μ₀`：根据年级和上次测评结果设定初始能力值
- `σ₀²`：初始方差，新用户设较大值（如 `1.0`），老用户设较小值（如 `0.3`）

**每题作答后的后验更新**（使用 BEC 近似——Bayesian Expected a Posteriori）：

```python
def update_ability(prior_mu, prior_sigma, item_b, item_a, response):
    """
    BEC 方法更新能力估计
    prior_mu:     先验能力均值
    prior_sigma:  先验能力标准差
    item_b:       题目难度
    item_a:       题目区分度
    response:     1=答对, 0=答错
    返回: (后验均值, 后验标准差)
    """
    # 计算先验方差
    prior_var = prior_sigma ** 2

    # 计算题目在当前能力处的概率和信息量
    exponent = item_a * (prior_mu - item_b)
    P = 1.0 / (1.0 + math.exp(-exponent))
    info = item_a ** 2 * P * (1 - P)

    # BEC 更新（一阶近似）
    posterior_mu = prior_mu + (prior_var * item_a * (response - P)) / (1 + prior_var * info)
    posterior_var = prior_var / (1 + prior_var * info)
    posterior_sigma = math.sqrt(posterior_var)

    return posterior_mu, posterior_sigma
```

#### 2.2.4 选题策略：KLI（Kullback-Leibler Information）

从题库中选择下一题的算法：

```python
def select_next_item(theta_hat, theta_sigma, available_items, used_item_ids):
    """
    基于 Kullback-Leibler 信息量选题
    theta_hat:        当前能力估计
    theta_sigma:      当前能力标准差
    available_items:  可选题池 [{item_id, b, a, word_id, ...}]
    used_item_ids:    已用题目集合
    返回: 最优题目
    """
    best_item = None
    best_score = -1

    for item in available_items:
        if item['item_id'] in used_item_ids:
            continue

        # 在 θ̂ 处的 KL 信息量
        P_hat = irf(item['a'], item['b'], theta_hat)
        kl = P_hat * math.log(P_hat / P_theta_range) + \
             (1 - P_hat) * math.log((1 - P_hat) / (1 - P_theta_range))

        # 加入不确定性加权：优先选在置信区间内信息量大的题
        # 简化为在 θ̂ ± σ 范围积分的近似
        theta_low = theta_hat - 1.5 * theta_sigma
        theta_high = theta_hat + 1.5 * theta_sigma

        # 优先选难度在置信区间内的题
        if theta_low <= item['b'] <= theta_high:
            score = item['a'] ** 2 * P_hat * (1 - P_hat)  # Fisher 信息量
        else:
            score = 0.1 * item['a'] ** 2 * P_hat * (1 - P_hat)  # 惩罚

        # 内容平衡：限制连续同题型
        if best_score < score:
            best_score = score
            best_item = item

    return best_item
```

#### 2.2.5 测评终止规则

满足以下任一条件即终止测评：

```python
def should_terminate(session):
    """
    判断测评是否应终止
    """
    # 条件1：能力估计标准差足够小（测量精度达标）
    if session['theta_sigma'] < TERMINATE_SIGMA:  # 默认 0.35
        return True, "precision_reached"

    # 条件2：已达到最大题数
    if session['item_count'] >= MAX_ITEMS:  # 默认 35
        return True, "max_items_reached"

    # 条件3：达到最小题数且能力估计稳定（连续5题θ̂变化 < 0.1）
    if session['item_count'] >= MIN_ITEMS:  # 默认 20
        recent_thetas = session['theta_history'][-5:]
        if max(recent_thetas) - min(recent_thetas) < 0.1:
            return True, "stable_estimate"

    # 条件4：超时
    if session['elapsed_seconds'] > MAX_DURATION:  # 默认 300秒
        return True, "timeout"

    return False, None
```

### 2.3 隐式能力追踪：日常学习行为推断

除了正式的测评会话，系统还从日常学习行为中**隐式**更新词汇能力：

| 信号来源 | 更新规则 | 权重 |
|---------|---------|------|
| 词汇练习答对 | 对应词 P(known) 提升 | 高 |
| 词汇练习答错 | 对应词 P(known) 降低 | 高 |
| 阅读理解答题中含目标词 | 根据题目正确率推断 | 中 |
| AI 辅导对话中使用高级词汇 | 正面信号，小幅提升 | 低 |
| 单词本手动移除(已知) | P(known) 设为 0.9 | 中 |
| 同义词/词族关联词掌握 | 关联词 P(known) 小幅提升 | 低 |

### 4.4 词汇量估计计算

从 IRT 能力值 `θ` 到人类可理解的词汇量的映射：

```python
def theta_to_vocab_size(theta, grade, vocab_db_size):
    """
    将 IRT 能力值 θ 映射为词汇量估计
    theta:         IRT 能力值 [-3, 3]
    grade:         用户年级 (1-12)
    vocab_db_size: 词库总词数
    """
    # 方案1: 基于词频排序的映射
    # θ 越高 → 认识的词频排名越靠后 → 词汇量越大

    # 各年级 θ=0 对应的基准词汇量
    GRADE_BASELINE = {
        3: 200, 4: 350, 5: 500, 6: 700,
        7: 900, 8: 1200, 9: 1600,
        10: 2200, 11: 3000, 12: 3800
    }

    baseline = GRADE_BASELINE.get(grade, 500)

    # θ 到词汇量的非线性映射（sigmoid 变换）
    # θ=-3 → 接近 0, θ=0 → baseline, θ=3 → 接近 vocab_db_size
    theta_normalized = (theta + 3) / 6  # [0, 1]

    # 使用对数曲线：词汇量增长是递减的
    import math
    ratio = 1 / (1 + math.exp(-2 * theta))  # sigmoid
    vocab_estimate = int(ratio * vocab_db_size * 0.8 + baseline * 0.2)

    return max(0, min(vocab_estimate, vocab_db_size))
```

## 6. 关键代码实现

### 6.1 测评会话管理器

```python
import uuid
import math
from datetime import datetime, timezone
from typing import Optional

class VocabAssessmentManager:
    """词汇测评会话管理器"""

    # 测评配置常量
    MIN_ITEMS = 20
    MAX_ITEMS = 35
    TERMINATE_SIGMA = 0.35
    MAX_DURATION_SECONDS = 300

    # 年级先验能力值（μ₀）
    GRADE_PRIOR_THETA = {
        3: -1.5, 4: -1.0, 5: -0.5, 6: 0.0,
        7: 0.3, 8: 0.5, 9: 0.8,
        10: 1.0, 11: 1.3, 12: 1.5
    }

    async def start_session(
        self,
        user_id: int,
        assessment_type: str,
        grade: int,
        textbook_version: Optional[str] = None
    ) -> dict:
        """创建测评会话"""
        session_id = f"va-{datetime.now().strftime('%Y%m%d')}-{uuid.uuid4().hex[:8]}"

        # 获取先验能力值
        profile = await self._get_or_create_profile(user_id, grade)
        prior_mu = profile.current_theta
        prior_sigma = profile.current_sigma

        # 新用户用年级先验
        if profile.total_assessments == 0:
            prior_mu = self.GRADE_PRIOR_THETA.get(grade, 0.0)
            prior_sigma = 1.0

        # 创建会话记录
        session = await self.db.insert('vocab_assessment_session', {
            'id': session_id,
            'user_id': user_id,
            'assessment_type': assessment_type,
            'grade': grade,
            'theta_initial': prior_mu,
            'sigma_initial': prior_sigma,
            'status': 'IN_PROGRESS',
            'item_count': 0,
            'correct_count': 0,
            'started_at': datetime.now(timezone.utc),
        })

        # 选择第一道题
        first_item = await self._select_first_item(prior_mu, grade, textbook_version)

        # 缓存会话状态到 Redis
        await self.redis.hset(f"vocab_session:{session_id}", mapping={
            'user_id': user_id,
            'theta': prior_mu,
            'sigma': prior_sigma,
            'item_count': 0,
            'used_item_ids': '',
            'grade': grade,
            'started_ts': datetime.now(timezone.utc).timestamp(),
        })

        return {
            'session_id': session_id,
            'first_item': first_item,
            'total_items_estimate': f"{self.MIN_ITEMS}-{self.MAX_ITEMS}",
            'estimated_duration': '3-5分钟'
        }

    async def process_response(
        self,
        session_id: str,
        item_id: int,
        answer: str,
        time_cost_ms: int
    ) -> dict:
        """处理用户作答并返回下一题或完成"""
        # 从 Redis 获取会话状态
        session_state = await self.redis.hgetall(f"vocab_session:{session_id}")
        if not session_state:
            raise NotFoundError(f"Session {session_id} not found")

        # 获取题目信息
        item = await self.db.fetch_one(
            'vocab_assessment_item',
            id=item_id
        )
        if not item:
            raise NotFoundError(f"Item {item_id} not found")

        # 判题
        is_correct = (answer.upper() == item['correct_key'])

        # IRT 贝叶斯更新
        theta_before = float(session_state['theta'])
        sigma_before = float(session_state['sigma'])

        theta_after, sigma_after = self._bayesian_update(
            theta_before, sigma_before,
            item['difficulty_b'], item['discrimination_a'],
            1 if is_correct else 0
        )

        # 写入答题记录
        await self.db.insert('vocab_assessment_response', {
            'session_id': session_id,
            'user_id': session_state['user_id'],
            'item_id': item_id,
            'word_id': item['word_id'],
            'item_order': int(session_state['item_count']) + 1,
            'response': 1 if is_correct else 0,
            'user_answer': answer,
            'theta_before': theta_before,
            'sigma_before': sigma_before,
            'theta_after': theta_after,
            'sigma_after': sigma_after,
            'time_cost_ms': time_cost_ms,
        })

        # 更新 Redis 会话状态
        item_count = int(session_state['item_count']) + 1
        used_ids = session_state.get('used_item_ids', '')
        used_ids = used_ids + f",{item_id}" if used_ids else str(item_id)

        await self.redis.hset(f"vocab_session:{session_id}", mapping={
            'theta': theta_after,
            'sigma': sigma_after,
            'item_count': item_count,
            'used_item_ids': used_ids,
        })

        # 更新词汇掌握概率
        await self._update_word_knowledge(
            int(session_state['user_id']),
            item['word_id'],
            item['word'],
            is_correct,
            'ASSESSMENT'
        )

        # 终止判断
        should_stop, reason = self._should_terminate(
            theta_after, sigma_after, item_count,
            datetime.now(timezone.utc).timestamp() - float(session_state['started_ts'])
        )

        if should_stop:
            return await self._complete_session(session_id, session_state, reason)

        # 选择下一题
        next_item = await self._select_next_item(
            theta_after, sigma_after,
            int(session_state['grade']),
            used_ids.split(',')
        )

        return {
            'is_correct': is_correct,
            'correct_key': item['correct_key'],
            'explanation': item.get('explanation', ''),
            'progress': {
                'item_count': item_count,
                'correct_count': int(session_state.get('correct_count', 0)) + (1 if is_correct else 0),
            },
            'next_item': next_item,
            'is_finished': False
        }

    def _bayesian_update(
        self,
        prior_mu: float,
        prior_sigma: float,
        item_b: float,
        item_a: float,
        response: int
    ) -> tuple:
        """IRT 贝叶斯后验更新（BEC 方法）"""
        prior_var = prior_sigma ** 2

        # 2PL 模型下的正确概率
        exponent = item_a * (prior_mu - item_b)
        exponent = max(-30, min(30, exponent))  # 防溢出
        P = 1.0 / (1.0 + math.exp(-exponent))

        # Fisher 信息量
        info = item_a ** 2 * P * (1 - P)

        # BEC 后验更新
        denominator = 1.0 + prior_var * info
        posterior_mu = prior_mu + (prior_var * item_a * (response - P)) / denominator
        posterior_var = prior_var / denominator
        posterior_sigma = math.sqrt(max(posterior_var, 0.01))  # 防止方差过小

        return round(posterior_mu, 3), round(posterior_sigma, 3)
```

class AdaptiveItemSelector:
    """CAT 自适应选题引擎"""

    # 各题型的种子题数量（首次选题用）
    SEED_ITEM_COUNT = 3

    # 题型权重（内容平衡）
    ITEM_TYPE_WEIGHTS = {
        'WORD_MEANING': 0.50,   # 看词选义
        'SPELLING': 0.20,       # 听音拼写
        'CONTEXT': 0.20,        # 语境填空
        'PRONUNCIATION': 0.10,  # 音标选择
    }

    async def select_first_item(
        self,
        prior_theta: float,
        grade: int,
        textbook_version: Optional[str] = None
    ) -> dict:
        """选择首道题目：难度最接近先验能力值"""
        # 从题库中选取难度在 θ₀ ± 0.5 范围内的题
        candidates = await self.db.fetch_all(
            """
            SELECT * FROM vocab_assessment_item
            WHERE status = 1
              AND difficulty_b BETWEEN %s AND %s
              AND FIND_IN_SET(%s, grade_range)
            ORDER BY RAND() LIMIT 10
            """,
            [prior_theta - 0.5, prior_theta + 0.5, f"grade_{grade}"]
        )

        if not candidates:
            # 降级：取所有可用题中难度最接近的
            candidates = await self.db.fetch_all(
                """
                SELECT * FROM vocab_assessment_item
                WHERE status = 1
                ORDER BY ABS(difficulty_b - %s) ASC LIMIT 10
                """,
                [prior_theta]
            )

        # 从候选中随机选一道（增加安全性，避免固定序列）
        import random
        return self._format_item(random.choice(candidates))

    async def select_next_item(
        self,
        theta_hat: float,
        theta_sigma: float,
        grade: int,
        used_item_ids: list,
        item_type_history: Optional[list] = None
    ) -> dict:
        """基于 CAT 引擎选择最优下一题"""

        # 从题库获取候选题（排除已用题）
        used_ids_str = ','.join(used_item_ids) if used_item_ids else '0'
        candidates = await self.db.fetch_all(
            """
            SELECT * FROM vocab_assessment_item
            WHERE status = 1
              AND id NOT IN (%s)
              AND FIND_IN_SET(%s, grade_range)
            """,
            [used_ids_str, f"grade_{grade}"]
        )

        if not candidates:
            return None  # 题库耗尽

        # 计算每道题的评分
        scored = []
        for item in candidates:
            # Fisher 信息量（核心指标）
            P_hat = self._irf(item['discrimination_a'], item['difficulty_b'], theta_hat)
            fisher_info = item['discrimination_a'] ** 2 * P_hat * (1 - P_hat)

            # 难度适配性：优先选难度在置信区间内的题
            theta_low = theta_hat - 1.5 * theta_sigma
            theta_high = theta_hat + 1.5 * theta_sigma
            if theta_low <= item['difficulty_b'] <= theta_high:
                difficulty_score = 1.0
            else:
                distance = abs(item['difficulty_b'] - theta_hat)
                difficulty_score = max(0.1, 1.0 - 0.2 * distance)

            # 内容平衡：控制题型分布
            type_count = 0
            if item_type_history:
                type_count = item_type_history.count(item['item_type'])
            type_weight = self.ITEM_TYPE_WEIGHTS.get(item['item_type'], 0.1)
            recent_type_penalty = max(0.3, 1.0 - 0.15 * type_count)

            # 词频覆盖率检查：确保不同词频段都有覆盖
            frequency_score = self._frequency_coverage_score(item['frequency_rank'])

            # 综合评分
            total_score = (
                fisher_info * 0.55 +
                difficulty_score * 0.20 +
                type_weight * recent_type_penalty * 0.15 +
                frequency_score * 0.10
            )

            scored.append((total_score, item))

        # 选评分最高的
        scored.sort(key=lambda x: x[0], reverse=True)

        # 从 top-3 中随机选一道（增加随机性，防猜测）
        import random
        top_k = min(3, len(scored))
        selected = random.choice(scored[:top_k])[1]

        return self._format_item(selected)

    def _irf(self, a: float, b: float, theta: float) -> float:
        """IRT 2PL 项目反应函数"""
        exponent = max(-30, min(30, a * (theta - b)))
        return 1.0 / (1.0 + math.exp(-exponent))

    def _frequency_coverage_score(self, frequency_rank: int) -> float:
        """词频覆盖度评分：鼓励不同频段选题"""
        if frequency_rank <= 500:
            band = 'top500'
        elif frequency_rank <= 1000:
            band = 'top1k'
        elif frequency_rank <= 2000:
            band = 'top2k'
        elif frequency_rank <= 3000:
            band = 'top3k'
        else:
            band = 'beyond'
        # 实际实现需要检查已选题的频段分布
        return 1.0  # 简化版

    def _format_item(self, item: dict) -> dict:
        """格式化题目输出（移除答案和IRT参数）"""
        return {
            'item_id': item['id'],
            'item_type': item['item_type'],
            'word': item['word'],
            'phonetic_us': item.get('phonetic_us', ''),
            'options': item['options'] if item['item_type'] in ('WORD_MEANING', 'PRONUNCIATION') else None,
            'prompt': item.get('prompt'),
            'audio_us_url': item.get('audio_us_url'),
            'audio_uk_url': item.get('audio_uk_url'),
            'time_limit_seconds': 15 if item['item_type'] == 'WORD_MEANING' else 20,
        }

        if 'delta_set' in rule:
            new_p = rule['delta_set']  # 直接设置
        else:
            new_p = current_p + rule['delta']
            new_p = max(0.001, min(0.999, new_p))

        # 置信度（基于证据数量）
        confidence = min(100, evidence_count * 15)

            'sigma': sigma_final,

    async def _batch_update_word_knowledge_from_assessment(
        self,
        user_id: int,
        session_id: str,
        theta: float
    ):
        """根据测评能力值批量更新全词库的 P(known) 推断"""
        # 仅更新未被直接测量过的词（通过 IRT 模型推断）
        # 批量更新，每批 1000 词
        BATCH_SIZE = 1000
        offset = 0

        while True:
            words = await self.db.fetch_all(
                """
                SELECT vw.id, vw.word, vw.difficulty
                FROM vocab_word vw
                LEFT JOIN vocab_word_knowledge vwk
                  ON vw.id = vwk.word_id AND vwk.user_id = %s
                WHERE vw.status = 1 AND vwk.id IS NULL
                LIMIT %s OFFSET %s
                """,
                [user_id, BATCH_SIZE, offset]
            )

            if not words:
                break

            # 批量计算 P(known)
            rows = []
            for w in words:
                # 将难度 1-10 映射到 IRT b 参数
                b = (w['difficulty'] - 5.5) / 2.0  # difficulty 1→b=-2.25, 10→b=2.25
                P = 1.0 / (1.0 + math.exp(-1.2 * (theta - b)))
                rows.append({
                    'user_id': user_id,
                    'word_id': w['id'],
                    'word': w['word'],
                    'p_known': round(P, 4),
                    'evidence_count': 0,
                    'last_evidence': 'INFERRED',
                    'confidence': 20,  # 低置信度（推断值）
                    'last_updated': datetime.now(timezone.utc),
                })

            # 批量插入
            await self.db.bulk_upsert('vocab_word_knowledge', rows, conflict_keys=['user_id', 'word_id'])

            offset += BATCH_SIZE

    def _theta_to_cefr(self, theta: float, grade: int) -> str:
        """能力值映射到 CEFR 等级"""
        # 简化映射（可按年级调整）
        CEFR_MAP = [
            (-2.0, 'pre_A1'),
            (-1.0, 'A1'),
            (0.0,  'A2'),
            (0.8,  'B1'),
            (1.5,  'B2'),
            (2.2,  'C1'),
        ]
        for threshold, level in CEFR_MAP:
            if theta < threshold:
                return level
        return 'C2'

### 9.2 降级策略

```python
class AssessmentFallbackHandler:
    """测评降级处理器"""

    async def handle_insufficient_items(self, session_id, session_state):
        """题库不足时的降级：使用已有数据结束测评"""
        if int(session_state['item_count']) >= 10:
            # 至少10题，可以给出粗略估计
            return await self.complete_session(session_id, session_state, "item_bank_insufficient")
        else:
            # 题数太少，使用年级先验作为结果
            grade = int(session_state['grade'])
            fallback_theta = VocabAssessmentManager.GRADE_PRIOR_THETA.get(grade, 0)
            session_state['theta'] = fallback_theta
            session_state['sigma'] = 1.5  # 高不确定性
            return await self.complete_session(session_id, session_state, "fallback_to_prior")

    async def handle_redis_failure(self, session_id):
        """Redis 故障时从 DB 恢复会话状态"""
        session = await self.db.fetch_one(
            'vocab_assessment_session', id=session_id
        )
        if not session or session['status'] != 'IN_PROGRESS':
            raise NotFoundError("Session not found")

        # 从 DB 重建会话状态
        responses = await self.db.fetch_all(
            """
            SELECT * FROM vocab_assessment_response
            WHERE session_id = %s ORDER BY item_order
            """,
            [session_id]
        )

        # 逐步重放能力更新
        theta = float(session['theta_initial'])
        sigma = float(session['sigma_initial'])
        used_ids = []
        for r in responses:
            item = await self.db.fetch_one('vocab_assessment_item', id=r['item_id'])
            theta, sigma = self._bayesian_update(
                theta, sigma,
                item['difficulty_b'], item['discrimination_a'],
                r['response']
            )
            used_ids.append(str(r['item_id']))

        # 写回 Redis
        await self.redis.hset(f"vocab_session:{session_id}", mapping={
            'theta': theta, 'sigma': sigma,
            'item_count': len(responses),
            'used_item_ids': ','.join(used_ids),
            # ...
        })

        return {'theta': theta, 'sigma': sigma, 'item_count': len(responses)}
```

## 附录

### A. IRT 参数标定流程

题目初始的 `difficulty_b` 和 `discrimination_a` 参数来源：

1. **初始值**：由学科专家根据难度等级设定
2. **预测试标定**：取 500+ 样本数据用 `mirt` R 包进行 EM 估计
3. **在线校准**：每月基于全量答题数据重新估计参数，剔除区分度过低(a<0.3)或过高(a>2.5)的异常题目

### B. CEFR 与词频对应参考

| CEFR | 词汇量参考 | COCA 词频排名范围 |
|------|-----------|-----------------|
| pre-A1 | 0-100 | 1-100 |
| A1 | 100-500 | 100-500 |
| A2 | 500-1000 | 500-1200 |
| B1 | 1000-2500 | 1200-3000 |
| B2 | 2500-4000 | 3000-5000 |
| C1 | 4000-8000 | 5000-10000 |
| C2 | 8000+ | 10000+ |

### C. 安全考虑

- 测评答案不返回给客户端直到答题完成（防止前端作弊）
- 每道题设置 15-20 秒超时（防止查词典）
- 同一用户的测评频率限制：每天≤3次，每周≤5次
- 测评结果含异常模式检测（全对/全错/固定时间间隔等）
- P(known) 推断数据不直接暴露给客户端，仅返回聚合统计
