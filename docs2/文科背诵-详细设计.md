# 文科背诵 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

文科背诵模块面向小学至高中学生，覆盖语文、英语、历史、政治、地理等文科学科，提供记忆辅助、背诵检测和知识点复述练习。该模块以**独立的背诵练习入口**和**嵌入式背诵触发**两种形式存在——用户可以在"同步课堂"或"考点梳理"的学习流程中随时启动背诵练习，也可以从首页直达背诵模块。

### 1.2 目标用户

| 学段 | 学科 | 典型背诵内容 |
| --- | --- | --- |
| 小学 | 语文 | 古诗词、课文段落、生字词 |
| 小学 | 英语 | 单词、短语、简单句型 |
| 初中 | 语文 | 文言文、古诗文、课文段落 |
| 初中 | 英语 | 单词、语法例句、范文段落 |
| 初中 | 历史/政治/地理 | 重要年代、事件、概念、地图知识 |
| 高中 | 语文 | 文言文全文、古诗词、文学常识 |
| 高中 | 英语 | 高考词汇、语法句型、写作模板 |
| 高中 | 历史/政治/地理 | 知识点、框架、材料分析模板 |

### 1.3 核心原则

1. **科学记忆**：基于艾宾浩斯遗忘曲线安排复习频次，避免"背了就忘"
2. **分段突破**：长文本拆分为适合记忆的小段，降低认知负担
3. **主动回忆**：优先使用填空、关键词提示、问答等方式触发主动回忆，而非简单重复阅读
4. **多模态支持**：结合文字、语音进行背诵检测，适配不同学习习惯
5. **即时反馈**：背诵完成后立即给出准确率、遗漏点和改进建议

## 2. 整体流程

```
用户进入背诵模块
        │
        ▼
┌────────────────────┐
│  选择背诵材料       │  ← 从教材章节/考点/自定义导入
└────────────────────┘
        │
        ▼
┌────────────────────┐
│  材料预处理         │  ← 分段、提取关键词、生成提示
└────────────────────┘
        │
        ▼
┌────────────────────┐
│  选择背诵模式       │  ← 初学/复习/检测/速览
└────────────────────┘
        │
        ├── 初学模式 ──────► 通读原文 → 逐段背诵 → 关键词提示 → 完整背诵
        │
        ├── 复习模式 ──────► 填空练习 → 关键词回忆 → 完整复述
        │
        ├── 检测模式 ──────► 语音/文本背诵 → AI 对比评分 → 错误标注
        │
        └── 速览模式 ──────► 闪卡式快速浏览 → 自评掌握度
        │
        ▼
┌────────────────────┐
│  记录背诵结果       │  ← 掌握度评分、错误点、耗时
└────────────────────┘
        │
        ▼
┌────────────────────┐
│  更新复习计划       │  ← 按遗忘曲线计算下次复习时间
└────────────────────┘
```

## 3. 数据结构设计

### 3.1 背诵材料模型 (RecitationMaterial)

```json
{
  "tableName": "recitation_material",
  "fields": {
    "id": "BIGINT PRIMARY KEY AUTO_INCREMENT",
    "title": "VARCHAR(200) NOT NULL COMMENT '材料标题，如《静夜思》'",
    "subject": "ENUM('chinese','english','history','politics','geography') NOT NULL",
    "grade_level": "VARCHAR(20) NOT NULL COMMENT '学段年级，如 junior_1'",
    "textbook_id": "BIGINT COMMENT '关联教材ID，可为空表示课外材料'",
    "chapter_id": "BIGINT COMMENT '关联章节ID'",
    "knowledge_point_id": "BIGINT COMMENT '关联知识点ID'",
    "full_text": "TEXT NOT NULL COMMENT '完整原文'",
    "segments": "JSON NOT NULL COMMENT '分段信息，见 RecitationSegment'",
    "keywords": "JSON NOT NULL COMMENT '关键词列表，见 KeywordItem'",
    "difficulty": "TINYINT DEFAULT 3 COMMENT '难度 1-5，5最难'",
    "estimated_memory_minutes": "INT COMMENT '预估背诵所需分钟数'",
    "source_type": "ENUM('textbook','exam','custom','platform') DEFAULT 'textbook'",
    "audio_url": "VARCHAR(500) COMMENT '标准朗读音频URL'",
    "tags": "JSON COMMENT '标签，如 [\"必背\",\"高考\",\"七年级\"]'",
    "status": "TINYINT DEFAULT 1 COMMENT '0-禁用 1-启用'",
    "created_at": "DATETIME DEFAULT CURRENT_TIMESTAMP",
    "updated_at": "DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP"
  },
  "indexes": [
    {"name": "idx_subject_grade", "columns": ["subject", "grade_level"]},
    {"name": "idx_textbook_chapter", "columns": ["textbook_id", "chapter_id"]},
    {"name": "idx_knowledge_point", "columns": ["knowledge_point_id"]}
  ]
}
```

## 5. 背诵模式详细设计

### 5.1 初学模式 (first_learn)

适用场景：首次学习新内容。

**流程：**

```
Step 1: 展示原文 + 朗读音频 → 用户通读（建议30秒-2分钟）
         │
Step 2: 展示第一段原文 → 隐藏 → 用户尝试背诵
         │
         ├── 通过 → 进入 Step 3
         └── 未通过 → 给出关键词提示 → 再试一次
         │
Step 3: 展示第二段原文 → 隐藏 → 用户尝试背诵
         │
         ... 逐段进行 ...
         │
Step N: 全文连背 → 评分 → 生成反馈 → 创建复习计划
```

**Prompt 模板（AI 辅助讲解）：**

```
你是一位耐心的背诵辅导老师。学生正在学习背诵以下内容：

【材料标题】{title}
【学科】{subject}
【年级】{grade_level}
【当前段落】{current_segment_text}
【关键词】{keywords}

请为学生提供背诵技巧提示，要求：
1. 2-3条记忆技巧（如联想记忆、画面想象、韵律节奏等）
2. 标注关键词的释义或记忆锚点
3. 语气亲切鼓励，适合{grade_level}学生理解
4. 控制在100字以内
```

### 5.2 复习模式 (review)

适用场景：已学过，按计划复习。

**流程：**

```
Step 1: 不展示原文，直接要求背诵（或填空）
         │
Step 2: 用户输入背诵内容（文字或语音）
         │
Step 3: AI 对比评分 → 标注错误点
         │
         ├── 掌握度 ≥ 80 → 通过，更新复习计划（延长间隔）
         ├── 掌握度 50-79 → 部分通过，展示错误段落并要求重背
         └── 掌握度 < 50 → 未通过，进入"重新学习"流程
```

**填空变体（用于知识点和短文本）：**

```
原文：秦始皇统一六国，建立了中国历史上第一个统一的多民族封建国家。

填空：秦___统一六国，建立了中国历史上第一个统一的___封建国家。
      ↑        ↑
    始皇     多民族
```

填空内容由 AI 根据关键词自动生成，每次复习随机选择不同的关键词挖空。

### 5.3 检测模式 (test)

适用场景：考前自测、正式背诵检测。

**流程：**

```
Step 1: 选择要检测的材料
         │
Step 2: 全文背诵（不提供任何提示）
         │
Step 3: AI 逐字逐句对比 → 生成详细评分报告
         │
Step 4: 展示评分报告（分数、错误清单、改进建议）
```

**评分报告包含：**

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 完整度 | 40% | 是否背诵完整，有无遗漏段落 |
| 准确度 | 35% | 字词是否正确，有无替换/颠倒 |
| 流畅度 | 15% | 语音模式下判断停顿、卡顿（文本模式此项给满分） |
| 语音（可选） | 10% | 发音准确性，仅在语音模式下评估 |

### 5.4 闪卡模式 (flash)

适用场景：快速浏览大量材料，唤醒记忆。

**流程：**

```
展示正面（标题/关键词） → 用户自评是否记住
         │
         ├── "记住了" → 标记为已通过，下次间隔拉长
         ├── "模糊" → 展示原文 → 标记需复习
         └── "忘记了" → 展示原文 + 背诵技巧 → 加入今日复习列表
```

特点：无输入负担，适合碎片时间快速刷一遍。

## 6. 遗忘曲线复习算法

### 6.1 SM-2 算法改编

采用基于 SM-2（SuperMemo 2）的改编算法，适配背诵场景：

```
输入：
  - quality: 本次背诵掌握度评分 (0-100)
  - easiness_factor (EF): 难度因子，默认 2.50，范围 [1.30, 3.00]
  - interval: 当前间隔天数
  - review_count: 累计复习次数

计算规则：
  1. 将 quality 映射为 q (0-5)：
     - quality >= 95 → q = 5 (完美)
     - quality >= 80 → q = 4 (顺利)
     - quality >= 60 → q = 3 (勉强通过)
     - quality >= 40 → q = 2 (困难)
     - quality >= 20 → q = 1 (很困难)
     - quality < 20  → q = 0 (完全忘记)

  2. 更新 EF：
     EF' = EF + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02))
     EF' = max(1.30, EF')   // 下限保护

  3. 计算新间隔：
     if q < 3:
       // 未通过，重置间隔
       interval' = 1
       review_count' = 0
     else:
       // 通过，按规则增长
       if review_count == 0: interval' = 1
       elif review_count == 1: interval' = 6
       else: interval' = round(interval * EF')

  4. 计算下次复习时间：
     next_review_at = now + interval' days (固定在当天 09:00)
```

### 6.2 关键实现代码

```python
from datetime import datetime, timedelta
from dataclasses import dataclass

@dataclass
class ReviewState:
    """背诵复习状态"""
    easiness_factor: float = 2.50
    interval_days: int = 1
    review_count: int = 0
    current_mastery: float = 0.0

def calculate_next_review(quality: float, state: ReviewState) -> ReviewState:
    """
    根据背诵质量计算下次复习计划。
    
    Args:
        quality: 本次背诵掌握度 0-100
        state: 当前复习状态
    
    Returns:
        更新后的复习状态
    """
    # Step 1: 将 quality 映射到 0-5
    if quality >= 95:   q = 5
    elif quality >= 80: q = 4
    elif quality >= 60: q = 3
    elif quality >= 40: q = 2
    elif quality >= 20: q = 1
    else:               q = 0

    # Step 2: 更新 EF
    new_ef = state.easiness_factor + (
        0.1 - (5 - q) * (0.08 + (5 - q) * 0.02)
    )
    new_ef = max(1.30, new_ef)

    # Step 3: 计算间隔
    if q < 3:
        # 未通过：重置
        new_interval = 1
        new_count = 0
    else:
        new_count = state.review_count + 1
        if new_count == 1:
            new_interval = 1
        elif new_count == 2:
            new_interval = 6
        else:
            new_interval = round(state.interval_days * new_ef)

    return ReviewState(
        easiness_factor=new_ef,
        interval_days=new_interval,
        review_count=new_count,
        current_mastery=quality
    )

def get_next_review_datetime(interval_days: int) -> datetime:
    """计算下次复习时间，固定在当天 09:00"""
    target = datetime.now() + timedelta(days=interval_days)
    return target.replace(hour=9, minute=0, second=0, microsecond=0)
```

### 6.3 复习调度策略

```
每日复习调度流程（定时任务 08:00 执行）：

1. 查询所有 next_review_at <= 今天的活跃复习计划
2. 按优先级排序：
   - overdue（逾期） > today（今日到期）
   - mastery 越低优先级越高
   - review_stage 越大（越接近遗忘）优先级越高
3. 取 Top 20 条生成今日复习任务
4. 向用户推送"今日待复习背诵"提醒
```

## 7. AI 对比评分引擎

### 7.1 文本对比评分

```python
import difflib
from typing import List, Tuple

@dataclass
class DiffResult:
    """对比结果"""
    score: float               # 0-100
    errors: List[ErrorDetail]   # 错误详情
    matched_segments: int       # 匹配段数
    total_segments: int         # 总段数


def compare_recitation(expected: str, actual: str,
                       subject: str) -> DiffResult:
    """
    背诵文本对比核心算法。
    
    逻辑：
    1. 预处理：统一标点、空格、大小写（英语）
    2. 按段落拆分对比（基于换行符或分号）
    3. 对每段使用 SequenceMatcher 计算相似度
    4. 标记差异点，分类为 missing/substitute/extra/reorder
    5. 加权计算总分
    """
    expected_clean = _normalize(expected, subject)
    actual_clean = _normalize(actual, subject)
    
    exp_segments = expected_clean.split('\n')
    act_segments = actual_clean.split('\n')
    
    errors = []
    total_score = 0.0
    
    for i, (exp_seg, act_seg) in enumerate(
        itertools.zip_longest(exp_segments, act_segments, fillvalue='')
    ):
        if not exp_seg:
            errors.append(ErrorDetail(
                position=0, expected='', actual=act_seg,
                error_type='extra', segment_index=i+1
            ))
            continue
        if not act_seg:
            errors.append(ErrorDetail(
                position=0, expected=exp_seg, actual='',
                error_type='missing', segment_index=i+1
            ))
            continue
        
        ratio = difflib.SequenceMatcher(
            None, exp_seg, act_seg
        ).ratio()
        seg_score = ratio * 100
        total_score += seg_score
        
        if seg_score < 100:
            for tag, i1, i2, j1, j2 in difflib.SequenceMatcher(
                None, exp_seg, act_seg
            ).get_opcodes():
                if tag == 'replace':
                    errors.append(ErrorDetail(
                        position=i1, expected=exp_seg[i1:i2],
                        actual=act_seg[j1:j2],
                        error_type='substitute', segment_index=i+1
                    ))
                elif tag == 'delete':
                    errors.append(ErrorDetail(
                        position=i1, expected=exp_seg[i1:i2],
                        actual='', error_type='missing', segment_index=i+1
                    ))
                elif tag == 'insert':
                    errors.append(ErrorDetail(
                        position=i1, expected='',
                        actual=act_seg[j1:j2],
                        error_type='extra', segment_index=i+1
                    ))
    
    avg_score = total_score / max(len(exp_segments), 1)
    return DiffResult(
        score=round(avg_score, 2),
        errors=errors,
        matched_segments=sum(1 for e in exp_segments if e),
        total_segments=len(exp_segments)
    )


def _normalize(text: str, subject: str) -> str:
    """文本标准化"""
    import re
    # 统一中英文标点
    for cn, en in [('，',','),('。','.'),('！','!'),('？','?'),('；',';'),('：',':')]:
        text = text.replace(cn, en)
    # 去除多余空格
    text = re.sub(r'\s+', ' ', text).strip()
    # 英语特殊处理：不区分大小写
    if subject == 'english':
        text = text.lower()
    return text
```

### 7.3 语音评分流程

```
语音输入
    │

    │

    │
    ▼

    │
```

发音质量评分规则：

- ASR 整体置信度 0.7-0.9 → 发音分 80
- ASR 整体置信度 0.5-0.7 → 发音分 60
- ASR 整体置信度 < 0.5 → 发音分 40，提示发音不标准
