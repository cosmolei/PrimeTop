# 服务端-学生用户学习日历事件冲突检测与智能时间槽推荐引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 学习日历体系中的**智能调度核心**。当学生的日历中汇聚了多种来源的事件（学校课表、考试日程、作业截止、学习计划任务、系统推荐复习、家长设置的限制时段等）后，本引擎负责：

1. **冲突检测**：识别时间重叠、间隔过密、认知负荷过载等多种冲突类型。
2. **时间槽推荐**：在学生的可用时间窗内，智能推荐最优学习时间槽。
3. **重排建议**：当临时事件（如今晚加作业）打破原有计划时，自动生成重排方案。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 冲突检测延迟 | P99 < 200ms（单用户单日事件 ≤ 50 条） |
| 时间槽推荐质量 | 推荐采纳率 ≥ 60%（上线 3 个月后） |
| 系统吞吐 | 支持 10K 并发日历查询 |
| 可用性 | 99.9% |

### 1.3 适用范围

- 小学至高中全学段学生用户
- 与 `学习日历事件与考试日程管理服务` 协同工作
- 为 `每日任务智能生成与学习计划执行追踪服务` 提供调度能力
- 为 `多源学习任务统一调度与优先级仲裁引擎` 提供时间冲突判断

## 2. 核心概念定义

### 2.1 日历事件(Calendar Event)

```typescript
interface CalendarEvent {
  eventId: string;              // 事件唯一ID
  userId: string;               // 学生用户ID
  eventType: EventType;         // 事件类型
  title: string;                // 事件标题
  startTime: string;            // ISO 8601 开始时间
  endTime: string;              // ISO 8601 结束时间
  timezone: string;             // 时区
  isAllDay: boolean;            // 是否全天事件
  priority: EventPriority;      // 优先级
  flexibility: Flexibility;     // 时间灵活度
  source: EventSource;          // 事件来源
  status: EventStatus;          // 事件状态
  subject?: string;             // 关联学科(可选)
  cognitiveLoad?: CognitiveLoad;// 认知负荷等级(可选)
  relatedTaskId?: string;       // 关联任务ID(可选)
  relatedExamId?: string;       // 关联考试ID(可选)
  metadata?: Record<string, any>; // 扩展元数据
}

type EventType =
  | 'SCHOOL_CLASS'        // 学校课程
  | 'EXAM'                // 考试
  | 'HOMEWORK_DEADLINE'   // 作业截止
  | 'STUDY_PLAN_TASK'     // 学习计划任务
  | 'REVIEW_SESSION'      // 复习会话
  | 'EXTRACURRICULAR'     // 课外活动
  | 'REST_BREAK'          // 休息时间
  | 'SLEEP'               // 睡眠时段
  | 'MEAL'                // 用餐时间
  | 'PARENTAL_LIMIT'      // 家长管控时段
  | 'SYSTEM_RECOMMENDED'; // 系统推荐

type EventPriority = 'CRITICAL' | 'HIGH' | 'MEDIUM' | 'LOW';

// 时间灵活度：决定是否可以被重排
type Flexibility =
  | 'FIXED'        // 完全固定(如学校上课、考试)
  | 'SEMI_FLEXIBLE'// 可微调±30分钟(如复习会话)
  | 'FLEXIBLE'     // 可自由移动(如自主练习)
  | 'SUGGESTED';   // 仅建议(系统推荐)

type EventStatus = 'SCHEDULED' | 'IN_PROGRESS' | 'COMPLETED' | 'CANCELLED' | 'SKIPPED';

// 认知负荷等级
type CognitiveLoad = 1 | 2 | 3 | 4 | 5;
// 1=极低(如简单阅读), 3=中等(如练习题), 5=极高(如数学证明推导)
```

## 5. 核心算法设计

### 5.1 冲突检测算法

#### 5.1.1 算法流程

```python
class ConflictDetector:
    """冲突检测器：对单用户指定日期范围内的事件进行多维冲突检测"""

    CONFLICT_RULES = {
        ConflictType.TIME_OVERLAP: {
            'severity': 'CRITICAL',
            'auto_resolve_eligible': False,
        },
        ConflictType.BACK_TO_BACK: {
            'severity': 'INFO',
            'auto_resolve_eligible': True,
        },
        ConflictType.TOO_CLOSE: {
            'severity': 'WARNING',
            'auto_resolve_eligible': True,
        },
        ConflictType.DAILY_OVERLOAD: {
            'severity': 'WARNING',
            'auto_resolve_eligible': False,
        },
        ConflictType.SUBJECT_OVERLOAD: {
            'severity': 'WARNING',
            'auto_resolve_eligible': False,
        },
        ConflictType.LATE_NIGHT: {
            'severity': 'WARNING',
            'auto_resolve_eligible': False,
        },
        ConflictType.PARENTAL_VIOLATION: {
            'severity': 'CRITICAL',
            'auto_resolve_eligible': False,
        },
        ConflictType.EXAM_EVE_OVERLOAD: {
            'severity': 'WARNING',
            'auto_resolve_eligible': False,
        },
        ConflictType.SLEEP_DEPRIVATION: {
            'severity': 'CRITICAL',
            'auto_resolve_eligible': False,
        },
    }

    def detect_conflicts(
        self,
        user_id: str,
        events: list[CalendarEvent],
        preferences: StudentSchedulePreference,
        new_event: CalendarEvent | None = None,
    ) -> list[Conflict]:
        """
        主检测入口：对给定事件集合执行全量冲突检测
        
        Args:
            user_id: 学生ID
            events: 已有事件列表(按时间排序)
            preferences: 学生作息偏好
            new_event: 待新增事件(可选，用于新增前检测)
        
        Returns:
            冲突列表
        """
        all_events = events.copy()
        if new_event:
            all_events.append(new_event)
        all_events.sort(key=lambda e: e.start_time)

        conflicts = []

        # 按天分组
        daily_groups = self._group_by_date(all_events)

        for date, day_events in daily_groups.items():
            # 1. 两两时间重叠检测
            conflicts.extend(self._detect_time_overlaps(day_events, new_event))

            # 2. 间隔密度检测(背靠背、过密)
            conflicts.extend(self._detect_spacing_issues(day_events, preferences))

            # 3. 每日总学习时长超载检测
            conflicts.extend(self._detect_daily_overload(day_events, preferences))

            # 4. 单科连续超时检测
            conflicts.extend(self._detect_subject_overload(day_events, preferences))

            # 5. 深夜学习检测
            conflicts.extend(self._detect_late_night(day_events, preferences))

            # 6. 家长管控时段冲突
            conflicts.extend(self._detect_parental_violations(day_events))

            # 7. 睡眠侵占检测
            conflicts.extend(self._detect_sleep_deprivation(day_events, preferences))

            # 8. 考前夜晚过载检测
            conflicts.extend(self._detect_exam_eve_overload(day_events, all_events))

        return conflicts

    def _detect_time_overlaps(
        self, day_events: list[CalendarEvent], new_event: CalendarEvent | None
    ) -> list[Conflict]:
        """时间重叠检测：使用扫描线算法"""
        conflicts = []
        # 构建时间点扫描线
        points = []
        for e in day_events:
            points.append((e.start_time, 'start', e))
            points.append((e.end_time, 'end', e))
        points.sort(key=lambda p: (p[0], p[1]))  # end 排在 start 前面(同时间点先结束再开始)

        active = []
        for time, kind, event in points:
            if kind == 'start':
                for a in active:
                    # 全天事件不参与重叠检测
                    if event.is_all_day or a.is_all_day:
                        continue
                    overlap_min = self._calc_overlap_minutes(a, event)
                    if overlap_min > 0:
                        # 固定事件之间冲突是 CRITICAL
                        # 灵活事件冲突是 WARNING
                        severity = 'CRITICAL'
                        if (a.flexibility in ('FLEXIBLE', 'SUGGESTED') and
                                event.flexibility in ('FLEXIBLE', 'SUGGESTED')):
                            severity = 'WARNING'
                        conflicts.append(Conflict(
                            conflict_type=ConflictType.TIME_OVERLAP,
                            severity=severity,
                            event_id_1=a.event_id,
                            event_id_2=event.event_id,
                            overlap_minutes=overlap_min,
                            description=f"「{a.title}」与「{event.title}」时间重叠{overlap_min}分钟",
                        ))
                active.append(event)
            else:
                active = [a for a in active if a.event_id != event.event_id]

        return conflicts

    def _detect_spacing_issues(
        self, day_events: list[CalendarEvent], pref: StudentSchedulePreference
    ) -> list[Conflict]:
        """间隔密度检测：背靠背(< 5min)和高负荷过密(< min_break_between)"""
        conflicts = []
        study_events = [e for e in day_events if e.event_type in STUDY_EVENT_TYPES]
        study_events.sort(key=lambda e: e.start_time)

        for i in range(len(study_events) - 1):
            curr = study_events[i]
            nxt = study_events[i + 1]
            gap_min = (nxt.start_time - curr.end_time).total_seconds() / 60

            if gap_min < 0:
                continue  # 重叠，已由 overlap 检测处理

            if gap_min < 5:
                conflicts.append(Conflict(
                    conflict_type=ConflictType.BACK_TO_BACK,
                    severity='INFO',
                    event_id_1=curr.event_id,
                    event_id_2=nxt.event_id,
                    overlap_minutes=int(gap_min),
                    description=f"「{curr.title}」结束到「{nxt.title}」开始仅{gap_min:.0f}分钟，建议增加休息",
                ))
            elif gap_min < pref.min_break_between and (
                (curr.cognitive_load or 0) >= 4 or (nxt.cognitive_load or 0) >= 4
            ):
                conflicts.append(Conflict(
                    conflict_type=ConflictType.TOO_CLOSE,
                    severity='WARNING',
                    event_id_1=curr.event_id,
                    event_id_2=nxt.event_id,
                    overlap_minutes=int(gap_min),
                    description=(
                        f"高负荷学习之间仅{gap_min:.0f}分钟，"
                        f"建议至少{pref.min_break_between}分钟休息"
                    ),
                ))

        return conflicts

    def _detect_daily_overload(
        self, day_events: list[CalendarEvent], pref: StudentSchedulePreference
    ) -> list[Conflict]:
        """每日学习总时长超载检测"""
        study_events = [e for e in day_events if e.event_type in STUDY_EVENT_TYPES]
        total_min = sum(self._duration_min(e) for e in study_events)

        if total_min > pref.max_daily_study:
            over_min = total_min - pref.max_daily_study
            return [Conflict(
                conflict_type=ConflictType.DAILY_OVERLOAD,
                severity='WARNING',
                event_id_1=day_events[0].event_id if day_events else None,
                description=(
                    f"当日学习总时长{total_min}分钟，"
                    f"超过建议上限{pref.max_daily_study}分钟（超出{over_min}分钟）"
                ),
            )]
        return []

    def _detect_subject_overload(
        self, day_events: list[CalendarEvent], pref: StudentSchedulePreference
    ) -> list[Conflict]:
        """单学科连续学习超时检测(默认不超过120分钟)"""
        SUBJECT_MAX = 120  # 分钟
        conflicts = []
        subject_groups = {}
        for e in day_events:
            if e.subject and e.event_type in STUDY_EVENT_TYPES:
                subject_groups.setdefault(e.subject, []).append(e)

        for subject, events in subject_groups.items():
            events.sort(key=lambda e: e.start_time)
            # 检查连续时段(间隔<30分钟视为连续)
            chains = self._find_continuous_chains(events, max_gap=30)
            for chain in chains:
                total = sum(self._duration_min(e) for e in chain)
                if total > SUBJECT_MAX:
                    conflicts.append(Conflict(
                        conflict_type=ConflictType.SUBJECT_OVERLOAD,
                        severity='WARNING',
                        event_id_1=chain[0].event_id,
                        description=(
                            f"学科{subject}连续学习{total}分钟，"
                            f"建议不超过{SUBJECT_MAX}分钟"
                        ),
                    ))
        return conflicts

    def _detect_late_night(
        self, day_events: list[CalendarEvent], pref: StudentSchedulePreference
    ) -> list[Conflict]:
        """深夜学习检测(超过就寝时间)"""
        LATE_THRESHOLD = datetime_time(22, 30)
        conflicts = []
        for e in day_events:
            if e.event_type in STUDY_EVENT_TYPES:
                event_end_time = e.end_time.time()
                if event_end_time > LATE_THRESHOLD:
                    conflicts.append(Conflict(
                        conflict_type=ConflictType.LATE_NIGHT,
                        severity='WARNING',
                        event_id_1=e.event_id,
                        description=f"「{e.title}」结束于{e.end_time.strftime('%H:%M')}，影响睡眠",
                    ))
        return conflicts

    def _detect_parental_violations(
        self, day_events: list[CalendarEvent]
    ) -> list[Conflict]:
        """家长管控时段冲突检测"""
        conflicts = []
        for e in day_events:
            if e.event_type == 'PARENTAL_LIMIT':
                # 检查是否有学习事件与管控时段重叠
                overlap_events = [
                    s for s in day_events
                    if s.event_id != e.event_id
                    and s.event_type in STUDY_EVENT_TYPES
                    and self._calc_overlap_minutes(s, e) > 0
                ]
                for oe in overlap_events:
                    conflicts.append(Conflict(
                        conflict_type=ConflictType.PARENTAL_VIOLATION,
                        severity='CRITICAL',
                        event_id_1=oe.event_id,
                        event_id_2=e.event_id,
                        description=f"「{oe.title}」违反家长设置的管控时段",
                    ))
        return conflicts

    def _detect_sleep_deprivation(
        self, day_events: list[CalendarEvent], pref: StudentSchedulePreference
    ) -> list[Conflict]:
        """睡眠侵占检测"""
        conflicts = []
        bedtime = pref.weekday_end_time if day_events[0].start_time.weekday() < 5 else pref.weekend_end_time
        bedtime_dt = datetime.combine(day_events[0].start_time.date(), bedtime)

        for e in day_events:
            if e.event_type in STUDY_EVENT_TYPES and e.end_time > bedtime_dt:
                deprive_min = (e.end_time - bedtime_dt).total_seconds() / 60
                conflicts.append(Conflict(
                    conflict_type=ConflictType.SLEEP_DEPRIVATION,
                    severity='CRITICAL',
                    event_id_1=e.event_id,
                    overlap_minutes=int(deprive_min),
                    description=f"「{e.title}」侵占睡眠时间{deprive_min:.0f}分钟",
                ))
        return conflicts

    def _detect_exam_eve_overload(
        self, day_events: list[CalendarEvent], all_events: list[CalendarEvent]
    ) -> list[Conflict]:
        """考前夜晚学习过载检测：如果次日有考试，当晚不应超过2小时"""
        EXAM_EVE_MAX = 120  # 分钟
        conflicts = []
        # 找到考试事件
        for e in all_events:
            if e.event_type != 'EXAM':
                continue
            exam_eve = e.start_time.date() - timedelta(days=1)
            eve_events = [
                ev for ev in all_events
                if ev.start_time.date() == exam_eve
                and ev.event_type in STUDY_EVENT_TYPES
            ]
            total = sum(self._duration_min(ev) for ev in eve_events)
            if total > EXAM_EVE_MAX:
                conflicts.append(Conflict(
                    conflict_type=ConflictType.EXAM_EVE_OVERLOAD,
                    severity='WARNING',
                    description=(
                        f"{e.start_time.strftime('%m月%d日')}有考试，"
                        f"前晚学习{total}分钟，建议不超过{EXAM_EVE_MAX}分钟以保证休息"
                    ),
                ))
        return conflicts

    # ---- 工具方法 ----

    def _group_by_date(self, events):
        groups = {}
        for e in events:
            key = e.start_time.date()
            groups.setdefault(key, []).append(e)
        return groups

    def _calc_overlap_minutes(self, a: CalendarEvent, b: CalendarEvent) -> int:
        latest_start = max(a.start_time, b.start_time)
        earliest_end = min(a.end_time, b.end_time)
        delta = (earliest_end - latest_start).total_seconds() / 60
        return max(0, int(delta))

    def _duration_min(self, e: CalendarEvent) -> int:
        return int((e.end_time - e.start_time).total_seconds() / 60)

    def _find_continuous_chains(self, events, max_gap=30):
        chains = []
        current = [events[0]]
        for e in events[1:]:
            gap = (e.start_time - current[-1].end_time).total_seconds() / 60
            if gap <= max_gap:
                current.append(e)
            else:
                chains.append(current)
                current = [e]
        chains.append(current)
        return chains
```

```python
class TimeSlotRecommender:
    """智能时间槽推荐器：在学生可用时间窗内找到最优学习时段"""

    # 评分权重配置
    WEIGHTS = {
        'time_preference': 25,   # 学生历史偏好时段
        'cognitive_fit':    25,  # 认知负荷与时段匹配
        'continuity':       20,  # 学习连续性(与近期任务衔接)
        'subject_balance':  15,  # 学科均衡(避免同科扎堆)
        'freshness':        15,  # 距上次同科学习时间
    }

    def recommend_slots(
        self,
        user_id: str,
        target_date: date,
        duration_min: int,
        subject: str,
        cognitive_load: int,
        preferences: StudentSchedulePreference,
        existing_events: list[CalendarEvent],
        user_behavior_profile: BehaviorProfile,
        max_results: int = 5,
    ) -> list[TimeSlot]:
        """
        生成时间槽推荐
        
        Args:
            target_date: 目标日期
            duration_min: 需要的时长(分钟)
            subject: 学科
            cognitive_load: 认知负荷1-5
            preferences: 学生作息偏好
            existing_events: 当日已有事件
            user_behavior_profile: 学生学习行为画像
            max_results: 最大返回数量
        """
        # Step 1: 计算可用时间窗
        available_windows = self._compute_available_windows(
            target_date, preferences, existing_events
        )

        # Step 2: 在每个窗口内生成候选时间槽
        candidates = []
        step = 15  # 15分钟步进
        for window in available_windows:
            window_duration = (window.end - window.start).total_seconds() / 60
            if window_duration < duration_min:
                continue
            # 滑动窗口生成候选
            offset = 0
            while offset + duration_min <= window_duration:
                slot_start = window.start + timedelta(minutes=offset)
                slot_end = slot_start + timedelta(minutes=duration_min)
                candidates.append(TimeSlot(
                    start_time=slot_start,
                    end_time=slot_end,
                    duration=duration_min,
                    available=True,
                ))
                offset += step

        # Step 3: 对每个候选评分
        scored = []
        for slot in candidates:
            factors = self._score_slot(
                slot, subject, cognitive_load, existing_events,
                user_behavior_profile, preferences, target_date
            )
            slot.score_factors = factors
            slot.score = sum(vars(factors).values())
            scored.append(slot)

        # Step 4: 非极大值抑制(NMS)去重相近时间段
        filtered = self._non_max_suppression(scored, min_gap=30)

        # Step 5: 排序并取Top-K
        filtered.sort(key=lambda s: s.score, reverse=True)
        top_k = filtered[:max_results]

        # 生成推荐理由
        for i, slot in enumerate(top_k):
            slot.rank = i + 1
            slot.reason = self._generate_reason(slot, subject, existing_events, user_behavior_profile)

        return top_k

    def _compute_available_windows(
        self,
        target_date: date,
        pref: StudentSchedulePreference,
        events: list[CalendarEvent],
    ) -> list[TimeWindow]:
        """计算当日可用时间窗(扣除: 睡眠、用餐、学校课程、固定事件)"""
        is_weekend = target_date.weekday() >= 5

        # 基础作息窗口
        wake = datetime.combine(target_date,
            pref.weekend_start_time if is_weekend else pref.weekday_start_time)
        sleep = datetime.combine(target_date,
            pref.weekend_end_time if is_weekend else pref.weekday_end_time)
        lunch_s = datetime.combine(target_date, pref.lunch_start)
        lunch_e = datetime.combine(target_date, pref.lunch_end)
        dinner_s = datetime.combine(target_date, pref.dinner_start)
        dinner_e = datetime.combine(target_date, pref.dinner_end)

        # 构建不可用时段列表
        blocked = [
            TimeWindow(wake, sleep + timedelta(days=1)),  # 先标记全部为不可用，然后挖洞
        ]
        # 实际方法：从wake到sleep之间，扣除blocked periods
        blocked_periods = [
            TimeWindow(lunch_s, lunch_e),
            TimeWindow(dinner_s, dinner_e),
        ]
        # 加入固定事件
        for e in events:
            if e.flexibility in ('FIXED', 'SEMI_FLEXIBLE') or e.event_type in (
                'SCHOOL_CLASS', 'EXAM', 'PARENTAL_LIMIT', 'REST_BREAK'
            ):
                blocked_periods.append(TimeWindow(e.start_time, e.end_time))

        # 从总窗口中减去blocked periods，得到available windows
        total_window = TimeWindow(wake, sleep)
        available = self._subtract_windows(total_window, blocked_periods)

        return available

    def _subtract_windows(
        self, main: TimeWindow, subtracts: list[TimeWindow]
    ) -> list[TimeWindow]:
        """从主窗口中减去多个子窗口"""
        result = [main]
        for sub in subtracts:
            new_result = []
            for r in result:
                if sub.end <= r.start or sub.start >= r.end:
                    new_result.append(r)  # 无交集
                else:
                    if sub.start > r.start:
                        new_result.append(TimeWindow(r.start, sub.start))
                    if sub.end < r.end:
                        new_result.append(TimeWindow(sub.end, r.end))
            result = new_result
        return [w for w in result if (w.end - w.start).total_seconds() / 60 >= 15]

    def _score_slot(
        self,
        slot: TimeSlot,
        subject: str,
        cognitive_load: int,
        events: list[CalendarEvent],
        profile: BehaviorProfile,
        pref: StudentSchedulePreference,
        target_date: date,
    ) -> ScoreFactors:
        """对单个时间槽评分"""
        # 1. 时间偏好分(0-25): 基于学生历史高效时段
        hour = slot.start_time.hour
        time_pref = self._get_time_preference_score(hour, profile)
        time_pref_score = int(time_pref * self.WEIGHTS['time_preference'])

        # 2. 认知适宜度(0-25): 高负荷任务安排在高效时段
        cog_score = self._get_cognitive_fit_score(hour, cognitive_load, profile)
        cognitive_fit_score = int(cog_score * self.WEIGHTS['cognitive_fit'])

        # 3. 连续性分(0-20): 与已有学习事件的衔接程度
        continuity = self._get_continuity_score(slot, events)
        continuity_score = int(continuity * self.WEIGHTS['continuity'])

        # 4. 学科均衡分(0-15): 当日该学科占比是否合理
        balance = self._get_subject_balance_score(slot, subject, events)
        subject_balance_score = int(balance * self.WEIGHTS['subject_balance'])

        # 5. 新鲜度分(0-15): 距上次同科学习的间隔
        freshness = self._get_freshness_score(slot, subject, events, target_date)
        freshness_score = int(freshness * self.WEIGHTS['freshness'])

        return ScoreFactors(
            time_preference_score=time_pref_score,
            cognitive_fit_score=cognitive_fit_score,
            continuity_score=continuity_score,
            subject_balance_score=subject_balance_score,
            freshness_score=freshness_score,
        )

    def _get_time_preference_score(self, hour: int, profile: BehaviorProfile) -> float:
        """根据学生行为画像获取时段偏好得分(归一化 0-1)"""
        # profile.hourly_performance: {hour: avg_performance_score}
        hourly_perf = profile.hourly_performance
        perf = hourly_perf.get(hour, 0.5)  # 默认中等
        return min(1.0, perf)

    def _get_cognitive_fit_score(
        self, hour: int, cognitive_load: int, profile: BehaviorProfile
    ) -> float:
        """认知负荷与时段匹配度"""
        # 学生高效时段适合高认知负荷
        peak_hours = profile.peak_hours  # e.g., [9, 10, 14, 15, 16, 19, 20]
        if cognitive_load >= 4:
            # 高负荷任务：只有在高效时段才高分
            return 1.0 if hour in peak_hours else 0.3
        elif cognitive_load >= 3:
            return 0.8 if hour in peak_hours else 0.6
        else:
            # 低负荷任务随时段影响小
            return 0.7

    def _get_continuity_score(self, slot: TimeSlot, events: list[CalendarEvent]) -> float:
        """与已有事件的连续性：紧接在学习事件后得分高"""
        best = 0.0
        for e in events:
            if e.event_type not in STUDY_EVENT_TYPES:
                continue
            gap_before = (slot.start_time - e.end_time).total_seconds() / 60
            gap_after = (e.start_time - slot.end_time).total_seconds() / 60

            if 0 <= gap_before <= 15:
                # 紧接在前一个学习事件后：好连续性
                best = max(best, 1.0)
            elif 0 <= gap_after <= 15:
                best = max(best, 0.9)
            elif -5 <= gap_before <= 30:
                best = max(best, 0.6)
        return best

    def _get_subject_balance_score(
        self, slot: TimeSlot, subject: str, events: list[CalendarEvent]
    ) -> float:
        """学科均衡：当日该学科学习时长占比"""
        subject_min = 0
        total_min = 0
        for e in events:
            if e.event_type in STUDY_EVENT_TYPES:
                dur = (e.end_time - e.start_time).total_seconds() / 60
                total_min += dur
                if e.subject == subject:
                    subject_min += dur

        if total_min == 0:
            return 1.0  # 当日还没有学习任务

        subject_ratio = subject_min / total_min
        # 理想比例：单科不超过40%
        if subject_ratio >= 0.4:
            return 0.3  # 已经很多了
        elif subject_ratio >= 0.25:
            return 0.6
        else:
            return 1.0

    def _get_freshness_score(
        self, slot: TimeSlot, subject: str, events: list[CalendarEvent], target_date: date
    ) -> float:
        """距上次同科学习的时间间隔(越久越需要复习)"""
        # 查找最近一次同学科事件
        last_same_subject = None
        for e in events:
            if e.subject == subject and e.end_time <= slot.start_time:
                if last_same_subject is None or e.end_time > last_same_subject:
                    last_same_subject = e.end_time

        if last_same_subject is None:
            return 1.0  # 很久没学了，优先安排

        hours_since = (slot.start_time - last_same_subject).total_seconds() / 3600
        if hours_since >= 24:
            return 1.0
        elif hours_since >= 6:
            return 0.8
        elif hours_since >= 2:
            return 0.5
        else:
            return 0.2  # 刚学过，不急

    def _non_max_suppression(
        self, slots: list[TimeSlot], min_gap: int = 30
    ) -> list[TimeSlot]:
        """非极大值抑制：合并时间相近、评分接近的候选槽"""
        slots.sort(key=lambda s: s.score, reverse=True)
        result = []
        for slot in slots:
            is_redundant = False
            for kept in result:
                gap = abs((slot.start_time - kept.start_time).total_seconds() / 60)
                if gap < min_gap:
                    is_redundant = True
                    break
            if not is_redundant:
                result.append(slot)
        return result

    def _generate_reason(
        self, slot: TimeSlot, subject: str,
        events: list[CalendarEvent], profile: BehaviorProfile
    ) -> str:
        """生成人类可读的推荐理由"""
        factors = slot.score_factors
        reasons = []

        if factors.time_preference_score >= 18:
            reasons.append("该时段为你的高效学习时间")
        if factors.cognitive_fit_score >= 18:
            reasons.append("精力状态适合当前任务难度")
        if factors.continuity_score >= 16:
            # 找到前一个事件
            for e in events:
                gap = (slot.start_time - e.end_time).total_seconds() / 60
                if 0 <= gap <= 15:
                    reasons.append(f"紧接「{e.title}」，保持学习节奏")
                    break
        if factors.subject_balance_score >= 12:
            reasons.append(f"当日{subject}学习时间合理")
        if factors.freshness_score >= 12:
            reasons.append(f"距上次{subject}学习已有较长时间，适合巩固")

        if not reasons:
            reasons.append("当前时段无冲突，可自由安排")

        return "；".join(reasons)
```

```python
class ScheduleRescheduler:
    """计划重排器：当新增紧急任务时，智能调整现有灵活任务的排期"""

    def reschedule(
        self,
        user_id: str,
        new_event: NewEventRequest,
        existing_events: list[CalendarEvent],
        preferences: StudentSchedulePreference,
        strategy: str = 'BALANCED',
    ) -> RescheduleResult:
        """
        重排策略:
        - MINIMAL_DISPLACE: 最小化位移总和
        - BALANCED: 综合考虑位移和优先级
        - PRIORITY_FIRST: 低优先级事件先让位
        """
        # Step 1: 将新事件插入最佳位置(尝试每个可用窗口)
        recommender = TimeSlotRecommender()
        detector = ConflictDetector()

        best_slot = None
        best_displacements = None
        best_cost = float('inf')

        # 获取可用窗口
        target_date = new_event.target_date
        windows = recommender._compute_available_windows(
            target_date, preferences, existing_events
        )

        for window in windows:
            window_min = (window.end - window.start).total_seconds() / 60
            if window_min < new_event.required_duration:
                continue

            slot_start = window.start
            while slot_start + timedelta(minutes=new_event.required_duration) <= window.end:
                slot_end = slot_start + timedelta(minutes=new_event.required_duration)
                temp_event = CalendarEvent(
                    event_id='temp',
                    user_id=user_id,
                    event_type=new_event.event_type,
                    title=new_event.title,
                    start_time=slot_start,
                    end_time=slot_end,
                    subject=new_event.subject,
                    cognitive_load=new_event.cognitive_load,
                    flexibility='FLEXIBLE',
                )

                # 找出与此时间槽冲突的灵活事件
                conflicts = []
                for e in existing_events:
                    if e.flexibility in ('FLEXIBLE', 'SUGGESTED'):
                        overlap = detector._calc_overlap_minutes(e, temp_event)
                        if overlap > 0:
                            conflicts.append((e, overlap))

                # 尝试将冲突事件移到其他位置
                displacements = []
                success = True
                for event, _ in conflicts:
                    alt_slot = self._find_alternative_slot(
                        event, existing_events + [temp_event],
                        preferences, exclude_range=(slot_start, slot_end)
                    )
                    if alt_slot:
                        displacements.append(Displacement(
                            event_id=event.event_id,
                            original_start=event.start_time,
                            original_end=event.end_time,
                            new_start=alt_slot.start_time,
                            new_end=alt_slot.end_time,
                            displacement_minutes=abs(
                                (alt_slot.start_time - event.start_time).total_seconds() / 60
                            ),
                        ))
                    else:
                        success = False
                        break

                if not success:
                    slot_start += timedelta(minutes=15)
                    continue

                # 计算重排成本
                cost = self._compute_reschedule_cost(
                    displacements, strategy
                )

                if cost < best_cost:
                    best_cost = cost
                    best_slot = (slot_start, slot_end)
                    best_displacements = displacements

                slot_start += timedelta(minutes=15)

        if best_slot is None:
            return RescheduleResult(
                success=False,
                reason="无法找到无冲突的重排方案，建议减少当日其他任务或缩短时长",
            )

        # 验证重排后无新冲突
        return RescheduleResult(
            success=True,
            new_event_slot=TimeSlot(
                start_time=best_slot[0],
                end_time=best_slot[1],
                duration=new_event.required_duration,
            ),
            displaced_events=best_displacements,
            conflicts_after_reschedule=[],  # 已验证
            summary=self._generate_summary(new_event, best_slot, best_displacements),
        )

    def _compute_reschedule_cost(self, displacements: list, strategy: str) -> float:
        """计算重排成本"""
        if strategy == 'MINIMAL_DISPLACE':
            return sum(d.displacement_minutes for d in displacements)
        elif strategy == 'BALANCED':
            # 位移 + 优先级权重
            return sum(
                d.displacement_minutes * (1 + 0.5 * priority_weight)
                for d, priority_weight in zip(
                    displacements,
                    [self._get_priority_weight(d) for d in displacements]
                )
            )
        elif strategy == 'PRIORITY_FIRST':
            return sum(
                d.displacement_minutes + priority_weight * 100
                for d, priority_weight in zip(
                    displacements,
                    [self._get_priority_weight(d) for d in displacements]
                )
            )

    def _get_priority_weight(self, displacement: Displacement) -> float:
        """优先级越高，位移代价越大"""
        return {'CRITICAL': 5, 'HIGH': 3, 'MEDIUM': 2, 'LOW': 1}.get(
            getattr(displacement, 'priority', 'MEDIUM'), 2
        )
```

```python
class ConflictDetectionFallback:
    """冲突检测降级策略"""

    async def detect_with_fallback(
        self, user_id: str, events: list, pref: StudentSchedulePreference
    ) -> list[Conflict]:
        try:
            # 完整检测
            return detector.detect_conflicts(user_id, events, pref)
        except Exception as e:
            logger.warning(f"Full conflict detection failed: {e}, falling back")
            try:
                # Level 1 降级：仅时间重叠 + 家长管控
                return self._basic_overlap_detection(events)
            except Exception:
                # Level 2 降级：跳过，返回空（让用户自行判断）
                logger.error("Even basic conflict detection failed")
                return []

    def _basic_overlap_detection(self, events: list) -> list[Conflict]:
        """仅检测时间重叠"""
        conflicts = []
        sorted_events = sorted(events, key=lambda e: e.start_time)
        for i in range(len(sorted_events) - 1):
            for j in range(i + 1, len(sorted_events)):
                overlap = detector._calc_overlap_minutes(
                    sorted_events[i], sorted_events[j]
                )
                if overlap > 0:
                    conflicts.append(Conflict(
                        conflict_type=ConflictType.TIME_OVERLAP,
                        severity='CRITICAL',
                        event_id_1=sorted_events[i].event_id,
                        event_id_2=sorted_events[j].event_id,
                        overlap_minutes=overlap,
                    ))
        return conflicts
```

```python
async def batch_detect(user_id: str, dates: list[date]) -> list[Conflict]:
    # 批量查询事件(一次查7天)
    all_events = await batch_get_events(user_id, min(dates), max(dates))

    # 按天分组后并行检测
    tasks = []
    for d in dates:
        day_events = [e for e in all_events if e.start_time.date() == d]
        tasks.append(asyncio.create_task(

    all_conflicts = []
    for r in results:
        if isinstance(r, Exception):
            logger.warning(f"Detection failed for one day: {r}")
            continue
        all_conflicts.extend(r)
    return all_conflicts
```

### 9.3 时间槽推荐剪枝

```python
def prune_candidates(candidates: list[TimeSlot], max_candidates: int = 20) -> list[TimeSlot]:
    """在评分前先剪枝，减少计算量"""
    # 1. 按粗略评分排序(仅时间偏好，不做详细评分)
    coarse_scored = [(c, coarse_score(c)) for c in candidates]
    coarse_scored.sort(key=lambda x: x[1], reverse=True)
    return [c for c, _ in coarse_scored[:max_candidates]]

def coarse_score(slot: TimeSlot) -> float:
    """粗略评分：仅基于时段(快)"""
    hour = slot.start_time.hour
    # 简单规则：下午16-20点得分高，上午9-11点次之
    if 16 <= hour <= 20:
        return 0.9
    elif 9 <= hour <= 11:
        return 0.8
    elif 14 <= hour <= 16:
        return 0.7
    elif 19 <= hour <= 21:
        return 0.6
    else:
        return 0.3
```

| 推荐评分 | 高效时段+高负荷 | score >= 80 |
| 重排-最小位移 | 紧急任务插入 | 位移最小的方案 |

### 14.2 术语表

| 术语 | 含义 |
| --- | --- |
| 冲突(Conflict) | 两个或多个日历事件之间的时间或逻辑上的不兼容 |
| 时间槽(Time Slot) | 一个连续的可用时间段，用于安排学习任务 |
| 认知负荷(Cognitive Load) | 学习任务对学生认知资源的消耗程度(1-5) |
| 灵活度(Flexibility) | 事件时间是否可以被调整的灵活程度 |
| 重排(Reschedule) | 当新事件插入时调整现有事件时间的过程 |
| NMS(非极大值抑制) | 去除评分相近的重叠候选，保留最优代表 |
