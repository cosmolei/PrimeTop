# 考点梳理模块 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

考点梳理模块面向初中和高中考试场景，围绕考试大纲、教材知识点和历年高频考点进行结构化梳理，帮助学生快速定位需要复习的内容，形成高效的备考路径。

### 1.2 覆盖学段

- 初中（7-9年级）：中考全科
- 高中（10-12年级）：高考全科

### 1.3 优先级

| 功能 | 优先级 | 版本 |
|------|--------|------|
| 考点清单浏览 | P1 | V1.5 |
| 高频考点标注 | P1 | V1.5 |
| 知识图谱可视化 | P2 | V1.5 |
| 专题突破训练 | P1 | V1.5 |
| 易错提醒 | P2 | V1.5 |
| 冲刺计划生成 | P2 | V1.5 |

### 1.4 依赖关系

- 依赖「同步课堂学习」模块的教材章节、知识点数据
- 依赖「学情分析」模块的掌握度数据
- 依赖「错题整理」模块的错因数据
- 依赖「AI智能辅导」模块的生成能力
- 依赖「学习规划」模块的计划框架

## 2. 核心概念与数据模型

### 2.1 概念定义

| 概念 | 定义 | 示例 |
|------|------|------|
| 考点(ExamPoint) | 考试中可能出题的最小知识单元 | "二次函数的顶点坐标公式" |
| 考点大纲(ExamSyllabus) | 按学科、学段组织的考点层级结构 | "初中数学 → 方程与不等式 → 一元二次方程" |
| 高频考点(HotExamPoint) | 近年考试中频繁出现的考点 | "过去3年中考出现率 > 60% 的考点" |
| 知识图谱(KnowledgeGraph) | 考点之间的前置/关联/并列关系 | "一次函数" → 前置 → "二元一次方程" |
| 专题(Topic) | 围绕某个知识领域聚合的考点群 | "函数综合专题" |
| 易错点(CommonMistake) | 特定考点的典型错误模式 | "忘记考虑判别式的符号" |

### 2.2 数据库表设计

#### 2.2.1 考点表 `exam_points`

```sql
CREATE TABLE exam_points (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    code            VARCHAR(64)  NOT NULL UNIQUE COMMENT '考点编码，如 MATH-JHS-EQ-001',
    name            VARCHAR(128) NOT NULL COMMENT '考点名称',
    description     TEXT         COMMENT '考点详细描述',
    subject_id      BIGINT       NOT NULL COMMENT '学科ID',
    stage           ENUM('junior_high', 'senior_high') NOT NULL COMMENT '学段',
    grade_range     VARCHAR(32)  COMMENT '适用年级范围，如 "7-9"',
    parent_id       BIGINT       DEFAULT NULL COMMENT '父级考点ID，支持层级',
    level           TINYINT      NOT NULL DEFAULT 1 COMMENT '层级深度，1=大类，2=中类，3=具体考点',
    sort_order      INT          NOT NULL DEFAULT 0 COMMENT '同级排序权重',
    exam_frequency  DECIMAL(5,2) DEFAULT NULL COMMENT '考试频率(0-100)，近N年出现率',
    difficulty_avg  DECIMAL(3,1) DEFAULT NULL COMMENT '平均难度(1-5)',
    knowledge_point_ids JSON     DEFAULT NULL COMMENT '关联的知识点ID列表',
    status          ENUM('draft', 'active', 'archived') NOT NULL DEFAULT 'draft',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_subject_stage (subject_id, stage),
    INDEX idx_parent (parent_id),
    INDEX idx_frequency (exam_frequency DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='考点表';
```

#### 2.2.2 考点关系表 `exam_point_relations`

```sql
CREATE TABLE exam_point_relations (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    source_point_id     BIGINT    NOT NULL COMMENT '源考点ID',
    target_point_id     BIGINT    NOT NULL COMMENT '目标考点ID',
    relation_type       ENUM('prerequisite', 'related', 'parallel', 'contains') NOT NULL
                        COMMENT '前置依赖/关联/并列/包含',
    strength            TINYINT   DEFAULT 1 COMMENT '关系强度 1-5',
    description         VARCHAR(512) COMMENT '关系描述',
    created_at          DATETIME  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uk_relation (source_point_id, target_point_id, relation_type),
    INDEX idx_target (target_point_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='考点关系表';
```

#### 2.2.3 高频考点快照表 `hot_exam_point_snapshots`

```sql
CREATE TABLE hot_exam_point_snapshots (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    subject_id      BIGINT       NOT NULL,
    stage           ENUM('junior_high', 'senior_high') NOT NULL,
    exam_type       ENUM('midterm', 'final', 'zhongkao', 'gaokao') NOT NULL COMMENT '考试类型',
    year_range      VARCHAR(16)  NOT NULL COMMENT '统计年份范围，如 "2023-2025"',
    exam_point_id   BIGINT       NOT NULL,
    frequency       DECIMAL(5,2) NOT NULL COMMENT '出现频率百分比',
    avg_score_ratio DECIMAL(5,2) COMMENT '平均得分率',
    question_types  JSON         COMMENT '常见题型列表 ["选择题","填空题","解答题"]',
    snapshot_date   DATE         NOT NULL,
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_subject_exam (subject_id, exam_type, snapshot_date DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='高频考点快照';
```

#### 2.2.4 易错点表 `common_mistakes`

```sql
CREATE TABLE common_mistakes (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    exam_point_id   BIGINT       NOT NULL COMMENT '考点ID',
    title           VARCHAR(256) NOT NULL COMMENT '易错点标题',

    mistake_pattern TEXT         NOT NULL COMMENT '典型错误模式',
    correct_approach TEXT        NOT NULL COMMENT '正确做法',
    example_question_id BIGINT   COMMENT '示例题目ID',
    subject_id      BIGINT       NOT NULL,
    stage           ENUM('junior_high', 'senior_high') NOT NULL,
    occurrence_rate DECIMAL(5,2) COMMENT '学生犯错频率百分比',
    sort_order      INT          DEFAULT 0,
    status          ENUM('draft', 'active', 'archived') NOT NULL DEFAULT 'draft',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_point (exam_point_id),
    INDEX idx_subject (subject_id, stage)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='易错点表';
```

#### 2.2.6 用户考点掌握记录 `user_exam_point_mastery`


### 2.3 核心数据结构（TypeScript）

```typescript
/** 考点 */
interface ExamPoint {
  id: number;
  code: string;
  name: string;
  description?: string;
  subjectId: number;
  stage: 'junior_high' | 'senior_high';
  gradeRange?: string;
  parentId?: number;
  level: number;
  sortOrder: number;
  examFrequency?: number;       // 0-100
  difficultyAvg?: number;       // 1-5
  knowledgePointIds?: number[];
  children?: ExamPoint[];       // 子级考点（树形展开用）
}

/** 考点关系 */
interface ExamPointRelation {
  id: number;
  sourcePointId: number;
  targetPointId: number;
  relationType: 'prerequisite' | 'related' | 'parallel' | 'contains';
  strength: number;             // 1-5
  description?: string;
}

/** 易错点 */
interface CommonMistake {
  id: number;
  examPointId: number;
  title: string;
  description: string;
  mistakePattern: string;
  correctApproach: string;
  exampleQuestionId?: number;
  occurrenceRate?: number;
}

/** 专题 */
interface ExamTopic {
  id: number;
  code: string;
  name: string;
  description?: string;
  subjectId: number;
  stage: 'junior_high' | 'senior_high';
  difficultyRange?: string;
  examPointIds: number[];
  coverImageUrl?: string;
}

/** 用户考点掌握度 */
interface UserExamPointMastery {
  id: number;
  userId: number;
  examPointId: number;
  masteryLevel: 'unknown' | 'weak' | 'basic' | 'proficient' | 'strong';
  correctCount: number;
  totalCount: number;
  lastPracticedAt?: string;
}

/** 知识图谱节点（可视化用） */
interface GraphNode {
  id: number;
  label: string;
  masteryLevel?: UserExamPointMastery['masteryLevel'];
  examFrequency?: number;
  isHot?: boolean;
}

/** 知识图谱边 */
interface GraphEdge {
  source: number;
  target: number;
  type: ExamPointRelation['relationType'];
  strength: number;
}

/** 知识图谱数据 */
interface KnowledgeGraphData {
  nodes: GraphNode[];
  edges: GraphEdge[];
}
```

## 4. 关键业务流程

### 4.1 考点浏览与学习流程

```
用户选择学科+学段
       │
       ▼
  加载考点树 ──────────────────────┐
       │                           │
       ▼                           │
  展示分层考点清单                  │
  (标注高频/掌握度/易错)            │
       │                           │
       ├── 点击具体考点             │
       │       │                   │
       │       ▼                   │
       │  考点详情页                │
       │  - 描述/关联知识点          │
       │  - 高频考情统计            │
       │  - 易错点提示              │
       │  - AI讲解入口              │
       │  - 专项练习入口            │
       │       │                   │
       │       ├── AI讲解 ──→ 流式返回讲解内容
       │       ├── 开始练习 ──→ 加载关联题目
       │       └── 查看图谱 ──→ 知识图谱可视化
       │                           │
       └── 知识图谱视图 ────────────┘
              节点可点击进入考点详情
```

### 4.2 专题突破训练流程

```
选择专题
    │
    ▼
展示专题包含的考点列表
(标注每个考点的掌握度和是否高频)
    │
    ▼
系统生成训练建议：
  - 已掌握的考点 → 跳过或轻度巩固
  - 薄弱的考点 → 重点训练
  - 未练习的考点 → 从基础开始
    │
    ▼
进入训练模式
    │
    ├── 逐题作答（题目关联考点标签）
    │       │
    │       ▼
    │   提交答案 → 判分 → 更新考点掌握度
    │       │
    │       ▼
    │   展示解析（标注涉及的考点和易错点）
    │       │
    │       ▼
    │   下一题 / 退出
    │
    └── 完成训练 → 生成专题训练报告
            │
            ▼
        展示：正确率、耗时、薄弱考点、
              推荐下一步行动
```

### 4.3 冲刺计划生成流程

```
用户输入：目标考试类型、考试日期、每日可用时间
       │
       ▼
系统收集数据：
```

### 4.4 掌握度更新流程

```typescript
/**
 * 掌握度更新：在答题、练习、AI诊断后触发
 */
async function updateMastery(params: {
  userId: number;
  examPointId: number;
  isCorrect: boolean;
  source: 'practice' | 'exam' | 'ai_diagnosis' | 'self_eval';
}): Promise<void> {
  const { userId, examPointId, isCorrect, source } = params;

  // 1. 获取或创建掌握记录
  let mastery = await db.userExamPointMastery.findUnique({
    where: { userId_examPointId: { userId, examPointId } }
  });

  if (!mastery) {
    mastery = await db.userExamPointMastery.create({
      data: { userId, examPointId, masteryLevel: 'unknown', source }
    });
  }

  // 2. 更新计数
  const newTotal = mastery.totalCount + 1;
  const newCorrect = mastery.correctCount + (isCorrect ? 1 : 0);
  const accuracy = newCorrect / newTotal;

  // 3. 计算新掌握等级
  const newLevel = calculateMasteryLevel({
    accuracy,
    totalCount: newTotal,
    currentLevel: mastery.masteryLevel
  });

  // 4. 写入
  await db.userExamPointMastery.update({
    where: { id: mastery.id },
    data: {
      correctCount: newCorrect,
      totalCount: newTotal,
      masteryLevel: newLevel,
      lastPracticedAt: new Date(),
      source
    }
  });
}

/**
 * 掌握等级判定算法
 */
function calculateMasteryLevel(params: {
  accuracy: number;
  totalCount: number;
  currentLevel: string;
}): string {
  const { accuracy, totalCount, currentLevel } = params;

  // 需要至少3次作答才能稳定判定
  if (totalCount < 3) {
    if (accuracy >= 0.8) return 'basic';
    if (accuracy < 0.4) return 'weak';
    return 'unknown';
  }

  // 基于正确率分级
  if (accuracy >= 0.85) return 'strong';
  if (accuracy >= 0.65) return 'proficient';
  if (accuracy >= 0.45) return 'basic';
  return 'weak';
}
```

## 6. 冲刺计划生成算法

### 6.1 核心算法

```typescript
interface SprintPlanInput {
  userId: number;
  subjectId: number;
  stage: 'junior_high' | 'senior_high';
  examType: 'zhongkao' | 'gaokao' | 'midterm' | 'final';
  examDate: string;            // ISO date
  dailyMinutes: number;        // 每日可用分钟
  focusWeakPoints: boolean;
}

interface SprintPlan {
  planId: string;
  totalDays: number;
  phases: SprintPhase[];
}

interface SprintPhase {
  name: string;
  dayRange: [number, number];
  tasks: SprintTask[];
}

interface SprintTask {
  day: number;
  examPointIds: number[];
  taskType: 'review' | 'practice' | 'intensive_practice' | 'mock_exam';
  estimatedMinutes: number;
  description: string;
}

/**
 * 冲刺计划生成主流程
 */
async function generateSprintPlan(input: SprintPlanInput): Promise<SprintPlan> {
  const { examDate, dailyMinutes } = input;
  const today = new Date();
  const exam = new Date(examDate);
  const totalDays = Math.max(1, Math.ceil((exam.getTime() - today.getTime()) / 86400000));

  // 1. 获取考点数据
  const allPoints = await getExamPointsWithMastery(input.userId, input.subjectId, input.stage);
  const hotSnapshots = await getHotSnapshots(input.subjectId, input.stage, input.examType);

  // 2. 考点评分排序（决定复习优先级）
  const scoredPoints = allPoints.map(point => {
    const masteryScore = masteryToScore(point.masteryLevel);  // strong=0, unknown=50, weak=100
    const frequencyScore = point.examFrequency || 50;
    const composite = masteryScore * 0.6 + frequencyScore * 0.4;  // 薄弱+高频 = 最高优先
    return { ...point, priorityScore: composite };
  }).sort((a, b) => b.priorityScore - a.priorityScore);

  // 3. 划分阶段
  const phase1End = Math.ceil(totalDays * 0.25);   // 高频速览
  const phase2End = Math.ceil(totalDays * 0.75);   // 薄弱突破
  // phase3: day (phase2End+1) ~ totalDays           // 模拟查漏

  // 4. 分配每日任务
  const phases: SprintPhase[] = [];

  // Phase 1: 高频考点速览
  const hotPoints = scoredPoints.filter(p => (p.examFrequency || 0) >= 60);
  phases.push({
    name: '高频考点速览',
    dayRange: [1, phase1End],
    tasks: distributeTasks(hotPoints, 1, phase1End, dailyMinutes, 'review')
  });

  // Phase 2: 薄弱点突破
  const weakPoints = input.focusWeakPoints
    ? scoredPoints.filter(p => ['weak', 'basic', 'unknown'].includes(p.masteryLevel || 'unknown'))
    : scoredPoints;
  phases.push({
    name: '薄弱点突破',
    dayRange: [phase1End + 1, phase2End],
    tasks: distributeTasks(weakPoints, phase1End + 1, phase2End, dailyMinutes, 'intensive_practice')
  });

  // Phase 3: 模拟与查漏
  const mockDays = totalDays - phase2End;
  phases.push({
    name: '模拟与查漏',
    dayRange: [phase2End + 1, totalDays],
    tasks: generateMockTasks(phase2End + 1, totalDays, Math.min(mockDays, 3))
  });

  return {
    planId: `sprint-${input.userId}-${Date.now()}`,
    totalDays,
    phases
  };
}

/** 掌握度 → 优先级分值（越高越优先复习） */
function masteryToScore(level?: string): number {
  const map: Record<string, number> = {
    unknown: 50, weak: 100, basic: 60, proficient: 30, strong: 0
  };
  return map[level || 'unknown'] ?? 50;
}

/** 将考点分配到每日任务中 */
function distributeTasks(
  points: any[],
  startDay: number,
  endDay: number,
  dailyMinutes: number,
  taskType: SprintTask['taskType']
): SprintTask[] {
  const tasks: SprintTask[] = [];
  const totalDays = endDay - startDay + 1;
  const pointsPerDay = Math.max(1, Math.ceil(points.length / totalDays));

  for (let day = startDay; day <= endDay; day++) {
    const offset = day - startDay;
    const slice = points.slice(offset * pointsPerDay, (offset + 1) * pointsPerDay);
    if (slice.length === 0) break;

    tasks.push({
      day,
      examPointIds: slice.map(p => p.id),
      taskType,
      estimatedMinutes: dailyMinutes,
      description: `${taskType === 'review' ? '复习' : '强化训练'}${slice.length}个考点`
    });
  }
  return tasks;
}
```

### 10.3 前端错误处理模式

```typescript
/**
 * 通用错误处理装饰器
 */
function withErrorHandler<T extends (...args: any[]) => Promise<any>>(
  fn: T,
  errorConfig: {
    errorCode: string;
    fallback?: () => void;
    toast?: string;
  }
): T {
  return (async (...args: any[]) => {
    try {
      return await fn(...args);
    } catch (error: any) {
      const code = error?.response?.data?.code;

      switch (code) {
        case 'EXAM_POINT_006':
          // AI服务不可用 - 静默降级
          errorConfig.fallback?.();
          break;
        case 'EXAM_POINT_008':
          // 图谱异常 - 降级为列表
          errorConfig.fallback?.();
          showToast('图谱加载失败，已切换为列表视图');
          break;
        default:
          showToast(errorConfig.toast || '操作失败，请稍后重试');
      }
    }
  }) as T;
}
```

| 考点树 | Redis + 客户端本地 | 24h | 结构稳定，变更少 |
| 高频考点快照 | Redis | 7d | 季度更新 |
| 知识图谱数据 | Redis | 1h | 按学科+学段缓存 |
| 用户掌握度 | 客户端内存 | 15min | 实时性要求不高 |
| AI讲解内容 | 对象存储 | 永久 | 相同考点可复用 |
| 专题训练报告 | Redis + DB | 30d | 用户可回看 |

### 11.2 关键性能指标

## 12. 数据初始化与运维

### 12.1 考点数据录入

考点数据由内容教研团队通过管理后台录入，流程：

```
教研团队准备Excel/JSON数据
       │
       ▼
管理后台批量导入
       │
       ▼
系统自动：
  - 生成考点编码
  - 校验层级关系
  - 建立知识点关联
  - 计算排序权重
       │
       ▼
审核 → 发布
```

### 12.2 考点编码规则

```
{学科}_{学段}_{大类}_{序号}

示例：
MATH_JHS_FUNC_001    初中数学-函数-001
PHYS_SHS_MECH_015    高中物理-力学-015
CHEM_JHS_EQUATION_003 初中化学-方程式-003

学科代码：MATH, CHIN, ENG, PHYS, CHEM, BIO, HIST, GEO, POLI
学段代码：JHS(junior high), SHS(senior high)
```

### 12.3 高频考点更新

- 每季度由教研团队根据最新考试真题更新频率数据
- 系统自动从题库和用户答题数据中统计出现频率
- AI辅助分析考情趋势，生成更新建议
