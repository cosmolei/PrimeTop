# 服务端 - 用户账号合并与多账号数据迁移服务 详细设计

## 1. 模块概述

### 1.1 背景

在实际使用中，学生可能因以下原因创建了多个账号：

1. 先用手机号注册，后来又用微信/Apple 第三方登录创建了新账号。
2. 换号后用新手机号重新注册，旧账号仍存在学习数据。
3. 家长和孩子各自注册了账号，后续需要合并为学生账号+家长绑定关系。
4. 寒暑假不同设备上分别注册。

这些场景导致同一用户拥有多个账号，数据分散，影响学习画像完整性和用户体验。需要提供一套安全的账号合并与数据迁移机制。

### 1.2 目标

- 提供用户可自助发起的账号合并流程。
- 将源账号（被合并账号）的学习记录、错题、笔记、会员权益等安全迁移至目标账号（保留账号）。
- 保证数据一致性，不丢失、不重复。
- 合并完成后安全停用源账号。
- 提供管理后台合并工具（客服/运营协助场景）。

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 用户安全 | 合并操作需双重验证，防止恶意合并他人账号 |
| 数据不丢 | 所有迁移操作幂等可重试，失败可回滚 |
| 权益取优 | 会员有效期取最长，额度取之和（不超上限） |
| 审计完整 | 每一步操作记录审计日志，可追溯 |
| 限频控制 | 同一账号 30 天内最多合并 1 次 |

### 3.2 发起合并申请（用户自助）

#### 前置检查

```java
public class MergeEligibilityChecker {
    
    /**
     * 检查是否允许发起合并
     */
    public MergeEligibilityResult check(Long targetUserId, Long sourceUserId) {
        // 1. 两账号不能相同
        if (targetUserId.equals(sourceUserId)) {
            return MergeEligibilityResult.fail("不能合并同一个账号");
        }
        
        // 2. 目标账号状态正常
        User target = userRepository.findById(targetUserId);
        if (target.getStatus() != UserStatus.ACTIVE) {
            return MergeEligibilityResult.fail("目标账号状态异常");
        }
        
        // 3. 源账号未被合并过
        User source = userRepository.findById(sourceUserId);
        if (source.getMergedInto() != null) {
            return MergeEligibilityResult.fail("该账号已被合并，无法重复操作");
        }
        
        // 4. 目标账号30天内未被合并过（限频）
        if (target.getLastMergeAt() != null 
            && target.getLastMergeAt().isAfter(Instant.now().minus(30, ChronoUnit.DAYS))) {
            return MergeEligibilityResult.fail("30天内仅可执行一次账号合并");
        }
        
        // 5. 不存在进行中的合并申请
        Optional<AccountMergeRequest> existing = mergeRequestRepository
            .findActiveByUserIds(targetUserId, sourceUserId);
        if (existing.isPresent()) {
            return MergeEligibilityResult.fail("已存在进行中的合并申请: " + existing.get().getRequestNo());
        }
        
        // 6. 两账号至少有一个是学生身份
        if (target.getUserType() != UserType.STUDENT && source.getUserType() != UserType.STUDENT) {
            return MergeEligibilityResult.fail("合并操作至少需要一个学生账号");
        }
        
        return MergeEligibilityResult.ok();
    }
}
```

### 3.3 源账号身份验证

源账号验证是安全核心——必须证明对被合并账号拥有所有权。

#### 验证方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| SMS | 向源账号绑定手机发送验证码 | 源账号有绑定手机 |
| PASSWORD | 输入源账号密码 | 源账号设置了密码 |
| THIRD_PARTY | 通过第三方平台授权验证 | 源账号绑定了微信/Apple |

```java
public class SourceAccountVerifier {

    /**
     * 发送源账号验证令牌
     */
    public void sendVerification(AccountMergeRequest request, VerifyMethod method) {
        String token = TokenGenerator.generateNumeric(6); // 6位验证码
        Instant expiresAt = Instant.now().plus(10, ChronoUnit.MINUTES);
        
        request.setSourceVerifyMethod(method.name());
        request.setSourceVerifyToken(passwordEncoder.encode(token));
        request.setSourceVerifyExpires(expiresAt);
        mergeRequestRepository.save(request);
        
        switch (method) {
            case SMS:
                smsService.send(sourceUser.getPhone(), 
                    "【启硕】您的账号合并验证码为：" + token + "，10分钟内有效。");
                break;
            case PASSWORD:
                // 密码验证不需要发送令牌，直接比较
                break;
            case THIRD_PARTY:
                // 生成第三方授权链接
                String authUrl = oauthService.generateAuthUrl(
                    request.getSourceUserId(), 
                    "account_merge:" + request.getRequestNo()
                );
                notificationService.notify(request.getTargetUserId(), 
                    "请使用源账号的第三方平台完成授权: " + authUrl);
                break;
        }
    }
    
    /**
     * 验证源账号令牌
     */
    public boolean verify(AccountMergeRequest request, String userInput) {
        // 检查是否过期
        if (Instant.now().isAfter(request.getSourceVerifyExpires())) {
            throw new BizException(ErrorCode.MERGE_TOKEN_EXPIRED);
        }
        
        boolean matched = passwordEncoder.matches(userInput, request.getSourceVerifyToken());
        if (!matched) {
            // 记录失败次数，5次失败锁定
            int failCount = redisTemplate.opsForValue().increment(
                "merge:verify:fail:" + request.getId());
            if (failCount >= 5) {
                request.setStatus(MergeStatus.CANCELLED);
                mergeRequestRepository.save(request);
                throw new BizException(ErrorCode.MERGE_VERIFICATION_LOCKED);
            }
            return false;
        }
        
        request.setSourceVerifiedAt(Instant.now());
        request.setStatus(MergeStatus.SOURCE_VERIFIED);
        mergeRequestRepository.save(request);
        
        // 清除失败计数
        redisTemplate.delete("merge:verify:fail:" + request.getId());
        return true;
    }
}
```

### 3.4 目标账号确认

源账号验证通过后，需要目标账号用户确认同意合并（防止单方面操作）。

```java
public void confirmByTarget(AccountMergeRequest request, Long targetUserId) {
    // 验证操作者是目标账号本人
    if (!request.getTargetUserId().equals(targetUserId)) {
        throw new BizException(ErrorCode.PERMISSION_DENIED);
    }
    
    // 生成确认令牌（如果还没生成）
    if (request.getTargetConfirmToken() == null) {
        String token = TokenGenerator.generateNumeric(6);
        request.setTargetConfirmToken(passwordEncoder.encode(token));
        request.setTargetConfirmExpires(Instant.now().plus(10, ChronoUnit.MINUTES));
        mergeRequestRepository.save(request);
        
        // 发送确认验证码到目标账号
        smsService.send(targetUser.getPhone(),
            "【启硕】确认将源账号合并至当前账号，验证码：" + token + "，10分钟内有效。");
        return;
    }
    
    // 验证确认码
    if (!passwordEncoder.matches(userInput, request.getTargetConfirmToken())) {
        throw new BizException(ErrorCode.MERGE_CONFIRM_CODE_INVALID);
    }
    
    if (Instant.now().isAfter(request.getTargetConfirmExpires())) {
        throw new BizException(ErrorCode.MERGE_TOKEN_EXPIRED);
    }
    
    request.setTargetConfirmedAt(Instant.now());
    request.setStatus(MergeStatus.TARGET_CONFIRMED);
    
    // 生成迁移计划
    MigrationPlan plan = migrationPlanner.generatePlan(request);
    request.setMigrationPlan(plan.toJson());
    mergeRequestRepository.save(request);
}
```

### 3.5 迁移计划生成

在确认合并后，系统自动分析两个账号的数据情况，生成迁移计划。

```java
public class MigrationPlanner {
    
    public MigrationPlan generatePlan(AccountMergeRequest request) {
        Long targetId = request.getTargetUserId();
        Long sourceId = request.getSourceUserId();
        
        MigrationPlan plan = new MigrationPlan();
        
        // 学生档案：取学段更高的账号为主，或取目标账号
        StudentProfile targetProfile = profileService.get(targetId);
        StudentProfile sourceProfile = profileService.get(sourceId);
        plan.setStudentProfileStrategy(resolveProfileStrategy(targetProfile, sourceProfile));
        
        // 学习记录：合并，取进度更前的
        plan.setLearningRecordStrategy(merge LearningRecord.KEEP_FURTHEST);
        
        // 错题本：全部合并，自动去重
        int mistakeCount = mistakeRepository.countByUserId(sourceId);
        plan.addModule(MergeModule.MISTAKE_BOOK, mistakeCount, ConflictStrategy.MERGE_DEDUP);
        
        // 答题记录：全部迁移，追加标注来源
        int answerCount = answerRecordRepository.countByUserId(sourceId);
        plan.addModule(MergeModule.ANSWER_RECORD, answerCount, ConflictStrategy.APPEND);
        
        // AI对话记录：全部迁移
        int convCount = conversationRepository.countByUserId(sourceId);
        plan.addModule(MergeModule.AI_CONVERSATION, convCount, ConflictStrategy.APPEND);
        
        // 笔记收藏：合并去重
        int noteCount = noteRepository.countByUserId(sourceId);
        plan.addModule(MergeModule.NOTES_COLLECTION, noteCount, ConflictStrategy.MERGE_DEDUP);
        
        // 学习计划：仅迁移未完成的，已完成的跳过
        int planCount = studyPlanRepository.countPendingByUserId(sourceId);
        plan.addModule(MergeModule.STUDY_PLAN, planCount, ConflictStrategy.KEEP_PENDING);
        
        // 考试记录：全部迁移
        int examCount = examRecordRepository.countByUserId(sourceId);
        plan.addModule(MergeModule.EXAM_RECORD, examCount, ConflictStrategy.APPEND);
        
        // 会员权益：取最优
        Membership targetMem = membershipService.get(targetId);
        Membership sourceMem = membershipService.get(sourceId);
        plan.setMembershipStrategy(resolveMembershipStrategy(targetMem, sourceMem));
        
        // 订单：仅迁移历史记录引用（不改归属用于审计）
        int orderCount = orderRepository.countByUserId(sourceId);
        plan.addModule(MergeModule.ORDER, orderCount, ConflictStrategy.REFERENCE_ONLY);
        
        // 积分：累加（有上限）
        long sourcePoints = pointsService.getBalance(sourceId);
        long targetPoints = pointsService.getBalance(targetId);
        long maxMerge = PointsConfig.MAX_MERGE_POINTS; // 如5000
        plan.setPointsStrategy(Math.min(sourcePoints, maxMerge - targetPoints));
        
        // 成就勋章：合并取并集
        int achievementCount = achievementRepository.countByUserId(sourceId);
        plan.addModule(MergeModule.POINTS, achievementCount, ConflictStrategy.MERGE_UNION);
        
        // 社交关系：合并好友列表，处理班级归属
        plan.setSocialStrategy(ConflictStrategy.MERGE_DEDUP);
        
        // 家长绑定：迁移绑定关系
        plan.setParentBindingStrategy(ConflictStrategy.TRANSFER);
        
        return plan;
    }
    
    private MembershipStrategy resolveMembershipStrategy(Membership target, Membership source) {
        if (source == null || source.getPlanType() == PlanType.FREE) {
            return MembershipStrategy.keep(target);
        }
        if (target == null || target.getPlanType() == PlanType.FREE) {
            return MembershipStrategy.transfer(source);
        }
        // 都是付费会员：取等级更高的为主，延长有效期至两者中最晚的
        PlanType higherPlan = target.getPlanType().getLevel() >= source.getPlanType().getLevel()
            ? target.getPlanType() : source.getPlanType();
        Instant laterExpiry = target.getExpireAt().isAfter(source.getExpireAt())
            ? target.getExpireAt() : source.getExpireAt();
        return MembershipStrategy.merge(higherPlan, laterExpiry, target, source);
    }
}
```

### 4.2 迁移编排器

```java
public class MergeOrchestrator {
    
    private final List<ModuleMigrator> migrators;
    private final MergeProgressTracker progressTracker;
    private final MergeAuditLogger auditLogger;
    
    /**
     * 执行合并迁移
     * 各模块按 order 顺序执行，同一模块内分批处理
     */
    @Transactional(propagation = Propagation.NEVER) // 不使用大事务，按模块分批提交
    public void executeMerge(AccountMergeRequest request) {
        Long targetId = request.getTargetUserId();
        Long sourceId = request.getSourceUserId();
        
        request.setStatus(MergeStatus.MIGRATING);
        request.setStartedAt(Instant.now());
        mergeRequestRepository.save(request);
        
        auditLogger.log(request.getId(), "MERGE_START", 
            "开始合并: source=" + sourceId + " → target=" + targetId);
        
        try {
            // 按顺序执行各模块迁移
            List<ModuleMigrator> ordered = migrators.stream()
                .sorted(Comparator.comparingInt(ModuleMigrator::getOrder))
                .collect(Collectors.toList());
            
            for (ModuleMigrator migrator : ordered) {
                ModuleMigrationResult result = migrateModule(request, migrator);
                
                if (result.getStatus() == ModuleMigrationStatus.FAILED 
                    && migrator.isRequired()) {
                    throw new MergeMigrationException(
                        migrator.getModule(), result.getErrorMessage());
                }
                
                progressTracker.markModuleDone(request.getId(), migrator.getModule(), result);
            }
            
            // 所有模块迁移完成 → 停用源账号
            deactivateSourceAccount(request);
            
            // 记录合并完成
            request.setStatus(MergeStatus.COMPLETED);
            request.setCompletedAt(Instant.now());
            mergeRequestRepository.save(request);
            
            // 保存合并记录（支持回滚）
            saveMergeRecord(request);
            
            auditLogger.log(request.getId(), "MERGE_COMPLETE", "合并完成");
            
        } catch (MergeMigrationException e) {
            handleMigrationFailure(request, e);
        }
    }
    
    private ModuleMigrationResult migrateModule(
            AccountMergeRequest request, ModuleMigrator migrator) {
        
        MergeModule module = migrator.getModule();
        Long targetId = request.getTargetUserId();
        Long sourceId = request.getSourceUserId();
        
        // 创建模块迁移日志
        AccountMergeLog log = new AccountMergeLog();
        log.setRequestId(request.getId());
        log.setStepName(module.name());
        log.setStepStatus("IN_PROGRESS");
        log.setRecordsTotal(migrator.countRecords(sourceId));
        log.setStartedAt(Instant.now());
        mergeLogRepository.save(log);
        
        try {
            ModuleMigrationResult result = migrator.migrate(sourceId, targetId, request);
            
            log.setStepStatus(result.getStatus().name());
            log.setRecordsMigrated(result.getMigratedCount());
            log.setRecordsSkipped(result.getSkippedCount());
            log.setDetail(result.getDetail());
            log.setFinishedAt(Instant.now());
            mergeLogRepository.save(log);
            
            return result;
            
        } catch (Exception e) {
            log.setStepStatus("FAILED");
            log.setErrorMessage(e.getMessage());
            log.setFinishedAt(Instant.now());
            mergeLogRepository.save(log);
            throw e;
        }
    }
}
```

### 4.3 分批迁移框架

```java
public abstract class BatchModuleMigrator implements ModuleMigrator {
    
    private static final int BATCH_SIZE = 200;
    
    @Override
    public ModuleMigrationResult migrate(Long sourceId, Long targetId, 
                                          AccountMergeRequest request) {
        int total = countRecords(sourceId);
        int migrated = 0;
        int skipped = 0;
        List<ConflictRecord> conflicts = new ArrayList<>();
        
        Long cursor = 0L;
        while (true) {
            // 分批读取源账号数据
            List<?> batch = fetchBatch(sourceId, cursor, BATCH_SIZE);
            if (batch.isEmpty()) break;
            
            // 更新游标
            cursor = getNextCursor(batch);
            
            int batchMigrated = 0;
            int batchSkipped = 0;
            
            for (Object record : batch) {
                ConflictResolution resolution = resolveConflict(record, targetId);
                
                switch (resolution.getAction()) {
                    case MIGRATE:
                        doMigrate(record, sourceId, targetId);
                        batchMigrated++;
                        break;
                    case SKIP:
                        batchSkipped++;
                        conflicts.add(resolution.getConflictRecord());
                        break;
                    case OVERWRITE:
                        doOverwrite(record, sourceId, targetId);
                        batchMigrated++;
                        break;
                }
            }
            
            migrated += batchMigrated;
            skipped += batchSkipped;
            
            // 更新进度
            progressTracker.updateProgress(
                request.getId(), getModule().name(), 
                migrated + skipped, total);
            
            // 每批次提交事务
            // 已在 doMigrate/doOverwrite 内部处理事务
        }
        
        return ModuleMigrationResult.builder()
            .status(ModuleMigrationStatus.SUCCESS)
            .migratedCount(migrated)
            .skippedCount(skipped)
            .detail(Map.of("conflicts", conflicts))
            .build();
    }
    
    /**
     * 子类实现：批量读取
     */
    protected abstract List<?> fetchBatch(Long sourceId, Long cursor, int size);
    
    /**
     * 子类实现：冲突检测与解决
     */
    protected abstract ConflictResolution resolveConflict(Object record, Long targetId);
    
    /**
     * 子类实现：执行单条迁移
     */
    protected abstract void doMigrate(Object record, Long sourceId, Long targetId);
}
```

```java
@Component
@MergeModule(MergeModule.MEMBERSHIP)
public class MembershipMigrator implements ModuleMigrator {
    
    @Override
    @Transactional
    public ModuleMigrationResult migrate(Long sourceId, Long targetId, 
                                          AccountMergeRequest request) {
        Membership targetMem = membershipRepository.findByUserId(targetId);
        Membership sourceMem = membershipRepository.findByUserId(sourceId);
        
        if (sourceMem == null || sourceMem.getPlanType() == PlanType.FREE) {
            return ModuleMigrationResult.skipped("源账号无付费会员");
        }
        
        MembershipSnapshot sourceSnapshot = MembershipSnapshot.from(sourceMem);
        
        if (targetMem == null || targetMem.getPlanType() == PlanType.FREE) {
            // 直接转移
            sourceMem.setUserId(targetId);
            membershipRepository.save(sourceMem);
            
            // 记录原target的free会员
            if (targetMem != null) {
                targetMem.setStatus(MembershipStatus.REPLACED);
                membershipRepository.save(targetMem);
            }
            
            return ModuleMigrationResult.success(1, 0, 
                Map.of("action", "TRANSFER", "snapshot", sourceSnapshot));
        }
        
        // 都是付费：取等级高的，有效期取最晚的
        PlanType finalPlan = targetMem.getPlanType().getLevel() >= sourceMem.getPlanType().getLevel()
            ? targetMem.getPlanType() : sourceMem.getPlanType();
        
        Instant finalExpiry = targetMem.getExpireAt().isAfter(sourceMem.getExpireAt())
            ? targetMem.getExpireAt() : sourceMem.getExpireAt();
        
        // 计算需要补偿的天数（如果源账号等级更高且有剩余天数）
        int补偿Days = 0;
        if (sourceMem.getPlanType().getLevel() > targetMem.getPlanType().getLevel()) {
            // 源账号等级更高，按目标账号剩余天数计算补偿
            long targetRemainDays = ChronoUnit.DAYS.between(Instant.now(), targetMem.getExpireAt());
            long sourceRemainDays = ChronoUnit.DAYS.between(Instant.now(), sourceMem.getExpireAt());
            补偿Days = (int) Math.min(sourceRemainDays, 365); // 最多补偿1年
        }
        
        targetMem.setPlanType(finalPlan);
        targetMem.setExpireAt(finalExpiry);
        targetMem.setDailyAiLimit(Math.max(
            targetMem.getDailyAiLimit(), 
            sourceMem.getDailyAiLimit()));
        targetMem.setDailyPhotoLimit(Math.max(
            targetMem.getDailyPhotoLimit(),
            sourceMem.getDailyPhotoLimit()));
        membershipRepository.save(targetMem);
        
        // 停用源账号会员
        sourceMem.setStatus(MembershipStatus.MERGED);
        sourceMem.setMergedInto(targetId);
        membershipRepository.save(sourceMem);
        
        // 通知用户权益变更
        notificationService.notify(targetId, NotificationType.MEMBERSHIP_MERGED,
            Map.of("finalPlan", finalPlan, "finalExpiry", finalExpiry, 
                   "补偿Days", 补偿Days));
        
        return ModuleMigrationResult.success(1, 0,
            Map.of("action", "MERGE", "finalPlan", finalPlan,
                   "finalExpiry", finalExpiry, "sourceSnapshot", sourceSnapshot));
    }
}
```

```java
@Component
@MergeModule(MergeModule.POINTS)
public class PointsMigrator implements ModuleMigrator {
    
    @Override
    @Transactional
    public ModuleMigrationResult migrate(Long sourceId, Long targetId,
                                          AccountMergeRequest request) {
        long sourceBalance = pointsService.getBalance(sourceId);
        
        if (sourceBalance <= 0) {
            return ModuleMigrationResult.skipped("源账号无积分");
        }
        
        long targetBalance = pointsService.getBalance(targetId);
        long maxAfterMerge = PointsConfig.MAX_POINTS_BALANCE; // 如 50000
        long transferable = Math.min(sourceBalance, maxAfterMerge - targetBalance);
        
        if (transferable <= 0) {
            return ModuleMigrationResult.skipped("目标账号积分已达上限");
        }
        
        // 执行积分转账
        pointsService.transfer(sourceId, targetId, transferable, "ACCOUNT_MERGE");
        
        // 迁移成就勋章（取并集）
        List<Badge> sourceBadges = badgeRepository.findByUserId(sourceId);
        List<Badge> targetBadges = badgeRepository.findByUserId(targetId);
        Set<String> targetBadgeCodes = targetBadges.stream()
            .map(Badge::getBadgeCode)
            .collect(Collectors.toSet());
        
        int newBadges = 0;
        for (Badge sourceBadge : sourceBadges) {
            if (!targetBadgeCodes.contains(sourceBadge.getBadgeCode())) {
                Badge newBadge = sourceBadge.toBuilder()
                    .id(null)
                    .userId(targetId)
                    .originalUserId(sourceId)
                    .build();
                badgeRepository.save(newBadge);
                newBadges++;
            }
        }
        
        return ModuleMigrationResult.success(1, 0,
            Map.of("transferredPoints", transferable,
                   "newBadges", newBadges,
                   "skippedPoints", sourceBalance - transferable));
    }
}
```

### 6.2 回滚机制

合并后 7 天内支持回滚，将数据恢复到合并前状态。

```java
public class MergeRollbackManager {
    
    private static final int ROLLBACK_WINDOW_DAYS = 7;
    
    @Transactional
    public void rollback(Long mergeRecordId) {
        AccountMergeRecord record = mergeRecordRepository.findById(mergeRecordId);
        
        // 检查是否在回滚窗口内
        if (!record.getRollbackPossible() 
            || Instant.now().isAfter(record.getRollbackDeadline())) {
            throw new BizException(ErrorCode.MERGE_ROLLBACK_EXPIRED);
        }
        
        AccountMergeRequest request = mergeRequestRepository
            .findById(record.getMergeRequestId());
        
        // 1. 反向恢复各模块数据
        List<AccountMergeLog> logs = mergeLogRepository
            .findByRequestIdOrderByStepName(request.getId());
        
        for (AccountMergeLog log : lists) {
            ModuleMigrator migrator = migratorRegistry.get(log.getStepName());
            migrator.rollback(log, record);
        }
        
        // 2. 恢复源账号
        User source = userRepository.findById(record.getSourceUserId());
        UserSnapshot snapshot = record.getSourceUserSnapshot();
        source.restoreFrom(snapshot);
        source.setMergedInto(null);
        source.setStatus(UserStatus.ACTIVE);
        userRepository.save(source);
        
        // 3. 恢复目标账号的合并时间标记
        User target = userRepository.findById(record.getTargetUserId());
        target.setLastMergeAt(null); // 回滚不消耗限频
        userRepository.save(target);
        
        // 4. 标记回滚完成
        record.setRollbackPossible(false);
        mergeRecordRepository.save(record);
        
        auditLogger.log(request.getId(), "MERGE_ROLLBACK",
            "合并已回滚: source=" + source.getId() + " restored");
    }
}
```

```java
    for (AccountMergeRecord record : expired) {
        record.setRollbackPossible(false);
        mergeRecordRepository.save(record);
    }
}
```

```java
@Component
public class MergeSecurityGuard {
    
    /**
     * 检查是否存在恶意合并风险
     */
    public void checkRisk(Long targetId, Long sourceId) {
        // 1. 两个账号注册IP不能相距太远（防止盗号合并）
        // 对于不同地区注册的账号，需要额外的安全验证
        
        // 2. 源账号最近7天有活跃学习行为？
        // 如果源账号极度活跃，可能是盗号者正在使用的账号
        
        // 3. 目标账号最近是否有异常登录
        
        // 4. 两账号是否曾经被关联（如同一设备登录过）
        DeviceFingerprint targetDevice = deviceService.getLastDevice(targetId);
        DeviceFingerprint sourceDevice = deviceService.getLastDevice(sourceId);
        
        boolean deviceMatched = targetDevice != null 
            && sourceDevice != null 
            && targetDevice.getFingerprint().equals(sourceDevice.getFingerprint());
        
        if (!deviceMatched) {
            // 不同设备注册的账号合并，需要升级验证级别
            // 要求双方都完成人脸验证或人工审核
            throw new MergeSecurityException(
                "两账号设备不匹配，需要人工审核或额外验证");
        }
    }
}
```

### 10.2 失败处理策略

```java
private void handleMigrationFailure(AccountMergeRequest request, 
                                     MergeMigrationException e) {
    request.setRetryCount(request.getRetryCount() + 1);
    
    if (request.getRetryCount() < 3) {
        // 自动重试：从失败的模块重新开始
        MergeModule failedModule = e.getModule();
        
        // 将失败模块及之后的所有模块重置为 PENDING
        List<AccountMergeLog> pendingLogs = mergeLogRepository
            .findFromModule(request.getId(), failedModule);
        for (AccountMergeLog log : pendingLogs) {
            log.setStepStatus("PENDING");
            mergeLogRepository.save(log);
        }
        
        // 延迟30秒后重试
        taskScheduler.schedule(
            () -> mergeOrchestrator.executeMerge(request),
            Instant.now().plus(30, ChronoUnit.SECONDS));
            
    } else {
        // 重试3次仍失败，标记为FAILED，通知用户和管理员
        request.setStatus(MergeStatus.FAILED);
        request.setFailReason(e.getMessage());
        request.setFailStep(e.getModule().name());
        mergeRequestRepository.save(request);
        
        notificationService.notify(request.getTargetUserId(),
            NotificationType.ACCOUNT_MERGE_FAILED,
            "账号合并遇到问题，客服将协助处理。申请编号: " + request.getRequestNo());
        
        // 通知运营
        opsNotificationService.notifyMergeFailure(request);
    }
}
```

## 12. 数据一致性保障

### 12.1 幂等设计

```java
/**
 * 所有迁移操作通过 request_id + module + batch 实现 idempotent
 * 重复执行不会产生副作用
 */
@Idempotent(
    key = "merge:#{#requestId}:#{#module}:#{#batchSeq}",
    expire = 24 * 3600  // 24小时
)
public void migrateBatch(Long requestId, String module, int batchSeq) {
    // 检查该批次是否已迁移
    AccountMergeLog log = mergeLogRepository
        .findByRequestIdAndModule(requestId, module);
    
    if (log.getRecordsMigrated() >= (batchSeq + 1) * BATCH_SIZE) {
        log.info("批次已迁移，跳过 requestId={} module={} batch={}", 
            requestId, module, batchSeq);
        return;
    }
    
    // 执行迁移
    // ...
}
```

### 12.2 数据校验

```java
@Scheduled(cron = "0 30 * * * ?") // 每小时执行
public void dataConsistencyCheck() {
    // 检查最近24小时完成的合并数据一致性
    List<AccountMergeRecord> recentMerges = mergeRecordRepository
        .findCompletedSince(Instant.now().minus(24, ChronoUnit.HOURS));
    
    for (AccountMergeRecord record : recentMerges) {
        ConsistencyReport report = new ConsistencyReport();
        
        // 检查源账号是否还有未迁移的数据
        long remainingMistakes = mistakeRepository
            .countByUserId(record.getSourceUserId());
        if (remainingMistakes > 0) {
            report.addIssue("源账号残留错题: " + remainingMistakes);
        }
        
        // 检查源账号会话是否已清除
        long activeSessions = sessionRepository
            .countActiveByUserId(record.getSourceUserId());
        if (activeSessions > 0) {
            report.addIssue("源账号仍有活跃会话: " + activeSessions);
        }
        
        // 检查目标账号数据数量是否合理
        // (目标账号合并后的数据量应 >= 合并前 + 迁移量 - 冲突量)
        
        if (!report.isOk()) {
            log.warn("数据一致性问题: mergeRecordId={} issues={}", 
                record.getId(), report.getIssues());
            alertService.sendConsistencyAlert(record, report);
        }
    }
}
```

## 13. 注意事项与边界条件

### 13.1 特殊场景处理

| 场景 | 处理方式 |
|------|----------|
| 两账号均为免费用户 | 正常合并，积分累加 |
| 源账号有未完成考试 | 不迁移进行中的考试会话，标记为放弃 |
| 两账号绑定了同一家长 | 目标账号保留绑定，源账号绑定关系删除 |
| 源账号有未核销优惠券 | 优惠券转移至目标账号，检查使用条件 |
| 两账号年级/学段不同 | 目标账号年级优先，源账号年级记入历史 |
| 源账号是班级群成员 | 自动退出班级群，由用户自行加入目标班级 |
| 三方账号绑定冲突 | 目标账号已有该三方绑定 → 保留目标账号的绑定 |
| 合并中途数据库主从切换 | 幂等设计保障，可安全重试 |

### 13.2 性能考量

- 单次合并数据量上限：源账号所有数据合计不超过 100 万条记录。
- 超过上限时提示用户联系客服进行人工合并。
- 大数据量合并（>10万条）使用异步队列执行，通过 WebSocket 推送实时进度。
- 分批迁移每批 200 条，每批间释放数据库连接。
