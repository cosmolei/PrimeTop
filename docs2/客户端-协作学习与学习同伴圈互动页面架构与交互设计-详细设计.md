# 客户端-协作学习与学习同伴圈互动页面架构与交互设计-详细设计

> **文档版本**: v1.0  
> **细化日期**: 2026-06-14  
> **对应模块**: 社交学习 / 协作学习客户端  
> **优先级**: P2（V1.5 阶段）  
> **依赖服务**: 学习同伴圈层匹配与协作学习编排引擎  
> **技术栈**: Flutter 3.x + Riverpod + GoRouter

---

## 1. 模块概述

### 1.1 功能目标

为 PrimeTop 学生端 APP 提供完整的协作学习交互界面，将服务端"学习圈层匹配与协作学习编排引擎"的能力以适龄化、安全可控的方式呈现给学生用户。涵盖学习圈发现与加入、圈层详情与互动、同伴问答、协作笔记、小组挑战、社交画像管理等核心交互场景。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 安全感知优先 | 未成年人社交场景下，每个交互入口都附带安全提示与家长授权状态标识 |
| 轻量入口 | 学习圈功能从首页二级入口进入，不占用底部导航位 |
| 渐进式社交 | 首次进入引导设置画像 → 推荐圈层 → 互动参与，分步降低认知负荷 |
| 隐私保护 | 界面不展示真实姓名、学校全称、联系方式；所有用户均展示脱敏昵称 |
| 时长管控 | 社交功能使用时长计入防沉迷总时长，到达限制自动提醒退出 |
| 分龄适配 | 低龄段（小学）强调图文卡片与大按钮交互；高年龄段（初中/高中）增强信息密度 |

### 1.3 用户角色与权限矩阵

| 角色 | 可见页面 | 核心操作 |
|------|---------|---------|
| 未授权学生 | 仅社交画像引导页 | 设置画像 + 发起家长授权申请 |
| 已授权学生 | 全部协作学习页面 | 创建/加入圈层、发帖、回复、分享笔记、参与挑战 |
| 圈层创建者 | 圈层管理页 | 审核加入申请、邀请同伴、解散圈层 |
| 家长 | 家长中心-社交管控面板 | 授权/撤销、查看圈层成员、设置限制 |
| 教师 | 教师端-班级圈推荐 | 查看关联圈层、推荐分组 |

#### 3.1.2 交互逻辑

1. **昵称校验**：输入时实时校验，2-16字符，正则过滤真实姓名/手机号/QQ号等敏感信息
2. **学科选择**：至少选择 1 个兴趣学科，多选上限 5 个
3. **家长授权**：点击后跳转家长授权流程

   - 未绑定家长：提示先绑定家长账号
4. **授权等待态**：发送后进入"等待家长授权"页面，支持手动刷新

// social_profile_guide_page.dart

class SocialProfileGuidePage extends ConsumerStatefulWidget {
  const SocialProfileGuidePage({super.key});
  
  @override
  ConsumerState<SocialProfileGuidePage> createState() => _GuidePageState();
}

class _GuidePageState extends ConsumerState<SocialProfileGuidePage> {
  final _nicknameController = TextEditingController();
  final _selectedSubjects = <String>{};
  String? _learningGoal;
  final _activeSlots = <String>{};
  
  bool get _isNicknameValid {
    final name = _nicknameController.text.trim();
    if (name.length < 2 || name.length > 16) return false;
    // 检查是否包含手机号、QQ号等敏感信息
    if (RegExp(r'1[3-9]\d{9}').hasMatch(name)) return false;
    if (RegExp(r'[Qq]{1,2}\d{5,}').hasMatch(name)) return false;
    return true;
  }
  
  bool get _canSubmit => 
    _isNicknameValid && 
    _selectedSubjects.isNotEmpty && 
    _learningGoal != null;

  Future<void> _submitProfile() async {
    final api = ref.read(socialApiProvider);
    
    // Step 1: 创建社交画像
    final profileResult = await api.createSocialProfile(
      displayName: _nicknameController.text.trim(),
      subjectInterests: _selectedSubjects.toList(),
      learningGoal: _learningGoal!,
      activeTimeSlots: _activeSlots.toList(),
    );
    
    if (!profileResult.isSuccess) {
      _showError(profileResult.message);
      return;
    }
    
    // Step 2: 发起家长授权请求
    final authResult = await api.requestParentAuthorization();
    
    if (authResult.isSuccess) {
      if (!mounted) return;
      // 跳转等待授权页
      context.go('/social/guide/waiting');
    } else {
      _showError(authResult.message);
    }
  }

  @override
  Widget build(BuildContext context) {
    final stage = ref.watch(currentStageProvider);
    final isLowerGrade = stage == StageKind.primary && 
                         ref.watch(currentGradeProvider) <= 3;
    
    return Scaffold(
      appBar: AppBar(title: const Text('开启同伴学习')),
      body: SingleChildScrollView(
        padding: EdgeInsets.all(isLowerGrade ? 20.r : 16.r),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // 引导头部 - 低年级使用更大字体和插图
            _buildGuideHeader(isLowerGrade),
            SizedBox(height: 24.h),
            
            // Step 1: 昵称
            _buildNicknameSection(),
            SizedBox(height: 20.h),
            
            // Step 2: 兴趣学科
            _buildSubjectSection(isLowerGrade),
            SizedBox(height: 20.h),
            
            // Step 3: 学习目标
            _buildGoalSection(),
            SizedBox(height: 20.h),
            
            // Step 4: 活跃时段
            _buildActiveTimeSection(),
            SizedBox(height: 32.h),
            
            // 家长授权提示
            _buildAuthorizationNotice(),
            SizedBox(height: 16.h),
            
            // 提交按钮
            SizedBox(
              width: double.infinity,
              height: isLowerGrade ? 56.h : 48.h,
              child: FilledButton(
                onPressed: _canSubmit ? _submitProfile : null,
                child: Text('发送家长授权请求'),
              ),
            ),
          ],
        ),
      ),
    );
  }
  
  Widget _buildSubjectSection(bool isLowerGrade) {
    final subjects = ['数学', '语文', '英语', '物理', '化学', '生物', '历史', '地理', '政治'];
    
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text('选择你感兴趣的学科', style: AppTextStyles.titleMedium),
        SizedBox(height: 12.h),
        Wrap(
          spacing: isLowerGrade ? 12.w : 8.w,
          runSpacing: isLowerGrade ? 12.h : 8.h,
          children: subjects.map((subject) {
            final selected = _selectedSubjects.contains(subject);
            return GestureDetector(
              onTap: () => setState(() {
                if (selected) {
                  _selectedSubjects.remove(subject);
                } else if (_selectedSubjects.length < 5) {
                  _selectedSubjects.add(subject);
                }
              }),
              child: AnimatedContainer(
                duration: const Duration(milliseconds: 200),
                padding: EdgeInsets.symmetric(
                  horizontal: isLowerGrade ? 20.w : 16.w,
                  vertical: isLowerGrade ? 12.h : 10.h,
                ),
                decoration: BoxDecoration(
                  color: selected 
                    ? AppColors.primaryLight 
                    : AppColors.surfaceVariant,
                  borderRadius: BorderRadius.circular(24.r),
                  border: Border.all(
                    color: selected ? AppColors.primary : Colors.transparent,
                  ),
                ),
                child: Row(
                  mainAxisSize: MainAxisSize.min,
                  children: [
                    if (selected) ...[
                      Icon(Icons.check_circle, 
                        size: isLowerGrade ? 20.sp : 16.sp,
                        color: AppColors.primary),
                      SizedBox(width: 4.w),
                    ],
                    Text(
                      subject,
                      style: TextStyle(
                        fontSize: isLowerGrade ? 18.sp : 15.sp,
                        fontWeight: selected ? FontWeight.w600 : FontWeight.w400,
                      ),
                    ),
                  ],
                ),
              ),
            );
          }).toList(),
        ),
      ],
    );
  }
}

class _CreateCirclePageState extends ConsumerState<CreateCirclePage> {

  final _descController = TextEditingController();
  CircleType _type = CircleType.studyGroup;
  int _targetSize = 5;
  int _minMatchScore = 70;
  bool _autoMatch = true;
  bool _sameTextbookOnly = false;
  bool _openJoin = false;
  bool _isCreating = false;
  
  @override
  void dispose() {
    _nameController.dispose();
    _descController.dispose();
    super.dispose();
  }

  Future<void> _create() async {
    if (_nameController.text.trim().length < 2 || _isCreating) return;
    
    setState(() => _isCreating = true);
    
    try {
      final api = ref.read(socialApiProvider);
      final result = await api.createCircle(
        name: _nameController.text.trim(),
        description: _descController.text.trim().isEmpty 
          ? null 
          : _descController.text.trim(),
        circleType: _type,
        subject: _type == CircleType.subjectFocus 
          ? ref.read(selectedSubjectProvider) 
          : null,
        targetSize: _targetSize,
        autoMatch: _autoMatch,
        preferences: CirclePreferences(
          minMatchScore: _minMatchScore,
          sameTextbookOnly: _sameTextbookOnly,
          openJoin: _openJoin,
        ),
      );
      
      if (!mounted) return;
      
      if (result.isSuccess) {
        // 显示创建成功并跳转
        _showSuccessDialog(result.data!);
      } else {
        _showError(result.message);
      }
    } catch (e) {
      _showError('创建失败：$e');
    } finally {
      if (mounted) setState(() => _isCreating = false);

// services/social_api_impl.dart

class SocialApiImpl implements SocialApi {
  final Dio _dio;
  final TokenManager _tokenManager;
  
  SocialApiImpl(this._dio, this._tokenManager);
  
  @override
  Future<PageResult<CircleRecommend>> getRecommendedCircles({
    int page = 1, int size = 10, String? subject,
  }) async {
    final response = await _dio.get(
      '/api/v1/social/circles/recommend',
      queryParameters: {
        'page': page,
        'size': size,
        if (subject != null) 'subject': subject,
      },
    );
    
    final data = response.data['data'];
    return PageResult(
      list: (data['list'] as List)
        .map((e) => CircleRecommend.fromJson(e))
        .toList(),
      total: data['total'],
      page: data['page'],
      size: data['size'],
      hasMore: data['page'] * data['size'] < data['total'],
    );
  }
  
  @override
  Future<ApiResult<CreatedCircle>> createCircle({
    required String name,
    String? description,
    required CircleType circleType,
    String? subject,
    int? targetSize,
    bool autoMatch = true,
    required CirclePreferences preferences,
  }) async {
    try {
      final response = await _dio.post(
        '/api/v1/social/circles',
        data: {
          'name': name,
          'description': description,
          'circleType': circleType.name.toUpperCase(),
          'subject': subject,
          'targetSize': targetSize,
          'autoMatch': autoMatch,
          'preferences': {
            'goal': preferences.goal,
            'minMatchScore': preferences.minMatchScore,
            'sameSchoolOnly': preferences.sameTextbookOnly,
          },
        },
      );
      
      return ApiResult.success(
        CreatedCircle.fromJson(response.data['data']));
    } on DioException catch (e) {
      return ApiResult.failure(
        code: e.response?.statusCode ?? 0,
        message: e.response?.data?['message'] ?? '网络错误',
      );
    }
  }
  
  @override
  Future<void> respondCircleInvite({
    required int messageId,
    required int circleId,
    required bool accept,
  }) async {
    await _dio.post(
      '/api/v1/social/circles/$circleId/invite/respond',
      data: {
        'messageId': messageId,
        'accept': accept,
      },
    );
    // 触发消息列表刷新
  }

    final api = ref.watch(socialApiProvider);
    
    // 监听发帖成功事件，自动刷新
    ref.listen(threadPostedProvider, (_, posted) {
      if (posted == circleId) ref.invalidateSelf();
    });
    
    return api.getCircleFeed(circleId, page: 1, size: 20);
  },
);

final challengeProgressProvider = FutureProvider.family.autoDispose<
    ChallengeProgress, (int, int)>(
  (ref, params) async {
    final (circleId, challengeId) = params;
    final api = ref.watch(socialApiProvider);
    
    // 挑战进行中时每60秒刷新一次
    final progress = await api.getChallengeProgress(circleId, challengeId);
    if (progress.status == 'ACTIVE') {
      final timer = Timer.periodic(
        const Duration(seconds: 60),
        (_) => ref.invalidateSelf(),
      );
      ref.onDispose(() => timer.cancel());
    }
    
    return progress;
  },
);

final socialMessagesProvider = FutureProvider.family.autoDispose<
    List<SocialMessage>, ({String type, int? page})>(
  (ref, params) async {
    final api = ref.watch(socialApiProvider);
    return api.getMessages(type: params.type);
  },
);

final socialTimeProvider = StreamProvider.autoDispose<Duration>((ref) async* {
  final api = ref.watch(socialApiProvider);
  
  // 首次立即获取
  final initial = await api.getSocialTimeUsage();
  yield initial;
  
  // 每30秒更新
  while (true) {
    await Future.delayed(const Duration(seconds: 30));
    try {
      yield await api.getSocialTimeUsage();
    } catch (_) {
      // 静默失败
    }
  }
});

## 12. 边界条件与注意事项

### 12.1 特殊场景

| 场景 | 处理策略 |
|------|---------|
| 用户中途退出圈层 | 保留贡献度数据；已发布的帖子和笔记标记为"已退出成员"发布 |
| 圈层冻结后恢复 | 成员需重新确认加入，冻结期间挑战暂停 |
| 跨学段升迁 | 初三→高一后，旧圈层保留 30 天后自动归档，推荐新学段圈层 |
| 家长撤销授权 | 社交功能冻结，已加入的圈层标记为 INACTIVE，已有数据保留 90 天 |
| AI辅助回答触发 | 发帖后 30 分钟内无回复时自动触发，标记 `ai_generated=true` |
| 同一用户加入多个圈 | 最多同时加入 5 个活跃圈层 |
| 图片上传失败 | 提供重试按钮，失败不影响文本内容发布 |
| 低端设备性能 | 关闭封面图大图加载，使用缩略图；关闭进度动画 |

### 12.2 安全注意

- 所有用户输入内容必须经过内容审核（前端正则预检 + 后端 AI 审核）
- 严禁在界面展示用户手机号、真实姓名、学校全称、QQ号等信息
- AI辅助回答内容也需审核后展示
- 圈层成员列表仅展示脱敏昵称和年级标签
- 家长端可查看完整成员列表和关系链
