# 语文朗读评估系统详细设计

## 1. 概述

### 1.1 模块定位
语文朗读评估系统是面向小学、初中、高中语文学科朗读与背诵场景的自动化语音评测引擎。通过 ASR、语音信号分析、文本对齐与教育学打分规则，输出分项打分与发音/停顿/情感等多维度反馈。

### 1.2 核心职责
- 音频接入与预处理（降噪、VAD、分段）
- 文本预处理（分词、声韵/节奏边界标注）
- 准确率/流畅度/完整度打分（单字/词/句/段落级别）
- 声韵调错音检测、漏读/增读检测
- 停顿节奏、情感语调分析与建议
- 错因标注与分段对齐可视化
- 结果缓存与重评

### 1.3 依赖关系
- 上游：客户端上传音频 + 元数据（年级/段/文本ID/语速范围）
- 下游：题目服务/课文服务（提供目标文本）、SSE 推送评估结果、学习档案服务（结果归档）
- 外部：ASR 引擎（必选）、可选 TTS 生成示范音频

### 3.3 错误码定义
| 错误码 | 说明 | 建议 |
|---|---|---|
| READ_INVALID_AUDIO | 音频格式/时长/采样率不符合规范 | 检查音频，支持 WAV/MP3/M4A，时长 5s-300s，采样率 16kHz+ |
| READ_TEXT_NOT_FOUND | 文本不存在/版本不支持 | 检查 text_id 与 text_version_id |
| READ_ASR_UNAVAILABLE | ASR 引擎不可用/超时 | 稍后重试或联系支持 |
| READ_ALIGNMENT_FAILED | 文本对齐失败（置信度过低） | 确认文本准确性，建议重录 |
| READ_EVALUATION_FAILED | 评估过程异常 | 稍后重试，可反馈错误码 |

## 4. 业务逻辑

### 4.1 核心流程
1. 接收上传：multipart/form-data 接收音频 + 元数据，转存对象存储，返回任务ID。
2. 预处理：降噪（可选）、VAD 分段、时长/采样率校验。
3. 文本获取：从题目服务/课文服务获取目标文本与元数据。
4. 文本预处理：分词、标注标点与停顿位置、声韵切分、生成参考对齐段。
5. ASR 识别：调用 ASR，获得字级/词级时间戳与置信度。
6. 对齐与错音检测：将 ASR 结果与目标文本对齐，输出错因、漏读/增读位置。
7. 打分计算：
   - 准确率 = 正确字符数 / 总字符数（排除标点）
   - 流畅度 = 基于停顿分布、语速方差、重复/回退统计
   - 完整度 = 1 - 漏读/增读惩罚
   - 语调/情感 = 基于音高/音量变化度与期望情感标签匹配度
8. 结果聚合：按学段阈值定级（A/B/C/D），生成分段对齐与诊断建议。
9. 缓存与推送：Redis 缓存结果，SSE 推送完成事件，写入 DB。
10. 可选：保存评估记录到学习档案服务。

### 4.2 状态机
```
pending -> processing -> completed
         -> failed

completed -> retry -> pending
failed    -> retry -> pending
```

### 4.3 关键算法
- 停顿节奏：检测标点前后停顿时长与期望停顿区间差异，过短/过长给予扣分与建议。
- 情感语调：基于 F0（音高）与能量（音量）方差，对齐情感标签（如激昂/柔和）进行相似度打分。
- 错音检测：映射拼音字库，检测声韵缺失/混淆与声调错误。
- 漏读/增读：对齐后未匹配的字或额外出现的字。

### 5.2 关键方法实现（Python）
```python
# services/read_evaluator.py
import librosa
import numpy as np
from typing import Tuple, List

class ReadEvaluator:
    def __init__(self, asr_client, pinyin_dict):
        self.asr = asr_client
        self.pinyin = pinyin_dict

    async def evaluate(self, assessment: ReadAssessment, audio_bytes: bytes) -> ReadAssessment:
        try:
            assessment.status = "processing"
            # 1. 预处理音频
            y, sr = librosa.load(audio_bytes, sr=assessment.audio_sample_rate, mono=True)
            # VAD 分段（示例：基于能量门限）
            segments = self._vad_segmentation(y, sr)

            # 2. 文本预处理
            tokens = self._tokenize_text(assessment.target_text)
            expected_pauses = self._detect_pauses(tokens)

            # 3. ASR 识别
            asr_result = await self.asr.recognize(audio_bytes, granularity="word")
            if not asr_result:
                raise RuntimeError("ASR returned empty result")

            # 4. 对齐
            alignments = self._align(asr_result, tokens)

            # 5. 错音检测
            self._detect_mispronunciations(alignments)

            # 6. 打分
            scores = self._compute_scores(alignments, segments, expected_pauses)
            assessment.sub_scores = scores
            assessment.total_score = sum(scores[k] * assessment.scoring_config.weights[k] for k in scores)
            assessment.grade = self._determine_grade(assessment.total_score, assessment.grade_level)
            assessment.alignments = alignments
            assessment.status = "completed"
            assessment.completed_at = datetime.utcnow()

            # 7. 生成建议
            assessment.suggestions = self._generate_suggestions(alignments, scores)

            # 统计
            assessment.total_chars = len(tokens)
            assessment.correct_chars = sum(1 for a in alignments if a.is_correct)
            assessment.misread_chars = sum(1 for a in alignments if a.mispronunciation)
            assessment.missed_chars = len(tokens) - len(alignments)  # 简单估算
            assessment.added_chars = len(asr_result["words"]) - len(tokens)  # 简单估算

            return assessment
        except Exception as e:
            assessment.status = "failed"
            assessment.error_code = "READ_EVALUATION_FAILED"
            assessment.error_message = str(e)
            raise

    def _vad_segmentation(self, y: np.ndarray, sr: int) -> List[Tuple[int, int]]:
        # 简化示例：使用能量 VAD（生产环境建议使用 WebRTC VAD 或专业库）
        energy = librosa.feature.rms(y=y)[0]
        threshold = np.median(energy) * 0.5
        segments = []
        in_speech = False
        start = 0
        for i, e in enumerate(energy):
            if e > threshold and not in_speech:
                start = i
                in_speech = True
            elif e <= threshold and in_speech:
                segments.append((start, i))
                in_speech = False
        if in_speech:
            segments.append((start, len(energy)))
        return segments

    def _tokenize_text(self, text: str) -> List[str]:
        # 中文分词（建议使用 jieba 或自定义字典）
        import jieba
        return list(jieba.cut(text))

    def _detect_pauses(self, tokens: List[str]) -> List[bool]:
        # 根据标点检测期望停顿位置
        punctuations = {"，", "。", "！", "？", "；", "、"}
        return [token in punctuations for token in tokens]

    def _align(self, asr_result: dict, tokens: List[str]) -> List[SegmentAlignment]:
        # 简化示例：基于编辑距离对齐（生产环境建议使用 CTC/强制对齐）
        words = [w["word"] for w in asr_result["words"]]
        dp = [[0] * (len(words) + 1) for _ in range(len(tokens) + 1)]
        for i in range(len(tokens) + 1):
            for j in range(len(words) + 1):
                if i == 0 and j == 0:
                    dp[i][j] = 0
                elif i == 0:
                    dp[i][j] = dp[i][j-1] + 1  # insertion
                elif j == 0:
                    dp[i][j] = dp[i-1][j] + 1  # deletion
                else:
                    cost = 0 if tokens[i-1] == words[j-1] else 1
                    dp[i][j] = min(dp[i-1][j-1] + cost, dp[i][j-1] + 1, dp[i-1][j] + 1)
        # 回溯
        alignments = []
        i, j = len(tokens), len(words)
        idx = 0
        while i > 0 or j > 0:
            if i > 0 and j > 0 and dp[i][j] == dp[i-1][j-1] + (0 if tokens[i-1] == words[j-1] else 1):
                alignments.append(SegmentAlignment(
                    index=idx,
                    segment_text=tokens[i-1],
                    start_time_ms=int(asr_result["words"][j-1].get("start_time", 0) * 1000),
                    end_time_ms=int(asr_result["words"][j-1].get("end_time", 0) * 1000),
                    confidence=asr_result["words"][j-1].get("confidence", 1.0),
                    is_correct=(tokens[i-1] == words[j-1]),
                    duration_ms=int((asr_result["words"][j-1].get("end_time", 0) - asr_result["words"][j-1].get("start_time", 0)) * 1000)
                ))
                i -= 1; j -= 1; idx += 1
            elif i > 0 and dp[i][j] == dp[i-1][j] + 1:  # deletion
                alignments.append(SegmentAlignment(
                    index=idx,
                    segment_text=tokens[i-1],
                    start_time_ms=0,
                    end_time_ms=0,
                    confidence=0.0,
                    is_correct=False,
                    mispronunciation=Mispronunciation(type="omission", expected=tokens[i-1], detected="", position=0, tone_expected="", tone_detected="")
                ))
                i -= 1; idx += 1
            elif j > 0 and dp[i][j] == dp[i][j-1] + 1:  # insertion
                alignments.append(SegmentAlignment(
                    index=idx,
                    segment_text="",
                    start_time_ms=int(asr_result["words"][j-1].get("start_time", 0) * 1000),
                    end_time_ms=int(asr_result["words"][j-1].get("end_time", 0) * 1000),
                    confidence=asr_result["words"][j-1].get("confidence", 1.0),
                    is_correct=False,
                    mispronunciation=Mispronunciation(type="insertion", expected="", detected=words[j-1], position=0, tone_expected="", tone_detected="")
                ))
                j -= 1; idx += 1
        alignments.reverse()
        # 计算停顿
        for i in range(1, len(alignments)):
            alignments[i].gap_before_ms = alignments[i].start_time_ms - alignments[i-1].end_time_ms
        return alignments

    def _detect_mispronunciations(self, alignments: List[SegmentAlignment]):
        for a in alignments:
            if not a.is_correct and a.mispronunciation is None:
                # 简化示例：基于拼音字库检测声韵调
                if a.segment_text and self.pinyin.get(a.segment_text):
                    exp_pinyin = self.pinyin[a.segment_text]
                    # 实际检测需要结合 ASR 识别拼音或再次声韵识别
                    # 这里仅占位，生产环境应接入声韵识别模型或 ASR 返回拼音
                    pass

    def _compute_scores(self, alignments: List[SegmentAlignment], segments: List[Tuple[int, int]], expected_pauses: List[bool]) -> Dict[str, float]:
        # 准确率
        total = sum(1 for a in alignments if a.segment_text)
        correct = sum(1 for a in alignments if a.is_correct)
        accuracy = correct / total if total > 0 else 0.0

        # 流畅度：基于停顿分布与语速方差
        pause_scores = []
        for i, a in enumerate(alignments[1:], start=1):
            if expected_pauses[i-1]:
                # 标点处停顿：过短扣分，过长可接受但给予提示
                if a.gap_before_ms < 200:  # 期望至少 200ms
                    pause_scores.append(0.5)
                elif a.gap_before_ms < 500:
                    pause_scores.append(1.0)
                else:
                    pause_scores.append(0.8)
            else:
                # 非标点处停顿：过长扣分
                if a.gap_before_ms > 150:
                    pause_scores.append(0.7)
                else:
                    pause_scores.append(1.0)
        fluency = np.mean(pause_scores) if pause_scores else 1.0

        # 完整度：漏读/增读惩罚
        completeness = 1.0 - (sum(1 for a in alignments if a.mispronunciation and a.mispronunciation.type in ["omission", "insertion"]) / total) if total > 0 else 0.0

        # 语调/情感：基于音高变化度（简化示例）
        # 实际需从音频提取 F0 并计算方差，此处仅占位
        tone = 1.0  # 若接入 F0 分析，可计算 F0 std 并归一化

        return {
            "accuracy": accuracy * 100,
            "fluency": fluency * 100,
            "completeness": completeness * 100,
            "tone": tone * 100
        }

    def _determine_grade(self, total_score: float, grade_level: str) -> str:
        # 学段阈值（可根据学段差异化配置）
        cutoffs = {"A": 90, "B": 80, "C": 70}
        if total_score >= cutoffs["A"]:
            return "A"
        elif total_score >= cutoffs["B"]:
            return "B"
        elif total_score >= cutoffs["C"]:
            return "C"
        else:
            return "D"

    def _generate_suggestions(self, alignments: List[SegmentAlignment], scores: Dict[str, float]) -> List[Dict[str, Any]]:
        suggestions = []
        # 音准建议
        mis_indices = [i for i, a in enumerate(alignments) if a.mispronunciation and a.mispronunciation.type in ["tone_missing", "tone_wrong", "tone_confused", "sound_missing", "sound_wrong"]]
        if mis_indices:
            suggestions.append({
                "category": "音准",
                "message": "部分字音不准，建议先跟读示范音频再练习",
                "segment_indices": mis_indices,
                "severity": "moderate"
            })
        # 节奏建议
        if scores["fluency"] < 85:
            suggestions.append({
                "category": "节奏",
                "message": "停顿不自然，注意标点处的适当停顿",
                "segment_indices": [],
                "severity": "mild"
            })
        # 完整度建议
        if scores["completeness"] < 90:
            suggestions.append({
                "category": "完整度",
                "message": "有漏读或增读，请核对文本后重读",
                "segment_indices": [i for i, a in enumerate(alignments) if a.mispronunciation and a.mispronunciation.type in ["omission", "insertion"]],
                "severity": "severe"
            })
        # 情感建议
        if scores["tone"] < 75:
            suggestions.append({
                "category": "情感",
                "message": "语气平淡，尝试根据文本情感调整语调",
                "segment_indices": [],
                "severity": "mild"
            })
        return suggestions
```

## 6. 错误处理

### 6.1 异常类型
- AudioValidationException：音频格式/时长/采样率不符合规范。
- ASRUnavailableException：ASR 引擎不可用/超时/返回空结果。
- AlignmentFailedException：文本对齐失败（置信度过低或对齐结果无效）。
- EvaluationException：评估过程内部错误。

### 6.2 重试策略
- ASR 调用失败：最多重试 3 次，指数退避（1s, 2s, 4s）。
- 对齐失败：若置信度全局低于阈值（如 0.5），可建议用户重录；若局部低置信，仍输出结果但标记 uncertainty。

### 6.3 降级方案
- ASR 不可用时：返回 ASR_UNAVAILABLE 错误码，不重试。
- F0 情感分析失败：将 tone 分数置 1.0 并在建议中提示“语调分析暂不可用”。

## 7. 性能优化

### 7.1 缓存策略
- 文本预处理结果缓存（7d）：减少重复分词与停顿检测开销。
- 评估结果缓存（30d）：支持结果查询与重放。

### 7.2 并发控制
- 单用户并发评估限制：同一用户最多同时处理 3 个评估任务。
- 全局队列：使用任务队列（如 Celery/Temporal）控制并发度，避免资源挤占。

### 7.3 资源限制
- 音频时长限制：5s-300s，超长返回错误。
- 文本长度限制：最多 5000 字，超长返回错误。

## 8. 安全考虑

### 8.1 权限控制
- 仅用户本人可创建/查询/删除自己的评估记录。
- 文本访问需授权（题目服务/课文服务鉴权）。

### 8.2 数据验证
- 音频格式验证：支持 WAV/MP3/M4A，拒绝其他格式。
- 音频采样率校验：要求 >= 16kHz，拒绝低采样率。
- 文本合法性：检查非空与长度限制。

### 8.3 审计日志
- 记录评估创建/查询/删除事件（user_id, session_id, text_id, 时间戳）。

## 9. 测试策略

### 9.1 单元测试
- 测试文本预处理（分词/停顿检测）。
- 测试对齐算法（编辑距离对齐准确性）。
- 测试打分计算（准确率/流畅度/完整度/语调）。
- 测试边界条件（空文本、超长文本、空音频）。

### 9.2 集成测试
- 测试与 ASR 引擎集成（超时/空结果/异常返回）。
- 测试 SSE 推送（started/progress/completed/failed 事件）。
- 测试缓存命中/未命中。

### 9.3 性能测试
- 模拟并发评估（50 QPS），检查队列与资源占用。
- 长音频（300s）评估耗时测试。

### 9.4 教育学测试
- 招募学生样本，对比人工打分与系统打分相关性。
- 检查错因标注的准确性（声韵/声调/漏读/增读）。
