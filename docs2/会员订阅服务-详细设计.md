# 会员订阅服务 - 详细设计

## 1. 概述

### 1.1 模块定位

会员订阅服务是 PrimeTop 的商业化核心模块，负责会员订阅的完整生命周期管理，包括创建订单、支付处理、权益发放、权益变更、续费、降级、退款等全流程，同时提供权益校验接口供其他业务模块调用。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 订单管理 | 创建、查询、更新订单，支持幂等性和价格锁定 |
| 支付处理 | 对接第三方支付渠道，处理支付回调，保证状态一致性 |
| 权益发放 | 支付成功后立即发放会员权益和额度资产 |
| 权益变更 | 支持会员升级、降级、续费、试用转正式等场景 |
| 生命周期 | 管理会员状态机，处理到期、续费、退款等状态流转 |
| 权益校验 | 对外提供权益校验接口，校验会员身份和额度余额 |
| 数据统计 | 统计会员转化率、续费率、权益消耗情况 |

### 1.3 依赖关系

```
会员订阅服务（本模块）
  ↓ 调用
- 用户服务（用户信息、未成年人状态）
- 支付网关（微信、支付宝、苹果内购）
- 消息队列（发送支付成功事件）
- 额度服务（发放和扣减额度）
- 增值服务（发放增值资产）
- 审计服务（记录操作日志）
  ↓ 被调用
- AI 服务（校验会员身份和额度）
- 拍题服务（校验拍题次数）
- 同步课堂（校验课程权限）
- 家长中心（展示会员信息）
- 管理后台（配置会员等级和权益）
```

## 2. 数据结构

### 2.1 核心表设计

#### 2.1.1 membership_orders（订单表）

```sql
CREATE TABLE membership_orders (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    order_no VARCHAR(32) NOT NULL UNIQUE COMMENT '业务订单号 MOS{yyyyMMdd}{6位seq}',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    order_type VARCHAR(32) NOT NULL COMMENT '订单类型：subscription_new/subscription_renew/subscription_upgrade/addon_purchase',
    
    -- 商品信息
    product_id VARCHAR(64) NOT NULL COMMENT '商品ID',
    product_name VARCHAR(128) NOT NULL COMMENT '商品快照名称',
    product_snapshot JSON NOT NULL COMMENT '商品快照（价格、权益、时长）',
    
    -- 价格信息
    original_price_cents INT NOT NULL COMMENT '原价（分）',
    discount_price_cents INT NOT NULL COMMENT '实付价（分）',
    discount_reason VARCHAR(64) NULL COMMENT '优惠原因：促销/优惠券/首充',
    coupon_id VARCHAR(64) NULL COMMENT '使用的优惠券ID',
    
    -- 支付信息
    payment_channel VARCHAR(32) NOT NULL COMMENT '支付渠道：wechat_pay/alipay/apple_iap/google_play',
    payment_status VARCHAR(16) NOT NULL DEFAULT 'pending' COMMENT '支付状态：pending/paid/failed/refunded/partial_refunded',
    payment_time DATETIME NULL COMMENT '支付完成时间',
    transaction_id VARCHAR(128) NULL COMMENT '第三方支付流水号',
    payment_raw_data JSON NULL COMMENT '第三方回调原始数据',
    
    -- 会员信息
    target_tier VARCHAR(32) NOT NULL COMMENT '目标会员等级',
    duration_days INT NOT NULL COMMENT '购买天数',
    effective_start DATE NULL COMMENT '权益生效日期',
    effective_end DATE NULL COMMENT '权益失效日期',
    
    -- 风控
    risk_check_passed TINYINT NULL COMMENT '风控检查是否通过：0/1',
    risk_check_detail JSON NULL COMMENT '风控检查详情',
    minor_verified TINYINT NOT NULL DEFAULT 0 COMMENT '是否通过未成年人消费验证',
    
    -- 元数据
    device_id VARCHAR(64) NULL COMMENT '设备ID',
    client_ip VARCHAR(45) NULL COMMENT '客户端IP',
    app_version VARCHAR(16) NULL COMMENT 'APP版本',
    platform VARCHAR(16) NULL COMMENT '平台：ios/android',
    remark VARCHAR(256) NULL COMMENT '备注',
    
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    INDEX idx_user_id (user_id),
    INDEX idx_payment_status (payment_status),
    INDEX idx_created_at (created_at),
    INDEX idx_transaction_id (transaction_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会员订阅订单表';
```

#### 2.1.2 user_memberships（用户会员表）

```sql
CREATE TABLE user_memberships (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    user_id BIGINT NOT NULL UNIQUE COMMENT '用户ID（一个用户仅一条主记录）',
    
    current_tier VARCHAR(32) NOT NULL DEFAULT 'free' COMMENT '当前会员等级',
    previous_tier VARCHAR(32) NULL COMMENT '上一会员等级',
    status VARCHAR(16) NOT NULL DEFAULT 'active' COMMENT '会员状态：active/trial/expiring_soon/expired/cancelled/refunded/suspended',
    
    started_at DATETIME NOT NULL COMMENT '会员开始时间',
    expires_at DATETIME NOT NULL COMMENT '会员到期时间',
    auto_renew TINYINT NOT NULL DEFAULT 0 COMMENT '是否自动续费：0/1',
    auto_renew_channel VARCHAR(32) NULL COMMENT '自动续费渠道',
    
    trial_used TINYINT NOT NULL DEFAULT 0 COMMENT '是否已使用试用：0/1',
    trial_expires_at DATETIME NULL COMMENT '试用到期时间',
    
    total_paid_cents INT NOT NULL DEFAULT 0 COMMENT '累计支付金额（分）',
    total_orders INT NOT NULL DEFAULT 0 COMMENT '累计订单数',
    consecutive_months INT NOT NULL DEFAULT 0 COMMENT '连续续费月数',
    
    cancelled_at DATETIME NULL COMMENT '取消时间',
    cancel_reason VARCHAR(64) NULL COMMENT '取消原因',
    
    -- Apple/Google 订阅管理
    external_sub_id VARCHAR(128) NULL COMMENT 'Apple/Google 原始订阅ID',
    external_management VARCHAR(256) NULL COMMENT '外部管理URL',
    
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    INDEX idx_status (status),
    INDEX idx_expires_at (expires_at),
    INDEX idx_auto_renew (auto_renew, expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户会员状态表';
```

```sql
CREATE TABLE user_assets (
```

### 2.2 Redis 数据结构

```
# 用户会员缓存（写入后同步到 Redis）
user:membership:{user_id} → Hash {tier, status, expires_at, auto_renew} TTL=会员到期时间

# 用户额度（原子操作）
user:quota:{user_id}:{quota_type} → String (剩余次数) TTL=会员到期时间

# 订单幂等键
order:idempotent:{user_id}:{product_id}:{hash} → String "order_no" TTL=5min

# 支付回调处理锁
pay:callback:lock:{transaction_id} → String "1" TTL=30s

# 价格缓存
config:tier:prices → Hash {tier_code → price_json} TTL=10min
```

## 3. API 接口设计

### 3.1 获取会员商品列表

#### `GET /api/v1/membership/products`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| grade_code | string | 是 | 年级代码（用于分龄推荐） |
| platform | string | 是 | 平台：ios/android（影响价格和支付渠道） |
| include_addons | bool | 否 | 是否包含增值商品，默认 false |
