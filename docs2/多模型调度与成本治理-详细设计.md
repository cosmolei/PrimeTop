## 1. 模块概述

### 1.1 定位

多模型调度与成本治理系统是 PrimeTop AI 能力层的基础设施中枢。它统一管理所有大模型供应商的接入、路由、降级、限流和成本核算，为上层业务（AI 辅导、拍题答疑、作文批改等）提供透明的模型调用能力。

本系统的核心价值：
1. **解耦业务与模型**：上层业务只声明"场景+需求"，不关心具体调用哪个模型
2. **高可用保障**：自动降级、熔断、重试，确保 AI 服务在单供应商故障时仍可用
3. **成本可控**：按用户/场景/时段的 Token 预算管理，防止调用成本失控
4. **数据驱动调优**：模型级别的延迟、成功率、质量评分监控，支持 A/B 测试和灰度切换

### 1.2 系统边界

| 范围内 | 范围外 |
| --- | --- |
| 模型供应商注册、健康检查、启停 | Prompt 模板渲染（由 Prompt 编排系统负责） |
| 场景→模型智能路由（成本/延迟/质量感知） | RAG 检索（由 RAG 系统负责） |
| 多级降级链、熔断器、限流 | 具体业务逻辑（辅导/拍题/批改等） |
| Token 用量计量、成本核算、预算控制 | 用户鉴权（由 API 网关负责） |
| 模型性能监控、告警 | 客户端通信协议 |
| 模型 A/B 测试与灰度放量 | |

### 1.3 核心用户

| 用户 | 使用方式 |
| --- | --- |
| 上层业务服务 | 调用 `ModelDispatcher.dispatch()` 获取模型响应 |
| 运营管理员 | 后台配置模型供应商、路由规则、预算策略 |
| 财务/运营 | 查看成本报表、用量趋势 |

## 4. 场景路由器 (Router)

### 4.1 路由策略

路由器根据 `scene_code` + 用户画像（学段、年级、学科）匹配路由规则，确定模型降级链。

```python
from dataclasses import dataclass
from typing import Optional
from enum import Enum

class RoutingStrategy(Enum):
    FIXED = "fixed"              # 固定模型，降级链顺序执行
    WEIGHTED = "weighted"        # 按权重随机分配（负载均衡）
    COST_OPTIMAL = "cost_optimal"    # 优先选择成本最低的可用模型
    LATENCY_OPTIMAL = "latency_optimal"  # 优先选择延迟最低的可用模型
    QUALITY_OPTIMAL = "quality_optimal"  # 优先选择质量评分最高的模型
    AB_TEST = "ab_test"          # A/B 测试分流

@dataclass
class RoutingRequest:
    scene_code: str              # 场景编码
    user_id: int
    stage: Optional[str] = None  # 学段
    grade: Optional[int] = None  # 年级
    subject: Optional[str] = None  # 学科
    stream: bool = True          # 是否流式
    max_tokens: Optional[int] = None  # 期望最大输出 Token
    
@dataclass  
class ModelCandidate:
    model_id: int
    provider_id: int
    model_code: str
    weight: int = 100
    timeout_ms: int = 30000
```

### 4.2 路由规则匹配

```python
class ModelRouter:
    """场景路由器：根据场景+用户画像匹配最优模型链"""
    
    def __init__(self, rule_repo, model_repo, ab_test_service):
        self.rule_repo = rule_repo
        self.model_repo = model_repo
        self.ab_test_service = ab_test_service
    
    async def resolve(self, req: RoutingRequest) -> list[ModelCandidate]:
        """
        解析路由请求，返回有序模型候选列表
        
        匹配逻辑：
        1. 按 scene_code 查找所有启用的规则
        2. 按优先级排序，依次尝试匹配条件（stage/subject/grade）
        3. 第一个完全匹配的规则生效
        4. 无匹配则使用场景默认规则（无匹配条件的规则）
        """
        rules = await self.rule_repo.find_by_scene(req.scene_code)
        
        matched_rule = None
        default_rule = None
        
        for rule in sorted(rules, key=lambda r: r.priority):
            if rule.status != 1:
                continue
            
            # 记录默认规则（无匹配条件）
            if not any([rule.match_stage, rule.match_subject, 
                       rule.match_grade_min, rule.match_grade_max]):
                default_rule = rule
                continue
            
            # 逐条件匹配
            if rule.match_stage and rule.match_stage != req.stage:
                continue
            if rule.match_subject and rule.match_subject != req.subject:
                continue
            if rule.match_grade_min and req.grade and req.grade < rule.match_grade_min:
                continue
            if rule.match_grade_max and req.grade and req.grade > rule.match_grade_max:
                continue
            
            matched_rule = rule
            break
        
        rule = matched_rule or default_rule
        if not rule:
            raise NoRoutingRuleError(f"场景 {req.scene_code} 无可用路由规则")
        
        # 根据策略解析模型链
        candidates = self._resolve_strategy(rule, req)
        
        # A/B 测试覆盖
        ab_override = await self.ab_test_service.get_variant(
            scene_code=req.scene_code, 
            user_id=req.user_id
        )
        if ab_override:
            candidates = [ab_override] + candidates
        
        return candidates
    
    def _resolve_strategy(self, rule, req: RoutingRequest) -> list[ModelCandidate]:
        """根据路由策略生成候选列表"""
        
        if rule.strategy == RoutingStrategy.FIXED:
            # 按降级链顺序返回
            return [
                ModelCandidate(
                    model_id=item["model_id"],
                    provider_id=self._get_provider_id(item["model_id"]),
                    model_code=self._get_model_code(item["model_id"]),
                    weight=100,
                    timeout_ms=item.get("timeout_ms", 30000),
                )
                for item in rule.model_chain
            ]
        
        elif rule.strategy == RoutingStrategy.WEIGHTED:
            # 按权重加权随机选取一个
            import random
            total = sum(item["weight"] for item in rule.model_chain)
            r = random.randint(1, total)
            cumulative = 0
            for item in rule.model_chain:
                cumulative += item["weight"]
                if r <= cumulative:
                    return [ModelCandidate(
                        model_id=item["model_id"],
                        provider_id=self._get_provider_id(item["model_id"]),
                        model_code=self._get_model_code(item["model_id"]),
                        weight=item["weight"],
                        timeout_ms=item.get("timeout_ms", 30000),
                    )]
        
        elif rule.strategy in (RoutingStrategy.COST_OPTIMAL, 
                               RoutingStrategy.LATENCY_OPTIMAL,
                               RoutingStrategy.QUALITY_OPTIMAL):
            # 按优化目标排序所有候选模型
            return self._rank_by_objective(rule, rule.strategy)
        
        return [ModelCandidate(
            model_id=item["model_id"],
            provider_id=self._get_provider_id(item["model_id"]),
            model_code=self._get_model_code(item["model_id"]),
            weight=item["weight"],
            timeout_ms=item.get("timeout_ms", 30000),
        ) for item in rule.model_chain]
    
    def _rank_by_objective(self, rule, strategy) -> list[ModelCandidate]:
        """按成本/延迟/质量排序模型"""
        models = []
        for item in rule.model_chain:
            instance = self.model_repo.get_by_id(item["model_id"])
            models.append((item, instance))
        
        if strategy == RoutingStrategy.COST_OPTIMAL:
            # 按成本升序
            models.sort(key=lambda x: x[1].cost_input_per_million + x[1].cost_output_per_million)
        elif strategy == RoutingStrategy.LATENCY_OPTIMAL:
            # 按 P50 延迟升序
            models.sort(key=lambda x: x[1].avg_latency_ms)
        elif strategy == RoutingStrategy.QUALITY_OPTIMAL:
            # 按质量评分降序
            models.sort(key=lambda x: x[1].quality_score, reverse=True)
        
        return [ModelCandidate(
            model_id=item["model_id"],
            provider_id=inst.provider_id,
            model_code=inst.model_code,
            weight=100,
            timeout_ms=item.get("timeout_ms", 30000),
        ) for item, inst in models]
```

## 5. 熔断器 (Circuit Breaker)

### 5.1 熔断状态机

```
         ┌──────────────────────────────────────────┐
         │                                          │
         ▼                                          │
    ┌─────────┐   连续失败 >= N 次    ┌─────────┐   │
    │  CLOSED │ ──────────────────▶ │   OPEN   │   │
    │ (正常)   │                     │ (熔断)   │   │
    └─────────┘                     └────┬────┘   │
         ▲                               │        │
         │                         冷却时间过后   │
         │                               │        │
         │                               ▼        │
         │                         ┌──────────┐   │
         └──────── 探测成功 ────── │HALF_OPEN │───┘
                                   │ (半开)    │─── 探测失败 ───▶ 回到 OPEN
                                   └──────────┘
```

### 5.2 熔断器实现

```python
import time
from dataclasses import dataclass, field
from threading import Lock
from enum import Enum

class CircuitState(Enum):
    CLOSED = "closed"       # 正常状态
    OPEN = "open"           # 熔断状态（拒绝请求）
    HALF_OPEN = "half_open" # 半开状态（允许探测）

@dataclass
class CircuitBreakerConfig:
    failure_threshold: int = 5       # 连续失败N次触发熔断
    success_threshold: int = 3       # 半开状态下连续成功N次恢复
    cooldown_seconds: float = 30.0   # 熔断冷却时间（秒）
    half_open_max_calls: int = 3     # 半开状态最大探测请求数

@dataclass
class CircuitBreaker:
    """单模型熔断器"""
    model_id: int
    config: CircuitBreakerConfig = field(default_factory=CircuitBreakerConfig)
    
    _state: CircuitState = CircuitState.CLOSED
    _failure_count: int = 0
    _success_count: int = 0
    _last_failure_time: float = 0
    _half_open_calls: int = 0
    _lock: Lock = field(default_factory=Lock)
    
    @property
    def state(self) -> CircuitState:
        with self._lock:
            if self._state == CircuitState.OPEN:
                # 检查冷却时间是否已过
                elapsed = time.time() - self._last_failure_time
                if elapsed >= self.config.cooldown_seconds:
                    self._state = CircuitState.HALF_OPEN
                    self._half_open_calls = 0
                    self._success_count = 0
            return self._state
    
    def allow_request(self) -> bool:
        """是否允许请求通过"""
        state = self.state
        if state == CircuitState.CLOSED:
            return True
        elif state == CircuitState.OPEN:
            return False
        elif state == CircuitState.HALF_OPEN:
            with self._lock:
                if self._half_open_calls < self.config.half_open_max_calls:
                    self._half_open_calls += 1
                    return True
                return False
        return False
    
    def record_success(self):
        """记录成功"""
        with self._lock:
            if self._state == CircuitState.HALF_OPEN:
                self._success_count += 1
                if self._success_count >= self.config.success_threshold:
                    self._state = CircuitState.CLOSED
                    self._failure_count = 0
            else:
                self._failure_count = 0
    
    def record_failure(self):
        """记录失败"""
        with self._lock:
            self._failure_count += 1
            self._last_failure_time = time.time()
            
            if self._state == CircuitState.HALF_OPEN:
                # 半开状态探测失败，立即回到 OPEN
                self._state = CircuitState.OPEN
            elif self._failure_count >= self.config.failure_threshold:
                self._state = CircuitState.OPEN


class CircuitBreakerManager:
    """熔断器管理器：为每个 model_id 维护独立熔断器"""
    
    def __init__(self):
        self._breakers: dict[int, CircuitBreaker] = {}
        self._lock = Lock()
    
    def get(self, model_id: int) -> CircuitBreaker:
        with self._lock:
            if model_id not in self._breakers:
                self._breakers[model_id] = CircuitBreaker(model_id=model_id)
            return self._breakers[model_id]
    
    def get_all_states(self) -> dict[int, dict]:
        """获取所有熔断器状态（监控用）"""
        result = {}
        for mid, cb in self._breakers.items():
            result[mid] = {
                "model_id": mid,
                "state": cb.state.value,
                "failure_count": cb._failure_count,
                "last_failure_time": cb._last_failure_time,
            }
        return result
```

## 6. 限流器 (Rate Limiter)

### 6.1 多级限流

系统采用三层限流：供应商级 → 模型级 → 用户级。

```python
import time
from collections import defaultdict

class SlidingWindowRateLimiter:
    """滑动窗口限流器（基于 Redis 实现，此处展示核心逻辑）"""
    
    def __init__(self, redis_client):
        self.redis = redis_client
    
    async def is_allowed(self, key: str, max_qps: int, window_seconds: float = 1.0) -> bool:
        """
        滑动窗口限流检查
        
        Args:
            key: 限流维度键（如 "provider:1" / "model:5" / "user:123"）
            max_qps: 窗口内最大请求数
            window_seconds: 窗口大小（秒）
        
        Returns:
            True=允许, False=限流
        """
        now = time.time()
        window_start = now - window_seconds
        
        pipe = self.redis.pipeline()
        # Redis Sorted Set 实现滑动窗口
        pipe.zremrangebyscore(key, 0, window_start)       # 清理过期条目
        pipe.zcard(key)                                      # 当前窗口请求数
        pipe.zadd(key, {str(now): now})                     # 添加当前请求
        pipe.expire(key, int(window_seconds) + 1)           # 自动过期
        
        results = await pipe.execute()
        current_count = results[1]
        
        return current_count < max_qps


class MultiLevelRateLimiter:
    """多级限流管理"""
    
    def __init__(self, redis_client, provider_repo, model_repo, budget_repo):
        self.limiter = SlidingWindowRateLimiter(redis_client)
        self.provider_repo = provider_repo
        self.model_repo = model_repo
        self.budget_repo = budget_repo
    
    async def check(self, provider_id: int, model_id: int, user_id: int) -> tuple[bool, str]:
        """
        三级限流检查
        
        Returns:
            (allowed, reason) - allowed=True表示通过，reason在拒绝时说明原因
        """
        provider = await self.provider_repo.get_by_id(provider_id)
        model = await self.model_repo.get_by_id(model_id)
        
        # Level 1: 供应商级 QPS
        if not await self.limiter.is_allowed(
            f"ratelimit:provider:{provider_id}", 
            provider.max_qps
        ):
            return False, f"供应商 {provider.provider_name} QPS 已达上限"
        
        # Level 2: 模型级 QPS（按供应商 QPS 的权重分配）
        model_qps = max(provider.max_qps // 3, 10)  # 简化：每模型至少10QPS
        if not await self.limiter.is_allowed(
            f"ratelimit:model:{model_id}",
            model_qps
        ):
            return False, f"模型 {model.model_code} QPS 已达上限"
        
        # Level 3: 用户级日调用限额
        budget = await self.budget_repo.get_or_create(user_id)
        daily_limit = budget.member_daily_limit or budget.free_daily_limit
        
        if not await self.limiter.is_allowed(
            f"ratelimit:user:daily:{user_id}",
            daily_limit,
            window_seconds=86400  # 24小时窗口
        ):
            return False, "今日 AI 调用次数已达上限"
        
        return True, ""
```

from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import AsyncIterator, Optional

@dataclass
class LLMRequest:
    messages: list[dict]         # [{"role":"user","content":"..."}]
    model: str                   # 模型编码
    max_tokens: int = 4096
    temperature: float = 0.7
    stream: bool = True
    timeout_ms: int = 30000

@dataclass
class LLMResponse:
    content: str                 # 完整内容（非流式时）
    input_tokens: int = 0
    output_tokens: int = 0
    finish_reason: str = ""      # stop|length|content_filter
    model: str = ""
    latency_ms: int = 0
    
    # 流式相关
    stream_iterator: Optional[AsyncIterator[str]] = None

@dataclass
class TokenUsage:
    input_tokens: int
    output_tokens: int

class BaseProviderAdapter(ABC):
    """模型供应商适配器基类"""
    
    @abstractmethod
    async def call(self, request: LLMRequest) -> LLMResponse:
        """调用模型（非流式）"""
        ...
    
    @abstractmethod
    async def stream(self, request: LLMRequest) -> AsyncIterator[str]:
        """调用模型（流式），逐 token 返回"""
        ...
    
    @abstractmethod
    async def embed(self, text: str, model: str) -> list[float]:
        """文本向量化"""
        ...
    
    @abstractmethod
    async def health_check(self) -> bool:
        """健康检查"""
        ...
    
    @abstractmethod

        """估算 Token 数（用于预算前置检查）"""
        ...

### 7.2 OpenAI 兼容适配器

```python
import httpx
import json

class OpenAICompatibleAdapter(BaseProviderAdapter):
    """
    OpenAI 兼容适配器
    适用于: OpenAI, 智谱 GLM, DeepSeek, Moonshot 等兼容 OpenAI API 的供应商
    """
    
    def __init__(self, base_url: str, api_key: str, default_model: str = ""):
        self.base_url = base_url.rstrip("/")
        self.api_key = api_key
        self.default_model = default_model
        self.client = httpx.AsyncClient(
            timeout=httpx.Timeout(connect=5.0, read=60.0, write=10.0, pool=10.0),
            limits=httpx.Limits(max_connections=100, max_keepalive_connections=20),
        )
    
    async def call(self, request: LLMRequest) -> LLMResponse:
        import time
        start = time.time()
        
        resp = await self.client.post(
            f"{self.base_url}/v1/chat/completions",
            headers={"Authorization": f"Bearer {self.api_key}"},
            json={
                "model": request.model or self.default_model,
                "messages": request.messages,
                "max_tokens": request.max_tokens,
                "temperature": request.temperature,
                "stream": False,
            },
            timeout=request.timeout_ms / 1000,
        )
        resp.raise_for_status()
        data = resp.json()
        
        latency_ms = int((time.time() - start) * 1000)
        choice = data["choices"][0]
        usage = data.get("usage", {})
        
        return LLMResponse(
            content=choice["message"]["content"],
            input_tokens=usage.get("prompt_tokens", 0),
            output_tokens=usage.get("completion_tokens", 0),
            finish_reason=choice.get("finish_reason", "stop"),
            model=data.get("model", ""),
            latency_ms=latency_ms,
        )
    
    async def stream(self, request: LLMRequest) -> AsyncIterator[str]:
        async with self.client.stream(
            "POST",
            f"{self.base_url}/v1/chat/completions",
            headers={"Authorization": f"Bearer {self.api_key}"},
            json={
                "model": request.model or self.default_model,
                "messages": request.messages,
                "max_tokens": request.max_tokens,
                "temperature": request.temperature,
                "stream": True,
            },
            timeout=request.timeout_ms / 1000,
        ) as resp:
            resp.raise_for_status()
            async for line in resp.aiter_lines():
                if not line.startswith("data: "):
                    continue
                data_str = line[6:]
                if data_str.strip() == "[DONE]":
                    break
                try:
                    chunk = json.loads(data_str)
                    delta = chunk["choices"][0].get("delta", {})
                    content = delta.get("content", "")
                    if content:
                        yield content
                except (json.JSONDecodeError, KeyError, IndexError):
                    continue
    
    async def embed(self, text: str, model: str = "text-embedding-3-small") -> list[float]:
        resp = await self.client.post(
            f"{self.base_url}/v1/embeddings",
            headers={"Authorization": f"Bearer {self.api_key}"},
            json={"input": text, "model": model},
        )
        resp.raise_for_status()
        return resp.json()["data"][0]["embedding"]
    
    async def health_check(self) -> bool:
        try:
            resp = await self.client.get(
                f"{self.base_url}/v1/models",
                headers={"Authorization": f"Bearer {self.api_key}"},
                timeout=5.0,
            )
            return resp.status_code == 200
        except Exception:
            return False
    
    def count_tokens(self, text: str, model: str = "") -> int:
        """简单估算：中文约 1.5 字/token，英文约 4 字符/token"""
        chinese_chars = sum(1 for c in text if '\u4e00' <= c <= '\u9fff')
        other_chars = len(text) - chinese_chars
        return int(chinese_chars / 1.5 + other_chars / 4)
```

## 8. 调度引擎 (ModelDispatcher)

### 8.1 核心调度器

```python
import time
import logging
from dataclasses import dataclass

logger = logging.getLogger(__name__)

@dataclass
class DispatchRequest:
    scene_code: str
    user_id: int
    messages: list[dict]
    stage: str = None
    grade: int = None
    subject: str = None
    stream: bool = True
    max_tokens: int = 4096
    temperature: float = 0.7
    trace_id: str = ""

@dataclass
class DispatchResult:
    content: str = ""
    stream_iterator: AsyncIterator = None
    model_id: int = 0
    model_code: str = ""
    provider_id: int = 0
    is_fallback: bool = False
    input_tokens: int = 0
    output_tokens: int = 0
    latency_ms: int = 0
    cost_yuan: float = 0.0


class ModelDispatcher:
    """
    核心调度器：统一入口，串联路由→限流→熔断→调用→降级→计量
    """
    
    def __init__(
        self,
        router: ModelRouter,
        circuit_manager: CircuitBreakerManager,
        rate_limiter: MultiLevelRateLimiter,
        adapter_factory: ProviderAdapterFactory,
        usage_recorder: "UsageRecorder",
        budget_guard: "BudgetGuard",
        model_repo,
        provider_repo,
    ):
        self.router = router
        self.circuit_manager = circuit_manager
        self.rate_limiter = rate_limiter
        self.adapter_factory = adapter_factory
        self.usage_recorder = usage_recorder
        self.budget_guard = budget_guard
        self.model_repo = model_repo
        self.provider_repo = provider_repo
    
    async def dispatch(self, req: DispatchRequest) -> DispatchResult:
        """
        调度主流程
        """
        # 1. 预算前置检查
        budget_ok, budget_reason = await self.budget_guard.check(req.user_id, req.scene_code)
        if not budget_ok:
            raise BudgetExceededError(budget_reason)
        
        # 2. 路由解析
        routing_req = RoutingRequest(
            scene_code=req.scene_code,
            user_id=req.user_id,
            stage=req.stage,
            grade=req.grade,
            subject=req.subject,
        )
        candidates = await self.router.resolve(routing_req)
        
        if not candidates:
            raise NoModelAvailableError(f"场景 {req.scene_code} 无可用模型")
        
        # 3. 逐个尝试候选模型
        last_error = None
        for idx, candidate in enumerate(candidates):
            is_fallback = idx > 0
            
            # 3a. 熔断检查
            circuit = self.circuit_manager.get(candidate.model_id)
            if not circuit.allow_request():
                logger.warning(f"[{req.trace_id}] 模型 {candidate.model_code} 已熔断，跳过")
                continue
            
            # 3b. 限流检查
            allowed, rate_reason = await self.rate_limiter.check(
                candidate.provider_id, candidate.model_id, req.user_id
            )
            if not allowed:
                logger.warning(f"[{req.trace_id}] 模型 {candidate.model_code} 限流: {rate_reason}")
                continue
            
            # 3c. 调用模型
            try:
                start = time.time()
                provider_config = await self.provider_repo.get_config(candidate.provider_id)
                adapter = self.adapter_factory.get(candidate.provider_id, provider_config)
                
                llm_req = LLMRequest(
                    messages=req.messages,
                    model=candidate.model_code,
                    max_tokens=req.max_tokens,
                    temperature=req.temperature,
                    stream=req.stream,
                    timeout_ms=candidate.timeout_ms,
                )
                
                if req.stream:
                    # 流式调用：先获取 iterator，延迟计量
                    stream_iter = adapter.stream(llm_req)
                    return DispatchResult(
                        stream_iterator=stream_iter,
                        model_id=candidate.model_id,
                        model_code=candidate.model_code,
                        provider_id=candidate.provider_id,
                        is_fallback=is_fallback,
                        latency_ms=int((time.time() - start) * 1000),
                    )
                else:
                    # 非流式调用
                    response = await adapter.call(llm_req)
                    latency_ms = int((time.time() - start) * 1000)
                    
                    # 记录成功
                    circuit.record_success()
                    
                    # 计量
                    cost = self._calculate_cost(candidate, response)
                    await self.usage_recorder.record(
                        trace_id=req.trace_id,
                        user_id=req.user_id,
                        scene_code=req.scene_code,
                        provider_id=candidate.provider_id,
                        model_id=candidate.model_id,
                        model_code=candidate.model_code,
                        is_fallback=is_fallback,
                        input_tokens=response.input_tokens,
                        output_tokens=response.output_tokens,
                        cost_yuan=cost,
                        latency_ms=latency_ms,
                        status="success",
                    )
                    
                    return DispatchResult(
                        content=response.content,
                        model_id=candidate.model_id,
                        model_code=candidate.model_code,
                        provider_id=candidate.provider_id,
                        is_fallback=is_fallback,
                        input_tokens=response.input_tokens,
                        output_tokens=response.output_tokens,
                        latency_ms=latency_ms,
                        cost_yuan=cost,
                    )
            
            except (TimeoutError, httpx.TimeoutException) as e:
                logger.warning(f"[{req.trace_id}] 模型 {candidate.model_code} 超时")
                circuit.record_failure()
                last_error = e
                await self._record_failure(req, candidate, is_fallback, "timeout")
                continue
            
            except (httpx.HTTPStatusError,) as e:
                if e.response.status_code == 429:
                    logger.warning(f"[{req.trace_id}] 模型 {candidate.model_code} 被限流")
                    circuit.record_failure()
                    last_error = e
                    await self._record_failure(req, candidate, is_fallback, "rate_limited")
                    continue
                elif e.response.status_code >= 500:
                    logger.warning(f"[{req.trace_id}] 模型 {candidate.model_code} 服务端错误: {e}")
                    circuit.record_failure()
                    last_error = e
                    await self._record_failure(req, candidate, is_fallback, "error")
                    continue
                else:
                    raise  # 4xx 客户端错误不重试
            
            except Exception as e:
                logger.error(f"[{req.trace_id}] 模型 {candidate.model_code} 异常: {e}")
                circuit.record_failure()
                last_error = e
                await self._record_failure(req, candidate, is_fallback, "error")
                continue
        
        # 所有候选模型均失败
        raise AIServiceUnavailableError(
            f"场景 {req.scene_code} 所有模型不可用，请稍后重试"
        ) from last_error
    
    def _calculate_cost(self, candidate: ModelCandidate, response: LLMResponse) -> float:
        """计算单次调用成本"""
        model = self.model_repo.get_by_id(candidate.model_id)
        input_cost = response.input_tokens * model.cost_input_per_million / 1_000_000
        output_cost = response.output_tokens * model.cost_output_per_million / 1_000_000
        return round(input_cost + output_cost, 6)
    
    async def _record_failure(self, req, candidate, is_fallback, status):
        """记录失败调用"""
        await self.usage_recorder.record(
            trace_id=req.trace_id,
            user_id=req.user_id,
            scene_code=req.scene_code,
            provider_id=candidate.provider_id,
            model_id=candidate.model_id,
            model_code=candidate.model_code,
            is_fallback=is_fallback,
            input_tokens=0,
            output_tokens=0,
            cost_yuan=0,
            latency_ms=0,
            status=status,
        )
```

class StreamingTokenCounter:
    """流式响应的 Token 计数包装器"""
    
    def __init__(
        self, 
        stream_iter: AsyncIterator[str],
        model_id: int,
        model_code: str,
        provider_id: int,
        dispatcher: ModelDispatcher,
        req: DispatchRequest,
    ):
        self._stream = stream_iter
        self._model_id = model_id
        self._model_code = model_code
        self._provider_id = provider_id
        self._dispatcher = dispatcher
        self._req = req
        
        self.collected_content = ""
        self.input_tokens = 0  # 由调用者设置
    
    async def __aiter__(self):
        return self
    
    async def __anext__(self):
        try:
            token = await self._stream.__anext__()
            self.collected_content += token
            return token
        except StopAsyncIteration:
            # 流结束，执行计量
            await self._finalize()
            raise
    
    async def _finalize(self):
        """流结束后记录用量"""
        # 估算输出 Token（精确值可能需要供应商返回）
        output_tokens = self._dispatcher.adapter_factory \
            .get(self._provider_id, {}) \
            .count_tokens(self.collected_content)
        
        model = self._dispatcher.model_repo.get_by_id(self._model_id)
        input_cost = self.input_tokens * model.cost_input_per_million / 1_000_000
        output_cost = output_tokens * model.cost_output_per_million / 1_000_000
        
        await self._dispatcher.usage_recorder.record(
            trace_id=self._req.trace_id,
            user_id=self._req.user_id,
            scene_code=self._req.scene_code,
            provider_id=self._provider_id,
            model_id=self._model_id,
            model_code=self._model_code,
            is_fallback=False,
            input_tokens=self.input_tokens,
            output_tokens=output_tokens,

class BudgetGuard:
    """用户 Token 预算守卫"""
    
    # 不同会员等级的默认额度
    LEVEL_DEFAULTS = {
        "free":     {"daily_limit": 20,   "daily_tokens": 100_000},
        "monthly":  {"daily_limit": 200,  "daily_tokens": 2_000_000},
        "yearly":   {"daily_limit": None, "daily_tokens": None},    # None = 不限
        "premium":  {"daily_limit": None, "daily_tokens": None},
    }
    
    # 高成本场景的额外限制
    SCENE_COST_MULTIPLIER = {
        "math_solve": 1.5,       # 推理模型成本高
        "physics_solve": 1.5,
        "chemistry_solve": 1.5,
        "essay_review": 2.0,     # 作文批改 Token 消耗大
        "ocr_solve": 1.0,
    }
    
    def __init__(self, budget_repo, usage_repo):
        self.budget_repo = budget_repo
        self.usage_repo = usage_repo
    
    async def check(self, user_id: int, scene_code: str) -> tuple[bool, str]:
        """
        检查用户是否还有预算
        
        Returns:
            (allowed, reason)
        """
        budget = await self.budget_repo.get_or_create(user_id)
        
        # 确定有效限额
        daily_limit = budget.member_daily_limit or budget.free_daily_limit
        daily_tokens = budget.member_daily_tokens or budget.free_daily_tokens
        
        # 会员不限额
        if daily_limit is None and daily_tokens is None:
            return True, ""
        
        # 检查日重置
        await self._check_reset(budget)
        
        # 检查次数
        if daily_limit is not None and budget.daily_used_count >= daily_limit:
            return False, f"今日 AI 调用次数已达上限({daily_limit}次)，升级会员可获得更多额度"
        
        # 检查 Token
        if daily_tokens is not None and budget.daily_used_tokens >= daily_tokens:
            return False, f"今日 Token 用量已达上限，升级会员可获得更多额度"
        
        return True, ""
    
    async def consume(self, user_id: int, input_tokens: int, output_tokens: int):
        """消费额度（调用成功后）"""
        budget = await self.budget_repo.get_or_create(user_id)
        budget.daily_used_count += 1
        budget.daily_used_tokens += input_tokens + output_tokens
        await self.budget_repo.save(budget)
    
    async def _check_reset(self, budget):
        """检查是否需要重置日额度"""
        from datetime import datetime, timedelta
        now = datetime.now()
        
        if budget.daily_reset_at is None or budget.daily_reset_at.date() < now.date():
            budget.daily_used_count = 0
            budget.daily_used_tokens = 0
            budget.daily_reset_at = now.replace(hour=0, minute=0, second=0) + timedelta(days=1)
            await self.budget_repo.save(budget)

import hashlib

class ABTestService:
    """模型 A/B 测试服务"""
    
    def __init__(self, ab_test_repo):
        self.ab_test_repo = ab_test_repo
        self._cache: dict[str, dict] = {}
        self._cache_ts = 0
    
    async def get_variant(self, scene_code: str, user_id: int) -> Optional[ModelCandidate]:
        """
        获取用户的 A/B 测试分组
        
        使用确定性哈希：同一用户始终分配到同一分组
        """
        await self._refresh_cache()
        
        # 查找该场景下正在运行的实验
        test = self._cache.get(scene_code)
        if not test or test["status"] != "running":
            return None
        
        # 流量百分比检查
        user_hash = int(hashlib.md5(f"ab:{test['id']}:{user_id}".encode()).hexdigest(), 16) % 100
        if user_hash >= test["traffic_percent"]:
            return None  # 不参与实验
        
        # 确定分组
        variant_hash = int(hashlib.md5(f"variant:{test['id']}:{user_id}".encode()).hexdigest(), 16) % 100
        cumulative = 0
        for variant in test["variants"]:
            cumulative += variant["weight"]
            if variant_hash < cumulative:
                return ModelCandidate(
                    model_id=variant["model_id"],
                    provider_id=0,  # 由后续路由填充
                    model_code="",
                )
        
        return None
    
    async def _refresh_cache(self):
        """每 60 秒刷新缓存"""
        import time
        now = time.time()
        if now - self._cache_ts > 60:
            tests = await self.ab_test_repo.find_running()
            self._cache = {t["scene_code"]: t for t in tests}
            self._cache_ts = now

## 16. 错误处理

### 16.1 错误码定义

| 错误码 | 含义 | HTTP状态码 | 客户端行为 |
|--------|------|-----------|-----------|
| 40001 | 用户预算不足（次数用完） | 403 | 弹出升级引导 |
| 40002 | 用户预算不足（Token用完） | 403 | 弹出升级引导 |
| 40003 | 场景无路由规则 | 500 | 提示稍后重试（告警运维） |
| 40004 | 所有模型不可用 | 503 | 提示稍后重试 |
| 40005 | 模型调用超时 | 504 | 自动重试1次 |
| 40006 | 模型限流（供应商429） | 503 | 自动降级重试 |
| 40007 | 模型返回内容被安全过滤 | 200 | 显示安全提示 |
| 40008 | 路由规则配置错误 | 500 | 告警运维 |
| 40009 | 供应商认证失败 | 500 | 告警运维 |

### 16.2 降级策略矩阵

| 故障类型 | 处理策略 | 重试 | 降级 | 通知 |
|---------|---------|------|------|------|
| 网络超时 | 降级到下一模型 | 本模型最多2次 | ✅ | 记录日志 |
| HTTP 429 | 降级到下一模型 | ❌ | ✅ | 记录日志 |
| HTTP 5xx | 降级到下一模型 | 本模型最多1次 | ✅ | 告警 |
| 认证失败 | 不降级，直接失败 | ❌ | ❌ | 立即告警 |
| 内容过滤 | 返回安全提示 | ❌ | ❌ | 记录日志 |
| 所有模型失败 | 返回友好错误 | ❌ | ❌ | 立即告警 |

## 18. 与其他模块的集成

### 18.1 业务层调用示例

```python
# modules/ai_tutor/service.py — AI辅导模块调用调度器
from modules.model_dispatch.dispatcher import ModelDispatcher, DispatchRequest

class AITutorService:
    def __init__(self, dispatcher: ModelDispatcher, ...):
        self.dispatcher = dispatcher
    
    async def chat(self, user_id: int, message: str, context: dict) -> AsyncIterator[str]:
        """AI辅导对话 — 只关心业务逻辑，不关心模型选择"""
        
        dispatch_req = DispatchRequest(
            scene_code=SceneCode.GENERAL_QA,
            user_id=user_id,
            messages=self._build_messages(context, message),
            stage=context.get("stage"),
            grade=context.get("grade"),
            subject=context.get("subject"),
            stream=True,
            trace_id=context.get("trace_id", ""),
        )
        
        result = await self.dispatcher.dispatch(dispatch_req)
        
        if result.stream_iterator:
            # 流式返回
            counter = StreamingTokenCounter(
                stream_iter=result.stream_iterator,
                model_id=result.model_id,
                model_code=result.model_code,
                provider_id=result.provider_id,
                dispatcher=self.dispatcher,
                req=dispatch_req,
            )
            counter.input_tokens = self._estimate_input_tokens(dispatch_req.messages)
            return counter  # 业务层直接 async for 遍历
        else:
            return result.content
```

## 20. 上线计划

### 20.1 MVP 阶段

1. **硬编码路由表**：初期只需 `MODEL_ROUTING` + `FALLBACK_CHAIN` 字典（与现有 AI智能辅导 模块一致）
2. **单供应商起步**：先接入智谱 GLM-5 作为主力
3. **简单限流**：基于 Redis 的用户级日调用次数限制
4. **基础计量**：记录每次调用的 Token 数和延迟，写入 MySQL

### 20.2 V1.0 阶段

1. 引入完整路由规则表，支持后台动态配置
2. 接入 2-3 家供应商，实现降级链
3. 实现熔断器
4. 成本核算和报表

### 20.3 V1.5+ 阶段

1. A/B 测试框架
2. 智能路由（成本/延迟/质量优化策略）
3. 供应商 Token 级别精细限流
4. ClickHouse 用量分析
