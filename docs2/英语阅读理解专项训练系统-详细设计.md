# 英语阅读理解专项训练系统 - 详细设计

> 模块定位：面向小学高年级至高中学生，提供英语阅读理解专项训练、AI 辅助精讲、分级阅读材料管理与阅读能力评估的一体化训练系统。
> 优先级：P1（V1.5 阶段上线）
> 依赖模块：题目与题库服务、AI 对话引擎、用户学习画像、学情分析、自适应推荐引擎

---

## 1. 模块概述

### 1.1 背景

阅读理解在中考英语中占比约 30%-40%，在高考英语中占比约 35%-45%，是英语考试中分值最高、区分度最大的题型。当前产品已有英语口语陪练、词汇记忆、听力模拟模块，但缺少系统的阅读理解专项训练能力。

### 1.2 目标

1. 建立分级阅读材料库，覆盖小学高年级至高考难度
2. 支持主流阅读理解题型（主旨大意、细节理解、推理判断、词义猜测、七选五等）
3. 提供 AI 辅助精读讲解，逐段解析文章结构与答题逻辑
4. 基于答题数据构建阅读能力多维度评估模型
5. 生成个性化阅读训练计划与材料推荐

### 1.3 覆盖学段

| 学段 | 目标 | 题材范围 | 难度（CEFR） |
| --- | --- | --- | --- |
| 小学 5-6 年级 | 培养基本阅读习惯 | 童话、日常生活、学校场景 | A1-A2 |
| 初中 7-9 年级 | 中考阅读理解提分 | 人物故事、科普说明、社会文化 | A2-B1 |
| 高中 10-12 年级 | 高考阅读理解提分 | 科技、社会、文化、经济、环境 | B1-B2 |

## 2. 核心功能设计

### 2.1 功能清单

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 分级阅读材料库 | 按难度、题材、题型标签管理阅读材料 | P1 |
| 阅读训练答题 | 支持单篇精读和限时套题两种训练模式 | P1 |
| AI 精读讲解 | 逐段/逐题 AI 辅导，讲解答题依据 | P1 |
| 生词标注与收集 | 文中生词高亮、释义、一键加入生词本 | P1 |
| 长难句解析 | AI 自动识别并拆解长难句语法结构 | P2 |
| 阅读能力评估 | 多维度阅读能力雷达图 | P1 |
| 个性化推荐 | 基于薄弱点推荐阅读材料和训练策略 | P2 |
| 七选五专项 | 高考七选五（段落插入）专项训练 | P1 |
| 阅读速度训练 | 计时阅读，培养快速获取信息能力 | P2 |

### 2.2 用户旅程

```text
[入口] → 选择训练模式（单篇精读/限时套题/专项突破）
    ↓
[材料选择] → 系统推荐 或 用户自选（按题材/难度/题型）
    ↓
[阅读阶段] → 展示文章（支持生词标注、段落标记、计时）
    ↓
[答题阶段] → 逐题作答（单选/多选/七选五/简答）
    ↓
[结果页] → 答题统计、正确率、用时分析
    ↓
[AI 精讲] → 可选择逐题查看 AI 讲解或请求全文精讲
    ↓
[能力更新] → 更新阅读能力维度分数、推荐下一步训练
```

## 3. 数据模型设计

### 3.1 阅读材料表 `reading_materials`

```sql
CREATE TABLE reading_materials (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    title           VARCHAR(255) NOT NULL COMMENT '文章标题',
    source_type     TINYINT NOT NULL COMMENT '来源类型: 1=真题 2=模拟题 3=原创 4=外刊改编',
    source_year     SMALLINT COMMENT '来源年份（真题）',
    source_region   VARCHAR(50) COMMENT '来源地区（如：全国I卷、北京卷）',
    
    -- 难度与学段
    grade_level     TINYINT NOT NULL COMMENT '适用年级: 5=小学5年级 ... 12=高三',
    difficulty      TINYINT NOT NULL COMMENT '难度等级: 1-10',
    cefr_level      VARCHAR(5) NOT NULL COMMENT 'CEFR等级: A1/A2/B1/B2/C1',
    lexile_score    SMALLINT COMMENT '蓝思值（Lexile）',
    
    -- 文章内容
    word_count      SMALLINT NOT NULL COMMENT '总词数',
    paragraph_count TINYINT NOT NULL COMMENT '段落数',
    content_json    JSON NOT NULL COMMENT '文章内容（按段落结构化存储）',
    full_text       TEXT NOT NULL COMMENT '完整文本（用于搜索索引）',
    
    -- 分类标签
    genre           VARCHAR(30) NOT NULL COMMENT '体裁: narrative/expository/argumentative/practical',
    topic           VARCHAR(50) NOT NULL COMMENT '题材: science/society/culture/technology/...',
    exam_type       VARCHAR(30) COMMENT '考试类型: zhongkao/gaokao/ielts/toefl',
    
    -- 关联数据
    vocabulary_ids  JSON COMMENT '生词ID列表',
    knowledge_point_ids JSON COMMENT '关联知识点ID列表',
    
    -- 状态
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '0=草稿 1=已上线 2=已下线',
    created_by      BIGINT COMMENT '创建人',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_grade_difficulty (grade_level, difficulty),
    INDEX idx_genre_topic (genre, topic),
    INDEX idx_exam_type (exam_type),
    INDEX idx_source (source_type, source_year),
    FULLTEXT INDEX ft_content (full_text)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='阅读理解材料库';
```

### 3.3 阅读题目表 `reading_questions`

```sql
CREATE TABLE reading_questions (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    material_id         BIGINT NOT NULL COMMENT '关联阅读材料ID',
    question_index      TINYINT NOT NULL COMMENT '题号（同一材料内排序）',
    
    -- 题目内容
    question_type       VARCHAR(30) NOT NULL COMMENT '题型（见 3.4 枚举）',
    stem                TEXT NOT NULL COMMENT '题干',
    options_json        JSON COMMENT '选项（选择题用），格式: [{"label":"A","text":"..."},...]',
    blanks_json         JSON COMMENT '七选五空位信息',
    
    -- 答案与解析
    correct_answer      VARCHAR(50) NOT NULL COMMENT '正确答案（A/B/C/D 或段落编号）',
    explanation         TEXT NOT NULL COMMENT 'AI 生成的答案解析',
    explanation_strategy VARCHAR(30) COMMENT '解题策略标签',
    
    -- 定位信息
    evidence_paragraph  TINYINT COMMENT '答案定位段落索引',
    evidence_text       TEXT COMMENT '答案依据原文片段',
    
    -- 难度与能力维度
    difficulty          TINYINT NOT NULL COMMENT '难度 1-10',
    ability_dimensions  JSON NOT NULL COMMENT '考查能力维度及权重',
    
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_material_question (material_id, question_index),
    INDEX idx_question_type (question_type),
    FOREIGN KEY (material_id) REFERENCES reading_materials(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='阅读理解题目';
```

### 3.4 题型枚举 `ReadingQuestionType`

```typescript
enum ReadingQuestionType {
  MAIN_IDEA        = 'main_idea',        // 主旨大意题
  DETAIL           = 'detail',           // 细节理解题
  INFERENCE        = 'inference',        // 推理判断题
  WORD_GUESSING    = 'word_guessing',    // 词义猜测题
  ATTITUDE         = 'attitude',         // 作者态度题
  PURPOSE          = 'purpose',          // 写作目的题
  TITLE            = 'title',            // 最佳标题题
  STRUCTURE        = 'structure',        // 篇章结构题
  SEVEN_CHOOSE_FIVE = 'seven_choose_five', // 七选五（段落插入）
  FILL_BLANK       = 'fill_blank',       // 语法填空（阅读类）
  SHORT_ANSWER     = 'short_answer',     // 简答题
}
```

```typescript
interface ReadingAbilityDimensions {
```

### 4.4 请求 AI 精读讲解

```
POST /api/v1/reading/practices/{practiceId}/ai-explanation
```

**请求体：**

```json
{
  "mode": "full_article",
  "focus_question_ids": [10002],
  "detail_level": "thorough"
}
```

| mode | 说明 |
| --- | --- |
| full_article | 全文精讲 |
| wrong_only | 仅讲错题 |
| focus_questions | 指定题目 |

| detail_level | 说明 |
| --- | --- |
| brief | 简要提示 |
| standard | 标准讲解 |
| thorough | 详细精讲（含语法、词汇、逻辑链） |

**响应：** SSE 流式返回

```json

  "code": 0,
  "data": {
    "session_id": "ai_sess_reading_50001",

```

```
event: question_explanation
```

### 5.1 阅读能力维度评分算法

采用 ELO 评分思想的变体，根据题目难度和答题结果动态调整能力维度分数：

```java
@Service
public class ReadingAbilityScorer {

    // 能力维度权重映射（不同题型对不同维度的影响系数）
    private static final Map<String, Map<String, Double>> QUESTION_TYPE_DIMENSION_IMPACT = Map.of(
        "main_idea", Map.of("main_idea_grasp", 0.8, "structure_analysis", 0.2),
        "detail", Map.of("detail_retrieval", 0.9, "speed_efficiency", 0.1),
        "inference", Map.of("inference_reasoning", 0.7, "vocabulary_in_context", 0.3),
        "word_guessing", Map.of("vocabulary_in_context", 0.8, "inference_reasoning", 0.2),
        "attitude", Map.of("inference_reasoning", 0.5, "main_idea_grasp", 0.5),
        "purpose", Map.of("main_idea_grasp", 0.6, "structure_analysis", 0.4),
        "title", Map.of("main_idea_grasp", 0.7, "inference_reasoning", 0.3),
        "structure", Map.of("structure_analysis", 0.9, "main_idea_grasp", 0.1),
        "seven_choose_five", Map.of("structure_analysis", 0.5, "inference_reasoning", 0.3, "detail_retrieval", 0.2)
    );

    // 难度系数 K 值：高难度题目影响更大
    private static final double BASE_K = 4.0;
    private static final double DIFFICULTY_MULTIPLIER = 0.5;

    /**
     * 计算单题对能力维度的影响
     */
    public Map<String, Double> calculateDimensionDeltas(
            String questionType,
            int difficulty,     // 1-10
            boolean isCorrect,
            long responseTimeMs,
            boolean hintUsed,
            Map<String, Double> currentDimensions) {

        Map<String, Double> deltas = new HashMap<>();
        Map<String, Double> impactWeights = QUESTION_TYPE_DIMENSION_IMPACT.getOrDefault(
            questionType, Map.of("detail_retrieval", 1.0));

        double k = BASE_K + difficulty * DIFFICULTY_MULTIPLIER;
        // 使用提示则效果减半
        if (hintUsed) k *= 0.5;

        double expectedScore = difficulty / 10.0; // 难度归一化为期望正确率
        double actualScore = isCorrect ? 1.0 : 0.0;

        for (Map.Entry<String, Double> entry : impactWeights.entrySet()) {
            String dimension = entry.getKey();
            double weight = entry.getValue();
            double current = currentDimensions.getOrDefault(dimension, 50.0);

            // 基础分变化
            double baseDelta = k * (actualScore - expectedScore) * weight;

            // 时间因子：答题过快且错误，额外扣分；答题合理时间且正确，额外加分
            double timeFactor = calculateTimeFactor(responseTimeMs, difficulty, isCorrect);
            double delta = baseDelta + baseDelta * timeFactor * 0.2;

            // 回归均值：距离50分越远，变化越小
            double regression = 1.0 - Math.abs(current - 50.0) / 100.0;
            delta *= regression;

            deltas.put(dimension, Math.round(delta * 100.0) / 100.0);
        }

        // 更新速度维度（无论对错）
        double speedDelta = calculateSpeedDelta(responseTimeMs, difficulty);
        deltas.merge("speed_efficiency", speedDelta, Double::sum);

        return deltas;
    }

    private double calculateTimeFactor(long responseTimeMs, int difficulty, boolean isCorrect) {
        // 基于难度的期望答题时间（秒）
        double expectedTimeSeconds = 15.0 + difficulty * 3.0;
        double actualTimeSeconds = responseTimeMs / 1000.0;
        double ratio = actualTimeSeconds / expectedTimeSeconds;

        if (isCorrect) {
            // 正确且快 → 加分更多
            return ratio < 0.7 ? 0.3 : (ratio < 1.3 ? 0.0 : -0.2);
        } else {
            // 错误且快（秒选）→ 扣分更多
            return ratio < 0.3 ? -0.5 : 0.0;
        }
    }

    private double calculateSpeedDelta(long responseTimeMs, int difficulty) {
        // WPM 估算（基于假设平均阅读量）
        double wpm = 200.0 / (responseTimeMs / 60000.0);
        double targetWpm = 80.0 + difficulty * 15.0;
        double ratio = wpm / targetWpm;
        return Math.max(-3.0, Math.min(3.0, (ratio - 1.0) * 2.0));
    }
}
```

### 5.2 阅读材料推荐引擎

```java
@Service
public class ReadingMaterialRecommender {

    /**
     * 个性化推荐阅读材料
     * 策略：
     * 1. 难度匹配：推荐难度在用户能力±2范围内
     * 2. 薄弱维度强化：优先推荐包含用户薄弱题型的材料
     * 3. 题材多样性：避免连续推荐相同题材
     * 4. 去重：排除用户近期已练习的材料
     */
    public List<ReadingMaterialDTO> recommend(
            Long userId,
            String practiceMode,
            int count,
            ReadingMaterialFilter filter) {

        // 1. 获取用户阅读能力档案
        UserReadingProfile profile = profileRepository.findByUserId(userId);
        int targetDifficulty = profile.getRecommendedDifficulty();
        String weakestDim = profile.getWeakestDimension();

        // 2. 获取题型-维度反向映射，找到薄弱维度对应的题型
        List<String> targetQuestionTypes = dimensionToQuestionTypes(weakestDim);

        // 3. 获取用户近30天已练习的材料ID
        Set<Long> practicedIds = practiceRepository
            .findRecentMaterialIds(userId, LocalDate.now().minusDays(30));

        // 4. 构建查询条件
        Specification<ReadingMaterial> spec = Specification
            .where(MaterialSpecs.difficultyBetween(
                Math.max(1, targetDifficulty - 2),
                Math.min(10, targetDifficulty + 2)))
            .and(MaterialSpecs.hasQuestionTypes(targetQuestionTypes))
            .and(MaterialSpecs.notInIds(practicedIds))
            .and(MaterialSpecs.statusOnline())
            .and(filter != null ? filter.toSpec() : Specification.where(null));

        // 5. 按题材多样性加权排序
        List<ReadingMaterial> candidates = materialRepository.findAll(spec);
        List<ReadingMaterial> recentByGenre = getRecentGenreDistribution(userId);

        return candidates.stream()
            .sorted(Comparator.comparingDouble(m ->
                -computeRecommendationScore(m, profile, recentByGenre)))
            .limit(count)
            .map(this::toDTO)
            .collect(Collectors.toList());
    }

    private double computeRecommendationScore(
            ReadingMaterial material,
            UserReadingProfile profile,
            List<ReadingMaterial> recentByGenre) {
        double score = 0;

        // 薄弱维度匹配度（权重 40%）
        double weakDimMatch = computeWeakDimensionMatch(material, profile);
        score += weakDimMatch * 0.4;

        // 难度适宜度（权重 30%）
        double difficultyFit = 1.0 - Math.abs(
            material.getDifficulty() - profile.getRecommendedDifficulty()) / 5.0;
        score += difficultyFit * 0.3;

        // 题材多样性（权重 20%）- 推荐不同于近期练习的题材
        double genreDiversity = computeGenreDiversity(material, recentByGenre);
        score += genreDiversity * 0.2;

        // 新鲜度（权重 10%）- 未练习过的材料
        score += 0.1;

        return score;
    }
}
```

### 6.2 七选五评分逻辑

```java
@Service
public class SevenChooseFiveScorer {

    public SevenChooseFiveResult score(
            String materialId,
            Map<String, String> userMapping,  // blank_id → option_label
            Map<String, String> correctMapping) {

        int totalBlanks = correctMapping.size();
        int correctCount = 0;
        List<BlankResult> blankResults = new ArrayList<>();

        for (Map.Entry<String, String> entry : correctMapping.entrySet()) {
            String blankId = entry.getKey();
            String correctOption = entry.getValue();
            String userOption = userMapping.get(blankId);

            boolean isCorrect = correctOption.equals(userOption);
            if (isCorrect) correctCount++;

            blankResults.add(new BlankResult(
                blankId, userOption, correctOption, isCorrect,
                isCorrect ? null : generateHint(userOption, correctOption)
            ));
        }

        return new SevenChooseFiveResult(
            totalBlanks, correctCount, blankResults,
            (double) correctCount / totalBlanks
        );
    }

    private String generateHint(String userOption, String correctOption) {
        // 提供线索但不直接给答案
        return String.format(
            "你选择的选项 %s 似乎与上下文有关联，但请注意空位前后的逻辑衔接词和指代关系。",
            userOption
        );
    }
}
```

### 6.3 七选五解题策略 Prompt

```
七选五解题策略模板（嵌入 AI 讲解 Prompt）：

1. 代词线索法：空位后出现 it/they/this/these → 找包含对应名词的选项
2. 逻辑关系法：空位前后有 however/therefore/for example → 判断转折/因果/举例关系
3. 词汇复现法：选项中出现的核心词与前文或后文存在同义/近义复现
4. 结构对称法：前后句结构平行时空位应保持对称
5. 排除法：先确定最明显的 2-3 个，缩小剩余选择范围
```
