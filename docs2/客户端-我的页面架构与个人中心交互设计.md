# 客户端 - 我的页面架构与个人中心交互设计

## 1. 模块概述

### 1.1 功能定位

"我的"页面是底部导航第 5 个 Tab（最右侧），是用户进入个人中心的唯一主入口。该页面承载用户身份展示、会员状态、学习数据概览、功能快捷入口、系统设置等职责，是连接用户与服务端个人信息、权益、偏好的核心枢纽。

### 1.2 设计目标

1. **身份清晰**：一眼确认当前登录身份、年级学段、会员状态
2. **数据可见**：展示学习数据摘要（学习天数、累计时长、知识点掌握度）
3. **功能可达**：高频功能（会员中心、家长中心、设置、客服）一步触达
4. **分龄适配**：幼儿/小学/初中/高中不同学段的页面呈现策略有差异
5. **性能优先**：本地缓存优先，关键信息即时展示，异步加载非核心数据

### 1.3 页面入口与退出

| 场景 | 入口 |
| --- | --- |
| 底部 Tab 切换 | 点击底部导航栏"我的"Tab |
| 深链接跳转 | `primetop://app/profile` 或 `primetop://app/settings` |
| 推送通知 | 点击"会员即将到期"等通知跳转至对应子页面 |
| 其他页面关联 | 从 AI 对话页点击用户头像跳转 |

class UserProfileCard {
  /// 用户ID
  final String userId;
  
  /// 头像URL
  final String? avatarUrl;
  
  /// 昵称
  final String nickname;
  
  /// 学段枚举
  final GradePhase gradePhase; // kindergarten, primary, junior, senior
  
  /// 年级
  final String grade; // "小学三年级", "初中二年级", "高中一年级"
  
  /// 教材版本（主学科）
  final String textbookEdition; // "人教版", "苏教版"
  
  /// 会员信息
  final MembershipInfo membership;
  
  /// 上次同步时间
  final DateTime? lastSyncTime;
  
  /// 是否需要完善信息
  final bool needCompleteProfile;
}

/// 会员信息
class MembershipInfo {
  /// 会员类型
  final MembershipType type; // free, monthly, yearly, exam_sprint
  
  /// 到期时间（null 表示免费用户）
  final DateTime? expireAt;
  
  /// 是否即将到期（7天内）
  bool get isExpiringSoon => expireAt != null && 
    expireAt!.difference(DateTime.now()).inDays <= 7;
  
  /// 剩余天数
  int? get remainingDays => expireAt
    ?.difference(DateTime.now()).inDays;
  
  /// 会员标签文案
  String get displayLabel {
    switch (type) {
      case MembershipType.free: return '免费用户';
      case MembershipType.monthly: return '月度会员';
      case MembershipType.yearly: return '年度会员';
      case MembershipType.examSprint: return '备考专项会员';
    }
  }
}
```

/// 学习数据概览模型
class LearningDataOverview {
  /// 累计学习天数
  final int totalStudyDays;
  
  /// 本周学习时长（分钟）
  final int weeklyStudyMinutes;
  
  /// 连续打卡天数
  final int consecutiveCheckInDays;
  
  /// 已掌握知识点数量
  final int masteredKnowledgePoints;
  
  /// 总知识点数量（用于计算掌握率）
  final int totalKnowledgePoints;
  
  /// 本周学习时长格式化
  String get weeklyStudyDisplay {
    if (weeklyStudyMinutes < 60) return '$weeklyStudyMinutes分钟';
    final hours = weeklyStudyMinutes ~/ 60;
    final mins = weeklyStudyMinutes % 60;
    return mins > 0 ? '$hours小时$mins分钟' : '$hours小时';
  }
}
```

### 4.4 本地缓存策略

```dart
/// 学习数据缓存管理
class LearningOverviewCache {
  static const _cacheKey = 'learning_overview';
  static const _cacheDuration = Duration(minutes: 30);
  
  /// 获取缓存数据（如果有效）
  LearningDataOverview? getCached() {
    final cached = LocalStorage.getJson(_cacheKey);
    if (cached == null) return null;
    
    final cacheTime = DateTime.parse(cached['cachedAt']);
    if (DateTime.now().difference(cacheTime) > _cacheDuration) {
      return null; // 缓存过期
    }
    
    return LearningDataOverview.fromJson(cached['data']);
  }
  
  /// 保存缓存
  void save(LearningDataOverview data) {
    LocalStorage.setJson(_cacheKey, {
      'cachedAt': DateTime.now().toIso8601String(),
      'data': data.toJson(),
    });
  }
}
```

class ProfileMenuItem {

  final String id;
  
  /// 图标（资源名或SF Symbol名）
  final String icon;
  
  /// 标题
  final String title;
  
  /// 副标题/描述（可选）
  final String? subtitle;
  
  /// 角标类型
  final BadgeType badge;
  
  /// 是否可见
  final bool visible;
  
  /// 是否启用
  final bool enabled;
  
  /// 排序权重
  final int sortOrder;
  
  /// 跳转目标
  final ProfileMenuTarget target;
  
  /// 学段限制（null表示全学段）
  final List<GradePhase>? gradeRestriction;
  
  /// 功能开关key（对应服务端特性开关）
  final String? featureFlagKey;
}

/// 跳转目标
sealed class ProfileMenuTarget {
  /// 内部页面路由
  const ProfileMenuTarget();
}

class PageTarget extends ProfileMenuTarget {
  final String route;
  final Map<String, dynamic>? params;
  const PageTarget(this.route, {this.params});
}

class ExternalUrlTarget extends ProfileMenuTarget {
  final String url;
  const ExternalUrlTarget(this.url);
}

class NativeActionTarget extends ProfileMenuTarget {
  final String action; // "openCustomerService", "shareApp", "checkUpdate"
  const NativeActionTarget(this.action);
}

/// 角标类型
enum BadgeType {
  none,       // 无角标
  dot,        // 红点
  text,       // 文字角标
  number,     // 数字角标
}

/// "我的"页面状态管理器
class ProfileCubit extends Cubit<ProfileState> {
  final UserRepository _userRepo;
  final LearningRepository _learningRepo;
  final MembershipRepository _membershipRepo;
  final ProfileMenuConfigRepository _menuConfigRepo;

  ProfileCubit({
    required UserRepository userRepo,
    required LearningRepository learningRepo,
    required MembershipRepository membershipRepo,
    required ProfileMenuConfigRepository menuConfigRepo,
  })  : _userRepo = userRepo,
        _learningRepo = learningRepo,
        _membershipRepo = membershipRepo,
        _menuConfigRepo = menuConfigRepo,
        super(const ProfileState(loadStatus: LoadStatus.initial));

  /// 页面初始化：优先展示缓存数据，后台刷新
  Future<void> init() async {
    // 1. 尝试从本地缓存加载
    final cached = await _loadFromCache();
    if (cached != null) {
      emit(cached.copyWith(loadStatus: LoadStatus.success));
    }

    // 2. 从服务端刷新
    await refresh();
  }

  /// 刷新数据
  Future<void> refresh() async {
    emit(state.copyWith(loadStatus: LoadStatus.loading));

    try {
      // 并发请求三个数据源
      final results = await Future.wait([
        _userRepo.getProfileCard(),
        _learningRepo.getOverview(),
        _membershipRepo.getStatus(),
        _menuConfigRepo.getMenuConfig(),
      ]);

      final newState = state.copyWith(
        loadStatus: LoadStatus.success,
        userProfile: results[0] as UserProfileCard,
        learningData: results[1] as LearningDataOverview,
        membership: results[2] as MembershipInfo,
        menuItems: _mergeMenuConfig(
          getDefaultMenuItems(),
          results[3] as ProfileMenuConfig,
        ),
        needsRefresh: false,
      );

      // 保存缓存
      await _saveToCache(newState);
      emit(newState);
    } catch (e) {
      // 如果已有缓存数据，仅更新 needsRefresh 标记
      if (state.userProfile != null) {
        emit(state.copyWith(
          loadStatus: LoadStatus.success,
          needsRefresh: true,
        ));
      } else {
        emit(state.copyWith(loadStatus: LoadStatus.error));
      }
    }
  }

  /// 合并本地默认配置与服务端动态配置
  List<ProfileMenuItem> _mergeMenuConfig(
    List<ProfileMenuItem> defaults,
    ProfileMenuConfig config,
  ) {
    final configMap = {for (var c in config.items) c.id: c};
    return defaults.map((item) {
      final override = configMap[item.id];
      if (override == null) return item;
      return item.copyWith(
        visible: override.visible,
        badge: override.badge != null
          ? _parseBadge(override.badge!)
          : item.badge,
        subtitle: override.subtitle ?? item.subtitle,
      );
    }).where((item) => item.visible).toList();
  }
}

## 11. 生命周期与刷新策略

### 11.1 页面刷新时机

| 时机 | 刷新范围 | 说明 |
| --- | --- | --- |
| 页面首次加载 | 全量 | init() 加载缓存+网络刷新 |
| 下拉刷新 | 全量 | 用户主动触发 |
| 从后台回到前台 | 增量 | 超过 5 分钟未刷新时触发 |
| 从其他 Tab 切回 | 不刷新 | 保持上次状态 |
| 会员购买成功回调 | 会员状态 | 监听支付结果回调 |
| 学习完成回调 | 学习数据 | 从学习页返回时标记 dirty |
| 收到推送通知 | 对应模块 | 按通知类型局部刷新 |

### 11.2 生命周期管理

```dart
/// 页面生命周期混入
mixin ProfileLifecycleMixin on State<ProfilePage> {
  late final AppLifecycleListener _lifecycleListener;
  DateTime? _lastRefreshTime;

  @override
  void initState() {
    super.initState();
    _lifecycleListener = AppLifecycleListener(
      onResume: _onAppResumed,
    );
  }

  void _onAppResumed() {
    final now = DateTime.now();
    final lastRefresh = _lastRefreshTime;
    if (lastRefresh == null ||
        now.difference(lastRefresh).inMinutes >= 5) {
      // 超过5分钟，触发后台刷新
      context.read<ProfileCubit>().refresh();
      _lastRefreshTime = now;
    }
  }

  @override
  void dispose() {
    _lifecycleListener.dispose();
    super.dispose();
  }
}

### 12.1 错误场景与处理策略

| 错误场景 | UI 表现 | 恢复策略 |

| Token 过期 | 弹出登录过期对话框 | 跳转重新登录 |
| 服务端维护 | 展示维护公告页 | 自动轮询恢复 |

        // 每个菜单项独立key，列表变化时高效更新
        return KeyedSubtree(
          key: ValueKey(item.id),
          child: MenuItemTile(item: item),
        );
      }).toList(),
    );
  }
}
```

### 14.2 图片优化

- 头像使用 `CachedNetworkImage` + 圆形裁剪
- 头像缩略图尺寸：128×128px（显示 64dp 的 2x 分辨率）
- 默认头像使用本地 Asset，无网络请求
- 会员卡片背景使用本地渐变，无图片加载

### 14.3 数据预加载

```dart
/// APP 启动时预加载 "我的"页面数据
class ProfilePreloader {
  /// 在首页加载完成后，后台预加载 "我的"页面数据
  static void preload(BuildContext context) {
    // 延迟执行，不阻塞首页渲染
    Future.delayed(const Duration(seconds: 2), () {
      if (!context.mounted) return;
      // 预加载到内存缓存
      context.read<UserRepository>().prefetchProfileCard();
      context.read<LearningRepository>().prefetchOverview();
    });
  }
}
```
