# 服务端-学生用户学习会话全链路行为录制与会话回放诊断引擎

## 1. 概述

### 1.1 功能定位

本模块为 PrimeTop 平台提供**统一的学习行为录制与会话回放**基础设施。与现有的「答题过程行为追踪」「写作过程行为分析」等单模块行为采集不同，本引擎横跨**所有学习活动类型**（AI 对话、拍题答疑、同步课堂、练习测评、错题复习、阅读内容、背诵练习等），将分散的行为事件组装为**完整可回放的学习会话时间线**，并提供回放、诊断、归因分析能力。

### 1.2 核心目标

| 目标 | 说明 |
| --- | --- |
| 全链路录制 | 捕获学生在一次学习会话中的全部交互行为，形成连续时间线 |
| 会话回放 | 支持教师、家长、学生本人以"播放器"模式回看学习过程 |
| 诊断分析 | 自动识别学习过程中的低效行为、注意力分散点、知识卡点 |
| 隐私合规 | 精细化的录制范围控制、脱敏存储、按角色分级的回放权限 |

### 1.3 适用场景

| 场景 | 用户 | 价值 |
| --- | --- | --- |
| 学习过程回顾 | 学生 | 复盘自己的学习路径，发现低效环节 |
| 学习辅导诊断 | 教师/家长 | 了解学生"怎么学的"，而非只看"学了什么" |
| 学情深度归因 | 系统/AI | 基于过程数据提供更精准的个性化推荐 |
| 学习质量评估 | 运营/教研 | 分析平台学习体验瓶颈 |
| 异常行为检测 | 风控系统 | 识别刷题机器行为、代写代答等 |

### 1.4 与现有模块的边界

| 现有模块 | 覆盖范围 | 本模块差异 |
| --- | --- | --- |
| 学生答题过程行为追踪与思维路径可视化引擎 | 仅答题场景的行为追踪 | 本模块覆盖**全部学习活动类型**，提供跨模块统一回放 |
| 练习答题行为数据采集与学习过程分析引擎 | 练习答题的数据采集 | 本模块是**会话级**录制，包含练习答题之外的阅读、对话、观看等 |
| 学生学习过程质量实时感知与低效学习行为智能干预引擎 | 实时质量感知与干预 | 本模块关注**事后回放与诊断**，而非实时干预 |
| 客户端-埋点事件体系与数据采集规范 | 通用埋点采集 | 本模块在埋点之上构建**会话编排层和回放渲染层** |

## 2. 数据结构定义

### 2.1 核心数据模型

#### 2.1.1 学习会话表 `learning_session_record`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| session_id | VARCHAR(36) PK | 会话唯一ID（UUID） |
| user_id | BIGINT | 学生用户ID |
| session_type | VARCHAR(32) | 会话类型：`AI_TUTOR`/`PHOTO_SEARCH`/`SYNC_CLASS`/`PRACTICE`/`ERROR_REVIEW`/`READING`/`RECITATION`/`COMPOSITION`/`MIXED` |
| start_time | DATETIME(3) | 会话开始时间（毫秒精度） |
| end_time | DATETIME(3) | 会话结束时间 |
| duration_ms | INT | 会话总时长（毫秒） |
| module_sequence | JSON | 会话涉及的模块跳转序列 `[{"module":"AI_TUTOR","start":0,"end":120000},{"module":"PRACTICE","start":120000,"end":300000}]` |
| event_count | INT | 会话内行为事件总数 |
| activity_summary | JSON | 活动摘要统计 `{"questions_asked":5,"problems_solved":12,"pages_read":3,...}` |
| focus_score | DECIMAL(4,2) | 专注度评分（0.00-100.00），基于行为信号计算 |
| efficiency_score | DECIMAL(4,2) | 学习效率评分（0.00-100.00） |
| interruption_count | INT | 中断次数（App 切后台、电话等） |
| device_info | JSON | 设备信息 `{"platform":"android","model":"MI 13","app_version":"2.1.0","screen_width":1080,"screen_height":2400}` |
| network_info | JSON | 网络信息 `{"type":"wifi","carrier":"","avg_latency_ms":45}` |
| learning_context | JSON | 学习上下文 `{"grade":"高一","subject":"数学","textbook_version":"人教版","chapter_id":"ch_2019_math_hs_1_3"}` |
| diagnostic_tags | JSON | 诊断标签 `["high_interruption","late_night","low_focus_period"]` |
| replay_enabled | TINYINT(1) | 是否允许回放（受隐私设置控制） |
| created_at | DATETIME | 记录创建时间 |
| updated_at | DATETIME | 记录更新时间 |

```sql
CREATE TABLE learning_session_record (
    session_id          VARCHAR(36) PRIMARY KEY,
    user_id             BIGINT NOT NULL,
    session_type        VARCHAR(32) NOT NULL,
    start_time          DATETIME(3) NOT NULL,
    end_time            DATETIME(3),
    duration_ms         INT DEFAULT 0,
    module_sequence     JSON,
    event_count         INT DEFAULT 0,
    activity_summary    JSON,
    focus_score         DECIMAL(4,2),
    efficiency_score    DECIMAL(4,2),
    interruption_count  INT DEFAULT 0,
    device_info         JSON,
    network_info        JSON,
    learning_context    JSON,
    diagnostic_tags     JSON,
    replay_enabled      TINYINT(1) DEFAULT 1,
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_time (user_id, start_time DESC),
    INDEX idx_type_time (session_type, start_time DESC),
    INDEX idx_focus (focus_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习会话录制记录';
```

#### 2.1.2 行为事件流表 `learning_behavior_event`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| event_id | BIGINT PK AUTO_INCREMENT | 事件自增ID |
| session_id | VARCHAR(36) | 所属会话ID |
| user_id | BIGINT | 学生用户ID |
| event_seq | INT | 会话内序号（从0递增） |
| event_type | VARCHAR(48) | 事件类型（见 2.1.3） |
| event_source | VARCHAR(32) | 来源模块：`AI_TUTOR`/`PHOTO_SEARCH`/`SYNC_CLASS`/`PRACTICE`/`ERROR_REVIEW`/`READING`/`RECITATION`/`COMPOSITION` |
| timestamp_ms | BIGINT | 事件发生时间戳（毫秒） |
| relative_ms | INT | 相对会话开始的毫秒偏移 |
| content_ref | JSON | 关联内容引用 `{"content_id":"q_12345","content_type":"question","subject":"数学"}` |
| interaction_data | JSON | 交互详情（按键、点击坐标、滚动位置等） |
| response_data | JSON | 系统响应数据（AI 回复摘要、批改结果摘要等） |
| duration_ms | INT | 该事件持续时间（如阅读一段内容耗时） |
| screen_snapshot_ref | VARCHAR(256) | 屏幕快照引用（可选，脱敏后的DOM快照路径） |
| metadata | JSON | 扩展元数据 |

```sql
CREATE TABLE learning_behavior_event (
    event_id            BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id          VARCHAR(36) NOT NULL,
    user_id             BIGINT NOT NULL,
    event_seq           INT NOT NULL,
    event_type          VARCHAR(48) NOT NULL,
    event_source        VARCHAR(32) NOT NULL,
    timestamp_ms        BIGINT NOT NULL,
    relative_ms         INT NOT NULL,
    content_ref         JSON,
    interaction_data    JSON,
    response_data       JSON,
    duration_ms         INT DEFAULT 0,
    screen_snapshot_ref VARCHAR(256),
    metadata            JSON,
    INDEX idx_session_seq (session_id, event_seq),
    INDEX idx_user_time (user_id, timestamp_ms),
    INDEX idx_type_time (event_type, timestamp_ms)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习行为事件流';
```

> **存储策略**：热数据保留在 MySQL（近 30 天），冷数据归档至 ClickHouse / Elasticsearch 用于长期分析和检索。

#### 2.1.4 会话回放快照表 `session_replay_snapshot`

用于存储关键节点的屏幕状态快照（脱敏后的 DOM 结构或组件树 JSON，**不存储截图**以保护隐私）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| snapshot_id | BIGINT PK AUTO_INCREMENT | 快照ID |
| session_id | VARCHAR(36) | 会话ID |
| event_seq | INT | 对应事件序号 |
| snapshot_type | VARCHAR(32) | `DOM_TREE`/`COMPONENT_TREE`/`LAYOUT_META` |
| snapshot_data | MEDIUMTEXT | 序列化的界面结构JSON（脱敏后） |
| viewport_info | JSON | 视口信息 `{"width":1080,"height":2400,"scroll_y":1280}` |
| storage_path | VARCHAR(256) | 对象存储路径（如果数据量大于阈值） |
| created_at | DATETIME | 创建时间 |

```sql
CREATE TABLE session_replay_snapshot (
    snapshot_id     BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      VARCHAR(36) NOT NULL,
    event_seq       INT NOT NULL,
    snapshot_type   VARCHAR(32) NOT NULL DEFAULT 'COMPONENT_TREE',
    snapshot_data   MEDIUMTEXT,
    viewport_info   JSON,
    storage_path    VARCHAR(256),
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_session_seq (session_id, event_seq)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会话回放界面快照';
```

#### 2.1.5 回放诊断报告表 `session_diagnostic_report`

| 字段 | 类型 | 说明 |

| session_id | VARCHAR(36) | 关联会话ID |
| user_id | BIGINT | 学生用户ID |
| report_type | VARCHAR(32) | `AUTO_SUMMARY`/`TEACHER_REVIEW`/`PARENT_DIGEST`/`SELF_REFLECTION` |

| behavior_patterns | JSON | 识别到的行为模式列表 |

### 3.3 获取会话回放数据

**GET** `/api/v1/session/{sessionId}/replay`

> 获取会话完整回放数据，包含事件时间线和快照索引。

**查询参数：**

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| include_snapshots | Boolean | 否 | 是否包含界面快照（默认 true） |
| snapshot_interval | Integer | 否 | 快照采样间隔（事件数），默认 10 |
| viewer_role | String | 是 | 查看者角色：`STUDENT`/`PARENT`/`TEACHER`/`ADMIN` |

**响应体：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "session_info": {
      "session_id": "sess_a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "session_type": "MIXED",
      "start_time": "2026-08-10T10:00:00.000+08:00",
```

```dart
/// SessionRecorder - 统一学习行为采集SDK
/// 集成在各业务模块中，自动采集行为事件

class SessionRecorder {
  static final SessionRecorder _instance = SessionRecorder._internal();
  factory SessionRecorder() => _instance;
  SessionRecorder._internal();

  final EventQueue _eventQueue = EventQueue();
  final BatchUploader _uploader = BatchUploader();
  SessionContext? _currentSession;
  StreamSubscription? _appLifecycleSub;

  /// 初始化SDK
  void init({required String userId, required String appVersion}) {
    _uploader.configure(
      endpoint: '/api/v1/session/events/batch',
      maxBatchSize: 50,
      flushIntervalMs: 30000,
    );
    _appLifecycleSub = AppLifecycleObserver.onStateChanged.listen(_onLifecycleChange);
  }

  /// 开启新会话
  SessionContext startSession({
    required String sessionType,
    required String entryPoint,
    Map<String, dynamic>? learningContext,
  }) {
    // 如果已有会话且未关闭，先自动关闭
    if (_currentSession != null && _currentSession!.isActive) {
      closeSession(endReason: 'AUTO_NEW_SESSION');
    }

    final session = SessionContext(
      sessionId: _generateSessionId(),
      sessionType: sessionType,
      startTime: DateTime.now(),
      entryPoint: entryPoint,
      learningContext: learningContext ?? {},
    );
    _currentSession = session;

    // 发送会话开始事件
    record(LearningEvent(
      type: LearningEventType.sessionStart,
      source: 'SYSTEM',
      interactionData: {'entry_point': entryPoint},
    ));

    return session;
  }

  /// 记录行为事件（核心方法）
  void record(LearningEvent event) {
    final session = _currentSession;
    if (session == null || !session.isActive) return;

    // 填充会话上下文
    event.sessionId = session.sessionId;
    event.eventSeq = session.nextSeq();
    event.timestampMs = DateTime.now().millisecondsSinceEpoch;
    event.relativeMs = DateTime.now().difference(session.startTime).inMilliseconds;

    // 脱敏处理
    _redactSensitiveData(event);

    // 加入队列
    _eventQueue.enqueue(event);

    // 触发批量上传判断
    if (_eventQueue.size >= 50) {
      _uploader.flush(sessionId: session.sessionId);
    }
  }

  /// 关闭会话
  Future<void> closeSession({required String endReason}) async {
    final session = _currentSession;
    if (session == null) return;

    record(LearningEvent(
      type: LearningEventType.sessionEnd,
      source: 'SYSTEM',
      interactionData: {'exit_reason': endReason},
    ));

    session.isActive = false;

    // 上传剩余事件
    await _uploader.flush(sessionId: session.sessionId);

    // 通知服务端关闭会话
    await _uploader.closeSession(
      sessionId: session.sessionId,
      endReason: endReason,
    );

    _currentSession = null;
  }

  void _onLifecycleChange(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.paused:
        record(LearningEvent(
          type: LearningEventType.appBackground,
          source: 'SYSTEM',
        ));
        break;
      case AppLifecycleState.resumed:
        record(LearningEvent(
          type: LearningEventType.appForeground,
          source: 'SYSTEM',
        ));
        break;
      default:
        break;
    }
  }

  /// 脱敏处理：移除或哈希化敏感内容
  void _redactSensitiveData(LearningEvent event) {
    // 不记录完整的AI回复文本，仅保留摘要
    // 不记录题目完整题干，仅保留题目ID
    // 不记录学生输入的个人信息
    final data = event.interactionData;
    if (data == null) return;

    if (data.containsKey('message_preview')) {
      final preview = data['message_preview'] as String;
      if (preview.length > 100) {
        data['message_preview'] = '${preview.substring(0, 100)}...';
      }
    }
  }

  String _generateSessionId() {
    return 'sess_${Uuid().v4()}';
  }
}
```

```java
@Service
public class EventIngestionService {

    @Autowired
    private LearningBehaviorEventMapper eventMapper;

    @Autowired
    private LearningSessionRecordMapper sessionMapper;

    @Autowired
    private SessionAssembler sessionAssembler;

    @Autowired
    private DiagnosticAnalyzer diagnosticAnalyzer;

    @Autowired
    private KafkaTemplate<String, Object> kafkaTemplate;

    /**
     * 批量接收事件
     */
    @Transactional
    public BatchIngestResult batchIngest(EventBatchDTO batch) {
        String sessionId = batch.getSessionId();

        // 1. 校验会话是否存在
        LearningSessionRecord session = sessionMapper.selectById(sessionId);
        if (session == null) {
            // 自动创建会话记录（首次上报）
            session = createSessionRecord(batch);
            sessionMapper.insert(session);
        }

        // 2. 批量写入事件
        List<LearningBehaviorEvent> events = batch.getEvents().stream()
            .map(e -> buildEventEntity(e, session))
            .collect(Collectors.toList());

        eventMapper.batchInsert(events);

        // 3. 更新会话统计
        sessionMapper.incrementEventCount(sessionId, events.size());

        // 4. 发送事件到 Kafka 流处理管线
        for (LearningBehaviorEvent event : events) {
            kafkaTemplate.send("learning-behavior-events",
                sessionId, event);
        }

        // 5. 检查是否需要更新模块序列
        sessionAssembler.updateModuleSequence(sessionId, events);

        return BatchIngestResult.builder()
            .acceptedCount(events.size())
            .sessionId(sessionId)
            .serverTimeMs(System.currentTimeMillis())
            .build();
    }

    /**
     * 关闭会话 - 触发诊断分析
     */
    public CloseResult closeSession(String sessionId, CloseDTO dto) {
        LearningSessionRecord session = sessionMapper.selectById(sessionId);
        if (session == null) {
            throw new BizException(ErrorCode.SESSION_NOT_FOUND);
        }

        // 1. 计算会话时长
        long durationMs = Duration.between(
            session.getStartTime().toInstant(),
            Instant.now()
        ).toMillis();

        session.setEndTime(LocalDateTime.now());
       .setDurationMs((int) durationMs);
        sessionMapper.updateById(session);

        // 2. 异步触发诊断分析
        diagnosticAnalyzer.analyzeAsync(sessionId);

        // 3. 发送会话关闭事件
        kafkaTemplate.send("session-lifecycle-events",
            new SessionClosedEvent(sessionId, durationMs, dto.getEndReason()));

        return CloseResult.builder()
            .sessionId(sessionId)
            .durationMs((int) durationMs)
            .eventCount(session.getEventCount())
            .diagnosticStatus("PROCESSING")
            .estimatedReportReadyMs(15000)
            .build();
    }

    private LearningSessionRecord createSessionRecord(EventBatchDTO batch) {

        record.setSessionId(batch.getSessionId());
        record.setSessionType(batch.getSessionType());
        record.setStartTime(LocalDateTime.now());
        record.setEventCount(0);
        record.setInterruptionCount(0);
        return record;
    }
```

```java
/**
 * 诊断分析引擎 - 对学习会话进行多维度分析

@Service
public class DiagnosticAnalyzer {

    @Autowired
    private LearningBehaviorEventMapper eventMapper;

    @Autowired
    private SessionDiagnosticReportMapper reportMapper;

    @Autowired
    private LlmClient llmClient;

    @Autowired
    private KnowledgePointService kpService;

    @Async("diagnosticExecutor")
    public CompletableFuture<Void> analyzeAsync(String sessionId) {
        try {
            // 1. 加载会话全部事件
            List<LearningBehaviorEvent> events = eventMapper.findBySessionIdOrderByEventSeq(sessionId);
            if (events.isEmpty()) {
                return CompletableFuture.completedFuture(null);
            }

            // 2. 行为模式识别
            List<BehaviorPattern> patterns = detectBehaviorPatterns(events);

            // 3. 低效节点检测
            List<InefficiencyPoint> inefficiencies = detectInefficiencies(events);

            // 4. 注意力分析
            AttentionAnalysis attention = analyzeAttention(events);

            // 5. 知识卡点识别
            List<KnowledgeBlocker> blockers = detectKnowledgeBlockers(events);

            // 6. 计算多维度评分
            ScoreBreakdown scores = calculateScores(events, patterns, attention);

            // 7. 调用 LLM 生成自然语言评估
            String assessment = generateAssessment(events, patterns, scores);

            // 8. 生成改进建议
            List<Recommendation> recommendations = generateRecommendations(
                blockers, inefficiencies, scores);

            // 9. 组装并保存报告
            SessionDiagnosticReport report = SessionDiagnosticReport.builder()
                .reportId(IdUtil.uuid())
                .sessionId(sessionId)
                .userId(events.get(0).getUserId())
                .reportType("AUTO_SUMMARY")
                .overallAssessment(assessment)
                .behaviorPatterns(JsonUtils.toJson(patterns))
                .inefficiencyPoints(JsonUtils.toJson(inefficiencies))
                .knowledgeBlockers(JsonUtils.toJson(blockers))
                .attentionAnalysis(JsonUtils.toJson(attention))
                .recommendations(JsonUtils.toJson(recommendations))
                .scoreBreakdown(JsonUtils.toJson(scores))
                .generatedBy("AI")
                .generatedAt(LocalDateTime.now())
                .build();

            reportMapper.insert(report);

            // 10. 更新会话评分
            updateSessionScores(sessionId, scores);

            return CompletableFuture.completedFuture(null);

        } catch (Exception e) {
            log.error("诊断分析失败, sessionId={}", sessionId, e);
            return CompletableFuture.failedFuture(e);
        }
    }

    /**
     * 行为模式识别
     */
    private List<BehaviorPattern> detectBehaviorPatterns(List<LearningBehaviorEvent> events) {
        List<BehaviorPattern> patterns = new ArrayList<>();

        // 模式1：深度提问（连续追问3次以上）
        patterns.addAll(detectDeepQuestioningPattern(events));

        // 模式2：快速猜测（连续5题，每题<8秒）
        patterns.addAll(detectRapidGuessingPattern(events));

        // 模式3：重复查看（同一内容查看3次以上）
        patterns.addAll(detectRepeatedViewingPattern(events));

        // 模式4：频繁切换（1分钟内切换模块3次以上）
        patterns.addAll(detectFrequentSwitchingPattern(events));

        // 模式5：专注沉浸（连续同一类型学习15分钟以上无中断）
        patterns.addAll(detectFlowStatePattern(events));

        // 模式6：被动学习（只看不做，无任何交互行为超过10分钟）
        patterns.addAll(detectPassiveLearningPattern(events));

        return patterns;
    }

    /**
     * 快速猜测模式检测
     */
    private List<BehaviorPattern> detectRapidGuessingPattern(List<LearningBehaviorEvent> events) {
        List<BehaviorPattern> results = new ArrayList<>();
        int GUESS_THRESHOLD_MS = 8000;
        int MIN_GUESS_COUNT = 5;

        // 筛选出答题事件对（ANSWER_SUBMIT）
        List<LearningBehaviorEvent> submitEvents = events.stream()
            .filter(e -> e.getEventType().equals("ANSWER_SUBMIT"))
            .collect(Collectors.toList());

        // 滑动窗口检测连续快速提交
        int start = 0;
        while (start < submitEvents.size()) {
            int end = start;
            while (end + 1 < submitEvents.size()
                   && submitEvents.get(end + 1).getRelativeMs()
                      - submitEvents.get(end).getRelativeMs() < GUESS_THRESHOLD_MS) {
                end++;
            }

            int count = end - start + 1;
            if (count >= MIN_GUESS_COUNT) {
                results.add(BehaviorPattern.builder()
                    .name("快速猜测行为")
                    .description(String.format("连续%d道题平均用时%.1f秒",
                        count,
                        avgTimeBetween(submitEvents, start, end) / 1000.0))
                    .timeRange(TimeRange.builder()
                        .startMs(submitEvents.get(start).getRelativeMs())
                        .endMs(submitEvents.get(end).getRelativeMs())
                        .build())
                    .module(submitEvents.get(start).getEventSource())
                    .sentiment("NEGATIVE")
                    .build());
            }
            start = end + 1;
        }

        return results;
    }

    /**
     * 注意力分析
     */
    private AttentionAnalysis analyzeAttention(List<LearningBehaviorEvent> events) {
        // 识别中断事件
        List<LearningBehaviorEvent> interruptions = events.stream()
            .filter(e -> Set.of("APP_BACKGROUND", "IDLE_DETECTED").contains(e.getEventType()))
            .collect(Collectors.toList());

        // 计算每段连续专注时长
        List<Long> focusSpans = calculateFocusSpans(events, interruptions);

        return AttentionAnalysis.builder()
            .avgFocusSpanMs(focusSpans.isEmpty() ? 0 :
                (long) focusSpans.stream().mapToLong(l -> l).average().orElse(0))
            .longestFocusMs(focusSpans.stream().mapToLong(l -> l).max().orElse(0))
            .distractionCount(interruptions.size())
            .distractionDetails(interruptions.stream()
                .map(this::toDistractionDetail)
                .collect(Collectors.toList()))
            .build();
    }

    /**
     * 多维度评分计算
     */
    private ScoreBreakdown calculateScores(
            List<LearningBehaviorEvent> events,
            List<BehaviorPattern> patterns,
            AttentionAnalysis attention) {

        // 专注度评分：基于平均专注时长和中断频率
        double focusScore = calculateFocusScore(attention);

        // 效率评分：有效学习时间 / 总时长
        double efficiencyScore = calculateEfficiencyScore(events);

        // 深度评分：基于互动深度（追问、查看解析、做笔记等）
        double depthScore = calculateDepthScore(events);

        // 持续性评分：基于学习时长和中断后的恢复行为
        double persistenceScore = calculatePersistenceScore(events, attention);

        double overall = (focusScore + efficiencyScore + depthScore + persistenceScore) / 4.0;

        return ScoreBreakdown.builder()
            .focus(BigDecimal.valueOf(focusScore).setScale(2, RoundingMode.HALF_UP))
            .efficiency(BigDecimal.valueOf(efficiencyScore).setScale(2, RoundingMode.HALF_UP))
            .depth(BigDecimal.valueOf(depthScore).setScale(2, RoundingMode.HALF_UP))
            .persistence(BigDecimal.valueOf(persistenceScore).setScale(2, RoundingMode.HALF_UP))
            .overall(BigDecimal.valueOf(overall).setScale(2, RoundingMode.HALF_UP))
```

### 4.4 服务端：会话回放数据组装

```java
/**
 * 回放数据组装服务
 */
@Service
public class SessionReplayService {

    @Autowired
    private LearningBehaviorEventMapper eventMapper;

    @Autowired
    private SessionReplaySnapshotMapper snapshotMapper;

    @Autowired
    private SessionDiagnosticReportMapper reportMapper;

    @Autowired
    private ReplayPermissionService permissionService;

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    /**
     * 获取会话回放数据
     */
    public ReplayDataDTO getReplayData(String sessionId, String viewerRole, Long viewerUserId) {
        // 1. 权限校验
        ReplayPermission perm = permissionService.checkPermission(
            sessionId, viewerRole, viewerUserId);

        if (!perm.isCanViewEvents()) {
            throw new BizException(ErrorCode.REPLAY_PERMISSION_DENIED);
        }

        // 2. 查缓存
        String cacheKey = String.format("replay:%s:%s", sessionId, viewerRole);
        ReplayDataDTO cached = (ReplayDataDTO) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return cached;
        }

        // 3. 加载事件时间线
        List<LearningBehaviorEvent> events = eventMapper.findBySessionIdOrderByEventSeq(sessionId);

        // 4. 根据角色脱敏
        events = redactByRole(events, perm);

        // 5. 提取高亮事件
        List<HighlightEvent> highlights = extractHighlights(events);

        // 6. 加载快照（按采样间隔）
        List<SnapshotDTO> snapshots = loadSnapshots(sessionId, events,
            perm.isCanViewSnapshots());

        // 7. 组装模块跳转序列
        List<ModuleSegment> moduleSequence = buildModuleSequence(events);

        // 8. 组装响应
        ReplayDataDTO result = ReplayDataDTO.builder()
            .sessionInfo(buildSessionInfo(sessionId))
            .timeline(TimelineDTO.builder()
                .totalEvents(events.size())
                .filteredEvents(events.size())
                .events(events.stream().map(this::toEventDTO).collect(Collectors.toList()))
                .highlights(highlights)
                .build())
            .snapshots(snapshots)
            .playConfig(PlayConfig.builder()
                .defaultSpeed(1.0)
                .availableSpeeds(List.of(0.5, 1.0, 2.0, 4.0, 8.0))
                .autoplay(true)
                .skipIdle(true)
                .idleThresholdMs(30000)
                .build())
            .build();

        // 9. 缓存（5分钟过期）
        redisTemplate.opsForValue().set(cacheKey, result, 5, TimeUnit.MINUTES);

        return result;
    }

    /**
     * 按角色脱敏
     */
    private List<LearningBehaviorEvent> redactByRole(
            List<LearningBehaviorEvent> events, ReplayPermission perm) {
        if ("SUMMARY_ONLY".equals(perm.getRedactionLevel())) {
            // 家长查看模式：仅保留摘要级事件，移除具体内容
            return events.stream()
                .filter(e -> isSummaryLevelEvent(e))
                .map(e -> redactContent(e))
                .collect(Collectors.toList());
        }
        return events;
    }

    private boolean isSummaryLevelEvent(LearningBehaviorEvent e) {
        return Set.of(
            "SESSION_START", "SESSION_END", "MODULE_ENTER", "MODULE_LEAVE",
            "PAGE_ENTER", "PAGE_LEAVE", "APP_BACKGROUND", "APP_FOREGROUND",
            "ANSWER_SUBMIT", "ANSWER_RESULT_SHOW", "CONTENT_COMPLETE",
            "TASK_COMPLETE", "IDLE_DETECTED", "FAST_SKIP"
        ).contains(e.getEventType());
    }
}
```

```
  ┌──────┐    start()    ┌──────────┐   events     ┌──────────┐  │

                             │                         │       │
                             │ app_background          │       │
                             ▼                         │       │
                        ┌──────────┐                   │       │
                        │ PAUSED   │ ── app_foreground ┘       │
                        └─────┬────┘                          │
                              │                               │
                              │ close()/timeout               │
                              ▼                               │
                        ┌──────────┐                          │
                        │ CLOSING  │                          │
                        └─────┬────┘                          │
                              │ events flushed                │
                              ▼                               │
                        ┌──────────┐                          │
                        │ ANALYZING│ (服务端诊断中)             │
                        └─────┬────┘
                              │ report generated            │
                              ▼                             │
                        ┌──────────┐                        │
                        │ COMPLETED│ ── re-analyze ──────────┘
                        └──────────┘
```

| 状态 | 说明 | 触发条件 |
| --- | --- | --- |
| IDLE | 空闲，无活跃会话 | 初始状态或会话结束后 |
| RECORDING | 正在录制行为事件 | `startSession()` 或收到首批事件 |
| PAUSED | 会话暂停（App切后台） | `APP_BACKGROUND` 事件 |
| CLOSING | 会话关闭中，正在上传剩余事件 | `closeSession()` 或超时(30分钟无事件) |
| ANALYZING | 服务端正在生成诊断报告 | 会话关闭后自动触发 |
| COMPLETED | 会话已完成，报告已生成 | 诊断分析完成 |

## 6. 错误处理与降级策略

### 6.1 错误码定义

| 错误码 | 说明 | 处理策略 |
| --- | --- | --- |
| SESSION_NOT_FOUND | 会话不存在 | 返回 404，客户端清除本地会话状态 |
| SESSION_ALREADY_CLOSED | 会话已关闭 | 幂等处理，返回成功 |
| SESSION_EVENT_SEQ_CONFLICT | 事件序号冲突 | 服务端自动重排序号 |
| REPLAY_PERMISSION_DENIED | 无回放权限 | 返回 403，提示用户无权查看 |
| DIAGNOSTIC_ANALYSIS_FAILED | 诊断分析失败 | 重试3次后降级为基础统计报告 |
| SNAPSHOT_STORAGE_FULL | 快照存储已满 | 停止快照采集，仅保留事件流 |
| EVENT_RATE_LIMIT_EXCEEDED | 事件上报频率超限 | 客户端降低采样率 |

### 6.2 客户端降级策略

```dart
class SessionRecorder {
  // 网络异常时的本地缓存策略
  static const int MAX_LOCAL_CACHE_SIZE = 500; // 最多缓存500条事件
  static const int LOCAL_CACHE_TTL_HOURS = 72; // 本地缓存72小时

  void onError(UploadError error) {
    switch (error.type) {
      case ErrorType.NETWORK_FAILURE:
        // 切换到本地缓存模式
        _eventQueue.enableLocalCache(
          maxSize: MAX_LOCAL_CACHE_SIZE,
          ttl: Duration(hours: LOCAL_CACHE_TTL_HOURS),
        );
        // 网络恢复后自动重试
        break;
      case ErrorType.RATE_LIMIT:
        // 降低采样率：从全量采集降级为关键事件采集
        _eventQueue.setFilter(EventFilter.KEY_EVENTS_ONLY);
        break;
      case ErrorType.SERVER_ERROR:
        // 暂停上报，保留本地缓存
        _uploader.pause();
        break;
    }
  }
}
```

### 6.3 服务端容错策略

| 场景 | 处理策略 |
| --- | --- |
| 事件批量写入失败 | 重试3次 → 写入死信队列 → 告警 |
| 诊断分析超时（>60秒） | 降级为基础统计报告（不含LLM评估） |
| 快照存储失败 | 忽略快照，仅保留事件流 |

| Redis 缓存失效 | 回源数据库查询 |

## 12. 总结

本模块填补了 PrimeTop 平台在学习行为**全链路录制与会话级回放**方面的空白。与现有的单模块行为追踪不同，它提供了跨模块的统一时间线视角，使教师、家长和系统能够回答**「学生是怎么学的？」**而不仅仅是**「学生学了什么？」**。

核心价值在于：
1. **过程可追溯**：完整记录学习过程，支持回放和复盘
2. **诊断更精准**：基于过程数据提供更深层的学情归因
3. **隐私可控**：多级脱敏和权限控制保障学生隐私
4. **闭环反馈**：将过程分析结果回流至推荐和干预系统，形成学习优化闭环
