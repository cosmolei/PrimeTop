# 智能组卷与自适应测试引擎 — 详细设计

> 版本：v1.0 | 更新：2026-05-23 | 状态：初稿

## 1. 概述

### 1.1 功能定位

智能组卷与自适应测试引擎（Intelligent Test Assembly & Adaptive Testing Engine）是 PrimeTop 学习闭环中的核心测评子系统。它负责：

1. **智能组卷**：根据用户需求（知识点范围、难度分布、题型比例、时间限制）从题库中自动选编一套试卷。
2. **自适应测试（CAT）**：在作答过程中根据学生的实时表现动态调整后续题目的难度，用更少的题目精准定位学生的能力水平。
3. **测评分析**：测试结束后输出详细的能力诊断报告，包括知识点掌握度、能力区间估计、薄弱项标注。

### 1.2 与其他模块的关系

```
题目与题库服务 ──────→ 智能组卷引擎 ──────→ 考试模拟与真题练习系统
     ↑                     │                         │
     │                     ↓                         ↓
题目难度标定 ─────── 自适应测试引擎 ──────→ 学习记录与进度追踪
     │                     │                         │
     ↓                     ↓                         ↓
知识点体系 ─────── 测评分析引擎 ───────→ 学情分析 & 学习报告
```

| 关联模块 | 交互方式 | 说明 |
|---------|---------|------|
| 题目与题库服务 | 读题库 | 获取候选题目及其元数据（难度、知识点、题型） |
| 题目难度标定与能力评估模型 | 读取难度参数、IRT 参数 | 题目区分度、猜测参数、难度系数 |
| 知识点体系与教材映射引擎 | 读取知识点树 | 确定知识点覆盖范围与层级关系 |
| 考试模拟与真题练习系统 | 提供试卷数据 | 组卷结果交付给考试模拟模块进行前端渲染 |
| 学习记录与进度追踪服务 | 写入测评记录 | 测评结果持久化 |
| 学情分析 | 写入能力估计 | 更新学生知识掌握度 |
| 自适应学习与个性化推荐引擎 | 触发 | 测评结果驱动学习路径调整 |

### 1.3 设计目标

| 指标 | 目标值 |
|------|--------|
| 组卷响应时间 | ≤ 3 秒（100 题以内） |
| CAT 能力估计精度 | 误差 ≤ 0.3 logit（约 5% 能力偏差） |
| CAT 收敛题数 | ≤ 25 题（标准差 < 0.5） |
| 知识点覆盖率 | ≥ 设定目标的 90% |
| 并发组卷支持 | ≥ 500 QPS |

## 2. 核心概念与数据模型

### 2.1 关键术语

| 术语 | 定义 |
|------|------|
| IRT（Item Response Theory） | 项目反应理论，基于概率模型估计被试能力和题目参数 |
| 能力值 θ（Theta） | 学生潜在能力的估计值，通常为标准正态分布尺度（均值 0，标准差 1） |
| 难度参数 b | IRT 三参数模型中的题目难度，与 θ 在同一尺度上 |
| 区分度参数 a | 题目区分高能力与低能力学生的效力 |
| 猜测参数 c | 低能力学生凭猜测答对的概率 |
| 信息函数 I(θ) | Fisher 信息量，衡量题目在特定能力水平上的测量精度 |
| Testlet | 一组共享题干的题目（如阅读理解），需作为整体编排 |
| 曝光度 | 题目在测试中出现的频率，需控制以防止题目泄露 |
| Blueprint | 试卷蓝图，定义知识点、题型、难度的约束条件 |

```typescript
interface TestBlueprint {
  id: string;                          // 蓝图 ID
  name: string;                        // 蓝图名称，如 "高二数学期中测试"
  description?: string;

  // 基本约束
  totalQuestions: number;              // 总题数
  totalTimeMinutes: number;            // 总时长（分钟）
  subjectId: string;                   // 学科 ID
  gradeId: string;                     // 年级 ID
  textbookId?: string;                 // 教材版本 ID（可选）

  // 知识点覆盖约束
  knowledgePointSpecs: KnowledgePointSpec[];

  // 题型分布约束
  questionTypeSpecs: QuestionTypeSpec[];

  // 难度分布约束
  difficultyDistribution: DifficultyDistribution;

  // 自适应测试配置（可选）
  adaptiveConfig?: AdaptiveConfig;

  // 排重与防曝光
  excludeQuestionIds?: string[];       // 排除的题目 ID（如已做过的题）
  maxExposureRate?: number;            // 最大曝光率阈值，默认 0.3

  // Testlet 约束
  testletSpecs?: TestletSpec[];
}

interface KnowledgePointSpec {
  knowledgePointId: string;            // 知识点 ID（支持多级）
  minQuestions: number;                // 最少题数
  maxQuestions: number;                // 最多题数
  weight?: number;                     // 权重（0-1），影响选题优先级
}

interface QuestionTypeSpec {
  questionType: QuestionType;          // 题型枚举
  minQuestions: number;
  maxQuestions: number;
  pointsPerQuestion?: number;          // 每题分值
}

interface DifficultyDistribution {
  // 定义各难度区间的题目数量范围
  ranges: DifficultyRange[];
}

interface DifficultyRange {
  label: string;                       // 如 "基础"、"中等"、"较难"、"挑战"
  minDifficulty: number;               // 难度下界（b 参数）
  maxDifficulty: number;               // 难度上界
  minQuestions: number;
  maxQuestions: number;
}

interface AdaptiveConfig {
  enabled: boolean;
  mode: 'full_adaptive' | 'multi_stage' | 'linear_on_the_fly';
  initialThetaEstimate?: number;       // 初始 θ 估计（可从历史数据获取）
  terminationCriteria: TerminationCriteria;
  itemSelectionStrategy: ItemSelectionStrategy;
}

interface TerminationCriteria {
  maxQuestions: number;                // 最大题数
  minQuestions: number;                // 最少题数（至少做几题才允许结束）
  targetSE: number;                    // 目标标准误差（如 0.3）
  maxTimeMinutes?: number;             // 最大时间
}

interface ItemSelectionStrategy {
  method: 'mfi' | 'kullback_leibler' | 'random' | 'weighted_random';
  // mfi = Maximum Fisher Information（最大信息量）
  // kullback_leibler = KL 信息量
  exposureControlEnabled: boolean;
  contentBalancingEnabled: boolean;    // 是否做知识点均衡
}

interface TestletSpec {
  testletId: string;
  minCount: number;                    // 至少选几个 testlet
  maxCount: number;
}

type QuestionType =
  | 'single_choice'       // 单选
  | 'multi_choice'        // 多选
  | 'true_false'          // 判断
  | 'fill_blank'          // 填空
  | 'short_answer'        // 简答
  | 'calculation'         // 计算
  | 'essay'               // 作文/论述
  | 'proof'               // 证明
  | 'reading_comprehension' // 阅读理解（testlet）
  | 'cloze';              // 完形填空
```

## 3. 智能组卷引擎

### 3.1 组卷算法概述

智能组卷本质是一个**约束满足问题（CSP）**，需要同时满足：
- 知识点覆盖约束
- 题型分布约束
- 难度分布约束
- Testlet 整体性约束
- 题目不重复、不超曝光率
- 试卷信息量最大化

采用**贪心搜索 + 回溯**策略，在可接受时间内找到近似最优解。

### 3.2 组卷流程

```
┌──────────────┐
│  输入蓝图     │
└──────┬───────┘
       ↓
┌──────────────┐     ┌───────────────────────┐
│ 1. 解析蓝图  │────→│  提取所有约束条件       │
│    约束条件   │     │  生成约束检查器         │
└──────┬───────┘     └───────────────────────┘
       ↓
┌──────────────┐     ┌───────────────────────┐
│ 2. 候选池构建 │────→│  按约束过滤题库        │
│              │     │  排除已用题/高曝光题    │
└──────┬───────┘     └───────────────────────┘
       ↓
┌──────────────┐     ┌───────────────────────┐
│ 3. 分阶段选题 │────→│  按 Testlet → 题型 →  │
│              │     │  知识点 → 难度 优先级   │
└──────┬───────┘     └───────────────────────┘
       ↓
┌──────────────┐     ┌───────────────────────┐
│ 4. 约束验证  │────→│  检查所有约束是否满足   │
│    & 调整     │     │  不满足则回溯重选       │
└──────┬───────┘     └───────────────────────┘
       ↓
┌──────────────┐     ┌───────────────────────┐
│ 5. 局部优化  │────→│  替换低信息量题目      │
│              │     │  优化整体信度           │
└──────┬───────┘     └───────────────────────┘
       ↓
┌──────────────┐
│ 6. 输出试卷  │
└──────────────┘
```

### 3.3 核心算法实现

#### 3.3.1 贪心选题（TypeScript 伪代码）

```typescript
class TestAssemblyEngine {
  /**
   * 核心组卷方法
   * @param blueprint 试卷蓝图
   * @param candidatePool 候选题目池（已预过滤）
   * @returns 组卷结果
   */
  assemble(blueprint: TestBlueprint, candidatePool: Question[]): AssemblyResult {
    const state: AssemblyState = {
      selectedQuestions: [],
      remainingConstraints: this.flattenConstraints(blueprint),
      usedQuestionIds: new Set(blueprint.excludeQuestionIds ?? []),
      attempts: 0,
      maxAttempts: 5000,
    };

    // 阶段 1：优先选择 Testlet（阅读理解等共享题干组）
    if (blueprint.testletSpecs) {
      this.selectTestlets(state, blueprint, candidatePool);
    }

    // 阶段 2：按题型分组贪心选择
    for (const typeSpec of blueprint.questionTypeSpecs) {
      this.selectByType(state, typeSpec, candidatePool, blueprint);
    }

    // 阶段 3：补充知识点覆盖不足
    this.ensureKnowledgeCoverage(state, blueprint, candidatePool);

    // 阶段 4：局部优化——替换低贡献题目
    this.localOptimize(state, blueprint, candidatePool);

    // 验证
    const violations = this.validateConstraints(state, blueprint);
    if (violations.length > 0) {
      // 尝试修复
      const repaired = this.attemptRepair(state, violations, candidatePool, blueprint);
      if (!repaired) {
        return { success: false, violations, paper: null };
      }
    }

    const paper = this.buildPaper(state, blueprint);
    return { success: true, violations: [], paper };
  }

  /**
   * 选题评分函数——综合考虑信息量、曝光率、约束紧迫度
   */
  private scoreQuestion(
    question: Question,
    state: AssemblyState,
    blueprint: TestBlueprint
  ): number {
    const irt = question.irtParams;
    // 假设学生 θ = 0（均未知的组卷场景），计算该题在 θ=0 处的信息量
    const info = this.fisherInformation(irt, 0);

    // 曝光惩罚：曝光率越高的题越不倾向选
    const exposurePenalty = irt.exposureCount > (blueprint.maxExposureRate ?? 0.3) * 10000
      ? 0.1 : 1.0;

    // 约束紧迫度：该题能满足多少尚未满足的约束
    const urgencyBonus = this.constraintUrgency(question, state.remainingConstraints);

    return info * 0.4 + urgencyBonus * 0.4 + exposurePenalty * 0.2;
  }

  /**
   * Fisher 信息量计算（3PL 模型）
   */
  private fisherInformation(irt: QuestionIRTParams, theta: number): number {
    const { discrimination: a, difficulty: b, guessing: c } = irt;
    const p = this.threePLProbability(a, b, c, theta);
    const q = 1 - p;
    const numerator = a * a * (p - c) * (p - c) * q;
    const denominator = p * p * (1 - c) * (1 - c);
    return numerator / denominator;
  }

  /**
   * 3PL 概率函数 P(θ) = c + (1-c) / (1 + exp(-Da(θ-b)))
   * D = 1.702（缩放常数，使逻辑斯蒂模型近似正态卵形模型）
   */
  private threePLProbability(a: number, b: number, c: number, theta: number): number {
    const D = 1.702;
    const exponent = -D * a * (theta - b);
    return c + (1 - c) / (1 + Math.exp(exponent));
  }
}
```

#### 3.3.2 回溯策略

```typescript
class BacktrackAssembler {
  /**
   * 当贪心算法无法满足约束时，使用受限回溯
   * 最多回溯 K 步（默认 K=10），避免组合爆炸
   */
  assembleWithBacktrack(
    blueprint: TestBlueprint,
    candidatePool: Question[],
    maxBacktrackDepth: number = 10
  ): AssemblyResult {
    let bestResult: AssemblyResult | null = null;
    let bestScore = -Infinity;

    // 多次随机贪心 + 局部搜索
    for (let trial = 0; trial < 20; trial++) {
      // 随机打乱候选池顺序增加多样性
      const shuffled = this.shuffleWithWeight(candidatePool, trial);
      const result = this.greedyAssemble(blueprint, shuffled);

      if (result.success) {
        const score = this.evaluatePaper(result.paper!, blueprint);
        if (score > bestScore) {
          bestScore = score;
          bestResult = result;
          break; // 找到满意解即停
        }
      }
    }

    if (bestResult) return bestResult;

    // 回溯搜索（受限深度）
    return this.backtrackSearch(blueprint, candidatePool, maxBacktrackDepth);
  }

  /**
   * 试卷评分——综合信息量、覆盖度、分布均衡度
   */
  private evaluatePaper(paper: GeneratedTestPaper, blueprint: TestBlueprint): number {
    let score = 0;

    // 1. 总信息量（越高越好）
    const totalInfo = paper.sections
      .flatMap(s => s.questions)
      .reduce((sum, q) => sum + this.fisherInfo(q.questionSnapshot.difficulty), 0);
    score += Math.min(totalInfo / 10, 1) * 0.3;

    // 2. 知识点覆盖率
    const coveredKps = new Set(
      paper.sections.flatMap(s => s.questions).flatMap(q => q.questionSnapshot.knowledgePointIds)
    );
    const requiredKps = blueprint.knowledgePointSpecs.map(s => s.knowledgePointId);
    const coverageRate = requiredKps.length > 0
      ? coveredKps.size / requiredKps.length : 1;
    score += coverageRate * 0.4;

    // 3. 难度分布匹配度
    const diffMatch = this.difficultyDistributionScore(paper, blueprint);
    score += diffMatch * 0.3;

    return score;
  }
}
```

#### 3.3.3 曝光度控制

Sympson-Hetter 替代法：每次选题时以概率 p 选入高曝光题。

```typescript
class ExposureController {
  /**
   * 计算题目的选中概率上限
   * 基于 Sympson-Hetter 方法：控制题目在最终试卷中出现的概率
   */
  calculateSelectionProbability(
    question: QuestionIRTParams,
    targetExposureRate: number  // 通常 0.2 ~ 0.4
  ): number {
    // 如果当前曝光率低于目标，不限制
    if (question.usageCount === 0) return 1.0;
    const currentRate = question.exposureCount / question.usageCount;
    if (currentRate < targetExposureRate) return 1.0;
    // 否则按比例降低选中概率
    return Math.max(0.1, targetExposureRate / currentRate);
  }

  /**
   * 在候选题目中执行概率筛选
   */
  filterByExposure(
    candidates: Question[],
    targetRate: number,
    requiredCount: number
  ): Question[] {
    // 先按信息量排序
    const sorted = candidates.sort((a, b) =>
      this.fisherInformation(b.irtParams, 0) - this.fisherInformation(a.irtParams, 0)
    );

    const selected: Question[] = [];
    for (const q of sorted) {
      if (selected.length >= requiredCount) break;
      const prob = this.calculateSelectionProbability(q.irtParams, targetRate);
      if (Math.random() < prob) {
        selected.push(q);
      }
    }
    return selected;
  }
}
```

### 4.2 θ 估计方法

采用 **EAP（Expected A Posteriori）** 贝叶斯估计法，计算效率高、适用于实时场景。

```python
import numpy as np
from scipy import integrate


class ThetaEstimator:
    """基于 EAP 的 θ 估计器"""

    # 先验分布：标准正态 N(0,1)
    PRIOR_MEAN = 0.0
    PRIOR_SD = 1.0

    # 数值积分配置
    QUADRATURE_POINTS = 41        # 积分点数
    QUADRATURE_RANGE = (-4.0, 4.0)

    def __init__(self):
        # 预计算积分锚点和权重
        self.q_points = np.linspace(
            self.QUADRATURE_RANGE[0],
            self.QUADRATURE_RANGE[1],
            self.QUADRATURE_POINTS,
        )
        self.q_weights = np.ones(self.QUADRATURE_POINTS) / self.QUADRATURE_POINTS

    def estimate(
        self,
        responses: list[tuple[float, float, float, bool]],  # (a, b, c, is_correct)
        prior_mean: float = 0.0,
        prior_sd: float = 1.0,
    ) -> tuple[float, float]:
        """
        EAP 估计 θ 和 SE
        
        Args:
            responses: [(a, b, c, is_correct), ...] 答题记录
            prior_mean: 先验均值
            prior_sd: 先验标准差
            
        Returns:
            (theta_estimate, standard_error)
        """
        # 后验分布 g(θ) ∝ L(θ) × φ(θ)
        posterior = np.array([
            self._likelihood(theta, responses) * self._prior(theta, prior_mean, prior_sd)
            for theta in self.q_points
        ])

        # 归一化
        total = np.sum(posterior * self.q_weights)
        if total < 1e-300:
            return prior_mean, prior_sd
        posterior /= total

        # EAP: θ̂ = Σ θ_i × g(θ_i) × Δθ
        theta_hat = np.sum(self.q_points * posterior * self.q_weights)

        # SE = sqrt(Σ (θ_i - θ̂)² × g(θ_i) × Δθ)
        variance = np.sum(
            (self.q_points - theta_hat) ** 2 * posterior * self.q_weights
        )
        se = np.sqrt(max(variance, 0.0))

        return float(theta_hat), float(se)

    def update_incremental(
        self,
        current_theta: float,
        current_se: float,
        a: float,
        b: float,
        c: float,
        is_correct: bool,
    ) -> tuple[float, float]:
        """
        增量更新 θ 估计（单题更新，无需重算全部）
        适用于 CAT 中每答一题后快速更新
        """
        # 用当前后验作为新的先验
        new_prior_mean = current_theta
        new_prior_sd = min(current_se, 1.0)  # 限制先验宽度

        # 只需用最新一题的作答
        return self.estimate(
            [(a, b, c, is_correct)],
            prior_mean=new_prior_mean,
            prior_sd=new_prior_sd,
        )

    def _likelihood(
        self,
        theta: float,
        responses: list[tuple[float, float, float, bool]],
    ) -> float:
        """计算似然函数 L(θ)"""
        D = 1.702
        log_L = 0.0
        for a, b, c, is_correct in responses:
            exp_val = np.exp(-D * a * (theta - b))
            p = c + (1 - c) / (1 + exp_val)
            p = np.clip(p, 1e-10, 1 - 1e-10)
            if is_correct:
                log_L += np.log(p)
            else:
                log_L += np.log(1 - p)
        return np.exp(log_L)

    def _prior(self, theta: float, mean: float, sd: float) -> float:
        """先验概率密度 φ(θ)"""
        return (
            1.0 / (sd * np.sqrt(2 * np.pi))
            * np.exp(-0.5 * ((theta - mean) / sd) ** 2)
        )
```

### 4.3 选题策略

#### 4.3.1 最大信息量法（MFI）

```python
class MFISelector:
    """Maximum Fisher Information 选题策略"""

    def select_next(
        self,
        current_theta: float,
        candidate_pool: list,     # 未使用的题目
        content_balancer: 'ContentBalancer | None' = None,
        exposure_controller: 'ExposureController | None' = None,
    ) -> object:
        """
        选择信息量最大的题目
        """
        # 计算每道题在当前 θ 处的信息量
        scored = []
        for q in candidate_pool:
            info = self._fisher_info(q.irt_params, current_theta)

            # 曝光控制加权
            if exposure_controller:
                exposure_prob = exposure_controller.get_selection_prob(q)
                info *= exposure_prob

            scored.append((q, info))

        # 按信息量降序排列
        scored.sort(key=lambda x: x[1], reverse=True)

        # 内容均衡：如果存在未充分覆盖的知识点，优先从该知识点中选题
        if content_balancer:
            undercovered_kps = content_balancer.get_undercovered_kps()
            if undercovered_kps:
                # 在信息量 top-N 中选择覆盖未充分知识点的题目
                top_n = scored[:min(20, len(scored))]
                for q, info in top_n:
                    kp_ids = set(q.knowledge_point_ids)
                    if kp_ids & undercovered_kps:
                        return q

        return scored[0][0] if scored else None

    def _fisher_info(self, irt_params, theta: float) -> float:
        a, b, c = irt_params.discrimination, irt_params.difficulty, irt_params.guessing
        D = 1.702
        p = c + (1 - c) / (1 + np.exp(-D * a * (theta - b)))
        q = 1 - p
        num = (a ** 2) * ((p - c) ** 2) * q
        den = (p ** 2) * ((1 - c) ** 2)
        return num / den if den > 0 else 0.0
```

#### 4.3.2 内容均衡器

```python
class ContentBalancer:
    """确保自适应测试覆盖所需知识点"""

    def __init__(self, knowledge_point_specs: list, total_max_questions: int):
        # 每个知识点应出现的题目数量
        self.target_counts = {}
        for spec in knowledge_point_specs:
            target = max(spec.min_questions,
                         int(total_max_questions * spec.weight))
            self.target_counts[spec.knowledge_point_id] = target
        self.current_counts: dict[str, int] = {}

    def record_question(self, knowledge_point_ids: list[str]):
        for kp_id in knowledge_point_ids:
            self.current_counts[kp_id] = self.current_counts.get(kp_id, 0) + 1

    def get_undercovered_kps(self) -> set[str]:
        """返回尚未达到最低覆盖的知识点集合"""
        undercovered = set()
        for kp_id, target in self.target_counts.items():
            current = self.current_counts.get(kp_id, 0)
            if current < target:
                undercovered.add(kp_id)
        return undercovered

    def get_priority_kps(self) -> list[str]:
        """返回按缺口大小排序的知识点（缺口大的优先）"""
        gaps = []
        for kp_id, target in self.target_counts.items():
            current = self.current_counts.get(kp_id, 0)
            gap = target - current
            if gap > 0:
                gaps.append((kp_id, gap))
        gaps.sort(key=lambda x: x[1], reverse=True)
        return [kp_id for kp_id, _ in gaps]
```

```python
# services/adaptive_test_service.py

from datetime import datetime

logger = logging.getLogger(__name__)


class AdaptiveTestService:
    """自适应测试会话管理服务"""

    def __init__(
        self,
        session_repo: AssessmentSessionRepository,
        question_repo: QuestionRepository,
        irt_repo: IRTParamsRepository,
        theta_estimator: ThetaEstimator,
    ):
        self.session_repo = session_repo
        self.question_repo = question_repo
        self.irt_repo = irt_repo
        self.theta_estimator = theta_estimator
        self.selector = MFISelector()

    def start_session(
        self,
        test_paper_id: str,
        user_id: str,
        initial_theta: float = 0.0,
    ) -> dict:
        """
        开始自适应测试会话
        
        Returns:
            { session_id, first_question }
        """
        session = AssessmentSession.create(
            test_paper_id=test_paper_id,
            user_id=user_id,
        )

        # 初始化自适应状态
        adaptive_state = AdaptiveSessionState(
            current_theta=initial_theta,
            current_se=1.0,  # 初始不确定性较高
            completed_questions=0,
            response_pattern=[],
            administered_question_ids=[],
            terminated=False,
        )
        session.adaptive_state = adaptive_state.to_dict()
        self.session_repo.save(session)

        # 选择第一题
        first_question = self._select_next_question(
            session, adaptive_state
        )

        return {
            'session_id': session.id,
            'first_question': first_question,
            'theta': adaptive_state.current_theta,
            'se': adaptive_state.current_se,
        }

    def submit_response(
        self,
        session_id: str,
        question_id: str,
        is_correct: bool,
        response_time_seconds: float = None,
    ) -> dict:
        """
        提交一题的作答结果，返回更新后的状态和下一题（或结束信号）
        
        Returns:
            { theta, se, next_question, terminated, termination_reason }
        """
        session = self.session_repo.get(session_id)
        state = AdaptiveSessionState.from_dict(session.adaptive_state)

        # 获取 IRT 参数
        irt = self.irt_repo.get(question_id)

        # 记录答题
        theta_before = state.current_theta
        se_before = state.current_se

        response = {
            'question_id': question_id,
            'is_correct': is_correct,
            'response_time': response_time_seconds,
            'theta_before': theta_before,
            'se_before': se_before,
        }

        # 增量更新 θ
        new_theta, new_se = self.theta_estimator.update_incremental(
            current_theta=state.current_theta,
            current_se=state.current_se,
            a=irt.discrimination,
            b=irt.difficulty,
            c=irt.guessing,
            is_correct=is_correct,
        )

        response['theta_after'] = new_theta
        response['se_after'] = new_se
        response['question_info'] = self._calc_fisher_info(irt, theta_before)

        # 更新状态
        state.current_theta = new_theta
        state.current_se = new_se
        state.completed_questions += 1
        state.response_pattern.append(response)
        state.administered_question_ids.append(question_id)

        # 检查终止条件
        terminated, reason = self._check_termination(session, state)
        state.terminated = terminated
        if terminated:
            state.termination_reason = reason
            session.status = 'completed'
            session.completed_at = datetime.utcnow()

        session.adaptive_state = state.to_dict()
        self.session_repo.save(session)

        result = {
            'theta': new_theta,
            'se': new_se,
            'completed_questions': state.completed_questions,
            'terminated': terminated,
            'termination_reason': reason if terminated else None,
        }

        if not terminated:
            next_q = self._select_next_question(session, state)
            result['next_question'] = next_q

        return result

    def _check_termination(
        self,
        session: AssessmentSession,
        state: AdaptiveSessionState,
    ) -> tuple[bool, str | None]:
        """检查是否满足终止条件"""
        # 获取蓝图中的终止配置
        paper = self._get_paper(session.test_paper_id)
        config = paper.blueprint.adaptive_config
        criteria = config.termination_criteria

        # 1. 最大题数
        if state.completed_questions >= criteria.max_questions:
            return True, 'max_questions'

        # 2. 目标精度（仅当最少题数已满足）
        if (state.completed_questions >= criteria.min_questions
                and state.current_se <= criteria.target_se):
            return True, 'target_se'

        # 3. 超时
        if criteria.max_time_minutes:
            elapsed = (datetime.utcnow() - session.started_at).total_seconds() / 60
            if elapsed >= criteria.max_time_minutes:
                return True, 'timeout'

        return False, None

    def _select_next_question(
        self,
        session: AssessmentSession,
        state: AdaptiveSessionState,
    ) -> dict:
        """为当前状态选择下一道最佳题目"""
        paper = self._get_paper(session.test_paper_id)
        blueprint = paper.blueprint

        # 构建候选池（排除已用题）
        used_ids = set(state.administered_question_ids)
        candidates = self.question_repo.find_candidates_for_adaptive(
            subject_id=blueprint.subject_id,
            grade_id=blueprint.grade_id,
            exclude_ids=used_ids,
            theta=state.current_theta,  # 在 θ±1 范围内筛选
            theta_range=1.5,
        )

        # 获取 IRT 参数
        irt_map = self.irt_repo.batch_get([q.id for q in candidates])
        for q in candidates:
            q.irt_params = irt_map.get(q.id)

        # 内容均衡
        content_balancer = ContentBalancer(
            knowledge_point_specs=blueprint.knowledge_point_specs,
            total_max_questions=blueprint.adaptive_config.termination_criteria.max_questions,
        )
        # 回放已答题的知识点
        for resp in state.response_pattern:
            q = self.question_repo.get(resp['question_id'])
            content_balancer.record_question(q.knowledge_point_ids)

        # 曝光控制
        exposure_ctrl = ExposureController(
            target_rate=blueprint.max_exposure_rate or 0.3
        )

        # 选题
        next_q = self.selector.select_next(
            current_theta=state.current_theta,
            candidate_pool=candidates,
            content_balancer=content_balancer,
            exposure_controller=exposure_ctrl,
        )

        if not next_q:
            logger.warning(f"CAT 候选题用尽: session={session.id}")
            return None

        return {
            'question_id': next_q.id,
            'question_type': next_q.question_type,
            'stem': next_q.stem,
            'options': next_q.options,
            'images': next_q.images,
            'knowledge_point_ids': next_q.knowledge_point_ids,
            'points': next_q.points,
        }

    @staticmethod
    def _calc_fisher_info(irt, theta: float) -> float:
        D = 1.702
        a, b, c = irt.discrimination, irt.difficulty, irt.guessing
        p = c + (1 - c) / (1 + np.exp(-D * a * (theta - b)))
        q = 1 - p
        num = (a ** 2) * ((p - c) ** 2) * q
        den = (p ** 2) * ((1 - c) ** 2)
        return num / den if den > 0 else 0.0
```

```python
# services/assessment_report_service.py

import logging
from datetime import datetime

from models.assessment_report import AssessmentReport
from models.assessment_session import AssessmentSession
from engines.theta_estimator import ThetaEstimator
from repositories.session_repo import AssessmentSessionRepository
from repositories.report_repo import AssessmentReportRepository
from repositories.knowledge_point_repo import KnowledgePointRepository
from event_bus import publish_event

logger = logging.getLogger(__name__)


class AssessmentReportService:
    """测评报告生成服务"""

    def __init__(
        self,
        session_repo: AssessmentSessionRepository,
        report_repo: AssessmentReportRepository,
        kp_repo: KnowledgePointRepository,
        theta_estimator: ThetaEstimator,
    ):
        self.session_repo = session_repo
        self.report_repo = report_repo
        self.kp_repo = kp_repo
        self.theta_estimator = theta_estimator

    def generate_report(self, session_id: str) -> AssessmentReport:
        """根据测评会话生成完整报告"""
        session = self.session_repo.get(session_id)
        if session.status != 'completed':
            raise ValueError(f"Session {session_id} is not completed")

        state = session.adaptive_state
        responses = state['response_pattern']

        # 1. 总分计算
        total_score = sum(
            r.get('points_earned', 0) for r in responses
        )
        total_possible = sum(
            r.get('points_possible', 0) for r in responses
        )

        # 2. θ 最终估计
        theta = state['current_theta']
        se = state['current_se']

        # 3. 知识点维度分析
        kp_results = self._analyze_by_knowledge_points(responses)

        # 4. 题型维度分析
        type_results = self._analyze_by_question_type(responses)

        # 5. 难度维度分析
        diff_results = self._analyze_by_difficulty(responses)

        # 6. 时间分析
        time_analysis = self._analyze_time(responses)

        # 7. 诊断建议
        strengths, weaknesses, recommendations = self._generate_diagnostics(
            kp_results, diff_results, theta
        )

        # 8. 构建报告
        report = AssessmentReport(
            session_id=session_id,
            user_id=session.user_id,
            test_paper_id=session.test_paper_id,
            total_score=total_score,
            total_possible=total_possible,
            theta_estimate=theta,
            theta_se=se,
            theta_ci_lower=theta - 1.96 * se,
            theta_ci_upper=theta + 1.96 * se,
            knowledge_point_results=kp_results,
            question_type_results=type_results,
            difficulty_results=diff_results,
            time_analysis=time_analysis,
            strengths=strengths,
            weaknesses=weaknesses,
            recommendations=recommendations,
        )

        self.report_repo.save(report)

        # 更新 session 关联
        session.report_id = report.id
        self.session_repo.save(session)

        # 发布事件
        publish_event('assessment.completed', {
            'user_id': session.user_id,
            'report_id': report.id,
            'theta': theta,
            'se': se,
            'weakness_kp_ids': [w['knowledge_point_id'] for w in weaknesses],
        })

        logger.info(
            f"Report generated: report_id={report.id}, "
            f"theta={theta:.3f}, se={se:.3f}"
        )

        return report

    def _analyze_by_knowledge_points(self, responses: list) -> list:
        """知识点维度分析"""
        kp_stats: dict[str, dict] = {}

        for r in responses:
            for kp_id in r.get('knowledge_point_ids', []):
                if kp_id not in kp_stats:
                    kp_stats[kp_id] = {'total': 0, 'correct': 0}
                kp_stats[kp_id]['total'] += 1
                if r.get('is_correct'):
                    kp_stats[kp_id]['correct'] += 1

        results = []
        for kp_id, stats in kp_stats.items():
            accuracy = stats['correct'] / stats['total'] if stats['total'] > 0 else 0
            mastery = self._classify_mastery(accuracy)
            kp = self.kp_repo.get(kp_id)
            results.append({
                'knowledge_point_id': kp_id,
                'knowledge_point_name': kp.name if kp else kp_id,
                'total_questions': stats['total'],
                'correct_count': stats['correct'],
                'accuracy': round(accuracy, 4),
                'mastery_level': mastery,
            })

        return results

    def _analyze_by_question_type(self, responses: list) -> list:
        """题型维度分析"""
        type_stats: dict[str, dict] = {}
        for r in responses:
            qt = r.get('question_type', 'unknown')
            if qt not in type_stats:
                type_stats[qt] = {'total': 0, 'correct': 0}
            type_stats[qt]['total'] += 1
            if r.get('is_correct'):
                type_stats[qt]['correct'] += 1

        return [
            {
                'question_type': qt,
                'total_questions': s['total'],
                'correct_count': s['correct'],
                'accuracy': round(s['correct'] / s['total'], 4),
            }
            for qt, s in type_stats.items()
        ]

    def _analyze_by_difficulty(self, responses: list) -> list:
        """难度维度分析"""
        ranges = [
            ('基础', -3.0, -0.5),
            ('中等', -0.5, 0.5),
            ('较难', 0.5, 1.5),
            ('挑战', 1.5, 3.0),
        ]
        results = []
        for label, low, high in ranges:
            matched = [
                r for r in responses
                if low <= r.get('difficulty', 0) < high
            ]
            total = len(matched)
            correct = sum(1 for r in matched if r.get('is_correct'))
            results.append({
                'difficulty_range': label,
                'total_questions': total,
                'correct_count': correct,
                'accuracy': round(correct / total, 4) if total > 0 else 0,
            })
        return results

    def _analyze_time(self, responses: list) -> dict:
        """时间分析"""
        times = [r.get('response_time', 0) for r in responses if r.get('response_time')]
        if not times:
            return {'total_seconds': 0, 'avg_per_question': 0}

        return {
            'total_seconds': sum(times),
            'avg_per_question': round(sum(times) / len(times), 1),
            'by_difficulty': self._avg_time_by_difficulty(responses),
        }

    def _generate_diagnostics(
        self,
        kp_results: list,
        diff_results: list,
        theta: float,
    ) -> tuple:
        """生成诊断建议"""
        strengths = []
        weaknesses = []
        recommendations = []

        for kp in kp_results:
            if kp['accuracy'] >= 0.8:
                strengths.append({
                    'knowledge_point_id': kp['knowledge_point_id'],
                    'knowledge_point_name': kp['knowledge_point_name'],
                    'evidence': f"正确率 {kp['accuracy']*100:.0f}%，掌握良好",
                    'severity': 'info',
                })
            elif kp['accuracy'] < 0.5:
                weaknesses.append({
                    'knowledge_point_id': kp['knowledge_point_id'],
                    'knowledge_point_name': kp['knowledge_point_name'],
                    'evidence': f"正确率仅 {kp['accuracy']*100:.0f}%，建议重点复习",
                    'severity': 'critical' if kp['accuracy'] < 0.3 else 'warning',
                })
                recommendations.append(
                    f"建议针对「{kp['knowledge_point_name']}」进行专项练习，"
                    f"先巩固基础概念再提升解题技巧"
                )

        # 全局建议
        if theta < -1.0:
            recommendations.append("整体能力偏低，建议从基础知识开始系统复习")
        elif theta > 1.0:
            recommendations.append("整体能力较强，建议挑战更高难度的拓展题目")

        if not recommendations:
            recommendations.append("表现均衡，继续保持当前学习节奏")

        return strengths, weaknesses, recommendations

    @staticmethod
    def _classify_mastery(accuracy: float) -> str:
        if accuracy >= 0.9:
            return 'excellent'
        elif accuracy >= 0.7:
            return 'good'
        elif accuracy >= 0.5:
            return 'fair'
        elif accuracy >= 0.3:
            return 'weak'
        else:
            return 'critical'
```

## 8. 错误处理

### 8.1 错误码体系

| 错误码 | HTTP | 含义 | 处理建议 |
|--------|------|------|----------|
| ASSESS_001 | 400 | 蓝图不存在或已归档 | 检查蓝图 ID |
| ASSESS_002 | 400 | 蓝图约束冲突（如总题数与题型分配不一致） | 修改蓝图 |
| ASSESS_003 | 409 | 组卷失败——候选题不足 | 放宽约束或补充题库 |
| ASSESS_004 | 408 | 组卷超时（>5s） | 重试或使用兜底试卷 |
| ASSESS_005 | 400 | 无效的题目 ID（作答提交时） | 检查请求 |
| ASSESS_006 | 409 | 会话已结束，无法继续作答 | 新建会话 |
| ASSESS_007 | 409 | 会话不存在或已过期 | 检查 session ID |
| ASSESS_008 | 400 | 未达到最少题数，无法结束 | 继续答题 |
| ASSESS_009 | 422 | IRT 参数缺失——题目未经标定 | 补充标定数据 |
| ASSESS_010 | 500 | 报告生成失败 | 重试 |
| ASSESS_011 | 429 | 组卷频率限制 | 稍后重试 |

### 8.2 降级策略

| 场景 | 降级方案 |
|------|----------|
| IRT 参数缺失 | 退化为经典测量理论（CTT），使用正确率代替 θ 估计 |
| 候选题目用尽（CAT） | 提前终止测试，基于已有数据生成报告 |
| θ 估计数值不稳定 | 重置为先验 θ=0, SE=1.0，重新积累 |
| 报告生成失败 | 降级为基础统计报告（无 IRT 分析） |
| 组卷服务不可用 | 返回缓存的热门试卷 |

### 8.3 重试与幂等

- 组卷操作：支持幂等（相同 blueprintId + 相同 excludeQuestionIds + 相同种子 → 相同结果）
- 作答提交：基于 `sessionId + questionId` 唯一约束，重复提交返回已有结果
- 报告生成：幂等，同一 session 只生成一份报告

```dart
    );

    if (mounted) {
      Navigator.of(context).pushReplacementNamed(
        '/assessment/report',
        arguments: report.id,
      );
    }
  }

    _countdownTimer?.cancel();
```

```dart
class AdaptiveTestPage extends ConsumerStatefulWidget {
  final String blueprintId;
  const AdaptiveTestPage({required this.blueprintId, super.key});

  @override
  ConsumerState<AdaptiveTestPage> createState() => _AdaptiveTestPageState();
}

class _AdaptiveTestPageState extends ConsumerState<AdaptiveTestPage> {
  String? _sessionId;
  Map<String, dynamic>? _currentQuestion;
  double _theta = 0.0;
  double _se = 1.0;
  int _completedCount = 0;
  int _maxQuestions = 25;
  bool _isLoading = false;
  bool _terminated = false;

  @override
  void initState() {
    super.initState();
    _startTest();
  }

  Future<void> _startTest() async {
    setState(() => _isLoading = true);
    try {
      final result = await ref.read(assessmentServiceProvider).startAdaptive(
        blueprintId: widget.blueprintId,
      );
      setState(() {
        _sessionId = result['sessionId'];
        _currentQuestion = result['firstQuestion'];
        _theta = result['theta'];
        _se = result['se'];
      });
    } finally {
      setState(() => _isLoading = false);
    }
  }

  Future<void> _submitAnswer(String answer, int responseTimeMs) async {
    if (_sessionId == null || _terminated) return;
    setState(() => _isLoading = true);

    try {
      final isCorrect = _checkAnswer(answer, _currentQuestion!);
      final result = await ref.read(assessmentServiceProvider).respondAdaptive(
        sessionId: _sessionId!,
        questionId: _currentQuestion!['questionId'],
        answer: answer,
        responseTimeSeconds: responseTimeMs / 1000,
      );

      setState(() {
        _theta = result['theta'];
        _se = result['se'];
        _completedCount = result['completedQuestions'];
        _terminated = result['terminated'];
      });

      if (_terminated) {
        // 导航到报告页
        final reportId = result['reportId'];
        if (mounted) {
          Navigator.of(context).pushReplacementNamed(
            '/assessment/report',
            arguments: reportId,
          );
        }
      } else {
        setState(() {
          _currentQuestion = result['nextQuestion'];
        });
      }
    } finally {
      setState(() => _isLoading = false);
    }
  }

  Future<void> _stopEarly() async {
    if (_completedCount < 5) {
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('至少完成 5 道题才能结束测试')),
      );
      return;
    }
    final confirmed = await showDialog<bool>(
      context: context,
      builder: (_) => AlertDialog(
        title: Text('提前结束测试？'),
        content: Text('已完成 $_completedCount 题。结束将基于当前作答生成报告。'),
        actions: [
          TextButton(onPressed: () => Navigator.pop(context, false), child: Text('继续答题')),
          TextButton(onPressed: () => Navigator.pop(context, true), child: Text('确认结束')),
        ],
      ),
    );
    if (confirmed == true && _sessionId != null) {
      final result = await ref.read(assessmentServiceProvider).stopAdaptive(
        sessionId: _sessionId!,
      );
      if (mounted) {
        Navigator.of(context).pushReplacementNamed(
          '/assessment/report',
          arguments: result['reportId'],
        );
      }
    }
  }
}
```

```dart
class ThetaGauge extends StatelessWidget {
  final double theta;
  final double se;
  final int completedQuestions;
  final int maxQuestions;

  const ThetaGauge({
    required this.theta,
    required this.se,
    required this.completedQuestions,
    required this.maxQuestions,
    super.key,
  });

  @override
  Widget build(BuildContext context) {
    // 将 θ 映射到 0-100 的可视范围（θ ∈ [-3, 3]）
    final gaugeValue = ((theta + 3) / 6 * 100).clamp(0, 100);
    final confidenceWidth = (se * 1.96 / 6 * 100).clamp(2, 50);

    return Card(
      child: Padding(
        padding: EdgeInsets.all(16),
        child: Column(
          children: [
            Text('能力估计', style: Theme.of(context).textTheme.titleMedium),
            SizedBox(height: 8),
            // θ 仪表盘
            Stack(
              alignment: Alignment.center,
              children: [
                LinearProgressIndicator(
                  value: gaugeValue / 100,
                  minHeight: 12,
                  backgroundColor: Colors.grey[200],
                ),
                // 置信区间高亮
                Positioned(
                  left: (gaugeValue - confidenceWidth / 2).clamp(0, 100),
                  child: Container(
                    width: confidenceWidth,
                    height: 16,
                    decoration: BoxDecoration(
                      border: Border.all(color: Colors.blue, width: 2),
                      borderRadius: BorderRadius.circular(4),
                    ),
                  ),
                ),
              ],
            ),
            SizedBox(height: 4),
            Row(
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [
                Text('θ = ${theta.toStringAsFixed(2)}'),
                Text('SE = ${se.toStringAsFixed(2)}'),
                Text('进度 $completedQuestions/$maxQuestions'),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
```

## 11. 性能与容量

### 11.1 性能目标

| 操作 | 目标延迟 | 并发目标 |
|------|---------|----------|
| 固定组卷 | ≤ 3s | 100 QPS |
| CAT 选题（单次） | ≤ 200ms | 500 QPS |
| 作答提交 + θ 更新 | ≤ 300ms | 500 QPS |
| 报告生成 | ≤ 5s（异步） | 100 QPS |
| 蓝图 CRUD | ≤ 500ms | 50 QPS |

### 11.2 缓存策略

| 缓存项 | 存储 | TTL | 说明 |
|--------|------|-----|------|
| 蓝图定义 | Redis | 1h | 读取频繁、变更少 |
| 题目 IRT 参数 | Redis | 30min | 标定后更新 |
| CAT 候选池（按 θ 分桶） | Redis | 10min | 减少重复查询 |
| 热门预组试卷 | Redis | 24h | 兜底用 |
| 测评报告 | Redis + MySQL | 7d | 报告生成后缓存 |

### 11.3 容量估算

| 数据表 | 预估行数（1 年） | 存储估算 |
|--------|-----------------|----------|
| test_blueprints | ~5,000 | ~50MB |
| question_irt_params | ~500,000 | ~100MB |
| generated_test_papers | ~200,000 | ~2GB（含 JSON 快照） |
| assessment_sessions | ~5,000,000 | ~5GB |
| assessment_reports | ~5,000,000 | ~3GB |
| question_exposure_log | ~50,000,000 | ~5GB |

### 11.4 扩展性考虑

1. **IRT 参数批量标定**：使用 Celery 异步任务 + 批量处理，避免在线阻塞
2. **CAT 选题加速**：按 θ 分桶预计算候选池（每 0.5 logit 一个桶），减少在线查询量
3. **曝光率统计**：使用 ClickHouse 异步聚合，避免 MySQL 高频写入
4. **报告生成**：通过事件驱动异步生成，前端轮询或 WebSocket 通知完成
5. **分库策略**：assessment_sessions 和 question_exposure_log 按用户 ID 取模分表

## 13. 安全与合规

1. **答案隔离**：学生端 API 不返回正确答案和 IRT 参数，仅在测评完成后提供解析
2. **防作弊**：记录每题作答时间，异常快速作答（< 3 秒）标记为可疑
3. **题目保护**：曝光率控制 + 定期轮换题库
4. **数据隐私**：测评数据仅用户本人、绑定家长和授权教师可查看
5. **未成年人保护**：限制单次测试最大时长（小学生 ≤ 45 分钟，初中 ≤ 60 分钟，高中 ≤ 90 分钟）
