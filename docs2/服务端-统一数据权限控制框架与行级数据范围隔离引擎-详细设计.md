# 服务端-统一数据权限控制框架与行级数据范围隔离引擎 详细设计

## 1. 概述

### 1.1 模块定位

本模块是 PrimeTop 平台**数据安全架构的核心中间件层**，位于业务服务与数据访问层之间，负责对所有涉及用户数据的查询进行**自动化的行级数据范围过滤**。

与现有权限体系的协作关系：

| 层次 | 现有文档 | 职责 | 本模块补充 |
| --- | --- | --- | --- |
| 功能权限 (RBAC) | 权限管理与角色访问控制 | 控制**能做什么操作**（增/删/改/查） | — |
| 租户隔离 | 多租户数据隔离 | 控制**跨学校/机构**数据分离 | — |
| 字段脱敏 | 数据脱敏规则引擎 | 控制**敏感字段**如何遮蔽 | — |
| **行级数据范围** | **（缺失）** | 控制**能看到哪些数据行** | **✅ 本文档** |

### 1.2 核心问题

PrimeTop 面向多种角色：学生、家长、教师、年级主任、内容运营、平台管理员。同一张 `student_answer_record` 表，不同角色能查询的数据范围完全不同：

| 角色 | 数据范围示例 |
| --- | --- |
| 学生 | 仅能查看自己的答题记录 |
| 家长 | 仅能查看已绑定孩子的答题记录 |
| 教师 | 仅能查看自己所教班级学生的答题记录 |
| 年级主任 | 可查看本年级所有班级的数据 |
| 区域管理员 | 可查看区域内所有学校的数据 |
| 平台管理员 | 可查看全部数据 |

如果由各业务服务手动拼接 SQL WHERE 条件，存在以下风险：
1. **遗漏**：新增接口忘记加数据过滤 → 数据越权泄露
2. **不一致**：不同开发者实现方式不同，维护成本高
3. **难审计**：无法统一追踪哪些查询做了数据范围控制
4. **难扩展**：新增角色或数据范围规则时需修改大量接口

### 1.3 设计目标

1. **声明式**：开发者通过注解声明数据范围，无需手动拼接 SQL
2. **自动化**：MyBatis 拦截器自动注入行级过滤条件，杜绝遗漏
3. **可组合**：支持多种数据范围类型的组合（如"教师 + 所教班级"）
4. **可审计**：所有数据范围决策可追溯，支持安全审计
5. **高性能**：范围解析结果可缓存，避免重复查询

```java
public enum DataScopeType {
    
    /** 全部数据，仅超管可用 */
    ALL("全部数据"),
    
    /** 仅本人数据 */
    SELF("仅本人"),

    OWN_GRADE("所管年级"),
    
    /** 本人所管理的学校范围数据（校长） */
    OWN_SCHOOL("所管学校"),
    
    /** 本人所负责的区域范围数据（区域管理员） */
    OWN_REGION("所管区域"),
    
    /** 自定义数据范围，通过SQL片段动态指定 */
    CUSTOM("自定义"),
    
    /** 部门数据范围（运营/内容团队按部门划分） */
    DEPT("本部门");

        this.description = description;
    }

    }
```

## 3. 核心注解定义

### 3.1 @DataScope 主注解

```java
/**
 * 数据范围控制注解
 * 
 * 标注在 Mapper 方法或 Service 方法上，声明该方法的数据查询
 * 需要进行行级数据范围过滤。
 * 
 * 示例：
 *   @DataScope(type = DataScopeType.SELF, userIdColumn = "student_id")
 *   List<AnswerRecord> selectByCondition(@Param("query") AnswerQuery query);
 */
@Target({ElementType.METHOD, ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface DataScope {
    
    /**
     * 数据范围类型，默认为 SELF
     * 设置 ALL 表示跳过数据权限检查（仅超管接口使用）
     */
    DataScopeType type() default DataScopeType.SELF;
    
    /**
     * 用户ID字段名（数据库列名）
     * 默认为 user_id
     */
    String userIdColumn() default "user_id";
    
    /**
     * 组织ID字段名（班级/年级维度）
     * 为空字符串表示该表无组织维度
     */
    String orgIdColumn() default "";
    
    /**
     * 学校ID字段名
     */
    String schoolIdColumn() default "";
    
    /**
     * 区域ID字段名
     */
    String regionIdColumn() default "";
    
    /**
     * 部门ID字段名
     */
    String deptIdColumn() default "";
    
    /**
     * 是否忽略当前注解（用于内部调用跳过权限）
     * 仅 ADMIN 角色可使用 ignore=true
     */
    boolean ignore() default false;
    
    /**
     * 自定义范围解析器（仅 type=CUSTOM 时使用）
     */
    Class<? extends DataScopeResolver> resolver() default DataScopeResolver.class;
}
```

### 3.2 @DataScopeCombine 组合注解

```java
/**
 * 多数据范围组合注解
 * 
 * 当一个查询涉及多个数据范围维度时使用
 * 例如：查询答题记录 = 教师所教班级 + 且仅含非敏感内容
 */
@Target({ElementType.METHOD})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface DataScopeCombine {
    
    DataScope[] value();
    
    /** 组合逻辑：AND 或 OR */
    LogicalOperator operator() default LogicalOperator.AND;
    
    enum LogicalOperator {
        AND, OR
    }
}
```

### 3.3 典型使用示例

```java
// 学生查询自己的答题记录
@DataScope(type = DataScopeType.SELF, userIdColumn = "student_id")
List<AnswerRecord> selectStudentAnswers(@Param("query") AnswerQuery query);

// 教师查看班级答题记录
@DataScope(type = DataScopeType.OWN_CLASSES, orgIdColumn = "class_id", userIdColumn = "student_id")
List<AnswerRecord> selectClassAnswers(@Param("query") ClassAnswerQuery query);

// 家长查看孩子学习报告
@DataScope(type = DataScopeType.SELF_AND_BOUND, userIdColumn = "student_id")
List<StudyReport> selectReports(@Param("query") ReportQuery query);

// 年级主任查看年级数据
@DataScope(type = DataScopeType.OWN_GRADE, orgIdColumn = "class_id")
List<AnswerRecord> selectGradeAnswers(@Param("query") GradeAnswerQuery query);

// 管理后台 - 全部数据
@DataScope(type = DataScopeType.ALL)
List<AnswerRecord> selectAllForAdmin(@Param("query") AdminQuery query);

// 组合范围：教师所教班级 且 排除非活跃学生
@DataScopeCombine(
    value = {
        @DataScope(type = DataScopeType.OWN_CLASSES, orgIdColumn = "class_id"),
        @DataScope(type = DataScopeType.CUSTOM, resolver = ActiveStudentResolver.class)
    },
    operator = DataScopeCombine.LogicalOperator.AND
)
List<AnswerRecord> selectActiveClassAnswers(@Param("query") ClassAnswerQuery query);
```

### 4.2 MyBatis 拦截器实现

```java
/**
 * 数据权限 MyBatis 拦截器
 * 
 * 拦截所有 SQL 查询，根据 @DataScope 注解自动注入行级过滤条件
 */
@Intercepts({
    @Signature(
        type = Executor.class,
        method = "query",
        args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class}
    ),
    @Signature(
        type = Executor.class,
        method = "query",
        args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class, CacheKey.class, BoundSql.class}
    )
})
@Slf4j
public class DataScopeInterceptor implements Interceptor {
    
    @Autowired
    private DataScopeResolverFactory resolverFactory;
    
    @Autowired
    private DataScopeRegistryService registryService;
    
    @Autowired
    private DataScopeAuditService auditService;
    
    private static final String DATA_SCOPE_APPLIED = "_dataScopeApplied";
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        // 1. 检查是否已处理（防止重复拦截）
        Object[] args = invocation.getArgs();
        MappedStatement ms = (MappedStatement) args[0];
        Object parameter = args[1];
        
        // 2. 获取方法上的 @DataScope 注解
        DataScope dataScope = resolveAnnotation(ms);
        if (dataScope == null || dataScope.ignore()) {
            return invocation.proceed();
        }
        
        // 3. 获取数据范围上下文
        DataScopeContext context = DataScopeContextHolder.get();
        if (context == null) {
            // 内部调用无上下文，检查是否为系统调用
            if (isSystemCall()) {
                return invocation.proceed();
            }
            throw new DataScopeException("DATA_SCOPE_CONTEXT_REQUIRED", 
                "数据范围上下文未初始化，拒绝执行查询");
        }
        
        // 4. 超管直接放行
        if (context.getScopeType() == DataScopeType.ALL) {
            return invocation.proceed();
        }
        
        // 5. 解析数据范围
        long startTime = System.currentTimeMillis();
        ScopeResolutionResult result = resolveScope(dataScope, context);
        
        // 6. 重写 SQL
        BoundSql boundSql = ms.getBoundSql(parameter);
        String originalSql = boundSql.getSql();
        String rewrittenSql = rewriteSql(originalSql, dataScope, result, ms);
        
        // 7. 记录审计日志（异步）
        long costMs = System.currentTimeMillis() - startTime;
        auditService.logAsync(DataScopeAuditLog.builder()
            .userId(context.getCurrentUserId())
            .roleType(context.getRoleType().name())
            .scopeType(dataScope.type().name())
            .targetTable(extractTableName(originalSql))
            .targetEntity(ms.getId())
            .resolvedScope(result.getSummary())
            .costMs((int) costMs)
            .build());
        
        // 8. 执行重写后的SQL
        if (rewrittenSql.equals(originalSql)) {
            return invocation.proceed();
        }
        
        return executeRewrittenQuery(invocation, ms, parameter, rewrittenSql, boundSql);
    }
    
    /**
     * SQL重写核心逻辑
     */
    private String rewriteSql(String originalSql, DataScope annotation, 
                              ScopeResolutionResult result, MappedStatement ms) {
        
        // 构建数据权限 WHERE 条件
        String scopeCondition = buildScopeCondition(annotation, result);
        
        if (StringUtils.isBlank(scopeCondition)) {
            return originalSql;
        }
        
        // 检查原始SQL是否已有 WHERE 子句
        String upperSql = originalSql.toUpperCase().trim();
        
        if (upperSql.contains("WHERE")) {
            // 已有WHERE，用AND追加
            // 需要找到 WHERE 的位置并插入
            int whereIndex = findWhereIndex(originalSql);
            String beforeWhere = originalSql.substring(0, whereIndex);
            String afterWhere = originalSql.substring(whereIndex);
            
            return beforeWhere + afterWhere + " AND " + scopeCondition;
        } else {
            // 没有WHERE，在 ORDER BY / GROUP BY / LIMIT 之前插入
            int insertPos = findConditionInsertPosition(originalSql);
            if (insertPos == -1) {
                return originalSql + " WHERE " + scopeCondition;
            }
            String before = originalSql.substring(0, insertPos);
            String after = originalSql.substring(insertPos);
            return before + " WHERE " + scopeCondition + " " + after;
        }
    }
    
    /**
     * 构建数据范围条件 SQL 片段
     */
    private String buildScopeCondition(DataScope annotation, ScopeResolutionResult result) {
        
        StringBuilder sb = new StringBuilder();
        String tableAlias = resolveTableAlias(annotation);
        String columnPrefix = StringUtils.isNotBlank(tableAlias) ? tableAlias + "." : "";
        
        switch (annotation.type()) {
            case SELF:
                // AND user_id = :currentUserId
                // 或 AND user_id IN (:accessibleUserIds)（当包含代理/绑定关系时）
                if (result.getAccessibleUserIds() != null && !result.getAccessibleUserIds().isEmpty()) {
                    String userIds = result.getAccessibleUserIds().stream()
                        .map(String::valueOf)
                        .collect(Collectors.joining(","));
                    sb.append(columnPrefix).append(annotation.userIdColumn())
                      .append(" IN (").append(userIds).append(")");
                } else {
                    sb.append(columnPrefix).append(annotation.userIdColumn())
                      .append(" = ").append(result.getCurrentUserId());
                }
                break;
                
            case OWN_CLASSES:
                // AND class_id IN (:classIds) 
                if (StringUtils.isNotBlank(annotation.orgIdColumn())) {
                    String classIds = result.getAccessibleOrgIds().stream()
                        .map(String::valueOf)
                        .collect(Collectors.joining(","));
                    if (classIds.isEmpty()) {
                        // 无可访问班级，返回不可能满足的条件
                        sb.append("1 = 0");
                    } else {
                        sb.append(columnPrefix).append(annotation.orgIdColumn())
                          .append(" IN (").append(classIds).append(")");
                    }
                }
                break;
                
            case OWN_GRADE:
                // AND class_id IN (SELECT id FROM class WHERE grade_id = :gradeId)
                // 或 AND grade_id = :gradeId
                if (result.getAccessibleOrgIds() != null && !result.getAccessibleOrgIds().isEmpty()) {
                    String orgIds = result.getAccessibleOrgIds().stream()
                        .map(String::valueOf)
                        .collect(Collectors.joining(","));
                    sb.append(columnPrefix).append(annotation.orgIdColumn())
                      .append(" IN (").append(orgIds).append(")");
                }
                if (result.getCustomSqlSegment() != null) {
                    sb.append(result.getCustomSqlSegment());
                }
                break;
                
            case OWN_SCHOOL:
                if (result.getAccessibleSchoolIds() != null && !result.getAccessibleSchoolIds().isEmpty()) {
                    String schoolIds = result.getAccessibleSchoolIds().stream()
                        .map(String::valueOf)
                        .collect(Collectors.joining(","));
                    sb.append(columnPrefix).append(annotation.schoolIdColumn())
                      .append(" IN (").append(schoolIds).append(")");
                }
                break;
                
            case SELF_AND_BOUND:
                // 家长：AND student_id IN (:childUserIds)
                if (result.getAccessibleUserIds() != null && !result.getAccessibleUserIds().isEmpty()) {
                    String userIds = result.getAccessibleUserIds().stream()
                        .map(String::valueOf)
                        .collect(Collectors.joining(","));
                    sb.append(columnPrefix).append(annotation.userIdColumn())
                      .append(" IN (").append(userIds).append(")");
                } else {
                    // 无绑定孩子，返回空结果
                    sb.append("1 = 0");
                }
                break;
                
            case CUSTOM:
                // 使用自定义SQL片段
                sb.append(result.getCustomSqlSegment());
                break;
                
            case DEPT:
                // AND dept_id = :deptId
                if (result.getAccessibleOrgIds() != null) {
                    sb.append(columnPrefix).append(annotation.deptIdColumn())
                      .append(" = ").append(result.getAccessibleOrgIds().iterator().next());
                }
                break;
                
            case ALL:
                // 无条件
                break;
        }
        
        return sb.toString();
    }
    
    // ... 其他辅助方法
    
    /**
     * 查找 WHERE 关键字的起始位置（大小写不敏感）
     */
    private int findWhereIndex(String sql) {
        String upper = sql.toUpperCase();
        int idx = upper.indexOf("WHERE");
        // 确保 WHERE 是独立单词（前面有空格或换行）
        while (idx != -1) {
            if (idx == 0 || !Character.isLetterOrDigit(sql.charAt(idx - 1))) {
                return idx;
            }
            idx = upper.indexOf("WHERE", idx + 5);
        }
        return -1;
    }
    
    /**
     * 在没有 WHERE 的情况下，找到应插入 WHERE 的位置
     * 在 ORDER BY / GROUP BY / HAVING / LIMIT 之前插入
     */
    private int findConditionInsertPosition(String sql) {
        String upper = sql.toUpperCase();
        String[] keywords = {"ORDER BY", "GROUP BY", "HAVING", "LIMIT", "UNION"};
        int minPos = Integer.MAX_VALUE;
        for (String keyword : keywords) {
            int pos = upper.indexOf(keyword);
            while (pos != -1) {
                if (pos == 0 || !Character.isLetterOrDigit(sql.charAt(pos - 1))) {
                    minPos = Math.min(minPos, pos);
                    break;
                }
                pos = upper.indexOf(keyword, pos + keyword.length());
            }
        }
        return minPos == Integer.MAX_VALUE ? -1 : minPos;
    }
}
```

```java
/**
 * 数据范围解析器工厂
 * 
 * 根据数据范围类型选择对应的解析器
 * 解析器负责查询"当前用户能访问哪些数据"
 */
@Component
public class DataScopeResolverFactory {
    
    @Autowired
    private Map<String, DataScopeResolver> resolverMap; // Spring自动注入所有Resolver
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private UserOrganizationService userOrgService;
    
    /**
     * 解析数据范围
     */
    public ScopeResolutionResult resolve(DataScope annotation, DataScopeContext context) {
        
        DataScopeType type = determineScopeType(annotation, context);
        
        DataScopeResolver resolver = resolverMap.get(type.name() + "Resolver");
        if (resolver == null) {
            throw new DataScopeException("RESOLVER_NOT_FOUND",
                "未找到数据范围解析器: " + type);
        }
        
        // 尝试从缓存获取
        String cacheKey = buildCacheKey(type, context);
        ScopeResolutionResult cached = getCachedResult(cacheKey);
        if (cached != null) {
            return cached;
        }
        
        // 执行解析
        ScopeResolutionResult result = resolver.resolve(annotation, context);
        result.setResolvedAt(System.currentTimeMillis());
        
        // 缓存结果
        cacheResult(cacheKey, result, 300); // 5分钟TTL
        
        return result;
    }
    
    /**
     * 确定最终数据范围类型
     * 优先级：用户覆盖 > 角色默认 > 注解声明
     */
    private DataScopeType determineScopeType(DataScope annotation, DataScopeContext context) {
        // 1. 检查用户级覆盖
        DataScopeType override = getUserOverride(context.getCurrentUserId());
        if (override != null) {
            return override;
        }
        
        // 2. 使用注解声明的类型
        return annotation.type();
    }
```

```java
            headers.set(HEADER_SIGNATURE, signature);
        }
        return execution.execute(request, body);

            }
            
            filterChain.doFilter(request, response);

            .roleType(roleType)
```

## 7. 安全保障机制

### 7.1 默认拒绝策略

```java
/**
 * 数据范围安全策略
 */
@Component
@Slf4j
public class DataScopeSecurityPolicy {
    
    /**
     * 当范围解析失败时的处理策略
     */
    public enum FailureStrategy {
        /** 默认拒绝（返回空结果） - 推荐生产环境 */
        DENY,
        /** 允许但告警（继续执行但记录告警） */
        ALLOW_WITH_WARNING,
        /** 抛出异常（中断请求） */
        THROW
    }
    
    private final FailureStrategy strategy = FailureStrategy.DENY;
    
    /**
     * 处理解析失败
     */
    public ScopeResolutionResult handleResolveFailure(
            DataScope annotation, DataScopeContext context, Exception cause) {
        
        log.error("数据范围解析失败! userId={}, scope={}, error={}", 
            context.getCurrentUserId(), annotation.type(), cause.getMessage());
        
        switch (strategy) {
            case DENY:
                // 返回空结果集的条件
                ScopeResolutionResult deny = new ScopeResolutionResult();
                deny.setCustomSqlSegment("1 = 0"); // 永假条件
                deny.setSummary("DENIED: resolve failed - " + cause.getMessage());
                return deny;
                
            case ALLOW_WITH_WARNING:
                log.warn("⚠️ 数据范围解析失败，降级为无限制查询! userId={}, scope={}", 
                    context.getCurrentUserId(), annotation.type());
                ScopeResolutionResult allow = new ScopeResolutionResult();
                allow.setSummary("ALLOWED_WITH_WARNING: " + cause.getMessage());
                return allow;
                
            case THROW:
                throw new DataScopeException("SCOPE_RESOLVE_FAILED", 
                    "数据范围解析失败: " + cause.getMessage(), cause);
                
            default:
                throw new IllegalStateException("Unknown strategy: " + strategy);
        }
    }
    
    /**
     * SQL注入检测
     */
    public void validateSqlFragment(String sqlFragment) {
        if (sqlFragment == null) return;
        
        String lower = sqlFragment.toLowerCase();
        String[] forbidden = {
            ";", "--", "/*", "*/", "xp_", "exec(", 
            "union select", "information_schema", "sleep(",
            "benchmark(", "load_file(", "into outfile"
        };
        
        for (String pattern : forbidden) {
            if (lower.contains(pattern)) {
                throw new DataScopeException(
                    "SQL_INJECTION_DETECTED",
                    "SQL片段包含可疑模式: " + pattern
                );
            }
        }
    }
}
```

## 10. 性能保障

### 10.1 IN 条件优化

当 `accessibleUserIds` 或 `accessibleOrgIds` 集合过大时（如区域管理员可能管辖上千个班级），需要优化：

```java
/**
 * 大集合IN条件优化策略
 */
@Component
public class LargeInConditionOptimizer {
    
    private static final int MAX_IN_SIZE = 1000;
    
    /**
     * 当ID集合超过阈值时，使用临时表JOIN替代IN
     */
    public String optimizeInCondition(String column, Set<Long> ids, String tableAlias) {
        if (ids.size() <= MAX_IN_SIZE) {
            // 小集合：直接IN
            String idStr = ids.stream().map(String::valueOf)
                .collect(Collectors.joining(","));
            return tableAlias + "." + column + " IN (" + idStr + ")";
        }
        
        // 大集合：使用临时表
        String tempTableName = createTempIdTable(ids);
        return tableAlias + "." + column + " IN (SELECT id FROM " + tempTableName + ")";
    }
    
    /**
     * 创建内存临时表存储ID集合
     */
    private String createTempIdTable(Set<Long> ids) {
        String tableName = "tmp_scope_ids_" + ThreadLocalRandom.current().nextInt(1000000);
        // 使用 MySQL 内存引擎临时表
        jdbcTemplate.execute("CREATE TEMPORARY TABLE " + tableName 
            + " (id BIGINT PRIMARY KEY) ENGINE=MEMORY");
        
        // 批量插入
        List<Object[]> batch = ids.stream()
            .map(id -> new Object[]{id})
            .collect(Collectors.toList());
        
        jdbcTemplate.batchUpdate(
            "INSERT INTO " + tableName + " (id) VALUES (?)", 
            batch
        );
        
        return tableName;
    }
}
```

## 14. 与现有系统对接说明

### 14.1 与用户权限管理的分工

| 维度 | 用户权限管理 (RBAC) | 本模块 (DataScope) |
| --- | --- | --- |
| 粒度 | 操作级（能否调用某API） | 数据行级（能看到哪些行） |
| 注解 | `@PreAuthorize("hasRole('TEACHER')")` | `@DataScope(type=OWN_CLASSES)` |
| 时机 | 方法调用前 | SQL执行前 |
| 实现 | Spring Security | MyBatis Interceptor |

**协作模式**：先由 RBAC 判断用户是否有权调用接口，再由 DataScope 自动过滤返回数据。

### 14.2 与多租户隔离的分工

| 维度 | 多租户隔离 | 本模块 |
| --- | --- | --- |
| 目的 | 隔离不同学校/机构的数据 | 隔离同一学校内不同角色的数据 |
| 实现 | 租户ID字段过滤 | 角色-关系驱动的行级过滤 |
| 触发 | 所有查询自动注入 tenant_id 条件 | @DataScope 注解触发 |

**执行顺序**：租户隔离先执行（缩小到本租户范围），数据权限后执行（在租户内进一步按角色过滤）。

### 14.3 与数据脱敏的分工

| 维度 | 数据脱敏 | 本模块 |
| --- | --- | --- |
| 目的 | 隐藏字段值（如手机号中间四位） | 过滤数据行 |
| 实现 | JSON 序列化时脱敏 | SQL 执行前重写 |
| 时机 | 数据返回前 | 数据查询前 |

**协作模式**：DataScope 先过滤出合法的数据行，脱敏模块再对返回的字段做遮蔽。
