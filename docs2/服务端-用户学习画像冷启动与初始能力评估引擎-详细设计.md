# 用户学习画像冷启动与初始能力评估引擎 - 详细设计

## 1. 模块概述

### 1.1 定位

用户学习画像冷启动与初始能力评估引擎（以下简称"冷启动引擎"）是 PrimeTop 个性化学习体系的**冷启动引导层**。当新用户注册完成、设置年级和学科后，系统尚无任何学习行为数据，无法进行有效的个性化推荐和自适应学习路径规划。本模块负责在这一"数据真空"阶段，通过**分层诊断策略**快速构建初始能力画像，使后续的自适应推荐、错题分析、学情报告等模块能够立即生效。

### 1.2 解决的核心问题

| 问题 | 说明 |
|------|------|
| 新用户无历史数据 | 注册后无法进行个性化推荐，首页推荐内容无差异化 |
| 初始掌握度全零 | 知识点掌握度全部为 0，导致推荐引擎退化为随机推荐 |
| 年级≠能力 | 同一年级的学生实际水平差异很大，不能仅凭年级假设能力 |
| 冷启动流失风险 | 新用户首次体验若无法感知个性化，流失率显著升高 |
| 升学/转段断层 | 学期末升级时，画像需要平滑过渡而非归零重建 |

### 1.3 与其他模块的关系

```
用户账号体系 ──→ 注册完成/年级设置 ──→ 本模块（冷启动引擎）
                                              │
                                              ├──→ 用户学习画像与能力维度模型（写入初始画像）
                                              ├──→ 知识点体系与教材映射引擎（读取知识点树+前置关系）
                                              ├──→ 自适应学习与个性化推荐引擎（消费画像数据）
                                              ├──→ 学习规划模块（基于画像生成初始计划）
                                              ├──→ 练习与测评系统（执行诊断测试）
                                              ├──→ 首页与学习工作台（展示诊断进度+结果）
                                              ├──→ 学情分析模块（补充初始学情数据）
                                              └──→ 用户引导与新手教程系统（集成诊断流程引导）
```

### 1.4 核心目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 诊断完成率 | ≥ 70% | 新注册用户完成至少一轮诊断 |
| 诊断耗时 | ≤ 8 分钟 | 单次诊断测试平均完成时长 |
| 画像准确度 | ≥ 75% | 初始画像与后续 2 周实际表现的一致率 |
| 首次个性化推荐点击率 | ≥ 40% | 基于初始画像的推荐内容点击率 |
| 升级画像继承率 | 100% | 学段升级时已有画像数据完全继承 |

## 2. 核心概念与数据模型

### 2.1 核心概念

- **诊断阶段（DiagnosticPhase）**：冷启动的分层评估阶段，从轻量到深度逐步构建画像
- **诊断测试（DiagnosticTest）**：用于评估能力的专项测试，包含一组按策略选取的题目
- **初始画像（InitialProfile）**：诊断完成后的初始能力评估结果，写入用户画像系统
- **年级基准（GradeBaseline）**：系统预设的各年级各学科能力基线，作为无诊断数据时的兜底
- **能力先验（PriorEstimate）**：基于年级、地区、教材版本等先验信息的能力预估值
- **画像继承策略（ProfileInheritance）**：升学/转段时旧画像到新画像的映射规则

### 2.2 冷启动分层策略

冷启动不是一步到位的，而是分三层逐步精细化：

```
Layer 1: 先验估计（注册即生效，零交互成本）
   │  基于年级 + 地区 + 教材版本 + 时间（学期初/末）生成先验画像
   │
Layer 2: 快速诊断（3-5 分钟，5-10 题快速探测）
   │  薄弱点扫描 + 关键知识点采样检测
   │
Layer 3: 深度诊断（可选，8-15 分钟，15-25 题自适应测试）
      基于 IRT 自适应选题的精细画像构建
```

## 3. 核心流程设计

### 3.1 整体冷启动流程

```

        │
        ▼
┌─────────────────────────┐

│  (Prior Profile Build)   │
│  - 查询年级基准线         │
│  - 应用学期进度修正       │
│  - 生成先验知识点掌握度   │

└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│  Layer 2: 快速诊断邀请   │ ← 用户下次打开APP时触发

│  - 首页卡片 / 浮窗引导    │

            │ 用户接受
            ▼
```

### 3.2 Layer 1: 先验画像生成流程

```python
# services/cold_start/prior_profile_builder.py

from dataclasses import dataclass
from typing import Optional
import math

@dataclass
class PriorProfile:
    """先验画像数据"""
    user_id: int
    subject_code: str
    grade_code: str

    # 全局先验
    overall_mastery: float           # 整体掌握度先验
    confidence: float                # 置信度

    # 能力维度先验
    calc_ability: float
    reading_comprehension: float
    logic_reasoning: float
    expression_ability: float
    spatial_imagination: float

    # 知识点先验列表: [(kp_id, estimated_mastery, confidence)]
    kp_estimates: list[tuple[int, float, float]]


class PriorProfileBuilder:
    """先验画像构建器"""

    def __init__(self, db, cache):
        self.db = db
        self.cache = cache

    async def build_for_new_user(
        self,
        user_id: int,
        grade_code: str,
        subject_code: str,
        semester: str,
        region_code: str = "DEFAULT",
        current_date: Optional[str] = None,
    ) -> PriorProfile:
        """
        为新用户生成先验画像。

        策略:
        1. 查询年级基准线 (grade_baselines)
        2. 应用学期进度修正
        3. 获取该年级学科的知识点树
        4. 按"基础/核心/拓展"三层分布生成各知识点先验掌握度
        5. 写入用户画像系统
        """

        # Step 1: 查询基准线
        baseline = await self._get_baseline(grade_code, subject_code, semester, region_code)

        # Step 2: 学期进度修正
        progress_factor = self._calc_semester_progress(semester, current_date)
        adjusted_mastery = baseline.mastery_baseline + progress_factor * 0.15
        adjusted_mastery = min(adjusted_mastery, 0.80)  # 先验上限不超过 0.80

        # Step 3: 获取知识点树
        kp_tree = await self._get_knowledge_point_tree(grade_code, subject_code)

        # Step 4: 为每个知识点生成先验掌握度
        kp_estimates = self._generate_kp_estimates(kp_tree, baseline, progress_factor)

        # Step 5: 构建先验画像
        profile = PriorProfile(
            user_id=user_id,
            subject_code=subject_code,
            grade_code=grade_code,
            overall_mastery=adjusted_mastery,
            confidence=0.15,  # 先验画像置信度低
            calc_ability=baseline.calc_ability + progress_factor * 0.10,
            reading_comprehension=baseline.reading_comprehension + progress_factor * 0.10,
            logic_reasoning=baseline.logic_reasoning + progress_factor * 0.10,
            expression_ability=baseline.expression_ability + progress_factor * 0.10,
            spatial_imagination=baseline.spatial_imagination + progress_factor * 0.10,
            kp_estimates=kp_estimates,
        )

        return profile

    def _calc_semester_progress(self, semester: str, current_date: str = None) -> float:
        """
        计算学期进度因子 (0.0 ~ 1.0)。
        学期初 → 0.0, 学期末 → 1.0
        """
        # 简化实现：按月份估算
        # S1: 9月~1月, S2: 2月~6月
        from datetime import datetime
        now = datetime.strptime(current_date, "%Y-%m-%d") if current_date else datetime.now()
        month = now.month

        if semester == "S1":
            # 9月=0.0, 10月=0.2, 11月=0.4, 12月=0.6, 1月=0.8
            if month >= 9:
                return (month - 9) / 5.0
            elif month == 1:
                return 0.8
            else:
                return 0.0
        else:  # S2
            # 2月=0.0, 3月=0.2, 4月=0.4, 5月=0.6, 6月=0.8, 7月=1.0
            if month >= 2 and month <= 7:
                return min((month - 2) / 5.0, 1.0)
            else:
                return 0.5  # 暑假期间默认 0.5

    def _generate_kp_estimates(self, kp_tree, baseline, progress_factor) -> list:
        """
        按知识点层级生成先验掌握度。

        策略:
        - 基础知识点 (层级=1-2): 使用 foundational 分布
        - 核心知识点 (层级=3-4): 使用 core 分布
        - 拓展知识点 (层级=5+):  使用 advanced 分布
        - 加入少量随机扰动，避免所有同年级用户画像完全一致
        """
        import random

        estimates = []
        distribution = baseline.kp_distribution

        for kp in kp_tree:
            level = kp.get("level", 3)
            if level <= 2:
                dist_key = "foundational"
            elif level <= 4:
                dist_key = "core"
            else:
                dist_key = "advanced"

            dist = distribution.get(dist_key, {"mean": 0.30, "stddev": 0.15})
            mean = dist["mean"] + progress_factor * 0.10
            # 加入 ±5% 的随机扰动
            noise = random.uniform(-0.05, 0.05)
            mastery = max(0.05, min(0.85, mean + noise))
            confidence = 0.15  # 先验置信度固定低值

            estimates.append((kp["id"], round(mastery, 4), confidence))

        return estimates
```

### 3.3 Layer 2: 快速诊断选题算法

```python
# services/cold_start/quick_diagnostic.py

from enum import Enum
from typing import Optional

class QuickDiagnosticStrategy(Enum):
    """快速诊断策略"""
    CHAPTER_SAMPLING = "chapter_sampling"      # 按章节均匀采样
    WEAK_AREA_PROBE  = "weak_area_probe"       # 薄弱点探测（基于先验低掌握度知识点）
    MIXED            = "mixed"                  # 混合策略


class QuickDiagnosticEngine:
    """快速诊断引擎"""

    # 快速诊断参数
    QUICK_TEST_CONFIG = {
        "min_questions": 5,
        "max_questions": 10,
        "target_time_sec": 240,     # 4 分钟目标
        "max_time_sec": 360,        # 6 分钟上限
        "kp_coverage_target": 0.30, # 覆盖 30% 知识点
    }

    def __init__(self, db, question_service, kp_service):
        self.db = db
        self.question_service = question_service
        self.kp_service = kp_service

    async def generate_test(
        self,
        user_id: int,
        subject_code: str,
        grade_code: str,
        prior_profile: Optional[PriorProfile] = None,
    ) -> dict:
        """
        生成快速诊断测试。

        选题策略 (MIXED):
        1. 60% 题目按章节均匀采样 → 覆盖广度
        2. 40% 题目针对先验低掌握度知识点 → 薄弱点探测
        3. 题目难度分布: 简单 30% / 中等 50% / 较难 20%
        """
        # 获取知识点树
        kp_tree = await self.kp_service.get_tree(grade_code, subject_code)
        total_kps = len(kp_tree)
        target_cover = max(3, int(total_kps * self.QUICK_TEST_CONFIG["kp_coverage_target"]))

        # 计算题目数
        num_questions = min(
            self.QUICK_TEST_CONFIG["max_questions"],
            max(self.QUICK_TEST_CONFIG["min_questions"], target_cover)
        )

        # 策略分配
        num_sampling = max(3, int(num_questions * 0.6))
        num_weak_probe = num_questions - num_sampling

        selected_items = []

        # --- 章节均匀采样 ---
        chapters = self._group_by_chapter(kp_tree)
        sampling_kps = self._uniform_sample_kps(chapters, num_sampling)
        for kp in sampling_kps:
            question = await self.question_service.find_question(
                knowledge_point_id=kp["id"],
                difficulty=self._sample_difficulty(),
                limit=1,
            )
            if question:
                selected_items.append({
                    "knowledge_point_id": kp["id"],
                    "question_id": question[0]["id"],
                    "difficulty": question[0]["difficulty"],
                    "selection_reason": "SAMPLING",
                })

        # --- 薄弱点探测（如有先验画像）---
        if prior_profile and prior_profile.kp_estimates:
            # 取掌握度最低的知识点
            weak_kps = sorted(prior_profile.kp_estimates, key=lambda x: x[1])[:num_weak_probe]
            for kp_id, est_mastery, _ in weak_kps:
                # 根据估计掌握度选择难度
                difficulty = "easy" if est_mastery < 0.20 else "medium"
                question = await self.question_service.find_question(
                    knowledge_point_id=kp_id,
                    difficulty=difficulty,
                    limit=1,
                )
                if question:
                    selected_items.append({
                        "knowledge_point_id": kp_id,
                        "question_id": question[0]["id"],
                        "difficulty": question[0]["difficulty"],
                        "selection_reason": "TARGETED",
                    })

        # 打乱顺序，避免连续同类型题目
        import random
        random.shuffle(selected_items)

        # 编号
        for i, item in enumerate(selected_items, 1):
            item["seq_num"] = i

        return {
            "test_type": "QUICK",
            "subject_code": subject_code,
            "grade_code": grade_code,
            "total_questions": len(selected_items),
            "time_limit_sec": self.QUICK_TEST_CONFIG["max_time_sec"],
            "items": selected_items,
        }

    def _group_by_chapter(self, kp_tree: list) -> dict:
        """按章节分组知识点"""
        chapters = {}
        for kp in kp_tree:
            ch = kp.get("chapter_id", "unknown")
            chapters.setdefault(ch, []).append(kp)
        return chapters

    def _uniform_sample_kps(self, chapters: dict, count: int) -> list:
        """从各章节均匀采样知识点"""
        import random
        chapter_list = list(chapters.values())
        sampled = []
        # 轮询每个章节，每次取一个，直到达到目标数
        idx = 0
        while len(sampled) < count and chapter_list:
            ch_kps = chapter_list[idx % len(chapter_list)]
            if ch_kps:
                kp = random.choice(ch_kps)
                if kp not in sampled:
                    sampled.append(kp)
            idx += 1
            if idx > count * 3:  # 防止无限循环
                break
        return sampled[:count]

    def _sample_difficulty(self) -> str:
        """按分布采样题目难度"""
        import random
        r = random.random()
        if r < 0.30:
            return "easy"
        elif r < 0.80:
            return "medium"
        else:
            return "hard"
```

### 3.4 Layer 3: 自适应深度诊断（IRT-CAT）

```python
# services/cold_start/adaptive_diagnostic.py

import math
from typing import Optional

class AdaptiveDiagnosticEngine:
    """
    基于 IRT (Item Response Theory) 的自适应诊断引擎。

    使用 3PL (Three-Parameter Logistic) 模型：
    P(θ) = c + (1 - c) / (1 + exp(-1.7 * a * (θ - b)))

    选题策略: 最大信息量法 (Maximum Fisher Information, MFI)
    终止条件: SE < 0.35 或达到最大题数
    """

    # IRT 参数默认值
    DEFAULT_DISCRIMINATION = 1.0   # a 参数默认值
    DEFAULT_GUESSING = 0.20        # c 参数默认值（4选1约25%，适当降低）

    # 终止条件
    MAX_QUESTIONS = 25
    MIN_QUESTIONS = 10
    TARGET_SE = 0.35               # 目标标准误差

    def estimate_ability(self, responses: list[dict]) -> tuple[float, float]:
        """
        基于 EAP (Expected A Posteriori) 估计能力值 θ。

        Args:
            responses: [{"difficulty": b, "discrimination": a, "guessing": c, "correct": bool}, ...]

        Returns:
            (theta_estimate, standard_error)
        """
        # EAP 使用数值积分
        # 先验分布: N(0, 1)
        quadrature_points = 41
        theta_range = (-4.0, 4.0)
        step = (theta_range[1] - theta_range[0]) / (quadrature_points - 1)

        # 计算每个积分点上的后验概率
        posterior = []
        for i in range(quadrature_points):
            theta_q = theta_range[0] + i * step
            # 先验: 标准正态
            prior = math.exp(-0.5 * theta_q ** 2) / math.sqrt(2 * math.pi)
            # 似然
            likelihood = 1.0
            for resp in responses:
                b = resp.get("difficulty", 0.0)
                a = resp.get("discrimination", self.DEFAULT_DISCRIMINATION)
                c = resp.get("guessing", self.DEFAULT_GUESSING)
                p_correct = c + (1 - c) / (1 + math.exp(-1.7 * a * (theta_q - b)))
                if resp["correct"]:
                    likelihood *= max(p_correct, 1e-10)
                else:
                    likelihood *= max(1 - p_correct, 1e-10)

            posterior.append(prior * likelihood)

        # 归一化
        total = sum(posterior)
        if total < 1e-30:
            return (0.0, 1.0)  # 回退到默认值

        posterior = [p / total for p in posterior]

        # EAP 估计 = Σ(θ_q * posterior_q * step)
        theta_eap = sum(
            (theta_range[0] + i * step) * posterior[i]
            for i in range(quadrature_points)
        )

        # 标准误差
        variance = sum(
            ((theta_range[0] + i * step) - theta_eap) ** 2 * posterior[i]
            for i in range(quadrature_points)
        )
        se = math.sqrt(variance) if variance > 0 else 1.0

        return (theta_eap, se)

    def select_next_question(
        self,
        current_theta: float,
        current_se: float,
        answered_question_ids: set[int],
        available_questions: list[dict],
        content_balance: dict,  # 内容均衡约束
    ) -> Optional[dict]:
        """
        使用 MFI (Maximum Fisher Information) 策略选择下一题。

        在当前 θ 估计处 Fisher 信息量最大的题目提供最多信息。
        同时考虑内容均衡（不同知识点/章节的覆盖）。
        """
        best_question = None
        best_info = -1

        for q in available_questions:
            if q["id"] in answered_question_ids:
                continue

            # 内容均衡检查
            kp_id = q.get("knowledge_point_id")
            if kp_id and content_balance.get(kp_id, 0) >= 2:
                continue  # 同一知识点不超过2题

            # 计算 Fisher 信息量
            b = q.get("difficulty", 0.0)
            a = q.get("discrimination", self.DEFAULT_DISCRIMINATION)
            c = q.get("guessing", self.DEFAULT_GUESSING)

            info = self._fisher_information(current_theta, a, b, c)

            if info > best_info:
                best_info = info
                best_question = q

        return best_question

    def _fisher_information(self, theta: float, a: float, b: float, c: float) -> float:
        """计算 3PL 模型在 θ 处的 Fisher 信息量"""
        exp_term = math.exp(-1.7 * a * (theta - b))
        p = c + (1 - c) / (1 + exp_term)
        p = max(p, 1e-10)

        # I(θ) = (1.7*a)^2 * (p-c)^2 * (1-p) / ((1-c)^2 * p)
        numerator = (1.7 * a) ** 2 * (p - c) ** 2 * (1 - p)
        denominator = (1 - c) ** 2 * p

        if denominator < 1e-20:
            return 0.0

        return numerator / denominator

    def should_terminate(
        self,
        num_answered: int,
        current_se: float,
    ) -> tuple[bool, str]:
        """
        判断是否应该终止自适应测试。

        Returns:
            (should_stop, reason)
        """
        if num_answered < self.MIN_QUESTIONS:
            return (False, "")

        if num_answered >= self.MAX_QUESTIONS:
            return (True, "MAX_QUESTIONS_REACHED")

        if current_se < self.TARGET_SE:
            return (True, "TARGET_SE_ACHIEVED")

        return (False, "")
```

```python
# services/cold_start/profile_updater.py

class DiagnosticProfileUpdater:
    """将诊断结果转化为用户画像更新"""

    def __init__(self, db, profile_service, kp_service):
        self.db = db
        self.profile_service = profile_service
        self.kp_service = kp_service

    async def apply_diagnostic_results(self, test_id: int) -> dict:
        """
        将诊断测试结果应用到用户画像。

        流程:
        1. 读取诊断测试的所有答题记录
        2. 按知识点聚合：直接证据（有答题数据）和间接证据（关联知识点推断）
        3. 与先验画像融合（贝叶斯更新）
        4. 更新能力维度评分
        5. 写入用户画像系统
        6. 触发画像变更事件
        """
        # Step 1: 读取测试结果
        test = await self.db.fetch_one(
            "SELECT * FROM diagnostic_tests WHERE id = %s", (test_id,)
        )
        items = await self.db.fetch_all(
            "SELECT * FROM diagnostic_test_items WHERE test_id = %s ORDER BY seq_num",
            (test_id,),
        )

        # Step 2: 按知识点聚合直接证据
        kp_evidence = self._aggregate_kp_evidence(items)

        # Step 3: 间接证据推断（通过知识点前置关系）
        indirect_evidence = await self._infer_indirect_evidence(kp_evidence, test["subject_code"])

        # Step 4: 融合先验画像（贝叶斯更新）
        prior = await self.profile_service.get_current_profile(test["user_id"], test["subject_code"])
        updated_kps = self._bayesian_update(prior, kp_evidence, indirect_evidence)

        # Step 5: 更新能力维度
        ability_dims = self._estimate_ability_dimensions(items)

        # Step 6: 计算新置信度
        confidence = self._calc_confidence(len(items), test["test_type"])

        # Step 7: 写入画像
        profile_update = {
            "user_id": test["user_id"],
            "subject_code": test["subject_code"],
            "overall_mastery": test["score"],
            "confidence": confidence,
            "kp_mastery_updates": updated_kps,
            **ability_dims,
            "source": f"DIAGNOSTIC_{test['test_type']}",
            "diagnostic_test_id": test_id,
        }

        await self.profile_service.batch_update(profile_update)

        # Step 8: 写入诊断知识点结果表
        await self._save_kp_results(test_id, test["user_id"], test["subject_code"], updated_kps)

        return {
            "user_id": test["user_id"],
            "subject_code": test["subject_code"],
            "confidence": confidence,
            "kp_updated_count": len(updated_kps),
            "ability_dims": ability_dims,
        }

    def _bayesian_update(
        self,
        prior: dict,
        direct_evidence: dict,
        indirect_evidence: dict,
    ) -> list[dict]:
        """
        贝叶斯更新知识点掌握度。

        先验: P(mastery) ~ Beta(α_prior, β_prior)
        似然: 观测到 correct/total 次答题结果
        后验: P(mastery|data) ~ Beta(α_post, β_post)

        α_post = α_prior + correct_count
        β_post = β_prior + incorrect_count
        E[mastery] = α_post / (α_post + β_post)
        """
        results = []
        all_kp_ids = set(direct_evidence.keys()) | set(indirect_evidence.keys())

        for kp_id in all_kp_ids:
            # 获取先验参数
            prior_mastery = prior.get_kp_mastery(kp_id, default=0.30)
            prior_confidence = prior.get_kp_confidence(kp_id, default=0.15)
            # 转换为 Beta 分布参数
            # α = μ * κ, β = (1-μ) * κ, 其中 κ = confidence * 20 (等效样本量)
            kappa = prior_confidence * 20
            alpha = prior_mastery * kappa + 1  # +1 避免零值
            beta = (1 - prior_mastery) * kappa + 1

            # 合并直接证据
            if kp_id in direct_evidence:
                de = direct_evidence[kp_id]
                alpha += de["correct"]
                beta += de["total"] - de["correct"]

            # 合并间接证据（权重降低）
            if kp_id in indirect_evidence:
                ie = indirect_evidence[kp_id]
                weight = 0.5  # 间接证据权重
                alpha += ie["correct"] * weight
                beta += (ie["total"] - ie["correct"]) * weight

            # 后验期望
            posterior_mastery = alpha / (alpha + beta)
            posterior_confidence = min(0.95, (alpha + beta - 2) / 20)

            evidence_type = "DIRECT" if kp_id in direct_evidence else "INDIRECT"
            if prior_confidence < 0.20 and kp_id not in direct_evidence:
                evidence_type = "PRIOR"

            results.append({
                "knowledge_point_id": kp_id,
                "estimated_mastery": round(posterior_mastery, 4),
                "confidence": round(posterior_confidence, 2),
                "evidence_type": evidence_type,
            })

        return results

    def _aggregate_kp_evidence(self, items: list) -> dict:
        """按知识点聚合直接答题证据"""
        evidence = {}
        for item in items:
            if not item["is_answered"]:
                continue
            kp_id = item["knowledge_point_id"]
            if not kp_id:
                continue

            if kp_id not in evidence:
                evidence[kp_id] = {"correct": 0, "total": 0, "total_time": 0.0}

            evidence[kp_id]["total"] += 1
            if item["is_correct"]:
                evidence[kp_id]["correct"] += 1
            evidence[kp_id]["total_time"] += item.get("time_spent_sec", 0)

        return evidence

    async def _infer_indirect_evidence(self, direct_evidence: dict, subject_code: str) -> dict:
        """
        通过知识点前置关系推断间接证据。

        如果知识点 A 是知识点 B 的前置（A → B）：
        - B 答对 → 推断 A 也可能掌握（间接正确）
        - A 答错 → 推断 B 也可能不掌握（间接错误）
        """
        indirect = {}
        for kp_id, de in direct_evidence.items():
            # 获取前置知识点
            prerequisites = await self.kp_service.get_prerequisites(kp_id)
            for prereq in prerequisites:
                prereq_id = prereq["id"]
                if prereq_id in direct_evidence:
                    continue  # 已有直接证据，不需要间接

                if prereq_id not in indirect:
                    indirect[prereq_id] = {"correct": 0, "total": 0}

                # B 答对 → A 间接正确（但不是100%确定）
                if de["correct"] > 0:
                    indirect[prereq_id]["correct"] += de["correct"]
                indirect[prereq_id]["total"] += de["total"]

            # 获取后继知识点
            successors = await self.kp_service.get_successors(kp_id)
            for succ in successors:
                succ_id = succ["id"]
                if succ_id in direct_evidence:
                    continue

                if succ_id not in indirect:
                    indirect[succ_id] = {"correct": 0, "total": 0}

                # A 答错 → B 间接错误
                incorrect = de["total"] - de["correct"]
                if incorrect > 0:
                    indirect[succ_id]["total"] += incorrect
                else:
                    indirect[succ_id]["correct"] += de["correct"]
                    indirect[succ_id]["total"] += de["total"]

        return indirect

    def _calc_confidence(self, num_items: int, test_type: str) -> float:
        """根据诊断类型和题目数计算画像置信度"""
        base_confidence = {
            "QUICK": 0.50,
            "DEEP": 0.80,
            "RECALIBRATION": 0.70,
        }
        base = base_confidence.get(test_type, 0.40)
        # 题数修正：题目越多置信度越高
        factor = min(1.0, num_items / 15.0)
        return min(0.95, base * (0.7 + 0.3 * factor))

    def _estimate_ability_dimensions(self, items: list) -> dict:
        """从答题数据估算能力维度"""
        # 简化实现：基于正确率和题目属性推断
        if not items:
            return {}

        total = len([i for i in items if i.get("is_answered")])
        correct = len([i for i in items if i.get("is_correct")])
        score = correct / total if total > 0 else 0.3

        # 基于答题时间推断（快速正确 → 能力强）
        avg_time = sum(i.get("time_spent_sec", 60) for i in items if i.get("is_answered")) / max(total, 1)
        time_factor = 1.0 if avg_time < 30 else (0.8 if avg_time < 60 else 0.6)

        adjusted = min(0.90, score * time_factor * 1.1)

        return {
            "calc_ability": adjusted,
            "reading_comprehension": adjusted * 0.95,
            "logic_reasoning": adjusted * 0.90,
            "expression_ability": adjusted * 0.85,
            "spatial_imagination": adjusted * 0.80,
        }
```

### 3.6 画像继承（升学/转段）流程

```python
# services/cold_start/profile_inheritance.py

class ProfileInheritanceEngine:
    """升学/转段时的画像继承引擎"""

    def __init__(self, db, profile_service, kp_service):
        self.db = db
        self.profile_service = profile_service
        self.kp_service = kp_service

    async def inherit_on_grade_up(
        self,
        user_id: int,
        from_grade: str,
        to_grade: str,
        subject_code: str,
    ) -> dict:
        """
        升级时继承旧画像到新年级。

        继承策略:
        1. 查找继承规则 (profile_inheritance_rules)
        2. CARRY_OVER: 直接携带，加时间衰减
        3. DECAY: 强衰减，适合跨学段（小学→初中）
        4. RESET: 仅保留能力维度，知识点掌握度重置
        5. MAP: 知识点映射，将旧知识点掌握度映射到新知识点
        """
        # 获取旧画像
        old_profile = await self.profile_service.get_current_profile(
            user_id, subject_code, grade=from_grade
        )

        # 查找继承规则
        rule = await self.db.fetch_one(
            """SELECT * FROM profile_inheritance_rules
               WHERE from_grade = %s AND to_grade = %s
               AND subject_code = %s AND is_active = 1
               ORDER BY priority DESC LIMIT 1""",
            (from_grade, to_grade, subject_code),
        )

        if not rule:
            # 默认策略：通用衰减
            return await self._default_inheritance(old_profile, to_grade, subject_code)

        rule_type = rule["rule_type"]
        config = rule["rule_config"]

        if rule_type == "CARRY_OVER":
            return await self._carry_over(old_profile, config, to_grade, subject_code)
        elif rule_type == "DECAY":
            return await self._decay_inheritance(old_profile, config, to_grade, subject_code)
        elif rule_type == "RESET":
            return await self._reset_inheritance(old_profile, config, to_grade, subject_code)
        elif rule_type == "MAP":
            return await self._map_inheritance(old_profile, config, to_grade, subject_code)
        else:
            return await self._default_inheritance(old_profile, to_grade, subject_code)

    async def _carry_over(self, old_profile, config, to_grade, subject_code):
        """直接携带 + 轻微衰减"""
        decay = config.get("decay_factor", 0.90)
        min_mastery = config.get("min_mastery", 0.10)

        new_kps = []
        for kp_id, mastery, conf in old_profile.kp_estimates:
            new_mastery = max(min_mastery, mastery * decay)
            new_kps.append((kp_id, round(new_mastery, 4), conf))

        return {
            "grade_code": to_grade,
            "subject_code": subject_code,
            "kp_estimates": new_kps,
            "inheritance_type": "CARRY_OVER",
        }

    async def _decay_inheritance(self, old_profile, config, to_grade, subject_code):
        """强衰减（跨学段）"""
        decay = config.get("decay_factor", 0.70)

        new_kps = []
        for kp_id, mastery, conf in old_profile.kp_estimates:
            new_mastery = max(0.05, mastery * decay)
            # 置信度降低（因为跨学段推断不确定）
            new_conf = max(0.15, conf * 0.60)
            new_kps.append((kp_id, round(new_mastery, 4), new_conf))

        return {
            "grade_code": to_grade,
            "subject_code": subject_code,
            "kp_estimates": new_kps,
            "inheritance_type": "DECAY",
        }

    async def _map_inheritance(self, old_profile, config, to_grade, subject_code):
        """知识点映射继承"""
        kp_mapping = config.get("kp_mapping", [])
        mapping_dict = {m["from_kp"]: m for m in kp_mapping}

        new_kps = []
        # 获取新年级知识点
        new_kp_tree = await self.kp_service.get_tree(to_grade, subject_code)

        mapped_ids = set()
        for kp_id, mastery, conf in old_profile.kp_estimates:
            str_kp_id = str(kp_id)
            if str_kp_id in mapping_dict:
                mapping = mapping_dict[str_kp_id]
                weight = mapping.get("weight", 0.80)
                new_mastery = max(0.05, mastery * weight)
                new_kps.append((kp_id, round(new_mastery, 4), conf * 0.80))
                mapped_ids.add(kp_id)

        # 未映射的新知识点使用年级基准
        for kp in new_kp_tree:
            if kp["id"] not in mapped_ids:
                new_kps.append((kp["id"], 0.15, 0.10))

        return {
            "grade_code": to_grade,
            "subject_code": subject_code,
            "kp_estimates": new_kps,
            "inheritance_type": "MAP",
        }

    async def _default_inheritance(self, old_profile, to_grade, subject_code):
        """默认继承策略：通用衰减 0.85"""
        return await self._carry_over(
            old_profile, {"decay_factor": 0.85, "min_mastery": 0.10},
            to_grade, subject_code,
        )
```

## 6. 错误处理

### 6.1 错误码段

冷启动引擎使用错误码段 `42xxx`。

| 错误码 | HTTP 状态 | 说明 | 处理建议 |
|--------|----------|------|---------|
| 42001 | 400 | 年级基准数据不存在 | 检查年级+学科+地区组合是否有基准配置 |
| 42002 | 400 | 知识点树为空 | 检查该年级学科的知识点数据是否已入库 |
| 42003 | 409 | 诊断测试已存在（同用户同学科进行中）| 先完成或放弃已有测试 |
| 42004 | 404 | 诊断测试不存在 | 检查 test_id |
| 42005 | 409 | 测试已过期 | 重新创建测试 |
| 42006 | 409 | 测试已完成，不可再答题 | — |
| 42007 | 400 | 题序号不合法 | 检查 seq_num |
| 42008 | 400 | 选题失败（题库无合适题目）| 降级为跳过该知识点 |
| 42009 | 400 | 画像继承规则缺失 | 使用默认衰减策略 |
| 42010 | 500 | IRT 计算失败（数值溢出）| 回退到简单正确率算法 |
| 42011 | 400 | 用户不存在或未设置年级 | 引导完善信息 |

### 6.2 关键降级策略

| 场景 | 降级方案 |
|------|---------|
| 题库中无合适诊断题目 | 缩减题目数（最少3题），降低知识点覆盖目标 |
| IRT 自适应计算失败 | 回退到固定序列 + 简单正确率评估 |
| 年级基准数据缺失 | 使用相邻年级基准插值，或使用全局默认值 (0.30) |
| 知识点前置关系数据缺失 | 跳过间接证据推断，仅使用直接证据 |
| 诊断超时/放弃 | 保留已答题数据，应用部分画像更新（置信度相应降低）|
| 用户跳过所有诊断 | 仅保持先验画像，后续通过自然学习行为逐步修正 |

### 12.3 画像准确率验证

```python
def test_profile_accuracy():
    """
    验证方法：选取已完成诊断且有2周学习数据的用户，
    比较初始画像估计 vs 实际2周后的知识点掌握度。
    """
    users = get_users_with_diagnostic_and_2week_data()

    total_accuracy = 0
    for user in users:
        initial = get_diagnostic_profile(user.id)
        actual = get_current_profile(user.id)

        # 比较知识点掌握度排序一致性 (Spearman 相关)
        correlation = spearman_correlation(
            [kp.mastery for kp in initial.kps],
            [kp.mastery for kp in actual.kps],
        )
        total_accuracy += correlation

    avg_accuracy = total_accuracy / len(users)
    assert avg_accuracy >= 0.75, f"画像准确率 {avg_accuracy:.2%} 低于目标 75%"
```
