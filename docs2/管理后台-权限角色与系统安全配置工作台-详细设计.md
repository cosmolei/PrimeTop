# 管理后台 - 权限角色与系统安全配置工作台 详细设计

## 1. 概述

### 1.1 功能定位

权限角色与系统安全配置工作台是 PrimeTop 管理后台的核心 P0 模块，负责管理后台账号、角色、权限分配、系统安全策略及操作审计。它是所有其他管理后台工作台的"安全基座"，确保不同岗位的运营人员、内容编辑、审核员、管理员只能访问其职责范围内的功能和数据。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 最小权限原则 | 每个后台账号仅授予完成其工作所必需的最小权限集合 |
| 权限可配置 | 支持菜单级、按钮级、数据行级三维权限控制 |
| 安全可审计 | 所有敏感操作记录审计日志，支持追溯查询 |
| 防御纵深 | 密码策略、MFA、IP 白名单、会话超时等多层防护 |
| 开箱即用 | 预设超级管理员、内容运营、审核员、财务、客服等标准角色 |

### 1.3 适用范围

- 后端服务：权限服务（`auth-service`）、审计服务（`audit-service`）
- 前端：管理后台 Web（React / Vue 中后台框架）
- 本文档不涉及学生端 / 家长端的权限控制（由用户服务负责）

## 3. 数据结构定义

### 3.1 后台管理员账号表 `admin_users`

```sql
CREATE TABLE `admin_users` (
    `id`              BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `username`        VARCHAR(64)  NOT NULL COMMENT '登录用户名，唯一',
    `display_name`    VARCHAR(128) NOT NULL DEFAULT '' COMMENT '显示名称',
    `email`           VARCHAR(128) NOT NULL DEFAULT '' COMMENT '邮箱',
    `phone`           VARCHAR(20)  NOT NULL DEFAULT '' COMMENT '手机号',
    `password_hash`   VARCHAR(255) NOT NULL COMMENT 'bcrypt加密密码',
    `password_changed_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '密码最后修改时间',
    `status`          TINYINT      NOT NULL DEFAULT 1 COMMENT '状态: 0=禁用, 1=启用, 2=锁定',
    `mfa_secret`      VARCHAR(255) NOT NULL DEFAULT '' COMMENT 'MFA密钥(AES加密存储)',
    `mfa_enabled`     TINYINT      NOT NULL DEFAULT 0 COMMENT 'MFA是否启用: 0=否, 1=是',
    `failed_login_count` INT       NOT NULL DEFAULT 0 COMMENT '连续登录失败次数',
    `locked_until`    DATETIME     NULL COMMENT '锁定截止时间',
    `last_login_at`   DATETIME     NULL COMMENT '最后登录时间',
    `last_login_ip`   VARCHAR(45)  NOT NULL DEFAULT '' COMMENT '最后登录IP',
    `department`      VARCHAR(128) NOT NULL DEFAULT '' COMMENT '所属部门',
    `position`        VARCHAR(128) NOT NULL DEFAULT '' COMMENT '岗位',
    `created_by`      BIGINT       NOT NULL DEFAULT 0 COMMENT '创建者ID',
    `created_at`      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    `deleted_at`      DATETIME     NULL COMMENT '软删除时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_username` (`username`),
    KEY `idx_status` (`status`),
    KEY `idx_department` (`department`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='后台管理员账号';
```

### 3.2 角色表 `admin_roles`

### 3.3 权限资源表 `admin_permissions`

```sql
CREATE TABLE `admin_permissions` (

    `icon`            VARCHAR(64)  NOT NULL DEFAULT '' COMMENT '菜单图标',
    `route_path`      VARCHAR(256) NOT NULL DEFAULT '' COMMENT '前端路由路径',

    `created_at`      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_permission_code` (`permission_code`),
    KEY `idx_parent_id` (`parent_id`),
    KEY `idx_resource_type` (`resource_type`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='权限资源';
```

| `DATA_ANALYST` | 数据分析 | 全部 | 数据看板、报表导出（只读） |
| `SYSTEM_ADMIN` | 系统管理员 | 全部 | 权限、安全、系统配置 |

## 5. API 接口设计

### 5.1 管理员账号管理

#### 5.1.1 创建管理员

```
POST /api/admin/system/admin-users
Content-Type: application/json
Authorization: Bearer {access_token}

Request Body:
{
    "username": "zhangsan",
    "display_name": "张三",
    "email": "zhangsan@primetop.edu",
    "phone": "13800138000",
    "password": "Temp@2026",
    "department": "内容部",
    "position": "内容运营",
    "role_ids": [2, 5]
}

Response (201):
{
    "code": 0,
    "message": "success",
    "data": {
        "id": 101,
        "username": "zhangsan",
        "display_name": "张三",
        "status": 1,
        "created_at": "2026-07-22T14:00:00Z"
    }
}

Response (400):
{
    "code": 40001,
    "message": "用户名已存在"
}
```

**校验规则：**
- `username`: 4-20位，字母数字下划线，唯一
- `password`: 至少8位，包含大小写字母+数字+特殊字符
- `email`: 合法邮箱格式
- `phone`: 中国手机号格式
- 创建后发送密码设置邮件给用户

## 7. 权限缓存设计

### 7.1 Redis 缓存结构

```
# 管理员权限集合（SET类型）
Key:  perm:{admin_id}
Value: SET of permission_code strings
TTL:  300秒（5分钟）

# 示例
perm:101 -> {"dashboard:view", "user:list", "user:detail", "textbook:list", ...}

# 管理员角色列表（SET类型，用于权限变更时反查）
Key:  roles:{admin_id}
Value: SET of role_id integers
TTL:  300秒

# 角色→管理员映射（SET类型，用于角色权限变更时查找受影响用户）
Key:  role_admins:{role_id}
Value: SET of admin_id integers
TTL:  600秒（10分钟）
```

### 7.2 缓存操作封装

```python
import redis
import json
import logging

logger = logging.getLogger(__name__)


class PermissionCache:
    def __init__(self, redis_client: redis.Redis):
        self.redis = redis_client
        self.perm_ttl = 300
        self.role_ttl = 600
    
    def get_permissions(self, admin_id: int) -> set:
        """获取管理员的权限集合"""
        key = f"perm:{admin_id}"
        permissions = self.redis.smembers(key)
        if permissions:
            return set(p.decode() for p in permissions)
        return None  # 缓存未命中
    
    def set_permissions(self, admin_id: int, permissions: set):
        """设置管理员权限集合"""
        key = f"perm:{admin_id}"
        pipe = self.redis.pipeline()
        pipe.delete(key)
        if permissions:
            pipe.sadd(key, *permissions)
        pipe.expire(key, self.perm_ttl)
        pipe.execute()
    
    def invalidate_permissions(self, admin_id: int):
        """使管理员的权限缓存失效"""
        self.redis.delete(f"perm:{admin_id}")
        self.redis.delete(f"roles:{admin_id}")
    
    def invalidate_by_role(self, role_id: int):
        """角色权限变更时，使所有关联管理员的权限缓存失效"""
        # 获取角色关联的所有管理员
        role_admins_key = f"role_admins:{role_id}"
        admin_ids = self.redis.smembers(role_admins_key)
        
        if not admin_ids:
            # 缓存未命中，从数据库查询
            admin_ids = self._query_admin_ids_by_role(role_id)
            if admin_ids:
                self.redis.sadd(role_admins_key, *admin_ids)
                self.redis.expire(role_admins_key, self.role_ttl)
        
        # 批量删除权限缓存
        if admin_ids:
            keys = [f"perm:{aid.decode() if isinstance(aid, bytes) else aid}" for aid in admin_ids]
            self.redis.delete(*keys)
```

## 9. 数据权限拦截器

### 9.1 行级数据范围控制

对于需要数据范围隔离的查询接口，通过 MyBatis Interceptor 自动注入 SQL 条件：

```java
/**
 * 数据权限拦截器 - 自动在 SQL 中注入数据范围条件
 */
@Intercepts({
    @Signature(type = Executor.class, method = "query",
              args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class})
})
public class DataScopeInterceptor implements Interceptor {
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        // 1. 获取当前登录管理员的数据范围
        AdminContext ctx = AdminContextHolder.get();
        if (ctx == null || ctx.isSuperAdmin()) {
            return invocation.proceed(); // 超管不做限制
        }
        
        DataScope scope = ctx.getDataScope();
        if (scope == DataScope.ALL) {
            return invocation.proceed(); // 全部数据
        }
        
        // 2. 构建 SQL 条件
        String scopeSql = buildScopeSql(scope, ctx);
        
        // 3. 通过 BoundSql 注入条件
        Object[] args = invocation.getArgs();
        MappedStatement ms = (MappedStatement) args[0];
        Object parameter = args[1];
        
        BoundSql boundSql = ms.getBoundSql(parameter);
        String originalSql = boundSql.getSql();
        String newSql = injectCondition(originalSql, scopeSql);
        
        // 4. 用新 SQL 执行
        return executeWithNewSql(ms, parameter, boundSql, newSql, args);
    }
    
    private String buildScopeSql(DataScope scope, AdminContext ctx) {
        switch (scope) {
            case DEPARTMENT:
                return "department = '" + ctx.getDepartment() + "'";
            case DEPARTMENT_AND_SUB:
                return "department IN (" + ctx.getDepartmentTreeSql() + ")";
            case CUSTOM:
                return "department IN ('" + 
                    String.join("','", ctx.getCustomDepartments()) + "')";
            default:
                return "1=1";
        }
    }
}
```

## 10. 审计日志切面

```java
/**
 * 审计日志 AOP 切面
 * 拦截 @AuditLog 注解的方法，自动记录操作日志
 */
@Aspect
@Component
public class AuditLogAspect {
    
    private static final Logger logger = LoggerFactory.getLogger(AuditLogAspect.class);
    
    @Autowired
    private AuditLogService auditLogService;
    
    @Autowired
    private DiffExtractor diffExtractor;
    
    @Around("@annotation(auditLogAnno)")
    public Object around(ProceedingJoinPoint joinPoint, AuditLog auditLogAnno) throws Throwable {
        long startTime = System.currentTimeMillis();
        
        // 1. 获取操作前数据快照（针对 UPDATE 操作）
        Object beforeSnapshot = null;
        if ("UPDATE".equals(auditLogAnno.action()) || "DELETE".equals(auditLogAnno.action())) {
            beforeSnapshot = diffExtractor.extractBeforeSnapshot(joinPoint, auditLogAnno);
        }
        
        AuditLogEntity logEntity = new AuditLogEntity();
        logEntity.setModule(auditLogAnno.module());
        logEntity.setAction(auditLogAnno.action());
        logEntity.setTargetType(auditLogAnno.targetType());
        AdminContext ctx = AdminContextHolder.get();
        
        Throwable error = null;
        try {
            // 2. 执行业务方法
            Object result = joinPoint.proceed();
            logEntity.setResponseStatus(200);
            
            // 3. 提取操作后数据快照
            if (beforeSnapshot != null) {
                Object afterSnapshot = diffExtractor.extractAfterSnapshot(joinPoint, result);
                logEntity.setDiffBefore(JsonUtil.toJson(beforeSnapshot));
                logEntity.setDiffAfter(JsonUtil.toJson(afterSnapshot));
            }
            
            // 4. 提取目标 ID
            String targetId = diffExtractor.extractTargetId(joinPoint, result);
            logEntity.setTargetId(targetId);
            
            return result;
        } catch (Throwable e) {
            error = e;
            logEntity.setResponseStatus(e instanceof BusinessException ? 
                ((BusinessException) e).getCode() : 500);
            logEntity.setErrorMessage(e.getMessage());
            throw e;
        } finally {
            // 5. 填充日志基础信息
            logEntity.setAdminId(ctx.getAdminId());
            logEntity.setAdminUsername(ctx.getUsername());
            logEntity.setRequestPath(RequestContext.getCurrentRequest().getRequestURI());
            logEntity.setRequestMethod(RequestContext.getCurrentRequest().getMethod());
            logEntity.setIpAddress(ctx.getIpAddress());
            logEntity.setUserAgent(RequestContext.getUserAgent());
            logEntity.setDurationMs((int) (System.currentTimeMillis() - startTime));
            logEntity.setCreatedAt(LocalDateTime.now());
            
            // 6. 请求参数（脱敏）
            logEntity.setRequestParams(
                sanitizeParams(joinPoint.getArgs(), auditLogAnno));
            
            // 7. 异步写入审计日志
            try {
                auditLogService.asyncSave(logEntity);
            } catch (Exception e) {
                logger.error("Failed to save audit log", e);
            }
            
            // 8. 敏感操作检测
            auditLogService.checkSensitiveAction(logEntity);
        }
    }
    
    /**
     * 脱敏请求参数：移除密码、token 等敏感字段
     */
    private String sanitizeParams(Object[] args, AuditLog auditLogAnno) {
        Map<String, Object> paramMap = extractParamMap(args);
        paramMap.remove("password");
        paramMap.remove("newPassword");
        paramMap.remove("oldPassword");
        paramMap.remove("mfaSecret");
        paramMap.replaceAll((k, v) -> {
            if (v instanceof String && ((String) v).length() > 500) {
                return "[TRUNCATED]";
            }
            return v;
        });
        return JsonUtil.toJson(paramMap);
    }
}
```

## 12. 密码安全策略实现

### 12.1 密码强度校验

```python
import re


class PasswordPolicy:
    """密码策略校验器"""
    
    def __init__(self, config: dict):
        self.min_length = config.get("min_length", 8)
        self.require_uppercase = config.get("require_uppercase", True)
        self.require_lowercase = config.get("require_lowercase", True)
        self.require_digit = config.get("require_digit", True)
        self.require_special = config.get("require_special_char", True)
        self.expiry_days = config.get("password_expiry_days", 90)
        self.history_count = config.get("password_history_count", 5)
    
    def validate(self, password: str) -> tuple[bool, str]:
        """校验密码强度，返回 (是否通过, 错误信息)"""
        if len(password) < self.min_length:
            return False, f"密码长度不能少于{self.min_length}位"
        
        if self.require_uppercase and not re.search(r'[A-Z]', password):
            return False, "密码必须包含大写字母"
        
        if self.require_lowercase and not re.search(r'[a-z]', password):
            return False, "密码必须包含小写字母"
        
        if self.require_digit and not re.search(r'\d', password):
            return False, "密码必须包含数字"
        
        if self.require_special and not re.search(r'[!@#$%^&*()_+\-=\[\]{};:\'",.<>?/]', password):
            return False, "密码必须包含特殊字符"
        
        return True, ""
    
    def is_expired(self, password_changed_at) -> bool:
        """检查密码是否已过期"""
        if self.expiry_days <= 0:
            return False
        from datetime import datetime, timedelta
        expiry_date = password_changed_at + timedelta(days=self.expiry_days)
        return datetime.now() > expiry_date
    
    def check_history(self, new_password: str, password_hashes: list) -> bool:
        """检查新密码是否与历史密码重复"""
        import bcrypt
        for old_hash in password_hashes[:self.history_count]:
            if bcrypt.checkpw(new_password.encode(), old_hash.encode()):
                return True  # 与历史密码重复
        return False
```
