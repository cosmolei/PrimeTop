# 教育内容结构化模板引擎与内容组装服务 - 详细设计

## 1. 模块概述

### 1.1 功能定位

本服务为 PrimeTop 平台所有教育内容（课文讲解、知识点说明、章节总结、专题复习、考前冲刺等）提供**统一的模板定义、管理与内容组装能力**。内容编辑人员通过模板引擎定义各类内容的结构骨架（由哪些区块组成、每个区块的类型和约束），实际内容生产时基于模板填充具体素材，最终组装为标准化的结构化内容对象供客户端渲染。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 结构标准化 | 所有教育内容遵循统一的结构模型，保证客户端渲染一致性和数据可分析性 |
| 模板复用 | 同类型内容共享模板，减少内容生产重复劳动 |
| 灵活扩展 | 支持新增内容区块类型而不修改核心引擎代码 |
| 版本管理 | 模板支持多版本，旧内容绑定旧版本不受模板更新影响 |
| 前后端解耦 | 客户端只关心渲染数据结构，不关心模板定义细节 |

### 1.3 与已有模块的关系

| 已有模块 | 关系 |
|----------|------|
| 教材内容数字化与结构化生产管线 | 是本服务的上游使用方，调用模板引擎创建结构化内容 |
| 教育内容协同创作与审校发布生产线引擎 | 协作工作流中嵌入模板选择与内容填充环节 |
| 教育互动练习类型注册中心与练习素材配置装配引擎 | 本服务定义"练习区块"的占位，练习引擎填充具体交互内容 |
| 富文本与学科内容渲染引擎 | 本服务输出结构化JSON，渲染引擎负责客户端视觉呈现 |
| 教育内容审核工作流与多级审核管线 | 审核管线对模板组装后的内容进行合规检查 |
| 教育内容版本管理与教材同步更新引擎 | 内容版本与模板版本的双重版本管理协调 |

## 2. 核心概念模型

### 2.1 概念关系图

```
┌─────────────┐     defines     ┌──────────────┐    instantiates    ┌──────────────────┐
│ ContentTemplate │──────────────→│ TemplateSlot │                    │ ContentInstance  │
│  (内容模板)     │               │  (模板槽位)   │                    │  (内容实例)       │
└──────┬──────┘                  └──────────────┘                    └────────┬─────────┘
       │                                                                      │
       │ 1:N                                                                  │ 1:N
       │                                                                      │
       ▼                                                                      ▼
┌──────────────┐                                                  ┌──────────────────────┐
│ TemplateVersion │                                                │ ContentSlotInstance  │
│  (模板版本)      │                                                │  (槽位填充实例)       │
└──────────────┘                                                  └──────────────────────┘
```

### 2.2 核心概念说明

#### 2.2.1 ContentTemplate（内容模板）

模板是某一类教育内容的结构蓝图。例如"课文讲解模板"定义了一个课文讲解应包含：导入、核心讲解、例题、小结、拓展阅读等区块。

#### 2.2.2 TemplateSlot（模板槽位）

模板由多个槽位组成，每个槽位代表内容的一个逻辑区块。槽位有明确的类型（文本、富文本、图片、视频、练习引用、知识图谱引用等）和约束（是否必填、字数范围、数量限制等）。

#### 2.2.3 ContentInstance（内容实例）

基于某个模板版本创建的实际内容对象。例如"人教版七年级数学第三章《一元一次方程》讲解"就是一个内容实例。

#### 2.2.4 ContentSlotInstance（槽位填充实例）

内容实例中每个槽位的具体填充数据。每个槽位实例包含实际的教学内容（文字、图片URL、引用ID等）。

## 4. 槽位类型处理框架

### 4.1 SlotTypeHandler 接口设计

采用策略模式，每种槽位类型有对应的 Handler 负责数据校验和预处理。

```java
/**
 * 槽位类型处理器接口
 * 每种 SlotType 对应一个 SlotTypeHandler 实现
 */
public interface SlotTypeHandler {

    /** 返回此处理器负责的槽位类型 */
    SlotType getSlotType();

    /**
     * 校验槽位填充数据是否符合模板定义的约束
     *
     * @param slotData  垂填充数据（JSON解析后的Map）
     * @param constraints 模板中定义的该槽位的constraints
     * @return 校验结果
     */
    ValidationResult validate(Map<String, Object> slotData, Map<String, Object> constraints);

    /**
     * 预处理填充数据（如：下载远程图片到OSS、压缩、格式标准化等）
     * 在保存前调用
     */
    Map<String, Object> preprocess(Map<String, Object> slotData, PreprocessContext context);

    /**
     * 组装为客户端渲染所需的最终格式
     */
    RenderBlock toRenderBlock(Map<String, Object> slotData, RenderContext context);

    /** 获取该槽位类型的空数据模板（用于编辑器初始化） */
    Map<String, Object> getDefaultData(Map<String, Object> constraints);
}
```

### 4.2 SlotTypeRegistry 注册中心

```java
/**
 * 槽位类型注册中心
 * 负责管理所有 SlotTypeHandler 的注册与查找
 * 支持运行时动态注册新类型（自定义组件场景）
 */
@Component
public class SlotTypeRegistry {

    private final Map<SlotType, SlotTypeHandler> handlers = new ConcurrentHashMap<>();
    private final Map<String, SlotTypeHandler> customHandlers = new ConcurrentHashMap<>();

    @Autowired
    public SlotTypeRegistry(List<SlotTypeHandler> autoRegistered) {
        for (SlotTypeHandler handler : autoRegistered) {
            register(handler);
        }
    }

    public void register(SlotTypeHandler handler) {
        handlers.put(handler.getSlotType(), handler);
    }

    /**
     * 注册自定义槽位类型
     * @param customType 自定义类型标识（如 "MIND_MAP"、"TIMELINE"）
     * @param handler 对应处理器
     */
    public void registerCustom(String customType, SlotTypeHandler handler) {
        customHandlers.put(customType, handler);
    }

    public SlotTypeHandler getHandler(SlotType type) {
        SlotTypeHandler handler = handlers.get(type);
        if (handler == null) {
            throw new TemplateException(
                TemplateErrorCode.SLOT_TYPE_NOT_SUPPORTED,
                "Unsupported slot type: " + type
            );
        }
        return handler;
    }

    public SlotTypeHandler getCustomHandler(String customType) {
        return customHandlers.get(customType);
    }

    /** 获取所有已注册类型（含自定义），用于编辑器展示可用组件列表 */
    public List<SlotTypeInfo> listAllTypes() {
        List<SlotTypeInfo> result = new ArrayList<>();
        handlers.forEach((type, handler) -> {
            result.add(new SlotTypeInfo(type.name(), type.getDescription()));
        });
        customHandlers.forEach((type, handler) -> {
            result.add(new SlotTypeInfo(type, "自定义: " + type));
        });
        return result;
    }
}
```

## 5. 模板生命周期与状态流转

### 5.1 模板状态机

```
  ┌────────┐  publish()   ┌──────────┐  deprecate()  ┌──────────┐
  │ 草稿   │ ──────────→  │ 已发布    │ ───────────→  │ 已下线    │
  │ DRAFT  │              │PUBLISHED │               │ DEPRECATED│
  └────────┘              └────┬─────┘               └──────────┘
       │                       │                          │
       │ edit()                │ edit() → new version     │ 不可逆
       ↓                       ↓
  ┌────────┐         ┌──────────────┐
  │ 编辑中  │         │ 新版本草稿    │
  └────────┘         └──────────────┘
```

### 5.2 内容实例状态机

```
  ┌────────┐  submit()    ┌──────────────┐  approve()   ┌──────────┐  publish()  ┌───────────┐
  │ 草稿   │ ──────────→  │ 待审核        │ ──────────→  │ 已通过    │ ─────────→  │ 已发布     │
  │ DRAFT  │              │PENDING_REVIEW│              │ APPROVED  │            │ PUBLISHED │
  └────┬───┘              └──────┬───────┘              └──────────┘            └─────┬─────┘
       │                         │ reject()                                          │ archive()
       │ edit()                  ↓                                                    │
       │                  ┌──────────────┐                                      ┌──────────┐
       └──────────────────│ 驳回修改      │                                      │ 已归档    │
                          │REJECTED       │                                      │ ARCHIVED │
                          └──────────────┘                                      └──────────┘
```

### 5.3 模板版本兼容性策略

当模板需要修改时，按变更类型决策：

| 变更类型 | 处理方式 | 说明 |
|----------|----------|------|
| 新增非必填槽位 | 创建新版本，已有内容自动兼容 | 旧内容渲染时新槽位显示空态 |
| 新增必填槽位 | 创建新版本，旧内容标记"需更新" | 不强制旧内容立即更新 |
| 删除槽位 | 创建新版本，旧内容保留数据但渲染时跳过 | 数据不丢失 |
| 修改槽位约束（收紧） | 创建新版本，已有内容触发重新校验 | 不合格内容进入"待修订"队列 |
| 修改槽位约束（放宽） | 创建新版本，已有内容自动兼容 | 无需操作 |
| 修改槽位类型 | 不允许直接修改 | 必须删除旧槽位+新增新槽位 |

### 7.2 ContentAssemblyService 核心代码

```java
/**
 * 内容组装服务
 * 负责将模板 + 槽位数据 → 最终客户端渲染格式
 */
@Service
@Slf4j
public class ContentAssemblyService {

    @Autowired
    private ContentTemplateRepository templateRepo;
    
    @Autowired
    private ContentInstanceRepository instanceRepo;
    
    @Autowired
    private ContentSlotDataRepository slotDataRepo;
    
    @Autowired
    private SlotTypeRegistry slotTypeRegistry;

    /**
     * 组装内容实例为客户端渲染格式
     */
    public AssembledContent assemble(Long instanceId) {
        // 1. 加载内容实例
        ContentInstance instance = instanceRepo.findById(instanceId)
            .orElseThrow(() -> new ContentNotFoundException(instanceId));

        // 2. 加载模板版本定义
        ContentTemplateVersion templateVersion = templateRepo
            .findVersion(instance.getTemplateId(), instance.getTemplateVersion())
            .orElseThrow(() -> new TemplateVersionNotFoundException(
                instance.getTemplateId(), instance.getTemplateVersion()));

        // 3. 加载所有槽位数据
        List<ContentSlotData> slotDataList = slotDataRepo
            .findByInstanceIdAndVersion(instanceId, instance.getVersion());

        Map<String, ContentSlotData> slotDataMap = slotDataList.stream()
            .collect(Collectors.toMap(ContentSlotData::getSlotKey, s -> s));

        // 4. 获取模板槽位定义
        SlotDefinitionSet slotDefs = SlotDefinitionSet.fromJson(
            templateVersion.getSlotDefinitions());

        // 5. 按顺序组装渲染块
        List<RenderBlock> renderBlocks = new ArrayList<>();
        RenderContext context = RenderContext.builder()
            .subject(instance.getSubject())
            .stage(instance.getStage())
            .gradeLevel(instance.getGradeLevel())
            .build();

        for (SlotDefinition slotDef : slotDefs.getSlotsInOrder()) {
            ContentSlotData slotData = slotDataMap.get(slotDef.getSlotKey());
            
            if (slotData == null || isEmpty(slotData)) {
                // 跳过未填充的非必填槽位
                if (!slotDef.isRequired()) {
                    continue;
                }
                log.warn("Required slot [{}] not filled for instance [{}]", 
                    slotDef.getSlotKey(), instanceId);
                continue;
            }

            // 获取对应Handler并组装
            SlotTypeHandler handler = slotTypeRegistry.getHandler(slotDef.getSlotType());
            RenderBlock block = handler.toRenderBlock(slotData.getSlotData(), context);
            
            // 注入元信息
            block.setSlotKey(slotDef.getSlotKey());
            block.setSlotName(slotDef.getSlotName());
            
            renderBlocks.add(block);
        }

        // 6. 计算元信息
        ContentMetadata metadata = buildMetadata(instance, renderBlocks);

        return AssembledContent.builder()
            .instanceId(instanceId)
            .title(instance.getTitle())
            .templateCode(templateVersion.getTemplate().getTemplateCode())
            .templateVersion(instance.getTemplateVersion())
            .renderBlocks(renderBlocks)
            .metadata(metadata)
            .assembledAt(LocalDateTime.now())
            .build();
    }

    /**
     * 校验内容实例所有槽位
     */
    public ValidationReport validate(Long instanceId) {
        ContentInstance instance = instanceRepo.findById(instanceId)
            .orElseThrow(() -> new ContentNotFoundException(instanceId));

        ContentTemplateVersion templateVersion = templateRepo
            .findVersion(instance.getTemplateId(), instance.getTemplateVersion())
            .orElseThrow(() -> new TemplateVersionNotFoundException(
                instance.getTemplateId(), instance.getTemplateVersion()));

        List<ContentSlotData> slotDataList = slotDataRepo
            .findByInstanceIdAndVersion(instanceId, instance.getVersion());

        Map<String, ContentSlotData> slotDataMap = slotDataList.stream()
            .collect(Collectors.toMap(ContentSlotData::getSlotKey, s -> s));

        SlotDefinitionSet slotDefs = SlotDefinitionSet.fromJson(
            templateVersion.getSlotDefinitions());

        List<SlotValidationResult> results = new ArrayList<>();
        int filledCount = 0;
        int validCount = 0;

        for (SlotDefinition slotDef : slotDefs.getSlots()) {
            ContentSlotData slotData = slotDataMap.get(slotDef.getSlotKey());
            boolean filled = slotData != null && !isEmpty(slotData);
            
            if (filled) {
                filledCount++;
                SlotTypeHandler handler = slotTypeRegistry.getHandler(slotDef.getSlotType());
                ValidationResult vr = handler.validate(
                    slotData.getSlotData(), slotDef.getConstraints());
                
                if (vr.isValid()) validCount++;
                
                results.add(SlotValidationResult.builder()
                    .slotKey(slotDef.getSlotKey())
                    .filled(true)
                    .valid(vr.isValid())
                    .errors(vr.getErrors())
                    .build());
            } else {
                results.add(SlotValidationResult.builder()
                    .slotKey(slotDef.getSlotKey())
                    .filled(false)
                    .valid(!slotDef.isRequired())
                    .errors(slotDef.isRequired() ? 
                        List.of(ValidationError.of("required", "必填项未填充")) :
                        Collections.emptyList())
                    .build());
            }
        }

        return ValidationReport.builder()
            .overallValid(results.stream().allMatch(SlotValidationResult::isValid))
            .completionRate((double) filledCount / slotDefs.getSlots().size())
            .slotResults(results)
            .build();
    }

    private ContentMetadata buildMetadata(ContentInstance instance, 
                                           List<RenderBlock> blocks) {
        int wordCount = blocks.stream()
            .filter(b -> b.getBlockType() == BlockType.RICH_TEXT 
                      || b.getBlockType() == BlockType.PLAIN_TEXT)
            .mapToInt(b -> countWords(b.getData()))
            .sum();

        int mediaCount = blocks.stream()
            .mapToInt(b -> countMedia(b.getData()))
            .sum();

        // 基于内容量估算阅读时长（平均400字/分钟 + 媒体15秒/个）
        int estimatedMinutes = (int) Math.ceil(wordCount / 400.0 + mediaCount * 0.25);

        return ContentMetadata.builder()
            .subject(instance.getSubject())
            .stage(instance.getStage())
            .gradeLevel(instance.getGradeLevel())
            .wordCount(wordCount)
            .mediaCount(mediaCount)
            .estimatedDurationMin(estimatedMinutes)
            .build();
    }
}
```

### 7.3 RichTextSlotHandler 实现示例

```java
/**
 * 富文本槽位处理器
 * 处理含格式、图片、公式的富文本内容
 */
@Component
@Slf4j
public class RichTextSlotHandler implements SlotTypeHandler {

    @Autowired
    private OssClient ossClient;

    @Autowired
    private SensitiveWordFilter sensitiveWordFilter;

    @Override
    public SlotType getSlotType() {
        return SlotType.RICH_TEXT;
    }

    @Override
    public ValidationResult validate(Map<String, Object> slotData, 
                                      Map<String, Object> constraints) {
        List<ValidationError> errors = new ArrayList<>();
        
        String content = (String) slotData.getOrDefault("content", "");
        int textLength = stripHtml(content).length();

        // 校验最小长度
        Integer minLength = (Integer) constraints.get("min_length");
        if (minLength != null && textLength < minLength) {
            errors.add(ValidationError.of("min_length", 
                String.format("内容长度不足：当前%d字，最少要求%d字", textLength, minLength)));
        }

        // 校验最大长度
        Integer maxLength = (Integer) constraints.get("max_length");
        if (maxLength != null && textLength > maxLength) {
            errors.add(ValidationError.of("max_length",
                String.format("内容超出长度限制：当前%d字，最多允许%d字", textLength, maxLength)));
        }

        // 校验图片数量限制
        @SuppressWarnings("unchecked")
        List<Map<String, Object>> assets = (List<Map<String, Object>>) 
            slotData.getOrDefault("assets", Collections.emptyList());
        Boolean allowImages = (Boolean) constraints.getOrDefault("allow_images", true);
        if (!allowImages && !assets.isEmpty()) {
            errors.add(ValidationError.of("allow_images", "当前槽位不允许包含图片"));
        }
        Integer maxImages = (Integer) constraints.get("max_images");
        if (maxImages != null && assets.size() > maxImages) {
            errors.add(ValidationError.of("max_images",
                String.format("图片数量超限：当前%d张，最多允许%d张", assets.size(), maxImages)));
        }

        // 敏感词检测
        if (!sensitiveWordFilter.isClean(content)) {
            List<String> flagged = sensitiveWordFilter.findSensitiveWords(content);
            errors.add(ValidationError.of("sensitive_content",
                "内容包含敏感词：" + String.join("、", flagged)));
        }

        // XSS检测
        if (containsScriptTag(content)) {
            errors.add(ValidationError.of("xss", "内容包含不安全的脚本标签"));
        }

        return ValidationResult.builder()
            .valid(errors.isEmpty())
            .errors(errors)
            .build();
    }

    @Override
    @Transactional
    public Map<String, Object> preprocess(Map<String, Object> slotData, 
                                           PreprocessContext context) {
        String content = (String) slotData.get("content");
        
        // 1. 清洗HTML（移除危险标签和属性）
        content = sanitizeHtml(content);
        
        // 2. 处理Base64内联图片 → 上传OSS → 替换URL
        content = processInlineImages(content, context.getOperatorId());
        
        // 3. 标准化公式标签
        content = normalizeFormulaTags(content);
        
        Map<String, Object> processed = new HashMap<>(slotData);
        processed.put("content", content);

        // 4. 处理assets中的图片（压缩+格式转换）
        @SuppressWarnings("unchecked")
        List<Map<String, Object>> assets = (List<Map<String, Object>>)
            slotData.getOrDefault("assets", Collections.emptyList());
        
        List<Map<String, Object>> processedAssets = assets.stream()
            .map(asset -> processAsset(asset, context))
            .collect(Collectors.toList());
        processed.put("assets", processedAssets);

        return processed;
    }

    @Override
    public RenderBlock toRenderBlock(Map<String, Object> slotData, RenderContext context) {
        return RenderBlock.builder()
            .blockType(BlockType.RICH_TEXT)
            .data(slotData)
            .build();
    }

    @Override
    public Map<String, Object> getDefaultData(Map<String, Object> constraints) {
        Map<String, Object> data = new HashMap<>();
        data.put("content", "");
        data.put("assets", Collections.emptyList());
        return data;
    }

    private String sanitizeHtml(String html) {
        // 使用 OWASP Java HTML Sanitizer
        return Jsoup.clean(html, Safelist.relaxed()
            .addTags("span", "div", "p", "img", "sub", "sup", "em", "strong")
            .addAttributes("span", "class")
            .addAttributes("img", "src", "alt", "width", "height")
            .addProtocols("img", "src", "https")
            .preserveRelativeLinks(false));
    }

    private String processInlineImages(String content, Long operatorId) {
        Pattern pattern = Pattern.compile(
            "data:image/(png|jpeg|jpg|webp);base64,([A-Za-z0-9+/=]+)");
        Matcher matcher = pattern.matcher(content);
        StringBuffer sb = new StringBuffer();
        
        while (matcher.find()) {
            String format = matcher.group(1);
            String base64 = matcher.group(2);
            byte[] bytes = Base64.getDecoder().decode(base64);
            
            String objectKey = String.format("content/rich-text/%s/%s.%s",
                LocalDate.now(), UUID.randomUUID(), format);
            String url = ossClient.upload(objectKey, bytes, "image/" + format);
            
            matcher.appendReplacement(sb, Matcher.quoteReplacement(url));
        }
        matcher.appendTail(sb);
        return sb.toString();
    }
}
```

### 7.4 ExerciseRefSlotHandler 实现示例

```java
/**
 * 互动练习引用槽位处理器
 * 管理内容中嵌入的练习题引用
 */
@Component
public class ExerciseRefSlotHandler implements SlotTypeHandler {

    @Autowired
    private ExerciseServiceClient exerciseServiceClient;

    @Override
    public SlotType getSlotType() {
        return SlotType.EXERCISE_REF;
    }

    @Override
    public ValidationResult validate(Map<String, Object> slotData, 
                                      Map<String, Object> constraints) {
        List<ValidationError> errors = new ArrayList<>();

        @SuppressWarnings("unchecked")
        List<Map<String, Object>> refs = (List<Map<String, Object>>)
            slotData.getOrDefault("exercise_refs", Collections.emptyList());

        // 数量校验
        Integer minCount = (Integer) constraints.get("min_count");
        Integer maxCount = (Integer) constraints.get("max_count");
        
        if (minCount != null && refs.size() < minCount) {
            errors.add(ValidationError.of("min_count",
                String.format("练习数量不足：当前%d题，最少要求%d题", refs.size(), minCount)));
        }
        if (maxCount != null && refs.size() > maxCount) {
            errors.add(ValidationError.of("max_count",
                String.format("练习数量超限：当前%d题，最多允许%d题", refs.size(), maxCount)));
        }

        // 验证练习ID有效性
        @SuppressWarnings("unchecked")
        List<String> allowedTypes = (List<String>) constraints.get("exercise_types");
        
        for (int i = 0; i < refs.size(); i++) {
            Map<String, Object> ref = refs.get(i);
            String exerciseId = (String) ref.get("exercise_id");
            
            if (exerciseId == null || exerciseId.isBlank()) {
                errors.add(ValidationError.of("exercise_id", 
                    String.format("第%d题缺少练习ID", i + 1)));
                continue;
            }

            // 远程校验练习是否存在
            ExerciseInfo info = exerciseServiceClient.getExerciseInfo(exerciseId);
            if (info == null) {
                errors.add(ValidationError.of("exercise_not_found",
                    String.format("练习[%s]不存在", exerciseId)));
                continue;
            }

            // 校验题型
            if (allowedTypes != null && !allowedTypes.contains(info.getType())) {
                errors.add(ValidationError.of("exercise_type",
                    String.format("练习[%s]类型[%s]不在允许范围内", exerciseId, info.getType())));
            }

            // 校验难度范围
            @SuppressWarnings("unchecked")
            List<Integer> diffRange = (List<Integer>) constraints.get("difficulty_range");
            if (diffRange != null && diffRange.size() == 2) {
                if (info.getDifficulty() < diffRange.get(0) 
                    || info.getDifficulty() > diffRange.get(1)) {
                    errors.add(ValidationError.of("difficulty",
                        String.format("练习[%s]难度[%d]不在要求范围[%d-%d]内",
                            exerciseId, info.getDifficulty(), diffRange.get(0), diffRange.get(1))));
                }
            }
        }

        return ValidationResult.builder().valid(errors.isEmpty()).errors(errors).build();
    }

    @Override
    public RenderBlock toRenderBlock(Map<String, Object> slotData, RenderContext context) {
        @SuppressWarnings("unchecked")
        List<Map<String, Object>> refs = (List<Map<String, Object>>)
            slotData.getOrDefault("exercise_refs", Collections.emptyList());

        // 批量获取练习详情
        List<String> exerciseIds = refs.stream()
            .map(r -> (String) r.get("exercise_id"))
            .collect(Collectors.toList());

        Map<String, ExerciseInfo> infoMap = exerciseServiceClient.batchGetInfo(exerciseIds);

        List<Map<String, Object>> exercises = refs.stream()
            .map(ref -> {
                String eid = (String) ref.get("exercise_id");
                ExerciseInfo info = infoMap.get(eid);
                Map<String, Object> ex = new HashMap<>();
                ex.put("exercise_id", eid);
                ex.put("exercise_type", info != null ? info.getType() : "UNKNOWN");
                ex.put("question_preview", info != null ? info.getQuestionPreview() : "加载失败");
                ex.put("display_mode", ref.getOrDefault("display_mode", "INLINE"));
                ex.put("show_answer_by_default", ref.getOrDefault("show_answer_by_default", false));
                return ex;
            })
            .collect(Collectors.toList());

        return RenderBlock.builder()
            .blockType(BlockType.EXERCISE_GROUP)
            .data(Map.of("exercises", exercises))
            .build();
    }

    @Override
    public Map<String, Object> getDefaultData(Map<String, Object> constraints) {
        return Map.of("exercise_refs", Collections.emptyList());
    }
}
```

```dart
/// 内容渲染器 - 根据block_type分发到对应的渲染Widget
class ContentRenderer extends StatelessWidget {
  final List<RenderBlock> blocks;

  const ContentRenderer({super.key, required this.blocks});

  @override
  Widget build(BuildContext context) {
    return Column(
      children: blocks.map((block) => _buildBlock(context, block)).toList(),
    );
  }

  Widget _buildBlock(BuildContext context, RenderBlock block) {
    switch (block.blockType) {
      case 'PLAIN_TEXT':
        return _PlainTextWidget(data: block.data);
      case 'RICH_TEXT':
        return _RichTextWidget(data: block.data);
      case 'STRUCTURED_CONTAINER':
        return _StructuredContainerWidget(
          children: (block.data['children'] as List)
              .map((c) => RenderBlock.fromJson(c))
              .map((b) => _buildBlock(context, b))
              .toList(),
        );
      case 'BULLET_LIST':
        return _BulletListWidget(items: block.data['items']);
      case 'FORMULA':
        return MathFormulaWidget(latex: block.data['latex']);
      case 'EXAMPLE':
        return ExampleBlockWidget(data: block.data);
      case 'EXERCISE_GROUP':
        return ExerciseGroupWidget(
          exercises: (block.data['exercises'] as List)
              .map((e) => ExerciseRef.fromJson(e))
              .toList(),
        );
      case 'CALLOUT':
        return CalloutBoxWidget(
          variant: block.data['variant'],
          title: block.data['title'],
          content: block.data['content'],
        );
      case 'IMAGE':
        return ContentImageWidget(
          url: block.data['url'],
          alt: block.data['alt'],
        );
      case 'VIDEO':
        return ContentVideoWidget(url: block.data['url']);
      case 'DIVIDER':
        return const Padding(
          padding: EdgeInsets.symmetric(vertical: 16),
          child: Divider(),
        );
      default:
        return _UnknownBlockWidget(blockType: block.blockType);
    }
  }
```

## 9. 内容缓存与预热策略

### 9.1 组装结果缓存

组装后的内容体积较大且计算耗时，需要多层缓存：

```
请求 → CDN边缘缓存 → Redis热点缓存 → 应用本地缓存 → 数据库组装
```

| 缓存层 | TTL | 容量 | 失效策略 |
|--------|-----|------|----------|
| CDN | 30 min | 不限 | 内容更新时主动刷新URL |
| Redis | 60 min | 最近访问Top 5000 | 内容发布/更新时删除key |
| 本地缓存(Caffeine) | 10 min | Top 500 | 发布事件通知时清除 |

### 9.2 缓存Key设计

```
# 组装内容缓存
content:assembled:{instanceCode}:v{contentVersion}

# 模板定义缓存（读多写少）
content:template:{templateId}:v{version}

# 内容实例元信息
content:instance:meta:{instanceCode}
```

### 9.3 缓存失效流程

```java
/**
 * 内容发布时触发缓存失效
 */
@EventListener
public void onContentPublished(ContentPublishedEvent event) {
    String instanceCode = event.getInstanceCode();
    
    // 1. 删除Redis缓存
    String cacheKey = String.format("content:assembled:%s:v%d", 
        instanceCode, event.getNewVersion());
    redisTemplate.delete(cacheKey);
    
    // 2. 发布本地缓存失效事件
    applicationEventPublisher.publishEvent(
        new LocalCacheEvictEvent(cacheKey));
    
    // 3. 预热新版本缓存（异步）
    asyncWarmer.warmAsync(instanceCode, event.getNewVersion());
    
    // 4. 刷新CDN
    if (event.isPublished()) {
        cdnPurger.purgePath("/api/v1/content/" + instanceCode);
    }
}
```

### 13.2 XSS防护

所有富文本槽位在保存前经过HTML Sanitizer处理：
- 移除 `<script>`、`<iframe>`、`<object>` 等危险标签
- 移除 `on*` 事件属性（如 `onclick`、`onload`）
- 图片URL仅允许 HTTPS 协议
- 链接URL仅允许 HTTPS 或 mailto 协议

### 13.3 敏感词过滤

所有文本类槽位在保存和发布时经过敏感词检测：
- 保存时：检测并返回警告（允许保存但标记）
- 发布时：强制阻断，包含敏感词的内容不可发布
- 敏感词库支持多级别（政治/色情/暴力/广告/自定义）

## 14. 性能考量

### 14.1 数据库优化

- `content_slot_data` 表按 `content_instance_id` 分表（预估单表500万行后分表）
- 热点内容的槽位数据使用 Redis Hash 缓存：`content:slots:{instanceId}:v{version}`
- 模板定义JSON使用压缩存储（LZ4）
- 查询内容列表时避免 JOIN 槽位表，先查实例再批量查槽位

### 14.2 组装性能

- 单篇内容组装目标：< 100ms（缓存命中）/ < 300ms（冷组装）
- 批量组装使用并行流处理各槽位
- 练习引用使用批量RPC获取信息（避免N+1查询）
- 组装结果整体缓存，避免重复计算

### 14.3 数据量预估
