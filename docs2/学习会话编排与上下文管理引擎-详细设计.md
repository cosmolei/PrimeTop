# 学习会话编排与上下文管理引擎 — 详细设计

> 版本：v1.0 | 日期：2026-05-23 | 状态：初稿

## 1. 概述

### 1.1 背景

PrimeTop 的学习体验由多个功能模块组成：AI 智能辅导、同步课堂、拍题答疑、错题复习、练习测评等。用户的一次完整学习活动往往需要跨模块流转——例如"打开某章节 → 预习知识点 → 做练习 → 遇到错题 → AI 讲解 → 加入错题本"。

目前各模块的详细设计已经完成，但**模块间的运行时编排**、**跨模块上下文传递**和**会话状态管理**尚未有统一的设计。本文档定义学习会话（Learning Session）的生命周期、上下文模型、编排引擎和状态机，使开发人员能够在统一框架下串联各学习模块。

### 1.2 设计目标

1. **统一会话模型**：所有学习活动（AI 对话、拍题答疑、章节学习、错题复习、练习测评等）都纳入统一的会话框架。
2. **跨模块上下文传递**：用户从模块 A 跳转到模块 B 时，系统自动携带并衔接学习上下文。
3. **会话可恢复**：用户中断学习后（切换应用、锁屏、断网），重新进入时能恢复到上次状态。
4. **学习链路追踪**：完整记录用户的学习路径，用于学情分析和自适应推荐。
5. **适龄化适配**：会话编排策略根据用户学段自动调整。

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| LearningSession | 学习会话，用户从打开 APP 到离开的一次完整学习活动 |
| SessionContext | 会话上下文，包含当前学习目标、知识点、进度等元数据 |
| SessionNode | 会话节点，一次原子学习操作（如一次 AI 对话、一道题的解答） |
| SessionTransition | 会话流转，从一个节点到下一个节点的跳转逻辑 |
| SessionTemplate | 会话模板，预定义的学习流程（如"章节预习流"、"错题复习流"） |
| SessionCheckpoint | 会话检查点，用于持久化和恢复会话状态 |

## 2. 整体架构

### 2.1 架构分层

```

│                    客户端表现层                           │

└──────────────────────┬──────────────────────────────────┘

┌──────────────────────▼──────────────────────────────────┐

│  ┌──────────┐ ┌───────────┐ ┌──────────┐ ┌───────────┐ │

└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────┐
│                   服务端会话服务                           │
│  ┌──────────┐ ┌───────────┐ ┌──────────┐ ┌───────────┐ │
│  │ 会话CRUD │ │ 链路追踪   │ │ 模板管理  │ │ 统计聚合  │ │

                       │
```

### 2.2 核心组件职责

| 组件 | 职责 |
|------|------|
| Session Orchestrator | 客户端核心引擎，管理会话生命周期、节点流转和上下文 |
| 模板解析器 | 解析 SessionTemplate 定义，生成可执行的节点图 |
| 流转控制器 | 根据当前节点结果和模板规则，决定下一步跳转目标 |
| 上下文管理器 | 维护和传递会话上下文，支持跨模块共享 |
| 检查点管理器 | 定期持久化会话状态，支持断点恢复 |
| 服务端会话服务 | 会话元数据的 CRUD、链路事件记录和统计分析 |

## 3. 数据模型

### 3.1 核心实体

#### 3.1.1 LearningSession（学习会话）

```sql
CREATE TABLE learning_sessions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    session_type    VARCHAR(32) NOT NULL COMMENT '会话类型: chapter_preview/chapter_review/practice/error_review/exam_simulation/ai_tutoring/free_explore',
    template_id     VARCHAR(64) NULL COMMENT '使用的模板ID',
    status          VARCHAR(16) NOT NULL DEFAULT 'active' COMMENT 'active/paused/completed/abandoned',
    
    -- 学习目标
    subject_id      INT NULL COMMENT '学科ID',
    grade_id        INT NULL COMMENT '年级ID',
    textbook_id     INT NULL COMMENT '教材ID',
    chapter_id      INT NULL COMMENT '章节ID（可为空表示跨章节）',
    knowledge_point_ids JSON NULL COMMENT '关联知识点ID列表',
    
    -- 时间
    started_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    last_active_at  DATETIME NOT NULL COMMENT '最后活跃时间',
    completed_at    DATETIME NULL,
    total_duration_sec INT NOT NULL DEFAULT 0 COMMENT '累计学习时长（秒）',
    
    -- 上下文快照（最后检查点）
    context_snapshot JSON NULL COMMENT '会话上下文快照',
    checkpoint_at   DATETIME NULL COMMENT '最后检查点时间',
    
    -- 统计
    nodes_completed INT NOT NULL DEFAULT 0 COMMENT '完成节点数',
    questions_attempted INT NOT NULL DEFAULT 0 COMMENT '答题数',
    correct_count   INT NOT NULL DEFAULT 0 COMMENT '正确数',
    
    -- 元数据
    app_version     VARCHAR(16) NULL COMMENT '客户端版本',
    device_id       VARCHAR(64) NULL COMMENT '设备ID',
    platform        VARCHAR(16) NULL COMMENT 'android/ios/web',
    
    INDEX idx_user_status (user_id, status, last_active_at),
    INDEX idx_user_time (user_id, started_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.2 SessionNode（会话节点）

```sql
CREATE TABLE session_nodes (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      BIGINT NOT NULL COMMENT '所属会话ID',
    node_index      INT NOT NULL COMMENT '节点顺序（从0开始）',
    node_type       VARCHAR(32) NOT NULL COMMENT '节点类型: ai_chat/photo_solve/chapter_read/practice_question/error_review/knowledge_review/break',
    
    -- 关联资源
    target_id       VARCHAR(64) NULL COMMENT '目标资源ID（题ID/章节ID/知识点ID）',
    target_type     VARCHAR(32) NULL COMMENT '目标资源类型: question/chapter/knowledge_point/conversation',
    
    -- 输入上下文
    input_context   JSON NULL COMMENT '节点输入上下文（进入时快照）',
    
    -- 节点状态
    status          VARCHAR(16) NOT NULL DEFAULT 'pending' COMMENT 'pending/active/completed/skipped/failed',
    started_at      DATETIME NULL,
    completed_at    DATETIME NULL,
    duration_sec    INT NOT NULL DEFAULT 0,
    
    -- 节点结果
    result          JSON NULL COMMENT '节点执行结果（答案/评分/理解度等）',
    outcome         VARCHAR(16) NULL COMMENT '节点结局: pass/fail/partial/skip',
    
    -- 流转
    transition_rule VARCHAR(32) NULL COMMENT '使用的流转规则',
    next_node_index INT NULL COMMENT '下一个节点索引（NULL=会话结束）',
    
    INDEX idx_session (session_id, node_index),
    INDEX idx_session_status (session_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.3 SessionContext（会话上下文）— JSON 结构

```typescript
interface SessionContext {
    // === 用户信息 ===
    userId: number;
    gradeId: number;
    gradeStage: 'kindergarten' | 'primary' | 'junior' | 'senior';
    textbookId: number;
    
    // === 学习目标 ===
    objective: {
        type: 'preview' | 'review' | 'practice' | 'exam_prep' | 'error_correction' | 'free_explore';
        subjectId: number;
        chapterId?: number;
        knowledgePointIds: number[];
        targetExamDate?: string;       // 考试日期（考试模式）
        targetCompletionRate?: number;  // 目标完成率
    };
    
    // === 学习进度 ===
    progress: {
        currentNodeIndex: number;
        totalNodesEstimated: number;
        completionRate: number;        // 0.0 - 1.0
        masteryLevels: Record<number, number>;  // knowledgePointId → mastery (0.0-1.0)
        weakPoints: number[];           // 薄弱知识点ID
    };
    
    // === 知识上下文 ===
    knowledgeContext: {
        recentTopics: string[];         // 最近讨论的主题（用于AI上下文）
        recentQuestionIds: number[];    // 最近答过的题（避免重复推荐）
        recentErrorIds: number[];       // 最近复习过的错题
        aiConversationSummary?: string; // AI对话摘要（用于跨节点延续）
    };
    
    // === 行为上下文 ===
    behaviorContext: {
        consecutiveCorrectCount: number;  // 连续正确数
        consecutiveWrongCount: number;    // 连续错误数
        sessionDurationSec: number;       // 已学习时长
        breakNeeded: boolean;             // 是否需要休息提醒
        fatigueScore: number;             // 疲劳度 (0.0-1.0)
    };
    
    // === 适配参数 ===
    adaptation: {
        difficultyLevel: number;          // 当前难度 (1-5)
        hintFrequency: 'high' | 'medium' | 'low';  // 提示频率
        encouragementStyle: 'praise' | 'neutral' | 'challenge';  // 鼓励风格
        maxContinuousQuestions: number;    // 连续答题上限
    };
}
```

```sql
CREATE TABLE session_events (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      BIGINT NOT NULL,
    node_id         BIGINT NULL,
    event_type      VARCHAR(32) NOT NULL COMMENT 'session_start/node_enter/node_complete/transition/context_update/break/resume/session_end',
```

## 4. 会话模板系统

### 4.1 模板定义格式

```typescript
interface SessionTemplate {
    id: string;
    name: string;
    description: string;
    applicableStages: GradeStage[];    // 适用学段
    applicableSubjects: number[];      // 适用学科（空=全部）
    
    // 入口触发条件
    trigger: {
        source: 'chapter_select' | 'error_book' | 'study_plan' | 'exam_prep' | 'ai_suggestion' | 'user_manual';
        conditions?: Record<string, any>;  // 额外触发条件
    };
    
    // 节点图
    nodes: TemplateNode[];
    transitions: TemplateTransition[];
    
    // 全局设置
    settings: {
        maxDurationMin?: number;           // 最大时长（分钟），超时自动暂停
        breakIntervalMin?: number;         // 休息间隔（分钟）
        breakDurationMin?: number;         // 休息时长（分钟）
        enableAIContext?: boolean;         // 是否在整个会话中维持AI上下文
        contextWindowSize?: number;        // 上下文窗口大小（token数）
    };
}

interface TemplateNode {
    id: string;
    type: NodeType;
    config: Record<string, any>;     // 节点配置
    required: boolean;               // 是否可跳过
    retryable: boolean;              // 失败后是否可重试
    maxRetries?: number;
}

interface TemplateTransition {
    from: string;                     // 源节点ID 或 'start'
    to: string;                       // 目标节点ID 或 'end'
    condition: TransitionCondition;   // 触发条件
    action?: TransitionAction;        // 流转时的动作
}

type TransitionCondition = 
    | { type: 'always' }
    | { type: 'outcome', outcome: string }           // 'pass' | 'fail' | 'partial'
    | { type: 'mastery', minMastery: number }         // 掌握度阈值
    | { type: 'consecutive_correct', count: number }
    | { type: 'consecutive_wrong', count: number }
    | { type: 'duration', maxSec: number }
    | { type: 'custom', expression: string };         // 自定义表达式

type TransitionAction = 
    | { type: 'adjust_difficulty', delta: number }
    | { type: 'add_nodes', nodeTemplates: TemplateNode[] }
    | { type: 'set_context', key: string, value: any }
    | { type: 'trigger_break' }
    | { type: 'send_notification', template: string };
```

## 5. 状态机设计

### 5.1 会话生命周期

```
                    ┌─────────┐
          创建会话   │ created │
              ┌─────┴─────────┘
              │
              ▼
        ┌──────────┐
        │  active  │◄──────────────┐
        └────┬─────┘               │
             │                     │
     ┌───────┼────────┐            │
     │       │        │            │
     ▼       ▼        ▼            │
┌────────┐┌───────┐┌───────┐      │
│paused  ││completed││abandoned    │
│(用户切出││(正常结束││(用户主动     │
│ /锁屏/  ││或完成所 ││放弃)        │
│ 断网)   ││有节点) ││             │
└───┬────┘└───────┘└───────┘      │
    │                              │
    │ 恢复条件满足                   │
    └──────────────────────────────┘
```

### 5.2 节点状态流转

```
  ┌──────────┐
  │ pending  │ (等待执行)
  └────┬─────┘
       │ 进入节点
       ▼
  ┌──────────┐
  │  active  │ (执行中)
  └──┬───┬───┘
     │   │
     │   │ 超时/异常
     │   ▼
     │ ┌──────────┐
     │ │  failed  │ ──重试──► pending
     │ └──────────┘
     │
     │ 用户完成节点
     ▼
  ┌──────────┐
  │completed │ (outcome: pass/fail/partial)
  └──────────┘
       │
       │ 用户主动跳过
       ▼
  ┌──────────┐
  │ skipped  │ (可跳过的非必要节点)
  └──────────┘
```

### 5.3 会话暂停与恢复规则

| 暂停触发 | 检查点行为 | 恢复行为 |
|----------|-----------|----------|
| 用户切到后台 | 立即保存检查点（内存→本地DB） | 恢复到当前节点，保留上下文 |
| 锁屏 | 同上 | 同上 |
| 网络断开 | 本地保存，标记 `offline_checkpoint` | 重连后同步到服务端 |
| 应用被系统回收 | 最后一次定期检查点 | 恢复到最近检查点，可能丢失少量进度 |
| 用户主动退出 | 弹出确认 → 保存检查点 | 下次进入会话恢复列表 |
| 超时（超过 maxDurationMin） | 自动暂停，标记 `timeout_paused` | 询问用户是否继续 |

## 8. 流转控制器详细设计

### 8.1 流转决策算法

```python
def determine_next_node(session: LearningSession, current_node: SessionNode, 
                        context: SessionContext) -> Optional[SessionNode]:
    """根据当前节点结果和会话上下文，决定下一个节点"""
    
    template = load_template(session.template_id)
    
    # 1. 查找匹配的 transition 规则
    matching_transitions = []
    for transition in template.transitions:
        if transition.from != current_node.id and transition.from != 'any':
            continue
        if evaluate_condition(transition.condition, current_node, context):
            matching_transitions.append(transition)
    
    if not matching_transitions:
        # 无匹配规则，尝试默认流转（下一个序号的节点）
        next_index = current_node.node_index + 1
        if next_index < len(template.nodes):
            return template.nodes[next_index]
        return None  # 会话结束
    
    # 2. 按优先级选择（outcome > mastery > consecutive > duration > always）
    priority_order = ['outcome', 'mastery', 'consecutive_correct', 
                      'consecutive_wrong', 'duration', 'custom', 'always']
    selected = None
    for prio in priority_order:
        for t in matching_transitions:
            if t.condition.type == prio:
                selected = t
                break
        if selected:
            break
    
    if not selected:
        selected = matching_transitions[0]
    
    # 3. 执行 transition action
    if selected.action:
        execute_action(selected.action, context)
    
    # 4. 返回目标节点
    if selected.to == 'end':
        return None
    
    target_node = find_node_by_id(template, selected.to)
    
    # 5. 特殊处理：动态添加节点
    if selected.action and selected.action.type == 'add_nodes':
        insert_dynamic_nodes(session, selected.action.nodeTemplates, 
                            after_index=current_node.node_index)
    
    return target_node


def evaluate_condition(condition: TransitionCondition, node: SessionNode, 
                       context: SessionContext) -> bool:
    """评估流转条件"""
    if condition.type == 'always':
        return True
    elif condition.type == 'outcome':
        return node.outcome == condition.outcome
    elif condition.type == 'mastery':
        avg_mastery = calculate_avg_mastery(context.progress.masteryLevels)
        return avg_mastery >= condition.minMastery
    elif condition.type == 'consecutive_correct':
        return context.behaviorContext.consecutiveCorrectCount >= condition.count
    elif condition.type == 'consecutive_wrong':
        return context.behaviorContext.consecutiveWrongCount >= condition.count
    elif condition.type == 'duration':
        return context.behaviorContext.sessionDurationSec <= condition.maxSec
    elif condition.type == 'custom':
        return eval_custom_expression(condition.expression, node, context)
    return False
```

### 8.2 动态适配策略

流转控制器在每次节点流转时，会根据上下文自动调整以下参数：

| 参数 | 调整规则 | 触发条件 |
|------|----------|----------|
| 难度等级 (1-5) | +1（连续3题正确） / -1（连续2题错误） | `consecutiveCorrect >= 3` 或 `consecutiveWrong >= 2` |
| 提示频率 | high→medium（连续5题正确） / medium→high（连续3题错误） | 基于连续正确/错误数 |
| 疲劳度 | 每分钟 +0.02，答错 +0.05，答对 -0.01 | `fatigueScore >= 0.7` 触发休息提醒 |
| 学习节奏 | 插入 break 节点 | `sessionDuration >= breakIntervalMin` 且 `fatigueScore >= 0.5` |
| AI 对话风格 | challenge→neutral（疲劳度高） / neutral→praise（连续错误后首次正确） | 基于行为上下文 |

```python
def update_adaptation(context: SessionContext, node_result: NodeResult):
    """根据节点结果更新适配参数"""
    adaptation = context.adaptation
    behavior = context.behaviorContext
    
    # 难度调整
    if behavior.consecutiveCorrectCount >= 3:
        adaptation.difficultyLevel = min(5, adaptation.difficultyLevel + 1)
        behavior.consecutiveCorrectCount = 0
    elif behavior.consecutiveWrongCount >= 2:
        adaptation.difficultyLevel = max(1, adaptation.difficultyLevel - 1)
        behavior.consecutiveWrongCount = 0
    
    # 提示频率调整
    if behavior.consecutiveCorrectCount >= 5 and adaptation.hintFrequency == 'high':
        adaptation.hintFrequency = 'medium'
    elif behavior.consecutiveWrongCount >= 3 and adaptation.hintFrequency == 'medium':
        adaptation.hintFrequency = 'high'
    
    # 疲劳度计算
    behavior.fatigueScore = min(1.0, behavior.fatigueScore + 0.02)  # 时间因子
    if node_result.outcome == 'fail':
        behavior.fatigueScore = min(1.0, behavior.fatigueScore + 0.05)
    elif node_result.outcome == 'pass':
        behavior.fatigueScore = max(0.0, behavior.fatigueScore - 0.01)
    
    # 鼓励风格
    if behavior.consecutiveWrongCount >= 3 and node_result.outcome == 'pass':
        adaptation.encouragementStyle = 'praise'  # 终于答对了，表扬
    elif behavior.fatigueScore >= 0.7:
        adaptation.encouragementStyle = 'neutral'  # 疲劳时减少刺激性
    elif behavior.consecutiveCorrectCount >= 5:
        adaptation.encouragementStyle = 'challenge'  # 状态好，上难度
```

### 9.3 AI 上下文管理

在整个会话中维持 AI 对话上下文的连续性：

```python
class SessionAIContextManager:
    """会话级 AI 上下文管理器"""
    
    def __init__(self, session_id: int, context: SessionContext):
        self.session_id = session_id
        self.context = context
        self.conversation_buffer = []  # 跨节点的对话摘要
        self.token_budget = context.adaptation.get('contextWindowSize', 4000)
    
    def build_system_prompt(self, node_type: str) -> str:
        """根据当前节点类型和会话上下文构建系统提示"""
        base_prompt = load_template_prompt(node_type)
        
        # 注入会话上下文
        context_injection = self._serialize_context_for_prompt()
        
        # 注入对话历史摘要
        history_summary = self._compress_history()
        
        return f"""{base_prompt}

## 当前学习会话上下文
{context_injection}

## 之前的学习摘要
{history_summary}"""
    
    def _serialize_context_for_prompt(self) -> str:
        ctx = self.context
        return f"""- 学段/年级: {ctx.gradeStage}/{ctx.gradeId}
- 当前学科: {ctx.objective.subjectId}
- 章节: {ctx.objective.chapterId or '未指定'}
- 学习目标: {ctx.objective.type}
- 进度: {ctx.progress.completionRate*100:.0f}%
- 当前难度: {ctx.adaptation.difficultyLevel}/5
- 连续正确/错误: {ctx.behaviorContext.consecutiveCorrectCount}/{ctx.behaviorContext.consecutiveWrongCount}
- 疲劳度: {ctx.behaviorContext.fatigueScore:.1f}
- 薄弱知识点: {ctx.progress.weakPoints}"""
    
    def _compress_history(self) -> str:
        """将跨节点对话历史压缩为摘要，控制在 token 预算内"""
        total_tokens = estimate_tokens(self.conversation_buffer)
        if total_tokens <= self.token_budget * 0.3:  # 历史占不超过30%预算
            return format_conversation(self.conversation_buffer)
        
        # 超出预算，用摘要模型压缩
        summary = summarize_conversation(self.conversation_buffer)
        return summary
    
    def record_exchange(self, role: str, content: str, node_id: str):
        """记录一次对话交换"""
        self.conversation_buffer.append({
            'role': role,
            'content': content,
            'node_id': node_id,
            'timestamp': datetime.now().isoformat()
        })
        
        # 超过容量时自动压缩
        if len(self.conversation_buffer) > 50:
            self._auto_compress()
    
    def _auto_compress(self):
        """自动压缩：保留最近10条完整对话 + 更早部分的摘要"""
        recent = self.conversation_buffer[-10:]
        older = self.conversation_buffer[:-10]
        older_summary = summarize_conversation(older)
        self.conversation_buffer = [
```

```typescript
// session_orchestrator.ts

class SessionOrchestrator {
    private activeSession: LearningSession | null;
    private context: SessionContext;
    private templateEngine: TemplateEngine;
    private transitionController: TransitionController;
    private checkpointManager: CheckpointManager;
    private contextManager: ContextManager;
    
    /**
     * 启动一个新会话
     */
    async startSession(params: StartSessionParams): Promise<SessionStartResult> {
        // 1. 检查是否有冲突的活跃会话
        const activeSession = await this.findActiveSession();
        if (activeSession) {
            return { type: 'conflict', existingSession: activeSession };
        }
        
        // 2. 加载并解析模板
        const template = this.templateEngine.load(params.templateId);
        
        // 3. 初始化上下文
        this.context = await this.contextManager.initialize({
            userId: params.userId,
            gradeId: params.gradeId,
            ...params
        });
        
        // 4. 创建服务端会话
        const session = await api.post('/sessions', {
            sessionType: params.sessionType,
            templateId: params.templateId,
            ...params
        });
        
        this.activeSession = session;
        
        // 5. 启动定期检查点
        this.checkpointManager.startAutoCheckpoint(session.id, intervalSec: 30);
        
        // 6. 记录事件
        await this.recordEvent('session_start', { templateId: params.templateId });
        
        return { 
            type: 'started', 
            session,
            firstNode: template.nodes[0]
        };
    }
    
    /**
     * 完成当前节点并流转到下一个
     */
    async completeCurrentNode(result: NodeResult): Promise<TransitionResult> {
        const currentNode = this.getCurrentNode();
        
        // 1. 更新节点状态
        currentNode.status = 'completed';
        currentNode.outcome = this.evaluateOutcome(result);
        currentNode.result = result;
        
        // 2. 更新上下文
        this.context = this.contextManager.updateAfterNode(this.context, result);
        
        // 3. 决定下一个节点
        const nextNode = this.transitionController.determineNext(
            this.activeSession, currentNode, this.context
        );
        
        // 4. 上报服务端
        await api.put(`/sessions/${this.activeSession.id}/nodes/${currentNode.index}/complete`, {
            outcome: currentNode.outcome,
            result: result,
            contextUpdate: this.contextManager.getDelta()
        });
        
        // 5. 保存检查点
        await this.checkpointManager.save(this.activeSession.id, this.context);
        
        // 6. 判断是否需要休息
        if (this.shouldSuggestBreak()) {
            return { type: 'break_suggested', nextNode };
        }
        
        if (!nextNode) {
            return { type: 'session_complete' };
        }
        
        return { type: 'next_node', node: nextNode };
    }
    
    /**
     * 暂停会话
     */
    async pauseSession(reason: string): Promise<void> {
        if (!this.activeSession) return;
        
        // 保存当前状态
        await this.checkpointManager.save(this.activeSession.id, this.context);
        
        // 通知服务端
        await api.put(`/sessions/${this.activeSession.id}/pause`, {
            reason,
            checkpoint: this.checkpointManager.getSnapshot()
        });
        
        this.activeSession.status = 'paused';
        this.checkpointManager.stopAutoCheckpoint();
    }
    
    /**
     * 恢复会话
     */
    async resumeSession(sessionId: number): Promise<ResumeResult> {
        // 1. 从服务端获取最新状态
        const session = await api.get(`/sessions/${sessionId}`);
        
        // 2. 恢复上下文
        this.context = await this.contextManager.restore(session.context);
        
        // 3. 通知服务端
        await api.put(`/sessions/${sessionId}/resume`);
        
        this.activeSession = session;
        this.checkpointManager.startAutoCheckpoint(session.id, intervalSec: 30);
        
        // 4. 返回当前节点信息
        const currentNode = this.getCurrentNode();
        return { session, currentNode };
    }
}
```

### 10.2 检查点管理器

```typescript
class CheckpointManager {
    private autoCheckpointTimer: NodeJS.Timer | null;
    private localDB: LocalDatabase;
    
    /**
     * 启动自动检查点
     */
    startAutoCheckpoint(sessionId: number, intervalSec: number): void {
        this.stopAutoCheckpoint();
        this.autoCheckpointTimer = setInterval(async () => {
            await this.save(sessionId, this.getCurrentContext());
        }, intervalSec * 1000);
    }
    
    stopAutoCheckpoint(): void {
        if (this.autoCheckpointTimer) {
            clearInterval(this.autoCheckpointTimer);
            this.autoCheckpointTimer = null;
        }
    }
    
    /**
     * 保存检查点（双重写入：本地 + 服务端）
     */
    async save(sessionId: number, context: SessionContext): Promise<void> {
        const checkpoint = {
            sessionId,
            currentNodeIndex: context.progress.currentNodeIndex,
            contextSnapshot: JSON.stringify(context),
            clientTimestamp: new Date().toISOString()
        };
        
        // 本地立即写入（SQLite/Hive）
        await this.localDB.saveCheckpoint(checkpoint);
        
        // 服务端异步写入（失败不阻塞）
        api.post(`/sessions/${sessionId}/checkpoint`, checkpoint)
            .catch(err => {
                // 标记为待同步
                this.localDB.markCheckpointPendingSync(sessionId);
            });
    }
    
    /**
     * 获取最新检查点（合并本地和服务端）
     */
    async getLatestCheckpoint(sessionId: number): Promise<Checkpoint | null> {
        const local = await this.localDB.getCheckpoint(sessionId);
        
        try {
            const remote = await api.get(`/sessions/${sessionId}/checkpoint`);
            
            // 以时间戳较新的为准
            if (local && new Date(local.clientTimestamp) > new Date(remote.clientTimestamp)) {
                return local;  // 本地更新（离线期间产生的）
            }
            return remote;
        } catch {
            // 服务端不可用时使用本地
            return local;
        }
    }
}
```

```java
@Service
public class SessionService {
    
    @Autowired
    private RedissonClient redisson;
    
    /**
     * 完成节点（需要分布式锁防止并发操作）
     */
    public NodeCompleteResult completeNode(Long sessionId, Integer nodeIndex, 
                                           NodeCompleteRequest request) {
        String lockKey = "session:node:" + sessionId + ":" + nodeIndex;
        RLock lock = redisson.getLock(lockKey);
        
        try {
            // 获取分布式锁（最多等待5秒，锁定30秒）
            boolean acquired = lock.tryLock(5, 30, TimeUnit.SECONDS);
            if (!acquired) {
                throw new BusinessException(ErrorCode.CONCURRENT_CONFLICT, 
                    "节点操作冲突，请稍后重试");
            }
            
            // 1. 验证会话和节点状态
            LearningSession session = sessionMapper.selectById(sessionId);
            validateSessionActive(session);
            
            SessionNode node = nodeMapper.selectBySessionAndIndex(sessionId, nodeIndex);
            validateNodeActive(node);
            
            // 2. 更新节点
            node.setStatus("completed");
            node.setOutcome(request.getOutcome());
            node.setResult(JSON.toJSONString(request.getResult()));
            node.setCompletedAt(LocalDateTime.now());
            node.setDurationSec((int) Duration.between(node.getStartedAt(), 
                LocalDateTime.now()).getSeconds());
            nodeMapper.updateById(node);
            
            // 3. 更新会话统计
            session.setNodesCompleted(session.getNodesCompleted() + 1);
            session.setLastActiveAt(LocalDateTime.now());
            if (request.getResult() != null && request.getResult().getQuestionsAttempted() != null) {
                session.setQuestionsAttempted(
                    session.getQuestionsAttempted() + request.getResult().getQuestionsAttempted());
                session.setCorrectCount(
                    session.getCorrectCount() + request.getResult().getCorrectCount());
            }
            sessionMapper.updateById(session);
            
            // 4. 更新 Redis 缓存
            String cacheKey = "session:context:" + sessionId;
            String contextJson = JSON.toJSONString(request.getContextUpdate());
            redisTemplate.opsForValue().set(cacheKey, contextJson, 2, TimeUnit.HOURS);
            
            // 5. 异步记录事件
            eventService.recordEvent(sessionId, node.getId(), "node_complete", 
                JSON.toJSONString(request));
            
            // 6. 异步触发下游处理（学情更新、成就检测等）
            eventPublisher.publishEvent(new NodeCompletedEvent(sessionId, nodeIndex, 
                request.getOutcome()));
            
            return NodeCompleteResult.success();
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new BusinessException(ErrorCode.INTERRUPTED, "操作被中断");
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

```java
@Component
public class SessionCleanupTask {
    
    /**
     * 每小时执行一次：清理超时的活跃/暂停会话
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void cleanupStaleSessions() {
        LocalDateTime staleThreshold = LocalDateTime.now().minusHours(24);
        
        // 1. 找出超过24小时未活跃的会话
        List<LearningSession> staleSessions = sessionMapper.selectList(
            new QueryWrapper<LearningSession>()
                .in("status", "active", "paused")

            session.setStatus("abandoned");
            session.setCompletedAt(LocalDateTime.now());
            sessionMapper.updateById(session);
            
            // 记录事件
            eventService.recordEvent(session.getId(), null, "session_auto_abandoned", 
                "{"reason":"stale_24h"}");
            
            // 清理 Redis 缓存
            redisTemplate.delete("session:context:" + session.getId());
        }
        
        log.info("Cleaned up {} stale sessions", staleSessions.size());
    }
```

## 13. 错误处理

### 13.1 错误码定义

| 错误码 | 说明 | 客户端处理 |
|--------|------|------------|
| `SESSION_NOT_FOUND` | 会话不存在 | 提示用户，返回首页 |
| `SESSION_NOT_ACTIVE` | 会话非活跃状态 | 提示状态，提供恢复入口 |
| `SESSION_CONFLICT` | 存在冲突的活跃会话 | 弹出选择：继续旧会话 or 结束旧会话创建新会话 |
| `NODE_ALREADY_COMPLETED` | 节点已完成 | 忽略，跳到当前活跃节点 |
| `NODE_NOT_ACTIVE` | 节点非活跃 | 刷新会话状态 |
| `CONCURRENT_CONFLICT` | 并发操作冲突 | 提示重试 |
| `TEMPLATE_NOT_FOUND` | 模板不存在 | 降级为自由探索模式 |
| `TEMPLATE_PARSE_ERROR` | 模板解析错误 | 降级为顺序执行模式 |
| `CHECKPOINT_CORRUPTED` | 检查点数据损坏 | 从上一个有效检查点恢复或重新开始 |
| `CONTEXT_SYNC_FAILED` | 上下文同步失败 | 使用本地上下文继续，标记待同步 |
| `SESSION_TIMEOUT` | 会话超时 | 弹出提示，可继续或结束 |
| `SESSION_LIMIT_EXCEEDED` | 用户同时活跃会话数超限 | 提示结束已有会话 |

### 13.2 容错策略

```
网络断开时的处理流程:

1. 检测到网络断开
   ├── 本地继续执行当前节点（不阻塞用户）
   ├── 本地保存检查点（标记 offline_checkpoint）
   └── 操作队列缓存到本地

2. 网络恢复
   ├── 批量上传缓存的操作和事件
   ├── 上传最新检查点
   └── 同步服务端上下文（如果有变更）

3. 冲突处理（本地和服务端都更新了）
   ├── 以时间戳较新的为准
   ├── 如果无法自动合并，以服务端为准
   └── 记录冲突事件供后续分析
```

### 13.3 降级策略

| 场景 | 降级方案 |
|------|----------|
| 模板服务不可用 | 使用内置默认模板（顺序执行） |
| 会话服务不可用 | 本地创建会话，后台异步同步 |
| 检查点服务不可用 | 仅本地保存，网络恢复后同步 |
| 学情分析服务不可用 | 跳过掌握度更新，使用历史值 |
| AI 服务不可用 | AI 节点降级为知识卡片展示 |
| 题库服务不可用 | 练习节点跳过，进入下一节点 |

```
   ├── 活跃会话上下文（TTL=2h，自动续期）
   ├── 活跃会话列表（TTL=2h）
   └── 模板定义缓存（TTL=1h，版本变化时刷新）

4. 服务端 MySQL
   ├── 会话元数据
   ├── 节点状态
   └── 事件记录

5. ClickHouse
   └── 事件流数据（用于分析）
```
