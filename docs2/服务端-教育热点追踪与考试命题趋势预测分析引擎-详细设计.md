## 1. 模块概述

### 1.1 功能定位

教育热点追踪与考试命题趋势预测分析引擎（以下简称"趋势引擎"）是 PrimeTop 平台级的智能分析服务，负责：

1. **平台热度追踪**：实时汇总全平台学生学习行为数据，识别当前热门知识点、高频搜索题目、高频错题和高频提问内容。
2. **考试命题趋势分析**：基于历年真题数据，结合知识点权重变化、题型分布演变，分析中考/高考等关键考试的命题趋势。
3. **命题方向预测**：利用时间序列模型 + 知识图谱关联，对未来考试季可能出现的考点进行概率预测。
4. **内容生产指导**：为内容运营团队输出"热点内容生产建议"，指导题库补充和专题策划。
5. **学生端高频考点推荐**：将分析结果下发给"考点梳理"模块，在学生端呈现"本月高频考点""考前预测专题"等内容。

### 1.2 核心价值

| 价值维度 | 说明 |
|----------|------|
| 学生侧 | 让学生在备考冲刺阶段聚焦高频考点，提升复习效率 |
| 内容侧 | 指导内容团队优先生产高价值题目和解析，避免盲目铺量 |
| 运营侧 | 为运营活动（专题营、冲刺包）提供数据支撑 |
| 产品侧 | 增强"考点梳理"模块的时效性和权威性 |

### 1.4 设计约束

1. 趋势数据存在**地域差异**（不同省份教材版本、考试卷型不同），分析结果需按地区维度隔离。
2. 考试命题预测具有**敏感性**，面向学生的预测内容须标注"参考性质"，避免引发焦虑或赌题行为。
3. 平台热度数据需要**T+1 粒度**即可，不需要实时；命题趋势预测按**周/月**粒度更新。
4. 数据来源涉及用户行为日志，需脱敏处理，不暴露个体信息。

## 3. 核心算法设计

### 3.1 热度分值计算

#### 3.1.1 算法公式

```
HotScore(kp, date) = Σ(wi × normalize(signal_i)) × TimeDecay(kp, date)

其中:
  wi              = 权重系数（来自 trend_hot_score_weight 配置表）
  normalize(x)    = log10(x + 1) / log10(max_signal + 1)   -- 对数归一化
  TimeDecay(kp)   = 指数衰减因子，反映该知识点的持续关注度
```

#### 3.1.2 时间衰减因子

```
TimeDecay(kp, date) = 1 - e^(-λ × recentActiveDays(kp))

其中:
  λ                = ln(2) / half_life_days   (默认半衰期30天)
  recentActiveDays = 过去90天内该知识点有行为记录的天数
```

**设计意图**：避免一次性爆发后迅速归零，持续被讨论的知识点保持高热度。

#### 3.1.3 代码实现

```java
@Service
public class HotScoreCalculator {

    @Autowired
    private TrendHotScoreWeightRepository weightRepo;

    /**
     * 计算单日知识点热度分值
     *
     * @param signal    当日各信号聚合值
     * @param weight    权重配置
     * @param recentActiveDays 过去90天活跃天数
     * @return 热度分值（0 ~ 100）
     */
    public BigDecimal calculateKnowledgePointHotScore(
            KnowledgePointSignal signal,
            TrendHotScoreWeight weight,
            int recentActiveDays) {

        // 1. 各信号对数归一化
        double normSearch     = logNormalize(signal.getSearchCount());
        double normView       = logNormalize(signal.getQuestionViewCount());
        double normAiAsk      = logNormalize(signal.getAiAskCount());
        double normMistake    = logNormalize(signal.getMistakeCount());
        double normPractice   = logNormalize(signal.getPracticeCount());
        double normErrorRate  = Math.min(signal.getErrorRate().doubleValue(), 1.0);

        // 2. 加权求和
        double rawScore = 0;
        rawScore += weight.getWSearch().doubleValue()       * normSearch;
        rawScore += weight.getWQuestionView().doubleValue() * normView;
        rawScore += weight.getWAiAsk().doubleValue()        * normAiAsk;
        rawScore += weight.getWMistake().doubleValue()      * normMistake;
        rawScore += weight.getWPractice().doubleValue()     * normPractice;
        rawScore += weight.getWErrorRate().doubleValue()    * normErrorRate;

        // 3. 时间衰减
        double lambda = Math.log(2) / weight.getHalfLifeDays();
        double timeDecay = 1.0 - Math.exp(-lambda * recentActiveDays);

        // 4. 缩放到 0~100
        double finalScore = rawScore * timeDecay * 100.0;

        return BigDecimal.valueOf(finalScore)
                .setScale(2, RoundingMode.HALF_UP);
    }

    /**
     * 对数归一化：将正整数信号压缩到 [0, 1] 区间
     * 使用 log10(x+1) 变换，缓解长尾分布
     */
    private double logNormalize(int value) {
        if (value <= 0) return 0.0;
        // 以平台历史最大值作为分母（配置项，定期更新）
        double maxVal = 10000.0; // 可配置: TRENDFUL_MAX_SIGNAL
        return Math.log10(value + 1) / Math.log10(maxVal + 1);
    }
}
```

### 3.2 趋势方向判断

```java
/**
 * 趋势方向判断
 * 比较近7日均分 vs 前7日均分，判断升降
 */
public TrendDirection calculateTrendDirection(
        List<BigDecimal> recent7Days,   // 近7天热度分（含今天）
        List<BigDecimal> previous7Days   // 前7天热度分
) {
    if (recent7Days.isEmpty() || previous7Days.isEmpty()) {
        return TrendDirection.STABLE;
    }

    double recentAvg = avg(recent7Days);
    double previousAvg = avg(previous7Days);

    if (previousAvg == 0) {
        return recentAvg > 0 ? TrendDirection.RISING : TrendDirection.STABLE;
    }

    double changeRate = (recentAvg - previousAvg) / previousAvg;

    if (changeRate >= 0.20) {       // 上升 >= 20%
        return TrendDirection.RISING;
    } else if (changeRate <= -0.20) { // 下降 >= 20%
        return TrendDirection.FALLING;
    } else {
        return TrendDirection.STABLE;
    }
}
```

### 3.3 命题趋势预测模型

#### 3.3.1 模型概览

采用 **多信号融合 + 时序分析** 的混合预测方案，不依赖单一深度学习模型（教育数据量有限，且解释性要求高）。

```
预测概率 = α × HistoricalFrequency + β × RecentTrend + γ × CurriculumChange + δ × KnowledgeGraphCentrality

其中:
  α = 0.40   历年出现频率（过去 N 年该知识点在真题中的出现比例）
  β = 0.25   近期热度趋势（过去3个月平台内该知识点热度变化率）
  γ = 0.20   课标变更信号（新课标是否新增/强调该知识点）
  δ = 0.15   知识图谱中心性（该知识点在学科图谱中的度中心性/介数中心性）
```

#### 3.3.2 历年出现频率计算

```java
/**
 * 计算知识点在历年真题中的出现频率
 *
 * @param kpId      知识点ID
 * @param subject   学科
 * @param examType  考试类型
 * @param lookbackYears 回溯年数（默认5年）
 * @return 频率 [0, 1]，如 5年内出现4次 → 0.8
 */
public double calculateHistoricalFrequency(
        Long kpId, String subject, String examType, int lookbackYears) {

    int currentYear = LocalDate.now().getYear();
    int startYear = currentYear - lookbackYears;

    // 查询历年真题中包含该知识点的试卷数
    int appearedYears = examPaperAnalysisMapper.countYearsWithKnowledgePoint(
            kpId, subject, examType, startYear, currentYear - 1);

    return (double) appearedYears / lookbackYears;
}
```

#### 3.3.3 近期热度趋势计算

```java
/**
 * 计算知识点近3个月热度变化率
 * 使用线性回归斜率作为趋势信号
 */
public double calculateRecentTrend(Long kpId, String subject, String gradeGroup) {
    LocalDate endDate = LocalDate.now();
    LocalDate startDate = endDate.minusMonths(3);

    // 获取日热度序列
    List<DateScorePair> scores = trendKpHotMapper.selectDailyScores(
            kpId, subject, gradeGroup, startDate, endDate);

    if (scores.size() < 7) {
        return 0.0; // 数据不足，返回中性
    }

    // 简单线性回归，取斜率
    double slope = calculateLinearRegressionSlope(scores);

    // 归一化到 [-1, 1] 区间
    return Math.tanh(slope);
}
```

#### 3.3.4 课标变更信号

```java
/**
 * 获取课标变更信号
 *
 * @return 变更信号值
 *   1.0  = 新增知识点（课标今年新增）
 *   0.5  = 强调变化（表述明显修改、要求等级提升）
 *   0.0  = 无变化
 */
public double getCurriculumChangeSignal(Long kpId, String subject) {
    CurriculumChangeRecord change = curriculumChangeMapper.findLatest(kpId, subject);
    if (change == null) return 0.0;

    int yearsSinceChange = Period.between(
            change.getEffectiveDate(), LocalDate.now()).getYears();

    // 变更越近，信号越强，2年后衰减为0
    if (yearsSinceChange >= 2) return 0.0;

    double baseSignal = switch (change.getChangeType()) {
        case NEW -> 1.0;
        case ENHANCED -> 0.5;
        default -> 0.0;
    };

    // 线性衰减
    return baseSignal * (1.0 - yearsSinceChange / 2.0);
}
```

```java
@Service
public class ExamTrendPredictionService {

    // 预测权重配置
    private static final double W_HISTORICAL = 0.40;
    private static final double W_RECENT_TREND = 0.25;
    private static final double W_CURRICULUM = 0.20;
    private static final double W_GRAPH = 0.15;

    /**
     * 生成本年度某学科某考试的命题趋势预测
     */
    @Transactional
    public ExamTrendPrediction generatePrediction(
            String examType, int targetYear,
            String subjectCode, String gradeGroup,
            String regionCode) {

        // 1. 获取该学科该学段所有知识点
        List<KnowledgePoint> allKPs = knowledgePointService
                .findBySubjectAndGrade(subjectCode, gradeGroup);

        // 2. 逐知识点计算预测概率
        List<KpPrediction> predictions = new ArrayList<>();

        for (KnowledgePoint kp : allKPs) {
            double histFreq = calculateHistoricalFrequency(
                    kp.getId(), subjectCode, examType, 5);
            double recentTrend = calculateRecentTrend(
                    kp.getId(), subjectCode, gradeGroup);
            double currSignal = getCurriculumChangeSignal(
                    kp.getId(), subjectCode);
            double centrality = getGraphCentrality(kp.getId(), subjectCode);

            double probability = W_HISTORICAL * histFreq
                               + W_RECENT_TREND * recentTrend
                               + W_CURRICULUM * currSignal
                               + W_GRAPH * centrality;

            // 只保留概率 > 0.3 的预测
            if (probability > 0.3) {
                KpPrediction pred = KpPrediction.builder()
                        .knowledgePointId(kp.getId())
                        .knowledgePointName(kp.getName())
                        .probability(BigDecimal.valueOf(probability)
                                .setScale(2, RoundingMode.HALF_UP))
                        .reasons(buildReasons(histFreq, recentTrend, currSignal, centrality))
                        .build();
                predictions.add(pred);
            }
        }

        // 3. 分档：高概率(>=0.7) / 中概率(0.5~0.7) / 新兴关注(<0.5 但趋势上升)
        List<KpPrediction> highProb = predictions.stream()
                .filter(p -> p.getProbability().compareTo(BigDecimal.valueOf(0.7)) >= 0)
                .sorted(Comparator.comparing(KpPrediction::getProbability).reversed())
                .collect(Collectors.toList());

        List<KpPrediction> midProb = predictions.stream()
                .filter(p -> p.getProbability().compareTo(BigDecimal.valueOf(0.5)) >= 0
                          && p.getProbability().compareTo(BigDecimal.valueOf(0.7)) < 0)
                .sorted(Comparator.comparing(KpPrediction::getProbability).reversed())
                .collect(Collectors.toList());

        List<KpPrediction> emerging = predictions.stream()
                .filter(p -> p.getProbability().compareTo(BigDecimal.valueOf(0.5)) < 0)
                .sorted(Comparator.comparing(KpPrediction::getProbability).reversed())
                .limit(10) // 新兴关注最多10个
                .collect(Collectors.toList());

        // 4. 构建预测结果
        Map<String, Object> predictionsJson = new LinkedHashMap<>();
        predictionsJson.put("highProbability", highProb);
        predictionsJson.put("mediumProbability", midProb);
        predictionsJson.put("emergingTopics", emerging);

        // 5. 计算整体置信度
        double confidence = calculateConfidence(
                allKPs.size(), examType, subjectCode, targetYear);

        // 6. 持久化
        ExamTrendPrediction prediction = new ExamTrendPrediction();
        prediction.setPredictionCode(generatePredictionCode(
                examType, targetYear, subjectCode, regionCode));
        prediction.setTargetExam(examType);
        prediction.setTargetYear(targetYear);
        prediction.setRegionCode(regionCode);
        prediction.setSubjectCode(subjectCode);
        prediction.setGradeGroup(gradeGroup);
        prediction.setPredictions(objectMapper.writeValueAsString(predictionsJson));
        prediction.setConfidenceLevel(BigDecimal.valueOf(confidence));
        prediction.setStatus("DRAFT");
        prediction.setModelVersion("v1.0");

        return prediction;
    }

    /**
     * 构建预测理由（可解释性）
     */
    private List<String> buildReasons(
            double histFreq, double trend, double curriculum, double centrality) {
        List<String> reasons = new ArrayList<>();
        if (histFreq >= 0.8) {
            reasons.add("近5年出现频率 " + (int)(histFreq * 100) + "%");
        } else if (histFreq >= 0.5) {
            reasons.add("近5年出现频率 " + (int)(histFreq * 100) + "%");
        }
        if (trend > 0.3) {
            reasons.add("近期平台热度上升趋势明显");
        }
        if (curriculum >= 0.5) {
            reasons.add("新课标有新增/调整要求");
        }
        if (centrality > 0.6) {
            reasons.add("该知识点在学科知识网络中处于核心位置");
        }
        if (reasons.isEmpty()) {
            reasons.add("综合分析评分达到预测阈值");
        }
        return reasons;
    }
}
```

```java
                            + "建议制作专题讲解内容",

        if ("RISING".equals(hot.getTrendDirection())
                && hot.getTrendChangeRate() > 0.5) {

                    "HIGH",
                    String.format("知识点 '%s' 近期热度上升 %.0f%%，"
                            + "建议提前布局讲解内容",
                            hot.getKnowledgePointName(),
                            hot.getTrendChangeRate() * 100));
        }
    }

    generateExamSeasonSuggestions(subject, gradeGroup);
```

### 5.2 每日快照任务流程

```java
@Service
public class TrendDailySnapshotJob {

    /**
     * 每日凌晨执行：
     * 1. 从 ClickHouse 读取前一天聚合数据
     * 2. 计算每个知识点的热度分
     * 3. 判断趋势方向
     * 4. 写入 PostgreSQL 热度快照表
     * 5. 更新 Redis 缓存
     */
    @Scheduled(cron = "0 0 2 * * *")
    public void executeDailySnapshot() {
        LocalDate targetDate = LocalDate.now().minusDays(1);
        log.info("开始执行趋势日快照任务, date={}", targetDate);

        try {
            // 按学科+学段分批处理（避免内存溢出）
            for (String subject : SUPPORTED_SUBJECTS) {
                for (String gradeGroup : SUPPORTED_GRADE_GROUPS) {
                    processSnapshotForSegment(targetDate, subject, gradeGroup);
                }
            }

            // 刷新缓存
            trendCacheService.refreshDailyCache(targetDate);

            // 发送完成通知
            notificationService.notifyJobComplete("TrendDailySnapshot", targetDate);

        } catch (Exception e) {
            log.error("趋势日快照任务失败, date={}", targetDate, e);
            alertService.sendAlert("TREND_SNAPSHOT_FAILED",
                    "趋势日快照任务失败: " + e.getMessage(),
                    AlertLevel.URGENT);
        }
    }

    private void processSnapshotForSegment(
            LocalDate date, String subject, String gradeGroup) {

        // 1. 从 ClickHouse 获取前日聚合
        List<KpSignalAggregate> signals = clickHouseTrendMapper
                .selectDailyAggregates(date, subject, gradeGroup, "ALL");

        // 2. 获取权重配置
        TrendHotScoreWeight weight = weightRepo.findActive(subject, gradeGroup);

        // 3. 逐知识点计算热度
        List<TrendKnowledgePointHot> records = new ArrayList<>();
        for (KpSignalAggregate signal : signals) {
            int activeDays = trendKpHotMapper.countRecentActiveDays(
                    signal.getKnowledgePointId(), date, 90);

            BigDecimal hotScore = hotScoreCalculator.calculateKnowledgePointHotScore(
                    signal, weight, activeDays);

            // 趋势方向判断
            List<BigDecimal> recent7 = trendKpHotMapper.selectRecentScores(
                    signal.getKnowledgePointId(), subject, gradeGroup,
                    date.minusDays(6), date);
            List<BigDecimal> prev7 = trendKpHotMapper.selectRecentScores(
                    signal.getKnowledgePointId(), subject, gradeGroup,
                    date.minusDays(13), date.minusDays(7));

            TrendDirection direction = trendCalculator
                    .calculateTrendDirection(recent7, prev7);

            BigDecimal changeRate = trendCalculator
                    .calculateChangeRate(recent7, prev7);

            TrendKnowledgePointHot record = new TrendKnowledgePointHot();
            record.setSnapshotDate(date);
            record.setRegionCode("ALL");
            record.setGradeGroup(gradeGroup);
            record.setSubjectCode(subject);
            record.setKnowledgePointId(signal.getKnowledgePointId());
            record.setSearchCount(signal.getSearchCount());
            record.setQuestionViewCount(signal.getQuestionViewCount());
            record.setAiAskCount(signal.getAiAskCount());
            record.setMistakeCount(signal.getMistakeCount());
            record.setPracticeCount(signal.getPracticeCount());
            record.setErrorRate(signal.getErrorRate());
            record.setHotScore(hotScore);
            record.setTrendDirection(direction.name());
            record.setTrendChangeRate(changeRate);
            records.add(record);
        }

        // 4. 批量写入（UPSERT）
        trendKpHotMapper.batchUpsert(records);

        log.info("趋势快照完成: date={}, subject={}, grade={}, count={}",
                date, subject, gradeGroup, records.size());
    }
}
```

## 7. 错误处理与降级策略

### 7.1 异常场景处理

| 场景 | 影响 | 处理策略 |
|------|------|----------|
| ClickHouse 查询超时 | 无法聚合当日数据 | 重试3次（间隔5min），失败则跳过当日，下次补数 |
| 知识点ID变更/删除 | 热度记录指向无效知识点 | 数据清洗任务标记为 `INVALID`，排除在榜单外 |
| 历年真题数据不足（< 3年） | 预测置信度过低 | 降低 confidence_level < 0.5，学生端不展示 |
| Redis 缓存不可用 | 榜单查询走DB | 增加DB查询超时（500ms），降级返回缓存上次值 |
| 预测模型权重异常 | 预测结果不合理 | 增加结果校验：highProb 数量不超过学科知识点总数的 15% |

### 7.2 数据一致性保障

```java
/**
 * 补数机制：每日快照失败后，在次日补齐
 */
@Scheduled(cron = "0 0 4 * * *")  // 每日4:00 检查
public void backfillMissingSnapshots() {
    LocalDate yesterday = LocalDate.now().minusDays(1);
    LocalDate earliestCheck = LocalDate.now().minusDays(7); // 最多补7天

    List<LocalDate> missingDates = trendKpHotMapper
            .findMissingSnapshotDates(yesterday, earliestCheck);

    for (LocalDate missing : missingDates) {
        log.warn("发现缺失快照: {}, 执行补数", missing);
        trendDailySnapshotJob.processSnapshotForAllSegments(missing);
    }
}
```

## 9. 数据隐私与安全

### 9.1 数据脱敏规则

1. 所有热度统计基于**聚合数据**（count、sum），不存储个体行为记录。
2. 搜索日志提取知识点后，原始搜索文本不进入趋势分析流程。
3. AI 提问日志只提取关联的知识点 ID，提问内容不保留。
4. 运营后台展示的数据均为脱敏后的统计数据。

### 9.2 敏感性控制

1. **学生端预测展示限制**：
   - 不显示具体概率数值，只显示分档（高频/上升/新兴）
   - 必须附带免责声明
   - 不展示"押题""必考"等绝对化表述

2. **预测结果审核流程**：
   - 系统自动生成 → DRAFT
   - 内容教研团队审核 → PUBLISHED / REJECTED
   - 发布后才对学生可见

3. **审核日志**：所有预测发布、修改、下架操作记录审计日志。

### 12.2 预测模型评估指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 命中率 (Hit Rate) | 命中知识点数 / 预测高概率知识点数 | 考试结束后回填实际考点，计算命中率 |
| 覆盖率 (Coverage) | 命中知识点数 / 实际考点总数 | 预测覆盖了多少实际考点 |
| 精确率 (Precision) | TP / (TP + FP) | 高概率预测的准确性 |
| 召回率 (Recall) | TP / (TP + FN) | 实际考点中被预测到的比例 |
| F1-Score | 2 × P × R / (P + R) | 综合评估 |

> 考试结束后，由内容团队标注实际考点，系统自动计算上述指标，用于优化模型权重。
