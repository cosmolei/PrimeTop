# 服务端-教育内容静态资源互动化智能增强与自动交互元素注入引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 教育平台内容生产管线的核心增强组件，负责将平台中海量的**静态教育内容**（纯文本讲解、图片说明、教材摘录等）自动或半自动地转化为**具备交互能力的学习内容**，通过智能识别内容结构、提取可交互锚点、匹配交互模板、生成交互组件，实现静态内容的规模化互动化改造。

### 1.2 问题背景

PrimeTop 平台的内容来源包括：
- 教材出版社授权的数字化内容（以文本+图片为主）
- 教研团队编写的学习卡片和知识讲解
- AI 自动生成的知识摘要和解析
- 题库中的答案解析和知识点说明

这些内容**80%以上以静态文本/图片形式存在**，而研究表明交互式内容的学习效果显著优于静态内容（完成率提升 40%~60%，知识保留率提升 25%~35%）。但完全依靠人工将静态内容改造为互动内容，一个知识点的平均处理时间为 30-60 分钟，无法匹配平台的内容量级（预计 50万+ 知识内容单元）。

### 1.3 设计目标

| 目标 | 指标 |
| --- | --- |
| 自动化率 | 对输入内容自动生成交互增强建议的覆盖率 ≥ 70% |
| 准确率 | 自动注入的交互元素经教研审核通过率 ≥ 85% |
| 性能 | 单篇内容（2000字以内）互动化处理延迟 ≤ 10秒 |
| 可扩展性 | 支持新增交互模板类型，无需修改核心引擎 |
| 人机协同 | 教研人员可在自动生成基础上进行微调和审核 |

### 1.4 适用范围

- **输入**：平台内容管理系统中状态为"已发布"或"待增强"的静态教育内容
- **输出**：带有交互元素标注的增强版内容描述（JSON Schema），供客户端渲染引擎解析
- **覆盖学科**：全学科（语文、数学、英语、物理、化学、生物、历史、地理、政治、信息技术）
- **覆盖学段**：小学至高中（幼儿启蒙阶段因交互形式特殊，单独处理）

### 2.2 核心处理流水线

```text
静态内容 → ① 结构解析 → ② 锚点提取 → ③ 模板匹配 → ④ 内容生成 → ⑤ 质量校验 → ⑥ 合成输出

并行处理：
  ├── 学科分类 & 难度评估（辅助决策）
  ├── 知识点关联查询（提供上下文）
  └── 用户学情关联（个性化标注）
```

## 4. 核心处理流程详细设计

### 4.1 内容结构解析器 (Content Structure Parser)

**职责**：将原始静态内容解析为结构化的内容块序列，识别内容的语义结构。

#### 处理流程

```text
原始内容 (Markdown/HTML)
    │
    ├── 1. 格式归一化 → 统一为内部 AST 表示
    │
    ├── 2. 段落切分 → 按语义边界切分（段落/标题/列表/公式块/图片）
    │
    ├── 3. 实体标注 → NER 识别学科实体（术语/公式/人名/地名/化学式等）
    │
    ├── 4. 功能分段 → 将内容标记为: 定义段/推导段/例题段/总结段/过渡段
    │
    └── 5. 输出: ContentBlock[] + StructuralMetadata
```

#### 关键代码示例

```python
import re
from dataclasses import dataclass, field
from typing import List, Optional
from enum import Enum

class BlockType(Enum):
    HEADING = "HEADING"
    PARAGRAPH = "PARAGRAPH"
    IMAGE = "IMAGE"
    FORMULA = "FORMULA"
    CODE = "CODE"
    QUOTE = "QUOTE"
    LIST = "LIST"

class SegmentFunction(Enum):
    """内容段功能分类"""
    DEFINITION = "DEFINITION"       # 概念定义
    DERIVATION = "DERIVATION"       # 推导过程
    EXAMPLE = "EXAMPLE"             # 例题/示例
    SUMMARY = "SUMMARY"             # 总结归纳
    TRANSITION = "TRANSITION"       # 过渡连接
    EXERCISE = "EXERCISE"           # 练习题
    ANALYSIS = "ANALYSIS"           # 分析说明

@dataclass
class ParsedBlock:
    block_id: str
    block_type: BlockType
    content: str
    paragraph_index: int
    char_range: tuple  # (start, end) in original text
    entities: List[dict] = field(default_factory=list)
    segment_function: Optional[SegmentFunction] = None
    children: List['ParsedBlock'] = field(default_factory=list)


class ContentStructureParser:
    """内容结构解析器"""
    
    # 学科实体识别正则模式（预定义）
    ENTITY_PATTERNS = {
        'MATH_FORMULA': r'\$[^$]+\$|\\\([^)]+\\\)\\\[[^\]]+\\\]',
        'CHEMICAL_FORMULA': r'[A-Z][a-z]?\d*(?:[A-Z][a-z]?\d*)+',
        'PHYSICS_UNIT': r'\d+(?:\.\d+)?\s*(?:N|kg|m|s|J|W|V|A|Hz|Pa|C|Ω|F|T)',
        'TERM_CN': r'【[^】]+】|《[^》]+》',  # 中文术语标记
    }
    
    # 段落功能识别关键词
    SEGMENT_SIGNALS = {
        SegmentFunction.DEFINITION: ['定义', '是指', '叫做', '称为', '概念', 'definition', 'means'],
        SegmentFunction.DERIVATION: ['推导', '证明', '因为', '所以', '由此可得', '根据', 'therefore', 'thus'],
        SegmentFunction.EXAMPLE: ['例如', '比如', '例题', '举例', 'for example', 'such as', 'e.g.'],
        SegmentFunction.SUMMARY: ['综上', '总结', '归纳', '总之', '小结', 'in summary', 'to conclude'],
        SegmentFunction.EXERCISE: ['练习', '习题', '思考', '动脑筋', '试一试', 'exercise', 'practice'],
    }
    
    def parse(self, raw_content: str, subject: str) -> List[ParsedBlock]:
        """
        解析原始内容，返回结构化内容块列表
        
        Args:
            raw_content: 原始内容（Markdown/HTML）
            subject: 学科代码
            
        Returns:
            结构化内容块列表
        """
        # 1. 格式归一化
        normalized = self._normalize_format(raw_content)
        
        # 2. 按语义边界切分
        raw_blocks = self._split_by_semantic_boundary(normalized)
        
        # 3. 实体标注
        blocks = []
        for idx, raw_block in enumerate(raw_blocks):
            entities = self._extract_entities(raw_block, subject)
            seg_func = self._classify_segment_function(raw_block)
            
            block = ParsedBlock(
                block_id=f"blk_{idx:04d}",
                block_type=self._infer_block_type(raw_block),
                content=raw_block,
                paragraph_index=idx,
                char_range=self._calc_char_range(raw_content, raw_block, idx),
                entities=entities,
                segment_function=seg_func,
            )
            blocks.append(block)
        
        return blocks
    
    def _classify_segment_function(self, text: str) -> Optional[SegmentFunction]:
        """识别段落的功能类型"""
        text_lower = text.lower()
        for func, keywords in self.SEGMENT_SIGNALS.items():
            for kw in keywords:
                if kw in text_lower:
                    return func
        return None
    
    def _extract_entities(self, text: str, subject: str) -> List[dict]:
        """提取学科实体"""
        entities = []
        for entity_type, pattern in self.ENTITY_PATTERNS.items():
            for match in re.finditer(pattern, text):
                entities.append({
                    'type': entity_type,
                    'text': match.group(),
                    'start': match.start(),
                    'end': match.end(),
                })
        # 可接入学科NLP服务进行更精确的实体识别
        return entities
```

### 4.2 交互锚点提取器 (Interaction Anchor Extractor)

**职责**：在结构化内容块中识别适合注入交互元素的位置（锚点），并评估每个锚点的交互潜力。

#### 锚点类型与识别策略

| 锚点类型 | 识别方法 | 推荐交互类型 | 示例 |
| --- | --- | --- | --- |
| `CONCEPT_TERM` | 学科术语词典匹配 | TOOLTIP, KNOWLEDGE_LINK | "牛顿第二定律" |
| `KEY_FORMULA` | LaTeX/公式模式匹配 | TOOLTIP, STEP_THROUGH | "$F=ma$" |
| `EXAMPLE_SECTION` | 段落功能分类=EXAMPLE | TOGGLE_REVEAL, CAROUSEL | "例如：一个质量为2kg的物体..." |
| `DERIVATION_SECTION` | 段落功能分类=DERIVATION | STEP_THROUGH | "根据公式推导..." |
| `SECTION_END` | 段落/小节结束位置 | EMBEDDED_QUESTION, SUMMARY_KEYPOINTS | 一个知识点讲解结束后 |
| `IMAGE_REFERENCE` | 图片引用检测 | HOTSPOT_IMAGE | 带有标注的实验图/示意图 |
| `LIST_CONTENT` | 列表/枚举内容 | DRAG_DROP_MATCH, CAROUSEL | "力的三要素：大小、方向、作用点" |
| `COMPARISON_CONTEXT` | 对比/类比模式 | DRAG_DROP_MATCH | "区别于牛顿第一定律..." |

```python
from dataclasses import dataclass
from typing import List, Optional
import numpy as np

@dataclass
class InteractionAnchor:
    anchor_id: str
    block_id: str                          # 关联的内容块ID
    anchor_type: str                        # 锚点类型
    anchor_text: str                        # 锚点文本

    knowledge_point_id: Optional[str]       # 关联知识点ID

    context_snippet: str                    # 上下文片段
    interaction_potential: float            # 交互潜力评分 0-1
    
class AnchorExtractionStrategy:
    """锚点提取策略基类"""
    
    def extract(self, blocks: List[ParsedBlock], context: dict) -> List[InteractionAnchor]:
        raise NotImplementedError


class ConceptTermExtractor(AnchorExtractionStrategy):
    """学科术语锚点提取"""
    
    def __init__(self, terminology_service):
        self.terminology_service = terminology_service  # 学科术语词典服务
    
    def extract(self, blocks: List[ParsedBlock], context: dict) -> List[InteractionAnchor]:
        anchors = []
        subject = context['subject']
        
        for block in blocks:
            if block.block_type not in (BlockType.PARAGRAPH, BlockType.HEADING):
                continue
            
            # 从术语词典中查找本学科的关键术语
            terms = self.terminology_service.get_terms_for_position(
                subject=subject,
                text=block.content,
                grade_range=context['grade_range']
            )
            
            for term in terms:
                # 计算置信度：基于术语重要性 + 出现位置 + 上下文相关性
                confidence = self._calculate_confidence(
                    term=term,
                    block=block,
                    context=context
                )
                
                if confidence < 0.5:  # 置信度阈值
                    continue
                
                anchor = InteractionAnchor(
                    anchor_id=f"anc_{block.block_id}_{term.term_id}",
                    block_id=block.block_id,
                    anchor_type='CONCEPT_TERM',
                    anchor_text=term.text,
                    content_position={
                        'paragraph_index': block.paragraph_index,
                        'char_start': term.start_pos,
                        'char_end': term.end_pos,
                    },
                    matched_template_ids=['TOOLTIP_CONCEPT_001', 'KNOWLEDGE_LINK_001'],
                    knowledge_point_id=term.knowledge_point_id,
                    confidence_score=confidence,
                    context_snippet=block.content[max(0, term.start_pos-30):term.end_pos+30],
                    interaction_potential=self._assess_potential(term, block)
                )
                anchors.append(anchor)
        
        return anchors
    
    def _calculate_confidence(self, term, block, context) -> float:
        """计算锚点置信度"""
        score = 0.0
        # 术语重要性权重 (0-0.3)
        score += term.importance_score * 0.3
        # 首次出现权重 (0-0.2) — 首次出现更适合加tooltip
        if term.is_first_occurrence_in_content:
            score += 0.2
        # 学段匹配度 (0-0.2)
        if context['grade_range'] in term.applicable_grades:
            score += 0.2
        # 上下文相关性 (0-0.3) — 通过embedding相似度
        relevance = self._compute_context_relevance(term, block)
        score += relevance * 0.3
        return min(score, 1.0)


class SectionEndDetector(AnchorExtractionStrategy):
    """小节结束锚点检测 — 用于在知识点讲解后插入检查题"""
    
    # 小节结束信号
    SECTION_END_SIGNALS = [
        r'。\s*\n\s*\n',           # 段落结束+空行
        r'因此.*?。',              # "因此..."总结句
        r'所以.*?。',              # "所以..."总结句
        r'这就是.*?。',            # "这就是..."归纳句
        r'综上.*?[。：]',          # "综上..."
    ]
    
    MIN_CONTENT_BEFORE_QUESTION = 150  # 最少内容字数后才插入检查题
    MIN_CONTENT_AFTER_QUESTION = 100   # 插入位置后至少还有这么多内容
    
    def extract(self, blocks: List[ParsedBlock], context: dict) -> List[InteractionAnchor]:
        anchors = []
        accumulated_chars = 0
        total_chars = sum(len(b.content) for b in blocks)
        
        for i, block in enumerate(blocks):
            accumulated_chars += len(block.content)
            remaining_chars = total_chars - accumulated_chars
            
            # 检查是否适合插入检查题
            if (accumulated_chars >= self.MIN_CONTENT_BEFORE_QUESTION and
                remaining_chars >= self.MIN_CONTENT_AFTER_QUESTION and
                self._is_natural_break_point(block, blocks, i)):
                
                # 限制每篇内容最多插入的检查题数量
                existing_questions = len([a for a in anchors if a.anchor_type == 'SECTION_END'])
                if existing_questions >= 3:  # 每篇最多3个内嵌检查题
                    break
                
                anchor = InteractionAnchor(
                    anchor_id=f"anc_section_end_{i}",
                    block_id=block.block_id,
                    anchor_type='SECTION_END',
                    anchor_text='',
                    content_position={'after_block_index': i},
                    matched_template_ids=['EMBEDDED_QUESTION_001', 'SUMMARY_KEYPOINTS_001'],
                    knowledge_point_id=context.get('current_kp_id'),
                    confidence_score=0.8,
                    context_snippet=block.content[-100:],
                    interaction_potential=0.85
                )
                anchors.append(anchor)
        
        return anchors
    
    def _is_natural_break_point(self, block, all_blocks, index) -> bool:
        """判断是否是自然的插入断点"""
        # 定义段和推导段后是好的断点
        if block.segment_function in (SegmentFunction.DEFINITION, SegmentFunction.DERIVATION, SegmentFunction.EXAMPLE):
            return True
        # 检查是否有小节结束信号
        for pattern in self.SECTION_END_SIGNALS:
            if re.search(pattern, block.content):
                return True
        # 下一个块是新的标题也是好的断点
        if index + 1 < len(all_blocks) and all_blocks[index + 1].block_type == BlockType.HEADING:
            return True
        return False
```

```python
class InteractionDensityController:
    """交互密度控制器"""
    
    # 密度策略：每 N 个字插入一个交互元素
    DENSITY_STRATEGY = {
        'LOW': {
            'min_interval_chars': 400,    # 低密度：每400字一个交互
            'max_per_content': 3,
            'preferred_types': ['EMBEDDED_QUESTION', 'SUMMARY_KEYPOINTS'],
        },
        'MEDIUM': {
            'min_interval_chars': 200,
            'max_per_content': 6,
            'preferred_types': ['TOOLTIP', 'TOGGLE_REVEAL', 'EMBEDDED_QUESTION', 
                              'STEP_THROUGH', 'KNOWLEDGE_LINK'],
        },
        'HIGH': {
            'min_interval_chars': 100,
            'max_per_content': 12,
            'preferred_types': ['TOOLTIP', 'TOGGLE_REVEAL', 'EMBEDDED_QUESTION',
                              'STEP_THROUGH', 'KNOWLEDGE_LINK', 'HOTSPOT_IMAGE',
                              'DRAG_DROP_MATCH', 'CAROUSEL_EXAMPLES'],
        },
    }
    
    def __init__(self, user_preference_service=None):
        self.user_pref_service = user_preference_service
    
    def determine_density(self, content_meta: dict, user_id: str = None) -> str:
        """决定交互密度级别"""
        # 基于内容类型
        base_density = {
            'EXPLANATION': 'MEDIUM',
            'ANSWER_ANALYSIS': 'LOW',       # 答案解析不宜过多打断
            'KNOWLEDGE_CARD': 'HIGH',       # 知识卡片适合高交互
            'TEXTBOOK_EXCERPT': 'LOW',      # 教材原文低交互
            'SUMMARY': 'MEDIUM',
        }.get(content_meta.get('content_type', 'EXPLANATION'), 'MEDIUM')
        
        # 基于用户偏好（如果有用户上下文）
        if user_id and self.user_pref_service:
            user_pref = self.user_pref_service.get_interaction_preference(user_id)
            if user_pref == 'MINIMAL':
                base_density = 'LOW'
            elif user_pref == 'RICH':
                base_density = 'HIGH'
        
        # 基于学段调整
        grade = content_meta.get('grade_range', 'JUNIOR')
        if grade in ('PRIMARY',):  # 小学适当增加交互
            base_density = max(base_density, 'MEDIUM')
        
        return base_density
    
    def filter_by_density(self, anchors: List[InteractionAnchor], 
                          density_level: str) -> List[InteractionAnchor]:
        """根据密度策略过滤锚点"""
        strategy = self.DENSITY_STRATEGY[density_level]
        min_interval = strategy['min_interval_chars']
        max_count = strategy['max_per_content']
        preferred = set(strategy['preferred_types'])
        
        # 按置信度和交互潜力排序
        sorted_anchors = sorted(
            anchors, 
            key=lambda a: (a.confidence_score + a.interaction_potential) / 2,
            reverse=True
        )
        
        selected = []
        last_position = -min_interval  # 确保第一个可以被选中
        
        for anchor in sorted_anchors:
            if len(selected) >= max_count:
                break
            
            current_pos = anchor.content_position.get('paragraph_index', 0) * 100
            
            # 间隔检查
            if current_pos - last_position < min_interval:
                continue
            
            # 偏好类型检查（优先选择偏好类型）
            anchor_template_types = set()
            for tid in anchor.matched_template_ids:
                # 获取模板对应的交互类型
                anchor_template_types.add(self._get_template_interaction_type(tid))
            
            if not anchor_template_types.intersection(preferred):
                continue
            
            selected.append(anchor)
            last_position = current_pos
        
        # 按位置重新排序
        selected.sort(key=lambda a: a.content_position.get('paragraph_index', 0))
        return selected
```

### 4.5 增强内容合成器 (Enhanced Content Composer)

**职责**：将所有交互元素与原始内容合成为最终的增强内容描述。

```python
class EnhancedContentComposer:
    """增强内容合成器"""
    
    def compose(
        self,
        original_content: str,
        parsed_blocks: List[ParsedBlock],
        interaction_elements: List[InteractionElement],
        content_meta: dict,
        quality_report: dict
    ) -> EnhancedContent:
        """合成最终的增强内容"""
        
        # 1. 构建内容块序列
        blocks = []
        interaction_map = {}  # block_id → [element_ids]
        
        for elem in interaction_elements:
            bid = elem.anchor_block_id
            if bid not in interaction_map:
                interaction_map[bid] = []
            interaction_map[bid].append(elem.elementId)
        
        for block in parsed_blocks:
            content_block = {
                'blockId': block.block_id,
                'blockType': block.block_type.value,
                'content': block.content,
                'interactionRefs': interaction_map.get(block.block_id, [])
            }
            blocks.append(content_block)
        
        # 2. 计算交互密度
        word_count = len(original_content)
        element_count = len(interaction_elements)
        if element_count == 0:
            density = 'LOW'
        elif word_count / element_count > 300:
            density = 'LOW'
        elif word_count / element_count > 150:
            density = 'MEDIUM'
        else:
            density = 'HIGH'
        
        # 3. 计算预估学习时长
        # 基础阅读时间 + 交互元素额外时间
        base_read_time = word_count / 5  # 假设每分钟300字阅读速度 = 5字/秒
        interaction_extra_time = sum(self._estimate_interaction_time(e) for e in interaction_elements)
        estimated_duration = int(base_read_time + interaction_extra_time)
        
        return EnhancedContent(
            meta={
                'contentId': content_meta['content_id'],
                'title': content_meta.get('title', ''),
                'subject': content_meta['subject'],
                'gradeRange': content_meta['grade_range'],
                'difficultyLevel': content_meta.get('difficulty', 3),
                'estimatedDurationSec': estimated_duration,
                'enhancementVersion': f"v{datetime.now().strftime('%Y%m%d')}.1"
            },
            blocks=blocks,
            interactions=interaction_elements,
            metadata={
                'originalWordCount': word_count,
                'enhancedElementCount': element_count,
                'interactionDensity': density,
                'personalizationTags': content_meta.get('tags', [])
            }
        )
    
    def _estimate_interaction_time(self, element: InteractionElement) -> float:
        """估算交互元素的耗时（秒）"""
        time_map = {
            'TOOLTIP': 5,
            'TOGGLE_REVEAL': 15,
            'EMBEDDED_QUESTION': 30,
            'STEP_THROUGH': 45,
            'HOTSPOT_IMAGE': 20,
            'CAROUSEL_EXAMPLES': 25,
            'DRAG_DROP_MATCH': 30,
            'KNOWLEDGE_LINK': 3,
            'PRACTICE_PROMPT': 10,
            'SUMMARY_KEYPOINTS': 15,
        }
        return time_map.get(element.interactionType, 10)
```

## 8. 质量保障与自动校验

### 8.1 自动质量评分器

```python
class EnhancementQualityScorer:
    """增强内容自动质量评分器"""
    
    def score(self, enhanced_content: EnhancedContent) -> dict:
        """计算增强内容的质量评分"""
        scores = {}
        
        # 1. 交互相关性评分 (0-30分)
        scores['relevance'] = self._score_relevance(enhanced_content)
        
        # 2. 内容准确性评分 (0-25分)
        scores['accuracy'] = self._score_accuracy(enhanced_content)
        
        # 3. 交互密度合理性评分 (0-15分)
        scores['density'] = self._score_density(enhanced_content)
        
        # 4. 学段适配性评分 (0-15分)
        scores['grade_fit'] = self._score_grade_fit(enhanced_content)
        
        # 5. 格式规范性评分 (0-15分)
        scores['format'] = self._score_format(enhanced_content)
        
        total = sum(scores.values())
        
        return {
            'total_score': total,
            'dimension_scores': scores,
            'grade': self._score_to_grade(total),
            'needs_review': total < 90,
            'issues': self._collect_issues(enhanced_content, scores)
        }
    
    def _score_relevance(self, content: EnhancedContent) -> float:
        """交互元素与原始内容的相关性评分"""
        if not content.interactions:
            return 25.0  # 没有交互元素，给中等分
        
        relevant_count = 0
        for interaction in content.interactions:
            # 检查交互元素锚定的内容块是否存在
            anchor_block = self._find_block(content, interaction.anchorBlockId)
            if not anchor_block:
                continue
            
            # 检查交互内容与锚定内容的相关性
            # 方法：关键词重合度 + 语义相似度
            relevance = self._compute_semantic_relevance(
                anchor_block['content'],
                self._extract_interaction_text(interaction)
            )
            if relevance > 0.6:
                relevant_count += 1
        
        return (relevant_count / len(content.interactions)) * 30.0
    
    def _score_density(self, content: EnhancedContent) -> float:
        """交互密度合理性评分"""
        word_count = content.metadata.originalWordCount
        element_count = content.metadata.enhancedElementCount
        
        if element_count == 0:
            return 10.0  # 无交互元素，中等分
        
        chars_per_element = word_count / element_count
        
        # 理想范围：150-300字/交互
        if 150 <= chars_per_element <= 300:
            return 15.0
        elif 100 <= chars_per_element < 150 or 300 < chars_per_element <= 400:
            return 12.0
        elif 50 <= chars_per_element < 100 or 400 < chars_per_element <= 500:
            return 8.0
        else:
            return 4.0  # 过密或过疏
```

```python
class AIInteractionGeneratorWithFallback:
    """带降级策略的AI交互内容生成器"""
    
    def __init__(self, primary_llm, fallback_llm, rule_engine):
        self.primary = primary_llm      # 主模型 (如 GPT-4 级别)
        self.fallback = fallback_llm    # 备用模型 (如 更便宜/更快的模型)
        self.rule_engine = rule_engine  # 规则引擎 (零AI依赖)
    
    async def generate_embedded_question(
        self, content_snippet: str, subject: str, grade: str
    ) -> Optional[dict]:
        """生成内嵌题目，带三级降级"""
        
        # Level 1: 主模型
        try:
            result = await asyncio.wait_for(
                self.primary.generate_embedded_question(content_snippet, subject, grade),
                timeout=5.0
            )
            if result and self._quality_check(result):
                return result
        except (asyncio.TimeoutError, Exception) as e:
            logger.warning(f"主模型生成失败: {e}")
        
        # Level 2: 备用模型
        try:
            result = await asyncio.wait_for(
                self.fallback.generate_embedded_question(content_snippet, subject, grade),
                timeout=3.0
            )
            if result and self._quality_check(result):
                return result
        except (asyncio.TimeoutError, Exception) as e:
            logger.warning(f"备用模型生成失败: {e}")
        
        # Level 3: 规则引擎（从题库中检索最相似的题目）
        question = self.rule_engine.find_similar_question(
            content_snippet, subject, grade
        )
        return question  # 可能为 None
    
    def _quality_check(self, result: dict) -> bool:
        """基本质量检查"""
        return (
            result is not None and
            'question_stem' in result and
            len(result['question_stem']) > 10 and
            len(result.get('options', [])) == 4 and
            result.get('correct_answer') in ['A', 'B', 'C', 'D']
        )
```

```python
class BatchEnhancementOptimizer:
    """批量增强优化器"""
    
    BATCH_SIZE = 20
    MAX_CONCURRENT = 5
    
    async def batch_enhance(self, content_ids: List[int]) -> BatchResult:
        """分批并行处理"""
        results = []
        
        # 分批
        for i in range(0, len(content_ids), self.BATCH_SIZE):

            batch_results = await asyncio.gather(*batch_tasks, return_exceptions=True)
            results.extend(batch_results)
        
        return BatchResult(
            total=len(content_ids),
            success=sum(1 for r in results if not isinstance(r, Exception)),
            failed=sum(1 for r in results if isinstance(r, Exception)),
            results=results
```

```python
        stale = self._find_stale_enhancements()

            self._schedule_re_enhancement(content_id)
```

## 12. 安全与合规

### 12.1 内容安全

- **AI生成内容审核**：所有AI生成的交互内容（特别是题目和解析）必须经过内容安全过滤，确保不含敏感、不当信息
- **AIGC标识**：AI生成的交互元素需标注来源，符合AIGC内容标识规范
- **题目答案保护**：内嵌检查题的答案在传输和存储中加密，防止客户端泄露

客户端渲染引擎根据 `interactionType` 选择对应组件：

```dart
// Flutter 渲染分发示例
Widget renderInteraction(InteractionElement element) {
  switch (element.interactionType) {
    case 'TOOLTIP':
      return TooltipWidget(
        triggerText: element.data['triggerText'],
        tooltipContent: element.data['tooltipContent'],
        tooltipType: element.data['tooltipType'],
        display: element.display,
      );
    case 'TOGGLE_REVEAL':
      return ToggleRevealWidget(
        toggleText: element.data['toggleText'],
        revealedContent: element.data['revealedContent'],
        hintBeforeReveal: element.data['hintBeforeReveal'],
      );
    case 'EMBEDDED_QUESTION':
      return EmbeddedQuestionWidget(
        stem: element.data['stem'],
        options: element.data['options'],
        onSubmit: (answer) => handleSubmit(element.elementId, answer),
        showExplanation: element.data['showExplanationAfter'],
        explanation: element.data['explanation'],
      );
    case 'STEP_THROUGH':
      return StepThroughWidget(
        title: element.data['title'],
        steps: element.data['steps'],
        onComplete: () => handleComplete(element.elementId),
      );
    case 'HOTSPOT_IMAGE':
      return HotspotImageWidget(
        imageUrl: element.data['imageUrl'],
        hotspots: element.data['hotspots'],
      );
    case 'DRAG_DROP_MATCH':
      return DragDropMatchWidget(
        instruction: element.data['instruction'],
        dragItems: element.data['dragItems'],
        dropZones: element.data['dropZones'],
        shuffle: element.data['shuffleItems'],
      );
    case 'CAROUSEL_EXAMPLES':
      return CarouselWidget(
        title: element.data['title'],
        slides: element.data['slides'],
        autoPlay: element.data['autoPlay'],
      );
    case 'KNOWLEDGE_LINK':
      return KnowledgeLinkWidget(
        linkText: element.data['linkText'],
        targetKnowledgePointId: element.data['targetKnowledgePointId'],
        previewContent: element.data['previewContent'],
        relationship: element.data['relationship'],
      );
    case 'SUMMARY_KEYPOINTS':
      return SummaryKeypointsWidget(
        keypoints: element.data['keypoints'],
      );
    default:
      logger.warning('Unknown interaction type: ${element.interactionType}');
      return SizedBox.shrink();
  }
}
```

### 16.3 术语表

| 术语 | 说明 |
| --- | --- |
| 增强任务 (Enhancement Task) | 将一篇静态内容转化为交互内容的一次处理任务 |
| 交互锚点 (Interaction Anchor) | 静态内容中适合注入交互元素的位置 |
| 交互模板 (Interaction Template) | 可复用的交互组件模式定义 |
| 交互密度 (Interaction Density) | 单位内容长度内交互元素的数量 |
| 交互潜力 (Interaction Potential) | 某个位置适合添加交互的评估值 |
| 增强评分 (Enhancement Score) | 对增强内容质量的自动评分 |
