# 服务端-学习计划质量智能评估与执行成功率预测引擎-详细设计

## 1. 概述

### 1.1 功能定位

学习计划质量智能评估与执行成功率预测引擎是 PrimeTop 学习规划子系统的核心质量保障组件。当系统为学生自动生成学习计划后，本引擎负责对该计划进行多维度质量评估，并预测学生在未来一段时间内完成该计划的概率，从而：

1. **拦截低质计划**：在计划推送给学生前，识别并修正不合理的任务安排。
2. **预警高风险计划**：对执行成功率低于阈值的计划标注风险等级，触发降级或人工介入。
3. **驱动计划迭代**：将质量评分与执行结果反馈闭环，持续优化计划生成策略。
4. **支撑差异化推荐**：基于历史成功率分布，为不同画像的学生推荐最合适的计划模板。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 计划质量评分准确率 | 评分与实际执行结果的相关系数 ≥ 0.65 |
| 执行成功率预测 AUC | ≥ 0.82（基于历史数据回测） |
| 单次评估延迟（P99） | ≤ 80ms（不含模型推理），含模型推理 ≤ 300ms |
| 日均评估量 | 支撑 ≥ 50 万次计划生成场景 |
| 覆盖学段 | 小学、初中、高中全学段 |

### 1.3 适用范围

- 自动学习计划生成流程（系统为学生生成日/周/月/考前冲刺计划时）
- 计划模板推荐流程（从模板库推荐最优模板时）
- 计划动态调整流程（计划执行中途重新评估调整后计划质量）
- 运营分析（从平台维度分析计划整体质量分布趋势）

### 1.4 术语定义

| 术语 | 定义 |
| --- | --- |
| Plan | 一份完整的学习计划，包含若干 Task |
| Task | 计划中的单个学习任务（如：完成第3章练习、复习错题本数学部分） |
| 完成率 | 已完成 Task 数 / 总 Task 数 |
| 达标率 | 达标 Task 数 / 总 Task 数（达标 = 完成且质量合格，如正确率 ≥ 60%） |
| 计划质量评分 | 0-100 分，综合多个维度评估的计划合理度 |
| 执行成功率 | 预测的达标率期望值，0.0-1.0 |

| **PlanQualityEvaluationGateway** | 对外统一 API，接收评估请求，路由到内部模块 | Spring Boot REST Controller |

### 4.2 各维度评分算法

#### 4.2.1 任务量合理性（TASK_VOLUME_RATIONALITY）

```java
/**
 * 任务量合理性评分
 * 
 * 评估逻辑：
 * 1. 计算计划总时长 vs 学生历史日均学习时长
 * 2. 计算单日任务总量上限校验
 * 3. 考量学段差异（高中可承受更多）
 */
public class TaskVolumeRationalityScorer implements DimensionScorer {
    
    @Override
    public DimensionScore evaluate(Plan plan, StudentProfile profile) {
        int estimatedMinutes = plan.getEstimatedTotalMinutes();
        int planDays = (int) ChronoUnit.DAYS.between(plan.getStartDate(), plan.getEndDate()) + 1;
        int dailyMinutes = estimatedMinutes / planDays;
        
        // 基准日均学习时长（分钟），来自学生画像
        int baselineDailyMinutes = profile.getAvgDailyStudyMinutes();
        
        // 学段调整系数
        double stageFactor = switch (profile.getStage()) {
            case "PRIMARY" -> 1.0;    // 小学基准
            case "JUNIOR" -> 1.3;     // 初中 +30%
            case "SENIOR" -> 1.6;     // 高中 +60%
            default -> 1.2;
        };
        
        // 上限：基准 × 学段系数 × 1.5（容忍区间）
        int upperLimit = (int) (baselineDailyMinutes * stageFactor * 1.5);
        // 下限：基准 × 学段系数 × 0.5
        int lowerLimit = (int) (baselineDailyMinutes * stageFactor * 0.5);
        
        double score;
        if (dailyMinutes <= upperLimit && dailyMinutes >= lowerLimit) {
            // 在合理区间内，按接近最优值打分
            int optimalMinutes = (int) (baselineDailyMinutes * stageFactor);
            double deviation = Math.abs(dailyMinutes - optimalMinutes) / (double) optimalMinutes;
            score = 100 * (1 - deviation * 0.5); // 偏离最优值每10%扣5分
        } else if (dailyMinutes > upperLimit) {
            // 超出上限，严厉扣分
            double excessRatio = (double) (dailyMinutes - upperLimit) / upperLimit;
            score = Math.max(0, 60 * (1 - excessRatio));
        } else {
            // 低于下限，适度扣分（量不足也是问题）
            double shortfallRatio = (double) (lowerLimit - dailyMinutes) / lowerLimit;
            score = Math.max(20, 70 * (1 - shortfallRatio * 0.5));
        }
        
        // 单任务时长校验：任何单任务超过120分钟（高中150分钟）扣分
        int maxTaskMinutes = "SENIOR".equals(profile.getStage()) ? 150 : 120;
        int minTaskMinutes = 10;
        long overlongTasks = plan.getTasks().stream()
            .filter(t -> t.getEstimatedMinutes() > maxTaskMinutes)
            .count();
        long tooShortTasks = plan.getTasks().stream()
            .filter(t -> t.getEstimatedMinutes() < minTaskMinutes)
            .count();
        score -= overlongTasks * 8;
        score -= tooShortTasks * 3;
        
        return new DimensionScore(
            QualityDimension.TASK_VOLUME_RATIONALITY,
            Math.max(0, Math.min(100, score)),
            Map.of(
                "dailyMinutes", dailyMinutes,
                "baselineDailyMinutes", baselineDailyMinutes,
                "upperLimit", upperLimit,
                "lowerLimit", lowerLimit,
                "overlongTasks", overlongTasks,
                "tooShortTasks", tooShortTasks
            )
        );
    }
}
```

```java
 * 
 * 评估逻辑：
 * 1. 计算任务难度序列的相邻差异
 * 2. 检查是否存在难度跳跃（前后任务难度差 > 2级）
 * 3. 检查整体趋势是否为渐进式
 */
public class DifficultyGradientScorer implements DimensionScorer {
    
    @Override
    public DimensionScore evaluate(Plan plan, StudentProfile profile) {
        List<PlanTask> sortedTasks = plan.getTasks().stream()
            .sorted(Comparator.comparing(PlanTask::getSortOrder))
            .collect(Collectors.toList());
        
        if (sortedTasks.size() < 2) {
            return new DimensionScore(
                QualityDimension.DIFFICULTY_GRADIENT, 75.0,
                Map.of("note", "任务数不足，使用默认分")
            );
        }
        
        // 提取难度序列
        List<Integer> difficulties = sortedTasks.stream()
            .map(PlanTask::getDifficultyLevel)
            .collect(Collectors.toList());
        
        // 计算相邻难度差
        List<Integer> jumps = new ArrayList<>();
        for (int i = 1; i < difficulties.size(); i++) {
            jumps.add(Math.abs(difficulties.get(i) - difficulties.get(i - 1)));
        }
        
        // 统计难度跳跃次数（差 > 2 视为跳跃）
        long bigJumps = jumps.stream().filter(j -> j > 2).count();
        // 平均难度差
        double avgJump = jumps.stream().mapToInt(Integer::intValue).average().orElse(0);
        
        // 计算趋势单调性（理想情况：难度递增或波动平缓）
        double monotonicityScore = calculateMonotonicity(difficulties);
        
        // 综合评分
        double score = 100;
        score -= bigJumps * 15;          // 每次大跳跃扣15分
        score -= Math.max(0, (avgJump - 1.0)) * 20;  // 平均跳跃>1时扣分
        score = score * 0.6 + monotonicityScore * 0.4;  // 趋势单调性占40%
        
        // 学段调整：小学生对难度跳跃更敏感
        if ("PRIMARY".equals(profile.getStage())) {
            score -= bigJumps * 5; // 额外扣分
        }
        
        return new DimensionScore(
            QualityDimension.DIFFICULTY_GRADIENT,
            Math.max(0, Math.min(100, score)),
            Map.of(
                "difficultySequence", difficulties,
                "bigJumps", bigJumps,
                "avgJump", avgJump,
                "monotonicityScore", monotonicityScore
            )
        );
    }
    
    /**
     * 计算序列的单调性评分（0-100）
     * 使用 Spearman 等级相关系数
     */
    private double calculateMonotonicity(List<Integer> sequence) {
        int n = sequence.size();
        if (n <= 1) return 75.0;
        
        // 计算 Spearman 相关系数（与完美递增序列的相似度）
        List<Integer> ranked = rank(sequence);
        List<Integer> idealRank = IntStream.rangeClosed(1, n).boxed().collect(Collectors.toList());
        
        double spearman = spearmanCorrelation(ranked, idealRank);
        
        // spearman 范围 [-1, 1]，映射到 [0, 100]
        // 但并非所有计划都应难度递增，波动式也是合理的
        // 因此对 |spearman| > 0.3 给予较高分
        return Math.abs(spearman) * 50 + 50;
    }
}
```

#### 4.2.3 学科均衡性（SUBJECT_BALANCE）

```java
/**
 * 学科均衡性评分
 * 
 * 评估逻辑：
 * 1. 计算各学科时间占比
 * 2. 对比目标分布（基于学生薄弱学科和考试权重）
 * 3. 使用基尼系数衡量不均衡度
 */
public class SubjectBalanceScorer implements DimensionScorer {
    
    @Override
    public DimensionScore evaluate(Plan plan, StudentProfile profile) {
        // 统计各学科总时长
        Map<String, Integer> subjectMinutes = plan.getTasks().stream()
            .collect(Collectors.groupingBy(
                PlanTask::getSubject,
                Collectors.summingInt(PlanTask::getEstimatedMinutes)
            ));
        
        int totalMinutes = subjectMinutes.values().stream().mapToInt(Integer::intValue).sum();
        if (totalMinutes == 0) {
            return new DimensionScore(
                QualityDimension.SUBJECT_BALANCE, 0.0,
                Map.of("error", "totalMinutes is 0")
            );
        }
        
        // 计算各学科占比
        Map<String, Double> subjectRatios = subjectMinutes.entrySet().stream()
            .collect(Collectors.toMap(
                Map.Entry::getKey,
                e -> e.getValue() / (double) totalMinutes
            ));
        
        // 获取目标分布（基于学生薄弱学科 + 考试权重）
        Map<String, Double> targetDistribution = getTargetSubjectDistribution(profile, plan.getPlanType());
        
        // 计算分布距离（加权 KL 散度）
        double klDivergence = weightedKLDivergence(subjectRatios, targetDistribution);
        
        // KL散度 → 评分映射
        // KL=0 完美匹配 → 100分
        // KL=0.3 严重偏离 → ~40分
        // KL=0.5+ → 接近0分
        double score = 100 * Math.exp(-klDivergence * 3.0);
        
        // 单一学科占比超过 60%（非考前冲刺场景）扣分
        if (!"EXAM_SPRINT".equals(plan.getPlanType())) {
            for (Map.Entry<String, Double> entry : subjectRatios.entrySet()) {
                if (entry.getValue() > 0.6) {
                    score -= (entry.getValue() - 0.6) * 100;
                }
            }
        }
        
        return new DimensionScore(
            QualityDimension.SUBJECT_BALANCE,
            Math.max(0, Math.min(100, score)),
            Map.of(
                "subjectRatios", subjectRatios,
                "targetDistribution", targetDistribution,
                "klDivergence", klDivergence
            )
        );
    }
    
    /**
     * 获取目标学科分布
     * 综合考虑：考试权重 × 薄弱程度 × 学生年级标准课时比
     */
    private Map<String, Double> getTargetSubjectDistribution(StudentProfile profile, String planType) {
        // 基础权重表（根据学段不同）
        Map<String, Double> baseWeights = getBaseWeightsByStage(profile.getStage());
        
        // 根据薄弱学科加权
        Map<String, Double> weaknessBoost = profile.getSubjectWeaknessScores(); // 0-1, 越大越弱
        
        Map<String, Double> combined = new HashMap<>();
        double sum = 0;
        for (String subject : baseWeights.keySet()) {
            double base = baseWeights.get(subject);
            double weakness = weaknessBoost.getOrDefault(subject, 0.0);
            double weight = base * (1 + weakness * 0.5); // 薄弱学科 +50% 权重
            combined.put(subject, weight);
            sum += weight;
        }
        
        // 归一化
        double finalSum = sum;
        combined.replaceAll((k, v) -> v / finalSum);
        return combined;
    }
}
```

## 5. 执行成功率预测模型

### 5.1 模型架构

采用 **XGBoost 二分类器**，预测目标为 `was_completed`（达标率 ≥ 0.6 视为完成 = 1）。

按学段分别训练三个模型，避免特征分布差异过大。

### 5.2 特征工程

```python
"""
学习计划执行成功率预测 - 特征工程管线
"""

import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler

class PlanSuccessFeatureExtractor:
    """计划成功率预测特征提取器"""
    
    FEATURE_GROUPS = [
        # === 1. 计划结构特征 (Plan Structure Features) ===
        "plan_structure",
        # === 2. 学生画像特征 (Student Profile Features) ===
        "student_profile", 
        # === 3. 时序上下文特征 (Temporal Context Features) ===
        "temporal_context",
        # === 4. 历史行为特征 (Historical Behavior Features) ===
        "historical_behavior",
        # === 5. 计划-学生匹配特征 (Plan-Student Matching Features) ===
        "plan_student_match",
    ]
    
    def extract(self, plan: dict, student_profile: dict, 
                historical_data: dict) -> pd.DataFrame:
        """提取完整特征向量"""
        
        features = {}
        features.update(self._extract_plan_structure(plan))
        features.update(self._extract_student_profile(student_profile))
        features.update(self._extract_temporal_context(plan))
        features.update(self._extract_historical_behavior(historical_data))
        features.update(self._extract_match_features(plan, student_profile, historical_data))
        
        return pd.DataFrame([features])
    
    def _extract_plan_structure(self, plan: dict) -> dict:
        """计划结构特征"""
        tasks = plan["tasks"]
        total_minutes = sum(t["estimated_minutes"] for t in tasks)
        plan_days = plan["plan_days"]
        
        return {
            # 基本量
            "plan_task_count": len(tasks),
            "plan_total_minutes": total_minutes,
            "plan_daily_minutes": total_minutes / plan_days,
            "plan_duration_days": plan_days,
            
            # 任务多样性
            "plan_subject_count": len(set(t["subject"] for t in tasks)),
            "plan_task_type_count": len(set(t["task_type"] for t in tasks)),
            
            # 难度统计
            "plan_avg_difficulty": np.mean([t["difficulty_level"] for t in tasks]),
            "plan_std_difficulty": np.std([t["difficulty_level"] for t in tasks]),
            "plan_max_difficulty": max(t["difficulty_level"] for t in tasks),
            "plan_min_difficulty": min(t["difficulty_level"] for t in tasks),
            
            # 难度梯度
            "plan_difficulty_jumps": self._count_difficulty_jumps(tasks),
            "plan_difficulty_trend": self._difficulty_trend(tasks),
            
            # 时间分配
            "plan_avg_task_minutes": np.mean([t["estimated_minutes"] for t in tasks]),
            "plan_max_task_minutes": max(t["estimated_minutes"] for t in tasks),
            "plan_task_duration_std": np.std([t["estimated_minutes"] for t in tasks]),
            "plan_task_duration_cv": (np.std([t["estimated_minutes"] for t in tasks]) / 
                                      max(np.mean([t["estimated_minutes"] for t in tasks]), 1)),
            
            # 学科分布
            "plan_subject_entropy": self._subject_entropy(tasks),
            "plan_max_subject_ratio": self._max_subject_ratio(tasks),
            
            # 弹性
            "plan_flexibility_buffer_ratio": plan.get("buffer_ratio", 0),
            "plan_has_fallback_tasks": int(plan.get("has_fallback", False)),
            
            # 间隔重复
            "plan_review_task_ratio": (
                len([t for t in tasks if t["task_type"] == "REVIEW"]) / max(len(tasks), 1)
            ),
        }
    
    def _extract_student_profile(self, profile: dict) -> dict:
        """学生画像特征"""
        return {
            "student_stage": self._encode_stage(profile["stage"]),
            "student_grade": profile["grade_level"],
            "student_avg_daily_minutes": profile.get("avg_daily_study_minutes", 0),
            "student_study_streak_days": profile.get("current_streak_days", 0),
            "student_completion_rate_30d": profile.get("completion_rate_30d", 0),
            "student_completion_rate_7d": profile.get("completion_rate_7d", 0),
            "student_avg_quality_score": profile.get("avg_quality_score", 0),
            "student_subject_weakness_count": sum(1 for v in profile.get("subject_weakness", {}).values() if v > 0.5),
            "student_preferred_time_slot": self._encode_time_slot(profile.get("preferred_time_slot")),
            "student_member_tier": self._encode_member(profile.get("member_tier")),
            "student_days_since_register": profile.get("days_since_register", 0),
        }
    
    def _extract_temporal_context(self, plan: dict) -> dict:
        """时序上下文特征"""
        now = pd.Timestamp.now()
        start = pd.Timestamp(plan["start_date"])
        
        return {
            "is_weekend_plan": int(start.dayofweek >= 5),
            "is_holiday_plan": int(plan.get("is_holiday", False)),
            "is_exam_season": int(plan.get("is_exam_season", False)),
            "days_to_nearest_exam": plan.get("days_to_exam", 365),
            "semester_week_number": self._semester_week(start),
            "plan_starts_today": int((start - now).days == 0),
            "plan_days_until_start": max(0, (start - now).days),
            "season": self._encode_season(start.month),  # 春夏秋冬影响学习状态
        }
    
    def _extract_historical_behavior(self, hist: dict) -> dict:
        """历史行为特征"""
        recent_plans = hist.get("recent_plan_outcomes", [])
        
        return {
            # 最近计划执行情况
            "hist_completion_rate_trend_3": self._trend(recent_plans[-3:], "completion_rate"),
            "hist_avg_completion_rate_5": self._avg(recent_plans[-5:], "completion_rate"),
            "hist_avg_time_deviation_5": self._avg(recent_plans[-5:], "time_deviation_ratio"),
            "hist_abandonment_rate_10": self._abandonment_rate(recent_plans[-10:]),
            "hist_consecutive_completions": self._consecutive_completions(recent_plans),
            "hist_same_type_completion_rate": self._same_type_rate(
                recent_plans, hist.get("plan_type")
            ),
            
            # 学科历史表现
            "hist_best_subject": self._encode_subject(hist.get("best_subject")),
            "hist_worst_subject": self._encode_subject(hist.get("worst_subject")),
            "hist_subject_balance_30d": hist.get("subject_balance_30d", 0.5),
        }
    
    def _extract_match_features(self, plan, profile, hist) -> dict:
        """计划-学生匹配特征"""
        plan_daily = sum(t["estimated_minutes"] for t in plan["tasks"]) / plan["plan_days"]
        student_avg = profile.get("avg_daily_study_minutes", 0)
        
        return {
            # 量级匹配
            "match_volume_ratio": plan_daily / max(student_avg, 1),
            "match_volume_exceeds_threshold": int(plan_daily > student_avg * 1.3),
            
            # 难度匹配（基于IRT）
            "match_difficulty_to_ability": (
                np.mean([t["difficulty_level"] for t in plan["tasks"]]) / 
                max(profile.get("ability_level", 3), 1)
            ),
            
            # 时段匹配
            "match_time_slot_alignment": self._time_alignment(plan["tasks"], profile),
            
            # 学科偏好匹配
            "match_weak_subject_coverage": self._weak_subject_coverage(
                plan["tasks"], profile.get("subject_weakness", {})
            ),
            
            # 同类计划历史成功率
            "match_historical_similar_success": self._similar_plan_success_rate(
                plan, hist.get("recent_plan_outcomes", [])
            ),
        }
    
    # === 辅助方法 ===
    
    def _count_difficulty_jumps(self, tasks):
        diffs = [t["difficulty_level"] for t in tasks]
        return sum(1 for i in range(1, len(diffs)) if abs(diffs[i] - diffs[i-1]) > 2)
    
    def _difficulty_trend(self, tasks):
        diffs = [t["difficulty_level"] for t in tasks]
        if len(diffs) < 2: return 0
        x = np.arange(len(diffs))
        slope = np.polyfit(x, diffs, 1)[0]
        return float(slope)
    
    def _subject_entropy(self, tasks):
        from collections import Counter
        counts = Counter(t["subject"] for t in tasks)
        total = sum(counts.values())
        probs = [c/total for c in counts.values()]
        return float(-sum(p * np.log2(p) for p in probs if p > 0))
    
    def _max_subject_ratio(self, tasks):
        from collections import Counter
        counts = Counter(t["subject"] for t in tasks)
        return max(counts.values()) / len(tasks) if tasks else 1.0
    
    def _trend(self, plans, key):
        vals = [p.get(key, 0) for p in plans if p]
        if len(vals) < 2: return 0
        return float(np.polyfit(range(len(vals)), vals, 1)[0])
    
    def _avg(self, plans, key):
        vals = [p.get(key, 0) for p in plans if p]
        return float(np.mean(vals)) if vals else 0
    
    def _abandonment_rate(self, plans):
        if not plans: return 0.5
        abandoned = sum(1 for p in plans if p and p.get("completion_rate", 1) < 0.3)
        return abandoned / len(plans)
    
    def _consecutive_completions(self, plans):
        count = 0
        for p in reversed(plans):
            if p and p.get("completion_rate", 0) >= 0.6:
                count += 1
            else:
                break
        return count
    
    def _time_alignment(self, tasks, profile):
        preferred = profile.get("preferred_time_slot", "FLEXIBLE")
        if preferred == "FLEXIBLE": return 1.0
        aligned = sum(1 for t in tasks if t.get("time_slot") == preferred or t.get("time_slot") == "FLEXIBLE")
        return aligned / len(tasks) if tasks else 0.5
    
    def _weak_subject_coverage(self, tasks, weakness_map):
        weak = {s for s, v in weakness_map.items() if v > 0.4}
        if not weak: return 1.0
        covered = {t["subject"] for t in tasks}
        return len(weak & covered) / len(weak)
    
    def _similar_plan_success_rate(self, plan, outcomes):
        same_type = [o for o in outcomes if o and o.get("plan_type") == plan.get("plan_type")]
        if not same_type: return 0.5
        return np.mean([o.get("completion_rate", 0) for o in same_type])
```

### 5.3 模型训练管线

```python
"""
执行成功率预测模型训练管线
"""

import xgboost as xgb
from sklearn.model_selection import TimeSeriesSplit
from sklearn.metrics import roc_auc_score, classification_report
import joblib
import mlflow

class PlanSuccessModelTrainer:
    
    def __init__(self, config):
        self.config = config
        self.stages = ["PRIMARY", "JUNIOR", "SENIOR"]
    
    def train_all(self, training_data_df):
        """训练所有学段模型"""
        models = {}
        for stage in self.stages:
            stage_df = training_data_df[training_data_df["student_stage"] == stage]
            if len(stage_df) < self.config["min_samples_per_stage"]:
                print(f"⚠️ {stage} 样本不足({len(stage_df)}), 跳过训练")
                continue
            models[stage] = self._train_single(stage_df, stage)
        return models
    
    def _train_single(self, df, stage):
        """训练单个学段模型"""
        mlflow.start_run(run_name=f"plan_success_{stage}_{pd.Timestamp.now().strftime('%Y%m%d')}")
        
        # 特征/标签分离
        exclude_cols = ["was_completed", "plan_id", "user_id", "student_stage"]
        feature_cols = [c for c in df.columns if c not in exclude_cols]
        X = df[feature_cols]
        y = df["was_completed"]
        
        # 时间序列交叉验证
        tscv = TimeSeriesSplit(n_splits=5)
        
        # XGBoost 参数（按学段差异化）
        params = self._get_params(stage)
        
        # 训练
        best_model = None
        best_auc = 0
        
        for train_idx, val_idx in tscv.split(X):
            X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
            y_train, y_val = y.iloc[train_idx], y.iloc[val_idx]
            
            model = xgb.XGBClassifier(**params)
            model.fit(
                X_train, y_train,
                eval_set=[(X_val, y_val)],
                verbose=False
            )
            
            y_pred = model.predict_proba(X_val)[:, 1]
            auc = roc_auc_score(y_val, y_pred)
            
            if auc > best_auc:
                best_auc = auc
                best_model = model
        
        # 记录 MLflow
        mlflow.log_params(params)
        mlflow.log_metric("val_auc", best_auc)
        mlflow.log_metric("train_samples", len(df))
        mlflow.xgboost.log_model(best_model, f"plan_success_{stage}")
        
        # 特征重要度
        importance = best_model.feature_importances_
        feat_imp = sorted(zip(feature_cols, importance), key=lambda x: -x[1])
        for name, imp in feat_imp[:20]:
            mlflow.log_metric(f"feat_imp_{name}", imp)
        
        print(f"✅ {stage} 模型训练完成, AUC={best_auc:.4f}, 样本数={len(df)}")
        
        mlflow.end_run()
        return best_model
    
    def _get_params(self, stage):
        """按学段差异化超参数"""
        base_params = {
            "objective": "binary:logistic",
            "eval_metric": "auc",
            "tree_method": "hist",
            "n_jobs": -1,
            "random_state": 42,
        }
        
        stage_overrides = {
            "PRIMARY": {"max_depth": 5, "learning_rate": 0.08, "n_estimators": 250,
                       "min_child_weight": 8, "subsample": 0.8, "colsample_bytree": 0.8},
            "JUNIOR":  {"max_depth": 6, "learning_rate": 0.06, "n_estimators": 300,
                       "min_child_weight": 5, "subsample": 0.85, "colsample_bytree": 0.85},
            "SENIOR":  {"max_depth": 7, "learning_rate": 0.05, "n_estimators": 350,
                       "min_child_weight": 3, "subsample": 0.9, "colsample_bytree": 0.85},
        }
        return {**base_params, **stage_overrides.get(stage, {})}
```

## 6. 规则引擎设计

### 6.1 规则分类

规则引擎实现"硬性约束校验 + 一票否决"机制，作为模型评分之外的保底安全网。

| 规则类别 | 触发条件 | 处理方式 | 示例 |
| --- | --- | --- | --- |
| **HARD_VETO** | 违反教育/安全底线 | 一票否决，计划不可发布 | 任务总量 > 720分钟/天 |
| **SOFT_WARN** | 不合理但可发布 | 扣分 + 标记建议 | 连续无休息天数 > 6 |
| **INFO_HINT** | 优化建议 | 仅记录，不扣分 | 建议在英语弱项前安排数学热身 |

### 6.2 核心规则集

```java
/**
 * 计划质量硬性规则集
 */
@Component
public class PlanQualityRules {
    
    // ============ HARD_VETO 规则 ============
    
    /** 规则RV-01: 单日学习总时长不可超过上限 */
    @Rule(name = "RV-01", priority = 1, type = RuleType.HARD_VETO)
    public RuleResult checkDailyTimeLimit(Plan plan, StudentProfile profile) {
        int planDays = calcDays(plan);
        int dailyMinutes = plan.getEstimatedTotalMinutes() / planDays;
        
        int maxDailyMinutes = switch (profile.getStage()) {
            case "PRIMARY" -> 180;  // 小学 ≤ 3小时
            case "JUNIOR" -> 300;   // 初中 ≤ 5小时
            case "SENIOR" -> 480;   // 高中 ≤ 8小时
            default -> 360;
        };
        
        if (dailyMinutes > maxDailyMinutes) {
            return RuleResult.veto(
                "RV-01",
                String.format("日均学习时长%d分钟超过上限%d分钟", dailyMinutes, maxDailyMinutes)
            );
        }
        return RuleResult.pass();
    }
    
    /** 规则RV-02: 任何任务难度不可超过学生当前能力+2 */
    @Rule(name = "RV-02", priority = 1, type = RuleType.HARD_VETO)
    public RuleResult checkDifficultyVsAbility(Plan plan, StudentProfile profile) {
        int abilityLevel = profile.getAbilityLevel(); // 1-5
        int maxDifficulty = abilityLevel + 2;
        
        List<PlanTask> tooHard = plan.getTasks().stream()
            .filter(t -> t.getDifficultyLevel() > maxDifficulty)
            .collect(Collectors.toList());
        
        if (!tooHard.isEmpty()) {
            return RuleResult.veto(
                "RV-02",
                String.format("%d个任务难度(%d级)超过学生能力上限(%d级)",
                    tooHard.size(), 
                    tooHard.get(0).getDifficultyLevel(), maxDifficulty)
            );
        }
        return RuleResult.pass();
    }
    
    /** 规则RV-03: 深夜时段（22:00-06:00）不可安排任务 */
    @Rule(name = "RV-03", priority = 1, type = RuleType.HARD_VETO)
    public RuleResult checkLateNightTasks(Plan plan, StudentProfile profile) {
        // 检查是否有任务被安排在深夜时段
        boolean hasLateNight = plan.getTasks().stream()
            .anyMatch(t -> "LATE_NIGHT".equals(t.getTimeSlot()));
        
        if (hasLateNight) {
            return RuleResult.veto("RV-03", "计划包含深夜时段任务，违反未成年人保护规则");
        }
        return RuleResult.pass();
    }
    
    /** 规则RV-04: 计划必须包含至少一个非学习类休息/缓冲时段 */
    @Rule(name = "RV-04", priority = 2, type = RuleType.HARD_VETO)
    public RuleResult checkHasBreakTime(Plan plan, StudentProfile profile) {
        int planDays = calcDays(plan);
        int totalTaskMinutes = plan.getEstimatedTotalMinutes();
        int totalAvailableMinutes = planDays * switch(profile.getStage()) {
            case "PRIMARY" -> 240;
            case "JUNIOR" -> 420;
            case "SENIOR" -> 600;
            default -> 360;
        };
        
        double utilizationRate = (double) totalTaskMinutes / totalAvailableMinutes;
        if (utilizationRate > 0.9) {
            return RuleResult.veto("RV-04", 
                String.format("时间利用率%.0f%%过高，必须保留休息时间", utilizationRate * 100));
        }
        return RuleResult.pass();
    }
    
    // ============ SOFT_WARN 规则 ============
    
    /** 规则SW-01: 连续学习天数不可超过6天无休 */
    @Rule(name = "SW-01", priority = 3, type = RuleType.SOFT_WARN)
    public RuleResult checkRestDayPattern(Plan plan, StudentProfile profile) {
        // 统计计划期间连续无休息日数
        int maxConsecutive = calcMaxConsecutiveDays(plan);
        if (maxConsecutive > 6) {
            return RuleResult.warn("SW-01",
                String.format("连续学习%d天无休息日，建议插入休息日", maxConsecutive),
                SuggestionType.ADD_REST_DAY
            );
        }
        return RuleResult.pass();
    }
    
    /** 规则SW-02: 同一学科连续任务时长不可超过120分钟 */
    @Rule(name = "SW-02", priority = 3, type = RuleType.SOFT_WARN)
    public RuleResult checkSubjectSessionLength(Plan plan, StudentProfile profile) {
        Map<String, Integer> subjectConsecutive = calcMaxConsecutiveSubjectMinutes(plan);
        
        List<String> overLimit = subjectConsecutive.entrySet().stream()
            .filter(e -> e.getValue() > 120)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
        
        if (!overLimit.isEmpty()) {
            return RuleResult.warn("SW-02",
                String.format("学科%s连续学习超过120分钟，建议穿插其他学科", 
                    String.join("、", overLimit)),
                SuggestionType.INTERLEAVE_SUBJECTS
            );
        }
        return RuleResult.pass();
    }
    
    /** 规则SW-03: 目标关键知识点不可遗漏 */
    @Rule(name = "SW-03", priority = 4, type = RuleType.SOFT_WARN)
    public RuleResult checkKeyKnowledgeCoverage(Plan plan, StudentProfile profile) {
        if (plan.getGoalId() == null) return RuleResult.pass();
        
        Set<Long> requiredKps = goalService.getRequiredKnowledgePoints(plan.getGoalId());
        Set<Long> plannedKps = plan.getTasks().stream()
            .flatMap(t -> t.getKnowledgePointIds().stream())
            .collect(Collectors.toSet());
        
        Set<Long> missing = new HashSet<>(requiredKps);
        missing.removeAll(plannedKps);
        
        if (!missing.isEmpty()) {
            return RuleResult.warn("SW-03",
                String.format("目标要求%d个知识点中，%d个未在计划中覆盖", 
                    requiredKps.size(), missing.size()),
                SuggestionType.ADD_MISSING_KNOWLEDGE_TASKS
            );
        }
        return RuleResult.pass();
    }
    
    // ============ INFO_HINT 规则 ============
    
    /** 规则IH-01: 薄弱学科建议安排在学生高效时段 */
    @Rule(name = "IH-01", priority = 5, type = RuleType.INFO_HINT)
    public RuleResult checkWeakSubjectTimeSlot(Plan plan, StudentProfile profile) {
        String preferredSlot = profile.getPreferredTimeSlot();
        Map<String, Double> weakness = profile.getSubjectWeaknessScores();
        
        List<String> weakSubjects = weakness.entrySet().stream()
            .filter(e -> e.getValue() > 0.5)
            .sorted(Map.Entry.<String, Double>comparingByValue().reversed())
            .map(Map.Entry::getKey)
            .limit(2)
            .collect(Collectors.toList());
        
        for (String subject : weakSubjects) {
            boolean inPreferredSlot = plan.getTasks().stream()
                .anyMatch(t -> subject.equals(t.getSubject()) && preferredSlot.equals(t.getTimeSlot()));
            if (!inPreferredSlot) {
                return RuleResult.hint("IH-01",
                    String.format("薄弱学科%s建议安排在高效时段(%s)", subject, preferredSlot),
                    SuggestionType.MOVE_WEAK_SUBJECT_TO_PREFERRED_SLOT
                );
            }
        }
        return RuleResult.pass();
    }
}
```

## 9. 修正建议引擎

### 9.1 建议生成策略

```java
/**
 * 计划修正建议生成器
 * 
 * 根据质量评分中的低分维度和规则引擎的警告结果，
 * 生成可操作的修正建议
 */
@Component
public class PlanSuggestionGenerator {
    
    /**
     * 生成修正建议
     */
    public List<PlanSuggestion> generate(
            Map<QualityDimension, DimensionScore> dimensionScores,
            List<RuleResult> ruleResults,
            Plan plan,
            StudentProfile profile) {
        
        List<PlanSuggestion> suggestions = new ArrayList<>();
        
        // 1. 从规则引擎结果生成建议
        for (RuleResult rule : ruleResults) {
            if (rule.getResult() == RuleResultType.WARN && rule.getSuggestionType() != null) {
                suggestions.add(buildFromRule(rule, plan, profile));
            }
        }
        
        // 2. 从低分维度生成建议（按维度得分升序，优先处理最差维度）
        dimensionScores.entrySet().stream()
            .sorted(Comparator.comparingDouble(e -> e.getValue().getScore()))
            .limit(3) // 最多取3个最低分维度
            .forEach(entry -> {
                QualityDimension dim = entry.getKey();
                double score = entry.getValue().getScore();
                if (score < 70) {
                    suggestions.add(buildFromDimension(dim, score, entry.getValue().getDetails(), plan, profile));
                }
            });
        
        // 3. 去重和优先级排序
        return suggestions.stream()
            .distinct()
            .sorted(Comparator.comparing(PlanSuggestion::getPriority).reversed())
            .limit(5)
            .collect(Collectors.toList());
    }
    
    private PlanSuggestion buildFromDimension(QualityDimension dim, double score,
            Map<String, Object> details, Plan plan, StudentProfile profile) {
        
        return switch (dim) {
            case TASK_VOLUME_RATIONALITY -> buildVolumeSuggestion(details, plan);
            case SUBJECT_BALANCE -> buildBalanceSuggestion(details, plan);
            case DIFFICULTY_GRADIENT -> buildDifficultySuggestion(details, plan);
            case REVIEW_INTERVAL -> buildReviewSuggestion(details, plan);
            case FLEXIBILITY -> buildFlexibilitySuggestion(plan);
            default -> new PlanSuggestion(dim.name(), "MEDIUM", 
                String.format("维度%s得分%.1f，建议优化", dim.getLabel(), score), List.of());
        };
    }
    
    /**
     * 学科均衡性修正建议
     */
    private PlanSuggestion buildBalanceSuggestion(Map<String, Object> details, Plan plan) {
        @SuppressWarnings("unchecked")
        Map<String, Double> ratios = (Map<String, Double>) details.get("subjectRatios");
        
        String overWeighted = ratios.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey).orElse(null);
        double maxRatio = ratios.values().stream().max(Double::compare).orElse(0.0);
        
        List<ActionableChange> changes = new ArrayList<>();
        
        if (maxRatio > 0.5) {
            // 找出占比最低的学科作为增加目标
            String underWeighted = ratios.entrySet().stream()
                .min(Map.Entry.comparingByValue())
                .map(Map.Entry::getKey).orElse(null);
            
            // 将该学科最后一个任务改为薄弱学科
            List<PlanTask> subjectTasks = plan.getTasks().stream()
                .filter(t -> overWeighted.equals(t.getSubject()))
                .sorted(Comparator.comparing(PlanTask::getSortOrder).reversed())
                .collect(Collectors.toList());
            
            if (!subjectTasks.isEmpty()) {
                PlanTask lastTask = subjectTasks.get(0);
                changes.add(new ActionableChange(
                    lastTask.getTaskId(), "subject", overWeighted, underWeighted
                ));
            }
        }
        
        return new PlanSuggestion(
            "SUBJECT_BALANCE",
            maxRatio > 0.6 ? "HIGH" : "MEDIUM",
            String.format("%s占比%.0f%%偏高，建议调整为40%%以内", overWeighted, maxRatio * 100),
            changes
        );
    }
}
```

## 10. 错误处理与降级策略

### 10.1 错误分级与处理

| 错误场景 | 错误码 | 处理策略 |
| --- | --- | --- |
| 学生画像数据缺失 | PE-4001 | 使用学段默认画像，标记 `profile_fallback=true` |
| 特征提取异常 | PE-4002 | 跳过成功率预测，仅返回质量评分 |
| 模型推理超时（>300ms） | PE-5001 | 返回缓存的上次评估结果，异步重试 |
| 模型服务不可用 | PE-5002 | 仅返回规则引擎结果 + 默认评分(70分) |
| 规则引擎执行异常 | PE-5003 | 跳过规则校验，仅返回评分结果 + 告警 |
| 学生画像过期（>7天） | PE-4003 | 使用过期画像 + 标记 `profile_stale=true` |

### 10.2 降级链路

```
完整评估 (规则 + 评分 + 预测)
    ↓ [模型不可用]
规则 + 评分 (不含预测)
    ↓ [评分模型不可用]
规则 + 默认评分 (经验值)
    ↓ [规则引擎不可用]
仅预测 (模型评估)
    ↓ [全部不可用]
默认通过 + 人工抽检告警
```

### 10.3 核心异常处理代码

```java
/**
 * 评估服务降级处理器
 */
@Service
public class PlanQualityEvaluationService {
    
    @Autowired private RuleEngine ruleEngine;
    @Autowired private QualityScorer qualityScorer;
    @Autowired private SuccessPredictor successPredictor;
    @Autowired private PlanQualityCacheManager cacheManager;
    @Autowired private AlertService alertService;
    
    @Retryable(maxAttempts = 2, backoff = @Backoff(delay = 100))
    @CircuitBreaker(fallbackMethod = "fallbackEvaluate")
    public PlanQualityEvaluation evaluate(Plan plan, StudentProfile profile, 
                                          EvaluationOptions options) {
        long startTime = System.currentTimeMillis();
        
        // 1. 规则引擎
        List<RuleResult> ruleResults;
        try {
            ruleResults = ruleEngine.checkAll(plan, profile);
        } catch (Exception e) {
            log.warn("规则引擎异常，跳过规则校验 planId={}", plan.getPlanId(), e);
            ruleResults = Collections.emptyList();
            alertService.sendQuietAlert("RULE_ENGINE_ERROR", 
                Map.of("planId", plan.getPlanId(), "error", e.getMessage()));
        }
        
        // 检查一票否决
        Optional<RuleResult> veto = ruleResults.stream()
            .filter(r -> r.getResult() == RuleResultType.VETO)
            .findFirst();
        if (veto.isPresent()) {
            return buildVetoedEvaluation(plan, veto.get(), startTime);
        }
        
        // 2. 质量评分
        QualityScoreResult scoreResult;
        try {
            scoreResult = qualityScorer.score(plan, profile);
        } catch (Exception e) {
            log.warn("质量评分异常，使用默认评分 planId={}", plan.getPlanId(), e);
            scoreResult = QualityScoreResult.defaultScore();
        }
        
        // 3. 成功率预测
        double successProb = 0.7; // 默认值
        try {
            if (options.isEnableSuccessPredictor()) {
                successProb = successPredictor.predict(plan, profile, scoreResult);
            }
        } catch (Exception e) {
            log.warn("成功率预测异常，使用默认值 planId={}", plan.getPlanId(), e);
            // 尝试缓存
            Double cached = cacheManager.getLastSuccessProbability(plan.getUserId());
            if (cached != null) {
                successProb = cached;
            }
        }
        
        // 4. 聚合结果
        return aggregateResult(plan, profile, scoreResult, successProb, ruleResults, startTime);
    }
    
    /**
     * 熔断降级方法
     */
    public PlanQualityEvaluation fallbackEvaluate(Plan plan, StudentProfile profile,
                                                   EvaluationOptions options, 
                                                   Throwable cause) {
        log.error("评估服务熔断，返回降级结果 planId={}", plan.getPlanId(), cause);
        
        // 返回保守的默认评估
        return PlanQualityEvaluation.builder()
            .planId(plan.getPlanId())
            .overallScore(70.0)  // 默认可接受分数
            .qualityGrade("ACCEPTABLE")
            .successProbability(0.65)
            .riskLevel("MEDIUM")
            .vetoReason(null)
            .suggestionsJson("[]")
            .evaluationDurationMs(1)
            .modelVersion("FALLBACK")
            .build();
    }
}
```
