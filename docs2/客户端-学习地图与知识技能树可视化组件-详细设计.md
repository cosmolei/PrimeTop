# 客户端-学习地图与知识技能树可视化组件-详细设计

> **文档版本**: v1.0  
> **创建日期**: 2026-06-25  
> **所属模块**: 客户端组件库 / 学习激励 / 同步课堂  
> **优先级**: P1 (V1.5 阶段)  
> **依赖文档**: 知识图谱构建与可视化交互引擎、学习规划与每日任务、学生个人知识图谱构建与认知网络演化追踪引擎

---

## 1. 概述

### 1.1 设计目标

为学生提供可视化的个人学习进度地图，将抽象的"知识点掌握程度"和"学习路径"转化为直观的、游戏化的交互体验。学生可以在地图上：

- 看到自己已经攻克的知识节点（成就感）
- 清晰地知道下一步该学什么（方向感）
- 感知到薄弱区域需要复习（紧迫感）
- 通过解锁、连线、点亮等交互获得持续学习动力（激励感）

### 1.2 与已有模块的边界

| 已有文档 | 关注点 | 本文档区别 |
|---------|--------|-----------|
| 知识图谱构建与可视化交互引擎 | 知识点之间的**学科关系**（前置、关联、包含） | 本文档关注**学生个人进度**在知识点上的投射，而非知识结构本身 |
| 知识图谱浏览与关联学习 | 用户主动浏览探索知识网络 | 本文档是**学习引导路径**，有明确的先后顺序和进度状态 |
| 学习规划与每日任务 | 任务清单式的学习计划（文本/卡片） | 本文档是**空间化/图形化**的进度呈现，侧重视觉激励 |
| 学生个人知识图谱构建 | 学生知识掌握的数据建模 | 本文档消费这些数据，聚焦**前端渲染与交互** |

### 1.3 核心设计理念

```
知识图谱 = "地图地形"（道路、城市、地形）
学习路径规划 = "导航路线"（从A到B怎么走）
学习地图组件 = "你当前在地图上的位置 + 已探索区域 + 前方可解锁区域"
                — 让学生感觉自己在"征服"知识世界
```

## 2. 视觉模式设计

### 2.1 三种可视化模式

组件支持三种渲染模式，按学段和场景切换：

#### 模式一：路径闯关式（Path / Trail）

适用场景：**章节学习、同步课堂、拼音识字**

```
  ☆ 起点
  |
  ●─── 第1章：认识数字 [已完成 ✅]
  |
  ●─── 第2章：加减法入门 [已完成 ✅]
  |
  ◎─── 第3章：乘法口诀 [进行中 📍]  ← 当前位置
 / \
●   ●─── 第3.1节：2-5乘法 [已掌握]
    |
    ○─── 第3.2节：6-9乘法 [未解锁] 🔒
    |
    ○─── 第4章：除法基础 [未解锁] 🔒
    |
  ★─── 期末目标 [终点]
```

- 节点之间的连线表示学习顺序
- 已完成节点高亮，当前节点有呼吸光圈动画
- 分支路径用分叉表示（如选修/扩展内容）

#### 模式二：技能树式（Skill Tree）

适用场景：**考点梳理、学科总复习、知识体系浏览**

```
            ┌─────────────┐
            │  代数基础    │ Lv.3
            │  ████████░░  │ 80%
            └──────┬───────┘
          ┌────────┼────────┐
     ┌────┴───┐ ┌──┴───┐ ┌──┴────┐
     │ 方程   │ │ 不等式│ │ 函数  │
     │ Lv.3  │ │ Lv.2 │ │ Lv.1  │
     │████░░░░│ │██░░░░│ │█░░░░░░│
     └────────┘ └──────┘ └───────┘
```

- 树状层级展示知识体系
- 每个节点显示掌握度进度条
- 子节点亮度随父节点掌握度递减
- 鼠标/触摸展开子树

#### 模式三：星座点亮式（Constellation）

适用场景：**幼儿启蒙、学情总览首页**

```
    ✨ 拼音星座
   ⭐ ── ⭐
   /       \
 ⭐    🌙    ⭐
  \   |   /
    ⭐ ── ⭐

  已点亮 ⭐ = 已掌握
  灰色 ☆ = 未学习
  闪烁 ✨ = 当前推荐
```

- 适合低龄用户，视觉柔和
- 以"点亮星星"为激励隐喻
- 星座之间用虚线连接，形成可探索的"知识星空"

### 2.2 分龄模式适配

| 学段 | 默认模式 | 视觉风格 | 交互复杂度 |
|------|---------|---------|-----------|
| 幼儿 | 星座点亮式 | 圆润、明亮、大触控区 | 点击点亮，长按听发音 |
| 小学 | 路径闯关式 | 卡通、色彩丰富、有角色引导 | 点击进入学习，滑动浏览 |
| 初中 | 路径闯关式 + 技能树切换 | 简洁、有进度数据 | 支持缩放、拖拽、筛选 |
| 高中 | 技能树式 | 专业、数据密集、高信息量 | 支持多维筛选、深度下钻 |

## 3. 数据结构定义

### 3.1 服务端响应数据模型

```typescript
/**
 * 学习地图完整数据结构
 * 由服务端根据学生ID、学科、教材版本动态生成
 */
interface LearningMapData {
  /** 地图元信息 */
  mapId: string;                    // 地图唯一标识
  studentId: string;                // 学生ID
  subject: Subject;                 // 学科
  stage: Stage;                     // 学段
  grade: number;                    // 年级
  textbookVersion: string;          // 教材版本
  mode: MapMode;                    // 推荐渲染模式
  generatedAt: string;              // 生成时间 ISO 8601
  /** 全局进度统计 */
  overallProgress: number;          // 总进度 0-100
  totalNodes: number;               // 总节点数
  masteredNodes: number;            // 已掌握节点数
  learningNodes: number;            // 学习中节点数
  lockedNodes: number;              // 未解锁节点数
  /** 节点列表 */
  nodes: LearningMapNode[];
  /** 边/连线列表 */
  edges: LearningMapEdge[];
  /** 当前推荐节点 */
  recommendedNodeId: string | null;
  /** 最近成就 */
  recentAchievements: MapAchievement[];
}

type Subject = 'chinese' | 'math' | 'english' | 'physics' | 'chemistry' 
             | 'biology' | 'history' | 'geography' | 'politics' | 'pinyin';

type Stage = 'preschool' | 'primary' | 'junior' | 'senior';

type MapMode = 'path' | 'skill_tree' | 'constellation';

type NodeStatus = 'mastered' | 'learning' | 'available' | 'locked' | 'weak';

type NodeType = 'chapter' | 'section' | 'knowledge_point' | 'exercise_set' 
              | 'checkpoint' | 'boss_battle' | 'bonus';

/**
 * 学习地图节点
 */
interface LearningMapNode {
  /** 节点唯一标识 */
  nodeId: string;
  /** 关联的知识点/章节ID */
  knowledgePointId: string;
  /** 节点类型 */
  type: NodeType;
  /** 显示名称 */
  title: string;
  /** 副标题/描述 */
  subtitle?: string;
  /** 节点状态 */
  status: NodeStatus;
  /** 掌握度 0-100（locked 为 null） */
  mastery: number | null;
  /** 估计学习时长（分钟） */
  estimatedMinutes: number;
  /** 节点难度 1-5 */
  difficulty: 1 | 2 | 3 | 4 | 5;
  /** 父节点ID（技能树模式用于层级） */
  parentNodeId?: string;
  /** 节点层级深度 */
  depth: number;
  /** 前置节点ID列表（必须完成后才能解锁） */
  prerequisites: string[];
  /** 奖励信息 */
  rewards?: NodeReward;
  /** 图标资源URL（可选，不传用默认） */
  iconUrl?: string;
  /** 布局坐标（服务端可给建议，客户端可覆盖） */
  suggestedPosition?: { x: number; y: number };
  /** 薄弱标记（该节点关联的知识点在错题本中出现频次高） */
  isWeakSpot?: boolean;
  /** 最后学习时间 */
  lastStudiedAt?: string;
  /** 累计学习时长（秒） */
  totalStudySeconds?: number;
  /** 练习题数量 */
  exerciseCount?: number;
  /** 正确率 */
  accuracy?: number;
}

/**
 * 学习地图边/连线
 */
interface LearningMapEdge {
  edgeId: string;
  fromNodeId: string;
  toNodeId: string;
  /** 边类型 */
  type: 'prerequisite' | 'related' | 'parent_child' | 'cross_subject';
  /** 边的强度（关联程度 0-1） */
  weight?: number;
  /** 边的显示标签 */
  label?: string;
}

/**
 * 节点奖励信息
 */
interface NodeReward {
  /** 积分奖励 */
  points: number;
  /** 经验值 */
  exp: number;
  /** 徽章ID（完成后获得） */
  badgeId?: string;
  /** 奖杯/星星数 */
  stars: 0 | 1 | 2 | 3;
  /** 特殊奖励描述 */
  specialReward?: string;
}

/**
 * 地图成就
 */
interface MapAchievement {
  achievementId: string;
  type: 'streak' | 'milestone' | 'perfection' | 'speed' | 'comeback';
  title: string;
  description: string;
  iconUrl: string;
  unlockedAt: string;
}
```

### 3.2 客户端内部状态模型

```typescript
/**
 * 组件内部状态管理

interface LearningMapState {
  /** 原始数据 */

  /** 当前渲染模式（可被用户切换） */

  /** 当前选中节点 */

  /** 当前焦点节点（地图居中/缩放目标） */

  viewport: ViewportState;
  /** 筛选器 */
  filters: MapFilters;
  /** 动画状态 */
  animation: {
    /** 节点点亮动画队列 */
    lightingQueue: string[];
    /** 是否正在播放路径动画 */
    isPathAnimating: boolean;
    /** 脉冲动画的节点ID */
    pulsingNodeId: string | null;

  /** 用户偏好（持久化） */
  preferences: {

    showLabels: boolean;
    showWeakSpots: boolean;

  };
  /** 加载状态 */

  /** 错误信息 */
  error: string | null;
}

interface ViewportState {
  /** 缩放比例 0.5 - 3.0 */
  scale: number;
  /** 平移偏移 */
  offsetX: number;
  offsetY: number;
  /** 最小缩放 */
  minScale: number;
  /** 最大缩放 */
  maxScale: number;

interface MapFilters {
  /** 按状态筛选 */
  statusFilter: NodeStatus[] | null;
  /** 按难度筛选 */
  difficultyFilter: number[] | null;
```

### 3.3 节点状态机

```
┌─────────────────────────────────────────────────────────────┐
│                    Node Status State Machine                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────┐  解锁条件满足   ┌───────────┐                │
│   │ locked  │ ──────────────→ │ available │                │
│   └─────────┘                 └─────┬─────┘                │
│                                      │ 用户开始学习          │
│                                      ▼                      │
│                                 ┌───────────┐               │
│                                 │ learning  │               │
│                                 └─────┬─────┘               │
│                      ┌───────────────┼───────────────┐     │
│                      │ 正确率 ≥ 80%   │ 正确率 < 80%   │     │
│                      ▼               ▼               │     │
│                ┌───────────┐  ┌─────────┐             │     │
│                │ mastered  │  │  weak   │             │     │
│                └─────┬─────┘  └────┬────┘             │     │
│                      │             │                   │     │
│                      │    重新练习改善 │                   │     │
│                      │      且保持   │                   │     │
│                      │   正确率≥80%  │                   │     │
│                      └─────→────────┘                   │     │
│                                                           │
│   回退场景：                                               │
│   mastered → weak : 长时间未复习 + 错题率上升               │
│   mastered → learning : 用户主动重新学习（重置进度）          │
│   any → locked : 管理员操作（极少，如内容下线）              │
│                                                           │
└─────────────────────────────────────────────────────────────┘
```

状态流转规则定义：

```typescript
interface NodeStatusTransition {
  from: NodeStatus;
  to: NodeStatus;
  condition: TransitionCondition;
  /** 是否需要用户确认 */
  requiresConfirmation: boolean;
  /** 触发的动画类型 */
  animation: 'light_up' | 'pulse' | 'shake' | 'fade' | 'celebration';
}

type TransitionCondition =
  | { type: 'prerequisite_met' }           // 前置节点全部达到 available 以上
  | { type: 'user_start' }                 // 用户点击开始学习
  | { type: 'mastery_threshold'; min: number } // 掌握度达到阈值
  | { type: 'accuracy_drop'; max: number }    // 正确率下降到阈值以下
  | { type: 'time_decay'; days: number }      // 超过N天未复习
  | { type: 'manual_reset' }                  // 用户手动重置
  | { type: 'admin_action' };                 // 管理员操作
```

## 4. API 接口设计

### 4.1 接口总览

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/learning-map/{subject}` | GET | 获取学科的完整学习地图 |
| `/api/v1/learning-map/{subject}/node/{nodeId}` | GET | 获取节点详情 |
| `/api/v1/learning-map/{subject}/node/{nodeId}/start` | POST | 开始学习某个节点 |
| `/api/v1/learning-map/{subject}/node/{nodeId}/progress` | PUT | 更新节点学习进度 |
| `/api/v1/learning-map/{subject}/node/{nodeId}/reset` | POST | 重置节点进度 |
| `/api/v1/learning-map/overview` | GET | 获取全学科概览缩略图数据 |
| `/api/v1/learning-map/{subject}/path` | GET | 获取推荐学习路径 |
| `/api/v1/learning-map/{subject}/weak-spots` | GET | 获取薄弱节点列表 |

```dart
/// 路径模式画布渲染器
class PathMapRenderBox extends RenderBox {
  final List<LearningMapNode> _nodes;
  final List<LearningMapEdge> _edges;
  final Map<String, Offset> _nodePositions;
  final LearningMapController _controller;
  final PathMapTheme _theme;

  /// 缓存的路径对象（避免每帧重建）
  final Map<String, Path> _edgePaths = {};

  PathMapRenderBox({
    required List<LearningMapNode> nodes,
    required List<LearningMapEdge> edges,
    required LearningMapController controller,
    required PathMapTheme theme,
  })  : _nodes = nodes,
        _edges = edges,
        _controller = controller,
        _theme = theme,
        _nodePositions = {} {
    _layoutNodes();
  }

  /// 自动布局算法 - 蛇形路径布局
  void _layoutNodes() {
    // 1. 按前置关系构建拓扑排序
    final sorted = _topologicalSort(_nodes);
    
    // 2. 蛇形布局：每行 N 个节点，到行尾后折返
    const nodesPerRow = 4;
    const horizontalSpacing = 120.0;
    const verticalSpacing = 100.0;
    
    bool leftToRight = true;
    
    for (int i = 0; i < sorted.length; i++) {
      final row = i ~/ nodesPerRow;
      final col = i % nodesPerRow;
      final actualCol = leftToRight ? col : (nodesPerRow - 1 - col);
      
      _nodePositions[sorted[i].nodeId] = Offset(
        actualCol * horizontalSpacing + 60,
        row * verticalSpacing + 60,
      );
      
      // 到行尾时翻转方向
      if (col == nodesPerRow - 1) {
        leftToRight = !leftToRight;
      }
    }
  }

  /// 拓扑排序（基于前置依赖）
  List<LearningMapNode> _topologicalSort(List<LearningMapNode> nodes) {
    final result = <LearningMapNode>[];
    final visited = <String>{};
    final visiting = <String>{};

    void visit(LearningMapNode node) {
      if (visited.contains(node.nodeId)) return;
      if (visiting.contains(node.nodeId)) return; // 环检测
      
      visiting.add(node.nodeId);
      
      for (final prereqId in node.prerequisites) {
        final prereq = nodes.firstWhere(
          (n) => n.nodeId == prereqId,
          orElse: () => null,
        );
        if (prereq != null) visit(prereq);
      }
      
      visiting.remove(node.nodeId);
      visited.add(node.nodeId);
      result.add(node);
    }

    for (final node in nodes) {
      visit(node);
    }
    
    return result;
  }

  @override
  void paint(PaintingContext context, Offset offset) {
    final canvas = context.canvas;
    
    // 1. 绘制背景装饰
    _drawBackground(canvas, offset);
    
    // 2. 绘制连线
    for (final edge in _edges) {
      _drawEdge(canvas, edge, offset);
    }
    
    // 3. 绘制节点
    for (final node in _nodes) {
      _drawNode(canvas, node, offset);
    }
    
    // 4. 绘制粒子特效（如果有）
    _drawParticles(canvas, offset);
  }

  void _drawEdge(Canvas canvas, LearningMapEdge edge, Offset offset) {
    final fromPos = _nodePositions[edge.fromNodeId];
    final toPos = _nodePositions[edge.toNodeId];
    if (fromPos == null || toPos == null) return;

    final fromNode = _nodes.firstWhere((n) => n.nodeId == edge.fromNodeId);
    final toNode = _nodes.firstWhere((n) => n.nodeId == edge.toNodeId);
    
    // 根据两端节点状态决定连线样式
    final edgeStyle = _getEdgeStyle(fromNode, toNode);
    
    final paint = Paint()
      ..color = edgeStyle.color
      ..strokeWidth = edgeStyle.width
      ..style = PaintingStyle.stroke;

    if (edgeStyle.dashed) {
      // 虚线
      paint.pathEffect = _createDashEffect(edgeStyle.dashPattern);
    }

    // 贝塞尔曲线路径（更自然）
    final path = Path();
    path.moveTo(fromPos.dx + offset.dx, fromPos.dy + offset.dy);
    
    final midY = (fromPos.dy + toPos.dy) / 2 + offset.dy;
    path.cubicTo(
      fromPos.dx + offset.dx, midY,
      toPos.dx + offset.dx, midY,
      toPos.dx + offset.dx, toPos.dy + offset.dy,
    );
    
    canvas.drawPath(path, paint);

    // 如果是当前学习路径，添加流光动画
    if (edgeStyle.isAnimated) {
      _drawFlowingLight(canvas, path, edge);
    }
  }

  EdgeRenderStyle _getEdgeStyle(
    LearningMapNode from,
    LearningMapNode to,
  ) {
    // 两端都已掌握 → 实线金色
    if (from.status == 'mastered' && to.status == 'mastered') {
      return EdgeRenderStyle(
        color: _theme.masteredEdgeColor,
        width: 3.0,
        dashed: false,
      );
    }
    // 源点已掌握，目标可学习 → 实线高亮+流光
    if (from.status == 'mastered' && 
        (to.status == 'available' || to.status == 'learning')) {
      return EdgeRenderStyle(
        color: _theme.activeEdgeColor,
        width: 3.0,
        dashed: false,
        isAnimated: true,
      );
    }
    // 其他情况 → 虚线灰色
    return EdgeRenderStyle(
      color: _theme.lockedEdgeColor,
      width: 2.0,
      dashed: true,
      dashPattern: [6, 4],
    );
  }

  void _drawNode(Canvas canvas, LearningMapNode node, Offset offset) {
    final pos = _nodePositions[node.nodeId];
    if (pos == null) return;
    
    final center = pos + offset;
    final radius = _getNodeRadius(node);
    
    // 外圈光晕（当前学习节点）
    if (node.status == 'learning') {
      _drawPulsingHalo(canvas, center, radius, _theme.activeGlowColor);
    }
    
    // 节点主体
    final nodePaint = Paint()
      ..color = _getNodeColor(node)
      ..style = PaintingStyle.fill;
    
    canvas.drawCircle(center, radius, nodePaint);
    
    // 边框
    final borderPaint = Paint()
      ..color = _getNodeBorderColor(node)
      ..strokeWidth = 2.5
      ..style = PaintingStyle.stroke;
    canvas.drawCircle(center, radius, borderPaint);
    
    // 内部图标/文字
    _drawNodeContent(canvas, center, radius, node);
    
    // 掌握度进度环（已开始学习的节点）
    if (node.mastery != null && node.mastery! > 0) {
      _drawMasteryRing(canvas, center, radius + 4, node.mastery!);
    }
    
    // 锁图标（locked 节点）
    if (node.status == 'locked') {
      _drawLockIcon(canvas, center, radius * 0.5);
    }
    
    // 星星奖励（已掌握节点）
    if (node.status == 'mastered' && node.rewards != null) {
      _drawStars(canvas, center, radius, node.rewards!.stars);
    }
  }

  void _drawMasteryRing(
    Canvas canvas,
    Offset center,
    double radius,
    int mastery,
  ) {
    final sweepAngle = (mastery / 100) * 2 * pi;
    
    // 背景环
    canvas.drawArc(
      Rect.fromCircle(center: center, radius: radius),
      0,
      2 * pi,
      false,
      Paint()
        ..color = _theme.masteryRingBackgroundColor
        ..style = PaintingStyle.stroke
        ..strokeWidth = 3,
    );
    
    // 进度环
    canvas.drawArc(
      Rect.fromCircle(center: center, radius: radius),
      -pi / 2, // 从顶部开始
      sweepAngle,
      false,
      Paint()
        ..color = _theme.masteryRingColor
        ..style = PaintingStyle.stroke
        ..strokeWidth = 3
        ..strokeCap = StrokeCap.round,
    );
  }

  @override
  bool hitTestSelf(Offset position) => true;

  @override
  void handleTapDown(TapDownDetails details) {
    // 检测点击了哪个节点
    final localPos = globalToLocal(details.globalPosition);
    
    for (final node in _nodes) {
      final nodePos = _nodePositions[node.nodeId];
      if (nodePos == null) continue;
      
      final distance = (localPos - nodePos).distance;
      final radius = _getNodeRadius(node);
      
      if (distance <= radius + 8) { // 8px 额外触摸区域
        _controller.onNodeTap(node.nodeId);
        return;
      }
    }
  }
}
```

### 5.4 技能树模式布局算法

```dart
/// 技能树层级布局（简化版 Reingold-Tilford 算法）
class SkillTreeLayout {
  final double nodeRadius;
  final double horizontalGap;
  final double verticalGap;

  SkillTreeLayout({
    this.nodeRadius = 32,
    this.horizontalGap = 80,
    this.verticalGap = 120,
  });

  Map<String, Offset> layout(List<LearningMapNode> nodes) {
    // 1. 构建树结构
    final tree = _buildTree(nodes);
    
    // 2. 计算每个子树的宽度
    _calculateSubtreeWidth(tree);
    
    // 3. 递归分配位置
    final positions = <String, Offset>{};
    _assignPositions(tree, 0, 0, positions);
    
    return positions;
  }

  _TreeNode _buildTree(List<LearningMapNode> nodes) {
    final nodeMap = {for (var n in nodes) n.nodeId: n};
    final childrenMap = <String, List<String>>{};
    
    _TreeNode? root;
    for (final node in nodes) {
      if (node.parentNodeId == null) {
        root = _TreeNode(node: node);
      } else {
        childrenMap.putIfAbsent(node.parentNodeId!, () => []).add(node.nodeId);
      }
    }
    
    if (root == null) {
      // 取 depth 最小的作为根
      root = _TreeNode(node: nodes.reduce(
        (a, b) => a.depth < b.depth ? a : b,
      ));
    }
    
    _attachChildren(root, childrenMap, nodeMap);
    return root;
  }

  double _calculateSubtreeWidth(_TreeNode node) {
    if (node.children.isEmpty) {
      node.subtreeWidth = nodeRadius * 2 + horizontalGap;
      return node.subtreeWidth!;
    }
    
    double totalWidth = 0;
    for (final child in node.children) {
      totalWidth += _calculateSubtreeWidth(child);
    }
    node.subtreeWidth = max(totalWidth, nodeRadius * 2 + horizontalGap);
    return node.subtreeWidth!;
  }

  void _assignPositions(
    _TreeNode node,
    double x,
    double y,
    Map<String, Offset> positions,
  ) {
    positions[node.node.nodeId] = Offset(x, y);
    
    if (node.children.isEmpty) return;
    
    double childX = x - (node.subtreeWidth! / 2);
    for (final child in node.children) {
      final childWidth = child.subtreeWidth!;
      _assignPositions(
        child,
        childX + childWidth / 2,
        y + verticalGap,
        positions,
      );
      childX += childWidth;
    }
  }
}

class _TreeNode {
  final LearningMapNode node;
  List<_TreeNode> children = [];
  double? subtreeWidth;
  
  _TreeNode({required this.node});
  String get nodeId => node.nodeId;
}
```

```dart
/// 星座模式：将节点分布在圆形区域内，模拟星空
class ConstellationLayout {
  final Size canvasSize;
  final Random _random = Random(42); // 固定种子保证一致性
  
  ConstellationLayout({required this.canvasSize});
  
  Map<String, Offset> layout(List<LearningMapNode> nodes) {
    final positions = <String, Offset>{};
    final center = Offset(canvasSize.width / 2, canvasSize.height / 2);
    final maxRadius = min(canvasSize.width, canvasSize.height) / 2 - 40;
    
    // 按章节分组（每个章节形成一个"星座"）
    final groups = <String, List<LearningMapNode>>{};
    for (final node in nodes) {
      final groupKey = node.parentNodeId ?? node.nodeId;
      groups.putIfAbsent(groupKey, () => []).add(node);
    }
    
    // 为每个组分配一个扇区
    final groupCount = groups.length;
    final sectorAngle = 2 * pi / groupCount;
    int groupIndex = 0;
    
    for (final entry in groups.entries) {
      final groupNodes = entry.value;
      final baseAngle = groupIndex * sectorAngle - pi / 2;
      final groupCenter = Offset(
        center.dx + cos(baseAngle) * maxRadius * 0.5,
        center.dy + sin(baseAngle) * maxRadius * 0.5,
      );
      
      // 在组中心附近散布节点
      for (int i = 0; i < groupNodes.length; i++) {
        final angle = baseAngle + (i / groupNodes.length) * sectorAngle * 0.8;
        final radius = 30.0 + _random.nextDouble() * 60;
        positions[groupNodes[i].nodeId] = Offset(
          groupCenter.dx + cos(angle) * radius,
          groupCenter.dy + sin(angle) * radius,
        );
      }
      groupIndex++;
    }
    
    return positions;
  }
}
```

## 8. 性能优化策略

### 8.1 渲染性能

| 策略 | 说明 |
|------|------|
| Canvas 复用 | 使用单一 CustomPaint + RenderBox，避免大量 Widget 嵌套 |
| 视口裁剪 | 仅绘制可见区域内的节点和连线（culling） |

| 图层分离 | 背景装饰 / 连线 / 节点 / 覆盖层 分层绘制，减少重绘范围 |

### 8.2 数据优化

```dart
class LearningMapCacheManager {
  /// 地图数据本地缓存有效期
  static const _cacheTTL = Duration(hours: 2);
  
  /// 增量更新：只请求状态变化的节点
  Future<LearningMapData> refreshMap(String subject) async {
    // 获取本地缓存的版本号
    final localVersion = await _localCache.getMapVersion(subject);
    
    // 请求增量更新
    final response = await _api.deltaUpdate(
      subject: subject,
      sinceVersion: localVersion,
    );
    
    if (response.hasChanges) {
      // 合并增量变化到本地数据
      final localData = await _localCache.getMap(subject);
      final updated = _mergeDelta(localData, response.changes);
      await _localCache.saveMap(subject, updated);
      return updated;
    }
    
    return localData!; // 无变化，返回缓存
  }
  
  LearningMapData _mergeDelta(
    LearningMapData base,
    List<NodeDelta> deltas,
  ) {
    final nodeMap = {for (var n in base.nodes) n.nodeId: n};
    
    for (final delta in deltas) {
      switch (delta.type) {
        case DeltaType.statusChanged:
          final node = nodeMap[delta.nodeId];
          if (node != null) {
            nodeMap[delta.nodeId] = node.copyWith(
              status: delta.newStatus!,
              mastery: delta.newMastery,
              lastStudiedAt: delta.timestamp,
            );
          }
          break;
        case DeltaType.nodeAdded:
          nodeMap[delta.node!.nodeId] = delta.node!;
          break;
        case DeltaType.nodeRemoved:
          nodeMap.remove(delta.nodeId);
          break;
      }
    }
    
    return base.copyWith(nodes: nodeMap.values.toList());
  }
}
```

### 9.3 并发安全

```dart
/// 多个页面同时更新节点进度时的并发控制
class MapUpdateQueue {
  final _updateLock = Mutex();
  final _pendingUpdates = <String, NodeProgressUpdate>{};
  
  /// 入队进度更新（相同节点的更新合并取最新）
  Future<void> enqueue(NodeProgressUpdate update) async {
    _pendingUpdates[update.nodeId] = update;
    
    // 延迟批量发送（debounce 500ms）
    _debounceTimer?.cancel();
    _debounceTimer = Timer(const Duration(milliseconds: 500), () {
      _flush();
    });
  }
  
  Future<void> _flush() async {
    if (_pendingUpdates.isEmpty) return;
    
    final lock = await _updateLock.acquire();
    try {
      final updates = _pendingUpdates.values.toList();
      _pendingUpdates.clear();
      
      // 批量发送到服务端
      await _repository.batchUpdateProgress(updates);
    } catch (e) {
      // 失败放回队列
      for (final update in updates) {
        _pendingUpdates[update.nodeId] = update;
      }
    } finally {
      lock.release();
    }
  }
}
```
