> 版本：v1.0  
> 创建日期：2026-06-10  
> 模块定位：学习数据分析层 · 专注力量化与时段优化服务

## 1. 模块概述

### 1.1 功能定位

本引擎负责对用户学习过程中的专注力水平进行实时量化分析，识别每个用户的高效学习时段，为学习任务智能调度、学习计划优化、番茄钟参数个性化等上游服务提供数据支撑。

### 1.2 核心价值

| 价值维度 | 说明 |
|---------|------|
| 个性化学习时间推荐 | 基于历史专注力数据，推荐每天最佳学习时段 |
| 专注力异常预警 | 当用户专注力持续下降时，主动建议休息或切换任务 |
| 学习效率归因 | 将学习成果（正确率、掌握度提升）与专注力水平关联分析 |
| 计划调度依据 | 为每日任务智能生成服务提供时段偏好数据 |
| 家长报告数据源 | 为家长端学情报告提供专注力维度分析 |

## 2. 数据结构定义

### 2.1 专注力快照记录 (focus_snapshot)

每次学习会话中按固定间隔（默认 5 分钟）或关键事件触发时产生一条快照。

```sql
CREATE TABLE focus_snapshot (
    id              BIGINT          NOT NULL COMMENT '主键ID',
    user_id         BIGINT          NOT NULL COMMENT '用户ID',
    session_id      VARCHAR(64)     NOT NULL COMMENT '学习会话ID',
    subject_code    VARCHAR(16)     NOT NULL COMMENT '学科编码',
    snapshot_time   DATETIME        NOT NULL COMMENT '快照时间点',
    session_elapsed INT             NOT NULL COMMENT '会话已持续时间（秒）',
    
    -- 专注力指标
    focus_score     TINYINT         NOT NULL COMMENT '专注力评分 0-100',
    focus_level     TINYINT         NOT NULL COMMENT '专注力等级: 1=高度专注 2=中等专注 3=轻度分心 4=明显分心',
    
    -- 行为信号
    interaction_count    INT        NOT NULL DEFAULT 0 COMMENT '采集窗口内交互次数',
    avg_response_time_ms INT        NOT NULL DEFAULT 0 COMMENT '平均响应时间（毫秒）',
    idle_seconds         INT        NOT NULL DEFAULT 0 COMMENT '空闲时长（秒）',
    tab_switch_count     INT        NOT NULL DEFAULT 0 COMMENT '应用切换次数',
    
    -- 答题信号（仅答题场景有值）
    question_count       INT        NOT NULL DEFAULT 0 COMMENT '窗口内答题数',
    correct_rate         DECIMAL(5,4) DEFAULT NULL COMMENT '窗口内正确率',
    avg_think_time_ms    INT        DEFAULT NULL COMMENT '平均思考时间（毫秒）',
    revision_count       INT        NOT NULL DEFAULT 0 COMMENT '修改答案次数',
    
    -- 上下文
    day_of_week          TINYINT    NOT NULL COMMENT '星期几 1-7',
    hour_of_day          TINYINT    NOT NULL COMMENT '小时 0-23',
    is_holiday           TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否节假日',
    
    -- 元数据
    created_at           DATETIME   NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    PRIMARY KEY (id),
    INDEX idx_user_time (user_id, snapshot_time),
    INDEX idx_user_subject_time (user_id, subject_code, snapshot_time),
    INDEX idx_session (session_id, snapshot_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习专注力快照记录';
```

## 4. 核心算法设计

### 4.1 专注力实时评分算法

专注力评分采用多信号加权融合模型，每 5 分钟计算一次。

```
focusScore = w1 × interactionScore 
           + w2 × responseTimeScore 
           + w3 × idleRatioScore 
           + w4 × answerAccuracyScore
           + w5 × continuityScore
```

**权重配置：**

| 信号 | 权重 | 说明 |
|------|------|------|
| interactionScore | 0.25 | 交互频率评分：窗口内有效交互次数与期望值的比值 |
| responseTimeScore | 0.20 | 响应时间评分：响应时间越接近合理范围分越高 |
| idleRatioScore | 0.25 | 空闲比例评分：空闲时间占比越低分越高 |
| answerAccuracyScore | 0.15 | 答题正确率评分（仅答题场景） |
| continuityScore | 0.15 | 连续性评分：未中断学习的持续时间贡献 |

**各子评分计算方式：**

```java
/**
 * 专注力实时评分计算器
 */
@Component
public class FocusScoreCalculator {
    
    // 默认权重（可通过配置中心动态调整）
    private static final double W_INTERACTION = 0.25;
    private static final double W_RESPONSE_TIME = 0.20;
    private static final double W_IDLE_RATIO = 0.25;
    private static final double W_ACCURACY = 0.15;
    private static final double W_CONTINUITY = 0.15;
    
    // 期望交互频率（次/5分钟窗口），按学段差异化
    private static final Map<String, Integer> EXPECTED_INTERACTIONS = Map.of(
        "PRIMARY", 8,    // 小学生操作频率高
        "JUNIOR", 6,     // 初中
        "SENIOR", 4,     // 高中思考时间更长
        "KINDERGARTEN", 12 // 幼儿互动最频繁
    );
    
    public FocusScoreResult calculate(FocusCalculationInput input) {
        double interactionScore = calcInteractionScore(input);
        double responseTimeScore = calcResponseTimeScore(input);
        double idleRatioScore = calcIdleRatioScore(input);
        double accuracyScore = calcAccuracyScore(input);
        double continuityScore = calcContinuityScore(input);
        
        // 如果非答题场景，重新分配权重
        double[] weights = redistributeWeights(!input.hasAnswerData());
        
        double rawScore = weights[0] * interactionScore
                        + weights[1] * responseTimeScore
                        + weights[2] * idleRatioScore
                        + weights[3] * accuracyScore
                        + weights[4] * continuityScore;
        
        // 应用衰减因子：会话时间越长，基线越低
        double decayFactor = calcDecayFactor(input.getSessionElapsedSeconds());
        double finalScore = rawScore * decayFactor;
        
        // 钳位到 0-100
        finalScore = Math.max(0, Math.min(100, finalScore));
        
        return FocusScoreResult.builder()
                .focusScore((int) Math.round(finalScore))
                .focusLevel(FocusLevel.fromScore((int) finalScore))
                .interactionScore(interactionScore)
                .responseTimeScore(responseTimeScore)
                .idleRatioScore(idleRatioScore)
                .accuracyScore(accuracyScore)
                .continuityScore(continuityScore)
                .decayFactor(decayFactor)
                .build();
    }
    
    /**
     * 会话时间衰减因子
     * 30分钟内不衰减，30-60分钟轻微衰减，超过60分钟加速衰减
     */
    private double calcDecayFactor(int elapsedSeconds) {
        int minutes = elapsedSeconds / 60;
        if (minutes <= 30) return 1.0;
        if (minutes <= 60) return 1.0 - (minutes - 30) * 0.003;  // 30-60分钟衰减0.3%/分钟
        return 0.91 - (minutes - 60) * 0.005;  // 60分钟后衰减0.5%/分钟
    }
    
    /**
     * 空闲比例评分
     * 空闲比例 = idleSeconds / windowSeconds
     * 评分 = 100 × (1 - idleRatio^0.5)  -- 使用平方根使轻微空闲影响减小
     */
    private double calcIdleRatioScore(FocusCalculationInput input) {
        double idleRatio = (double) input.getIdleSeconds() / input.getWindowSeconds();
        return 100 * (1 - Math.pow(idleRatio, 0.5));
    }
    
    /**
     * 响应时间评分
     * 最佳响应时间范围：3-15秒（思考型交互）
     * 过快（<1秒）可能是随机点击，过慢（>60秒）可能是走神
     */
    private double calcResponseTimeScore(FocusCalculationInput input) {
        if (input.getInteractionCount() == 0) return 20.0;
        
        double avgMs = input.getAvgResponseTimeMs();
        double seconds = avgMs / 1000.0;
        
        if (seconds >= 3 && seconds <= 15) return 100.0;
        if (seconds >= 1 && seconds < 3) return 60.0 + (seconds - 1) / 2 * 40;
        if (seconds > 15 && seconds <= 60) return 100 - (seconds - 15) / 45 * 50;
        if (seconds < 1) return 30.0;  // 太快，疑似随机操作
        return 20.0;  // 超过60秒
    }
    
    /**
     * 非答题场景权重重新分配
     */
    private double[] redistributeWeights(boolean noAnswerData) {
        if (!noAnswerData) {
            return new double[]{W_INTERACTION, W_RESPONSE_TIME, W_IDLE_RATIO, W_ACCURACY, W_CONTINUITY};
        }
        // 无答题数据时，将 W_ACCURACY 的权重分给 idle 和 continuity
        return new double[]{0.28, 0.22, 0.30, 0.0, 0.20};
    }
}
```

### 4.2 高效时段识别算法

采用**加权指数移动平均 (WEMA)** 结合**时段内方差分析**的方法。

**核心思路：**
1. 收集用户最近 N 天（默认 30 天）的 `focus_snapshot` 数据
2. 按小时聚合，计算每个小时的加权平均专注力评分（越近期的数据权重越高）
3. 识别连续高专注力时段（相邻小时均高于阈值）
4. 结合学科维度细化推荐

```java
/**
 * 高效学习时段识别引擎
 */
@Component
public class FocusTimeSlotIdentifier {
    
    private static final int ANALYSIS_WINDOW_DAYS = 30;
    private static final int HIGH_FOCUS_THRESHOLD = 65;  // 高效专注力阈值
    private static final int MIN_SAMPLE_DAYS = 7;        // 最少样本天数
    
    @Autowired
    private FocusSnapshotRepository snapshotRepository;
    @Autowired
    private FocusTimePreferenceRepository preferenceRepository;
    @Autowired
    private ConfigService configService;
    
    /**
     * 计算用户时段偏好模型
     * 每日凌晨定时任务调用
     */
    @Scheduled(cron = "0 30 2 * * *")  // 每天凌晨 2:30 执行
    public void computeUserTimePreference() {
        List<Long> activeUserIds = getActiveUsersInLastNDays(7);
        
        for (Long userId : activeUserIds) {
            try {
                computeAndSavePreference(userId);
            } catch (Exception e) {
                log.error("计算用户时段偏好失败, userId={}", userId, e);
            }
        }
    }
    
    public UserFocusTimePreference computeAndSavePreference(Long userId) {
        // 1. 获取原始数据
        LocalDate endDate = LocalDate.now().minusDays(1);
        LocalDate startDate = endDate.minusDays(ANALYSIS_WINDOW_DAYS - 1);
        
        List<FocusSnapshot> snapshots = snapshotRepository
            .findByUserIdAndSnapshotTimeBetween(userId, 
                startDate.atStartOfDay(), 
                endDate.atTime(23, 59, 59));
        
        // 2. 数据充分性检查
        long distinctDays = snapshots.stream()
            .map(s -> s.getSnapshotTime().toLocalDate())
            .distinct().count();
        
        boolean isColdStart = distinctDays < MIN_SAMPLE_DAYS;
        
        // 3. 计算小时维度评分（WEMA）
        Map<Integer, Double> hourScores = computeHourScoresWEMA(snapshots);
        
        // 4. 计算星期维度评分
        Map<Integer, Double> weekdayScores = computeWeekdayScores(snapshots);
        
        // 5. 识别连续高效时段
        List<TimeSlotRecommendation> bestSlots = identifyContinuousSlots(hourScores);
        
        // 6. 计算置信度
        double confidence = calculateConfidence(distinctDays, snapshots.size());
        
        // 7. 持久化
        UserFocusTimePreference preference = buildPreferenceEntity(
            userId, hourScores, weekdayScores, bestSlots, 
            confidence, isColdStart, distinctDays
        );
        preferenceRepository.save(preference);
        
        return preference;
    }
    
    /**
     * 加权指数移动平均计算小时评分
     * 越近期的数据权重越高，衰减系数 α=0.15
     */
    private Map<Integer, Double> computeHourScoresWEMA(List<FocusSnapshot> snapshots) {
        // 按小时+日期分组
        Map<Integer, List<FocusSnapshot>> byHour = snapshots.stream()
            .collect(Collectors.groupingBy(s -> s.getSnapshotTime().getHour()));
        
        Map<Integer, Double> hourScores = new HashMap<>();
        double alpha = 0.15;  // EMA 衰减系数
        
        for (Map.Entry<Integer, List<FocusSnapshot>> entry : byHour.entrySet()) {
            int hour = entry.getKey();
            // 按日期排序（从旧到新）
            List<FocusSnapshot> hourSnapshots = entry.getValue().stream()
                .sorted(Comparator.comparing(FocusSnapshot::getSnapshotTime))
                .toList();
            
            // 按日期聚合为日均值，再计算 WEMA
            Map<LocalDate, Double> dailyAvg = hourSnapshots.stream()
                .collect(Collectors.groupingBy(
                    s -> s.getSnapshotTime().toLocalDate(),
                    Collectors.averagingDouble(FocusSnapshot::getFocusScore)
                ));
            
            List<Double> sortedAvg = dailyAvg.entrySet().stream()
                .sorted(Map.Entry.comparingByKey())
                .map(Map.Entry::getValue)
                .toList();
            
            // WEMA 计算
            double ema = sortedAvg.get(0);
            for (int i = 1; i < sortedAvg.size(); i++) {
                ema = alpha * sortedAvg.get(i) + (1 - alpha) * ema;
            }
            
            hourScores.put(hour, ema);
        }
        
        return hourScores;
    }
    
    /**
     * 识别连续高效时段
     * 将连续高于阈值的小时合并为时段，按综合评分排序
     */
    private List<TimeSlotRecommendation> identifyContinuousSlots(
            Map<Integer, Double> hourScores) {
        
        int threshold = configService.getInt(
            "focus.slot.high_threshold", HIGH_FOCUS_THRESHOLD);
        
        // 标记每个小时是否为高效
        boolean[] isHigh = new boolean[24];
        for (int h = 0; h < 24; h++) {
            isHigh[h] = hourScores.getOrDefault(h, 0.0) >= threshold;
        }
        
        // 识别连续时段
        List<TimeSlotRecommendation> slots = new ArrayList<>();
        int start = -1;
        
        for (int h = 0; h <= 24; h++) {  // 24 为哨兵，处理末尾时段
            boolean high = (h < 24) && isHigh[h];
            if (high && start == -1) {
                start = h;
            } else if (!high && start != -1) {
                // 结束一个连续时段
                double avgScore = IntStream.range(start, h)
                    .mapToObj(hh -> hourScores.getOrDefault(hh, 0.0))
                    .mapToDouble(Double::doubleValue)
                    .average().orElse(0);
                
                double stability = calcStability(hourScores, start, h);
                
                slots.add(TimeSlotRecommendation.builder()
                    .startHour(start)
                    .endHour(h)
                    .avgFocusScore(avgScore)
                    .stability(stability)
                    .compositeScore(avgScore * 0.7 + stability * 0.3)  // 综合评分
                    .build());
                
                start = -1;
            }
        }
        
        // 按综合评分降序排序，取 Top 3
        return slots.stream()
            .sorted(Comparator.comparing(TimeSlotRecommendation::getCompositeScore).reversed())
            .limit(3)
            .collect(Collectors.toList());
    }
    
    /**
     * 计算时段内专注力稳定性（方差越小越稳定）
     * 返回 0-100 的稳定性评分
     */
    private double calcStability(Map<Integer, Double> hourScores, int start, int end) {
        if (end - start <= 1) return 100.0;
        
        double mean = IntStream.range(start, end)
            .mapToObj(h -> hourScores.getOrDefault(h, 0.0))
            .mapToDouble(Double::doubleValue)
            .average().orElse(0);
        
        double variance = IntStream.range(start, end)
            .mapToObj(h -> hourScores.getOrDefault(h, 0.0))
            .mapToDouble(v -> Math.pow(v - mean, 2))
            .average().orElse(0);
        
        // 方差 -> 稳定性评分：方差 0 → 100分，方差 >= 400 → 0分
        return Math.max(0, 100 - variance / 4);
    }
    
    /**
     * 计算模型置信度
     * 基于样本天数和数据量
     */
    private double calculateConfidence(long sampleDays, int totalSnapshots) {
        // 天数贡献（7天为满分基础，30天为满分）
        double dayScore = Math.min(1.0, sampleDays / 30.0);
        
        // 数据量贡献（每天至少 10 个快照为有效天）
        double densityScore = Math.min(1.0, 
            (double) totalSnapshots / (sampleDays * 10));
        
        return dayScore * 0.7 + densityScore * 0.3;
    }
}
```

### 4.4 专注力-效率关联分析算法

采用**皮尔逊相关系数**衡量专注力与学习效率的线性关联。

```java
/**
 * 专注力-效率关联分析
 */
@Component
public class FocusEfficiencyCorrelationAnalyzer {
    
    public CorrelationResult analyze(Long userId, String subjectCode, int days) {
        // 1. 获取关联数据
        List<FocusEfficiencyCorrelation> data = correlationRepository
            .findByUserAndPeriod(userId, subjectCode, days);
        
        if (data.size() < 5) {
            return CorrelationResult.insufficient();
        }
        
        // 2. 提取专注力评分和效率评分两个序列
        double[] focusScores = data.stream()
            .mapToDouble(d -> d.getAvgFocusScore().doubleValue())
            .toArray();
        double[] efficiencyScores = data.stream()
            .mapToDouble(d -> d.getEfficiencyScore().doubleValue())
            .toArray();
        
        // 3. 计算皮尔逊相关系数
        double correlation = pearsonCorrelation(focusScores, efficiencyScores);
        
        // 4. 识别专注力阈值（低于此值效率显著下降）
        double threshold = findFocusThreshold(focusScores, efficiencyScores);
        
        // 5. 生成洞察
        String insight = generateInsight(correlation, threshold, subjectCode);
        
        return CorrelationResult.builder()
            .correlationCoefficient(correlation)
            .focusThreshold(threshold)
            .insight(insight)
            .sampleSize(data.size())
            .build();
    }
    
    /**
     * 查找效率显著下降的专注力阈值
     * 使用分段均值比较法
     */
    private double findFocusThreshold(double[] focus, double[] efficiency) {
        // 按专注力排序
        List<double[]> pairs = new ArrayList<>();
        for (int i = 0; i < focus.length; i++) {
            pairs.add(new double[]{focus[i], efficiency[i]});
        }
        pairs.sort(Comparator.comparingDouble(a -> a[0]));
        
        // 尝试每个可能的分割点，找到使两组均值差异最大的点
        double maxDiff = 0;
        double bestThreshold = 50;
        
        for (int i = 2; i < pairs.size() - 2; i++) {
            double lowAvg = mean(pairs, 0, i, 1);
            double highAvg = mean(pairs, i, pairs.size(), 1);
            double diff = highAvg - lowAvg;
            
            if (diff > maxDiff) {
                maxDiff = diff;
                bestThreshold = (pairs.get(i - 1)[0] + pairs.get(i)[0]) / 2;
            }
        }
        
        return bestThreshold;
    }
}
```

### 6.1 专注力事件处理服务

```java
@Service
@Slf4j
public class FocusEventProcessor {
    
    @Autowired
    private FocusScoreCalculator scoreCalculator;
    @Autowired
    private FocusSnapshotRepository snapshotRepository;
    @Autowired
    private FocusDailySummaryRepository dailySummaryRepository;
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    // 内存中的会话窗口缓存（5分钟窗口）
    private final LoadingCache<String, FocusWindow> windowCache = Caffeine.newBuilder()
        .expireAfterWrite(6, TimeUnit.MINUTES)
        .build(this::createNewWindow);
    
    /**
     * 处理专注力原始事件
     */
    @Async("focusEventExecutor")
    public void processEvent(FocusRawEvent event) {
        String windowKey = event.getSessionId();
        FocusWindow window = windowCache.get(windowKey);
        
        // 累积事件到窗口
        window.accumulate(event);
        
        // 检查窗口是否到期（5分钟）
        if (window.isExpired()) {
            finalizeWindow(window);
            windowCache.invalidate(windowKey);
        }
    }
    
    /**
     * 窗口到期时计算专注力快照
     */
    private void finalizeWindow(FocusWindow window) {
        FocusCalculationInput input = window.toCalculationInput();
        FocusScoreResult result = scoreCalculator.calculate(input);
        
        // 持久化快照
        FocusSnapshot snapshot = FocusSnapshot.builder()
            .userId(window.getUserId())
            .sessionId(window.getSessionId())
            .subjectCode(window.getSubjectCode())
            .snapshotTime(window.getWindowEndTime())
            .sessionElapsed(window.getSessionElapsed())
            .focusScore(result.getFocusScore())
            .focusLevel(result.getFocusLevel().getCode())
            .interactionCount(window.getInteractionCount())
            .avgResponseTimeMs(window.getAvgResponseTimeMs())
            .idleSeconds(window.getIdleSeconds())
            .questionCount(window.getQuestionCount())
            .correctRate(window.getCorrectRate())
            .dayOfWeek(window.getWindowEndTime().getDayOfWeek().getValue())
            .hourOfDay(window.getWindowEndTime().getHour())
            .build();
        
        snapshotRepository.save(snapshot);
        
        // 发布专注力变化事件（供其他服务订阅）
        eventPublisher.publishEvent(new FocusScoreUpdatedEvent(
            window.getUserId(), 
            result.getFocusScore(), 
            result.getFocusLevel(),
            window.getSessionId()
        ));
        
        // 检查是否需要实时提醒
        checkAndNotifyFocusAlert(window.getUserId(), result, window);
    }
    
    /**
     * 专注力异常提醒
     */
    private void checkAndNotifyFocusAlert(Long userId, FocusScoreResult result, 
            FocusWindow window) {
        // 连续3个窗口低于40分，推送休息提醒
        if (result.getFocusScore() < 40 && window.getConsecutiveLowWindows() >= 3) {
            eventPublisher.publishEvent(new FocusAlertEvent(
                userId, 
                "SUSTAINED_LOW_FOCUS",
                "您已持续一段时间注意力不集中，建议休息5-10分钟后再继续学习"
            ));
        }
        
        // 长时间学习超过45分钟且专注力下降趋势
        if (window.getSessionElapsed() > 45 * 60 
            && result.getFocusScore() < 50
            && window.getFocusTrend() == FocusTrend.DECLINING) {
            eventPublisher.publishEvent(new FocusAlertEvent(
                userId,
                "FATIGUE_DETECTED",
```

### 6.2 学习会话结算服务

```java
@Service
@Slf4j
public class FocusSessionSettlementService {
    
    @Autowired
    private FocusSnapshotRepository snapshotRepository;
    @Autowired
    private FocusDailySummaryRepository dailySummaryRepository;
    @Autowired
    private FocusEfficiencyCorrelationRepository correlationRepository;
    @Autowired
    private FocusTimeSlotIdentifier timeSlotIdentifier;
    
    /**
     * 学习会话结束时调用，进行专注力结算
     */
    @Transactional
    public void settleSession(FocusSessionSettleRequest request) {
        Long userId = request.getUserId();
        String sessionId = request.getSessionId();
        
        // 1. 获取本次会话的所有快照
        List<FocusSnapshot> snapshots = snapshotRepository
            .findBySessionIdOrderBySnapshotTime(sessionId);
        
        if (snapshots.isEmpty()) {
            log.warn("会话无专注力快照, sessionId={}", sessionId);
            return;
        }
        
        // 2. 计算会话级别的专注力统计
        double avgFocus = snapshots.stream()
            .mapToInt(FocusSnapshot::getFocusScore)
            .average().orElse(0);
        
        int maxContinuous = calculateMaxContinuousFocus(snapshots);
        
        // 3. 更新当日日报
        updateDailySummary(userId, request, snapshots, avgFocus, maxContinuous);
        
        // 4. 生成专注力-效率关联记录
        generateEfficiencyCorrelation(userId, request, snapshots);
        
        // 5. 如果当天有足够新数据，异步触发时段模型更新
        if (shouldTriggerModelUpdate(userId)) {
            CompletableFuture.runAsync(() -> 
                timeSlotIdentifier.computeAndSavePreference(userId)
            );
        }
    }
    
    /**
     * 更新当日专注力日报
     * 使用 INSERT ON DUPLICATE KEY UPDATE 保证幂等
     */
    private void updateDailySummary(Long userId, FocusSessionSettleRequest request,
            List<FocusSnapshot> snapshots, double avgFocus, int maxContinuous) {
        
        LocalDate today = request.getSessionEndTime().toLocalDate();
        
        // 聚合当日所有会话的快照
        List<FocusSnapshot> todayAllSnapshots = snapshotRepository
            .findByUserIdAndSnapshotTimeBetween(userId,
                today.atStartOfDay(), today.atTime(23, 59, 59));
        
        FocusDailySummary summary = FocusDailySummary.builder()
            .userId(userId)
            .summaryDate(today)
            .totalStudySeconds(calculateTotalStudy(todayAllSnapshots))
            .effectiveStudySeconds(calculateEffectiveStudy(todayAllSnapshots))
            .avgFocusScore(BigDecimal.valueOf(avgFocus))
            .maxFocusScore(findMaxFocus(todayAllSnapshots))
            .minFocusScore(findMinFocus(todayAllSnapshots))
            .peakFocusHour(findPeakHour(todayAllSnapshots))
            .highFocusSeconds(calculateLevelSeconds(todayAllSnapshots, FocusLevel.HIGHLY_FOCUSED))
            .mediumFocusSeconds(calculateLevelSeconds(todayAllSnapshots, FocusLevel.MODERATELY_FOCUSED))
            .lightDistractSeconds(calculateLevelSeconds(todayAllSnapshots, FocusLevel.LIGHTLY_DISTRACTED))
            .heavyDistractSeconds(calculateLevelSeconds(todayAllSnapshots, FocusLevel.HEAVILY_DISTRACTED))
            .maxContinuousFocusSeconds(maxContinuous)
            .snapshotCount(todayAllSnapshots.size())
            .build();
        
        dailySummaryRepository.upsert(summary);
    }
}
```

```java
@Component
public class FocusServiceFallback {
    
    /**
     * 专注力评分计算降级
     * 当评分算法异常时，使用简化评分
     */
    public FocusScoreResult fallbackScore(FocusCalculationInput input) {
        // 简化评分：仅基于交互频率
        int simplifiedScore = Math.min(100, 
            input.getInteractionCount() * 12);
        
        return FocusScoreResult.builder()
            .focusScore(simplifiedScore)
            .focusLevel(FocusLevel.fromScore(simplifiedScore))
            .isDegraded(true)
            .build();
    }
    
    /**

     * 当个性化模型不可用时，返回通用推荐

    public TimeSlotRecommendationResponse fallbackTimeslots(

        return coldStartStrategy.getColdStartPreference(
            profile.getUserId(), profile).toResponse();
    }
```

## 9. 安全与隐私

### 9.1 数据访问控制

- 专注力数据仅用户本人和绑定的家长账号可查询
- 教师端仅可查看班级聚合数据，不可查看个体专注力详情
- 管理后台查看个体数据需审计日志记录

### 9.2 数据脱敏规则

- 专注力趋势分析对外暴露时，不展示具体时间点的精确评分
- 时段推荐 API 返回时段范围，不暴露用户具体的学习时间分布
- 数据导出时，专注力评分按等级（而非精确数值）导出

### 9.3 合规要求

- 专注力分析功能需在用户协议中明确告知
- 幼儿/小学低年级用户的专注力数据不用于广告推荐
- 用户可关闭专注力分析功能，关闭后仅收集基础学习时长数据
- 专注力数据保留 180 天，超期自动归档
