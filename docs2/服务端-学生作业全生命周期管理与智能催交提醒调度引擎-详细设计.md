# 服务端-学生作业全生命周期管理与智能催交提醒调度引擎

> **文档版本：** v1.0  
> **最后更新：** 2026-06-20  
> **所属模块：** 学习服务 → 作业管理  
> **优先级：** P1（V1.0 阶段）  
> **依赖模块：** 教师班级管理与作业发布服务、消息推送服务、学习规划服务、学情分析服务

---

## 1. 模块概述

### 1.1 功能定位

本模块是学生端作业管理的**服务端核心引擎**，负责从教师发布作业、学生接收作业、作业完成追踪、智能催交提醒，直到作业提交确认与完成度分析的全生命周期管理。

与已有模块的边界划分：

| 已有模块 | 覆盖范围 | 与本模块关系 |
| --- | --- | --- |
| 服务端-教师班级管理与作业发布服务 | 教师创建、编辑、发布、批改作业 | 上游：教师发布后触发本模块 |
| 客户端-学生班级与作业提交页面 | 学生端作业列表、提交交互UI | 下游：本模块提供数据接口 |
| 服务端-多源学习任务统一调度与优先级仲裁引擎 | 通用学习任务的优先级排序 | 协作：作业作为任务源之一接入 |
| 服务端-每日任务智能生成与学习计划执行追踪服务 | 学习计划和每日任务追踪 | 协作：作业任务纳入每日任务 |

### 1.2 核心能力

1. **作业生命周期状态机**：管理从"已发布"到"已完成"的完整状态流转
2. **智能催交调度**：基于截止时间、学生行为模式、学科负荷动态生成催交提醒
3. **作业负荷均衡分析**：跨学科汇总学生作业量，检测过载/冲突
4. **作业完成度统计**：个人、班级、学科维度的作业完成率与质量分析
5. **家长通知联动**：作业状态变更时按策略通知家长
6. **作业-学习计划联动**：将作业自动纳入学生学习计划与每日任务

## 3. 作业状态机设计

### 3.1 状态定义与流转图

```
                    ┌──────────────┐
                    │   ASSIGNED   │  教师发布，学生未查看
                    └──────┬───────┘
                           │ 学生查看作业
                           ▼
                    ┌──────────────┐
                    │    VIEWED    │  学生已查看，未开始作答
                    └──────┬───────┘
                           │ 学生开始作答（打开第一题）
                           ▼
                    ┌──────────────┐
     ┌──────────────│ IN_PROGRESS  │  学生正在作答
     │              └──────┬───────┘
     │                     │ 学生提交全部/部分
     │                     ▼
     │              ┌──────────────┐
     │              │  SUBMITTED   │  学生已提交（待批改）
     │              └──────┬───────┘
     │                     │ 教师批改完成
     │                     ▼
     │              ┌──────────────┐
     │              │   GRADED     │  教师已批改，有成绩/评语
     │              └──────────────┘
     │
     │ 截止时间已过，未提交
     ▼
┌──────────────┐
│   OVERDUE    │  逾期未交
└──────┬───────┘
       │ 学生补交 / 教师标记免交
       ▼
┌──────────────┐
│ LATE_SUBMIT  │  迟交（仍可提交）
└──────┬───────┘
       │ 学生提交
       ▼
┌──────────────┐
│  SUBMITTED   │  走正常批改流程
└──────────────┘

特殊终态：
┌──────────────┐
│  EXEMPTED    │  教师标记免交（请假等）
└──────────────┘
┌──────────────┐
│  WITHDRAWN   │  教师撤回该作业
└──────────────┘
```

### 3.2 状态转换规则

```java
public enum AssignmentStatus {
    ASSIGNED,      // 已分配，待查看
    VIEWED,        // 已查看
    IN_PROGRESS,   // 进行中
    SUBMITTED,     // 已提交
    GRADED,        // 已批改
    OVERDUE,       // 逾期
    LATE_SUBMIT,   // 迟交中（允许补交）
    EXEMPTED,      // 已豁免
    WITHDRAWN      // 已撤回
}

// 合法状态转换映射
private static final Map<AssignmentStatus, Set<AssignmentStatus>> TRANSITIONS = Map.of(
    ASSIGNED,    Set.of(VIEWED, OVERDUE, WITHDRAWN, EXEMPTED),
    VIEWED,      Set.of(IN_PROGRESS, OVERDUE, WITHDRAWN, EXEMPTED),
    IN_PROGRESS, Set.of(SUBMITTED, OVERDUE, WITHDRAWN),
    OVERDUE,     Set.of(LATE_SUBMIT, EXEMPTED, WITHDRAWN),
    LATE_SUBMIT, Set.of(SUBMITTED, EXEMPTED, WITHDRAWN),
    SUBMITTED,   Set.of(GRADED, IN_PROGRESS),  // IN_PROGRESS: 教师打回重做
    GRADED,      Set.of(GRADED)                 // 终态：可重新批改
);
```

### 3.3 状态转换事件定义

| 事件 | 触发条件 | 原状态 → 目标状态 | 副作用 |
| --- | --- | --- | --- |
| `STUDENT_VIEWED` | 学生打开作业详情 | ASSIGNED → VIEWED | 记录 `viewed_at`，推送预览 |
| `STUDENT_STARTED` | 学生开始作答（打开题目） | VIEWED → IN_PROGRESS | 记录 `started_at` |
| `STUDENT_SUBMITTED` | 学生提交作业 | IN_PROGRESS/LATE_SUBMIT → SUBMITTED | 记录 `submitted_at`，触发批改流程 |
| `TEACHER_GRADED` | 教师完成批改 | SUBMITTED → GRADED | 记录 `graded_at`/`score`/`comment` |
| `DUE_TIME_PASSED` | 定时任务检测到逾期 | ASSIGNED/VIEWED/IN_PROGRESS → OVERDUE | 触发逾期通知 |
| `STUDENT_LATE_SUBMIT` | 逾期后学生补交 | OVERDUE → LATE_SUBMIT | 计算迟交时长 |
| `TEACHER_EXEMPT` | 教师标记免交 | ANY → EXEMPTED | 通知学生 |
| `TEACHER_RETURN` | 教师打回重做 | SUBMITTED/GRADED → IN_PROGRESS | 重置提交状态 |
| `TEACHER_WITHDRAW` | 教师撤回作业 | ANY → WITHDRAWN | 批量处理所有学生实例 |

## 5. 智能催交提醒调度引擎

### 5.1 催交策略矩阵

催交调度引擎根据作业状态、时间节点、学生行为模式、历史数据综合决策。

#### 5.1.1 提醒阶段定义

| 阶段 | 触发时机 | 提醒类型 | 目标 | 强度 |
| --- | --- | --- | --- | --- |
| T1 预提醒 | 截止前 24h ± 2h | `PRE_DUE` | 未开始(ASSIGNED)的学生 | 低 |
| T2 临近提醒 | 截止前 4h ± 1h | `PRE_DUE_URGENT` | 未提交(ASSIGNED/VIEWED/IN_PROGRESS) | 中 |
| T3 截止提醒 | 截止时刻 | `AT_DUE` | 仍未提交 | 高 |
| T4 逾期提醒 | 截止后 2h | `OVERDUE` | 逾期未交(OVERDUE) | 高 |
| T5 升级提醒 | 截止后 24h | `ESCALATION` | 仍未交，同时通知家长 | 最高 |
