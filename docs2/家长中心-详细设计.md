# 家长中心 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

家长中心是 PrimeTop 面向家长用户的核心功能模块，提供孩子学情查看、使用时长管控、内容范围设置、学习提醒接收和会员订阅管理等服务。该模块是实现未成年人保护、家长监督和家校协同的关键组件。

### 1.2 覆盖学段

全学段（幼儿至高中），核心面向家长用户。

### 1.3 优先级

P1（首个正式版本应具备）。

### 1.4 模块依赖

| 依赖模块 | 说明 |
| --- | --- |
| 用户账号体系 | 家长注册登录、家长与学生绑定 |
| 学情分析 | 学情报告数据来源 |
| 学习规划 | 任务完成数据、提醒机制 |
| 支付服务 | 家庭套餐、会员续费 |

## 4. API 接口设计

### 4.1 绑定管理

#### 4.1.1 生成绑定邀请码

```
POST /api/v1/parent/bind/code
```

**请求体：**
```json
{
  "studentId": 10001
}
```

**响应体：**
```json
{
  "code": 0,
  "data": {
    "bindCode": "ABCD1234",
    "expiresIn": 86400
  }
}
```

**逻辑说明：**
- 家长端调用，生成 8 位字母数字混合的邀请码
- 有效期 24 小时
- 每个家长对同一学生只能有一个待确认的绑定

#### 4.1.2 学生确认绑定

```
POST /api/v1/parent/bind/confirm
```

**请求体：**
```json
{
  "bindCode": "ABCD1234",
  "relationType": "mother"
}
```

**响应体：**
```json
{
  "code": 0,
  "data": {
    "bindingId": 5001,
    "parentNickname": "张妈妈",
    "confirmedAt": "2026-05-19T10:30:00+08:00"
  }
}
```

**逻辑说明：**
- 学生端调用
- 验证邀请码有效性和过期时间
- 同一学生最多绑定 4 个家长账号

#### 4.1.3 解除绑定

```
DELETE /api/v1/parent/bind/{bindingId}
```

**请求参数：**
- `reason` (可选): 解绑原因

**逻辑说明：**
- 家长或学生均可发起
- 解绑后自动停用该绑定下的管控配置
- 保留历史学情报告数据

## 5. 状态流转

### 5.1 绑定流程

```
家长端                      系统                      学生端
  |                         |                         |
  |-- 生成绑定邀请码 ------->|                         |
  |<-- 返回邀请码 -----------|                         |
  |                         |                         |
  |   (家长将邀请码告知学生)  |                         |
  |                         |                         |
  |                         |<-- 提交邀请码确认绑定 ---|
  |                         |-- 验证邀请码有效性 ---->|
  |                         |-- 创建绑定关系 -------->|
  |                         |-- 初始化管控配置 ------>|
  |                         |-- 返回绑定成功 -------->|
  |<-- 推送绑定成功通知 -----|                         |
  |                         |                         |
```

### 5.2 管控状态检查流程

```
学生端发起操作（AI问答/拍题/学习）
        |
        v
[查询管控配置] --> 无管控 --> 允许操作
        |
     有管控
        v
[检查时段] --> 不在允许时段 --> 提示"当前不在学习时间"
        |
     在允许时段
        v
[检查今日已用时长] --> 已达上限 --> 提示"今日学习时间已用完，明天再来吧"
        |
     未达上限
        v
[检查内容范围] --> 不在允许范围 --> 提示"该功能暂未开放"
        |
     在允许范围
        v
   允许操作
```

### 5.3 报告生成流程

```
定时任务（每日/每周/每月触发）
        |
        v
[查询所有活跃绑定关系]
        |
        v
[聚合学生学习数据] -- 调用学情分析服务
        |
        v
[生成学科统计 + 薄弱点 + 趋势对比]
        |
        v

        |
        v

        |
        v
[推送报告通知给家长]
```

### 5.4 家长验证流程

```
用户点击"家长中心"入口
        |
        v
[检查是否有有效验证token] -- 有 --> 直接进入
        |

        v

        |

        v
```

## 6. 关键代码示例

### 6.1 管控检查中间件（服务端）

```python
class ParentControlMiddleware:
    """学生操作前的家长管控检查"""
    
    def __init__(self, control_repo: ParentControlRepository):
        self.control_repo = control_repo
    
    async def check(self, student_id: int, feature: str, subject: str = None) -> ControlResult:
        """
        检查学生是否被允许执行该操作
        
        Args:
            student_id: 学生用户ID
            feature: 功能标识 (ai_tutor/photo_search/sync_class 等)
            subject: 学科标识 (可选)
        
        Returns:
            ControlResult: allowed=bool, reason=str, remaining_min=int
        """
        config = await self.control_repo.get_active_config(student_id)
        if config is None:
            return ControlResult(allowed=True)  # 无管控配置，允许
        
        # 1. 检查时段
        if config.allowed_time_slots:
            now = datetime.now().time()
            in_slot = any(
                parse_time(slot["start"]) <= now <= parse_time(slot["end"])
                for slot in config.allowed_time_slots
            )
            if not in_slot:
                return ControlResult(
                    allowed=False, 
                    reason="NOT_IN_ALLOWED_TIME",
                    message="当前不在允许的学习时间内"
                )
        
        # 2. 检查功能范围
        if config.allowed_features and feature not in config.allowed_features:
            return ControlResult(
                allowed=False,
                reason="FEATURE_NOT_ALLOWED",
                message="该功能暂未开放"
            )
        
        # 3. 检查学科范围
        if subject and config.allowed_subjects and subject not in config.allowed_subjects:
            return ControlResult(
                allowed=False,
                reason="SUBJECT_NOT_ALLOWED",
                message="该学科暂未开放"
            )
        
        # 4. 检查今日时长
        if config.daily_time_limit_min is not None:
            used_min = await self.control_repo.get_today_used_minutes(student_id)
            remaining = config.daily_time_limit_min - used_min
            if remaining <= 0:
                return ControlResult(
                    allowed=False,
                    reason="TIME_LIMIT_REACHED",
                    message="今日学习时间已用完",
                    remaining_min=0
                )
            return ControlResult(allowed=True, remaining_min=remaining)
        
        return ControlResult(allowed=True)
```

### 6.2 报告生成服务

```python
class ParentReportService:
    """家长学情报告生成服务"""
    
    def __init__(
        self, 
        study_repo: StudyDataRepository,
        report_repo: ParentStudyReportRepository,
        ai_service: AIService,
    ):
        self.study_repo = study_repo
        self.report_repo = report_repo
        self.ai_service = ai_service
    
    async def generate_weekly_report(self, student_id: int, binding_id: int) -> ParentStudyReport:
        """生成周报"""
        today = date.today()
        week_start = today - timedelta(days=today.weekday() + 7)  # 上周一
        week_end = week_start + timedelta(days=6)  # 上周日
        
        # 聚合学习数据
        stats = await self.study_repo.aggregate_student_stats(
            student_id=student_id,
            start_date=week_start,
            end_date=week_end
        )
        
        # 获取上一期数据用于趋势对比
        prev_start = week_start - timedelta(days=7)
        prev_end = week_start - timedelta(days=1)
        prev_stats = await self.study_repo.aggregate_student_stats(
            student_id=student_id,
            start_date=prev_start,
            end_date=prev_end
        )
        
        # 计算趋势
        trend = self._calc_trend(stats.total_study_min, prev_stats.total_study_min)
        
        # 获取薄弱知识点
        weak_points = await self.study_repo.get_weak_points(
            student_id=student_id,
            start_date=week_start,
            end_date=week_end,
            threshold_accuracy=0.6,
            limit=5
        )
        
        # AI 生成建议
        ai_suggestion = await self.ai_service.generate_parent_suggestion(
            student_id=student_id,
            stats=stats,
            prev_stats=prev_stats,
            weak_points=weak_points
        )
        
        # 持久化报告
        report = ParentStudyReport(
            binding_id=binding_id,
            student_id=student_id,
            report_type="weekly",
            report_period_start=week_start,
            report_period_end=week_end,
            total_study_min=stats.total_study_min,
            ai_qa_count=stats.ai_qa_count,
            photo_search_count=stats.photo_search_count,
            mistake_count=stats.mistake_count,
            mistake_reviewed=stats.mistake_reviewed,
            plan_completion_pct=stats.plan_completion_pct,
            subject_stats=[s.dict() for s in stats.subject_stats],
            weak_points=[w.dict() for w in weak_points],
            trend_vs_last=trend,
            ai_suggestion=ai_suggestion,
        )
        
        return await self.report_repo.save(report)
    
    def _calc_trend(self, current: float, previous: float) -> str:
        if previous == 0:
            return "up" if current > 0 else "flat"
        change_pct = (current - previous) / previous * 100
        if change_pct > 5:
            return "up"
        elif change_pct < -5:
            return "down"
        return "flat"
```

### 6.3 时长追踪服务

```python
class UsageTrackingService:
    """学生使用时长追踪服务"""
    
    def __init__(self, redis: Redis, control_repo: ParentControlRepository):
        self.redis = redis
        self.control_repo = control_repo
    
    async def start_session(self, student_id: int) -> str:
        """记录学习会话开始"""
        session_id = str(uuid.uuid4())
        key = f"usage:session:{student_id}:{session_id}"
        await self.redis.set(key, str(int(time.time())), ex=86400)
        
        # 更新当日累计
        today_key = f"usage:daily:{student_id}:{date.today()}"
        await self.redis.incrby(today_key, 0)  # 确保key存在
        await self.redis.expire(today_key, 172800)  # 48h TTL
        
        return session_id
    
    async def heartbeat(self, student_id: int, session_id: str) -> UsageCheckResult:
        """
        学习会话心跳（客户端每60秒调用一次）
        返回是否允许继续使用
        """
        # 累加60秒到当日时长
        today_key = f"usage:daily:{student_id}:{date.today()}"
        used_min = await self.redis.incrbyfloat(today_key, 1.0 / 60)  # 加1分钟
        await self.redis.expire(today_key, 172800)
        
        # 检查是否超限
        config = await self.control_repo.get_active_config(student_id)
        if config and config.daily_time_limit_min:
            remaining = max(0, config.daily_time_limit_min - int(used_min))
            if remaining <= 0:
                return UsageCheckResult(
                    allowed=False,
                    reason="TIME_LIMIT_REACHED",
                    remaining_min=0
                )
            return UsageCheckResult(allowed=True, remaining_min=remaining)
        
        return UsageCheckResult(allowed=True)
    
    async def end_session(self, student_id: int, session_id: int):
        """记录学习会话结束"""
        key = f"usage:session:{student_id}:{session_id}"
        await self.redis.delete(key)
```

## 8. 错误处理

### 8.1 错误码定义

| 错误码 | HTTP状态 | 说明 | 处理建议 |
| --- | --- | --- | --- |
| `PARENT_NOT_BOUND` | 403 | 家长未绑定该学生 | 引导绑定 |
| `BIND_CODE_INVALID` | 400 | 邀请码无效 | 重新获取 |
| `BIND_CODE_EXPIRED` | 400 | 邀请码已过期 | 重新获取 |
| `BIND_LIMIT_EXCEEDED` | 400 | 绑定数量超限（学生最多4个家长） | 提示上限 |
| `PIN_VERIFICATION_FAILED` | 401 | PIN 验证失败 | 提示剩余次数 |
| `PIN_LOCKED` | 429 | PIN 连续失败被锁定 | 提示解锁时间 |
| `CONTROL_NOT_FOUND` | 404 | 无管控配置 | 使用默认配置 |
| `REPORT_NOT_FOUND` | 404 | 报告不存在 | 返回空状态 |
| `NOT_IN_ALLOWED_TIME` | 200 | 不在允许时段（业务拒绝） | 显示友好提示 |
| `TIME_LIMIT_REACHED` | 200 | 时长已用尽（业务拒绝） | 显示鼓励文案 |
| `FEATURE_NOT_ALLOWED` | 200 | 功能不在允许范围（业务拒绝） | 引导家长开放 |

### 8.2 降级策略

| 场景 | 策略 |
| --- | --- |
| Redis 不可用（时长统计） | 降级为不限时长，记录日志，待恢复后补偿计算 |
| 学情分析服务超时 | 报告生成任务标记失败，重试 3 次，最终失败则跳过该周期 |
| AI 建议生成失败 | 报告正常保存，`ai_suggestion` 字段为空，后续异步补充 |
| 推送服务不可用 | 存入推送队列表，后续补偿推送 |

## 11. 安全与合规

1. **家长验证**：所有管控配置的查看和修改都需要通过家长身份验证
2. **PIN 安全**：PIN 使用 bcrypt 加密存储，连续 5 次失败锁定 15 分钟
3. **数据隔离**：家长只能查看已绑定学生的数据，API 层强制校验绑定关系
4. **最小化采集**：家长端不采集额外个人信息，仅使用注册手机号
5. **未成年人保护**：时长限制和内容管控为家长中心的核心功能，确保符合相关法规
6. **操作审计**：管控配置的每次修改都记录操作日志（操作人、时间、变更内容）
7. **隐私合规**：学情报告数据加密存储，家长与学生的绑定关系不对外暴露
