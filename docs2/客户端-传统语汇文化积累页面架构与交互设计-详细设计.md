## 1. 模块概述

### 1.1 功能定位

本文档是传统语汇学习域(Folk Phrase,内部代号 FOLK-UI)的**客户端呈现层权威**,兑现服务端引擎 v1.0 交付后客户端页面层的零覆盖缺口。

经全目录关键词扫描确认(2026-11-24,`歇后语/谚语/俗语/名言警句/传统语汇/接龙`):服务端引擎文档命中,客户端页面层零覆盖——既有《客户端-语文词语辨析练习页面架构与交互设计》覆盖近义词/反义词/多音字/形近字、《客户端-古诗文专项学习页面架构与交互设计》覆盖诗词背诵与飞花令、《客户端-诗词飞花令与诗词竞技页面架构与交互设计》覆盖诗句接龙竞技,均不含"歇后语/谚语/俗语/名言警句"四类语汇的补全/辨析/配对训练链路;飞花令接龙为诗句域(诗词竞技引擎),本文接龙为语汇域(folk 引擎),路由与数据双隔离。本文补齐该缺口(模式同批次(四十)棋类/(四十五)配音/(四十六)词语辨析/(四十九)写字:服务端已就绪→客户端页面层补全)。

语汇页面的核心交互是**语料积累与语境运用**:学生经每日一句/闪卡接触语料→按子域进入补全/判断/配对练习→服务端同步判分→答错即时进入 SSE 讲解流→接龙挑战以游戏化巩固→画像沉淀驱动复习队列。客户端只做呈现与采集:零判分、零选项重排、未作答前答案零渲染、题目快照零落盘、**拼音零本地转换**(接龙拼音提示只渲染服务端 pinyin_snapshot)。

### 1.3 明确不做(本期)

1. 不做**成语**训练入口(归 LIT 语文素养系统;本文 CATEGORY_CLASSIFY 仅渲染服务端装配的"俗语 vs 成语"分类题,成语释义数据为服务端投影快照);
2. 不做**古诗文/诗句**接龙入口(归诗词竞技引擎 PGE 域,路由命名空间隔离);
3. 不做 UGC 造句/分享接龙成绩/语料收藏社交(服务端 C3 零社交,客户端零分享组件);
4. 不做全服排行榜/班级排名/同龄对比组件(合规,CI 组件白名单扫描;chain_best 仅自比);
5. 不做题目内容本地缓存/离线练习模式(题目快照零落盘,弱网诚实提示);
6. 不做录音跟读——本域为文本积累训练,无录音入口无麦克风权限申请;
7. 不做学前段入口,路由守卫 fail-closed(服务端 grade_band 过滤为权威,客户端双保险);
8. 不做本地判分预演/选项正误预标记/答案键驻留/本地拼音转换(CI 禁词表扫描,含拼音库引用);
9. 不做名言英文翻译训练入口(归英语专项域);
10. 不做绕口令入口(归中文朗读能力评估域)。

## 3. 页面架构

### 3.1 `/folk` 语汇首页

**布局**:顶部标题"传统语汇";每日一句卡(引子大字+破折号排版+后衬折叠/展开,meaning 默认折叠,usage_example 展开区,AIGC 徽标条件渲染,底部"摇一摇换一句"按钮+已摇置灰态);四子域入口卡(2×2 网格:歇后语/谚语/俗语/名言警句,各卡展示 learned/mastered 迷你进度条+到期复习数小红点);接龙挑战卡(chain_best 个人最佳"你的纪录:N 链"+开始按钮);继续会话卡(探测到 ACTIVE 会话时置顶,展示模式+进度"第 3/10 题");画像摘要卡(四子域迷你条)与"今日复习"入口行。

**交互规约**:
- 每日一句卡数据来自 GET /folk/daily(服务端权威,含当日是否已摇签);摇签按钮点击→POST /folk/daily/draw(带 Idempotency-Key=UUID v7)→ 200 刷新卡片;44708(今日已摇签)→ 按钮置灰+诚实提示"明天再来摇新签",**禁本地锁定逻辑**(服务端权威);
- 子域卡点击→创建会话(POST /folk/sessions,mode=PRACTICE,quizTypes 按 §3.9 分龄默认集,totalCount 按 §3.9,Idempotency-Key=UUID v7)→ 跳练习页;点击即置按钮 LOADING 防双击(幂等由服务端回放保证,44706 返回首次结果按成功渲染);
- 44707(DAILY_NEW_LIMIT 200 引导帧)→ 不打断首页,弹层引导"今天新学的够多啦,去复习巩固一下吧"+按钮"去复习"跳 `/folk/reviews`(引导帧按业务成功语义处理,禁报错渲染);
- 44712(POOL_EMPTY 200)→ 该子域卡置灰+"语料正在准备中"占位,其余子域可点;
- 44730(防沉迷拦截)→ fail-closed 休息引导页,无重试按钮(R8);
- 44731(家长管控关闭)→ 首页渲染"家长已关闭,去和家长聊聊"空态;
- 继续会话卡:PRACTICE/FLASHCARD/CHAIN 分别深链对应页面;会话 24h 过期(44703/44704)→ 移除卡片并吐司"上次的练习已结束";
- 骨架屏/错误重试态遵循《客户端-页面状态模式与骨架屏加载空态错误态设计规范》;每日一句卡失败不阻塞子域卡(练习主链路不依赖每日数据)。

### 3.2 `/folk/session/:sessionNo` 练习页(核心页,PRACTICE/DAILY)

单页结构:顶部进度条(seq/总数+子域 chip+题型 chip)、主体题型工作区、底部操作条(提交答案/下一题,末题为"完成并交卷")。

**通用规约**:
- 题目数据以创建会话响应 questions 为**内存快照 SSOT**(R1/R11),全程禁回源拉取(防版本分叉);
- 未作答前,答案相关字段在响应中本就不存在(answer_json 零答案字段,服务端 G2),客户端渲染层无答案数据源(G5);CI 模型扫描禁止任何"本地答案表";
- 选项原样渲染(服务端已乱序,R3),客户端禁 reshuffle;
- 提交流程:ANSWERING→SUBMITTING(不可取消,按钮置灰+菊花)→JUDGED(渲染判分)→下一题;幂等键创建会话时定(X-Idempotency-Key),单题提交以 (sessionNo,seq) 为天然幂等键,弱网重发/进程恢复重放同 seq(G7);
- 44705(题序越界/乱序)→ 自动 GET /folk/sessions/{sessionNo} 刷新会话快照,以服务端 answeredCount 为准重定位当前题;刷新仍失败→退出会话回首页并吐司;
- 44704(会话状态非法/过期)→ 诚实页"这次练习已结束",展示已答进度(最后一次 judge 响应/会话详情),1 个按钮"再练一组"回首页;禁渲染题目内容;
- 末题判分后操作条变"完成并交卷"(二次确认弹窗:"还有 X 题没做,确定交卷吗?"),**不自动提交**(服务端 §8.1 防弱网半卷裁决);未答题可跳过(进度条区分色),交卷二次确认文案含未答数;DAILY 模式(totalCount=1)免二次确认,判分后直接内联结果卡(§3.6 DAILY 分支),离开页时静默调 finish(服务端"最后一题提交"自动 FINISHED 语义兜底,重复 finish 幂等 G9)。

**七题型渲染**(FolkQuizRendererRegistry 委托分发):

| 题型 | 渲染 | 提交载荷(answer 对象) | 预校验(仅格式,零判定) |
| --- | --- | --- | --- |
| LATTER_SELECT | 引子文本大字+破折号留白;选项列(文本,1-2 年级带拼音);点击选中态高亮 | `{selectedOptionId}` | 必须选中一项才可提交 |
| FORMER_SELECT | 后衬文本大字+"这句的引子是?";选项列为引子候选 | `{selectedOptionId}` | 必须选中一项 |
| HOMOPHONE_EXPLAIN | 完整歇后语(引子+后衬)+谐音点提问"妙在哪里?";选项列 | `{selectedOptionId}` | 必须选中一项 |
| NEXT_HALF_COMPLETE | 前半句大字+"后半句是?";SELECT:选项列;INPUT:输入框(inputHint Placeholder 服务端下发) | `{selectedOptionId}` 或 `{inputText}` | SELECT 必须选中;INPUT 非空才可提交,**不**做长度/字数控核(服务端 §4.3 归一化裁决) |
| USAGE_JUDGE | 例句文本(语汇高亮)+这句话用得对吗?双按钮(对/不对) | `{judgement:true/false}` | 必须二选一 |
| SOURCE_MATCH | 名言文本大卡+三组维度(作者/朝代/出处)各为选项列;逐维单选 | 客户端组装 `{matches:{author:optionId,source:optionId}}` 形状,**wire 以服务端判题输入为最终权威**(R2) | 三个维度全部选中才可提交 |
| CATEGORY_CLASSIFY | 短语大卡+"它是俗语还是成语?";双按钮(俗语/成语) | `{judgement:true/false}`(true=俗语,语义以服务端题面说明为准,R2) | 必须二选一 |

**判分反馈(JUDGED 态)**:对/错动画(分龄时长见 §3.9);对→绿色确认+轻音效;错→正确答案位置高亮(SELECT 型)/正解文本展示(INPUT 型,服务端 judge 响应权威)+explainHint 一句话点拨(服务端下发原文渲染)+错因成长型话术映射(TAIL_CONFUSED→"后衬有点记混了,听讲解分清它";HOMOPHONE_IGNORED→"谐音的小机关没发现哦";SOURCE_CONFUSED→"作者和出处搭错线啦";REGISTER_MISMATCH→"这句话的语体要看场合";CATEGORY_CONFUSED→"俗语和成语的分家线在这儿");底部出现"听讲解"主按钮(仅答错)与"下一题"。judgeDetail 不直接展示,仅用于埋点(errorTags 白名单字段)。

**讲解抽屉**:见 §3.3。

### 3.3 答错讲解抽屉(SSE)

**触发**:JUDGED=WRONG 时底部"听讲解"→请求 `POST /folk/explain`(body `{sessionNo, seq}`)。

**帧渲染**(协议委托 SSE 引擎 R4;服务端 §6.4 帧协议):

| 帧 | 客户端行为 |
| --- | --- |
| `event: explanation` | 流式渲染 JSON 三字段:plainExplanation(主体讲解,分条渐入)/memoryHook(记忆钩子卡,重点高亮)/followUpTip(下步建议条);未知字段忽略不 crash |
| `event: done` | 渲染 explainId 落内存(去重用);`aiGenerated=true`→AIGC 徽标常驻;`aiGenerated=false`→顶部诚实标注"简化讲解" |
| 44710(AI_QUOTA_EXHAUSTED,HTTP 200 降级帧) | 不弹错误:顶部降级条"AI 忙不过来,这是课本版讲解",静态解析正常渲染(aiGenerated=false) |
| 44711(EXPLAIN_IN_PROGRESS,HTTP 200 异步任务态) | 渲染"讲解生成中"骨架+退避轮询(委托统一异步任务进度中心,1.5s 起退避封顶 5s×20 次),就绪后自动续显 |

**断线与竞态**:SSE 断连 3s 内自动重连一次(携带 since/explainId 由 SSE 引擎管理),重连期间已渲染内容保留;重连失败或超时 8s→静态 explainHint+本地兜底话术"可以问问老师这句的妙处",可手动重试一次。同一 (sessionNo,seq) 重复打开抽屉:explainId 命中即复用已渲染内容,不重复请求(去重守卫)。讲解中退出抽屉:流继续或取消由 SSE 引擎管理,重进断点续显。

**红线**:讲解渲染零自调 LLM(R5);讲解中禁展示"你错了/太粗心"等否定式措辞(合规 C2,话术白名单制);AIGC 徽标常驻不可关闭(合规 C4)。

### 5.1 FolkSessionController(PRACTICE/DAILY 练习主控制器)

```dart
class FolkSessionController extends ChangeNotifier {
  final FolkApi api;
  final SseEngine sse;
  List<FolkQuestionView> _queue = [];      // 内存快照 SSOT,零落盘
  int _current = 0;
  MirrorState _state = MirrorState.ready;
  FolkJudgeOutcome? _lastJudge;
  String? _sessionNo;

  FolkQuestionView get current => _queue[_current];

  Future<void> submitAnswer({
    String? selectedOptionId,
    String? inputText,
    bool? judgement,
    Map<String, String>? matches,          // SOURCE_MATCH(R2 wire 权威)
    int clientElapsedMs = 0,
  }) async {
    if (_state == MirrorState.submitting) return;            // G7 防双击
    _state = MirrorState.submitting;
    notifyListeners();
    try {
      final outcome = await api.submitAnswer(
        sessionNo: _sessionNo!,
        seq: current.seq,                                   // (sessionNo,seq) 天然幂等
        selectedOptionId: selectedOptionId,
        inputText: inputText,
        judgement: judgement,
        matches: matches,
        clientElapsedMs: clientElapsedMs,
      );
      _lastJudge = outcome;
      _state = MirrorState.judged;
    } on FolkException catch (e) {
      if (e.code == 44705) { await _refreshSessionSnapshot(); }     // 乱序:服务端权威重取
      else if (e.code == 44704 || e.code == 44703) { _state = MirrorState.expiredLocal; }
      else { _state = MirrorState.judgedError; rethrow; }
    } finally { notifyListeners(); }
  }

  void next() {
    _lastJudge = null;
    _state = _current + 1 >= _queue.length
        ? MirrorState.allAnswered            // 引导交卷,不自动提交(服务端 §8.1)
        : MirrorState.ready;
    if (_state == MirrorState.ready) _current++;
    notifyListeners();
  }
}
```

### 5.2 FolkChainController(接龙回合流)

```dart
class FolkChainController extends ChangeNotifier {
  final FolkApi api;
  FolkQuestionView? _round;
  int _chainLen = 0;
  bool _broken = false;
  bool _finishedNaturally = false;         // 44709 正常收官
  ChainState _state = ChainState.roundActive;

  Future<void> submitLink({String? selectedOptionId, String? inputText}) async {
    if (_state != ChainState.roundActive) return;
    _state = ChainState.submitting;        // 不可取消,回合同 seq 幂等

      else if (e.code == 44704 || e.code == 44703) { _state = ChainState.sessionGone; }

  }
}
```

```dart
class FolkExplainController extends ChangeNotifier {
  final SseEngine sse;
  final Map<String, FolkExplainDoc> _cache = {};   // (sessionNo,seq) -> 讲解,内存零落盘

  Future<void> open(String sessionNo, int seq) async {
    final key = '$sessionNo:$seq';
    if (_cache.containsKey(key)) { notifyListeners(); return; }   // explainId 去重
    final ctrl = sse.connect('POST', '/api/v1/folk/explain',
        body: {'sessionNo': sessionNo, 'seq': seq});
    ctrl.onEvent('explanation', (d) => _doc.appendFields(d));      // 三字段增量渲染
    ctrl.onEvent('done', (d) {
      _doc.explainId = d['explainId'];
      _doc.aiGenerated = d['aiGenerated'] == true;                 // AIGC 徽标/降级标注
      _cache[key] = _doc;
    });
    ctrl.onErrorFrame((e) {                                         // 44710/44711 降级帧
      if (e['code'] == 44710) _doc.degradedNotice = e['message'];
      if (e['code'] == 44711) _doc.asyncPending = true;            // 转轮询
    });
    await ctrl.withTimeout(const Duration(seconds: 8)).withOneRetry(); // 断线 3s 重连一次
    // 兜底:超时/二次失败 → 静态 explainHint+成长型话术,不弹错误
  }
}
```
