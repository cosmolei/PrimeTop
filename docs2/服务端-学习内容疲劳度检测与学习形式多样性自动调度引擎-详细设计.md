# 学习内容疲劳度检测与学习形式多样性自动调度引擎 - 详细设计

## 1. 模块概述

### 1.1 背景与问题

在 PrimeTop 的学习闭环中，学生在一次学习会话（Session）内可能连续消费大量同质化形式的内容——例如连续看 8 段视频讲解、连续做 20 道选择题、连续阅读 5 篇知识点图文。即使内容本身质量和难度合适，**单一形式的持续刺激**会导致：

- **注意力衰减**：学生对相同形式的刺激产生习惯化（Habituation）， engagement 指标下降。
- **被动学习陷阱**：连续观看视频容易进入"伪学习"状态——眼睛在看，大脑没转。
- **完成率下降**：A/B 数据表明，单一形式学习会话的中途流失率比混合形式高 23-35%。
- **学习效果降低**：主动回忆（Active Recall）和间隔练习（Spaced Practice）等认知科学原则要求形式切换。

### 1.2 模块定位

**学习内容疲劳度检测与学习形式多样性自动调度引擎**（以下简称"疲劳度调度引擎"）负责：

1. **实时检测**学生在当前学习会话中的内容形式疲劳度。
2. **自动调度**下一个推荐内容的学习形式（视频 / 图文 / 互动练习 / 闪卡 / AI 对话 / 测验等），确保形式多样性。
3. 在形式切换时**保持学习目标连续性**——切换的是"怎么学"，不是"学什么"。
4. 为上游推荐引擎和编排引擎提供形式层面的约束信号。

### 1.3 与现有模块的边界

| 现有模块 | 职责 | 本模块区别 |
|---------|------|-----------|
| 学生认知负荷监测与学习内容难度动态调节引擎 | 监测**难度**是否过高/过低，调节难度曲线 | 本模块调节**形式**，不碰难度 |
| 推荐内容多样性保障与信息茧房破壁引擎 | 保障推荐**主题/知识点**的多样性 | 本模块保障**内容载体形式**的多样性 |
| 学习会话内容编排与学习节奏智能控制引擎 | 编排会话内的整体节奏和步骤 | 本模块是其在"形式"维度的专项子引擎 |
| 统一学习干预编排与智能频控引擎 | 统一干预触发和频控 | 本模块输出形式疲劳干预信号，由统一干预引擎执行 |

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| ContentFormat | 内容载体形式，枚举值见 §2.1 |
| FatigueScore | 疲劳度分数，0-100，越高越疲劳 |
| FormatStreak | 连续消费同一形式的计数 |
| SessionFormatHistory | 当前会话内已消费内容的形式序列 |
| DiversityIndex | 会话内形式多样性指数（Shannon Entropy） |
| FormatSwitch | 形式切换事件 |
| EngagementSignal | 参与度信号（点击、停留、完成、互动等） |

## 3. 核心算法设计

### 3.1 疲劳度计算模型

疲劳度分数（FatigueScore）由三个子分量加权合成：

```
FatigueScore = w1 × StreakFatigue + w2 × EngagementDecline + w3 × DiversityPenalty
```

**默认权重**：`w1=0.45, w2=0.35, w3=0.20`（可通过配置中心调整）

### 3.1.1 连续形式疲劳 StreakFatigue

```java
/**
 * 连续同一形式消费导致的疲劳。
 * 使用 sigmoid 函数建模：streak 越大，疲劳度增长越快（到达饱和）。
 *
 * @param streak   当前形式连续消费次数
 * @param threshold 该形式的疲劳阈值（来自基线表或全局默认4）
 * @return 0-100 的疲劳分数
 */
public double calculateStreakFatigue(int streak, int threshold) {
    if (streak <= 1) return 0;
    // 归一化到阈值相对位置
    double x = (double) (streak - 1) / threshold;
    // Sigmoid: x=0 → ~0, x=1 → 50, x=2 → ~88, x=3 → ~98
    double sigmoid = 100.0 / (1.0 + Math.exp(-(x - 1) * 4.6));
    return Math.min(100, sigmoid);
}
```

**疲劳曲线示例**（threshold=4）：

| Streak | StreakFatigue |
|--------|--------------|
| 1      | ~2           |
| 2      | ~12          |
| 3      | ~31          |
| 4      | 50           |
| 5      | ~69          |
| 6      | ~83          |
| 7      | ~92          |
| 8      | ~96          |

### 3.1.2 参与度衰减 EngagementDecline

```java
/**
 * 通过滑动窗口内最近的参与度信号，判断用户 engagement 是否在下降。
 * 比较当前形式最近 N 条信号与基线的偏差。
 *
 * 核心：如果当前形式的完成率在下降、停留时间在缩短、跳过率在上升，
 *      说明疲劳正在实际影响行为。
 */
public double calculateEngagementDecline(
        List<EngagementSignal> recentSignals,
        ContentFormat currentFormat,
        FormatEngagementBaseline baseline) {
    
    if (recentSignals.size() < 3) return 0;
    
    // 取当前形式最近N条信号
    List<EngagementSignal> formatSignals = recentSignals.stream()
            .filter(s -> s.getFormat() == currentFormat)
            .limit(5)
            .collect(Collectors.toList());
    
    if (formatSignals.size() < 2) return 0;
    
    // 计算完成率趋势（线性回归斜率）
    double[] completionRates = formatSignals.stream()
            .mapToDouble(EngagementSignal::getCompletionRate).toArray();
    double slope = linearRegressionSlope(completionRates);
    
    // 计算与基线的偏差
    double currentAvgCompletion = average(completionRates);
    double baselineCompletion = baseline.getAvgCompletionRate();
    double deviation = baselineCompletion - currentAvgCompletion; // 正值=低于基线
    
    // 综合趋势和绝对偏差
    double trendPenalty = Math.max(0, -slope) * 200;  // 斜率为负→疲劳
    double absolutePenalty = Math.max(0, deviation) * 150;
    
    return Math.min(100, trendPenalty + absolutePenalty);
}
```

### 3.1.3 多样性惩罚 DiversityPenalty

```java
/**
 * 使用 Shannon 熵计算会话内形式多样性。
 * 熵越低 → 多样性越差 → 惩罚越高。
 */
public double calculateDiversityPenalty(List<ContentFormat> formatHistory) {
    if (formatHistory.isEmpty()) return 0;
    
    // 统计各 Category 出现频率
    Map<FormatCategory, Long> categoryCounts = formatHistory.stream()
            .collect(Collectors.groupingBy(
                    FormatClassifier::classify,
                    Collectors.counting()));
    
    int total = formatHistory.size();
    double shannonEntropy = 0.0;
    for (long count : categoryCounts.values()) {
        double p = (double) count / total;
        shannonEntropy -= p * Math.log(p);
    }
    
    // 归一化：最大熵 = ln(5)（5个Category）
    double maxEntropy = Math.log(5);
    double normalizedEntropy = shannonEntropy / maxEntropy;  // 0-1
    
    // 多样性指数 = normalizedEntropy（0=完全单一, 1=均匀分布）
    // 惩罚 = (1 - diversityIndex) × 100，但需要会话长度>阈值才生效
    if (total < 3) return 0;
    
    return (1.0 - normalizedEntropy) * 100;
}
```

### 3.1.4 综合疲劳度计算

```java
public FatigueAssessment assess(UserContext user, SessionContext session) {
    // 1. 获取当前状态
    ContentFormat currentFormat = session.getCurrentFormat();
    int streak = session.getCurrentStreak();
    List<ContentFormat> formatHistory = session.getFormatHistory();
    List<EngagementSignal> recentSignals = session.getRecentSignals(5);
    
    // 2. 获取基线
    FormatEngagementBaseline baseline = baselineService.getBaseline(
            user.getUserId(), currentFormat, user.getGradeLevel());
    int threshold = baseline != null ? baseline.getFatigueThreshold() : 4;
    
    // 3. 计算三个子分量
    double streakFatigue = calculateStreakFatigue(streak, threshold);
    double engagementDecline = calculateEngagementDecline(
            recentSignals, currentFormat, baseline);
    double diversityPenalty = calculateDiversityPenalty(formatHistory);
    
    // 4. 加权合成
    double[] weights = configService.getFatigueWeights(); // [0.45, 0.35, 0.20]
    double fatigueScore = weights[0] * streakFatigue 
                       + weights[1] * engagementDecline 
                       + weights[2] * diversityPenalty;
    
    fatigueScore = Math.round(fatigueScore * 100.0) / 100.0;
    fatigueScore = Math.min(100, Math.max(0, fatigueScore));
    
    // 5. 判断是否需要干预
    boolean needIntervention = fatigueScore >= configService.getFatigueInterventionThreshold(); // 默认55
    
    // 6. 如果需要干预，推荐下一个形式
    ContentFormat suggestedFormat = null;
    String reason = null;
    if (needIntervention) {
        FormatSuggestion suggestion = recommendNextFormat(user, session, fatigueScore);
        suggestedFormat = suggestion.getFormat();
        reason = suggestion.getReason();
    }
    
    return new FatigueAssessment(
            fatigueScore, streakFatigue, engagementDecline, diversityPenalty,
            currentFormat, streak, calculateDiversityIndex(formatHistory),
            needIntervention, suggestedFormat, reason);
}
```

### 3.2 下一个形式推荐算法

当疲劳度触发干预时，引擎需要推荐一个"形式切换方案"。

```java
public FormatSuggestion recommendNextFormat(
        UserContext user, SessionContext session, double fatigueScore) {
    
    ContentFormat currentFormat = session.getCurrentFormat();
    FormatCategory currentCategory = FormatClassifier.classify(currentFormat);
    
    // ---- 策略1：认知模式切换 ----
    // 被动消费太久 → 切到主动练习
    // 主动练习太久 → 切到互动记忆或AI对话
    // 原则：切换到认知参与模式不同的类别
    
    FormatCategory targetCategory = switch (currentCategory) {
        case PASSIVE_CONSUMPTION -> {
            // 被动→主动：唤醒学生
            if (session.getSessionDurationMinutes() > 20 && fatigueScore > 70) {
                yield FormatCategory.INTERACTIVE_MEMORY; // 严重疲劳→游戏化
            } else {
                yield FormatCategory.ACTIVE_PRACTICE;     // 一般疲劳→做题
            }
        }
        case ACTIVE_PRACTICE -> {
            // 主动→反思/互动
            if (session.getCorrectRate() < 0.5) {
                yield FormatCategory.AI_DIALOG; // 正确率低→AI辅导
            } else {
                yield FormatCategory.PASSIVE_CONSUMPTION; // 正确率高→看讲解放松
            }
        }
        case INTERACTIVE_MEMORY -> FormatCategory.PASSIVE_CONSUMPTION;
        case AI_DIALOG -> FormatCategory.ACTIVE_PRACTICE;
        case CREATIVE_OUTPUT -> FormatCategory.PASSIVE_CONSUMPTION;
    };
    
    // ---- 策略2：在目标类别中选择具体形式 ----
    // 考虑：用户偏好权重 × 知识点适配度 × 近期未使用
    List<ContentFormat> candidates = FormatClassifier.getFormatsByCategory(targetCategory);
    
    Map<ContentFormat, Double> scores = new LinkedHashMap<>();
    for (ContentFormat candidate : candidates) {
        double prefWeight = preferenceService.getFormatPreference(
                user.getUserId(), candidate);       // 0-1，用户历史偏好
        double recencyPenalty = calculateRecencyPenalty(
                session.getFormatHistory(), candidate); // 近期用过则降分
        double suitabilityScore = contentService.checkFormatSuitability(
                session.getCurrentKnowledgePoint(), candidate); // 知识点是否支持该形式
        
        double score = prefWeight * 0.4 
                     + (1 - recencyPenalty) * 0.3 
                     + suitabilityScore * 0.3;
        
        scores.put(candidate, score);
    }
    
    // 选最高分形式
    ContentFormat best = scores.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElse(candidates.get(0));
    
    String reason = buildReason(currentFormat, best, fatigueScore, targetCategory);
    return new FormatSuggestion(best, reason);
}

private double calculateRecencyPenalty(List<ContentFormat> history, ContentFormat candidate) {
    // 最近3条中出现过→penalty=1，最近5条出现→0.5，否则→0
    int size = history.size();
    List<ContentFormat> recent3 = history.subList(Math.max(0, size - 3), size);
    List<ContentFormat> recent5 = history.subList(Math.max(0, size - 5), size);
    
    if (recent3.contains(candidate)) return 1.0;
    if (recent5.contains(candidate)) return 0.5;
    return 0.0;
}
```

### 3.3 多样性保障约束

除了被动响应疲劳，引擎还维护一个**多样性保障约束**，在推荐层做前置过滤：

```java
/**
 * 多样性硬约束：在任何连续 N 条内容中，
 * - 同一 ContentFormat 不超过 maxSameFormat 次
 * - 同一 FormatCategory 不超过 maxSameCategory 次
 * - 至少包含 minDistinctCategories 个不同 Category
 */
public static class DiversityConstraint {
    private int windowSize = 6;               // 检查窗口
    private int maxSameFormat = 2;            // 同形式最多出现次数
    private int maxSameCategory = 3;          // 同类别最多出现次数
    private int minDistinctCategories = 2;    // 至少包含的不同类别数
}

public boolean checkConstraint(
        List<ContentFormat> proposedHistory, 
        ContentFormat candidate,
        DiversityConstraint constraint) {
    
    // 构建假设加入 candidate 后的窗口
    List<ContentFormat> window = new ArrayList<>(proposedHistory);
    window.add(candidate);
    if (window.size() > constraint.getWindowSize()) {
        window = window.subList(window.size() - constraint.getWindowSize(), window.size());
    }
    
    // 检查同形式计数
    Map<ContentFormat, Long> formatCounts = window.stream()
            .collect(Collectors.groupingBy(Function.identity(), Collectors.counting()));
    if (formatCounts.get(candidate) > constraint.getMaxSameFormat()) {
        return false;
    }
    
    // 检查同类别计数
    FormatCategory candidateCategory = FormatClassifier.classify(candidate);
    long categoryCount = window.stream()
            .map(FormatClassifier::classify)
            .filter(candidateCategory::equals)
            .count();
    if (categoryCount > constraint.getMaxSameCategory()) {
        return false;
    }
    
    // 检查最小类别数
    long distinctCategories = window.stream()
            .map(FormatClassifier::classify)
            .distinct().count();
    if (distinctCategories < constraint.getMinDistinctCategories()) {
        return false;
    }
    
    return true;
}
```

### 6.1 服务核心类

```java
package com.primetop.learning.fatigue;

import org.springframework.stereotype.Service;
import org.springframework.data.redis.core.StringRedisTemplate;
import com.google.gson.Gson;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;

import java.time.Duration;
import java.time.Instant;
import java.util.*;
import java.util.stream.Collectors;

@Slf4j
@Service
@RequiredArgsConstructor
public class FatigueScheduleService {

    private final StringRedisTemplate redis;
    private final FatigueConfigService configService;
    private final FormatBaselineService baselineService;
    private final PreferenceService preferenceService;
    private final ContentFormatAdapter contentAdapter;
    private final FatigueEventLogger eventLogger;
    private final Gson gson = new Gson();

    private static final String SESSION_KEY_PREFIX = "fatigue:session:";
    private static final String FORMAT_SEQ_SUFFIX = ":format_seq";
    private static final String STATE_SUFFIX = ":state";
    private static final String SIGNALS_SUFFIX = ":signals";
    private static final Duration SESSION_TTL = Duration.ofHours(6);

    /**
     * 核心入口：内容消费后评估疲劳度
     */
    public FatigueAssessment assess(FatigueAssessRequest request) {
        String sessionId = request.getSessionId();
        long userId = request.getUserId();

        // 1. 更新 Redis 中的形式序列和状态
        ContentConsumptionEvent event = request.getJustCompleted();
        updateSessionFormatSequence(sessionId, event);
        updateSessionState(sessionId, event);
        addEngagementSignal(sessionId, event);

        // 2. 加载当前状态
        SessionFormatState state = loadSessionState(sessionId);
        List<ContentFormat> formatHistory = loadFormatHistory(sessionId);
        List<EngagementSignal> recentSignals = loadRecentSignals(sessionId);

        // 3. 计算疲劳度
        FormatEngagementBaseline baseline = baselineService.getBaseline(
                userId, event.getContentFormat(), request.getGradeLevel());

        double streakFatigue = calculateStreakFatigue(
                state.getCurrentStreak(), 
                baseline.getFatigueThreshold());

        double engagementDecline = calculateEngagementDecline(
                recentSignals, state.getCurrentFormat(), baseline);

        double diversityPenalty = calculateDiversityPenalty(formatHistory);

        double[] weights = configService.getFatigueWeights();
        double fatigueScore = Math.min(100, Math.max(0,
                weights[0] * streakFatigue +
                weights[1] * engagementDecline +
                weights[2] * diversityPenalty));

        double diversityIndex = calculateDiversityIndex(formatHistory);

        // 4. 决策
        double interventionThreshold = configService.getInterventionThreshold();
        boolean needIntervention = fatigueScore >= interventionThreshold;
        String fatigueLevel = classifyFatigueLevel(fatigueScore);

        FormatSuggestion suggestion = null;
        String nextAction = "CONTINUE_CURRENT_FORMAT";

        if (needIntervention) {
            suggestion = recommendNextFormat(
                    userId, formatHistory, state, request, fatigueScore);
            nextAction = fatigueScore >= configService.getForceSwitchThreshold()
                    ? "FORCE_FORMAT_SWITCH" : "SUGGEST_FORMAT_SWITCH";

            eventLogger.log(FatigueEvent.builder()
                    .eventType("FATIGUE_DETECTED")
                    .userId(userId)
                    .sessionId(sessionId)
                    .triggerFormat(state.getCurrentFormat())
                    .fatigueScore(fatigueScore)
                    .streakCount(state.getCurrentStreak())
                    .diversityIndex(diversityIndex)
                    .recommendedFormat(suggestion.getFormat())
                    .build());
        }

        // 5. 更新 Redis 状态
        state.setFatigueScore(fatigueScore);
        state.setDiversityIndex(diversityIndex);
        state.setSuggestedNextFormat(suggestion != null ? suggestion.getFormat() : null);
        saveSessionState(sessionId, state);

        return FatigueAssessment.builder()
                .fatigueScore(fatigueScore)
                .streakFatigue(streakFatigue)
                .engagementDecline(engagementDecline)
                .diversityPenalty(diversityPenalty)
                .currentFormat(state.getCurrentFormat())
                .currentStreak(state.getCurrentStreak())
                .diversityIndex(diversityIndex)
                .needIntervention(needIntervention)
                .fatigueLevel(fatigueLevel)
                .suggestedNextFormat(suggestion)
                .nextAction(nextAction)
                .build();
    }

    /**
     * 获取形式建议
     */
    public FormatSuggestion suggest(FormatSuggestionRequest request) {
        String sessionId = request.getSessionId();
        long userId = request.getUserId();

        SessionFormatState state = loadSessionState(sessionId);
        List<ContentFormat> history = loadFormatHistory(sessionId);

        return recommendNextFormat(userId, history, state, 
                FatigueAssessRequest.newBuilder()
                        .setSessionId(sessionId)
                        .setUserId(userId)
                        .setGradeLevel(request.getGradeLevel())
                        .build(),
                state.getFatigueScore());
    }

    /**
     * 记录形式切换反馈
     */
    public void recordFeedback(FormatSwitchFeedback feedback) {
        eventLogger.log(FatigueEvent.builder()
                .eventType("FORMAT_SWITCHED")
                .userId(feedback.getUserId())
                .sessionId(feedback.getSessionId())
                .triggerFormat(feedback.getPreviousFormat())
                .recommendedFormat(feedback.getRecommendedFormat())
                .actualNextFormat(feedback.getActualFormat())
                .accepted(feedback.isAcceptedRecommendation())
                .build());

        // 如果接受了推荐，重置 streak
        if (feedback.isAcceptedRecommendation()) {
            SessionFormatState state = loadSessionState(feedback.getSessionId());
            state.setCurrentFormat(feedback.getActualFormat());
            state.setCurrentStreak(1);
            saveSessionState(feedback.getSessionId(), state);
        }

        // 更新用户形式偏好
        preferenceService.updatePreference(
                feedback.getUserId(),
                feedback.getActualFormat(),
                feedback.isAcceptedRecommendation() ? 0.05 : -0.02);
    }

    // ==================== 私有方法 ====================

    private void updateSessionFormatSequence(String sessionId, ContentConsumptionEvent event) {
        String key = SESSION_KEY_PREFIX + sessionId + FORMAT_SEQ_SUFFIX;
        long ts = Instant.now().toEpochMilli();
        String member = ts + ":" + event.getContentFormat() + ":" + event.getContentId();
        redis.opsForZSet().add(key, member, ts);
        redis.expire(key, SESSION_TTL);

        // 保留最近100条
        Long size = redis.opsForZSet().size(key);
        if (size != null && size > 100) {
            redis.opsForZSet().removeRange(key, 0, size - 101);
        }
    }

    private void updateSessionState(String sessionId, ContentConsumptionEvent event) {
        String key = SESSION_KEY_PREFIX + sessionId + STATE_SUFFIX;
        String prevFormat = (String) redis.opsForHash().get(key, "current_format");

        if (event.getContentFormat().equals(prevFormat)) {
            redis.opsForHash().increment(key, "current_streak", 1);
        } else {
            redis.opsForHash().put(key, "current_streak", "1");
        }
        redis.opsForHash().put(key, "current_format", event.getContentFormat());
        redis.opsForHash().put(key, "last_content_id", event.getContentId());
        redis.opsForHash().put(key, "last_update_ts", 
                String.valueOf(Instant.now().toEpochMilli()));
        redis.expire(key, SESSION_TTL);
    }

    private void addEngagementSignal(String sessionId, ContentConsumptionEvent event) {
        String key = SESSION_KEY_PREFIX + sessionId + SIGNALS_SUFFIX;
        String signal = gson.toJson(Map.of(
                "format", event.getContentFormat(),
                "ts", Instant.now().getEpochSecond(),
                "completion", event.getCompletionRate(),
                "time_spent", event.getDurationSeconds(),
                "interactions", event.getInteractions(),
                "skipped", event.isSkipped()
        ));
        redis.opsForList().leftPush(key, signal);
        redis.opsForList().trim(key, 0, 19); // 保留最近20条
        redis.expire(key, SESSION_TTL);
    }

    @SuppressWarnings("unchecked")
    private List<EngagementSignal> loadRecentSignals(String sessionId) {
        String key = SESSION_KEY_PREFIX + sessionId + SIGNALS_SUFFIX;
        List<String> raw = redis.opsForList().range(key, 0, 19);
        if (raw == null || raw.isEmpty()) return Collections.emptyList();
        return raw.stream()
                .map(s -> gson.fromJson(s, EngagementSignal.class))
                .collect(Collectors.toList());
    }

    private List<ContentFormat> loadFormatHistory(String sessionId) {
        String key = SESSION_KEY_PREFIX + sessionId + FORMAT_SEQ_SUFFIX;
        Set<String> members = redis.opsForZSet().range(key, 0, -1);
        if (members == null || members.isEmpty()) return Collections.emptyList();
        return members.stream()
                .map(m -> {
                    String[] parts = m.split(":");
                    return ContentFormat.valueOf(parts[1]);
                })
                .collect(Collectors.toList());
    }

    private SessionFormatState loadSessionState(String sessionId) {
        String key = SESSION_KEY_PREFIX + sessionId + STATE_SUFFIX;
        Map<Object, Object> raw = redis.opsForHash().entries(key);
        if (raw == null || raw.isEmpty()) {
            return new SessionFormatState();
        }
        SessionFormatState state = new SessionFormatState();
        state.setCurrentFormat((String) raw.get("current_format"));
        state.setCurrentStreak(Integer.parseInt((String) raw.getOrDefault("current_streak", "0")));
        state.setFatigueScore(Double.parseDouble((String) raw.getOrDefault("fatigue_score", "0")));
        state.setDiversityIndex(Double.parseDouble(
                (String) raw.getOrDefault("diversity_index", "0")));
        return state;
    }

    private void saveSessionState(String sessionId, SessionFormatState state) {
        String key = SESSION_KEY_PREFIX + sessionId + STATE_SUFFIX;
        Map<String, String> map = new HashMap<>();
        map.put("current_format", state.getCurrentFormat());
        map.put("current_streak", String.valueOf(state.getCurrentStreak()));
        map.put("fatigue_score", String.valueOf(state.getFatigueScore()));
        map.put("diversity_index", String.valueOf(state.getDiversityIndex()));
        map.put("suggested_next_format", 
                state.getSuggestedNextFormat() != null ? state.getSuggestedNextFormat() : "");
        map.put("last_update_ts", String.valueOf(Instant.now().toEpochMilli()));
        redis.opsForHash().putAll(key, map);
        redis.expire(key, SESSION_TTL);
    }

    private String classifyFatigueLevel(double score) {
        if (score <= 25) return "LOW";
        if (score <= 55) return "MODERATE";
        if (score <= 75) return "HIGH";
        return "CRITICAL";
    }

    private double linearRegressionSlope(double[] y) {
        int n = y.length;
        double sumX = 0, sumY = 0, sumXY = 0, sumXX = 0;
        for (int i = 0; i < n; i++) {
            sumX += i;
            sumY += y[i];
            sumXY += i * y[i];
            sumXX += (long) i * i;
        }
        double denominator = n * sumXX - sumX * sumX;
        if (denominator == 0) return 0;
        return (n * sumXY - sumX * sumY) / denominator;
    }
}
```

```java
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

import java.time.LocalDate;
import java.util.*;

@Slf4j
@Component
@RequiredArgsConstructor
public class FatigueBaselineScheduler {

    private final FormatEngagementBaselineRepository baselineRepo;
    private final SessionFormatSnapshotRepository snapshotRepo;
    private final FormatFatigueEventLogRepository eventLogRepo;

    /**
     * 每天凌晨3点，基于前一天数据更新形式参与度基线
     */
    @Scheduled(cron = "0 0 3 * * ?")
    public void updateBaselines() {
        log.info("[FatigueBaseline] 开始更新形式参与度基线...");
        
        LocalDate yesterday = LocalDate.now().minusDays(1);
        
        // 按用户+形式聚合昨天的参与度数据
        List<FormatEngagementStats> stats = snapshotRepo.aggregateDailyStats(yesterday);
        
        int updated = 0;
        for (FormatEngagementStats stat : stats) {
            FormatEngagementBaseline baseline = baselineRepo
                    .findByUserIdAndFormatAndGrade(stat.getUserId(), stat.getFormat(), stat.getGrade())
                    .orElse(new FormatEngagementBaseline(stat.getUserId(), stat.getFormat(), stat.getGrade()));
            
            // 指数移动平均（EMA）更新基线
            double alpha = 0.3; // 新数据权重
            baseline.setAvgCompletionRate(
                    baseline.getAvgCompletionRate() * (1 - alpha) + stat.getAvgCompletion() * alpha);
            baseline.setAvgEngagementTime(
                    (int)(baseline.getAvgEngagementTime() * (1 - alpha) + stat.getAvgTime() * alpha));
            baseline.setAvgSkipRate(
                    baseline.getAvgSkipRate() * (1 - alpha) + stat.getSkipRate() * alpha);
            
            // 动态调整疲劳阈值
            int newThreshold = calculateAdaptiveThreshold(stat);
            baseline.setFatigueThreshold(newThreshold);
            
            baseline.setSampleCount(baseline.getSampleCount() + stat.getSampleCount());
            baselineRepo.save(baseline);
            updated++;
        }
        
        log.info("[FatigueBaseline] 更新完成，共更新 {} 条基线记录", updated);
    }

    /**
     * 自适应疲劳阈值：如果该形式的完成率普遍较高，
     * 说明学生耐受度好，可以适当放宽阈值；反之收紧。
     */
    private int calculateAdaptiveThreshold(FormatEngagementStats stats) {
        double completion = stats.getAvgCompletion();
        int baseThreshold = 4; // 默认连续4次触发疲劳
        
        if (completion > 0.9) return Math.min(6, baseThreshold + 1);
        if (completion < 0.6) return Math.max(2, baseThreshold - 1);
        return baseThreshold;
    }

    /**
     * 每周一生成上周形式疲劳周报
     */
    @Scheduled(cron = "0 0 6 * * MON")
    public void generateWeeklyReport() {
        LocalDate weekStart = LocalDate.now().minusDays(7);
        LocalDate weekEnd = LocalDate.now().minusDays(1);
        
        List<FormatFatigueWeeklyStats> weeklyStats = eventLogRepo
                .aggregateWeeklyStats(weekStart, weekEnd);
        
        // 写入运营看板 / 发送给产品团队
        log.info("[FatigueBaseline] 周报生成完成，{} 条统计", weeklyStats.size());
        // TODO: 推送到运营看板服务
    }
}
```

### 6.3 多样性约束过滤器（供推荐引擎调用）

```java
package com.primetop.learning.fatigue.filter;

import com.primetop.learning.fatigue.model.*;
import com.primetop.learning.fatigue.service.FatigueScheduleService;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;

import java.util.*;
import java.util.stream.Collectors;

/**
 * 形式多样性约束过滤器
 * 嵌入推荐引擎的候选筛选阶段
 */
@Component
@RequiredArgsConstructor
public class DiversityConstraintFilter {

    private final FatigueScheduleService fatigueService;
    private final FatigueConfigService configService;

    /**
     * 对推荐引擎的候选列表进行形式约束过滤
     *
     * @param candidates 候选内容列表（已按知识点/难度匹配）
     * @param sessionId 当前会话ID
     * @return 过滤后的候选列表
     */
    public List<CandidateContent> filter(List<CandidateContent> candidates, String sessionId) {
        DiversityConstraint constraint = configService.getDiversityConstraint();
        List<ContentFormat> history = fatigueService.loadFormatHistory(sessionId);

        // 按形式分组
        Map<ContentFormat, List<CandidateContent>> byFormat = candidates.stream()
                .collect(Collectors.groupingBy(CandidateContent::getFormat));

        List<CandidateContent> filtered = new ArrayList<>();
        
        for (CandidateContent candidate : candidates) {
            if (checkConstraint(history, candidate.getFormat(), constraint)) {
                filtered.add(candidate);
            }
        }

        // 如果过滤后候选不足，逐步放宽约束
        if (filtered.size() < 5) {
            log.warn("[DiversityFilter] 过滤后候选不足({}条)，放宽约束", filtered.size());
            DiversityConstraint relaxed = constraint.toBuilder()
                    .maxSameFormat(constraint.getMaxSameFormat() + 1)
                    .maxSameCategory(constraint.getMaxSameCategory() + 1)
                    .build();
            filtered = candidates.stream()
                    .filter(c -> checkConstraint(history, c.getFormat(), relaxed))
                    .collect(Collectors.toList());
        }

        // 最终兜底：返回原始候选
        return filtered.isEmpty() ? candidates : filtered;
    }

    private boolean checkConstraint(
            List<ContentFormat> history, 
            ContentFormat candidate,
            DiversityConstraint constraint) {
        
        List<ContentFormat> window = new ArrayList<>(history);
        window.add(candidate);
        
        int windowSize = constraint.getWindowSize();
        if (window.size() > windowSize) {
            window = window.subList(window.size() - windowSize, window.size());
        }
        if (window.size() < 2) return true;

        // 检查同形式计数
        long sameFormatCount = window.stream()
                .filter(f -> f == candidate).count();
        if (sameFormatCount > constraint.getMaxSameFormat()) return false;

        // 检查同类别计数
        FormatCategory cat = FormatClassifier.classify(candidate);
        long sameCategoryCount = window.stream()
                .map(FormatClassifier::classify)
                .filter(cat::equals).count();
        if (sameCategoryCount > constraint.getMaxSameCategory()) return false;

        return true;
    }
}
```

## 7. 错误处理与降级策略

### 7.1 错误场景与处理

| 场景 | 触发原因 | 处理策略 |
|------|---------|---------|
| Redis 不可用 | 网络抖动/Redis宕机 | 降级为"无疲劳干预"模式，编排引擎按原有逻辑运行；本地缓存最近一次成功评估的快照 |
| 基线数据缺失 | 新用户/新形式无历史数据 | 使用全局默认基线（streak阈值=4，completion=0.8） |
| 评估超时 (>50ms) | 数据量大/计算复杂 | 异步评估：先返回默认（无干预），后续异步更新；保证主流程不被阻塞 |
| 推荐形式无内容 | 知识点不支持该形式 | 降级为备选形式（alternatives列表中的下一个） |
| 形式历史数据为空 | 会话刚开始 | 返回疲劳度0，nextAction=CONTINUE |

### 7.2 降级链路

```
正常链路：
编排引擎 → 疲劳调度引擎(Redis+MySQL) → 返回评估+建议

降级链路1（Redis不可用）：
编排引擎 → 疲劳调度引擎 → Redis失败 → 返回默认值{fatigue:0, action:CONTINUE}
编排引擎 → 不感知异常，继续正常流程

降级链路2（评估超时）：
编排引擎 → 疲劳调度引擎(50ms超时) → 超时 → 返回默认值
异步线程继续计算 → 写入Redis → 下次请求时生效

降级链路3（推荐形式无内容）：
疲劳调度推荐 FLASHCARD → 内容服务返回空 → 
自动降级到 alternatives[0] → 仍为空 → 
降级到 ACTIVE_PRACTICE → 仍为空 → 
取消形式约束，返回任意可用内容
```

### 7.3 异常码定义

| 错误码 | 含义 | HTTP Status |
|--------|------|-------------|
| FATIGUE_001 | 会话不存在或已过期 | 404 |
| FATIGUE_002 | 用户ID与会话不匹配 | 403 |
| FATIGUE_003 | 参数校验失败 | 400 |
| FATIGUE_004 | Redis操作失败（降级模式） | 200（降级响应） |
| FATIGUE_005 | 评估超时（降级响应） | 200（降级响应） |
| FATIGUE_006 | 基线数据缺失（使用默认值） | 200（正常响应） |
