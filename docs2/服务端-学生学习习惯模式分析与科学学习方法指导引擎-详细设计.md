# 服务端-学生学习习惯模式分析与科学学习方法指导引擎-详细设计

> **文档版本**: v1.0  
> **创建日期**: 2026-06-23  
> **所属模块**: 学情分析服务域  
> **关联模块**: 学习记录服务、学情分析服务、AI辅导服务、学习规划服务、通知服务

## 1. 模块概述

### 1.1 功能定位

本引擎负责从学生日常学习行为数据中，**识别和量化学习习惯模式**（如集中突击 vs 分散学习、学科交替 vs 单科连续、主动回忆 vs 被动浏览等），将习惯模式与学习效果（知识点掌握度变化、答题正确率提升、遗忘曲线表现等）进行**关联分析**，最终为学生生成**个性化的科学学习方法改进建议**，为家长提供**学习习惯报告**，为推荐系统提供**学习策略维度的用户画像标签**。

### 1.2 与现有模块的边界

| 对比模块 | 关注点 | 本模块差异 |
|---------|--------|-----------|
| 用户学习专注力分析与高效学习时段识别引擎 | 识别"什么时间"学习最专注 | 本模块关注"怎么学"——策略、节奏、方法选择 |
| 学生学习投入度多维量化与学习效能综合评估引擎 | 量化"投入了多少"及"投入质量" | 本模块分析投入的"结构模式"并给出方法改进建议 |
| 学习路径效果分析与学习行为序列模式挖掘引擎 | 分析学习路径（先学什么后学什么）的效果 | 本模块分析的是学习行为的"策略模式"而非知识路径 |
| 学习习惯养成与打卡系统 | 通过打卡激励学生坚持学习 | 本模块是分析引擎，为打卡系统提供习惯诊断数据 |
| 学生认知负荷监测与学习内容难度动态调节引擎 | 监测认知负荷并调节难度 | 本模块提供习惯层面的诊断，负荷数据作为输入 |

### 1.3 核心价值

- **对学生**：帮助认识自己的学习习惯盲区（如"总是考前突击""从不复习错题"），获得量身定制的学习方法改进方案
- **对家长**：了解孩子不是"不努力"而是"方法不对"，获得具体的家庭辅导方向
- **对系统**：学习习惯画像提升推荐精准度，学习规划服务据此生成更合理的计划
- **对教研**：群体学习习惯数据帮助教研团队优化内容设计和教学策略

## 2. 学习习惯模式分类体系

### 2.1 习惯维度模型

基于学习科学（Learning Science）和循证教育学研究成果，定义以下六大习惯维度：

```
学习习惯模式分类体系
├── D1: 时间分布策略 (Temporal Distribution)
│   ├── D1.1 分散学习 vs 集中突击 (Spaced vs Massed)
│   ├── D1.2 学习时段稳定性 (Time Slot Consistency)
│   └── D1.3 学习节奏规律性 (Rhythm Regularity)
│
├── D2: 内容组织策略 (Content Organization)
│   ├── D2.1 学科交替 vs 单科连续 (Interleaving vs Blocking)
│   ├── D2.2 难度梯度选择 (Difficulty Progression)
│   └── D2.3 新旧内容比例 (New/Review Ratio)
│
├── D3: 认知策略选择 (Cognitive Strategy)
│   ├── D3.1 主动回忆 vs 被动重读 (Active Recall vs Passive Rereading)
│   ├── D3.2 练习产出率 (Active Production Ratio)
│   └── D3.3 追问深度 (Inquiry Depth)
│
├── D4: 复习策略 (Review Strategy)
│   ├── D4.1 错题复习及时性 (Error Review Timeliness)
│   ├── D4.2 间隔重复遵循度 (Spaced Repetition Adherence)
│   └── D4.3 旧知识回访频率 (Old Content Revisitation)
│
├── D5: 元认知策略 (Metacognitive Strategy)
│   ├── D5.1 学习计划遵循度 (Plan Adherence)
│   ├── D5.2 自我检测频率 (Self-testing Frequency)
│   └── D5.3 反思行为频率 (Reflection Frequency)
│
└── D6: 持久性与专注策略 (Persistence & Focus)
    ├── D6.1 单次会话长度分布 (Session Length Distribution)
    ├── D6.2 干扰中断频率 (Interruption Frequency)
    └── D6.3 任务完成率 (Task Completion Rate)
```

### 3.2 习惯指标计算公式

#### 3.2.1 分散指数 (Spaced Index, M-D1.1a) 与突击倾向指数 (Cramming Index, M-D1.1b)

**分散指数**衡量学习行为在时间上的分散程度。

```
给定时间窗口 W（默认最近14天），学科 S：

设学习日 = 该学科有学习行为的天数集合 {d₁, d₂, ..., dₙ}
设每日学习时长 = {t₁, t₂, ..., tₙ}
总学习时长 T = Σtᵢ

分散指数 = 1 - Gini系数({t₁/T, t₂/T, ..., tₙ/T})

其中 Gini 系数计算：
  G = (Σᵢ Σⱼ |tᵢ - tⱼ|) / (2n × T)

当所有日学习量相等时，Spaced Index = 1（完全分散）
当某一天占绝大部分时，Spaced Index → 0（高度集中）
```

**突击倾向指数**专门识别"考前突击"模式：

```
设窗口内有评估事件（考试/模拟）的时刻 E，
设 E 前3天的日均学习量为 T_pre，
设 E 前7~4天的日均学习量为 T_base。

突击倾向指数 = clamp((T_pre - T_base) / (T_pre + T_base), 0, 1)

当 T_pre ≈ T_base 时 → 0（无突击）
当 T_pre >> T_base 时 → 1（严重突击）
```

#### 3.2.2 时段一致性 (Time Slot Consistency, M-D1.2a)

```
将每天划分为6个时段：
  S1: 06:00-09:00 (晨间)
  S2: 09:00-12:00 (上午)
  S3: 13:00-17:00 (下午)
  S4: 18:00-21:00 (晚间)
  S5: 21:00-23:00 (夜修)
  S6: 23:00-06:00 (深夜，不推荐)

对最近28天（4周），计算每周在各时段的学习时长占比，
得到4组向量 V₁, V₂, V₃, V₄ ∈ ℝ⁶。

时段一致性 = 1 - (平均余弦距离 / 2)
         = (Σᵢ<ⱼ cos(Vᵢ, Vⱼ)) / C(4,2) × 0.5 + 0.5

取值范围调整到 [0, 1]，1 表示每周时段分布完全一致。
```

#### 3.2.3 周节奏稳定性 (Rhythm Regularity, M-D1.3a)

```
统计最近4周，每周7天（周一~周日）的学习时长向量：
W₁ = [m₁₁, m₁₂, ..., m₁₇]
W₂ = [m₂₁, m₂₂, ..., m₂₇]
W₃ = [m₃₁, m₃₂, ..., m₃₇]
W₄ = [m₄₁, m₄₂, ..., m₄₇]

周节奏稳定性 = 1 - (σ_across / μ_across)

其中对每个星期几 i：
  μᵢ = mean(m₁ᵢ, m₂ᵢ, m₃ᵢ, m₄ᵢ)
  σᵢ = std(m₁ᵢ, m₂ᵢ, m₃ᵢ, m₄ᵢ)

  μ_across = mean(μ₁, ..., μ₇)
  σ_across = mean(σ₁, ..., σ₇)

值域通过 clamp 归一化到 [0, 1]。
```

#### 3.2.4 交替指数 (Interleaving Index, M-D2.1a)

```
给定一个学习会话中的行为序列 A = [a₁, a₂, ..., aₙ]，
每个行为 aᵢ 有学科标签 s(aᵢ)。

统计学科切换次数：
  switches = Σᵢ₌₁ⁿ⁻¹ 1[s(aᵢ) ≠ s(aᵢ₊₁)]

交替指数 = switches / max(1, n-1)

= 0：全程只学一门学科（Blocking 策略）
→ 1：每次行为都在切换学科（极端 Interleaving）
```

#### 3.2.5 难度偏好斜率 (Difficulty Progression, M-D2.2a)

```
给定窗口内学生的答题序列，按时间排序：
Q = [(d₁, t₁), (d₂, t₂), ..., (dₙ, tₙ)]
其中 dᵢ 为题目难度（0~1），tᵢ 为时间序号。

对 (tᵢ, dᵢ) 做线性回归，斜率 β：

难度偏好斜率 = β

β > 0：倾向于先易后难（递进策略）
β < 0：倾向于先难后易（递减策略）
β ≈ 0：难度随机或不刻意排序
```

#### 3.2.6 主动回忆比 (Active Recall Ratio, M-D3.1a)

```
主动回忆行为定义：
  - 主动发起答题/测试（非作业驱动）
  - 尝试默写/背诵检测
  - 闪卡自我检测（Flashcard Self-Test）
  - 主动请求"出题考我"

被动浏览行为定义：
  - 纯阅读知识点讲解
  - 观看视频讲解
  - 浏览他人笔记
  - 回顾错题解析（仅看不做）

主动回忆比 = 主动回忆行为数 / (主动回忆行为数 + 被动浏览行为数)
```

#### 3.2.7 产出行为占比 (Active Production Ratio, M-D3.2a)

```
产出性行为：答题、写作、语音背诵、手写笔记、提问
消费性行为：阅读、观看、浏览、收听

产出行为占比 = 产出行为时长 / 总学习时长
```

#### 4.2.1 周度习惯指标计算任务

```java
/**
 * 每周日凌晨 02:00 执行的批量计算任务
 * 计算上周（周一~周日）的学生习惯指标
 */
@Scheduled(cron = "0 0 2 * * SUN")
public class WeeklyHabitMetricJob {
    
    // 分批处理，每批 500 学生
    private static final int BATCH_SIZE = 500;
    
    /**
     * 执行入口
     */
    public void execute() {
        LocalDate weekStart = LocalDate.now().minusWeeks(1)
            .with(TemporalAdjusters.previousOrSame(DayOfWeek.MONDAY));
        
        // 1. 获取活跃用户列表（上周有学习行为的用户）
        List<String> activeUsers = userRepository.findActiveUserIds(weekStart);
        
        // 2. 分批计算
        Lists.partition(activeUsers, BATCH_SIZE).forEach(batch -> {
            CompletableFuture.runAsync(() -> processBatch(batch, weekStart));
        });
    }
    
    /**
     * 处理一批学生的习惯指标
     */
    void processBatch(List<String> userIds, LocalDate weekStart) {
        for (String userId : userIds) {
            try {
                // 采集原始数据
                HabitRawData raw = collectRawData(userId, weekStart);
                
                // 数据完整度检查（至少3天有学习行为才计算）
                if (raw.activeDays < 3) {
                    markInsufficientData(userId, weekStart);
                    continue;
                }
                
                // 计算全学科指标
                HabitMetrics allSubjectMetrics = metricCalculator.calculate(raw);
                
                // 按学科分别计算（数据充足时）
                Map<String, HabitMetrics> subjectMetrics = new HashMap<>();
                for (String subject : raw.getCoveredSubjects()) {
                    if (raw.getActiveDays(subject) >= 3) {
                        subjectMetrics.put(subject, 
                            metricCalculator.calculate(raw, subject));
                    }
                }
                
                // 综合评分
                allSubjectMetrics.setHabitHealthScore(
                    healthScoreCalculator.calculate(allSubjectMetrics));
                
                // 生成标签
                List<HabitTag> tags = tagGenerator.generate(allSubjectMetrics);
                
                // 持久化
                persistMetrics(userId, weekStart, allSubjectMetrics, subjectMetrics);
                persistTags(userId, tags, weekStart);
                
                // 诊断问题 & 生成建议
                List<MethodRecommendation> recs = advisor.generateRecommendations(
                    allSubjectMetrics, raw.getUserGradeLevel());
                persistRecommendations(userId, weekStart, recs);
                
            } catch (Exception e) {
                log.error("习惯指标计算失败 userId={} week={}", userId, weekStart, e);
                metricRecorder.increment("habit.calc.error");
            }
        }
    }
}
```

### 4.3 习惯健康度评分算法

习惯健康度总分（0~100）基于各维度子得分加权汇总：

```java
/**
 * 习惯健康度评分计算器
 */
public class HabitHealthScoreCalculator {
    
    // 各维度权重（可根据学段调整）
    private static final Map<StudyPhase, Map<String, Double>> PHASE_WEIGHTS = Map.of(
        StudyPhase.PRIMARY, Map.of(
            "D1", 0.20,  // 小学阶段时间分布权重适中
            "D2", 0.10,
            "D3", 0.15,
            "D4", 0.15,
            "D5", 0.15,
            "D6", 0.25   // 小学更重专注和持久
        ),
        StudyPhase.JUNIOR, Map.of(
            "D1", 0.25,  // 初中开始强调分散学习
            "D2", 0.15,
            "D3", 0.20,
            "D4", 0.20,  // 复习策略权重增大
            "D5", 0.10,
            "D6", 0.10
        ),
        StudyPhase.SENIOR, Map.of(
            "D1", 0.25,
            "D2", 0.15,
            "D3", 0.20,
            "D4", 0.25,  // 高中复习策略最关键
            "D5", 0.10,
            "D6", 0.05
        )
    );
    
    /**
     * 计算习惯健康度总分
     */
    public double calculate(HabitMetrics metrics, StudyPhase phase) {
        Map<String, Double> weights = PHASE_WEIGHTS.getOrDefault(phase, 
            PHASE_WEIGHTS.get(StudyPhase.JUNIOR));
        
        double d1Score = calculateD1Score(metrics);
        double d2Score = calculateD2Score(metrics);
        double d3Score = calculateD3Score(metrics);
        double d4Score = calculateD4Score(metrics);
        double d5Score = calculateD5Score(metrics);
        double d6Score = calculateD6Score(metrics);
        
        double total = d1Score * weights.get("D1")
                      + d2Score * weights.get("D2")
                      + d3Score * weights.get("D3")
                      + d4Score * weights.get("D4")
                      + d5Score * weights.get("D5")
                      + d6Score * weights.get("D6");
        
        return Math.round(total * 100);
    }
    
    /**
     * D1: 时间分布策略子得分 (0~1)
     */
    private double calculateD1Score(HabitMetrics m) {
        // 分散学习越好（分散指数高、突击倾向低）
        double spacedScore = m.getSpacedIndex() * 0.4
                           + (1 - m.getCrammingIndex()) * 0.3
                           + m.getTimeSlotConsistency() * 0.15
                           + m.getRhythmRegularity() * 0.15;
        return clamp(spacedScore, 0, 1);
    }
    
    /**
     * D2: 内容组织策略子得分 (0~1)
     */
    private double calculateD2Score(HabitMetrics m) {
        // 适度交替、合理难度递进、适度复习
        // 交替指数最优区间为 0.2~0.5（不是越高越好）
        double interleaveScore = bellCurve(m.getInterleavingIndex(), 0.35, 0.2);
        double difficultyScore = m.getDifficultySlope() > 0 ? 0.8 : 0.5;
        double reviewScore = m.getReviewRatio() > 0.3 ? 0.8 : m.getReviewRatio() * 2.5;
        return clamp(interleaveScore * 0.4 + difficultyScore * 0.3 + reviewScore * 0.3, 0, 1);
    }
    
    /**
     * D3: 认知策略子得分 (0~1)
     */
    private double calculateD3Score(HabitMetrics m) {
        // 主动回忆比越高越好（最优 > 0.6）
        double recallScore = Math.min(1.0, m.getActiveRecallRatio() / 0.6);
        double prodScore = Math.min(1.0, m.getProductionRatio() / 0.5);
        double inquiryScore = Math.min(1.0, m.getAvgInquiryDepth() / 3.0);
        return clamp(recallScore * 0.5 + prodScore * 0.3 + inquiryScore * 0.2, 0, 1);
    }
    
    /**
     * D4: 复习策略子得分 (0~1)
     */
    private double calculateD4Score(HabitMetrics m) {
        // 错题复习延迟越小越好（理想 < 48小时）
        double delayScore = m.getErrorReviewDelayMedian() <= 0 ? 0 
            : Math.max(0, 1 - m.getErrorReviewDelayMedian() / 168); // 168h = 7天
        double adherenceScore = m.getSpacedRepetitionAdherence();
        double revisitScore = m.getOldContentRevisitIndex();
        return clamp(delayScore * 0.4 + adherenceScore * 0.35 + revisitScore * 0.25, 0, 1);
    }
    
    /**
     * D5: 元认知策略子得分 (0~1)
     */
    private double calculateD5Score(HabitMetrics m) {
        double planScore = m.getPlanCompletionRate();
        double selfTestScore = Math.min(1.0, m.getSelfTestFrequency() / 3.0);
        double reflectScore = Math.min(1.0, m.getReflectionBehaviorIndex() / 5.0);
        return clamp(planScore * 0.4 + selfTestScore * 0.35 + reflectScore * 0.25, 0, 1);
    }
    
    /**
     * D6: 持久性与专注子得分 (0~1)
     */
    private double calculateD6Score(HabitMetrics m) {
        // 会话长度变异系数越小越好（理想 < 0.5）
        double consistencyScore = Math.max(0, 1 - m.getSessionLengthCv() / 1.0);
        // 中断频率越小越好（理想 < 2次/小时）
        double focusScore = Math.max(0, 1 - m.getInterruptionRate() / 5.0);
        double taskScore = 1 - m.getTaskAbandonRate();
        return clamp(consistencyScore * 0.35 + focusScore * 0.35 + taskScore * 0.3, 0, 1);
    }
    
    /**
     * 钟形曲线评分：在最优值附近得分最高
     */
    private double bellCurve(double value, double optimal, double spread) {
        double z = (value - optimal) / spread;
        return Math.exp(-0.5 * z * z); // 标准正态密度
    }
    
    private double clamp(double v, double min, double max) {
        return Math.max(min, Math.min(max, v));
    }
}
```

### 5.2 建议生成服务

```java
/**
 * 学习方法建议生成器
 */
@Service
public class StudyMethodAdvisor {
    
    @Autowired
    private PromptTemplateService promptTemplateService;
    
    @Autowired
    private AIOrchestrator aiOrchestrator;
    
    /**
     * 基于习惯诊断结果生成个性化学习方法建议
     */
    public List<MethodRecommendation> generateRecommendations(
            HabitMetrics metrics, 
            StudyPhase phase,
            String gradeLevel) {
        
        // 1. 运行诊断规则，识别问题
        List<HabitDiagnosis> diagnoses = diagnose(metrics);
        
        // 2. 按优先级排序，取 Top 3
        List<HabitDiagnosis> topIssues = diagnoses.stream()
            .sorted(Comparator.comparingInt(HabitDiagnosis::getPriority))
            .limit(3)
            .collect(Collectors.toList());
        
        // 3. 为每个问题生成具体建议
        List<MethodRecommendation> recommendations = new ArrayList<>();
        for (HabitDiagnosis issue : topIssues) {
            MethodRecommendation rec = buildRecommendation(issue, metrics, phase);
            recommendations.add(rec);
        }
        
        // 4. 若无明显问题，生成维持型建议
        if (recommendations.isEmpty()) {
            recommendations.add(buildMaintenanceRecommendation(metrics, phase));
        }
        
        return recommendations;
    }
    
    /**
     * 构建单条建议
     */
    private MethodRecommendation buildRecommendation(
            HabitDiagnosis issue, HabitMetrics metrics, StudyPhase phase) {
        
        MethodTemplate template = MethodTemplateRegistry.get(issue.getCode());
        
        return MethodRecommendation.builder()
            .recommendationId(UUID.randomUUID().toString())
            .targetDimension(issue.getDimension())
            .issueCode(issue.getCode())
            .methodCode(template.getCode())
            .methodTitle(template.getTitle())
            .methodDetail(buildDetail(template, metrics, phase))
            .priority(issue.getPriority())
            .status("PENDING")
            .baselineScore(metrics.getDimensionScore(issue.getDimension()))
            .createdAt(Instant.now())
            .build();
    }
    
    /**
     * 构建建议详情（结构化 JSON）
     */

        detail.put("currentStatus", template.describeCurrent(metrics));
        detail.put("targetStatus", template.describeTarget());
        detail.put("actionSteps", template.getActionSteps(phase));
        detail.put("estimatedImprovement", template.getExpectedGain());
        detail.put("difficulty", template.getDifficulty());
```

## 8. 效果关联分析

### 8.1 习惯-效果关联模型

将习惯指标变化与学习效果指标变化做关联分析：

```java
/**
 * 习惯效果关联分析器
 * 每月运行一次，分析习惯改善与学习效果提升的相关性
 */
@Service
public class HabitEffectivenessAnalyzer {
    
    /**
     * 分析习惯改善对学习效果的影响
     * 
     * @param userId 学生ID
     * @param fromWeek 起始周
     * @param toWeek 结束周
     * @return 各维度改善与效果提升的关联报告
     */
    public HabitEffectivenessReport analyze(
            String userId, LocalDate fromWeek, LocalDate toWeek) {
        
        // 获取起止周的习惯指标
        HabitMetricSnapshot fromSnapshot = 
            metricRepository.findById(userId, fromWeek, "ALL");
        HabitMetricSnapshot toSnapshot = 
            metricRepository.findById(userId, toWeek, "ALL");
        
        // 获取起止周的学习效果指标
        LearningOutcomeSnapshot fromOutcome = 
            outcomeRepository.findById(userId, fromWeek);
        LearningOutcomeSnapshot toOutcome = 
            outcomeRepository.findById(userId, toWeek);
        
        List<DimensionCorrelation> correlations = new ArrayList<>();
        
        // 逐维度分析
        for (String dim : List.of("D1", "D2", "D3", "D4", "D5", "D6")) {
            double habitDelta = getDimensionScore(toSnapshot, dim) 
                              - getDimensionScore(fromSnapshot, dim);
            double outcomeDelta = toOutcome.getOverallScore() 
                                - fromOutcome.getOverallScore();
            
            correlations.add(new DimensionCorrelation(
                dim, habitDelta, outcomeDelta,
                interpretCorrelation(habitDelta, outcomeDelta)
            ));
        }
        
        return new HabitEffectivenessReport(
            userId, fromWeek, toWeek, correlations);
    }
    
    private String interpretCorrelation(double habitDelta, double outcomeDelta) {
        if (habitDelta > 0.05 && outcomeDelta > 2) 
            return "POSITIVE_EFFECT";  // 习惯改善→效果提升
        if (habitDelta < -0.05 && outcomeDelta < -2)
            return "NEGATIVE_EFFECT";  // 习惯恶化→效果下降
        if (Math.abs(habitDelta) < 0.02)
            return "STABLE";           // 习惯稳定
        return "INCONCLUSIVE";         // 无法确定
    }
}
```

### 8.2 群体习惯-效果统计

```sql
-- 查询：按习惯健康度分组的学习效果对比
SELECT 
    CASE 
        WHEN habit_health_score >= 80 THEN 'EXCELLENT'
        WHEN habit_health_score >= 65 THEN 'GOOD'
        WHEN habit_health_score >= 50 THEN 'FAIR'
        WHEN habit_health_score >= 35 THEN 'NEEDS_IMPROVEMENT'
        ELSE 'POOR'
    END AS habit_level,
    COUNT(DISTINCT user_id) AS user_count,
    AVG(active_recall_ratio) AS avg_recall,
    AVG(spaced_index) AS avg_spaced,
    AVG(error_review_delay_median) AS avg_error_delay,
    AVG(spaced_repetition_adherence) AS avg_sr_adherence
FROM habit_metric_snapshot
WHERE week_start_date = DATE_SUB(CURDATE(), INTERVAL WEEKDAY(CURDATE()) DAY)
    AND data_completeness > 0.6
GROUP BY habit_level
ORDER BY habit_level;
```

## 9. 错误处理与降级策略

### 9.1 计算任务错误处理

| 异常场景 | 处理策略 |
|---------|---------|
| 原始数据不足（activeDays < 3） | 标记 data_completeness，不计算指标，不下发建议 |
| 原始数据部分缺失（某维度指标无法计算） | 计算可得指标，缺失维度标记 NULL，健康度评分按可用维度加权 |
| 计算超时（单用户 > 30s） | 跳过该用户，记录告警，下一轮补算 |
| 数据库写入失败 | 重试3次（间隔5s/30s/120s），仍失败则写入死信队列人工介入 |
| 事件流积压 | 降级为仅计算全学科汇总指标，跳过分学科计算 |

### 9.2 查询服务降级

## 10. 性能设计

### 10.1 计算性能指标

| 指标 | 目标 |
|------|------|
| 单用户周度计算耗时 | < 2秒 |
| 全量用户（100万）周度计算总耗时 | < 4小时 |
| 查询API P99延迟 | < 200ms |
| 趋势查询（12周）P99延迟 | < 300ms |
| 建议生成（含AI增强）延迟 | < 5秒 |

### 10.2 优化策略

1. **增量计算**：仅计算本周新增数据，历史指标从快照表读取
2. **并行处理**：按用户分批并行，每批500用户，线程池大小20
3. **预聚合**：趋势查询所需的12周数据在写入时预聚合为JSON
4. **缓存策略**：
   - 查询结果缓存5分钟（Redis）
   - 习惯画像标签缓存1小时
   - 建议列表缓存直到状态变更
5. **冷热分离**：
   - 近4周快照：热数据，Redis + MySQL
   - 4周以上：仅MySQL，定期归档到冷存储

## 14. 安全与隐私

1. **数据最小化**：习惯分析仅使用学习行为数据，不采集设备指纹、位置等隐私信息
2. **未成年人保护**：家长端展示的建议不包含诊断负向表述，仅以积极引导方式呈现
3. **数据聚合**：群体对比分析使用最小5人聚合，避免个体可识别
4. **数据保留**：习惯快照保留2年，超期归档；建议记录保留1年
5. **权限控制**：仅学生本人、绑定的家长、授权的教师可查看对应数据
