# 客户端 - 元素周期表交互组件与化学学科工具集 - 详细设计

> 版本：1.0 | 日期：2026-06-10 | 模块代号：`chem-tools`

## 1. 模块定位与边界

### 1.1 模块职责

化学学科工具集是客户端侧的**交互式化学学习组件库**，提供元素周期表交互浏览、元素详情展示、化学方程式速查与配平辅助、常见物质性质卡片等可视化工具，帮助初中和高中学生在解题、复习过程中快速获取化学学科基础信息。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 直观浏览 | 可缩放、可点击的交互式元素周期表，替代纸质查阅 |
| 分龄呈现 | 初中显示基础属性（原子序数、符号、相对原子质量），高中增加电子排布、电负性等 |
| 上下文联动 | AI 解答中出现元素符号时，可一键跳转元素详情 |
| 离线可用 | 元素数据全部内嵌本地资源包，无需网络 |
| 考试友好 | 提供常见元素速查卡片，支持按族/周期快速定位 |

### 1.3 依赖模块

| 模块 | 依赖方式 |
|------|----------|
| 学科工具与参考资料库（服务端） | 提供元素数据、方程式数据的版本管理与增量更新 |
| 客户端资源包下载管理器 | 化学数据包的下载、缓存、版本校验 |
| 客户端主题引擎 | 分龄主题适配（初中 vs 高中色彩方案） |
| 客户端路由与深链接系统 | 支持从 AI 对话跳转到指定元素 `primetop://chem/element/{symbol}` |
| 客户端组件库与设计系统 | 卡片、BottomSheet、搜索栏等基础组件 |
| 富文本与学科内容渲染引擎 | 化学方程式在 AI 回答中的渲染 |

### 1.4 不负责

- **化学方程式渲染**：由富文本渲染引擎负责（`$$\ce{...}$$` LaTeX mhchem 语法）
- **化学内容教学**：由同步课堂和 AI 辅导模块负责
- **化学实验模拟**：V2.0+ 远期功能，不在本文档范围

### 1.5 版本规划

| 阶段 | 范围 |
|------|------|
| V1.0（P0） | 交互式元素周期表 + 元素详情页 |
| V1.5（P1） | 化学方程式速查 + 常见离子/物质颜色卡片 |
| V2.0（P2） | 方程式配平辅助工具 + 分子结构简图 |

## 2. 数据结构设计

### 2.1 元素数据模型

元素数据以 JSON 资源包形式内嵌客户端，由资源包下载管理器负责版本更新。

#### 2.1.1 元素实体（ElementEntity）

```dart
/// 化学元素数据模型
class ChemElement {
  /// 原子序数（唯一标识）
  final int atomicNumber;

  /// 元素符号（如 "Fe"）
  final String symbol;

  /// 中文名称（如 "铁"）
  final String nameZh;

  /// 英文名称（如 "Iron"）
  final String nameEn;

  /// 相对原子质量（精确到小数点后 2 位）
  final double relativeAtomicMass;

  /// 元素类别
  final ElementCategory category;

  /// 周期（1-7）
  final int period;

  /// 族（1-18，镧系/锕系为特殊标记）
  final int group;

  /// 区（s/p/d/f）
  final String block;

  /// 电子排布（高中）- 如 "[Ar] 3d⁶ 4s²"
  final String? electronConfiguration;

  /// 电子层排布（初中）- 如 "2, 8, 14, 2"
  final String? electronShellConfig;

  /// 电负性（鲍林标度，高中）
  final double? electronegativity;

  /// 常见化合价（如 ["+2", "+3"]）
  final List<String> commonValences;

  /// 物态（常温）: solid / liquid / gas / unknown
  final PhysicalState stateAtRT;

  /// 密度（g/cm³）
  final double? density;

  /// 熔点（°C）
  final double? meltingPoint;

  /// 沸点（°C）
  final double? boilingPoint;

  /// 发现年份
  final int? discoveredYear;

  /// 周期表格位置（用于布局）
  final PeriodicTablePosition position;

  /// 初中必学元素标记
  final bool isJuniorRequired;

  /// 高中必学元素标记
  final bool isSeniorRequired;

  /// 元素简介（2-3 句话，分学段）
  final Map<StudentPhase, String> description;

  /// 常见化合物示例
  final List<CompoundExample> commonCompounds;

  /// 原子结构示意图资源路径（SVG）
  final String? atomDiagramAsset;
}
```

#### 3.1.2 Flutter 布局方案

采用 `CustomMultiChildLayout` 实现绝对定位网格，保证元素格子精确对齐。

```dart
class PeriodicTableView extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return InteractiveViewer(
      minScale: 0.5,
      maxScale: 3.0,
      child: CustomMultiChildLayout(
        delegate: PeriodicTableLayoutDelegate(),
        children: _buildElementCells(),
      ),
    );
  }

  List<Widget> _buildElementCells() {
    return elements.map((e) {
      return LayoutId(
        id: e.atomicNumber,
        child: ElementCell(element: e),
      );
    }).toList();
  }
}
```

#### 3.2.3 元素格子交互状态

```dart
class ElementCell extends StatefulWidget {
  final ChemElement element;
  final StudentPhase phase;
  final VoidCallback? onTap;
  final bool highlightValence;  // 高亮化合价模式
  final bool highlightState;    // 高亮物态模式

  @override
  State<ElementCell> createState() => _ElementCellState();
}

class _ElementCellState extends State<ElementCell>
    with SingleTickerProviderStateMixin {
  late AnimationController _hoverController;

  // 状态：normal → hover（桌面端）→ pressed → tapped
  // 视觉反馈：hover 放大 1.05 + 阴影增强，pressed 缩小 0.95

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: widget.onTap,
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 150),
        decoration: BoxDecoration(
          color: _getBackgroundColor(),
          borderRadius: BorderRadius.circular(4),
          border: _isSelected
              ? Border.all(color: AppColors.primary, width: 2)
              : null,
          boxShadow: _isHovered
              ? [BoxShadow(color: Colors.black26, blurRadius: 4, offset: Offset(0, 2))]
              : [],
        ),
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('${widget.element.atomicNumber}',
                style: TextStyle(fontSize: 10, color: Colors.grey[600])),
            Text(widget.element.symbol,
                style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
            if (widget.phase == StudentPhase.junior)
              Text(widget.element.nameZh,
                  style: TextStyle(fontSize: 8)),
            if (widget.phase == StudentPhase.senior)
              Text('${widget.element.relativeAtomicMass}',
                  style: TextStyle(fontSize: 8, color: Colors.grey[700])),
          ],
        ),
      ),
    );
  }
}
```

### 4.4 原子结构示意图渲染

原子结构示意图是初中化学的核心图示（同心圆 + 电子分布）。使用 Flutter `CustomPainter` 绘制：

```dart
class AtomStructurePainter extends CustomPainter {
  final List<int> electronShells; // 如 [2, 8, 14, 2] 表示 Fe
  final Color primaryColor;

  AtomStructurePainter({
    required this.electronShells,
    this.primaryColor = Colors.blue,
  });

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final maxRadius = min(size.width, size.height) / 2 - 8;

    // 绘制原子核
    final nucleusPaint = Paint()
      ..color = Colors.grey[700]!
      ..style = PaintingStyle.fill;
    canvas.drawCircle(center, 12, nucleusPaint);

    // 绘制 "+" 号
    final plusPaint = Paint()
      ..color = Colors.white
      ..strokeWidth = 2;
    canvas.drawLine(
      Offset(center.dx - 5, center.dy),
      Offset(center.dx + 5, center.dy),
      plusPaint,
    );
    canvas.drawLine(
      Offset(center.dx, center.dy - 5),
      Offset(center.dx, center.dy + 5),
      plusPaint,
    );

    // 绘制各电子层
    for (int i = 0; i < electronShells.length; i++) {
      final shellRadius = 20.0 + (i + 1) * ((maxRadius - 20) / electronShells.length);

      // 电子层圆弧
      final shellPaint = Paint()
        ..color = Colors.grey[300]!
        ..style = PaintingStyle.stroke
        ..strokeWidth = 1;
      canvas.drawCircle(center, shellRadius, shellPaint);

      // 电子
      final electronCount = electronShells[i];
      final electronPaint = Paint()
        ..color = primaryColor
        ..style = PaintingStyle.fill;

      for (int j = 0; j < electronCount; j++) {
        final angle = (2 * pi * j / electronCount) - pi / 2;
        final ex = center.dx + shellRadius * cos(angle);
        final ey = center.dy + shellRadius * sin(angle);
        canvas.drawCircle(Offset(ex, ey), 4, electronPaint);
      }
    }
  }

  @override
  bool shouldRepaint(covariant AtomStructurePainter oldDelegate) {
    return oldDelegate.electronShells != electronShells;
  }
}
```

### 5.3 搜索与筛选

```dart
class EquationSearchController {
  /// 搜索维度
  String? keyword;          // 关键词（方程式内容、物质名称）
  ReactionType? type;       // 反应类型筛选
  String? knowledgePointId; // 按知识点筛选
  String? elementSymbol;    // 按涉及元素筛选
  StudentPhase phase;       // 学段过滤

  /// 搜索方法
  List<ChemicalEquation> search(List<ChemicalEquation> all) {
    return all.where((eq) {
      // 学段过滤
      if (phase != StudentPhase.senior && eq.phase == StudentPhase.senior) {
        return false;
      }
      // 反应类型过滤
      if (type != null && eq.reactionType != type) return false;
      // 元素过滤
      if (elementSymbol != null && !eq.relatedElements.contains(elementSymbol)) return false;
      // 关键词过滤
      if (keyword != null && keyword!.isNotEmpty) {
        final kw = keyword!.toLowerCase();
        return eq.plainTextFormula.toLowerCase().contains(kw) ||
            eq.textbookTags.any((t) => t.contains(kw)) ||
            (eq.phenomenon?.toLowerCase().contains(kw) ?? false);
      }
      // 知识点过滤
      if (knowledgePointId != null && !eq.knowledgePointIds.contains(knowledgePointId)) return false;
      return true;
    }).toList();
  }
}
```

```dart
class ChemDataRepository {
  final ResourcePackageManager _packageManager;
  static const String _chemDataPackageId = 'chem_tools';

  List<ChemElement>? _cachedElements;
  List<ChemicalEquation>? _cachedEquations;

  /// 初始化：加载本地数据包
  Future<void> initialize() async {

    if (manifest == null) {
      // 首次使用：使用内置 assets 作为兜底
      await _loadFromBundledAssets();
    } else {
      await _loadFromCache(manifest);
    }
  }

  /// 检查更新
  Future<void> checkForUpdates() async {
    await _packageManager.checkAndUpdate(_chemDataPackageId);
    await _reloadFromCache();
  }

  Future<void> _loadFromBundledAssets() async {
    final jsonStr = await rootBundle.loadString('assets/chem_data/elements.json');
    final List<dynamic> jsonList = jsonDecode(jsonStr);
    _cachedElements = jsonList.map((e) => ChemElement.fromJson(e)).toList();
  }
}
```

```dart
class ElementSearchDelegate extends SearchDelegate<ChemElement?> {
  final List<ChemElement> elements;
  final StudentPhase phase;

  ElementSearchDelegate({required this.elements, required this.phase});

  @override
  List<Widget> buildActions(BuildContext context) {
    return [IconButton(icon: Icon(Icons.clear), onPressed: () => query = '')];
  }

  @override
  Widget buildLeading(BuildContext context) {
    return IconButton(icon: Icon(Icons.arrow_back), onPressed: () => close(context, null));
  }

  @override
  Widget buildResults(BuildContext context) {
    return _buildSearchList();
  }

  @override
  Widget buildSuggestions(BuildContext context) {
    return _buildSearchList();
  }

  Widget _buildSearchList() {
    final q = query.toLowerCase().trim();
    if (q.isEmpty) {
      return Center(child: Text('输入元素名称、符号或原子序数'));
    }

    final results = elements.where((e) {
      return e.symbol.toLowerCase().startsWith(q) ||
          e.nameZh.contains(q) ||
          e.nameEn.toLowerCase().startsWith(q) ||
          e.atomicNumber.toString() == q;
    }).toList();

    if (results.isEmpty) {
      return Center(child: Text('未找到匹配的元素'));
    }

    return ListView.builder(
      itemCount: results.length,
      itemBuilder: (ctx, i) {
        final e = results[i];
        return ListTile(
          leading: CircleAvatar(
            backgroundColor: ElementCategoryColors.light[e.category],
            child: Text(e.symbol, style: TextStyle(fontSize: 14, fontWeight: FontWeight.bold)),
          ),
          title: Text('${e.nameZh} (${e.symbol})'),
          subtitle: Text('原子序数 ${e.atomicNumber} · 相对原子质量 ${e.relativeAtomicMass}'),
          onTap: () => close(context, e),
        );
      },
    );
  }
}
```
