# 服务端-统一文档预览与多格式文件转换服务 详细设计

## 1. 概述

### 1.1 模块定位

统一文档预览与多格式文件转换服务（Document Preview & Conversion Service，简称 DPCS）是 PrimeTop 教育平台的基础设施层服务，负责将教师上传的 Word/PPT/Excel/PDF 等办公文档、教研团队制作的试卷/课件、以及用户提交的作文/作业等各类文件转换为可在移动端、Web 端统一预览的格式（图片、PDF、HTML），并提供缩略图生成、水印嵌入、页面提取、内容提取等能力。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 格式转换 | 将 Word(.doc/.docx)、PPT(.ppt/.pptx)、Excel(.xls/.xlsx)、PDF、ODT 等格式转换为 PDF、图片(PNG/JPEG)、HTML |
| 文档预览 | 生成分页预览图、缩略图、低清/高清预览，支持按页请求 |
| 水印嵌入 | 对预览图片/PDF 嵌入用户身份水印（学号、姓名、时间戳），用于版权保护与泄密追溯 |
| 文本提取 | 从文档中提取纯文本内容，供全文检索、AI 辅导引用、内容审核 |
| 页面操作 | 支持按页拆分、页面合并、指定页面提取（如只预览前 N 页） |
| 内容保护 | 转换结果加密、防盗链、访问令牌控制 |

### 1.4 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| 文档转换引擎 | LibreOffice (headless mode) | 开源、成熟、支持格式全面（Word/PPT/Excel/PDF/ODT）、Docker 部署友好 |
| PDF 处理 | PyMuPDF (fitz) | 高性能 PDF 页面渲染为图片、文本提取、页面操作 |
| 辅助转换 | Pandoc | Markdown/HTML/Word 互转，轻量快速 |
| 图片处理 | Pillow (Python) | 缩略图生成、水印嵌入、图片压缩 |
| 任务队列 | Celery + Redis | 异步转换任务调度、重试、优先级 |
| 缓存 | Redis | 转换结果缓存、任务状态缓存 |
| 对象存储 | MinIO / 阿里云 OSS | 原始文件与转换结果存储 |
| 服务框架 | FastAPI (Python) | 异步 API、自带 OpenAPI 文档 |

## 2. 数据模型

### 2.1 核心实体

#### 2.1.1 转换任务表 `dpcs_convert_tasks`

```sql
CREATE TABLE dpcs_convert_tasks (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '任务ID',
    task_uuid       VARCHAR(36) NOT NULL UNIQUE COMMENT '任务UUID(对外暴露)',
    source_file_key VARCHAR(512) NOT NULL COMMENT '原始文件在对象存储中的key',
    source_file_name VARCHAR(255) NOT NULL COMMENT '原始文件名(含扩展名)',
    source_format   VARCHAR(20) NOT NULL COMMENT '源格式: docx, pptx, xlsx, pdf, odt...',
    source_size     BIGINT NOT NULL DEFAULT 0 COMMENT '原始文件大小(字节)',
    source_md5      VARCHAR(32) NOT NULL COMMENT '原始文件MD5',
    target_format   VARCHAR(20) NOT NULL COMMENT '目标格式: pdf, png, jpeg, html, txt',
    options_json    JSON COMMENT '转换选项(水印、分辨率、页面范围等)',
    status          VARCHAR(20) NOT NULL DEFAULT 'pending' COMMENT '状态: pending/processing/success/failed/cancelled',
    priority        TINYINT NOT NULL DEFAULT 5 COMMENT '优先级 1-10, 10最高',
    result_file_key VARCHAR(512) COMMENT '转换结果文件key(如为多页图片则为前缀)',
    result_page_count INT COMMENT '转换后总页数',
    result_size     BIGINT COMMENT '转换结果总大小(字节)',
    error_code      VARCHAR(50) COMMENT '失败错误码',
    error_message   TEXT COMMENT '失败详情',
    retry_count     INT NOT NULL DEFAULT 0 COMMENT '已重试次数',
    max_retry       INT NOT NULL DEFAULT 2 COMMENT '最大重试次数',
    created_by      BIGINT COMMENT '创建者用户ID',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    completed_at    DATETIME COMMENT '完成时间',
    expires_at      DATETIME COMMENT '结果过期时间(用于自动清理)',
    
    INDEX idx_status_priority (status, priority DESC, created_at),
    INDEX idx_source_md5_target (source_md5, target_format),
    INDEX idx_created_at (created_at),
    INDEX idx_expires_at (expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='文档转换任务表';
```


### 2.3 Redis 缓存策略

| 缓存键 | 用途 | TTL |
|--------|------|-----|
| `dpcs:task:status:{taskUuid}` | 任务实时状态 | 任务完成后 24h |
| `dpcs:preview:page:{resultKey}:{pageNum}` | 单页预览图(Base64) | 30 分钟 |
| `dpcs:convert:lock:{sourceMd5}:{targetFormat}` | 转换去重锁(防并发) | 10 分钟 |

## 3. API 接口设计

### 3.1 提交转换任务

将一个文件提交到转换队列，返回任务ID。支持异步回调通知。

```
POST /api/v1/dpcs/convert
```

**请求体：**
```json
{
  "sourceFileKey": "uploads/2026/07/14/uuid-doc-xxx.docx",
  "sourceFileName": "初二数学期末试卷.docx",
  "targetFormat": "pdf",
  "options": {
    "watermark": {
      "enabled": true,
      "text": "PrimeTop | 用户ID:10086 | 2026-07-14",
      "fontSize": 12,
      "opacity": 0.15,
      "rotation": -30,
      "position": "diagonal"
    },
    "imageDpi": 150,
    "pageRange": null,
    "thumbnail": {
      "enabled": true,
      "width": 200,
      "pages": [1]
    },
    "maxPages": 50,
    "callbackUrl": "https://api.primetop.com/internal/dpcs/callback"
  },
  "priority": 5,
  "clientRef": "homework-submit-12345"
}
```

**请求参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| sourceFileKey | String | ✅ | 对象存储中原始文件 key |
| sourceFileName | String | ✅ | 原始文件名(含扩展名，用于格式推断) |
| targetFormat | String | ✅ | 目标格式: `pdf` / `png` / `jpeg` / `html` / `txt` |
| options.watermark.enabled | Boolean | | 是否启用水印，默认 false |
| options.watermark.text | String | | 水印文本 |
| options.watermark.opacity | Float | | 水印透明度 0-1，默认 0.15 |
| options.imageDpi | Integer | | 图片渲染 DPI (72-300)，默认 150 |
| options.pageRange | String | | 页面范围 (如 "1-5,8,10-12")，NULL 表示全部 |
| options.thumbnail.enabled | Boolean | | 是否生成缩略图 |
| options.thumbnail.width | Integer | | 缩略图宽度(px)，默认 200 |
| options.maxPages | Integer | | 最大转换页数，防止超大文档，默认 50 |
| options.callbackUrl | String | | 转换完成后的回调通知 URL |
| priority | Integer | | 优先级 1-10，默认 5 |
| clientRef | String | | 调用方自定义引用号，用于幂等 |

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "taskUuid": "dpcs-a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "status": "pending",
    "cached": false,
    "estimatedSeconds": 15
  }
}
```

**幂等控制：** 同一文件 MD5 + 目标格式 + 选项 hash 的转换请求，若已完成则直接返回缓存结果（`cached: true`），若正在进行则返回已有任务。

### 3.3 获取文档预览（分页）

返回指定页的预览图片或 PDF 页面。支持按页请求，适用于前端翻页浏览。

```
GET /api/v1/dpcs/preview/{taskUuid}?token={token}&page={page}&quality={quality}
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| taskUuid | String | ✅ | 转换任务UUID (路径参数) |
| token | String | ✅ | 预览访问令牌 |
| page | Integer | | 页码(从1开始)，默认 1 |
| quality | String | | 图片质量: `thumbnail` / `standard` / `hd`，默认 `standard` |

**响应：** 直接返回图片二进制内容 (image/png 或 image/jpeg)，HTTP Header 包含：

```
Content-Type: image/png
X-Total-Pages: 8
X-Current-Page: 1
Cache-Control: public, max-age=86400
ETag: "dpcs-a1b2c3d4-page1-std"
```

### 4.2 LibreOffice 转换引擎关键实现

LibreOffice headless 模式是核心转换引擎。需要注意：

1. **进程隔离**：每个转换任务在独立的 Docker 容器中执行，防止进程间干扰
2. **超时控制**：单文件转换超时 120 秒
3. **资源限制**：单容器最大内存 1GB，CPU 1 核
4. **并发控制**：单个 Worker 节点最多 3 个并发 LibreOffice 进程

#### 4.2.1 LibreOffice 调用封装

```python
import asyncio
import os
import shutil
import tempfile
from pathlib import Path
from typing import Optional

class LibreOfficeConverter:
    """LibreOffice headless 转换引擎封装"""

    # 支持的源格式 → LibreOffice 过滤器名映射
    FORMAT_FILTERS = {
        "pdf": "writer_pdf_Export",      # Writer → PDF
        "pdf_from_calc": "calc_pdf_Export",  # Calc → PDF
        "pdf_from_impress": "impress_pdf_Export",  # Impress → PDF
        "html": "HTML (StarWriter)",
        "txt": "Text",
        "odt": "writer8",
    }

    def __init__(self, soffice_path: str = "soffice", timeout: int = 120):
        self.soffice = soffice_path
        self.timeout = timeout
        # LibreOffice 用户配置目录，隔离每次调用避免锁冲突
        self._profile_counter = 0

    async def convert(
        self,
        input_path: str,
        output_dir: str,
        target_format: str = "pdf",
        page_range: Optional[str] = None,
    ) -> str:
        """
        执行格式转换
        Args:
            input_path: 输入文件绝对路径
            output_dir: 输出目录
            target_format: 目标格式 (pdf/html/txt/odt)
            page_range: 页面范围 (仅 PDF 输出时有效)
        Returns:
            输出文件路径
        Raises:
            ConversionError: 转换失败
            ConversionTimeoutError: 转换超时
        """
        # 为每次转换创建独立的用户配置目录，避免 LibreOffice 锁冲突
        profile_dir = tempfile.mkdtemp(prefix="lo_profile_")
        output_dir_abs = os.path.abspath(output_dir)
        os.makedirs(output_dir_abs, exist_ok=True)

        cmd = [
            self.soffice,
            f"-env:UserInstallation=file://{profile_dir}",
            "--headless",
            "--nologo",
            "--nofirststartwizard",
            "--nolockcheck",       # 禁止锁检查，避免并发问题
            "--nodefault",
            "--norestore",
            f"--convert-to {target_format}",
            f"--outdir {output_dir_abs}",
            os.path.abspath(input_path),
        ]

        try:
            process = await asyncio.create_subprocess_exec(
                *cmd,
                stdout=asyncio.subprocess.PIPE,
                stderr=asyncio.subprocess.PIPE,
            )
            stdout, stderr = await asyncio.wait_for(
                process.communicate(), timeout=self.timeout
            )

            if process.returncode != 0:
                error_msg = stderr.decode("utf-8", errors="replace")
                raise ConversionError(
                    f"LibreOffice conversion failed (code={process.returncode}): {error_msg}"
                )

            # 推断输出文件名 (LibreOffice 保持原文件名，替换扩展名)
            input_name = Path(input_path).stem
            output_file = os.path.join(output_dir_abs, f"{input_name}.{target_format}")

            if not os.path.exists(output_file):
                raise ConversionError(
                    f"Output file not found: {output_file}. "
                    f"stdout={stdout.decode(errors='replace')}"
                )

            return output_file

        except asyncio.TimeoutError:
            process.kill()
            await process.communicate()
            raise ConversionTimeoutError(
                f"LibreOffice conversion timed out after {self.timeout}s"
            )
        finally:
            # 清理用户配置目录
            shutil.rmtree(profile_dir, ignore_errors=True)
```

#### 4.2.2 PDF 渲染为图片

```python
import fitz  # PyMuPDF
from PIL import Image
import io
from typing import List, Tuple

class PDFRenderer:
    """PDF 页面渲染为图片"""

    QUALITY_PRESETS = {
        "thumbnail": {"dpi": 72, "max_width": 200},    # 缩略图
        "standard": {"dpi": 150, "max_width": 1080},   # 标准预览
        "hd": {"dpi": 300, "max_width": 1920},         # 高清预览
    }

    def render_page(
        self,
        pdf_path: str,
        page_num: int,
        quality: str = "standard",
    ) -> bytes:
        """
        渲染 PDF 指定页为 PNG 图片
        Args:
            pdf_path: PDF 文件路径
            page_num: 页码 (0-indexed)
            quality: 质量 preset
        Returns:
            PNG 图片二进制数据
        """
        preset = self.QUALITY_PRESETS.get(quality, self.QUALITY_PRESETS["standard"])

        doc = fitz.open(pdf_path)
        if page_num >= doc.page_count:
            raise PageNotFoundError(f"Page {page_num} not found, total={doc.page_count}")

        page = doc[page_num]
        # 使用 Matrix 控制 DPI: 默认 72 DPI, matrix = DPI/72
        zoom = preset["dpi"] / 72.0
        matrix = fitz.Matrix(zoom, zoom)
        pixmap = page.get_pixmap(matrix=matrix, alpha=False)

        # 如果宽度超过 max_width，按比例缩放
        if pixmap.width > preset["max_width"]:
            img = Image.open(io.BytesIO(pixmap.tobytes("png")))
            ratio = preset["max_width"] / img.width
            new_size = (preset["max_width"], int(img.height * ratio))
            img = img.resize(new_size, Image.LANCZOS)
            buf = io.BytesIO()
            img.save(buf, format="PNG", optimize=True)
            return buf.getvalue()

        return pixmap.tobytes("png")

    def render_all_pages(
        self,
        pdf_path: str,
        quality: str = "standard",
        max_pages: int = 50,
    ) -> List[bytes]:
        """渲染所有页"""
        doc = fitz.open(pdf_path)
        total = min(doc.page_count, max_pages)
        return [self.render_page(pdf_path, i, quality) for i in range(total)]

    def get_page_count(self, pdf_path: str) -> int:
        """获取 PDF 总页数"""
        doc = fitz.open(pdf_path)
        return doc.page_count

    def extract_text(self, pdf_path: str, page_num: int = None) -> str | List[str]:
        """提取 PDF 文本内容"""
        doc = fitz.open(pdf_path)
        if page_num is not None:
            return doc[page_num].get_text("text")
        return [doc[i].get_text("text") for i in range(doc.page_count)]
```

### 4.3 水印嵌入引擎

```python
from PIL import Image, ImageDraw, ImageFont
import io
import math

class WatermarkEngine:
    """文档水印嵌入引擎"""

    DEFAULT_FONT = "/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf"
    # 中文字体 (Docker 镜像内预装)
    CN_FONT = "/usr/share/fonts/truetype/noto/NotoSansCJK-Regular.ttc"

    def embed_image_watermark(
        self,
        image_bytes: bytes,
        text: str,
        opacity: float = 0.15,
        font_size: int = 14,
        rotation: float = -30,
        position: str = "diagonal",
        color: tuple = (128, 128, 128),
    ) -> bytes:
        """
        在图片上嵌入平铺水印
        Args:
            image_bytes: 原始图片 PNG/JPEG 二进制
            text: 水印文本
            opacity: 透明度 0-1
            font_size: 字号
            rotation: 旋转角度
            position: "diagonal"(对角平铺) / "center"(居中) / "bottom-right"
            color: RGB 文字颜色
        Returns:
            带水印的图片二进制
        """
        base = Image.open(io.BytesIO(image_bytes)).convert("RGBA")
        watermark_layer = Image.new("RGBA", base.size, (0, 0, 0, 0))
        draw = ImageDraw.Draw(watermark_layer)

        try:
            font = ImageFont.truetype(self.CN_FONT, font_size)
        except (OSError, IOError):
            font = ImageFont.truetype(self.DEFAULT_FONT, font_size)

        if position == "diagonal":
            # 对角线平铺水印
            text_width = draw.textlength(text, font=font)
            step_x = text_width + 100
            step_y = font_size * 4
            alpha = int(255 * opacity)

            for y in range(-base.height, base.height * 2, int(step_y)):
                for x in range(-base.width, base.width * 2, int(step_x)):
                    # 添加文字到水印层
                    draw.text(
                        (x, y), text, font=font,
                        fill=(color[0], color[1], color[2], alpha)
                    )

            # 旋转水印层
            watermark_layer = watermark_layer.rotate(
                rotation, expand=False, fillcolor=(0, 0, 0, 0)
            )
            # 裁剪到原图大小
            watermark_layer = watermark_layer.crop(base.size + (0, 0))
            watermark_layer = watermark_layer.resize(base.size)

        elif position == "center":
            alpha = int(255 * (opacity * 2))  # 居中水印更不透明
            text_width = draw.textlength(text, font=font)
            x = (base.width - text_width) // 2
            y = (base.height - font_size) // 2
            draw.text(
                (x, y), text, font=font,
                fill=(color[0], color[1], color[2], alpha)
            )

        # 合并图层
        result = Image.alpha_composite(base, watermark_layer)
        buf = io.BytesIO()
        result.convert("RGB").save(buf, format="PNG", optimize=True)
        return buf.getvalue()

    def embed_pdf_watermark(
        self,
        pdf_path: str,
        output_path: str,
        text: str,
        opacity: float = 0.15,
    ) -> str:
        """
        在 PDF 每页上叠加水印
        使用 PyMuPDF 的 insert_text / insert_image 方法
        """
        doc = fitz.open(pdf_path)

        for page in doc:
            rect = page.rect
            # 创建水印文本框
            font_size = 10
            # 计算对角线位置
            diag_length = math.sqrt(rect.width ** 2 + rect.height ** 2)
            text_len = len(text) * font_size * 0.6
            repeats = int(diag_length / text_len) + 1
            watermark_text = "  ".join([text] * repeats)

            # 在页面上插入半透明文字
            page.insert_text(
                fitz.Point(0, rect.height / 2),
                watermark_text,
                fontsize=font_size,
                fontname="helv",
                color=(0.7, 0.7, 0.7),
                fill_opacity=opacity,
                rotate=-30,
                overlay=True,
            )

        doc.save(output_path, garbage=4, deflate=True)
        doc.close()
        return output_path
```

## 5. 状态机设计

### 5.1 任务状态流转

```
                        ┌──────────┐
                        │ PENDING  │◄──────── 重试时回到此状态
                        └─────┬────┘
                              │ Worker 拾取任务
                              ▼
                        ┌──────────┐
              ┌────────│PROCESSING│
              │         └─────┬────┘
              │               │
     用户取消 │      ┌────────┴────────┐
     (API)    │      │                 │
              │      ▼                 ▼
              │ ┌────────┐     ┌────────────┐
              │ │SUCCESS │     │   FAILED   │
              │ └────────┘     └──────┬─────┘
              │                        │ retries < max?
              │                 ┌──────┴──────┐
              │                 │ YES         │ NO
              │                 ▼             ▼
              │           回到 PENDING   ┌──────────┐
              │                         │CANCELLED │
              ▼                         └──────────┘
        ┌──────────┐
        │CANCELLED │
        └──────────┘
```

### 5.2 状态定义

| 状态 | 说明 | 允许的转换 |
|------|------|-----------|
| `pending` | 任务已入队，等待处理 | → `processing`, `cancelled` |
| `processing` | Worker 正在转换 | → `success`, `failed` |
| `success` | 转换完成，结果可用 | → (终态) |
| `failed` | 转换失败(重试耗尽) | → (终态)，可手动重新提交 |
| `cancelled` | 用户或系统取消 | → (终态) |

### 5.3 状态机实现

```python
from enum import Enum
from typing import Optional

class TaskStatus(str, Enum):
    PENDING = "pending"
    PROCESSING = "processing"
    SUCCESS = "success"
    FAILED = "failed"
    CANCELLED = "cancelled"

# 合法状态转换
VALID_TRANSITIONS = {
    TaskStatus.PENDING: {TaskStatus.PROCESSING, TaskStatus.CANCELLED},
    TaskStatus.PROCESSING: {TaskStatus.SUCCESS, TaskStatus.FAILED},
    TaskStatus.FAILED: {TaskStatus.PENDING},  # 重试
    TaskStatus.SUCCESS: set(),  # 终态
    TaskStatus.CANCELLED: set(),  # 终态
}

def transition_status(
    current: TaskStatus,
    target: TaskStatus,
    task_repo: "TaskRepository",
    task_uuid: str,
) -> TaskStatus:
    """执行状态转换，带合法性检查"""
    if target not in VALID_TRANSITIONS.get(current, set()):
        raise InvalidStatusTransitionError(
            f"Cannot transition from {current.value} to {target.value} "
            f"for task {task_uuid}"
        )

    task_repo.update_status(task_uuid, target.value)
    # 发布状态变更事件 (供其他服务订阅)
    event_bus.publish("dpcs.task.status_changed", {
        "taskUuid": task_uuid,
        "from": current.value,
        "to": target.value,
    })
    return target
```

### 6.1 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 处理策略 |
|--------|:---:|------|------|
| `DPCS_001` | 400 | 不支持的源格式 | 拒绝请求，返回支持的格式列表 |

### 7.2 缓存策略

```python
class ConversionCacheManager:
    """多级缓存管理器"""

    def __init__(self, redis, db_repo, oss_client):
        self.redis = redis       # L1: Redis 热缓存
        self.db = db_repo        # L2: MySQL 持久缓存
        self.oss = oss_client    # L3: 对象存储

    async def get_or_create(
        self,
        source_md5: str,
        source_format: str,
        target_format: str,
        options: dict,
        convert_func: callable,
    ) -> dict:
        """查询缓存链路: Redis → MySQL → 对象存储 → 实际转换"""

        options_hash = hashlib.sha256(
            json.dumps(options, sort_keys=True).encode()
        ).hexdigest()

        # L1: 查 Redis (仅缓存任务 UUID, 快速跳转)
        cache_key = f"dpcs:cache:{source_md5}:{target_format}:{options_hash}"
        cached = await self.redis.get(cache_key)
        if cached:
            cache_data = json.loads(cached)
            # 验证对象存储中结果是否仍在
            if await self.oss.exists(cache_data["result_key"]):
                await self.db.increment_hit_count(source_md5, target_format, options_hash)
                return {"result": cache_data, "cached": True}

        # L2: 查 MySQL
        db_cache = await self.db.query_cache(
            source_md5, source_format, target_format, options_hash
        )
        if db_cache and not db_cache.is_expired():
            if await self.oss.exists(db_cache.result_file_key):
                # 回填 Redis
                await self.redis.setex(
                    cache_key, 1800, json.dumps({
                        "result_key": db_cache.result_file_key,
                        "page_count": db_cache.result_page_count,
                    })
                )
                return {"result": db_cache.to_dict(), "cached": True}

        # L3: 缓存未命中，执行实际转换
        result = await convert_func()

        # 写入缓存
        await self.db.write_cache(
            source_md5=source_md5,
            source_format=source_format,
            target_format=target_format,
            options_hash=options_hash,
            result_file_key=result["result_key"],
            page_count=result["page_count"],
            ttl_days=7,  # 缓存 7 天
        )
        await self.redis.setex(cache_key, 1800, json.dumps(result))

        return {"result": result, "cached": False}
```

```python
class LibreOfficePool:
```

```python
class PreviewTokenValidator:
    """预览令牌验证器"""

        self,
        task_uuid: str,

        user_id: int,
```

```python
class QuotaManager:
    """用户级配额管理"""

    # 免费用户: 每天 10 次转换
    # 会员用户: 每天 100 次转换
    # 教师: 每天 500 次转换

    QUOTA_MAP = {
        "free": 10,
        "member": 100,
        "teacher": 500,
        "admin": float("inf"),
    }

    # 频率限制: 每分钟最多 5 次提交
    RATE_LIMIT_PER_MINUTE = 5

    async def check_quota(self, user_id: int, user_role: str) -> None:
        """检查用户配额"""
        # 1. 每日配额检查
        today = datetime.utcnow().strftime("%Y%m%d")
        quota_key = f"dpcs:quota:user:{user_id}:{today}"
        current = await self.redis.incr(quota_key)
        if current == 1:
            await self.redis.expire(quota_key, 86400)

        limit = self.QUOTA_MAP.get(user_role, 10)
        if current > limit:
            raise DPCSError(
                code="DPCS_011",
                http_status=429,
                message=f"Daily quota exceeded ({limit}). Resets at 00:00 UTC."
            )

        # 2. 频率检查 (滑动窗口)
        rate_key = f"dpcs:rate:user:{user_id}"
        pipe = self.redis.pipeline()
        pipe.zadd(rate_key, {str(time.time()): 1})
        pipe.zremrangebyscore(rate_key, time.time() - 60, time.time())
        pipe.zcard(rate_key)
        _, _, count = pipe.execute()

        if count > self.RATE_LIMIT_PER_MINUTE:
            raise DPCSError(
                code="DPCS_010",
                http_status=429,
                message=f"Rate limit exceeded. Max {self.RATE_LIMIT_PER_MINUTE} requests/minute."
            )
```

```python
@celery_app.task(name="dpcs.cleanup_expired_cache")
def cleanup_expired_cache():
    """清理过期的转换结果缓存"""
    expired = db.query(Cache).filter(Cache.expires_at < datetime.utcnow()).all()
    for cache in expired:
        # 删除对象存储中的文件
        oss.delete_object(cache.result_file_key)
        db.delete(cache)
    db.commit()
    logger.info(f"Cleaned up {len(expired)} expired cache entries")


@celery_app.task(name="dpcs.retry_stuck_tasks")
def retry_stuck_tasks():
    """重试卡在 processing 状态超过 5 分钟的任务"""
    threshold = datetime.utcnow() - timedelta(minutes=5)
    stuck = db.query(Task).filter(
        Task.status == "processing",
        Task.updated_at < threshold,
    ).all()

    for task in stuck:
        logger.warning(f"Task {task.task_uuid} stuck, resetting to pending")
        task.status = "pending"
        task.retry_count += 1
        if task.retry_count > task.max_retry:
            task.status = "failed"
            task.error_code = "DPCS_102"
            task.error_message = "Task stuck and max retries exceeded"
    db.commit()
```

```python
        content = await self.content_service.get(content_id)

        # 2. 生成预览令牌
        token_resp = await self.http_client.post(
            "http://dpcs-api:8000/api/v1/internal/dpcs/tokens",
            json={
                "taskUuid": content.dpcs_task_uuid,
                "userId": user_id,
                "watermarkText": f"PrimeTop | UID:{user_id} | {datetime.now():%Y-%m-%d}",
                "ttlSeconds": 3600,
            }
        )
        token = token_resp.json()["data"]["token"]

        # 3. 返回预览信息给客户端
        return {
            "previewUrl": f"/api/v1/dpcs/preview/{content.dpcs_task_uuid}?token={token}&page={{page}}",
            "totalPages": content.page_count,
            "downloadUrl": f"/api/v1/dpcs/download/{content.dpcs_task_uuid}?token={token}",
            "tokenExpiresIn": 3600,
        }
```

```dart
// Flutter 客户端预览组件
class DocumentPreviewWidget extends StatefulWidget {
  final String previewUrl; // 模板 URL, {page} 为占位符
  final int totalPages;

  @override
  _DocumentPreviewWidgetState createState() => _DocumentPreviewWidgetState();
}

class _DocumentPreviewWidgetState extends State<DocumentPreviewWidget> {
  final PageController _pageController = PageController();
  final Map<int, Uint8List> _imageCache = {};
  int _currentPage = 1;
  bool _isLoading = false;

  Future<Uint8List> _loadPage(int page) async {
    if (_imageCache.containsKey(page)) {
      return _imageCache[page]!;
    }

    final url = widget.previewUrl
        .replaceAll('{page}', page.toString())
        .replaceAll('{quality}', 'standard');

    final response = await http.get(Uri.parse(url));
    if (response.statusCode == 200) {
      _imageCache[page] = response.bodyBytes;
      // 预加载下一页
      if (page < widget.totalPages) {
        _preloadPage(page + 1);
      }
      return response.bodyBytes;
    }
    throw Exception('Failed to load page $page');
  }

  void _preloadPage(int page) async {
    try {
      await _loadPage(page);
    } catch (_) {
      // 预加载失败忽略，翻页时会重试
    }
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        // 文档内容区域
        Expanded(
          child: InteractiveViewer(
            child: FutureBuilder<Uint8List>(
              future: _loadPage(_currentPage),
              builder: (context, snapshot) {
                if (snapshot.hasData) {
                  return Image.memory(snapshot.data!);
                }
                return Center(child: CircularProgressIndicator());
              },
            ),
          ),
        ),
        // 页面导航
        Container(
          padding: EdgeInsets.all(16),
          child: Row(
            mainAxisAlignment: MainAxisAlignment.spaceBetween,
            children: [
              IconButton(
                icon: Icon(Icons.chevron_left),
                onPressed: _currentPage > 1
                    ? () => setState(() => _currentPage--)
                    : null,
              ),
              Text('$_currentPage / ${widget.totalPages}'),
              IconButton(
                icon: Icon(Icons.chevron_right),
                onPressed: _currentPage < widget.totalPages
                    ? () => setState(() => _currentPage++)
                    : null,
              ),
            ],
          ),
        ),
      ],
    );
  }
}
```
