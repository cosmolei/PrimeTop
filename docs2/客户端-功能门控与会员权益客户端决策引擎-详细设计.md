# 客户端-功能门控与会员权益客户端决策引擎 - 详细设计

## 1. 模块概述

### 1.1 定位

功能门控与会员权益客户端决策引擎（Client-side Entitlement & Feature Gate Engine）是 PrimeTop 客户端的**运行时权益感知与决策中枢**。它在客户端本地统一管理会员等级、功能开关、额度余量、灰度实验等状态，为所有业务页面提供一致的权益判断能力。

> **与已有模块的区别**：
> - **服务端-用户额度管控与功能门控引擎**：服务端运行时扣减、统计、风控
> - **客户端-会员中心与订阅购买交互设计**：会员购买、订阅管理 UI
> - **本模块**：客户端如何**消费**服务端下发的权益信息，在 UI 层统一做门控决策——"这个按钮能不能点"、"这个功能要不要灰显"、"今天还剩几次"、"触发升级引导的时机和方式"

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 权益状态管理 | 从服务端拉取并缓存会员等级、额度余量、功能开关、灰度变体 |
| 功能门控决策 | 根据权益状态决定功能可用性（可用 / 锁定 / 限额） |
| 额度感知展示 | 在 UI 各处实时展示剩余额度（"今日还可问 AI 3 次"） |
| Paywall 编排 | 在合适时机触发升级引导，统一管理弹窗优先级与频控 |
| 降级体验 | 免费用户功能受限时的友好 UX（灰显、提示、替代方案） |
| 离线降级 | 断网时基于本地缓存做尽力而为的门控判断 |
| 权益变更响应 | 会员升级 / 降级 / 过期时，全局 UI 即时刷新 |

### 1.3 适用范围

覆盖学生端 App 所有需要权益判断的场景：

| 场景 | 触发模块 | 门控维度 |
|------|----------|----------|
| AI 文字对话 | AI 辅导对话页 | AI 对话次数/日 |
| AI 语音提问 | 语音输入 | ASR 调用次数/日 + AI 对话次数/日 |
| 拍照搜题 | 拍题页 | 拍题次数/日 |
| 同类题推荐 | AI 对话/题目解析页 | AI 对话次数/日 |
| 作文批改 | 作文辅导页 | 作文批改次数/周 |
| 考试模拟 | 考试模拟页 | 考试次数/周 |
| 同步课堂内容 | 同步课堂页 | 部分章节会员限定 |
| 文科背诵检测 | 背诵页 | 背诵次数/日 |
| PDF 导出 | 错题/报告页 | 导出次数/日 |
| 深度解析 | 题目解析页 | 完整解析会员限定 |
| 学习规划高级版 | 学习规划页 | 高级功能会员限定 |

## 3. 数据结构定义

### 3.1 权益快照 (EntitlementSnapshot)

权益快照是客户端本地保存的、某一时刻用户权益的完整描述。它是所有门控决策的基础数据源。

```dart
/// models/entitlement_snapshot.dart

import 'package:equatable/equatable.dart';

/// 权益快照 —— 客户端权益状态的完整镜像
class EntitlementSnapshot extends Equatable {
  /// 快照版本号（服务端递增生成）
  final int version;

  /// 用户 ID
  final String userId;

  /// 会员等级
  final MembershipTier tier;

  /// 会员有效期（可为 null 表示免费用户）
  final DateTime? membershipExpiry;

  /// 是否处于自动续费状态
  final bool autoRenewEnabled;

  /// 各功能额度状态
  final Map<QuotaType, QuotaState> quotas;

  /// 功能开关列表（服务端下发的动态开关）
  final Map<String, FeatureFlag> featureFlags;

  /// 实验分组（A/B 测试变体分配）
  final Map<String, String> experimentVariants;

  /// 额外权益标签（如：体验会员、活动赠送等）
  final List<EntitlementTag> tags;

  /// 快照生成时间（服务端时间）
  final DateTime serverTime;

  /// 快照本地缓存时间
  final DateTime cachedAt;

  /// 签名（防篡改，HMAC）
  final String signature;

  const EntitlementSnapshot({
    required this.version,
    required this.userId,
    required this.tier,
    this.membershipExpiry,
    required this.autoRenewEnabled,
    required this.quotas,
    required this.featureFlags,
    required this.experimentVariants,
    required this.tags,
    required this.serverTime,
    required this.cachedAt,
    required this.signature,
  });

  @override
  List<Object?> get props => [version, userId];
}
```

### 3.2 会员等级枚举

```dart
/// enums/membership_tier.dart

enum MembershipTier {
  /// 免费用户
  free('free', '免费用户'),
  
  /// 月度会员
  monthly('monthly', '月度会员'),
  
  /// 季度会员
  quarterly('quarterly', '季度会员'),
  
  /// 年度会员
  annual('annual', '年度会员'),
  
  /// 中考专项会员
  zhongkao('zhongkao', '中考专项'),
  
  /// 高考专项会员
  gaokao('gaokao', '高考专项'),
  
  /// 体验会员（活动赠送 / 试用期）
  trial('trial', '体验会员'),
  
  /// 家庭会员
  family('family', '家庭会员');

  final String code;
  final String displayName;

  const MembershipTier(this.code, this.displayName);

  /// 是否为付费会员（任何非免费等级）
  bool get isPaid => this != MembershipTier.free;

  /// 是否享有完整权益
  bool get isFullAccess =>
      this == MembershipTier.annual ||
      this == MembershipTier.family;

  /// 是否为考试专项会员
  bool get isExamSpecific =>
      this == MembershipTier.zhongkao ||
      this == MembershipTier.gaokao;

  /// 从服务端 code 解析
  static MembershipTier fromCode(String code) {
    return MembershipTier.values.firstWhere(
      (t) => t.code == code,
      orElse: () => MembershipTier.free,
    );
  }
}
```

### 3.3 额度状态 (QuotaState)

```dart
/// models/quota_state.dart

class QuotaState extends Equatable {
  /// 额度类型
  final QuotaType type;

  /// 时间窗口
  final QuotaWindow window;

  /// 窗口内总额度（-1 表示无限）
  final int limit;

  /// 已使用量
  final int used;

  /// 重置时间（当前窗口结束后下次重置时间）
  final DateTime resetAt;

  /// 是否可通过观看广告获得额外额度
  final bool adRewardedAvailable;

  /// 广告额外额度数量
  final int adRewardAmount;

  const QuotaState({
    required this.type,
    required this.window,
    required this.limit,
    required this.used,
    required this.resetAt,
    this.adRewardedAvailable = false,
    this.adRewardAmount = 0,
  });

  /// 剩余额度（-1 表示无限）
  int get remaining => limit < 0 ? -1 : (limit - used).clamp(0, limit);

  /// 是否已耗尽
  bool get isExhausted => limit >= 0 && used >= limit;

  /// 使用百分比（0.0 ~ 1.0），无限额度返回 0
  double get usageRatio => limit < 0 ? 0.0 : (used / limit).clamp(0.0, 1.0);

  /// 剩余百分比（0.0 ~ 1.0），无限额度返回 1.0
  double get remainingRatio => 1.0 - usageRatio;

  /// 是否接近耗尽（剩余 < 20%）
  bool get isNearLimit => limit >= 0 && remainingRatio < 0.2;

  @override
  List<Object?> get props => [type, window, used];
}
```

```dart
/// 门控决策结果 —— canAccess() 的返回值
class GateDecision extends Equatable {
  /// 决策类型
  final GateDecisionType type;

  /// 关联的功能 Key
  final String featureKey;

  /// 关联的额度类型（如果适用）
  final QuotaType? quotaType;

  /// 剩余额度（如果适用）
  final int? remainingQuota;

  /// 被拦截的原因（如果 type != allowed）
  final String? reason;

  /// 推荐的升级方案
  final UpgradeSuggestion? upgradeSuggestion;

  /// 降级替代方案
  final FallbackOption? fallback;

  const GateDecision({
    required this.type,
    required this.featureKey,
    this.quotaType,
    this.remainingQuota,
    this.reason,
    this.upgradeSuggestion,
    this.fallback,
  });

  /// 快捷判断
  bool get isAllowed => type == GateDecisionType.allowed;

  /// 快捷判断：是否需要触发 Paywall
  bool get shouldShowPaywall =>
      type == GateDecisionType.membershipLocked ||
      type == GateDecisionType.quotaExhausted;

  @override
  List<Object?> get props => [featureKey, type];
}

enum GateDecisionType {
  /// 允许访问
  allowed,
  
  /// 会员等级不足，功能锁定
  membershipLocked,
  
  /// 额度耗尽
  quotaExhausted,
  
  /// 功能未开放（灰度/地区/学段限制）
  featureDisabled,
  
  /// 被防沉迷系统拦截
  antiAddictionBlocked,
  
  /// 网络异常，本地缓存也无法判断（降级放行或拦截）
  unknown,
```

### 3.5 功能开关 (FeatureFlag)

```dart
/// models/feature_flag.dart

class FeatureFlag extends Equatable {
  /// 开关 Key
  final String key;

  /// 是否启用
  final bool enabled;

  /// 生效条件（JSON，如 {"min_version": "1.2.0", "platform": "ios"}）
  final Map<String, dynamic> conditions;

  /// 变体（用于 A/B 测试）
  final String? variant;

  /// 过期时间
  final DateTime? expiresAt;

  const FeatureFlag({
    required this.key,
    required this.enabled,
    this.conditions = const {},
    this.variant,
    this.expiresAt,
  });

  /// 检查是否对当前客户端生效
  bool appliesTo({
    required String appVersion,
    required String platform,
    required MembershipTier tier,
    required String grade,
  }) {
    if (!enabled) return false;
    if (expiresAt != null && DateTime.now().isAfter(expiresAt!)) return false;

    // 版本检查
    final minVersion = conditions['min_version'];
    if (minVersion != null && _compareVersion(appVersion, minVersion) < 0) {
      return false;
    }

    // 平台检查
    final targetPlatform = conditions['platform'];
    if (targetPlatform != null && targetPlatform != platform) {
      return false;
    }

    // 会员等级检查
    final minTier = conditions['min_tier'];
    if (minTier != null) {
      // 简化判断：付费会员即可
      if (minTier == 'paid' && !tier.isPaid) return false;
    }

    return true;
  }

  int _compareVersion(String a, String b) {
    final partsA = a.split('.').map(int.parse).toList();
    final partsB = b.split('.').map(int.parse).toList();
    for (var i = 0; i < 3; i++) {
      final va = i < partsA.length ? partsA[i] : 0;
      final vb = i < partsB.length ? partsB[i] : 0;
      if (va != vb) return va.compareTo(vb);
    }
    return 0;
  }

  @override
  List<Object?> get props => [key, enabled, variant];
}
```

```dart
/// core/feature_gate/feature_gate_decision_engine.dart

/// 功能门控统一决策引擎
///
/// 所有业务模块通过此引擎查询功能可用性。
/// 引擎内部合并权益等级、额度状态、功能开关、实验分组
/// 和防沉迷状态，返回最终决策。
class FeatureGateDecisionEngine {
  final EntitlementManager _entitlementManager;
  final QuotaTracker _quotaTracker;
  final PaywallOrchestrator _paywallOrchestrator;
  final AntiAddictionService _antiAddictionService;
  final AppLogger _logger;

  FeatureGateDecisionEngine({
    required EntitlementManager entitlementManager,
    required QuotaTracker quotaTracker,
    required PaywallOrchestrator paywallOrchestrator,
    required AntiAddictionService antiAddictionService,
    required AppLogger logger,
  })  : _entitlementManager = entitlementManager,
        _quotaTracker = quotaTracker,
        _paywallOrchestrator = paywallOrchestrator,
        _antiAddictionService = antiAddictionService,
        _logger = logger;

  /// 核心方法：检查功能是否可用
  ///
  /// [featureKey] 功能标识，如 "ai_chat"、"photo_search"
  /// [context] 调用上下文（页面、触发来源等）
  GateDecision canAccess({
    required String featureKey,
    required GateContext context,
  }) {
    _logger.debug('canAccess: featureKey=$featureKey, context=$context');

    // 1. 防沉迷优先检查
    final antiAddictionResult = _antiAddictionService.check();
    if (antiAddictionResult.isBlocked) {
      return GateDecision(
        type: GateDecisionType.antiAddictionBlocked,
        featureKey: featureKey,
        reason: antiAddictionResult.message,
        fallback: FallbackOption(
          type: FallbackType.retryLater,
          message: '今日学习时长已达上限，请在 ${antiAddictionResult.resetTime} 后再试',
        ),
      );
    }

    // 2. 功能开关检查（灰度/版本/平台）
    final flag = _entitlementManager.getFeatureFlag(featureKey);
    if (flag != null && !flag.appliesTo(
      appVersion: context.appVersion,
      platform: context.platform,
      tier: _entitlementManager.currentTier,
      grade: context.grade,
    )) {
      return GateDecision(
        type: GateDecisionType.featureDisabled,
        featureKey: featureKey,
        reason: '该功能暂未开放',
      );
    }

    // 3. 会员等级检查
    final requiredTier = _getRequiredTier(featureKey);
    if (!_entitlementManager.meetsTier(requiredTier)) {
      return GateDecision(
        type: GateDecisionType.membershipLocked,
        featureKey: featureKey,
        reason: '该功能为会员专享',
        upgradeSuggestion: _buildUpgradeSuggestion(
          featureKey: featureKey,
          requiredTier: requiredTier,
          triggerScene: context.scene,
        ),
      );
    }

    // 4. 额度检查
    final quotaType = _getQuotaType(featureKey);
    if (quotaType != null) {
      final quota = _quotaTracker.getQuota(quotaType);
      if (quota != null && quota.isExhausted) {
        return GateDecision(
          type: GateDecisionType.quotaExhausted,
          featureKey: featureKey,
          quotaType: quotaType,
          remainingQuota: 0,
          reason: _buildQuotaExhaustedMessage(quota),
          upgradeSuggestion: _buildUpgradeSuggestion(
            featureKey: featureKey,
            requiredTier: MembershipTier.monthly,
            triggerScene: context.scene,
          ),
          fallback: _buildFallback(quota),
        );
      }

      // 返回允许访问 + 额度信息
      return GateDecision(
        type: GateDecisionType.allowed,
        featureKey: featureKey,
        quotaType: quotaType,
        remainingQuota: quota?.remaining,
      );
    }

    // 5. 无额外限制，允许访问
    return GateDecision(
      type: GateDecisionType.allowed,
      featureKey: featureKey,
    );
  }

  /// 在操作执行前调用：检查并本地扣减额度
  ///
  /// 返回 null 表示允许执行，返回 GateDecision 表示被拦截。
  GateDecision? tryConsume({
    required String featureKey,
    required GateContext context,
    int amount = 1,
  }) {
    final decision = canAccess(featureKey: featureKey, context: context);
    if (!decision.isAllowed) {
      return decision;
    }

    // 本地预扣减
    final quotaType = decision.quotaType;
    if (quotaType != null) {
      _quotaTracker.localConsume(quotaType, amount);
    }

    return null; // null 表示放行
  }

  /// 服务端确认扣减后，校正本地状态
  void confirmConsume({
    required QuotaType quotaType,
    required int serverUsed,
  }) {
    _quotaTracker.syncFromServer(quotaType, serverUsed);
  }

  /// 服务端拒绝时，回滚本地预扣减
  void rollbackConsume({
    required QuotaType quotaType,
    int amount = 1,
  }) {
    _quotaTracker.localRefund(quotaType, amount);
  }

  /// 获取该功能需要的最低会员等级
  MembershipTier _getRequiredTier(String featureKey) {
    // 从功能权益矩阵配置中查询
    return _entitlementManager
        .getFeatureTierRequirement(featureKey) ?? MembershipTier.free;
  }

  QuotaType? _getQuotaType(String featureKey) {
    const map = {
      'ai_chat': QuotaType.aiChat,
      'photo_search': QuotaType.photoSearch,
      'essay_correct': QuotaType.essayCorrect,
      'exam_sim': QuotaType.examSim,
      'pdf_export': QuotaType.pdfExport,
      'asr_call': QuotaType.asrCall,
      'recitation': QuotaType.recitation,
    };
    return map[featureKey];
  }

  String _buildQuotaExhaustedMessage(QuotaState quota) {
    final windowLabel = switch (quota.window) {
      QuotaWindow.daily => '今日',
      QuotaWindow.weekly => '本周',
      QuotaWindow.monthly => '本月',
    };
    return '$windowLabel次数已用完'
        '${quota.adRewardedAvailable ? "，看广告可获 ${quota.adRewardAmount} 次额外机会" : ""}';
  }

  UpgradeSuggestion _buildUpgradeSuggestion({
    required String featureKey,
    required MembershipTier requiredTier,
    required String triggerScene,
  }) {
    return UpgradeSuggestion(
      recommendedTier: requiredTier,
      title: switch (featureKey) {
        'ai_chat' => '升级会员，解锁更多提问次数',
        'photo_search' => '升级会员，解锁更多拍题次数',
        'essay_correct' => '升级会员，解锁作文批改',
        _ => '升级会员，解锁完整功能',
      },
      subtitle: switch (requiredTier) {
        MembershipTier.monthly => '月度会员 ¥29/月',
        MembershipTier.annual => '年度会员 ¥198/年（低至 ¥0.54/天）',
        _ => '查看会员权益',
      },
      triggerScene: triggerScene,
    );
  }

  FallbackOption? _buildFallback(QuotaState quota) {
    if (quota.adRewardedAvailable) {
      return FallbackOption(
        type: FallbackType.watchAd,
        message: '看一段广告，免费获得 ${quota.adRewardAmount} 次机会',
      );
    }
    return FallbackOption(
      type: FallbackType.retryLater,
      message: '额度将在 ${_formatResetTime(quota.resetAt)} 重置',
    );
  }

  String _formatResetTime(DateTime resetAt) {
    final now = DateTime.now();
    if (resetAt.day == now.day + 1) {
      return '明天 0:00';
    }
    return '${resetAt.month}/${resetAt.day} 0:00';
  }
}
```

```dart
/// core/feature_gate/entitlement_manager.dart

class EntitlementManager {
  final EntitlementSyncService _syncService;
  final EntitlementStorage _storage;
  final AppLogger _logger;

  // 内存中的权益快照
  EntitlementSnapshot? _snapshot;

  // 权益变更通知
  final _controller = StreamController<EntitlementSnapshot>.broadcast();
  Stream<EntitlementSnapshot> get onSnapshotChanged => _controller.stream;

  // 功能权益矩阵（从本地配置加载，可被远程配置覆盖）
  Map<String, MembershipTier> _featureTierMatrix = {};

  EntitlementManager({
    required EntitlementSyncService syncService,
    required EntitlementStorage storage,
    required AppLogger logger,
  })  : _syncService = syncService,
        _storage = storage,
        _logger = logger;

  /// 当前会员等级
  MembershipTier get currentTier => _snapshot?.tier ?? MembershipTier.free;

  /// 当前快照版本
  int get snapshotVersion => _snapshot?.version ?? 0;

  /// 是否为付费会员
  bool get isPaidMember => currentTier.isPaid;

  /// 初始化：加载本地缓存 → 拉取最新
  Future<void> initialize() async {
    // 1. 加载本地缓存（快速恢复 UI 状态）
    final cached = await _storage.loadSnapshot();
    if (cached != null) {
      _snapshot = cached;
      _logger.info('Loaded cached snapshot v${cached.version}');
    }

    // 2. 加载功能权益矩阵
    _featureTierMatrix = await _storage.loadTierMatrix();

    // 3. 异步拉取最新快照（不阻塞启动）
    _syncService.fetchSnapshot().then((snapshot) {
      _applySnapshot(snapshot);
    }).catchError((e) {
      _logger.warning('Failed to fetch entitlement snapshot: $e');
    });

    // 4. 订阅 WebSocket 推送
    _syncService.entitlementEvents.listen(_handlePushEvent);
  }

  /// 判断是否满足指定会员等级要求
  bool meetsTier(MembershipTier required) {
    // 年度会员 > 季度 > 月度 > 免费
    // 家庭会员等同于年度
    // 考试专项会员：对应科目功能可用，通用功能等同于月度
    if (required == MembershipTier.free) return true;

    final current = currentTier;
    if (current == MembershipTier.annual ||
        current == MembershipTier.family) {
      return true; // 最高等级，满足所有
    }
    if (current.isExamSpecific && required.isExamSpecific) {
      // 同为考试专项时按科目判断（简化：放行）
      return true;
    }

    // 通用等级比较
    return _tierLevel(current) >= _tierLevel(required);
  }

  int _tierLevel(MembershipTier tier) {
    return switch (tier) {
      MembershipTier.free => 0,
      MembershipTier.trial => 1,
      MembershipTier.monthly => 2,
      MembershipTier.quarterly => 3,
      MembershipTier.zhongkao => 3,
      MembershipTier.gaokao => 3,
      MembershipTier.annual => 4,
      MembershipTier.family => 4,
    };
  }

  /// 获取功能开关
  FeatureFlag? getFeatureFlag(String key) {
    return _snapshot?.featureFlags[key];
  }

  /// 获取实验变体
  String? getExperimentVariant(String experimentKey) {
    return _snapshot?.experimentVariants[experimentKey];
  }

  /// 获取功能所需最低会员等级
  MembershipTier? getFeatureTierRequirement(String featureKey) {
    return _featureTierMatrix[featureKey];
  }

  /// 应用新的权益快照
  void _applySnapshot(EntitlementSnapshot snapshot) {
    final oldTier = _snapshot?.tier;
    _snapshot = snapshot;
    _storage.saveSnapshot(snapshot);
    _controller.add(snapshot);

    // 会员等级变更通知
    if (oldTier != snapshot.tier) {
      _logger.info(
        'Membership tier changed: ${oldTier?.code} → ${snapshot.tier.code}',
      );
      _onTierChanged(oldTier, snapshot.tier);
    }
  }

  /// 处理 WebSocket 推送事件
  void _handlePushEvent(EntitlementPushEvent event) {
    switch (event.type) {
      case PushEventType.quotaUpdated:
        // QuotaTracker 会独立处理，这里不重复
        break;

      case PushEventType.membershipChanged:
        // 会员状态变更，需要拉取完整快照
        _syncService.fetchSnapshot().then(_applySnapshot);
        break;

      case PushEventType.flagToggled:
        // 功能开关变更
        if (_snapshot != null) {
          final newFlags = Map<String, FeatureFlag>.from(
            _snapshot!.featureFlags,
          );
          if (event.data['flag'] != null) {
            final flag = FeatureFlag.fromJson(event.data['flag']);
            newFlags[flag.key] = flag;
          }
          _applySnapshot(_snapshot!.copyWith(featureFlags: newFlags));
        }
        break;

      case PushEventType.experimentReassigned:
        // 实验重新分组，拉取完整快照
        _syncService.fetchSnapshot().then(_applySnapshot);
        break;
    }
  }

  /// 会员等级变更处理
  void _onTierChanged(MembershipTier? oldTier, MembershipTier newTier) {
    // 触发全局事件总线
    EventBus.instance.fire(MembershipChangedEvent(
      oldTier: oldTier,
      newTier: newTier,
    ));

    // 如果是升级，触发庆祝动画
    if (oldTier != null && _tierLevel(newTier) > _tierLevel(oldTier)) {
      EventBus.instance.fire(ShowCelebrationEvent(
        type: CelebrationType.membershipUpgraded,
        tier: newTier,
      ));
    }
  }

  /// 手动刷新权益
  Future<void> refresh() async {
    final snapshot = await _syncService.fetchSnapshot();
    _applySnapshot(snapshot);
  }

  void dispose() {
    _controller.close();
  }
}
```

### 5.3 QuotaTracker — 额度追踪器

```dart
/// core/feature_gate/quota_tracker.dart

class QuotaTracker {
  final EntitlementSyncService _syncService;
  final AppLogger _logger;

  // 本地额度状态（包含乐观扣减后的值）
  final Map<QuotaType, QuotaState> _localStates = {};

  // 本地待同步的扣减记录
  final List<PendingConsume> _pendingConsumes = [];

  // 额度变更通知
  final _controller = StreamController<QuotaUpdate>.broadcast();
  Stream<QuotaUpdate> get onQuotaChanged => _controller.stream;

  QuotaTracker({
    required EntitlementSyncService syncService,
    required AppLogger logger,
  })  : _syncService = syncService,
        _logger = logger;

  /// 初始化
  Future<void> initialize(EntitlementSnapshot snapshot) async {
    _localStates.clear();
    for (final entry in snapshot.quotas.entries) {
      _localStates[entry.key] = entry.value;
    }

    // 订阅推送
    _syncService.entitlementEvents.listen((event) {
      if (event.type == PushEventType.quotaUpdated) {
        _handleQuotaPush(event.data);
      }
    });
  }

  /// 获取额度状态
  QuotaState? getQuota(QuotaType type) => _localStates[type];

  /// 本地乐观扣减
  void localConsume(QuotaType type, int amount) {
    final current = _localStates[type];
    if (current == null) return;

    final newState = QuotaState(
      type: current.type,
      window: current.window,
      limit: current.limit,
      used: current.used + amount,
      resetAt: current.resetAt,
      adRewardedAvailable: current.adRewardedAvailable,
      adRewardAmount: current.adRewardAmount,
    );

    _localStates[type] = newState;

    // 记录待同步
    _pendingConsumes.add(PendingConsume(
      type: type,
      amount: amount,
      timestamp: DateTime.now(),
      traceId: _generateTraceId(),
    ));

    // 通知 UI
    _controller.add(QuotaUpdate(
      type: type,
      newState: newState,
      source: UpdateSource.localConsume,
    ));

    _logger.debug(
      'Local consume: $type -$amount, remaining=${newState.remaining}',
    );
  }

  /// 本地回滚扣减
  void localRefund(QuotaType type, int amount) {
    final current = _localStates[type];
    if (current == null) return;

    final newState = QuotaState(
      type: current.type,
      window: current.window,
      limit: current.limit,
      used: (current.used - amount).clamp(0, current.limit < 0 ? 0 : current.limit),
      resetAt: current.resetAt,
      adRewardedAvailable: current.adRewardedAvailable,
      adRewardAmount: current.adRewardAmount,
    );

    _localStates[type] = newState;

    _controller.add(QuotaUpdate(
      type: type,
      newState: newState,
      source: UpdateSource.localRefund,
    ));
  }

  /// 从服务端同步额度
  void syncFromServer(QuotaType type, int serverUsed) {
    final current = _localStates[type];
    if (current == null) return;

    final newState = QuotaState(
      type: current.type,
      window: current.window,
      limit: current.limit,
      used: serverUsed,
      resetAt: current.resetAt,
      adRewardedAvailable: current.adRewardedAvailable,
      adRewardAmount: current.adRewardAmount,
    );

    _localStates[type] = newState;

    // 清理已确认的 pending 记录
    _pendingConsumes.removeWhere(
      (c) => c.type == type && DateTime.now().difference(c.timestamp).inMinutes > 5,
    );

    _controller.add(QuotaUpdate(
      type: type,
      newState: newState,
      source: UpdateSource.serverSync,
    ));
  }

  /// 处理 WebSocket 推送的额度更新
  void _handleQuotaPush(Map<String, dynamic> data) {
    final typeStr = data['quotaType'] as String?;
    if (typeStr == null) return;

    final type = QuotaType.values.firstWhere(
      (t) => t.value == typeStr,
      orElse: () => QuotaType.aiChat,
    );

    final current = _localStates[type];
    if (current == null) return;

    final newState = QuotaState(
      type: type,
      window: QuotaWindow.values.firstWhere(
        (w) => w.value == data['window'],
        orElse: () => QuotaWindow.daily,
      ),
      limit: data['limit'] ?? current.limit,
      used: data['used'] ?? current.used,
      resetAt: DateTime.parse(data['resetAt']),
      adRewardedAvailable: data['adRewardedAvailable'] ?? false,
      adRewardAmount: data['adRewardAmount'] ?? 0,
    );

    _localStates[type] = newState;

    _controller.add(QuotaUpdate(
      type: type,
      newState: newState,
      source: UpdateSource.serverPush,
    ));
  }

  /// 检查并执行额度重置（本地定时检查）
  void checkAndResetExpired() {
    final now = DateTime.now();
    for (final entry in _localStates.entries) {
      final state = entry.value;
      if (now.isAfter(state.resetAt)) {
        // 本地重置：等待服务端推送确认
        final newState = QuotaState(
          type: state.type,
          window: state.window,
          limit: state.limit,
          used: 0,
          resetAt: _calculateNextReset(state.window),
          adRewardedAvailable: state.adRewardedAvailable,
          adRewardAmount: state.adRewardAmount,
        );
        _localStates[entry.key] = newState;

        _controller.add(QuotaUpdate(
          type: entry.key,
          newState: newState,
          source: UpdateSource.localReset,
        ));

        _logger.info('Quota reset: ${entry.key}');
      }
    }
  }

  DateTime _calculateNextReset(QuotaWindow window) {
    final now = DateTime.now();
    return switch (window) {
      QuotaWindow.daily => DateTime(now.year, now.month, now.day + 1),
      QuotaWindow.weekly => DateTime(now.year, now.month, now.day)
          .add(Duration(days: 7 - now.weekday % 7 + 1)),
      QuotaWindow.monthly => DateTime(now.year, now.month + 1, 1),
    };
  }

  String _generateTraceId() {
    return 'trace_${DateTime.now().millisecondsSinceEpoch}'
        '_${_pendingConsumes.length}';
  }

  void dispose() {
    _controller.close();
  }
}

/// 额度更新事件
class QuotaUpdate {
  final QuotaType type;
  final QuotaState newState;
  final UpdateSource source;

  const QuotaUpdate({
    required this.type,
    required this.newState,
    required this.source,
  });
}

  serverSync,     // 服务端同步校正
  serverPush,     // WebSocket 推送
  localReset,     // 本地定时重置
}

  final QuotaType type;
  final int amount;
  final DateTime timestamp;
  final String traceId;

  const PendingConsume({
    required this.type,
    required this.amount,
    required this.timestamp,
    required this.traceId,
  });
}
```

### 5.4 PaywallOrchestrator — Paywall 编排器

```dart
/// core/feature_gate/paywall_orchestrator.dart

/// Paywall 展示编排器
///
/// 负责管理全 App 的 Paywall 触发：
/// - 优先级仲裁：同一页面多个功能触发 Paywall 时，只展示一个
/// - 频率控制：避免短时间内反复弹窗
/// - 冷却期：用户 dismiss 后的一段时间内不再弹
/// - 场景归因：记录触发场景用于数据分析
/// - A/B 方案：根据实验分组选择不同 Paywall 样式
class PaywallOrchestrator {
  final EntitlementManager _entitlementManager;
  final NavigationService _navigation;
  final AnalyticsService _analytics;
  final AppLogger _logger;

  // 冷却期配置
  static const _cooldownDuration = Duration(minutes: 30);
  static const _maxDismissPerDay = 5;

  DateTime? _lastDismissTime;
  int _dismissCountToday = 0;
  String? _lastShownScene;
  DateTime? _lastShownTime;

  // 当前是否正在展示 Paywall（防止叠加）
  bool _isShowing = false;

  // 待展示的 Paywall 请求队列（按优先级排序）
  final List<PendingPaywall> _queue = [];

  PaywallOrchestrator({
    required EntitlementManager entitlementManager,
    required NavigationService navigation,
    required AnalyticsService analytics,
    required AppLogger logger,
  })  : _entitlementManager = entitlementManager,
        _navigation = navigation,
        _analytics = analytics,
        _logger = logger;

  /// 触发 Paywall
  ///
  /// 返回 true 表示 Paywall 已展示（或正在展示），
  /// 返回 false 表示因冷却期/频率限制被跳过。
  Future<bool> trigger({
    required BuildContext context,
    required GateDecision decision,
    required String scene,
  }) async {
    if (!decision.shouldShowPaywall) return false;

    // 1. 防叠加
    if (_isShowing) {
      _logger.debug('Paywall already showing, queuing: $scene');
      _queue.add(PendingPaywall(
        decision: decision,
        scene: scene,
        priority: _getScenePriority(scene),
        timestamp: DateTime.now(),
      ));
      _queue.sort((a, b) => b.priority.compareTo(a.priority));
      return true;
    }

    // 2. 冷却期检查
    if (_isInCooldown) {
      _logger.debug('Paywall in cooldown, skipping: $scene');
      return false;
    }

    // 3. 日频率检查
    if (_dismissCountToday >= _maxDismissPerDay) {
      _logger.debug('Paywall daily limit reached, skipping');
      return false;
    }

    // 4. 同场景去重（30 秒内同场景不重复弹）
    if (_lastShownScene == scene &&
        _lastShownTime != null &&
        DateTime.now().difference(_lastShownTime!) < const Duration(seconds: 30)) {
      return false;
    }

    // 5. 展示 Paywall
    _isShowing = true;
    _lastShownScene = scene;
    _lastShownTime = DateTime.now();

    final variant = _selectPaywallVariant();
    final upgradeSuggestion = decision.upgradeSuggestion!;

    // 埋点：Paywall 展示
    _analytics.track('paywall_shown', properties: {
      'scene': scene,
      'feature_key': decision.featureKey,
      'reason': decision.type.name,
      'recommended_tier': upgradeSuggestion.recommendedTier.code,
      'variant': variant,
      'remaining_quota': decision.remainingQuota,
    });

    // 展示并等待用户操作
    final result = await _navigation.push<PaywallResult>(
      context,
      PaywallPage(
        decision: decision,
        scene: scene,
        variant: variant,
      ),
    );

    _isShowing = false;

    // 处理结果
    _handlePaywallResult(result, scene, decision);

    // 处理队列中下一个
    if (_queue.isNotEmpty) {
      final next = _queue.removeAt(0);
      // 延迟 500ms 避免视觉叠加
      Future.delayed(const Duration(milliseconds: 500), () {
        trigger(
          context: context,
          decision: next.decision,
          scene: next.scene,
        );
      });
    }

    return true;
  }

  /// 手动触发升级页（非拦截场景，如用户主动点击"升级会员"）
  Future<void> openUpgradePage({
    required BuildContext context,
    String? source,
  }) async {
    _analytics.track('upgrade_page_opened', properties: {
      'source': source ?? 'manual',
      'current_tier': _entitlementManager.currentTier.code,
    });

    await _navigation.push(
      context,
      const PaywallPage.manualEntry(),
    );
  }

  /// Paywall 结果处理
  void _handlePaywallResult(
    PaywallResult? result,
    String scene,
    GateDecision decision,
  ) {
    if (result == null) {
      // 用户关闭
      _lastDismissTime = DateTime.now();
      _dismissCountToday++;

      _analytics.track('paywall_dismissed', properties: {
        'scene': scene,
        'feature_key': decision.featureKey,
        'dismiss_count_today': _dismissCountToday,
      });
      return;
    }

    switch (result.action) {
      case PaywallAction.purchased:
        _analytics.track('paywall_converted', properties: {
          'scene': scene,
          'feature_key': decision.featureKey,
          'new_tier': result.newTier?.code,
        });
        // 购买成功后，权益会通过 WebSocket 推送更新
        break;

      case PaywallAction.watchAd:
        _analytics.track('paywall_watch_ad', properties: {
          'scene': scene,
          'feature_key': decision.featureKey,
        });
        // 广告奖励额度由服务端推送
        break;

      case PaywallAction.usePoints:
        _analytics.track('paywall_use_points', properties: {
          'scene': scene,
        });
        break;

      case PaywallAction.dismissed:
        _lastDismissTime = DateTime.now();
        _dismissCountToday++;
        break;
    }
  }

  /// 选择 Paywall A/B 测试变体
  String _selectPaywallVariant() {
    final variant = _entitlementManager.getExperimentVariant('paywall_design');
    return variant ?? 'control';
  }

  /// 场景优先级
  int _getScenePriority(String scene) {
    return switch (scene) {
      'ai_dialog_quota_exhausted' => 80,
      'photo_search_quota_exhausted' => 70,
      'essay_correct_membership_locked' => 60,
      'exam_sim_membership_locked' => 50,
      'feature_locked' => 30,
      _ => 10,
    };
  }

  bool get _isInCooldown {
    if (_lastDismissTime == null) return false;
    return DateTime.now().difference(_lastDismissTime!) < _cooldownDuration;
  }

  /// 每日重置
  void resetDaily() {
    _dismissCountToday = 0;
  }
}
```

## 10. 错误处理与降级策略

### 10.1 网络异常降级

| 场景 | 处理策略 |
|------|----------|
| App 启动时拉取权益快照失败 | 使用本地缓存（可能过期），后台定期重试 |
| 额度检查请求超时 | 本地决策：基于缓存额度放行，服务端后续校正 |
| WebSocket 断连 | 降级为轮询拉取（每 5 分钟一次） |
| 支付后权益未即时刷新 | 支付成功页主动调用 `refresh()` + 重试机制 |

### 10.2 本地缓存过期处理

```dart
/// 缓存有效期：2 小时
/// 超过有效期后：
///   - 非关键功能：仍可使用缓存额度判断（best effort）
///   - 关键功能（支付、额度购买）：强制走服务端检查
static const _cacheMaxAge = Duration(hours: 2);

bool get _isCacheStale {
  if (_snapshot == null) return true;
  return DateTime.now().difference(_snapshot!.cachedAt) > _cacheMaxAge;
}

/// 关键操作不允许使用过期缓存
Future<bool> requireFreshSnapshot() async {
  if (!_isCacheStale) return true;
  
  try {
    await refresh();
    return true;
  } catch (_) {
    return false;
  }
}
```

```dart
  required QuotaType type,
  required String featureKey,
  required GateContext context,
  int amount = 1,
}) async {
```

```dart
/// 对于同一页面、同一功能的多次 canAccess 调用，
/// 在同一帧内做缓存避免重复计算
class GateDecisionCache {
  final _cache = <String, GateDecision>{};
  int _frameNumber = 0;

  GateDecision getOrCompute(
    String featureKey,
    String scene,
    GateDecision Function() compute,
  ) {
    final key = '${featureKey}_$scene';
    final cached = _cache[key];
    if (cached != null) return cached;

    final result = compute();
    _cache[key] = result;
    return result;
  }

  /// 每帧清空缓存
  void onFrameEnd() {
    _frameNumber++;
    if (_frameNumber % 60 == 0) {
      _cache.clear();
    }
  }
}
```

### 13.3 本地持久化优化

```dart
/// 权益快照使用 Protocol Buffers 或 JSON 序列化存储
/// 
/// 存储策略：
/// - SharedPreferences: 仅存最新快照的版本号、tier、核心额度（< 1KB）
/// - SQLite: 完整快照 JSON（用于恢复）
/// - Memory: 全部热数据
///
/// 写入策略：
/// - 去抖写入：合并 5 秒内的多次更新为一次磁盘写入
/// - 增量更新：只更新变化的 QuotaState，不重写整个快照

class EntitlementStorage {
  static const _spKey = 'entitlement_snapshot_meta';
  static const _dbTable = 'entitlement_snapshots';

  /// 快速恢复核心信息（< 5ms）
  Future<SnapshotMeta?> loadMeta() async {
    final json = _sharedPreferences.getString(_spKey);
    if (json == null) return null;
    return SnapshotMeta.fromJson(jsonDecode(json));
  }

  /// 完整快照加载（< 50ms）
  Future<EntitlementSnapshot?> loadSnapshot() async {
    final meta = await loadMeta();
    if (meta == null) return null;

    final row = await _database.query(
      _dbTable,
      where: 'version = ?',
      whereArgs: [meta.version],
      limit: 1,
    );
    if (row.isEmpty) return null;

    return EntitlementSnapshot.fromJson(
      jsonDecode(row.first['data'] as String),
    );
  }

  /// 去抖写入
  Timer? _debounceTimer;

  void saveSnapshot(EntitlementSnapshot snapshot) {
    // 立即更新内存 meta
    _sharedPreferences.setString(
      _spKey,
      jsonEncode({
        'version': snapshot.version,
        'tier': snapshot.tier.code,
        'cachedAt': snapshot.cachedAt.toIso8601String(),
      }),
    );

    // 去抖写入完整快照到 DB
    _debounceTimer?.cancel();
    _debounceTimer = Timer(const Duration(seconds: 5), () {
      _database.insert(
        _dbTable,
        {
          'version': snapshot.version,
          'data': jsonEncode(snapshot.toJson()),
          'updated_at': DateTime.now().toIso8601String(),
        },
        conflictAlgorithm: ConflictAlgorithm.replace,
      );
    });
  }
}
```

## 14. 安全考虑

### 14.1 防止权益篡改

1. **签名校验**：权益快照包含 HMAC-SHA256 签名，客户端使用内置公钥验签
2. **服务端权威**：本地扣减仅作为乐观更新，最终额度以服务端为准
3. **异常检测**：如果本地 used 与服务端 used 差异过大（>5），上报异常
4. **Root/越狱检测**：在 root 设备上，强制走服务端实时检查，不信任本地缓存

### 14.2 Paywall 防绕过

```dart
/// 关键功能在执行前仍然需要服务端确认
/// 不能仅依赖客户端门控判断
///
/// 策略：
/// - 低风险功能（浏览、查看）：客户端决策即可
/// - 高风险功能（AI 调用、支付）：客户端预判 + 服务端确认
/// - 超高风险（额度购买、积分兑换）：仅服务端决策

enum GateTrustLevel {
  /// 客户端决策即可（如：UI 是否显示会员标识）
  clientOnly,
  
  /// 客户端预判 + 服务端确认（如：AI 对话）
  clientOptimistic,
  
  /// 强制服务端决策（如：额度购买、支付）
  serverOnly,
}
```

| 额度耗尽 → Paywall 触发 | 正确展示 Paywall + 正确文案 |

| 离线 → 缓存决策 | 断网下基于缓存做出合理决策 |
| 恢复网络 → 数据校正 | 重连后本地额度被服务端校正 |

```dart
/// pages/ai_dialog/ai_dialog_page.dart

class AIDialogPage extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {

          // 输入栏
          _buildInputBar(context, ref, canSend, quotaState),
        ],
      ),
    );
  }

  Widget _buildInputBar(
    BuildContext context,
    WidgetRef ref,
    bool canSend,
    QuotaState? quota,
  ) {
    return SafeArea(
      child: Padding(
        padding: const EdgeInsets.all(12),
        child: Row(
          children: [
            // 拍照按钮
            GateAwareButton(
              featureKey: 'photo_search',
              scene: 'ai_dialog_toolbar',
              onAllowed: () => _openCamera(context),
              child: const Icon(Icons.camera_alt_outlined, size: 22),
            ),
            const SizedBox(width: 8),

            // 语音按钮
            GateAwareButton(
              featureKey: 'ai_voice_question',
              scene: 'ai_dialog_toolbar',
              onAllowed: () => _startVoiceInput(context),
              child: const Icon(Icons.mic_none, size: 22),
            ),
            const SizedBox(width: 8),

            // 输入框
            Expanded(
              child: TextField(
                decoration: InputDecoration(
                  hintText: canSend ? '输入你的问题...' : '今日免费次数已用完',
                  suffixIcon: IconButton(
                    icon: const Icon(Icons.send),
                    onPressed: canSend ? () => _sendMessage(context, ref) : null,
                  ),
                ),
                onSubmitted: canSend ? (_) => _sendMessage(context, ref) : null,
                enabled: canSend,
              ),
            ),
          ],
        ),
      ),
    );
  }

  void _sendMessage(BuildContext context, WidgetRef ref) {
    final gate = ref.read(featureGateEngineProvider);
    final textController = ref.read(inputControllerProvider);

    // 门控检查 + 本地扣减
    final decision = gate.tryConsume(
      featureKey: 'ai_chat',
      context: GateContext.current(context),
    );

    if (decision != null && decision.shouldShowPaywall) {
      // 触发 Paywall
      ref.read(paywallOrchestratorProvider).trigger(
            context: context,
            decision: decision,
            scene: 'ai_dialog_quota_exhausted',
          );
      
      // 回滚不会执行，因为 tryConsume 在拦截时不扣减
      return;
    }

    // 发送消息...
    _actualSendMessage(context, ref, textController.text);

    // 发送成功后，服务端会确认额度扣减
    // 如果服务端拒绝，在 API 回调中调用 gate.rollbackConsume()
  }
}
```
