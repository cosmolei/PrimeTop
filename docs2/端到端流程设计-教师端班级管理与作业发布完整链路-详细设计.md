## 1. 链路概述

### 1.1 链路定位

本链路覆盖教师从注册认证到完成一次完整教学闭环的全流程，涉及 **教师端**（Web 管理后台 / 小程序）、**学生端**（APP）、**家长端**（APP 家长中心）、**服务端**（多个微服务协同）四方交互。是 PrimeTop V2.0 阶段打开 B 端场景的核心链路。

### 2.3 认证审核策略

| 审核方式 | 触发条件 | 处理时效 |
|----------|----------|----------|
| 自动审核（快通道） | 提供教师资格证编号 + 系统对接教育部教师资格库验证 | 即时（< 30s） |
| 人工审核 | 仅提供学校信息或资格证照片 | 1-3 工作日 |
| 快速体验模式 | 不提供认证材料，仅验证手机号 | 即时开通（功能受限：最多1个班级、30学生） |

### 2.4 关键代码示例

```java
// TeacherCertService.java - 教师资格认证服务
@Service
public class TeacherCertService {
    
    @Autowired
    private TeacherMapper teacherMapper;
    @Autowired
    private CertVerificationClient certVerificationClient; // 教育部资格库接口
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    /**
     * 提交教师认证
     */
    @Transactional
    public TeacherCertResult submitCertification(Long teacherId, TeacherCertRequest request) {
        Teacher teacher = teacherMapper.selectById(teacherId);
        Preconditions.checkArgument(
            teacher.getCertStatus() == CertStatus.NONE || 
            teacher.getCertStatus() == CertStatus.FAILED,
            "当前状态不允许提交认证"
        );
        
        // 更新教师信息
        teacher.setCertNo(request.getCertNo());
        teacher.setSchoolName(request.getSchoolName());
        teacher.setSchoolCode(request.getSchoolCode());
        teacher.setTitle(request.getTitle());
        teacher.setSubjectIds(JsonUtils.toJson(request.getSubjectIds()));
        
        // 策略1：有资格证编号 → 自动验证
        if (StringUtils.isNotBlank(request.getCertNo())) {
            teacher.setCertStatus(CertStatus.VERIFYING);
            teacherMapper.updateById(teacher);
            
            // 异步调用教育部资格库
            eventPublisher.publishEvent(
                new CertVerifyEvent(teacherId, request.getCertNo(), request.getRealName())
            );
            
            return TeacherCertResult.autoVerifying(teacherId);
        }
        
        // 策略2：有资格证照片 → OCR + 人工审核
        if (CollectionUtils.isNotEmpty(request.getCertImages())) {
            teacher.setCertStatus(CertStatus.PENDING_MANUAL);
            teacherMapper.updateById(teacher);
            
            // 提交到人工审核队列
            eventPublisher.publishEvent(
                new ManualCertReviewEvent(teacherId, request.getCertImages())
            );
            
            return TeacherCertResult.manualReview(teacherId);
        }
        
        // 策略3：快速体验模式
        teacher.setCertStatus(CertStatus.QUICK_MODE);
        teacherMapper.updateById(teacher);
        
        return TeacherCertResult.quickMode(teacherId);
    }
    
    /**
     * 自动验证回调（教育部资格库返回结果）
     */
    @Transactional
    public void handleAutoVerifyResult(Long teacherId, boolean verified, String reason) {
        Teacher teacher = teacherMapper.selectById(teacherId);
        if (verified) {
            teacher.setCertStatus(CertStatus.VERIFIED);
            teacher.setCertVerifiedAt(LocalDateTime.now());
        } else {
            teacher.setCertStatus(CertStatus.FAILED);
        }
        teacherMapper.updateById(teacher);
        
        // 发送通知
        eventPublisher.publishEvent(
            new CertResultNotifyEvent(teacherId, verified, reason)
        );
    }
}
```

### 2.5 错误处理

| 错误场景 | 错误码 | 处理策略 |
|----------|--------|----------|
| 资格证号格式错误 | 50001 | 前端校验 + 后端二次校验，返回具体格式要求 |
| 资格证号已被其他账号认证 | 50002 | 提示联系客服，锁定该证号 |
| 资格库验证超时 | 50003 | 自动降级为人工审核，通知教师 |
| 重复提交认证 | 50004 | 幂等处理，返回当前审核状态 |
| OCR 识别失败 | 50005 | 提示重新上传清晰照片 |

### 3.3 并发控制与幂等

```java
// ClassJoinService.java - 学生加入班级
@Service
public class ClassJoinService {
    
    @Autowired
    private ClassStudentMapper classStudentMapper;
    @Autowired
    private ClassMapper classMapper;
    @Autowired
    private RedissonClient redissonClient;
    
    private static final String JOIN_IDEMPOTENT_KEY = "class:join:idempotent:";
    
    /**
     * 学生申请加入班级（幂等）
     */
    @Transactional
    public ClassJoinResult joinClass(Long studentId, String classCode) {
        // 1. 幂等检查：同一学生对同一班级只允许一条记录
        String idempotentKey = JOIN_IDEMPOTENT_KEY + studentId + ":" + classCode;
        RLock lock = redissonClient.getLock(idempotentKey);
        
        try {
            if (!lock.tryLock(0, 10, TimeUnit.SECONDS)) {
                throw new BusinessException(50100, "操作过于频繁，请稍后再试");
            }
            
            // 2. 查找班级
            Class clazz = classMapper.selectByClassCode(classCode);
            if (clazz == null) {
                throw new BusinessException(50101, "邀请码无效，请核实后重试");
            }
            if (clazz.getStatus() != ClassStatus.ACTIVE) {
                throw new BusinessException(50102, "该班级已停用或归档");
            }
            
            // 3. 检查是否已加入
            ClassStudent existing = classStudentMapper.selectByClassAndStudent(
                clazz.getId(), studentId
            );
            if (existing != null) {
                if (existing.getJoinStatus() == JoinStatus.APPROVED && existing.getStatus() == 1) {
                    return ClassJoinResult.alreadyJoined(clazz);
                }
                if (existing.getJoinStatus() == JoinStatus.PENDING) {
                    return ClassJoinResult.alreadyPending(clazz);
                }
                if (existing.getJoinStatus() == JoinStatus.REJECTED) {
                    // 被拒绝后允许重新申请
                    existing.setJoinStatus(JoinStatus.PENDING);
                    existing.setCreatedAt(LocalDateTime.now());
                    classStudentMapper.updateById(existing);
                    return ClassJoinResult.reApplied(clazz);
                }
            }
            
            // 4. 检查班级人数上限
            int currentCount = classStudentMapper.countByClassId(clazz.getId(), 
                JoinStatus.APPROVED);
            if (currentCount >= clazz.getMaxStudents()) {
                throw new BusinessException(50103, "班级人数已满，请联系教师");
            }
            
            // 5. 创建申请记录
            ClassStudent classStudent = new ClassStudent();
            classStudent.setClassId(clazz.getId());
            classStudent.setStudentId(studentId);
            classStudent.setJoinMethod(JoinMethod.INVITE_CODE);
            classStudent.setJoinStatus(JoinStatus.PENDING);
            classStudent.setStatus((byte) 1);
            classStudentMapper.insert(classStudent);
            
            // 6. 发送通知给教师
            eventPublisher.publishEvent(
                new StudentJoinApplyEvent(clazz.getId(), clazz.getCreatedBy(), studentId)
            );
            
            return ClassJoinResult.applied(clazz);
            
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new BusinessException(50000, "系统繁忙，请稍后再试");
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }
}
```

### 4.4 作业发布异步流水线

```java
// AssignmentPublishPipeline.java - 作业发布流水线
@Service
public class AssignmentPublishPipeline {
    
    @Autowired
    private AssignmentMapper assignmentMapper;
    @Autowired
    private AssignmentTaskMapper assignmentTaskMapper;
    @Autowired
    private ClassStudentMapper classStudentMapper;
    @Autowired
    private QuestionService questionService;
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    /**
     * 执行作业发布流水线
     * 触发条件：教师手动发布 或 定时任务触发
     */
    @Async("assignmentPublishExecutor")
    @DistributedLock(key = "'assignment:publish:' + #assignmentId", waitTime = 0)
    public void executePublishPipeline(Long assignmentId) {
        Assignment assignment = assignmentMapper.selectById(assignmentId);
        if (assignment == null || assignment.getStatus() != AssignmentStatus.DRAFT) {
            log.warn("作业 {} 状态不允许发布: {}", assignmentId, 
                assignment != null ? assignment.getStatus() : "不存在");
            return;
        }
        
        try {
            // Step 1: 校验题目有效性
            AssignmentContent content = JsonUtils.fromJson(assignment.getContent(), 
                AssignmentContent.class);
            ValidationResult validation = validateQuestions(content);
            if (!validation.isValid()) {
                log.error("作业 {} 题目校验失败: {}", assignmentId, validation.getErrors());
                notifyTeacher(assignment.getTeacherId(), assignmentId, 
                    "作业发布失败：题目校验不通过 - " + String.join("; ", validation.getErrors()));
                return;
            }
            
            // Step 2: 获取目标学生列表
            List<ClassStudent> students = classStudentMapper.selectApprovedStudents(
                assignment.getClassId()
            );
            if (students.isEmpty()) {
                log.warn("班级 {} 无已审核学生，跳过发布", assignment.getClassId());
                return;
            }
            
            // Step 3: 批量生成学生作业实例
            List<AssignmentTask> tasks = students.stream()
                .map(cs -> buildTask(assignment, cs))
                .collect(Collectors.toList());
            assignmentTaskMapper.batchInsert(tasks);
            
            // Step 4: 更新作业状态和统计
            assignment.setStatus(AssignmentStatus.PUBLISHED);
            assignment.setPublishedAt(LocalDateTime.now());
            assignment.setTotalStudents(students.size());
            assignment.setSubmittedCount(0);
            assignment.setGradedCount(0);
            assignmentMapper.updateById(assignment);
            
            // Step 5: 发送通知事件
            eventPublisher.publishEvent(new AssignmentPublishedEvent(
                assignmentId,
                assignment.getClassId(),
                assignment.getTeacherId(),
                assignment.getTitle(),
                assignment.getDeadlineAt(),
                students.stream().map(ClassStudent::getStudentId).collect(Collectors.toList())
            ));
            
            log.info("作业 {} 发布成功，目标学生 {} 人", assignmentId, students.size());
            
        } catch (Exception e) {
            log.error("作业 {} 发布异常", assignmentId, e);
            // 回滚状态
            assignment.setStatus(AssignmentStatus.DRAFT);
            assignmentMapper.updateById(assignment);
        }
    }
    
    private AssignmentTask buildTask(Assignment assignment, ClassStudent cs) {
        AssignmentTask task = new AssignmentTask();
        task.setAssignmentId(assignment.getId());
        task.setStudentId(cs.getStudentId());
        task.setClassId(assignment.getClassId());
        task.setStatus(TaskStatus.NOT_STARTED);
        return task;
    }
}
```

### 5.2 实时保存策略

学生答题过程中采用 **逐题实时保存** 策略，防止因网络异常或 APP 崩溃导致答题内容丢失。

```dart
// student_answer_provider.dart - 学生答题状态管理
class StudentAnswerProvider extends ChangeNotifier {
  final AssignmentApiService _apiService;
  final LocalStorageService _localStorage;
  
  // 内存答题缓存
  final Map<String, AnswerItem> _answers = {};
  
  // 脏标记：需要同步到服务端的答案
  final Set<String> _dirtyKeys = {};
  
  Timer? _syncTimer;
  
  /// 保存单题答案（本地优先 + 定期同步）
  Future<void> saveAnswer({
    required int assignmentId,
    required int sectionIndex,
    required int itemIndex,
    required String answer,
    List<String>? images,
  }) async {
    final key = '${sectionIndex}_${itemIndex}';
    
    _answers[key] = AnswerItem(
      sectionIndex: sectionIndex,
      itemIndex: itemIndex,
      answer: answer,
      images: images,
      updatedAt: DateTime.now(),
    );
    _dirtyKeys.add(key);
    notifyListeners();
    
    // 本地持久化（防崩溃丢失）
    await _localStorage.saveAnswerCache(assignmentId, key, _answers[key]!);
  }
  
  /// 启动定时同步（每30秒或切后台时触发）
  void startPeriodicSync(int assignmentId) {
    _syncTimer?.cancel();
    _syncTimer = Timer.periodic(Duration(seconds: 30), (_) {
      _syncDirtyAnswers(assignmentId);
    });
  }
  
  /// 同步脏数据到服务端
  Future<void> _syncDirtyAnswers(int assignmentId) async {
    if (_dirtyKeys.isEmpty) return;
    
    final dirtyAnswers = _dirtyKeys
        .map((key) => _answers[key])
        .whereType<AnswerItem>()
        .toList();
    
    try {
      await _apiService.batchSaveAnswers(assignmentId, dirtyAnswers);
      _dirtyKeys.clear();
    } catch (e) {
      log.warning('答案同步失败，将在下次重试: $e');
      // 本地已保存，不丢数据
    }
  }
  
  /// 提交作业
  Future<SubmitResult> submitAssignment(int assignmentId) async {
    // 1. 先同步所有脏答案
    await _syncDirtyAnswers(assignmentId);
    
    // 2. 校验完整性（检查必答题是否已答）
    final assignment = await _apiService.getAssignmentDetail(assignmentId);
    final validationResult = _validateCompleteness(assignment, _answers);
    if (!validationResult.isComplete) {
      return SubmitResult.incomplete(validationResult.missingItems);
    }
    
    // 3. 提交
    final result = await _apiService.submitAssignment(assignmentId);
    
    // 4. 清理本地缓存
    await _localStorage.clearAnswerCache(assignmentId);
    _answers.clear();
    _dirtyKeys.clear();
    _syncTimer?.cancel();
    
    return result;
  }
}
```

```java
public class AiGradingService {

    @Autowired
    private List<QuestionGrader> graders; // 策略模式，按题型分发
    
    /**
     * 批改一份学生作业
     */
    @Async("aiGradingExecutor")
    public void gradeAssignmentTask(Long assignmentId, Long taskId) {
        AssignmentTask task = assignmentTaskMapper.selectById(taskId);
        Assignment assignment = assignmentMapper.selectById(assignmentId);
        AssignmentContent content = parseContent(assignment.getContent());
        List<StudentAnswerItem> answers = parseAnswers(task.getAnswers());
        
        AiGradingResult result = new AiGradingResult();
        BigDecimal totalAutoScore = BigDecimal.ZERO;
        
        for (Section section : content.getSections()) {
            for (int i = 0; i < section.getItems().size(); i++) {
                Item item = section.getItems().get(i);
                StudentAnswerItem answer = findAnswer(answers, section.getIndex(), i);
                
                if (answer == null) {
                    result.addResult(section.getIndex(), i, 
                        GradeResult.unanswered(item.getScore()));
                    continue;
                }
                
                // 按题型选择批改器
                QuestionGrader grader = selectGrader(item.getType());
                GradeResult gradeResult = grader.grade(item, answer);
                
                result.addResult(section.getIndex(), i, gradeResult);
                totalAutoScore = totalAutoScore.add(
                    BigDecimal.valueOf(gradeResult.getScore())
                );
            }
        }
        
        // 汇总写入
        task.setAutoScore(totalAutoScore);
        task.setAiFeedback(JsonUtils.toJson(result));
        assignmentTaskMapper.updateById(task);
        
        // 生成错题记录（异步）
        eventPublisher.publishEvent(new GradingCompletedEvent(
            assignmentId, taskId, result
        ));
    }
    
    private QuestionGrader selectGrader(String questionType) {
        return graders.stream()
            .filter(g -> g.supports(questionType))
            .findFirst()
            .orElseThrow(() -> new IllegalStateException(
                "无对应批改器: " + questionType));
    }
```

```java
// AssignmentGradingService.java - 教师批改确认
@Service
public class AssignmentGradingService {
    
    /**
     * 教师批改单份作业
     */
    @Transactional
    public void gradeTask(Long assignmentId, Long taskId, TeacherGradeRequest request) {
        AssignmentTask task = assignmentTaskMapper.selectById(taskId);
        Assignment assignment = assignmentMapper.selectById(assignmentId);
        
        // 1. 校验权限：只有发布作业的教师或同班教师可批改
        validateGradingPermission(request.getTeacherId(), assignment);
        
        // 2. 校验状态：只有已提交的作业可批改
        if (task.getStatus() != TaskStatus.SUBMITTED) {
            throw new BusinessException(50200, "当前状态不允许批改");
        }
        
        // 3. 计算最终分数
        BigDecimal finalScore = calculateFinalScore(task, request);
        
        // 4. 更新批改信息
        task.setScore(finalScore);
        task.setManualScore(request.getManualScore());
        task.setGradedBy(request.getTeacherId());
        task.setGradedAt(LocalDateTime.now());
        task.setTeacherComment(request.getTeacherComment());
        task.setStatus(TaskStatus.GRADED);
        assignmentTaskMapper.updateById(task);
        
        // 5. 生成错题记录（标记的题目）
        if (CollectionUtils.isNotEmpty(request.getMistakesToRecord())) {
            eventPublisher.publishEvent(new MistakeRecordEvent(
                task.getStudentId(),
                assignmentId,
                taskId,
                request.getMistakesToRecord()
            ));
        }
        
        // 6. 更新作业统计
        updateAssignmentStats(assignmentId);
        
        // 7. 通知学生
        eventPublisher.publishEvent(new TaskGradedNotifyEvent(
            task.getStudentId(), assignmentId, taskId, finalScore
        ));
        
        // 8. 通知家长
        eventPublisher.publishEvent(new ParentTaskGradedEvent(
            task.getStudentId(), assignment.getTitle(), finalScore, 
            assignment.getTotalScore()
        ));
    }
    
    /**
     * 批量确认AI批改结果
     */
    @Transactional
    public BatchGradeResult batchConfirmAutoGrade(
            Long assignmentId, List<Long> taskIds, Long teacherId) {
        
        int confirmed = 0;
        int errors = 0;
        
        for (Long taskId : taskIds) {
            try {
                AssignmentTask task = assignmentTaskMapper.selectById(taskId);
                if (task.getStatus() != TaskStatus.SUBMITTED) continue;
                if (task.getAutoScore() == null) continue;
                
                // 确认AI分数为最终分数
                task.setScore(task.getAutoScore());
                task.setManualScore(task.getAutoScore());
                task.setGradedBy(teacherId);
                task.setGradedAt(LocalDateTime.now());
                task.setTeacherComment("已完成批改");
                task.setStatus(TaskStatus.GRADED);
                assignmentTaskMapper.updateById(task);
                
                confirmed++;
                
            } catch (Exception e) {
                log.error("批量确认批改失败, taskId={}", taskId, e);
                errors++;
            }
        }
        
        // 更新作业级统计
        updateAssignmentStats(assignmentId);
        
        return new BatchGradeResult(confirmed, errors);
    }
    
    /**
     * 最终分数 = max(autoScore, manualScore) 或按配置合并
     */
    private BigDecimal calculateFinalScore(AssignmentTask task, TeacherGradeRequest request) {
        // 如果教师给了手动分数，以手动分数为准
        if (request.getManualScore() != null) {
            return request.getManualScore();
        }
        // 否则使用AI自动分数
        return task.getAutoScore() != null ? task.getAutoScore() : BigDecimal.ZERO;
    }
}
```

```java
@Service
public class TeacherNotificationService {
    
    /**
     * 发送作业发布通知给全班学生
     */
    public void notifyAssignmentPublished(AssignmentPublishedEvent event) {
        // 1. 构建通知内容
        String title = "新作业：" + event.getTitle();
        String body = String.format("截止时间：%s，请及时完成",
            event.getDeadlineAt() != null 
                ? event.getDeadlineAt().format(DateTimeFormatter.ofPattern("MM月dd日 HH:mm"))
                : "不限时"
        );
        
        // 2. 批量查询学生设备Token
        List<DeviceToken> tokens = deviceService.getTokensByUserIds(
            event.getStudentIds()
        );
        
        // 3. 分通道发送
        // 3.1 站内信（必达）
        batchCreateInAppMessages(event.getStudentIds(), title, body, 
            Map.of("type", "assignment", "assignmentId", event.getAssignmentId().toString()));
        
        // 3.2 Push通知（尽力送达）
        pushService.batchSend(tokens, title, body, 
            Map.of("route", "/assignment/${assignmentId}"));
        
        // 3.3 家长通道（如果家长订阅了作业通知）
        List<Long> parentIds = parentService.getParentIdsByStudents(event.getStudentIds());
        List<DeviceToken> parentTokens = deviceService.getTokensByUserIds(parentIds);
        pushService.batchSend(parentTokens, 
            "班级新作业通知", 
            String.format("您的孩子班级发布了新作业：%s", event.getTitle()),
            Map.of("route", "/parent/assignment"));
    }
}
```

## 10. 跨链路异常处理与降级

### 10.1 关键异常场景

| 场景 | 影响 | 处理策略 |
|------|------|----------|
| AI 批改服务超时/不可用 | 自动判分失败 | 标记为"需人工批改"，教师手动批改 |
| 消息推送服务不可用 | 学生收不到作业通知 | 降级为站内信，学生下次打开APP可见 |
| 题库服务不可用 | 作业发布时题目校验失败 | 阻止发布，提示教师稍后重试 |
| 作业截止时大量并发提交 | 数据库压力骤增 | 请求排队（MQ），客户端显示"提交中" |
| 教师批改时学生已删除账号 | 外键关联异常 | 跳过该学生，不影响其他批改 |
| 班级邀请码被恶意刷量 | 大量垃圾申请 | 邀请码限流 + 教师审批制 |

## 11. 数据一致性保障

### 11.1 作业统计数据一致性

作业表的统计字段（`submitted_count`、`graded_count`、`avg_score`、`completion_rate`）通过异步事件更新，存在短暂不一致。采用以下策略保障最终一致：

```
学生提交 / 教师批改
       │
       ▼
  ┌──────────┐     ┌──────────────┐     ┌──────────────┐
  │ 写入主数据 │────>│ 发送领域事件  │────>│ 异步更新统计  │
  │ (事务内)   │     │ (事务提交后)  │     │ (最终一致)    │
  └──────────┘     └──────────────┘     └──────┬───────┘
                                              │
                                    ┌─────────▼─────────┐
                                    │ 定时对账任务(每5分钟)│
                                    │ 校正统计偏差        │
                                    └───────────────────┘
```

### 11.2 对账任务

```java
@Component
public class AssignmentStatsReconciliation {
    
    @Scheduled(fixedDelay = 300000) // 每5分钟
    public void reconcile() {
        // 查找最近24小时内有变动的作业
        List<Assignment> recentAssignments = assignmentMapper.selectRecentlyActive(
            LocalDateTime.now().minusHours(24)
        );
        
        for (Assignment assignment : recentAssignments) {
            // 从 task 表重新计算统计
            AssignmentStats actual = assignmentTaskMapper.calculateStats(
                assignment.getId()
            );
            
            // 比对差异
            Assignment cached = assignmentMapper.selectById(assignment.getId());
            if (needsUpdate(cached, actual)) {
                assignmentMapper.updateStats(assignment.getId(), actual);
                log.info("作业 {} 统计已校正", assignment.getId());
            }
        }
    }
}
```

```java
@Aspect
@Component
public class TeacherPermissionAspect {
    
    @Autowired
    private TeacherClassMapper teacherClassMapper;
    
    @Before("@annotation(requireTeacherRole)")
    public void checkPermission(JoinPoint joinPoint, RequireTeacherRole requireTeacherRole) {
        Long teacherId = SecurityContext.getCurrentTeacherId();
        Long classId = extractClassId(joinPoint.getArgs());
        String requiredRole = requireTeacherRole.value();
        
        TeacherClass teacherClass = teacherClassMapper.selectByTeacherAndClass(
            teacherId, classId
        );
        
        if (teacherClass == null || teacherClass.getStatus() != 1) {
            throw new ForbiddenException("您不是该班级的教师");
        }
        
        if (!hasRequiredRole(teacherClass.getRole(), requiredRole)) {
            throw new ForbiddenException("您的角色无权执行此操作");
        }
    }
    
    private boolean hasRequiredRole(byte actualRole, String requiredRole) {
        return switch (requiredRole) {
            case "HEAD_TEACHER" -> actualRole == 1;
            case "SUBJECT_TEACHER" -> actualRole == 1 || actualRole == 2;
            case "ASSISTANT" -> actualRole >= 1 && actualRole <= 3;
            default -> false;
        };
    }
}
```

## 15. 安全考量

### 15.1 数据隔离

- 教师只能查看自己管理的班级和学生数据
- 跨班级查询需明确关联关系（如教研组长）
- 学生个人数据（如AI对话历史）不对教师开放，仅展示学情统计

### 15.2 作业防作弊

- 限时作业在服务端控制起止时间，客户端不可篡改
- 学生答题提交时间以服务端时间为准
- 作业答案在截止前对学生不可见（即使已提交）
- 同一班级不同学生的题目顺序可随机打乱（可配置）

### 15.3 敏感信息保护

- 学生真实姓名在教师端脱敏展示（仅显示姓+名首字）
- 教师手机号不对外暴露
- 班级邀请码设置有效期和次数限制
