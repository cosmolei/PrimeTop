# 中文朗读能力智能评估与口语表达诊断训练引擎 — 详细设计

> **模块定位**：AI 能力层 / 学习服务层
> **优先级**：P2（V1.5 阶段）
> **关联模块**：语音服务(ASR-TTS)、文科背诵、同步课堂学习、拼音识字启蒙、学情分析
> **文档版本**：1.0  | **日期**：2026-06-26

---

## 1. 概述与设计目标

### 1.1 背景与问题

中国语文课程标准对各学段明确提出"用普通话正确、流利、有感情地朗读课文"的要求。朗读是语文教学的核心训练手段，覆盖识字、阅读理解、语感培养、审美鉴赏等多个维度。

现有产品在中文语音方面主要覆盖：
- **拼音识字启蒙**：侧重声韵母认读和单字发音
- **文科背诵检测**：侧重记忆完整度，通过语音识别判断背诵内容是否正确
- **通用 ASR/TTS**：提供基础设施能力

**缺失环节**：缺少专门针对**中文课文朗读场景**的多维度评估能力，包括：
- 普通话声韵调准确性（不是英语音素，而是中文声母/韵母/声调）
- 朗读流利度（语速、停顿、回读）
- 有感情朗读的表现力（重音、语调、节奏）
- 与教材课文对齐的字-词-句-段分级诊断

### 1.2 设计目标

| 目标 | 描述 |
|------|------|
| 多维评估 | 从声韵调准确性、流利度、表现力三个维度对朗读进行评分 |
| 课文对齐 | 支持将学生朗读音频与教材标准课文进行字级对齐，定位具体错误 |
| 分龄适配 | 不同学段采用不同评估标准和反馈策略 |
| 个性化训练 | 基于诊断结果生成针对性训练任务（绕口令、篇章朗读等） |
| 数据沉淀 | 朗读评估数据纳入学情画像，追踪朗读能力成长轨迹 |

### 1.3 与现有模块的边界

| 能力 | 归属模块 | 本模块角色 |
|------|----------|------------|
| 音频采集与预处理 | 客户端-语音交互/音频播放器与录制引擎 | 调用方，接收处理后音频 |
| ASR 语音识别 | 语音服务(ASR-TTS) | 依赖其提供音素级时间戳对齐结果 |
| TTS 语音合成 | 语音服务(ASR-TTS) | 依赖其生成标准朗读范本音频 |
| 拼音声调基础训练 | 拼音识字启蒙 | 为低年级提供基础衔接 |
| 背诵内容完整度检测 | 文科背诵内容管理与记忆效果检测 | 共享音频提交链路，评估维度不同 |
| 朗读能力成长追踪 | 学情分析/学生电子成长档案 | 输出朗读能力维度数据 |

## 2. 评估模型架构

### 2.1 三维评估框架

```
┌─────────────────────────────────────────────────────────────┐
│                   中文朗读能力总评分 (0-100)                   │
├─────────────────┬──────────────────┬────────────────────────┤
│  声韵调准确性    │   朗读流利度      │    朗读表现力           │
│  (Accuracy)     │   (Fluency)      │   (Expressiveness)     │
│  权重: 40%      │   权重: 35%       │   权重: 25%            │
├─────────────────┼──────────────────┼────────────────────────┤
│ · 声母准确率     │ · 语速适当性      │ · 重音处理             │
│ · 韵母准确率     │ · 停顿合理性      │ · 语调变化             │
│ · 声调准确率     │ · 回读次数        │ · 情感表达             │
│ · 音变处理       │ · 断句准确性      │ · 节奏韵律             │
│  (轻声/儿化/    │ · 语速稳定性      │ · 音量控制             │
│   变调/啊的变读) │ · 流畅连读        │ · 段落层次区分         │
└─────────────────┴──────────────────┴────────────────────────┘
```

### 2.2 分学段评估权重矩阵

| 学段 | 声韵调准确性 | 流利度 | 表现力 | 说明 |
|------|-------------|--------|--------|------|
| 幼儿（大班） | 60% | 30% | 10% | 侧重拼音准确性，情感要求低 |
| 小学低年级（1-2） | 55% | 30% | 15% | 重视字音准确，鼓励有感情朗读 |
| 小学中年级（3-4） | 45% | 35% | 20% | 提升流利度要求，开始注重表现力 |
| 小学高年级（5-6） | 35% | 35% | 30% | 三维均衡，表现力权重提升 |
| 初中 | 25% | 35% | 40% | 重视情感表达和文本理解 |
| 高中 | 20% | 30% | 50% | 表现力为主，强调审美鉴赏 |

### 2.3 评估流程

```
学生提交朗读音频
       │
       ▼
┌──────────────────┐
│  1. 音频预处理     │  ← 降噪、VAD、重采样至16kHz
└──────┬───────────┘
       ▼
┌──────────────────┐
│  2. ASR识别+对齐   │  ← 声学模型输出音素级时间戳
└──────┬───────────┘     返回: 文本识别结果 + 字级时间戳 + 音素对齐
       ▼
┌──────────────────┐
│  3. 文本对齐校验   │  ← 与标准课文进行字级Diff对齐
└──────┬───────────┘     输出: 正确字/错字/漏字/多字 标注
       ▼
┌──────────────────┐
│  4. 声韵调评分     │  ← 逐字音素对比，声母/韵母/声调分评
└──────┬───────────┘
       ▼
┌──────────────────┐
│  5. 流利度评分     │  ← 基于时间戳分析停顿、回读、语速
└──────┬───────────┘
       ▼
┌──────────────────┐
│  6. 表现力评分     │  ← 韵律特征提取 + AI模型评估
└──────┬───────────┘
       ▼
┌──────────────────┐
│  7. 综合报告生成   │  ← 多维评分 + 字级标注 + 改进建议
└──────────────────┘
```

## 3. 数据结构定义

### 3.1 核心数据表

#### 3.1.1 朗读评估任务表 `oral_reading_task`

```sql
CREATE TABLE oral_reading_task (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id         VARCHAR(36) NOT NULL UNIQUE COMMENT 'UUID',
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    task_type       TINYINT NOT NULL COMMENT '任务类型: 1-课文朗读 2-古诗文朗读 3-自由朗读 4-绕口令训练 5-拼音专项',
    subject_content_id BIGINT COMMENT '关联的内容/课文ID (task_type=1,2时必填)',
    
    -- 课文信息冗余（减少关联查询）
    textbook_id     VARCHAR(32) COMMENT '教材版本ID',
    grade_code      VARCHAR(16) COMMENT '年级编码: K-幼儿园 P1-P6-小学 J1-J3-初中 S1-S3-高中',
    subject         VARCHAR(16) COMMENT '学科: CHINESE',
    chapter_id      VARCHAR(64) COMMENT '章节ID',
    content_title   VARCHAR(256) COMMENT '朗读材料标题',
    reference_text  TEXT COMMENT '标准课文文本',
    reference_pinyin TEXT COMMENT '标准课文拼音序列(JSON)',
    
    -- 音频信息
    audio_url       VARCHAR(512) NOT NULL COMMENT '学生朗读音频URL',
    audio_duration_ms INT COMMENT '音频时长(毫秒)',
    
    -- 状态管理
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '0-待处理 1-处理中 2-已完成 3-处理失败 4-已取消',
    error_code      VARCHAR(32) COMMENT '失败错误码',
    error_msg       VARCHAR(512) COMMENT '失败错误信息',
    
    -- 提交上下文
    source          TINYINT NOT NULL DEFAULT 0 COMMENT '来源: 0-同步课堂 1-背诵作业 2-自由练习 3-教师布置 4-AI推荐',
    client_type     TINYINT NOT NULL COMMENT '客户端: 1-Android 2-iOS 3-Web',
    device_id       VARCHAR(64) COMMENT '设备ID',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    processed_at    DATETIME COMMENT '处理完成时间',
    
    INDEX idx_user_created (user_id, created_at),
    INDEX idx_status_created (status, created_at),
    INDEX idx_content (subject_content_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='朗读评估任务表';
```

#### 3.1.2 朗读评估结果表 `oral_reading_result`

```sql
CREATE TABLE oral_reading_result (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,

    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    
    -- 总评分
    overall_score   DECIMAL(5,2) NOT NULL COMMENT '总评分(0-100)',
    accuracy_score  DECIMAL(5,2) NOT NULL COMMENT '声韵调准确性得分(0-100)',
    fluency_score   DECIMAL(5,2) NOT NULL COMMENT '流利度得分(0-100)',
    express_score   DECIMAL(5,2) NOT NULL COMMENT '表现力得分(0-100)',
    grade_level     VARCHAR(8) COMMENT '评级: S/A/B/C/D',
    
    -- 声韵调详细数据
    initial_accuracy   DECIMAL(5,2) COMMENT '声母准确率(%)',
    final_accuracy     DECIMAL(5,2) COMMENT '韵母准确率(%)',
    tone_accuracy      DECIMAL(5,2) COMMENT '声调准确率(%)',
    sandhi_accuracy    DECIMAL(5,2) COMMENT '音变处理准确率(%)',
    error_phonemes     JSON COMMENT '错误音素详情(数组)',
    
    -- 流利度详细数据
    speech_rate     DECIMAL(5,2) COMMENT '语速(字/分钟)',
    speech_rate_eval VARCHAR(8) COMMENT '语速评价: SLOW/PROPER/FAST',
    pause_count     INT COMMENT '不当停顿次数',
    reread_count    INT COMMENT '回读次数',
    avg_pause_dur_ms INT COMMENT '平均停顿时长(毫秒)',
    
    -- 表现力详细数据
    intonation_score    DECIMAL(5,2) COMMENT '语调得分',
    rhythm_score        DECIMAL(5,2) COMMENT '节奏得分',
    emotion_score       DECIMAL(5,2) COMMENT '情感表达得分',
    
    -- 字级标注
    char_align_result JSON COMMENT '字级对齐结果(数组)',
    
    -- ASR原始数据
    asr_text        TEXT COMMENT 'ASR识别文本',
    asr_confidence  DECIMAL(5,4) COMMENT 'ASR置信度',
    
    -- AI反馈
    feedback_text   TEXT COMMENT 'AI生成的综合反馈文本',
    suggestions     JSON COMMENT '改进建议列表',
    recommended_actions JSON COMMENT '推荐训练动作',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_user_created (user_id, created_at),
    INDEX idx_score (overall_score),
    INDEX idx_grade_level (grade_level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='朗读评估结果表';
```

## 5. 核心算法设计

### 5.1 文本对齐算法（字级 Diff + 时间戳映射）

朗读评估的核心前提是将学生朗读音频与标准课文进行精确的字级对齐。

#### 算法选择

采用**动态规划（DP）序列对齐 + ASR 时间戳**的混合方案：

```python
"""
字级文本对齐算法
输入：标准课文文本 ref_text, ASR识别结果 asr_result(含时间戳)
输出：对齐后的字级列表 char_alignments
"""
import editdistance

def align_reading_to_reference(ref_text: str, asr_result: dict) -> list[dict]:
    """
    ref_text:   "春眠不觉晓，处处闻啼鸟。"
    asr_result: {"text": "春眠不觉小，处处闻提鸟。", "words": [...]}
    """
    ref_chars = list(ref_text)
    asr_chars = list(asr_result["text"])
    asr_timestamps = asr_result["word_timestamps"]  # [{char, start, end}, ...]
    
    # Step 1: 去除标点后的字符序列对齐
    ref_clean = [c for c in ref_chars if c not in PUNCTUATIONS]
    asr_clean = [c for c in asr_chars if c not in PUNCTUATIONS]
    
    # Step 2: 使用改进的 Levenshtein 距离进行对齐
    # 对中文汉字操作集：match / substitute / insert(多读) / delete(漏读)
    alignment = needleman_wunsch_align(ref_clean, asr_clean,
                                        match_score=1,
                                        mismatch_penalty=-1,
                                        gap_penalty=-2)
    
    # Step 3: 将时间戳映射回对齐结果
    result = []
    for align_item in alignment:
        entry = {
            "index": len(result),
            "expected": align_item.ref_char,
            "actual": align_item.asr_char,  
            "isCorrect": align_item.ref_char == align_item.asr_char,
            "startTime": align_item.timestamp_start,
            "endTime": align_item.timestamp_end,
            "errorType": classify_error(align_item),
        }
        result.append(entry)
    
    return result

def needleman_wunsch_align(seq1, seq2, match_score, mismatch_penalty, gap_penalty):
    """
    全局对齐算法，适用于朗读场景的文本-识别结果对齐
    返回对齐路径上的操作序列
    """
    m, n = len(seq1), len(seq2)
    # DP矩阵
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    # 回溯矩阵
    trace = [[None] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        dp[i][0] = dp[i-1][0] + gap_penalty
        trace[i][0] = "DELETE"  # ref有，asr没有 → 漏读
    for j in range(1, n + 1):
        dp[0][j] = dp[0][j-1] + gap_penalty
        trace[0][j] = "INSERT"  # ref没有，asr有 → 多读
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            match = dp[i-1][j-1] + (match_score if seq1[i-1] == seq2[j-1] else mismatch_penalty)
            delete = dp[i-1][j] + gap_penalty
            insert = dp[i][j-1] + gap_penalty
            
            best = max(match, delete, insert)
            dp[i][j] = best
            
            if best == match:
                trace[i][j] = "MATCH" if seq1[i-1] == seq2[j-1] else "SUBSTITUTE"
            elif best == delete:
                trace[i][j] = "DELETE"
            else:
                trace[i][j] = "INSERT"
    
    # 回溯生成对齐结果
    return backtrack(trace, seq1, seq2)
```

### 5.2 声韵调评分算法

```python
"""
基于音素级对齐的声韵调三维度评分
依赖：声学模型输出的音素级置信度 + 拼音知识库
"""

def score_pronunciation(char_alignments: list[dict], 
                         user_grade: str) -> dict:
    """
    返回三维度得分 + 详细错误分析
    """
    initial_scores = []  # 声母得分
    final_scores = []    # 韵母得分
    tone_scores = []     # 声调得分
    sandhi_scores = []   # 音变得分
    error_details = []
    
    for item in char_alignments:
        if not item["isCorrect"] and item["errorType"] == "OMISSION":
            # 漏读的字：各维度均计0分
            initial_scores.append(0)
            final_scores.append(0)
            tone_scores.append(0)
            error_details.append({
                "char": item["expected"],
                "type": "OMISSION",
                "message": f"漏读了'{item['expected']}'"
            })
            continue
        
        ref_pinyin = get_pinyin(item["expected"], tone_sandhi=True)
        actual_pinyin = infer_actual_pinyin(item, ref_pinyin)

        ini_score = score_initial(ref_pinyin.initial, 
                                   actual_pinyin.initial,

        initial_scores.append(ini_score)

        fin_score = score_final(ref_pinyin.final,
                                 actual_pinyin.final,
                                 item.get("phoneme_confidence"))
        final_scores.append(fin_score)
        
        # 声调评分

        if has_sandhi_context(item, char_alignments):
            sandhi_score = evaluate_sandhi(item, char_alignments)
            sandhi_scores.append(sandhi_score)
        
        # 记录错误
        if ini_score < THRESHOLD or fin_score < THRESHOLD or tone_score < THRESHOLD:
            error_details.append({
                "char": item["expected"],
                "pinyin": f"{ref_pinyin.initial}{ref_pinyin.final}{tone_mark(ref_pinyin.tone)}",

                "toneScore": tone_score,

    # 加权汇总
    accuracy_overall = (
        weighted_mean(initial_scores, weights=get_initial_weights(user_grade)) * 0.35 +

    return {

        "initialAccuracy": round(mean(initial_scores) * 100, 2),
        "finalAccuracy": round(mean(final_scores) * 100, 2),
        "toneAccuracy": round(mean(tone_scores) * 100, 2),
        "sandhiAccuracy": round(mean(sandhi_scores) * 100, 2) if sandhi_scores else None,
```

```python
"""
基于时间戳和停顿模式的流利度评估

def score_fluency(char_alignments: list[dict], 
                  audio_duration_s: float,
                  user_grade: str) -> dict:
    
    valid_chars = [c for c in char_alignments if c.get("startTime") is not None]
    char_count = len(valid_chars)
    
    # 1. 语速计算 (字/分钟)
    speech_rate = (char_count / audio_duration_s) * 60
    
    # 2. 停顿分析
    pauses = []
    rereads = []
    for i in range(1, len(valid_chars)):
        gap = valid_chars[i]["startTime"] - valid_chars[i-1]["endTime"]
        
        if gap > PAUSE_THRESHOLD_MS[user_grade]:  # 不同年级停顿阈值不同
            # 判断停顿是否合理（标点位置 vs 非标点位置）
            prev_char = valid_chars[i-1]["expected"]
            is_punctuation_pause = prev_char in PUNCTUATIONS
            
            pauses.append({
                "position": i,
                "duration": gap,
                "isAppropriate": is_punctuation_pause,
                "charBefore": prev_char
            })
    
    # 3. 回读检测（基于ASR置信度变化和重复片段）
    rereads = detect_reread_segments(valid_chars)
    
    # 4. 评分计算
    rate_score = score_speech_rate(speech_rate, user_grade)         # 0-100
    pause_score = score_pauses(pauses, char_count)                   # 0-100
    reread_penalty = max(0, 100 - len(rereads) * 10)                 # 每次回读扣10分
    
    fluency_score = (
        rate_score * 0.30 +
        pause_score * 0.45 +
        reread_penalty * 0.25
    )
    
    return {

            "totalPauses": len(pauses),
            "appropriatePauses": len([p for p in pauses if p["isAppropriate"]]),
            "inappropriatePauses": len([p for p in pauses if not p["isAppropriate"]]),
        }
    }
```

### 6.2 异步处理流水线

朗读评估是计算密集型任务，采用异步消息驱动架构：

```java
/**
 * 朗读评估异步处理流水线
 */
@Service
public class OralReadingPipelineService {
    
    @Autowired private OralReadingTaskMapper taskMapper;
    @Autowired private AsrClient asrClient;
    @Autowired private ProsodyAnalysisClient prosodyClient;
    @Autowired private EvaluationEngine evaluationEngine;
    @Autowired private FeedbackGenerator feedbackGenerator;
    @Autowired private AbilityUpdater abilityUpdater;
    @Autowired private EventPublisher eventPublisher;
    
    /**
     * 消费评估任务队列
     */
    @RabbitListener(queues = "queue.oral-reading.eval")
    public void processEvaluationTask(String taskId) {
        OralReadingTask task = taskMapper.selectByTaskId(taskId);
        if (task == null || task.getStatus() != TaskStatus.PENDING) {
            return;
        }
        
        try {
            // 更新状态为处理中
            taskMapper.updateStatus(taskId, TaskStatus.PROCESSING);
            
            // Step 1: ASR 识别 + 音素级对齐
            AsrResult asrResult = asrClient.recognizeWithAlignment(
                task.getAudioUrl(), 
                Language.ZH_CN,
                AsrMode.FORCE_ALIGN,    // 强制对齐模式（用参考文本引导）
                task.getReferenceText()
            ).orElseThrow(() -> new EvaluationException("ASR_FAILED", "语音识别失败"));
            
            // Step 2: 韵律特征提取（并行）
            CompletableFuture<ProsodyFeatures> prosodyFuture = CompletableFuture.supplyAsync(
                () -> prosodyClient.extractFeatures(task.getAudioUrl(), asrResult.getTimestamps())
            );
            
            // Step 3: 字级文本对齐
            List<CharAlignment> alignments = evaluationEngine.alignText(
                task.getReferenceText(), 
                asrResult
            );
            
            // Step 4: 多维度评分（并行计算）
            CompletableFuture<PronunciationScore> accFuture = CompletableFuture.supplyAsync(
                () -> evaluationEngine.scorePronunciation(alignments, task.getGradeCode())
            );
            ProsodyFeatures prosody = prosodyFuture.join();
            CompletableFuture<FluencyScore> fluencyFuture = CompletableFuture.supplyAsync(
                () -> evaluationEngine.scoreFluency(alignments, prosody, task.getGradeCode())
            );
            CompletableFuture<ExpressivenessScore> expressFuture = CompletableFuture.supplyAsync(
                () -> evaluationEngine.scoreExpressiveness(prosody, task)
            );
            
            PronunciationScore accScore = accFuture.join();
            FluencyScore fluencyScore = fluencyFuture.join();
            ExpressivenessScore expressScore = expressFuture.join();
            
            // Step 5: 计算加权总分
            WeightConfig weights = WeightConfig.forGrade(task.getGradeCode());
            double overallScore = 
                accScore.getOverall() * weights.getAccuracy() +
                fluencyScore.getScore() * weights.getFluency() +
                expressScore.getScore() * weights.getExpressiveness();
            
            // Step 6: 生成反馈
            OralReadingFeedback feedback = feedbackGenerator.generate(
                task, alignments, accScore, fluencyScore, expressScore, overallScore
            );
            
            // Step 7: 持久化结果
            OralReadingResult result = OralReadingResult.builder()
                .taskId(taskId)
                .userId(task.getUserId())
                .overallScore(overallScore)
                .accuracyScore(accScore.getOverall())
                .fluencyScore(fluencyScore.getScore())
                .expressScore(expressScore.getScore())
                .gradeLevel(OralReadingGradeLevel.fromScore(overallScore))
                .charAlignResult(alignments)
                .errorPhonemes(accScore.getErrorDetails())
                .feedbackText(feedback.getFeedbackText())
                .suggestions(feedback.getSuggestions())
                .build();
            resultMapper.insert(result);
            
            // Step 8: 更新朗读能力画像
            abilityUpdater.updateAbility(task.getUserId(), result);
            
            // Step 9: 发布领域事件
            eventPublisher.publish(new OralReadingEvaluatedEvent(task, result));
            
            // 完成
            taskMapper.updateStatus(taskId, TaskStatus.COMPLETED);
            
        } catch (Exception e) {
            log.error("朗读评估失败, taskId={}", taskId, e);
            taskMapper.updateStatusWithError(taskId, TaskStatus.FAILED, 
                ErrorCode.fromException(e));
            
            // 失败重试（最多3次，间隔30秒）
            if (task.getRetryCount() < 3) {
                scheduleRetry(taskId, Duration.ofSeconds(30));
            }
        }
    }
}
```

### 7.1 综合反馈生成

```java
@Service
public class FeedbackGenerator {
    
    private static final String FEEDBACK_PROMPT_TEMPLATE = """
        你是一位经验丰富的小学/中学语文老师，正在为学生提供朗读反馈。
        请根据以下朗读评估数据，生成温暖、具体、可操作的反馈。
        
        ## 学生信息
        - 年级: {gradeLabel}
        - 朗读材料: {contentTitle}
        - 材料类型: {contentType}
        
        ## 评估数据
        - 总评分: {overallScore}/100 ({gradeLevel})
        - 声韵调准确性: {accuracyScore}/100
        - 流利度: {fluencyScore}/100
        - 表现力: {expressScore}/100
        
        ## 主要问题（按严重程度排序）
        {errorHighlights}
        
        ## 朗读特征数据
        - 语速: {speechRate}字/分钟 ({speechRateEval})
        - 不当停顿: {pauseCount}次
        - 回读: {rereadCount}次
        
        ## 反馈要求
        1. 开头用一句鼓励性的话
        2. 肯定做得好的方面（必须有）
        3. 指出最多3个需要改进的点，每个点要具体到字
        4. 给出1-2条可以立即执行的练习建议
        5. 语气: {toneRequirement}
        6. 字数: 100-200字
        7. 不要用"很好""不错"等空泛评价
        
        请直接输出反馈文本，不需要额外格式。
        """;
    
    public OralReadingFeedback generate(OralReadingTask task,
                                         List<CharAlignment> alignments,
                                         PronunciationScore accScore,
                                         FluencyScore fluencyScore,
                                         ExpressivenessScore expressScore,
                                         double overallScore) {
        
        // 构建错误高亮列表
        String errorHighlights = alignments.stream()
            .filter(a -> !a.isCorrect())
            .limit(5)
            .map(a -> String.format("- '%s'(应读%s): %s", 
                a.getExpected(), a.getPinyin(), a.getErrorDescription()))
            .collect(Collectors.joining("\n"));
        
        // 根据年级选择语气
        String toneRequirement = switch (task.getGradeGroup()) {
            case KINDERGARTEN, LOWER_PRIMARY -> "亲切温暖，像大姐姐一样，多用鼓励";
            case UPPER_PRIMARY -> "友好但具体，像喜欢的老师";
            case JUNIOR_HIGH, SENIOR_HIGH -> "平和专业，直接有用";
        };
        
        String prompt = FEEDBACK_PROMPT_TEMPLATE
            .replace("{gradeLabel}", GradeUtil.gradeToLabel(task.getGradeCode()))
            .replace("{contentTitle}", task.getContentTitle())
            .replace("{contentType}", task.getContentType().getDescription())
            .replace("{overallScore}", String.format("%.1f", overallScore))
            .replace("{gradeLevel}", OralReadingGradeLevel.fromScore(overallScore).getLabel())
            .replace("{accuracyScore}", String.format("%.1f", accScore.getOverall()))
            .replace("{fluencyScore}", String.format("%.1f", fluencyScore.getScore()))
            .replace("{expressScore}", String.format("%.1f", expressScore.getScore()))
            .replace("{errorHighlights}", errorHighlights)
            .replace("{speechRate}", String.format("%.0f", fluencyScore.getSpeechRate()))
            .replace("{speechRateEval}", fluencyScore.getSpeechRateEval())
            .replace("{pauseCount}", String.valueOf(fluencyScore.getPauseCount()))
            .replace("{rereadCount}", String.valueOf(fluencyScore.getRereadCount()))
            .replace("{toneRequirement}", toneRequirement);
        
        String feedbackText = llmClient.complete(prompt, ModelTier.STANDARD);
        
        // 生成结构化建议
        List<PracticeSuggestion> suggestions = generateSuggestions(
            accScore, fluencyScore, expressScore, alignments, task);
        
        return new OralReadingFeedback(feedbackText, suggestions);
    }
    
    private List<PracticeSuggestion> generateSuggestions(
            PronunciationScore acc, FluencyScore flu, ExpressivenessScore exp,
            List<CharAlignment> alignments, OralReadingTask task) {
        
        List<PracticeSuggestion> suggestions = new ArrayList<>();
        
        // 优先级 1: 声调错误 > 声母/韵母错误
        List<CharAlignment> toneErrors = alignments.stream()
            .filter(a -> a.hasErrorType(OralReadingErrorType.TONE_ERROR))
            .collect(Collectors.toList());
        
        if (!toneErrors.isEmpty()) {
            // 生成声调专项练习
            String toneType = toneErrors.get(0).getErrorDetail().getCorrectTone();
            suggestions.add(PracticeSuggestion.builder()
                .type("TONE_PRACTICE")
                .title(toneType + "声调专项练习")
                .description("针对声调发音进行强化训练")
                .practiceItems(generateTonePracticeItems(toneErrors))
                .build());
        }
        
        // 优先级 2: s/sh, c/ch, z/zh, n/l, f/h 等常见混淆
        Optional<PhonemeConfusion> confusion = detectPhonemeConfusion(alignments);
        if (confusion.isPresent()) {
            suggestions.add(PracticeSuggestion.builder()
                .type("TONGUE_TWISTER")
                .title("绕口令：" + confusion.get().getDescription())
                .description(confusion.get().getDescription())
                .practiceItems(confusion.get().getTongueTwisters())
                .build());
        }
        
        // 优先级 3: 表现力不足
        if (exp.getScore() < 70) {
            suggestions.add(PracticeSuggestion.builder()
                .type("REREAD_GUIDANCE")
                .title("再读一遍《" + task.getContentTitle() + "》")
                .description("带着反馈重新朗读，重点关注情感表达")
                .focusPoints(generateExpressionFocusPoints(task))
                .build());
        }
        
        return suggestions;
    }
}
```

```java
@Service
public class OralReadingTrainingRecommender {
    
    /**
     * 根据最近评估结果生成训练推荐
     */
    public List<TrainingTask> recommend(Long userId) {
        // 1. 获取最近10次评估结果
        List<OralReadingResult> recentResults = resultMapper
            .selectRecentByUserId(userId, 10);
        
        // 2. 分析薄弱维度
        AbilityProfile profile = analyzeAbilityProfile(recentResults);
        
        // 3. 根据薄弱维度生成任务
        List<TrainingTask> tasks = new ArrayList<>();
        
        // 维度1: 声韵调薄弱 → 声母/韵母/声调专项
        if (profile.getAccuracyScore() < ACCURACY_THRESHOLD) {
            tasks.addAll(generatePronunciationTasks(profile));
        }
        
        // 维度2: 流利度薄弱 → 课文朗读 + 语速训练
        if (profile.getFluencyScore() < FLUENCY_THRESHOLD) {
            tasks.addAll(generateFluencyTasks(profile));
        }
        
        // 维度3: 表现力薄弱 → 情感朗读 + 范文跟读
        if (profile.getExpressScore() < EXPRESS_THRESHOLD) {
            tasks.addAll(generateExpressionTasks(profile));
        }
        
        // 4. 每日任务补充：课文朗读（不论薄弱与否）
        if (tasks.size() < 3) {
            TextbookContent dailyContent = textbookService
                .getDailyReadingContent(profile.getGradeCode());
            tasks.add(TrainingTask.from(dailyContent, "TEXTBOOK_READING"));
        }
        
        // 5. 排序：优先纠正性任务，再日常任务
        tasks.sort(Comparator
            .comparing(TrainingTask::getPriority).reversed()
            .thenComparing(TrainingTask::getDifficulty));
        
        return tasks.stream().limit(5).collect(Collectors.toList());
    }
    
    /**
     * 易混淆声母组合训练
     */
    private static final Map<String, List<String>> CONFUSION_PAIRS = Map.of(
        "s_sh", List.of("四是四，十是十", "四是四，十是十，十四是十四，四十是四十"),
        "c_ch", List.of("吃饭出气", "粗出初级"),
        "z_zh", List.of("找到组长", "站着做饭"),
        "n_l", List.of("牛年连年", "刘奶奶找牛奶奶"),
        "f_h", List.of("分红藤", "黑化肥发灰")
    );
    
    private List<TrainingTask> generatePronunciationTasks(AbilityProfile profile) {
        List<TrainingTask> tasks = new ArrayList<>();
        
        // 检测高频错误音素对
        Map<String, Integer> confusionCounts = profile.getErrorPhonemeStats();
        
        confusionCounts.entrySet().stream()
            .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
            .limit(2)
            .forEach(entry -> {
                String pair = entry.getKey();
                List<String> tongueTwisters = CONFUSION_PAIRS.get(pair);
                if (tongueTwisters != null) {
                    tasks.add(TrainingTask.builder()
                        .type(TrainingType.TONGUE_TWISTER)
                        .title("绕口令：" + tongueTwisters.get(0))
                        .focus(pair.replace("_", "/") + "声母区分")
                        .difficulty(Difficulty.EASY)
                        .estimatedMinutes(3)
                        .content(tongueTwisters)
                        .build());
                }
            });
        
        return tasks;
    }
}
```
