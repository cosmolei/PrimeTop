# 种子数据管理与自动化测试数据生成引擎 详细设计

## 1. 概述

### 1.1 模块定位

种子数据管理与自动化测试数据生成引擎是 PrimeTop 项目研发基础设施的核心组成部分。它负责为开发环境、测试环境、预发布环境和本地调试提供可复现、可控制、可扩展的数据支撑，确保开发人员从项目第一天起就能获得"开箱即用"的完整数据环境。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 基础种子数据管理 | 学科、教材版本、章节、知识点等系统级字典数据的版本化管理与初始化 |
| 测试数据工厂 | 提供各类实体的 Factory/Builder 模式，支持链式构造复杂测试对象 |
| 合成数据生成 | 按规则批量生成模拟学生、家长、教师、题目、答题记录等业务数据 |
| 场景化数据集 | 预定义"初一学生期中复习""高三冲刺""小学生拍题答疑"等典型场景数据包 |
| 数据版本控制 | 种子数据与代码版本对齐，支持数据回滚与差异对比 |
| 环境隔离 | 开发/测试/预发布/CI 环境的数据互不污染 |
| 数据脱敏 | 确保测试环境中无真实用户数据，满足未成年人隐私合规要求 |

## 3. 种子数据管理

### 3.1 种子数据分层

```
┌─────────────────────────────────────────────────┐
│ Layer 1: 系统级种子数据（必须，不可省略）            │
│ - 学科列表、教材版本、学段年级枚举                   │
│ - 系统角色与权限定义                                │
│ - AI Prompt 模板基线                               │
│ - 系统配置参数默认值                                │
├─────────────────────────────────────────────────┤
│ Layer 2: 业务级种子数据（推荐，保证功能可用）         │
│ - 主流教材章节目录（人教版语数英至少一册）             │
│ - 核心知识点（至少覆盖已导入教材）                    │
│ - 示例题目（每学科至少100题，含完整解析）             │
│ - 管理员与测试运营账号                              │
│ - 会员套餐与定价配置                                │
├─────────────────────────────────────────────────┤
│ Layer 3: 开发辅助种子数据（可选，方便调试）           │
│ - 模拟学生/家长/教师账号（各10个）                   │
│ - 模拟学习记录、答题记录、错题数据                    │
│ - 模拟AI对话历史                                    │
│ - 模拟订单与支付记录                                │
├─────────────────────────────────────────────────┤
│ Layer 4: 压测/演示数据（按需生成）                   │
│ - 大规模合成数据（万级学生、百万级答题记录）            │
│ - 高并发模拟数据                                    │
│ - 演示环境精美数据                                  │
└─────────────────────────────────────────────────┘
```

### 3.3 种子数据加载策略

```java
/**
 * 种子数据加载器 — 按 Profile 分层加载
 */
@Component
@Profile({"dev", "test", "staging"})
public class SeedDataLoader implements CommandLineRunner {

    @Qualifier("flywayConfiguration")
    private final Flyway flyway;
    private final SeedDataProperties properties;

    @Override
    public void run(String... args) {
        SeedLayer targetLayer = properties.getLoadLayer();

        // Layer 1: 系统级（始终加载）
        flyway.migrate(); // Flyway 自动执行 V1.0.0__ 系列脚本

        if (targetLayer.ordinal() >= SeedLayer.BUSINESS.ordinal()) {
            // Layer 2: 业务级
            flyway.migrate(); // 继续执行 V1.0.1__ 系列
        }

        if (targetLayer.ordinal() >= SeedLayer.DEV_ASSIST.ordinal()) {
            // Layer 3: 开发辅助
            loadDevAssistSeedData();
        }

        if (targetLayer.ordinal() >= SeedLayer.STRESS_TEST.ordinal()) {
            // Layer 4: 压测/演示数据
            generateStressTestData();
        }

        log.info("✅ 种子数据加载完成 [layer={}]", targetLayer);
    }

    private void loadDevAssistSeedData() {
        // 加载模拟学生、家长、教师
        String sql = ResourceUtils.readResource("db/seed/dev/V1.0.3__demo_accounts.sql");
        jdbcTemplate.execute(sql);

        // 初始化 Redis 缓存
        redisTemplate.opsForValue().set("seed:version", properties.getVersion());

        // 初始化 Elasticsearch 索引
        elasticIndexer.bulkIndex("questions", questionSeedData);
    }
}

public enum SeedLayer {
    SYSTEM,         // 仅系统级
    BUSINESS,       // 系统 + 业务
    DEV_ASSIST,     // + 开发辅助
    STRESS_TEST     // + 压测数据
}
```

```java
/**
 * 学生实体测试数据工厂
 */
public class StudentFactory extends AbstractEntityFactory<Student> {

    private Long id;
    private String phone = "138" + randomDigits(8);
    private String nickname = "测试学生_" + randomString(4);
    private StudentPhase phase = StudentPhase.MIDDLE;
    private Integer gradeLevel = 7;
    private String textbookVersionCode = "PEP";
    private String avatarUrl = "https://cdn.primetop.com/test/avatar/default_" + randomInt(1, 20) + ".png";
    private MembershipLevel membership = MembershipLevel.FREE;
    private Boolean parentBound = false;
    private LocalDateTime createdAt = LocalDateTime.now().minusDays(randomInt(1, 90));

    public static StudentFactory aStudent() {
        return new StudentFactory();
    }

    public static StudentFactory aPrimaryStudent() {
        return new StudentFactory()
            .withPhase(StudentPhase.PRIMARY)
            .withGradeLevel(randomInt(1, 6));
    }

    public static StudentFactory aMiddleStudent() {
        return new StudentFactory()
            .withPhase(StudentPhase.MIDDLE)
            .withGradeLevel(randomInt(7, 9));
    }

    public static StudentFactory aHighStudent() {
        return new StudentFactory()
            .withPhase(StudentPhase.HIGH)
            .withGradeLevel(randomInt(10, 12));
    }

    public static StudentFactory aVipStudent() {
        return new StudentFactory()
            .withMembership(MembershipLevel.ANNUAL);
    }

    public StudentFactory withPhase(StudentPhase phase) {
        this.phase = phase;
        return this;
    }

    public StudentFactory withGradeLevel(int grade) {
        this.gradeLevel = grade;
        // 自动调整phase
        if (grade <= 0) this.phase = StudentPhase.KINDERGARTEN;
        else if (grade <= 6) this.phase = StudentPhase.PRIMARY;
        else if (grade <= 9) this.phase = StudentPhase.MIDDLE;
        else this.phase = StudentPhase.HIGH;
        return this;
    }

    public StudentFactory withTextbook(String versionCode) {
        this.textbookVersionCode = versionCode;
        return this;
    }

    public StudentFactory withMembership(MembershipLevel level) {
        this.membership = level;
        return this;
    }

    public StudentFactory withParentBound() {
        this.parentBound = true;
        return this;
    }

    @Override
    public Student build() {
        Student student = new Student();
        student.setPhone(phone);
        student.setNickname(nickname);
        student.setPhase(phase);
        student.setGradeLevel(gradeLevel);
        student.setTextbookVersionCode(textbookVersionCode);
        student.setAvatarUrl(avatarUrl);
        student.setMembershipLevel(membership);
        student.setParentBound(parentBound);
        student.setCreatedAt(createdAt);
        return student;
    }

    /**
     * 批量创建
     */
    public List<Student> buildList(int count) {
        return IntStream.range(0, count)
            .mapToObj(i -> {
                // 确保每个学生有独立的手机号
                this.phone = "138" + String.format("%08d", randomInt(0, 99999999));
                this.nickname = "测试学生_" + randomString(4) + "_" + i;
                return build();
            })
            .collect(Collectors.toList());
    }
}
```

### 5.3 场景注册与执行引擎

```java
/**
 * 场景执行引擎
 */
@Component
public class ScenarioEngine {

    private final List<ScenarioPack> scenarios;
    private final ApplicationContext applicationContext;

    public ScenarioEngine(List<ScenarioPack> scenarios,
                          ApplicationContext applicationContext) {
        this.scenarios = scenarios.stream()
            .sorted(Comparator.comparingInt(s -> {
                Order order = s.getClass().getAnnotation(Order.class);
                return order != null ? order.value() : 100;
            }))
            .collect(Collectors.toList());
        this.applicationContext = applicationContext;
    }

    /**
     * 加载指定场景（含依赖）
     */
    @Transactional
    public void loadScenario(String code) {
        ScenarioPack pack = findScenario(code);
        if (pack == null) {
            throw new IllegalArgumentException("场景不存在: " + code);
        }

        // 递归加载依赖
        for (String dep : pack.getDependencies()) {
            ScenarioPack depPack = findScenario(dep);
            if (depPack != null) {
                depPack.load(createContext(depPack));
            }
        }

        // 加载目标场景
        ScenarioContext ctx = createContext(pack);
        pack.load(ctx);

        log.info("🎯 场景 [{}] 执行完成", code);
    }

    /**
     * 加载所有场景
     */
    @Transactional
    public void loadAll() {
        for (ScenarioPack pack : scenarios) {
            ScenarioContext ctx = createContext(pack);
            try {
                pack.load(ctx);
            } catch (Exception e) {
                log.error("❌ 场景 [{}] 加载失败", pack.getCode(), e);
            }
        }
    }

    /**
     * 清理指定场景数据
     */
    @Transactional
    public void cleanupScenario(String code) {
        ScenarioPack pack = findScenario(code);
        if (pack != null) {
            pack.cleanup(createContext(pack));
            log.info("🧹 场景 [{}] 已清理", code);
        }
    }

    /**
     * 列出所有可用场景
     */
    public List<ScenarioInfo> listScenarios() {
        return scenarios.stream()
            .map(s -> new ScenarioInfo(s.getCode(), s.getDescription(), s.getDependencies()))
            .collect(Collectors.toList());
    }

    private ScenarioPack findScenario(String code) {
        return scenarios.stream()
            .filter(s -> s.getCode().equals(code))
            .findFirst()
            .orElse(null);
    }

    private ScenarioContext createContext(ScenarioPack pack) {
        return new ScenarioContext(
            applicationContext.getBean(JdbcTemplate.class),
            applicationContext.getBean(EntityManager.class),
            pack.getCode()
        );
    }
}
```

```java
    public static void generateLargeScaleData(int studentCount, int recordsPerStudent) {

            try (PreparedStatement ps = conn.prepareStatement(insertStudent, Statement.RETURN_GENERATED_KEYS)) {
                for (int i = 0; i < studentCount; i++) {
                    ps.setString(1, "139" + String.format("%08d", i));

                    if (i % 5000 == 0) {

                        log.info("  已生成 {} / {} 学生", i + 5000, studentCount);
                    }
                }
                ps.executeBatch();
                conn.commit();

            String insertRecord = "INSERT INTO answer_record (student_id, question_id, is_correct, duration_ms, ...) VALUES (?, ?, ?, ?, ...)";
            try (PreparedStatement ps = conn.prepareStatement(insertRecord)) {
                int totalRecords = studentCount * recordsPerStudent;
                int batchCount = 0;

                for (int s = 1; s <= studentCount; s++) {
                    for (int r = 0; r < recordsPerStudent; r++) {
                        ps.setLong(1, s);
                        ps.setLong(2, 1 + (r % 1000));  // 循环使用1000道题
                        ps.setBoolean(3, Math.random() > 0.35);
                        ps.setInt(4, 30000 + randomInt(0, 120000));

    private static Map<Student, AcademicTier> assignTiers(
            List<Student> students, double excellentRatio, double averageRatio, double needsHelpRatio) {
        Map<Student, AcademicTier> result = new LinkedHashMap<>();
        List<Student> shuffled = new ArrayList<>(students);
        Collections.shuffle(shuffled);

        int excellentCount = (int) (shuffled.size() * excellentRatio);
        int averageCount = (int) (shuffled.size() * averageRatio);

        for (int i = 0; i < shuffled.size(); i++) {
            if (i < excellentCount) {
                result.put(shuffled.get(i), AcademicTier.EXCELLENT);
            } else if (i < excellentCount + averageCount) {
                result.put(shuffled.get(i), AcademicTier.AVERAGE);
            } else {
                result.put(shuffled.get(i), AcademicTier.NEEDS_HELP);
            }
        }
        return result;
    }
```

```java
/**

@Service
@Profile("dev")
public class DevDataSnapshotService {

    private final JdbcTemplate jdbc;
    private final File snapshotDir = new File("./dev-snapshots");

    /**
     * 创建数据快照
     */
    public String createSnapshot(String label) throws IOException {
        String timestamp = DateTimeFormatter.ofPattern("yyyyMMdd-HHmmss")
            .format(LocalDateTime.now());
        String fileName = "snapshot-" + timestamp + "-" + label + ".sql";
        File outputFile = new File(snapshotDir, fileName);

        // 使用 mysqldump 导出
        ProcessBuilder pb = new ProcessBuilder(
            "mysqldump",
            "-u", "root", "-pprimetop_dev",
            "--single-transaction",
            "--routines",
            "primetop_dev"
        );
        pb.redirectOutput(outputFile);
        Process process = pb.start();
        int exitCode = process.waitFor();

        if (exitCode != 0) {
            throw new RuntimeException("快照导出失败: " + exitCode);
        }

        log.info("📸 数据快照已创建: {}", outputFile.getAbsolutePath());
        return outputFile.getAbsolutePath();
    }

    /**
     * 恢复数据快照
     */
    public void restoreSnapshot(String snapshotFile) throws IOException, InterruptedException {
        File file = new File(snapshotDir, snapshotFile);
        if (!file.exists()) {
            throw new FileNotFoundException("快照不存在: " + snapshotFile);
        }

        log.warn("⚠️  正在恢复快照: {}", snapshotFile);

        ProcessBuilder pb = new ProcessBuilder(
            "mysql", "-u", "root", "-pprimetop_dev", "primetop_dev"
        );
        pb.redirectInput(file);
        Process process = pb.start();
        int exitCode = process.waitFor();

        if (exitCode != 0) {
            throw new RuntimeException("快照恢复失败: " + exitCode);
        }

        log.info("✅ 快照已恢复: {}", snapshotFile);
    }

    /**
     * 列出所有快照
     */
    public List<String> listSnapshots() {
        File[] files = snapshotDir.listFiles((dir, name) -> name.endsWith(".sql"));
        if (files == null) return List.of();

        return Arrays.stream(files)
            .sorted(Comparator.reverseOrder())
            .map(File::getName)
            .collect(Collectors.toList());
    }
}
```

```java
/**
 * 种子数据加载互斥锁
 */
@Component
public class SeedDataLockManager {

    private static final String LOCK_KEY = "seed:data:lock";
    private static final int LOCK_TIMEOUT_SECONDS = 600; // 10分钟

    private final StringRedisTemplate redis;

    /**
     * 尝试获取加载锁（防止多人同时初始化）
     */
    public boolean tryAcquireLock(String operator) {
        Boolean acquired = redis.opsForValue()
            .setIfAbsent(LOCK_KEY, operator, Duration.ofSeconds(LOCK_TIMEOUT_SECONDS));
        return Boolean.TRUE.equals(acquired);
    }

    /**
     * 释放锁
     */
    public void releaseLock() {
        redis.delete(LOCK_KEY);
    }

    /**
     * 查看当前持锁人
     */
    public String getCurrentHolder() {
        return redis.opsForValue().get(LOCK_KEY);
    }
}
```

## 16. 错误处理

### 16.1 常见问题与解决方案

| 问题 | 原因 | 解决方案 |
| --- | --- | --- |
| 种子数据加载失败 | 外键约束冲突 | 检查加载顺序，确保父表先于子表加载 |
| Flyway 校验失败 | 已执行的脚本被修改 | 使用 `flyway repair` 或新建修正脚本 |
| 重复加载报错 | 主键冲突 | 使用 `INSERT IGNORE` 或 `ON DUPLICATE KEY UPDATE` |
| 批量生成OOM | 数据量过大 | 分批提交，控制每批 ≤ 5000 条 |
| 测试数据污染 | 场景数据未清理 | 使用 `@Transactional` 回滚或 `@AfterEach` 清理 |
| Mock Server 端口冲突 | 3001 被占用 | 修改启动端口或使用环境变量 |

### 16.2 种子数据加载失败重试

```java
@Component
public class SeedDataRetryTemplate {

    private static final int MAX_RETRIES = 3;
    private static final Duration RETRY_DELAY = Duration.ofSeconds(5);

    /**
     * 带重试的种子数据加载
     */
    public <T> T executeWithRetry(String operationName, Supplier<T> operation) {
        Exception lastException = null;

        for (int attempt = 1; attempt <= MAX_RETRIES; attempt++) {
            try {
                T result = operation.get();
                if (attempt > 1) {
                    log.info("✅ {} 第{}次尝试成功", operationName, attempt);
                }
                return result;
            } catch (DataIntegrityViolationException e) {
                lastException = e;
                log.warn("⚠️  {} 第{}次失败: {}", operationName, attempt, e.getMessage());

                if (attempt < MAX_RETRIES) {
                    try {
                        Thread.sleep(RETRY_DELAY.toMillis());
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        throw new RuntimeException("重试被中断", ie);
                    }
                }
            }
        }

        throw new SeedDataLoadException(
            String.format("%s 在 %d 次尝试后仍然失败", operationName, MAX_RETRIES),
            lastException
        );
    }
}
```
