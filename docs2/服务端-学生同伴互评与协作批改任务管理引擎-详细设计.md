# 服务端-学生同伴互评与协作批改任务管理引擎-详细设计

## 1. 概述

### 1.1 功能定位

同伴互评（Peer Assessment）是教育学中经过充分验证的协作学习策略，指学生在教师指导下对同伴的学习成果进行评价并提供建设性反馈。本引擎为 PrimeTop 平台提供完整的同伴互评任务管理能力，覆盖互评任务创建、作业匿名分发、评分校准、反馈质量评估、争议仲裁和数据沉淀全链路。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 支持多题型互评 | 支持作文、简答题、编程题、项目报告等多类作业的同伴互评 |
| 匿名安全 | 互评过程中双向匿名，避免社交偏见影响评分公正性 |
| 评分校准 | 通过锚点作业和教师基准评分自动校准学生评分偏差 |
| 质量保障 | AI 辅助评估互评反馈质量，自动识别敷衍/抄袭/恶意评价 |
| 教师减负 | 教师只需设定评分量规和抽检比例，系统自动完成分发和初筛 |
| 数据沉淀 | 互评行为数据回流至学生画像，反映批判性思维和学科理解深度 |

### 1.3 适用范围

- **学段**：小学高年级（4-6年级）、初中、高中
- **学科**：全学科（作文、解答题为主，客观题为辅）
- **触发方**：教师端发布互评任务，学生学习端执行互评
- **部署形态**：服务端微服务，隶属学习服务域

### 1.4 核心约束

1. **未成年人保护**：互评内容经安全过滤后展示，禁止自由文字包含敏感信息
2. **隐私合规**：互评双向匿名，真实身份仅教师可见
3. **防欺凌机制**：异常低分、恶意评语自动拦截并上报教师
4. **公平性保障**：每份作业至少被 3 名同伴评价，取校准后中位数

```text

               │                      │
        ┌──────▼──────┐      ┌───────▼───────┐
        │  作业服务    │      │  学习会话服务  │
        └──────┬──────┘      └───────┬───────┘
               │                      │
        ┌──────▼──────────────────────▼───────┐
        │      同伴互评与协作批改引擎           │
        │  ┌─────────┐  ┌─────────────────┐  │
        │  │任务调度器│  │匿名分发与回收器  │  │
        │  └────┬────┘  └────────┬────────┘  │
        │  ┌────▼─────────────────▼────────┐  │
        │  │   评分校准与聚合器              │  │
        │  └────────────┬──────────────────┘  │
        │  ┌────────────▼──────────────────┐  │
        │  │  反馈质量AI评估器              │  │
        │  └────────────┬──────────────────┘  │
        │  ┌────────────▼──────────────────┐  │
        │  │  争议仲裁与教师抽检管理器       │  │
        │  └───────────────────────────────┘  │
        └──────────────────────────────────────┘
               │                      │
        ┌──────▼──────┐      ┌───────▼───────┐
        │  学情画像    │      │  AI 安全审核   │
        └─────────────┘      └───────────────┘
```

### 2.2 核心子模块职责

| 子模块 | 职责 |
| --- | --- |
| 互评任务调度器 | 管理互评任务生命周期（创建→开放→截止→评分→关闭） |
| 匿名分发与回收器 | 作业-评价者双向匿名匹配，分发作业、回收评价结果 |
| 评分校准与聚合器 | 利用锚点作业校准评分偏差，聚合多评价者分数 |
| 反馈质量AI评估器 | 对互评评语进行质量分级，检测敷衍/抄袭/恶意内容 |
| 争议仲裁管理器 | 处理学生对互评结果的申诉，管理教师复核流程 |

## 3. 数据结构定义

### 3.1 核心表设计

#### 3.1.1 peer_review_tasks — 互评任务表

```sql
CREATE TABLE peer_review_tasks (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_code       VARCHAR(64) NOT NULL UNIQUE COMMENT '任务编号 PRT{timestamp}{random}',
    class_id        BIGINT NOT NULL COMMENT '班级ID',
    teacher_id      BIGINT NOT NULL COMMENT '发布教师ID',
    subject_id      BIGINT NOT NULL COMMENT '学科ID',
    assignment_id   BIGINT NOT NULL COMMENT '关联作业ID',
    title           VARCHAR(200) NOT NULL COMMENT '互评任务标题',
    description     TEXT COMMENT '互评要求说明',
    
    -- 互评配置
    review_count    INT NOT NULL DEFAULT 3 COMMENT '每份作业被评价次数',
    reviewer_count  INT NOT NULL DEFAULT 3 COMMENT '每位学生需评价几份作业',
    anonymity_mode  TINYINT NOT NULL DEFAULT 1 COMMENT '匿名模式: 0=实名, 1=双向匿名, 2=仅评价者匿名',
    
    -- 时间安排
    review_start_at DATETIME NOT NULL COMMENT '互评开始时间',
    review_end_at   DATETIME NOT NULL COMMENT '互评截止时间',
    
    -- 评分量规
    rubric_id       BIGINT COMMENT '关联评分量规ID',
    
    -- 校准配置
    calibration_mode TINYINT NOT NULL DEFAULT 1 COMMENT '校准模式: 0=不校准, 1=锚点校准, 2=教师基准校准',
    anchor_count    INT DEFAULT 3 COMMENT '锚点作业数量（教师预评）',
    
    -- 质量控制
    min_feedback_length INT NOT NULL DEFAULT 30 COMMENT '最短评语字数',
    ai_quality_check TINYINT NOT NULL DEFAULT 1 COMMENT '是否开启AI质量检测',
    teacher_sample_ratio DECIMAL(5,2) NOT NULL DEFAULT 0.20 COMMENT '教师抽检比例',
    
    -- 状态
    status          VARCHAR(20) NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT/PUBLISHED/IN_PROGRESS/SCORING/COMPLETED/CANCELLED',
    
    -- 元数据
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_class_status (class_id, status),
    INDEX idx_teacher (teacher_id),
    INDEX idx_assignment (assignment_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='同伴互评任务表';
```

#### 3.1.3 peer_review_assignments — 互评分配记录表

```sql
CREATE TABLE peer_review_assignments (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id             BIGINT NOT NULL COMMENT '互评任务ID',
    
    -- 作业与评价者（双向匿名）
    submission_id       BIGINT NOT NULL COMMENT '被评价的作业提交ID',
    submitter_id        BIGINT NOT NULL COMMENT '作业提交者真实ID',
    submitter_alias     VARCHAR(50) NOT NULL COMMENT '提交者匿名标识（如：同学A）',
    
    reviewer_id         BIGINT NOT NULL COMMENT '评价者真实ID',
    reviewer_alias      VARCHAR(50) NOT NULL COMMENT '评价者匿名标识',
    
    -- 防止自评
    -- 应用层保证 submitter_id != reviewer_id
    
    -- 分配状态
    status              VARCHAR(20) NOT NULL DEFAULT 'ASSIGNED' 
                        COMMENT 'ASSIGNED/IN_PROGRESS/SUBMITTED/LATE/EXPIRED',
    
    assigned_at         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '分配时间',
    started_at          DATETIME COMMENT '开始评价时间',
    submitted_at        DATETIME COMMENT '提交评价时间',
    
    -- 防泄露约束：不存储真实姓名映射在此表中，通过独立安全映射表查找
    
    UNIQUE KEY uk_task_submission_reviewer (task_id, submission_id, reviewer_id),
    INDEX idx_task_reviewer (task_id, reviewer_id),
    INDEX idx_task_submission (task_id, submission_id),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='互评分配记录表';
```

## 4. 核心流程与状态机

### 4.1 互评任务主状态机

```text
DRAFT ──(教师发布)──> PUBLISHED ──(到达开始时间)──> IN_PROGRESS
                                                           │
                                                    (互评截止)
                                                           │
                                                           ▼
                                                       SCORING
                                                           │
                                                    (评分完成)
                                                           │
                                                           ▼
                                                      COMPLETED

  任意状态 ──(教师取消)──> CANCELLED
```

| 状态 | 说明 | 允许的操作 |
| --- | --- | --- |
| DRAFT | 教师编辑中 | 修改配置、添加锚点、预览 |
| PUBLISHED | 已发布，等待互评开始 | 学生可查看预告，不可评价 |
| IN_PROGRESS | 互评进行中 | 学生执行互评，实时提交 |
| SCORING | 互评已截止，进入评分聚合 | 系统自动校准、AI质检、教师抽检 |
| COMPLETED | 评分完成，结果可查看 | 学生查看最终分数和反馈 |
| CANCELLED | 教师取消 | 数据保留但不计入成绩 |

### 4.2 单次互评分配状态机

```text
ASSIGNED ──(学生打开作业)──> IN_PROGRESS ──(提交评价)──> SUBMITTED
     │                                                        │
     │(超时未开始)                                    (AI质检完成)
     │                                                        │
     ▼                                                        ▼
  EXPIRED                                              AI_CHECKED
                                                                  │
                                                          (教师抽检/自动)
                                                                  │
                                                                  ▼
                                                        TEACHER_APPROVED
                                                        TEACHER_REJECTED
                                                        DISPUTED
```

## 6. 核心算法设计

### 6.1 匿名分配算法

**目标**：将 N 份作业分配给 M 个学生评价，每份作业被 `review_count` 人评价，每人评价 `reviewer_count` 份，禁止自评，尽量均匀。

```python
import random
from collections import defaultdict
from typing import List, Tuple


def distribute_peer_review(
    submissions: List[dict],       # [{"submission_id": 200001, "submitter_id": 101}, ...]
    review_count: int,             # 每份作业被评价次数
    reviewer_count: int,           # 每人评价几份
    seed: int = None
) -> List[Tuple[int, int, str, str]]:
    """
    分配互评任务，返回 (submission_id, reviewer_id, submitter_alias, reviewer_alias) 列表。
    
    算法：基于环状移位的改良二分匹配。
    1. 验证可行性：N * review_count <= N * reviewer_count 且 N >= review_count + 1
    2. 对提交者列表做环状偏移分配
    3. 使用随机洗牌打破可预测性
    4. 冲突检测与局部交换
    """
    n = len(submissions)
    
    # 可行性检查
    if n < review_count + 1:
        raise ValueError(f"参与人数({n})不足以满足每份被评价{review_count}次且禁止自评")
    if review_count != reviewer_count:
        # 非对称模式：允许 review_count != reviewer_count，但需满足总量守恒
        total_review_slots = n * review_count
        total_reviewer_capacity = n * reviewer_count
        if total_review_slots != total_reviewer_capacity:
            raise ValueError("总评价需求与总评价能力不匹配")
    
    rng = random.Random(seed)
    
    # 生成匿名标识池
    alias_pool = _generate_anon_aliases(n, rng)
    
    # 用户ID到匿名标识映射
    user_to_alias = {}
    alias_to_user = {}
    for i, sub in enumerate(submissions):
        uid = sub["submitter_id"]
        alias = alias_pool[i]
        user_to_alias[uid] = alias
        alias_to_user[alias] = uid
    
    # 构建分配：环状偏移 + 随机扰动
    # 提交者索引列表
    indices = list(range(n))
    rng.shuffle(indices)
    
    assignments = []
    reviewer_load = defaultdict(int)  # 每人已分配的评价数
    submission_reviewed = defaultdict(int)  # 每份作业已被分配的评价数
    
    # 多轮分配，每轮每人分配一份
    for round_idx in range(review_count):
        offset = round_idx + 1  # 偏移量，避免自评
        
        for i in range(n):
            submitter_idx = indices[i]
            # 环状偏移选择评价者
            reviewer_idx = indices[(i + offset) % n]
            
            submitter = submissions[submitter_idx]
            reviewer = submissions[reviewer_idx]
            
            # 确保不自评
            assert submitter["submitter_id"] != reviewer["submitter_id"], "自评检测失败"
            
            assignments.append((
                submitter["submission_id"],
                reviewer["submitter_id"],
                user_to_alias[submitter["submitter_id"]],
                user_to_alias[reviewer["submitter_id"]]
            ))
            
            reviewer_load[reviewer["submitter_id"]] += 1
            submission_reviewed[submitter["submission_id"]] += 1
    
    # 验证分配均匀性
    loads = list(reviewer_load.values())
    max_load = max(loads)
    min_load = min(loads)
    assert max_load - min_load <= 1, f"分配不均匀：max={max_load}, min={min_load}"
    
    return assignments


def _generate_anon_aliases(n: int, rng: random.Random) -> List[str]:
    """生成 n 个不重复的匿名标识，如 '同学A', '同学B', ..., '同学F2' 等"""
    prefixes = ["同学"]
    letters = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    
    aliases = []
    used = set()
    
    for i in range(n):
        # 第一轮：A-Z
        if i < 26:
            alias = f"{prefixes[0]}{letters[i]}"
        else:
            # 后续：A2, B2, C2...
            cycle = i // 26
            letter = letters[i % 26]
            alias = f"{prefixes[0]}{letter}{cycle + 1}"
        aliases.append(alias)
    
    rng.shuffle(aliases)
    return aliases
```

### 6.2 锚点评分校准算法

**目标**：利用教师预评的锚点作业，计算每位学生评价者的评分偏差，并据此校准其后续评分。

```python
import numpy as np
from typing import List, Dict


class AnchorCalibrator:
    """
    锚点校准器。
    
    原理：
    1. 每位评价者在完成锚点作业评价后，系统对比其评分与教师基准评分。
    2. 计算评价者的系统性偏差（偏高/偏低）及一致性。
    3. 对该评价者的后续评分施加线性校准：adjusted = (raw - bias) / scale_factor
    
    校准模型：adjusted_score = raw_score - bias_i + bias_correction
    其中 bias_i = mean(student_scores_on_anchors) - mean(teacher_scores_on_anchors)
    """
    
    def __init__(self, rubric_dimensions: List[str]):
        self.dimensions = rubric_dimensions
        # 评价者校准参数：{reviewer_id: {dim: {"bias": float, "scale": float, "r": float}}}
        self.calibration_params = {}
    
    def calibrate_reviewer(
        self,
        reviewer_id: int,
        anchor_reviews: List[dict],
        teacher_anchor_scores: List[dict]
    ) -> dict:
        """
        校准单个评价者。
        
        Args:
            reviewer_id: 评价者ID
            anchor_reviews: 该评价者对锚点作业的评分列表
                [{"submission_id": 200001, "scores": {"content": 26, "structure": 20}},
                 {"submission_id": 200002, "scores": {"content": 18, "structure": 15}}]
            teacher_anchor_scores: 教师对同一批锚点的评分列表
                [{"submission_id": 200001, "scores": {"content": 28, "structure": 23}},
                 {"submission_id": 200002, "scores": {"content": 20, "structure": 17}}]
        
        Returns:
            校准参数和诊断信息
        """
        params = {}
        diagnosis = {
            "reviewer_id": reviewer_id,
            "overall_tendency": "WELL_CALIBRATED",
            "dimension_details": {},
            "calibrated": False
        }
        
        for dim in self.dimensions:
            student_scores = np.array([r["scores"].get(dim, 0) for r in anchor_reviews])
            teacher_scores = np.array([t["scores"].get(dim, 0) for t in teacher_anchor_scores])
            
            if len(student_scores) == 0:
                continue
            
            # 偏差：正值=偏高，负值=偏低
            bias = float(np.mean(student_scores - teacher_scores))
            
            # 线性回归：teacher = a * student + b → student_calibrated = (student - b) / a
            if np.std(student_scores) > 0.01:
                # 有方差时可以拟合缩放因子
                a, b = np.polyfit(student_scores, teacher_scores, 1)
                scale = float(a)
            else:
                # 无方差时仅做平移校准
                scale = 1.0
            
            # 相关系数（一致性）
            if len(student_scores) >= 3 and np.std(teacher_scores) > 0.01:
                r = float(np.corrcoef(student_scores, teacher_scores)[0, 1])
            else:
                r = None  # 样本不足
            
            params[dim] = {
                "bias": bias,
                "scale": scale,
                "correlation": r,
                "student_mean": float(np.mean(student_scores)),
                "teacher_mean": float(np.mean(teacher_scores))
            }
            
            dim_diagnosis = self._diagnose_dimension(bias, r)
            diagnosis["dimension_details"][dim] = dim_diagnosis
        
        self.calibration_params[reviewer_id] = params
        diagnosis["calibrated"] = True
        
        # 总体判断
        avg_bias = np.mean([p["bias"] for p in params.values()])
        if avg_bias > 3.0:
            diagnosis["overall_tendency"] = "OVER_GRADING"
        elif avg_bias < -3.0:
            diagnosis["overall_tendency"] = "UNDER_GRADING"
        else:
            diagnosis["overall_tendency"] = "WELL_CALIBRATED"
        
        return diagnosis
    
    def apply_calibration(
        self,
        reviewer_id: int,
        raw_scores: Dict[str, float]
    ) -> Dict[str, float]:
        """
        对评价者的原始评分施加校准。
        """
        if reviewer_id not in self.calibration_params:
            return raw_scores  # 未校准的评价者，保持原分
        
        params = self.calibration_params[reviewer_id]
        calibrated = {}
        
        for dim, raw_score in raw_scores.items():
            if dim in params:
                p = params[dim]
                # 线性校准：adjusted = (raw - bias)
                adjusted = raw_score - p["bias"]
                # 缩放校准（仅当scale有效且偏离不大时）
                if 0.7 <= p["scale"] <= 1.5:
                    adjusted = adjusted * (1.0 / p["scale"])
                calibrated[dim] = round(max(0, adjusted), 2)
            else:
                calibrated[dim] = raw_score
        
        return calibrated
    
    def _diagnose_dimension(self, bias: float, r: float = None) -> dict:
        """诊断单个维度的评分质量"""
        diagnosis = {
            "bias": bias,
            "tendency": "OK",
            "consistency": "UNKNOWN" if r is None else ("HIGH" if r > 0.7 else ("MODERATE" if r > 0.4 else "LOW")),
            "recommendation": ""
        }
        
        if abs(bias) <= 2.0:
            diagnosis["tendency"] = "ACCURATE"
        elif bias > 2.0:
            diagnosis["tendency"] = "INFLATED"
            diagnosis["recommendation"] = "该维度评分偏高，建议更严格对照量规标准"
        else:
            diagnosis["tendency"] = "DEFLATED"
            diagnosis["recommendation"] = "该维度评分偏低，建议更全面地发现优点"
        
        if r is not None and r < 0.3:
            diagnosis["recommendation"] += "；评分一致性偏低，建议仔细区分不同质量层次"
        
        return diagnosis
```

### 6.3 最终分数聚合算法

```python
from typing import List
import statistics


def aggregate_final_score(
    calibrated_results: List[dict],
    quality_threshold: float = 50.0,
    min_valid_count: int = 2
) -> dict:
    """
    聚合多评价者的校准后评分，输出最终分数。
    
    策略：
    1. 过滤掉AI质量分低于阈值的评价
    2. 若剩余有效评价 >= min_valid_count，取截尾均值（去掉最高最低后取平均）
    3. 若有效评价不足，标记为 NEED_TEACHER_REVIEW
    
    Args:
        calibrated_results: [{"result_id": 800001, "total_score": 88.5, "ai_quality_score": 85.0, 
                               "dimension_scores": {"content": 26, ...}, "reviewer_id": 201}, ...]
        quality_threshold: AI质量分低于此值的评价被排除
        min_valid_count: 最少有效评价数
    
    Returns:
        {"final_score": float, "raw_avg": float, "valid_count": int, "excluded": [...], "method": str}
    """
    # Step 1: 质量过滤
    valid = [r for r in calibrated_results if r["ai_quality_score"] >= quality_threshold]
    excluded = [r for r in calibrated_results if r["ai_quality_score"] < quality_threshold]
    
    if len(valid) < min_valid_count:
        return {
            "final_score": None,
            "raw_avg": statistics.mean([r["total_score"] for r in calibrated_results]) if calibrated_results else 0,
            "valid_count": len(valid),
            "excluded": [{"result_id": r["result_id"], "reason": "LOW_QUALITY", "score": r["ai_quality_score"]} for r in excluded],
            "method": "NEED_TEACHER_REVIEW",
            "message": f"有效评价({len(valid)})不足最小要求({min_valid_count})，需教师手动评分"
        }
    
    # Step 2: 截尾均值（Truncated Mean）
    scores = [r["total_score"] for r in valid]
    
    if len(scores) <= 2:
        # 2个评价：取均值
        final = statistics.mean(scores)
        method = "MEAN"
    elif len(scores) == 3:
        # 3个评价：取中位数
        final = statistics.median(scores)
        method = "MEDIAN"
    else:
        # 4+评价：去掉最高最低后取均值
        sorted_scores = sorted(scores)
        trimmed = sorted_scores[1:-1]
        final = statistics.mean(trimmed)
        method = "TRUNCATED_MEAN"
    
    # Step 3: 维度级别聚合
    dim_scores = {}
    for r in valid:
        for dim, score in r["dimension_scores"].items():
            dim_scores.setdefault(dim, []).append(score)
    
    dim_final = {}
    for dim, vals in dim_scores.items():
        dim_final[dim] = round(statistics.median(vals), 2)
    
    return {
        "final_score": round(final, 2),
        "raw_avg": round(statistics.mean(scores), 2),
        "calibration_adjustment": round(final - statistics.mean(scores), 2),
        "dimension_final": dim_final,
        "valid_count": len(valid),
        "excluded_count": len(excluded),
        "excluded": [{"result_id": r["result_id"], "reason": "LOW_QUALITY", "score": r["ai_quality_score"]} for r in excluded],
        "method": method
    }
```

### 6.4 AI 反馈质量评估

```python
from typing import List
import re


class FeedbackQualityAssessor:
    """
    互评反馈质量AI评估器。
    
    使用规则 + LLM 混合方案：
    - 规则层：快速检测字数、关键词、模式匹配
    - LLM层：对通过规则层的评语进行深层质量评估
    
    质量标记：
    - HASTY: 敷衍评价（字数过少、无实质内容）
    - OFF_TOPIC: 跑题（评语与作业内容无关）
    - PLEASANT_BIAS: 讨好偏差（全部满分+泛泛好评）
    - HARSH: 恶意低分（远低于其他评价者+苛刻评语）
    - PLAGIARIZED: 抄袭（与其他评价者评语高度相似）
    - GOOD: 高质量评价（具体、建设性、有依据）
    """
    
    # 规则层检测器
    HASTY_PATTERNS = [
        r"^好+$",           # "好好好好好"
        r"^不错+$",
        r"^可以+$",
        r"^.{0,10}$",       # 10字以内
        r"^(还行|一般|挺好的|继续努力)$",
    ]
    
    POSITIVE_KEYWORDS = {"优秀", "完美", "出色", "精彩", "极好", "满分"}
    NEGATIVE_KEYWORDS = {"差", "烂", "糟糕", "一无是处", "狗屁", "垃圾"}
    
    def assess(
        self,
        review_data: dict,
        context: dict
    ) -> dict:
        """
        评估单条互评反馈的质量。
        
        Args:
            review_data: {
                "dimension_scores": {"content": 26, ...},
                "total_score": 86,
                "strengths_feedback": "...",
                "improvements_feedback": "...",
                "overall_comment": "..."
            }
            context: {
                "submission_content": "...",      # 被评价的作业内容
                "rubric_max_scores": {"content": 30, ...},
                "other_reviews": [...],            # 同一作业的其他评价（用于一致性检测）
                "min_feedback_length": 50
            }
        
        Returns:
            {
                "quality_score": 0-100,
                "flags": ["HASTY", "OFF_TOPIC", ...],
                "details": {...},
                "action": "ACCEPT" | "FLAG" | "REJECT"
            }
        """
        flags = []
        detail_scores = {}
        
        feedback_text = " ".join(filter(None, [
            review_data.get("strengths_feedback", ""),
            review_data.get("improvements_feedback", ""),
            review_data.get("overall_comment", "")
        ]))
        
        # === 规则层 ===
        
        # 1. 字数检测
        feedback_len = len(feedback_text.strip())
        min_len = context.get("min_feedback_length", 30)
        if feedback_len < min_len:
            flags.append("HASTY")
            detail_scores["length"] = max(0, feedback_len / min_len * 30)
        else:
            detail_scores["length"] = min(100, 30 + (feedback_len - min_len) / min_len * 20)
        
        # 2. 敷衍模式匹配
        if any(re.match(p, feedback_text.strip()) for p in self.HASTY_PATTERNS):
            if "HASTY" not in flags:
                flags.append("HASTY")
            detail_scores["pattern"] = 0
        
        # 3. 讨好偏差检测
        max_scores = context["rubric_max_scores"]
        all_max = all(
            review_data["dimension_scores"].get(dim, 0) >= max_scores[dim] * 0.95
            for dim in max_scores
        )
        if all_max and not any(kw in feedback_text for kw in ["但是", "建议", "不足", "改进", "问题"]):
            flags.append("PLEASANT_BIAS")
            detail_scores["bias"] = 40
        
        # 4. 恶意低分检测
        other_reviews = context.get("other_reviews", [])
        if other_reviews:
            other_avg = sum(r["total_score"] for r in other_reviews) / len(other_reviews)
            current = review_data["total_score"]
            if current < other_avg - 15:  # 远低于平均
                flags.append("HARSH")
                detail_scores["consistency"] = 30
        
        # 5. 抄袭检测
        if other_reviews:
            for other in other_reviews:
                other_text = " ".join(filter(None, [
                    other.get("strengths_feedback", ""),
                    other.get("improvements_feedback", ""),
                    other.get("overall_comment", "")
                ]))
                similarity = self._text_similarity(feedback_text, other_text)
                if similarity > 0.8:
                    flags.append("PLAGIARIZED")
                    detail_scores["originality"] = 20
                    break
        
        # 6. 恶意词汇检测
        if any(kw in feedback_text for kw in self.NEGATIVE_KEYWORDS):
            flags.append("INAPPROPRIATE")
            detail_scores["safety"] = 10
        
        # === LLM 深层评估（对通过规则层的评价） ===
        if not flags:
            llm_result = self._llm_assess(review_data, context)
            detail_scores.update(llm_result["dimension_scores"])
            if llm_result.get("flags"):
                flags.extend(llm_result["flags"])
        
        # === 综合评分 ===
        base_scores = list(detail_scores.values()) if detail_scores else [50]
        quality_score = sum(base_scores) / len(base_scores) if base_scores else 0
        
        # 有严重flag时降分
        severe_flags = {"HARSH", "PLAGIARIZED", "INAPPROPRIATE"}
        if any(f in severe_flags for f in flags):
            quality_score = min(quality_score, 30)
        
        # 决定动作
        if quality_score < 30 or any(f in severe_flags for f in flags):
            action = "REJECT"
        elif quality_score < 60 or "HASTY" in flags or "PLEASANT_BIAS" in flags:
            action = "FLAG"
        else:
            action = "ACCEPT"
        
        return {
            "quality_score": round(quality_score, 2),
            "flags": list(set(flags)),  # 去重
            "details": detail_scores,
            "action": action
        }
    
    def _text_similarity(self, text_a: str, text_b: str) -> float:
        """使用 Jaccard 相似度进行快速文本去重"""
        set_a = set(text_a)
        set_b = set(text_b)
        if not set_a or not set_b:
            return 0.0
        intersection = set_a & set_b
        union = set_a | set_b
        return len(intersection) / len(union)
    
    def _llm_assess(self, review_data: dict, context: dict) -> dict:
        """
        调用 LLM 评估反馈质量。
        
        评估维度：
        - specificity: 反馈是否具体（引用了作业中的内容）
        - constructiveness: 改进建议是否建设性
        - alignment: 评分是否与评语一致（高分但批评=不一致）
        - rubric_alignment: 评分是否合理对照量规
        """
        prompt = self._build_quality_prompt(review_data, context)
        # 实际实现中调用 AI 服务
        # result = ai_service.call(prompt, model="gpt-4o-mini")
        # return self._parse_llm_result(result)
        
        # 占位返回
        return {
            "dimension_scores": {
                "specificity": 75,
                "constructiveness": 80,
                "alignment": 85,
                "rubric_alignment": 78
            },
            "flags": []
        }
    
    def _build_quality_prompt(self, review_data: dict, context: dict) -> str:
        """构建反馈质量评估的 LLM Prompt"""
        return f"""你是一位教育评估专家，请评估以下学生同伴互评的质量。

## 被评价的作业内容（摘要）
{context["submission_content"][:500]}

## 评价者评分
{review_data["dimension_scores"]}
总分: {review_data["total_score"]}

## 评价者反馈
优点: {review_data.get("strengths_feedback", "（未填写）")}
改进建议: {review_data.get("improvements_feedback", "（未填写）")}
总评: {review_data.get("overall_comment", "（未填写）")}

## 评分量规
{context["rubric_max_scores"]}

## 请从以下维度评估（0-100分）:
1. specificity（具体性）: 反馈是否引用了作业中的具体内容？
2. constructiveness（建设性）: 改进建议是否具体可操作？
3. alignment（一致性）: 评分与文字反馈是否逻辑一致？
4. rubric_alignment（量规匹配）: 评分是否合理对应量规标准？

## 输出格式（JSON）:
{{"specificity": 0-100, "constructiveness": 0-100, "alignment": 0-100, "rubric_alignment": 0-100, "issues": []}}

只输出 JSON，不要其他内容。"""
```

```python
async def safe_quality_check(review_result: dict, context: dict) -> dict:
    """
    AI质量检测的降级处理。
    当AI服务不可用时，仅执行规则层检测，将结果标记为待补检。
    """
    try:
        assessor = FeedbackQualityAssessor()
        
        # 始终先执行规则层（本地、快速）
        rule_result = assessor.assess(review_data=review_result, context=context)
        
        # 尝试 LLM 层（远程、可能失败）
        if rule_result["action"] == "ACCEPT":
            try:
                llm_result = await call_llm_quality_service(review_result, context, timeout_ms=3000)
                rule_result["details"].update(llm_result.get("dimension_scores", {}))
                rule_result["flags"].extend(llm_result.get("flags", []))
                # 重新计算综合分
                rule_result["quality_score"] = recalculate_score(rule_result["details"])
                rule_result["action"] = determine_action(rule_result["quality_score"], rule_result["flags"])
            except (TimeoutError, ServiceUnavailableError):
                # AI 服务不可用：降级为仅规则层结果
                logger.warning("AI quality check service unavailable, falling back to rule-based check only")
                review_result["_ai_check_pending"] = True
        
        return rule_result
    except Exception as e:
        logger.error(f"Quality check failed completely: {e}")
        return {
            "quality_score": 50.0,  # 中性默认分
            "flags": [],
            "details": {},
            "action": "ACCEPT",  # 宽松放行，教师抽检兜底
            "_note": "Quality check skipped due to error, relying on teacher sampling"
        }
```

| 匿名标识唯一 | 每个互评任务内，每人有唯一匿名标识（如"同学F"），不同任务间标识不同 |
| 映射表隔离 | `peer_review_anon_mapping` 表通过行级数据权限隔离，仅任务发布教师可查 |

| 结果发布延迟 | 互评结果在全部评价完成后才统一发布，避免通过"先评价者先看到结果"推断身份 |

### 8.2 评分公正性规则

| 规则 | 说明 |
| --- | --- |
| 三份底线 | 每份作业至少被 3 名同伴评价（可配置），低于此数的作业由教师补充评分 |
| 截尾聚合 | 最终分数使用截尾均值（去掉最高最低），降低极端值影响 |
| 校准必行 | 锚点校准模式开启时，未完成锚点评价的学生不能参与正式评价 |
| 偏差监控 | 系统持续监控每位评价者的评分偏差趋势，异常时自动预警教师 |
| 教师抽检 | 按配置比例（默认 20%）随机抽取结果由教师复核 |

### 8.3 反馈安全规则

| 规则 | 说明 |
| --- | --- |
| 安全过滤 | 所有文字反馈经敏感词过滤后展示 |
