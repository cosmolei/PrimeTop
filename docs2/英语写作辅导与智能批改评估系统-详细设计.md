# 英语写作辅导与智能批改评估系统 - 详细设计

## 1. 模块概述

### 1.1 功能定位

为小学至高中阶段学生提供英语写作全流程辅助，覆盖审题立意、素材推荐、大纲生成、逐段写作引导、智能批改评分与提升建议。区别于中文作文辅导，英语写作需额外关注语法正确性、词汇丰富度、句式多样性、拼写准确以及中式英语检测等维度。

### 1.2 覆盖学段与写作类型

| 学段 | 写作类型 | 词数要求 | 评分标准 |
| --- | --- | --- | --- |
| 小学（4-6年级） | 看图写话、简单描述、书信便条 | 30-80 词 | 内容完整度、基本语法、拼写 |
| 初中 | 书信邮件、话题作文、看图写话、记叙文 | 80-120 词 | 内容要点、语法词汇、连贯性、书写 |
| 高中 | 议论文、应用文（书信/通知/演讲稿）、读后续写、概要写作 | 100-150 词（应用文）/ 150-350 词（读后续写） | 内容、语言、结构、衔接连贯 |

### 1.3 核心价值

1. **即时反馈**：学生提交作文后 10 秒内获得初步评分和关键问题标注
2. **分级指导**：不同学段使用不同评分标准和表达方式
3. **避免代写**：只提供修改建议和方向指引，不替学生重写全文
4. **渐进提升**：基于历史作文数据追踪写作能力进步曲线
5. **考试对标**：评分模型对齐中高考英语写作评分标准

## 3. 数据模型设计

### 3.1 核心实体

#### 3.1.1 写作题目（essay_topic）

```sql
CREATE TABLE essay_topic (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    topic_code      VARCHAR(64) NOT NULL UNIQUE COMMENT '题目编码',
    title           VARCHAR(500) NOT NULL COMMENT '题目标题',
    description     TEXT COMMENT '题目详细描述（含图片URL、情景说明等）',
    essay_type      ENUM('narrative', 'argumentative', 'application_letter',
                         'notice', 'speech', 'picture_writing',
                         'continuation_writing', 'summary_writing',
                         'email', 'diary') NOT NULL COMMENT '写作类型',
    grade_range     VARCHAR(32) NOT NULL COMMENT '适用学段 G4-6/G7-9/G10-12',
    word_count_min  INT NOT NULL COMMENT '最低词数',
    word_count_max  INT NOT NULL COMMENT '最高词数',
    key_points      JSON COMMENT '评分要点 [{point, weight}]',
    scoring_rubric  JSON COMMENT '评分标准 {content, language, structure, coherence} 各维度权重与描述',
    source_type     ENUM('textbook', 'exam_real', 'exam_mock', 'ai_generated',
                         'teacher_created', 'user_custom') NOT NULL,
    source_ref      VARCHAR(200) COMMENT '来源引用（教材章节/考试年份等）',
    difficulty      TINYINT COMMENT '难度 1-5',
    tags            JSON COMMENT '标签列表',
    status          TINYINT DEFAULT 1,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_type_grade (essay_type, grade_range),
    INDEX idx_source (source_type, source_ref)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.2 写作会话（essay_session）

```sql
CREATE TABLE essay_session (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_code    VARCHAR(64) NOT NULL UNIQUE COMMENT '会话编码',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    topic_id        BIGINT COMMENT '题目ID（系统题/考试题）',
    custom_topic    TEXT COMMENT '自定义题目文本',
    grade_level     VARCHAR(16) NOT NULL COMMENT '当前年级 G7/G10 等',
    essay_type      VARCHAR(32) COMMENT '写作类型',
    status          ENUM('drafting_outline', 'writing', 'submitted',
                         'scoring', 'reviewed', 'revised', 'archived') NOT NULL DEFAULT 'drafting_outline',
    outline         JSON COMMENT '大纲 [{section, key_points, status}]',
    current_section INT DEFAULT 0 COMMENT '当前写作段落序号',
    content         JSON COMMENT '正文按段存储 [{section_no, content, word_count, updated_at}]',
    total_word_count INT DEFAULT 0,
    time_spent_ms   BIGINT DEFAULT 0 COMMENT '写作耗时（毫秒）',
    ai_usage_count  INT DEFAULT 0 COMMENT 'AI辅助调用次数',
    parent_session  BIGINT COMMENT '修改稿对应的原始会话ID',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user (user_id, status),
    INDEX idx_parent (parent_session),
    INDEX idx_created (user_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.3 批改结果（essay_correction）

```sql
CREATE TABLE essay_correction (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      BIGINT NOT NULL COMMENT '写作会话ID',
    correction_type ENUM('full', 'paragraph', 'sentence', 'quick_check') NOT NULL,
    overall_score   DECIMAL(5,2) COMMENT '总分（百分制）',
    dimension_scores JSON COMMENT '各维度得分 {content, language, structure, coherence, spelling}',
    band_level      VARCHAR(16) COMMENT '等级 A/B/C/D 或优秀/良好/及格/不及格',
    issues          JSON COMMENT '问题列表 [{type, position, original, suggestion, severity}]',
    corrections     JSON COMMENT '逐句批改 [{sentence_no, original, corrected, issues, suggestion}]',
    highlights      JSON COMMENT '亮点 [{position, text, comment}]',
    summary_comment TEXT COMMENT '总体评语',
    improvement_plan JSON COMMENT '提升建议 [{dimension, current_level, target, actions}]',
    model_id        VARCHAR(64) COMMENT '使用的AI模型标识',
    model_version   VARCHAR(32) COMMENT '模型版本',
    scoring_latency_ms INT COMMENT '批改耗时',
    user_feedback   TINYINT COMMENT '用户满意度 1-5',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_session (session_id),
    INDEX idx_user_time (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.4 素材库（essay_material）

```sql
CREATE TABLE essay_material (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    material_type   ENUM('sentence_pattern', 'transition_phrase', 'vocabulary',
                         'opening_template', 'closing_template', 'topic_sentence',
                         'model_essay', 'model_paragraph') NOT NULL,
    content         TEXT NOT NULL COMMENT '素材内容（英文）',
    translation     VARCHAR(500) COMMENT '中文翻译',
    topic_tags      JSON COMMENT '适用话题标签',
    grade_range     VARCHAR(32) COMMENT '适用学段',
    difficulty      TINYINT COMMENT '难度 1-5',
    usage_count     INT DEFAULT 0 COMMENT '被引用次数',
    avg_rating      DECIMAL(3,2) COMMENT '用户平均评分',
    embedding_id    VARCHAR(128) COMMENT '向量索引ID',
    status          TINYINT DEFAULT 1,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_type (material_type, grade_range),
    INDEX idx_topic (topic_tags(64))
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.5 写作能力档案（writing_profile）

```sql
CREATE TABLE writing_profile (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL UNIQUE COMMENT '用户ID',
    total_essays    INT DEFAULT 0 COMMENT '累计作文数',
    avg_score       DECIMAL(5,2) COMMENT '平均得分',
    dimension_avgs  JSON COMMENT '各维度平均得分 {content, language, structure, coherence, spelling}',
    weak_dimensions JSON COMMENT '薄弱维度列表',
    common_errors   JSON COMMENT '高频错误统计 [{error_type, count, recent_examples}]',
    vocabulary_level VARCHAR(16) COMMENT '词汇水平评估 A1-C2',
    grammar_level   VARCHAR(16) COMMENT '语法水平评估',
    progress_curve  JSON COMMENT '进步曲线 [{date, score}]',
    achievements    JSON COMMENT '写作成就 [{type, unlocked_at}]',
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.2 缓存设计

```
# 审题结果缓存（题目不变则可复用）
essay:topic:analysis:{topic_id}             → JSON, TTL=24h

# 用户写作中状态（断点续写）
essay:session:state:{session_id}            → JSON, TTL=2h（活跃续期）

# 批改结果缓存（同一内容不重复批改）
essay:correction:hash:{content_hash}        → JSON, TTL=1h

# 素材推荐缓存（按话题+年级）
essay:material:rec:{topic_hash}:{grade}     → JSON, TTL=6h

# 用户写作能力快照
essay:profile:snapshot:{user_id}            → JSON, TTL=10min
```

### 7.2 AI评分与规则引擎结合

```
综合评分 = f(AI评分, 规则引擎评分, 历史校准)

其中：
- AI评分：大模型给出的各维度分数（权重 60%）
- 规则引擎评分：基于确定性规则的评分（权重 30%）
  - 词数是否达标（未达标扣分）
  - 格式是否正确（书信格式等）
  - 语法错误数量（按密度计算）
  - 拼写错误数量
  - 段落数量是否合理
- 历史校准：基于已有人工评分样本的校准因子（权重 10%）
```

### 7.3 分数校准策略

```java
/**
 * 基于人工标注数据的评分校准
 * 目标：AI评分与人工评分的Pearson相关系数 > 0.85
 */
public class ScoreCalibrator {

    // 校准数据：收集人工批改样本，每周更新校准参数
    private CalibrationModel calibrationModel;

    public CalibratedScore calibrate(RawScore rawScore, String gradeLevel) {
        // 1. 载入该学段的校准参数
        CalibrationParams params = calibrationModel.getParams(gradeLevel);

        // 2. 线性回归校准
        double calibrated = params.getIntercept()
            + params.getCoefficient() * rawScore.getOverallScore();

        // 3. 限制在合法范围
        calibrated = Math.max(0, Math.min(100, calibrated));

        // 4. 四舍五入到0.5分
        calibrated = Math.round(calibrated * 2) / 2.0;

        return new CalibratedScore(calibrated, rawScore.getDimensions());
    }
}
```

### 9.1 批改服务核心逻辑（伪代码）

```java
@Service
public class EssayCorrectionService {

    @Autowired
    private GrammarCheckEngine grammarEngine;
    @Autowired
    private ChinglishDetector chinglishDetector;
    @Autowired
    private AIModelDispatcher aiDispatcher;
    @Autowired
    private ScoreCalibrator calibrator;
    @Autowired
    private WritingProfileService profileService;

    /**
     * 完整批改流程
     */
    @Async("essayCorrectionExecutor")
    public CompletableFuture<CorrectionResult> correctEssay(EssaySession session) {
        String content = session.getFullContent();
        GradeLevel grade = session.getGradeLevel();

        // 1. 内容预处理
        PreprocessedEssay preprocessed = preprocess(content);

        // 2. 并行分析
        CompletableFuture<List<GrammarIssue>> grammarFuture =
            CompletableFuture.supplyAsync(() ->
                grammarEngine.check(preprocessed, grade));

        CompletableFuture<List<ChinglishAlert>> chinglishFuture =
            CompletableFuture.supplyAsync(() ->
                chinglishDetector.detect(preprocessed, grade));

        CompletableFuture<AIReviewResult> aiReviewFuture =
            CompletableFuture.supplyAsync(() ->
                aiDispatcher.dispatchEssayReview(preprocessed, grade,
                    session.getTopicAnalysis(), session.getScoringRubric()));

        // 等待所有结果
        CompletableFuture.allOf(grammarFuture, chinglishFuture, aiReviewFuture).join();

        List<GrammarIssue> grammarIssues = grammarFuture.get();
        List<ChinglishAlert> chinglishAlerts = chinglishFuture.get();
        AIReviewResult aiReview = aiReviewFuture.get();

        // 3. 合并问题列表
        List<CorrectionIssue> allIssues = mergeIssues(
            grammarIssues, chinglishAlerts, aiReview.getIssues());

        // 4. 计算综合评分
        RawScore rawScore = calculateScore(aiReview, grammarIssues, preprocessed);
        CalibratedScore finalScore = calibrator.calibrate(rawScore, grade);

        // 5. 生成结果
        CorrectionResult result = CorrectionResult.builder()
            .overallScore(finalScore.getOverall())
            .dimensionScores(finalScore.getDimensions())
            .bandLevel(determineBand(finalScore.getOverall()))
            .issues(allIssues)
            .highlights(aiReview.getHighlights())
            .summaryComment(aiReview.getSummary())
            .improvementPlan(generateImprovementPlan(finalScore, allIssues, grade))
            .build();

        // 6. 异步更新写作能力档案
        profileService.updateWritingProfile(session.getUserId(), result);

        return CompletableFuture.completedFuture(result);
    }

    /**
     * 内容预处理
     */
    private PreprocessedEssay preprocess(String content) {
        // 分段
        List<String> paragraphs = Arrays.asList(content.split("\n+"));

        // 分句
        List<Sentence> sentences = new ArrayList<>();
        for (int pIdx = 0; pIdx < paragraphs.size(); pIdx++) {
            List<String> split = SentenceSplitter.split(paragraphs.get(pIdx));
            for (int sIdx = 0; sIdx < split.size(); sIdx++) {
                sentences.add(new Sentence(pIdx, sIdx, split.get(sIdx)));
            }
        }

        // 词数统计
        int wordCount = WordCounter.count(content);

        // 去重哈希
        String contentHash = DigestUtils.md5Hex(
            content.replaceAll("\\s+", " ").trim());

        return new PreprocessedEssay(paragraphs, sentences, wordCount, contentHash);
    }
}
```

```java
@Component
public class GrammarCheckEngine {

    /**
     * 基于规则的语法检查（无需AI调用，低延迟）
     */
    public List<GrammarIssue> check(PreprocessedEssay essay, GradeLevel grade) {
        List<GrammarIssue> issues = new ArrayList<>();

        for (Sentence sentence : essay.getSentences()) {
            String text = sentence.getText();

            // 主谓一致检查
            issues.addAll(checkSubjectVerbAgreement(text, sentence));

            // 冠词使用检查
            issues.addAll(checkArticleUsage(text, sentence));

            // 时态一致性检查
            issues.addAll(checkTenseConsistency(text, sentence));

            // 标点符号检查
            issues.addAll(checkPunctuation(text, sentence));

            // 首字母大写检查
            issues.addAll(checkCapitalization(text, sentence));
        }

        return issues;
    }

    /**
     * 主谓一致检查示例
     */
    private List<GrammarIssue> checkSubjectVerbAgreement(String text, Sentence sentence) {
        List<GrammarIssue> issues = new ArrayList<>();

        // 模式：单数主语 + 复数动词
        // e.g., "The school have" → "The school has"
        Pattern pattern = Pattern.compile(
            "\\b(school|program|student|government|country|city|child|person)" +
            "\\s+(have|do|are|were)\\b",
            Pattern.CASE_INSENSITIVE
        );

        Matcher matcher = pattern.matcher(text);
        while (matcher.find()) {
            issues.add(GrammarIssue.builder()
                .type("subject_verb_agreement")
                .severity("high")
                .position(new TextPosition(sentence.getParagraphIndex(),
                    sentence.getSentenceIndex(), matcher.start(), matcher.end()))
                .original(matcher.group())
                .suggestion(fixSubjectVerbAgreement(matcher.group()))
                .explanation("主语是第三人称单数，谓语动词需要相应变化")
                .build());
        }

        return issues;
    }
}
```

```java
@Service
public class WritingProfileService {

    @Async
    public void updateWritingProfile(Long userId, CorrectionResult result) {
        WritingProfile profile = profileRepository.findByUserId(userId)
            .orElseGet(() -> createInitialProfile(userId));

        // 更新基础统计
        profile.setTotalEssays(profile.getTotalEssays() + 1);

        // 滑动平均分数
        double newAvg = (profile.getAvgScore() * (profile.getTotalEssays() - 1)
            + result.getOverallScore()) / profile.getTotalEssays();
        profile.setAvgScore(newAvg);

        // 更新维度均分
        updateDimensionAvgs(profile, result.getDimensionScores());

        // 更新高频错误
        updateCommonErrors(profile, result.getIssues());

        // 更新进步曲线（保留最近30个点）
        updateProgressCurve(profile, result.getOverallScore());

        // 评估词汇和语法水平
        profile.setVocabularyLevel(
            VocabularyLevelEstimator.estimate(profile.getDimensionAvgs(),
                profile.getCommonErrors()));

        // 识别薄弱维度
        profile.setWeakDimensions(
            identifyWeakDimensions(profile.getDimensionAvgs()));

        profileRepository.save(profile);
    }

    private List<String> identifyWeakDimensions(Map<String, Double> dimAvgs) {
        // 找出低于各维度满分60%的维度
        return dimAvgs.entrySet().stream()
            .filter(e -> e.getValue() < getMaxScore(e.getKey()) * 0.6)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
    }
}
```

### 11.2 AI 调用成本优化

```
单次全篇批改预估成本：
- 审题分析：~800 tokens × ¥0.002/1K = ¥0.0016
- AI深度评审：~2000 tokens × ¥0.005/1K = ¥0.01
- Chinglish检测：~500 tokens × ¥0.002/1K = ¥0.001
- 大纲生成（按需）：~1000 tokens × ¥0.002/1K = ¥0.002
- 段落提示（按需）：~500 tokens × ¥0.002/1K = ¥0.001
─────────────────────────────────────
合计单次约 ¥0.015-0.02

优化措施：
1. 内容哈希去重：相同内容不重复调用AI
2. 语法检查优先使用本地规则引擎（免费）
3. 段落级快检使用轻量模型（成本降低60%）
4. 大纲生成结果缓存（同题目同年级可复用）
5. 素材推荐使用向量检索 + 缓存（减少AI调用）
```

## 13. 测试要点

### 13.1 功能测试场景

| 场景 | 测试内容 | 预期结果 |
| --- | --- | --- |
| 审题-书信题 | 输入书信类题目 | 正确识别为 application_letter 类型 |
| 审题-图片题 | 输入看图写话题目 | 识别为 picture_writing 并提取图片要点 |
| 大纲-初中议论文 | 生成初中议论文大纲 | 三段式结构，词数80-120 |
| 语法-主谓一致 | 输入含主谓不一致文本 | 准确标注错误位置和建议修改 |
| 语法-时态混用 | 输入过去时和现在时混用文本 | 标注时态不一致处 |
| Chinglish-直译 | 输入 "open the light" | 建议改为 "turn on the light" |
| 评分-满分作文 | 提交高质量作文 | 得分 > 90，亮点标注完整 |
| 评分-低分作文 | 提交大量语法错误作文 | 得分 < 50，问题标注详细 |
| 断点续写 | 中途退出后重新进入 | 恢复上次的写作进度 |
| 降级-AI不可用 | 模拟AI服务超时 | 返回规则引擎评分结果 |

### 13.2 边界条件测试

```
- 空内容提交 → 返回 ESSAY_003 错误
- 1个词的作文 → 提示词数不足
- 超长作文（2000词）→ 截断处理并提示
- 全中文提交 → 提示请用英语写作
- 纯复制粘贴范文 → 标记疑似抄袭
- 含特殊字符/表情 → 正常处理不崩溃
- 同一内容重复提交 → 返回缓存的批改结果
- 并发提交同一会话 → 只执行一次批改
```
