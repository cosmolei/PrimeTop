# 服务端-用户年级升迁与学段转换服务 - 详细设计

> **版本**: v1.0 | **日期**: 2026-05-31 | **状态**: 初稿
> **模块定位**: PrimeTop 用户生命周期管理子系统
> **优先级**: P1（V1.5 阶段核心功能，但需 MVP 阶段预留扩展点）

---

## 1. 概述

### 1.1 功能边界

**一句话定义**：当学生用户发生年级变更（如 G5→G6）或学段转换（如小学→初中、初中→高中）时，自动完成教材版本重映射、学科列表调整、学习计划重置、知识掌握度迁移、UI 适配策略切换等全链路处理。

**本服务负责**：

| 职责 | 说明 |
|------|------|
| 年级变更检测 | 自动/手动触发年级升迁事件 |
| 学段转换判定 | 判别是否跨学段（小学→初中、初中→高中） |
| 教材版本重映射 | 新年级对应教材版本选择与切换 |
| 学科列表调整 | 增删学科（如初中新增物理、化学） |
| 知识掌握度迁移 | 跨学段知识点延续性评估与掌握度折算 |
| 学习计划重置 | 基于新年级/学段重新生成学习规划 |
| 学习数据归档 | 旧学段数据归档保留，新学段初始化 |
| 家长通知 | 升迁事件推送到家长端 |

**本服务不负责**（依赖其他服务）：

| 外部依赖 | 说明 |
|----------|------|
| 用户服务 | 用户基本信息、年级/学段字段存储 |
| 内容服务 | 教材版本、章节目录、知识点体系 |
| 学习规划服务 | 学习计划生成与任务创建 |
| 学情分析服务 | 知识掌握度查询与更新 |
| 通知服务 | 消息推送与家长提醒 |
| 事件总线 | Kafka 事件发布与消费 |

### 1.2 学段与年级模型

```
┌─────────────┬──────────────────────────┬──────────────┐
│   学段代码   │         年级范围          │   学段转换点  │
├─────────────┼──────────────────────────┼──────────────┤
│ PRESCHOOL   │ 幼儿园 K1-K3 (无年级)     │ → PRIMARY    │
│ PRIMARY     │ 小学 1-6 年级             │ → JUNIOR     │
│ JUNIOR      │ 初中 7-9 年级（或初一-初三）│ → SENIOR     │
│ SENIOR      │ 高中 10-12 年级（或高一-高三）│ → 毕业       │
└─────────────┴──────────────────────────┴──────────────┘
```

**学段转换关键节点**：

| 转换 | 典型变化 |
|------|---------|
| 幼儿→小学 | 学科体系建立、教材版本首次选择、UI 从图像化切换为文字+图像 |
| 小学→初中 | 新增物理/化学/生物/历史/地理/政治、知识点难度跃升、教材版本可能变更 |
| 初中→高中 | 学科深度大幅提升、新增高考备考场景、教材版本独立选择 |

```
                                         └────────────┘
```

## 5. 核心逻辑详细设计

### 5.1 升迁触发判定引擎

```java
/**
 * 年级升迁触发判定服务
 */
@Service
public class GradeTransitionEvaluator {
    
    @Autowired
    private UserPropertyService userPropertyService;
    
    @Autowired
    private SemesterCalendarService semesterCalendarService;
    
    /**
     * 判定是否为学段转换（跨学段）
     */
    public TransitionType evaluateTransitionType(int oldGrade, int newGrade,
                                                  String oldStage, String newStage) {
        if (!oldStage.equals(newStage)) {
            return TransitionType.STAGE_UP;
        }
        if (newGrade > oldGrade) {
            return TransitionType.GRADE_UP;
        }
        throw new BusinessException("INVALID_TRANSITION", 
            "不支持的年级变更: " + oldGrade + " → " + newGrade);
    }
    
    /**
     * 自动升迁检测（学期结束时触发）
     * 由定时任务在每个学期结束时调用
     */
    public List<TransitionCandidate> detectAutoTransitionCandidates() {
        // 1. 获取当前学期信息
        SemesterInfo currentSemester = semesterCalendarService.getCurrentSemester();
        if (!currentSemester.isEnding()) {
            return Collections.emptyList();
        }
        
        // 2. 查询本学期即将升学的学生
        //    小学六年级、初中三年级、高中三年级
        List<Integer> graduationGrades = Arrays.asList(6, 9, 12);
        List<UserProfile> candidates = userPropertyService
            .findByGradeInAndStageTransitionEligible(graduationGrades);
        
        return candidates.stream()
            .map(user -> {
                int newGrade = user.getGrade() + 1;
                String newStage = calculateNewStage(user.getGrade(), user.getStage());
                // 高三毕业不再自动升级
                if ("SENIOR".equals(user.getStage()) && user.getGrade() == 12) {
                    return null;
                }
                return new TransitionCandidate(user.getUserId(), newGrade, newStage);
            })
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
    }
    
    private String calculateNewStage(int grade, String currentStage) {
        switch (grade) {
            case 6:  return "JUNIOR";   // 小学毕业→初中
            case 9:  return "SENIOR";   // 初中毕业→高中
            default: return currentStage; // 同学段升级
        }
    }
}
```

### 5.2 教材版本自动推荐

```java
/**
 * 教材版本推荐服务
 * 基于用户历史教材版本和地区信息，推荐新学段教材版本
 */
@Service
public class TextbookRecommendationService {
    
    @Autowired
    private StageTextbookRecommendationMapper recommendationMapper;
    
    @Autowired
    private TextbookService textbookService;
    
    /**
     * 为用户推荐新学段教材版本集
     */
    public TextbookSetRecommendation recommend(String userId, String oldTextbookSetId,
                                                 String fromStage, String toStage,
                                                 String region) {
        // 1. 查询推荐规则表
        List<StageTextbookRecommendation> recommendations = recommendationMapper
            .findByFromStageAndTextbook(fromStage, oldTextbookSetId, toStage);
        
        // 2. 地区匹配优先
        StageTextbookRecommendation best = recommendations.stream()
            .filter(r -> region != null && region.equals(r.getRegion()))
            .max(Comparator.comparing(StageTextbookRecommendation::getConfidence))
            .orElse(null);
        
        // 3. 无地区匹配，取默认推荐
        if (best == null) {
            best = recommendations.stream()
                .filter(r -> r.getIsDefault() == 1)
                .findFirst()
                .orElse(null);
        }
        
        // 4. 兜底：取该学段最常用教材版本
        if (best == null) {
            String defaultTextbookId = textbookService
                .getDefaultTextbookSetId(toStage, region);
            best = new StageTextbookRecommendation();
            best.setToTextbookId(defaultTextbookId);
            best.setConfidence(new BigDecimal("0.50"));
        }
        
        // 5. 构建推荐结果
        return TextbookSetRecommendation.builder()
            .recommendedTextbookSetId(best.getToTextbookId())
            .confidence(best.getConfidence())
            .textbookDetails(textbookService.getTextbookSetDetail(best.getToTextbookId()))
            .reason(buildRecommendationReason(best, fromStage, toStage))
            .build();
    }
    
    private String buildRecommendationReason(StageTextbookRecommendation rec, 
                                              String fromStage, String toStage) {
        return String.format("基于您当前使用的人教版小学教材，推荐继续使用人教版初中教材（匹配度 %.0f%%）",
            rec.getConfidence().doubleValue() * 100);
```

### 5.3 知识掌握度迁移引擎

```java
/**
 * 跨学段知识掌握度迁移服务
 * 
 * 迁移策略：
 * - CONTINUOUS（延续性知识）：直接迁移掌握度（如小学数学→初中数学的基础运算）
 * - FOUNDATION（基础性知识）：掌握度打折迁移（如小学科学→初中物理的力学基础）
 * - INDEPENDENT（独立性知识）：不迁移，重置为0（如高中政治的全新内容）
 */
@Service
public class KnowledgeMasteryMigrationService {
    
    @Autowired
    private CrossStageKnowledgeMappingMapper mappingMapper;
    
    @Autowired
    private UserMasteryService masteryService;
    
    /**
     * 执行知识掌握度迁移
     * @return 迁移摘要
     */
    public MasteryMigrationResult migrate(String userId, String fromStage, String toStage) {
        MasteryMigrationResult result = new MasteryMigrationResult();
        
        // 1. 查询跨学段知识映射关系
        List<CrossStageKnowledgeMapping> mappings = mappingMapper
            .findByStageTransition(fromStage, toStage);
        
        // 2. 获取用户当前掌握度快照
        Map<String, Double> currentMastery = masteryService.batchGetMastery(userId, fromStage);
        
        int migrated = 0, reset = 0;
        List<KnowledgeMasteryTransfer> transfers = new ArrayList<>();
        
        // 3. 逐个知识点迁移
        for (CrossStageKnowledgeMapping mapping : mappings) {
            Double sourceMastery = currentMastery.getOrDefault(mapping.getFromKpId(), 0.0);
            
            if (mapping.getRelationType().equals("INDEPENDENT")) {
                // 独立知识：不迁移
                reset++;
                continue;
            }
            
            // 计算迁移后的掌握度
            double transferCoefficient = mapping.getMasteryTransfer().doubleValue();
            double targetMastery = sourceMastery * transferCoefficient;
            
            // 保底处理：如果源掌握度 < 0.3，说明基础薄弱，目标重置为 0
            if (sourceMastery < 0.3) {
                targetMastery = 0.0;
                reset++;
            } else {
                // 上限保护：不超过 0.8（新学段需要重新验证）
                targetMastery = Math.min(targetMastery, 0.8);
                migrated++;
            }
            
            transfers.add(new KnowledgeMasteryTransfer(
                mapping.getToKpId(),
                mapping.getSubject(),
                sourceMastery,
                targetMastery,
                mapping.getRelationType()
            ));
        }
        
        // 4. 批量写入新学段掌握度
        if (!transfers.isEmpty()) {
            masteryService.batchUpdateMastery(userId, toStage, transfers);
        }
        
        // 5. 构建迁移摘要
        result.setTotal(mappings.size() + reset);
        result.setMigrated(migrated);
        result.setReset(reset);
        result.setAveragePreserved(calculateAveragePreserved(transfers));
        result.setTransfers(transfers);
        
        return result;
    }
    
    private double calculateAveragePreserved(List<KnowledgeMasteryTransfer> transfers) {
        if (transfers.isEmpty()) return 0.0;
        return transfers.stream()
            .mapToDouble(t -> t.getTargetMastery())
            .average()
            .orElse(0.0);
    }
}
```

### 5.4 升迁编排器（核心流程）

```java
/**
 * 年级升迁编排器
 * 按步骤顺序执行升迁流程，支持失败重试和回滚
 */
@Service
@Slf4j
public class GradeTransitionOrchestrator {
    
    @Autowired
    private GradeTransitionLogMapper transitionLogMapper;
    
    @Autowired
    private List<TransitionStepHandler> stepHandlers; // Spring 自动注入所有步骤处理器
    
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    private static final int MAX_RETRY = 3;
    
    /**
     * 执行年级升迁
     */
    @Transactional
    public TransitionResult execute(String transitionId) {
        // 1. 加载升迁记录
        GradeTransitionLog transition = transitionLogMapper
            .selectByTransitionId(transitionId);
        if (transition == null) {
            throw new BusinessException("TRANSITION_NOT_FOUND", "升迁记录不存在");
        }
        if (transition.getStatus() != TransitionStatus.PENDING 
            && transition.getStatus() != TransitionStatus.PROCESSING) {
            throw new BusinessException("INVALID_STATUS", "升迁记录状态不允许执行");
        }
        
        // 2. 更新状态为处理中
        transition.setStatus(TransitionStatus.PROCESSING);
        transition.setStartedAt(LocalDateTime.now());
        transitionLogMapper.update(transition);
        
        // 3. 获取有序步骤处理器
        List<TransitionStepHandler> orderedHandlers = stepHandlers.stream()
            .sorted(Comparator.comparingInt(TransitionStepHandler::getOrder))
            .collect(Collectors.toList());
        
        TransitionContext context = new TransitionContext(transition);
        
        // 4. 顺序执行各步骤
        for (TransitionStepHandler handler : orderedHandlers) {
            String stepCode = handler.getStepCode();
            
            try {
                // 检查是否已完成（重试场景）
                StepStatus existingStatus = getStepStatus(transitionId, stepCode);
                if (existingStatus == StepStatus.SUCCESS) {
                    log.info("步骤 {} 已完成，跳过", stepCode);
                    continue;
                }
                
                // 记录步骤开始
                recordStep(transitionId, stepCode, handler.getStepName(), 
                          StepStatus.RUNNING, null, null);
                transition.setCurrentStep(stepCode);
                transitionLogMapper.update(transition);
                
                // 执行步骤
                StepResult stepResult = handler.execute(context);
                
                // 记录步骤成功
                recordStep(transitionId, stepCode, handler.getStepName(),
                          StepStatus.SUCCESS, stepResult.getInput(), stepResult.getOutput());
                
                context.addCompletedStep(stepCode, stepResult);
                
            } catch (Exception e) {
                log.error("升迁步骤 {} 执行失败: {}", stepCode, e.getMessage(), e);
                
                // 记录步骤失败
                recordStep(transitionId, stepCode, handler.getStepName(),
                          StepStatus.FAILED, null, e.getMessage());
                
                // 重试判定
                int retryCount = transition.getRetryCount();
                if (retryCount < MAX_RETRY) {
                    transition.setRetryCount(retryCount + 1);
                    transition.setErrorCode("STEP_FAILED");
                    transition.setErrorMessage(
                        String.format("步骤 %s 失败: %s (第%d次重试)", 
                            stepCode, e.getMessage(), retryCount + 1));
                    transitionLogMapper.update(transition);
                    
                    // 发布重试事件（由定时任务拾取重试）
                    eventPublisher.publishEvent(new TransitionRetryEvent(transitionId));
                    return TransitionResult.retry(transitionId, stepCode, retryCount + 1);
                }
                
                // 超过重试次数，标记失败
                transition.setStatus(TransitionStatus.FAILED);
                transition.setErrorCode("MAX_RETRY_EXCEEDED");
                transition.setErrorMessage(
                    String.format("步骤 %s 失败，已超过最大重试次数: %s", stepCode, e.getMessage()));
                transitionLogMapper.update(transition);
                
                return TransitionResult.failed(transitionId, stepCode, e.getMessage());
            }
        }
        
        // 5. 全部步骤完成
        transition.setStatus(TransitionStatus.COMPLETED);
        transition.setCompletedAt(LocalDateTime.now());
        transition.setCurrentStep("FINALIZE");
        
        // 填充迁移摘要
        TransitionResult summary = context.buildSummary();
        transition.setSubjectsAdded(toJson(summary.getSubjectsAdded()));
        transition.setSubjectsRemoved(toJson(summary.getSubjectsRemoved()));
        transition.setKnowledgeMigrated(toJson(summary.getKnowledgeMigration()));
        transition.setPlanReset(summary.isPlanReset() ? 1 : 0);
        
        transitionLogMapper.update(transition);
        
        // 6. 发布升迁完成事件
        eventPublisher.publishEvent(
            new GradeTransitionCompletedEvent(transition.getUserId(), transitionId));
        
        return TransitionResult.success(transitionId, summary);
    }
}
```

```java
/**
 * 步骤⑤：学科列表调整
 */
@Component
public class AdjustSubjectsStepHandler implements TransitionStepHandler {
    
    @Override
    public String getStepCode() { return "ADJUST_SUBJECTS"; }
    
    @Override
    public String getStepName() { return "学科列表调整"; }
    
    @Override
    public int getOrder() { return 50; }
    
    @Autowired
    private StageSubjectMappingMapper subjectMappingMapper;
    
    @Autowired
    private UserSubjectService userSubjectService;
    
    @Override
    public StepResult execute(TransitionContext context) {
        GradeTransitionLog transition = context.getTransition();
        String newStage = transition.getNewStage();
        int newGrade = transition.getNewGrade();
        
        // 1. 查询目标学段学科列表
        List<StageSubjectMapping> targetSubjects = subjectMappingMapper
            .findByStageAndGrade(newStage, newGrade);
        
        // 2. 获取当前用户学科列表
        List<String> currentSubjects = userSubjectService
            .getUserSubjects(transition.getUserId());
        
        List<String> currentCodes = targetSubjects.stream()
            .map(StageSubjectMapping::getSubjectCode).collect(Collectors.toList());
        
        // 3. 计算差异
        List<String> added = currentCodes.stream()
            .filter(code -> !currentSubjects.contains(code))
            .collect(Collectors.toList());
        
        List<String> removed = currentSubjects.stream()
            .filter(code -> !currentCodes.contains(code))
            .collect(Collectors.toList());
        
        // 4. 执行学科调整
        if (!added.isEmpty()) {
            userSubjectService.addSubjects(transition.getUserId(), added, newStage);
        }
        if (!removed.isEmpty()) {
            userSubjectService.archiveSubjects(transition.getUserId(), removed);
        }
        
        // 5. 为新增学科初始化基础数据
        for (String subjectCode : added) {
            userSubjectService.initializeNewSubject(transition.getUserId(), 
                subjectCode, newStage, newGrade);
        }
        
        Map<String, Object> output = new HashMap<>();
        output.put("subjectsAdded", added);
        output.put("subjectsRemoved", removed);
        output.put("totalSubjects", currentCodes.size());
        
        return StepResult.success(output);
    }
}
```

### 7.3 回滚策略

```java
/**
 * 升迁回滚服务
 */
@Service
public class GradeTransitionRollbackService {
    
    /**
     * 回滚已完成的升迁操作
     * 
     * 回滚条件：
     * 1. 升迁状态为 COMPLETED
     * 2. 距离升迁完成不超过 24 小时
     * 3. 升迁后用户未产生新的学习行为（安全校验）
     */
    @Transactional
    public void rollback(String transitionId, String reason) {
        GradeTransitionLog transition = transitionLogMapper.selectByTransitionId(transitionId);
        
        // 1. 校验回滚条件
        validateRollbackPrecondition(transition);
        
        // 2. 按逆序执行各步骤的 rollback 方法
        List<TransitionStepHandler> handlers = stepHandlers.stream()
            .sorted(Comparator.comparingInt(TransitionStepHandler::getOrder).reversed())
            .collect(Collectors.toList());
        
        TransitionContext context = new TransitionContext(transition);
        
        for (TransitionStepHandler handler : handlers) {
            StepStatus stepStatus = getStepStatus(transitionId, handler.getStepCode());
            if (stepStatus == StepStatus.SUCCESS) {
                try {
                    handler.rollback(context);
                } catch (Exception e) {
                    log.error("回滚步骤 {} 失败: {}", handler.getStepCode(), e.getMessage());
                    // 回滚失败不中断，继续尝试回滚其他步骤
                }
            }
        }
        
        // 3. 更新状态
        transition.setStatus(TransitionStatus.ROLLED_BACK);
        transition.setErrorMessage("手动回滚: " + reason);
        transition.setCompletedAt(LocalDateTime.now());
        transitionLogMapper.update(transition);
        
        // 4. 发布回滚事件
        eventPublisher.publishEvent(
            new GradeTransitionRolledBackEvent(transition.getUserId(), transitionId));
    }
    
    private void validateRollbackPrecondition(GradeTransitionLog transition) {
        // 24小时限制
        if (transition.getCompletedAt()
            .isBefore(LocalDateTime.now().minusHours(24))) {
            throw new BusinessException("ROLLBACK_TIMEOUT", "超过24小时不可回滚");
        }
        
        // 安全校验：升迁后是否有新学习行为
        boolean hasNewActivity = learningActivityChecker
            .hasActivitySince(transition.getUserId(), transition.getCompletedAt());
        if (hasNewActivity) {
            throw new BusinessException("ROLLBACK_UNSAFE", 
                "升迁后已有新的学习行为，回滚可能导致数据不一致");
        }
    }
}
```

## 10. 性能与容量

### 10.1 性能指标

| 操作 | 目标响应时间 | 说明 |
|------|------------|------|
| 预览升迁影响 | < 1s | 查询为主，可缓存 |

| 查询升迁进度 | < 100ms | 读缓存 |
| 回滚升迁 | < 60s | 逆序回滚各步骤 |

### 10.2 并发控制

```java
// 分布式锁：同一用户同一时间只允许一个升迁任务
String lockKey = "transition:lock:" + userId;
boolean locked = redisTemplate.opsForValue()
    .setIfAbsent(lockKey, transitionId, Duration.ofMinutes(5));

if (!locked) {
    throw new BusinessException("TRANSITION_IN_PROGRESS", 
        "该用户已有升迁任务进行中，请稍后再试");
}
```

## 13. 监控与告警

### 13.1 监控指标

| 指标名 | 类型 | 说明 |
|--------|------|------|
| `transition.created.total` | Counter | 升迁任务创建总数 |
| `transition.completed.total` | Counter | 升迁完成总数 |
| `transition.failed.total` | Counter | 升迁失败总数 |
| `transition.rolled_back.total` | Counter | 回滚总数 |
| `transition.duration.seconds` | Histogram | 升迁执行耗时分布 |
| `transition.step.duration.seconds` | Histogram | 单步骤执行耗时 |
| `transition.active.count` | Gauge | 当前进行中的升迁数 |

### 13.2 告警规则

```
# 升迁失败率超过 5%
ALERT TransitionFailureRateHigh
  WHEN rate(transition.failed.total[5m]) / rate(transition.created.total[5m]) > 0.05
  NOTIFY ops-team

# 单次升迁执行超过 60 秒
ALERT TransitionSlowExecution
  WHEN histogram_quantile(0.95, transition.duration.seconds) > 60
  NOTIFY ops-team

# 升迁重试队列积压超过 10
ALERT TransitionRetryBacklog
  WHEN transition.retry.pending.count > 10
  NOTIFY ops-team
```
