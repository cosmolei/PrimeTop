# 学生薄弱点识别与靶向训练推荐服务 详细设计

## 1. 概述

### 1.1 模块定位

学生薄弱点识别与靶向训练推荐服务是 PrimeTop 学习闭环的核心引擎之一，负责将学生历史答题、错题、学习行为等数据转化为可执行的薄弱点画像，并据此生成个性化的靶向训练计划与资源推荐。该服务向上承接「学情分析」「错题整理」「答题记录」等数据，向下驱动「题目推荐」「学习规划」「学习内容分发」等执行模块。

### 1.2 核心职责

1. **薄弱点识别**：基于答题记录、错题记录、练习记录、知识点掌握度，计算学生薄弱点。  
2. **薄弱点画像**：按学科、知识点、题型、错误原因、时间维度构建动态画像。  
3. **靶向训练推荐**：为每个薄弱点推荐合适的题目、课程、复习材料、学习策略。  
4. **训练计划编排**：生成短期（今日/本周）和中期（本月/阶段）训练计划。  
5. **效果追踪**：记录训练完成情况，重新评估薄弱点，形成闭环反馈。  
6. **与学情/规划联动**：将薄弱点信息同步给学情报告、学习规划、每日任务生成服务。

### 1.3 依赖关系

| 依赖模块 | 依赖方式 | 用途 |
| --- | --- | --- |
| 答题记录服务 | 查询 | 获取答题正确率、耗时、次数 |
| 错题服务 | 查询 | 获取错题标签、错因、订正状态 |
| 题目服务 | 查询/调用 | 题目检索、类题推荐、难度查询 |
| 学情分析服务 | 查询/推送 | 获取能力画像、掌握度，同步薄弱点 |
| 学习规划服务 | 调用 | 将训练计划纳入学习计划 |
| 学习内容服务 | 查询 | 获取课程、微课、讲义等复习资源 |
| 用户画像服务 | 查询 | 学段、年级、教材版本、学习偏好 |
| 消息/通知服务 | 调用 | 训练提醒、复习提醒 |

## 4. 业务逻辑

### 4.1 核心流程

#### 4.1.1 薄弱点分析流程

```
[触发条件] -> [数据采集] -> [指标计算] -> [薄弱度评分] -> [画像生成] -> [缓存更新] -> [事件通知]
```

触发条件：
- 每日定时任务（凌晨 2:00）
- 用户完成一次练习/测验后
- 用户错题新增/订正后
- 手动触发（管理后台/调试接口）
- 学习规划生成前

数据采集：
- 答题记录：近 90 天答题数据
- 错题记录：未订正、订正后仍错、反复错的题目
- 学习会话：学习时长、重复学习次数
- 知识点掌握度：来自学情分析服务

指标计算：
- 正确率 = correct_count / total_answer_count
- 错误频率 = wrong_count / days_since_first_answer
- 连续错误次数
- 近期趋势（近 7 天 vs 近 30 天）
- 知识点掌握度

薄弱度评分：
```
weak_score = w1 * (1 - correct_rate) 
           + w2 * normalize(error_frequency) 
           + w3 * normalize(consecutive_wrong) 
           + w4 * recency_weight 
           + w5 * (1 - mastery_level / 5)
```

权重建议：w1=0.35, w2=0.15, w3=0.15, w4=0.15, w5=0.20

掌握度等级映射：
- weak_score >= 0.75: 1-未掌握
- 0.55 <= weak_score < 0.75: 2-薄弱
- 0.35 <= weak_score < 0.55: 3-一般
- 0.15 <= weak_score < 0.35: 4-良好
- weak_score < 0.15: 5-精通

#### 4.1.2 靶向训练推荐流程

```
[获取薄弱点] -> [知识点扩展] -> [内容检索] -> [难度匹配] -> [多样性控制] -> [排序输出]
```

知识点扩展：
- 对薄弱知识点，查询其前置知识点和关联知识点
- 若前置知识点也薄弱，优先推荐前置知识点训练

内容检索：
- 调用题目服务：按知识点、题型、难度检索题目
- 调用内容服务：获取相关微课、讲义、知识点卡片
- 调用错题服务：获取该知识点相关错题

难度匹配：
- 根据薄弱度选择难度：
  - 未掌握/薄弱：难度 0.2~0.5（基础题为主）
  - 一般：难度 0.4~0.7（巩固提升）
  - 良好：难度 0.6~0.9（挑战拔高）

多样性控制：
- 题型多样化：选择、填空、解答、判断混合
- 内容类型多样化：题目 + 微课 + 错题复习
- 时间分散：避免同一知识点连续出现

排序输出：
- 优先级 = 薄弱度 * 0.4 + 近期错误权重 * 0.3 + 知识点重要性 * 0.2 + 多样性奖励 * 0.1

#### 4.1.3 训练计划生成流程

```
[选择薄弱点] -> [设定目标] -> [内容编排] -> [时间分配] -> [生成计划] -> [同步学习规划]
```

选择薄弱点：
- 默认选择 TOP 5 薄弱点
- 过滤已掌握和已归档的薄弱点
- 考虑学科平衡：避免单一学科占用过多时间

设定目标：
- 每个薄弱点设定目标掌握度等级
- 计算预计需要练习次数/时长

内容编排：
- 每个薄弱点：先复习错题/知识点，再做基础题，再做变式题
- 交错安排：避免长时间练习同一知识点

时间分配：
- 日计划：20~30 分钟
- 周计划：60~120 分钟
- 阶段计划：根据目标灵活设定

同步学习规划：
- 将训练计划写入学习规划服务，作为每日任务的一部分
- 触发消息服务发送提醒

### 4.2 状态机

#### 4.2.1 训练计划状态机

```
DRAFT(1) -> ACTIVE(2) -> COMPLETED(3) -> ARCHIVED(4)
  |
  v
CANCELLED(5)
```

状态说明：
- DRAFT（1）：草稿，刚生成，尚未开始
- ACTIVE（2）：进行中，已到开始时间或学生已开始训练
- COMPLETED（3）：已完成，所有训练项完成或到达结束时间
- ARCHIVED（4）：已归档，完成效果评估后归档
- CANCELLED（5）：已取消，学生或系统主动取消

状态转换规则：
- DRAFT -> ACTIVE：到达 start_time 或学生开始第一项训练
- ACTIVE -> COMPLETED：所有 item 完成或到达 end_time
- COMPLETED -> ARCHIVED：效果评估完成
- ACTIVE -> CANCELLED：学生取消或计划被新计划覆盖
- DRAFT -> CANCELLED：学生取消

#### 4.2.2 训练项状态机

```
PENDING(1) -> IN_PROGRESS(2) -> COMPLETED(3)
  |              |
  v              v
SKIPPED(4)   SKIPPED(4)
```

状态说明：
- PENDING（1）：待完成
- IN_PROGRESS（2）：进行中（已开始学习/答题）
- COMPLETED（3）：已完成
- SKIPPED（4）：已跳过

状态转换规则：
- PENDING -> IN_PROGRESS：学生开始训练项
- IN_PROGRESS -> COMPLETED：训练项完成
- PENDING -> SKIPPED：学生手动跳过或超时未做
- IN_PROGRESS -> SKIPPED：学生中途跳过

### 4.3 关键算法

#### 4.3.1 薄弱度综合评分算法

```python
def calculate_weak_score(correct_rate, error_freq, consecutive_wrong, 
                         days_since_last_wrong, mastery_level, total_count):
    """
    计算薄弱度得分，范围 [0, 1]
    """
    # 正确率因子：正确率越低，得分越高
    correct_factor = 1 - correct_rate
    
    # 错误频率因子：错误频率越高，得分越高
    error_freq_factor = min(1.0, error_freq / 10.0)
    
    # 连续错误因子：连续错误次数越多，得分越高
    consecutive_factor = min(1.0, consecutive_wrong / 5.0)
    
    # 时效因子：近期错误权重更高
    recency_factor = 1.0 / (1 + days_since_last_wrong / 7.0)
    
    # 掌握度因子：掌握度等级越低，得分越高
    mastery_factor = 1 - mastery_level / 5.0
    
    # 样本可信度：答题次数越多，评分越可信
    confidence = min(1.0, total_count / 10.0)
    
    # 加权计算
    score = (0.35 * correct_factor + 
             0.15 * error_freq_factor + 
             0.15 * consecutive_factor + 
             0.15 * recency_factor + 
             0.20 * mastery_factor) * confidence
    
    return min(1.0, max(0.0, score))
```

#### 4.3.2 知识点掌握度更新

```python
def update_mastery_level(old_mastery, answer_correct, difficulty, 
                         learning_session_count, forget_curve_factor):
    """
    根据答题结果更新掌握度等级
    """
    # 基础调整步长
    step = 0.5 if answer_correct else -0.8
    
    # 难度加权：难题答对增加更多，简单题答错减少更多
    difficulty_adjust = (difficulty - 0.5) * 0.4
    if answer_correct:
        step += difficulty_adjust
    else:
        step -= difficulty_adjust
    
    # 学习会话加权：多次学习后调整放缓
    session_dampening = 1.0 / (1 + learning_session_count * 0.2)
    step *= session_dampening
    
    # 遗忘曲线因子：长时间未复习，掌握度自然衰减
    new_mastery = old_mastery + step - forget_curve_factor
    
    # 限制在 [1, 5] 等级
    return max(1.0, min(5.0, new_mastery))
```

#### 4.3.3 推荐排序算法

```python
def recommendation_score(weak_point, content, recent_error_weight, 
                         knowledge_importance, diversity_bonus):
    """
    计算推荐内容得分
    """
    weak_score = weak_point.weak_score
    difficulty_match = 1 - abs(content.difficulty - weak_point.recommended_difficulty)
    
    score = (0.4 * weak_score + 
             0.25 * recent_error_weight + 
             0.15 * knowledge_importance + 
             0.10 * difficulty_match + 
             0.10 * diversity_bonus)
    
    return score
```

```java
@Service
public class WeakPointAnalysisService {
    
    @Autowired
    private WeakPointProfileRepository profileRepository;
    
    @Autowired
    private AnswerRecordClient answerRecordClient;
    
    @Autowired
    private MistakeRecordClient mistakeRecordClient;
    
    @Autowired
    private LearningProfileClient learningProfileClient;

    @Autowired

    /**
     * 触发学生薄弱点分析
     */
    public AnalysisTask triggerAnalysis(Long studentId, List<String> subjectCodes, 
                                         String triggerScene, boolean force) {
        String lockKey = String.format("wp:lock:analyze:%d", studentId);
        Boolean locked = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "1", Duration.ofSeconds(60));
        
        if (!locked && !force) {
            throw new BizException(400007, "分析任务正在执行中，请勿重复触发");
        }
        
        String taskId = String.format("wp-analyze-%s-%d", 
            LocalDateTime.now().format(DateTimeFormatter.BASIC_ISO_DATE), studentId);
        
        // 异步执行分析
        CompletableFuture.runAsync(() -> {
            try {
                analyzeInternal(studentId, subjectCodes, taskId);
            } finally {
                redisTemplate.delete(lockKey);
            }
        });
        
        return new AnalysisTask(taskId, AnalysisTaskStatus.ACCEPTED);
    }
    
    /**
     * 执行分析核心逻辑
     */
    @Transactional
    public void analyzeInternal(Long studentId, List<String> subjectCodes, String taskId) {
        // 1. 采集数据
        AnswerRecordQuery query = AnswerRecordQuery.builder()
            .studentId(studentId)
            .subjectCodes(subjectCodes)
            .startTime(LocalDateTime.now().minusDays(90))
            .build();
        
        List<AnswerRecord> records = answerRecordClient.queryRecords(query);
        List<MistakeRecord> mistakes = mistakeRecordClient.queryMistakes(query);
        Map<String, BigDecimal> masteryMap = learningProfileClient
            .getMasteryLevels(studentId, subjectCodes);
        
        // 2. 按知识点聚合
        Map<String, KnowledgePointStats> statsMap = aggregateByKnowledgePoint(records, mistakes);
        
        // 3. 计算薄弱点
        List<WeakPointProfile> profiles = new ArrayList<>();
        for (Map.Entry<String, KnowledgePointStats> entry : statsMap.entrySet()) {
            String kpId = entry.getKey();
            KnowledgePointStats stats = entry.getValue();
            
            BigDecimal mastery = masteryMap.getOrDefault(kpId, BigDecimal.valueOf(1.0));
            BigDecimal weakScore = calculateWeakScore(stats, mastery);
            Integer masteryLevel = mapToMasteryLevel(weakScore);
            Integer trend = calculateTrend(studentId, kpId, weakScore);
            
            WeakPointProfile profile = WeakPointProfile.builder()
                .studentId(studentId)
                .knowledgePointId(kpId)
                .subjectCode(stats.getSubjectCode())
                .gradeCode(stats.getGradeCode())
                .weakScore(weakScore)
                .masteryLevel(masteryLevel)
                .totalAnswerCount(stats.getTotalCount())
                .correctCount(stats.getCorrectCount())
                .wrongCount(stats.getWrongCount())
                .consecutiveWrong(stats.getConsecutiveWrong())
                .firstWrongTime(stats.getFirstWrongTime())
                .lastWrongTime(stats.getLastWrongTime())
                .errorReasonTags(stats.getErrorReasonTags())
                .questionTypeTags(stats.getQuestionTypeTags())
                .trend(trend)
                .calculatedAt(LocalDateTime.now())
                .updatedAt(LocalDateTime.now())
                .isArchived(0)
                .build();
            
            profiles.add(profile);
        }
        
        // 4. 批量保存
        profileRepository.batchUpsert(profiles);
        
        // 5. 更新缓存
        profileCacheService.refresh(studentId);
        
        // 6. 发布事件
        eventPublisher.publishEvent(new WeakPointAnalyzedEvent(studentId, taskId, profiles));
    }
    
    private BigDecimal calculateWeakScore(KnowledgePointStats stats, BigDecimal masteryLevel) {
        double correctRate = stats.getTotalCount() > 0 
            ? (double) stats.getCorrectCount() / stats.getTotalCount() : 0.0;
        
        long daysSinceLastWrong = stats.getLastWrongTime() != null 
            ? ChronoUnit.DAYS.between(stats.getLastWrongTime().toLocalDate(), LocalDate.now())
            : 90;
        
        double correctFactor = 1.0 - correctRate;
        double errorFreqFactor = Math.min(1.0, stats.getWrongCount() / 10.0);
        double consecutiveFactor = Math.min(1.0, stats.getConsecutiveWrong() / 5.0);
        double recencyFactor = 1.0 / (1.0 + daysSinceLastWrong / 7.0);
        double masteryFactor = 1.0 - masteryLevel.doubleValue() / 5.0;
        double confidence = Math.min(1.0, stats.getTotalCount() / 10.0);
        
        double score = (0.35 * correctFactor + 0.15 * errorFreqFactor 
                      + 0.15 * consecutiveFactor + 0.15 * recencyFactor 
                      + 0.20 * masteryFactor) * confidence;
        
        return BigDecimal.valueOf(Math.min(1.0, Math.max(0.0, score)))
            .setScale(4, RoundingMode.HALF_UP);
    }
    
    private Integer mapToMasteryLevel(BigDecimal weakScore) {
        double score = weakScore.doubleValue();
        if (score >= 0.75) return 1;
        if (score >= 0.55) return 2;
        if (score >= 0.35) return 3;
        if (score >= 0.15) return 4;
        return 5;
    }
}
```

### 5.2 推荐服务实现

```java
@Service
public class TargetedRecommendationService {
    
    @Autowired
    private WeakPointProfileRepository profileRepository;
    
    @Autowired
    private QuestionServiceClient questionServiceClient;
    
    @Autowired
    private ContentServiceClient contentServiceClient;
    
    @Autowired
    private MistakeRecordClient mistakeRecordClient;
    
    /**
     * 获取靶向推荐
     */
    public RecommendationResult getRecommendations(Long studentId, String subjectCode, 
                                                    String scene, Integer limit) {
        // 1. 查询薄弱点画像
        List<WeakPointProfile> profiles = profileRepository
            .findActiveByStudentAndSubject(studentId, subjectCode, limit * 2);
        
        if (profiles.isEmpty()) {
            return RecommendationResult.empty();
        }
        
        // 2. 构建候选集
        List<RecommendationItem> candidates = new ArrayList<>();
        for (WeakPointProfile profile : profiles) {
            candidates.addAll(buildCandidatesForProfile(studentId, profile));
        }
        
        // 3. 排序与多样性控制
        List<RecommendationItem> sorted = candidates.stream()
            .sorted(Comparator.comparing(RecommendationItem::getScore).reversed())
            .collect(Collectors.toList());
        
        List<RecommendationItem> diversified = applyDiversityControl(sorted, limit);
        
        return RecommendationResult.builder()
            .focusWeakPoints(profiles.stream()
                .map(WeakPointProfile::getKnowledgePointId)
                .collect(Collectors.toList()))
            .recommendations(diversified)
            .build();
    }
    
    private List<RecommendationItem> buildCandidatesForProfile(Long studentId, 
                                                               WeakPointProfile profile) {
        List<RecommendationItem> candidates = new ArrayList<>();
        String kpId = profile.getKnowledgePointId();
        
        // 2.1 错题复习
        List<MistakeRecord> mistakes = mistakeRecordClient
            .queryByKnowledgePoint(studentId, kpId, 3);
        for (MistakeRecord mistake : mistakes) {
            candidates.add(RecommendationItem.builder()
                .profileId(profile.getProfileId())
                .knowledgePointId(kpId)
                .itemType(TrainingItemType.MISTAKE_REVIEW)
                .contentId(mistake.getMistakeId())
                .title(mistake.getQuestionTitle())
                .difficulty(mistake.getDifficulty())
                .estimatedMinutes(8)
                .purpose("回顾错题，强化" + mistake.getKnowledgePointName())
                .score(profile.getWeakScore().doubleValue() * 0.9)
                .build());
        }
        
        // 2.2 推荐题目
        double recommendedDifficulty = mapWeakScoreToDifficulty(profile.getWeakScore());
        QuestionQuery query = QuestionQuery.builder()
            .knowledgePointIds(List.of(kpId))
            .difficultyMin(recommendedDifficulty - 0.15)
            .difficultyMax(recommendedDifficulty + 0.15)
            .questionTypes(profile.getQuestionTypeTags())
            .limit(5)
            .build();
        
        List<Question> questions = questionServiceClient.search(query);
        for (Question question : questions) {
            double difficultyMatch = 1.0 - Math.abs(question.getDifficulty() - recommendedDifficulty);
            candidates.add(RecommendationItem.builder()
                .profileId(profile.getProfileId())
                .knowledgePointId(kpId)
                .itemType(TrainingItemType.QUESTION)
                .contentId(question.getQuestionId())
                .title(question.getTitle())
                .difficulty(question.getDifficulty())
                .estimatedMinutes(question.getEstimatedMinutes())
                .purpose("针对性练习：" + question.getKnowledgePointName())
                .score(profile.getWeakScore().doubleValue() * 0.6 
                       + difficultyMatch * 0.3)
                .build());
        }
        
        // 2.3 微课/知识点卡片
        List<ContentResource> resources = contentServiceClient
            .queryByKnowledgePoint(kpId, List.of("micro_course", "knowledge_card"), 2);
        for (ContentResource resource : resources) {
            candidates.add(RecommendationItem.builder()
                .profileId(profile.getProfileId())
                .knowledgePointId(kpId)
                .itemType(TrainingItemType.MICRO_COURSE)
                .contentId(resource.getContentId())
                .title(resource.getTitle())
                .difficulty(resource.getDifficulty())
                .estimatedMinutes(resource.getDurationMinutes())
                .purpose("重新学习" + resource.getKnowledgePointName())
                .score(profile.getWeakScore().doubleValue() * 0.5)
                .build());
        }
        
        return candidates;
    }
    
    private double mapWeakScoreToDifficulty(BigDecimal weakScore) {
        double score = weakScore.doubleValue();
        if (score >= 0.75) return 0.35;
        if (score >= 0.55) return 0.50;
        if (score >= 0.35) return 0.65;
        if (score >= 0.15) return 0.80;
        return 0.90;
    }
    
    /**
     * 多样性控制：避免同一知识点/题型连续出现
     */
    private List<RecommendationItem> applyDiversityControl(
            List<RecommendationItem> sorted, Integer limit) {
        Set<String> selectedKp = new HashSet<>();
        Set<String> selectedType = new HashSet<>();
        List<RecommendationItem> result = new ArrayList<>();
        
        for (RecommendationItem item : sorted) {
            if (result.size() >= limit) break;
            
            boolean kpDuplicate = selectedKp.contains(item.getKnowledgePointId()) 
                && selectedKp.size() >= 2;
            boolean typeDuplicate = selectedType.contains(item.getItemType().name()) 
                && selectedType.size() >= 2;
            
            if (kpDuplicate && typeDuplicate) {
                continue;
            }
            
            result.add(item);
            selectedKp.add(item.getKnowledgePointId());
            selectedType.add(item.getItemType().name());
        }
        
        return result;
    }
}
```

### 6.2 重试策略

| 操作 | 重试次数 | 退避策略 | 说明 |
| --- | --- | --- | --- |
| 外部服务查询 | 3 | 指数退避 100ms/500ms/2s | 题目/内容服务查询 |
| 数据写入 | 3 | 固定间隔 200ms | 数据库写入失败 |
| 缓存刷新 | 2 | 固定间隔 100ms | Redis 写入失败 |
| 事件发送 | 3 | 指数退避 | 消息队列发送失败 |

### 6.3 降级方案

| 场景 | 降级策略 | 说明 |
| --- | --- | --- |
| 薄弱点分析失败 | 返回最近一次成功画像 | 保持推荐可用 |
| 画像数据缺失 | 基于历史答题记录快速估算 | 简化计算，不依赖外部服务 |
| 题目服务不可用 | 返回知识点卡片+错题复习 | 减少题目推荐数量 |
| 内容服务不可用 | 仅推荐题目和错题 | 不返回微课/讲义 |
| 训练计划生成失败 | 返回单点推荐列表，不生成计划 | 降低耦合 |
| 缓存不可用 | 直接查数据库，不阻塞主流程 | 增加 DB 压力但保证可用 |

## 7. 性能优化

### 7.1 缓存策略

1. **画像缓存**：学生薄弱点画像按学科聚合缓存，减少数据库查询。  
2. **推荐缓存**：同一学生、相同学科、相同场景的推荐结果缓存 5 分钟。  
3. **计算锁**：使用 Redis 分布式锁防止并发分析同一学生。  
4. **缓存预热**：每日分析完成后，异步刷新热点学生缓存。  
5. **缓存失效**：答题/错题新增时，按学生 ID 失效相关缓存。

### 7.2 并发控制

1. **分析任务线程池**：独立线程池，避免阻塞主线程。  
2. **批量写入**：画像批量 upsert，减少数据库往返。  
3. **分页查询**：聚合答题记录时，按时间分页，避免大查询。  
4. **限流**：分析接口按学生 ID 限流（每 5 分钟 1 次），避免滥用。  
5. **数据库连接池**：画像查询使用独立连接池，避免被大查询占满。

### 7.3 资源限制

1. **单次分析知识点上限**：每个学科最多 200 个知识点，避免计算爆炸。  
2. **推荐候选集上限**：每个薄弱点最多 10 个候选，总候选不超过 100。  
3. **训练计划周期**：日计划最长 1 天，周计划最长 7 天，阶段计划最长 30 天。  
4. **归档策略**：30 天未更新的薄弱点画像自动归档，减少数据量。  
5. **维度快照保留**：维度快照保留 90 天，过期自动清理。

## 8. 安全考虑

### 8.1 权限控制

1. **学生数据隔离**：所有查询必须带 `student_id`，只能查询本人数据。  
2. **家长授权**：家长端查看薄弱点需验证绑定关系。  
3. **教师授权**：教师查看班级薄弱点需验证班级权限。  
4. **后台权限**：运营/教研查看 aggregate 数据需角色授权。  
5. **API 鉴权**：所有接口通过网关统一鉴权，携带用户 token。

### 8.2 数据验证

1. **参数校验**：`student_id` 必须为正整数，`subject_code` 必须来自枚举。  
2. **时间范围校验**：`start_time` 不得早于当前时间，`end_time` 必须晚于 `start_time`。  
3. **薄弱点数量校验**：单次计划聚焦薄弱点不超过 5 个。  
4. **难度范围校验**：`difficulty_range` 必须在 [0, 1] 之间。  
5. **输入消毒**：`plan_name` 过滤 HTML 标签和特殊字符。

### 8.3 审计日志

1. **分析触发日志**：记录触发人、触发场景、任务 ID、耗时。  
2. **训练计划变更日志**：记录计划状态变更、操作人、变更原因。  
3. **推荐反馈日志**：记录学生对推荐的反馈（有用/无用/跳过）。  
4. **数据导出日志**：记录薄弱点画像导出行为，用于合规审计。  
5. **异常日志**：记录所有外部服务异常、计算异常、状态机异常。

## 10. 部署与运维

### 10.1 服务拆分建议

MVP 阶段可作为「学习服务」子模块部署；随着数据量增长，可独立为「薄弱点服务」。

### 10.2 关键监控指标

| 指标 | 告警阈值 | 说明 |
| --- | --- | --- |
| 分析任务成功率 | < 95% | 每日分析任务成功率 |
| 分析任务耗时 | > 10 分钟/千学生 | 分析性能指标 |
| 推荐接口 P95 | > 500ms | 接口性能指标 |
| 画像查询 P95 | > 200ms | 接口性能指标 |
| 训练计划完成率 | < 30% | 业务健康指标 |
| 推荐点击率 | < 20% | 推荐质量指标 |
| 外部服务失败率 | > 5% | 依赖服务稳定性 |

### 10.3 应急预案

1. **分析任务堆积**：增加 worker 线程，或按优先级分批处理（活跃用户优先）。  
2. **数据库性能下降**：开启只读副本查询，降低缓存过期时间。  
3. **推荐结果异常**：切换为基于历史错题的兜底推荐。  
4. **算法效果下降**：快速回滚评分权重配置，启用历史稳定版本。  
5. **数据泄露风险**：立即关闭相关接口，审计日志排查，通知安全团队。
