# 学习效果量化追踪与教育价值归因分析系统 - 详细设计

## 1. 模块定位与目标

### 1.1 为什么需要这个系统

PrimeTop 作为教育产品，需要回答三个核心问题：
1. **学生用了产品后，学习有没有变好？** — 效果量化
2. **变好（或没变好）的原因是什么？** — 归因分析
3. **哪些产品功能对学习效果贡献最大？** — 价值归因

现有模块的职责边界：

| 现有模块 | 职责 | 与本系统的关系 |
| --- | --- | --- |
| 学情分析 | 描述"学生当前状态" | 本系统的数据源之一 |
| 数据埋点与关键指标 | 采集"用户做了什么" | 本系统的原始数据来源 |
| 学习报告生成与交付 | 呈现"学情信息" | 本系统的输出消费者 |
| AB测试与实验平台 | 验证"功能变更效果" | 本系统的实验基础设施 |
| 错题整理 | 管理"错误记录" | 本系统的数据源之一 |
| 答题与测评 | 产生"答题结果" | 本系统的数据源之一 |

本系统填补的空白：**从"数据采集"到"效果证明"之间的分析引擎**。

### 1.2 核心目标

| 目标 | 衡量标准 | 优先级 |
| --- | --- | --- |
| 学习效果可量化 | 每个学生可生成阶段性"学习效果指数"(LEI) | P0 |
| 效果归因可追溯 | 能回答"哪些功能/行为对提分贡献最大" | P1 |
| B端价值可证明 | 为学校/机构提供班级/年级级别的效果报告 | P1 |
| 产品优化有依据 | 功能优先级决策有数据支撑 | P2 |

### 1.3 设计原则

1. **教育科学为基**：效果衡量指标必须符合教育测量学原理，不能简单等同于"使用时长"或"做题数量"
2. **因果推断优先**：区分"相关性"和"因果性"，避免混淆变量干扰
3. **隐私保护严格**：效果分析结果仅用于产品优化和教育反馈，不用于排名或营销
4. **渐进式建设**：MVP 先做基础量化，逐步引入归因模型

## 2. 核心概念与数据模型

### 2.1 关键概念定义

```
学习效果 (Learning Effectiveness)
├── 知识掌握度变化 (Knowledge Mastery Delta)
│   ├── 单知识点掌握度变化
│   ├── 章节综合掌握度变化
│   └── 学科整体掌握度变化
├── 能力维度提升 (Skill Dimension Improvement)
│   ├── 计算能力
│   ├── 阅读理解
│   ├── 逻辑推理
│   ├── 表达写作
│   └── 记忆复述
├── 错误模式改善 (Error Pattern Improvement)
│   ├── 同类题正确率变化
│   ├── 错因类型分布变化
│   └── 重复犯错频率变化
└── 学习行为优化 (Learning Behavior Optimization)
    ├── 主动学习比例变化
    ├── 复习完成率变化
    └── 知识留存率变化
```

```
教育价值归因 (Educational Value Attribution)
├── 功能归因：哪个产品功能贡献了多少效果
├── 行为归因：哪种学习行为模式对应更好的效果
├── 内容归因：哪类学习内容带来更高的掌握度提升
└── 时间归因：学习效果随时间的衰减/累积规律
```

### 2.2 学习效果指数 (LEI - Learning Effectiveness Index)

LEI 是一个综合指标，用于量化学生在一段时间内的学习效果变化。

```
LEI = W1 × ΔKM + W2 × ΔSD + W3 × ΔEP + W4 × ΔLB

其中：
  ΔKM = 知识掌握度变化分（归一化到 0-100）
  ΔSD = 能力维度提升分（归一化到 0-100）
  ΔEP = 错误模式改善分（归一化到 0-100）
  ΔLB = 学习行为优化分（归一化到 0-100）
  
  W1, W2, W3, W4 = 权重（可按学段调整）
  默认权重：小学(0.3, 0.2, 0.2, 0.3) 初中(0.35, 0.2, 0.25, 0.2) 高中(0.4, 0.25, 0.2, 0.15)
```

### 3.2 知识掌握度变化计算 (ΔKM)

```python
class MasteryDeltaCalculator:
    """知识掌握度变化计算器"""
    
    # 最低数据要求
    MIN_QUESTIONS_FOR_CONFIDENCE = 10  # 至少10题才有统计意义
    MIN_DAYS_FOR_DELTA = 7             # 至少7天才能计算变化
    
    def calculate(
        self, 
        user_id: int, 
        knowledge_ids: list[str],
        period_start: date, 
        period_end: date
    ) -> MasteryDeltaResult:
        """
        计算指定周期内知识点掌握度的变化。
        
        方法：比较周期起始和结束时的掌握度快照。
        如果快照不存在，回退到基于答题记录的估算。
        """
        
        deltas = []
        weights = []
        
        for kp_id in knowledge_ids:
            # 1. 尝试获取前后快照
            pre = self._get_nearest_snapshot(
                user_id, kp_id, period_start, 'before'
            )
            post = self._get_nearest_snapshot(
                user_id, kp_id, period_end, 'after'
            )
            
            if pre and post:
                # 有快照：直接计算差异
                delta = post.mastery_score - pre.mastery_score
                confidence = min(pre.confidence, post.confidence)
            else:
                # 无快照：基于答题记录估算
                delta, confidence = self._estimate_from_answers(
                    user_id, kp_id, period_start, period_end
                )
            
            if confidence >= 0.3:  # 置信度过低的排除
                # 权重 = 知识点重要度 × 置信度
                kp_weight = self._get_kp_importance(kp_id) * confidence
                deltas.append(delta)
                weights.append(kp_weight)
        
        if not deltas:
            return MasteryDeltaResult(
                score=0.0, 
                confidence=0.0,
                data_quality='insufficient',
                kp_count=0
            )
        
        # 加权平均
        normalized_deltas = self._normalize_to_100(deltas)
        weighted_delta = np.average(normalized_deltas, weights=weights)
        overall_confidence = np.mean([w for w in weights]) / max(weights)
        
        return MasteryDeltaResult(
            score=round(weighted_delta, 3),
            confidence=round(overall_confidence, 4),
            data_quality=self._assess_quality(len(deltas), overall_confidence),
            kp_count=len(deltas)
        )
    
    def _estimate_from_answers(
        self, user_id, kp_id, period_start, period_end
    ) -> tuple[float, float]:
        """
        无快照时的回退方案：按时间窗口分前后两段，
        分别计算正确率作为掌握度代理指标。
        """
        mid_date = period_start + (period_end - period_start) / 2
        
        first_half = self._get_answer_stats(
            user_id, kp_id, period_start, mid_date
        )
        second_half = self._get_answer_stats(
            user_id, kp_id, mid_date + timedelta(days=1), period_end
        )
        
        if first_half.count < 3 or second_half.count < 3:
            return 0.0, 0.1  # 数据不足，极低置信度
        
        delta = second_half.correct_rate - first_half.correct_rate
        confidence = min(
            self._sample_confidence(first_half.count),
            self._sample_confidence(second_half.count)
        )
        
        return delta, confidence
    
    @staticmethod
    def _sample_confidence(n: int) -> float:
        """基于样本量的置信度衰减"""
        if n >= 30: return 0.9
        if n >= 15: return 0.7
        if n >= 5:  return 0.4
        return 0.2
```

### 3.3 能力维度提升计算 (ΔSD)

```python
# 能力维度映射表（各学科的能力维度权重不同）
SKILL_DIMENSION_WEIGHTS = {
    "math": {
        "calculation": 0.30,     # 计算能力
        "logic": 0.35,           # 逻辑推理
        "spatial": 0.20,         # 空间想象
        "application": 0.15,     # 应用建模
    },
    "chinese": {
        "reading": 0.30,         # 阅读理解
        "writing": 0.30,         # 表达写作
        "memory": 0.20,          # 记忆复述
        "analysis": 0.20,        # 分析鉴赏
    },
    "english": {
        "listening": 0.20,       # 听力理解
        "reading": 0.25,         # 阅读理解
        "writing": 0.20,         # 写作表达
        "vocabulary": 0.15,      # 词汇量
        "grammar": 0.20,         # 语法应用
    },
    "physics": {
        "calculation": 0.25,
        "logic": 0.30,
        "experiment": 0.20,      # 实验分析
        "application": 0.25,
    },
    # ... 其他学科类似
}

class SkillDimensionCalculator:
    """能力维度提升计算器"""
    
    def calculate(
        self, user_id: int, subject: str,
        period_start: date, period_end: date
    ) -> SkillDeltaResult:
        """
        基于答题记录中的题目能力标签，计算各能力维度的变化。
        
        算法：
        1. 从题目元数据获取每道题的能力维度标签和权重
        2. 按时间段分别计算各维度的加权正确率
        3. 比较前后正确率变化
        """
        dimensions = SKILL_DIMENSION_WEIGHTS.get(subject, {})
        if not dimensions:
            return SkillDeltaResult(score=0.0, confidence=0.0)
        
        mid_date = period_start + (period_end - period_start) / 2
        
        dimension_deltas = {}
        for dim_name in dimensions:
            pre_rate = self._get_dimension_accuracy(
                user_id, subject, dim_name, period_start, mid_date
            )
            post_rate = self._get_dimension_accuracy(
                user_id, subject, dim_name, mid_date + timedelta(days=1), period_end
            )
            
            if pre_rate is not None and post_rate is not None:
                dimension_deltas[dim_name] = post_rate - pre_rate
        
        if not dimension_deltas:
            return SkillDeltaResult(score=0.0, confidence=0.0, data_quality='insufficient')
        
        # 加权聚合
        weights = {dim: dimensions.get(dim, 0.25) for dim in dimension_deltas}
        total_weight = sum(weights.values())
        weighted_delta = sum(
            dimension_deltas[dim] * weights[dim] for dim in dimension_deltas
        ) / total_weight
        
        # 归一化到 0-100 分
        normalized_score = max(0, min(100, (weighted_delta + 0.5) * 100))
        
        return SkillDeltaResult(
            score=round(normalized_score, 3),
            confidence=round(len(dimension_deltas) / len(dimensions), 4),
            dimension_details=dimension_deltas,
            data_quality='high' if len(dimension_deltas) >= 3 else 'medium'
        )
    
    def _get_dimension_accuracy(
        self, user_id, subject, dimension, start, end
    ) -> float | None:
        """获取指定时间段、学科、能力维度的加权正确率"""
        results = self.db.query("""
            SELECT qr.is_correct, q.difficulty_weight
            FROM question_results qr
            JOIN questions q ON qr.question_id = q.id
            JOIN question_skill_tags qst ON q.id = qst.question_id
            WHERE qr.user_id = %s
              AND q.subject = %s
              AND qst.skill_dimension = %s
              AND qr.answered_at BETWEEN %s AND %s
              AND qr.is_practice = TRUE
        """, (user_id, subject, dimension, start, end))
        
        if len(results) < 3:
            return None
        
        total_weight = sum(r['difficulty_weight'] for r in results)
        correct_weight = sum(
            r['difficulty_weight'] for r in results if r['is_correct']
        )
        return correct_weight / total_weight if total_weight > 0 else 0.0
```

```python
class ErrorPatternCalculator:
    """错误模式改善计算器"""
    
    ERROR_CATEGORIES = [
        'concept_misunderstanding',   # 概念理解错误
        'calculation_error',          # 计算失误
        'reading_error',              # 审题错误
        'method_error',               # 方法选择错误
        'knowledge_gap',              # 知识点遗漏
        'careless_mistake',           # 粗心失误
    ]
    
    def calculate(
        self, user_id: int,
        period_start: date, period_end: date
    ) -> ErrorPatternResult:
        """
        从三个维度衡量错误模式改善：
        1. 同类题重复犯错率下降
        2. 错因分布向"低严重性"偏移
        3. 订正后的保持率（纠正后不再犯）
        """
        mid_date = period_start + (period_end - period_start) / 2
        
        # 维度1：同类题重复犯错率
        repeat_error_improvement = self._calc_repeat_error_rate(
            user_id, period_start, mid_date, period_end
        )
        
        # 维度2：错因严重性偏移
        error_severity_improvement = self._calc_error_severity_shift(
            user_id, period_start, mid_date, period_end
        )
        
        # 维度3：订正保持率
        correction_retention = self._calc_correction_retention(
            user_id, period_start, period_end
        )
        
        # 加权聚合
        score = (
            repeat_error_improvement * 0.35 +
            error_severity_improvement * 0.35 +
            correction_retention * 0.30
        )
        
        return ErrorPatternResult(
            score=round(score * 100, 3),
            confidence=0.7,  # 错题分析通常有较好的数据基础
            details={
                'repeat_error_improvement': round(repeat_error_improvement, 4),
                'severity_shift': round(error_severity_improvement, 4),
                'correction_retention': round(correction_retention, 4),
            }
        )
    
    def _calc_repeat_error_rate(
        self, user_id, start, mid, end
    ) -> float:
        """
        计算同类题重复犯错率的改善。
        返回值: 0.0 ~ 1.0, 越大表示改善越多
        """
        # 前半段：第一次做错的题中，后续同类题又做错的比例
        pre_rate = self._get_similar_question_repeat_error_rate(
            user_id, start, mid
        )
        # 后半段
        post_rate = self._get_similar_question_repeat_error_rate(
            user_id, mid + timedelta(days=1), end
        )
        
        if pre_rate is None or post_rate is None:
            return 0.5  # 无数据时给中间值
        
        # 改善 = 前半段犯错率 - 后半段犯错率（正值表示改善）
        improvement = pre_rate - post_rate
        # 归一化到 0-1
        return max(0.0, min(1.0, improvement + 0.5))
    
    def _calc_correction_retention(
        self, user_id, start, end
    ) -> float:
        """
        订正保持率：错题订正后，在后续遇到同类题时做对的比例。
        """
        # 查询所有在周期内订正过的错题
        corrected = self.db.query("""
            SELECT mr.knowledge_id, mr.corrected_at
            FROM mistake_records mr
            WHERE mr.user_id = %s
              AND mr.status = 'corrected'
              AND mr.corrected_at BETWEEN %s AND %s
        """, (user_id, start, end))
        
        if not corrected:
            return 0.5
        
        # 查询订正后对这些知识点的再次答题情况
        retained_count = 0
        total_checked = 0
        
        for record in corrected:
            subsequent = self.db.query("""
                SELECT COUNT(*) as total,
                       SUM(CASE WHEN is_correct THEN 1 ELSE 0 END) as correct
                FROM question_results
                WHERE user_id = %s
                  AND knowledge_id = %s
                  AND answered_at > %s
                  AND answered_at <= %s
            """, (user_id, record['knowledge_id'], record['corrected_at'], end))
            
            if subsequent and subsequent[0]['total'] >= 1:
                total_checked += 1
                if subsequent[0]['correct'] >= 1:
                    retained_count += 1
        
        if total_checked == 0:
            return 0.5
        
        return retained_count / total_checked
```

```python
class LearningBehaviorCalculator:
    """学习行为优化计算器"""
    
    def calculate(
        self, user_id: int,
        period_start: date, period_end: date
    ) -> BehaviorDeltaResult:
        """
        从以下维度衡量学习行为的优化：
        1. 主动学习比例变化（主动提问 vs 被动推送）
        2. 复习计划完成率变化
        3. 学习规律性（每天学习时长标准差越小越规律）
        4. 知识留存率（学过的内容隔一段时间后还能答对的比例）
        """
        mid_date = period_start + (period_end - period_start) / 2
        
        # 维度1：主动学习比例
        proactive_shift = self._calc_proactive_ratio_shift(
            user_id, period_start, mid_date, period_end
        )
        
        # 维度2：复习完成率变化
        review_improvement = self._calc_review_completion_shift(
            user_id, period_start, mid_date, period_end
        )
        
        # 维度3：学习规律性变化
        regularity_shift = self._calc_regularity_shift(
            user_id, period_start, mid_date, period_end
        )
        
        # 维度4：知识留存率
        retention_rate = self._calc_knowledge_retention(
            user_id, period_start, period_end
        )
        
        score = (
            proactive_shift * 0.25 +
            review_improvement * 0.25 +
            regularity_shift * 0.20 +
            retention_rate * 0.30
        ) * 100
        
        return BehaviorDeltaResult(
            score=round(score, 3),
            confidence=0.65,
            details={
                'proactive_shift': proactive_shift,
                'review_completion': review_improvement,
                'regularity': regularity_shift,
                'retention_rate': retention_rate,
            }
        )
    
    def _calc_regularity_shift(
        self, user_id, start, mid, end
    ) -> float:
        """
        学习规律性：每日学习时长的变异系数(CV)变化。
        CV 越低越规律，CV 下降表示行为优化。
        """
        pre_cv = self._get_daily_study_cv(user_id, start, mid)
        post_cv = self._get_daily_study_cv(user_id, mid + timedelta(days=1), end)
        
        if pre_cv is None or post_cv is None:
            return 0.5
        
        # CV 下降 = 规律性提升
        # 返回 0-1，0.5 表示无变化
        improvement = (pre_cv - post_cv) / (pre_cv + 0.001)
        return max(0.0, min(1.0, 0.5 + improvement))
    
    def _calc_knowledge_retention(
        self, user_id, start, end
    ) -> float:
        """
        知识留存率：
        在前半段学过的知识点中，后半段随机抽查时还能答对的比例。
        """
        mid_date = start + (end - start) / 2
        
        # 前半段"学会"的知识点（正确率 >= 0.7）
        learned_kps = self.db.query("""
            SELECT knowledge_id, AVG(is_correct) as accuracy
            FROM question_results
            WHERE user_id = %s AND answered_at BETWEEN %s AND %s
            GROUP BY knowledge_id
            HAVING AVG(is_correct) >= 0.7 AND COUNT(*) >= 3
        """, (user_id, start, mid_date))
        
        if not learned_kps:
            return 0.5
        
        # 检查后半段这些知识点的正确率
        retained = 0
        for kp in learned_kps:
            post_accuracy = self.db.query("""
                SELECT AVG(is_correct) as accuracy
                FROM question_results
                WHERE user_id = %s 
                  AND knowledge_id = %s 
                  AND answered_at BETWEEN %s AND %s
            """, (user_id, kp['knowledge_id'], mid_date + timedelta(days=1), end))
            
            if post_accuracy and post_accuracy[0]['accuracy'] >= 0.6:
                retained += 1
        
        return retained / len(learned_kps) if learned_kps else 0.5
```

class LEICalculator:
    """学习效果指数(LEI)聚合计算器"""

        period_end: date,

        计算指定周期的综合学习效果指数。
        """

            km_result.score * weights["km"] +
            sd_result.score * weights["sd"] +
            ep_result.score * weights["ep"] +
            lb_result.score * weights["lb"]
        )

            km_result.confidence * weights["km"],
            sd_result.confidence * weights["sd"],
            ep_result.confidence * weights["ep"],
            lb_result.confidence * weights["lb"],

            active_days, min_days, confidence,

        )
        
        return LearningEffectiveness(
            user_id=user_id,
            period_type=period_type,
            period_start=period_start,
            period_end=period_end,

            delta_sd=sd_result.score,

### 4.2 功能归因（基于 Shapley Value 的简化实现）

```python
class FeatureAttributionEngine:
    """
    功能归因引擎
    
    核心思想：将每个功能视为"玩家"，学习效果视为"收益"，
    用 Shapley Value 思想计算每个功能的边际贡献。
    
    简化实现：由于完整的 Shapley Value 计算是 NP-hard 的，
    采用基于多元线性回归的近似方法。
    """
    
    # 所有可归因的产品功能
    TRACKABLE_FEATURES = [
        "ai_tutor",           # AI 智能辅导（文字问答）
        "photo_search",       # 拍照搜题
        "sync_class",         # 同步课堂学习
        "mistake_review",     # 错题复习
        "practice_quiz",      # 习题练习
        "study_plan",         # 学习计划执行
        "essay_coach",        # 作文辅导
        "memorization",       # 背诵练习
        "knowledge_map",      # 知识图谱浏览
        "exam_simulation",    # 考试模拟
        "concept_explain",    # 概念讲解（AI 主动推送）
        "similar_questions",  # 同类题练习
    ]
    
    def analyze_feature_attribution(
        self,
        user_ids: list[int],
        period_type: str,
        period_start: date,
        period_end: date,
        min_users: int = 50  # 最低样本量
    ) -> list[AttributionResult]:
        """
        对一组用户进行功能归因分析。
        
        算法步骤：
        1. 收集所有用户的功能使用特征矩阵
        2. 收集所有用户的 LEI 作为目标变量
        3. 标准化特征
        4. 使用 Lasso 回归（自动特征选择）拟合
        5. 将回归系数转化为贡献度百分比
        """
        
        # 1. 构建特征矩阵
        X, y, valid_users = self._build_feature_matrix(
            user_ids, period_type, period_start, period_end
        )
        
        if len(valid_users) < min_users:
            return self._low_confidence_result(valid_users)
        
        # 2. 标准化
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        # 3. Lasso 回归（L1 正则化自动选择重要特征）
        lasso = Lasso(alpha=0.01, max_iter=5000)
        lasso.fit(X_scaled, y)
        
        # 4. 将系数转化为贡献度
        coefs = np.abs(lasso.coef_)
        total = np.sum(coefs)
        if total == 0:
            return self._no_effect_result()
        
        contributions = coefs / total
        
        # 5. 效果方向（正/负系数）
        directions = ['positive' if c > 0 else 'negative' 
                      for c in lasso.coef_]
        
        # 6. 计算统计显著性（自助法）
        p_values = self._bootstrap_significance(
            X_scaled, y, lasso, n_bootstrap=1000
        )
        
        results = []
        for i, feature_key in enumerate(self.TRACKABLE_FEATURES):
            if contributions[i] >= 0.01:  # 只报告贡献度 >= 1% 的
                results.append(AttributionResult(
                    attribution_type='feature',
                    factor_key=feature_key,
                    factor_name=self._get_feature_name(feature_key),
                    contribution=round(float(contributions[i]), 4),
                    effect_direction=directions[i],
                    effect_magnitude=round(float(np.abs(lasso.coef_[i])), 3),
                    sample_size=len(valid_users),
                    p_value=round(float(p_values[i]), 6),
                    model_version='lasso_v1',
                    confidence=round(1.0 - p_values[i], 4),
                ))
        
        # 按贡献度排序
        results.sort(key=lambda r: r.contribution, reverse=True)
        return results
    
    def _build_feature_matrix(
        self, user_ids, period_type, period_start, period_end
    ) -> tuple[np.ndarray, np.ndarray, list[int]]:
        """
        构建特征矩阵。
        
        每行 = 一个用户
        每列 = 一个功能的使用强度指标
        
        使用强度 = 标准化使用次数 × 标准化使用天数 × 标准化使用时长
        """
        valid_users = []
        feature_rows = []
        targets = []
        
        for uid in user_ids:
            # 获取功能使用数据
            features = []
            for fk in self.TRACKABLE_FEATURES:
                usage = self._get_feature_usage(
                    uid, fk, period_start, period_end
                )
                # 综合使用强度指标
                intensity = (
                    np.log1p(usage.count) * 0.3 +
                    np.log1p(usage.days) * 0.4 +
                    np.log1p(usage.duration_min) * 0.3
                )
                features.append(intensity)
            
            # 获取目标变量（LEI）
            lei = self._get_user_lei(uid, period_type, period_start)
            if lei is not None and lei.data_quality != 'insufficient':
                valid_users.append(uid)
                feature_rows.append(features)
                targets.append(lei.lei_score)
        
        return (
            np.array(feature_rows),
            np.array(targets),
            valid_users
        )
    
    def _bootstrap_significance(
        self, X, y, model, n_bootstrap=1000
    ) -> np.ndarray:
        """
        自助法估计每个特征系数的 p 值。
        """
        n_features = X.shape[1]
        bootstrap_coefs = np.zeros((n_bootstrap, n_features))
        
        for i in range(n_bootstrap):
            indices = np.random.choice(len(X), size=len(X), replace=True)
            X_boot = X[indices]
            y_boot = y[indices]
            
            boot_model = Lasso(alpha=0.01, max_iter=5000)
            boot_model.fit(X_boot, y_boot)
            bootstrap_coefs[i] = boot_model.coef_
        
        # p 值 = 系数为0或反方向的比例
        original_signs = np.sign(model.coef_)
        p_values = np.zeros(n_features)
        for j in range(n_features):
            opposite = np.sum(
                np.sign(bootstrap_coefs[:, j]) != original_signs[j]
            )
            p_values[j] = opposite / n_bootstrap
        
        return p_values
```

### 4.3 行为模式归因

```python
class BehaviorAttributionEngine:
    """
    行为模式归因引擎
    
    识别高效学习行为模式和低效学习行为模式，
    并量化不同行为模式对学习效果的影响。
    """
    
    def analyze(
        self,
        user_ids: list[int],
        period_type: str,
        period_start: date,
        period_end: date
    ) -> BehaviorAttributionResult:
        """
        算法：
        1. 提取每个用户的行为特征向量
        2. K-Means 聚类识别行为模式
        3. 计算每个聚类的平均 LEI
        4. 识别"高效行为特征"和"低效行为特征"
        """
        
        # 1. 提取行为特征
        behavior_features = self._extract_behavior_features(
            user_ids, period_start, period_end
        )
        
        # 2. 聚类（K=4，分为4种行为模式）
        from sklearn.cluster import KMeans
        scaler = StandardScaler()
        X = scaler.fit_transform(
            np.array([bf.features for bf in behavior_features])
        )
        
        kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
        clusters = kmeans.fit_predict(X)
        
        # 3. 计算每个聚类的效果
        cluster_effects = {}
        for cluster_id in range(4):
            member_indices = np.where(clusters == cluster_id)[0]
            member_leis = [
                self._get_user_lei(
                    behavior_features[i].user_id, 
                    period_type, period_start
                )
                for i in member_indices
            ]
            member_leis = [lei.lei_score for lei in member_leis 
                          if lei is not None]
            
            if member_leis:
                cluster_effects[cluster_id] = {
                    'size': len(member_indices),
                    'avg_lei': np.mean(member_leis),
                    'median_lei': np.median(member_leis),
                    'center': scaler.inverse_transform(
                        kmeans.cluster_centers_[cluster_id].reshape(1, -1)
                    )[0],
                }
        
        # 4. 识别高效 vs 低效模式
        sorted_clusters = sorted(
            cluster_effects.items(), 
            key=lambda x: x[1]['avg_lei'], 
            reverse=True
        )
        
        high_efficiency = sorted_clusters[0]
        low_efficiency = sorted_clusters[-1]
        
        # 5. 提取区分性特征
        feature_names = self._get_feature_names()
        discriminative = self._find_discriminative_features(
            high_efficiency[1]['center'],
            low_efficiency[1]['center'],
            feature_names
        )
        
        return BehaviorAttributionResult(
            cluster_count=4,
            high_efficiency_cluster={
                'cluster_id': high_efficiency[0],
                'avg_lei': round(high_efficiency[1]['avg_lei'], 3),
                'size': high_efficiency[1]['size'],
                'key_behaviors': discriminative['positive'],
            },
            low_efficiency_cluster={
                'cluster_id': low_efficiency[0],
                'avg_lei': round(low_efficiency[1]['avg_lei'], 3),
                'size': low_efficiency[1]['size'],
                'key_behaviors': discriminative['negative'],
            },
            sample_size=len(behavior_features),
        )
    
    def _extract_behavior_features(
        self, user_ids, period_start, period_end
    ) -> list[BehaviorFeatures]:
        """
        提取行为特征向量。
        
        特征包括：
        - daily_avg_study_minutes: 日均学习时长
        - active_day_ratio: 活跃天占比
        - proactive_ratio: 主动学习占比（vs 被动推送）
        - review_completion_rate: 错题复习完成率
        - session_length_avg: 平均单次学习时长
        - session_count_daily: 日均学习次数
        - subject_diversity: 涉及学科数
        - feature_diversity: 使用的功能种类数
        - peak_hour: 高峰学习时段
        - weekend_ratio: 周末学习占比
        - streak_max: 最长连续学习天数
        - mastery_first_attempt_rate: 首次答对率
        """
        features_list = []
        for uid in user_ids:
            features = self._get_user_behavior_features(
                uid, period_start, period_end
            )
            if features is not None:
                features_list.append(features)
        return features_list
```

    内容归因引擎
    
    分析哪类学习内容对哪类学生的学习效果最好。

        算法：
        1. 对学习内容按特征分类（难度、类型、时长、交互方式）
        2. 按用户学习阶段（学段+掌握度水平）分组
        3. 计算每组用户在不同内容类型上的掌握度变化
        4. 构建内容-效果矩阵
        """
        
        # 内容特征维度
        content_features = {
            "difficulty": ["basic", "intermediate", "advanced", "challenge"],
            "type": ["explanation", "example", "exercise", "quiz", "simulation"],
            "modality": ["text", "image", "audio", "video", "interactive"],
            "ai_involvement": ["ai_generated", "human_curated", "hybrid"],
        }
        
        results = {}
        
        # 按用户掌握度水平分组
        user_groups = self._group_users_by_mastery(user_ids, subject)
        
        for group_name, group_users in user_groups.items():
            group_result = {}
            
            for feature_name, categories in content_features.items():
                category_effects = {}
                
                for category in categories:
                    # 获取该组用户使用该类型内容前后的掌握度变化
                    deltas = self._get_content_category_mastery_delta(
                        group_users, subject, feature_name, category,
                        period_start, period_end
                    )
                    
                    if deltas:
                        category_effects[category] = {
                            'avg_delta': round(np.mean(deltas), 4),
                            'median_delta': round(np.median(deltas), 4),
                            'sample_size': len(deltas),
                            'std': round(np.std(deltas), 4),
                        }
                
                group_result[feature_name] = category_effects
            
            results[group_name] = group_result
        
        return ContentAttributionResult(
            subject=subject,
            period_start=period_start,
            period_end=period_end,
            user_group_count=len(user_groups),

```python
class MonthlyEffectivenessTask:
    """月度学习效果计算任务"""
    
    def run(self, year: int, month: int):
        period_start = date(year, month, 1)
        period_end = date(year, month, calendar.monthrange(year, month)[1])
        
        logger.info(f"开始计算 {period_start} ~ {period_end} 的月度学习效果")
        
        # Step 1: 确定活跃用户列表
        active_users = self._get_active_users(period_start, period_end)
        logger.info(f"活跃用户数: {len(active_users)}")
        
        # Step 2: 分批计算（每批500人）
        batch_size = 500
        results = []
        errors = []
        
        for i in range(0, len(active_users), batch_size):
            batch = active_users[i:i+batch_size]
            try:
                batch_results = self._calculate_batch(
                    batch, 'monthly', period_start, period_end
                )
                results.extend(batch_results)
            except Exception as e:
                logger.error(f"批次 {i//batch_size} 计算失败: {e}")
                errors.append({'batch': i//batch_size, 'error': str(e)})
        
        # Step 3: 批量写入
        self._batch_upsert(results)
        logger.info(f"成功写入 {len(results)} 条效果记录")
        
        # Step 4: 计算前后测对比（如果有配对测评）
        pre_post_pairs = self._find_pre_post_pairs(period_start, period_end)
        if pre_post_pairs:
            self._calculate_pre_post_deltas(pre_post_pairs)
        
        # Step 5: 更新功能-效果关联表
        self._update_feature_effect_mapping(active_users, period_start, period_end)
        
        # Step 6: 发送通知事件
        self._publish_completion_event(period_start, period_end, len(results))
        
        if errors:
            logger.warning(f"月度效果计算完成，{len(errors)} 个批次失败")
    
    def _calculate_batch(
        self, user_ids, period_type, period_start, period_end
    ) -> list[LearningEffectiveness]:
        """批量计算用户效果"""
        results = []
        calculator = LEICalculator()
        
        for uid in user_ids:
            try:
                stage = self._get_user_stage(uid)
                result = calculator.calculate(
                    uid, period_type, period_start, period_end, stage
                )
                results.append(result)
            except Exception as e:
                logger.debug(f"用户 {uid} 效果计算失败: {e}")
                continue
        
        return results

class MonthlyAttributionTask:
    """月度归因分析任务"""
    
    def run(self, year: int, month: int):
        period_start = date(year, month, 1)
        period_end = date(year, month, calendar.monthrange(year, month)[1])
        
        logger.info(f"开始归因分析 {period_start} ~ {period_end}")
        
        # Step 1: 获取有足够数据的用户
        qualified_users = self._get_qualified_users(period_start, period_end)
        
        if len(qualified_users) < 100:
            logger.warning("有效样本不足100，跳过归因分析")
            return
        
        # Step 2: 按学段分组执行
        for stage in ['primary', 'junior', 'senior']:
            stage_users = [
                uid for uid in qualified_users 
                if self._get_user_stage(uid) == stage
            ]
            
            if len(stage_users) < 50:
                continue
            
            # 功能归因
            feature_results = self.feature_engine.analyze_feature_attribution(
                stage_users, 'monthly', period_start, period_end
            )
            self._save_attribution_results(
                feature_results, 'monthly', period_start, period_end
            )
            
            # 行为归因
            behavior_result = self.behavior_engine.analyze(
                stage_users, 'monthly', period_start, period_end
            )
            self._save_behavior_result(
                behavior_result, 'monthly', period_start, period_end
            )
        
        # Step 3: 按学科执行内容归因
        for subject in ['math', 'chinese', 'english', 'physics', 'chemistry']:
            subject_users = [
                uid for uid in qualified_users
                if self._has_subject_activity(uid, subject, period_start, period_end)
            ]
            
            if len(subject_users) < 50:
                continue
            
            content_result = self.content_engine.analyze(
                subject_users, subject, period_start, period_end
            )
            self._save_content_result(
                content_result, 'monthly', period_start, period_end
            )
        
        logger.info("归因分析完成")
```

## 9. 错误处理与降级策略

### 9.1 错误码定义

| 错误码 | 场景 | 处理策略 |
| --- | --- | --- |
| `EFF_001` | 用户数据不足，无法计算效果 | 返回 `insufficient_data` 状态 |
| `EFF_002` | 快照生成失败 | 回退到实时计算模式 |
| `EFF_003` | 归因分析样本不足 | 跳过归因，仅返回效果指标 |
| `EFF_004` | 回归模型拟合失败 | 使用上期归因结果或返回默认权重 |
| `EFF_005` | 批量计算部分失败 | 记录失败用户，不影响其他用户 |
| `EFF_006` | 前后测配对失败 | 标记为未配对，使用掌握度快照替代 |
| `EFF_007` | 群体效果聚合超时 | 缩小时间范围或降低精度 |

## 11. 数据安全与隐私

### 11.1 隐私保护措施

1. **聚合匿名化**：归因分析以群体为粒度，不暴露单用户归因结果给第三方
2. **最小化展示**：家长端只展示效果结论和建议，不展示原始分值细节
3. **百分位而非排名**：使用百分位数（"超过了72%的同龄学生"）而非绝对排名
4. **B端数据脱敏**：学校报告中的学生数据使用匿名ID，仅展示群体统计
5. **分析数据留存**：原始分析数据保留2年，聚合数据永久保留
6. **分析数据隔离**：效果分析数据与用户身份信息分库存储

## 12. 容量估算

### 12.1 数据量预估

| 表 | 行数估算（100万用户） | 单行大小 | 存储空间 |
| --- | --- | --- | --- |
| mastery_snapshots | 100万 × 50知识点 × 365天/10（日快照折算） ≈ 18亿/年 | ~80B | ~140GB/年 |
| learning_effectiveness | 100万 × 12月 = 1200万/年 | ~200B | ~2.4GB/年 |
| attribution_records | 12月 × 7因子 × N学段 ≈ 500/年（聚合级） | ~300B | ~150KB/年 |
| feature_effect_mapping | 100万 × 12月 × 12功能 = 1.44亿/年 | ~120B | ~17GB/年 |
| pre_post_assessments | 100万 × 2学期 × 2(prem+post) = 400万/年 | ~500B | ~2GB/年 |
| group_effectiveness | ~10万班级 × 12月 = 120万/年 | ~300B | ~360MB/年 |

### 12.2 优化策略

1. **mastery_snapshots**: 仅保留 daily 最近30天，weekly 最近1年，monthly 永久
2. **feature_effect_mapping**: 仅保留最近12个月，更早的归档到冷存储
3. **learning_effectiveness**: 热数据保留2年，通过定时任务归档
4. **归因计算**: 按月聚合，不存储用户级别归因（节省空间）

## 14. 风险与应对

| 风险 | 影响 | 应对策略 |
| --- | --- | --- |
| 数据稀疏导致 LEI 不准 | 用户看到波动较大的效果指数 | 设置数据质量门槛，不足时展示提示而非数值 |
| 归因分析结果不稳定 | 每月的功能贡献度排名变化大 | 使用滑动窗口（3个月数据），平滑月度波动 |
