# 服务端 - 数据血缘追踪与元数据治理平台 详细设计

## 1. 概述

### 1.1 文档目的

本文档为 PrimeTop 平台的**数据血缘追踪与元数据治理平台**提供可直接用于编码的详细设计。该平台是所有数据密集型子系统（学习数据仓库、BI 分析平台、学情分析引擎、合规审计系统等）的基础治理设施，负责回答"数据从哪里来、经过哪些转换、流向哪里、谁在使用、质量如何"等核心问题。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 数据血缘可视化 | 支持表级和字段级血缘关系的自动采集与可视化展示 |
| 统一元数据管理 | 集中管理数据库表、字段、指标、API、报表等元数据 |
| 数据目录与发现 | 提供数据资产目录，支持搜索、标签、分类浏览 |
| 数据质量监控 | 定义数据质量规则，自动执行检测并产出报告 |
| 影响分析 | Schema 变更或下线前，分析下游影响范围 |
| 数据合规审计 | 追踪敏感数据的流转路径，满足未成年人数据保护合规要求 |

### 1.3 设计原则

1. **非侵入采集**：通过解析 SQL、解析日志、扫描代码等方式自动采集血缘，不侵入业务代码。
2. **最终一致**：血缘和元数据允许短暂延迟，通过异步采集 + 定时全量校准保证最终一致。
3. **可扩展采集器**：新增数据源类型时只需实现采集器接口，无需修改核心引擎。
4. **安全优先**：元数据不含实际业务数据值，仅描述结构和流转关系。

#### 3.1.4 血缘关系 (DataLineage)

血缘采用图数据库 (Neo4j) 存储，同时在关系库中保存扁平化索引以支持快速查询。

**Neo4j 节点定义：**

```cypher
// 资产节点
(:Asset {
    asset_id: 1001,
    asset_code: "mysql://prod/primetop/answer_record",
    name: "answer_record",
    type: "TABLE"
})

// 字段节点
(:Column {
    column_id: 50001,
    asset_id: 1001,
    column_name: "user_id",
    column_type: "BIGINT"
})
```

**Neo4j 关系定义：**

```cypher
// 表级血缘: 上游表 -> 下游表
(:Asset)-[:FLOWS_TO {
    lineage_type: "ETL",           // ETL | SYNC | VIEW | API_CALL | STREAM
    task_name: "dw_etl_answer_record_daily",
    transform_logic: "SELECT user_id, question_id, ... FROM answer_record WHERE ...",
    confidence: 0.95,              // 血缘采集置信度
    detected_at: "2026-06-20T10:00:00Z"
}]->(:Asset)

// 字段级血缘: 上游字段 -> 下游字段
(:Column)-[:DERIVED_FROM {
    task_name: "dw_etl_answer_record_daily",
    transform_type: "DIRECT",     // DIRECT | AGGREGATE | JOIN_KEY | COMPUTED
    expression: "user_id",        // 转换表达式
    confidence: 0.98
}]->(:Column)
```

### 4.2 采集器接口定义

```java
/**
 * 数据血缘采集器接口
 * 每种数据源/ETL工具实现此接口
 */
public interface LineageCollector {

    /**
     * 采集器类型标识
     */
    String collectorType();

    /**
     * 从指定数据源采集表级元数据和血缘关系
     *
     * @param datasource 数据源配置
     * @return 采集到的血缘三元组列表
     */
    List<LineageTriple> collectTableLineage(DataSource datasource);

    /**
     * 从指定数据源采集字段级血缘
     */
    List<LineageTriple> collectColumnLineage(DataSource datasource);

    /**
     * 采集元数据（表结构、字段信息）
     */
    MetadataSnapshot collectMetadata(DataSource datasource);

    /**
     * 是否支持自动采集
     */
    default boolean supportsAutoCollection() {
        return true;
    }
}

/**
 * 血缘三元组: source → transform → target
 */
public class LineageTriple {
    private String sourceAssetCode;      // 上游资产编码
    private String targetAssetCode;      // 下游资产编码
    private String sourceColumn;         // 上游字段名(可空)
    private String targetColumn;         // 下游字段名(可空)
    private LineageType lineageType;     // ETL / VIEW / STREAM ...
    private String taskName;             // 产生血缘的任务
    private String transformExpression;  // 转换表达式
    private double confidence;           // 置信度 0~1
    private Instant detectedAt;
}
```

### 4.3 SQL 解析血缘采集器（核心采集器）

通过解析 ETL 脚本和定时任务中的 SQL 语句，自动提取 `INSERT INTO ... SELECT ...` 和 `CREATE VIEW AS SELECT ...` 中的血缘关系。

```java
/**
 * 基于 SQL 静态解析的血缘采集器
 * 使用 Apache Calcite 或 Druid SQL Parser 解析 SQL AST
 */
@Component
public class SqlLineageCollector implements LineageCollector {

    private final SqlLineageParser parser = new SqlLineageParser();

    @Override
    public String collectorType() {
        return "SQL_PARSER";
    }

    /**
     * 解析单条 SQL 语句，提取血缘
     */
    public List<LineageTriple> parseSql(String sql, String defaultDatabase) {
        List<LineageTriple> triples = new ArrayList<>();

        try {
            SQLStatement stmt = SQLUtils.parseSingleMysqlStatement(sql);

            if (stmt instanceof SQLInsertStatement insert) {
                // INSERT INTO target SELECT ... FROM source1 JOIN source2 ...
                String targetTable = extractTableName(insert.getTableName(), defaultDatabase);

                SQLSelect selectQuery = insert.getQuery();
                if (selectQuery != null) {
                    // 提取 SELECT 中的所有源表
                    Set<TableReference> sourceTables = extractSourceTables(selectQuery);
                    // 提取字段映射
                    Map<String, String> columnMapping = extractColumnMapping(selectQuery, insert.getColumns());

                    for (TableReference source : sourceTables) {
                        String sourceTable = source.getQualifiedName();

                        // 表级血缘
                        triples.add(buildTableTriple(sourceTable, targetTable, sql));

                        // 字段级血缘
                        columnMapping.forEach((targetCol, sourceCol) -> {
                            triples.add(buildColumnTriple(
                                sourceTable, sourceCol,
                                targetTable, targetCol,
                                sql
                            ));
                        });
                    }
                }
            } else if (stmt instanceof SQLCreateViewStatement view) {
                String targetView = extractTableName(view.getName(), defaultDatabase);
                Set<TableReference> sourceTables = extractSourceTables(view.getSubQuery());

                for (TableReference source : sourceTables) {
                    triples.add(buildTableTriple(
                        source.getQualifiedName(), targetView, sql
                    ));
                }
            }
        } catch (ParserException e) {
            log.warn("SQL解析失败，跳过血缘采集: {}", e.getMessage());
        }

        return triples;
    }

    @Override
    public List<LineageTriple> collectTableLineage(DataSource datasource) {
        // 从定时任务配置库中拉取该数据源关联的所有 ETL SQL
        List<String> sqlList = etlTaskRepository.findSqlByDatasource(datasource.getId());
        List<LineageTriple> all = new ArrayList<>();

        for (String sql : sqlList) {
            all.addAll(parseSql(sql, datasource.getDatabaseName()));
        }

        // 去重
        return deduplicate(all);
    }

    @Override
    public MetadataSnapshot collectMetadata(DataSource datasource) {
        // 通过 JDBC 读取 information_schema
        MetadataSnapshot snapshot = new MetadataSnapshot();
        snapshot.setDatasourceId(datasource.getId());
        snapshot.setScanTime(Instant.now());

        String sql = """
            SELECT TABLE_NAME, COLUMN_NAME, DATA_TYPE, IS_NULLABLE,
                   COLUMN_DEFAULT, COLUMN_KEY, COLUMN_COMMENT, ORDINAL_POSITION
            FROM INFORMATION_SCHEMA.COLUMNS
            WHERE TABLE_SCHEMA = ?
            ORDER BY TABLE_NAME, ORDINAL_POSITION
            """;

        try (Connection conn = getConnection(datasource);
             PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setString(1, datasource.getDatabaseName());

            Map<String, List<ColumnInfo>> tableColumns = new HashMap<>();
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) {
                    String tableName = rs.getString("TABLE_NAME");
                    ColumnInfo col = new ColumnInfo();
```

```java
/**
 * 血缘写入处理器
 * 同时写入 Neo4j (图查询) 和 MySQL (快速检索)
 */
@Service
public class LineagePersistenceProcessor {

    private final Neo4jClient neo4jClient;
    private final LineageEdgeRepository edgeRepository;
    private final DataAssetRepository assetRepository;

    /**
     * 批量持久化血缘三元组
     */
    @Transactional
    public BatchPersistResult persist(List<LineageTriple> triples) {
        BatchPersistResult result = new BatchPersistResult();

        // Step 1: 解析资产编码，确保资产节点存在
        Set<String> assetCodes = new HashSet<>();
        triples.forEach(t -> {
            assetCodes.add(t.getSourceAssetCode());
            assetCodes.add(t.getTargetAssetCode());
        });

        Map<String, Long> assetIdMap = ensureAssetsExist(assetCodes);

        // Step 2: 写入 MySQL 扁平化索引
        List<LineageEdge> edges = triples.stream()
            .map(t -> buildEdge(t, assetIdMap))
            .toList();

        // UPSERT: 已存在的血缘更新 confidence/detected_at，新的插入
        for (LineageEdge edge : edges) {
            edgeRepository.upsert(edge);
        }
        result.setMysqlRowsAffected(edges.size());

        // Step 3: 写入 Neo4j 图数据库
        String cypher = """
            UNWIND $triples AS triple
            MERGE (src:Asset {asset_id: triple.sourceId})
            MERGE (tgt:Asset {asset_id: triple.targetId})
            MERGE (src)-[r:FLOWS_TO {
                task_name: triple.taskName,
                source_column_id: triple.sourceColumnId,
                target_column_id: triple.targetColumnId
            }]->(tgt)
            SET r.lineage_type = triple.lineageType,
                r.transform_type = triple.transformType,
                r.expression = triple.expression,
                r.confidence = triple.confidence,
                r.detected_at = triple.detectedAt
            """;

        List<Map<String, Object>> cypherParams = triples.stream()
            .map(t -> toCypherParam(t, assetIdMap))
            .toList();

        neo4jClient.query(cypher).bindAll(cypherParams).run();
        result.setNeo4jRelationshipsAffected(cypherParams.size());

        return result;
    }

    /**
     * 确保资产节点存在（不存在则自动创建）
     */
    private Map<String, Long> ensureAssetsExist(Set<String> assetCodes) {
        List<DataAsset> existing = assetRepository.findByAssetCodeIn(assetCodes);
        Map<String, Long> map = existing.stream()
            .collect(Collectors.toMap(DataAsset::getAssetCode, DataAsset::getId));

        // 创建缺失的资产占位记录
        List<DataAsset> toCreate = assetCodes.stream()
            .filter(code -> !map.containsKey(code))
            .map(code -> {
                DataAsset asset = new DataAsset();
                asset.setAssetCode(code);
                asset.setAssetType(inferAssetType(code));
                asset.setName(extractName(code));
                asset.setStatus("PENDING_ENRICH"); // 待补充元数据
                return asset;
            })
            .toList();

        if (!toCreate.isEmpty()) {
            List<DataAsset> created = assetRepository.saveAll(toCreate);
            created.forEach(a -> map.put(a.getAssetCode(), a.getId()));
        }

        return map;
    }
}
```

```java
/**

@Service
public class LineageQueryService {

    private final Neo4jClient neo4jClient;
    private final LineageEdgeRepository edgeRepository;

    /**
     * 获取上游血缘链路（递归）
     * @param assetId 目标资产ID
     * @param depth   最大递归深度（推荐 ≤ 10）
     */
    public LineageGraph getUpstream(Long assetId, int depth) {
        String cypher = """
            MATCH path = (target:Asset {asset_id: $assetId})<-[:FLOWS_TO*1..%depth]-(upstream:Asset)
            RETURN nodes(path) AS nodes, relationships(path) AS rels
            """.replace("%depth", String.valueOf(Math.min(depth, 10)));

        List<LineageNode> nodes = new ArrayList<>();
        List<LineageLink> links = new ArrayList<>();
        Set<Long> seenNodes = new HashSet<>();
        Set<String> seenEdges = new HashSet<>();

        neo4jClient.query(cypher, Map.of("assetId", assetId))
            .fetchAs(Map.class)
            .all().forEach(row -> {
                // 解析图查询结果为前端可用的节点-边结构
                parsePath(row, nodes, links, seenNodes, seenEdges);
            });

        return new LineageGraph(nodes, links, "upstream");
    }

    /**
     * 获取下游血缘链路（递归）
     */
    public LineageGraph getDownstream(Long assetId, int depth) {
        String cypher = """
            MATCH path = (source:Asset {asset_id: $assetId})-[:FLOWS_TO*1..%depth]->(downstream:Asset)
            RETURN nodes(path) AS nodes, relationships(path) AS rels
            """.replace("%depth", String.valueOf(Math.min(depth, 10)));

        // ... 同上解析逻辑
        return new LineageGraph(nodes, links, "downstream");
    }

    /**
     * 全血缘图（上下游合并）
     */
    public LineageGraph getFullLineage(Long assetId, int depth) {
        LineageGraph upstream = getUpstream(assetId, depth);
        LineageGraph downstream = getDownstream(assetId, depth);
        return LineageGraph.merge(upstream, downstream);
    }

/**
```
```java
 * Schema 变更影响分析
 * 当某张表要修改字段或下线时，分析所有下游影响
 */
@Service
public class ImpactAnalysisService {

    private final LineageQueryService lineageQueryService;
    private final DataAssetRepository assetRepository;
    private final MetricAssetRepository metricRepository;

    /**
     * 分析删除/修改字段的影响范围
     *
     * @param assetId   变更的资产ID
     * @param columnName 变更字段名
     * @param changeType 变更类型
     */
    public ImpactAnalysisResult analyzeFieldChange(
            Long assetId, String columnName, SchemaChangeType changeType) {

        // 获取下游血缘
        LineageGraph downstream = lineageQueryService.getDownstream(assetId, 5);

        // 获取字段级下游血缘
        ColumnLineageGraph colLineage = lineageQueryService
            .getColumnLineage(assetId, columnName, 5);

        ImpactAnalysisResult result = new ImpactAnalysisResult();
        result.setChangeType(changeType);
        result.setSourceAsset(assetRepository.findById(assetId).orElseThrow());
        result.setSourceColumn(columnName);

        // 分类影响
        Set<Long> affectedAssetIds = colLineage.getAllAssetIds();
        Set<String> affectedColumns = colLineage.getAllColumnNames();

        // 影响的下游资产
        result.setAffectedAssets(
            assetRepository.findByIdIn(affectedAssetIds).stream()
                .map(this::toAssetBrief)
                .toList()
        );

        // 影响的指标
        List<MetricAsset> affectedMetrics = metricRepository
            .findBySourceAssetIdsContaining(assetId);
        result.setAffectedMetrics(affectedMetrics.stream()
            .map(this::toMetricBrief)
            .toList());

        // 影响等级评估
        result.setSeverityLevel(assessSeverity(
            affectedAssetIds.size(),
            affectedMetrics.size(),
            changeType
        ));

        // 生成建议
        result.setRecommendations(generateRecommendations(result));

        return result;
    }

    /**
     * 影响等级评估
     */
    private SeverityLevel assessSeverity(int affectedAssetCount,
                                          int affectedMetricCount,
                                          SchemaChangeType changeType) {
        int score = affectedAssetCount * 2 + affectedMetricCount * 5;

        if (changeType == SchemaChangeType.DROP_TABLE) {
            score += 50; // 删表影响极大
        } else if (changeType == SchemaChangeType.DROP_COLUMN) {
            score += 20;
        } else if (changeType == SchemaChangeType.MODIFY_TYPE) {
            score += 10;
        }

        if (score >= 50) return SeverityLevel.CRITICAL;
        if (score >= 20) return SeverityLevel.HIGH;
        if (score >= 5)  return SeverityLevel.MEDIUM;
        return SeverityLevel.LOW;
    }

    private List<String> generateRecommendations(ImpactAnalysisResult result) {
        List<String> recs = new ArrayList<>();

        if (result.getSeverityLevel() == SeverityLevel.CRITICAL) {
            recs.add("⚠️ 影响等级为 CRITICAL，建议先在测试环境验证全部下游链路");
            recs.add("⚠️ 需通知所有下游资产负责人确认：" +
                result.getAffectedAssets().stream()
                    .map(ImpactAnalysisResult.AssetBrief::getOwnerTeam)
                    .distinct()
                    .reduce((a, b) -> a + ", " + b)
                    .orElse("N/A"));
        }

        if (!result.getAffectedMetrics().isEmpty()) {
            recs.add("📊 受影响的指标：" +
                result.getAffectedMetrics().stream()
                    .map(ImpactAnalysisResult.MetricBrief::getMetricName)
                    .reduce((a, b) -> a + ", " + b)
                    .orElse("N/A"));
            recs.add("📊 建议在变更窗口前确认指标计算逻辑兼容性");
        }

        if (result.getChangeType() == SchemaChangeType.DROP_COLUMN) {
            recs.add("🔧 建议采用渐进式废弃：先标记 deprecated → 确认无下游读取 → 再删除");
        }

        return recs;
    }
}
```

```java
    @Scheduled(cron = "0 0 3 * * SUN") // 每周日凌晨3点
    public void autoTagPiiFields() {
        List<DataSource> allSources = dataSourceRepository.findByStatus("ACTIVE");

        for (DataSource ds : allSources) {
            MetadataSnapshot snapshot = collector.collectMetadata(ds);

            for (Map.Entry<String, List<ColumnInfo>> entry : snapshot.getTables().entrySet()) {
                for (ColumnInfo col : entry.getValue()) {
                    PiiCategory detected = detectPii(col);

                    if (detected != PiiCategory.NONE) {
                        // 更新字段 PII 标签
                        updateColumnPiiTag(ds, entry.getKey(), col, detected);
                    }
                }
            }
        }
    }

    private PiiCategory detectPii(ColumnInfo col) {
        String colName = col.getColumnName().toLowerCase();

        for (PiiDetectionRule rule : DETECTION_RULES) {
            // 名称模式匹配
            for (String keyword : rule.nameKeywords()) {
                if (colName.contains(keyword.toLowerCase())) {
                    return PiiCategory.valueOf(rule.category());
                }
            }
        }

        // 注释匹配
        if (col.getComment() != null) {
            String comment = col.getComment().toLowerCase();
            for (PiiDetectionRule rule : DETECTION_RULES) {
                for (String keyword : rule.nameKeywords()) {
                    if (comment.contains(keyword.toLowerCase())) {
                        return PiiCategory.valueOf(rule.category());
                    }
                }
            }
        }

        return PiiCategory.NONE;
    }
}
```

### 9.2 采集器容错策略

```java
/**
 * 血缘采集容错：单个数据源采集失败不影响其他数据源
 */
public class LineageCollectionException extends BizException {
    private final Long datasourceId;
    private final String collectorType;
    private final CollectionFailureReason reason;

    public enum CollectionFailureReason {
        CONNECTION_FAILED,        // 数据源连接失败
        AUTH_ERROR,               // 认证失败
        SQL_PARSE_ERROR,          // SQL解析失败
        METADATA_INCOMPLETE,      // 元数据不完整
        TIMEOUT,                  // 采集超时
        NEO4J_WRITE_FAILED        // 图数据库写入失败
    }
}

// 定时采集任务的容错处理
@Scheduled(cron = "0 0 */6 * * *") // 每6小时全量采集
public void scheduledFullCollection() {
    List<DataSource> sources = dataSourceRepository.findByStatus("ACTIVE");

    for (DataSource ds : sources) {
        try {
            LineageCollector collector = collectorRegistry.get(ds.getSourceType());
            List<LineageTriple> triples = collector.collectTableLineage(ds);
            persistenceProcessor.persist(triples);
            ds.setLastScanAt(Instant.now());
        } catch (LineageCollectionException e) {
            log.warn("血缘采集失败 datasource={}, reason={}",
                ds.getSourceCode(), e.getReason(), e);
            // 记录失败，不中断后续数据源采集
            scanFailureRecorder.record(ds.getId(), e);
        }
    }
}
```

## 12. 安全考虑

1. **元数据隔离**：平台仅存储表结构、字段名、类型、流转关系等元数据，**绝不存储实际业务数据值**。
2. **PII 标签保护**：PII 分类标签本身属于敏感元数据，仅授权人员可查看。
3. **SQL 表达式脱敏**：血缘中存储的 SQL 表达式摘要需去除可能的硬编码参数值。
4. **访问控制**：数据目录搜索、血缘查询接口需进行 RBAC 鉴权；合规报告接口需额外审计权限。
5. **采集器凭据安全**：数据源连接凭据统一通过密钥管理服务（如 Vault / KMS）管理，不在平台存储明文密码。
