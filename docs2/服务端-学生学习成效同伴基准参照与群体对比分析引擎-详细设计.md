# 服务端 - 学生学习成效同伴基准参照与群体对比分析引擎

## 1. 模块概述

### 1.1 功能定位

同伴基准参照与群体对比分析引擎负责将学生个体的学习成效指标放入同龄/同年级/同班/同区域群体中进行统计对比，生成百分位排名、群体分位值、相对优势/薄弱诊断和同伴分布分析数据，为学情报告、家长报告、教师班级分析和个性化推荐提供**常模参照（Norm-Referenced）**数据支撑。

该引擎与现有的**绝对评估**（如学科能力维度评估、知识点掌握度）形成互补：绝对评估回答"学生掌握了多少"，本引擎回答"学生在同龄人中处于什么位置"。

### 1.2 核心能力

| 能力 | 说明 |
| --- | --- |
| 同伴群体管理 | 定义和管理不同层级的参照群体（班级/年级/学校/区域/全国） |
| 百分位计算 | 对学科掌握度、正确率、学习时长、能力维度等指标计算百分位排名 |
| 群体分布统计 | 计算群体均值、标准差、四分位数、概率密度分布 |
| 常模表构建 | 周期性构建各年级×学科×指标的常模基准表 |
| 相对优势诊断 | 在群体对比中识别学生的相对优势学科和相对薄弱学科 |
| 同伴画像匹配 | 基于学习特征聚类，找到"相似学习者"群体用于对比和推荐 |
| 对比报告生成 | 生成学生端、家长端、教师端不同视角的对比分析报告数据 |
| 隐私保护聚合 | 确保所有群体统计满足最小样本量要求和匿名化处理 |

### 1.4 设计约束

| 约束 | 说明 |
| --- | --- |
| 最小样本量 | 任何对外暴露的群体统计指标要求群体内有效样本 ≥ 30 人，否则不返回对比数据 |
| 隐私合规 | 群体统计数据不可反向推导出个体信息；不向学生展示其他个体的具体数据 |
| 双减合规 | 不对义务教育阶段学生公开展示排名榜单；仅在学生本人/家长/教师端以私密方式展示相对位置 |
| 数据时效 | 常模基准表按周更新；百分位计算基于最近4周滚动窗口数据 |
| 性能要求 | 单次百分位查询响应 < 200ms；班级分布查询 < 500ms |

## 3. 核心算法设计

### 3.1 百分位计算算法

#### 3.1.1 基于常模表的百分位估算

当常模基准表已生成时，使用已知分布参数估算百分位。

```java
/**
 * 基于常模分布参数计算百分位
 * 
 * @param rawValue    学生原始值
 * @param baseline    常模基准记录
 * @return 百分位 (0-100)
 */
public BigDecimal calculatePercentile(double rawValue, NormBaseline baseline) {
    // 1. 根据分布类型选择计算策略
    switch (baseline.getDistributionType()) {
        case "normal":
            return calculateNormalPercentile(rawValue, baseline);
        case "skewed":
            return calculateSkewedPercentile(rawValue, baseline);
        case "bimodal":
            return calculateBimodalPercentile(rawValue, baseline);
        default:
            return calculateEmpiricalPercentile(rawValue, baseline);
    }
}

/**
 * 正态分布近似百分位计算
 */
private BigDecimal calculateNormalPercentile(double rawValue, NormBaseline baseline) {
    if (baseline.getStdDev() == 0) {
        // 标准差为0，所有值相同
        return rawValue >= baseline.getMeanValue() 
            ? BigDecimal.valueOf(50.0) 
            : BigDecimal.valueOf(0.0);
    }
    double z = (rawValue - baseline.getMeanValue()) / baseline.getStdDev();
    // 使用标准正态CDF查表/近似
    double percentile = NormalDistribution.cumulativeProbability(z) * 100;
    // 边界裁剪到 [0.1, 99.9]
    percentile = Math.max(0.1, Math.min(99.9, percentile));
    return BigDecimal.valueOf(percentile).setScale(2, RoundingMode.HALF_UP);
}

/**
 * 基于经验直方图的百分位计算（非正态分布）
 */
private BigDecimal calculateEmpiricalPercentile(double rawValue, NormBaseline baseline) {
    List<HistogramBucket> buckets = baseline.getHistogramBuckets();
    if (buckets == null || buckets.isEmpty()) {
        // 无直方图数据，退化为线性插值
        return linearInterpPercentile(rawValue, baseline);
    }
    
    double cumulativeCount = 0;
    double totalCount = baseline.getSampleSize();
    
    for (HistogramBucket bucket : buckets) {
        if (rawValue < bucket.getBucketMin()) {
            // 值在当前桶之前，使用线性插值
            double prevCumRatio = cumulativeCount / totalCount;
            return BigDecimal.valueOf(prevCumRatio * 100).setScale(2, RoundingMode.HALF_UP);
        }
        if (rawValue >= bucket.getBucketMin() && rawValue < bucket.getBucketMax()) {
            // 值落在当前桶内，桶内线性插值
            double prevCumRatio = cumulativeCount / totalCount;
            double bucketRatio = (rawValue - bucket.getBucketMin()) 
                / (bucket.getBucketMax() - bucket.getBucketMin());
            double bucketCountRatio = (bucket.getCount() / totalCount) * bucketRatio;
            double percentile = (prevCumRatio + bucketCountRatio) * 100;
            return BigDecimal.valueOf(percentile).setScale(2, RoundingMode.HALF_UP);
        }
        cumulativeCount += bucket.getCount();
    }
    return BigDecimal.valueOf(99.9); // 超过最大值
}
```

#### 3.1.2 实时百分位计算（无常模表时的降级策略）

```java
/**
 * 实时百分位计算 - 直接从预计算分桶统计中查询
 * 用于常模表尚未生成的场景
 */
public PercentileResult calculateRealtimePercentile(
        Long userId, String metricCode, String subjectCode, Integer gradeLevel) {
    
    // 1. 获取用户所属年级群体
    String groupId = resolveDefaultGroup(userId, gradeLevel);
    
    // 2. 从Redis预计算缓存获取分桶统计
    String cacheKey = String.format("percentile:bucket:%s:%s:%s", 
        groupId, subjectCode, metricCode);
    PercentileBucketCache bucketCache = percentileCache.get(cacheKey);
    
    if (bucketCache == null || bucketCache.isExpired()) {
        // 缓存未命中，触发异步重算
        percentileRecomputeProducer.send(groupId, subjectCode, metricCode);
        return PercentileResult.unavailable();
    }
    
    // 3. 从分桶中查询百分位
    double rawValue = getUserMetricValue(userId, metricCode, subjectCode);
    double percentile = bucketLookup(rawValue, bucketCache);
    
    // 4. 缓存结果
    return PercentileResult.builder()
        .rawValue(rawValue)
        .percentile(percentile)
        .sampleSize(bucketCache.getSampleSize())
        .computationMethod("realtime_bucket")
        .computedAt(LocalDateTime.now())
        .build();
}
```

### 3.2 常模基准计算引擎

```java
/**
 * 常模基准计算任务
 * 按周执行，对每个 群体×年级×学科×指标 组合计算统计分布参数
 */
@Component
public class NormBaselineComputeJob {
    
    @Scheduled(cron = "0 0 2 * * MON") // 每周一凌晨2点
    public void executeWeeklyBaselineComputation() {
        // 1. 获取所有活跃群体
        List<PeerGroup> activeGroups = peerGroupService.listActiveGroups();
        
        for (PeerGroup group : activeGroups) {
            // 2. 对每个指标分别计算
            for (String metricCode : SUPPORTED_METRICS) {
                for (String subjectCode : getSubjectsForGroup(group)) {
                    computeBaselineForGroupMetric(group, metricCode, subjectCode);
                }
            }
        }
    }
    
    private void computeBaselineForGroupMetric(
            PeerGroup group, String metricCode, String subjectCode) {
        
        // 1. 获取群体内所有活跃成员的指标值
        LocalDate periodStart = LocalDate.now().minusWeeks(4); // 滚动4周
        LocalDate periodEnd = LocalDate.now().minusDays(1);
        
        List<Double> values = studentMetricService.batchQueryMetricValues(
            group.getGroupId(), subjectCode, metricCode, periodStart, periodEnd);
        
        // 2. 最小样本量检查
        if (values.size() < MIN_SAMPLE_SIZE) {
            log.info("Skip baseline for group={}, metric={}, sample={}",
                group.getGroupId(), metricCode, values.size());
            return;
        }
        
        // 3. 异常值剔除（IQR方法）
        List<Double> cleanedValues = removeOutliers(values);
        
        // 4. 计算统计参数
        DescriptiveStatistics stats = new DescriptiveStatistics(
            cleanedValues.stream().mapToDouble(Double::doubleValue).toArray());
        
        // 5. 构建直方图（Freedman-Diaconis规则确定桶数）
        List<HistogramBucket> histogram = buildHistogram(cleanedValues);
        
        // 6. 判断分布类型
        String distributionType = detectDistributionType(stats, histogram);
        
        // 7. 持久化（标记旧版本为非当前）
        NormBaseline baseline = NormBaseline.builder()
            .groupId(group.getGroupId())
            .gradeLevel(group.getGradeLevel())
            .subjectCode(subjectCode)
            .metricCode(metricCode)
            .periodType(PeriodType.WEEKLY)
            .periodStart(periodStart)
            .periodEnd(periodEnd)
            .sampleSize(cleanedValues.size())
            .meanValue(BigDecimal.valueOf(stats.getMean()))
            .stdDev(BigDecimal.valueOf(stats.getStandardDeviation()))
            .medianValue(BigDecimal.valueOf(stats.getPercentile(50)))
            .p10Value(BigDecimal.valueOf(stats.getPercentile(10)))
            .p25Value(BigDecimal.valueOf(stats.getPercentile(25)))
            .p75Value(BigDecimal.valueOf(stats.getPercentile(75)))
            .p90Value(BigDecimal.valueOf(stats.getPercentile(90)))
            .minValue(BigDecimal.valueOf(stats.getMin()))
            .maxValue(BigDecimal.valueOf(stats.getMax()))
            .skewness(BigDecimal.valueOf(stats.getSkewness()))
            .kurtosis(BigDecimal.valueOf(stats.getKurtosis()))
            .distributionType(distributionType)
            .histogramBuckets(histogram)
            .computedAt(LocalDateTime.now())
            .isCurrent(true)
            .build();
        
        // 8. 原子更新：旧版本置为非当前 → 插入新版本
        normBaselineDao.deprecateCurrent(group.getGroupId(), subjectCode, metricCode);
        normBaselineDao.insert(baseline);
        
        // 9. 更新Redis缓存
        String cacheKey = String.format("norm:baseline:%s:%s:%s", 
            group.getGroupId(), subjectCode, metricCode);
        normCache.put(cacheKey, baseline, Duration.ofDays(8));
        
        // 10. 触发受影响学生的百分位重算
        percentileRecomputeProducer.sendBatch(group.getGroupId(), subjectCode, metricCode);
    }
    
    /**
     * IQR异常值剔除
     */
    private List<Double> removeOutliers(List<Double> values) {
        DescriptiveStatistics stats = new DescriptiveStatistics(
            values.stream().mapToDouble(Double::doubleValue).toArray());
        double q1 = stats.getPercentile(25);
        double q3 = stats.getPercentile(75);
        double iqr = q3 - q1;
        double lowerBound = q1 - 1.5 * iqr;
        double upperBound = q3 + 1.5 * iqr;
        return values.stream()
            .filter(v -> v >= lowerBound && v <= upperBound)
            .collect(Collectors.toList());
    }
