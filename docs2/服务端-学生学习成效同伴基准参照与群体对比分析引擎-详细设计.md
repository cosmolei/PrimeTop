# 服务端 - 学生学习成效同伴基准参照与群体对比分析引擎

## 1. 模块概述

### 1.1 功能定位

同伴基准参照与群体对比分析引擎负责将学生个体的学习成效指标放入同龄/同年级/同班/同区域群体中进行统计对比，生成百分位排名、群体分位值、相对优势/薄弱诊断和同伴分布分析数据，为学情报告、家长报告、教师班级分析和个性化推荐提供**常模参照（Norm-Referenced）**数据支撑。

该引擎与现有的**绝对评估**（如学科能力维度评估、知识点掌握度）形成互补：绝对评估回答"学生掌握了多少"，本引擎回答"学生在同龄人中处于什么位置"。

### 1.2 核心能力

| 能力 | 说明 |
| --- | --- |
| 同伴群体管理 | 定义和管理不同层级的参照群体（班级/年级/学校/区域/全国） |
| 百分位计算 | 对学科掌握度、正确率、学习时长、能力维度等指标计算百分位排名 |
| 群体分布统计 | 计算群体均值、标准差、四分位数、概率密度分布 |
| 常模表构建 | 周期性构建各年级×学科×指标的常模基准表 |
| 相对优势诊断 | 在群体对比中识别学生的相对优势学科和相对薄弱学科 |
| 同伴画像匹配 | 基于学习特征聚类，找到"相似学习者"群体用于对比和推荐 |
| 对比报告生成 | 生成学生端、家长端、教师端不同视角的对比分析报告数据 |
| 隐私保护聚合 | 确保所有群体统计满足最小样本量要求和匿名化处理 |

### 1.4 设计约束

| 约束 | 说明 |
| --- | --- |
| 最小样本量 | 任何对外暴露的群体统计指标要求群体内有效样本 ≥ 30 人，否则不返回对比数据 |
| 隐私合规 | 群体统计数据不可反向推导出个体信息；不向学生展示其他个体的具体数据 |
| 双减合规 | 不对义务教育阶段学生公开展示排名榜单；仅在学生本人/家长/教师端以私密方式展示相对位置 |
| 数据时效 | 常模基准表按周更新；百分位计算基于最近4周滚动窗口数据 |
| 性能要求 | 单次百分位查询响应 < 200ms；班级分布查询 < 500ms |

## 3. 核心算法设计

### 3.1 百分位计算算法

#### 3.1.1 基于常模表的百分位估算

当常模基准表已生成时，使用已知分布参数估算百分位。

```java
/**
 * 基于常模分布参数计算百分位
 * 
 * @param rawValue    学生原始值
 * @param baseline    常模基准记录
 * @return 百分位 (0-100)
 */
public BigDecimal calculatePercentile(double rawValue, NormBaseline baseline) {
    // 1. 根据分布类型选择计算策略
    switch (baseline.getDistributionType()) {
        case "normal":
            return calculateNormalPercentile(rawValue, baseline);
        case "skewed":
            return calculateSkewedPercentile(rawValue, baseline);
        case "bimodal":
            return calculateBimodalPercentile(rawValue, baseline);
        default:
            return calculateEmpiricalPercentile(rawValue, baseline);
    }
}

/**
 * 正态分布近似百分位计算
 */
private BigDecimal calculateNormalPercentile(double rawValue, NormBaseline baseline) {
    if (baseline.getStdDev() == 0) {
        // 标准差为0，所有值相同
        return rawValue >= baseline.getMeanValue() 
            ? BigDecimal.valueOf(50.0) 
            : BigDecimal.valueOf(0.0);
    }
    double z = (rawValue - baseline.getMeanValue()) / baseline.getStdDev();
    // 使用标准正态CDF查表/近似
    double percentile = NormalDistribution.cumulativeProbability(z) * 100;
    // 边界裁剪到 [0.1, 99.9]
    percentile = Math.max(0.1, Math.min(99.9, percentile));
    return BigDecimal.valueOf(percentile).setScale(2, RoundingMode.HALF_UP);
}

/**
 * 基于经验直方图的百分位计算（非正态分布）
 */
private BigDecimal calculateEmpiricalPercentile(double rawValue, NormBaseline baseline) {
    List<HistogramBucket> buckets = baseline.getHistogramBuckets();
    if (buckets == null || buckets.isEmpty()) {
        // 无直方图数据，退化为线性插值
        return linearInterpPercentile(rawValue, baseline);
    }
    
    double cumulativeCount = 0;
    double totalCount = baseline.getSampleSize();
    
    for (HistogramBucket bucket : buckets) {
        if (rawValue < bucket.getBucketMin()) {
            // 值在当前桶之前，使用线性插值
            double prevCumRatio = cumulativeCount / totalCount;
            return BigDecimal.valueOf(prevCumRatio * 100).setScale(2, RoundingMode.HALF_UP);
        }
        if (rawValue >= bucket.getBucketMin() && rawValue < bucket.getBucketMax()) {
            // 值落在当前桶内，桶内线性插值
            double prevCumRatio = cumulativeCount / totalCount;
            double bucketRatio = (rawValue - bucket.getBucketMin()) 
                / (bucket.getBucketMax() - bucket.getBucketMin());
            double bucketCountRatio = (bucket.getCount() / totalCount) * bucketRatio;
            double percentile = (prevCumRatio + bucketCountRatio) * 100;
            return BigDecimal.valueOf(percentile).setScale(2, RoundingMode.HALF_UP);
        }
        cumulativeCount += bucket.getCount();
    }
    return BigDecimal.valueOf(99.9); // 超过最大值
}
```

#### 3.1.2 实时百分位计算（无常模表时的降级策略）

```java
/**
 * 实时百分位计算 - 直接从预计算分桶统计中查询
 * 用于常模表尚未生成的场景
 */
public PercentileResult calculateRealtimePercentile(
        Long userId, String metricCode, String subjectCode, Integer gradeLevel) {
    
    // 1. 获取用户所属年级群体
    String groupId = resolveDefaultGroup(userId, gradeLevel);
    
    // 2. 从Redis预计算缓存获取分桶统计
    String cacheKey = String.format("percentile:bucket:%s:%s:%s", 
        groupId, subjectCode, metricCode);
    PercentileBucketCache bucketCache = percentileCache.get(cacheKey);
    
    if (bucketCache == null || bucketCache.isExpired()) {
        // 缓存未命中，触发异步重算
        percentileRecomputeProducer.send(groupId, subjectCode, metricCode);
        return PercentileResult.unavailable();
    }
    
    // 3. 从分桶中查询百分位
    double rawValue = getUserMetricValue(userId, metricCode, subjectCode);
    double percentile = bucketLookup(rawValue, bucketCache);
    
    // 4. 缓存结果
    return PercentileResult.builder()
        .rawValue(rawValue)
        .percentile(percentile)
        .sampleSize(bucketCache.getSampleSize())
        .computationMethod("realtime_bucket")
        .computedAt(LocalDateTime.now())
        .build();
}
```

### 3.2 常模基准计算引擎

```java
/**
 * 常模基准计算任务
 * 按周执行，对每个 群体×年级×学科×指标 组合计算统计分布参数
 */
@Component
public class NormBaselineComputeJob {
    
    @Scheduled(cron = "0 0 2 * * MON") // 每周一凌晨2点
    public void executeWeeklyBaselineComputation() {
        // 1. 获取所有活跃群体
        List<PeerGroup> activeGroups = peerGroupService.listActiveGroups();
        
        for (PeerGroup group : activeGroups) {
            // 2. 对每个指标分别计算
            for (String metricCode : SUPPORTED_METRICS) {
                for (String subjectCode : getSubjectsForGroup(group)) {
                    computeBaselineForGroupMetric(group, metricCode, subjectCode);
                }
            }
        }
    }
    
    private void computeBaselineForGroupMetric(
            PeerGroup group, String metricCode, String subjectCode) {
        
        // 1. 获取群体内所有活跃成员的指标值
        LocalDate periodStart = LocalDate.now().minusWeeks(4); // 滚动4周
        LocalDate periodEnd = LocalDate.now().minusDays(1);
        
        List<Double> values = studentMetricService.batchQueryMetricValues(
            group.getGroupId(), subjectCode, metricCode, periodStart, periodEnd);
        
        // 2. 最小样本量检查
        if (values.size() < MIN_SAMPLE_SIZE) {
            log.info("Skip baseline for group={}, metric={}, sample={}",
                group.getGroupId(), metricCode, values.size());
            return;
        }
        
        // 3. 异常值剔除（IQR方法）
        List<Double> cleanedValues = removeOutliers(values);
        
        // 4. 计算统计参数
        DescriptiveStatistics stats = new DescriptiveStatistics(
            cleanedValues.stream().mapToDouble(Double::doubleValue).toArray());
        
        // 5. 构建直方图（Freedman-Diaconis规则确定桶数）
        List<HistogramBucket> histogram = buildHistogram(cleanedValues);
        
        // 6. 判断分布类型
        String distributionType = detectDistributionType(stats, histogram);
        
        // 7. 持久化（标记旧版本为非当前）
        NormBaseline baseline = NormBaseline.builder()
            .groupId(group.getGroupId())
            .gradeLevel(group.getGradeLevel())
            .subjectCode(subjectCode)
            .metricCode(metricCode)
            .periodType(PeriodType.WEEKLY)
            .periodStart(periodStart)
            .periodEnd(periodEnd)
            .sampleSize(cleanedValues.size())
            .meanValue(BigDecimal.valueOf(stats.getMean()))
            .stdDev(BigDecimal.valueOf(stats.getStandardDeviation()))
            .medianValue(BigDecimal.valueOf(stats.getPercentile(50)))
            .p10Value(BigDecimal.valueOf(stats.getPercentile(10)))
            .p25Value(BigDecimal.valueOf(stats.getPercentile(25)))
            .p75Value(BigDecimal.valueOf(stats.getPercentile(75)))
            .p90Value(BigDecimal.valueOf(stats.getPercentile(90)))
            .minValue(BigDecimal.valueOf(stats.getMin()))
            .maxValue(BigDecimal.valueOf(stats.getMax()))
            .skewness(BigDecimal.valueOf(stats.getSkewness()))
            .kurtosis(BigDecimal.valueOf(stats.getKurtosis()))
            .distributionType(distributionType)
            .histogramBuckets(histogram)
            .computedAt(LocalDateTime.now())
            .isCurrent(true)
            .build();
        
        // 8. 原子更新：旧版本置为非当前 → 插入新版本
        normBaselineDao.deprecateCurrent(group.getGroupId(), subjectCode, metricCode);
        normBaselineDao.insert(baseline);
        
        // 9. 更新Redis缓存
        String cacheKey = String.format("norm:baseline:%s:%s:%s", 
            group.getGroupId(), subjectCode, metricCode);
        normCache.put(cacheKey, baseline, Duration.ofDays(8));
        
        // 10. 触发受影响学生的百分位重算
        percentileRecomputeProducer.sendBatch(group.getGroupId(), subjectCode, metricCode);
    }
    
    /**
     * IQR异常值剔除
     */
    private List<Double> removeOutliers(List<Double> values) {
        DescriptiveStatistics stats = new DescriptiveStatistics(
            values.stream().mapToDouble(Double::doubleValue).toArray());
        double q1 = stats.getPercentile(25);
        double q3 = stats.getPercentile(75);
        double iqr = q3 - q1;
        double lowerBound = q1 - 1.5 * iqr;
        double upperBound = q3 + 1.5 * iqr;
        return values.stream()
            .filter(v -> v >= lowerBound && v <= upperBound)
            .collect(Collectors.toList());
    }
    
    /**
     * 分布类型检测
     */
    private String detectDistributionType(DescriptiveStatistics stats, List<HistogramBucket> histogram) {
        double skewness = stats.getSkewness();
        double kurtosis = stats.getKurtosis();
        
        // 双峰检测：直方图有明显的两个峰
        if (isBimodal(histogram)) {
            return "bimodal";
        }
        // 正态分布：偏度接近0，峰度接近3(超额峰度接近0)
        if (Math.abs(skewness) < 0.5 && Math.abs(kurtosis) < 1.0) {
            return "normal";
        }
        // 平坦（近似均匀）分布：超额峰度显著为负且几乎无偏
        if (kurtosis < -1.2 && Math.abs(skewness) < 0.3) {
            return "uniform";
        }
        // 其余一律按偏态处理：百分位走经验直方图路径，宁可降低近似精度也不做正态强估
        return "skewed";
    }

    /**
     * 双峰检测：基于直方图桶密度的局部极大值结构判定
     * 规则：存在两个显著峰（密度 ≥ 全局峰值密度 40%），两峰桶序号间隔 ≥ 2，
     * 且两峰之间存在密度 ≤ 较矮峰密度 50% 的谷
     */
    private boolean isBimodal(List<HistogramBucket> histogram) {
        if (histogram == null || histogram.size() < 5) {
            return false;
        }
        double maxDensity = histogram.stream()
                .mapToDouble(HistogramBucket::getDensity)
                .max().orElse(0.0);
        if (maxDensity <= 0.0) {
            return false;
        }
        List<Integer> peakIdx = new ArrayList<>();
        for (int i = 1; i < histogram.size() - 1; i++) {
            double d = histogram.get(i).getDensity();
            if (d >= maxDensity * 0.4
                    && d > histogram.get(i - 1).getDensity()
                    && d >= histogram.get(i + 1).getDensity()) {
                peakIdx.add(i);
            }
        }
        for (int p = 1; p < peakIdx.size(); p++) {
            int prev = peakIdx.get(p - 1);
            int curr = peakIdx.get(p);
            if (curr - prev < 2) {
                continue;
            }
            double minValley = Double.MAX_VALUE;
            for (int j = prev + 1; j < curr; j++) {
                minValley = Math.min(minValley, histogram.get(j).getDensity());
            }
            double lowerPeak = Math.min(
                    histogram.get(prev).getDensity(),
                    histogram.get(curr).getDensity());
            if (minValley <= lowerPeak * 0.5) {
                return true;
            }
        }
        return false;
    }

    /**
     * Freedman-Diaconis 规则构建直方图
     * 桶宽 h = 2·IQR / n^(1/3)，桶数裁剪到 [8, 40]，边界桶覆盖 [min, max]
     */
    private List<HistogramBucket> buildHistogram(List<Double> values) {
        DescriptiveStatistics stats = new DescriptiveStatistics(
                values.stream().mapToDouble(Double::doubleValue).toArray());
        double q1 = stats.getPercentile(25);
        double q3 = stats.getPercentile(75);
        double iqr = Math.max(q3 - q1, 1e-9); // IQR=0（大量同值）时退化为极小值防除零
        double binWidth = 2.0 * iqr / Math.cbrt(values.size());
        int binCount = (int) Math.ceil(
                (stats.getMax() - stats.getMin()) / binWidth);
        binCount = Math.max(8, Math.min(40, binCount));

        double min = stats.getMin();
        double width = (stats.getMax() - min) / binCount;
        List<HistogramBucket> buckets = new ArrayList<>(binCount);
        for (int i = 0; i < binCount; i++) {
            buckets.add(new HistogramBucket(
                    min + i * width, min + (i + 1) * width, 0, 0.0));
        }
        for (double v : values) {
            int idx = (int) Math.min(binCount - 1, Math.floor((v - min) / width));
            buckets.get(idx).incrementCount();
        }
        for (HistogramBucket b : buckets) {
            // density = 桶计数 / (总样本 × 桶宽)，用于双峰检测与对外分布渲染
            b.setDensity(b.getCount() / ((double) values.size() * width));
        }
        return buckets;
    }

    /**
     * 基准有效性自检（守卫 G3 的写入侧前置防线）：
     * NaN / 负标准差 / 样本坍缩 / 分位数乱序 一律判失败，
     * 保留上一期基准并告警，绝不写入脏常模
     */
    private boolean validateBaseline(NormBaseline b) {
        if (b.getSampleSize() < MIN_SAMPLE_SIZE) return false;
        if (Double.isNaN(b.getMeanValue().doubleValue())
                || Double.isNaN(b.getStdDev().doubleValue())) return false;
        if (b.getStdDev().doubleValue() < 0) return false;
        return b.getP10Value().doubleValue() <= b.getP25Value().doubleValue()
            && b.getP25Value().doubleValue() <= b.getMedianValue().doubleValue()
            && b.getMedianValue().doubleValue() <= b.getP75Value().doubleValue()
            && b.getP75Value().doubleValue() <= b.getP90Value().doubleValue();
    }
}
```

### 3.3 相对优势与薄弱学科诊断算法

诊断采用**两层参照**：先用同伴基准把各学科掌握度换算为同群体百分位（消除学科间难度与评分口径差异），再在学生自己的学科百分位集合内做组内标准化，识别相对高/低位置。

**公式定义：**

- 学科相对指数：`SRI(s) = (P(s) - mean(P)) / std(P)`，其中 `P(s)` 为学科 s 的掌握度百分位，`P` 为该学生全部有效学科百分位集合
- 判定阈值：`SRI > +0.6` → 相对优势学科；`SRI < -0.6` → 相对薄弱学科；其余为与自身水平相当
- 均衡度指数：`BDI = round(100 × (1 - min(1, std(P) / 25)))`，`std(P)` 越小越均衡（std=0 → 100 分）；25 为经验归一常数（对应百分位标准差的明显偏科水位）

```java
/**
 * 相对优势/薄弱学科诊断
 * 两层参照：学科内同伴百分位（消除学科难度差）→ 学生自身学科集合组内标准化
 */
public RelativeStrengthReport diagnoseRelativeStrength(Long userId, String groupId) {
    // 1. 批量获取学生各学科 mastery_score 百分位（样本不足的学科已在内部被剔除）
    Map<String, SubjectPercentile> percentileMap =
        percentileService.batchGetSubjectPercentiles(userId, groupId, "mastery_score");

    // 2. 守卫：有效学科 < 3 不出诊断（避免两学科互为强弱造成误导）
    if (percentileMap.size() < 3) {
        return RelativeStrengthReport.insufficient();
    }

    // 3. 组内标准化：SRI(s) = (P(s) - mean(P)) / std(P)
    double[] ps = percentileMap.values().stream()
        .mapToDouble(SubjectPercentile::getPercentile).toArray();
    double mean = StatUtils.mean(ps);
    double std = Math.sqrt(StatUtils.variance(ps));

    List<SubjectDiagnosis> items = new ArrayList<>();
    for (Map.Entry<String, SubjectPercentile> e : percentileMap.entrySet()) {
        double sri = std == 0 ? 0.0 : (e.getValue().getPercentile() - mean) / std;
        items.add(SubjectDiagnosis.builder()
            .subjectCode(e.getKey())
            .percentile(e.getValue().getPercentile())
            .sri(BigDecimal.valueOf(sri).setScale(3, RoundingMode.HALF_UP))
            .level(sri > 0.6 ? RelativeLevel.RELATIVE_ADVANTAGE
                 : sri < -0.6 ? RelativeLevel.RELATIVE_WEAK
                              : RelativeLevel.COMPARABLE)
            .build());
    }

    // 4. 均衡度指数：std(P) 越小越均衡
    int bdi = (int) Math.round(100 * (1 - Math.min(1.0, std / 25.0)));
    return RelativeStrengthReport.builder()
        .userId(userId).groupId(groupId)
        .subjects(items).balanceIndex(bdi)
        .diagnosedAt(LocalDateTime.now())
        .build();
}
```

**边界与守卫：**

1. 学科百分位缺失（该学科常模未生成/样本不足）的学科不参与诊断，也不计入 `P` 集合；
2. `percentile_delta` 进步提示需要两期以上快照，首期学生仅展示当期位置不展示变化；
3. 诊断结果落库 `student_percentile` 同库的扩展表并经 Outbox 发布（见 §7），下游禁止各自重算；
4. 客户端话术使用成长型表述：优先"较上期 +4.3"，其次"位于全国初一学生前 30%"，禁止出现指向具体同伴的对比表述（见 §10 合规红线）。

### 3.4 学习者聚类与相似学习者匹配算法

#### 3.4.1 特征向量构建（18 维）

| 特征组 | 维度 | 构成 |
| --- | --- | --- |
| 学科掌握度 | 9 | 各学科 `mastery_score`（缺失学科用群体均值填充，并记录 mask 位供相似度加权） |
| 学习行为 | 6 | `study_minutes_daily` / `exercise_count_weekly` / `correct_rate` / `error_resolution_rate` / `plan_completion_rate` / `engagement_score` |
| 学习模式 | 3 | 晚间(18-23点)学习时长占比 / 周末学习时长占比 / 单次会话中位时长 |

全部特征先按**该年级常模基准做 z 标准化**（保证跨年级、跨指标可比），再做 L2 归一化，最终相似度使用余弦度量。

#### 3.4.2 离线训练（每周日执行）

- 算法：MiniBatchKMeans（batchSize=1024，maxIter=200，随机种子固定保证可复现）；
- k 选择：在 [4, 10] 内按轮廓系数（silhouette）步长 1 搜索，每个 k 训练 5 次取稳定解，`silhouette < 0.25` 视为聚类质量不达标，该年级本期不发布新模型（沿用上期）；
- 训练样本：该年级近 4 周活跃学生全量；样本 < 5000 时该年级降级复用上一期模型；
- 发布：新模型 `version+1` 写入 `learner_cluster`（is_active=1，同年级旧模型置 0）；成员全量重分配为异步任务，按 user_id 1000/批推进，完成后发布 `ClusterAssigned` 事件。

#### 3.4.3 在线聚类分配

```java
/**
 * 学习者聚类分配（在线推理）
 * 特征构建 → 常模 z 标准化 → L2 归一化 → 最近质心（余弦）
 */
public ClusterAssignment assignCluster(Long userId, Integer gradeLevel) {
    List<LearnerCluster> clusters = clusterService.listActiveClusters(gradeLevel);
    if (clusters.isEmpty()) {
        return ClusterAssignment.unavailable(); // 降级 D5
    }
    double[] features = featureBuilder.buildNormalized(userId, gradeLevel);
    double bestSim = -1.0;
    LearnerCluster best = null;
    for (LearnerCluster c : clusters) {
        double[] centroid = c.parseCentroidFeatures();
        double sim = CosineSimilarity.compute(features, centroid);
        if (sim > bestSim) { bestSim = sim; best = c; }
    }
    // 守卫 G7：相似度阈值 0.55，低于阈值标记"未分类"而非强行归入
    if (best == null || bestSim < 0.55) {
        return ClusterAssignment.unclassified(userId, bestSim);
    }
    return ClusterAssignment.of(userId, best.getClusterId(), bestSim);
}
```

#### 3.4.4 相似学习者池（服务端聚合，个体身份不出栈）

```java
/**
 * 相似学习者池：仅服务端内部使用，任何 API 不返回个体身份。
 * 粗筛：同聚类成员全量；精排：18 维特征余弦 Top-50。
 */
public SimilarPeerPool buildSimilarPool(Long userId, int topK) {
    Integer grade = profileService.getGradeLevel(userId);
    ClusterAssignment self = assignmentService.getCurrent(userId);
    if (!self.isClassified()) {
        return SimilarPeerPool.empty(); // G7 未分类 → 不建池
    }
    double[] selfFeatures = featureBuilder.buildNormalized(userId, grade);
    // 粗筛：当前聚类成员；精排：余弦相似度堆取 Top-K
    List<PeerCandidate> candidates = featureStore.loadClusterMembers(self.getClusterId());
        .stream()
        .map(p -> PeerCandidate.of(p,
            CosineSimilarity.compute(selfFeatures, p.getFeatures())))
        .sorted(Comparator.comparingDouble(PeerCandidate::getSimilarity).reversed())
        .limit(topK)
        .collect(Collectors.toList());
    // 守卫 G8：池内 < 5 人不产出任何聚合结论
    if (candidates.size() < 5) {
        return SimilarPeerPool.tooSmall();
    }
    return SimilarPeerPool.of(candidates); // 仅供服务端聚合：如"相似学习者本周高频练习章节"
}
```

**隐私输出边界：**池内个体身份（user_id/昵称/画像）禁止出现在任何响应、日志、事件载荷中；对外仅允许聚合结论（≥5 人池），推荐引擎消费的是聚合后的章节/内容候选，而非同伴列表。

### 3.5 事件驱动的增量百分位更新（实时通道）

常模表周更意味着百分位最多滞后一周；对正确率、学习时长等高频变化指标，提供 Redis ZSET 实时通道补位：

- ZSET key：`rt:pc:{group_id}:{subject}:{metric}`，member=user_id，score=指标原始值；
- 消费事件：`practice.graded` / `mastery.updated` / `study.session.closed`（均为学习行为事件标准 Schema 已注册事件）；
- 更新与查询使用同一 Lua 脚本保证原子性：

```lua
-- KEYS[1] = rt:pc:{group}:{subject}:{metric}
-- ARGV[1] = userId, ARGV[2] = rawValue
-- 原子更新成员值并返回该成员的实时百分位
redis.call('ZADD', KEYS[1], ARGV[2], ARGV[1])
local total = redis.call('ZCARD', KEYS[1])
local below = redis.call('ZCOUNT', KEYS[1], '-inf', ARGV[2])
local pct = below / (total + 1) * 100
if pct < 0.1 then pct = 0.1 elseif pct > 99.9 then pct = 99.9 end
return string.format('%.2f', pct)
```

**读写路径与一致性：**

1. 读路径优先级：`student_percentile` 当期快照 → ZSET 实时值 → 常模表估算 → 降级不出数（D1/D2）；
2. 每周日常模刷新完成后，ZSET 按 group 分片全量重建（pipeline 批量 ZADD，500/批）；
3. 夜间对账 Job：随机抽 1% 成员比对 ZSET 百分位与常模表百分位，偏差 > 5 个百分位点的组合自动触发重算并记录 `recompute_log`；
4. ZSET 设置 9 天 TTL（略长于刷新周期），防止僵尸组合占用内存；成员离组由群组成员同步任务负责 ZREM。

```protobuf
message GetSubjectPercentileRequest {
  int64 user_id = 1;
  string subject_code = 2;
  string metric_code = 3;      // 默认 mastery_score
  string group_id = 4;         // 可空，缺省解析该生年级群体
}

message PercentilePoint {
  int64 user_id = 1;
  string subject_code = 2;
  string metric_code = 3;
  double raw_value = 4;
  double percentile = 5;
  int32 grade_band = 6;
  double percentile_delta = 7; // 上期差值，无上期为 0
  bool degraded = 8;           // true=实时通道/上卷降级结果
  string baseline_version = 9;
}
```

## 5. 状态流转设计

### 5.1 常模基准版本状态（隐式状态，由 is_current/version 字段表达）

```text
COMPUTING ──校验通过──→ CURRENT ──新版本发布──→ DEPRECATED ──保留13个月──→ ARCHIVED(清理)
    │
    └──校验失败(validateBaseline)──→ DISCARDED(不落库,仅审计日志+告警,读路径继续用旧版)
```

约束：同一 (group_id, subject_code, metric_code) 下 `is_current=1` 至多一条（G2）；版本切换在单事务内完成 deprecate+activate+Outbox 写入。

### 5.2 聚类模型状态机

```text
TRAINING ──训练完成──→ EVALUATING ──silhouette≥0.25──→ PUBLISHED ──新版本发布──→ SUPERSEDED
                         │                                │
                         │ silhouette<0.25                │ 人工回退(管理端)
                         ↓                                ↓
                      ABORTED(沿用上期)              ROLLED_BACK(恢复上一活跃版,成员映射回滚)
```

### 5.3 群体成员状态

```text
JOIN ──→ ACTIVE ⇄ INACTIVE(连续30天无学习行为自动转;新行为事件唤醒) ──→ LEFT(转班/毕业/注销)
```

上卷统计与 ZSET 仅计入 `ACTIVE` 成员；`peer_group_member.leave_date` 非空的成员在周任务与成员同步任务中统一剔除。

### 5.4 守卫规则总表

| 编号 | 守卫 | 违反后果 |
| --- | --- | --- |
| G1 | 对外群体统计样本量 ≥ 30 | 拒绝返回，触发上卷（D2） |
| G2 | 同组合 is_current 唯一，版本切换原子 | 双写检测告警，事务回滚 |
| G3 | percentile ∈ [0.1, 99.9] 裁剪；std=0 时同值返回 50 | 计算层兜底，不外抛异常 |
| G4 | 义务教育学生端不返回精确百分位（仅 band+区间） | 序列化层拦截（响应变形） |
| G5 | 家长查询需绑定关系；教师查询需班级归属+DataScope | 54705 / 54706 |
| G6 | 群体上卷仅允许 班级→年级→学校→区域→全国 单向链 | 跨层跳跃/回退直接拒绝（54711） |
| G7 | 聚类分配相似度 ≥ 0.55 才归入 | 标记未分类，不强行归类 |
| G8 | 相似学习者聚合输出要求池内 ≥ 5 人；个体身份不出栈 | 聚合结论为空 + 代码评审红线 |
| G9 | 直方图对外桶计数 < 5 时与相邻桶合并（k-匿名） | 序列化层自动合并 |

## 7. 事件设计（Outbox）

事件统一走 `peer.domain.events` Topic，信封复用《学习行为事件标准化 Schema 注册中心》的通用信封（event_id/occurred_at/producer/version/payload），生产侧与业务写入同事务落 Outbox 表。

| 事件 | 触发时机 | 载荷要点 | 消费方（幂等键） |
| --- | --- | --- | --- |
| PercentileUpdated | 周快照生成/实时通道首次计算 | userId, subjectCode, metricCode, percentile, gradeBand, delta, period, degraded | 学情分析（event_id）、家长报告聚合（event_id）、学习数据看板（event_id）、学习报告生成服务（event_id+period 去重） |
| RelativeStrengthDiagnosed | 诊断完成（周） | userId, strengths[], weaknesses[], balanceIndex | 个性化推荐引擎（event_id）、薄弱点识别服务（event_id） |
| BaselineRefreshed | 新版本常模生效 | groupId, subjectCode, metricCode, version, sampleSize | 推荐解释引擎（缓存失效）、管理后台看板（物化视图刷新） |
| ClusterAssigned | 聚类分配完成（首次/变更） | userId, clusterId, modelVersion, similarity | 个性化推荐引擎、AI 学习伙伴（画像注入） |
| PeerGroupArchived | 群体归档 | groupId, reason, memberCount | 数据看板、存储生命周期管理（下游清理编排） |

消费方统一要求：以 (event_id, consumer) 写去重表后再处理；处理失败进各自重试队列，超过 5 次进死信并告警。

## 10. 合规与隐私红线

1. **双减红线**：义务教育阶段（小学/初中）不得以任何形式公开展示排名与榜单；精确百分位仅学生本人、绑定家长、任课教师三类主体可见（G4/§4.1.1 响应变形）；
2. 学生端展示策略：义务教育段自动降档为五级 band + ±10 百分位模糊区间；高中段可展示精确百分位；
3. 最小样本量 30 为硬门槛（G1），不足时只允许向上聚合，禁止返回小群体统计；
4. 群体规模一律区间化返回（"30-50"/"10000+"），禁止暴露精确成员数（防成员枚举攻击面）；
5. 相似学习者功能仅输出聚合结论（池 ≥ 5 人，G8），任何接口/日志/事件不携带同伴个体标识；
6. 禁止个体指向型对比话术（"超过同桌""比 XX 同学强"）；统一使用成长型表述（"较上期 +4.3"优先于"超过全国 72% 同龄人"）；
7. 区域层级统计最小必要原则：学生/家长端默认全国·年级层；区域层数据仅管理端与授权教研角色可见；
8. 百分位快照与常模基准保留 13 个月（覆盖两个完整学年支持同比），到期归档，年度聚合永久保留；
9. 群体统计不向第三方共享明细；管理端导出群体数据需二级审批且输出脱敏（无个体行）；
10. 对外直方图经 k-匿名校验：任一桶计数 < 5 与相邻桶合并后再返回（G9）。
