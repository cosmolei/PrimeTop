## 1. 概述

### 1.1 背景

拍题答疑是 PrimeTop 学生端使用频率最高的功能之一。设计文档 §6.3 与 §9.5 定义了整体功能目标与交互思路，docs2 中已有以下底层模块的详细设计：

| 已有模块 | 覆盖范围 |
|----------|----------|
| 客户端-拍照图像采集与预处理引擎 | 相机取景、拍照、裁剪、旋转、增强、压缩 |
| 拍照识题多题检测与选择交互引擎 | 多题检测、题目区域框选、用户选择 |
| 客户端-题目展示与答题交互组件库 | 通用题目渲染、答题收集组件 |

但上述模块之间缺乏**端到端的页面级编排**——即用户从首页点击"拍照答疑"入口到最终获得解析结果并执行后续操作（加入错题本、同类题练习等）的完整页面流、导航架构、状态管理和交互细节。

本文档补齐这一层，为开发人员提供可直接编码的页面架构蓝图。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 最少步骤触达解析 | 从首页入口到看到解析结果 ≤ 3 步（拍照 → 选题 → 查看解析） |
| 快速重拍重试 | 任何步骤允许回退，重拍 ≤ 1 步操作 |
| 渐进式答案展示 | 默认先展示思路提示，用户主动展开完整步骤 |
| 操作零思考 | 底部操作栏固定，核心操作一步到位 |
| 全学段适配 | 交互复杂度根据学段自动调整（幼儿/小学简化、高中完整） |
| 弱网容错 | 上传失败支持自动重试，离线时缓存图片待恢复后重传 |

- 点击关闭：pop 回首页

```dart
class CameraPage extends StatefulWidget {
  const CameraPage({super.key});

  @override
  State<CameraPage> createState() => _CameraPageState();
}

class _CameraPageState extends State<CameraPage> {
  CameraController? _controller;
  bool _isFlashOn = false;
  CameraState _state = CameraState.initializing;

  @override
  void initState() {
    super.initState();
    _initCamera();
  }

  Future<void> _initCamera() async {
    final cameras = await availableCameras();
    final rearCamera = cameras.firstWhere(
      (c) => c.lensDirection == CameraLensDirection.back,
      orElse: () => cameras.first,
    );
    _controller = CameraController(
      rearCamera,
      ResolutionPreset.high,
      enableAudio: false,
    );
    await _controller!.initialize();
    if (mounted) setState(() => _state = CameraState.ready);
  }

  Future<void> _onCapture() async {
    if (_controller == null || !_controller!.value.isInitialized) return;
    final XFile file = await _controller!.takePicture();
    if (!mounted) return;
    // 跳转图片编辑页
    final result = await Navigator.push<ImageEditResult>(
      context,
      MaterialPageRoute(
        builder: (_) => ImageEditPage(imagePath: file.path),
      ),
    );
    if (result != null) {
      _navigateToQuestionFlow(result);
    }
  }

  void _navigateToQuestionFlow(ImageEditResult editResult) {
    Navigator.push(
      context,
      MaterialPageRoute(
        builder: (_) => QuestionSelectPage(
          imageBytes: editResult.processedImageBytes,
          originalImagePath: editResult.originalPath,
        ),
      ),
    );
  }
}

enum CameraState { initializing, ready, qualityWarning }
```

```dart
class _QuestionSelectPageState extends State<QuestionSelectPage> {
  QuestionSelectState _state = QuestionSelectState.detecting;
  List<DetectedQuestion> _detectedQuestions = [];
  final Set<int> _selectedIndices = {};

  @override
  void initState() {
    super.initState();
    _detectQuestions();
  }

  Future<void> _detectQuestions() async {
    setState(() => _state = QuestionSelectState.detecting);

    try {
      final result = await _questionDetectService.detect(
        imageBytes: widget.imageBytes,
        timeout: const Duration(seconds: 8),
      );

      _detectedQuestions = result.questions;

      if (_detectedQuestions.isEmpty) {
        // 未检测到题目 → 提示用户手动框选或重拍
        setState(() => _state = QuestionSelectState.detectFailed);
        _showNoQuestionDialog();
      } else if (_detectedQuestions.length == 1) {
        // 单题自动跳过选择，直接解析
        _navigateToAnalysis([0]);
      } else {
        // 多题默认全选
        _selectedIndices.addAll(
          List.generate(_detectedQuestions.length, (i) => i),
        );
        setState(() => _state = QuestionSelectState.selecting);
      }
    } on TimeoutException {
      setState(() => _state = QuestionSelectState.detectFailed);
      _showRetryDialog('识别超时，请检查网络后重试');
    } on ApiException catch (e) {
      setState(() => _state = QuestionSelectState.detectFailed);
      _showRetryDialog('识别失败：${_friendlyError(e)}');
    }
  }

  void _navigateToAnalysis(List<int> indices) {
    final selected = indices
        .map((i) => _detectedQuestions[i])
        .toList();

    Navigator.pushReplacement(
      context,
      MaterialPageRoute(
        builder: (_) => AnalysisLoadingPage(
          questions: selected,
          sourceImageBytes: widget.imageBytes,
        ),
      ),
    );
  }
}

/// 单个检测到的题目
class DetectedQuestion {
  /// 题目在原图中的边界框（归一化坐标）
  final Rect boundingBox;

  /// 题目裁剪图片字节
  final Uint8List croppedImageBytes;

  /// OCR 预览文字（前 100 字）
  final String ocrSnippet;

  /// 服务端返回的题目临时 ID
  final String tempQuestionId;
```

#### 2.4.3 流水线状态模型

```dart
/// 解析流水线步骤
enum AnalysisPipelineStep {
  uploading,      // 上传图片到服务端
  ocrRecognizing, // OCR 文字识别
  aiAnalyzing,    // AI 分析解题思路
  generating,     // 生成解析结果
}

/// 解析流水线状态
class AnalysisPipelineState {
  final AnalysisPipelineStep currentStep;
  final int currentQuestionIndex;  // 当前解析第几题（从0开始）
  final int totalQuestions;

  /// 各步骤进度 (0.0 ~ 1.0)
  final Map<AnalysisPipelineStep, double> stepProgress;

  const AnalysisPipelineState({
    required this.currentStep,
    required this.currentQuestionIndex,
    required this.totalQuestions,
    this.stepProgress = const {},
  });

  String get stepLabel {
    switch (currentStep) {
      case AnalysisPipelineStep.uploading:
        return '上传图片';
      case AnalysisPipelineStep.ocrRecognizing:
        return '识别文字';
      case AnalysisPipelineStep.aiAnalyzing:
        return 'AI 分析解题思路';
      case AnalysisPipelineStep.generating:
        return '生成解析';
    }
  }

  double get overallProgress {
    final questionBase = currentQuestionIndex / totalQuestions;
    final stepContribution = stepProgress[currentStep] ?? 0.0 / totalQuestions;
    return (questionBase + stepContribution).clamp(0.0, 1.0);
  }
}
```

#### 2.4.4 后端 API 对接

解析请求使用 SSE（Server-Sent Events）流式推送进度，避免轮询：

```dart
/// 调用解析 API
Future<void> _startAnalysis() async {
  final sseSource = await _analysisService.analyzeStream(
    questions: widget.questions,
    sourceImageBytes: widget.sourceImageBytes,
    userGrade: _userProfile.grade,
    userTextbook: _userProfile.textbookVersion,
  );

  sseSource.listen(
    (event) {
      switch (event.type) {
        case 'pipeline_progress':
          // 更新流水线步骤进度
          setState(() => _pipelineState = AnalysisPipelineState(
            currentStep: _parseStep(event.data['step']),
            currentQuestionIndex: event.data['questionIndex'] ?? 0,
            totalQuestions: widget.questions.length,
            stepProgress: _pipelineState.stepProgress,
          ));
          break;

        case 'question_result':
          // 单题解析完成，累积结果
          _completedResults.add(QuestionAnalysisResult.fromJson(event.data));
          break;

        case 'complete':
          // 全部完成，跳转结果页
          _navigateToResults();
          break;

        case 'error':
          _handleAnalysisError(event.data);
          break;
      }
    },
    onError: (error) => _handleAnalysisError(error),
    onDone: () {
      if (_completedResults.isNotEmpty) {
        _navigateToResults();
      }
    },
  );
}
```

#### 2.5.5 渐进式答案展示策略

这是拍题答疑最核心的交互设计。目标：**默认不直接展示完整答案，引导学生先思考。**

```dart
/// 答案展开层级
enum AnswerRevealLevel {
  hintOnly,        // 仅展示思路提示（默认）
  stepsCollapsed,  // 展示步骤标题，内容折叠
  stepsExpanded,   // 全部步骤展开（用户主动点击）
}

class ProgressiveRevealController extends ChangeNotifier {
  AnswerRevealLevel _level = AnswerRevealLevel.hintOnly;

  AnswerRevealLevel get level => _level;

  void revealNext() {
    switch (_level) {
      case AnswerRevealLevel.hintOnly:
        _level = AnswerRevealLevel.stepsCollapsed;
        break;
      case AnswerRevealLevel.stepsCollapsed:
        _level = AnswerRevealLevel.stepsExpanded;
        break;
      case AnswerRevealLevel.stepsExpanded:
        break; // 已经全部展开
    }
    notifyListeners();
  }
}
```

**学段差异**：

| 学段 | 默认展开级别 | 说明 |
|------|-------------|------|
| 小学低年级 (1-3) | `stepsCollapsed` | 直接展示步骤框架，降低等待焦虑 |
| 小学高年级 (4-6) | `hintOnly` | 先给思路，引导思考 |
| 初中 | `hintOnly` | 先给思路，强调方法 |
| 高中 | `hintOnly` | 先给思路，鼓励独立推导 |

## 3. 跨页面状态管理

### 3.1 状态管理架构

整个拍题答疑流程跨越 5+ 个页面，需要一个流程级别的状态管理器来协调数据传递和生命周期。

```dart
/// 拍题答疑全流程状态管理器
class PhotoAnalysisFlowController extends ChangeNotifier {
  // ── 流程步骤 ──
  PhotoAnalysisStep _currentStep = PhotoAnalysisStep.camera;

  // ── 各步骤产出 ──
  String? _capturedImagePath;              // P1 产出
  ImageEditResult? _editResult;             // P2 产出
  List<DetectedQuestion> _detectedQuestions = []; // P3 产出
  List<QuestionAnalysisResult> _analysisResults = []; // P4 产出

  // ── 错误与重试 ──
  int _retryCount = 0;
  static const int _maxRetryCount = 3;

  PhotoAnalysisStep get currentStep => _currentStep;

  void advanceTo(PhotoAnalysisStep step) {
    _currentStep = step;
    notifyListeners();
  }

  void setCapturedImage(String path) {
    _capturedImagePath = path;
    advanceTo(PhotoAnalysisStep.editing);
  }

  void setEditResult(ImageEditResult result) {
    _editResult = result;
    advanceTo(PhotoAnalysisStep.detecting);
  }

  void setDetectedQuestions(List<DetectedQuestion> questions) {
    _detectedQuestions = questions;
    if (questions.length == 1) {
      advanceTo(PhotoAnalysisStep.analyzing);
    } else {
      advanceTo(PhotoAnalysisStep.selecting);
    }
  }

  void setAnalysisResults(List<QuestionAnalysisResult> results) {
    _analysisResults = results;
    advanceTo(PhotoAnalysisStep.result);
  }

  /// 重试当前步骤
  bool canRetry() => _retryCount < _maxRetryCount;

  void incrementRetry() {
    _retryCount++;
    notifyListeners();
  }

  /// 重置整个流程（重拍）
  void reset() {
    _currentStep = PhotoAnalysisStep.camera;
    _capturedImagePath = null;
    _editResult = null;
    _detectedQuestions = [];
    _analysisResults = [];
    _retryCount = 0;
    notifyListeners();
  }
}

enum PhotoAnalysisStep {
  camera,      // P1 拍照
  editing,     // P2 图片编辑
  detecting,   // P3 题目检测
  selecting,   // P3 用户选择
  analyzing,   // P4 AI 解析
  result,      // P5 展示结果
}
```

```dart
  /// 从编辑页 → 题目选择页（pushReplacement 保持栈深度）
  static void toQuestionSelect(
    BuildContext context,
    ImageEditResult editResult,
  ) {
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(
        builder: (_) => QuestionSelectPage(
          imageBytes: editResult.processedImageBytes,
          originalImagePath: editResult.originalPath,
        ),
      ),
    );
  }

  /// 从题目选择页 → 解析加载页（pushReplacement）
  static void toAnalysisLoading(
    BuildContext context,
    List<DetectedQuestion> selectedQuestions,
    Uint8List sourceImageBytes,
  ) {
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(
        builder: (_) => AnalysisLoadingPage(
          questions: selectedQuestions,
          sourceImageBytes: sourceImageBytes,
        ),
      ),
    );
  }

  /// 从解析加载页 → 解析结果页（pushReplacement）
  static void toAnalysisResult(
    BuildContext context,
    List<QuestionAnalysisResult> results,
  ) {
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(
        builder: (_) => AnalysisResultPage(results: results),
      ),
    );
  }

  /// 从结果页 → 追问对话页（push，保留结果页）
  static void toFollowUpChat(
    BuildContext context,
    FollowUpChatArguments args,
  ) {
    Navigator.push(
      context,
      MaterialPageRoute(
        builder: (_) => FollowUpChatPage(arguments: args),
      ),
    );
  }

  /// 从结果页 → 同类题练习页（push，保留结果页）
  static void toSimilarQuestions(
    BuildContext context,
    List<String> similarQuestionIds,
    String sourceQuestionId,
  ) {
    Navigator.push(
      context,
      MaterialPageRoute(
        builder: (_) => SimilarQuestionPage(
          similarQuestionIds: similarQuestionIds,
          sourceQuestionId: sourceQuestionId,
        ),
      ),
    );
  }

  /// 退出整个流程回到首页
  static void exitToHome(BuildContext context) {
    Navigator.popUntil(context, (route) => route.isFirst);
  }
}
```

**页面栈深度控制**：

```
首页 → CameraPage → (replace) ImageEditPage → (replace) QuestionSelectPage
      → (replace) AnalysisLoadingPage → (replace) AnalysisResultPage

最大栈深度 = 2（首页 + 当前页）

进入追问/同类题时栈深度 = 3（首页 + 结果页 + 子页面）
```

### 4.2 弱网策略

```dart
class NetworkAwareInterceptor {
  /// 超时配置
  static const Duration connectTimeout = Duration(seconds: 10);
  static const Duration uploadTimeout = Duration(seconds: 30);
  static const Duration analysisTimeout = Duration(seconds: 45);

  /// 网络质量检测
  static Future<NetworkQuality> checkQuality() async {
    final connectivityResult = await Connectivity().checkConnectivity();
    if (connectivityResult.contains(ConnectivityResult.none)) {
      return NetworkQuality.offline;
    }
    if (connectivityResult.contains(ConnectivityResult.mobile)) {
      // 可选: 通过小文件下载测试实际速度
      return NetworkQuality.medium;
    }
    return NetworkQuality.good;
  }
}

enum NetworkQuality { offline, poor, medium, good }
```

### 4.3 图片上传重试

```dart
class ResilientImageUploader {
  final int maxRetries;
  final Duration retryDelay;

  Future<UploadResult> upload(Uint8List imageBytes, {String? path}) async {
    int attempt = 0;
    while (attempt < maxRetries) {
      try {
        final result = await _doUpload(imageBytes, path: path);
        return result;
      } on SocketException {
        attempt++;
        if (attempt >= maxRetries) rethrow;
        await Future.delayed(retryDelay * attempt); // 指数退避
      } on TimeoutException {
        attempt++;
        if (attempt >= maxRetries) rethrow;
        await Future.delayed(retryDelay * attempt);
      }
    }
    throw UploadException('上传失败，已重试 $maxRetries 次');
  }
}
```

```dart
class GradeStrategy {
  final GradeLevel level;

  GradeStrategy(this.level);

  /// 是否显示多题选择页
  bool get showQuestionSelection {
    switch (level) {
      case GradeLevel.kindergarten:
      case GradeLevel.primaryLow:
        return false; // 自动选第一题
      default:
        return true;
    }
  }

  AnswerRevealLevel get defaultRevealLevel {
    switch (level) {
      case GradeLevel.primaryLow:

    }
  }

      case GradeLevel.primaryHigh:
        return 3;
      default:
        return 5;
    }
```
