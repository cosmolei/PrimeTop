# 服务端-学生学习迁移能力检测与跨情境知识应用评估引擎-详细设计

## 1. 概述

### 1.1 模块定位

学生学习迁移能力检测与跨情境知识应用评估引擎（Learning Transfer Detection & Cross-Context Application Assessment Engine，简称 LT-Engine）是 PrimeTop 平台核心教育评估组件之一。

**学习迁移（Learning Transfer）** 是教育心理学中的核心概念——指学生将在某一情境中学到的知识、技能或方法，应用到**新的、不同的情境**中的能力。这是衡量"真正理解"与"机械记忆"的关键分水岭。

本引擎负责：
1. **检测迁移事件**：从学生答题行为中识别出"跨情境知识应用"事件
2. **量化迁移能力**：为每位学生构建多维度的迁移能力画像
3. **诊断迁移障碍**：识别学生在哪些知识域间存在"迁移阻断"
4. **生成迁移训练**：智能编排跨情境练习，促进学生举一反三能力的发展
5. **追踪迁移发展**：长期追踪学生迁移能力的成长轨迹

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 迁移事件感知 | 实时消费答题事件流，识别跨章节/跨题型/跨情境的应用行为 |
| 迁移能力建模 | 构建学生跨知识域、跨题型的迁移能力矩阵 |
| 迁移阻断诊断 | 检测"会做A题但不会做等价B题"的知识应用障碍 |
| 跨情境题组编排 | 生成检测迁移能力的变式题组与跨情境练习 |
| 教学建议生成 | 为AI辅导对话、学习规划等下游模块提供迁移能力数据支撑 |

### 1.3 依赖关系

```
上游输入：
├── 练习答题事件流（来自 答题记录服务 / 练习测评会话服务）
├── 知识点图谱与关联关系（来自 知识图谱服务 / 知识点体系服务）
├── 题目元数据与知识点标注（来自 题库服务）
├── 学生能力画像（来自 知识追踪模型引擎 / 用户学习画像服务）
└── 学习行为序列（来自 学习行为事件流处理引擎）

下游消费：
├── AI辅导对话 → 根据迁移能力调整讲解策略
├── 题目智能推荐 → 根据迁移薄弱点推荐跨情境练习
├── 学情分析报告 → 输出迁移能力维度分析
├── 学习规划服务 → 将迁移训练纳入学习计划
├── 错题整理模块 → 标注迁移阻断类错题
└── 家长端学情报告 → 展示举一反三能力评估
```

### 1.4 设计原则

1. **教育科学性**：迁移检测基于 Bransford 转移理论、Salomon & Perkins 的"低路迁移/高路迁移"框架
2. **非侵入式**：不需要专门的"迁移测试"，而是从日常答题行为中提取迁移信号
3. **渐进精确**：冷启动阶段使用启发式规则，随着数据积累逐步引入模型化判断
4. **可解释**：每个迁移能力评分必须附带具体的证据题组和解释

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 迁移能力档案（TransferProfile）

```java
/**
 * 学生迁移能力综合档案
 * 每位学生维护一份，随答题行为持续更新
 */
@Data
@TableName("lt_transfer_profile")
public class TransferProfile {
    /** 主键ID */
    private Long id;
    
    /** 学生用户ID */
    private Long studentId;
    
    /** 综合迁移能力指数 [0-100] */
    private Double transferIndex;
    
    /** 低路迁移得分 [0-100]（自动化、近迁移） */
    private Double lowRoadScore;
    
    /** 高路迁移得分 [0-100]（反思性、远迁移） */
    private Double highRoadScore;
    
    /** 跨章节迁移得分 [0-100] */
    private Double crossChapterScore;
    
    /** 跨学科迁移得分 [0-100] */
    private Double crossSubjectScore;
    
    /** 跨题型迁移得分 [0-100] */
    private Double crossQuestionTypeScore;
    
    /** 迁移能力等级 */
    private TransferLevel level;
    
    /** 检测到的迁移事件总数 */
    private Integer totalTransferEvents;
    
    /** 检测到的迁移阻断总数 */
    private Integer totalTransferBlocks;
    
    /** 最近一次评估时间 */
    private LocalDateTime lastAssessedAt;
    
    /** 创建时间 */
    private LocalDateTime createdAt;
    
    /** 版本号（乐观锁） */
    private Integer version;
}
```

```java
public enum TransferLevel {
    NOVICE("初学者", 0, 20),      // 机械记忆为主，难以迁移
    APPRENTICE("初通者", 20, 40),  // 近迁移偶尔成功
    ADAPTER("适应者", 40, 60),     // 近迁移稳定，偶发远迁移
    TRANSFERER("迁移者", 60, 80),  // 近迁移熟练，远迁移时有发生
    MASTER("通达者", 80, 101);     // 近远迁移均熟练，能创造性应用
    
    private final String label;
    private final int minScore;
    private final int maxScore;
}
```


```java
public enum TransferType {
    /** 同知识点不同题型迁移 */
    CROSS_QUESTION_TYPE,
    /** 同学科跨章节迁移 */
    CROSS_CHAPTER,
    /** 跨学科迁移（如物理数学方法互用） */
    CROSS_SUBJECT,
    /** 理论到应用迁移（课本知识解决实际问题） */
    THEORY_TO_APPLICATION,
    /** 方法迁移（同一解题方法应用到不同题目） */
    METHOD_TRANSFER,
    /** 类比迁移（通过类比将熟悉域知识映射到新域） */
    ANALOGY_TRANSFER
}

public enum TransferDistance {
    /** 近迁移：高度相似的情境 */
    NEAR,
    /** 中迁移：有一定相似性但需要改编 */
    MEDIUM,
    /** 远迁移：表面差异大但深层结构相同 */
    FAR
}

public enum TransferResult {
    /** 成功迁移：在新情境中正确应用了知识 */
    SUCCESS,
    /** 部分迁移：方向正确但执行有误 */
    PARTIAL,
    /** 迁移失败：未能将已有知识迁移到新情境 */
    FAILURE,
    /** 负迁移：旧知识干扰了新问题的解决 */
    NEGATIVE
}
```

#### 2.1.3 迁移阻断记录（TransferBlock）

```java
/**
 * 迁移阻断：学生具备源知识点能力，但在目标情境中失败
 * 表明"会A但不会等价的B"，是需要重点干预的信号
 */
@Data
@TableName("lt_transfer_block")
public class TransferBlock {
    private Long id;
    
    /** 学生用户ID */
    private Long studentId;
    
    /** 源知识点ID */
    private Long sourceKpId;
    
    /** 目标知识点ID */
    private Long targetKpId;
    
    /** 阻断类型 */
    private BlockType blockType;
    
    /** 源知识点掌握度 [0-1]（来自知识追踪模型） */
    private Double sourceMastery;
    
    /** 目标知识点掌握度 [0-1] */
    private Double targetMastery;
    
    /** 掌握度差异阈值 */
    private Double masteryGap;
    
    /** 检测到的失败次数 */
    private Integer failureCount;
    
    /** 最近一次失败时间 */
    private LocalDateTime lastFailureAt;
    
    /** 状态 */
    private BlockStatus status;
    
    /** 建议干预策略ID */
    private String recommendedStrategyId;
    
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}

public enum BlockType {
    /** 题型差异阻断：同一知识点换题型就不会 */
    QUESTION_TYPE_GAP,
    /** 情境差异阻断：换一个生活情境就不会 */
    CONTEXT_GAP,
    /** 表征差异阻断：图形↔文字↔符号之间转换困难 */
    REPRESENTATION_GAP,
    /** 方法迁移阻断：会用方法A但不会用等价方法B */
    METHOD_GAP,
    /** 跨学科阻断：数学方法不会用到物理中 */
    SUBJECT_BOUNDARY
}

public enum BlockStatus {
    ACTIVE,      // 活跃阻断，需干预
    MONITORING,  // 已干预，监测中
    RESOLVED,    // 已解决
    ARCHIVED     // 已归档
}
```

```java
/**

    /** 包含的题目ID列表（JSON数组） */
    private String questionIds;
    
    /** 题目数量 */
    private Integer questionCount;
    
    /** 题组难度均值 */
    private Double avgDifficulty;
    
    /** 变式维度列表（JSON） */
    private String variationDimensions;
    
    /** 质量评分 */
    private Double qualityScore;
    
    /** 状态 */
    private SetStatus status;
    
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}

public enum SetDesignGoal {
    /** 迁移检测：判断学生是否已具备迁移能力 */

    /** 迁移训练：通过变式练习促进迁移 */
    TRAINING,
    /** 迁移诊断：精确定位迁移障碍点 */
    DIAGNOSIS,
    /** 迁移巩固：在掌握后强化跨情境应用 */
```

### 3.1 接口总览

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |

### 4.1 迁移事件检测流程（核心）

答题事件触发后，异步执行迁移分析。检测分为三层：

```
答题事件 → 事件接收器 → 三层迁移检测管线 → 结果聚合 → 档案更新 + 下游通知
                           │
                ┌──────────┼──────────┐
                ▼          ▼          ▼
          第一层       第二层       第三层
         规则匹配     图谱推理     行为序列分析
```

#### 第一层：规则匹配检测

基于预定义的迁移规则库进行快速匹配。

```java
/**
 * 第一层：规则匹配迁移检测器
 * 检查当前答题行为是否匹配预定义的迁移模式
 */
@Component
public class RuleBasedTransferDetector {
    
    /**
     * 迁移规则库（按学科分组）
     * 规则定义了哪些知识点对之间存在迁移关系
     */
    @Autowired
    private TransferRuleRepository ruleRepository;
    
    /**
     * 检测入口
     */
    public List<TransferEvent> detect(AnswerEvent event, StudentContext context) {
        List<TransferEvent> events = new ArrayList<>();
        
        // 获取当前题目的知识点标注
        Set<Long> questionKpIds = event.getKnowledgePointIds();
        
        // 获取该学生历史掌握的知识点（mastery > 0.7）
        Set<Long> masteredKpIds = context.getMasteredKnowledgePoints();
        
        // 对每个题目知识点，检查是否存在跨情境迁移
        for (Long questionKpId : questionKpIds) {
            // 情况1：题目知识点与学生已掌握知识点属于"迁移关联对"
            List<TransferRule> rules = ruleRepository.findByTargetKpId(questionKpId);
            for (TransferRule rule : rules) {
                if (masteredKpIds.contains(rule.getSourceKpId())) {
                    // 满足迁移前置条件，判断结果
                    TransferEvent te = buildEvent(event, rule, context);
                    events.add(te);
                }
            }
            
            // 情况2：同一知识点，但题型/情境与历史答题不同
            List<AnswerRecord> history = context.getHistoryByKp(questionKpId);
            if (!history.isEmpty()) {
                TransferType detectedType = detectVariation(event, history);
                if (detectedType != null) {
                    TransferEvent te = buildVariationEvent(event, detectedType, context);
                    events.add(te);
                }
            }
        }
        
        return events;
    }
    
    /**
     * 检测变式：同知识点，不同题型/情境
     */
    private TransferType detectVariation(AnswerEvent event, List<AnswerRecord> history) {
        String currentType = event.getQuestionType();
        String currentContext = event.getQuestionContext();
        
        Set<String> historicalTypes = history.stream()
            .map(AnswerRecord::getQuestionType)
            .collect(Collectors.toSet());
        Set<String> historicalContexts = history.stream()
            .map(AnswerRecord::getQuestionContext)
            .collect(Collectors.to_set());
        
        // 题型变式检测
        if (!historicalTypes.contains(currentType) && historicalTypes.size() > 0) {
            return TransferType.CROSS_QUESTION_TYPE;
        }
        
        // 情境变式检测
        if (!historicalContexts.contains(currentContext) && historicalContexts.size() > 0) {
            return TransferType.THEORY_TO_APPLICATION;
        }
        
        return null;
    }
}
```

#### 第二层：知识图谱推理检测

利用知识图谱的结构关系，检测隐式迁移。

```java
/**
 * 第二层：基于知识图谱的迁移推理
 * 利用知识点间的结构关系（前置、并列、类比）推断迁移
 */
@Component
public class GraphBasedTransferDetector {
    
    @Autowired
    private KnowledgeGraphClient graphClient;
    
    /**
     * 知识点关系类型 → 迁移类型映射
     */
    private static final Map<String, TransferDistance> RELATION_MAP = Map.of(
        "PREREQUISITE", TransferDistance.NEAR,     // 前置知识 → 近迁移
        "SIBLING", TransferDistance.NEAR,           // 同级并列 → 近迁移
        "ANALOGY", TransferDistance.MEDIUM,         // 类比关系 → 中迁移
        "CROSS_DOMAIN", TransferDistance.FAR,       // 跨域关联 → 远迁移
        "ABSTRACT_LINK", TransferDistance.FAR       // 抽象关联 → 远迁移
    );
    
    public List<TransferEvent> detect(AnswerEvent event, StudentContext context) {
        List<TransferEvent> events = new ArrayList<>();
        
        for (Long kpId : event.getKnowledgePointIds()) {
            // 在图谱中查找该知识点的关联节点
            List<KpRelation> relations = graphClient.findRelations(kpId, 2); // 2跳以内
            
            for (KpRelation rel : relations) {
                Long relatedKpId = rel.getTargetKpId();
                
                // 学生在关联知识点上有历史答题记录
                if (context.hasHistoryFor(relatedKpId)) {
                    Double sourceMastery = context.getMastery(relatedKpId);
                    Double targetMastery = context.getMastery(kpId);
                    
                    // 构建迁移事件
                    TransferDistance distance = RELATION_MAP.getOrDefault(
                        rel.getRelationType(), TransferDistance.MEDIUM);
                    
                    TransferEvent te = new TransferEvent();
                    te.setSourceKnowledgePointId(relatedKpId);
                    te.setTargetKnowledgePointId(kpId);
                    te.setDistance(distance);
                    te.setConfidence(calculateConfidence(sourceMastery, distance, event));
                    te.setResult(determineResult(event.isCorrect(), sourceMastery));
                    events.add(te);
                }
            }
        }
        
        return events;
    }
    
    /**
     * 计算迁移置信度
     * 源知识掌握度越高、迁移距离越远、结果越正确 → 置信度越高
     */
    private Double calculateConfidence(Double sourceMastery, 
                                        TransferDistance distance, 
                                        AnswerEvent event) {
        double masteryWeight = sourceMastery;           // [0, 1]
        double distanceWeight = switch (distance) {     // 近迁移置信度更高
            case NEAR -> 0.9;
            case MEDIUM -> 0.75;
            case FAR -> 0.6;
        };
        double correctnessWeight = event.isCorrect() ? 1.0 : 0.5;
        
        return masteryWeight * distanceWeight * correctnessWeight;
    }
}
```

#### 第三层：行为序列模式检测

分析学生答题序列中的迁移模式。

```java
/**
 * 第三层：答题序列迁移模式分析
 * 检测"连续答不同知识点题目时的迁移表现"
 */
@Component
public class SequenceTransferDetector {
    
    /**
     * 分析同一答题会话内的跨知识点行为
     */
    public List<TransferEvent> detectInSession(
            Long studentId, 
            String sessionId,
            List<AnswerEvent> sessionEvents) {
        
        List<TransferEvent> events = new ArrayList<>();
        
        // 按时间排序
        sessionEvents.sort(Comparator.comparing(AnswerEvent::getTimestamp));
        
        for (int i = 1; i < sessionEvents.size(); i++) {
            AnswerEvent prev = sessionEvents.get(i - 1);
            AnswerEvent curr = sessionEvents.get(i);
            
            // 连续题目考查不同知识点
            if (!Collections.disjoint(prev.getKnowledgePointIds(), curr.getKnowledgePointIds())) {
                continue; // 同知识点，跳过
            }
            
            // 检测是否存在方法迁移
            TransferEvent methodEvent = detectMethodTransfer(prev, curr, studentId);
            if (methodEvent != null) {
                events.add(methodEvent);
            }
        }
        
        return events;
    }
    
    /**
     * 方法迁移检测：两道不同知识点的题目使用了相同解题方法
     */
    private TransferEvent detectMethodTransfer(
            AnswerEvent prev, AnswerEvent curr, Long studentId) {
        
        // 获取两道题目的解题方法标签
        Set<String> prevMethods = questionService.getMethodTags(prev.getQuestionId());
        Set<String> currMethods = questionService.getMethodTags(curr.getQuestionId());
        
        // 交集 = 共同方法
        Set<String> sharedMethods = new HashSet<>(prevMethods);
        sharedMethods.retainAll(currMethods);
        
        if (sharedMethods.isEmpty()) {
            return null;
        }
        
        // 学生在前一道用了某方法，在后一道（不同知识点）也用了相同方法
        TransferEvent event = new TransferEvent();
        event.setStudentId(studentId);
        event.setTransferType(TransferType.METHOD_TRANSFER);
        event.setDistance(TransferDistance.MEDIUM);
        event.setResult(curr.isCorrect() ? TransferResult.SUCCESS : TransferResult.FAILURE);
        event.setConfidence(0.7);
        event.setEvidenceDetail(JSON.toJSONString(Map.of(
            "sharedMethods", sharedMethods,
            "prevQuestion", prev.getQuestionId(),
            "currQuestion", curr.getQuestionId()
        )));
        
        return event;
    }
}
```

### 4.2 迁移能力评分计算

```java
/**
 * 迁移能力综合评分引擎
 */
@Component
public class TransferScoringEngine {
    
    private static final double DECAY_HALF_LIFE_DAYS = 30.0; // 30天半衰期
    
    /**
     * 根据近N条迁移事件重新计算学生迁移能力得分
     */
    public TransferScore calculateScore(Long studentId, List<TransferEvent> recentEvents) {
        if (recentEvents.isEmpty()) {
            return TransferScore.zero();
        }
        
        LocalDateTime now = LocalDateTime.now();
        
        // 按迁移维度分组计算
        double lowRoadScore = calculateDimensionScore(recentEvents, 
            e -> e.getDistance() == TransferDistance.NEAR, now);
        double highRoadScore = calculateDimensionScore(recentEvents, 
            e -> e.getDistance() == TransferDistance.MEDIUM || e.getDistance() == TransferDistance.FAR, now);
        double crossChapterScore = calculateDimensionScore(recentEvents, 
            e -> e.getTransferType() == TransferType.CROSS_CHAPTER, now);
        double crossSubjectScore = calculateDimensionScore(recentEvents, 
            e -> e.getTransferType() == TransferType.CROSS_SUBJECT, now);
        double crossQuestionTypeScore = calculateDimensionScore(recentEvents, 
            e -> e.getTransferType() == TransferType.CROSS_QUESTION_TYPE, now);
        
        // 加权综合得分
        double transferIndex = 
            lowRoadScore * 0.20 +
            highRoadScore * 0.30 +
            crossChapterScore * 0.20 +
            crossSubjectScore * 0.15 +
            crossQuestionTypeScore * 0.15;
        
        // 确定等级
        TransferLevel level = TransferLevel.fromScore(transferIndex);
        
        return TransferScore.builder()
            .transferIndex(Math.round(transferIndex * 100) / 100.0)
            .lowRoadScore(lowRoadScore)
            .highRoadScore(highRoadScore)
            .crossChapterScore(crossChapterScore)
            .crossSubjectScore(crossSubjectScore)
            .crossQuestionTypeScore(crossQuestionTypeScore)
            .level(level)
            .build();
    }
    
    /**
     * 计算单维度得分
     * 考虑：成功率 × 置信度 × 时间衰减
     */
    private double calculateDimensionScore(List<TransferEvent> events, 
                                            Predicate<TransferEvent> filter,
                                            LocalDateTime now) {
        List<TransferEvent> filtered = events.stream()
            .filter(filter)
            .collect(Collectors.toList());
        
        if (filtered.isEmpty()) {
            return 0.0;
        }
        
        double weightedScore = 0.0;
        double totalWeight = 0.0;
        
        for (TransferEvent event : filtered) {
            // 时间衰减权重
            long daysAgo = ChronoUnit.DAYS.between(event.getOccurredAt(), now);
            double timeWeight = Math.pow(0.5, daysAgo / DECAY_HALF_LIFE_DAYS);
            
            // 置信度权重
            double confidence = event.getConfidence();
            
            // 结果分数
            double resultScore = switch (event.getResult()) {
                case SUCCESS -> 1.0;
                case PARTIAL -> 0.5;
                case FAILURE -> 0.0;
                case NEGATIVE -> -0.3; // 负迁移扣分
            };
            
            // 距离加成（远迁移成功得分更高）
            double distanceBonus = switch (event.getDistance()) {
                case NEAR -> 1.0;
                case MEDIUM -> 1.2;
                case FAR -> 1.5;
            };
            
            double weight = timeWeight * confidence;
            weightedScore += resultScore * distanceBonus * weight;
            totalWeight += weight;
        }
        
        double rawScore = totalWeight > 0 ? weightedScore / totalWeight : 0;
        
        // 归一化到 [0, 100]
        return Math.max(0, Math.min(100, rawScore * 100));
    }
}
```

```java
/**
 * 迁移阻断检测器
 * 核心逻辑：学生源知识点掌握度高，但目标知识点掌握度低 → 迁移阻断

@Component
public class TransferBlockDetector {
    
    private static final double MASTERY_THRESHOLD = 0.70;    // 掌握度阈值
    private static final double BLOCK_GAP_THRESHOLD = 0.25;  // 掌握度差异阈值
    
    /**
     * 检测迁移阻断
     * 定时任务 + 事件驱动
     */
    public void detectBlocks(Long studentId) {
        // 获取学生所有知识点的当前掌握度
        Map<Long, Double> masteryMap = knowledgeTrackingService.batchGetMastery(studentId);
        
        // 获取所有迁移关联规则

        for (TransferRule rule : allRules) {
            Long sourceKp = rule.getSourceKpId();
            Long targetKp = rule.getTargetKpId();
            
            Double sourceMastery = masteryMap.get(sourceKp);
            Double targetMastery = masteryMap.get(targetKp);
```

### 5.1 自动题组生成算法

```java
/**
 * 跨情境题组自动生成器
 * 为给定知识点生成多维度变式题组
 */
@Component
public class CrossContextSetGenerator {
    
    /**
     * 生成跨情境题组
     * 
     * @param coreKpId 核心知识点
     * @param studentId 目标学生（用于个性化）
     * @param goal 题组目标
     */
    public CrossContextQuestionSet generate(Long coreKpId, Long studentId, SetDesignGoal goal) {
        // 1. 获取知识点元数据
        KnowledgePoint kp = knowledgePointService.getById(coreKpId);
        
        // 2. 从题库中获取该知识点的所有题目
        List<Question> candidates = questionService.findByKpId(coreKpId);
        
        // 3. 按变式维度分组
        Map<String, List<Question>> byType = candidates.stream()
            .collect(Collectors.groupingBy(Question::getQuestionType));
        Map<String, List<Question>> byContext = candidates.stream()
            .collect(Collectors.groupingBy(Question::getContextTag));
        Map<String, List<Question>> byDifficulty = candidates.stream()
            .collect(Collectors.groupingBy(q -> difficultyBand(q.getDifficulty())));
        
        // 4. 根据目标选择变式策略
        VariationStrategy strategy = selectStrategy(goal, studentId, coreKpId);
        
        // 5. 选题组卷
        List<Question> selected = strategy.select(
            candidates, byType, byContext, byDifficulty, studentId);
        
        // 6. 构建题组
        CrossContextQuestionSet set = new CrossContextQuestionSet();
        set.setName(kp.getName() + " 跨情境训练");
        set.setCoreKnowledgePointId(coreKpId);
        set.setSubject(kp.getSubject());
        set.setDesignGoal(goal);
        set.setQuestionIds(JSON.toJSONString(
            selected.stream().map(Question::getId).collect(Collectors.toList())));
        set.setQuestionCount(selected.size());
        set.setVariationDimensions(JSON.toJSONString(strategy.getDimensions()));
        set.setAvgDifficulty(calculateAvg(selected));
        set.setStatus(SetStatus.ACTIVE);
        
        return set;
    }
    
    /**
     * 变式策略选择
     */
    private VariationStrategy selectStrategy(SetDesignGoal goal, Long studentId, Long kpId) {
        return switch (goal) {
            case DETECTION -> new DetectionStrategy();     // 全覆盖，快速检测
            case TRAINING -> new TrainingStrategy(studentId, kpId); // 个性化，针对薄弱维度
            case DIAGNOSIS -> new DiagnosisStrategy();     // 精细诊断，单一维度逐级变化
            case REINFORCEMENT -> new ReinforcementStrategy(); // 巩固，混合多维度
        };
    }
}

/**
 * 训练策略：针对学生薄弱变式维度重点出题
 */
class TrainingStrategy implements VariationStrategy {
    private final Long studentId;
    private final Long kpId;
    
    @Override
    public List<Question> select(
            List<Question> candidates,
            Map<String, List<Question>> byType,
            Map<String, List<Question>> byContext,
            Map<String, List<Question>> byDifficulty,
            Long studentId) {
        
        // 获取学生该知识点的迁移阻断类型
        List<TransferBlock> blocks = blockService.findActive(studentId, kpId);
        
        List<Question> selected = new ArrayList<>();
        
        for (TransferBlock block : blocks) {
            switch (block.getBlockType()) {
                case QUESTION_TYPE_GAP:
                    // 选不同题型的题目
                    selectFromEachCategory(byType, selected, 2);
                    break;
                case CONTEXT_GAP:
                    // 选不同情境的题目
                    selectFromEachCategory(byContext, selected, 2);
                    break;
                case REPRESENTATION_GAP:
                    // 选不同表征方式的题目
                    selectByRepresentation(candidates, selected, 3);
                    break;
            }
        }
        
        // 补充基础题确保覆盖
        if (selected.size() < 5) {
            selectFromEachCategory(byDifficulty, selected, 1);
        }
        
        // 限制总数在 5-8 道
        return selected.size() > 8 ? selected.subList(0, 8) : selected;
    }
}
```

### 6.2 迁移分析编排服务

```java
/**
 * 迁移分析编排服务
 * 协调三层检测器，聚合结果，更新档案
 */
@Service
@Slf4j
public class TransferAnalysisService {
    
    @Autowired private RuleBasedTransferDetector ruleDetector;
    @Autowired private GraphBasedTransferDetector graphDetector;
    @Autowired private SequenceTransferDetector sequenceDetector;
    @Autowired private TransferScoringEngine scoringEngine;
    @Autowired private TransferBlockDetector blockDetector;
    @Autowired private TransferProfileRepository profileRepo;
    @Autowired private TransferEventRepository eventRepo;
    @Autowired private RedisTemplate<String, Object> redisTemplate;
    
    /**
     * 答题事件迁移分析主入口
     */
    @Async("transferAnalysisExecutor")
    public void analyzeAnswerEvent(AnswerEventMessage message) {
        Long studentId = message.getStudentId();
        
        // 1. 构建学生上下文
        StudentContext context = buildContext(studentId);
        
        // 2. 构建答题事件
        AnswerEvent event = AnswerEvent.from(message);
        
        // 3. 三层检测
        List<TransferEvent> ruleEvents = ruleDetector.detect(event, context);
        List<TransferEvent> graphEvents = graphDetector.detect(event, context);
        List<TransferEvent> seqEvents = sequenceDetector.detectInSession(
            studentId, event.getSessionId(), 
            context.getSessionEvents(event.getSessionId()));
        
        // 4. 去重合并
        List<TransferEvent> allEvents = mergeAndDedup(ruleEvents, graphEvents, seqEvents);
        
        if (allEvents.isEmpty()) {
            return; // 无迁移事件
        }
        
        // 5. 持久化迁移事件
        eventRepo.batchInsert(allEvents);
        
        // 6. 更新迁移能力档案
        updateProfile(studentId, allEvents);
        
        // 7. 触发阻断检测（限流：每人最多每5分钟一次）
        if (rateLimiter.tryAcquire("block_detect:" + studentId, 1, TimeUnit.MINUTES.toSeconds(5))) {
            blockDetector.detectBlocks(studentId);
        }
        
        // 8. 通知下游模块
        notifyDownstream(studentId, allEvents);
    }
    
    /**
     * 更新学生迁移能力档案
     */
    private void updateProfile(Long studentId, List<TransferEvent> newEvents) {
        // 获取最近90天的事件
        List<TransferEvent> recent = eventRepo.findRecentByStudent(
            studentId, LocalDateTime.now().minusDays(90));
        
        // 重新计算得分
        TransferScore score = scoringEngine.calculateScore(studentId, recent);
        
        // 更新或创建档案
        TransferProfile profile = profileRepo.findByStudentId(studentId)
            .orElse(new TransferProfile(studentId));
        
        profile.setTransferIndex(score.getTransferIndex());
        profile.setLowRoadScore(score.getLowRoadScore());
        profile.setHighRoadScore(score.getHighRoadScore());
        profile.setCrossChapterScore(score.getCrossChapterScore());
        profile.setCrossSubjectScore(score.getCrossSubjectScore());
        profile.setCrossQuestionTypeScore(score.getCrossQuestionTypeScore());
        profile.setLevel(score.getLevel());
        profile.setTotalTransferEvents(recent.size());
        profile.setLastAssessedAt(LocalDateTime.now());
        
        profileRepo.saveWithVersion(profile); // 乐观锁更新
        
        // 刷新缓存
        redisTemplate.opsForValue().set(
            TransferCacheKeys.profile(studentId), 
            profile, 
            2, TimeUnit.HOURS);
    }
    
    /**
     * 通知下游模块
     */
    private void notifyDownstream(Long studentId, List<TransferEvent> events) {
        // 发布迁移事件消息
        applicationEventPublisher.publishEvent(
            new TransferAnalysisCompletedEvent(studentId, events));
    }
}
```

### 8.3 增量评分优化

```java
/**
 * 增量评分优化
 * 避免每次都重新计算全部历史事件
 */
@Component
public class IncrementalScoringService {
    
    /**
     * 增量更新策略：
     * 1. 保留上次的维度累加器
     * 2. 新事件仅做增量调整
     * 3. 每100条事件或每7天做一次全量重算
     */
    public TransferScore incrementalUpdate(
            Long studentId,
            TransferProfile lastProfile,
            List<TransferEvent> newEvents) {
        
        // 检查是否需要全量重算
        if (needsFullRecompute(lastProfile)) {
            return scoringEngine.calculateScore(studentId, 
                eventRepo.findRecentByStudent(studentId, 
                    LocalDateTime.now().minusDays(90)));
        }
        
        // 增量计算
        TransferScore delta = calculateDelta(newEvents);
        
        return TransferScore.builder()
            .transferIndex(adjust(lastProfile.getTransferIndex(), delta.getTransferIndex()))
            .lowRoadScore(adjust(lastProfile.getLowRoadScore(), delta.getLowRoadScore()))
            .highRoadScore(adjust(lastProfile.getHighRoadScore(), delta.getHighRoadScore()))
            .crossChapterScore(adjust(lastProfile.getCrossChapterScore(), delta.getCrossChapterScore()))
            .crossSubjectScore(adjust(lastProfile.getCrossSubjectScore(), delta.getCrossSubjectScore()))
            .crossQuestionTypeScore(adjust(lastProfile.getCrossQuestionTypeScore(), delta.getCrossQuestionTypeScore()))
            .build();
    }
    
    private boolean needsFullRecompute(TransferProfile profile) {
        // 距离上次全量计算超过7天，或事件数超过100
        return profile.getLastFullRecomputeAt().isBefore(
                   LocalDateTime.now().minusDays(7))
               || profile.getTotalTransferEvents() % 100 == 0;
    }
    
    /**
     * 加权调整：新旧分数按 0.85:0.15 融合
     */
    private double adjust(double oldScore, double deltaScore) {
        double adjusted = oldScore * 0.85 + (oldScore + deltaScore) * 0.15;
        return Math.max(0, Math.min(100, adjusted));
    }
}
```

```java
        List<TransferBlock> blocks = transferService.getActiveBlocks(studentId);
        
        List<RecommendationItem> items = new ArrayList<>();
        
        for (TransferBlock block : blocks) {
            // 获取或生成跨情境题组
            CrossContextQuestionSet set = transferService.getOrCreateSet(
                block.getSourceKpId(), studentId, SetDesignGoal.TRAINING);
            
            // 转化为推荐项
            for (String questionId : set.getQuestionIdList()) {
                items.add(RecommendationItem.builder()
                    .questionId(questionId)
                    .reason("迁移训练：" + block.getBlockType().getDescription())
                    .priority(block.getFailureCount() > 3 ? "HIGH" : "MEDIUM")
                    .source("TRANSFER_ENGINE")
                    .build());
            }
        }
        
        return items;
    }
    
    @Override
    public int getOrder() {
        return 30; // 在知识点推荐和错题推荐之后
    }
```

```java
/**

@Component
public class TransferReportDataProvider {
    
    public TransferReportSection buildReportSection(Long studentId) {
        TransferProfile profile = transferService.getProfile(studentId);
        List<TransferBlock> blocks = transferService.getActiveBlocks(studentId);
        TransferTrend trend = transferService.getTrend(studentId, 30);
        
        return TransferReportSection.builder()
            .title("知识迁移能力分析")
            .overallScore(profile.getTransferIndex())
            .level(profile.getLevel().getLabel())
            .percentile(transferService.getPercentile(studentId))
            .radar(buildRadar(profile))
            .trend(trend)
            .activeBlocks(blocks.stream()
                .map(this::toBlockDetail)
                .collect(Collectors.toList()))
            .suggestion(generateSuggestion(profile, blocks))
            .build();
    }
    
    private String generateSuggestion(TransferProfile profile, List<TransferBlock> blocks) {
        StringBuilder sb = new StringBuilder();
        
        // 综合评价
        sb.append(String.format("该学生当前迁移能力等级为「%s」，", profile.getLevel().getLabel()));
        sb.append(String.format("超越了%.0f%%的同年级学生。", 
            transferService.getPercentile(profile.getStudentId())));
        
        // 突出维度
        String strongest = findStrongestDimension(profile);
        String weakest = findWeakestDimension(profile);
        sb.append(String.format("在「%s」方面表现突出，", strongest));
        sb.append(String.format("「%s」方面有待加强。", weakest));
        
        // 具体阻断
        if (!blocks.isEmpty()) {
            sb.append("\n建议重点关注以下知识迁移障碍：\n");
            blocks.stream().limit(3).forEach(b -> {
                sb.append(String.format("- %s\n", b.getBlockType().getDescription()));
            });
        }
        
        return sb.toString();
    }
}
```

### 13.1 教育理论基础

本引擎设计参考了以下教育心理学理论：

| 理论 | 核心概念 | 在本引擎中的应用 |
| --- | --- | --- |
| Salomon & Perkins 迁移理论 | 低路迁移（自动化）vs 高路迁移（反思性） | 两种迁移得分独立计算 |
| Bransford 转移框架 | 初始学习程度 → 迁移准备度 → 迁移执行 | 掌握度阈值前置条件 |
| Csikszentmihalyi 心流理论 | 挑战-技能平衡 | 迁移训练题组难度递进设计 |
| Vygotsky 最近发展区 | 知识点间的认知距离 | 迁移距离（NEAR/MEDIUM/FAR）分级 |
| Anderson 知识分类 | 陈述性知识 vs 程序性知识 | 迁移类型（理论→应用）映射 |

### 13.3 术语表

| 术语 | 说明 |
| --- | --- |
| 学习迁移 | 将某一情境中学到的知识/技能应用到新情境的能力 |
| 近迁移 | 两个情境高度相似时的迁移（如同一知识点换题型） |
| 远迁移 | 两个情境表面差异大但深层结构相同时的迁移 |
| 低路迁移 | 经过充分练习后近乎自动化的迁移 |
| 高路迁移 | 需要有意识地抽象和反思的迁移 |
| 迁移阻断 | 学生掌握源知识但无法应用到目标情境的现象 |
| 负迁移 | 既有知识干扰新问题解决的现象 |
| 变式题组 | 同一知识点在不同情境/题型/表征下的题目集合 |
