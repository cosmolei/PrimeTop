# 服务端-学生试卷扫描智能识别与考试错题自动归档入库引擎-详细设计

## 1. 概述

### 1.1 功能定位

本模块是 PrimeTop 学习数据采集体系的重要补充。当学生拿到学校考试或日常测验的**已批改纸质试卷**后，通过 APP 拍照上传整张试卷，系统自动完成：

1. 试卷图像预处理与版面分析
2. 题目区域智能切分与题干 OCR 识别
3. 学生手写答案与标准答案比对
4. 错题自动提取与错因初步标注
5. 知识点反向映射
6. 错题归档入库 + 学情画像增量更新
7. 试卷维度的考试报告生成

与现有 `拍照搜题` 模块的区别：

| 维度 | 拍照搜题 | 试卷扫描归档 |
|------|---------|-------------|
| 输入 | 单题/多题照片 | 整张试卷（1-8页） |
| 目标 | 获取单题解析 | 全卷结构化 → 批量错题入库 |
| 答案角色 | 学生不会做，求解析 | 试卷已考完，求归档分析 |
| 输出 | 单题讲解 | 试卷报告 + N条错题 + 学情更新 |
| 触发场景 | 日常作业遇到难题 | 考后/测验后试卷整理 |

### 1.2 适用范围

- **学段**：小学高年级至高中（3年级以上，试卷格式相对规范）
- **学科**：全学科（语文/数学/英语/物理/化学/生物/历史/地理/政治）
- **试卷类型**：学校统考、月考、单元测验、期中期末、模拟考试
- **约束**：暂不支持纯手写无固定格式的开放性试卷（如作文手稿）

### 1.3 核心价值

- **省去手动录入**：学生无需逐题拍照、逐题加错题本，一张照片完成全卷归档
- **考试数据资产化**：将纸质考试数据转化为结构化学情数据，补全线下考试数据缺口
- **闭环驱动**：试卷归档 → 错题入库 → 复习推荐 → 学情更新，一条龙自动化

```java
// ==================== 请求/响应 DTO ====================

/**
 * 试卷扫描提交请求
 */
public class PaperScanSubmitRequest {
    private Long userId;
    private Integer gradeId;
    private Integer subjectId;
    private Integer textbookVersionId;
    
    // 试卷信息
    private String examName;
    private ExamType examType;          // UNIT_TEST, MONTHLY, MIDTERM, FINAL, MOCK, PAST_PAPER
    private LocalDate examDate;
    private String schoolName;
    private BigDecimal totalScore;      // 可选，学生可手动输入
    private BigDecimal studentScore;    // 可选，学生可手动输入
    
    // 图片
    private List<String> imageUrls;     // 试卷各页图片URL（已上传至OSS）
    private Integer pageCount;
    
    // 学生自述（帮助系统理解）
    private String studentNote;         // 如"最后一题太长了可能没拍全"
}

/**
 * 试卷扫描结果响应
 */
public class PaperScanResultResponse {
    private String taskNo;
    private TaskStatus status;
    private Integer progress;
    private String currentStep;
    
    // 处理完成后填充
    private PaperScanReportDTO report;
    private List<PaperQuestionDTO> questions;
    private List<MistakeItemDTO> generatedMistakes;  // 新生成的错题
    
    // 错误信息
    private String errorCode;
    private String errorMsg;
}

/**
 * 单题识别结果
 */
public class PaperQuestionDTO {
    private Long questionId;
    private Integer pageIndex;
    private String questionNo;
    private Integer questionType;
    private String sectionName;
    
    private String questionText;
    private String questionImageUrl;
    private Map<String, String> options;
    
    private String studentAnswer;
    private String studentAnswerImage;
    private String correctAnswer;
    private Correctness correctness;    // CORRECT, WRONG, PARTIAL, UNKNOWN
    private BigDecimal score;
    private BigDecimal fullScore;
    private Double ocrConfidence;
    
    private List<Long> knowledgePointIds;
    private Boolean userCorrected;
    
    // 学生可修正
    public boolean needsReview() {
        return correctness == Correctness.UNKNOWN 
            || ocrConfidence < 0.75
            || studentAnswer == null || studentAnswer.isBlank();
    }
}

/**
 * 题目修正请求（学生手动修正识别结果）
 */
public class QuestionCorrectionRequest {
    private Long questionId;
    private String correctedStudentAnswer;  // 修正后的学生答案
    private Correctness correctedCorrectness; // 修正后的判定
    private Boolean addToMistakeBook;        // 是否加入错题本
}
```

```java
/**
 * 图像质量检测 - 决定是否接受任务或要求重拍
 */
public class ImageQualityCheckStep {
    
    public QualityCheckResult execute(List<String> imageUrls) {
        List<ImageQuality> qualities = new ArrayList<>();
        
        for (String url : imageUrls) {
            BufferedImage img = downloadImage(url);
            ImageQuality q = checkSingleImage(img);
            qualities.add(q);
        }
        
        // 整体判定
        boolean allAcceptable = qualities.stream()
            .allMatch(q -> q.getOverallScore() >= QUALITY_THRESHOLD);
        
        if (!allAcceptable) {
            // 判断是否完全不可用
            boolean anyUsable = qualities.stream()
                .anyMatch(q -> q.getOverallScore() >= MINIMUM_THRESHOLD);
            
            if (!anyUsable) {
                return QualityCheckResult.reject(
                    "IMAGE_QUALITY_POOR",
                    getRetakeSuggestions(qualities)
                );
            }
            // 部分可用 → 标记低质量页面，继续处理
            return QualityCheckResult.partial(qualities);
        }
        
        return QualityCheckResult.pass(qualities);
    }
    
    private ImageQuality checkSingleImage(BufferedImage img) {
        return ImageQuality.builder()
            .resolutionScore(checkResolution(img))      // ≥ 200 DPI 等效
            .blurScore(checkBlur(img))                  // Laplacian variance
            .lightingScore(checkLighting(img))          // 亮度均匀性
            .skewScore(checkSkew(img))                  // 倾斜角度
            .shadowScore(checkShadow(img))              // 阴影/反光
            .completenessScore(checkCompleteness(img))   // 边缘完整性
            .overallScore(calculateOverall())
            .build();
    }
}
```

### 5.3 Step2: 版面分析与题目切分

版面分析是整个流程最关键的步骤。采用**规则 + AI**混合策略。

```java
/**
 * 版面分析器 - 将试卷图像分解为结构化的题目区域
 */
public class PaperLayoutAnalyzer {
    
    /**
     * 分析流程:
     * 1. 二值化 + 去噪
     * 2. 水平/垂直投影检测题号行
     * 3. 识别大题标题（"一、选择题"）
     * 4. 基于题号模式切分小题
     * 5. AI辅助修正切分边界
     */
    public LayoutAnalysisResult analyze(BufferedImage pageImage, 
                                         int pageIndex,
                                         Subject subject,
                                         int grade) {
        
        // Step 1: 预处理
        Mat binary = preprocess(pageImage);
        
        // Step 2: 检测印刷区域
        RectArray contentRegions = detectContentRegions(binary);
        
        // Step 3: 检测题号模式
        List<QuestionHeader> headers = detectQuestionHeaders(binary, contentRegions);
        // headers = [{"no":"1","bbox":[x,y,w,h]}, {"no":"2","bbox":[...]}, ...]
        
        // Step 4: 检测大题分隔
        List<SectionHeader> sections = detectSectionHeaders(binary, contentRegions);
        // sections = [{"title":"一、选择题","bbox":[...],"questionRange":"1-10"}, ...]
        
        // Step 5: 基于题号间距和行间距，确定每题边界
        List<QuestionRegion> regions = segmentQuestions(headers, sections, contentRegions);
        
        // Step 6: 对每个区域，进一步区分为：
        //   - 题干区 (question_text_area)
        //   - 答案/作答区 (answer_area)  ← 学生手写区域
        //   - 选项区 (options_area) ← 选择题
        for (QuestionRegion r : regions) {
            r.setSubRegions(detectSubRegions(r, binary, r.getQuestionType()));
        }
        
        // Step 7: AI修正（对于格式不规范的试卷）
        if (hasAmbiguousRegions(regions)) {
            regions = aiRefineRegions(pageImage, regions, subject, grade);
        }
        
        return LayoutAnalysisResult.builder()
            .pageIndex(pageIndex)
            .sections(sections)
            .questionRegions(regions)
            .build();
    }
    
    /**
     * 题号模式检测 - 支持多种中国试卷常见格式
     */
    private List<QuestionHeader> detectQuestionHeaders(Mat binary, RectArray content) {
        // 支持的题号格式:
        // "1." / "1、" / "1）" / "1)" / "(1)" / "（1）"
        // "11-12." / "13-14题" (多题共享题干)
        // "23.(1)" / "23.①" (大题带小问)
        
        String[] patterns = {
            r"^\d{1,2}[.、）)]\s*",           // 1. / 2、 / 3）
            r"^[（(]\d{1,2}[）)]\s*",         // (1) / （2）
            r"^\d{1,2}[-～]\d{1,2}[.、]?\s*", // 11-12.
            r"^\d{1,2}[.、]\s*[①②③④⑤]",      // 23.①
        };
        
        // OCR扫描行首区域，匹配题号模式

    }
}
```

```java
/**
 * 题目OCR引擎 - 对切分后的区域进行识别

public class QuestionOcrEngine {
    
    /**
     * 对单个题目区域执行OCR
     */
    public QuestionOcrResult ocrQuestion(QuestionRegion region, 
                                          BufferedImage pageImage) {
        
        // 裁切题目区域图片
        BufferedImage questionImg = cropRegion(pageImage, region.getBbox());
        
        // 根据题型选择OCR策略
        OcrStrategy strategy = selectStrategy(region.getQuestionType());
        
        // 执行OCR
        OcrRawResult raw = strategy.recognize(questionImg);
        
        // 结构化解析
        QuestionOcrResult result = QuestionOcrResult.builder()
            .questionText(raw.getText())
            .options(extractOptions(raw, region))         // 选择题选项
            .formulas(extractFormulas(raw))               // 数学公式 → LaTeX
            .figures(extractFigures(questionImg, raw))    // 图形区域
            .confidence(raw.getAvgConfidence())
            .build();
        
        // 对答案区域单独做手写体识别
        if (region.getAnswerArea() != null) {
            BufferedImage answerImg = cropRegion(pageImage, region.getAnswerArea());
            HandwritingResult hwResult = handwritingEngine.recognize(answerImg);
            result.setStudentAnswer(hwResult.getText());
            result.setAnswerOcrConfidence(hwResult.getConfidence());
            result.setStudentAnswerImage(uploadImage(answerImg));
        }
        
        return result;
    }
    
    /**
     * 策略选择
     */
    private OcrStrategy selectStrategy(QuestionType type) {
        return switch (type) {
            case CHOICE   -> choiceQuestionOcrStrategy;    // 选项结构化提取
            case FILL     -> fillBlankOcrStrategy;          // 填空线检测
            case JUDGE    -> judgeOcrStrategy;              // √× 检测
            case ESSAY    -> essayOcrStrategy;              // 长文本识别
            case SOLUTION -> solutionOcrStrategy;           // 含公式+文字+图形
            default       -> generalOcrStrategy;
        };
    }
}
```

### 5.5 Step4: 答案比对与判分

这是本模块的核心难点——如何在没有标准答案的情况下判断学生答案对错？

**策略：三路并行，分级处理。**

```java
/**
 * 答案比对引擎
 */
public class AnswerComparisonEngine {
    
    /**
     * 三路并行判定策略:
     * 
     * 路径A - 试卷自带批改痕迹识别:
     *   如果老师在试卷上打了√/×/分数，直接读取批改标记
     * 
     * 路径B - 标准答案库匹配:
     *   题干与题库匹配 → 获取标准答案 → 比对学生答案
     * 
     * 路径C - AI大模型判定:
     *   将题干+学生答案发给大模型，判定对错
     */
    public ComparisonResult compare(QuestionOcrResult ocrResult,
                                     String subject,
                                     int grade,
                                     BufferedImage pageImage) {
        
        // === 路径A: 读取试卷批改标记 ===
        BatchMark mark = detectTeacherBatchMark(pageImage, ocrResult.getRegion());
        if (mark != null && mark.getConfidence() > 0.85) {
            // 老师已经批改过了，直接采用
            return ComparisonResult.fromTeacherMark(mark);
            // mark = {isCorrect: WRONG, score: 4, fullScore: 10}
        }
        
        // === 路径B: 题库标准答案匹配 ===
        QuestionMatch match = questionBankService.matchQuestion(
            ocrResult.getQuestionText(),
            subject,
            grade,
            ocrResult.getOptions()
        );
        
        if (match != null && match.getMatchScore() > 0.90) {
            // 高置信度匹配到题库中的题目
            String correctAnswer = match.getCorrectAnswer();
            Correctness correctness = compareAnswer(
                ocrResult.getStudentAnswer(),
                correctAnswer,
                match.getQuestionType()
            );
            return ComparisonResult.fromQuestionBank(match, correctness);
        }
        
        // === 路径C: AI大模型判定 ===
        AIJudgeResult aiResult = aiJudgeService.judge(
            ocrResult.getQuestionText(),
            ocrResult.getStudentAnswer(),
            ocrResult.getStudentAnswerImage(),
            subject,
            grade
        );
        
        return ComparisonResult.fromAIJudge(aiResult);
    }
    
    /**
     * 检测老师的批改标记
     */
    private BatchMark detectTeacherBatchMark(BufferedImage img, Bbox region) {
        // 检测区域内的:
        // - "√" / "×" 符号
        // - 红笔标记（颜色检测）
        // - 分数标记如 "-3" / "扣2分" / "5/10"
        // - 圈出的错误
        
        Mat regionMat = cropAndPreprocess(img, region);
        
        // 红色通道检测（老师常用红笔）
        Mat redMask = detectRedInk(regionMat);
        List<Contour> redContours = findContours(redMask);
        
        // 分类批改标记
        List<MarkSymbol> symbols = redContours.stream()
            .map(this::classifyMark)
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
        
        // 推断判定结果
        return inferBatchResult(symbols, region);
    }
    
    /**
     * AI判定（大模型）
     */
    // aiJudgeService.judge 内部逻辑:
    // Prompt示例:
    // """
    // 你是一位严谨的{subject}老师。请判断以下学生的答案是否正确。
    //
    // 题目: {questionText}
    // 学生的答案: {studentAnswer}
    // 年级: {grade}
    //
    // 请返回JSON:
    // {
    //   "is_correct": true/false/"partial",
    //   "score": number (0-fullScore),
    //   "reason": "简要说明判定依据",
    //   "error_type": "概念不清"|"计算失误"|"审题错误"|"方法错误"|"表达不规范"|"其他"
```

```java
/**
 * 试卷扫描工作器基类
 */
public abstract class PaperScanWorker {
    
    @KafkaListener(topics = "#{T(com.primetop.paperscan.WorkerConfig).INPUT_TOPIC}")
    public void onMessage(ScanTaskMessage message) {
        Long taskId = message.getTaskId();
        
        try {
            // 更新任务状态
            taskService.updateStatus(taskId, Status.PROCESSING, getCurrentStep());
            
            // 执行业务逻辑
            StepResult result = execute(message);
            
            if (result.isSuccess()) {
                // 发送下一步消息
                ScanTaskMessage next = message.toBuilder()
                    .step(getNextStep())
                    .payload(result.getPayload())
                    .build();
                kafkaTemplate.send(getOutputTopic(), next);
                
                taskService.updateProgress(taskId, getProgressPercent());
            } else if (result.isRetryable()) {
                // 可重试错误 → 延迟重试
                retryScheduler.schedule(message, result.getRetryDelayMs());
            } else {
                // 不可恢复错误
                taskService.markFailed(taskId, result.getErrorCode(), result.getErrorMsg());
            }
            
        } catch (Exception e) {
            log.error("Paper scan worker error, taskId={}, step={}", 
                      taskId, getCurrentStep(), e);
            errorHandler.handle(message, e);
        }
    }
    
    protected abstract StepResult execute(ScanTaskMessage message);
    protected abstract String getCurrentStep();
    protected abstract String getOutputTopic();
    protected abstract int getProgressPercent();
}
```

```java
@Component
public class PaperScanTimeoutMonitor {
    
    private static final Duration TASK_TIMEOUT = Duration.ofMinutes(5);
    private static final Duration STEP_TIMEOUT = Duration.ofMinutes(2);
    
    @Scheduled(fixedDelay = 30000)  // 每30秒扫描一次
    public void checkTimeout() {
        // 查找超时任务
        List<PaperScanTask> timeoutTasks = taskService.findStaleTasks(
            TASK_TIMEOUT, STEP_TIMEOUT
        );
        
        for (PaperScanTask task : timeoutTasks) {
            handleTimeout(task);
        }
    }
    
    private void handleTimeout(PaperScanTask task) {
        Duration elapsed = Duration.between(
            task.getUpdatedAt().toInstant(), 
            Instant.now()
        );
        
        if (elapsed.compareTo(STEP_TIMEOUT) > 0 && elapsed.compareTo(TASK_TIMEOUT) < 0) {
            // 单步超时但总时间未超 → 重试当前步骤
            retryCurrentStep(task);
        } else {
            // 总时间超时 → 标记失败，部分结果保留
            taskService.markPartialFailed(
                task.getId(), 
                "TASK_TIMEOUT",
                "处理超时，已识别" + task.getQuestionCount() + "题中的部分题目"
            );
            notificationService.notifyUser(
                task.getUserId(),
                "试卷扫描超时",
                "您的试卷扫描任务处理超时，已保留已识别部分。建议重新拍照上传或手动录入。"
            );
        }
    }
}
```

```java
/**
 * 答案比对工具 - 根据题型选择不同策略
 */
public class AnswerComparator {
    
    public Correctness compare(String studentAnswer, 
                                String correctAnswer,
                                QuestionType type,
                                String subject) {
        
        if (studentAnswer == null || studentAnswer.isBlank()) {
            return Correctness.UNKNOWN;
        }
        
        // 归一化
        String s = normalize(studentAnswer);
        String c = normalize(correctAnswer);
        
        return switch (type) {
            case CHOICE   -> compareChoice(s, c);
            case FILL     -> compareFill(s, c, subject);
            case JUDGE    -> compareJudge(s, c);
            case SOLUTION -> compareSolution(s, c, subject);
            default       -> compareSemantic(s, c);
        };
    }
    
    /**
     * 选择题比对: 精确匹配 + 多选支持
     */
    private Correctness compareChoice(String s, String c) {
        // 标准化: "A" / "AB" / "A,B" / "A、B" → 排序去重
        Set<String> sSet = parseChoiceOptions(s);
        Set<String> cSet = parseChoiceOptions(c);
        
        if (sSet.equals(cSet)) return Correctness.CORRECT;
        
        // 部分正确（多选题）
        if (!Collections.disjoint(sSet, cSet)) {
            return Correctness.PARTIAL;
        }
        
        return Correctness.WRONG;
    }
    
    /**
     * 填空题比对: 数学等价性 + 近义容忍
     */
    private Correctness compareFill(String s, String c, String subject) {
        // 数学/理科: 检查数学等价性
        if (isMathSubject(subject)) {
            MathEquivalenceResult eq = mathEngine.checkEquivalence(s, c);
            if (eq.isEquivalent()) return Correctness.CORRECT;
            if (eq.isPartiallyEquivalent()) return Correctness.PARTIAL;
            return Correctness.WRONG;
        }
        
        // 文科: 语义相似度
        double sim = calculateSemanticSimilarity(s, c);
        if (sim >= 0.90) return Correctness.CORRECT;
        if (sim >= 0.60) return Correctness.PARTIAL;
        return Correctness.WRONG;
    }
    
    /**
     * 数学等价性检查 (委托给统一学科计算引擎)
     * 
     * 示例:
     * "x=±2" ≡ "x=2或x=-2" ≡ "x₁=2, x₂=-2"
     * "1/2" ≡ "0.5"
     * "x²-1" ≡ "(x+1)(x-1)"
     */
    private boolean checkMathEquivalence(String s, String c) {
        // 调用 服务端-统一学科计算引擎与符号推理服务
        // 1. 将文本转为数学表达式 AST
        // 2. 符号化简
        // 3. 结构化比较
        MathExpr sExpr = mathParser.parse(s);
        MathExpr cExpr = mathParser.parse(c);
        return sExpr.canonicalForm().equals(cExpr.canonicalForm());
    }
    
    /**
     * 文本归一化
     */
    private String normalize(String text) {
        return text.trim()
            .replaceAll("\\s+", " ")              // 多空格合一
            .replaceAll("[，。、]", ",")            // 中文标点统一
            .replaceAll("[（）]", "()")            // 括号统一
            .toLowerCase()                         // 大小写无关(英语)
            .replaceAll("^答[:：]", "")            // 去掉"答:"前缀
            ;
    }
}
```

### 7.2 题库匹配算法

```java
/**
 * 题库匹配 - 通过文本相似度在已有题库中查找相同/相似题目
 */
public class QuestionBankMatcher {
    
    /**
     * 多阶段匹配策略:
     * 1. BM25全文检索 (快，粗筛)
     * 2. 向量相似度 (准，精排)
     * 3. 关键实体匹配 (兜底)
     */
    public QuestionMatch match(String questionText, 
                                Integer subjectId,
                                Integer gradeId,
                                Map<String,String> options) {
        
        // Stage 1: ES BM25检索 Top-20
        List<QuestionDoc> candidates = esClient.search(
            QuestionIndex.builder()
                .subjectId(subjectId)
                .gradeId(gradeId)
                .query(questionText)
                .size(20)
                .build()
        );
        
        if (candidates.isEmpty()) return null;
        
        // Stage 2: 向量相似度精排
        float[] queryVec = embeddingService.embed(questionText);
        List<ScoredQuestion> scored = candidates.stream()
            .map(q -> {
                float[] qVec = q.getEmbedding();
                double cosineSim = cosineSimilarity(queryVec, qVec);
                // 结合选项匹配度
                double optionMatch = calculateOptionMatch(options, q.getOptions());
                double score = 0.7 * cosineSim + 0.3 * optionMatch;
                return new ScoredQuestion(q, score);
            })
            .sorted(Comparator.comparingDouble(ScoredQuestion::getScore).reversed())
            .collect(Collectors.toList());
        
        ScoredQuestion best = scored.get(0);
        
        if (best.getScore() >= 0.95) {
            return QuestionMatch.exact(best.getQuestion());
        } else if (best.getScore() >= 0.85) {
            return QuestionMatch.similar(best.getQuestion(), best.getScore());
        }
        
        return null;
    }
}
```

```java
/**
 * 分级降级策略
 */
public class PaperScanDegradationManager {
    
    /**
     * 根据系统负载和错误率选择降级级别
     */
    public DegradationLevel evaluateSystemState() {
        double currentErrorRate = metricsService.getErrorRate("paper-scan", 5);
        double systemLoad = systemMonitor.getCpuUsage();
        int queueSize = taskQueue.size();
        
        if (currentErrorRate > 0.3 || systemLoad > 0.9 || queueSize > 500) {
            return DegradationLevel.LEVEL_3;  // 最高级降级
        } else if (currentErrorRate > 0.15 || systemLoad > 0.75 || queueSize > 200) {
            return DegradationLevel.LEVEL_2;
        } else if (currentErrorRate > 0.05 || queueSize > 100) {
            return DegradationLevel.LEVEL_1;
        }
        return DegradationLevel.NONE;
    }
    
    /**
     * 各级别降级措施
     */
    public void applyDegradation(DegradationLevel level, ScanContext ctx) {
        switch (level) {
            case LEVEL_1:
                // 减少AI判定并发数，非选择题不再走大模型判定
                ctx.setAiJudgeEnabled(false);
                log.info("Level 1 degradation: AI judge disabled");
                break;
                
            case LEVEL_2:
                // 跳过知识点AI重标注，使用规则匹配
                ctx.setKpMappingMode(KpMappingMode.RULE_ONLY);
                ctx.setMaxConcurrentOcr(2);  // 限制OCR并发
                break;
                
            case LEVEL_3:
                // 只做基础OCR+题库匹配，不做任何AI调用
                ctx.setAiJudgeEnabled(false);
                ctx.setAiLayoutEnabled(false);
                ctx.setKpMappingMode(KpMappingMode.RULE_ONLY);
                ctx.setReportGenerationMode(ReportMode.TEMPLATE_ONLY);
                // 新任务排队等待
                taskQueue.pause();
                notificationService.notifyAdmin(
                    "试卷扫描服务高负载降级",
                    "当前队列: " + taskQueue.size() + ", 错误率: " + metricsService.getErrorRate("paper-scan", 5)
                );
                break;
        }
    }
}
```

### 8.3 部分成功处理

```java
/**
 * 允许部分成功的容错设计
 * 
 * 核心原则: 不因单题失败阻塞整卷处理
 */
public class PartialSuccessHandler {
    
    public TaskResult aggregateResult(List<QuestionProcessResult> perQuestion) {
        int success = 0, failed = 0, unknown = 0;
        List<PaperScanQuestion> questions = new ArrayList<>();
        
        for (QuestionProcessResult qpr : perQuestion) {
            switch (qpr.getStatus()) {
                case SUCCESS:
                    success++;
                    questions.add(qpr.getQuestion());
                    break;
                case OCR_FAILED:
                case ANSWER_UNKNOWN:
                    unknown++;
                    questions.add(qpr.getQuestion());  // 保留，标记UNKNOWN
                    break;
                case LAYOUT_FAILED:
                    failed++;
                    break;  // 不加入结果
            }
        }
        
        // 如果至少有1题成功，就返回部分结果
        if (success + unknown > 0) {
            TaskStatus status = (failed == 0) ? TaskStatus.COMPLETED : TaskStatus.PARTIAL_COMPLETED;
            
            return TaskResult.builder()
                .status(status)
                .questions(questions)
                .summary(buildSummary(success, unknown, failed))
                .warning(failed > 0 ? 
                    failed + "题因版面识别问题未能处理，建议手动添加" : null)
                .build();
        }
        
        return TaskResult.failed("NO_QUESTION_PROCESSED", "无法识别试卷内容");
    }
}
```

```dart
class PaperScanPoller {
  Timer? _pollTimer;
  int _pollCount = 0;
  static const _maxPollCount = 60;    // 最多轮询60次
  static const _pollInterval = 2;      // 每2秒一次
  
  void startPolling(String taskNo) {
    _pollCount = 0;
    _pollTimer = Timer.periodic(
      Duration(seconds: _pollInterval), 
      (_) => _poll(taskNo)
    );
  }
  
  Future<void> _poll(String taskNo) async {
    _pollCount++;
    
    if (_pollCount > _maxPollCount) {
      _pollTimer?.cancel();
      emit(PaperScanState.timeout());
      return;
    }
    
    final progress = await api.getProgress(taskNo);
    
    emit(PaperScanState.progress(
      percent: progress.progress,
      stepName: _localizeStep(progress.currentStep),
    ));
    
    if (progress.status == TaskStatus.COMPLETED || 
        progress.status == TaskStatus.PARTIAL_COMPLETED) {
      _pollTimer?.cancel();
      final result = await api.getResult(taskNo);
      emit(PaperScanState.completed(result));
    } else if (progress.status == TaskStatus.FAILED) {
      _pollTimer?.cancel();
      emit(PaperScanState.failed(progress.errorMsg));
    }
  }
}
```

### 15.2 容量预估

```
假设:
- 日活学生: 10万
- 每学生每周扫描: 0.5次（考试频率）
- 日均扫描量: ~7000次
- 峰值（考试季）: 日均20000次

单任务平均耗时: 30秒
平均并发: 7000 * 30 / (16 * 3600) ≈ 3.6 并发
峰值并发: 20000 * 30 / (16 * 3600) ≈ 10.4 并发

→ 初始配置可承载3-4倍峰值余量
```
