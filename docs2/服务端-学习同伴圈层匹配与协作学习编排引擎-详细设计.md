> **文档版本**: v1.0  
> **细化日期**: 2026-06-14  
> **对应模块**: 社交学习 / 协作学习 / 学习圈层  
> **优先级**: P2（V1.5 阶段）

## 1. 模块概述

### 1.1 功能目标

为 PrimeTop 平台学生用户提供智能同伴匹配与协作学习编排能力，将"个体孤立学习"升级为"同伴互助共学"。系统基于学生年级、学段、学科能力、学习风格、活跃时段、学习目标等多维度特征，智能推荐学习同伴并组建学习圈层，支持同伴问答、互助打卡、小组挑战、协作笔记等协作场景。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 安全优先 | 未成年人社交场景严格管控，支持家长授权、内容审核、关系链可见性控制 |
| 能力互补 | 匹配策略优先"能力互补 + 目标一致"，避免强弱悬殊导致体验失衡 |
| 渐进开放 | 从轻量互动（点赞、鼓励）逐步开放深度协作（笔记共享、小组挑战） |
| 隐私保护 | 真实信息脱敏，通讯隔离，禁止私信自由发送 |
| 可控退出 | 用户和家长可随时退出学习圈，数据清理机制完备 |

### 1.3 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| 学习圈成员 | 被匹配进入圈层的学生 | 参与圈内活动、查看圈内共享内容 |
| 圈层发起人 | 主动创建学习圈的学生 | 设置圈层主题、邀请同伴（需审核） |
| 家长 | 圈成员的监护人 | 查看孩子所在圈层、授权/退出、举报 |
| 教师 | 关联班级的教师 | 查看班级关联圈层、推荐分组 |
| 系统管理员 | 平台运营人员 | 圈层审核、违规处理、数据分析 |

## 4. 匹配引擎设计

### 4.1 匹配特征向量

系统为每个用户计算社交学习特征向量，作为圈层匹配的基础：

```python
@dataclass
class SocialMatchVector:
    user_id: int
    
    # ── 学业特征 (权重 35%) ──
    stage: str                          # 学段 PRIMARY/JUNIOR/SENIOR
    grade: int                          # 具体年级 G1-G12
    subject proficiency: dict[str, float]  # 各学科掌握度 0-1
    weak_subjects: list[str]            # 薄弱学科
    strong_subjects: list[str]         # 擅长学科
    
    # ── 学习行为特征 (权重 25%) ──
    learning_style: str                 # VISUAL/AUDITORY/READING/KINESTHETIC
    avg_daily_duration: int             # 日均学习时长（秒）
    active_time_slots: list[str]        # 活跃时段
    consistency_score: float            # 学习连贯性评分 0-1
    
    # ── 目标与兴趣 (权重 20%) ──
    learning_goal: str                  # 学习目标类型
    target_exam: str | None             # 目标考试（中考/高考/期末）
    interest_tags: list[str]            # 兴趣标签
    
    # ── 社交偏好 (权重 10%) ──
    collaboration_preference: str       # COMPETITIVE/COLLABORATIVE/MENTOR
    group_size_preference: int          # 偏好小组规模
    
    # ── 安全约束 (权重 10% / 硬性约束) ──
    same_school_only: bool              # 是否限定同校
    age_tolerance: int                  # 允许年龄差（年级差）
```

### 4.2 匹配算法

采用**多维度加权相似度 + 互补度**混合匹配策略：

```python
class CircleMatchEngine:
    """
    学习圈层匹配引擎
    策略：相似度（60%）+ 互补度（40%）的混合匹配
    """
    
    WEIGHTS = {
        "similarity": 0.6,
        "complementarity": 0.4
    }
    
    DIMENSION_WEIGHTS = {
        "stage_grade": 0.20,        # 学段年级必须接近
        "goal_alignment": 0.15,     # 目标一致性
        "schedule_overlap": 0.15,   # 活跃时段重叠度
        "ability_proximity": 0.10,  # 能力水平接近度
        "style_compatibility": 0.10,# 学习风格兼容性
        "subject_complement": 0.15, # 学科互补性（A擅长=B薄弱）
        "interest_overlap": 0.10,   # 兴趣重叠
        "consistency_match": 0.05,  # 学习连贯性匹配
    }
    
    # 硬性约束：违反任一则不匹配
    HARD_CONSTRAINTS = [
        "same_stage",               # 必须同学段
        "grade_diff <= 2",          # 年级差不超过2
        "parent_authorized",        # 双方家长均已授权
        "not_blocked",              # 无拉黑关系
        "not_same_circle_active",   # 不在同一个活跃圈中
    ]
    
    def calculate_match_score(
        self, 
        user_a: SocialMatchVector, 
        user_b: SocialMatchVector
    ) -> tuple[float, dict[str, float]]:
        """
        计算两个用户之间的匹配分数
        
        Returns:
            (总分0-100, 各维度明细)
        """
        # 1. 检查硬性约束
        if not self._check_hard_constraints(user_a, user_b):
            return 0.0, {}
        
        dimension_scores = {}
        
        # 2. 相似度维度（越高越好）
        dimension_scores["stage_grade"] = self._grade_similarity(
            user_a.grade, user_b.grade
        )
        dimension_scores["goal_alignment"] = self._goal_similarity(
            user_a.learning_goal, user_b.learning_goal
        )
        dimension_scores["schedule_overlap"] = self._schedule_overlap(
            user_a.active_time_slots, user_b.active_time_slots
        )
        dimension_scores["ability_proximity"] = self._ability_proximity(
            user_a.subject_proficiency, user_b.subject_proficiency
        )
        dimension_scores["style_compatibility"] = self._style_compatibility(
            user_a.learning_style, user_b.learning_style
        )
        dimension_scores["interest_overlap"] = self._interest_overlap(
            user_a.interest_tags, user_b.interest_tags
        )
        dimension_scores["consistency_match"] = 1.0 - abs(
            user_a.consistency_score - user_b.consistency_score
        )
        
        # 3. 互补度维度（差异化匹配）
        dimension_scores["subject_complement"] = self._subject_complementarity(
            user_a.subject_proficiency, user_b.subject_proficiency,
            user_a.weak_subjects, user_b.weak_subjects,
            user_a.strong_subjects, user_b.strong_subjects
        )
        
        # 4. 加权汇总
        similarity_score = sum(
            dimension_scores[d] * self.DIMENSION_WEIGHTS[d]
            for d in [
                "stage_grade", "goal_alignment", "schedule_overlap",
                "ability_proximity", "style_compatibility",
                "interest_overlap", "consistency_match"
            ]
        )
        
        complementarity_score = (
            dimension_scores["subject_complement"] 
            * self.DIMENSION_WEIGHTS["subject_complement"]
        )
        
        total = (
            similarity_score * self.WEIGHTS["similarity"] 
            + complementarity_score * self.WEIGHTS["complementarity"]
            # 归一化
        ) / sum(self.DIMENSION_WEIGHTS.values()) * 100
        
        return round(total, 2), dimension_scores
    
    def _subject_complementarity(
        self, 
        prof_a: dict[str, float], 
        prof_b: dict[str, float],
        weak_a: list[str], 
        weak_b: list[str],
        strong_a: list[str], 
        strong_b: list[str]
    ) -> float:
        """
        学科互补度：A擅长=B薄弱 且 B擅长=A薄弱 时互补分最高
        范围 0-1
        """
        a_helps_b = len(set(strong_a) & set(weak_b))
        b_helps_a = len(set(strong_b) & set(weak_a))
        total_weak = len(set(weak_a) | set(weak_b))
        
        if total_weak == 0:
            return 0.5  # 都没有薄弱学科，中性
        
        return min((a_helps_b + b_helps_a) / max(total_weak, 1), 1.0)
    
    def _schedule_overlap(
        self, 
        slots_a: list[str], 
        slots_b: list[str]
    ) -> float:
        """活跃时段重叠率（Jaccard系数）"""
        if not slots_a or not slots_b:
            return 0.0
        set_a, set_b = set(slots_a), set(slots_b)
        intersection = set_a & set_b
        union = set_a | set_b
        return len(intersection) / len(union) if union else 0.0
    
    def find_matches_for_user(
        self,
        user_id: int,
        max_results: int = 10,
        min_score: float = 60.0,
        exclude_user_ids: set[int] | None = None
    ) -> list[MatchCandidate]:
        """
        为指定用户寻找最佳同伴匹配
        
        流程:
        1. 获取用户特征向量
        2. 候选池筛选（同学段、年级差≤2、已授权）
        3. 批量计算匹配分
        4. 过滤已同圈用户
        5. 排序返回Top-N
        """
        target_vector = self._load_user_vector(user_id)
        if not target_vector or not target_vector.social_authorized:
            return []
        
        # 候选池：从缓存/数据库预筛
        candidates = self._get_candidate_pool(
            stage=target_vector.stage,
            grade_min=target_vector.grade - 2,
            grade_max=target_vector.grade + 2,
            exclude=exclude_user_ids or set()
        )
        
        scored = []
        for candidate_id in candidates:
            candidate_vector = self._load_user_vector(candidate_id)
            score, dimensions = self.calculate_match_score(
                target_vector, candidate_vector
            )
            if score >= min_score:
                scored.append(MatchCandidate(
                    user_id=candidate_id,
                    score=score,
                    dimensions=dimensions,
                    vector=candidate_vector
                ))
        
        # 按分数降序，取Top-N
        scored.sort(key=lambda x: x.score, reverse=True)
        return scored[:max_results]
```

### 4.3 圈层自动组建算法

当用户发起"帮我找学习伙伴"请求时，系统执行自动组圈：

```python
class CircleFormationService:
    """
    自动组建学习圈服务
    """
    
    MIN_MEMBERS = 3
    OPTIMAL_MEMBERS = 5
    MAX_MEMBERS = 8
    
    def auto_form_circle(
        self,
        initiator_id: int,
        preferences: CirclePreferences,
        match_engine: CircleMatchEngine
    ) -> StudyCircle:
        """
        自动组建学习圈
        
        算法:
        1. 以发起人为中心寻找候选同伴
        2. 构建候选关系图（彼此之间也有一定匹配度）
        3. 使用贪心算法选择使"团队整体匹配度"最大化的成员组合
        4. 创建圈层并发出邀请
        """
        # Step 1: 获取发起人的匹配候选
        candidates = match_engine.find_matches_for_user(
            user_id=initiator_id,
            max_results=30,
            min_score=preferences.min_match_score
        )
        
        if len(candidates) < self.MIN_MEMBERS - 1:
            raise BizException(
                code="INSUFFICIENT_CANDIDATES",
                message=f"匹配候选不足，无法组建学习圈（需要至少{self.MIN_MEMBERS}人）"
            )
        
        # Step 2: 计算候选之间的互相匹配度（构建邻接矩阵）
        all_users = [initiator_id] + [c.user_id for c in candidates]
        pairwise_scores = self._compute_pairwise_scores(all_users, match_engine)
        
        # Step 3: 贪心选择成员组合
        selected = self._greedy_select_members(
            initiator_id=initiator_id,
            candidates=candidates,
            pairwise_scores=pairwise_scores,
            target_size=preferences.target_size or self.OPTIMAL_MEMBERS
        )
        
        # Step 4: 创建圈层
        circle = self._create_circle(
            initiator_id=initiator_id,
            members=selected,
            preferences=preferences
        )
        
        # Step 5: 发送邀请（异步通知）
        for member_id in selected:
            if member_id != initiator_id:
                self.notification_service.send_circle_invitation(
                    circle_id=circle.id,
                    inviter_id=initiator_id,
                    invitee_id=member_id,
                    match_score=pairwise_scores[initiator_id][member_id]
                )
        
        return circle
    
    def _greedy_select_members(
        self,
        initiator_id: int,
        candidates: list[MatchCandidate],
        pairwise_scores: dict[int, dict[int, float]],
        target_size: int
    ) -> list[int]:
        """
        贪心选择成员组合，最大化团队整体匹配度
        
        团队匹配度 = 所有成员对之间匹配分数的平均值
        """
        selected = [initiator_id]
        remaining = [c.user_id for c in candidates]
        
        while len(selected) < target_size and remaining:
            best_addition = None
            best_delta = -1
            
            for candidate_id in remaining:
                # 计算加入此人后的团队平均匹配度增量
                avg_with_new = self._team_avg_score(
                    selected + [candidate_id], pairwise_scores
                )
                if avg_with_new > best_delta:
                    best_delta = avg_with_new
                    best_addition = candidate_id
            
            if best_addition and best_delta > 0:
                selected.append(best_addition)
                remaining.remove(best_addition)
            else:
                break  # 无法提升团队匹配度，停止
        
        return selected
    
    def _team_avg_score(
        self,
        members: list[int],
        pairwise_scores: dict[int, dict[int, float]]
    ) -> float:
        """计算团队成员间平均匹配度"""
        if len(members) < 2:
            return 0.0
        total = 0.0
        count = 0
        for i in range(len(members)):
            for j in range(i + 1, len(members)):
                total += pairwise_scores[members[i]][members[j]]
                count += 1
        return total / count if count > 0 else 0.0
```

```python
class SocialSafetyGuard:
    """
    社交安全守卫：对所有社交互动进行前置检查
    """
    
    # 内容发布频率限制
    RATE_LIMITS = {
        "qa_thread": {"max": 5, "window_minutes": 60},     # 每小时最多5个问题
        "qa_reply": {"max": 20, "window_minutes": 60},     # 每小时最多20条回复
        "note": {"max": 3, "window_minutes": 60},          # 每小时最多3篇笔记
        "circle_create": {"max": 1, "window_minutes": 1440},# 每天最多创建1个圈
        "invite_send": {"max": 10, "window_minutes": 60},  # 每小时最多10个邀请
    }
    
    # 禁止行为
    FORBIDDEN_ACTIONS = [
        "DIRECT_MESSAGE",        # 禁止自由私信（只能在圈内公开互动）
        "SHARE_CONTACT",         # 禁止分享联系方式
        "EXTERNAL_LINK",         # 禁止外链（白名单CDN域名除外）
        "REAL_NAME_EXPOSURE",    # 禁止暴露真实姓名
    ]
    
    def check_before_publish(
        self,
        user_id: int,
        content: str,
        action_type: str,
        circle_id: int | None = None
    ) -> SafetyCheckResult:
        """
        发布前安全检查
        """
        # 1. 频率检查
        if not self._check_rate_limit(user_id, action_type):
            return SafetyCheckResult(
                passed=False,
                reason="RATE_LIMIT_EXCEEDED",
                message="发布太频繁了，休息一下吧~"
            )
        
        # 2. 内容审核（敏感词、联系方式、不当内容）
        moderation_result = self.content_moderation_service.check_sync(
            content=content,
            user_age=self._get_user_age(user_id),
            scene="PEER_SOCIAL"
        )
        if not moderation_result.passed:
            return SafetyCheckResult(
                passed=False,
                reason="CONTENT_REJECTED",
                message=moderation_result.reason
            )
        
        # 3. 联系方式泄露检测
        if self._detect_contact_info(content):
            return SafetyCheckResult(
                passed=False,
                reason="CONTACT_INFO_DETECTED",
                message="为了保护安全，请不要在内容中包含联系方式哦"
            )
        
        # 4. 外链检测
        external_links = self._extract_external_links(content)
        if external_links:
            whitelisted = self._filter_whitelist_domains(external_links)
            if len(whitelisted) < len(external_links):
                return SafetyCheckResult(
                    passed=False,
                    reason="EXTERNAL_LINK_DETECTED",
                    message="不支持分享外部链接"
                )
        
        return SafetyCheckResult(passed=True)
    
    def check_parent_authorization(
        self,
        user_id: int,
        action_scope: str
    ) -> bool:
        """
        检查家长是否已授权该社交功能范围
        
        授权范围:
        - VIEW_CIRCLE: 查看圈层信息
        - INTERACT: 互动（发帖、回复）
        - CREATE_CIRCLE: 创建圈层
        - JOIN_MATCH: 接受系统匹配
        """
        authorization = self._get_parent_authorization(user_id)
        if not authorization:
            return False
        
        required_level = {
            "VIEW_CIRCLE": 1,
            "INTERACT": 2,
            "CREATE_CIRCLE": 3,
            "JOIN_MATCH": 3,
        }
        
        return authorization.authorized_level >= required_level.get(action_scope, 3)
```

### 8.3 贡献度衰减机制

```python
class ContributionDecayService:
    """
    贡献度半衰减机制：防止只活跃一段时间后长期挂名
    
    规则：
    - 贡献度总量按90天半衰减
    - 每日衰减 = 当前总量 × (1 - 0.5^(1/90))
    - 近30天新增的贡献度不衰减
    """
    
    HALF_LIFE_DAYS = 90
    RECENT_PROTECTION_DAYS = 30
    
    def calculate_decay(self, user_id: int) -> int:
        total = self._get_total_contribution(user_id)
        recent = self._get_recent_contribution(user_id, self.RECENT_PROTECTION_DAYS)
        decayable = total - recent
        
        if decayable <= 0:
            return 0
        
        daily_decay_rate = 1 - (0.5 ** (1 / self.HALF_LIFE_DAYS))
        daily_decay = int(decayable * daily_decay_rate)
        return daily_decay
```

```java
/**

@Service
@Slf4j
public class CircleLifecycleService {
    
    @Autowired private StudyCircleRepository circleRepo;
    @Autowired private CircleMemberRepository memberRepo;
    @Autowired private NotificationService notificationService;
    @Autowired private CircleEventProducer eventProducer;
    @Autowired private SocialSafetyGuard safetyGuard;
    
    /** 最大圈层数限制 */
    private static final int MAX_CIRCLES_PER_USER = 3;
    
    /**
     * 创建学习圈
     */
    @Transactional
    public CircleCreateResult createCircle(
        Long creatorId,
        CircleCreateRequest request
    ) {
        // 1. 安全校验
        safetyGuard.checkParentAuthorization(creatorId, "CREATE_CIRCLE");
        
        // 2. 数量限制检查
        int activeCircles = memberRepo.countActiveCirclesByUser(creatorId);
        if (activeCircles >= MAX_CIRCLES_PER_USER) {
            throw new BizException(
                SocialErrorCodes.MAX_CIRCLES_EXCEEDED,
                String.format("每人最多同时加入%d个学习圈", MAX_CIRCLES_PER_USER)
            );
        }
        
        // 3. 创建圈层实体
        StudyCircle circle = StudyCircle.builder()
            .circleNo(generateCircleNo())
            .name(request.getName())
            .description(request.getDescription())
            .circleType(request.getCircleType())
            .subject(request.getSubject())
            .stage(request.getStage())
            .creatorId(creatorId)
            .maxMembers(request.getTargetSize())
            .currentMembers(1)
            .status(StudyCircle.Status.PENDING)
            .privacyLevel(StudyCircle.PrivacyLevel.CLOSED)
            .parentAuthorized(true)  // 前面已校验
            .build();
        
        circle = circleRepo.save(circle);
        
        // 4. 创建者自动加入为LEADER
        CircleMember leader = CircleMember.builder()
            .circleId(circle.getId())
            .userId(creatorId)
            .role(CircleMember.Role.LEADER)
            .joinSource(CircleMember.JoinSource.SELF_JOIN)
            .status(CircleMember.Status.ACTIVE)
            .joinedAt(Instant.now())
            .build();
        memberRepo.save(leader);
        
        // 5. 自动匹配（如请求）
        MatchResult matchResult = null;
        if (request.isAutoMatch()) {
            matchResult = triggerAutoMatch(circle, request.getPreferences());
        }
        
        // 6. 发送领域事件
        eventProducer.publish(new CircleCreatedEvent(
            circle.getId(), creatorId, Instant.now()
        ));
        
        return CircleCreateResult.builder()
            .circleId(circle.getId())
            .circleNo(circle.getCircleNo())
            .status(circle.getStatus())
            .matchResults(matchResult)
            .build();
    }
    
    /**
     * 成员加入圈层
     */
    @Transactional
    public void joinCircle(
        Long userId,
        Long circleId,
        String joinMessage
    ) {
        StudyCircle circle = circleRepo.findById(circleId)
            .orElseThrow(() -> new NotFoundException("圈层不存在"));
        
        // 状态校验
        if (circle.getStatus() != StudyCircle.Status.ACTIVE 
            && circle.getStatus() != StudyCircle.Status.PENDING) {
            throw new BizException(
                SocialErrorCodes.CIRCLE_NOT_JOINABLE,
                "该学习圈当前不可加入"
            );
        }
        
        // 容量校验
        if (circle.getCurrentMembers() >= circle.getMaxMembers()) {
            throw new BizException(
                SocialErrorCodes.CIRCLE_FULL,
                "学习圈已满员"
            );
        }
        
        // 家长授权校验
        safetyGuard.checkParentAuthorization(userId, "JOIN_MATCH");
        
        // 圈层数量限制
        int activeCircles = memberRepo.countActiveCirclesByUser(userId);
        if (activeCircles >= MAX_CIRCLES_PER_USER) {
            throw new BizException(
                SocialErrorCodes.MAX_CIRCLES_EXCEEDED,
                "已达到最大圈层数限制"
            );
        }
        
        // 检查是否已在圈中
        if (memberRepo.existsByCircleIdAndUserIdAndStatus(
            circleId, userId, CircleMember.Status.ACTIVE
        )) {
            throw new BizException(
                SocialErrorCodes.ALREADY_MEMBER,
                "已在圈层中"
            );
        }
        
        // 根据隐私级别决定是否需要审核
        CircleMember member;
        if (circle.getPrivacyLevel() == StudyCircle.PrivacyLevel.OPEN) {
            member = CircleMember.builder()
                .circleId(circleId)
                .userId(userId)
                .role(CircleMember.Role.MEMBER)
                .joinSource(CircleMember.JoinSource.SELF_JOIN)
                .status(CircleMember.Status.ACTIVE)
                .joinedAt(Instant.now())
                .build();
            circle.setCurrentMembers(circle.getCurrentMembers() + 1);
            circleRepo.save(circle);
        } else {
            member = CircleMember.builder()
                .circleId(circleId)
                .userId(userId)
                .role(CircleMember.Role.MEMBER)
                .joinSource(CircleMember.JoinSource.SELF_JOIN)
                .status(CircleMember.Status.INVITED) // 待审核
                .build();
            
            // 通知圈主审核
            notificationService.sendJoinRequest(circle.getCreatorId(), circleId, userId, joinMessage);
        }
        
        memberRepo.save(member);
        
        eventProducer.publish(new MemberJoinedEvent(
            circleId, userId, Instant.now()
        ));
    }
    
    /**
     * 圈层自动冻结检测（定时任务调用）
     * 规则：14天内无任何活跃成员互动 → 冻结
     */
    @Scheduled(cron = "0 0 3 * * *") // 每天凌晨3点
    public void autoFreezeInactiveCircles() {
        List<Long> inactiveCircleIds = circleRepo.findInactiveCircles(
            Duration.ofDays(14)
        );
        
        for (Long circleId : inactiveCircleIds) {
            try {
                freezeCircle(circleId, "连续14天无活跃互动，自动冻结");
            } catch (Exception e) {
                log.error("自动冻结圈层失败 circleId={}", circleId, e);
            }
        }
    }
    
    private void freezeCircle(Long circleId, String reason) {
        StudyCircle circle = circleRepo.findById(circleId).orElse(null);
        if (circle == null || circle.getStatus() == StudyCircle.Status.DISSOLVED) {
            return;
        }
        
        circle.setStatus(StudyCircle.Status.FROZEN);
        circleRepo.save(circle);
        
        // 通知所有成员
        List<CircleMember> members = memberRepo.findActiveByCircleId(circleId);
        for (CircleMember member : members) {
            notificationService.sendCircleFrozen(
                member.getUserId(), circleId, reason
            );
        }
        
        eventProducer.publish(new CircleFrozenEvent(circleId, reason, Instant.now()));
    }
}
```

```java
/**
 * 监听答题行为，自动更新相关小组挑战进度

@Component
@Slf4j
public class ChallengeProgressListener {
    
    @Autowired private GroupChallengeRepository challengeRepo;
    @Autowired private CircleMemberRepository memberRepo;
    @Autowired private NotificationService notificationService;
    
    @KafkaListener(topics = "learning-behavior-events")
    public void onLearningBehavior(LearningBehaviorEvent event) {
        // 只关注题目完成事件
        if (event.getEventType() != LearningBehaviorEvent.Type.QUESTION_ANSWERED) {
            return;
        }
        
        Long userId = event.getUserId();
        
        // 查找该用户所在的所有活跃圈层的活跃挑战
        List<Long> circleIds = memberRepo.findActiveCircleIdsByUser(userId);
        if (circleIds.isEmpty()) return;
        
        List<GroupChallenge> activeChallenges = challengeRepo
            .findActiveByCircleIds(circleIds);
        
        for (GroupChallenge challenge : activeChallenges) {
            // 只统计对应学科的挑战
            if (challenge.getSubject() != null 
                && !challenge.getSubject().equals(event.getSubject())) {
                continue;
            }
            
            // 更新进度
            ChallengeProgress progress = challenge.getProgress();
            if ("total_questions".equals(progress.getTargetType())) {
                progress.incrementCompleted(1);
            }
            
            // 记录个人贡献
            progress.recordMemberContribution(userId, 1, event.isCorrect());
            
            challengeRepo.save(challenge);
            
            // 检查是否完成
            if (progress.isCompleted()) {
                handleChallengeCompleted(challenge);
            }
        }
    }
    
    private void handleChallengeCompleted(GroupChallenge challenge) {
        challenge.setStatus(GroupChallenge.Status.COMPLETED);
        challengeRepo.save(challenge);
        
        // 发放奖励
        RewardConfig reward = challenge.getRewardConfig();
        List<CircleMember> members = memberRepo.findActiveByCircleId(
            challenge.getCircleId()
        );
        
        for (CircleMember member : members) {
            // 发放积分
            if (reward.getPoints() > 0) {
                pointsService.award(
                    member.getUserId(),
                    reward.getPoints(),
                    "GROUP_CHALLENGE",
                    challenge.getId()
                );
            }
            // 发放徽章
            if (reward.getBadge() != null) {
                badgeService.award(
                    member.getUserId(),
                    reward.getBadge()
                );
            }
            
            // 通知
            notificationService.sendChallengeCompleted(
                member.getUserId(),
                challenge.getCircleId(),
                challenge.getTitle()
            );
        }
    }
}
```

### 11.2 匹配计算缓存策略

```python
class MatchVectorCache:
    """
    匹配向量缓存：避免重复计算学情特征
    失效策略：学情数据更新时主动失效
    """
    
    CACHE_KEY = "social:match_vector:{user_id}"
    TTL = 3600  # 1小时
    
    def get_or_compute(self, user_id: int) -> SocialMatchVector:
        cached = self.redis.get_json(self.CACHE_KEY.format(user_id=user_id))
        if cached:
            return SocialMatchVector.from_dict(cached)
        
        # 实时计算
        vector = self._compute_vector(user_id)
        self.redis.set_json(
            self.CACHE_KEY.format(user_id=user_id),
            vector.to_dict(),
            ex=self.TTL
        )
        return vector
    
    def invalidate(self, user_id: int):
        """学情数据更新时调用"""
        self.redis.delete(self.CACHE_KEY.format(user_id=user_id))
```

## 15. 边界条件与注意事项

### 15.1 特殊场景处理

| 场景 | 处理方式 |
|------|----------|
| 用户年级升迁 | 自动更新匹配向量，标记旧圈层为"年级不匹配"，推荐新圈层 |
| 用户学段切换 | 小学→初中过渡期，旧圈层保持可见但不可新建活动，引导加入新学段圈层 |
| 家长取消授权 | 冻结用户在所有圈层的成员状态，保留历史数据，30天后自动退出 |
| 用户注销账号 | 自动退出所有圈层，协作内容标记为"已注销用户"保留展示（不删除笔记/问答，保护圈层内容完整性） |
| 圈主退出 | 自动转让圈主给贡献度最高的活跃成员；无活跃成员则解散 |
| 圈层成员不足3人 | 7天宽限期内推荐补充成员；超期自动冻结 |
| 网络断连时发帖 | 客户端本地队列缓存，恢复后重试（参照弱网方案） |
| 并发同时加入 | 数据库乐观锁控制 `current_members`，超员时返回失败 |

### 15.2 注意事项

1. **未成年人保护优先于一切体验优化**：任何模糊地带一律选择更保守的策略
2. **匹配算法可解释性**：必须能向用户/家长解释"为什么推荐这个人"，避免黑箱
3. **内容留存**：同伴问答和协作笔记是学习资产，用户退出后不删除，仅匿名化
4. **AI辅助边界**：AI在同伴问答中是"辅助"角色，不应取代学生间的真实互动，需控制触发条件（如30分钟无人回复才触发）
5. **反作弊**：贡献度系统需防止刷分（重复发帖、互相点赞等），参照 `设备指纹与反作弊风控引擎`
