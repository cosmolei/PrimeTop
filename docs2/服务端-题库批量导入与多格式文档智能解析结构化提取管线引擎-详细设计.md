# 服务端-题库批量导入与多格式文档智能解析结构化提取管线引擎-详细设计

## 1. 概述

### 1.1 功能定位

题库批量导入引擎是教育内容生产线的核心入口组件。内容编辑人员、教研团队和供应商通过上传 Word（.docx）、Excel（.xlsx）、PDF（.pdf）、LaTeX（.tex）、Markdown（.md）等格式的题目文档，系统自动完成：

1. 文档解析与结构识别
2. 题目边界检测与切分
3. 题型自动分类（选择题、填空题、解答题、判断题等）
4. 数学公式提取与格式转换（OMML → LaTeX）
5. 嵌入图片提取与对象存储
6. 答案与解析关联映射
7. 知识点自动预标注
8. 质量校验与重复检测
9. 入库审核流转

### 1.2 设计目标

| 指标 | 目标值 |
| --- | --- |
| 单次导入文件大小上限 | 50MB |
| 单文件题目数量上限 | 2000 题 |
| 解析准确率（结构化提取） | ≥ 95% |
| 数学公式转换准确率 | ≥ 98% |
| 图片提取成功率 | ≥ 99% |
| 单题平均处理耗时 | ≤ 500ms |
| 并发导入任务数 | ≤ 20 |
| 部分成功率（有效题目占比） | ≥ 90% |

### 1.3 适用范围

- 管理后台 → 题库管理 → 批量导入
- 供应商交付内容入库前处理
- 教研团队自建题库导入
- 历史纸质试卷数字化录入（配合 OCR 扫描件）

### 3.4 统一中间表示（IR）数据模型

所有格式的文档在解析后都转换为统一的中间表示（Intermediate Representation），供后续结构化提取使用：

```java
/**
 * 文档统一中间表示
 */
public class DocumentIR {
    private String jobId;
    private String sourceFormat;        // docx / xlsx / pdf / tex / md
    private List<DocumentBlock> blocks; // 有序文档块列表
    private List<DocumentImage> images; // 全部图片
    private DocumentMeta meta;          // 文档元数据
}

/**
```

## 4. 核心处理流程

### 4.1 总体流水线（Pipeline DAG）

```
[1.文件接收] → [2.格式预处理] → [3.文档解析] → [4.IR生成]
                                                      │
                   ┌──────────────────────────────────┘
                   ▼
    [5.题目切分] → [6.题型识别] → [7.选项提取] → [8.答案关联]
                                                      │
                   ┌──────────────────────────────────┘
                   ▼
    [9.公式转换] → [10.图片处理] → [11.知识点标注] → [12.查重检测]
                                                      │
                   ┌──────────────────────────────────┘
                   ▼
    [13.质量评分] → [14.暂存入库] → [15.进度通知] → [等待审核]
```

每个阶段都是独立的处理单元，通过 DAG 调度器编排，支持：

- 单阶段失败不影响其他题目
- 阶段间通过 IR 传递数据
- 支持断点续处理（从失败阶段重试）
- 全程进度可追踪

### 4.2 阶段一：文件预处理

```java
/**
 * 文件预处理服务
 * 职责：格式检测、编码统一、安全扫描、文件解压
 */
@Service
public class FilePreprocessor {

    @Autowired
    private ClamAvClient clamAvClient;

    @Autowired
    private OssClient ossClient;

    /**
     * 预处理入口
     */
    public PreprocessResult preprocess(MultipartFile file, ImportJob job) {
        // 1. 基础校验
        validateFileSize(file, 50 * 1024 * 1024); // 50MB
        validateExtension(file, Set.of("docx", "xlsx", "pdf", "tex", "md"));

        // 2. 计算MD5
        String md5 = DigestUtils.md5Hex(file.getInputStream());

        // 3. 幂等校验 - 同一MD5文件不重复处理
        if (checkDuplicateFile(md5)) {
            throw new BizException("FILE_DUPLICATE", "文件已导入过，请勿重复上传");
        }

        // 4. 病毒扫描
        ScanResult scanResult = clamAvClient.scan(file.getInputStream());
        if (!scanResult.isClean()) {
            throw new BizException("FILE_UNSAFE", "文件存在安全风险: " + scanResult.getThreat());
        }

        // 5. 真实格式检测（不信任扩展名）
        String detectedFormat = detectRealFormat(file);
        if (!detectedFormat.equals(job.getFileFormat())) {
            log.warn("文件扩展名与实际格式不符: 声明={}, 实际={}", job.getFileFormat(), detectedFormat);
            job.setFileFormat(detectedFormat);
        }

        // 6. 上传到OSS
        String ossPath = String.format("imports/%s/%s/%s",
            LocalDate.now(),
            job.getJobNo(),
            file.getOriginalFilename());
        ossClient.upload(ossPath, file.getInputStream());

        // 7. 更新任务信息
        job.setFilePath(ossPath);
        job.setFileMd5(md5);
        job.setStatus(JobStatus.PREPROCESSED);

        return PreprocessResult.builder()
            .format(detectedFormat)
            .md5(md5)
            .ossPath(ossPath)
            .build();
    }

    /**
     * 基于文件魔数检测真实格式
     */
    private String detectRealFormat(MultipartFile file) throws IOException {
        byte[] header = new byte[8];
        try (InputStream is = file.getInputStream()) {
            is.read(header);
        }

        // PK zip (docx, xlsx)
        if (header[0] == 0x50 && header[1] == 0x4B) {
            String name = file.getOriginalFilename().toLowerCase();
            if (name.endsWith(".docx")) return "docx";
            if (name.endsWith(".xlsx")) return "xlsx";
            // 进一步检测内部结构
            return detectOfficeXmlType(file);
        }
        // PDF
        if (new String(header).startsWith("%PDF")) {
            return "pdf";
        }
        // 纯文本类（tex, md）
        if (isPrintableAscii(header)) {
            String name = file.getOriginalFilename().toLowerCase();
            if (name.endsWith(".tex")) return "tex";
            if (name.endsWith(".md")) return "md";
            return "md"; // 默认按markdown处理
        }
        throw new BizException("UNSUPPORTED_FORMAT", "不支持的文件格式");
    }
}
```

### 4.3 阶段二：多格式文档解析

#### 4.3.1 Word（.docx）解析器

```java
/**
 * Word文档解析器
 * 使用 Apache POI 解析 .docx 文件，生成统一 IR
 */
@Service
public class DocxParser implements DocumentParser {

    @Override
    public DocumentIR parse(InputStream input, ParseConfig config) {
        XWPFDocument doc = new XWPFDocument(input);
        DocumentIR ir = new DocumentIR();
        List<DocumentBlock> blocks = new ArrayList<>();
        Map<String, DocumentImage> imageMap = new LinkedHashMap<>();

        // 遍历文档段落
        int seq = 0;
        for (IBodyElement element : doc.getBodyElements()) {
            if (element instanceof XWPFParagraph para) {
                seq = processParagraph(para, blocks, imageMap, seq, config);
            } else if (element instanceof XWPFTable table) {
                seq = processTable(table, blocks, seq, config);
            }
        }

        // 提取文档属性
        ir.setMeta(extractDocMeta(doc));

        // 提取所有嵌入图片
        ir.setImages(new ArrayList<>(imageMap.values()));

        ir.setBlocks(blocks);
        return ir;
    }

    /**
     * 处理段落
     */
    private int processParagraph(XWPFParagraph para, List<DocumentBlock> blocks,
                                  Map<String, DocumentImage> imageMap,
                                  int seq, ParseConfig config) {
        String styleName = para.getStyle();
        String text = para.getText().trim();

        // 空段落
        if (text.isEmpty() && para.getRuns().stream().noneMatch(r -> r.getEmbeddedPictures() != null && !r.getEmbeddedPictures().isEmpty())) {
            blocks.add(new DocumentBlock(++seq, BlockType.BLANK_LINE, ""));
            return seq;
        }

        // 判断块类型
        BlockType blockType = classifyBlock(para, text, styleName, config);

        // 提取内联元素（文本 + 公式 + 图片引用）
        List<InlineElement> inlines = extractInlines(para, imageMap);

        // 构建富文本（含公式标记）
        String richText = buildRichText(inlines);

        DocumentBlock block = DocumentBlock.builder()
            .seq(++seq)
            .type(blockType)
            .text(text)
            .richText(richText)
            .inlines(inlines)
            .style(StyleInfo.from(para))
            .build();

        blocks.add(block);
        return seq;
    }

    /**
     * 提取段落内联元素，包括 OMML 公式
     */
    private List<InlineElement> extractInlines(XWPFParagraph para,
                                                Map<String, DocumentImage> imageMap) {
        List<InlineElement> inlines = new ArrayList<>();

        for (XWPFRun run : para.getRuns()) {
            // 处理文本
            String runText = run.text();
            if (runText != null && !runText.isEmpty()) {
                InlineElement textEl = new InlineElement(InlineType.TEXT, runText);
                if (run.isBold()) textEl.getAttrs().put("bold", "true");
                if (run.isItalic()) textEl.getAttrs().put("italic", "true");
                if (run.getSubscript() != VerticalAlign.NONE && run.getSubscript() == VerticalAlign.SUBSCRIPT) {
                    textEl.getAttrs().put("sub", "true");
                }
                if (run.getSubscript() != VerticalAlign.NONE && run.getSubscript() == VerticalAlign.SUPERSCRIPT) {
                    textEl.getAttrs().put("super", "true");
                }
                inlines.add(textEl);
            }

            // 处理 OMML 数学公式（关键！）
            // POI 不原生支持 OMML 提取，需要直接访问 XML
            org.apache.xmlbeans.XmlObject[] ommlObjs = run.getCTR()
                .selectChildren(javax.xml.namespace.QName.valueOf(
                    "{http://schemas.openxmlformats.org/officeDocument/2006/math}oMath"));
            for (XmlObject ommlObj : ommlObjs) {
                String ommlXml = ommlObj.xmlText();
                String latex = OmmlToLatexConverter.convert(ommlXml);
                inlines.add(new InlineElement(InlineType.FORMULA, latex));
            }

            // 处理嵌入图片
            if (run.getEmbeddedPictures() != null) {
                for (XWPFPictureData pic : run.getEmbeddedPictures()) {
                    String imageId = "img_" + UUID.randomUUID().toString().substring(0, 8);
                    DocumentImage img = new DocumentImage();
                    img.setImageId(imageId);
                    img.setFormat(detectImageFormat(pic.suggestFileExtension()));
                    img.setData(pic.getData());
                    imageMap.put(imageId, img);

                    inlines.add(new InlineElement(InlineType.IMAGE_REF, imageId));
                }
            }
        }

        return inlines;
    }

    /**
     * 块类型分类
     */
    private BlockType classifyBlock(XWPFParagraph para, String text,
                                     String styleName, ParseConfig config) {
        // 1. 基于样式名
        if (styleName != null) {
            if (styleName.contains("Heading1") || styleName.contains("标题 1"))
                return BlockType.HEADING_L1;
            if (styleName.contains("Heading2") || styleName.contains("标题 2"))
                return BlockType.HEADING_L2;
            if (styleName.contains("Heading3") || styleName.contains("标题 3"))
                return BlockType.HEADING_L3;
        }

        // 2. 基于内容模式匹配
        // 题目编号: "1." "2." "3、" "第1题"
        if (text.matches(config.getQuestionPrefixPattern())) {
            return BlockType.NUMBERED_ITEM;
        }
        // 选项: "A." "B." "A、" "(A)"
        if (text.matches(config.getOptionPattern())) {
            return BlockType.LETTERED_ITEM;
        }
        // 答案标记: "答案：" "参考答案:" "【答案】"
        if (text.matches(config.getAnswerMarkerPattern())) {
            return BlockType.ANSWER_BLOCK;
        }
        // 解析标记: "解析：" "【解析】" "分析："
        if (text.matches(config.getExplanationMarkerPattern())) {
            return BlockType.EXPLANATION_BLOCK;
        }

        return BlockType.PARAGRAPH;
    }
}
```

```java
/**
 * OMML (Office Math Markup Language) 转 LaTeX
 * 使用 XSLT 样式表 + 后处理修正
 */
public class OmmlToLatexConverter {

    private static final TransformerFactory transformerFactory = TransformerFactory.newInstance();
    private static final Templates ommlToMmlTemplates;
    private static final Templates mmlToLatexTemplates;

    static {
        try {
            // 加载 OMML → MathML XSLT (微软官方提供)
            Source ommlToMml = new StreamResource("/xslt/OMML2MML.XSL");
            ommlToMmlTemplates = transformerFactory.newTemplates(ommlToMml);

            // 加载 MathML → LaTeX XSLT (开源社区提供)
            Source mmlToLatex = new StreamResource("/xslt/mmltex.xsl");
            mmlToLatexTemplates = transformerFactory.newTemplates(mmlToLatex);
        } catch (TransformerException e) {
            throw new RuntimeException("XSLT 模板加载失败", e);
        }
    }

    /**
     * 将 OMML XML 转换为 LaTeX 字符串
     */
    public static String convert(String ommlXml) {
        try {
            // Step 1: OMML → MathML
            String mathMl = transform(ommlXml, ommlToMmlTemplates);

            // Step 2: MathML → LaTeX
            String latex = transform(mathMl, mmlToLatexTemplates);

            // Step 3: 后处理修正
            latex = postProcess(latex);

            return latex;
        } catch (Exception e) {
            log.error("OMML转LaTeX失败: {}", ommlXml, e);
            // 降级：返回原始 OMML 标记，后续人工处理
            return "[FORMULA_PARSE_ERROR:" + ommlXml.hashCode() + "]";
        }
    }

    /**
     * 后处理：修复常见转换错误
     */
    private static String postProcess(String latex) {
        // 修复分式：\frac → \dfrac (行间公式用 \dfrac)
        // 修复根号嵌套
        // 修复矩阵格式
        // 修复特殊符号映射
        latex = latex.replace("\\unicode{x2236}", ":");  // 比号
        latex = latex.replace("\\unicode{x2221}", "∠");  // 角
        latex = latex.replace("\\unicode{x22A5}", "⊥");  // 垂直

        // 修复上下标中的多字符问题
        latex = fixMultiCharScripts(latex);

        // 去除多余空格
        latex = latex.replaceAll("\\s+", " ").trim();

        return latex;
    }

    private static String fixMultiCharScripts(String latex) {
        // 将 x_{abc} 修复为 x_{abc}（确认花括号正确）
        // 将 ^2 → ^{2} 统一格式
        return latex;
    }
}
```

```java
/**
 * Excel文档解析器
 * 适用于模板化导入：每行一道题，列定义题型、题干、选项、答案等
 */
@Service
public class XlsxParser implements DocumentParser {

    // 标准 Excel 导入模板列定义
    private static final Map<String, Integer> STANDARD_COLUMNS = Map.of(
        "题型", 0,
        "难度", 1,
        "章节", 2,
        "知识点", 3,
        "题干", 4,
        "选项A", 5,
        "选项B", 6,
        "选项C", 7,
        "选项D", 8,
        "选项E", 9,
        "答案", 10,
        "解析", 11
    );

    @Override
    public DocumentIR parse(InputStream input, ParseConfig config) {
        try (Workbook wb = WorkbookFactory.create(input)) {
            Sheet sheet = wb.getSheetAt(0);

            // 1. 读取表头，建立列映射
            Row headerRow = sheet.getRow(0);
            Map<String, Integer> colMap = buildColumnMapping(headerRow);

            // 2. 逐行解析为 DocumentBlock
            List<DocumentBlock> blocks = new ArrayList<>();
            int seq = 0;
            for (int r = 1; r <= sheet.getLastRowNum(); r++) {
                Row row = sheet.getRow(r);
                if (row == null) continue;

                // 每行转换为一个 NUMBERED_ITEM + 其选项/答案子块
                seq = processExcelRow(row, colMap, blocks, seq, config);
            }

            DocumentIR ir = new DocumentIR();
            ir.setBlocks(blocks);
            ir.setImages(new ArrayList<>()); // Excel模板通常不含图片
            ir.setMeta(new DocumentMeta("Excel导入", "", ""));
            return ir;
        }
    }

    private int processExcelRow(Row row, Map<String, Integer> colMap,
                                 List<DocumentBlock> blocks, int seq,
                                 ParseConfig config) {
        String type = getCellString(row, colMap.getOrDefault("题型", -1));
        String content = getCellString(row, colMap.getOrDefault("题干", -1));
        String answer = getCellString(row, colMap.getOrDefault("答案", -1));
        String explanation = getCellString(row, colMap.getOrDefault("解析", -1));

        if (content == null || content.isBlank()) return seq; // 空行跳过

        // 题干块
        DocumentBlock qBlock = DocumentBlock.builder()
            .seq(++seq)
            .type(BlockType.NUMBERED_ITEM)
            .text(content)
            .richText(content)
            .build();
        // 附加元数据
        qBlock.getMeta().put("questionType", type);
        qBlock.getMeta().put("difficulty", getCellString(row, colMap.get("难度")));
        qBlock.getMeta().put("chapter", getCellString(row, colMap.get("章节")));
        qBlock.getMeta().put("knowledgePoints", getCellString(row, colMap.get("知识点")));
        blocks.add(qBlock);

        // 选项块（选择题）
        for (String optKey : List.of("选项A", "选项B", "选项C", "选项D", "选项E")) {
            String optText = getCellString(row, colMap.getOrDefault(optKey, -1));
            if (optText != null && !optText.isBlank()) {
                blocks.add(DocumentBlock.builder()
                    .seq(++seq)
                    .type(BlockType.LETTERED_ITEM)
                    .text(optText)
                    .richText(optText)
                    .build());
            }
        }

        // 答案块
        if (answer != null && !answer.isBlank()) {
            blocks.add(DocumentBlock.builder()
                .seq(++seq)
                .type(BlockType.ANSWER_BLOCK)
                .text(answer)
                .richText(answer)
                .build());
        }

        // 解析块
        if (explanation != null && !explanation.isBlank()) {
            blocks.add(DocumentBlock.builder()
                .seq(++seq)
                .type(BlockType.EXPLANATION_BLOCK)
                .text(explanation)
                .richText(explanation)
                .build());
        }

        return seq;
    }

    private Map<String, Integer> buildColumnMapping(Row headerRow) {
        Map<String, Integer> map = new HashMap<>();
        if (headerRow == null) return STANDARD_COLUMNS; // 降级为标准模板

        for (int c = 0; c < headerRow.getLastCellNum(); c++) {
            Cell cell = headerRow.getCell(c);
            if (cell != null) {
                String header = cell.getStringCellValue().trim();
                map.put(header, c);
            }
        }
        return map;
    }
}
```

```java
/**
 * PDF文档解析器
 * 使用 Apache PDFBox 解析文本和布局
 * 注意：PDF 解析准确率低于 Word/Excel，建议配合 OCR 校验

@Service
public class PdfParser implements DocumentParser {

    @Autowired
    private ImageExtractor imageExtractor;

    @Override
    public DocumentIR parse(InputStream input, ParseConfig config) {
        try (PDDocument doc = Loader.loadPDF(input.readAllBytes())) {

            PDFTextStripper stripper = new PDFTextStripper();
            stripper.setSortByPosition(true);
            stripper.setParagraphStart("\n");
            stripper.setParagraphStart("\t");

            // 提取全文文本（按段落分隔）
            String fullText = stripping.getText(doc);

            // 将文本切分为段落级 Block
            List<DocumentBlock> blocks = splitToBlocks(fullText, config);

            // 提取嵌入图片
            List<DocumentImage> images = imageExtractor.extractFromPdf(doc);

            DocumentIR ir = new DocumentIR();
            ir.setBlocks(blocks);
            ir.setImages(images);
            ir.setMeta(extractPdfMeta(doc));
            return ir;
        }
    }

    /**
     * 将纯文本按模式切分为 DocumentBlock
     * PDF 解析的挑战在于丢失了样式信息，需要完全依赖模式匹配
     */
    private List<DocumentBlock> splitToBlocks(String text, ParseConfig config) {
        List<DocumentBlock> blocks = new ArrayList<>();
        String[] lines = text.split("\n");
        int seq = 0;

        for (String line : lines) {
            String trimmed = line.trim();
            if (trimmed.isEmpty()) {
                blocks.add(new DocumentBlock(++seq, BlockType.BLANK_LINE, ""));
                continue;
            }

            BlockType type = classifyByText(trimmed, config);
            blocks.add(DocumentBlock.builder()
                .seq(++seq)
                .type(type)
                .text(trimmed)
                .richText(trimmed)
                .build());
        }
        return blocks;
    }

    /**
     * 纯文本模式分类（PDF专用，因为丢失了样式信息）
     */
    private BlockType classifyByText(String text, ParseConfig config) {
        // 题号模式: "1." "2、" "第3题" "（4）" "(4)"
        if (text.matches("^(\\d+|[一二三四五六七八九十]+)[\\.、）)]\\s*\\S")) {
            return BlockType.NUMBERED_ITEM;
        }
        // 选项模式: "A." "B、" "(A)" "A）"
        if (text.matches("^[A-E][\\.、）)]\\s*\\S")) {
            return BlockType.LETTERED_ITEM;
        }
        // 答案: "答案：A" "参考答案: B" "【答案】"
        if (text.matches("^(答案|参考答案|【答案】|【参考答案】)\\s*[:：]?\\s*\\S")) {
            return BlockType.ANSWER_BLOCK;
        }
        // 解析: "解析：" "【解析】" "分析:"
        if (text.matches("^(解析|分析|【解析】|【分析】)\\s*[:：]?")) {
            return BlockType.EXPLANATION_BLOCK;
        }
        return BlockType.PARAGRAPH;
    }
}
```

### 4.4 阶段三：题目切分与结构化提取

```java
/**
 * 题目切分与结构化提取引擎
 * 基于 IR 中的 Block 序列，识别题目边界，提取完整题目结构
 */
@Service
public class QuestionStructureExtractor {

    @Autowired
    private ImportRuleService ruleService;

    @Autowired
    private KnowledgeTagger knowledgeTagger;

    /**
     * 主提取入口
     */
    public List<QuestionDraft> extract(DocumentIR ir, ImportJob job) {
        List<DocumentBlock> blocks = ir.getBlocks();

        // 加载学科专属规则
        List<ImportRule> rules = ruleService.getRules(job.getFileFormat(), job.getSubjectCode());

        // 第一步：将 Block 序列切分为题目组（QuestionGroup）
        List<QuestionGroup> groups = splitIntoGroups(blocks, rules);

        // 第二步：对每个 QuestionGroup 进行结构化解析
        List<QuestionDraft> drafts = new ArrayList<>();
        for (int i = 0; i < groups.size(); i++) {
            QuestionGroup group = groups.get(i);
            try {
                QuestionDraft draft = parseGroup(group, ir.getImages(), job, i + 1);
                drafts.add(draft);
            } catch (Exception e) {
                log.warn("题目解析失败, groupSeq={}, error={", i + 1, e.getMessage());
                QuestionDraft failed = QuestionDraft.failed(group.getSeq(), e.getMessage());
                drafts.add(failed);
            }
        }
        return drafts;
    }

    /**
     * 将 Block 序列切分为题目组
     * 核心逻辑：遇到 NUMBERED_ITEM 即开始一个新题，直到下一个 NUMBERED_ITEM 或文档结束
     */
    private List<QuestionGroup> splitIntoGroups(List<DocumentBlock> blocks,
                                                  List<ImportRule> rules) {
        List<QuestionGroup> groups = new ArrayList<>();
        QuestionGroup current = null;

        for (DocumentBlock block : blocks) {
            switch (block.getType()) {
                case NUMBERED_ITEM:
                    // 新题开始
                    if (current != null) {
                        groups.add(current);
                    }
                    current = new QuestionGroup(groups.size() + 1);
                    current.addBlock(block);
                    break;

                case HEADING_L1:
                case HEADING_L2:
                case HEADING_L3:
                    // 大题标题（如 "一、选择题（每题5分）"）
                    // 作为 section header 记录，不归入任何题目
                    if (current != null) {
                        groups.add(current);
                        current = null;
                    }
                    // 可以在规则中定义 sectionHeader 如何影响题型
                    break;

                default:
                    if (current != null) {
                        current.addBlock(block);
                    }
                    break;
            }
        }
        if (current != null) {
            groups.add(current);
        }
        return groups;
    }

    /**
     * 解析单个题目组为 QuestionDraft
     */
    private QuestionDraft parseGroup(QuestionGroup group, List<DocumentImage> images,
                                      ImportJob job, int seqNo) {
        QuestionDraft draft = new QuestionDraft();
        draft.setJobId(job.getId());
        draft.setSeqNo(seqNo);

        List<DocumentBlock> groupBlocks = group.getBlocks();
        if (groupBlocks.isEmpty()) {
            throw new ExtractionException("EMPTY_GROUP", "题目组为空");
        }

        // 提取题干（第一个 NUMBERED_ITEM 去掉序号后的内容 + 后续 PARAGRAPH 直到遇到选项/答案）
        StringBuilder contentBuilder = new StringBuilder();
        List<QuestionOption> options = new ArrayList<>();
        String answer = null;
        StringBuilder explanationBuilder = new StringBuilder();

        ParsePhase phase = ParsePhase.CONTENT;
        QuestionType detectedType = null;

        for (DocumentBlock block : groupBlocks) {
            switch (block.getType()) {
                case NUMBERED_ITEM:
                    // 去掉题号前缀
                    String content = stripNumberPrefix(block.getRichText());
                    contentBuilder.append(content);
                    detectedType = detectTypeFromContent(content, block.getMeta());
                    break;

                case LETTERED_ITEM:
                    phase = ParsePhase.OPTIONS;
                    // 解析选项
                    ParsedOption opt = parseOption(block.getRichText());
                    options.add(new QuestionOption(opt.key(), opt.text()));
                    break;

                case ANSWER_BLOCK:
                    phase = ParsePhase.ANSWER;
                    answer = extractAnswer(block.getRichText());
                    // 根据答案修正题型（多选 vs 单选）
                    detectedType = refineTypeByAnswer(detectedType, answer);
                    break;

                case EXPLANATION_BLOCK:
                    phase = ParsePhase.EXPLANATION;
                    explanationBuilder.append(stripExplanationPrefix(block.getRichText()));
                    break;

                case PARAGRAPH:
                    // 根据当前阶段追加到对应内容
                    switch (phase) {
                        case CONTENT -> contentBuilder.append("\n").append(block.getRichText());
                        case ANSWER -> answer = (answer == null ? "" : answer) + block.getRichText();
                        case EXPLANATION -> explanationBuilder.append("\n").append(block.getRichText());
                        case OPTIONS -> {
                            // 选项区域的额外段落通常是选项续行或图表说明
                            if (!options.isEmpty()) {
                                options.get(options.size() - 1)
                                    .appendText("\n" + block.getRichText());
                            }
                        }
                    }
                    break;

                case IMAGE:
                    // 关联图片到当前位置
                    String imgRef = block.getImageRef();
                    if (imgRef != null) {
                        // 将图片引用插入到当前内容
                        contentBuilder.append(String.format("[IMG:%s]", imgRef));
                    }
                    break;

                case FORMULA_BLOCK:
                    // 独立公式块
                    contentBuilder.append(String.format("\n$$%s$$\n", block.getRichText()));
                    break;

                default:
                    break;
            }
        }

        // 如果没有检测到题型，基于选项推断
        if (detectedType == null) {
            detectedType = options.isEmpty() ? QuestionType.SHORT_ANSWER : QuestionType.SINGLE_CHOICE;
        }

        // 构建结果
        draft.setQuestionType(detectedType.getCode());
        draft.setQuestionContent(contentBuilder.toString().trim());
        draft.setOptions(options);
        draft.setAnswer(answer);
        draft.setExplanation(explanationBuilder.toString().trim());

        // 关联图片
        List<String> contentImageRefs = extractImageRefs(contentBuilder.toString());
        draft.setImages(resolveImages(contentImageRefs, images));

        // 设置难度（从元数据或默认值）
        draft.setDifficulty(parseDifficulty(groupBlocks.get(0).getMeta().get("difficulty"), 3));

        return draft;
    }

    /**
     * 从内容特征检测题型
     */
    private QuestionType detectTypeFromContent(String content, Map<String, String> meta) {
        // 优先使用元数据中的题型（Excel 导入有明确列）
        if (meta != null && meta.containsKey("questionType")) {
            String type = meta.get("questionType");
            try {
                return QuestionType.fromLabel(type);
            } catch (IllegalArgumentException ignored) {}
        }

        // 基于内容模式检测
        if (content.contains("判断") || content.contains("正确") && content.contains("错误")) {
            return QuestionType.TRUE_FALSE;
        }
        if (content.contains("填空") || content.matches(".*_+.*")) {
            return QuestionType.FILL_BLANK;
        }
        if (content.contains("计算") || content.contains("求") || content.contains("解")) {
            // 不确定，待选项确认
        }

        return null; // 待后续阶段确定
    }

    /**
     * 根据答案修正题型
     */
    private QuestionType refineTypeByAnswer(QuestionType current, String answer) {
        if (answer == null || answer.isBlank()) return current;
        String trimmed = answer.trim().toUpperCase();

        // 单选：答案为单个字母 A/B/C/D
        if (trimmed.matches("^[A-E]$")) {
            return QuestionType.SINGLE_CHOICE;
        }
        // 多选：答案为多个字母 "AB" "ACD" "A,B,C"
        if (trimmed.matches("^[A-E]{2,}$") || trimmed.matches("^([A-E][,，])*[A-E]$")) {
            return QuestionType.MULTI_CHOICE;
        }
        // 判断题：答案为"正确"/"错误"/"对"/"错"/"T"/"F"
        if (trimmed.matches("^[对错正确错误TF]$")) {
            return QuestionType.TRUE_FALSE;
        }
        return current;
    }

    private enum ParsePhase { CONTENT, OPTIONS, ANSWER, EXPLANATION }
}
```

### 4.5 阶段四：图片处理

```java
/**
 * 图片提取与处理服务
 * 职责：从文档中提取嵌入图片，上传到OSS，生成引用URL
 */
@Service
public class ImageExtractor {

    @Autowired
    private OssClient ossClient;

    @Autowired
    private ImageHashService imageHashService;

    /**
     * 批量处理图片
     */
    public List<ProcessedImage> processImages(List<DocumentImage> rawImages,
                                               String jobNo) {
        List<ProcessedImage> results = new ArrayList<>();

        for (DocumentImage raw : rawImages) {
            try {
                ProcessedImage processed = processSingle(raw, jobNo);
                results.add(processed);
            } catch (Exception e) {
                log.error("图片处理失败: imageId={}, error={}", raw.getImageId(), e.getMessage());
                results.add(ProcessedImage.failed(raw.getImageId(), e.getMessage()));
            }
        }
        return results;
    }

    /**
     * 处理单张图片
     */
    private ProcessedImage processSingle(DocumentImage raw, String jobNo) throws Exception {
        byte[] data = raw.getData();
        String format = raw.getFormat();

        // 1. 格式统一：EMF/WMF → PNG（Office 矢量图格式需要转换）
        if ("emf".equalsIgnoreCase(format) || "wmf".equalsIgnoreCase(format)) {
            data = convertEmfToPng(data);
            format = "png";
        }

        // 2. 图片压缩（对大图进行合理压缩）
        data = compressIfNeeded(data, format);

        // 3. 计算感知哈希（用于图片去重）
        String perceptualHash = imageHashService.perceptualHash(data);

        // 4. 检查是否已存在相同图片
        String existingUrl = imageHashService.findByHash(perceptualHash);
        if (existingUrl != null) {
            return ProcessedImage.reused(raw.getImageId(), existingUrl, perceptualHash);
        }

        // 5. 上传到 OSS
        String ossPath = String.format("question-images/%s/%s.%s",
            jobNo, raw.getImageId(), format);
        String ossUrl = ossClient.upload(ossPath, data,
            "image/" + format);

        // 6. 记录图片哈希
        imageHashService.record(perceptualHash, ossUrl);

        return ProcessedImage.created(raw.getImageId(), ossUrl, format,
            data.length, perceptualHash);
    }

    /**
     * EMF/WMF 矢量图转 PNG
     * 使用 Apache Batik 或 LibreOffice headless 转换
     */
    private byte[] convertEmfToPng(byte[] emfData) throws Exception {
        // 方案1: 使用 batik-all 库（EMF → SVG → PNG）
        // 方案2: 调用 LibreOffice headless 命令行
        // 推荐方案2，转换保真度更高
        Path tmpInput = Files.createTempFile("emf_input_", ".emf");
        Path tmpOutput = Files.createTempFile("emf_output_", ".png");
        Files.write(tmpInput, emfData);

        ProcessBuilder pb = new ProcessBuilder(
            "libreoffice", "--headless", "--convert-to", "png",
            "--outdir", tmpOutput.getParent().toString(),
            tmpInput.toString()
        );
        pb.redirectErrorStream(true);
        Process proc = pb.start();
        int exitCode = proc.waitFor();
        if (exitCode != 0) {
            throw new RuntimeException("EMF转换失败: " + new String(proc.getInputStream().readAllBytes()));
        }

        // 找到转换后的PNG文件
        String outputName = tmpInput.getFileName().toString().replace(".emf", ".png");
        Path pngPath = tmpOutput.resolveSibling(outputName);
        byte[] pngData = Files.readAllBytes(pngPath);

        // 清理临时文件
        Files.deleteIfExists(tmpInput);
        Files.deleteIfExists(pngPath);

        return pngData;
    }

    /**
     * 图片压缩策略
     */
    private byte[] compressIfNeeded(byte[] data, String format) throws Exception {
        // 超过 500KB 的图片进行压缩
        if (data.length > 500 * 1024) {
            BufferedImage img = ImageIO.read(new ByteArrayInputStream(data));

            // 计算缩放比例（最大宽度 1200px）
            int maxW = 1200;
            if (img.getWidth() > maxW) {
                int newH = (int) ((double) maxW / img.getWidth() * img.getHeight());
                BufferedImage scaled = new BufferedImage(maxW, newH, BufferedImage.TYPE_INT_RGB);
                Graphics2D g = scaled.createGraphics();
                g.setRenderingHint(RenderingHints.KEY_INTERPOLATION,
                    RenderingHints.VALUE_INTERPOLATION_BILINEAR);
                g.drawImage(img, 0, 0, maxW, newH, null);
                g.dispose();
                img = scaled;
            }

            ByteArrayOutputStream baos = new ByteArrayOutputStream();
            ImageWriter writer = ImageIO.getImageWritersByFormatName(format).next();
            ImageWriteParam param = writer.getDefaultWriteParam();
            if ("jpg".equals(format) || "jpeg".equals(format)) {
                param.setCompressionMode(ImageWriteParam.MODE_EXPLICIT);
                param.setCompressionQuality(0.85f); // 85% 质量
            }
            writer.write(ImageIO.createImageOutputStream(baos).,
                new IIOImage(img, null, null), param);
            writer.dispose();
            return baos.toByteArray();
        }
        return data;
    }
}
```

```java
            .index("knowledge_points")
            .query(q -> q.bool(b -> b
                .must(m -> m.term(t -> t.field("subject_code").value(subjectCode)))
                .should(m -> m.multiMatch(mm -> mm
                    .query(text)
                    .fields("name^3", "keywords^2", "description")
                    .fuzziness("AUTO")))
                .minimumShouldMatch("1")
            ))
            .size(10),
            Map.class
        );

        return response.hits().hits().stream()
            .map(hit -> {
                Map<String, Object> source = hit.source();
                double score = hit.score() != null ? hit.score() : 0;
                double normalizedScore = Math.min(score / 20.0, 1.0); // 归一化
                return new KpSuggestion(
                    (String) source.get("id"),
                    (String) source.get("name"),
                    normalizedScore
```

### 4.7 阶段六：查重检测

```java
/**
 * 题目查重服务
 * 基于 SimHash + 语义相似度的双层查重
 */
@Service
public class DeduplicationChecker {

    @Autowired
    private QuestionRepository questionRepository;

    @Autowired
    private SimHashService simHashService;

    @Autowired
    private VectorSearchClient vectorClient;

    /**
     * 批量查重
     */
    public DedupResult check(QuestionDraft draft) {
        String normalizedText = normalize(draft.getQuestionContentLatex());

        // 第一层：SimHash 快速筛选
        String simHash = simHashService.compute(normalizedText);
        draft.setDedupSimHash(simHash);

        // 海明距离 ≤ 3 的视为疑似重复
        List<Question> candidates = questionRepository.findBySimHashHammingDistance(
            simHash, 3, 1000);

        if (candidates.isEmpty()) {
            return DedupResult.noDuplicate();
        }

        // 第二层：对疑似重复项进行精确相似度计算
        List<SimilarityResult> detailedResults = new ArrayList<>();
        for (Question candidate : candidates) {
            double similarity = computeJaccardSimilarity(
                normalizedText,
                normalize(candidate.getContentText())
            );
            if (similarity >= 0.85) {
                detailedResults.add(new SimilarityResult(
                    candidate.getId(), similarity, candidate.getSubjectCode(),
                    candidate.getGradeCode()
                ));
            }
        }

        detailedResults.sort(Comparator.comparingDouble(SimilarityResult::getSimilarity).reversed());

        if (detailedResults.isEmpty()) {
            return DedupResult.noDuplicate();
        }

        SimilarityResult top = detailedResults.get(0);
        return DedupResult.builder()
            .isDuplicate(top.getSimilarity() >= 0.92)
            .topMatch(top)
            .allMatches(detailedResults)
            .action(top.getSimilarity() >= 0.92 ? "SKIP" : "REVIEW")
            .build();
    }

    /**
     * 文本归一化（去除不影响语义的差异）
     */
    private String normalize(String text) {
        if (text == null) return "";
        // 去除所有空白
        text = text.replaceAll("\\s+", "");
        // 统一标点
        text = text.replaceAll("[，。、；：]", "");
        // 去除 LaTeX 公式标记符（保留公式内容）
        text = text.replaceAll("\\$+", "");
        // 统一数字格式
        text = text.replaceAll("（(\\d+)）", "($1)");
        return text;
    }

    /**
     * Jaccard 相似度（基于 N-gram）
     */
    private double computeJaccardSimilarity(String s1, String s2) {
        Set<String> ngrams1 = generateNGrams(s1, 3);
        Set<String> ngrams2 = generateNGrams(s2, 3);

        Set<String> intersection = new HashSet<>(ngrams1);
        intersection.retainAll(ngrams2);

        Set<String> union = new HashSet<>(ngrams1);
        union.addAll(ngrams2);

        return union.isEmpty() ? 0 : (double) intersection.size() / union.size();
    }

    private Set<String> generateNGrams(String text, int n) {
        Set<String> ngrams = new HashSet<>();
        for (int i = 0; i <= text.length() - n; i++) {
            ngrams.add(text.substring(i, i + n));
        }
        return ngrams;
    }
}
```

## 6. 任务状态机

### 6.1 导入任务状态流转

```
                         ┌─────────────────────────────────────────────────────┐
                         │                                                     │
  QUEUED ──→ PREPROCESSING ──→ PARSING ──→ EXTRACTING ──→ POST_PROCESSING ──→ PENDING_REVIEW
     │              │              │              │               │                    │
     │              ↓              ↓              ↓               ↓                    ↓
     │         PREPROCESS     PARSE_FAILED   EXTRACT_FAILED  POST_PROCESS        COMPLETED
     │         _FAILED                                                   _FAILED
     ↓
  CANCELLED ←── (任意阶段可取消)
```

| 状态 | 说明 | 可流转至 |
| --- | --- | --- |
| `QUEUED` | 任务已创建，等待处理 | PREPROCESSING, CANCELLED |
| `PREPROCESSING` | 文件预处理中（格式检测、安全扫描） | PARSING, PREPROCESS_FAILED, CANCELLED |
| `PARSING` | 文档解析中（格式特定解析 → IR） | EXTRACTING, PARSE_FAILED, CANCELLED |
| `EXTRACTING` | 结构化提取中（切分、分类、关联） | POST_PROCESSING, EXTRACT_FAILED, CANCELLED |
| `POST_PROCESSING` | 后处理中（公式、图片、标注、查重） | PENDING_REVIEW, POST_PROCESS_FAILED, CANCELLED |
| `PENDING_REVIEW` | 全部处理完成，等待人工审核 | COMPLETED, CANCELLED |
| `COMPLETED` | 审核入库完成（终态） | - |
| `PREPROCESS_FAILED` | 预处理失败（终态） | - |
| `PARSE_FAILED` | 解析失败（终态） | - |
| `EXTRACT_FAILED` | 提取失败（可部分恢复） | - |
| `POST_PROCESS_FAILED` | 后处理失败（可部分恢复） | - |
| `CANCELLED` | 已取消（终态） | - |

```java
/**
 * 导入任务状态机
 */
public class ImportJobStateMachine {

    private static final Map<JobStatus, Set<JobStatus>> TRANSITIONS = Map.of(
        JobStatus.QUEUED,           EnumSet.of(JobStatus.PREPROCESSING, JobStatus.CANCELLED),
        JobStatus.PREPROCESSING,    EnumSet.of(JobStatus.PARSING, JobStatus.PREPROCESS_FAILED, JobStatus.CANCELLED),
        JobStatus.PARSING,          EnumSet.of(JobStatus.EXTRACTING, JobStatus.PARSE_FAILED, JobStatus.CANCELLED),
        JobStatus.EXTRACTING,       EnumSet.of(JobStatus.POST_PROCESSING, JobStatus.EXTRACT_FAILED, JobStatus.CANCELLED),
        JobStatus.POST_PROCESSING,  EnumSet.of(JobStatus.PENDING_REVIEW, JobStatus.POST_PROCESS_FAILED, JobStatus.CANCELLED),
        JobStatus.PENDING_REVIEW,   EnumSet.of(JobStatus.COMPLETED, JobStatus.CANCELLED)
    );

    public static void transition(ImportJob job, JobStatus target) {
        JobStatus current = job.getStatus();
        if (!TRANSITIONS.getOrDefault(current, EnumSet.noneOf(JobStatus.class)).contains(target)) {
            throw new IllegalStateException(
                String.format("非法状态转换: %s → %s", current, target));
        }
        job.setStatus(target);
    }
}
```

```java
    public void saveCheckpoint(Long jobId, String stage, int processedIndex,
                               Object intermediateResult) {
        String key = String.format(CHECKPOINT_KEY, jobId);
        Checkpoint cp = new Checkpoint(stage, processedIndex,
            LocalDateTime.now(), intermediateResult);
        redisTemplate.opsForValue().set(key, cp, Duration.ofHours(2));
    }

    /**
     * 读取检查点
     */
    public Checkpoint loadCheckpoint(Long jobId) {
        String key = String.format(CHECKPOINT_KEY, jobId);
        return (Checkpoint) redisTemplate.opsForValue().get(key);
    }

    /**
     * 清除检查点
     */
    public void clearCheckpoint(Long jobId) {
        redisTemplate.delete(String.format(CHECKPOINT_KEY, jobId));
    }

    /**
     * 从检查点恢复
     */
    public void resume(Long jobId) {
        Checkpoint cp = loadCheckpoint(jobId);
        if (cp == null) {
            // 无检查点，从头开始
            importPipeline.startFromBeginning(jobId);
            return;
        }

        ImportJob job = jobRepository.findById(jobId);

        // 从失败阶段的下一个题目开始
        switch (cp.getStage()) {
            case "EXTRACTING" -> importPipeline.resumeExtracting(jobId, cp.getProcessedIndex());
            case "POST_PROCESSING" -> importPipeline.resumePostProcessing(jobId, cp.getProcessedIndex());
            default -> importPipeline.startFromBeginning(jobId);
        }
    }
}
```

### 8.1 任务队列与并发管理

```java
/**
 * 导入任务调度器
 */
@Service
public class ImportJobScheduler {

    // 全局并发上限
    private static final int MAX_CONCURRENT_JOBS = 20;

    // 单任务内题目处理并发数
    private static final int PER_JOB_PARALLELISM = 5;

    private final Semaphore globalSemaphore = new Semaphore(MAX_CONCURRENT_JOBS);

    @Autowired
    @Qualifier("importTaskExecutor")
    private ThreadPoolTaskExecutor taskExecutor;

    /**
     * 提交导入任务
     */
    @Async("importTaskExecutor")
    public void execute(Long jobId) {
        if (!globalSemaphore.tryAcquire()) {
            // 等待队列位置
            jobRepository.updateStatus(jobId, JobStatus.QUEUED, "等待处理资源...");
            globalSemaphore.acquire();
        }

        try {
            ImportJob job = jobRepository.findById(jobId);
            pipeline.run(job);
        } finally {
            globalSemaphore.release();
        }
    }

    /**
     * 任务内并行处理（同一任务的多个题目后处理阶段并行）
     */
    public CompletableFuture<Void> processQuestionsParallel(
            List<QuestionDraft> drafts, ImportJob job) {

        List<CompletableFuture<Void>> futures = drafts.stream()
            .collect(Collectors.groupingByConcurrent(
                Function.identity(),
                PER_JOB_PARALLELISM  // 分5组并行
            ))
            .values()
            .stream()
            .map(group -> CompletableFuture.runAsync(() -> {
                for (QuestionDraft draft : group) {
                    try {
                        postProcessor.process(draft, job);
                    } catch (Exception e) {
                        log.error("题目后处理失败: seq={}", draft.getSeqNo(), e);
                        draft.markError(e.getMessage());
                    }
                }
            }, taskExecutor))
            .collect(Collectors.toList());

        return CompletableFuture.allOf(
            futures.toArray(new CompletableFuture[0])
        );
    }
}
```

### 8.2 大文件流式处理

对于大文件（>10MB），采用流式处理避免 OOM：

```java
/**
 * 流式 DOCX 解析（避免一次性加载大文档到内存）
 */
@Service
public class StreamingDocxParser implements DocumentParser {

    @Override
    public DocumentIR parse(InputStream input, ParseConfig config) {
        // 使用 ZIP 流式遍历 docx 内部结构
        // docx 本质是 ZIP 包: word/document.xml + word/media/

        try (ZipInputStream zis = new ZipInputStream(input)) {
            ZipEntry entry;
            ByteArrayOutputStream docXmlBuf = null;
            Map<String, byte[]> mediaFiles = new HashMap<>();

            while ((entry = zis.getNextEntry()) != null) {
                if (entry.getName().equals("word/document.xml")) {
                    docXmlBuf = new ByteArrayOutputStream();
                    zis.transferTo(docXmlBuf);
                } else if (entry.getName().startsWith("word/media/")) {
                    // 媒体文件直接读取二进制
                    String mediaName = entry.getName().substring("word/media/".length());
                    mediaFiles.put(mediaName, zis.readAllBytes());
                }
                zis.closeEntry();
            }

            if (docXmlBuf == null) {
                throw new ParseException("INVALID_DOCX", "未找到 word/document.xml");
            }

            // 流式 SAX 解析 XML，避免 DOM 树内存占用
            return parseDocumentXml(docXmlBuf.toByteArray(), mediaFiles, config);
        }
    }

    /**
     * SAX 流式 XML 解析
     */
    private DocumentIR parseDocumentXml(byte[] xmlBytes,
                                         Map<String, byte[]> mediaFiles,
                                         ParseConfig config) {
        // 使用 StAX (XMLStreamReader) 逐元素解析
        // 这比 DOM 解析节省 5-10 倍内存

        XMLInputFactory factory = XMLInputFactory.newInstance();
        // 安全配置：防止 XXE 攻击
        factory.setProperty(XMLInputFactory.IS_SUPPORTING_EXTERNAL_ENTITIES, false);
        factory.setProperty(XMLInputFactory.SUPPORT_DTD, false);

        XMLStreamReader reader = factory.createXMLStreamReader(
            new ByteArrayInputStream(xmlBytes));

        List<DocumentBlock> blocks = new ArrayList<>();
        int seq = 0;

        while (reader.hasNext()) {
            int event = reader.next();
            if (event == XMLStreamConstants.START_ELEMENT) {
                String localName = reader.getLocalName();

                if ("p".equals(localName)) {
                    // <w:p> 段落
                    seq = processParagraphElement(reader, blocks, seq, mediaFiles, config);
                } else if ("tbl".equals(localName)) {
                    // <w:tbl> 表格
                    seq = processTableElement(reader, blocks, seq);
                }
            }
        }

        DocumentIR ir = new DocumentIR();
        ir.setBlocks(blocks);
        ir.setImages(extractImagesFromMedia(mediaFiles));
        return ir;
    }
}
```

### 9.2 规则热加载

```java
/**
 * 规则服务 - 支持热加载
 */
@Service
public class ImportRuleService {

    private final AtomicReference<Map<String, List<ImportRule>>> ruleCache =
        new AtomicReference<>(new HashMap<>());

    @PostConstruct
    public void init() {
        loadRules();
    }

    /**
     * 从数据库重新加载规则到缓存
     */
    public void reload() {
        loadRules();
        log.info("导入规则缓存已刷新, 共{}条规则",
            ruleCache.get().values().stream().mapToInt(List::size).sum());
    }

    /**
     * 获取适用规则
     */
    public List<ImportRule> getRules(String fileFormat, String subjectCode) {
        return ruleCache.get().values().stream()
            .flatMap(List::stream)
            .filter(r -> r.matches(fileFormat, subjectCode))
            .sorted(Comparator.comparingInt(ImportRule::getPriority))
            .collect(Collectors.toList());
    }

    private void loadRules() {
        List<ImportRule> all = ruleRepository.findAllByEnabledTrue();
        Map<String, List<ImportRule>> grouped = all.stream()
            .collect(Collectors.groupingBy(r -> r.getFileFormat() + ":" + r.getSubjectCode()));
        ruleCache.set(grouped);
    }
}
```

```java
/**
 * 文件安全策略
 */
@Component
public class ImportFileSecurityPolicy {

    // 允许的文件扩展名
    private static final Set<String> ALLOWED_EXTENSIONS = Set.of(
        "docx", "xlsx", "pdf", "tex", "md"
    );

    // 允许的 MIME 类型
    private static final Set<String> ALLOWED_MIMES = Set.of(
        "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
        "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
        "application/pdf",
        "application/x-tex",
        "text/markdown",
        "text/plain"
    );

    // 文件大小上限
    private static final long MAX_FILE_SIZE = 50 * 1024 * 1024; // 50MB

    public void validate(MultipartFile file) {
        // 1. 文件名安全检查（防路径穿越）
        String filename = file.getOriginalFilename();
        if (filename != null && (filename.contains("..") || filename.contains("/") ||
            filename.contains("\\"))) {
            throw new SecurityException("文件名包含非法字符");
        }

        // 2. 扩展名白名单
        String ext = FilenameUtils.getExtension(filename).toLowerCase();
        if (!ALLOWED_EXTENSIONS.contains(ext)) {
            throw new SecurityException("不支持的文件格式: " + ext);
        }

        // 3. 文件大小
        if (file.getSize() > MAX_FILE_SIZE) {
            throw new SecurityException("文件超过大小限制(50MB)");
        }

        // 4. XML 宏检测（docx/xlsx 是 ZIP+XML，可能含宏）
        if (ext.equals("docx") || ext.equals("xlsx")) {
            checkNoMacros(file);
        }
    }

    /**
     * 检查 Office 文件是否包含宏（VBA 宏可能携带恶意代码）
     */
    private void checkNoMacros(MultipartFile file) {
        try (ZipInputStream zis = new ZipInputStream(file.getInputStream())) {
            ZipEntry entry;
            while ((entry = zis.getNextEntry()) != null) {
                // 检测 vbaProject.bin（VBA 宏标记）
                if (entry.getName().contains("vbaProject") ||
                    entry.getName().contains("vbaData")) {
                    throw new SecurityException("文件包含 VBA 宏，不允许导入");
                }
                zis.closeEntry();
            }
        } catch (IOException e) {
            throw new SecurityException("文件安全检测失败", e);
        }
    }
}
```

## 12. 关键实现注意事项

### 12.1 OMML 公式转换的已知问题

| 问题 | 原因 | 解决方案 |
| --- | --- | --- |
| 矩阵公式丢失行列对齐 | XSLT 转换不支持 `m:eqArr` | 自定义 XSLT 扩展，手动处理矩阵 |
| 根式嵌套层级错误 | `m:rad` 嵌套时 degree 丢失 | 后处理修正器检测并修复 |
| 积分号上下限位置异常 | OMML 使用 `naryLim` 控制定位 | 映射为 `\int\limits_^{}` |
| 中文字符在公式中丢失 | 编码转换问题 | 确保使用 UTF-8 全链路 |
| 分数显示为行内格式 | `\frac` vs `\dfrac` 选择 | 独立公式块强制使用 `\dfrac` |
| 上标多字符未加花括号 | 转换器未自动添加 `{}` | 正则后处理：`^{2n} → ^{2n}` (已正确) → 检测并修复裸上标 |

### 12.2 PDF 解析的局限性应对

PDF 格式固有挑战较大，建议采取以下策略：

1. **优先推荐 Word 格式导入**：UI 上将 Word 模板放在第一位
2. **PDF 配合 OCR 双通道**：PDF 解析结果与 OCR 结果交叉验证
3. **人工校对优先级提升**：PDF 导入的题目强制进入人工校对流程
4. **结构化 PDF 优先**：如果 PDF 是从 Word 导出的（有结构信息），解析效果更好
