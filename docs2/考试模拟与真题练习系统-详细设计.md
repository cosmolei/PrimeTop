# 考试模拟与真题练习系统 - 详细设计

## 1. 模块概述

### 1.1 功能定位

为初高中生提供结构化的考试模拟和真题练习能力，覆盖单元测试、期中期末、中考、高考等核心考试场景。系统基于题库中收录的历年真题和模拟题，支持按试卷、专题、知识点等多维度组卷，提供限时答题、自动批阅、成绩分析和薄弱点定位等一站式考试练习体验。

### 1.2 目标用户

| 用户 | 场景 |
|------|------|
| 初中生 | 单元测试、期中期末复习、中考模拟 |
| 高中生 | 月考模拟、期中期末复习、高考真题训练、专题限时练 |
| 教师 | 布置模拟考试、查看班级成绩分布 |
| 家长 | 查看孩子模考成绩、对比历史进步 |

### 1.3 与其他模块的关系

                    │   题目与题库  │ ← 提供真题与模拟题源

## 2. 核心概念与数据结构

### 2.1 试卷 (ExamPaper)

```typescript
interface ExamPaper {
  id: string;                    // 试卷唯一ID
  title: string;                 // 试卷标题，如"2025年全国甲卷数学"
  paperType: PaperType;          // 试卷类型
  examLevel: ExamLevel;          // 考试级别
  subject: Subject;              // 学科
  grade: Grade;                  // 年级
  region?: string;               // 适用地区（如"全国甲卷"、"北京卷"）
  year?: number;                 // 年份（真题年份）
  duration: number;              // 考试时长（分钟）
  totalScore: number;            // 满分分值
  difficulty: Difficulty;        // 整体难度
  sections: ExamSection[];       // 试卷分区
  status: PaperStatus;           // 试卷状态
  sourceType: SourceType;        // 来源类型
  tags: string[];                // 标签（如"高考真题"、"一模"、"名校模拟"）
  metadata: PaperMetadata;       // 元数据
  createdAt: Date;
  updatedAt: Date;
}

enum PaperType {
  REAL_EXAM = 'real_exam',           // 真题
  MOCK_EXAM = 'mock_exam',           // 模拟题
  UNIT_TEST = 'unit_test',           // 单元测试
  SECTION_TEST = 'section_test',     // 专题测试
  DAILY_PRACTICE = 'daily_practice', // 每日一练
  CUSTOM = 'custom'                  // 自定义组卷
}

enum ExamLevel {
  UNIT = 'unit',               // 单元级别
  MIDTERM = 'midterm',         // 期中
  FINAL = 'final',             // 期末
  MONTHLY = 'monthly',         // 月考
  REGIONAL_MOCK = 'regional_mock', // 地区模拟
  ZHONGKAO = 'zhongkao',       // 中考
  GAOKAO = 'gaokao'            // 高考
}

enum PaperStatus {
  DRAFT = 'draft',             // 草稿
  PUBLISHED = 'published',     // 已发布
  ARCHIVED = 'archived'        // 已归档
}

enum SourceType {
  OFFICIAL = 'official',       // 官方真题
  PARTNER = 'partner',         // 合作方提供
  AI_GENERATED = 'ai_generated', // AI生成
  EDITORIAL = 'editorial'      // 编辑录入
}

interface PaperMetadata {
  source?: string;              // 来源描述
  examDate?: Date;              // 考试日期
  applicableTextbooks?: string[]; // 适配教材版本
  knowledgePoints?: string[];   // 涉及知识点ID列表
  averageScore?: number;        // 历史平均分（平台用户统计）
  completionCount?: number;     // 已完成人次
  likeCount?: number;           // 收藏/点赞数
}
```

### 2.2 试卷分区与题目 (ExamSection, ExamQuestion)

```typescript
interface ExamSection {
  id: string;
  title: string;                 // 如"一、选择题"、"二、填空题"、"三、解答题"
  instruction: string;           // 答题说明，如"本大题共12小题，每小题5分"
  questionType: QuestionType;    // 题型
  questions: ExamQuestion[];     // 题目列表
  totalScore: number;            // 本区总分
}

enum QuestionType {
  SINGLE_CHOICE = 'single_choice',       // 单选
  MULTI_CHOICE = 'multi_choice',         // 多选
  FILL_BLANK = 'fill_blank',             // 填空
  TRUE_FALSE = 'true_false',             // 判断
  SHORT_ANSWER = 'short_answer',         // 简答
  ESSAY = 'essay',                       // 论述/作文
  CALCULATION = 'calculation',           // 计算
  PROOF = 'proof',                       // 证明
  READING_COMPREHENSION = 'reading_comp', // 阅读理解
  CLOZE = 'cloze',                       // 完形填空
  LISTENING = 'listening'                // 听力
}

interface ExamQuestion {
  id: string;
  sectionId: string;
  sequenceNumber: number;         // 题号
  content: QuestionContent;       // 题目内容
  options?: QuestionOption[];     // 选项（选择题）
  score: number;                  // 分值
  difficulty: Difficulty;         // 难度
  knowledgePointIds: string[];    // 关联知识点
  standardAnswer: AnswerContent;  // 标准答案
  scoringRubric: ScoringRubric;   // 评分细则
  analysis: AnalysisContent;      // 解析
  relatedQuestions?: string[];    // 关联题目（如大题下的子题）
  subQuestions?: ExamQuestion[];  // 子题（阅读理解下的小题等）
  isRequired: boolean;            // 是否必答
  timeSuggestion?: number;        // 建议用时（分钟）
}

interface QuestionContent {
  text: string;                   // 题干文本
  images?: ImageResource[];       // 图片资源
  audio?: AudioResource;          // 听力音频
  formulas?: FormulaResource[];   // 数学公式
  tables?: TableResource[];       // 表格
  passage?: string;               // 阅读材料/题干材料
}

interface QuestionOption {
  label: string;                  // A/B/C/D
  content: QuestionContent;       // 选项内容
  isCorrect?: boolean;            // 是否正确（阅卷用）
}

interface ScoringRubric {
  totalScore: number;
  steps: ScoringStep[];           // 分步得分点
  tolerance?: ScoringTolerance;   // 容错规则
}

interface ScoringStep {
  description: string;            // 得分点描述
  score: number;                  // 该步骤分值
  keywords?: string[];            // 关键词匹配（用于主观题辅助判分）
  keywordMatchRatio?: number;     // 关键词匹配比例阈值
}

interface AnswerContent {
  text: string;
  images?: ImageResource[];
  formulas?: FormulaResource[];
  isExactMatch?: boolean;         // 是否精确匹配（填空题）
  acceptableAnswers?: string[];   // 可接受答案列表
}

interface AnalysisContent {
  text: string;                   // 解析文本
  images?: ImageResource[];
  formulas?: FormulaResource[];
  method?: string;                // 解题方法总结
  commonMistakes?: string[];      // 常见错误提醒
  relatedKnowledgePoints?: string[]; // 相关知识点
}
```

### 2.3 考试会话 (ExamSession)

```typescript
interface ExamSession {
  id: string;
  userId: string;
  paperId: string;
  status: ExamSessionStatus;
  mode: ExamMode;
  
  // 时间管理
  startedAt?: Date;
  submittedAt?: Date;
  timeLimit: number;              // 限时（分钟）
  remainingSeconds?: number;      // 剩余秒数（实时）
  pausedAt?: Date;                // 暂停时间
  totalPausedSeconds: number;     // 累计暂停时长
  
  // 答题数据
  answers: Map<string, UserAnswer>;   // questionId → 答案
  currentQuestionId?: string;         // 当前正在答的题目
  questionVisitLog: QuestionVisit[];  // 题目访问日志
  
  // 批阅结果
  result?: ExamResult;
  
  // 元数据
  deviceInfo: DeviceInfo;
  networkType?: string;
  createdAt: Date;
  updatedAt: Date;
}

enum ExamSessionStatus {
  NOT_STARTED = 'not_started',   // 未开始
  IN_PROGRESS = 'in_progress',   // 答题中
  PAUSED = 'paused',             // 已暂停
  SUBMITTED = 'submitted',       // 已提交
  GRADING = 'grading',           // 批阅中
  GRADED = 'graded',             // 已批阅
  ABANDONED = 'abandoned'        // 已放弃
}

enum ExamMode {
  TIMED = 'timed',               // 限时模考
  UNTIMED = 'untimed',           // 不限时练习
  PRACTICE = 'practice',         // 练习模式（答完一题即出解析）
  RETAKE = 'retake'              // 重做（基于历史会话）
}

interface UserAnswer {
  questionId: string;
  content: AnswerContent;        // 用户答案内容
  selectedOptions?: string[];    // 选择的选项label
  filledText?: string;           // 填空文本
  essayText?: string;            // 主观题文本
  images?: ImageResource[];      // 拍照上传的答案
  isMarked: boolean;             // 是否标记（疑难题标记）
  timeSpentSeconds: number;      // 该题用时
  answeredAt: Date;
  isModified: boolean;           // 是否修改过
  modifiedCount: number;         // 修改次数
}

interface QuestionVisit {
  questionId: string;
  firstVisitAt: Date;
  lastVisitAt: Date;
  visitCount: number;
}

interface ExamResult {
  totalScore: number;            // 总得分
  maxScore: number;              // 满分
  scorePercentage: number;       // 得分率
  timeSpentSeconds: number;      // 总用时
  
  questionResults: QuestionResult[];
  sectionResults: SectionResult[];
  
  // 统计分析
  correctCount: number;
  wrongCount: number;
  unansweredCount: number;
  partiallyCorrectCount: number;
  
  // 知识点维度分析
  knowledgePointResults: KnowledgePointResult[];
  
  // 能力维度分析
  abilityResults: AbilityResult[];
  
  // 对比数据
  percentile?: number;           // 平台百分位
  averageScore?: number;         // 平台平均分
  
  gradedAt: Date;
  gradedBy: 'auto' | 'ai' | 'manual';
}

interface QuestionResult {
  questionId: string;
  isCorrect: boolean;
  isPartiallyCorrect: boolean;
  earnedScore: number;
  maxScore: number;
  scorePercentage: number;
  gradingDetail?: GradingDetail;  // 分步得分详情
  aiFeedback?: string;            // AI评语（主观题）
}

interface SectionResult {
  sectionId: string;
  earnedScore: number;
  maxScore: number;
  correctCount: number;
  wrongCount: number;
  unansweredCount: number;
}

interface KnowledgePointResult {
  knowledgePointId: string;
  knowledgePointName: string;
  totalQuestions: number;
  correctCount: number;
  earnedScore: number;
  maxScore: number;
  masteryLevel: MasteryLevel;
}

interface AbilityResult {
  abilityDimension: string;     // 如"计算能力"、"逻辑推理"、"阅读理解"
  earnedScore: number;
  maxScore: number;
  level: string;
}

enum MasteryLevel {
  WEAK = 'weak',           // 掌握度 < 40%
  BASIC = 'basic',         // 40% ≤ 掌握度 < 60%
  PROFICIENT = 'proficient', // 60% ≤ 掌握度 < 80%
  EXCELLENT = 'excellent'  // 掌握度 ≥ 80%
}
```

### 2.4 组卷规则 (PaperCompositionRule)

```typescript
interface PaperCompositionRule {
  id: string;
  name: string;                    // 规则名称
  subject: Subject;
  grade: Grade;
  examLevel: ExamLevel;
  
  structureRules: StructureRule[]; // 题型结构规则
  difficultyDistribution: DifficultyDistribution; // 难度分布
  knowledgeCoverage: KnowledgeCoverage; // 知识点覆盖规则
  timeLimit: number;               // 建议考试时长
  totalScore: number;              // 总分
  
  isActive: boolean;
  createdAt: Date;
}

interface StructureRule {
  sectionTitle: string;            // "一、选择题"
  questionType: QuestionType;
  questionCount: number;
  scorePerQuestion: number;
  knowledgePointConstraints?: {
    knowledgePointId: string;
    minCount: number;
    maxCount: number;
  }[];
  difficultyConstraint?: {
    min: Difficulty;
    max: Difficulty;
  };
}

interface DifficultyDistribution {
  easy: number;      // 简单题比例 (0-1)
  medium: number;    // 中等题比例
  hard: number;      // 较难题比例
}

interface KnowledgeCoverage {
  mode: 'all' | 'sample' | 'weighted';
  requiredPoints?: string[];       // 必考知识点
  weightMap?: Map<string, number>; // 知识点权重
  coverageRatio: number;           // 最小覆盖率 (0-1)
}
```

### 5.1 限时模考完整流程

```
用户选择试卷 → 创建会话 → 开始答题 → [逐题作答] → 交卷 → 批阅 → 查看报告

    b. 各题型得分
    c. 知识点掌握度雷达图
    d. 薄弱知识点列表
    e. 逐题解析入口
    f. 错题一键收录按钮
    g. 推荐复习计划
```

### 5.2 智能组卷流程

```
用户设置组卷参数 → 系统匹配题目 → 排重检查 → 生成试卷 → 预览确认

组卷算法:
1. 根据参数确定题型结构
2. 从题库中筛选候选题目:
   - 匹配学科、年级、难度
   - 匹配指定知识点（优先选择）
   - 排除已做过的题目
3. 知识点覆盖优化:
   - 贪心算法确保最大知识点覆盖率
   - 必考知识点优先排入
   - 加权随机补充其他知识点题目
4. 难度分布调整:
   - 按设定比例从各难度池中抽题
   - 若某难度题目不足，从相邻难度补充
5. 去重检查:
   - 排除最近3次考试中出现过的题目
   - 排除与已选题目高度相似（>80%文本相似度）的题目
6. 题目排序:
   - 按题型分区
   - 区内按难度升序排列（由易到难）
   - 阅读理解等关联题组保持完整
7. 生成试卷元数据并持久化
```

### 6.1 客观题批阅

```python
class ObjectiveGrader:
    """客观题自动批阅"""
    
    def grade(self, question: ExamQuestion, user_answer: UserAnswer) -> QuestionResult:
        question_type = question.question_type
        
        if question_type in ('single_choice', 'true_false'):
            return self._grade_choice(question, user_answer, allow_partial=False)
        
        elif question_type == 'multi_choice':
            return self._grade_multi_choice(question, user_answer)
        
        elif question_type == 'fill_blank':
            return self._grade_fill_blank(question, user_answer)
    
    def _grade_choice(self, question, user_answer, allow_partial=False):
        correct_options = [o.label for o in question.options if o.is_correct]
        user_options = user_answer.selected_options or []
        
        is_correct = set(user_options) == set(correct_options)
        return QuestionResult(
            question_id=question.id,
            is_correct=is_correct,
            is_partially_correct=False,
            earned_score=question.score if is_correct else 0,
            max_score=question.score,
        )
    
    def _grade_multi_choice(self, question, user_answer):
        correct_options = set(o.label for o in question.options if o.is_correct)
        user_options = set(user_answer.selected_options or [])
        
        if user_options == correct_options:
            # 全对满分
            return self._result(question, True, False, question.score)
        elif user_options.issubset(correct_options) and len(user_options) > 0:
            # 选对部分但没选全：得一半分（可配置）
            return self._result(question, False, True, question.score // 2)
        else:
            # 包含错误选项：0分（部分省份高考规则）
            return self._result(question, False, False, 0)
    
    def _grade_fill_blank(self, question, user_answer):
        answer = question.standard_answer
        user_text = (user_answer.filled_text or '').strip()
        
        if answer.is_exact_match:
            # 精确匹配
            is_correct = user_text == answer.text.strip()
        else:
            # 多答案可接受列表匹配
            acceptable = [a.strip() for a in (answer.acceptable_answers or [answer.text])]
            is_correct = user_text in acceptable
        
        # 数值容差（如答案是分数或小数）
        if not is_correct:
            is_correct = self._try_numeric_match(user_text, answer)
        
        return self._result(question, is_correct, False, 
                           question.score if is_correct else 0)
    
    def _try_numeric_match(self, user_text: str, answer: AnswerContent) -> bool:
        try:
            target = float(answer.text.strip())
            user_val = float(user_text.strip())
            tolerance = abs(target) * 0.001 + 0.01  # 相对误差0.1% + 绝对误差0.01
            return abs(user_val - target) <= tolerance
        except (ValueError, TypeError):
            return False
```

        self,

        context: GradingContext

        user_text = user_answer.essay_text or ''
        
        # 1. 构建批阅Prompt
        prompt = self._build_grading_prompt(question, rubric, user_text, context)
        
        # 2. 调用大模型（使用推理增强模型）

### 8.2 Redis 缓存设计

```
# 考试会话实时状态（答题过程中高频读写）
exam:session:{sessionId}:state
  → Hash {
      status, remainingSeconds, currentQuestionId,
      lastSyncAt, answeredCount
    }
  TTL: timeLimit * 60 + 3600 (考试时长 + 1小时buffer)

# 考试会话答案缓存（写入缓冲）
exam:session:{sessionId}:answers
  → Hash { questionId → JSON_answer }
  TTL: 同上

# 试卷热门排行
exam:papers:hot:{subject}:{grade}
  → Sorted Set { paperId → score (综合热度) }
  TTL: 1小时

# 用户进行中的考试（防止重复开考）
exam:user:active:{userId}
  → String sessionId
  TTL: timeLimit * 60 + 3600
```

## 9. 错误处理

### 9.1 异常场景与处理策略

| 场景 | 处理策略 | 用户提示 |
|------|---------|---------|
| 答题中网络断开 | 本地继续答题，缓存到SQLite | "网络已断开，答案已本地保存，联网后自动同步" |
| 交卷时网络失败 | 本地标记待提交，网络恢复后自动提交 | "提交失败，将在网络恢复后自动提交" |
| 倒计时结束前闪退 | 重启后从服务端恢复会话，继续倒计时 | "检测到未完成的考试，是否继续？" |
| 批阅超时（主观题AI服务异常） | 先返回客观题分数，主观题标记"批阅中" | "客观题已批阅，主观题正在批阅中，稍后可查看完整结果" |
| 试卷资源加载失败 | 预加载时校验完整性，失败提示重试 | "试卷资源加载失败，请检查网络后重试" |
| 并发提交冲突 | 以最后一条有效答案为准 | 无感知 |
| 组卷题目不足 | 降低知识点覆盖率要求，不足部分标记"待补充" | "题库资源有限，部分题型数量不足，已尽可能组卷" |
| AI批阅置信度低 | 标记为"待人工复核"，给出保守分数 | "此题评分仅供参考，最终以教师确认为准" |

### 9.2 断线恢复流程

```typescript
async function recoverExamSession(sessionId: string): Promise<RecoveryResult> {
  // 1. 检查本地是否有未同步的答案
  const localAnswers = await localDB.getUnsyncedAnswers(sessionId);
  
  // 2. 拉取服务端状态
  const serverState = await api.getExamSessionState(sessionId);
  
  if (serverState.status === 'in_progress') {
    // 3. 合并本地与服务端答案（以时间戳较新的为准）
    const mergedAnswers = mergeAnswers(localAnswers, serverState.answers);
    
    // 4. 同步合并后的答案到服务端
    await api.syncAnswers(sessionId, mergedAnswers);
    
    // 5. 恢复计时器（使用服务端剩余时间）
    return {
      shouldResume: true,
      remainingSeconds: serverState.remainingSeconds,
      currentQuestionId: serverState.currentQuestionId,
      answers: mergedAnswers
    };
  } else if (serverState.status === 'submitted' || serverState.status === 'graded') {
    // 服务端已交卷（可能超时自动交卷），直接查看结果
    return {
      shouldResume: false,
      shouldShowResult: true,
      result: serverState.result
    };
  }
}
```

## 10. 性能设计

### 10.1 响应时间要求

| 接口 | 目标响应时间 | 优化策略 |
|------|------------|---------|
| 试卷列表 | < 500ms | Redis缓存热门试卷列表 |
| 试卷详情 | < 800ms | 题目内容CDN缓存 |
| 提交答案 | < 200ms | 异步写入，先更新Redis |
| 交卷 | < 1s | 客观题即时批阅，主观题异步 |
| 获取批阅结果 | < 500ms | 批阅结果写入后缓存 |
| 智能组卷 | < 3s | 候选题库预计算 + 缓存 |

### 10.2 资源预加载策略

```
用户进入试卷详情页时:
1. 预加载试卷JSON数据 → 内存缓存
2. 预加载题目图片（优先加载前10题） → 磁盘缓存
3. 预加载听力音频（英语试卷） → 后台下载
4. 预创建SQLite表结构
5. 检查磁盘空间是否充足（至少预留50MB）

用户点击"开始考试"后:
1. 确认所有必要资源已加载完成
2. 未完成则阻塞等待（最多10秒）
3. 超时提示用户网络不佳，可选择继续（图片按需加载）
```

## 11. 安全与合规

### 11.1 防作弊机制

```
1. 客户端层面:
   - 切应用检测：记录切出次数和时长
   - 截屏检测：标记截屏行为
   - 答题节奏分析：异常快速答题标记
   - 设备时间篡改检测：对比服务端时间

2. 服务端层面:
   - 单设备单会话：同一用户同一时间只能有一个进行中的考试
   - IP异常检测：答题过程中IP变化过大标记
   - 答案相似度检测：批量交卷时检测异常相似答案

3. 数据层面:
   - 试卷题目按需下发（不一次性暴露全部答案）
   - 解析仅在交卷后下发
   - 批阅结果不可篡改（审计日志）
```

### 11.2 内容合规

```
- 真题使用需确认版权授权
- AI生成题目需经过内容审核
- 试卷解析内容需符合教育价值观
- 分数展示避免过度排名焦虑（展示百分位而非绝对排名）
```
