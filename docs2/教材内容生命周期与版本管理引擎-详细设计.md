# 教材内容生命周期与版本管理引擎 - 详细设计

> **模块定位**：核心基础设施，负责教材版本、章节、知识点、教材内容等资源的生命周期管理，支持内容创建、审核、发布、下架、版本迭代等全流程。

## 1. 模块概述

### 1.1 核心职责

| 职责 | 说明 |
|------|------|
| 教材版本管理 | 维护教材版本的基础信息、状态、适用范围及发布周期 |
| 章节结构管理 | 管理教材的年级、学期、单元、章节、课时层级结构 |
| 内容生命周期控制 | 支持创建、审核、发布、归档、下架、废弃等状态流转 |
| 版本迭代与对比 | 支持教材版本升级、变更记录、内容差异比对 |
| 权限与流程控制 | 集成审核流程、版本切换权限及安全合规校验 |
| 关联数据一致性 | 确保教材版本变更时，关联的知识点、题库、课程内容同步更新 |

### 1.2 依赖关系

```
┌──────────────────────────────────────────────────────┐
│            调用方（业务模块）                          │
├───────────┬───────────┬──────────┬─────────────────┤
│ 同步课堂  │ 考点梳理  │ RAG检索  │ AI辅导          │
│ 题库服务  │ 学习规划  │ 家长中心 │ 教师端          │
├───────────┴───────────┴──────────┴─────────────────┤

```

## 2. 数据结构

### 2.1 教材版本表 `textbook_versions`

```sql
CREATE TABLE textbook_versions (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT,
    publisher_id      INT NOT NULL COMMENT '出版社ID',
    subject_id        INT NOT NULL COMMENT '学科ID',
    stage             VARCHAR(20) NOT NULL COMMENT '学段: primary/junior/senior',
    name              VARCHAR(100) NOT NULL COMMENT '教材名称，如：人教版数学三年级上册',
    short_name        VARCHAR(50) NOT NULL COMMENT '简称，如：人教-三上',
    version           VARCHAR(50) NOT NULL COMMENT '版本号，如：2024-09',
    region            VARCHAR(20) DEFAULT 'national' COMMENT '适用地区',
    status            VARCHAR(20) NOT NULL DEFAULT 'draft' COMMENT 'draft/review/published/archived/deprecated',
    is_default        TINYINT NOT NULL DEFAULT 0 COMMENT '是否为默认版本',
    effective_date    DATE COMMENT '生效日期',
    expire_date       DATE COMMENT '过期日期',
    metadata          JSON COMMENT '教材元数据（目录结构、适用年级等）',
    created_by        BIGINT NOT NULL,
    created_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    published_at      DATETIME COMMENT '发布时间',
    archived_at       DATETIME COMMENT '归档时间',
    UNIQUE KEY uk_publisher_subject_version (publisher_id, subject_id, version),
    INDEX idx_status (status),
    INDEX idx_stage_subject (stage, subject_id),
    INDEX idx_effective (effective_date, expire_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教材版本表';
```

### 2.2 教材章节目录表 `textbook_chapters`

```sql
CREATE TABLE textbook_chapters (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT,
    textbook_id       BIGINT NOT NULL COMMENT '教材版本ID',
    parent_id         BIGINT COMMENT '父章节ID，顶级章节为NULL',
    grade             INT NOT NULL COMMENT '年级',
    semester          TINYINT NOT NULL COMMENT '学期 1=上学期 2=下学期',
    level             TINYINT NOT NULL COMMENT '层级 1=年级 2=单元 3=章节 4=课时',
    sort_order        INT NOT NULL DEFAULT 0 COMMENT '同级排序',
    name              VARCHAR(100) NOT NULL COMMENT '章节名称',
    code              VARCHAR(50) COMMENT '章节编码',
    knowledge_points  JSON COMMENT '关联知识点ID列表',
    metadata          JSON COMMENT '扩展元数据（课时、难度等）',
    status            VARCHAR(20) NOT NULL DEFAULT 'active',
    created_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_textbook (textbook_id),
    INDEX idx_parent (parent_id),
    INDEX idx_grade_semester (grade, semester)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教材章节目录表';
```

### 2.3 教材内容表 `textbook_contents`

```sql
CREATE TABLE textbook_contents (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT,
    textbook_id       BIGINT NOT NULL,
    chapter_id        BIGINT NOT NULL COMMENT '章节ID',
    content_type      VARCHAR(20) NOT NULL COMMENT 'text/image/video/audio/practice',

    content           TEXT COMMENT '内容文本（富文本）',
    media_url         VARCHAR(500) COMMENT '媒体资源URL',
    media_type        VARCHAR(20) COMMENT '图片、视频等类型',
    sort_order        INT NOT NULL DEFAULT 0,

    status            VARCHAR(20) NOT NULL DEFAULT 'draft',
    created_by        BIGINT NOT NULL,
    created_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_type (content_type)

```

### 2.5 教材版本变更记录表 `textbook_version_changes`

```sql
CREATE TABLE textbook_version_changes (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT,
    textbook_id       BIGINT NOT NULL,
    from_version      VARCHAR(50) COMMENT '原版本号',
    to_version        VARCHAR(50) NOT NULL COMMENT '新版本号',
    change_type       VARCHAR(20) NOT NULL COMMENT 'create/update/major_upgrade/minor_upgrade',
    change_summary    TEXT COMMENT '变更摘要',
    diff_snapshot     JSON COMMENT '变更差异快照',
    changed_by        BIGINT NOT NULL,
    changed_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_textbook (textbook_id),
    INDEX idx_version (from_version, to_version)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教材版本变更记录表';
```

## 4. 状态流转与业务流程

### 4.1 教材版本状态机

```
draft（草稿）
  ↓ submit_review()
review（审核中）
  ↓ approve()  ←  reject() → draft
published（已发布）
  ↓ archive()
archived（已归档）
  ↓ deprecate()
deprecated（已废弃）
```

### 4.2 内容审核流程

1. 创建内容（status=draft）
2. 提交审核 → 创建审核记录
3. 审核员审批 → 通过（status=published）或 驳回（status=draft）
4. 发布后触发关联数据同步

### 4.3 版本切换通知流程

```
教材版本发布 → 检查关联用户/班级 → 推送版本更新通知 → 同步课堂/题库模块更新索引 → RAG 刷新知识库
```

## 5. 关键代码示例

### 5.1 教材版本状态机实现（Go）

```go
type TextbookStatus string

const (
    StatusDraft      TextbookStatus = "draft"
    StatusReview     TextbookStatus = "review"
    StatusPublished  TextbookStatus = "published"
    StatusArchived   TextbookStatus = "archived"
    StatusDeprecated TextbookStatus = "deprecated"
)

func (s *TextbookStatus) CanTransitionTo(newStatus TextbookStatus) bool {
    transitions := map[TextbookStatus][]TextbookStatus{
        StatusDraft:      {StatusReview},
        StatusReview:     {StatusPublished, StatusDraft},
        StatusPublished:  {StatusArchived},
        StatusArchived:   {StatusDeprecated},
    }
    allowed, exists := transitions[*s]
    if !exists {
        return false
    }
    for _, status := range allowed {
        if status == newStatus {
            return true
        }
    }
    return false
}
```

### 5.2 教材版本发布服务

```go
func (s *TextbookService) PublishVersion(ctx context.Context, req *PublishRequest) error {
    version, err := s.repo.GetByID(ctx, req.VersionID)
    if err != nil {
        return err
    }

    if version.Status != StatusReview {
        return errors.New("only reviewed version can be published")
    }

    // 更新状态
    version.Status = StatusPublished
    version.EffectiveDate = req.EffectiveDate
    version.IsDefault = req.IsDefault
    version.PublishedAt = time.Now()

    err = s.repo.Update(ctx, version)
    if err != nil {
        return err
    }

    // 异步触发关联数据同步
    go s.triggerSync(ctx, version.ID)

    return nil
}
```

### 5.3 章节树递归查询（MySQL）

```sql
WITH RECURSIVE chapter_tree AS (
    SELECT id, name, parent_id, level, sort_order, 1 AS depth
    FROM textbook_chapters
    WHERE textbook_id = ? AND parent_id IS NULL
    UNION ALL
    SELECT c.id, c.name, c.parent_id, c.level, c.sort_order, ct.depth + 1
    FROM textbook_chapters c
    JOIN chapter_tree ct ON c.parent_id = ct.id
    WHERE ct.depth < 3
)
SELECT * FROM chapter_tree ORDER BY depth, sort_order;
```

## 6. 错误处理与异常场景

### 6.1 常见错误码

| 错误码 | 说明 | HTTP 状态码 |
|--------|------|------------|
| 40001 | 教材版本不存在 | 404 |
| 40002 | 状态不可流转 | 400 |
| 40003 | 审核权限不足 | 403 |
| 40004 | 关联数据仍在使用中，无法归档 | 409 |
| 40005 | 版本号重复 | 409 |

### 6.2 异常处理策略

- 发布前预检查：依赖的服务（同步课堂、题库）是否就绪
- 归档时校验：是否有用户仍使用该版本
- 审核操作记录：所有审核动作保留日志，支持追溯

## 7. 性能与缓存策略

- Redis 缓存教材元数据（版本信息、章节树），TTL 1 小时
- Elasticsearch 索引教材内容，支持全文检索
- 章节树查询使用 WITH RECURSIVE 递归查询，支持按层级展开

---

## 8. 安全与合规

- 操作权限控制：仅具备 `textbook:audit` 角色可审核
- 敏感操作日志：审核、发布、归档操作留存审计日志
- 内容审核：教材内容通过审核后才可发布
