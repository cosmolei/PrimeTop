# 服务端-教育内容语义标签体系与多维度内容画像引擎

> **文档版本**: v1.0  
> **创建日期**: 2026-06-20  
> **所属模块**: 内容服务层 / AI 能力层  
> **优先级**: P1  
> **关联模块**: 题库服务、知识点体系、内容管理后台、推荐系统、搜索服务、RAG 知识库、运营看板

---

## 1. 概述

### 1.1 设计目的

PrimeTop 平台涵盖海量教育内容——知识点讲解、教材解读、题目与解析、微课视频、范文素材、考点总结、学习计划模板、互动练习等。随着内容规模增长和多学段、多教材版本的扩展，**内容的统一描述、自动标注和智能检索**成为核心基础设施诉求。

现有系统中：
- `题目知识点自动标注引擎` 仅覆盖**题目**的知识点标签
- `布鲁姆认知层级自动分类引擎` 仅覆盖**认知深度**单一维度
- `教材课标对齐度分析` 聚焦于**覆盖率统计**，不做内容级标签
- `用户学习画像` 是用户维度的画像，不是内容维度

缺乏一个面向**全部内容类型**、覆盖**多维度语义标签**、生成**内容画像向量**的统一引擎。本引擎正是为填补这一空白而设计。

### 1.2 设计范围

| 范围 | 包含 | 不包含 |
|------|------|--------|
| 内容类型 | 知识点讲解、教材解读、题目与解析、微课视频(字幕/描述)、范文、考点总结、互动练习、学习计划模板 | AI 实时对话回答、用户生成的笔记和错题 |
| 标签维度 | 学科、学段年级、知识点、教材版本章节、难度、认知层级、题型、内容形式、语言难度、情感倾向、时效性、教学场景 | 内容质量评分（由 `内容质量评估引擎` 负责） |
| 输出物 | 多维度标签集、内容画像向量、标签索引、内容相似度矩阵 | 推荐排序（由 `推荐系统` 消费画像数据） |
| 操作动作 | 自动标注、人工修正、标签查询、标签统计、覆盖度分析 | 内容的创建/编辑/删除（由 `内容管理系统` 负责） |

### 1.3 核心价值

| 角色 | 价值 |
|------|------|
| 推荐系统 | 获得内容画像向量用于相似度计算和个性化推荐 |
| 搜索服务 | 多维度标签驱动的精确筛选和语义搜索 |
| 内容运营 | 标签覆盖度分析，识别内容缺口和冗余 |
| 知识图谱 | 内容与知识点的精确关联，丰富图谱节点 |
| RAG 系统 | 基于标签的检索增强，提高检索精度 |
| 教研团队 | 多维度内容统计，支撑内容建设规划 |
| 学生端 | 更精准的内容匹配和学习体验 |

### 1.4 名词定义

| 术语 | 定义 |
|------|------|
| 内容画像 (Content Profile) | 对一条教育内容的多维度结构化描述，包含标签集合和向量化表示 |
| 语义标签 (Semantic Tag) | 从内容中自动或人工提取的结构化属性，属于预定义的分类体系 |
| 标签维度 (Tag Dimension) | 标签的分类体系中的一级类别，如"学科"、"难度"、"认知层级"等 |
| 内容向量 (Content Vector) | 内容的语义嵌入向量，用于相似度计算 |
| 标签置信度 (Tag Confidence) | 自动标注的置信度分数，0-1 之间 |
| 标签覆盖度 (Tag Coverage) | 某标签维度下各取值的内容数量分布 |

## 2. 标签分类体系

### 2.1 维度总览

本引擎定义 **12 个一级标签维度**，覆盖教育内容的核心描述属性：

| 序号 | 维度 | 维度编码 | 值类型 | 标注方式 | 必填 |
|------|------|----------|--------|----------|------|
| D1 | 学科 | subject | 枚举 | 自动+人工 | ✅ |
| D2 | 学段 | stage | 枚举 | 自动+人工 | ✅ |
| D3 | 年级 | grade | 枚举 | 自动+人工 | ✅ |
| D4 | 教材版本 | textbook_version | 枚举 | 自动+人工 | ✅ |
| D5 | 章节单元 | chapter | 层级编码 | 自动+人工 | ✅ |
| D6 | 知识点 | knowledge_points | ID数组 | 自动+人工 | ✅ |
| D7 | 难度等级 | difficulty | 枚举 | 自动+人工 | ✅ |
| D8 | 认知层级 | cognitive_level | 枚举 | 自动(AI) | ⬜ |
| D9 | 内容形式 | content_format | 枚举 | 自动 | ✅ |
| D10 | 语言难度 | language_level | 枚举 | 自动(AI) | ⬜ |
| D11 | 教学场景 | teaching_scenario | 枚举(多选) | 自动+人工 | ⬜ |
| D12 | 时效标识 | freshness | 枚举 | 自动 | ⬜ |

### 2.2 各维度详细定义

#### D1 - 学科 (subject)

```
枚举值:
  chinese       语文
  math          数学
  english       英语
  physics       物理
  chemistry     化学
  biology       生物
  history       历史
  geography     地理
  politics      政治
  pinyin        拼音识字 (幼儿/低年级专属)
  general       综合/跨学科
```

#### D2 - 学段 (stage)

```
枚举值:
  kindergarten  幼儿园 (3-6岁)
  primary       小学 (1-6年级)
  junior        初中 (7-9年级)
  senior        高中 (10-12年级)
```

#### D3 - 年级 (grade)

```
枚举值:
  K1-K3         幼儿园小/中/大班
  G1-G6         小学1-6年级
  G7-G9         初中7-9年级
  G10-G12       高中10-12年级
```

#### D4 - 教材版本 (textbook_version)

```
枚举值(部分, 可扩展):
  PEP           人教版
  SUJIAO        苏教版
  BNU           北师大版
  FOREIGN_LANG  外研版
  LUKE          鲁科版
  SHANGHAI      沪教版
  GUANGZHOU     广州版
  GENERAL       通用
```

#### D5 - 章节单元 (chapter)

采用层级编码，格式：`{textbook_version}-{subject}-{grade}-{unit}-{lesson}`

```
示例:
  PEP-math-G7-U1-L2  →  人教版-七年级数学-第一单元-第2课
  PEP-chinese-G3-U4-L1 → 人教版-三年级语文-第四单元-第1课
```

#### D6 - 知识点 (knowledge_points)

引用知识点体系的 ID 数组。一条内容可关联多个知识点，支持主知识点和关联知识点。

```json
{
  "primary": ["KP_MATH_007_003"],
  "related": ["KP_MATH_007_001", "KP_MATH_007_005"],
  "weight": { "KP_MATH_007_003": 0.8, "KP_MATH_007_001": 0.3, "KP_MATH_007_005": 0.2 }
}
```

#### D7 - 难度等级 (difficulty)

```
枚举值:
  L1  基础      — 课标要求的基础掌握，正确率预期 >85%
  L2  理解      — 课标要求的理解运用，正确率预期 65%-85%
  L3  提高      — 课标要求的综合应用，正确率预期 40%-65%
  L4  拓展      — 超过课标要求的拓展内容，正确率预期 20%-40%
  L5  挑战      — 竞赛/强基计划级别，正确率预期 <20%
```

#### D8 - 认知层级 (cognitive_level)

```
枚举值(对接布鲁姆分类体系):
  REMEMBER      记忆
  UNDERSTAND    理解
  APPLY         应用
  ANALYZE       分析
  EVALUATE      评价
  CREATE        创造
```

> 注：详细分类逻辑由 `布鲁姆认知层级自动分类引擎` 负责，本引擎仅消费其输出。

#### D9 - 内容形式 (content_format)

```
枚举值:
  EXPLANATION   知识讲解
  EXAMPLE       例题精讲
  EXERCISE      练习题
  EXAM_QUESTION 考试真题
  SUMMARY       知识总结/思维导图
  VIDEO         微课视频
  AUDIO         音频讲解
  INTERACTIVE   互动练习
  FLASHCARD     闪卡
  ESSAY_SAMPLE  范文
  STUDY_PLAN    学习计划模板
  CONCEPT_MAP   概念图
  LAB_SIM       实验模拟
```

#### D10 - 语言难度 (language_level)

衡量内容文本的阅读难度，独立于学科难度。

```
枚举值:
  BEGINNER      入门 (识字量 <500, 简单句式, 适合幼儿/低年级)
  EASY          简单 (识字量 500-1500, 基本句式, 适合小学)
  MEDIUM        中等 (识字量 1500-3500, 复合句式, 适合初中)
  ADVANCED      进阶 (识字量 3500+, 长句/抽象表达, 适合高中)
  EXPERT        专业 (学术性表达, 专业术语密集)
```

评估算法基于：平均句长、生僻字比例、专业术语密度、语法复杂度。

#### D11 - 教学场景 (teaching_scenario)

```
枚举值(多选):
  PREVIEW           课前预习
  IN_CLASS          课中讲解
  PRACTICE          课后练习
  REVIEW            复习巩固
  EXAM_PREP         考试备考
  ERROR_CORRECTION  错题订正
  INQUIRY           探究式学习
  PROJECT           项目式学习
  PARENT_CHILD      亲子共学
  SELF_STUDY        自主学习
```

#### D12 - 时效标识 (freshness)

```
枚举值:
  EVERGREEN     常青 (知识点稳定, 长期有效)
  SEASONAL      季节性 (如期末复习、中高考冲刺)
  TRENDING      热点 (如教育政策变化、考试新题型)
  OUTDATED      疑似过时 (教材版本变更后需复核)
```

### 2.3 标签扩展机制

标签体系支持动态扩展，运营人员可通过管理后台新增标签维度或枚举值，无需修改代码。

```sql
-- 标签维度注册表
CREATE TABLE content_tag_dimension_registry (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    dimension_code  VARCHAR(50) NOT NULL UNIQUE,
    dimension_name  VARCHAR(100) NOT NULL,
    value_type      VARCHAR(20) NOT NULL,  -- ENUM / HIERARCHY / ID_ARRAY / FLOAT
    is_required     BOOLEAN DEFAULT FALSE,
    auto_taggable   BOOLEAN DEFAULT TRUE,
    ai_confidence_threshold DECIMAL(3,2) DEFAULT 0.75,
    description     TEXT,
    status          VARCHAR(20) DEFAULT 'ACTIVE',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 3. 数据模型设计

### 3.1 核心表结构

#### 3.1.1 内容主表 (edu_content)

```sql
CREATE TABLE edu_content (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    content_uid     VARCHAR(64) NOT NULL UNIQUE COMMENT '内容唯一标识(UUID)',
    title           VARCHAR(500) NOT NULL COMMENT '标题',
    content_type    VARCHAR(30) NOT NULL COMMENT '内容形式(EXPLANATION/EXERCISE/...)',
    body_text       MEDIUMTEXT COMMENT '纯文本正文(用于NLP处理)',
    body_rich       MEDIUMTEXT COMMENT '富文本/JSON结构正文(用于展示)',
    source_type     VARCHAR(20) NOT NULL DEFAULT 'MANUAL' COMMENT '来源: MANUAL/AI_GENERATED/IMPORTED',
    source_id       VARCHAR(64) COMMENT '来源系统ID(如题库题目ID)',
    status          VARCHAR(20) NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT/PENDING_TAG/TAGGED/PUBLISHED/ARCHIVED',
    version         INT NOT NULL DEFAULT 1,
    created_by      BIGINT,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    published_at    DATETIME,
    
    INDEX idx_content_type (content_type),
    INDEX idx_status (status),
    INDEX idx_source (source_type, source_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教育内容主表';
```

#### 3.1.2 内容标签表 (edu_content_tag)

```sql
CREATE TABLE edu_content_tag (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    content_uid     VARCHAR(64) NOT NULL COMMENT '关联内容',
    dimension_code  VARCHAR(50) NOT NULL COMMENT '标签维度编码',
    tag_value       VARCHAR(200) NOT NULL COMMENT '标签值(枚举值/知识点ID/章节编码)',
    tag_value_type  VARCHAR(20) NOT NULL COMMENT 'SINGLE / MULTI / WEIGHTED',
    weight          DECIMAL(5,4) DEFAULT 1.0000 COMMENT '权重(0-1, 用于WEIGHTED类型)',
    source          VARCHAR(20) NOT NULL DEFAULT 'AUTO' COMMENT 'AUTO(AI自动) / MANUAL(人工) / IMPORTED(导入)',
    confidence      DECIMAL(5,4) DEFAULT 1.0000 COMMENT '置信度(0-1)',
    verified_by     BIGINT COMMENT '人工审核人(如有)',
    verified_at     DATETIME,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_content_tag (content_uid, dimension_code, tag_value),
    INDEX idx_dimension (dimension_code, tag_value),
    INDEX idx_content (content_uid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容标签关联表';
```

#### 3.1.3 内容画像向量表 (edu_content_profile_vector)

```sql
CREATE TABLE edu_content_profile_vector (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    content_uid     VARCHAR(64) NOT NULL UNIQUE COMMENT '关联内容',
    embedding_model VARCHAR(100) NOT NULL COMMENT '嵌入模型名称+版本',
    vector_dim      INT NOT NULL COMMENT '向量维度',
    vector_data     VARBINARY(8192) NOT NULL COMMENT '向量二进制数据(float32数组)',
    text_hash       VARCHAR(64) NOT NULL COMMENT '正文文本哈希(用于增量更新判断)',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_model (embedding_model),
    INDEX idx_hash (text_hash)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容画像向量表';
```

#### 3.1.4 标注任务表 (edu_tagging_task)

```sql
CREATE TABLE edu_tagging_task (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_uid        VARCHAR(64) NOT NULL UNIQUE,
    content_uid     VARCHAR(64) NOT NULL,
    task_type       VARCHAR(30) NOT NULL COMMENT 'INITIAL_TAG / RE_TAG / VERIFY / BATCH_TAG',
    status          VARCHAR(20) NOT NULL DEFAULT 'PENDING' COMMENT 'PENDING/PROCESSING/SUCCESS/FAILED/RETRY',
    priority        INT DEFAULT 5 COMMENT '1(最高) - 10(最低)',
    payload         JSON COMMENT '任务参数',
    result          JSON COMMENT '标注结果(JSON)',
    error_message   TEXT,
    retry_count     INT DEFAULT 0,
    max_retry       INT DEFAULT 3,
    assigned_worker VARCHAR(50) COMMENT '处理worker标识',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    started_at      DATETIME,
    completed_at    DATETIME,
    
    INDEX idx_status_priority (status, priority),
    INDEX idx_content (content_uid),
    INDEX idx_task_type (task_type, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='标注任务队列表';
```

#### 3.1.5 标签覆盖度统计表 (edu_tag_coverage_stat)

```sql
CREATE TABLE edu_tag_coverage_stat (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    stat_date       DATE NOT NULL,
    dimension_code  VARCHAR(50) NOT NULL,
    tag_value       VARCHAR(200) NOT NULL,
    content_count   INT NOT NULL DEFAULT 0,
    pct_ratio       DECIMAL(5,4) DEFAULT 0 COMMENT '占比',
    
    UNIQUE KEY uk_date_dim_val (stat_date, dimension_code, tag_value),
    INDEX idx_date (stat_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='标签覆盖度日统计表';
```

```python
import re

import jieba.posseg as pseg

class ContentPreprocessor:
    """教育内容文本预处理器"""

        'geography': ['气候', '地形', '河流', '人口', '城市', '农业', '工业',

        'politics': ['政治', '经济', '哲学', '法律', '社会', '国家', '制度',
                    '市场', '宏观', '微观', '矛盾', '辩证']
    }
    
    def __init__(self):
        # 加载学科术语词典到 jieba
        for subject, keywords in self.SUBJECT_KEYWORDS.items():
            for kw in keywords:
                jieba.add_word(kw, tag='n')
    
    def preprocess(self, content_text: str, content_type: str) -> dict:
        """
        预处理内容文本
        返回: {
            'clean_text': str,       # 清洗后文本
            'tokens': list,          # 分词结果
            'entities': list,        # 实体(术语)
            'formulas': list,        # 数学公式/化学方程式
            'subject_hints': dict,   # 学科线索 {subject: score}
        }
        """
        # 1. 文本清洗
        clean_text = self._clean_text(content_text)
        
        # 2. 分词 + 词性标注
        tokens_with_pos = list(pseg.cut(clean_text))
        tokens = [(w.word, w.flag) for w in tokens_with_pos if len(w.word) > 0]
        
        # 3. 学科术语识别
        entities = self._extract_entities(tokens)
        
        # 4. 公式/方程式检测
        formulas = self._detect_formulas(content_text)
        
        # 5. 学科线索打分
        subject_hints = self._score_subjects(clean_text, entities)
        
        return {
            'clean_text': clean_text,
            'tokens': tokens,
            'entities': entities,
            'formulas': formulas,
            'subject_hints': subject_hints
        }
    
    def _clean_text(self, text: str) -> str:
        """清洗文本: 去除HTML标签、多余空白、标准化标点"""
        text = re.sub(r'<[^>]+>', '', text)           # 去HTML标签
        text = re.sub(r'\s+', ' ', text)               # 合并空白
        text = re.sub(r'【答案】.*?【解析】', '', text) # 基础去除答案(防止泄露)
        return text.strip()
    
    def _extract_entities(self, tokens: list) -> list:
        """提取学科术语实体"""
        entities = []
        for word, pos in tokens:
            if pos in ('n', 'vn', 'nz') and len(word) >= 2:
                entities.append({'text': word, 'pos': pos})
        return entities
    
    def _detect_formulas(self, text: str) -> list:
        """检测数学公式和化学方程式"""
        formulas = []
        # LaTeX 公式: $...$ 或 $$...$$
        formulas.extend(re.findall(r'\$\$?(.+?)\$\$?', text))
        # 化学方程式: 粗略匹配 (如 2H₂ + O₂ → 2H₂O)
        formulas.extend(re.findall(r'[0-9]*[A-Z][a-z]?\d*(?:\s*[+=→]\s*[0-9]*[A-Z][a-z]?\d*)+', text))
        return formulas
    
    def _score_subjects(self, text: str, entities: list) -> dict:
        """基于关键词频率为各学科打分"""
        scores = {}
        entity_texts = [e['text'] for e in entities]
        
        for subject, keywords in self.SUBJECT_KEYWORDS.items():
            score = sum(1 for kw in keywords if kw in text or kw in entity_texts)
            if score > 0:
                scores[subject] = score
        
        return scores
```

```java
        results.add(inferFreshness(content));

     * 学科推断: 如果内容来源已有学科信息则直接使用，
     * 否则基于预处理阶段的学科关键词打分
     */
    private TagResult inferSubject(EduContent content, PreprocessResult pre) {
        // 优先使用来源元数据
        if (content.getSourceMetadata() != null 
            && content.getSourceMetadata().containsKey("subject")) {
            return TagResult.of("subject", 
                content.getSourceMetadata().get("subject"), 1.0, "RULE");
        }
        
        // 基于关键词打分
        Map<String, Double> hints = pre.getSubjectHints();
        if (!hints.isEmpty()) {
            String bestSubject = hints.entrySet().stream()
                .max(Map.Entry.comparingByValue())
                .map(Map.Entry::getKey)
                .orElse("general");
            double confidence = hints.get(bestSubject) / 
                (hints.values().stream().mapToDouble(d -> d).sum() + 1.0);
            return TagResult.of("subject", bestSubject, 
                Math.max(confidence, 0.5), "RULE");
        }
        
        return TagResult.of("subject", "general", 0.3, "RULE");
    }
    
    /**
     * 时效性推断
     */
    private TagResult inferFreshness(EduContent content) {
        String text = content.getBodyText();
        
        // 检测考试年份关键词
        if (text.matches(".*\\b(20\\d{2})\\s*[年]?\\s*(高考|中考|真题).*")) {
            return TagResult.of("freshness", "SEASONAL", 0.8, "RULE");
        }
        
        // 检测热点事件
        if (text.contains("新课标") || text.contains("新教材") 
            || text.contains("双减") || text.contains("新高考")) {
            return TagResult.of("freshness", "TRENDING", 0.7, "RULE");
        }
        
        // 默认常青
        return TagResult.of("freshness", "EVERGREEN", 0.9, "RULE");
    }
```

```java
/**
 * 知识点关联标注器
 * 采用两阶段策略: Embedding 召回 → Cross-Encoder 精排
 */
@Component
public class KnowledgePointTagger {
    
    @Autowired
    private EmbeddingService embeddingService;  // 向量化服务
    
    @Autowired
    private VectorSearchService vectorSearch;    // 向量检索服务
    
    @Autowired
    private LLMService llmService;              // 大模型服务
    
    @Autowired
    private KnowledgePointRepository kpRepo;
    
    private static final int RECALL_TOP_K = 20;    // 召回数量
    private static final int FINAL_TOP_K = 5;      // 最终保留数量
    private static final double CONFIDENCE_THRESHOLD = 0.65;
    
    /**
     * 标注知识点标签
     */
    public List<TagResult> tag(EduContent content, PreprocessResult pre) {
        // 1. 内容文本向量化
        float[] contentVector = embeddingService.embed(
            pre.getCleanText(), EmbeddingModel.TEXT_EMBEDDING_V3
        );
        
        // 2. 向量召回: 从知识点库中检索最相关的知识点
        List<KnowledgePoint> candidates = vectorSearch.searchKnowledgePoints(
            contentVector, 
            pre.getSubjectHints().keySet(),  // 限定学科范围
            RECALL_TOP_K
        );
        
        if (candidates.isEmpty()) {
            return Collections.emptyList();
        }
        
        // 3. Cross-Encoder 精排
        List<KnowledgePointScore> ranked = crossEncoderRank(
            content.getBodyText(), candidates
        );
        
        // 4. 过滤低置信度结果
        List<TagResult> results = new ArrayList<>();
        boolean isFirst = true;
        for (KnowledgePointScore score : ranked) {
            if (results.size() >= FINAL_TOP_K) break;
            if (score.getScore() < CONFIDENCE_THRESHOLD && !isFirst) break;
            
            String tagType = isFirst ? "primary" : "related";
            double weight = isFirst ? 1.0 : score.getScore();
            
            results.add(TagResult.builder()
                .dimension("knowledge_points")
                .value(score.getKpId())
                .valueType(tagType.equals("primary") ? "SINGLE" : "WEIGHTED")
                .weight(weight)
                .source("AUTO")
                .confidence(score.getScore())
                .build()
            );
            isFirst = false;
        }
        
        return results;
    }
    
    /**
     * Cross-Encoder 精排: 使用 LLM 判断内容与知识点的关联度
     */
    private List<KnowledgePointScore> crossEncoderRank(
            String contentText, List<KnowledgePoint> candidates) {
        
        // 构建批量评估 Prompt
        String prompt = buildRankingPrompt(contentText, candidates);
        
        // 调用 LLM 进行评分
        LLMResponse response = llmService.chat(
            LLMRequest.builder()
                .model("gpt-4o-mini")  // 使用低成本模型
                .messages(List.of(
                    Message.system(SYSTEM_PROMPT_KP_RANKING),
                    Message.user(prompt)
                ))
                .temperature(0.0)      // 确定性输出
                .responseFormat(JsonSchema.KP_RANKING)
                .build()
        );
        
        // 解析评分结果
        Map<String, Double> scores = parseRankingResponse(response.getContent());
        
        return candidates.stream()
            .map(kp -> new KnowledgePointScore(
                kp.getId(), 
                scores.getOrDefault(kp.getId(), 0.0)
            ))
            .sorted(Comparator.comparingDouble(KnowledgePointScore::getScore)
                .reversed())
            .collect(Collectors.toList());
    }
    
    private static final String SYSTEM_PROMPT_KP_RANKING = """
        你是教育内容分析专家。你需要评估一段教育内容与各个知识点的关联度。
        
        评分标准:
        - 0.9-1.0: 内容直接讲解该知识点，是核心主题
        - 0.7-0.89: 内容大量涉及该知识点，是重要组成部分
        - 0.5-0.69: 内容部分涉及该知识点，作为背景或前提
        - 0.3-0.49: 内容略微提及该知识点
        - 0.0-0.29: 内容与该知识点无关
        
        请以 JSON 数组格式输出评分结果。
        """;
}
```

```java
/**
 * 难度等级标注器
 */
@Component
public class DifficultyTagger {
    
    @Autowired
    private LLMService llmService;
    
    @Autowired
    private AnswerRecordRepository answerRecordRepo;
    
    /**
     * 标注难度等级
     * 综合策略: 
     *   1. 如果有历史答题数据 → 基于正确率计算(最准确)
     *   2. 如果无历史数据 → LLM 分析评估
     *   3. 综合两者给出最终结果
     */
    public TagResult tag(EduContent content, PreprocessResult pre) {
        // 策略1: 基于历史答题数据(仅适用于题目类型)
        Optional<Double> empiricalDifficulty = estimateFromHistory(content);
        
        // 策略2: LLM 分析评估
        DifficultyEstimate aiEstimate = estimateByLLM(content, pre);
        
        // 融合结果
        String finalDifficulty = fuseDifficulty(empiricalDifficulty, aiEstimate);
        
        return TagResult.builder()
            .dimension("difficulty")
            .value(finalDifficulty)
            .source("AUTO")
            .confidence(calculateConfidence(empiricalDifficulty, aiEstimate))
            .build();
    }
    
    /**
     * 基于历史答题正确率推断难度
     * IRT 3PL 简化版: P(correct) → difficulty
     */
    private Optional<Double> estimateFromHistory(EduContent content) {
        if (!content.getContentType().equals("EXERCISE") 
            && !content.getContentType().equals("EXAM_QUESTION")) {
            return Optional.empty();
        }
        
        AnswerStat stat = answerRecordRepo.getStatByContentUid(content.getContentUid());
        if (stat == null || stat.getTotalCount() < 30) {
            return Optional.empty();  // 样本不足
        }
        
        double correctRate = (double) stat.getCorrectCount() / stat.getTotalCount();
        
        // 正确率 → 难度等级映射
        if (correctRate > 0.85) return Optional.of(0.1);  // L1 基础
        if (correctRate > 0.65) return Optional.of(0.3);  // L2 理解
        if (correctRate > 0.40) return Optional.of(0.5);  // L3 提高
        if (correctRate > 0.20) return Optional.of(0.7);  // L4 拓展
        return Optional.of(0.9);                           // L5 挑战
    }
    
    private DifficultyEstimate estimateByLLM(EduContent content, PreprocessResult pre) {
        String prompt = String.format("""
            请评估以下教育内容的难度等级(1-5):
            - L1(基础): 课标要求的基础知识，适合初学
            - L2(理解): 需要理解概念，适合巩固
            - L3(提高): 需要综合应用，适合提升
            - L4(拓展): 超纲拓展，适合培优
            - L5(挑战): 竞赛级别，极具挑战
            
            内容类型: %s
            学段: %s
            学科: %s
            
            内容摘要(前500字):
            %s
            
            请以JSON格式返回: {"level": "L1-L5", "score": 0.0-1.0, "reason": "..."}
            """, 
            content.getContentType(),
            pre.getStageHint(),
            pre.getSubjectHints(),
            content.getBodyText().substring(0, Math.min(500, content.getBodyText().length()))
        );
        
        LLMResponse response = llmService.chat(
            LLMRequest.builder()
                .model("gpt-4o-mini")
                .messages(List.of(Message.user(prompt)))
                .temperature(0.0)
                .build()
        );
        
        return DifficultyEstimate.fromJson(response.getContent());
    }
    
    private String fuseDifficulty(Optional<Double> empirical, DifficultyEstimate ai) {
        if (empirical.isPresent()) {
            double empScore = empirical.get();
            double aiScore = ai.getScore();
            // 加权融合: 经验数据权重 0.7, AI 估计权重 0.3
            double fused = empScore * 0.7 + aiScore * 0.3;
            return scoreToLevel(fused);
        }
        return ai.getLevel();
    }
    
    private String scoreToLevel(double score) {
        if (score < 0.2) return "L1";
        if (score < 0.4) return "L2";
        if (score < 0.6) return "L3";
        if (score < 0.8) return "L4";
        return "L5";
    }
}
```

#### 5.3.3 语言难度标注

```python
class LanguageLevelTagger:
    """语言难度标注器 - 基于文本统计特征评估"""
    
    def tag(self, content_text: str, tokens: list, stage_hint: str = None) -> dict:
        """
        评估文本的语言难度等级
        
        返回: {
            'dimension': 'language_level',
            'value': 'BEGINNER/EASY/MEDIUM/ADVANCED/EXPERT',
            'confidence': float,
            'metrics': {...}  # 各项指标详情
        }
        """
        metrics = self._compute_metrics(content_text, tokens)
        
        # 综合评分 (0-1, 越高代表越难)
        score = self._compute_difficulty_score(metrics)
        
        # 映射到等级
        if score < 0.2:
            level = "BEGINNER"
        elif score < 0.4:
            level = "EASY"
        elif score < 0.6:
            level = "MEDIUM"
        elif score < 0.8:
            level = "ADVANCED"
        else:
            level = "EXPERT"
        
        # 如果有学段提示, 作为参考校准
        if stage_hint:
            level = self._calibrate_with_stage(level, stage_hint)
        
        return {
            'dimension': 'language_level',
            'value': level,
            'confidence': 0.85,
            'metrics': metrics,
            'raw_score': score
        }
    
    def _compute_metrics(self, text: str, tokens: list) -> dict:
        sentences = re.split(r'[。！？.!?\n]+', text)
        sentences = [s.strip() for s in sentences if len(s.strip()) > 0]
        
        words = [w for w, _ in tokens]
        total_chars = len(text.replace(' ', '').replace('\n', ''))
        total_words = len(words)
        
        if total_words == 0:
            return {'avg_sentence_length': 0, 'rare_char_ratio': 0, 
                    'term_density': 0, 'complexity': 0}
        
        # 1. 平均句长 (字符数)
        avg_sentence_length = total_chars / max(len(sentences), 1)
        
        # 2. 生僻字比例 (使用常用字表外字符占比)
        common_chars = set('常用3000字范围...')  # 实际实现需加载常用字表
        rare_chars = sum(1 for c in text if c not in common_chars and '\u4e00' <= c <= '\u9fff')
        rare_char_ratio = rare_chars / max(total_chars, 1)
        
        # 3. 专业术语密度
        term_count = sum(1 for w, pos in tokens if pos in ('nz', 'vn') and len(w) >= 2)
        term_density = term_count / total_words
        
        # 4. 语法复杂度 (平均嵌套深度, 简化估计)
        clause_markers = len(re.findall(r'[，,；;：:、]', text))
        complexity = clause_markers / max(len(sentences), 1)
        
        return {
            'avg_sentence_length': avg_sentence_length,
            'rare_char_ratio': rare_char_ratio,
            'term_density': term_density,
            'complexity': complexity
        }
    
    def _compute_difficulty_score(self, metrics: dict) -> float:
        """加权计算综合难度评分"""
        w = {
            'avg_sentence_length': 0.25,   # 归一化: /50
            'rare_char_ratio': 0.25,        # 已归一化
            'term_density': 0.30,           # 归一化: 已在0-1范围
            'complexity': 0.20,             # 归一化: /5
        }
        
        score = 0.0
        score += min(metrics['avg_sentence_length'] / 50.0, 1.0) * w['avg_sentence_length']
        score += metrics['rare_char_ratio'] * w['rare_char_ratio']
        score += min(metrics['term_density'], 1.0) * w['term_density']
        score += min(metrics['complexity'] / 5.0, 1.0) * w['complexity']
        
        return score
```

### 5.4 Stage 4: 向量生成

#### 5.4.1 内容画像向量生成策略

```java
/**
 * 内容画像向量生成器
 * 融合文本语义向量 + 标签编码向量 → 统一画像向量
 */
@Component
public class ContentProfileVectorGenerator {
    
    @Autowired
    private EmbeddingService embeddingService;
    
    // 文本向量维度 (使用 Embedding 模型决定)
    private static final int TEXT_VECTOR_DIM = 1024;
    // 标签编码向量维度 (固定编码空间)
    private static final int TAG_VECTOR_DIM = 256;
    // 最终画像向量维度
    private static final int PROFILE_VECTOR_DIM = TEXT_VECTOR_DIM + TAG_VECTOR_DIM;
    
    /**
     * 生成内容画像向量
     */
    public float[] generate(String contentUid, String text, List<TagResult> tags) {
        // 1. 生成文本语义向量
        float[] textVector = embeddingService.embed(text, EmbeddingModel.TEXT_EMBEDDING_V3);
        
        // 2. 生成标签编码向量
        float[] tagVector = encodeTags(tags);
        
        // 3. 拼接为统一画像向量
        float[] profileVector = new float[PROFILE_VECTOR_DIM];
        System.arraycopy(textVector, 0, profileVector, 0, TEXT_VECTOR_DIM);
        System.arraycopy(tagVector, 0, profileVector, TEXT_VECTOR_DIM, TAG_VECTOR_DIM);
        
        // 4. L2 归一化
        return l2Normalize(profileVector);
    }
    
    /**
     * 标签编码为固定维度向量
     * 每个维度占用固定的编码子空间
     */
    private float[] encodeTags(List<TagResult> tags) {
        float[] vector = new float[TAG_VECTOR_DIM];
        
        // 将 256 维划分为 12 个子空间(对应12个标签维度)
        int subDim = TAG_VECTOR_DIM / 12;
        
        for (TagResult tag : tags) {
            int dimIndex = getDimensionIndex(tag.getDimensionCode());
            int offset = dimIndex * subDim;
            
            // 在子空间内编码标签值
            int valueIndex = getTagValueIndex(tag.getDimensionCode(), tag.getValue());
            if (valueIndex >= 0 && valueIndex < subDim) {
                float weight = (float) (tag.getWeight() * tag.getConfidence());
                vector[offset + valueIndex] = weight;
            }
        }
        
        return vector;
    }
    
    private float[] l2Normalize(float[] vector) {
        double norm = 0;
        for (float v : vector) norm += v * v;
        norm = Math.sqrt(norm);
        if (norm > 0) {
            for (int i = 0; i < vector.length; i++) {
                vector[i] /= norm;
            }
        }
        return vector;
    }
}
```

### 5.5 Stage 5: 质量校验门

```java
/**
 * 标注质量校验门
 * 在标签写入前执行一系列检查
 */
@Component
public class TaggingQualityGate {
    
    // 各维度的最低置信度要求
    private static final Map<String, Double> CONFIDENCE_THRESHOLDS = Map.of(
        "subject",          0.70,
        "stage",            0.70,
        "grade",            0.70,
        "knowledge_points", 0.65,
        "difficulty",       0.60,
        "cognitive_level",  0.60,
        "language_level",   0.70
    );
    
    // 必填维度列表
    private static final Set<String> REQUIRED_DIMENSIONS = Set.of(
        "subject", "stage", "grade", "textbook_version", 
        "knowledge_points", "difficulty", "content_format"
    );
    
    /**
     * 执行质量校验
     * @return 校验结果, 包含是否通过、需人工复核的标签列表
     */
    public QualityResult validate(List<TagResult> tags) {
        List<String> errors = new ArrayList<>();
        List<TagResult> needManualReview = new ArrayList<>();
        Set<String> taggedDimensions = new HashSet<>();
        
        for (TagResult tag : tags) {
            taggedDimensions.add(tag.getDimensionCode());
            
            // 1. 置信度检查
            double threshold = CONFIDENCE_THRESHOLDS
                .getOrDefault(tag.getDimensionCode(), 0.5);
            if (tag.getConfidence() < threshold) {
                needManualReview.add(tag);
            }
            
            // 2. 标签值合法性校验
            if (!isValidTagValue(tag)) {
                errors.add(String.format("非法标签值: %s=%s", 
                    tag.getDimensionCode(), tag.getValue()));
            }
        }
        
        // 3. 必填项检查
        for (String required : REQUIRED_DIMENSIONS) {
            if (!taggedDimensions.contains(required)) {
                errors.add("缺少必填标签维度: " + required);
            }
        }
        
        // 4. 一致性检查
        checkConsistency(tags, errors);
        
        boolean passed = errors.isEmpty();
        boolean needReview = !needManualReview.isEmpty();
        
        return new QualityResult(passed, needReview, errors, needManualReview);
    }
    
    /**
     * 一致性检查: 各维度标签之间是否有矛盾
     */
    private void checkConsistency(List<TagResult> tags, List<String> errors) {
        Map<String, String> tagMap = tags.stream()
            .collect(Collectors.toMap(
                TagResult::getDimensionCode, 
                TagResult::getValue,
                (a, b) -> a
            ));
        
        // 学段与年级一致性
        String stage = tagMap.get("stage");
        String grade = tagMap.get("grade");
        if (stage != null && grade != null && !isStageGradeConsistent(stage, grade)) {
            errors.add(String.format("学段(%s)与年级(%s)不一致", stage, grade));
        }
        
        // 学科与学段一致性
        String subject = tagMap.get("subject");
        if ("pinyin".equals(subject) && !"kindergarten".equals(stage) 
            && !"primary".equals(stage)) {
            errors.add("拼音识字仅适用于幼儿/小学阶段");
        }
        
        // 教材版本与学科一致性
        String textbook = tagMap.get("textbook_version");
        if (textbook != null && !isTextbookSubjectConsistent(textbook, subject)) {
            errors.add(String.format("教材版本(%s)与学科(%s)不匹配", textbook, subject));
        }
    }
    
    private boolean isStageGradeConsistent(String stage, String grade) {
        return switch (stage) {
            case "kindergarten" -> grade.startsWith("K");
            case "primary" -> grade.startsWith("G") 
                && Integer.parseInt(grade.substring(1)) <= 6;
            case "junior" -> grade.startsWith("G") 
                && Integer.parseInt(grade.substring(1)) >= 7 
                && Integer.parseInt(grade.substring(1)) <= 9;
            case "senior" -> grade.startsWith("G") 
                && Integer.parseInt(grade.substring(1)) >= 10;
            default -> true;
        };
    }
}
```

```java
/**
 * 标注任务状态机
 */
public enum TaggingTaskStatus {
    PENDING,      // 待处理
    PROCESSING,   // 处理中
    SUCCESS,      // 成功
    FAILED,       // 失败
    RETRY         // 待重试
}

public class TaggingTaskStateMachine {
    
    private static final Map<TaggingTaskStatus, Set<TaggingTaskStatus>> TRANSITIONS = Map.of(
        TaggingTaskStatus.PENDING, EnumSet.of(TaggingTaskStatus.PROCESSING),
        TaggingTaskStatus.PROCESSING, EnumSet.of(TaggingTaskStatus.SUCCESS, TaggingTaskStatus.FAILED),
        TaggingTaskStatus.FAILED, EnumSet.of(TaggingTaskStatus.RETRY, TaggingTaskStatus.SUCCESS),
        TaggingTaskStatus.RETRY, EnumSet.of(TaggingTaskStatus.PROCESSING)
    );
    
    public void transition(TaggingTask task, TaggingTaskStatus target) {
        TaggingTaskStatus current = task.getStatus();
        if (!TRANSITIONS.getOrDefault(current, EnumSet.noneOf(TaggingTaskStatus.class))
                .contains(target)) {
            throw new IllegalStateTransitionException(
                String.format("非法状态转换: %s → %s", current, target));
        }
        
        task.setStatus(target);
        switch (target) {
            case PROCESSING -> {
                task.setStartedAt(LocalDateTime.now());
            }
            case SUCCESS -> {
                task.setCompletedAt(LocalDateTime.now());
            }
            case FAILED -> {
                task.setRetryCount(task.getRetryCount() + 1);
                if (task.getRetryCount() < task.getMaxRetry()) {
                    task.setStatus(TaggingTaskStatus.RETRY);
                }
            }
        }
    }
}
```

### 8.2 标注Worker实现

```java
/**
 * 标注Worker - 持续消费标注任务队列
 */
@Component
public class TaggingWorker {
    
    @Autowired private TaggingTaskService taskService;
    @Autowired private ContentPreprocessor preprocessor;
    @Autowired private RuleBasedTagger ruleTagger;
    @Autowired private KnowledgePointTagger kpTagger;
    @Autowired private DifficultyTagger difficultyTagger;
    @Autowired private LanguageLevelTagger languageTagger;
    @Autowired private CognitiveLevelClient cognitiveLevelClient;
    @Autowired private ContentProfileVectorGenerator vectorGenerator;
    @Autowired private TaggingQualityGate qualityGate;
    @Autowired private TagRepository tagRepo;
    @Autowired private VectorRepository vectorRepo;
    
    @Scheduled(fixedDelay = 5000)  // 每5秒轮询一次
    public void processTasks() {
        // 拉取一批任务(PREFETCH=10)
        List<TaggingTask> tasks = taskService.fetchPendingTasks(10);
        
        for (TaggingTask task : tasks) {
            try {
                processSingleTask(task);
            } catch (Exception e) {
                log.error("标注任务失败: taskUid={}, error={}", 
                    task.getTaskUid(), e.getMessage(), e);
                taskService.markFailed(task, e);
            }
        }
    }
    
    private void processSingleTask(TaggingTask task) {
        // 1. 标记为处理中
        taskService.markProcessing(task);
        
        // 2. 加载内容
        EduContent content = contentService.getByUid(task.getContentUid());
        
        // 3. Stage 1: 预处理
        PreprocessResult preResult = preprocessor.preprocess(
            content.getBodyText(), content.getContentType()
        );
        
        // 4. Stage 2: 规则标注
        List<TagResult> allTags = new ArrayList<>();
        allTags.addAll(ruleTagger.tag(content, preResult));
        
        // 5. Stage 3: AI标注
        allTags.addAll(kpTagger.tag(content, preResult));
        allTags.addAll(difficultyTagger.tag(content, preResult));
        allTags.addAll(languageTagger.tag(content, preResult));
        
        // 5.1 认知层级 - 调用布鲁姆分类引擎
        CognitiveLevelResult clResult = cognitiveLevelClient.classify(content);
        if (clResult != null) {
            allTags.add(TagResult.of("cognitive_level", 
                clResult.getLevel(), clResult.getConfidence(), "AUTO"));
        }
        
        // 6. Stage 4: 生成画像向量
        float[] profileVector = vectorGenerator.generate(
            content.getContentUid(), preResult.getCleanText(), allTags
        );
        
        // 7. Stage 5: 质量校验
        QualityResult quality = qualityGate.validate(allTags);
        
        if (!quality.isPassed()) {
            log.warn("标注质量校验未通过: {}, errors={}", 
                content.getContentUid(), quality.getErrors());
            taskService.markNeedsReview(task, quality);
            return;
        }
        
        // 8. 持久化
        tagRepo.batchUpsert(content.getContentUid(), allTags);
        vectorRepo.upsert(content.getContentUid(), profileVector);
        
        // 9. 更新ES索引
        searchIndexService.updateContentIndex(content.getContentUid(), allTags);
        
        // 10. 标记成功
        taskService.markSuccess(task, allTags);
        
        // 11. 如需人工复核(低置信度项), 发送通知
        if (quality.isNeedReview()) {
            notifyService.notifyTaggingReviewers(
                content.getContentUid(), quality.getNeedManualReview()
            );
        }
    }
}
```

## 11. 错误处理与降级策略

### 11.1 错误分类与处理

| 错误类型 | 场景 | 处理策略 |
|---------|------|----------|
| AI服务超时 | LLM/Embedding API 响应超时 | 标注任务标记FAILED, 进入重试队列, 最多重试3次 |
| AI服务不可用 | 模型API宕机 | 降级: 仅使用规则标注, AI标注维度标记为"PENDING_AI" |
| 预处理异常 | 文本为空/格式异常 | 跳过AI标注, 仅做规则标注, 标记"需人工处理" |
| 向量生成失败 | Embedding API错误 | 标签正常写入, 向量延迟生成, 标记"VECTOR_PENDING" |
| 质量校验失败 | 必填项缺失/标签冲突 | 标记"NEEDS_REVIEW", 发送通知给内容审核团队 |
| 数据库写入失败 | DB异常 | 任务重试, 同时写入死信队列人工介入 |

### 11.2 降级策略代码

```java
/**
 * 标注降级处理器
 */
@Component
public class TaggingFallbackHandler {
    
    /**
     * AI服务不可用时的降级处理
     */
    public List<TagResult> fallbackToRuleOnly(EduContent content, 
                                               PreprocessResult pre) {
        log.warn("AI标注服务不可用, 降级为仅规则标注: {}", 
            content.getContentUid());
        
        List<TagResult> tags = new ArrayList<>();
        
        // 仅使用规则标注器
        tags.addAll(ruleTagger.tag(content, pre));
        
        // AI相关维度标记为待处理
        for (String aiDimension : List.of(
            "knowledge_points", "difficulty", "cognitive_level", "language_level"
        )) {
            tags.add(TagResult.builder()
                .dimension(aiDimension)
                .value("__PENDING_AI__")
                .source("FALLBACK")
                .confidence(0.0)
                .build());
        }
        
        return tags;
    }
    
    /**
     * 向量生成服务不可用时的降级处理
     */
    public void handleVectorUnavailable(String contentUid, List<TagResult> tags) {
        log.warn("向量生成服务不可用, 延迟生成向量: {}", contentUid);
        
        // 标签正常写入, 向量异步补偿
        // 写入延迟向量任务
        taggingTaskService.createDelayedVectorTask(contentUid, 
            DelayLevel.LEVEL_3);  // 30秒后重试
    }
}
```

```yaml
content:
```
