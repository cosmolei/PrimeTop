## 1. 模块概述

### 1.1 背景与目标

PrimeTop 面向 K12 全学段用户（3-18 岁），必须严格遵守《未成年人保护法》《未成年人网络保护条例》《儿童个人信息网络保护规定》等法规。本引擎作为平台级风控中间件，统一管理：

1. **青少年模式** 开关与强制启用策略。
2. **内容访问分级** 体系——按学段/年龄段对平台所有可消费内容进行分级标注与访问拦截。
3. **功能访问分级** ——不同年龄段可用功能集合的差异化管理。
4. **动态风控决策** ——结合用户画像、行为上下文、时间维度进行实时风险判定。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **默认安全** | 未完成实名/年龄核验的用户默认进入最严格分级 |
| **最小权限** | 青少年模式下仅暴露白名单功能与内容 |
| **不可绕过** | 分级策略在服务端强制执行，客户端仅做展示层适配 |
| **可审计** | 所有分级判定与拦截事件留存审计日志 |
| **可配置** | 分级规则、内容标签、功能白名单通过管理后台动态配置 |

### 1.3 在整体架构中的位置

```
客户端请求
    │
    ▼
API 网关 (鉴权/限流)
    │
    ▼
┌───────────────────────────────────────┐
│   青少年模式风控与内容访问分级引擎      │ ← 本模块
│   (请求拦截器 / 切面 / 中间件)          │
└───────────────────────────────────────┘
    │
    ▼
业务服务层 (用户/学习/题库/AI/社交/支付…)
```

引擎以 **请求拦截器 + 策略服务** 形式部署，所有涉及内容消费、功能访问的 API 请求必须先经过本引擎的分级策略校验。

## 2. 核心概念与领域模型

### 2.1 关键术语

| 术语 | 定义 |
|------|------|
| YouthMode（青少年模式） | 一种受限使用模式，启用后仅允许访问白名单功能和适龄内容 |
| ContentRating（内容分级标签） | 标注内容适用年龄段的标签，如 `ALL`、`3-6`、`7-12`、`13-15`、`16-18`、`ADULT_ONLY` |
| FeatureGate（功能门控级别） | 功能的最低年龄/学段要求，如 `require_age_min: 7` |
| RiskLevel（风险等级） | 实时风险判定结果：`LOW`、`MEDIUM`、`HIGH`、`BLOCKED` |
| ProtectionProfile（保护画像） | 针对用户计算的当前保护策略集合 |

### 2.2 内容分级体系

采用 **六级分级标准**，与中国教材学段对齐：

| 分级代码 | 适用年龄 | 对应学段 | 内容示例 |
|----------|----------|----------|----------|
| `ALL` | 全年龄 | — | 平台公告、帮助中心、隐私政策 |
| `ECE` | 3-6 岁 | 幼儿启蒙 | 拼音卡片、识字动画、趣味数学 |
| `PRI` | 7-12 岁 | 小学 | 小学教材、基础练习、启蒙作文 |
| `JUN` | 13-15 岁 | 初中 | 初中全科、中考专题、物理实验 |
| `SEN` | 16-18 岁 | 高中 | 高考专题、复杂理科推导、深度解析 |
| `RESTRICTED` | 仅成人 | 教师/家长/管理员 | 家长社区、教师论坛、管理后台内容 |

### 2.3 功能访问分级矩阵

| 功能模块 | ECE (3-6) | PRI (7-12) | JUN (13-15) | SEN (16-18) | 备注 |
|----------|-----------|------------|-------------|-------------|------|
| AI 智能辅导 | ✅ 限定场景 | ✅ | ✅ | ✅ | 幼儿仅支持语音/图片 |
| 拍照搜题 | ❌ | ✅ | ✅ | ✅ | 幼儿不可用 |
| 同步课堂 | ✅ 简化版 | ✅ | ✅ | ✅ | |
| 错题本 | ❌ | ✅ | ✅ | ✅ | 幼儿不需要 |
| 作文辅导 | ❌ | ✅ 基础 | ✅ | ✅ | |
| 文科背诵 | ✅ 朗读版 | ✅ | ✅ | ✅ | |
| 学习规划 | ❌ | ✅ 家长代设 | ✅ | ✅ | |
| 社交/学习圈 | ❌ | ❌ | ✅ 受限 | ✅ | 13 岁以下禁社交 |
| 直播课堂 | ✅ 仅观看 | ✅ | ✅ | ✅ | 幼儿不可互动 |
| 优惠券/活动 | ❌ | ✅ 家长确认 | ✅ | ✅ | |
| 支付/购买 | ❌ | ❌ | ❌ | ❌ | 一律跳转家长 |

### 3.2 核心枚举定义

```java
/** 内容分级等级 */
public enum ContentRating {
    ALL("全年龄", 0),
    ECE("幼儿启蒙(3-6岁)", 3),
    PRI("小学(7-12岁)", 7),
    JUN("初中(13-15岁)", 13),
    SEN("高中(16-18岁)", 16),
    RESTRICTED("仅成人", 18);

    private final String description;
    private final int minAge;

    ContentRating(String description, int minAge) {
        this.description = description;
        this.minAge = minAge;
    }

    /** 判断当前分级是否允许访问目标分级的内容 */
    public boolean canAccess(ContentRating required) {
        return this.minAge >= required.minAge;
    }

    /** 根据年龄自动推断分级 */
    public static ContentRating fromAge(int age) {
        if (age <= 6)  return ECE;
        if (age <= 12) return PRI;
        if (age <= 15) return JUN;
        if (age <= 18) return SEN;
        return RESTRICTED;
    }
}

/** 风控决策结果 */
public enum ProtectionDecision {
    ALLOW,     // 允许访问
    WARN,      // 允许但提示（如：内容可能偏难）
    BLOCK,     // 拦截访问
    REPLACE    // 替换为适龄内容
}

/** 风控拦截原因码 */
public enum ReasonCode {
    AGE_RESTRICTION("未达到内容最低年龄要求"),
    YOUTH_MODE_BLOCK("青少年模式禁用此功能"),
    NIGHT_TIME_BLOCK("夜间禁用时段"),
    DAILY_LIMIT_EXCEEDED("每日使用时长超限"),
    PARENT_RESTRICTION("家长设置限制"),
    CONTENT_NOT_RATED("内容未分级,默认拦截"),
    UNVERIFIED_USER("未完成年龄核验,默认严格模式"),
    HIGH_RISK_CONTENT("高风险内容"),
    SOCIAL_FEATURE_UNDERAGE("未满13岁不可使用社交功能"),
    PAYMENT_PROHIBITED("未成年人禁止直接支付");

    private final String description;
    ReasonCode(String description) { this.description = description; }
}
```


```
         │
         ▼
┌─────────────────────────┐
│ 1. 提取 userId 与功能码  │
│    从请求上下文中获取     │
└──────────┬──────────────┘
           │
           ▼
┌─────────────────────────┐
│ 2. 加载用户保护画像      │
│    从缓存/DB获取         │
```

### 5.2 内容分级判定算法

```java
/**
 * 内容分级判定核心逻辑
 */
public ContentRatingResult evaluateContentRating(
        Long userId,
        String contentId,
        String contentType,
        ProtectionProfile profile) {

    // 1. 获取内容自身的分级标签
    ContentRating contentRating = contentRatingService.getRating(contentId, contentType);

    // 2. 未分级内容 → 默认 BLOCK (default-safe 原则)
    if (contentRating == null) {
        return ContentRatingResult.block(ReasonCode.CONTENT_NOT_RATED, contentId);
    }

    // 3. 获取用户当前生效的内容分级
    ContentRating userRating = profile.getEffectiveContentRating();

    // 4. 简单比较: 用户分级 >= 内容要求分级 → 允许
    if (userRating.canAccess(contentRating)) {
        return ContentRatingResult.allow(contentId, contentRating);
    }

    // 5. 查询是否有特殊放行规则 (如: 考试冲刺期间临时开放)
    List<ContentRatingRule> overrideRules = ruleEngine.matchRules(
        contentType, contentId, userRating, profile.getFeatureContext()
    );

    for (ContentRatingRule rule : overrideRules) {
        switch (rule.getAction()) {
            case "BLOCK":
                return ContentRatingResult.block(
                    rule.getId(), ReasonCode.AGE_RESTRICTION,
                    findAlternative(contentId, userRating)  // 尝试找替代内容
                );
            case "WARN":
                return ContentRatingResult.warn(rule.getId(), contentId);
            case "FILTER":
                ContentRating filteredRating = applyFilter(contentId, userRating, rule.getReplaceStrategy());
                return ContentRatingResult.replace(contentId, filteredRating);
            case "REVIEW":
                // 标记为需人工复核, 暂时放行
                reviewQueueService.enqueue(userId, contentId, contentType);
                return ContentRatingResult.allow(contentId, contentRating);
        }
    }

    // 6. 无特殊规则 → 默认拦截
    return ContentRatingResult.block(
        ReasonCode.AGE_RESTRICTION,
        findAlternative(contentId, userRating)
    );
}
```

### 6.1 请求拦截器（Spring AOP 切面）

```java
/**
 * 青少年保护切面 — 拦截所有标注了 @ProtectedResource 的接口
 */
@Aspect
@Component
@Slf4j
public class YouthProtectionAspect {

    @Autowired
    private ProtectionProfileService profileService;

    @Autowired
    private FeatureGateService featureGateService;

    @Autowired
    private ContentRatingService contentRatingService;

    @Autowired
    private ProtectionAuditService auditService;

    @Around("@annotation(protectedResource)")
    public Object checkProtection(ProceedingJoinPoint joinPoint,
                                   ProtectedResource protectedResource) throws Throwable {

        // 1. 获取当前用户
        Long userId = UserContextHolder.getUserId();
        if (userId == null) {
            // 未登录请求打到标注了 @ProtectedResource 的接口 → 拒绝
            throw new ProtectionException(ReasonCode.UNVERIFIED_USER, "请先登录");
        }

        // 2. 加载保护画像
        ProtectionProfile profile = profileService.getOrInitProfile(userId);

        // 3. 教师和管理员直接放行
        if (profile.isStaffRole()) {
            return joinPoint.proceed();
        }

        // 4. 青少年模式全局检查
        ProtectionDecision globalDecision = checkGlobalConstraints(profile, protectedResource);
        if (globalDecision == ProtectionDecision.BLOCK) {
            auditService.logAsync(userId, protectedResource.featureCode(),
                ProtectionDecision.BLOCK, "GLOBAL_CONSTRAINT");
            throw new ProtectionBlockException(globalDecision.getReasonCode(),
                globalDecision.getReasonDetail());
        }

        // 5. 功能门控检查
        FeatureGateResult featureResult = featureGateService.check(
            protectedResource.featureCode(), profile
        );
        if (featureResult.isBlocked()) {
            auditService.logAsync(userId, protectedResource.featureCode(),
                ProtectionDecision.BLOCK, featureResult.getReasonCode());
            throw new ProtectionBlockException(featureResult.getReasonCode(),
                featureResult.getDetail());
        }

        // 6. 如果涉及内容ID，进行内容分级检查
        if (protectedResource.checkContent() && hasContentParam(joinPoint)) {
            String contentId = extractContentId(joinPoint);
            String contentType = protectedResource.contentType();

            ContentRatingResult contentResult = contentRatingService.evaluate(
                userId, contentId, contentType, profile
            );

            if (contentResult.isBlocked()) {
                auditService.logAsync(userId, protectedResource.featureCode(),
                    ProtectionDecision.BLOCK, ReasonCode.AGE_RESTRICTION);
                throw new ProtectionBlockException(
                    ReasonCode.AGE_RESTRICTION,
                    "该内容不适合当前年龄段",
                    contentResult.getAlternativeContentId()  // 提供替代内容
                );
            }

            // 如果需要替换内容，将替代内容ID注入请求上下文
            if (contentResult.isReplaced()) {
                RequestContextHolder.setAttribute(
                    "replacementContentId", contentResult.getAlternativeContentId()
                );
            }
        }

        // 7. 写审计日志(ALLOW)
        auditService.logAsync(userId, protectedResource.featureCode(),
            ProtectionDecision.ALLOW, null);

        // 8. 放行
        return joinPoint.proceed();
    }

    /**
     * 全局约束检查：夜间禁用、每日时长限制
     */
    private ProtectionDecision checkGlobalConstraints(ProtectionProfile profile,
                                                       ProtectedResource annotation) {
        // 夜间禁用时段
        if (profile.isYouthModeEnabled() && profile.isInNightBlockTime()) {
            return ProtectionDecision.block(
                ReasonCode.NIGHT_TIME_BLOCK,
                String.format("夜间休息时间(%s-%s)不可使用",
                    profile.getNightBlockStart(), profile.getNightBlockEnd())
            );
        }

        // 每日使用时长限制
        if (profile.isYouthModeEnabled() && profile.hasDailyLimit()) {
            int usedMinutes = dailyUsageService.getTodayUsageMinutes(profile.getUserId());
            if (usedMinutes >= profile.getDailyLimitMinutes()) {
                return ProtectionDecision.block(
                    ReasonCode.DAILY_LIMIT_EXCEEDED,
                    String.format("今日已使用%d分钟，超过%d分钟上限",
                        usedMinutes, profile.getDailyLimitMinutes())
                );
            }
        }

        return ProtectionDecision.ALLOW;
    }
}
```

```java
/**
 * 当内容被分级拦截时，尝试查找用户分级的替代版本
 */
@Service
@Slf4j
public class AlternativeContentFinder {

    @Autowired
    private ContentMetadataRepository contentRepo;

    @Autowired
    private KnowledgePointMappingService kpMappingService;

    /**
     * 查找替代内容
     * 策略优先级:
     * 1. 同一知识点下、用户分级的对应内容 (如: 高中版→初中版)
     * 2. 同一章节下、更低分级的内容
     * 3. 返回 null (无替代)
     */
    public String findAlternative(String originalContentId, ContentRating userRating) {
        // 1. 获取原始内容的知识点关联
        List<Long> knowledgePointIds = kpMappingService.getKnowledgePoints(originalContentId);

        // 2. 查找同知识点、匹配用户分级的内容
        for (Long kpId : knowledgePointIds) {
            Optional<String> altContent = contentRepo.findbyKnowledgePointAndRating(
                kpId, userRating.name()
            );
            if (altContent.isPresent()) {
                log.info("找到替代内容: original={}, alternative={}, rating={}",
                    originalContentId, altContent.get(), userRating);
                return altContent.get();
            }
        }

        // 3. 查找同章节下的基础内容
        Optional<String> chapterFallback = contentRepo.findBasicContentBySameChapter(originalContentId);
        if (chapterFallback.isPresent()) {
            return chapterFallback.get();
        }

        log.info("未找到替代内容: original={}, userRating={}", originalContentId, userRating);
        return null;
    }
}
```

### 6.5 缓存策略

```java
/**
 * 保护画像缓存 — 高频读取，多级缓存
 */
@Service
public class ProtectionProfileCache {

    private static final String CACHE_KEY = "protection:profile:";
    private static final Duration LOCAL_TTL = Duration.ofSeconds(30);   // 本地缓存30秒
    private static final Duration REDIS_TTL = Duration.ofMinutes(10);   // Redis缓存10分钟

    @Autowired
    private RedisTemplate<String, ProtectionProfile> redisTemplate;

    @Autowired
    private ProtectionProfileRepository repo;

    private final Cache<Long, ProtectionProfile> localCache = Caffeine.newBuilder()
        .maximumSize(10_000)
        .expireAfterWrite(LOCAL_TTL)
        .recordStats()
        .build();

    /**
     * 获取保护画像 — 三级缓存: 本地 → Redis → DB
     */
    public ProtectionProfile getProfile(Long userId) {
        // 1. 本地缓存
        ProtectionProfile cached = localCache.getIfPresent(userId);
        if (cached != null) return cached;

        // 2. Redis
        String key = CACHE_KEY + userId;
        cached = redisTemplate.opsForValue().get(key);
        if (cached != null) {
            localCache.put(userId, cached);
            return cached;
        }

        // 3. DB
        ProtectionProfile profile = repo.findByUserId(userId);
        if (profile == null) {
            profile = createDefaultProfile(userId);
        }

        // 回填缓存
        localCache.put(userId, profile);
        redisTemplate.opsForValue().set(key, profile, REDIS_TTL);

        return profile;
    }

    /**
     * 画像变更时清除缓存
     */
    public void evictProfile(Long userId) {
        localCache.invalidate(userId);
        redisTemplate.delete(CACHE_KEY + userId);
    }
}
```

| | | 多设备同时登录 | +8 |

| | | 短时间频繁查看商品 | +8 |

```java
@Service
@Slf4j
public class RiskScoringService {

    @Autowired
    private RiskScoreRepository riskScoreRepo;

    @Autowired
    private ProtectionProfileCache profileCache;

    /**
     * 增加风险分
     */
    @Async
    public void addRiskScore(Long userId, RiskFactor factor) {
        RiskScore score = riskScoreRepo.findByUserIdAndDate(userId, LocalDate.now());
        if (score == null) {
            score = RiskScore.initToday(userId);
        }

        score.addComponent(factor);
        score.recalculate();

        riskScoreRepo.save(score);

        // 如果进入HIGH区间，触发通知
        if (score.getTotalScore() >= 51 && score.getPreviousLevel() == RiskLevel.MEDIUM) {
            notificationService.notifyParentRiskAlert(userId, score);
        }

        // 如果进入BLOCKED区间，触发冻结
        if (score.getTotalScore() >= 81) {
            accountService.temporaryFreeze(userId, "高风险评分自动冻结");
        }

        // 更新画像中的风险分
        profileCache.evictProfile(userId);
    }
}
```

### 9.2 降级策略

```java
@Service
@Slf4j
public class ProtectionFallbackHandler {

    /**
     * 当保护画像服务不可用时的降级处理
     * 原则: 默认安全(fail-closed)
     */
    public ProtectionDecision handleProfileServiceDown(Long userId, String featureCode) {
        log.error("保护画像服务不可用, 执行降级: userId={}, feature={}", userId, featureCode);

        // 1. 尝试从本地缓存获取
        ProtectionProfile cached = localCache.getIfPresent(userId);
        if (cached != null) {
            log.info("降级使用本地缓存画像: userId={}", userId);
            return evaluateWithProfile(cached, featureCode);
        }

        // 2. 无法获取画像 → 默认拦截
        // 对于公开接口允许通过, 其他一律拦截
        if (isPublicFeature(featureCode)) {
            return ProtectionDecision.ALLOW;
        }

        log.warn("无法获取保护画像, 默认拦截: userId={}, feature={}", userId, featureCode);
        return ProtectionDecision.block(
            ReasonCode.UNVERIFIED_USER,
            "系统繁忙，请稍后重试"
        );
    }

    /**
     * 规则引擎不可用时降级为静态默认规则
     */
    public ContentRatingResult handleRuleEngineDown(Long userId, String contentId,
                                                      ContentRating userRating) {
        log.error("规则引擎不可用, 使用静态分级: contentId={}", contentId);

        // 获取内容自身标签(直接查DB)
        ContentRating contentRating = contentRepo.getStaticRating(contentId);
        if (contentRating == null) {
            return ContentRatingResult.block(ReasonCode.CONTENT_NOT_RATED, null);
        }

        // 简单比较
        if (userRating.canAccess(contentRating)) {
            return ContentRatingResult.allow(contentId, contentRating);
        }
        return ContentRatingResult.block(ReasonCode.AGE_RESTRICTION, null);
    }
}
```

### 10.2 内容批量打标工具

```java
@Service
public class ContentBatchRatingService {

    /**
     * AI辅助内容分级 — 对未分级内容自动建议分级
     */
    public BatchRatingResult autoSuggestRatings(List<String> contentIds) {
        BatchRatingResult result = new BatchRatingResult();

        for (String contentId : contentIds) {
            ContentMetadata meta = contentRepo.getMetadata(contentId);

            // 规则匹配
            ContentRating suggested = ruleBasedRating(meta);

            // 如果规则无法判定, 调用AI模型
            if (suggested == null) {
                suggested = aiBasedRating(meta);
            }

            result.add(contentId, suggested, ConfidenceLevel.calculate(suggested, meta));
        }

        return result;
    }

    /**
     * 规则优先的内容分级
     */
    private ContentRating ruleBasedRating(ContentMetadata meta) {
        // 1. 根据关联的学段标签
        if (meta.hasTag("stage_ece"))  return ContentRating.ECE;
        if (meta.hasTag("stage_pri"))  return ContentRating.PRI;
        if (meta.hasTag("stage_jun"))  return ContentRating.JUN;
        if (meta.hasTag("stage_sen"))  return ContentRating.SEN;

        // 2. 根据关联教材年级
        if (meta.getGradeLevel() != null) {
            return ContentRating.fromAge(meta.getGradeLevel() + 6); // 1年级=7岁
        }

        // 3. 根据知识点关联的学段
        if (meta.getKnowledgePoints() != null) {
            return kpService.getDominantStage(meta.getKnowledgePoints());
        }

        return null; // 规则无法判定
    }

    /**
     * AI辅助分级 — 调用教育NLP管线
     */
    private ContentRating aiBasedRating(ContentMetadata meta) {
        AiRatingRequest request = AiRatingRequest.builder()
            .contentId(meta.getId())
            .title(meta.getTitle())
            .textContent(truncate(meta.getTextContent(), 2000))
            .subject(meta.getSubject())
            .build();

        AiRatingResponse response = nlpService.rateContent(request);
        return ContentRating.valueOf(response.getSuggestedRating());
    }
}
```
