# 服务端-教育内容时效性监控与过时风险内容自动预警引擎-详细设计

## 1. 概述

### 1.1 功能定位

教育内容时效性监控与过时风险内容自动预警引擎是 PrimeTop 平台内容质量保障体系的关键组成部分。教育平台的内容库并非"一次发布、永久有效"——现实世界的变化可能使已发布的内容变得不准确、不完整甚至产生误导。本引擎专注于**自动检测已发布内容的时效性风险**，在内容过时之前或之初自动触发预警与更新流程。

核心解决以下问题：

1. **内容什么时候过时了**：通过外部数据源监控、知识演进事件检测，自动识别平台内容库中受影响的内容条目。
2. **过时程度有多严重**：对受影响内容进行过时风险分级（轻微偏差 / 需要修订 / 紧急下线）。
3. **谁来更新、什么时候更新**：自动生成内容更新工单并流转至内容生产管线，按优先级排期。
4. **更新效果如何验证**：更新后的内容需经事实性校验和时效性复审才能重新发布。

### 1.2 过时场景示例

| 场景类型 | 具体示例 | 影响范围 |
| --- | --- | --- |
| 科学发现 | 冥王星被重新分类为矮行星（已完成）/ 新元素被发现并命名 | 天文、化学相关内容 |
| 历史事件 | 新的国家领导人当选 / 新的国际条约签署 / 重大历史事件发生 | 历史、政治相关内容 |
| 政策法规 | 教育部发布新课标 / 高考改革方案调整 / 减负政策更新 | 全学科课标相关内容 |
| 技术演进 | 编程语言版本更新 / 新的科技突破（如 AI 大模型） | 信息技术相关内容 |
| 教材改版 | 人教版数学教材修订 / 新版教材投入使用 | 对应教材版本的全部关联内容 |
| 社会发展 | 国家行政区划调整 / 人口数据更新 | 地理、社会相关内容 |
| 事实修正 | 原有内容中存在未被发现的 factual error | 涉及该事实的所有内容 |

### 1.3 与现有系统的关系

| 现有系统 | 关系 |
| --- | --- |
| 教育内容事实性校验与知识准确性验证引擎 | **互补**：事实性校验关注"内容是否正确"，本引擎关注"曾经正确的内容是否已过时" |
| 教材修订内容变更检测与平台内容影响评估引擎 | **上游输入**：教材修订事件作为本引擎的一个重要触发源 |
| 教育内容质量自动评估与低质内容智能检测引擎 | **互补**：质量评估关注"内容好不好"，本引擎关注"内容是否仍然有效" |
| 教育内容审核工作流与多级审核管线 | **下游**：本引擎产出的内容更新工单进入审核管线 |
| 教育内容紧急下线与安全事故应急响应工作流引擎 | **协作**：紧急过时内容（如重大错误）触发紧急下线流程 |
| 教育内容事实性校验与知识准确性验证引擎 | **协作**：更新后的内容需经事实性校验复核 |
| 教育内容生产任务编排与产能智能调度引擎 | **下游**：更新工单汇入生产任务排产计划 |
| 管理后台-题库内容管理与生产运维工作台 | **展示层**：运维人员查看时效性预警看板和过时内容清单 |
| 管理后台-教材版本与课程章节内容管理工作台 | **展示层**：内容编辑查看待更新内容详情 |

### 1.4 设计目标

| 目标 | 指标 |
| --- | --- |
| 过时事件检测延迟 | 外部事件发生后 ≤ 24h 内识别受影响内容 |
| 过时内容识别准确率 | ≥ 85%（标记为过时的内容确实需要更新） |
| 过时内容召回率 | ≥ 80%（实际过时的内容被成功识别） |
| 风险分级准确率 | ≥ 90%（风险等级判定与人工审核一致） |
| 自动化工单生成率 | ≥ 95%（识别后自动生成更新工单，无需人工创建） |
| 更新闭环平均周期 | ≤ 7 天（从预警到更新完成） |

## 2. 核心概念与领域模型

### 2.1 领域概念

```
TimelinessEvent（时效性事件）
  ├── 来源：教材修订 / 课标更新 / 科学发现 / 政策变更 / 历史事件 / 技术更新 / 社会发展
  ├── 影响范围：学科 × 学段 × 知识点 × 教材版本
  ├── 严重程度：INFO（信息更新）/ MINOR（轻微偏差）/ MAJOR（需要修订）/ CRITICAL（紧急修正）
  ├── 发现渠道：外部数据源订阅 / 用户反馈 / 专家审核 / 定期巡检
  └── 关联实体：受影响的内容ID列表

ContentFreshnessProfile（内容时效画像）
  ├── 内容ID：题目 / 解析 / 知识点讲解 / 课件 / 视频
  ├── 时效敏感度：HIGH（高度敏感，如政治、地理数据）/ MEDIUM（中度敏感，如科学概念）/ LOW（低度敏感，如数学公式）
  ├── 最后验证时间：最近一次事实性校验时间
  ├── 时效性评分：0~100，越低表示过时风险越高
  └── 已知风险标签：如"包含可能过时的统计数据"、"引用了特定时期的政策文件"

RefreshTask（内容刷新任务）
  ├── 来源：自动生成（时效性事件触发）/ 人工创建（运营人员手动发起）
  ├── 类型：FACT_UPDATE（事实更新）/ CONTEXT_SUPPLEMENT（补充新背景）/ CORRECTION（纠正错误）/ RETIREMENT（内容退役）
  ├── 优先级：基于内容使用量 × 过时严重程度 × 受影响学生数量
  ├── 状态：CREATED → ASSIGNED → IN_PROGRESS → UNDER_REVIEW → COMPLETED / REJECTED
  └── 关联：时效性事件ID + 受影响内容ID列表

TimelinessRule（时效性规则）
  ├── 适用范围：按学科 × 内容类型 × 知识点
  ├── 规则类型：PERIODIC_CHECK（定期检查）/ EVENT_TRIGGERED（事件触发）/ USAGE_THRESHOLD（使用量阈值）
  ├── 检查周期：如统计数据类内容每年检查一次、政治类内容每月检查一次
  ├── 数据源：外部数据源URL / 内部知识库变更事件 / 用户反馈信号
  └── 动作：标记为需检查 / 标记为过时 / 触发紧急下线
```

## 3. 数据结构定义

### 3.1 数据库表设计

#### 3.1.1 timeliness_event（时效性事件表）

```sql
CREATE TABLE timeliness_event (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    event_code      VARCHAR(64) NOT NULL UNIQUE COMMENT '事件唯一编码，如 TE-2026-00001',
    event_type      VARCHAR(32) NOT NULL COMMENT '事件类型: TEXTBOOK_REVISION/CURRICULUM_UPDATE/SCIENCE_DISCOVERY/POLICY_CHANGE/HISTORICAL_EVENT/TECH_UPDATE/SOCIAL_CHANGE',
    event_source    VARCHAR(32) NOT NULL COMMENT '发现渠道: EXTERNAL_FEED/USER_REPORT/EXPERT_REVIEW/PERIODIC_SCAN/MANUAL',
    title           VARCHAR(256) NOT NULL COMMENT '事件标题',
    description     TEXT COMMENT '事件详细描述',
    severity        VARCHAR(16) NOT NULL COMMENT '严重程度: INFO/MINOR/MAJOR/CRITICAL',

    -- 影响范围
    affected_subjects   JSON COMMENT '受影响学科列表 ["politics","geography"]',
    affected_stages     JSON COMMENT '受影响学段列表 ["SENIOR_HIGH","JUNIOR_HIGH"]',
    affected_knowledge_points JSON COMMENT '受影响知识点ID列表',
    affected_textbook_versions JSON COMMENT '受影响教材版本ID列表',

    -- 外部参考
    external_references JSON COMMENT '外部参考链接 [{"type":"official","url":"...","title":"..."}]',

    -- 状态管理
    status          VARCHAR(20) NOT NULL DEFAULT 'DETECTED' COMMENT 'DETECTED/ANALYZING/IMPACT/RISK_ASSESSED/CLOSED',
    affected_content_count INT DEFAULT 0 COMMENT '受影响内容数量',

    -- 审核信息
    detected_by     VARCHAR(32) NOT NULL COMMENT '检测者: SYSTEM/USER:user_id/EXPERT:user_id',
    detected_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    analyzed_at     DATETIME COMMENT '分析完成时间',
    resolved_at     DATETIME COMMENT '关闭时间',
    closed_by       VARCHAR(64) COMMENT '关闭人',

    -- 扩展
    extra_data      JSON COMMENT '扩展字段',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_type_status (event_type, status),
    INDEX idx_severity (severity),
    INDEX idx_detected_at (detected_at),
    INDEX idx_event_code (event_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='时效性事件表';
```

#### 3.1.2 content_freshness_profile（内容时效画像表）

```sql
CREATE TABLE content_freshness_profile (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    content_id      VARCHAR(64) NOT NULL COMMENT '内容唯一标识',
    content_type    VARCHAR(32) NOT NULL COMMENT '内容类型: QUESTION/EXPLANATION/VIDEO/SLIDE/KNOWLEDGE_POINT/EXAM_PAPER',

    -- 时效属性
    timeliness_sensitivity VARCHAR(16) NOT NULL DEFAULT 'MEDIUM' COMMENT '时效敏感度: HIGH/MEDIUM/LOW/STABLE',
    sensitivity_reasons    JSON COMMENT '敏感度判定依据 ["contains_statistics","references_policy","mentions_technology"]',
    check_period_days      INT NOT NULL DEFAULT 90 COMMENT '建议检查周期(天)',

    -- 时效评分
    freshness_score        DECIMAL(5,2) DEFAULT 100.00 COMMENT '时效性评分 0-100',
    score_factors          JSON COMMENT '评分因子 {"last_verified":"2026-01-01","outdated_flags":2,"user_reports":0}',

    -- 时间节点
    published_at    DATETIME COMMENT '内容发布时间',
    last_verified_at DATETIME COMMENT '最近一次事实性校验时间',
    next_check_due  DATETIME COMMENT '下次检查到期日',
    last_refreshed_at DATETIME COMMENT '最近一次内容更新时间',

    -- 风险标记
    known_risks     JSON COMMENT '已知风险标签 ["statistics_may_be_outdated","policy_reference_dated"]',
    outdated_event_ids JSON COMMENT '关联的时效性事件ID列表',

    -- 状态
    status          VARCHAR(20) NOT NULL DEFAULT 'FRESH' COMMENT 'FRESH/STALE/OUTDATED/UNDER_REVIEW/UPDATING/RETIRED',

    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_content (content_id, content_type),
    INDEX idx_sensitivity (timeliness_sensitivity),
    INDEX idx_next_check (next_check_due),
    INDEX idx_status (status),
    INDEX idx_freshness (freshness_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容时效画像表';
```

```java
/**
 * 时效性事件检测服务
 */
@Service
public class TimelinessEventDetector {

    @Autowired
    private ExternalDataSourceManager sourceManager;
    @Autowired
    private EventStandardizer standardizer;
    @Autowired
    private TimelinessEventService eventService;
    @Autowired
    private ImpactAnalyzer impactAnalyzer;

    /**
     * 定时拉取外部数据源（每30分钟）
     */
    @Scheduled(fixedDelay = 30 * 60 * 1000)
    public void pollExternalSources() {
        List<ExternalDataSource> activeSources = sourceManager.getActiveSources();
        for (ExternalDataSource source : activeSources) {
            try {
                List<RawSignal> signals = sourceManager.fetchSignals(source);
                for (RawSignal signal : signals) {
                    processSignal(signal, source);
                }
                sourceManager.recordSuccess(source.getId());
            } catch (Exception e) {
                log.error("Failed to fetch from source: {}", source.getSourceName(), e);
                sourceManager.recordFailure(source.getId(), e.getMessage());
            }
        }
    }

    /**
     * 处理原始信号
     */
    private void processSignal(RawSignal signal, ExternalDataSource source) {
        // 1. 去重检查
        if (eventService.isDuplicate(signal.getHash())) {
            return;
        }

        // 2. 标准化为事件
        TimelinessEvent event = standardizer.standardize(signal, source);
        if (event == null) {
            return; // 不相关的信号
        }

        // 3. 严重程度预判
        Severity severity = assessInitialSeverity(signal, source);
        event.setSeverity(severity);

        // 4. 影响范围预识别
        identifyAffectedScope(event);

        // 5. 持久化事件
        event = eventService.save(event);

        // 6. CRITICAL 级别立即处理
        if (severity == Severity.CRITICAL) {
            impactAnalyzer.emergencyAnalyze(event);
        } else {
            // 异步分析（批量处理优化）
            impactAnalyzer.asyncAnalyze(event);
        }
    }

    /**
     * 严重程度预判
     */
    private Severity assessInitialSeverity(RawSignal signal, ExternalDataSource source) {
        // 基于数据源类别和信号关键词判断
        if (source.getSourceCategory() == SourceCategory.TEXTBOOK_PUBLISHER) {
            return Severity.MAJOR; // 教材修订通常是重大影响
        }

        if (source.getSourceCategory() == SourceCategory.CURRICULUM_AUTHORITY) {
            return Severity.MAJOR; // 课标变更通常是重大影响
        }

        // 基于关键词判断
        String content = signal.getTitle() + " " + signal.getDescription();
        if (containsCriticalKeywords(content)) {
            return Severity.CRITICAL;
        }
        if (containsMajorKeywords(content)) {
            return Severity.MAJOR;
        }

        return Severity.MINOR;
    }

    private boolean containsCriticalKeywords(String content) {
        List<String> keywords = List.of(
            "撤销", "废止", "重大错误", "严重误导", "安全事故",
            "立即停止使用", "紧急通知"
        );
        return keywords.stream().anyMatch(content::contains);
    }

    private void identifyAffectedScope(TimelinessEvent event) {
        // 基于事件类型预识别影响范围
        switch (event.getEventType()) {
            case TEXTBOOK_REVISION:
                // 教材修订 → 从教材映射表查找受影响版本和知识点
                List<Long> kpIds = textbookMappingService.findKnowledgePoints(
                    event.getAffectedTextbookVersionIds()
                );
                event.setAffectedKnowledgePointIds(kpIds);
                break;

            case POLICY_CHANGE:
                // 政策变更 → 默认影响政治学科高中段
                event.setAffectedSubjects(List.of("politics"));
                event.setAffectedStages(List.of("SENIOR_HIGH"));
                break;

            case SCIENCE_DISCOVERY:
                // 科学发现 → 通过知识图谱查找相关学科和知识点
                KnowledgeGraphMatchResult matchResult = knowledgeGraphService
                    .findRelatedKnowledgePoints(event.getTitle(), event.getDescription());
                event.setAffectedKnowledgePointIds(matchResult.getKnowledgePointIds());
                event.setAffectedSubjects(matchResult.getSubjects());
                break;
            // ... 其他类型
        }
    }
}
```

```java
/**
 * 影响分析器 - 分析时效性事件影响哪些内容
 */
@Service
public class ImpactAnalyzer {

    @Autowired
    private ContentSearchService contentSearchService;
    @Autowired
    private KnowledgeGraphService knowledgeGraphService;
    @Autowired
    private TimelinessRuleEngine ruleEngine;
    @Autowired
    private ContentTimelinessLinkService linkService;
    @Autowired
    private ContentFreshnessProfileService profileService;
    @Autowired
    private RefreshTaskGenerator taskGenerator;

    /**
     * 异步分析（普通事件）
     */
    @Async("timelinessExecutor")
    public void asyncAnalyze(TimelinessEvent event) {
        analyze(event);
    }

    /**
     * 紧急分析（CRITICAL事件）
     */
    public void emergencyAnalyze(TimelinessEvent event) {
        event.setStatus(EventStatus.ANALYZING);
        analyze(event);
        // CRITICAL 直接触发紧急下线
        triggerEmergencyTakedown(event);
    }

    /**
     * 核心分析逻辑
     */
    private void analyze(TimelinessEvent event) {
        log.info("Analyzing timeliness event: {} [{}]", event.getEventCode(), event.getEventType());

        // Step 1: 基于知识图谱关联查找受影响内容
        List<ContentRef> graphMatched = findByKnowledgeGraph(event);

        // Step 2: 基于关键词匹配查找
        List<ContentRef> keywordMatched = findByKeywords(event);

        // Step 3: 基于语义相似度查找
        List<ContentRef> semanticMatched = findBySemanticSimilarity(event);

        // Step 4: 基于规则引擎查找
        List<ContentRef> ruleMatched = findByRules(event);

        // Step 5: 合并去重
        Set<ContentRef> allAffected = new HashSet<>();
        allAffected.addAll(graphMatched);
        allAffected.addAll(keywordMatched);
        allAffected.addAll(semanticMatched);
        allAffected.addAll(ruleMatched);

        // Step 6: 逐条评估影响级别和风险
        List<ImpactAnalysisResult> results = new ArrayList<>();
        for (ContentRef content : allAffected) {
            ImpactAnalysisResult result = assessImpact(content, event);
            if (result.getImpactLevel() != ImpactLevel.NONE) {
                results.add(result);
            }
        }

        // Step 7: 批量持久化关联关系
        saveContentLinks(event.getId(), results);

        // Step 8: 更新内容时效画像
        updateFreshnessProfiles(results);

        // Step 9: 更新事件状态
        event.setStatus(EventStatus.RISK_ASSESSED);
        event.setAffectedContentCount(results.size());
        event.setAnalyzedAt(LocalDateTime.now());
        eventService.update(event);

        // Step 10: 生成刷新任务
        if (!results.isEmpty()) {
            taskGenerator.generateTasks(event, results);
        }

        log.info("Analysis complete for event {}: {} content items affected",
            event.getEventCode(), results.size());
    }

    /**
     * 基于知识图谱查找受影响内容
     */
    private List<ContentRef> findByKnowledgeGraph(TimelinessEvent event) {
        if (CollectionUtils.isEmpty(event.getAffectedKnowledgePointIds())) {
            return Collections.emptyList();
        }

        // 通过知识图谱查找所有关联内容
        return contentSearchService.findByKnowledgePoints(
            event.getAffectedKnowledgePointIds(),
            event.getAffectedSubjects(),
            event.getAffectedStages()
        );
    }

    /**
     * 基于关键词查找受影响内容
     */
    private List<ContentRef> findByKeywords(TimelinessEvent event) {
        // 从事件描述中提取关键词
        List<String> keywords = KeywordExtractor.extract(
            event.getTitle() + " " + event.getDescription(),
            event.getAffectedSubjects()
        );

        // 过滤掉过于通用的词
        keywords = KeywordFilter.filterGeneric(keywords);

        if (keywords.isEmpty()) {
            return Collections.emptyList();
        }

        // 在内容库中检索
        return contentSearchService.searchByKeywords(keywords, event.getAffectedSubjects());
    }

    /**
     * 基于语义相似度查找受影响内容
     */
    private List<ContentRef> findBySemanticSimilarity(TimelinessEvent event) {
        // 将事件描述向量化
        float[] eventVector = embeddingService.embed(
            event.getTitle() + " " + event.getDescription()
        );

        // 在向量库中查找相似内容
        return contentSearchService.searchByVector(eventVector, 0.75, 100);
    }

    /**
     * 基于规则引擎查找
     */
    private List<ContentRef> findByRules(TimelinessEvent event) {
        List<TimelinessRule> matchedRules = ruleEngine.findMatchingRules(event);
        List<ContentRef> results = new ArrayList<>();

        for (TimelinessRule rule : matchedRules) {
            List<ContentRef> matched = ruleEngine.applyRule(rule, event);
            results.addAll(matched);
        }

        return results;
    }

    /**
     * 评估单个内容的影响级别
     */
    private ImpactAnalysisResult assessImpact(ContentRef content, TimelinessEvent event) {
        ImpactAnalysisResult result = new ImpactAnalysisResult();
        result.setContentId(content.getContentId());
        result.setContentType(content.getContentType());

        // 获取内容全文
        String contentText = contentSearchService.getFullText(content.getContentId());

        // 判断影响级别
        ImpactAssessment assessment = ImpactAssessor.assess(contentText, event);

        result.setImpactLevel(assessment.getImpactLevel());
        result.setImpactDescription(assessment.getDescription());
        result.setAffectedSegments(assessment.getAffectedSegments());

        // 计算风险评分
        BigDecimal riskScore = calculateRiskScore(content, event, assessment);
        result.setRiskScore(riskScore);

        // 推荐动作
        result.setRecommendedAction(recommendAction(assessment, riskScore, content));

        // 匹配置信度
        result.setMatchConfidence(assessment.getConfidence());

        return result;
    }

    /**
     * 计算风险评分 (0-100)
     *
     * 风险评分 = w1 × 过时严重度 + w2 × 内容使用量 + w3 × 影响级别 + w4 × 时间衰减
     */
    private BigDecimal calculateRiskScore(ContentRef content,
                                          TimelinessEvent event,
                                          ImpactAssessment assessment) {
        // 严重度评分 (0-100)
        double severityScore = switch (event.getSeverity()) {
            case CRITICAL -> 100;
            case MAJOR -> 70;
            case MINOR -> 40;
            case INFO -> 10;
        };

        // 内容使用量评分 (0-100) - 使用量越高风险越大
        long usageCount = contentUsageService.getUsageCount(content.getContentId());
        double usageScore = Math.min(100, Math.log10(usageCount + 1) * 20);

        // 影响级别评分
        double impactScore = switch (assessment.getImpactLevel()) {
            case FULL -> 100;
            case PARTIAL -> 60;
            case CONTEXTUAL -> 30;
            case NONE -> 0;
        };

        // 内容时效敏感度评分
        TimelinessSensitivity sensitivity = profileService.getSensitivity(content.getContentId());
        double sensitivityScore = switch (sensitivity) {
            case HIGH -> 100;
            case MEDIUM -> 60;
            case LOW -> 30;
            case STABLE -> 10;
        };

        // 加权计算
        double risk = 0.30 * severityScore
                    + 0.25 * usageScore
                    + 0.25 * impactScore
                    + 0.20 * sensitivityScore;

        return BigDecimal.valueOf(risk).setScale(2, RoundingMode.HALF_UP);
    }

    private String recommendAction(ImpactAssessment assessment,
                                    BigDecimal riskScore,
                                    ContentRef content) {
        if (riskScore.compareTo(BigDecimal.valueOf(80)) >= 0) {
            return "EMERGENCY_TAKEDOWN";
        }
        if (assessment.getImpactLevel() == ImpactLevel.FULL) {
            return "CORRECTION";
        }
        if (assessment.getImpactLevel() == ImpactLevel.PARTIAL) {
            return "UPDATE";
        }
        if (assessment.getImpactLevel() == ImpactLevel.CONTEXTUAL) {
            return "CONTEXT_SUPPLEMENT";
        }
        return "MARK_FOR_CHECK";
    }
}
```

```java
     * 每天凌晨 02:00 执行巡检
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void dailyFreshnessCheck() {
        log.info("Starting daily freshness check...");

        // 1. 查找到期需要检查的内容
        List<ContentFreshnessProfile> dueForCheck = profileService
            .findDueForCheck(LocalDate.now());

        log.info("Found {} content items due for check", dueForCheck.size());

        // 2. 分批处理
        int batchSize = 200;
        List<List<ContentFreshnessProfile>> batches = partition(dueForCheck, batchSize);

        for (List<ContentFreshnessProfile> batch : batches) {
            processBatch(batch);
        }

        // 3. 更新时效性评分（批量衰减）
        profileService.batchDecayFreshnessScores();

        log.info("Daily freshness check completed");
    }

    private void processBatch(List<ContentFreshnessProfile> profiles) {
        for (ContentFreshnessProfile profile : profiles) {
            try {
                checkSingleContent(profile);
            } catch (Exception e) {
                log.error("Error checking content {}: {}",
                    profile.getContentId(), e.getMessage());
            }
        }
    }

    private void checkSingleContent(ContentFreshnessProfile profile) {
        // 获取适用的规则
        List<TimelinessRule> rules = ruleEngine.findRulesForContent(
            profile.getContentType(),
            profile.getTimelinessSensitivity()
        );

        boolean needsAttention = false;
        List<String> detectedRisks = new ArrayList<>();

        for (TimelinessRule rule : rules) {
            RuleCheckResult result = ruleEngine.executeCheck(rule, profile.getContentId());
            if (result.isTriggered()) {
                needsAttention = true;
                detectedRisks.add(result.getRiskLabel());

                // 如果规则动作是 MARK_OUTDATED，降低时效评分
                if (rule.getAction() == "MARK_OUTDATED") {
                    profile.setFreshnessScore(
                        profile.getFreshnessScore().subtract(BigDecimal.valueOf(20))
                    );
                }
            }
        }

        if (needsAttention) {
            // 更新风险标签
            profile.setKnownRisks(detectedRisks);
            profile.setStatus(FreshnessStatus.STALE);
        }

        // 更新下次检查时间
        profile.setLastVerifiedAt(LocalDateTime.now());
        profile.setNextCheckDue(LocalDateTime.now().plusDays(profile.getCheckPeriodDays()));

        profileService.update(profile);
    }
}
```

### 4.5 时效性评分衰减模型

```java
/**
 * 时效性评分衰减模型
 *
 * 评分随时间自然衰减，衰减速率取决于时效敏感度：
 * - HIGH: 每月衰减 15 分
 * - MEDIUM: 每月衰减 8 分
 * - LOW: 每月衰减 3 分
 * - STABLE: 不衰减
 *
 * 评分公式：
 * score = max(0, 100 - decayRate × monthsSinceVerification)
 *
 * 当评分低于 40 时自动标记为 STALE
 * 当评分低于 20 时自动标记为 OUTDATED
 */
public class FreshnessScoreDecayModel {

    private static final Map<TimelinessSensitivity, Double> MONTHLY_DECAY = Map.of(
        TimelinessSensitivity.HIGH,   15.0,
        TimelinessSensitivity.MEDIUM, 8.0,
        TimelinessSensitivity.LOW,    3.0,
        TimelinessSensitivity.STABLE, 0.0
    );

    private static final double STALE_THRESHOLD = 40.0;
    private static final double OUTDATED_THRESHOLD = 20.0;

    /**
     * 计算衰减后的评分
     */
    public static BigDecimal calculateDecayedScore(ContentFreshnessProfile profile) {
        if (profile.getLastVerifiedAt() == null) {
            return BigDecimal.valueOf(50.0); // 从未验证过，给中等评分
        }

        long monthsSinceVerification = ChronoUnit.MONTHS.between(
            profile.getLastVerifiedAt(),
            LocalDateTime.now()
        );

        double decayRate = MONTHLY_DECAY.getOrDefault(
            profile.getTimelinessSensitivity(), 8.0
        );

        double decayedScore = Math.max(0,
            100.0 - decayRate * monthsSinceVerification
        );

        return BigDecimal.valueOf(decayedScore).setScale(2, RoundingMode.HALF_UP);
    }

    /**
     * 基于衰减评分判定状态
     */
    public static FreshnessStatus determineStatus(double score) {
        if (score >= STALE_THRESHOLD) {
            return FreshnessStatus.FRESH;
        }
        if (score >= OUTDATED_THRESHOLD) {
            return FreshnessStatus.STALE;
        }
        return FreshnessStatus.OUTDATED;
    }
}
```

## 6. 时效性敏感度自动标注引擎

内容发布时或入库时，需要自动判定内容的时效敏感度。此模块基于内容文本特征自动标注。

```java
/**
 * 时效敏感度自动标注器
 */
@Service
public class TimelinessSensitivityAutoTagger {

    // 高敏感度信号词
    private static final List<String> HIGH_SENSITIVITY_SIGNALS = List.of(
        // 统计数据相关
        "据统计", "数据表明", "截至.*年", "目前.*约", "现有.*人口",
        "GDP", "人均", "总量", "排名",
        // 政策法规相关
        "根据.*规定", "根据.*法", "按照.*政策", "教育部.*要求",
        "新课标", "高考改革", "双减",
        // 时事相关
        "现任", "现任总统", "目前.*主席", "当前.*局势",
        // 科技相关
        "最新.*技术", "目前.*主流", "当前.*版本"
    );

    // 中敏感度信号词
    private static final List<String> MEDIUM_SENSITIVITY_SIGNALS = List.of(
        "科学家认为", "研究表明", "最新的.*发现",
        "近期.*研究", "近年来", "二十一世纪",
        "目前.*共识", "学术界.*观点"
    );

    /**
     * 自动标注内容的时效敏感度
     */
    public TimelinessSensitivityResult tag(String contentId, String contentText,
                                            String subject, ContentType contentType) {
        List<String> reasons = new ArrayList<>();
        int sensitivityScore = 0;

        // 1. 关键词匹配
        for (String pattern : HIGH_SENSITIVITY_SIGNALS) {
            if (contentText.matches(".*" + pattern + ".*")) {
                sensitivityScore += 30;
                reasons.add("high_sensitivity_keyword: " + pattern);
            }
        }

        for (String pattern : MEDIUM_SENSITIVITY_SIGNALS) {
            if (contentText.matches(".*" + pattern + ".*")) {
                sensitivityScore += 15;
                reasons.add("medium_sensitivity_keyword: " + pattern);
            }
        }

        // 2. 学科维度调整
        sensitivityScore += getSubjectBaseScore(subject);

        // 3. 内容类型调整
        sensitivityScore += getContentTypeAdjustment(contentType);

        // 4. 包含具体年份数据时增加敏感度
        Pattern yearPattern = Pattern.compile("(19|20)\\d{2}年");
        if (yearPattern.matcher(contentText).find()) {
            sensitivityScore += 10;
            reasons.add("contains_specific_year_reference");
        }

        // 5. 判定敏感度等级
        TimelinessSensitivity sensitivity;
        int checkPeriodDays;

        if (sensitivityScore >= 60) {
            sensitivity = TimelinessSensitivity.HIGH;
            checkPeriodDays = 30;
        } else if (sensitivityScore >= 30) {
            sensitivity = TimelinessSensitivity.MEDIUM;
            checkPeriodDays = 90;
        } else if (sensitivityScore >= 10) {
            sensitivity = TimelinessSensitivity.LOW;
            checkPeriodDays = 365;
        } else {
            sensitivity = TimelinessSensitivity.STABLE;
            checkPeriodDays = 0; // 仅事件触发
        }

        return new TimelinessSensitivityResult(sensitivity, checkPeriodDays, reasons);
    }

    private int getSubjectBaseScore(String subject) {
        return switch (subject) {
            case "politics" -> 40;  // 政治高度时效敏感
            case "geography" -> 25;  // 地理中度时效敏感
            case "history" -> 20;
            case "biology" -> 15;
            case "chemistry" -> 10;
            case "physics" -> 5;
            case "math" -> 0;       // 数学基本不受时效影响
            default -> 10;
        };
    }

    private int getContentTypeAdjustment(ContentType contentType) {
        return switch (contentType) {
            case QUESTION -> 5;       // 题目可能引用时事
            case EXPLANATION -> 10;   // 讲解可能引用数据
            case VIDEO -> 5;
            default -> 0;
        };
    }
}
```

## 8. 紧急下线联动流程

当发现 CRITICAL 级别的过时内容时，需要紧急下线处理：

```java
/**
 * 紧急下线联动处理器
 */
@Service
public class EmergencyTakedownHandler {

    @Autowired
    private ContentManagementService contentService;
    @Autowired
    private NotificationService notificationService;

    /**
     * 触发紧急下线
     */
    public void handleEmergency(TimelinessEvent event, List<ImpactAnalysisResult> impacts) {
        // 1. 过滤需要紧急下线的内容
        List<String> takedownContentIds = impacts.stream()
            .filter(i -> "EMERGENCY_TAKEDOWN".equals(i.getRecommendedAction())
                      || i.getRiskScore().compareTo(BigDecimal.valueOf(80)) >= 0)
            .map(ImpactAnalysisResult::getContentId)
            .toList();

        if (takedownContentIds.isEmpty()) {
            return;
        }

        // 2. 批量下线
        for (String contentId : takedownContentIds) {
            contentService.takedown(contentId, TakedownReason.CONTENT_OUTDATED, event.getEventCode());

            // 更新画像状态
            profileService.updateStatus(contentId, FreshnessStatus.RETIRED);
        }

        // 3. 通知相关人员
        notifyStakeholders(event, takedownContentIds);

        // 4. 创建紧急修正任务
        RefreshTask emergencyTask = RefreshTask.builder()
            .taskCode(taskCodeGenerator.next())
            .eventId(event.getId())
            .taskType(RefreshTaskType.CORRECTION)
            .priority("P0")
            .contentIds(takedownContentIds)
            .changeDescription("紧急修正：" + event.getTitle())
            .dueDate(LocalDateTime.now().plusHours(48))
            .status(RefreshTaskStatus.CREATED)
            .build();

        taskService.save(emergencyTask);

        log.warn("Emergency takedown triggered for {} content items due to event: {}",
            takedownContentIds.size(), event.getEventCode());
    }

    private void notifyStakeholders(TimelinessEvent event, List<String> contentIds) {
        // 通知内容运营负责人
        notificationService.sendToRole("CONTENT_OPS_LEAD",
            String.format("【紧急】%d个内容已因时效性问题紧急下线。事件：%s。请立即处理。",
                contentIds.size(), event.getTitle()));

        // 通知学科负责人
        for (String subject : event.getAffectedSubjects()) {
            notificationService.sendToRole("SUBJECT_LEAD:" + subject,
```

## 9. 错误处理与容灾

### 9.1 外部数据源容错

| 异常场景 | 处理策略 |
| --- | --- |
| 外部数据源不可达 | 重试3次，间隔递增（1min, 5min, 15min），失败后暂停该数据源，发告警 |
| 数据源返回格式异常 | 记录原始响应，跳过该条信号，不中断整体流程 |
| 数据源返回大量信号 | 批量处理，单批最多100条，超出排队异步处理 |
| 数据源认证过期 | 自动尝试刷新token，失败则暂停数据源并告警 |

### 9.2 分析引擎容错

| 异常场景 | 处理策略 |
| --- | --- |
| 向量检索服务不可用 | 降级为仅使用关键词+规则匹配，跳过语义匹配 |
| 知识图谱服务不可用 | 降级为仅使用关键词+语义匹配，跳过图谱关联 |
| 单条内容分析超时 | 跳过该条，记录失败日志，不阻塞批次 |
| 批量分析中部分失败 | 已成功的结果正常保存，失败的记录重试队列 |
| 数据库写入失败 | 重试3次，失败后存入死信队列，人工介入 |

## 10. 性能优化

### 10.1 批量分析优化

```java
/**
 * 批量影响分析优化器
 *
 * 单次事件可能影响数千条内容，需要高效的批量处理策略。
 */
@Service
public class BatchImpactOptimizer {

    /**
     * 批量分析策略：
     * 1. 先用知识图谱 + 关键词做粗筛（快速，覆盖大部分）
     * 2. 对粗筛结果用语义相似度做精筛（准确，但慢）
     * 3. 对精筛结果逐条评估影响级别
     */
    public BatchAnalysisResult batchAnalyze(TimelinessEvent event) {
        // Phase 1: 粗筛（并行）
        CompletableFuture<List<ContentRef>> graphFuture = CompletableFuture.supplyAsync(
            () -> impactAnalyzer.findByKnowledgeGraph(event)
        );
        CompletableFuture<List<ContentRef>> keywordFuture = CompletableFuture.supplyAsync(
            () -> impactAnalyzer.findByKeywords(event)
        );
        CompletableFuture<List<ContentRef>> ruleFuture = CompletableFuture.supplyAsync(
            () -> impactAnalyzer.findByRules(event)
        );

        // 等待粗筛完成
        CompletableFuture.allOf(graphFuture, keywordFuture, ruleFuture).join();

        Set<ContentRef> coarseFiltered = new HashSet<>();
        coarseFiltered.addAll(graphFuture.join());
        coarseFiltered.addAll(keywordFuture.join());
        coarseFiltered.addAll(ruleFuture.join());

        // Phase 2: 语义精筛（仅对粗筛结果）
        List<ContentRef> fineFiltered = new ArrayList<>();
        if (!coarseFiltered.isEmpty()) {
            float[] eventVector = embeddingService.embed(
                event.getTitle() + " " + event.getDescription()
            );

            for (ContentRef content : coarseFiltered) {
                float[] contentVector = embeddingService.getOrCreateContentVector(
                    content.getContentId()
                );
                float similarity = CosineSimilarity.calculate(eventVector, contentVector);

                if (similarity > 0.65) {
                    fineFiltered.add(content);
                }
            }
        }

        // Phase 3: 并行逐条评估
        List<ImpactAnalysisResult> results = fineFiltered.parallelStream()
            .map(content -> impactAnalyzer.assessImpact(content, event))
            .filter(r -> r.getImpactLevel() != ImpactLevel.NONE)
            .toList();

        return new BatchAnalysisResult(
            coarseFiltered.size(), fineFiltered.size(), results.size(), results
        );
    }
}
```

## 13. 与内容生产管线的集成

刷新任务完成后，需要通知内容生产管线更新相关内容状态：

```java
/**
 * 刷新任务完成后的事件处理
 */
@Component
public class RefreshTaskCompletionHandler {

    @EventListener
    public void onRefreshTaskCompleted(RefreshTaskCompletedEvent event) {
        RefreshTask task = event.getTask();

        // 1. 更新内容时效画像
        for (String contentId : task.getContentIds()) {
            ContentFreshnessProfile profile = profileService.findByContentId(contentId);

            profile.setFreshnessScore(BigDecimal.valueOf(100));
            profile.setStatus(FreshnessStatus.FRESH);
            profile.setLastVerifiedAt(LocalDateTime.now());
            profile.setLastRefreshedAt(LocalDateTime.now());
            profile.setNextCheckDue(LocalDateTime.now().plusDays(profile.getCheckPeriodDays()));

            // 清除已知风险
            profile.setKnownRisks(Collections.emptyList());

            // 移除已解决的事件关联
            profile.getOutdatedEventIds().remove(task.getEventId());

            profileService.update(profile);
        }

        // 2. 更新时效性事件状态
        if (task.getEventId() != null) {
            TimelinessEvent timelinessEvent = eventService.findById(task.getEventId());

            // 检查该事件的所有关联内容是否都已处理
            int pendingTasks = taskService.countPendingByEventId(task.getEventId());
            if (pendingTasks == 0) {
                timelinessEvent.setStatus(EventStatus.CLOSED);
                timelinessEvent.setResolvedAt(LocalDateTime.now());
                eventService.update(timelinessEvent);
            }
        }

        // 3. 通知内容搜索索引重建
        indexingService.reindex(task.getContentIds());

        // 4. 清除相关缓存
        for (String contentId : task.getContentIds()) {
            cacheService.evict("freshness:" + contentId);
        }
    }
}
```

## 14. 总结

### 14.1 核心价值

本引擎为 PrimeTop 平台提供了**教育内容时效性的自动化保障能力**：

1. **主动发现**：通过外部数据源监控和定期巡检，在用户发现问题之前识别过时内容。
2. **精准定位**：通过知识图谱 + 关键词 + 语义相似度 + 规则引擎的多维匹配，精确找到受影响的内容。
3. **智能分级**：基于内容使用量、时效敏感度、影响级别等因素，自动计算风险评分和优先级。
4. **闭环处理**：从发现 → 分析 → 任务生成 → 内容更新 → 审核验证，全流程自动化。

### 14.2 技术亮点

| 亮点 | 说明 |
| --- | --- |
| 多维度匹配 | 知识图谱关联 + 关键词 + 语义向量 + 规则引擎四路并行 |
| 自适应评分衰减 | 基于时效敏感度的动态评分衰减模型 |
| 用户参与 | 用户反馈通道 + 多反馈聚合升级机制 |
| 紧急联动 | CRITICAL 级别自动触发下线 + 通知 + 紧急任务 |
| 批量优化 | 粗筛→精筛→逐条评估的三级漏斗式处理 |

### 14.3 后续演进方向

1. **AI 驱动的语义变化检测**：对比内容发布时的外部知识快照与当前状态的差异。
2. **预测性过时预警**：基于历史数据预测哪些内容即将过时（如统计数据类内容每年固定更新期）。
3. **自动化内容修正**：对于简单的过时修正（如年份更新、数据替换），探索 AI 自动生成修正建议。
4. **跨平台内容同步**：与教材出版社、教育机构的官方更新通道直接对接。
