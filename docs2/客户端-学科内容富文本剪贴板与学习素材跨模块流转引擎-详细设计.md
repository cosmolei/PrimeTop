# 客户端-学科内容富文本剪贴板与学习素材跨模块流转引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

在 PrimeTop App 中，学生频繁需要在不同模块间传递学习素材：从 AI 对话中复制公式到笔记、把题目从练习页转发到错题本、将解析内容分享到微信等。学科内容包含 LaTeX 公式、化学方程式、几何图形、Markdown 富文本等复杂结构，传统纯文本剪贴板会破坏格式。

本引擎作为**客户端基础设施层**，统一处理：
- 学科富文本的复制/粘贴/拖拽
- 学习素材在模块间的安全流转（AI 对话 → 错题本 → 笔记 → 打印 → 分享）
- 剪贴板智能感知与上下文操作推荐
- 系统级 Share Sheet / Share 接口集成

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 格式保真 | LaTeX 公式、化学方程式、Markdown 等跨模块传递时格式不丢失 |
| 零拷贝流转 | 用户长按/拖拽即可将内容发往目标模块，无需手动截图或重输入 |
| 智能感知 | 监听系统剪贴板，识别题目/公式/单词等内容类型，主动推荐操作 |
| 安全隔离 | 剪贴板内容不落盘到明文文件，敏感内容自动脱敏 |
| 多端一致 | Android / iOS 双端行为一致，API 统一 |

### 1.3 适用范围

- AI 对话页面、练习答题页面、错题本、笔记系统、同步课堂阅读器
- 拍照搜题结果页、作文辅导页、学情报告页
- 系统级分享面板（iOS Share Sheet / Android Share Sheet）
- 应用内模块间跳转传参

## 3. 核心数据结构

### 3.1 ClipboardPayload — 剪贴板内容统一数据模型

```dart
/// 剪贴板承载的统一内容模型，所有复制/转发操作的标准载体。
class ClipboardPayload {
  /// 唯一ID（UUID v4）
  final String payloadId;

  /// 内容类型
  final PayloadType type;

  /// 原始富文本（Markdown 格式，含 LaTeX 公式行内/行间标记）
  final String richContent;

  /// 纯文本降级（用于系统剪贴板兜底）
  final String plainText;

  /// 携带的结构化学科片段
  final List<SubjectFragment> fragments;

  /// 来源信息
  final PayloadSource source;

  /// 创建时间戳（毫秒）
  final int createdAt;

  /// 过期时间戳（毫秒），0 表示不过期
  final int expireAt;

  /// 附加元数据
  final Map<String, dynamic> metadata;
}

enum PayloadType {
  text,           // 纯文本
  richText,       // Markdown 富文本
  question,       // 题目（含题干/选项/图形）
  formula,        // 独立公式片段
  image,          // 图片
  audio,          // 音频片段
  note,           // 笔记内容
  report,         // 学习报告片段
  mixed,          // 混合内容
}
```

## 4. 核心模块详细设计

### 4.1 RichContentCodec — 富文本编解码器

负责在 `ClipboardPayload` 与各种目标格式之间互转。

#### 4.1.1 编码策略矩阵

| 源内容类型 | 系统剪贴板格式 | 内部传递格式 | 分享导出格式 |
| --- | --- | --- | --- |
| 纯文本 | text/plain | ClipboardPayload JSON | text/plain |
| Markdown 富文本 | text/plain + text/html | ClipboardPayload JSON | text/html + 附件 |
| LaTeX 公式 | text/plain (LaTeX源码) | SubjectFragment JSON | PNG 渲染图 + LaTeX 源码 |
| 化学方程式 | text/plain | SubjectFragment JSON | PNG + 纯文本 |
| 题目（含图） | text/plain (文字部分) | ClipboardPayload JSON (含图片引用) | HTML + 图片附件 |
| 图片 | image/png (Native) | 图片路径引用 | image/png |
| 学习报告 | text/plain + text/html | ClipboardPayload JSON | PDF / PNG 长图 |

#### 4.1.2 关键实现

```dart
class RichContentCodec {
  /// 将 ClipboardPayload 编码为系统剪贴板可接受的多格式数据
  static ClipboardData encodeToClipboard(ClipboardPayload payload) {
    switch (payload.type) {
      case PayloadType.text:
        return ClipboardData(text: payload.plainText);

      case PayloadType.formula:
        // 公式：同时写入 LaTeX 源码和渲染后的 HTML
        return ClipboardData(
          text: payload.plainText,
          richText: _formulaToHtml(payload.fragments.first),
        );

      case PayloadType.question:
      case PayloadType.richText:
        // 富文本：写入 Markdown 源码 + HTML 渲染结果
        return ClipboardData(
          text: payload.plainText,
          richText: _markdownToHtml(payload.richContent),
        );

      case PayloadType.image:
        // 图片走平台通道写入
        _writeImageToClipboard(payload);
        return ClipboardData(text: '[图片]');

      default:
        return ClipboardData(text: payload.plainText);
    }
  }

  /// 从系统剪贴板解码为 ClipboardPayload
  static Future<ClipboardPayload?> decodeFromClipboard({
    required PayloadSource source,
  }) async {
    final clipData = await Clipboard.getData(Clipboard.kTextPlain);
    if (clipData?.text == null || clipData!.text!.isEmpty) return null;

    final text = clipData.text!;

    // 检测是否是内部格式的 JSON
    if (_isPrimeTopPayload(text)) {
      return _deserializePayload(text);
    }

    // 外部纯文本 → 构造基本 Payload 并做智能识别
    final fragments = _extractFragments(text);
    final type = _inferPayloadType(text, fragments);

    return ClipboardPayload(
      payloadId: _uuid(),
      type: type,
      richContent: text,
      plainText: text,
      fragments: fragments,
      source: source,
      createdAt: DateTime.now().millisecondsSinceEpoch,
      expireAt: 0,
      metadata: {},
    );
  }

  /// 从 LaTeX 生成 PNG 图片字节（用于分享/导出）
  static Future<Uint8List> formulaToPng(String latex, {
    double scale = 3.0,
    Color background = Colors.white,
  }) async {
    final renderer = MathRenderer.instance;
    final picture = await renderer.renderToPicture(
      latex,
      scale: scale,
      background: background,
    );
    return await picture.toByteData(format: ImageByteFormat.png)
        .then((b) => b!.buffer.asUint8List());
  }

  /// 将 Markdown（含公式、化学式）转换为 HTML 字符串
  static String _markdownToHtml(String markdown) {
    // 1. 提取并保护 LaTeX 公式段
    final placeholders = <String, String>{};
    var protected = markdown.replaceAllMapped(
      RegExp(r'\$\$?[\s\S]+?\$\$?'),
      (m) {
        final key = '__FORMULA_${placeholders.length}__';
        placeholders[key] = m.group(0)!;
        return key;
      },
    );

    // 2. 标准 Markdown → HTML
    var html = markdownToHtml(protected);

    // 3. 还原公式为 MathJax 兼容 HTML
    placeholders.forEach((key, formula) {
      html = html.replaceAll(key, '<span class="math">$formula</span>');
    });

    return html;
  }

  /// 智能提取学科片段
  static List<SubjectFragment> _extractFragments(String text) {
    final fragments = <SubjectFragment>[];

    // LaTeX 行间公式
    for (final match in RegExp(r'\$\$([\s\S]+?)\$\$').allMatches(text)) {
      fragments.add(SubjectFragment(
        fragmentType: FragmentType.latexBlock,
        raw: match.group(0)!,
        renderContent: match.group(1)!,
        fallbackText: '[公式]',
        knowledgePointIds: [],
        subject: '',
      ));
    }

    // LaTeX 行内公式
    for (final match in RegExp(r'(?<!\$)\$(?!\$)(.+?)(?<!\$)\$(?!\$)').allMatches(text)) {
      fragments.add(SubjectFragment(
        fragmentType: FragmentType.latexInline,
        raw: match.group(0)!,
        renderContent: match.group(1)!,
        fallbackText: '[公式]',
        knowledgePointIds: [],
        subject: '',
      ));
    }

    // 化学方程式简易检测（大写字母开头，含 → 或 ⇌ 或数字下标）
    final chemPattern = RegExp(
      r'(?:[A-Z][a-z]?\d*(?:[=→⇌]|->)(?:(?:[A-Z][a-z]?\d*)+|.+?)(?:\s*[（(].+?[）)])?)',
    );
    for (final match in chemPattern.allMatches(text)) {
      fragments.add(SubjectFragment(
        fragmentType: FragmentType.chemicalFormula,
        raw: match.group(0)!,
        renderContent: match.group(0)!,
        fallbackText: match.group(0)!,
        knowledgePointIds: [],
        subject: 'chemistry',
      ));
    }

    return fragments;
  }
}
```

### 4.2 ClipboardSniffer — 剪贴板智能感知器

在 App 从后台回到前台时，检测系统剪贴板内容并推荐操作。

#### 4.2.1 感知策略

```
触发时机：
  1. App 从后台恢复（AppLifecycleState.resumed）
  2. 用户在输入框长按（准备粘贴时）
  3. 用户从外部 App 切入（Deep Link / Share）

频率控制：
  - 同一剪贴板内容 hash 只提示一次
  - 距上次提示 < 30s 不重复提示
  - 用户关闭后 2h 内不再提示
```

#### 4.2.2 内容识别引擎

```dart
class ClipboardSniffer {
  final _lastSniffHash = <String, int>{}; // hash → timestamp
  final _suppressUntil = <String, int>{};  // type → suppress deadline

  /// App 恢复前台时调用
  Future<SniffResult?> sniffOnResume() async {
    if (!_shouldSniff()) return null;

    final payload = await RichContentCodec.decodeFromClipboard(
      source: PayloadSource(
        module: SourceModule.external,
        route: '/',
        entityId: null,
        userId: null,
      ),
    );
    if (payload == null) return null;

    final hash = _contentHash(payload);
    final now = DateTime.now().millisecondsSinceEpoch;

    // 去重
    if (_lastSniffHash.containsKey(hash) &&
        now - _lastSniffHash[hash]! < 30000) {
      return null;
    }
    _lastSniffHash[hash] = now;

    // 智能分类
    final contentType = _classifyContent(payload);
    if (_isSuppressed(contentType, now)) return null;

    return SniffResult(
      payload: payload,
      contentType: contentType,
      suggestedActions: _buildSuggestions(payload, contentType),
    );
  }

  /// 内容分类器
  ContentType _classifyContent(ClipboardPayload payload) {
    final text = payload.plainText.trim();

    // 题目检测：包含"求"、"解"、"证明"、选项标记(A/B/C/D)、问号等
    if (_looksLikeQuestion(text)) return ContentType.question;

    // 公式检测
    if (payload.fragments.any((f) =>
        f.fragmentType == FragmentType.latexBlock ||
        f.fragmentType == FragmentType.latexInline)) {
      return ContentType.formula;
    }

    // 英语单词检测
    if (RegExp(r'^[a-zA-Z]+(-[a-zA-Z]+)*$').hasMatch(text) &&
        text.length <= 50) {
      return ContentType.englishWord;
    }

    // 古诗文检测（含文言特征词）
    if (_looksLikeClassicalChinese(text)) return ContentType.classicalText;

    // 代码检测
    if (_looksLikeCode(text)) return ContentType.code;

    // URL 检测
    if (Uri.tryParse(text)?.hasAbsolutePath == true) {
      return ContentType.url;
    }

    return ContentType.plainText;
  }

  List<TransferAction> _buildSuggestions(
    ClipboardPayload payload,
    ContentType contentType,
  ) {
    switch (contentType) {
      case ContentType.question:
        return [
          TransferAction(
            actionId: 'ask_ai',
            type: TransferType.askAi,
            label: '问AI解析',
            iconAsset: 'assets/icons/ask_ai.png',
            targetRoute: '/ai-chat',
            paramBuilder: (p) => {
              'prefill': p.plainText,
              'source': 'clipboard_question',
            },
          ),
          TransferAction(
            actionId: 'photo_search',
            type: TransferType.searchRelated,
            label: '搜题',
            iconAsset: 'assets/icons/search.png',
            targetRoute: '/search',
            paramBuilder: (p) => {'query': p.plainText},
          ),
          TransferAction(
            actionId: 'add_mistake',
            type: TransferType.addToMistakeBook,
            label: '加入错题本',
            iconAsset: 'assets/icons/mistake.png',
            targetRoute: '/mistake-book/add',
            paramBuilder: (p) => {
              'questionText': p.plainText,
              'fragments': p.fragments.map((f) => f.toJson()).toList(),
            },
          ),
        ];

      case ContentType.formula:
        return [
          TransferAction(
            actionId: 'formula_render',
            type: TransferType.generateCard,
            label: '生成公式卡片',
            iconAsset: 'assets/icons/card.png',
            targetRoute: '/card/preview',
            paramBuilder: (p) => {
              'latex': p.fragments.first.renderContent,
              'source': 'clipboard',
            },
          ),
          TransferAction(
            actionId: 'formula_search',
            type: TransferType.searchRelated,
            label: '搜索此公式',
            iconAsset: 'assets/icons/search.png',
            targetRoute: '/search',
            paramBuilder: (p) => {'query': p.fragments.first.raw},
          ),
        ];

      case ContentType.englishWord:
        return [
          TransferAction(
            actionId: 'word_lookup',
            type: TransferType.searchRelated,
            label: '查单词',
            iconAsset: 'assets/icons/dict.png',
            targetRoute: '/search',
            paramBuilder: (p) => {
              'query': p.plainText,
              'type': 'word_lookup',
            },
          ),
          TransferAction(
            actionId: 'word_to_note',
            type: TransferType.addToNote,
            label: '加入单词本',
            iconAsset: 'assets/icons/note.png',
            targetRoute: '/note/english-vocab',
            paramBuilder: (p) => {'word': p.plainText},
          ),
        ];

      case ContentType.classicalText:
        return [
          TransferAction(
            actionId: 'classical_recite',
            type: TransferType.generateCard,
            label: '开始背诵',
            iconAsset: 'assets/icons/recite.png',
            targetRoute: '/recite',
            paramBuilder: (p) => {'text': p.plainText},
          ),
          TransferAction(
            actionId: 'classical_translate',
            type: TransferType.askAi,
            label: 'AI翻译',
            iconAsset: 'assets/icons/translate.png',
            targetRoute: '/ai-chat',
            paramBuilder: (p) => {
              'prefill': '请翻译以下古文：\n${p.plainText}',
              'source': 'clipboard_classical',
            },
          ),
        ];

      default:
        return [
          TransferAction(
            actionId: 'plain_ask_ai',
            type: TransferType.askAi,
            label: '问AI',
            iconAsset: 'assets/icons/ask_ai.png',
            targetRoute: '/ai-chat',
            paramBuilder: (p) => {'prefill': p.plainText},
          ),

    }
  }
}
```

### 4.3 ContentTransferRouter — 内容转发路由器

负责将 `ClipboardPayload` 路由到目标模块。

#### 4.3.1 转发流程状态机

```
用户触发转发（长按菜单 / 智能推荐 / 拖拽）
         │
         ▼
   ┌─────────────┐
   │ SELECT_TARGET│ ── 用户选择目标（取消？→ END）
   └──────┬──────┘
          │
          ▼
   ┌─────────────┐    目标模块未注册    ┌──────────┐
   │ VALIDATE    │ ──────────────────→ │ ERROR    │
   └──────┬──────┘                      └──────────┘
          │ 校验通过
          ▼
   ┌─────────────┐    格式转换失败      ┌──────────┐
   │ TRANSFORM   │ ──────────────────→ │ FALLBACK │ (降级为纯文本)
   └──────┬──────┘                      └────┬─────┘
          │                                  │
          │ 转换成功                          │ 降级成功
          ▼                                  ▼
   ┌─────────────┐                       ┌──────────┐
   │ DISPATCH    │ ←─────────────────────│          │
   └──────┬──────┘                       └──────────┘
          │
          ▼
   ┌─────────────┐
   │ ACKNOWLEDGE │ ── 目标模块确认接收
   └──────┬──────┘
          │
          ▼
   ┌─────────────┐
   │ NAVIGATE    │ ── 跳转到目标页面（可选）
   └─────────────┘
```

#### 4.3.2 核心实现

```dart
class ContentTransferRouter {
  static final ContentTransferRouter _instance = ContentTransferRouter._();
  factory ContentTransferRouter() => _instance;
  ContentTransferRouter._();

  /// 模块注册表：moduleId → ModuleHandler
  final Map<String, ModuleHandler> _handlers = {};

  /// 注册模块处理器
  void registerModule(String moduleId, ModuleHandler handler) {
    _handlers[moduleId] = handler;
  }

  /// 执行转发
  Future<TransferResult> transfer({
    required ClipboardPayload payload,
    required String targetModuleId,
    Map<String, dynamic>? extraParams,
    bool navigateAfter = true,
  }) async {
    // 1. 校验目标模块
    final handler = _handlers[targetModuleId];
    if (handler == null) {
      return TransferResult(
        success: false,
        errorCode: 'MODULE_NOT_FOUND',
        errorMessage: '目标模块未注册: $targetModuleId',
      );
    }

    // 2. 能力校验
    if (!handler.canAccept(payload.type)) {
      // 尝试降级
      final downgraded = _downgradePayload(payload);
      if (!handler.canAccept(downgraded.type)) {
        return TransferResult(
          success: false,
          errorCode: 'TYPE_MISMATCH',
          errorMessage: '目标模块不支持此内容类型',
        );
      }
      payload = downgraded;
    }

    // 3. 格式转换
    ClipboardPayload transformed;
    try {
      transformed = handler.transform(payload);
    } catch (e) {
      // 降级为纯文本
      transformed = _stripToPlainText(payload);
    }

    // 4. 派发到目标模块
    try {
      final params = <String, dynamic>{
        'payload': transformed.toJson(),
        ...?extraParams,
      };

      // 写入跨模块消息总线
      await _ModuleBus.instance.send(
        target: targetModuleId,
        message: ModuleMessage(
          type: 'content_transfer',
          data: params,
          timestamp: DateTime.now().millisecondsSinceEpoch,
        ),
      );

      // 5. 目标模块确认
      final ack = await _ModuleBus.instance.waitForAck(
        target: targetModuleId,
        timeout: const Duration(seconds: 3),
      );

      if (ack == null) {
        // 超时：存入草稿箱，目标模块上线后补收
        await _DraftBox.instance.save(
          targetModuleId: targetModuleId,
          payload: transformed,
        );
      }

      // 6. 页面跳转
      if (navigateAfter && handler.route != null) {
        AppRouter.push(
          handler.route!,
          arguments: params,
        );
      }

      return TransferResult(
        success: true,
        targetModuleId: targetModuleId,
        payloadId: transformed.payloadId,
      );
    } catch (e) {
      return TransferResult(
        success: false,
        errorCode: 'DISPATCH_FAILED',
        errorMessage: '转发失败: $e',
      );
    }
  }

  /// 降级策略
  ClipboardPayload _downgradePayload(ClipboardPayload original) {
    // richText → text
    if (original.type == PayloadType.richText) {
      return ClipboardPayload(
        payloadId: original.payloadId,
        type: PayloadType.text,
        richContent: original.plainText,
        plainText: original.plainText,
        fragments: [],
        source: original.source,
        createdAt: original.createdAt,
        expireAt: original.expireAt,
        metadata: {...original.metadata, 'downgraded': true},
      );
    }
    return original;
  }

  /// 极端降级：仅保留纯文本
  ClipboardPayload _stripToPlainText(ClipboardPayload original) {
    return ClipboardPayload(
      payloadId: original.payloadId,
      type: PayloadType.text,
      richContent: original.plainText,
      plainText: original.plainText,
      fragments: [],
      source: original.source,
      createdAt: original.createdAt,
      expireAt: original.expireAt,
      metadata: {...original.metadata, 'force_downgraded': true},
    );
  }
}

/// 模块处理器接口
abstract class ModuleHandler {

  /// 内容预处理/格式转换

  /// 模块路由地址

}
```

```swift
// AppDelegate.swift

import UIKit
import Social

class ShareBridge: NSObject, FlutterPlugin {
  static func register(with registrar: FlutterPluginRegistrar) {
    let channel = FlutterMethodChannel(
      name: "primetop/share",
      binaryMessenger: registrar.messenger()
    )
    instance.channel = channel
    registrar.addMethodCallDelegate(instance, channel: channel)
  }

  func handle(_ call: FlutterMethodCall, result: @escaping FlutterResult) {
    switch call.method {
    case "share":
      let args = call.arguments as! [String: Any]
      sharePayload(args, result: result)
    case "shareImage":
      let args = call.arguments as! [String: Any]
      shareImage(args, result: result)
    default:
      result(FlutterMethodNotImplemented)
    }
  }

  private func sharePayload(_ args: [String: Any], result: @escaping FlutterResult) {
    let plainText = args["plainText"] as? String ?? ""
    let html = args["html"] as? String
    let imageData = args["imageData"] as? FlutterStandardTypedArray

    var items: [Any] = [plainText]
    if let html = html, let data = html.data(using: .utf8) {
      // NSAttributedString from HTML
      if let attrStr = try? NSAttributedString(
        data: data,
        options: [.documentType: NSAttributedString.DocumentType.html],
        documentAttributes: nil
      ) {
        items.append(attrStr)
      }
    }
    if let imageData = imageData {
      let image = UIImage(data: imageData.data)
      items.append(image!)
    }

    DispatchQueue.main.async {
      let activityVC = UIActivityViewController(
        activityItems: items,
        applicationActivities: nil
      )

      // iPad popover 支持
      if let popover = activityVC.popoverPresentationController {
        popover.sourceView = UIApplication.shared
          .connectedScenes
          .compactMap { ($0 as? UIWindowScene)?.windows.first }
          .first?.rootViewController?.view
        popover.sourceRect = CGRect(x: 200, y: 200, width: 100, height: 100)
      }

      UIApplication.shared
        .connectedScenes
        .compactMap { ($0 as? UIWindowScene)?.windows.first }
        .first?.rootViewController?
        .present(activityVC, animated: true)

      result(true)
    }
  }
```

```kotlin
// ShareBridgePlugin.kt

class ShareBridgePlugin : FlutterPlugin, MethodCallHandler {
    private lateinit var channel: MethodChannel

    override fun onAttachedToEngine(binding: FlutterPlugin.FlutterPluginBinding) {
        channel = MethodChannel(binding.binaryMessenger, "primetop/share")
        channel.setMethodCallHandler(this)
        context = binding.applicationContext
    }

    override fun onMethodCall(call: MethodCall, result: MethodChannel.Result) {
        when (call.method) {
            "share" -> {
                val args = call.arguments as Map<String, Any>
                shareText(result, args)
            }
            "shareImage" -> {
                val args = call.arguments as Map<String, Any>
                shareImage(result, args)
            }
            else -> result.notImplemented()
        }
    }

    private fun shareText(result: MethodChannel.Result, args: Map<String, Any>) {
        val plainText = args["plainText"] as? String ?: ""
        val html = args["html"] as? String

        val sendIntent = Intent(Intent.ACTION_SEND).apply {
            type = "text/plain"
            putExtra(Intent.EXTRA_TEXT, plainText)
            if (html != null) {
                putExtra(Intent.EXTRA_HTML_TEXT, html)
            }
        }

        val chooser = Intent.createChooser(sendIntent, "分享到").apply {
            addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
        }

        context.startActivity(chooser)
        result.success(true)
    }

    private fun shareImage(result: MethodChannel.Result, args: Map<String, Any>) {
        val imageBytes = args["imageData"] as ByteArray
        val caption = args["caption"] as? String ?: ""

        // 写入临时文件并通过 FileProvider 共享
        val tempFile = File(context.cacheDir, "share_${System.currentTimeMillis()}.png")
        tempFile.writeBytes(imageBytes)

        val uri = FileProvider.getUriForFile(
            context,
            "${context.packageName}.fileprovider",
            tempFile
        )

        val shareIntent = Intent(Intent.ACTION_SEND).apply {
            type = "image/png"
            putExtra(Intent.EXTRA_STREAM, uri)
            putExtra(Intent.EXTRA_TEXT, caption)
            addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
        }

        val chooser = Intent.createChooser(shareIntent, "分享图片到").apply {
            addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
        }

        context.startActivity(chooser)
        result.success(true)
    }
}
```

## 7. 草稿箱与未送达管理

```dart
class _DraftBox {
  static final _DraftBox instance = _DraftBox._();
  _DraftBox._();

  final _box = Hive.box('clipboard_draft_box');

  /// 保存未送达的转发
  Future<void> save({
    required String targetModuleId,
    required ClipboardPayload payload,
  }) async {
    final key = '${targetModuleId}_${payload.payloadId}';
    await _box.put(key, {
      'targetModuleId': targetModuleId,
      'payload': payload.toJson(),
      'savedAt': DateTime.now().millisecondsSinceEpoch,
    });
  }

  /// 恢复所有待处理的转发
  Future<void> restorePending() async {
    final now = DateTime.now().millisecondsSinceEpoch;
    final expired = <String>[];

    for (final key in _box.keys) {
      final entry = _box.get(key) as Map;
      final savedAt = entry['savedAt'] as int;

      // 24小时过期
      if (now - savedAt > 86400000) {
        expired.add(key as String);
        continue;
      }

      // 尝试重新发送
      final payload = ClipboardPayload.fromJson(
        Map<String, dynamic>.from(entry['payload'] as Map),
      );
      final target = entry['targetModuleId'] as String;

      try {
        await ContentTransferRouter().transfer(
          payload: payload,
          targetModuleId: target,
          navigateAfter: false,
        );
        expired.add(key);
      } catch (_) {
        // 仍然失败，保留
      }
    }

    for (final key in expired) {
      await _box.delete(key);
    }
  }
}
```

## 8. API 接口设计

### 8.1 客户端内部接口

本引擎为纯客户端基础设施，不涉及服务端 API，但提供以下 Dart API：

| 方法 | 说明 | 参数 |
| --- | --- | --- |
| `ClipboardService.copy(payload)` | 复制内容到系统剪贴板 | `ClipboardPayload` |
| `ClipboardService.paste()` | 从系统剪贴板读取并解析 | → `Future<ClipboardPayload?>` |
| `ContentTransferRouter.transfer(...)` | 跨模块转发 | payload, targetModuleId |

## 9. 错误处理

### 9.1 错误码定义

| 错误码 | 说明 | 处理策略 |
| --- | --- | --- |
| `MODULE_NOT_FOUND` | 目标模块未注册 | 提示用户"功能暂不可用" |
| `TYPE_MISMATCH` | 目标模块不支持该内容类型 | 尝试降级，降级失败则提示 |
| `TRANSFORM_FAILED` | 格式转换失败 | 降级为纯文本，提示"部分格式可能丢失" |
| `DISPATCH_TIMEOUT` | 模块响应超时 | 存入草稿箱，下次启动重试 |
| `CLIPBOARD_READ_DENIED` | 系统剪贴板读取被拒绝（权限问题） | 静默忽略，不提示 |
| `SHARE_FAILED` | 系统分享调用失败 | Toast 提示"分享失败，请重试" |
| `PAYLOAD_TOO_LARGE` | 内容超过大小限制（1MB） | 提示"内容过长，请截取后再操作" |
| `IMAGE_RENDER_FAILED` | 公式/图表渲染为图片失败 | 降级分享纯文本 |

### 9.2 全局错误处理

```dart
class ClipboardErrorHandler {
  static void handleError(Object error, StackTrace stack, {
    required BuildContext? context,
  }) {
    if (error is ClipboardException) {
      switch (error.code) {
        case 'MODULE_NOT_FOUND':
          _showToast(context, '该功能暂不可用');
          break;
        case 'TYPE_MISMATCH':
          _showToast(context, '该内容类型不支持此操作');
          break;
        case 'PAYLOAD_TOO_LARGE':
          _showToast(context, '内容过长，请截取后再操作');
          break;
        case 'SHARE_FAILED':
          _showToast(context, '分享失败，请重试');
          break;
        default:
          _showToast(context, '操作失败，请重试');
      }
    } else {
      // 未知异常：记录日志但不暴露给用户
      Logger.error('Clipboard transfer error', error, stack);
      _showToast(context, '操作失败');
    }
  }
}

class ClipboardException implements Exception {
  final String code;
  final String message;
  ClipboardException(this.code, this.message);

  @override
  String toString() => 'ClipboardException($code): $message';
}
```

## 10. 安全与隐私

### 10.1 安全策略

| 风险 | 应对措施 |
| --- | --- |
| 剪贴板敏感信息泄露 | 剪贴板内容仅驻留内存，不写入持久化日志；Payload JSON 中手机号/邮箱自动脱敏 |
| 外部应用读取内部格式 | PrimeTop 内部 Payload JSON 使用自定义 MIME type (`application/x-primetop-payload`)，仅 App 内可识别 |
| 跨用户数据泄露 | 多账号切换时自动清空草稿箱和剪贴板历史 |
| 恶意内容注入 | 外部粘贴内容经过 Sniffer 的安全检查，执行 XSS 过滤后渲染 |
| 图片隐私 | 分享图片自动去除 EXIF 中的 GPS 信息 |

### 10.2 内容脱敏

```dart
class ContentSanitizer {
  static String sanitize(String text) {
    // 手机号脱敏
    text = text.replaceAllMapped(
      RegExp(r'1[3-9]\d{9}'),
      (m) => '${m.group(0)!.substring(0, 3)}****${m.group(0)!.substring(7)}',
    );

    // 邮箱脱敏
    text = text.replaceAllMapped(
      RegExp(r'[\w.+-]+@[\w-]+\.[\w.-]+'),
      (m) {
        final email = m.group(0)!;
        final atIdx = email.indexOf('@');
        return '${email[0]}***${email.substring(atIdx)}';
      },
    );

    // 身份证号脱敏
    text = text.replaceAllMapped(
      RegExp(r'\d{17}[\dXx]'),
      (m) => '${m.group(0)!.substring(0, 6)}********${m.group(0)!.substring(14)}',
    );

    return text;
  }
}
```

## 11. 性能优化

### 11.1 性能指标

| 指标 | 目标 |
| --- | --- |
| 复制操作响应 | < 50ms（纯文本）/ < 200ms（含公式渲染） |
| 转发到模块 | < 100ms（不含页面跳转动画） |
| 剪贴板感知延迟 | < 300ms（前台恢复后到弹出建议） |
| 公式转 PNG | < 500ms（单个公式） |
| 内容大小限制 | 单次 Payload ≤ 1MB |

### 11.2 优化策略

1. **公式渲染缓存**：同一 LaTeX 字符串的 PNG 渲染结果缓存到 LRU（最大 100 项，每项 200KB）
2. **片段提取惰性执行**：`_extractFragments` 仅在需要时执行（粘贴到特定模块时才解析）
3. **Sniffer 频控**：30 秒内同一内容不重复提示，使用快速 hash（CRC32）而非全量比较
4. **草稿箱惰性恢复**：仅在对应模块首次打开时检查并恢复
5. **Share 延迟初始化**：ShareBridge 在首次调用时才建立 MethodChannel

```dart
/// 公式渲染缓存
class FormulaRenderCache {
  static final _cache = LRU<String, Uint8List>(maxSize: 100);

  static Future<Uint8List> render(String latex) async {
    final cached = _cache.get(latex);
    if (cached != null) return cached;

    final png = await RichContentCodec.formulaToPng(latex);
    _cache.put(latex, png);
    return png;
  }
}
```
