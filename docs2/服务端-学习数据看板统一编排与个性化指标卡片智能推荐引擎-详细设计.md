# 服务端-学习数据看板统一编排与个性化指标卡片智能推荐引擎-详细设计

## 1. 概述

### 1.1 功能定位

学习数据看板统一编排引擎是 PrimeTop 平台**数据展示层的核心编排中枢**，负责从多个后端分析服务（学情分析、错题统计、学习规划、会员服务等）聚合数据，组装为结构化的看板卡片数据模型，按用户角色（学生、家长、教师、管理员）和个性化偏好，动态生成首页工作台和学习报告页所需的看板数据。

### 1.2 与现有模块的边界

| 现有模块 | 职责 | 与本引擎的关系 |
| --- | --- | --- |
| 首页内容卡片推荐与聚合编排服务 | 推荐**学习内容**卡片（课程、任务、练习） | 本引擎聚焦**数据指标**卡片，不负责内容推荐 |
| 学习数据实时聚合与统计预计算引擎 | 底层统计计算（时长、正确率等） | 本引擎是其上游消费方，调用预计算结果组装卡片 |
| 学习数据可视化与图表渲染引擎 | 客户端图表**渲染**（折线图、雷达图等） | 本引擎为渲染层提供标准化的**数据契约** |
| 统一指标中心与数据语义查询引擎 | 指标定义和语义查询 | 本引擎消费指标中心的标准化指标 |
| 管理后台-学情数据分析与教育运营驾驶舱 | 管理后台看板 | 本引擎服务学生端/家长端/教师端，非管理后台 |

### 1.3 设计目标

1. **统一数据出口**：为客户端提供一站式看板数据 API，避免客户端多次 RPC 调用
2. **角色感知**：同一指标，不同角色看到不同粒度和口径的数据
3. **个性化编排**：根据用户偏好和使用习惯，动态调整卡片种类和排序
4. **高性能**：看板首屏数据响应 < 300ms（P95）
5. **可扩展**：新增卡片类型不需修改编排核心逻辑

---

## 2. 核心概念定义

### 2.1 卡片（Card）

看板的最小展示单元。每张卡片包含：
- 唯一卡片类型标识
- 标题、副标题、图标
- 指标数据体（数值、趋势、对比）
- 可选的图表数据（折线、柱状、雷达等）
- 跳转链接（点击卡片后进入的详情页）
- 展示条件（是否对该用户可见）

### 2.2 看板布局（Dashboard Layout）

一组卡片的有序集合，按用户角色和场景定义默认排列方式。

### 2.3 卡片数据提供者（Card Provider）

后端微服务中负责为特定卡片类型生产数据的组件。每个卡片类型对应一个 Provider 实现。

### 2.4 编排策略（Orchestration Strategy）

决定哪些卡片出现在看板上、以什么顺序出现、使用什么数据参数查询的策略。

## 3. 数据结构定义

### 3.1 卡片类型注册表 `card_type_registry`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| card_type_id | VARCHAR(64) PK | 卡片类型唯一标识，如 `study_duration_summary` |
| card_name | VARCHAR(128) | 卡片中文名，如"学习时长总览" |
| card_category | VARCHAR(32) | 分类：`metric`/`progress`/`alert`/`recommendation`/`comparison` |
| description | TEXT | 卡片描述 |
| default_size | VARCHAR(16) | 卡片尺寸：`small`/`medium`/`large`/`wide` |
| default_priority | INT | 默认展示优先级（1-100，越大越靠前） |
| applicable_roles | JSON | 适用角色列表 `["student", "parent", "teacher"]` |
| applicable_stages | JSON | 适用学段 `["kindergarten", "primary", "junior", "senior"]` |
| min_member_tier | VARCHAR(16) | 最低会员等级要求：`free`/`basic`/`premium` |
| data_source | VARCHAR(64) | 数据来源服务标识 |
| cache_ttl_seconds | INT | 卡片数据缓存有效期（秒） |
| refresh_strategy | VARCHAR(32) | 刷新策略：`realtime`/`hourly`/`daily`/`on_demand` |
| display_conditions | JSON | 展示条件表达式（见 3.6） |
| status | VARCHAR(16) | 状态：`active`/`deprecated`/`beta` |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**SQL 建表语句：**

```sql
CREATE TABLE card_type_registry (
    card_type_id       VARCHAR(64)   NOT NULL COMMENT '卡片类型唯一标识',
    card_name          VARCHAR(128)  NOT NULL COMMENT '卡片中文名',
    card_category      VARCHAR(32)   NOT NULL COMMENT '卡片分类',
    description        TEXT          NULL     COMMENT '卡片描述',
    default_size       VARCHAR(16)   NOT NULL DEFAULT 'medium' COMMENT '卡片尺寸',
    default_priority   INT           NOT NULL DEFAULT 50 COMMENT '默认优先级',
    applicable_roles   JSON          NOT NULL COMMENT '适用角色列表',
    applicable_stages  JSON          NOT NULL COMMENT '适用学段列表',
    min_member_tier    VARCHAR(16)   NOT NULL DEFAULT 'free' COMMENT '最低会员等级',
    data_source        VARCHAR(64)   NOT NULL COMMENT '数据来源服务',
    cache_ttl_seconds  INT           NOT NULL DEFAULT 300 COMMENT '缓存有效期(秒)',
    refresh_strategy   VARCHAR(32)   NOT NULL DEFAULT 'hourly' COMMENT '刷新策略',
    display_conditions JSON          NULL     COMMENT '展示条件表达式',
    status             VARCHAR(16)   NOT NULL DEFAULT 'active' COMMENT '状态',
    created_at         DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at         DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (card_type_id),
    INDEX idx_status_category (status, card_category),
    INDEX idx_data_source (data_source)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='卡片类型注册表';
```

| card_type_id | VARCHAR(64) | 卡片类型 ID |

| is_visible | TINYINT(1) | 是否可见（用户可隐藏卡片） |
| custom_config | JSON | 卡片个性化配置（如时间范围、科目筛选） |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

```sql
CREATE TABLE user_dashboard_config (
    id                 BIGINT        NOT NULL AUTO_INCREMENT,
    user_id            BIGINT        NOT NULL COMMENT '用户ID',
    role_type          VARCHAR(16)   NOT NULL COMMENT '角色类型',
    context_user_id    BIGINT        NULL     COMMENT '上下文用户ID(家长→孩子/教师→班级)',
    dashboard_scene    VARCHAR(32)   NOT NULL DEFAULT 'home' COMMENT '看板场景',
    card_type_id       VARCHAR(64)   NOT NULL COMMENT '卡片类型ID',
    display_order      INT           NOT NULL DEFAULT 0 COMMENT '展示顺序',
    is_visible         TINYINT(1)    NOT NULL DEFAULT 1 COMMENT '是否可见',
    custom_config      JSON          NULL     COMMENT '卡片个性化配置',
    created_at         DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at         DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE INDEX uk_user_scene_card (user_id, dashboard_scene, card_type_id, context_user_id),
    INDEX idx_user_scene (user_id, dashboard_scene, is_visible)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户看板配置';
```

### 3.4 卡片数据统一响应模型

```typescript
/**
 * 看板卡片统一数据模型
 */
interface DashboardCard {
  /** 卡片类型标识 */
  cardTypeId: string;
  /** 卡片展示名称 */
  cardName: string;
  /** 卡片分类 */
  cardCategory: 'metric' | 'progress' | 'alert' | 'recommendation' | 'comparison';
  /** 卡片尺寸 */
  cardSize: 'small' | 'medium' | 'large' | 'wide';
  /** 展示顺序 */
  displayOrder: number;
  /** 卡片标题（动态生成，含日期范围等上下文） */
  title: string;
  /** 副标题 */
  subtitle?: string;
  /** 指标数据 */
  metrics: CardMetric[];
  /** 图表数据（可选） */
  chart?: CardChart;
  /** AI 洞察文本（可选） */
  insight?: string;
  /** 操作行为 */
  action?: CardAction;
  /** 卡片状态 */
  status: 'loading' | 'ready' | 'error' | 'empty' | 'locked';
  /** 错误信息（status=error 时） */
  errorMessage?: string;
  /** 数据生成时间 */
  generatedAt: string;
}

/** 指标项 */
interface CardMetric {
  /** 指标标识 */
  metricId: string;
  /** 指标名称 */
  label: string;
  /** 指标值 */
  value: number | string;
  /** 单位 */
  unit?: string;
  /** 格式化后的展示值 */
  displayValue: string;
  /** 趋势信息 */
  trend?: {
    direction: 'up' | 'down' | 'flat';
    percentage: number;
    comparedTo: string;
  };
  /** 指标等级 */
  level?: 'excellent' | 'good' | 'normal' | 'warning' | 'danger';
}

/** 图表数据 */
interface CardChart {
  type: 'line' | 'bar' | 'radar' | 'pie' | 'heatmap' | 'progress_ring';
  xAxis?: string[];
  series: CardChartSeries[];
}

interface CardChartSeries {
  name: string;
  data: (number | null)[];
  color?: string;
}

/** 卡片操作 */
interface CardAction {
  text: string;
  route: string;
  params?: Record<string, string>;
}

/** 看板响应 */
interface DashboardResponse {
  /** 看板场景 */
  scene: string;
  /** 用户角色 */
  roleType: string;
  /** 上下文用户（家长看孩子时为孩子的信息） */
  contextUserInfo?: {
    userId: number;
    nickname: string;
    gradeName: string;
    avatarUrl?: string;
  };
  /** 卡片列表 */
  cards: DashboardCard[];
  /** 看板元信息 */
  meta: {
    /** 服务端耗时(ms) */
    elapsedMs: number;
    /** 是否来自缓存 */
    fromCache: boolean;
    /** 建议下次刷新时间 */
    nextRefreshAt: string;
  };
}
```

### 3.5 卡片展示条件表达式

```typescript
/**
 * 展示条件 DSL
 * 用于在运行时判断某卡片是否应对特定用户展示
 */
interface DisplayCondition {
  /** 条件组合方式 */
  logic?: 'AND' | 'OR';
  /** 条件列表（嵌套） */
  conditions?: DisplayCondition[];
  /** 单个条件 */
  field?: string;       // 如 'student.grade', 'member.tier', 'stats.total_questions'
  operator?: string;    // 'eq', 'ne', 'gt', 'gte', 'lt', 'lte', 'in', 'not_in', 'between'
  value?: any;          // 比较值
}

// 示例：仅当学生为初中及以上且会员等级≥basic时展示
{
  "logic": "AND",
  "conditions": [
    {
      "field": "student.stage",
      "operator": "in",
      "value": ["junior", "senior"]
    },
    {
      "field": "member.tier",
      "operator": "gte",
      "value": "basic"
    }
  ]
}
```

```java
                    .sum();

                    .metricId("total_minutes")
                    .label("总时长")

                    .trend(Trend.builder()
                        .direction(trendPercentage > 0 ? "up" : trendPercentage < 0 ? "down" : "flat")
                        .percentage(Math.abs(trendPercentage))
                        .comparedTo("上周")
                        .build())
                    .level(evaluateDurationLevel(totalMinutes, ctx.getStudentStage()))
                    .build();
                
                // 5. 构建图表数据
                CardChart chart = CardChart.builder()
                    .type("bar")
                    .xAxis(getWeekDayLabels(dateRange, ctx.getTimezone()))
                    .series(List.of(CardChartSeries.builder()
                        .name("学习时长(分钟)")
                        .data(dailyData.stream()
                            .map(DailyStudyDuration::getMinutes)
                            .map(m -> (m == 0 ? null : m))  // 0转为null，不显示空柱
                            .collect(Collectors.toList()))
                        .build()))
                    .build();
                
                // 6. 生成洞察文本
                String insight = generateInsight(totalMinutes, trendPercentage, ctx.getStudentStage());
                
                return CardData.builder()
                    .cardTypeId(CARD_TYPE_ID)
                    .title("本周学习时长")
                    .subtitle(formatDateRange(dateRange))
                    .metrics(List.of(totalMetric))
                    .chart(chart)
                    .insight(insight)
                    .action(CardAction.builder()
                        .text("查看详情")
                        .route("/study/report/duration")
                        .build())
                    .status("ready")
                    .generatedAt(LocalDateTime.now())
                    .build();
                    
            } catch (Exception e) {
                log.error("Failed to fetch study duration card for student {}", ctx.getStudentId(), e);
                return CardData.error(CARD_TYPE_ID, "数据加载失败，请稍后重试");
            }
        });
    }
    
    /**
     * 根据学段评估学习时长等级
     */
    private String evaluateDurationLevel(int weeklyMinutes, String stage) {
        // 各学段每周建议学习时长阈值（分钟）
        int[][] thresholds = {
            {"primary", 300, 500},   // 小学: 5h-8.3h
            {"junior",  450, 700},   // 初中: 7.5h-11.7h
            {"senior",  600, 900}    // 高中: 10h-15h
        };
        // 返回 excellent / good / normal / warning
        // ...省略具体逻辑
        return "good";
    }
    
    private String formatDuration(int minutes) {
        int hours = minutes / 60;
        int mins = minutes % 60;
        if (hours > 0 && mins > 0) return hours + "小时" + mins + "分钟";
        if (hours > 0) return hours + "小时";
        return mins + "分钟";
    }
    
    private double calculateTrend(int current, int previous) {
        if (previous == 0) return current > 0 ? 100.0 : 0.0;
        return BigDecimal.valueOf((current - previous) * 100.0 / previous)
            .setScale(1, RoundingMode.HALF_UP)
            .doubleValue();
    }
    
    private String generateInsight(int minutes, double trend, String stage) {
        if (trend > 20) return "学习时长显著提升，注意劳逸结合！";
        if (trend > 0) return "本周学习时长比上周增加了" + trend + "%，保持良好节奏！";
        if (trend == 0) return "学习时长与上周持平，尝试增加一些练习吧。";
        return "本周学习时长有所下降，调整一下学习计划？";
    }
}
```

### 5.4 编排引擎核心逻辑

```java
@Service
@Slf4j
public class DashboardOrchestrationEngine {
    
    @Resource
    private CardRegistryManager cardRegistry;
    
    @Resource
    private UserDashboardConfigService configService;
    
    @Resource
    private CardProviderCoordinator providerCoordinator;
    
    @Resource
    private ConditionEvaluator conditionEvaluator;
    
    @Resource
    private DashboardCacheManager cacheManager;
    
    /**
     * 编排看板数据 - 核心入口
     */
    public DashboardResponse orchestrate(DashboardRequest request) {
        long startTime = System.currentTimeMillis();
        
        // 1. 构建上下文
        CardDataContext context = buildContext(request);
        
        // 2. 获取用户看板配置（哪些卡片可见、排序）
        List<UserCardConfig> userCardConfigs = configService
            .getUserDashboardConfig(request.getUserId(), request.getScene(), request.getContextUserId());
        
        // 3. 如果用户没有自定义配置，使用默认配置
        if (userCardConfigs.isEmpty()) {
            userCardConfigs = configService.getDefaultDashboardConfig(
                context.getRoleType(), 
                context.getStudentStage(), 
                request.getScene()
            );
        }
        
        // 4. 过滤：角色/学段/会员等级/展示条件
        List<UserCardConfig> applicableCards = userCardConfigs.stream()
            .filter(cfg -> isCardApplicable(cfg.getCardTypeId(), context))
            .filter(cfg -> cfg.getIsVisible())
            .sorted(Comparator.comparing(UserCardConfig::getDisplayOrder))
            .collect(Collectors.toList());
        
        // 5. 并行获取卡片数据（带超时）
        long fetchTimeoutMs = 2000;  // 单卡片最大等待2秒
        List<CardData> cardDataList = providerCoordinator
            .fetchCardsParallel(applicableCards, context, fetchTimeoutMs);
        
        // 6. 过滤空状态卡片（可选：某些空状态卡片不展示）
        cardDataList = filterEmptyCards(cardDataList);
        
        // 7. 构建响应
        long elapsed = System.currentTimeMillis() - startTime;
        
        return DashboardResponse.builder()
            .scene(request.getScene())
            .roleType(context.getRoleType())
            .contextUserInfo(getContextUserInfo(context))
            .cards(cardDataList)
            .meta(DashboardMeta.builder()
                .elapsedMs(elapsed)
                .fromCache(cardDataList.stream().anyMatch(cd -> cd.isFromCache()))
                .nextRefreshAt(calculateNextRefresh(cardDataList))
                .build())
            .build();
    }
    
    /**
     * 判断卡片是否适用于当前用户上下文
     */
    private boolean isCardApplicable(String cardTypeId, CardDataContext context) {
        CardTypeRegistry registry = cardRegistry.getCardType(cardTypeId);
        if (registry == null || !"active".equals(registry.getStatus())) {
            return false;
        }
        
        // 角色匹配
        if (!registry.getApplicableRoles().contains(context.getRoleType())) {
            return false;
        }
        
        // 学段匹配
        if (!registry.getApplicableStages().contains(context.getStudentStage())) {
            return false;
        }
        
        // 会员等级检查
        if (!MemberTierChecker.check(context.getMemberTier(), registry.getMinMemberTier())) {
            return false;
        }
        
        // 展示条件评估
        if (registry.getDisplayConditions() != null) {
            return conditionEvaluator.evaluate(registry.getDisplayConditions(), context);
        }
        
        return true;
    }
}
```

### 5.5 并行调度协调器

```java
@Component
@Slf4j
public class CardProviderCoordinator {
    
    @Resource
    private Map<String, CardProvider> providerMap;  // Spring 注入所有 CardProvider 实现
    
    @Resource
    private DashboardCacheManager cacheManager;
    
    private final ExecutorService cardFetchExecutor;
    
    public CardProviderCoordinator() {
        // 专用线程池：核心10线程，最大50线程，队列200
        this.cardFetchExecutor = new ThreadPoolExecutor(
            10, 50, 60L, TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(200),
            new ThreadFactoryBuilder()
                .setNameFormat("card-fetch-%d")
                .setDaemon(true)
                .build(),
            new ThreadPoolExecutor.CallerRunsPolicy()
        );
    }
    
    /**
     * 并行获取多张卡片数据
     * 使用 CompletableFuture.allOf 控制总超时
     */
    public List<CardData> fetchCardsParallel(
            List<UserCardConfig> cardConfigs, 
            CardDataContext context,
            long timeoutMs) {
        
        // 1. 检查缓存
        Map<String, CardData> cachedResults = new ConcurrentHashMap<>();
        List<UserCardConfig> uncachedConfigs = new ArrayList<>();
        
        for (UserCardConfig cfg : cardConfigs) {
            if (!context.isForceRefresh()) {
                CardData cached = cacheManager.get(context.getStudentId(), 
                    context.getContextUserId(), cfg.getCardTypeId());
                if (cached != null) {
                    cachedResults.put(cfg.getCardTypeId(), cached);
                    continue;
                }
            }
            uncachedConfigs.add(cfg);
        }
        
        // 2. 并行获取未缓存卡片
        Map<String, CompletableFuture<CardData>> futures = new LinkedHashMap<>();
        
        for (UserCardConfig cfg : uncachedConfigs) {
            CardProvider provider = providerMap.get(cfg.getCardTypeId());
            if (provider == null) {
                log.warn("No provider found for card type: {}", cfg.getCardTypeId());
                futures.put(cfg.getCardTypeId(), CompletableFuture.completedFuture(
                    CardData.error(cfg.getCardTypeId(), "卡片提供者未注册")));
                continue;
            }
            
            // 合并用户自定义配置到上下文
            CardDataContext ctxWithConfig = context.toBuilder()
                .customConfig(cfg.getCustomConfig())
                .build();
            
            CompletableFuture<CardData> future = provider
                .fetchCardData(ctxWithConfig)
                .orTimeout(timeoutMs, TimeUnit.MILLISECONDS)
                .exceptionally(ex -> {
                    log.warn("Card fetch timeout or error: {}", cfg.getCardTypeId(), ex);
                    return CardData.error(cfg.getCardTypeId(), "数据加载超时");
                });
            
            futures.put(cfg.getCardTypeId(), future);
        }
        
        // 3. 等待全部完成
        CompletableFuture<Void> allFutures = CompletableFuture.allOf(
            futures.values().toArray(new CompletableFuture[0])
        );
        
        try {
            allFutures.get(timeoutMs + 500, TimeUnit.MILLISECONDS);
        } catch (TimeoutException e) {
            log.warn("Dashboard fetch partial timeout after {}ms", timeoutMs + 500);
        } catch (Exception e) {
            log.error("Dashboard fetch error", e);
        }
        
        // 4. 收集结果
        List<CardData> results = new ArrayList<>();
        
        for (UserCardConfig cfg : cardConfigs) {
            String cardTypeId = cfg.getCardTypeId();
            
            if (cachedResults.containsKey(cardTypeId)) {
                CardData cd = cachedResults.get(cardTypeId);
                cd.setFromCache(true);
                cd.setDisplayOrder(cfg.getDisplayOrder());
                results.add(cd);
            } else if (futures.containsKey(cardTypeId)) {
                CompletableFuture<CardData> future = futures.get(cardTypeId);
                CardData cd;
                if (future.isDone()) {
                    try {
                        cd = future.get();
                        if ("ready".equals(cd.getStatus())) {
                            cacheManager.set(context.getStudentId(),
                                context.getContextUserId(), cardTypeId, cd,
                                cardRegistry.getCacheTtl(cardTypeId));
                        }
                    } catch (Exception e) {
                        cd = CardData.error(cardTypeId, "数据加载失败");
                    }
                } else {
                    cd = CardData.error(cardTypeId, "数据加载超时");
                }
                cd.setDisplayOrder(cfg.getDisplayOrder());
                results.add(cd);
            }
        }
        
        return results;
    }
}
```

```java
@Service
@Slf4j
public class DashboardCacheManager {
    
    @Resource
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String KEY_PREFIX = "card_data:";
    private static final String LOCK_PREFIX = "card_lock:";
    
    public CardData get(Long studentId, Long contextUserId, String cardTypeId) {
        String key = buildKey(studentId, contextUserId, cardTypeId);
        Object cached = redisTemplate.opsForValue().get(key);
        if (cached instanceof CardData) {
            return (CardData) cached;
        }
        return null;
    }
    
    public void set(Long studentId, Long contextUserId, String cardTypeId, 
                    CardData data, int ttlSeconds) {
        String key = buildKey(studentId, contextUserId, cardTypeId);
        redisTemplate.opsForValue().set(key, data, ttlSeconds, TimeUnit.SECONDS);
    }
    
    /**
     * 使用分布式锁防止缓存击穿
     */
    public CardData getWithLock(Long studentId, Long contextUserId, String cardTypeId,
                                 Supplier<CardData> loader, int ttlSeconds) {
        String key = buildKey(studentId, contextUserId, cardTypeId);
        String lockKey = LOCK_PREFIX + key;
        
        CardData cached = get(studentId, contextUserId, cardTypeId);
        if (cached != null) return cached;
        
        Boolean locked = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "1", 10, TimeUnit.SECONDS);
        
        if (Boolean.TRUE.equals(locked)) {
            try {
                cached = get(studentId, contextUserId, cardTypeId);
                if (cached != null) return cached;
                CardData data = loader.get();
                set(studentId, contextUserId, cardTypeId, data, ttlSeconds);
                return data;
            } finally {
                redisTemplate.delete(lockKey);
            }
        } else {
            try { Thread.sleep(100); } catch (InterruptedException ignored) {}
            cached = get(studentId, contextUserId, cardTypeId);
            return cached != null ? cached : CardData.error(cardTypeId, "数据繁忙");
        }
    }
    
    public void invalidateUser(Long studentId) {
        Set<String> keys = redisTemplate.keys(KEY_PREFIX + studentId + ":*");
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }
    }
    
    public void invalidateCardType(String cardTypeId) {
        Set<String> keys = redisTemplate.keys(KEY_PREFIX + "*:" + cardTypeId + ":*");
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }
    }
    
    private String buildKey(Long studentId, Long contextUserId, String cardTypeId) {
        return KEY_PREFIX + studentId + ":" + 
               (contextUserId != null ? contextUserId : studentId) + ":" + 
               cardTypeId;
    }
}
```

```java
    public boolean evaluate(DisplayCondition condition, CardDataContext context) {
        if (condition == null) return true;
        
        if (condition.getConditions() != null && !condition.getConditions().isEmpty()) {
            String logic = condition.getLogic() != null ? condition.getLogic() : "AND";
            if ("AND".equals(logic)) {
                return condition.getConditions().stream()
                    .allMatch(sub -> evaluate(sub, context));
            } else {
                return condition.getConditions().stream()
                    .anyMatch(sub -> evaluate(sub, context));
            }
        }
        
        if (condition.getField() == null) return true;
        Object fieldValue = resolveFieldValue(condition.getField(), context);
        return compareValues(fieldValue, condition.getOperator(), condition.getValue());
    }
    
    private Object resolveFieldValue(String fieldPath, CardDataContext context) {
        Map<String, Object> contextData = userContextService.getContextData(context);
        String[] parts = fieldPath.split("\\.");
        Object current = contextData;
        for (String part : parts) {
            if (current instanceof Map) {
                current = ((Map<String, Object>) current).get(part);
            }
            if (current == null) return null;
        }
        return current;
    }
    
    @SuppressWarnings("unchecked")
    private boolean compareValues(Object fieldValue, String operator, Object targetValue) {
        if (fieldValue == null) return false;
        switch (operator) {
            case "eq": return fieldValue.equals(targetValue);
            case "ne": return !fieldValue.equals(targetValue);
            case "gt": return toDouble(fieldValue) > toDouble(targetValue);
            case "gte": return toDouble(fieldValue) >= toDouble(targetValue);
            case "lt": return toDouble(fieldValue) < toDouble(targetValue);
            case "lte": return toDouble(fieldValue) <= toDouble(targetValue);
            case "in": 
                if (targetValue instanceof Collection) {
                    return ((Collection<Object>) targetValue).contains(fieldValue);
                }
                return false;
            case "not_in":
                if (targetValue instanceof Collection) {
                    return !((Collection<Object>) targetValue).contains(fieldValue);
                }
                return true;
            case "between":
                if (targetValue instanceof List && ((List<?>) targetValue).size() == 2) {
                    double val = toDouble(fieldValue);
                    double min = toDouble(((List<?>) targetValue).get(0));
                    double max = toDouble(((List<?>) targetValue).get(1));
                    return val >= min && val <= max;
                }
                return false;
            default: return false;
        }
    }
    
    private double toDouble(Object value) {
        if (value instanceof Number) return ((Number) value).doubleValue();
        return Double.parseDouble(String.valueOf(value));
    }
}
```

## 7. 个性化推荐策略

### 7.1 卡片排序算法

综合考虑三个因素：用户自定义顺序（60%）、场景动态优先级（25%）、智能推荐分（15%）。

```java
@Service
public class CardRankingService {
    
    public List<DashboardCard> rankCards(List<DashboardCard> cards, 
                                          CardDataContext context,
                                          UserBehaviorProfile behavior) {
        return cards.stream()
            .map(card -> {
                double score = calculateScore(card, context, behavior);
                card.setRankScore(score);
                return card;
            })
            .sorted(Comparator.comparingDouble(DashboardCard::getRankScore).reversed())
            .collect(Collectors.toList());
    }
    
    private double calculateScore(DashboardCard card, CardDataContext ctx, 
                                   UserBehaviorProfile behavior) {
        double orderScore = 100.0 - (card.getDisplayOrder() * 5);
        double sceneScore = calculateSceneScore(card, ctx);
        double recommendScore = calculateRecommendScore(card, behavior);
        return orderScore * 0.6 + sceneScore * 0.25 + recommendScore * 0.15;
    }
    
    /**
     * 场景动态评分：早上优先任务，晚上优先总结
     */
    private double calculateSceneScore(DashboardCard card, CardDataContext ctx) {
        int hour = ctx.getRequestTime().getHour();
        if (hour >= 6 && hour < 9) {
            if ("today_task_progress".equals(card.getCardTypeId())) return 90;
            if ("mistake_review_reminder".equals(card.getCardTypeId())) return 80;
        }
        if (hour >= 19 && hour < 22) {
            if ("study_duration_summary".equals(card.getCardTypeId())) return 90;
            if ("accuracy_trend".equals(card.getCardTypeId())) return 85;
            if ("study_streak_calendar".equals(card.getCardTypeId())) return 80;
        }
        return 50;
    }
    
    private double calculateRecommendScore(DashboardCard card, UserBehaviorProfile behavior) {
        Double clickRate = behavior.getCardClickRate(card.getCardTypeId());
        if (clickRate != null) return clickRate * 100;
        return 50;
    }
}
```

```java
@Service
public class DashboardFallbackService {
    
    public CardData fallback(String cardTypeId, Throwable error) {
        // 1. 尝试返回过期缓存
        CardData stale = cacheManager.getStale(cardTypeId);
        if (stale != null) {
            stale.setSubtitle("数据可能不是最新");
            return stale;
        }
        // 2. 返回友好错误卡片
        return CardData.builder()
            .cardTypeId(cardTypeId)
            .status("error")
            .errorMessage(error instanceof TimeoutException 
                ? "数据加载超时，请下拉刷新" : "数据暂时不可用")
            .action(CardAction.builder()
                .text("重试")
                .route("refresh://card/" + cardTypeId)
                .build())
            .generatedAt(LocalDateTime.now())
            .build();
    }
}
```

## 15. 总结

本设计定义了 PrimeTop 平台学习数据看板统一编排引擎的完整技术方案，核心价值：

1. **统一数据出口**：客户端一次 API 调用获取全部看板数据
2. **角色感知编排**：学生、家长、教师看到不同维度和粒度的数据
3. **插件化扩展**：新增卡片只需注册类型 + 实现 Provider，零侵入核心
4. **高性能保障**：并行获取 + 多级缓存 + 熔断降级，确保 < 300ms 响应
5. **个性化体验**：基于场景、时段、用户行为的智能卡片排序
6. **条件化展示**：DSL 表达式控制卡片可见性，避免无意义内容

该引擎是连接后端数据能力与前端用户体验的关键中间层。
