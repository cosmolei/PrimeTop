# 内容服务详细设计

## 1. 概述

### 1.1 模块定位

内容服务（Content Service）是 PrimeTop 平台的核心基础服务之一，负责全学段、全学科学习内容的统一生产、组织、版本控制、发布授权与消费分发。它为 AI 辅导、同步课堂、考点梳理、错题服务、学习规划、作文辅导等业务模块提供标准化、可检索、可版本追踪的内容支撑。

内容服务不直接生成教学讲解，而是管理教学内容元数据、结构化资源、章节关系、知识点图谱和课程资源包，确保平台各业务模块在正确的时间向正确的学生交付正确的内容。

### 1.2 核心职责

| 职责域 | 说明 |
| --- | --- |
| 教材管理 | 维护学段、学科、年级、学期、教材版本、章节目录体系 |
| 知识点管理 | 维护知识点层级、前置依赖、学科属性、课标对齐信息 |
| 考点管理 | 维护考试大纲考点、高频考点、易错点、专题归属 |
| 课程资源管理 | 管理微课、讲义、习题集、图文、音频、视频等多媒体资源 |
| 内容版本控制 | 支持教材版本、资源版本、知识点版本的版本化与历史追溯 |
| 内容发布工作流 | 支持草稿、审核、已发布、下架、作废等状态流转 |
| 内容权限与授权 | 控制免费/会员/B端/年级可见范围，支持权益决策 |
| 内容分发接口 | 为客户端、AI 服务、推荐服务提供标准化的内容查询与聚合接口 |
| 内容变更通知 | 在内容更新时通知依赖服务（缓存失效、推荐重算、学习进度重校准） |

### 1.3 依赖关系

```text
内容服务
  ├─ 依赖：用户服务（学段、年级、教材版本）
  ├─ 依赖：权限服务（内容可见性、权益校验）
  ├─ 依赖：文件存储服务（多媒体资源文件）
  ├─ 依赖：消息服务（内容变更事件通知）
  ├─ 被依赖：AI 服务（知识点、教材上下文检索）
  ├─ 被依赖：题目服务（题目与知识点、章节关联）
  ├─ 被依赖：学习服务（学习进度与章节完成度）
  ├─ 被依赖：推荐服务（内容推荐与编排）
  └─ 被依赖：管理后台（内容运营与审核）
```

### 2.2 数据库表结构

#### 2.2.1 subject（学科表）

```sql
CREATE TABLE subject (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    code VARCHAR(32) NOT NULL COMMENT '学科编码',
    name VARCHAR(64) NOT NULL COMMENT '学科名称',
    phase VARCHAR(32) NOT NULL COMMENT '学段',
    display_order INT DEFAULT 0 COMMENT '展示顺序',
    icon_url VARCHAR(512) COMMENT '图标地址',
```

### 2.3 缓存策略

| 缓存对象 | 缓存键 | 过期时间 | 说明 |
| --- | --- | --- | --- |
| 教材版本列表 | `content:textbook:list:{phase}:{subject}:{grade}:{semester}` | 30 min | 按学段/学科/年级/学期缓存 |
| 章节树 | `content:chapter:tree:{textbookId}` | 30 min | 教材章节目录树 |
| 知识点详情 | `content:kp:{code}` | 60 min | 单个知识点元数据 |
| 考点详情 | `content:ep:{code}` | 60 min | 单个考点元数据 |
| 资源详情 | `content:resource:{resourceCode}:{version}` | 30 min | 课程资源详情 |
| 资源列表 | `content:resource:list:{subject}:{phase}:{grade}:{type}` | 15 min | 资源筛选列表（分页） |
| 学生可见内容 | `content:visible:{userId}:{subject}:{grade}` | 10 min | 已按权益过滤的内容视图 |

缓存失效采用发布订阅或消息队列事件：`content.changed:{entityType}:{entityId}`。

## 4. 业务逻辑

### 4.1 内容生命周期状态机

```text
                  ┌─────────────┐
                  │   DRAFT     │ 草稿
                  └──────┬──────┘
                         │ submit
                         ▼
                  ┌─────────────┐
                  │   PENDING   │ 待审核
                  └──────┬──────┘
        ┌────────────────┼────────────────┐
   reject│                │ approve        │
        ▼                ▼                │
   ┌─────────┐      ┌─────────────┐        │
   │  DRAFT  │      │  PUBLISHED  │ 已发布 │
   └─────────┘      └──────┬──────┘        │
                           │ deprecate     │
                           ▼               │
                      ┌─────────────┐     │
                      │ DEPRECATED  │ 已下架│
                      └──────┬──────┘     │
                             │              │
                             └──────────────┘
                                   publish
```

状态定义：

| 状态 | 说明 | 可执行操作 |
| --- | --- | --- |
| DRAFT | 草稿，仅运营人员可见 | 编辑、提交审核、删除 |
| PENDING | 待审核 | 审核通过、审核驳回 |
| PUBLISHED | 已发布，用户可见 | 下架、版本升级 |
| DEPRECATED | 已下架，历史用户仍可见但不再推荐 | 重新发布、删除 |

### 4.2 内容版本升级流程

教材版本或资源内容发生变更时，遵循版本升级流程：

1. **创建新版本**：基于旧版本创建新版本，复制元数据和关系，version + 1。
2. **内容编辑**：编辑新版本内容，旧版本保持 PUBLISHED 状态不变。
3. **审核发布**：新版本审核通过后，旧版本自动 DEPRECATED，新版本 PUBLISHED。
4. **影响评估**：发布前调用 教材修订内容变更检测与平台内容影响评估引擎 评估影响。
5. **变更通知**：发布成功后通过消息队列发送 `ContentVersionUpgraded` 事件，订阅方包括：
   - 学习服务：更新学生当前学习进度对应的新版本章节映射。
   - 推荐服务：重新计算推荐内容。
   - 缓存服务：失效相关缓存。
   - AI 服务：更新 RAG 知识库索引。

### 4.3 知识点关联图谱构建

知识点之间的关系包括：

| 关系类型 | 说明 | 用途 |
| --- | --- | --- |
| prerequisite | 前置依赖 | 学习路径规划、薄弱点归因 |
| related | 关联 | 推荐相关学习内容 |
| post | 后续延伸 | 进阶学习推荐 |
| belongs_to | 属于章节 | 教材目录关联 |
| maps_to | 映射考点 | 考试复习关联 |

关系更新时，需要同步到图数据库（如 Neo4j）或宽表索引，以支持知识图谱查询和路径规划。

### 4.4 内容可见性过滤

用户请求内容列表时，必须按以下规则过滤：

1. 内容状态必须为 PUBLISHED。
2. 内容适用学段、年级必须匹配用户档案。
3. 内容访问权限必须满足用户权益：
   - FREE：所有用户可见。
   - MEMBER：需会员权益。
   - PAID：需单独购买或解锁。
   - SCHOOL：仅限 B 端合作学校用户可见。
4. 家长端控制的学习范围限制（如家长仅允许数学、英语）。
5. 未成年人保护过滤（如内容适龄性）。

过滤逻辑统一封装在 `ContentVisibilityFilter` 中，优先在服务端过滤，减少客户端处理。

```java
@Service
@RequiredArgsConstructor
public class ContentService {

    private final TextbookVersionMapper textbookVersionMapper;
    private final ChapterMapper chapterMapper;
    private final KnowledgePointMapper knowledgePointMapper;
    private final LearningResourceMapper learningResourceMapper;
    private final ContentCacheManager contentCacheManager;
    private final ContentEventPublisher eventPublisher;
    private final ContentVisibilityFilter visibilityFilter;

    /**
     * 查询教材版本列表
     */
    public List<TextbookVersionDTO> listTextbooks(TextbookQuery query) {
        String cacheKey = buildTextbookListCacheKey(query);
        List<TextbookVersionDTO> cached = contentCacheManager.getTextbookList(cacheKey);
        if (cached != null) {
            return cached;
        }

        List<TextbookVersionDO> list = textbookVersionMapper.selectByCondition(
            query.getPhase(),
            query.getSubjectCode(),
            query.getGrade(),
            query.getSemester(),
            ContentStatus.PUBLISHED.name()
        );

        List<TextbookVersionDTO> result = list.stream()
            .map(this::convertToTextbookDTO)
            .collect(Collectors.toList());

        contentCacheManager.setTextbookList(cacheKey, result, Duration.ofMinutes(30));
        return result;
    }

    /**
     * 查询章节树
     */
    public List<ChapterTreeDTO> getChapterTree(Long textbookId) {
        String cacheKey = "content:chapter:tree:" + textbookId;
        List<ChapterTreeDTO> cached = contentCacheManager.getChapterTree(cacheKey);
        if (cached != null) {
            return cached;
        }

        List<ChapterDO> chapters = chapterMapper.selectByTextbookId(textbookId);
        List<ChapterTreeDTO> tree = buildChapterTree(chapters, 0L);

        contentCacheManager.setChapterTree(cacheKey, tree, Duration.ofMinutes(30));
        return tree;
    }

    private List<ChapterTreeDTO> buildChapterTree(List<ChapterDO> chapters, Long parentId) {
        return chapters.stream()
            .filter(c -> c.getParentId().equals(parentId))
            .sorted(Comparator.comparingInt(ChapterDO::getDisplayOrder))
            .map(c -> {
                ChapterTreeDTO dto = new ChapterTreeDTO();
                dto.setId(c.getId());
                dto.setCode(c.getCode());
                dto.setName(c.getName());
                dto.setLevel(c.getLevel());
                dto.setDisplayOrder(c.getDisplayOrder());
                dto.setKnowledgePointCodes(parseJsonList(c.getKnowledgePointCodes()));
                dto.setChildren(buildChapterTree(chapters, c.getId()));
                return dto;
            })
            .collect(Collectors.toList());
    }

    /**
     * 查询知识点详情
     */
    public KnowledgePointDTO getKnowledgePoint(String code) {
        String cacheKey = "content:kp:" + code;
        KnowledgePointDTO cached = contentCacheManager.getKnowledgePoint(cacheKey);
        if (cached != null) {
            return cached;
        }

        KnowledgePointDO kp = knowledgePointMapper.selectByCode(code);
        if (kp == null || !ContentStatus.PUBLISHED.name().equals(kp.getStatus())) {
            throw new ContentException(ContentErrorCode.KNOWLEDGE_POINT_NOT_FOUND);
        }

        KnowledgePointDTO dto = convertToKnowledgePointDTO(kp);
        contentCacheManager.setKnowledgePoint(cacheKey, dto, Duration.ofMinutes(60));
        return dto;
    }

    /**
     * 查询课程资源列表（带可见性过滤）
     */
    public PageResult<LearningResourceDTO> listResources(ResourceQuery query, UserContext user) {
        String cacheKey = buildResourceListCacheKey(query, user);
        PageResult<LearningResourceDTO> cached = contentCacheManager.getResourceList(cacheKey);
        if (cached != null) {
            return cached;
        }

        // 数据库分页查询仅按索引条件过滤
        Page<LearningResourceDO> page = learningResourceMapper.selectPublishedByCondition(
            new Page<>(query.getPage(), query.getSize()),
            query.getSubjectCode(),
            query.getPhase(),
            query.getGrade(),
            query.getResourceType(),
            query.getChapterCode(),
            query.getKnowledgePointCode()
        );

        List<LearningResourceDTO> visibleList = page.getRecords().stream()
            .map(this::convertToResourceDTO)
            .filter(dto -> visibilityFilter.isVisible(dto, user))
            .collect(Collectors.toList());

        PageResult<LearningResourceDTO> result = new PageResult<>(
            page.getTotal(), page.getCurrent(), page.getSize(), visibleList
        );

        contentCacheManager.setResourceList(cacheKey, result, Duration.ofMinutes(15));
        return result;
    }

    /**
     * 发布资源内容
     */
    @Transactional(rollbackFor = Exception.class)
    public void publishResource(Long resourceId, Long operatorId) {
        LearningResourceDO resource = learningResourceMapper.selectById(resourceId);
        if (resource == null) {
            throw new ContentException(ContentErrorCode.RESOURCE_NOT_FOUND);
        }
        if (!ContentStatus.PENDING.name().equals(resource.getStatus())) {
            throw new ContentException(ContentErrorCode.STATUS_NOT_ALLOWED);
        }

        resource.setStatus(ContentStatus.PUBLISHED.name());
        resource.setPublisherId(operatorId);
        resource.setPublishTime(LocalDateTime.now());
        learningResourceMapper.updateById(resource);

        // 失效缓存
        contentCacheManager.invalidateResource(resource.getResourceCode(), resource.getVersion());
        contentCacheManager.invalidateResourceList(resource.getSubjectCode(), resource.getPhase());

        // 发布事件
        eventPublisher.publish(new ContentPublishedEvent(
            ResourceType.valueOf(resource.getResourceType()),
            resource.getId(),
            resource.getResourceCode(),
            resource.getVersion()
        ));
    }

    /**
     * 创建新版本资源
     */
    @Transactional(rollbackFor = Exception.class)
    public LearningResourceDTO createNewResourceVersion(String resourceCode) {
        LearningResourceDO latest = learningResourceMapper.selectLatestByCode(resourceCode);
        if (latest == null) {
            throw new ContentException(ContentErrorCode.RESOURCE_NOT_FOUND);
        }

        LearningResourceDO newVersion = new LearningResourceDO();
        BeanUtils.copyProperties(latest, newVersion);
        newVersion.setId(null);
        newVersion.setVersion(latest.getVersion() + 1);
        newVersion.setStatus(ContentStatus.DRAFT.name());
        newVersion.setPublisherId(null);
        newVersion.setPublishTime(null);
        newVersion.setCreatedAt(LocalDateTime.now());
        newVersion.setUpdatedAt(LocalDateTime.now());

        learningResourceMapper.insert(newVersion);
        return convertToResourceDTO(newVersion);
    }

    private String buildTextbookListCacheKey(TextbookQuery query) {
        return String.format("content:textbook:list:%s:%s:%d:%d",
            query.getPhase(), query.getSubjectCode(), query.getGrade(), query.getSemester());
    }

    private String buildResourceListCacheKey(ResourceQuery query, UserContext user) {
        return String.format("content:resource:list:%s:%s:%d:%s:%s:%s:%d:%d:%s",
            query.getSubjectCode(), query.getPhase(), query.getGrade(),
            query.getResourceType(), query.getChapterCode(), query.getKnowledgePointCode(),
            query.getPage(), query.getSize(), user.getAccessTag());
    }
}
```

### 5.4 内容可见性过滤

```java
@Component
@RequiredArgsConstructor
public class ContentVisibilityFilter {

    private final UserServiceClient userServiceClient;
    private final MembershipServiceClient membershipServiceClient;
    private final ParentControlServiceClient parentControlServiceClient;

    public boolean isVisible(LearningResourceDTO resource, UserContext user) {
        // 1. 状态检查
        if (!ContentStatus.PUBLISHED.name().equals(resource.getStatus())) {
            return false;
        }

        // 2. 学段/年级匹配
        if (!resource.getGradeRange().contains(user.getGrade())) {
            return false;
        }
        if (!resource.getPhase().equals(user.getPhase())) {
            return false;
        }

        // 3. 家长控制范围
        Set<String> allowedSubjects = parentControlServiceClient.getAllowedSubjects(user.getUserId());
        if (!allowedSubjects.isEmpty() && !allowedSubjects.contains(resource.getSubjectCode())) {
            return false;
        }

        // 4. 访问权限
        ContentAccess access = ContentAccess.valueOf(resource.getAccessLevel());
        switch (access) {
            case FREE:
                return true;
            case MEMBER:
                return membershipServiceClient.hasActiveMembership(user.getUserId());
            case PAID:
                return membershipServiceClient.hasUnlockedResource(user.getUserId(), resource.getResourceCode());
            case SCHOOL:
                return user.getSchoolId() != null && user.getSchoolId().equals(resource.getSchoolId());
            default:
                return false;
        }
    }
}
```

```java
@RestControllerAdvice
public class ContentExceptionHandler {

    @ExceptionHandler(ContentException.class)
    public ApiResponse<Void> handleContentException(ContentException e) {
        log.warn("ContentException: code={}, message={}", e.getCode(), e.getMessage());
        return ApiResponse.fail(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ApiResponse<Void> handleValidationException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
            .map(error -> error.getField() + ":" + error.getDefaultMessage())
            .collect(Collectors.joining(";"));
        return ApiResponse.fail(ContentErrorCode.PARAM_INVALID.getCode(), message);
    }

    @ExceptionHandler(Exception.class)
    public ApiResponse<Void> handleGenericException(Exception e) {
        log.error("Internal error", e);
        return ApiResponse.fail(ContentErrorCode.INTERNAL_ERROR.getCode(),
            ContentErrorCode.INTERNAL_ERROR.getMessage());
    }
}
```

### 6.3 重试策略

| 场景 | 策略 | 说明 |
| --- | --- | --- |
| 数据库写入失败 | 立即重试 3 次，指数退避 | 防止瞬时网络抖动 |
| 缓存失效失败 | 异步补偿，写入延迟队列 | 不影响主流程 |
| 事件发布失败 | 本地事务表 + 定时重试 | 保证最终一致性 |
| 下游服务调用失败 | 熔断 + 降级返回 | 如会员服务异常时，按 FREE 降级 |

### 6.4 降级方案

| 异常场景 | 降级行为 |
| --- | --- |
| Redis 不可用 | 直接查询数据库，接口响应增加但可服务 |
| 会员服务不可用 | 临时按 FREE 内容返回，记录异常日志 |
| 用户服务不可用 | 使用缓存中的用户档案，超时则拒绝访问 |
| 文件存储服务异常 | 返回资源元数据，文件 URL 置空，提示稍后重试 |

## 7. 性能优化

### 7.1 缓存策略

1. **教材版本与章节树**：长时间缓存，内容变更时主动失效。
2. **知识点与考点**：读多写少，长时间缓存。
3. **资源列表**：短时间缓存，按查询条件+用户权益标签缓存，避免会员权益穿透。
4. **热点内容**：使用本地缓存（Caffeine）+ 分布式缓存（Redis）两级缓存。

### 7.2 数据库优化

1. 教材版本表按 `subject_code, grade, semester, status` 建立复合索引。
2. 章节表按 `textbook_id, parent_id, display_order` 建立复合索引。
3. 资源表 JSON 字段上建立前缀索引，用于知识点/章节关联查询。
4. 资源类型、状态、访问权限等枚举字段使用 `VARCHAR` 并建立索引。
5. 大文本字段（`content_body`）单独存储，查询列表时不返回。

### 7.3 并发控制

1. 教材版本编码全局唯一，使用数据库唯一约束防止重复创建。
2. 资源版本升级使用 `SELECT ... FOR UPDATE` 或分布式锁，避免并发创建同一版本。
3. 审核/发布操作幂等，通过状态机防止重复提交。

### 7.4 资源限制

| 限制项 | 值 | 说明 |
| --- | --- | --- |
| 单次资源列表返回条数 | 最大 100 | 防止分页过大 |
| 章节树最大层级 | 4 层 | 单元/章/节/课时 |
| 单个知识点关联数 | 最多 50 个 | 控制关系图规模 |
| 单个资源关联章节数 | 最多 10 个 | 保持资源聚焦 |
| 教材版本同时生效数 | 同一学科/年级/学期最多 2 个 | 新旧版本并行过渡 |

## 8. 安全考虑

### 8.1 权限控制

1. **查询接口**：学生/家长用户仅能访问 PUBLISHED 状态且符合自身学段年级的内容。
2. **管理接口**：后台接口需 `ADMIN`、`CONTENT_EDITOR`、`CONTENT_AUDITOR` 角色之一。
3. **审核操作**：仅 `CONTENT_AUDITOR` 可执行审核通过/驳回。
4. **发布操作**：仅 `ADMIN` 和 `CONTENT_EDITOR` 可执行发布/下架。

### 8.2 数据验证

1. 所有写入接口必须校验必填字段、字段长度、枚举值合法性。
2. 富文本内容（`content_body`）需进行 XSS 过滤和危险标签白名单处理。
3. 文件 URL 必须来自平台内部对象存储域名，禁止外部 URL。
4. 知识点编码、章节编码、资源编码必须符合平台编码规范。

### 8.3 审计日志

所有后台管理操作记录审计日志：

```sql
CREATE TABLE content_audit_log (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    operator_id BIGINT NOT NULL COMMENT '操作人ID',
    operator_name VARCHAR(64) COMMENT '操作人姓名',
    action VARCHAR(64) NOT NULL COMMENT '操作类型',
    entity_type VARCHAR(64) NOT NULL COMMENT '实体类型',
    entity_id BIGINT NOT NULL COMMENT '实体ID',
    before_value JSON COMMENT '变更前内容',
    after_value JSON COMMENT '变更后内容',
    ip VARCHAR(64) COMMENT '操作IP',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    KEY idx_entity (entity_type, entity_id),
    KEY idx_operator (operator_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容审计日志表';
```

### 8.4 数据隔离

1. 内容按学段、学科、年级进行逻辑隔离，查询时严格过滤。
2. B 端学校内容使用 `school_id` 字段隔离，普通用户不可见。
3. 管理后台支持多租户时，内容按租户 ID 隔离。

3. 知识点详情高并发查询（QPS 1000）缓存命中率 > 95%。
4. 内容发布时缓存失效广播延迟 < 500ms。
