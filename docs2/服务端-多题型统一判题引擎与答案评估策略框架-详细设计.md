## 1. 概述

### 1.1 文档定位

PrimeTop 平台支持选择、填空、判断、简答、计算、证明、应用、综合等 **8 大基础题型**，以及听写默写、语音背诵、代码提交、拖拽排序等 **扩展交互题型**。现有设计文档已分别针对主观题评分、手写体批改、作文批改、实时批改等场景做了详细设计。

但在实际练习/考试流程中，一次练习会话往往混合多种题型，需要一个 **统一的判题入口** 来：

1. 根据题型自动路由到正确的评估策略
2. 支持新题型的热插拔注册（无需修改核心判题流程）
3. 统一管理同步判题与异步判题的执行调度
4. 提供统一的评分结果结构（满分/得分/部分分/反馈/知识点映射）
5. 内置 AI 辅助评估兜底链路（当规则判题无法覆盖时降级到 AI 判题）
6. 管理判题超时、重试与降级策略

本设计定义了整个判题引擎的架构、接口、策略注册机制和执行管线，是连接「答题交互」与「评分反馈」之间的核心中间件。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 统一判题入口 | 接收所有题型的答案提交，返回统一格式的判题结果 |
| 策略路由 | 根据题型自动选择对应的评估器 (Evaluator) |
| 插件注册 | 支持新增题型评估器，无需改动核心流程 |
| 同步/异步调度 | 客观题同步返回，复杂主观题异步评估 |
| 部分分计算 | 统一的部分分 (partial credit) 计算框架 |
| AI 兜底链路 | 规则判题无法处理时，降级到 AI 大模型评估 |
| 结果置信度 | 输出判题结果置信度，低置信度结果标记人工复核 |
| 批量判题 | 支持一次提交多道题目，并行评估 |
| 判题事件 | 产出标准化的判题事件供下游模块消费 |

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 客观题判题延迟 | P99 ≤ 50ms（规则匹配） |
| 主观题判题延迟 | P99 ≤ 5s（AI 辅助评估） |
| 批量判题吞吐 | 单次请求 50 道题，总耗时 ≤ 10s |
| 判题准确率 | 客观题 100%（规则匹配），主观题 ≥ 92%（与人工标注一致性） |
| 判题可用性 | ≥ 99.95%（AI 兜底保证） |
| 可扩展性 | 新增题型评估器 ≤ 1 人天工作量 |

### 1.5 术语表

| 术语 | 定义 |
|------|------|
| Judge / 判题 | 对学生提交的答案进行正确性判定和评分的过程 |
| Evaluator / 评估器 | 针对特定题型的判题策略实现，是一个独立的可插拔组件 |
| Verdict / 判定结果 | 判题结论：correct / incorrect / partially_correct / pending_review |
| Confidence / 置信度 | 判题结果的可信程度，0.0 ~ 1.0 |
| Partial Credit / 部分分 | 对于非完全正确也非完全错误的答案，按比例给予分数 |
| Rubric / 评分量规 | 主观题评分的维度、标准与分值分配规则 |
| AI Fallback / AI 兜底 | 当规则判题无法处理或置信度过低时，调用 AI 大模型进行评估 |

## 2. 数据模型

### 2.1 答案提交结构 (AnswerSubmission)

客户端提交答案时的统一请求结构，适用于所有题型：

```typescript
interface AnswerSubmission {
  /** 答题记录唯一ID（客户端生成，用于幂等） */
  attemptId: string;
  /** 题目ID */
  questionId: number;
  /** 练习会话ID */
  sessionId: string;
  /** 用户ID */
  userId: number;
  /** 题型（由题目服务决定，客户端仅传递） */
  questionType: QuestionType;
  /** 学生答案（格式因题型而异，见 §2.2） */
  answer: StudentAnswer;
  /** 答题耗时（毫秒） */
  timeCostMs: number;
  /** 修改次数 */
  editCount: number;
  /** 输入方式 */
  inputMethod: 'keyboard' | 'handwriting' | 'voice' | 'photo' | 'drag_drop';
  /** 辅助手段使用标记 */
  hintsUsed: number;
  /** 提交时间戳（毫秒） */
  submittedAt: number;
  /** 设备信息 */
  deviceInfo?: {
    platform: 'android' | 'ios' | 'web' | 'mini_program';
    appVersion: string;
  };
}

/** 题型枚举 */
type QuestionType =
  | 'choice'          // 选择题（单选/多选）
  | 'fill'            // 填空题
  | 'judge'           // 判断题
  | 'short_answer'    // 简答题
  | 'calculation'     // 计算题
  | 'proof'           // 证明题
  | 'application'     // 应用题
  | 'synthesis'       // 综合题
  | 'dictation'       // 听写默写
  | 'recitation'      // 背诵检测
  | 'code'            // 编程题
  | 'ordering';       // 排序/拖拽题
```

### 2.2 学生答案格式 (StudentAnswer)

不同题型对应不同的答案数据结构：

```typescript
/** 学生答案联合类型 */
type StudentAnswer =
  | ChoiceAnswer
  | FillAnswer
  | JudgeAnswer
  | TextAnswer
  | CalculationAnswer
  | ProofAnswer
  | DictationAnswer
  | CodeAnswer
  | OrderingAnswer;

/** 选择题答案 */
interface ChoiceAnswer {
  type: 'choice';
  /** 单选: ["A"], 多选: ["A", "C", "D"] */
  selectedOptions: string[];
  /** 是否多选 */
  isMultiple: boolean;
}

/** 填空题答案 */
interface FillAnswer {
  type: 'fill';
  /** 每个空的答案，按空序号排列 */
  blanks: FillBlank[];

interface FillBlank {
  /** 空的序号，从 1 开始 */
  index: number;
  /** 学生填写的内容 */
  content: string;
  /** 输入方式: text / latex / handwriting_image_url */
  contentType: 'text' | 'latex' | 'handwriting_image' | 'voice_url';
}

/** 判断题答案 */
interface JudgeAnswer {
  type: 'judge';
  value: boolean;
}

/** 文本类答案（简答题/应用题/综合题） */
interface TextAnswer {
  type: 'short_answer' | 'application' | 'synthesis';
  /** 文本内容（支持 Markdown + LaTeX） */
  content: string;
  /** 手写图片URL（如有） */
  handwritingImages?: string[];
  /** 语音回答URL（如有） */
  voiceUrl?: string;
}

/** 计算题答案 */
interface CalculationAnswer {
  type: 'calculation';
  /** 最终答案 */
  finalAnswer: string;
  /** 解题过程（分步骤） */
  steps?: {
    stepNo: number;
    content: string;      // 步骤内容（支持 LaTeX）
    expression?: string;   // 数学表达式
  }[];
  /** 手写演算图片URL */
  handwritingImages?: string[];
}

/** 证明题答案 */
interface ProofAnswer {
  type: 'proof';
  /** 完整证明过程（Markdown + LaTeX） */
  content: string;
  /** 证明步骤结构化表示 */
  steps?: {
    stepNo: number;
    statement: string;     // 命题/推导
    reasoning: string;     // 依据（定理/公理/已知条件）
  }[];
}

/** 听写默写答案 */
interface DictationAnswer {
  type: 'dictation';
  /** 文本输入 */
  text?: string;
  /** 语音回答URL（ASR 识别后文本） */
  voiceUrl?: string;
  /** ASR 识别结果 */
  recognizedText?: string;
}

/** 编程题答案 */
interface CodeAnswer {
  type: 'code';
  /** 源代码 */
  code: string;
  /** 编程语言 */
  language: 'python' | 'cpp' | 'java' | 'javascript';
}

/** 排序/拖拽题答案 */
interface OrderingAnswer {
  type: 'ordering';
  /** 排序后的元素ID序列 */
  orderedIds: string[];
}
```

### 2.3 判题结果结构 (JudgeResult)

所有评估器输出的统一结果格式：

```typescript
/** 判题结果 */
interface JudgeResult {
  /** 答题记录ID */
  attemptId: string;
  /** 题目ID */
  questionId: number;
  /** 判定结论 */
  verdict: JudgeVerdict;
  /** 得分（0 ~ 满分） */
  score: number;
  /** 满分 */
  maxScore: number;
  /** 得分率 (score / maxScore) */
  scoreRate: number;
  /** 判题置信度 (0.0 ~ 1.0) */
  confidence: number;
  /** 使用的判题策略 */
  strategy: JudgeStrategy;
  /** 判题耗时（毫秒） */
  judgeTimeMs: number;
  /** 分步评分明细（如有） */
  stepResults?: StepJudgeResult[];
  /** 反馈信息 */
  feedback: JudgeFeedback;
  /** 知识点掌握度变化 */
  knowledgeUpdates?: KnowledgeUpdate[];
  /** 是否需要人工复核 */
  needsReview: boolean;
  /** 复核原因（needsReview=true 时） */
  reviewReason?: string;
  /** 判题时间戳 */
  judgedAt: number;
  /** 判题引擎版本 */
  engineVersion: string;
}

/** 判定结论 */
type JudgeVerdict =
  | 'correct'              // 完全正确
  | 'partially_correct'    // 部分正确
  | 'incorrect'            // 错误
  | 'pending_review';      // 待人工复核

/** 判题策略标识 */
type JudgeStrategy =
  | 'exact_match'          // 精确匹配
  | 'fuzzy_match'          // 模糊匹配
  | 'regex_match'          // 正则匹配
  | 'equivalence_check'    // 等价性校验（如数学表达式等价）
  | 'rubric_based'         // 基于评分量规
  | 'ai_assisted'          // AI 辅助评估
  | 'ai_with_rubric'       // AI + 评分量规
  | 'code_execution'       // 代码执行验证
  | 'manual_review';       // 人工复核

/** 分步评分明细 */
interface StepJudgeResult {
  stepNo: number;
  /** 该步骤判定 */
  verdict: 'correct' | 'incorrect' | 'skipped';
  /** 该步骤得分 */
  score: number;
  /** 该步骤满分 */
  maxScore: number;
  /** 反馈 */
  comment?: string;
}

/** 反馈信息 */
interface JudgeFeedback {
  /** 总体评价（一句话） */
  summary: string;
  /** 错误类型分类 */
  errorType?: ErrorType;
  /** 具体错误说明 */
  errorDetails?: string;
  /** 正确答案提示（根据答案管控策略决定是否展示） */
  correctHint?: string;
  /** 知识点关联反馈 */
  knowledgePoints?: {
    pointId: number;
    pointName: string;
    mastery: 'mastered' | 'weak' | 'unknown';
  }[];
  /** 鼓励性提示 */
  encouragement?: string;
}

/** 错误类型分类 */
type ErrorType =
  | 'concept_misunderstanding'   // 概念理解错误
  | 'calculation_error'          // 计算失误
  | 'careless_mistake'           // 粗心错误
  | 'incomplete_answer'          // 答案不完整
  | 'wrong_method'              // 方法错误
  | 'format_error'              // 格式错误
  | 'spelling_error'            // 拼写错误
  | 'logic_error'               // 逻辑错误
  | 'missing_steps'             // 缺少步骤
  | 'other';                    // 其他

/** 知识点掌握度更新 */
interface KnowledgeUpdate {
  knowledgePointId: number;
  /** 更新前掌握度 */
  beforeMastery: number;
  /** 更新后掌握度 */
  afterMastery: number;
  /** 变化来源 */
  source: 'correct_answer' | 'incorrect_answer' | 'partial_answer';
}
```

```sql
CREATE TABLE judge_records (
    id              BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    attempt_id      CHAR(36) NOT NULL UNIQUE COMMENT '答题尝试ID（幂等键）',
    session_id      CHAR(36) NOT NULL COMMENT '练习会话ID',
    user_id         BIGINT UNSIGNED NOT NULL COMMENT '用户ID',
    question_id     BIGINT UNSIGNED NOT NULL COMMENT '题目ID',
    question_type   VARCHAR(20) NOT NULL COMMENT '题型',
    subject_code    VARCHAR(16) NOT NULL COMMENT '学科编码',

    -- 答案快照
    student_answer  JSON NOT NULL COMMENT '学生答案（完整快照）',
    correct_answer  JSON DEFAULT NULL COMMENT '标准答案（判题时快照）',

    -- 判题结果
    verdict         ENUM('correct','partially_correct','incorrect','pending_review')
                    NOT NULL COMMENT '判定结论',
    score           DECIMAL(6,2) NOT NULL COMMENT '得分',
    max_score       DECIMAL(6,2) NOT NULL COMMENT '满分',
    score_rate      DECIMAL(5,4) GENERATED ALWAYS AS (score / max_score) STORED
                    COMMENT '得分率',
    confidence      DECIMAL(3,2) NOT NULL DEFAULT 1.00 COMMENT '判题置信度',
    strategy        VARCHAR(32) NOT NULL COMMENT '判题策略',
    step_results    JSON DEFAULT NULL COMMENT '分步评分明细',
    feedback        JSON DEFAULT NULL COMMENT '反馈信息',
    knowledge_updates JSON DEFAULT NULL COMMENT '知识点掌握度变化',

    -- 判题元数据
    judge_time_ms   INT UNSIGNED NOT NULL COMMENT '判题耗时(ms)',
    engine_version  VARCHAR(20) NOT NULL COMMENT '判题引擎版本',
    evaluator_id    VARCHAR(64) NOT NULL COMMENT '使用的评估器标识',
    needs_review    TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否需要人工复核',
    review_reason   VARCHAR(255) DEFAULT NULL COMMENT '复核原因',
    reviewer_id     BIGINT UNSIGNED DEFAULT NULL COMMENT '复核人ID',
    review_result   ENUM('confirmed','overturned','modified') DEFAULT NULL COMMENT '复核结果',

    -- AI 评估元数据
    ai_model        VARCHAR(64) DEFAULT NULL COMMENT 'AI模型（如使用）',
    ai_prompt_id    VARCHAR(64) DEFAULT NULL COMMENT 'Prompt模板ID',
    ai_token_cost   INT UNSIGNED DEFAULT NULL COMMENT 'Token消耗',

    -- 时间字段
    submitted_at    DATETIME(3) NOT NULL COMMENT '提交时间',
    judged_at       DATETIME(3) NOT NULL COMMENT '判题完成时间',
    created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '记录创建时间',

    -- 索引
    INDEX idx_session (session_id),
    INDEX idx_user_question (user_id, question_id),
    INDEX idx_review (needs_review, review_result),
    INDEX idx_subject_verdict (subject_code, verdict),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='判题记录表';
```
