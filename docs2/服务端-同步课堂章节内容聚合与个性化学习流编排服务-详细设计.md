# 服务端-同步课堂章节内容聚合与个性化学习流编排服务 - 详细设计

> **模块定位**: 将散落在知识点库、题库、教材资源库中的章节学习内容动态聚合，根据学生画像编排个性化学习流（预习→概念→例题→练习→复习），按需插入自适应内容（薄弱强化/拓展挑战），为客户端提供统一的章节学习内容API。
>
> **优先级**: P0 (MVP核心闭环)
> **依赖**: 知识点体系与教材映射引擎、题目与题库服务、用户学习画像与能力维度模型、学习记录与进度追踪服务、AI模型上下文管理与对话记忆引擎

### 2.1 章节内容清单 (ChapterContentManifest)

```python
class ChapterContentManifest(TypedDict):
    """章节内容清单 — 一个章节所有可聚合内容的元数据目录"""
    chapter_id: str               # 章节ID (格式: tb_{版本}_{册}_{章}_{节})
    textbook_id: str              # 教材版本ID
    subject: str                  # 学科
    grade: str                    # 年级代码
    term: Literal["上册", "下册"]
    
    # 知识点
    knowledge_points: List[KnowledgePointRef]
    
    # 学习资源
    resources: List[ContentResourceRef]
    
    # 题目池
    question_pool: QuestionPoolRef
    
    # 教学要求
    teaching_requirements: TeachingRequirements
    
    # 元数据
    total_estimated_minutes: int  # 预估学习总时长(分钟)
    difficulty_level: float       # 章节整体难度 0-1
    updated_at: str               # ISO8601
    version_hash: str             # v1.1 增补:内容版本SHA256(缓存校验/失效判断用)


class KnowledgePointRef(TypedDict):
    """知识点引用"""
    kp_id: str
    name: str
    level: Literal["core", "important", "supplementary"]  # 核心/重要/补充
    order: int                    # 学习顺序
    prerequisites: List[str]      # 前置知识点ID
    estimated_minutes: int
    mastery_threshold: float      # 掌握度阈值 0-1


class ContentResourceRef(TypedDict):
    """学习资源引用"""
    resource_id: str
    resource_type: Literal[
        "concept_text",       # 概念讲解文本
        "example",            # 例题
        "video",              # 视频讲解
        "animation",          # 动画演示
        "image",              # 图片/图表
        "audio",              # 音频(如英语听力)
        "interactive",        # 交互式内容
        "summary",            # 知识总结
        "mind_map",           # 思维导图
    ]
    kp_ids: List[str]            # 关联知识点
    difficulty: float            # 0-1
    duration_seconds: int        # 时长(文本为阅读时长估算)
    title: str
    storage_uri: str
    format: str                  # json/markdown/mp4/webp/mp3/html


class QuestionPoolRef(TypedDict):
    """题目池引用"""
    basic_count: int              # 基础题数量
    medium_count: int             # 中等题数量
    hard_count: int               # 拔高题数量
    total_count: int
    tags: List[str]               # 题目标签


class TeachingRequirements(TypedDict):
    """教学要求"""
    cognitive_levels: List[str]   # 认知层次: 记忆/理解/应用/分析/综合/评价
    key_abilities: List[str]      # 关键能力
    exam_weight: float            # 考试占比权重
    curriculum_standard: str      # 课标要求文本
```

class LearningFlowTemplate(TypedDict):

        "example",         # 例题讲解

        "independent_practice",  # 独立练习
        "review",          # 复习总结
        "challenge",       # 拓展挑战

    description: str
    estimated_minutes: int
    required: bool                # 是否必学阶段
    content_slots: List[ContentSlot]  # 内容槽位

    content_types: List[str]      # 接受的内容类型
    min_count: int
    max_count: int

class PersonalizedLearningFlow(TypedDict):

    """自适应插入的阶段"""

        "prerequisite_remedy",    # 前置知识补救
        "challenge_extension",    # 拓展挑战
        "review_before_exam",     # 考前复习

    insert_after_stage_index: int

    """填充后的阶段"""
    stage: LearningStage
    contents: List[FilledContent]
    progress: StageProgress
    adaptive_insertions: List[AdaptiveInsertion]  # 自适应插入的内容


class FilledContent(TypedDict):
    """填充后的内容"""
    slot_id: str
    content_ref: ContentResourceRef
    personalized: bool           # 是否经过个性化选择
    relevance_score: float       # 与用户画像的相关性 0-1
    order: int


class StageProgress(TypedDict):
    """阶段进度"""
    status: Literal["locked", "available", "in_progress", "completed", "skipped"]
    started_at: Optional[str]
    completed_at: Optional[str]
    time_spent_seconds: int
    content_viewed_count: int
    content_total_count: int
    practice_score: Optional[float]  # 练习得分(如有)


class AdaptiveInsertion(TypedDict):

    insert_position: int

### 3.1 章节内容聚合流程

```python
class ChapterContentAggregator:
    """章节内容聚合器 — 从多数据源聚合章节全部可学习内容"""
    
    def __init__(
        self,
        knowledge_point_service: KnowledgePointService,
        question_service: QuestionService,
        resource_service: ResourceService,
        cache: Redis,
    ):
        self.kp_service = knowledge_point_service
        self.question_service = question_service
        self.resource_service = resource_service
        self.cache = cache
    
    async def get_or_build_manifest(
        self, chapter_id: str, textbook_id: str
    ) -> ChapterContentManifest:
        """获取或构建章节内容清单(带缓存)"""
        
        # 1. 查缓存
        cache_key = f"chapter_manifest:{chapter_id}:{textbook_id}"
        cached = await self.cache.get(cache_key)
        if cached:
            manifest = json.loads(cached)
            # 校验版本哈希是否变化
            current_hash = await self._compute_version_hash(chapter_id)
            if current_hash == manifest.get("version_hash"):
                return manifest
        
        # 2. 构建清单
        # v1.1 修复缺陷 D1:原实现缓存命中分支读取 manifest.get("version_hash"),
        # 但 TypedDict 与构建流程均未写入该字段,导致缓存校验永远 miss→每次全量重建。
        # 现改为构建后立即计算并写入 version_hash,再持久化与缓存。
        manifest = await self._build_manifest(chapter_id, textbook_id)
        manifest["version_hash"] = await self._compute_version_hash(chapter_id)
        
        # 3. 持久化 + 缓存
        await self._save_manifest(manifest)
        await self.cache.set(
            cache_key, json.dumps(manifest, ensure_ascii=False),
            ex=3600  # 1小时缓存
        )
        
        return manifest
    
    async def _build_manifest(
        self, chapter_id: str, textbook_id: str
    ) -> ChapterContentManifest:
        """构建章节内容清单"""
        
        # 并行拉取各数据源
        kp_task = self.kp_service.get_chapter_knowledge_points(chapter_id)
        res_task = self.resource_service.get_chapter_resources(chapter_id)
        q_task = self.question_service.get_chapter_question_stats(chapter_id)
        meta_task = self.kp_service.get_chapter_metadata(chapter_id)
        
        kps, resources, question_stats, metadata = await asyncio.gather(
            kp_task, res_task, q_task, meta_task
        )
        
        # 构建知识点引用
        kp_refs = [
            KnowledgePointRef(
                kp_id=kp.id,
                name=kp.name,
                level=kp.importance_level,
                order=kp.sort_order,
                prerequisites=kp.prerequisite_ids,
                estimated_minutes=kp.estimated_learn_minutes,
                mastery_threshold=kp.mastery_threshold,
            )
            for kp in sorted(kps, key=lambda x: x.sort_order)
        ]
        
        # 构建资源引用
        res_refs = [
            ContentResourceRef(
                resource_id=r.id,
                resource_type=r.type,
                kp_ids=r.knowledge_point_ids,
                difficulty=r.difficulty,
                duration_seconds=r.duration_seconds,
                title=r.title,
                storage_uri=r.storage_uri,
                format=r.format,
            )
            for r in resources
        ]
        
        # 构建题目池引用
        pool_ref = QuestionPoolRef(
            basic_count=question_stats.get("basic", 0),
            medium_count=question_stats.get("medium", 0),
            hard_count=question_stats.get("hard", 0),
            total_count=question_stats.get("total", 0),
            tags=question_stats.get("tags", []),
        )
        
        # 计算总时长
        total_minutes = sum(kp.estimated_minutes for kp in kp_refs)
        
        return ChapterContentManifest(
            chapter_id=chapter_id,
            textbook_id=textbook_id,
            subject=metadata.subject,
            grade=metadata.grade,
            term=metadata.term,
            knowledge_points=kp_refs,
            resources=res_refs,
            question_pool=pool_ref,
            teaching_requirements=metadata.teaching_requirements,
            total_estimated_minutes=total_minutes,
            difficulty_level=metadata.difficulty_level,
            updated_at=datetime.now(timezone.utc).isoformat(),
        )
```

### 3.2 学习流编排流程

```python
class LearningFlowOrchestrator:
    """学习流编排引擎 — 根据模板和用户画像生成个性化学习流"""
    
    # 默认阶段序列
    DEFAULT_STAGE_SEQUENCE = [
        "preview",                # 预习
        "concept",                # 概念学习
        "example",                # 例题讲解
        "guided_practice",        # 引导练习
        "independent_practice",   # 独立练习
        "review",                 # 复习总结
    ]
    
    # 分龄模板策略
    AGE_STAGE_STRATEGIES = {
        "primary_low": {   # 小学低年级(1-3)
            "required_stages": ["preview", "concept", "guided_practice", "review"],
            "optional_stages": ["example", "independent_practice", "challenge"],
            "default_difficulty": 0.3,
            "max_content_per_stage": 3,
            "prefer_resource_types": ["animation", "interactive", "image", "audio"],
        },
        "primary_high": {  # 小学高年级(4-6)
            "required_stages": ["preview", "concept", "example", "guided_practice", "review"],
            "optional_stages": ["independent_practice", "challenge"],
            "default_difficulty": 0.4,
            "max_content_per_stage": 4,
            "prefer_resource_types": ["concept_text", "example", "video", "interactive"],
        },
        "junior": {        # 初中
            "required_stages": ["concept", "example", "guided_practice", "independent_practice", "review"],
            "optional_stages": ["preview", "challenge"],
            "default_difficulty": 0.5,
            "max_content_per_stage": 5,
            "prefer_resource_types": ["concept_text", "example", "summary", "mind_map"],
        },
        "senior": {        # 高中
            "required_stages": ["concept", "example", "independent_practice", "review"],
            "optional_stages": ["preview", "guided_practice", "challenge"],
            "default_difficulty": 0.6,
            "max_content_per_stage": 6,
            "prefer_resource_types": ["concept_text", "example", "summary", "mind_map"],
        },
    }
    
    def __init__(
        self,
        manifest_aggregator: ChapterContentAggregator,
        adaptive_inserter: AdaptiveInsertionEngine,
        user_profile_service: UserProfileService,
        progress_service: ProgressTrackingService,
        template_repo: LearningFlowTemplateRepository,
    ):
        self.aggregator = manifest_aggregator
        self.adaptive_inserter = adaptive_inserter
        self.profile_service = user_profile_service
        self.progress_service = progress_service
        self.template_repo = template_repo
    
    async def generate_personalized_flow(
        self,
        user_id: str,
        chapter_id: str,
        textbook_id: str,
        force_regenerate: bool = False,
    ) -> PersonalizedLearningFlow:
        """
        为用户生成个性化章节学习流
        核心入口方法
        """
        
        # 1. 检查是否已有未完成的学习流
        if not force_regenerate:
            existing = await self._get_active_flow(user_id, chapter_id)
            if existing:
                return existing
        
        # 2. 获取章节内容清单
        manifest = await self.aggregator.get_or_build_manifest(
            chapter_id, textbook_id
        )
        
        # 3. 获取用户画像和学习上下文
        profile = await self.profile_service.get_learning_profile(user_id)
        context = await self._build_learning_context(user_id, chapter_id, manifest)
        
        # 4. 选择学习流模板
        template = await self._select_template(manifest, profile)
        
        # 5. 生成基础学习流(填充内容)
        base_flow = await self._build_base_flow(template, manifest, profile, context)
        
        # 6. 自适应插入(薄弱强化/前置补救/拓展挑战)
        enhanced_flow = await self.adaptive_inserter.enhance_with_adaptives(
            base_flow, manifest, profile, context
        )
        
        # 7. 个性化排序
        sorted_flow = await self._personalized_sort(enhanced_flow, profile, context)
        
        # 8. 持久化
        flow_instance = PersonalizedLearningFlow(
            flow_id=str(uuid.uuid4()),
            user_id=user_id,
            chapter_id=chapter_id,
            template_id=template["template_id"],
            status="not_started",
            current_stage_index=0,
            current_slot_index=0,
            skipped_stages=[],
            inserted_stages=[s for s in sorted_flow["inserted_stages"]],
            difficulty_override=context.get("difficulty_override"),
            stages=sorted_flow["stages"],
            started_at=None,
            last_active_at=None,
            completed_at=None,
            total_time_spent_seconds=0,
            generated_at=datetime.now(timezone.utc).isoformat(),
            expires_at=self._compute_expiry(manifest).isoformat(),
        )
        
        await self._save_flow(flow_instance)
        return flow_instance
    
    async def _build_learning_context(
        self,
        user_id: str,
        chapter_id: str,
        manifest: ChapterContentManifest,
    ) -> dict:
        """构建学习上下文"""
        
        # 获取用户对该章节知识点的掌握度
        kp_mastery = await self.progress_service.batch_get_kp_mastery(
            user_id, [kp["kp_id"] for kp in manifest["knowledge_points"]]
        )
        
        # 获取前置章节完成情况
        prerequisite_chapters = await self._get_prerequisite_chapters(chapter_id)
        prereq_completion = await self.progress_service.batch_get_chapter_completion(
            user_id, prerequisite_chapters
        )
        
        # 获取最近学习行为(判断学习疲劳度)
        recent_activity = await self.progress_service.get_recent_learning_sessions(
            user_id, hours=2
        )
        
        # 计算知识点掌握度分布
        weak_kps = [
            kp for kp in manifest["knowledge_points"]
            if kp_mastery.get(kp["kp_id"], 0) < kp["mastery_threshold"]
        ]
        
        strong_kps = [
            kp for kp in manifest["knowledge_points"]
            if kp_mastery.get(kp["kp_id"], 0) >= 0.85
        ]
        
        # 判断是否为首次学习
        is_first_visit = all(
            kp_mastery.get(kp["kp_id"], 0) == 0
            for kp in manifest["knowledge_points"]
        )
        
        return {
            "kp_mastery": kp_mastery,
            "weak_kps": weak_kps,
            "strong_kps": strong_kps,
            "prerequisite_completion": prereq_completion,
            "has_prerequisite_gaps": any(
                v < 0.6 for v in prereq_completion.values()
            ),
            "recent_study_minutes": sum(
                s.duration_seconds for s in recent_activity
            ) / 60,
            "is_fatigued": sum(
                s.duration_seconds for s in recent_activity
            ) > 90 * 60,  # 90分钟以上视为疲劳
            "is_first_visit": is_first_visit,
            "difficulty_override": self._compute_difficulty_override(
                kp_mastery, manifest
            ),
        }
    
    def _compute_difficulty_override(
        self, kp_mastery: dict, manifest: ChapterContentManifest
    ) -> Optional[float]:
        """根据知识点掌握度计算难度覆盖值"""
        if not kp_mastery:
            return None  # 首次学习，使用默认难度
        
        avg_mastery = sum(kp_mastery.values()) / len(kp_mastery) if kp_mastery else 0
        
        # 掌握度低→降低难度, 掌握度高→提升难度
        base_difficulty = manifest["difficulty_level"]
        adjusted = base_difficulty + (avg_mastery - 0.5) * 0.3
        return max(0.1, min(0.9, adjusted))
    
    async def _build_base_flow(
        self,
        template: LearningFlowTemplate,
        manifest: ChapterContentManifest,
        profile: dict,
        context: dict,
    ) -> dict:
        """基于模板构建基础学习流并填充内容"""
        
        age_group = self._get_age_group(profile["grade"])
        strategy = self.AGE_STAGE_STRATEGIES[age_group]
        
        filled_stages = []
        
        for stage_def in template["stage_sequence"]:
            # 判断阶段是否需要跳过
            if not self._should_include_stage(stage_def, strategy, context):
                continue
            
            # 为每个内容槽位填充具体内容
            filled_contents = await self._fill_content_slots(
                stage_def["content_slots"],
                manifest,
                profile,
                context,
                strategy,
            )
            
            filled_stages.append(FilledStage(
                stage=stage_def,
                contents=filled_contents,
                progress=StageProgress(
                    status="locked" if len(filled_stages) > 0 else "available",
                    started_at=None,
                    completed_at=None,
                    time_spent_seconds=0,
                    content_viewed_count=0,
                    content_total_count=len(filled_contents),
                    practice_score=None,
                ),
                adaptive_insertions=[],
            ))
        
        # 解锁第一个阶段
        if filled_stages:
            filled_stages[0]["progress"]["status"] = "available"
        
        return {"stages": filled_stages, "inserted_stages": []}
    
    async def _fill_content_slots(
        self,
        slots: List[ContentSlot],
        manifest: ChapterContentManifest,
        profile: dict,
        context: dict,
        strategy: dict,
    ) -> List[FilledContent]:
        """为内容槽位填充具体资源"""
        
        filled = []
        difficulty = context.get("difficulty_override") or strategy["default_difficulty"]
        
        for slot in slots:
            # 筛选匹配的资源
            candidates = self._filter_resources_for_slot(
                slot, manifest["resources"], difficulty, strategy
            )
            
            # 评分排序
            scored = [
                (res, self._score_resource(res, slot, profile, context))
                for res in candidates
            ]
            scored.sort(key=lambda x: x[1], reverse=True)
            
            # 取 top-N
            count = min(slot["max_count"], strategy["max_content_per_stage"])
            for res, score in scored[:count]:
                filled.append(FilledContent(
                    slot_id=slot["slot_id"],
                    content_ref=res,
                    personalized=slot["slot_type"] in ("recommended", "adaptive"),
                    relevance_score=score,
                    order=len(filled),
                ))
        
        return filled
    
    def _score_resource(
        self,
        resource: ContentResourceRef,
        slot: ContentSlot,
        profile: dict,
        context: dict,
    ) -> float:
        """为资源打分(个性化相关性)"""
        score = 0.5  # 基础分
        
        # 偏好类型加分
        age_group = self._get_age_group(profile["grade"])
        strategy = self.AGE_STAGE_STRATEGIES[age_group]
        if resource["resource_type"] in strategy["prefer_resource_types"]:
            score += 0.2
        
        # 关联薄弱知识点加分
        weak_kp_ids = {kp["kp_id"] for kp in context.get("weak_kps", [])}
        if set(resource["kp_ids"]) & weak_kp_ids:
            score += 0.15
        
        # 难度匹配度加分
        target_diff = context.get("difficulty_override") or 0.5
        diff_distance = abs(resource["difficulty"] - target_diff)
        score += max(0, 0.15 - diff_distance * 0.3)
        
        return min(1.0, score)
```

class AdaptiveInsertionEngine:
    """自适应内容插入引擎 — 根据学习画像动态插入额外学习内容"""

        self,
        knowledge_point_service: KnowledgePointService,
        question_service: QuestionService,
        resource_service: ResourceService,

        self.question_service = question_service

    async def enhance_with_adaptives(
        self,
        base_flow: dict,
        manifest: ChapterContentManifest,
        profile: dict,
        context: dict,
    ) -> dict:
        """在基础学习流中插入自适应内容"""
        
        insertions = []
        
        # 1. 前置知识补救
        if context.get("has_prerequisite_gaps"):
            insertion = await self._create_prerequisite_remedy(
                manifest, context
            )
            if insertion:
                insertions.append(insertion)
        
        # 2. 薄弱知识点强化
        if context.get("weak_kps"):
            insertion = await self._create_weak_kp_reinforcement(
                manifest, context, profile
            )
            if insertion:
                insertions.append(insertion)
        
        # 3. 拓展挑战(针对掌握度高的学生)
        if len(context.get("strong_kps", [])) >= len(manifest["knowledge_points"]) * 0.6:
            insertion = await self._create_challenge_extension(
                manifest, context, profile
            )
            if insertion:
                insertions.append(insertion)
        
        # 将插入内容合并到学习流中
        # v1.1 修复缺陷 D2:原实现 idx = insert_after_stage_index + 1 未累计前序插入
        # 造成的索引偏移。insert_after_stage_index 语义为「模板基础流的原始阶段下标」,
        # 当同时存在两个插入(如前置补救 after=0、薄弱强化 after=2)时,第二次 insert
        # 会错位到基础阶段之前。现按偏移累计修正,并把插入记录映射为 InsertedStage 契约
        # (v1.0 直接塞入内部 dict,键名 filled_stage 与 §2.3 InsertedStage.stage 不符,缺陷 D3)。
        applied = 0
        base_flow["inserted_stages"] = []
        for ins in sorted(insertions, key=lambda x: x["insert_after_stage_index"]):
            idx = ins["insert_after_stage_index"] + 1 + applied
            base_flow["stages"].insert(idx, ins["filled_stage"])
            base_flow["inserted_stages"].append(InsertedStage(
                reason=ins["reason"],
                target_kp_ids=ins["target_kp_ids"],
                insert_after_stage_index=ins["insert_after_stage_index"],
                stage=ins["filled_stage"]["stage"],
            ))
            applied += 1
        
        return base_flow

```python
class LearningFlowProgressEngine:
    """学习流进度引擎 — 服务端权威的阶段推进与完成判定"""
    
    # 完成判定的最大可信倍率:上报时长超过「内容总时长×倍率」的部分不计入有效学习时长
    MAX_CREDIBLE_TIME_RATIO = 2.0
    # 单条内容浏览的最小有效停留(秒),低于该值视为滑动跳读,不计 viewed
    MIN_EFFECTIVE_VIEW_SECONDS = 5
    
    def __init__(
        self,
        flow_repo: PersonalizedFlowRepository,
        event_repo: LearningFlowEventRepository,
        outbox: OutboxWriter,
        clock: Clock,
    ):
        self.flow_repo = flow_repo
        self.event_repo = event_repo
        self.outbox = outbox
        self.clock = clock
    
    async def on_stage_started(
        self, flow: PersonalizedLearningFlow, stage_index: int
    ) -> PersonalizedLearningFlow:
        """阶段开始:locked→in_progress,幂等(已开始直接返回)"""
        stage = flow["stages"][stage_index]
        guard = self._check_stage_unlock(flow, stage_index)
        if not guard.ok:
            raise FlowGuardError(guard.code, guard.message)
        
        if stage["progress"]["status"] == "in_progress":
            return flow  # 幂等:重复 start 不重复计时
        
        stage["progress"]["status"] = "in_progress"
        stage["progress"]["started_at"] = self.clock.now_iso()
        flow["current_stage_index"] = stage_index
        if flow["status"] == "not_started":
            flow["status"] = "in_progress"
            flow["started_at"] = self.clock.now_iso()
        flow["last_active_at"] = self.clock.now_iso()
        
        await self.event_repo.append(flow, "stage_start", stage_index)
        await self.flow_repo.save(flow)
        return flow
    
    async def on_content_viewed(
        self,
        flow: PersonalizedLearningFlow,
        stage_index: int,
        content_order: int,
        view_seconds: int,
    ) -> PersonalizedLearningFlow:
        """内容浏览上报:仅当停留超过 MIN_EFFECTIVE_VIEW_SECONDS 才计入 viewed"""
        stage = flow["stages"][stage_index]
        content = next(
            (c for c in stage["contents"] if c["order"] == content_order), None
        )
        if content is None:
            raise FlowError(57307, "content not in stage")
        
        credible = min(
            view_seconds,
            int(content["content_ref"]["duration_seconds"] * self.MAX_CREDIBLE_TIME_RATIO),
        )
        if view_seconds < self.MIN_EFFECTIVE_VIEW_SECONDS:
            credible = 0  # 跳读:时长与 viewed 均不计
        
        if credible > 0:
            stage["progress"]["content_viewed_count"] += 1
        stage["progress"]["time_spent_seconds"] += credible
        flow["total_time_spent_seconds"] += credible
        flow["last_active_at"] = self.clock.now_iso()
        
        await self.event_repo.append(
            flow, "content_view", stage_index,
            data={"content_order": content_order, "credited_seconds": credible},
        )
        
        # content_viewed 完成条件即时判定
        if self._criteria_met(stage, "content_viewed"):
            return await self._try_complete_stage(flow, stage_index)
        await self.flow_repo.save(flow)
        return flow
    
    async def on_practice_result(
        self,
        flow: PersonalizedLearningFlow,
        stage_index: int,
        score: float,
        session_id: str,
    ) -> PersonalizedLearningFlow:
        """练习结果回填:来源为练习测评会话服务的 practice.done 事件(不信任客户端直报分数)"""
        stage = flow["stages"][stage_index]
        stage["progress"]["practice_score"] = score
        
        await self.event_repo.append(
            flow, "practice_done", stage_index,
            data={"score": score, "assessment_session_id": session_id},
        )
        
        if self._criteria_met(stage, "practice_passed"):
            return await self._try_complete_stage(flow, stage_index)
        await self.flow_repo.save(flow)
        return flow
    
    async def _try_complete_stage(
        self, flow: PersonalizedLearningFlow, stage_index: int
    ) -> PersonalizedLearningFlow:
        """阶段完成:完成条件判定→解锁下一阶段→全流完成检测(CAS 防双端重复完成)"""
        stage = flow["stages"][stage_index]
        if stage["progress"]["status"] == "completed":
            return flow  # 幂等
        
        # CAS:仅当阶段仍为 in_progress 才允许置 completed,防双端并发
        updated = await self.flow_repo.cas_stage_status(
            flow["flow_id"], stage_index,
            expect="in_progress", target="completed",
        )
        if not updated:
            return await self.flow_repo.get(flow["flow_id"])
        
        stage["progress"]["status"] = "completed"
        stage["progress"]["completed_at"] = self.clock.now_iso()
        
        # 解锁下一个未完成且未跳过的阶段
        self._unlock_next(flow)
        
        # 全流完成检测:全部 required 阶段 completed/skipped
        if self._all_required_done(flow):
            flow["status"] = "completed"
            flow["completed_at"] = self.clock.now_iso()
            await self.event_repo.append(flow, "flow_complete", stage_index)
            # Outbox:学习流完成事件→进度追踪(章节完成度)/学情分析/首页卡片
            await self.outbox.publish("flow.completed", {
                "flow_id": flow["flow_id"],
                "user_id": flow["user_id"],
                "chapter_id": flow["chapter_id"],
                "total_time_spent_seconds": flow["total_time_spent_seconds"],
                "skipped_stages": flow["skipped_stages"],
            })
        
        await self.flow_repo.save(flow)
        return flow
    
    def _criteria_met(self, stage: FilledStage, criteria_type: str) -> bool:
        """完成条件判定(按 CompletionCriteria.type 分派)"""
        criteria = stage["stage"]["completion_criteria"]
        if criteria["type"] != criteria_type:
            return False
        p = stage["progress"]
        total = max(p["content_total_count"], 1)
        if criteria_type == "content_viewed":
            return p["content_viewed_count"] / total >= criteria["threshold"]
        if criteria_type == "practice_passed":
            return (p["practice_score"] or 0) >= criteria["threshold"]
        if criteria_type == "time_spent":
            return p["time_spent_seconds"] >= criteria["threshold"] * 60
        return False  # manual_confirm 需显式接口触发,不在自动判定内
```

**关键设计约束**:

| 约束 | 说明 | 红线 |
|------|------|------|
| 服务端权威判定 | 阶段完成只由服务端依据事件判定,客户端 `complete` 仅对 `manual_confirm` 型阶段生效 | 客户端直报「阶段完成」不生效 |
| 练习分数来源 | `practice_score` 只接受练习测评会话服务的事件回填 | 客户端直报分数一律忽略 |
| 时长可信上限 | 单条内容计时不超 `duration × 2.0`,防挂机刷时长 | 超限部分不计入有效学习时长 |
| required 语义 | `required=true` 阶段不可 skip;optional 阶段 skip 后流仍可完成 | skip 接口对 required 阶段返回 57311 |
| 解锁链 | 仅线性解锁:下一阶段 `available` 当且仅当前序全部 `completed/skipped` | 不允许跳阶段访问(防泄题/防跳过前置补救) |

### 3.5 学习流生命周期(过期/失效/重学/复习)

```python
class FlowLifecycleManager:
    """学习流生命周期管理 — 过期检测、内容失效、重学生成"""
    
    # 学习流有效期:教材版本不变时,生成后 N 天过期(期间画像漂移可容忍)
    DEFAULT_EXPIRY_DAYS = 14
    
    def __init__(self, flow_repo, aggregator, orchestrator, clock):
        self.flow_repo = flow_repo
        self.aggregator = aggregator
        self.orchestrator = orchestrator
        self.clock = clock
    
    async def check_and_handle_stale(self, flow: PersonalizedLearningFlow):
        """内容失效检测:version_hash 不匹配→标记 stale 并生成迁移建议"""
        manifest = await self.aggregator.get_or_build_manifest(
            flow["chapter_id"], flow["textbook_id"] if "textbook_id" in flow else None
        )
        if manifest["version_hash"] == flow.get("content_version_hash"):
            return flow  # 内容未变
        
        # 内容已变:保留历史流,标记 stale(派生标记,非独立状态)
        flow["stale"] = True
        flow["stale_reason"] = "content_version_changed"
        return await self.flow_repo.save(flow)
    
    async def regenerate(
        self,
        user_id: str,
        chapter_id: str,
        textbook_id: str,
        mode: Literal["fresh", "review"] = "review",
    ) -> PersonalizedLearningFlow:
        """
        再生成学习流(重学/复习模式)。
        - fresh: 全新生成,旧活跃流置 abandoned(reason=regenerate_fresh)
        - review: 复习模式生成,已完成阶段按 stage_type 匹配保留 completed 状态,
          仅重排未完成阶段与自适应插入(错开已掌握内容,聚焦薄弱)
        """
        active = await self.flow_repo.get_active(user_id, chapter_id)
        if active:
            active["status"] = "abandoned"
            active["abandoned_reason"] = f"regenerate_{mode}"
            await self.flow_repo.save(active)
        
        new_flow = await self.orchestrator.generate_personalized_flow(
            user_id, chapter_id, textbook_id, force_regenerate=True
        )
        
        if mode == "review" and active:
            new_flow = self._carry_over_completed(new_flow, active)
            await self.flow_repo.save(new_flow)
        
        return new_flow
    
    def _carry_over_completed(
        self, new_flow: PersonalizedLearningFlow, old_flow: PersonalizedLearningFlow
    ) -> PersonalizedLearningFlow:
        """复习模式:按 stage_type + 知识点集合匹配迁移已完成阶段(内容引用以新流为准)"""
        old_done_types = {
            s["stage"]["stage_type"]: s
            for s in old_flow["stages"]
            if s["progress"]["status"] == "completed"
        }
        for stage in new_flow["stages"]:
            matched = old_done_types.get(stage["stage"]["stage_type"])
            if matched and self._kp_overlap_ratio(matched, stage) >= 0.6:
                stage["progress"]["status"] = "completed"
                stage["progress"]["completed_at"] = self.clock.now_iso()
        self._reindex_and_unlock(new_flow)
        return new_flow
```

**生命周期规则表**:

| 场景 | 触发 | 动作 | 说明 |
|------|------|------|------|
| 自然过期 | `expires_at` 到达 | 后台扫描置 `abandoned(reason=expired)` | 不自动重建,用户再进入时按需生成 |
| 内容版本变更 | `version_hash` 不匹配 | 现行流标记 `stale=true` | 客户端收到 `stale` 提示「内容已更新」,由用户选择保留或再生成 |
| 主动放弃 | 用户/家长端锁定 | `abandoned(reason=user_action)` | 进度快照保留在 flow_data,可再生成恢复 |
| 重学(fresh) | 用户章节重学 | 旧流 abandoned → 全新生成 | 对应 D4 修复:函数唯一索引允许多条历史流 |
| 复习(review) | 考前复习/周期回顾 | 保留 completed 阶段,重排薄弱 | 匹配规则:stage_type 相同且知识点重叠 ≥ 0.6 |
| 完成后重开 | flow=completed 再进入 | 生成新流(复习模式默认) | 完成流只读,永不复活 |

### 3.6 缓存一致性与上游内容变更失效

```python
class ManifestInvalidationHandler:
    """清单缓存失效处理器 — 订阅上游内容事件,驱动 version_hash 重算"""
    
    INVALIDATE_TOPICS = [
        "content.resource.published",   # 资源发布/更新/下线
        "content.resource.unpublished",
        "question.bank.updated",        # 题库章节题目增删
        "kp.graph.updated",             # 知识点图谱变更(前置关系/掌握度阈值)
    ]
    
    async def on_content_changed(self, event: dict):
        """内容变更→删除清单缓存(懒重建)→标记 DB 清单 is_active=false"""
        chapter_ids = event.get("chapter_ids", [])
        pipe = self.cache.pipeline()
        db_marks = []
        for cid in chapter_ids:
            # Redis 键按 textbook 维度可能多条,用 SCAN 模式删除
            async for key in self.cache.scan_iter(f"chapter_manifest:{cid}:*"):
                pipe.delete(key)
            db_marks.append(cid)
        await pipe.execute()
        await self.manifest_repo.deactivate_batch(db_marks)
        # 不主动重建:下一次 get_or_build_manifest 懒加载 + singleflight 防击穿
```

**双层缓存一致性**:

| 层 | Key/形式 | TTL | 失效方式 |
|----|----------|-----|----------|
| Redis | `chapter_manifest:{chapter_id}:{textbook_id}` | 1h | 事件驱动删除 + TTL 兜底 |
| Redis | `chapter_flow_template:{subject}:{age_group}` | 24h | 模板管理端发布时主动删除 |
| 本地 LRU | manifest 对象(进程内,容量 512) | 5min TTL + 版本号比对 | version_hash 每次读时比对(轻量:先比 Redis 存储的 hash 快照) |
| singleflight | `sf:manifest:{chapter_id}` (SETNX 3s) | 3s | 并发重建只放行一个执行者,其余等待读结果 |

**version_hash 计算口径**(防止无关字段抖动导致频繁失效):
```
sha256( sorted(kp.id + kp.mastery_threshold + kp.prerequisites)
      + sorted(resource.id + resource.kp_ids + resource.difficulty)
      + question_pool.total_count
      + teaching_requirements.exam_weight )
```
不纳入 `updated_at`、`title` 微调等非学习语义字段。

## 5. 状态机与守卫

### 5.1 学习流状态机 (flow)

```
not_started ──start──▶ in_progress ──pause──▶ paused
                          │  ▲                    │ resume
                          │  └────────────────────┘
              全部required │ 阶段完成
                          ▼
                      completed (终态,只读)
   [not_started/in_progress/paused] ──abandon(expired/user_action/parental_lock/regenerate)──▶ abandoned (终态)
```

**转移表**:

| from | event | to | 守卫 |
|------|-------|----|------|
| not_started | stage_start | in_progress | G2 |
| in_progress | pause(客户端切后台≥60s 或显式暂停) | paused | G3 |
| paused | resume | in_progress | G3 |
| in_progress | all_required_done | completed | G4 |
| not_started/in_progress/paused | abandon | abandoned | G5 |
| 任意活跃态 | 后台过期扫描(expires_at 到达) | abandoned(reason=expired) | G6 |

**派生标记(非独立状态)**:`stale=true`(内容版本变更)、`degraded[]`(生成降级痕迹)。

### 5.2 阶段状态机 (stage)

```
locked ──unlock(前序全完成)──▶ available ──start──▶ in_progress ──criteria_met──▶ completed
                                  │                                        (CAS)
                                  └──skip(仅optional)──▶ skipped (终态)
```

| from | event | to | 守卫 |
|------|-------|----|------|
| locked | 前序阶段全部 completed/skipped | available | G7(线性解锁链) |
| available | stage_start | in_progress | G8 |
| in_progress | criteria_met(自动) / manual_confirm | completed | G9(CAS 防双端) |
| available/in_progress | skip | skipped | G10(仅 optional) |
| locked | skip | — | 拒绝:未解锁阶段不可跳 |

### 5.3 清单缓存生命周期

`BUILDING(singleflight 持有者) → READY → STALE(上游内容事件/TTL 到达,懒重建)`

### 5.4 守卫总表 G1-G15

| 守卫 | 场景 | 规则 |
|------|------|------|
| G1 | 并发生成 | 函数唯一索引 `uk_user_chapter_active` 兜底,双活跃流插入冲突→返回已存在流 |
| G2 | 首阶段启动 | 仅 `current_stage_index` 指向或其后已解锁阶段可 start |
| G3 | 暂停语义 | paused 期间时长不累计(viewed 上报在 paused 流上返回 57312) |
| G4 | 全流完成 | required 全部 completed/skipped 才置 completed;插入的 required 补救阶段计入 |
| G5 | abandon 权限 | 仅本人/家长管控/系统三类来源;completed 流不可 abandon |
| G6 | 过期扫描 | 批量 CAS,单批 500;过期流 abandon 后 30 天归档到冷表 |
| G7 | 线性解锁 | 不提供「跳阶段访问」;客户端预加载下一阶段内容仅限 `available` 之后 |
| G8 | 阶段互斥 | 同一时刻一个流仅一个阶段 in_progress(跨阶段乱序上报返回 57313) |
| G9 | 完成互斥 | `cas_stage_status(expect=in_progress)` 双端并发仅一次生效、一次幂等返回 |
| G10 | skip 限制 | required 阶段 skip → 57311;插入的 `prerequisite_remedy` 为 required 不可跳 |
| G11 | 练习分数 | practice_score 仅接受测评会话服务事件,客户端直报忽略并埋点 `flow_cheat_attempt` |
| G12 | 模板 schema | stage_sequence 非空、slot min≤max、completion_criteria.type 合法 |
| G13 | 模板下线 | 被 ≥1 活跃流引用的模板不可删除;下线仅影响新生成,存量流不受影响 |
| G14 | 内容可见性 | 填充结果只引用 `is_active=true` 且适龄等级匹配的资源(适龄标签过滤) |
| G15 | stale 流写保护 | `stale=true` 的流允许继续学(旧内容仍有效)但禁止 stage skip/complete 迁移类写操作冲突 |

## 6. 幂等与并发控制

| # | 场景 | 机制 | 裁决 |
|---|------|------|------|
| 1 | 重复点击生成 | Idempotency-Key 24h 去重表 | 同键返回同 flow_id |
| 2 | 双设备并发生成 | `uk_user_chapter_active` 函数唯一索引 | 后插入者捕获 1062 → 读回先创建者返回 |
| 3 | 双端同阶段完成 | CAS(expect=in_progress→completed) | 一端生效,另一端幂等返回最新流 |
| 4 | viewed 重复上报 | `(flow_id, stage_index, content_order)` 事件表唯一键 | 只计一次 viewed,时长取首次可信值 |
| 5 | 练习结果重复投递 | 测评服务 `practice.done` 事件携带 `assessment_session_id` 去重表 | 幂等消费 |
| 6 | regenerate 与并发 stage 写 | regenerate 前先 CAS 旧流→abandoned;阶段写携带 flow 状态版本号 | 旧流上的在途写全部拒绝(57314 流已废弃) |
| 7 | 清单并发重建 | Redis singleflight(SETNX 3s)+ DB 唯一主键 upsert | 一个执行者重建,等待者 200ms 轮询读 |
| 8 | 过期扫描与用户操作竞态 | 两者同为 CAS abandon;已 completed 流过期扫描跳过 | 用户操作优先,扫描幂等跳过 |

**并发写一致性**:flow 为聚合根,单流写走 `flow_version`(乐观锁,flow_data JSON 内 `meta.version`);冲突时客户端收到 409 + 最新流快照,以服务端为准重放未确认操作。

| `question.bank.updated` | 题库服务 | 同上 | chapter_id + updated_seq |

### 7.3 对账

Relay 日终对账:比对 `flow_outbox`(当日 SENT/FAILED)与下游消费确认表,FAILED 重投 5 次退避(1m/5m/15m/1h/6h),超限告警人工介入;`flow.completed` 类事件额外做「进度追踪服务章节完成度反向核对」差异日报。

    ADD COLUMN idempotency_key VARCHAR(128) NULL COMMENT '(flow_id:stage_index:content_order) viewed 去重',

    ADD INDEX idx_client_event (client_event_id);

-- personalized_learning_flows 增补
ALTER TABLE personalized_learning_flows
    ADD COLUMN flow_version    INT          NOT NULL DEFAULT 1 COMMENT '乐观锁版本号',
    ADD COLUMN stale           BOOLEAN      NOT NULL DEFAULT FALSE,
    ADD COLUMN stale_reason    VARCHAR(64)  NULL,
    ADD COLUMN abandoned_reason VARCHAR(64) NULL,
    ADD COLUMN mode            ENUM('fresh','review') NOT NULL DEFAULT 'fresh',
    ADD COLUMN content_version_hash VARCHAR(64) NULL,
    ADD COLUMN degraded        JSON         NULL COMMENT '生成降级痕迹数组';

-- §2.4 D4 修复的存量迁移(uk_user_chapter_active 上线前置)
-- 步骤:1) 清洗同一(user,chapter)多条活跃流(保留 last_active_at 最新,其余置 abandoned)
--       2) 影响行数入迁移报告;3) 再创建函数唯一索引
UPDATE personalized_learning_flows t
JOIN (
    SELECT flow_id FROM (
        SELECT flow_id,
               ROW_NUMBER() OVER (
                   PARTITION BY user_id, chapter_id
                   ORDER BY last_active_at DESC, flow_id DESC
               ) AS rn
        FROM personalized_learning_flows
        WHERE status IN ('not_started','in_progress','paused')
    ) x WHERE x.rn > 1
) d ON t.flow_id = d.flow_id
SET t.status = 'abandoned', t.abandoned_reason = 'migration_dedup';

## 10. 降级矩阵 D1-D10

| # | 故障 | 降级行为 | 红线 |
|---|------|----------|------|
| D1 | 用户画像服务不可用 | 画像置空,按年龄组默认策略生成,degraded 标记 `profile_unavailable` | 仍可生成(清单+模板本地即可),不因画像故障阻断学习 |
| D2 | 题库服务不可用 | weak_practice/challenge 槽位跳过,阶段内仅保留讲解资源,degraded 标记 `question_unavailable` | 不虚构题目数量;content_total_count 如实 |
| D3 | 资源服务不可用 | 槽位填充失败阶段整体跳过(fallback 到模板最少必选阶段),degraded 标记 | preview/concept 核心阶段不可用时返回 503 不空壳流 |
| D4 | 知识点服务不可用 | 无法确定前置缺口→跳过插入,退化为纯模板流 | 同 D1,不阻断 |
| D5 | Redis 不可用 | 清单/模板直接读 DB(限流并发,PG 连接池隔离),singleflight 退化为 DB 行锁 | 读吞吐降 60% 但功能完整;幂等改 DB 唯一键兜底 |
| D6 | 进度追踪服务不可用 | 掌握度取本地 10min 快照;快照过期→视为首次学习 | 宁可保守(默认难度)不误判 |
| D7 | Outbox 投递失败 | 事件积压重试退避,flow 核心写入不受影响 | 事件最终一致,不丢(对账兜底) |
| D8 | 测评会话服务不可用 | practice 阶段可 start 但 complete 阻塞于 practice_passed 条件→允许 manual_confirm 兜底(仅降级期) | 兜底开关走远程配置,默认关 |
| D9 | 模板缓存未命中且 DB 慢 | 回退内置 DEFAULT_STAGE_SEQUENCE + 年龄组策略 | 内置序列随版本发布,不依赖 DB |
| D10 | 内容适龄标签缺失 | 该资源不进入候选(过滤优先) | 宁缺毋滥,适龄过滤永不降级放行 |

**总原则**:生成链路所有降级必须显式落到 `degraded[]` 并透出客户端;任何降级不允许下发未过审/适龄标签缺失内容。

## 14. 验收场景(18 条)

1. 首次进入章节→生成流:primary_low 学生得到 4 必选阶段、动画/交互优先,首个阶段 available,其余 locked。
2. 前置缺口学生:插入 `prerequisite_remedy`(required,位置=预习后),话术无否定词;完成后下一阶段才解锁。
3. 双插入偏移验证:D2 修复后同时存在前置补救(after=0)与薄弱强化(after=2)时,插入顺序与索引正确(回归 v1.0 缺陷)。
4. 章节重学:completed 流再生成→新流创建成功,旧流保留历史(函数唯一索引,回归 D4)。
5. 复习模式再生成:同 stage_type 且知识点重叠 ≥0.6 的已完成阶段保留 completed。
6. 同键重复 generate(Idempotency-Key)→返回同一 flow_id。
7. 双设备并发点击生成→仅一条活跃流,后到者读回。
8. 双端同时完成同一阶段→一次生效一次幂等,CAS 冲突指标 +1。
9. viewed 上报停留 3 秒→不计 viewed 不计时长;重复上报同 order→只计一次。
10. 挂机上报 3600 秒(内容时长 150 秒)→仅计 300 秒,cheat 事件发出。
11. required 阶段 skip→57311;optional 阶段 skip→skipped 且流可完成。
12. 答题分数客户端直报→忽略 + flow_cheat_attempt 埋点;经测评服务事件回填→生效。
13. 内容服务发布新资源版本→缓存失效→stale 流读取返回 57309 + new_version_hash。
14. 画像服务宕机→生成成功但 degraded=[profile_unavailable],难度为年龄组默认。
15. 过期扫描(04:30)→expired 流批量 abandon,完成流不受影响。
16. 模板被活跃流引用时删除→57320;下线→新流用新模板,存量流不受影响。
17. gRPC 批量 summary(100 用户)→P99 < 100ms(Redis 命中路径)。
18. Outbox 事件对账:当日 flow.completed 与进度服务章节完成度差异=0。
