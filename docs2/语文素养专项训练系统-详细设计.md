## 1. 概述

### 1.1 功能目标

语文素养专项训练系统是语文学科智能辅导引擎下的独立专项模块，覆盖"语言积累与运用"层的基础能力训练，包含四个子域：

| 子域 | 训练目标 | 覆盖学段 |
|------|----------|----------|
| 成语积累与运用 | 成语释义、语境运用、辨析（望文生义/褒贬误用/对象误用）、积累打卡 | 小学高年级、初中、高中 |
| 病句辨析与修改 | 六大病句类型识别、修改符号运用、语病修改实操 | 初中、高中（小学仅作语感启蒙） |
| 文学与文化常识 | 作家作品、文学流派、文化常识（称谓/礼仪/节日/典故/书法/天干地支等）、名著常识 | 小学、初中、高中 |
| 名著导读 | 新课标必读名著的结构化导读、章节阅读任务、阅读检测题、阅读打卡与进度追踪 | 小学高年级、初中、高中 |

系统提供：**每日积累推送 → 专项练习 → AI 即时讲解 → 错题联动 → 掌握度更新 → 学情报告沉淀** 的完整闭环。

### 1.2 学段差异设计

| 维度 | 小学 | 初中 | 高中 |
|------|------|------|------|
| 成语重点 | 常用成语 300-500 个，看图猜成语、成语接龙游戏化 | 成语 800-1200 个，语境辨析、近义成语对比 | 成语 1500+，文言成语溯源、褒贬与谦敬辨析 |
| 病句重点 | 仅语感训练（长句读顺、成分残缺感知） | 六大类型全覆盖，单句修改 | 病句类型细分（搭配/语序/结构混乱）、长难句、语段修改 |
| 常识重点 | 神话寓言、传统节日、基本作家（李白/杜甫等） | 课内作家作品、文学体裁、文化常识基础 | 文学史脉络、流派风格、文化常识拓展（官职/纪年/科举） |
| 名著重点 | 快乐读书吧书目，亲子共读 | 初中必读 12 部，章节导读 + 检测 | 高中必读与自主阅读书目，深度探究题 |
| 反馈方式 | 游戏化、鼓励式、配图 | 规范解析、错因归类 | 学术性解析、拓展链接 |

**边界说明**：本模块只做"语言积累与运用 + 名著阅读任务管理"；阅读理解训练由「中小学语文阅读理解专项训练」负责；古诗文背诵默写由「文科背诵」「古诗文专项学习系统」负责；作文能力由「作文辅导」负责。本模块的题目产出统一进错题本与学情分析。

### 1.4 名词约定

- **积累项（AccumulationItem）**：一条可学习的最小知识单元，一条成语、一条文化常识、一个作家作品知识点。
- **练习会话（PracticeSession）**：一次专项练习，默认 10 题，可配置。
- **名著（ClassicWork）**：结构化管理的文学名著书目条目。
- **阅读任务（ReadingTask）**：针对某部名著的章节级阅读 + 检测任务。
- **素养维度（LiteracyDimension）**：评估模型的能力分域：IDIOM / SENTENCE / CULTURE / CLASSIC_READING。

## 2. 核心概念与领域模型

### 2.1 领域实体关系

```text
LiteracyCategory(素养分类)
  ├── IDIOM 成语
  ├── SENTENCE 病句
  ├── CULTURE 文学文化常识
  └── CLASSIC_READING 名著导读

AccumulationItem(积累项) 1 ─── n AccumulationRecord(学生积累记录)
Question(题目, 复用题库统一模型) n ─── n 本模块练习会话
PracticeSession(练习会话) 1 ─── n PracticeAnswerRecord(答题记录)
ClassicWork(名著) 1 ─── n ClassicChapter(章节) 1 ─── n ReadingTask(阅读任务)
ReadingTask 1 ─── n ReadingTaskItem(任务项) 
ReadingTaskItem n ─── 1 Question(检测题)
StudentLiteracyProfile(素养画像) ← 聚合 PracticeAnswerRecord + ReadingTask 数据
```

### 2.2 领域枚举

```java
/** 素养子域分类 */
public enum LiteracyCategory {
    IDIOM("成语积累与运用"),
    SENTENCE("病句辨析与修改"),
    CULTURE("文学与文化常识"),
    CLASSIC_READING("名著导读");

    private final String label;
    LiteracyCategory(String label) { this.label = label; }
    public String getLabel() { return label; }
}

/** 成语练习题型 */
public enum IdiomQuestionType {
    IDIOM_EXPLAIN,        // 根据成语选释义
    IDIOM_USAGE,          // 语境中判断使用是否正确
    IDIOM_FILL_BLANK,     // 根据释义/语境填成语
    IDIOM_DISCRIMINATE,   // 近义成语辨析选择
    IDIOM_DERIVATION      // 成语典故溯源（来源故事选择/排序）
}

/** 病句六大类型（细分到小类） */
public enum SentenceErrorType {
    MISSING_COMPONENT("成分残缺"),
    REDUNDANT_COMPONENT("成分赘余"),
    MATCHING_ERROR("搭配不当"),
    ORDER_ERROR("语序不当"),
    STRUCTURE_CONFUSION("结构混乱"),
    TABLE_MEANING("表意不明"),
    ILL_LOGIC("不合逻辑");

    private final String label;
    SentenceErrorType(String label) { this.label = label; }
    public String getLabel() { return label; }
}

/** 文化常识分类 */
public enum CultureCategory {
    AUTHOR_WORK("作家作品"),
    LITERARY_GENRE("文学体裁与流派"),
    TRADITIONAL_FESTIVAL("传统节日"),
    ADDRESS_ETIQUETTE("称谓与礼仪"),
    HISTORICAL_ALLUSION("历史典故"),
    CALLIGRAPHY_ART("书法与传统文化艺术"),
    TIME_CALENDAR("纪年计时"),
    CUSTOM_GEOGRAPHY("民俗与地域文化"),
    CLASSIC_COMMON("经典常读"),
    OTHER("其他")
}

/** 练习会话状态 */
public enum PracticeSessionStatus {
    GENERATING,   // 生成中（AI 出题）
    IN_PROGRESS,  // 进行中
    SUBMITTED,    // 已交卷，批改中
    FINISHED,     // 已完成（批改完毕，结果可见）
    EXPIRED       // 已过期（24h 未完成自动过期）
}

/** 阅读任务状态 */
public enum ReadingTaskStatus {
    NOT_STARTED,
    IN_PROGRESS,
    COMPLETED,
    ABANDONED
}
```

## 3. 数据库设计

> 统一使用 InnoDB / utf8mb4。金额与时间字段规范、审计字段（created_at / updated_at / deleted）遵循《服务端-核心领域模型与统一领域语言定义规范》。题目主表 `question` 复用《题目管理与题库系统》的统一模型，本模块仅扩展标签与业务关联表。

### 3.1 积累项主表 `literacy_accumulation_item`

```sql
CREATE TABLE literacy_accumulation_item (
  id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  category        VARCHAR(32)  NOT NULL COMMENT ' LiteracyCategory',
  sub_type        VARCHAR(64)  NOT NULL DEFAULT '' COMMENT '细分类型：病句大类/文化常识分类/成语等级',
  title           VARCHAR(255) NOT NULL COMMENT '积累项标题，如成语本身、常识条目名',
  content_json    JSON         NOT NULL COMMENT '内容载荷，结构随子域变化，见 3.2',
  grade_range     VARCHAR(32)  NOT NULL COMMENT '适用年级范围，如 4-6/7-9/10-12，格式: start-end',
  textbook_tags   JSON         NULL COMMENT '关联教材章节/单元标签 [{textbookId, chapterId}]',
  knowledge_point_ids JSON     NULL COMMENT '关联知识点ID数组',
  difficulty      TINYINT      NOT NULL DEFAULT 3 COMMENT '难度 1-5',
  source          VARCHAR(32)  NOT NULL DEFAULT 'EDITORIAL' COMMENT 'EDITORIAL编辑录入/AI_GENERATED/IMPORTED',
  review_status   VARCHAR(16)  NOT NULL DEFAULT 'APPROVED' COMMENT 'PENDING/APPROVED/REJECTED，AI生成需审核',
  usage_count     INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '被引用练习次数',
  created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted         TINYINT      NOT NULL DEFAULT 0,
  KEY idx_category_grade (category, grade_range),
  KEY idx_review (review_status)
) COMMENT='语文素养积累项主表';
```

```sql
CREATE TABLE literacy_accumulation_record (
```

## 5. 子域二：病句辨析与修改训练

### 5.1 内容范围与能力阶梯

```
Level 1 (小学, 语感启蒙): 长句朗读通顺度判断、明显重复成分感知（非术语化呈现）

Level 3 (高中): 六大类型细分小类判断 + 语段多处语病修改 + 表达效果比较
```

### 5.2 练习题型与判题规则

| 题型 | 交互 | 判题方式 | 满分 |
|------|------|----------|------|
| SENTENCE_JUDGE | 判断句子是否有语病 | 精确匹配 | 10 |
| SENTENCE_TYPE_SELECT | 选出病句并判断类型 | 双维判分：选对病句 6 分 + 类型对 4 分 | 10 |
| SENTENCE_MODIFY | 给出病句，学生输入/点选修改后句子 | 与标准修改精确匹配；非标准修改转 AI 批改（语义等价判定） | 10 |

**AI 批改规则（SENTENCE_MODIFY 非标准答案）**：

1. 调用 AI 引擎做"语义等价 + 语病消除"双重判定（Prompt 见 §8.2）。
2. AI 返回 `equivalent: true/false` + `reason`，置信度低于 0.85 或模型超时 → 转人工标注队列（见「AI对话质量抽样审核与标注工作台服务」）。
3. AI 批改耗时计入会话，超过 8s 前端展示"批改中"占位并异步回推（SSE，见「SSE流式响应与AI增量渲染引擎」）。

**错因标签**：直接复用 `SentenceErrorType` 枚举值。

## 11. 关键代码示例

### 11.1 创建练习会话（幂等 + 防并发）

```java
@Service
@RequiredArgsConstructor
public class LiteracyPracticeService {

    private final LiteracyPracticeSessionMapper sessionMapper;
    private final QuestionAssemblyService questionAssemblyService;
    private final IdempotentService idempotentService;
    private final EventBus eventBus;

    @Transactional
    public CreateSessionResult createSession(Long studentId, CreateSessionRequest req) {
        // 1. 幂等校验：同 idempotentKey 直接返回历史会话
        var existed = sessionMapper.findByIdempotentKey(studentId, req.getIdempotentKey());
        if (existed != null) {
            return CreateSessionResult.of(existed, true);
        }
        // 2. 进行中的会话互斥：同 category 仅允许一个 IN_PROGRESS
        var active = sessionMapper.findActive(studentId, req.getCategory());
        if (active.isPresent()) {
            throw new BizException(ErrorCode.LITERACY_SESSION_ACTIVE_EXISTS, active.get().getId());
        }
        // 3. 创建会话（状态 GENERATING），异步装配题目
        var session = LiteracyPracticeSession.builder()
                .sessionNo(NoGenerator.next("PT-LIT"))
                .studentId(studentId)
                .category(req.getCategory())
                .subType(Strings.nullToEmpty(req.getSubType()))
                .questionCount(clamp(req.getQuestionCount(), 5, 20, 10))
                .status(PracticeSessionStatus.GENERATING)
                .idempotentKey(req.getIdempotentKey())
                .build();
        sessionMapper.insert(session);

        // 4. 异步装配（AI 出题或题库抽题），完成后状态 → IN_PROGRESS 并推送 SSE
        questionAssemblyService.assembleAsync(session.getId());
        return CreateSessionResult.of(session, false);
    }
}
```

### 11.2 病句修改题判题（规则 + AI 兜底）

```java
@Component
public class SentenceModifyGrader implements QuestionGrader {

    private final AiJudgeClient aiJudgeClient;
    private final AiGradingCache cache;

    @Override
    public GradeResult grade(Question question, JsonNode studentAnswer) {
        var standard = question.getStandardAnswer();
        String studentText = studentAnswer.path("text").asText();

        // 1. 规则精确匹配（容忍全半角与空白差异）
        if (TextNormalize.equalsLoose(studentText, standard.path("text").asText())) {
            return GradeResult.correct(10, 10);
        }
        // 2. 标准答案多解逐一匹配
        for (JsonNode alt : standard.path("alternatives")) {
            if (TextNormalize.equalsLoose(studentText, alt.asText())) {
                return GradeResult.correct(10, 10);
            }
        }
        // 3. AI 语义等价批改（带缓存）
        String cacheKey = CacheKeys.sentenceGrading(question.getId(), studentText);
        return cache.getOrCompute(cacheKey, Duration.ofHours(24), () ->
            aiJudgeClient.judgeSentenceModify(
                standard.path("original").asText(),
                question.getErrorType(),
                standard.path("text").asText(),
                studentText
            )
        ).toGradeResult();
    }
}
```

## 12. 状态流转

### 12.1 练习会话状态机

```
                装配成功(题目就绪)         整卷提交            判题完成
GENERATING ──────────────────▶ IN_PROGRESS ─────────▶ SUBMITTED ────────▶ FINISHED
     │                            │                                            ▲
     │ 装配失败(重试3次仍失败)      │ 创建后24h未提交                               │ AI批改回调回填
     ▼                            ▼                                            │
  FAILED(可重试创建)           EXPIRED(定时任务扫描: created_at+24h) ───────────┘
                                                              (SUBMITTED超时30min未完成批改→FINISHED并标记异常)
```

**迁移约束**：

| 迁移 | 触发 | 守卫条件 |
|------|------|----------|
| GENERATING → IN_PROGRESS | 装配完成事件 | question_ids 非空且长度=question_count |
| GENERATING → FAILED | 装配重试耗尽 | 记录失败原因，释放用户该 category 的互斥锁 |
| IN_PROGRESS → SUBMITTED | 整卷提交 | 所有题目均有作答或明确跳过标记 |
| SUBMITTED → FINISHED | 判题全部完成 | AI 批改项全部回调或超时降级（人工队列） |
| IN_PROGRESS → EXPIRED | 定时扫描 | created_at 超过 24h；EXPIRED 不计入学情统计 |

### 12.2 阅读任务状态机

```
NOT_STARTED ──(章节阅读心跳/开始检测)──▶ IN_PROGRESS ──(checkCompletion=true)──▶ COMPLETED
     │                                        │
     │                                        └──(学生放弃/计划过期)──▶ ABANDONED
     └──(由学习计划服务按计划日期自动创建后即为 NOT_STARTED)
```

### 12.3 积累项学习状态（单学生单积累项）

```
NEW ──(首次学习)──▶ LEARNING ──(复习按SM-2变体调度)──▶ REVIEWING ⇄ MASTERED
                                   │  连续答错 → memory_stage 回退
                                   ▼
                              STRUGGLING(薄弱标记,进入错题联动推荐)
```

## 13. 错误处理与边界条件

### 13.1 业务错误码（统一前缀 `LIT`，注册进《服务端统一业务异常码与错误分类体系》）

| 错误码 | HTTP | 说明 | 前端处理 |
|--------|------|------|----------|
| `LIT_SESSION_ACTIVE_EXISTS` | 409 | 同子域存在进行中的练习会话 | toast + 跳转继续原会话 |
| `LIT_SESSION_EXPIRED` | 410 | 会话已过期 | 提示重新开始 |
| `LIT_SESSION_NOT_READY` | 425 | 题目装配中 | 客户端继续轮询/SSE 等待 |
| `LIT_AI_GRADING_TIMEOUT` | 200* | AI 批改超时进入人工队列 | 展示"批改中，稍后查看结果"（异步回推） |
| `LIT_ITEM_NOT_FOUND` | 404 | 积累项不存在或已下线 | 常规空态 |
| `LIT_TASK_ALREADY_COMPLETED` | 409 | 阅读任务重复提交 | 返回已有成绩 |
| `LIT_CONTENT_NOT_APPROVED` | 403 | 内容未过审不可练习 | 换题重试 |

\* 业务码层面正常返回，data 中标注 `gradingStatus=PENDING`。

### 13.2 边界条件

| 场景 | 处理 |
|------|------|
| AI 出题全部失败 | 降级为题库同知识点抽题；题库也不足 → `LIT_CONTENT_NOT_APPROVED`，返回可练习的其他子域推荐 |
| 病句修改学生答案为空/无关文本 | 判 0 分，错因 `NO_ATTEMPT`，不做 AI 调用 |
| 学生年级变更（如初一→初二） | 画像保留，grade_range 过滤即时生效；已创建未完成任务不强制终止 |
| 积累项被内容下线 | 在练习中引用已下线题目 → 该题跳过并补题，答案记录保留 |
| 同一成语大小写/简体繁体输入 | `TextNormalize` 统一：去空白、全半角归一、简体归一后匹配 |
| 阅读时长刷量 | 单章节有效时长上限 = 字数/150字每分钟，超出截断；异常行为上报「用户学习行为异常检测与作弊行为识别服务」 |
| 名著版权到期 | work 状态 → OFFLINE，未开始任务不可创建，进行中任务允许完成但不推新任务（「教育内容版权到期预警与授权内容自动下线替换引擎」联动） |

### 13.3 降级策略

- AI 批改不可用（供应商故障）：修改题按"仅标准答案精确匹配"判分，主观题标记 `PENDING` 排队，恢复后批量回填，符合「错误处理与服务降级策略」。
- AI 讲解不可用：返回积累项内置 `content_json` 静态讲解（编辑预置）。

### 13.4 幂等与并发

- 所有 POST 创建类接口必须携带 `idempotentKey`（UUID），服务端 `(student_id, idempotent_key)` 唯一约束兜底（见《接口幂等性与防重提交机制》）。
- 整卷提交使用乐观锁：`UPDATE ... SET status='SUBMITTED' WHERE id=? AND status='IN_PROGRESS'`，影响行数=0 即重复提交，返回已有结果。

## 14. 缓存与性能策略

| 数据 | 策略 | TTL |
|------|------|-----|
| 积累项详情 | 本地缓存(Caffeine) + Redis 二级 | Redis 30min，变更消息失效 |
| 今日积累卡片 | Redis，按 (studentId, date) 键 | 24h |
| 名著书目列表 | Redis + CDN 封面图 | 1h |
| AI 批改结果 | Redis，(questionId+answerHash) | 24h |
| 素养画像 | Redis 最新快照 | 1天，批计算后主动刷新 |

- 练习会话装配走异步线程池（独立池 `literacy-assembly`，不与主请求线程竞争，见《服务端-线程池与异步执行资源统一治理规范》）。
- 高频接口（卡片/详情）P99 < 200ms；练习创建 P95 < 500ms（异步装配）；AI 批改 P95 < 8s。
