# 英语词汇记忆与单词本系统 - 详细设计

> **版本**: v1.0 | **日期**: 2026-06-02 | **状态**: 细化完成
> **关联文档**: 英语专项学习与口语陪练、文科背诵、间隔重复算法与遗忘曲线复习调度引擎、语音服务(ASR-TTS)、学情分析、同步课堂学习、练习与测评系统、用户学习画像与能力维度模型

## 1. 模块概述

### 1.1 功能定位

英语词汇记忆与单词本系统面向小学至高中全学段学生，提供 **单词学习、词汇练习、单词本管理、词汇量评估、记忆曲线复习调度** 五大核心能力。本系统作为英语专项学习的子模块，与口语陪练、听力训练等互补，形成完整的英语学习闭环。

**一句话定位：** 为每位学生构建个性化的英语词汇习得体系，从生词发现到长期记忆到灵活运用。

### 1.2 核心能力

| 能力 | 说明 | 优先级 | MVP |
|------|------|--------|-----|
| 单词卡片学习 | 展示单词、音标、释义、例句、发音 | P0 | ✅ |
| 单词本管理 | 自动收录 + 手动添加生词，分类管理 | P0 | ✅ |
| 词汇练习 | 拼写、选词、连线、听写等多种题型 | P0 | ✅ |
| 记忆曲线复习 | 基于间隔重复算法自动安排复习 | P0 | ✅ |
| 词汇量评估 | 动态评估学生词汇量并给出等级 | P1 | ❌ |
| 词根词缀学习 | 通过词根词缀帮助理解单词构成 | P2 | ❌ |
| 词汇竞赛/挑战 | 与同学或 AI 进行词汇 PK | P2 | ❌ |
| 每日一词推送 | 每天推送一个适合当前水平的单词 | P2 | ❌ |

### 1.3 与其他模块的关系

```
英语专项学习与口语陪练 ──► 上层入口，本模块为子能力
    │
```

|---------|------|---------|

### 1.4 学段差异

| 学段 | 词汇范围 | 单词本容量上限 | 重点练习类型 | 词汇量目标 |
|------|---------|--------------|------------|-----------|
| 小学(3-4年级) | 教材单词 + 基础常见词 | 500词 | 图文配对、听音选词、跟读 | 300-600 |
| 小学(5-6年级) | 教材单词 + KET 词汇 | 1000词 | 拼写、选词填空、英汉互选 | 600-1200 |
| 初中 | 教材单词 + 中考考纲词汇 | 3000词 | 拼写、语境选词、词义辨析、听写 | 1500-2500 |
| 高中 | 教材单词 + 高考考纲词汇 | 5000词 | 语境应用、词形变化、搭配、听写 | 3000-4500 |

## 2. 整体流程

### 2.1 用户学习流程

```
用户进入词汇模块
    │
    ├─── 首次使用 ──────► 词汇量评估(快速测试) ──► 生成初始词汇计划
    │
    ├─── 日常学习 ──┬──► 今日新词学习（单词卡片 + 发音 + 例句）
    │               ├──► 今日复习（间隔重复调度）
    │               └──► 词汇练习（多种题型）
    │
    ├─── 单词本管理 ──┬──► 查看全部生词（按状态/学科/时间筛选）
    │                 ├──► 手动添加生词（输入/拍照）
    │                 └──► 批量导入（教材单元/考纲词表）
    │
    └─── 数据总览 ──────► 已掌握/学习中/待学习统计 + 词汇量曲线
```

### 2.2 单词学习状态流转

```
                    ┌──────────┐
     首次收录/添加 ──►│  NEW     │  新词
                    └────┬─────┘
                         │ 学习一次后
                         ▼
                    ┌──────────┐
                    │ LEARNING │  学习中
                    └────┬─────┘
                         │ 复习通过次数达标
          ┌──────────────┤
          │              │ 复习失败/多次错误
          ▼              ▼
    ┌──────────┐   ┌──────────┐
    │ MASTERED │   │ WEAK     │  薄弱词
    │  已掌握   │   │ (退回复习)│
    └────┬─────┘   └────┬─────┘
         │              │
         │  长期未复习    │ 重新学习通过
         │  掌握度衰减    │
         ▼              │
    ┌──────────┐        │
    │ FADING   │◄───────┘
    │ 需要巩固  │
    └──────────┘
```

### 2.3 词汇练习完成流程

```
开始练习（选择练习类型和词源范围）
    │
    ▼
展示题目（根据题型渲染不同 UI）
    │
    ▼
用户作答 ──┬──► 正确 ──► 展示解析 ──► 更新掌握度(+)
           │
           └──► 错误 ──► 展示正确答案 + 解析 ──► 更新掌握度(-)
                            │
                            ▼
                       错词自动收录到单词本
                            │
                            ▼
                    注册/更新间隔重复复习项
                            │
                            ▼
                    完成本题 ──► 下一题
                            │
                            ▼（全部完成）
                    展示练习报告（正确率、用时、薄弱词）
```

## 3. 数据结构设计

### 3.1 核心实体

#### 3.1.1 词汇主表 `vocab_word`

```sql
CREATE TABLE vocab_word (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '单词ID',
    word              VARCHAR(100) NOT NULL COMMENT '单词拼写',
    phonetic_us       VARCHAR(100) COMMENT '美式音标 (KK音标)',
    phonetic_uk       VARCHAR(100) COMMENT '英式音标 (IPA)',
    pos_list          JSON COMMENT '词性列表: [{"pos":"n","zh":"名词"},{"pos":"v","zh":"动词"}]',
    definitions       JSON NOT NULL COMMENT '释义列表: [{"pos":"n","zh":"苹果","en":"a round fruit"}]',
    difficulty        TINYINT NOT NULL COMMENT '难度等级 1-10',
    cefr_level        CHAR(2) COMMENT 'CEFR等级: A1/A2/B1/B2/C1/C2',
    grade_range       VARCHAR(200) COMMENT '适用学段: primary3,primary4,junior1...',
    frequency_rank    INT COMMENT '词频排名 (COCA/BNC)',
    word_length       TINYINT COMMENT '单词长度 (冗余加速查询)',
    syllable_count    TINYINT COMMENT '音节数',
    audio_us_url      VARCHAR(500) COMMENT '美式发音音频URL',
    audio_uk_url      VARCHAR(500) COMMENT '英式发音音频URL',
    example_sentences JSON COMMENT '例句: [{"en":"...","zh":"...","audio_url":"..."}]',
    collocations      JSON COMMENT '常见搭配: ["make a decision","decision making"]',
    synonyms          JSON COMMENT '同义词: ["choice","resolution"]',
    antonyms          JSON COMMENT '反义词: ["hesitation"]',
    word_family       JSON COMMENT '词族: {"decide":"v","decision":"n","decisive":"adj"}',
    etymology         VARCHAR(500) COMMENT '词源简述',
    root_affix        JSON COMMENT '词根词缀: {"root":"decide","suffix":"-sion"}',
    tags              JSON COMMENT '标签: ["高考核心","中考高频","易混淆","形近词"]',
    textbook_refs     JSON COMMENT '教材关联: [{"textbook_id":1,"chapter_id":101,"unit":"Unit 3"}]',
    status            TINYINT DEFAULT 1 COMMENT '1-有效 0-无效',
    created_at        DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at        DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_word (word),
    INDEX idx_cefr (cefr_level),
    INDEX idx_difficulty (difficulty),
    INDEX idx_grade (grade_range(50)),
    INDEX idx_frequency (frequency_rank)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='英语词汇主表';
```

### 3.2 Redis 缓存结构

```
# 用户今日词汇学习计划
vocab:daily_plan:{user_id}:{date}  → Hash {
    new_word_ids: "w1,w2,w3,...",       # 今日新词ID列表
    review_word_ids: "w10,w11,...",      # 今日复习词ID列表
    new_target: 15,                      # 今日新词目标数
    new_completed: 3,                    # 已完成新词数
    review_completed: 5,                 # 已完成复习数
    total_time_ms: 120000                # 今日累计学习时长
}
TTL: 48h

# 用户词汇统计概览 (加速首页展示)
vocab:stats:{user_id}  → Hash {
    total_words: 320,                    # 单词本总词数
    mastered: 180,                       # 已掌握
    learning: 95,                        # 学习中
    new: 25,                             # 待学习
    weak: 20,                            # 薄弱词
    today_review: 12,                    # 今日待复习
    today_new: 15,                       # 今日新词目标
    streak_days: 7                       # 连续学习天数
}
TTL: 10min

# 单词详情缓存 (热点词)
vocab:word:detail:{word_id}  → String(JSON)  TTL: 24h

# 用户词汇量估算值 (避免频繁重新计算)
vocab:estimated:{user_id}  → String(number)  TTL: 1h
```

```python
class VocabDailyPlanService:
    """每日词汇学习计划生成服务"""

    def generate_daily_plan(self, user_id: int) -> VocabDailyPlan:
        # 1. 获取用户配置
        profile = self.get_user_profile(user_id)
        config = self.get_vocab_config(user_id)

        # 2. 计算今日新词数量
        new_target = config.new_words_per_day  # 默认15, 用户可调
        new_words = self.select_new_words(
            user_id=user_id,
            count=new_target,
            grade=profile.grade,
            cefr_level=profile.cefr_level,
            exclude_source="wordbook"  # 排除已在单词本中的
        )

        # 3. 获取今日待复习词 (来自间隔重复引擎)
        review_words = self.review_engine.get_due_words(
            user_id=user_id,
            content_type="vocab",
            date=today(),
            max_count=config.review_words_per_day  # 默认20
        )

        # 4. 按优先级排序
        #    优先级: 即将遗忘的 > 逾期未复习的 > 新词
        review_words = self.prioritize_reviews(review_words)

        # 5. 缓存到 Redis
        plan = VocabDailyPlan(
            user_id=user_id,
            date=today(),
            new_word_ids=[w.word_id for w in new_words],
            review_word_ids=[w.word_id for w in review_words],
            new_target=new_target,
        )
        self.cache_plan(plan)

        return plan

    def select_new_words(self, user_id, count, grade, cefr_level, exclude_source):
        """智能选词策略"""
        # 优先级:
        #   1. 当前教材章节单词 (如果正在学习某章节)
        #   2. 同级别未学单词 (按词频排序)
        #   3. 上一个级别遗漏的补漏词
        words = []

        # 策略1: 教材同步 (70%的名额)
        textbook_words = self.get_textbook_progress_words(user_id, limit=int(count * 0.7))
        words.extend(textbook_words)

        # 策略2: 词频补充 (30%的名额)
        remaining = count - len(words)
        if remaining > 0:
            freq_words = self.get_frequency_words(
                cefr_level=cefr_level,
                exclude_user_words=True,
                limit=remaining
            )
            words.extend(freq_words)

        return words
```

### 5.2 掌握度更新算法

```python
class VocabMasteryService:
    """词汇掌握度更新服务"""

    def update_mastery(self, user_id: int, word_id: int,
                       action: str, result: str, time_cost_ms: int,
                       exercise_type: str = None) -> MasteryUpdateResult:
        """
        掌握度更新规则:
        - 范围: 0-100
        - 学习新词并认识: +15~25 (根据答题速度)
        - 学习新词不认识: +0, 保持 LEARNING
        - 复习答对: +10~20
        - 复习答错: -15~25
        - 练习答对(非首次): +5~10
        - 练习答错: -10~15
        """
        word_record = self.get_user_word(user_id, word_id)
        old_mastery = word_record.mastery_level
        old_status = word_record.status

        # 计算掌握度变化
        delta = self._calc_mastery_delta(
            action=action,
            result=result,
            time_cost_ms=time_cost_ms,
            current_mastery=old_mastery,
            exercise_type=exercise_type
        )

        new_mastery = max(0, min(100, old_mastery + delta))

        # 状态流转判定
        new_status = self._determine_status(old_status, new_mastery, result)

        # 更新记录
        word_record.mastery_level = new_mastery
        word_record.status = new_status
        if result == "KNOWN":
            word_record.correct_count += 1
        else:
            word_record.wrong_count += 1
        word_record.last_reviewed_at = now()

        # 注册/更新间隔重复项
        self._update_review_schedule(word_record, result)

        # 发布学习事件
        self.event_bus.publish(VocabLearnEvent(
            user_id=user_id,
            word_id=word_id,
            action=action,
            result=result,
            mastery_delta=delta,
            new_mastery=new_mastery,
            new_status=new_status
        ))

        return MasteryUpdateResult(
            old_mastery=old_mastery,
            new_mastery=new_mastery,
            mastery_delta=delta,
            old_status=old_status,
            new_status=new_status,
            next_review_at=word_record.next_review_at
        )

    def _calc_mastery_delta(self, action, result, time_cost_ms,
                             current_mastery, exercise_type):
        """根据场景计算掌握度变化"""
        if action == "STUDY":
            if result == "KNOWN":
                # 答得越快加分越多
                if time_cost_ms < 3000:
                    return 25
                elif time_cost_ms < 8000:
                    return 20
                else:
                    return 15
            elif result == "PARTIAL":
                return 8
            else:  # UNKNOWN
                return 0

        elif action == "REVIEW":
            if result == "KNOWN":
                if time_cost_ms < 3000:
                    return 20
                elif time_cost_ms < 8000:
                    return 15
                else:
                    return 10
            else:
                # 错误惩罚：当前掌握度越高惩罚越重
                base_penalty = 15
                if current_mastery > 60:
                    base_penalty = 25
                elif current_mastery > 30:
                    base_penalty = 20
                return -base_penalty

        elif action == "QUIZ":
            if result == "KNOWN":
                return 8 if time_cost_ms < 5000 else 5
            else:
                return -12 if current_mastery < 50 else -15

        return 0

    def _determine_status(self, old_status, new_mastery, result):
        """状态流转逻辑"""
        if new_mastery >= 80:
            return "MASTERED"
        elif new_mastery >= 20:
            return "LEARNING"
        elif new_mastery > 0:
            return "WEAK"
        else:
            return "NEW" if old_status == "NEW" else "WEAK"

        # 特殊：从 MASTERED 答错退化
        if old_status == "MASTERED" and result == "UNKNOWN":
            word_record.lapses += 1
            if new_mastery < 60:
                return "WEAK"
            return "LEARNING"
```

### 5.3 词汇量估算算法

```python
class VocabAssessmentService:
    """词汇量评估服务 - 基于分层抽样 + 贝叶斯估计"""

    # CEFR 各级别对应的词汇量区间
    CEFR_RANGES = {
        "A1": (0, 500),
        "A2": (500, 1500),
        "B1": (1500, 3000),
        "B2": (3000, 5000),
        "C1": (5000, 8000),
        "C2": (8000, 16000),
    }

    # 各级别词库总大小
    LEVEL_TOTALS = {
        "A1": 500,
        "A2": 1000,
        "B1": 1500,
        "B2": 2000,
        "C1": 3000,
        "C2": 8000,
    }

    def estimate_vocab_size(self, user_id: int, results: List[AssessmentResult]) -> VocabEstimation:
        """
        基于测试结果估算词汇量
        使用贝叶斯估计: 对每个级别，根据测试正确率估算该级别的掌握比例
        """
        level_estimates = {}

        for level in ["A1", "A2", "B1", "B2", "C1", "C2"]:
            level_results = [r for r in results if r.cefr_level == level]
            if not level_results:
                # 未测试的级别，根据相邻级别推断
                level_estimates[level] = self._infer_level(level, level_estimates)
                continue

            tested = len(level_results)
            correct = sum(1 for r in level_results if r.is_correct)
            rate = correct / tested

            # 贝叶斯校正 (Beta分布先验)
            # 先验: Beta(1,1) 均匀分布
            alpha = 1 + correct
            beta_param = 1 + (tested - correct)
            estimated_rate = alpha / (alpha + beta_param)

            # 估算该级别掌握的词汇数
            total_in_level = self.LEVEL_TOTALS[level]
            estimated_known = int(total_in_level * estimated_rate)
            level_estimates[level] = {
                "tested": tested,
                "correct": correct,
                "rate": rate,
                "estimated_known": estimated_known
            }

        # 汇总
        total_estimated = sum(e["estimated_known"] for e in level_estimates.values())
        cefr_level = self._determine_cefr(total_estimated)

        return VocabEstimation(
            estimated_size=total_estimated,
            cefr_level=cefr_level,
            level_breakdown=level_estimates
        )
```

```python
class VocabQuestionGenerator:
    """词汇练习题目生成器"""

    def generate_questions(self, session: ExerciseSession) -> List[Question]:
        questions = []
        for word in session.selected_words:
            q = self._generate_by_type(word, session.exercise_type)
            questions.append(q)
        return questions

    def _generate_by_type(self, word: VocabWord, exercise_type: str) -> Question:
        if exercise_type == "SPELLING":
            return self._gen_spelling(word)
        elif exercise_type == "EN_ZH_SELECT":
            return self._gen_en_zh_select(word)
        elif exercise_type == "ZH_EN_SELECT":
            return self._gen_zh_en_select(word)
        elif exercise_type == "LISTEN_SELECT":
            return self._gen_listen_select(word)
        elif exercise_type == "LISTEN_SPELL":
            return self._gen_listen_spell(word)
        elif exercise_type == "CONTEXT_FILL":
            return self._gen_context_fill(word)
        elif exercise_type == "WORD_MATCH":
            return self._gen_word_match(word)

    def _gen_spelling(self, word: VocabWord) -> Question:
        """拼写题: 看中文 + 首字母提示 → 拼写完整单词"""
        return Question(
            question_type="SPELLING",
            word_id=word.id,
            prompt={
                "zh": word.definitions[0].zh,
                "pos": word.pos_list[0],
                "hint_letter_count": len(word.word),
                "hint_first_letter": word.word[0],
            },
            answer=word.word,
            difficulty=word.difficulty
        )

    def _gen_en_zh_select(self, word: VocabWord) -> Question:
        """英译中选择题: 看英文 → 选中文"""
        # 从同级别词库中选取3个干扰项
        distractors = self._get_distractors(
            target_word=word,
            strategy="similar_pos",  # 同词性干扰
            count=3
        )
        options = self._shuffle_options(
            correct={"id": "A", "text": word.definitions[0].zh},
            distractors=[{"id": chr(66+i), "text": d.definitions[0].zh}
                        for i, d in enumerate(distractors)]
        )
        return Question(
            question_type="EN_ZH_SELECT",
            word_id=word.id,
            prompt={
                "en": word.word,
                "phonetic": word.phonetic_us,
                "audio_url": word.audio_us_url,
            },
            options=options,
            answer=self._find_correct_id(options, word.definitions[0].zh),
            difficulty=word.difficulty
        )

    def _get_distractors(self, target_word, strategy, count):
        """
        干扰项选取策略:
        - similar_pos: 同词性、同级别的其他词
        - similar_sound: 发音相近的词 (易混淆)
        - similar_shape: 拼写相近的词 (形近词)
        - random: 随机同级别词
        """
        if strategy == "similar_pos":
            # 优选取同词性、同难度范围的词
            return self.vocab_repo.find_similar_pos_words(
                pos=target_word.pos_list[0],
                difficulty_range=(target_word.difficulty - 2, target_word.difficulty + 2),
                exclude_ids=[target_word.id],
                limit=count
            )
        # ... 其他策略
```

### 10.1 掌握度衰减任务

```python
class VocabDecayJob:
    """定时任务：检测长期未复习的已掌握单词并衰减"""

    def execute(self):
        # 查找所有超过30天未复习的 MASTERED 单词
        fading_words = self.vocab_repo.find_mastered_not_reviewed(
            days_threshold=30,
            batch_size=500
        )

        for word in fading_words:
            days_since = (now() - word.last_reviewed_at).days

            # 指数衰减: 每超过30天多一天，掌握度 -2
            decay = min(20, (days_since - 30) * 2)
            word.mastery_level = max(0, word.mastery_level - decay)

            if word.mastery_level < 60:
                word.status = "FADING"
                # 重新注册复习项
                self.review_engine.register_review_item(
                    user_id=word.user_id,
                    content_type="vocab",
                    content_id=word.word_id,
                    initial_interval=1  # 明天就复习
                )

            self.vocab_repo.save(word)
```

| VOCAB_004 | 400 | 练习类型不支持该学段 | 推荐可用练习类型 |
| VOCAB_005 | 404 | 练习会话不存在或已过期 | 创建新会话 |
| VOCAB_006 | 429 | 今日练习次数已达上限 | 显示下次可用时间 |
| VOCAB_007 | 400 | 教材章节无关联词汇 | 检查章节配置 |
| VOCAB_008 | 500 | TTS 发音合成失败 | 降级为文字模式 |
| VOCAB_009 | 500 | 题目生成失败 | 重试或切换题型 |
| VOCAB_010 | 400 | 批量导入超过数量限制 | 分批导入 |

### 11.2 降级策略

| 场景 | 降级方案 |
|------|---------|
| TTS 服务不可用 | 隐藏发音按钮，展示音标文字；听写题自动跳过 |
| 间隔重复引擎超时 | 使用默认间隔（1/3/7/14天），异步补偿更新 |
| AI Prompt 生成失败 | 使用缓存的标准讲解模板 |
| 词汇量评估题目生成失败 | 使用预置题库 fallback |
| Redis 缓存不可用 | 直连数据库查询，跳过缓存层 |
