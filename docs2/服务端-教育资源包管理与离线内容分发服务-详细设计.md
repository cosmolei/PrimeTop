# 服务端-教育资源包管理与离线内容分发服务 - 详细设计

## 1. 模块概述

### 1.1 模块定位

教育资源包管理服务负责将教材内容、题库数据、知识点解析、多媒体素材等教育资源进行打包、版本管理、加密签名后，通过 CDN 分发到客户端，支持客户端离线使用。该服务是支撑弱网/无网环境下学习体验的核心基础设施。

### 1.2 核心职责

1. **资源包定义与组装**：将分散的教育内容按维度（教材章节、学科、学段、专题）组装为可独立下载的资源包
2. **版本管理与增量更新**：每次内容变更生成新版本，支持全量包和差量（Delta）包
3. **加密与完整性校验**：资源包加密传输，客户端可校验包完整性和来源合法性
4. **CDN 分发策略**：对接 CDN 进行预热、调度、回源策略管理
5. **下载控制与调度**：根据用户设备状态、网络条件、业务优先级调度下载任务
6. **使用统计与质量监控**：追踪资源包下载成功率、使用率、过期淘汰情况

### 1.3 与其他模块的关系

```
┌──────────────────────────────────────────────────────────┐
│                      客户端层                              │
│  客户端资源包下载管理器  ←→  客户端本地持久层  ←→  业务模块  │
└──────────────────────┬───────────────────────────────────┘
                       │ HTTPS / WebSocket
┌──────────────────────┴───────────────────────────────────┐
│                    API 网关层                              │
└──────────────────────┬───────────────────────────────────┘
                       │
┌──────────────────────┴───────────────────────────────────┐
│              资源包管理服务 (本模块)                        │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐    │
│  │ 包定义   │ │ 版本管理 │ │ 加密签名 │ │ 分发调度 │    │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘    │
└───────┬──────────┬──────────┬──────────┬─────────────────┘
        │          │          │          │
   ┌────┘    ┌─────┘    ┌─────┘    ┌─────┘
   ▼         ▼          ▼          ▼
 PostgreSQL  Redis    CDN/OSS    Kafka
```

**上游依赖**：
- 内容服务：提供教材、知识点、题目的原始数据
- 文件与资源存储服务：提供图片、音频、视频等媒体文件存储
- 权限服务：校验用户是否有权下载特定资源包

**下游消费**：
- 客户端资源包下载管理器：下载、解压、校验、加载资源包
- 学习服务：查询客户端本地可用的离线内容范围

## 2. 核心概念与数据模型

### 2.1 资源包类型

| 类型代码 | 名称 | 说明 | 典型大小 |
|---------|------|------|---------|
| `TEXTBOOK_CHAPTER` | 教材章节包 | 某教材某章节的全部内容（知识点、例题、解析、配套练习） | 5-20 MB |
| `QUESTION_BANK` | 题库包 | 按学科/章节/难度聚合的题目集合 | 10-50 MB |
| `KNOWLEDGE_MAP` | 知识图谱包 | 知识点关系图、考点网络 | 2-10 MB |
| `MEDIA_BUNDLE` | 媒体资源包 | 图片、音频、视频等媒体文件集合 | 50-200 MB |
| `PHONETICS` | 拼音识字包 | 拼音、识字卡、发音音频、互动练习 | 20-80 MB |
| `EXAM_PAPER` | 试卷包 | 历年真题、模拟试卷及解析 | 5-30 MB |
| `FORMULA_SHEET` | 公式速查包 | 学科公式、定理、常数表 | 1-5 MB |
| `APP_CONFIG` | 应用配置包 | 分龄UI配置、运营配置、Prompt模板等 | < 1 MB |

### 2.2 资源包生命周期

```
DRAFT → BUILDING → READY → PUBLISHED → DEPRECATED → ARCHIVED
                          ↘ OFFLINE
```

| 状态 | 说明 |
|------|------|
| `DRAFT` | 资源包定义已创建，尚未开始构建 |
| `BUILDING` | 正在从内容系统拉取数据、打包、加密 |
| `READY` | 打包完成，通过质量校验，等待发布 |
| `PUBLISHED` | 已发布到 CDN，客户端可下载 |
| `DEPRECATED` | 已被新版本替代，仍可下载但标记为过时 |
| `ARCHIVED` | 已归档，不可下载，仅保留元数据 |
| `OFFLINE` | 因内容合规问题临时下线 |

### 2.3 数据库表设计

#### 2.3.1 resource_package（资源包定义表）

```sql
CREATE TABLE resource_package (
    id                  BIGSERIAL PRIMARY KEY,
    package_code        VARCHAR(128) NOT NULL,         -- 资源包唯一编码，如 TEXTBOOK_GRADE7_MATH_SEM1_CH03
    package_name        VARCHAR(256) NOT NULL,         -- 资源包名称
    package_type        VARCHAR(32)  NOT NULL,         -- 包类型：TEXTBOOK_CHAPTER / QUESTION_BANK / ...
    description         TEXT,                          -- 包描述
    tags                JSONB DEFAULT '[]',            -- 标签列表，如 ["人教版","七年级","数学","上册"]
    
    -- 归属与定位
    subject_code        VARCHAR(16),                   -- 学科代码：MATH / CHINESE / ENGLISH / ...
    grade_code          VARCHAR(16),                   -- 年级代码：G1~G12 / K1~K3(幼儿园)
    semester            VARCHAR(8),                    -- 学期：S1(上) / S2(下)
    textbook_id         BIGINT,                        -- 关联教材ID（如有）
    chapter_id          BIGINT,                        -- 关联章节ID（如有）
    
    -- 目标受众
    min_age             SMALLINT,                      -- 最小年龄
    max_age             SMALLINT,                      -- 最大年龄
    
    -- 业务元数据
    priority            SMALLINT DEFAULT 50,           -- 下载优先级：0(最高)~100(最低)
    auto_download       BOOLEAN DEFAULT FALSE,         -- 是否自动下载（WiFi环境下）
    required            BOOLEAN DEFAULT FALSE,         -- 是否为必需包（核心功能依赖）
    
    -- 容量预估
    estimated_size_mb   DECIMAL(10,2),                 -- 预估大小(MB)
    
    -- 状态与时间
    status              VARCHAR(16) DEFAULT 'DRAFT',   -- 生命周期状态
    created_by          VARCHAR(64),                   -- 创建人
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    updated_at          TIMESTAMPTZ DEFAULT NOW(),
    
    CONSTRAINT uk_package_code UNIQUE (package_code)
);

CREATE INDEX idx_rp_type_status ON resource_package(package_type, status);
CREATE INDEX idx_rp_subject_grade ON resource_package(subject_code, grade_code);
CREATE INDEX idx_rp_textbook_chapter ON resource_package(textbook_id, chapter_id);
```

#### 2.3.2 resource_package_version（资源包版本表）

```sql
CREATE TABLE resource_package_version (
    id                  BIGSERIAL PRIMARY KEY,
    package_id          BIGINT NOT NULL REFERENCES resource_package(id),
    version_code        VARCHAR(32) NOT NULL,          -- 语义化版本号：1.0.0 / 2.1.3
    version_seq         INT NOT NULL,                  -- 单调递增序号，用于差量计算
    content_hash        VARCHAR(128) NOT NULL,         -- 内容SHA-256哈希
    
    -- 构建信息
    build_id            VARCHAR(64),                   -- 构建任务ID
    build_started_at    TIMESTAMPTZ,
    build_finished_at   TIMESTAMPTZ,
    build_duration_ms   INT,
    
    -- 包文件信息
    full_package_url    VARCHAR(1024),                 -- 全量包 CDN URL
    full_package_size   BIGINT,                        -- 全量包字节数
    full_package_hash   VARCHAR(128),                  -- 全量包SHA-256
    encryption_key_id   VARCHAR(64),                   -- 加密密钥ID
    encryption_iv       VARCHAR(64),                   -- AES-GCM IV
    
    -- 内容清单
    file_count          INT DEFAULT 0,                 -- 包内文件数量
    content_manifest    JSONB,                         -- 内容清单（文件列表+各文件hash）
    
    -- 兼容性
    min_app_version     VARCHAR(16),                   -- 最低APP版本要求
    min_os_version      VARCHAR(16),                   -- 最低OS版本要求
    
    -- 差量信息（相对上一版本）
    delta_package_url   VARCHAR(1024),                 -- 差量包 CDN URL
    delta_package_size  BIGINT,                        -- 差量包字节数
    delta_algorithm     VARCHAR(16),                   -- 差量算法：BSDIFF / VCDIFF / CUSTOM
    
    -- 变更说明
    change_log          TEXT,                          -- 变更说明
    change_type         VARCHAR(16),                   -- MAJOR / MINOR / PATCH / HOTFIX
    
    -- 状态
    status              VARCHAR(16) DEFAULT 'BUILDING', -- BUILDING / READY / PUBLISHED / DEPRECATED
    published_at        TIMESTAMPTZ,
    deprecated_at       TIMESTAMPTZ,
    
    -- 统计
    download_count      BIGINT DEFAULT 0,             -- 下载次数
    install_count       BIGINT DEFAULT 0,             -- 安装确认次数
    
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    
    CONSTRAINT uk_pkg_version UNIQUE (package_id, version_code)
);

CREATE INDEX idx_rpv_package_seq ON resource_package_version(package_id, version_seq DESC);
CREATE INDEX idx_rpv_status ON resource_package_version(status);
```

#### 2.3.3 resource_package_content（资源包内容关联表）

```sql
CREATE TABLE resource_package_content (
    id                  BIGSERIAL PRIMARY KEY,
    package_id          BIGINT NOT NULL REFERENCES resource_package(id),
    content_type        VARCHAR(32) NOT NULL,          -- KNOWLEDGE_POINT / QUESTION / MEDIA / CHAPTER / FORMULA
    content_id          BIGINT NOT NULL,               -- 内容实体ID
    content_path        VARCHAR(512),                  -- 包内相对路径
    estimated_size      BIGINT,                        -- 单项预估字节数
    
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    
    CONSTRAINT uk_package_content UNIQUE (package_id, content_type, content_id)
);

CREATE INDEX idx_rpc_content ON resource_package_content(content_type, content_id);
```

#### 2.3.4 client_resource_inventory（客户端资源清单表）

记录每个客户端已安装的资源包版本，用于计算差量更新和离线能力查询。

```sql
CREATE TABLE client_resource_inventory (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL,
    device_id           VARCHAR(128) NOT NULL,         -- 设备唯一标识
    package_id          BIGINT NOT NULL REFERENCES resource_package(id),
    installed_version_seq INT NOT NULL,                -- 已安装的版本序号
    installed_at        TIMESTAMPTZ NOT NULL,
    last_used_at        TIMESTAMPTZ,                   -- 最后使用时间，用于淘汰策略
    local_size_bytes    BIGINT,                        -- 本地占用空间
    
    CONSTRAINT uk_user_device_pkg UNIQUE (user_id, device_id, package_id)
);

CREATE INDEX idx_cri_user ON client_resource_inventory(user_id);
CREATE INDEX idx_cri_user_device ON client_resource_inventory(user_id, device_id);
```

#### 2.3.5 resource_download_task（下载任务追踪表）

```sql
CREATE TABLE resource_download_task (
    id                  BIGSERIAL PRIMARY KEY,
    task_id             VARCHAR(64) NOT NULL,          -- 任务唯一ID (UUID)
    user_id             BIGINT NOT NULL,
    device_id           VARCHAR(128) NOT NULL,
    package_id          BIGINT NOT NULL,
    target_version_seq  INT NOT NULL,                  -- 目标版本序号
    download_type       VARCHAR(16) NOT NULL,          -- FULL / DELTA
    
    -- 下载状态
    status              VARCHAR(16) DEFAULT 'PENDING', -- PENDING / DOWNLOADING / VERIFYING / INSTALLING / COMPLETED / FAILED / CANCELLED
    progress_percent    SMALLINT DEFAULT 0,            -- 下载进度 0-100
    downloaded_bytes    BIGINT DEFAULT 0,
    total_bytes         BIGINT,
    
    -- 网络信息
    network_type        VARCHAR(8),                    -- WIFI / CELLULAR / UNKNOWN
    
    -- 时间信息
    started_at          TIMESTAMPTZ,
    completed_at        TIMESTAMPTZ,
    next_retry_at       TIMESTAMPTZ,                   -- 下次重试时间
    retry_count         SMALLINT DEFAULT 0,
    max_retries         SMALLINT DEFAULT 3,
    
    -- 错误信息
    last_error_code     VARCHAR(32),
    last_error_message  TEXT,
    
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    updated_at          TIMESTAMPTZ DEFAULT NOW(),
    
    CONSTRAINT uk_task_id UNIQUE (task_id)
);

CREATE INDEX idx_rdt_user_status ON resource_download_task(user_id, status);
CREATE INDEX idx_rdt_retry ON resource_download_task(status, next_retry_at) WHERE status = 'FAILED';
```

#### 2.3.6 resource_package_subscription（用户资源包订阅表）

记录用户当前需要哪些资源包，用于推送更新通知和自动下载调度。

```sql
CREATE TABLE resource_package_subscription (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL,
    package_id          BIGINT NOT NULL REFERENCES resource_package(id),
    auto_update         BOOLEAN DEFAULT TRUE,          -- 是否自动更新
    wifi_only           BOOLEAN DEFAULT TRUE,          -- 仅WiFi下自动下载
    created_at          TIMESTAMPTZ DEFAULT NOW(),
    
    CONSTRAINT uk_user_sub UNIQUE (user_id, package_id)
);

CREATE INDEX idx_rps_user ON resource_package_subscription(user_id);
```

### 4.1 资源包构建流程

**构建过程代码示例（伪代码）：**

```java
@Service
public class PackageBuildService {

    private static final String COMPRESSION_ALGORITHM = "zstd";
    private static final String ENCRYPTION_ALGORITHM = "AES-256-GCM";

    @Async("packageBuildExecutor")
    public void buildPackage(Long packageId, String changeLog, String changeType) {
        // 1. 获取资源包定义
        ResourcePackage pkg = packageRepository.findById(packageId)
            .orElseThrow(() -> new BusinessException(ErrorCode.PACKAGE_NOT_FOUND));

        // 2. 创建版本记录
        int nextSeq = versionRepository.findMaxSeq(packageId).orElse(0) + 1;
        String versionCode = generateVersionCode(pkg.getId(), nextSeq, changeType);

        ResourcePackageVersion version = new ResourcePackageVersion();
        version.setPackageId(packageId);
        version.setVersionCode(versionCode);
        version.setVersionSeq(nextSeq);
        version.setStatus("BUILDING");
        version.setBuildStartedAt(Instant.now());
        version.setChangeLog(changeLog);
        version.setChangeType(changeType);
        versionRepository.save(version);

        try {
            // 3. 获取关联内容
            List<ResourcePackageContent> contents = contentRepository
                .findByPackageId(packageId);

            // 4. 构建临时目录，拉取并序列化内容
            Path buildDir = Files.createTempDirectory("pkg_build_");
            ContentManifest manifest = new ContentManifest();

            for (ResourcePackageContent content : contents) {
                byte[] data = fetchContentData(content);
                Path filePath = buildDir.resolve(content.getContentPath());
                Files.createDirectories(filePath.getParent());
                Files.write(filePath, data);

                manifest.addFile(content.getContentPath(),
                    sha256Hex(data), data.length);
            }

            // 5. 写入清单文件
            byte[] manifestBytes = objectMapper.writeValueAsBytes(manifest);
            Files.write(buildDir.resolve("manifest.json"), manifestBytes);

            // 6. 打包压缩
            byte[] compressed = compressDirectory(buildDir);

            // 7. 加密
            String keyId = keyManagementService.getCurrentKeyId();
            EncryptionResult encrypted = encryptionService.encrypt(
                compressed, keyId);

            // 8. 计算哈希
            String contentHash = sha256Hex(compressed);

            // 9. 上传至 OSS
            String ossKey = String.format("packages/%d/v%d/full.pkg",
                packageId, nextSeq);
            String cdnUrl = ossService.upload(ossKey, encrypted.getData(),
                "application/octet-stream");

            // 10. 生成差量包（如果有上一版本）
            generateDeltaPackage(packageId, nextSeq - 1, compressed, nextSeq);

            // 11. 更新版本记录
            version.setFullPackageUrl(cdnUrl);
            version.setFullPackageSize((long) encrypted.getData().length);
            version.setFullPackageHash(contentHash);
            version.setEncryptionKeyId(keyId);
            version.setEncryptionIv(encrypted.getIv());
            version.setFileCount(manifest.getFiles().size());
            version.setContentManifest(objectMapper.valueToTree(manifest));
            version.setBuildFinishedAt(Instant.now());
            version.setBuildDurationMs((int) Duration.between(
                version.getBuildStartedAt(), version.getBuildFinishedAt()).toMillis());
            version.setStatus("READY");

            versionRepository.save(version);

            // 12. 发送构建完成事件
            eventPublisher.publishEvent(new PackageBuildCompletedEvent(
                packageId, version.getId()));

        } catch (Exception e) {
            version.setStatus("FAILED");
            versionRepository.save(version);
            throw new PackageBuildException("构建失败", e);
        }
    }

    private void generateDeltaPackage(Long packageId, int fromSeq,
                                       byte[] newData, int toSeq) {
        if (fromSeq <= 0) return;

        // 获取旧版本数据
        byte[] oldData = decryptAndFetchFullPackage(packageId, fromSeq);
        if (oldData == null) return;

        // BSDIFF 生成差量
        byte[] delta = BsdiffUtils.diff(oldData, newData);
        if (delta.length > newData.length * 0.8) {
            // 差量包过大（超过新包80%），不提供差量
            log.info("Delta package too large, skipping. packageId={}, from={}, to={}",
                packageId, fromSeq, toSeq);
            return;
        }

        String deltaKey = String.format("packages/%d/v%d/delta_from_v%d.pkg",
            packageId, toSeq, fromSeq);
        EncryptionResult deltaEncrypted = encryptionService.encrypt(
            delta, keyManagementService.getCurrentKeyId());
        String deltaUrl = ossService.upload(deltaKey, deltaEncrypted.getData(),
            "application/octet-stream");

        // 更新版本记录
        ResourcePackageVersion version = versionRepository
            .findByPackageIdAndVersionSeq(packageId, toSeq);
        version.setDeltaPackageUrl(deltaUrl);
        version.setDeltaPackageSize((long) delta.length);
        version.setDeltaAlgorithm("BSDIFF");
        versionRepository.save(version);
    }
}
```

```dart
// Flutter/Dart 客户端
class DeltaApplyService {
  Future<bool> applyDelta({
    required String deltaFilePath,
    required String currentPackagePath,
    required String targetHash,
  }) async {
    // 1. 读取当前版本的完整包
    final currentData = await File(currentPackagePath).readAsBytes();

    // 2. 解密差量包
    final deltaEncrypted = await File(deltaFilePath).readAsBytes();
    final deltaData = await CryptoService.decrypt(deltaEncrypted);

    // 3. 应用 BSDIFF 补丁
    final newData = await BsdiffNative.apply(currentData, deltaData);

    // 4. 校验目标哈希
    final actualHash = sha256(newData);
    if (actualHash != targetHash) {
      throw PackageIntegrityError(
        'Delta apply hash mismatch: expected=$targetHash, actual=$actualHash');
    }

    // 5. 写入新版本包文件
    final newPath = await PackagePath.getFullPath(packageId, newVersionSeq);
    await File(newPath).writeAsBytes(newData);

    // 6. 删除旧版本包
    await File(currentPackagePath).delete();

    return true;
  }
}
```

## 5. 加密与安全设计

### 5.1 加密方案

```
资源包加密流程：

原始内容 → ZSTD压缩 → AES-256-GCM加密 → 签名 → CDN存储
                         ↑
                    密钥管理服务
                    (动态轮换)
```

| 环节 | 算法 | 说明 |
|------|------|------|
| 压缩 | Zstandard (zstd) | 压缩比优于gzip，解压速度更快 |
| 加密 | AES-256-GCM | 对称加密+认证标签，防篡改 |
| 签名 | HMAC-SHA256 | 使用独立签名密钥 |
| 哈希 | SHA-256 | 内容完整性校验 |
| 密钥轮换 | 按季度轮换 | 每个季度新的加密密钥，旧密钥保留用于解密历史包 |

### 5.2 密钥管理

```java
@Service
public class PackageEncryptionService {

    /**
     * 加密资源包数据
     * - 从密钥管理服务获取当前活跃密钥
     * - 生成随机IV
     * - AES-256-GCM加密
     */
    public EncryptionResult encrypt(byte[] plaintext, String keyId) {
        SecretKey key = keyManagementService.getKey(keyId);
        byte[] iv = new byte[12]; // GCM推荐12字节IV
        SecureRandom.getInstanceStrong().nextBytes(iv);

        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        GCMParameterSpec spec = new GCMParameterSpec(128, iv); // 128-bit auth tag
        cipher.init(Cipher.ENCRYPT_MODE, key, spec);

        byte[] ciphertext = cipher.doFinal(plaintext);

        return new EncryptionResult(
            ciphertext,
            Base64.getEncoder().encodeToString(iv),
            keyId
        );
    }

    /**
     * 生成下载签名URL，防止盗链
     * - 有效期：2小时
     * - 包含用户ID、设备ID绑定
     */
    public String generateSignedDownloadUrl(String baseUrl, Long userId,
                                             String deviceId) {
        long expires = Instant.now().plus(Duration.ofHours(2)).getEpochSecond();
        String payload = userId + ":" + deviceId + ":" + expires;
        String signature = HmacUtils.hmacSha256Hex(urlSigningKey, payload);

        return baseUrl + "?expires=" + expires
            + "&uid=" + userId
            + "&sig=" + signature;
    }
}
```

### 5.3 防盗链策略

1. **签名URL**：下载链接包含过期时间和用户绑定签名，2小时有效
2. **设备绑定**：下载链接与设备ID绑定，不可跨设备使用
3. **频率限制**：同一用户每分钟最多10次下载请求
4. **IP限制**：同一IP每分钟最多50次下载请求
5. **Referer校验**：CDN层校验 Referer 为合法域名

### 7.2 下载队列优先级

```java
public class DownloadScheduler {

    /**
     * 下载队列排序规则：
     * 1. 必需包 > 非必需包
     * 2. 优先级数值小的 > 数值大的
     * 3. 差量包 > 全量包（同等条件下优先节省流量）
     * 4. 发布时间早的 > 发布时间晚的（先到先得）
     */
    public List<DownloadTask> prioritize(List<DownloadTask> tasks) {
        return tasks.stream()
            .sorted(Comparator
                .comparing(DownloadTask::isRequired).reversed()
                .thenComparing(DownloadTask::getPriority)
                .thenComparing(DownloadTask::getDownloadType,
                    Comparator.comparing(t -> "DELTA".equals(t) ? 0 : 1))
                .thenComparing(DownloadTask::getPublishedAt))
            .collect(Collectors.toList());
    }
}
```

## 9. 错误处理

### 9.1 错误码定义

| 错误码 | HTTP状态码 | 说明 | 客户端处理建议 |
|--------|-----------|------|--------------|
| `PKG_001` | 404 | 资源包不存在 | 提示用户该内容暂不可用 |
| `PKG_002` | 404 | 版本不存在 | 重新查询最新版本 |
| `PKG_003` | 403 | 无权下载该资源包（会员限制） | 引导开通会员 |
| `PKG_004` | 410 | 下载链接已过期 | 重新请求下载链接 |
| `PKG_005` | 409 | 当前有正在进行的下载任务 | 等待或取消现有任务 |
| `PKG_006` | 503 | CDN 暂时不可用 | 稍后重试 |
| `PKG_007` | 400 | 差量包不适用于当前版本 | 改为全量下载 |
| `PKG_008` | 429 | 下载频率超限 | 等待后重试 |
| `PKG_009` | 500 | 构建失败 | 联系运营人员 |
| `PKG_010` | 400 | 校验失败（哈希不匹配） | 重新下载 |

### 9.2 重试策略

```java
public class DownloadRetryPolicy {

    // 指数退避重试
    public static final RetryPolicy DEFAULT = RetryPolicy.builder()
        .maxRetries(3)
        .backoffStrategy(BackoffStrategy.EXPONENTIAL)
        .initialDelay(Duration.ofSeconds(5))
        .maxDelay(Duration.ofMinutes(10))
        .jitterFactor(0.2)       // 随机抖动，防止雪崩
        .retryOnErrors(
            NetworkError.class,
            TimeoutError.class,
            CdnUnavailableError.class
        )
        .abortOnErrors(
            IntegrityError.class,    // 校验失败不重试
            PermissionError.class    // 权限不足不重试
        )
        .build();
}
```

### 11.3 批量检查更新优化

```java
@Service
public class PackageUpdateCheckService {

    /**
     * 批量检查优化策略：
     * 1. 使用 Redis 缓存每个包的最新版本
     * 2. 批量查询客户端已安装版本
     * 3. 内存中对比，避免逐条查询数据库
     */
    @Cacheable(value = "latest_versions", key = "#root.methodName")
    public Map<Long, Integer> getLatestVersionMap() {
        // 从 version 表中查询每个 package_id 的最新 version_seq
        // 缓存5分钟
        return versionRepository.findLatestVersionSeqMap();
    }

    public BatchCheckResult batchCheck(Long userId, String deviceId,
                                        List<InstalledPackage> installed) {
        Map<Long, Integer> latestMap = getLatestVersionMap();

        List<UpdateInfo> updates = new ArrayList<>();
        for (InstalledPackage ip : installed) {
            Integer latestSeq = latestMap.get(ip.getPackageId());
            if (latestSeq != null && latestSeq > ip.getVersionSeq()) {
                updates.add(buildUpdateInfo(ip, latestSeq));
            }
        }

        return new BatchCheckResult(updates,
            updates.stream().anyMatch(u -> u.isRequired()));
    }
}
```

### 13.2 资源包使用热度排行

```sql
-- 查询最近30天下载量TOP20资源包
SELECT
    rp.package_code,
    rp.package_name,
    rp.package_type,
    rp.subject_code,
    rp.grade_code,
    COUNT(DISTINCT cri.user_id) AS installed_users,
    SUM(CASE WHEN rdt.status = 'COMPLETED' THEN 1 ELSE 0 END) AS download_count,
    AVG(rdt.downloaded_bytes) AS avg_download_bytes,
    rp.estimated_size_mb
FROM resource_package rp
LEFT JOIN client_resource_inventory cri ON cri.package_id = rp.id
    AND cri.last_used_at > NOW() - INTERVAL '30 days'
LEFT JOIN resource_download_task rdt ON rdt.package_id = rp.id
    AND rdt.created_at > NOW() - INTERVAL '30 days'
WHERE rp.status = 'PUBLISHED'
GROUP BY rp.id
ORDER BY installed_users DESC
LIMIT 20;
```
