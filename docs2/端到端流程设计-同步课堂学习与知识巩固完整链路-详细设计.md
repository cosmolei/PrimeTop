# 端到端流程设计 - 同步课堂学习与知识巩固完整链路

> 本文档详细描述同步课堂学习从"教材版本选择 → 章节目录浏览 → 预习/学习/复习 → 练习巩固 → 进度追踪 → 掌握度更新"的完整端到端链路，供开发人员直接编码参考。

---

## 1. 流程总览

### 1.1 链路全景图

```
┌──────────────────────────────────────────────────────────────────────────┐

├──────────┬──────────┬──────────┬──────────┬──────────┬──────────────────┤
│ 1.教材选择 │ 2.章节浏览 │ 3.章节学习 │ 4.练习巩固 │ 5.复习闭环 │ 6.数据沉淀     │
│          │          │          │          │          │                │
│ 选学段    │ 目录树    │ 预习导学  │ 同步练习  │ 错题关联  │ 进度更新       │
│ 选年级    │ 学习状态  │ 知识讲解  │ 巩固提升  │ 知识回顾  │ 掌握度计算     │

│ 选学科    │ 继续学习  │ 笔记收藏  │ 结果反馈  │ 薄弱预警  │ 学情报告生成   │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────────────┘
```

### 1.2 核心用户旅程

```
学生打开APP → 首页"同步课堂"入口 → [首次]教材版本配置 / [已有]上次学习章节
    → 章节目录页 → 选择章节 → 进入章节学习主页
    → 课前预习 → 知识点学习(讲解/例题/互动) → 学习进度记录
    → 同步练习 → 答题 → 批改反馈 → 错题自动收录
    → 课后复习 → 知识总结 → 掌握度评估 → 返回目录
    → [系统]更新学习画像/能力维度/薄弱点 → 推送复习提醒
```

## 2. 阶段一：教材版本选择与学科配置

### 2.1 流程说明

首次使用同步课堂时，学生需要完成教材配置；后续可在设置中修改。

```
[首次进入]                    [已有配置]
    │                            │
    ▼                            ▼
学段选择(幼/小/初/高)        直接进入上次学科
    │
    ▼
年级选择(一年级~高三)
    │
    ▼
学科选择(语文/数学/英语/...)
    │
    ▼
教材版本选择(人教版/苏教版/...)
    │
    ▼
教材封面确认 → 保存配置
    │
    ▼
进入章节目录
```

### 2.4 关键业务规则

1. **推荐优先**：根据用户地区（IP/注册信息）推荐主流教材版本，人教版为默认推荐
2. **多学科支持**：用户可配置多个学科，每个学科独立教材版本
3. **学期自动切换**：根据系统时间判断当前学期，首次每学期进入时提示确认
4. **配置缓存**：教材配置在客户端本地缓存，减少重复请求

## 3. 阶段二：章节目录浏览

### 3.1 流程说明

```
进入章节目录
    │
    ├── 加载目录树(带学习进度标记)
    ├── 显示"继续学习"入口(如果有未完成章节)
    ├── 显示"推荐学习"入口(基于薄弱点)
    │
    ▼
用户选择章节
    │
    ├── 已完成 → 显示学习报告/重新学习入口
    ├── 进行中 → 从断点继续
    ├── 未开始 → 进入预习导学
    └── 锁定(前置章节未完成) → 提示先完成前置
```

### 3.2 数据结构

```typescript
// 客户端章节目录组件状态管理
class ChapterDirectoryBloc {
  final String textbookId;
  ChapterTreeState _state = ChapterTreeState.loading();

  // 加载目录
  Future<void> loadChapters() async {
    final response = await api.getChapters(textbookId: textbookId, withStatus: true);
    _state = ChapterTreeState.loaded(
      chapters: _buildTree(response.chapters),
      continueLearning: response.continueLearning,
      recommendations: response.recommendedChapters,
    );
  }

  // 章节点击处理
  Future<void> onChapterTap(ChapterNode chapter, ChapterStudyStatus status) async {
    switch (status.status) {
      case 'locked':
        _showLockedDialog(chapter, status);
        break;
      case 'not_started':
        _navigateToPreview(chapter);
        break;
      case 'completed':
        _showCompletedSummary(chapter, status);
        break;
      default:
        _resumeFromLastPosition(chapter, status);
        break;
    }
  }
}
```

```typescript
interface KnowledgePointContent {

  explanation: {

    method: RichContent;        // 方法/步骤

    commonMistakes: RichContent; // 易错点
```

```dart
// 客户端：知识点学习页面状态管理
class KnowledgePointStudyBloc extends Bloc<KPStudyEvent, KPStudyState> {
  final String kpId;
  final KnowledgePointContent content;
  int _currentStepIndex = 0;

  // 渐进展示策略
  List<StudyStep> buildStudySteps() {
    return [
      // Step 1: 概念引入(必看)
      StudyStep(
        type: StepType.concept,
        title: '概念理解',
        content: content.explanation.concept,
        isRequired: true,
        minViewDuration: Duration(seconds: 15),
      ),
      // Step 2: 方法讲解(必看)
      StudyStep(
        type: StepType.method,
        title: '方法学习',
        content: content.explanation.method,
        isRequired: true,
        minViewDuration: Duration(seconds: 20),
      ),
      // Step 3: 例题(至少看1个，展开步骤)
      StudyStep(
        type: StepType.examples,
        title: '例题讲解',
        content: content.explanation.examples,
        isRequired: true,
        minRequired: 1,           // 至少看1个例题
        progressiveReveal: true,  // 步骤渐进展示
      ),
      // Step 4: 互动练习(推荐)
      StudyStep(
        type: StepType.interaction,
        title: '动手试试',
        content: content.interactions,
        isRequired: false,
        maxAttempts: 3,
      ),
      // Step 5: AI答疑(可选)
      StudyStep(
        type: StepType.aiAsk,
        title: '还有疑问？问AI',
        isRequired: false,
      ),
      // Step 6: 易错点(推荐)
      StudyStep(
        type: StepType.mistakes,
        title: '注意这些易错点',
        content: content.explanation.commonMistakes,
        isRequired: false,
      ),
    ];
  }

  // 步骤完成判定
  bool isStepCompleted(StudyStep step) {
    switch (step.type) {
      case StepType.concept:
      case StepType.method:
        return _viewDuration >= step.minViewDuration && _hasScrolledToEnd;
      case StepType.examples:
        return _viewedExamples >= step.minRequired;
      case StepType.interaction:
        return _interactionAttempted || _skipped;
      default:
        return true;
    }
  }
}
```

### 7.3 掌握度计算模型

```typescript
// 知识点掌握度计算
interface MasteryCalculation {
  kpId: string;
  userId: string;

  // 输入因子
  factors: {
    studyDuration: number;        // 学习时长(秒), 权重0.15
    studyCompleteness: number;    // 学习完整度(0-1), 权重0.15
    interactionAccuracy: number;  // 互动正确率(0-1), 权重0.15
    practiceAccuracy: number;     // 练习正确率(0-1), 权重0.30
    reviewPassRate: number;       // 复习通过率(0-1), 权重0.15
    timeDecay: number;            // 时间衰减因子(0-1), 权重0.10
  };

  // 计算公式
  calculate(): number {
    const { studyDuration, studyCompleteness, interactionAccuracy,
            practiceAccuracy, reviewPassRate, timeDecay } = this.factors;

    // 时长归一化(超过预估时长×1.5则满分)
    const durationScore = Math.min(1, studyDuration / (estimatedDuration * 1.5));

    return (
      durationScore * 0.15 +
      studyCompleteness * 0.15 +
      interactionAccuracy * 0.15 +
      practiceAccuracy * 0.30 +
      reviewPassRate * 0.15 +
      timeDecay * 0.10
    );
    // 返回 0-1 的掌握度值
  }
}

// 掌握度等级映射
function masteryToLevel(mastery: number): MasteryLevel {
  if (mastery >= 0.9) return 'mastered';
  if (mastery >= 0.7) return 'proficient';
  if (mastery >= 0.5) return 'familiar';
  if (mastery >= 0.2) return 'beginner';
  return 'none';
}

// 时间衰减(艾宾浩斯遗忘曲线简化模型)
function calculateTimeDecay(lastStudyDate: Date, now: Date): number {
  const daysSince = (now.getTime() - lastStudyDate.getTime()) / (1000 * 60 * 60 * 24);
  // R = e^(-t/S), S为记忆稳定性(默认约7天)
  return Math.exp(-daysSince / 7);
}

// 章节综合掌握度 = 所含知识点掌握度的加权平均
function chapterMastery(kpMasteries: { weight: number; mastery: number }[]): number {
  const totalWeight = kpMasteries.reduce((sum, kp) => sum + kp.weight, 0);
  return kpMasteries.reduce((sum, kp) => sum + kp.mastery * kp.weight, 0) / totalWeight;
}
```

| 教材内容未上架 | `CONTENT_NOT_AVAILABLE` | 展示"内容正在建设中"占位页，推荐已上线的替代内容 |
| 知识点内容加载失败 | `KP_LOAD_FAILED` | 重试3次，失败后展示离线缓存内容或降级为纯文本 |
| 练习题生成不足 | `INSUFFICIENT_QUESTIONS` | 降级：减少题目数量 + AI补充生成 |
| AI辅导请求失败 | `AI_SERVICE_UNAVAILABLE` | 展示预置的讲解内容(不依赖AI)，提示"AI暂时不可用" |
| 网络中断 | `NETWORK_ERROR` | 切换到离线模式：展示已缓存的章节内容 |
| 掌握度计算服务超时 | `MASTERY_TIMEOUT` | 异步计算，使用缓存的旧值展示，后台更新 |

### 10.2 降级层级

```
Level 0: 完整功能 (所有服务正常)
    ↓
Level 1: 去AI化 (AI服务不可用，使用预置内容)
    - 知识点讲解 → 静态富文本内容
    - 答疑 → 展示FAQ和预置解答
    - AI提示 → 不显示AI提示按钮
    ↓
Level 2: 离线模式 (网络不可用，使用本地缓存)
    - 仅展示已缓存的章节内容
    - 练习使用本地题库
    - 学习记录本地暂存，联网后同步
    ↓
Level 3: 只读模式 (核心服务不可用)
    - 展示"服务暂时不可用"
    - 允许浏览已下载的内容
    - 学习进度暂停记录
```

### 10.3 客户端错误处理代码示例

```dart
class SyncClassRepository {
  final ApiClient _api;
  final LocalCache _cache;

  Future<ChapterContent> loadChapterContent(String chapterId) async {
    try {
      // 优先从服务端获取
      final response = await _api.get('/sync-class/chapters/$chapterId/content');
      final content = ChapterContent.fromJson(response.data);

      // 成功后更新本地缓存
      await _cache.put('chapter_content_$chapterId', content.toJson());
      return content;
    } on ApiException catch (e) {
      switch (e.code) {
        case 'CONTENT_NOT_AVAILABLE':
          throw ContentNotAvailableException(chapterId: chapterId);
        case 'NETWORK_ERROR':
          // 降级到本地缓存
          final cached = await _cache.get('chapter_content_$chapterId');
          if (cached != null) {
            return ChapterContent.fromJson(cached);
          }
          throw OfflineNoCacheException();
        default:
          rethrow;
      }
    }
  }

  // 练习生成降级
  Future<PracticeContent> generatePractice(PracticeConfig config) async {
    try {
      return await _api.generatePractice(config);
    } on ApiException catch (e) {
      if (e.code == 'INSUFFICIENT_QUESTIONS') {
        // 降级：减少题目数量重试
        final reducedConfig = config.copyWith(
          questionCount: max(5, config.questionCount ~/ 2),
        );
        return await _api.generatePractice(reducedConfig);
      }
      rethrow;
    }
  }
}
```

```typescript
// 客户端缓存层级
const CACHE_CONFIG = {
  // 教材目录：长期缓存，教材版本不变则不更新
  chapterDirectory: {
    ttl: 24 * 60 * 60 * 1000,     // 24小时
    strategy: 'stale_while_revalidate',  // 先展示缓存，后台更新
  },

  // 知识点内容：中期缓存
  knowledgePointContent: {
    ttl: 2 * 60 * 60 * 1000,      // 2小时
    strategy: 'cache_first',
    maxEntries: 50,                // 最多缓存50个知识点
  },

  // 练习题：短期缓存，完成后清除
  practiceContent: {
    ttl: 30 * 60 * 1000,          // 30分钟
    strategy: 'network_first',
    clearOnComplete: true,
  },

  // 学习进度：实时同步
  studyProgress: {
    ttl: 0,                        // 不缓存，每次请求
    localBackup: true,             // 本地备份防丢失
  },

  // 图片/动画资源：长期缓存
  mediaResources: {
    ttl: 7 * 24 * 60 * 60 * 1000, // 7天
    strategy: 'cache_first',
    maxCacheSize: 500 * 1024 * 1024, // 500MB上限
  },
};
```

### 11.3 预加载策略

```dart
// 预加载逻辑
class SyncClassPreloader {
  // 进入章节目录时，预加载当前章节和下一章节内容
  Future<void> preloadOnDirectoryEnter(String currentChapterId) async {
    // 预加载当前/下一个章节的知识点列表
    unawaited(_loadChapterKnowledgePoints(currentChapterId));
    unawaited(_loadNextChapterContent(currentChapterId));

    // 预加载首屏知识点内容
    unawaited(_loadFirstKnowledgePointContent(currentChapterId));
  }

  // 学习知识点时，预加载下一个知识点
  Future<void> preloadNextKnowledgePoint(String currentKpId, String chapterId) async {
    final nextKp = await _getNextKnowledgePoint(currentKpId, chapterId);
    if (nextKp != null) {
      unawaited(_loadKnowledgePointContent(nextKp.kpId));
    }
  }

  // WiFi环境下，后台预下载整章资源
  Future<void> backgroundPreloadChapter(String chapterId) async {
    if (await _isWifi() && await _hasStorageSpace()) {
      final content = await _loadFullChapterContent(chapterId);
      await _cacheAllResources(content);
    }
  }
}
```

## 12. 安全与合规

### 12.1 内容安全

1. **教材版权**：教材内容数字化需获得版权授权，系统记录内容来源和授权信息
2. **AI输出审核**：知识点讲解、AI辅导回复均需经过内容安全过滤
3. **适龄内容**：根据学段自动调整内容展示方式和信息密度

### 12.2 数据安全

1. **学习数据归属**：学习记录归属于学生本人，家长可通过绑定关系查看
2. **进度数据同步**：使用HTTPS传输，关键操作增加幂等性保证
3. **离线数据**：本地缓存的学习数据加密存储，设备切换时需重新验证

## 14. 总结

同步课堂学习完整链路是PrimeTop的核心学习闭环之一，贯穿以下关键设计要点：

1. **教材适配**：支持多版本教材，通过统一的知识点映射层实现跨版本内容对齐
2. **渐进式学习**：预习→学习→练习→复习的递进结构，符合认知规律
3. **断点续学**：完整的学习上下文保存/恢复机制，保障学习连续性
4. **数据驱动**：每个环节产生学习行为事件，级联更新掌握度、能力维度、学情画像
5. **降级容错**：三级降级策略确保弱网/离线场景下仍可使用
6. **性能优先**：预加载+多级缓存策略保障流畅的学习体验
