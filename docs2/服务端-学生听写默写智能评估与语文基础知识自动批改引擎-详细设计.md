# 服务端-学生听写默写智能评估与语文基础知识自动批改引擎 详细设计

## 1. 概述

### 1.1 模块定位

听写默写是中小学语文（及英语词汇）教学中最高频的日常练习形式——几乎每个小学生每天都有听写或默写任务。本引擎为 PrimeTop 提供听写默写全链路服务能力，覆盖任务创建、语音朗读、作答采集、手写识别、智能批改、错误归因、复习推荐和进度追踪。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 听写任务管理 | 创建、配置、发布、关闭听写默写任务 |
| 语音合成朗读 | 按可配置语速、停顿、重复次数朗读待听写内容 |
| 作答采集 | 支持拍照OCR和屏幕手写两种采集方式 |
| 手写识别与批改 | 中文手写体识别、字形比对、错误定位与分类 |
| 错误归因分析 | 同音字混淆、形近字混淆、偏旁错误、笔顺错误等分类 |
| 复习推荐 | 基于错误模式生成个性化复习内容，对接间隔重复系统 |
| 进度追踪 | 按字/词/单元维度追踪掌握度，生成趋势报告 |

### 1.3 依赖关系

```
┌─────────────────────────────────────────────────────┐
│              听写默写智能评估引擎                      │
├─────────┬──────────┬──────────┬─────────┬───────────┤
│  TTS    │  OCR/    │ 知识点   │ 间隔重复 │  学情分析  │
│  语音合成│  手写识别 │ 体系服务 │ 复习引擎 │  服务     │
└─────────┴──────────┴──────────┴─────────┴───────────┘
      │           │          │          │          │
      ▼           ▼          ▼          ▼          ▼
  ASR/TTS      OCR管线    教材章节     遗忘曲线    学习画像
  服务         服务       知识点库     算法服务    数据服务
```

### 1.4 与已有模块的边界

| 已有模块 | 覆盖范围 | 本引擎差异 |
|---------|---------|-----------|
| 拼音识字启蒙 | 学习新字/新词的认知阶段 | 听写默写是**检测阶段**，验证已学内容的回忆和书写能力 |
| 文科背诵内容管理 | 课文/古诗的整段背诵检测 | 听写默写是**逐字/词级别的书写检测**，侧重字形正确性 |
| 中文朗读能力评估 | 评估口语发音和朗读流利度 | 听写默写评估的是**书面输出**，不是口语表达 |
| 汉字笔画顺序检测 | 评估书写过程中的笔画顺序 | 听写默写评估的是**最终书写结果**的正确性（字形对错） |
| 间隔重复算法引擎 | 通用复习调度算法 | 本引擎是听写默写**业务层**，调用间隔重复引擎作为底层能力 |

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 DictationTask（听写默写任务）

```typescript
interface DictationTask {
  id: string;                          // 任务ID，全局唯一
  title: string;                       // 任务标题，如"三年级上册第5单元听写"
  type: DictationType;                 // 听写类型
  sourceType: TaskSourceType;          // 内容来源类型
  sourceRef?: string;                  // 来源引用（教材章节ID/词库ID/自定义文本）
  subject: Subject;                    // 学科（语文/英语）
  gradeLevel: GradeLevel;              // 年级
  textbookId?: string;                 // 关联教材版本ID
  chapterIds?: string[];               // 关联章节ID列表
  items: DictationItem[];              // 听写条目列表
  config: DictationConfig;             // 朗读与作答配置
  publisherType: PublisherType;        // 发布者类型（系统/教师/家长/学生自测）
  publisherId: string;                 // 发布者ID
  targetUserIds: string[];             // 目标学生ID列表
  status: TaskStatus;                  // 任务状态
  scheduledAt?: Date;                  // 计划开始时间
  deadline?: Date;                     // 截止时间
  createdAt: Date;
  updatedAt: Date;
}

enum DictationType {
  DICTATION = 'dictation',             // 听写（音频朗读 → 学生书写）
  DICTATION_FROM_MEMORY = 'recitation',// 默写（看提示 → 凭记忆书写）
  MIXED = 'mixed',                     // 混合模式（部分听写 + 部分默写）
}

enum TaskSourceType {
  TEXTBOOK_CHAPTER = 'textbook_chapter', // 教材章节生字词
  WORD_BANK = 'word_bank',               // 系统词库
  CUSTOM = 'custom',                     // 自定义内容
  AI_GENERATED = 'ai_generated',         // AI根据学生薄弱点生成
  ERROR_DRIVEN = 'error_driven',         // 从历史错题中抽取
}

interface DictationConfig {
  readMode: ReadMode;                  // 朗读模式
  speed: number;                       // 语速倍率 (0.5 ~ 2.0, 默认1.0)
  repeatCount: number;                 // 每条朗读重复次数（默认1次）
  intervalSeconds: number;             // 条目间停顿秒数（默认5秒）
  answerMode: AnswerMode;              // 作答方式
  timeLimit?: number;                  // 总时长限制（秒），可选
  showPinyin: boolean;                 // 默写模式是否显示拼音提示
  showHint: boolean;                   // 是否显示首字提示
  strictness: GradingStrictness;       // 批改严格程度
}

enum ReadMode {
  CHAR_BY_CHAR = 'char_by_char',       // 逐字朗读
  WORD_BY_WORD = 'word_by_word',       // 逐词朗读
  PHRASE_BY_PHRASE = 'phrase_by_phrase',// 逐短语朗读
  SENTENCE_THEN_SLOW = 'sentence_then_slow', // 先整句后慢速
}

enum AnswerMode {
  PAPER_PHOTO = 'paper_photo',         // 纸质拍照
  DIGITAL_HANDWRITE = 'digital_handwrite', // 屏幕手写
  DIGITAL_TYPE = 'digital_type',       // 键盘输入（辅助模式）
}

enum GradingStrictness {
  STRICT = 'strict',                   // 每一笔画都需正确
  STANDARD = 'standard',               // 整体字形正确即可
  LENIENT = 'lenient',                 // 允许轻微笔画差异（低年级）
}
```

interface DictationItem {

#### 2.1.3 DictationAttempt（学生作答记录）

```typescript
interface DictationAttempt {
  id: string;                          // 作答记录ID
  taskId: string;                      // 关联任务ID
  userId: string;                      // 学生ID
  status: AttemptStatus;               // 作答状态
  startedAt: Date;                     // 开始作答时间
  submittedAt?: Date;                  // 提交时间
  durationSeconds?: number;            // 用时（秒）
  answerImages?: AnswerImage[];        // 拍照模式下的作答图片
  answerStrokes?: AnswerStroke[];      // 屏幕手写模式下的笔迹数据
  digitalAnswers?: DigitalAnswer[];    // 键盘输入模式下的答案
  gradingResult?: GradingResult;       // 批改结果
  feedbackShown: boolean;              // 是否已展示反馈
  createdAt: Date;
  updatedAt: Date;
}

enum AttemptStatus {
  IN_PROGRESS = 'in_progress',         // 进行中
  SUBMITTED = 'submitted',             // 已提交待批改
  GRADING = 'grading',                 // 批改中
  GRADED = 'graded',                   // 已批改
  NEED_REVIEW = 'need_review',         // 需人工复核
  COMPLETED = 'completed',             // 已完成（学生已查看反馈）
}

interface AnswerImage {
  itemId: string;                      // 对应条目ID
  imageUrl: string;                    // OSS图片URL
  boundingBox?: BoundingBox;           // 自动裁剪区域（OCR引擎标注）
  ocrProcessed: boolean;               // 是否已OCR处理
}

interface BoundingBox {
  x: number;
  y: number;
  width: number;
  height: number;
}

interface AnswerStroke {
  itemId: string;
  strokes: StrokeData[];               // 笔迹数据
  canvasWidth: number;
  canvasHeight: number;
}

interface StrokeData {
  points: { x: number; y: number; pressure: number; t: number }[];
  color: string;
  width: number;
}

interface DigitalAnswer {
  itemId: string;
  text: string;                        // 学生输入的文本
}
```

#### 2.1.4 GradingResult（批改结果）

```typescript
interface GradingResult {
  attemptId: string;
  overallScore: number;                // 总分（百分制）
  correctCount: number;                // 正确数
  incorrectCount: number;              // 错误数
  partialCount: number;                // 部分正确数（如多字词中部分正确）
  totalCount: number;                  // 总条目数
  itemResults: ItemGradingResult[];    // 逐条结果
  errorSummary: ErrorSummary;          // 错误汇总
  gradedAt: Date;
  gradedBy: GradingMethod;             // 批改方式
  reviewerId?: string;                 // 人工复核者ID（如有）
  confidence: number;                  // 批改置信度（0-1）
}

enum GradingMethod {
  OCR_AUTO = 'ocr_auto',               // OCR自动识别批改
  DIGITAL_AUTO = 'digital_auto',       // 数字输入自动比对
  AI_VISION = 'ai_vision',             // AI视觉模型批改（复杂场景）
  MANUAL = 'manual',                   // 人工批改
  HYBRID = 'hybrid',                   // 混合模式（自动+人工复核）
}

interface ItemGradingResult {
  itemId: string;
  ordinal: number;
  expectedContent: string;             // 正确内容
  recognizedContent?: string;          // OCR/输入识别到的内容
  isCorrect: boolean;
  correctnessLevel: CorrectnessLevel;  // 正确程度
  errors: CharacterError[];            // 详细错误列表
  imageUrl?: string;                   // 对应的作答图片区域
  comment?: string;                    // 批改评语
}

enum CorrectnessLevel {
  FULLY_CORRECT = 'fully_correct',     // 完全正确
  PARTIALLY_CORRECT = 'partially_correct', // 部分正确
  INCORRECT = 'incorrect',             // 错误
  BLANK = 'blank',                     // 未作答
  UNRECOGNIZABLE = 'unrecognizable',   // 无法识别
}

interface CharacterError {
  position: number;                    // 错误位置（第几个字）
  expected: string;                    // 正确字
  actual: string;                      // 实际写的字
  errorType: CharacterErrorType;       // 错误类型
  severity: ErrorSeverity;             // 严重程度
  suggestion?: string;                 // 纠正建议
}

enum CharacterErrorType {
  HOMOPHONE = 'homophone',             // 同音字混淆（如 做/作）
  VISUALLY_SIMILAR = 'visually_similar',// 形近字混淆（如 己/已/巳）
  RADICAL_ERROR = 'radical_error',     // 偏旁部首错误（如 清/请）
  MISSING_STROKE = 'missing_stroke',   // 漏画
  EXTRA_STROKE = 'extra_stroke',       // 多画
  WRONG_CHARACTER = 'wrong_character', // 完全错字
  PHONETIC_ERROR = 'phonetic_error',   // 拼音对应的字写错
  UNRECOGNIZED = 'unrecognized',       // 无法识别
  OMISSION = 'omission',               // 漏写
  EXTRA = 'extra',                     // 多写
}

enum ErrorSeverity {
  MINOR = 'minor',                     // 轻微（如笔画不规范但字形可辨认）
  MODERATE = 'moderate',               // 中等（如形近字混淆）
  MAJOR = 'major',                     // 严重（如完全错字）
}
```

interface CharacterMastery {

enum MasteryLevel {

  actual: string;
  occurredAt: Date;
}

CREATE TABLE dictation_task (

    type            VARCHAR(20)   NOT NULL DEFAULT 'dictation' COMMENT '听写类型: dictation/recitation/mixed',

    source_ref      VARCHAR(64)   COMMENT '来源引用ID',
    subject         VARCHAR(10)   NOT NULL DEFAULT 'chinese' COMMENT '学科',

    publisher_id    VARCHAR(32)   NOT NULL COMMENT '发布者ID',
    target_user_ids JSON          NOT NULL COMMENT '目标学生ID列表',
    status          VARCHAR(20)   NOT NULL DEFAULT 'draft' COMMENT '任务状态',
    scheduled_at    DATETIME      COMMENT '计划开始时间',
    deadline        DATETIME      COMMENT '截止时间',
    created_at      DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_publisher (publisher_type, publisher_id),
    INDEX idx_status (status, scheduled_at),
    INDEX idx_grade_subject (grade_level, subject),
    INDEX idx_source (source_type, source_ref)

## 3. API 接口设计

### 3.1 接口总览

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 创建听写任务 | POST | `/api/v1/dictation/tasks` | 教师/家长/系统创建任务 |
| 查询任务列表 | GET | `/api/v1/dictation/tasks` | 按发布者/学生/状态查询 |
| 获取任务详情 | GET | `/api/v1/dictation/tasks/{taskId}` | 含条目列表与配置 |
| 更新任务 | PATCH | `/api/v1/dictation/tasks/{taskId}` | 修改配置/条目/状态 |
| 删除任务 | DELETE | `/api/v1/dictation/tasks/{taskId}` | 软删除（仅draft/cancelled状态） |
| 发布任务 | POST | `/api/v1/dictation/tasks/{taskId}/publish` | 将任务状态改为published |
| 获取朗读音频 | GET | `/api/v1/dictation/tasks/{taskId}/audio` | 获取按序排列的音频URL列表 |
| 开始作答 | POST | `/api/v1/dictation/tasks/{taskId}/attempts` | 创建作答会话 |
| 提交作答 | POST | `/api/v1/dictation/attempts/{attemptId}/submit` | 提交图片/笔迹/文字 |
| 获取批改结果 | GET | `/api/v1/dictation/attempts/{attemptId}/result` | 获取批改详情 |
| 获取掌握度报告 | GET | `/api/v1/dictation/mastery/report` | 学生维度字形掌握度 |

### 4.3 掌握度更新算法

```java
/**
 * 字形掌握度增量更新算法
 * 基于Bayesian知识追踪(BKT)简化版 + 自定义启发式规则
 */
public class MasteryUpdater {
    
    // BKT参数（可按年级和难度调整）
    private static final double P_TRANSIT = 0.3;    // 从未掌握到掌握的转移概率
    private static final double P_SLIP = 0.1;       // 已掌握但答错的失误概率
    private static final double P_GUESS = 0.2;      // 未掌握但答对的猜测概率
    private static final double P_KNOW_INIT = 0.5;  // 初始掌握概率
    
    /**
     * 更新掌握度
     * @param mastery 当前掌握度记录
     * @param isCorrect 本次是否正确
     * @return 更新后的掌握概率
     */
    public double updateMastery(CharacterMastery mastery, boolean isCorrect) {
        double priorKnowledge = mapLevelToProbability(mastery.getMasteryLevel());
        
        double posterior;
        if (isCorrect) {
            // P(Know | Correct) = P(Correct|Know) * P(Know) / P(Correct)
            double pCorrect = (1 - P_SLIP) * priorKnowledge + P_GUESS * (1 - priorKnowledge);
            posterior = (1 - P_SLIP) * priorKnowledge / pCorrect;
        } else {
            // P(Know | Incorrect) = P(Incorrect|Know) * P(Know) / P(Incorrect)
            double pIncorrect = P_SLIP * priorKnowledge + (1 - P_GUESS) * (1 - priorKnowledge);
            posterior = P_SLIP * priorKnowledge / pIncorrect;
        }
        
        // 考虑转移：即使本次正确，也有概率从"未掌握"转移到"掌握"
        posterior = posterior + (1 - posterior) * P_TRANSIT;
        
        // 更新统计字段
        mastery.setTotalAttempts(mastery.getTotalAttempts() + 1);
        if (isCorrect) {
            mastery.setCorrectAttempts(mastery.getCorrectAttempts() + 1);
            mastery.setConsecutiveCorrect(mastery.getConsecutiveCorrect() + 1);
        } else {
            mastery.setConsecutiveCorrect(0);
        }
        
        // 映射概率到掌握度等级
        mastery.setMasteryLevel(mapProbabilityToLevel(posterior, mastery));
        
        // 计算下次复习时间（基于间隔重复）
        mastery.setNextReviewAt(calculateNextReview(mastery, isCorrect));
        mastery.setLastAttemptAt(LocalDateTime.now());
        
        return posterior;
    }
    
    private MasteryLevel mapProbabilityToLevel(double probability, CharacterMastery mastery) {
        if (probability >= 0.95 && mastery.getConsecutiveCorrect() >= 5) {
            return MasteryLevel.MASTERED;
        } else if (probability >= 0.80 && mastery.getConsecutiveCorrect() >= 3) {
            return MasteryLevel.PROFICIENT;
        } else if (probability >= 0.50) {
            return MasteryLevel.FAMILIAR;
        } else {
            return MasteryLevel.LEARNING;
        }
    }
    
    private LocalDateTime calculateNextReview(CharacterMastery mastery, boolean isCorrect) {
        if (!isCorrect) {
            // 答错：明天复习
            return LocalDateTime.now().plusDays(1);
        }
        
        // 答对：根据连续正确次数指数增长间隔
        int[] intervals = {1, 2, 4, 7, 15, 30}; // 天
        int idx = Math.min(mastery.getConsecutiveCorrect() - 1, intervals.length - 1);
        return LocalDateTime.now().plusDays(intervals[idx]);
    }
}
```

@Service
@RequiredArgsConstructor
public class DictationGradingService {
    
    private final DictationAttemptRepository attemptRepo;
    private final CharacterMasteryRepository masteryRepo;
    private final OcrClient ocrClient;
    private final VisionModelClient visionClient;
    private final DictationReviewService reviewService;
    private final ApplicationEventPublisher eventPublisher;
    
    @Async("gradingExecutor")
    public void gradeAsync(String attemptId) {
        DictationAttempt attempt = attemptRepo.findById(attemptId)
                .orElseThrow(() -> new BizException("DICT_ATTEMPT_NOT_FOUND"));
        
        try {
            attempt.setStatus(AttemptStatus.GRADING);
            attemptRepo.save(attempt);
            
            GradingResult result = switch (attempt.getAnswerMode()) {
                case PAPER_PHOTO -> gradeByOcr(attempt);
                case DIGITAL_HANDWRITE -> gradeByVision(attempt);
                case DIGITAL_TYPE -> gradeByTextComparison(attempt);
            };
            
            // 置信度评估
            if (result.getConfidence() < 0.75) {
                attempt.setStatus(AttemptStatus.NEED_REVIEW);
                result.setComment("部分识别置信度较低，建议人工复核");
                eventPublisher.publishEvent(new LowConfidenceGradingEvent(attemptId));
            } else {
                attempt.setStatus(AttemptStatus.GRADED);
            }
            
            attempt.setGradingResult(result);
            attemptRepo.save(attempt);
            
            // 异步更新掌握度
            if (result.getConfidence() >= 0.75) {
                updateMasteryBatch(attempt.getUserId(), result);
            }
            
            // 生成/更新复习计划
            reviewService.updateReviewPlan(attempt.getUserId(), result);
            
            // 发布批改完成事件
            eventPublisher.publishEvent(new GradingCompletedEvent(attemptId, result));
            
        } catch (Exception e) {
            log.error("Grading failed for attempt: {}", attemptId, e);
            attempt.setStatus(AttemptStatus.SUBMITTED);
            attemptRepo.save(attempt);
            eventPublisher.publishEvent(new GradingFailedEvent(attemptId, e.getMessage()));
        }
    }
    
    /**
     * OCR批改流程（拍照模式）
     */
    private GradingResult gradeByOcr(DictationAttempt attempt) {
        DictationTask task = getTask(attempt.getTaskId());
        List<ItemGradingResult> itemResults = new ArrayList<>();
        int correctCount = 0, incorrectCount = 0, partialCount = 0;
        
        for (AnswerImage answerImage : attempt.getAnswerImages()) {
            DictationItem expectedItem = findItem(task, answerImage.getItemId());
            
            // 调用OCR识别
            OcrResult ocrResult = ocrClient.recognizeHandwriting(
                    answerImage.getImageUrl(),
                    OcrOptions.builder()
                            .language("zh-Hans")
                            .characterMode(true)
                            .boundingBox(answerImage.getBoundingBox())
                            .build()
            );
            
            String recognized = ocrResult.getText().trim();
            ItemGradingResult itemResult = gradeItem(expectedItem, recognized);
            itemResult.setImageUrl(answerImage.getImageUrl());
            
            // 设置OCR置信度
            itemResult.setOcrConfidence(ocrResult.getConfidence());
            
            itemResults.add(itemResult);
            
            switch (itemResult.getCorrectnessLevel()) {
                case FULLY_CORRECT -> correctCount++;
                case PARTIALLY_CORRECT -> partialCount++;
                default -> incorrectCount++;
            }
        }
        
        double avgConfidence = itemResults.stream()
                .mapToDouble(ItemGradingResult::getOcrConfidence)
                .average().orElse(0.0);
        
        return buildResult(itemResults, correctCount, incorrectCount, 
                partialCount, task.getItems().size(), GradingMethod.OCR_AUTO, avgConfidence);
    }
    
    /**
     * AI视觉模型批改（屏幕手写或OCR低置信度复核）
     */
    private GradingResult gradeByVision(DictationAttempt attempt) {
        DictationTask task = getTask(attempt.getTaskId());
        List<ItemGradingResult> itemResults = new ArrayList<>();
        
        for (AnswerStroke answerStroke : attempt.getAnswerStrokes()) {
            DictationItem expectedItem = findItem(task, answerStroke.getItemId());
            
            // 将笔迹渲染为图片
            String renderedImageUrl = strokeRenderer.render(answerStroke);
            
            // 调用多模态视觉模型判断
            VisionGradingResult visionResult = visionClient.gradeHandwriting(
                    VisionGradingRequest.builder()
                            .imageUrl(renderedImageUrl)
                            .expectedContent(expectedItem.getContent())
                            .expectedPinyin(expectedItem.getPinyin())
                            .strictness(task.getConfig().getStrictness())
                            .gradeLevel(task.getGradeLevel())
                            .build()
            );
            
            ItemGradingResult itemResult = ItemGradingResult.builder()
                    .itemId(expectedItem.getItemId())
                    .ordinal(expectedItem.getOrdinal())
                    .expectedContent(expectedItem.getContent())
                    .recognizedContent(visionResult.getRecognizedText())
                    .isCorrect(visionResult.isCorrect())
                    .correctnessLevel(visionResult.getCorrectnessLevel())
                    .errors(visionResult.getErrors())
                    .imageUrl(renderedImageUrl)
                    .build();
            
            itemResults.add(itemResult);
        }
        
        int correctCount = (int) itemResults.stream()
                .filter(r -> r.getCorrectnessLevel() == CorrectnessLevel.FULLY_CORRECT).count();
        int incorrectCount = (int) itemResults.stream()
                .filter(r -> r.getCorrectnessLevel() == CorrectnessLevel.INCORRECT 
                          || r.getCorrectnessLevel() == CorrectnessLevel.BLANK).count();
        int partialCount = (int) itemResults.stream()
                .filter(r -> r.getCorrectnessLevel() == CorrectnessLevel.PARTIALLY_CORRECT).count();
        
        return buildResult(itemResults, correctCount, incorrectCount,
                partialCount, task.getItems().size(), GradingMethod.AI_VISION, 0.85);
    }
    
    /**
     * 逐字/词批改与错误归因
     */
    private ItemGradingResult gradeItem(DictationItem expected, String recognized) {
        String expectedContent = expected.getContent();
        
        // 完全匹配
        if (expectedContent.equals(recognized)) {
            return ItemGradingResult.builder()
                    .itemId(expected.getItemId())
                    .ordinal(expected.getOrdinal())
                    .expectedContent(expectedContent)
                    .recognizedContent(recognized)
                    .isCorrect(true)
                    .correctnessLevel(CorrectnessLevel.FULLY_CORRECT)
                    .errors(Collections.emptyList())
                    .build();
        }
        
        // 空白检测
        if (recognized == null || recognized.isBlank()) {
            return buildErrorResult(expected, recognized, 
                    CorrectnessLevel.BLANK, CharacterErrorType.OMISSION);
        }
        
        // 逐字比对（适用于词语、成语等多字内容）
        List<CharacterError> errors = new ArrayList<>();
        int correctChars = 0;
        int totalChars = expectedContent.length();
        int compareLen = Math.min(expectedContent.length(), recognized.length());
        
        for (int i = 0; i < compareLen; i++) {
            char expectedChar = expectedContent.charAt(i);
            char actualChar = i < recognized.length() ? recognized.charAt(i) : 0;
            
            if (expectedChar == actualChar) {
                correctChars++;
            } else {
                CharacterError error = analyzeCharacterError(expectedChar, actualChar, expected.getPinyin());
                errors.add(error);
            }
        }
        
        // 处理长度差异
        if (recognized.length() < expectedContent.length()) {
            for (int i = recognized.length(); i < expectedContent.length(); i++) {
                errors.add(CharacterError.builder()
                        .position(i + 1)
                        .expected(String.valueOf(expectedContent.charAt(i)))
                        .actual("")
                        .errorType(CharacterErrorType.OMISSION)
                        .severity(ErrorSeverity.MAJOR)
                        .build());
            }
        } else if (recognized.length() > expectedContent.length()) {
            errors.add(CharacterError.builder()
                    .position(expectedContent.length() + 1)
                    .expected("")
                    .actual(recognized.substring(expectedContent.length()))
                    .errorType(CharacterErrorType.EXTRA)
                    .severity(ErrorSeverity.MINOR)
                    .build());
        }
        
        CorrectnessLevel level = correctChars == totalChars 
                ? CorrectnessLevel.FULLY_CORRECT 
                : correctChars > 0 
                    ? CorrectnessLevel.PARTIALLY_CORRECT 
                    : CorrectnessLevel.INCORRECT;
        
        return ItemGradingResult.builder()
                .itemId(expected.getItemId())
                .ordinal(expected.getOrdinal())
                .expectedContent(expectedContent)
                .recognizedContent(recognized)
                .isCorrect(errors.isEmpty())
                .correctnessLevel(level)
                .errors(errors)
                .build();
    }
    
    /**
     * 单字错误归因分析
     */
    private CharacterError analyzeCharacterError(char expected, char actual, String pinyin) {
        CharacterErrorType errorType;
        
        // 检查是否同音字
        if (pinyinHelper.isHomophone(expected, actual)) {
            errorType = CharacterErrorType.HOMOPHONE;
        }
        // 检查是否形近字
        else if (charSimilarityCalculator.calculate(expected, actual) > 0.7) {
            errorType = CharacterErrorType.VISUALLY_SIMILAR;
        }
        // 检查是否偏旁不同
        else if (radicalAnalyzer.shareSamePhonetic(expected, actual)) {
            errorType = CharacterErrorType.RADICAL_ERROR;
        }
        // 检查笔画数差异
        else {
            int strokeDiff = strokeCountProvider.get(expected) - strokeCountProvider.get(actual);
            if (strokeDiff > 0 && strokeDiff <= 2) {
                errorType = CharacterErrorType.MISSING_STROKE;
            } else if (strokeDiff < 0 && strokeDiff >= -2) {
                errorType = CharacterErrorType.EXTRA_STROKE;
            } else {
                errorType = CharacterErrorType.WRONG_CHARACTER;
            }
        }
        
        String suggestion = generateCorrectionSuggestion(expected, actual, errorType);
        
        return CharacterError.builder()
                .position(0) // 由调用方设置
                .expected(String.valueOf(expected))
                .actual(String.valueOf(actual))
                .errorType(errorType)
                .severity(determineSeverity(errorType))
                .suggestion(suggestion)
                .build();
    }
    
    private String generateCorrectionSuggestion(
            char expected, char actual, CharacterErrorType errorType) {
        return switch (errorType) {
            case HOMOPHONE -> String.format(
                    "「%s」和「%s」读音相同/相近，但含义不同。「%s」%s",
                    expected, actual, expected, 
                    dictionaryService.getDefinition(expected));
            case VISUALLY_SIMILAR -> String.format(
                    "「%s」和「%s」字形相近，注意区分。「%s」的部首是「%s」，%s",
                    expected, actual, expected,
                    radicalAnalyzer.getRadical(expected),
                    dictionaryService.getDefinition(expected));
            case RADICAL_ERROR -> String.format(
                    "部首写错了。「%s」的部首是「%s」，不是「%s」",
                    expected,
                    radicalAnalyzer.getRadical(expected),
                    radicalAnalyzer.getRadical(actual));
            default -> String.format("正确写法是「%s」", expected);
        };
    }
}

@Service
@RequiredArgsConstructor
public class DictationAudioService {
    
    private final TtsClient ttsClient;
    private final RedisTemplate<String, Object> redisTemplate;
    private final OssClient ossClient;
    
    /**
     * 批量预生成听写音频
     */
    public List<String> preGenerateAudio(List<DictationItem> items, DictationConfig config) {
        List<String> audioUrls = new ArrayList<>();
        
        for (DictationItem item : items) {
            String cacheKey = String.format("dict:audio:%s_%.1f", 
                    item.getItemId(), config.getSpeed());
            
            // 查缓存
            String cached = (String) redisTemplate.opsForValue().get(cacheKey);
            if (cached != null) {
                audioUrls.add(cached);
                continue;
            }
            
            // 根据朗读模式生成文本
            String ttsText = buildTtsText(item, config.getReadMode());
            
            // 调用TTS
            TtsResult ttsResult = ttsClient.synthesize(TtsRequest.builder()
                    .text(ttsText)
                    .voice("zh-CN-XiaoxiaoNeural") // 或更适合教育的声音
                    .speed(config.getSpeed())
                    .format("mp3")
                    .build());
            
            // 上传OSS
            String objectKey = String.format("dictation/audio/%s_v%d.mp3", 
                    item.getItemId(), System.currentTimeMillis() / 1000);
            String url = ossClient.upload(objectKey, ttsResult.getAudioData());
            
            // 写缓存（7天）
            redisTemplate.opsForValue().set(cacheKey, url, Duration.ofDays(7));
            
            audioUrls.add(url);
        }
        
        return audioUrls;
    }
    
    /**
     * 根据朗读模式构建TTS文本
     */
    private String buildTtsText(DictationItem item, ReadMode readMode) {
        return switch (readMode) {
            case CHAR_BY_CHAR -> {
                // 逐字朗读，字间加SSML停顿
                StringBuilder sb = new StringBuilder("<speak>");
                for (char c : item.getContent().toCharArray()) {
                    sb.append(c).append('<').append("break time=\"300ms\"/>");
                }
                sb.append("</speak>");
                yield sb.toString();
            }
            case WORD_BY_WORD -> 
                // 直接朗读词语
                item.getContent();
            case SENTENCE_THEN_SLOW -> 
                // 先正常语速朗读，再慢速重复
                String content = item.getContent();
                content + '<' + "break time=\"500ms\"/>" + 
                '<' + "prosody rate=\"slow\">" + content + "</prosody>";
            default -> item.getContent();
        };
    }
}

    private final TextbookChapterRepository chapterRepo;

    /**
     * 基于学生薄弱点自动生成听写任务
     */
    public List<DictationItem> generateWeakItems(String userId, int itemCount, 
                                                   int gradeLevel, String textbookId) {
        // 1. 获取掌握度低下的字词
        List<CharacterMastery> weakItems = masteryRepo
                .findTop50ByUserIdAndMasteryLevelLessThanOrderByLastAttemptAtAsc(
                        userId, MasteryLevel.PROFICIENT.ordinal());
        
        // 2. 获取当前教材章节需要掌握的字词
        List<String> currentChapterWords = chapterRepo
                .findCurrentChapterWords(textbookId, gradeLevel);
        
        // 3. 交集 + 补充策略
        List<CharacterMastery> targetedWeak = weakItems.stream()
                .filter(m -> currentChapterWords.contains(m.getCharacter()))
                .limit(itemCount * 6 / 10) // 60%来自当前章节薄弱字
                .collect(Collectors.toList());
        
        List<CharacterMastery> generalWeak = weakItems.stream()
                .filter(m -> !currentChapterWords.contains(m.getCharacter()))
                .limit(itemCount * 3 / 10) // 30%来自历史薄弱字
                .collect(Collectors.toList());
        
        // 4. 剩余10%从当前章节随机抽取尚未练习的字
        int remaining = itemCount - targetedWeak.size() - generalWeak.size();
        List<String> newWords = currentChapterWords.stream()
                .filter(w -> weakItems.stream().noneMatch(m -> m.getCharacter().equals(w)))
                .collect(Collectors.collectingAndThen(
                        Collectors.toList(),
                        list -> shuffleAndTake(list, remaining)));
        
        // 5. 组装结果
        List<DictationItem> items = new ArrayList<>();
        int ordinal = 1;
        for (CharacterMastery m : targetedWeak) {
            items.add(buildItem(ordinal++, m, "weak_chapter"));
        }
        for (CharacterMastery m : generalWeak) {
            items.add(buildItem(ordinal++, m, "weak_general"));
        }
        for (String word : newWords) {
            items.add(buildNewItem(ordinal++, word, "new"));
        }
        
        // 打乱顺序（避免同类题目扎堆）
        Collections.shuffle(items);
        for (int i = 0; i < items.size(); i++) {
            items.get(i).setOrdinal(i + 1);
        }
        
        return items;
    }

### 6.1 异常分类与处理策略

| 异常场景 | 处理策略 | 用户感知 |
|---------|---------|---------|
| TTS音频生成失败 | 自动重试3次，仍失败则降级为本地TTS或跳过 | "音频生成中，请稍后重试" |
| OCR识别超时 | 30秒超时，标记为 `need_review` | "识别超时，正在人工复核中" |
| OCR识别结果为空 | 可能是空白卷或图片质量差 | "未检测到书写内容，请重新拍照" |
| 图片上传失败 | 客户端断点续传，服务端幂等校验 | "上传中，请保持网络连接" |
| AI视觉模型调用失败 | 自动降级为OCR批改 | 无感（可能准确率略降） |
| 批改过程中服务崩溃 | 消息队列重试，最终标记为 `need_review` | "批改遇到问题，正在处理" |
| 并发提交同一作答 | 乐观锁/幂等key校验 | "已提交，无需重复操作" |
| 掌握度更新失败 | 写入重试队列，异步补偿 | 无感 |

### 7.3 存储优化

- **作答图片**：按 `userId/yyyyMM/` 分目录存储，30天后自动转低清缩略图（保留批改标注，原图移至冷存储）。
- **笔迹数据**：JSON压缩存储，单次作答笔迹数据通常 < 50KB。
- **音频文件**：同一itemId+speed的音频全局共享，不同任务复用。
- **掌握度冷数据**：超过6个月未练习的字词掌握度记录归档至冷存储。

## 8. 安全考虑

### 8.1 内容安全

| 风险 | 措施 |
|------|------|
| 自定义听写内容包含不当文字 | 创建任务时调用敏感词过滤服务，拦截违规内容 |
| 学生上传与学习无关的图片 | 图片安全审核（复用通用内容审核管线） |
| AI生成内容不符合课标 | AI生成任务仅从题库/教材词库中选题，不自由生成 |

### 8.2 权限控制
