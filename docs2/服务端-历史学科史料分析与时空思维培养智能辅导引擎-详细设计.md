# 历史学科史料分析与时空思维培养智能辅导引擎 - 详细设计

## 1. 概述

### 1.1 模块定位

历史学科智能辅导引擎是 PrimeTop 全学科 AI 辅导体系中的学科专项引擎之一，面向初中、高中阶段（七年级至高三）学生，提供历史学科的智能问答、史料分析、时空思维训练、材料分析题辅导和历史解释能力培养服务。

与其他理科学科强调"解题步骤推导"不同，历史学科的核心能力维度围绕**时空观念、史料实证、历史解释、唯物史观**五大核心素养展开。本引擎需要深度理解历史叙事的因果关系、时代背景和多维视角，而非简单的知识点问答。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 历史知识问答 | 对教材知识点、历史事件、人物、制度等进行适龄化讲解 |
| 史料解读辅导 | 对文言史料、近代史料、图表史料进行分层解读和关键信息提取 |
| 材料分析题辅导 | 材料分析题（材料题）审题、答题结构规划、要点提炼 |
| 时空思维训练 | 时间轴定位、空间地图联动、跨时期比较、因果链条梳理 |
| 历史解释引导 | 多视角分析、历史评价方法、论从史出能力培养 |
| 知识网络构建 | 历史事件关联、中外对比、古今联系、专题串联 |
| 考点关联 | 紧扣中考/高考历史考点，结合真题进行专题训练 |

### 1.3 依赖关系

```
本引擎
├── AI 对话引擎（提供基础对话能力与上下文管理）
├── RAG 知识库系统（提供教材知识点检索增强）
├── 知识图谱服务（提供历史事件关联关系查询）
├── 题库服务（提供历史题目检索与同类题推荐）
├── Prompt 编排系统（提供场景化 Prompt 模板管理）
├── 学习画像服务（提供学生能力维度数据）
├── 学情分析服务（提供薄弱知识点数据）
└── 答题记录服务（提供历史答题行为数据）
```

### 1.4 适用学段

| 学段 | 年级 | 教材范围 | 辅导重点 |
| --- | --- | --- | --- |
| 初中 | 七年级 | 中国古代史 | 朝代更替、制度演变、文明成就 |
| 初中 | 八年级 | 中国近代史、现代史 | 列强侵略、民族复兴、现代化进程 |
| 初中 | 九年级 | 世界古代史、近现代史 | 文明交流、两次世界大战、冷战格局 |

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 历史事件实体（HistoricalEvent）

```typescript
interface HistoricalEvent {
  id: string;                          // 事件唯一ID
  name: string;                        // 事件名称，如"贞观之治"
  aliases: string[];                   // 别名/又称，如"贞观之治"又称"贞观政治"
  category: EventCategory;             // 事件类别
  startTime: TimeExpression;           // 时间表达式（支持模糊时间）
  endTime: TimeExpression;             // 结束时间
  duration: string;                    // 持续时间描述
  dynasties: string[];                 // 所属朝代/时期
  regions: string[];                   // 涉及地区（现代地理名称映射）
  keyFigures: string[];                // 关键历史人物ID列表
  causes: string[];                    // 原因（背景因素）
  consequences: string[];              // 结果/影响
  significance: string;                // 历史意义
  relatedEvents: string[];             // 关联事件ID列表
  textbookRefs: TextbookRef[];         // 教材引用
  examFrequency: number;               // 考频热度（0-100）
  cognitiveLevel: CognitiveLevel;      // 认知层级（了解/理解/分析/综合运用）
}

type EventCategory =
  | 'political'        // 政治事件
  | 'economic'         // 经济事件
  | 'military'         // 军事战争
  | 'cultural'         // 文化思想
  | 'diplomatic'       // 外交事件
  | 'social'           // 社会变革
  | 'technological'    // 科技发明
  | 'institutional';   // 制度变革

interface TimeExpression {
  year?: number;                       // 精确年份（公元前为负数）
  month?: number;
  day?: number;
  eraName?: string;                    // 年号纪年，如"贞观元年"
  gregorianLabel?: string;             // 公元标签，如"公元前221年"
  fuzzy?: boolean;                     // 是否模糊时间
  description?: string;                // 自然语言时间描述
}
```

#### 2.1.2 历史人物实体（HistoricalFigure）

```typescript
interface HistoricalFigure {
  id: string;

  deathTime: TimeExpression;

  evaluations: HistoricalEvaluation[]; // 历史评价

interface FigureDeed {
  eventId: string;                     // 关联事件ID
  role: string;                        // 该人物在此事件中的角色
  description: string;                 // 事迹描述
}

interface HistoricalEvaluation {
  source: string;                      // 评价来源（如《新唐书》）
  content: string;                     // 评价内容
  perspective: 'positive' | 'negative' | 'neutral' | 'mixed';
}
```

#### 2.1.3 史料实体（HistoricalSource）

```typescript
interface HistoricalSource {

  | 'letter'               // 书信
  | 'diary'                // 日记

  | 'picture'              // 历史图片/照片
```

### 2.2 数据库表结构

#### 2.2.1 历史事件表（history_event）

```sql
CREATE TABLE history_event (
    id              VARCHAR(36) PRIMARY KEY,
    name            VARCHAR(200) NOT NULL,
    aliases         JSON COMMENT '别名列表',
    category        VARCHAR(50) NOT NULL COMMENT '事件类别',
    start_year      INT COMMENT '开始年份（公元前为负）',
    end_year        INT COMMENT '结束年份',
    time_desc       VARCHAR(500) COMMENT '自然语言时间描述',
    dynasty         VARCHAR(100) COMMENT '所属朝代',
    regions         JSON COMMENT '涉及地区',
    causes          JSON COMMENT '原因列表',
    consequences    JSON COMMENT '结果/影响列表',
    significance    TEXT COMMENT '历史意义',
    background      TEXT COMMENT '时代背景',
    process         TEXT COMMENT '过程简述',
    exam_frequency  INT DEFAULT 0 COMMENT '考频热度',
    cognitive_level VARCHAR(50) DEFAULT 'understand',
    status          TINYINT DEFAULT 1 COMMENT '1=有效 0=下线',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_category (category),
    INDEX idx_dynasty (dynasty),
    INDEX idx_start_year (start_year),
    INDEX idx_exam_freq (exam_frequency),
    FULLTEXT INDEX ft_name_aliases (name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='历史事件表';
```

```sql
CREATE TABLE history_event_relation (
    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    source_event_id VARCHAR(36) NOT NULL COMMENT '源事件ID',
    target_event_id VARCHAR(36) NOT NULL COMMENT '目标事件ID',
    relation_type   VARCHAR(50) NOT NULL COMMENT '因果关系/继承关系/对比关系/影响关系',
```

### 4.4 时空思维培养算法

#### 4.4.1 时间轴自动编排

```python
def build_chronological_timeline(
    events: List[HistoricalEvent],
    student_grade: str,
    focus_category: Optional[str] = None
) -> Timeline:
    """
    将离散历史事件编排为时间轴结构，
    同时标注同期世界事件供对比参照。
    """
    # 1. 按时间排序
    sorted_events = sorted(events, key=lambda e: e.startTime.year or 0)

    # 2. 按年级过滤和调整信息密度
    grade_density = {
        "七年级": (10, 15),   # 每个时段最多展示 10-15 个事件
        "八年级": (15, 20),
        "九年级": (15, 20),
        "高一": (20, 30),
        "高三": (25, 40),
    }
    max_events, _ = grade_density.get(student_grade, (15, 20))

    # 3. 按重要性筛选
    if len(sorted_events) > max_events:
        sorted_events = sorted(
            sorted_events,
            key=lambda e: (e.examFrequency, e.cognitiveLevel.value),
            reverse=True
        )[:max_events]
        sorted_events = sorted(sorted_events, key=lambda e: e.startTime.year or 0)

    # 4. 分段（按朝代或世纪）
    segments = segment_by_era(sorted_events)

    # 5. 注入同期世界事件
    for segment in segments:
        segment.simultaneous_world = fetch_world_events(
            start_year=segment.start_year,
            end_year=segment.end_year
        )

    # 6. 标注因果链
    causal_chains = build_causal_chains(sorted_events)

    return Timeline(
        segments=segments,
        causal_chains=causal_chains,
        total_events=len(sorted_events)
    )
```

#### 4.4.2 因果链构建

```python
def build_causal_chains(events: List[HistoricalEvent]) -> List[CausalChain]:
    """
    从事件列表中提取因果关系链条。
    例：商鞅变法 → 秦国强盛 → 秦统一六国 → 中央集权确立
    """
    chains = []

    # 构建事件邻接图
    graph = {}
    for event in events:
        for related_id in event.relatedEvents:
            relation = get_event_relation(event.id, related_id)
            if relation and relation.relation_type == 'causal':
                graph.setdefault(event.id, []).append(related_id)

    # 查找最长因果链
    for start_node in graph:
        chain = dfs_causal_path(graph, start_node, max_depth=5)
        if len(chain) >= 2:
            chains.append(CausalChain(
                events=chain,
                description=generate_chain_description(chain)
            ))

    # 去重并按链长度排序
    chains = deduplicate_chains(chains)
    chains.sort(key=lambda c: len(c.events), reverse=True)

    return chains[:5]  # 返回前5条最重要的因果链
```

### 4.5 历史知识图谱查询

引擎与全局知识图谱服务的交互接口：

```python
class HistoryKnowledgeGraphClient:
    """历史知识图谱客户端，封装图查询操作"""

    async def get_event_cascade(self, event_id: str, depth: int = 2) -> dict:
        """获取事件的级联关联（原因链+影响链）"""
        query = """
        MATCH path = (e:HistoricalEvent {id: $eventId})-[:CAUSED_BY|LED_TO*1..$depth]-(related)
        RETURN path
        """
        return await self.graph_db.execute(query, {"eventId": event_id, "depth": depth})

    async def get_figure_event_network(self, figure_id: str) -> dict:
        """获取历史人物关联的事件网络"""
        query = """
        MATCH (f:HistoricalFigure {id: $figureId})-[:PARTICIPATED_IN]->(e:HistoricalEvent)
        OPTIONAL MATCH (e)-[:CAUSED_BY|LED_TO]->(e2:HistoricalEvent)
        RETURN f, e, e2
        """
        return await self.graph_db.execute(query, {"figureId": figure_id})

    async def find_cross_dyansty_patterns(
        self, pattern: str, dynasties: List[str]
    ) -> List[dict]:
        """跨朝代模式匹配（如查找所有"变法"事件）"""
        query = """
        MATCH (e:HistoricalEvent)-[:BELONGS_TO]->(d:Dynasty)
        WHERE d.name IN $dynasties AND e.category = $pattern
        RETURN e, d ORDER BY e.startTime
        """
        return await self.graph_db.execute(
            query, {"dynasties": dynasties, "pattern": pattern}
        )
```

### 6.2 RAG 检索策略

```python
class HistoryRAGService:
    """历史学科 RAG 检索增强服务"""

    async def retrieve_relevant_knowledge(
        self,
        question: str,
        grade: str,
        textbook_version: str,
        entities: List[HistoryEntity],
        top_k: int = 8
    ) -> str:
        """
        多路检索融合策略：
        1. 教材知识点精确匹配
        2. 史料向量语义检索
        3. 知识图谱关联扩展
        4. 历年真题关联
        """

        # 路径1：教材知识点检索（基于结构化标签）
        textbook_results = await self.textbook_search.search(
            query=question,
            filters={
                "subject": "history",
                "grade": grade,
                "textbook_version": textbook_version,
            },
            top_k=3
        )

        # 路径2：史料语义向量检索
        source_results = await self.vector_store.search(
            query=question,
            collection="history_sources",
            filter={"era": [e.era for e in entities if e.era]},
            top_k=3
        )

        # 路径3：知识图谱关联查询
        graph_results = []
        for entity in entities:
            if entity.type == "event":
                cascade = await self.graph_client.get_event_cascade(entity.id, depth=2)
                graph_results.extend(cascade.to_text_blocks())

        # 路径4：真题关联
        exam_results = await self.exam_db.search(
            query=question,
            filters={"subject": "history", "grade": grade},
            top_k=2
        )

        # 融合去重排序
        all_results = (
            textbook_results + source_results + graph_results + exam_results
        )
        merged = self._merge_and_deduplicate(all_results)
        ranked = self._rerank(merged, question, top_k)

        return self._format_context(ranked)

    def _rerank(
        self,
        results: List[RAGResult],
        query: str,
        top_k: int
    ) -> List[RAGResult]:
        """重排序：教材知识 > 史料 > 图谱 > 真题，同类型按相关性分数排序"""
        type_priority = {
            "textbook": 1,    # 教材知识优先级最高
            "source": 2,      # 史料次之
            "graph": 3,       # 图谱关联
            "exam": 4,        # 真题参考
        }
        results.sort(key=lambda r: (
            type_priority.get(r.source_type, 5),
            -r.relevance_score
        ))
        return results[:top_k]
```

### 6.3 史实准确性校验

```python
class HistoryFactValidator:
    """
    历史事实校验器：对 AI 输出中的历史事实进行自动校验，
    防止年代错误、人物混淆、因果关系颠倒等"AI幻觉"。
    """

    async def validate(self, ai_output: str, entities: List[HistoryEntity]) -> FactCheckResult:
        errors = []

        # 1. 年代一致性校验
        year_mentions = self._extract_year_mentions(ai_output)
        for mention in year_mentions:
            event = self._match_event(mention, entities)
            if event:
                if not self._check_year_consistency(mention, event):
                    errors.append(FactError(
                        type="year_mismatch",
                        excerpt=mention.text,
                        correct_value=event.start_time.gregorian_label,
                        severity="high"
                    ))

        # 2. 人物-事件关联校验
        figure_mentions = self._extract_figure_mentions(ai_output)
        for figure in figure_mentions:
            if not await self._verify_figure_event_link(figure, entities):
                errors.append(FactError(
                    type="figure_event_mismatch",
                    excerpt=figure.text,
                    severity="medium"
                ))

        # 3. 朝代-事件匹配校验
        dynasty_mentions = self._extract_dynasty_mentions(ai_output)
        for dynasty in dynasty_mentions:
            if not await self._verify_dynasty_context(dynasty, entities):
                errors.append(FactError(
                    type="dynasty_mismatch",
                    excerpt=dynasty.text,
                    severity="high"
                ))

        # 4. 因果逻辑校验
        causal_claims = self._extract_causal_claims(ai_output)
        for claim in causal_claims:
            if not await self._verify_causal_relation(claim):
                errors.append(FactError(
                    type="causal_error",
                    excerpt=claim.text,
                    severity="medium"
                ))

        return FactCheckResult(
            passed=len(errors) == 0,
            errors=errors,
            confidence=1.0 - len(errors) * 0.15
        )
```

## 9. 性能优化

### 9.1 关键性能指标

| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 历史问答首 token | ≤ 2.5s | 低于全科平均（历史问题通常上下文较长） |
| 史料解读完整响应 | ≤ 8s | 四层分析需要较多生成内容 |
| 材料题指导响应 | ≤ 15s | 多材料多设问，需要更长的推理 |
| 时间轴查询 | ≤ 200ms | 纯数据查询，走缓存 |
| 因果网络查询 | ≤ 500ms | 图谱查询 2 跳 |
| RAG 检索 | ≤ 800ms | 多路检索融合 |

### 9.2 优化措施

1. **预计算专题路径**：热门专题（如"中央集权演变""中国近代化历程"）预先计算学习路径，缓存到 Redis
2. **史料索引预热**：教材中出现的核心史料在系统启动时加载到本地缓存
3. **RAG 检索并行化**：四路检索（教材/史料/图谱/真题）使用 CompletableFuture 并行执行
4. **AI 输出分段流式**：对于史料解读等长内容，按层级流式输出，减少用户等待感
5. **时间轴预聚合**：每个朝代的时间轴数据预聚合为 JSON，避免实时查询

| 答题记录服务 | 事件消息 | 答题行为数据回传 |

### 12.2 事件流

```
历史问答完成 → 发布 HistoryAskCompletedEvent
    ├──→ [学情分析] 更新历史知识点掌握度
    ├──→ [错题本] 若涉及错误作答则收录
    ├──→ [学习画像] 更新历史学科能力维度
    └──→ [推荐系统] 触发相关内容推荐

史料解读完成 → 发布 SourceAnalysisCompletedEvent
    ├──→ [学习画像] 记录史料分析能力练习
    └──→ [学情分析] 更新史料解读维度掌握度

材料分析题完成 → 发布 MaterialQuestionCompletedEvent
    ├──→ [答题记录] 保存答题数据
    ├──→ [题库] 记录题目使用情况
    └──→ [学情分析] 更新综合分析能力评估
```
