# 客户端路由与深链接系统 - 详细设计

> 版本：v1.0 | 日期：2026-05-23 | 状态：初稿

## 1. 模块概述

### 1.1 功能定位

客户端路由与深链接系统（Routing & Deep Link System）是 PrimeTop APP 的横切基础设施，负责管理所有页面导航、深链接解析、外部跳转入口和路由守卫。该系统确保：

1. 用户通过推送通知、分享链接、短信、QR 码等入口能准确跳转到目标页面
2. 各角色（学生/家长/教师）看到的导航结构不同，路由自动适配
3. 敏感页面（会员内容、年龄限制功能）经过守卫校验
4. 导航状态在进程重启后可恢复
5. 页面跳转流畅，动画与分龄 UI 适配一致

```
/{scope}/{module}/{page}?{queryParams}

scope   = 主导航域（home / learn / tools / profile / parent / teacher / admin）

page    = 具体页面
```

- `/home` — 首页

- `/tools/periodic-table` — 元素周期表

## 3. 路由守卫系统

### 3.1 守卫架构

采用 GoRouter 的 `redirect` 和 `redirectList` 实现链式守卫。守卫按优先级顺序执行，任一守卫触发重定向即终止后续守卫。

```dart
/// 守卫优先级：数值越小优先级越高
enum GuardPriority {
  maintenance,    // 0 - 维护模式检查
  upgrade,        // 1 - 版本升级检查
  auth,           // 2 - 登录状态检查
  role,           // 3 - 角色权限检查
  age,            // 4 - 年龄/学段检查
  membership,     // 5 - 会员权益检查
  featureFlag,    // 6 - 特性开关检查
  youthMode,      // 7 - 青少年模式检查
  antiAddiction,   // 8 - 防沉迷检查
}
```

### 3.2 守卫链执行流程

```
用户访问 /learn/exam/paper/123
         │
    ┌────▼─────┐
    │ 维护检查  │ → 是 → /maintenance
    └────┬─────┘
    ┌────▼─────┐
    │ 升级检查  │ → 需要 → /upgrade
    └────┬─────┘
    ┌────▼─────┐
    │ 登录检查  │ → 未登录 → /login（携带 returnTo）
    └────┬─────┘
    ┌────▼─────┐
    │ 角色检查  │ → 角色不匹配 → 对应角色首页
    └────┬─────┘
    ┌────▼─────┐
    │ 年龄检查  │ → 年龄不足 → 提示弹窗 + 返回
    └────┬─────┘
    ┌────▼─────┐
    │ 会员检查  │ → 权益不足 → /profile/membership（携带来源）
    └────┬─────┘
    ┌────▼─────┐
    │ 开关检查  │ → 功能未开放 → 对应降级页
    └────┬─────┘
    ┌────▼─────┐
    │ 青少模式  │ → 功能受限 → 提示弹窗
    └────┬─────┘
    ┌────▼─────┐
    │ 防沉迷    │ → 时段/时长超限 → 锁定提示
    └────┬─────┘
         │
    ✅ 允许访问目标页面
```

### 3.3 守卫实现

#### 3.3.1 路由守卫注册表

```dart
/// 路由守卫接口
abstract class RouteGuard {
  GuardPriority get priority;
  
  /// 返回 null 表示放行，返回 GoRouteMatch 列表表示重定向
  Future<GoRouterState?> redirect(GoRouterState state);
}

/// 守卫注册中心
class GuardRegistry {
  final List<RouteGuard> _guards = [];
  
  void register(RouteGuard guard) {
    _guards.add(guard);
    _guards.sort((a, b) => a.priority.index.compareTo(b.priority.index));
  }
  
  List<RouteGuard> get guards => List.unmodifiable(_guards);
}
```

#### 3.3.2 登录守卫

```dart
class AuthGuard implements RouteGuard {
  @override
  GuardPriority get priority => GuardPriority.auth;
  
  final AuthService _authService;
  final Set<String> _publicRoutes = {
    '/splash', '/login', '/login/phone', '/login/third-party',
    '/register', '/onboarding', '/onboarding/welcome',
    '/onboarding/role-select', '/error', '/maintenance', '/upgrade',
    '/web-view',
  };
  
  @override
  Future<GoRouterState?> redirect(GoRouterState state) async {
    final path = state.matchedLocation;
    
    // 公开路由放行
    if (_publicRoutes.any((r) => path.startsWith(r))) return null;
    
    // 已登录放行
    if (_authService.isLoggedIn) return null;
    
    // 未登录 → 重定向到登录页，携带回跳地址
    return GoRouterState(
      state.router,
      matchedLocation: '/login',
      queryParameters: {'returnTo': path},
    );
  }
}
```

#### 3.3.3 角色守卫

```dart
class RoleGuard implements RouteGuard {
  @override
  GuardPriority get priority => GuardPriority.role;
  
  final AuthService _authService;
  
  /// 路由前缀 → 允许的角色
  static const _roleRouteMap = <String, Set<UserRole>>{
    '/parent':  {UserRole.parent},
    '/teacher': {UserRole.teacher},
    '/ai':      {UserRole.student},
    '/learn':   {UserRole.student},
    '/mistakes': {UserRole.student},
    '/enlightenment': {UserRole.student},
  };
  
  /// 共享路由（所有角色可访问）
  static const _sharedRoutes = <String>{
    '/home', '/profile', '/tools', '/home/search',
  };
  
  @override
  Future<GoRouterState?> redirect(GoRouterState state) async {
    final path = state.matchedLocation;
    final role = _authService.currentRole;
    
    // 共享路由放行
    if (_sharedRoutes.any((r) => path == r || path.startsWith('$r/'))) {
      return null;
    }
    
    // 检查路由角色限制
    for (final entry in _roleRouteMap.entries) {
      if (path.startsWith(entry.key)) {
        if (entry.value.contains(role)) return null;
        // 角色不匹配 → 跳转到该角色的首页
        return _roleHomeRedirect(role);
      }
    }
    
    return null; // 无限制的路由放行
  }
  
  GoRouterState _roleHomeRedirect(UserRole role) {
    final homePaths = {
      UserRole.student: '/home',
      UserRole.parent: '/parent/home',
      UserRole.teacher: '/teacher/home',
    };
    return GoRouterState(
      /* router */ null,
      matchedLocation: homePaths[role] ?? '/home',
    );
  }
}
```

#### 3.3.4 会员权益守卫

```dart
class MembershipGuard implements RouteGuard {
  @override
  GuardPriority get priority => GuardPriority.membership;
  
  final MembershipService _membershipService;
  final FeatureGateService _featureGate;
  
  /// 路由 → 所需权益等级
  /// free = 免费可访问, basic = 基础会员, premium = 高级会员
  static const _membershipRequired = <String, String>{
    '/learn/exam/practice': 'basic',
    '/learn/enrollment': 'basic',
    '/essay/review': 'basic',
    '/recite/practice': 'free',    // 背诵基础功能免费
    '/profile/analysis/report': 'basic',  // 详细报告需会员
  };
  
  /// 按通配符匹配，精确路径优先
  String? _matchRequired(String path) {
    // 精确匹配
    if (_membershipRequired.containsKey(path)) {
      return _membershipRequired[path];
    }
    // 前缀匹配（最长前缀优先）
    final sorted = _membershipRequired.keys.toList()
      ..sort((a, b) => b.length.compareTo(a.length));
    for (final prefix in sorted) {
      if (path.startsWith(prefix) && _membershipRequired[prefix] != 'free') {
        return _membershipRequired[prefix];
      }
    }
    return null;
  }
  
  @override
  Future<GoRouterState?> redirect(GoRouterState state) async {
    final required = _matchRequired(state.matchedLocation);
    if (required == null || required == 'free') return null;
    
    final level = _membershipService.currentLevel;
    final satisfied = _levelSatisfied(level, required);
    if (satisfied) return null;
    
    // 权益不足 → 展示权益拦截弹窗（而非直接跳转）
    // 通过 Shell 路由的 overlay 展示弹窗，保留当前路由上下文
    _membershipService.showUpsellDialog(
      requiredLevel: required,
      currentLevel: level,
      source: state.matchedLocation,
    );
    return null; // 不重定向，由弹窗处理
  }
  
  bool _levelSatisfied(String current, String required) {
    const order = ['free', 'basic', 'premium'];
    return order.indexOf(current) >= order.indexOf(required);
  }
}
```

#### 3.3.5 防沉迷守卫

```dart
class AntiAddictionGuard implements RouteGuard {
  @override
  GuardPriority get priority => GuardPriority.antiAddiction;
  
  final AntiAddictionService _antiAddiction;
  
  /// 免审查路由（不受防沉迷限制）
  static const _exemptRoutes = <String>{
    '/splash', '/login', '/register', '/onboarding',
    '/maintenance', '/upgrade', '/error',
    '/profile/settings', '/profile/youth-mode',
    '/parent',
  };
  
  @override
  Future<GoRouterState?> redirect(GoRouterState state) async {
    final path = state.matchedLocation;
    
    // 免审查路由放行
    if (_exemptRoutes.any((r) => path.startsWith(r))) return null;
    
    // 非学生角色不受防沉迷限制
    if (_antiAddiction.currentRole != UserRole.student) return null;
    
    final status = await _antiAddiction.checkStatus();
    
    if (status.isLocked) {
      // 时段锁定（夜间/超出每日限额） → 显示锁定页
      return GoRouterState(
        state.router,
        matchedLocation: '/home',
        extra: AntiAddictionLockArgs(
          reason: status.lockReason,
          unlockTime: status.unlockTime,
        ),
      );
    }
    
    if (status.shouldRestReminder) {
      // 休息提醒（不阻断，弹窗提醒）
      _antiAddiction.showRestReminder(status.usedMinutes);
    }
    
    return null;
  }
}
```

```dart
class DeepLink {
  final String targetPath;       // 内部路由路径
  final Map<String, String> queryParams;
  final DeepLinkSource source;   // 来源
  final String? sourceDetail;    // 来源详情（如推送 ID、分享者 ID）
```

```dart
class LinkParser {
  /// 外部 URL → 内部路由的映射规则
  static const _urlMappings = <UrlMapping>[
    // === 自定义 Scheme 映射 ===
    UrlMapping(
      pattern: RegExp(r'^primetop://home$'),

    ),

      targetPath: '/ai/photo',
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://learn/textbook/chapter/(.+)$'),
      targetPath: '/learn/textbook/chapter',
      pathParams: {'id': 1},  // 第 1 个捕获组 → id 参数
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://learn/lesson/(\d+)$'),
      targetPath: '/learn/textbook/lesson',
      pathParams: {'id': 1},
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://mistakes/review$'),
      targetPath: '/mistakes/review',
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://mistakes/detail/(\d+)$'),
      targetPath: '/mistakes/detail',
      pathParams: {'id': 1},
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://essay/create$'),
      targetPath: '/essay/create',
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://essay/review/(\d+)$'),
      targetPath: '/essay/review',
      pathParams: {'id': 1},
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://enlightenment/pinyin$'),
      targetPath: '/enlightenment/pinyin',
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://tools/periodic-table$'),
      targetPath: '/tools/periodic-table',
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://tools/calculator$'),
      targetPath: '/tools/calculator',
    ),
    UrlMapping(
      pattern: RegExp(r'^primetop://profile/membership$'),
      targetPath: '/profile/membership',
    ),
    
    // === HTTPS Universal Link 映射 ===
    UrlMapping(
      pattern: RegExp(r'^https://app\.primetop\.cn/ai/chat$'),
      targetPath: '/ai/chat',
    ),
    UrlMapping(
      pattern: RegExp(r'^https://app\.primetop\.cn/learn/lesson/(\d+)$'),
      targetPath: '/learn/textbook/lesson',
      pathParams: {'id': 1},
    ),
    UrlMapping(
      pattern: RegExp(r'^https://app\.primetop\.cn/share/question/(.+)$'),
      targetPath: '/ai/chat',
      queryTransform: {'sharedQuestion': 'q'},
    ),
    UrlMapping(
      pattern: RegExp(r'^https://app\.primetop\.cn/share/essay/(.+)$'),
      targetPath: '/essay/review',
    ),
    UrlMapping(
      pattern: RegExp(r'^https://app\.primetop\.cn/invite/(.+)$'),
      targetPath: '/register',
      queryTransform: {'inviteCode': 'code'},
    ),
    UrlMapping(
      pattern: RegExp(r'^https://app\.primetop\.cn/campaign/(.+)$'),
      targetPath: '/web-view',
      queryTransform: {'_self': 'url'},  // 特殊标记：campaign slug → WebView URL
    ),
  ];
  
  /// 解析外部 URL
  ParseResult parse(String url, DeepLinkSource source) {
    try {
      final uri = Uri.parse(url);
      
      for (final mapping in _urlMappings) {
        final match = mapping.pattern.firstMatch(url);
        if (match != null) {
          final params = <String, String>{};
          
          // 处理路径参数
          mapping.pathParams?.forEach((name, groupIndex) {
            params[name] = match.group(groupIndex)!;
          });
          
          // 处理查询参数
          uri.queryParameters.forEach((key, value) {
            final mappedKey = mapping.queryTransform?[key] ?? key;
            params[mappedKey] = value;
          });
          
          return ParseSuccess(DeepLink(
            targetPath: mapping.targetPath,
            queryParams: params,
            source: source,
            receivedAt: DateTime.now(),
            deferred: false,
          ));
        }
      }
      
      return ParseUnknown(url);
    } catch (e) {
      return ParseError(url, e.toString());
    }
  }
}

/// URL 映射规则
class UrlMapping {
  final RegExp pattern;
  final String targetPath;
  final Map<String, int>? pathParams;     // 参数名 → 捕获组索引
  final Map<String, String>? queryTransform;  // 原始参数名 → 目标参数名
  
  const UrlMapping({
    required this.pattern,
    required this.targetPath,
    this.pathParams,
    this.queryTransform,
  });
}
```

#### 4.2.4 深链接路由器

```dart
class LinkRouter {
  final LinkParser _parser;
  final GoRouter _router;
  final GuardRegistry _guards;
  final DeepLinkLogger _logger;
  
  /// 处理外部链接
  Future<void> handleDeepLink(String url, DeepLinkSource source) async {
    final result = _parser.parse(url, source);
    
    switch (result) {
      case ParseSuccess(:final link):
        _logger.logLinkReceived(link);
        await _navigateToLink(link);
        
      case ParseUnknown(:final rawUrl):
        _logger.logUnknownLink(rawUrl, source);
        // 未识别的 HTTPS 链接 → 降级到 WebView
        if (rawUrl.startsWith('https://')) {
          _router.go('/web-view', extra: {'url': rawUrl});
        }
        
      case ParseError(:final rawUrl, :final error):
        _logger.logLinkError(rawUrl, error);
        _router.go('/error', extra: {'message': '无法打开链接'});
    }
  }
  
  Future<void> _navigateToLink(DeepLink link) async {
    // 执行路由守卫（守卫内部决定是否放行或重定向）
    _router.go(
      link.targetPath,
      queryParams: link.queryParams,
      extra: _buildExtra(link),
    );
  }
  
  Map<String, dynamic> _buildExtra(DeepLink link) => {
    'deepLinkSource': link.source,
    'deepLinkSourceDetail': link.sourceDetail,
    'deepLinkReceivedAt': link.receivedAt,
  };
}
```

```dart
class PushLinkHandler {
  final LinkRouter _linkRouter;
  
  /// 从推送数据构建深链接并路由
  Future<void> handlePushPayload(Map<String, dynamic> data) async {
    final targetPath = data['target_path'] as String?;
    final targetParams = (data['target_params'] as Map<String, dynamic>?) 
        ?.cast<String, String>() ?? {};
    final targetId = data['target_id'] as String?;
    final fallbackPath = data['fallback_path'] as String? ?? '/home';
    
    if (targetPath == null) {
      _linkRouter.handleDeepLink(
        'primetop://$fallbackPath',
        DeepLinkSource.pushNotification,
      );
      return;
    }
    
    // 替换路径中的 ID 占位符
    var resolvedPath = targetPath;
    if (targetId != null) {
      resolvedPath = resolvedPath.replaceAll('{id}', targetId);
    }
    
    // 构建查询字符串
    final queryString = targetParams.entries
        .map((e) => '${e.key}=${Uri.encodeComponent(e.value)}')
        .join('&');
    
    final url = 'primetop://$resolvedPath${queryString.isNotEmpty ? '?$queryString' : ''}';
    _linkRouter.handleDeepLink(url, DeepLinkSource.pushNotification);
  }
}
```

### 6.1 设计目标

1. APP 被系统回收后重启时，恢复到用户最后浏览的页面
2. 多任务切换后，导航栈保持一致
3. 登录/退出登录时，切换到对应角色的首页
4. 首次安装后，走引导流程

### 6.2 状态存储

```dart
class NavigationStateService {
  final SharedPreferences _prefs;
  
  static const _keyLastRoute = 'nav_last_route';
  static const _keyLastParams = 'nav_last_params';
  static const _keyRoleHomeRoute = 'nav_role_home';
  static const _keyRestoreEnabled = 'nav_restore_enabled';
  
  /// 保存当前路由状态
  void saveCurrentRoute(String path, {Map<String, String>? params}) {
    _prefs.setString(_keyLastRoute, path);
    if (params != null && params.isNotEmpty) {
      _prefs.setString(_keyLastParams, jsonEncode(params));
    }
  }
  
  /// 读取上次路由
  SavedRoute? getLastRoute() {
    final path = _prefs.getString(_keyLastRoute);
    if (path == null) return null;
    
    Map<String, String>? params;
    final paramsJson = _prefs.getString(_keyLastParams);
    if (paramsJson != null) {
      params = (jsonDecode(paramsJson) as Map).cast<String, String>();
    }
    
    return SavedRoute(path: path, params: params);
  }
  
  /// 清除保存的路由（用于登录/退出/角色切换）
  void clearSavedRoute() {
    _prefs.remove(_keyLastRoute);
    _prefs.remove(_keyLastParams);
  }
  
  /// 设置角色首页路由
  void setRoleHomeRoute(UserRole role) {
    const homeRoutes = {
      UserRole.student: '/home',
      UserRole.parent: '/parent/home',
      UserRole.teacher: '/teacher/home',
    };
    _prefs.setString(_keyRoleHomeRoute, homeRoutes[role] ?? '/home');
  }
  
  /// 获取角色首页路由
  String getRoleHomeRoute() {
    return _prefs.getString(_keyRoleHomeRoute) ?? '/home';
  }
}

class SavedRoute {
  final String path;
  final Map<String, String>? params;
  const SavedRoute({required this.path, this.params});
}
```

### 6.3 恢复策略

```dart
/// APP 启动时的路由恢复逻辑
class AppNavigationInitializer {
  final NavigationStateService _navState;
  final AuthService _auth;
  final OnboardingService _onboarding;
  
  /// 获取初始路由
  Future<String> resolveInitialRoute() async {
    // 1. 检查是否首次启动 → 引导流程
    if (_onboarding.isFirstLaunch) {
      return '/onboarding/welcome';
    }
    
    // 2. 检查是否完成引导 → 未完成则继续
    if (!_onboarding.isCompleted) {
      return '/onboarding/${_onboarding.currentStep}';
    }
    
    // 3. 检查登录状态
    if (!_auth.isLoggedIn) {
      return '/login';
    }
    
    // 4. 已登录 → 恢复上次路由或角色首页
    final saved = _navState.getLastRoute();
    if (saved != null && _navState.shouldRestore) {
      return saved.path;
    }
    
    return _navState.getRoleHomeRoute();
  }
}
```

```dart
    required GoRouterState state,
    required Widget child,

  }) {
```

## 10. 错误处理

### 10.1 错误场景

| 场景 | 处理策略 |
|------|----------|
| 无法解析的深链接 URL | 记录日志，跳转首页，Toast 提示"链接无效" |
| 目标页面需要登录但未登录 | 重定向到登录页，登录成功后自动回跳 |
| 目标页面不存在（404） | 跳转全局错误页，提供"返回首页"按钮 |
| 守卫循环重定向 | 检测循环（同一路径 3 次重定向），强制跳转首页 |
| 路由参数缺失（如 `/mistakes/detail/`） | 跳转列表页，Toast 提示 |
| 外部链接打开 APP 失败 | Universal Link 降级到自定义 Scheme → 降级到应用商店 |
| APP 版本过低，目标页面不存在 | 升级守卫拦截，引导升级 |
| WebView 加载失败 | 展示错误页 + 重试按钮 |
| 导航栈过深（>20 层） | 自动清除底层路由，保留最近 10 层 |

### 10.2 错误码

| 错误码 | 含义 | 处理 |
|--------|------|------|
| `ROUTE_001` | 路由不存在 | 404 页面 |
| `ROUTE_002` | 路由参数缺失 | 回退到列表页 |
| `ROUTE_003` | 参数格式错误（如 ID 非数字） | 回退到列表页 |
| `ROUTE_004` | 守卫循环检测 | 强制跳转首页 |
| `ROUTE_005` | 深链接解析失败 | 跳转首页 + Toast |
| `ROUTE_006` | WebView 加载超时 | 展示重试页 |
| `ROUTE_007` | 剪贴板链接解析失败 | 静默忽略 |

### 10.3 防循环机制

```dart
class LoopDetector {
  final int _maxRedirects;
  final List<String> _history = [];
  
  LoopDetector({int maxRedirects = 3}) : _maxRedirects = maxRedirects;
  
  /// 检查是否发生循环重定向
  bool isLoop(String path) {
    _history.add(path);
    if (_history.length > _maxRedirects) {
      _history.removeAt(0);
    }
    // 连续 N 次重定向到相同路径 → 循环
    return _history.length >= _maxRedirects && 
           _history.every((p) => p == path);
  }
  
  void reset() => _history.clear();
}
```
