> **文档版本**: v1.0

## 1. 概述

### 1.1 设计目标

为平台中所有教育内容（题目、解析、AI 讲解、微课、练习等）自动标注**布鲁姆认知层级**（Bloom's Taxonomy Cognitive Level），建立从"记忆→理解→应用→分析→评价→创造"的六级认知深度分类体系，驱动以下核心能力：

1. **认知平衡性保障**：确保学生的练习和复习在六个认知层级上均衡分布，避免过度停留在低层级（机械记忆）。
2. **认知递进推荐**：根据学生当前能力，推荐略高认知层级的内容（最近发展区）。
3. **考试认知对齐**：将历年真题和模拟题标注认知层级，帮助学生适应考试的认知要求。
4. **教师认知图谱**：为教师提供班级在各认知层级上的表现分布，辅助教学策略调整。
5. **内容质量审核**：检测题库中认知层级单一（如全是"记忆"层）的章节，辅助内容建设。

### 1.2 核心挑战

| 挑战 | 说明 | 应对策略 |
|------|------|----------|
| 分类准确性 | AI 自动分类可能存在误判 | 多模型投票 + 人工抽检校准 |
| 学科差异 | 不同学科的认知层级表现不同 | 按学科训练专用分类器 |
| 跨层级题目 | 部分综合题横跨多个认知层级 | 支持主层级 + 副层级标注 |
| 动态变化 | 课标改革导致认知要求变化 | 支持课标版本感知的动态分类 |
| 冷启动 | 新增内容无历史数据 | AI 零样本分类 + 人工标注模板 |

### 1.3 布鲁姆认知层级定义

| 层级 | 中文名 | 英文 | 认知动作 | 题目示例 |
|------|--------|------|----------|----------|
| L1 | 记忆 | Remember | 回忆、识别、列举 | "中国的首都是哪里？" |
| L2 | 理解 | Understand | 解释、归纳、比较 | "用自己的话解释光合作用的过程" |
| L3 | 应用 | Apply | 计算、实施、解决 | "已知 f(x)=2x+3，求 f(5)" |
| L4 | 分析 | Analyze | 区分、组织、归因 | "分析下列数据中的变化趋势及其原因" |
| L5 | 评价 | Evaluate | 判断、批判、论证 | "评价两种历史观点的合理性并说明理由" |
| L6 | 创造 | Create | 设计、构建、生成 | "设计一个实验验证假设并写出实验方案" |

## 4. 核心分类算法

### 4.1 分类流程总览

```text
输入内容
  │
  ├──→ ① 规则预分类器 (快速、低延迟)
  │     │ 关键词匹配 + 结构特征
  │     │ 置信度 > 0.85 → 直接输出
  │     │ 置信度 0.50~0.85 → 进入 AI 分类的低优先级队列
  │     │ 置信度 < 0.50 或 无匹配 → 进入 AI 分类
  │     │
  ├──→ ② AI 多模型分类器 (高准确率)
  │     │ 构建分类 Prompt
  │     │ 并行调用 2-3 个模型
  │     │ 多数投票 + 置信度计算
  │     │
  ├──→ ③ 后处理
  │     │ 学科规则修正
  │     │ 副层级推断
  │     │ 置信度低于阈值 → 创建校准任务
  │     │
  └──→ 输出：主层级 + 副层级 + 置信度 + 特征快照
```

### 4.2 规则预分类器

```java
/**
 * 规则预分类器：基于关键词和结构特征进行快速初步分类
 */
public class BloomRuleClassifier {

    private final BloomRuleRepository ruleRepository;
    
    /**
     * 对内容进行规则预分类
     * @param content 待分类的内容文本
     * @param metadata 内容元数据（学科、学段、题型等）
     * @return 分类结果，可能为空（规则未命中）
     */
    public Optional<BloomRuleResult> classify(String content, ContentMetadata metadata) {
        // 1. 加载适用的规则集
        List<BloomRule> rules = ruleRepository.findActiveRules(
            metadata.getSubjectCode(), 
            metadata.getGradeBand()
        );
        
        // 2. 对每个层级计算匹配得分
        Map<BloomLevel, Double> scores = new EnumMap<>(BloomLevel.class);
        Map<BloomLevel, List<String>> matchedKeywords = new EnumMap<>(BloomLevel.class);
        
        for (BloomRule rule : rules) {
            double score = calculateRuleScore(content, rule);
            if (score > 0) {
                scores.merge(rule.getTargetLevel(), score * rule.getWeight(), Double::sum);
                matchedKeywords.computeIfAbsent(rule.getTargetLevel(), k -> new ArrayList<>())
                    .addAll(extractMatchedKeywords(content, rule));
            }
        }
        
        // 3. 如果没有任何匹配，返回空
        if (scores.isEmpty()) {
            return Optional.empty();
        }
        
        // 4. 选择得分最高的层级
        Map.Entry<BloomLevel, Double> best = Collections.max(
            scores.entrySet(), Map.Entry.comparingByValue()
        );
        
        // 5. 计算置信度（归一化得分差异）
        double totalScore = scores.values().stream().mapToDouble(Double::doubleValue).sum();
        double confidence = best.getValue() / totalScore;
        
        return Optional.of(BloomRuleResult.builder()
            .level(best.getKey().getLevel())
            .confidence(confidence)
            .matchedKeywords(matchedKeywords.get(best.getKey()))
            .allScores(scores)
            .build());
    }
    
    /**
     * 计算单条规则的匹配得分
     */
    private double calculateRuleScore(String content, BloomRule rule) {
        double score = 0;
        String normalizedContent = content.toLowerCase();
        
        // 关键词匹配
        for (String pattern : rule.getKeywordPatterns()) {
            Pattern p = Pattern.compile(pattern, Pattern.CASE_INSENSITIVE);
            Matcher m = p.matcher(normalizedContent);
            int matchCount = 0;
            while (m.find()) {
                matchCount++;
            }
            if (matchCount > 0) {
                score += rule.getWeight() * Math.min(matchCount, 3); // 单关键词最多计3次
            }
        }
        
        // 结构特征匹配
        if (rule.getStructurePatterns() != null) {
            score += evaluateStructurePatterns(content, rule.getStructurePatterns());
        }
        
        return score;
    }
    
    /**
     * 评估结构特征
     */
    private double evaluateStructurePatterns(String content, JsonNode patterns) {
        double score = 0;
        
        // 题型特征：如"选择题"倾向L1-L2，"论述题"倾向L4-L5
        if (patterns.has("question_type_weight")) {
            // 通过外部传入的题型信息加权
        }
        
        // 长度特征：长文本更可能是分析/评价
        if (patterns.has("min_length")) {
            int minLength = patterns.get("min_length").asInt();
            if (content.length() > minLength) {
                score += 0.3;
            }
        }
        
        // 公式密度：含较多数学公式倾向应用/分析
        if (patterns.has("formula_density_threshold")) {
            double formulaRatio = countFormulas(content) / (double) content.length();
            if (formulaRatio > patterns.get("formula_density_threshold").asDouble()) {
                score += 0.5;
            }
        }
        
        return score;
    }
}
```

注意：
1. 优先依据题目要求学生执行的核心认知动作来判断层级
2. 如果题目包含多个小问且认知层级不同，以最高认知要求为准
3. "计算/求解"类题目默认 L3，但如果要求"分析计算过程并论证方法选择"则可能为 L4 或 L5
4. 作文/写作题通常为 L6（创造），但读后感/赏析可能为 L4 或 L5
5. 实验设计题为 L6，实验现象解释为 L2 或 L4

```java
/**
 * AI 多模型投票分类器
 */
public class BloomAIClassifier {

    private final List<ModelClient> modelClients;  // 多个 LLM 客户端
    private final PromptTemplateService promptService;
    private final ObjectMapper objectMapper;
    
    private static final double CONFIDENCE_THRESHOLD = 0.75;
    private static final double LOW_CONFIDENCE_THRESHOLD = 0.55;
    private static final int VOTE_TIMEOUT_MS = 8000;
    
    /**
     * 多模型并行分类 + 投票
     */
    @Async("bloomClassifyExecutor")
    public CompletableFuture<BloomAIResult> classify(
            String content, ContentMetadata metadata) {
        
        // 1. 构建分类 Prompt
        String prompt = promptService.render("bloom-classify", Map.of(
            "subject", metadata.getSubjectName(),
            "grade_band", metadata.getGradeBandName(),
            "question_type", metadata.getQuestionType(),
            "content_text", truncate(content, 2000)
        ));
        
        // 2. 并行调用多个模型
        List<CompletableFuture<BloomModelResponse>> futures = modelClients.stream()
            .map(client -> CompletableFuture.supplyAsync(() -> 
                callModelWithRetry(client, prompt, VOTE_TIMEOUT_MS)
            ))
            .toList();
        
        // 3. 收集结果
        List<BloomModelResponse> responses = futures.stream()
            .map(f -> f.exceptionally(ex -> null).join())
            .filter(Objects::nonNull)
            .toList();
        
        if (responses.isEmpty()) {
            log.error("所有模型分类调用失败, content_id={}", metadata.getContentId());
            return CompletableFuture.completedFuture(
                BloomAIResult.fallback(metadata)
            );
        }
        
        // 4. 多数投票
        return CompletableFuture.completedFuture(aggregateVotes(responses, metadata));
    }
    
    /**
     * 聚合投票结果
     */
    private BloomAIResult aggregateVotes(List<BloomModelResponse> responses, 
                                          ContentMetadata metadata) {
        // 统计每个层级获得的投票
        Map<Integer, List<ModelVote>> levelVotes = responses.stream()
            .flatMap(r -> Stream.of(new ModelVote(
                r.getModelName(), 
                r.getPrimaryLevel(), 
                r.getConfidence()
            )))
            .collect(Collectors.groupingBy(ModelVote::level));
        
        // 按加权票数排序（权重 = 模型权重 × 模型置信度）
        int bestLevel = levelVotes.entrySet().stream()
            .max(Comparator.comparingDouble(e -> 
                e.getValue().stream().mapToDouble(v -> 
                    getModelWeight(v.modelName()) * v.confidence()
                ).sum()
            ))
            .map(Map.Entry::getKey)
            .orElse(2); // 默认"理解"
        
        // 计算最终置信度
        double totalWeight = responses.stream()
            .mapToDouble(r -> getModelWeight(r.getModelName()) * r.getConfidence())
            .sum();
        double winningWeight = levelVotes.get(bestLevel).stream()
            .mapToDouble(v -> getModelWeight(v.modelName()) * v.confidence())
            .sum();
        double finalConfidence = winningWeight / totalWeight;
        
        // 合并副层级（取所有模型副层级的交集或高频项）
        Set<Integer> secondaryLevels = responses.stream()
            .flatMap(r -> r.getSecondaryLevels().stream())
            .collect(Collectors.groupingBy(Function.identity(), Collectors.counting()))
            .entrySet().stream()
            .filter(e -> e.getValue() >= responses.size() / 2.0)  // 过半数同意
            .map(Map.Entry::getKey)
            .filter(l -> l != bestLevel)  // 排除主层级
            .sorted()
            .collect(Collectors.toSet());
        
        // 合并认知动作词
        Set<String> actionVerbs = responses.stream()
            .flatMap(r -> r.getActionVerbs().stream())
            .collect(Collectors.toSet());
        
        return BloomAIResult.builder()
            .primaryLevel(bestLevel)
            .secondaryLevels(new ArrayList<>(secondaryLevels))
            .confidence(finalConfidence)
            .actionVerbs(actionVerbs)
            .modelNames(responses.stream().map(BloomModelResponse::getModelName).toList())
            .build();
    }
    
    private double getModelWeight(String modelName) {
        return switch (modelName) {
            case "deepseek-v3" -> 1.0;   // 推理强
            case "gpt-4o" -> 1.0;         // 综合能力强
            case "glm-4-plus" -> 0.8;     // 中文教育场景适配
            case "qwen-max" -> 0.9;       // 中文理解强
            default -> 0.7;
        };
    }
}
```

```java
            Set.of("年代记忆", "事件名称填空")
        ),

            "化学",
            Map.of("实验方案设计", 3, "反应原理分析", 1, "化学方程式推导", 1),
            Set.of("元素符号记忆", "周期表背诵")
        )
    );
    
    /**
     * 对 AI 分类结果进行学科修正
     */
    public BloomAIResult correct(BloomAIResult original, ContentMetadata metadata) {
        SubjectBloomConfig config = SUBJECT_CONFIGS.get(metadata.getSubjectCode());
        if (config == null) {
            return original;
        }
        
        int adjustedLevel = original.getPrimaryLevel();
        
        // 检查是否有学科特定的层级调整规则
        for (Map.Entry<String, Integer> entry : config.levelAdjustments().entrySet()) {

                break;

        if (adjustedLevel >= 3) {

                if (metadata.getQuestionType() != null 
                        && metadata.getQuestionType().contains(pattern)) {
                    adjustedLevel = Math.max(1, adjustedLevel - 2);
                    break;
                }
            }
        }
        
        return original.withPrimaryLevel(adjustedLevel);
    }
```

## 6. 认知平衡指数计算

### 6.1 香农熵平衡指数

认知平衡指数使用**归一化香农熵**衡量六个认知层级的分布均匀程度：

```java
/**
 * 认知平衡指数计算器
 */
public class CognitiveBalanceCalculator {
    
    private static final int TOTAL_LEVELS = 6;
    
    /**
     * 计算认知平衡指数
     * @param levelDistribution 各层级的题目数量
     * @return 平衡指数 0.0-1.0，1.0 表示完全均匀分布
     */
    public static double calculateBalanceIndex(Map<Integer, Integer> levelDistribution) {
        int total = levelDistribution.values().stream().mapToInt(Integer::intValue).sum();
        if (total == 0) return 0.0;
        
        // 计算香农熵
        double entropy = 0.0;
        for (int count : levelDistribution.values()) {
            if (count > 0) {
                double p = (double) count / total;
                entropy -= p * (Math.log(p) / Math.log(2));
            }
        }
        
        // 归一化：除以 log2(6) ≈ 2.585
        double maxEntropy = Math.log(TOTAL_LEVELS) / Math.log(2);
        return entropy / maxEntropy;
    }
    
    /**
     * 计算覆盖率（非零层级的比例）
     */
    public static double calculateCoverageRatio(Map<Integer, Integer> levelDistribution) {
        long nonZeroLevels = levelDistribution.values().stream()
            .filter(c -> c > 0)
            .count();
        return (double) nonZeroLevels / TOTAL_LEVELS;
    }
    
    /**
     * 生成认知分布建议
     */
    public static String generateBalanceSuggestion(
            Map<Integer, Integer> distribution,
            double balanceIndex,
            int subjectCode) {
        
        StringBuilder sb = new StringBuilder();
        int total = distribution.values().stream().mapToInt(Integer::intValue).sum();
        
        // 目标分布（参考课标建议）
        double[] targetRatios = {0.10, 0.20, 0.30, 0.25, 0.10, 0.05};
        
        for (int level = 1; level <= 6; level++) {
            int count = distribution.getOrDefault(level, 0);
            double actualRatio = total > 0 ? (double) count / total : 0;
            double targetRatio = targetRatios[level - 1];
            
            if (actualRatio < targetRatio * 0.5) {
                sb.append(String.format("L%d(%s)占比%.1f%%，低于建议的%.0f%%，",
                    level, BloomLevel.fromLevel(level).getChineseName(),
                    actualRatio * 100, targetRatio * 100));
                sb.append("建议增加该层级练习。\n");
            }
        }
        
        if (balanceIndex < 0.5) {
            sb.append("整体认知分布不够均衡，建议关注高阶思维培养。");
        } else if (balanceIndex > 0.85) {
            sb.append("认知分布较为均衡，继续保持。");
        }
        
        return sb.toString();
    }
}
```

```java
 */
public enum AnnotationStatus {
    
    PENDING("待校准"),      // AI 分类完成，等待系统抽检或人工确认
    APPROVED("已确认"),      // 人工确认 AI 分类正确
    ADJUSTED("已修正"),      // 人工修改了分类结果
    DISPUTED("有争议"),      // 多个校准者意见不一致
    ARCHIVED("已归档");      // 内容已下线，标注归档
    
    private final String description;
    
    /**
     * 合法状态转换
     */
    public static boolean canTransition(AnnotationStatus from, AnnotationStatus to) {
        return switch (from) {
            case PENDING -> to == APPROVED || to == ADJUSTED || to == DISPUTED;
            case APPROVED -> to == DISPUTED || to == ARCHIVED;  // 可被重新争议
            case ADJUSTED -> to == APPROVED || to == DISPUTED;
            case DISPUTED -> to == APPROVED || to == ADJUSTED;
            case ARCHIVED -> false;  // 终态
        };
    }
}
```

### 7.3 校准任务调度

```java
/**
 * 校准任务生成策略
 */
public class CalibrationTaskGenerator {
    
    private static final double AUTO_SAMPLE_RATIO = 0.05;       // 5% 自动抽检
    private static final double LOW_CONFIDENCE_THRESHOLD = 0.65; // 低置信度阈值
    private static final double DISPUTE_RATIO = 0.33;           // 争议抽检比例
    
    /**
     * 根据标注结果决定是否生成校准任务
     */
    public List<BloomCalibrationTask> generate(BloomAnnotation annotation) {
        List<BloomCalibrationTask> tasks = new ArrayList<>();
        
        // 1. 置信度低于阈值 → 强制校准
        if (annotation.getConfidenceScore().compareTo(
                BigDecimal.valueOf(LOW_CONFIDENCE_THRESHOLD)) < 0) {
            tasks.add(buildTask(annotation, "DISPUTED_REVIEW", 100));
        }
        
        // 2. 随机抽检
        else if (Math.random() < AUTO_SAMPLE_RATIO) {
            tasks.add(buildTask(annotation, "SAMPLE_CHECK", 50));
        }
        
        // 3. 特定条件强制校准：L6创造类内容（分类容易出错）
        else if (annotation.getPrimaryLevel() == 6 
                && annotation.getClassificationMethod().equals("AI_CLASSIFIED")) {
            tasks.add(buildTask(annotation, "SAMPLE_CHECK", 80));
        }
        
        return tasks;
    }
}
```

```java
/**
 * 事件消费者：监听内容创建/更新事件，触发自动分类
 */
@Component
public class BloomEventListener {
    
    @Autowired
    private BloomClassificationService classifyService;
    
    @Autowired
    private BloomQueryService queryService;
    
    @Autowired
    private CognitiveProfileService profileService;
    
    /**
     * 监听新题目入库事件 → 触发自动分类
     */
    @KafkaListener(topics = "question.created", groupId = "bloom-classifier")
    public void onQuestionCreated(QuestionCreatedEvent event) {
        classifyService.classifyAsync(
            "QUESTION",
            event.questionId(),
            event.content(),
            ContentMetadata.fromQuestionEvent(event)
        );
    }
    
    /**
     * 监听标注完成事件 → 更新认知分布画像
     */
    @KafkaListener(topics = "bloom.annotation.completed", groupId = "bloom-profile")
    public void onAnnotationCompleted(BloomAnnotationCompleted event) {
        // 更新学科-学段全局分布
        profileService.updateSubjectDistribution(
            event.subjectCode(), event.primaryLevel()
        );
        
        // 如果是题目，更新相关章节的认知分布
        if ("QUESTION".equals(event.contentType())) {
            profileService.updateChapterDistribution(event.contentId());
        }
    }
    
    /**
     * 监听学生答题完成事件 → 更新学生个人认知分布
     */
    @KafkaListener(topics = "answer.completed", groupId = "bloom-student-profile")
    public void onAnswerCompleted(AnswerCompletedEvent event) {
        // 查询题目的认知层级
        Optional<BloomAnnotation> annotation = queryService.getByContent(
            "QUESTION", event.questionId()
        );
        
        if (annotation.isPresent()) {
            // 更新学生的认知练习分布
            profileService.updateStudentDistribution(
                event.userId(),
                annotation.get().getPrimaryLevel(),
                event.subjectCode()
            );
        }
    }
}
```

## 9. 错误处理与降级策略

### 9.1 错误分类与处理

| 错误场景 | 错误码 | 处理策略 |
|----------|--------|----------|
| AI 分类服务全部不可用 | BLOOM_AI_UNAVAILABLE | 降级为纯规则分类，标记 `classification_method=RULE_BASED` |
| AI 分类超时 (>10s) | BLOOM_AI_TIMEOUT | 返回规则分类结果，异步重试 AI 分类 |
| 内容文本为空 | BLOOM_EMPTY_CONTENT | 返回默认层级 L2（理解），标记低置信度 0.3 |
| 不支持的学科/学段 | BLOOM_UNSUPPORTED_SUBJECT | 使用通用规则集分类，不执行学科修正 |
| 批量分类部分失败 | BLOOM_PARTIAL_FAILURE | 成功的结果正常存储，失败的加入重试队列 |

### 9.2 降级逻辑

```java
/**
 * 分类降级处理器
 */
public class BloomFallbackHandler {
    
    /**
     * AI 分类失败时的降级处理
     */
    public BloomAnnotation fallback(ContentMetadata metadata, String content) {
        // 1. 尝试纯规则分类
        Optional<BloomRuleResult> ruleResult = ruleClassifier.classify(content, metadata);
        
        if (ruleResult.isPresent() && ruleResult.get().getConfidence() > 0.5) {
            return BloomAnnotation.builder()
                .primaryLevel(ruleResult.get().getLevel())
                .confidenceScore(ruleResult.get().getConfidence())
                .classificationMethod("RULE_BASED")
                .calibrationStatus("PENDING")
                .build();
        }
        
        // 2. 规则也不命中，使用题型默认层级
        int defaultLevel = getDefaultLevelByQuestionType(metadata.getQuestionType());
        
        return BloomAnnotation.builder()
            .primaryLevel(defaultLevel)
            .confidenceScore(BigDecimal.valueOf(0.3))
            .classificationMethod("RULE_BASED")
            .calibrationStatus("PENDING")
            .build();
    }
    
    private int getDefaultLevelByQuestionType(String questionType) {
        return switch (questionType) {
            case "FILL_BLANK", "MULTIPLE_CHOICE" -> 1; // 记忆
            case "SHORT_ANSWER" -> 2;                   // 理解
            case "CALCULATION" -> 3;                    // 应用
            case "PROOF", "ANALYSIS" -> 4;              // 分析
            case "ESSAY", "DISCUSSION" -> 5;            // 评价
            case "COMPOSITION", "DESIGN" -> 6;          // 创造
            default -> 2;                                 // 默认理解
        };
    }
}
```

## 10. 性能优化与容量规划

### 10.1 性能指标

| 指标 | 目标值 |
|------|--------|
| 规则分类延迟 | < 50ms |
| AI 分类延迟 (单条) | < 5s |
| AI 分类延迟 (批量100条) | < 60s |
| 标注查询 QPS | 2000+ |
| 分布分析查询延迟 | < 200ms |
| 批量分类吞吐量 | 500条/分钟 |

### 10.2 优化策略

1. **并行模型调用**：多模型投票并行执行，总延迟 ≈ 最慢模型的延迟
2. **规则缓存**：规则集 Redis 缓存，10 分钟刷新
3. **结果缓存**：已标注内容 Redis 缓存，TTL 24h，内容更新时主动失效
4. **批量优化**：批量分类使用消息队列削峰，支持优先级调度
5. **预计算画像**：认知分布画像通过定时任务每小时预计算，避免实时聚合
6. **增量更新**：新标注完成时增量更新分布计数器，而非全量重算
