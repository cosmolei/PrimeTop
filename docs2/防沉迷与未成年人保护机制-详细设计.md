# 防沉迷与未成年人保护机制 — 详细设计

> 版本：v1.0 | 更新日期：2026-05-20 | 状态：草案

---

## 1. 概述

### 1.1 背景

根据国家新闻出版署《关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》、教育部《关于预防中小学生沉迷网络的指导》以及《儿童个人信息网络保护规定》等法规要求，面向未成年人的教育类 APP 必须建立完善的防沉迷和未成年人保护机制。

PrimeTop 作为覆盖幼儿园至高中阶段的 AI 辅助学习产品，需从**时长管控、消费保护、内容安全、隐私保护、家长监督**五个维度构建未成年人保护体系。

### 1.2 设计目标

1. **合规达标**：满足国家关于未成年人网络保护的相关法规要求。
2. **分龄管控**：不同年龄段实施差异化的使用时长和功能权限策略。
3. **家长协同**：家长可实时了解、控制孩子的使用行为。
4. **柔性体验**：防沉迷机制不阻断正常学习流程，避免过度打扰。
5. **数据可追溯**：所有管控操作留痕，支持合规审计。

### 1.3 适用范围

- 学生端 APP（Android / iOS）
- 家长端（独立模块 / 微信小程序）
- 管理后台（合规配置）

## 2. 核心概念与术语

| 术语 | 定义 |
|------|------|
| 青少年模式 | APP 内置的受限制使用模式，启用后所有防沉迷规则生效 |
| 实名认证 | 通过身份信息验证用户真实年龄的流程 |
| 使用时段 | 允许未成年人使用 APP 的时间窗口 |
| 累计时长 | 当日实际使用 APP 的总时长 |
| 冷却期 | 达到时长上限后禁止继续使用的等待时间 |
| 免打扰时段 | 禁止使用 APP 的时间段（如夜间、上课时间） |
| 消费限额 | 未成年人单次/单月充值或消费上限 |
| 家长密钥 | 家长操作敏感设置时需要输入的验证码 |

## 3. 用户年龄分层与管控策略

### 3.1 年龄分层定义

| 层级 | 年龄范围 | 学段映射 | 代号 |
|------|----------|----------|------|
| L0 | < 8 岁 | 幼儿、小学低年级 | `AGE_TODDLER` |
| L1 | 8–15 岁 | 小学中高年级、初中 | `AGE_JUNIOR` |
| L2 | 16–17 岁 | 高中 | `AGE_SENIOR` |
| L3 | ≥ 18 岁 | 成人（家长/教师） | `AGE_ADULT` |

### 3.2 差异化管控规则

```
┌─────────────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│ 规则维度            │ L0 (<8岁)    │ L1 (8-15岁)  │ L2 (16-17岁) │ L3 (≥18岁)   │
├─────────────────────┼──────────────┼──────────────┼──────────────┼──────────────┤
│ 每日最大使用时长    │ 40 分钟      │ 60 分钟      │ 90 分钟      │ 无限制       │
│ 单次最大连续使用    │ 20 分钟      │ 30 分钟      │ 45 分钟      │ 无限制       │
│ 免打扰时段(平日)    │ 20:00-08:00  │ 21:00-06:00  │ 22:00-06:00  │ 无           │
│ 免打扰时段(周末/假) │ 21:00-07:00  │ 22:00-07:00  │ 23:00-06:00  │ 无           │
│ 单次充值限额        │ 禁止充值     │ 50 元        │ 100 元       │ 无限制       │
│ 月累计充值限额      │ 禁止充值     │ 200 元       │ 400 元       │ 无限制       │
│ 强制休息提醒        │ 每15分钟     │ 每25分钟     │ 每40分钟     │ 无           │
│ 夜间打赏/礼物       │ 禁止         │ 禁止         │ 禁止         │ 无限制       │
│ 青少年模式默认      │ 强制开启     │ 强制开启     │ 默认开启     │ 默认关闭     │
│ 家长可自定义时长    │ ✅           │ ✅           │ ✅           │ —           │
│ AI 对话内容过滤等级 │ 最严格       │ 严格         │ 标准         │ 标准         │
└─────────────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
```

> 以上默认值为系统预置规则，家长可在范围内自定义调整（但不能超过系统上限）。

## 5. 数据模型

### 5.1 实名认证记录表 `real_name_auth`

```sql
CREATE TABLE real_name_auth (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    auth_type       TINYINT NOT NULL COMMENT '认证方式: 1=身份证二要素 2=运营商三要素 3=人脸比对',
    real_name       VARCHAR(64) NOT NULL COMMENT '真实姓名(加密存储)',
    id_number       VARCHAR(256) NOT NULL COMMENT '证件号码(AES加密)',
    verified_age    TINYINT COMMENT '验证后年龄',
    age_level       VARCHAR(16) COMMENT '年龄层级: AGE_TODDLER/AGE_JUNIOR/AGE_SENIOR/AGE_ADULT',
    auth_status     TINYINT NOT NULL DEFAULT 0 COMMENT '0=待验证 1=通过 2=失败 3=过期',
    auth_source     VARCHAR(32) COMMENT '认证来源: app/parent_bind/admin',
    third_party_req_id VARCHAR(128) COMMENT '第三方认证请求ID',
    verified_at     DATETIME COMMENT '验证通过时间',
    expires_at      DATETIME COMMENT '认证过期时间(需要重新认证)',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_id (user_id),
    INDEX idx_status (auth_status),
    UNIQUE INDEX uk_user_auth_type (user_id, auth_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='实名认证记录表';
```

### 5.2 青少年模式配置表 `youth_mode_config`

```sql
CREATE TABLE youth_mode_config (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    is_enabled      TINYINT NOT NULL DEFAULT 1 COMMENT '是否启用青少年模式: 0=否 1=是',
    daily_max_minutes   INT NOT NULL DEFAULT 60 COMMENT '每日最大使用分钟数',
    session_max_minutes INT NOT NULL DEFAULT 30 COMMENT '单次最大连续使用分钟数',
    rest_interval_minutes INT NOT NULL DEFAULT 25 COMMENT '休息提醒间隔(分钟)',
    -- 免打扰时段(平日)
    quiet_weekday_start TIME NOT NULL DEFAULT '21:00:00' COMMENT '平日免打扰开始时间',
    quiet_weekday_end   TIME NOT NULL DEFAULT '06:00:00' COMMENT '平日免打扰结束时间',
    -- 免打扰时段(周末/假日)
    quiet_weekend_start TIME NOT NULL DEFAULT '22:00:00' COMMENT '周末免打扰开始时间',
    quiet_weekend_end   TIME NOT NULL DEFAULT '07:00:00' COMMENT '周末免打扰结束时间',
    -- 消费限额
    single_pay_limit    INT COMMENT '单次充值上限(分), NULL=禁止充值',
    monthly_pay_limit   INT COMMENT '月累计充值上限(分), NULL=禁止充值',
    -- 内容过滤等级
    content_filter_level VARCHAR(16) NOT NULL DEFAULT 'strict' COMMENT '内容过滤等级: strictest/strict/standard',
    -- 管控来源
    rule_source     VARCHAR(16) NOT NULL DEFAULT 'system' COMMENT '规则来源: system=系统默认 parent=家长自定义',
    parent_user_id  BIGINT COMMENT '设置规则的家长用户ID',
    updated_by      VARCHAR(32) NOT NULL DEFAULT 'system' COMMENT '最后修改者: system/parent:userId/admin',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_user_id (user_id),
    INDEX idx_parent (parent_user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='青少年模式配置表';
```

### 5.5 管控操作审计日志表 `protection_audit_log`

```sql
CREATE TABLE protection_audit_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    operator_type   VARCHAR(16) NOT NULL COMMENT '操作者类型: system/parent/admin',
    operator_id     BIGINT COMMENT '操作者ID',
    target_user_id  BIGINT NOT NULL COMMENT '被操作的用户ID(学生)',
    action          VARCHAR(64) NOT NULL COMMENT '操作类型(见下方枚举)',
    detail          JSON COMMENT '操作详情',
    ip_address      VARCHAR(45) COMMENT '操作者IP',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_target (target_user_id),
    INDEX idx_action (action),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='保护机制审计日志表';
```

**审计日志 action 枚举值：**

| action 值 | 说明 |
|-----------|------|
| `REAL_NAME_VERIFY` | 实名认证完成 |
| `YOUTH_MODE_ENABLE` | 启用青少年模式 |
| `YOUTH_MODE_DISABLE` | 关闭青少年模式（需记录家长密钥验证） |
| `TIME_LIMIT_REACHED` | 达到每日时长上限 |
| `SESSION_REST_ENFORCED` | 强制休息触发 |
| `QUIET_PERIOD_BLOCK` | 免打扰时段拦截使用 |
| `SPENDING_LIMIT_CHECK` | 消费限额校验 |
| `SPENDING_LIMIT_REJECT` | 消费被限额拒绝 |
| `PARENT_RULE_UPDATE` | 家长修改管控规则 |
| `PARENT_UNLOCK` | 家长密钥解锁 |

## 6. API 接口设计

### 6.1 实名认证

#### 6.1.1 提交实名认证

```
POST /api/v1/protection/real-name/verify
```

**请求体：**
```json
{
  "realName": "张三",
  "idNumber": "110101200801011234",
  "authType": "ID_CARD_TWO_FACTOR"
}
```

**响应：**
```json
{
  "code": 0,
  "data": {
    "authId": 10001,
    "status": "PENDING",
    "estimatedAge": 18,
    "ageLevel": "AGE_ADULT",
    "message": "认证信息已提交，正在验证"
  }
}
```

#### 6.1.2 查询认证状态

```
GET /api/v1/protection/real-name/status?userId={userId}
```

**响应：**
```json
{
  "code": 0,
  "data": {
    "isVerified": true,
    "authType": "ID_CARD_TWO_FACTOR",
    "ageLevel": "AGE_JUNIOR",
    "verifiedAt": "2026-05-15T10:30:00+08:00",
    "expiresAt": "2027-05-15T10:30:00+08:00"
  }
}
```

### 6.2 时长管控

#### 6.2.1 上报使用时长（心跳）

客户端每 **60 秒** 上报一次心跳。

```
POST /api/v1/protection/usage/heartbeat
```

**请求体：**
```json
{
  "clientTimestamp": 1716123600000,
  "activeModule": "AI_TUTOR",
  "sessionDurationSeconds": 180
}
```

**响应：**
```json
{
  "code": 0,
  "data": {
    "dailyUsedSeconds": 2400,
    "dailyLimitSeconds": 3600,
    "remainingSeconds": 1200,
    "sessionUsedSeconds": 180,
    "sessionLimitSeconds": 1800,
    "shouldShowRestReminder": false,
    "shouldForceRest": false,
    "dailyLimitReached": false
  }
}
```

#### 6.2.2 会话开始/结束

```
POST /api/v1/protection/usage/session
```

**请求体：**
```json
{
```

### 6.3 青少年模式配置

#### 6.3.1 获取当前配置

```
GET /api/v1/protection/youth-mode/config?userId={userId}
```

#### 6.3.2 家长修改配置

```
PUT /api/v1/protection/youth-mode/config
```

**请求体：**
```json
{
  "targetUserId": 20001,
  "parentKey": "123456",
  "updates": {
    "dailyMaxMinutes": 45,
    "sessionMaxMinutes": 25,
    "restIntervalMinutes": 20,
```

```json
{
  "code": 0,
  "data": {
    "appliedRules": {
      "dailyMaxMinutes": 45,
      "sessionMaxMinutes": 25,
      "restIntervalMinutes": 20,
      "quietWeekdayStart": "20:30:00",
      "quietWeekdayEnd": "06:30:00",
      "contentFilterLevel": "strictest"
    },
    "effectiveImmediately": true
  }
}
```

### 6.4 消费限额校验

#### 6.4.1 支付前校验

支付服务在发起扣款前同步调用此接口。

```
POST /api/v1/protection/spending/check
```

**请求体：**
```json
{
  "userId": 20001,
  "amountCents": 3000,
  "payType": "SUBSCRIPTION_MONTHLY"
}
```

**响应：**
```json
{
  "code": 0,
  "data": {
    "allowed": true,
    "currentMonthSpentCents": 5000,
    "monthlyLimitCents": 20000,
    "singleLimitCents": 5000,
    "remainingMonthlyCents": 15000
  }
}
```

若不允许：
```json
{
  "code": 40301,
  "message": "已达到本月消费上限",
  "data": {
    "allowed": false,
    "reason": "MONTHLY_LIMIT_EXCEEDED",
    "currentMonthSpentCents": 20000,
    "monthlyLimitCents": 20000
  }
}
```

#### 6.4.2 消费确认（支付成功后回调）

```
POST /api/v1/protection/spending/confirm
```

**请求体：**
```json
{
  "userId": 20001,
  "amountCents": 3000,
  "orderId": "ORD20260520123456",
  "payType": "SUBSCRIPTION_MONTHLY"
}
```

```dart
/// 防沉迷计时管理器
class AntiAddictionTimer {
  final String userId;
  final AntiAddictionService _service;
  
  DateTime? _sessionStart;
  int _dailyUsedSeconds = 0;
  int _sessionUsedSeconds = 0;
  Timer? _heartbeatTimer;
  Timer? _localCheckTimer;
  
  AntiAddictionConfig get config => _currentConfig;
  AntiAddictionConfig _currentConfig = AntiAddictionConfig.defaults();
  
  /// APP 启动时调用
  Future<void> onAppStart() async {
    // 1. 检查免打扰时段
    if (_isInQuietPeriod()) {
      _showQuietPeriodLock();
      return;
    }
    
    // 2. 从服务端同步当日使用数据
    final usage = await _service.fetchTodayUsage();
    _dailyUsedSeconds = usage.dailyUsedSeconds;
    _currentConfig = usage.config;
    
    if (_dailyUsedSeconds >= _currentConfig.dailyLimitSeconds) {
      _showDailyLimitReached();
      return;
    }
    
    // 3. 启动心跳和本地检查
    _startHeartbeat();
    _startLocalCheck();
    _beginNewSession();
  }
  
  /// APP 切前台
  void onAppResumed() {
    if (_isInQuietPeriod()) {
      _showQuietPeriodLock();
      return;
    }
    _beginNewSession();
    _startHeartbeat();
  }
  
  /// APP 切后台
  void onAppPaused() {
    _endCurrentSession();
    _heartbeatTimer?.cancel();
  }
  
  void _startHeartbeat() {
    _heartbeatTimer?.cancel();
    _heartbeatTimer = Timer.periodic(
      const Duration(seconds: 60),
      (_) => _sendHeartbeat(),
    );
  }
  
  void _startLocalCheck() {
    _localCheckTimer?.cancel();
    _localCheckTimer = Timer.periodic(
      const Duration(seconds: 30),
      (_) => _localCheck(),
    );
  }
  
  void _localCheck() {
    _sessionUsedSeconds = DateTime.now()
        .difference(_sessionStart!).inSeconds;
    final totalUsed = _dailyUsedSeconds + _sessionUsedSeconds;
    
    // 检查休息提醒间隔
    if (_sessionUsedSeconds > 0 &&
        _sessionUsedSeconds % _currentConfig.restIntervalSeconds == 0 &&
        !_restReminderShown) {
      _showRestReminder();
    }
    
    // 检查单次上限
    if (_sessionUsedSeconds >= _currentConfig.sessionLimitSeconds) {
      _showForceRest();
    }
    
    // 检查每日上限
    if (totalUsed >= _currentConfig.dailyLimitSeconds) {
      _showDailyLimitReached();
    }
  }
  
  Future<void> _sendHeartbeat() async {
    final resp = await _service.heartbeat(
      module: _currentModule,
      sessionDurationSeconds: _sessionUsedSeconds,
    );
    
    // 服务端可能有更精准的计时
    _dailyUsedSeconds = resp.dailyUsedSeconds;
    
    if (resp.shouldForceRest) {
      _showForceRest();
    }
    if (resp.dailyLimitReached) {
      _showDailyLimitReached();
    }
  }
  
  void _beginNewSession() {
    _sessionStart = DateTime.now();
    _sessionUsedSeconds = 0;
    _restReminderShown = false;
    _service.reportSession(action: 'START', module: _currentModule);
  }
  
  void _endCurrentSession() {
    if (_sessionStart != null) {
      final duration = DateTime.now()
          .difference(_sessionStart!).inSeconds;
      _dailyUsedSeconds += duration;
      _service.reportSession(action: 'END', module: _currentModule);
    }
    _sessionStart = null;
  }
  
  bool _isInQuietPeriod() {
    final now = TimeOfDay.now();
    final config = _currentConfig;
    // 判断当前时间是否在免打扰时段
    // 处理跨午夜的情况 (如 21:00 - 06:00)
    return _isInTimeRange(now, config.quietStart, config.quietEnd);
  }
}
```

```go
type AntiAddictionService struct {
    db          *gorm.DB
    redis       *redis.Client

// GetEffectiveConfig 获取用户生效的防沉迷配置
func (s *AntiAddictionService) GetEffectiveConfig(ctx context.Context, userID int64) (*YouthModeConfig, error) {
    // 1. 查询用户年龄层级
    ageLevel, err := s.getUserAgeLevel(ctx, userID)
    if err != nil {
        return nil, err
    }
    
    // 成人用户无限制
    if ageLevel == AgeAdult {
        return s.adultConfig(), nil
    }
    
    // 2. 查询用户自定义配置（家长设置）
    custom, err := s.ruleRepo.FindByUserID(ctx, userID)
    if err != nil {
        return nil, err
    }
    
    // 3. 获取系统默认规则
    systemDefault := s.getSystemDefault(ageLevel)
    
    // 4. 合并规则：自定义覆盖系统默认，但不能超过系统上限
    return s.mergeConfig(systemDefault, custom), nil
}

// CheckSpendingLimit 消费限额校验
func (s *AntiAddictionService) CheckSpendingLimit(ctx context.Context, 
    userID int64, amountCents int) (*SpendingCheckResult, error) {
    
    ageLevel, _ := s.getUserAgeLevel(ctx, userID)
    
    // 成人不限制
    if ageLevel == AgeAdult {
        return &SpendingCheckResult{Allowed: true}, nil
    }
    
    // L0 禁止充值
    if ageLevel == AgeToddler {
        return &SpendingCheckResult{
            Allowed: false,
            Reason:  "UNDERAGE_PAYMENT_PROHIBITED",
        }, nil
    }
    
    config, err := s.GetEffectiveConfig(ctx, userID)
    if err != nil {
        return nil, err
    }
    
    // 单次限额校验
    if config.SinglePayLimit != nil && amountCents > *config.SinglePayLimit {
        return &SpendingCheckResult{
            Allowed:      false,
            Reason:       "SINGLE_LIMIT_EXCEEDED",
            SingleLimit:  *config.SinglePayLimit,
        }, nil
    }
    
    // 月累计限额校验
    if config.MonthlyPayLimit != nil {
        monthKey := time.Now().Format("2006-01")
        spent, _ := s.getMonthlySpending(ctx, userID, monthKey)
        if spent + amountCents > *config.MonthlyPayLimit {
            return &SpendingCheckResult{
                Allowed:       false,
                Reason:        "MONTHLY_LIMIT_EXCEEDED",
                MonthlySpent:  spent,
                MonthlyLimit:  *config.MonthlyPayLimit,
            }, nil
        }
    }
    
    return &SpendingCheckResult{
        Allowed:          true,
        CurrentMonthSpent: ...,
        MonthlyLimit:      ...,
    }, nil
}

// Heartbeat 处理客户端心跳
func (s *AntiAddictionService) Heartbeat(ctx context.Context, 
    req *HeartbeatRequest) (*HeartbeatResponse, error) {
    
    config, _ := s.GetEffectiveConfig(ctx, req.UserID)
    
    // Redis 原子更新当日使用时长
    today := time.Now().Format("2006-01-02")
    key := fmt.Sprintf("usage:%d:%s", req.UserID, today)
    
    // 自增60秒（心跳间隔）
    dailySeconds, _ := s.redis.IncrBy(ctx, key, 60).Result()
    s.redis.Expire(ctx, key, 48*time.Hour) // 保留48小时
    
    // 异步写入 MySQL
    go s.persistUsageLog(req.UserID, today, int(dailySeconds))
    
    // 判断是否需要强制休息或已达每日上限
    sessionLimit := config.SessionMaxMinutes * 60
    dailyLimit := config.DailyMaxMinutes * 60
    
    return &HeartbeatResponse{
        DailyUsedSeconds:   int(dailySeconds),
        DailyLimitSeconds:  dailyLimit,
        RemainingSeconds:   max(0, dailyLimit - int(dailySeconds)),
        ShouldForceRest:    req.SessionDurationSeconds >= sessionLimit,
        DailyLimitReached:  int(dailySeconds) >= dailyLimit,
    }, nil
}
```

```go
func ParentKeyAuth(svc *AntiAddictionService) gin.HandlerFunc {

            })

        }

    }
```

## 11. 错误处理

### 11.1 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 客户端处理 |
|--------|------------|------|-----------|
| `40301` | 403 | 月消费限额已超 | 引导联系家长 |
| `40302` | 403 | 单次消费限额已超 | 提示限额金额 |
| `40303` | 403 | 未成年禁止充值 | 提示需家长操作 |
| `40304` | 403 | 当日使用时长已达上限 | 显示锁定屏 |
| `40305` | 403 | 当前为免打扰时段 | 显示休息提示 |
| `40306` | 403 | 需要完成实名认证 | 引导认证流程 |
| `40307` | 403 | 家长密钥验证失败 | 提示剩余尝试次数 |
| `42901` | 429 | 实名认证请求过于频繁 | 提示稍后再试 |
| `50001` | 500 | 第三方实名服务异常 | 提示稍后再试 |
| `50002` | 500 | 时长数据同步异常 | 使用本地计时器兜底 |

### 11.2 容错策略

| 场景 | 策略 |
|------|------|
| 服务端心跳失败 | 客户端使用本地计时器继续计时，缓存心跳数据，恢复后批量上报 |
| 实名认证第三方超时 | 返回 PENDING 状态，客户端轮询结果（最多5次，间隔3秒） |
| Redis 不可用 | 降级为 MySQL 直接读写，允许性能下降 |
| 时长数据不一致（客户端与服务端偏差 > 5分钟） | 以服务端数据为准，客户端同步修正 |
| 家长密钥连续错误5次 | 锁定密钥验证15分钟，通知家长端 |

## 14. 安全考虑

1. **敏感数据加密**：真实姓名和身份证号使用 AES-256-GCM 加密存储，密钥由 KMS 管理。
2. **最小化采集**：仅在实名认证时采集身份信息，不在其他场景要求。
3. **数据脱敏展示**：管理后台展示身份证号时只显示前3位和后4位。
4. **家长密钥安全**：密钥以 bcrypt 哈希存储，不支持明文查询。
5. **防绕过**：
   - 卸载重装不会重置时长（服务端记录）。
   - 修改系统时间不影响计时（以服务端时间为准）。
   - 多设备登录共享时长限制。
6. **审计留痕**：所有管控操作写入审计日志，保留至少 180 天。
