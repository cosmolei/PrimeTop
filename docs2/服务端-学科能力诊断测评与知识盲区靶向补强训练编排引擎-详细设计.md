# 服务端-学科能力诊断测评与知识盲区靶向补强训练编排引擎-详细设计

## 1. 模块概述

### 1.1 功能定位

学科能力诊断测评与知识盲区靶向补强训练编排引擎（以下简称"诊断补强引擎"）是 PrimeTop 学情分析体系中的核心编排层，负责将**诊断测评 → 盲区识别 → 靶向训练 → 成效验证**串联为一个自动化闭环。

该引擎不替代已有的智能组卷、练习测评、自适应推荐等单点服务，而是在其之上提供一个**以"知识盲区发现与消除"为目标的高层编排策略**，类似于医疗领域的"体检 → 诊断 → 处方 → 复查"流程。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 主动发现盲区 | 不依赖学生被动出错后才发现薄弱点，通过主动诊断提前扫描 |
| 精准定位 | 将诊断结果映射到具体知识点，精确到叶子节点 |
| 靶向训练 | 为每个盲区生成定制化的"概念复习 → 引导练习 → 独立练习 → 验证"训练序列 |
| 闭环验证 | 训练完成后自动安排验证测评，确认盲区已被消除 |
| 持续迭代 | 支持多轮诊断循环，逐步提升学科能力完整度 |

| 学段 | 诊断粒度 | 典型场景 |
|------|----------|----------|
| 小学 | 学科 → 单元 → 知识点 | 单元学完后诊断，考前全面扫描 |

## 2. 核心概念与数据模型

### 2.1 关键概念

| 概念 | 定义 |
|------|------|
| 诊断测评 | 一种特殊测评，目的是"发现盲区"而非"评分"，题目覆盖目标知识点范围 |
| 知识盲区 | 学生在某个知识点上掌握度低于阈值的区域 |
| 靶向训练 | 针对盲区设计的有序训练序列，包含概念复习、引导练习、独立练习、验证题 |
| 补强周期 | 从"开始诊断"到"验证通过"的完整闭环生命周期 |
| 诊断覆盖图 | 一次诊断中，题目与知识点的覆盖映射关系 |

### 2.2 数据库表设计

#### 2.2.1 `diag_assessment_plan` — 诊断测评计划

```sql
CREATE TABLE diag_assessment_plan (
    id              BIGSERIAL PRIMARY KEY,
    plan_no         VARCHAR(32) NOT NULL UNIQUE,      -- 业务编号 DIAG-YYYYMMDD-XXXXX
    user_id         BIGINT NOT NULL,                   -- 学生用户ID
    subject_code    VARCHAR(16) NOT NULL,              -- 学科编码 math/physics/...
    stage_code      VARCHAR(16) NOT NULL,              -- 学段 primary/junior/senior
    grade_level     SMALLINT NOT NULL,                 -- 年级 1-12
    textbook_id     BIGINT,                            -- 教材版本ID
    scope_type      VARCHAR(32) NOT NULL,              -- 范围类型: chapter/unit/subject/exam
    scope_refs      JSONB NOT NULL DEFAULT '[]',       -- 范围引用: [{type:'chapter', ids:[1,2,3]}]
    diag_strategy   VARCHAR(32) NOT NULL,              -- 策略: full_scan / quick_scan / targeted_verify
    target_kp_count INT NOT NULL,                      -- 目标覆盖知识点数
    question_count  INT NOT NULL,                      -- 计划出题数
    estimated_min   INT NOT NULL,                      -- 预计用时(分钟)
    status          VARCHAR(20) NOT NULL DEFAULT 'created', -- created/in_progress/completed/expired/cancelled
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    started_at      TIMESTAMPTZ,
    completed_at    TIMESTAMPTZ,
    expired_at      TIMESTAMPTZ,                       -- 超时未完成的过期时间
    meta_data       JSONB DEFAULT '{}'

    , CONSTRAINT chk_diag_strategy CHECK (diag_strategy IN ('full_scan','quick_scan','targeted_verify'))
    , CONSTRAINT chk_scope_type CHECK (scope_type IN ('chapter','unit','subject','exam','custom'))
);

CREATE INDEX idx_diag_plan_user ON diag_assessment_plan(user_id, status);
CREATE INDEX idx_diag_plan_subject ON diag_assessment_plan(subject_code, stage_code);
CREATE INDEX idx_diag_plan_created ON diag_assessment_plan(created_at DESC);
```

#### 2.2.2 `diag_assessment_question` — 诊断测评题目明细

```sql
CREATE TABLE diag_assessment_question (
    id              BIGSERIAL PRIMARY KEY,
    plan_id         BIGINT NOT NULL REFERENCES diag_assessment_plan(id),
    seq_no          SMALLINT NOT NULL,                 -- 题目序号
    question_id     BIGINT NOT NULL,                   -- 题库题目ID
    question_type   VARCHAR(20) NOT NULL,              -- choice/fill/short_answer/essay
    difficulty      DECIMAL(3,2) NOT NULL,             -- 难度值 0.00-1.00
    kp_ids          JSONB NOT NULL DEFAULT '[]',       -- 本题考查的知识点ID列表
    kp_weight       JSONB NOT NULL DEFAULT '{}',       -- 知识点权重 {kp_id: weight}，权重之和=1
    is_result       BOOLEAN DEFAULT FALSE,             -- 是否已作答
    is_correct      BOOLEAN,                           -- 是否正确
    score           DECIMAL(5,2),                      -- 得分
    full_score      DECIMAL(5,2) NOT NULL,             -- 满分
    answered_at     TIMESTAMPTZ,
    time_cost_sec   INT,                               -- 答题用时(秒)
    answer_data     JSONB,                             -- 学生答案详情

    , UNIQUE(plan_id, seq_no)
);

CREATE INDEX idx_diag_q_plan ON diag_assessment_question(plan_id);
CREATE INDEX idx_diag_q_question ON diag_assessment_question(question_id);
```

#### 2.2.3 `diag_kp_coverage` — 知识点诊断覆盖与结果

```sql
CREATE TABLE diag_kp_coverage (
    id              BIGSERIAL PRIMARY KEY,
    plan_id         BIGINT NOT NULL REFERENCES diag_assessment_plan(id),
    kp_id           BIGINT NOT NULL,                   -- 知识点ID
    kp_name         VARCHAR(200) NOT NULL,             -- 知识点名称（冗余）
    kp_path         VARCHAR(500) NOT NULL,             -- 知识点路径 如 "数学>代数>函数>二次函数"
    parent_kp_id    BIGINT,                            -- 父知识点ID
    is_leaf         BOOLEAN NOT NULL DEFAULT TRUE,     -- 是否叶子知识点
    question_count  INT NOT NULL DEFAULT 0,            -- 诊断中涉及该知识点的题目数
    correct_count   INT NOT NULL DEFAULT 0,            -- 正确题数
    partial_count   INT NOT NULL DEFAULT 0,            -- 部分正确题数
    wrong_count     INT NOT NULL DEFAULT 0,            -- 错误题数
    mastery_before  DECIMAL(4,3),                     -- 诊断前掌握度 0.000-1.000
    mastery_after   DECIMAL(4,3),                     -- 诊断后掌握度（基于本次结果更新）
    mastery_delta   DECIMAL(4,3),                     -- 变化量
    blind_spot_level VARCHAR(20) NOT NULL,             -- none/mild/moderate/severe
    diag_detail     JSONB DEFAULT '{}',                -- 详细诊断数据（错误模式、典型错误等）

    , UNIQUE(plan_id, kp_id)
);

CREATE INDEX idx_diag_cov_plan ON diag_kp_coverage(plan_id);
CREATE INDEX idx_diag_cov_kp ON diag_kp_coverage(kp_id);
CREATE INDEX idx_diag_cov_blind ON diag_kp_coverage(blind_spot_level) WHERE blind_spot_level != 'none';
```

#### 2.2.4 `remediation_cycle` — 补强周期

```sql
CREATE TABLE remediation_cycle (
    id              BIGSERIAL PRIMARY KEY,
    cycle_no        VARCHAR(32) NOT NULL UNIQUE,       -- 业务编号 REM-YYYYMMDD-XXXXX
    user_id         BIGINT NOT NULL,
    subject_code    VARCHAR(16) NOT NULL,
    diag_plan_id    BIGINT NOT NULL REFERENCES diag_assessment_plan(id),
    blind_kp_count  INT NOT NULL,                      -- 盲区知识点数量
    blind_kp_ids    JSONB NOT NULL DEFAULT '[]',       -- 盲区知识点ID列表
    priority_order  JSONB NOT NULL DEFAULT '[]',       -- 补强优先级排序 [{kp_id, priority, reason}]
    status          VARCHAR(20) NOT NULL DEFAULT 'pending', -- pending/in_progress/verified/partially_verified/abandoned
    total_steps     INT NOT NULL DEFAULT 0,            -- 总训练步骤数
    completed_steps INT NOT NULL DEFAULT 0,            -- 已完成步骤数
    started_at      TIMESTAMPTZ,
    completed_at    TIMESTAMPTZ,
    expired_at      TIMESTAMPTZ,                       -- 超时放弃时间
    verify_plan_id  BIGINT,                            -- 最终验证测评计划ID（关联diag_assessment_plan）
    result_summary  JSONB DEFAULT '{}',                -- 周期结果摘要
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()

    , CONSTRAINT chk_cycle_status CHECK (status IN ('pending','in_progress','verified','partially_verified','abandoned'))
);

CREATE INDEX idx_rem_cycle_user ON remediation_cycle(user_id, status);
CREATE INDEX idx_rem_cycle_diag ON remediation_cycle(diag_plan_id);
```

#### 2.2.5 `remediation_task` — 补强训练任务

```sql
CREATE TABLE remediation_task (
    id              BIGSERIAL PRIMARY KEY,
    cycle_id        BIGINT NOT NULL REFERENCES remediation_cycle(id),
    seq_no          SMALLINT NOT NULL,                 -- 训练顺序
    kp_id           BIGINT NOT NULL,                   -- 针对的知识点ID
    kp_name         VARCHAR(200) NOT NULL,
    task_type       VARCHAR(30) NOT NULL,              -- concept_review/guided_practice/independent_practice/verification
    content_refs    JSONB NOT NULL DEFAULT '[]',       -- 内容引用 [{type, id, title}]
    question_ids    JSONB NOT NULL DEFAULT '[]',       -- 关联题目ID列表
    target_mastery  DECIMAL(4,3) NOT NULL DEFAULT 0.750, -- 目标掌握度
    actual_mastery  DECIMAL(4,3),                      -- 训练后实际掌握度
    status          VARCHAR(20) NOT NULL DEFAULT 'pending', -- pending/in_progress/completed/skipped/failed
    started_at      TIMESTAMPTZ,
    completed_at    TIMESTAMPTZ,
    time_cost_sec   INT,                               -- 实际用时
    score_summary   JSONB DEFAULT '{}',                -- 得分摘要
    meta_data       JSONB DEFAULT '{}'

    , CONSTRAINT chk_task_type CHECK (task_type IN ('concept_review','guided_practice','independent_practice','verification'))
    , CONSTRAINT chk_task_status CHECK (status IN ('pending','in_progress','completed','skipped','failed'))
    , UNIQUE(cycle_id, seq_no)
);

CREATE INDEX idx_rem_task_cycle ON remediation_task(cycle_id, status);
CREATE INDEX idx_rem_task_kp ON remediation_task(kp_id);
```

#### 2.2.6 `diag_blind_spot_history` — 盲区历史追踪

```sql
CREATE TABLE diag_blind_spot_history (
```

### 2.3 Redis 缓存设计

```
# 诊断测评进行中状态缓存
diag:plan:{planId}:progress     → Hash { total, answered, current_seq, started_ts }
diag:plan:{planId}:session      → String (assessment_session_id，关联练习测评会话)

# 学生盲区摘要缓存（TTL 1h）
diag:user:{userId}:blindspots   → Hash { subject_code → count, last_update }

# 补强周期进度缓存
rem:cycle:{cycleId}:progress    → Hash { total_tasks, completed_tasks, current_kp }

# 诊断计划防重锁（防止学生同时进行多个诊断）
diag:user:{userId}:lock         → String(planId), TTL=7200s

# 知识点诊断覆盖度计算缓存
diag:plan:{planId}:coverage_cache → String(JSON), TTL=3600s
```

## 3. 核心流程设计

### 3.1 总体状态流转

```

                        │            补强周期 (Remediation Cycle)       │
                        │                                             │
    ┌───────────┐       │  ┌─────────┐    ┌──────────────┐           │
    │  created  │───────┼─▶│ pending │───▶│ in_progress  │           │
    └───────────┘       │  └─────────┘    └──────┬───────┘           │
                        │                        │                   │
                        │              ┌─────────┼─────────┐         │
                        │              ▼         ▼         ▼         │
                        │     partially   verified   abandoned      │
                        │     _verified              (timeout)       │
                        └─────────────────────────────────────────────┘
                                          ▲
                                          │验证通过
    ┌───────────┐  ┌───────────┐  ┌──────┴──────┐  ┌───────────┐
    │  created  │─▶│in_progress│─▶│  completed  │─▶│ 生成补强   │

        │                              │            └───────────┘
        ▼                              ▼
```


### 3.3 盲区识别分析流程

学生完成诊断测评后触发：

```
答题完成事件 ──▶ 盲区分析 ──▶ 更新掌握度 ──▶ 生成盲区报告
                    │
          ┌─────────┴──────────────┐
          │ 1. 逐题分析正误与得分    │
          │ 2. 按知识点聚合正确率     │
          │ 3. 计算各知识点诊断掌握度 │
          │ 4. 对比历史掌握度         │
          │ 5. 判定盲区等级           │
          └─────────┬──────────────┘
                    │
          ┌─────────┴──────────────┐
          │ 盲区等级判定规则：        │
          │ - none:     掌握度≥0.75  │
          │ - mild:     0.60~0.75   │
          │ - moderate: 0.40~0.60   │
          │ - severe:   <0.40       │
          └─────────┬──────────────┘
                    │
          ┌─────────┴──────────────┐
          │ 6. 记录到覆盖结果表      │
          │ 7. 更新盲区历史表        │
          │ 8. 更新知识点掌握度缓存   │
          │ 9. 触发补强周期创建      │
          └────────────────────────┘
```

### 3.4 靶向训练编排流程

```
补强周期创建 ──▶ 优先级排序 ──▶ 逐知识点生成训练序列 ──▶ 合并为完整训练计划
     │                │                │
     │         ┌──────┴───────┐       │
     │         │ 排序因子：     │       │
     │         │ • 盲区严重度   │       │
     │         │ • 知识点重要性 │       │
     │         │ • 前置依赖关系 │       │
     │         │ • 距考试天数   │       │
     │         │ • 历史补强失败 │       │
     │         │   次数         │       │
     │         └──────────────┘       │
     │                                  │
     │         ┌──────────────────────┴────────┐
     │         │  每个盲区知识点的训练序列：      │
     │         │                                │
     │         │  Step 1: concept_review         │
     │         │  → 选择最优概念讲解内容          │
     │         │  → 关联教材章节                  │
     │         │                                │
     │         │  Step 2: guided_practice        │
     │         │  → 选择带解析的引导题（2-3题）    │
     │         │  → 难度 = 基础~中等              │
     │         │  → 包含详细步骤解析              │
     │         │                                │
     │         │  Step 3: independent_practice   │
     │         │  → 选择无解析的独立练习（2-4题）  │
     │         │  → 难度 = 中等~中高              │
     │         │  → 即时批改反馈                  │
     │         │                                │
     │         │  Step 4: verification           │
     │         │  → 选择验证题（1-2题）            │
     │         │  → 难度 = 中高                   │
     │         │  → 通过则标记知识点为已补强       │
     │         └────────────────────────────────┘
```

### 3.5 成效验证与周期闭环

```
所有训练步骤完成 ──▶ 生成验证测评 ──▶ 学生完成验证 ──▶ 分析验证结果
                                                            │
                                                   ┌────────┴────────┐
                                                   │                 │
                                              全部通过          部分/全未通过
```

## 5. 核心算法设计

### 5.1 诊断题目编排算法

```java
/**
 * 诊断题目编排服务
 * <p>
 * 目标：在有限题数内最大化知识点覆盖率和诊断信度。
 */
@Service
public class DiagnosticQuestionOrchestrator {

    private static final double COVERAGE_THRESHOLD = 0.85; // 目标知识点覆盖率
    private static final int MAX_ATTEMPTS = 3;             // 编排重试次数

    /**
     * 为诊断计划编排题目
     *
     * @param plan 诊断计划
     * @return 编排结果
     */
    public OrchestrationResult orchestrate(DiagAssessmentPlan plan) {
        // 1. 获取目标知识点集合
        List<KnowledgePoint> targetKps = getTargetKnowledgePoints(plan);
        if (targetKps.isEmpty()) {
            throw new BizException(40902, "诊断范围内没有可用的知识点");
        }

        // 2. 区分核心知识点和边缘知识点
        Map<Boolean, List<KnowledgePoint>> partitioned = targetKps.stream()
            .collect(Collectors.partitioningBy(kp -> kp.getImportanceLevel() >= 3));
        List<KnowledgePoint> coreKps = partitioned.get(true);
        List<KnowledgePoint> peripheralKps = partitioned.get(false);

        // 3. 按策略分配题目数
        QuestionAllocation alloc = allocateQuestions(plan, targetKps.size());

        // 4. 从题库选题
        List<QuestionCandidate> candidates = Lists.newArrayList();
        
        // 4.1 核心知识点优先选题（每个至少1题）
        for (KnowledgePoint kp : coreKps) {
            List<QuestionCandidate> kpQuestions = selectQuestionsForKp(
                kp, alloc.questionsPerCoreKp, plan
            );
            candidates.addAll(kpQuestions);
        }

        // 4.2 边缘知识点补充选题
        int remaining = plan.getQuestionCount() - candidates.size();
        if (remaining > 0) {
            candidates.addAll(selectSupplementQuestions(
                peripheralKps, remaining, plan
            ));
        }

        // 5. 验证覆盖率
        Set<Long> coveredKpIds = candidates.stream()
            .flatMap(q -> q.getKpIds().stream())
            .collect(Collectors.toSet());
        double coverage = (double) coveredKpIds.size() / targetKps.size();
        
        if (coverage < COVERAGE_THRESHOLD && candidates.size() < plan.getQuestionCount()) {
            // 尝试补充题目提升覆盖率
            candidates.addAll(fillCoverageGaps(targetKps, coveredKpIds, 
                plan.getQuestionCount() - candidates.size(), plan));
        }

        // 6. 难度分布调整
        candidates = adjustDifficultyDistribution(candidates, plan);

        // 7. 去重已做过的题目
        candidates = deduplicate(candidates, plan.getUserId());

        return new OrchestrationResult(candidates, coveredKpIds, coverage);
    }

    /**
     * 题目数量分配策略
     */
    private QuestionAllocation allocateQuestions(DiagAssessmentPlan plan, int totalKp) {
        int totalQ = plan.getQuestionCount();
        int coreKp = (int) targetKps.stream()
            .filter(kp -> kp.getImportanceLevel() >= 3).count();
        
        // 核心知识点每个分配更多题
        int questionsPerCoreKp = Math.max(1, totalQ / (coreKp + peripheralKp.size() / 2));
        
        return new QuestionAllocation(coreKp, questionsPerCoreKp, totalQ);
    }

    /**
     * 难度分布调整：诊断题应覆盖不同难度
     * 分布目标：基础30% / 中等40% / 中高20% / 拔高10%
     */
    private List<QuestionCandidate> adjustDifficultyDistribution(
            List<QuestionCandidate> candidates, DiagAssessmentPlan plan) {
        Map<DifficultyTier, List<QuestionCandidate>> grouped = candidates.stream()
            .collect(Collectors.groupingBy(QuestionCandidate::getDifficultyTier));
        
        int total = candidates.size();
        int expectedBasic = (int)(total * 0.30);
        int expectedMedium = (int)(total * 0.40);
        int expectedMidHigh = (int)(total * 0.20);
        int expectedAdvanced = total - expectedBasic - expectedMedium - expectedMidHigh;
        
        // 如果某难度层题目过多，用该知识点的其他难度题目替换
        // 实现略...
        return candidates;
    }
}
```

### 5.2 盲区识别与等级判定算法

```java
/**
 * 盲区分析服务
 */
@Service
public class BlindSpotAnalyzer {

    // 盲区等级阈值
    private static final double SEVERE_THRESHOLD   = 0.40;
    private static final double MODERATE_THRESHOLD = 0.60;
    private static final double MILD_THRESHOLD     = 0.75;
    
    // 掌握度更新学习率
    private static final double LEARNING_RATE = 0.35;

    /**
     * 分析诊断结果，识别知识盲区
     */
    @Transactional
    public BlindSpotAnalysisResult analyze(Long planId) {
        DiagAssessmentPlan plan = planRepository.findById(planId)
            .orElseThrow(() -> new BizException(40401, "诊断计划不存在"));
        
        List<DiagAssessmentQuestion> questions = questionRepository
            .findByPlanIdOrderBySeqNo(planId);
        
        // 1. 按知识点聚合答题结果
        Map<Long, KpAggregation> kpAggMap = aggregateByKnowledgePoint(questions);

        // 2. 计算每个知识点的诊断掌握度
        List<DiagKpCoverage> coverages = Lists.newArrayList();
        for (Map.Entry<Long, KpAggregation> entry : kpAggMap.entrySet()) {
            Long kpId = entry.getKey();
            KpAggregation agg = entry.getValue();
            
            // EMA加权掌握度更新
            BigDecimal masteryBefore = getExistingMastery(plan.getUserId(), kpId);
            BigDecimal diagMastery = calculateDiagMastery(agg);
            BigDecimal masteryAfter = updateMastery(masteryBefore, diagMastery);
            
            // 盲区等级判定
            String blindSpotLevel = determineBlindSpotLevel(masteryAfter);
            
            // 错误模式识别
            ErrorPattern errorPattern = identifyErrorPattern(agg, kpId);

            DiagKpCoverage coverage = DiagKpCoverage.builder()
                .planId(planId)
                .kpId(kpId)
                .kpName(agg.getKpName())
                .kpPath(agg.getKpPath())
                .parentKpId(agg.getParentKpId())
                .isLeaf(agg.isLeaf())
                .questionCount(agg.getTotal())
                .correctCount(agg.getCorrect())
                .partialCount(agg.getPartial())
                .wrongCount(agg.getWrong())
                .masteryBefore(masteryBefore)
                .masteryAfter(masteryAfter)
                .masteryDelta(masteryAfter.subtract(masteryBefore))
                .blindSpotLevel(blindSpotLevel)
                .diagDetail(JsonUtil.toJsonNode(errorPattern))
                .build();
            
            coverages.add(coverage);
            
            // 同步更新全局知识点掌握度
            masteryService.updateMastery(plan.getUserId(), kpId, masteryAfter, 
                MasteryUpdateSource.DIAGNOSTIC, planId);
        }
        
        kpCoverageRepository.saveAll(coverages);

        // 3. 更新盲区历史
        List<DiagKpCoverage> blindSpots = coverages.stream()
            .filter(c -> !"none".equals(c.getBlindSpotLevel()))
            .collect(Collectors.toList());
        
        updateBlindSpotHistory(plan.getUserId(), blindSpots, planId);

        // 4. 按知识点路径汇总非叶子节点
        rollUpToParentNodes(coverages);

        return new BlindSpotAnalysisResult(plan, coverages, blindSpots);
    }

    /**
     * 诊断掌握度计算
     * 综合正确率、部分正确、题目难度权重
     */
    private BigDecimal calculateDiagMastery(KpAggregation agg) {
        double weightedScore = 0;
        double maxWeight = 0;
        
        for (AnswerDetail answer : agg.getAnswers()) {
            double difficultyWeight = 1.0 - answer.getDifficulty(); // 简单题权重低，难题权重高
            maxWeight += difficultyWeight;
            
            if (answer.isCorrect()) {
                weightedScore += difficultyWeight;
            } else if (answer.isPartial()) {
                weightedScore += difficultyWeight * 0.5;
            }
        }
        
        return maxWeight > 0 
            ? BigDecimal.valueOf(weightedScore / maxWeight).setScale(3, RoundingMode.HALF_UP)
            : BigDecimal.ZERO;
    }

    /**
     * EMA掌握度更新
     * new_mastery = old_mastery * (1-α) + diag_mastery * α
     */
    private BigDecimal updateMastery(BigDecimal oldMastery, BigDecimal diagMastery) {
        if (oldMastery == null || oldMastery.compareTo(BigDecimal.ZERO) == 0) {
            // 无历史数据，直接使用诊断结果
            return diagMastery;
        }
        double alpha = LEARNING_RATE;
        double updated = oldMastery.doubleValue() * (1 - alpha) 
                       + diagMastery.doubleValue() * alpha;
        return BigDecimal.valueOf(updated).setScale(3, RoundingMode.HALF_UP);
    }

    /**
     * 盲区等级判定
     */
    private String determineBlindSpotLevel(BigDecimal mastery) {
        double m = mastery.doubleValue();
        if (m < SEVERE_THRESHOLD)   return "severe";
        if (m < MODERATE_THRESHOLD) return "moderate";
        if (m < MILD_THRESHOLD)     return "mild";
        return "none";
    }

    /**
     * 错误模式识别
     * 基于错误类型统计和知识点关联分析
     */
    private ErrorPattern identifyErrorPattern(KpAggregation agg, Long kpId) {
        ErrorPattern pattern = new ErrorPattern();
        
        // 统计最常见的错误表现
        Map<String, Integer> errorTypeCounts = agg.getWrongAnswers().stream()
            .collect(Collectors.groupingBy(
                AnswerDetail::getErrorTag,
                Collectors.summingInt(a -> 1)
            ));
        
        String topErrorPattern = errorTypeCounts.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElse("未知错误模式");
        
        pattern.setErrorPattern(topErrorPattern);
        pattern.setTypicalErrors(errorTypeCounts.keySet().stream()
            .limit(3).collect(Collectors.toList()));
        
        return pattern;
    }
}
```

### 5.3 补强优先级排序算法

```java
/**
 * 补强优先级排序服务
 * <p>
 * 综合考虑盲区严重度、知识点重要性、前置依赖、考试临近等因素，
 * 为每个盲区知识点计算补强优先级。
 */
@Service
public class RemediationPrioritizer {

    /**
     * 排序权重配置
     */
    private static final double W_SEVERITY      = 0.35;  // 盲区严重度
    private static final double W_IMPORTANCE    = 0.25;  // 知识点重要性
    private static final double W_DEPENDENCY    = 0.15;  // 前置依赖影响面
    private static final double W_EXAM_PROXIMITY= 0.10;  // 考试临近度
    private static final double W_RECURRENCE    = 0.10;  // 历史复发次数
    private static final double W_TEXTBOOK_FREQ = 0.05;  // 教材/考试出现频率

    public List<RemediationPriority> prioritize(
            List<DiagKpCoverage> blindSpots,
            Long userId,
            String subjectCode) {
        
        // 获取学生上下文
        StudentContext ctx = studentContextService.getContext(userId, subjectCode);
        
        List<RemediationPriority> priorities = Lists.newArrayList();
        
        for (DiagKpCoverage blindSpot : blindSpots) {
            Long kpId = blindSpot.getKpId();
            
            // 1. 盲区严重度得分 (0-1)
            double severityScore = severityToScore(blindSpot.getBlindSpotLevel());
            
            // 2. 知识点重要性得分 (0-1)
            double importanceScore = knowledgePointService
                .getImportanceScore(kpId, ctx.getStageCode());
            
            // 3. 前置依赖影响面得分 (0-1)
            // 该知识点被多少后续知识点依赖
            double dependencyScore = knowledgeGraphService
                .getDependencyImpactScore(kpId);
            
            // 4. 考试临近度得分 (0-1)
            // 如果该知识点在即将到来的考试范围内，得分更高
            double examProximityScore = examCalendarService
                .getExamProximityScore(kpId, ctx);
            
            // 5. 历史复发次数得分 (0-1)
            // 补强后再次成为盲区的知识点优先级更高
            BlindSpotHistory history = blindSpotHistoryRepository
                .findByUserIdAndKpId(userId, kpId);
            double recurrenceScore = history != null 
                ? Math.min(1.0, history.getRecurrenceCount() / 3.0) 
                : 0.0;
            
            // 6. 教材/考试出现频率得分 (0-1)
            double freqScore = knowledgePointService.getExamFrequencyScore(kpId);
            
            // 加权综合得分
            double totalScore = 
                W_SEVERITY       * severityScore +
                W_IMPORTANCE     * importanceScore +
                W_DEPENDENCY     * dependencyScore +
                W_EXAM_PROXIMITY * examProximityScore +
                W_RECURRENCE     * recurrenceScore +
                W_TEXTBOOK_FREQ  * freqScore;
            
            // 生成优先级原因说明
            String reason = buildPriorityReason(
                blindSpot, severityScore, importanceScore, 
                dependencyScore, examProximityScore, recurrenceScore
            );
            
            priorities.add(new RemediationPriority(
                kpId, blindSpot.getKpName(), totalScore, reason
            ));
        }
        
        // 按得分降序排列
        priorities.sort(Comparator.comparingDouble(RemediationPriority::getScore).reversed());
        
        // 设置排名
        for (int i = 0; i < priorities.size(); i++) {
            priorities.get(i).setPriority(i + 1);
        }
        
        return priorities;
    }

    private double severityToScore(String level) {
        return switch (level) {
            case "severe"   -> 1.0;
            case "moderate" -> 0.65;
            case "mild"     -> 0.35;
            default         -> 0.0;
        };
    }
}
```

### 5.4 靶向训练序列生成

```java
/**
 * 靶向训练序列生成器
 * <p>
 * 为每个盲区知识点生成 4 阶段训练序列。
 */
@Service
public class TargetedTrainingGenerator {

    // 各阶段默认题目数
    private static final int GUIDED_Q_COUNT       = 3;
    private static final int INDEPENDENT_Q_COUNT  = 4;
    private static final int VERIFICATION_Q_COUNT = 2;
    
    // 各阶段通过阈值
    private static final double GUIDED_PASS_THRESHOLD      = 0.60;
    private static final double INDEPENDENT_PASS_THRESHOLD = 0.70;
    private static final double VERIFICATION_PASS_THRESHOLD= 0.75;

    /**
     * 为一个盲区知识点生成完整训练序列
     */
    public List<RemediationTask> generateTasksForKp(
            DiagKpCoverage blindSpot,
            RemediationCycle cycle,
            int seqStart) {
        
        Long kpId = blindSpot.getKpId();
        String kpName = blindSpot.getKpName();
        
        List<RemediationTask> tasks = Lists.newArrayList();
        int seq = seqStart;

        // Stage 1: 概念复习
        RemediationTask conceptTask = buildConceptReviewTask(
            cycle, kpId, kpName, seq++, blindSpot
        );
        tasks.add(conceptTask);

        // Stage 2: 引导练习（有解析）
        RemediationTask guidedTask = buildGuidedPracticeTask(
            cycle, kpId, kpName, seq++, blindSpot
        );
        tasks.add(guidedTask);

        // Stage 3: 独立练习（无解析，即时批改）
        RemediationTask independentTask = buildIndependentPracticeTask(
            cycle, kpId, kpName, seq++, blindSpot
        );
        tasks.add(independentTask);

        // Stage 4: 验证题
        RemediationTask verifyTask = buildVerificationTask(
            cycle, kpId, kpName, seq++, blindSpot
        );
        tasks.add(verifyTask);

        return tasks;
    }

    /**
     * Stage 1: 概念复习
     * 选择与该知识点最匹配的讲解内容（视频/图文）
     */
    private RemediationTask buildConceptReviewTask(
            RemediationCycle cycle, Long kpId, String kpName,
            int seq, DiagKpCoverage blindSpot) {
        
        // 调用内容服务获取该知识点最优讲解内容
        List<ContentRef> contents = contentRecommendationService
            .getBestConceptContents(kpId, ContentSelectionCriteria.builder()
                .stageCode(cycle.getStageCode())
                .subjectCode(cycle.getSubjectCode())
                .difficultyLevel(blindSpot.getBlindSpotLevel().equals("severe") 
                    ? DifficultyLevel.BASIC 
                    : DifficultyLevel.MEDIUM)
                .contentType(EnumSet.of(ContentType.VIDEO, ContentType.GRAPHIC_TEXT))
                .limit(2)
                .build());

        return RemediationTask.builder()
            .cycleId(cycle.getId())
            .seqNo(seq)
            .kpId(kpId)
            .kpName(kpName)
            .taskType("concept_review")
            .contentRefs(contents.stream()
                .map(c -> new ContentRefDto(c.getType().name(), c.getId(), c.getTitle()))
                .collect(Collectors.toList()))
            .questionIds(Collections.emptyList())
            .targetMastery(null) // 概念复习无量化目标
            .status("pending")
            .build();
    }

    /**
     * Stage 2: 引导练习
     * 选择带详细解析的题目，难度偏低，帮助学生建立理解
     */
    private RemediationTask buildGuidedPracticeTask(
            RemediationCycle cycle, Long kpId, String kpName,
            int seq, DiagKpCoverage blindSpot) {
        
        // 基于盲区严重度调整难度
        DifficultyRange diffRange = blindSpot.getBlindSpotLevel().equals("severe")
            ? new DifficultyRange(0.15, 0.45)   // 严重盲区：基础题
            : new DifficultyRange(0.30, 0.55);  // 中等盲区：中等题

        List<Long> questionIds = questionRecommendationService
            .selectQuestionsForKp(kpId, GUIDED_Q_COUNT, diffRange,
                QuestionFilter.builder()
                    .requireDetailedSolution(true)  // 必须有详细解析
                    .excludeDoneByUser(cycle.getUserId())
                    .build());

        return RemediationTask.builder()
            .cycleId(cycle.getId())
            .seqNo(seq)
            .kpId(kpId)
            .kpName(kpName)
            .taskType("guided_practice")
            .contentRefs(Collections.emptyList())
            .questionIds(questionIds)
            .targetMastery(new BigDecimal(GUIDED_PASS_THRESHOLD))
            .status("pending")
            .build();
    }

    /**
     * Stage 3: 独立练习
     * 无解析提示，学生独立完成，检验真实掌握程度
     */
    private RemediationTask buildIndependentPracticeTask(
            RemediationCycle cycle, Long kpId, String kpName,
            int seq, DiagKpCoverage blindSpot) {
        
        DifficultyRange diffRange = blindSpot.getBlindSpotLevel().equals("severe")
            ? new DifficultyRange(0.30, 0.60)
            : new DifficultyRange(0.40, 0.70);

        List<Long> questionIds = questionRecommendationService
            .selectQuestionsForKp(kpId, INDEPENDENT_Q_COUNT, diffRange,
                QuestionFilter.builder()
                    .requireDetailedSolution(false)
                    .excludeDoneByUser(cycle.getUserId())
                    .build());

        return RemediationTask.builder()
            .cycleId(cycle.getId())
            .seqNo(seq)
            .kpId(kpId)
            .kpName(kpName)
            .taskType("independent_practice")
            .contentRefs(Collections.emptyList())
            .questionIds(questionIds)
            .targetMastery(new BigDecimal(INDEPENDENT_PASS_THRESHOLD))
            .status("pending")
            .build();
    }

    /**
     * Stage 4: 验证题
     * 难度中高，一锤定音检验是否真正掌握
     */
    private RemediationTask buildVerificationTask(
            RemediationCycle cycle, Long kpId, String kpName,
            int seq, DiagKpCoverage blindSpot) {
        
        DifficultyRange diffRange = new DifficultyRange(0.45, 0.75);

        List<Long> questionIds = questionRecommendationService
            .selectQuestionsForKp(kpId, VERIFICATION_Q_COUNT, diffRange,
                QuestionFilter.builder()
                    .requireDetailedSolution(false)
                    .excludeDoneByUser(cycle.getUserId())
                    .build());

        return RemediationTask.builder()
            .cycleId(cycle.getId())
            .seqNo(seq)
            .kpId(kpId)
            .kpName(kpName)
            .taskType("verification")
            .contentRefs(Collections.emptyList())
            .questionIds(questionIds)
            .targetMastery(new BigDecimal(VERIFICATION_PASS_THRESHOLD))
            .status("pending")
            .build();
    }
}
```

## 8. 关键业务规则

### 8.1 诊断策略规则

| 策略 | 适用场景 | 题目数范围 | 覆盖目标 | 特点 |
|------|----------|-----------|----------|------|
| `full_scan` | 单元/章节学完后全面诊断 | 10-30 | ≥90% 叶子知识点 | 全覆盖，耗时较长 |
| `quick_scan` | 日常快速检测 | 5-10 | ≥60% 核心知识点 | 抽样核心考点，快速出结果 |
| `targeted_verify` | 补强后验证 / 定向复查 | 3-8 | 仅指定知识点 | 精准验证，不做冗余覆盖 |

### 8.2 盲区等级与补强强度映射

| 盲区等级 | 掌握度 | 概念复习 | 引导练习 | 独立练习 | 验证题 | 预计天数 |
|----------|--------|----------|----------|----------|--------|----------|
| mild | 0.60-0.75 | 1篇 | 2题 | 2题 | 1题 | 1天 |
| moderate | 0.40-0.60 | 1-2篇 | 3题 | 3题 | 2题 | 2-3天 |
| severe | <0.40 | 2篇 | 3题 | 4题 | 2题 | 3-5天 |

### 8.3 前置依赖处理规则

```
当知识点A被判定为盲区时：
1. 检查A的前置知识点列表：prereqs = getPrerequisites(A)
2. 对每个前置知识点P：
   a. 如果P也是盲区 → P的补强优先级应高于A
   b. 如果P掌握度未知 → 标记为"待诊断"，纳入下一轮诊断
   c. 如果P掌握度≥0.75 → 正常编排A的补强训练
3. 补强序列：先补P，再补A
4. 如果P的补强未通过 → A的补强推迟
```

### 8.4 诊断频率限制

| 维度 | 限制 |
|------|------|
| 同一学科 24h 内 | 最多 3 次诊断 |
| 同一学科 7d 内 | 最多 5 次诊断 |
| 补强周期同时进行 | 最多 2 个（不同学科） |
| 诊断计划有效时长 | 创建后 2h 内未完成自动过期 |

```java
@Scheduled(cron = "0 0 3 * * MON")
public void detectBlindSpotRecurrence() {
    List<BlindSpotHistory> remediated = historyRepository
        .findByStatus("remediated");

        // 获取补强后的所有答题数据

                history.getKpId(),

        // 计算当前掌握度

        if (currentMastery < 0.60) {

            history.setRecurrenceCount(history.getRecurrenceCount() + 1);

            diagOrchestratorService.createTargetedVerifyPlan(
                history.getUserId(),
                history.getSubjectCode(),
                List.of(history.getKpId())
            );
        }
```

### 12.2 关键枚举定义

```java
/** 诊断策略 */
public enum DiagStrategy {
    FULL_SCAN,       // 全覆盖扫描
    QUICK_SCAN,      // 快速抽样
    TARGETED_VERIFY  // 定向验证
}

/** 盲区等级 */
public enum BlindSpotLevel {
    NONE,            // 无盲区 (mastery ≥ 0.75)
    MILD,            // 轻度 (0.60 ≤ mastery < 0.75)
    MODERATE,        // 中度 (0.40 ≤ mastery < 0.60)
    SEVERE           // 重度 (mastery < 0.40)
}

/** 补强训练阶段 */
public enum RemediationTaskType {
    CONCEPT_REVIEW,        // 概念复习
    GUIDED_PRACTICE,       // 引导练习（带解析）
    INDEPENDENT_PRACTICE,  // 独立练习（无解析）
    VERIFICATION           // 验证题
}

/** 补强周期状态 */
public enum RemediationCycleStatus {
    PENDING,             // 待开始
    IN_PROGRESS,         // 进行中
    VERIFIED,            // 全部验证通过
    PARTIALLY_VERIFIED,  // 部分验证通过
    ABANDONED            // 已放弃（超时）
}

/** 盲区历史状态 */
public enum BlindSpotStatus {
    ACTIVE,       // 当前活跃盲区
    REMEDIATED,   // 已补强消除
    RECURRENT     // 补强后复发
}
```
