# 端到端流程设计 - 学习报告查看与社交分享传播完整链路

## 1. 文档概述

### 1.1 功能定位

本文档细化 PrimeTop 学习报告从**生成触发**到**用户查看**再到**社交分享传播**的完整端到端链路。重点解决以下场景：

- 学生/家长收到报告生成通知后，在 APP 内查看完整报告
- 用户将学习报告导出为精美长图/PDF，分享到微信、朋友圈、QQ 等社交平台
- 受众通过分享卡片/链接进入 APP 或下载页，完成新用户转化
- 分享传播链路的数据追踪与增长归因

> 本文档串联但不重复以下已有文档内容：
> - `学习报告生成与交付服务-详细设计.md` — 服务端报告生成管线
> - `客户端-学习报告详情与分享页面架构与交互设计.md` — 报告页面 UI/交互
> - `学习数据可视化与图表渲染引擎-详细设计.md` — 图表渲染组件
> - `分享与社交裂变系统-详细设计.md` — 分享 SDK 与裂变机制
> - `消息与推送服务-详细设计.md` — 推送触达通道
> - `客户端路由与深链接系统-详细设计.md` — Deep Link 路由

### 1.2 核心目标

| 目标 | 量化指标 |
|------|----------|
| 报告查看率 | 通知送达后 24h 内打开报告 ≥ 45% |
| 分享转化率 | 查看报告后发起分享 ≥ 12% |
| 社交回流率 | 单次分享平均带回 ≥ 0.8 次点击 |
| 新增注册归因 | 月度通过报告分享带来的新注册 ≥ 5% |
| 分享内容加载 | 分享长图渲染 < 3s，H5 预览首屏 < 2s |

### 3.2 通知推送策略

报告生成完成后，推送双通道通知：

```java
public class ReportDeliveryService {

    /**
     * 报告交付：Push + 站内通知
     */
    public void deliverReport(Report report) {
        // 1. 站内消息（必达）
        NotificationMessage notification = NotificationMessage.builder()
            .userId(report.getUserId())
            .type(NotificationType.REPORT_READY)
            .title(getReportTitle(report))
            .body(getReportSummary(report))
            .deeplink(buildReportDeeplink(report))
            .imageUrl(report.getCoverImageUrl())
            .build();
        notificationService.send(notification);

        // 2. Push推送（根据用户偏好）
        UserNotificationPreference pref = getUserPreference(report.getUserId());
        if (pref.isPushEnabled()) {
            PushMessage push = PushMessage.builder()
                .userId(report.getUserId())
                .title(getPushTitle(report))
                .body(getPushBody(report))
                .deeplink(buildReportDeeplink(report))
                .pushChannel(selectChannel(report.getUserId())) // APNs/FCM/华为/小米
                .build();
            pushService.send(push);
        }

        // 3. 家长端：如果学生<14岁，同步推送给绑定家长
        if (report.getStudentAge() < 14) {
            List<ParentBinding> parents = parentService.getBoundParents(report.getUserId());
            for (ParentBinding parent : parents) {
                sendParentNotification(parent.getParentUserId(), report);
            }
        }
    }

    private String buildReportDeeplink(Report report) {
        // scheme://report/detail?reportId=xxx&type=weekly&source=push
        return String.format("primetop://report/detail?reportId=%s&type=%s&source=push",
            report.getReportId(), report.getReportType());
    }
}
```

### 4.1 通知跳转路由

用户点击 Push 通知或站内消息后，客户端路由处理：

```dart
// 客户端 Deep Link 路由处理
class ReportDeeplinkHandler {
  /// primetop://report/detail?reportId=xxx&type=weekly&source=push
  Future<bool> handleReportDeeplink(Uri uri) async {
    final reportId = uri.queryParameters['reportId'];
    final reportType = uri.queryParameters['type'];
    final source = uri.queryParameters['source'] ?? 'unknown';

    if (reportId == null) return false;

    // 1. 埋点：报告从通知打开
    AnalyticsService.track('report_open_from_notification', {
      'report_id': reportId,
      'report_type': reportType,
      'source': source,
    });

    // 2. 检查登录状态
    if (!authService.isLoggedIn) {
      // 未登录：跳转登录后回跳
      await navigator.push(LoginPage(
        onLoginSuccess: () => _navigateToReport(reportId, source),
      ));
      return true;
    }

    return _navigateToReport(reportId, source);
  }

  Future<bool> _navigateToReport(String reportId, String source) async {
    // 3. 导航到报告详情页
    navigator.push(ReportDetailPage(
      reportId: reportId,
      entrySource: source, // push / notification_center / share_link
    ));
    return true;
  }
}
```

### 4.2 报告详情数据加载

```dart
// 报告详情页 ViewModel
class ReportDetailViewModel extends ChangeNotifier {
  final ReportApiService _reportApi;
  
  ReportDetail? _reportDetail;
  bool _isLoading = true;
  String? _error;
  
  ReportDetail? get reportDetail => _reportDetail;
  bool get isLoading => _isLoading;
  String? get error => _error;

  Future<void> loadReport(String reportId) async {
    _isLoading = true;
    _error = null;
    notifyListeners();

    try {
      // 并行加载报告数据和分享配置
      final results = await Future.wait([
        _reportApi.getReportDetail(reportId),
        _reportApi.getShareConfig(reportId),
      ]);

      _reportDetail = ReportDetail(
        data: results[0] as ReportData,
        shareConfig: results[1] as ShareConfig,
      );
    } on ApiException catch (e) {
      if (e.statusCode == 404) {
        _error = '报告不存在或已过期';
      } else if (e.statusCode == 403) {
        _error = '无权查看此报告';
      } else {
        _error = '加载失败，请稍后重试';
      }
    } on SocketException {
      // 离线降级：尝试加载本地缓存
      final cached = await _reportApi.getCachedReport(reportId);
      if (cached != null) {
        _reportDetail = ReportDetail(data: cached, shareConfig: null);
      } else {
        _error = '网络不可用，请检查网络后重试';
      }
    } finally {
      _isLoading = false;
      notifyListeners();
    }
  }
}
```

### 4.3 服务端报告详情 API

```java
@RestController
@RequestMapping("/api/v1/reports")
public class ReportController {

    /**
     * 获取报告详情
     * GET /api/v1/reports/{reportId}
     */
    @GetMapping("/{reportId}")
    public ApiResponse<ReportDetailVO> getReportDetail(
            @PathVariable String reportId,
            @RequestHeader("X-User-Id") String userId) {

        // 1. 权限校验：报告归属验证
        Report report = reportService.getReport(reportId);
        if (!reportService.canView(userId, report)) {
            throw new BusinessException(ErrorCode.REPORT_ACCESS_DENIED);
        }

        // 2. 记录查看事件
        analyticsService.trackReportView(userId, reportId);

        // 3. 组装报告详情 VO
        ReportDetailVO detail = ReportDetailVO.builder()
            .reportId(report.getReportId())
            .reportType(report.getReportType())
            .periodStart(report.getPeriodStart())
            .periodEnd(report.getPeriodEnd())
            .studentName(report.getStudentName())
            .gradeInfo(report.getGradeInfo())
            .coverImage(report.getCoverImage())
            .aiSummary(report.getAiSummary())           // AI 智能摘要
            .sections(buildReportSections(report))       // 各数据区块
            .build();

        return ApiResponse.success(detail);
    }

    /**
     * 获取分享配置
     * GET /api/v1/reports/{reportId}/share-config
     */
    @GetMapping("/{reportId}/share-config")
    public ApiResponse<ShareConfigVO> getShareConfig(
            @PathVariable String reportId,
            @RequestHeader("X-User-Id") String userId) {

        ShareConfigVO config = shareService.getShareConfig(userId, reportId);
        return ApiResponse.success(config);
    }
}
```

### 4.5 报告页面渲染流程

```dart
// ReportDetailPage 核心渲染逻辑
class ReportDetailPage extends StatefulWidget {
  final String reportId;
  final String entrySource;
  
  @override
  State<ReportDetailPage> createState() => _ReportDetailPageState();
}

class _ReportDetailPageState extends State<ReportDetailPage> {
  late ReportDetailViewModel _vm;
  final ScrollController _scrollController = ScrollController();
  bool _showShareButton = false;  // 滚动到底部显示浮动分享按钮

  @override
  void initState() {
    super.initState();
    _vm = ReportDetailViewModel();
    _vm.loadReport(widget.reportId);
    
    // 监听滚动，控制浮动分享按钮
    _scrollController.addListener(() {
      final showShare = _scrollController.offset > 200;
      if (showShare != _showShareButton) {
        setState(() => _showShareButton = showShare);
      }
    });
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _vm,
      builder: (context, _) {
        if (_vm.isLoading) return _buildLoading();
        if (_vm.error != null) return _buildError(_vm.error!);
        return _buildReportContent(_vm.reportDetail!);
      },
    );
  }

  Widget _buildReportContent(ReportDetail detail) {
    return Scaffold(
      appBar: ReportAppBar(
        title: _getReportTitle(detail),
        actions: [
          // 顶部分享按钮（始终可见）
          ShareButton(onPressed: () => _handleShare(detail)),
          // 收藏按钮
          BookmarkButton(
            isBookmarked: detail.isBookmarked,
            onToggle: () => _toggleBookmark(detail),
          ),
        ],
      ),
      body: SingleChildScrollView(
        controller: _scrollController,
        padding: EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // 封面卡片
            _buildCoverCard(detail),
            SizedBox(height: 16),
            // AI 智能摘要
            _buildAiSummary(detail.aiSummary),
            SizedBox(height: 16),
            // 各数据区块（动态渲染）
            ...detail.sections.map((s) => _buildSection(s)),
            SizedBox(height: 80), // 底部留白给浮动按钮
          ],
        ),
      ),
      // 浮动分享按钮
      floatingActionButton: _showShareButton
          ? FloatingActionButton.extended(
              icon: Icon(Icons.share),
              label: Text('分享报告'),
              onPressed: () => _handleShare(detail),
            )
          : null,
    );
  }

  /// 渲染单个报告区块
  Widget _buildSection(ReportSection section) {
    return Padding(
      padding: EdgeInsets.only(bottom: 20),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          // 区块标题
          Text(section.title, style: Theme.of(context).textTheme.titleMedium),
          if (section.subtitle != null)
            Text(section.subtitle, style: Theme.of(context).textTheme.bodySmall),
          SizedBox(height: 12),
          // 图表渲染（调用 VizEngine）
          if (section.charts != null)
            ...section.charts!.map((c) => VizChart(config: c)),
          // 区块特化内容
          _buildSectionContent(section),
        ],
      ),
    );
  }
}
```

### 5.2 分享素材生成流程

分享前需要生成三类素材：

| 素材类型 | 用途 | 生成方式 | 规格 |
|----------|------|----------|------|
| 缩略图 | 社交平台分享卡片封面 | 服务端预生成 | 300×300px, PNG |
| 分享长图 | 朋友圈/QQ空间图文分享 | 客户端实时渲染 | 750×N px, PNG, ≤5MB |
| H5 预览页 | 链接分享落地页 | 服务端预生成 | 响应式 H5 |

#### 5.2.1 服务端分享素材预生成

```java
@Service
public class ReportShareAssetService {

    /**
     * 报告生成时预生成分享素材
     */
    public ShareAssets preGenerateShareAssets(Report report) {
        // 1. 生成分享缩略图
        String thumbnailUrl = generateThumbnail(report);
        
        // 2. 生成 H5 预览页
        String h5PreviewUrl = generateH5Preview(report);
        
        // 3. 生成长图模板配置（客户端用此配置实时渲染）
        LongImageTemplate template = buildLongImageTemplate(report);
        
        return ShareAssets.builder()
            .thumbnailUrl(thumbnailUrl)
            .h5PreviewUrl(h5PreviewUrl)
            .longImageTemplate(template)
            .shareTitle(buildShareTitle(report))
            .shareDescription(buildShareDescription(report))
            .build();
    }

    private String generateThumbnail(Report report) {
        // 使用服务端图片渲染引擎生成缩略图
        Map<String, Object> thumbnailData = Map.of(
            "coverImage", report.getCoverImage(),
            "period", formatPeriod(report),
            "highlights", extractHighlights(report),
            "studentAvatar", report.getStudentAvatar(),
            "gradeInfo", report.getGradeInfo()
        );
        
        byte[] image = imageRenderer.render("report-thumbnail", thumbnailData);
        String path = String.format("share/report/%s/thumbnail.png", report.getReportId());
        return storageService.upload(image, path, "image/png");
    }
```

```dart
class ReportShareService {

        break;
      case SharePlatform.qq:

        break;
      case SharePlatform.qzone:
        await _shareToQZone(report, shareId);
        break;
      case SharePlatform.weibo:
        await _shareToWeibo(report, shareId, mode);
        break;
      case SharePlatform.copyLink:
        await _copyShareLink(report, shareId);
        break;
    }

    // 3. 埋点：分享发起
    AnalyticsService.track('report_share_initiated', {
      'report_id': report.reportId,
      'platform': platform.name,
      'share_mode': mode.name,
      'share_id': shareId,
    });
  }

  /// 微信好友分享
  Future<void> _shareToWechat(ReportDetail report, String shareId, ShareMode mode) async {
    final shareLink = _buildShareLink(report.reportId, shareId);
    
    if (mode == ShareMode.LINK) {
      // 链接分享：缩略图 + 标题 + 描述 + 链接
      await _shareSdk.shareToWechat(WechatShareWebpage(
        webpageUrl: shareLink,
        title: report.shareConfig.shareTitle,
        description: report.shareConfig.shareDescription,
        thumbnail: await _loadThumbnail(report),
      ));
    } else {
      // 图片分享：长图直接发送
      final longImage = await _imageRenderer.renderLongImage(
        report, report.shareConfig.longImageTemplate,
      );
      await _shareSdk.shareToWechat(WechatShareImage(
        imageData: longImage,
      ));
    }
  }

  /// 朋友圈分享（仅支持图片）
  Future<void> _shareToMoments(ReportDetail report, String shareId) async {
    final longImage = await _imageRenderer.renderLongImage(
      report, report.shareConfig.longImageTemplate,
    );
    await _shareSdk.shareToWechatMoments(WechatMomentsShareImage(
      imageData: longImage,
    ));
  }

  /// 构建分享链接
  String _buildShareLink(String reportId, String shareId) {
    // https://primetop.app/share/report?rid=xxx&sid=xxx&channel=wechat
    return Uri.https('primetop.app', '/share/report', {
      'rid': reportId,
      'sid': shareId,
      'channel': 'share',
    }).toString();
  }

  /// 生成分享追踪ID
  String _generateShareId(String reportId, SharePlatform platform) {
    // shareId = base64(userId_reportId_platform_timestamp_random)
    final parts = [
      authService.currentUserId,
      reportId,
      platform.name,
      DateTime.now().millisecondsSinceEpoch.toString(),
      Random().nextInt(9999).toString().padLeft(4, '0'),
    ];
    return base64UrlEncode(utf8.encode(parts.join('_')));
  }
}
```

```java
@Service
public class ShareAttributionService {

    /**
     * 记录分享事件
     */
    public void recordShareEvent(String shareId, String reportId, 
                                  String sharerId, String platform) {
        ShareRecord record = ShareRecord.builder()
            .shareId(shareId)
            .reportId(reportId)
            .sharerUserId(sharerId)
            .platform(platform)
            .shareTime(Instant.now())
            .clickCount(0)
            .installCount(0)
            .registerCount(0)
            .build();
        shareRecordRepository.save(record);
    }

    /**
     * 记录回流点击
     */
    @Transactional
    public void recordShareCallback(String shareId, String viewerUserId) {
        ShareRecord record = shareRecordRepository.findById(shareId)
            .orElse(null);
        if (record == null) return;

        // 更新点击计数
        record.incrementClickCount();

        // 如果是已登录用户且不是分享者本人
        if (viewerUserId != null && !viewerUserId.equals(record.getSharerUserId())) {
            // 检查是否是新注册用户
            User viewer = userService.getUser(viewerUserId);
            if (viewer.getCreatedAt().isAfter(record.getShareTime())) {
                // 新注册归因
                record.incrementRegisterCount();
                growthAttributionService.attribute(
                    viewerUserId, 
                    record.getSharerUserId(),
                    "report_share",
                    record.getReportId()
                );
            }
        }

        shareRecordRepository.save(record);
    }
}
```

## 9. 错误处理与降级策略

### 9.1 各阶段错误处理

| 阶段 | 错误场景 | 处理策略 |
|------|----------|----------|
| 生成通知 | Push 推送失败 | 降级为仅站内通知，下次启动时弹提醒 |
| 数据加载 | 网络不可用 | 展示本地缓存版本，标注"数据可能不是最新" |
| 数据加载 | 报告已过期/删除 | 展示过期提示页，提供"查看最新报告"入口 |
| 数据加载 | 无权查看（他人报告）| 展示预览版（脱敏数据）+ 下载 CTA |

| 长图渲染 | 渲染超时 (>5s) | 取消渲染，降级为链接分享 |
| 平台分享 | 微信未安装 | Toast 提示"请先安装微信"，移除微信选项 |

## 10. 安全与合规

### 10.1 分享内容脱敏规则

```java
@Service
public class ReportShareSanitizer {

    /**
     * 对外分享内容脱敏处理
     */
    public ReportPreview sanitizeForShare(Report report, String viewerUserId) {
        ReportPreview preview = new ReportPreview();
        
        // 1. 是否是本人或绑定家长
        boolean isOwner = report.getUserId().equals(viewerUserId);
        boolean isParent = parentService.isBoundParent(viewerUserId, report.getUserId());
        
        if (isOwner || isParent) {
            // 本人/家长：完整数据
            preview.setFullAccess(true);
            preview.setData(report.getFullData());
        } else {
            // 外部查看者：脱敏数据
            preview.setFullAccess(false);
            preview.setData(sanitizeData(report));
        }
        
        return preview;
    }

    private Map<String, Object> sanitizeData(Report report) {
        Map<String, Object> data = new HashMap<>();
        
        // 只保留汇总级数据，不展示详细知识点和具体题目
        data.put("totalDuration", report.getTotalDuration());
        data.put("taskCompleted", report.getTaskCompleted());
        data.put("streakDays", report.getStreakDays());
        
        // 移除个人身份信息
        // - 不展示真实姓名（用昵称或"某同学"）
        data.put("studentName", "某同学");
        // - 不展示学校信息
        // - 不展示具体薄弱知识点
        // - 不展示具体题目和答案
        
        return data;
    }
}
```

### 11.2 长图渲染优化

```dart
class OptimizedLongImageRenderer {
  /// 分块渲染策略：避免一次性分配大内存
  Future<Uint8List> renderChunked(ReportDetail detail) async {
    final chunks = <Uint8List>[];
    
    for (final section in detail.sections) {
      // 每个区块独立渲染
      final chunk = await compute(
        _renderSectionIsolate,  // 在 Isolate 中渲染
        _SectionParams(section, detail.theme),
      );
      chunks.add(chunk);
    }
    
    // 合并所有区块
    return _mergeChunks(chunks, width: 750);
  }
  
  /// 长图缓存：同一报告不重复渲染
  Future<Uint8List> renderWithCache(ReportDetail detail) async {
    final cacheKey = 'report_long_${detail.reportId}_${detail.versionHash}';
    final cached = await ImageCacheManager.get(cacheKey);
    if (cached != null) return cached;
    
    final image = await renderChunked(detail);
    await ImageCacheManager.put(cacheKey, image, ttl: Duration(hours: 24));
    return image;
  }
}
```
