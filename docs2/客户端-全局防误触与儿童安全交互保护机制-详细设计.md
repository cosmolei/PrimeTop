# 客户端-全局防误触与儿童安全交互保护机制-详细设计

## 1. 概述

### 1.1 模块定位

PrimeTop 面向幼儿至高中全学段用户，其中幼儿（3-6 岁）和小学低年级（6-9 岁）用户的精细动作发育尚未成熟，认知能力有限，容易在操作 App 时产生误触行为——如意外退出学习会话、误删错题记录、误触支付按钮、误改学习设置等。本模块为客户端全局基础组件，提供统一的防误触检测、操作分级拦截、年龄自适应确认交互和家长验证网关，在不影响高年龄段用户使用效率的前提下，保障低龄用户的操作安全与数据安全。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 防误支付 | 低龄用户无法独立完成任何付费操作 |
| 防误退出 | 学习会话中意外退出需二次确认，避免打断学习节奏 |
| 防误删除 | 用户数据（错题、笔记、计划）删除需年龄适配的确认 |
| 防误设置 | 关键设置变更（年级切换、教材版本、解绑家长）需保护 |
| 手势容错 | 区分有意触摸与无意触碰，降低误操作触发率 |
| 无感保护 | 对高年龄段用户（初中及以上）自动降低拦截强度，不影响效率 |

### 1.3 适用范围

- 客户端：Flutter（iOS / Android）
- 作用域：全局所有页面与组件
- 触发条件：根据用户年龄、学段自动生效，支持家长端配置

## 2. 用户分龄保护策略

### 2.1 学段保护等级

| 学段 | 年龄区间 | 保护等级 | 核心策略 |
| --- | --- | --- | --- |
| 幼儿 | 3-6 岁 | L3-严格 | 所有关键操作需家长验证；手势容错高阈值；3秒无操作自动取消弹窗 |
| 小学低年级 | 6-9 岁（1-3年级） | L2-加强 | 付费与设置需家长验证；删除操作需拖拽确认；手势容错中阈值 |
| 小学高年级 | 9-12 岁（4-6年级） | L1-标准 | 付费需家长验证或密码确认；删除操作需二次点击确认 |
| 初中及以上 | 12+ 岁 | L0-常规 | 付费需密码/生物识别；删除操作常规确认框 |
| 家长身份 | - | L0-常规 | 按成人模式处理，不施加额外保护 |

### 2.2 保护等级决策流程

```
用户操作触发
    │
    ▼
查询当前账号身份 ──→ 是否为家长身份？──→ YES ──→ L0-常规处理
    │                              │
    │ NO                           │
    ▼                              │
查询学生学段                       │
    │                              │
    ├── 幼儿 ──────────────────→ L3-严格
    ├── 小学低年级(1-3) ────────→ L2-加强
    ├── 小学高年级(4-6) ────────→ L1-标准
    └── 初中及以上 ─────────────→ L0-常规
    │
    ▼
是否家长端覆盖配置？──→ YES ──→ 使用家长配置的保护等级（可更严）
    │ NO
    ▼
使用系统默认保护等级
```

### 2.3 家长端自定义配置

家长可在家长中心调整保护强度，但只能**加强**不能减弱最低保护线：

## 3. 操作分级体系

### 3.1 操作风险等级定义

| 风险等级 | 代号 | 说明 | 示例操作 |
| --- | --- | --- | --- |
| 无风险 | R0 | 纯浏览/学习行为 | 查看题目、阅读教材、答题选择、翻页 |
| 低风险 | R1 | 可逆的界面操作 | 切换Tab、返回上一页、展开/收起面板 |
| 中风险 | R2 | 可恢复的数据操作 | 删除单条错题、清除单条对话记录、修改昵称 |
| 高风险 | R3 | 难以恢复或影响重大的操作 | 清空全部错题、切换学段/年级、解绑家长账号、重置学习计划 |
| 关键风险 | R4 | 涉及资金或隐私的操作 | 购买会员、支付订单、订阅自动续费、导出个人数据、注销账号 |

### 3.2 保护等级 × 风险等级拦截矩阵

| 操作风险 \ 保护等级 | L0-常规 | L1-标准 | L2-加强 | L3-严格 |
| --- | --- | --- | --- | --- |
| R0-无风险 | 放行 | 放行 | 放行 | 放行 |
| R1-低风险 | 放行 | 放行 | 手势检测 | 手势检测 + 防抖延迟(300ms) |
| R2-中风险 | 常规确认框 | 二次点击确认 | 拖拽滑块确认 | **家长验证** |
| R3-高风险 | 密码确认 | 密码确认 | **家长验证** | **家长验证** |
| R4-关键风险 | 密码/生物识别 | **家长验证** | **家长验证** | **家长验证** |

> **加粗**表示该组合为强制规则，家长配置不可绕过。

## 4. 核心交互机制设计

### 4.1 确认交互类型

根据保护等级与风险等级的组合，系统提供 5 种确认交互组件：

| 类型 | 适用场景 | 交互方式 | 用户体验 |
| --- | --- | --- | --- |
| 常规确认框 | L0 + R2 | 标准 AlertDialog，[取消] [确定] | 快速操作 |
| 二次点击确认 | L1 + R2 | 首次点击高亮按钮，2秒内再次点击生效 | 轻量防误触 |
| 拖拽滑块确认 | L2 + R2 | 需拖动滑块从左到右，触发震动反馈 | 有意操作验证 |
| 密码/PIN确认 | L0-L1 + R3-R4 | 输入4位PIN码或系统生物识别 | 快速身份验证 |
| 家长验证网关 | L2-L3 + R2-R4 或 forceParentAuth | 扫码 / 家长PIN / 家长指纹 | 增强身份验证 |

### 4.3 家长验证网关

家长验证是最高级别的保护，适用于 L3-严格等级下的 R2+ 操作和所有等级下的 R4 操作。

#### 4.3.1 验证方式优先级

```
1. 家长端在线（同一设备/关联设备在线）
   ├── 方式A：推送通知 → 家长端一键确认（推荐，体验最好）
   └── 方式B：家长PIN码输入（家长提前设置4-6位数字PIN）

2. 家长端离线
   ├── 方式C：家长生物识别（本机存储的家长指纹/Face ID）
   └── 方式D：预设安全问题（回答家长预设的问题）

3. 所有方式均不可用
   └── 拒绝操作，引导联系客服
```

#### 4.3.2 家长验证服务

```dart
/// 家长验证网关服务
class ParentVerificationService {
  static final ParentVerificationService _instance = ParentVerificationService._();
  factory ParentVerificationService() => _instance;
  ParentVerificationService._();

  final ParentAuthApi _api = ParentAuthApi();
  final LocalSecureStorage _secureStorage = LocalSecureStorage();

  /// 发起家长验证请求
  /// 
  /// [operationId] 操作标识（如 'payment.subscribe'）
  /// [studentId] 当前学生ID
  /// [description] 操作描述（展示给家长）
  Future<ParentVerificationResult> verify({
    required String operationId,
    required String studentId,
    required String description,
    required ParentAuthMethod preferredMethod,
  }) async {
    // Step 1: 尝试首选验证方式
    switch (preferredMethod) {
      case ParentAuthMethod.pushNotification:
        return await _verifyViaPush(
          operationId: operationId,
          studentId: studentId,
          description: description,
        );
      
      case ParentAuthMethod.pin:
        return await _verifyViaPin(
          operationId: operationId,
          studentId: studentId,
        );
      
      case ParentAuthMethod.biometric:
        return await _verifyViaBiometric(
          operationId: operationId,
          studentId: studentId,
        );
      
      case ParentAuthMethod.securityQuestion:
        return await _verifyViaSecurityQuestion(
          operationId: operationId,
          studentId: studentId,
        );
    }
  }

  /// 推送通知验证
  Future<ParentVerificationResult> _verifyViaPush({
    required String operationId,
    required String studentId,
    required String description,
  }) async {
    final requestId = await _api.createVerificationRequest(
      operationId: operationId,
      studentId: studentId,
      description: description,
      method: ParentAuthMethod.pushNotification,
    );

    // 轮询验证结果，超时120秒
    final result = await _api.pollVerificationResult(
      requestId: requestId,
      timeout: const Duration(seconds: 120),
    );

    return result;
  }

  /// PIN码验证
  Future<ParentVerificationResult> _verifyViaPin({
    required String operationId,
    required String studentId,
  }) async {
    // PIN码本地校验（离线可用）
    final storedHash = await _secureStorage.read(
      key: 'parent_pin_hash_$studentId',
    );

    if (storedHash == null) {
      // PIN未设置，降级到推送验证
      return await _verifyViaPush(
        operationId: operationId,
        studentId: studentId,
        description: 'PIN码未设置，需要家长确认',
      );
    }

    // UI层展示PIN输入面板，此处只返回验证入口
    return ParentVerificationResult.pendingPinInput(
      storedHash: storedHash,
    );
  }

  /// 生物识别验证
  Future<ParentVerificationResult> _verifyViaBiometric({
    required String operationId,
    required String studentId,
  }) async {
    final hasBiometric = await BiometricUtil.isAvailable();
    if (!hasBiometric) {
      return ParentVerificationResult.failed(
        reason: '设备不支持生物识别',
        fallbackMethod: ParentAuthMethod.pin,
      );
    }

    final authenticated = await BiometricUtil.authenticate(
      reason: '请家长验证身份',
      biometricOnly: true,
    );

    if (authenticated) {
      return ParentVerificationResult.success(
        method: ParentAuthMethod.biometric,
      );
    } else {
      return ParentVerificationResult.failed(
        reason: '生物识别失败',
        fallbackMethod: ParentAuthMethod.pin,
      );
    }
  }
}

enum ParentAuthMethod {
  pushNotification,
  pin,
  biometric,
  securityQuestion,
}

class ParentVerificationResult {
  final bool success;
  final String? reason;
  final ParentAuthMethod? method;
  final ParentAuthMethod? fallbackMethod;
  final String? pendingPinHash;

  // ... 工厂构造方法省略
}
```

## 5. 手势防误触检测引擎

### 5.1 设计原理

低龄用户（尤其幼儿）操作触摸屏时，常见误触模式包括：

| 误触类型 | 特征 | 示例 |
| --- | --- | --- |
| 掌触 | 大面积接触，无明确移动轨迹 | 拿手机时手掌碰到屏幕 |
| 多指误触 | 多点同时触摸，无规律 | 握持时多指同时按下 |
| 边缘误触 | 触摸点位于屏幕安全区域外 | 手指搭在屏幕边缘 |
| 快速连续触 | 短时间内多次触摸同一区域 | 手指抖动或无意快速点击 |
| 滑动误触 | 从屏幕边缘意外滑入 | 手汗或握持滑动 |

### 5.2 触摸事件分类器

```dart
/// 手势防误触检测器
/// 包装在需要保护的目标 Widget 外层
class SafeTouchDetector extends StatelessWidget {
  final Widget child;
  final VoidCallback? onSafeTap;
  final ProtectionLevel protectionLevel;

  const SafeTouchDetector({
    super.key,
    required this.child,
    this.onSafeTap,
    required this.protectionLevel,
  });

  @override
  Widget build(BuildContext context) {
    if (protectionLevel == ProtectionLevel.L0 || 
        protectionLevel == ProtectionLevel.L1) {
      // L0/L1: 不启用手势检测，直接透传
      return GestureDetector(onTap: onSafeTap, child: child);
    }

    return _SafeTouchWrapper(
      protectionLevel: protectionLevel,
      onSafeTap: onSafeTap,
      child: child,
    );
  }
}

class _SafeTouchWrapper extends StatefulWidget {
  final Widget child;
  final VoidCallback? onSafeTap;
  final ProtectionLevel protectionLevel;

  @override
  State<_SafeTouchWrapper> createState() => _SafeTouchWrapperState();
}

class _SafeTouchWrapperState extends State<_SafeTouchWrapper> {
  DateTime? _lastValidTapTime;
  static const _minTapInterval = Duration(milliseconds: 500);
  static const _maxTouchArea = 6000.0;  // px²，超过视为掌触
  static const _edgeMargin = 8.0;       // px，边缘安全距离

  @override
  Widget build(BuildContext context) {
    return Listener(
      onPointerDown: _handlePointerDown,
      child: GestureDetector(
        onTap: _handleTap,
        child: widget.child,
      ),
    );
  }

  void _handlePointerDown(PointerDownEvent event) {
    // 检测1：边缘误触
    final size = MediaQuery.of(context).size;
    if (event.position.dx < _edgeMargin ||
        event.position.dx > size.width - _edgeMargin ||
        event.position.dy < _edgeMargin ||
        event.position.dy > size.height - _edgeMargin) {
      _logMisTouch('edge_touch', event);
      return;  // 忽略
    }

    // 检测2：大面积接触（掌触）
    // PointerEvent的pressure估算接触面积
    if (event.radiusMajor > 25.0) {  // 半径>25px视为掌触
      _logMisTouch('palm_touch', event);
      return;
    }
  }

  void _handleTap() {
    // 检测3：快速连续触摸
    final now = DateTime.now();
    if (_lastValidTapTime != null &&
        now.difference(_lastValidTapTime!) < _minTapInterval) {
      _logMisTouch('rapid_tap', null);
      return;  // 忽略
    }

    // 检测4：多指触摸（通过GestureDetector的竞争机制处理）
    // 如果有多指同时触摸，GestureDetector通常不会触发onTap

    _lastValidTapTime = now;
    widget.onSafeTap?.call();
  }

  void _logMisTouch(String type, PointerDownEvent? event) {
    // 上报误触事件（脱敏，仅记录类型和位置区域）
    AnalyticsService.log(
      eventName: 'mis_touch_detected',
      params: {
        'type': type,
        'protection_level': widget.protectionLevel.name,
        'page': RouterManager.currentPageName,
      },
    );

    // L3-严格：提供触觉反馈提示用户
    if (widget.protectionLevel == ProtectionLevel.L3) {
      HapticFeedback.selectionClick();
    }
  }
}
```

/// 学习会话退出拦截器
/// 挂载在学习相关页面的WillPopScope和底部导航栏拦截器上
class LearningSessionExitGuard {
  static final LearningSessionExitGuard _instance = LearningSessionExitGuard._();
  factory LearningSessionExitGuard() => _instance;
  LearningSessionExitGuard._();

  final ProtectionDecisionService _decisionService = ProtectionDecisionService();

  /// 判断是否拦截退出行为
  Future<bool> shouldInterceptExit({
    required String userId,
    required String sessionType,  // 'video', 'practice', 'reading'
    required int sessionProgress, // 0-100
  }) async {
    final level = await _decisionService.getUserProtectionLevel(userId);
    
    // L0/L1: 不拦截
    if (level.index <= ProtectionLevel.L1.index) {
      // 但如果进度 > 50%，温和提示
      if (sessionProgress > 50) {
        return _showSoftExitConfirm(
          title: '确定要退出吗？',
          subtitle: '当前进度 ${sessionProgress}%，下次可以继续学习',
        );
      }
      return false;  // 不拦截
    }

    // L2/L3: 弹出确认弹窗
    if (sessionProgress < 20) {
      // 进度很低，直接退出不挽留
      return false;
    }

    final confirmed = await _showExitConfirmDialog(
      level: level,
      sessionType: sessionType,
      progress: sessionProgress,
    );
    return !confirmed;  // confirmed=true → 不拦截(!true=false)
  }

  Future<bool> _showExitConfirmDialog({
    required ProtectionLevel level,
    required String sessionType,
    required int progress,
  }) async {
    final context = RouterManager.currentContext;
    if (context == null) return true;

    final result = await showDialog<bool>(
      context: context,
      barrierDismissible: level == ProtectionLevel.L0,  // L2/L3不可点外部关闭
      builder: (ctx) => _ExitConfirmDialog(
        level: level,
        sessionType: sessionType,
        progress: progress,
      ),
    );
    return result ?? false;
  }
}

## 7. 支付场景特殊保护

### 7.1 强制规则

支付相关操作（R4级）对所有学段均强制家长验证，无例外：

```dart
class PaymentProtectionInterceptor {
  static final PaymentProtectionInterceptor _instance = PaymentProtectionInterceptor._();
  factory PaymentProtectionInterceptor() => _instance;
  PaymentProtectionInterceptor._();

  /// 支付前置检查
  Future<PaymentProtectionResult> preCheck({
    required String userId,
    required String operationId,
    required PaymentInfo paymentInfo,
  }) async {
    // Step 1: 查询用户是否为未成年学生身份
    final userRole = await UserService.getUserRole(userId);
    if (userRole == UserRole.parent || userRole == UserRole.adult) {
      // 成人用户：正常密码/生物识别即可
      return PaymentProtectionResult.proceedWithStandardAuth();
    }

    // Step 2: 学生身份 - 强制家长验证
    final parentBinding = await UserService.getParentBinding(userId);
    if (parentBinding == null) {
      // 未绑定家长，无法验证
      return PaymentProtectionResult.blocked(
        reason: '请先绑定家长账号',
        actionLabel: '去绑定',
        actionRoute: '/parent/bind',
      );
    }

    // Step 3: 发起家长验证
    final verification = await ParentVerificationService().verify(
      operationId: operationId,
      studentId: userId,
      description: _buildPaymentDescription(paymentInfo),
      preferredMethod: ParentAuthMethod.pushNotification,
    );

    if (verification.success) {
      // 记录授权凭证
      await PaymentAuthService.recordAuthorization(
        userId: userId,
        operationId: operationId,
        amount: paymentInfo.amount,
        verificationId: verification.verificationId,
        method: verification.method!,
      );
      return PaymentProtectionResult.proceed();
    } else {
      return PaymentProtectionResult.blocked(
        reason: verification.reason ?? '家长验证未通过',
        actionLabel: '重试',
        actionRoute: null,
      );
    }
  }

  String _buildPaymentDescription(PaymentInfo info) {
    return '${info.productName} ${CurrencyFormatter.format(info.amount)}';
  }
}

## 10. 客户端架构集成

### 10.1 全局拦截中间件

防误触保护作为客户端全局中间件，集成在路由层和操作分发层之间：

```dart
/// 全局操作保护拦截器
/// 所有需要保护的操作通过此入口执行
class ProtectionMiddleware {
  static final ProtectionMiddleware _instance = ProtectionMiddleware._();
  factory ProtectionMiddleware() => _instance;
  ProtectionMiddleware._();

  final OperationRegistry _registry = OperationRegistry();
  final ProtectionDecisionService _decisionService = ProtectionDecisionService();
  final ParentVerificationService _parentService = ParentVerificationService();

  /// 执行受保护的操作
  /// 
  /// 使用方式：
  /// ```dart
  /// await ProtectionMiddleware().execute(
  ///   operationId: 'data.delete_mistake',
  ///   context: context,
  ///   action: () async {
  ///     await MistakeService.delete(mistakeId);
  ///   },
  /// );
  /// ```
  Future<ProtectionResult> execute({
    required String operationId,
    required BuildContext context,
    required Future<void> Function() action,
  }) async {
    // 1. 查询操作元数据
    final meta = _registry.resolve(operationId);
    if (meta == null) {
      // 未注册的操作，直接执行
      await action();
      return ProtectionResult.executed();
    }

    // 2. R0操作直接放行
    if (meta.riskLevel == RiskLevel.R0) {
      await action();
      return ProtectionResult.executed();
    }

    // 3. 获取用户保护等级
    final level = await _decisionService.getCurrentUserProtectionLevel();

    // 4. 判断拦截策略
    final strategy = _resolveStrategy(level, meta.riskLevel, meta.forceParentAuth);

    // 5. 执行拦截策略
    final passed = await _applyStrategy(
      strategy: strategy,
      context: context,
      meta: meta,
      level: level,
    );

    if (!passed) {
      _auditLog(operationId, meta.riskLevel, level, 'cancelled');
      return ProtectionResult.cancelled();
    }

    // 6. 执行实际操作
    _auditLog(operationId, meta.riskLevel, level, 'confirmed');
    await action();
    _auditLog(operationId, meta.riskLevel, level, 'executed');

    return ProtectionResult.executed();
  }

  ProtectionStrategy _resolveStrategy(
    ProtectionLevel level,
    RiskLevel risk,
    bool forceParentAuth,
  ) {
    // 强制家长验证
    if (forceParentAuth) {
      return ProtectionStrategy.parentVerification;
    }

    // 查拦截矩阵
    switch (level) {
      case ProtectionLevel.L0:
        switch (risk) {
          case RiskLevel.R0:
          case RiskLevel.R1:
            return ProtectionStrategy.pass;
          case RiskLevel.R2:
          case RiskLevel.R3:
            return ProtectionStrategy.passwordConfirm;
          case RiskLevel.R4:
            return ProtectionStrategy.parentVerification;
        }

      case ProtectionLevel.L1:
        switch (risk) {
          case RiskLevel.R0:
          case RiskLevel.R1:
            return ProtectionStrategy.pass;
          case RiskLevel.R2:
            return ProtectionStrategy.doubleTapConfirm;
          case RiskLevel.R3:
            return ProtectionStrategy.passwordConfirm;
          case RiskLevel.R4:
            return ProtectionStrategy.parentVerification;
        }

      case ProtectionLevel.L2:
        switch (risk) {
          case RiskLevel.R0:
            return ProtectionStrategy.pass;
          case RiskLevel.R1:
            return ProtectionStrategy.touchDetection;
          case RiskLevel.R2:
            return ProtectionStrategy.dragSliderConfirm;
          case RiskLevel.R3:
          case RiskLevel.R4:
            return ProtectionStrategy.parentVerification;
        }

      case ProtectionLevel.L3:
        switch (risk) {
          case RiskLevel.R0:
            return ProtectionStrategy.pass;
          case RiskLevel.R1:
            return ProtectionStrategy.touchDetectionWithDelay;
          case RiskLevel.R2:
          case RiskLevel.R3:
          case RiskLevel.R4:
            return ProtectionStrategy.parentVerification;
        }
    }
  }

  Future<bool> _applyStrategy({
    required ProtectionStrategy strategy,
    required BuildContext context,
    required OperationMeta meta,
    required ProtectionLevel level,
  }) async {
    switch (strategy) {
      case ProtectionStrategy.pass:
        return true;

      case ProtectionStrategy.touchDetection:
        // SafeTouchDetector已在Widget层处理，此处直接通过
        return true;

      case ProtectionStrategy.touchDetectionWithDelay:
        return true;  // DebounceButton已处理

      case ProtectionStrategy.doubleTapConfirm:
        return await _showDoubleTapConfirm(context, meta);

      case ProtectionStrategy.dragSliderConfirm:
        return await _showDragSliderConfirm(context, meta);

      case ProtectionStrategy.passwordConfirm:
        return await _showPasswordConfirm(context, meta);

      case ProtectionStrategy.parentVerification:
        return await _showParentVerification(context, meta);
    }
  }

  Future<bool> _showDoubleTapConfirm(
    BuildContext context,
    OperationMeta meta,
  ) async {
    return await showDialog<bool>(
      context: context,
      builder: (ctx) => DoubleTapConfirmDialog(
        title: meta.description,
        message: '请再次点击确认按钮',
      ),
    ) ?? false;
  }

  Future<bool> _showDragSliderConfirm(
    BuildContext context,
    OperationMeta meta,
  ) async {
    return await showDialog<bool>(
      context: context,
      barrierDismissible: false,
      builder: (ctx) => AlertDialog(
        content: DragConfirmSlider(
          title: meta.description,
          confirmText: '确认',
          onConfirmed: () => Navigator.of(ctx).pop(true),
        ),
      ),
    ) ?? false;
  }

  Future<bool> _showPasswordConfirm(
    BuildContext context,
    OperationMeta meta,
  ) async {
    final pin = await PinInputDialog.show(context, title: meta.description);
    if (pin == null) return false;

    final valid = await AuthService.verifyPin(pin);
    return valid;
  }

  Future<bool> _showParentVerification(
    BuildContext context,
    OperationMeta meta,
  ) async {
    final result = await ParentVerificationService().verify(
      operationId: meta.operationId,
      studentId: CurrentUser.id,
      description: meta.description,
      preferredMethod: ParentAuthMethod.pushNotification,
    );

    if (!result.success && result.fallbackMethod != null) {
      // 尝试降级验证方式
      return await ParentVerificationService().verify(
        operationId: meta.operationId,
        studentId: CurrentUser.id,
        description: meta.description,
        preferredMethod: result.fallbackMethod!,
      ).then((r) => r.success);
    }

    return result.success;
  }

  void _auditLog(
    String operationId,
    RiskLevel risk,
    ProtectionLevel level,
    String action,
  ) {
    ProtectionAuditLogger.log(
      operationId: operationId,
      riskLevel: risk,
      protectionLevel: level,
      action: action,
    );
  }
}

enum ProtectionStrategy {
  pass,
  touchDetection,
  touchDetectionWithDelay,
  doubleTapConfirm,
  dragSliderConfirm,
  passwordConfirm,
  parentVerification,
}

class ProtectionResult {
  final bool executed;
  final bool cancelled;
  final String? reason;

  ProtectionResult._({this.executed = false, this.cancelled = false, this.reason});

  factory ProtectionResult.executed() => ProtectionResult._(executed: true);
  factory ProtectionResult.cancelled({String? reason}) => 
      ProtectionResult._(cancelled: true, reason: reason);
}

## 12. 错误处理

### 12.1 错误码定义

| 错误码 | 说明 | 处理策略 |
| --- | --- | --- |
| `PROTECTION_001` | 操作未注册 | 记录日志，默认放行，告警通知开发团队 |
| `PROTECTION_002` | 保护等级获取失败（网络异常） | 使用本地缓存等级；无缓存时按 L1 处理 |
| `PROTECTION_003` | 家长验证推送发送失败 | 降级到PIN码验证 |
| `PROTECTION_004` | 家长验证轮询超时 | 提示"未收到家长确认，请稍后重试或联系家长" |
| `PROTECTION_005` | 家长PIN码未设置 | 引导设置PIN，或降级到推送验证 |
| `PROTECTION_006` | 家长PIN码连续错误(>3次) | 锁定PIN验证15分钟，引导使用推送验证 |
| `PROTECTION_007` | 生物识别不可用 | 降级到PIN或推送验证 |
| `PROTECTION_008` | 未绑定家长账号 | 引导绑定家长账号 |
| `PROTECTION_009` | 审计日志写入失败 | 本地队列重试，不影响主流程 |

### 12.2 降级策略

```dart
class ProtectionErrorHandler {
  /// 保护服务异常时的降级处理
  static Future<bool> onProtectionServiceError(
    String operationId,
    ProtectionLevel fallbackLevel,
    dynamic error,
  ) async {
    // 关键操作（R4）：宁可拦截不可放行
    final meta = OperationRegistry.resolve(operationId);
    if (meta?.riskLevel == RiskLevel.R4) {
      return false;  // 拦截操作
    }

    // 非关键操作：降级到最基本的确认框
    if (fallbackLevel.index >= ProtectionLevel.L1.index) {
      // 有网络问题时，使用本地缓存的保护配置
      return true;  // 放行，稍后补记审计
    }

    return true;
  }
}

## 13. 性能考虑

### 13.1 本地决策优先

保护等级的决策优先使用本地缓存，避免每次操作都发起网络请求：

```dart
class ProtectionDecisionService {
  final ProtectionConfigCache _cache = ProtectionConfigCache();

  Future<ProtectionLevel> getCurrentUserProtectionLevel() async {
    // 1. 先读内存缓存
    final cached = _cache.get(CurrentUser.id);
    if (cached != null && !cached.isExpired) {
      return cached.level;
    }

    // 2. 读本地持久化缓存
    final local = await _cache.readFromDisk(CurrentUser.id);
    if (local != null) {
      _cache.set(CurrentUser.id, local);
      return local.level;
    }

    // 3. 根据本地用户信息推导
    final grade = CurrentUser.grade;
    final derived = _deriveFromGrade(grade);
    _cache.set(CurrentUser.id, derived);
    return derived.level;
  }

  ProtectionLevel _deriveFromGrade(String grade) {
    if (grade.startsWith('kindergarten')) return ProtectionLevel.L3;
    if (grade.startsWith('g1') || grade.startsWith('g2') || grade.startsWith('g3')) {
      return ProtectionLevel.L2;
    }
    if (grade.startsWith('g4') || grade.startsWith('g5') || grade.startsWith('g6')) {
      return ProtectionLevel.L1;
    }
    return ProtectionLevel.L0;
  }
}
```

## 14. 安全考虑

### 14.1 PIN码安全

- PIN码存储：SHA-256(PIN + per-user-salt)，永不明文存储
- PIN码传输：TLS加密通道，前端公钥加密后传输
- 错误锁定：连续错误3次锁定PIN验证15分钟，连续错误5次锁定1小时
- PIN码修改：需要家长身份验证（推送或生物识别）

### 14.2 防绕过

```dart
/// 关键操作的二次校验
/// 防止客户端被篡改后绕过保护
class ServerSideVerification {
  /// 支付类操作：服务端独立校验家长授权
  static Future<bool> verifyPaymentAuthorization({
    required String orderId,
    required String studentId,
  }) async {
    // 服务端检查该订单是否有有效的家长授权记录
    final response = await ApiClient.post(
      '/api/v1/payment/verify-authorization',
      data: {
        'order_id': orderId,
        'student_id': studentId,
      },
    );
    return response.data['authorized'] == true;
  }
}
```

> 服务端必须独立验证家长授权，不依赖客户端传参。即使客户端被篡改绕过了保护，服务端也会拦截未授权的付费操作。

### 14.3 审计日志防篡改

客户端审计日志定期同步到服务端，服务端保留不可篡改的操作审计记录，用于事后追查。
