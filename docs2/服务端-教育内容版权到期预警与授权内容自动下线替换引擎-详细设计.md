# 教育内容版权到期预警与授权内容自动下线替换引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责管理 PrimeTop 平台中所有第三方教育内容（教材章节、题库资源、音视频课程、图片素材等）的版权授权期限，在版权即将到期时触发多级预警，到期后执行自动化内容下线流程，并智能推荐替代内容以保障用户学习连续性。

### 1.2 核心目标

| 目标 | 说明 |
| --- | --- |
| **版权合规保障** | 确保平台不会在授权过期后继续向用户提供受版权保护的内容，避免法律风险 |
| **业务影响最小化** | 通过提前预警和替代内容预填充，使学生端学习体验不受内容下线影响 |
| **运营效率提升** | 将版权到期处理从人工流程升级为自动化工作流，减少人工遗漏和操作成本 |
| **学习路径连续性** | 内容下线时自动调整学生学习路径和错题本引用，保持学习闭环不中断 |

### 1.3 适用范围

- 所有通过版权采购、授权引入的第三方教育内容
- 供应商提供的试用内容（有时效限制）
- 教材版本更新导致旧版内容需要下线的场景
- 运营活动中引入的限时免费内容

### 2.2 核心模块

| 模块 | 职责 |
| --- | --- |
| **ContentLicenseService** | 管理所有内容的授权记录，包括授权范围、期限、供应商、合同编号 |
| **ExpirationAlertScheduler** | 定时扫描即将到期的授权记录，按时间梯度生成预警任务 |
| **TakedownExecutionEngine** | 执行内容下线操作，包括 CDN 缓存失效、搜索索引移除、接口屏蔽 |
| **ReplacementRecommender** | 为即将下线的内容推荐替代内容，支持自动替换和人工审核两种模式 |
| **LearningPathRepairService** | 修复因内容下线受到影响的学习路径、错题本引用、收藏记录 |
| **NotificationDispatcher** | 向运营人员、教师、学生、家长发送版权到期相关通知 |

## 3. 数据结构定义

### 3.1 内容授权记录表 `content_license`

```sql
CREATE TABLE content_license (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    license_code    VARCHAR(64) NOT NULL UNIQUE COMMENT '授权编号',
    content_id      BIGINT NOT NULL COMMENT '关联内容ID',
    content_type    VARCHAR(32) NOT NULL COMMENT '内容类型: CHAPTER/QUESTION/VIDEO/AUDIO/IMAGE/DOCUMENT',
    supplier_id     BIGINT NOT NULL COMMENT '供应商ID',
    contract_id     VARCHAR(64) COMMENT '关联合同编号',
    
    -- 授权范围
    scope_type      VARCHAR(32) NOT NULL DEFAULT 'FULL' COMMENT '授权范围: FULL/PARTIAL/TRIAL',
    scope_subjects  JSON COMMENT '限定学科列表(部分授权时使用)',
    scope_grades    JSON COMMENT '限定年级列表',
    scope_regions   JSON COMMENT '限定地区列表',
    
    -- 授权期限
    start_date      DATE NOT NULL COMMENT '授权开始日期',
    end_date        DATE NOT NULL COMMENT '授权结束日期',
    grace_period_days INT DEFAULT 0 COMMENT '宽限天数(到期后仍可使用的天数)',
    is_permanent    BOOLEAN DEFAULT FALSE COMMENT '是否永久授权',
    
    -- 授权状态
    status          VARCHAR(20) NOT NULL DEFAULT 'ACTIVE' COMMENT '状态: ACTIVE/EXPIRING/EXPIRED/REVOKED/RENEWED',
    
    -- 替换配置
    replacement_strategy VARCHAR(32) DEFAULT 'AUTO' COMMENT '替换策略: AUTO/MANUAL/NONE',
    replacement_content_id BIGINT COMMENT '指定替换内容ID',
    
    -- 元数据
    contract_url    VARCHAR(512) COMMENT '合同文件URL',
    remark          TEXT COMMENT '备注',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_end_date (end_date),
    INDEX idx_status_end (status, end_date),
    INDEX idx_content (content_id, content_type),
    INDEX idx_supplier (supplier_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容版权授权记录表';
```

```sql

    alert_targets   JSON NOT NULL COMMENT '通知对象列表: ["OPS","CONTENT_OWNER","SUPPLIER_MANAGER"]',
    alert_channels  JSON NOT NULL COMMENT '通知渠道: ["EMAIL","SMS","WORKBENCH","WEBHOOK"]',
    alert_context   JSON COMMENT '附加上下文数据',
    
    -- 处理结果
    result_summary  TEXT COMMENT '执行结果摘要',
    error_detail    TEXT COMMENT '错误详情(失败时)',

    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_scheduled (scheduled_at, status),
    INDEX idx_license (license_id),
    UNIQUE KEY uk_license_level (license_id, alert_level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='版权预警任务表';
```

### 3.5 核心枚举定义

```java
public enum ContentType {
    CHAPTER,        // 教材章节
    QUESTION,       // 题目
    VIDEO,          // 视频课程
    AUDIO,          // 音频资源
    IMAGE,          // 图片素材
    DOCUMENT,       // 文档资源
    EXERCISE_SET,   // 练习集
    KNOWLEDGE_POINT // 知识点讲解
}

public enum LicenseStatus {
    ACTIVE,         // 授权有效
    EXPIRING,       // 即将到期（进入预警窗口）
    EXPIRED,        // 已到期（宽限期内）
    TERMINATED,     // 已终止（宽限期结束，内容已下线）
    REVOKED,        // 被撤销（供应商提前终止）
    RENEWDED        // 已续期
}

public enum AlertLevel {
    L1_ADVANCE_90,    // 90天预警
    L2_ADVANCE_60,    // 60天预警
    L3_ADVANCE_30,    // 30天预警
    L4_ADVANCE_7,     // 7天紧急预警
    L5_EXPIRED,       // 到期当天
    L6_GRACE_END      // 宽限期结束
}

public enum ReplacementStrategy {
    AUTO,             // 自动匹配替代内容
    MANUAL,           // 人工指定替代内容
    SUPPLIER_PROVIDED,// 供应商提供替代内容
    NONE              // 不需要替代（下线即可）
}

public enum TakedownType {
    LICENSE_EXPIRED,    // 授权到期
    LICENSE_REVOKED,    // 授权被撤销
    MANUAL_OPERATION,   // 人工下线
    CONTENT_UPGRADED,   // 内容升级替换
    LEGAL_COMPLIANCE    // 法规合规要求
}
```

## 5. 核心业务流程

### 5.1 预警流程状态机

```text
                    ┌──────────────────────────────────────────────────┐
```

```java
/**
 * 版权到期预警调度引擎
 * 每日凌晨 02:00 执行，扫描所有即将到期的授权记录并生成/执行预警任务
 */
@Component
@Slf4j
public class ExpirationAlertScheduler {

    @Resource
    private ContentLicenseMapper licenseMapper;
    @Resource
    private LicenseAlertTaskMapper alertTaskMapper;
    @Resource
    private NotificationDispatcher notificationDispatcher;
    @Resource
    private ReplacementRecommender replacementRecommender;

    // 预警级别配置: 天数阈值 -> 级别
    private static final int[][] ALERT_THRESHOLDS = {
        {90, 60, 30, 7, 0},           // 提前天数
        // 对应级别
    };

    /**
     * 定时扫描调度主入口
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void scanAndScheduleAlerts() {
        LocalDate today = LocalDate.now();

        // 1. 查询所有 ACTIVE 且在 90 天内到期的非永久授权
        List<ContentLicense> expiringLicenses = licenseMapper.selectExpiringWithin(today, 90);

        for (ContentLicense license : expiringLicenses) {
            try {
                processLicenseAlert(license, today);
            } catch (Exception e) {
                log.error("处理授权预警失败 licenseId={}", license.getId(), e);
                // 记录失败，不影响其他授权的处理
                alertTaskMapper.insertFailedRecord(license.getId(), e.getMessage());
            }
        }

        // 2. 处理已到期但仍在宽限期的授权
        List<ContentLicense> gracePeriodLicenses = licenseMapper.selectInGracePeriod(today);
        for (ContentLicense license : gracePeriodLicenses) {
            processGracePeriodAlert(license, today);
        }

        // 3. 处理宽限期结束的授权 -> 触发强制下线
        List<ContentLicense> graceEndedLicenses = licenseMapper.selectGracePeriodEnded(today);
        for (ContentLicense license : graceEndedLicenses) {
            triggerForcedTakedown(license);
        }
    }

    /**
     * 处理单个授权的预警逻辑
     */
    private void processLicenseAlert(ContentLicense license, LocalDate today) {
        int daysRemaining = (int) ChronoUnit.DAYS.between(today, license.getEndDate());
        AlertLevel targetLevel = resolveAlertLevel(daysRemaining);

        if (targetLevel == null) {
            return; // 尚未进入预警窗口
        }

        // 更新授权状态为 EXPIRING
        if (license.getStatus() != LicenseStatus.EXPIRING) {
            licenseMapper.updateStatus(license.getId(), LicenseStatus.EXPIRING.name());
        }

        // 检查该级别预警是否已生成
        LicenseAlertTask existingTask = alertTaskMapper.selectByLicenseAndLevel(
            license.getId(), targetLevel.name()
        );
        if (existingTask != null && existingTask.getStatus() == TaskStatus.COMPLETED) {
            return; // 已执行过
        }

        // 创建并执行预警任务
        LicenseAlertTask task = buildAlertTask(license, targetLevel, daysRemaining);
        alertTaskMapper.insert(task);

        executeAlertTask(task, license);
    }

    /**
     * 根据剩余天数确定预警级别
     */
    private AlertLevel resolveAlertLevel(int daysRemaining) {
        if (daysRemaining <= 0) return AlertLevel.L5_EXPIRED;
        if (daysRemaining <= 7) return AlertLevel.L4_ADVANCE_7;
        if (daysRemaining <= 30) return AlertLevel.L3_ADVANCE_30;
        if (daysRemaining <= 60) return AlertLevel.L2_ADVANCE_60;
        if (daysRemaining <= 90) return AlertLevel.L1_ADVANCE_90;
        return null;
    }

    /**
     * 执行预警任务：发送通知 + 触发自动动作
     */
    private void executeAlertTask(LicenseAlertTask task, ContentLicense license) {
        try {
            task.markProcessing();
            alertTaskMapper.updateStatus(task);

            // 1. 构建预警上下文
            AlertContext context = AlertContext.builder()
                .licenseCode(license.getLicenseCode())
                .contentTitle(getContentTitle(license))
                .supplierName(getSupplierName(license.getSupplierId()))
                .endDate(license.getEndDate())
                .daysRemaining(task.getDaysRemaining())
                .affectedUserCount(countAffectedUsers(license))
                .gracePeriodDays(license.getGracePeriodDays())
                .build();

            // 2. 发送多渠道通知
            notificationDispatcher.dispatch(task.getAlertTargets(), task.getAlertChannels(), context);

            // 3. L3(30天)级别触发自动替代内容匹配
            if (task.getAlertLevel() == AlertLevel.L3_ADVANCE_30
                    && license.getReplacementStrategy() == ReplacementStrategy.AUTO) {
                replacementRecommender.preGenerateReplacements(license);
            }

            // 4. L4(7天)级别触发替代内容预部署
            if (task.getAlertLevel() == AlertLevel.L4_ADVANCE_7) {
                replacementRecommender.preDeployReplacement(license);
            }

            task.markCompleted();
            alertTaskMapper.updateStatus(task);

        } catch (Exception e) {
            task.markFailed(e.getMessage());
            alertTaskMapper.updateStatus(task);
            log.error("预警任务执行失败 taskId={} licenseId={}", task.getId(), license.getId(), e);
        }
    }
}
```

### 6.2 替代内容推荐服务

```java
/**
 * 替代内容推荐服务
 * 基于知识点覆盖、难度匹配、格式兼容、学段适配等多维度计算相似度
 */
@Service
@Slf4j
public class ReplacementRecommender {

    @Resource
    private ContentMetadataService contentMetadataService;
    @Resource
    private KnowledgePointService knowledgePointService;
    @Resource
    private ContentLicenseMapper licenseMapper;
    @Resource
    private ContentReplacementMappingMapper mappingMapper;
    @Resource
    private TakedownExecutionEngine takedownEngine;

    // 相似度权重配置
    private static final double W_KNOWLEDGE_POINTS = 0.45;
    private static final double W_DIFFICULTY = 0.20;
    private static final double W_FORMAT = 0.15;
    private static final double W_TARGET_GRADE = 0.10;
    private static final double W_DURATION = 0.10;

    /**
     * 为即将下线的内容推荐替代内容
     * @param originalContentId 原内容ID
     * @param originalContentType 原内容类型
     * @param limit 返回数量
     * @return 按匹配度排序的推荐列表
     */
    public List<ReplacementRecommendation> recommendReplacements(
            Long originalContentId, String originalContentType, int limit) {

        // 1. 获取原内容元数据
        ContentMetadata original = contentMetadataService.getMetadata(
            originalContentId, originalContentType
        );
        if (original == null) {
            throw new BusinessException("CONTENT_NOT_FOUND", "原内容不存在");
        }

        // 2. 基于知识点检索候选内容
        List<Long> candidateIds = contentMetadataService.searchByKnowledgePoints(
            original.getKnowledgePointIds(),
            original.getSubject(),
            original.getTargetGrades(),
            originalContentType,
            limit * 3 // 多取3倍候选以提高匹配质量
        );

        // 3. 过滤掉版权状态不可用的候选
        candidateIds = filterByLicenseStatus(candidateIds);

        // 4. 排除原内容自身
        candidateIds.remove(originalContentId);

        // 5. 多维度计算匹配分数
        List<ReplacementRecommendation> recommendations = new ArrayList<>();
        for (Long candidateId : candidateIds) {
            ContentMetadata candidate = contentMetadataService.getMetadata(
                candidateId, originalContentType
            );
            MatchResult match = calculateMatchScore(original, candidate);
            if (match.getOverallScore() >= 60.0) { // 最低匹配阈值
                recommendations.add(buildRecommendation(candidate, match));
            }
        }

        // 6. 按分数排序并返回 top N
        recommendations.sort(Comparator.comparingDouble(
            (ReplacementRecommendation r) -> r.getMatchScore()
        ).reversed());

        return recommendations.stream().limit(limit).collect(Collectors.toList());
    }

    /**
     * 多维度相似度计算
     */
    private MatchResult calculateMatchScore(ContentMetadata original, ContentMetadata candidate) {
        // 知识点覆盖度 (Jaccard系数 × 权重)
        Set<String> originalKPs = new HashSet<>(original.getKnowledgePointIds());
        Set<String> candidateKPs = new HashSet<>(candidate.getKnowledgePointIds());
        double kpScore = jaccardSimilarity(originalKPs, candidateKPs) * 100;

        // 难度匹配度
        int diffDiff = Math.abs(original.getDifficulty() - candidate.getDifficulty());
        double difficultyScore = Math.max(0, 100 - diffDiff * 20);

        // 格式兼容度
        double formatScore = calculateFormatCompatibility(original, candidate);

        // 目标年级匹配度
        double gradeScore = calculateGradeOverlap(original.getTargetGrades(),
                                                   candidate.getTargetGrades());

        // 时长/篇幅接近度
        double durationScore = calculateDurationSimilarity(
            original.getEstimatedDuration(), candidate.getEstimatedDuration()
        );

        // 综合加权得分
        double overallScore = kpScore * W_KNOWLEDGE_POINTS
                            + difficultyScore * W_DIFFICULTY
                            + formatScore * W_FORMAT
                            + gradeScore * W_TARGET_GRADE
                            + durationScore * W_DURATION;

        return MatchResult.builder()
            .overallScore(Math.round(overallScore * 10) / 10.0)
            .knowledgePointScore(kpScore)
            .difficultyScore(difficultyScore)
            .formatScore(formatScore)
            .gradeScore(gradeScore)
            .durationScore(durationScore)
            .build();
    }

    /**
     * 预生成替代映射（预警阶段调用）
     * 自动匹配并存储最佳替代内容，供下线时直接使用
     */
    @Transactional
    public void preGenerateReplacements(ContentLicense license) {
        List<ReplacementRecommendation> recommendations = recommendReplacements(
            license.getContentId(), license.getContentType(), 1
        );

        if (recommendations.isEmpty()) {
            log.warn("未找到合适的替代内容 licenseId={} contentId={}",
                license.getId(), license.getContentId());
            // 标记为需要人工处理
            licenseMapper.updateReplacementStatus(license.getId(), "MANUAL_REQUIRED");
            return;
        }

        ReplacementRecommendation best = recommendations.get(0);
        ContentReplacementMapping mapping = new ContentReplacementMapping();
        mapping.setOriginalContentId(license.getContentId());
        mapping.setOriginalContentType(license.getContentType());
        mapping.setReplacementContentId(best.getContentId());
        mapping.setReplacementContentType(license.getContentType());
        mapping.setMatchScore(best.getMatchScore());
        mapping.setMatchDimensions(best.getMatchDimensions());
        mapping.setMatchMethod("AUTO_SEMANTIC");
        mapping.setStatus("ACTIVE");
        mapping.setEffectiveFrom(license.getEndDate().atStartOfDay());
        mapping.setReviewScore(best.getMatchScore() >= 85 ? "AUTO_APPROVED" : "PENDING_REVIEW");

        mappingMapper.insert(mapping);
        log.info("预生成替代内容映射 licenseId={} original={} replacement={} score={}",
            license.getId(), license.getContentId(), best.getContentId(), best.getMatchScore());
    }

    // ---- 工具方法 ----

    private <T> double jaccardSimilarity(Set<T> set1, Set<T> set2) {
        if (set1.isEmpty() && set2.isEmpty()) return 1.0;
        Set<T> intersection = new HashSet<>(set1);
        intersection.retainAll(set2);
        Set<T> union = new HashSet<>(set1);
        union.addAll(set2);
        return (double) intersection.size() / union.size();
    }
}
```

### 6.3 下线执行引擎

```java
/**
 * 内容下线执行引擎
 * 负责协调各子系统完成内容下线的完整流程
 */
@Service
@Slf4j
public class TakedownExecutionEngine {

    @Resource
    private ContentLicenseMapper licenseMapper;
    @Resource
    private ContentServiceClient contentServiceClient;
    @Resource
    private SearchServiceClient searchServiceClient;
    @Resource
    private CdnServiceClient cdnServiceClient;
    @Resource
    private LearningPathServiceClient learningPathServiceClient;
    @Resource
    private MistakeServiceClient mistakeServiceClient;
    @Resource
    private FavoriteServiceClient favoriteServiceClient;
    @Resource
    private NotificationServiceClient notificationServiceClient;
    @Resource
    private TakedownRecordMapper takedownRecordMapper;
    @Resource
    private AuditLogService auditLogService;

    // 每步最大重试次数
    private static final int MAX_RETRY = 3;
    // 每步超时（秒）
    private static final int STEP_TIMEOUT_SECONDS = 60;

    /**
     * 执行内容下线完整流程
     */
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public TakedownResult executeTakedown(Long licenseId, TakedownRequest request) {
        // 1. 预检查
        ContentLicense license = licenseMapper.selectById(licenseId);
        validatePreconditions(license, request);

        // 2. 创建下线记录
        ContentTakedownRecord record = createTakedownRecord(license, request);

        try {
            // 3. 收集影响范围快照 + 回滚数据
            ImpactSnapshot snapshot = collectImpactSnapshot(license);
            record.setAffectedUserCount(snapshot.getAffectedUsers());
            record.setAffectedPaths(snapshot.getAffectedPaths());
            record.setAffectedMistakes(snapshot.getAffectedMistakes());
            record.setAffectedFavorites(snapshot.getAffectedFavorites());
            record.setRollbackData(snapshot.getRollbackData());
            takedownRecordMapper.updateById(record);

            // 4. 执行各步骤
            executeTakedownSteps(license, record, request);

            // 5. 更新授权状态
            licenseMapper.updateStatus(license.getId(), LicenseStatus.TERMINATED.name());

            record.markCompleted();
            takedownRecordMapper.updateById(record);

            auditLogService.log("CONTENT_TAKEDOWN", request.getTriggeredBy(),
                String.format("内容下线完成: contentId=%d, type=%s, affectedUsers=%d",
                    license.getContentId(), license.getContentType(),
                    snapshot.getAffectedUsers()));

            return TakedownResult.success(record, snapshot);

        } catch (Exception e) {
            log.error("内容下线失败 licenseId={} recordId={}", licenseId, record.getId(), e);
            record.markFailed(e.getMessage());
            takedownRecordMapper.updateById(record);
            throw new BusinessException("TAKEDOWN_FAILED", "内容下线执行失败: " + e.getMessage(), e);
        }
    }

    /**
     * 按顺序执行下线各步骤
     */
    private void executeTakedownSteps(ContentLicense license, ContentTakedownRecord record,
                                       TakedownRequest request) {
        List<TakedownStepResult> stepResults = new ArrayList<>();

        // Step 1: CDN缓存失效
        stepResults.add(executeStep("CDN_CACHE_INVALIDATE", () -> {
            cdnServiceClient.invalidateCache(license.getContentId(), license.getContentType());
            return null;
        }));

        // Step 2: 搜索索引移除
        stepResults.add(executeStep("SEARCH_INDEX_REMOVE", () -> {
            searchServiceClient.removeFromIndex(license.getContentId());
            return null;
        }));

        // Step 3: 内容可见性下线
        stepResults.add(executeStep("CONTENT_VISIBILITY_OFFLINE", () -> {
            contentServiceClient.updateVisibility(license.getContentId(),
                ContentVisibility.OFFLINE);
            return null;
        }));

        // Step 4a: 学习路径修复
        stepResults.add(executeStep("LEARNING_PATH_REPAIR", () -> {
            Long replacementId = record.getReplacementContentId();
            int repaired = learningPathServiceClient.replaceContentInPaths(
                license.getContentId(), replacementId
            );
            return Map.of("repairedPaths", repaired);
        }));

        // Step 4b: 错题引用更新
        stepResults.add(executeStep("MISTAKE_REFERENCE_UPDATE", () -> {
            int updated = mistakeServiceClient.updateContentReferences(
                license.getContentId(),
                record.getReplacementContentId()
            );
            return Map.of("updatedRecords", updated);
        }));

        // Step 4c: 收藏引用更新
        stepResults.add(executeStep("FAVORITE_REFERENCE_UPDATE", () -> {
            int updated = favoriteServiceClient.updateContentReferences(
                license.getContentId(),
                record.getReplacementContentId()
            );
            return Map.of("updatedRecords", updated);
        }));

        // Step 5: 替代内容部署
        if (record.getReplacementContentId() != null) {
            stepResults.add(executeStep("REPLACEMENT_DEPLOY", () -> {
                contentServiceClient.deployReplacement(
                    license.getContentId(),
                    record.getReplacementContentId()
                );
                return null;
            }));
        }

        // Step 6: 用户通知
        if (request.isNotifyUsers()) {
            stepResults.add(executeStep("USER_NOTIFICATION", () -> {
                int notified = notificationServiceClient.sendContentReplacementNotice(
                    license.getContentId(),
                    record.getReplacementContentId(),
                    record.getAffectedUserCount()
                );
                return Map.of("notifiedUsers", notified);
            }));
        }

        // 记录各步骤执行详情
        record.setSteps(stepResults.stream()
            .map(TakedownStepResult::toJson)
            .collect(Collectors.toList()));
    }

    /**
     * 通用步骤执行器（含重试和超时）
     */
    private TakedownStepResult executeStep(String stepName, Supplier<Map<String, Object>> action) {
        long startTime = System.currentTimeMillis();
        Exception lastError = null;

        for (int attempt = 1; attempt <= MAX_RETRY; attempt++) {
            try {
                Map<String, Object> result = action.get();
                long duration = (System.currentTimeMillis() - startTime) / 1000;
                return TakedownStepResult.success(stepName, duration, result);
            } catch (Exception e) {
                lastError = e;
                log.warn("下线步骤失败 step={} attempt={}/{}", stepName, attempt, MAX_RETRY, e);
                if (attempt < MAX_RETRY) {
                    Thread.sleep(1000L * attempt); // 指数退避
                }
            }
        }

        long duration = (System.currentTimeMillis() - startTime) / 1000;
        return TakedownStepResult.failed(stepName, duration, lastError.getMessage());
    }

    /**
     * 回滚下线操作（7天窗口期内可用）
     */
    @Transactional
    public void rollbackTakedown(Long takedownId) {
        ContentTakedownRecord record = takedownRecordMapper.selectById(takedownId);
        if (!record.isRollbackAvailable()) {
            throw new BusinessException("ROLLBACK_UNAVAILABLE", "回滚窗口已过期");
        }
        if (record.getStatus() != TakedownStatus.COMPLETED) {
            throw new BusinessException("ROLLBACK_INVALID_STATE", "仅已完成的状态可回滚");
        }

        // 恢复内容可见性
        contentServiceClient.updateVisibility(record.getContentId(), ContentVisibility.ONLINE);

        // 恢复搜索索引
        searchServiceClient.reindex(record.getContentId());

        // 恢复CDN缓存
        cdnServiceClient.refreshCache(record.getContentId());

        // 恢复学习路径/错题/收藏引用
        if (record.getRollbackData() != null) {
            learningPathServiceClient.restoreFromSnapshot(record.getRollbackData());
            mistakeServiceClient.restoreFromSnapshot(record.getRollbackData());
            favoriteServiceClient.restoreFromSnapshot(record.getRollbackData());
        }

        // 更新记录
        record.setStatus(TakedownStatus.ROLLED_BACK);
        takedownRecordMapper.updateById(record);

        // 恢复授权状态
        licenseMapper.updateStatus(record.getLicenseId(), LicenseStatus.EXPIRED.name());

        log.info("内容下线已回滚 takedownId={} contentId={}", takedownId, record.getContentId());
    }
```

## 7. 学习路径修复策略

### 7.1 修复决策矩阵

| 场景 | 替代内容可用 | 替代内容不可用 |
| --- | --- | --- |
| **系统学习路径** | 自动替换节点内容，保持路径结构不变 | 移除该节点，后续节点前移；路径末尾补充新内容 |
| **个人学习路径** | 自动替换 + 推送通知告知用户 | 标记为"内容暂不可用"，建议用户跳过或选择同类内容 |
| **AI推荐路径** | 替换并重新计算路径难度梯度 | 触发路径重规划，生成替代路径段 |
| **教师布置路径** | 替换后通知教师确认 | 移除节点并通知教师重新布置 |

### 7.2 路径修复实现

```java
/**
 * 学习路径修复服务
 */
@Service
public class LearningPathRepairService {

    @Resource
    private LearningPathMapper pathMapper;
    @Resource
    private PathNodeMapper nodeMapper;
    @Resource
    private ContentReplacementMappingMapper replacementMappingMapper;
    @Resource
    private NotificationService notificationService;

    /**
     * 在所有学习路径中替换指定内容
     * @return 修复的路径数量
     */
    @Transactional
    public int replaceContentInPaths(Long originalContentId, Long replacementContentId) {
        // 1. 查找所有包含该内容节点的路径
        List<PathNode> affectedNodes = nodeMapper.selectByContentId(originalContentId);
        if (affectedNodes.isEmpty()) {
            return 0;
        }

        int repairedCount = 0;
        Map<Long, PathRepairType> pathRepairMap = new HashMap<>();

        for (PathNode node : affectedNodes) {
            if (replacementContentId != null) {
                // 场景A: 有替代内容 → 直接替换节点内容引用
                node.setContentId(replacementContentId);
                node.setReplacedFrom(originalContentId);
                node.setReplacedAt(LocalDateTime.now());
                nodeMapper.updateById(node);
                pathRepairMap.put(node.getPathId(), PathRepairType.CONTENT_REPLACED);
            } else {
                // 场景B: 无替代内容 → 根据路径类型采取不同策略
                LearningPath path = pathMapper.selectById(node.getPathId());
                switch (path.getPathType()) {
                    case SYSTEM:
                        // 系统路径: 尝试从候选池选择同知识点内容
                        Long fallbackContentId = findFallbackContent(node);
                        if (fallbackContentId != null) {
                            node.setContentId(fallbackContentId);
                            nodeMapper.updateById(node);
                            pathRepairMap.put(path.getId(), PathRepairType.FALLBACK_USED);
                        } else {
                            // 无法找到替代，移除节点并调整路径序号
                            removeNodeAndReindex(path, node);
                            pathRepairMap.put(path.getId(), PathRepairType.NODE_REMOVED);
                        }
                        break;

                    case PERSONAL:
                        // 个人路径: 标记为不可用，用户自行决定跳过
                        node.setStatus(NodeStatus.CONTENT_UNAVAILABLE);
                        nodeMapper.updateById(node);
                        pathRepairMap.put(path.getId(), PathRepairType.MARKED_UNAVAILABLE);
                        break;

                    case AI_RECOMMENDED:
                        // AI推荐路径: 触发局部重规划
                        triggerPathReplanning(path, node);
                        pathRepairMap.put(path.getId(), PathRepairType.REPLANNED);
                        break;

                    case TEACHER_ASSIGNED:
                        // 教师布置路径: 移除节点 + 通知教师
                        removeNodeAndReindex(path, node);
                        notificationService.notifyTeacherContentRemoved(
                            path.getCreatorId(), originalContentId, path.getId()
                        );
                        pathRepairMap.put(path.getId(), PathRepairType.TEACHER_NOTIFIED);
                        break;
                }
            }
            repairedCount++;
        }

        // 记录修复审计日志
        auditLogService.logPathRepairs(originalContentId, replacementContentId, pathRepairMap);

        return repairedCount;
    }

    /**
     * 查找同知识点的兜底内容
     */
    private Long findFallbackContent(PathNode node) {
        // 获取原节点的知识点标签
        List<String> knowledgePointIds = node.getKnowledgePointIds();
        if (knowledgePointIds == null || knowledgePointIds.isEmpty()) {
            return null;
        }

        // 在内容池中查找: 同知识点 + 版权有效 + 未被占用
        return contentService.findAvailableContentByKnowledgePoints(
            knowledgePointIds,
            node.getSubject(),
            node.getDifficulty(),
            node.getContentType()
        );
    }
}
```

### 9.1 异常分类与处理策略

| 异常场景 | 错误码 | 处理策略 |
| --- | --- | --- |
| CDN缓存失效超时 | `CDN_INVALIDATE_TIMEOUT` | 重试3次，失败后降级为标记"缓存延迟"，异步重试 |
| 搜索索引移除失败 | `SEARCH_INDEX_REMOVE_FAILED` | 重试3次，失败后通过补偿任务异步清理 |
| 学习路径修复部分失败 | `PATH_REPAIR_PARTIAL` | 记录失败的pathId列表，触发补偿任务，不影响整体流程 |

| 授权记录数据不一致 | `LICENSE_DATA_INCONSISTENT` | 中止下线流程，告警通知管理员人工排查 |
| 宽限期结束但续期进行中 | `RENEWAL_IN_PROGRESS` | 暂停下线流程，等待续期确认结果（最多等待48小时） |
| 并发下线同一内容 | `CONCURRENT_TAKEDOWN` | 分布式锁保护，第二个请求直接返回"正在处理中" |
| 回滚窗口已过期 | `ROLLBACK_WINDOW_EXPIRED` | 返回不可回滚错误，引导人工恢复 |

### 9.2 补偿任务机制

```java
/**
 * 下线补偿任务
 * 处理下线过程中部分失败的步骤
 */
@Component
@Slf4j
public class TakedownCompensationJob {

    /**
     * 每小时扫描部分失败的下线记录，执行补偿
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void compensateFailedSteps() {
        List<ContentTakedownRecord> partialFailures =
            takedownRecordMapper.selectByStatus(TakedownStatus.PARTIAL_FAILURE);

        for (ContentTakedownRecord record : partialFailures) {
            List<TakedownStepResult> failedSteps = record.getSteps().stream()
                .filter(step -> step.getStatus() == StepStatus.FAILED)
                .collect(Collectors.toList());

            for (TakedownStepResult step : failedSteps) {
                if (step.getRetryCount() >= MAX_COMPENSATION_RETRY) {
                    // 超过最大补偿次数，升级为人工处理
                    alertService.notifyOpsTeam(
                        "下线补偿失败，需要人工介入",
                        record.getId(), step.getStepName()
                    );
                    continue;
                }

                boolean success = retryStep(record, step);
                if (success) {
                    step.markCompensated();
                    log.info("补偿成功 recordId={} step={}", record.getId(), step.getStepName());
                }
            }

            // 检查是否所有步骤都已成功
            if (record.getSteps().stream().allMatch(s -> s.getStatus() == StepStatus.COMPLETED)) {
                record.setStatus(TakedownStatus.COMPLETED);
                takedownRecordMapper.updateById(record);
            }
        }
    }
}
```

## 10. 性能优化

### 10.1 批量下线优化

当大量内容同时到期（如某供应商合同终止），需支持批量下线：

```java
/**
 * 批量下线优化策略
 */
public class BatchTakedownOptimizer {

    // 批量大小：每批最多处理50个内容
    private static final int BATCH_SIZE = 50;
    // 批次间隔：每批之间间隔5秒，避免瞬时压力
    private static final int BATCH_INTERVAL_SECONDS = 5;

    /**
     * 批量下线执行
     */
    public BatchTakedownResult executeBatchTakedown(List<Long> licenseIds) {
        BatchTakedownResult result = new BatchTakedownResult();

        // 按内容类型分组（同类型内容批量操作CDN和索引更高效）
        Map<String, List<Long>> groupedByType = licenseIds.stream()
            .collect(Collectors.groupingBy(
                id -> licenseMapper.selectById(id).getContentType()
            ));

        for (Map.Entry<String, List<Long>> entry : groupedByType.entrySet()) {
            String contentType = entry.getKey();
            List<Long> typeLicenseIds = entry.getValue();

            // 分批执行
            for (int i = 0; i < typeLicenseIds.size(); i += BATCH_SIZE) {
                List<Long> batch = typeLicenseIds.subList(
                    i, Math.min(i + BATCH_SIZE, typeLicenseIds.size())
                );

                // 批量CDN失效
                cdnServiceClient.batchInvalidate(batch, contentType);
                // 批量搜索索引移除
                searchServiceClient.batchRemoveFromIndex(batch);
                // 批量内容可见性更新
                contentServiceClient.batchUpdateVisibility(batch, ContentVisibility.OFFLINE);

                result.addBatchResult(batch.size());
                Thread.sleep(BATCH_INTERVAL_SECONDS * 1000L);
            }
        }

        // 批量修复引用关系（异步）
        asyncRepairService.batchRepairReferences(licenseIds);

        return result;
    }
}
```

| `replacement_strategy` | ENUM | `AUTO`=自动匹配替代；`MANUAL`=人工指定替代；`SUPPLIER_PROVIDED`=供应商提供替代；`NONE`=不需要替代 |
| `takedown_type` | ENUM | `LICENSE_EXPIRED`=授权到期；`LICENSE_REVOKED`=授权撤销；`MANUAL_OPERATION`=人工下线；`CONTENT_UPGRADED`=内容升级；`LEGAL_COMPLIANCE`=合规要求 |
