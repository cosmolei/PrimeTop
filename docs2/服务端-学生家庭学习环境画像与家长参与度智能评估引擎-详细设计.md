# 服务端-学生家庭学习环境画像与家长参与度智能评估引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责收集、计算和输出学生家庭学习环境的多维度画像数据，核心围绕**家长参与度（Parental Engagement）**进行量化评估。通过对家长在平台上的行为轨迹、互动频率、管控配置、反馈响应等数据的持续追踪，构建动态的家庭教育参与度模型，为个性化推荐、风险预警、家长端运营和产品决策提供数据支撑。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 家长参与度量化 | 建立科学的评分体系，将家长参与度从0-100进行量化 |
| 家庭环境画像 | 构建包含设备、时段、互动模式等多维度的家庭学习环境画像 |
| 风险预警 | 识别家长参与度低、家庭教育支持不足的学生，触发预警 |
| 个性化推荐 | 根据家庭画像为不同参与度的家长推荐适合的介入策略 |
| 数据服务 | 为学情报告、家长端、运营后台提供统一的家庭画像数据接口 |

### 1.3 适用范围

- 学生端：根据家庭画像调整学习提醒策略和学习内容推荐
- 家长端：提供家长参与度反馈报告和改进建议
- 运营后台：识别低参与度家庭进行定向运营触达
- 数据分析：为学情分析引擎提供家庭环境维度数据

### 1.4 核心概念定义

| 概念 | 定义 |
| --- | --- |
| 家长参与度（PE Score） | 量化评估家长在学生学习过程中参与程度的综合评分，范围 0-100 |
| 家庭学习环境画像 | 描述学生家庭学习环境特征的结构化数据集合 |
| 家长互动事件 | 家长在平台上产生的各类行为事件（查看报告、设置管控、复习辅导等） |
| 家庭参与模式 | 基于长期行为聚类得出的家长参与类型分类 |
| 参与度基线 | 同年级/同学段家长的参与度统计数据，用于相对评估 |

## 3. 参与度评分模型

### 3.1 评分维度设计

家长参与度评分（PE Score）由 5 个维度加权构成，每个维度满分 100，总分通过加权求和得出：

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 活跃度（Activity） | 25% | 家长在平台上的活跃频率 |
| 关注度（Attention） | 25% | 家长对学生学习数据的关注程度 |
| 管控度（Control） | 15% | 家长对学习行为的管理和规范程度 |
| 辅导度（Guidance） | 25% | 家长直接参与学习辅导的程度 |
| 投入度（Investment） | 10% | 家长在会员/资源上的投入程度 |

### 3.2 维度计算逻辑

#### 3.2.1 活跃度（Activity Score）

```python
def compute_activity_score(parent_user_id: int, period_days: int = 30) -> float:
    """
    计算家长活跃度评分
    基于近 N 天的活跃天数和事件总数
    """
    # 获取近N天事件数据
    daily_events = get_daily_event_counts(parent_user_id, period_days)
    active_days = sum(1 for count in daily_events.values() if count > 0)
    total_events = sum(daily_events.values())
    
    # 活跃天数得分（满分60）：每天占比 = 60 / period_days
    active_day_score = min(60.0, (active_days / period_days) * 60.0)
    
    # 日均事件得分（满分40）：每天>=3个事件即为满分
    avg_daily_events = total_events / period_days
    event_score = min(40.0, (avg_daily_events / 3.0) * 40.0)
    
    # 时效性加成：最近7天的活跃权重更高
    recent_7d_active = sum(1 for d in range(7) if daily_events.get(today - d, 0) > 0)
    recency_bonus = recent_7d_active * 2.0  # 最多+14
    
    score = min(100.0, active_day_score + event_score + recency_bonus)
    return round(score, 2)
```

#### 3.2.2 关注度（Attention Score）

```python
def compute_attention_score(parent_user_id: int, student_id: int, period_days: int = 30) -> float:
    """
    计算家长关注度评分
    基于报告查看行为、学情页面访问、薄弱点关注等
    """
    events = get_events_by_category(parent_user_id, student_id, ['REPORT_VIEW'], period_days)
    
    # 报告查看覆盖率（满分40）
    expected_reports = period_days  # 每日1份报告
    viewed_reports = len({e.occurred_at.date() for e in events 
                          if e.event_type == 'DAILY_REPORT_VIEW'})
    report_coverage = min(40.0, (viewed_reports / expected_reports) * 40.0)
    
    # 报告类型多样性（满分30）：查看多种类型报告得分更高
    report_types = {e.event_type for e in events}
    type_score = min(30.0, len(report_types) / 4.0 * 30.0)  # 4种报告类型满分
    
    # 深度交互分（满分30）：在报告中点击查看详情、分享报告等
    deep_interactions = count_deep_interactions(parent_user_id, student_id, period_days)
    deep_score = min(30.0, deep_interactions / 10.0 * 30.0)
    
    score = report_coverage + type_score + deep_score
    return round(min(100.0, score), 2)
```

#### 3.2.3 管控度（Control Score）

```python
def compute_control_score(parent_user_id: int, student_id: int) -> float:
    """
    计算家长管控度评分
    基于管控配置的完整性、合理性和持续调整行为
    """
    config = get_parent_control_config(student_id)
    if not config:
        return 0.0
    
    # 配置完整度（满分50）
    completeness = 0.0
    if config.daily_time_limit_minutes is not None:
        completeness += 15.0
    if config.enabled_subjects is not None:
        completeness += 10.0
    if config.enabled_modules is not None:
        completeness += 10.0
    if config.daily_report_enabled:
        completeness += 7.5
    if config.weekly_report_enabled:
        completeness += 7.5
    
    # 配置合理性（满分30）：时长限制在合理范围内
    reasonableness = 0.0
    if config.daily_time_limit_minutes:
        if 30 <= config.daily_time_limit_minutes <= 240:
            reasonableness = 30.0  # 合理范围
        elif config.daily_time_limit_minutes > 0:
            reasonableness = 15.0  # 有设置但不太合理
    
    # 持续调整行为（满分20）：近90天有调整记录
    recent_adjustments = count_config_adjustments(parent_user_id, student_id, days=90)
    adjustment_score = min(20.0, recent_adjustments * 5.0)
    
    score = completeness + reasonableness + adjustment_score
    return round(min(100.0, score), 2)
```

#### 3.2.4 辅导度（Guidance Score）

```python
def compute_guidance_score(parent_user_id: int, student_id: int, period_days: int = 30) -> float:
    """
    计算家长辅导度评分
    基于直接参与学习辅导的行为：共学、错题复习、作业检查等
    """
    guidance_events = get_events_by_category(
        parent_user_id, student_id, 
        ['STUDY_GUIDANCE', 'CO_LEARNING'], 
        period_days
    )
    
    # 高质量辅导行为（满分50）：共学、错题复习等
    high_quality_types = {
        'CO_LEARN_SESSION', 'CO_LEARN_COMPLETED', 
        'MISTAKE_REVIEW_WITH_CHILD', 'GOAL_SETTING'
    }
    high_quality_count = sum(1 for e in guidance_events if e.event_type in high_quality_types)
    high_quality_score = min(50.0, high_quality_count * 10.0)
    
    # 常规辅导行为（满分30）：作业检查、计划查看等
    regular_types = {'HOMEWORK_CHECK', 'PLAN_REVIEW'}
    regular_count = sum(1 for e in guidance_events if e.event_type in regular_types)
    regular_score = min(30.0, regular_count * 6.0)
    
    # 沟通行为（满分20）：与孩子/教师沟通
    comm_events = get_events_by_category(
        parent_user_id, student_id, ['COMMUNICATION'], period_days
    )
    comm_score = min(20.0, len(comm_events) * 4.0)
    
    score = high_quality_score + regular_score + comm_score
    return round(min(100.0, score), 2)
```

#### 3.2.5 投入度（Investment Score）

```python
def compute_investment_score(parent_user_id: int, student_id: int) -> float:
    """
    计算家长投入度评分
    基于会员订阅状态、增值服务购买等
    """
    membership = get_membership_status(student_id)
    purchase_history = get_purchase_history(parent_user_id, student_id, days=365)
    
    score = 0.0
    
    # 会员状态（满分50）
    if membership and membership.is_active:
        if membership.plan_type == 'ANNUAL':
            score += 50.0
        elif membership.plan_type == 'MONTHLY':
            score += 35.0
        elif membership.plan_type == 'FAMILY':
            score += 50.0
        
        # 持续订阅时长加成
        if membership.continuous_months >= 12:
            score = min(50.0, score + 10.0)
    
    # 增值服务购买（满分30）
    value_added_count = sum(1 for p in purchase_history if p.is_value_added)
    score += min(30.0, value_added_count * 10.0)
    
    # 资源包/课程购买（满分20）
    resource_count = sum(1 for p in purchase_history if p.category == 'RESOURCE')
    score += min(20.0, resource_count * 7.0)
    
    return round(min(100.0, score), 2)
```

### 3.3 综合评分计算

```python
def compute_pe_score(parent_user_id: int, student_id: int) -> dict:
    """
    计算家长参与度综合评分
    """
    # 各维度权重
    WEIGHTS = {
        'activity': 0.25,
        'attention': 0.25,
        'control': 0.15,
        'guidance': 0.25,
        'investment': 0.10,
    }
    
    # 计算各维度分数
    dimensions = {
        'activity': compute_activity_score(parent_user_id),
        'attention': compute_attention_score(parent_user_id, student_id),
        'control': compute_control_score(parent_user_id, student_id),
        'guidance': compute_guidance_score(parent_user_id, student_id),
        'investment': compute_investment_score(parent_user_id, student_id),
    }
    
    # 加权求和
    total_score = sum(dimensions[d] * WEIGHTS[d] for d in dimensions)
    total_score = round(total_score, 2)
    
    # 确定参与度等级
    level = classify_pe_level(total_score)
    
    # 确定参与模式
    pattern = classify_engagement_pattern(dimensions)
    
    # 确定趋势
    prev_score = get_previous_pe_score(student_id)
    trend = classify_trend(total_score, prev_score)
    
    return {
        'pe_score': total_score,
        'pe_level': level,
        'pe_score_trend': trend,
        'engagement_pattern': pattern,
        'dimension_scores': dimensions,
        'weights': WEIGHTS,
    }


def classify_pe_level(score: float) -> str:
    """参与度等级分类"""
    if score >= 80:
        return 'HIGHLY_ENGAGED'      # 高度参与
    elif score >= 60:
        return 'ENGAGED'              # 积极参与
    elif score >= 40:
        return 'MODERATELY_ENGAGED'   # 适度参与
    elif score >= 20:
        return 'LOW_ENGAGED'          # 低参与
    elif score > 0:
        return 'MINIMAL_ENGAGED'      # 极低参与
    else:
        return 'NO_ENGAGEMENT'        # 无参与（未绑定家长或无任何行为）


def classify_engagement_pattern(dimensions: dict) -> str:
    """
    参与模式分类
    基于各维度得分分布识别家长的参与行为模式
    """
    max_dim = max(dimensions, key=dimensions.get)
    sorted_dims = sorted(dimensions.items(), key=lambda x: x[1], reverse=True)
    
    # 模式判断逻辑
    if dimensions['guidance'] >= 60 and dimensions['activity'] >= 50:
        return 'HANDS_ON_PARENT'          # 亲力亲为型：直接辅导+高活跃
    elif dimensions['attention'] >= 60 and dimensions['guidance'] < 40:
        return 'MONITOR_PARENT'           # 监督关注型：多看不教
    elif dimensions['control'] >= 60 and dimensions['activity'] < 40:
        return 'CONTROL_PARENT'           # 管控型：设置规则但不常互动
    elif dimensions['investment'] >= 60 and dimensions['guidance'] < 40:
        return 'INVESTOR_PARENT'          # 投资型：花钱但少参与
    elif all(v >= 50 for v in dimensions.values()):
        return 'BALANCED_PARENT'          # 均衡型：各方面都有参与
    elif all(v < 30 for v in dimensions.values()):
        return 'ABSENT_PARENT'            # 缺席型：各方面都低
    else:
        return 'SELECTIVE_PARENT'         # 选择性参与型
```

## 5. 参与模式分类体系

### 5.1 参与模式定义

| 模式 | 特征 | 各维度典型表现 | 人数占比（预期） |
| --- | --- | --- | --- |
| `HANDS_ON_PARENT` 亲力亲为型 | 直接深度参与学习辅导 | guidance≥60, activity≥50 | 10-15% |
| `MONITOR_PARENT` 监督关注型 | 经常查看数据但较少直接辅导 | attention≥60, guidance<40 | 25-30% |
| `CONTROL_PARENT` 管控型 | 注重规则设置但互动少 | control≥60, activity<40 | 10-15% |
| `INVESTOR_PARENT` 投资型 | 花钱买服务但少参与 | investment≥60, guidance<40 | 5-10% |
| `BALANCED_PARENT` 均衡型 | 各方面均有参与 | 全维度≥50 | 5-10% |
| `SELECTIVE_PARENT` 选择性参与型 | 在某1-2个方面参与 | 至少1个维度≥40，但分布不均 | 20-25% |
| `ABSENT_PARENT` 缺席型 | 几乎无任何参与 | 全维度<30 | 15-25% |
| `NO_ENGAGEMENT` 无参与 | 未绑定家长或完全无行为 | 全维度=0 | 5-10% |

### 5.2 模式转换路径

```
NO_ENGAGEMENT → MINIMAL_ENGAGED → SELECTIVE_PARENT
                                         ↓
                              ┌──────────┼──────────┐
                              ↓          ↓          ↓
                    MONITOR_PARENT  CONTROL_PARENT  INVESTOR_PARENT
                              └────┬─────┴──────────┘
                                   ↓
                           HANDS_ON_PARENT
                                   ↓
                            BALANCED_PARENT
```

系统通过推荐建议引导家长沿着路径向上升级，每次推荐根据当前模式选择**最容易实现的下一步**作为突破口。

```python
def evaluate_risk_factors(profile: FamilyEnvProfile) -> list[str]:
    """评估家庭风险因子"""
    factors = []
    
    # 无家长绑定
    if profile.parent_user_id is None:
        factors.append("NO_PARENT_BOUND")
    
    # 家长超过30天未活跃
    if profile.last_parent_action_time:
        days_inactive = (datetime.now() - profile.last_parent_action_time).days
        if days_inactive > 30:
            factors.append(f"PARENT_INACTIVE_{days_inactive}D")
    
    # 参与度持续下降
    recent_scores = get_recent_pe_scores(profile.student_id, weeks=4)
    if len(recent_scores) >= 3 and all(recent_scores[i] > recent_scores[i+1] 
                                        for i in range(len(recent_scores)-1)):
        factors.append("PE_CONTINUOUS_DECLINE")
    
    # 从未设置管控
    config = get_parent_control_config(profile.student_id)
    if config and config.config_completeness_score < 20:
        factors.append("NO_PARENTAL_CONTROL")
    
    # 从未查看报告
    if profile.parent_report_view_rate == 0:
        factors.append("NEVER_VIEWED_REPORT")
    
    # 无会员
    membership = get_membership_status(profile.student_id)
    if not membership or not membership.is_active:
        factors.append("NO_MEMBERSHIP")
    
    # 学生活跃但家长完全不参与（落差大）
    student_activity = get_student_activity_level(profile.student_id)
    if student_activity == 'HIGH' and profile.pe_score < 20:
        factors.append("STUDENT_PARENT_ENGAGEMENT_GAP")
    
    return factors
```

```python
def daily_pe_score_computation():
    """
    每日参与度评分全量重算
    策略：增量计算 + 全量校正
    """
    # 1. 获取需要重算的学生列表（活跃学生 + 有家长行为变化的学生）
    active_students = get_active_student_ids(days=30)
    changed_parents = get_parents_with_recent_events(days=1)

    # 2. 分批计算（每批500人）
    batch_size = 500
    for batch in chunk(target_students, batch_size):
        for student_id in batch:
            try:
                profile = get_or_create_profile(student_id)
                
                # 检查是否有家长绑定
                if not profile.parent_user_id:
                    profile.pe_score = 0
                    profile.pe_level = 'NO_ENGAGEMENT'
                    profile.risk_level = 'CRITICAL'
                    profile.risk_factors = ['NO_PARENT_BOUND']
                    save_profile(profile)
                    continue
                
                # 计算综合评分
                score_result = compute_pe_score(profile.parent_user_id, student_id)
                
                # 更新画像
                profile.pe_score_prev = profile.pe_score
                profile.pe_score = score_result['pe_score']
                profile.pe_level = score_result['pe_level']
                profile.pe_score_trend = score_result['pe_score_trend']
                profile.engagement_pattern = score_result['engagement_pattern']
                
                # 重新评估风险
                profile.risk_level = classify_risk_level(score_result['pe_score'])
                profile.risk_factors = evaluate_risk_factors(profile)
                
                # 更新环境特征
                profile.co_learn_frequency = count_co_learn_sessions(student_id, days=30)
                profile.parent_notification_open_rate = compute_notification_open_rate(
                    profile.parent_user_id, days=30)
                profile.parent_report_view_rate = compute_report_view_rate(
                    profile.parent_user_id, student_id, days=30)
                
                profile.score_computed_at = datetime.now()
                save_profile(profile)
                
                # 写入评分历史
                save_score_history(student_id, profile.parent_user_id, score_result, 'DAILY')
                
            except Exception as e:
                logger.error(f"PE score computation failed for student {student_id}", exc_info=e)
                continue
        
        # 批间休眠，降低数据库压力
        time.sleep(0.5)
    
    # 3. 更新Redis缓存
    refresh_family_profile_cache(target_students)

    refresh_risk_sets()
    
    logger.info(f"PE score computation completed. {len(target_students)} students processed.")
```

### 9.2 建议去重与频控

```python
def filter_recommendations(
    student_id: int, 
    recommendations: list[Recommendation],
    cooldown_days: int = 7,
) -> list[Recommendation]:
    """
    过滤已展示且在冷却期内的建议
    """
    shown_history = get_shown_recommendations(student_id, days=cooldown_days)
    shown_keys = {(r.type, r.target_dimension) for r in shown_history}
    
    filtered = [r for r in recommendations 
                if (r.type, r.target_dimension) not in shown_keys]
    
    # 如果全部在冷却期内，返回评分最高的（即使重复）
    if not filtered:
        return recommendations[:1]
    
    return filtered
```

### 10.2 降级策略

```python
async def get_family_profile_with_fallback(student_id: int) -> dict:
    """
    获取家庭画像（带降级逻辑）
    """
    try:
        # 1. 先查缓存
        cached = await redis.get(f"family:profile:{student_id}")
        if cached:
            return json.loads(cached)
        
        # 2. 查数据库
        profile = await get_profile_from_db(student_id)
        if profile:
            await redis.setex(
                f"family:profile:{student_id}", 
                6 * 3600,  # 6小时
                json.dumps(profile.to_dict())
            )
            return profile.to_dict()
        
        # 3. 新学生，返回默认画像
        return default_profile(student_id)
        
    except DatabaseError as e:
        logger.error(f"DB error fetching family profile for {student_id}", exc_info=e)
        # 降级：返回最小可用数据
        return {
            'student_id': student_id,
            'pe_score': 0,
            'pe_level': 'UNKNOWN',
            'error': 'PROFILE_UNAVAILABLE',
        }
    except Exception as e:
        logger.error(f"Unexpected error fetching family profile for {student_id}", exc_info=e)
        return default_profile(student_id)
```

### 10.3 评分计算失败补偿

```python
async def safe_compute_pe_score(student_id: int) -> Optional[dict]:
    """
    安全的评分计算（带超时和补偿）
    """
    try:
        result = await asyncio.wait_for(
            compute_pe_score_async(student_id),
            timeout=10.0  # 10秒超时
        )
        return result
    except asyncio.TimeoutError:
        logger.warning(f"PE score computation timeout for student {student_id}")
        # 补偿：使用上一次评分，标记为可能过期
        last_score = await get_last_pe_score(student_id)
        if last_score:
            return {**last_score, '_stale': True}
        return None
    except Exception as e:
        logger.error(f"PE score computation failed for {student_id}", exc_info=e)
        return None
```

```sql
-- 按风险等级批量查询（走 idx_risk 索引）
SELECT student_id, parent_user_id, pe_score, risk_factors
FROM family_env_profile
WHERE risk_level = 'CRITICAL'
  AND updated_at > DATE_SUB(NOW(), INTERVAL 48 HOUR)
ORDER BY pe_score ASC
LIMIT 1000;

-- 按学段聚合统计
SELECT 
    CASE 
        WHEN pe_score = 0 THEN 'NO_ENGAGEMENT'
        WHEN pe_score < 20 THEN 'MINIMAL'
        WHEN pe_score < 40 THEN 'LOW'
        WHEN pe_score < 60 THEN 'MODERATE'
        WHEN pe_score < 80 THEN 'ENGAGED'
        ELSE 'HIGHLY_ENGAGED'
    END AS engagement_bucket,
    COUNT(*) AS count
FROM family_env_profile
WHERE updated_at > DATE_SUB(NOW(), INTERVAL 7 DAY)
GROUP BY engagement_bucket;
```

## 13. 数据安全与隐私

### 13.1 数据安全要求

1. 家长行为数据属于用户隐私，需加密存储敏感字段
2. 家长参与度评分不对学生可见（避免引发家庭矛盾）
3. 家长端展示的对比数据需脱敏（不显示其他家长的具体分数）
4. 画像数据访问需进行权限校验（仅本人、绑定关系、管理员可查）
