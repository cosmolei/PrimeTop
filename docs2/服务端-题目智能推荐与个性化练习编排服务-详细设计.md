# 服务端 - 题目智能推荐与个性化练习编排服务 详细设计

> **模块定位**：本服务是 PrimeTop 学习闭环中"练习巩固"环节的核心引擎，负责根据学生当前的知识掌握度、薄弱知识点、学习阶段、教材进度和错题历史，从题库中智能筛选并编排个性化的练习题组。它不同于「智能组卷与自适应测试引擎」（面向考试场景的完整试卷生成），本服务聚焦于**日常学习中的短时练习编排**——每次 3~15 道题的轻量练习，嵌入到同步课堂、错题复习、每日任务、首页推荐等多种学习场景中。

## 1. 概述

### 1.1 背景与问题

PrimeTop 的学习闭环要求"讲解 → 练习 → 检测 → 巩固"环环相扣。当前系统已具备：
- 题目与题库服务：提供题目的 CRUD 和检索能力
- 知识点掌握度：记录每个学生对每个知识点的掌握水平
- 错题整理：收录学生的错题记录和错因标签
- 间隔重复复习调度：安排错题和知识点的复习时间

但缺少一个**统一的中层编排服务**，将上述数据源综合起来，回答："这个学生现在应该做什么题？"

具体痛点：
1. 各业务模块自行拼凑推荐逻辑，逻辑分散且不一致
2. 题目难度与学生能力不匹配（太简单浪费时间，太难打击信心）
3. 知识点覆盖不够均衡（只练会的不练薄弱的）
4. 无法在练习过程中实时调整难度（Cat 模式）
5. 缺乏对"同类题""变式题"的系统性推荐机制

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 精准匹配 | 根据学生能力水平推荐合适难度的题目 |
| 薄弱优先 | 优先覆盖掌握度低的知识点 |
| 均衡覆盖 | 避免长期偏向某些知识点，保证知识面完整 |
| 实时调整 | 练习过程中根据答题结果动态调整后续题目难度 |
| 多场景适配 | 同步课堂、错题复习、每日任务、首页推荐等场景统一调用 |
| 去重去偏 | 避免重复推荐已做过的题、已掌握的题 |

### 1.3 核心概念

| 概念 | 说明 |
| --- | --- |
| **练习会话 (Practice Session)** | 一次完整的练习过程，包含 3~15 道题 |
| **推荐请求 (Recommend Request)** | 业务模块发起的题目推荐请求，指定场景、学科、知识点等约束 |
| **题目池 (Question Pool)** | 候选题目集合，从题库中根据条件筛选 |
| **推荐策略 (Recommend Strategy)** | 决定题目选择和排序的算法逻辑 |
| **难度模型 (Difficulty Model)** | 将题目难度和学生能力映射到同一量尺（IRT 模型） |
| **练习报告 (Practice Report)** | 练习会话结束后的统计分析结果 |

## 2. 数据模型

### 2.1 推荐请求参数 (RecommendRequest)

```java
public class RecommendRequest {
    /** 用户ID */
    private Long userId;
    
    /** 学科代码: MATH, CHINESE, ENGLISH, PHYSICS, ... */
    private String subjectCode;
    
    /** 推荐场景 */
    private RecommendScene scene;
    
    /** 知识点范围（可选，为空则自动选取） */
    private List<String> knowledgePointIds;
    
    /** 教材版本ID（可选） */
    private String textbookId;
    
    /** 章节ID范围（可选） */
    private List<String> chapterIds;
    
    /** 期望题目数量 */
    private Integer questionCount;
    
    /** 难度约束（可选） */
    private DifficultyConstraint difficultyConstraint;
    
    /** 题型约束（可选） */
    private List<String> questionTypes;
    
    /** 排除题目ID列表（已做过的、已推荐的） */
    private List<Long> excludeQuestionIds;
    
    /** 练习会话ID（自适应模式续推时传入） */
    private String sessionId;
    
    /** 时间约束（可选） */
    private TimeConstraint timeConstraint;
}
```

### 2.2 枚举定义

```java
/** 推荐场景 */
public enum RecommendScene {
    SYNC_CLASSroom("同步课堂课后练习"),
    MISTAKE_REINFORCE("错题同类题巩固"),
    DAILY_TASK("每日任务练习"),
    HOMEWORK_HELPER("作业辅导"),
    WEAK_POINT_DRILL("薄弱知识点专项"),
    FREE_PRACTICE("自由练习"),
    PRE_EXAM_REVIEW("考前复习练习"),
    AI_FOLLOW_UP("AI对话跟进练习");
    
    private final String description;
}

/** 难度等级（5级制） */
public enum DifficultyLevel {
    EASY(1, "基础", 0.0, 0.2),
    BASIC(2, "基本", 0.2, 0.4),
    MEDIUM(3, "中等", 0.4, 0.6),
    HARD(4, "较难", 0.6, 0.8),
    CHALLENGE(5, "挑战", 0.8, 1.0);
    
    private final int level;
    private final String label;
    private final double minTheta;  // IRT θ 范围下界
    private final double maxTheta;  // IRT θ 范围上界
}

/** 难度约束 */
public class DifficultyConstraint {
    /** 最小难度等级 */
    private DifficultyLevel minDifficulty;
    /** 最大难度等级 */
    private DifficultyLevel maxDifficulty;
    /** 目标难度（自适应模式） */
    private Double targetDifficulty;
    /** 难度分布策略 */
    private DifficultyDistribution distribution;
}

/** 难度分布策略 */
public enum DifficultyDistribution {
    UNIFORM,       // 均匀分布：各级别等量
    PYRAMID,       // 金字塔：基础多→挑战少
    DIAMOND,       // 菱形：中等最多
    TARGET_CENTER, // 聚焦目标难度：以学生能力±0.3为主
    GRADUATED      // 渐进：由易到难递增
}

/** 时间约束 */
public class TimeConstraint {
    /** 预计可用时间（分钟） */
    private Integer availableMinutes;
    /** 是否严格限时 */
    private boolean strictTimeLimit;
}

/** 推荐结果项 */
public class RecommendedQuestion {
    private Long questionId;
    private String questionType;
    private DifficultyLevel difficulty;
    private String knowledgePointId;
    private Double predictedCorrectRate;  // 预测正确率
    private String recommendReason;       // 推荐理由
    private Integer estimatedMinutes;     // 预估耗时
}
```

```python
def resolve_target_knowledge_points(
    request: RecommendRequest,
    profile: StudentProfile
) -> list[TargetKnowledgePoint]:
    """
    根据场景自动选取目标知识点。
    返回: [(kp_id, target_weight, min_difficulty, max_difficulty), ...]
    """
    scene = request.scene
    
    # 场景1: 指定知识点 → 直接使用
    if request.knowledge_point_ids:
        return [
            TargetKnowledgePoint(kp_id=kp, weight=1.0/len(request.knowledge_point_ids))
            for kp in request.knowledge_point_ids
        ]
    
    # 场景2: 薄弱知识点专项
    if scene == RecommendScene.WEAK_POINT_DRILL:
        # 选取掌握度最低的 Top N 知识点
        weak_kps = sorted(
            profile.weak_knowledge_points,
            key=lambda kp: profile.knowledge_mastery.get(kp, 0.5)
        )[:5]
        weights = [1.0 / (i + 1) for i in range(len(weak_kps))]  # 越薄弱权重越高
        total = sum(weights)
        return [
            TargetKnowledgePoint(
                kp_id=kp,
                weight=w / total,
                min_difficulty=compute_min_difficulty(profile.knowledge_mastery.get(kp, 0.5)),
                max_difficulty=compute_max_difficulty(profile.knowledge_mastery.get(kp, 0.5))
            )
            for kp, w in zip(weak_kps, weights)
        ]
    
    # 场景3: 同步课堂课后练习
    if scene == RecommendScene.SYNC_CLASSroom:
        # 选取当前章节的知识点
        chapter_kps = get_chapter_knowledge_points(request.chapter_id)
        return distribute_weight_by_mastery(chapter_kps, profile)
    
    # 场景4: 错题同类题巩固
    if scene == RecommendScene.MISTAKE_REINFORCE:
        # 从错题中提取知识点
        mistake_kps = list(profile.mistake_kp_distribution.keys())
        return distribute_weight_by_mistake_count(mistake_kps, profile)
    
    # 场景5: 每日任务练习 → 均衡覆盖
    if scene == RecommendScene.DAILY_TASK:
        # 获取当前学期所有已学知识点
        all_kps = get_semester_knowledge_points(request.subject_code, profile)
        # 薄弱知识点占 60%，已学知识点复习占 40%
        return balanced_coverage(all_kps, profile, weak_ratio=0.6)
    
    # 场景6: 自由练习 / AI跟进 → 能力匹配
    if scene in (RecommendScene.FREE_PRACTICE, RecommendScene.AI_FOLLOW_UP):
        all_kps = get_subject_knowledge_points(request.subject_code, profile.grade)
        return distribute_by_zone_of_proximal_development(all_kps, profile)
```

```python
def build_candidate_pool(
    request: RecommendRequest,
    target_kps: list[TargetKnowledgePoint],
    profile: StudentProfile
) -> list[CandidateQuestion]:
    """
    构建候选题目池
    过滤链: 知识点筛选 → 难度筛选 → 去重 → 质量过滤
    """
    # 1. 知识点范围检索
    kp_ids = [tkp.kp_id for tkp in target_kps]
    candidates = question_service.search_by_knowledge_points(
        subject_code=request.subject_code,
        knowledge_point_ids=kp_ids,
        textbook_id=request.textbook_id,
        limit=500  # 候选池上限
    )
    
    # 2. 难度过滤
    if request.difficulty_constraint:
        candidates = filter_by_difficulty(candidates, request.difficulty_constraint)
    
    # 3. 去重（排除已做过、已推荐、已排除的题目）
    exclude_ids = set()
    exclude_ids.update(profile.recent_done_questions)
    exclude_ids.update(request.exclude_question_ids or [])
    # 加入近7天推荐过的题目（避免短期内重复）
    recent_recommended = get_recent_recommended(request.user_id, days=7)
    exclude_ids.update(recent_recommended)
    candidates = [c for c in candidates if c.question_id not in exclude_ids]
    
    # 4. 题型过滤
    if request.question_types:
        candidates = [c for c in candidates if c.question_type in request.question_types]
    
    # 5. 质量过滤（排除被标记为低质量的题目）
    candidates = [c for c in candidates if c.quality_score >= 0.6]
    
    # 6. 学段适配（排除超出学生学段的题目）
    candidates = [c for c in candidates if c.grade_range <= profile.grade]
    
    return candidates
```

### 4.5 步骤 5：评分与排序（核心推荐算法）

每个候选题目计算综合推荐分，由多个维度加权求和：

```python
def score_candidates(
    candidates: list[CandidateQuestion],
    target_kps: list[TargetKnowledgePoint],
    profile: StudentProfile,
    scene: RecommendScene
) -> list[ScoredCandidate]:
    """
    对候选题目进行多维评分
    综合分 = w1*难度匹配分 + w2*知识点权重分 + w3*新鲜度分 + w4*题型多样性分 + w5*预测正确率分
    """
    # 场景权重矩阵
    SCENE_WEIGHTS = {
        RecommendScene.WEAK_POINT_DRILL: (0.30, 0.35, 0.10, 0.10, 0.15),
        RecommendScene.SYNC_CLASSroom:   (0.25, 0.30, 0.15, 0.15, 0.15),
        RecommendScene.DAILY_TASK:        (0.20, 0.25, 0.20, 0.15, 0.20),
        RecommendScene.MISTAKE_REINFORCE: (0.25, 0.35, 0.10, 0.10, 0.20),
        RecommendScene.FREE_PRACTICE:     (0.30, 0.20, 0.15, 0.15, 0.20),
        RecommendScene.PRE_EXAM_REVIEW:   (0.25, 0.30, 0.10, 0.15, 0.20),
    }
    w1, w2, w3, w4, w5 = SCENE_WEIGHTS.get(scene, (0.25, 0.25, 0.15, 0.15, 0.20))
    
    # 构建知识点权重映射
    kp_weight_map = {tkp.kp_id: tkp.weight for tkp in target_kps}
    
    scored = []
    used_types = set()  # 用于题型多样性
    
    for candidate in candidates:
        # 维度1: 难度匹配分（基于IRT预测正确率）
        predicted_p = predict_correct_rate(
            theta=profile.ability_theta,
            difficulty=candidate.difficulty_theta,
            discrimination=candidate.discrimination,
            guessing=candidate.guessing
        )
        # 目标正确率区间 [0.5, 0.8]，中间值 0.65 最优
        difficulty_score = 1.0 - abs(predicted_p - 0.65) / 0.65
        difficulty_score = max(0, min(1, difficulty_score))
        
        # 维度2: 知识点权重分
        kp_score = kp_weight_map.get(candidate.knowledge_point_id, 0.0)
        # 薄弱知识点加权
        mastery = profile.knowledge_mastery.get(candidate.knowledge_point_id, 0.5)
        if mastery < 0.4:
            kp_score *= 1.5  # 高薄弱加权
        elif mastery < 0.6:
            kp_score *= 1.2
        kp_score = min(1.0, kp_score)
        
        # 维度3: 新鲜度分（越久没做越好）
        last_done = profile.question_last_done.get(candidate.question_id)
        if last_done is None:
            freshness_score = 1.0  # 从未做过
        else:
            days_since = (datetime.now() - last_done).days
            freshness_score = min(1.0, days_since / 30.0)  # 30天线性增长
        
        # 维度4: 题型多样性分（鼓励不同题型）
        if candidate.question_type not in used_types:
            diversity_score = 1.0
        else:
            diversity_score = 0.3  # 已有同题型降权
        
        # 维度5: 预测正确率分（鼓励适度挑战）
        if 0.5 <= predicted_p <= 0.8:
            accuracy_score = 1.0  # 黄金区间
        elif 0.3 <= predicted_p < 0.5:
            accuracy_score = 0.6  # 稍难
        elif predicted_p > 0.8:
            accuracy_score = 0.4  # 太简单
        else:
            accuracy_score = 0.2  # 太难
        
        # 综合分
        total_score = (
            w1 * difficulty_score +
            w2 * kp_score +
            w3 * freshness_score +
            w4 * diversity_score +
            w5 * accuracy_score
        )
        
        scored.append(ScoredCandidate(
            candidate=candidate,
            total_score=total_score,
            difficulty_score=difficulty_score,
            kp_score=kp_score,
            freshness_score=freshness_score,
            predicted_correct_rate=predicted_p,
            scores=(difficulty_score, kp_score, freshness_score, diversity_score, accuracy_score)
        ))
    
    # 按综合分降序排序
    scored.sort(key=lambda x: x.total_score, reverse=True)
    return scored
```

#### 4.5.1 IRT 预测正确率（3PL 模型）

```python
def predict_correct_rate(
    theta: float,       # 学生能力参数
    difficulty: float,   # 题目难度参数
    discrimination: float = 1.0,  # 区分度参数
    guessing: float = 0.2  # 猜测参数（选择题默认0.2）
) -> float:
    """
    三参数逻辑斯蒂克模型（3PL）
    P(θ) = c + (1 - c) / (1 + exp(-a * (θ - b)))
    
    θ: 学生能力（-3 ~ +3）
    b: 题目难度（-3 ~ +3）
    a: 区分度（0.5 ~ 2.5）
    c: 猜测参数（0 ~ 0.5）
    """
    exponent = -discrimination * (theta - difficulty)
    # 防溢出
    exponent = max(-30, min(30, exponent))
    probability = guessing + (1.0 - guessing) / (1.0 + math.exp(exponent))
    return round(max(0.0, min(1.0, probability)), 4)
```

### 4.6 步骤 6：约束优化选择

从排序后的候选列表中，按约束条件选出最终题目集合：

```python
def select_with_constraints(
    scored: list[ScoredCandidate],
    count: int,
    target_kps: list[TargetKnowledgePoint],
    distribution: DifficultyDistribution
) -> list[ScoredCandidate]:
    """
    在满足约束条件的前提下，从高分候选中选出题目。
    约束：知识点均衡覆盖 + 难度分布符合策略
    """
    selected = []
    kp_quotas = {tkp.kp_id: max(1, round(count * tkp.weight)) for tkp in target_kps}
    
    # 调整配额总和等于 count
    total_quota = sum(kp_quotas.values())
    if total_quota != count:
        # 按权重从大到小调整
        sorted_kps = sorted(kp_quotas.keys(), key=lambda k: kp_quotas[k], reverse=True)
        diff = count - total_quota
        for kp in sorted_kps:
            if diff == 0:
                break
            if diff > 0:
                kp_quotas[kp] += 1
                diff -= 1
            else:
                if kp_quotas[kp] > 1:
                    kp_quotas[kp] -= 1
                    diff += 1
    
    # 按知识点配额选择
    kp_filled = {kp: 0 for kp in kp_quotas}
    
    for candidate in scored:
        if len(selected) >= count:
            break
        kp = candidate.candidate.knowledge_point_id
        if kp not in kp_quotas:
            continue
        if kp_filled.get(kp, 0) >= kp_quotas[kp]:
            continue
        selected.append(candidate)
        kp_filled[kp] = kp_filled.get(kp, 0) + 1
    
    # 如果还有空位（某些知识点候选不足），用剩余高分填充
    if len(selected) < count:
        selected_ids = {s.candidate.question_id for s in selected}
        for candidate in scored:
            if len(selected) >= count:
                break
            if candidate.candidate.question_id not in selected_ids:
                selected.append(candidate)
    
    # 难度分布检查与调整
    selected = adjust_difficulty_distribution(selected, distribution)
    
    return selected[:count]
```

```python
def order_questions(
    selected: list[ScoredCandidate],
    scene: RecommendScene
) -> list[ScoredCandidate]:
    """根据场景决定题目输出顺序"""
    
    if scene in (RecommendScene.WEAK_POINT_DRILL, RecommendScene.SYNC_CLASSroom):
        # 渐进式：由易到难
        return sorted(selected, key=lambda s: s.candidate.difficulty_level)
    
    elif scene == RecommendScene.PRE_EXAM_REVIEW:
        # 混合难度：避免连续同类
        return interleave_by_difficulty(selected)
    
    elif scene == RecommendScene.DAILY_TASK:
        # 交错排列：不同知识点交替
        return interleave_by_knowledge_point(selected)
    
    else:
        # 默认：按综合分降序
        return selected


def interleave_by_knowledge_point(items):
    """按知识点交错排列，避免连续同一知识点"""
    from collections import defaultdict
    kp_groups = defaultdict(list)
    for item in items:
        kp_groups[item.candidate.knowledge_point_id].append(item)
    
    result = []
    while kp_groups:
        for kp in list(kp_groups.keys()):
            if kp_groups[kp]:
                result.append(kp_groups[kp].pop(0))
            if not kp_groups[kp]:
                del kp_groups[kp]
    return result
```

### 5.1 能力估计更新（EAP 算法）

```python
def update_ability_estimate(
    current_theta: float,
    question_difficulty: float,
    question_discrimination: float,
    is_correct: bool,
    learning_rate: float = 0.3
) -> float:
    """
    基于 Expected a Posteriori (EAP) 的简化能力更新
    
    核心逻辑:
    - 答对难题 → 能力上升多
    - 答对简单题 → 能力上升少
    - 答错简单题 → 能力下降多
    - 答错难题 → 能力下降少
    """
    # 预测正确率
    p_correct = predict_correct_rate(current_theta, question_difficulty, question_discrimination)
    
    # 信息量（Fisher Information）
    info = question_discrimination ** 2 * p_correct * (1 - p_correct)
    
    # 更新量
    if is_correct:
        delta = learning_rate * info * (1 - p_correct)
    else:
        delta = -learning_rate * info * p_correct
    
    new_theta = current_theta + delta
    
    # 限制范围
    return round(max(-3.0, min(3.0, new_theta)), 3)
```

```python
def select_next_difficulty(
    current_theta: float,
    seq_index: int,          # 当前是第几题
    total_count: int,         # 总题数
    session_accuracy: float   # 本轮当前正确率
) -> tuple[int, float]:
    """
    根据当前能力估计选择下一题的目标难度
    返回: (difficulty_level, difficulty_theta)
    """
    progress = seq_index / total_count  # 进度 0~1
    
    # 策略: 前期探索，中期匹配，后期确认
    if progress < 0.3:
        # 探索阶段：在能力附近稍宽范围选题
        target_theta = current_theta + random.uniform(-0.3, 0.3)
    elif progress < 0.7:
        # 匹配阶段：精确匹配能力
        target_theta = current_theta
    else:
        # 确认阶段：如果正确率高则稍加难度，低则降低
        if session_accuracy > 0.7:
            target_theta = current_theta + 0.2
        elif session_accuracy < 0.4:
            target_theta = current_theta - 0.3
        else:
            target_theta = current_theta
    
    target_theta = max(-2.0, min(2.5, target_theta))
    difficulty_level = theta_to_difficulty_level(target_theta)
    
    return difficulty_level, target_theta
```

### 6.1 相似度计算

```python
def compute_question_similarity(q1: Question, q2: Question) -> float:
    """
    计算两道题的相似度 (0~1)
    维度: 知识点重叠 + 题型匹配 + 难度接近 + 考查能力维度重叠
    """
    score = 0.0
    
    # 维度1: 知识点重叠（权重 0.4）
    kp_overlap = len(set(q1.knowledge_point_ids) & set(q2.knowledge_point_ids))
    kp_union = len(set(q1.knowledge_point_ids) | set(q2.knowledge_point_ids))
    kp_similarity = kp_overlap / kp_union if kp_union > 0 else 0
    score += 0.4 * kp_similarity
    
    # 维度2: 题型匹配（权重 0.25）
    type_match = 1.0 if q1.question_type == q2.question_type else 0.0
    score += 0.25 * type_match
    
    # 维度3: 难度接近度（权重 0.2）
    diff_gap = abs(q1.difficulty_theta - q2.difficulty_theta)
    difficulty_similarity = max(0, 1.0 - diff_gap / 2.0)
    score += 0.2 * difficulty_similarity
    
    # 维度4: 考查能力维度重叠（权重 0.15）
    ability_overlap = len(set(q1.ability_dimensions) & set(q2.ability_dimensions))
    ability_union = len(set(q1.ability_dimensions) | set(q2.ability_dimensions))
    ability_similarity = ability_overlap / ability_union if ability_union > 0 else 0
    score += 0.15 * ability_similarity
    
    return round(score, 4)
```

### 7.1 核心服务类

```java
@Service
@Slf4j
public class PracticeRecommendService {

    private final CandidatePoolBuilder poolBuilder;
    private final CandidateScorer scorer;
    private final ConstraintSelector selector;
    private final AdaptiveEngine adaptiveEngine;
    private final PracticeSessionRepository sessionRepo;
    private final RecommendLogRepository logRepo;
    private final ApplicationEventPublisher eventPublisher;

    /**
     * 推荐题目（主入口）
     */
    @Transactional
    public RecommendResult recommend(RecommendRequest request) {
        long startTime = System.currentTimeMillis();
        String requestId = UUID.randomUUID().toString();
        
        try {
            // 1. 加载学生画像
            StudentProfile profile = loadStudentProfile(
                request.getUserId(), request.getSubjectCode()
            );
            
            // 2. 确定目标知识点
            List<TargetKnowledgePoint> targetKps = resolveTargetKnowledgePoints(
                request, profile
            );
            
            // 3. 构建候选池
            List<CandidateQuestion> pool = poolBuilder.build(
                request, targetKps, profile
            );
            
            if (pool.isEmpty()) {
                throw new BusinessException("PRACTICE_001", "未找到符合条件的题目");
            }
            
            // 4. 评分排序
            List<ScoredCandidate> scored = scorer.score(
                pool, targetKps, profile, request.getScene()
            );
            
            // 5. 约束选择
            int count = request.getQuestionCount() != null
                ? request.getQuestionCount()
                : getDefaultCount(request.getScene());
            DifficultyDistribution distribution = getDistribution(request);
            List<ScoredCandidate> selected = selector.select(
                scored, count, targetKps, distribution
            );
            
            // 6. 排序输出
            List<ScoredCandidate> ordered = orderQuestions(
                selected, request.getScene()
            );
            
            // 7. 创建练习会话
            PracticeSession session = createSession(request, ordered, profile);
            sessionRepo.save(session);
            
            // 8. 构建返回结果
            RecommendResult result = buildResult(session, ordered, profile, pool.size());
            
            // 9. 记录推荐日志
            long latency = System.currentTimeMillis() - startTime;
            saveRecommendLog(requestId, request, result, latency);
            
            log.info("推荐完成: user={}, scene={}, candidates={}, selected={}, latency={}ms",
                request.getUserId(), request.getScene(), pool.size(), ordered.size(), latency);
            
            return result;
            
        } catch (BusinessException e) {
            throw e;
        } catch (Exception e) {
            log.error("推荐异常: user={}, scene={}", request.getUserId(), request.getScene(), e);
            throw new ServiceException("PRACTICE_002", "题目推荐服务异常", e);
        }
    }

    /**
     * 提交答题结果（自适应模式）
     */
    @Transactional
    public AnswerResult submitAnswer(AnswerRequest request) {
        // 1. 加载会话
        PracticeSession session = sessionRepo.findById(request.getSessionId())
            .orElseThrow(() -> new BusinessException("PRACTICE_003", "会话不存在"));
        
        if (session.getStatus() != SessionStatus.IN_PROGRESS) {
            throw new BusinessException("PRACTICE_004", "会话状态不允许答题");
        }
        
        // 2. 更新能力估计
        double abilityBefore = session.getCurrentAbility();
        double abilityAfter = adaptiveEngine.updateAbility(
            abilityBefore,
            request.getDifficultyTheta(),
            request.getDiscrimination(),
            request.isCorrect()
        );
        session.setCurrentAbility(abilityAfter);
        
        // 3. 保存答题记录
        PracticeAnswer answer = PracticeAnswer.builder()
            .sessionId(session.getId())
            .userId(session.getUserId())
            .questionId(request.getQuestionId())
            .answerSeq(session.getCompletedCount() + 1)
            .isCorrect(request.isCorrect())
            .timeSpentSec(request.getTimeSpentSec())
            .abilityBefore(abilityBefore)
            .abilityAfter(abilityAfter)
            .build();
        practiceAnswerRepo.save(answer);
        
        // 4. 更新会话统计
        session.setCompletedCount(session.getCompletedCount() + 1);
        if (request.isCorrect()) {
            session.setCorrectCount(session.getCorrectCount() + 1);
        }
        session.setTotalTimeSec(session.getTotalTimeSec() + request.getTimeSpentSec());
        
        // 5. 判断是否还有下一题
        AnswerResult result = new AnswerResult();
        result.setAbilityChange(abilityAfter - abilityBefore);
        result.setCurrentAbility(abilityAfter);
        result.setProgress(new Progress(
            session.getCompletedCount(),
            session.getTotalCount(),
            session.getCorrectCount()
        ));
        
        if (session.getCompletedCount() >= session.getTotalCount()) {
            // 全部完成
            completeSession(session);
            result.setSessionCompleted(true);
        } else if (session.isAdaptiveMode()) {
            // 自适应：选择下一题
            ScoredCandidate nextQuestion = adaptiveEngine.selectNext(
                session, request.isCorrect()
            );
            result.setNextQuestion(toRecommendedQuestion(nextQuestion));
        }
        
        sessionRepo.save(session);
        
        // 6. 更新做题历史
        updateUserQuestionHistory(session.getUserId(), request.getQuestionId(),
            session.getSubjectCode(), request.isCorrect());
        
        // 7. 发布答题事件（供其他模块消费）
        eventPublisher.publishEvent(new PracticeAnswerEvent(
            session.getUserId(), session.getSubjectCode(),
            request.getQuestionId(), request.isCorrect(),
            request.getKnowledgePointId(), abilityAfter
        ));
        
        return result;
    }

    /**
     * 结束会话，生成报告
     */
    private void completeSession(PracticeSession session) {
        session.setStatus(SessionStatus.COMPLETED);
        session.setEndAt(LocalDateTime.now());
        
        // 发布练习完成事件
        eventPublisher.publishEvent(new PracticeCompletedEvent(
            session.getUserId(),
            session.getSubjectCode(),
            session.getId(),
            session.getTotalCount(),
            session.getCorrectCount(),
            session.getTotalTimeSec(),
            session.getInitialAbility(),
            session.getCurrentAbility()
        ));
    }
}
```

| `recommend:kps:{subject}:{chapterId}` | List | 1h | 章节-知识点映射缓存 |
| `recommend:pool:{subject}:{kp_hash}` | List | 30min | 候选题目池缓存 |

```java
@Service
public class RecommendCacheManager {
    
    /**
     * 答题后失效相关缓存
     */
    public void invalidateAfterAnswer(Long userId, String subjectCode) {
        // 画像缓存失效（能力值已更新）
        redisTemplate.delete(
            String.format("recommend:profile:%d:%s", userId, subjectCode)
        );
        // 已做题目集合更新
        redisTemplate.delete(
            String.format("recommend:done:%d:%s", userId, subjectCode)
        );
    }
}
```

```java
@Component
@Slf4j
public class PracticeEventListener {

    /**
     * 错题创建 → 更新知识点推荐权重
     */
    @Async("standardExecutor")
    @EventListener
    public void onMistakeCreated(MistakeCreatedEvent event) {
        // 清除对应知识点的候选池缓存
        cacheManager.invalidateKpPool(event.getSubjectCode(), event.getKnowledgePointId());
        // 更新推荐权重（错题对应知识点权重提升）
        log.info("错题事件处理: userId={}, kpId={}",
            event.getUserId(), event.getKnowledgePointId());
    }

    /**
     * 知识点掌握度更新 → 刷新推荐缓存
     */
    @Async("standardExecutor")
    @EventListener
    public void onMasteryUpdated(MasteryUpdatedEvent event) {
        cacheManager.invalidateProfile(event.getUserId(), event.getSubjectCode());
    }
}
```

| 异常码 | HTTP状态 | 场景 | 处理建议 |
| --- | --- | --- | --- |
| `PRACTICE_001` | 404 | 无符合条件题目 | 扩大知识点范围或降低难度 |
| `PRACTICE_002` | 500 | 推荐服务内部异常 | 重试 |
| `PRACTICE_003` | 404 | 练习会话不存在 | 返回列表页 |
| `PRACTICE_004` | 400 | 会话状态不允许操作 | 刷新页面 |
| `PRACTICE_005` | 409 | 重复提交答题结果 | 幂等忽略 |
| `PRACTICE_006` | 403 | 无权操作该会话 | 返回首页 |
| `PRACTICE_007` | 429 | 推荐请求过于频繁 | 限流（同一用户 10秒内最多1次） |
| `PRACTICE_008` | 400 | 推荐参数无效 | 检查参数 |
| `PRACTICE_009` | 503 | 画像服务不可用 | 使用默认能力值 θ=0 推荐 |
| `PRACTICE_010` | 503 | 题库服务不可用 | 降级返回缓存中的热门题目 |

### 10.2 降级策略

```java
@Component
public class RecommendFallback {

    /**
     * 画像服务不可用时的降级推荐
     */
    public RecommendResult fallbackWithoutProfile(RecommendRequest request) {
        // 使用默认能力 θ=0，均匀难度分布
        // 从题库热门题目中随机选取
        List<Question> popularQuestions = questionService.getPopularQuestions(
            request.getSubjectCode(),
            request.getQuestionCount() * 3  // 扩大候选
        );
        Collections.shuffle(popularQuestions);
        List<Question> selected = popularQuestions.subList(0, request.getQuestionCount());
        
        return buildFallbackResult(selected, "画像服务暂不可用，使用热门题目推荐");
    }

    /**
     * 题库服务不可用时的降级
     */
    public RecommendResult fallbackWithCache(RecommendRequest request) {
        // 尝试从缓存中读取最近一次成功推荐结果
        String cacheKey = String.format("recommend:last:%d:%s",
            request.getUserId(), request.getSubjectCode());
        RecommendResult cached = redisTemplate.opsForValue().get(cacheKey);
        
        if (cached != null) {
            // 标记为降级结果
            cached.setFallback(true);
            cached.setFallbackReason("题库服务暂不可用，使用历史推荐");
            return cached;
        }
        
        // 完全无缓存时返回空
        return RecommendResult.empty("暂时无法推荐题目，请稍后重试");
    }
}
```
