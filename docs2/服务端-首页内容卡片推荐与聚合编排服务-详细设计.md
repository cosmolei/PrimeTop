# 服务端-首页内容卡片推荐与聚合编排服务 — 详细设计

> **模块定位**：本服务是 PrimeTop 学生端首页的**后端推荐与聚合引擎**，负责根据学生画像、学习状态、时间上下文和业务规则，从多个内容源（学习规划、错题复习、自适应推荐、同步课堂、运营活动等）聚合生成个性化首页卡片列表，并以统一的排序策略输出给 BFF 层渲染。

> **关联模块**：
> - 自适应学习与个性化推荐引擎 → 候选题目推荐
> - 学习规划 → 每日任务与里程碑
> - 错题整理 → 待复习错题
> - 同步课堂学习 → 章节进度与继续学习
> - 学情分析 → 薄弱知识点
> - 运营活动与成长激励体系 → 运营卡片
> - 用户学习画像与能力维度模型 → 用户特征
> - 服务端-BFF数据聚合层与多端接口适配设计 → API 消费方
> - 客户端-首页与学习工作台 → 前端渲染

---

## 1. 模块概述

### 1.1 解决的问题

| 问题 | 现状 | 本服务的解决方案 |
|------|------|------------------|
| 首页内容拼凑 | BFF 层直接聚合多个服务，逻辑分散 | 统一编排层集中决策 |
| 卡片排序无策略 | 固定顺序或简单时间排序 | 多因子加权排序 + 上下文感知 |
| 推荐不精准 | 各模块独立推荐，互不感知 | 全局视角去重、平衡、去冲突 |
| 业务规则硬编码 | 运营需求需要客户端发版 | 服务端配置化规则引擎 |
| 新用户首页空 | 无数据时展示固定内容 | 冷启动策略 + 先验推荐 |

### 1.2 核心职责

1. **卡片候选生成**：从各内容源拉取候选卡片数据
2. **过滤与去重**：去除已过期、已曝光、不适龄内容
3. **打分与排序**：多因子加权排序，结合上下文（时间、设备、学段）
4. **业务规则叠加**：运营置顶、强制展示、频次控制
5. **分龄适配**：按学段调整卡片类型权重和展示策略
6. **缓存管理**：结果缓存 + 增量更新

### 1.3 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 首页卡片接口 P95 延迟 | ≤ 200ms | 含缓存命中 |
| 首页卡片接口 P99 延迟 | ≤ 500ms | 缓存未命中 |
| 并发支持 | ≥ 1000 QPS | 高峰期 |
| 缓存命中率 | ≥ 85% | 正常时段 |
| 卡片数量 | 6-15 张 | 根据学段和内容密度 |

### 1.4 设计原则

1. **服务端排序，客户端渲染**：所有排序和筛选逻辑在服务端完成
2. **配置优于硬编码**：权重、规则、阈值通过配置中心管理
3. **渐进式降级**：单个内容源不可用不影响整体首页展示
4. **曝光可控**：追踪卡片曝光，避免重复推荐

```python
from enum import Enum
from dataclasses import dataclass, field
from typing import Optional, Any
from datetime import datetime

class CardType(str, Enum):
    """卡片类型枚举"""
    # === 学习类 ===
    TODAY_TASK = "today_task"               # 今日任务
    CONTINUE_LEARN = "continue_learn"       # 继续学习（同步课堂）
    REVIEW_REMINDER = "review_reminder"     # 错题复习提醒
    WEAK_POINT = "weak_point"               # 薄弱知识点
    RECOMMENDED_PRACTICE = "recommended"    # 推荐练习
    EXAM_COUNTDOWN = "exam_countdown"       # 考试倒计时
    AI_HELPER = "ai_helper"                 # AI 辅导入口

    # === 进度类 ===
    STUDY_STREAK = "study_streak"           # 连续学习天数
    MILESTONE = "milestone"                 # 里程碑/成就
    WEEKLY_REPORT = "weekly_report"         # 周报

    # === 运营类 ===
    BANNER = "banner"                       # 运营 Banner
    ACTIVITY = "activity"                   # 运营活动
    MEMBERSHIP_PROMO = "membership_promo"   # 会员推广

    # === 快捷入口 ===
    QUICK_ACTIONS = "quick_actions"         # 快捷操作区（拍题/AI/同步课堂）
    SUBJECT_TOOLS = "subject_tools"         # 学科工具箱


class CardPriority(str, Enum):
    """卡片优先级"""
    PINNED = "pinned"       # 运营置顶
    HIGH = "high"           # 高优先（今日任务、考试倒计时）
    NORMAL = "normal"       # 正常
    LOW = "low"             # 低优先
    FILLER = "filler"       # 填充（内容不足时）


@dataclass
class HomeCard:
    """首页卡片统一数据模型"""
    card_id: str                    # 卡片唯一 ID (UUID)
    card_type: CardType             # 卡片类型
    title: str                      # 卡片标题
    subtitle: str                   # 副标题/描述
    priority: CardPriority = CardPriority.NORMAL

    # === 排序相关 ===
    score: float = 0.0              # 综合得分（排序依据）
    base_weight: float = 1.0        # 基础权重
    context_boost: float = 0.0      # 上下文加分
    freshness: float = 1.0          # 新鲜度 (0~1)

    # === 关联数据 ===
    payload: dict = field(default_factory=dict)    # 类型特定数据
    action_url: str = ""            # 点击跳转 URL / DeepLink
    action_text: str = ""           # 按钮文案

    # === 展示控制 ===
    expires_at: Optional[datetime] = None   # 过期时间
    max_show_count: int = 0                 # 最大展示次数 (0=无限)
    shown_count: int = 0                    # 已展示次数
    min_interval_hours: int = 0             # 最小展示间隔(小时)

    # === 画像标签 ===
    target_grades: list[str] = field(default_factory=list)   # 目标学段
    target_subjects: list[str] = field(default_factory=list)  # 目标学科
    membership_required: Optional[str] = None   # 所需会员等级 (null=免费)


@dataclass
class HomeCardResponse:
    """首页卡片响应"""
    cards: list[HomeCard]           # 卡片列表
    refresh_token: str              # 刷新令牌（用于增量更新）
    generated_at: datetime          # 生成时间
    ttl_seconds: int = 300          # 客户端缓存时间
    has_more: bool = False          # 是否有更多（下拉加载）
```

```sql
-- 卡片曝光记录表（用于频次控制和去重）
CREATE TABLE home_card_exposure (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id         VARCHAR(36) NOT NULL COMMENT '用户 ID',
    card_id         VARCHAR(64) NOT NULL COMMENT '卡片 ID',
    card_type       VARCHAR(32) NOT NULL COMMENT '卡片类型',

    first_seen_at   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '首次曝光',

    clicked         TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否点击',
    clicked_at      DATETIME DEFAULT NULL COMMENT '点击时间',

    INDEX idx_user_type (user_id, card_type),
    INDEX idx_user_last (user_id, last_seen_at),
    UNIQUE INDEX idx_user_card (user_id, card_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='首页卡片曝光记录';

-- 卡片排序结果缓存表
CREATE TABLE home_card_cache (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id         VARCHAR(36) NOT NULL COMMENT '用户 ID',
    refresh_token   VARCHAR(64) NOT NULL COMMENT '刷新令牌',
    card_data       JSON NOT NULL COMMENT '卡片数据 (序列化后的 HomeCard 列表)',
    context_hash    VARCHAR(32) NOT NULL COMMENT '上下文哈希（用于判断是否需要重新生成）',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    expires_at      DATETIME NOT NULL COMMENT '过期时间',

    UNIQUE INDEX idx_user_token (user_id, refresh_token),
    INDEX idx_user_expires (user_id, expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='首页卡片缓存';

-- 运营置顶/强制展示规则表
CREATE TABLE home_pin_rule (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    card_type       VARCHAR(32) NOT NULL COMMENT '卡片类型',
    card_payload    JSON NOT NULL COMMENT '卡片数据',
    priority        TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '置顶优先级(1最高)',
    position        INT NOT NULL DEFAULT 0 COMMENT '固定位置(0=参与排序)',

    -- 定向条件
    target_grades   JSON COMMENT '目标学段列表',
    target_subjects JSON COMMENT '目标学科列表',
    membership_tier VARCHAR(32) DEFAULT NULL COMMENT '会员等级限制',
    ab_test_group   VARCHAR(32) DEFAULT NULL COMMENT 'A/B 测试分组',

    -- 时间控制
    start_at        DATETIME NOT NULL COMMENT '开始时间',
    end_at          DATETIME NOT NULL COMMENT '结束时间',
    max_show_per_user INT UNSIGNED DEFAULT 0 COMMENT '每用户最大展示次数(0=无限)',

    status          TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '1=启用 0=禁用',
    created_by      VARCHAR(64) NOT NULL COMMENT '创建人',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_status_time (status, start_at, end_at),
    INDEX idx_type (card_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='首页运营置顶规则';
```

#### 4.2.1 编排服务主类

```python
import asyncio
import hashlib
import uuid
from datetime import datetime, timedelta
from typing import Optional
import logging

logger = logging.getLogger(__name__)


class HomeCardOrchestrator:
    """首页卡片编排引擎"""

    # 并发拉取超时
    FETCH_TIMEOUT = 2.0  # 秒

    # 类型平衡限制
    MAX_SAME_TYPE = 3            # 同类型最大卡片数
    MIN_LEARNING_RATIO = 0.6     # 学习类卡片最低比例
    MAX_PROMO_RATIO = 0.2        # 运营类卡片最高比例

    # 学习类卡片类型
    LEARNING_TYPES = {
        CardType.TODAY_TASK, CardType.CONTINUE_LEARN, CardType.REVIEW_REMINDER,
        CardType.WEAK_POINT, CardType.RECOMMENDED_PRACTICE, CardType.EXAM_COUNTDOWN,
        CardType.AI_HELPER,
    }

    PROMO_TYPES = {CardType.BANNER, CardType.ACTIVITY, CardType.MEMBERSHIP_PROMO}

    def __init__(
        self,
        cache_repo: "HomeCacheRepository",
        exposure_repo: "ExposureRepository",
        pin_rule_repo: "PinRuleRepository",
        weight_config_repo: "WeightConfigRepository",
        source_fetchers: dict[str, "CardSourceFetcher"],
        event_publisher: "EventPublisher",
    ):
        self.cache_repo = cache_repo
        self.exposure_repo = exposure_repo
        self.pin_rule_repo = pin_rule_repo
        self.weight_config_repo = weight_config_repo
        self.source_fetchers = source_fetchers
        self.event_publisher = event_publisher

    async def get_cards(
        self,
        user_id: str,
        refresh_token: Optional[str] = None,
        limit: int = 10,
        platform: str = "android",
        app_version: str = "1.0.0",
    ) -> HomeCardResponse:
        """获取首页卡片列表"""

        # ① 检查缓存
        if refresh_token:
            cached = await self.cache_repo.get(user_id, refresh_token)
            if cached and not cached.is_expired():
                # 增量更新：检查是否有强制刷新的事件
                if not await self._has_pending_refresh(user_id):
                    return cached

        # ② 构建推荐上下文
        context = await self._build_context(user_id, platform, app_version)

        # ③ 并行拉取候选卡片
        candidates = await self._fetch_candidates(context)

        # ④ 过滤 & 去重
        filtered = await self._filter_and_dedup(candidates, context)

        # ⑤ 运营规则叠加
        pinned = await self._apply_pin_rules(filtered, context)

        # ⑥ 多因子打分 & 排序
        scored = self._score_and_sort(filtered, context)

        # ⑦ 类型平衡截断
        final_cards = self._balance_and_truncate(scored, pinned, limit, context)

        # ⑧ 写入缓存 & 曝光记录
        token = str(uuid.uuid4())[:16]
        response = HomeCardResponse(
            cards=final_cards,
            refresh_token=token,
            generated_at=datetime.utcnow(),
            ttl_seconds=300,
        )
        await self._save_response(user_id, token, response, context)

        return response

    async def _build_context(
        self, user_id: str, platform: str, app_version: str
    ) -> RecommendationContext:
        """构建推荐上下文"""
        now = datetime.utcnow()

        # 并行获取用户信息、学习状态、画像摘要
        user_profile, study_state, portrait = await asyncio.gather(
            self._get_user_profile(user_id),
            self._get_study_state(user_id),
            self._get_portrait_summary(user_id),
        )

        # 计算时间上下文
        hour = now.hour
        if 6 <= hour < 12:
            time_of_day = "morning"
        elif 12 <= hour < 18:
            time_of_day = "afternoon"
        elif 18 <= hour < 22:
            time_of_day = "evening"
        else:
            time_of_day = "night"

        return RecommendationContext(
            user_id=user_id,
            grade_level=user_profile.grade_level,
            grade_number=user_profile.grade_number,
            subjects=user_profile.subjects,
            membership_tier=user_profile.membership_tier,
            time_of_day=time_of_day,
            day_of_week="weekend" if now.weekday() >= 5 else "weekday",
            is_holiday=await self._check_holiday(now),
            is_exam_season=await self._check_exam_season(user_profile),
            has_pending_tasks=study_state.pending_task_count > 0,
            pending_task_count=study_state.pending_task_count,
            has_overdue_reviews=study_state.overdue_review_count > 0,
            overdue_review_count=study_state.overdue_review_count,
            study_streak_days=study_state.streak_days,
            today_study_minutes=study_state.today_minutes,
            daily_goal_minutes=study_state.daily_goal_minutes,
            last_active_at=study_state.last_active_at,
            weak_subject=portrait.weak_subject,
            weak_knowledge_points=portrait.weak_points[:5],
            current_chapter=portrait.current_chapter,
            platform=platform,
            app_version=app_version,
        )

    async def _fetch_candidates(self, context: RecommendationContext) -> list[HomeCard]:
        """并行拉取各来源的候选卡片"""
        tasks = []
        source_names = []

        for name, fetcher in self.source_fetchers.items():
            tasks.append(fetcher.fetch(context))
            source_names.append(name)

        results = await asyncio.wait_for(
            asyncio.gather(*tasks, return_exceptions=True),
            timeout=self.FETCH_TIMEOUT,
        )

        candidates = []
        for name, result in zip(source_names, results):
            if isinstance(result, Exception):
                logger.warning(f"Card source '{name}' failed: {result}")
                continue
            if result:
                candidates.extend(result)

        logger.info(
            f"Fetched {len(candidates)} candidates from "
            f"{len(source_names)} sources for user {context.user_id}"
        )
        return candidates

    async def _filter_and_dedup(
        self, candidates: list[HomeCard], context: RecommendationContext
    ) -> list[HomeCard]:
        """过滤与去重"""
        # 获取曝光历史
        exposures = await self.exposure_repo.get_recent_exposures(
            context.user_id, hours=24
        )

        seen_types: dict[str, int] = {}      # 同类型计数
        seen_kp: set[str] = set()             # 已出现的知识点
        result = []

        for card in candidates:
            # --- 过滤条件 ---

            # 1. 学段过滤
            if card.target_grades and context.grade_level not in card.target_grades:
                continue

            # 2. 会员过滤
            if card.membership_required and context.membership_tier == "free":
                continue

            # 3. 过期过滤
            if card.expires_at and card.expires_at < datetime.utcnow():
                continue

            # 4. 曝光频次过滤
            exposure = exposures.get(card.card_id)
            if exposure:
                if card.max_show_count > 0 and exposure.count >= card.max_show_count:
                    continue
                if card.min_interval_hours > 0:
                    hours_since = (datetime.utcnow() - exposure.last_seen_at).total_seconds() / 3600
                    if hours_since < card.min_interval_hours:
                        continue
                # 用户主动关闭过
                if exposure.dismissed_at and exposure.clicked == 0:
                    continue

            # 5. 同类型数量限制
            type_count = seen_types.get(card.card_type, 0)
            if type_count >= self.MAX_SAME_TYPE:
                continue

            # 6. 同知识点去重（避免推荐同一知识点的多张卡片）
            card_kps = card.payload.get("knowledge_points", [])
            if card_kps:
                overlap = set(card_kps) & seen_kp
                if len(overlap) >= len(card_kps) * 0.8:  # 80% 重叠则去重
                    continue
                seen_kp.update(card_kps)

            seen_types[card.card_type] = type_count + 1
            result.append(card)

        return result

    async def _apply_pin_rules(
        self, cards: list[HomeCard], context: RecommendationContext
    ) -> list[HomeCard]:
        """叠加运营置顶规则"""
        active_rules = await self.pin_rule_repo.get_active_rules(
            grades=[context.grade_level],
            subjects=context.subjects,
            membership=context.membership_tier,
        )

        pinned = []
        for rule in active_rules:
            # 检查每用户展示次数
            if rule.max_show_per_user > 0:
                exposure = await self.exposure_repo.get_exposure(
                    context.user_id, rule.card_payload["card_id"]
                )
                if exposure and exposure.count >= rule.max_show_per_user:
                    continue

            pin_card = HomeCard(
                card_id=rule.card_payload["card_id"],
                card_type=CardType(rule.card_type),
                title=rule.card_payload["title"],
                subtitle=rule.card_payload.get("subtitle", ""),
                priority=CardPriority.PINNED,
                payload=rule.card_payload,
                action_url=rule.card_payload.get("action_url", ""),
                action_text=rule.card_payload.get("action_text", ""),
            )
            pinned.append((rule.position, pin_card))

            # 从候选列表中移除同类型卡片（避免重复）
            cards = [c for c in cards if c.card_type != pin_card.card_type]

        return pinned, cards

    def _score_and_sort(
        self, cards: list[HomeCard], context: RecommendationContext
    ) -> list[HomeCard]:
        """多因子打分 & 排序"""
        weights = self.weight_config_repo.get_weights()

        for card in cards:
            config = weights.get(card.card_type)
            if not config:
                config = CardWeightConfig(card_type=card.card_type, base_weight=1.0)

            # 基础权重
            base = config.base_weight

            # 学段因子
            grade_factor = config.grade_weights.get(context.grade_level, 1.0)

            # 时间因子
            time_factor = config.time_boosts.get(context.time_of_day, 1.0)

            # 新鲜度因子（越新越高分）
            freshness = card.freshness

            # 上下文加分
            context_boost = self._compute_context_boost(card, context)

            # 紧急度加分
            urgency_bonus = self._compute_urgency_bonus(card, context)

            # 综合得分
            card.score = (
                base
                * grade_factor
                * time_factor
                * freshness
                + context_boost
                + urgency_bonus
            )

        # 按得分降序排序
        cards.sort(key=lambda c: c.score, reverse=True)
        return cards

    def _compute_context_boost(
        self, card: HomeCard, context: RecommendationContext
    ) -> float:
        """计算上下文加分"""
        boost = 0.0

        # 有逾期复习 → 复习卡片加分
        if card.card_type == CardType.REVIEW_REMINDER and context.has_overdue_reviews:
            boost += 3.0 * min(context.overdue_review_count / 5, 1.0)

        # 今日未开始学习 → 任务类卡片加分
        if card.card_type == CardType.TODAY_TASK and context.today_study_minutes < 10:
            boost += 2.0

        # 快到每日目标时间 → 鼓励类卡片加分
        if context.daily_goal_minutes > 0:
            progress = context.today_study_minutes / context.daily_goal_minutes
            if 0.7 <= progress < 1.0:
                if card.card_type == CardType.STUDY_STREAK:
                    boost += 2.0  # "再加把劲" 激励

        # 考试季 → 考试相关卡片加分
        if context.is_exam_season:
            if card.card_type in (CardType.EXAM_COUNTDOWN, CardType.WEAK_POINT):
                boost += 2.0

        # 周末 → 适当降低任务压力，增加推荐探索
        if context.day_of_week == "weekend":
            if card.card_type == CardType.RECOMMENDED_PRACTICE:
                boost += 1.0
            if card.card_type == CardType.TODAY_TASK:
                boost -= 1.0

        # 幼儿阶段 → 增加趣味性卡片，减少压力型卡片
        if context.grade_level == "kindergarten":
            if card.card_type in (CardType.STUDY_STREAK, CardType.MILESTONE):
                boost += 2.0
            if card.card_type in (CardType.EXAM_COUNTDOWN, CardType.WEAK_POINT):
                boost -= 5.0

        # 长时间未活跃 → 降级任务压力
        if context.last_active_at:
            hours_since = (datetime.utcnow() - context.last_active_at).total_seconds() / 3600
            if hours_since > 48:
                if card.card_type == CardType.TODAY_TASK:
                    boost -= 2.0
                if card.card_type in (CardType.STUDY_STREAK, CardType.RECOMMENDED_PRACTICE):
                    boost += 1.5

        return boost

    def _compute_urgency_bonus(
        self, card: HomeCard, context: RecommendationContext
    ) -> float:
        """计算紧急度加分"""
        bonus = 0.0

        payload = card.payload

        # 逾期复习
        if payload.get("overdue", 0) > 0:
            bonus += min(payload["overdue"] * 0.5, 3.0)

        # 考试倒计时 < 7 天
        if card.card_type == CardType.EXAM_COUNTDOWN:
            days = payload.get("days_remaining", 30)
            if days <= 3:
                bonus += 5.0
            elif days <= 7:
                bonus += 3.0
            elif days <= 14:
                bonus += 1.0

        # 正确率极低 (< 30%)
        if card.card_type == CardType.WEAK_POINT:
            accuracy = payload.get("accuracy_rate", 1.0)
            if accuracy < 0.3:
                bonus += 2.0
            elif accuracy < 0.5:
                bonus += 1.0

        return bonus

    def _balance_and_truncate(
        self,
        scored: list[HomeCard],
        pinned: list[tuple[int, HomeCard]],
        limit: int,
        context: RecommendationContext,
    ) -> list[HomeCard]:
        """类型平衡 & 截断"""
        # 快捷操作区固定在顶部
        quick_actions = HomeCard(
            card_id="fixed_quick_actions",
            card_type=CardType.QUICK_ACTIONS,
            title="快捷操作",
            subtitle="",
            priority=CardPriority.PINNED,
        )

        result: list[HomeCard] = []

        # 固定位置：快捷操作
        result.append(quick_actions)

        # 运营置顶卡片
        for position, pin_card in sorted(pinned, key=lambda x: x[0]):
            if position > 0 and position <= len(result):
                result.insert(position, pin_card)
            else:
                result.append(pin_card)

        # 动态卡片（按得分排序）
        remaining_slots = limit - len(result)
        learning_cards = []
        promo_cards = []
        other_cards = []

        for card in scored:
            if card.card_type in self.LEARNING_TYPES:
                learning_cards.append(card)
            elif card.card_type in self.PROMO_TYPES:
                promo_cards.append(card)
            else:
                other_cards.append(card)

        # 学习类卡片占 60%+
        max_promo = max(1, int(remaining_slots * self.MAX_PROMO_RATIO))
        min_learning = max(1, int(remaining_slots * self.MIN_LEARNING_RATIO))

        # 先填充学习类
        for card in learning_cards[:remaining_slots]:
            result.append(card)
            remaining_slots -= 1

        # 补充运营类（限制数量）
        for card in promo_cards[:min(max_promo, remaining_slots)]:
            result.append(card)
            remaining_slots -= 1

        # 补充其他类
        for card in other_cards[:remaining_slots]:
            result.append(card)
            remaining_slots -= 1

        return result[:limit]

    async def _save_response(
        self,
        user_id: str,
        token: str,
        response: HomeCardResponse,
        context: RecommendationContext,
    ):
        """保存缓存 & 更新曝光记录"""
        # 计算上下文哈希（用于判断是否需要重新生成）
        ctx_str = f"{context.user_id}:{context.grade_level}:{context.has_pending_tasks}:{context.overdue_review_count}:{context.today_study_minutes}"
        ctx_hash = hashlib.md5(ctx_str.encode()).hexdigest()

        # 异步保存缓存
        await self.cache_repo.save(
            user_id=user_id,
            token=token,
            response=response,
            context_hash=ctx_hash,
            ttl_seconds=300,
        )

        # 异步更新曝光记录
        exposure_updates = [
            {"user_id": user_id, "card_id": c.card_id, "card_type": c.card_type}
            for c in response.cards
        ]
        await self.exposure_repo.batch_upsert(exposure_updates)
```

```python
from abc import ABC, abstractmethod


class CardSourceFetcher(ABC):
    """卡片来源拉取器接口"""

    @abstractmethod
    async def fetch(self, context: RecommendationContext) -> list[HomeCard]:
        """拉取候选卡片"""
        ...


class TodayTaskFetcher(CardSourceFetcher):
    """今日任务来源"""

    async def fetch(self, context: RecommendationContext) -> list[HomeCard]:
        if not context.has_pending_tasks:
            return []

        # 调用学习规划服务获取今日任务
        tasks = await self.plan_client.get_today_tasks(context.user_id)

        completed = sum(1 for t in tasks if t.status == "completed")
        total = len(tasks)
        pending = total - completed
        estimated = sum(t.estimated_minutes for t in tasks if t.status == "pending")

        return [
            HomeCard(
                card_id=f"today_task_{context.user_id}_{datetime.utcnow().strftime('%Y%m%d')}",
                card_type=CardType.TODAY_TASK,
                title="今日学习任务",
                subtitle=f"{pending} 个任务待完成，预计 {estimated} 分钟",
                priority=CardPriority.HIGH,
                freshness=1.0 if pending > 0 else 0.3,
                payload={
                    "total_tasks": total,
                    "completed_tasks": completed,
                    "pending_tasks": pending,
                    "estimated_minutes": estimated,
                },
                action_url="primetop://tasks/today",
                action_text="开始学习",
                expires_at=datetime.utcnow().replace(hour=23, minute=59),
                max_show_count=3,
                min_interval_hours=2,
            )

class ReviewReminderFetcher(CardSourceFetcher):
    """错题复习提醒来源"""

    async def fetch(self, context: RecommendationContext) -> list[HomeCard]:
        # 幼儿不需要错题复习
        if context.grade_level == "kindergarten":
            return []

        # 调用错题服务获取待复习数据
        review_data = await self.mistake_client.get_pending_reviews(
            context.user_id, limit=50
        )

        if not review_data or review_data.total_count == 0:
            return []

        overdue = review_data.overdue_count
        due_today = review_data.due_today_count

        if due_today == 0 and overdue == 0:
            return []

        # 按学科分组
        subjects = list(set(r.subject for r in review_data.items[:20]))
        kps = list(set(r.knowledge_point for r in review_data.items[:20]))[:5]

        return [
            HomeCard(
                card_id=f"review_reminder_{context.user_id}_{datetime.utcnow().strftime('%Y%m%d')}",
                card_type=CardType.REVIEW_REMINDER,

                    "knowledge_points": kps,
                    "urgent": overdue > 0,

class ExamCountdownFetcher(CardSourceFetcher):
    """考试倒计时来源"""

    async def fetch(self, context: RecommendationContext) -> list[HomeCard]:
        if context.grade_level == "kindergarten":
            return []

        exams = await self.calendar_client.get_upcoming_exams(
            context.user_id, days=30
        )

        if not exams:
            return []

        # 取最近的考试
        nearest = min(exams, key=lambda e: e.days_remaining)

        # 找出薄弱学科
        weak_subjects = []
        if context.weak_subject:
            weak_subjects.append(context.weak_subject)

        return [
            HomeCard(
                card_id=f"exam_cd_{nearest.exam_id}_{context.user_id}",
                card_type=CardType.EXAM_COUNTDOWN,
                title=f"{nearest.exam_name}倒计时",

                priority=CardPriority.HIGH if nearest.days_remaining <= 7 else CardPriority.NORMAL,
                freshness=1.0 if nearest.days_remaining <= 3 else 0.7,
                payload={
                    "exam_id": nearest.exam_id,
                    "exam_name": nearest.exam_name,
                    "days_remaining": nearest.days_remaining,
                    "exam_date": nearest.exam_date.isoformat(),
                    "weak_subjects": weak_subjects,
                    "suggested_action": self._suggest_action(nearest, weak_subjects),
                },
                action_url="primetop://exam/sprint",
                action_text="查看冲刺计划",
                expires_at=datetime.utcnow().replace(hour=23, minute=59),
                max_show_count=1,

            return f"{weak_subjects[0]}·紧急补弱"
```

```python
class CacheRefreshHandler:
    """缓存刷新处理器 — 由事件总线触发"""

    # 事件 → 刷新紧急度映射
    EVENT_URGENCY = {
        "plan.task_completed": "normal",
        "plan.all_tasks_completed": "immediate",
        "review.completed": "normal",
        "mastery.updated": "lazy",
        "chapter.complete": "normal",
        "exam.registered": "immediate",
        "user.profile_changed": "immediate",
        "streak.broken": "immediate",
        "streak.milestone": "immediate",
    }

    async def handle_event(self, event_type: str, payload: dict):
        """处理事件，决定是否刷新缓存"""
        user_id = payload.get("user_id")
        if not user_id:
            return

        urgency = self.EVENT_URGENCY.get(event_type, "lazy")

        if urgency == "immediate":
            # 立即清除缓存，下次请求时重新生成
            await self.cache_repo.invalidate(user_id)
            logger.info(f"Cache invalidated for user {user_id} due to {event_type}")

        elif urgency == "normal":
            # 标记需要刷新，设置短 TTL
            await self.cache_repo.shorten_ttl(user_id, new_ttl_seconds=60)
            logger.info(f"Cache TTL shortened for user {user_id} due to {event_type}")

        else:  # lazy
            # 不做任何操作，等自然过期后重新生成
            pass
```
