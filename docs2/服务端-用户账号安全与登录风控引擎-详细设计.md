# 服务端 - 用户账号安全与登录风控引擎 详细设计

> 版本：1.0 | 创建日期：2026-06-06

## 1. 概述

### 1.1 背景

启硕 PrimeTop 作为面向未成年人的教育产品，用户账号安全具有极高优先级：

- 学生账号内含学习数据、错题本、学情画像等长期积累资产，账号被盗将造成不可逆损失
- 家长绑定的账号可查看孩子学习详情，账号泄露涉及未成年人隐私
- 会员订阅体系下，账号共享/倒卖会直接导致收入损失
- 恶意注册、撞库攻击、短信轰炸等行为会造成短信成本浪费和系统压力
- 《儿童个人信息网络保护规定》要求对未成年人信息采取严格保护措施

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 实时风控 | 登录请求的风控决策延迟 < 100ms（P99），不阻塞正常登录流程 |
| 精准识别 | 异常登录识别准确率 > 95%，误判率 < 0.5% |
| 渐进式处置 | 从静默标记、二次验证到临时锁定，分级别自动处置 |
| 自适应学习 | 基于用户历史行为建立基线，减少误报，适应正常行为变迁 |
| 全链路可审计 | 每次风控决策留存完整上下文，支持事后追溯和策略调优 |
| 隐私合规 | 风控数据采集遵循最小化原则，敏感数据脱敏存储 |

## 2. 风险模型定义

### 2.1 风险因子

风控引擎从多个维度收集风险信号，每个因子产生 0~100 的分项风险分：

| 因子 ID | 因子名称 | 数据来源 | 高风险阈值 | 说明 |
|---------|---------|---------|-----------|------|
| `F01` | 新设备 | 设备管理服务 | 设备首次出现 = 60 分 | 设备指纹在用户历史设备列表中不存在 |
| `F02` | 新 IP 地址 | 网关请求 IP | 首次出现 = 40 分 | IP 在用户近 90 天登录记录中未出现过 |
| `F03` | 高风险 IP | IP 信誉库 | 命中 = 80 分 | IP 在代理/VPN/ Tor 出口节点、黑产库中 |
| `F04` | 异常地理位置 | IP 地理定位 + 历史登录城市 | 跨城市 = 50 分 | 与用户常用地市不一致（排除已知出差/搬家场景） |
| `F05` | 异常时间段 | 用户历史登录时段分布 | 凌晨首次登录 = 30 分 | 登录时间落在用户历史 5% 分位以外的时段 |
| `F06` | 短信验证码高频请求 | Redis 计数器 | 同号码 > 5次/小时 = 70 分 | 防短信轰炸 |
| `F07` | 撞库特征 | 登录失败模式分析 | 批量不同号码同 IP = 90 分 | 短时间内大量不同账号从同一 IP 登录失败 |
| `F08` | 账号异常状态 | 用户账号体系 | 已锁定/注销中 = 100 分 | 尝试登录已被风控锁定的账号 |
| `F09` | 密码错误次数 | Redis 计数器 | > 5 次/30 分钟 = 60 分 | 短时间多次密码错误（预留密码登录场景） |
| `F10` | 设备环境异常 | 设备指纹 SDK | root/模拟器 = 70 分 | 设备处于 root、越狱、模拟器、多开环境 |
| `F11` | 注册异常 | 注册风控共享数据 | 新注册即批量操作 = 50 分 | 新注册账号在极短时间内产生大量操作 |
| `F12` | 账号共享嫌疑 | 设备管理服务 | 同账号 > 5 台设备/月 = 40 分 | 同一账号近期在过多不同设备上登录 |

### 2.2 风险评分模型

综合风险分采用加权求和 + 阈值判定：

```java
/**
 * 风险评分计算
 * 
 * 各因子权重可在管理后台动态配置，支持灰度调整
 */
public class RiskScoreCalculator {

    // 因子权重配置（管理后台可调）
    private final Map<String, Double> factorWeights = Map.of(
        "F01", 1.5,  // 新设备 - 较高权重
        "F02", 1.0,  // 新IP
        "F03", 2.0,  // 高风险IP - 最高权重
        "F04", 1.2,  // 异常地理位置
        "F05", 0.8,  // 异常时间段
        "F06", 1.8,  // 短信轰炸
        "F07", 2.0,  // 撞库特征
        "F08", 3.0,  // 账号已锁定
        "F09", 1.5,  // 密码错误
        "F10", 1.5,  // 设备环境异常
        "F11", 1.2,  // 注册异常
        "F12", 1.0   // 账号共享嫌疑
    );

    /**
     * 计算综合风险分
     * @param factorScores 各因子分项得分 (0-100)
     * @return 综合风险分 (0-100)
     */
    public RiskAssessmentResult calculate(Map<String, Integer> factorScores) {
        double weightedSum = 0;
        double weightTotal = 0;
        
        for (Map.Entry<String, Integer> entry : factorScores.entrySet()) {
            String factorId = entry.getKey();
            int score = entry.getValue();
            double weight = factorWeights.getOrDefault(factorId, 1.0);
            
            weightedSum += score * weight;
            weightTotal += weight;
        }
        
        int compositeScore = weightTotal > 0 
            ? (int) Math.min(100, (weightedSum / weightTotal)) 
            : 0;
        
        RiskLevel level = determineRiskLevel(compositeScore);
        
        return new RiskAssessmentResult(compositeScore, level, factorScores);
    }

    private RiskLevel determineRiskLevel(int score) {
        if (score >= 80) return RiskLevel.BLOCK;      // 阻断
        if (score >= 60) return RiskLevel.CHALLENGE;   // 挑战验证
        if (score >= 40) return RiskLevel.MONITOR;     // 静默监控
        return RiskLevel.PASS;                          // 放行
    }
}
```

### 2.3 风险等级与处置策略

| 风险等级 | 分值范围 | 处置动作 | 用户体验 |
|---------|---------|---------|---------|
| `PASS` | 0 ~ 39 | 正常放行，记录日志 | 无感知 |
| `MONITOR` | 40 ~ 59 | 放行但标记为监控会话，加强后续行为监测 | 无感知（后台标记） |
| `CHALLENGE` | 60 ~ 79 | 要求二次验证（短信验证码 / 滑动验证 / 人脸识别） | 需完成额外验证步骤 |
| `BLOCK` | 80 ~ 100 | 拒绝登录，账号临时锁定 30 分钟 | 提示"检测到异常登录，请稍后再试" |

### 4.2 风险评估详细流程

```java
/**
 * 登录风控评估服务
 */
@Service
public class LoginRiskAssessmentService {

    @Autowired
    private UserLoginDeviceRepository deviceRepo;
    @Autowired
    private UserLoginBaselineRepository baselineRepo;
    @Autowired
    private IpReputationService ipReputationService;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private RiskScoreCalculator scoreCalculator;
    @Autowired
    private RiskActionRuleService ruleService;

    /**
     * 执行登录风控评估
     * @param request 登录风控请求
     * @return 风控决策结果
     */
    public RiskDecision assess(LoginRiskRequest request) {
        long startTime = System.currentTimeMillis();
        Map<String, Integer> factorScores = new LinkedHashMap<>();

        // ---- 因子评估（并行执行，总耗时取决于最慢的因子） ----

        // F01: 新设备检测
        factorScores.put("F01", evaluateNewDevice(request));

        // F02: 新IP检测
        factorScores.put("F02", evaluateNewIp(request));

        // F03: 高风险IP检测（查询IP信誉库）
        factorScores.put("F03", evaluateIpReputation(request));

        // F04: 异常地理位置
        factorScores.put("F04", evaluateGeoAnomaly(request));

        // F05: 异常时间段
        factorScores.put("F05", evaluateTimeAnomaly(request));

        // F06: 短信轰炸检测
        factorScores.put("F06", evaluateSmsBombing(request));

        // F07: 撞库特征检测
        factorScores.put("F07", evaluateCredentialStuffing(request));

        // F08: 账号状态检查
        factorScores.put("F08", evaluateAccountStatus(request));

        // F09: 密码错误次数
        factorScores.put("F09", evaluatePasswordFailures(request));

        // F10: 设备环境检测
        factorScores.put("F10", evaluateDeviceEnvironment(request));

        // F11: 注册异常
        factorScores.put("F11", evaluateRegistrationAnomaly(request));

        // F12: 账号共享嫌疑
        factorScores.put("F12", evaluateAccountSharing(request));

        // ---- 综合评分 ----
        RiskAssessmentResult result = scoreCalculator.calculate(factorScores);

        // ---- 匹配处置规则 ----
        RiskAction action = ruleService.matchAction(result.getRiskLevel(), 
                                                      factorScores, 
                                                      request.getUserType());

        long evalTime = System.currentTimeMillis() - startTime;

        // ---- 记录风控事件 ----
        saveRiskEvent(request, result, action, factorScores, evalTime);

        return new RiskDecision(result, action);
    }
}
```

private int evaluateNewDevice(LoginRiskRequest request) {
    if (request.getUserId() == null || request.getDeviceFingerprint() == null) {
        return 30; // 未登录或无设备信息，中等风险
    }
    
    Optional<UserLoginDevice> device = deviceRepo
        .findByUserIdAndDeviceFingerprint(request.getUserId(), request.getDeviceFingerprint());
    
    if (device.isEmpty()) {
        return 60; // 完全新设备
    }
    
    if (device.get().getIsTrusted() == 1) {
        return 0;  // 已信任设备
    }
    
    // 非信任但已出现过，根据登录次数递减风险
    int loginCount = device.get().getLoginCount();
    if (loginCount >= 10) return 10;
    if (loginCount >= 5)  return 20;
    return 35;
}

### 6.2 挑战验证状态机

```java
/**
 * 挑战验证状态机
 */
public enum ChallengeState {
    PENDING,        // 已下发，等待用户响应
    VERIFIED,       // 验证通过
    FAILED,         // 验证失败（单次）
    MAX_RETRIES,    // 达到最大重试次数，触发锁定
    EXPIRED;        // 超时未响应

    /**
     * 执行状态转换
     */
    public static ChallengeState transition(ChallengeState current, 
                                             boolean verifyResult, 
                                             int attempts, 
                                             int maxAttempts) {
        return switch (current) {
            case PENDING -> {
                if (verifyResult) yield VERIFIED;
                if (attempts >= maxAttempts) yield MAX_RETRIES;
                yield FAILED;  // 失败但仍可重试，实际状态回到PENDING等待下次提交
            }
            case VERIFIED -> VERIFIED;  // 终态
            case MAX_RETRIES -> MAX_RETRIES;  // 终态
            case EXPIRED -> EXPIRED;  // 终态
            default -> throw new IllegalStateException("Unexpected state: " + current);
        };
    }
}

@Service
public class ChallengeSessionService {

    /**
     * 创建挑战会话
     */
    public ChallengeSession createChallenge(Long userId, 
                                             String phone,
                                             ChallengeType type,
                                             RiskDecision decision) {
        String challengeId = "ch_" + UUID.randomUUID().toString("N");
        
        ChallengeSession session = new ChallengeSession();
        session.setChallengeId(challengeId);
        session.setUserId(userId);
        session.setPhone(phone);
        session.setType(type);
        session.setRiskEventId(decision.getEventId());
        session.setAttempts(0);
        session.setMaxAttempts(type.getMaxAttempts());
        session.setExpiresAt(LocalDateTime.now().plusSeconds(type.getTimeoutSeconds()));
        session.setState(ChallengeState.PENDING);
        
        // 存储到 Redis
        String key = "challenge:" + challengeId;
        redisTemplate.opsForValue().set(key, 
            JsonUtils.toJson(session), 
            Duration.ofSeconds(type.getTimeoutSeconds()));
        
        // 发送验证码/生成验证数据
        dispatchChallenge(session);
        
        return session;
    }

    /**
     * 验证挑战响应
     */
    public ChallengeResult verify(String challengeId, String response) {
        String key = "challenge:" + challengeId;
        String sessionJson = redisTemplate.opsForValue().get(key);
        
        if (sessionJson == null) {
            return ChallengeResult.expired("验证会话已过期，请重新登录");
        }
        
        ChallengeSession session = JsonUtils.fromJson(sessionJson, ChallengeSession.class);
        
        if (session.getState() == ChallengeState.EXPIRED) {
            return ChallengeResult.expired("验证已超时");
        }
        
        if (session.getAttempts() >= session.getMaxAttempts()) {
            // 达到最大尝试次数 → 锁定
            lockAccount(session.getUserId(), "challenge_max_retries", 30);
            redisTemplate.delete(key);
            return ChallengeResult.locked("验证次数过多，账号已临时锁定30分钟");
        }
        
        session.setAttempts(session.getAttempts() + 1);
        
        // 校验响应
        boolean valid = validateResponse(session, response);
        
        if (valid) {
            session.setState(ChallengeState.VERIFIED);
            redisTemplate.delete(key);
            return ChallengeResult.success();
        } else {
            // 更新尝试次数
            redisTemplate.opsForValue().set(key, JsonUtils.toJson(session));
            int remaining = session.getMaxAttempts() - session.getAttempts();
            return ChallengeResult.failed("验证失败，还可尝试" + remaining + "次", remaining);
        }
    }
}

public class AccountLockService {

            Map.of("reason", reason, "duration", durationMinutes));
    }

    /**
     * 检查账号是否被锁定
     */
    public LockStatus checkLock(Long userId) {
        String lockKey = "login_lock:" + userId;
        String lockInfoJson = redisTemplate.opsForValue().get(lockKey);
        
        if (lockInfoJson == null) {
            return LockStatus.notLocked();
        }
        
        LockInfo lockInfo = JsonUtils.fromJson(lockInfoJson, LockInfo.class);
        return new LockStatus(true, lockInfo.getReason(), lockInfo.getUnlockAt());
    }

        redisTemplate.delete(lockKey);

### 10.1 IP 信誉查询

@Service
public class IpReputationService {

    /**
     * 查询IP信誉（带缓存）
     */
    public IpReputation lookup(String ip) {
        // 1. 查 Redis 缓存
        String cacheKey = "ip_rep:" + ip;
        String cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return JsonUtils.fromJson(cached, IpReputation.class);
        }
        
        // 2. 查数据库
        Optional<IpReputation> dbResult = ipReputationRepo.findByIpAddress(ip);
        if (dbResult.isPresent()) {
            IpReputation rep = dbResult.get();
            // 写入缓存，TTL 根据数据时效设定
            long ttlSeconds = rep.getExpiresAt() != null 
                ? Duration.between(LocalDateTime.now(), rep.getExpiresAt()).getSeconds()
                : 86400;
            if (ttlSeconds > 0) {
                redisTemplate.opsForValue().set(cacheKey, 
                    JsonUtils.toJson(rep), 
                    Duration.ofSeconds(Math.min(ttlSeconds, 86400)));
            }
            return rep;
        }
        
        // 3. 调用外部 IP 信誉 API（按需，有日配额限制）
        IpReputation external = queryExternalIpReputation(ip);
        if (external != null) {
            // 异步入库
            asyncSaveIpReputation(external);
            redisTemplate.opsForValue().set(cacheKey, 
                JsonUtils.toJson(external), 
                Duration.ofHours(24));
            return external;
        }
        
        return null; // 未知IP，低风险
    }
}
```

### 10.2 IP 前缀匹配（CIDR 级别）

对于 VPN/代理服务的 IP 段，需要支持前缀匹配而非精确匹配：

```java
/**
 * 检查IP是否属于已知风险网段
 */
public boolean isInRiskSubnet(String ip) {
    String[] octets = ip.split("\\.");
    // 检查 /24 前缀
    String prefix24 = octets[0] + "." + octets[1] + "." + octets[2];
    // 检查 /16 前缀
    String prefix16 = octets[0] + "." + octets[1];
    
    return ipReputationRepo.existsRiskByPrefix(prefix24)
        || ipReputationRepo.existsRiskByPrefix(prefix16);
}
```

## 12. 降级与容错

### 12.1 风控服务降级策略

风控服务不可用时，不能阻塞正常登录流程：

```java
@Aspect
@Component
public class RiskAssessmentCircuitBreaker {

    private final CircuitBreaker circuitBreaker;

    public RiskAssessmentCircuitBreaker() {
        this.circuitBreaker = CircuitBreaker.ofDefaults("riskAssessment")
            .toBuilder()
            .failureRateThreshold(50)       // 失败率 50% 触发熔断
            .waitDurationInOpenState(Duration.ofSeconds(30))  // 熔断 30 秒
            .permittedNumberOfCallsInHalfOpenState(5)          // 半开状态允许 5 次试探
            .slidingWindowSize(20)                            // 滑动窗口 20 次调用
            .build();
    }

    @Around("execution(* com.primetop.risk.LoginRiskAssessmentService.assess(..))")
    public Object assessWithFallback(ProceedingJoinPoint joinPoint) throws Throwable {
        return circuitBreaker.executeSupplier(() -> {
            try {
                return joinPoint.proceed();
            } catch (Throwable e) {
                throw new RuntimeException(e);
            }
        }, () -> {
            // 降级策略：风控不可用时放行，但记录日志
            log.warn("风控服务降级，登录请求放行");
            auditLogService.log(AuditAction.RISK_SERVICE_DEGRADED, null,
                Map.of("action", "pass_through"));
            return RiskDecision.passWithMonitor("risk_service_degraded");
        });
    }
}
```

## 16. 安全与隐私

### 16.1 数据脱敏

- 手机号在日志和风控事件中脱敏存储：`138****1234`
- IP 地址在风控事件表中存储原文（后续审计需要），但管理后台展示时对非管理员脱敏
- 设备指纹为哈希值，不包含可逆的设备信息

### 16.2 数据最小化

- 风控日志仅记录必要的风险评估上下文，不记录用户学习行为
- Redis 中的风控数据均设置 TTL，不无限期保留
- IP 信誉信息仅存储风险类别和地理位置，不关联具体用户

### 16.3 未成年人保护

- 学生账号被锁定时，推送通知给绑定的家长账号
- 家长可在家长中心查看孩子的登录设备列表
- 可疑登录被拦截时，同步通知家长

## 17. 客户端对接

### 17.1 客户端处理流程

```dart
// Flutter 客户端登录处理示例
Future<LoginResult> login(String phone, String smsCode) async {
  try {
    final response = await api.post('/api/v1/auth/login', body: {
      'phone': phone,
      'smsCode': smsCode,
      'deviceFingerprint': await getDeviceFingerprint(),
      'platform': Platform.operatingSystem,
    });
    
    return LoginResult.success(
      accessToken: response['accessToken'],
      refreshToken: response['refreshToken'],
    );
    
  } on ApiException catch (e) {
    switch (e.errorCode) {
      case 'RISK_CHALLENGE_REQUIRED':
        // 需要二次验证
        final challenge = ChallengeData.fromJson(e.data);
        final challengeResult = await showChallengeDialog(challenge);
        if (challengeResult != null) {
          return await submitChallenge(challenge.challengeId, challengeResult);
        }
        return LoginResult.cancelled();
        
      case 'RISK_ACCOUNT_LOCKED':
        // 账号被锁定
        final unlockAt = DateTime.parse(e.data['unlockAt']);
        showLockDialog(unlockAt);
        return LoginResult.locked(unlockAt);
        
      case 'RISK_LOGIN_BLOCKED':
        // 登录被拒绝
        showBlockedDialog();
        return LoginResult.blocked();
        
      default:
        rethrow;
    }
  }
}
```
