# 服务端-学生答题犹豫度分析与知识点掌握信心度评估引擎-详细设计

## 1. 概述

### 1.1 模块定位

本引擎是 PrimeTop 学情分析体系中的**精细化行为诊断组件**，专注于从学生答题过程中的微观时间行为和交互模式中，提取**犹豫度（Hesitation Score）**和**信心度（Confidence Level）**两个关键指标。

与已有的"答题过程行为追踪引擎"（关注思维路径可视化）和"练习答题行为数据采集引擎"（关注原始数据采集）不同，本引擎的核心职责是：

1. **犹豫度量化**：通过作答时间、答案修改频次、驻留时长等微观行为信号，量化学生在每道题目上的犹豫程度。
2. **信心度推断**：结合犹豫度信号、正确率、历史表现，区分"真掌握"、"猜对"、"蒙对"、"会但不自信"等不同掌握状态。
3. **知识点信心画像**：将逐题信心度聚合到知识点维度，形成带信心区间的能力评估。
4. **教学干预建议**：对"会但不自信"和"蒙对"的学生生成精准的信心建设训练建议。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 犹豫度计算延迟 | 单题犹豫度计算 < 50ms（同步） |
| 信心度评估延迟 | 批量评估（50题以内）< 500ms |
| 信号采集维度 | ≥ 8 种行为信号 |
| 信心度准确率 | 与二次测试结果的一致性 ≥ 80% |
| 知识点信心覆盖率 | 活跃知识点的信心度数据覆盖率 ≥ 95% |

### 1.3 适用范围

- **学段**：小学三年级及以上（低年级交互行为噪声大，需特殊处理）
- **题型**：选择题、填空题、判断题（主观题通过语音/文本停顿分析扩展）
- **场景**：日常练习、章节测试、模拟考试（不含限时冲刺模式下的极速作答）

### 1.4 核心概念定义

| 概念 | 定义 |
| --- | --- |
| **犹豫度 Hesitation Score** | 0-100 的连续值，表示学生在该题上表现出的不确定程度。0 = 毫不犹豫，100 = 极度犹豫 |
| **信心度 Confidence Level** | 枚举值：HIGH（高信心正确）/ LIKELY（较有信心）/ UNSURE（不确定）/ GUESS（猜测）/ LOW（低信心错误） |
| **作答时间偏差比 TDR** | Time Deviation Ratio = 实际作答时间 / 预期作答时间。TDR > 1.5 且答对可能意味着"会但不自信" |
| **答案修改次数 AMC** | Answer Modification Count。学生提交答案前的修改次数 |
| **页面切换频次 PSF** | Page Switch Frequency。答题过程中切出/切入页面的次数 |
| **知识点信心区间** | 对某知识点的掌握信心范围，如 [0.65, 0.85]，表示真实掌握概率落在此区间的置信度 |

## 4. 核心算法设计

### 4.1 犹豫度计算模型

犹豫度计算采用**多信号加权融合**策略，每个信号先独立归一化到 0-100，再加权求和。

#### 4.1.1 信号归一化

```python
import numpy as np
from typing import Optional

class HesitationSignalNormalizer:
    """将原始行为信号归一化到 0-100 的犹豫贡献分"""

    @staticmethod
    def normalize_time_deviation(
        actual_ms: int,
        expected_mean_ms: int,
        expected_std_ms: int
    ) -> float:
        """
        作答时间偏差信号 → 犹豫贡献分
        TDR = actual / expected
        TDR ≤ 0.8: 可能太快（猜测倾向），贡献中等分
        TDR ≈ 1.0: 正常，贡献低分
        TDR > 1.5: 明显犹豫，贡献高分
        """
        if expected_mean_ms <= 0:
            return 50.0  # 无基线数据时给中等分

        tdr = actual_ms / expected_mean_ms

        if tdr <= 0.5:
            # 过快可能意味着猜测
            return 60.0
        elif tdr <= 0.8:
            return 25.0
        elif tdr <= 1.2:
            # 正常范围
            return 10.0
        elif tdr <= 1.8:
            # 轻度超时
            ratio = (tdr - 1.2) / 0.6  # 0→1
            return 25.0 + ratio * 35.0  # 25→60
        elif tdr <= 3.0:
            # 明显超时
            ratio = (tdr - 1.8) / 1.2
            return 60.0 + ratio * 25.0  # 60→85
        else:
            # 极端超时
            return 95.0

    @staticmethod
    def normalize_answer_changes(
        change_count: int,
        max_expected: int = 0
    ) -> float:
        """
        答案修改次数 → 犹豫贡献分
        0次: 满分确定（低犹豫）
        1次: 轻微犹豫
        2次: 中度犹豫
        ≥3次: 高度犹豫
        """
        mapping = {0: 10, 1: 35, 2: 60, 3: 80}
        if change_count >= 4:
            return 95.0
        return mapping.get(change_count, 95.0)

    @staticmethod
    def normalize_page_blur(
        blur_count: int,
        blur_total_ms: int,
        total_time_ms: int
    ) -> float:
        """
        页面失焦 → 犹豫贡献分
        频繁切出可能意味着查询资料、犹豫不决或注意力分散
        """
        if total_time_ms <= 0:
            return 50.0

        blur_ratio = blur_total_ms / total_time_ms

        # 次数维度
        count_score = min(blur_count * 20, 80)

        # 时长占比维度
        ratio_score = min(blur_ratio * 200, 80)

        # 取较大值
        return min(max(count_score, ratio_score), 95.0)

    @staticmethod
    def normalize_first_input_delay(
        delay_ms: int,
        expected_delay_ms: int = 3000
    ) -> float:
        """
        首次输入延迟 → 犹豫贡献分
        过长延迟可能意味着审题困难或犹豫
        """
        if delay_ms <= 0:
            return 60.0  # 无数据

        ratio = delay_ms / expected_delay_ms if expected_delay_ms > 0 else 1.0

        if ratio <= 1.0:
            return 15.0
        elif ratio <= 2.0:
            return 30.0 + (ratio - 1.0) * 30.0  # 30→60
        elif ratio <= 4.0:
            return 60.0 + (ratio - 2.0) * 12.5  # 60→85
        else:
            return 90.0

    @staticmethod
    def normalize_cursor_pause(
        pause_count: Optional[int],
        pause_ratio: Optional[float]
    ) -> float:
        """
        光标停顿 → 犹豫贡献分（移动端可选信号）
        """
        if pause_count is None or pause_ratio is None:
            return 30.0  # 无数据时给中等偏低分

        count_score = min(pause_count * 15, 75)
        ratio_score = min(pause_ratio * 150, 75)
        return max(count_score, ratio_score) * 0.7 + 15  # 降低权重因数据不全
```

#### 4.1.2 加权融合模型

```python
class HesitationScorer:
    """
    多信号加权融合犹豫度评分器
    权重通过历史数据回归训练得到，可按年级/学科/题型差异化配置
    """

    # 默认权重（总和新等于1.0）
    DEFAULT_WEIGHTS = {
        "time": 0.35,
        "answer_change": 0.25,
        "page_blur": 0.15,
        "first_input_delay": 0.15,
        "cursor_pause": 0.10,
    }

    def __init__(self, weights: dict = None):
        self.weights = weights or self.DEFAULT_WEIGHTS

    def compute_hesitation(
        self,
        signals: dict,
        is_correct: bool,
        difficulty: float
    ) -> tuple[float, dict]:
        """
        计算综合犹豫度

        Args:
            signals: 归一化后的各信号分数
                {
                    "time": float,
                    "answer_change": float,
                    "page_blur": float,
                    "first_input_delay": float,
                    "cursor_pause": float
                }
            is_correct: 是否答对
            difficulty: 题目难度 0-1

        Returns:
            (hesitation_score: float, factor_breakdown: dict)
        """
        normalizer = HesitationSignalNormalizer()

        # 难度修正：难题的犹豫度天然偏高，需适当下调
        difficulty_factor = 1.0 - (difficulty - 0.5) * 0.3  # 0.85 ~ 1.15
        difficulty_factor = max(0.8, min(1.2, difficulty_factor))

        # 加权求和
        total = 0.0
        factor_breakdown = {}

        for signal_name, raw_score in signals.items():
            weight = self.weights.get(signal_name, 0.0)
            if weight > 0:
                contribution = raw_score * weight * difficulty_factor
                total += contribution
                factor_breakdown[signal_name] = round(contribution, 2)

        # 限制范围
        hesitation_score = max(0.0, min(100.0, round(total, 1)))

        return hesitation_score, factor_breakdown

    @staticmethod
    def score_to_level(score: float) -> str:
        """犹豫度分数 → 等级"""
        if score <= 15:
            return "NONE"
        elif score <= 35:
            return "LOW"
        elif score <= 60:
            return "MEDIUM"
        elif score <= 80:
            return "HIGH"
        else:
            return "EXTREME"
```

### 4.2 信心度推断模型

信心度推断综合考虑犹豫度、作答结果和题目难度，输出一个 5 分类标签和连续概率值。

#### 4.2.1 规则 + 概率混合模型

```python
class ConfidenceInferencer:
    """
    信心度推断器
    采用「规则初筛 + 概率校准」的两阶段策略
    """

    def __init__(self, model=None):
        """
        Args:
            model: 预训练的 LightGBM 模型（特征→信心概率）
        """
        self.model = model

    def infer_confidence(
        self,
        hesitation_score: float,
        is_correct: bool,
        difficulty: float,
        time_deviation_ratio: float,
        answer_change_count: int,
        historical_accuracy: float,
        historical_hesitation: float
    ) -> dict:
        """
        推断单题信心度

        Returns:
            {
                "level": ConfidenceLevel,
                "probability": float,  # 真掌握概率 0-1
                "interval_low": float,
                "interval_high": float,
                "tags": list[str]
            }
        """
        # 阶段1: 规则初筛
        level, tags = self._rule_based_classify(
            hesitation_score, is_correct, difficulty,
            time_deviation_ratio, answer_change_count
        )

        # 阶段2: 概率校准
        if self.model is not None:
            probability = self._model_predict(
                hesitation_score, is_correct, difficulty,
                time_deviation_ratio, answer_change_count,
                historical_accuracy, historical_hesitation
            )
        else:
            probability = self._heuristic_probability(
                level, hesitation_score, is_correct, difficulty
            )

        # 计算置信区间
        interval_low, interval_high = self._compute_confidence_interval(
            probability, sample_evidence=1
        )

        # 概率微调规则初筛结果
        level = self._reconcile_level_probability(level, probability, is_correct)

        return {
            "level": level,
            "probability": round(probability, 3),
            "interval_low": round(interval_low, 3),
            "interval_high": round(interval_high, 3),
            "tags": tags
        }

    def _rule_based_classify(
        self,
        hesitation: float,
        is_correct: bool,
        difficulty: float,
        tdr: float,
        change_count: int
    ) -> tuple[str, list[str]]:
        """规则初筛"""

        tags = []

        if is_correct:
            if hesitation <= 15 and tdr <= 1.2:
                tags.append("CONFIDENT")
                return ConfidenceLevel.HIGH, tags

            if hesitation <= 35 and change_count == 0:
                tags.append("SOLID")
                return ConfidenceLevel.LIKELY, tags

            if tdr <= 0.6 and hesitation <= 20:
                tags.append("GUESSED_RIGHT")
                return ConfidenceLevel.GUESS, tags

            if change_count >= 2:
                tags.append("UNSTABLE")
                return ConfidenceLevel.UNSURE, tags

            if hesitation >= 60:
                tags.append("SLOW_BUT_RIGHT")
                return ConfidenceLevel.UNSURE, tags

            # 默认
            return ConfidenceLevel.LIKELY, tags

        else:  # is_correct = False
            if tdr <= 0.5:
                tags.append("FAST_WRONG")
                return ConfidenceLevel.LOW, tags

            if hesitation >= 60:
                tags.append("HESITATED_WRONG")
                return ConfidenceLevel.LOW, tags

            if change_count >= 3:
                tags.append("UNSTABLE")
                return ConfidenceLevel.LOW, tags

            tags.append("FAST_WRONG")
            return ConfidenceLevel.LOW, tags

    def _heuristic_probability(
        self,
        level: str,
        hesitation: float,
        is_correct: bool,
        difficulty: float
    ) -> float:
        """无模型时的启发式概率估计"""

        base_probs = {
            ConfidenceLevel.HIGH: 0.95,
            ConfidenceLevel.LIKELY: 0.80,
            ConfidenceLevel.UNSURE: 0.55,
            ConfidenceLevel.GUESS: 0.40,
            ConfidenceLevel.LOW: 0.20,
        }

        prob = base_probs.get(level, 0.5)

        # 犹豫度微调
        hesitation_adjustment = (50 - hesitation) / 200.0  # -0.25 ~ +0.25
        prob += hesitation_adjustment

        # 难度微调（难题答对信心略降）
        if is_correct:
            prob -= (difficulty - 0.5) * 0.1
        else:
            prob += (difficulty - 0.5) * 0.05  # 难题答错信心略高

        return max(0.05, min(0.98, prob))

    def _model_predict(
        self,
        hesitation: float,
        is_correct: bool,
        difficulty: float,
        tdr: float,
        change_count: int,
        hist_accuracy: float,
        hist_hesitation: float
    ) -> float:
        """使用 LightGBM 模型预测真掌握概率"""
        import lightgbm as lgb
        import numpy as np

        features = np.array([[
            hesitation, int(is_correct), difficulty,
            tdr, change_count, hist_accuracy, hist_hesitation
        ]])

        # model 输出的是"真掌握"概率
        return float(self.model.predict(features)[0])

    @staticmethod
    def _compute_confidence_interval(
        probability: float,
        sample_evidence: int,
        z: float = 1.96
    ) -> tuple[float, float]:
        """
        基于证据量计算 Wilson 置信区间
        样本越少，区间越宽
        """
        n = max(sample_evidence, 1)

        denominator = 1 + z * z / n
        center = (probability + z * z / (2 * n)) / denominator
        spread = z * np.sqrt(probability * (1 - probability) / n + z * z / (4 * n * n)) / denominator

        low = max(0.0, center - spread)
        high = min(1.0, center + spread)

        return low, high

    @staticmethod
    def _reconcile_level_probability(
        level: str,
        probability: float,
        is_correct: bool
    ) -> str:
        """当概率与规则标签明显矛盾时，修正标签"""
        if is_correct and probability < 0.4 and level in (ConfidenceLevel.HIGH, ConfidenceLevel.LIKELY):
            return ConfidenceLevel.GUESS
        if not is_correct and probability > 0.7:
            # 概率很高但答错 → 可能是粗心
            pass  # 保持 LOW
        return level
```

### 4.3 知识点信心度聚合算法

```python
class KnowledgePointConfidenceAggregator:
    """
    将逐题信心度聚合到知识点维度
    采用贝叶斯增量更新，避免重新全量计算
    """

    def __init__(self, db_session):
        self.db = db_session

    async def update_knowledge_point_confidence(
        self,
        student_id: int,
        knowledge_point_id: int,
        subject: str,
        question_result: dict
    ) -> dict:
        """
        增量更新知识点信心度

        Args:
            question_result: 单题评估结果
                {
                    "hesitation_score": float,
                    "confidence_level": str,
                    "confidence_probability": float,
                    "is_correct": bool,
                    "difficulty": float,
                    "question_id": int
                }
        """
        # 获取当前快照
        current = await self._get_current_snapshot(student_id, knowledge_point_id)

        # 增量更新统计
        updated = self._incremental_update(current, question_result)

        # 计算趋势
        updated["trend_direction"] = self._compute_trend(
            updated.get("confidence_trend", [])
        )

        # 判断是否需要信心建设训练
        updated["needs_confidence_build"] = self._check_confidence_build_need(updated)

        # 持久化
        await self._save_snapshot(student_id, knowledge_point_id, updated)

        return updated

    def _incremental_update(self, current: dict, result: dict) -> dict:
        """贝叶斯增量更新"""
        updated = current.copy()

        updated["total_questions"] = current.get("total_questions", 0) + 1
        updated["correct_count"] = current.get("correct_count", 0) + (1 if result["is_correct"] else 0)
        updated["correct_rate"] = updated["correct_count"] / updated["total_questions"]

        # 信心度计数
        level = result["confidence_level"]
        count_keys = {
            ConfidenceLevel.HIGH: "high_confidence_count",
            ConfidenceLevel.LIKELY: "likely_confidence_count",
            ConfidenceLevel.UNSURE: "unsure_confidence_count",
            ConfidenceLevel.GUESS: "guess_confidence_count",
            ConfidenceLevel.LOW: "low_confidence_count",
        }
        count_key = count_keys.get(level, "unsure_confidence_count")
        updated[count_key] = current.get(count_key, 0) + 1

        # 滑动平均犹豫度
        alpha = 0.15  # EMA 平滑因子
        updated["avg_hesitation"] = (
            current.get("avg_hesitation", 50) * (1 - alpha)
            + result["hesitation_score"] * alpha
        )

        # 信心概率滑动平均
        updated["avg_confidence_prob"] = (
            current.get("avg_confidence_prob", 0.5) * (1 - alpha)
            + result["confidence_probability"] * alpha
        )

        # 有效掌握度 = Σ(信心概率_i * indicator(答对_i)) / N
        prev_effective = current.get("effective_mastery", 0.5)
        prev_total = max(updated["total_questions"] - 1, 1)
        prev_sum = prev_effective * prev_total
        new_contribution = result["confidence_probability"] if result["is_correct"] else 0
        updated["effective_mastery"] = (prev_sum + new_contribution) / updated["total_questions"]

        # 虚高掌握风险 = 蒙对比例
        guess_right = updated.get("guess_confidence_count", 0)
        updated["false_mastery_risk"] = guess_right / max(updated["total_questions"], 1)

        # 带信心的掌握度（仅 HIGH + LIKELY 且答对）
        confident_correct = (
            updated.get("high_confidence_count", 0) +
            updated.get("likely_confidence_count", 0)
        )
        updated["mastery_with_confidence"] = confident_correct / max(updated["total_questions"], 1)

        # 更新趋势序列（保留最近20个）
        trend = current.get("confidence_trend", [])
        trend.append(result["confidence_probability"])
        if len(trend) > 20:
            trend = trend[-20:]
        updated["confidence_trend"] = trend

        return updated

    @staticmethod
    def _compute_trend(probability_series: list) -> dict:
        """简单线性回归判断趋势"""
        if len(probability_series) < 3:
            return {"direction": "STABLE", "slope": 0.0}

        n = len(probability_series)
        x = np.arange(n)
        y = np.array(probability_series)

        slope = np.polyfit(x, y, 1)[0]

        if slope > 0.02:
            direction = "UP"
        elif slope < -0.02:
            direction = "DOWN"
        else:
            direction = "STABLE"

        return {"direction": direction, "slope": float(slope)}

    @staticmethod
    def _check_confidence_build_need(stats: dict) -> bool:
        """
        判断是否需要信心建设训练
        触发条件：
        1. 正确率 ≥ 70% 但平均犹豫度 ≥ 50（会但不自信）
        2. 猜测占比 ≥ 20%（虚高风险高）
        3. 信心趋势连续下降
        """
        if stats.get("correct_rate", 0) >= 0.7 and stats.get("avg_hesitation", 0) >= 50:
            return True
        if stats.get("false_mastery_risk", 0) >= 0.2:
            return True
        if stats.get("trend_direction") == "DOWN" and stats.get("total_questions", 0) >= 5:
            return True
        return False
```

## 6. 犹豫度基线模型训练

### 6.1 训练数据来源

```python
class HesitationBaselineTrainer:
    """犹豫度基线模型训练器"""

    FEATURE_COLUMNS = [
        "total_time_ms", "first_input_delay_ms",
        "answer_change_count", "page_blur_count", "page_blur_total_ms",
        "cursor_pause_count", "cursor_pause_ratio"
    ]

    def __init__(self, clickhouse_client):
        self.ch = clickhouse_client

    def fetch_training_data(
        self,
        grade_level: str,
        subject: str,
        question_type: str,
        days: int = 90
    ) -> "pd.DataFrame":
        """从 ClickHouse 获取训练数据"""
        import pandas as pd

        query = f"""
        SELECT
            e.total_time_ms,
            e.first_input_at - e.question_shown_at AS first_input_delay_ms,
            e.answer_change_count,
            e.page_blur_count,
            e.page_blur_total_ms,
            e.cursor_pause_count,
            e.cursor_pause_ratio,
            e.difficulty,
            e.is_correct,
            q.expected_time_ms
        FROM practice_answer_behavior_events e
        JOIN questions q ON e.question_id = q.id
        WHERE e.created_at >= now() - INTERVAL {days} DAY
          AND e.device_type IN ('PHONE', 'TABLET')
          AND e.total_time_ms BETWEEN 1000 AND 600000  -- 过滤异常值
          AND q.grade_level = '{grade_level}'
          AND q.subject = '{subject}'
          AND q.question_type = '{question_type}'
        """

        return pd.read_sql(query, self.ch)

    def compute_baselines(
        self,
        df: "pd.DataFrame"
    ) -> dict:
        """计算基线参数"""

        # 按难度区间分组
        results = {}
        for band, (lo, hi) in {
            "EASY": (0.0, 0.35),
            "MEDIUM": (0.35, 0.7),
            "HARD": (0.7, 1.0)
        }.items():
            subset = df[(df["difficulty"] >= lo) & (df["difficulty"] < hi)]

            if len(subset) < 30:
                continue

            # 作答时间使用 IQR 去除离群值
            q1, q3 = subset["total_time_ms"].quantile([0.25, 0.75])
            iqr = q3 - q1
            filtered = subset[
                (subset["total_time_ms"] >= q1 - 1.5 * iqr) &
                (subset["total_time_ms"] <= q3 + 1.5 * iqr)
            ]

            results[band] = {
                "expected_time_ms_mean": int(filtered["total_time_ms"].mean()),
                "expected_time_ms_std": int(filtered["total_time_ms"].std()),
                "expected_answer_changes": float(filtered["answer_change_count"].mean()),
                "expected_blur_count": float(filtered["page_blur_count"].mean()),
                "sample_size": len(filtered),
            }

        return results

    def train_confidence_model(
        self,
        df: "pd.DataFrame"
    ) -> "lgb.LGBMClassifier":
        """
        训练信心度概率模型
        标签定义：二次测试中同一知识点答对 → 1（真掌握），否则 → 0
        """
        import lightgbm as lgb
        from sklearn.model_selection import train_test_split

        # 构造标签：通过 join 二次测试结果
        # 这里简化为：如果该知识点历史正确率 > 80%，则认为真掌握
        # 生产环境应使用真实的二次测试数据

        features = df[self.FEATURE_COLUMNS + ["difficulty", "is_correct"]].values
        labels = (df["knowledge_point_accuracy"] > 0.8).astype(int).values

        X_train, X_test, y_train, y_test = train_test_split(
            features, labels, test_size=0.2, random_state=42
        )

        model = lgb.LGBMClassifier(
            objective="binary",
            n_estimators=100,
            max_depth=6,
            learning_rate=0.1,
            feature_name=self.FEATURE_COLUMNS + ["difficulty", "is_correct"],
            verbose=-1
        )

        model.fit(
            X_train, y_train,
            eval_set=[(X_test, y_test)],
            callbacks=[lgb.early_stopping(10)]
        )

        return model
```

```python
"""

"""
import json
import logging
from kafka import KafkaConsumer
from typing import Optional

logger = logging.getLogger(__name__)

class BehaviorEventConsumer:
    """答题行为事件消费者"""

    CONSUMER_GROUP = "hesitation-engine"
    TOPIC = "practice-answer-behavior-events"

    def __init__(self, kafka_bootstrap: str, engine: "HesitationEngine"):
        self.consumer = KafkaConsumer(
            self.TOPIC,
            bootstrap_servers=kafka_bootstrap,
            group_id=self.CONSUMER_GROUP,
            value_deserializer=lambda m: json.loads(m.decode("utf-8")),
            enable_auto_commit=False,
            max_poll_records=200,
            session_timeout_ms=30000,
        )
        self.engine = engine

    def run(self):
        """主消费循环"""
        logger.info("启动犹豫度分析消费者...")

        for message in self.consumer:
            try:
                event = message.value
                event_type = event.get("event_type")

                if event_type == "ANSWER_SUBMITTED":
                    # 答题提交：触发完整评估
                    result = self.engine.evaluate_single(event)

                    # 发送评估结果到下游
                    self.engine.publish_result(event["practice_session_id"], result)

                elif event_type == "SESSION_ENDED":
                    # 会话结束：触发批量聚合和趋势分析
                    self.engine.on_session_ended(event)

                # 手动提交 offset
                self.consumer.commit()

            except Exception as e:
                logger.error(f"处理事件失败: {event}, error={e}", exc_info=True)
                # 不阻塞消费，继续处理下一条
                self.consumer.commit()
```

### 8.2 犹豫度引擎核心服务

```python
"""
犹豫度分析引擎核心服务
"""
import time
import logging
from typing import Optional
from dataclasses import dataclass, field

logger = logging.getLogger(__name__)

@dataclass
class HesitationEngineConfig:
    """引擎配置"""
    # 犹豫度计算权重（可按年级覆盖）
    weights: dict = field(default_factory=lambda: {
        "time": 0.35,
        "answer_change": 0.25,
        "page_blur": 0.15,
        "first_input_delay": 0.15,
        "cursor_pause": 0.10,
    })
    # 信号缺失时的默认犹豫贡献分
    default_missing_score: float = 30.0
    # 是否启用 ML 模型
    enable_ml_model: bool = True
    # 模型降级阈值（推理耗时超过此值则降级）
    model_timeout_ms: int = 50


class HesitationEngine:
    """犹豫度分析引擎"""

    def __init__(
        self,
        config: HesitationEngineConfig,
        redis_client,
        clickhouse_client,
        kp_aggregator: KnowledgePointConfidenceAggregator,
        ml_model=None,
        producer=None  # Kafka producer for downstream
    ):
        self.config = config
        self.redis = redis_client
        self.ch = clickhouse_client
        self.kp_aggregator = kp_aggregator
        self.ml_model = ml_model
        self.producer = producer
        self.scorer = HesitationScorer(config.weights)
        self.inferencer = ConfidenceInferencer(ml_model)
        self.normalizer = HesitationSignalNormalizer()

    def evaluate_single(self, event: dict) -> dict:
        """
        评估单道题目的犹豫度和信心度
        核心入口方法
        """
        start_time = time.monotonic()

        student_id = event["student_id"]
        question_id = event["question_id"]

        # 1. 加载基线参数
        baseline = self._load_baseline(
            event.get("grade_level", "UNKNOWN"),
            event.get("subject", "UNKNOWN"),
            event.get("question_type", "CHOICE"),
            event.get("difficulty", 0.5)
        )

        # 2. 提取并归一化信号
        signals = self._extract_signals(event, baseline)
        normalized = self._normalize_signals(signals, baseline)

        # 3. 计算犹豫度
        hesitation_score, factors = self.scorer.compute_hesitation(
            signals=normalized,
            is_correct=bool(event.get("is_correct", 0)),
            difficulty=event.get("difficulty", 0.5)
        )
        hesitation_level = HesitationScorer.score_to_level(hesitation_score)

        # 4. 推断信心度
        historical_stats = self._get_historical_stats(student_id, question_id)

        confidence = self.inferencer.infer_confidence(
            hesitation_score=hesitation_score,
            is_correct=bool(event.get("is_correct", 0)),
            difficulty=event.get("difficulty", 0.5),
            time_deviation_ratio=signals["tdr"],
            answer_change_count=event.get("answer_change_count", 0),
            historical_accuracy=historical_stats.get("accuracy", 0.5),
            historical_hesitation=historical_stats.get("avg_hesitation", 50.0)
        )

        # 5. 构造结果
        result = {
            "student_id": student_id,
            "question_id": question_id,
            "practice_session_id": event["practice_session_id"],
            "hesitation_score": hesitation_score,
            "hesitation_level": hesitation_level,
            "hesitation_factors": factors,
            "confidence_level": confidence["level"],
            "confidence_probability": confidence["probability"],
            "confidence_interval_low": confidence["interval_low"],
            "confidence_interval_high": confidence["interval_high"],
            "diagnostic_tags": confidence["tags"],
            "model_version": self._get_model_version(),
            "computed_at": int(time.time() * 1000),
        }

        # 6. 异步更新知识点信心度
        for kp_id in event.get("knowledge_point_ids", []):
            try:
                self.kp_aggregator.update_knowledge_point_confidence(
                    student_id=student_id,
                    knowledge_point_id=kp_id,
                    subject=event.get("subject", "UNKNOWN"),
                    question_result={
                        "hesitation_score": hesitation_score,
                        "confidence_level": confidence["level"],
                        "confidence_probability": confidence["probability"],
                        "is_correct": bool(event.get("is_correct", 0)),
                        "difficulty": event.get("difficulty", 0.5),
                        "question_id": question_id,
                    }
                )
            except Exception as e:
                logger.warning(f"知识点信心度更新失败: student={student_id}, kp={kp_id}, err={e}")

        # 7. 持久化评估结果到 ClickHouse
        self._persist_result(result)

        elapsed_ms = (time.monotonic() - start_time) * 1000
        if elapsed_ms > 100:
            logger.warning(f"犹豫度评估耗时过长: {elapsed_ms:.1f}ms, question={question_id}")

        return result

    def _extract_signals(self, event: dict, baseline: dict) -> dict:
        """提取原始行为信号"""
        total_time_ms = event.get("total_time_ms", 0)
        expected_mean = baseline.get("expected_time_ms_mean", 30000)

        return {
            "total_time_ms": total_time_ms,
            "tdr": total_time_ms / max(expected_mean, 1),
            "first_input_delay_ms": event.get("first_input_delay_ms", 0) or self._infer_first_input_delay(event),
            "answer_change_count": event.get("answer_change_count", 0),
            "page_blur_count": event.get("page_blur_count", 0),
            "page_blur_total_ms": event.get("page_blur_total_ms", 0),
            "cursor_pause_count": event.get("cursor_pause_count"),
            "cursor_pause_ratio": event.get("cursor_pause_ratio"),
        }

    def _normalize_signals(self, signals: dict, baseline: dict) -> dict:
        """归一化信号到 0-100"""
        n = self.normalizer

        return {
            "time": n.normalize_time_deviation(
                signals["total_time_ms"],
                baseline.get("expected_time_ms_mean", 30000),
                baseline.get("expected_time_ms_std", 15000)
            ),
            "answer_change": n.normalize_answer_changes(
                signals["answer_change_count"],
                int(baseline.get("expected_answer_changes", 0))
            ),
            "page_blur": n.normalize_page_blur(
                signals["page_blur_count"],
                signals["page_blur_total_ms"],
                signals["total_time_ms"]
            ),
            "first_input_delay": n.normalize_first_input_delay(
                signals["first_input_delay_ms"]
            ),
            "cursor_pause": n.normalize_cursor_pause(
                signals.get("cursor_pause_count"),
                signals.get("cursor_pause_ratio")
            ),
        }

    def _load_baseline(
        self, grade: str, subject: str, qtype: str, difficulty: float
    ) -> dict:
        """从缓存加载犹豫度基线"""
        # 确定难度区间
        if difficulty < 0.35:
            band = "EASY"
        elif difficulty < 0.7:
            band = "MEDIUM"
        else:
            band = "HARD"

        cache_key = f"hes_baseline:{grade}:{subject}:{qtype}:{band}"

        import json
        cached = self.redis.get(cache_key)
        if cached:
            return json.loads(cached)

        # 查询 ClickHouse
        query = """
        SELECT * FROM hesitation_baselines FINAL
        WHERE grade_level = %(grade)s
          AND subject = %(subject)s
          AND question_type = %(qtype)s
          AND difficulty_band = %(band)s
        LIMIT 1
        """
        result = self.ch.execute(query, {
            "grade": grade, "subject": subject,
            "qtype": qtype, "band": band
        })

        if result:
            baseline = dict(result[0])
            self.redis.setex(cache_key, 3600, json.dumps(baseline))
            return baseline

        # 全局默认基线
        return {
            "expected_time_ms_mean": 30000,
            "expected_time_ms_std": 15000,
            "expected_answer_changes": 0.3,
            "expected_blur_count": 0.2,
        }

    def _get_historical_stats(self, student_id: int, question_id: int) -> dict:
        """获取学生历史统计"""
        cache_key = f"hist_stats:{student_id}"
        cached = self.redis.hgetall(cache_key)
        if cached:
            return {
                "accuracy": float(cached.get("accuracy", 0.5)),
                "avg_hesitation": float(cached.get("avg_hesitation", 50.0))
            }
        return {"accuracy": 0.5, "avg_hesitation": 50.0}

    @staticmethod
    def _infer_first_input_delay(event: dict) -> int:
        """无显式首次输入时间时，使用估算"""
        total = event.get("total_time_ms", 30000)
        # 经验值：首次输入延迟约占总时间的 10-20%
        return int(total * 0.15)

    def _persist_result(self, result: dict):
        """异步写入 ClickHouse"""
        try:
            insert_sql = """
            INSERT INTO hesitation_scores (
                id, student_id, question_id, practice_session_id,
                knowledge_point_ids,
                time_deviation_ratio, answer_change_count, page_blur_count,
                page_blur_ratio, cursor_pause_ratio, first_input_delay_ms,
                hesitation_score, hesitation_level, hesitation_factors,
                confidence_level, confidence_probability,
                confidence_interval_low, confidence_interval_high,
                diagnostic_tags, model_version, computed_at
            ) VALUES
            """
            # 实际实现中使用批量插入
            logger.debug(f"持久化犹豫度评估结果: qid={result['question_id']}")
        except Exception as e:
            logger.error(f"持久化犹豫度评估结果失败: {e}")

    def publish_result(self, session_id: str, result: dict):
        """发布评估结果到下游"""
        if self.producer:
            self.producer.send(
                "hesitation-evaluation-results",
                key=f"{session_id}:{result['question_id']}",
                value=result
            )

    def _get_model_version(self) -> str:
        if self.ml_model:
            return f"lgbm_v{getattr(self.ml_model, 'version', '1.0')}"
        return "heuristic_v1.0"
```

### 8.3 知识点信心度聚合服务（异步更新）

```python
"""
知识点信心度增量聚合服务
使用 Redis Hash 缓存 + 定时持久化到 MySQL
"""
import asyncio
import json
import logging
from datetime import datetime

logger = logging.getLogger(__name__)

class KnowledgePointConfidenceService:
    """知识点信心度聚合服务"""

    REDIS_KEY_PREFIX = "kp_confidence"
    BATCH_FLUSH_INTERVAL = 60  # 秒

    def __init__(self, redis_client, mysql_pool):
        self.redis = redis_client
        self.mysql = mysql_pool
        self._flush_task = None

    async def start(self):
        """启动定时持久化任务"""
        self._flush_task = asyncio.create_task(self._periodic_flush())
        logger.info("知识点信心度服务已启动")

    async def stop(self):
        if self._flush_task:
            self._flush_task.cancel()

    async def update(self, student_id: int, kp_id: int, subject: str, result: dict):
        """增量更新（Redis 操作，低延迟）"""
        key = f"{self.REDIS_KEY_PREFIX}:{student_id}:{kp_id}"

        # 使用 Redis Hash 存储所有字段
        pipe = self.redis.pipeline()

        # 增量计数
        pipe.hincrby(key, "total_questions", 1)
        if result["is_correct"]:
            pipe.hincrby(key, "correct_count", 1)

        level = result["confidence_level"]
        level_field_map = {
            "HIGH": "high_confidence_count",
            "LIKELY": "likely_confidence_count",
            "UNSURE": "unsure_confidence_count",
            "GUESS": "guess_confidence_count",
            "LOW": "low_confidence_count",
        }
        field = level_field_map.get(level, "unsure_confidence_count")
        pipe.hincrby(key, field, 1)

        # EMA 更新犹豫度和信心概率
        pipe.hget(key, "avg_hesitation")
        pipe.hget(key, "avg_confidence_prob")
        responses = pipe.execute()

        prev_hesitation = float(responses[-2] or 50)
        prev_conf = float(responses[-1] or 0.5)

        alpha = 0.15
        new_hesitation = prev_hesitation * (1 - alpha) + result["hesitation_score"] * alpha
        new_conf = prev_conf * (1 - alpha) + result["confidence_probability"] * alpha

        # 更新趋势序列
        trend_key = f"{key}:trend"
        pipe.lpush(trend_key, round(result["confidence_probability"], 3))
        pipe.ltrim(trend_key, 0, 19)  # 保留最近20个

        # 写回
        pipe.hset(key, mapping={
            "avg_hesitation": round(new_hesitation, 2),
            "avg_confidence_prob": round(new_conf, 3),
            "student_id": student_id,
            "knowledge_point_id": kp_id,
            "subject": subject,
            "last_updated_at": datetime.now().isoformat(),
        })

        pipe.execute()

    async def get(self, student_id: int, kp_id: int) -> Optional[dict]:
        """查询知识点信心度"""
        key = f"{self.REDIS_KEY_PREFIX}:{student_id}:{kp_id}"
        data = await self.redis.hgetall(key)

        if not data:
            return None

        # 获取趋势
        trend = await self.redis.lrange(f"{key}:trend", 0, -1)
        trend_values = [float(v) for v in reversed(trend)]  # 恢复时间顺序

        result = {k.decode(): v.decode() for k, v in data.items()}
        result["confidence_trend"] = trend_values

        # 计算衍生指标
        total = int(result.get("total_questions", 0))
        correct = int(result.get("correct_count", 0))
        result["correct_rate"] = correct / max(total, 1)

        guess_count = int(result.get("guess_confidence_count", 0))
        result["false_mastery_risk"] = guess_count / max(total, 1)

        return result

    async def _periodic_flush(self):
        """定时将 Redis 数据持久化到 MySQL"""
        while True:
            try:
                await asyncio.sleep(self.BATCH_FLUSH_INTERVAL)
                await self._flush_to_mysql()
            except asyncio.CancelledError:
                break
            except Exception as e:
                logger.error(f"知识点信心度持久化失败: {e}", exc_info=True)

    async def _flush_to_mysql(self):
        """批量刷入 MySQL"""
        # 扫描所有变更的 key
        pattern = f"{self.REDIS_KEY_PREFIX}:*"
        keys = []
        async for key in self.redis.scan_iter(match=pattern, count=500):
            key_str = key.decode()
            if ":trend" in key_str:
                continue
            keys.append(key_str)

        if not keys:
            return

        batch = []
        for key in keys[:1000]:  # 每次最多1000条
            data = await self.redis.hgetall(key)
            if not data:
                continue
            decoded = {k.decode(): v.decode() for k, v in data.items()}
            batch.append(decoded)

        if batch:
            async with self.mysql.acquire() as conn:
                await conn.executemany(
                    """
                    INSERT INTO knowledge_point_confidence
                    (student_id, knowledge_point_id, subject,
                     total_questions, correct_count, correct_rate,
                     avg_hesitation, avg_confidence_prob,
                     high_confidence_count, likely_confidence_count,
                     unsure_confidence_count, guess_confidence_count,
                     low_confidence_count,
                     false_mastery_risk, last_updated_at)
                    VALUES (%(student_id)s, %(knowledge_point_id)s, %(subject)s,
                            %(total_questions)s, %(correct_count)s, %(correct_rate)s,
                            %(avg_hesitation)s, %(avg_confidence_prob)s,
                            %(high_confidence_count)s, %(likely_confidence_count)s,
                            %(unsure_confidence_count)s, %(guess_confidence_count)s,
                            %(low_confidence_count)s,
                            %(false_mastery_risk)s, %(last_updated_at)s)
                    ON DUPLICATE KEY UPDATE
                        total_questions = VALUES(total_questions),
                        correct_count = VALUES(correct_count),
                        correct_rate = VALUES(correct_rate),
                        avg_hesitation = VALUES(avg_hesitation),
                        avg_confidence_prob = VALUES(avg_confidence_prob),
                        last_updated_at = VALUES(last_updated_at)
                    """,
                    batch
                )

        logger.info(f"知识点信心度持久化完成: {len(batch)} 条记录")
```

### 9.1 错误码定义

| 错误码 | 含义 | HTTP Status |
| --- | --- | --- |
| `HES_001` | 行为信号不完整 | 400 |
| `HES_002` | 无匹配的犹豫度基线 | 200（降级处理，返回默认基线结果） |
| `HES_003` | ML 模型推理超时 | 200（降级到启发式） |
| `HES_004` | ML 模型推理异常 | 200（降级到启发式） |
| `HES_005` | 知识点信心度更新并发冲突 | 200（自动重试） |

### 9.2 降级链

```text
正常流程: ML模型推理 → 高精度信心度
    ↓ (模型超时/异常)
降级1: 启发式概率估计 → 中精度信心度
    ↓ (历史数据缺失)
降级2: 仅基于犹豫度+正确率的简化估计 → 低精度信心度
    ↓ (行为信号不足)
降级3: 返回默认信心度 UNSURE (概率=0.5) → 标记 SIGNAL_INSUFFICIENT
```

### 9.3 关键异常处理代码

```python
class HesitationEngineErrorHandler:
    """犹豫度引擎错误处理"""

    @staticmethod
    def safe_evaluate(engine: HesitationEngine, event: dict) -> dict:
        """带完整错误处理的评估包装器"""
        try:
            # 信号完整性检查
            if not event.get("total_time_ms") or event["total_time_ms"] < 1000:
                return HesitationEngineErrorHandler._fallback_result(
                    event, reason="SIGNAL_INSUFFICIENT"
                )

            # 正常评估
            return engine.evaluate_single(event)

        except TimeoutError:
            logger.warning(f"评估超时, 降级到启发式: qid={event.get('question_id')}")
            return HesitationEngineErrorHandler._heuristic_fallback(engine, event)

        except Exception as e:
            logger.error(f"评估异常: {e}", exc_info=True)
            return HesitationEngineErrorHandler._fallback_result(
                event, reason=str(e)
            )

    @staticmethod
    def _heuristic_fallback(engine: HesitationEngine, event: dict) -> dict:
        """启发式降级"""
        result = engine.evaluate_single(event)
        result["model_version"] = "heuristic_fallback"
        result["diagnostic_tags"] = result.get("diagnostic_tags", []) + ["DEGRADED"]
        return result

    @staticmethod
    def _fallback_result(event: dict, reason: str) -> dict:
        """默认降级结果"""
        return {
            "student_id": event.get("student_id"),
            "question_id": event.get("question_id"),
            "practice_session_id": event.get("practice_session_id"),
            "hesitation_score": 50.0,
            "hesitation_level": "MEDIUM",
            "hesitation_factors": {},
            "confidence_level": "UNSURE",
            "confidence_probability": 0.5,
            "confidence_interval_low": 0.3,
            "confidence_interval_high": 0.7,
            "diagnostic_tags": ["FALLBACK"],
            "fallback_reason": reason,
            "model_version": "fallback_v1.0",
            "computed_at": int(time.time() * 1000),
        }
```

### 10.2 批量优化

```python
class BatchHesitationEvaluator:
    """批量评估优化器"""

    BATCH_SIZE = 50
    PARALLEL_WORKERS = 4

    async def batch_evaluate(
        self,
        events: list[dict],
        engine: HesitationEngine
    ) -> list[dict]:
        """并发批量评估"""
        import asyncio

        # 按学生分组（减少同一学生的并发冲突）
        student_groups = {}
        for event in events:
            sid = event["student_id"]
            student_groups.setdefault(sid, []).append(event)

        # 按学生串行，不同学生并行
        tasks = []
        for sid, student_events in student_groups.items():
            tasks.append(self._evaluate_student_batch(sid, student_events, engine))

        results = await asyncio.gather(*tasks, return_exceptions=True)

        # 展平结果
        flat_results = []
        for result in results:
            if isinstance(result, Exception):
                logger.error(f"批量评估异常: {result}")
                continue
            flat_results.extend(result)

        return flat_results

    async def _evaluate_student_batch(
        self, student_id: int, events: list[dict], engine: HesitationEngine
    ) -> list[dict]:
        """单个学生的批量评估（串行，避免知识点并发冲突）"""
        results = []
        for event in events:
            result = HesitationEngineErrorHandler.safe_evaluate(engine, event)
            results.append(result)
        return results
```

### 10.3 ClickHouse 写入优化

```python
class HesitationResultWriter:
    """犹豫度评估结果批量写入器"""

    BATCH_SIZE = 200
    FLUSH_INTERVAL = 5  # 秒

    def __init__(self, clickhouse_client):
        self.ch = clickhouse_client
        self._buffer = []
        self._lock = asyncio.Lock()

    async def append(self, result: dict):
        """追加到缓冲区"""
        async with self._lock:
            self._buffer.append(result)
            if len(self._buffer) >= self.BATCH_SIZE:
                await self._flush()

    async def _flush(self):
        """批量写入 ClickHouse"""
        if not self._buffer:
            return

        batch = self._buffer[:self.BATCH_SIZE]
        self._buffer = self._buffer[self.BATCH_SIZE:]

        try:
            # 构造批量 INSERT
            values = []
            for r in batch:
                values.append((
                    r["student_id"], r["question_id"],
                    r["practice_session_id"],
                    r.get("knowledge_point_ids", []),
                    r.get("time_deviation_ratio", 1.0),
                    r.get("answer_change_count", 0),
                    r.get("page_blur_count", 0),
                    r.get("page_blur_ratio", 0),
                    r.get("cursor_pause_ratio"),
                    r.get("first_input_delay_ms", 0),
                    r["hesitation_score"],
                    r["hesitation_level"],
                    json.dumps(r.get("hesitation_factors", {})),
                    r["confidence_level"],
                    r["confidence_probability"],
                    r.get("confidence_interval_low", 0),
                    r.get("confidence_interval_high", 1),
                    r.get("diagnostic_tags", []),
                    r["model_version"],
                    r["computed_at"]
                ))

            self.ch.execute(
                "INSERT INTO hesitation_scores VALUES",
                batch
            )
            logger.debug(f"ClickHouse 批量写入: {len(batch)} 条")

        except Exception as e:
            logger.error(f"ClickHouse 写入失败: {e}")
            # 失败的数据重新入队
            self._buffer.extend(batch)
```
