# 用户标签与智能分群引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

用户标签与智能分群引擎是 PrimeTop 的底层基础能力，负责为每个用户（学生/家长）动态计算和存储多维度标签，并基于标签组合将用户划分为不同群组，支撑首页推荐、自适应学习路径、运营活动定向、学习规划差异化和精细化通知等功能。

### 1.2 设计目标

1. **标签体系标准化**：定义统一的标签分类、数据类型和计算规范
2. **实时+批量双轨计算**：关键标签实时更新，统计类标签批量离线计算
3. **群组灵活编排**：支持基于标签组合的动态群组规则
4. **跨模块集成**：提供统一查询接口供各业务模块调用
5. **隐私合规**：<14 岁用户标签严格遵守最小必要原则，家长可查看

### 1.3 与其他模块的关系

| 关联模块 | 集成方式 | 说明 |
|---------|---------|------|
| 首页与学习工作台 | 调用标签查询 → 推荐决策 | 根据用户标签决定首页内容分区和排序 |
| 自适应学习引擎 | 调用标签查询 → 学习路径 | 根据能力标签调整推荐难度和内容 |
| 运营活动与激励体系 | 调用群组查询 → 活动定向 | 根据群组推送定向活动和奖励 |
| 学习规划 | 调用标签查询 → 计划模板 | 根据学习习惯标签选择规划模板 |
| 通知中心 | 调用群组查询 → 消息定向 | 根据群组推送个性化通知 |
| 消息与推送服务 | 调用群组查询 → 推送定向 | 同上 |
| 数据埋点系统 | 接收事件 → 触发标签计算 | 用户行为事件驱动标签更新 |
| 学情分析 | 调用标签查询 → 报告内容 | 学情报告中引用标签维度分析 |
| 用户学习画像 | 共享数据基础 | 画像偏展示层，标签偏计算层 |

```
│   ├── 用户阶段 (user_stage)            [new/active/engaged/at_risk/churned/returned]

│   └── 付费意愿 (pay_propensity)        0.0~1.0

    ├── 内容风险标记 (content_risk)       [none/low/medium/high]
    └── 未成年人保护等级 (minor_protect)  [standard/enhanced/restricted]
```

## 3. 标签计算引擎

### 3.1 计算模式

| 模式 | 触发方式 | 适用标签 | 延迟 |
|------|---------|---------|------|
| **realtime** | 用户行为事件触发 | 活跃度、连续学习天数、输入方式偏好 | < 500ms |
| **batch** | Celery 定时任务 | 学科掌握度、薄弱知识点数、付费意愿 | T+1 或每小时 |
| **hybrid** | 事件触发 + 定时校准 | 正确率等级、解题速度 | 事件触发即时 + 每日校准 |

### 3.3 标签计算函数注册表

```python
from abc import ABC, abstractmethod
from typing import Any


class TagComputer(ABC):
    """标签计算器基类"""

    @property
    @abstractmethod
    def tag_code(self) -> str:
        ...

    @abstractmethod
    async def compute(self, user_id: int, context: dict) -> tuple[str, float]:
        """
        计算标签值。

        Args:
            user_id: 用户 ID
            context: 计算上下文，包含触发事件和相关数据

        Returns:
            (tag_value, confidence) 标签值和置信度
        """
        ...


# ---- 具体计算器示例 ----

class ActivityLevelComputer(TagComputer):
    """活跃度标签计算器"""

    tag_code = "activity_level"

    async def compute(self, user_id: int, context: dict) -> tuple[str, float]:
        # 取近 7 天学习天数
        redis_key = f"user:activity:daily:{user_id}"
        active_days = await redis.scard(redis_key)

        if active_days >= 5:
            return "high", 0.95
        elif active_days >= 3:
            return "medium", 0.90
        elif active_days >= 1:
            return "low", 0.85
        else:
            return "dormant", 0.80


class SubjectMasteryComputer(TagComputer):
    """学科掌握度标签计算器 (hybrid)"""

    tag_code = "subject_mastery"

    async def compute(self, user_id: int, context: dict) -> tuple[str, float]:
        # 从学习记录服务获取各学科掌握度
        subject_scores: dict[str, float] = await self._get_subject_scores(user_id)

        # 转为 JSON Map 格式
        value = json.dumps(subject_scores, ensure_ascii=False)

        # 置信度基于数据量
        total_answers = await self._get_total_answer_count(user_id)
        confidence = min(1.0, total_answers / 50)  # 50 题以上达到 1.0

        return value, confidence

    async def _get_subject_scores(self, user_id: int) -> dict[str, float]:
        """从学习记录服务或缓存获取各学科掌握度"""
        cached = await redis.get(f"user:subject_mastery:{user_id}")
        if cached:
            return json.loads(cached)

        # 查询数据库聚合
        async with get_db() as db:
            rows = await db.execute(
                select(
                    AnswerRecord.subject,
                    func.avg(AnswerRecord.is_correct.cast(Float)).label("mastery")
                )
                .where(AnswerRecord.user_id == user_id)
                .where(AnswerRecord.created_at >= datetime.now() - timedelta(days=30))
                .group_by(AnswerRecord.subject)
            )
            result = {}
            for row in rows:
                result[row.subject] = round(float(row.mastery), 3)

            # 缓存 10 分钟
            await redis.setex(
                f"user:subject_mastery:{user_id}",
                600,
                json.dumps(result)
            )
            return result


class PayPropensityComputer(TagComputer):
    """付费意愿标签计算器 (batch)"""

    tag_code = "pay_propensity"

    async def compute(self, user_id: int, context: dict) -> tuple[str, float]:
        """
        基于多维度特征计算付费意愿评分。

        特征维度:
        - 活跃度 (0-25分)
        - AI 使用深度 (0-25分)
        - 会员历史 (0-25分)
        - 功能探索广度 (0-25分)
        """
        score = 0.0
        feature_count = 0

        # 1. 活跃度贡献
        activity_tag = await self._get_tag_value(user_id, "activity_level")
        activity_scores = {"high": 25, "medium": 18, "low": 10, "dormant": 0}
        score += activity_scores.get(activity_tag, 0)
        feature_count += 1

        # 2. AI 使用深度 (近30天 AI 问答次数)
        ai_count = await self._get_ai_usage_count(user_id, days=30)
        if ai_count >= 100:
            score += 25
        elif ai_count >= 30:
            score += 18
        elif ai_count >= 10:
            score += 10
        feature_count += 1

        # 3. 会员历史
        membership_tag = await self._get_tag_value(user_id, "membership_stage")
        membership_scores = {"paid": 25, "trial": 20, "expiring": 22, "free": 5, "expired": 15}
        score += membership_scores.get(membership_tag, 0)
        feature_count += 1

        # 4. 功能探索广度 (使用过的功能模块数)
        used_modules = await self._get_used_module_count(user_id, days=30)
        module_ratio = min(1.0, used_modules / 6)  # 6 个核心模块
        score += module_ratio * 25
        feature_count += 1

        # 归一化到 0.0~1.0
        propensity = round(score / (feature_count * 25), 3)
        return str(propensity), min(1.0, feature_count / 4)
```

### 3.4 实时计算主流程

```python
async def handle_event_update_tags(
    event_type: str,
    user_id: int,
    event_data: dict,
) -> list[str]:
    """
    事件驱动标签更新主入口。

    流程:
    1. 根据 event_type 查找需要更新的标签列表
    2. 依次调用对应计算器
    3. 对比新旧值，有变化则写入
    4. 记录计算日志
    5. 返回更新的标签列表

    性能要求: 单次事件处理总耗时 < 500ms
    """
    tag_codes = EVENT_TAG_MAP.get(event_type, [])
    if not tag_codes:
        return []

    updated_tags = []

    for tag_code in tag_codes:
        computer = get_computer(tag_code)
        if not computer:
            logger.warning(f"No computer registered for tag: {tag_code}")
            continue

        start = time.monotonic()
        try:
            new_value, confidence = await asyncio.wait_for(
                computer.compute(user_id, {"event": event_type, "data": event_data}),
                timeout=2.0  # 单个标签计算超时 2s
            )

            # 获取旧值
            old_value = await _get_current_tag_value(user_id, tag_code)

            # 写入新值
            await _upsert_tag(user_id, tag_code, new_value, confidence, "event_computed")

            # 记录日志
            compute_ms = int((time.monotonic() - start) * 1000)
            await _log_compute(user_id, tag_code, old_value, new_value, event_type, compute_ms)

            if old_value != new_value:
                updated_tags.append(tag_code)
                # 发布标签变更事件（供其他模块监听）
                await event_bus.emit("tag_changed", {
                    "user_id": user_id,
                    "tag_code": tag_code,
                    "old_value": old_value,
                    "new_value": new_value,
                })

        except asyncio.TimeoutError:
            logger.error(f"Tag compute timeout: {tag_code} for user {user_id}")
        except Exception as e:
            logger.error(f"Tag compute error: {tag_code} for user {user_id}: {e}")

    return updated_tags
```

### 3.5 批量计算调度

```python
# Celery 任务定义

@app.task(name="tags.batch_compute_all")
def batch_compute_all():
    """
    全量批量标签计算（每日凌晨 3:00 执行）。

    流程:
    1. 查询所有 batch/hybrid 类型标签
    2. 按标签分批处理用户
    3. 每批 500 用户并行计算
    """
    batch_tags = db.query(TagDef).filter(
        TagDef.compute_mode.in_(["batch", "hybrid"]),
        TagDef.status == "active",
    ).all()

    for tag_def in batch_tags:
        batch_compute_tag.delay(tag_def.tag_code)


@app.task(
    name="tags.batch_compute_tag",
    bind=True,
    rate_limit="100/m",   # 限速避免数据库压力
)
def batch_compute_tag(self, tag_code: str, last_user_id: int = 0):
    """单个标签的批量计算（分页处理）"""
    BATCH_SIZE = 500

    # 获取活跃用户 ID 列表（分页）
    user_ids = db.query(User.id).filter(
        User.id > last_user_id,
        User.status == "active",
    ).order_by(User.id).limit(BATCH_SIZE).all()

    if not user_ids:
        return  # 本标签计算完成

    computer = get_computer(tag_code)
    if not computer:
        return

    for uid in user_ids:
        try:
            new_value, confidence = asyncio.run(
                computer.compute(uid, {"batch": True})
            )
            old_value = _get_current_tag_value_sync(uid, tag_code)
            _upsert_tag_sync(uid, tag_code, new_value, confidence, "batch_computed")
            _log_compute_sync(uid, tag_code, old_value, new_value, "batch_cron", None)
        except Exception as e:
            logger.error(f"Batch compute error: {tag_code} user {uid}: {e}")

    # 继续下一批
    batch_compute_tag.delay(tag_code, user_ids[-1])
```

### 4.3 规则引擎评估器

```python
from typing import Any


class RuleEvaluator:
    """分群规则评估器"""

    def __init__(self, user_tags: dict[str, str]):
        """
        Args:
            user_tags: {tag_code: tag_value} 该用户的所有标签值
        """
        self.user_tags = user_tags

    async def evaluate(self, rule: dict) -> bool:
        """评估规则是否匹配"""
        operator = rule.get("operator")

        if operator == "AND":
            return all(await self.evaluate(c) for c in rule["conditions"])
        elif operator == "OR":
            return any(await self.evaluate(c) for c in rule["conditions"])
        elif operator == "NOT":
            return not await self.evaluate(rule["conditions"][0])
        else:
            # 叶子条件
            return self._evaluate_condition(rule)

    def _evaluate_condition(self, condition: dict) -> bool:
        tag_code = condition["tag_code"]
        op = condition["op"]

        if op == "EXISTS":
            return tag_code in self.user_tags
        if op == "NOT_EXISTS":
            return tag_code not in self.user_tags

        tag_value = self.user_tags.get(tag_code)
        if tag_value is None:
            return False

        if op == "IN":
            return tag_value in condition["values"]
        if op == "NOT_IN":
            return tag_value not in condition["values"]
        if op == "EQ":
            return tag_value == str(condition["value"])
        if op == "NEQ":
            return tag_value != str(condition["value"])

        # 数值比较
        try:
            numeric_value = float(tag_value)
        except (ValueError, TypeError):
            return False

        target = condition.get("value", 0)

        if op == "GT":
            return numeric_value > target
        if op == "GTE":
            return numeric_value >= target
        if op == "LT":
            return numeric_value < target
        if op == "LTE":
            return numeric_value <= target
        if op == "BETWEEN":
            return condition["min"] <= numeric_value <= condition["max"]

        return False
```

```python
    bind=True,

def refresh_group(self, group_id: int):
    """刷新单个群组成员"""
    group = db.get(UserGroup, group_id)
    if not group:
        return

    rule = group.rules
    version = int(time.time())

    # 分批扫描活跃用户
    BATCH_SIZE = 1000
    last_id = 0
    matched_user_ids = []

    while True:
        users = db.query(User.id).filter(
            User.id > last_id,
            User.status == "active",
        ).order_by(User.id).limit(BATCH_SIZE).all()

        if not users:
            break

        user_ids = [u.id for u in users]
        last_id = user_ids[-1]

        # 批量获取标签
        tags_batch = _batch_get_user_tags(user_ids)

        for uid in user_ids:
            evaluator = RuleEvaluator(tags_batch.get(uid, {}))
            if evaluator.evaluate(rule):
                matched_user_ids.append(uid)

    # 更新群组成员（先删后插，在事务中执行）
    with db.begin():
        db.execute(
            delete(UserGroupMember).where(UserGroupMember.group_id == group_id)
        )
        if matched_user_ids:
            db.execute(
                insert(UserGroupMember),
                [{"user_id": uid, "group_id": group_id, "match_version": version}
                 for uid in matched_user_ids]
            )

    # 更新预估人数
    group.estimated_size = len(matched_user_ids)
    db.commit()

    logger.info(f"Group {group.group_code} refreshed: {len(matched_user_ids)} members")
```

### 4.5 Redis 缓存策略

```python
class TagCacheService:
    """标签缓存服务"""

    TAG_CACHE_TTL = 3600       # 标签缓存 1 小时
    GROUP_CACHE_TTL = 1800     # 群组缓存 30 分钟
    USER_ALL_TAGS_TTL = 1800   # 用户全量标签缓存 30 分钟

    @staticmethod
    async def get_user_tags(user_id: int) -> dict[str, str]:
        """
        获取用户全部标签（带缓存）。

        缓存 key: tag:user:{user_id}:all
        """
        cache_key = f"tag:user:{user_id}:all"
        cached = await redis.get(cache_key)
        if cached:
            return json.loads(cached)

        # 查数据库
        rows = await db.execute(
            select(UserTag.tag_code, UserTag.tag_value)
            .where(UserTag.user_id == user_id)
        )
        tags = {row.tag_code: row.tag_value for row in rows}

        await redis.setex(cache_key, TagCacheService.USER_ALL_TAGS_TTL, json.dumps(tags))
        return tags

    @staticmethod
    async def get_tag_value(user_id: int, tag_code: str) -> Optional[str]:
        """
        获取用户单个标签值。

        优先查缓存，miss 则查 DB。
        """
        cache_key = f"tag:user:{user_id}:{tag_code}"
        cached = await redis.get(cache_key)
        if cached is not None:
            return cached

        row = await db.execute(
            select(UserTag.tag_value)
            .where(UserTag.user_id == user_id, UserTag.tag_code == tag_code)
        )
        value = row.scalar_one_or_none()

        if value is not None:
            await redis.setex(cache_key, TagCacheService.TAG_CACHE_TTL, value)
        return value

    @staticmethod
    async def invalidate_user(user_id: int, tag_codes: list[str] = None):
        """
        失效用户标签缓存。

        Args:
            tag_codes: 指定失效的标签，None 表示失效全部
        """
        if tag_codes:
            pipe = redis.pipeline()
            for code in tag_codes:
                pipe.delete(f"tag:user:{user_id}:{code}")
            await pipe.execute()
        # 始终失效全量缓存
        await redis.delete(f"tag:user:{user_id}:all")

    @staticmethod
    async def get_user_groups(user_id: int) -> list[int]:
        """
        获取用户所属群组 ID 列表（带缓存）。

        缓存 key: group:user:{user_id}
        """
        cache_key = f"group:user:{user_id}"
        cached = await redis.get(cache_key)
        if cached is not None:
            return json.loads(cached)

        rows = await db.execute(
            select(UserGroupMember.group_id)
            .where(UserGroupMember.user_id == user_id)
        )
        group_ids = [row.group_id for row in rows]

        await redis.setex(cache_key, TagCacheService.GROUP_CACHE_TTL, json.dumps(group_ids))
        return group_ids

    @staticmethod
    async def is_in_group(user_id: int, group_code: str) -> bool:
        """快速判断用户是否在某群组中"""
        group_id = await TagCacheService._resolve_group_code(group_code)
        if not group_id:
            return False

        group_ids = await TagCacheService.get_user_groups(user_id)
        return group_id in group_ids
```

| 错误码 | 说明 |
|-------|------|
| `TAG_001` | 标签定义不存在 |
| `TAG_002` | 标签值类型不匹配 |
| `TAG_003` | 计算器未注册 |
| `TAG_004` | 计算超时 |
| `TAG_005` | 标签已过期需重新计算 |
| `GRP_001` | 群组不存在 |
| `GRP_002` | 规则语法错误 |
| `GRP_003` | 群组刷新失败 |
| `GRP_004` | 权限不足（家长查看非绑定孩子） |

### 8.2 降级策略

| 场景 | 降级方案 |
|------|---------|
| Redis 不可用 | 直接查数据库，跳过缓存层 |
| 标签计算超时 | 保留旧标签值，记录日志，不阻塞主流程 |
| 批量任务积压 | 降低刷新频率，优先保证 realtime 标签 |
| 数据库读取慢 | 返回默认标签值（全量标签 → 空字典） |
| 群组查询失败 | 按未分群处理，走通用逻辑 |
