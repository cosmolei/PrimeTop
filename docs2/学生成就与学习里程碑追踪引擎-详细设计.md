## 1. 模块概述

### 1.1 定位

学生成就与学习里程碑追踪引擎是 PrimeTop 平台的**核心游戏化驱动层**，负责定义、追踪、触发和展示学生在学习过程中达成的各类成就与里程碑。它独立于运营活动和打卡系统，提供一套通用、可扩展的成就规则引擎，让学习过程具有目标感、获得感和持续驱动力。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| 激励持续学习 | 通过里程碑节点给予正向反馈，降低流失率 |
| 引导功能探索 | 将功能发现融入成就解锁，引导用户使用更多能力 |
| 学习行为量化 | 将抽象学习过程转化为可感知的进度和等级 |
| 社交传播素材 | 成就可分享至家长端/社交平台，兼具传播价值 |
| 数据驱动运营 | 成就解锁数据反哺用户画像和运营策略 |

### 1.3 与其他模块的关系

## 2. 核心概念定义

### 2.1 成就 (Achievement)

一个成就代表一项可解锁的里程碑目标。

```typescript
interface Achievement {
  id: string;                    // 唯一标识，如 "first_question_answered"
  category: AchievementCategory; // 成就分类
  tier: AchievementTier;         // 成就等级（铜/银/金/钻石）
  display: {
    name: string;                // 显示名称，如 "初出茅庐"
    description: string;         // 描述，如 "完成你的第一次AI提问"
    icon: string;                // 图标资源路径
    unlockedIcon: string;        // 解锁后图标
    lockedIcon: string;          // 未解锁时图标
    color: string;               // 主题色（铜=#CD7F32, 银=#C0C0C0, 金=#FFD700, 钻=#B9F2FF）
  };
  condition: AchievementCondition; // 解锁条件定义
  rewards?: AchievementReward[];   // 解锁奖励
  displayOrder: number;            // 展示排序权重
  hidden: boolean;                 // 是否隐藏（未解锁时不显示条件详情）
  repeatable: boolean;             // 是否可重复达成（如"连续7天学习"每月可重复）
  maxRepeat?: number;              // 最大重复次数，null=无限
  validFrom?: string;              // 生效开始时间（ISO 8601）
  validTo?: string;                // 生效结束时间
  metadata?: Record<string, any>;  // 扩展字段
}
```

### 2.4 成就条件 (AchievementCondition)

```typescript
interface AchievementCondition {
  type: ConditionType;
  params: Record<string, any>;
}

enum ConditionType {
  // 累计型
  COUNTER = "counter",                         // 累计计数达阈值
  // 连续型
  STREAK = "streak",                           // 连续天数
  // 一次性
  ONE_TIME = "one_time",                       // 首次触发某事件
  // 集合型
  COLLECTION = "collection",                   // 收集N个不同项（如掌握N个知识点）
  // 百分比型
  PERCENTAGE = "percentage",                   // 达到某百分比（如章节掌握度>80%）
  // 复合条件
  COMPOSITE_AND = "composite_and",             // 多条件同时满足
  COMPOSITE_OR = "composite_or",               // 多条件任一满足
  // 时间窗口型
  TIME_WINDOW = "time_window",                 // 在指定时间窗口内完成
}
```

**条件参数示例：**

```typescript
// 累计AI问答100次
{
  type: "counter",
  params: {
    eventType: "ai_question_asked",
    threshold: 100,
    timeScope: "all_time"   // all_time | daily | weekly | monthly
  }
}

// 连续学习7天
{
  type: "streak",
  params: {
    eventType: "daily_learning_completed",
    minDuration: 600,       // 每日最少学习秒数
    targetDays: 7
  }
}

// 掌握50个不同知识点
{
  type: "collection",
  params: {
    eventType: "knowledge_point_mastered",
    targetCount: 50,
    distinctBy: "knowledgePointId"
  }
}

// 数学章节掌握度达80%
{
  type: "percentage",
  params: {
    source: "chapter_mastery",
    subjectId: "math",
    targetPercentage: 80
  }
}

// 复合条件：连续7天 + 累计问AI 30次
{
  type: "composite_and",
  params: {
    conditions: [
      { type: "streak", params: { eventType: "daily_learning_completed", targetDays: 7 } },
      { type: "counter", params: { eventType: "ai_question_asked", threshold: 30 } }
    ]
  }
}
```

## 3. 数据模型设计

### 3.1 数据库表结构

#### 3.1.1 成就定义表 `achievement_definitions`

```sql
CREATE TABLE achievement_definitions (
  id              VARCHAR(64) PRIMARY KEY,          -- 成就ID
  category        VARCHAR(32) NOT NULL,             -- 分类
  tier            VARCHAR(16) NOT NULL,             -- 等级
  name            VARCHAR(64) NOT NULL,             -- 名称
  description     VARCHAR(256) NOT NULL,            -- 描述
  icon_url        VARCHAR(512) NOT NULL,            -- 图标URL
  unlocked_icon   VARCHAR(512),                     -- 解锁图标
  locked_icon     VARCHAR(512),                     -- 锁定图标
  condition_json  JSON NOT NULL,                    -- 条件定义（JSON）
  reward_json     JSON,                             -- 奖励定义（JSON）
  display_order   INT DEFAULT 0,                    -- 排序权重
  hidden          TINYINT(1) DEFAULT 0,             -- 是否隐藏
  repeatable      TINYINT(1) DEFAULT 0,             -- 是否可重复
  max_repeat      INT,                              -- 最大重复次数
  valid_from      DATETIME,                         -- 生效开始时间
  valid_to        DATETIME,                         -- 生效结束时间
  status          VARCHAR(16) DEFAULT 'active',     -- active/disabled/archived
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  INDEX idx_category (category),
  INDEX idx_tier (tier),
  INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

#### 3.1.2 用户成就进度表 `user_achievements`

```sql
CREATE TABLE user_achievements (
  id              BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id         VARCHAR(64) NOT NULL,             -- 用户ID
  achievement_id  VARCHAR(64) NOT NULL,             -- 成就ID
  status          VARCHAR(16) NOT NULL DEFAULT 'locked',  -- locked/in_progress/unlocked
  progress        INT NOT NULL DEFAULT 0,           -- 当前进度
  target          INT NOT NULL,                     -- 目标值
  progress_json   JSON,                             -- 多维度进度明细
  repeat_count    INT DEFAULT 0,                    -- 重复达成次数
  unlocked_at     DATETIME,                         -- 解锁时间
  notified_at     DATETIME,                         -- 通知已读时间
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  UNIQUE KEY uk_user_achievement (user_id, achievement_id),
  INDEX idx_user_status (user_id, status),
  INDEX idx_unlocked_at (unlocked_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 3.2 Redis 缓存设计

```
# 用户成就进度缓存（Hash）
achievement:progress:{userId}
  → {achievementId} → JSON(progress, target, status, repeatCount)
TTL: 1小时，写入时刷新

# 用户等级缓存（String）
achievement:level:{userId}
  → JSON({totalXP, currentLevel, currentLevelXP, nextLevelXP, levelTitle})
TTL: 30分钟

# 每日XP限额追踪（String）
achievement:daily_xp:{userId}:{date}
  → 当日累计XP值
TTL: 48小时

# 成就定义缓存（Hash）
achievement:definitions
  → {achievementId} → JSON(完整成就定义)
TTL: 24小时，后台更新时主动刷新

# 事件计数器（String，用于 counter 类型条件的实时统计）
achievement:counter:{userId}:{eventType}:{timeScope}
  → 计数值
TTL: 
  daily → 48小时
  weekly → 8天
  monthly → 32天
  all_time → 无过期（需配合持久化策略）

# 连续学习天数（String）
achievement:streak:{userId}
  → JSON({currentStreak, lastActiveDate})
TTL: 无过期
```

## 5. 核心业务流程

### 5.1 成就评估触发流程

```
用户行为 → 事件发布 → 成就引擎消费事件 → 条件评估 → 进度更新/解锁触发
```

**详细时序：**

```
用户操作                   事件总线                 成就引擎                     数据层
  │                         │                       │                          │
  │ 完成一次AI提问           │                       │                          │
  │──────────────────────▶ │                       │                          │
  │                         │ ai_question_asked     │                          │
  │                         │ {userId, subject, ...}│                          │
  │                         │──────────────────────▶│                          │
  │                         │                       │                          │
  │                         │                       │ 1. 查询关联该事件的成就列表 │
  │                         │                       │─────────────────────────▶│
  │                         │                       │◀─────────────────────────│
  │                         │                       │                          │
  │                         │                       │ 2. 对每个成就评估条件       │
  │                         │                       │    - counter: 递增计数     │
  │                         │                       │    - streak: 检查连续性    │
  │                         │                       │    - one_time: 标记完成    │
  │                         │                       │    - collection: 去重计数  │
  │                         │                       │    - percentage: 查询掌握度│
  │                         │                       │                          │
  │                         │                       │ 3. 更新进度               │
  │                         │                       │─────────────────────────▶│
  │                         │                       │                          │
  │                         │                       │ 4. 若进度 >= 目标值        │
  │                         │                       │    → 触发解锁             │
  │                         │                       │    → 发放奖励             │
  │                         │                       │    → 发布解锁通知          │
  │                         │                       │─────────────────────────▶│
  │                         │                       │                          │

```

### 5.2 事件与成就绑定机制

成就定义中的 `condition.params.eventType` 字段决定该成就关注哪些事件。系统启动时加载所有活跃成就定义，建立 `eventType → List<Achievement>` 的映射关系，避免每次事件到来时全表扫描。

```typescript
// 内存中的事件-成就映射表
interface EventAchievementMap {
  [eventType: string]: Achievement[];
}

// 构建映射
function buildEventMap(achievements: Achievement[]): EventAchievementMap {
  const map: EventAchievementMap = {};
  for (const ach of achievements) {
    const eventTypes = extractEventTypes(ach.condition);
    for (const eventType of eventTypes) {
      if (!map[eventType]) map[eventType] = [];
      map[eventType].push(ach);
    }
  }
  return map;
}

// 从条件中提取所有关联的事件类型
function extractEventTypes(condition: AchievementCondition): string[] {
  switch (condition.type) {
    case 'counter':
    case 'streak':
    case 'one_time':
      return [condition.params.eventType];
    case 'collection':
      return [condition.params.eventType];
    case 'composite_and':
    case 'composite_or':
      return condition.params.conditions.flatMap(extractEventTypes);
    case 'percentage':
    case 'time_window':
      return []; // 这些不直接关联事件，由定时任务或查询触发
    default:
      return [];
  }
}
```

#### 5.3.1 累计型 (COUNTER)

```typescript
async function evaluateCounterCondition(
  userId: string,
  condition: CounterCondition,
  event: LearningEvent
): Promise<ConditionResult> {
  const { eventType, threshold, timeScope } = condition.params;
  
  // 从Redis计数器获取当前值
  const cacheKey = `achievement:counter:${userId}:${eventType}:${timeScope}`;
  const currentCount = await redis.incr(cacheKey);
  
  // 首次计数时设置TTL
  if (currentCount === 1) {
    const ttl = getTTLForTimeScope(timeScope);
    if (ttl) await redis.expire(cacheKey, ttl);
  }
  
  // 定期持久化到数据库（每10次或每5分钟）
  if (currentCount % 10 === 0) {
    await persistCounterToDB(userId, eventType, timeScope, currentCount);
  }
  
  return {
    progress: currentCount,
    target: threshold,
    completed: currentCount >= threshold
  };
}
```

#### 5.3.2 连续型 (STREAK)

```typescript
async function evaluateStreakCondition(
  userId: string,
  condition: StreakCondition,
  event: LearningEvent
): Promise<ConditionResult> {
  const { minDuration, targetDays } = condition.params;
  const today = new Date().toISOString().split('T')[0];
  
  const cacheKey = `achievement:streak:${userId}`;
  const streakData = await redis.get(cacheKey);
  let streak = streakData ? JSON.parse(streakData) : { currentStreak: 0, lastActiveDate: null };
  
  // 检查今日学习时长是否达标
  const todayDuration = await getTodayLearningDuration(userId);
  if (todayDuration < minDuration) {
    return {
      progress: streak.currentStreak,
      target: targetDays,
      completed: false,
      details: { todayDuration, requiredDuration: minDuration }
    };
  }
  
  // 更新连续天数
  const yesterday = new Date(Date.now() - 86400000).toISOString().split('T')[0];
  if (streak.lastActiveDate === today) {
    // 今日已记录，不重复计算
  } else if (streak.lastActiveDate === yesterday) {
    streak.currentStreak += 1;
    streak.lastActiveDate = today;
  } else {
    // 断连了，重新开始
    streak.currentStreak = 1;
    streak.lastActiveDate = today;
  }
  
  await redis.set(cacheKey, JSON.stringify(streak));
  
  return {
    progress: streak.currentStreak,
    target: targetDays,
    completed: streak.currentStreak >= targetDays
  };
}
```

#### 5.3.3 集合型 (COLLECTION)

```typescript
async function evaluateCollectionCondition(
  userId: string,
  condition: CollectionCondition,
  event: LearningEvent
): Promise<ConditionResult> {
  const { eventType, targetCount, distinctBy } = condition.params;
  
  // 使用Redis HyperLogLog或Set追踪去重项
  const setKey = `achievement:collection:${userId}:${condition.id}`;
  const distinctId = event.data[distinctBy]; // 如 knowledgePointId
  
  await redis.sadd(setKey, distinctId);
  const currentCount = await redis.scard(setKey);
  
  return {
    progress: currentCount,
    target: targetCount,
    completed: currentCount >= targetCount
  };
}
```

#### 5.3.5 复合条件 (COMPOSITE)

```typescript
async function evaluateCompositeCondition(
  userId: string,
  condition: CompositeCondition,
  event: LearningEvent
): Promise<ConditionResult> {
  const results = await Promise.all(
    condition.params.conditions.map(sub => 
      evaluateCondition(userId, sub, event)  // 递归评估
    )
  );
  
  const isAnd = condition.type === 'composite_and';
  const completed = isAnd
    ? results.every(r => r.completed)
    : results.some(r => r.completed);
  
  // 进度取所有子条件完成度的最小值(AND)或最大值(OR)
  const progress = isAnd
    ? Math.min(...results.map(r => r.progress / r.target))
    : Math.max(...results.map(r => r.progress / r.target));
  
  const maxTarget = Math.max(...results.map(r => r.target));
  
  return {
    progress: Math.round(progress * maxTarget),
    target: maxTarget,
    completed,
    subResults: results
  };
}
```

### 5.4 成就解锁流程

```typescript
async function unlockAchievement(
  userId: string,
  achievement: Achievement,
  userAchievement: UserAchievement
): Promise<UnlockResult> {
  // 1. 幂等检查：避免重复解锁
  if (userAchievement.status === 'unlocked' && !achievement.repeatable) {
    return { alreadyUnlocked: true };
  }
  
  // 2. 更新成就状态
  const now = new Date();
  await db.userAchievements.update({
    where: { id: userAchievement.id },
    data: {
      status: 'unlocked',
      unlockedAt: now,
      repeatCount: userAchievement.repeatCount + 1,
      updatedAt: now
    }
  });
  
  // 3. 发放奖励
  const rewardResults: RewardResult[] = [];
  if (achievement.rewards) {
    for (const reward of achievement.rewards) {
      const result = await grantReward(userId, reward);
      rewardResults.push(result);
    }
  }
  
  // 4. 发送通知
  await notificationService.send(userId, {
    type: 'achievement_unlocked',
    title: '🏆 成就解锁！',
    body: `你获得了「${achievement.display.name}」成就！`,
    data: {
      achievementId: achievement.id,
      tier: achievement.tier,
      rewards: rewardResults
    }
  });
  
  // 5. 发布解锁事件（用于推送弹窗、分享卡片等）
  await eventBus.publish('achievement_unlocked', {
    userId,
    achievementId: achievement.id,
    achievementName: achievement.display.name,
    tier: achievement.tier,
    rewards: rewardResults,
    timestamp: now
  });
  
  // 6. 更新统计缓存
  await invalidateUserAchievementCache(userId);
  
  return {
    achievementId: achievement.id,
    rewards: rewardResults,
    isNewUnlock: userAchievement.status !== 'unlocked'
  };
}
```

## 6. 经验值与等级系统

### 6.1 XP 获取规则

```typescript
class XPService {
  // 每日XP上限（防止刷分）
  private readonly DAILY_XP_CAP = 500;
  
  // 单次行为XP上限（防止单一行为刷分）
  private readonly PER_ACTION_DAILY_CAP: Record<string, number> = {
    ai_question_asked: 100,       // 每日最多通过AI提问获100XP
    question_answered_correctly: 200,
    exercise_completed: 150,
  };
  
  async addXP(userId: string, amount: number, source: string, referenceId?: string): Promise<XPResult> {
    // 1. 检查每日上限
    const dailyXP = await this.getDailyXP(userId);
    if (dailyXP >= this.DAILY_XP_CAP) {
      return { added: 0, reason: 'daily_cap_reached' };
    }
    
    // 2. 检查单行为上限
    const actionCap = this.PER_ACTION_DAILY_CAP[source];
    if (actionCap) {
      const actionDailyXP = await this.getActionDailyXP(userId, source);
      if (actionDailyXP >= actionCap) {
        return { added: 0, reason: 'action_cap_reached' };
      }
    }
    
    // 3. 计算实际可添加量
    const maxAdd = Math.min(
      amount,
      this.DAILY_XP_CAP - dailyXP,
      actionCap ? actionCap - (await this.getActionDailyXP(userId, source)) : Infinity
    );
    const actualAdd = Math.max(0, maxAdd);
    
    if (actualAdd <= 0) return { added: 0, reason: 'cap_reached' };
    
    // 4. 更新经验值
    await db.userExperience.increment({ userId }, 'total_xp', actualAdd);
    
    // 5. 记录流水
    await db.xpTransactionLog.create({
      data: { userId, source, amount: actualAdd, referenceType: source, referenceId }
    });
    
    // 6. 检查是否升级
    const levelUp = await this.checkLevelUp(userId);
    
    // 7. 更新缓存
    await this.updateXPCache(userId, actualAdd);
    
    return { added: actualAdd, levelUp };
  }
  
  private async checkLevelUp(userId: string): Promise<LevelUpResult | null> {
    const userXP = await db.userExperience.findUnique({ where: { userId } });
    if (!userXP) return null;
    
    let currentLevel = userXP.current_level;
    let remainingXP = userXP.total_xp;
    
    // 计算当前应有的等级
    const levelTable = getLevelTable();
    let newLevel = currentLevel;
    for (const lvl of levelTable) {
      if (remainingXP >= lvl.cumulativeXP) {
        newLevel = lvl.level;
      } else {
        break;
      }
    }
    
    // 超出预设表时按公式计算
    if (remainingXP >= levelTable[levelTable.length - 1].cumulativeXP) {
      const lastLevel = levelTable[levelTable.length - 1];
      let xp = lastLevel.cumulativeXP;
      let level = lastLevel.level;
      let nextLevelXP = lastLevel.xpRequired;
      while (remainingXP >= xp + nextLevelXP) {
        xp += nextLevelXP;
        level += 1;
        nextLevelXP = Math.round(nextLevelXP * 1.2);
      }
      newLevel = level;
    }
    
    if (newLevel > currentLevel) {
      // 升级了！
      const levelInfo = getLevelInfo(newLevel);
      await db.userExperience.update({
        where: { userId },
        data: {
          current_level: newLevel,
          current_level_xp: remainingXP - getCumulativeXPForLevel(newLevel),
          next_level_xp: getXPRequiredForLevel(newLevel + 1)
        }
      });
      
      // 发布升级事件
      await eventBus.publish('user_level_up', {
        userId,
        previousLevel: currentLevel,
        newLevel,
        title: levelInfo.title
      });
      
      return { previousLevel: currentLevel, newLevel, title: levelInfo.title };
    }
    
    return null;
  }
}
```

## 11. 错误处理与降级策略

### 11.1 常见错误场景

| 场景 | 影响 | 处理策略 |
|------|------|---------|
| Redis不可用 | 进度计数器无法写入 | 降级为数据库计数，异步补偿 |
| 事件消费延迟 | 成就解锁延迟 | 用户可接受，不阻断主流程 |
| 重复解锁 | 奖励重复发放 | 幂等检查：UserAchievement.status + repeatCount |
| 成就定义被禁用 | 已解锁不受影响，进行中的停止追踪 | 标记为 archived，保持已解锁状态 |
| 升级计算错误 | 等级显示异常 | 以数据库 totalXP 为准重建等级 |
| 奖励发放失败 | 用户未收到奖励 | 记录失败，定时重试，支持手动补发 |

### 11.2 降级方案

```typescript
class AchievementEngine {
  private redisAvailable = true;
  
  async trackProgress(userId: string, event: LearningEvent): Promise<void> {
    try {
      if (this.redisAvailable) {
        await this.trackViaRedis(userId, event);
      } else {
        await this.trackViaDB(userId, event);
      }
    } catch (error) {
      if (isRedisError(error)) {
        this.redisAvailable = false;
        // 降级到数据库模式
        await this.trackViaDB(userId, event);
        // 异步尝试恢复Redis
        this.tryRecoverRedis();
      } else {
        // 记录错误但不阻断主流程
        logger.error('Achievement tracking failed', { userId, event, error });
        await this.queueForRetry(userId, event);
      }
    }
  }
  
  @Cron('*/30 * * * *')  // 每30分钟
  private async tryRecoverRedis(): Promise<void> {
    try {
      await redis.ping();
      this.redisAvailable = true;
      // 补偿期间遗漏的进度
      await this.compensateMissedProgress();
    } catch {
      // Redis仍然不可用
    }
  }
}
```

## 12. 性能考量

### 12.1 关键性能指标

| 指标 | 目标 | 方案 |
|------|------|------|
| 事件处理延迟 | <100ms | Redis内存计数 + 异步持久化 |
| 成就列表加载 | <500ms | 分页查询 + Redis缓存 |
| 解锁弹窗响应 | <200ms | 预计算 + 本地缓存 |
| 每日批量处理 | <30min完成 | 分批处理 + 并行 |

### 12.2 优化策略

1. **事件过滤**：不是所有学习事件都需要触发成就评估，只有 `eventType` 在映射表中的事件才进入引擎
2. **延迟写入**：进度更新先写Redis，批量异步写数据库
3. **分级缓存**：成就定义24小时缓存，用户进度1小时缓存
4. **预计算**：首页成就进度条使用Redis中的实时数据，不走数据库

### 12.3 容量估算

```
假设：
- DAU = 100万
- 每用户日均触发学习事件 ≈ 50次
- 成就定义 ≈ 100个
- 每事件平均关联成就 ≈ 3个

每日事件处理量 = 100万 × 50 × 3 = 1.5亿次条件评估
→ Redis内存计数，批量写DB，可承受

用户成就记录数 = 100万用户 × 100成就 = 1亿条
→ 分库分表，按 userId hash

Redis内存估算：
- 计数器：100万 × 10种事件 × 4种时间范围 = 4000万 key × ~50 bytes = ~2GB
- 进度缓存：100万 × ~20个活跃成就 = 2000万条 × ~100 bytes = ~2GB
- 总计约 4-6GB Redis内存
```

## 13. 安全与防刷

### 13.1 防刷策略

```typescript
class AntiCheatService {
  // 检测异常行为
  async validateEvent(userId: string, event: LearningEvent): Promise<boolean> {
    // 1. 频率检查：同一事件每秒最多1次
    const recentCount = await redis.incr(`event:rate:${userId}:${event.type}`);
    if (recentCount === 1) await redis.expire(`event:rate:${userId}:${event.type}`, 1);
    if (recentCount > 3) {
      logger.warn('Rate limited event', { userId, eventType: event.type });
      return false;
    }
    
    // 2. 学习时长合理性检查
    if (event.type === 'daily_learning_completed') {
      const sessionDuration = event.data.durationSeconds;
      // 单次学习记录不能超过12小时
      if (sessionDuration > 12 * 3600) return false;
      // 当日总学习时长不能超过16小时
      const dailyTotal = await getDailyLearningTotal(userId);
      if (dailyTotal + sessionDuration > 16 * 3600) return false;
    }
    
    // 3. 设备指纹检查（可选）
    // 同一事件不能在多个设备同时触发
    
    return true;
  }
}
```
