# 服务端 - 亲子共学会话管理与双角色状态同步服务 详细设计

> **版本**：v1.0 | **日期**：2026-06-07 | **优先级**：P1 | **服务负责人**：待定
> **关联模块**：用户账号体系、家长中心、拼音识字启蒙、语音服务(ASR/TTS)、学习记录与进度追踪、防沉迷系统、运营活动与成长激励

---

## 1. 概述

### 1.1 功能定位

亲子共学会话管理服务（CoLearn Session Service）是服务端侧负责管理亲子共学全生命周期的核心服务。它处理会话创建、双角色状态流转、任务编排、实时状态同步、学习数据持久化以及与其他业务模块的集成。该服务解决的核心问题是：**在家长与孩子共享同一设备的场景下，如何安全、可靠地管理共学过程的服务端状态**。

### 1.2 与现有设计的关系

| 现有文档 | 覆盖范围 | 本文档补充 |
|---------|---------|-----------|
| 亲子共学模式与双角色交互设计 | 客户端交互、UI 流程、本地数据模型 | 服务端 API、状态机、数据库完整设计 |
| 端到端流程设计-亲子共学模式完整链路 | 端到端用户旅程、角色权限矩阵 | 服务端内部编排、跨服务调用链、异常处理 |
| 服务端-家庭账户管理与多孩子切换服务 | 家庭账户绑定关系 | 共学会话中的家长-孩子关系校验与联动 |

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 会话创建响应时间 | < 200ms |
| 任务下发延迟 | < 300ms |
| 实时状态同步延迟 | < 500ms（WebSocket 推送） |
| 会话结束后报告生成 | < 3s |
| 并发共学会话支持 | 10,000+ 同时在线 |
| 数据一致性 | 最终一致，会话结束时强一致 |

### 1.4 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 主数据库 | PostgreSQL | 会话持久化，JSONB 存储灵活结构 |
| 缓存 | Redis | 会话实时状态、分布式锁、发布/订阅 |
| 实时通信 | WebSocket (Socket.IO / ws) | 双角色状态同步 |
| 消息队列 | RabbitMQ / Kafka | 异步事件通知（学情分析、成就触发） |
| 对象存储 | S3 / MinIO | 语音作答录音文件 |

### 3.2 共学任务明细表 (colearn_task)

```sql
CREATE TABLE colearn_task (
    id                  VARCHAR(36)    NOT NULL PRIMARY KEY,
    session_id          VARCHAR(36)    NOT NULL,
    task_order          INT            NOT NULL COMMENT '任务序号(1-based)',
    
    -- 任务内容
    task_type           VARCHAR(20)    NOT NULL COMMENT 'recognize/pronounce/match/sort/fill_blank/listen_choose/trace',
    content_ref         JSONB          NOT NULL COMMENT '内容引用，包含知识点ID、题目ID等',
    content_snapshot    JSONB          NULL COMMENT '内容快照，任务创建时的题目内容缓存',
    
    -- 状态流转
    status              VARCHAR(20)    NOT NULL DEFAULT 'pending',
    started_at          TIMESTAMPTZ    NULL,
    ended_at            TIMESTAMPTZ    NULL,
    duration_ms         INT            NULL COMMENT '任务耗时',
    
    -- 孩子作答
    child_response_type VARCHAR(20)    NULL COMMENT 'voice/tap/drag/trace_path/none',
    child_response_data JSONB          NULL COMMENT '孩子作答详情',
    child_is_correct    BOOLEAN        NULL,
    
    -- AI 评估
    ai_evaluated        BOOLEAN        NOT NULL DEFAULT FALSE,
    ai_confidence       DECIMAL(3,2)   NULL COMMENT 'AI判断置信度 0.00-1.00',
    ai_evaluation       JSONB          NULL COMMENT 'AI评估详情(评分/建议)',
    
    -- 家长操作
    parent_action_type  VARCHAR(20)    NULL COMMENT 'hint/encourage/correct/confirm/skip/demo/praise',
    parent_action_data  JSONB          NULL COMMENT '家长操作详情',
    
    -- 综合结果
    final_result        VARCHAR(10)    NULL COMMENT 'correct/incorrect/skipped/pending_review',
    score               INT            NULL COMMENT '本任务得分 0-100',
    stars               INT            NULL COMMENT '本任务获得星星数 0-3',
    
    created_at          TIMESTAMPTZ    NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ    NOT NULL DEFAULT NOW(),
    
    FOREIGN KEY (session_id) REFERENCES colearn_session(id) ON DELETE CASCADE
);

CREATE INDEX idx_colearn_task_session ON colearn_task (session_id, task_order);
CREATE INDEX idx_colearn_task_status ON colearn_task (session_id, status);
```

## 4. 会话状态机

### 4.1 会话级状态机

```
                    ┌──────────────────────────┐
                    │                          │
                    ▼                          │
  ┌─────────┐   ┌────────┐   ┌─────────┐    │
  │ CREATED │──→│ ACTIVE │──→│ PAUSED  │────┘
  └─────────┘   └───┬─┬──┘   └─────────┘
                    │ │         ▲
                    │ │         │ 暂停
                    │ │    ┌────┴─────┐
                    │ │    │ BREAKING │ ← 休息中
                    │ │    └────┬─────┘
                    │ │         │ 休息结束
                    │ │         └──────→ ACTIVE
                    │ │
          ┌─────────┘ └───────────────────┐
          │                               │
          ▼                               ▼
  ┌─────────────┐              ┌───────────────┐
  │  COMPLETED  │              │  FORCE_ENDED  │
  └─────────────┘              └───────────────┘
          │                               │
          └───────────┬───────────────────┘
                      ▼
               ┌─────────────┐
               │  ARCHIVED   │ ← 定时任务归档
               └─────────────┘
```

### 4.2 状态转换规则

| 当前状态 | 事件 | 目标状态 | 触发条件 | 服务端动作 |
|---------|------|---------|---------|-----------|
| CREATED | session.activate | ACTIVE | 家长确认配置并点击开始 | 初始化 Redis 状态、加载任务序列、推送首任务 |
| ACTIVE | session.pause | PAUSED | 家长点击暂停 / 系统触发休息 | 记录暂停时间、冻结计时器、推送暂停状态 |
| ACTIVE | session.break | BREAKING | 达到休息间隔或连续错误触发 | 生成休息内容、推送休息界面 |
| ACTIVE | session.complete | COMPLETED | 所有任务完成 | 计算统计、生成报告、发布事件 |
| ACTIVE | session.force_end | FORCE_ENDED | 家长主动结束 / 服务端超时清理 | 保存已做数据、标记未完成任务 |
| ACTIVE | session.timeout | FORCE_ENDED | 无心跳超过 5 分钟 | 同 force_end |
| PAUSED | session.resume | ACTIVE | 家长点击继续 | 恢复计时器、推送当前任务 |
| PAUSED | session.timeout | FORCE_ENDED | 暂停超过 30 分钟未恢复 | 同 force_end |
| BREAKING | break.end | ACTIVE | 休息倒计时结束 / 家长跳过 | 推送下一任务 |
| COMPLETED | - | ARCHIVED | 定时归档任务（T+1 凌晨） | 压缩事件日志、更新聚合统计 |

## 5. Redis 状态设计

### 5.1 Key 规划

```
# 会话实时状态（Hash）
colearn:session:{sessionId}
  ├─ status: "active"
  ├─ currentRole: "child"
  ├─ currentTaskIndex: "3"
  ├─ lastActiveTime: "1749264000000"
  ├─ parentUserId: "xxx"
  ├─ childUserId: "xxx"
  ├─ startTime: "1749264000000"
  ├─ totalPauseSec: "60"
  ├─ pauseStartTime: ""
  ├─ totalTasks: "10"
  ├─ completedTasks: "3"
  ├─ correctCount: "2"
  ├─ parentActionCount: "1"
  └─ starsEarned: "4"

# 任务实时状态（Hash）
colearn:task:{sessionId}:{taskOrder}
  ├─ id: "task-uuid"
  ├─ status: "in_progress"
  ├─ taskType: "pronounce"
  ├─ startedAt: "1749264100000"
  ├─ childResponseType: ""
  ├─ childIsCorrect: ""
  ├─ aiConfidence: ""
  └─ parentActionType: ""

# 会话 WebSocket 连接映射（Set，支持重连）
colearn:ws:{sessionId}
  └─ members: ["parent:connId1", "child:connId2"]
  注：单设备场景通常只有一个连接，但保留扩展能力

# 活跃会话列表（Sorted Set，按最后活跃时间排序，用于超时扫描）
colearn:active_sessions
  └─ score = lastActiveTime, member = sessionId

# 分布式锁（防止并发操作冲突）
colearn:lock:session:{sessionId}
  └─ value = operationId, TTL = 10s

# 幂等键（防止重复提交）
colearn:idempotent:{operationType}:{clientEventId}
  └─ value = "1", TTL = 60s
```

### 5.2 TTL 策略

| Key 模式 | TTL | 说明 |
|---------|-----|------|
| `colearn:session:*` | 会话结束后 1 小时 | 会话结束后延迟删除，供报告查询 |
| `colearn:task:*` | 跟随会话 TTL | 随会话一起清理 |
| `colearn:ws:*` | 无（主动清理） | 断线时主动移除 |
| `colearn:active_sessions` | 无（定时扫描清理） | 通过定时任务清理过期条目 |
| `colearn:lock:*` | 10 秒 | 自动过期释放 |
| `colearn:idempotent:*` | 60 秒 | 防止短时间重复提交 |
