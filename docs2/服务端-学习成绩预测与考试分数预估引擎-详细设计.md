## 1. 模块概述

### 1.1 背景与问题

PrimeTop 已有完善的学情分析、能力评估、错题整理等模块，能回答"学生当前的水平是什么"。但缺少一个关键能力：**预测学生未来的考试成绩**。

家长和学生的核心诉求：
- "按目前的学习状态，期中考试大概能考多少分？"
- "距离目标高中还差多少？现在该怎么努力？"
- "如果每天多学 30 分钟，成绩能提升多少？"
- "哪些知识点是提分最快的突破口？"

### 1.2 功能目标

构建基于多维历史数据的**成绩预测与提分路径推荐引擎**（Score Prediction & Improvement Path Engine，简称 SPICE），提供：

1. **考试分数预估**：基于当前能力值、学习趋势、知识点掌握度，预测指定考试的成绩区间
2. **提分空间分析**：识别提分性价比最高的知识点和题型
3. **场景模拟**：模拟不同学习投入下的成绩变化
4. **预测准确度追踪**：持续校准预测模型，提升准确率

### 1.3 核心价值

| 价值维度 | 说明 |
|---------|------|
| **目标可视化** | 将抽象的"努力"转化为具体的"预期分数" |
| **行动指导** | 告诉学生"练什么提分最快"，而非泛泛的"你需要努力" |
| **家长沟通** | 家长报告中的预测数据比历史数据更有决策参考价值 |
| **商业转化** | 预测结果可作为增值服务/会员专属功能 |

### 1.4 设计约束

1. **可解释性优先**：不使用黑盒深度学习模型，所有预测必须能解释推理过程
2. **数据不足时降级**：新用户/数据不足时提供基于群体统计的粗略预估
3. **隐私敏感**：预测结果涉及学生学业评价，仅对本人和家长（已绑定）开放
4. **避免焦虑传递**：预测展示以区间+建议为主，避免展示绝对排名预测

## 4. 预测算法核心设计

### 4.1 算法整体架构

预测采用**分层加权融合模型**，分为四层：

```
Layer 1: 基础分估算 (BaselineEstimator)
    │   基于 IRT 能力值 θ + 考试难度参数 → 期望分数
    │
Layer 2: 趋势修正 (TrendModifier)
    │   基于近 4~8 周学习速率和成绩变化趋势 → 修正量
    │
Layer 3: 行为因子调整 (BehaviorModifier)
    │   基于学习时长稳定性、练习频率、错题订正率 → 调整量
    │
Layer 4: 融合输出 (FusionOutputter)
    │   加权融合 → 点估计 + 置信区间 + 因素分解
```

### 4.2 Layer 1：基础分估算

基于 IRT（项目反应理论）能力值和考试难度参数计算期望分数。

```python
class BaselineEstimator:
    """基础分估算器"""

    def estimate(self, theta: float, exam_difficulty_profile: dict,
                 mastery_distribution: dict, full_score: float) -> float:
        """
        基于能力值θ和考试难度画像估算基础分。

        Args:
            theta: 学生 IRT 能力值 (-3.0 ~ 3.0)
            exam_difficulty_profile: 考试难度画像
                {"easy_ratio": 0.3, "medium_ratio": 0.5, "hard_ratio": 0.2,
                 "avg_difficulty": 0.55}
            mastery_distribution: 知识点掌握度分布
                {"mastered": 0.45, "learning": 0.30, "weak": 0.20, "unknown": 0.05}
            full_score: 满分值

        Returns:
            基础预估分（百分制）
        """
        # Step 1: 基于θ估算各难度层正确率 (3PL模型简化版)
        easy_acc = self._irt_correct_rate(theta, difficulty=-1.0)
        medium_acc = self._irt_correct_rate(theta, difficulty=0.0)
        hard_acc = self._irt_correct_rate(theta, difficulty=1.5)

        # Step 2: 加权计算期望正确率
        expected_accuracy = (
            easy_acc * exam_difficulty_profile["easy_ratio"] +
            medium_acc * exam_difficulty_profile["medium_ratio"] +
            hard_acc * exam_difficulty_profile["hard_ratio"]
        )

        # Step 3: 掌握度分布修正
        mastery_bonus = (
            mastery_distribution["mastered"] * 0.15 +
            mastery_distribution["learning"] * 0.05 -
            mastery_distribution["weak"] * 0.10
        )

        # Step 4: 计算基础分
        base_score = (expected_accuracy + mastery_bonus) * full_score
        base_score = max(0, min(full_score, base_score))

        return round(base_score, 2)

    def _irt_correct_rate(self, theta: float, difficulty: float,
                          a: float = 1.2, c: float = 0.25) -> float:
        """3PL模型正确率 P(θ) = c + (1-c) / (1 + exp(-a*(θ-b)))"""
        import math
        return c + (1 - c) / (1 + math.exp(-a * (theta - difficulty)))
```

### 4.3 Layer 2：趋势修正

```python
class TrendModifier:
    """趋势修正器：基于近期学习速率和成绩变化趋势"""

    LEARNING_RATE_WEIGHTS = {
        "4w": 0.40,   # 近4周
        "8w": 0.35,   # 近8周
        "12w": 0.25,  # 近12周
    }

    def modify(self, base_score: float, historical_data: dict) -> tuple:
        """
        计算趋势修正量。

        Returns:
            (修正量, 趋势方向)
        """
        # 成绩趋势：基于近期模拟考试/练习成绩的变化率
        score_slope_4w = historical_data.get("score_slope_4w", 0.0)  # 每周变化率
        score_slope_8w = historical_data.get("score_slope_8w", 0.0)
        score_slope_12w = historical_data.get("score_slope_12w", 0.0)

        # 学习投入趋势：每周学习时长变化
        study_minutes_slope = historical_data.get("study_minutes_slope", 0.0)

        # 知识点掌握度增速：每周新掌握的知识点数量
        mastery_growth_rate = historical_data.get("mastery_growth_rate", 0.0)

        # 综合趋势分
        trend_score = (
            score_slope_4w * 0.40 +
            score_slope_8w * 0.25 +
            study_minutes_slope * 0.5 +   # 每增加10分钟/周 → +0.5分
            mastery_growth_rate * 2.0      # 每周多掌握1个知识点 → +2分
        )

        # 趋势方向判定
        if trend_score > 2.0:
            direction = "IMPROVING"
        elif trend_score < -1.5:
            direction = "DECLINING"
        else:
            direction = "STABLE"

        return round(trend_score, 2), direction
```

### 4.4 Layer 3：行为因子调整

```python
class BehaviorModifier:
    """行为因子调整器"""

    def adjust(self, historical_data: dict) -> tuple:
        """
        基于学习行为模式计算调整量。

        Returns:
            (调整量, 行为因子列表)
        """
        factors = []

        # 因子1: 学习时长稳定性 (变异系数越低越好)
        cv = historical_data.get("study_duration_cv", 0.5)
        stability_score = max(0, (0.5 - cv)) * 20  # -10 ~ +0
        factors.append(("STABILITY", stability_score))

        # 因子2: 练习频率 (每周练习天数)
        weekly_practice_days = historical_data.get("weekly_practice_days", 3)
        frequency_score = (weekly_practice_days - 3) * 1.5  # 基准3天
        factors.append(("FREQUENCY", frequency_score))

        # 因子3: 错题订正率
        correction_rate = historical_data.get("mistake_correction_rate", 0.3)
        correction_score = (correction_rate - 0.3) * 15  # 基准30%
        factors.append(("CORRECTION", correction_score))

        # 因子4: 考前冲刺指数（考前2周学习量是否增加）
        pre_exam_boost = historical_data.get("pre_exam_boost", 1.0)
        boost_score = (pre_exam_boost - 1.0) * 5  # 增长20% → +1分
        factors.append(("PRE_EXAM", boost_score))

        # 因子5: AI辅导互动深度 (追问次数、同类题练习)
        ai_interaction_depth = historical_data.get("ai_interaction_depth", 0.5)
        depth_score = (ai_interaction_depth - 0.5) * 8
        factors.append(("AI_DEPTH", depth_score))

        total_adjustment = sum(score for _, score in factors)
        # 限制总调整幅度在 -15 ~ +15 分
        total_adjustment = max(-15, min(15, total_adjustment))

        return round(total_adjustment, 2), factors
```

### 4.5 Layer 4：融合输出

```python
class FusionOutputter:
    """融合输出器"""

    def fuse(self, base_score: float, trend_delta: float,
             behavior_delta: float, behavior_factors: list,
             confidence_input: dict) -> dict:
        """
        融合三层结果，输出最终预测。
        """
        # 加权融合 (Layer1为主, Layer2/3为修正)
        predicted = base_score + trend_delta + behavior_delta

        # 置信度计算
        confidence = self._calculate_confidence(confidence_input)

        # 置信区间 (分数标准差估算)
        if confidence >= 0.7:
            margin = 8.0   # ±8分
        elif confidence >= 0.5:
            margin = 14.0  # ±14分
        else:
            margin = 22.0  # ±22分

        lower = predicted - margin
        upper = predicted + margin

        return {
            "predicted_score": round(predicted, 2),
            "score_lower_bound": round(lower, 2),
            "score_upper_bound": round(upper, 2),
            "confidence_level": round(confidence, 3),
            "factor_breakdown": {
                "base_score": round(base_score, 2),
                "trend_delta": round(trend_delta, 2),
                "behavior_delta": round(behavior_delta, 2),
                "behavior_factors": [
                    {"name": name, "score": round(s, 2)}
                    for name, s in behavior_factors
                ]
            }
        }

    def _calculate_confidence(self, data: dict) -> float:
        """基于数据充分性计算置信度"""
        confidence = 0.0

        # 数据量因子
        total_questions = data.get("total_questions_answered", 0)
        if total_questions > 500:
            confidence += 0.35
        elif total_questions > 200:
            confidence += 0.25
        elif total_questions > 50:
            confidence += 0.15

        # 历史考试次数
        past_exams = data.get("past_exam_count", 0)
        if past_exams >= 5:
            confidence += 0.25
        elif past_exams >= 3:
            confidence += 0.18
        elif past_exams >= 1:
            confidence += 0.08

        # 学习持续时间
        active_weeks = data.get("active_learning_weeks", 0)
        if active_weeks >= 8:
            confidence += 0.20
        elif active_weeks >= 4:
            confidence += 0.12

        # 知识点覆盖率
        coverage = data.get("knowledge_coverage_ratio", 0)
        confidence += coverage * 0.20

        return min(0.95, confidence)
```

    """预测冷启动策略"""

    def get_cold_start_prediction(self, user_profile: dict,
                                   subject_code: str, full_score: float) -> dict:

## 5. 提分路径推荐算法

### 5.1 提分性价比评分模型

对每个知识点计算"提分性价比"（ROI Score），优先推荐 ROI 最高的知识点。

```python
class ImprovementPathRecommender:
    """提分路径推荐器"""

    def recommend(self, user_id: int, subject_code: str,
                  target_score: float, current_score: float,
                  available_weeks: int) -> dict:
        """
        生成提分路径推荐。
        """
        score_gap = target_score - current_score

        if score_gap <= 0:
            return {"achievable": True, "priorityTopics": [],
                    "message": "当前预测已达到目标分数"}

        # Step 1: 获取该学科所有知识点的掌握度和考试权重
        knowledge_points = self._get_knowledge_points_with_weight(user_id, subject_code)

        # Step 2: 对每个知识点计算提分ROI
        roi_list = []
        for kp in knowledge_points:
            roi = self._calculate_roi(kp, score_gap, available_weeks)
            if roi["estimated_gain"] > 0.5:  # 过滤掉收益过小的
                roi_list.append(roi)

        # Step 3: 按ROI排序，贪心选择
        roi_list.sort(key=lambda x: x["roi_score"], reverse=True)

        # Step 4: 贪心填充直到填满分数差距
        selected = []
        accumulated_gain = 0.0
        for roi in roi_list:
            if accumulated_gain >= score_gap:
                break
            selected.append(roi)
            accumulated_gain += roi["estimated_gain"]

        # Step 5: 排序为优先级
        selected.sort(key=lambda x: x["roi_score"], reverse=True)
        for i, item in enumerate(selected):
            item["priority_rank"] = i + 1

        achievable = accumulated_gain >= score_gap * 0.85

        return {
            "current_predicted_score": current_score,
            "target_score": target_score,
            "score_gap": round(score_gap, 2),
            "achievable": achievable,
            "estimated_weeks": self._estimate_weeks(selected, available_weeks),
            "priority_topics": selected
        }

    def _calculate_roi(self, kp: dict, score_gap: float,
                       available_weeks: int) -> dict:
        """
        计算单个知识点的提分ROI。

        ROI = 预估提分 / 所需时间
        """
        mastery = kp["current_mastery"]
        weight = kp["exam_weight"]  # 该知识点在考试中的权重(0-1)
        difficulty = kp["difficulty"]  # 1-5

        # 理论最大提分：从当前掌握度提升到0.85
        target_mastery = min(0.85, mastery + 0.40)
        mastery_delta = target_mastery - mastery

        # 预估提分 = 权重 × 掌握度增量 × 满分 × 转换系数
        estimated_gain = weight * mastery_delta * 100 * 0.6  # 转换系数0.6

        # 所需时间估算 (分钟)
        difficulty_multiplier = {1: 1.0, 2: 1.2, 3: 1.5, 4: 2.0, 5: 2.5}
        estimated_minutes = int(
            mastery_delta * 600 * difficulty_multiplier.get(difficulty, 1.5)
        )

        # ROI评分 = 提分 / sqrt(时间) (时间平方根做边际递减)
        import math
        roi_score = estimated_gain / math.sqrt(max(30, estimated_minutes))

        return {
            "knowledge_point_id": kp["id"],
            "knowledge_point_name": kp["name"],
            "current_mastery": round(mastery, 2),
            "target_mastery": round(target_mastery, 2),
            "impact_score": round(estimated_gain, 2),
            "estimated_minutes": estimated_minutes,
            "difficulty": kp["difficulty_label"],
            "roi_score": round(roi_score, 4),
            "suggestion": self._generate_suggestion(kp, mastery, target_mastery),
            "recommended_actions": self._recommend_actions(kp)
        }
```

class ScenarioSimulator:

    def simulate_time_change(self, current_prediction: dict,
                              daily_delta: int, weeks: int) -> dict:
        """模拟学习时长变化的分数影响"""
        # 基于历史数据估算"每分钟学习产出"

        return 1.0  # 默认平均效率

### 7.2 模型校准策略

```python
class ModelCalibrator:
    """模型校准器"""

    CALIBRATION_THRESHOLD = 50  # 每积累50个验证样本触发一次校准

    def check_and_calibrate(self, subject_code: str):
        """检查是否需要校准模型参数"""
        recent_samples = self._get_recent_verifications(
            subject_code, limit=self.CALIBRATION_THRESHOLD
        )

        if len(recent_samples) < self.CALIBRATION_THRESHOLD:
            return

        # 计算关键指标
        avg_error = sum(s["prediction_error"] for s in recent_samples) / len(recent_samples)
        within_rate = sum(1 for s in recent_samples if s["within_confidence"]) / len(recent_samples)

        # 系统性偏差检测
        signed_errors = [s["actual"] - s["predicted"] for s in recent_samples]
        avg_bias = sum(signed_errors) / len(signed_errors)

        if abs(avg_bias) > 3.0:
            # 存在系统性高估或低估
            direction = "高估" if avg_bias < 0 else "低估"
            self._log_calibration_issue(
                subject_code, avg_error, within_rate,
                avg_bias, f"模型存在系统性{direction}，偏差{abs(avg_bias):.1f}分"
            )

        # 如果区间覆盖率低于80%，需要扩大置信区间
        if within_rate < 0.80:
            self._adjust_confidence_margin(subject_code, expand=True)

        # 如果平均误差持续小于3分，可以缩小置信区间（提升精度展示）
        if avg_error < 3.0 and within_rate > 0.95:
            self._adjust_confidence_margin(subject_code, expand=False)
```
