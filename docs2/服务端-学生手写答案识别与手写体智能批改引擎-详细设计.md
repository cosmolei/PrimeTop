# 服务端-学生手写答案识别与手写体智能批改引擎 - 详细设计

## 1. 概述

### 1.1 模块定位

学生手写答案识别与手写体智能批改引擎（Handwritten Answer Recognition & Intelligent Grading Engine，简称 HARG Engine）是 PrimeTop 平台手写体处理的核心服务端子系统。当学生通过拍照上传手写作业、试卷答卷、练习解答时，本引擎负责将手写图像转化为结构化文本/公式/图形数据，并据此进行自动批改与过程性评价。

与现有模块的差异化定位：

| 已有模块 | 覆盖范围 | 与本引擎的区别 |
|---------|---------|--------------|
| 图片处理与OCR识别管线 | 印刷体题目识别（拍题搜题） | OCR 管线聚焦印刷体，手写体准确率仅 85% 且不做批改 |
| 汉字笔画顺序检测系统 | 触屏实时书写轨迹评估 | 该系统针对幼小阶段触屏写字，不涉及纸上手写内容识别 |
| 智能作业批改与教师阅卷辅助引擎 | 教师端作业批改流程 | 该引擎聚焦批改工作流，手写识别是其上游数据源之一 |
| 主观题智能评分与自适应反馈引擎 | 文本型主观题评分 | 该引擎处理已数字化的文本，不涉及手写体识别 |

**本引擎的核心职责：**
1. 手写体识别（HTR）：纸上手写文字、数字、符号的高准确率识别
2. 数学表达式识别（HMER）：手写公式、方程、推导过程的 LaTeX 结构化
3. 化学方程式识别：手写化学式、反应方程式的结构化
4. 图形/图表理解：手绘几何图形、力学图、电路图的语义提取
5. 手写答案批改：基于识别结果进行分步评分与过程性评价
6. 识别质量保障：置信度评估、人工审核触发、模型自学习闭环

### 1.2 核心业务场景

| 场景 | 描述 | 典型输入 | 期望输出 |
|------|------|---------|---------|
| 数学作业批改 | 学生在纸上完成数学解答后拍照上传 | 手写解题步骤照片 | 分步识别 + 每步正确性判断 + 部分分 |
| 物理实验报告 | 学生手写实验数据和结论 | 手写实验报告照片 | 数据提取 + 结论正确性判断 |
| 化学方程式听写 | 学生手写化学反应方程式 | 手写化学式照片 | 方程式结构化 + 配平检查 |
| 语文作文初稿 | 学生手写作文后拍照 | 手写作文照片 | 文本数字化 + 错别字检测 + 批改建议 |
| 英语听写练习 | 学生手写英语单词/句子 | 手写英文照片 | 文本识别 + 拼写检查 |
| 试卷答题卡 | 学生在标准答题卡上手写答案 | 答题卡扫描图 | 各题答案提取 + 自动评分 |

### 1.3 设计目标

| 目标维度 | 指标 |
|---------|------|
| 数学表达式识别准确率 | ≥ 92%（中小学常见公式），≥ 85%（高中复杂公式） |
| 中文手写识别准确率 | ≥ 94%（常用字），≥ 88%（生僻字/潦草字） |
| 英文手写识别准确率 | ≥ 93%（单词级），≥ 88%（连续手写句子） |
| 化学方程式识别准确率 | ≥ 90%（标准格式） |
| 手绘几何图形识别率 | ≥ 85%（三角形、圆、矩形、函数图像） |
| 单题批改延迟（P95） | ≤ 4 秒 |
| 多题批改延迟（P95，≤ 10 题） | ≤ 15 秒 |
| 批改结果与教师评分一致性 | ≥ 88%（分步部分分一致性） |
| 端到端吞吐 | 峰值 200 张图片/秒 |

### 2.2 处理流程总览

```
学生上传手写答案图片
        │
        ▼
[1] 图片接收与质量检查 ─── 不合格 ──→ 返回错误提示
        │ (合格)
        ▼
[2] 图像预处理 (去噪/矫正/区域分割)
        │
        ▼
[3] 内容类型判定 (数学/语文/英语/化学/混合)
        │
        ├─ 数学/理科 ──→ [4a] HMER 数学表达式识别
        ├─ 文字内容  ──→ [4b] HTR 手写文本识别
        ├─ 化学方程式 ──→ [4c] 化学式结构化识别
        └─ 图形内容  ──→ [4d] 手绘图形识别
        │
        ▼
[5] 识别结果后处理 (去歧义/合并/格式化)
        │
        ▼
[6] 置信度评估 ─── 低置信度 ──→ [6a] 人工审核队列
        │ (高置信度)               │
        ▼                         ▼
[7] 自动批改评分            [6b] 教师人工批改
        │                         │
        ▼                         ▼
[8] 结果入库 + 推送通知 ←──── 结果回填
```

#### 3.1.1 手写识别任务表 `harg_recognition_tasks`

```sql
CREATE TABLE harg_recognition_tasks (
    id              BIGINT PRIMARY KEY COMMENT '分布式ID',
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    task_type       VARCHAR(32) NOT NULL COMMENT '任务类型: MATH_HOMEWORK|EXAM_PAPER|ESSAY|CHEMISTRY|MIXED',
    source_type     VARCHAR(32) NOT NULL COMMENT '来源: HOMEWORK|EXAM|PRACTICE|UPLOAD',
    source_id       BIGINT COMMENT '来源ID(作业ID/考试ID等)',
    image_urls      JSON NOT NULL COMMENT '图片URL列表',
    status          VARCHAR(32) NOT NULL DEFAULT 'PENDING' COMMENT '状态: PENDING|PROCESSING|RECOGNIZED|GRADED|REVIEW|FAILED',
    priority        INT NOT NULL DEFAULT 5 COMMENT '优先级 1-10, 10最高',
    subject         VARCHAR(16) COMMENT '学科: MATH|PHYSICS|CHEMISTRY|CHINESE|ENGLISH|BIOLOGY',
    grade_level     INT COMMENT '学生年级',
    textbook_ver    VARCHAR(32) COMMENT '教材版本',
    
    -- 识别相关
    recognition_started_at  DATETIME COMMENT '识别开始时间',
    recognition_completed_at DATETIME COMMENT '识别完成时间',
    recognition_result_json JSON COMMENT '识别原始结果JSON',
    avg_confidence         DECIMAL(5,4) COMMENT '平均置信度 0-1',
    
    -- 批改相关
    grading_started_at     DATETIME COMMENT '批改开始时间',
    grading_completed_at   DATETIME COMMENT '批改完成时间',
    grading_result_json    JSON COMMENT '批改结果JSON',
    total_score            DECIMAL(6,2) COMMENT '总得分',
    max_score              DECIMAL(6,2) COMMENT '满分',
    
    -- 审核相关
    review_status          VARCHAR(32) DEFAULT 'NONE' COMMENT 'NONE|PENDING_REVIEW|REVIEWED|OVERRIDDEN',
    reviewer_id            BIGINT COMMENT '审核人(教师)ID',
    reviewed_at            DATETIME COMMENT '审核时间',
    review_result_json     JSON COMMENT '审核修正后的结果',
    
    error_code     VARCHAR(64) COMMENT '错误码',
    error_message  TEXT COMMENT '错误详情',
    retry_count    INT DEFAULT 0 COMMENT '重试次数',
    
    created_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_status (user_id, status),
    INDEX idx_source (source_type, source_id),
    INDEX idx_review (review_status),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='手写识别批改任务表';
```

## 4. API 接口设计

### 4.1 接口总览

| # | 接口 | 方法 | 路径 | 说明 |
|---|------|------|------|------|
| 1 | 提交手写批改任务 | POST | `/api/v1/harg/tasks` | 上传图片，创建识别批改任务 |

### 5.1 图像预处理子系统

#### 5.1.1 处理管线

```python
class HandwritingImagePreprocessor:
    """手写图像预处理管线"""
    
    PIPELINE_STEPS = [
        "load_and_validate",    # 加载与基本验证
        "orientation_detect",   # 方向检测 (0/90/180/270)
        "deskew",              # 倾斜矫正
        "illumination_norm",   # 光照均衡
        "denoise",             # 去噪
        "binarize",            # 二值化 (自适应阈值)
        "line_removal",        # 横线/网格线去除
        "region_segment",      # 区域分割 (题目/公式/图形)
        "quality_assess",      # 质量评估
    ]
    
    def process(self, image_url: str, subject: str, grade: int) -> PreprocessResult:
        """执行完整预处理管线"""
        # 1. 加载并验证图片
        raw = self.load_image(image_url)
        if not self.validate_image(raw):
            raise ImageQualityError("图片分辨率过低或损坏")
        
        # 2. 方向检测与矫正
        angle = self.detect_orientation(raw)
        if angle != 0:
            raw = self.rotate(raw, angle)
        
        # 3. 倾斜矫正 (精细级 ±5°)
        deskew_angle = self.compute_deskew_angle(raw)
        raw = self.rotate(raw, deskew_angle, interpolation=cv2.INTER_CUBIC)
        
        # 4. 光照均衡 (CLAHE)
        raw = self.normalize_illumination(raw)
        
        # 5. 去噪 (非局部均值 / BM3D)
        if self.estimate_noise(raw) > 15:
            raw = self.denoise(raw, method="nlm", strength=10)
        
        # 6. 自适应二值化 (Sauvola 或自适应高斯)
        binary = self.binarize(raw, method="sauvola", window=25, k=0.2)
        
        # 7. 横线/网格线去除
        if subject in ("MATH", "PHYSICS", "CHEMISTRY"):
            # 理科作业常有横线，会干扰公式识别
            binary = self.remove_lines(binary, 
                                       min_line_length=100,
                                       max_line_thickness=3)
        
        # 8. 区域分割
        regions = self.segment_regions(binary, subject, grade)
        
        # 9. 质量评估
        quality = self.assess_quality(raw, binary)
        if quality.score < 0.4:
            return PreprocessResult(
                status="LOW_QUALITY",
                quality=quality,
                suggestion="图片模糊或光线不足，建议在光线充足处重新拍摄"
            )
        
        return PreprocessResult(
            status="OK",
            processed_image=raw,
            binary_image=binary,
            regions=regions,
            quality=quality
        )
```

#### 5.1.2 区域分割算法

区域分割的目标是将一张完整的手写作业图片切分为独立的题目区域、公式区域和图形区域。

```python
@dataclass
class Region:
    """检测到的区域"""
    region_type: str    # QUESTION / FORMULA / FIGURE / TEXT
    bbox: BoundingBox   # 边界框 {x, y, w, h}
    confidence: float
    question_index: Optional[int] = None  # 题号(如能识别)


class RegionSegmenter:
    """基于连通域分析与启发式规则的区域分割"""
    
    def segment(self, binary_image: np.ndarray, subject: str) -> List[Region]:
        # Step 1: 题号检测 — 识别 "1." "2." "3)" "(1)" 等题号标记
        question_markers = self.detect_question_markers(binary_image)
        
        # Step 2: 基于题号位置进行水平切分
        horizontal_cuts = self.compute_horizontal_cuts(question_markers, binary_image)
        
        # Step 3: 在每个水平条带内，识别内容类型
        regions = []
        for i, (y_start, y_end) in enumerate(horizontal_cuts):
            strip = binary_image[y_start:y_end, :]
            
            # 检测是否包含公式 (通过密度特征+笔画特征)
            has_formula = self.detect_formula_region(strip)
            
            # 检测是否包含图形
            has_figure = self.detect_figure_region(strip)
            
            if has_figure:
                fig_bbox = self.extract_figure_bbox(strip)
                regions.append(Region("FIGURE", fig_bbox, 0.85))
            
            if has_formula:
                formula_bbox = self.extract_formula_bbox(strip, exclude=[fig_bbox] if has_figure else [])
                regions.append(Region("FORMULA", formula_bbox, 0.90))
            
            # 剩余区域为文本
            text_bbox = self.extract_text_bbox(strip, exclude=[r.bbox for r in regions if r.region_type != "TEXT"])
            if text_bbox.area > MIN_REGION_AREA:
                regions.append(Region("TEXT", text_bbox, 0.88))
            
            # 关联题号
            if i < len(question_markers):
                regions[-1].question_index = question_markers[i].number
        
        return regions
```

#### 5.2.3 二阶段识别策略

为提高中小学场景识别准确率，采用 **粗识别 → 精校正** 二阶段策略：

```python
class HMERPipeline:
    """手写数学表达式识别管线"""
    
    def __init__(self, coarse_model: CoMER, refine_model: CoMER, 
                 latex_validator: LatexValidator):
        self.coarse_model = coarse_model      # 粗识别模型(快速)
        self.refine_model = refine_model      # 精细模型(高准确率)
        self.latex_validator = latex_validator
    
    async def recognize(self, image: np.ndarray, 
                        context: RecognitionContext) -> HMERResult:
        # 阶段1：粗识别
        coarse_latex = await self.coarse_model.infer(image)
        coarse_confidence = self.coarse_model.last_confidence
        
        # 阶段2：LaTeX 合法性检查
        is_valid, errors = self.latex_validator.validate(coarse_latex)
        
        if is_valid and coarse_confidence > 0.92:
            # 高置信度 + 合法 LaTeX → 直接返回
            return HMERResult(latex=coarse_latex, confidence=coarse_confidence,
                            stage="COARSE", need_review=False)
        
        # 阶段3：低置信度或非法 LaTeX → 精细模型
        refined_latex = await self.refine_model.infer(
            image, 
            hint=self._generate_hint(coarse_latex, errors, context)
        )
        refined_confidence = self.refine_model.last_confidence
        
        # 阶段4：结果选择
        candidates = [
            (coarse_latex, coarse_confidence),
            (refined_latex, refined_confidence),
        ]
        best = self._select_best(candidates, context)
        
        # 阶段5：LaTeX 后处理 (修正常见错误模式)
        best.latex = self._post_fix(best.latex, context)
        
        return best
    
    def _post_fix(self, latex: str, context: RecognitionContext) -> str:
        """基于规则的常见错误修正"""
        fixes = {
            # 混淆修正
            r"l\b(?=[^a-zA-Z])": "1",   # 小写l → 1 (数字上下文)
            r"O\b(?=[^a-zA-Z])": "0",   # 大写O → 0
            r"\|": "\\mid",              # | → \mid (数学上下文)
            # 常见中小学符号修正
            r"×": "\\times",
            r"÷": "\\div",
            r"≤": "\\leq",
            r"≥": "\\geq",
            r"≠": "\\neq",
            r"≈": "\\approx",
            r"∞": "\\infty",
            r"∠": "\\angle",
            r"⊥": "\\perp",
            r"∥": "\\parallel",
            r"△": "\\triangle",
            r"°": "^{\\circ}",
            r"√": "\\sqrt",
            r"∵": "\\because",
            r"∴": "\\therefore",
        }
        for pattern, replacement in fixes.items():
            latex = re.sub(pattern, replacement, latex)
        return latex
```

### 5.3 中文手写文本识别 (HTR-CN)

#### 5.3.1 模型架构

采用 **CRNN + CTC + Attention 混合** 架构，兼顾速度和准确率：

```
输入：手写文本行图像 (H=48, W=variable, C=1)
  │
  ▼
┌──────────────────────────────────────┐
│  ResNet-18 特征提取器                  │
│  - 输出序列特征 (T × 512)              │
└──────────────────┬───────────────────┘
                   │
        ┌──────────┴──────────┐
        │                     │
        ▼                     ▼
┌──────────────┐     ┌──────────────┐
│  BiLSTM      │     │  Transformer │
│  Encoder     │     │  Decoder     │
│  (CTC 分支)  │     │  (Attn 分支) │
└──────┬───────┘     └──────┬───────┘
       │                    │
       ▼                    ▼
   CTC Loss            CrossEntropy
   (对齐无关)          (对齐相关)
       │                    │

                  │
                  ▼
```

#### 5.3.2 识别策略

```python
class ChineseHTRPipeline:
    """中文手写文本识别管线"""
    
    async def recognize(self, line_images: List[np.ndarray],
                       context: RecognitionContext) -> List[TextLineResult]:
        results = []
        for line_img in line_images:
            # 双分支并行识别
            ctc_result, attn_result = await asyncio.gather(
                self.ctc_model.infer(line_img),
                self.attn_model.infer(line_img)
            )
            
            # 集成选择策略
            if self._edit_distance(ctc_result.text, attn_result.text) <= 2:
                # 两分支结果接近 → 取置信度高的
                chosen = ctc_result if ctc_result.confidence > attn_result.confidence else attn_result
            else:
                # 分歧较大 → 使用语言模型重排序
                candidates = [ctc_result.text, attn_result.text]
                reranked = self.lm_rerank(candidates, context=context)
                chosen = reranked[0]
            
            # 后处理：基于上下文的修正
            chosen.text = self._contextual_postfix(chosen.text, context)
            
            results.append(chosen)
        
        return results
    
    def _contextual_postfix(self, text: str, context: RecognitionContext) -> str:
        """上下文感知后处理"""
        # 1. 同音字纠正 (基于上下文)
        text = self.homophone_corrector.correct(text, context.sentence_context)
        
        # 2. 学科术语修正
        if context.subject == "MATH":
            term_fixes = {
                "因为": "∵", "所以": "∴", "等于": "=",
                "大薪": "大概", "正名": "证明",
            }
            for wrong, right in term_fixes.items():
                text = text.replace(wrong, right)
        
        # 3. 标点符号规范化
        text = self.punctuation_normalizer.normalize(text)
        
        return text
```

### 5.4 自动批改评分子系统

#### 5.4.1 分步评分架构

```python
class HandwritingGradingEngine:
    """手写答案自动批改引擎"""
    
    async def grade(
        self,
        recognition_result: RecognitionResult,
        question_meta: QuestionMeta,
        standard_answer: StandardAnswer,
        grading_config: GradingConfig
    ) -> GradingResult:
        """
        对识别后的手写答案进行分步批改。
        
        Args:
            recognition_result: 手写识别结果
            question_meta: 题目元数据(题型/分值/知识点)
            standard_answer: 标准答案 + 评分标准
            grading_config: 批改配置(从严/标准/从宽)
        """
        
        # Step 1: 根据题型选择批改策略
        strategy = self._select_strategy(question_meta.question_type)
        
        # Step 2: 执行批改
        if strategy == "MATH_SOLUTION":
            result = await self._grade_math_solution(
                recognition_result, standard_answer, grading_config
            )
        elif strategy == "SHORT_ANSWER":
            result = await self._grade_short_answer(
                recognition_result, standard_answer, grading_config
            )
        elif strategy == "ESSAY":
            result = await self._grade_essay(
                recognition_result, standard_answer, grading_config
            )
        elif strategy == "FILL_BLANK":
            result = await self._grade_fill_blank(
                recognition_result, standard_answer, grading_config
            )
        else:
            result = await self._grade_generic(
                recognition_result, standard_answer, grading_config
            )
        
        # Step 3: 知识点关联分析
        result.knowledge_points = self._map_knowledge_points(
            result.error_steps, question_meta
        )
        
        # Step 4: 生成评语
        result.feedback = await self._generate_feedback(result, question_meta)
        
        # Step 5: 识别-批改联合置信度
        result.combined_confidence = self._compute_combined_confidence(
            recognition_result.avg_confidence,
            result.grading_confidence
        )
        
        return result
```

```python
        """
        将学生手写识别结果与标准答案的分步评分标准进行匹配，
        逐步判断正确性，最终计算部分分。
        """
        # 1. 将学生解答切分为步骤
        student_steps = self._split_steps(recognition.recognized_latex)
        
        # 2. 获取标准答案的评分步骤
        standard_steps = standard.grading_steps  # 已标注的评分标准
        
        # 3. 对齐学生步骤与标准步骤 (DTW + 语义匹配)
        alignment = self._align_steps(student_steps, standard_steps)
        # alignment: List[(student_step_idx, standard_step_idx, match_score)]
        
        # 4. 逐步评估
        step_results = []
        total_score = 0.0
        
        for stu_idx, std_idx, match_score in alignment:
            if std_idx is not None:
                std_step = standard_steps[std_idx]
                stu_step = student_steps[stu_idx] if stu_idx is not None else None
                
                if stu_step is None:
                    # 漏步
                    step_results.append(StepResult(
                        step_number=std_idx + 1,
                        status="MISSING",
                        score=0,
                        max_score=std_step.score,
                        comment="缺少此步骤"
                    ))
                    continue
                
                # 判断该步骤是否正确
                is_correct, partial_ratio = self._evaluate_step(
                    stu_step, std_step, config
                )
                
                step_score = std_step.score * (1.0 if is_correct else partial_ratio)
                total_score += step_score
                
                step_results.append(StepResult(
                    step_number=std_idx + 1,
                    status="CORRECT" if is_correct else "WRONG",
                    score=step_score,
                    max_score=std_step.score,
                    student_content=stu_step.content,
                    expected_content=std_step.content,
                    error_reason=self._diagnose_error(stu_step, std_step) if not is_correct else None,
                    comment=self._generate_step_comment(stu_step, std_step, is_correct)
                ))
            else:
                # 多余步骤 (学生写了标准答案中没有的步骤)
                step_results.append(StepResult(
                    step_number=len(step_results) + 1,
                    status="EXTRA",
                    score=0,
                    max_score=0,
                    student_content=student_steps[stu_idx].content,
                    comment="额外步骤（不影响得分）"
                ))
        
        # 5. 应用评分策略调整
        total_score = self._apply_grading_policy(total_score, step_results, config)
        
        # 6. 确定最终结果
        max_score = sum(s.score for s in standard_steps)
        is_correct = total_score >= max_score * 0.95  # 95%以上算正确
        
        return GradingResult(
            is_correct=is_correct,
            score=min(total_score, max_score),
            max_score=max_score,
            step_results=step_results,
            error_type=self._classify_error(step_results),
        )
    
    def _evaluate_step(
        self,
        student_step: MathStep,
        standard_step: MathStep,
        config: GradingConfig
    ) -> Tuple[bool, float]:
        """
        评估单步是否正确。
        返回: (是否完全正确, 部分分比率 0-1)
        """
        # 策略1：符号精确匹配 (最快)
        if self._symbolic_match(student_step.canonical_form, standard_step.canonical_form):
            return True, 1.0
        
        # 策略2：数值等价验证 (使用 SymPy)
        if self._numeric_equivalent(student_step.expr, standard_step.expr):
            return True, 1.0
        
        # 策略3：AI语义判断 (大模型判断等价性)
        ai_judgment = await self._ai_step_comparison(
            student_step.content, standard_step.content
        )
        
        if ai_judgment.is_equivalent:
            return True, 1.0
        
        if ai_judgment.partial_credit > 0:
            # 有部分分（思路对但计算错等）
            partial = ai_judgment.partial_credit
            if config.strictness == "STRICT":
                partial *= 0.7  # 从严模式打折
            elif config.strictness == "LENIENT":
                partial = min(1.0, partial * 1.2)  # 从宽模式加成
            return False, partial
        
        return False, 0.0
    
    def _symbolic_match(self, form_a: str, form_b: str) -> bool:
        """使用 SymPy 进行符号等价判断"""
        try:
            expr_a = sp.sympify(form_a)
            expr_b = sp.sympify(form_b)
            return sp.simplify(expr_a - expr_b) == 0
        except Exception:
            return False
```

```python
class ErrorDiagnostician:
    """手写答案错误类型自动诊断"""
    
    ERROR_TYPES = {
        "CONCEPT": "概念性错误 — 对基础概念理解有误",
        "CALC": "计算错误 — 运算过程中出现失误",
        "SIGN": "符号错误 — 正负号、不等号方向错误",
        "FORMAT": "格式错误 — 解题格式不规范、缺少必要步骤",
        "LOGIC": "逻辑错误 — 推理链条断裂或跳跃",
        "METHOD": "方法错误 — 解题方法选择不当",
        "TRANSFORM": "变形错误 — 公式变形/化简过程出错",
        "UNIT": "单位错误 — 量纲或单位遗漏/错误",
        "COPY": "抄写错误 — 从上一步到下一步抄写出错",
    }
    
    def diagnose(
        self,
        student_steps: List[StepResult],
        standard_steps: List[StandardStep]
    ) -> ErrorDiagnosis:
        """基于步骤对比自动诊断错误类型"""
        
        wrong_steps = [s for s in student_steps if s.status == "WRONG"]
        if not wrong_steps:
            return ErrorDiagnosis(primary_type=None, confidence=1.0)
        
        # 特征提取
        features = self._extract_error_features(wrong_steps, standard_steps)
        
        # 规则匹配 + ML 分类器
        rule_result = self._rule_based_classify(features)
        ml_result = self._ml_classify(features)
        
        # 集成选择
        if rule_result.confidence > 0.85:
            primary_type = rule_result.error_type
            confidence = rule_result.confidence
        else:
            primary_type = ml_result.error_type
            confidence = ml_result.confidence
        
        # 补充诊断细节
        detail = self._generate_detail(primary_type, features, wrong_steps)
        
        return ErrorDiagnosis(
            primary_type=primary_type,
            confidence=confidence,
            detail=detail,
            remediation=self._suggest_remediation(primary_type, features)
        )
    
    def _extract_error_features(
        self,
        wrong_steps: List[StepResult],
        standard_steps: List[StandardStep]
    ) -> ErrorFeatures:
        """提取错误特征向量"""
        features = ErrorFeatures()
        
        for step in wrong_steps:
            student_expr = step.student_content
            expected_expr = step.expected_content
            
            # 数值差异
            features.value_diff = self._compute_value_diff(student_expr, expected_expr)
            
            # 符号差异
            features.sign_diff = self._check_sign_difference(student_expr, expected_expr)
            
            # 结构相似度
            features.structural_sim = self._structural_similarity(student_expr, expected_expr)
            
            # 运算复杂度
            features.complexity = self._estimate_complexity(expected_expr)
            
            # 步骤位置
            features.step_position = step.step_number / len(standard_steps)
        
        return features
```

#### 5.5.1 多维度置信度融合

```python
class ConfidenceAssessor:
    """综合置信度评估器"""
    
    def assess(self, recognition_result: RecognitionResult, 
               grading_result: GradingResult) -> ConfidenceAssessment:
        """
        融合多个置信度信号，决定是否需要人工审核。
        """
        signals = {
            # 识别置信度
            "recognition_avg": recognition_result.avg_confidence,
            "recognition_min": min(r.confidence for r in recognition_result.regions),
            
            # 批改置信度
            "grading_confidence": grading_result.grading_confidence,
            
            # 结构合法度
            "latex_validity": recognition_result.latex_validity_score,
            "structure_consistency": recognition_result.structure_consistency,
            
            # 图像质量
            "image_quality": recognition_result.image_quality_score,
        }
        
        # 加权融合
        weights = {
            "recognition_avg": 0.25,
            "recognition_min": 0.20,
            "grading_confidence": 0.25,
            "latex_validity": 0.10,
            "structure_consistency": 0.10,
            "image_quality": 0.10,
        }
        
        fused_score = sum(signals[k] * weights[k] for k in signals)
        
        # 路由决策
        if fused_score >= 0.90:
            action = "AUTO_ACCEPT"  # 自动接受，直接推送结果
        elif fused_score >= 0.70:
            action = "AUTO_ACCEPT_WITH_FLAG"  # 接受但标记，教师可选择复核
        elif fused_score >= 0.50:
            action = "PENDING_REVIEW"  # 进入人工审核队列
        else:
            action = "REJECT_AND_RETRY"  # 拒绝，提示用户重新拍照
        
        return ConfidenceAssessment(
            fused_score=fused_score,
            signals=signals,
            action=action,
            review_priority=self._compute_review_priority(signals, grading_result)
        )
```

```java
@Component
@Slf4j
public class HargTaskConsumer {
    
    @Autowired private HargTaskService taskService;
    @Autowired private ImagePreprocessor preprocessor;
    @Autowired private HmerPipeline hmerPipeline;
    @Autowired private ChineseHtrPipeline cnHtrPipeline;

    @Autowired private ReviewQueueService reviewQueueService;
    @Autowired private ResultNotificationService notificationService;
    
    @KafkaListener(
        topics = "${harg.topic.task-created}",
        groupId = "${harg.consumer.group}",
        concurrency = "8"  // 8个并发消费者
    )
    public void onTaskCreated(TaskCreatedMessage msg) {
        Long taskId = msg.getTaskId();
        MDC.put("taskId", String.valueOf(taskId));
        
        try {
            log.info("开始处理手写批改任务: taskId={}, subject={}", 
                taskId, msg.getSubject());
            
            // 1. 更新任务状态
            taskService.updateStatus(taskId, TaskStatus.PROCESSING);
            
            // 2. 加载任务详情
            HargTask task = taskService.getById(taskId);
            
            // 3. 并行处理多张图片
            List<CompletableFuture<ImageProcessResult>> futures = task.getImageUrls()
                .stream()
                .map(imgUrl -> CompletableFuture.supplyAsync(
                    () -> processSingleImage(imgUrl, task),
                    processingExecutor
                ))
                .toList();
            
            CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
            
            // 4. 汇总结果
            List<ImageProcessResult> results = futures.stream()
                .map(CompletableFuture::join)
                .sorted(Comparator.comparingInt(ImageProcessResult::getImageIndex))
                .toList();
            
            // 5. 合并为最终识别结果
            RecognitionResult recognition = mergeResults(results, task);
            
            // 6. 自动批改
            GradingResult grading = null;
            if (task.getOptions().isEnableGrading()) {
                grading = performGrading(recognition, task);
            }
            
            // 7. 置信度评估 + 路由
            ConfidenceAssessment assessment = confidenceAssessor.assess(recognition, grading);
            
            switch (assessment.getAction()) {
                case "AUTO_ACCEPT":
                case "AUTO_ACCEPT_WITH_FLAG":
                    completeTask(taskId, recognition, grading, assessment);
                    break;
                    
                case "PENDING_REVIEW":
                    sendToReviewQueue(taskId, recognition, grading, assessment);
                    break;
                    
                case "REJECT_AND_RETRY":
                    rejectTask(taskId, "图片质量不足，请重新拍摄");
                    break;
            }
            
        } catch (Exception e) {
            log.error("任务处理失败: taskId={}", taskId, e);
            handleFailure(taskId, e);
        } finally {
            MDC.clear();
        }
    }
    
    private ImageProcessResult processSingleImage(String imageUrl, HargTask task) {
        // Step 1: 图像预处理
        PreprocessResult preprocessed = preprocessor.process(imageUrl, 
            task.getSubject(), task.getGradeLevel());
        
        if (preprocessed.getStatus() == "LOW_QUALITY") {
            return ImageProcessResult.lowQuality(imageUrl, preprocessed.getQuality());
        }
        
        // Step 2: 内容类型判定
        ContentType contentType = ContentTypeClassifier.classify(
            preprocessed, task.getSubject()
        );
        
        // Step 3: 分区域识别
        List<RegionResult> regionResults = new ArrayList<>();
        
        for (Region region : preprocessed.getRegions()) {
            RegionResult result = switch (region.getRegionType()) {
                case FORMULA -> recognizeFormula(region, preprocessed, task);
                case TEXT -> recognizeText(region, preprocessed, task);
                case FIGURE -> recognizeFigure(region, preprocessed, task);
                default -> recognizeGeneric(region, preprocessed, task);
            };
            regionResults.add(result);
        }
        
        // Step 4: 组装图片级结果
        return ImageProcessResult.builder()
            .imageUrl(imageUrl)
            .regions(regionResults)
            .quality(preprocessed.getQuality())
            .build();
    }
    
    private RegionResult recognizeFormula(Region region, PreprocessResult img, HargTask task) {
        // 裁剪公式区域
        Mat formulaImg = ImageUtils.crop(img.getProcessedImage(), region.getBbox());
        
        // 调用 HMER 管线
        HMERResult hmer = hmerPipeline.recognize(formulaImg, 
            RecognitionContext.from(task)).join();
        
        return RegionResult.builder()
            .regionType("FORMULA")
            .bbox(region.getBbox())
            .content(hmer.getLatex())
            .confidence(hmer.getConfidence())
            .build();
    }
}
```

```python
class ModelSelfLearningPipeline:
    """模型自学习闭环：收集纠正数据 → 增量训练 → 灰度评估 → 上线"""
```

```java
/**
 * 手写识别批改降级策略链
 * 当主链路出现问题时，逐级降级保证基本可用
 */
public class HargDegradationChain {
    
    public RecognitionResult recognizeWithFallback(Mat image, RecognitionContext ctx) {
        // Level 0: 完整管线 (HMER精模型 + HTR精模型)
        try {
            return fullPipeline.recognize(image, ctx);
        } catch (ModelTimeoutException e) {
            log.warn("精模型超时，降级到快速模型");
        }
        
        // Level 1: 快速管线 (轻量模型, 延迟减半, 准确率下降~5%)
        try {
            return fastPipeline.recognize(image, ctx);
        } catch (ServiceUnavailableException e) {
            log.warn("快速模型不可用，降级到通用OCR");
        }
        
        // Level 2: 通用OCR (已有OCR管线, 仅印刷体准确, 手写体准确率~75%)
        try {
            OcrResult ocr = ocrPipeline.recognize(image);
            return RecognitionResult.fromOcr(ocr, degraded=true);
        } catch (Exception e) {
            log.error("所有识别方案均不可用");
        }
        
        // Level 3: 返回原始图片，仅展示不识别
        return RecognitionResult.rawImage(image, "手写识别服务暂时不可用，请稍后重试");
    }
    
    public GradingResult gradeWithFallback(RecognitionResult recognition, 
                                            QuestionMeta question,
                                            GradingConfig config) {
        // Level 0: 分步精确批改
        try {
            return gradingEngine.grade(recognition, question, config);
        } catch (Exception e) {
            log.warn("精确批改失败，降级到AI语义批改");
        }
        
        // Level 1: AI大模型语义批改 (调用LLM判断答案正确性)
        try {
            return aiGradingService.grade(recognition, question, config);
        } catch (Exception e) {
            log.warn("AI批改不可用，降级到简单匹配");
        }
        
        // Level 2: 关键词/数值简单匹配
        return simpleMatcher.match(recognition, question);
        
        // Level 3 (隐含): 标记为"需人工批改"
    }
}
```

### 9.2 批处理调度优化

```python
class BatchInferenceScheduler:
    """GPU 批处理推理调度器"""
    
    def __init__(self, max_batch_size: int = 16, max_wait_ms: int = 100):
        self.max_batch_size = max_batch_size
        self.max_wait_ms = max_wait_ms
        self.pending_queue = asyncio.Queue()
    
    async def submit(self, image: np.ndarray, model_type: str) -> InferenceResult:
        """提交推理请求，动态组batch"""
        future = asyncio.Future()
        await self.pending_queue.put((image, model_type, future, time.time()))
        return await future
    
    async def batch_loop(self):
        """批处理主循环"""
        while True:
            batch = []
            deadline = time.time() + self.max_wait_ms / 1000
            
            # 收集请求，直到 batch 满或超时
            while len(batch) < self.max_batch_size and time.time() < deadline:
                remaining = deadline - time.time()
                if remaining <= 0:
                    break
                try:
                    item = await asyncio.wait_for(
                        self.pending_queue.get(), 
                        timeout=remaining
                    )
                    batch.append(item)
                except asyncio.TimeoutError:
                    break
            
            if not batch:
                continue
            
            # 按 model_type 分组推理
            groups = group_by(batch, key=lambda x: x[1])
            
            for model_type, items in groups.items():
                images = [item[0] for item in items]
                results = await self.model_infer(model_type, images)  # 批量推理
                
                for item, result in zip(items, results):
                    item[2].set_result(result)  # resolve future
```

```java
@Component
public class HandwritingContentFilter {
    
    public FilterResult filter(RecognitionResult recognition) {
        // 1. 文本类识别结果 → 走文本安全审核
        if (recognition.hasText()) {
            SafetyResult textSafety = textSafetyService.check(recognition.getAllText());
            if (textSafety.isBlocked()) {
                return FilterResult.blocked("检测到不当文字内容");
            }
        }
        
        // 2. 图片本身 → 走图片安全审核
        SafetyResult imageSafety = imageSafetyService.check(recognition.getSourceImageUrl());
        if (imageSafety.isBlocked()) {
            return FilterResult.blocked("图片包含不当内容");
        }
        
        // 3. 识别出的LaTeX → 检查是否包含恶意脚本
        if (recognition.hasLatex()) {
            for (String latex : recognition.getAllLatex()) {
                if (containsMaliciousPattern(latex)) {
                    return FilterResult.blocked("公式内容异常");
                }
            }
        }
        
        return FilterResult.passed();
    }
    
    private boolean containsMaliciousPattern(String latex) {
        // 检查 LaTeX 注入模式
        return latex.contains("\\input") || 
               latex.contains("\\include") ||
               latex.contains("\\write18") ||
               latex.contains("\\immediate") ||
               latex.matches(".*\\\\readline.*");
    }
}
```

### 11.1 离线评估指标体系

| 评估维度 | 指标 | 计算方式 | 目标值 |
|---------|------|---------|--------|
| **表达式识别** | ExpRate (表达式级准确率) | 完全正确的表达式 / 总表达式数 | ≥ 88% |
| | BLEU-4 | n-gram 机器翻译指标 | ≥ 0.85 |
| | CER (字符错误率) | 编辑距离 / 参考文本长度 | ≤ 8% |
| **文本识别** | CER (中文) | 字符级错误率 | ≤ 6% |
| | WER (英文, 词错误率) | 词级错误率 | ≤ 7% |
| **批改一致性** | Quadratic Weighted Kappa | 与教师评分的二次加权 Kappa | ≥ 0.85 |
| | Exact Match Rate | 与教师评分完全一致的比例 | ≥ 75% |
| | Score Error (MAE) | 平均绝对误差 (分) | ≤ 0.5 分 |
| **系统性能** | P95 延迟 | 95 百分位端到端延迟 | ≤ 4s (单题) |
| | 吞吐量 | 峰值 QPS | ≥ 200 |

### 11.2 在线 A/B 评估框架

```python
class OnlineEvaluationFramework:
    """模型在线 A/B 评估框架"""
    
    async def evaluate_model_switch(
        self,
        candidate_model_id: str,
        baseline_model_id: str,
        traffic_split: float = 0.1,  # 10%流量给候选模型
        evaluation_period_days: int = 7
    ):
        """模型切换前的在线评估"""
        
        # 1. 配置流量切分
        await self.traffic_router.set_split(
            baseline=baseline_model_id,
            candidate=candidate_model_id,
            ratio=traffic_split
        )
        
        # 2. 收集评估期间的预测结果
        evaluation_start = datetime.utcnow()
        
        # 3. 等待教师反馈/人工标注回流
        await asyncio.sleep(evaluation_period_days * 86400)
        
        # 4. 计算在线指标
        metrics = await self._compute_online_metrics(
            baseline_model_id, candidate_model_id, evaluation_start
        )
        
        # 5. 统计显著性检验
        significance = self._significance_test(
            metrics.baseline, metrics.candidate
        )
        
        # 6. 决策
        if significance.is_significant and metrics.candidate_better:
            await self.promote_to_production(candidate_model_id)
            return Decision.PROMOTE
        else:
            await self.rollback(baseline_model_id)
            return Decision.KEEP_BASELINE
```

## 附录 A: 常见问题 (FAQ)

**Q1: 手写识别和印刷体OCR的本质区别是什么？**
A: 印刷体OCR处理的是规范字体，字形统一、间距固定，传统CNN+CTC方案即可达到99%+准确率。手写识别面临的核心挑战包括：(1) 字形因人而异，变化极大；(2) 连笔/简写/涂改频繁；(3) 数学表达式有二维结构(分式、上下标)；(4) 写写停停导致间距不规则。因此需要更复杂的模型架构(Attention/Coverage)和更大的训练数据量。

**Q2: 为什么不直接用大模型(如GPT-4V)做手写识别？**
A: 大模型在手写识别上存在几个问题：(1) 延迟过高(3-10秒)，不适合高并发场景；(2) 成本高昂(每次调用约$0.01-0.05)；(3) LaTeX输出格式不稳定；(4) 隐私合规风险(学生数据不可发送到第三方)。专有模型在延迟(<1s)、成本(约$0.0005/次)、格式稳定性和数据安全方面有显著优势。

**Q3: 批改一致性88%够用吗？如何处理不一致的情况？**
A: 88%的Kappa一致性已经达到了"教师间一致性"的中上水平(人类教师间Kappa约0.85-0.92)。对于不一致的12%案例，系统通过置信度路由自动识别并转入人工审核队列。随着模型自学习闭环的运行，一致性会持续提升。
