# 服务端-学生写作过程行为智能分析与个性化写作体验优化引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责**实时采集、分析和响应学生在写作过程中的行为信号**，聚焦于"学生如何写"而非"学生写了什么"。通过对写作过程中键盘行为、编辑行为、停顿模式、修改行为、AI 辅助使用模式等多维度数据的智能分析，构建学生写作过程画像，检测写作困难与卡点，动态优化写作环境与辅助策略。

### 1.2 与现有模块的区别与协同

| 现有模块 | 关注点 | 与本引擎关系 |
| --- | --- | --- |
| 作文批改评分引擎 | 写作**结果**质量评估 | 本引擎提供过程数据，批改引擎提供结果数据，联合形成"过程+结果"双维评价 |
| 客户端-富文本编辑器与作文书写引擎 | 编辑器**交互能力** | 本引擎是编辑器行为数据的消费方，编辑器是数据采集源 |
| 作文审题分析与提纲生成引擎 | 写作**前**辅助 | 本引擎在写作**中**提供过程感知与实时辅助 |
| 作文范文智能推荐与结构拆解 | 范文**参考** | 本引擎在学生写作困难时可触发范文推荐 |
| 学生认知负荷监测引擎 | 通用**认知负荷** | 本引擎专注写作场景的认知状态，提供更精准的领域信号 |
| 学生学习投入度多维量化 | 整体**投入度** | 本引擎提供写作场景的投入度细分数据 |

### 1.3 设计目标

1. **过程透明化**：将不可见的写作思维过程转化为可量化、可分析的行为指标
2. **实时感知**：在写作过程中实时检测困难、卡点、注意力涣散，并触发智能干预
3. **个性化适配**：基于学生个体写作习惯和水平，动态调整写作辅助策略
4. **数据驱动评估**：为教师和家长提供写作过程的可视化报告，支持形成性评价
5. **AI 辅助依赖预警**：识别学生对 AI 写作辅助的过度依赖，引导独立写作能力培养

### 1.4 适用范围

| 维度 | 说明 |
| --- | --- |
| 学段 | 小学三年级及以上（需具备基本键盘/手写输入能力） |
| 学科 | 语文作文、英语写作、其他学科短文回答 |
| 写作类型 | 命题作文、材料作文、读后感、书信、日记、英语作文、自由写作 |
| 输入方式 | 键盘输入、手写输入（平板场景）、语音转文字 |
| 客户端 | 移动端 APP、Web 端、平板端 |

## 3. 数据结构定义

### 3.1 写作行为事件（WritingBehaviorEvent）

客户端采集的原子级行为事件，通过批量上报或 WebSocket 实时流发送到服务端。

```json
{
  "eventId": "evt_20260731150000_001",
  "sessionId": "ws_8f7e6d5c4b3a",
  "userId": "U10002345",
  "compositionId": "comp_900123",
  "timestamp": 1753945200000,
  "eventType": "KEYSTROKE",
  "eventData": {
    "key": "a",
    "position": 156,
    "textBefore": "春天的风",
    "textAfter": "春天的风a"
  },
  "context": {
    "clientTime": 1753945199985,
    "viewportWidth": 375,
    "viewportHeight": 812,
    "inputMethod": "KEYBOARD",
    "deviceModel": "iPad_Air_5th",
    "appVersion": "2.4.1",
    "networkType": "WIFI",
    "batteryLevel": 78
  }
}
```

### 3.2 事件类型枚举（WritingEventType）

```sql
-- 写作行为事件类型字典表
CREATE TABLE writing_event_type_dict (
    type_code       VARCHAR(40)    PRIMARY KEY,
    type_name       VARCHAR(60)    NOT NULL,
    type_category   VARCHAR(30)    NOT NULL COMMENT 'INPUT/EDIT/NAVIGATION/SESSION/AI_ASSIST/SYSTEM',
    description     TEXT,
    is_active       TINYINT(1)     DEFAULT 1,
    created_at      DATETIME       DEFAULT CURRENT_TIMESTAMP
) COMMENT '写作行为事件类型字典';
```

| type_code | type_name | type_category | 说明 |
| --- | --- | --- | --- |
| `KEYSTROKE` | 按键输入 | INPUT | 单个字符输入 |
| `BACKSPACE` | 退格删除 | EDIT | 删除前一个字符 |
| `DELETE_TEXT` | 选区删除 | EDIT | 选中一段文本后删除 |
| `PASTE` | 粘贴 | EDIT | 粘贴文本（含来源标记：剪贴板/AI建议） |
| `SELECTION` | 文本选择 | NAVIGATION | 选中一段文本（未操作） |
| `CURSOR_MOVE` | 光标移动 | NAVIGATION | 光标跳转（点击/方向键） |
| `SCROLL` | 滚动 | NAVIGATION | 页面滚动 |
| `PAUSE` | 停顿 | SESSION | 连续输入间的间隔超过阈值 |
| `RESUME` | 恢复输入 | SESSION | 停顿后恢复输入 |
| `SESSION_START` | 写作开始 | SESSION | 进入写作页面 / 新建作文 |
| `SESSION_END` | 写作结束 | SESSION | 退出写作页面 / 提交作文 |
| `SESSION_PAUSE` | 暂时离开 | SESSION | App 切后台 / 屏幕息屏 |
| `SESSION_RESUME` | 回来继续 | SESSION | App 切回前台 |
| `AI_SUGGEST_REQUEST` | 请求AI辅助 | AI_ASSIST | 点击"帮我写"/"给我灵感"等 |
| `AI_SUGGEST_ACCEPT` | 采纳AI建议 | AI_ASSIST | 接受AI生成的内容 |
| `AI_SUGGEST_REJECT` | 拒绝AI建议 | AI_ASSIST | 关闭/忽略AI建议 |
| `AI_SUGGEST_MODIFY` | 修改后采纳 | AI_ASSIST | 在AI建议基础上修改后使用 |
| `OUTLINE_VIEW` | 查看提纲 | AI_ASSIST | 查看之前生成的提纲 |
| `REFERENCE_VIEW` | 查看素材 | AI_ASSIST | 查看推荐素材/范文 |
| `WORD_COUNT_CHECK` | 查看字数 | SYSTEM | 点击字数统计 |
| `VOICE_INPUT_START` | 开始语音输入 | INPUT | 启动语音转文字 |
| `VOICE_INPUT_END` | 结束语音输入 | INPUT | 结束语音转文字 |
| `UNDO` | 撤销 | EDIT | 撤销操作 |
| `REDO` | 重做 | EDIT | 重做操作 |
| `FORMAT_APPLY` | 格式应用 | EDIT | 加粗/缩进等格式操作 |

### 3.3 写作会话表（WritingSession）

```sql
CREATE TABLE writing_session (
    id              BIGINT         PRIMARY KEY AUTO_INCREMENT,
    session_id      VARCHAR(40)    NOT NULL UNIQUE COMMENT '会话唯一标识',
    user_id         VARCHAR(20)    NOT NULL,
    composition_id  VARCHAR(40)    NOT NULL COMMENT '关联作文ID',
    
    -- 写作任务信息
    subject         VARCHAR(10)    NOT NULL COMMENT '学科: CHINESE/ENGLISH',
    grade_level     TINYINT        NOT NULL COMMENT '年级',
    composition_type VARCHAR(30)   NOT NULL COMMENT '命题作文/材料作文/读后感/自由写作等',
    title           VARCHAR(200)   COMMENT '作文题目',
    target_word_count INT          DEFAULT 0 COMMENT '目标字数',
    
    -- 会话状态
    status          VARCHAR(20)    DEFAULT 'IN_PROGRESS' COMMENT 'IN_PROGRESS/SUBMITTED/ABANDONED',
    started_at      DATETIME       NOT NULL,
    last_active_at  DATETIME       NOT NULL,
    submitted_at    DATETIME       NULL,
    abandoned_at    DATETIME       NULL,
    duration_ms     BIGINT         DEFAULT 0 COMMENT '实际写作时长（毫秒，排除离开时间）',
    
    -- 输入方式
    primary_input_method VARCHAR(20) DEFAULT 'KEYBOARD' COMMENT 'KEYBOARD/HANDWRITING/VOICE',
    
    INDEX idx_user_date (user_id, started_at),
    INDEX idx_composition (composition_id),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作会话记录';
```

```sql
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作特征快照';
```

### 3.5 写作困难检测记录表（WritingDifficultyEvent）

```sql
CREATE TABLE writing_difficulty_event (
    id                  BIGINT         PRIMARY KEY AUTO_INCREMENT,
    session_id          VARCHAR(40)    NOT NULL,
    user_id             VARCHAR(20)    NOT NULL,
    detected_at         DATETIME       NOT NULL,
    
    difficulty_type     VARCHAR(40)    NOT NULL COMMENT '见下方枚举',
    severity_level      TINYINT        NOT NULL COMMENT '1轻微/2中等/3严重',
    
    -- 上下文
    current_word_count  INT            NOT NULL,
    trigger_signals     JSON            NOT NULL COMMENT '触发信号明细JSON',
    writing_position    INT             COMMENT '困难发生时的写作位置',
    text_snippet        VARCHAR(200)    COMMENT '当前位置文本片段(脱敏后)',
    
    -- 干预记录
    intervention_type   VARCHAR(40)     COMMENT '干预类型',
    intervention_id     VARCHAR(40)     COMMENT '干预消息ID',
    user_response       VARCHAR(20)     COMMENT 'ACCEPTED/DISMISSED/IGNORED',
    response_time_ms    INT             COMMENT '用户响应耗时',
    
    INDEX idx_session_detected (session_id, detected_at),
    INDEX idx_user_detected (user_id, detected_at),
    INDEX idx_type_level (difficulty_type, severity_level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作困难检测记录';
```

**困难类型枚举（DifficultyType）：**

| 类型 | 说明 | 检测信号 |
| --- | --- | --- |
| `STARTING_ANXIETY` | 起笔困难 | 进入写作页面后超过60秒无实质输入 |
| `MID_BLOCK` | 写作中卡壳 | 连续长停顿>15秒出现2次以上，且位置在文中 |
| `EXCESSIVE_REVISION` | 过度修改 | 退格/删除次数与新增字符比>0.5 |
| `STAGNATION` | 停滞不前 | 近2分钟净增字数<10字 |
| `OFF_TASK` | 注意力涣散 | 频繁切出App、滚动查看非写作区域 |
| `STRUCTURE_LOST` | 结构混乱 | 频繁大幅光标跳转、段落逻辑断裂 |
| `AI_OVER_RELIANCE` | AI依赖过高 | AI辅助生成内容占比>40%且无修改 |
| `LENGTH_ANXIETY` | 字数焦虑 | 频繁查看字数统计且未达目标50% |
| `ENDING_DIFFICULTY` | 收尾困难 | 字数接近目标但长时间停滞在结尾 |

## 5. 核心算法与处理逻辑

### 5.1 写作阶段自动识别（WritingPhaseDetector）

将写作过程自动划分为四个阶段：

```python
class WritingPhase:
    PLANNING = "PLANNING"      # 构思阶段
    DRAFTING = "DRAFTING"       # 起草阶段
    REVISING = "REVISING"       # 修改阶段
    POLISHING = "POLISHING"     # 润色阶段

class WritingPhaseDetector:
    """
    基于滑动窗口（默认60秒）的行为特征自动判定当前写作阶段。
    
    判定规则优先级：
    1. PLANNING: 会话开始前N秒(N由年级配置，小学120s，初中90s，高中60s)，
       且期间有查看提纲/素材行为或净增字数<10
    2. POLISHING: 字数已达目标90%以上，且修改操作占比>50%
    3. REVISING: 窗口内删除/修改操作占比>30%，且存在跨段落光标跳转
    4. DRAFTING: 默认状态，有持续输入且修改占比<30%
    """
    
    PHASE_TIMEOUTS = {
        'PRIMARY': 120,    # 小学
        'JUNIOR': 90,      # 初中
        'SENIOR': 60        # 高中
    }
    
    def detect_phase(self, window_events, session_context):
        """
        Args:
            window_events: 最近60秒内的行为事件列表
            session_context: 会话上下文(已写时间、字数、目标字数等)
        Returns:
            (phase: str, confidence: float)
        """
        elapsed = session_context['elapsed_seconds']
        word_count = session_context['current_word_count']
        target_count = session_context.get('target_word_count', 0)
        grade_level = session_context['grade_level']
        
        # 计算窗口内行为特征
        features = self._extract_window_features(window_events)
        
        # Rule 1: PLANNING
        planning_timeout = self._get_planning_timeout(grade_level)
        has_planning_signals = (
            elapsed < planning_timeout and 
            features['net_chars'] < 10 and
            (features['has_outline_view'] or features['has_reference_view'] or 
             features['total_events'] < 5)
        )
        if has_planning_signals:
            return WritingPhase.PLANNING, 0.85
        
        # Rule 2: POLISHING
        if target_count > 0:
            progress_ratio = word_count / target_count
            if progress_ratio >= 0.9 and features['edit_ratio'] > 0.5:
                return WritingPhase.POLISHING, 0.80
        
        # Rule 3: REVISING
        has_revision_signals = (
            features['edit_ratio'] > 0.30 and
            features['cross_paragraph_jumps'] > 0
        )
        if has_revision_signals:
            return WritingPhase.REVISING, 0.75
        
        # Rule 4: DRAFTING (default)
        if features['input_rate'] > 0:
            return WritingPhase.DRAFTING, 0.70
        
        # Fallback: maintain previous phase
        return session_context.get('previous_phase', WritingPhase.PLANNING), 0.50
    
    def _extract_window_features(self, events):
        """提取时间窗口内的行为特征"""
        keystrokes = sum(1 for e in events if e['eventType'] == 'KEYSTROKE')
        backspaces = sum(1 for e in events if e['eventType'] == 'BACKSPACE')
        deletes = sum(1 for e in events if e['eventType'] == 'DELETE_TEXT')
        pastes = sum(1 for e in events if e['eventType'] == 'PASTE')
        cursor_jumps = sum(1 for e in events 
                          if e['eventType'] == 'CURSOR_MOVE' and 
                          e.get('eventData', {}).get('jumpDistance', 0) > 50)
        outline_views = sum(1 for e in events if e['eventType'] == 'OUTLINE_VIEW')
        reference_views = sum(1 for e in events if e['eventType'] == 'REFERENCE_VIEW')
        
        total_edits = backspaces + deletes
        total_input = keystrokes + sum(
            len(e.get('eventData', {}).get('text', '')) 
            for e in events if e['eventType'] == 'PASTE'
        )
        
        return {
            'net_chars': keystrokes - backspaces - deletes,
            'total_events': len(events),
            'input_rate': keystrokes / 60.0,  # chars per second
            'edit_ratio': total_edits / max(total_input, 1),
            'cross_paragraph_jumps': cursor_jumps,
            'has_outline_view': outline_views > 0,
            'has_reference_view': reference_views > 0
        }
```

### 5.2 困难检测引擎（DifficultyDetector）

基于实时行为特征流，检测多种写作困难状态：

```python
from dataclasses import dataclass
from typing import Optional, List

@dataclass
class DifficultyDetection:
    """困难检测结果"""
    difficulty_type: str
    severity: int              # 1=轻微, 2=中等, 3=严重
    confidence: float
    trigger_signals: dict
    suggested_intervention: str
    context: dict

class WritingDifficultyDetector:
    """
    多策略困难检测器，每个检测策略独立运行，
    结果汇总后进行优先级排序和去重。
    """
    
    def __init__(self):
        self.detectors = [
            StartingAnxietyDetector(),
            MidBlockDetector(),
            ExcessiveRevisionDetector(),
            StagnationDetector(),
            OffTaskDetector(),
            StructureLostDetector(),
            AIOverRelianceDetector(),
            LengthAnxietyDetector(),
            EndingDifficultyDetector(),
        ]
    
    def detect(self, session_state, recent_events, profile):
        """
        运行所有检测器，返回排序后的困难列表。
        
        Args:
            session_state: 当前会话状态(时间、字数、阶段等)
            recent_events: 最近N秒的事件流
            profile: 学生写作习惯画像
        Returns:
            List[DifficultyDetection] 按严重度+置信度排序
        """
        detections = []
        for detector in self.detectors:
            result = detector.check(session_state, recent_events, profile)
            if result is not None:
                detections.append(result)
        
        # 去重：同一类型在3分钟内只保留最高严重度
        detections = self._deduplicate(detections)
        
        # 按严重度+置信度排序
        detections.sort(key=lambda d: (d.severity, d.confidence), reverse=True)
        
        # 限频：每次最多返回2个困难
        return detections[:2]


class StartingAnxietyDetector:
    """起笔困难检测：进入写作页面后长时间无实质输入"""
    
    def check(self, state, events, profile):
        elapsed = state['elapsed_seconds']
        word_count = state['current_word_count']
        grade = state['grade_level']
        
        # 年级相关的起笔阈值
        threshold = {1: 120, 2: 90, 3: 60}.get(
            self._grade_to_tier(grade), 90
        )
        
        if elapsed > threshold and word_count < 10:
            # 检查是否有查看提纲/素材行为（说明在构思）
            has_planning = any(
                e['eventType'] in ('OUTLINE_VIEW', 'REFERENCE_VIEW')
                for e in events
            )
            
            severity = 3 if elapsed > threshold * 2 else 2
            if has_planning:
                severity = max(1, severity - 1)
            
            # 个性化调整：历史起笔困难频率高的学生降低触发阈值
            if profile and profile.get_common_difficulty_freq('STARTING_ANXIETY') > 0.5:
                threshold = int(threshold * 0.7)
            
            return DifficultyDetection(
                difficulty_type='STARTING_ANXIETY',
                severity=severity,
                confidence=0.80,
                trigger_signals={
                    'elapsed': elapsed,
                    'wordCount': word_count,
                    'threshold': threshold,
                    'hasPlanningBehavior': has_planning
                },
                suggested_intervention='OFFER_OUTLINE_OR_PROMPT',
                context={'phase': 'PLANNING'}
            )
        return None


class MidBlockDetector:
    """写作中卡壳检测：连续长停顿"""
    
    LONG_PAUSE_THRESHOLD = 15.0  # 秒
    WINDOW_SIZE = 120            # 检测窗口2分钟
    
    def check(self, state, events, profile):
        if state['current_word_count'] < 20:
            return None  # 起笔阶段不检测卡壳
            
        recent = [e for e in events if 
                  e['timestamp'] > state['now'] - self.WINDOW_SIZE * 1000]
        
        long_pauses = [e for e in recent 
                       if e['eventType'] == 'PAUSE' and 
                       e['eventData']['duration'] > self.LONG_PAUSE_THRESHOLD * 1000]
        
        if len(long_pauses) >= 2:
            avg_pause = sum(e['eventData']['duration'] for e in long_pauses) / len(long_pauses)
            severity = 3 if len(long_pauses) >= 4 or avg_pause > 30000 else 2
            
            return DifficultyDetection(
                difficulty_type='MID_BLOCK',
                severity=severity,
                confidence=0.75,
                trigger_signals={
                    'longPauseCount': len(long_pauses),
                    'avgPauseDuration': avg_pause,
                    'windowSize': self.WINDOW_SIZE
                },
                suggested_intervention='OFFER_INSPIRATION',
                context={
                    'phase': state.get('current_phase', 'DRAFTING'),
                    'position': state.get('current_position', 0)
                }
            )
        return None


class ExcessiveRevisionDetector:
    """过度修改检测：删除操作占比过高"""
    
    WINDOW_SIZE = 180  # 3分钟窗口
    
    def check(self, state, events, profile):
        recent = [e for e in events if
                  e['timestamp'] > state['now'] - self.WINDOW_SIZE * 1000]
        
        keystrokes = sum(1 for e in recent if e['eventType'] == 'KEYSTROKE')
        backspaces = sum(1 for e in recent if e['eventType'] == 'BACKSPACE')
        deletes = sum(1 for e in recent if e['eventType'] == 'DELETE_TEXT')
        
        total_input = keystrokes
        total_edits = backspaces + deletes
        
        if total_input < 20:  # 输入太少不检测
            return None
            
        edit_ratio = total_edits / total_input
        
        if edit_ratio > 0.5:
            severity = 3 if edit_ratio > 0.8 else 2
            return DifficultyDetection(
                difficulty_type='EXCESSIVE_REVISION',
                severity=severity,
                confidence=0.78,
                trigger_signals={
                    'editRatio': edit_ratio,
                    'backspaceCount': backspaces,
                    'deleteCount': deletes,
                    'keystrokeCount': keystrokes
                },
                suggested_intervention='SUGGEST_OUTLINE_REVIEW',
                context={'phase': state.get('current_phase', 'DRAFTING')}
            )
        return None


class StagnationDetector:
    """停滞不前检测：长时间净增字数极少"""
    
    WINDOW_SIZE = 120  # 2分钟
    MIN_NET_CHARS = 10
    
    def check(self, state, events, profile):
        recent = [e for e in events if
                  e['timestamp'] > state['now'] - self.WINDOW_SIZE * 1000]
        
        net_chars = sum(
            1 if e['eventType'] == 'KEYSTROKE' else 0
            for e in recent
        ) - sum(
            1 if e['eventType'] in ('BACKSPACE', 'DELETE_TEXT') else 0
            for e in recent
        )
        
        has_activity = len(recent) > 5  # 有事件但没产出
        
        if net_chars < self.MIN_NET_CHARS and has_activity:
            return DifficultyDetection(
                difficulty_type='STAGNATION',
                severity=2,
                confidence=0.70,
                trigger_signals={
                    'netChars': net_chars,
                    'totalEvents': len(recent),
                    'windowSize': self.WINDOW_SIZE
                },
                suggested_intervention='OFFER_BREAK_OR_TOPIC_SHIFT',
                context={'phase': state.get('current_phase', 'DRAFTING')}
            )
        return None


class AIOverRelianceDetector:
    """AI依赖过高检测"""
    
    def check(self, state, events, profile):
        total_chars = state['current_word_count']
        if total_chars < 50:
            return None
            
        recent = [e for e in events if
                  e['timestamp'] > state['now'] - 300000]  # 5分钟窗口
        
        ai_requests = sum(1 for e in recent if e['eventType'] == 'AI_SUGGEST_REQUEST')
        ai_accepts = sum(1 for e in recent if e['eventType'] == 'AI_SUGGEST_ACCEPT')
        ai_modifies = sum(1 for e in recent if e['eventType'] == 'AI_SUGGEST_MODIFY')
        ai_rejects = sum(1 for e in recent if e['eventType'] == 'AI_SUGGEST_REJECT')
        
        # 计算AI内容占比（近似）
        ai_chars = state.get('ai_generated_chars', 0)
        ai_ratio = ai_chars / max(total_chars, 1)
        
        signals = {
            'aiRequests': ai_requests,
            'aiAccepts': ai_accepts,
            'aiModifies': ai_modifies,
            'aiRejects': ai_rejects,
            'aiContentRatio': ai_ratio
        }
        
        # 高依赖：AI内容占比>40%且修改后采纳率低
        modify_rate = ai_modifies / max(ai_accepts + ai_modifies, 1)
        if ai_ratio > 0.40 and modify_rate < 0.2:
            severity = 3 if ai_ratio > 0.60 else 2
            return DifficultyDetection(
                difficulty_type='AI_OVER_RELIANCE',
                severity=severity,
                confidence=0.82,
                trigger_signals=signals,
                suggested_intervention='ENCOURAGE_INDEPENDENT_WRITE',
                context={'aiRatio': ai_ratio, 'modifyRate': modify_rate}
            )
        return None
```

### 5.3 心流状态评分（FlowStateScorer）

```python
class FlowStateScorer:
    """
    基于写作行为特征计算心流沉浸度评分（0-100）。
    
    心流特征映射：
    - 高打字速度且低修改率 → 高心流（流畅输出）
    - 短停顿后恢复输入 → 中高心流（正常思考节奏）
    - 长停顿频繁 → 低心流（卡壳/走神）
    - 无中断（切后台/通知）持续写作 → 心流加分
    """
    
    WEIGHTS = {
        'typing_consistency': 0.30,   # 输入连续性
        'speed_appropriateness': 0.20, # 速度适配度
        'low_disruption': 0.25,        # 低中断
        'revision_health': 0.15,       # 修改健康度
        'sustained_attention': 0.10    # 持续注意力
    }
    
    def compute_score(self, features, profile=None):
        scores = {}
        
        # 1. 输入连续性：基于停顿频率和时长
        pause_rate = features.get('pause_count_per_min', 0)
        avg_pause = features.get('avg_pause_duration', 0)
        long_pause_ratio = features.get('long_pause_ratio', 0)
        
        continuity = 100 * max(0, 1 - pause_rate / 8)       # 每分钟<8次停顿为佳
        continuity *= max(0, 1 - long_pause_ratio / 0.3)     # 长停顿占比<30%
        scores['typing_consistency'] = max(0, min(100, continuity))
        
        # 2. 速度适配度：与学生个人基线比较
        current_speed = features.get('typing_speed_wpm', 0)
        baseline = profile.avg_typing_speed if profile else 20
        if baseline > 0:
            speed_ratio = current_speed / baseline
            # 速度在基线的80%-150%之间为最佳
            if 0.8 <= speed_ratio <= 1.5:
                scores['speed_appropriateness'] = 100
            elif speed_ratio > 1.5:
                scores['speed_appropriateness'] = max(40, 100 - (speed_ratio - 1.5) * 40)
            else:
                scores['speed_appropriateness'] = max(20, speed_ratio / 0.8 * 100)
        else:
            scores['speed_appropriateness'] = 50
        
        # 3. 低中断：无切后台/通知干扰
        disruptions = features.get('disruption_count', 0)
        scores['low_disruption'] = max(0, 100 - disruptions * 25)
        
        # 4. 修改健康度：适度修改为佳，不修改或过度修改扣分
        revision_ratio = features.get('revision_ratio', 0)
        if 0.05 <= revision_ratio <= 0.20:
            scores['revision_health'] = 100   # 健康范围
        elif revision_ratio < 0.05:
            scores['revision_health'] = 70    # 很少修改
        else:
            scores['revision_health'] = max(20, 100 - (revision_ratio - 0.20) * 200)
        
        # 5. 持续注意力：连续写作时长（无中断）
        sustained_min = features.get('sustained_writing_minutes', 0)
        scores['sustained_attention'] = min(100, sustained_min * 10)  # 10分钟满分
        
        # 加权综合
        total = sum(scores[k] * self.WEIGHTS[k] for k in self.WEIGHTS)
        return round(total, 2)
```

### 5.4 AI依赖度评分（AIDependencyScorer）

```python
class AIDependencyScorer:
    """
    计算学生对AI写作辅助的依赖程度（0-100，越高越依赖）。
    综合考虑：AI内容占比、请求频率、修改后采纳率、独立尝试时长。
    """
    
    def compute_score(self, session_metrics, profile=None):
        # 维度1: AI生成内容占总字数比例
        ai_ratio = session_metrics.get('ai_content_ratio', 0)
        ratio_score = min(100, ai_ratio * 200)  # 50%AI内容=100分
        
        # 维度2: AI请求频率（次/千字）
        ai_requests_per_1k = session_metrics.get('ai_requests_per_1k_chars', 0)
        freq_score = min(100, ai_requests_per_1k * 20)  # 5次/千字=100分
        
        # 维度3: 原文采纳vs修改后采纳比例
        raw_accepts = session_metrics.get('ai_raw_accepts', 0)
        modified_accepts = session_metrics.get('ai_modified_accepts', 0)
        total_accepts = raw_accepts + modified_accepts
        if total_accepts > 0:
            raw_ratio = raw_accepts / total_accepts
            raw_ratio_score = raw_ratio * 100  # 原文直接采纳越多=依赖越重
        else:
            raw_ratio_score = 0
        
        # 维度4: 首次独立尝试时长（请求AI前的独立写作时间）
        avg_independent_write = session_metrics.get('avg_independent_write_before_ai_sec', 0)
        if avg_independent_write > 60:
            independence_score = 0     # 独立写>1分钟才求助=低依赖
        elif avg_independent_write > 30:
            independence_score = 30
        elif avg_independent_write > 10:
            independence_score = 60
        else:
            independence_score = 100   # 几乎立刻求助AI
        
        # 加权综合
        weights = {
            'ratio': 0.35,
            'freq': 0.20,
            'raw_accept': 0.20,
            'independence': 0.25
        }
        
        dependency = (
            ratio_score * weights['ratio'] +
            freq_score * weights['freq'] +
            raw_ratio_score * weights['raw_accept'] +
            independence_score * weights['independence']
        )
        
        return round(dependency, 2)
```

### 5.5 智能干预决策引擎（InterventionAdvisor）

```python
class WritingInterventionAdvisor:
    """
    根据检测结果决定是否、何时、以何种方式干预学生写作过程。
    
    核心原则：
    1. 不过度干预，避免打断良好的写作状态
    2. 干预内容要轻量、可关闭
    3. 优先使用鼓励和启发，而非直接给答案
    4. 尊重学生个体差异和写作风格
    """
    
    # 干预冷却时间（同一类型干预的最短间隔）
    COOLDOWN_SECONDS = {
        'OFFER_OUTLINE_OR_PROMPT': 300,
        'OFFER_INSPIRATION': 180,
        'SUGGEST_OUTLINE_REVIEW': 240,
        'OFFER_BREAK_OR_TOPIC_SHIFT': 300,
        'ENCOURAGE_INDEPENDENT_WRITE': 600,
        'ENCOURAGEMENT': 120,
    }
    
    # 心流保护阈值：心流分数高于此值时减少干预
    FLOW_PROTECTION_THRESHOLD = 80.0
    
    def advise(self, difficulty, session_state, profile, intervention_history):
        """
        决定是否执行干预及具体干预方案。
        
        Args:
            difficulty: DifficultyDetection 对象
            session_state: 当前会话状态
            profile: 学生写作画像
            intervention_history: 本次会话的历史干预记录
        Returns:
            InterventionPlan 或 None（不干预）
        """
        # 1. 心流保护：如果学生正在高心流状态，低严重度困难不干预
        if (session_state.get('flow_score', 0) > self.FLOW_PROTECTION_THRESHOLD 
                and difficulty.severity <= 2):
            return None
        
        # 2. 冷却检查：同类型干预是否在冷却期内
        last_intervention = intervention_history.get_last(difficulty.difficulty_type)
        if last_intervention:
            elapsed = session_state['now'] - last_intervention['timestamp']
            cooldown = self.COOLDOWN_SECONDS.get(
                last_intervention['intervention_type'], 180
            ) * 1000
            if elapsed < cooldown:
                return None
        
        # 3. 个性化调整：根据学生画像调整干预策略
        adjusted_type = self._personalize_strategy(
            difficulty.suggested_intervention, profile
        )
        
        # 4. 构建干预方案
        return InterventionPlan(
            intervention_type=adjusted_type,
            difficulty_type=difficulty.difficulty_type,
            severity=difficulty.severity,
            content=self._build_content(adjusted_type, difficulty, session_state, profile),
            display_config=self._build_display_config(difficulty.severity),
            priority=self._compute_priority(difficulty, session_state)
        )
    
    def _personalize_strategy(self, default_type, profile):
        """根据学生画像个性化干预策略"""
        if profile is None:
            return default_type
        
        # AI依赖高的学生：减少AI类干预，增加自主思考引导
        if profile.avg_ai_content_ratio > 0.35:
            if 'OFFER' in default_type and 'INDEPENDENT' not in default_type:
                return 'ENCOURAGE_INDEPENDENT_WRITE'
        
        # 经常起笔困难的学生：提前主动提供提纲提醒
        if profile.get_common_difficulty_freq('STARTING_ANXIETY') > 0.4:
            if default_type == 'OFFER_OUTLINE_OR_PROMPT':
                return 'PROACTIVE_OUTLINE_REMINDER'
        
        return default_type
    
    def _build_content(self, intervention_type, difficulty, state, profile):
        """构建干预内容"""
        templates = {
            'OFFER_OUTLINE_OR_PROMPT': {
                'templateId': 'writing_offer_outline',
                'variables': {
                    'topic': state.get('title', '当前题目'),
                    'gradeLevel': state.get('grade_level', 7)
                }
            },
            'OFFER_INSPIRATION': {
                'templateId': 'writing_offer_inspiration',
                'variables': {
                    'currentParagraph': state.get('current_paragraph_topic', ''),
                    'wordCount': state.get('current_word_count', 0)
                }
            },
            'ENCOURAGE_INDEPENDENT_WRITE': {
                'templateId': 'writing_encourage_independent',
                'variables': {
                    'aiRatio': difficulty.trigger_signals.get('aiContentRatio', 0)
                }
            },
            'ENCOURAGEMENT': {
                'templateId': 'writing_encourage_progress',
                'variables': {
                    'progress': f"{state.get('progress_percent', 0):.0f}%",
                    'wordCount': state.get('current_word_count', 0)
                }
            }
        }
        return templates.get(intervention_type, templates['ENCOURAGEMENT'])
    
    def _build_display_config(self, severity):
        """根据严重度配置展示方式"""
        if severity >= 3:
            return {'position': 'MODAL', 'duration': 0, 'dismissible': True}
        elif severity == 2:
            return {'position': 'TOP_BANNER', 'duration': 5000, 'dismissible': True}
        else:
            return {'position': 'TOOLTIP', 'duration': 3000, 'dismissible': True}
    
    def _compute_priority(self, difficulty, state):
        """计算干预优先级"""
        base = difficulty.severity * 10 + difficulty.confidence * 5
        # 写作初期困难优先级更高（更可能放弃）
        if state.get('elapsed_seconds', 0) < 300:
            base += 5
        return round(base, 1)
```

```python
class WritingBehaviorPrivacyFilter:
    """
    对上报的行为数据进行隐私过滤。
    """
    
    # 敏感模式列表（不上报具体按键内容）
    SENSITIVE_PATTERNS = [
        # 密码输入区域
        # 个人信息输入（姓名、地址等）
    ]
    
    def filter_event(self, event, session_context):
        """过滤单个事件的敏感信息"""
        if event['eventType'] == 'KEYSTROKE':
            data = event.get('eventData', {})
            # 方案1: 移除具体字符，只保留位置和时长
            data.pop('key', None)
            data.pop('textBefore', None)
            data.pop('textAfter', None)
            # 保留：position（用于分析位置跳转）、timestamp（用于速度计算）
            
            # 每N个字符采样一次完整文本快照（用于字数统计校准）
            position = data.get('position', 0)
            if position % 50 == 0:  # 每50字记录一次快照
                data['snapshot'] = self._hash_text(session_context.get_full_text()[:position+1])
            
            event['eventData'] = data
        
        elif event['eventType'] in ('PASTE',):
            data = event.get('eventData', {})
            data.pop('content', None)
            data['length'] = len(data.get('content', ''))  # 只保留长度
            event['eventData'] = data
            
        return event
```

## 9. 错误处理与降级策略

### 9.1 错误码定义

| 错误码 | HTTP | 说明 | 处理方式 |
| --- | --- | --- | --- |
| WB_001 | 400 | 事件数据格式错误 | 丢弃错误事件，返回详细错误信息 |
| WB_002 | 401 | 会话未授权 | 客户端重新鉴权 |
| WB_003 | 403 | 写作会话不属于当前用户 | 拒绝操作 |
| WB_004 | 404 | 写作会话不存在 | 客户端创建新会话 |
| WB_005 | 409 | 会话状态冲突（如已提交仍在上报事件） | 客户端同步状态 |
| WB_006 | 429 | 事件上报频率超限 | 客户端降频，指数退避重试 |
| WB_007 | 500 | 服务端内部错误 | 客户端本地缓冲，稍后重试 |
| WB_008 | 503 | 分析引擎暂时不可用 | 降级模式：仅存储不分析 |

### 9.2 降级策略

```python
class WritingBehaviorServiceDegradation:
    """
    分级降级策略，确保核心功能在异常情况下仍可用。
    """
    
    LEVEL_NORMAL = 0       # 全功能运行
    LEVEL_REDUCED = 1      # 降低分析频率
    LEVEL_MINIMAL = 2      # 仅存储不分析
    LEVEL_OFFLINE = 3      # 客户端独立运行
    
    def get_service_level(self):
        """根据系统负载和依赖状态决定服务等级"""
        # 检查Kafka是否可用
        if not self._check_kafka_health():
            return self.LEVEL_MINIMAL
        
        # 检查Flink作业状态
        if not self._check_flink_health():
            return self.LEVEL_MINIMAL
        
        # 检查Redis延迟
        redis_latency = self._check_redis_latency()
        if redis_latency > 100:  # ms
            return self.LEVEL_REDUCED
        
        # 检查系统负载
        cpu_usage = self._get_cpu_usage()
        if cpu_usage > 80:
            return self.LEVEL_REDUCED
        
        return self.LEVEL_NORMAL
    
    def apply_level(self, level):
        """应用降级等级"""
        if level == self.LEVEL_REDUCED:
            # 降低检测频率：60s instead of 30s
            self.detector_interval = 60
            self.snapshot_interval = 60
            # 关闭非关键检测器
            self.detectors = self.detectors[:3]  # 只保留前3个
            
        elif level == self.LEVEL_MINIMAL:
            # 仅接受事件存储，不做实时分析
            self.realtime_analysis = False
            # WebSocket不推送反馈
            self.ws_feedback_enabled = False
            # 标记为延后分析
            
        elif level == self.LEVEL_OFFLINE:
            # 客户端完全独立运行
            # 服务端不接受新事件
            pass
```

## 12. 总结

本引擎作为 PrimeTop 写作辅导链路中**过程侧**的核心分析能力，填补了现有作文模块仅关注写作**结果**（批改评分、抄袭检测、结构分析）的空白。

### 核心价值

1. **过程可视化**：将不可见的写作思维过程转化为可量化、可追踪的行为指标
2. **实时关怀**：在学生写作遇到困难时提供及时、轻量、个性化的智能干预
3. **AI依赖防控**：精准识别学生对AI写作辅助的过度依赖，引导独立写作能力培养
4. **形成性评价**：为教师和家长提供写作过程的形成性评价数据，而非仅依赖最终成品评分
5. **习惯养成**：通过长期写作习惯画像，帮助学生认识并改善自己的写作模式

### 实施建议

- **Phase 1 (MVP+)**：实现基础事件采集、阶段识别、困难检测（起笔困难+卡壳）、简单干预（鼓励提示）
- **Phase 2 (V1.0)**：完善全部检测器、WebSocket实时反馈、写作过程报告、家长/教师端推送
- **Phase 3 (V1.5)**：AI依赖度深度分析、个性化干预策略优化、写作习惯画像趋势分析
- **Phase 4 (V2.0)**：跨学生群体写作行为模式挖掘、班级写作教学改进建议、AI辅助效果归因分析
