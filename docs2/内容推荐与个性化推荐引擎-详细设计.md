# 内容推荐与个性化推荐引擎 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

内容推荐与个性化推荐引擎是 PrimeTop 的智能化核心组件，负责根据用户的学习画像、行为历史、学习目标和上下文场景，为每个学生提供个性化的内容推荐，包括题目、知识点、学习路径、学习计划等。推荐引擎是提升用户粘性、学习效果和商业转化的关键基础设施。

### 1.2 与其他模块的边界

| 维度 | 推荐引擎（本文档） | 其他模块 |
|------|-------------------|---------|
| 职责 | 计算和排序个性化内容列表 | 内容存储、内容展示、内容评估 |
| 输入 | 用户画像、学习行为、内容特征 | 原始内容、题目、章节 |
| 输出 | 推荐结果列表（带评分） | 用户界面、学习计划 |
| 评估 | 推荐效果指标（CTR、完成率、正确率） | 学习效果、留存、转化 |
| 类比 | 推荐算法 + 排序服务 | 内容服务 + 学习服务 |

### 1.3 优先级

P1 — V1.0 阶段核心能力，支持智能选题和个性化学习路径

### 1.4 依赖关系

```
用户学习画像服务 ───→ 用户能力模型、薄弱点、学习偏好
学习记录服务       ───→ 答题历史、学习时长、章节进度
错题整理服务       ───→ 错题数据、错因标签、复习状态
题目与题库服务     ───→ 题目特征、难度、知识点标签
知识点体系         ───→ 知识点层级、前置关系
教材章节服务       ───→ 教材版本、章节进度
学习规划服务       ───→ 学习目标、学习计划
时间与场景服务     ───→ 当前时间、学习场景、设备信息
```

下游消费方：
```
首页工作台       ──→ 展示个性化任务推荐
同步课堂         ──→ 推荐章节学习内容
错题复习         ──→ 推荐复习题目
学习规划         ──→ 生成个性化学习计划
拍题答疑         ──→ 推荐同类练习题
家长报告         ──→ 展示学习建议
```

## 2. 核心概念

### 2.1 推荐场景

PrimeTop 的推荐场景可以分为以下几类：

| 场景类型 | 说明 | 输入 | 输出 |
|---------|------|------|------|
| 题目推荐 | 根据当前学习进度推荐练习题 | 用户ID、学科、章节 | 题目列表（按相关性排序） |
| 错题复习推荐 | 根据错题数据推荐复习题目 | 用户ID、错题集合 | 需复习的题目列表 |
| 知识点推荐 | 推荐下一个应该学习的知识点 | 用户ID、当前章节 | 知识点列表（按优先级） |
| 学习路径推荐 | 生成完整的学习路径规划 | 用户ID、学习目标 | 学习路径（章节/知识点序列） |
| 类题推荐 | 基于当前题目推荐相似题目 | 题目ID、用户能力 | 相似题目列表 |
| 文章/资源推荐 | 推荐学习资料、微课、知识点讲解 | 用户ID、当前知识点 | 资源列表 |

### 2.2 推荐策略

推荐引擎采用多策略融合的方式：

| 策略名称 | 说明 | 适用场景 | 实现方式 |
|---------|------|---------|---------|
| 基于知识点的推荐 | 按照知识点层级和前置关系推荐 | 章节学习、知识点学习 | 知识图谱 + 拓扑排序 |
| 基于薄弱点的推荐 | 优先推荐用户薄弱的知识点 | 错题复习、巩固提升 | 掌握度排序 |
| 基于难度的推荐 | 匹配用户当前能力水平的难度 | 日常练习、测评 | 难度自适应算法 |
| 基于协同过滤的推荐 | 推荐"相似用户"也学的内容 | 发现式推荐、拓展学习 | User-based CF / Item-based CF |
| 基于内容的推荐 | 根据内容特征相似性推荐 | 类题推荐、资源推荐 | 向量相似度 |
| 基于时序的推荐 | 根据时间规律推荐（复习、巩固） | 复习提醒、间隔重复 | 遗忘曲线算法 |
| 混合推荐 | 融合多种策略，加权综合 | 综合推荐 | 多策略融合 + Learning to Rank |

### 2.3 评估指标

| 指标类型 | 指标名称 | 说明 | 计算方式 |
|---------|---------|------|---------|
| **推荐质量** | 相关性评分 | 推荐内容与用户需求的相关度 | 人工标注 / 模型评估 |
| | 预期正确率 | 用户完成推荐题目预计的准确率 | 基于能力预测 |
| **用户行为** | 点击率 (CTR) | 推荐内容被点击的比例 | 点击次数 / 展示次数 |
| | 完成率 | 推荐任务被完成的比例 | 完成次数 / 展示次数 |
| | 正确率 | 完成推荐题目的平均正确率 | 答对次数 / 答题次数 |
| | 深度 | 用户在推荐结果上的浏览深度 | 点击位置平均排名 |
| **学习效果** | 知识掌握度提升 | 完成推荐后的掌握度变化 | 掌握度增量 |
| | 错题减少率 | 复习后错题比例的下降 | (初始-后续) / 初始 |
| **商业指标** | 会员转化率 | 使用推荐功能后的付费转化 | 付费人数 / 活跃人数 |
| | 留存提升 | 推荐功能使用者的留存率提升 | 推荐用户留存 - 非推荐用户留存 |

## 3. 数据结构

### 3.1 推荐任务表 `recommendation_tasks`

```sql
CREATE TABLE recommendation_tasks (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id         VARCHAR(32) NOT NULL COMMENT '任务唯一标识',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    task_type       VARCHAR(20) NOT NULL COMMENT '任务类型：question/knowledge/learning_path/article',
    scene           VARCHAR(30) NOT NULL COMMENT '推荐场景：home_review/chapter_learning/mistake_review/similar_questions',
    request_params  JSON COMMENT '请求参数',
    result_count    INT DEFAULT 0 COMMENT '返回结果数量',
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '状态：0=待处理 1=处理中 2=已完成 3=失败',
    error_message   VARCHAR(500) COMMENT '错误信息',
    processing_time_ms INT COMMENT '处理耗时(毫秒)',
    strategy_used   VARCHAR(100) COMMENT '使用的推荐策略',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_user_scene (user_id, scene, created_at),
    INDEX idx_task_id (task_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='推荐任务记录';
```

## 5. 核心算法与逻辑

### 5.1 基于知识点的推荐算法

**适用场景**：章节学习、知识点学习

**算法原理**：
1. 获取用户当前章节/知识点
2. 查找该知识点的子知识点（后置知识点）
3. 查找该知识点的关联知识点
4. 按照前置依赖关系排序，确保推荐路径的正确性
5. 过滤用户已掌握的知识点

**伪代码**：

```python
def recommend_by_knowledge_point(user_id, current_kp_id, limit=10):
    # 获取用户画像
    user_profile = get_user_profile(user_id)

    # 获取当前知识点信息
    current_kp = get_knowledge_point(current_kp_id)

    # 获取后置知识点（直接子节点）
    child_kps = get_child_knowledge_points(current_kp_id)

    # 获取关联知识点
    related_kps = get_related_knowledge_points(current_kp_id)

    # 合并候选知识点
    candidate_kps = list(set(child_kps + related_kps))

    # 过滤已掌握的
    candidate_kps = [kp for kp in candidate_kps
                     if not is_kp_mastered(user_id, kp.id)]

    # 根据前置依赖关系排序
    def sort_key(kp):
        # 优先级1：是否是当前知识点的直接子节点
        is_child = kp.id in [c.id for c in child_kps]
        # 优先级2：重要性
        importance = kp.importance
        # 优先级3：难度（先易后难）
        difficulty = kp.difficulty
        return (not is_child, -importance, difficulty)

    candidate_kps.sort(key=sort_key)

    return candidate_kps[:limit]
```

### 5.2 基于薄弱点的推荐算法

**适用场景**：错题复习、巩固提升

**算法原理**：
1. 从用户画像中获取知识点掌握度数据
2. 筛选掌握度低于阈值的知识点
3. 按掌握度排序（优先推荐最薄弱的）
4. 考虑时间因素（优先推荐长时间未复习的薄弱点）
5. 考虑知识点重要性（优先推荐高权重的薄弱点）

**伪代码**：

```python
def recommend_by_weakness(user_id, subject_id, limit=10):
    # 获取用户掌握度数据
    mastery_data = get_knowledge_mastery(user_id, subject_id)

    # 筛选薄弱知识点（掌握度 < 0.7）
    weak_kps = [kp for kp in mastery_data if kp.mastery < 0.7]

    # 计算优先级分数
    def calculate_priority_score(kp_mastery):
        mastery = kp_mastery.mastery
        last_review_time = kp_mastery.last_review_time
        importance = kp_mastery.importance
        frequency = kp_mastery.frequency

        # 分数越低，优先级越高
        # 掌握度越低，优先级越高
        score = mastery

        # 时间衰减：距离上次复习越久，优先级越高
        days_since_review = (now() - last_review_time).days
        time_decay = max(0.1, 1 - days_since_review / 30)  # 30天衰减
        score *= time_decay

        # 重要性加权
        score *= (5 - importance) / 4

        # 频率加权（高频考点优先）
        score *= (5 - frequency) / 4

        return score

    weak_kps.sort(key=calculate_priority_score)

    return weak_kps[:limit]
```

### 5.3 基于难度的自适应推荐算法

**适用场景**：日常练习、测评

**算法原理**：
1. 根据用户能力评估当前合适的难度范围
2. 采用**i+1 原则**：推荐略高于用户当前能力的题目（难度 × 1.1）
3. 连续答对时，逐步提高推荐难度
4. 连续答错时，逐步降低推荐难度
5. 维护用户的动态难度调整系数

**伪代码**：

```python
class DifficultyAdjuster:
    def __init__(self, user_id):
        self.user_id = user_id
        self.user_level = get_user_ability_level(user_id)  # 1-5
        self.recent_results = get_recent_answer_results(user_id, n=10)
        self.adjust_factor = 1.0

    def calculate_target_difficulty(self):
        # 基础难度
        base_difficulty = self.user_level

        # 根据最近答题结果调整
        correct_rate = calculate_correct_rate(self.recent_results)

        if correct_rate > 0.8:
            # 答对率高，适当提升难度
            self.adjust_factor = min(1.3, self.adjust_factor * 1.05)
        elif correct_rate < 0.5:
            # 答对率低，降低难度
            self.adjust_factor = max(0.7, self.adjust_factor * 0.95)

        target_difficulty = base_difficulty * self.adjust_factor

        # 限制在合理范围内
        return max(1, min(5, target_difficulty))

    def on_answer(self, question_difficulty, is_correct):
        # 记录答题结果
        record_answer_result(self.user_id, question_difficulty, is_correct)

        # 更新最近结果缓存
        self.recent_results.append(is_correct)
        if len(self.recent_results) > 10:
            self.recent_results.pop(0)

def recommend_by_difficulty(user_id, knowledge_point_id, limit=10):
    adjuster = DifficultyAdjuster(user_id)
    target_difficulty = adjuster.calculate_target_difficulty()

    # 查找难度接近的题目
    tolerance = 0.5  # 难度容差
    min_diff = max(1, target_difficulty - tolerance)
    max_diff = min(5, target_difficulty + tolerance)

    questions = find_questions_by_difficulty_range(
        knowledge_point_id, min_diff, max_diff, limit * 2
    )

    # 排除已答过的题目（最近7天）
    answered_question_ids = get_recent_answered_question_ids(
        user_id, days=7
    )

    questions = [q for q in questions
                 if q.id not in answered_question_ids]

    return questions[:limit]
```

### 5.4 基于遗忘曲线的复习推荐算法

**适用场景**：错题复习、间隔重复

**算法原理**：
1. 采用 SuperMemo-2 简化版算法或艾宾浩斯遗忘曲线
2. 根据答题结果计算下次复习时间
3. 推荐到达复习时间的内容
4. 根据记忆强度调整复习间隔

**伪代码**：

```python
class SpacedRepetition:
    # SuperMemo-2 简化版算法
    @staticmethod
    def calculate_next_review(last_review_date, quality, interval, easiness):
        """
        quality: 答题质量 (0-5)
        interval: 上次复习间隔（天）
        easiness: 记忆难易度 (1.3-2.5)
        """
        if quality >= 3:
            if interval == 0:
                next_interval = 1
            elif interval == 1:
                next_interval = 6
            else:
                next_interval = interval * easiness
        else:
            # 答错，重置间隔
            next_interval = 1

        # 更新记忆难易度
        easiness = easiness + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
        easiness = max(1.3, easiness)

        next_review_date = last_review_date + timedelta(days=int(next_interval))

        return next_review_date, next_interval, easiness

def recommend_for_review(user_id, limit=10):
    # 获取待复习的题目/知识点
    review_items = get_review_items(user_id)

    # 筛选到达复习时间的
    now = datetime.now()
    due_items = [item for item in review_items
                 if item.next_review_date <= now]

    # 按逾期时间排序
    due_items.sort(key=lambda x: (now - x.next_review_date).days, reverse=True)

    return due_items[:limit]

def on_answer_for_review(user_id, item_id, quality):
    # 获取复习记录
    review_record = get_review_record(user_id, item_id)

    # 计算下次复习时间
    next_date, interval, easiness = SpacedRepetition.calculate_next_review(
        review_record.last_review_date,
        quality,
        review_record.interval,
        review_record.easiness
    )

    # 更新复习记录
    update_review_record(user_id, item_id, {
        'last_review_date': datetime.now(),
        'next_review_date': next_date,
        'interval': interval,
        'easiness': easiness,
        'last_quality': quality
    })
```

### 5.5 混合推荐与 Learning to Rank

**适用场景**：综合推荐场景，如首页推荐

**算法原理**：
1. 多策略并行计算，生成多个候选列表
2. 对每个候选项计算多维度特征
3. 使用 Learning to Rank 模型（如 LambdaMART）进行重排序
4. 支持多样性控制（避免推荐过于相似的内容）

**特征工程**：

| 特征类别 | 特征名称 | 说明 |
|---------|---------|------|
| **用户特征** | 用户能力等级 | 基于历史答题计算的等级 (1-5) |
| | 学科偏好 | 各学科的答题比例 |
| | 活跃度 | 近30天活跃天数 |
| | 学习时段偏好 | 用户常活跃的时段 |
| **内容特征** | 难度 | 题目/知识点难度 (1-5) |
| | 知识点重要性 | 知识点重要程度 (1-5) |
| | 知识点频率 | 考点出现频率 (1-5) |
| | 内容类型 | 题目/微课/文章 |
| | 内容质量 | 内容评分/点赞数 |
| **交互特征** | 用户与知识点的关系 | 掌握度/最近学习时间 |
| | 用户相似度 | 与相似用户的重叠度 |
| | 内容流行度 | 最近7天点击/完成次数 |
| | 时效性 | 内容发布时间/更新时间 |
| **上下文特征** | 推荐场景 | home/chapter/mistake |
| | 当前时间 | 小时/星期几 |
| | 剩余时间 | 用户计划学习时间 |
| | 设备类型 | 手机/平板 |

**伪代码**：

```python
def hybrid_recommendation(user_id, scene, limit=10):
    # 并行执行多个推荐策略
    strategies = [
        recommend_by_knowledge_point,
        recommend_by_weakness,
        recommend_by_difficulty,
        recommend_by_collaborative_filtering,
        recommend_by_content_similarity
    ]

    all_candidates = []
    for strategy in strategies:
        candidates = strategy(user_id, scene)
        all_candidates.extend(candidates)

    # 去重
    unique_candidates = deduplicate(all_candidates)

    # 提取特征
    features = []
    for candidate in unique_candidates:
        feature_dict = extract_features(user_id, candidate, scene)
        features.append((candidate, feature_dict))

    # 使用 LTR 模型排序
    ranked_items = ltr_model.rank(features)

    # 多样性控制
    diversified_items = diversify(ranked_items, limit)

    return diversified_items[:limit]

def diversify(items, limit):
    """
    多样性控制：避免推荐过于相似的内容
    使用 MM（Maximal Marginal Relevance）算法
    """
    if len(items) <= limit:
        return items

    selected = [items[0]]
    remaining = items[1:]

    while len(selected) < limit and remaining:
        # 找到与已选项最不相似的
        best_item = None
        best_score = -1

        for item in remaining:
            # 计算与已选项的最大相似度（越小越好）
            max_sim = max([similarity(item, sel) for sel in selected])
            # MMR 分数 = 相关性 - λ × 相似度
            score = item.score - 0.5 * max_sim

            if score > best_score:
                best_score = score
                best_item = item

        if best_item:
            selected.append(best_item)
            remaining.remove(best_item)
        else:
            break

    return selected
```

        pass

    @abstractmethod

        """执行推荐逻辑"""
        pass

    @abstractmethod
    def is_enabled(self):
        """判断策略是否启用"""
        pass

class TrendBasedStrategy(RecommendationStrategy):

def cross_device_recommendation(user_id, device_type, scene):
