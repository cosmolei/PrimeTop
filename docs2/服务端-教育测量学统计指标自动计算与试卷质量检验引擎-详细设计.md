# 服务端-教育测量学统计指标自动计算与试卷质量检验引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 教育平台的**教育测量学核心计算基础设施**，负责对题库中的题目和组装完成的试卷进行**统计学质量指标**的自动计算、持续监控和质量分级。

与已有模块的职责边界：
- **题目难度标定与能力评估模型**：侧重于题目难度参数的初始标定和被试能力估计（IRT参数估计）
- **智能组卷与自适应测试引擎**：侧重于试卷组装和自适应选题
- **考后试卷深度分析与个性化讲评报告生成服务**：侧重于面向学生的个性化讲评
- **本引擎**：侧重于从**教育测量学**角度，对题目和试卷进行**信度、效度、区分度、选项分析、DIF分析**等统计质量检验，输出标准化质量报告，为内容生产团队提供数据驱动的质量改进依据

### 1.2 设计目标

1. **自动化**：答题数据产生后自动触发指标计算，无需人工干预
2. **标准化**：输出符合教育测量学规范的统计指标和评判标准
3. **实时性**：支持离线批量计算和在线实时查询双模式
4. **可解释**：每个指标附带直观的质量评级和改进建议
5. **规模化**：支持百万级答题记录的高效聚合计算

### 1.3 适用范围

| 场景 | 说明 |
|------|------|
| 新题入库质检 | 题目经过试测后，自动计算各项指标，判断是否达到入库标准 |
| 试卷质量验收 | 组卷完成后或考试结束后，评估整份试卷的信度、效度 |
| 题目生命周期管理 | 定期重新计算指标，识别质量退化题目 |
| DIF公平性审查 | 检测题目对不同地区/性别/学段学生是否存在测量偏差 |
| 内容生产反馈 | 为内容团队提供数据驱动的题目改进方向 |

## 2. 核心概念与指标体系

### 2.1 经典测验理论（CTT）指标

#### 2.1.1 题目难度指数（P-Value）

```
P = R / N

P: 难度指数（0~1）
R: 答对人数
N: 总作答人数
```

- P 越大，题目越容易
- 对于多分值主观题，采用均分率：`P = 平均得分 / 满分`

#### 2.1.2 题目区分度（Discrimination Index, D）

```
方法一：极端组法（27%分组）
D = (PH - PL) / M

PH: 高分组（前27%）答对率
PL: 低分组（后27%）答对率
M: 题目满分（客观题M=1）

方法二：点双列相关系数（Point-Biserial Correlation）
r_pbs = (M_h - M_l) / S_t × √(p × q)

M_h: 答对该题学生的总分均值
M_l: 答错该题学生的总分均值
S_t: 总分标准差
p: 答对率
q: 1-p
```

#### 2.1.3 选择题干扰项分析（Distractor Analysis）

对每个干扰项分析：
- **选择率**：选择该项的人数比例
- **高分组vs低分组选择率差异**：好的干扰项应吸引更多低分组学生
- **无效干扰项标准**：选择率 < 5% 或高分组选择率 > 低分组选择率

#### 2.1.4 试卷信度（Reliability）

```
Cronbach's Alpha:
α = (K / (K-1)) × (1 - Σσ²_i / σ²_t)

K: 题目数
σ²_i: 第i题的方差
σ²_t: 总分方差

KR-20（二分计分题目）:
KR-20 = (K / (K-1)) × (1 - Σp_i×q_i / σ²_t)

p_i: 第i题答对率
q_i: 1 - p_i
```

### 2.2 项目反应理论（IRT）指标

#### 2.2.1 三参数逻辑斯蒂模型（3PL）

```
P(θ) = c + (1-c) × 1 / (1 + exp(-a×(θ-b)))

a: 区分度参数（discrimination）
b: 难度参数（difficulty）
c: 猜测参数（guessing，下限渐近线）
θ: 受测者能力值
```

#### 2.2.2 题目信息函数（Item Information Function）

```
I(θ) = a² × [P'(θ)]² / [P(θ) × (1-P(θ))]

简化形式（3PL）:
I(θ) = a² × (1-P) / P × [(P-c)/(1-c)]²
```

#### 2.2.3 测验信息函数与标准误

```
测验信息函数: TIF(θ) = Σ I_i(θ)
测量标准误: SEM(θ) = 1 / √TIF(θ)
```

### 2.3 差异题目功能分析（DIF）

使用 **Mantel-Haenszel (MH) 方法**检测题目对不同群体是否存在系统性偏差：

```
MH统计量: α_MH = Σ(n_{1k}×m_{0k}/T_k) / Σ(n_{0k}×m_{1k}/T_k)

MH-Ln(a) = -2.35 × ln(α_MH)  （ETD分类标准）

|MH-Ln(a)| < 1.0: A级（无DIF）
1.0 ≤ |MH-Ln(a)| < 1.5: B级（轻微DIF）
|MH-Ln(a)| ≥ 1.5: C级（严重DIF，需修订或淘汰）
```

### 5.1 CTT 指标计算引擎

```java
@Service
public class CTTCalculationEngine {
    
    private static final double UPPER_LOWER_RATIO = 0.27; // 极端组比例
    
    /**
     * 计算题目CTT指标
     * @param responses 作答记录列表
     * @param questionScore 题目满分
     * @return CTT指标结果
     */
    public CTTResult calculate(List<QuestionResponse> responses, double questionScore) {
        int n = responses.size();
        if (n < 30) {
            return CTTResult.insufficient(n);
        }
        
        // 1. 计算难度P值
        double difficultyP = calculateDifficulty(responses, questionScore, n);
        
        // 2. 按总分排序，划分极端组
        List<QuestionResponse> sorted = responses.stream()
            .sorted(Comparator.comparingDouble(QuestionResponse::getTotalScore).reversed())
            .collect(Collectors.toList());
        
        int groupSize = (int) Math.floor(n * UPPER_LOWER_RATIO);
        List<QuestionResponse> upperGroup = sorted.subList(0, groupSize);
        List<QuestionResponse> lowerGroup = sorted.subList(n - groupSize, n);
        
        // 3. 计算区分度（极端组法）
        double upperCorrectRate = calculateCorrectRate(upperGroup, questionScore);
        double lowerCorrectRate = calculateCorrectRate(lowerGroup, questionScore);
        double discriminationD = upperCorrectRate - lowerCorrectRate;
        
        // 4. 计算点双列相关系数
        double pointBiserial = calculatePointBiserial(responses, questionScore);
        
        // 5. 确定等级
        DifficultyLevel diffLevel = DifficultyLevel.fromPValue(difficultyP);
        DiscriminationQuality discQuality = DiscriminationQuality.fromDValue(discriminationD);
        
        return CTTResult.builder()
            .difficultyP(round(difficultyP, 4))
            .difficultyLevel(diffLevel)
            .discriminationD(round(discriminationD, 4))
            .discriminationPbis(round(pointBiserial, 4))
            .discriminationQuality(discQuality)
            .upperGroupCorrectRate(round(upperCorrectRate, 4))
            .lowerGroupCorrectRate(round(lowerCorrectRate, 4))
            .sampleSize(n)
            .build();
    }
    
    private double calculateDifficulty(List<QuestionResponse> responses, 
                                        double maxScore, int n) {
        if (maxScore <= 0) return 0;
        double totalEarned = responses.stream()
            .mapToDouble(QuestionResponse::getEarnedScore)
            .sum();
        return totalEarned / (maxScore * n);
    }
    
    private double calculatePointBiserial(List<QuestionResponse> responses, 
                                           double questionScore) {
        int n = responses.size();
        
        // 分为答对和答错两组
        List<Double> correctTotalScores = new ArrayList<>();
        List<Double> wrongTotalScores = new ArrayList<>();
        
        for (QuestionResponse r : responses) {
            if (r.getEarnedScore() / questionScore >= 0.5) {
                correctTotalScores.add(r.getTotalScore());
            } else {
                wrongTotalScores.add(r.getTotalScore());
            }
        }
        
        if (correctTotalScores.isEmpty() || wrongTotalScores.isEmpty()) {
            return 0.0;
        }
        
        double meanCorrect = mean(correctTotalScores);
        double meanWrong = mean(wrongTotalScores);
        double sdTotal = standardDeviation(
            responses.stream().map(QuestionResponse::getTotalScore).collect(Collectors.toList())
        );
        
        if (sdTotal == 0) return 0.0;
        
        double p = (double) correctTotalScores.size() / n;
        double q = 1.0 - p;
        
        return (meanCorrect - meanWrong) / sdTotal * Math.sqrt(p * q);
    }
    
    private double calculateCorrectRate(List<QuestionResponse> group, double questionScore) {
        if (group.isEmpty() || questionScore <= 0) return 0;
        double earned = group.stream()
            .mapToDouble(QuestionResponse::getEarnedScore)
            .sum();
        return earned / (questionScore * group.size());
    }
}
```

### 5.2 IRT 参数估计引擎

```java
@Service
public class IRTEstimationEngine {
    
    private static final int MAX_ITERATIONS = 200;
    private static final double CONVERGENCE_THRESHOLD = 0.001;
    private static final double THETA_RANGE_MIN = -3.0;
    private static final double THETA_RANGE_MAX = 3.0;
    private static final int QUADRATURE_POINTS = 40; // EM算法积分点数
    
    /**
     * 使用EM算法估计3PL模型参数
     * @param responseMatrix 作答矩阵 [学生数 × 题目数]
     * @param itemCount 题目数
     * @return IRT参数估计结果
     */
    public IRTResult estimate3PL(int[][] responseMatrix, int studentCount, int itemCount) {
        // 初始化参数
        double[] a = new double[itemCount];   // 区分度
        double[] b = new double[itemCount];   // 难度
        double[] c = new double[itemCount];   // 猜测参数
        
        Arrays.fill(a, 1.0);
        Arrays.fill(c, 0.1);
        
        // 初始化θ的先验分布（正态分布N(0,1)的离散化）
        double[] thetaNodes = new double[QUADRATURE_POINTS];
        double[] thetaWeights = new double[QUADRATURE_POINTS];
        initializeNormalQuadrature(thetaNodes, thetaWeights, 0, 1);
        
        // 初始难度估计（使用CTT难度对数转换）
        for (int j = 0; j < itemCount; j++) {
            double p = calculateItemDifficulty(responseMatrix, j, studentCount);
            b[j] = logit(p);
        }
        
        // EM迭代
        for (int iter = 0; iter < MAX_ITERATIONS; iter++) {
            // E步：计算每个学生在每个θ节点上的后验概率
            double[][][] posterior = new double[studentCount][QUADRATURE_POINTS][itemCount];
            double[] marginalLikelihood = new double[studentCount];
            
            for (int i = 0; i < studentCount; i++) {
                for (int q = 0; q < QUADRATURE_POINTS; q++) {
                    double likelihood = 1.0;
                    for (int j = 0; j < itemCount; j++) {
                        double prob = calculate3PLProbability(thetaNodes[q], a[j], b[j], c[j]);
                        if (responseMatrix[i][j] == 1) {
                            likelihood *= prob;
                        } else {
                            likelihood *= (1 - prob);
                        }
                    }
                    posterior[i][q] = likelihood * thetaWeights[q];
                    marginalLikelihood[i] += posterior[i][q];
                }
                // 归一化
                if (marginalLikelihood[i] > 0) {
                    for (int q = 0; q < QUADRATURE_POINTS; q++) {
                        posterior[i][q] /= marginalLikelihood[i];
                    }
                }
            }
            
            // M步：更新参数
            double maxDelta = 0;
            for (int j = 0; j < itemCount; j++) {
                double oldA = a[j], oldB = b[j], oldC = c[j];
                
                // 使用Newton-Raphson更新参数
                updateItemParameters(responseMatrix, posterior, a, b, c, 
                                     j, studentCount, thetaNodes);
                
                maxDelta = Math.max(maxDelta, 
                    Math.abs(a[j] - oldA) + Math.abs(b[j] - oldB) + Math.abs(c[j] - oldC));
            }
            
            // 收敛检查
            if (maxDelta < CONVERGENCE_THRESHOLD) {
                log.info("IRT 3PL EM converged at iteration {}", iter);
                break;
            }
        }
        
        // 计算参数标准误
        double[] seA = calculateParameterSE(responseMatrix, a, b, c, 'a', studentCount);
        double[] seB = calculateParameterSE(responseMatrix, a, b, c, 'b', studentCount);
        double[] seC = calculateParameterSE(responseMatrix, a, b, c, 'c', studentCount);
        
        // 计算拟合统计量
        double fitStatistic = calculateItemFit(responseMatrix, a, b, c, studentCount);
        
        return IRTResult.builder()
            .model("3PL")
            .aParameters(a)
            .bParameters(b)
            .cParameters(c)
            .standardErrorsA(seA)
            .standardErrorsB(seB)
            .standardErrorsC(seC)
            .fitStatistic(fitStatistic)
            .iterations(iterations)
            .converged(maxDelta < CONVERGENCE_THRESHOLD)
            .build();
    }
    
    /**
     * 计算3PL模型下的作答概率
     */
    private double calculate3PLProbability(double theta, double a, double b, double c) {
        double z = a * (theta - b);
        double pStar = 1.0 / (1.0 + Math.exp(-z));
        return c + (1.0 - c) * pStar;
    }
    
    /**
     * 计算题目信息函数
     */
    public double calculateItemInformation(double theta, double a, double b, double c) {
        double p = calculate3PLProbability(theta, a, b, c);
        double pStar = 1.0 / (1.0 + Math.exp(-a * (theta - b)));
        double qStar = 1.0 - pStar;
        double q = 1.0 - p;
        
        if (p <= 0 || q <= 0 || (1 - c) <= 0) return 0;
        
        double numerator = a * a * pStar * pStar * qStar;
        double denominator = p * p * (1 - c) * (1 - c);
        
        return numerator / denominator;
    }
    
    /**
     * 计算测验信息函数（所有题目信息函数之和）
     */
    public TestInformationResult calculateTestInformation(
            double[] thetaRange, double[] aParams, double[] bParams, double[] cParams) {
        
        int points = thetaRange.length;
        double[] tif = new double[points];
        double[] sem = new double[points];
        
        for (int i = 0; i < points; i++) {
            double theta = thetaRange[i];
            double totalInfo = 0;
            for (int j = 0; j < aParams.length; j++) {
                totalInfo += calculateItemInformation(theta, aParams[j], bParams[j], cParams[j]);
            }
            tif[i] = totalInfo;
            sem[i] = totalInfo > 0 ? 1.0 / Math.sqrt(totalInfo) : Double.MAX_VALUE;
        }
        
        return TestInformationResult.builder()
            .thetaPoints(thetaRange)
            .testInformationFunction(tif)
            .standardErrorOfMeasurement(sem)
            .build();
    }
}
```

### 5.3 Cronbach's Alpha 计算

```java
@Service
public class ReliabilityCalculator {
    
    /**
     * 计算Cronbach's Alpha
     * @param scoreMatrix 得分矩阵 [学生数 × 题目数]
     * @return Alpha系数
     */
    public double calculateCronbachAlpha(double[][] scoreMatrix) {
        int n = scoreMatrix.length;        // 学生数
        if (n < 2) return 0;
        
        int k = scoreMatrix[0].length;     // 题目数
        if (k < 2) return 1.0; // 单题信度定义为1
        
        // 计算每道题的方差
        double[] itemVariances = new double[k];
        for (int j = 0; j < k; j++) {
            itemVariances[j] = variance(extractColumn(scoreMatrix, j));
        }
        
        // 计算总分方差
        double[] totalScores = new double[n];
        for (int i = 0; i < n; i++) {
            totalScores[i] = Arrays.stream(scoreMatrix[i]).sum();
        }
        double totalVariance = variance(totalScores);
        
        if (totalVariance == 0) return 0;
        
        double sumItemVariance = Arrays.stream(itemVariances).sum();
        
        return (k / (double)(k - 1)) * (1 - sumItemVariance / totalVariance);
    }
    
    /**
     * 计算KR-20（适用于二分计分题目）
     */
    public double calculateKR20(double[][] scoreMatrix) {
        int n = scoreMatrix.length;
        int k = scoreMatrix[0].length;
        
        // 计算每题p和q
        double sumPQ = 0;
        for (int j = 0; j < k; j++) {
            double[] column = extractColumn(scoreMatrix, j);
            double p = mean(column);
            double q = 1.0 - p;
            sumPQ += p * q;
        }
        
        double[] totalScores = new double[n];
        for (int i = 0; i < n; i++) {
            totalScores[i] = Arrays.stream(scoreMatrix[i]).sum();
        }
        double totalVariance = variance(totalScores);
        
        if (totalVariance == 0) return 0;
        
        return (k / (double)(k - 1)) * (1 - sumPQ / totalVariance);
    }
    
    /**
     * 分半信度 + Spearman-Brown校正
     */
    public SplitHalfResult calculateSplitHalfReliability(double[][] scoreMatrix) {
        int n = scoreMatrix.length;
        int k = scoreMatrix[0].length;
        
        // 奇偶分半
        double[] oddHalfScores = new double[n];
        double[] evenHalfScores = new double[n];
        
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < k; j++) {
                if (j % 2 == 0) {
                    oddHalfScores[i] += scoreMatrix[i][j];
                } else {
                    evenHalfScores[i] += scoreMatrix[i][j];
                }
            }
        }
        
        // 计算Pearson相关
        double r = pearsonCorrelation(oddHalfScores, evenHalfScores);
        
        // Spearman-Brown校正
        double sbCorrected = (2 * r) / (1 + r);
        
        return SplitHalfResult.builder()
            .halfCorrelation(round(r, 4))
            .spearmanBrownCorrected(round(sbCorrected, 4))
            .splitMethod("ODD_EVEN")
            .build();
    }
}
```

```java
@Service
public class DistractorAnalysisEngine {
    
    private static final double INEFFECTIVE_THRESHOLD = 0.05; // 5%选择率阈值
    private static final double UPPER_LOWER_RATIO = 0.27;
    
    public List<DistractorAnalysisResult> analyze(
            List<QuestionResponse> responses, 
            Map<String, Boolean> optionCorrectMap,
            double questionScore) {
        
        int n = responses.size();
        
        // 按总分排序并取极端组
        List<QuestionResponse> sorted = responses.stream()
            .sorted(Comparator.comparingDouble(QuestionResponse::getTotalScore).reversed())
            .collect(Collectors.toList());
        
        int groupSize = (int) Math.floor(n * UPPER_LOWER_RATIO);
        List<QuestionResponse> upperGroup = sorted.subList(0, Math.min(groupSize, n));
        List<QuestionResponse> lowerGroup = sorted.subList(
            Math.max(n - groupSize, groupSize), n);
        
        List<DistractorAnalysisResult> results = new ArrayList<>();
        
        for (Map.Entry<String, Boolean> entry : optionCorrectMap.entrySet()) {
            String optionKey = entry.getKey();
            boolean isCorrect = entry.getValue();
            
            // 总体选择率
            int totalSelected = (int) responses.stream()
                .filter(r -> optionKey.equals(r.getSelectedOption()))
                .count();
            double selectionRate = (double) totalSelected / n;
            
            // 高分组和低分组选择率
            long upperSelected = upperGroup.stream()
                .filter(r -> optionKey.equals(r.getSelectedOption())).count();
            long lowerSelected = lowerGroup.stream()
                .filter(r -> optionKey.equals(r.getSelectedOption())).count();
            
            double upperRate = (double) upperSelected / upperGroup.size();
            double lowerRate = (double) lowerSelected / lowerGroup.size();
            
            // 选项区分度（正确答案应为正值，干扰项应为负值）
            double discriminationPower = lowerRate - upperRate;
            
            // 评估干扰项有效性
            DistractorEffectiveness effectiveness;
            String issueFlag = "NONE";
            
            if (isCorrect) {
                effectiveness = null; // 正确答案不评估干扰有效性
            } else {
                if (selectionRate < INEFFECTIVE_THRESHOLD) {
                    effectiveness = DistractorEffectiveness.INEFFECTIVE;
                    issueFlag = "TOO_FEW";
                } else if (upperRate > lowerRate) {
                    effectiveness = DistractorEffectiveness.POOR;
                    issueFlag = "REVERSED_DISCRIMINATION"; // 高分组更多选择此干扰项，题目有问题
                } else if (selectionRate > 0.40 && Math.abs(discriminationPower) < 0.05) {
                    effectiveness = DistractorEffectiveness.POOR;
                    issueFlag = "AMBIGUOUS"; // 选择率高但无区分，可能题目表述有歧义
                } else if (Math.abs(discriminationPower) > 0.1) {
                    effectiveness = DistractorEffectiveness.GOOD;
                } else {
                    effectiveness = DistractorEffectiveness.ACCEPTABLE;
                }
            }
            
            results.add(DistractorAnalysisResult.builder()
                .optionKey(optionKey)
                .isCorrect(isCorrect)
                .selectionRate(round(selectionRate, 4))
                .upperGroupRate(round(upperRate, 4))
                .lowerGroupRate(round(lowerRate, 4))
                .discriminationPower(round(discriminationPower, 4))
                .effectiveness(effectiveness)
                .issueFlag(issueFlag)
                .build());
        }
        
        return results;
    }
}
```

### 5.5 DIF 分析引擎（Mantel-Haenszel方法）

```java
@Service
public class DIFAnalysisEngine {
    
    /**
     * 使用Mantel-Haenszel方法进行DIF分析
     * @param responses 作答数据
     * @param groupAssignments 每个学生的分组 (0=参照组, 1=焦点组)
     * @param totalScoreBands 总分分层（用于MH检验的匹配变量）
     * @return DIF分析结果
     */
    public DIFResult calculateMH(List<DIFResponseData> responses,
                                  Map<Long, Integer> groupAssignments,
                                  int scoreBandCount) {
        
        // 按总分分层
        Map<Integer, List<DIFResponseData>> bands = responses.stream()
            .collect(Collectors.groupingBy(r -> 
                assignToBand(r.getTotalScore(), scoreBandCount)));
        
        double numerator = 0;
        double denominator = 0;
        
        for (Map.Entry<Integer, List<DIFResponseData>> band : bands.entrySet()) {
            List<DIFResponseData> bandData = band.getValue();
            
            // 构建分层2×2×2列联表
            // 对于每个层k: 
            //   n_1k1 (焦点组答对), n_1k0 (焦点组答错)
            //   n_0k1 (参照组答对), n_0k0 (参照组答错)
            //   m_1k (总答对), m_0k (总答错), T_k (层总数)
            
            int n11 = 0, n10 = 0, n01 = 0, n00 = 0; // n_{group}{correct}
            
            for (DIFResponseData rd : bandData) {
                int group = groupAssignments.getOrDefault(rd.getStudentId(), -1);
                if (group < 0) continue;
                
                if (group == 1) { // 焦点组
                    if (rd.isCorrect()) n11++;
                    else n10++;
                } else { // 参照组
                    if (rd.isCorrect()) n01++;
                    else n00++;
                }
            }
            
            int m1k = n11 + n01; // 层内总答对
            int m0k = n10 + n00; // 层内总答错
            int T_k = n11 + n10 + n01 + n00; // 层总数
            
            if (T_k == 0 || m0k == 0) continue;
            
            // MH分子: Σ(n_1k1 × m_0k / T_k) 简化形式
            // MH分母: Σ(n_1k0 × m_1k / T_k) 简化形式
            // 实际使用精确形式:
            double expectedFocalCorrect = (double)(n11 + n10) * m1k / T_k;
            numerator += n11 - expectedFocalCorrect;
            
            double varianceFocalCorrect = (double)(n11 + n10) * (n01 + n00) * m1k * m0k 
                / (T_k * T_k * (T_k - 1));
            denominator += varianceFocalCorrect;
        }
        
        // MH ΔαMH 统计量
        double mhDelta = numerator / denominator;
        
        // 对数比值比 → MH-Ln(a) = -2.35 × ΔαMH
        double mhLogOddsRatio = -2.35 * mhDelta;
        
        // 标准误
        double mhSE = denominator > 0 ? 1.0 / Math.sqrt(denominator) : Double.MAX_VALUE;
        
        // DIF分类
        DIFClassification classification;
        if (Math.abs(mhLogOddsRatio) < 1.0) {
            classification = DIFClassification.A;
        } else if (Math.abs(mhLogOddsRatio) < 1.5) {
            classification = DIFClassification.B;
        } else {
            classification = DIFClassification.C;
        }
        
        // DIF方向
        String direction = Math.abs(mhLogOddsRatio) < 1.0 ? "NEGLIGIBLE" :
            (mhLogOddsRatio > 0 ? "FAVOR_REFERENCE" : "FAVOR_FOCAL");
        
        // 推荐操作
        String recommendedAction;
        switch (classification) {
            case A: recommendedAction = "NONE"; break;
            case B: recommendedAction = "MONITOR"; break;
            case C: recommendedAction = "RETIRE"; break;
            default: recommendedAction = "MONITOR";
        }
        
        return DIFResult.builder()
            .mhStatistic(round(mhDelta, 3))
            .mhLogOddsRatio(round(mhLogOddsRatio, 3))
            .standardError(round(mhSE, 3))
            .classification(classification)
            .direction(direction)
            .recommendedAction(recommendedAction)
            .focalGroupN((int) groupAssignments.values().stream().filter(g -> g == 1).count())
            .referenceGroupN((int) groupAssignments.values().stream().filter(g -> g == 0).count())
            .build();
    }
    
    private int assignToBand(double totalScore, int bandCount) {
        // 按总分分层（通常以1分为一层，或按百分位分层）
        return (int) Math.floor(totalScore);
    }
}
```

```java
@Service
public class QualityScoringEngine {
    
    /**
     * 计算题目综合质量评分（0-100）
     */
    public QualityScore calculateQuestionScore(
            CTTResult ctt, IRTResult irt, 
            List<DistractorAnalysisResult> distractors,
            List<DIFResult> difResults) {
        
        double score = 0;
        List<String> strengths = new ArrayList<>();
        List<String> weaknesses = new ArrayList<>();
        List<String> suggestions = new ArrayList<>();
        
        // 1. 难度维度（20分）
        double difficultyScore = scoreDifficulty(ctt.difficultyP);
        score += difficultyScore;
        if (ctt.difficultyLevel == DifficultyLevel.MEDIUM) {
            strengths.add("难度适中(P=" + ctt.difficultyP + ")");
        } else if (ctt.difficultyP < 0.15 || ctt.difficultyP > 0.90) {
            weaknesses.add("难度极端(P=" + ctt.difficultyP + ")，区分能力受限");
            suggestions.add("建议调整题目难度至P值0.3~0.7区间");
        }
        
        // 2. 区分度维度（30分）
        double discScore = scoreDiscrimination(ctt.discriminationD);
        score += discScore;
        if (ctt.discriminationQuality == DiscriminationQuality.EXCELLENT) {
            strengths.add("区分度优秀(D=" + ctt.discriminationD + ")");
        } else if (ctt.discriminationQuality == DiscriminationQuality.POOR) {
            weaknesses.add("区分度不足(D=" + ctt.discriminationD + ")");
            suggestions.add("建议修改干扰项或调整题目表述以提升区分能力");
        }
        
        // 3. IRT拟合质量（15分）
        if (irt != null && irt.isConverged()) {
            double irtScore = scoreIRT(irt);
            score += irtScore;
            if (irt.getFitStatistic() > 0.95) {
                strengths.add("IRT模型拟合良好");
            }
            
            // 检查猜测参数
            if (irt.getC() != null && irt.getC() > 0.2) {
                weaknesses.add("猜测参数偏高(c=" + irt.getC() + ")，存在较大猜测成分");
                suggestions.add("考虑增加选项迷惑性或减少选项数量");
            }
        } else {
            score += 8; // IRT未收敛给基础分
        }
        
        // 4. 干扰项质量（20分，仅选择题）
        if (distractors != null && !distractors.isEmpty()) {
            double distractorScore = scoreDistractors(distractors);
            score += distractorScore;
            
            long ineffective = distractors.stream()
                .filter(d -> d.getEffectiveness() == DistractorEffectiveness.INEFFECTIVE)
                .count();
            if (ineffective > 0) {
                weaknesses.add(ineffective + "个干扰项选择率过低(<5%)");
                suggestions.add("建议替换无效干扰项");
            }
            
            long reversed = distractors.stream()
                .filter(d -> "REVERSED_DISCRIMINATION".equals(d.getIssueFlag()))
                .count();
            if (reversed > 0) {
                weaknesses.add(reversed + "个干扰项出现反向区分，高分组更多选择");
                suggestions.add("题目可能存在表述歧义，建议全面修订");
            }
        } else {
            score += 15; // 非选择题给基础分
        }
        
        // 5. DIF公平性（15分）
        if (difResults != null && !difResults.isEmpty()) {
            double difScore = scoreDIF(difResults);
            score += difScore;
            
            for (DIFResult dif : difResults) {
                if (dif.getClassification() == DIFClassification.C) {
                    weaknesses.add("在" + dif.getGroupingVariable() + 
                        "维度检测到严重DIF(C级)");
                    suggestions.add("建议立即修订或淘汰该题目");
                } else if (dif.getClassification() == DIFClassification.B) {
                    weaknesses.add("在" + dif.getGroupingVariable() + 
                        "维度检测到轻微DIF(B级)，需持续监控");
                }
            }
        } else {
            score += 12; // 未进行DIF分析给基础分
        }
        
        score = Math.min(100, Math.max(0, score));
        OverallQualityGrade grade = OverallQualityGrade.fromScore(score);
        
        return QualityScore.builder()
            .score(round(score, 2))
            .grade(grade)
            .strengths(strengths)
            .weaknesses(weaknesses)
            .suggestions(String.join("；", suggestions))
            .build();
    }
    
    private double scoreDifficulty(double p) {
        // 钟形曲线评分：P=0.5时满分，两端递减
        if (p >= 0.30 && p <= 0.70) return 20;
        if (p >= 0.20 && p <= 0.80) return 15;
        if (p >= 0.10 && p <= 0.90) return 10;
        return 5;
    }
    
    private double scoreDiscrimination(double d) {
        if (d >= 0.40) return 30;
        if (d >= 0.30) return 25;
        if (d >= 0.20) return 18;
        if (d >= 0.10) return 10;
        return 0;
    }
    
    private double scoreIRT(IRTResult irt) {
        double score = 15;
        if (irt.getFitStatistic() != null && irt.getFitStatistic() < 0.90) {
            score -= 5;
        }
        if (irt.getC() != null && irt.getC() > 0.25) {
            score -= 3;
        }
        if (irt.getA() != null && (irt.getA() < 0.35 || irt.getA() > 2.5)) {
            score -= 3;
        }
        return Math.max(5, score);
    }
    
    private double scoreDistractors(List<DistractorAnalysisResult> distractors) {
        int totalDistractors = distractors.size() - 1; // 排除正确答案
        if (totalDistractors == 0) return 20;
        
        double goodDistractors = distractors.stream()
            .filter(d -> !d.isCorrect() && d.getEffectiveness() == DistractorEffectiveness.GOOD)
            .count();
        double ineffectiveDistractors = distractors.stream()
            .filter(d -> !d.isCorrect() && d.getEffectiveness() == DistractorEffectiveness.INEFFECTIVE)
            .count();
        double reversedDistractors = distractors.stream()
            .filter(d -> "REVERSED_DISCRIMINATION".equals(d.getIssueFlag()))
            .count();
        
        double baseScore = (goodDistractors / totalDistractors) * 15;
        baseScore -= ineffectiveDistractors * 2;
        baseScore -= reversedDistractors * 5;
        
        return Math.max(0, Math.min(20, baseScore + 5));
    }
    
    private double scoreDIF(List<DIFResult> difResults) {
        double maxPenalty = difResults.stream()
            .mapToDouble(dif -> {
                switch (dif.getClassification()) {
                    case A: return 0;
                    case B: return 3;
                    case C: return 8;
                    default: return 0;
                }
            })
            .max()
            .orElse(0);
        
        return Math.max(0, 15 - maxPenalty);
    }
}
```

```java
@Service
public class PsychometricCalculationOrchestrator {
    
    /**
     * 执行完整的质量计算流程
     */
    @Transactional
    public void executeCalculation(String batchId) {
        QualityCalculationTask task = taskRepository.findByBatchId(batchId);
        
        try {
            // 1. 数据采样
            task.updateStatus(Status.SAMPLING);
            taskRepository.save(task);
            
            List<QuestionResponse> responses = dataSampler.sample(task.getSampleQuery());
            
            if (responses.size() < task.getMinSampleSize()) {
                task.fail("样本量不足: " + responses.size() + " < " + task.getMinSampleSize());
                taskRepository.save(task);
                notifyCallback(task, "FAILED", "INSUFFICIENT_SAMPLE");
                return;
            }
            
            // 2. 数据清洗
            List<QuestionResponse> cleanedData = dataCleaner.clean(responses, 
                task.getCalculationOptions());
            
            // 3. 并行计算各指标
            task.updateStatus(Status.CALCULATING);
            taskRepository.save(task);
            
            CompletableFuture<CTTResult> cttFuture = CompletableFuture.supplyAsync(
                () -> cttEngine.calculate(cleanedData, task.getQuestionScore()));
            
            CompletableFuture<IRTResult> irtFuture = CompletableFuture.supplyAsync(
                () -> irtEngine.estimate3PL(
                    buildResponseMatrix(cleanedData), 
                    cleanedData.size(), 1));
            
            CompletableFuture<List<DistractorAnalysisResult>> distractorFuture = 
                CompletableFuture.supplyAsync(
                    () -> distractorEngine.analyze(cleanedData, 
                        task.getOptionCorrectMap(), task.getQuestionScore()));
            
            CompletableFuture<List<DIFResult>> difFuture = CompletableFuture.supplyAsync(
                () -> {
                    if (!task.getCalculationOptions().isCalculateDIF()) {
                        return Collections.emptyList();
                    }
                    return calculateAllDIF(cleanedData, task);
                });
            
            // 等待所有计算完成
            CompletableFuture.allOf(cttFuture, irtFuture, distractorFuture, difFuture).join();
            
            CTTResult ctt = cttFuture.get();
            IRTResult irt = irtFuture.get();
            List<DistractorAnalysisResult> distractors = distractorFuture.get();
            List<DIFResult> difResults = difFuture.get();
            
            // 4. 计算综合质量评分
            QualityScore qualityScore = scoringEngine.calculateQuestionScore(
                ctt, irt, distractors, difResults);
            
            // 5. 持久化结果
            saveResults(task, ctt, irt, distractors, difResults, qualityScore);
            
            // 6. 更新任务状态
            task.complete(Map.of(
                "cttP", ctt.getDifficultyP(),
                "cttD", ctt.getDiscriminationD(),
                "qualityScore", qualityScore.getScore(),
                "qualityGrade", qualityScore.getGrade().name()
            ));
            taskRepository.save(task);
            
            // 7. 触发后续动作
            eventPublisher.publishEvent(new QualityCalculationCompletedEvent(task, qualityScore));
            
            // 8. 回调通知
            notifyCallback(task, "COMPLETED", qualityScore);
            
        } catch (Exception e) {
            log.error("Quality calculation failed for batch {}", batchId, e);
            task.fail(e.getMessage());
            taskRepository.save(task);
            notifyCallback(task, "FAILED", e.getMessage());
        }
    }
    
    private List<DIFResult> calculateAllDIF(List<QuestionResponse> responses, 
                                             QualityCalculationTask task) {
        List<DIFResult> results = new ArrayList<>();
        
        for (String groupingVar : task.getCalculationOptions().getDifGroupingVariables()) {
            Map<Long, Integer> groupAssignments = buildGroupAssignments(responses, groupingVar);
            DIFResult dif = difEngine.calculateMH(
                convertToDIFData(responses), groupAssignments, 
                task.getCalculationOptions().getScoreBandCount());
            
            DIFResult enriched = dif.toBuilder()
                .groupingVariable(groupingVar)
                .build();
            results.add(enriched);
        }
        
        return results;
    }
}
```

```java
@Service
public class PsychometricDataSampler {
    
    /**
     * 科学采样：确保样本代表性和充足性
     */
    public List<QuestionResponse> sample(SampleQuery conditions) {
        // 1. 基础过滤
        SqlQueryBuilder queryBuilder = new SqlQueryBuilder()
            .select("student_id", "question_id", "earned_score", "total_score", 
                    "selected_option", "duration_seconds", "created_at")
            .from("answer_record")
            .where("question_id", conditions.getQuestionId())
            .where("created_at", ">=", conditions.getStartDate())
            .where("created_at", "<", conditions.getEndDate())
            .where("is_practice", true); // 排除测试数据
        
        // 2. 排除重考（取首次作答）
        if (conditions.isExcludeRetake()) {
            queryBuilder.where("attempt_number", 1);
        }
        
        // 3. 排除异常作答时长
        if (conditions.isExcludeAbnormalDuration()) {
            queryBuilder.where("duration_seconds", ">=", conditions.getMinDurationSeconds());
            queryBuilder.where("duration_seconds", "<=", conditions.getMaxDurationSeconds());
        }
        
        // 4. 排除抄袭嫌疑
        queryBuilder.where("cheating_flag", false);
        
        List<QuestionResponse> allData = queryBuilder.execute();
        
        // 5. 分层抽样（如果样本量过大，按学段/地区分层抽样）
        if (allData.size() > MAX_SAMPLE_SIZE) {
            allData = stratifiedSample(allData, MAX_SAMPLE_SIZE);
        }
        
        return allData;
    }
    
    private List<QuestionResponse> stratifiedSample(
            List<QuestionResponse> data, int targetSize) {
        // 按地区分层
        Map<String, List<QuestionResponse>> strata = data.stream()
            .collect(Collectors.groupingBy(QuestionResponse::getRegion));
        
        List<QuestionResponse> sampled = new ArrayList<>();
        int totalPopulation = data.size();
        
        for (List<QuestionResponse> stratum : strata.values()) {
            // 按比例分配样本
            int stratumSize = (int) Math.round(
                (double) stratum.size() / totalPopulation * targetSize);
            Collections.shuffle(stratum, new Random(42)); // 固定种子保证可复现
            sampled.addAll(stratum.subList(0, Math.min(stratumSize, stratum.size())));
        }
        
        return sampled;
    }
}
```

```java
@Service
public class PsychometricDataCleaner {
    
    public List<QuestionResponse> clean(List<QuestionResponse> rawData, 
                                         CalculationOptions options) {
        List<QuestionResponse> cleaned = new ArrayList<>(rawData);
        
        // 1. 剔除全对或全错（方差为0）的无效记录
        cleaned = removeZeroVarianceRecords(cleaned);
        
        // 2. 剔除总分异常值（使用IQR方法）
        cleaned = removeOutliers(cleaned, options.getOutlierHandling(), 
            options.getIqrMultiplier());
        
        // 3. 剔除规律性作答（如全选C）
        cleaned = removePattern responders(cleaned);
        
        // 4. 剔除作答时间异常短（< 2秒）或异常长（> 30分钟）
        cleaned = cleaned.stream()
            .filter(r -> r.getDurationSeconds() >= 2 && r.getDurationSeconds() <= 1800)
            .collect(Collectors.toList());
        
        // 5. 确保每个学生只有一条记录
        cleaned = deduplicateByStudent(cleaned);
        
        return cleaned;
    }
    
    private List<QuestionResponse> removeOutliers(List<QuestionResponse> data, 
                                                    String method, double multiplier) {
        if (!"IQR".equals(method)) return data;
        
        double[] totalScores = data.stream()
            .mapToDouble(QuestionResponse::getTotalScore)
            .sorted()
            .toArray();
        
        double q1 = percentile(totalScores, 25);
        double q3 = percentile(totalScores, 75);
        double iqr = q3 - q1;
        double lowerBound = q1 - multiplier * iqr;
        double upperBound = q3 + multiplier * iqr;
        
        return data.stream()
            .filter(r -> r.getTotalScore() >= lowerBound && r.getTotalScore() <= upperBound)
            .collect(Collectors.toList());
    }
}
```

## 9. 错误处理与降级策略

### 9.1 错误码定义

| 错误码 | 含义 | 处理建议 |
|--------|------|----------|
| PSY_4001 | 样本量不足（< 30） | 等待更多作答数据后重新触发 |
| PSY_4002 | 样本量不足（< 200，IRT计算） | IRT计算跳过，仅输出CTT指标 |
| PSY_4003 | 数据方差为零 | 检查题目或采样是否存在异常 |
| PSY_4004 | IRT参数估计未收敛 | 尝试2PL模型或增加迭代次数 |
| PSY_4005 | IRT猜测参数超出范围 | 固定c=0，使用2PL模型 |
| PSY_4006 | DIF分析参照组/焦点组样本不均衡 | 确保两组各有至少100人 |
| PSY_4007 | 计算超时 | 降级为仅CTT计算 |
| PSY_5001 | 数据库查询超时 | 重试或缩小采样范围 |
| PSY_5002 | 内存溢出 | 减小样本量或分批计算 |

### 9.2 降级策略

```java
@Service
public class PsychometricFallbackHandler {
    
    public QualityResult calculateWithFallback(List<QuestionResponse> data, 
                                                CalculationOptions options) {
        try {
            // 尝试完整计算
            return fullCalculation(data, options);
            
        } catch (IRTConvergenceException e) {
            log.warn("IRT 3PL not converged, falling back to 2PL");
            // 降级1: 3PL → 2PL
            options.setIrtModel("2PL");
            try {
                return fullCalculation(data, options);
            } catch (Exception e2) {
                log.warn("IRT 2PL also failed, falling back to CTT only");
                // 降级2: 跳过IRT，仅CTT
                return cttOnlyCalculation(data, options);
            }
            
        } catch (InsufficientSampleException e) {
            log.warn("Insufficient sample for full calculation: {}", e.getMessage());
            // 降级3: 仅CTT基础指标
            if (data.size() >= 30) {
                return cttOnlyCalculation(data, options);
            } else {
                return QualityResult.insufficient(data.size());
            }
            
        } catch (CalculationTimeoutException e) {
            log.warn("Calculation timeout, returning partial results");
            // 降级4: 返回部分结果
            return partialResult(data, e.getCompletedSteps());
        }
    }
}
```

### 13.1 事件驱动集成

```java
// 事件定义
public class QualityCalculationCompletedEvent {
    private Long questionId;
    private String batchId;
    private QualityScore qualityScore;
    private List<String> alerts;
}

// 消费者：题库生命周期管理
@EventListener
public void onQualityCalculated(QualityCalculationCompletedEvent event) {
    // F级题目自动标记为待修订
    if (event.getQualityScore().getGrade() == OverallQualityGrade.F) {
        questionLifecycleService.markForRevision(event.getQuestionId(), 
            "自动标记: 质量评分F级(" + event.getQualityScore().getScore() + ")");
    }
    
    // C级DIF题目自动标记
    if (event.getAlerts() != null) {
        for (String alert : event.getAlerts()) {
            if (alert.contains("C级DIF")) {
                questionLifecycleService.flagForDIFReview(event.getQuestionId(), alert);
            }
        }
    }
}

// 消费者：智能组卷引擎
@EventListener
public void onQualityCalculated(QualityCalculationCompletedEvent event) {
    // 更新题库选题过滤条件
    assemblyEngine.updateQuestionQualityCache(
        event.getQuestionId(), 
        event.getQualityScore().getGrade());
}
```

### 16.1 教育测量学指标参考标准

| 指标 | 优秀 | 良好 | 可接受 | 差 |
|------|------|------|--------|-----|
