## 1. 概述

### 1.1 功能定位

本引擎负责在学生学习过程中**实时检测心流状态（Flow State）**，并根据心流状态动态优化学习体验参数，包括内容难度调节、通知抑制、会话节奏控制、环境适配等，以最大化学生进入并维持深度沉浸学习状态的概率。

### 1.2 心流理论背景

心流（Flow）由心理学家 Mihaly Csikszentmihalyi 提出，指个体完全投入当前活动时的一种最佳体验状态，具有以下特征：

| 特征维度 | 说明 | 平台可观测信号 |
| --- | --- | --- |
| 注意力高度集中 | 对当前任务全神贯注 | 操作连续性高、无切换行为 |
| 技能与挑战平衡 | 任务难度恰好匹配能力水平 | 答题正确率在 60%-85% 区间 |
| 目标清晰 | 明确知道下一步要做什么 | 任务完成→自动衔接下一任务 |
| 即时反馈 | 每一步都有明确的进展反馈 | 快速答题、连续提交行为 |
| 自我意识消失 | 忘记时间流逝 | 会话时长显著超出平均 |
| 控制感 | 感觉能掌控学习进程 | 主动操作（非被动浏览）占比高 |

### 1.3 与现有模块的边界

| 现有模块 | 关注点 | 本引擎差异 |
| --- | --- | --- |
| 学生学习注意力实时监测引擎 | 检测注意力分散并恢复 | 心流是比"注意力集中"更深层的状态，需技能-挑战平衡、目标清晰等多维条件 |
| 学生学习会话疲劳度监测引擎 | 检测疲劳并触发休息 | 疲劳是负面信号；心流是正面最优状态，两者需平衡 |
| 学生认知负荷监测引擎 | 评估负荷是否过载 | 认知负荷是心流的输入维度之一（负荷过高→焦虑，过低→无聊） |
| 练习答题实时自适应难度调节引擎 | 调节题目难度 | 本引擎向难度调节引擎提供心流状态作为调控信号 |
| 统一学习干预编排与智能频控引擎 | 统一干预频控 | 本引擎向其提供"心流保护"级别的干预抑制信号 |

### 1.4 设计目标

1. **实时检测**：在 3 秒滑动窗口内输出心流概率分数（0.0~1.0）
2. **低延迟**：心流评分计算延迟 < 500ms
3. **隐私安全**：仅使用行为信号，不采集摄像头/生物特征数据
4. **可解释**：心流评分附带因子贡献分解，便于下游决策
5. **自适应**：模型参数按学生个体基线自动校准
6. **可干预**：输出结构化干预建议，支持下游模块执行

### 3.2 多通道信号提取

#### 3.2.1 操作频率通道 (Action Rate Channel)

```python
class ActionRateChannel:
    """
    计算近30秒滑动窗口内的用户操作频率
    操作定义: 答题提交、内容翻页、按钮点击、文本输入、语音提交
    排除: 纯滚动、鼠标移动（噪声过大）
    """
    WINDOW_SECONDS = 30
    
    def extract(self, event_stream: list, baseline_rate: float) -> float:
        """
        返回操作频率的标准化得分 [0, 1]
        :param event_stream: 近30秒事件流
        :param baseline_rate: 该学生基线操作频率
        :return: action_rate_score
        """
        now = time.time()
        recent = [e for e in event_stream if now - e.timestamp <= self.WINDOW_SECONDS]
        
        action_types = {
            'ANSWER_SUBMIT', 'PAGE_NEXT', 'PAGE_PREV', 
            'BUTTON_CLICK', 'TEXT_INPUT_COMPLETE', 'VOICE_SUBMIT',
            'CONTENT_INTERACT', 'HINT_REQUEST', 'BOOKMARK_ADD'
        }
        
        actions = [e for e in recent if e.event_type in action_types]
        rate_per_min = len(actions) / (self.WINDOW_SECONDS / 60)
        
        # 与基线比较，标准化为 [0, 1]
        # 操作频率高于基线 → 可能高度投入
        # 操作频率低于基线 → 可能走神或无聊
        if baseline_rate <= 0:
            return 0.5
            
        ratio = rate_per_min / baseline_rate
        
        # 使用钟形映射：最优点在 ratio ≈ 1.3 (略高于基线)
        # 过低(< 0.5) → 低投入; 过高(> 3.0) → 可能盲目点击
        score = self._bell_curve(ratio, optimal=1.3, width=0.8)
        return max(0.0, min(1.0, score))
    
    @staticmethod
    def _bell_curve(x: float, optimal: float, width: float) -> float:
        """高斯钟形曲线映射"""
        return math.exp(-((x - optimal) ** 2) / (2 * width ** 2))
```

#### 3.2.2 技能-挑战平衡通道 (Skill-Challenge Balance Channel)

```python
class SkillChallengeChannel:
    """
    基于心流理论核心：技能与挑战的平衡
    挑战水平由题目难度和内容复杂度推断
    技能水平由学生该知识点掌握度和历史正确率推断
    """
    
    def extract(
        self,
        content_difficulty: float,   # 0-1, 当前内容难度
        student_mastery: float,       # 0-1, 学生知识点掌握度
        recent_correct_rate: float,   # 0-1, 近5题正确率
        target_zone_min: float = 0.6, # 心流区正确率下限
        target_zone_max: float = 0.85 # 心流区正确率上限
    ) -> tuple[float, str]:
        """
        返回 (balance_score, quadrant)
        quadrant: FLOW/BOREDOM/ANXIETY/APATHY
        """
        challenge = content_difficulty  # 0-1
        skill = max(student_mastery, recent_correct_rate)  # 取较高值避免低估
        
        # 技挑差值
        diff = skill - challenge
        
        # 判断象限
        if challenge > 0.5 and skill > 0.5:
            if abs(diff) < 0.15:
                quadrant = 'FLOW'
                score = 1.0 - abs(diff) / 0.15
            elif diff > 0:
                quadrant = 'BOREDOM'  # 技能高于挑战
                score = max(0, 1.0 - diff)
            else:
                quadrant = 'ANXIETY'  # 挑战高于技能
                score = max(0, 1.0 + diff)
        elif challenge < 0.5 and skill < 0.5:
            quadrant = 'APATHY'
            score = 0.2  # 低技能低挑战，冷淡区
        elif challenge >= 0.5 and skill < 0.5:
            quadrant = 'ANXIETY'
            score = max(0, skill / challenge * 0.5)
        else:  # challenge < 0.5 and skill >= 0.5
            quadrant = 'BOREDOM'
            score = max(0, challenge / skill * 0.5)
        
        # 正确率修正：如果正确率在心流区(60%-85%)，加分
        if target_zone_min <= recent_correct_rate <= target_zone_max:
            score = min(1.0, score * 1.2)
        
        return score, quadrant
```

#### 3.2.3 行为连续性通道 (Behavioral Continuity Channel)

```python
class BehavioralContinuityChannel:
    """
    检测行为连续性：无中断、无切换、无犹豫的高连续性操作
    """
    
    def extract(
        self,
        event_stream: list,
        window_seconds: int = 300  # 5分钟窗口
    ) -> float:
        """
        返回连续性得分 [0, 1]
        """
        now = time.time()
        recent = [e for e in event_stream if now - e.timestamp <= window_seconds]
        
        if len(recent) < 3:
            return 0.3  # 数据不足，给保守分
        
        # 指标1: 页面切换次数 (越少越好)
        page_switches = sum(1 for e in recent if e.event_type == 'PAGE_SWITCH')
        switch_penalty = min(1.0, page_switches / 5.0)  # 5次切换扣满
        continuity_from_switch = 1.0 - switch_penalty
        
        # 指标2: 无操作停顿次数 (停顿>20秒视为断连续)
        gaps = self._count_gaps(recent, threshold_sec=20)
        gap_penalty = min(1.0, gaps / 3.0)  # 3次停顿扣满
        continuity_from_gap = 1.0 - gap_penalty
        
        # 指标3: 主动操作占比 (非系统触发的操作)
        user_initiated = sum(1 for e in recent if not e.is_system_triggered)
        total = len(recent)
        proactive_ratio = user_initiated / total if total > 0 else 0
        
        # 指标4: 回看/修改频率 (适度回看正常，过多表示犹豫)
        back_tracks = sum(1 for e in recent if e.event_type in {'ANSWER_CHANGE', 'PAGE_PREV', 'ERASE'})
        back_penalty = min(1.0, back_tracks / 8.0)
        continuity_from_backtrack = 1.0 - back_penalty
        
        # 加权融合
        score = (
            continuity_from_switch * 0.35 +
            continuity_from_gap * 0.25 +
            proactive_ratio * 0.20 +
            continuity_from_backtrack * 0.20
        )
        
        return max(0.0, min(1.0, score))
    
    @staticmethod
    def _count_gaps(events: list, threshold_sec: float) -> int:
        gaps = 0
        for i in range(1, len(events)):
            delta = events[i].timestamp - events[i-1].timestamp
            if delta >= threshold_sec:
                gaps += 1
        return gaps
```

```python
    评估学生在当前学习会话中的"沉浸深度"
    会话越长且越专注，深度越高
    但超长会话反而可能意味着疲劳
    """
    
    def extract(
        self,
        minutes_into_session: int,
        action_density: float,      # 操作密度 (次/分钟)
        avg_session_length: int,    # 该学生平均会话时长(分钟)
        has_content_switch: bool    # 会话内是否切换过内容
    ) -> float:
        """
        返回会话深度得分 [0, 1]
        """
        # 会话深度模型：
        # - 0-5分钟: 热身阶段，深度较低
        # - 5-20分钟: 心流高发区，深度最高
        # - 20-40分钟: 深度维持区，但开始有疲劳风险
        # - 40+分钟: 疲劳区，深度下降
        
        if minutes_into_session < 5:
            time_factor = minutes_into_session / 5.0 * 0.6  # 线性上升
        elif minutes_into_session <= 20:
            time_factor = 0.6 + 0.4 * (minutes_into_session - 5) / 15.0  # 达到1.0
        elif minutes_into_session <= 40:
            time_factor = 1.0 - (minutes_into_session - 20) / 40.0 * 0.3  # 缓慢下降到0.85
        else:
            time_factor = max(0.3, 0.7 - (minutes_into_session - 40) / 60.0 * 0.4)  # 加速下降
        
        # 操作密度修正
        if action_density < 3:  # 操作太少
            time_factor *= 0.5
        
        # 内容切换惩罚
        if has_content_switch:
            time_factor *= 0.8
        
        return max(0.0, min(1.0, time_factor))
```

### 3.3 特征融合与心流评分

```python
class FlowScoreCalculator:
    """
    多通道特征融合，输出最终心流概率分数
    """
    
    # 默认权重 (可按学生个体校准)
    DEFAULT_WEIGHTS = {
        'action_rate': 0.20,
        'skill_challenge': 0.30,   # 心流理论核心维度，权重最高
        'continuity': 0.25,
        'session_depth': 0.15,
        'correct_rate_zone': 0.10,
    }
    
    def calculate(
        self,
        channels: dict,           # 各通道分数
        student_baseline: dict,    # 学生基线
        context: dict              # 上下文(时段、学科等)
    ) -> tuple[float, dict]:
        """
        返回 (flow_score, factor_breakdown)
        """
        weights = self._get_calibrated_weights(student_baseline)
        
        # 基础加权求和
        flow_score = sum(
            channels.get(ch, 0.5) * weights.get(ch, 0)
            for ch in weights
        )
        
        # 上下文修正
        flow_score = self._apply_context_adjustments(flow_score, context)
        
        # 规则约束
        flow_score = self._apply_rule_constraints(flow_score, channels, context)
        
        # 生成因子贡献分解
        factor_breakdown = {
            ch: {
                'score': round(channels.get(ch, 0.5), 4),
                'weight': weights.get(ch, 0),
                'contribution': round(channels.get(ch, 0.5) * weights.get(ch, 0), 4)
            }
            for ch in weights
        }
        factor_breakdown['_context_adjustment'] = round(
            flow_score - sum(factor_breakdown[ch]['contribution'] for ch in factor_breakdown), 4
        )
        
        return max(0.0, min(1.0, flow_score)), factor_breakdown
    
    def _get_calibrated_weights(self, baseline: dict) -> dict:
        """根据学生画像微调权重"""
        weights = dict(self.DEFAULT_WEIGHTS)
        
        # 低龄学生更依赖操作频率和连续性
        if baseline.get('age_group') == 'PRIMARY':
            weights['action_rate'] += 0.05
            weights['continuity'] += 0.05
            weights['skill_challenge'] -= 0.10
        
        # 高中生更依赖技挑平衡
        if baseline.get('age_group') == 'HIGH_SCHOOL':
            weights['skill_challenge'] += 0.05
            weights['session_depth'] -= 0.05
        
        return weights
    
    def _apply_context_adjustments(self, score: float, ctx: dict) -> float:
        """上下文修正"""
        # 深夜学习心流可信度降低 (可能是机械式操作)
        if ctx.get('time_of_day') == 'LATE_NIGHT':
            score *= 0.85
        
        # AI对话场景特殊处理：对话天然有间隔，不应惩罚响应慢
        if ctx.get('content_type') == 'AI_DIALOG':
            score *= 1.10  # 略加分因为AI对话场景信号弱
        
        # 考试模式：高压环境，心流判定标准更严格
        if ctx.get('content_type') == 'EXAM':
            score *= 0.90
        
        return score
    
    def _apply_rule_constraints(
        self, 
        score: float, 
        channels: dict, 
        ctx: dict
    ) -> float:
        """硬性规则约束"""
        
        # 规则1: 如果近5分钟完全没有操作 → 强制低分
        if channels.get('action_rate', 0) < 0.1:
            return min(score, 0.15)
        
        # 规则2: 如果正确率极低(<30%) → 可能在猜测，不是心流
        if channels.get('correct_rate_zone', 0.5) < 0.2:
            return min(score, 0.30)
        
        # 规则3: 如果频繁切换(>8次/5分钟) → 强制低分
        if channels.get('continuity', 1.0) < 0.15:
            return min(score, 0.25)
        
        # 规则4: 如果会话超过60分钟且操作频率下降 → 疲劳，降低心流分
        if (ctx.get('minutes_into_session', 0) > 60 and 
            channels.get('action_rate', 0.5) < 0.3):
            return min(score, 0.40)
        
        return score
```

```python
class FlowLevelMapper:
    """
    将连续心流分数映射到离散等级
    基于心流理论二维模型（技能×挑战）+ 行为信号修正
    """
    
    def map_to_level(
        self,
        flow_score: float,
        skill_challenge_quadrant: str,
        challenge: float,
        skill: float,
        threshold: float  # 个体校准阈值
    ) -> FlowLevel:
        """
        综合分数和象限信息确定心流等级
        """
        # 心流区：分数高 + 象限在FLOW
        if flow_score >= threshold and skill_challenge_quadrant == 'FLOW':
            return FlowLevel.FLOW
        
        # 唤醒区：分数较高，接近心流
        if flow_score >= threshold - 0.15:
            if skill_challenge_quadrant in ('FLOW',):
                return FlowLevel.AROUSAL
            elif skill_challenge_quadrant == 'BOREDOM' and challenge > 0.4:
                return FlowLevel.AROUSAL  # 中等挑战+高技能可能只是还没进入
        
        # 无聊区：技能远高于挑战
        if skill_challenge_quadrant == 'BOREDOM':
            return FlowLevel.BOREDOM
        
        # 焦虑区：挑战远高于技能
        if skill_challenge_quadrant == 'ANXIETY':
            if challenge > 0.85:
                return FlowLevel.OVERLOAD  # 极端高挑战
            return FlowLevel.ANXIETY
        
        # 冷淡区
        if skill_challenge_quadrant == 'APATHY':
            return FlowLevel.APATHY
        
        # 默认
        if flow_score >= 0.5:
            return FlowLevel.AROUSAL
        return FlowLevel.APATHY
```

### 3.5 心流事件检测状态机

```python
class FlowEventDetector:
    """
    基于状态机检测心流进入/退出/峰值/打断事件
    
    状态转换图:
    
    IDLE ──(score>=enter_threshold 持续T_enter秒)──> ENTERING
    ENTERING ──(维持score>=enter_threshold)──> IN_FLOW
    ENTERING ──(score<enter_threshold)──> IDLE
    IN_FLOW ──(score>=peak_threshold)──> PEAK_FLOW
    PEAK_FLOW ──(score<peak_threshold but>=enter_threshold)──> IN_FLOW
    IN_FLOW ──(score<exit_threshold 持续T_exit秒)──> EXITING
    IN_FLOW ──(外部打断事件)──> DISRUPTED
    EXITING ──(score>=enter_threshold)──> IN_FLOW (恢复)
    EXITING ──(持续T_exit秒)──> IDLE
    DISRUPTED ──(score>=enter_threshold)──> ENTERING
    DISRUPTED ──(10秒无恢复)──> IDLE
    """
    
    ENTER_THRESHOLD_DEFAULT = 0.70
    PEAK_THRESHOLD_DEFAULT = 0.85
    EXIT_THRESHOLD_DEFAULT = 0.45
    T_ENTER_SECONDS = 10   # 持续10秒高分才确认进入心流
    T_EXIT_SECONDS = 15    # 持续15秒低分才确认退出心流
    RECOVERY_WINDOW = 10   # 打断后10秒内恢复算"心流恢复"
    
    def __init__(self, student_id: int, baseline: dict):
        self.student_id = student_id
        self.state = 'IDLE'
        self.state_since = time.time()
        self.enter_threshold = baseline.get('flow_threshold', self.ENTER_THRESHOLD_DEFAULT)
        self.peak_threshold = self.enter_threshold + 0.15
        self.exit_threshold = self.EXIT_THRESHOLD_DEFAULT
        self.flow_enter_time = None
        self.peak_score = 0.0
        self.events = []
    
    def update(self, flow_score: float, external_events: list) -> list:
        """
        每次新的心流评分到达时调用
        返回本次更新触发的事件列表
        """
        now = time.time()
        elapsed = now - self.state_since
        new_events = []
        
        # 检查外部打断
        disruptions = [e for e in external_events if self._is_disrupting(e)]
        
        if self.state == 'IDLE':
            if flow_score >= self.enter_threshold:
                self._transition('ENTERING')
        
        elif self.state == 'ENTERING':
            if flow_score >= self.enter_threshold and elapsed >= self.T_ENTER_SECONDS:
                self._transition('IN_FLOW')
                self.flow_enter_time = now
                new_events.append(self._make_event('FLOW_ENTER', flow_score))
            elif flow_score < self.enter_threshold:
                self._transition('IDLE')
        
        elif self.state == 'IN_FLOW':
            # 检查打断
            if disruptions:
                self._transition('DISRUPTED')
                new_events.append(self._make_event(
                    'FLOW_DISRUPTED', flow_score,
                    disrupt_source=disruptions[0].source
                ))
            elif flow_score >= self.peak_threshold and flow_score > self.peak_score:
                self.peak_score = flow_score
                new_events.append(self._make_event('FLOW_PEAK', flow_score))
            elif flow_score < self.exit_threshold:
                self._transition('EXITING')
        
        elif self.state == 'PEAK_FLOW':
            if disruptions:
                self._transition('DISRUPTED')
                new_events.append(self._make_event(
                    'FLOW_DISRUPTED', flow_score,
                    disrupt_source=disruptions[0].source
                ))
            elif flow_score < self.exit_threshold:
                self._transition('EXITING')
        
        elif self.state == 'EXITING':
            if flow_score >= self.enter_threshold:
                # 恢复
                self._transition('IN_FLOW')
                new_events.append(self._make_event('FLOW_RECOVERED', flow_score))
            elif elapsed >= self.T_EXIT_SECONDS:
                duration_ms = int((now - self.flow_enter_time) * 1000) if self.flow_enter_time else 0
                new_events.append(self._make_event(
                    'FLOW_EXIT', flow_score,
                    flow_duration_ms=duration_ms
                ))
                self._transition('IDLE')
                self.flow_enter_time = None
                self.peak_score = 0.0
        
        elif self.state == 'DISRUPTED':
            if flow_score >= self.enter_threshold:
                self._transition('IN_FLOW')
                new_events.append(self._make_event('FLOW_RECOVERED', flow_score))
            elif elapsed >= self.RECOVERY_WINDOW:
                duration_ms = int((now - self.flow_enter_time) * 1000) if self.flow_enter_time else 0
                new_events.append(self._make_event(
                    'FLOW_EXIT', flow_score,
                    flow_duration_ms=duration_ms
                ))
                self._transition('IDLE')
                self.flow_enter_time = None
                self.peak_score = 0.0
        
        self.events.extend(new_events)
        return new_events
    
    def _transition(self, new_state: str):
        self.state = new_state
        self.state_since = time.time()
    
    def _is_disrupting(self, event) -> bool:
        """判断外部事件是否足以打断心流"""
        disrupting_types = {
            'FULL_SCREEN_POPUP', 'FORCE_REDIRECT', 
            'NOTIFICATION_BANNER_PERSISTENT', 'PAGE_SWITCH_FORCED'
        }
        return event.event_type in disrupting_types
    
    def _make_event(self, event_type: str, score: float, **kwargs) -> dict:
        return {
            'event_type': event_type,
            'flow_score': score,
            'timestamp': time.time(),
            'state_duration': time.time() - self.state_since,
            **kwargs
        }
```

### 5.1 心流保护级别与动作矩阵

### 5.2 心流优化决策器

```python
class FlowOptimizationDecisioner:
    """
    根据当前心流状态输出体验优化建议
    """
    
    def decide(
        self,
        flow_state: dict,
        student_baseline: dict,
        current_content: dict,
        upcoming_content: dict
    ) -> dict:
        """
        返回优化决策包
        """
        flow_score = flow_state['flow_score']
        flow_level = flow_state['flow_level']
        quadrant = flow_state.get('quadrant', '')
        
        decision = {
            'protection_level': 0,
            'content_difficulty_adjustment': 0.0,  # -0.1~+0.1 微调
            'notification_policy': 'NORMAL',
            'session_pacing': 'NORMAL',
            'auto_advance': False,
            'preload_next': False,
            'reasoning': ''
        }
        
        # ---- 心流保护 ----
        if flow_score >= 0.85 and flow_state.get('state') == 'IN_FLOW':
            decision['protection_level'] = 4
            decision['notification_policy'] = 'SUPPRESS_ALL'
            decision['auto_advance'] = True
            decision['preload_next'] = True
            decision['reasoning'] = '学生处于心流峰值，最大化保护'
        
        elif flow_score >= 0.70:
            decision['protection_level'] = 3
            decision['notification_policy'] = 'SUPPRESS_ALL'
            decision['auto_advance'] = True
            decision['reasoning'] = '学生处于心流状态，抑制干扰'
        
        elif flow_score >= 0.60:
            decision['protection_level'] = 2
            decision['notification_policy'] = 'DELAY_30S'
            decision['reasoning'] = '学生接近心流，减少干扰'
        
        # ---- 内容难度调节 ----
        if quadrant == 'BOREDOM':
            # 无聊：技能>挑战，适当提升难度
            difficulty_delta = self._calc_difficulty_adjustment(
                current_difficulty=current_content.get('difficulty', 0.5),
                student_mastery=flow_state.get('skill_level', 0.7),
                direction='UP'
            )
            decision['content_difficulty_adjustment'] = difficulty_delta
            decision['reasoning'] += f'; 检测到无聊状态，建议提升难度+{difficulty_delta:.2f}'
        
        elif quadrant == 'ANXIETY':
            # 焦虑：技能<挑战，适当降低难度或给提示
            difficulty_delta = self._calc_difficulty_adjustment(
                current_difficulty=current_content.get('difficulty', 0.5),
                student_mastery=flow_state.get('skill_level', 0.3),
                direction='DOWN'
            )
            decision['content_difficulty_adjustment'] = difficulty_delta
            decision['reasoning'] += f'; 检测到焦虑状态，建议降低难度{difficulty_delta:.2f}'
        
        elif quadrant == 'APATHY':
            # 冷淡：低技能低挑战，需要切换到更适合的内容
            decision['session_pacing'] = 'SUGGEST_BREAK_OR_SWITCH'
            decision['reasoning'] += '; 检测到冷淡状态，建议休息或切换内容类型'
        
        # ---- 会话节奏 ----
        minutes = flow_state.get('minutes_into_session', 0)
        if minutes > 45 and flow_score < 0.4:
            decision['session_pacing'] = 'SUGGEST_BREAK'
            decision['protection_level'] = 0
            decision['reasoning'] += f'; 会话已{minutes}分钟且心流低，建议休息'
        
        return decision
    
    @staticmethod
    def _calc_difficulty_adjustment(
        current_difficulty: float,
        student_mastery: float,
        direction: str,
        max_delta: float = 0.15
    ) -> float:
        """计算难度调整量"""
        gap = abs(student_mastery - current_difficulty)
        delta = min(max_delta, gap * 0.3)  # 调整幅度为差距的30%
        return delta if direction == 'UP' else -delta
```

```python
class FlowBaselineCalibrator:
    """
    定期校准学生心流基线参数
    触发条件：每天凌晨 / 累计新样本>200条 / 检测到基线漂移
    """
    
    SAMPLE_THRESHOLD = 200       # 新样本阈值
    CALIBRATION_WINDOW_DAYS = 7  # 使用近7天数据校准
    DRIFT_THRESHOLD = 0.15       # 基线漂移检测阈值
    
    async def calibrate(self, student_id: int) -> dict:
        """
        执行一次基线校准
        """
        # 1. 获取近7天的心流记录和事件
        records = await self._fetch_recent_records(student_id, self.CALIBRATION_WINDOW_DAYS)
        events = await self._fetch_recent_events(student_id, self.CALIBRATION_WINDOW_DAYS)
        
        if len(records) < 50:
            return {'status': 'INSUFFICIENT_DATA', 'samples': len(records)}
        
        # 2. 更新行为基线
        new_baselines = {
            'baseline_action_rate': statistics.median(r.action_rate for r in records),
            'baseline_response_ms': int(statistics.median(r.avg_response_ms for r in records)),
            'baseline_correct_rate': statistics.median(r.correct_rate for r in records),
            'baseline_flow_prob': statistics.mean(1 if r.flow_level == 5 else 0 for r in records),
        }
        
        # 3. 更新心流画像
        flow_records = [r for r in records if r.flow_level == 5]
        flow_episodes = self._group_into_episodes(events)
        
        if flow_episodes:
            durations = [ep['duration_min'] for ep in flow_episodes]
            new_baselines['peak_flow_duration_min'] = max(durations)
            new_baselines['avg_flow_duration_min'] = statistics.mean(durations)
            new_baselines['flow_frequency_weekly'] = len(flow_episodes)
            new_baselines['best_flow_time_slot'] = self._find_best_time_slot(flow_episodes)
            new_baselines['best_flow_subjects'] = self._find_best_subjects(flow_records)
        
        # 4. 校准心流阈值
        # 使用正确率分布找到该学生的"心流正确率区间"
        flow_correct_rates = [r.correct_rate for r in flow_records if r.correct_rate > 0]
        if len(flow_correct_rates) >= 10:
            # 心流时正确率的中位数通常在 70-80%
            flow_median = statistics.median(flow_correct_rates)
            non_flow = [r.correct_rate for r in records if r.flow_level < 5 and r.correct_rate > 0]
            non_flow_median = statistics.median(non_flow) if non_flow else 50
            
            # 阈值校准：心流和非心流正确率差异越大，阈值越高
            threshold_delta = (flow_median - non_flow_median) / 100.0
            new_threshold = max(0.55, min(0.85, 0.65 + threshold_delta * 0.5))
            new_baselines['flow_threshold'] = round(new_threshold, 4)
        
        # 5. 校准技挑比
        flow_ratios = []
        for r in flow_records:
            if r.skill_level > 0 and r.challenge_level > 0:
                flow_ratios.append(r.skill_level / r.challenge_level)
        if flow_ratios:
            new_baselines['challenge_skill_ratio'] = round(statistics.median(flow_ratios), 2)
        
        # 6. 写入
        new_baselines['last_calibrated_at'] = datetime.now()
        new_baselines['sample_count'] = len(records)
        
        await self._update_baseline(student_id, new_baselines)
        
        return {
            'status': 'CALIBRATED',
            'samples': len(records),
            'changes': new_baselines
        }
```

```python
class FlowConsistencyManager:

    # 对账任务：每小时运行一次
    async def reconcile(self):
        """

        active_students = await self._get_active_students(sample_size=100)

                    redis_state['last_event_ts'] - 
                    db_record.created_at.timestamp()

                    logger.warning(f'Flow state inconsistency for student {student_id}, refreshed')
    
    # 心流事件精确一次处理保障
    async def ensure_exactly_once(self, event: dict):
        """使用幂等键保障事件处理精确一次"""
        idempotency_key = f"{event['session_id']}:{event['timestamp']}"
        
        # 检查是否已处理
        exists = await self._redis.set(
            f'flow:processed:{idempotency_key}',
            '1', ex=3600, nx=True
        )
        
        if not exists:
            logger.debug(f'Duplicate event skipped: {idempotency_key}')
            return False  # 已处理过
        
        return True  # 可以处理
```

```python
# 2. 基线缓存策略
class BaselineCache:
    """
    两级缓存: L1=进程内LRU(5分钟TTL), L2=Redis(1小时TTL)
    """
    L1_CACHE = LRUCache(maxsize=10000)  # 进程内缓存
    L1_TTL = 300  # 5分钟
    L2_TTL = 3600  # 1小时
    
    async def get(self, student_id: int) -> dict:
        # L1
        cached = self.L1_CACHE.get(student_id)
        if cached and time.time() - cached['_ts'] < self.L1_TTL:
            return cached
        
        # L2
        redis_data = await self.redis.get(f'flow:baseline:{student_id}')
        if redis_data:
            data = json.loads(redis_data)
            data['_ts'] = time.time()
            self.L1_CACHE.set(student_id, data)
            return data
        
        # DB
        data = await self.db.fetch_one(
            'SELECT * FROM student_flow_baseline WHERE student_id = %s',
            [student_id]
        )
        if data:
            data['_ts'] = time.time()
            self.L1_CACHE.set(student_id, data)
            await self.redis.setex(
                f'flow:baseline:{student_id}',
                self.L2_TTL, json.dumps(data, default=str)
            )
        return data

# 3. 窗口计算优化：使用增量计算而非全量重算
class IncrementalWindowCalculator:
    """
    滑动窗口的增量计算
    新事件到来时只更新增量，不全量重算
    """
    def __init__(self, window_sec: int = 30):
        self.window_sec = window_sec
        self.events = deque()  # 时间有序队列
        self.metrics = {
            'action_count': 0,
            'correct_count': 0,
            'total_answered': 0,
            'response_times': deque(maxlen=20),
        }
    
    def add_event(self, event):
        """添加事件并淘汰过期数据"""
        now = time.time()
        
        # 淘汰过期
        while self.events and self.events[0].timestamp < now - self.window_sec:
            old = self.events.popleft()
            self._decrement_metrics(old)
        
        # 添加新事件
        self.events.append(event)
        self._increment_metrics(event)
    
    def get_metrics(self) -> dict:
        """获取当前窗口指标"""
        return {
            'action_rate': self.metrics['action_count'] / (self.window_sec / 60),
            'correct_rate': self.metrics['correct_count'] / max(1, self.metrics['total_answered']),
            'avg_response_ms': statistics.mean(self.metrics['response_times']) if self.metrics['response_times'] else 30000,
            'event_count': len(self.events),
        }
```
