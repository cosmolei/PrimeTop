## 1. 概述

### 1.1 功能定位

解题步骤分步动画展示与推导过程可视化引擎（Step-by-Step Solution Animation Engine，简称 SAE）是 PrimeTop 客户端的核心教学展示组件。它负责将 AI 生成的或预置的解题过程，按照**教学合理的节奏**拆分为独立的视觉步骤，配合动画效果逐步呈现，让学生的认知过程与解题推导过程同步。

与现有模块的定位区分：

| 模块 | 关注点 | 与 SAE 的关系 |
|------|--------|---------------|
| Markdown 流式渲染引擎 | 文本 token 级流式渲染 | SAE 的底层文本渲染能力提供者 |
| 题目展示与答题交互组件库 | 题目内容展示与答案收集 | SAE 不负责题目展示，只负责解析过程 |
| 答案管控与渐进式提示引擎 | 答案分级策略与解锁控制 | ACPH 决定"何时展示哪一步"，SAE 决定"如何动效呈现每一步" |
| AI 教育辅导策略引擎 | 教学策略决策（启发/讲解/评估） | PSE 决定教学方式，SAE 负责视觉执行 |
| 富文本与学科内容渲染引擎 | 通用学科内容 Widget 库 | SAE 的基础渲染能力提供者 |

**一句话定位**：ACPH 是"策略层"（决定展示什么），SAE 是"表现层"（决定如何用动画和节奏呈现），Markdown/富文本引擎是"渲染层"（负责像素级绘制）。

### 1.2 设计动机

原始设计文档多处强调分步展示的重要性：

- §6.2.2："分步提示：优先引导学生理解思路，再逐步展示答案"
- §6.3.2："解题步骤：输出分步解析、关键公式、易错点提醒"
- §6.11.2："分步推导：展示推理过程、公式来源和变形过程"
- §9.1："引导理解：AI 回答应采用提示、思路、步骤、总结、练习的结构"
- §9.4：AI 回答采用"分段卡片式结构"，提供"再讲简单点""生成同类题"等快捷操作
- §9.5："解答过程采用渐进式展示，可先给提示，再展开完整步骤"

当前 Markdown 流式渲染引擎实现了 token 级别的逐字显示，但无法满足以下教学需求：

1. **教学节奏控制**：不同复杂度的步骤需要不同的停留时间
2. **图形协调变化**：几何题中每一步推导需要在图上标注新的辅助线/角度
3. **公式高亮动画**：关键公式变形时需要高亮被变换的部分
4. **注意力引导**：通过箭头、圆圈、颜色等视觉手段引导学生关注重点
5. **交互式推进**：学生可以自主控制节奏（暂停/继续/重看/跳过）
6. **分步回放**：支持从任意步骤开始重新播放

### 1.3 设计目标

| 目标 | 说明 | 指标 |
|------|------|------|
| **教学节奏适配** | 根据步骤复杂度自动调整动画时长 | 简单步骤 0.8s，中等 1.5s，复杂 2.5s |
| **流畅动画** | 步骤切换动画 60fps | 低端设备不低于 45fps |
| **跨场景复用** | 同一引擎服务 AI 对话/拍题/练习/错题/考试 5+ 场景 | 统一 API |
| **分龄适配** | 不同学段的动画风格、速度、提示密度自动调整 | 4 档预设 |
| **可访问性** | 支持关闭动画的"简洁模式" | 一键切换 |
| **离线可用** | 动画资源不依赖网络 | 全本地计算 |

### 1.4 适用学段与场景

| 学段 | 动画风格 | 步骤粒度 | 交互特点 |
|------|----------|----------|----------|
| 幼儿 | 卡通化、大幅动画、配合音效 | 极细粒度（每步只做一个操作） | 点击触发下一步 |
| 小学 | 温和动画、配合鼓励文案 | 细粒度（每步一个知识点） | 点击或自动播放 |
| 初中 | 简洁动画、侧重公式推导 | 中粒度（每步一个小阶段） | 自动播放+暂停控制 |
| 高中 | 精练动画、侧重逻辑展示 | 粗粒度（每步一个推理阶段） | 快速播放+跳过 |

```dart
/// 解题方案：一个题目的完整解题过程
class Solution {
  /// 唯一标识
  final String solutionId;
  
  /// 关联的题目 ID
  final String questionId;
  
  /// 解题步骤列表（有序）
  final List<SolutionStep> steps;
  
  /// 解题总结
  final String? summary;
  
  /// 涉及知识点列表
  final List<String> knowledgePointIds;
  
  /// 解题方法标签
  final List<String> methodTags;
  
  /// 难度等级 (1-5)
  final int difficultyLevel;
  
  /// 来源（AI实时生成 / 题库预置 / 用户上传）
  final SolutionSource source;
  
  /// 元数据
  final SolutionMetadata metadata;
}

/// 单个解题步骤
class SolutionStep {
  /// 步骤序号（从1开始）
  final int stepIndex;
  
  /// 步骤类型
  final StepType type;
  
  /// 步骤标题（如"第一步：提取已知条件"）
  final String title;
  
  /// 步骤内容块列表
  final List<ContentBlock> blocks;
  
  /// 该步骤的提示/注解
  final String? annotation;
  
  /// 该步骤关联的图形操作（如有）
  final List<DiagramOperation>? diagramOps;
  
  /// 该步骤的关键高亮区域
  final List<HighlightTarget>? highlights;
  
  /// 步骤复杂度（影响动画时长）
  final StepComplexity complexity;
  
  /// 是否为关键步骤（需要用户确认才继续）
  final bool isKeyStep;
  
  /// 该步骤后的"你的 turn"提示（如有）
  final PromptAfterStep? userPrompt;
}

/// 步骤类型枚举
enum StepType {
  /// 条件提取：识别已知量和求解目标
  conditionExtract,
  /// 思路分析：分析解题方向
  approachAnalysis,
  /// 公式应用：代入公式计算
  formulaApply,
  /// 公式变形：等式变换、化简
  formulaTransform,
  /// 计算求解：具体数值计算
  calculate,
  /// 图形分析：结合图形推理
  diagramAnalysis,
  /// 结论推导：得出最终结果
  conclusion,
  /// 验证检查：验证结果正确性
  verification,
  /// 易错提醒：指出常见错误
  pitfallWarning,
  /// 方法总结：归纳通用方法
  methodSummary,
}

/// 内容块：一步内可包含多种内容
sealed class ContentBlock {}

class TextBlock extends ContentBlock {
  final String markdown;  // 支持 Markdown 格式
  final TextStyleOverride? style;
}

class FormulaBlock extends ContentBlock {
  final String latex;           // LaTeX 公式
  final FormulaRole role;       // 公式角色：关键/辅助/结果
}

  final DiagramType type;       // 图形类型
  final String? svgContent;     // SVG 内容

class TableBlock extends ContentBlock {
  final List<List<String>> headers;
  final List<List<String>> rows;

}

class CodeBlock extends ContentBlock {
  final String language;
  final String code;
}

class ComparisonBlock extends ContentBlock {
  final String leftLabel;
  final String leftContent;
  final String rightLabel;
  final String rightContent;
  final String? comparisonNote;
}
```

#### 4.2.2 Markdown 分隔格式（兼容模式）

当 AI 输出为 Markdown 文本时，使用分隔符进行步骤拆分：

```markdown
---STEP---
## 第一步：提取已知条件

从题目中我们可以得到以下已知条件：

$$a = 3, \quad b = 4, \quad \angle C = 90^{\circ}$$

---STEP---
## 第二步：确定解题方向

已知直角三角形的两条直角边，要求斜边长度，应该使用**勾股定理**。

---STEP---
## 第三步：代入勾股定理

$$c^2 = a^2 + b^2$$

$$c^2 = 3^2 + 4^2 = 9 + 16 = 25$$

---STEP---
## 第四步：得出结论

因此，斜边的长度为：

$$c = \sqrt{25} = 5$$
```

### 4.3 解析器实现

```dart
class StepSequenceParser {
  /// 解析 JSON 结构化输出
  static Solution parseFromJson(
    Map<String, dynamic> json,
    String questionId,
  ) {
    final solutionJson = json['solution'] as Map<String, dynamic>;
    final stepsJson = solutionJson['steps'] as List<dynamic>;
    
    return Solution(
      solutionId: 'sol_${questionId}_${DateTime.now().millisecondsSinceEpoch}',
      questionId: questionId,
      steps: stepsJson.map((s) => _parseStep(s as Map<String, dynamic>)).toList(),
      summary: solutionJson['summary'] as String?,
      knowledgePointIds: (solutionJson['knowledgePointIds'] as List<dynamic>?)
          ?.map((e) => e as String)
          .toList() ??
          [],
      methodTags: (solutionJson['methodTags'] as List<dynamic>?)
          ?.map((e) => e as String)
          .toList() ??
          [],
      difficultyLevel: solutionJson['difficultyLevel'] as int? ?? 3,
      source: SolutionSource.aiGenerated,
      metadata: SolutionMetadata(
        createdAt: DateTime.now(),
        modelId: json['_modelId'] as String?,
        tokenCount: json['_tokenCount'] as int?,
      ),
    );
  }
  
  /// 解析 Markdown 分隔格式
  static Solution parseFromMarkdown(
    String markdown,
    String questionId, {
    String splitter = r'---STEP---',
  }) {
    final parts = markdown.split(RegExp('^' + RegExp.escape(splitter), multiLine: true));
    
    final steps = <SolutionStep>[];
    for (var i = 0; i < parts.length; i++) {
      final part = parts[i].trim();
      if (part.isEmpty) continue;
      
      steps.add(_parseMarkdownStep(part, i + 1));
    }
    
    return Solution(
      solutionId: 'sol_${questionId}_${DateTime.now().millisecondsSinceEpoch}',
      questionId: questionId,
      steps: steps,
      source: SolutionSource.aiGenerated,
      metadata: SolutionMetadata(createdAt: DateTime.now()),
    );
  }
  
  /// 解析单个步骤
  static SolutionStep _parseStep(Map<String, dynamic> json) {
    return SolutionStep(
      stepIndex: json['stepIndex'] as int,
      type: StepType.values.firstWhere(
        (e) => e.name == json['type'],
        orElse: () => StepType.approachAnalysis,
      ),
      title: json['title'] as String? ?? '步骤 ${json['stepIndex']}',
      blocks: _parseBlocks(json['blocks'] as List<dynamic>),
      annotation: json['annotation'] as String?,
      diagramOps: (json['diagramOps'] as List<dynamic>?)
          ?.map((e) => _parseDiagramOp(e as Map<String, dynamic>))
          .toList(),
      highlights: (json['highlights'] as List<dynamic>?)
          ?.map((e) => _parseHighlight(e as Map<String, dynamic>))
          .toList(),
      complexity: StepComplexity.values.firstWhere(
        (e) => e.name == (json['complexity'] ?? 'medium'),
        orElse: () => StepComplexity.medium,
      ),
      isKeyStep: json['isKeyStep'] as bool? ?? false,
      userPrompt: json['userPrompt'] != null
          ? PromptAfterStep.fromJson(json['userPrompt'] as Map<String, dynamic>)
          : null,
    );
  }
  
  /// 解析内容块列表
  static List<ContentBlock> _parseBlocks(List<dynamic> blocksJson) {
    return blocksJson.map((b) {
      final map = b as Map<String, dynamic>;
      final type = map['type'] as String;
      
      return switch (type) {
        'text' => TextBlock(
          markdown: map['markdown'] as String,
          style: map['style'] != null
              ? TextStyleOverride.fromJson(map['style'])
              : null,
        ),
        'formula' => FormulaBlock(
          latex: map['latex'] as String,
          role: FormulaRole.values.firstWhere(
            (e) => e.name == (map['role'] ?? 'auxiliary'),
            orElse: () => FormulaRole.auxiliary,
          ),
        ),
        'diagram' => DiagramBlock(
          diagramId: map['diagramId'] as String,
          type: DiagramType.values.firstWhere(
            (e) => e.name == map['diagramType'],
            orElse: () => DiagramType.geometry,
          ),
          svgContent: map['svg'] as String?,
          layers: (map['layers'] as List<dynamic>?)
              ?.map((e) => DiagramLayer.fromJson(e))
              .toList() ??
              [],
        ),
        'table' => TableBlock(
          headers: (map['headers'] as List<dynamic>).cast<String>(),
          rows: (map['rows'] as List<dynamic>)
              .map((r) => (r as List<dynamic>).cast<String>())
              .toList(),
        ),
        'comparison' => ComparisonBlock(
          leftLabel: map['leftLabel'] as String,
          leftContent: map['leftContent'] as String,
          rightLabel: map['rightLabel'] as String,
          rightContent: map['rightContent'] as String,
          comparisonNote: map['note'] as String?,
        ),
        _ => TextBlock(markdown: '[不支持的内容类型: $type]'),
      };
    }).toList();
  }
  
  static SolutionStep _parseMarkdownStep(String md, int index) {
    // 解析标题行
    final titleMatch = RegExp(r'^#+\s*(.+)$').firstMatch(md);
    final title = titleMatch?.group(1) ?? '步骤 $index';
    
    // 提取公式块
    final formulaPattern = RegExp(r'\$\$(.+?)\$\$', dotAll: true);
    final formulas = formulaPattern.allMatches(md).toList();
    
    // 移除公式后的纯文本
    final textOnly = md
        .replaceFirst(titleMatch?.group(0) ?? '', '')
        .replaceAll(formulaPattern, ' {{formula}} ')
        .trim();
    
    final blocks = <ContentBlock>[];
    
    // 添加文本块（如果有内容）
    if (textOnly.isNotEmpty) {
      blocks.add(TextBlock(markdown: textOnly));
    }
    
    // 添加公式块
    for (final f in formulas) {
      blocks.add(FormulaBlock(
        latex: f.group(1)!.trim(),
        role: FormulaRole.auxiliary,
      ));
    }
    
    return SolutionStep(
      stepIndex: index,
      type: _inferStepType(title),
      title: title,
      blocks: blocks,
      complexity: _inferComplexity(blocks),
      isKeyStep: false,
    );
  }
  
  static StepType _inferStepType(String title) {
    final lower = title.toLowerCase();
    if (lower.contains('已知') || lower.contains('条件')) return StepType.conditionExtract;
    if (lower.contains('思路') || lower.contains('方向')) return StepType.approachAnalysis;
    if (lower.contains('代入') || lower.contains('公式')) return StepType.formulaApply;
    if (lower.contains('变形') || lower.contains('化简')) return StepType.formulaTransform;
    if (lower.contains('计算')) return StepType.calculate;
    if (lower.contains('结论') || lower.contains('所以') || lower.contains('因此')) return StepType.conclusion;
    if (lower.contains('验证') || lower.contains('检查')) return StepType.verification;
    if (lower.contains('易错') || lower.contains('注意') || lower.contains('警示')) return StepType.pitfallWarning;
    if (lower.contains('总结') || lower.contains('归纳') || lower.contains('方法')) return StepType.methodSummary;
    return StepType.approachAnalysis;
  }
  
  static StepComplexity _inferComplexity(List<ContentBlock> blocks) {
    final formulaCount = blocks.whereType<FormulaBlock>().length;
    final totalLength = blocks.fold(0, (sum, b) {
      return switch (b) {
        TextBlock(:final markdown) => sum + markdown.length,
        FormulaBlock(:final latex) => sum + latex.length,
        _ => sum + 50,
      };
    });
    
    if (formulaCount >= 3 || totalLength > 200) return StepComplexity.complex;
    if (formulaCount >= 1 || totalLength > 80) return StepComplexity.medium;
    return StepComplexity.simple;
  }
}
```

## 5. 播放状态机（PlaybackStateMachine）

### 5.1 状态流转图

```
                    ┌─────────┐
         ┌─────────│  idle   │
         │         └────┬────┘
         │              │ start()
         │              ▼
         │         ┌─────────┐
         │    ┌───│ playing  │──┐
         │    │    └────┬────┘  │
         │    │         │       │ pause()
         │    │ stepDone│       │
         │    │(keyStep)│       ▼
         │    │         │  ┌─────────┐
         │    │         │  │ paused  │
         │    │         │  └────┬────┘
         │    │         │       │ resume()
         │    │         │       │
         │    ▼         │       │
    ┌─────────┐         │       │
    │stepDone │         │       │
    └────┬────┘         │       │
         │ advance()    │       │
         ├──────────────┘       │
         │                      │
         │ no more steps        │
         ▼                      │
    ┌─────────┐                 │
    │finished │                 │
    └────┬────┘                 │
         │ replay()             │
         ├──────────────────────┘
         │
         ▼
    ┌─────────┐
    │replaying│──→ playing (from step N)
    └─────────┘
```

### 5.2 状态机实现

```dart
class PlaybackStateMachine extends ChangeNotifier {
  PlaybackState _state = PlaybackState.idle;
  int _currentStepIndex = 0;
  final Solution _solution;
  final PlaybackConfig _config;
  
  // 步骤完成回调
  void Function(int stepIndex, SolutionStep step)? onStepComplete;
  void Function(int stepIndex, SolutionStep step)? onStepStart;
  void Function()? onAllComplete;
  
  PlaybackStateMachine({
    required Solution solution,
    required PlaybackConfig config,
  })  : _solution = solution,
        _config = config;
  
  PlaybackState get state => _state;
  int get currentStepIndex => _currentStepIndex;
  SolutionStep? get currentStep =>
      _currentStepIndex < _solution.steps.length
          ? _solution.steps[_currentStepIndex]
          : null;
  
  /// 开始播放
  void start() {
    if (_state != PlaybackState.idle) return;
    _currentStepIndex = 0;
    _transition(PlaybackState.playing);
    onStepStart?.call(0, _solution.steps[0]);
  }
  
  /// 当前步骤播放完成
  void stepComplete() {
    final step = currentStep!;
    onStepComplete?.call(_currentStepIndex, step);
    
    // 关键步骤需要用户确认
    if (step.isKeyStep && _config.mode == PlaybackMode.autoPaced) {
      _transition(PlaybackState.stepDone);
      return;
    }
    
    _advance();
  }
  
  /// 推进到下一步
  void advance() {
    if (_state != PlaybackState.stepDone && _state != PlaybackState.paused) return;
    _advance();
  }
  
  void _advance() {
    _currentStepIndex++;
    
    if (_currentStepIndex >= _solution.steps.length) {
      _transition(PlaybackState.finished);
      onAllComplete?.call();
      return;
    }
    
    _transition(PlaybackState.playing);
    onStepStart?.call(_currentStepIndex, currentStep!);
  }
  
  /// 暂停
  void pause() {
    if (_state == PlaybackState.playing) {
      _transition(PlaybackState.paused);
    }
  }
  
  /// 恢复
  void resume() {
    if (_state == PlaybackState.paused || _state == PlaybackState.stepDone) {
      _transition(PlaybackState.playing);
      onStepStart?.call(_currentStepIndex, currentStep!);
    }
  }
  
  /// 跳转到指定步骤
  void jumpTo(int stepIndex) {
    if (stepIndex < 0 || stepIndex >= _solution.steps.length) return;
    _currentStepIndex = stepIndex;
    _transition(PlaybackState.playing);
    onStepStart?.call(stepIndex, _solution.steps[stepIndex]);
  }
  
  /// 重播当前步骤
  void replayCurrent() {
    _transition(PlaybackState.replaying);
    // 动画引擎会重新播放当前步骤
    Future.delayed(const Duration(milliseconds: 100), () {
      _transition(PlaybackState.playing);
      onStepStart?.call(_currentStepIndex, currentStep!);
    });
  }
  
  /// 重播全部
  void replayAll() {
    _currentStepIndex = 0;
    _transition(PlaybackState.replaying);
    Future.delayed(const Duration(milliseconds: 200), () {
      _transition(PlaybackState.playing);
      onStepStart?.call(0, _solution.steps[0]);
    });
  }
  
  void _transition(PlaybackState newState) {
    final oldState = _state;
    _state = newState;
    notifyListeners();
    PlaybackLog.debug('PlaybackState: $oldState → $newState, step=$_currentStepIndex');
  }
}
```

## 6. 节奏策略（PacingStrategy）

### 6.1 职责

根据步骤复杂度、用户学段、动画偏好和场景模式，计算每一步的动画参数。

### 6.2 节奏预设

```dart
class PacingStrategy {
  /// 学段节奏预设
  static const Map<GradeLevel, PacingPreset> _presets = {
    GradeLevel.kindergarten: PacingPreset(
      stepBaseDuration: Duration(milliseconds: 1200),
      interStepDelay: Duration(milliseconds: 800),
      textRevealSpeed: 50, // 字/秒
      formulaRevealDuration: Duration(milliseconds: 1500),
      diagramAnimDuration: Duration(milliseconds: 2000),
    ),
    GradeLevel.primary: PacingPreset(
      stepBaseDuration: Duration(milliseconds: 1000),
      interStepDelay: Duration(milliseconds: 500),
      textRevealSpeed: 80,
      formulaRevealDuration: Duration(milliseconds: 1200),
      diagramAnimDuration: Duration(milliseconds: 1500),
    ),
    GradeLevel.middle: PacingPreset(
      stepBaseDuration: Duration(milliseconds: 800),
      interStepDelay: Duration(milliseconds: 300),
      textRevealSpeed: 120,
      formulaRevealDuration: Duration(milliseconds: 1000),
      diagramAnimDuration: Duration(milliseconds: 1200),
    ),
    GradeLevel.high: PacingPreset(
      stepBaseDuration: Duration(milliseconds: 600),
      interStepDelay: Duration(milliseconds: 200),
      textRevealSpeed: 160,
      formulaRevealDuration: Duration(milliseconds: 800),
      diagramAnimDuration: Duration(milliseconds: 1000),
    ),
  };
  
  /// 计算步骤的完整动画配置
  StepAnimationConfig calculate(
    SolutionStep step,
    GradeLevel grade,
    AnimationPreference pref,
    double speedMultiplier,
  ) {
    final preset = _presets[grade] ?? _presets[GradeLevel.middle]!;
    
    // 复杂度系数
    final complexityMultiplier = switch (step.complexity) {
      StepComplexity.simple => 0.8,
      StepComplexity.medium => 1.0,
      StepComplexity.complex => 1.5,
    };
    
    // 动画偏好系数
    final prefMultiplier = switch (pref) {
      AnimationPreference.full => 1.0,
      AnimationPreference.reduced => 0.6,
      AnimationPreference.minimal => 0.3,
      AnimationPreference.off => 0.0,
    };
    
    final effectiveMultiplier = (speedMultiplier * prefMultiplier).clamp(0.0, 2.0);    
    // 关键步骤停留系数（让学生多看一眼）
    final keyStepHold = step.isKeyStep ? 1.3 : 1.0;
    
    // 步骤总时长（下限 200ms 防闪烁，上限 8s 防拖沓）
    final baseMs = (preset.stepBaseDuration.inMilliseconds *
            complexityMultiplier *
            effectiveMultiplier *
            keyStepHold)
        .round()
        .clamp(200, 8000);
    
    // 文本揭示时长：按字数与学段速度推导（下限 300ms 防闪读；off 模式为 0）
    final totalChars = step.blocks
        .whereType<TextBlock>()
        .fold<int>(0, (s, b) => s + b.markdown.length);
    final textRevealMs = pref == AnimationPreference.off
        ? 0
        : ((totalChars / preset.textRevealSpeed) * 1000)
            .round()
            .clamp(300, baseMs);
    
    return StepAnimationConfig(
      stepDuration: Duration(milliseconds: baseMs),
      blockDelay: Duration(milliseconds: (120 * effectiveMultiplier).round()),
      textRevealDuration: Duration(milliseconds: textRevealMs),
      formulaRevealDuration: Duration(
        milliseconds: (preset.formulaRevealDuration.inMilliseconds *
                effectiveMultiplier)
            .round(),
      ),
      diagramAnimDuration: Duration(
        milliseconds:
            (preset.diagramAnimDuration.inMilliseconds * effectiveMultiplier)
                .round(),
      ),
      interStepDelay: Duration(
        milliseconds:
            (preset.interStepDelay.inMilliseconds * effectiveMultiplier)
                .round(),
      ),
      curve: pref == AnimationPreference.full
          ? Curves.easeOutCubic
          : Curves.linear,
      animateText: pref != AnimationPreference.off && totalChars > 0,
    );
  }
}
```

> **裁决说明**：`speedMultiplier` 允许范围 [0.5, 2.0]（见 §6.3 调速控制器），此处再 clamp 一次是防御性兜底；`prefMultiplier == 0`（off 模式）时 `baseMs` 被 clamp 到 200ms，保证状态机时序不塌陷，同时 `animateText == false` 保证零逐字动画（G7 红线）。

## 7. 动画引擎层（AnimationTimeline）

### 7.1 职责

把一个步骤的 `StepAnimationConfig` 展开为可执行的时间轴：按顺序编排内容块动画（渐入 → 文本揭示 → 公式揭示+高亮 → 图形操作 → 停留），统一调度 Ticker，支持取消与跳步清理。

### 7.2 时间轴实现

```dart
/// 时间轴条目
class TimelineEntry {
  final StepAnimPhaseKind kind;
  final Duration offset;      // 相对步骤开始的偏移
  final Duration duration;    // 本阶段时长
  final VoidCallback onFire;  // 触发回调（驱动渲染层）
  
  const TimelineEntry({
    required this.kind,
    required this.offset,
    required this.duration,
    required this.onFire,
  });
}

/// 动画时间轴：单步骤内的阶段编排与执行
class AnimationTimeline {
  final List<TimelineEntry> _entries;
  final TickerProvider _tickerProvider;
  
  Ticker? _ticker;
  Duration _elapsed = Duration.zero;
  int _nextFireIndex = 0;
  bool _cancelled = false;
  
  AnimationTimeline({
    required List<TimelineEntry> entries,
    required TickerProvider tickerProvider,
  })  : _entries = entries..sort((a, b) => a.offset.compareTo(b.offset)),
        _tickerProvider = tickerProvider;
  
  bool get isDone => _nextFireIndex >= _entries.length;
  
  /// 从某个步骤的 config + step 构建时间轴
  factory AnimationTimeline.forStep({
    required SolutionStep step,
    required StepAnimationConfig config,
    required TickerProvider tickerProvider,
    required StepRenderHooks hooks,
  }) {
    final entries = <TimelineEntry>[];
    var cursor = Duration.zero;
    
    // 1. 卡片渐入
    entries.add(TimelineEntry(
      kind: StepAnimPhaseKind.fadeIn,
      offset: cursor,
      duration: const Duration(milliseconds: 200),
      onFire: hooks.onCardFadeIn,
    ));
    cursor += const Duration(milliseconds: 200);
    
    // 2. 逐块渲染内容
    for (final block in step.blocks) {
      switch (block) {
        case TextBlock():
          if (config.animateText) {
            entries.add(TimelineEntry(
              kind: StepAnimPhaseKind.textReveal,
              offset: cursor,
              duration: config.textRevealDuration,
              onFire: () => hooks.onTextReveal(block, config.textRevealDuration),
            ));
            cursor += config.textRevealDuration + config.blockDelay;
          } else {
            entries.add(TimelineEntry(
              kind: StepAnimPhaseKind.fadeIn,
              offset: cursor,
              duration: Duration.zero,
              onFire: () => hooks.onTextInstant(block),
            ));
          }
        case FormulaBlock():
          entries.add(TimelineEntry(
            kind: StepAnimPhaseKind.formulaReveal,
            offset: cursor,
            duration: config.formulaRevealDuration,
            onFire: () => hooks.onFormulaReveal(block, config.formulaRevealDuration),
          ));
          cursor += config.formulaRevealDuration + config.blockDelay;
        case DiagramBlock():
          entries.add(TimelineEntry(
            kind: StepAnimPhaseKind.diagramOp,
            offset: cursor,
            duration: config.diagramAnimDuration,
            onFire: () => hooks.onDiagramShow(block, config.diagramAnimDuration),
          ));
          cursor += config.diagramAnimDuration + config.blockDelay;
        default:
          entries.add(TimelineEntry(
            kind: StepAnimPhaseKind.fadeIn,
            offset: cursor,
            duration: Duration.zero,
            onFire: () => hooks.onBlockInstant(block),
          ));
      }
    }
    
    // 3. 图形操作序列（与 diagramOps 一一对应）
    for (final op in (step.diagramOps ?? const <DiagramOperation>[])) {
      entries.add(TimelineEntry(
        kind: StepAnimPhaseKind.diagramOp,
        offset: cursor,
        duration: const Duration(milliseconds: 400),
        onFire: () => hooks.onDiagramOperation(op),
      ));
      cursor += const Duration(milliseconds: 400);
    }
    
    // 4. 高亮标注
    for (final h in (step.highlights ?? const <HighlightTarget>[])) {
      entries.add(TimelineEntry(
        kind: StepAnimPhaseKind.highlight,
        offset: cursor,
        duration: const Duration(milliseconds: 300),
        onFire: () => hooks.onHighlight(h),
      ));
      cursor += const Duration(milliseconds: 300);
    }
    
    return AnimationTimeline(
      entries: entries,
      tickerProvider: tickerProvider,
    );
  }
  
  /// 播放（G4：跳步/销毁前必须先 cancel 旧时间轴）
  void play() {
    _cancelled = false;
    _elapsed = Duration.zero;
    _nextFireIndex = 0;
    _ticker?.dispose();
    _ticker = _tickerProvider.createTicker(_onTick)..start();
  }
  
  void _onTick(Duration elapsed) {
    if (_cancelled) return;
    final delta = elapsed - _elapsed;
    _elapsed = elapsed;
    
    while (_nextFireIndex < _entries.length &&
        _entries[_nextFireIndex].offset <= _elapsed) {
      final entry = _entries[_nextFireIndex++];
      try {
        entry.onFire();
      } catch (e) {
        // G10：单阶段动画异常 fail-silent，继续后续阶段
        PlaybackLog.warning('timeline entry ${entry.kind} failed: $e');
      }
    }
    
    if (isDone) {
      _ticker?.stop();
      onTimelineComplete?.call();
    }
  }
  
  /// 取消（不触发任何后续回调）
  void cancel() {
    _cancelled = true;
    _ticker?.stop();
  }
  
  void dispose() {
    cancel();
    _ticker?.dispose();
    _ticker = null;
  }
  
  void Function()? onTimelineComplete;
}

/// 渲染层钩子集合（由 StepRenderer 层实现，见 §8）
abstract class StepRenderHooks {
  void onCardFadeIn();
  void onTextReveal(TextBlock block, Duration duration);
  void onTextInstant(TextBlock block);
  void onFormulaReveal(FormulaBlock block, Duration duration);
  void onDiagramShow(DiagramBlock block, Duration duration);
  void onBlockInstant(ContentBlock block);
  void onDiagramOperation(DiagramOperation op);
  void onHighlight(HighlightTarget target);
}
```

```dart
      switch (op.type) {
        case DiagramOpType.addLine:
        case DiagramOpType.addAngle:
        case DiagramOpType.addLabel:
        case DiagramOpType.highlight:
        case DiagramOpType.shade:

        case DiagramOpType.transform:
          // 变换类操作触发图层重渲染（具体由 Canvas 实现）
          _annotations[op.params['target'] as String] =
              DiagramAnnotation.fromOp(op);
      }
    });

      annotations: _annotations.values.toList(),
```

## 9. 交互控制器（InteractionController）

### 9.1 职责

把用户输入（点击/手势/进度条跳转/调速/重播）翻译为状态机调用，并维护"当前步骤动画是否播完"的门控，防止用户在动画中途重复触发。

### 9.2 控制器实现

```dart
class InteractionController {
  final PlaybackStateMachine machine;
  final AnimationTimeline? Function() currentTimeline;
  final PlaybackSpeedController speedController;
  
  bool _stepAnimInFlight = false;
  
  InteractionController({
    required this.machine,
    required this.currentTimeline,
    required this.speedController,
  }) {
    machine.onStepStart = _handleStepStart;
    machine.onStepComplete = _handleStepComplete;
  }
  
  void _handleStepStart(int index, SolutionStep step) {
    _stepAnimInFlight = true;
    // 渲染层构建时间轴并播放，完成后回调 machine.stepComplete()
    onBuildAndPlayTimeline?.call(index, step, () {
      _stepAnimInFlight = false;
      machine.stepComplete();
    });
  }
  
  void _handleStepComplete(int index, SolutionStep step) {
    // 埋点：步骤曝光完成（见 §15）
    onStepViewed?.call(index, step);
  }
  
  /// 用户点击"下一步/继续"
  void onAdvanceTap() {
    // G2：动画播完前忽略点击（防止连点穿透）
    if (_stepAnimInFlight) return;
    machine.advance();
  }
  
  /// 用户点击暂停/继续
  void onTogglePause() {
    if (machine.state == PlaybackState.playing) {
      currentTimeline()?.cancel();
      machine.pause();
    } else if (machine.state == PlaybackState.paused) {
      machine.resume(); // resume 会重建当前步骤时间轴
    }
  }
  
  /// 进度条跳转到指定步骤
  void onSeek(int stepIndex) {
    currentTimeline()?.cancel(); // G3：先取消旧动画
    _stepAnimInFlight = false;
    machine.jumpTo(stepIndex);
  }
  
  /// 重播当前步骤
  void onReplayCurrent() {
    currentTimeline()?.cancel();
    _stepAnimInFlight = false;
    machine.replayCurrent();
  }
  
  /// 调速
  void onSpeedAdjust(double delta) => speedController.adjust(delta);
  
  // 由 SAE 控制器注入的回调
  void Function(int index, SolutionStep step, VoidCallback onDone)? onBuildAndPlayTimeline;
  void Function(int index, SolutionStep step)? onStepViewed;
}
```

```dart
  final VoidCallback? onFinished;

    super.key,
    required this.solution,
    required this.gradeLevel,
    this.config,
    this.onFinished,
  });
  
  @override
  State<SaePlayerWidget> createState() => _SaePlayerWidgetState();
}

class _SaePlayerWidgetState extends State<SaePlayerWidget>
    with TickerProviderStateMixin {
  late final PlaybackStateMachine _machine;
  late final InteractionController _interaction;
  late final PlaybackSpeedController _speed;
  AnimationTimeline? _timeline;
  
  @override
  void initState() {
    super.initState();
    final config = widget.config ?? _defaultConfigFor(widget.gradeLevel);
    _machine = PlaybackStateMachine(
      solution: widget.solution,
      config: config,
    )..onAllComplete = widget.onFinished;
    _speed = PlaybackSpeedController();
    _interaction = InteractionController(
      machine: _machine,
      currentTimeline: () => _timeline,
      speedController: _speed,
    )..onBuildAndPlayTimeline = _buildAndPlay;
    
    // 自动开始
    WidgetsBinding.instance.addPostFrameCallback((_) => _machine.start());
  }
  
  PlaybackConfig _defaultConfigFor(GradeLevel grade) {
    return switch (grade) {
      GradeLevel.kindergarten => const PlaybackConfig(
          mode: PlaybackMode.manual, // 幼儿：点击触发
          speedMultiplier: 1.0,
          autoAdvance: false,
          animationPref: AnimationPreference.full,
        ),
      GradeLevel.primary => const PlaybackConfig(
          mode: PlaybackMode.autoPaced, // 小学：自动播放+关键步确认
          speedMultiplier: 1.0,
          autoAdvance: true,
          animationPref: AnimationPreference.full,
        ),
      GradeLevel.middle || GradeLevel.high => const PlaybackConfig(
          mode: PlaybackMode.autoFull, // 初高中：快速自动
          speedMultiplier: 1.2,
          autoAdvance: true,
          animationPref: AnimationPreference.reduced,
        ),
    };
  }
  
  void _buildAndPlay(int index, SolutionStep step, VoidCallback onDone) {
    final config = PacingStrategy().calculate(
      step,
      widget.gradeLevel,
      _speed.resolvePreference(
        widget.config?.animationPref ?? AnimationPreference.full,
      ),
      _speed.speedMultiplier,
    );
    
    _timeline?.dispose();
    _timeline = AnimationTimeline.forStep(
      step: step,
      config: config,
      tickerProvider: this,
      hooks: _buildHooks(step),
    )..onTimelineComplete = onDone;
    _timeline!.play();
  }
  
  StepRenderHooks _buildHooks(SolutionStep step) {
    // 委托给 §8 渲染层：通过 GlobalKey 找到当前 BlockRendererHost 执行动画
    // 实现细节略（渲染层按 block 索引维护 AnimationController 字典）
    return SaeRenderHooksBinding.instance.hooksFor(step.stepIndex);
  }
  
  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _machine,
      builder: (context, _) {
        final step = _machine.currentStep;
        return Column(
          children: [
            // 步骤视口
            Expanded(
              child: step != null
                  ? StepRenderer(
                      key: ValueKey(step.stepIndex),
                      step: step,
                      config: PacingStrategy().calculate(
                        step,
                        widget.gradeLevel,
                        AnimationPreference.full,
                        _speed.speedMultiplier,
                      ),
                      controller: _renderController,
                    )
                  : const SizedBox.shrink(),
            ),
            // 进度条（可点击跳转）
            SaeProgressBar(
              steps: widget.solution.steps,
              currentIndex: _machine.currentStepIndex,
              onSeek: _interaction.onSeek,
            ),
            // 控制条
            SaeControlBar(
              state: _machine.state,
              onAdvance: _interaction.onAdvanceTap,
              onTogglePause: _interaction.onTogglePause,
              onReplay: _interaction.onReplayCurrent,
              onSpeedAdjust: _interaction.onSpeedAdjust,
              speedLabel: '${_speed.speedMultiplier.toStringAsFixed(2)}x',
            ),
          ],
        );
      },
    );
  }
  
  @override
  void dispose() {
    _timeline?.dispose(); // G4
    _machine.dispose();
    super.dispose();
  }
}
```

## 11. 状态机守卫与竞态裁决

### 11.1 守卫总表（G1-G10）

| 编号 | 守卫 | 说明 | 违反后果处理 |
|------|------|------|--------------|
| G1 | 所有状态机入口前置状态校验 | 非法迁移（如 finished 态调 start）静默忽略并打 debug 日志，禁止抛异常打断页面 | 已有（§5.2 `if (_state != ...) return`），新增统一 `PlaybackLog.debug` |
| G2 | 动画播完前忽略 advance 点击 | `_stepAnimInFlight` 门控（§9.2） | 点击被吞没，不打断动画 |
| G3 | 跳步/重播必须先 cancel 旧时间轴 | `onSeek`/`onReplayCurrent` 先 `timeline.cancel()` 再调状态机 | 防止旧动画回调污染新步骤（setState 到已替换 Widget） |
| G4 | Widget dispose 必须释放 Timer/Ticker | `_SaePlayerWidgetState.dispose` 释放 `_timeline`/`AnimationController` | 防内存泄漏与"回调到已销毁元素"崩溃 |
| G5 | App 切后台自动暂停 | `AppLifecycleState.paused` → `machine.pause()` + `timeline.cancel()`；回前台**不自动恢复**（防沉迷对齐：不偷偷播） | 回前台停留在 paused 态，用户手动继续 |
| G6 | speedMultiplier 边界 clamp [0.5, 2.0] | 调速控制器与 PacingStrategy 双重 clamp | 超出值截断 |
| G7 | off 模式零动画 | `animateText=false`、各 Renderer `duration==Duration.zero` 时直出终态、不创建 Ticker | 保证"关闭动画"绝对无动画 |
| G8 | stepDone 态允许进度条跳步 | 点击其他步骤 = `jumpTo`，同时清除确认 UI（`showUserPrompt=false`） | 无残留确认弹窗 |
| G9 | 同步骤 onStepStart 不重复触发 | resume 当前步骤时不重新计埋点（`_stepAnimInFlight` 复位由回调保证） | 埋点不重复上报 |
| G10 | 动画执行异常 fail-silent | TimelineEntry.onFire 外层 try/catch（§7.2），单阶段失败继续后续 | 播放不被单点异常中断 |

### 11.2 竞态裁决

| 竞态场景 | 裁决 |
|----------|------|
| 动画播完回调 `stepComplete` 与用户点击 advance 同时到达 | `stepDone` 态 advance 合法；`playing` 态 advance 被 G1 吞没。先到者胜，无 double advance（状态机 CAS 语义） |
| 跳步（jumpTo）后旧时间轴延迟回调到达 | G3 保证旧 timeline 已 cancel，`_cancelled` 标志使 `_onTick` 直接 return |
| pause 与 Timeline onFire 同帧 | pause 先 cancel timeline，已到期的 entry 已执行的不回滚，未执行的不执行（幂等，无副作用累积） |
| 页面销毁与 onFire 同帧 | G4：dispose 顺序 `timeline.dispose()` 先于 super.dispose；onFire 内 setState 前校验 `mounted`（渲染层责任） |

## 12. 错误处理与降级

### 12.1 错误处理

| 错误 | 检测 | 处理 |
|------|------|------|
| AI JSON 解析失败（格式非法/缺字段） | `parseFromJson` 抛 FormatException | D1 回退 Markdown 静态渲染，上报 `sae_fallback` 埋点，不阻塞答疑 |
| Markdown 分隔格式无 `---STEP---` | `parts.length <= 1` | 整体作为单一步骤渲染（纯 Markdown 静显） |
| LaTeX 公式渲染失败 | LatexFormulaView 内部捕获 | 降级为等宽文本展示原始 LaTeX，不整步失败 |
| 图形 SVG 解析失败 | SvgDiagramCanvas onRenderError | D6 降级为 DiagramTextFallback（文字描述图形内容） |
| 动画引擎异常 | TimelineEntry try/catch（G10） | 跳过该阶段，继续播放 |
| 时间轴调度积压 | `_onTick` delta > 2 帧（>33ms×2） | D5 合并：直接触发全部到期 entry 并跳至终态 |

### 12.2 降级矩阵（D1-D8）

| 编号 | 降级条件 | 降级行为 | 恢复 |
|------|----------|----------|------|
| D1 | AI 输出非结构化 | 回退 Markdown 静态渲染（无分步动画） | 下一次请求恢复 |
| D2 | 低端机（RAM<4GB 或持续掉帧 <45fps 3 秒） | 自动降档：animationPref→reduced、帧率目标 30fps | 重启会话重置 |
| D3 | 系统"减弱动态效果"开启 | 强制最高 reduced（§6.3 resolvePreference） | 跟随系统设置即时恢复 |
| D4 | Timeline 积压 | 直出步骤终态（全部 entry 立即触发） | 下一新步骤正常 |
| D5 | SVG/图形渲染失败 | 文字降级 | 不可恢复（该步骤） |
| D6 | 内存压力（onMemoryPressure） | 取消非当前步骤的缓存位图，降低图层缓存上限 | 压力解除后自动 |
| D7 | 埋点上报失败 | 缓存本地，下次启动补传（委托埋点体系） | 不影响播放 |
| D8 | 离线/弱网 | 全部本地计算，零网络依赖（设计目标，非降级） | — |

> **总红线**：SAE 是表现层组件，任何降级路径不得阻塞或中断答题、答疑等主学习链路；D1/D2/D4 的终态渲染必须保证学生能看到完整解析内容。

## 13. 性能设计

### 13.1 性能指标

| 指标 | 目标 | 说明 |
|------|------|------|
| 首帧渲染（进入页面到第一步可见） | < 100ms | 不含解题内容网络耗时 |
| 步骤切换帧率 | 60fps | 中端设备 |
| 低端设备帧率 | ≥ 45fps | D2 降档后 30fps 目标 |
| 内存增量 | < 20MB | 含图形缓存 |
| 时间轴建立耗时 | < 5ms | forStep 构建开销 |

### 13.2 优化手段

1. **RepaintBoundary**：步骤卡片与图形 Canvas 分别包裹，动画重绘不扩散（§8.1）
2. **选择性重建**：`AnimatedBuilder` 只监听 `_machine`，调速走 `_speed` 独立监听，避免控制条操作触发步骤重渲染
3. **时间轴零 GC 热路径**：`_onTick` 内无对象分配（entry 列表预排序）
4. **图层缓存**：图形 Canvas 对静态底图缓存位图，仅标注层重绘
5. **Ticker 复用**：每步骤一个 Ticker，步骤切换时 dispose 旧 Ticker 防止泄漏（G4）
6. **图片资源**：图形中的位图素材走统一图片加载缓存框架（契约 R5）

| 速度条可见 | 否 | 是（0.75x-1.5x） | 是（0.5x-2x） | 是（0.5x-2x） |
| 进度条 | 圆点序列 | 圆点序列 | 细条+步号 | 细条+步号 |

### 14.2 无障碍

- **减少动画**：跟随系统 `MediaQuery.disableAnimations` 与平台无障碍设置（D3），最高允许 reduced
- **语义标签**：步骤标题读"第 N 步，共 M 步"；控制按钮均有 Semantics 标签
- **TalkBack/旁白**：公式朗读为"公式：{latex 线性化文本}"，由 LatexFormulaView 提供线性化
- **简洁模式入口**：设置页一键切换 `AnimationPreference.minimal/off`，全局生效（存用户偏好）
