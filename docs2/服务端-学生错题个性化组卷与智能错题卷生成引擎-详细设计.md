# 服务端 - 学生错题个性化组卷与智能错题卷生成引擎 详细设计

## 1. 概述

### 1.1 功能定位

学生错题个性化组卷与智能错题卷生成引擎（Mistake-Based Personalized Paper Generation Engine，简称 MPPG）是 PrimeTop 错题学习闭环中的核心服务端引擎。它根据学生错题本中的历史错题，结合遗忘曲线复习调度、知识点覆盖度、难度分布、错因类型等多维度因素，智能筛选并编排生成结构化的"个性化错题卷"，供学生进行集中自测和复习巩固。

### 1.2 与现有模块的边界

| 模块 | 职责 | 与本引擎的关系 |
| --- | --- | --- |
| 错题整理模块 | 错题收录、分类管理、错因标签 | **数据来源**：本引擎从错题本读取数据 |
| 间隔重复算法与遗忘曲线复习调度引擎 | 计算单道错题的下次复习时间 | **调度输入**：本引擎引用其遗忘风险评分 |
| 智能组卷与自适应测试引擎 | 从题库中编排正式试卷/模拟卷 | **互补**：该引擎从题库组卷；本引擎从**个人错题集**组卷 |
| 题目智能推荐与个性化练习编排服务 | 日常短时练习（3-15题）推荐 | **互补**：该服务面向日常微练习；本引擎面向**完整试卷式**集中复习 |
| 客户端-错题打印与PDF导出 | 错题打印的页面交互 | **下游消费方**：可调用本引擎API获取推荐组卷结果用于打印 |
| 错题订正效果评估与复习成效追踪 | 订正后效果追踪 | **下游消费方**：消费错题卷完成结果用于成效分析 |

### 1.3 核心能力

1. **智能筛选**：从学生全部错题中，按复习紧迫度、知识价值、难易搭配等维度筛选最优子集
2. **结构编排**：将筛选出的错题按知识点聚类、难度递进、题型分布编排为结构化试卷
3. **变式注入**：按需在错题卷中注入同知识点同类新题（非错题），检测知识迁移效果
4. **多版本输出**：支持"纯错题卷"和"错题+变式混合卷"两种模式
5. **答案分离**：生成试题卷和答案卷两个版本，支持先测后查
6. **动态调整**：根据学生上次错题卷的完成表现，动态调整下一次组卷策略

### 1.4 设计目标

| 指标 | 目标 |
| --- | --- |
| 单次组卷响应时间 | P95 ≤ 800ms |
| 组卷题目数量 | 可配置，默认 20 题（范围 10-50） |
| 知识点覆盖率 | ≥ 80%（覆盖学生当前所有待复习错题涉及的独立知识点） |
| 难度分布合理性 | 易:中:难 ≈ 3:5:2（可按学生水平动态偏移） |
| 题型多样性 | 同一试卷内相同题型连续出现不超过 3 道 |
| 组卷满意度（用户反馈） | ≥ 85% 好评率 |

## 2. 数据结构设计

### 2.1 错题组卷任务表 `mistake_paper_tasks`

记录每次组卷请求及其生成参数。

```sql
CREATE TABLE mistake_paper_tasks (
    task_id          BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '组卷任务ID',
    student_id       BIGINT NOT NULL COMMENT '学生ID',
    subject_id       BIGINT NOT NULL COMMENT '学科ID',
    paper_mode       VARCHAR(20) NOT NULL DEFAULT 'PURE_MISTAKE'
                     COMMENT '组卷模式: PURE_MISTAKE(纯错题) / MIXED(错题+变式)',
    target_count     INT NOT NULL DEFAULT 20 COMMENT '目标题目数',
    actual_count     INT NOT NULL DEFAULT 0 COMMENT '实际入选题目数',
    difficulty_profile JSON NOT NULL COMMENT '难度分布配置 {easy:0.3, medium:0.5, hard:0.2}',
    knowledge_coverage JSON NULL COMMENT '知识点覆盖配置，NULL表示自动',
    include_variants INT NOT NULL DEFAULT 0 COMMENT '变式题注入数量（MIXED模式）',
    status           VARCHAR(20) NOT NULL DEFAULT 'PENDING'
                     COMMENT 'PENDING/GENERATING/COMPLETED/FAILED',
    paper_id         BIGINT NULL COMMENT '生成的试卷ID（关联 mistake_papers）',
    error_message    TEXT NULL COMMENT '失败原因',
    request_params   JSON NOT NULL COMMENT '完整请求参数快照',
    created_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    completed_at     DATETIME NULL,
    INDEX idx_student_subject (student_id, subject_id),
    INDEX idx_status_created (status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='错题组卷任务表';
```

## 4. 核心算法设计

### 4.1 组卷主流程

组卷采用 **"筛选评分 → 约束求解 → 排列优化"** 三阶段流水线：

```
学生请求组卷
    │
    ▼
┌──────────────────────────┐
│ Phase 1: 候选池构建        │   从错题本中拉取所有符合条件的候选错题
│ (Candidate Pool Build)    │   过滤：学科匹配、时间范围、排除最近连续正确的
└──────────┬───────────────┘
           │
           ▼
┌──────────────────────────┐
│ Phase 2: 多维度评分        │   对每道候选错题计算综合评分
│ (Multi-dim Scoring)       │   紧迫度 + 知识价值 + 多样性 + 历史表现
└──────────┬───────────────┘
           │
           ▼
┌──────────────────────────┐
│ Phase 3: 约束满足选择      │   在约束条件下选择最优子集
│ (Constraint Selection)    │   数量、难度分布、知识点覆盖、题型多样性
└──────────┬───────────────┘
           │
           ▼
┌──────────────────────────┐
│ Phase 4: 变式题注入        │   MIXED模式：从题库选取同知识点新题
│ (Variant Injection)       │
└──────────┬───────────────┘
           │
           ▼
┌──────────────────────────┐
│ Phase 5: 顺序编排          │   按策略排列题目顺序
│ (Sequence Arrangement)    │   题型分组 / 难度递进 / 随机
└──────────┬───────────────┘
           │
           ▼
┌──────────────────────────┐
│ Phase 6: 试卷持久化        │   写入数据库，生成试卷ID
│ (Persistence)             │
└──────────────────────────┘
```

### 4.2 Phase 1: 候选池构建

```java
/**
 * 构建候选错题池
 */
public List<ScoredMistake> buildCandidatePool(PaperGenerationRequest request) {
    // 1. 基础查询：拉取学生该学科的所有活跃错题
    List<MistakeRecord> mistakes = mistakeRecordMapper.selectActiveMistakes(
        request.getStudentId(),
        request.getSubjectId(),
        request.getKnowledgePointIds(),  // null表示全部
        request.getMistakeDateRange()
    );

    // 2. 过滤排除项
    List<MistakeRecord> filtered = mistakes.stream()
        // 排除最近3天内刚产生的错题（太新，还没消化）
        .filter(m -> m.getMistakeDate().before(
            DateUtils.addDays(new Date(), -request.getFromMistakeAgeDays())))

        // 排除连续正确次数≥3的错题（已掌握）
        .filter(m -> m.getConsecutiveCorrectCount() < 3)

        // 排除已标记为"已掌握"的错题
        .filter(m -> m.getStatus() != MistakeStatus.MASTERED)

        // 排除已删除/归档的错题
        .filter(m -> m.getStatus() != MistakeStatus.ARCHIVED)

        .collect(Collectors.toList());

    // 3. 转换为评分模型
    return filtered.stream()
        .map(this::toScoredMistake)
        .collect(Collectors.toList());
}
```

### 4.3 Phase 2: 多维度评分

每道候选错题的综合评分由四个维度加权计算：

```
TotalScore = w1 × UrgencyScore      (复习紧迫度)
           + w2 × KnowledgeValueScore (知识价值度)
           + w3 × DiversityBonus      (多样性加成)
           + w4 × WeaknessPenalty      (薄弱惩罚/奖励)
```

默认权重：`w1=0.40, w2=0.25, w3=0.15, w4=0.20`

#### 4.3.1 复习紧迫度评分（UrgencyScore）

基于间隔重复算法的遗忘风险，结合错因严重程度：

```java
/**
 * 计算复习紧迫度 [0-100]
 */
public double calculateUrgencyScore(MistakeRecord mistake) {
    // 1. 获取遗忘曲线引擎计算的下次复习时间和遗忘风险
    ReviewSchedule schedule = spacedRepetitionService.getSchedule(mistake.getId());
    
    // 超期天数（正数=已超期，负数=还没到期）
    long overdueDays = ChronoUnit.DAYS.between(
        schedule.getNextReviewDate().toInstant(),
        Instant.now()
    );
    
    // 2. 超期紧迫度：超期越多越紧迫，上限100
    double overdueScore = Math.min(100, Math.max(0, overdueDays * 15 + 30));
    // overdueDays=-2 → 0, overdueDays=0 → 30, overdueDays=5 → 105→100
    
    // 3. 错因严重度调整
    double severityMultiplier = switch (mistake.getErrorType()) {
        case "CONCEPT_ERROR" -> 1.3;      // 概念不清，最紧迫
        case "METHOD_ERROR" -> 1.2;       // 方法错误
        case "CALCULATION_ERROR" -> 1.0;  // 计算失误
        case "CARELESS_ERROR" -> 0.7;     // 粗心大意
        default -> 1.0;
    };
    
    // 4. 错题频率加成：同一知识点错误次数越多越紧迫
    int kpMistakeCount = mistakeRecordMapper.countByKnowledgePoint(
        mistake.getStudentId(), mistake.getKnowledgePointId());
    double frequencyBonus = Math.min(15, kpMistakeCount * 3);
    
    return Math.min(100, (overdueScore * severityMultiplier + frequencyBonus));
}
```

#### 4.3.2 知识价值度评分（KnowledgeValueScore）

基于知识点在课程体系中的重要性和考试频率：

```java
/**
 * 计算知识价值度 [0-100]
 */
public double calculateKnowledgeValue(MistakeRecord mistake) {
    KnowledgePoint kp = knowledgePointService.getById(mistake.getKnowledgePointId());
    
    // 1. 知识点重要性权重（来自知识点体系管理）
    double importance = kp.getImportanceScore(); // 0-1，由知识点管理服务维护
    
    // 2. 考试频率（该知识点在历年考试中出现频率）
    double examFrequency = kp.getExamFrequencyScore(); // 0-1
    
    // 3. 前置知识影响（该知识点是其他知识点前置的次数）
    int prerequisiteForCount = knowledgeGraphService.countPrerequisiteFor(kp.getId());
    double prerequisiteImpact = Math.min(1.0, prerequisiteForCount * 0.15);
    
    // 4. 综合计算
    return (importance * 40 + examFrequency * 35 + prerequisiteImpact * 25);
}
```

#### 4.3.3 多样性加成（DiversityBonus）

鼓励选择不同知识点、不同题型的题目：

```java
/**
 * 在选择过程中动态计算多样性加成
 * 已选集合中与当前题相似的越少，加成越高
 */
public double calculateDiversityBonus(
    ScoredMistake candidate,
    Set<Long> selectedKpIds,
    Map<String, Integer> selectedTypeCounts,
    int totalSelected
) {
    if (totalSelected == 0) return 100.0; // 第一道题满分
    
    // 知识点新颖度（0或100）
    double kpNovelty = selectedKpIds.contains(candidate.getKnowledgePointId()) ? 0 : 100;
    
    // 题型多样性
    int typeCount = selectedTypeCounts.getOrDefault(candidate.getQuestionType(), 0);
    double typeDiversity = Math.max(0, 100 - typeCount * 25);
    
    return kpNovelty * 0.6 + typeDiversity * 0.4;
}
```

#### 4.3.4 薄弱惩罚/奖励（WeaknessPenalty）

结合学生在该知识点上的整体表现：

```java
/**
 * 计算薄弱程度评分 [0-100]
 * 掌握度越低，分数越高（越应该选入错题卷）
 */
public double calculateWeaknessScore(ScoredMistake candidate) {
    // 1. 获取学生该知识点当前掌握度
    double mastery = knowledgeTrackingService.getMastery(
        candidate.getStudentId(), 
        candidate.getKnowledgePointId()
    );
    
    // 掌握度越低分数越高
    double masteryScore = (1.0 - mastery) * 100;
    
    // 2. 近期错误率
    double recentErrorRate = answerRecordService.getRecentErrorRate(
        candidate.getStudentId(),
        candidate.getKnowledgePointId(),
        30 // 最近30天
    );
    
    // 3. 加权
    return masteryScore * 0.7 + recentErrorRate * 100 * 0.3;
}
```

### 4.4 Phase 3: 约束满足选择

采用贪心算法在约束条件下选择最优子集：

```java
/**
 * 约束满足选择器
 * 使用改进的贪心算法，在满足约束的前提下选择总评分最高的子集
 */
public class ConstraintSelectionStrategy {
    
    // 约束参数
    private final int targetCount;
    private final DifficultyProfile difficultyProfile;
    private final int maxSameTypeStreak;
    private final int maxSameKpQuestions;
    
    public List<ScoredMistake> select(List<ScoredMistake> candidates) {
        List<ScoredMistake> selected = new ArrayList<>();
        Set<Long> selectedKpIds = new HashSet<>();
        Map<String, Integer> selectedTypeCounts = new HashMap<>();
        Map<Integer, Integer> difficultyCounts = new HashMap<>(); // 按难度计数
        Map<Long, Integer> kpCounts = new HashMap<>(); // 按知识点计数
        
        // 计算各难度目标数量
        int easyTarget = (int) Math.round(targetCount * difficultyProfile.getEasyRatio());
        int mediumTarget = (int) Math.round(targetCount * difficultyProfile.getMediumRatio());
        int hardTarget = targetCount - easyTarget - mediumTarget;
        
        // 按基础评分降序排列候选
        candidates.sort(Comparator.comparingDouble(
            (ScoredMistake m) -> m.getUrgencyScore() * 0.4 
                              + m.getKnowledgeValueScore() * 0.25 
                              + m.getWeaknessScore() * 0.2
        ).reversed());
        
        for (ScoredMistake candidate : candidates) {
            if (selected.size() >= targetCount) break;
            
            // --- 约束检查 ---
            
            // C1: 难度配额检查
            int diff = candidate.getDifficultyLevel();
            int diffBucket = diff <= 2 ? 1 : (diff <= 3 ? 2 : 3); // 1=easy, 2=medium, 3=hard
            int diffTarget = diffBucket == 1 ? easyTarget : (diffBucket == 2 ? mediumTarget : hardTarget);
            if (difficultyCounts.getOrDefault(diffBucket, 0) >= diffTarget) {
                // 该难度已满，但允许从其他难度调剂（容忍度±2）
                int currentTotal = selected.size();
                if (currentTotal < targetCount - 2) continue; // 还没到需要调剂的时候
            }
            
            // C2: 知识点数量限制
            if (kpCounts.getOrDefault(candidate.getKnowledgePointId(), 0) >= maxSameKpQuestions) {
                continue;
            }
            
            // C3: 同题型连续检查（查最后选择的题型）
            if (!selected.isEmpty()) {
                int consecutiveSameType = countTrailingSameType(selected, candidate.getQuestionType());
                if (consecutiveSameType >= maxSameTypeStreak) {
                    continue;
                }
            }
            
            // --- 计算动态评分（含多样性加成） ---
            double diversity = calculateDiversityBonus(
                candidate, selectedKpIds, selectedTypeCounts, selected.size()
            );
            double dynamicScore = candidate.getUrgencyScore() * 0.35
                               + candidate.getKnowledgeValueScore() * 0.20
                               + candidate.getWeaknessScore() * 0.15
                               + diversity * 0.15
                               + candidate.getKnowledgeValueScore() * 0.15; // 注意：重新加权
            
            candidate.setTotalScore(dynamicScore);
            
            // --- 选入 ---
            selected.add(candidate);
            selectedKpIds.add(candidate.getKnowledgePointId());
            selectedTypeCounts.merge(candidate.getQuestionType(), 1, Integer::sum);
            difficultyCounts.merge(diffBucket, 1, Integer::sum);
            kpCounts.merge(candidate.getKnowledgePointId(), 1, Integer::sum);
        }
        
        // 如果选不够，放宽约束再选一轮
        if (selected.size() < targetCount) {
            selected = relaxAndReselect(candidates, selected, targetCount);
        }
        
        return selected;
    }
    
    /**
     * 放宽约束重新选择（降级策略）
     */
    private List<ScoredMistake> relaxAndReselect(
        List<ScoredMistake> candidates, 
        List<ScoredMistake> alreadySelected,
        int target
    ) {
        Set<Long> alreadyIds = alreadySelected.stream()
            .map(ScoredMistake::getMistakeRecordId)
            .collect(Collectors.toSet());
        
        // 放宽: 允许更多同知识点题目、放宽题型连续限制
        List<ScoredMistake> remaining = candidates.stream()
            .filter(m -> !alreadyIds.contains(m.getMistakeRecordId()))
            .sorted(Comparator.comparingDouble(ScoredMistake::getTotalScore).reversed())
            .collect(Collectors.toList());
        
        for (ScoredMistake m : remaining) {
            if (selected.size() >= target) break;
            selected.add(m);
        }
        
        return selected;
    }
}
```

### 4.5 Phase 4: 变式题注入（MIXED模式）

```java
/**
 * 变式题注入器
 * 从题库中选取与已选错题同知识点但不同题目的新题
 */
public class VariantInjector {
    
    public List<Question> injectVariants(
        List<ScoredMistake> selectedMistakes,
        int variantCount,
        Long subjectId
    ) {
        List<Question> variants = new ArrayList<>();
        
        // 从已选错题中选取知识点重要度最高的若干个作为变式注入点
        Map<Long, List<ScoredMistake>> byKp = selectedMistakes.stream()
            .collect(Collectors.groupingBy(ScoredMistake::getKnowledgePointId));
        
        // 按知识点错误密度排序，密度高的优先注入变式
        List<Long> priorityKpIds = byKp.entrySet().stream()
            .sorted((a, b) -> b.getValue().size() - a.getValue().size())
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
        
        Set<Long> usedQuestionIds = selectedMistakes.stream()
            .map(ScoredMistake::getQuestionId)
            .collect(Collectors.toSet());
        
        for (Long kpId : priorityKpIds) {
            if (variants.size() >= variantCount) break;
            
            // 从题库查找同知识点、难度相近、学生未做过的题目
            int needed = variantCount - variants.size();
            List<Question> kpVariants = questionRepository.findSimilarQuestions(
                kpId,
                subjectId,
                usedQuestionIds,
                selectedMistakes.stream()
                    .filter(m -> m.getKnowledgePointId().equals(kpId))
                    .findFirst()
                    .map(ScoredMistake::getDifficultyLevel)
                    .orElse(3),
                needed
            );
            
            variants.addAll(kpVariants);
            usedQuestionIds.addAll(
                kpVariants.stream().map(Question::getId).collect(Collectors.toSet())
            );
        }
        
        return variants;
    }
}
```

### 4.6 Phase 5: 顺序编排

支持多种排序策略：

```java
/**
 * 试卷顺序编排器
 */
public class PaperArranger {
    
    /**
     * 按策略编排题目顺序
     */
    public List<PaperItem> arrange(
        List<ScoredMistake> mistakes,
        List<Question> variants,
        String strategy,
        boolean enableSectionGrouping
    ) {
        // 合并错题和变式题
        List<PaperItemData> allItems = mergeToItems(mistakes, variants);
        
        if (enableSectionGrouping) {
            // 按题型分组编排
            return arrangeBySection(allItems);
        }
        
        return switch (strategy) {
            case "DIFFICULTY_ESCALATION" -> arrangeByDifficultyAscending(allItems);
            case "KP_CLUSTER" -> arrangeByKnowledgeCluster(allItems);
            case "MISTAKE_CHRONOLOGICAL" -> arrangeByMistakeDate(allItems);
            default -> arrangeRandomly(allItems);
        };
    }
    
    /**
     * 按题型分组编排（默认策略）
     * 组内按难度递进排列
     * 组间按"客观题→主观题"顺序
     */
    private List<PaperItem> arrangeBySection(List<PaperItemData> items) {
        // 1. 定义题型优先级
        Map<String, Integer> typePriority = Map.of(
            "SINGLE_CHOICE", 1,
            "MULTI_CHOICE", 2,
            "TRUE_FALSE", 3,
            "FILL_BLANK", 4,
            "SHORT_ANSWER", 5,
            "ESSAY", 6,
            "PROOF", 7
        );
        
        // 2. 按题型分组
        Map<String, List<PaperItemData>> grouped = items.stream()
            .collect(Collectors.groupingBy(PaperItemData::getQuestionType));
        
        // 3. 组内按难度升序排列
        List<List<PaperItemData>> sortedGroups = grouped.entrySet().stream()
            .sorted(Comparator.comparingInt(
                e -> typePriority.getOrDefault(e.getKey(), 99)
            ))
            .peek(g -> g.getValue().sort(
                Comparator.comparingInt(PaperItemData::getDifficultyLevel)
            ))
            .map(Map.Entry::getValue)
            .collect(Collectors.toList());
        
        // 4. 生成题号和分节标签
        List<PaperItem> result = new ArrayList<>();
        int seqNo = 1;
        int sectionIndex = 1;
        
        for (List<PaperItemData> group : sortedGroups) {
            String sectionLabel = generateSectionLabel(sectionIndex, group.get(0).getQuestionType(), group.size());
            
            for (PaperItemData item : group) {
                PaperItem pi = new PaperItem();
                pi.setSeqNo(seqNo++);
                pi.setSectionLabel(sectionLabel);
                pi.setQuestionId(item.getQuestionId());
                pi.setSourceType(item.getSourceType());
                pi.setDifficultyLevel(item.getDifficultyLevel());
                pi.setKnowledgePointId(item.getKnowledgePointId());
                pi.setQuestionType(item.getQuestionType());
                pi.setEstimatedTimeSec(estimateTime(item));
                result.add(pi);
            }
            sectionIndex++;
        }
        
        return result;
    }
    
    private String generateSectionLabel(int index, String type, int count) {
        String[] chineseNum = {"一", "二", "三", "四", "五", "六", "七", "八"};
        String typeName = QUESTION_TYPE_NAMES.getOrDefault(type, "解答题");
        return String.format("%s、%s（共%d题）", 
            chineseNum[index - 1], typeName, count);
    }
    
    /**
     * 按难度递进排列
     */
    private List<PaperItem> arrangeByDifficultyAscending(List<PaperItemData> items) {
        items.sort(Comparator.comparingInt(PaperItemData::getDifficultyLevel));
        return assignSeqNumbers(items);
    }
    
    /**
     * 按知识点聚类排列
     */
    private List<PaperItem> arrangeByKnowledgeCluster(List<PaperItemData> items) {
        // 按知识点分组，组内按难度升序
        items.sort(Comparator
            .comparing(PaperItemData::getKnowledgePointId)
            .thenComparingInt(PaperItemData::getDifficultyLevel));
        return assignSeqNumbers(items);
    }
}
```

## 6. 关键业务流程

### 6.1 完整组卷编排流程

```java
/**
 * 错题卷生成主编排器
 */
@Service
public class MistakePaperGenerationOrchestrator {
    
    @Autowired private CandidatePoolBuilder poolBuilder;
    @Autowired private MistakeScoringService scoringService;
    @Autowired private ConstraintSelectionStrategy selectionStrategy;
    @Autowired private VariantInjector variantInjector;
    @Autowired private PaperArranger arranger;
    @Autowired private MistakePaperRepository paperRepository;
    @Autowired private PaperConfigService configService;
    @Autowired private EventPublisher eventPublisher;
    
    /**
     * 执行完整组卷流程
     */
    @Transactional
    public GeneratedPaper generate(PaperGenerationRequest request) {
        long startTime = System.currentTimeMillis();
        Long studentId = request.getStudentId();
        Long subjectId = request.getSubjectId();
        
        // 0. 加载策略配置
        PaperGenerationConfig config = configService.getConfig(studentId, subjectId);
        applyDefaults(request, config);
        
        // 1. 构建候选错题池
        List<ScoredMistake> candidates = poolBuilder.buildCandidatePool(request);
        
        if (candidates.size() < 5) {
            throw new PaperGenerationException(
                "ELIGIBLE_MISTAKES_INSUFFICIENT",
                String.format("符合条件错题仅%d道，至少需要5道才能组卷", candidates.size())
            );
        }
        
        // 2. 多维度评分
        for (ScoredMistake m : candidates) {
            m.setUrgencyScore(scoringService.calculateUrgencyScore(m));
            m.setKnowledgeValueScore(scoringService.calculateKnowledgeValue(m));
            m.setWeaknessScore(scoringService.calculateWeaknessScore(m));
        }
        
        // 3. 约束满足选择
        List<ScoredMistake> selected = selectionStrategy.select(candidates, request);
        
        // 4. 变式题注入（MIXED模式）
        List<Question> variants = List.of();
        if (request.getMode() == PaperMode.MIXED && request.getEnableVariants()) {
            int variantCount = (int) Math.round(
                request.getTargetCount() * request.getVariantRatio()
            );
            variants = variantInjector.injectVariants(selected, variantCount, subjectId);
        }
        
        // 5. 顺序编排
        List<PaperItem> arranged = arranger.arrange(
            selected, variants, request.getSortStrategy(), request.getEnableSectionGrouping()
        );
        
        // 6. 生成试卷标题
        String title = generateTitle(studentId, subjectId);
        
        // 7. 持久化
        GeneratedPaper paper = paperRepository.savePaper(
            title, arranged, selected, variants, request, config
        );
        
        // 8. 发布事件
        eventPublisher.publish(new PaperGeneratedEvent(
            paper.getPaperId(), studentId, subjectId, paper.getTotalQuestions()
        ));
        
        long elapsed = System.currentTimeMillis() - startTime;
        log.info("错题卷生成完成: studentId={}, paperId={}, questions={}, elapsed={}ms",
            studentId, paper.getPaperId(), paper.getTotalQuestions(), elapsed);
        
        return paper;
    }
    
    private String generateTitle(Long studentId, Long subjectId) {
        Subject subject = subjectService.getById(subjectId);
        String dateStr = LocalDate.now().format(
            DateTimeFormatter.ofPattern("M月d日")
        );
        return String.format("%s错题专练卷 · %s", subject.getName(), dateStr);
    }
}
```
