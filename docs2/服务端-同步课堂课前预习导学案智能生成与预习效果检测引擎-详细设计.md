# 服务端-同步课堂课前预习导学案智能生成与预习效果检测引擎 详细设计

## 1. 概述

### 1.1 模块定位

课前预习导学案智能生成与预习效果检测引擎是同步课堂学习模块的核心子服务之一。它负责在学生进入新章节学习之前，基于教材章节内容、知识点体系、学生当前学情画像，自动生成个性化预习导学案（含知识导读、重点词汇、基础概念、预习自测题），并在学生完成预习后检测预习效果，将检测结果反馈给后续课堂学习流编排服务，实现"预习→检测→课堂学习→课后复习"的完整学习闭环。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 预习导学案生成 | 根据章节知识点、教材内容、学生学情，生成结构化预习导学案 |
| 预习内容推送 | 将导学案推送到客户端，支持离线缓存 |
| 预习自测评估 | 生成预习检测题，评估学生预习效果 |
| 预习效果反馈 | 输出预习掌握度数据，驱动后续学习流编排 |
| 预习数据沉淀 | 记录预习行为数据，供学情分析和学习报告使用 |

### 1.3 依赖关系

```
┌─────────────────────────────────────────────────────────┐
│               课前预习导学案智能生成引擎                   │
├─────────────┬─────────────┬──────────────┬──────────────┤
│  章节内容    │  知识点体系   │  学生学情    │  AI大模型    │
│  聚合服务    │  管理服务     │  画像服务    │  调用服务    │
│  (上游)      │  (上游)      │  (上游)      │  (下游)      │
└─────────────┴─────────────┴──────────────┴──────────────┘
                         │
                         ▼
              ┌─────────────────────┐
              │  学习流编排服务      │
              │  (下游消费者)        │
              └─────────────────────┘
```

**上游依赖：**
- 同步课堂章节内容聚合服务：提供章节教材内容、知识结构
- 知识点体系管理服务：提供知识点定义、前置依赖关系
- 学生学情画像服务：提供当前掌握度、学习风格、认知水平
- AI Prompt 编排服务：提供大模型调用能力

**下游消费者：**
- 同步课堂学习流编排服务：接收预习效果数据，调整课堂学习路径
- 学情分析服务：消费预习行为数据
- 学习记录服务：记录预习完成情况
- 通知服务：发送预习提醒

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 PreviewGuide（预习导学案）

```typescript
interface PreviewGuide {
  id: string;                          // 导学案唯一ID (UUID)
  studentId: string;                   // 学生ID
  textbookVersionId: string;           // 教材版本ID
  subjectCode: string;                 // 学科编码 (e.g. "math", "chinese")
  gradeLevel: string;                  // 年级 (e.g. "grade_7")
  chapterId: string;                   // 章节ID
  lessonId?: string;                   // 课时ID (可选，精确到课时级别)
  guideType: GuideType;                // 导学案类型
  status: GuideStatus;                 // 生成状态
  sections: GuideSection[];            // 导学案各模块内容
  generatedAt: string;                 // 生成时间 (ISO 8601)
  expiredAt: string;                   // 过期时间 (章节学习完成后失效)
  modelVersion: string;                // 生成所用AI模型版本
  metadata: GuideMetadata;             // 元数据
}

type GuideType = 'STANDARD' | 'REINFORCED' | 'ADVANCED' | 'REVIEW';
// STANDARD: 标准预习导学案
// REINFORCED: 补强型预习 (针对薄弱基础)
// ADVANCED: 拔尖型预习 (针对学有余力)
// REVIEW: 复习型导学案 (章节复习场景)

type GuideStatus = 'GENERATING' | 'READY' | 'IN_PROGRESS' | 'COMPLETED' | 'EXPIRED' | 'FAILED';

interface GuideSection {
  sectionType: SectionType;
  title: string;
  content: string;                     // Markdown格式内容
  estimatedMinutes: number;            // 预计用时(分钟)
  order: number;                       // 排序
  interactions?: InteractionConfig;    // 交互配置
}

type SectionType =
  | 'KNOWLEDGE_OVERVIEW'    // 知识导读
  | 'KEY_VOCABULARY'        // 重点词汇/术语
  | 'BASIC_CONCEPTS'        // 基础概念
  | 'PREREQUISITE_REVIEW'   // 前置知识回顾
  | 'GUIDING_QUESTIONS'     // 导学思考题
  | 'PREVIEW_QUIZ'          // 预习自测题
  | 'REAL_WORLD_CONNECTION';// 生活化联系

interface GuideMetadata {
  knowledgePointIds: string[];         // 涉及知识点ID列表
  difficultyLevel: number;             // 难度等级 1-5
  bloomLevel: BloomLevel;              // 布鲁姆认知层级
  estimatedTotalMinutes: number;       // 预计总用时
  generatedBy: 'AI' | 'TEMPLATE' | 'HYBRID';
  promptTemplateId?: string;           // 使用的Prompt模板ID
  contentHash: string;                 // 内容哈希 (用于缓存/去重)
}

type BloomLevel = 'REMEMBER' | 'UNDERSTAND' | 'APPLY' | 'ANALYZE' | 'EVALUATE' | 'CREATE';
```

```typescript
interface PreviewQuiz {

  answer: string;                      // 正确答案
  explanation: string;                 // 答案解析
  difficulty: number;                  // 难度 1-5
  bloomLevel: BloomLevel;
  hint?: string;                       // 提示信息
}

type PreviewQuestionType =
  | 'SINGLE_CHOICE'       // 单选
  | 'MULTIPLE_CHOICE'     // 多选
  | 'TRUE_FALSE'          // 判断
  | 'FILL_BLANK'          // 填空
  | 'SHORT_ANSWER'        // 简答
  | 'CONCEPT_MATCH';      // 概念匹配
```

#### 2.1.3 PreviewResult（预习效果记录）

```typescript
interface PreviewResult {
  id: string;
  guideId: string;                     // 导学案ID
  studentId: string;
  chapterId: string;
  startedAt: string;                   // 开始时间
  completedAt?: string;                // 完成时间
  durationMinutes: number;             // 实际用时
  status: PreviewResultStatus;
  sectionProgress: SectionProgress[];  // 各模块完成情况
  quizResult?: QuizResult;             // 自测题结果
  masterySnapshot: MasterySnapshot;   // 预习后掌握度快照
  feedbackToLesson: LessonFeedback;    // 给课堂学习的反馈
  studentFeedback?: StudentFeedback;   // 学生主观反馈
}

type PreviewResultStatus = 'NOT_STARTED' | 'IN_PROGRESS' | 'COMPLETED' | 'ABANDONED';

interface SectionProgress {
  sectionType: SectionType;
  status: 'NOT_VIEWED' | 'VIEWED' | 'STUDIED' | 'SKIPPED';
  viewCount: number;
  timeSpentSeconds: number;
}

interface QuizResult {
  totalQuestions: number;
  correctCount: number;
  score: number;                       // 百分比
  passed: boolean;
  attemptCount: number;
  questionResults: QuestionResult[];
}

interface QuestionResult {
  questionId: string;
  studentAnswer: string;
  isCorrect: boolean;
  timeSpentSeconds: number;
}

interface MasterySnapshot {
  // 预习后各知识点掌握度 (0-1)
  knowledgePointMastery: Map<string, number>;
  // 整体预习掌握度
  overallMastery: number;
  // 预估认知层级
  achievedBloomLevel: BloomLevel;
}

interface LessonFeedback {
  // 推荐课堂学习起点
  recommendedStartPoint: 'BEGINNING' | 'KEY_CONCEPTS' | 'ADVANCED_TOPIC' | 'PRACTICE';
  // 识别到的共性薄弱点
  weakKnowledgePoints: string[];
  // 已掌握的知识点 (可跳过基础讲解)
  masteredKnowledgePoints: string[];
  // 建议课堂重点
  suggestedFocusAreas: string[];
  // 建议课堂难度
  suggestedDifficulty: number; // 1-5
}

interface StudentFeedback {
  difficultyRating: number;            // 难度评价 1-5
  helpfulRating: number;               // 有用程度 1-5
  comment?: string;                    // 文字反馈
}
```

### 2.3 缓存策略

| 缓存层 | Key 设计 | TTL | 用途 |
| --- | --- | --- | --- |
| Redis L1 | `pg:student:{studentId}:chapter:{chapterId}` | 2h | 学生当前导学案热数据 |
| Redis L2 | `pg:cache:hash:{contentHash}` | 24h | 相同参数导学案复用 |
| Redis L3 | `pg:result:{guideId}` | 7d | 预习结果热数据 |
| DB Cache | preview_guide_cache 表 | 30d | 跨学生导学案复用 |

**缓存复用策略：**
- 同一教材版本 + 同一年级 + 同一章节 + 同一导学案类型 → 可复用导学案内容
- 学生个性化部分（如难度适配）通过参数差异区分，不影响基础内容复用
- 当教材内容更新时，旧缓存自动失效（通过 content_hash 变化检测）

### 3.2 核心接口详细定义

#### 3.2.1 生成预习导学案

```
POST /api/v1/preview/guides
```

**请求体：**
```json
{
  "studentId": "stu_2026_00001",
  "chapterId": "ch_math_7a_ch3",
  "subjectCode": "math",
  "gradeLevel": "grade_7",
  "textbookVersionId": "tb_people_edition_v2024",
  "lessonId": "lesson_3_1",
  "guideType": "STANDARD",
  "forceRegenerate": false,
  "preferences": {
    "preferredLearningStyle": "VISUAL",
    "estimatedTimeMinutes": 15,
    "difficultyPreference": "AUTO"
  }
}
```

**响应（202 Accepted）：**
```json
{
  "code": 0,
  "data": {
    "guideId": "pg_a3f5e8d2_20260709",
    "status": "GENERATING",
    "estimatedWaitSeconds": 8,
    "callbackUrl": "/api/v1/preview/guides/pg_a3f5e8d2_20260709/status"
  }
}
```

**错误码：**

| 错误码 | 说明 | HTTP Status |
| --- | --- | --- |
| 40901 | 该章节导学案已存在且未过期 | 409 |
| 40902 | 章节内容尚未就绪（教材未配置） | 422 |
| 42901 | 生成频率超限 (同一章节5分钟内只能生成1次) | 429 |
| 50301 | AI模型服务不可用 | 503 |

```typescript
function determineGuideType(studentMastery: number, chapterDifficulty: number): GuideType {
  // studentMastery: 前置知识点平均掌握度 (0-1)
  // chapterDifficulty: 章节难度 (1-5)

  if (studentMastery < 0.4) {
    return GuideType.REINFORCED;  // 基础薄弱，生成补强型
  } else if (studentMastery > 0.85 && chapterDifficulty <= 3) {
    return GuideType.ADVANCED;    // 学有余力，生成拔尖型
  } else {
    return GuideType.STANDARD;    // 标准预习
  }
}
```

### 4.4 预习效果评估算法

#### 4.4.1 掌握度计算

```typescript
/**
 * 计算预习后各知识点掌握度
 * 综合考虑：自测题正确率 + 预习时长充分度 + 模块完成度
 */
function calculateMastery(
  quizResult: QuizResult,
  sectionProgress: SectionProgress[],
  knowledgePoints: KnowledgePoint[],
  estimatedMinutes: number
): MasterySnapshot {
  const knowledgePointMastery = new Map<string, number>();

  for (const kp of knowledgePoints) {
    // 1. 基于自测题的掌握度 (权重60%)
    const kpQuestions = quizResult.questionResults.filter(
      qr => getKnowledgePointForQuestion(qr.questionId) === kp.id
    );
    const quizMastery = kpQuestions.length > 0
      ? kpQuestions.filter(q => q.isCorrect).length / kpQuestions.length
      : 0.5; // 无题目关联时默认0.5

    // 2. 基于模块完成度的掌握度 (权重25%)
    const relatedSections = getSectionsForKnowledgePoint(kp.id, sectionProgress);
    const completionRate = relatedSections.length > 0
      ? relatedSections.filter(s => s.status === 'STUDIED').length / relatedSections.length
      : 0.5;

    // 3. 基于时间充分度的掌握度 (权重15%)
    const actualTime = sectionProgress.reduce((sum, s) => sum + s.timeSpentSeconds, 0) / 60;
    const timeRatio = Math.min(actualTime / estimatedMinutes, 1.5);
    const timeMastery = Math.min(timeRatio * 0.6, 1); // 时间充分但不超过1

    // 综合掌握度
    const mastery = quizMastery * 0.6 + completionRate * 0.25 + timeMastery * 0.15;
    knowledgePointMastery.set(kp.id, Math.round(mastery * 100) / 100);
  }

  const overallMastery = Array.from(knowledgePointMastery.values())
    .reduce((sum, v) => sum + v, 0) / knowledgePointMastery.size;

  const achievedBloomLevel = determineBloomLevel(quizResult, knowledgePoints);

  return {
    knowledgePointMastery,
    overallMastery,
    achievedBloomLevel,
  };
}
```
