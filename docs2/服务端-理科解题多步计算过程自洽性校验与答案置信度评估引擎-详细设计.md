# 服务端-理科解题多步计算过程自洽性校验与答案置信度评估引擎 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

理科解题多步计算过程自洽性校验与答案置信度评估引擎（以下简称 **CalcVerify Engine**）是 PrimeTop 理科解题链路中的**后置质量保障层**。它接收大模型生成的分步解析（含 LaTeX 公式、数值计算、单位标注），在不依赖标准答案库的前提下，对解析内部的**计算自洽性**、**单位一致性**、**逻辑连续性**进行自动化验证，并输出一个可指导下游决策的**置信度分数**。

该引擎核心价值：
- **拦截幻觉计算**：AI 在长篇推理中易出现抄错数字、运算符号错误、中间步骤遗漏等问题。
- **量化答案可信度**：为前端“是否直接展示答案”“是否提示‘仅供参考’”“是否触发人工复核”提供数据依据。
- **反哺模型优化**：将高频错误模式回流到 Prompt 优化和模型微调数据 pipeline。
- **降低合规风险**：对未成年人展示的内容增加一层客观校验。

### 1.2 适用范围

| 适用场景 | 说明 |
| --- | --- |
| 数学分步计算 | 方程、函数、数列、几何、概率统计等数值推导 |
| 物理力学/电磁学/热学/光学计算 | 含单位的公式代入、矢量运算、守恒量验证 |
| 化学方程式与物质的量计算 | 配平验证、摩尔比、浓度/质量换算 |
| 生物遗传概率计算 | 基因型比例、概率加法/乘法验证 |
| 跨步骤一致性校验 | 前一步变量值在后一步是否被正确使用 |

### 1.3 核心原则

1. **不依赖标准答案也能校验**：通过符号重算、量纲分析、守恒量验证发现明显错误。
2. **可解释**：每个置信度分数必须附带具体的验证项和异常点说明。
3. **快速失败友好**：当解析无法被结构化提取时，应标记为“无法验证”而非强行报错。
4. **安全执行**：数值计算必须在沙箱/受控环境中执行，禁止任意代码执行。
5. **与模型解耦**：校验失败不阻塞用户，仅作为风险提示和后续重试的触发条件。

### 1.4 与相关模块的关系

```text
理科解题引擎
    │
    ├── 题型识别 / 条件提取
    │
    ├── 大模型分步推理 ──→ 生成 LaTeX + 文字解析
    │                            │
    ▼                            ▼
CalcVerify Engine  ←── 接收 steps + 已知条件
    │
    ├── 结构化提取
    ├── 符号重算
    ├── 单位一致性检查
    ├── 跨步骤变量一致性检查
    └── 置信度评分
    │
    ▼
下游决策
    ├── 高分（≥0.85）→ 正常展示
    ├── 中分（0.60-0.84）→ 展示 + “请核对关键步骤”提示
    ├── 低分（<0.60）→ 触发二次求解 / 人工复核 / 标记“仅供参考”
    └── 错误模式 → 回流 AI 质量监控 / 模型训练数据
```

## 5. 关键代码示例

### 5.1 LaTeX 公式解析与数值提取

```python
import re
from dataclasses import dataclass, field
from typing import Optional, List

@dataclass
class ExtractedFormula:
    latex: str
    lhs: str                          # 左侧表达式（如 H）
    rhs: str                          # 右侧计算表达式（如 10**2 / (2 * 9.8)）
    expected_value: Optional[str] = None
    unit: Optional[str] = None
    is_equality: bool = True

LATEX_NUMBER_RE = re.compile(
    r"(?<![a-zA-Z_])(-?\d+\.?\d*(?:[eE][+-]?\d+)?)(?![a-zA-Z_])"
)

UNICODE_GREEK = {
    "θ": "theta", "α": "alpha", "β": "beta", "γ": "gamma",
    "°": "deg", "π": "pi", "²": "**2", "³": "**3",
    "₀": "_0", "₁": "_1", "₂": "_2", "ₓ": "_x", "ᵧ": "_y"
}


def latex_to_evaluable(latex: str, known_vars: dict) -> str:
    """
    将简单 LaTeX 公式转换为可在安全计算环境中执行的表达式。
    注意：仅处理常见代数/数值表达式，复杂积分/矩阵等返回 None。
    """
    # 1. 替换常见运算符
    expr = latex
    expr = expr.replace("\\times", "*").replace("\\cdot", "*")
    expr = expr.replace("\\div", "/").replace("\\frac", "")
    expr = expr.replace("\\", "")           # 简化：去掉转义反斜杠
    expr = expr.replace("^", "**")
    expr = expr.replace("{", "").replace("}", "")
    expr = expr.replace(" ", "")
    
    # 2. 替换希腊字母和特殊符号
    for k, v in UNICODE_GREEK.items():
        expr = expr.replace(k, v)
    
    # 3. 替换已知变量值（优先使用精确值）
    for symbol, value in known_vars.items():
        # 防止部分匹配，使用 token 边界
        pattern = r"(?<![a-zA-Z0-9_])" + re.escape(symbol) + r"(?![a-zA-Z0-9_])"
        expr = re.sub(pattern, str(value), expr)
    
    # 4. 去除单位标注（如 \\text{m}）
    expr = re.sub(r"text\{[^}]+\}", "", expr)
    expr = re.sub(r"[a-zA-Z]+\{[^}]+\}", "", expr)
    
    # 5. 清理残留字母（保留数字、运算符、括号）
    # 如果仍有未知字母变量，说明无法完全代入
    if re.search(r"[a-zA-Z_]", expr):
        return None
    
    return expr


def extract_formula_from_step(step: dict) -> List[ExtractedFormula]:
    """从解题步骤中提取可验证的等式。"""
    formulas = []
    for idx, f in enumerate(step.get("formulas", [])):
        latex = f.get("latex", "")
        # 简单拆分：按等号分为左侧和右侧
        if "=" not in latex:
            continue
        parts = latex.split("=")
        lhs = parts[0].strip()
        # 右侧可能包含多个等号，取最后一个（通常是最终数值）
        rhs = parts[-1].strip()
        # 从 rhs 中尝试提取数值和单位
        value_match = re.search(r"(-?\d+\.?\d*)", rhs)
        expected_value = value_match.group(1) if value_match else None
        unit_match = re.search(r"\\text\{([^}]+)\}", rhs)
        unit = unit_match.group(1) if unit_match else f.get("unit")
        
        formulas.append(ExtractedFormula(
            latex=latex,
            lhs=lhs,
            rhs=rhs,
            expected_value=expected_value,
            unit=unit,
        ))
    return formulas
```

### 5.2 安全数值计算沙箱

```python
import ast
import operator
from decimal import Decimal, InvalidOperation
from typing import Union

# 允许的安全节点和运算符
SAFE_NODES = (
    ast.Expression, ast.BinOp, ast.UnaryOp, ast.Num, ast.Constant,
    ast.Add, ast.Sub, ast.Mult, ast.Div, ast.Pow, ast.USub, ast.UAdd
)

SAFE_OPERATORS = {
    ast.Add: operator.add,
    ast.Sub: operator.sub,
    ast.Mult: operator.mul,
    ast.Div: operator.truediv,
    ast.Pow: operator.pow,
    ast.USub: operator.neg,
    ast.UAdd: operator.pos,
}


def safe_eval(expr: str) -> Union[float, int, None]:
    """
    在纯 Python AST 层面执行安全数值表达式计算。
    禁止函数调用、属性访问、变量名等。
    """
    try:
        tree = ast.parse(expr, mode="eval")
    except SyntaxError:
        return None
    
    for node in ast.walk(tree):
        if not isinstance(node, SAFE_NODES):
            return None
    
    def _eval(node):
        if isinstance(node, ast.Constant):
            if isinstance(node.value, (int, float)):
                return node.value
            return None
        if isinstance(node, ast.Num):  # py<3.8
            return node.n
        if isinstance(node, ast.BinOp):
            op_type = type(node.op)
            if op_type not in SAFE_OPERATORS:
                return None
            return SAFE_OPERATORS[op_type](_eval(node.left), _eval(node.right))
        if isinstance(node, ast.UnaryOp):
            op_type = type(node.op)
            if op_type not in SAFE_OPERATORS:
                return None
            return SAFE_OPERATORS[op_type](_eval(node.operand))
        return None
    
    try:
        result = _eval(tree.body)
        if result is None:
            return None
        # 避免极大或极小数值导致溢出
        if abs(result) > 1e308 or (isinstance(result, float) and abs(result) < 1e-308 and result != 0):
            return None
        return result
    except (ZeroDivisionError, OverflowError, ValueError, InvalidOperation):
        return None
```

### 5.3 单位一致性校验

```python
from typing import Dict, Optional
from dataclasses import dataclass

@dataclass
class UnitDimension:
    """量纲：用基本物理量的指数表示。"""
    m: int = 0   # 长度
    kg: int = 0  # 质量
    s: int = 0   # 时间
    A: int = 0   # 电流
    K: int = 0   # 温度
    mol: int = 0 # 物质的量
    cd: int = 0  # 发光强度

UNIT_DIMENSIONS = {
    "m": UnitDimension(m=1),
    "s": UnitDimension(s=1),
    "kg": UnitDimension(kg=1),
    "N": UnitDimension(m=1, kg=1, s=-2),
    "J": UnitDimension(m=2, kg=1, s=-2),
    "W": UnitDimension(m=2, kg=1, s=-3),
    "Pa": UnitDimension(m=-1, kg=1, s=-2),
    "m/s": UnitDimension(m=1, s=-1),
    "m/s^2": UnitDimension(m=1, s=-2),
    "kg/m^3": UnitDimension(m=-3, kg=1),
    "C": UnitDimension(A=1, s=1),
    "V": UnitDimension(m=2, kg=1, s=-3, A=-1),
    "Ω": UnitDimension(m=2, kg=1, s=-3, A=-2),
    "mol": UnitDimension(mol=1),
}


def parse_unit(unit_str: str) -> Optional[UnitDimension]:
    """解析单位字符串，返回量纲。支持简单乘除幂次。"""
    if not unit_str:
        return None
    unit_str = unit_str.strip()
    if unit_str in UNIT_DIMENSIONS:
        return UNIT_DIMENSIONS[unit_str]
    # 简易解析：如 m/s^2, kg·m/s^2
    # 生产环境应使用 sympy.physics.units 或 pint
    return None


def check_formula_unit_consistency(
    lhs_unit: str,
    rhs_unit: str,
) -> tuple[bool, Optional[str]]:
    """检查等式两侧单位是否一致（量纲相同）。"""
    lhs_dim = parse_unit(lhs_unit)
    rhs_dim = parse_unit(rhs_unit)
    if lhs_dim is None or rhs_dim is None:
        return True, "单位未识别，跳过校验"
    if lhs_dim == rhs_dim:
        return True, None
    return False, f"量纲不匹配：左侧 {lhs_unit}，右侧 {rhs_unit}"


def check_numerical_unit(
    value: float,
    expected_unit: str,
    expression_unit: str,
) -> tuple[bool, Optional[str]]:
    """检查数值结果单位是否与表达式单位一致。"""
    expected_dim = parse_unit(expected_unit)
    expr_dim = parse_unit(expression_unit)
    if expected_dim is None or expr_dim is None:
        return True, "单位未识别，跳过校验"
    if expected_dim != expr_dim:
        return False, f"结果单位 {expected_unit} 与表达式量纲 {expression_unit} 不一致"
    return True, None
```

### 5.4 跨步骤变量一致性校验

```python
from dataclasses import dataclass
from typing import List, Dict, Tuple

@dataclass
class VariableSnapshot:
    symbol: str
    value: float
    unit: str
    step_index: int
    source: str  # declared / calculated / reused


def check_cross_step_consistency(
    steps: List[dict],
    tolerance: float = 0.05,
) -> Tuple[float, List[dict]]:
    """
    检查变量在后续步骤中是否被正确使用。
    返回一致性分数和异常列表。
    """
    declared: Dict[str, VariableSnapshot] = {}
    issues = []
    
    for step in steps:
        step_idx = step["stepIndex"]
        
        # 1. 记录本步骤声明/计算出的变量
        for var in step.get("variables", []):
            try:
                val = float(var["value"])
            except (ValueError, TypeError):
                continue
            symbol = var["symbol"]
            declared[symbol] = VariableSnapshot(
                symbol=symbol,
                value=val,
                unit=var.get("unit", ""),
                step_index=step_idx,
                source=var.get("source", "calculated"),
            )
        
        # 2. 检查公式中使用的变量值是否与声明一致
        for f_idx, formula in enumerate(step.get("formulas", [])):
            latex = formula.get("latex", "")
            # 提取等式右侧使用的符号（简化实现）
            for symbol, snapshot in declared.items():
                if symbol not in latex:
                    continue
                # 查找公式中该符号附近是否有数值使用
                # 例如：R = v_{0x} * T = 17.3 * 2.04
                # 这里检查是否使用了近似值而非声明值
                nearby = _extract_numeric_near_symbol(latex, symbol)
                if nearby is None:
                    continue
                deviation = abs(nearby - snapshot.value) / max(abs(snapshot.value), 1e-9)
                if deviation > tolerance:
                    issues.append({
                        "stepIndex": step_idx,
                        "formulaIndex": f_idx,
                        "symbol": symbol,
                        "declaredValue": snapshot.value,
                        "usedValue": nearby,
                        "deviation": deviation,
                        "severity": "medium" if deviation > 0.1 else "low",
                        "message": f"步骤 {step_idx} 使用了与声明不一致的 {symbol} 值"
                    })
    
    # 分数：无异常 1.0，每出现一个 low 扣 0.05，medium 扣 0.15
    score = max(0.0, 1.0 - len([i for i in issues if i["severity"] == "low"]) * 0.05
                      - len([i for i in issues if i["severity"] == "medium"]) * 0.15)
    return score, issues


def _extract_numeric_near_symbol(latex: str, symbol: str) -> Optional[float]:
    """在符号附近提取被使用的数值（简化：取等号后第一个数字）。"""
    # 实际生产应使用更精确的 AST 解析
    parts = latex.split("=")
    if len(parts) < 2:
        return None
    rhs = parts[-1]
    match = re.search(r"(-?\d+\.?\d*)", rhs)
    if match:
        return float(match.group(1))
    return None
```

### 5.5 置信度聚合

```python
from dataclasses import dataclass, field
from typing import List

@dataclass
class WeightedCheck:
    check_type: str
    score: float
    weight: float
    is_available: bool


def aggregate_confidence(
    checks: List[WeightedCheck],
    subject: str,
) -> float:
    """
    按学科动态调整权重，聚合各检查项得分。
    """
    # 默认权重
    weights = {
        "latex_parse": 0.10,
        "numerical_recompute": 0.30,
        "unit_consistency": 0.15,
        "dimensional_analysis": 0.15,
        "cross_step_variable": 0.15,
        "answer_match": 0.10,
        "chemistry_balance": 0.15,
        "probability_sum": 0.10,
        "conservation_law": 0.15,
    }
    
    # 学科特化：化学强化配平，数学强化数值重算，物理强化量纲
    subject_bias = {
        "math": {"numerical_recompute": 0.40, "cross_step_variable": 0.20},
        "physics": {"dimensional_analysis": 0.25, "conservation_law": 0.20},
        "chemistry": {"chemistry_balance": 0.30, "unit_consistency": 0.20},
        "biology": {"probability_sum": 0.25, "numerical_recompute": 0.20},
    }
    
    bias = subject_bias.get(subject, {})
    for k, v in bias.items():
        weights[k] = v
    
    total_weight = 0.0
    weighted_sum = 0.0
    for check in checks:
        if not check.is_available:
            continue
        w = weights.get(check.check_type, 0.1)
        weighted_sum += check.score * w
        total_weight += w
    
    if total_weight == 0:
        return 0.0
    return round(weighted_sum / total_weight, 3)


def decide_verdict(confidence: float, has_fatal_issue: bool) -> str:
    """根据置信度和是否存在致命问题给出裁决。"""
    if has_fatal_issue:
        return "FAIL"
    if confidence >= 0.90:
        return "PASS"
    if confidence >= 0.70:
        return "PASS_WITH_CAUTION"
    if confidence >= 0.50:
        return "NEED_REVIEW"
    return "FAIL"
```

### 5.6 主校验流程编排

```python
import asyncio
from typing import Optional

class CalcVerifyEngine:
    def __init__(self, config: VerifyConfig):
        self.config = config
        self.latex_parser = LatexParser()
        self.safe_evaluator = SafeEvaluator()
        self.unit_checker = UnitChecker()
        self.cross_step_checker = CrossStepChecker()
    
    async def verify(self, request: CalcVerifyRequest) -> CalcVerifyResult:
        start = time.monotonic()
        checks = []
        issues = []
        
        # 1. LaTeX 解析
        parse_ok, parse_count, parse_total = self.latex_parser.parse_steps(
            request.solutionSteps
        )
        checks.append(WeightedCheck(
            check_type="latex_parse",
            score=parse_count / parse_total if parse_total else 0.0,
            weight=0.1,
            is_available=True,
        ))
        
        # 2. 数值重算
        recompute_score, recompute_issues = await self._recompute_numerical_steps(
            request.solutionSteps,
            request.structuredConditions,
            request.options.tolerance,
        )
        checks.append(WeightedCheck(
            check_type="numerical_recompute",
            score=recompute_score,
            weight=0.3,
            is_available=True,
        ))
        issues.extend(recompute_issues)
        
        # 3. 单位一致性
        if request.options.enableUnitCheck:
            unit_score, unit_issues = self.unit_checker.check_steps(
                request.solutionSteps
            )
            checks.append(WeightedCheck(
                check_type="unit_consistency",
                score=unit_score,
                weight=0.15,
                is_available=True,
            ))
            issues.extend(unit_issues)
        
        # 4. 量纲分析
        if request.options.enableDimensionalCheck and request.subject in ("physics", "chemistry"):
            dim_score, dim_issues = self.unit_checker.check_dimensional(
                request.solutionSteps
            )
            checks.append(WeightedCheck(
                check_type="dimensional_analysis",
                score=dim_score,
                weight=0.15,
                is_available=True,
            ))
            issues.extend(dim_issues)
        
        # 5. 跨步骤变量一致性
        if request.options.enableCrossStepCheck:
            cross_score, cross_issues = self.cross_step_checker.check(
                request.solutionSteps,
                request.options.tolerance,
            )
            checks.append(WeightedCheck(
                check_type="cross_step_variable",
                score=cross_score,
                weight=0.15,
                is_available=True,
            ))
            issues.extend(cross_issues)
        
        # 6. 答案匹配（可选）
        if request.expectedAnswer:
            answer_score, answer_issues = self._check_answer_match(
                request.solutionSteps,
                request.expectedAnswer,
                request.options.tolerance,
            )
            checks.append(WeightedCheck(
                check_type="answer_match",
                score=answer_score,
                weight=0.1,
                is_available=True,
            ))
            issues.extend(answer_issues)
        
        # 7. 聚合
        confidence = aggregate_confidence(checks, request.subject)
        has_fatal = any(i["severity"] == "fatal" for i in issues)
        verdict = decide_verdict(confidence, has_fatal)
        
        duration_ms = int((time.monotonic() - start) * 1000)
        
        return CalcVerifyResult(
            verifyId=request.verifyId,
            solveId=request.solveId,
            overallConfidence=confidence,
            status="VERIFIED",
            verdict=verdict,
            durationMs=duration_ms,
            checks=[c.to_dict() for c in checks],
            recommendedAction=self._action_from_verdict(verdict),
            issues=issues,
        )
```

## 7. 错误处理

### 7.1 业务错误码

| 错误码 | 场景 | 处理策略 |
| --- | --- | --- |
| `CALC_VERIFY_LATEX_PARSE_FAILED` | 公式无法解析 | 返回 INCONCLUSIVE，建议人工复核 |
| `CALC_VERIFY_SAFE_EVAL_TIMEOUT` | 计算表达式超时（>3s） | 跳过该表达式，不影响其他检查 |
| `CALC_VERIFY_UNIT_UNKNOWN` | 遇到未定义单位 | 标记该检查项不可用，不扣分 |
| `CALC_VERIFY_DIMENSION_MISMATCH` | 量纲不匹配（fatal） | verdict=FAIL，触发二次求解 |
| `CALC_VERIFY_CROSS_STEP_FATAL` | 关键变量前后不一致 | verdict=FAIL，触发二次求解 |
| `CALC_VERIFY_ANSWER_MISMATCH` | 最终答案与期望答案差异大 | verdict=FAIL，触发人工复核 |
| `CALC_VERIFY_SANDBOX_ERROR` | 计算沙箱异常 | 返回 INCONCLUSIVE，记录告警 |

### 7.2 降级策略

| 场景 | 降级方案 |
| --- | --- |
| 解析器不可用 | 跳过 LaTeX 解析，仅做文本层数值匹配 |
| 单位库未识别 | 跳过单位/量纲检查，依赖数值重算 |
| 跨步骤变量过多 | 仅检查关键变量（如最终答案相关变量） |
| 计算沙箱超时 | 标记该步骤不可验证，降低权重 |
| 期望答案缺失 | 关闭 answer_match 检查，其余检查正常进行 |
| 引擎整体超时 | 返回 INCONCLUSIVE，走默认展示策略 |

## 8. 性能与成本

### 8.3 成本控制

- 校验引擎不调用大模型，纯本地规则/符号计算，成本极低。
- 复杂符号计算（如高阶方程、矩阵）可降级到轻量数值计算，避免引入 CAS 服务。
- 批量验证用于模型评测时，使用离线任务队列，避免占用在线资源。

## 9. 安全与合规

1. **计算沙箱**：禁止 `eval` / `exec`，仅允许 AST 白名单节点。
2. **输入长度限制**：单条 LaTeX 不超过 2KB，单次请求不超过 50 个公式。
3. **超时控制**：单个表达式计算不超过 3s，整体请求不超过 10s。
4. **资源隔离**：批量任务与在线请求使用不同线程池。
5. **未成年人保护**：对 verdict=FAIL 的内容，前端默认不展示最终答案，避免错误信息误导。

## 11. 测试要点

### 11.1 单元测试矩阵

| 场景 | 输入 | 预期 |
| --- | --- | --- |
| 正确数学计算 | 一元二次方程求解 | confidence ≥ 0.90，verdict PASS |
| 符号错误 | 中间步骤把 + 写成 - | confidence < 0.60，verdict FAIL |
| 单位错误 | 力的单位写成 m/s | verdict FAIL |
| 量纲错误 | v = F/m | verdict FAIL |
| 跨步骤抄错数 | 上一步 v0=20，下一步用 10 | verdict FAIL |
| 四舍五入差异 | 使用 17.3 而非 17.32 | PASS_WITH_CAUTION |
| 化学方程式未配平 | H2 + O2 → H2O | verdict FAIL |
| 概率分布和不为 1 | 0.3 + 0.4 + 0.2 | verdict FAIL |
| 守恒量验证 | 动量守恒计算 | 检查通过 |
| 无法解析的 LaTeX | 含矩阵 / 积分 | INCONCLUSIVE，不崩溃 |

### 11.2 边界场景

1. 中间步骤结果为空字符串。
2. 公式中没有等号。
3. 数值极大或极小（1e-10 / 1e10）。
4. 单位包含复合单位（kg·m/s²）。
5. 变量名重复（如不同步骤都使用 t 但含义不同）。
6. 多解情况（数学方程两个根）。
7. 角度单位 deg / rad 混淆。
