## 1. 模块概述

### 1.1 模块定位

教育内容多媒体转码处理与自适应码率流媒体分发服务（以下简称「媒体处理服务」）是 PrimeTop 服务端的统一媒体基础设施层。它负责将运营/教师/教研人员上传的原始视频、音频、动画等教学媒体资源，经过标准化转码、多码率生成、加密处理、CDN 分发等环节，最终以自适应流的形式供客户端按需拉取播放。

本服务是客户端「多媒体内容播放与交互引擎」的服务端对等模块——客户端负责"怎么播"，本服务负责"怎么存、怎么转、怎么发"。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 多格式入站 | 支持 MP4、MOV、AVI、MKV、MP3、WAV、FLAC、PPT/PPTX 等常见格式的原始上传 |
| 标准化转码 | 统一输出 HLS（.m3u8 + .ts）+ DASH（.mpd）双协议，视频编码 H.264/H.265，音频编码 AAC |
| 多码率自适应 | 每个视频资源自动生成 3-5 个清晰度档位（240p / 360p / 480p / 720p / 1080p），支持 ABR 无缝切换 |
| 低延迟首帧 | 首帧时间 < 2s（WiFi / 4G+），通过 CDN 边缘缓存 + 分片预加载实现 |
| 播放安全 | 支持 DRM 加密（Widevine L1 / FairPlay DRM）与 Token 鉴权防盗链，防止教育资源盗播 |
| 成本可控 | 转码任务按优先级调度，非高峰期批量处理；CDN 按区域 + 流量套餐优化 |
| 高可用 | 转码节点故障自动重试，转码幂等，CDN 多供应商容灾切换 |
| 可观测 | 转码全链路追踪、播放质量监控（QoE 指标采集）、成本归集分析 |

### 1.3 使用场景矩阵

| 场景 | 媒体类型 | 典型时长 | 转码策略 | 分发策略 |
| --- | --- | --- | --- | --- |
| 同步课堂视频课 | 视频 | 10-30 min | 多码率 HLS + 加密 | CDN 边缘缓存 |
| 知识点微课 | 视频 | 1-5 min | 多码率 HLS + 加密 | CDN + 客户端预加载 |
| 英语听力音频 | 音频 | 5-20 min | 多码率 AAC + 逐句切片 | CDN + 离线下载 |
| 课文朗读示范 | 音频 | 1-10 min | AAC 标准编码 | CDN + 离线下载 |
| 物理实验动画 | 动画 (Lottie/序列帧) | 30s-2min | 原格式优化 + 预渲染首帧 | CDN 静态资源 |
| 化学分子3D模型 | 3D (GLTF) | - | 压缩优化 + LOD 分级 | CDN 静态资源 |
| 拼音识字发音音频 | 音频 | 3-10s | AAC 高质量编码 | CDN + 客户端预缓存 |
| 教师板书录屏 | 视频 | 5-20 min | 多码率 HLS | CDN |

### 1.4 术语约定

| 术语 | 含义 |
| --- | --- |
| Asset | 一个完整的媒体资源（如一个视频文件），对应唯一的 asset_id |
| Rendition | Asset 的一个特定码率/分辨率版本（如 720p 版本） |
| Segment | HLS/DASH 流的一个分片文件（如 10s 的 .ts 文件） |
| Manifest | HLS 的 .m3u8 或 DASH 的 .mpd 播放列表文件 |
| Job | 一次转码任务 |
| Pipeline | 转码流水线，包含多个有序的转码阶段 |
| Master Playlist | 主播放列表，包含所有可选清晰度的子播放列表 |

### 2.2 核心组件说明

| 组件 | 职责 | 技术选型 |
| --- | --- | --- |
| UploadManager | 接收原始文件上传，分片写入对象存储，计算文件指纹 | Go + MinIO SDK |
| TranscodeOrchestrator | 转码任务调度，优先级管理，失败重试，幂等控制 | Go + Redis + PostgreSQL |
| TranscodeWorker | 实际执行 FFmpeg 转码命令的 Worker 节点 | Go + FFmpeg 6.x / GPU 加速 |
| PackagingService | 将转码产物封装为 HLS/DASH 格式，生成 Manifest 文件 | Go + FFmpeg |
| DRMService | DRM 密钥管理，Widevine/FairPlay 授权代理 | Go + Shaka Packager |
| DistributionManager | CDN 刷新/预热/回源配置管理 | Go + CDN API |
| QualityMonitor | 播放质量数据采集，QoE 分析，告警 | Go + ClickHouse |

## 3. 数据结构定义

### 3.1 PostgreSQL 表设计

#### 3.1.1 `media_assets` — 媒体资源主表

```sql
CREATE TABLE media_assets (
    asset_id          VARCHAR(36)   PRIMARY key DEFAULT uuid_generate_v4(),
    business_type     VARCHAR(32)   NOT NULL,  -- VIDEO_COURSE, MICRO_LESSON, LISTENING_AUDIO, RECITATION_DEMO, ANIMATION, BOARD_RECORDING, PRONUNCIATION_AUDIO
    source_filename   VARCHAR(512)  NOT NULL,  -- 原始文件名
    source_format     VARCHAR(16)   NOT NULL,  -- mp4, mov, mp3, wav, pptx ...
    source_size_bytes BIGINT        NOT NULL,  -- 原始文件大小
    source_sha256     VARCHAR(64)   NOT NULL,  -- 原始文件 SHA-256 指纹（用于去重）
    source_storage_key VARCHAR(512) NOT NULL,  -- 对象存储 Key（原始文件）
    
    -- 探测信息
    duration_ms       BIGINT        NOT NULL,  -- 时长（毫秒）
    width             INT,                     -- 视频宽度（px），音频为 NULL
    height            INT,                     -- 视频高度（px）
    fps               DECIMAL(6,2),             -- 帧率
    video_codec       VARCHAR(32),              -- 视频编码（h264, h265, vp9 ...）
    audio_codec       VARCHAR(32),              -- 音频编码（aac, mp3, flac ...）
    audio_channels    INT,                      -- 音频声道数
    audio_sample_rate INT,                      -- 音频采样率（Hz）
    bitrate_bps       BIGINT,                   -- 总码率（bps）
    
    -- 状态管理
    status            VARCHAR(24)   NOT NULL DEFAULT 'UPLOADED',  -- 见状态机
    status_message    TEXT,                     -- 状态描述/错误信息
    priority          INT           NOT NULL DEFAULT 5,  -- 1(最高) ~ 10(最低)
    
    -- 加密/DRM
    drm_scheme        VARCHAR(16),              -- WIDEVINE, FAIRPLAY, NONE
    content_key_id    VARCHAR(64),              -- DRM Content Key ID
    
    -- 发布信息
    is_published      BOOLEAN       NOT NULL DEFAULT FALSE,
    published_at      TIMESTAMPTZ,
    cdn_domain        VARCHAR(256),             -- CDN 分发域名
    master_playlist_url VARCHAR(512),           -- Master Playlist URL
    thumbnail_url     VARCHAR(512),             -- 封面图 URL
    
    -- 归属
    owner_id          VARCHAR(36),              -- 上传者 ID
    textbook_chapter_id VARCHAR(36),            -- 关联教材章节（可选）
    subject_code      VARCHAR(16),              -- 关联学科（可选）
    grade_code        VARCHAR(16),              -- 关联年级（可选）
    
    -- 元数据
    metadata          JSONB        NOT NULL DEFAULT '{}',  -- 扩展字段
    
    -- 时间戳
    created_at        TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at        TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    
    CONSTRAINT uq_source_sha256 UNIQUE (source_sha256)
);

CREATE INDEX idx_assets_status ON media_assets(status) WHERE status != 'ARCHIVED';
CREATE INDEX idx_assets_business ON media_assets(business_type, is_published);
CREATE INDEX idx_assets_chapter ON media_assets(textbook_chapter_id) WHERE textbook_chapter_id IS NOT NULL;
CREATE INDEX idx_assets_owner ON media_assets(owner_id, created_at DESC);
```

#### 3.1.2 `media_renditions` — 码率版本表

```sql
CREATE TABLE media_renditions (
    rendition_id    VARCHAR(36)   PRIMARY KEY DEFAULT uuid_generate_v4(),
    asset_id        VARCHAR(36)   NOT NULL REFERENCES media_assets(asset_id) ON DELETE CASCADE,
    profile_name    VARCHAR(32)   NOT NULL,  -- 240p, 360p, 480p, 720p, 1080p, AUDIO_ONLY
    container       VARCHAR(16)   NOT NULL,  -- HLS, DASH, MP4
    video_codec     VARCHAR(32),             -- h264, h265
    video_bitrate   INT,                     -- 视频码率（kbps）
    video_width     INT,
    video_height    INT,
    video_framerate DECIMAL(6,2),
    audio_codec     VARCHAR(32),             -- aac
    audio_bitrate   INT,                     -- 音频码率（kbps）
    audio_channels  INT,
    audio_sample_rate INT,
    
    storage_key     VARCHAR(512)  NOT NULL,  -- 对象存储 Key（转码产物）
    playlist_url    VARCHAR(512),            -- 子 Playlist URL（HLS）
    segment_count   INT,                     -- 分片数量
    segment_duration_sec DECIMAL(8,2),       -- 每片时长（秒）
    total_size_bytes BIGINT,                 -- 该版本总大小
    
    status          VARCHAR(24)  NOT NULL DEFAULT 'PENDING', -- PENDING, TRANSCODING, PACKAGED, FAILED, ARCHIVED
    status_message  TEXT,
    
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    
    UNIQUE(asset_id, profile_name, container)
);

CREATE INDEX idx_renditions_asset ON media_renditions(asset_id);
CREATE INDEX idx_renditions_status ON media_renditions(status);
```

#### 3.1.3 `media_transcode_jobs` — 转码任务表

```sql
CREATE TABLE media_transcode_jobs (
    job_id          VARCHAR(36)   PRIMARY KEY DEFAULT uuid_generate_v4(),
    asset_id        VARCHAR(36)   NOT NULL REFERENCES media_assets(asset_id),
    rendition_id    VARCHAR(36)   REFERENCES media_renditions(rendition_id),
    
    stage           VARCHAR(32)   NOT NULL,  -- PROBE, TRANSCODE_VIDEO, TRANSCODE_AUDIO, PACKAGE, ENCRYPT, SCREENSHOT, DISTRIBUTE
    stage_status    VARCHAR(24)   NOT NULL DEFAULT 'QUEUED', -- QUEUED, RUNNING, SUCCESS, FAILED, SKIPPED, RETRY
    
    worker_node     VARCHAR(64),             -- 执行 Worker 节点标识
    command         TEXT,                    -- 实际执行的 FFmpeg 命令（审计）
    output_key      VARCHAR(512),            -- 产物存储 Key
    
    retry_count     INT          NOT NULL DEFAULT 0,
    max_retries     INT          NOT NULL DEFAULT 3,
    
    queued_at       TIMESTAMPTZ,
    started_at      TIMESTAMPTZ,
    finished_at     TIMESTAMPTZ,
    duration_ms     BIGINT,                  -- 执行耗时
    
    error_code      VARCHAR(32),
    error_message   TEXT,
    
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_jobs_asset ON media_transcode_jobs(asset_id, stage, stage_status);
CREATE INDEX idx_jobs_status ON media_transcode_jobs(stage_status, priority) 
    ON media_transcode_jobs(stage_status) WHERE stage_status IN ('QUEUED', 'RUNNING');
```

> **注：** `priority` 字段需通过 JOIN `media_assets` 获取，或在 jobs 表冗余。为简化查询，在 jobs 表也加一列：

```sql
ALTER TABLE media_transcode_jobs ADD COLUMN priority INT NOT NULL DEFAULT 5;
CREATE INDEX idx_jobs_queue ON media_transcode_jobs(stage_status, priority, queued_at) 
    WHERE stage_status = 'QUEUED';
```

#### 3.1.4 `media_playback_logs` — 播放日志表（ClickHouse）

```sql
-- ClickHouse 表，用于播放质量分析
CREATE TABLE media_playback_logs (
    event_id        String,
    user_id         String,
    device_id       String,
    asset_id        String,
    rendition_id    Nullable(String),

    playback_position_ms  UInt64,            -- 当前播放位置（毫秒）
    duration_ms     UInt64,                  -- 媒体总时长
    buffer_health_ms Int32,                  -- 缓冲健康度（前方已缓冲时长）
    measured_bitrate UInt64,                 -- 实际下载码率
    network_type    LowCardinality(String),  -- WIFI, 4G, 5G, 3G, ETHERNET, UNKNOWN
    rtt_ms          Int32,                   -- 网络往返延迟
    error_code      Nullable(String),
    error_message   Nullable(String),
    client_version  String,
    platform        LowCardinality(String),  -- ANDROID, IOS, WEB, MINI_PROGRAM
    cdn_edge_node   Nullable(String),
    session_id      String,                  -- 播放会话 ID
    timestamp       DateTime64(3)
) ENGINE = MergeTree()
PARTITION BY toYYYYMMDD(timestamp)
ORDER BY (asset_id, user_id, timestamp)
```


### 3.2 Redis 数据结构

#### 3.2.1 转码任务队列

```
# 有序集合，按优先级 + 排队时间排序
Key:  media:transcode:queue
Member: job_id
Score: priority * 1e10 - unix_timestamp  (值越小越优先执行)
```

#### 3.2.2 资源状态缓存

```
# Hash 结构，缓存 Asset 元数据，TTL 300s
Key:  media:asset:{asset_id}:info
Fields: status, master_playlist_url, thumbnail_url, duration_ms, drm_scheme, ...
```

#### 3.2.3 播放鉴权 Token

```
# String 结构，TTL 3600s
Key:  media:playback:token:{token_value}
Value: {asset_id}:{user_id}:{rendition_id}:{expire_ts}
```

#### 3.2.4 CDN 预热任务

```
# List 结构，待预热 URL 列表
Key:  media:cdn:warmup:batch:{batch_id}
Members: [url1, url2, ...]
```

## 4. API 接口设计

### 4.1 媒体上传接口

#### 4.1.1 请求上传凭证（分片上传）

```
POST /api/v1/media/assets/upload-token
```

**Request Body**
```json
{
  "filename": "七年级数学_第三章_方程与不等式.mp4",
  "file_size": 524288000,
  "file_sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "business_type": "VIDEO_COURSE",
  "content_type": "video/mp4",
  "metadata": {
    "textbook_chapter_id": "ch-7-math-3",
    "subject_code": "MATH",
    "grade_code": "G7"
  },
  "priority": 3
}
```

**Response 200**
```json
{
  "code": 0,
  "data": {
    "asset_id": "ast-3f8a1b2c-4d5e-6789-0123-456789abcdef",
    "upload_type": "MULTIPART",
    "upload_urls": [
      "https://oss-cn-beijing.aliyuncs.com/primetop-media/raw/ast-xxx/part-1?uploadId=xxx&sign=xxx",
      "https://oss-cn-beijing.aliyuncs.com/primetop-media/raw/ast-xxx/part-2?uploadId=xxx&sign=xxx"
    ],
    "chunk_size": 10485760,
    "max_chunks": 50,
    "expire_at": "2026-06-16T15:00:00.000Z",
    "deduplicated": false
  }
}
```

**说明：**
- 如果 `file_sha256` 已存在（重复上传），返回 `deduplicated: true` 并直接复用已有 asset
- 大文件（>100MB）强制分片上传，每片 10MB
- 凭证有效期 2 小时，超时需重新请求

```
POST /api/v1/media/assets/{asset_id}/upload-complete
```

```json
{
  "parts": [
```

## 6. 状态机设计

### 6.1 Asset 状态机

```
                         ┌───────────┐
                         │  UPLOADED │ ← 文件上传完成
                         └─────┬─────┘
                               │ 发起转码
                               ▼
                    ┌─────────────────────┐
                    │ TRANSCODE_QUEUED    │ ← 转码任务入队
                    └──────────┬──────────┘
                               │ Worker 拉取
                               ▼
                    ┌─────────────────────┐
            ┌──────│   TRANSCODING       │──────┐
            │      └──────────┬──────────┘      │
            │  全部成功       │                 │ 不可恢复失败
            ▼                 ▼                 ▼
┌───────────────────┐  ┌───────────┐  ┌───────────────┐
│ PACKAGING         │  │ (继续等待) │  │ TRANCODE_FAILED│
└───────┬───────────┘  └───────────┘  └───────┬───────┘
        │                                      │ 手动重试
        ▼                                      ▼
┌───────────────────┐                ┌───────────────┐
│ ENCRYPTING        │                │ UPLOADED       │
└───────┬───────────┘                └───────────────┘
        │
        ▼
┌───────────────────┐
│ READY             │ ← 全部处理完成，等待发布
└───────┬───────────┘
        │ 业务方审核确认
        ▼
┌───────────────────┐
│ PUBLISHED         │ ← CDN 分发就绪，可播放
└───────┬───────────┘
        │ 下线操作
        ▼
┌───────────────────┐
│ UNPUBLISHED       │ ← 停止分发，保留文件
└───────┬───────────┘
        │ 过期/清理
        ▼
┌───────────────────┐
│ ARCHIVED          │ ← 冷存储，元数据保留
└───────────────────┘
```

### 6.2 状态流转规则

| 当前状态 | 允许的转移 | 触发条件 |
| --- | --- | --- |
| UPLOADED | TRANSCODE_QUEUED | 调用发起转码 API |
| UPLOADED | TRANSCODE_FAILED | 探测失败（格式不支持） |
| TRANSCODE_QUEUED | TRANSCODING | Worker 拉取任务 |
| TRANSCODING | PACKAGING | 所有 rendition 视频转码完成 |
| TRANSCODING | TRANSCODE_FAILED | 重试超过上限仍失败 |
| PACKAGING | ENCRYPTING | HLS 打包完成 |
| PACKAGING | READY | 无需加密时直接就绪 |
| ENCRYPTING | READY | 加密完成 |
| READY | PUBLISHED | 业务方调用发布 |
| READY | UPLOADED | 转码质量不合格，重新触发 |
| PUBLISHED | UNPUBLISHED | 业务方下线 |
| UNPUBLISHED | PUBLISHED | 重新上线 |
| UNPUBLISHED | ARCHIVED | 超过保留期 |
| ARCHIVED | UPLOADED | 恢复（重新入库校验） |

### 6.3 Rendition 状态机

```
PENDING → TRANSCODING → PACKAGED → (ENCRYPTED) → READY
    │         │            │
    │         ▼            ▼
    └──── FAILED ←─────────┘
```

```python
# pseudo-code: UploadCompleteHandler

async def handle_upload_complete(asset_id: str, parts: list[Part]) -> Asset:
    asset = await get_asset(asset_id)
    
    # 1. 合并分片
    await object_storage.complete_multipart_upload(
        bucket="primetop-media-raw",
        key=asset.source_storage_key,
        parts=parts
    )
    
    # 2. 病毒扫描（异步，不阻塞主流程）
    scan_task = await submit_virus_scan(asset.source_storage_key)
    
    # 3. FFprobe 探测
    probe_result = await run_ffprobe(asset.source_storage_key)
    if not probe_result.success:
        asset.status = "TRANSCODE_FAILED"
        asset.status_message = f"探测失败: {probe_result.error}"
        await save(asset)
        raise ProbeError(probe_result.error)
    
    # 4. 更新 asset 探测信息
    asset.duration_ms = probe_result.duration_ms
    asset.width = probe_result.width
    asset.height = probe_result.height
    asset.fps = probe_result.fps
    asset.video_codec = probe_result.video_codec
    asset.audio_codec = probe_result.audio_codec
    asset.audio_channels = probe_result.audio_channels
    asset.audio_sample_rate = probe_result.audio_sample_rate
    asset.bitrate_bps = probe_result.bitrate_bps
    
    # 5. 智能选择转码档位（过滤不需要的高档位）
    recommended_profiles = select_profiles(
        source_width=asset.width,
        source_height=asset.height,
        source_bitrate=asset.bitrate_bps,
        business_type=asset.business_type
    )
    asset.metadata["recommended_profiles"] = recommended_profiles
    
    await save(asset)
    
    # 6. 发布 AssetReady 事件
    await event_bus.publish("media.asset.uploaded", {
        "asset_id": asset_id,
        "recommended_profiles": recommended_profiles
    })
    
    return asset


def select_profiles(source_width, source_height, source_bitrate, business_type) -> list[str]:
    """根据源文件参数智能选择转码档位"""
    all_profiles = ["240p", "360p", "480p", "720p", "1080p"]
    
    # 不生成高于源文件的档位
    max_profile = determine_max_profile(source_height)
    profiles = [p for p in all_profiles if profile_rank(p) <= profile_rank(max_profile)]
    
    # 纯音频场景
    if business_type in ("LISTENING_AUDIO", "RECITATION_DEMO", "PRONUNCIATION_AUDIO"):
        return ["AUDIO_ONLY"]
    
    # 微课短视频：至少 480p
    if business_type == "MICRO_LESSON" and source_height >= 480:
        profiles = [p for p in profiles if profile_rank(p) >= profile_rank("480p")]
    
    return profiles
```

### 7.2 转码任务调度流程

```python
# pseudo-code: TranscodeOrchestrator

class TranscodeOrchestrator:
    
    async def submit_transcode_batch(
        self, asset_id: str, profiles: list[str], options: TranscodeOptions
    ) -> str:
        """提交转码批次"""
        asset = await get_asset(asset_id)
        batch_id = generate_id("tcb")
        
        # 创建 renditions
        renditions = []
        for profile in profiles:
            rendition = Rendition(
                asset_id=asset_id,
                profile_name=profile,
                container="HLS",
                status="PENDING"
            )
            await save(rendition)
            renditions.append(rendition)
        
        # 创建 jobs，按 stage 拆分
        for rendition in renditions:
            # Stage 1: TRANSCODE
            job_transcode = TranscodeJob(
                asset_id=asset_id,
                rendition_id=rendition.rendition_id,
                stage="TRANSCODE_VIDEO",
                stage_status="QUEUED",
                priority=asset.priority
            )
            await save(job_transcode)
            await self.queue.enqueue(job_transcode)
        
        # 更新 asset 状态
        asset.status = "TRANSCODE_QUEUED"
        await save(asset)
        
        return batch_id
    
    async def on_job_success(self, job: TranscodeJob):
        """Job 成功回调"""
        asset = await get_asset(job.asset_id)
        rendition = await get_rendition(job.rendition_id)
        
        if job.stage == "TRANSCODE_VIDEO":
            # 转码成功，进入打包
            rendition.status = "TRANSCODING"  # 还在进行中
            await self.create_package_job(asset, rendition)
            
        elif job.stage == "PACKAGE":
            rendition.status = "PACKAGED"
            await save(rendition)
            
            if asset.drm_scheme and asset.drm_scheme != "NONE":
                await self.create_encrypt_job(asset, rendition)
            else:
                rendition.status = "READY"
                await save(rendition)
                await self.check_all_ready(asset)
                
        elif job.stage == "ENCRYPT":
            rendition.status = "READY"
            await save(rendition)
            await self.check_all_ready(asset)
            
        elif job.stage == "SCREENSHOT":
            await self.check_all_ready(asset)
            
        elif job.stage == "DISTRIBUTE":
            asset.status = "READY"
            await save(asset)
            await self.notify_callback(asset)
    
    async def check_all_ready(self, asset: Asset):
        """检查所有 rendition 是否就绪"""
        renditions = await list_renditions(asset.asset_id)
        all_ready = all(r.status == "READY" for r in renditions)
        
        if all_ready:
            # 创建截图任务（如果需要）
            await self.create_screenshot_jobs(asset)
            # 创建分发任务
            await self.create_distribute_job(asset)
    
    async def on_job_failed(self, job: TranscodeJob, error: Exception):
        """Job 失败回调"""
        if job.retry_count < job.max_retries:
            # 指数退避重试
            delay = calculate_backoff(job.retry_count, base=30, max_delay=1800)
            job.retry_count += 1
            job.stage_status = "QUEUED"
            await save(job)
            await self.queue.enqueue(job, delay_seconds=delay)
        else:
            job.stage_status = "FAILED"
            job.error_message = str(error)
            await save(job)
            
            rendition = await get_rendition(job.rendition_id)
            rendition.status = "FAILED"
            rendition.status_message = f"Stage {job.stage} failed: {error}"
            await save(rendition)
            
            # 标记 asset 转码失败
            asset = await get_asset(job.asset_id)
            asset.status = "TRANSCODE_FAILED"
            asset.status_message = rendition.status_message
            await save(asset)
            
            # 发送告警
            await alert_manager.send(
                level="ERROR",
                title=f"Media transcode failed: {asset.asset_id}",
                message=rendition.status_message
            )


def calculate_backoff(retry_count: int, base: int = 30, max_delay: int = 1800) -> int:
    """指数退避：30s → 60s → 120s → ... → 1800s"""
    return min(base * (2 ** retry_count), max_delay)
```

### 7.4 播放 Token 鉴权实现

```go
// playback_token.go

type PlaybackToken struct {
    AssetID     string `json:"asset_id"`
    UserID      string `json:"user_id"`
    RenditionID string `json:"rendition_id,omitempty"` // 空表示所有档位
    ExpireTS    int64  `json:"expire_ts"`
    Platform    string `json:"platform"`
    Offline     bool   `json:"offline"`
    Signature   string `json:"sig"`
}

func GeneratePlaybackToken(assetID, userID string, ttl time.Duration) (string, error) {
    token := PlaybackToken{
        AssetID:  assetID,
        UserID:   userID,
        ExpireTS: time.Now().Add(ttl).Unix(),
    }
    
    payload, err := json.Marshal(token)
    if err != nil {
        return "", err
    }
    
    // HMAC-SHA256 签名
    sig := hmac256(securityKey, payload)
    token.Signature = hex.EncodeToString(sig)
    
    // 写入 Redis
    finalPayload, _ := json.Marshal(token)
    tokenID := uuid.NewString()
    redisKey := fmt.Sprintf("media:playback:token:%s", tokenID)
    redis.Set(ctx, redisKey, string(finalPayload), ttl)
    
    // 返回 tokenID（短 token，拼在 URL 参数里）
    return tokenID, nil
}

func VerifyPlaybackToken(tokenID string) (*PlaybackToken, error) {
    redisKey := fmt.Sprintf("media:playback:token:%s", tokenID)
    data, err := redis.Get(ctx, redisKey).Bytes()
    if err == redis.Nil {
        return nil, ErrTokenExpired
    }
    if err != nil {
        return nil, err
    }
    
    var token PlaybackToken
    if err := json.Unmarshal(data, &token); err != nil {
        return nil, err
    }
    
    // 验证签名
    expectedSig := hex.EncodeToString(hmac256(securityKey, data[:len(data)-64]))
    if !hmac.Equal([]byte(token.Signature), []byte(expectedSig)) {
        return nil, ErrInvalidToken
    }
    
    // 检查过期
    if time.Now().Unix() > token.ExpireTS {
        return nil, ErrTokenExpired
    }
    
    return &token, nil
}
```

### 9.2 异常恢复策略

#### 9.2.1 转码 Worker 崩溃

```
场景: Worker 节点在执行转码任务时崩溃/OOM/磁盘满

检测: Worker heartbeat 超时 (60s 无心跳)
恢复:
  1. 检测到 heartbeat 失败 → 标记 Worker 为 OFFLINE
  2. 扫描该 Worker 上所有 RUNNING 状态的 Jobs
  3. 将 Jobs 重置为 QUEUED，retry_count 不增加（非任务本身错误）
  4. 清理 Worker 节点上的中间产物
  5. 等待其他 Worker 拉取
```

#### 9.2.2 对象存储写入失败

```
场景: OSS/MinIO 暂时不可用

检测: SDK 返回 5xx 或超时
恢复:
  1. 写入操作自动重试 3 次（间隔 1s/3s/10s）
  2. 仍失败则 Job 进入 RETRY 队列，60s 后重试
  3. 连续 10 分钟内 >50% 请求失败 → 触发存储层告警
  4. 降级：新上传请求进入限流队列，返回 503 + Retry-After
```

#### 9.2.3 CDN 回源异常

```
场景: CDN 边缘节点无法回源获取分片

检测: CDN 健康检查 / 回源错误率监控
恢复:
  1. CDN 控制台自动切换备用源站
  2. 如主 CDN 供应商故障 → DNS 切换到备用 CDN
  3. 客户端收到 502/503 → 指数退避重试（1s/2s/4s）
  4. 超过 3 次失败 → 客户端切换到降级码率（如 720p → 480p）
```

#### 9.2.4 DRM License 服务不可用

```
场景: Widevine/FairPlay License 服务宕机

检测: License 接口错误率 > 5%
恢复:
  1. License 服务多副本部署，自动重试
  2. 非加密内容不受影响
  3. 加密内容播放失败 → 返回友好提示 + 重试按钮
  4. 紧急策略：临时关闭 DRM（仅限非敏感公开内容）
```

### 9.3 关键代码：Worker 心跳与任务恢复

```go
// transcode_worker.go

type TranscodeWorker struct {
    WorkerID     string
    Redis        *redis.Client
    DB           *gorm.DB
    HeartbeatKey string  // media:worker:{id}:heartbeat
    CurrentJobs  sync.Map  // job_id -> context.CancelFunc
}

func (w *TranscodeWorker) Start(ctx context.Context) {
    // 启动心跳
    go w.heartbeatLoop(ctx)
    
    // 启动任务执行循环
    go w.jobLoop(ctx)
    
    // 启动优雅停机
    go w.gracefulShutdown(ctx)
}

func (w *TranscodeWorker) heartbeatLoop(ctx context.Context) {
    ticker := time.NewTicker(15 * time.Second)
    defer ticker.Stop()
    
    for {
        select {
        case <-ctx.Done():
            return
        case <-ticker.C:
            // 更新心跳，TTL 60s
            w.Redis.Set(ctx, w.HeartbeatKey, time.Now().Unix(), 60*time.Second)
            // 更新 Worker 负载信息
            loadInfo := w.getLoadInfo()
            w.Redis.HSet(ctx, fmt.Sprintf("media:worker:%s:info", w.WorkerID), loadInfo)
        }
    }
}

func (w *TranscodeWorker) jobLoop(ctx context.Context) {
    for {
        select {
        case <-ctx.Done():
            return
        default:
            // 从队列拉取任务（阻塞式，超时 10s）
            jobID, err := w.Redis.BZPopMin(ctx, 10*time.Second, "media:transcode:queue").Result()
            if err == redis.Nil {
                continue
            }
            if err != nil {
                log.Errorf("BZPopMin error: %v", err)
                time.Sleep(time.Second)
                continue
            }
            
            // 检查容量
            if w.currentLoad() >= w.maxConcurrency {
                // 重新入队
                w.Redis.ZAdd(ctx, "media:transcode:queue", redis.Z{
                    Score:  float64(time.Now().Unix()),
                    Member: jobID.Member,
                })
                time.Sleep(5 * time.Second)
                continue
            }
            
            // 执行任务
            go w.executeJob(ctx, jobID.Member.(string))
        }
    }
}

func (w *TranscodeWorker) gracefulShutdown(ctx context.Context) {
    <-ctx.Done()
    
    // 停止接受新任务
    // 等待当前任务完成（最多 5 分钟）
    timeout := time.After(5 * time.Minute)
    for {
        select {
        case <-timeout:
            // 强制中断：标记当前 jobs 为 QUEUED
            w.CurrentJobs.Range(func(key, value interface{}) bool {
                jobID := key.(string)
                cancel := value.(context.CancelFunc)
                cancel()
                w.resetJobToQueued(jobID)
                return true
            })
            return
        default:
            if w.currentLoad() == 0 {
                return
            }
            time.Sleep(5 * time.Second)
        }
    }
}
```

### 13.1 内容安全

- 所有上传文件必须经过病毒扫描（ClamAV 或云服务）
- 上传文件名脱敏处理，不保留原始路径信息
- 媒体内容发布前需经过内容审核流程（与「教育内容审核工作流」联动）
- 删除 Asset 时，对象存储文件标记删除并 30 天后物理清除

### 13.2 访问控制

- 上传/管理 API：仅允许内部服务 + 运营后台调用（IP 白名单）
- 播放 API：用户需登录且具有有效会员/访问权限
- 离线下载：需会员权益校验 + 离线 License 有效期控制（默认 7 天）
- 转码 Worker：与控制面通过 mTLS 双向认证

### 13.3 隐私保护

- 播放日志中的 `user_id` 在写入 ClickHouse 前做哈希脱敏（不可逆）
- 设备信息仅记录设备类型和平台版本，不记录设备指纹明文
- 播放日志保留 90 天后自动清理
- 符合《儿童个人信息网络保护规定》要求，未满 14 岁用户播放数据不记录 IP 地址
