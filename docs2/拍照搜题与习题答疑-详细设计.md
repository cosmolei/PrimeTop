# 拍照搜题与习题答疑 - 详细设计文档

## 1. 模块概述

拍照搜题与习题答疑是 PrimeTop 的核心学习入口之一。学生通过手机拍摄纸质作业、试卷、练习册上的题目，系统通过 OCR 识别题目内容，经过题库匹配或 AI 解析，生成分步解答。该模块是"提问 → 讲解 → 错题收录 → 巩固练习"闭环的起点。

### 1.1 功能范围

| 功能 | 优先级 | MVP |
|------|--------|-----|
| 拍照识题（单题/多题） | P0 | ✅ |
| 题目结构化（题干/选项/公式/图形） | P0 | ✅ |
| 分步解析生成 | P0 | ✅ |
| 答案隐藏（先思路后答案） | P0 | ✅ |
| 一键加入错题本 | P0 | ✅ |
| 同类题推荐 | P1 | ❌ |
| 手写题识别优化 | P1 | ❌ |
| 题目区域裁剪/旋转 | P0 | ✅ |
| 多题选择（用户指定解析哪道） | P0 | ✅ |
| 图片预处理（去阴影/增强对比度） | P1 | ❌ |
| 解析历史记录 | P1 | ✅ |
| 识别结果修正（用户手动编辑） | P0 | ✅ |

### 1.2 与其他模块的关系

```
用户账号体系 → 提供用户身份、学段年级、教材版本
    ↓
拍照搜题与习题答疑 ← 本模块
    ↓
AI 智能辅导 → 题目解析实际调用 AI 服务
    ↓
错题整理 → 一键收录解析过的错题
    ↓
学情分析 → 答题记录为学情提供数据
```

## 2. 核心流程

### 2.1 拍题答疑主流程

```
┌─────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  拍照/选图  │───→│  图片预处理  │───→│  OCR 识别   │───→│  题目分割   │
└─────────┘    └──────────┘    └──────────┘    └──────────┘
                                                    │
                                                    ↓
┌─────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  展示解析  │←───│  生成解析   │←───│  AI / 题库  │←───│  题目结构化  │
└─────────┘    └──────────┘    └──────────┘    └──────────┘
     │
     ↓
┌──────────┐    ┌──────────┐
│ 加入错题本  │    │  推荐同类题  │（V1.0）
└──────────┘    └──────────┘
```

### 2.2 状态流转

题目解析记录（photo_task）的状态流转：

```
UPLOADING → PROCESSING → RECOGNIZED → SOLVING → COMPLETED
                │                        │
                ↓                        ↓
            RECOGNIZE_FAILED          SOLVE_FAILED
```

| 状态 | 含义 |
|------|------|
| UPLOADING | 图片上传中 |
| PROCESSING | OCR 识别中 |
| RECOGNIZED | 识别完成，等待解析 |
| SOLVING | AI/题库解析中 |
| COMPLETED | 解析完成 |
| RECOGNIZE_FAILED | OCR 识别失败 |
| SOLVE_FAILED | 解析失败 |

## 5. 核心逻辑设计

### 5.1 OCR 识别服务

```
┌──────────┐     ┌───────────┐     ┌───────────┐     ┌───────────┐
│ 图片上传   │────→│ 图片预处理   │────→│ OCR 识别    │────→│ 题目分割   │
└──────────┘     └───────────┘     └───────────┘     └───────────┘
                      │                                      │
                      ↓                                      ↓
              ┌──────────────┐                    ┌──────────────┐
              │ 去噪/矫正/增强  │                    │ 题目边界检测   │
              └──────────────┘                    └──────────────┘
```

**图片预处理（MVP 简化版）：**

```python
def preprocess_image(image_bytes: bytes) -> bytes:
    """图片预处理：压缩 + 基础增强"""
    from PIL import Image, ImageEnhance
    import io
    
    img = Image.open(io.BytesIO(image_bytes))
    
    # 1. 压缩至合理尺寸（长边不超过2048px）
    max_size = 2048
    ratio = min(max_size / max(img.size), 1.0)
    if ratio < 1.0:
        img = img.resize(
            (int(img.width * ratio), int(img.height * ratio)),
            Image.LANCZOS
        )
    
    # 2. 灰度化 + 对比度增强
    img = img.convert('L')
    img = ImageEnhance.Contrast(img).enhance(1.5)
    
    # 3. 输出
    buf = io.BytesIO()
    img.save(buf, format='JPEG', quality=85)
    return buf.getvalue()
```

**OCR 调用策略：**

```python
class OCRService:
    """OCR 识别服务，支持多供应商降级"""
    
    PROVIDERS = ['baidu', 'tencent', 'aliyun']  # 优先级顺序
    
    async def recognize(self, image_url: str) -> OCRResult:
        """调用 OCR 识别，支持降级"""
        last_error = None
        for provider in self.PROVIDERS:
            try:
                result = await self._call_provider(provider, image_url)
                if result.confidence >= 0.7:
                    return result
                # 置信度过低，尝试下一个供应商
                last_error = LowConfidenceError(result.confidence)
            except OCRProviderError as e:
                last_error = e
                continue
        
        raise OCRError(f"所有 OCR 供应商均失败: {last_error}")
```

### 5.2 题目分割与结构化

OCR 返回的是整页文本块列表，需要分割为独立题目。

```python
@dataclass
class QuestionSegment:
    """分割后的题目"""
    seq_no: int
    text: str
    bbox: BoundingBox        # 在原图中的位置
    question_type: str        # 题型
    options: list[str] | None # 选项
    has_image: bool

def segment_questions(ocr_blocks: list[OCRBlock]) -> list[QuestionSegment]:
    """将 OCR 文本块分割为独立题目"""
    questions = []
    current_text = ""
    current_bbox = None
    
    for block in ocr_blocks:
        # 题号检测：匹配 "1." "一、" "（1）" 等模式
        if is_question_number(block.text) and current_text:
            questions.append(_build_question(current_text, current_bbox))
            current_text = block.text
            current_bbox = block.bbox
        else:
            current_text += "\n" + block.text
            current_bbox = merge_bbox(current_bbox, block.bbox)
    
    # 最后一道题
    if current_text:
        questions.append(_build_question(current_text, current_bbox))
    
    return questions
```

### 5.3 解题策略（题库优先 → AI 兜底）

```python
class SolveService:
    """解题服务：题库匹配优先，AI 生成兜底"""
    
    def __init__(self, question_bank: QuestionBank, ai_service: AIService):
        self.qb = question_bank
        self.ai = ai_service
    
    async def solve(self, question: RecognizedQuestion, user: UserContext) -> Solution:
        """
        解题主流程:
        1. 先查题库精确匹配
        2. 再查题库语义匹配（向量检索）
        3. 都没命中则调用 AI 生成
        """
        # Step 1: 精确匹配（文本哈希）
        exact_match = await self.qb.exact_match(question.question_text)
        if exact_match and exact_match.solution:
            return Solution(
                source_type='question_bank',
                steps=exact_match.solution.steps,
                answer=exact_match.solution.answer,
                matched_question_id=exact_match.id
            )
        
        # Step 2: 语义匹配（向量检索）
        semantic_match = await self.qb.semantic_match(
            question.question_text,
            threshold=0.92
        )
        if semantic_match:
            return Solution(
                source_type='question_bank',
                steps=semantic_match.solution.steps,
                answer=semantic_match.solution.answer,
                matched_question_id=semantic_match.id,
                match_score=semantic_match.score
            )
        
        # Step 3: AI 生成
        solution = await self.ai.generate_solution(
            question_text=question.question_text,
            question_type=question.question_type,
            options=question.options,
            grade=user.grade,
            subject=question.subject_id,
            textbook_id=user.textbook_id
        )
        solution.source_type = 'ai_generated'
        return solution
```

### 5.5 次数限制与防刷

```python
class PhotoLimitService:
    """拍题次数限制"""
    
    # 不同会员等级的每日拍题限制
    DAILY_LIMITS = {
        'free': 5,       # 免费用户每天5次
        'monthly': 50,   # 月度会员每天50次
        'annual': -1,    # 年度会员不限
    }
    
    async def check_limit(self, user_id: int, membership_tier: str) -> LimitResult:
        """检查今日拍题次数"""
        limit = self.DAILY_LIMITS.get(membership_tier, 5)
        
        if limit == -1:
            return LimitResult(allowed=True, remaining=-1, limit=-1)
        
        used = await self._get_today_count(user_id)
        remaining = max(0, limit - used)
        
        return LimitResult(
            allowed=used < limit,
            remaining=remaining,
            limit=limit
        )
    
    async def _get_today_count(self, user_id: int) -> int:
        """从 Redis 获取今日已用次数"""
        key = f"photo:limit:{user_id}:{date.today()}"
        count = await redis.get(key)
        return int(count or 0)
    
    async def increment_usage(self, user_id: int):
        """记录一次使用"""
        key = f"photo:limit:{user_id}:{date.today()}"
        pipe = redis.pipeline()
        pipe.incr(key)
        pipe.expire(key, 86400 * 2)  # 保留2天
        await pipe.execute()
```

## 7. 服务端实现要点

### 7.1 异步任务处理

拍题解析是 IO 密集型任务（OCR + AI 调用），采用异步任务队列：

```python
# 使用 Celery 或类似任务队列
@app.task(bind=True, max_retries=2, time_limit=60)
def process_photo_task(self, task_id: int):
    """异步处理拍题任务"""
    task = PhotoTask.get(task_id)
    
    try:
        # 1. OCR 识别
        task.update_status('PROCESSING')
        ocr_result = ocr_service.recognize(task.image_url)
        
        # 2. 题目分割
        questions = segment_questions(ocr_result.blocks)
        
        if not questions:
            task.update_status('RECOGNIZE_FAILED')
            return
        
        # 3. 保存识别结果
        for q in questions:
            RecognizedQuestion.create(task_id=task.id, **q)
        
        task.update_status('RECOGNIZED')
        
    except OCRError as e:
        task.update_status('RECOGNIZE_FAILED', error=str(e))
        self.retry(countdown=5, exc=e)
```

### 7.2 SSE 流式返回解析

对于 AI 生成的解析，使用 Server-Sent Events 流式返回，提升用户体验：

```python
async def stream_solution(question_id: int, request: Request):
    """SSE 流式返回解析步骤"""
    question = await RecognizedQuestion.get(question_id)
    user = get_current_user(request)
    
    async def event_generator():
        solution = SolveService()
        async for chunk in solution.stream_solve(question, user):
            # 每个步骤完成时推送
            yield {
                "event": "step",
                "data": json.dumps({
                    "step": chunk.step,
                    "status": "completed" if chunk.done else "partial"
                })
            }
        
        yield {
            "event": "done",
            "data": json.dumps({"status": "COMPLETED"})
        }
    
    return EventSourceResponse(event_generator())
```
