# 英语听力理解与考试听力模拟系统 - 详细设计

## 1. 模块概述

### 1.1 定位与目标

英语听力理解与考试听力模拟系统是 PrimeTop 英语专项学习体系的核心子模块，面向小学至高中全学段学生，提供分年级、分难度、分题型的听力训练与考试模拟服务。

**核心目标：**
1. 提供与教材同步的课内听力训练，巩固课堂知识
2. 提供符合中高考听力考试规范的模拟测试，强化应试能力
3. 通过智能评估定位听力薄弱环节（词汇辨识、语速适应、细节捕捉、主旨理解等）
4. 支持离线缓存与弱网环境下的基础听力练习

### 1.2 覆盖学段与难度分层

| 学段 | 难度等级 | 语速范围 | 核心能力 |
|------|---------|---------|---------|
| 小学 (3-6年级) | L1-L2 | 80-100 词/分 | 单词辨识、简短对话理解、基础指令响应 |
| 初中 (7-9年级) | L3-L5 | 100-130 词/分 | 对话理解、短文主旨、细节信息提取 |
| 高中 (10-12年级) | L6-L8 | 130-160 词/分 | 长对话推理、段落主旨、隐含含义推断、综合信息匹配 |

### 1.3 与其他模块的关系

```
┌─────────────────────────────────────────────────────┐
│                  英语专项学习与口语陪练               │
│  ┌──────────┐  ┌──────────┐  ┌───────────────────┐  │
│  │ 口语练习  │  │ 词汇语法  │  │  听力理解(本模块)  │  │
│  └──────────┘  └──────────┘  └───────────────────┘  │
├─────────────────────────────────────────────────────┤
│  学习记录与进度追踪 │ 学情分析 │ 用户额度管控          │
├─────────────────────────────────────────────────────┤
│  语音服务(ASR/TTS) │ 文件与资源存储 │ 多级缓存        │
└─────────────────────────────────────────────────────┘
```

- **语音服务(ASR/TTS)**：提供音频播放、语音识别（用于跟读对比）
- **文件与资源存储**：音频文件的 CDN 分发与本地缓存
- **学习记录与进度追踪**：记录听力练习完成情况与正确率
- **用户额度管控**：听力模拟次数的额度控制
- **练习与测评系统**：答题批改与知识点掌握度更新

## 2. 功能设计

### 2.1 功能模块总览

| 功能 | 说明 | 优先级 |
|------|------|-------|
| 听力练习 | 分级听力练习，含音频播放与答题 | P0 |
| 考试模拟 | 按中高考规格组织的完整听力模拟 | P0 |
| 教材同步听力 | 按教材章节匹配的课内听力材料 | P0 |
| 听力评估报告 | 听力能力维度分析与薄弱点识别 | P1 |
| 错题回顾 | 听力错题重听与二次作答 | P1 |
| 变速播放 | 调节音频播放语速 | P1 |
| 精听模式 | 逐句播放、循环播放、跟读对比 | P2 |
| 离线听力包 | 下载听力资源包离线使用 | P2 |

### 2.2 听力练习流程

```
用户选择听力练习
    │
    ├─→ 按教材章节选择（同步课堂）
    ├─→ 按难度等级选择（自由练习）
    └─→ 按薄弱点推荐（智能推荐）
    │
    ▼
进入练习页面
    │
    ├─→ 展示练习信息（难度、题数、预计时长）
    ├─→ 加载音频资源（优先本地缓存 → CDN）
    └─→ 预加载题目文本框架（不展示选项）
    │
    ▼
播放音频（全段播放模式）
    │
    ├─→ 播放控制：播放/暂停、进度条、音量
    ├─→ 可选：变速（0.75x / 1x / 1.25x / 1.5x）
    └─→ 播放结束后自动进入答题
    │
    ▼
逐题作答
    │
    ├─→ 选择题 / 填空题 / 判断题 / 排序题
    ├─→ 每题可重听相关音频片段（标记区间）
    ├─→ 倒计时控制（模拟考试限时模式）
    └─→ 全部作答后提交
    │
    ▼
结果展示
    │
    ├─→ 总分、各题得分、正确率
    ├─→ 错题展示（正确答案 + 音频重听 + 解析）
    ├─→ 能力维度雷达图（细节捕捉/主旨理解/推理判断/词汇辨识）
    └─→ 推荐下一步练习
```

### 2.3 考试模拟流程

```
用户选择考试模拟
    │
    ├─→ 选择考试类型（中考/高考/期中/期末）
    ├─→ 选择试卷（历年真题/AI生成模拟卷/随机组卷）
    └─→ 确认开始（提示：考试模式下不可暂停、不可后退）
    │
    ▼
进入考试模式
    │
    ├─→ 全屏锁定（关闭底部导航）
    ├─→ 顶部计时器倒计时
    ├─→ 按考试规格播放音频：
    │   ├─ 中考格式：图片题 → 短对话 → 长对话 → 短文
    │   └─ 高考格式：短对话5题 → 长对话5题 → 独白/短文10题
    ├─→ 音频仅播放一遍（真题模式）/ 两遍（练习模式）
    ├─→ 每段音频播放后限时答题
    └─→ 答题卡视图（可跳题、标记待检查）
    │
    ▼
考试结束
    │
    ├─→ 倒计时结束 或 手动交卷
    ├─→ 自动批改（客观题即时出分）
    ├─→ 生成听力测试报告：
    │   ├─ 总分与预估分（映射到标准分）
    │   ├─ 各题型得分率
    │   ├─ 错题音频回放 + 解析
    │   ├─ 能力维度分析
    │   └── 与历史成绩对比
    └─→ 记录到学习记录系统
```

### 2.4 精听模式流程（P2）

```
进入精听模式
    │
    ├─→ 选择听力材料（从练习/模拟中的错题段落）
    ├─→ 进入逐句播放界面
    │
    ▼
逐句训练循环
    │
    ├─→ Step 1: 盲听 — 播放单句，不看文本
    ├─→ Step 2: 听写 — 用户输入听到的内容（文本输入框）
    ├─→ Step 3: 校对 — 展示原文，标记差异（红字）
    ├──→ Step 4: 跟读 — 播放原音 → 用户跟读 → ASR评分
    └─→ Step 5: 下一句 或 重练本句
    │
    ▼
精听完成
    │
    ├─→ 整体准确率统计
    ├─→ 标记薄弱句子（错误率 > 30%）
    └─→ 推荐相关强化练习
```

## 3. 数据模型设计

### 3.1 核心数据表

#### 3.1.1 听力资源表 (listening_resource)

```sql
CREATE TABLE listening_resource (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '资源ID',
    resource_code   VARCHAR(64) NOT NULL UNIQUE COMMENT '资源编码，如 LR-2026-EN-MID-001',
    title           VARCHAR(255) NOT NULL COMMENT '资源标题',
    description     TEXT COMMENT '资源描述',
    
    -- 分类信息
    grade_range     VARCHAR(32) NOT NULL COMMENT '适用学段: primary/junior/senior',
    grade_codes     JSON NOT NULL COMMENT '适用年级列表 ["G03","G04",...,"G06"]',
    difficulty      TINYINT NOT NULL COMMENT '难度等级 1-8',
    category        VARCHAR(32) NOT NULL COMMENT '分类: textbook_sync/free_practice/exam_sim/daily_listening',
    
    -- 教材关联
    textbook_id     BIGINT COMMENT '教材版本ID（同步听力时关联）',
    chapter_id      BIGINT COMMENT '章节ID',
    semester        VARCHAR(16) COMMENT '学期: first/second',
    
    -- 音频信息
    audio_url       VARCHAR(512) NOT NULL COMMENT '音频CDN地址',
    audio_duration  INT NOT NULL COMMENT '音频时长（毫秒）',
    audio_format    VARCHAR(16) NOT NULL DEFAULT 'mp3' COMMENT '音频格式: mp3/m4a/ogg',
    audio_bitrate   INT NOT NULL DEFAULT 128 COMMENT '比特率 kbps',
    audio_size_bytes BIGINT NOT NULL COMMENT '文件大小（字节）',
    
    -- 文本信息
    transcript      TEXT NOT NULL COMMENT '听力原文（完整文本）',
    sentence_timings JSON COMMENT '逐句时间标记 [{"start":0,"end":3200,"text":"Hello..."},...]',
    
    -- 元数据
    word_speed      INT COMMENT '语速（词/分）',
    speaker_count   TINYINT DEFAULT 1 COMMENT '说话人数',
    accent_type     VARCHAR(16) DEFAULT 'american' COMMENT '口音: american/british/mixed',
    topic_tags      JSON COMMENT '话题标签 ["school_life","travel","environment"]',
    
    -- 状态
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '1-草稿 2-已发布 3-已下线',
    sort_order      INT DEFAULT 0 COMMENT '排序权重',
    
    -- 审计字段
    created_by      BIGINT COMMENT '创建人',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_grade_difficulty (grade_range, difficulty),
    INDEX idx_textbook_chapter (textbook_id, chapter_id),
    INDEX idx_category_status (category, status)
) COMMENT '听力资源表';
```

#### 3.1.2 听力题目表 (listening_question)

```sql
CREATE TABLE listening_question (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '题目ID',
    resource_id     BIGINT NOT NULL COMMENT '关联听力资源ID',
    question_no     TINYINT NOT NULL COMMENT '题号（在资源内序号）',
    
    -- 题型
    question_type   VARCHAR(32) NOT NULL COMMENT '题型: choice/multi_choice/fill_blank/true_false/match/order',
    
    -- 题目内容
    question_text   TEXT NOT NULL COMMENT '题干文本',
    options         JSON COMMENT '选项 [{"label":"A","text":"Go to the library"},...]',
    correct_answer  VARCHAR(255) NOT NULL COMMENT '正确答案（JSON格式适配多选/匹配等）',
    
    -- 音频关联
    audio_segment_start INT COMMENT '关联音频片段起始时间（毫秒），null表示关联全文',
    audio_segment_end   INT COMMENT '关联音频片段结束时间（毫秒）',
    
    -- 解析
    explanation     TEXT COMMENT '解析说明',
    key_words       JSON COMMENT '关键词 ["library","homework"]',
    
    -- 知识点
    skill_tags      JSON COMMENT '听力技能标签: detail/main_idea/inference/vocabulary/attitude',
    difficulty      TINYINT NOT NULL COMMENT '题目难度 1-8',
    
    sort_order      INT DEFAULT 0,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_resource (resource_id),
    UNIQUE KEY uk_resource_question (resource_id, question_no)
) COMMENT '听力题目表';
```

#### 3.1.3 听力练习记录表 (listening_practice)

```sql
CREATE TABLE listening_practice (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '练习ID',
    practice_code   VARCHAR(64) NOT NULL UNIQUE COMMENT '练习编码',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    
    -- 练习信息
    practice_type   VARCHAR(32) NOT NULL COMMENT 'practice/exam_sim/intensive',
    resource_id     BIGINT COMMENT '资源ID（非随机组卷时关联）',
    exam_type       VARCHAR(32) COMMENT '考试类型: zhongkao/gaokao/midterm/final（考试模式）',
    
    -- 组卷快照
    question_snapshot JSON NOT NULL COMMENT '题目快照 [{"q_id":123,"type":"choice","order":1},...]',
    
    -- 播放信息
    play_count      INT DEFAULT 0 COMMENT '音频播放次数',
    speed_setting   DECIMAL(4,2) DEFAULT 1.00 COMMENT '播放速度倍率',
    
    -- 答题信息
    answers         JSON COMMENT '用户作答 [{"q_no":1,"answer":"B","time_ms":12000,"replay":true},...]',
    total_questions TINYINT NOT NULL COMMENT '总题数',
    correct_count   TINYINT NOT NULL COMMENT '正确数',
    score           DECIMAL(5,2) COMMENT '得分',
    
    -- 时间
    started_at      DATETIME NOT NULL COMMENT '开始时间',
    finished_at     DATETIME COMMENT '完成时间',
    duration_ms     INT COMMENT '用时（毫秒）',
    
    -- 评估
    skill_scores    JSON COMMENT '各技能得分 {"detail":85,"main_idea":72,"inference":60}',
    weak_points     JSON COMMENT '薄弱点标记 ["inference","vocabulary"]',
    
    status          VARCHAR(16) NOT NULL DEFAULT 'in_progress' COMMENT 'in_progress/completed/abandoned',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_type (user_id, practice_type),
    INDEX idx_user_time (user_id, created_at),
    INDEX idx_resource (resource_id)
) COMMENT '听力练习记录表';
```

#### 3.1.4 听力能力维度表 (listening_skill_profile)

```sql
CREATE TABLE listening_skill_profile (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT 'ID',
    user_id         BIGINT NOT NULL UNIQUE COMMENT '用户ID',
    
    -- 总体
    overall_level   TINYINT COMMENT '综合听力等级 1-8',
    total_practice_count INT DEFAULT 0 COMMENT '总练习次数',
    total_listen_minutes DECIMAL(10,1) DEFAULT 0 COMMENT '总听力时长（分）',
    
    -- 技能维度（0-100分）
    detail_score    DECIMAL(5,2) DEFAULT 0 COMMENT '细节捕捉能力',
    main_idea_score DECIMAL(5,2) DEFAULT 0 COMMENT '主旨理解能力',
    inference_score DECIMAL(5,2) DEFAULT 0 COMMENT '推理判断能力',
    vocabulary_score DECIMAL(5,2) DEFAULT 0 COMMENT '词汇辨识能力',
    attitude_score  DECIMAL(5,2) DEFAULT 0 COMMENT '态度/意图推断',
    number_score    DECIMAL(5,2) DEFAULT 0 COMMENT '数字/时间捕捉',
    
    -- 趋势
    recent_accuracy DECIMAL(5,2) COMMENT '近10次正确率',
    accuracy_trend  VARCHAR(8) COMMENT '趋势: up/stable/down',
    
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user (user_id)
) COMMENT '听力能力维度画像';
```


|------|------|------|------|
| gradeCode | String | 否 | 年级编码，如 G07 |

### 5.1 听力练习评分与技能归因

```java
@Service
public class ListeningScoreService {

    /**
     * 计算听力练习得分并进行技能维度归因
     */
    public ListeningPracticeResult calculateScore(ListeningPractice practice, List<AnswerSubmit> answers) {
        List<ListeningQuestion> questions = questionRepository
            .findByResourceIdOrderByQuestionNo(practice.getResourceId());
        
        int correctCount = 0;
        Map<String, List<Double>> skillScoreMap = new HashMap<>();
        
        for (int i = 0; i < questions.size(); i++) {
            ListeningQuestion q = questions.get(i);
            AnswerSubmit a = answers.get(i);
            
            boolean isCorrect = checkAnswer(q, a);
            if (isCorrect) {
                correctCount++;
            }
            
            // 按技能标签归因
            for (String skill : q.getSkillTags()) {
                skillScoreMap.computeIfAbsent(skill, k -> new ArrayList<>())
                    .add(isCorrect ? 100.0 : 0.0);
            }
        }
        
        // 计算各技能维度均分
        Map<String, Double> skillScores = new HashMap<>();
        for (Map.Entry<String, List<Double>> entry : skillScoreMap.entrySet()) {
            double avg = entry.getValue().stream()
                .mapToDouble(d -> d).average().orElse(0);
            skillScores.put(entry.getKey(), avg);
        }
        
        // 识别薄弱点（低于70分的技能）
        List<String> weakPoints = skillScores.entrySet().stream()
            .filter(e -> e.getValue() < 70.0)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
        
        double score = (double) correctCount / questions.size() * 100;
        
        return ListeningPracticeResult.builder()
            .score(score)
            .correctCount(correctCount)
            .totalQuestions(questions.size())
            .skillScores(skillScores)
            .weakPoints(weakPoints)
            .build();
    }
    
    private boolean checkAnswer(ListeningQuestion question, AnswerSubmit answer) {
        String correct = question.getCorrectAnswer();
        String userAns = answer.getAnswer();
        
        switch (question.getQuestionType()) {
            case "choice":
            case "true_false":
                return correct.equalsIgnoreCase(userAns);
            case "multi_choice":
                // 多选题：排序无关比较
                Set<String> correctSet = new HashSet<>(Arrays.asList(correct.split(",")));
                Set<String> userSet = new HashSet<>(Arrays.asList(userAns.split(",")));
                return correctSet.equals(userSet);
            case "fill_blank":
                // 填空题：忽略大小写和首尾空格
                return correct.trim().equalsIgnoreCase(userAns.trim());
            case "order":
                return correct.equals(userAns);
            case "match":
                return correct.equals(userAns);
            default:
                return false;
        }
    }
}
```

### 5.2 能力画像增量更新

```java
@Service
public class ListeningSkillProfileService {

    // 各技能字段名映射
    private static final Map<String, String> SKILL_FIELD_MAP = Map.of(
        "detail", "detail_score",
        "main_idea", "main_idea_score",
        "inference", "inference_score",
        "vocabulary", "vocabulary_score",
        "attitude", "attitude_score",
        "number", "number_score"
    );
    
    // EMA 平滑系数（越大越偏向新数据）
    private static final double EMA_ALPHA = 0.3;
    
    /**
     * 练习完成后增量更新听力能力画像
     */
    @Transactional
    public void updateProfile(Long userId, Map<String, Double> newSkillScores) {
        ListeningSkillProfile profile = profileRepository
            .findByUserIdForUpdate(userId)
            .orElseGet(() -> createNewProfile(userId));
        
        // EMA 更新各技能维度
        for (Map.Entry<String, Double> entry : newSkillScores.entrySet()) {
            String skill = entry.getKey();
            Double newScore = entry.getValue();
            String fieldName = SKILL_FIELD_MAP.get(skill);
            if (fieldName == null) continue;
            
            double oldScore = getFieldValue(profile, fieldName);
            double updated = oldScore == 0 
                ? newScore 
                : EMA_ALPHA * newScore + (1 - EMA_ALPHA) * oldScore;
            setFieldValue(profile, fieldName, updated);
        }
        
        // 更新综合等级
        double overallAvg = calculateOverallAverage(profile);
        profile.setOverallLevel(scoreToLevel(overallAvg));
        
        // 更新最近正确率趋势
        profile.setTotalPracticeCount(profile.getTotalPracticeCount() + 1);
        updateRecentAccuracy(profile, newSkillScores);
        
        profileRepository.save(profile);
        
        // 发送学习行为事件
        eventPublisher.publishEvent(new ListeningPracticeCompletedEvent(
            userId, newSkillScores, profile.getOverallLevel()));
    }
    
    /**
     * 分数 → 等级映射
     */
    private int scoreToLevel(double score) {
        if (score >= 95) return 8;
        if (score >= 85) return 7;
        if (score >= 75) return 6;
        if (score >= 65) return 5;
        if (score >= 55) return 4;
        if (score >= 45) return 3;
        if (score >= 30) return 2;
        return 1;
    }
}
```

```java
@Service
public class ListeningRecommendationService {

    /**
     * 基于能力画像推荐听力练习
     * 策略：
     * 1. 优先推荐薄弱技能对应的练习
     * 2. 难度略高于当前水平（+1级）
     * 3. 避免近期重复推荐同一资源
     */
    public List<ListeningResource> recommend(Long userId, int count) {
        ListeningSkillProfile profile = profileRepository.findByUserId(userId)
            .orElse(null);
        
        // 查找近期已做过的资源ID，避免重复
        Set<Long> recentResourceIds = practiceRepository
            .findRecentResourceIds(userId, LocalDate.now().minusDays(7))
            .stream().collect(Collectors.toSet());
        
        if (profile == null || profile.getOverallLevel() == null) {
            // 冷启动：按用户年级推荐基础难度资源
            return resourceRepository.findRandomByGrade(
                getUserGrade(userId), 1, count, recentResourceIds);
        }
        
        // 找出最弱技能
        List<String> weakSkills = getWeakSkills(profile);
        int targetDifficulty = Math.min(profile.getOverallLevel() + 1, 8);
        
        // 按薄弱技能匹配资源
        return resourceRepository.findBySkillAndDifficulty(
            weakSkills, targetDifficulty, profile.getGradeRange(),
            recentResourceIds, PageRequest.of(0, count));
    }
    
    private List<String> getWeakSkills(ListeningSkillProfile profile) {
        Map<String, Double> scores = Map.of(
            "detail", profile.getDetailScore(),
            "main_idea", profile.getMainIdeaScore(),
            "inference", profile.getInferenceScore(),
            "vocabulary", profile.getVocabularyScore(),
            "attitude", profile.getAttitudeScore(),
            "number", profile.getNumberScore()
        );
        
        return scores.entrySet().stream()
            .sorted(Map.Entry.comparingByValue())
            .limit(2)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
    }
}
```

```dart
        _player.pause();
        _positionSubscription?.cancel();
      }
    });
  }
  
  /// 变速播放
  Future<void> setSpeed(double speed) async {
    _speed = speed;
    await _player.setSpeed(speed);
    notifyListeners();
  }
```

```dart
class AudioLoadStrategy {
  /// 三级降级加载策略
  Future<String> getPlayableUrl(String resourceId) async {
    // Level 1: 本地缓存
    final localPath = await _cacheManager.getLocalPath(resourceId);
    if (localPath != null && await File(localPath).exists()) {
      return localPath;
    }
    
    // Level 2: 主CDN
    try {
      final url = await _cdnService.getSignedUrl(resourceId, cdn: 'primary');
      // 预检验（HEAD请求）
      final accessible = await _checkUrlAccessible(url);
      if (accessible) return url;
    } catch (e) {
      _logger.warn('Primary CDN failed for $resourceId: $e');
    }
    
    // Level 3: 备用CDN
    try {
      final fallbackUrl = await _cdnService.getSignedUrl(resourceId, cdn: 'fallback');
      return fallbackUrl;
    } catch (e) {
      throw ListeningException(
        code: 'LISTENING_003',
        message: '音频加载失败，请检查网络后重试',
      );
    }
  }
}
```

### 8.3 弱网与断线处理

```
音频播放中网络断开：
  ├─ 已缓冲部分：继续播放至缓冲末尾
  ├─ 未缓冲：暂停播放，显示"网络连接中断"提示
  ├─ 自动重试连接（最多3次，间隔2s）
  └─ 恢复后：从断点续播

答题过程中断线：
  ├─ 答案暂存本地（SharedPreferences / SQLite）
  ├─ 恢复后自动同步到服务端
  └─ 考试模式：倒计时暂停，断线不计入考试时间
```

## 10. 性能与缓存策略

### 10.1 音频缓存策略

| 层级 | 存储 | 策略 |
|------|------|------|
| 内存缓存 | 内存 | 当前播放音频的前30s预加载 |
| 磁盘缓存 | 本地文件 | LRU策略，最大500MB，最近使用保留 |
| CDN缓存 | CDN边缘节点 | 热门资源7天缓存，冷资源24小时 |

### 10.2 接口性能要求

| 接口 | 目标响应时间 | 说明 |
|------|-------------|------|
| 获取练习列表 | < 500ms | 支持分页缓存 |
| 开始练习 | < 1s | 含音频签名URL生成 |
| 提交答案 | < 2s | 含批改 + 能力更新 |
| 音频首字节 | < 300ms | CDN边缘节点命中 |

### 10.3 数据库查询优化

```sql
-- 高频查询：用户最近练习记录
SELECT id, practice_code, practice_type, resource_id, score, created_at
FROM listening_practice
WHERE user_id = ? AND status = 'completed'
ORDER BY created_at DESC
LIMIT 20;
-- 优化：idx_user_time (user_id, created_at)

-- 高频查询：按技能标签匹配资源
SELECT DISTINCT r.* FROM listening_resource r
INNER JOIN listening_question q ON q.resource_id = r.id
WHERE JSON_CONTAINS(q.skill_tags, '"inference"')
  AND r.difficulty BETWEEN 3 AND 5
  AND r.grade_range = 'junior'
  AND r.status = 2;
-- 优化：skill_tags 使用多值索引或冗余 skill_tag 关联表
```

## 11. 安全与合规

### 11.1 内容安全

- 所有听力音频资源经过人工审核，确保内容适宜未成年人
- 音频 URL 使用带过期时间的签名，防盗链
- 听力原文（transcript）仅在练习完成后返回，防止提前查看

### 11.2 考试防作弊

- 考试模式下禁用截屏和录屏
- 考试音频仅播放指定遍数，不可额外重听
- 答题时间记录精确到毫秒，异常短时答题标记风控
- 设备指纹校验，防止多设备同时考试

### 11.3 额度控制

```
免费用户：每日 3 次听力练习
月度会员：每日 10 次听力练习 + 2 次考试模拟
年度会员：无限次听力练习 + 无限次考试模拟

听力额度计入用户额度管控引擎的统一额度池。
```
