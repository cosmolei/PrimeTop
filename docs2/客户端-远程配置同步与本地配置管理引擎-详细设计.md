# 客户端-远程配置同步与本地配置管理引擎-详细设计

## 1. 概述

### 1.1 模块定位

远程配置同步与本地配置管理引擎是 PrimeTop 客户端的核心基础设施模块，负责从服务端拉取配置数据、在本地持久化缓存、监听实时变更并向业务模块广播，确保 APP 在不发版的前提下动态调整功能开关、UI 主题、AI 模型参数、运营活动、应急管控等配置项。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| **实时性** | 关键配置变更（如紧急下线）10 秒内生效 |
| **高可用** | 配置服务不可用时，APP 使用本地缓存正常运行 |
| **低开销** | 日常配置同步网络流量 < 50KB/天（增量模式） |
| **线程安全** | 配置读取无锁，写入原子化 |
| **可观测** | 配置版本、同步状态、异常全链路追踪 |

### 1.3 适用范围

- Flutter 客户端（Android / iOS）
- 配合服务端「配置中心与动态配置管理」使用
- 不涵盖：用户个人偏好设置（由 `客户端用户偏好设置与学习环境个性化系统` 负责）

## 3. 数据结构定义

### 3.1 配置命名空间

所有远程配置按命名空间（namespace）组织，每个命名空间对应一个业务域：

```dart
enum ConfigNamespace {
  /// 功能开关：控制各功能模块的启用/禁用
  featureFlags,      // "feature_flags"

  /// AI 模型配置：模型选择、参数、降级策略
  aiModel,           // "ai_model"

  /// UI 主题与外观：主题色、字体大小、暗黑模式
  uiTheme,           // "ui_theme"

  /// 运营配置：弹窗规则、Banner、公告
  operation,         // "operation"

  /// 学段适配：各年级可用学科、教材版本列表
  gradeMapping,      // "grade_mapping"

  /// 会员与计费：权益列表、限额数值、试用策略
  membership,        // "membership"

  /// 安全管控：强制升级版本、维护模式、紧急公告
  emergency,         // "emergency"

  /// AB 实验：实验分组配置
  experiment,        // "experiment"

  /// 学习参数：遗忘曲线参数、推荐策略权重
  learningParams,    // "learning_params"
}
```

### 3.2 配置项数据模型

#### 3.2.1 单个配置项

```dart
/// 单个配置项的完整元数据结构
class ConfigEntry {
  final String key;              // 配置键，格式: namespace.field_name
  final dynamic value;           // 配置值（String/int/bool/double/JsonObject）
  final ConfigValueType type;    // 值类型枚举
  final int version;             // 配置版本号（全局递增）
  final DateTime updatedAt;      // 服务端更新时间
  final String? md5;             // 值的 MD5 摘要（用于增量比对）
  final ConfigEntryMeta meta;    // 扩展元数据

  const ConfigEntry({
    required this.key,
    required this.value,
    required this.type,
    required this.version,
    required this.updatedAt,
    this.md5,
    required this.meta,
  });

  factory ConfigEntry.fromJson(Map<String, dynamic> json) => ConfigEntry(
    key: json['key'] as String,
    value: json['value'],
    type: ConfigValueType.fromName(json['type'] as String),
    version: json['version'] as int,
    updatedAt: DateTime.parse(json['updatedAt'] as String),
    md5: json['md5'] as String?,
    meta: ConfigEntryMeta.fromJson(json['meta'] as Map<String, dynamic>),
  );
}

enum ConfigValueType {
  string, boolean, integer, double_, json;

  static ConfigValueType fromName(String name) =>
    values.firstWhere((e) => e.name == name,
      orElse: () => ConfigValueType.string);
}

class ConfigEntryMeta {
  final String? description;     // 配置描述（调试用）
  final dynamic defaultValue;    // 默认值（远程未下发时的兜底）
  final List<String>? tags;      // 标签：如 ["p0", "hot", "internal"]

  const ConfigEntryMeta({this.description, this.defaultValue, this.tags});

  factory ConfigEntryMeta.fromJson(Map<String, dynamic> json) =>
    ConfigEntryMeta(
      description: json['description'] as String?,
      defaultValue: json['defaultValue'],
      tags: (json['tags'] as List<dynamic>?)?.cast<String>(),
    );
}
```

## 4. API 接口设计

### 4.1 全量配置拉取

```
GET /api/v1/config/bundle
```

**请求头：**

| Header | 说明 |
| --- | --- |
| Authorization | Bearer {token}（已登录时携带） |
| X-Device-Id | 设备唯一标识 |
| X-App-Version | 客户端版本号（如 "1.0.5"） |
| X-Platform | android / ios |
| X-Config-Version | 当前本地配置版本号（用于 304 判断） |
| If-None-Match | 上次响应的 ETag（可选） |

**响应：**

| HTTP状态码 | 说明 | 处理逻辑 |
| --- | --- | --- |
| 200 | 全量配置数据 | 解析并全量替换本地缓存 |
| 304 | 配置未变更 | 跳过更新，保持本地缓存 |
| 401 | 未授权 | 使用匿名配置（基础功能） |
| 5xx | 服务异常 | 使用本地缓存，进入降级模式 |

### 4.2 增量配置拉取

```
GET /api/v1/config/delta?since={version}
```

**路径参数：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| since | int | 本地配置版本号 |

**响应（200）：**

增量 JSON Patch 格式（见 3.4.2）。

**特殊响应码：**

| code | 说明 | 处理 |
| --- | --- | --- |
| 0 | 成功 | 应用 Patch |
| 40901 | 版本跨度过大（超过100个版本） | 触发全量拉取 |
| 40902 | 版本已过期 | 触发全量拉取 |

```
WSS /ws/config?deviceId={deviceId}&configVersion={version}
```

## 5. 核心代码实现

### 5.1 ConfigStore — 配置统一读取入口

```dart
/// 全局配置读取入口，所有业务模块通过此单例获取配置
///
/// 线程安全说明：Dart 是单线程事件循环模型，不存在多线程竞争。
/// 对于 [Isolate] 场景，通过 [sendPort] 传递配置快照副本。
class ConfigStore {
  static final ConfigStore _instance = ConfigStore._();
  static ConfigStore get instance => _instance;
  ConfigStore._();

  final ConfigBox _box = ConfigBox();
  final ConfigEventBus _eventBus = ConfigEventBus();
  final RemoteConfigService _remote = RemoteConfigService();

  bool _initialized = false;

  /// 初始化，在 APP 启动管线中调用
  Future<void> initialize({
    required String deviceId,
    String? userId,
    required String appVersion,
    required String platform,
  }) async {
    if (_initialized) return;

    // 1. 加载本地缓存（同步操作，确保首屏可用）
    await _box.loadFromDisk();

    // 2. 标记初始化完成
    _initialized = true;

    // 3. 异步拉取远程配置（不阻塞启动）
    _remote
        .fetchFullBundle(
          deviceId: deviceId,
          userId: userId,
          appVersion: appVersion,
          platform: platform,
          localVersion: _box.currentVersion,
        )
        .then((result) {
          if (result == null) return; // 304 Not Modified
          _applySnapshot(result);
        }).catchError((e) {
          // 网络异常，使用本地缓存继续运行
          _log.severe('Remote config fetch failed, using local cache', e);
        });

    // 4. 建立 WebSocket 连接（延迟 5 秒，避免启动并发压力）
    Future.delayed(const Duration(seconds: 5), () {
      _remote.connectWebSocket(
        deviceId: deviceId,
        configVersion: _box.currentVersion,
        onMessage: _handleWebSocketMessage,
        onError: _handleWebSocketError,
        onDisconnect: _handleWebSocketDisconnect,
      );
    });

    // 5. 启动定时增量轮询（兜底保障，每 15 分钟）
    Timer.periodic(const Duration(minutes: 15), (_) => _pollIncremental());
  }

  // ===================== 配置读取 API =====================

  /// 读取布尔型配置
  bool getBool(String key, {bool defaultValue = false}) {
    _ensureInitialized();
    return _box.getValue(key, defaultValue: defaultValue);
  }

  /// 读取字符串配置
  String getString(String key, {String defaultValue = ''}) {
    _ensureInitialized();
    return _box.getValue(key, defaultValue: defaultValue);
  }

  /// 读取整型配置
  int getInt(String key, {int defaultValue = 0}) {
    _ensureInitialized();
    return _box.getValue(key, defaultValue: defaultValue);
  }

  /// 读取浮点型配置
  double getDouble(String key, {double defaultValue = 0.0}) {
    _ensureInitialized();
    return _box.getValue(key, defaultValue: defaultValue);
  }

  /// 读取 JSON 配置，返回解析后的 Map
  Map<String, dynamic>? getJson(String key) {
    _ensureInitialized();
    final raw = _box.getRawValue(key);
    if (raw == null) return null;
    if (raw is Map<String, dynamic>) return raw;
    return null;
  }

  /// 获取配置条目的完整元数据
  ConfigEntry? getEntry(String key) {
    _ensureInitialized();
    return _box.getEntry(key);
  }

  // ===================== 配置监听 API =====================

  /// 监听单个配置项变更
  ///
  /// 返回 [Stream]，当该 key 的值变化时发出新值。
  /// 自动发出当前值作为第一个事件。
  Stream<T> observe<T>(String key, {required T defaultValue}) {
    _ensureInitialized();
    // 先发出当前值
    final controller = StreamController<T>();
    controller.add(_box.getValue(key, defaultValue: defaultValue));

    // 监听变更
    _eventBus.on<T>(key).listen((value) {
      if (!controller.isClosed) controller.add(value);
    });

    return controller.stream;
  }

  /// 监听某个命名空间下所有配置变更
  Stream<ConfigNamespaceChange> observeNamespace(ConfigNamespace ns) {
    _ensureInitialized();
    return _eventBus.onNamespace(ns);
  }

  // ===================== 内部方法 =====================

  void _ensureInitialized() {
    if (!_initialized) {
      throw StateError(
          'ConfigStore not initialized. Call initialize() first.');
    }
  }

  /// 应用全量配置快照
  void _applySnapshot(ConfigSnapshot snapshot) {
    final changedKeys = <String>[];

    for (final ns in ConfigNamespace.values) {
      final nsEntries = snapshot.entries[ns];
      if (nsEntries == null) continue;

      for (final entry in nsEntries.entries) {
        final oldEntry = _box.getEntry(entry.key);
        if (oldEntry == null || oldEntry.value != entry.value.value) {
          _box.putEntry(entry.key, entry.value);
          changedKeys.add(entry.key);
        }
      }
    }

    _box.setVersion(snapshot.version);
    _box.setServerTime(snapshot.serverTime);

    // 批量通知
    if (changedKeys.isNotEmpty) {
      _eventBus.fireBatch(changedKeys, _box);
    }
  }

  /// 处理 WebSocket 推送消息
  void _handleWebSocketMessage(Map<String, dynamic> message) {
    final type = message['type'] as String;

    switch (type) {
      case 'config_changed':
        _handleConfigChanged(message);
        break;
      case 'ping':
        // 回复 pong，携带当前版本号
        _remote.sendPong(_box.currentVersion);
        break;
      case 'force_reload':
        // 服务端要求强制全量拉取
        _remote.fetchFullBundle(
          deviceId: _remote.deviceId!,
          localVersion: _box.currentVersion,
        ).then((snapshot) {
          if (snapshot != null) _applySnapshot(snapshot);
        });
        break;
    }
  }

  void _handleConfigChanged(Map<String, dynamic> message) {
    final entries = (message['entries'] as List<dynamic>? ?? []);
    final changedKeys = <String>[];

    for (final entryJson in entries) {
      final entry = ConfigEntry.fromJson(entryJson as Map<String, dynamic>);
      _box.putEntry(entry.key, entry);
      changedKeys.add(entry.key);
    }

    if (changedKeys.isNotEmpty) {
      final version = message['version'] as int? ?? _box.currentVersion;
      _box.setVersion(version);
      _eventBus.fireBatch(changedKeys, _box);
    }
  }

  /// 定时增量轮询（WebSocket 兜底）
  Future<void> _pollIncremental() async {
    try {
      final result = await _remote.fetchDelta(_box.currentVersion);
      if (result == null) return;

      if (result.isFullResync) {
        // 服务端要求全量同步
        final snapshot = await _remote.fetchFullBundle(
          deviceId: _remote.deviceId!,
          localVersion: _box.currentVersion,
        );
        if (snapshot != null) _applySnapshot(snapshot);
      } else {
        _applyPatches(result.patches);
      }
    } catch (e) {
      _log.warning('Incremental poll failed', e);
    }
  }

  /// 应用增量 Patch
  void _applyPatches(List<ConfigPatch> patches) {
    final changedKeys = <String>{};

    for (final patch in patches) {
      switch (patch.op) {
        case PatchOp.replace:
          final key = _extractKeyFromPath(patch.path);
          if (key != null) {
            _box.updateValue(key, patch.value);
            changedKeys.add(key);
          }
          break;
        case PatchOp.add:
          final key = _extractKeyFromPath(patch.path);
          if (key != null && patch.value != null) {
            final entry = ConfigEntry.fromJson(
              (patch.value as Map).cast<String, dynamic>(),
            );
            _box.putEntry(key, entry);
            changedKeys.add(key);
          }
          break;
        case PatchOp.remove:
          final key = _extractKeyFromPath(patch.path);
          if (key != null) {
            _box.removeEntry(key);
            changedKeys.add(key);
          }
          break;
        case PatchOp.move:
          // 配置场景通常不使用 move 操作
          break;
      }
    }

    if (changedKeys.isNotEmpty) {
      _eventBus.fireBatch(changedKeys.toList(), _box);
    }
  }

  String? _extractKeyFromPath(String jsonPatchPath) {
    // path 格式: "/namespace/key_field/sub_field"
    // 提取 namespace + key
    final parts = jsonPatchPath.split('/').where((p) => p.isNotEmpty).toList();
    if (parts.length < 2) return null;
    return '${parts[0]}.${parts[1]}';
  }

  void _handleWebSocketError(dynamic error) {
    _log.warning('Config WebSocket error', error);
    // WebSocket 断开后，加速定时轮询频率
    // 由 RemoteConfigService 内部处理重连和退避
  }

  void _handleWebSocketDisconnect() {
    _log.info('Config WebSocket disconnected, will retry');
    _box.setWsConnected(false);
  }
}
```

### 5.2 ConfigBox — 本地持久化层

```dart
/// 配置本地持久化层，基于 Hive
///
/// 设计原则：
/// 1. 读写分离：读操作走内存缓存（O(1)），写操作同步落盘
/// 2. 原子写入：单次操作要么全部成功，要么全部失败
/// 3. 版本追踪：保留最近 N 个版本用于回滚
class ConfigBox {
  static const String _boxName = 'config_box';

  late Box _box;
  final Map<String, ConfigEntry> _memoryCache = {};
  int _currentVersion = 0;
  DateTime _serverTime = DateTime.now();

  bool _loaded = false;

  /// 从磁盘加载
  Future<void> loadFromDisk() async {
    if (_loaded) return;
    _box = await Hive.openBox(_boxName);

    // 加载所有 entry: 前缀的数据到内存
    for (final key in _box.keys) {
      final keyStr = key.toString();
      if (keyStr.startsWith('entry:')) {
        final configKey = keyStr.substring(6);
        final json = _box.get(key) as Map?;
        if (json != null) {
          _memoryCache[configKey] =
              ConfigEntry.fromJson(json.cast<String, dynamic>());
        }
      }
    }

    _currentVersion = _box.get('snapshot:version', defaultValue: 0) as int;
    final stStr = _box.get('snapshot:serverTime') as String?;
    if (stStr != null) _serverTime = DateTime.parse(stStr);

    _loaded = true;
  }

  int get currentVersion => _currentVersion;
  DateTime get serverTime => _serverTime;

  void setVersion(int version) {
    _currentVersion = version;
    _box.put('snapshot:version', version);
  }

  void setServerTime(DateTime time) {
    _serverTime = time;
    _box.put('snapshot:serverTime', time.toIso8601String());
  }

  void setWsConnected(bool connected) {
    _box.put('ws:connected', connected);
  }

  /// 获取配置值（泛型）
  T getValue<T>(String key, {required T defaultValue}) {
    final entry = _memoryCache[key];
    if (entry == null) return defaultValue;
    final value = entry.value;
    if (value is T) return value;
    // 类型转换容错
    if (T == bool) return (value == true || value == 'true') as T;
    if (T == int) return (int.tryParse('$value') ?? defaultValue) as T;
    if (T == double) return (double.tryParse('$value') ?? defaultValue) as T;
    if (T == String) return '$value' as T;
    return defaultValue;
  }

  dynamic getRawValue(String key) {
    return _memoryCache[key]?.value;
  }

  ConfigEntry? getEntry(String key) => _memoryCache[key];

  void putEntry(String key, ConfigEntry entry) {
    _memoryCache[key] = entry;
    _box.put('entry:$key', entry.toJson());
  }

  void updateValue(String key, dynamic newValue) {
    final existing = _memoryCache[key];
    if (existing == null) return;
    final updated = ConfigEntry(
      key: existing.key,
      value: newValue,
      type: existing.type,
      version: _currentVersion,
      updatedAt: DateTime.now(),
      md5: _computeMd5(newValue),
      meta: existing.meta,
    );
    putEntry(key, updated);
  }

  void removeEntry(String key) {
    _memoryCache.remove(key);
    _box.delete('entry:$key');
  }

  /// 保存版本历史（用于回滚）
  Future<void> saveVersionHistory(int version) async {
    final history = _box.get('history:versions', defaultValue: []) as List;
    final versions = history.cast<int>();
    versions.add(version);
    // 只保留最近 10 个版本
    while (versions.length > 10) {
      final removed = versions.removeAt(0);
      _box.delete('history:$removed');
    }
    await _box.put('history:versions', versions);
  }

  String _computeMd5(dynamic value) {
    final str = value.toString();
    return md5.convert(utf8.encode(str)).toString();
  }

  /// 导出当前快照（用于 Isolate 传递或调试）
  Map<String, dynamic> exportSnapshot() {
    return {
      'version': _currentVersion,
      'serverTime': _serverTime.toIso8601String(),
      'entries': _memoryCache.map((k, v) => MapEntry(k, v.toJson())),
    };
  }
}
```

### 5.3 ConfigEventBus — 配置变更事件总线

```dart
/// 配置变更事件总线
///
/// 设计特点：
/// 1. 基于 Stream，支持多个订阅者
/// 2. 批量变更节流：100ms 内的多个变更合并通知
/// 3. 命名空间级别聚合通知
class ConfigEventBus {
  final Map<String, StreamController<dynamic>> _keyControllers = {};
  final Map<ConfigNamespace, StreamController<ConfigNamespaceChange>> _nsControllers = {};
  final Logger _log = Logger('ConfigEventBus');

  /// 批量变更缓冲
  final Map<String, dynamic> _pendingChanges = {};
  Timer? _batchTimer;
  static const Duration _batchWindow = Duration(milliseconds: 100);

  /// 订阅单个 key 的变更
  Stream<T> on<T>(String key) {
    final controller = _keyControllers.putIfAbsent(
      key,
      () => StreamController<dynamic>.broadcast(),
    );
    return controller.stream.cast<T>();
  }

  /// 订阅命名空间变更
  Stream<ConfigNamespaceChange> onNamespace(ConfigNamespace ns) {
    final controller = _nsControllers.putIfAbsent(
      ns,
      () => StreamController<ConfigNamespaceChange>.broadcast(),
    );
    return controller.stream;
  }

  /// 批量触发变更通知（节流 100ms）
  void fireBatch(List<String> changedKeys, ConfigBox box) {
    for (final key in changedKeys) {
      _pendingChanges[key] = box.getRawValue(key);
    }

    _batchTimer?.cancel();
    _batchTimer = Timer(_batchWindow, () {
      _flushPendingChanges();
    });
  }

  void _flushPendingChanges() {
    final changes = Map<String, dynamic>.from(_pendingChanges);
    _pendingChanges.clear();

    // 1. 通知 key 级别订阅者
    for (final entry in changes.entries) {
      final controller = _keyControllers[entry.key];
      if (controller != null && !controller.isClosed) {
        controller.add(entry.value);
      }
    }

    // 2. 通知命名空间级别订阅者
    final nsChanges = <ConfigNamespace, List<String>>{};
    for (final key in changes.keys) {
      final nsName = key.split('.').first;
      final ns = _parseNamespace(nsName);
      if (ns != null) {
        nsChanges.putIfAbsent(ns, () => []).add(key);
      }
    }

    for (final entry in nsChanges.entries) {
      final controller = _nsControllers[entry.key];
      if (controller != null && !controller.isClosed) {
        controller.add(ConfigNamespaceChange(
          namespace: entry.key,
          changedKeys: entry.value,
          timestamp: DateTime.now(),
        ));
      }
    }

    _log.fine('Config changes flushed: ${changes.length} keys updated');
  }

  ConfigNamespace? _parseNamespace(String name) {
    try {
      return ConfigNamespace.values.firstWhere((e) => e.name == name);
    } catch (_) {
      return null;
    }
  }

  void dispose() {
    _batchTimer?.cancel();
    for (final c in _keyControllers.values) {
      c.close();
    }
    for (final c in _nsControllers.values) {
      c.close();
    }
  }
}

/// 命名空间变更事件
class ConfigNamespaceChange {
  final ConfigNamespace namespace;
  final List<String> changedKeys;
  final DateTime timestamp;

  const ConfigNamespaceChange({
    required this.namespace,
    required this.changedKeys,
    required this.timestamp,
  });
}
```

### 5.4 RemoteConfigService — 远程配置服务

```dart
/// 远程配置服务：负责 HTTP 拉取和 WebSocket 实时推送
class RemoteConfigService {
  final Logger _log = Logger('RemoteConfigService');

  // HTTP 客户端
  final Dio _dio;

  // WebSocket
  WebSocketChannel? _wsChannel;
  Timer? _wsReconnectTimer;
  Timer? _wsHeartbeatTimer;
  int _wsReconnectAttempts = 0;
  bool _wsConnected = false;
  static const int _maxReconnectAttempts = 5;

  // 连续失败后退避
  static const List<Duration> _backoffDurations = [
    Duration(seconds: 5),
    Duration(seconds: 10),
    Duration(seconds: 30),
    Duration(seconds: 60),
    Duration(seconds: 120),
  ];

  // 设备信息（初始化时注入）
  String? _deviceId;
  String? _userId;
  String? _appVersion;
  String? _platform;

  RemoteConfigService({Dio? dio}) : _dio = dio ?? Dio();

  String? get deviceId => _deviceId;

  Future<ConfigSnapshot?> fetchFullBundle({
    required String deviceId,
    String? userId,
    required String appVersion,
    required String platform,
    int? localVersion,
  }) async {
    _deviceId = deviceId;
    _userId = userId;
    _appVersion = appVersion;
    _platform = platform;

    try {
      final response = await _dio.get(
        '/api/v1/config/bundle',
        options: Options(headers: {
          'X-Device-Id': deviceId,
          if (userId != null) 'Authorization': 'Bearer $userId',
          'X-App-Version': appVersion,
          'X-Platform': platform,
          if (localVersion != null) 'X-Config-Version': localVersion.toString(),
        }),
      );

      if (response.statusCode == 304) {
        _log.info('Config not modified (304)');
        return null;
      }

      final data = response.data['data'] as Map<String, dynamic>;
      return _parseSnapshot(data);
    } on DioException catch (e) {
      if (e.response?.statusCode == 304) return null;
      _log.warning('Full bundle fetch failed', e);
      return null; // 返回 null 表示使用本地缓存
    }
  }

  Future<DeltaResult?> fetchDelta(int sinceVersion) async {
    if (_deviceId == null) return null;

    try {
      final response = await _dio.get(
        '/api/v1/config/delta',
        queryParameters: {'since': sinceVersion},
        options: Options(headers: {
          'X-Device-Id': _deviceId!,
          if (_userId != null) 'Authorization': 'Bearer $_userId',
          'X-App-Version': _appVersion ?? '',
          'X-Platform': _platform ?? '',
        }),
      );

      final code = response.data['code'] as int;
      if (code == 40901 || code == 40902) {
        // 版本跨度过大或已过期，需要全量同步
        return DeltaResult(isFullResync: true, patches: []);
      }

      final data = response.data['data'] as Map<String, dynamic>;
      final patchesJson = data['patches'] as List<dynamic>;
      final patches = patchesJson
          .map((p) => ConfigPatch.fromJson(p as Map<String, dynamic>))
          .toList();

      return DeltaResult(isFullResync: false, patches: patches);
    } catch (e) {
      _log.warning('Delta fetch failed', e);
      return null;
    }
  }

  // ===================== WebSocket =====================

  void connectWebSocket({
    required String deviceId,
    required int configVersion,
    required void Function(Map<String, dynamic>) onMessage,
    required void Function(dynamic) onError,
    required void Function() onDisconnect,
  }) {
    _deviceId = deviceId;

    _connectWs(
      deviceId: deviceId,
      configVersion: configVersion,
      onMessage: onMessage,
      onError: onError,
      onDisconnect: onDisconnect,
    );
  }

  void _connectWs({
    required String deviceId,
    required int configVersion,
    required void Function(Map<String, dynamic>) onMessage,
    required void Function(dynamic) onError,
    required void Function() onDisconnect,
  }) async {
    if (_wsReconnectAttempts >= _maxReconnectAttempts) {
      _log.warning('Max WebSocket reconnect attempts reached, '
          'falling back to polling only');
      return;
    }

    try {
      final uri = Uri.parse(
        '${ConfigConstants.wsBaseUrl}/ws/config'
        '?deviceId=$deviceId&configVersion=$configVersion',
      );
      _wsChannel = WebSocketChannel.connect(uri);

      _wsConnected = true;
      _wsReconnectAttempts = 0;

      // 发送订阅确认
      _wsChannel!.sink.add(jsonEncode({
        'type': 'subscribe',
        'namespaces': ConfigNamespace.values.map((e) => e.name).toList(),
        'configVersion': configVersion,
      }));

      // 启动心跳
      _startHeartbeat();

      // 监听消息
      _wsChannel!.stream.listen(
        (data) {
          try {
            final msg = jsonDecode(data as String) as Map<String, dynamic>;
            onMessage(msg);
          } catch (e) {
            _log.warning('Failed to parse WebSocket message', e);
          }
        },
        onError: (error) {
          _wsConnected = false;
          _stopHeartbeat();
          onError(error);
          _scheduleReconnect(
            deviceId: deviceId,
            configVersion: configVersion,
            onMessage: onMessage,
            onError: onError,
            onDisconnect: onDisconnect,
          );
        },
        onDone: () {
          _wsConnected = false;
          _stopHeartbeat();
          onDisconnect();
          _scheduleReconnect(
            deviceId: deviceId,
            configVersion: configVersion,
            onMessage: onMessage,
            onError: onError,
            onDisconnect: onDisconnect,
          );
        },
      );
    } catch (e) {
      _wsConnected = false;
      onError(e);
      _scheduleReconnect(
        deviceId: deviceId,
        configVersion: configVersion,
        onMessage: onMessage,
        onError: onError,
        onDisconnect: onDisconnect,
      );
    }
  }

  void _scheduleReconnect({
    required String deviceId,
    required int configVersion,
    required void Function(Map<String, dynamic>) onMessage,
    required void Function(dynamic) onError,
    required void Function() onDisconnect,
  }) {
    final backoff = _backoffDurations[
        _wsReconnectAttempts.clamp(0, _backoffDurations.length - 1)];
    _wsReconnectAttempts++;

    _log.info('WebSocket reconnecting in ${backoff.inSeconds}s '
        '(attempt $_wsReconnectAttempts/$_maxReconnectAttempts)');

    _wsReconnectTimer?.cancel();
    _wsReconnectTimer = Timer(backoff, () {
      _connectWs(
        deviceId: deviceId,
        configVersion: configVersion,
        onMessage: onMessage,
        onError: onError,
        onDisconnect: onDisconnect,
      );
    });
  }

  void _startHeartbeat() {
    _wsHeartbeatTimer?.cancel();
    _wsHeartbeatTimer = Timer.periodic(
      const Duration(seconds: 30),
      (_) => sendPing(),
    );
  }

  void _stopHeartbeat() {
    _wsHeartbeatTimer?.cancel();
    _wsHeartbeatTimer = null;
  }

  void sendPing() {
    if (_wsChannel != null && _wsConnected) {
      _wsChannel!.sink.add(jsonEncode({'type': 'ping'}));
    }
  }

  void sendPong(int configVersion) {
    if (_wsChannel != null && _wsConnected) {
      _wsChannel!.sink.add(jsonEncode({
        'type': 'pong',
        'configVersion': configVersion,
      }));
    }
  }

  void dispose() {
    _stopHeartbeat();
    _wsReconnectTimer?.cancel();
    _wsChannel?.sink.close();
  }

  // ===================== 解析逻辑 =====================

  ConfigSnapshot _parseSnapshot(Map<String, dynamic> data) {
    final entriesMap = data['entries'] as Map<String, dynamic>;
    final entries = <ConfigNamespace, Map<String, ConfigEntry>>{};

    for (final nsEntry in entriesMap.entries) {
      final ns = _parseNamespace(nsEntry.key);
      if (ns == null) continue;

      final nsItems = nsEntry.value as Map<String, dynamic>;
      entries[ns] = {};

      for (final itemEntry in nsItems.entries) {
        final configEntry =
            ConfigEntry.fromJson(itemEntry.value as Map<String, dynamic>);
        entries[ns]![configEntry.key] = configEntry;
      }
    }

    return ConfigSnapshot(
      version: data['version'] as int,
      serverTime: DateTime.parse(data['serverTime'] as String),
      deviceId: _deviceId ?? 'unknown',
      userId: _userId ?? 'anonymous',
      entries: entries,
    );
  }
}

/// 增量拉取结果
class DeltaResult {
  final bool isFullResync;
  final List<ConfigPatch> patches;

  const DeltaResult({required this.isFullResync, required this.patches});
}

/// JSON Patch 操作
class ConfigPatch {
  final PatchOp op;
  final String path;
  final dynamic value;

  const ConfigPatch({
    required this.op,
    required this.path,
    this.value,
  });

  factory ConfigPatch.fromJson(Map<String, dynamic> json) => ConfigPatch(
        op: PatchOp.fromName(json['op'] as String),
        path: json['path'] as String,
        value: json['value'],
      );
}

enum PatchOp {
  replace, add, remove, move;

  static PatchOp fromName(String name) =>
      values.firstWhere((e) => e.name == name, orElse: () => PatchOp.replace);
}
```

```dart
class SplashPage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return FutureBuilder<SplashDecision>(
      future: _decideSplash(),
      builder: (context, snapshot) {
        if (!snapshot.hasData) {
          return const LoadingIndicator();
        }

        switch (snapshot.data!) {
          case SplashDecision.maintenance:
            return const MaintenancePage();
          case SplashDecision.forceUpgrade:
            return const ForceUpgradePage();
          case SplashDecision.normal:
            return const HomePage();
        }
      },
    );
  }

  Future<SplashDecision> _decideSplash() async {
    final config = ConfigStore.instance;

    // 检查维护模式
    if (config.getBool('emergency.maintenance_mode', defaultValue: false)) {
      return SplashDecision.maintenance;
    }

    // 检查强制升级
    if (config.getBool('emergency.force_upgrade', defaultValue: false)) {
      final minVersion = config.getString('emergency.min_version',
          defaultValue: '0.0.0');
      if (compareVersions(DeviceInfo.appVersion, minVersion) < 0) {
        return SplashDecision.forceUpgrade;
      }
    }

    return SplashDecision.normal;
  }
```

## 8. 错误处理与降级策略

### 8.1 异常场景与处理

| 场景 | 触发条件 | 处理策略 | 用户感知 |
| --- | --- | --- | --- |
| 首次启动无缓存 | APP 首次安装 | 使用代码内置默认值 | 无感知（默认值保证基础可用） |
| 网络不可用 | 无网络/弱网 | 使用本地缓存，暂停远程同步 | 正常使用（配置可能非最新） |
| 配置服务宕机 | HTTP 5xx | 使用本地缓存，指数退避重试 | 正常使用 |
| WebSocket 断开 | 网络波动 | 降级为定时轮询（15min → 5min） | 无感知 |
| 增量版本跨度太大 | 本地版本过期 | 触发全量拉取 | 可能有短暂延迟 |
| 配置解析失败 | 数据格式错误 | 跳过该条目，使用旧值或默认值 | 该功能行为可能异常 |
| 配置类型不匹配 | 类型与预期不符 | 尝试类型转换，失败则用默认值 | 无感知 |
| 本地存储损坏 | Hive Box 异常 | 清空重建，触发全量拉取 | 配置短暂回退到默认值 |

### 8.2 配置校验管线

```dart
/// 配置值校验器
class ConfigValidator {
  /// 校验从服务端接收的配置值
  ///
  /// 返回 null 表示校验通过，否则返回错误描述
  static String? validate(String key, dynamic value, ConfigValueType type) {
    // 1. 非空检查
    if (value == null) {
      return 'Config value is null for key: $key';
    }

    // 2. 类型检查
    switch (type) {
      case ConfigValueType.boolean:
        if (value is! bool) return 'Expected bool for $key, got ${value.runtimeType}';
        break;
      case ConfigValueType.integer:
        if (value is! int) {
          // 尝试转换
          if (value is num) return null;  // 自动截断
          return 'Expected int for $key, got ${value.runtimeType}';
        }
        break;
      case ConfigValueType.double_:
        if (value is! double && value is! int) {
          return 'Expected double for $key, got ${value.runtimeType}';
        }
        break;
      case ConfigValueType.string:
        if (value is! String) {
          return 'Expected String for $key, got ${value.runtimeType}';
        }
        // 3. 长度限制检查
        if (value.length > 10000) {
          return 'String value too long for $key: ${value.length}';
        }
        break;
      case ConfigValueType.json:
        if (value is! Map && value is! List) {
          return 'Expected JSON for $key, got ${value.runtimeType}';
        }
        break;
    }

    // 4. 特定 key 的业务校验
    if (key.startsWith('ai_model.temperature')) {
      final temp = (value as num).toDouble();
      if (temp < 0 || temp > 2) {
        return 'Temperature out of range [0, 2]: $temp';
      }
    }

    if (key.startsWith('ai_model.max_tokens')) {
      final tokens = value as int;
      if (tokens < 100 || tokens > 32768) {
        return 'Max tokens out of range [100, 32768]: $tokens';
      }
    }

    return null; // 校验通过
  }
}
```

## 9. 安全设计

### 9.1 配置完整性校验

```dart
/// 配置签名验证
///
/// 服务端对配置数据生成 HMAC-SHA256 签名，客户端验证签名后再应用。
/// 防止中间人篡改配置数据。
class ConfigSignatureVerifier {
  /// 从编译时嵌入的公钥
  static const String _publicKeyPem = '''
-----BEGIN PUBLIC KEY-----
MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...
-----END PUBLIC KEY-----
''';

  /// 验证配置响应签名
  static bool verify(Map<String, dynamic> responseData, String signature) {
    try {
      // 1. 提取待签名数据（排除 signature 字段）
      final payload = jsonEncode(
        responseData,
        toEncodable: (o) => o is DateTime ? o.toIso8601String() : o.toString(),
      );

      // 2. 使用 RSA 公钥验签
      final publicKey = RSAKeyParser().parse(_publicKeyPem) as RSAPublicKey;
      final verifier = RSASigner(
        RSASignature.SHA256,
        publicKey: publicKey,
      );

      final sigBytes = base64Decode(signature);
      final dataBytes = utf8.encode(payload);

      return verifier.verify(dataBytes, RSASignature(sigBytes));
    } catch (e) {
      _log.severe('Config signature verification failed', e);
      return false;
    }
  }
}
```

## 11. 性能优化

### 11.1 内存优化

| 策略 | 说明 |
| --- | --- |
| 内存缓存 | ConfigBox 维护 `Map<String, ConfigEntry>` 内存索引，读取 O(1) |
| LRU 淘汰 | 非活跃命名空间的历史版本数据按 LRU 淘汰 |
| 快照复制 | observe() 返回值类型而非引用，避免共享可变状态 |

### 11.2 网络优化

| 策略 | 说明 |
| --- | --- |
| ETag + 304 | 全量拉取携带 If-None-Match，服务端无变更时返回 304 |
| 增量 Patch | 只传输变更项，减少 90%+ 的数据传输量 |
| WebSocket 推送 | 实时变更通过长连接推送，无需轮询 |
| 请求合并 | 多个配置变更在服务端聚合后一次推送 |
| Gzip 压缩 | HTTP 请求头 `Accept-Encoding: gzip`，配置数据压缩率 > 70% |
| 按需订阅 | WebSocket 只订阅业务关心的命名空间 |

### 11.3 存储优化

| 策略 | 说明 |
| --- | --- |
| Hive 二进制序列化 | 相比 JSON，减少 40% 存储空间 |
| 历史版本限制 | 仅保留最近 10 个版本的增量记录 |
| 过期数据清理 | 启动时检查并清理 7 天前的历史版本数据 |
| 延迟写入 | 非关键配置变更延迟 500ms 批量写入磁盘 |
