# 服务端 - 家长学习辅导建议生成与家庭教育内容推荐引擎

> **文档版本**: v1.0
> **最后更新**: 2026-06-14
> **负责模块**: parent-guidance-service
> **依赖模块**: 学情分析服务、学习画像服务、消息推送服务、内容服务、用户服务

---

## 1. 模块概述

### 1.1 功能目标

为家长提供 AI 驱动的个性化学习辅导建议和家庭教育内容推荐。系统持续分析孩子的学习行为、薄弱知识点、学习习惯和心理状态数据，自动生成可执行的辅导建议（如"本周数学函数掌握度偏低，建议周末花30分钟复习"），并推送匹配的家庭教育文章、亲子互动活动和沟通技巧内容。

### 1.2 核心价值

| 价值维度 | 说明 |
|---------|------|
| **可执行性** | 不止报数据，还告诉家长"该做什么、怎么做" |
| **适龄适配** | 根据孩子学段（幼儿/小学/初中/高中）调整建议深度和沟通方式 |
| **及时性** | 基于实时学习数据变化触发，而非固定模板 |
| **隐私安全** | 建议内容不暴露敏感数据细节，家长端仅展示指导性文字 |

### 1.3 用户场景

```
场景1: 小学生家长
  孩子本周数学「分数运算」知识点连续答错3题
  → 系统生成建议："孩子本周在分数运算遇到困难，建议您抽出15分钟，
    一起用切苹果的方式理解分数概念。这里有一篇《如何用生活场景教分数》
    的文章供您参考。"

场景2: 初中生家长
  孩子最近一周学习时长下降40%，AI对话中多次出现"好累"等情绪词
  → 系统生成建议："孩子近期学习强度较高，建议适当调整作息。
    可考虑安排一次轻松的户外活动。以下是《如何帮初中生减压》
    的家庭教育指南。"

场景3: 高中生家长
  孩子月考数学成绩提升，但英语阅读理解持续薄弱
  → 系统生成建议："孩子数学进步明显，建议给予肯定。同时英语阅读
    理解正确率连续两周低于60%，建议鼓励孩子每天阅读一篇英语短文。"
```

### 1.4 系统边界

```
本模块负责                          不负责
─────────────                      ─────────────
✅ 辅导建议内容生成                  ❌ 学情数据采集（学情分析服务负责）
✅ 家庭教育内容匹配推荐              ❌ 消息推送投递（消息推送服务负责）
✅ 建议生成策略与规则编排            ❌ 家长端UI渲染（客户端负责）
✅ 建议效果追踪（家长是否采纳）      ❌ 家长账号管理（用户服务负责）
✅ 教育内容库管理（后台运营）        ❌ 课程内容生产（内容服务负责）
```

## 3. 数据结构定义

### 3.1 数据库表设计

#### 3.1.1 parent_guidance_record（家长辅导建议记录表）

```sql
CREATE TABLE parent_guidance_record (
    id              BIGSERIAL PRIMARY KEY,
    record_id       VARCHAR(36) NOT NULL UNIQUE,      -- UUID，建议记录唯一标识
    parent_user_id  BIGINT NOT NULL,                   -- 家长用户ID
    student_user_id BIGINT NOT NULL,                   -- 学生用户ID
    trigger_type    VARCHAR(20) NOT NULL,              -- 触发类型: SCHEDULED/EVENT/MANUAL/ON_DEMAND
    trigger_ref     VARCHAR(255),                      -- 触发来源引用（事件ID/定时任务批次号）
    
    -- 建议内容
    title           VARCHAR(100) NOT NULL,             -- 建议标题
    summary         VARCHAR(500) NOT NULL,             -- 建议摘要（一句话）
    body            TEXT NOT NULL,                     -- 建议正文（富文本/Markdown）
    priority        SMALLINT NOT NULL DEFAULT 50,      -- 优先级: 10(紧急)/30(重要)/50(普通)/70(低)
    category        VARCHAR(30) NOT NULL,              -- 分类: ACADEMIC/HABIT/EMOTION/STRATEGY/MOTIVATION
    
    -- 关联数据
    related_subject VARCHAR(20),                       -- 关联学科
    related_kp_ids  JSONB,                             -- 关联知识点ID列表
    related_content_ids JSONB,                          -- 关联教育内容ID列表
    
    -- AI生成元信息
    ai_generated    BOOLEAN NOT NULL DEFAULT FALSE,    -- 是否经过AI增强
    ai_model        VARCHAR(50),                       -- 使用的AI模型
    ai_prompt_hash  VARCHAR(64),                       -- Prompt模板哈希（追溯）
    
    -- 状态管理
    status          VARCHAR(20) NOT NULL DEFAULT 'PENDING', -- PENDING/DELIVERED/READ/ACTED/DISMISSED/EXPIRED
    delivered_at    TIMESTAMPTZ,                       -- 送达时间
    read_at         TIMESTAMPTZ,                       -- 阅读时间
    acted_at        TIMESTAMPTZ,                       -- 家长采取行动时间
    dismissed_at    TIMESTAMPTZ,                       -- 家长忽略时间
    expired_at      TIMESTAMPTZ,                       -- 过期时间
    
    -- 反馈
    parent_feedback VARCHAR(20),                       -- 家长反馈: HELPFUL/NOT_HELPFUL/TOO_GENERIC
    feedback_detail TEXT,                              -- 反馈详情
    
    -- 时间戳
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    -- 索引
    CONSTRAINT idx_pgr_parent_student UNIQUE (parent_user_id, student_user_id, created_at),
    CONSTRAINT chk_trigger_type CHECK (trigger_type IN ('SCHEDULED', 'EVENT', 'MANUAL', 'ON_DEMAND')),
    CONSTRAINT chk_priority CHECK (priority BETWEEN 1 AND 99),
    CONSTRAINT chk_category CHECK (category IN ('ACADEMIC', 'HABIT', 'EMOTION', 'STRATEGY', 'MOTIVATION')),
    CONSTRAINT chk_status CHECK (status IN ('PENDING', 'DELIVERED', 'READ', 'ACTED', 'DISMISSED', 'EXPIRED'))
);

CREATE INDEX idx_pgr_student ON parent_guidance_record(student_user_id, created_at DESC);
CREATE INDEX idx_pgr_parent_status ON parent_guidance_record(parent_user_id, status, created_at DESC);
CREATE INDEX idx_pgr_trigger ON parent_guidance_record(trigger_type, created_at DESC);
CREATE INDEX idx_pgr_category ON parent_guidance_record(category, priority);
```

#### 3.1.2 guidance_strategy（辅导建议策略表）

```sql
CREATE TABLE guidance_strategy (
    id              BIGSERIAL PRIMARY KEY,
    strategy_code   VARCHAR(50) NOT NULL UNIQUE,       -- 策略编码: WEAK_KP_STREAK / STUDY_TIME_DROP / EMOTION_NEGATIVE ...
    strategy_name   VARCHAR(100) NOT NULL,             -- 策略名称
    category        VARCHAR(30) NOT NULL,              -- 分类
    priority        SMALLINT NOT NULL DEFAULT 50,      -- 默认优先级
    
    -- 触发条件（JSON规则表达式）
    condition_expr  JSONB NOT NULL,                    -- 条件表达式（见3.2节规则DSL）
    
    -- 模板
    template_id     VARCHAR(50) NOT NULL,              -- 关联Prompt模板ID
    content_tags    JSONB,                             -- 匹配内容标签
    
    -- 适用范围
    min_stage       VARCHAR(20),                       -- 最小学段: PRESCHOOL/PRIMARY/JUNIOR/SENIOR
    max_stage       VARCHAR(20),                       -- 最大学段
    
    -- 控制开关
    cooldown_hours  INT NOT NULL DEFAULT 72,           -- 冷却时间（小时），同一学生同一策略不重复触发
    max_per_week    INT NOT NULL DEFAULT 2,            -- 每周最大触发次数
    enabled         BOOLEAN NOT NULL DEFAULT TRUE,     -- 是否启用
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_gs_code ON guidance_strategy(strategy_code);
CREATE INDEX idx_gs_category ON guidance_strategy(category, enabled);
```

### 3.2 条件表达式规则 DSL

策略的 `condition_expr` 字段使用 JSON 规则 DSL，支持多条件组合：

```jsonc
// 示例：薄弱知识点连续错误策略
{
  "logic": "AND",
  "conditions": [
    {
      "type": "KP_MASTERY",
      "params": {
        "operator": "<=",
        "value": 0.4,
        "window_days": 7,
        "min_questions": 3
      }
    },
    {
      "type": "STAGE_IN",
      "params": {
        "values": ["PRIMARY", "JUNIOR", "SENIOR"]
      }
    }
  ]
}
```

**支持的条件下类型（condition type）**:

| type | 说明 | 关键参数 |
|------|------|---------|
| `KP_MASTERY` | 知识点掌握度 | `operator`, `value`, `window_days`, `min_questions` |
| `STUDY_TIME_TREND` | 学习时长趋势 | `trend`(`UP`/`DOWN`), `change_pct`, `window_days` |
| `ERROR_RATE` | 错误率 | `operator`, `value`, `subject`, `window_days` |
| `EMOTION_SIGNAL` | 情绪信号 | `signals`: [`FRUSTRATED`, `TIRED`, `ANXIOUS`, `CONFIDENT`], `window_days` |
| `STAGE_IN` | 学段匹配 | `values`: 学段列表 |
| `STUDY_PLAN_COMPLETION` | 计划完成率 | `operator`, `value`, `window_days` |
| `ACTIVE_DAYS_DROP` | 活跃天数下降 | `drop_pct`, `window_days` |
| `SUBJECT_PERF
