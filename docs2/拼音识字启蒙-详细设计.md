# 拼音识字启蒙专项学习系统 - 详细设计

## 1. 概述

### 1.1 设计目标
构建面向幼儿（3-6岁）及小学低年级（1-2年级）的拼音识字启蒙学习系统，支持：
- 系统化声母/韵母/整体认读音节学习路径
- 汉字识记（笔画、偏旁、组词、造句）
- 发音陪练与实时反馈
- 图文联想与趣味化互动
- 亲子模式与家长可配置学习内容与时长
- 基于强化学习的个性化练习推荐与学习进度追踪

### 1.2 边界与约束
- 不替代学校教学，作为启蒙与巩固辅助
- 语音识别精度依赖 ASR 提供商能力，提供回退文本验证与人工纠错
- 支持离线内容包缓存，但需联网同步学习记录
- 分龄适配：默认显示简单直观界面，字体、动画、按键符合低龄认知
- 未成年人保护：家长控制时长、内容范围，避免过度激励与消费诱导

### 1.3 术语
- 术语 | 定义
- --- | ---
- 声母 | 拼音系统中的辅音字母，如 b、p、m、f 等
- 韵母 | 拼音系统中的元音字母组合，如 a、o、e、ai、ei 等
- 整体认读音节 | 不拆分拼读的音节，如 zhi、chi、shi、ri 等
- 汉字卡片 | 单个汉字的学习单元，包含笔画、拼音、释义、例句
- 趣味练习 | 图片配对、连连看、拖拽、跟读、听音选字等游戏化练习
- 亲子模式 | 家长主导、学幼共同参与的互动学习会话

## 2. 系统架构

### 2.1 整体分层
- 客户端层：Flutter 跨平台 + 端侧本地检索与缓存
- 网关层：BFF 聚合接口，压缩与去重（字体、图片）
- 服务层：
  - 启蒙内容服务：拼音/汉字资源、课程大纲、练习编排
  - 练习评估服务：练习结果判分、正确率/耗时统计、错题归类
  - 学习调度服务：个性化路径推荐、会话管理、学习目标
  - 语音交互服务：ASR/TTS 调用与回退策略
- AI 能力层：多模态图文生成、发音质量反馈、个性化内容生成
- 数据层：关系库（用户/记录）、Redis（会话/热数据）、对象存储（音频/图片）、向量库（图谱/语义检索）

### 2.2 核心服务边界
- 启蒙内容服务：CRUD 拼音/汉字内容元数据，不做个性化推荐
- 练习评估服务：判定练习结果正确与否，不做干预决策
- 学习调度服务：编排练习序列与难度，不直接生成练习素材
- 语音交互服务：封装 ASR/TTS，提供文本-音频映射，不解释评测结果

## 3. 数据结构设计

### 3.1 概念模型（ER 视觉化）
```
User (1) <--(1:1)--> StudentProfile (1) <--(1:N)--> PinyinLearningSession
StudentProfile (1) <--(1:N)--> HanziLearningSession
PinyinLearningSession (1) <--(1:N)--> PinyinPracticeRecord
HanziLearningSession (1) <--(1:N)--> HanziPracticeRecord
PinyinContent (N) <--(N:1)--> PinyinCategory
HanziContent (N) <--(N:1)--> HanziCategory
PinyinCategory (N) <--(1:N)--> PinyinLearningSequence
HanziCategory (N) <--(1:N)--> HanziLearningSequence
StudentProfile (1) <--(1:N)--> PersonalizedLearningPath
PersonalizedLearningPath (1) <--(1:N)--> PathItem
```

## 5. 关键代码示例

### 5.1 客户端（Flutter）- 拼音练习页面骨架
```dart
// pinyin_practice_page.dart
import 'package:flutter/material.dart';
import 'package:audioplayers/audioplayers.dart';
import 'package:speech_to_text/speech_to_text.dart';

class PinyinPracticePage extends StatefulWidget {
  final String sessionId;
  final PinyinItem currentItem;
  const PinyinPracticePage({Key? key, required this.sessionId, required this.currentItem}) : super(key: key);

  @override
  _PinyinPracticePageState createState() => _PinyinPracticePageState();
}

class _PinyinPracticePageState extends State<PinyinPracticePage> {
  final AudioPlayer _audioPlayer = AudioPlayer();
  final SpeechToText _speech = SpeechToText();
  bool _isListening = false;
  String _userAnswer = '';
  bool _showResult = false;
  bool _isCorrect = false;

  @override
  void initState() {
    super.initState();
    _speech.initialize();
    _playPinyinAudio();
  }

  Future<void> _playPinyinAudio() async {
    await _audioPlayer.play(UrlSource(widget.currentItem.audioUrl));
  }

  Future<void> _startListening() async {
    if (!_isListening) {
      setState(() => _isListening = true);
      await _speech.listen(onResult: (result) {
        setState(() => _userAnswer = result.recognizedWords);
      });
    } else {
      await _speech.stop();
      setState(() => _isListening = false);
      await _submitAnswer();
    }
  }

  Future<void> _submitAnswer() async {
    // 校验用户答案是否与目标拼音一致
    final result = await EarlyLearningClient.instance.submitPractice(
      sessionId: widget.sessionId,
      itemType: 'pinyin',
      itemId: widget.currentItem.id,
      practiceType: 'reading',
      userAnswer: _userAnswer,
      attemptCount: 1,
      durationMs: 3000,
      feedback: {'asr_result': _userAnswer},
    );
    if (result != null) {
      setState(() {
        _isCorrect = result.isCorrect;
        _showResult = true;
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: Column(
          children: [
            const SizedBox(height: 20),
            // 拼音展示卡片
            Text(
              widget.currentItem.pinyinFull,
              style: const TextStyle(fontSize: 64, fontWeight: FontWeight.bold),
            ),
            const SizedBox(height: 10),
            // 代表图片
            Image.network(widget.currentItem.imageUrl, width: 200, height: 200),
            const SizedBox(height: 20),
            // 语音按钮
            ElevatedButton.icon(
              icon: Icon(_isListening ? Icons.stop : Icons.mic),
              label: Text(_isListening ? '停止录音' : '开始跟读'),
              onPressed: _startListening,
            ),
            const SizedBox(height: 20),
            // 用户答案展示
            Text(_userAnswer, style: const TextStyle(fontSize: 32)),
            if (_showResult)
              _buildResultCard(),
          ],
        ),
      ),
    );
  }

  Widget _buildResultCard() {
    return Card(
      color: _isCorrect ? Colors.green.shade100 : Colors.red.shade100,
      child: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          children: [
            Icon(_isCorrect ? Icons.check_circle : Icons.cancel, size: 48, color: _isCorrect ? Colors.green : Colors.red),
```

### 5.2 服务端（Node.js/Express）- 创建学习会话
```typescript
// earlyLearningSessionService.ts
import { v4 as uuidv4 } from 'uuid';
import { PrismaClient } from '@prisma/client';
import Redis from 'ioredis';

const prisma = new PrismaClient();
const redis = new Redis();

export async function createSession(params: {
  userId: string;
  type: 'pinyin' | 'hanzi' | 'mixed';
  mode: 'self' | 'parent' | 'guided';
  targetItemIds?: string[];
}) {
  const { userId, type, mode, targetItemIds } = params;
  const sessionId = uuidv4();
  const startTime = new Date().toISOString();

  // 如果未指定项目，从个性化学习路径中获取
  let itemPool: any[] = [];
  if (!targetItemIds || targetItemIds.length === 0) {
    const path = await redis.get(`hanzi:learning:path:${userId}`);
    if (path) {
      const parsedPath = JSON.parse(path);
      const nextSteps = parsedPath.steps.slice(parsedPath.current_index, parsedPath.current_index + 5);
      itemPool = nextSteps;
    } else {
      // 冷启动：按难度随机选取
      itemPool = await prisma.pinyinContent.findMany({
        where: { status: 'published', difficulty: 'easy' },
        take: 5,
      });
    }
  } else {
    // 按用户指定的ID获取项目
    itemPool = await prisma.pinyinContent.findMany({
      where: { id: { in: targetItemIds } },
    });
  }

  // 估算时长（每个项目预计30秒）
  const estimatedDurationMs = itemPool.length * 30000;

  // 创建会话记录
  const session = await prisma.pinyinHanziLearningSession.create({
    data: {
      id: sessionId,
      userId,
      sessionType: type,
      startTime,
      mode,
      totalDurationMs: 0,
      totalPractices: 0,
      correctCount: 0,
      completedItems: [],
    },
  });

  // 缓存会话状态
  await redis.setex(
    `pinyin:session:${sessionId}`,
    86400,
    JSON.stringify({
      current_step: 0,
      start_time: startTime,
      item_pool: itemPool,
    })
  );

  return {
    sessionId,
    startTime,
    itemPool,
    estimatedDurationMs,
  };
}
```

### 5.3 服务端 - 提交练习结果与进度更新
```typescript
// earlyLearningPracticeService.ts
import { PrismaClient } from '@prisma/client';
import Redis from 'ioredis';

const prisma = new PrismaClient();
const redis = new Redis();

export async function submitPractice(params: {
  sessionId: string;
  itemType: 'pinyin' | 'hanzi';
  itemId: string;
  practiceType: string;
  userAnswer: string;
  isCorrect: boolean;
  attemptCount: number;
  durationMs: number;
  feedback?: any;
}) {
  const { sessionId, itemType, itemId, practiceType, userAnswer, isCorrect, attemptCount, durationMs, feedback } = params;

  // 写入练习记录
  const practiceId = uuidv4();
  if (itemType === 'pinyin') {
    await prisma.pinyinPracticeRecord.create({
      data: {
        id: practiceId,
        userId: (await getSessionUserId(sessionId)),
        pinyinId: itemId,
        sessionId,
        practiceType,
        userAnswer,
        isCorrect,
        attemptCount,
        durationMs,
        feedback: feedback || {},
        createdAt: new Date(),
      },
    });
  } else {
    await prisma.hanziPracticeRecord.create({
      data: {
        id: practiceId,
        userId: (await getSessionUserId(sessionId)),
        hanziId: itemId,
        sessionId,
        practiceType,
        userAnswer,
        isCorrect,
        attemptCount,
        durationMs,
        feedback: feedback || {},
        createdAt: new Date(),
      },
    });
  }

  // 更新会话缓存
  const sessionCache = await redis.get(`pinyin:session:${sessionId}`);
  if (sessionCache) {
    const parsedCache = JSON.parse(sessionCache);
    parsedCache.current_step += 1;
    await redis.setex(`pinyin:session:${sessionId}`, 86400, JSON.stringify(parsedCache));
  }

  // 返回进度与下一题
  const session = await prisma.pinyinHanziLearningSession.findUnique({ where: { id: sessionId } });
  const total = session?.totalPractices || 0;
  const completed = total + 1;
  const correctCount = session?.correctCount || 0;
  const newCorrectCount = isCorrect ? correctCount + 1 : correctCount;

  await prisma.pinyinHanziLearningSession.update({
    where: { id: sessionId },
    data: {
      totalPractices: completed,
      correctCount: newCorrectCount,
    },
  });

  // 获取下一题（简版：随机取一项）
  const nextItem = await prisma.pinyinContent.findFirst({ where: { status: 'published' } });

  return {
    practiceId,
    sessionProgress: {
      total: total + 5,
      completed,
      correct: newCorrectCount,
    },
    nextItem,
    reward: {
      stars: isCorrect ? 1 : 0,
      badge: null,
    },
  };
}
```

## 6. 状态流转与错误处理

### 6.1 学习会话状态机
- 状态：INIT → ACTIVE → PAUSED → COMPLETED | ABORTED
- 转换条件：
  - INIT → ACTIVE：会话创建成功
  - ACTIVE → PAUSED：用户点击暂停或家长控制触发
  - PAUSED → ACTIVE：用户恢复或超时自动恢复
  - ACTIVE → COMPLETED：所有练习完成
  - ACTIVE → ABORTED：网络异常或强制退出

### 6.2 练习提交重试策略
- 初次提交：客户端直接发送
- 失败重试：最多重试 3 次，指数退避（1s, 2s, 4s）
- 离线队列：失败后存入本地 SQLite，待联网后批量重试
- 冲突处理：服务端依据 `created_at` 去重，保证幂等

### 6.3 语音识别回退方案
- ASR 成功：使用置信度评分，低于 0.85 提示重新录音
- ASR 失败：回退到文本输入框，允许手动输入拼音
- 网络超时：本地缓存音频，待网络恢复后再次识别

### 6.4 错误码与提示
| 错误码 | 场景 | 客户端提示 |
| --- | --- | --- |
| EL_4001 | 会话不存在 | "会话已失效，请重新开始学习" |
| EL_4002 | 音频资源404 | "音频加载失败，请检查网络" |
| EL_4003 | ASR 服务不可用 | "语音服务暂时不可用，请稍后再试或手动输入" |
| EL_4004 | 超出家长设定时长 | "今日学习时间已到，明天继续吧！" |
| EL_4005 | 练习参数校验失败 | "练习数据异常，请重试" |
| EL_4006 | 内容未发布或被删除 | "该内容已下架，切换到下一题" |

## 7. 安全与隐私

### 7.1 未成年人保护
- 家长控制：登录家长中心设置每日学习时长与可用模块
- 激励边界：仅星星、徽章等虚拟奖励，禁止货币化激励与消费诱导
- 内容安全：所有用户上传图片/文本通过内容安全服务审核

### 7.2 隐私与数据最小化
- 音频上传：仅上传用于评测的片段，匿名化存储，保留7天后删除
- 会话记录：仅保留学习统计（时长、正确率），不存储原始语音
- 离线缓存：资源包默认存储加密，不跨设备共享

### 7.3 API 安全
- 鉴权：基于 JWT，Token 有效期 24 小时，Refresh Token 有效期 7 天
- 限流：每人每分钟最多 30 次练习提交，防止刷题
- 防重放：每次提交带唯一 `request_id`，服务端校验唯一性

## 8. 性能与优化

### 8.1 BFF 聚合与压缩
- 图片：WebP 格式，自动缩放到目标分辨率（150x150 以下），开启浏览器缓存 1 天
- 音频：AAC 128kbps，分段缓存，首段预加载
- 接口响应时间目标：大纲列表 < 200ms，练习提交 < 500ms，会话创建 < 300ms

### 8.2 端侧优化
- 本地 SQLite：存储会话状态与练习记录，减少网络请求
- 缓存策略：常用拼音/汉字元数据缓存 24 小时，变动时通过版本号失效
- 动画：使用 Lottie 预编译，避免实时计算

### 8.3 服务端优化
- 读写分离：查询（课程大纲）走只读副本，写入（练习记录）走主库
- 批处理：每 5 分钟批量归档练习记录到 ClickHouse 用于分析
- Redis 集群：分片存储会话缓存，避免单点热点
