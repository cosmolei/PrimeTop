## 1. 模块概述

### 1.1 功能定位

面向 **3~8 岁**（幼儿园至小学二年级）用户，提供拼音、识字、发音、组词、造句和朗读启蒙服务。以游戏化、图像化、语音化交互为核心，降低操作门槛，强调亲子共学。

### 1.2 核心目标

| 目标 | 衡量指标 |
|------|----------|
| 拼音掌握 | 声母23个、韵母24个、整体认读音节16个全部覆盖 |
| 识字量 | 小学一年级上册要求 300 字，一年级下册累计 700 字 |
| 发音准确率 | 语音识别评分 ≥ 80 分视为通过 |
| 日活参与度 | 亲子模式用户日均学习 ≥ 10 分钟 |

### 1.3 目标用户画像

| 子群体 | 年龄 | 特点 |
|--------|------|------|
| 幼儿（中班~大班） | 4-6 | 不识字、依赖语音和图像、注意力短 |
| 小学一年级 | 6-7 | 正在学拼音、需巩固声韵母 |
| 小学二年级 | 7-8 | 拼音基本掌握、以识字和阅读为主 |
| 家长 | 25-40 | 设置学习内容、查看进度、亲子互动 |

## 3. 数据结构设计

### 3.1 拼音数据

#### 3.1.1 PinyinItem（拼音条目）

```sql
CREATE TABLE pinyin_items (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    pinyin          VARCHAR(10)    NOT NULL COMMENT '拼音字母，如 b, ao, ying',
    type            ENUM('shengmu', 'dan_yunmu', 'fu_yunmu', 'bi_yunmu', 'zhengti') NOT NULL COMMENT '类型',
    display_order   INT            NOT NULL COMMENT '排序号（教材顺序）',
    audio_url       VARCHAR(512)   NOT NULL COMMENT '标准发音音频URL',
    example_char    VARCHAR(4)     NOT NULL COMMENT '示范汉字，如 玻 for b',
    example_word    VARCHAR(20)    NOT NULL COMMENT '示范词语，如 波浪',
    example_img_url VARCHAR(512)   NULL     COMMENT '示范图片URL',
    mouth_img_url   VARCHAR(512)   NULL     COMMENT '口型示意图URL',
    tips            VARCHAR(500)   NULL     COMMENT '发音要领文字说明',
    grade_level     VARCHAR(20)    NOT NULL DEFAULT 'G1A' COMMENT '适用学段：G1A一年级上,G1B一年级下,K幼儿园',
    status          TINYINT        NOT NULL DEFAULT 1 COMMENT '1启用 0禁用',
    created_at      DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME       NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_type_order (type, display_order)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='拼音条目表';
```

#### 3.1.2 PinyinCombination（拼读组合）

```sql
CREATE TABLE pinyin_combinations (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    shengmu         VARCHAR(5)     NOT NULL COMMENT '声母',
    yunmu           VARCHAR(10)    NOT NULL COMMENT '韵母',
    result          VARCHAR(15)    NOT NULL COMMENT '拼读结果，如 ba',
    tone1_char      VARCHAR(4)     NULL COMMENT '一声例字',
    tone2_char      VARCHAR(4)     NULL COMMENT '二声例字',
    tone3_char      VARCHAR(4)     NULL COMMENT '三声例字',
    tone4_char      VARCHAR(4)     NULL COMMENT '四声例字',
    audio_url       VARCHAR(512)   NOT NULL COMMENT '拼读示范音频',
    grade_level     VARCHAR(20)    NOT NULL DEFAULT 'G1A',
    status          TINYINT        NOT NULL DEFAULT 1,
    UNIQUE KEY uk_combination (shengmu, yunmu),
    INDEX idx_grade (grade_level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='声韵母拼读组合表';
```

### 3.2 汉字数据

#### 3.2.1 CharacterItem（汉字条目）

```sql
CREATE TABLE character_items (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    char_utf8       CHAR(1)        NOT NULL COMMENT '汉字',
    pinyin          VARCHAR(20)    NOT NULL COMMENT '拼音（含声调），如 mā',
    stroke_count    TINYINT        NOT NULL COMMENT '笔画数',
    radical         VARCHAR(4)     NOT NULL COMMENT '偏旁部首',
    structure       VARCHAR(20)    NULL COMMENT '结构：左右/上下/独体/包围等',
    frequency_rank  INT            NULL COMMENT '字频排名',
    grade_level     VARCHAR(20)    NOT NULL COMMENT '适用学段',
    textbook_id     BIGINT         NULL COMMENT '关联教材ID',
    chapter_id      BIGINT         NULL COMMENT '关联章节ID',
    stroke_svg_url  VARCHAR(512)   NOT NULL COMMENT '笔画动画SVG/JSON',
    card_img_url    VARCHAR(512)   NULL COMMENT '识字卡片图片',
    meaning         VARCHAR(200)   NOT NULL COMMENT '释义（儿童版简明）',
    audio_url       VARCHAR(512)   NOT NULL COMMENT '朗读音频URL',
    status          TINYINT        NOT NULL DEFAULT 1,
    UNIQUE KEY uk_char (char_utf8, grade_level),
    INDEX idx_grade_radical (grade_level, radical),
    INDEX idx_textbook_chapter (textbook_id, chapter_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='汉字条目表';
```

### 5.4 掌握度判定算法

```
掌握度 = f(练习得分, 发音评分, 重复次数, 间隔天数)

规则：
1. 单次练习 score ≥ 80 → 标记本次通过
2. 连续 2 次通过 + 间隔 ≥ 1 天 → 标记为「已掌握」
3. 发音评测 overallScore ≥ 80 → 发音维度通过
4. 7天内未复习 → 掌握度衰减（进入复习队列）

掌握度衰减公式：
  decayed_mastery = base_mastery × 0.9^(days_since_last_review)

当 decayed_mastery < 0.6 时，该条目重新进入复习队列
```

### 6.2 AI 生成内容安全过滤

拼音识字模块面向幼儿，所有 AI 生成内容必须经过双重过滤：

1. **预过滤**：Prompt 中明确约束输出范围和风格
2. **后过滤**：通过内容安全 API 扫描 AI 输出，拦截不适宜内容
3. **兜底机制**：若 AI 生成失败或被拦截，使用预设的静态内容模板

### 10.1 服务端：掌握度判定（Python）

```python
from datetime import datetime, timedelta
from typing import Optional

MASTERY_THRESHOLD = 0.6  # 掌握度低于此值需复习
PASS_SCORE = 80          # 单次通过分数

def calculate_mastery(records: list[dict]) -> dict:
    """
    根据学习记录计算掌握度
    
    records: 学习记录列表，按时间升序，每条含 score, created_at
    返回: { mastered: bool, mastery_score: float, next_review: date }
    """
    if not records:
        return {"mastered": False, "masteryScore": 0.0, "nextReview": None}
    
    # 检查连续通过
    consecutive_pass = 0
    last_pass_date = None
    for r in reversed(records):
        if r["score"] >= PASS_SCORE:
            consecutive_pass += 1
            last_pass_date = r["created_at"].date()
        else:
            break
    
    # 连续2次通过 + 间隔≥1天 = 已掌握
    is_mastered = False
    if consecutive_pass >= 2:
        # 检查两次通过是否在不同天
        pass_records = [r for r in records if r["score"] >= PASS_SCORE]
        if len(pass_records) >= 2:
            dates = {r["created_at"].date() for r in pass_records[-2:]}
            if len(dates) >= 2:  # 至少跨2天
                is_mastered = True
    
    # 计算衰减掌握度
    last_record = records[-1]
    days_since = (datetime.now().date() - last_record["created_at"].date()).days
    base_mastery = min(last_record["score"] / 100.0, 1.0)
    decayed_mastery = base_mastery * (0.9 ** days_since)
    
    # 下次复习日期（遗忘曲线）
    if is_mastered:
        next_review = last_pass_date + timedelta(days=7)
    else:
        next_review = datetime.now().date() + timedelta(days=1)
    
    return {
        "mastered": is_mastered,
        "masteryScore": round(decayed_mastery, 3),
        "nextReview": next_review.isoformat() if next_review else None,
        "needsReview": decayed_mastery < MASTERY_THRESHOLD
    }
```

### 10.3 服务端：发音评测接口（Python/Flask）

```python
from flask import request, jsonify
import subprocess
import tempfile
import os

@app.route("/api/v1/enlightenment/pronunciation/evaluate", methods=["POST"])
def evaluate_pronunciation():
    """
    发音评测接口
    流程：接收音频 → ASR识别 → 与目标对比 → 计算分数 → 返回反馈
    """
    # 1. 参数校验
    if "audio" not in request.files:
        return jsonify({"code": 10301, "msg": "缺少音频文件"}), 400
    
    audio_file = request.files["audio"]
    target_type = request.form.get("target_type")
    target_id = request.form.get("target_id", type=int)
    target_text = request.form.get("target_text", "")
    
    if not all([target_type, target_id, target_text]):
        return jsonify({"code": 10301, "msg": "参数不完整"}), 400
    
    # 2. 保存临时音频文件
    with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as f:
        audio_file.save(f)
        audio_path = f.name
    
    try:
        # 3. 调用 ASR 服务识别
        asr_result = asr_service.recognize(audio_path)
        if not asr_result or not asr_result.get("text"):
            return jsonify({
                "code": 10004,
                "msg": "语音识别失败，请换个安静的环境再试"
            }), 422
        
        asr_text = asr_result["text"].strip()
        
        # 4. 发音评分
        scores = pronunciation_scorer.score(
            target=target_text,
            recognized=asr_text,
            audio_path=audio_path
        )
        # scores: { accuracy, fluency, overall, tone, initial, final }
        
        overall = scores["overall"]
        
        # 5. 保存记录
        record = PronunciationRecord(
            user_id=get_current_user_id(),
            target_type=target_type,
            target_id=target_id,
            target_text=target_text,
            audio_url=upload_to_oss(audio_path),
            asr_result=asr_text,
            accuracy_score=scores["accuracy"],
            fluency_score=scores["fluency"],
            overall_score=overall,
            feedback={
                "tone": scores.get("tone"),
                "initial": scores.get("initial"),
                "final": scores.get("final")
            }
        )
        db.session.add(record)
        db.session.commit()
        
        # 6. 计算星星奖励
        star_earned = 2 if overall >= 80 else 0
        
        return jsonify({
            "code": 0,
            "data": {
                "accuracyScore": scores["accuracy"],
                "fluencyScore": scores["fluency"],
                "overallScore": overall,
                "asrText": asr_text,
                "feedback": record.feedback,
                "starEarned": star_earned
            }
        })
    
    except ASRServiceUnavailable:
        return jsonify({"code": 10005, "msg": "语音服务暂不可用"}), 503
    
    finally:
        os.unlink(audio_path)
```

```dart
import 'dart:convert';
import 'package:flutter/material.dart';

/// 笔画动画渲染组件
class StrokeAnimationWidget extends StatefulWidget {
  final String strokeJsonUrl; // 笔画数据URL
  final double size;
  final Color strokeColor;
  final VoidCallback? onComplete;

  const StrokeAnimationWidget({
    super.key,
    required this.strokeJsonUrl,
    this.size = 200,
    this.strokeColor = Colors.black,
    this.onComplete,
  });

  @override
  State<StrokeAnimationWidget> createState() => _StrokeAnimationWidgetState();
}

class _StrokeAnimationWidgetState extends State<StrokeAnimationWidget>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  List<StrokeData> _strokes = [];
  int _currentStroke = 0;
  bool _isLoading = true;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 800),
    )..addStatusListener((status) {
        if (status == AnimationStatus.completed) {
          if (_currentStroke < _strokes.length - 1) {
            setState(() => _currentStroke++);
            _controller.forward(from: 0);
          } else {
            widget.onComplete?.call();
          }
        }
      });
    _loadStrokeData();
  }

  Future<void> _loadStrokeData() async {
    final response = await http.get(Uri.parse(widget.strokeJsonUrl));
    final data = json.decode(response.body);
    setState(() {
      _strokes = (data['strokes'] as List)
          .map((s) => StrokeData.fromJson(s))
          .toList();
      _isLoading = false;
    });
    if (_strokes.isNotEmpty) {
      _controller.forward();
    }
  }

  @override
  Widget build(BuildContext context) {
    if (_isLoading) {
      return SizedBox(
        width: widget.size,
        height: widget.size,
        child: const Center(child: CircularProgressIndicator()),
      );
    }

    return SizedBox(
      width: widget.size,
      height: widget.size,
      child: CustomPaint(
        painter: StrokePainter(
          strokes: _strokes,
          currentStroke: _currentStroke,
          progress: _controller.value,
          color: widget.strokeColor,
        ),
      ),
    );
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }
}

class StrokeData {
  final int order;
  final String name;
  final String path;
  final int duration;

  StrokeData({
    required this.order,
    required this.name,
    required this.path,
    required this.duration,
  });

  factory StrokeData.fromJson(Map<String, dynamic> json) => StrokeData(
        order: json['order'],
        name: json['name'],
        path: json['path'],
        duration: json['duration'],
      );
}

class StrokePainter extends CustomPainter {
  final List<StrokeData> strokes;
  final int currentStroke;
  final double progress;
  final Color color;

  StrokePainter({
    required this.strokes,
    required this.currentStroke,
    required this.progress,
    required this.color,
  });

  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()
      ..color = color
      ..style = PaintingStyle.stroke
      ..strokeWidth = 4.0
      ..strokeCap = StrokeCap.round;

    // 绘制已完成的笔画
    for (int i = 0; i < currentStroke; i++) {
      _drawPath(canvas, strokes[i].path, paint, 1.0);
    }

    // 绘制当前笔画（带动画进度）
    if (currentStroke < strokes.length) {
      _drawPath(canvas, strokes[currentStroke].path, paint, progress);
    }
  }

  void _drawPath(Canvas canvas, String pathData, Paint paint, double progress) {
    // 解析 SVG path 数据并绘制
    final path = parseSvgPath(pathData);
    final metrics = path.computeMetrics();
    
    for (final metric in metrics) {
      final end = metric.length * progress;
      canvas.drawPath(
        metric.extractPath(0, end),
        paint,
      );
    }
  }

  @override
  bool shouldRepaint(covariant StrokePainter old) =>
      old.currentStroke != currentStroke || old.progress != progress;
}
```

### 10.5 客户端：发音录制与评测（Flutter/Dart）

```dart
import 'dart:io';
import 'package:record/record.dart';
import 'package:http/http.dart' as http;

/// 发音评测管理器
class PronunciationManager {
  final AudioRecorder _recorder = AudioRecorder();
  bool _isRecording = false;

  /// 开始录音
  Future<bool> startRecording() async {
    if (_isRecording) return false;

    final hasPermission = await _recorder.hasPermission();
    if (!hasPermission) {
      throw Exception('麦克风权限未授予');
    }

    await _recorder.start(
      const RecordConfig(
        encoder: AudioEncoder.wav,
        sampleRate: 16000,
        numChannels: 1,
      ),
      path: await _getTempPath(),
    );

    _isRecording = true;
    return true;
  }

  /// 停止录音并提交评测
  Future<PronunciationResult> stopAndEvaluate({
    required String targetType,
    required int targetId,
    required String targetText,
  }) async {
    final audioPath = await _recorder.stop();
    _isRecording = false;

    if (audioPath == null) {
      throw Exception('录音失败');
    }

    final file = File(audioPath);
    
    // 音频时长校验（0.5s ~ 10s）
    final duration = await _recorder.duration(path: audioPath);
    if (duration.inMilliseconds < 500) {
      throw PronunciationException(code: 10002, message: '说得再长一点');
    }
    if (duration.inMilliseconds > 10000) {
      throw PronunciationException(code: 10003, message: '说短一点');
    }

    // 提交评测
    final request = http.MultipartRequest(
      'POST',
      Uri.parse('$baseUrl/api/v1/enlightenment/pronunciation/evaluate'),
    )
      ..headers['Authorization'] = 'Bearer $token'
      ..fields['target_type'] = targetType
      ..fields['target_id'] = targetId.toString()
      ..fields['target_text'] = targetText
      ..files.add(await http.MultipartFile.fromPath('audio', audioPath));

    final response = await request.send();
    final body = json.decode(await response.stream.bytesToString());

    if (body['code'] != 0) {
      throw PronunciationException(
        code: body['code'],
        message: body['msg'],
      );
    }

    // 清理临时文件
    file.delete();

    return PronunciationResult.fromJson(body['data']);
  }

  Future<String> _getTempPath() async {
    final dir = await getTemporaryDirectory();
    return '${dir.path}/pronunciation_${DateTime.now().millisecondsSinceEpoch}.wav';
  }
}

    required this.asrText,
    this.feedback,
    required this.starEarned,
  });

        asrText: json['asrText'],
        feedback: json['feedback'],
        starEarned: json['starEarned'],
      );
```
