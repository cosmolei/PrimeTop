# 服务端-教育内容情境化实例与生活化应用场景智能生成引擎 详细设计

## 1. 概述

### 1.1 模块定位

教育内容情境化实例与生活化应用场景智能生成引擎（Contextual Scenario Generation Engine，简称 CSGE）是 PrimeTop AI 能力层的核心辅助引擎之一。其核心职责是将抽象的知识点、公式、概念转化为学生可感知、可共鸣的具体生活场景与实例，弥合"教材知识"与"现实世界"之间的认知鸿沟。

### 1.2 核心问题

设计文档 §8.5.3 明确提出"小学生问题讲解：语言简明，使用生活化例子，避免跳步"的 Prompt 策略。然而在实际系统中：

| 痛点 | 表现 | 影响 |
| --- | --- | --- |
| AI 回答过于抽象 | 直接给出公式定义，缺乏生活类比 | 低龄学生难以理解 |
| 举例千篇一律 | 反复使用"小明买苹果"类雷同场景 | 学生失去兴趣 |
| 举例不适龄 | 给小学生举股市/房贷的例子 | 认知错位 |
| 缺乏文化适配 | 使用北方滑雪场景解释给南方学生 | 陌生感强 |
| 无法关联个人兴趣 | 对喜欢篮球和喜欢音乐的学生使用相同例子 | 个性化不足 |

### 1.3 核心职责

1. **知识点→场景映射**：为任意知识点自动匹配合适的真实世界场景。
2. **场景实例生成**：基于知识点+场景+学生画像生成具体的、适龄的、有趣的实例。
3. **类比推理生成**：为抽象概念生成类比解释（如"电流就像水流"）。
4. **情境化题目包装**：将干瘪的练习题包装为有故事背景的情境题。
5. **多模态场景描述**：输出文字+图片提示词+交互建议的场景包。
6. **场景质量评估**：评估生成场景的教育有效性和适龄度。

### 1.5 设计原则

| 原则 | 说明 |
| --- | --- |
| **适龄优先** | 生成的场景必须符合学生认知发展阶段 |
| **多样性保障** | 同一知识点至少维护 5+ 不同场景角度 |
| **文化敏感性** | 避免地域歧视、文化偏见和敏感话题 |
| **教育有效性** | 场景必须服务于知识理解，不是单纯讲故事 |
| **可缓存复用** | 高质量场景入库缓存，避免重复生成 |
| **渐进式丰富** | 先给简短类比，按需展开详细场景 |

### 2.1 核心实体定义

#### 2.1.1 场景模板 (SceneTemplate)

```typescript
interface SceneTemplate {
  id: string;                          // 模板ID，如 "st_001"
  knowledgePointId: string;            // 关联知识点ID
  subject: Subject;                    // 学科
  stage: SchoolStage;                  // 适用学段
  sceneCategory: SceneCategory;        // 场景大类
  sceneTopic: string;                  // 场景主题，如"超市购物"
  sceneAngle: string;                  // 切入角度，如"单价×数量=总价"
  targetAgeRange: [number, number];    // 目标年龄范围，如 [8, 10]
  keywords: string[];                  // 场景关键词
  difficultyLevel: number;             // 认知难度等级 1-5
  culturalTags: string[];              // 文化标签，如 ["南方", "城市"]
  interestTags: string[];              // 兴趣标签，如 ["运动", "美食"]
  templateContent: string;             // 场景模板内容（含占位符）
  variables: SceneVariable[];          // 可替换变量
  multimediaHints: MultimediaHint[];   // 多媒体素材提示
  effectivenessScore: number;          // 效果评分 0-100
  usageCount: number;                  // 使用次数
  positiveFeedbackRate: number;        // 正反馈率
  status: ContentStatus;               // 状态：draft/approved/published/archived
  createdAt: timestamp;
  updatedAt: timestamp;
}
```

### 2.4 缓存策略

```typescript
// Redis 缓存层级设计
const CacheKeys = {
  // L1: 知识点→场景模板列表（TTL: 1h，模板变更时主动失效）
  sceneTemplateList: (kpId: string, stage: string) =>
    `csge:tpl:${kpId}:${stage}`,

  // L2: 用户最近生成的场景（TTL: 24h）
  userRecentScene: (userId: string, kpId: string) =>
    `csge:user:${userId}:${kpId}`,

  // L3: 热门场景实例（TTL: 6h，基于 positive_rate + usage_count 排序）
  hotScene: (kpId: string, ageGroup: string) =>
    `csge:hot:${kpId}:${ageGroup}`,

  // L4: 类比映射缓存（TTL: 2h，低频变更）
  analogyMap: (conceptId: string) =>
    `csge:analogy:${conceptId}`,

  // L5: 学科场景索引（TTL: 1h）
  subjectSceneIndex: (subject: string, stage: string, category: SceneCategory) =>
    `csge:idx:${subject}:${stage}:${category}`,
};

// 缓存预热策略：系统启动时加载各学科TOP知识点的模板
```

### 4.2 生成策略决策引擎

策略决策是 CSGE 的核心，决定如何最优地组合模板和 AI 生成。

```python
class GenerationStrategy:
    """场景生成策略决策器"""

    def decide_mode(
        self,
        kp_id: str,
        stage: str,
        user_id: str,
        requested_mode: str,
        scene_category: str | None,
    ) -> GenerationPlan:
        """
        决策流程：
        1. 如果 requested_mode != 'auto'，直接使用指定模式
        2. auto 模式下的决策逻辑：
           a. 检查缓存命中率
           b. 评估模板覆盖度
           c. 判断用户个性化需求强度
           d. 评估成本预算
        """

        if requested_mode != 'auto':
            return self._build_plan(requested_mode, ...)

        # Step 1: 查模板覆盖度
        template_count = self.template_repo.count_by_kp(kp_id, stage)
        template_coverage = self._calc_coverage(template_count, scene_category)

        # Step 2: 查缓存命中
        cached_scenes = self.cache.get_hot_scenes(kp_id, age_group)

        # Step 3: 用户个性化需求强度
        user_profile = self.profile_service.get(user_id)
        personalization_needed = self._needs_personalization(user_profile)

        # Step 4: 成本预算检查
        budget_remaining = self.budget_service.check(user_id, 'csge')

        # 决策矩阵
        if template_coverage >= 0.8 and not personalization_needed:
            # 模板充足，用户无特殊偏好 → 模板模式
            return GenerationPlan(mode='template', source='cache+db')

        elif template_coverage >= 0.5 and budget_remaining < LOW_BUDGET:
            # 模板中等，预算紧张 → 混合模式（优先模板）
            return GenerationPlan(mode='hybrid', template_first=True)

        elif personalization_needed and budget_remaining > 0:
            # 需要个性化，预算充足 → 混合模式（AI补充）
            return GenerationPlan(mode='hybrid', template_first=False)

        elif template_coverage < 0.3 and budget_remaining > 0:
            # 模板严重不足，预算够 → AI模式
            return GenerationPlan(mode='ai', fallback='generic')

        else:
            # 兜底：模板模式 + 通用场景
            return GenerationPlan(mode='template', source='fallback_pool')
```

```python
        },
        'safety': {            # 内容安全性
            'weight': 0.15,
            'checker': 'safety_filter',
            'threshold': 1.0,   # 安全是硬性指标
        },
    }

    def evaluate(self, scene: GeneratedScene, kp: KnowledgePoint) -> float:
        scores = {}
        for dim, config in self.QUALITY_DIMENSIONS.items():
            score = self._run_checker(config['checker'], scene, kp)
            scores[dim] = score

            # 硬性指标不通过直接淘汰
            if score < config['threshold'] and dim == 'safety':
                return 0.0  # 安全问题直接0分

        weighted = sum(
            scores[dim] * config['weight']
            for dim, config in self.QUALITY_DIMENSIONS.items()
        )
        return round(weighted * 100, 1)
```

```java
/**
 * 场景生成核心服务
 */
@Service
@Slf4j
public class SceneGenerationService {

    @Autowired private SceneTemplateRepository templateRepo;
    @Autowired private GeneratedSceneRepository sceneRepo;
    @Autowired private LlmClient llmClient;
    @Autowired private SceneQualityEvaluator qualityEvaluator;
    @Autowired private UserProfileAdapter profileAdapter;
    @Autowired private KnowledgePointAdapter kpAdapter;
    @Autowired private ContentSafetyFilter safetyFilter;
    @Autowired private SceneCacheManager cacheManager;
    @Autowired private GenerationStrategy strategy;
    @Autowired private CostBudgetService budgetService;
    @Autowired private SceneMapper mapper;

    /**
     * 为知识点生成情境化场景
     */
    @Retryable(value = {LlmServiceException.class}, maxAttempts = 2,
               backoff = @Backoff(delay = 1000, multiplier = 2))
    public SceneGenerationResult generateScenes(SceneGenerationRequest request) {
        long startTime = System.currentTimeMillis();

        // 1. 预处理：加载知识点信息和用户画像
        KnowledgePointInfo kpInfo = kpAdapter.getKnowledgePoint(
            request.getKnowledgePointId(), request.getSubject());
        UserProfile profile = profileAdapter.getProfile(request.getUserId());
        ScenePreferences prefs = mergePreferences(request, profile);

        // 2. 决策生成策略
        GenerationPlan plan = strategy.decideMode(
            request.getKnowledgePointId(),
            request.getStage(),
            request.getUserId(),
            request.getGenerationMode(),
            request.getSceneCategory()
        );
        log.info("CSGE策略决策: kp={}, mode={}, plan={}",
            request.getKnowledgePointId(), request.getGenerationMode(), plan);

        // 3. 执行生成
        List<GeneratedScene> scenes = executeGeneration(plan, kpInfo, profile, prefs, request);

        // 4. 后处理：安全审核 + 质量评估
        List<GeneratedScene> qualifiedScenes = postProcess(scenes, kpInfo, request);

        // 5. 持久化 + 缓存
        persistAndCache(qualifiedScenes, plan);

        // 6. 记录生成统计
        GenerationStats stats = GenerationStats.builder()
            .totalTimeMs(System.currentTimeMillis() - startTime)
            .templateMatched((int) qualifiedScenes.stream()
                .filter(s -> s.getTemplateId() != null).count())
            .aiGenerated((int) qualifiedScenes.stream()
                .filter(s -> s.getTemplateId() == null).count())
            .build();

        return SceneGenerationResult.builder()
            .scenes(qualifiedScenes)
            .stats(stats)
            .build();
    }

    /**
     * 执行场景生成（根据策略分发）
     */
    private List<GeneratedScene> executeGeneration(
            GenerationPlan plan,
            KnowledgePointInfo kpInfo,
            UserProfile profile,
            ScenePreferences prefs,
            SceneGenerationRequest request) {

        return switch (plan.getMode()) {
            case TEMPLATE -> generateFromTemplate(kpInfo, profile, prefs, request);
            case AI -> generateFromAI(kpInfo, profile, prefs, request);
            case HYBRID -> generateHybrid(kpInfo, profile, prefs, request, plan);
        };
    }

    /**
     * 模板模式：从已入库模板渲染
     */
    private List<GeneratedScene> generateFromTemplate(
            KnowledgePointInfo kpInfo,
            UserProfile profile,
            ScenePreferences prefs,
            SceneGenerationRequest request) {

        // 查询匹配模板
        List<SceneTemplate> templates = templateRepo.findMatching(
            kpInfo.getId(),
            request.getStage(),
            profile.getAgeGroup(),
            prefs.getInterestTags(),
            prefs.getAvoidSceneIds(),
            request.getMaxScenes() * 2  // 多查一些用于筛选
        );

        if (templates.isEmpty()) {
            log.warn("模板不足，降级到兜底场景: kp={}", kpInfo.getId());
            return getFallbackScenes(kpInfo, request.getMaxScenes());
        }

        // 按用户偏好排序
        templates = rankTemplates(templates, profile, prefs);

        // 渲染模板变量
        return templates.stream()
            .limit(request.getMaxScenes())
            .map(tpl -> renderTemplate(tpl, profile, kpInfo))
            .collect(Collectors.toList());
    }

    /**
     * AI模式：调用大模型实时生成
     */
    private List<GeneratedScene> generateFromAI(
            KnowledgePointInfo kpInfo,
            UserProfile profile,
            ScenePreferences prefs,
            SceneGenerationRequest request) {

        // 预算检查
        if (!budgetService.canGenerate(request.getUserId(), "csge")) {
            log.warn("预算不足，降级到模板模式: user={}", request.getUserId());
            return generateFromTemplate(kpInfo, profile, prefs, request);
        }

        // 选择最优场景类别（如果未指定）
        List<SceneCategory> categories = request.getSceneCategory() != null
            ? List.of(request.getSceneCategory())
            : selectOptimalCategories(kpInfo, profile, prefs);

        // 构建Prompt
        List<String> prompts = categories.stream()
            .limit(request.getMaxScenes())
            .map(cat -> buildScenePrompt(kpInfo, profile, prefs, cat))
            .collect(Collectors.toList());

        // 并发调用AI
        List<CompletableFuture<GeneratedScene>> futures = prompts.stream()
            .map(prompt -> CompletableFuture.supplyAsync(() -> {
                try {
                    String response = llmClient.chat(
                        LlmRequest.builder()
                            .model(selectModel(kpInfo, profile))
                            .systemPrompt(SCENE_SYSTEM_PROMPT)
                            .userPrompt(prompt)
                            .temperature(0.8)
                            .maxTokens(800)
                            .responseFormat("json")
                            .build()
                    );
                    return parseSceneResponse(response, kpInfo, profile);
                } catch (Exception e) {
                    log.error("AI生成场景失败: kp={}", kpInfo.getId(), e);
                    return null;
                }
            }))
            .collect(Collectors.toList());

        return futures.stream()
            .map(CompletableFuture::join)
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
    }

    /**
     * 混合模式：先模板后AI补
     */
    private List<GeneratedScene> generateHybrid(
            KnowledgePointInfo kpInfo,
            UserProfile profile,
            ScenePreferences prefs,
            SceneGenerationRequest request,
            GenerationPlan plan) {

        List<GeneratedScene> result = new ArrayList<>();

        // 先从模板获取
        if (plan.isTemplateFirst()) {
            result.addAll(generateFromTemplate(kpInfo, profile, prefs, request));
        }

        // 不足时用AI补充
        int deficit = request.getMaxScenes() - result.size();
        if (deficit > 0) {
            SceneGenerationRequest aiRequest = request.toBuilder()
                .maxScenes(deficit)
                .avoidSceneIds(mergeAvoidList(result, prefs))
                .build();
            result.addAll(generateFromAI(kpInfo, profile, prefs, aiRequest));
        }

        return result;
    }

    /**
     * 模板渲染：填充变量
     */
    private GeneratedScene renderTemplate(
            SceneTemplate template,
            UserProfile profile,
            KnowledgePointInfo kpInfo) {

        Map<String, String> variables = resolveVariables(template, profile);
        String renderedText = renderTemplateString(template.getTemplateContent(), variables);

        return GeneratedScene.builder()
            .templateId(template.getId())
            .knowledgePointId(kpInfo.getId())
            .userId(profile.getUserId())
            .sceneText(renderedText)
            .analogy(renderTemplateString(template.getAnalogyTemplate(), variables))
            .question(renderTemplateString(template.getQuestionTemplate(), variables))
            .explanation(renderTemplateString(template.getExplanationTemplate(), variables))
            .realWorldConnection(template.getRealWorldConnection())
            .multimediaAssets(resolveMultimedia(template.getMultimediaHints(), variables))
            .metaInfo(SceneMetaInfo.builder()
                .subject(kpInfo.getSubject())
                .stage(profile.getStage())
                .ageGroup(profile.getAgeGroup())
                .modelUsed("template_engine")
                .tokenCost(0)
                .fromCache(true)
                .build())
            .build();
    }

    /**
     * 变量解析：根据用户画像和年龄自适应填充变量
     */
    private Map<String, String> resolveVariables(
            SceneTemplate template, UserProfile profile) {

        Map<String, String> resolved = new HashMap<>();

        for (SceneVariable var : template.getVariables()) {
            String value;

            // 优先使用年龄自适应值
            if (var.getAgeAdaptive() != null && !var.getAgeAdaptive().isEmpty()) {
                value = findAgeAdaptiveValue(var.getAgeAdaptive(), profile.getAge());
            }
            // 其次使用兴趣匹配值
            else if (var.getType() == VariableType.CHOICE && var.getCandidates() != null) {
                value = selectByInterest(var.getCandidates(), profile.getInterests());
            }
            // 兜底使用默认值
            else {
                value = var.getDefaultValue();
            }

            resolved.put(var.getName(), value);
        }

        return resolved;
    }

    /**
     * 后处理：安全审核 + 质量评估 + 格式标准化
     */
    private List<GeneratedScene> postProcess(
            List<GeneratedScene> scenes,
            KnowledgePointInfo kpInfo,
            SceneGenerationRequest request) {

        List<GeneratedScene> qualified = new ArrayList<>();

        for (GeneratedScene scene : scenes) {
            // 安全审核（硬性过滤）
            SafetyCheckResult safetyResult = safetyFilter.check(scene.getSceneText());
            if (!safetyResult.isSafe()) {
                log.warn("场景安全审核未通过: scene={}, reason={}",
                    scene.getId(), safetyResult.getReason());
                continue;
            }

            // 质量评估
            double qualityScore = qualityEvaluator.evaluate(scene, kpInfo);
            scene.getMetaInfo().setQualityScore(qualityScore);

            // 质量阈值过滤
            if (qualityScore >= QUALITY_THRESHOLD) {
                qualified.add(scene);
            } else if (qualityScore >= RETRY_THRESHOLD) {
                // 边缘质量：尝试一次修复
                GeneratedScene repaired = repairScene(scene, qualityScore);
                if (repaired != null) {
                    qualified.add(repaired);
                }
            }
        }

        return qualified;
    }
}
```

```java
/**
 * 场景推荐服务 - 基于用户画像推荐最优场景
 */
@Service
public class SceneRecommendationService {

    @Autowired private GeneratedSceneRepository sceneRepo;
    @Autowired private UserProfileAdapter profileAdapter;
    @Autowired private SceneFeedbackRepository feedbackRepo;
    @Autowired private SceneCacheManager cacheManager;

    /**
     * 多策略融合推荐
     * 策略权重：协同过滤 40% + 内容匹配 35% + 规则过滤 25%
     */
    public List<SceneRecommendation> recommend(
            String knowledgePointId, String userId, int limit, String context) {

        UserProfile profile = profileAdapter.getProfile(userId);

        // 1. 协同过滤：找相似用户喜欢的场景
        List<SceneScore> cfScores = collaborativeFiltering(
            knowledgePointId, profile, limit * 3);

        // 2. 内容匹配：基于用户兴趣和偏好
        List<SceneScore> contentScores = contentBasedMatch(
            knowledgePointId, profile, limit * 3);

        // 3. 规则过滤：质量分 + 热度 + 新鲜度
        List<SceneScore> ruleScores = ruleBasedRank(
            knowledgePointId, profile, limit * 3);

        // 4. 融合排序
        Map<String, Double> fusedScores = fuseScores(
            cfScores, contentScores, ruleScores);

        // 5. 多样性保障：避免同一场景类别扎堆
        List<String> topSceneIds = diversityAwareSelection(
            fusedScores, limit, maxPerCategory=2);

        // 6. 构建推荐结果（含推荐理由）
        return topSceneIds.stream()
            .map(id -> buildRecommendation(id, fusedScores.get(id), profile))
            .collect(Collectors.toList());
    }

    /**
     * 协同过滤：基于用户相似度
     */
    private List<SceneScore> collaborativeFiltering(
            String kpId, UserProfile profile, int pool) {

        // 找到与当前用户画像相似的用户群体
        List<String> similarUserIds = profileAdapter.findSimilarUsers(
            profile.getUserId(), 50);

        // 获取这些用户对相关场景的评分
        List<SceneFeedback> feedbacks = feedbackRepo.findByUsersAndKp(
            similarUserIds, kpId);

        // 聚合计算每个场景的协同过滤得分
        Map<String, Double> sceneScores = feedbacks.stream()
            .collect(Collectors.groupingBy(
                SceneFeedback::getSceneId,
                Collectors.averagingDouble(f -> f.getRating() / 5.0)
            ));

        return sceneScores.entrySet().stream()
            .map(e -> new SceneScore(e.getKey(), e.getValue() * 0.4))
            .sorted(Comparator.comparingDouble(SceneScore::getScore).reversed())
            .limit(pool)
            .collect(Collectors.toList());
    }

    /**
     * 多样性感知选择
     */
    private List<String> diversityAwareSelection(
            Map<String, Double> scores, int limit, int maxPerCategory) {

        // 按分数排序
        List<Map.Entry<String, Double>> sorted = scores.entrySet().stream()
            .sorted(Map.Entry.<String, Double>comparingByValue().reversed())
            .collect(Collectors.toList());

        // 类别配额选择
        Map<String, Integer> categoryCount = new HashMap<>();
        List<String> selected = new ArrayList<>();

        for (var entry : sorted) {
            if (selected.size() >= limit) break;

            String sceneId = entry.getKey();
            String category = sceneRepo.getSceneCategory(sceneId);

            int count = categoryCount.getOrDefault(category, 0);
            if (count < maxPerCategory) {
                selected.add(sceneId);
                categoryCount.put(category, count + 1);
            }
        }

        return selected;
    }
}
```

```java
@Service

        Question original = questionAdapter.getQuestion(request.getQuestionId());

        // 2. 确定包装方向
        SceneCategory category = request.getSceneCategory() != null
            ? request.getSceneCategory()
            : selectBestCategory(original);

        // 4. 调用AI
        String response = llmClient.chat(LlmRequest.builder()
            .model("gpt-4o-mini")
            .systemPrompt("你是教育命题专家，擅长将枯燥的题目包装为有趣的情境题。")
            .userPrompt(prompt)
            .temperature(0.7)
            .maxTokens(500)
            .responseFormat("json")
            .build());

        // 5. 解析结果
        ContextualizedResult result = parseContextualized(response, original);

        // 6. 验证：确保考点不变
        if (!validateSameKnowledgePoint(original, result)) {
            log.warn("情境化后考点偏移，使用原始题目: qId={}", request.getQuestionId());
            return null;
        }

        // 7. 持久化
        ContextualizedProblem problem = mapper.toEntity(result, original, request);
        return problemRepo.save(problem);
    }

    /**
     * 验证情境化后考点未偏移
     */
    private boolean validateSameKnowledgePoint(
            Question original, ContextualizedResult result) {
        // 提取情境化后题目的知识点
        List<String> kps = questionAdapter.extractKnowledgePoints(
            result.getContextualizedStem());
        // 与原始知识点对比
        Set<String> originalKps = Set.copyOf(original.getKnowledgePointIds());
        Set<String> newKps = Set.copyOf(kps);
        // 至少80%知识点保持一致
        long preserved = kps.stream()
            .filter(originalKps::contains).count();
        return (double) preserved / originalKps.size() >= 0.8;
    }
```

## 8. 安全考虑

### 8.1 内容安全过滤

```java
/**
 * 场景内容安全过滤器
 */
@Component
public class SceneSafetyFilter {

    // 禁止内容模式
    private static final List<Pattern> FORBIDDEN_PATTERNS = List.of(
        Pattern.compile("(暴力|打架|伤人|杀人)"),
        Pattern.compile("(赌博|毒品|色情)"),
        Pattern.compile("(跳楼|自残|自杀)"),
        Pattern.compile("(赌博式|博彩|彩票)")
    );

    // 敏感话题
    private static final Set<String> SENSITIVE_TOPICS = Set.of(
        "政治敏感", "宗教冲突", "民族歧视", "地域歧视",
        "性别歧视", "消费攀比", "外貌评价"
    );

    public SafetyCheckResult check(String sceneText) {
        // 1. 正则模式匹配
        for (Pattern p : FORBIDDEN_PATTERNS) {
            if (p.matcher(sceneText).find()) {
                return SafetyCheckResult.fail("匹配禁止内容模式: " + p.pattern());
            }
        }

        // 2. AI安全审核（对长文本）
        if (sceneText.length() > 100) {
            SafetyCheckResult aiCheck = aiSafetyClient.check(sceneText);
            if (!aiCheck.isSafe()) {
                return aiCheck;
            }
        }

        // 3. 敏感话题检测
        for (String topic : SENSITIVE_TOPICS) {
            if (sceneText.contains(topic)) {
                return SafetyCheckResult.fail("包含敏感话题: " + topic);
            }
        }

        return SafetyCheckResult.pass();
    }
}
```

- `{{protagonist}}`: [小海, 星星, 可乐] (按兴趣动态)
- `{{friend}}`: [阿月, 果果, 豆豆]
- `{{food}}`: [披萨, 蛋糕, 水果派]
- `{{ingredient}}`: [面团, 饼底]

### A.2 物理 - 摩擦力（初中）

**场景模板**：
> 冬天结冰了，{{location}} 的路上变得特别滑。{{protagonist}} 穿着普通运动鞋走在冰面上，差点摔倒。但换上 {{shoe_type}} 后，走起来稳多了。同样是走路，为什么冰面比水泥路滑？为什么换鞋后感觉不一样？

**变量**：
- `{{location}}`: [学校操场, 小区门口, 公园小路]
- `{{protagonist}}`: [小海, 阿月]
- `{{shoe_type}}`: [防滑钉鞋, 冬季靴子]

**类比**：
> 摩擦力就像路面的"抓手"——水泥路面表面粗糙，像无数只小手抓住鞋底；冰面太平滑，那些"小手"消失了，所以走起来打滑。

### A.3 化学 - 酸碱反应（初中）

**场景模板**：
> 妈妈在厨房做馒头，让 {{protagonist}} 帮忙。面团发好后有点酸味，妈妈往里加了一些白色粉末——小苏打，揉匀后酸味慢慢消失了。蒸出来的馒头又松又软，里面还有小气孔。这到底发生了什么？

**类比**：
> 酸碱中和就像"跷跷板平衡"——酸在左边、碱在右边，它们碰到一起就会互相抵消，最终让跷跷板回到平衡位置（中性）。产生的小气泡（二氧化碳）就是它们"和解"时蹦出来的火花。
