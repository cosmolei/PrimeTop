# 端到端流程设计：会员订阅与增值服务购买完整链路

> 版本：1.0 | 最后更新：2026-06-02

## 1. 概述

### 1.1 文档范围

本文档详细描述 PrimeTop 用户从**免费用户 → 会员订阅 → 增值服务购买 → 权益消费 → 续费/降级/退款**的完整端到端链路，覆盖客户端交互、服务端处理、支付网关对接、额度管控、权益联动和异步后置处理的全部环节。

### 1.2 核心价值

会员订阅与增值服务是 PrimeTop 的核心商业化引擎，本链路需要满足：

1. **购买体验流畅**：从发现到完成支付 ≤ 4 步操作
2. **权益即时生效**：支付成功后 ≤ 2s 内权益可感知
3. **合规安全**：未成年人消费保护、支付风控、退款合规
4. **数据一致**：支付状态、权益状态、额度状态三方强一致
5. **降级可控**：支付失败、回调超时、服务异常时有明确兜底

### 1.3 端到端阶段总览

```
P1 发现与选择 → P2 订单创建 → P3 支付执行 → P4 权益激活 → P5 增值购买 → P6 续费/降级/退款
```

| 阶段 | 核心职责 | 关键模块 |
|------|----------|----------|
| P1 发现与选择 | 引导用户了解权益、选择套餐 | 客户端会员中心、运营弹窗 |
| P2 订单创建 | 生成订单、锁定价格、预检资格 | 订单服务、配额服务 |
| P3 支付执行 | 调起支付SDK、处理回调 | 支付网关、第三方支付 |
| P4 权益激活 | 更新会员状态、同步额度、下发权益 | 会员服务、额度服务 |
| P5 增值购买 | 购买次数包/时长包等增值商品 | 增值商品服务、资产服务 |
| P6 续费/降级/退款 | 到期续费、等级变更、退款处理 | 会员服务、订单服务、退款引擎 |

### 2.3 Redis 数据结构

```
# 用户会员缓存 (写入后同步到Redis)
user:membership:{user_id}         → Hash {tier, status, expires_at, auto_renew}  TTL=会员到期时间

# 用户额度 (原子操作)
user:quota:{user_id}:{quota_type} → String (剩余次数)  TTL=会员到期时间

# 订单幂等键
order:idempotent:{user_id}:{product_id}:{hash}  → String "order_no"  TTL=5min

# 支付回调处理锁
pay:callback:lock:{transaction_id} → String "1"  TTL=30s

# 价格缓存
config:tier:prices                 → Hash {tier_code → price_json}  TTL=10min
```

### 4.2 未成年人消费保护

```python
class MinorProtectionService:
    """未成年人消费保护服务"""
    
    # 消费限额配置 (单笔/月累计)
    CONSUMPTION_LIMITS = {
        "under_8": {"single_cents": 0, "monthly_cents": 0},       # 8岁以下禁止消费
        "age_8_16": {"single_cents": 5000, "monthly_cents": 20000}, # 8-16岁单笔≤50元/月≤200元
        "age_16_18": {"single_cents": 10000, "monthly_cents": 50000}, # 16-18岁放宽
    }
    
    async def check_purchase_eligibility(
        self, user_id: int, amount_cents: int
    ) -> MinorCheckResult:
        """
        检查未成年人消费资格
        
        规则：
        1. 用户年龄 < 8 岁 → 拒绝，提示家长代购
        2. 用户年龄 8-16 岁 → 单笔/月累计限额
        3. 所有未成年人 → 消费前需家长授权(首次)/已授权
        4. 会员类商品 → 相对宽松(教育属性)
        5. 增值商品 → 严格限额
        """
        user = await self.user_repo.get(user_id)
        
        if not user.is_minor:
            return MinorCheckResult(passed=True)
        
        age = user.age
        if age < 8:
            return MinorCheckResult(
                passed=False,
                reason="age_restriction",
                message="根据相关规定，8岁以下用户不支持自主消费，请家长代为操作",
                redirect="parent_purchase_guide"
            )
        
        limits = self._get_limits(age)
        if amount_cents > limits["single_cents"]:
            return MinorCheckResult(
                passed=False,
                reason="single_limit_exceeded",
                message=f"单笔消费不可超过 {limits['single_cents'] // 100} 元",
            )
        
        # 检查月累计
        month_total = await self.order_repo.get_month_total(user_id)
        if month_total + amount_cents > limits["monthly_cents"]:
            return MinorCheckResult(
                passed=False,
                reason="monthly_limit_exceeded",
                message="本月消费已达上限",
            )
        
        # 检查家长授权
        parent_auth = await self.parent_auth_repo.get_active_auth(user_id)
        if not parent_auth:
            return MinorCheckResult(
                passed=False,
                reason="parent_auth_required",
                message="需要家长授权才能完成消费",
                redirect="parent_auth",
                auth_token=generate_auth_token(user_id)
            )
        
        return MinorCheckResult(passed=True, minor_verified=True)
```

async def create_membership_order(request: CreateOrderRequest) -> OrderResult:
    """
    订单创建核心流程
    """
    # 1. 商品查询与价格校验
    product = await product_repo.get_by_id(request.product_id)
    if not product or not product.is_on_sale:
        raise BizError(ErrorCode.PRODUCT_NOT_AVAILABLE)
    
    # 2. 用户当前会员状态校验
    membership = await membership_repo.get(request.user_id)
    if membership and membership.status == "active":
        if membership.current_tier == request.product_id:
            if request.order_type == "subscription_new":
                raise BizError(ErrorCode.ALREADY_MEMBER, "您已是会员，请选择续费")
        # 计算升级差价
        if request.order_type == "subscription_upgrade":
            upgrade_info = calculate_upgrade_price(membership, product)
            request.discount_price_cents = upgrade_info.price_cents
    
    # 3. 未成年人消费保护检查
    minor_check = await minor_protection_service.check_purchase_eligibility(
        request.user_id, product.price_cents
    )
    if not minor_check.passed:
        raise BizError(ErrorCode.MINOR_PROTECTION, minor_check.message)
    
    # 4. 风控预检
    risk_result = await risk_service.pre_check(
        user_id=request.user_id,
        amount=product.price_cents,
        device_id=request.device_id,
        client_ip=request.client_ip,
    )
    
    # 5. 幂等检查 (5分钟内同一用户+同一商品)
    idempotent_key = f"order:idempotent:{request.user_id}:{request.product_id}:{hash_parts}"
    existing = await redis.get(idempotent_key)
    if existing:
        return await get_existing_order(existing)
    
    # 6. 计算最终价格
    final_price = product.price_cents
    if request.coupon_id:
        coupon = await coupon_service.apply_coupon(
            request.coupon_id, request.user_id, product
        )
        final_price = max(0, final_price - coupon.discount_cents)
    
    if request.use_trial and await trial_service.is_eligible(request.user_id):
        final_price = 0  # 试用免费
    
    # 7. 创建订单
    order = MembershipOrder(
        order_no=generate_order_no(),
        user_id=request.user_id,
        order_type=request.order_type,
        product_id=product.id,
        product_name=product.name,
        product_snapshot=product.to_snapshot(),
        original_price_cents=product.original_price_cents,
        discount_price_cents=final_price,
        discount_reason=coupon.discount_reason if request.coupon_id else None,
        coupon_id=request.coupon_id,
        payment_channel=request.payment_channel,
        payment_status="pending",
        target_tier=product.tier_code,
        duration_days=product.duration_days,
        risk_check_passed=risk_result.passed,
        risk_check_detail=risk_result.to_dict(),
        minor_verified=minor_check.minor_verified,
        device_id=request.device_id,
        client_ip=request.client_ip,
    )
    await order_repo.create(order)
    
    # 8. 设置幂等键
    await redis.setex(idempotent_key, 300, order.order_no)
    
    # 9. 计算权益生效时间
    effective_start, effective_end = calculate_effective_period(
        membership, product, request.order_type
    )
    order.effective_start = effective_start
    order.effective_end = effective_end
    await order_repo.update_effective_period(order)
    
    # 10. 零元单直接完成
    if final_price == 0:
        await complete_free_order(order)
        return OrderResult(order_no=order.order_no, payment_status="paid", require_pay
