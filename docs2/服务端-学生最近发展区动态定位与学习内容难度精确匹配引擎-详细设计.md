# 服务端 - 学生最近发展区(ZPD)动态定位与学习内容难度精确匹配引擎 详细设计

## 1. 概述

### 1.1 功能定位

本引擎基于维果茨基(Lev Vygotsky)"最近发展区"(Zone of Proximal Development, ZPD)教育理论，为每位学生动态构建个人能力边界模型，精确识别"已知区"(已掌握)、"最近发展区"(适度挑战可达成)和"未知区"(超出当前能力)，驱动全平台学习内容推荐、练习选题、AI辅导深度等场景的难度精确匹配。

### 1.2 与现有模块的关系

| 现有模块 | 关系 |
| --- | --- |
| 教育内容个性化难度感知建模与主观难度反馈校准引擎 | 提供**内容侧**难度参数，本引擎消费该数据构建**学生侧**ZPD |
| 练习答题实时自适应难度调节与动态选题引擎 | 本引擎为其提供初始ZPD边界和长期趋势，该引擎负责会话内微调 |
| 学生认知负荷监测与学习内容难度动态调节引擎 | 提供实时认知负荷信号，作为ZPD短期修正输入 |
| 知识追踪模型引擎与学生能力动态评估服务 | 提供知识点掌握度数据，作为ZPD计算的底层能力值 |
| 学生学习投入度多维量化与学习效能综合评估引擎 | 提供投入度信号，辅助判断学生是否处于ZPD内 |

### 1.3 核心目标

1. **动态建模**：为每位学生在每个知识维度上维护一个随时间衰减和随学习增长的ZPD区间
2. **精确匹配**：在推荐内容、选题、AI讲解深度时，将内容难度精准落在ZPD区间内
3. **平稳过渡**：随着学生能力增长，ZPD边界平滑上移，避免难度跳跃过大
4. **多维度适配**：ZPD不是单一标量，而是按知识维度(如计算能力、逻辑推理、阅读理解)独立维护

### 1.4 适用范围

- 小学至高中全学段(幼儿启蒙阶段不适用ZPD模型，采用分龄内容策略)
- 覆盖语文、数学、英语、物理、化学、生物、历史、地理、政治全学科
- 驱动练习选题、内容推荐、AI辅导策略、学习路径规划等下游场景

## 2. 理论模型与核心算法

### 2.1 ZPD 数学模型

对每个学生在每个知识维度 $d$ 上，维护一个三元组：

$$
ZPD(student, dimension) = \langle L_{mastered}, L_{zpd\_lower}, L_{zpd\_upper} \rangle
$$

| 参数 | 含义 | 取值范围 |
| --- | --- | --- |
| $L_{mastered}$ | 已掌握水平上限 | [0, 10] 浮点数 |
| $L_{zpd\_lower}$ | ZPD 下界(= $L_{mastered}$) | [0, 10] |
| $L_{zpd\_upper}$ | ZPD 上界(学生借助辅助可达到的水平) | [0, 10] |
| ZPD 宽度 | $L_{zpd\_upper} - L_{zpd\_lower}$ | 典型值 1.5 ~ 3.0 |

### 2.2 能力维度定义

```java
public enum AbilityDimension {
    COMPUTATION("计算能力"),        // 数值计算、代数运算
    LOGIC_REASONING("逻辑推理"),    // 证明、推理、分析
    SPATIAL_THINKING("空间思维"),   // 几何、图形、立体

    WRITING_EXPRESSION("写作表达"),  // 作文、表达、语言组织
    MEMORY_RECALL("记忆复述"),      // 背诵、默写、知识点回忆
    EXPERIMENT_INQUIRY("实验探究"),  // 实验设计、数据分析
    CROSS_SUBJECT("跨学科综合");     // 综合题、材料题

    // constructor, getter...
```

### 2.3 ZPD 初始值估算（冷启动）

当新用户首次进入系统，通过以下信号估算初始 ZPD：

```python
def estimate_initial_zpd(student_profile, subject, dimension):
    """
    基于学生画像估算初始ZPD
    """
    base_level = {
        'grade_1_3': 2.0,   # 小学1-3年级
        'grade_4_6': 4.0,   # 小学4-6年级
        'grade_7_9': 6.0,   # 初中
        'grade_10_12': 7.5  # 高中
    }.get(student_profile.grade_group, 3.0)

    # 学科权重调整
    subject_factor = get_subject_difficulty_factor(subject)  # 0.8 ~ 1.2

    # 诊断测试校正
    diag_score = student_profile.diagnostic_scores.get((subject, dimension))
    if diag_score is not None:
        # 诊断测试直接映射能力水平
        estimated_level = diag_score * 10  # 0-1 → 0-10
    else:
        estimated_level = base_level * subject_factor

    zpd_width = 2.0  # 默认ZPD宽度

    return ZPDRange(
        mastered_level=estimated_level - zpd_width * 0.3,
        zpd_lower=estimated_level - zpd_width * 0.3,
        zpd_upper=estimated_level + zpd_width * 0.7,
        confidence=0.3 if diag_score is None else 0.6,
        last_updated=now()
    )
```

### 2.4 ZPD 动态更新算法

ZPD 随每次答题行为、学习交互持续更新，采用 **贝叶斯增量更新** 与 **指数遗忘衰减** 混合模型。

#### 2.4.1 答题事件更新

```python
def update_zpd_on_answer(zpd_state, question, is_correct, response_time, hint_used):
    """
    每次答题后增量更新ZPD
    """
    q_difficulty = question.difficulty_level  # [0, 10]
    dimension = question.ability_dimension

    # 1. 计算答题表现信号
    performance_signal = compute_performance_signal(
        is_correct, q_difficulty, response_time, hint_used, zpd_state
    )

    # 2. 如果答对了ZPD上界附近的题，扩展ZPD上界
    if is_correct and q_difficulty >= zpd_state.zpd_upper - 0.5:
        expansion = compute_zpd_expansion(performance_signal, zpd_state.confidence)
        zpd_state.zpd_upper = min(10.0, zpd_state.zpd_upper + expansion)

    # 3. 如果连续答对当前mastered水平附近的题，提升mastered水平
    if is_correct and q_difficulty <= zpd_state.mastered_level + 0.5:
        zpd_state.mastered_level = min(
            zpd_state.zpd_upper - 0.5,
            zpd_state.mastered_level + LEARNING_RATE * performance_signal
        )
        zpd_state.zpd_lower = zpd_state.mastered_level

    # 4. 如果答错了mastered水平以下的题，可能高估了，下调
    if not is_correct and q_difficulty < zpd_state.mastered_level - 1.0:
        zpd_state.mastered_level = max(
            0.0,
            zpd_state.mastered_level - REGRESSION_RATE * (1 - performance_signal)
        )
        zpd_state.zpd_lower = zpd_state.mastered_level
        zpd_state.zpd_upper = max(
            zpd_state.zpd_lower + 1.0,
            zpd_state.zpd_upper - REGRESSION_RATE * 0.5
        )

    # 5. 更新置信度
    zpd_state.confidence = min(1.0, zpd_state.confidence + CONFIDENCE_INCREMENT)
    zpd_state.last_updated = now()
    zpd_state.update_count += 1

    return zpd_state


def compute_performance_signal(is_correct, difficulty, response_time, hint_used, zpd_state):
    """
    计算综合表现信号 [0, 1]
    """
    # 正确率信号
    correctness = 1.0 if is_correct else 0.0

    # 时间信号：相比该难度预期时间的比率
    expected_time = estimate_expected_time(difficulty)
    time_ratio = expected_time / max(response_time, 1)
    time_signal = clamp(0.5 + 0.5 * math.log(time_ratio + 0.5), 0, 1)

    # 提示信号：未用提示得分更高
    hint_penalty = 0.15 if hint_used else 0.0

    # 综合信号
    signal = correctness * 0.6 + time_signal * 0.25 + (1 - hint_penalty) * 0.15
    return clamp(signal, 0, 1)
```

#### 2.4.2 遗忘衰减机制

```python
def apply_forgetting_decay(zpd_state, days_since_last_activity):
    """
    基于艾宾浩斯遗忘曲线对ZPD进行衰减
    """
    if days_since_last_activity <= 0:
        return zpd_state

    # 衰减率随天数增长，但有下限保护
    decay_rate = 0.02 * math.log(1 + days_since_last_activity)
    decay_rate = min(decay_rate, 0.3)  # 最多衰减30%

    zpd_state.mastered_level *= (1 - decay_rate)
    zpd_state.zpd_lower = zpd_state.mastered_level

    # ZPD上界衰减更慢(潜在能力消退比已掌握能力慢)
    upper_decay = decay_rate * 0.5
    zpd_state.zpd_upper *= (1 - upper_decay)

    # 确保ZPD宽度不小于最小值
    if zpd_state.zpd_upper - zpd_state.zpd_lower < MIN_ZPD_WIDTH:
        zpd_state.zpd_upper = zpd_state.zpd_lower + MIN_ZPD_WIDTH

    # 置信度随时间降低
    zpd_state.confidence *= math.exp(-days_since_last_activity / 30.0)

    return zpd_state
```

#### 2.4.3 常量参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `LEARNING_RATE` | 0.08 | 每次成功答题的能力提升步长 |
| `REGRESSION_RATE` | 0.05 | 错答导致的能力回调步长 |
| `CONFIDENCE_INCREMENT` | 0.02 | 每次交互增加的置信度 |
| `MIN_ZPD_WIDTH` | 1.0 | ZPD 最小宽度(避免过窄导致推荐困难) |
| `MAX_ZPD_WIDTH` | 4.0 | ZPD 最大宽度(避免过宽失去精确性) |
| `DECAY_HALF_LIFE_DAYS` | 14 | 衰减半衰期(两周不学习，掌握度约降一半) |

## 3. 数据结构定义

### 3.1 数据库表设计

#### 3.1.1 `student_zpd_state` — 学生ZPD状态表

```sql
CREATE TABLE student_zpd_state (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id      BIGINT NOT NULL COMMENT '学生ID',
    subject         VARCHAR(20) NOT NULL COMMENT '学科',
    dimension       VARCHAR(40) NOT NULL COMMENT '能力维度',
    mastered_level  DECIMAL(5,2) NOT NULL DEFAULT 0 COMMENT '已掌握水平[0,10]',
    zpd_lower       DECIMAL(5,2) NOT NULL DEFAULT 0 COMMENT 'ZPD下界',
    zpd_upper       DECIMAL(5,2) NOT NULL DEFAULT 2.0 COMMENT 'ZPD上界',
    zpd_width       DECIMAL(5,2) GENERATED ALWAYS AS (zpd_upper - zpd_lower) STORED COMMENT 'ZPD宽度',
    confidence      DECIMAL(3,2) NOT NULL DEFAULT 0.30 COMMENT '置信度[0,1]',
    update_count    INT NOT NULL DEFAULT 0 COMMENT '累计更新次数',
    last_answer_event_id BIGINT COMMENT '最近一次触发更新的答题事件ID',
    last_active_at  DATETIME NOT NULL COMMENT '最近活跃时间',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_student_subject_dim (student_id, subject, dimension),
    KEY idx_student_subject (student_id, subject),
    KEY idx_last_active (last_active_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生ZPD状态表';
```

#### 3.1.2 `zpd_update_log` — ZPD更新日志表

### 5.2 ZPD 计算服务核心代码

```java
@Service
public class ZpdCalculationService {

    @Autowired
    private ZpdStateRepository zpdRepo;

    @Autowired
    private ContentDifficultyService difficultyService;

    @Autowired
    private EventPublisher eventPublisher;

    private static final double LEARNING_RATE = 0.08;
    private static final double REGRESSION_RATE = 0.05;
    private static final double CONFIDENCE_INCREMENT = 0.02;
    private static final double MIN_ZPD_WIDTH = 1.0;
    private static final double MAX_ZPD_WIDTH = 4.0;

    /**
     * 处理答题事件，增量更新ZPD
     */
    @EventListener
    @Async("zpdUpdateExecutor")
    public void onAnswerEvent(AnswerEvent event) {
        // 1. 加载当前ZPD状态
        ZpdState state = zpdRepo.findOrCreate(
            event.getStudentId(),
            event.getSubject(),
            event.getDimension()
        );

        // 2. 应用遗忘衰减
        int daysInactive = Days.between(state.getLastActiveAt(), LocalDateTime.now());
        state = applyDecay(state, daysInactive);

        // 3. 获取题目难度
        ContentDifficulty difficulty = difficultyService.getDifficulty(
            event.getQuestionId(), "QUESTION"
        );

        // 4. 计算表现信号
        double performanceSignal = computePerformanceSignal(
            event.isCorrect(),
            difficulty.getDifficulty(),
            event.getResponseTimeMs(),
            event.isHintUsed(),
            state
        );

        // 5. 保存旧状态用于日志
        ZpdState oldState = state.copy();

        // 6. 根据答题结果更新ZPD
        state = updateZpd(state, difficulty.getDifficulty(), event.isCorrect(), performanceSignal);

        // 7. 持久化
        zpdRepo.save(state);
        zpdRepo.logUpdate(state, oldState, "ANSWER", event.getEventId(), performanceSignal);

        // 8. 发布事件
        eventPublisher.publish(new ZpdUpdatedEvent(state, oldState, event));
    }

    private ZpdState updateZpd(ZpdState state, double qDifficulty,
                                boolean isCorrect, double performanceSignal) {
        // 答对ZPD上界附近的题 → 扩展上界
        if (isCorrect && qDifficulty >= state.getZpdUpper() - 0.5) {
            double expansion = performanceSignal * 0.3;
            state.setZpdUpper(Math.min(10.0, state.getZpdUpper() + expansion));
        }

        // 答对mastered附近 → 提升mastered
        if (isCorrect && qDifficulty <= state.getMasteredLevel() + 0.5) {
            double increment = LEARNING_RATE * performanceSignal;
            double newMastered = Math.min(
                state.getZpdUpper() - 0.5,
                state.getMasteredLevel() + increment
            );
            state.setMasteredLevel(newMastered);
            state.setZpdLower(newMastered);
        }

        // 答错mastered以下 → 下调
        if (!isCorrect && qDifficulty < state.getMasteredLevel() - 1.0) {
            double decrement = REGRESSION_RATE * (1 - performanceSignal);
            double newMastered = Math.max(0.0, state.getMasteredLevel() - decrement);
            state.setMasteredLevel(newMastered);
            state.setZpdLower(newMastered);
            state.setZpdUpper(Math.max(
                newMastered + MIN_ZPD_WIDTH,
                state.getZpdUpper() - decrement * 0.5
            ));
        }

        // 限制ZPD宽度
        double width = state.getZpdUpper() - state.getZpdLower();
        if (width < MIN_ZPD_WIDTH) {
            state.setZpdUpper(state.getZpdLower() + MIN_ZPD_WIDTH);
        } else if (width > MAX_ZPD_WIDTH) {
            state.setZpdUpper(state.getZpdLower() + MAX_ZPD_WIDTH);
        }

        // 更新置信度和活跃时间
        state.setConfidence(Math.min(1.0, state.getConfidence() + CONFIDENCE_INCREMENT));
        state.setLastActiveAt(LocalDateTime.now());
        state.setUpdateCount(state.getUpdateCount() + 1);

        return state;
    }

    private double computePerformanceSignal(boolean isCorrect, double difficulty,
            long responseTimeMs, boolean hintUsed, ZpdState state) {
        double correctness = isCorrect ? 1.0 : 0.0;

        long expectedTime = estimateExpectedTimeMs(difficulty);
        double timeRatio = (double) expectedTime / Math.max(responseTimeMs, 1000);
        double timeSignal = Math.max(0, Math.min(1, 0.5 + 0.5 * Math.log(timeRatio + 0.5)));

        double hintFactor = hintUsed ? 0.85 : 1.0;

        return Math.max(0, Math.min(1,
            correctness * 0.6 + timeSignal * 0.25 * hintFactor + 0.15 * hintFactor
        ));
    }

    private long estimateExpectedTimeMs(double difficulty) {
        // 难度越高预期时间越长，基础30秒 + 难度系数
        return (long) (30000 + difficulty * 15000);
    }

    /**
     * 应用遗忘衰减
     */
    public ZpdState applyDecay(ZpdState state, int daysInactive) {
        if (daysInactive <= 0) return state;

        double decayRate = Math.min(0.3, 0.02 * Math.log(1 + daysInactive));

        double newMastered = state.getMasteredLevel() * (1 - decayRate);
        double newUpper = state.getZpdUpper() * (1 - decayRate * 0.5);

        // 保证最小宽度
        if (newUpper - newMastered < MIN_ZPD_WIDTH) {
            newUpper = newMastered + MIN_ZPD_WIDTH;
        }

        state.setMasteredLevel(newMastered);
        state.setZpdLower(newMastered);
        state.setZpdUpper(newUpper);
        state.setConfidence(state.getConfidence() * Math.exp(-daysInactive / 30.0));

        return state;
    }
}
```

```java
@Service
public class ZpdMatchingService {

    @Autowired
    private ZpdStateRepository zpdRepo;

    @Autowired
    private ContentDifficultyService difficultyService;

    @Autowired
    private ZpdMatchDecisionRepository decisionRepo;

    /**
     * 为学生匹配指定场景下最合适难度的内容
     */
    public MatchResult matchContents(MatchRequest request) {
        // 1. 获取学生ZPD
        ZpdState zpd = zpdRepo.findOrCreate(
            request.getStudentId(),
            request.getSubject(),
            request.getDimension()
        );

        // 2. 应用遗忘衰减(如果距上次活跃超过1天)
        int daysInactive = (int) ChronoUnit.DAYS.between(
            zpd.getLastActiveAt(), LocalDateTime.now()
        );
        if (daysInactive > 0) {
            zpd = zpdCalculationService.applyDecay(zpd, daysInactive);
        }

        // 3. 计算目标难度
        double targetDifficulty = computeTargetDifficulty(zpd, request.getStrategy());

        // 4. 从候选池中匹配
        List<ContentWithDifficulty> candidates = difficultyService.batchGetDifficulty(
            request.getContentPoolIds(), request.getSubject(), request.getDimension()
        );

        // 5. 按匹配度排序
        List<ContentMatch> matches = candidates.stream()
            .map(c -> computeMatchScore(c, targetDifficulty, zpd))
            .sorted(Comparator.comparingDouble(ContentMatch::getMatchScore).reversed())
            .limit(request.getCount())
            .collect(Collectors.toList());

        // 6. 过滤掉不适合的
        List<ContentMatch> filtered = candidates.stream()
            .filter(c -> !matches.contains(c))
            .map(c -> new ContentMatch(c, 0, determineFilterReason(c, zpd)))
            .collect(Collectors.toList());

        // 7. 记录决策
        MatchZone zone = determineZone(targetDifficulty, zpd);
        decisionRepo.save(new ZpdMatchDecision(
            request.getStudentId(), request.getSubject(), request.getDimension(),
            request.getScene(), zpd.getZpdLower(), zpd.getZpdUpper(),
            targetDifficulty, zone.name(),
            matches.stream().map(ContentMatch::getContentId).collect(Collectors.toList())
        ));

        return new MatchResult(zpd, targetDifficulty, zone, matches, filtered);
    }

    private double computeTargetDifficulty(ZpdState zpd, MatchStrategy strategy) {
        double lower = zpd.getZpdLower();
        double upper = zpd.getZpdUpper();
        double center = (lower + upper) / 2;

        return switch (strategy) {
            case ZPD_CENTERED -> center;
            case ZPD_LOWER_BOUND -> lower + (upper - lower) * 0.2;
            case ZPD_UPPER_BOUND -> lower + (upper - lower) * 0.8;
            case COMFORT_REVIEW -> Math.max(0, lower - 1.0);
            case MIXED_70_30 -> center; // 实际选取时混搭
        };
    }

    private ContentMatch computeMatchScore(ContentWithDifficulty content,
                                            double targetDifficulty, ZpdState zpd) {
        double diff = Math.abs(content.getDifficulty() - targetDifficulty);
        double score = Math.exp(-diff * diff / 2.0); // 高斯核

        String reason;
        if (content.getDifficulty() < zpd.getZpdLower()) {
            reason = "已掌握区，适合复习巩固";
        } else if (content.getDifficulty() > zpd.getZpdUpper()) {
            reason = "超出ZPD，暂不推荐";
            score = 0; // 超出ZPD的直接排除
        } else if (content.getDifficulty() < targetDifficulty) {
            reason = "ZPD下沿，热身推荐";
        } else if (content.getDifficulty() > targetDifficulty) {
            reason = "ZPD上沿，挑战推荐";
        } else {
            reason = "ZPD中心，最佳匹配";
        }

        return new ContentMatch(content.getContentId(), content.getDifficulty(), score, reason);
    }

    private MatchZone determineZone(double targetDifficulty, ZpdState zpd) {
        if (targetDifficulty < zpd.getZpdLower()) return MatchZone.COMFORT;
        if (targetDifficulty > zpd.getZpdUpper()) return MatchZone.CHALLENGE;
        return MatchZone.ZPD;
    }

    public enum MatchZone {
        COMFORT("已掌握区"),
        ZPD("最近发展区"),
        CHALLENGE("挑战区");

        private final String label;
        MatchZone(String label) { this.label = label; }
    }
}
```

```java
@Component
public class ZpdDecayScheduler {

    @Autowired
    private ZpdStateRepository zpdRepo;

    @Autowired
    private ZpdCalculationService zpdCalculationService;

    /**
     * 每天凌晨3点执行全局ZPD衰减
     */
    @Scheduled(cron = "0 0 3 * * ?")
    public void globalDecayJob() {
        int batchSize = 500;
        long lastId = 0;

        while (true) {
            List<ZpdState> batch = zpdRepo.findInactiveSince(
                lastId, LocalDateTime.now().minusDays(1), batchSize
            );

            if (batch.isEmpty()) break;

            for (ZpdState state : batch) {
                int daysInactive = (int) ChronoUnit.DAYS.between(
                    state.getLastActiveAt(), LocalDateTime.now()
                );
                ZpdState oldState = state.copy();
                zpdCalculationService.applyDecay(state, daysInactive);
                zpdRepo.save(state);
                zpdRepo.logUpdate(state, oldState, "DECAY", null, 0);

                // 如果衰减后置信度过低，标记需要重新诊断
                if (state.getConfidence() < 0.2) {
                    eventPublisher.publish(new ZpdConfidenceLowEvent(
                        state.getStudentId(), state.getSubject(), state.getDimension()
                    ));
                }
            }

            lastId = batch.get(batch.size() - 1).getId();
        }
    }
}
```

```java
public enum ZpdLifecycleState {
    COLD_START,    // 冷启动中，数据不足
    ACTIVE,        // 正常活跃，ZPD持续更新
    DECAYING,      // 衰减中，3天以上无活跃
    STALE          // 过期，需要重新诊断
}

@Component
public class ZpdLifecycleManager {

    public ZpdLifecycleState determineState(ZpdState zpd) {
        if (zpd.getUpdateCount() < 5) return ZpdLifecycleState.COLD_START;

        long daysInactive = ChronoUnit.DAYS.between(
            zpd.getLastActiveAt(), LocalDateTime.now()
        );

        if (daysInactive >= 14 || zpd.getConfidence() < 0.2) {
            return ZpdLifecycleState.STALE;
        } else if (daysInactive >= 3) {
            return ZpdLifecycleState.DECAYING;
        } else {
            return ZpdLifecycleState.ACTIVE;
        }
    }
}
```

```java
@Service
public class ZpdFallbackHandler {

    /**
     * 当ZPD引擎不可用时的降级逻辑
     */
    public MatchResult fallbackMatch(MatchRequest request) {
        // 降级策略1：使用年级-学科默认难度区间
        double[] defaultRange = getDefaultDifficultyRange(
            request.getStudentId(), request.getSubject()
        );

        // 从候选池中按默认区间筛选
        List<ContentMatch> matches = request.getContentPoolIds().stream()
            .map(id -> {
                ContentDifficulty d = difficultyService.getDifficultyOrNull(id, "QUESTION");
                if (d != null && d.getDifficulty() >= defaultRange[0]
                    && d.getDifficulty() <= defaultRange[1]) {
                    return new ContentMatch(id, d.getDifficulty(), 0.5, "降级匹配-默认年级区间");
                }
                return null;
            })
            .filter(Objects::nonNull)
            .limit(request.getCount())
            .collect(Collectors.toList());

        return MatchResult.builder()
            .zpdSnapshot(null)
            .targetDifficulty((defaultRange[0] + defaultRange[1]) / 2)
            .matchZone(MatchZone.ZPD)
            .matchedContents(matches)
            .degraded(true)
            .degradeReason("ZPD引擎不可用，使用年级默认难度区间")
            .build();
    }

    private double[] getDefaultDifficultyRange(Long studentId, String subject) {
        StudentProfile profile = studentService.getProfile(studentId);
        return switch (profile.getGradeGroup()) {
            case PRIMARY_LOW -> new double[]{1.0, 3.5};   // 小学低年级
            case PRIMARY_HIGH -> new double[]{2.5, 5.5};   // 小学高年级
            case JUNIOR -> new double[]{4.0, 7.0};         // 初中
            case SENIOR -> new double[]{5.5, 8.5};         // 高中
        };
```

### 10.3 读写分离

- **读取**：优先读Redis缓存，未命中读MySQL并回写缓存
- **衰减任务**：批量处理，每批500条，凌晨低峰期执行

### 11.3 数据质量校验

```java
@Component
public class ZpdDataQualityChecker {

    /**
     * 每小时执行一次数据质量校验
     */
    @Scheduled(fixedRate = 3600000)
    public void checkDataQuality() {
        // 1. 检查异常ZPD：upper < lower
        int invalidCount = zpdRepo.countInvalidZpdRanges();
        if (invalidCount > 0) {
            alertService.warn("ZPD_INVALID_RANGE", invalidCount + " 条ZPD记录上界<下界");
            zpdRepo.autoFixInvalidRanges();
        }

        // 2. 检查ZPD宽度异常
        int oversizedCount = zpdRepo.countOversizedZpd(4.0);
        int undersizedCount = zpdRepo.countUndersizedZpd(0.5);
        if (oversizedCount > 100 || undersizedCount > 100) {
            alertService.warn("ZPD_WIDTH_ANOMALY",
                String.format("过宽:%d, 过窄:%d", oversizedCount, undersizedCount));
        }

        // 3. 检查置信度分布
        double avgConfidence = zpdRepo.avgConfidence();
        if (avgConfidence < 0.4) {
            alertService.warn("ZPD_LOW_CONFIDENCE", "全平台平均置信度: " + avgConfidence);
        }

        // 4. 检查匹配正确率
        double recentMatchAccuracy = computeRecentMatchAccuracy(6); // 最近6小时
        log.info("Recent ZPD match accuracy: {}", recentMatchAccuracy);
        if (recentMatchAccuracy > 0.85 || recentMatchAccuracy < 0.50) {
            alertService.warn("ZPD_ACCURACY_DRIFT",
                "匹配正确率偏离理想区间(0.65-0.80): " + recentMatchAccuracy);
        }
    }
}
```

## 12. 安全与合规

### 12.1 数据隔离

- ZPD数据按 `student_id` 严格隔离，查询接口强制校验数据归属
- 家长查看孩子ZPD需经过家长绑定关系校验
- 教师查看班级学生ZPD需经过班级权限校验

- ZPD原始数值不直接展示给学生(避免标签化)，前端展示使用定性描述(如"进阶中""挑战中""已掌握")
- 对外API返回中 `mastered_level` 等数值需根据调用方权限进行脱敏

## 14. 测试策略

### 14.1 单元测试

```java
@DisplayName("ZPD计算引擎单元测试")
class ZpdCalculationServiceTest {

    @Test
    @DisplayName("答对ZPD上界附近的题目应扩展ZPD上界")
    void shouldExpandZpdUpperWhenCorrectAnswerNearUpper() {
        // Given
        ZpdState state = ZpdState.builder()
            .masteredLevel(5.0).zpdLower(5.0).zpdUpper(7.0)
            .confidence(0.8).build();
        double questionDifficulty = 6.8;

        // When
        ZpdState updated = service.updateZpd(state, questionDifficulty, true, 0.9);

        // Then
        assertThat(updated.getZpdUpper()).isGreaterThan(7.0);
        assertThat(updated.getZpdUpper()).isLessThanOrEqualTo(10.0);
    }

    @Test
    @DisplayName("答错远低于mastered的题应下调mastered")
    void shouldDecreaseMasteredWhenWrongAnswerBelowMastered() {
        ZpdState state = ZpdState.builder()
            .masteredLevel(6.0).zpdLower(6.0).zpdUpper(8.0)
            .confidence(0.8).build();

        ZpdState updated = service.updateZpd(state, 4.0, false, 0.2);

        assertThat(updated.getMasteredLevel()).isLessThan(6.0);
        assertThat(updated.getZpdLower()).isEqualTo(updated.getMasteredLevel());
    }

    @Test
    @DisplayName("ZPD宽度不应小于最小值")
    void shouldMaintainMinZpdWidth() {
        ZpdState state = ZpdState.builder()
            .masteredLevel(8.0).zpdLower(8.0).zpdUpper(9.0)
            .confidence(0.8).build();

        // 连续答错导致upper下降
        ZpdState updated = service.updateZpd(state, 6.0, false, 0.1);

        assertThat(updated.getZpdUpper() - updated.getZpdLower()).isGreaterThanOrEqualTo(1.0);
    }

    @Test
    @DisplayName("14天不活跃后衰减应将状态标记为STALE")
    void shouldBeStaleAfter14DaysInactivity() {
        ZpdState state = ZpdState.builder()
            .masteredLevel(6.0).zpdLower(6.0).zpdUpper(8.0)
            .confidence(0.8)
            .lastActiveAt(LocalDateTime.now().minusDays(15))
            .updateCount(100)
            .build();

        ZpdLifecycleState lifecycle = lifecycleManager.determineState(state);
        assertThat(lifecycle).isEqualTo(ZpdLifecycleState.STALE);
    }
}
```
