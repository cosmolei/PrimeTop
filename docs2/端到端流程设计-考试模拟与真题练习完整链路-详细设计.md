### 1.2 参与角色

| 角色 | 触点 | 说明 |
|------|------|------|
| 学生 | 全流程 | 核心用户，发起并完成考试 |
| 家长 | 成绩报告 | 接收孩子模考结果推送 |
| 系统 | 自动批阅、推荐、提醒 | 后台自动化处理 |
| AI | 主观题批阅、解析生成 | 辅助批改与讲解 |
| 内容运营 | 试卷管理 | 上架/下架试卷、维护试卷状态 |

### 1.3 核心业务约束

1. **限时强控**：模考模式时间到必须自动交卷，不允许延期
2. **答案隔离**：答题过程中不可查看答案与解析，防止作弊
3. **断点续答**：异常退出后可恢复到上次进度（剩余时间同步恢复）
4. **一次性作答**：已提交的考试不可修改答案，只能重做
5. **权益校验**：免费用户每月限 3 次模考，会员不限
6. **年龄适配**：初中卷不得推送给小学生，高中卷仅限高中生

def should_recommend_exam(user_profile, context):
    """判断是否应推荐模考试卷"""
    reasons = []
    
    # 规则1: 考试季节性 (期中/期末/中高考前 2-4 周)
    exam_season = get_upcoming_exam_season(user_profile.grade, context.now)
    if exam_season and exam_season.weeks_until <= 4:
        reasons.append({
            "type": "exam_season",
            "exam": exam_season.name,
            "weeks_until": exam_season.weeks_until
        })
    
    # 规则2: 知识薄弱积累 (3+ 知识点掌握度 < 50%)
    weak_points = get_weak_knowledge_points(user_profile.user_id, threshold=0.5)
    if len(weak_points) >= 3:
        reasons.append({
            "type": "weak_points",
            "count": len(weak_points),
            "subjects": list(set(p.subject for p in weak_points))
        })
    
    # 规则3: 学习计划中的模考任务
    pending_exam_tasks = get_pending_tasks(
        user_profile.user_id, task_type="exam_simulation"
    )
    if pending_exam_tasks:
        reasons.append({
            "type": "plan_task",
            "task": pending_exam_tasks[0]
        })
    
    # 规则4: 距上次模考超过 7 天
    last_exam = get_last_exam_session(user_profile.user_id)
    if not last_exam or (context.now - last_exam.submitted_at).days >= 7:
        reasons.append({
            "type": "interval",
            "days_since_last": (context.now - last_exam.submitted_at).days if last_exam else 999
        })
    
    # 冷却: 3 天内做过模考不再推荐
    if last_exam and (context.now - last_exam.submitted_at).days < 3:
        return None
    
    return reasons[0] if reasons else None
```

// ExamPaperQueryService.java
public PageResult<ExamPaperVO> queryPapers(ExamPaperQuery query, String userId) {
    // 1. 构建查询条件
    LambdaQueryWrapper<ExamPaper> wrapper = Wrappers.lambdaQuery();
    wrapper.eq(ExamPaper::getStatus, PaperStatus.PUBLISHED)
           .eq(query.getSubject() != null, ExamPaper::getSubject, query.getSubject())
           .eq(query.getGrade() != null, ExamPaper::getGrade, query.getGrade())
           .eq(query.getExamLevel() != null, ExamPaper::getExamLevel, query.getExamLevel())
           .eq(query.getRegion() != null, ExamPaper::getRegion, query.getRegion());
    
    // 2. 排序策略
    switch (query.getSortBy()) {
        case "latest":
            wrapper.orderByDesc(ExamPaper::getCreatedAt);
            break;
        case "popular":
            wrapper.orderByDesc(ExamPaper::getCompletionCount);
            break;
        case "score":
            wrapper.orderByDesc(ExamPaper::getAverageScore);
            break;
        default:
            wrapper.orderByDesc(ExamPaper::getCompletionCount);
    }
    
    // 3. 分页查询
    Page<ExamPaper> page = examPaperMapper.selectPage(
        new Page<>(query.getPage(), query.getPageSize()), wrapper
    );
    
    // 4. 附加用户维度数据
    List<String> paperIds = page.getRecords().stream()
        .map(ExamPaper::getId).collect(toList());
    Map<String, UserExamHistory> historyMap = examSessionService
        .getUserExamHistoryBatch(userId, paperIds);
    
    // 5. 组装 VO
    return PageResult.of(page.getRecords().stream().map(paper -> {
        ExamPaperVO vo = ExamPaperVO.from(paper);
        UserExamHistory history = historyMap.get(paper.getId());
        if (history != null) {
            vo.setHasUserHistory(true);
            vo.setBestScore(history.getBestScore());
            vo.setAttemptCount(history.getAttemptCount());
        }
        return vo;
    }).collect(toList()), page.getTotal());
}

**权益校验服务端逻辑：**

```java
// ExamEntitlementService.java
public ExamEntitlementResult checkEntitlement(String userId, String paperId) {
    // 1. 查询用户会员状态
    Membership membership = membershipService.getActiveMembership(userId);
    boolean isMember = membership != null && membership.isActive();
    
    // 2. 查询本月已用模考次数
    int usedCount = examSessionService.countMonthlyExams(userId);
    
    // 3. 免费用户限制
    if (!isMember) {
        int freeQuota = systemConfig.getInt("exam.free_monthly_quota", 3);
        if (usedCount >= freeQuota) {
            return ExamEntitlementResult.denied(
                "本月模考次数已用完",
                "MEMBERSHIP_REQUIRED",
                Map.of("usedCount", usedCount, "quota", freeQuota)
            );
        }
    }
    
    // 4. 检查试卷是否为会员专享
    ExamPaper paper = examPaperService.getById(paperId);
    if (paper != null && paper.isMembersOnly() && !isMember) {
        return ExamEntitlementResult.denied(
            "该试卷为会员专享",
            "MEMBERS_ONLY_PAPER",
            Map.of("paperId", paperId)
        );
    }
    
    // 5. 检查是否有未完成的同试卷会话
    ExamSession activeSession = examSessionService
        .findActiveSession(userId, paperId);
    if (activeSession != null) {
        return ExamEntitlementResult.resumeExisting(activeSession.getId());
    }
    
    return ExamEntitlementResult.allowed(
        isMember ? -1 : (3 - usedCount)  // 剩余次数，-1表示无限
    );
}
```

@Transactional
public ExamSessionDTO createSession(String userId, String paperId, ExamMode mode) {
    ExamPaper paper = examPaperService.getById(paperId);
    
    // 生成考试会话
    ExamSession session = ExamSession.builder()
        .id(idGenerator.nextId("exam_sess"))
        .userId(userId)
        .paperId(paperId)
        .status(ExamSessionStatus.NOT_STARTED)
        .mode(mode)
        .timeLimit(paper.getDuration())
        .totalPausedSeconds(0)
        .answers(new HashMap<>())
        .questionVisitLog(new ArrayList<>())
        .deviceInfo(deviceContextExtractor.extract())
        .createdAt(Instant.now())
        .build();
    
    // 初始化题目访问日志
    for (ExamSection section : paper.getSections()) {
        for (ExamQuestion question : section.getQuestions()) {
            session.getQuestionVisitLog().add(
                QuestionVisit.builder()
                    .questionId(question.getId())
                    .visitCount(0)
                    .build()
            );
        }
    }
    
    examSessionRepository.save(session);
    
    // 扣减权益
    if (!membershipService.isActiveMember(userId)) {
        quotaService.consumeExamQuota(userId);
    }
    
    // 发送事件
    eventPublisher.publish(new ExamSessionCreatedEvent(session.getId(), userId, paperId));
    
    return ExamSessionDTO.from(session, paper);
}

#### 2.4.3 答案持久化策略

采用"客户端实时保存 + 服务端定期确认"的双重保障机制：

```typescript
// 客户端答题引擎核心逻辑 (ExamAnswerEngine)

class ExamAnswerEngine {
  private localAnswerCache: Map<string, UserAnswer> = new Map();
  private dirtyQuestions: Set<string> = new Set();
  private syncTimer?: number;
  private readonly SYNC_INTERVAL_MS = 10_000; // 10秒同步一次
  private remainingSeconds: number = 0;

  /** 用户选择答案 */
  async selectAnswer(questionId: string, answer: Partial<UserAnswer>): Promise<void> {
    // 1. 本地立即保存
    const existing = this.localAnswerCache.get(questionId) ?? this.createEmptyAnswer(questionId);
    const merged = { ...existing, ...answer, isModified: true, modifiedCount: existing.modifiedCount + 1 };
    this.localAnswerCache.set(questionId, merged);
    this.dirtyQuestions.add(questionId);

    // 2. 更新本地UI（无网络等待）
    this.notifyUI(merged);

    // 3. 标记为待同步（不立即发请求，减少网络开销）
    this.scheduleSync();
  }

  /** 定期同步脏数据到服务端 */
  private scheduleSync(): void {
    if (this.syncTimer) clearTimeout(this.syncTimer);
    this.syncTimer = window.setTimeout(() => this.flushDirtyAnswers(), this.SYNC_INTERVAL_MS);
  }

  /** 批量同步脏答案 */
  private async flushDirtyAnswers(): Promise<void> {
    if (this.dirtyQuestions.size === 0) return;

    const questionIds = [...this.dirtyQuestions];
    const answers = questionIds.map(qid => ({
      questionId: qid,
      ...this.localAnswerCache.get(qid)!
    }));

    try {
      // 批量保存接口
      const result = await examApi.batchSaveAnswers(this.sessionId, answers);
      
      // 同步成功，清除脏标记
      questionIds.forEach(qid => this.dirtyQuestions.delete(qid));
      
      // 校对服务端剩余时间
      if (result.remainingSeconds !== undefined) {
        this.adjustTimer(result.remainingSeconds);
      }
    } catch (error) {
      // 同步失败，保持脏标记，下次重试
      console.warn(`答案同步失败，将在下次同步重试: ${error}`);
      // 本地数据不丢失，可继续答题
    }
  }

  /** 标记疑难题 */
  async toggleMark(questionId: string): Promise<void> {
    const existing = this.localAnswerCache.get(questionId);
    if (existing) {
      existing.isMarked = !existing.isMarked;
      this.dirtyQuestions.add(questionId);
      this.scheduleSync();
    }
  }

  /** 提交试卷前强制刷出所有脏数据 */
  async forceFlush(): Promise<void> {
    if (this.syncTimer) clearTimeout(this.syncTimer);
    await this.flushDirtyAnswers();
  }

  /** 离线/断线恢复 */
  restoreFromLocal(): void {
    const cached = localStorage.getItem(`exam_${this.sessionId}`);
    if (cached) {
      const state = JSON.parse(cached);
      this.localAnswerCache = new Map(Object.entries(state.answers));
      this.remainingSeconds = state.remainingSeconds;
    }
  }
}

#### 2.4.4 计时器同步机制

为防止客户端时钟不准，采用"客户端倒计时 + 服务端校准"方案：

```java
// 服务端时间校准
public TimeCalibrationResult calibrateTime(String sessionId, int clientRemainingSeconds) {
    ExamSession session = examSessionRepository.findById(sessionId);
    
    if (session.getStatus() != ExamSessionStatus.IN_PROGRESS) {
        throw new ExamStateException("考试未在进行中");
    }
    
    // 服务端计算的真实剩余秒数
    long serverRemaining = Duration.between(
        Instant.now(),
        session.getStartedAt().plus(Duration.ofMinutes(session.getTimeLimit()))
    ).getSeconds();
    
    serverRemaining = Math.max(0, serverRemaining);
    
    // 漂移容忍阈值: 60秒
    long drift = Math.abs(serverRemaining - clientRemainingSeconds);
    if (drift > 60) {
        // 客户端时钟严重偏差，强制校准
        log.warn("考试计时器漂移超过阈值: sessionId={}, drift={}s", sessionId, drift);
        return TimeCalibrationResult.calibrate(serverRemaining);
    }
    
    return TimeCalibrationResult.ok(serverRemaining);
}

@Transactional
public ExamSubmissionResult submitExam(String sessionId, String userId, boolean force) {
    ExamSession session = examSessionRepository.findById(sessionId);
    
    // 1. 状态校验
    validateSessionForSubmission(session, userId);
    
    // 2. 未答题检查
    int unanswered = countUnansweredQuestions(session);
    if (unanswered > 0 && !force) {
        return ExamSubmissionResult.confirmNeeded(unanswered);
    }
    
    // 3. 锁定会话，防止继续修改
    session.setStatus(ExamSessionStatus.SUBMITTED);
    session.setSubmittedAt(Instant.now());
    examSessionRepository.save(session);
    
    // 4. 触发异步批阅
    gradingService.submitGradingTask(session);
    
    // 5. 预估批阅时间
    int estimatedSeconds = estimateGradingTime(session);
    
    return ExamSubmissionResult.submitted(estimatedSeconds);
}

private int estimateGradingTime(ExamSession session) {
    ExamPaper paper = examPaperService.getById(session.getPaperId());
    int subjectiveCount = countSubjectiveQuestions(paper);
    // 客观题: < 2s, 主观题: ~3s/题
    return 2 + subjectiveCount * 3;
}

```java
// ExamGradingService.java
@Slf4j
@Service
public class ExamGradingService {
    
    @Async("examGradingExecutor")
    public void gradeExamSession(String sessionId) {
        ExamSession session = examSessionRepository.findById(sessionId);
        ExamPaper paper = examPaperService.getById(session.getPaperId());
        
        try {
            session.setStatus(ExamSessionStatus.GRADING);
            examSessionRepository.save(session);
            
            List<QuestionResult> questionResults = new ArrayList<>();
            
            for (ExamSection section : paper.getSections()) {
                for (ExamQuestion question : section.getQuestions()) {
                    UserAnswer userAnswer = session.getAnswers().get(question.getId());
                    QuestionResult result;
                    
                    if (userAnswer == null || userAnswer.isEmpty()) {
                        // 未作答
                        result = QuestionResult.unanswered(question);
                    } else if (isObjectiveQuestion(question)) {
                        // 客观题: 精确匹配
                        result = gradeObjectiveQuestion(question, userAnswer);
                    } else {
                        // 主观题: AI批阅
                        result = gradeSubjectiveQuestion(question, userAnswer, session, paper);
                    }
                    
                    questionResults.add(result);
                }
            }
            
            // 汇总成绩
            ExamResult examResult = aggregateResults(questionResults, paper, session);
            
            // 知识点维度分析
            analyzeKnowledgePoints(examResult, questionResults, paper);
            
            // 能力维度分析
            analyzeAbilities(examResult, questionResults, paper);
            
            // 平台百分位
            calculatePercentile(examResult, paper);
            
            // 保存结果
            session.setResult(examResult);
            session.setStatus(ExamSessionStatus.GRADED);
            examSessionRepository.save(session);
            
            // 触发后续事件
            eventPublisher.publish(new ExamGradedEvent(sessionId, examResult));
            
        } catch (Exception e) {
            log.error("批阅失败: sessionId={}", sessionId, e);
            session.setStatus(ExamSessionStatus.SUBMITTED); // 回退状态
            examSessionRepository.save(session);
            // 发送告警
            alertService.sendGradingFailureAlert(sessionId, e.getMessage());
        }
    }
    
    /**
     * 客观题批阅: 选择题/判断题/填空题
     */
    private QuestionResult gradeObjectiveQuestion(ExamQuestion question, UserAnswer answer) {
        boolean isCorrect = false;
        int earnedScore = 0;
        
        switch (question.getQuestionType()) {
            case SINGLE_CHOICE:
            case MULTI_CHOICE:
                List<String> correctOptions = question.getOptions().stream()
                    .filter(QuestionOption::isCorrect)
                    .map(QuestionOption::getLabel)
                    .sorted().collect(toList());
                List<String> selectedOptions = answer.getSelectedOptions().stream()
                    .sorted().collect(toList());
                isCorrect = correctOptions.equals(selectedOptions);
                earnedScore = isCorrect ? question.getScore() : 0;
                break;
                
            case FILL_BLANK:
                List<String> acceptableAnswers = question.getStandardAnswer().getAcceptableAnswers();
                String filledText = answer.getFilledText().trim();
                isCorrect = acceptableAnswers.stream()
                    .anyMatch(a -> a.equalsIgnoreCase(filledText) || 
                              normalizeExpression(a).equals(normalizeExpression(filledText)));
                earnedScore = isCorrect ? question.getScore() : 0;
                break;
                
            case TRUE_FALSE:
                isCorrect = answer.getFilledText()
                    .equalsIgnoreCase(question.getStandardAnswer().getText());
                earnedScore = isCorrect ? question.getScore() : 0;
                break;
        }
        
        return QuestionResult.builder()
            .questionId(question.getId())
            .isCorrect(isCorrect)
            .isPartiallyCorrect(false)
            .earnedScore(earnedScore)
            .maxScore(question.getScore())
            .scorePercentage(earnedScore * 1.0 / question.getScore())
            .build();
    }
    
    /**
     * 主观题批阅: AI辅助评分
     */
    private QuestionResult gradeSubjectiveQuestion(
            ExamQuestion question, UserAnswer answer,
            ExamSession session, ExamPaper paper) {
        
        // 构建 AI 批阅 Prompt
        String gradingPrompt = buildGradingPrompt(question, answer, paper);
        
        // 调用 AI 模型
        AIGradingResponse aiResponse = aiGradingClient.grade(
            GradingRequest.builder()
                .prompt(gradingPrompt)
                .scoringRubric(question.getScoringRubric())
                .standardAnswer(question.getStandardAnswer())
                .userAnswer(answer.getEssayText())
                .maxScore(question.getScore())
                .grade(paper.getGrade())
                .subject(paper.getSubject())
                .build()
        );
        
        // 分步得分详情
        List<ScoringStepResult> stepResults = aiResponse.getSteps().stream()
            .map(step -> ScoringStepResult.builder()
                .description(step.getDescription())
                .earnedScore(step.getEarnedScore())
                .maxScore(step.getMaxScore())
                .matchedKeywords(step.getMatchedKeywords())
                .build())
            .collect(toList());
        
        int earnedScore = stepResults.stream()
            .mapToInt(ScoringStepResult::getEarnedScore).sum();
        
        return QuestionResult.builder()
            .questionId(question.getId())
            .isCorrect(earnedScore == question.getScore())
            .isPartiallyCorrect(earnedScore > 0 && earnedScore < question.getScore())
            .earnedScore(earnedScore)
            .maxScore(question.getScore())
            .scorePercentage(earnedScore * 1.0 / question.getScore())
            .gradingDetail(GradingDetail.builder()
                .steps(stepResults)
                .build())
            .aiFeedback(aiResponse.getOverallFeedback())
            .build();
    }
}

    private String classifyError(QuestionResult result, ExamQuestion question) {
        if (result.getEarnedScore() == 0) {
            // 完全错误: 进一步区分
            if (question.getQuestionType() == QuestionType.CALCULATION ||
                question.getQuestionType() == QuestionType.PROOF) {
                return "method_error";  // 方法错误
            }
            return "concept_error";     // 概念不清
        }
        return "partial_understanding"; // 部分理解
    }
}

```java
// IntelligentPaperComposer.java
public ExamPaper composePaper(ComposeRequest request, String userId) {
    // 1. 加载组卷规则模板
    PaperCompositionRule rule = compositionRuleRepository
        .findBySubjectAndExamLevel(request.getSubject(), request.getExamLevel())
        .orElseThrow(() -> new RuleNotFoundException(request.getSubject()));
    
    // 2. 获取用户画像
    UserLearningProfile profile = profileService.getProfile(userId);
    
    // 3. 确定知识点权重
    Map<String, Double> knowledgeWeights = calculateKnowledgeWeights(
        profile, request.isWeakPointPriority(), request.getSubject()
    );
    
    // 4. 按题型分区组卷
    List<ExamSection> sections = new ArrayList<>();
    for (StructureRule structureRule : rule.getStructureRules()) {
        ExamSection section = composeSection(
            structureRule, knowledgeWeights, rule.getDifficultyDistribution(),
            profile, request.getDifficulty()
        );
        sections.add(section);
    }
    
    // 5. 校验试卷质量
    validatePaper(sections, rule);
    
    // 6. 构建试卷对象
    ExamPaper paper = ExamPaper.builder()
        .id(idGenerator.nextId("paper"))
        .title(generateTitle(request))
        .paperType(PaperType.CUSTOM)
        .sourceType(SourceType.AI_GENERATED)
        .subject(request.getSubject())
        .grade(profile.getGrade())
        .duration(request.getDuration())
        .sections(sections)
        .status(PaperStatus.PUBLISHED)
        .createdAt(Instant.now())
        .build();
    
    // 计算总分
    paper.setTotalScore(sections.stream()
        .mapToInt(ExamSection::getTotalScore).sum());
    
    // 保存（临时试卷，仅对当前用户可见）
    paper.setOwnerUserId(userId);
    examPaperRepository.save(paper);
    
    return paper;
}

/**
 * 计算知识点权重
 */
private Map<String, Double> calculateKnowledgeWeights(
        UserLearningProfile profile, boolean weakPointPriority, String subject) {
    
    // 基础权重: 均匀分布
    List<String> allPoints = knowledgePointService.getBySubject(subject);
    Map<String, Double> weights = allPoints.stream()
        .collect(toMap(id -> id, id -> 1.0));
    
    if (weakPointPriority) {
        // 薄弱知识点加权
        List<KnowledgeMastery> weakPoints = profile.getMasteries().stream()
            .filter(m -> m.getSubject().equals(subject))
            .filter(m -> m.getMasteryLevel() < 0.6)
            .collect(toList());
        
        for (KnowledgeMastery weak : weakPoints) {
            // 掌握度越低，权重越高 (反比例)
            double boost = (1.0 - weak.getMasteryLevel()) * 3.0;
            weights.merge(weak.getKnowledgePointId(), boost, Double::sum);
        }
    }
    
    // 归一化
    double totalWeight = weights.values().stream().mapToDouble(d -> d).sum();
    return weights.entrySet().stream()
        .collect(toMap(Map.Entry::getKey, e -> e.getValue() / totalWeight));
}

/**
 * 单个分区组卷
 */
private ExamSection composeSection(
        StructureRule rule, Map<String, Double> knowledgeWeights,
        DifficultyDistribution difficultyDist, UserLearningProfile profile,
        Difficulty preferredDifficulty) {
    
    // 根据权重选择知识点
    List<String> selectedPoints = weightedSample(
        knowledgeWeights, rule.getQuestionCount()
    );
    
    // 确定难度分布
    Map<Difficulty, Integer> difficultyCounts = distributeDifficulty(
        rule.getQuestionCount(), difficultyDist, preferredDifficulty
    );
    
    // 从题库选题
    List<ExamQuestion> questions = new ArrayList<>();
    for (int i = 0; i < rule.getQuestionCount(); i++) {
        String kpId = selectedPoints.get(i);
        Difficulty difficulty = selectDifficulty(difficultyCounts, i);
        
        // 排除做过的题
        Set<String> excludedIds = getRecentlyDoneQuestions(profile.getUserId(), kpId);
        
        Question candidate = questionBankService.selectQuestion(
            kpId, rule.getQuestionType(), difficulty, excludedIds
        );
        
        questions.add(convertToExamQuestion(candidate, i + 1, rule.getScorePerQuestion()));
    }
    
    return ExamSection.builder()
        .id(idGenerator.nextId("sec"))
        .title(rule.getSectionTitle())
        .questionType(rule.getQuestionType())
        .questions(questions)
        .totalScore(rule.getQuestionCount() * rule.getScorePerQuestion())
        .build();
}

## 4. 异常场景与错误处理

### 4.1 答题过程异常

| 异常场景 | 处理策略 | 用户感知 |
|---------|---------|---------|
| 网络断开 | 本地缓存答案，恢复后批量同步 | 顶部显示"离线模式"提示，可继续答题 |
| APP崩溃 | localStorage + 服务端双重恢复 | 重新打开APP自动弹窗"恢复上次考试" |
| 服务端超时 | 客户端重试（指数退避，最多3次） | 底部Toast"保存中..." |
| 答案冲突 | 以客户端最新为准 | 无感知 |
| 并发操作 | 服务端乐观锁（版本号） | "操作过快，请稍后重试" |

### 4.2 交卷异常

| 异常场景 | 处理策略 |
|---------|---------|
| 交卷时网络断开 | 本地标记"待提交"，网络恢复后自动提交 |
| 批阅AI超时 | 客观题先出分，主观题标记"AI批阅中"，后台异步完成 |
| 批阅AI失败 | 默认给满分（有利于用户），人工复核队列介入 |
| 服务端判定超时 | 定时任务（每分钟）扫描超时会话，自动交卷 |

// ExamTimeoutScheduler.java
@Scheduled(fixedDelay = 60_000) // 每分钟执行
public void autoSubmitExpiredExams() {
    List<ExamSession> expiredSessions = examSessionRepository
        .findByStatusAndDeadlineBefore(ExamSessionStatus.IN_PROGRESS, Instant.now());
    
    for (ExamSession session : expiredSessions) {
        try {
            log.info("自动交卷: sessionId={}, userId={}", 
                session.getId(), session.getUserId());
            
            session.setStatus(ExamSessionStatus.SUBMITTED);
            session.setSubmittedAt(Instant.now());
            session.setAutoSubmitted(true);
            session.setSubmitReason("timeout");
            examSessionRepository.save(session);
            
            // 触发批阅
            gradingService.submitGradingTask(session);
            
            // 推送通知用户
            pushService.send(session.getUserId(), PushMessage.builder()
                .title("考试已结束")
                .body("你的模考已到时间，系统已自动交卷")
                .deepLink("primetop://exam/" + session.getPaperId() + 
                    "/report/" + session.getId())
                .category("exam_auto_submit")
                .build());
                
        } catch (Exception e) {
            log.error("自动交卷失败: sessionId={}", session.getId(), e);
        }
    }
}
