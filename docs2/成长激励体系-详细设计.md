# 成长激励体系 - 详细设计文档

> 细化日期：2026-08-18
> 原始文档：`docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` §6.8 学习规划、§12.5 运营迭代

## 1. 模块概述

### 1.1 功能定位

成长激励体系是 PrimeTop 的用户留存和习惯养成核心模块，通过学习成就、连续打卡、阶段挑战、等级晋升、徽章收集等机制，帮助学生建立持续学习的良好习惯，增强学习成就感和趣味性。

### 1.2 覆盖学段

全学段（幼儿至高中），但激励形式和内容需要分龄适配。

### 1.3 优先级

P1（首个正式版本应具备）。

### 1.4 核心价值

1. **习惯养成**：通过连续打卡机制培养学生每日学习的习惯
2. **成就激励**：通过成就徽章和等级晋升增强学习成就感
3. **目标导向**：通过阶段挑战将大目标拆解为小任务，逐步完成
4. **趣味化学习**：通过游戏化元素提升学习趣味性和参与度
5. **社交激励**：通过排行榜和同伴对比激发学习动力（P2）

## 2. 激励机制总览

### 2.1 核心激励机制

| 机制 | 说明 | 覆盖学段 | 优先级 |
| --- | --- | --- | --- |
| 每日打卡 | 连续打卡记录，中断后重新计数 | 全学段 | P1 |
| 学习时长 | 累计学习时长，记录里程碑 | 全学段 | P1 |
| 成就徽章 | 达成特定条件获得徽章展示 | 全学段 | P1 |
| 等级晋升 | 根据经验值提升等级，解锁权益 | 全学段 | P1 |
| 阶段挑战 | 7天/21天/30天挑战任务 | 小学至高中 | P1 |
| 连续学习 | 每周/每月连续学习天数统计 | 全学段 | P1 |
| 知识点掌握度 | 完成知识点学习并达到掌握标准 | 全学段 | P2 |
| 学科成就 | 各学科独立成就和徽章 | 小学至高中 | P2 |
| 排行榜 | 班级/年级/全榜排名 | 初中至高中 | P2 |
| 挑战赛 | 学习速度/正确率等竞技活动 | 小学至高中 | P3 |

### 2.2 分龄适配策略

| 学段 | 激励重点 | 徽章风格 | 等级命名 |
| --- | --- | --- | --- |
| 幼儿 | 连续打卡、趣味激励、家长鼓励 | 可爱卡通、鲜艳色彩 | 小树苗、小芽、小叶子 |
| 小学 | 连续打卡、阶段挑战、基础成就 | 青春活力、明亮色系 | 小学生、学习小能手、学霸 |
| 初中 | 连续学习、阶段挑战、学科成就 | 简约清晰、中性色系 | 初中生、学习达人、学霸 |
| 高中 | 知识点掌握、学科成就、备考成就 | 专业简洁、深色系 | 高中生、学习高手、学神 |

## 3. 数据结构设计

### 3.1 学生成就记录表 `student_achievements`

```sql
CREATE TABLE student_achievements (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id          BIGINT NOT NULL COMMENT '学生用户ID',
    achievement_id      VARCHAR(50) NOT NULL COMMENT '成就ID',
    achievement_type    VARCHAR(20) NOT NULL COMMENT '成就类型: checkin/streak/challenge/subject/master/time/level',
    achievement_name    VARCHAR(100) NOT NULL COMMENT '成就名称',
    achievement_desc    VARCHAR(255) COMMENT '成就描述',
    achievement_level   VARCHAR(20) COMMENT '成就等级: bronze/silver/gold/platinum',
    icon_url            VARCHAR(512) COMMENT '成就图标URL',
    badge_url           VARCHAR(512) COMMENT '徽章图片URL',
    progress_value      INT DEFAULT 0 COMMENT '当前进度值',
    target_value        INT NOT NULL COMMENT '目标值',
    is_unlocked         TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否已解锁',
    unlocked_at         DATETIME COMMENT '解锁时间',
    progress_updated_at DATETIME COMMENT '进度最后更新时间',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_student_achievement (student_id, achievement_id),
    INDEX idx_student_type (student_id, achievement_type),
    INDEX idx_unlocked (is_unlocked, unlocked_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生成就记录表';
```

## 4. API 接口设计

### 4.1 每日打卡接口

#### 4.1.1 执行每日打卡

```
POST /api/v1/achievement/checkin
```

**请求体：**
```json
{
  "studyDuration": 15
}
```

**响应体：**
```json
{
  "code": 0,
  "data": {
    "checkinDate": "2026-08-18",
    "checkinTime": "20:30:00",
    "studyDuration": 15,
    "streakCount": 7,
    "expGained": 10,
    "achievementsUnlocked": [
      {
        "achievementId": "checkin_7_days",
        "achievementName": "连续打卡7天",
        "badgeUrl": "https://cdn.example.com/badges/checkin_7_days.png"
      }
    ],
    "nextMilestone": {
      "days": 10,
      "achievementName": "连续打卡10天"
    }
  }
}
```

**逻辑说明：**
- 每天只能打卡一次，重复打卡返回已打卡状态
- 连续打卡天数中断后从1重新开始计算
- 打卡后检查是否触发成就解锁
- 自动增加经验值，检查是否升级
- 幼儿端打卡可由家长代为完成（家长中心入口）

class DailyCheckinService:
    """每日打卡服务"""
    
    def __init__(
        self,
        checkin_repo: DailyCheckinRepository,
        achievement_service: AchievementService,
        level_service: LevelService,
        challenge_service: ChallengeService,
        exp_service: ExpService,
    ):
        self.checkin_repo = checkin_repo
        self.achievement_service = achievement_service
        self.level_service = level_service
        self.challenge_service = challenge_service
        self.exp_service = exp_service
    
    async def checkin(self, student_id: int, study_duration: int = 0) -> CheckinResult:
        """
        执行每日打卡
        
        Args:
            student_id: 学生用户ID
            study_duration: 当日学习时长（分钟）
        
        Returns:
            CheckinResult: 打卡结果
        """
        today = date.today()
        
        # 1. 检查今日是否已打卡
        existing = await self.checkin_repo.get_by_date(student_id, today)
        if existing:
            return CheckinResult(
                success=False,
                already_checked_in=True,
                checkin_date=existing.checkin_date,
                streak_count=existing.streak_count
            )
        
        # 2. 计算连续打卡天数
        yesterday = today - timedelta(days=1)
        yesterday_record = await self.checkin_repo.get_by_date(student_id, yesterday)
        
        if yesterday_record:
            streak_count = yesterday_record.streak_count + 1
        else:
            streak_count = 1
        
        # 3. 记录打卡
        checkin_record = DailyCheckinRecord(
            student_id=student_id,
            checkin_date=today,
            study_duration=study_duration,
            checkin_time=datetime.now().time(),
            streak_count=streak_count
        )
        
        await self.checkin_repo.save(checkin_record)
        
        # 4. 计算经验值（基础10 + 时长加成）
        exp_gained = await self._calc_checkin_exp(study_duration, streak_count)
        
        # 5. 增加经验值
        level_result = await self.exp_service.add_exp(
            student_id=student_id,
            exp_value=exp_gained,
            exp_type="checkin",
            exp_source="daily_checkin"
        )
        
        # 6. 检查并解锁成就
        unlocked_achievements = await self.achievement_service.check_and_unlock_achievements(
            student_id=student_id,
            trigger_type="checkin",
            trigger_data={
                "streak_count": streak_count,
                "total_checkins": await self.checkin_repo.get_total_count(student_id)
            }
        )
        
        # 7. 更新阶段挑战进度
        await self.challenge_service.update_progress(
            student_id=student_id,
            challenge_type="days",
            progress_delta=1
        )
        
        # 8. 查询下一个里程碑
        next_milestone = await self._get_next_milestone(streak_count)
        
        return CheckinResult(
            success=True,
            checkin_date=today,
            checkin_time=checkin_record.checkin_time,
            study_duration=study_duration,
            streak_count=streak_count,
            exp_gained=exp_gained,
            level_result=level_result,
            achievements_unlocked=unlocked_achievements,
            next_milestone=next_milestone
        )
    
    async def _calc_checkin_exp(self, study_duration: int, streak_count: int) -> int:
        """计算打卡经验值"""
        # 基础经验值
        exp = 10
        
        # 周末双倍
        if datetime.now().weekday() >= 5:  # 周六、周日
            exp *= 2
        
        # 连续打卡奖励
        if streak_count >= 7:
            exp += 10
        elif streak_count >= 3:
            exp += 5
        
        # 学习时长奖励
        if study_duration > 0:
            exp += min(study_duration, 10)  # 最多加10分钟的经验
        
        return exp
    
    async def _get_next_milestone(self, current_streak: int) -> Optional[Dict]:
        """获取下一个打卡里程碑"""
        milestones = [3, 7, 14, 30, 60, 100, 365]
        for milestone in milestones:
            if current_streak < milestone:
                achievement = await self.achievement_service.get_by_condition(
                    achievement_type="checkin_days",
                    target_value=milestone
                )
                if achievement:
                    return {
                        "days": milestone,
                        "progress": current_streak,
                        "achievement_name": achievement.achievement_name
                    }
        return None

class AchievementService:
    """成就服务"""
    
    def __init__(
        self,
        achievement_repo: AchievementRepository,
        badge_wall_service: BadgeWallService,
        notification_service: NotificationService,
    ):
        self.achievement_repo = achievement_repo
        self.badge_wall_service = badge_wall_service
        self.notification_service = notification_service
    
    async def check_and_unlock_achievements(
        self,
        student_id: int,
        trigger_type: str,
        trigger_data: Dict
    ) -> List[Achievement]:
        """
        检查并解锁成就
        
        Args:
            student_id: 学生用户ID
            trigger_type: 触发类型
            trigger_data: 触发数据
        
        Returns:
            List[Achievement]: 新解锁的成就列表
        """
        # 1. 查询该学生所有进行中的成就
        in_progress = await self.achievement_repo.get_in_progress_by_student(student_id)
        
        unlocked_achievements = []
        
        for achievement_progress in in_progress:
            # 2. 检查每个成就的解锁条件
            should_unlock = await self._check_unlock_condition(
                achievement=achievement_progress,
                trigger_type=trigger_type,
                trigger_data=trigger_data
            )
            
            if should_unlock:
                # 3. 更新成就进度
                await self._update_progress(
                    achievement_progress,
                    trigger_data
                )
                
                # 4. 检查是否达到目标值
                if achievement_progress.progress_value >= achievement_progress.target_value:
                    unlocked = await self._unlock_achievement(achievement_progress)
                    if unlocked:
                        unlocked_achievements.append(unlocked)
        
        return unlocked_achievements
    
    async def _check_unlock_condition(
        self,
        achievement: StudentAchievement,
        trigger_type: str,
        trigger_data: Dict
    ) -> bool:
        """检查成就解锁条件"""
        condition = achievement.unlock_condition
        condition_type = condition.get("type")
        
        if condition_type == "checkin_days":
            # 打卡天数类成就
            return trigger_type == "checkin" and "streak_count" in trigger_data
        
        elif condition_type == "study_duration":
            # 学习时长类成就
            return trigger_type == "study" and "duration_minutes" in trigger_data
        
        elif condition_type == "questions_correct":
            # 答题正确类成就
            return trigger_type == "question" and trigger_data.get("is_correct", False)
        
        elif condition_type == "challenge_completion":
            # 挑战完成类成就
            return trigger_type == "challenge" and "challenge_id" in trigger_data
        
        return False
    
    async def _update_progress(
        self,
        achievement: StudentAchievement,
        trigger_data: Dict
    ) -> None:
        """更新成就进度"""
        condition = achievement.unlock_condition
        condition_type = condition.get("type")
        
        if condition_type == "checkin_days":
            if "streak_count" in trigger_data:
                achievement.progress_value = max(
                    achievement.progress_value,
                    trigger_data["streak_count"]
                )
        
        elif condition_type == "study_duration":
            if "duration_minutes" in trigger_data:
                achievement.progress_value = trigger_data.get("total_duration", 0) + trigger_data["duration_minutes"]
        
        elif condition_type == "questions_correct":
            if trigger_data.get("is_correct", False):
                achievement.progress_value += 1
        
        achievement.progress_updated_at = datetime.now()
        await self.achievement_repo.save(achievement)
    
    async def _unlock_achievement(self, achievement: StudentAchievement) -> Optional[Achievement]:
        """解锁成就"""
        if achievement.is_unlocked:
            return None
        
        # 1. 标记已解锁
        achievement.is_unlocked = True
        achievement.unlocked_at = datetime.now()
        await self.achievement_repo.save(achievement)
        
        # 2. 加入徽章收集墙
        await self.badge_wall_service.add_badge(
            student_id=achievement.student_id,
            achievement_id=achievement.achievement_id,
            badge_url=achievement.badge_url
        )
        
        # 3. 发放奖励
        reward = achievement.reward_config
        if reward:
            await self._grant_reward(
                student_id=achievement.student_id,
                reward=reward
            )
        
        # 4. 推送通知
        await self.notification_service.push(
            user_id=achievement.student_id,
            title="恭喜解锁新成就！",
            body=f"你获得了「{achievement.achievement_name}」成就徽章",
            data={
                "type": "achievement_unlocked",
                "achievement_id": achievement.achievement_id

class LevelService:
    """等级服务"""
    
    def __init__(
        self,
        student_level_repo: StudentLevelRepository,
        level_definition_repo: LevelDefinitionRepository,
        notification_service: NotificationService,
    ):
        self.student_level_repo = student_level_repo
        self.level_definition_repo = level_definition_repo
        self.notification_service = notification_service
    
    async def check_and_promote(
        self,
        student_id: int,
        exp_gained: int
    ) -> Optional[LevelResult]:
        """
        检查并执行升级
        
        Args:
            student_id: 学生用户ID
            exp_gained: 获得的经验值
        
        Returns:
            LevelResult: 升级结果
        """
        # 1. 获取当前等级信息
        student_level = await self.student_level_repo.get_by_student_id(student_id)
        if student_level is None:
            student_level = await self._init_student_level(student_id)
        
        # 2. 增加经验值
        before_exp = student_level.current_exp
        student_level.current_exp += exp_gained
        student_level.total_exp += exp_gained
        
        # 3. 检查是否可以升级
        promoted = False
        promotions = []
        
        while student_level.current_exp >= student_level.level_exp_needed:
            # 执行升级
            next_level = await self._promote(student_level)
            promotions.append(next_level)
            promoted = True
            
            # 检查是否可以连续升级
            if student_level.current_exp < student_level.level_exp_needed:
                break
        
        # 4. 保存更新
        await self.student_level_repo.save(student_level)
        
        if promoted:
            # 5. 推送升级通知
            await self._send_promotion_notifications(student_id, promotions)
        
        return LevelResult(
            promoted=promoted,
            promotions=promotions,
            current_level=student_level.current_level,
            current_exp=student_level.current_exp,
            total_exp=student_level.total_exp
        )
    
    async def _init_student_level(self, student_id: int) -> StudentLevel:
        """初始化学生等级"""
        level_1_def = await self.level_definition_repo.get_by_level(1)
        
        student_level = StudentLevel(
            student_id=student_id,
            current_level=1,
            current_exp=0,
            level_exp_needed=level_1_def.exp_required,
            total_exp=0,
            level_name=level_1_def.level_name,
            unlocked_privileges=level_1_def.privileges,
            promoted_at=datetime.now()
        )
        
        await self.student_level_repo.save(student_level)
        return student_level
    
    async def _promote(self, student_level: StudentLevel) -> Dict:
        """执行升级"""
        current_level = student_level.current_level
        exp_needed = student_level.level_exp_needed
        
        # 1. 扣除升级所需经验值
        student_level.current_exp -= exp_needed
        
        # 2. 等级+1
        student_level.current_level += 1
        
        # 3. 获取新等级配置
        new_level_def = await self.level_definition_repo.get_by_level(student_level.current_level)
        
        # 4. 更新等级信息
        student_level.level_name = new_level_def.level_name
        student_level.level_exp_needed = new_level_def.exp_required
        student_level.unlocked_privileges = new_level_def.privileges
        student_level.promoted_at = datetime.now()
        
        return {
            "from_level": current_level,
            "to_level": student_level.current_level,
            "level_name": new_level_def.level_name,
            "exp_required": exp_needed,
            "privileges": new_level_def.privileges
        }
    
    async def _send_promotion_notifications(
        self,
        student_id: int,
        promotions: List[Dict]
    ) -> None:
        """发送升级通知"""
        for promotion in promotions:
            from_level = promotion["from_level"]
            to_level = promotion["to_level"]
            level_name = promotion["level_name"]
            
            await self.notification_service.push(
                user_id=student_id,
                title="恭喜升级！",
                body=f"你从Lv.{from_level}升级到了Lv.{to_level}「{level_name}」",
                data={
                    "type": "level_promoted",
                    "from_level": from_level,
                    "to_level": to_level
                }
            )

class ChallengeService:
    """阶段挑战服务"""
    
    def __init__(
        self,
        challenge_repo: ChallengeRepository,
        challenge_def_repo: ChallengeDefinitionRepository,
        exp_service: ExpService,
        notification_service: NotificationService,
    ):
        self.challenge_repo = challenge_repo
        self.challenge_def_repo = challenge_def_repo
        self.exp_service = exp_service
        self.notification_service = notification_service
    
    async def join_challenge(
        self,
        student_id: int,
        challenge_id: str
    ) -> ChallengeRecord:
        """参与挑战"""
        # 1. 检查是否有进行中的挑战
        active = await self.challenge_repo.get_active_by_student(student_id)
        if active:
            raise ChallengeConflictError("已有进行中的挑战，请先完成")
        
        # 2. 获取挑战配置
        challenge_def = await self.challenge_def_repo.get_by_id(challenge_id)
        if not challenge_def or not challenge_def.is_active:
            raise ChallengeNotFoundError("挑战不存在或已关闭")
        
        # 3. 检查学段匹配
        if challenge_def.stage_filter:
            student_profile = await self._get_student_profile(student_id)
            if student_profile.stage not in challenge_def.stage_filter:
                raise ChallengeNotEligibleError("该挑战不适合当前学段")
        
        # 4. 创建挑战记录
        today = date.today()
        end_date = today + timedelta(days=challenge_def.duration_days)
        
        challenge_record = ChallengeRecord(
            student_id=student_id,
            challenge_id=challenge_id,
            challenge_name=challenge_def.name,
            challenge_type=challenge_def.type,
            start_date=today,
            end_date=end_date,
            target_value=challenge_def.target_value,
            current_value=0,
            progress_pct=0.0,
            status="in_progress"
        )
        
        return await self.challenge_repo.save(challenge_record)
    
    async def update_progress(
        self,
        student_id: int,
        challenge_type: str,
        progress_delta: int = 1
    ) -> List[ChallengeRecord]:
        """更新挑战进度"""
        # 1. 查询进行中的挑战
        active_challenges = await self.challenge_repo.get_active_by_student(student_id)
        
        updated = []
        
        for challenge in active_challenges:
            # 2. 匹配挑战类型
            if challenge.challenge_type != challenge_type:
                continue
            
            # 3. 更新进度
            old_value = challenge.current_value
            challenge.current_value += progress_delta
            challenge.progress_pct = (challenge.current_value / challenge.target_value) * 100
            challenge.updated_at = datetime.now()
            
            await self.challenge_repo.save(challenge)
            
            # 4. 检查是否完成挑战
            if challenge.current_value >= challenge.target_value:
                completed = await self._complete_challenge(challenge)
                if completed:
                    updated.append(completed)
            else:
                updated.append(challenge)
        
        return updated
    
    async def _complete_challenge(self, challenge: ChallengeRecord) -> ChallengeRecord:
        """完成挑战"""
        # 1. 更新状态
        challenge.status = "completed"
        challenge.completed_at = datetime.now()
        await self.challenge_repo.save(challenge)
        
        # 2. 获取挑战配置
        challenge_def = await self.challenge_def_repo.get_by_id(challenge.challenge_id)
        
        # 3. 发放奖励
        if challenge_def and challenge_def.reward_config:
            await self._grant_challenge_reward(
                student_id=challenge.student_id,
                reward=challenge_def.reward_config
            )
        
        # 4. 推送完成通知
        await self.notification_service.push(
            user_id=challenge.student_id,
            title="挑战完成！",
            body=f"恭喜你完成了「{challenge.challenge_name}」挑战！",
            data={
                "type": "challenge_completed",
                "challenge_record_id": challenge.id
            }
        )
        
        return challenge
    
    async def _grant_challenge_reward(self, student_id: int, reward: Dict) -> None:
        """发放挑战奖励"""
        exp = reward.get("exp", 0)
        if exp > 0:
            await self.exp_service.add_exp(
                student_id=student_id,
                exp_value=exp,
                exp_type="challenge",
                exp_source=reward.get("badge", "")
            )

### 9.1 错误码定义

| 错误码 | HTTP状态 | 说明 | 处理建议 |
| --- | --- | --- | --- |
| `ALREADY_CHECKED_IN` | 200 | 今日已打卡 | 返回已打卡状态 |
| `CHALLENGE_NOT_FOUND` | 404 | 挑战不存在 | 提示挑战不存在或已关闭 |
| `CHALLENGE_NOT_ELIGIBLE` | 403 | 不符合参与条件 | 提示学段/学科不匹配 |
| `CHALLENGE_CONFLICT` | 409 | 已有进行中的挑战 | 提示先完成当前挑战 |
| `ACHIEVEMENT_NOT_FOUND` | 404 | 成就不存在 | 返回默认成就列表 |
| `LEVEL_MAX_REACHED` | 200 | 已达到最高等级 | 继续累计经验值但不升级 |
| `REWARD_ALREADY_CLAIMED` | 200 | 奖励已领取 | 提示奖励已领取 |
| `CHALLENGE_EXPIRED` | 410 | 挑战已过期 | 提示挑战已过期 |
| `STREAK_BROKEN` | 200 | 连续打卡中断 | 友好提示，鼓励继续打卡 |

### 9.2 降级策略

| 场景 | 策略 |
| --- | --- |
| 成就检查服务超时 | 记录触发事件，异步补查，不影响用户操作 |
| 等级计算服务异常 | 继续记录经验值，延迟等级计算，稍后补偿 |
| 挑战进度更新失败 | 记录原始事件，队列重试，最多3次 |
| 徽章收集墙异常 | 徽章正常解锁，收集墙异步补充 |
| 通知推送失败 | 记录到推送队列表，定时补偿 |

4. 多个成就同时解锁
5. 经验值巨大时的处理

## 18. 验收标准

1. 每日打卡功能正常运行，支持中断和重新开始
2. 成就系统能正确检测和解锁各类成就
3. 等级系统能正确计算和执行升级
4. 挑战系统能正确跟踪进度和发放奖励
5. 徽章收集墙能正确展示和管理徽章
6. 经验值规则正确执行，无重复或遗漏
7. 分龄适配正确，不同学段显示不同内容
8. 家长可以查看孩子的成就和打卡情况
9. 系统性能满足要求，响应时间在可接受范围内
10. 异常情况有合理的降级和补偿机制
