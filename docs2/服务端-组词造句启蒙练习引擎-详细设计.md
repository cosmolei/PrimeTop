# 服务端-组词造句启蒙练习引擎 详细设计

> 对应原始设计文档：6.5 拼音识字启蒙模块（6.5.1 功能目标中明确包含"组词、造句"启蒙服务）。
> 现有《拼音识字启蒙-详细设计》仅将"组词、造句"列为汉字识记的附属项，未给出独立的练习生成、评估与复习闭环设计，本文档补齐该细化空白。

## 1. 模块概述

### 1.1 功能定位

组词造句是从"识字"走向"用语言"的关键过渡能力，面向幼儿大班至小学三年级学生（可延伸至四年级）。本引擎提供 **认字 → 组词 → 造句 → 扩句润色** 的渐进式练习闭环，核心目标：

1. **生字组词**：针对学生当前识字库中的生字，生成/检索合适的组词练习（看字组词、选词填空）。
2. **词语造句**：基于学生已掌握的词语，生成情境化造句练习（看词造句、选句匹配、连词成句）。
3. **句子评估**：对学生输入的句子进行语法正确性、语义合理性、用词准确性评估，给出适龄化反馈。
4. **扩句缩句训练**：在低阶造句基础上训练句子扩展（加修饰语）与压缩（提取主干）。
5. **复习闭环**：接入间隔重复调度，与识字掌握度、错题本、成长激励体系联动。

### 1.2 适用学段与练习梯度

| 阶段 | 目标学段 | 核心练习类型 | 句子长度基准 |
| --- | --- | --- | --- |
| L1 萌芽 | 幼儿大班 ~ 一年级 | 看字选词、词语跟读、图片选词 | 2~4 字词语 |
| L2 起步 | 一年级 ~ 二年级 | 看字组词、选词填空、模板造句 | 4~8 字句子 |
| L3 进阶 | 二年级 ~ 三年级 | 看词造句、连词成句、扩句 | 8~15 字句子 |
| L4 提升 | 三年级 ~ 四年级 | 情境造句、缩句、病句修改启蒙 | 15~30 字句子 |

### 1.3 设计原则

- **词汇先于句子**：只有词语掌握度达到阈值（≥0.6）的词语才进入造句练习，避免"不会词硬造句"。
- **模板优先，AI 兜底**：组词/造句题的 80% 以上来自结构化词库与句式模板（零成本、低延迟、可控），AI 仅用于动态扩库、情境题生成与句子评估。
- **鼓励式反馈**：评估反馈先肯定后建议，禁止出现"错误""不对"等否定式措辞，符合低龄用户心理。
- **安全前置**：所有 AI 生成内容（题目与参考答案）必须经内容安全审核后方可入库/下发。

## 3. 核心数据结构

### 3.1 练习类型枚举

```typescript
/** 练习大类 */
enum ExerciseCategory {
  WORD_GROUPING = 'word_grouping',   // 组词练习
  SENTENCE_MAKING = 'sentence_making', // 造句练习
}

/** 组词练习子类型 */
enum GroupingSubType {
  PICK_WORD = 'pick_word',           // 看字选词：从 4 个词中选出含该生字的词
  TYPE_WORD = 'type_word',           // 看字组词：手动输入一个含该生字的词
  FILL_WORD = 'fill_word',           // 选词填空：在句子空格中选合适词语
}

/** 造句练习子类型 */
enum SentenceSubType {
  TEMPLATE_MAKING = 'template_making', // 模板造句：按"谁+在哪+干什么"句式填空
  FREE_MAKING = 'free_making',       // 看词造句：自由输入一句话
  ARRANGE_WORDS = 'arrange_words',   // 连词成句：拖拽字词排序成句
  EXPAND = 'expand',                 // 扩句：给句子加修饰语
  SHRINK = 'shrink',                 // 缩句：提取句子主干
}

/** 练习难度等级（与 1.2 梯度对应） */
enum SentenceLevel {
  L1 = 1, L2 = 2, L3 = 3, L4 = 4,
}

/** 评估结论 */
enum EvalVerdict {
  EXCELLENT = 'excellent',  // 优秀：语义通顺、用词准确
  GOOD = 'good',            // 良好：基本正确，有轻微瑕疵
  NEED_HINT = 'need_hint',  // 需提示：有明显错误，给出引导式提示
}
```

### 3.2 词语知识库（Word Bank）

```typescript
/**
 * 词语条目：组词造句练习的内容基础。
 * 数据来源：教研批量导入（主）+ AI 扩库 + 内容审核后入库。
 */
interface WordEntry {
  id: string;                    // 词语全局唯一 ID（WL 前缀 + 雪花 ID）
  word: string;                  // 词语文本，如 "苹果"
  pinyin: string;                // 带声调拼音："píng guǒ"
  chars: string[];               // 单字拆分：["苹", "果"]
  gradeBand: string;             // 适用学段："G1" | "G2" | "G3" | "PRE"（幼儿）
  difficulty: number;            // 难度分 1~10
  wordType: WordType;            // 词语类别
  sourceCharIds: string[];       // 来源生字 ID（组词练习的锚点）
  exampleSentence: string;       // 标准例句（教研审核）
  exampleSentenceAudio: string;  // 例句音频 OSS 地址
  semanticTags: string[];        // 语义标签：["水果", "食物", "红色"]
  scenarioTags: string[];        // 情境标签：["超市", "家庭", "校园"]
  status: WordStatus;            // 入库状态
  safetyChecked: boolean;        // 是否已过内容安全审核
  version: number;               // 乐观锁版本号
  createdAt: string;             // ISO8601
  updatedAt: string;
}

enum WordType {
  NOUN = 'noun',
  VERB = 'verb',
  ADJ = 'adj',
  QUANTIFIER = 'quantifier',
  IDIOM = 'idiom',              // 扩展：成语（仅 L4）
  OTHER = 'other',
}

enum WordStatus {
  DRAFT = 'draft',
  PUBLISHED = 'published',
  OFFLINE = 'offline',
}
```

### 3.3 句式模板库（Pattern Bank）

```typescript
/**
 * 句式模板：低龄造句练习的脚手架。
 * 占位符语法：{who} {where} {verb} {word} 等槽位。
 */
interface SentencePattern {
  id: string;
  level: SentenceLevel;          // 适用等级
  category: SentenceSubType;
  /** 模板槽位序列，如 ["{who}", "在", "{where}", "{verb}", "{word}", "。"] */
  slots: PatternSlot[];
  sampleFilled: string;          // 填充实例："妈妈在厨房削苹果。"
  hintText: string;              // 引导语："想一想，谁在哪里做什么？"
  status: WordStatus;
}

interface PatternSlot {
  key: string;                   // "who" | "where" | "verb" | "word" | "fixed"
  fixedText?: string;            // key=fixed 时的固定文本
  /** 槽位候选词约束，空表示自由发挥 */
  constraint?: {
    wordTypes?: WordType[];      // 约束词性
    semanticTags?: string[];     // 约束语义标签
    gradeBandMax?: string;       // 不超出的最高学段
  };
}
```

interface ExerciseTask {
  taskId: string;                // 任务 ID
  studentId: string;
  category: ExerciseCategory;
  subType: GroupingSubType | SentenceSubType;
  level: SentenceLevel;
  anchorCharId?: string;         // 组词练习锚定生字
  targetWordId?: string;         // 造句练习目标词语
  patternId?: string;            // 模板造句使用的模板
  /** 题目内容（按子类型序列化不同结构） */

  referenceAnswer: string;       // 参考答案/标准例句
  distractors: string[];         // 干扰项（选择题）
  source: 'template' | 'bank' | 'ai';  // 题目来源
  aiGenerated: boolean;          // 是否 AI 生成（影响审核链路与打点）
  safetyChecked: boolean;
  sessionId: string;             // 所属练习会话
  createdAt: string;
}

interface Pick4Payload {          // 看字选词
  type: 'pick_word';
  promptChar: string;            // "苹"
  options: string[];             // ["苹果", "平安", "评价", "秤杆"]
  audio: string;                 // 题目朗读音频
}

interface TypeWordPayload {       // 看字组词/看词造句（输入型）
  type: 'type_word' | 'free_making';
  promptChar?: string;
  promptWord?: string;
  hint?: string;                 // 引导提示
  minLength: number;             // 最少字数
  maxLength: number;
}

interface ArrangePayload {        // 连词成句
  type: 'arrange_words';
  tokens: string[];              // 打乱的字/词块：["苹果", "吃", "我", "一个"]
  punctuation: string[];         // 可用标点：["。", "！"]
}

interface ExpandPayload {         // 扩句/缩句
  type: 'expand' | 'shrink';
  baseSentence: string;          // 基础句："小鸟飞。"
  requirement: string;           // 任务要求："加上在哪里、怎样地飞"
}

/** 一次答题记录（评估的输入与画像的数据源） */
interface AnswerRecord {
  recordId: string;
  taskId: string;
  studentId: string;
  sessionId: string;
  submittedAnswer: string;       // 学生提交的原文
  /** 客观题判定（选择题/排序题由规则直接判定） */
  objectiveCorrect: boolean | null;
  /** 主观评估结果（输入型/扩缩句由评估管线产出） */
  subjectiveEval?: SentenceEvaluation;
  timeSpentMs: number;           // 作答耗时
  hintUsed: number;              // 使用提示次数
  attemptCount: number;          // 第几次作答（允许重试）
  completedAt: string;
}

/** 句子多维评估结果 */
interface SentenceEvaluation {
  verdict: EvalVerdict;
  overallScore: number;          // 0~100
  dimensions: {
    grammaticality: DimensionScore;  // 语法正确性
    semanticFit: DimensionScore;     // 语义合理性（是否用对词）
    completeness: DimensionScore;    // 完整性（成分齐全）
    richness: DimensionScore;        // 丰富性（L3+ 才计分）
  };
  errorPoints: SentenceErrorPoint[];
  encouragement: string;         // 鼓励语（先肯定）
  suggestion: string;            // 引导式建议（不直接给改后句，除非 2 次失败）
  correctedSentence?: string;    // need_hint 且 attempt≥2 时给出参考改写
}

interface DimensionScore {
  score: number;                 // 0~100
  reason: string;
}

interface SentenceErrorPoint {
  type: ErrorPointType;
  span?: [number, number];       // 错误文本位置

  MISSING_COMPONENT = 'missing_component', // 成分残缺

  WORD_ORDER = 'word_order',             // 语序不当
  PUNCTUATION = 'punctuation',           // 标点问题
  IRRELEVANT = 'irrelevant',             // 与目标词语无关
  TOO_SHORT = 'too_short',
  OVER_LENGTH = 'over_length',
  SAFETY_RISK = 'safety_risk',           // 内容安全风险（单独拦截通道）
}

## 4. 功能设计

### 4.1 组词练习（WordGroupingService）

**出题流程**：

1. 从学生识字库中筛选 `status=已学` 且存在 `sourceCharIds` 关联词语的生字，排除 7 天内已练过的组合。
2. 按掌握度升序排序（优先练习薄弱生字），取 Top N 生成任务队列。
3. 对每个生字，按学段选择子类型：L1 只用 `pick_word`；L2 起混入 `type_word`；L3 起混入 `fill_word`。
4. 选项/干扰项从词库检索：同字数、同首字或形近字词语，AI 扩库时补充的干扰项必须已过审核。

**看字组词（type_word）判定**：

- 正向判定：提交词存在于词库且 `chars` 包含目标字 → 正确。
- 词库未收录但可能正确（如"苹"→"苹藻"超出小学生范围）：走 AI 评估管线确认合法性，确认通过则自动反哺词库（进入 `draft` 待审核）。
- 同音字替代（"平果"）：判定错误，但反馈中引导："是这个字哦，再想想『苹』可以组什么词？"

### 4.2 造句练习（SentenceMakingService）

**出题流程**：

1. 词语准入：学生词语掌握度 ≥ 0.6 且状态为 `published` 的词语进入造句候选池。
2. 子类型选择：按学生等级取对应子类型权重（L2：template_making 70% / free_making 30%；L3：arrange_words 30% / free_making 40% / expand 30%）。
3. 模板造句：从句式模板库抽取模板，各槽位按 constraint 从词库填充候选，保证所选词学生均已掌握。
4. 情境造句（AI）：`source=ai` 时调用 AI 生成"看图说话式"情境题（文字描述情境），生成结果同步走安全审核，审核通过才可下发；审核超时（>1.5s）自动降级为模板题。

**连词成句（arrange_words）判定**：

- 规则判定：与 `referenceAnswer` 做规范化比对（去标点、全半角统一），完全一致为正确。
- 语义等价判定：语序不同但语义通顺（如"我吃了一个苹果。/ 一个苹果被我吃了。"超出小学范围不做等价，仅接受原序），由评估管线判断，一年级仅接受原序。

### 4.3 句子评估管线（SentenceEvaluator）

评估采用 **规则初筛 → 模型评估 → 安全复核** 三段式：

```text
学生提交句子
    │
    ▼
[1] 规则初筛（<50ms，本地）
    - 长度校验（min/maxLength）
    - 标点校验（句末标点、连续标点）
    - 目标词出现校验（free_making 必须包含目标词）
    - 重复字检测（"我我我"）
    │
    ▼
[2] 模型评估（LLM，≤2s，超时降级）
    - Prompt 注入：学段/等级、目标词、句子
    - 输出 JSON Schema 强约束（见 5.3）
    - 输出解析失败 → 重试 1 次 → 仍失败走保守策略
    │
    ▼
[3] 安全复核（异步，不阻塞反馈）
    - 句子送内容安全服务（敏感词/不适龄内容）
    - 命中 → 记录 + 上报，反馈侧替换为中性引导语
```

**保守降级策略**（模型评估不可用）：verdict 默认 `good`（鼓励为主），errorPoints 仅保留规则初筛能发现的问题，不打 richness 分。降级状态写入 `eval_json.degraded=true`，供质量监控统计。

### 4.4 复习调度

- 词语级复习：答错或 `verdict=need_hint` 的词语，按间隔重复引擎计算 `next_review_at`（初始间隔 1 天，按艾宾浩斯曲线递增，答错重置）。
- 会话级复习：每次练习会话开始时，若存在到期复习词语，优先插入 2~3 题复习题（占比不超过本次任务的 40%），避免复习挤占新学。
- 复习题从原错题直接复用（相同 taskId 重新下发，`attemptCount` 递增）。

### 4.5 激励联动

- 完成一个会话（≥5 题且正确率 ≥60%）：发 `ExerciseSessionCompleted` 事件，成长激励体系发放星星。
- 首次造句获得 `excellent`：触发"小小造句家"徽章校验（成长激励体系负责判定）。
- 连续 3 次会话正确率 ≥80%：词语掌握度加速衰减因子调优，由复习调度引擎处理。

## 7. 关键代码示例

### 7.1 练习会话编排（TypeScript / NestJS 风格）

```typescript
@Injectable()
export class WordSentenceSessionService {
  constructor(
    private readonly taskFactory: ExerciseTaskFactory,
    private readonly wordBank: WordBankRepository,
    private readonly masteryStore: WordMasteryRepository,
    private readonly reviewScheduler: ReviewSchedulerClient,
    private readonly eventBus: EventBus,
    private readonly idGen: IdGenerator,
  ) {}

  /**
   * 创建练习会话：复习题优先（≤40%），其余按掌握度薄弱优先出新题。
   * 幂等键 clientToken 由唯一索引保证重试安全。
   */
  async createSession(cmd: CreateSessionCommand): Promise<SessionView> {
    const dueWords = await this.reviewScheduler.listDueWords(
      cmd.studentId, Math.ceil(cmd.taskCount * 0.4),
    );
    const newAnchors = await this.wordBank.findWeaklyMasteredChars(
      cmd.studentId, cmd.taskCount - dueWords.length,
    );

    const tasks: ExerciseTask[] = [];
    for (const w of dueWords) {
      tasks.push(await this.taskFactory.rebuildReviewTask(w));   // 复用原错题
    }
    for (const c of newAnchors) {
      tasks.push(await this.taskFactory.buildNewTask(c, cmd));   // 模板/词库/AI
    }
    // 模板题与 AI 题打散交错，避免 AI 题集中出现（AI 题有降级风险）
    const session = shuffleInterleave(tasks);

    await this.sessionRepo.save({ ...session, clientToken: cmd.clientToken });
    return SessionView.from(session);
  }
}
```

### 7.2 出题策略（策略模式）

```typescript
interface ItemBuildStrategy {
  readonly source: 'template' | 'bank' | 'ai';
  supports(ctx: BuildContext): boolean;
  build(ctx: BuildContext): Promise<ExerciseTask>;
}

@Injectable()
export class TemplateStrategy implements ItemBuildStrategy {
  readonly source = 'template';
  constructor(private readonly patternRepo: PatternRepository) {}

  supports(ctx: BuildContext) {
    return ctx.level <= SentenceLevel.L3;   // L4 情境题以 AI 为主
  }

  async build(ctx: BuildContext): Promise<ExerciseTask> {
    const pattern = await this.patternRepo.randomByLevel(ctx.level, ctx.subType);
    const payload = await this.fillSlots(pattern, ctx.studentId); // 槽位词全部来自已掌握词
    return ExerciseTask.fromTemplate(pattern, payload);
  }
}

@Injectable()
export class AiScenarioStrategy implements ItemBuildStrategy {
  readonly source = 'ai';
  constructor(
    private readonly llm: LlmGateway,
    private readonly safety: ContentSafetyClient,
  ) {}

  supports(ctx: BuildContext) { return ctx.allowAi; }

  async build(ctx: BuildContext): Promise<ExerciseTask> {
    const raw = await this.llm.generateJson(SENTENCE_SCENARIO_PROMPT, ctx, {
      schema: ScenarioSchema, timeoutMs: 1500, maxRetries: 1,
    });
    // 硬约束：AI 生成内容未过安全审核绝不下发
    const checked = await this.safety.checkSync(raw.scenarioText, { timeoutMs: 800 });
    if (!checked.pass) throw new AiContentRejectedError(checked.hitTags);
    return ExerciseTask.fromAi(raw);
  }
}
```

### 7.3 句子评估管线

```typescript
@Injectable()
export class SentenceEvaluationPipeline {
  constructor(
    private readonly ruleChecker: RuleBasedSentenceChecker,
    private readonly llm: LlmGateway,
    private readonly safety: ContentSafetyClient,
  ) {}

  async evaluate(input: EvalInput, sink: SseSink): Promise<SentenceEvaluation> {
    sink.send('eval_progress', { stage: 'rule_check' });
    const ruleResult = this.ruleChecker.check(input);       // <50ms

    // 硬错误（长度/目标词缺失）直接返回，不浪费模型调用
    if (ruleResult.hardFailures.length > 0) {
      return this.toNeedHint(ruleResult, input);
    }

    sink.send('eval_progress', { stage: 'model_eval' });
    let modelResult: SentenceEvaluation;
    try {
      modelResult = await this.llm.generateJson(SENTENCE_EVAL_PROMPT, input, {
        schema: SentenceEvalSchema, timeoutMs: 2000, maxRetries: 1,
      });
    } catch (e) {
      // 降级：以规则结果为准，鼓励为主，标记 degraded 供质量监控
      modelResult = this.degrade(ruleResult);
    }

    // 异步安全复核，不阻塞反馈
    this.safety.checkAsync(input.sentence).then(r => {
      if (!r.pass) this.reportSafetyEvent(input, r);
    });

    return merge(ruleResult, modelResult);
  }
}
```

### 7.4 掌握度更新（增量贝叶斯式加权）

```typescript
/**
 * 词语掌握度增量更新：
 * - objectiveCorrect / verdict → delta 基础值
 * - hintUsed 与 attemptCount 做衰减（用了提示/重试，增量打折）
 * - 只在事件消费者中写 mastery，评估管线本身不直连存储
 */
export function masteryDelta(r: AnswerRecord): number {
  const base = r.objectiveCorrect === true ? 0.08
             : r.eval?.verdict === 'excellent' ? 0.10
             : r.eval?.verdict === 'good' ? 0.06
             : -0.10;                                   // need_hint
  const decay = Math.pow(0.6, r.hintUsed) / r.attemptCount;
  return round2(clamp(base * decay, -0.15, 0.12));
}
```

## 8. 状态流转

### 8.1 练习会话状态机

```
                 createSession
   [无] ──────────────────────────────► IN_PROGRESS
                                            │
                    ┌───────────────────────┼────────────────────────┐
                    │ submitAnswer          │ submitAnswer           │ timeout(15min 无心跳)
                    ▼                       ▼                        ▼
              IN_PROGRESS              IN_PROGRESS               EXPIRED
              (答对，进度+1)          (答错/需提示，可重试)           │
                    │                       │                        │
                    │ tasks 全部完成         │ 主动退出 abandon         │ 不可恢复
                    ▼                       ▼                        ▼
               COMPLETED ◄────────────────────────────────────── [终态]
                    │
                    │ 发 ExerciseSessionCompleted 事件（激励/画像）
                    ▼
              ARCHIVED（7 天后归档，记录保留 3 年）
```

**状态与转换约束**：

| 当前状态 | 事件 | 下一状态 | 约束 |
| --- | --- | --- | --- |
| [无] | createSession（clientToken 唯一） | IN_PROGRESS | 同 clientToken 重试返回原会话 |
| IN_PROGRESS | 提交最后一题 | COMPLETED | 所有 task 有终态 record |
| IN_PROGRESS | abandon（客户端调用或 15 分钟无心跳） | EXPIRED | 已有答题记录保留 |
| EXPIRED | （无） | - | 终态，不可恢复；允许重新创建会话 |
| COMPLETED | 事件消费完成 | ARCHIVED | 由归档任务异步处理 |

### 8.2 答题判定状态（单题）

```
SUBMITTED ──规则初筛──► OBJECTIVE_JUDGED（选择题/排序题：对/错终态）
    │
    └──输入型──► MODEL_EVALUATING ──┬──► EVALUATED（正常）
                                  ├──► EVALUATED_DEGRADED（模型超时/失败）
                                  └──► SAFETY_BLOCKED（安全复核命中，反馈替换）
```

## 9. 错误处理

### 9.1 业务错误码（复用统一错误码体系，模块前缀 `WS`）

| 错误码 | HTTP | 含义 | 客户端处理建议 |
| --- | --- | --- | --- |
| WS_4001 | 400 | 提交答案长度超界 | 本地校验后提示 |
| WS_4002 | 400 | 句子缺少目标词语 | 引导"试着把『XX』用进去" |
| WS_4003 | 409 | clientToken 冲突（并发创建） | 使用响应中已存在会话 |
| WS_4041 | 404 | 会话/任务不存在或已过期 | 重新创建会话 |
| WS_4231 | 423 | 任务已完成，禁止重复提交 | 忽略，刷新进度 |
| WS_5001 | 200(SSE) | 模型评估超时，返回降级评估 | 正常展示，提示"稍后再试一次" |
| WS_5002 | 200 | AI 内容审核未通过，已替换模板题 | 无感知 |
| WS_5003 | 503 | 内容安全服务不可用 | 暂停 AI 题，仅出模板题 |
| WS_9001 | 500 | 系统内部错误 | 重试 1 次后上报 |

### 9.2 降级矩阵

| 故障点 | 降级行为 | 恢复检测 |
| --- | --- | --- |
| LLM 评估超时/失败 | 规则评估 + `degraded=true` | 熔断器半开探测，连续 3 次成功恢复 |
| AI 情境题生成失败 | 替换为同参数模板题 | 即时 |
| 内容安全同步接口超时 | AI 题不下发，仅模板题 | 健康检查 30s 周期 |
| 复习调度服务不可用 | 会话不插复习题（全部新题） | 即时 |
| 词库 Redis 缓存失效 | 回源 MySQL + 本地 1h 缓存兜底 | 即时 |

### 9.3 幂等与防重

- 创建会话、提交答案均以 `clientToken` + 学生 ID 建唯一索引，重复请求返回首次结果。
- 同一 task 重复提交：幂等键命中返回原 record；无幂等键且 task 已有终态 record 时返回 `WS_4231`。
- 重试不重复计 mastery：mastery 更新消费者以 `recordId` 去重。

## 10. 缓存与性能

| 数据 | 存储 | TTL | 说明 |
| --- | --- | --- | --- |
| 词语详情（热点学段） | Redis | 6h | 词库读多写少，版本号变更主动失效 |
| 句式模板（按 level+category） | Redis + 本地 Caffeine | 1h / 10min | 模板发布走主动失效 |
| 学生已学词语快照 | Redis | 30min | 出题准入判断用，容忍短暂滞后 |
| 学生提交句子的评估结果 | Redis | 24h | 相同原文（规范化后）直接复用，省模型调用 |
| AI 情境题（按 wordId+level 缓存） | Redis | 24h | 同一词语全班复用 |

**性能目标**：

- 客观题判定（含反馈）P95 ≤ 300ms。
- 输入型评估端到端（含 SSE）P95 ≤ 2.5s，降级评估 P95 ≤ 200ms。
- 创建会话（8 题）P95 ≤ 500ms。

## 11. 安全与合规

1. **未成年人内容安全**：学生输入句子、AI 生成内容双通道过审核；安全命中事件按等级上报内容安全审核工作台。
2. **AI 生成标识**：AI 生成的题目/例句下发时携带 `aiGenerated=true`，客户端按 AIGC 内容标识规范展示。
3. **数据最小化**：答题记录仅保存练习所需字段，不采集设备无关信息；记录保留 3 年，到期归档清理。
4. **防滥用**：评估接口按学生 ID 限流（每生每日 ≤60 次模型评估），超出后自动走规则评估；异常高频账号触发风控复核。
5. **无社交暴露**：造句内容仅学生本人与家长可见，不做公开展示。
