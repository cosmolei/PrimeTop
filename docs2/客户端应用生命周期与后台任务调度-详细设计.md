## 1. 文档定位与目标

### 1.1 为什么需要这份文档

移动端学习场景对应用生命周期管理有极高要求，以下场景必须被精确覆盖：

| 场景 | 问题描述 | 本文档解决方案 |
|------|---------|---------------|
| **学习中被打断恢复** | 用户接到电话/切换APP后返回，学习会话、答题进度、AI对话需完整恢复 | 状态保存与恢复机制（§3） |
| **后台数据同步** | 答题记录、学习进度需及时上报，否则多设备数据不一致 | 后台任务调度（§4）+ 数据同步策略（§8） |
| **后台资源预下载** | 课程资源包体积大，需在闲时后台预下载以保证前台体验流畅 | ResourceDownloadTaskHandler（§5.3） |
| **推送通知处理** | 学习提醒、作业通知需在前后台均能处理并正确路由 | 推送与生命周期集成（§6） |
| **内存压力管理** | Android/iOS 系统可能在后台杀进程，需优雅降级 | 状态保存（§3）+ 内存预算（§9） |
| **电量流量管控** | 后台任务不能无节制消耗电量和流量，需精确调度 | 性能预算（§9）+ 任务配置矩阵（§4.2） |

## 2. 生命周期状态模型

### 2.1 状态定义

```dart
/// 应用生命周期状态
///
/// 映射关系：
/// - Flutter AppLifecycleState.inactive   → LifecycleState.inactive
/// - Flutter AppLifecycleState.resumed    → LifecycleState.foreground
/// - Flutter AppLifecycleState.paused     → LifecycleState.background
/// - Flutter AppLifecycleState.detached   → LifecycleState.suspended
/// - 进程被系统杀死                        → LifecycleState.terminated
enum LifecycleState {
  /// 应用在前台，UI可见且可交互。
  /// 约束：所有功能正常运行，网络全速，动画流畅。
  foreground,

  /// 应用部分遮挡（如分屏、系统弹窗、下拉通知栏）。
  /// 约束：UI仍可见但失去焦点，应暂停输入和计时器但保持渲染。
  inactive,

  /// 应用在后台，UI不可见。
  /// 约束：应立即保存状态，降级网络活动，注册后台任务。
  /// Android：onStop 之后
  /// iOS：applicationDidEnterBackground
  background,

  /// 应用被系统挂起，CPU暂停，内存可能被回收。
  /// 约束：无法执行任何代码。iOS 独有状态。
  /// Android 上等同于 cached/empty 进程。
  suspended,

  /// 应用进程被系统杀死或用户主动关闭。
  /// 约束：下次启动为冷启动，需从持久化数据恢复状态。
  terminated,
}
```

### 2.2 状态转换图

```
                    ┌──────────────┐
         冷启动      │              │
        ───────────►│  terminated  │◄─── 系统杀死 / 用户关闭
                    │              │
                    └──────┬───────┘
                           │ 启动完成
                           ▼
                    ┌──────────────┐
            ┌──────│   foreground  │──────┐
            │      └──────┬───────┘      │
            │             │              │
     分屏/弹窗    失去焦点/切后台    恢复交互
            │             │              │
            ▼             ▼              │
     ┌─────────────┐ ┌──────────────┐    │
     │   inactive   ││   background  │────┘
     └──────┬──────┘ └──────┬───────┘
            │               │
     恢复交互         系统挂起(iOS)
            │               │
            │               ▼
            │        ┌──────────────┐
            └───────►│   suspended   │
                     └──────┬───────┘
                            │
                     系统唤醒 / 被杀
                            │
                    ┌───────┴────────┐
                    ▼                ▼
             foreground         terminated
```

**关键转换说明：**

| 转换 | 触发条件 | 需要执行的动作 |
|------|---------|---------------|
| foreground → inactive | 分屏、系统弹窗、下拉通知 | 暂停输入，暂停计时器 |
| inactive → foreground | 弹窗关闭、分屏结束 | 恢复正常操作 |
| foreground → background | 用户按Home键、切换APP | 保存状态→刷出数据→注册后台任务→降级网络 |
| background → foreground | 用户切回APP | 恢复网络→增量同步→刷新Token→恢复页面 |
| background → suspended | iOS系统挂起 | 无动作（代码无法执行） |
| suspended → foreground | 用户切回APP | 同 background → foreground |
| suspended → terminated | 系统杀进程 | 无动作（下次冷启动恢复） |

### 2.3 AppLifecycleListener 接口定义

```dart
/// 生命周期监听器接口
///
/// 各业务模块实现此接口以接收生命周期事件。
/// 监听器通过 [AppLifecycleManager] 注册，按优先级排序通知。
abstract class AppLifecycleListener {
  /// 监听器唯一标识，用于调试和去重。
  String get listenerId;

  /// 通知优先级，数值越小越先通知。
  /// 典型值：
  /// - 10: 数据持久化类（最先执行）
  /// - 50: 业务逻辑类
  /// - 100: UI刷新类（最后执行）
  int get priority => 50;

  /// 应用进入 inactive 状态。
  /// 可在此暂停输入法、弱化动画。
  void onInactive(AppLifecycleTransition transition) {}

  /// 应用回到 foreground 状态。
  /// 可在此恢复网络请求、刷新UI、恢复计时器。
  void onForeground(AppLifecycleTransition transition) {}

  /// 应用进入 background 状态。
  /// ⚠️ 此回调有严格时间限制（参见 §9 性能预算），只做必要操作。
  void onBackground(AppLifecycleTransition transition) {}

  /// 应用被系统挂起（iOS专用，Android不会触发）。
  void onSuspended(AppLifecycleTransition transition) {}

  /// 系统发出内存警告。
  /// 应释放缓存、清除非必要资源。
  void onMemoryWarning() {}
}
```

### 2.4 AppLifecycleTransition 上下文对象

```dart
/// 生命周期转换的上下文信息
class AppLifecycleTransition {
  /// 转换前的状态
  final LifecycleState fromState;

  /// 转换后的状态
  final LifecycleState toState;

  /// 转换原因
  final TransitionReason reason;

  /// 时间戳（毫秒级 epoch）
  final int timestamp;

  /// 离开前台经过的时间（仅 onForeground 回调有值）
  /// 用于判断恢复策略（参见 §3.4）
  final Duration? backgroundDuration;

  /// 是否为冷启动恢复
  final bool isColdStart;

  /// 附带数据（如推送唤起的 payload）
  final Map<String, dynamic>? extras;

  const AppLifecycleTransition({
    required this.fromState,
    required this.toState,
    required this.reason,
    required this.timestamp,
    this.backgroundDuration,
    this.isColdStart = false,
    this.extras,
  });

  @override
  String toString() =>
      'AppLifecycleTransition($fromState → $toState, reason: $reason, '
      'bgDuration: $backgroundDuration, coldStart: $isColdStart)';
}
```

```dart
enum TransitionReason {
  /// 用户主动按 Home 键
  userHomeButton,

  /// 用户切换到其他 APP
  userAppSwitch,

  /// 系统弹窗（来电、权限请求、系统对话框）

  /// 用户主动切回 APP

  pushNotification,

  backgroundTask,

  systemResume,

  /// 系统因内存压力终止
  systemTermination,

  /// 冷启动（进程不存在）
  coldStart,

  /// 原因未知
  unknown,
}
```

### 2.6 AppLifecycleManager 核心实现

```dart
import 'dart:async';
import 'package:flutter/scheduler.dart';
import 'package:flutter/widgets.dart';

/// 应用生命周期管理器
///
/// 单例，在 APP 启动时初始化。
/// 负责：
/// 1. 监听 Flutter 生命周期事件
/// 2. 管理监听器注册/注销
/// 3. 按优先级分发事件
/// 4. 编排进入后台/恢复前台的处理链
class AppLifecycleManager with WidgetsBindingObserver {
  AppLifecycleManager._();
  static final AppLifecycleManager instance = AppLifecycleManager._();

  final List<AppLifecycleListener> _listeners = [];
  LifecycleState _currentState = LifecycleState.terminated;
  int _backgroundTimestamp = 0;

  /// 状态变更事件流
  final StreamController<AppLifecycleTransition> _transitionController =
      StreamController<AppLifecycleTransition>.broadcast();
  Stream<AppLifecycleTransition> get transitionStream =>
      _transitionController.stream;

  LifecycleState get currentState => _currentState;

  /// 初始化，在 main() 中调用
  void init() {
    WidgetsBinding.instance.addObserver(this);
    _currentState = LifecycleState.foreground;
  }

  /// 注册监听器
  void addListener(AppLifecycleListener listener) {
    _listeners.add(listener);
    _listeners.sort((a, b) => a.priority.compareTo(b.priority));
  }

  /// 注销监听器
  void removeListener(AppLifecycleListener listener) {
    _listeners.remove(listener);
  }

  /// WidgetsBindingObserver 回调
  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    final lifecycleState = _mapFlutterState(state);
    final reason = _inferReason(_currentState, lifecycleState);
    final transition = AppLifecycleTransition(
      fromState: _currentState,
      toState: lifecycleState,
      reason: reason,
      timestamp: DateTime.now().millisecondsSinceEpoch,
      backgroundDuration: _currentState != LifecycleState.foreground &&
              lifecycleState == LifecycleState.foreground
          ? Duration(milliseconds: DateTime.now().millisecondsSinceEpoch - _backgroundTimestamp)
          : null,
      isColdStart: _currentState == LifecycleState.terminated,
    );

    final previousState = _currentState;
    _currentState = lifecycleState;

    // 记录进入后台的时间戳
    if (lifecycleState == LifecycleState.background ||
        lifecycleState == LifecycleState.suspended) {
      _backgroundTimestamp = transition.timestamp;
    }

    _notifyListeners(transition, previousState, lifecycleState);
    _transitionController.add(transition);
  }

  /// 内存警告回调
  @override
  void didHaveMemoryPressure() {
    for (final listener in _listeners) {
      listener.onMemoryWarning();
    }
  }

  // ─── 进入后台处理链 ─────────────────────────────
  //
  //  执行顺序（按优先级从低到高通知，确保数据层先执行）：
  //  1. [priority=10] 保存状态 → StatePreservationManager
  //  2. [priority=10] 刷出关键数据 → DataSyncTaskHandler
  //  3. [priority=20] 注册后台任务 → BackgroundTaskScheduler
  //  4. [priority=30] 降级网络 → NetworkManager
  //  5. [priority=50] 各业务模块暂停（AI对话SSE、计时器等）
  //  6. [priority=100] UI 层清理

  // ─── 恢复前台处理链 ─────────────────────────────
  //
  //  执行顺序：
  //  1. [priority=10] 恢复网络 → NetworkManager
  //  2. [priority=10] 增量同步 → DataSyncTaskHandler
  //  3. [priority=10] 刷新Token → TokenRefreshHandler
  //  4. [priority=20] 取消后台任务 → BackgroundTaskScheduler
  //  5. [priority=50] 恢复页面状态 → StatePreservationManager
  //  6. [priority=100] UI 层恢复渲染

  void _notifyListeners(
    AppLifecycleTransition transition,
    LifecycleState from,
    LifecycleState to,
  ) {
    for (final listener in _listeners) {
      switch (to) {
        case LifecycleState.inactive:
          listener.onInactive(transition);
          break;
        case LifecycleState.foreground:
          listener.onForeground(transition);
          break;
        case LifecycleState.background:
          listener.onBackground(transition);
          break;
        case LifecycleState.suspended:
          listener.onSuspended(transition);
          break;
        case LifecycleState.terminated:
          break; // 无法通知
      }
    }
  }

  LifecycleState _mapFlutterState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.resumed:
        return LifecycleState.foreground;
      case AppLifecycleState.inactive:
        return LifecycleState.inactive;
      case AppLifecycleState.paused:
        return LifecycleState.background;
      case AppLifecycleState.detached:
        return LifecycleState.suspended;
      case AppLifecycleState.hidden:
        return LifecycleState.background;
    }
  }

  TransitionReason _inferReason(LifecycleState from, LifecycleState to) {
    if (to == LifecycleState.foreground && from == LifecycleState.terminated) {
      return TransitionReason.coldStart;
    }
    if (to == LifecycleState.background) {
      return TransitionReason.userHomeButton; // 无法精确判断，默认
    }
    if (to == LifecycleState.foreground && from == LifecycleState.background) {
      return TransitionReason.userReturn;
    }
    return TransitionReason.unknown;
  }

  void dispose() {
    WidgetsBinding.instance.removeObserver(this);
    _transitionController.close();
  }
}
```

## 3. 状态保存与恢复机制

### 3.1 需要保存的状态清单

| 模块 | 保存数据 | 保存时机 | 恢复难度 |
|------|---------|---------|---------|
| **学习会话** | 当前学习科目、章节、知识点、会话ID | onBackground | 低 |
| **AI对话** | 对话历史（最近50条）、待回复消息、SSE连接状态 | onBackground | 中 |
| **答题状态** | 当前题目ID、已选答案、答题进度、剩余时间 | onBackground + 每题切换 | 低 |
| **拍题流程** | 已拍图片路径、OCR结果、当前步骤（拍照/裁剪/识别/结果） | onBackground + 每步 | 中 |
| **作文草稿** | 文本内容、光标位置、已写字数、自动保存时间 | 每30秒 + onBackground | 低 |
| **浏览位置** | 当前页面路由、滚动位置、Tab索引 | onBackground | 低 |
| **音视频** | 播放位置、播放速率、播放状态 | onBackground + 每5秒 | 低 |
| **表单数据** | 已填字段值、验证状态、当前步骤 | onBackground | 低 |

```dart
import 'package:hive/hive.dart';
import 'package:package_info/package_info.dart';
import 'dart:convert';

/// 状态保存与恢复管理器
///
/// 使用 Hive 作为持久化后端，保证 50ms 内完成保存。
class StatePreservationManager extends AppLifecycleListener {
  static const String _boxName = 'app_state_preservation';
  static const String _snapshotKey = 'latest_snapshot';

  Box<String>? _box;
  AppStateSnapshot? _currentSnapshot;

  @override
  String get listenerId => 'StatePreservationManager';

  @override
  int get priority => 10; // 最先保存

  /// 初始化
  Future<void> init() async {
    _box = await Hive.openBox<String>(_boxName);
    // 尝试恢复上次快照
    final raw = _box?.get(_snapshotKey);
    if (raw != null) {
      try {
        _currentSnapshot = AppStateSnapshot.fromJson(
          jsonDecode(raw) as Map<String, dynamic>,
        );
      } catch (_) {
        // 快照损坏，忽略
        await _box?.delete(_snapshotKey);
      }
    }
  }

  /// 保存当前状态快照
  ///
  /// ⚠️ 必须在 50ms 内完成
  Future<void> saveSnapshot(AppStateSnapshot snapshot) async {
    final stopwatch = Stopwatch()..start();
    try {
      final json = jsonEncode(snapshot.toJson());
      await _box?.put(_snapshotKey, json);
      _currentSnapshot = snapshot;
    } catch (e) {
      // 保存失败不应阻塞后台流程
      debugPrint('[StatePreservation] Save failed: $e');
    }
    stopwatch.stop();
    if (stopwatch.elapsedMilliseconds > 50) {
      debugPrint('[StatePreservation] ⚠️ Save took ${stopwatch.elapsedMilliseconds}ms (budget: 50ms)');
    }
  }

  /// 读取最近的快照
  AppStateSnapshot? get lastSnapshot => _currentSnapshot;

  /// 判断是否应该恢复状态
  ///
  /// 综合考虑：后台时间、应用版本、快照版本
  RecoveryDecision shouldRecover(AppStateSnapshot? snapshot, String currentAppVersion) {
    if (snapshot == null) {
      return RecoveryDecision.noRecovery;
    }

    // 版本不匹配则不恢复
    if (snapshot.appVersion != currentAppVersion) {
      return RecoveryDecision.versionMismatch;
    }

    final now = DateTime.now().millisecondsSinceEpoch;
    final elapsed = Duration(milliseconds: now - snapshot.timestamp);

    if (elapsed <= const Duration(minutes: 5)) {
      return RecoveryDecision.fullRecovery;
    } else if (elapsed <= const Duration(minutes: 30)) {
      return RecoveryDecision.partialRecovery;
    } else if (elapsed <= const Duration(hours: 4)) {
      return RecoveryDecision.promptRecovery;
    } else {
      return RecoveryDecision.noRecovery;
    }
  }

  /// 执行恢复
  Future<void> recover(AppStateSnapshot snapshot, RecoveryDecision decision) async {
    switch (decision) {
      case RecoveryDecision.fullRecovery:
        // 完整恢复所有模块状态
        await _restoreAll(snapshot);
        break;
      case RecoveryDecision.partialRecovery:
        // 恢复核心模块（答题、学习会话），丢弃浏览位置
        await _restorePartial(snapshot);
        break;
      case RecoveryDecision.promptRecovery:
        // 弹窗询问用户是否恢复
        // 由 UI 层处理，此处仅标记
        break;
      case RecoveryDecision.noRecovery:
      case RecoveryDecision.versionMismatch:
        // 清除快照
        await _box?.delete(_snapshotKey);
        _currentSnapshot = null;
        break;
    }
  }

  Future<void> _restoreAll(AppStateSnapshot snapshot) async {
    // 通过 Navigator 恢复路由栈
    // 各模块通过各自的 restore 方法接收数据
    // 具体实现依赖项目的路由框架
  }

  Future<void> _restorePartial(AppStateSnapshot snapshot) async {
    // 仅恢复答题、学习会话等核心状态
    // 路由栈只恢复最后一层
  }

  /// 清除保存的状态
  Future<void> clear() async {
    await _box?.delete(_snapshotKey);
    _currentSnapshot = null;
  }

  @override
  void onBackground(AppLifecycleTransition transition) {
    // 收集各模块状态并保存
    // 实际项目中由各模块注册 StateProvider
    _collectAndSave();
  }

  Future<void> _collectAndSave() async {
    final packageInfo = await PackageInfo.fromPlatform();
    final snapshot = AppStateSnapshot(
      timestamp: DateTime.now().millisecondsSinceEpoch,
      appVersion: packageInfo.version,
      deviceId: '', // 从设备信息获取
      routeStack: [], // 从 Navigator 获取
      // ... 各模块数据由 StateProvider 提供
    );
    await saveSnapshot(snapshot);
  }
}

enum RecoveryDecision {
  /// 完整恢复（≤5min）

  /// 部分恢复（5-30min）

  /// 提示用户是否恢复（30min-4h）
  promptRecovery,

  /// 不恢复（>4h）
  noRecovery,

  /// 版本不匹配，不恢复
```

### 4.4 Android WorkManager 实现

```dart
import 'package:workmanager/workmanager.dart';

/// Android 后台任务调度器实现
///
/// 基于 workmanager Flutter 插件（底层使用 Android Jetpack WorkManager）。
class AndroidBackgroundTaskScheduler extends BackgroundTaskScheduler {
  @override
  String get listenerId => 'AndroidBackgroundTaskScheduler';

  @override
  int get priority => 20;

  static const String _tagPrefix = 'primetop_bg_';

  final Map<BackgroundTaskType, String> _taskNames = {
    BackgroundTaskType.dataSync: '${_tagPrefix}data_sync',
    BackgroundTaskType.resourceDownload: '${_tagPrefix}resource_download',
    BackgroundTaskType.reminderPreprocess: '${_tagPrefix}reminder_preprocess',
    BackgroundTaskType.homeCacheWarmup: '${_tagPrefix}home_cache_warmup',
    BackgroundTaskType.mistakeReviewPreload: '${_tagPrefix}mistake_review_preload',
    BackgroundTaskType.telemetryUpload: '${_tagPrefix}telemetry_upload',
    BackgroundTaskType.tokenRefresh: '${_tagPrefix}token_refresh',
  };

  /// 初始化 WorkManager
  Future<void> init() async {
    await Workmanager().initialize(
      _callbackDispatcher,
      isInDebugMode: kDebugMode,
    );
  }

  /// WorkManager 回调分发入口点
  static void _callbackDispatcher() {
    Workmanager().executeTask((taskName, inputData) async {
      final taskType = BackgroundTaskType.values.firstWhere(
        (t) => taskName == '${_tagPrefix}${t.name}',
        orElse: () => BackgroundTaskType.telemetryUpload,
      );

      final handler = _createHandler(taskType);
      try {
        final result = await handler.execute(inputData ?? {});
        return result;
      } catch (e) {
        return false;
      }
    });
  }

  static BackgroundTaskHandler _createHandler(BackgroundTaskType type) {
    switch (type) {
      case BackgroundTaskType.dataSync:
        return DataSyncTaskHandler();
      case BackgroundTaskType.resourceDownload:
        return ResourceDownloadTaskHandler();
      case BackgroundTaskType.telemetryUpload:
        return TelemetryUploadHandler();
      case BackgroundTaskType.tokenRefresh:
        return TokenRefreshHandler();
      case BackgroundTaskType.reminderPreprocess:
        return ReminderPreprocessHandler();
      case BackgroundTaskType.homeCacheWarmup:
        return HomeCacheWarmupHandler();
      case BackgroundTaskType.mistakeReviewPreload:
        return MistakeReviewPreloadHandler();
    }
  }

  @override
  Future<void> registerPeriodicTask({
    required BackgroundTaskType type,
    required Duration frequency,
    required Duration initialDelay,
    required NetworkConstraint networkConstraint,
    required BatteryConstraint batteryConstraint,
    required Duration timeout,
  }) async {
    final taskName = _taskNames[type]!;

    await Workmanager().registerPeriodicTask(
      taskName,
      taskName,
      frequency: frequency,
      initialDelay: initialDelay,
      constraints: Constraints(
        network: _mapNetworkConstraint(networkConstraint),
        requiresBatteryNotLow: batteryConstraint == BatteryConstraint.notLow,
        requiresCharging: batteryConstraint == BatteryConstraint.charging,
      ),
      backoffPolicy: BackoffPolicy.exponential,
      backoffPolicyDelay: const Duration(seconds: 30),
      existingWorkPolicy: ExistingWorkPolicy.replace,
    );
  }

  @override
  Future<void> registerOneOffTask({
    required BackgroundTaskType type,
    required Duration initialDelay,
    required NetworkConstraint networkConstraint,
    required BatteryConstraint batteryConstraint,
    required Duration timeout,
  }) async {
    final taskName = _taskNames[type]!;

    await Workmanager().registerOneOffTask(
      taskName,
      taskName,
      initialDelay: initialDelay,
      constraints: Constraints(
        network: _mapNetworkConstraint(networkConstraint),
        requiresBatteryNotLow: batteryConstraint == BatteryConstraint.notLow,
        requiresCharging: batteryConstraint == BatteryConstraint.charging,
      ),
      backoffPolicy: BackoffPolicy.exponential,
      backoffPolicyDelay: const Duration(seconds: 30),
      existingWorkPolicy: ExistingWorkPolicy.replace,
    );
  }

  @override
  Future<void> cancelTask(BackgroundTaskType type) async {
    await Workmanager().cancelByUniqueName(_taskNames[type]!);
  }

  @override
  Future<void> cancelAllTasks() async {
    await Workmanager().cancelAll();
  }

  @override
  Future<DateTime?> lastRunTime(BackgroundTaskType type) async {
    // WorkManager 不直接提供此信息，需通过本地持久化记录
    return null;
  }

  NetworkType _mapNetworkConstraint(NetworkConstraint constraint) {
    switch (constraint) {
      case NetworkConstraint.none:
        return NetworkType.not_required;
      case NetworkConstraint.connected:
        return NetworkType.connected;
      case NetworkConstraint.unmetered:
        return NetworkType.unmetered;
    }
  }

  @override
  void onBackground(AppLifecycleTransition transition) {
    // 进入后台时注册立即执行的任务
    registerOneOffTask(
      type: BackgroundTaskType.dataSync,
      initialDelay: Duration.zero,
      networkConstraint: NetworkConstraint.connected,
      batteryConstraint: BatteryConstraint.none,
      timeout: const Duration(seconds: 10),
    );
    registerOneOffTask(
      type: BackgroundTaskType.telemetryUpload,
      initialDelay: Duration.zero,
      networkConstraint: NetworkConstraint.connected,
      batteryConstraint: BatteryConstraint.none,
      timeout: const Duration(seconds: 5),
    );
  }

  @override
  void onForeground(AppLifecycleTransition transition) {
    // 恢复前台时取消后台任务（前台直接处理同步）
    cancelAllTasks();
  }
}
```

import 'package:flutter/services.dart';

/// iOS 后台任务调度器实现
///
/// iOS 使用 BGTaskScheduler（需在 Info.plist 配置）。
/// Flutter 没有官方 BGTaskScheduler 插件，需通过 MethodChannel 调用原生代码。
class IOSBackgroundTaskScheduler extends BackgroundTaskScheduler {
  @override
  String get listenerId => 'IOSBackgroundTaskScheduler';

  @override
  int get priority => 20;

  static const MethodChannel _channel = MethodChannel('primetop.background_task');

  final Map<BackgroundTaskType, String> _taskIds = {
    BackgroundTaskType.dataSync: 'com.primetop.data-sync',
    BackgroundTaskType.resourceDownload: 'com.primetop.resource-download',
    BackgroundTaskType.reminderPreprocess: 'com.primetop.reminder-preprocess',
    BackgroundTaskType.homeCacheWarmup: 'com.primetop.home-cache-warmup',
    BackgroundTaskType.mistakeReviewPreload: 'com.primetop.mistake-review-preload',
    BackgroundTaskType.telemetryUpload: 'com.primetop.telemetry-upload',
    BackgroundTaskType.tokenRefresh: 'com.primetop.token-refresh',
  };

  /// Info.plist 需配置：
  /// ```xml
  /// <key>BGTaskSchedulerPermittedIdentifiers</key>
  /// <array>
  ///   <string>com.primetop.data-sync</string>
  ///   <string>com.primetop.resource-download</string>
  ///   ...
  /// </array>
  /// <key>UIBackgroundModes</key>
  /// <array>
  ///   <string>fetch</string>
  ///   <string>processing</string>
  /// </array>
  /// ```

  Future<void> registerPeriodicTask({
    required BackgroundTaskType type,
    required Duration frequency,
    required Duration initialDelay,
    required NetworkConstraint networkConstraint,
    required BatteryConstraint batteryConstraint,
    required Duration timeout,
  }) async {
    final taskId = _taskIds[type]!;

    // iOS BGAppRefreshTask（短任务，≤30s）
    await _channel.invokeMethod('registerBackgroundTask', {
      'taskId': taskId,
      'type': 'refresh', // BGAppRefreshTask
      'interval': frequency.inSeconds,
      'initialDelay': initialDelay.inSeconds,
      'requiresNetwork': networkConstraint != NetworkConstraint.none,
      'requiresExternalPower': batteryConstraint == BatteryConstraint.charging,
    });
  }

  @override
  Future<void> registerOneOffTask({
    required BackgroundTaskType type,
    required Duration initialDelay,
    required NetworkConstraint networkConstraint,
    required BatteryConstraint batteryConstraint,
    required Duration timeout,
  }) async {
    final taskId = _taskIds[type]!;

    // 资源下载等长任务使用 BGProcessingTask（可数分钟）
    final isLongRunning = type == BackgroundTaskType.resourceDownload;
    await _channel.invokeMethod('registerBackgroundTask', {
      'taskId': taskId,
      'type': isLongRunning ? 'processing' : 'refresh',
      'initialDelay': initialDelay.inSeconds,
      'requiresNetwork': networkConstraint != NetworkConstraint.none,
      'requiresExternalPower': batteryConstraint == BatteryConstraint.charging,
    });
  }

  @override
  Future<void> cancelTask(BackgroundTaskType type) async {
    await _channel.invokeMethod('cancelBackgroundTask', {
      'taskId': _taskIds[type],
    });
  }

  @override
  Future<void> cancelAllTasks() async {
    await _channel.invokeMethod('cancelAllBackgroundTasks');
  }

  @override
  Future<DateTime?> lastRunTime(BackgroundTaskType type) async {
    final timestamp = await _channel.invokeMethod<int>('getLastRunTime', {
      'taskId': _taskIds[type],
    });
    return timestamp != null
        ? DateTime.fromMillisecondsSinceEpoch(timestamp)
        : null;
  }

  @override
  void onBackground(AppLifecycleTransition transition) {
    // iOS 进入后台后立即请求后台时间
    registerOneOffTask(
      type: BackgroundTaskType.dataSync,
      initialDelay: Duration.zero,
      networkConstraint: NetworkConstraint.connected,
      batteryConstraint: BatteryConstraint.none,
      timeout: const Duration(seconds: 10),
    );
    registerOneOffTask(
      type: BackgroundTaskType.telemetryUpload,
      initialDelay: Duration.zero,
      networkConstraint: NetworkConstraint.connected,
      batteryConstraint: BatteryConstraint.none,
      timeout: const Duration(seconds: 5),
    );
  }

  @override
  void onForeground(AppLifecycleTransition transition) {
    cancelAllTasks();
  }
}

### 4.6 平台差异对照表

| 维度 | Android (WorkManager) | iOS (BGTaskScheduler) |
|------|----------------------|----------------------|
| **最小周期** | 15 分钟 | 无硬性限制，但系统决定实际执行时间 |
| **一次性任务延迟** | 支持 `initialDelay` | 支持 `earliestBeginDate` |
| **网络约束** | `NetworkType.connected/unmetered` | `requiresNetworkConnectivity` (布尔) |
| **电量约束** | `requiresBatteryNotLow` / `requiresCharging` | `requiresExternalPower` / `requiresEnergyCondition` |
| **任务类型** | 统一 `Worker` | `BGAppRefreshTask`(≤30s) / `BGProcessingTask`(数分钟) |
| **并发限制** | 无硬限制，但受 Doze 模式影响 | 系统严格控制，同类型任务串行 |
| **后台执行时间保证** | `JobScheduler` 保证执行 | 不保证，系统可能延迟或不执行 |
| **调试** | `adb shell dumpsys jobscheduler` | Xcode → Debug → Simulate Background Fetch |
| **配置** | 无需特殊配置 | Info.plist 需声明 `BGTaskSchedulerPermittedIdentifiers` |
| **测试便利性** | `adb shell cmd jobscheduler run` | 仅限 Xcode 模拟器触发 |

### 5.2 DataSyncTaskHandler

```dart
import 'dart:convert';
import 'package:sqflite/sqflite.dart';

/// 数据同步任务处理器
///
/// 将本地 SQLite 中待同步的学习记录批量上报到服务端。
class DataSyncTaskHandler extends BackgroundTaskHandler {
  @override
  int get maxRetries => 3;

  final Database _db;
  final ApiClient _apiClient;

  DataSyncTaskHandler({
    required Database db,
    required ApiClient apiClient,
  })  : _db = db,
        _apiClient = apiClient;

  @override
  Future<bool> execute(Map<String, dynamic> inputData) async {
    try {
      // 1. 从 SQLite 读取待同步记录
      final pendingRecords = await _db.query(
        'sync_queue',
        where: 'status = ? AND retry_count < ?',
        whereArgs: ['pending', maxRetries],
        orderBy: 'priority DESC, created_at ASC',
        limit: 100, // 每批最多100条
      );

      if (pendingRecords.isEmpty) {
        return true; // 无数据需同步
      }

      // 2. 按类型分组
      final grouped = <String, List<Map<String, dynamic>>>{};
      for (final record in pendingRecords) {
        final type = record['record_type'] as String;
        grouped.putIfAbsent(type, () => []).add(record);
      }

      // 3. 按优先级顺序同步
      // 优先级：答题记录 > 学习进度 > 浏览行为 > 埋点
      final typePriority = [
        'quiz_answer',
        'study_progress',
        'browse_behavior',
        'telemetry_event',
      ];

      for (final type in typePriority) {
        final records = grouped[type];
        if (records == null || records.isEmpty) continue;

        final success = await _syncBatch(type, records);
        if (!success) {
          // 标记失败，增加重试计数
          await _markRetry(records);
          return false;
        }

        // 标记成功
        await _markSynced(records);
      }

      return true;
    } catch (e) {
      debugPrint('[DataSyncTask] Error: $e');
      return false;
    }
  }

  /// 批量同步一组记录到服务端
  Future<bool> _syncBatch(String type, List<Map<String, dynamic>> records) async {
    try {
      final payload = records.map((r) {
        final data = jsonDecode(r['payload'] as String);
        return {
          'id': r['id'],
          'type': type,
          'data': data,
          'timestamp': r['created_at'],
          'deviceId': r['device_id'],
        };
      }).toList();

      final response = await _apiClient.post(
        '/api/v1/sync/batch',
        body: {
          'records': payload,
          'clientTimestamp': DateTime.now().millisecondsSinceEpoch,
        },
        timeout: const Duration(seconds: 8),
      );

      if (response.statusCode == 200) {
        // 处理服务端返回的冲突
        final body = response.data as Map<String, dynamic>;
        final conflicts = body['conflicts'] as List<dynamic>?;
        if (conflicts != null && conflicts.isNotEmpty) {
          await _resolveConflicts(conflicts);
        }
        return true;
      } else if (response.statusCode == 409) {
        // 冲突，需要特殊处理
        await _resolveConflicts(response.data['conflicts'] as List<dynamic>);
        return true;
      }

      return false;
    } on TimeoutException {
      return false;
    } catch (e) {
      debugPrint('[DataSyncTask] Batch sync error for $type: $e');
      return false;
    }
  }

  /// 冲突解决：服务端权威 + 客户端合并
  Future<void> _resolveConflicts(List<dynamic> conflicts) async {
    for (final conflict in conflicts) {
      final map = conflict as Map<String, dynamic>;
      final recordId = map['id'] as String;
      final serverVersion = map['serverVersion'] as int;
      final resolution = map['resolution'] as String; // 'server_wins' | 'merged'

      if (resolution == 'server_wins') {
        // 更新本地数据为服务端版本
        await _db.update(
          'sync_queue',
          {'status': 'conflict_resolved', 'server_version': serverVersion},
          where: 'id = ?',
          whereArgs: [recordId],
        );
      } else if (resolution == 'merged') {
        // 使用服务端合并结果更新本地
        final mergedData = map['mergedData'];
        await _db.update(
          'sync_queue',
          {
            'status': 'synced',
            'payload': jsonEncode(mergedData),
            'server_version': serverVersion,
          },
          where: 'id = ?',
          whereArgs: [recordId],
        );
      }
    }
  }

  /// 标记记录为已同步
  Future<void> _markSynced(List<Map<String, dynamic>> records) async {
    final ids = records.map((r) => r['id']).toList();
    await _db.delete(
      'sync_queue',
      where: 'id IN (${List.filled(ids.length, '?').join(',')})',
      whereArgs: ids,
    );
  }

  /// 标记记录重试
  Future<void> _markRetry(List<Map<String, dynamic>> records) async {
    for (final record in records) {
      await _db.update(
        'sync_queue',
        {
          'retry_count': (record['retry_count'] as int) + 1,
          'status': 'pending',
          'last_error': 'sync_failed',
          'next_retry_at': DateTime.now()
              .add(Duration(seconds: 30 * (record['retry_count'] as int + 1)))
              .millisecondsSinceEpoch,
        },
        where: 'id = ?',
        whereArgs: [record['id']],
      );
    }
  }
}
```

### 5.3 TelemetryUploadHandler

```dart
/// 埋点事件批量聚合上报处理器
class TelemetryUploadHandler extends BackgroundTaskHandler {
  @override
  int get maxRetries => 3;

  final Database _db;
  final ApiClient _apiClient;

  TelemetryUploadHandler({
    required Database db,
    required ApiClient apiClient,
  })  : _db = db,
        _apiClient = apiClient;

  @override
  Future<bool> execute(Map<String, dynamic> inputData) async {
    try {
      // 1. 从本地数据库读取待上报事件
      final events = await _db.query(
        'telemetry_events',
        where: 'uploaded = 0',
        orderBy: 'timestamp ASC',
        limit: 200,
      );

      if (events.isEmpty) return true;

      // 2. 聚合事件（相同类型事件合并统计）
      final aggregated = _aggregateEvents(events);

      // 3. 上报
      final response = await _apiClient.post(
        '/api/v1/telemetry/batch',
        body: {
          'events': aggregated,
          'batchId': _generateBatchId(),
          'clientTimestamp': DateTime.now().millisecondsSinceEpoch,
        },
        timeout: const Duration(seconds: 5),
      );

      if (response.statusCode == 200 || response.statusCode == 202) {
        // 标记为已上报
        final ids = events.map((e) => e['id']).toList();
        await _db.update(
          'telemetry_events',
          {'uploaded': 1},
          where: 'id IN (${List.filled(ids.length, '?').join(',')})',
          whereArgs: ids,
        );
        return true;
      }

      return false;
    } catch (e) {
      debugPrint('[TelemetryUpload] Error: $e');
      return false;
    }
  }

  /// 聚合事件：合并相同类型的重复事件
  List<Map<String, dynamic>> _aggregateEvents(List<Map<String, dynamic>> events) {
    // 对于 PV、点击等高频事件，按 (eventName, page, 1分钟窗口) 聚合
    final aggregated = <String, Map<String, dynamic>>{};

    for (final event in events) {
      final name = event['event_name'] as String;
      final timestamp = event['timestamp'] as int;
      final minuteKey = timestamp ~/ 60000; // 1分钟窗口
      final key = '${name}_${minuteKey}';

      if (aggregated.containsKey(key)) {
        // 增加计数
        aggregated[key]!['count'] = (aggregated[key]!['count'] as int) + 1;
      } else {
        aggregated[key] = {
          'eventName': name,
          'timestamp': timestamp,
          'count': 1,
          'properties': jsonDecode(event['properties'] as String? ?? '{}'),
        };
      }
    }

    return aggregated.values.toList();
  }

  String _generateBatchId() {
    return '${DateTime.now().millisecondsSinceEpoch}-${DateTime.now().microsecond}';
  }
}
```

```dart
import 'dart:io';

/// 资源包后台下载处理器
///
/// 与资源包下载管理器集成，在后台闲时预下载课程资源。
class ResourceDownloadTaskHandler extends BackgroundTaskHandler {
  @override
  int get maxRetries => 3;

  final ResourceDownloadManager _downloadManager;
  final ApiClient _apiClient;

  ResourceDownloadTaskHandler({
    required ResourceDownloadManager downloadManager,
    required ApiClient apiClient,
  })  : _downloadManager = downloadManager,
        _apiClient = apiClient;

  Future<bool> execute(Map<String, dynamic> inputData) async {

      // 1. 查询待下载的资源包列表

        '/api/v1/resources/pending',
        queryParameters: {
          'deviceId': await _getDeviceId(),
          'maxSize': 50 * 1024 * 1024, // 单个资源包最大 50MB
        },
        timeout: const Duration(seconds: 10),
      );

      if (response.statusCode != 200) return false;

      final resources = (response.data['resources'] as List<dynamic>)
          .cast<Map<String, dynamic>>();

      if (resources.isEmpty) return true;

      // 2. 按优先级排序（用户最近学习的科目优先）
      resources.sort((a, b) =>
          (a['priority'] as int).compareTo(b['priority'] as int));

      // 3. 逐个下载（支持断点续传）
      for (final resource in resources) {
        final success = await _downloadManager.downloadInBackground(
          resourceId: resource['id'] as String,
          url: resource['url'] as String,
          expectedMd5: resource['md5'] as String?,
          expectedSize: resource['size'] as int?,
          headers: {
            'Authorization': 'Bearer ${await _getToken()}',
          },
        );

        if (!success) {
          // 单个下载失败不阻塞后续，继续下载下一个
          continue;

        // 4. 下载完成后通知服务端

          '/api/v1/resources/confirm',
          body: {
            'resourceId': resource['id'],
            'status': 'downloaded',
          },
        );
      }

      return true;
    } catch (e) {
      debugPrint('[ResourceDownload] Error: $e');
      return false;
    }
  }
```

### 5.5 TokenRefreshHandler

```dart
/// Token 静默刷新处理器
class TokenRefreshHandler extends BackgroundTaskHandler {
  final TokenStorage _tokenStorage;
  final ApiClient _apiClient;

  TokenRefreshHandler({
    required TokenStorage tokenStorage,
    required ApiClient apiClient,
  })  : _tokenStorage = tokenStorage,
        _apiClient = apiClient;

  @override
  Future<bool> execute(Map<String, dynamic> inputData) async {
    try {
      final currentToken = await _tokenStorage.getAccessToken();
      final refreshToken = await _tokenStorage.getRefreshToken();

      if (currentToken == null || refreshToken == null) {
        return true; // 未登录，无需刷新
      }

      // 检查 Token 是否即将过期
      final expiry = await _tokenStorage.getTokenExpiry();
      if (expiry != null &&
          expiry.difference(DateTime.now()).inMinutes > 10) {
        return true; // Token 仍然有效，无需刷新
      }

      // 执行刷新
      final response = await _apiClient.post(
        '/api/v1/auth/refresh',
        body: {'refreshToken': refreshToken},
        timeout: const Duration(seconds: 5),
      );

      if (response.statusCode == 200) {
        final data = response.data as Map<String, dynamic>;
        await _tokenStorage.saveTokens(
          accessToken: data['accessToken'] as String,
          refreshToken: data['refreshToken'] as String? ?? refreshToken,
          expiry: DateTime.now().add(
            Duration(seconds: data['expiresIn'] as int),
          ),
        );
        return true;
      }

      if (response.statusCode == 401) {
        // Refresh Token 失效，需要重新登录
        await _tokenStorage.clearTokens();
        return true; // 不重试
      }

      return false;
    } catch (e) {
      debugPrint('[TokenRefresh] Error: $e');
      return false;
    }
  }
}
```

```dart
/// 推送数据处理与后台任务调度集成
class PushDataProcessor {
  final BackgroundTaskScheduler _scheduler;

  PushDataProcessor({required BackgroundTaskScheduler scheduler})
      : _scheduler = scheduler;

  /// 处理收到的远程推送数据
  ///
  /// [contentAvailable] iOS content-available 标志
  /// [data] 推送 payload
  Future<void> processPushData({
    required bool contentAvailable,
    required Map<String, dynamic> data,
  }) async {
    final action = data['action'] as String?;

    switch (action) {
      case 'sync_required':
        // 服务端有新数据，触发同步
        await _scheduler.registerOneOffTask(
          type: BackgroundTaskType.dataSync,
          initialDelay: Duration.zero,
          networkConstraint: NetworkConstraint.connected,
          batteryConstraint: BatteryConstraint.none,
          timeout: const Duration(seconds: 10),
        );
        break;

      case 'resource_ready':
        // 资源包已准备好，触发下载
        await _scheduler.registerOneOffTask(
          type: BackgroundTaskType.resourceDownload,
          initialDelay: Duration.zero,
          networkConstraint: NetworkConstraint.unmetered,
          batteryConstraint: BatteryConstraint.charging,
          timeout: const Duration(minutes: 30),
        );
        break;

      case 'reminder':
        // 学习提醒，触发预处理
        await _scheduler.registerOneOffTask(
          type: BackgroundTaskType.reminderPreprocess,
          initialDelay: Duration.zero,
          networkConstraint: NetworkConstraint.connected,
          batteryConstraint: BatteryConstraint.none,
          timeout: const Duration(seconds: 5),
        );
        break;

      case 'token_refresh':
        // Token 即将过期
        await _scheduler.registerOneOffTask(
          type: BackgroundTaskType.tokenRefresh,
          initialDelay: Duration.zero,
          networkConstraint: NetworkConstraint.connected,
          batteryConstraint: BatteryConstraint.none,
          timeout: const Duration(seconds: 5),
        );
        break;

      default:
        // 未知推送类型，忽略
        break;
    }
  }
}
```

```dart
class QuizLifecycleListener extends AppLifecycleListener {
  @override
  String get listenerId => 'QuizLifecycle';

  @override
  int get priority => 30; // 较高优先级，计时器需准确处理

  final QuizTimerManager _timerManager;
  final QuizRepository _repository;

  QuizLifecycleListener({
    required QuizTimerManager timerManager,
    required QuizRepository repository,
  })  : _timerManager = timerManager,
        _repository = repository;

  @override
  void onBackground(AppLifecycleTransition transition) {
    final activeQuiz = _repository.getActiveQuiz();
    if (activeQuiz == null) return;

    // 保存当前答题状态
    _repository.saveProgress(activeQuiz);

    if (activeQuiz.isTimed) {
      // 限时模式：记录进入后台的真实时间戳
      // 后台不暂停计时，恢复时根据真实经过时间计算
      _timerManager.recordBackgroundTimestamp(
        remainingSeconds: activeQuiz.remainingSeconds,
        backgroundTimestamp: transition.timestamp,
      );
    } else {
      // 非限时模式：暂停计时器
      _timerManager.pause();
    }
  }

  @override
  void onForeground(AppLifecycleTransition transition) {
    final activeQuiz = _repository.getActiveQuiz();
    if (activeQuiz == null) return;

    if (activeQuiz.isTimed && transition.backgroundDuration != null) {
      // 限时模式：计算真实经过时间，不补时
      final elapsed = transition.backgroundDuration!.inSeconds;
      final newRemaining = activeQuiz.remainingSeconds! - elapsed;

      if (newRemaining <= 0) {
        // 考试时间已耗尽
        _timerManager.handleTimeUp();
      } else {
        // 恢复计时器（使用更新后的剩余时间）
        _timerManager.resume(remainingSeconds: newRemaining);
      }
    } else {
      // 非限时模式：恢复计时器
      // 补时策略：恢复时加上后台经过的时间，确保总学习时间准确
      if (transition.backgroundDuration != null &&
          transition.backgroundDuration! <= const Duration(minutes: 5)) {
        // 短时间后台，不补时
        _timerManager.resume();
      } else {
        // 长时间后台，重新计算
        _timerManager.resume();
      }
    }
  }
}

  int? _remainingSeconds;
  int? _backgroundTimestamp;
  Timer? _timer;

  void recordBackgroundTimestamp({
    required int remainingSeconds,
    required int backgroundTimestamp,
  }) {
    _remainingSeconds = remainingSeconds;
    _backgroundTimestamp = backgroundTimestamp;
  }

  void pause() {
    _timer?.cancel();
    _timer = null;
  }

  void resume({int? remainingSeconds}) {
    if (remainingSeconds != null) {
      _remainingSeconds = remainingSeconds;
    }
    _startCountdown();
  }

    _timer?.cancel();
    _timer = Timer.periodic(const Duration(seconds: 1), (_) {
      if (_remainingSeconds != null && _remainingSeconds! > 0) {
        _remainingSeconds = _remainingSeconds! - 1;
      } else {
        _timer?.cancel();
        handleTimeUp();
      }
    });
  }

    // 通知 UI 层考试时间到
  }
```

```dart
/// 同步队列管理器
class SyncQueueManager {
  final Database _db;

  SyncQueueManager({required Database db}) : _db = db;

  /// 入队
  Future<void> enqueue({
    required String recordType,
    required Map<String, dynamic> payload,
    required SyncPriority priority,
  }) async {
    await _db.insert('sync_queue', {
      'id': _generateId(),
      'record_type': recordType,
      'payload': jsonEncode(payload),
      'priority': priority.priority,
      'status': 'pending',
      'retry_count': 0,
      'created_at': DateTime.now().millisecondsSinceEpoch,
      'device_id': await _getDeviceId(),
    });
  }

  /// 获取待处理队列
  Future<List<SyncQueueItem>> getPendingQueue({int limit = 100}) async {
    final rows = await _db.query(
      'sync_queue',
      where: 'status = ? AND (next_retry_at IS NULL OR next_retry_at <= ?)',
      whereArgs: ['pending', DateTime.now().millisecondsSinceEpoch],
      orderBy: 'priority DESC, created_at ASC',
      limit: limit,
    );
    return rows.map((r) => SyncQueueItem.fromMap(r)).toList();
  }

  /// 清理已同步和过期记录
  Future<void> cleanup() async {
    // 删除已同步的记录
    await _db.delete('sync_queue', where: 'status = ?', whereArgs: ['synced']);

    // 删除超过7天的失败记录
    final cutoff = DateTime.now()
        .subtract(const Duration(days: 7))
        .millisecondsSinceEpoch;
    await _db.delete(
      'sync_queue',
      where: 'status = ? AND created_at < ?',
      whereArgs: ['failed', cutoff],
    );
  }

  String _generateId() => '${DateTime.now().millisecondsSinceEpoch}-${DateTime.now().microsecond}';
  Future<String> _getDeviceId() async => 'default';
}
```

### 10.1 后台任务失败重试策略

```dart
/// 重试策略配置
class RetryPolicy {
  /// 最大重试次数
  final int maxRetries;

  /// 基础延迟
  final Duration baseDelay;

  /// 最大延迟
  final Duration maxDelay;

  /// 退避倍数
  final double backoffMultiplier;

  /// 添加随机抖动
  final bool withJitter;

  const RetryPolicy({
    this.maxRetries = 3,
    this.baseDelay = const Duration(seconds: 30),
    this.maxDelay = const Duration(minutes: 30),
    this.backoffMultiplier = 2.0,
    this.withJitter = true,
  });

  /// 计算第 N 次重试的延迟
  Duration delayForAttempt(int attempt) {
    var delayMs = baseDelay.inMilliseconds *
        (backoffMultiplier * attempt).toInt();
    if (withJitter) {
      delayMs += (delayMs * 0.1 * (DateTime.now().microsecond % 10)).toInt();
    }
    return Duration(
      milliseconds: delayMs.clamp(0, maxDelay.inMilliseconds),
    );
  }
}
```

### 10.2 状态恢复失败降级

```dart
/// 状态恢复失败处理
class StateRecoveryFallback {
  /// 尝试恢复，失败则降级到首页
  Future<void> recoverOrFallback(
    AppStateSnapshot? snapshot,
    String currentVersion,
  ) async {
    if (snapshot == null) {
      _navigateToHome();
      return;
    }

    try {
      final decision = StatePreservationManager().shouldRecover(snapshot, currentVersion);

      switch (decision) {
        case RecoveryDecision.fullRecovery:
          await _attemptFullRecovery(snapshot);
          break;
        case RecoveryDecision.partialRecovery:
          await _attemptPartialRecovery(snapshot);
          break;
        case RecoveryDecision.promptRecovery:
          _showRecoveryPrompt(snapshot);
          break;
        case RecoveryDecision.noRecovery:
        case RecoveryDecision.versionMismatch:
          _navigateToHome();
          break;
      }
    } catch (e) {
      debugPrint('[StateRecovery] Failed: $e, falling back to home');
      _navigateToHome();
    }
  }

  Future<void> _attemptFullRecovery(AppStateSnapshot snapshot) async {
    // 恢复路由栈
    // 如果恢复失败（如页面已下线），跳过该路由
    for (final route in snapshot.routeStack.reversed) {
      try {
        // await AppRouter.navigate(route);
      } catch (e) {
        debugPrint('[StateRecovery] Route $route failed: $e, skipping');
      }
    }
  }

  Future<void> _attemptPartialRecovery(AppStateSnapshot snapshot) async {
    // 只恢复最后一个路由 + 核心状态
    if (snapshot.routeStack.isNotEmpty) {
      final lastRoute = snapshot.routeStack.last;
      try {
        // await AppRouter.navigate(lastRoute);
      } catch (e) {
        _navigateToHome();
      }
    }
  }

  void _showRecoveryPrompt(AppStateSnapshot snapshot) {
    // 显示 Dialog：是否恢复上次学习进度？
    // 用户选择"是" → _attemptPartialRecovery
    // 用户选择"否" → _navigateToHome
  }

  void _navigateToHome() {
    // 导航到首页
  }
}
```
