# 服务端-课程标准数据库与课标条目结构化管理服务 详细设计

## 1. 概述

### 1.1 模块定位

课程标准数据库与课标条目结构化管理服务（CurriculumStandardService）是 PrimeTop 教育内容体系的基座服务。它负责：

- 结构化存储国家教育部颁布的《义务教育课程方案和课程标准（2022年版）》及《普通高中课程方案和课程标准（2017年版2020年修订）》等权威文件。
- 将课标文档拆解为可查询、可引用、可对齐的条目数据库（学段 → 学科 → 主题群 → 主题 → 核心素养 → 具体条目）。
- 为题目标注、教材对齐、内容审核、学情分析等上游服务提供统一的课标条目查询接口。
- 管理课标版本迭代（如 2011 版 → 2022 版），支持版本间差异对比和内容迁移。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 课标数据建模 | 将非结构化的课标文档转化为结构化的层次化数据模型。 |
| 课标条目管理 | 条目的增删改查、批量导入、结构化标注。 |
| 核心素养管理 | 维护各学科定义的核心素养维度及其描述。 |
| 学业质量标准 | 管理课标中的学业质量水平描述（如水平一至水平五）。 |
| 版本管理 | 课标版本的创建、发布、归档与版本间差异对比。 |
| 外部映射 | 课标条目与知识点、教材章节、考点的映射关系管理。 |
| 查询服务 | 提供多维度检索（按学段、学科、核心素养、关键词等）。 |

### 1.3 目标用户

| 用户 | 使用场景 |
|------|----------|
| 内容教研团队 | 录入和维护课标条目，标注核心素养 |
| 题目/内容生产 | 检索课标条目，为内容和题目打上课标标签 |
| AI 对齐引擎 | 自动将学习内容与课标条目匹配 |
| 学情分析服务 | 基于课标维度评估学生能力 |
| 管理后台 | 可视化浏览和管理课标数据库 |

### 1.4 依赖关系

```text
教育部课标文档（PDF/Word原始文件）
        |
    课标导入与解析管线
        |
    CurriculumStandardService（本服务）
        |
    +-----------+-----------+-----------+-----------+
    |           |           |           |           |
  题目服务   内容服务   学情分析   AI对齐引擎  教材映射
  (课标标注)  (内容对齐)  (素养评估)  (自动匹配)  (章节关联)
```

**上游依赖：**
- 教育部官方课标文档：权威数据源。
- 学科与科目基础数据管理：提供学段、学科编码体系。

**下游消费方：**
- 题目服务：题目知识点自动标注与课标对齐引擎。
- 内容服务：教材课标对齐度分析与内容覆盖率统计。
- AI 服务：Prompt 编排中注入课标要求。
- 学情分析：核心素养评估与学科能力维度分析。
- 教材版本与章节管理服务：章节到课标条目的映射。

## 2. 数据模型

### 2.1 核心实体定义

| 实体 | 英文 | 说明 |
|------|------|------|
| 课标版本 | CurriculumStandardVersion | 一份完整的课程标准发布版本（如"义务教育数学课程标准 2022年版"）。 |
| 学科课标 | SubjectCurriculum | 某版本下某学科的课标主体。 |
| 主题群 | ThemeGroup | 学科课标下的一级分类（如数学中的"数与代数""图形与几何"）。 |
| 主题 | Theme | 主题群下的二级分类（如"数与代数"下的"数的认识""数的运算"等）。 |
| 核心素养 | CoreCompetency | 学科定义的核心素养维度（如数学核心素养：数学抽象、逻辑推理、数学建模等）。 |
| 课标条目 | StandardItem | 课标中最小的可引用单元，包含具体的 content requirements（内容要求）和学业要求。 |
| 学业质量水平 | ProficiencyLevel | 课标中定义的学业质量等级描述。 |
| 课标映射关系 | StandardMapping | 课标条目与知识点/教材章节/考点的关联关系。 |

### 2.2 数据库表结构（DDL，MySQL 8）

```sql
-- ============================================================
-- 1. 课标版本表
-- ============================================================
CREATE TABLE `curriculum_standard_version` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    `version_code` VARCHAR(64) NOT NULL COMMENT '版本编码，如 CS-MATH-2022',
    `title` VARCHAR(256) NOT NULL COMMENT '课标全称',
    `stage` VARCHAR(16) NOT NULL COMMENT '学段：PRIMARY/JUNIOR/SENIOR',
    `subject_code` VARCHAR(32) NOT NULL COMMENT '学科编码',
    `publisher` VARCHAR(128) NOT NULL DEFAULT '中华人民共和国教育部' COMMENT '发布机构',
    `publish_date` DATE NOT NULL COMMENT '发布日期',
    `effective_date` DATE NOT NULL COMMENT '生效日期',
    `doc_url` VARCHAR(512) COMMENT '原始文档URL（对象存储）',
    `status` VARCHAR(16) NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT/PUBLISHED/ARCHIVED',
    `previous_version_id` BIGINT UNSIGNED COMMENT '上一版本ID（用于版本链）',
    `description` TEXT COMMENT '版本说明',
    `created_by` BIGINT UNSIGNED NOT NULL,
    `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_version_code` (`version_code`),
    KEY `idx_stage_subject` (`stage`, `subject_code`),
    KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课标版本';

-- ============================================================
-- 2. 学科课标表
-- ============================================================
CREATE TABLE `subject_curriculum` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    `version_id` BIGINT UNSIGNED NOT NULL COMMENT '课标版本ID',
    `subject_code` VARCHAR(32) NOT NULL COMMENT '学科编码',
    `stage` VARCHAR(16) NOT NULL COMMENT '学段',
    `total_hours` INT UNSIGNED COMMENT '总课时数',
    `overview` TEXT COMMENT '课程性质与基本理念',
    `design_principles` TEXT COMMENT '课程设计思路',
    `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),

-- ============================================================
-- 3. 核心素养表

    UNIQUE KEY `uk_version_subject_comp` (`version_id`, `competency_code`),

    CONSTRAINT `fk_cc_version` FOREIGN KEY (`version_id`) REFERENCES `curriculum_standard_version`(`id`)

-- ============================================================
-- 4. 主题群表
-- ============================================================
CREATE TABLE `theme_group` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    `version_id` BIGINT UNSIGNED NOT NULL,
    `subject_code` VARCHAR(32) NOT NULL,

    `name` VARCHAR(128) NOT NULL COMMENT '名称，如"数与代数"',
    `description` TEXT,
    `grade_range` VARCHAR(32) COMMENT '适用年级范围，如 1-3',
    `display_order` INT UNSIGNED NOT NULL DEFAULT 0,
    `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    PRIMARY KEY (`id`),

    KEY `idx_version_subject` (`version_id`, `subject_code`),
    CONSTRAINT `fk_tg_version` FOREIGN KEY (`version_id`) REFERENCES `curriculum_standard_version`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课标主题群';

-- ============================================================
-- 5. 主题表
-- ============================================================
CREATE TABLE `theme` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    `group_id` BIGINT UNSIGNED NOT NULL COMMENT '所属主题群ID',
    `theme_code` VARCHAR(64) NOT NULL COMMENT '主题编码',
    `name` VARCHAR(128) NOT NULL COMMENT '名称，如"数的认识"',
    `description` TEXT,
    `grade_range` VARCHAR(32) COMMENT '适用年级范围',

    `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_group_theme_code` (`group_id`, `theme_code`),
    KEY `idx_group` (`group_id`),
    CONSTRAINT `fk_theme_group` FOREIGN KEY (`group_id`) REFERENCES `theme_group`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课标主题';

-- ============================================================
-- 6. 课标条目表（核心表）
-- ============================================================
CREATE TABLE `standard_item` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    `version_id` BIGINT UNSIGNED NOT NULL COMMENT '课标版本ID',
    `subject_code` VARCHAR(32) NOT NULL COMMENT '学科编码',
    `stage` VARCHAR(16) NOT NULL COMMENT '学段',
    `theme_id` BIGINT UNSIGNED COMMENT '所属主题ID',
    `theme_group_id` BIGINT UNSIGNED COMMENT '所属主题群ID（冗余，方便查询）',
    `item_code` VARCHAR(128) NOT NULL COMMENT '条目编码，如 CS-MATH-2022-NA-NUM-001',
    `item_type` VARCHAR(32) NOT NULL COMMENT 'CONTENT_REQUIREMENT/ACADEMIC_REQUIREMENT/TEACHING_SUGGESTION/EVALUATION_CRITERION',
    `title` VARCHAR(256) NOT NULL COMMENT '条目标题',
    `content` TEXT NOT NULL COMMENT '条目正文内容',
    `grade_range` VARCHAR(32) COMMENT '适用年级，如 1-2 / 7 / 高一',
    `semester` VARCHAR(16) COMMENT '建议学期：FIRST/SECOND',
    `competency_ids` JSON COMMENT '关联核心素养ID数组',
    `difficulty_level` VARCHAR(16) COMMENT '认知层次：KNOW/UNDERSTAND/APPLY/ANALYZE/EVALUATE/CREATE',
    `keywords` JSON COMMENT '关键词数组，用于检索',
    `parent_item_id` BIGINT UNSIGNED COMMENT '父条目ID（条目可嵌套）',
    `display_order` INT UNSIGNED NOT NULL DEFAULT 0,
    `source_reference` VARCHAR(256) COMMENT '原文引用位置（页码/章节号）',
    `status` VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/DEPRECATED',
    `created_by` BIGINT UNSIGNED NOT NULL,
    `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_item_code` (`item_code`),
    KEY `idx_version_subject` (`version_id`, `subject_code`),
    KEY `idx_theme` (`theme_id`),
    KEY `idx_stage_grade` (`stage`, `grade_range`),
    KEY `idx_type` (`item_type`),
    KEY `idx_parent` (`parent_item_id`),
    FULLTEXT KEY `ft_content` (`title`, `content`),
    CONSTRAINT `fk_si_version` FOREIGN KEY (`version_id`) REFERENCES `curriculum_standard_version`(`id`),
    CONSTRAINT `fk_si_theme` FOREIGN KEY (`theme_id`) REFERENCES `theme`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课标条目';

-- ============================================================
-- 7. 学业质量水平表
-- ============================================================
CREATE TABLE `proficiency_level` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,

    PRIMARY KEY (`id`),

    KEY `idx_target` (`target_type`, `target_id`),

    CONSTRAINT `fk_sm_item` FOREIGN KEY (`standard_item_id`) REFERENCES `standard_item`(`id`)

```

### 2.3 缓存策略

| 缓存键 | TTL | 说明 |
|--------|-----|------|
| `cs:version:active:{stage}:{subject}` | 24h | 当前生效版本缓存 |
| `cs:tree:{versionId}:{subjectCode}` | 6h | 完整学科课标树结构 |
| `cs:item:{itemId}` | 2h | 单条目详情缓存 |
| `cs:competency:{versionId}:{subjectCode}` | 12h | 核心素养列表缓存 |
| `cs:mappings:{itemId}:{targetType}` | 4h | 条目映射关系缓存 |
| `cs:search:{versionId}:{queryHash}` | 30min | 搜索结果缓存 |

缓存失效策略：
- 课标版本发布/归档时，批量清除该版本所有缓存。
- 条目更新时，清除该条目及所属树结构缓存。
- 映射关系变更时，清除相关条目的映射缓存。
