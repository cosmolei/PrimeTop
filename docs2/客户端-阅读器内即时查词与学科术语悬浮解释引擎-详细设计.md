# 客户端-阅读器内即时查词与学科术语悬浮解释引擎-详细设计

## 1. 概述

### 1.1 功能定位

阅读器内即时查词与学科术语悬浮解释引擎（以下简称"即时查词引擎"）是 PrimeTop 客户端学习内容阅读器的核心增强组件。当学生在阅读课文、英语文章、古诗文、理科教材等内容时，通过点击/长按/拖选文本中的词语或短语，即可在当前位置弹出悬浮解释卡片，快速获得：

- **词语释义**：中文词语含义、成语典故
- **英文翻译**：单词释义、音标、例句
- **文言文解析**：古汉语字词的现代汉语翻译
- **学科术语**：数学/物理/化学/生物等专业术语的适龄解释
- **发音播放**：英语单词发音、中文朗读
- **生词收藏**：一键加入生词本/词汇表

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 即时性 | 查词响应时间 ≤ 300ms（本地缓存命中）, ≤ 800ms（网络请求） |
| 零干扰 | 悬浮卡片不遮挡阅读内容主体，支持快速关闭 |
| 上下文感知 | 根据当前学科、学段、年级返回适龄化解释 |
| 离线可用 | 高频词汇释义本地缓存，无网络时仍可查词 |
| 可扩展 | 支持后续接入更多词典源（成语词典、古汉语词典等） |

### 1.3 适用范围

| 场景 | 说明 |
| --- | --- |
| 同步课堂阅读 | 课文正文中的生字词、术语 |
| 英语阅读理解 | 文章中的生词 |
| 古诗文学习 | 文言文字词的现代汉语释义 |
| 理科教材学习 | 专业术语、公式符号说明 |
| 作文范文阅读 | 好词好句的释义和用法 |
| 错题/题目阅读 | 题干中的生词和术语 |

### 1.4 依赖关系

```
本模块
  ├── 依赖: 服务端-教育学科术语词典与智能词汇表自动构建管理引擎（术语数据源）
  ├── 依赖: 英语词汇记忆与单词本系统（生词本同步）
  ├── 依赖: 语音服务(ASR-TTS)（发音播放）
  ├── 依赖: 客户端-学习内容阅读器内批注与高亮系统（位置关联）
  ├── 依赖: 客户端-互动教材阅读器与课文点读学习组件（宿主容器）
  └── 依赖: 客户端本地持久层与数据管理（本地缓存）
```

## 2. 用户交互设计

### 2.1 触发方式

| 触发方式 | 适用场景 | 交互细节 |
| --- | --- | --- |
| **单击词语** | 中文课文、英语文章 | 点击文本中的单个词语，自动进行中文分词或英文单词边界识别 |
| **长按词语** | 所有场景 | 长按 500ms 触发，显示选择菜单（查词/复制/批注/高亮） |
| **拖拽选择** | 短语、句子 | 拖动选择手柄扩大选区，支持选择 2-20 个字的文本段 |
| **双击词语** | 英语阅读 | 快速双击英文单词，直接弹出释义卡片 |

### 2.2 交互流程

```
用户阅读内容
    │
    ├── 点击/长按/拖选词语
    │
    ▼
文本选择与词语识别
    │
    ├── 识别选中词或短语
    │   ├── 中文: 分词处理 → 提取词语/成语
    │   ├── 英文: 单词边界识别 → 提取 word/phrase
    │   └── 文言文: 字词切分 → 单字/词组
    │
    ▼
弹出加载态悬浮卡片
    │
    ├── 本地缓存命中? ── 是 ──▶ 直接渲染释义
    │                   否
    ▼
请求查词 API
    │
    ├── 请求成功 ──▶ 渲染释义卡片
    │   │              ├── 显示释义/翻译/音标
    │   │              ├── 显示词性、例句
    │   │              ├── 显示学科术语标签（如有）
    │   │              ├── 播放发音按钮
    │   │              └── 收藏到生词本按钮
    │   │
    │   └── 请求失败 ──▶ 显示"暂未收录该词" + 反馈入口
    │
    ▼
用户操作
    ├── 点击空白区域 / 返回键 → 关闭卡片
    ├── 点击"查看更多" → 展开详细释义页面
    ├── 点击 🔊 → 播放发音
    ├── 点击 ☆ → 收藏到生词本
    └── 点击"查看例句" → 跳转到例句列表
```

## 3. 数据结构定义

### 3.1 客户端数据模型

#### 3.1.1 词语查询请求 (LookupRequest)

```dart
/// 查词请求模型
class LookupRequest {
  final String query;          // 查询的词语
  final String normalizedQuery;// 标准化后的词语（小写、去标点等）
  final LookupType type;       // 查词类型
  final Subject subject;       // 当前学科上下文
  final GradeLevel grade;      // 当前年级
  final String? contentId;     // 当前阅读内容 ID（用于上下文感知）
  final String? sentenceContext; // 词语所在句子（用于消歧）
  final bool forceRefresh;     // 是否强制刷新缓存
}

enum LookupType {
  singleChar,      // 单字（文言文常用）
  word,            // 词语
  phrase,          // 短语
  idiom,           // 成语
  englishWord,     // 英文单词
  englishPhrase,   // 英文短语
  terminology,     // 学科术语
  symbol,          // 符号/公式
}
```

#### 3.1.2 词语查询结果 (LookupResult)

```dart
/// 查词结果模型
class LookupResult {
  final String word;            // 词语
  final String pinyin;          // 拼音（中文）
  final String? phoneticUs;     // 美式音标（英文）
  final String? phoneticUk;     // 英式音标（英文）
  final String? audioUrlUs;     // 美式发音音频 URL
  final String? audioUrlUk;     // 英式发音音频 URL
  final List<DefinitionEntry> definitions; // 释义列表
  final List<ExampleSentence> examples;    // 例句列表
  final List<String> tags;      // 标签：学科、年级、词频等
  final String? etymology;      // 词源（可选）
  final String? source;         // 出处（成语/古诗文）
  final List<RelatedWord>? synonyms;     // 近义词
  final List<RelatedWord>? antonyms;     // 反义词
  final bool isTerminology;     // 是否为学科术语
  final TerminologyInfo? terminologyInfo; // 术语详细信息
  final LookupSource source;    // 结果来源：cache / remote
  final int cacheExpireAt;      // 缓存过期时间戳
}

/// 释义条目
class DefinitionEntry {
  final String partOfSpeech;   // 词性：n. / v. / adj. / 【成语】等
  final String definition;     // 释义文本
  final List<String>? fields;  // 学科领域标签
  final int difficulty;        // 难度等级 1-5
}

/// 例句
class ExampleSentence {
  final String sentence;       // 例句原文
  final String translation;    // 翻译（英文例句需要）
  final String? source;        // 例句来源
  final bool isClassicExample; // 是否为经典例句
}

/// 术语信息
class TerminologyInfo {
  final String subject;        // 所属学科
  final String chapter;        // 关联章节
  final String gradeRange;     // 适用年级范围
  final String definition;     // 术语定义
  final String? formula;       // 关联公式（如适用）
  final String? relatedConcepts; // 关联概念
}

class RelatedWord {
  final String word;
  final String? difference;    // 与原词的差异说明
}

enum LookupSource { localCache, remoteAPI, offline }
```

#### 3.1.3 生词本条目 (VocabularyEntry)

```dart
/// 生词本条目（与生词本系统共用）
class VocabularyEntry {
  final String id;              // 条目 ID

  final String subject;         // 学科

  final String? note;           // 用户笔记

enum VocabularyType { chinese, english, classical, terminology }

```

### 3.2 本地缓存数据结构

#### 3.2.1 查词缓存表 (word_lookup_cache)

```sql
CREATE TABLE IF NOT EXISTS word_lookup_cache (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  query_key       TEXT NOT NULL,          -- 查询键: type|subject|grade|normalizedQuery
  query_text      TEXT NOT NULL,          -- 原始查询词语
  lookup_type     TEXT NOT NULL,          -- 查词类型
  subject         TEXT NOT NULL,          -- 学科上下文
  grade           TEXT NOT NULL,          -- 年级
  result_json     TEXT NOT NULL,          -- 完整结果 JSON
  hit_count       INTEGER DEFAULT 1,      -- 命中次数
  created_at      INTEGER NOT NULL,       -- 创建时间戳(ms)
  last_accessed   INTEGER NOT NULL,       -- 最后访问时间戳(ms)
  expire_at       INTEGER NOT NULL,       -- 过期时间戳(ms)
  UNIQUE(query_key)
);

-- 索引
CREATE INDEX IF NOT EXISTS idx_cache_query_key ON word_lookup_cache(query_key);
CREATE INDEX IF NOT EXISTS idx_cache_last_accessed ON word_lookup_cache(last_accessed);
CREATE INDEX IF NOT EXISTS idx_cache_expire ON word_lookup_cache(expire_at);
```

#### 3.2.2 生词收藏记录表 (vocabulary_collection)

```sql
CREATE TABLE IF NOT EXISTS vocabulary_collection (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  entry_id        TEXT NOT NULL UNIQUE,    -- 条目 ID (UUID)
  word            TEXT NOT NULL,           -- 词语
  vocab_type      TEXT NOT NULL,           -- 类型: chinese/english/classical/terminology
  subject         TEXT NOT NULL,           -- 学科
  content_id      TEXT,                    -- 来源内容 ID
  context_sentence TEXT,                   -- 收藏时的上下文
  note            TEXT,                    -- 用户笔记
  collected_at    INTEGER NOT NULL,        -- 收藏时间(ms)
  sync_status     TEXT DEFAULT 'pending',  -- 同步状态: pending/synced/conflict
  created_at      INTEGER NOT NULL,
  updated_at      INTEGER NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_vocab_word ON vocabulary_collection(word);
CREATE INDEX IF NOT EXISTS idx_vocab_subject ON vocabulary_collection(subject);
CREATE INDEX IF NOT EXISTS idx_vocab_sync ON vocabulary_collection(sync_status);
```

### 4.1 统一查词接口

**POST** `/api/v1/dictionary/lookup`

```json
{
  "query": "邯郸学步",
  "type": "idiom",
  "subject": "chinese",
  "grade": "grade_5",
  "content_id": "chapter_2024_renjiaban_5a_unit2",
  "sentence_context": "你这简直是邯郸学步，不仅没学到别人的长处，反而丢了自己的特色。",
  "force_refresh": false
```

| --- | --- | --- | --- |

| sentence_context | string | 否 | 词语所在原句，用于多义词消歧 |

### 4.6 错误码定义

| 错误码 | 含义 | 处理策略 |

| 0 | 成功 | — |
| 4001 | 词语未收录 | 显示"暂未收录"，提供反馈入口 |
| 4002 | 查询参数无效 | 客户端参数校验，不发请求 |
| 4003 | 术语不存在于指定学科 | 尝试通用词典查询 |

| 4006 | 生词本已存在该词 | 提示已收藏，不重复添加 |

```dart
/// 查词引擎主控制器
class LookupController extends ChangeNotifier {
  final CacheService _cacheService;
  final RemoteLookupService _remoteService;
  final AudioService _audioService;
  final VocabularyService _vocabService;
  final ContextResolver _contextResolver;

  LookupController({
    required CacheService cacheService,
    required RemoteLookupService remoteService,
    required AudioService audioService,
    required VocabularyService vocabService,
    required ContextResolver contextResolver,
  })  : _cacheService = cacheService,
        _remoteService = remoteService,
        _audioService = audioService,
        _vocabService = vocabService,
        _contextResolver = contextResolver;

  LookupState _state = LookupState.idle;
  LookupResult? _currentResult;
  String? _errorMessage;

  LookupState get state => _state;
  LookupResult? get currentResult => _currentResult;
  String? get errorMessage => _errorMessage;

  /// 主查词入口
  Future<void> lookup(LookupRequest request) async {
    _state = LookupState.loading;
    _errorMessage = null;
    notifyListeners();

    try {
      // 1. 上下文增强：根据当前阅读内容补充请求信息
      final enrichedRequest = await _contextResolver.enrich(request);

      // 2. 先查本地缓存
      final cached = await _cacheService.get(enrichedRequest.cacheKey);
      if (cached != null && !enrichedRequest.forceRefresh) {
        _currentResult = cached;
        _state = LookupState.success;
        notifyListeners();
        // 后台静默刷新（缓存快过期时）
        if (cached.shouldRefresh) {
          _silentRefresh(enrichedRequest);
        }
        return;
      }

      // 3. 调用远程接口
      final result = await _remoteService.lookup(enrichedRequest);

      // 4. 写入缓存
      await _cacheService.put(enrichedRequest.cacheKey, result);

      _currentResult = result;
      _state = LookupState.success;
      notifyListeners();
    } on ApiException catch (e) {
      if (e.code == 4001) {
        _state = LookupState.notFound;
        _errorMessage = '暂未收录该词';
      } else if (e.code == 4005) {
        // 服务降级：尝试返回缓存中最接近的结果
        final fallback = await _cacheService.fuzzyMatch(request.query);
        if (fallback != null) {
          _currentResult = fallback;
          _state = LookupState.successDegraded;
        } else {
          _state = LookupState.error;
          _errorMessage = '词典服务暂时不可用';
        }
      } else {
        _state = LookupState.error;
        _errorMessage = e.message;
      }
      notifyListeners();
    } catch (e) {
      _state = LookupState.error;
      _errorMessage = '查询失败，请稍后重试';
      notifyListeners();
    }
  }

  /// 静默刷新缓存
  Future<void> _silentRefresh(LookupRequest request) async {
    try {
      final result = await _remoteService.lookup(request);
      await _cacheService.put(request.cacheKey, result);
    } catch (_) {
      // 静默刷新失败不影响用户体验
    }
  }

  /// 播放发音
  Future<void> playPronunciation(AudioType type) async {
    if (_currentResult == null) return;
    final url = type == AudioType.us
        ? _currentResult!.audioUrlUs
        : _currentResult!.audioUrlUk;
    if (url != null) {
      await _audioService.play(url);
    }
  }

  /// 收藏到生词本
  Future<bool> addToVocabulary({
    String? note,
    String? contextSentence,
  }) async {
    if (_currentResult == null) return false;
    try {
      await _vocabService.collect(
        word: _currentResult!.word,
        result: _currentResult!,
        note: note,
        contextSentence: contextSentence,
      );
      return true;
    } catch (e) {
      return false;
    }
  }

  void reset() {
    _state = LookupState.idle;
    _currentResult = null;
    _errorMessage = null;
    notifyListeners();
  }
}

enum LookupState {
  idle,            // 初始/空闲
  loading,         // 查询中
  success,         // 查询成功
  successDegraded, // 降级成功（缓存/模糊匹配）
  notFound,        // 未收录
  error,           // 查询失败
}
```

```dart
/// 文本选择与词语识别处理器
class TextProcessor {
  static const int _minSelectionLength = 1;
  static const int _maxSelectionLength = 30;

  /// 根据点击位置识别词语
  LookupCandidate identifyWord({
    required String fullText,
    required int clickOffset,
    required Subject subject,
    required Locale locale,
  }) {
    if (locale == Locale.en) {
      return _identifyEnglishWord(fullText, clickOffset);
    } else {
      return _identifyChineseWord(fullText, clickOffset, subject);
    }
  }

  /// 英文单词边界识别
  LookupCandidate _identifyEnglishWord(String text, int offset) {
    // 向左查找单词起始
    int start = offset;
    while (start > 0 && _isEnglishChar(text[start - 1])) {
      start--;
    }
    // 向右查找单词结束
    int end = offset;
    while (end < text.length && _isEnglishChar(text[end])) {
      end++;
    }

    final word = text.substring(start, end).toLowerCase();
    if (word.isEmpty) {
      return LookupCandidate.empty();
    }

    // 判断是单词还是短语
    final type = word.contains(' ')
        ? LookupType.englishPhrase
        : LookupType.englishWord;

    return LookupCandidate(
      text: word,
      type: type,
      start: start,
      end: end,
    );
  }

  /// 中文分词识别
  LookupCandidate _identifyChineseWord(
    String text,
    int offset,
    Subject subject,
  ) {
    // 策略1: 优先匹配成语（4字）
    if (subject == Subject.chinese) {
      final idiom = _tryMatchIdiom(text, offset);
      if (idiom != null) return idiom;
    }

    // 策略2: 匹配已知学科术语
    final term = _terminologyMatcher.match(text, offset, subject);
    if (term != null) return term;

    // 策略3: 基础分词（2-3字词）
    final word = _segmentChinese(text, offset);
    return word;
  }

  /// 基于本地词典的中文分词
  LookupCandidate _segmentChinese(String text, int offset) {
    // 以当前字符为中心，尝试2字词、3字词、1字
    final char = text[offset];

    // 尝试2字词
    if (offset + 1 < text.length) {
      final twoChar = text.substring(offset, offset + 2);
      if (_commonWords.contains(twoChar)) {
        return LookupCandidate(
          text: twoChar,
          type: LookupType.word,
          start: offset,
          end: offset + 2,
        );
      }
    }

    // 尝试向左扩展为2字词
    if (offset > 0) {
      final twoCharLeft = text.substring(offset - 1, offset + 1);
      if (_commonWords.contains(twoCharLeft)) {
        return LookupCandidate(
          text: twoCharLeft,
          type: LookupType.word,
          start: offset - 1,
          end: offset + 1,
        );
      }
    }

    // 默认返回单字
    return LookupCandidate(
      text: char,
      type: LookupType.singleChar,
      start: offset,
      end: offset + 1,
    );
  }

  bool _isEnglishChar(String ch) {
    final code = ch.codeUnitAt(0);
    return (code >= 65 && code <= 90) || (code >= 97 && code <= 122) || ch == '\'';
  }

  LookupCandidate? _tryMatchIdiom(String text, int offset) {
    // 尝试以当前字符为起点的4字成语
    for (final len in [4, 3]) {
      final start = offset;
      final end = offset + len;
      if (end <= text.length) {
        final candidate = text.substring(start, end);
        if (_idiomSet.contains(candidate)) {
          return LookupCandidate(
            text: candidate,
            type: LookupType.idiom,
            start: start,
            end: end,
          );
        }
      }
      // 尝试以当前字符为终点
      final leftStart = offset - len + 1;
      if (leftStart >= 0) {
        final candidate = text.substring(leftStart, offset + 1);
        if (_idiomSet.contains(candidate)) {
          return LookupCandidate(
            text: candidate,
            type: LookupType.idiom,
            start: leftStart,
            end: offset + 1,
          );
        }
      }
    }
    return null;
  }
}

/// 查词候选项
class LookupCandidate {
  final String text;       // 识别到的词语
  final LookupType type;   // 词语类型
  final int start;         // 在原文中的起始位置
  final int end;           // 在原文中的结束位置

  LookupCandidate({
    required this.text,
    required this.type,
    required this.start,
    required this.end,
  });

  factory LookupCandidate.empty() => LookupCandidate(
        text: '',
        type: LookupType.word,
        start: 0,
        end: 0,
      );

  bool get isEmpty => text.isEmpty;
}
```

### 5.4 缓存管理服务

```dart
/// 查词缓存管理服务
class CacheService {
  final Database _db;           // SQLite 数据库
  final MemoryLRUCache _memory; // 内存 LRU 缓存

  static const int _maxMemoryEntries = 500;
  static const int _maxDbEntries = 10000;
  static const int _defaultExpireDays = 30;

  CacheService(this._db)
      : _memory = MemoryLRUCache(maxSize: _maxMemoryEntries);

  /// 构建缓存键
  String buildCacheKey(LookupRequest request) {
    return '${request.type}|${request.subject}|${request.grade}|${request.normalizedQuery}';
  }

  /// 获取缓存
  Future<LookupResult?> get(String key) async {
    // 1. 先查内存 LRU
    final memResult = _memory.get(key);
    if (memResult != null && !_isExpired(memResult)) {
      // 异步更新访问时间
      _updateAccessTime(key);
      return memResult;
    }

    // 2. 查 SQLite
    final rows = await _db.query(
      'word_lookup_cache',
      where: 'query_key = ? AND expire_at > ?',
      whereArgs: [key, DateTime.now().millisecondsSinceEpoch],
      limit: 1,
    );

    if (rows.isEmpty) return null;

    final result = LookupResult.fromJson(
      jsonDecode(rows.first['result_json'] as String),
    );

    // 回填内存缓存
    _memory.put(key, result);

    return result;
  }

  /// 写入缓存
  Future<void> put(String key, LookupResult result) async {
    final now = DateTime.now().millisecondsSinceEpoch;
    final expireAt = now + _defaultExpireDays * 86400000;

    // 写内存
    _memory.put(key, result);

    // 写 SQLite
    await _db.insert(
      'word_lookup_cache',
      {
        'query_key': key,
        'query_text': result.word,
        'lookup_type': '',
        'subject': '',
        'grade': '',
        'result_json': jsonEncode(result.toJson()),
        'hit_count': 1,
        'created_at': now,
        'last_accessed': now,
        'expire_at': expireAt,
      },
      conflictAlgorithm: ConflictAlgorithm.replace,
    );

    // 异步清理超额缓存
    if (await _getCacheCount() > _maxDbEntries) {
      await _evictOldEntries();
    }
  }

  /// 模糊匹配（服务降级时使用）
  Future<LookupResult?> fuzzyMatch(String query) async {
    final rows = await _db.query(
      'word_lookup_cache',
      where: 'query_text LIKE ? AND expire_at > ?',
      whereArgs: ['$query%', DateTime.now().millisecondsSinceEpoch],
      orderBy: 'hit_count DESC',
      limit: 1,
    );
    if (rows.isEmpty) return null;
    return LookupResult.fromJson(
      jsonDecode(rows.first['result_json'] as String),
    );
  }

  /// 清理过期缓存
  Future<int> cleanExpired() async {
    final now = DateTime.now().millisecondsSinceEpoch;
    return await _db.delete(
      'word_lookup_cache',
      where: 'expire_at < ?',
      whereArgs: [now],
    );
  }

  /// LRU 淘汰
  Future<int> _evictOldEntries() async {
    final deleteCount = _maxDbEntries ~/ 10; // 淘汰 10%
    return await _db.rawDelete('''
      DELETE FROM word_lookup_cache
      WHERE id IN (
        SELECT id FROM word_lookup_cache
        ORDER BY last_accessed ASC
        LIMIT ?
      )
    ''', [deleteCount]);
  }

  bool _isExpired(LookupResult result) {
    return DateTime.now().millisecondsSinceEpoch > result.cacheExpireAt;
  }

  Future<int> _getCacheCount() async {
    final result = await _db.rawQuery('SELECT COUNT(*) as count FROM word_lookup_cache');
    return result.first['count'] as int;
  }

  Future<void> _updateAccessTime(String key) async {
    final now = DateTime.now().millisecondsSinceEpoch;
    await _db.update(
      'word_lookup_cache',
      {'last_accessed': now, 'hit_count': Sqflite.intAdd(1)},
      where: 'query_key = ?',
      whereArgs: [key],
    );
  }
}

/// 内存 LRU 缓存
class MemoryLRUCache {
  final int maxSize;
  final LinkedHashMap<String, LookupResult> _map = LinkedHashMap();

  MemoryLRUCache({required this.maxSize});

  LookupResult? get(String key) {
    if (!_map.containsKey(key)) return null;
    // 移到末尾（最近使用）
    final value = _map.remove(key)!;
    _map[key] = value;
    return value;
  }

  void put(String key, LookupResult value) {
    if (_map.containsKey(key)) {
      _map.remove(key);
    } else if (_map.length >= maxSize) {
      // 移除最久未使用的
      _map.remove(_map.keys.first);
    }
    _map[key] = value;
  }
}
```

### 5.5 上下文感知处理器

```dart
/// 上下文感知处理器 — 根据当前阅读场景增强查词请求
class ContextResolver {
  final ContentMetadataService _metadataService;

  ContextResolver(this._metadataService);

  /// 增强查词请求
  Future<LookupRequest> enrich(LookupRequest request) async {
    LookupRequest enriched = request;

    // 1. 标准化查询词
    enriched = enriched.copyWith(
      normalizedQuery: _normalize(request.query, request.type),
    );

    // 2. 如果有 contentId，获取内容元数据
    if (request.contentId != null) {
      final metadata = await _metadataService.getMetadata(request.contentId!);
      if (metadata != null) {
        // 根据内容标签补充学科上下文
        if (enriched.subject == Subject.unknown) {
          enriched = enriched.copyWith(subject: metadata.subject);
        }
        // 文言文内容自动调整查词类型
        if (metadata.isClassicalChinese) {
          enriched = enriched.copyWith(
            type: _inferClassicalType(request.query),
          );
        }
      }
    }

    // 3. 基于句子上下文进行多义词消歧
    if (request.sentenceContext != null) {
      enriched = enriched.copyWith(
        sentenceContext: request.sentenceContext,
      );
    }

    return enriched;
  }

  String _normalize(String query, LookupType type) {
    switch (type) {
      case LookupType.englishWord:
      case LookupType.englishPhrase:
        return query.toLowerCase().trim();
      case LookupType.singleChar:
      case LookupType.word:
      case LookupType.phrase:
      case LookupType.idiom:
        return query.replaceAll(RegExp(r'[\s\p{P}]', unicode: true), '').trim();
      default:
        return query.trim();
    }
  }

  LookupType _inferClassicalType(String query) {
    if (query.length == 1) return LookupType.singleChar;
    if (query.length == 4) return LookupType.idiom;
    return LookupType.word;
  }
}
```

```dart
/// 悬浮卡片定位器 — 计算最优显示位置
class TooltipPositioner {
  /// 计算卡片显示位置
  static Offset calculatePosition({
    required Rect selectionRect,   // 选中文本的矩形区域
    required Size cardSize,         // 卡片尺寸
    required Size viewportSize,     // 屏幕可视区域尺寸
    required EdgeInsets padding,    // 安全边距
    double arrowHeight = 8,         // 箭头高度
  }) {
    double x, y;
    bool showBelow = true; // 默认显示在下方

    // 优先显示在选中文本下方
    double belowY = selectionRect.bottom + arrowHeight;
    double aboveY = selectionRect.top - arrowHeight - cardSize.height;

    if (belowY + cardSize.height <= viewportSize.height - padding.bottom) {
      // 下方有足够空间
      y = belowY;
      showBelow = true;
    } else if (aboveY >= padding.top) {
      // 上方有足够空间
      y = aboveY;
      showBelow = false;
    } else {
      // 上下都不够，选择空间更大的一侧
      final spaceBelow = viewportSize.height - padding.bottom - belowY;
      final spaceAbove = aboveY - padding.top;
      if (spaceBelow >= spaceAbove) {
        y = belowY;
        showBelow = true;
      } else {
        y = aboveY;
        showBelow = false;
      }
    }

    // 水平居中对齐选中文本
    x = selectionRect.center.dx - cardSize.width / 2;

    // 边界修正
    if (x < padding.left) {
      x = padding.left;
    } else if (x + cardSize.width > viewportSize.width - padding.right) {
      x = viewportSize.width - padding.right - cardSize.width;
    }

    return Offset(x, y);
  }
}
```

```dart
      query: candidate.text,
      normalizedQuery: candidate.text,
      type: candidate.type,
      subject: widget.subject,
      grade: widget.grade,
      contentId: widget.contentId,
    );

    _lookupController.lookup(request);

    _tooltipOverlay = OverlayEntry(
      builder: (context) => _TooltipOverlay(
        position: position,
        controller: _lookupController,
        context: LookupContext(
          subject: widget.subject,
          grade: widget.grade,
        ),
        onClose: _removeTooltip,
        onViewDetails: () {
          _removeTooltip();
          Navigator.pushNamed(
            context,
            '/word-detail',
            arguments: candidate.text,
          );
        },
        onPlayAudio: (type) => _lookupController.playPronunciation(type),
        onAddToVocabulary: () => _lookupController.addToVocabulary(
          contextSentence: widget.text.substring(
            max(0, candidate.start - 20),
            min(widget.text.length, candidate.end + 20),
          ),
        ),
      ),
    );

    Overlay.of(context).insert(_tooltipOverlay!);
  }

  void _removeTooltip() {
    _tooltipOverlay?.remove();
    _tooltipOverlay = null;
    _lookupController.reset();
  }

  LookupType _inferType(String text) {
    if (RegExp(r'^[a-zA-Z]').hasMatch(text)) {
      return text.contains(' ')
          ? LookupType.englishPhrase
          : LookupType.englishWord;
    }
    if (text.length == 4 && widget.isClassicalChinese) {
      return LookupType.idiom;
    }
    if (text.length == 1) {
      return LookupType.singleChar;
    }
    return LookupType.word;
  }

  @override
  void dispose() {
    _removeTooltip();
    super.dispose();
  }
}
```

```dart
          onTap: onClose,
          behavior: HitTestBehavior.opaque,

          listenable: controller,
          builder: (context, _) {
            if (controller.state == LookupState.idle) {
              return const SizedBox.shrink();
            }

            final cardSize = _estimateCardSize(controller.state, context);
            final adjustedPosition = TooltipPositioner.calculatePosition(
              selectionRect: Rect.fromCenter(
                center: position,
                width: 20,
                height: 20,

              cardSize: cardSize,
              viewportSize: MediaQuery.of(context).size,
              padding: const EdgeInsets.all(16),
            );

            return Positioned(
              left: adjustedPosition.dx,
              top: adjustedPosition.dy,
              child: _buildContent(context),
            );
          },
        ),
      ],
    );
  }

  Widget _buildContent(BuildContext context) {
    switch (controller.state) {
      case LookupState.loading:
        return _LoadingCard();
      case LookupState.success:
      case LookupState.successDegraded:
        return LookupTooltipCard(
          result: controller.currentResult!,
          context: context,
          onClose: onClose,
          onViewDetails: onViewDetails,
          onPlayAudio: onPlayAudio,
          onAddToVocabulary: onAddToVocabulary,
        );
      case LookupState.notFound:
        return _NotFoundCard(
          word: '',
          onClose: onClose,
        );
      case LookupState.error:
        return _ErrorCard(
          message: controller.errorMessage ?? '查询失败',
          onClose: onClose,
          onRetry: () => controller.lookup(/* retrigger */),
        );
      default:
        return const SizedBox.shrink();
    }
  }
```

### 10.2 预加载策略

```dart
/// 阅读内容预加载查词缓存
class ContentPreloader {
  final CacheService _cacheService;
  final DictionaryApiService _apiService;

  /// 用户打开阅读内容时，预加载文中高频生词
  Future<void> preloadForContent({
    required String contentId,
    required String fullText,
    required Subject subject,
    required GradeLevel grade,
  }) async {
    // 1. 提取可能需要查询的词语
    final candidates = _extractCandidates(fullText, subject);

    // 2. 过滤出未缓存的
    final uncached = <LookupCandidate>[];
    for (final candidate in candidates) {
      final key = _cacheService.buildCacheKey(LookupRequest(
        query: candidate.text,
        normalizedQuery: candidate.text,
        type: candidate.type,
        subject: subject,
        grade: grade,
      ));
      if (await _cacheService.get(key) == null) {
        uncached.add(candidate);
      }
    }

    // 3. 批量预加载（限制数量，避免大量请求）
    if (uncached.isNotEmpty) {
      final batch = uncached.take(20).toList(); // 最多预加载 20 个
      try {
        final results = await _apiService.batchLookup(
          queries: batch.map((c) => LookupQuery(
            query: c.text,
            type: c.type,
            subject: subject,
          )).toList(),
          grade: grade,
        );

        for (final result in results) {
          await _cacheService.put(
            _cacheService.buildCacheKey(LookupRequest(
              query: result.word,
              normalizedQuery: result.word,
              type: batch.firstWhere((c) => c.text == result.word).type,
              subject: subject,
              grade: grade,
            )),
            result,
          );
        }
      } catch (_) {
        // 预加载失败不影响正常使用
      }
    }
  }

  /// 提取候选查询词
  List<LookupCandidate> _extractCandidates(String text, Subject subject) {
    // 基于词频表，提取文本中可能不认识的词语
    // 策略：提取超出当前年级词汇范围的词语
    // 这里使用简化逻辑，实际实现需对接词频数据库
    final words = <LookupCandidate>[];
    final segments = _smartSegment(text, subject);
    for (final seg in segments) {
      if (_isLikelyUnfamiliar(seg, subject)) {
        words.add(seg);
      }
    }
    return words;
  }
```

### 10.3 节流与防抖

```dart
/// 查词请求节流器
class LookupThrottler {
  final Duration _minInterval;
  final int _maxRequestsPerMinute;
  final Queue<DateTime> _requestTimes = Queue();

  LookupThrottler({
    Duration minInterval = const Duration(milliseconds: 200),
    int maxRequestsPerMinute = 60,
  })  : _minInterval = minInterval,
        _maxRequestsPerMinute = maxRequestsPerMinute;

  bool canRequest() {
    final now = DateTime.now();

    // 清理 1 分钟前的记录
    while (_requestTimes.isNotEmpty &&
        now.difference(_requestTimes.first).inMinutes >= 1) {
      _requestTimes.removeFirst();
    }

    // 检查频率限制
    if (_requestTimes.length >= _maxRequestsPerMinute) {
      return false;
    }

    // 检查最小间隔
    if (_requestTimes.isNotEmpty &&
        now.difference(_requestTimes.last) < _minInterval) {
      return false;
    }

    _requestTimes.addLast(now);
    return true;
  }
}
```

## 11. 错误处理与降级策略

### 11.1 错误处理矩阵

| 错误场景 | 表现 | 处理策略 | 用户感知 |
| --- | --- | --- | --- |
| 网络超时 | API 请求 > 5s 未响应 | 取消请求，检查本地缓存 | 显示降级结果或"网络较慢，请稍后重试" |
| 网络断开 | 无网络连接 | 直接查本地缓存 | 如有缓存则正常显示，否则提示离线 |
| 词语未收录 | API 返回 4001 | 显示"暂未收录" | 提供反馈入口，鼓励用户提交 |
| 服务不可用 | API 返回 500/503 | 尝试模糊匹配本地缓存 | 降级显示或提示"服务暂时不可用" |
| 频率超限 | API 返回 429/4004 | 客户端节流，排队等待 | 无感知（请求自动延迟） |
| 发音加载失败 | 音频 URL 404 | 显示禁用状态 | 发音按钮变灰，不报错 |
| 生词本同步失败 | 收藏请求失败 | 本地暂存，稍后重试同步 | 显示"已收藏（同步中）" |
| 卡片渲染异常 | 数据格式异常 | 降级为纯文本显示 | 显示基础释义文本 |

### 11.2 降级策略实现

```dart
/// 降级策略管理器
class FallbackManager {
  final CacheService _cacheService;
  final LocalDictionaryService _localDict;

  /// 降级查询：当远程服务不可用时的备选方案
  Future<LookupResult?> fallbackLookup(LookupRequest request) async {
    // 降级级别 1: 精确缓存匹配
    final exact = await _cacheService.get(request.cacheKey);
    if (exact != null) return exact;

    // 降级级别 2: 模糊缓存匹配
    final fuzzy = await _cacheService.fuzzyMatch(request.query);
    if (fuzzy != null) return fuzzy;

    // 降级级别 3: 内置离线词典（仅高频词）
    final local = await _localDict.lookup(request.query);
    if (local != null) return local;

    // 降级级别 4: 返回最小化结果
    return LookupResult(
      word: request.query,
      pinyin: '',
      definitions: [
        DefinitionEntry(
          partOfSpeech: '',
          definition: '暂无释义，请连接网络后重试',
          fields: null,
          difficulty: 0,
        ),
      ],
      examples: [],
      tags: ['离线模式'],
      isTerminology: false,
      source: LookupSource.offline,
      cacheExpireAt: 0,
    );
  }
}
```
