# 客户端-化学实验模拟与化学反应方程式交互组件-详细设计

> 版本：v1.0 | 创建日期：2026-06-13 | 模块归属：学科工具与交互组件

## 1. 文档概述

### 1.1 目的

本文档对 PrimeTop 客户端的「化学实验模拟」与「化学反应方程式交互组件」进行详细设计，覆盖初中、高中化学学科的实验操作模拟、化学方程式书写与配平、反应现象可视化、分子结构展示等交互能力，使开发人员能直接进入编码阶段。

### 1.2 范围

- 化学实验操作模拟（实验台、器材选择、操作步骤、现象展示）
- 化学方程式编辑器（输入、配平、条件标注、状态标注）
- 化学反应过程动画（微观粒子视角、宏观现象视角）
- 分子/晶体结构3D可视化
- 常见实验危险提示与安全规范展示
- 与知识点、题目的关联跳转

### 1.3 目标用户

| 用户 | 学段 | 使用场景 |
|------|------|----------|
| 初中生 | 八~九年级 | 化学入门实验、常见反应观察 |
| 高中生 | 高一~高三 | 有机化学、电解质、化学平衡等进阶实验 |
| 教师 | — | 课堂演示、布置虚拟实验作业 |

### 1.4 依赖关系

| 依赖模块 | 说明 |
|----------|------|
| 客户端-元素周期表交互组件与化学学科工具集 | 共享元素数据、周期表引用 |
| 客户端-组件库与设计系统 | 基础UI组件、主题 |
| 客户端-富文本编辑器与作文书写引擎 | 方程式渲染共用渲染管线 |
| 客户端-题目展示与答题交互组件库 | 实验类题目嵌入 |
| 客户端-手势交互与动画系统 | 手势操作、动画引擎 |
| 客户端-学科上下文与学习环境管理 | 学段切换、知识点点关联 |

## 3. 数据结构定义

### 3.1 实验相关

```dart
/// 实验定义
class Experiment {
  final String id;                       // 唯一ID: "exp_chem_001"
  final String name;                     // "铁在氧气中燃烧"
  final String summary;                  // 实验概述
  final GradeRange gradeRange;           // 适用学段
  final DifficultyLevel difficulty;       // 难度等级
  final List<String> knowledgePointIds;  // 关联知识点ID
  final List<String> apparatusIds;       // 所需器材ID列表
  final List<ReagentUsage> reagentUsages;// 所需试剂及用量
  final List<ExperimentStep> steps;      // 操作步骤
  final SafetyLevel safetyLevel;         // 安全等级
  final String? safetyVideoUrl;          // 安全视频URL
  final String coverImage;               // 封面图
  final ExperimentCategory category;     // 分类
  final List<String> tags;               // 标签: ["氧化反应", "化合反应"]
}

/// 学段范围
enum GradeRange {
  juniorMiddle,   // 初中 (八年级~九年级)
  seniorHigh,     // 高中 (高一~高三)
  both,           // 通用
}

/// 难度等级
enum DifficultyLevel {
  basic,          // 基础操作
  intermediate,   // 中等难度
  advanced,       // 高难度
}

/// 安全等级
enum SafetyLevel {
  safe,           // 安全 - 无危险试剂
  caution,        // 注意 - 有腐蚀性/刺激性试剂
  hazardous,      // 危险 - 有毒/易燃/易爆试剂，需教师指导
}

/// 实验分类
enum ExperimentCategory {
  basicOperation,     // 基本操作 (过滤、蒸馏等)
  preparation,        // 物质制备 (制取氧气、氢气等)
  property,           // 性质验证 (酸碱盐性质等)
  identification,     // 物质检验 (离子检验等)
  quantitative,       // 定量实验 (中和滴定等)
  organic,            // 有机化学 (蒸馏、裂化等)
  electrochemistry,   // 电化学 (电解、原电池等)
}

/// 器材
class Apparatus {
  final String id;                  // "apparatus_test_tube"
  final String name;                // "试管"
  final String iconAsset;           // SVG资源路径
  final ApparatusType type;
  final double capacity;            // 容量(mL)，0表示不适用
  final bool isHeatResistant;       // 耐热
  final String description;
  final List<String> usageTips;     // 使用提示
}

enum ApparatusType {
  container,     // 容器 (试管、烧杯、锥形瓶...)
  heating,       // 加热 (酒精灯、酒精喷灯...)
  measuring,     // 量器 (量筒、温度计、天平...)
  separation,    // 分离 (漏斗、分液漏斗、冷凝管...)
  support,       // 支撑 (铁架台、石棉网...)
  transfer,      // 转移 (胶头滴管、玻璃棒...)
  collection,    // 收集 (集气瓶、排水集气装置...)
  other,         // 其他
}

/// 试剂
class Reagent {
  final String id;                  // "reagent_hcl_dilute"
  final String name;                // "稀盐酸"
  final String formula;             // "HCl(aq)"
  final ReagentCategory category;
  final ReagentHazardLevel hazardLevel;
  final String appearance;          // "无色透明液体"
  final String? storageCondition;   // 存储条件
  final String safetyNote;          // 安全注意事项
}

enum ReagentCategory {
  acid,           // 酸
  base,           // 碱
  salt,           // 盐
  oxide,          // 氧化物
  metal,          // 金属
  nonmetal,       // 非金属单质
  organic,        // 有机物
  indicator,      // 指示剂
  solution,       // 溶液
  gas,            // 气体
}

enum ReagentHazardLevel {
  none,           // 无危险
  irritant,       // 刺激性
  corrosive,      // 腐蚀性
  toxic,          // 有毒
  flammable,      // 易燃
  explosive,      // 易爆
  oxidizing,      // 强氧化性
}

/// 试剂用量
class ReagentUsage {
  final String reagentId;
  final double amount;              // 用量
  final String unit;                // "mL", "g", "滴"
  final String? concentration;      // 浓度 "2mol/L"
}

/// 实验步骤
class ExperimentStep {
  final int order;                  // 步骤序号
  final String instruction;         // 操作说明
  final StepType type;
  final List<StepAction> actions;   // 可执行动作
  final String? expectedPhenomenon; // 预期现象描述
  final PhenomenonAnimation? phenomenonAnim; // 现象动画配置
  final List<String> tips;          // 操作提示
  final List<String> commonMistakes;// 常见错误
  final bool isCriticalStep;        // 关键步骤（做错需重来）
}

enum StepType {
  addReagent,        // 加入试剂
  heat,              // 加热
  cool,              // 冷却
  stir,              // 搅拌
  filter,            // 过滤
  collect,           // 收集
  observe,           // 观察
  measure,           // 测量
  combine,           // 组合器材
  wait,              // 等待
  dispose,           // 处理废弃物
  custom,            // 自定义操作
}

/// 步骤动作
class StepAction {
  final ActionType type;
  final Map<String, dynamic> params;

  // 示例: {type: addReagent, params: {reagentId: "reagent_nacl", amount: 5, unit: "g", targetApparatus: "apparatus_test_tube_1"}}
}

enum ActionType {
  dragReagentToApparatus,   // 拖拽试剂到器材
  tapApparatus,             // 点击器材
  adjustAlcoholLamp,        // 调整酒精灯火焰
  tiltContainer,            // 倾斜容器
  insertApparatus,          // 插入器材(如玻璃棒)
  toggleSwitch,             // 开关切换
  setTimer,                 // 设置计时器
}

/// 现象动画配置
class PhenomenonAnimation {
  final AnimationType type;
  final Map<String, dynamic> params;
  final int durationMs;
}

enum AnimationType {
  colorChange,        // 颜色变化
  bubbleGeneration,   // 产生气泡
  precipitate,        // 生成沉淀
  gasRelease,         // 释放气体
  flame,              // 火焰效果
  smoke,              // 烟雾效果
  dissolve,           // 溶解效果
  crystallize,        // 结晶效果
  explosion,          // 爆炸效果(轻微演示)
  temperatureChange,  // 温度变化(温度计动画)
  indicatorColor,     // 指示剂变色
}

/// 实验结果
class ExperimentResult {
  final String experimentId;
  final bool isCorrect;              // 操作是否正确
  final List<StepResult> stepResults;
  final String conclusion;           // 实验结论
  final String reactionEquation;     // 对应化学方程式
  final int score;                   // 0-100 评分
  final Duration totalTime;          // 总耗时
  final List<String> mistakes;       // 错误列表
}

class StepResult {
  final int stepOrder;
  final bool isCorrect;
  final String? userAction;          // 用户实际操作
  final String? expectedAction;      // 期望操作
  final String? feedback;            // 反馈信息
}
```

### 3.2 方程式相关

```dart
/// 化学方程式
class ChemicalEquation {
  final String id;
  final List<EquationTerm> reactants;    // 反应物列表
  final List<EquationTerm> products;     // 生成物列表
  final EquationCondition? condition;    // 反应条件
  final bool isReversible;              // 可逆反应
  final String? category;               // 反应类型: "化合", "分解", "置换", "复分解"
  final List<String> knowledgePointIds;
  final String? relatedExperimentId;    // 关联实验ID
}

/// 方程式项（物质 + 系数）
class EquationTerm {
  final int coefficient;           // 系数，默认1
  final Substance substance;       // 物质
  final StateSymbol? stateSymbol;  // 状态符号
}

/// 物质
class Substance {
  final String id;
  final String name;               // "水"
  final String formula;            // "H₂O"
  final SubstanceType type;
  final int? charge;               // 离子电荷，如 SO₄²⁻ charge = -2
}

enum SubstanceType {
  element,       // 单质
  compound,      // 化合物
  ion,           // 离子
  radical,       // 原子团
}

/// 状态符号
enum StateSymbol {
  solid,       // ↓ 沉淀
  gas,         // ↑ 气体
  liquid,      // (l) 液态
  aqueous,     // (aq) 水溶液
}

/// 反应条件
class EquationCondition {
  final ConditionType type;
  final String? detail;             // 补充说明

  // 支持多条件组合，如 "点燃" + "催化剂"
  final List<EquationCondition>? additional;
}

enum ConditionType {
  heat,           // 加热 △
  highTemp,       // 高温
  ignite,         // 点燃
  catalyst,       // 催化剂
  electrify,      // 通电
  highPressure,   // 高压
  sunlight,       // 光照
  none,           // 无条件
}

/// 方程式编辑器状态
class EquationEditorState {
  final List<EquationTerm> reactants;
  final List<EquationTerm> products;
  final EquationCondition? condition;
  final bool isBalanced;
  final List<BalancingHint> balancingHints;
  final ValidationStatus validationStatus;
  final String? errorMessage;
}

enum ValidationStatus {
  empty,         // 空
  incomplete,    // 未完成
  unbalanced,    // 未配平（原子数不等）
  balanced,      // 已配平
  invalid,       // 不合法（不存在的物质等）
}

/// 配平提示
class BalancingHint {
  final String element;             // "H"
  final int leftCount;              // 左边原子数
  final int rightCount;             // 右边原子数
  final String message;             // "氢原子左边有4个，右边有2个，请调整系数"
}
```

```dart
/// 分子结构
class MoleculeStructure {
  final String id;
  final String name;                 // "水分子"
  final String formula;              // "H₂O"
  final MoleculeType type;
  final List<AtomInfo> atoms;
  final List<BondInfo> bonds;
  final GeometryInfo? geometry;      // 分子构型
  final String? description;
  final String? modelAsset;          // 3D模型资源路径
}

enum MoleculeType {
  simpleMolecule,    // 简单分子 (H₂O, CO₂...)
  complexMolecule,   // 复杂分子 (C₂H₅OH...)
  ion,               // 离子
  crystal,           // 晶体 (NaCl...)
  organic,           // 有机分子
  polymer,           // 高分子
}

/// 原子信息
class AtomInfo {
  final String element;              // 元素符号 "O"
  final int atomicNumber;
  final Offset3D position;           // 3D坐标
  final double radius;               // 显示半径
  final String color;                // CPK颜色
  final int? charge;                 // 化合价/电荷
  final int bondCount;               // 成键数
}

/// 化学键信息
class BondInfo {
  final int atomIndex1;              // 第一个原子索引
  final int atomIndex2;              // 第二个原子索引
  final BondType type;
  final double length;               // 键长(Å)
  final double? angle;               // 键角(°)
}

enum BondType {
  single,        // 单键
  double_,       // 双键
  triple_,       // 三键
  coordinate,    // 配位键
  ionic,         // 离子键
  hydrogen,      // 氢键
  metallic,      // 金属键
}

/// 分子构型
class GeometryInfo {
  final MolecularGeometry geometry;
  final String description;          // "V形（角形）"
  final double? bondAngle;           // 键角
}

enum MolecularGeometry {
  linear,           // 直线形
  vShape,           // V形/角形
  trigonalPlanar,   // 平面三角形
  tetrahedral,      // 正四面体形
  trigonalPyramidal,// 三角锥形
  squarePlanar,     // 平面四方形
  octahedral,       // 正八面体形
  seeSaw,           // 跷跷板形
  tShape,           // T形
}

class Offset3D {
  final double x, y, z;
  const Offset3D(this.x, this.y, this.z);
}
```

```dart
/// 化学实验模拟引擎
class ChemSimulationEngine {
  final Experiment _experiment;
  final ChemAnimationController _animationController;
  final ParticleSystem _particleSystem;
  final AudioEffectPlayer _audioPlayer;

  ExperimentState _state = ExperimentState.idle;
  int _currentStepIndex = 0;
  final Map<String, dynamic> _apparatusState = {};

  /// 执行步骤动作
  Future<StepResult> executeStepAction(StepAction action) async {
    final step = _experiment.steps[_currentStepIndex];

    // 1. 验证动作是否匹配当前步骤
    if (!_isActionValid(action, step)) {
      return StepResult(
        stepOrder: step.order,
        isCorrect: false,
        userAction: _describeAction(action),
        expectedAction: step.instruction,
        feedback: _generateWrongFeedback(step),
      );
    }

    // 2. 更新器材状态
    _updateApparatusState(action);

    // 3. 播放现象动画
    if (step.phenomenonAnim != null) {
      await _playPhenomenonAnimation(step.phenomenonAnim!);
    }

    // 4. 播放音效
    await _playStepSoundEffect(step.type);

    // 5. 检查是否为关键步骤的特定操作错误
    final result = StepResult(
      stepOrder: step.order,
      isCorrect: true,
      userAction: _describeAction(action),
      feedback: _generateCorrectFeedback(step),
    );

    // 6. 推进到下一步
    _currentStepIndex++;
    if (_currentStepIndex >= _experiment.steps.length) {
      _state = ExperimentState.completing;
    } else {
      _state = ExperimentState.stepping;
    }

    return result;
  }

  /// 播放现象动画
  Future<void> _playPhenomenonAnimation(PhenomenonAnimation anim) async {
    switch (anim.type) {
      case AnimationType.colorChange:
        final targetId = anim.params['targetApparatus'] as String;
        final fromColor = anim.params['fromColor'] as String;
        final toColor = anim.params['toColor'] as String;
        await _animationController.animateColorChange(
          targetId, fromColor, toColor, anim.durationMs,
        );

      case AnimationType.bubbleGeneration:
        final targetId = anim.params['targetApparatus'] as String;
        final intensity = anim.params['intensity'] as String? ?? 'medium';
        final color = anim.params['color'] as String? ?? '#FFFFFF';
        _particleSystem.startBubbles(
          targetId,
          intensity: _parseIntensity(intensity),
          color: color,
          duration: Duration(milliseconds: anim.durationMs),
        );

      case AnimationType.precipitate:
        final targetId = anim.params['targetApparatus'] as String;
        final precipitateColor = anim.params['color'] as String;
        final speed = anim.params['speed'] as String? ?? 'medium';
        await _animationController.animatePrecipitate(
          targetId, precipitateColor, speed, anim.durationMs,
        );

      case AnimationType.flame:
        final targetId = anim.params['targetApparatus'] as String?;
        final color = anim.params['color'] as String;
        final size = anim.params['size'] as String;
        final sparks = anim.params['sparks'] as bool? ?? false;
        _particleSystem.startFlame(

          flameColor: color,
          size: _parseFlameSize(size),

          duration: Duration(milliseconds: anim.durationMs),

      // ... 其他动画类型
      default:

    }
  }

    _animationController.resetAll();
  }
```

### 6.2 方程式配平算法

```dart
/// 方程式配平器
class EquationBalancer {
  /// 检查方程式是否已配平
  /// 返回每个元素的左右原子数对比
  Map<String, BalanceCheck> checkBalance(EquationEditorState state) {
    final Map<String, int> leftCounts = {};
    final Map<String, int> rightCounts = {};

    for (final term in state.reactants) {
      _countAtoms(term, leftCounts);
    }
    for (final term in state.products) {
      _countAtoms(term, rightCounts);
    }

    final result = <String, BalanceCheck>{};
    final allElements = {...leftCounts.keys, ...rightCounts.keys};

    for (final element in allElements) {
      final left = leftCounts[element] ?? 0;
      final right = rightCounts[element] ?? 0;
      result[element] = BalanceCheck(
        element: element,
        leftCount: left,
        rightCount: right,
        isBalanced: left == right,
      );
    }

    return result;
  }

  /// 统计单个物质中各元素原子数（乘以系数）
  void _countAtoms(EquationTerm term, Map<String, int> counts) {
    final parsed = _parseFormula(term.substance.formula);
    for (final entry in parsed.entries) {
      counts[entry.key] = (counts[entry.key] ?? 0) +
                          entry.value * term.coefficient;
    }
  }

  /// 解析化学式，返回元素→原子数的映射
  /// 例: "Fe3O4" → {"Fe": 3, "O": 4}
  ///     "Ca(OH)2" → {"Ca": 1, "O": 2, "H": 2}
  Map<String, int> _parseFormula(String formula) {
    final result = <String, int>{};
    final stack = <Map<String, int>>[result];
    int i = 0;

    while (i < formula.length) {
      if (formula[i] == '(') {
        stack.add(<String, int>{});
        i++;
      } else if (formula[i] == ')') {
        i++;
        final multiplier = _parseNumber(formula, i);
        i += multiplier > 1 ? multiplier.toString().length : 0;
        final inner = stack.removeLast();
        for (final entry in inner.entries) {
          stack.last[entry.key] =
              (stack.last[entry.key] ?? 0) + entry.value * multiplier;
        }
      } else if (_isUpperCase(formula[i])) {
        final element = _parseElement(formula, i);
        i += element.length;
        final count = _parseNumber(formula, i);
        i += count > 1 ? count.toString().length : 0;
        stack.last[element] = (stack.last[element] ?? 0) + count;
      } else {
        i++; // 跳过数字等
      }
    }

    return result;
  }

  int _parseNumber(String s, int pos) {
    if (pos >= s.length || !_isDigit(s[pos])) return 1;
    int start = pos;
    while (pos < s.length && _isDigit(s[pos])) pos++;
    return int.parse(s.substring(start, pos));
  }

  String _parseElement(String s, int pos) {
    final buf = StringBuffer(s[pos]);
    pos++;
    while (pos < s.length && _isLowerCase(s[pos])) {
      buf.write(s[pos]);
      pos++;
    }
    return buf.toString();
  }

  bool _isUpperCase(String c) => c.codeUnitAt(0) >= 65 && c.codeUnitAt(0) <= 90;
  bool _isLowerCase(String c) => c.codeUnitAt(0) >= 97 && c.codeUnitAt(0) <= 122;
  bool _isDigit(String c) => c.codeUnitAt(0) >= 48 && c.codeUnitAt(0) <= 57;
}

class BalanceCheck {
  final String element;
  final int leftCount;
  final int rightCount;
  final bool isBalanced;

  String get hint => isBalanced
    ? '$element: ✓ ($leftCount = $rightCount)'
    : '$element: 左边$leftCount个，右边${rightCount}个，${leftCount > rightCount ? "左边多" : "右边多"}';
```

```dart
class _MoleculeViewerState extends State<MoleculeViewer>
    with SingleTickerProviderStateMixin {

  Offset _rotationOffset = Offset.zero;
  double _zoom = 1.0;
  MoleculeViewMode _viewMode = MoleculeViewMode.ballAndStick;

  @override
  void initState() {
    super.initState();
    _rotationController = AnimationController(
      vsync: this,

    _viewMode = widget.initialMode;

    super.dispose();
  }

/// 分子绘制器
class MoleculePainter extends CustomPainter {
  final MoleculeStructure molecule;
  final double rotationY;
  final double rotationX;
  final double zoom;
  final MoleculeViewMode viewMode;
  final bool showLabels;

  MoleculePainter({
    required this.molecule,
    required this.rotationY,
    required this.rotationX,
    required this.zoom,
    required this.viewMode,
    required this.showLabels,
  });

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final scale = 60.0 * zoom; // 基准缩放

    // 1. 投影3D坐标到2D
    final projectedAtoms = molecule.atoms.map((atom) {
      final rotated = _rotate3D(atom.position, rotationX, rotationY);
      return _ProjectedAtom(
        atom: atom,
        screenX: center.dx + rotated.x * scale,
        screenY: center.dy - rotated.z * scale, // z轴向上
        depth: rotated.y, // y轴为深度
      );
    }).toList();

    // 2. 按深度排序（远的先画）
    final sortedIndices = List.generate(molecule.atoms.length, (i) => i)
      ..sort((a, b) => projectedAtoms[a].depth.compareTo(projectedAtoms[b].depth));

    // 3. 绘制化学键（先画键再画原子球）
    for (final bond in molecule.bonds) {
      _drawBond(canvas, projectedAtoms[bond.atomIndex1],
                projectedAtoms[bond.atomIndex2], bond.type);
    }

    // 4. 绘制原子球
    for (final idx in sortedIndices) {
      _drawAtom(canvas, projectedAtoms[idx]);
    }
  }

  Offset3D _rotate3D(Offset3D p, double rx, double ry) {
    // Y轴旋转
    var x = p.x * cos(ry) + p.y * sin(ry);
    var y = -p.x * sin(ry) + p.y * cos(ry);
    var z = p.z;
    // X轴旋转
    final z2 = z * cos(rx) - y * sin(rx);
    final y2 = z * sin(rx) + y * cos(rx);
    return Offset3D(x, y2, z2);
  }

  void _drawAtom(Canvas canvas, _ProjectedAtom pa) {
    final radius = (pa.atom.radius * 30 * zoom)
                  .clamp(8.0 * zoom, 25.0 * zoom);
    final paint = Paint()..color = _parseColor(pa.atom.color);

    // 球体渐变效果
    final gradient = RadialGradient(
      colors: [
        _parseColor(pa.atom.color).withOpacity(1.0),
        _parseColor(pa.atom.color).withOpacity(0.8),
        _parseColor(pa.atom.color).withOpacity(0.5),
      ],
      stops: const [0.0, 0.6, 1.0],
      center: Alignment(-0.3, -0.3),
    );

    paint.shader = gradient.createShader(
      Rect.fromCircle(center: Offset(pa.screenX, pa.screenY), radius: radius),
    );

    canvas.drawCircle(Offset(pa.screenX, pa.screenY), radius, paint);

    // 元素标签
    if (showLabels) {
      final textPainter = TextPainter(
        text: TextSpan(
          text: pa.atom.element,
          style: TextStyle(
            color: Colors.white,
            fontSize: (radius * 0.8).clamp(8, 14),
            fontWeight: FontWeight.bold,
          ),
        ),
        textDirection: TextDirection.ltr,
      )..layout();
      textPainter.paint(
        canvas,
        Offset(
          pa.screenX - textPainter.width / 2,
          pa.screenY - textPainter.height / 2,
        ),
      );
    }
  }

  void _drawBond(Canvas canvas, _ProjectedAtom a, _ProjectedAtom b, BondType type) {
    final paint = Paint()
      ..color = Colors.grey.shade400
      ..strokeWidth = (3.0 * zoom).clamp(1.0, 6.0);

    canvas.drawLine(
      Offset(a.screenX, a.screenY),
      Offset(b.screenX, b.screenY),
      paint,
    );

    if (type == BondType.double_) {
      // 双键：平行偏移
      final offset = 3.0 * zoom;
      final dx = b.screenX - a.screenX;
      final dy = b.screenY - a.screenY;
      final len = sqrt(dx * dx + dy * dy);
      final nx = -dy / len * offset;
      final ny = dx / len * offset;
      canvas.drawLine(
        Offset(a.screenX + nx, a.screenY + ny),
        Offset(b.screenX + nx, b.screenY + ny),
        paint,
      );
    } else if (type == BondType.triple_) {
      // 三键
      final offset = 3.0 * zoom;
      final dx = b.screenX - a.screenX;
      final dy = b.screenY - a.screenY;
      final len = sqrt(dx * dx + dy * dy);
      final nx = -dy / len * offset;
      final ny = dx / len * offset;
      canvas.drawLine(
        Offset(a.screenX + nx, a.screenY + ny),
        Offset(b.screenX + nx, b.screenY + ny),
        paint,
      );
      canvas.drawLine(
        Offset(a.screenX - nx, a.screenY - ny),
        Offset(b.screenX - nx, b.screenY - ny),
        paint,
      );
    }
  }

  Color _parseColor(String hex) {
    return Color(int.parse(hex.replaceFirst('#', 'FF'), radix: 16));
  }

  @override
  bool shouldRepaint(covariant MoleculePainter oldDelegate) => true;
}

class _ProjectedAtom {
  final AtomInfo atom;
  final double screenX;
  final double screenY;
  final double depth;
  const _ProjectedAtom({
    required this.atom,
    required this.screenX,
    required this.screenY,
    required this.depth,
  });
}

enum MoleculeViewMode {
  ballAndStick,  // 球棍模型
  spaceFilling,  // 比例模型
  wireframe,     // 线框模型
}
```

| `CHEM_EXP_003` | 实验版本不匹配 | 提示更新 |
| `CHEM_EXP_004` | 操作步骤超时 | 提示重试或跳过 |
| `CHEM_EXP_005` | 安全等级不足 | 需家长/教师授权 |
| `CHEM_EQ_001` | 方程式格式错误 | 标红错误位置 |
| `CHEM_EQ_002` | 物质不存在 | 提示修正 |
| `CHEM_EQ_003` | 配平检查失败 | 显示服务端返回提示 |
| `CHEM_MOL_001` | 分子数据缺失 | 降级为2D示意图 |
| `CHEM_MOL_002` | 3D渲染失败 | 降级为2D模式 |

### 9.2 降级策略

```text
3D分子渲染失败 → 2D静态结构图
现象动画播放失败 → 文字描述 + 静态图片
拖拽交互异常 → 点击选择模式
资源包下载失败 → 使用内嵌精简数据
```
