## 1. 概述

### 1.1 模块定位

课后答疑与内容互动讨论引擎（Course Discussion Engine, CDE）是 PrimeTop 平台**内容锚定型学术问答**的核心服务。与 AI 一对一辅导不同，本引擎构建的是**学习者社群化的群体互助答疑体系**——每一篇课文、每一段视频微课、每一组练习题都拥有独立的讨论空间，学生在学习过程中遇到疑问可以即时发起提问，由教师/TA、同伴学生和 AI 辅助三方协同解答。

### 1.2 与现有模块的边界

| 现有模块 | 定位 | 与本引擎的区别 |
| --- | --- | --- |
| AI 智能辅导（AI 对话引擎） | 学生与 AI 一对一问答 | 本引擎是学生↔学生↔教师的多方讨论 |
| 学习同伴圈层匹配与协作学习编排 | 学习圈内同伴互助 | 本引擎锚定到**具体内容**，非社交圈层 |
| 家校沟通与班级协作消息服务 | 教师→家长通知/私聊 | 本引擎是学生→学术问答，公开可见 |
| 教育内容用户评价体系 | 内容评分+评论 | 评价是"好不好用"；本引擎是"这题怎么做" |
| 用户生成内容安全审核 | UGC 安全管线 | 本引擎产生的 UGC 由 CDE 自身初审后委托 UGC 安全管线复核 |

### 1.3 核心职责

1. **内容锚定讨论区管理**：为平台内容（课文/微课/练习/知识点卡片）自动创建讨论空间
2. **结构化问答工作流**：提问 → 回复 → 采纳最佳答案 → 教师认证 → FAQ 沉淀
3. **智能问题路由**：新问题自动匹配已有优质回答，减少重复提问
4. **AI 辅助答疑**：30 分钟无人回复触发 AI 预回答，标记"AI 辅助"待人工确认
5. **讨论质量管控**：点赞/反对投票、优质回答置顶、低质回答折叠
6. **FAQ 自动萃取**：从高频问答中提取常见问题，关联到内容知识点
7. **讨论数据分析**：内容讨论热度、高频疑问知识点、回答者活跃度等运营数据

### 1.5 设计目标

| 指标 | 目标 | 说明 |
| --- | --- | --- |
| 问题发布延迟 | P99 < 300ms | 不含审核时间 |
| 问题列表加载 | P95 < 200ms | 首页 20 条 |
| 首个回答到达中位数 | < 30 分钟 | 含 AI 辅助回答 |
| 教师认证回答覆盖率 | ≥ 60% | 有教师参与的内容讨论区 |
| FAQ 自动萃取准确率 | ≥ 80% | 抽样人工评审 |
| 重复问题拦截率 | ≥ 50% | 命中已有问题并引导查看 |

## 2. 数据模型

### 2.1 核心实体关系

```
ContentThread (讨论主题/容器)
  ├── DiscussionQuestion (问题)
  │     ├── Answer (回答)
  │     │     ├── AnswerComment (评论)
  │     │     └── VoteRecord (投票记录)
  │     └── QuestionTag (问题标签)
  ├── FAQItem (常见问题条目)
  └── ThreadSubscription (订阅/关注)
```

### 2.2 讨论主题表 `discussion_thread`

每条平台内容（课文/微课/练习题组/知识点卡片）拥有一个讨论主题容器。

```sql
CREATE TABLE `discussion_thread` (
    `thread_id`         BIGINT       NOT NULL AUTO_INCREMENT,
    `content_id`        VARCHAR(64)  NOT NULL COMMENT '关联内容ID（课文/微课/练习/知识点）',
    `content_type`      TINYINT      NOT NULL COMMENT '内容类型: 1=课文 2=微课视频 3=练习题组 4=知识点卡片 5=考试试卷',
    `content_title`     VARCHAR(256) NOT NULL COMMENT '内容标题（冗余，减少联查）',
    `subject_code`      VARCHAR(16)  NOT NULL COMMENT '学科编码: CHN/MATH/ENG/PHY/CHE/BIO/HIS/GEO/POL',
    `grade_level`       TINYINT      NOT NULL COMMENT '学段: 1=幼儿 2=小学 3=初中 4=高中',
    `chapter_id`        VARCHAR(64)  DEFAULT NULL COMMENT '章节ID（冗余加速筛选）',
    `kp_id`             VARCHAR(64)  DEFAULT NULL COMMENT '主知识点ID（冗余加速筛选）',
    `status`            TINYINT      NOT NULL DEFAULT 1 COMMENT '1=开放 2=锁定(教师关闭) 3=归档(内容下架)',
    `question_count`    INT          NOT NULL DEFAULT 0 COMMENT '问题总数（冗余计数）',
    `unanswered_count`  INT          NOT NULL DEFAULT 0 COMMENT '待回答问题数（冗余计数）',
    `follower_count`    INT          NOT NULL DEFAULT 0 COMMENT '关注人数（冗余计数）',
    `last_activity_at`  DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '最后活跃时间',
    `created_at`        DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at`        DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    PRIMARY KEY (`thread_id`),
    UNIQUE KEY `uk_content` (`content_id`, `content_type`),
    KEY `idx_chapter_subject` (`chapter_id`, `subject_code`),
    KEY `idx_kp` (`kp_id`),
    KEY `idx_status_activity` (`status`, `last_activity_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容讨论主题容器';
```

### 2.3 讨论问题表 `discussion_question`

```sql
CREATE TABLE `discussion_question` (
    `question_id`       BIGINT       NOT NULL AUTO_INCREMENT,
    `thread_id`         BIGINT       NOT NULL COMMENT '所属讨论主题',
    `user_id`           BIGINT       NOT NULL COMMENT '提问用户ID',
    `user_nickname`     VARCHAR(50)  DEFAULT NULL COMMENT '提问时昵称（冗余）',
    `user_grade_level`  TINYINT      NOT NULL COMMENT '提问时学段（冗余，用于分龄展示）',
    `title`             VARCHAR(200) NOT NULL COMMENT '问题标题（≤100字）',
    `body`              TEXT         NOT NULL COMMENT '问题描述（Markdown格式，≤2000字）',
    `body_plain`        TEXT         NOT NULL COMMENT '问题纯文本（用于全文检索）',
    `anchor_type`       TINYINT      NOT NULL DEFAULT 0 COMMENT '锚点类型: 0=无 1=视频时间戳 2=章节段落 3=题目序号 4=知识点节点',
    `anchor_data`       JSON         DEFAULT NULL COMMENT '锚点数据 {"timestamp": 125, "section": "3.2", "question_no": 5}',
    `images`            JSON         DEFAULT NULL COMMENT '图片URL列表 ["oss://...", "oss://..."]',
    `kp_codes`          JSON         DEFAULT NULL COMMENT '关联知识点编码列表（AI自动标注或手动选择）',
    `subject_code`      VARCHAR(16)  NOT NULL COMMENT '学科编码（冗余）',
    `status`            TINYINT      NOT NULL DEFAULT 0 COMMENT '0=待审核 1=正常 2=有回答 3=已有最佳答案 4=已关闭 5=审核拒绝',
    `answer_count`      INT          NOT NULL DEFAULT 0 COMMENT '回答数（冗余）',
    `view_count`        INT          NOT NULL DEFAULT 0 COMMENT '浏览数（冗余）',
    `vote_score`        INT          NOT NULL DEFAULT 0 COMMENT '投票分（赞-反对，冗余）',
    `has_teacher_answer` TINYINT     NOT NULL DEFAULT 0 COMMENT '是否有教师/TA回答（0/1）',
    `has_accepted`      TINYINT      NOT NULL DEFAULT 0 COMMENT '是否有采纳答案（0/1）',
    `best_answer_id`    BIGINT       DEFAULT NULL COMMENT '最佳答案ID',
    `accepted_by`       BIGINT       DEFAULT NULL COMMENT '采纳人ID（提问者或教师）',
    `accepted_at`       DATETIME(3)  DEFAULT NULL COMMENT '采纳时间',
    `ai_assisted`       TINYINT      NOT NULL DEFAULT 0 COMMENT '是否有AI辅助回答（0/1）',
    `duplicate_of`      BIGINT       DEFAULT NULL COMMENT '重复问题指向的已有问题ID',
    `audit_status`      TINYINT      NOT NULL DEFAULT 0 COMMENT '0=待审 1=自动通过 2=人工通过 3=拒绝',
    `audit_reason`      VARCHAR(256) DEFAULT NULL COMMENT '审核拒绝原因',
    `audited_by`        BIGINT       DEFAULT NULL COMMENT '审核人ID',
    `audited_at`        DATETIME(3)  DEFAULT NULL,
    `created_at`        DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at`        DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    PRIMARY KEY (`question_id`),
    KEY `idx_thread_status` (`thread_id`, `status`),
    KEY `idx_thread_activity` (`thread_id`, `created_at` DESC),
    KEY `idx_user` (`user_id`),
    KEY `idx_status_unanswered` (`status`, `has_accepted`, `answer_count`),
    KEY `idx_duplicate` (`duplicate_of`),
    FULLTEXT KEY `ft_body` (`title`, `body_plain`) WITH PARSER ngram
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='讨论问题';
```

## 3. API 接口设计

### 3.1 接口总览

### 3.2 核心接口详细设计

#### 3.2.1 按内容获取讨论主题

```
GET /api/v1/discuss/by-content?contentId=xxx&contentType=2
```

**响应**：
```json
{
  "code": 0,
  "data": {
    "threadId": 10245,
    "contentId": "lesson_7g3k_ch3_5",
    "contentType": 2,
    "contentTitle": "勾股定理的应用",
    "subjectCode": "MATH",
    "gradeLevel": 3,
    "status": 1,
    "questionCount": 42,
    "unansweredCount": 3,
    "followerCount": 156,
    "hasSubscribed": true,
    "faqCount": 8,
    "lastActivityAt": "2026-06-29T10:30:00.000Z"
  }
}
```

**逻辑**：内容首次被访问时自动创建讨论主题（懒创建）。

#### 3.2.2 发布问题

```
POST /api/v1/discuss/questions
```

**请求**：
```json
{
  "threadId": 10245,
  "title": "勾股定理怎么证明？有没有简单的方法？",
  "body": "老师讲的面积法我没听懂，有没有更直观的证明思路？",
  "anchorType": 1,
  "anchorData": {
    "timestamp": 185
```

```java
public void acceptAnswer(Long answerId, Long operatorId, boolean isTeacher) {
    Answer answer = answerMapper.selectById(answerId);
    Question question = questionMapper.selectById(answer.getQuestionId());

    // 权限校验
    boolean canAccept = isTeacher
        || question.getUserId().equals(operatorId);
    if (!canAccept) {
        throw new BizException("DISCUSS_403", "无权采纳答案");
    }

    // 如果已有最佳答案，取消旧的
    if (question.getBestAnswerId() != null) {
        answerMapper.updateIsBest(question.getBestAnswerId(), 0);
        Answer oldBest = answerMapper.selectById(question.getBestAnswerId());
        userPointsService.adjustPoints(oldBest.getUserId(),
            PointAction.ANSWER_UNACCEPTED, -10);
    }

    // 设置新最佳答案
    answerMapper.updateIsBest(answerId, 1);
    questionMapper.updateBestAnswer(question.getQuestionId(),
        answerId, operatorId);

    // 积分奖励
    userPointsService.adjustPoints(answer.getUserId(),
        PointAction.ANSWER_ACCEPTED, +20);
    if (isTeacher) {
        answerMapper.updateTeacherVerified(answerId, operatorId);
    }

    // 触发 FAQ 自动萃取（异步）
    eventBus.publish(new AnswerAcceptedEvent(question, answer));

    // 通知提问者（如果采纳者是教师）
    if (isTeacher && !question.getUserId().equals(operatorId)) {
        notifyService.send(question.getUserId(),
            NotifyTemplate.QUESTION_ANSWER_ACCEPTED_BY_TEACHER,
            Map.of("questionTitle", question.getTitle()));
    }
}
```

### 4.4 重复问题检测

采用**双路召回 + 语义排序**策略：

```java
/**
 * 重复问题检测
 * @return 相似问题列表，按相似度降序
 */
public List<SimilarQuestion> detectDuplicate(Long threadId, String title, String body) {
    String combined = title + " " + body;

    // 路径1: MySQL全文检索（ngram分词）
    List<Long> fulltextIds = questionMapper.fulltextSearch(threadId, combined, 20);

    // 路径2: 向量检索（语义相似）
    float[] queryVec = embeddingService.embed(combined);
    List<Long> vectorIds = vectorSearchService.search(
        "question_vectors", queryVec, 20,
        Filter.eq("thread_id", threadId)
    );

    // 合并候选集
    Set<Long> candidateIds = new HashSet<>();
    candidateIds.addAll(fulltextIds);
    candidateIds.addAll(vectorIds);

    // 排除已关闭/重复问题
    candidateIds = candidateIds.stream()
        .filter(id -> questionMapper.isAnsweredOrResolved(id))
        .collect(Collectors.toSet());

    // 重排序：综合全文分 + 向量分
    return candidateIds.stream()
        .map(id -> {
            Question q = questionMapper.selectById(id);
            double fulltextScore = fulltextScore(title, q.getTitle());
            double vectorScore = vectorSimilarity(queryVec, q.getEmbedding());
            double finalScore = 0.3 * fulltextScore + 0.7 * vectorScore;
            return new SimilarQuestion(q, finalScore);
        })
        .filter(sq -> sq.getSimilarity() >= 0.6)
        .sorted(Comparator.comparingDouble(SimilarQuestion::getSimilarity).reversed())
        .limit(5)
        .collect(Collectors.toList());
}
```

```java
    /**
     * 发布新问题
     */
    @Transactional
    public QuestionDTO publishQuestion(Long userId, PublishQuestionReq req) {
        // 1. 权限与频率校验
        validateUserCanPost(userId);

        // 2. 获取或创建讨论主题
        DiscussionThread thread = getOrCreateThread(

        DiscussionQuestion question = DiscussionQuestion.builder()
            .threadId(thread.getThreadId())
            .userId(userId)
            .title(req.getTitle())
            .body(req.getBody())

            .anchorType(req.getAnchorType())
            .anchorData(req.getAnchorData())
            .images(req.getImages())
            .kpCodes(req.getKpCodes())
            .subjectCode(thread.getSubjectCode())
            .status(safetyResult.isPassed() ? QuestionStatus.OPEN.getCode()
                                            : QuestionStatus.PENDING.getCode())
            .auditStatus(safetyResult.isPassed() ? 1 : 0)
            .build();
        questionMapper.insert(question);

        // 6. 更新讨论主题计数
        threadMapper.incrementQuestionCount(thread.getThreadId());

        // 7. 生成向量并入库（异步）
        CompletableFuture.runAsync(() -> {
            float[] vec = embeddingService.embed(
                req.getTitle() + " " + stripMarkdown(req.getBody())
            );
            vectorSearchService.upsert("question_vectors",
                question.getQuestionId(), vec,
                Map.of("thread_id", thread.getThreadId(),
                       "subject", thread.getSubjectCode())
            );
        });

        // 8. AI 辅助冷却计时（异步事件）
        if (safetyResult.isPassed()) {
            eventBus.publish(new QuestionPublishedEvent(
                question.getQuestionId(),
                thread.getThreadId(),
                userId,

            ));

        eventBus.publish(new NotifySubscribersEvent(
            thread.getThreadId(), userId,

        // 更新问题状态
        if (safetyResult.isPassed()) {
            questionMapper.updateStatus(questionId, QuestionStatus.ANSWERED.getCode());
            questionMapper.incrementAnswerCount(questionId);

            redis.delete("discuss:ai:cooldown:" + question.getThreadId()
                + ":" + questionId);
        }

        if (!userId.equals(question.getUserId())) {
            eventBus.publish(new NewAnswerEvent(
                question.getUserId(), questionId, answer.getAnswerId(), userId
            ));
        }

        // 积分奖励
        eventBus.publish(new AwardPointsEvent(
            userId, PointAction.ANSWER_POSTED, 5
        ));

        return AnswerDTO.from(answer);

    /**
     * 投票（赞同/反对）
     */
    @Transactional
    public void vote(Long userId, int targetType, Long targetId, int voteType) {
        // 校验
        validateVoteTarget(targetType, targetId, userId);

        // 检查是否已投票
        DiscussionVote existing = voteMapper.findByUserAndTarget(
            userId, targetType, targetId
        );
        if (existing != null) {
            if (existing.getVoteType() == voteType) {
                throw new BizException("DISCUSS_302", "已经投过相同票");
            }
            // 更新投票
            voteMapper.updateVoteType(existing.getVoteId(), voteType);
        } else {
            voteMapper.insert(DiscussionVote.builder()
                .userId(userId)
                .targetType(targetType)
                .targetId(targetId)
                .voteType(voteType)
                .build());
        }

        // 更新目标冗余计数
        updateVoteScore(targetType, targetId, voteType,
            existing != null ? existing.getVoteType() : null);

        // 积分（回答被赞同 +2，被反对 -1）
        if (targetType == VoteTarget.ANSWER.getCode()) {
            Long answerOwnerId = answerMapper.selectUserIdById(targetId);
            int delta = (voteType == 1) ? +2 : -1;
            eventBus.publish(new AwardPointsEvent(
                answerOwnerId, PointAction.ANSWER_VOTED, delta
            ));
        }

        // 自动折叠低分回答
        if (targetType == VoteTarget.ANSWER.getCode()) {
            int currentScore = answerMapper.selectVoteScoreById(targetId);
            if (currentScore <= -5) {
                answerMapper.updateStatus(targetId, AnswerStatus.FOLDED.getCode());
            }
        }
    }

    /**
     * AI 辅助回答（由定时任务触发）
     */
    @Async
    public void generateAiAssistedAnswer(Long questionId) {
        DiscussionQuestion question = questionMapper.selectById(questionId);
        if (question == null) return;
        if (question.getStatus() != QuestionStatus.OPEN.getCode()) return;
        if (question.getAnswerCount() > 0) return; // 已有人工回答

        // 检查冷却Key
        String cooldownKey = "discuss:ai:cooldown:" + question.getThreadId()
            + ":" + questionId;
        if (!redis.hasKey(cooldownKey)) return;

        try {
            // 构建 AI 辅导 Prompt
            AiAssistPrompt prompt = buildAiAssistPrompt(question);

            // 调用 AI 对话引擎
            String aiResponse = aiTutorClient.generateDiscussionAnswer(prompt);

            // 安全检查
            UgcSafetyResult safetyResult = ugcSafetyClient.quickCheck(
                aiResponse, UgcScene.AI_GENERATED_DISCUSSION
            );
            if (!safetyResult.isPassed()) {
                log.warn("AI辅助回答未通过安全检查, questionId={}", questionId);
                return;
            }

            // 入库，标记为 AI 生成
            DiscussionAnswer answer = DiscussionAnswer.builder()
                .questionId(questionId)
                .userId(0L) // 系统AI用户
                .userRole(4) // AI助手
                .userNickname("AI学习助手")
                .body(aiResponse)
                .bodyPlain(stripMarkdown(aiResponse))
                .status(1)
                .auditStatus(1)
                .isAiGenerated((byte) 1)
                .aiModel(prompt.getModel())
                .aiStatus(0) // 待人工确认
                .build();
            answerMapper.insert(answer);

            questionMapper.updateStatus(questionId, QuestionStatus.ANSWERED.getCode());
            questionMapper.incrementAnswerCount(questionId);
            questionMapper.updateAiAssisted(questionId, (byte) 1);

            // 通知提问者
            eventBus.publish(new AiAnswerGeneratedEvent(
                question.getUserId(), questionId, answer.getAnswerId()
            ));

            log.info("AI辅助回答已生成, questionId={}, answerId={}",
                questionId, answer.getAnswerId());

        } catch (Exception e) {
            log.error("AI辅助回答生成失败, questionId=" + questionId, e);
        } finally {
            redis.delete(cooldownKey);
        }
    }

    /**
     * 构建 AI 辅助 Prompt
     */
    private AiAssistPrompt buildAiAssistPrompt(DiscussionQuestion question) {
        DiscussionThread thread = threadMapper.selectById(question.getThreadId());

        return AiAssistPrompt.builder()
            .questionTitle(question.getTitle())
            .questionBody(question.getBodyPlain())
            .subjectCode(thread.getSubjectCode())
            .gradeLevel(thread.getGradeLevel())
            .contentTitle(thread.getContentTitle())
            .kpCodes(question.getKpCodes())
            .instruction(
                "你是一位热心的高年级学长/学姐，正在学习社区的讨论区回答同学的提问。" +
                "请用友好、易懂的语气回答，注意：\n" +
                "1. 回答要准确，适合提问者的学段水平\n" +
                "2. 先给出直接回答，再补充解释\n" +
                "3. 如果涉及公式，使用 LaTeX 格式\n" +
                "4. 回答不超过500字\n" +
                "5. 末尾加上'（以上回答由AI生成，如有疑问请追问或等待老师/同学回答）'"
            )
            .model(selectModelByComplexity(question))
            .build();
    }

    private String selectModelByComplexity(DiscussionQuestion q) {
        // 简单问题用轻量模型，复杂推理用强模型
        if (q.getSubjectCode().equals("MATH") || q.getSubjectCode().equals("PHY")) {
            return "qwen-plus"; // 推理增强
        }
        return "qwen-turbo"; // 通用轻量
    }

    // ─────────────────────────────────────────
    // FAQ 自动萃取
    // ─────────────────────────────────────────

    @Async
    public void extractFaq(Long questionId, Long answerId) {
        DiscussionQuestion question = questionMapper.selectById(questionId);
        DiscussionAnswer answer = answerMapper.selectById(answerId);

        if (question == null || answer == null) return;
        if (question.getViewCount() < 50) return;
        if (answer.getVoteScore() < 5) return;

        // 检查是否已有FAQ
        if (faqMapper.existsByQuestion(questionId)) return;

        try {
            // LLM 生成摘要
            FaqExtractionResult result = aiTutorClient.extractFaq(
                question.getTitle(), question.getBodyPlain(),
                answer.getBodyPlain()
            );

            DiscussionFaq faq = DiscussionFaq.builder()
                .threadId(question.getThreadId())
                .questionId(questionId)
                .answerId(answerId)
                .questionTitle(result.getQuestionTitle())
                .answerSummary(result.getAnswerSummary())
                .kpCodes(question.getKpCodes())
                .status(0) // 待审
                .build();
            faqMapper.insert(faq);

            log.info("FAQ自动萃取完成, faqId={}, questionId={}",
                faq.getFaqId(), questionId);

        } catch (Exception e) {
            log.error("FAQ萃取失败, questionId=" + questionId, e);
        }
    }

    private void validateUserCanPost(Long userId) {
        // 频率限制：30秒1个问题
        String rateLimitKey = "discuss:rate:" + userId;
        if (redis.opsForValue().setIfAbsent(rateLimitKey, 1, 30, TimeUnit.SECONDS)) {
            // 频次限制：每日上限
            String dailyKey = "discuss:daily:" + userId + ":" + LocalDate.now();
            Integer count = (Integer) redis.opsForValue().get(dailyKey);
            int limit = membershipService.isMember(userId)
                ? MEMBER_USER_DAILY_LIMIT : FREE_USER_DAILY_LIMIT;
            if (count != null && count >= limit) {
                throw new BizException("DISCUSS_104",
                    "今日提问数已达上限（" + limit + "题/天）");
            }
            redis.opsForValue().increment(dailyKey);
            redis.expire(dailyKey, 1, TimeUnit.DAYS);
        } else {
            throw new BizException("DISCUSS_103", "操作过快，请稍后再试");
        }

        // 禁言检查
        if (userBanService.isBanned(userId, "discuss")) {
            throw new BizException("DISCUSS_101", "账号已被禁言");
        }
    }

    private void validateQuestionContent(PublishQuestionReq req) {
        if (req.getTitle() == null || req.getTitle().length() > QUESTION_TITLE_MAX) {
            throw new BizException("DISCUSS_001", "标题长度超限");

        if (req.getImages() != null && req.getImages().size() > MAX_IMAGES) {

        }
    }

        if (req.getBody() == null || req.getBody().length() > ANSWER_BODY_MAX) {
            throw new BizException("DISCUSS_002", "回答内容长度超限");
        }
        if (req.getImages() != null && req.getImages().size() > MAX_IMAGES) {

        }
    }

    private void validateVoteTarget(int targetType, Long targetId, Long userId) {
        if (targetType == VoteTarget.QUESTION.getCode()) {
            DiscussionQuestion q = questionMapper.selectById(targetId);

    }
```

| Redis缓存不可用 | 计数/限流不可用 | 降级为数据库查询；限流临时放宽 |

```java
/**
 * 游标分页（避免深翻页性能问题）
 */
public PageResult<QuestionDTO> getQuestionsByCursor(
        Long threadId, Long cursor, int size, String sort) {
    // sort: "new" | "hot" | "unanswered"
    List<DiscussionQuestion> questions;
    if ("new".equals(sort)) {
        questions = questionMapper.findByThreadAfterCursor(
            threadId, cursor, size + 1 // size+1判断是否有下一页
        );
    } else if ("hot".equals(sort)) {
        questions = questionMapper.findHotByThread(
            threadId, cursor, size + 1
        );
    } else {
        questions = questionMapper.findUnansweredByThread(
            threadId, cursor, size + 1
        );
    }

    boolean hasNext = questions.size() > size;
    if (hasNext) {
        questions = questions.subList(0, size);
    }

    return PageResult.of(
        questions.stream().map(QuestionDTO::from).collect(Collectors.toList()),
        hasNext
    );
}
```

```java
/**
 * 高频计数使用Redis原子操作，异步批量同步到MySQL
 */
@Component
public class ViewCountSync {

    private static final String VIEW_COUNT_KEY = "discuss:views:pending";

    /**
     * 增加浏览数（Redis原子操作）
     */
    public void incrementViewCount(int targetType, Long targetId) {
        String field = targetType + ":" + targetId;
        redis.opsForHash().increment(VIEW_COUNT_KEY, field, 1);
    }

    /**
     * 每30秒批量同步到数据库
     */
    @Scheduled(fixedRate = 30 * 1000)
    public void syncToDatabase() {
        Map<Object, Object> entries = redis.opsForHash().entries(VIEW_COUNT_KEY);
        if (entries.isEmpty()) return;

        redis.delete(VIEW_COUNT_KEY);

        Map<String, Long> counts = entries.entrySet().stream()
            .collect(Collectors.toMap(
                e -> (String) e.getKey(),
                e -> (Long) e.getValue()
            ));

        // 按targetType分组批量更新
        counts.entrySet().stream()
            .collect(Collectors.groupingBy(
                e -> e.getKey().split(":")[0] // targetType
            ))
            .forEach((type, items) -> {
                if ("1".equals(type)) {
                    questionMapper.batchAddViewCount(toLongMap(items, "1"));
                } else if ("2".equals(type)) {
                    answerMapper.batchAddViewCount(toLongMap(items, "2"));
                }
            });
    }
}
```

### 10.3 高频疑问知识点监控

```sql
-- 每周高频疑问知识点 Top 20
SELECT
    JSON_UNQUOTE(JSON_EXTRACT(kp_codes, '$[0]')) AS kp_code,
    COUNT(*) AS question_count,
    COUNT(DISTINCT user_id) AS unique_askers,
    AVG(answer_count) AS avg_answers,
    SUM(CASE WHEN has_accepted = 1 THEN 1 ELSE 0 END) AS resolved_count
FROM discussion_question
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
  AND status >= 1
  AND kp_codes IS NOT NULL
GROUP BY kp_code
HAVING question_count >= 3
ORDER BY question_count DESC
LIMIT 20;
```

> **运营价值**：高频疑问知识点可反馈给内容团队，优化对应课文的讲解质量；同时驱动 AI Prompt 模板更新，加强该知识点的 RAG 检索能力。
