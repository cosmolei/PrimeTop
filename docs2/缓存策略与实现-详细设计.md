## 3. 缓存数据结构

### 3.1 缓存分类与过期策略

| 缓存类型 | Key 前缀 | 数据结构 | 过期时间 | 更新策略 | 示例 |
|---------|----------|----------|----------|----------|------|
| 用户会话 | `session:{user_id}:{device_id}` | Hash | 24小时 | 登录/登出 | 用户登录状态、Token |
| 用户画像 | `user:profile:{user_id}` | Hash | 1小时 | 写入后刷新 | 用户年级、学科、会员等级 |
| 学习记录 | `learning:record:{user_id}` | ZSet | 7天 | 学习时更新 | 最近学习时间线 |
| 知识点 | `kp:{knowledge_point_id}` | Hash | 30天 | 内容变更时更新 | 知识点名称、难度、关联考点 |
| 章节内容 | `chapter:{chapter_id}` | Hash | 7天 | 内容变更时更新 | 章节摘要、知识清单 |
| 题目解析 | `question:answer:{question_id}` | String | 30天 | 生成后缓存 | AI生成的题目解析 |
| AI对话 | `chat:context:{session_id}` | List | 4小时 | 对话时追加 | 对话历史消息 |
| 权限缓存 | `perm:{user_id}` | Set | 1小时 | 权限变更时刷新 | 用户角色、权限列表 |
| 配置信息 | `config:{config_key}` | String | 10分钟 | 配置变更时刷新 | 功能开关、阈值配置 |
| 热点查询 | `query:hot:{hash_key}` | String | 5分钟 | 查询时设置 | 复杂查询结果缓存 |
| 分布式锁 | `lock:{resource}:{identifier}` | String | 30秒（可续期） | 获取锁时设置 | 防并发、防重复 |
| 限流计数 | `rate:{user_id}:{api}` | String | 时间窗口（如60秒） | 请求时递增 | API调用频率限制 |

## 4. 缓存操作规范

### 4.1 统一缓存客户端封装

```python
# app/core/redis_client.py

import json
import logging
from typing import Optional, Any, List, Dict, Union
from datetime import timedelta
from functools import wraps

import redis
from redis import Redis
from app.core.redis import cache_pool, session_pool, lock_pool

logger = logging.getLogger(__name__)

class CacheClient:
    """统一缓存客户端"""

    def __init__(self, pool):
        self.redis = Redis(connection_pool=pool)
        self.default_ttl = 3600  # 默认过期时间（秒）

    def get(self, key: str) -> Optional[str]:
        """获取缓存值"""
        try:
            return self.redis.get(key)
        except Exception as e:
            logger.error(f"Redis GET error: key={key}, error={e}")
            return None

    def set(self, key: str, value: str, ttl: Optional[int] = None) -> bool:
        """设置缓存值"""
        try:
            expire_time = ttl if ttl is not None else self.default_ttl
            return self.redis.setex(key, expire_time, value)
        except Exception as e:
            logger.error(f"Redis SET error: key={key}, error={e}")
            return False

    def delete(self, key: str) -> bool:
        """删除缓存"""
        try:
            return self.redis.delete(key) > 0
        except Exception as e:
            logger.error(f"Redis DELETE error: key={key}, error={e}")
            return False

    def expire(self, key: str, ttl: int) -> bool:
        """设置过期时间"""
        try:
            return self.redis.expire(key, ttl)
        except Exception as e:
            logger.error(f"Redis EXPIRE error: key={key}, error={e}")
            return False

    def exists(self, key: str) -> bool:
        """检查键是否存在"""
        try:
            return self.redis.exists(key) > 0
        except Exception as e:
            logger.error(f"Redis EXISTS error: key={key}, error={e}")
            return False

    def get_hash(self, key: str, field: Optional[str] = None) -> Union[Optional[str], Dict[str, str]]:
        """获取Hash值"""
        try:
            if field:
                return self.redis.hget(key, field)
            else:
                return self.redis.hgetall(key)
        except Exception as e:
            logger.error(f"Redis HGET/HGETALL error: key={key}, field={field}, error={e}")
            return None if field else {}

    def set_hash(self, key: str, mapping: Dict[str, str], ttl: Optional[int] = None) -> bool:
        """设置Hash值"""
        try:
            result = self.redis.hset(key, mapping=mapping)
            if ttl:
                self.redis.expire(key, ttl)
            return result > 0
        except Exception as e:
            logger.error(f"Redis HSET error: key={key}, error={e}")
            return False

    def zadd(self, key: str, mapping: Dict[str, float], ttl: Optional[int] = None) -> int:
        """添加有序集合成员"""
        try:
            result = self.redis.zadd(key, mapping)
            if ttl:
                self.redis.expire(key, ttl)
            return result
        except Exception as e:
            logger.error(f"Redis ZADD error: key={key}, error={e}")
            return 0

    def zrevrange(self, key: str, start: int = 0, end: int = -1) -> List[str]:
        """获取有序集合成员（按分数降序）"""
        try:
            return self.redis.zrevrange(key, start, end)
        except Exception as e:
            logger.error(f"Redis ZREVRANGE error: key={key}, error={e}")
            return []

    def lpush(self, key: str, *values) -> int:
        """从左侧推入列表"""
        try:
            return self.redis.lpush(key, *values)
        except Exception as e:
            logger.error(f"Redis LPUSH error: key={key}, error={e}")
            return 0

    def rpop(self, key: str) -> Optional[str]:
        """从右侧弹出列表"""
        try:
            return self.redis.rpop(key)
        except Exception as e:
            logger.error(f"Redis RPOP error: key={key}, error={e}")
            return None

    def lrange(self, key: str, start: int = 0, end: int = -1) -> List[str]:
        """获取列表范围"""
        try:
            return self.redis.lrange(key, start, end)
        except Exception as e:
            logger.error(f"Redis LRANGE error: key={key}, error={e}")
            return []

# 全局缓存实例
cache = CacheClient(cache_pool)
session_cache = CacheClient(session_pool)
lock_cache = CacheClient(lock_pool)
```

### 4.2 缓存装饰器

```python
# app/common/cache.py

import json
import logging
from functools import wraps
from typing import Optional, Callable, Any
from hashlib import md5

from app.core.redis_client import cache

logger = logging.getLogger(__name__)

def cache_result(
    key_prefix: str,
    ttl: int = 3600,
    key_builder: Optional[Callable] = None,
    serialize: bool = True,
):
    """缓存函数结果装饰器

    Args:
        key_prefix: 缓存键前缀
        ttl: 过期时间（秒）
        key_builder: 自定义键生成函数（参数为函数参数）
        serialize: 是否序列化返回值（JSON）
    """
    def decorator(func: Callable) -> Callable:
        @wraps(func)
        def wrapper(*args, **kwargs) -> Any:
            # 生成缓存键
            if key_builder:
                cache_key = key_builder(*args, **kwargs)
            else:
                # 默认键生成：前缀 + 参数哈希
                key_params = f"{args}{kwargs}"
                key_hash = md5(key_params.encode()).hexdigest()
                cache_key = f"{key_prefix}:{key_hash}"

            # 尝试从缓存获取
            cached_value = cache.get(cache_key)
            if cached_value is not None:
                logger.debug(f"Cache HIT: {cache_key}")
                if serialize:
                    return json.loads(cached_value)
                else:
                    return cached_value

            # 缓存未命中，执行函数
            logger.debug(f"Cache MISS: {cache_key}")
            result = func(*args, **kwargs)

            # 写入缓存
            try:
                cache_value = json.dumps(result) if serialize else result
                cache.set(cache_key, cache_value, ttl)
            except Exception as e:
                logger.warning(f"Cache SET failed: {cache_key}, error={e}")

            return result

        return wrapper

    return decorator


def invalidate_cache(key_pattern: str) -> int:
    """使缓存失效（支持通配符）

    Args:
        key_pattern: 键模式，如 "user:*"

    Returns:
        删除的键数量
    """
    try:
        keys = cache.redis.keys(key_pattern)
        if keys:
            return cache.redis.delete(*keys)
        return 0
    except Exception as e:
        logger.error(f"Cache INVALIDATE error: pattern={key_pattern}, error={e}")
        return 0
```

### 5.1 缓存更新模式

| 模式 | 说明 | 适用场景 | 优点 | 缺点 |
|------|------|----------|------|------|
| Cache Aside | 应用代码管理缓存，先查缓存，未命中查数据库 | 通用场景 | 简单、灵活 | 需要应用代码处理 |
| Read Through | 缓存层自动加载数据 | 读多写少 | 应用代码简单 | 缓存层复杂 |
| Write Through | 写入时同时更新缓存和数据库 | 数据一致性要求高 | 强一致性 | 写入性能低 |
| Write Behind | 写入时只更新缓存，异步写入数据库 | 写入性能要求高 | 高性能 | 数据丢失风险 |

def set_versioned_cache(key: str, value: dict, ttl: int = 3600):
    """设置带版本控制的缓存"""
    version_key = f"{key}:version"
    data_key = f"{key}:data"

    # 获取或创建版本号
    current_version = cache.redis.incr(version_key)
    if current_version == 1:
        cache.redis.expire(version_key, ttl * 2)  # 版本号过期时间更长

    # 写入数据（带版本号）
    cache.redis.hset(data_key, f"v{current_version}", json.dumps(value))
    cache.redis.expire(data_key, ttl)

    return current_version

def get_versioned_cache(key: str):
    """获取带版本控制的缓存"""
    version_key = f"{key}:version"
    data_key = f"{key}:data"

    # 获取当前版本号
    current_version = cache.redis.get(version_key)
    if not current_version:
        return None

    # 获取数据
    value_json = cache.redis.hget(data_key, f"v{current_version}")
    if value_json:
        return json.loads(value_json)

    return None

def invalidate_versioned_cache(key: str):
    """使带版本控制的缓存失效"""
    version_key = f"{key}:version"
    data_key = f"{key}:data"

    # 增加版本号（旧版本失效）
    cache.redis.incr(version_key)

## 7. 分布式锁实现

### 7.1 基础分布式锁

```python
from app.core.redis_client import lock_cache
import uuid

class DistributedLock:
    """分布式锁"""

    def __init__(self, resource: str, timeout: int = 30, auto_renewal: bool = False):
        self.resource = resource
        self.timeout = timeout
        self.auto_renewal = auto_renewal
        self.identifier = str(uuid.uuid4())
        self.lock_key = f"lock:{resource}:{self.identifier}"
        self.acquired = False
        self._stop_renewal = False

    def acquire(self, blocking: bool = True, blocking_timeout: int = None) -> bool:
        """获取锁

        Args:
            blocking: 是否阻塞等待
            blocking_timeout: 阻塞等待超时时间（秒）

        Returns:
            是否成功获取锁
        """
        start_time = time.time()

        while True:
            # 尝试获取锁
            result = lock_cache.redis.set(
                self.lock_key,
                self.identifier,
                nx=True,  # 只在键不存在时设置
                ex=self.timeout  # 自动过期时间
            )

            if result:
                self.acquired = True
                logger.info(f"Lock ACQUIRED: {self.lock_key}")

                # 自动续期
                if self.auto_renewal:
                    self._start_renewal()

                return True

            if not blocking:
                return False

            # 检查阻塞超时
            if blocking_timeout and (time.time() - start_time) >= blocking_timeout:
                logger.warning(f"Lock TIMEOUT: {self.lock_key}")
                return False

            # 短暂等待后重试
            time.sleep(0.1)

    def release(self) -> bool:
        """释放锁"""
        if not self.acquired:
            return False

        # 停止自动续期
        self._stop_renewal = True

        # 使用Lua脚本确保只释放自己持有的锁
        lua_script = """
        if redis.call("get", KEYS[1]) == ARGV[1] then
            return redis.call("del", KEYS[1])
        else
            return 0
        end
        """

        result = lock_cache.redis.eval(
            lua_script,
            1,
            self.lock_key,
            self.identifier
        )

        self.acquired = False
        logger.info(f"Lock RELEASED: {self.lock_key}, result={result}")

        return bool(result)

    def _start_renewal(self):
        """启动自动续期线程"""
        import threading

        def renewal_thread():
            while not self._stop_renewal and self.acquired:
                time.sleep(self.timeout // 3)  # 每1/3过期时间续期一次
                if self.acquired:
                    lock_cache.redis.expire(self.lock_key, self.timeout)

        thread = threading.Thread(target=renewal_thread, daemon=True)
        thread.start()

    def __enter__(self):
        self.acquire()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.release()
```

import logging
from typing import Dict
from app.core.redis_client import cache

logger = logging.getLogger(__name__)

class CacheMonitor:
    """缓存监控器"""

    @staticmethod
    def get_info() -> Dict:
        """获取Redis信息"""
        try:
            info = cache.redis.info()
            return {
                "version": info.get("redis_version"),
                "used_memory_human": info.get("used_memory_human"),
                "used_memory_peak_human": info.get("used_memory_peak_human"),
                "total_connections_received": info.get("total_connections_received"),
                "connected_clients": info.get("connected_clients"),
                "total_keys": info.get("db0", {}).get("keys", 0),
            }
        except Exception as e:
            logger.error(f"Get cache info failed: {e}")
            return {}

    @staticmethod
    def get_stats() -> Dict:
        """获取缓存统计信息"""
        try:
            stats = cache.redis.info("stats")
            return {
                "keyspace_hits": stats.get("keyspace_hits", 0),
                "keyspace_misses": stats.get("keyspace_misses", 0),
                "total_commands": stats.get("total_commands_processed", 0),
                "expired_keys": stats.get("expired_keys", 0),
                "evicted_keys": stats.get("evicted_keys", 0),
            }
        except Exception as e:
            logger.error(f"Get cache stats failed: {e}")
            return {}

    @staticmethod
    def calculate_hit_rate() -> float:
        """计算缓存命中率"""
        stats = CacheMonitor.get_stats()
        hits = stats.get("keyspace_hits", 0)
        misses = stats.get("keyspace_misses", 0)
        total = hits + misses

        if total == 0:
            return 0.0

        return (hits / total) * 100

    @staticmethod
    def get_slow_logs(count: int = 10) -> list:
        """获取慢查询日志"""
        try:
            return cache.redis.slowlog_get(count)
        except Exception as e:
            logger.error(f"Get slow logs failed: {e}")
            return []

    @staticmethod
    def log_cache_stats():
        """记录缓存统计信息（定时任务）"""
        info = CacheMonitor.get_info()
        stats = CacheMonitor.get_stats()
        hit_rate = CacheMonitor.calculate_hit_rate()

        logger.info(
            f"Cache Stats - "
            f"HitRate: {hit_rate:.2f}%, "
            f"Memory: {info.get('used_memory_human')}, "
            f"Clients: {info.get('connected_clients')}, "
            f"Keys: {info.get('total_keys')}, "
            f"Expired: {stats.get('expired_keys')}, "
            f"Evicted: {stats.get('evicted_keys')}"
        )

        # 检查告警阈值
        if hit_rate < 70:
            logger.warning(f"Cache hit rate too low: {hit_rate:.2f}%")

### 9.2 降级实现

```python
from app.common.cache import cache_result
import functools

def cache_with_fallback(
    key_prefix: str,
    ttl: int = 3600,
    fallback_value: Any = None,
):
    """带降级的缓存装饰器"""
    def decorator(func: Callable) -> Callable:
        @wraps(func)
        def wrapper(*args, **kwargs) -> Any:
            try:
                # 尝试从缓存获取
                cache_key = f"{key_prefix}:{args[0]}"  # 简化键生成

                cached_value = cache.get(cache_key)
                if cached_value is not None:
                    return json.loads(cached_value)

                # 执行函数
                result = func(*args, **kwargs)

                # 写入缓存
                cache.set(cache_key, json.dumps(result), ttl=ttl)

                return result

            except Exception as e:
                logger.error(f"Cache operation failed: {e}, using fallback")

                # 缓存失败，返回降级值
                if fallback_value is not None:
                    return fallback_value

                # 无降级值，直接执行函数
                return func(*args, **kwargs)

        return wrapper

    return decorator

# 使用示例
@cache_with_fallback(
    key_prefix="user:profile",
    ttl=3600,
    fallback_value=None
)
def get_user_profile_safe(user_id: str):
    """获取用户画像（带降级）"""
    return db.query(User).filter(User.id == user_id).first()
```

## 10. 最佳实践

### 10.1 缓存设计原则

1. **键命名规范**
   - 使用冒号分隔层次
   - 包含业务标识（如 `user:`, `kp:`, `question:`）
   - 避免过长的键名

2. **过期时间设置**
   - 根据数据更新频率设置
   - 避免所有键同时过期
   - 重要数据设置较长过期时间

3. **数据序列化**
   - 使用JSON格式
   - 避免存储过大的对象
   - 考虑压缩大型数据

4. **内存优化**
   - 定期清理无用键
   - 设置合理的过期时间
   - 监控内存使用情况

### 10.2 性能优化建议

1. **批量操作**
   - 使用 `mget` / `mset` 批量读写
   - 使用 Pipeline 减少网络往返

2. **数据结构选择**
   - Hash 存储对象属性
   - ZSet 存储排序列表
   - Set 存储去重集合

3. **连接管理**
   - 使用连接池
   - 合理设置连接数
   - 避免频繁创建连接

4. **本地缓存**
   - 对不常变化的数据使用本地缓存
   - 结合多级缓存策略
   - 注意本地缓存的一致性

### 10.3 安全建议

1. **访问控制**
   - 设置 Redis 密码
   - 使用防火墙限制访问
   - 避免公网暴露

2. **数据加密**
   - 敏感数据加密后存储
   - 使用 TLS 加密传输
   - 定期轮换密钥

3. **命令限制**
   - 禁用危险命令（FLUSHDB, FLUSHALL）
   - 使用 `rename-command` 重命名命令
   - 限制高危命令的执行

    # 第一次获取（查询数据库）
    profile1 = get_user_profile(user_id)

    # 第二次获取（从缓存获取）
    profile2 = get_user_profile(user_id)

    update_user_profile(user_id, {"username": "new_name"})
