# 客户端网络请求治理与弱网适配方案 - 详细设计

## 1. 概述

### 1.1 背景

PrimeTop 作为面向全学段的移动端 AI 辅助学习 APP，网络请求场景复杂且多样：AI 对话的 SSE 流式响应、拍题 OCR 的大图上传、错题本的高频读写、同步课堂的离线资源包下载、学习记录的实时上报等。移动端网络环境天然不稳定（地铁、电梯、校园 WiFi 拥堵），部分目标用户（乡村学生）甚至长期处于弱网环境。

现有各模块文档（客户端架构、离线缓存、性能优化）分别从各自角度提及了网络处理，但缺少一份统一的网络请求治理方案，定义请求分类、优先级调度、弱网检测、降级策略和离线队列等横切关注点。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **请求分级调度** | 不同业务请求按优先级排队，高优先级请求优先获得网络资源 |
| **弱网感知** | 实时检测网络质量，自动切换请求策略 |
| **离线可用** | 关键操作在无网络时本地排队，网络恢复后自动重放 |
| **流量节约** | 根据网络类型（WiFi/移动数据）自适应调整请求行为 |
| **体验一致** | 对上层业务屏蔽网络波动，提供统一的成功/失败/降级语义 |
| **可观测** | 网络质量、请求成功率、重试次数等指标可追踪 |

### 1.3 与其他文档的关系

| 文档 | 交叉点 | 本文档侧重点 |
|------|--------|-------------|
| 客户端架构与前端框架 | Dio 网络层封装 | 本文档细化 Dio 之上的请求治理层 |
| 离线缓存与数据同步 | 离线数据同步策略 | 本文档聚焦网络请求层面的队列与重放 |
| 非功能性需求-性能优化 | 首屏加载、资源预加载 | 本文档聚焦网络请求维度的优化 |
| 错误处理与服务降级 | 降级策略 | 本文档聚焦网络维度的降级 |
| 配置中心与动态配置 | 超时/重试等参数动态下发 | 本文档定义消费方的具体策略 |

## 3. 请求分类与优先级体系

### 3.1 请求通道定义

根据业务特征，将所有网络请求分为 6 个通道（Channel），每个通道有独立的优先级、并发数和超时策略。

```dart
/// 请求通道枚举
enum RequestChannel {
  /// 关键交互 - AI对话流式、拍题OCR
  /// 最高优先级，用户正在等待结果
  critical,

  /// 用户操作 - 错题收录、练习提交、作文提交
  /// 高优先级，用户刚做了操作需要确认
  userAction,

  /// 数据同步 - 学习记录上报、进度同步、答题记录
  /// 中优先级，可延迟但不能丢
  dataSync,

  /// 内容加载 - 同步课堂章节、知识点详情、题目列表
  /// 中优先级，影响浏览体验
  contentLoad,

  /// 资源下载 - 教材资源包、音频文件、图片预加载
  /// 低优先级，后台静默下载
  resourceDownload,

  /// 数据上报 - 埋点事件、崩溃日志、性能指标
  /// 最低优先级，批量合并后上报
  telemetry,
}
```

### 3.2 通道配置矩阵

| 通道 | 优先级 | 最大并发 | 默认超时 | 弱网超时 | 离线可队列 | 重试次数 |
|------|--------|---------|---------|---------|-----------|---------|
| `critical` | 100 | 3 | 15s | 30s | ❌ | 1 |
| `userAction` | 80 | 2 | 10s | 20s | ✅ | 2 |
| `dataSync` | 60 | 2 | 8s | 15s | ✅ | 3 |
| `contentLoad` | 50 | 4 | 10s | 20s | ❌ | 1 |
| `resourceDownload` | 20 | 1 | 30s | 60s | ✅ | 5 |
| `telemetry` | 10 | 1 | 5s | 10s | ✅ | 2 |

## 4. 网络质量检测引擎

### 4.1 网络质量分级

```dart
/// 网络质量等级
enum NetworkQuality {
  /// 优秀 - WiFi/5G，延迟 < 100ms，带宽充足
  excellent,

  /// 良好 - 4G/强WiFi，延迟 100-300ms
  good,

  /// 一般 - 3G/弱WiFi，延迟 300-1000ms
  fair,

  /// 差 - 2G/极弱信号，延迟 > 1000ms，高丢包
  poor,

  /// 离线 - 无网络连接
  offline,
}

/// 网络质量等级对应的数值范围
extension NetworkQualityScore on NetworkQuality {
  int get minScore => switch (this) {
    NetworkQuality.excellent => 80,
    NetworkQuality.good => 60,
    NetworkQuality.fair => 30,
    NetworkQuality.poor => 0,
    NetworkQuality.offline => -1,
  };
}
```

### 4.2 检测指标与算法

网络质量评分采用加权综合评分模型：

```
qualityScore = w1 × latencyScore + w2 × successRateScore + w3 × bandwidthScore + w4 × connectionTypeScore

其中:
  latencyScore    = max(0, 100 - (avgLatencyMs / 10))        // 延迟越低越好
  successRateScore = recentSuccessCount / recentTotalCount × 100
  bandwidthScore  = estimatedBandwidthKbps / 1000 × 100       // capped at 100
  connectionTypeScore = WiFi:100, 5G:90, 4G:70, 3G:40, 2G:10

  w1=0.3, w2=0.3, w3=0.2, w4=0.2
```

### 4.3 检测实现

```dart
/// 网络质量检测引擎
class NetworkQualityDetector {
  final Dio _dio;
  final Connectivity _connectivity;

  /// 最近 N 次请求的延迟记录（滑动窗口）
  final _recentLatencies = <_LatencyRecord>[];
  static const _maxRecords = 20;

  /// 最近 N 次请求的成功/失败统计
  int _recentSuccess = 0;
  int _recentFailure = 0;
  static const _statsWindow = 20;

  /// 当前网络质量（实时更新）
  NetworkQuality _currentQuality = NetworkQuality.good;
  NetworkQuality get currentQuality => _currentQuality;

  /// 质量变化流（供 UI 层监听显示网络提示）
  final _qualityStream = StreamController<NetworkQuality>.broadcast();
  Stream<NetworkQuality> get qualityStream => _qualityStream.stream;

  /// 连接类型
  ConnectivityResult _connectionType = ConnectivityResult.wifi;

  /// 质量检测探针端点（轻量级健康检查）
  static const _probeUrl = '/api/v1/health/ping';
  static const _probeInterval = Duration(seconds: 30);
  Timer? _probeTimer;

  /// 初始化
  Future<void> init() async {
    // 监听连接类型变化
    _connectivity.onConnectivityChanged.listen(_onConnectivityChanged);
    _connectionType = await _connectivity.checkConnectivity()
        .then((r) => r.firstOrNull ?? ConnectivityResult.none);

    // 启动定期探针
    _startProbing();

    // 初始检测
    await _probeOnce();
  }

  /// 记录一次请求结果（由 Dio 拦截器调用）
  void recordRequestResult({
    required Duration latency,
    required bool success,
    int? responseBytes,
  }) {
    // 记录延迟
    _recentLatencies.add(_LatencyRecord(
      timestamp: DateTime.now(),
      latencyMs: latency.inMilliseconds,
    ));
    if (_recentLatencies.length > _maxRecords) {
      _recentLatencies.removeAt(0);
    }

    // 记录成功/失败
    if (success) {
      _recentSuccess++;
    } else {
      _recentFailure++;
    }
    final total = _recentSuccess + _recentFailure;
    if (total > _statsWindow) {
      if (_recentSuccess > 0) _recentSuccess--;
      if (_recentFailure > 0) _recentFailure--;
    }

    // 重新计算质量
    _recalculateQuality();
  }

  void _recalculateQuality() {
    final score = _calculateScore();
    final newQuality = _scoreToQuality(score);

    if (newQuality != _currentQuality) {
      _currentQuality = newQuality;
      _qualityStream.add(newQuality);
    }
  }

  double _calculateScore() {
    if (_connectionType == ConnectivityResult.none) {
      return -1; // 离线
    }

    // 延迟得分 (w=0.3)
    final latencyScore = _recentLatencies.isEmpty
        ? 50.0 // 无数据时给中等分数
        : _recentLatencies
              .map((r) => (100 - (r.latencyMs / 10)).clamp(0, 100).toDouble())
              .reduce((a, b) => a + b) /
              _recentLatencies.length;

    // 成功率得分 (w=0.3)
    final total = _recentSuccess + _recentFailure;
    final successScore = total == 0 ? 50.0 : (_recentSuccess / total) * 100;

    // 连接类型得分 (w=0.2)
    final typeScore = switch (_connectionType) {
      ConnectivityResult.wifi => 100.0,
      ConnectivityResult.mobile => 70.0, // 简化，实际应细分 5G/4G/3G
      ConnectivityResult.ethernet => 100.0,
      _ => 30.0,
    };

    // 带宽得分 (w=0.2) - 简化：根据连接类型估算
    final bandwidthScore = typeScore; // 简化处理

    return 0.3 * latencyScore +
           0.3 * successScore +
           0.2 * bandwidthScore +
           0.2 * typeScore;
  }

  NetworkQuality _scoreToQuality(double score) {
    if (score < 0) return NetworkQuality.offline;
    if (score >= 80) return NetworkQuality.excellent;
    if (score >= 60) return NetworkQuality.good;
    if (score >= 30) return NetworkQuality.fair;
    return NetworkQuality.poor;
  }

  Future<void> _probeOnce() async {
    try {
      final stopwatch = Stopwatch()..start();
      await _dio.get(_probeUrl).timeout(const Duration(seconds: 5));
      stopwatch.stop();
      recordRequestResult(
        latency: stopwatch.elapsed,
        success: true,
      );
    } catch (_) {
      recordRequestResult(
        latency: const Duration(seconds: 5),
        success: false,
      );
    }
  }

  void _startProbing() {
    _probeTimer?.cancel();
    _probeTimer = Timer.periodic(_probeInterval, (_) => _probeOnce());
  }

  void _onConnectivityChanged(List<ConnectivityResult> results) {
    final result = results.firstOrNull ?? ConnectivityResult.none;
    if (result != _connectionType) {
      _connectionType = result;
      // 网络类型变化时立即探测
      if (result != ConnectivityResult.none) {
        _probeOnce();
        // 网络恢复时触发离线队列重放
        if (_currentQuality == NetworkQuality.offline) {
          _recalculateQuality();
        }
      } else {
        _currentQuality = NetworkQuality.offline;
        _qualityStream.add(NetworkQuality.offline);
      }
    }
  }

  void dispose() {
    _probeTimer?.cancel();
    _qualityStream.close();
  }
}

class _LatencyRecord {
  final DateTime timestamp;
  final int latencyMs;
  _LatencyRecord({required this.timestamp, required this.latencyMs});
}
```

## 5. 优先级调度器

### 5.1 调度策略

调度器维护每个通道的待执行请求队列，按优先级从高到低调度：

1. 每个通道维护一个 FIFO 队列
2. 全局调度器按通道优先级轮转选取请求
3. 同通道内的并发数受 `maxConcurrency` 限制
4. 低优先级通道在弱网时自动暂停（`resourceDownload`、`telemetry`）

### 5.2 调度器实现

```dart
/// 优先级调度器
class PriorityScheduler {
  final NetworkQualityDetector _qualityDetector;

  /// 每个通道的待执行队列
  final Map<RequestChannel, Queue<_QueuedRequest>> _queues = {};

  /// 每个通道当前执行中的请求数
  final Map<RequestChannel, int> _runningCount = {};

  /// 全局调度锁
  final _scheduleLock = Mutex();

  PriorityScheduler(this._qualityDetector) {
    for (final channel in RequestChannel.values) {
      _queues[channel] = Queue();
      _runningCount[channel] = 0;
    }
  }

  /// 提交请求到调度器
  Future<Response> submit({
    required RequestChannel channel,
    required Future<Response> Function() executor,
    required Duration timeout,
    int retryCount = 0,
  }) {
    final completer = Completer<Response>();
    final config = kChannelConfigs[channel]!;

    final request = _QueuedRequest(
      channel: channel,
      executor: executor,
      timeout: timeout,
      maxRetries: retryCount > 0 ? retryCount : config.maxRetries,
      completer: completer,
      enqueuedAt: DateTime.now(),
    );

    _queues[channel]!.add(request);
    _schedule();

    return completer.future;
  }

  /// 触发调度
  void _schedule() {
    // 不用锁的方式：用 scheduleMicrotask 避免递归
    scheduleMicrotask(() => _doSchedule());
  }

  Future<void> _doSchedule() async {
    await _scheduleLock.acquire();
    try {
      final quality = _qualityDetector.currentQuality;

      // 按优先级从高到低遍历通道
      final sortedChannels = RequestChannel.values.toList()
        ..sort((a, b) =>
            kChannelConfigs[b]!.priority.compareTo(kChannelConfigs[a]!.priority));

      for (final channel in sortedChannels) {
        final config = kChannelConfigs[channel]!;

        // 弱网时暂停低优先级通道
        if (_shouldPauseChannel(channel, quality)) {
          continue;
        }

        // 填充该通道的并发槽位
        while (_runningCount[channel]! < config.maxConcurrency &&
               _queues[channel]!.isNotEmpty) {
          final request = _queues[channel]!.removeFirst();
          _runningCount[channel] = _runningCount[channel]! + 1;
          _executeRequest(request, config);
        }
      }
    } finally {
      _scheduleLock.release();
    }
  }

  /// 判断通道是否应在当前网络质量下暂停
  bool _shouldPauseChannel(RequestChannel channel, NetworkQuality quality) {
    return switch (quality) {
      NetworkQuality.poor =>
        // 弱网时只保留 critical 和 userAction
        channel == RequestChannel.resourceDownload ||
        channel == RequestChannel.telemetry ||
        channel == RequestChannel.contentLoad,
      NetworkQuality.fair =>
        // 一般网络时暂停资源下载和埋点
        channel == RequestChannel.resourceDownload ||
        channel == RequestChannel.telemetry,
      _ => false,
    };
  }

  Future<void> _executeRequest(
    _QueuedRequest request,
    ChannelConfig config,
  ) async {
    int attempt = 0;
    while (attempt <= request.maxRetries) {
      try {
        final response = await request.executor()
            .timeout(request.timeout);
        request.completer.complete(response);
        return;
      } on TimeoutException {
        attempt++;
        if (attempt > request.maxRetries) {
          request.completer.completeError(
            NetworkTimeoutException(channel: request.channel),
          );
          break;
        }
        // 指数退避
        await Future.delayed(Duration(seconds: pow(2, attempt).toInt()));
      } catch (e) {
        attempt++;
        if (attempt > request.maxRetries) {
          request.completer.completeError(e);
          break;
        }
        await Future.delayed(Duration(milliseconds: 500 * attempt));
      } finally {
        _runningCount[request.channel] =
            _runningCount[request.channel]! - 1;
        _schedule(); // 触发下一轮调度
      }
    }
  }

  /// 取消某个通道的所有排队请求
  void cancelChannel(RequestChannel channel) {
    final queue = _queues[channel]!;
    while (queue.isNotEmpty) {
      final request = queue.removeFirst();
      request.completer.completeError(
        RequestCancelledException(channel: channel),
      );
    }
  }
}

class _QueuedRequest {
  final RequestChannel channel;
  final Future<Response> Function() executor;
  final Duration timeout;
  final int maxRetries;
  final Completer<Response> completer;
  final DateTime enqueuedAt;
  int retryCount = 0;

  _QueuedRequest({
    required this.channel,
    required this.executor,
    required this.timeout,
    required this.maxRetries,
    required this.completer,
    required this.enqueuedAt,
  });
}
```

## 6. 离线队列管理器

### 6.1 设计原则

1. **只队列幂等操作**：只有安全可重试的请求才进入离线队列（GET、部分幂等 POST）
2. **持久化存储**：队列数据写入本地 SQLite，APP 重启后不丢失
3. **优先级继承**：入队时继承通道优先级，重放时按优先级执行
4. **过期清理**：超过 TTL 的队列请求自动清理，避免陈旧数据回放
5. **容量限制**：队列总量有上限，防止磁盘溢出

### 6.2 可队列操作清单

| 业务操作 | HTTP 方法 | 幂等性 | 离线队列 | TTL |
|----------|----------|--------|---------|-----|
| 学习记录上报 | POST | 幂等（基于 idempotency_key） | ✅ | 24h |
| 答题记录提交 | POST | 幂等（基于 attempt_id） | ✅ | 24h |
| 错题收录 | POST | 幂等（去重检查） | ✅ | 72h |
| 学习进度同步 | PUT | 幂等 | ✅ | 48h |
| 笔记/收藏操作 | POST | 幂等（idempotency_key） | ✅ | 72h |
| 埋点事件上报 | POST | 非严格幂等（允许少量重复） | ✅ | 12h |
| AI 对话请求 | POST | 非幂等 | ❌ | — |

### 6.5 离线队列管理器实现

```dart
/// 离线队列管理器
class OfflineQueueManager {
  final Database _db;
  final NetworkQualityDetector _qualityDetector;
  final PriorityScheduler _scheduler;

  static const _maxQueueSize = 1000;
  static const _cleanupInterval = Duration(hours: 1);
  Timer? _cleanupTimer;
  Timer? _replayTimer;

  /// 队列变更通知流（供 UI 层监听显示"待同步N条"）
  final _queueChangeStream = StreamController<int>.broadcast();
  Stream<int> get queueChangeStream => _queueChangeStream.stream;

  OfflineQueueManager(this._db, this._qualityDetector, this._scheduler);

  /// 初始化
  Future<void> init() async {
    await _cleanExpired();
    _cleanupTimer = Timer.periodic(_cleanupInterval, (_) => _cleanExpired());

    // 监听网络恢复
    _qualityDetector.qualityStream.listen((quality) {
      if (quality != NetworkQuality.offline) {
        _startReplay();
      }
    });

    // 启动时如果在线，立即开始重放
    if (_qualityDetector.currentQuality != NetworkQuality.offline) {
      _startReplay();
    }
  }

  /// 入队
  Future<bool> enqueue(OfflineQueueEntry entry) async {
    // 容量检查
    final count = await _queueCount();
    if (count >= _maxQueueSize) {
      // 淘汰最早到期的条目
      await _db.delete(
        'offline_request_queue',
        where: 'id IN (SELECT id FROM offline_request_queue ORDER BY expires_at ASC LIMIT 1)',
      );
    }

    await _db.insert('offline_request_queue', {
      'id': entry.id,
      'channel': entry.channel.name,
      'method': entry.method,
      'path': entry.path,
      'query_params': jsonEncode(entry.queryParams),
      'body': entry.body,
      'headers': jsonEncode(entry.headers),
      'enqueued_at': entry.enqueuedAt.toIso8601String(),
      'expires_at': entry.expiresAt.toIso8601String(),
      'retry_count': entry.retryCount,
      'max_retries': entry.maxRetries,
      'idempotency_key': entry.idempotencyKey,
      'associated_data': entry.associatedData,
    });

    _notifyQueueChange();
    return true;
  }

  /// 重放队列
  Future<void> _startReplay() async {
    final entries = await _db.query(
      'offline_request_queue',
      orderBy: 'enqueued_at ASC',
      limit: 50, // 每批最多处理 50 条
    );

    for (final row in entries) {
      final entry = _rowToEntry(row);

      // 检查是否过期
      if (entry.expiresAt.isBefore(DateTime.now())) {
        await _db.delete('offline_request_queue', where: 'id = ?', whereArgs: [entry.id]);
        continue;
      }

      try {
        await _replayEntry(entry);
        await _db.delete('offline_request_queue', where: 'id = ?', whereArgs: [entry.id]);
      } catch (e) {
        // 增加重试计数
        final newRetryCount = entry.retryCount + 1;
        if (newRetryCount >= entry.maxRetries) {
          // 超过最大重试次数，移除并记录
          await _db.delete('offline_request_queue', where: 'id = ?', whereArgs: [entry.id]);
          _logDiscarded(entry, e.toString());
        } else {
          await _db.update(
            'offline_request_queue',
            {'retry_count': newRetryCount},
            where: 'id = ?',
            whereArgs: [entry.id],
          );
        }
      }
    }

    _notifyQueueChange();
  }

  Future<void> _replayEntry(OfflineQueueEntry entry) async {
    // 构建并提交请求到调度器
    await _scheduler.submit(
      channel: entry.channel,
      timeout: kChannelConfigs[entry.channel]!.defaultTimeout,
      executor: () async {
        final options = Options(method: entry.method, headers: entry.headers);
        // ... Dio 请求执行
        return Response(requestOptions: RequestOptions(path: entry.path));
      },
    );
  }

  /// 清理过期条目
  Future<void> _cleanExpired() async {
    await _db.delete(
      'offline_request_queue',
      where: 'expires_at < ?',
      whereArgs: [DateTime.now().toIso8601String()],
    );
    _notifyQueueChange();
  }

  Future<int> _queueCount() async {
    final result = await _db.rawQuery('SELECT COUNT(*) as cnt FROM offline_request_queue');
    return Sqflite.firstIntValue(result) ?? 0;
  }

  void _notifyQueueChange() async {
    _queueChangeStream.add(await _queueCount());
  }

  void _logDiscarded(OfflineQueueEntry entry, String reason) {
    // 记录丢弃日志，供问题排查
    debugPrint('[OfflineQueue] Discarded: ${entry.id}, reason: $reason');
  }

  OfflineQueueEntry _rowToEntry(Map<String, dynamic> row) {
    return OfflineQueueEntry(
      id: row['id'] as String,
      channel: RequestChannel.values.firstWhere((c) => c.name == row['channel']),
      method: row['method'] as String,
      path: row['path'] as String,
      queryParams: row['query_params'] != null ? jsonDecode(row['query_params']) : null,
      body: row['body'] as String?,
      headers: jsonDecode(row['headers']) as Map<String, dynamic>,
      enqueuedAt: DateTime.parse(row['enqueued_at'] as String),
      expiresAt: DateTime.parse(row['expires_at'] as String),
      retryCount: row['retry_count'] as int,
      maxRetries: row['max_retries'] as int,
      idempotencyKey: row['idempotency_key'] as String,
      associatedData: row['associated_data'] as String?,
    );
  }

  void dispose() {
    _cleanupTimer?.cancel();
    _replayTimer?.cancel();
    _queueChangeStream.close();
  }
}

## 7. 请求去重器

### 7.1 设计原理

移动端场景下，用户快速点击、页面重复加载、Widget 重建等均可能导致短时间内发出多个相同的网络请求。请求去重器通过请求指纹（method + path + body hash）识别重复请求，对正在执行中的相同请求进行合并（Request Coalescing），避免浪费网络资源和服务器算力。

### 7.2 去重策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| **合并等待** | 后续相同请求等待第一个请求的结果，共享响应 | 列表刷新、详情页加载 |
| **丢弃重复** | 直接丢弃后续相同请求，返回前一个的缓存结果 | 搜索请求、翻页请求 |
| **节流窗口** | 在时间窗口内只放行第一个请求 | 下拉刷新、按钮点击 |

### 7.3 实现

```dart
/// 请求去重器
class RequestDeduplicator {
  /// 正在执行中的请求：fingerprint → Completer
  final Map<String, Completer<_DedupResponse>> _inFlight = {};

  /// 请求指纹缓存（用于节流）
  final Map<String, DateTime> _lastExecuted = {};

  /// 节流窗口
  static const _throttleWindow = Duration(milliseconds: 500);

  /// 执行去重请求
  Future<Response> execute({
    required String method,
    required String path,
    Map<String, dynamic>? queryParams,
    String? body,
    required Future<Response> Function() executor,
    DedupStrategy strategy = DedupStrategy.coalesce,
  }) async {
    final fingerprint = _computeFingerprint(method, path, queryParams, body);

    switch (strategy) {
      case DedupStrategy.coalesce:
        return _coalesce(fingerprint, executor);
      case DedupStrategy.throttle:
        return _throttle(fingerprint, executor);
      case DedupStrategy.none:
        return executor();
    }
  }

  /// 合并等待策略
  Future<Response> _coalesce(
    String fingerprint,
    Future<Response> Function() executor,
  ) async {
    // 如果已有相同请求在执行中，等待其结果
    if (_inFlight.containsKey(fingerprint)) {
      final dedupResp = await _inFlight[fingerprint]!.future;
      // 复制响应，因为原始 Response 对象不可共享
      return _cloneResponse(dedupResp.response);
    }

    // 创建新的 Completer
    final completer = Completer<_DedupResponse>();
    _inFlight[fingerprint] = completer;

    try {
      final response = await executor();
      completer.complete(_DedupResponse(response: response));
      return response;
    } catch (e) {
      completer.completeError(e);
      rethrow;
    } finally {
      // 延迟移除，避免紧随其后的重复请求错过合并窗口
      Future.delayed(const Duration(milliseconds: 100), () {
        _inFlight.remove(fingerprint);
      });
    }
  }

  /// 节流策略
  Future<Response> _throttle(
    String fingerprint,
    Future<Response> Function() executor,
  ) async {
    final lastTime = _lastExecuted[fingerprint];
    if (lastTime != null &&
        DateTime.now().difference(lastTime) < _throttleWindow) {
      // 在节流窗口内，抛出节流异常
      throw ThrottledException(fingerprint: fingerprint);
    }

    _lastExecuted[fingerprint] = DateTime.now();
    return executor();
  }

  /// 计算请求指纹
  String _computeFingerprint(
    String method,
    String path,
    Map<String, dynamic>? queryParams,
    String? body,
  ) {
    final buffer = StringBuffer()
      ..write(method)
      ..write('|')
      ..write(path)
      ..write('|');
    if (queryParams != null) {
      final sortedKeys = queryParams.keys.toList()..sort();
      for (final key in sortedKeys) {
        buffer.write('$key=${queryParams[key]}&');
      }
    }
    if (body != null) {
      buffer.write(body);
    }
    return buffer.toString();
  }

  Response _cloneResponse(Response original) {
    return Response(
      requestOptions: original.requestOptions,
      statusCode: original.statusCode,
      statusMessage: original.statusMessage,
      data: original.data, // data 通常为已解析的 Map/List，可直接引用
      headers: original.headers,
      isRedirect: original.isRedirect,
    );
  }
}

/// 去重策略枚举
enum DedupStrategy {
  /// 合并等待（默认）
  coalesce,
  /// 节流窗口
  throttle,
  /// 不去重
  none,
}

class _DedupResponse {
  final Response response;
  _DedupResponse({required this.response});
}

/// 节流异常（业务层可静默处理）
class ThrottledException implements Exception {
  final String fingerprint;
  ThrottledException({required this.fingerprint});

  @override
  String toString() => 'Request throttled: $fingerprint';
}
```

## 8. 客户端限流控制器

### 8.1 设计目标

客户端侧限流是对服务端限流的补充，核心目的是：
1. **防止请求洪峰**：页面初始化、网络恢复时多个模块同时发起请求
2. **保护用户体验**：避免因大量并发请求导致网络拥堵，拖慢关键交互
3. **节约流量**：移动数据环境下控制请求频率

### 8.2 限流维度

| 维度 | 限流方式 | 说明 |
|------|---------|------|
| **全局并发** | 信号量（最大 6 个） | 防止同时发起过多 TCP 连接 |
| **通道并发** | 通道配置中的 maxConcurrency | 各通道独立限制 |
| **域名限流** | 令牌桶（10 req/s） | 同一域名的请求速率限制 |
| **接口限流** | 滑动窗口（可配置） | 特定接口的频率限制 |
| **用户操作** | 防抖 500ms | 按钮防重复点击 |

### 8.3 实现

```dart
/// 客户端限流控制器
class RateLimitController {
  /// 全局并发信号量
  int _globalRunning = 0;
  static const _maxGlobalConcurrency = 6;

  /// 域名令牌桶：<域名, 令牌桶>
  final Map<String, _TokenBucket> _domainBuckets = {};

  /// 接口滑动窗口：<接口路径, 窗口记录>
  final Map<String, _SlidingWindow> _apiWindows = {};

  /// 执行限流后的请求
  Future<Response> execute(
    String path,
    Future<Response> Function() executor, {
    RequestChannel? channel,
    String? apiPath,
    Duration? debounceWindow,
  }) async {
    // 1. 全局并发控制
    await _waitForGlobalSlot();

    try {
      // 2. 域名令牌桶
      final uri = Uri.parse(path);
      final domain = '${uri.scheme}://${uri.host}';
      await _waitForDomainToken(domain);

      // 3. 接口级限流
      if (apiPath != null && _apiWindows.containsKey(apiPath)) {
        await _waitForApiWindow(apiPath);
      }

      return executor();
    } finally {
      _globalRunning--;
    }
  }

  /// 等待全局并发槽位
  Future<void> _waitForGlobalSlot() async {
    while (_globalRunning >= _maxGlobalConcurrency) {
      await Future.delayed(const Duration(milliseconds: 50));
    }
    _globalRunning++;
  }

  /// 等待域名令牌
  Future<void> _waitForDomainToken(String domain) async {
    _domainBuckets.putIfAbsent(
      domain,
      () => _TokenBucket(capacity: 10, refillRate: 10), // 10 req/s
    );
    await _domainBuckets[domain]!.acquire();
  }

  /// 等待接口窗口
  Future<void> _waitForApiWindow(String apiPath) async {
    await _apiWindows[apiPath]!.acquire();
  }

  /// 注册接口级限流规则
  void registerApiLimit(String apiPath, {
    required int maxRequests,
    required Duration window,
  }) {
    _apiWindows[apiPath] = _SlidingWindow(
      maxRequests: maxRequests,
      window: window,
    );
  }
}

/// 令牌桶
class _TokenBucket {
  final int capacity;
  final int refillRate; // 每秒补充令牌数
  double _tokens;
  DateTime _lastRefill;

  _TokenBucket({required this.capacity, required this.refillRate})
      : _tokens = capacity.toDouble(),
        _lastRefill = DateTime.now();

  Future<void> acquire() async {
    _refill();
    if (_tokens >= 1) {
      _tokens -= 1;
      return;
    }
    // 等待令牌补充
    final waitMs = (1000 / refillRate).ceil();
    await Future.delayed(Duration(milliseconds: waitMs));
    return acquire();
  }

  void _refill() {
    final now = DateTime.now();
    final elapsed = now.difference(_lastRefill).inMilliseconds / 1000.0;
    _tokens = (_tokens + elapsed * refillRate).clamp(0, capacity.toDouble());
    _lastRefill = now;
  }
}

/// 滑动窗口限流器
class _SlidingWindow {
  final int maxRequests;
  final Duration window;
  final Queue<DateTime> _timestamps = Queue();

  _SlidingWindow({required this.maxRequests, required this.window});

  Future<void> acquire() async {
    _cleanExpired();
    if (_timestamps.length < maxRequests) {
      _timestamps.add(DateTime.now());
      return;
    }
    // 等待最早的一个请求过期
    final oldest = _timestamps.first;
    final waitDuration = window - DateTime.now().difference(oldest);
    if (waitDuration.isNegative) {
      _timestamps.removeFirst();
      _timestamps.add(DateTime.now());
      return;
    }
    await Future.delayed(waitDuration);
    return acquire();
  }

  void _cleanExpired() {
    final cutoff = DateTime.now().subtract(window);
    while (_timestamps.isNotEmpty && _timestamps.first.isBefore(cutoff)) {
      _timestamps.removeFirst();
    }
  }
}

## 10. Dio 拦截器集成

### 10.1 拦截器链路

网络请求治理层通过 Dio 拦截器（Interceptor）无缝集成到现有网络栈中。拦截器按以下顺序排列：

```text
请求发出方向 →
┌──────────────────────────────────────────────────────┐
│ 1. AuthInterceptor      → 注入 Token / 刷新 Token    │
│ 2. DeviceInterceptor    → 注入设备信息、版本号         │
│ 3. NetworkInterceptor   → 网络治理核心（本模块）       │
│ 4. CacheInterceptor     → 缓存策略（GET 请求缓存）    │
│ 5. RetryInterceptor     → 自动重试                    │
│ 6. LogInterceptor       → 请求/响应日志                │
└──────────────────────────────────────────────────────┘
← 响应返回方向
```

### 10.2 NetworkInterceptor 实现

```dart
/// 网络治理拦截器 — 核心入口
class NetworkGovernorInterceptor extends Interceptor {
  final RequestDeduplicator _deduplicator;
  final RateLimitController _rateLimiter;
  final NetworkQualityDetector _qualityDetector;
  final OfflineQueueManager _offlineQueue;
  final ContentLoadAdapter _contentAdapter;

  NetworkGovernorInterceptor({
    required RequestDeduplicator deduplicator,
    required RateLimitController rateLimiter,
    required NetworkQualityDetector qualityDetector,
    required OfflineQueueManager offlineQueue,
    required ContentLoadAdapter contentAdapter,
  })  : _deduplicator = deduplicator,
        _rateLimiter = rateLimiter,
        _qualityDetector = qualityDetector,
        _offlineQueue = offlineQueue,
        _contentAdapter = contentAdapter;

  @override
  void onRequest(RequestOptions options, RequestInterceptorHandler handler) async {
    // 1. 离线检查
    if (_qualityDetector.currentQuality == NetworkQuality.offline) {
      final channel = _extractChannel(options);
      if (channel != null && kChannelConfigs[channel]!.offlineQueueable) {
        // 可离线队列：入队并返回本地响应
        await _enqueueOffline(options, channel);
        return handler.resolve(_buildOfflineResponse());
      }
      return handler.reject(
        DioException.connectionError(
          reason: '当前无网络连接',
          requestOptions: options,
        ),
      );
    }

    // 2. 内容参数适配（弱网降级）
    if (options.extra['adapt_content'] == true) {
      final adaptedParams = _contentAdapter.adaptListParams(
        (options.queryParameters as Map<String, dynamic>?) ?? {},
      );
      options.queryParameters.addAll(adaptedParams);
    }

    // 3. 请求去重检查
    final dedupStrategy = options.extra['dedup_strategy'] as DedupStrategy? ??
        DedupStrategy.coalesce;
    if (dedupStrategy != DedupStrategy.none) {
      try {
        final response = await _deduplicator.execute(
          method: options.method,
          path: options.path,
          queryParams: options.queryParameters,
          body: options.data?.toString(),
          executor: () => _executeWithRateLimit(options),
          strategy: dedupStrategy,
        );
        return handler.resolve(response);
      } on ThrottledException {
        return handler.reject(
          DioException(
            type: DioExceptionType.unknown,
            error: '请求过于频繁，请稍后重试',
            requestOptions: options,
          ),
        );
      }
    }

    // 4. 限流后正常执行
    final response = await _executeWithRateLimit(options);
    handler.next(options);
  }

  @override
  void onResponse(Response response, ResponseInterceptorHandler handler) {
    // 记录请求成功结果（更新网络质量评分）
    final latency = response.headers.value('x-response-time');
    _qualityDetector.recordRequestResult(
      latency: Duration(milliseconds: int.tryParse(latency ?? '0') ?? 0),
      success: true,
    );
    handler.next(response);
  }

  @override
  void onError(DioException err, ErrorInterceptorHandler handler) async {
    // 记录失败结果
    _qualityDetector.recordRequestResult(
      latency: Duration.zero,
      success: false,
    );

    // 判断是否为网络相关错误
    if (_isNetworkError(err)) {
      final channel = _extractChannel(err.requestOptions);
      if (channel != null && kChannelConfigs[channel]!.offlineQueueable) {
        await _enqueueOffline(err.requestOptions, channel);
        return handler.resolve(_buildOfflineResponse());
      }
    }

    handler.next(err);
  }

  Future<Response> _executeWithRateLimit(RequestOptions options) {
    return _rateLimiter.execute(
      options.path,
      () => _actualExecute(options),
      channel: _extractChannel(options),
    );
  }

  Future<Response> _actualExecute(RequestOptions options) async {
    // 实际的 Dio 请求执行（绕过拦截器避免递归）
    return Dio().fetch(options);
  }

  RequestChannel? _extractChannel(RequestOptions options) {
    final channelName = options.extra['channel'] as String?;
    if (channelName == null) return null;
    return RequestChannel.values.firstWhere(
      (c) => c.name == channelName,
      orElse: () => RequestChannel.contentLoad,
    );
  }

  bool _isNetworkError(DioException err) {
    return err.type == DioExceptionType.connectionTimeout ||
        err.type == DioExceptionType.receiveTimeout ||
        err.type == DioExceptionType.connectionError;
  }

  Response _buildOfflineResponse() {
    return Response(
      requestOptions: RequestOptions(path: '/offline'),
      statusCode: 202,
      data: {'code': 0, 'message': '已加入离线队列，网络恢复后自动同步'},
    );
  }

  Future<void> _enqueueOffline(RequestOptions options, RequestChannel channel) async {
    final entry = OfflineQueueEntry(
      id: const Uuid().v4(),
      channel: channel,
      method: options.method,
      path: options.path,
      queryParams: options.queryParameters.isNotEmpty ? Map<String, dynamic>.from(options.queryParameters) : null,
      body: options.data?.toString(),
      headers: Map<String, dynamic>.from(options.headers),
      enqueuedAt: DateTime.now(),
      expiresAt: DateTime.now().add(Duration(hours: _ttlForChannel(channel))),
      retryCount: 0,
      maxRetries: kChannelConfigs[channel]!.maxRetries,
      idempotencyKey: options.headers['Idempotency-Key'] as String? ?? const Uuid().v4(),
      associatedData: options.extra['local_data_id'] as String?,
    );
    await _offlineQueue.enqueue(entry);
  }

  int _ttlForChannel(RequestChannel channel) => switch (channel) {
    RequestChannel.dataSync => 24,
    RequestChannel.userAction => 72,
    RequestChannel.telemetry => 12,
    _ => 24,
  };
}
```

### 11.2 异常转换策略

将底层 DioException 转换为业务语义清晰的 NetworkException：

```dart
/// Dio 异常转换器
class NetworkExceptionMapper {
  static NetworkException fromDioException(DioException dioError) {
    return switch (dioError.type) {
      DioExceptionType.connectionTimeout => NetworkTimeoutException(
          timeout: dioError.requestOptions.connectTimeout ?? const Duration(seconds: 15),
        ),
      DioExceptionType.sendTimeout => NetworkTimeoutException(
          timeout: dioError.requestOptions.sendTimeout ?? const Duration(seconds: 10),
        ),
      DioExceptionType.receiveTimeout => NetworkTimeoutException(
          timeout: dioError.requestOptions.receiveTimeout ?? const Duration(seconds: 10),
        ),
      DioExceptionType.connectionError => _mapConnectionError(dioError),
      DioExceptionType.badResponse => _mapBadResponse(dioError),
      _ => NetworkException(
          message: '网络请求失败: ${dioError.message}',
          retryable: true,
        ),
    };
  }

  static NetworkException _mapConnectionError(DioException dioError) {
    final error = dioError.error;
    if (error is SocketException) {
      return const NetworkUnreachableException();
    }
    if (error is HandshakeException) {
      return const NetworkException(
        message: '网络连接安全验证失败',
        retryable: false,
      );
    }
    return const NetworkUnreachableException();
  }

  static NetworkException _mapBadResponse(DioException dioError) {
    final statusCode = dioError.response?.statusCode ?? 0;
    return switch (statusCode) {
      429 => ServerRateLimitException(
          retryAfterSeconds: int.tryParse(
                dioError.response?.headers.value('retry-after') ?? '60',
              ) ??
              60,
        ),
      500 || 502 || 503 || 504 => ServerErrorException(statusCode: statusCode),
      _ => NetworkException(
          message: '请求失败 ($statusCode)',
          retryable: statusCode >= 500,
        ),
    };
  }
}
```

### 11.3 业务层错误处理模式

各业务模块应遵循统一的错误处理模式：

```dart
/// 通用网络请求包装器
///
/// 使用示例：
/// ```dart
/// final result = await NetworkResult.fetch(() => governor.get('/api/v1/mistakes'));
/// result.when(
///   success: (data) => _updateUI(data),
///   offline: () => _showOfflineHint(),
///   error: (err) => _showError(err.message),
/// );
/// ```
sealed class NetworkResult<T> {
  const NetworkResult();

  factory NetworkResult.fetch(Future<T> Function() fetcher) async {
    try {
      final data = await fetcher();
      return Success(data);
    } on OfflineException {
      return const Offline();
    } on NetworkTimeoutException catch (e) {
      return Error(e.message, retryable: e.retryable);
    } on ServerRateLimitException catch (e) {
      return Error(e.message, retryable: e.retryable, retryAfter: e.retryAfter);
    } on NetworkException catch (e) {
      return Error(e.message, retryable: e.retryable);
    } catch (e) {
      return Error('未知错误: $e', retryable: false);
    }
  }

  R when<R>({
    required R Function(T data) success,
    required R Function() offline,
    required R Function(String message, {bool retryable, Duration? retryAfter}) error,
  });
}

class Success<T> extends NetworkResult<T> {
  final T data;
  const Success(this.data);

  @override
  R when<R>({
    required R Function(T data) success,
    required R Function() offline,
    required R Function(String message, {bool retryable, Duration? retryAfter}) error,
  }) => success(data);
}

class Offline<T> extends NetworkResult<T> {
  const Offline();

  @override
  R when<R>({
    required R Function(T data) success,
    required R Function() offline,
    required R Function(String message, {bool retryable, Duration? retryAfter}) error,
  }) => offline();
}

class Error<T> extends NetworkResult<T> {
  final String message;
  final bool retryable;
  final Duration? retryAfter;
  const Error(this.message, {required this.retryable, this.retryAfter});

  @override
  R when<R>({
    required R Function(T data) success,
    required R Function() offline,
    required R Function(String message, {bool retryable, Duration? retryAfter}) error,
  }) => error(message, retryable: retryable, retryAfter: retryAfter);
}

### 13.2 指标采集埋点

```dart
/// 网络指标采集器
class NetworkMetricsCollector {
  final Map<String, int> _counters = {};
  final Map<String, List<int>> _histograms = {};

  /// 记录请求完成
  void recordRequest({
    required RequestChannel channel,
    required bool success,
    required Duration latency,
    int retryCount = 0,
    String? errorCode,
  }) {
    final channelName = channel.name;
    final status = success ? 'success' : 'failure';

    _incrementCounter('net_request_total',
        labels: {'channel': channelName, 'status': status});

    _recordHistogram('net_request_latency_ms', latency.inMilliseconds,
        labels: {'channel': channelName});

    if (retryCount > 0) {
      _incrementCounter('net_request_retry_total',
          labels: {'channel': channelName}, delta: retryCount);
    }

    if (!success && errorCode != null) {
      _incrementCounter('net_request_error_total',
          labels: {'channel': channelName, 'error': errorCode});
    }
  }

  /// 记录离线队列变更
  void recordOfflineQueueChange({
    required String event, // enqueued, replayed, discarded, expired
n    int queueSize = 0,
  }) {
    _incrementCounter('net_offline_queue_$event', labels: {});
  }

  /// 批量导出指标（供埋点上报模块消费）
  List<Map<String, dynamic>> flush() {
    final metrics = <Map<String, dynamic>>[];

    for (final entry in _counters.entries) {
      metrics.add({'metric': entry.key, 'value': entry.value});
    }

    for (final entry in _histograms.entries) {
      final values = entry.value;
      metrics.add({
        'metric': entry.key,
        'count': values.length,
        'sum': values.reduce((a, b) => a + b),
        'p50': _percentile(values, 50),
        'p95': _percentile(values, 95),
        'p99': _percentile(values, 99),
      });
    }

    _counters.clear();
    _histograms.clear();
    return metrics;
  }

  void _incrementCounter(String name, {
equired Map<String, String> labels, int delta = 1}) {
    final key = _metricKey(name, labels);
    _counters[key] = (_counters[key] ?? 0) + delta;
  }

  void _recordHistogram(String name, int value, {required Map<String, String> labels}) {
    final key = _metricKey(name, labels);
    _histograms.putIfAbsent(key, () => []).add(value);
  }

  String _metricKey(String name, Map<String, String> labels) {
    if (labels.isEmpty) return name;
    final labelStr = labels.entries.map((e) => '${e.key}=${e.value}').join(',');
    return '$name{$labelStr}';
  }

  int _percentile(List<int> sorted, int p) {
    final s = sorted..sort();
    final idx = (s.length * p / 100).ceil() - 1;
    return s[idx.clamp(0, s.length - 1)];
  }
}

/// 应用启动时的网络层初始化
Future<void> initNetworkStack() async {
  // 1. 创建 Dio 实例
  final dio = Dio(BaseOptions(
    baseUrl: EnvConfig.apiBaseUrl,
    connectTimeout: const Duration(seconds: 15),
    receiveTimeout: const Duration(seconds: 15),
    sendTimeout: const Duration(seconds: 10),
  ));

  // 2. 创建质量检测器
  final qualityDetector = NetworkQualityDetector(dio: dio, connectivity: Connectivity());
  await qualityDetector.init();

  // 3. 创建调度器
  final scheduler = PriorityScheduler(qualityDetector);

  // 4. 创建离线队列管理器
  final db = await openDatabase('primetop.db');
  final offlineQueue = OfflineQueueManager(db, qualityDetector, scheduler);
  await offlineQueue.init();

  // 5. 创建辅助组件
  final deduplicator = RequestDeduplicator();
  final rateLimiter = RateLimitController();
  final contentAdapter = ContentLoadAdapter(qualityDetector);

  // 6. 注册拦截器（按顺序）
  dio.interceptors.addAll([
    AuthInterceptor(),                          // 鉴权
    DeviceInterceptor(),                        // 设备信息
    NetworkGovernorInterceptor(                 // 网络治理
      deduplicator: deduplicator,
      rateLimiter: rateLimiter,
      qualityDetector: qualityDetector,
      offlineQueue: offlineQueue,
      contentAdapter: contentAdapter,
    ),
    CacheInterceptor(),                         // 缓存
    RetryInterceptor(),                         // 重试
    LogInterceptor(),                           // 日志
  ]);

  // 7. 创建门面
  final governor = RequestGovernor(dio: dio);

  // 8. 注册到全局 DI
  getIt.registerSingleton<RequestGovernor>(governor);
  getIt.registerSingleton<NetworkQualityDetector>(qualityDetector);
  getIt.registerSingleton<OfflineQueueManager>(offlineQueue);
}

### 15.2 App 生命周期联动

```dart
/// App 生命周期联动
class AppLifecycleObserver with WidgetsBindingObserver {
  final NetworkQualityDetector _qualityDetector;
  final OfflineQueueManager _offlineQueue;

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    switch (state) {
      case AppLifecycleState.resumed:
        // 从后台恢复：立即探测网络 + 启动离线队列重放
        _qualityDetector.probeOnce();
        _offlineQueue.startReplay();
        break;
      case AppLifecycleState.paused:
        // 进入后台：暂停低优先级请求
        _qualityDetector.pauseProbing();
        break;
      case AppLifecycleState.detached:
        // 进程终止：清理资源
        _qualityDetector.dispose();
        _offlineQueue.dispose();
        break;
      default:
        break;
    }
  }
}
