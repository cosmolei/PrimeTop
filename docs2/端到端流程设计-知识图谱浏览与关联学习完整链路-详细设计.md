# 端到端流程设计 - 知识图谱浏览与关联学习完整链路

> **版本**: v1.0 | **日期**: 2026-06-06 | **状态**: 初稿
> **原始需求来源**: `docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档` §6.9 考点梳理模块 — 知识图谱、§8.5.2 RAG检索增强生成
> **关联模块**: 知识图谱构建与可视化交互引擎、客户端-知识图谱浏览与关联学习页面架构与交互设计、知识点体系与教材映射引擎、学情分析、自适应学习与个性化推荐引擎、考点梳理、AI智能辅导

## 1. 流程概述

### 1.1 流程定义

知识图谱浏览与关联学习完整链路描述用户从**发现知识图谱入口** → **选择学科/章节范围** → **浏览图谱节点与关系** → **查看节点详情与掌握度** → **触发关联学习动作（AI讲解、练题、复习等）** → **学习结果回写图谱状态** 的端到端闭环。

### 1.2 用户旅程总览

```
┌─────────────┐     ┌──────────────┐     ┌───────────────┐     ┌──────────────┐
│ 1. 入口发现  │────▶│ 2. 范围选择   │────▶│ 3. 图谱浏览    │────▶│ 4. 节点交互   │
│ 首页卡片/    │     │ 学科+章节    │     │ 力导向图渲染   │     │ 点击/长按/   │
│ 考点入口     │     │ 筛选条件     │     │ 掌握度叠加     │     │ 搜索定位     │
└─────────────┘     └──────────────┘     └───────────────┘     └──────┬───────┘
                                                                       │
          ┌────────────────────────────────────────────────────────────┘
          │
          ▼
┌──────────────┐     ┌───────────────┐     ┌───────────────┐     ┌──────────────┐
│ 5. 学习动作  │────▶│ 6. 学习执行    │────▶│ 7. 结果回写    │────▶│ 8. 图谱刷新   │
│ AI讲解/练题/ │     │ 对话/答题/    │     │ 掌握度更新     │     │ 节点重渲染   │
│ 复习/收藏    │     │ 背诵检测      │     │ 进度同步       │     │ 路径推荐更新 │
└──────────────┘     └───────────────┘     └───────────────┘     └──────────────┘
```

### 1.3 涉及角色

| 角色 | 场景 | 说明 |
|------|------|------|
| 学生 | 全链路主角色 | 浏览图谱、触发学习、查看掌握度变化 |
| 家长 | 查看图谱报告 | 在家长端查看孩子的知识掌握全景图 |
| 教师 | 班级图谱统计 | 查看班级整体薄弱知识点分布 |

### 1.4 分龄策略

| 学段 | 图谱交互差异 | 学习动作差异 |
|------|-------------|-------------|
| 小学(1-6) | 大节点、卡通配色、简化关系（仅显示前置关系）、动画引导 | 直接进入AI趣味讲解 |
| 初中(7-9) | 标准节点、掌握度色阶、显示考点频率标签 | AI讲解 + 同类题练习 |
| 高中(10-12) | 紧凑布局、多维筛选（按考点/掌握度/章节）、推荐路径覆盖 | AI深度讲解 + 专题训练 + 考点冲刺 |

## 2. 入口场景与触发条件

### 2.1 入口清单

| 入口位置 | 触发方式 | 携带参数 | 优先级 |
|----------|----------|----------|--------|
| 首页学习工作台 - 薄弱点图谱卡片 | 点击卡片 | `subjectId`, `weakOnly=true` | P1 |
| 考点梳理模块 - 知识图谱Tab | Tab切换 | `subjectId`, `gradeId` | P1 |
| 学情分析报告 - 知识掌握度图谱 | 点击"查看图谱" | `subjectId`, `chapterId` | P1 |
| 同步课堂 - 章节完成后 | 点击"查看知识图谱" | `subjectId`, `chapterId`, `highlightCurrent=true` | P1 |
| AI对话 - 知识点关联推荐 | 点击关联知识点 | `knowledgePointId` | P2 |
| 学习规划 - 推荐路径可视化 | 点击"查看路径" | `studyPlanId`, `pathMode=true` | P2 |
| 深链接/推送 | URL打开 | 全部参数通过URL编码 | P2 |
| 搜索结果 - 知识点图谱定位 | 点击"在图谱中查看" | `knowledgePointId` | P2 |

### 2.2 深链接路由定义

```
# 图谱全景
primetop://knowledge-graph?subjectId={}&chapterId={}&weakOnly={}

# 特定节点定位
primetop://knowledge-graph/node/{knowledgePointId}?expandLevel=2

# 推荐路径
primetop://knowledge-graph/path?studyPlanId={}&subjectId={}

# 薄弱点子图
primetop://knowledge-graph/weak?subjectId={}
```

### 2.3 入口参数校验

```typescript
interface GraphEntryParams {
  subjectId: string;          // 必填，学科ID
  gradeId?: string;           // 可选，年级（默认当前用户年级）
  chapterId?: string;         // 可选，章节（不传则显示学科全景）
  knowledgePointId?: string;  // 可选，聚焦到特定节点
  weakOnly?: boolean;         // 可选，仅显示薄弱点
  pathMode?: boolean;         // 可选，显示推荐路径
  studyPlanId?: string;       // 可选，学习计划ID（pathMode时必填）
  highlightCurrent?: boolean; // 可选，高亮当前学习位置
  expandLevel?: number;       // 可选，聚焦节点展开层级，默认2
}
```

### 4.2 节点掌握度状态机

```
┌─────────────┐  首次学习   ┌──────────────────┐  正确率>60%  ┌──────────────────┐
│ NOT_STARTED │──────────▶│  PARTIALLY_MASTERED│──────────▶│   MOSTLY_MASTERED │
│ (未学习)     │           │  (部分掌握)         │           │   (基本掌握)       │
└─────────────┘           └──────────────────┘           └──────────────────┘
                                │                               │
                                │ 正确率<30%                     │ 正确率>85%
                                ▼                               ▼
                          ┌────────────┐                  ┌────────────┐
                          │  WEAK      │                  │ MASTERED   │
                          │  (薄弱)     │                  │ (已掌握)    │
                          └────────────┘                  └────────────┘
                                │                               │
                                │ 长期未复习                     │ 30天未复习
                                ▼                               ▼
                          ┌──────────────────┐           ┌──────────────────┐
                          │ NEEDS_REVIEW     │           │ NEEDS_REVIEW     │
                          │ (需复习)          │           │ (需复习)          │
                          └──────────────────┘           └──────────────────┘
```

**状态定义枚举**

```typescript
enum MasteryStatus {
  NOT_STARTED = 'NOT_STARTED',           // 未学习
  WEAK = 'WEAK',                         // 薄弱（正确率 < 30%）
  PARTIALLY_MASTERED = 'PARTIALLY_MASTERED', // 部分掌握（30%-60%）
  MOSTLY_MASTERED = 'MOSTLY_MASTERED',   // 基本掌握（60%-85%）
  MASTERED = 'MASTERED',                 // 已掌握（> 85%）
  NEEDS_REVIEW = 'NEEDS_REVIEW',         // 需复习（长期未接触）
}
```

**状态映射色值**

```dart
// 节点颜色根据掌握度映射
Color masteryToColor(MasteryStatus status, double level) {
  switch (status) {
    case MasteryStatus.NOT_STARTED:
      return Colors.grey[300];      // 灰色
    case MasteryStatus.WEAK:
      return Color(0xFFE53935);     // 红色
    case MasteryStatus.PARTIALLY_MASTERED:
      return Color(0xFFFF9800);     // 橙色
    case MasteryStatus.MOSTLY_MASTERED:
      return Color(0xFF4CAF50);     // 绿色
    case MasteryStatus.MASTERED:
      return Color(0xFF1565C0);     // 蓝色
    case MasteryStatus.NEEDS_REVIEW:
      return Color(0xFFAB47BC);     // 紫色
  }
}
```

## 5. 关键交互流程

### 5.1 图谱首次加载流程

```
用户点击入口
    │
    ▼
[1] 解析入口参数 → GraphEntryParams
    │
    ▼
[2] 检查本地缓存
    ├── 缓存命中且未过期(< 30min)
    │       │
    │       ▼
    │   使用缓存数据 + 仅请求掌握度增量更新
    │       │
    └── 缓存未命中或已过期
            │
            ▼
[3] 请求 GET /knowledge-graph/subgraph（带includeMastery=true）
    │
    ▼
[4] 数据预处理
    ├── 按依赖关系排序节点
    ├── 计算节点布局位置（力导向布局参数初始化）
    ├── 映射掌握度色值
    └── 过滤不可见节点（已掌握且非聚焦范围的可折叠）
    │
    ▼
```

## 7. 服务端实现要点

### 7.1 子图提取算法

```java
@Service
public class KnowledgeGraphService {

    /**
     * 提取子图：按学科+章节范围，限制节点数量
     */
    public GraphSubgraph getSubgraph(String subjectId, String gradeId,
                                      String chapterId, int expandLevel, int maxNodes) {
        // 1. 确定根节点集合
        List<String> rootNodeIds;
        if (chapterId != null) {
            // 按章节：获取该章节下所有知识点
            rootNodeIds = knowledgePointRepo.findIdsByChapter(chapterId);
        } else {
            // 学科全景：获取该学科下所有知识点
            rootNodeIds = knowledgePointRepo.findIdsBySubjectAndGrade(subjectId, gradeId);
        }

        // 2. BFS扩展，收集关联节点
        Set<String> visited = new HashSet<>();
        Queue<String> queue = new LinkedList<>(rootNodeIds);
        int level = 0;

        while (!queue.isEmpty() && level < expandLevel && visited.size() < maxNodes) {
            int size = queue.size();
            for (int i = 0; i < size && visited.size() < maxNodes; i++) {
                String nodeId = queue.poll();
                if (visited.add(nodeId)) {
                    // 获取该节点的所有邻居（PREREQUISITE + RELATED）
                    List<String> neighbors = edgeRepo.findNeighborIds(nodeId);
                    queue.addAll(neighbors);
                }
            }
            level++;
        }

        // 3. 批量查询节点和边
        List<GraphNode> nodes = nodeRepo.findByIds(visited);
        List<GraphEdge> edges = edgeRepo.findByNodeIds(visited);

        return new GraphSubgraph(nodes, edges);
    }
}
```

### 7.2 掌握度增量更新

```java
/**
 * 学习完成后，增量更新知识点掌握度
 * 支持批量更新（一次练习可能涉及多个知识点）
 */
@Transactional
public MasteryUpdateResult updateMastery(String userId, List<MasteryUpdate> updates) {
    List<String> updatedNodes = new ArrayList<>();
    List<String> affectedPaths = new ArrayList<>();

    for (MasteryUpdate update : updates) {
        String kpId = update.getKnowledgePointId();

        // 1. 获取当前掌握度记录
        KnowledgeMastery mastery = masteryRepo
            .findByUserAndKnowledgePoint(userId, kpId)
            .orElseGet(() -> KnowledgeMastery.create(userId, kpId));

        // 2. 计算新的掌握度
        double oldLevel = mastery.getLevel();
        double delta = calculateDelta(update);
        double newLevel = Math.min(1.0, Math.max(0.0, oldLevel + delta));

        // 3. 更新掌握度
        mastery.setLevel(newLevel);
        mastery.setStatus(classifyMasteryStatus(newLevel, update.getCorrectRate()));
        mastery.setLastStudyAt(Instant.now());
        mastery.setTotalStudyMinutes(mastery.getTotalStudyMinutes() + update.getStudyMinutes());
        masteryRepo.save(mastery);

        updatedNodes.add(kpId);

        // 4. 发布掌握度变更事件（触发下游：路径更新、推荐刷新）
        eventPublisher.publishEvent(new MasteryChangedEvent(
            userId, kpId, oldLevel, newLevel, update.getSource()
        ));

        // 5. 检查是否影响进行中的学习路径
        List<String> paths = learningPathRepo.findActivePathsContaining(userId, kpId);
        affectedPaths.addAll(paths);
    }

    // 6. 生成新推荐
    List<Recommendation> recommendations = generateRecommendations(userId, updatedNodes);

    return new MasteryUpdateResult(updatedNodes, affectedPaths, recommendations);
}

/**
 * 掌握度增量计算
 * 考虑：正确率、题目数量、学习时长、当前掌握度水平（高掌握度提升更慢）
 */
private double calculateDelta(MasteryUpdate update) {
    double baseDelta = (update.getCorrectRate() - 0.5) * 0.1; // 基础增量

    // 题目数量加权（做更多题目，权重更高）
    double volumeWeight = Math.min(1.0, update.getQuestionCount() / 10.0);

    // 边际递减（掌握度越高，提升越慢）
    double diminishingFactor = 1.0 - mastery.getLevel() * 0.5;

    return baseDelta * volumeWeight * diminishingFactor;
}
```

### 7.3 薄弱点传播分析

```java
/**
 * 薄弱点传播分析：找出薄弱知识点的根因和影响范围
 */
public WeakPropagationAnalysis analyzeWeakPropagation(String userId, String subjectId) {
    // 1. 获取所有薄弱知识点
    List<KnowledgeMastery> weakNodes = masteryRepo
        .findWeakByUserAndSubject(userId, subjectId);

    // 2. 对每个薄弱节点，向上追溯根因
    List<WeakRootCause> rootCauses = new ArrayList<>();
    Set<String> affectedDownstream = new HashSet<>();

    for (KnowledgeMastery weak : weakNodes) {
        // 向上BFS找到最远的前置薄弱节点（根因）
        List<String> weakChain = traceWeakChain(weak.getKnowledgePointId(), userId);
        if (!weakChain.isEmpty()) {
            String rootId = weakChain.get(weakChain.size() - 1);
            rootCauses.add(new WeakRootCause(rootId, weakChain, weak.getLevel()));
        }

        // 向下预测受影响的下游知识点
        Set<String> downstream = findDownstreamNodes(weak.getKnowledgePointId());
        affectedDownstream.addAll(downstream);
    }

    // 3. 计算修复优先级（综合影响范围 × 修复难度）
    List<WeakFixPriority> priorities = rootCauses.stream()
        .map(rc -> {
            int impactCount = countAffectedDownstream(rc.getRootId());
            double difficulty = estimateFixDifficulty(rc.getRootId(), userId);
            return new WeakFixPriority(rc, impactCount, difficulty,
                impactCount * (1.0 - difficulty));
        })
        .sorted(Comparator.comparingDouble(WeakFixPriority::getScore).reversed())
        .collect(Collectors.toList());

    return new WeakPropagationAnalysis(rootCauses, affectedDownstream, priorities);
}
```
