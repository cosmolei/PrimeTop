## 2. 账号体系

### 2.1 [A-01] 用户注册登录

- **原始需求来源**: §7.1 账号体系 → 注册登录
- **涉及端**: 客户端 + 服务端
- **前置依赖**: 无（首个功能）

#### 验收标准

| AC | 条件描述 |
|----|----------|
| AC-1 | 用户可通过手机号 + 短信验证码完成注册，验证码 6 位数字，60 秒有效期 |
| AC-2 | 验证码发送间隔 ≥ 60 秒，同一号码每日最多发送 10 条 |
| AC-3 | 注册成功后自动登录，跳转到学生档案设置页 |
| AC-4 | 已注册手机号使用验证码登录（不区分注册/登录，统一流程） |
| AC-5 | 支持第三方登录：微信授权（MVP 必须）、苹果 Sign-In（iOS 必须） |
| AC-6 | 注册过程网络异常时给出明确提示，支持重试，不产生脏数据 |
| AC-7 | 首次启动 APP 后 3 秒内展示登录/注册页面 |

#### 端到端测试场景

| 编号 | 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|------|----------|----------|----------|
| E2E-A01-01 | 正常手机号注册 | APP 已安装，未注册 | ① 输入手机号 ② 点击获取验证码 ③ 输入验证码 ④ 点击确认 | 注册成功，自动登录，跳转学生档案设置页 |
| E2E-A01-02 | 已注册号码登录 | 手机号已注册 | ① 输入已注册手机号 ② 获取验证码 ③ 输入验证码 | 直接登录成功，跳转首页或档案设置页 |
| E2E-A01-03 | 验证码过期 | 已发送验证码 | ① 等待 60 秒以上 ② 输入过期验证码 ③ 点击确认 | 提示"验证码已过期"，不创建会话 |
| E2E-A01-04 | 频繁发送验证码 | 已发送过验证码 | ① 30 秒内再次点击"获取验证码" | 按钮置灰，显示倒计时 |
| E2E-A01-05 | 微信授权登录 | 设备已安装微信 | ① 点击"微信登录" ② 跳转授权 ③ 确认 | 登录成功，新用户跳转档案设置页 |
| E2E-A01-06 | 网络中断 | 已输入手机号和验证码 | ① 断开网络 ② 点击确认 | 提示网络失败，不产生注册记录 |
| E2E-A01-07 | 验证码错误 | 已发送验证码 | ① 输入错误验证码 ② 点击确认 | 提示错误，同一验证码最多 5 次尝试 |

#### 边界条件与异常处理

| 编号 | 场景 | 处理策略 |
|------|------|----------|
| B-A01-01 | 手机号格式非法 | 前端实时校验拦截，提示"请输入正确的手机号" |
| B-A01-02 | 短信服务宕机 | 返回友好错误码，提示"短信发送失败，请稍后重试" |
| B-A01-03 | 并发注册同一手机号 | 数据库唯一索引，后者返回"已注册"引导登录 |
| B-A01-04 | iOS 微信未安装 | 隐藏微信登录按钮或提示安装 |
| B-A01-05 | 快速多次点击确认 | 前端 500ms 防抖 + 后端请求幂等 |

#### 性能要求

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 验证码发送延迟 | ≤ 3s（P99） | 接口延迟 |
| 注册接口响应 | ≤ 1s | 服务端处理时间 |
| 登录页首屏渲染 | ≤ 1.5s | 冷启动到可交互 |

### 2.2 [A-02] 年级学段选择（学生档案设置）

| AC | 条件描述 |
|----|----------|

## 3. AI 智能辅导

### 3.1 [AI-01] 文字问答

- **原始需求来源**: §7.1 AI 辅导 → 文字问答
- **涉及端**: 客户端 + 服务端 + AI 层
- **前置依赖**: A-01, A-02 完成

#### 验收标准

| AC | 条件描述 |
|----|----------|
| AC-1 | 用户可输入文字问题，获得分步骤讲解回答 |
| AC-2 | 回答根据学段、年级自动调整深度和表达方式 |
| AC-3 | 支持 Markdown 渲染，含数学公式（LaTeX）、代码块、列表 |
| AC-4 | 流式输出（SSE），首 token 延迟 ≤ 3 秒 |
| AC-5 | 回答结构化：问题理解 → 思路提示 → 详细步骤 → 总结 |
| AC-6 | 免费用户每日 10 次，会员无限制 |
| AC-7 | 自动关联知识点标签 |
| AC-8 | 提供快捷操作："再讲简单点""生成同类题""加入错题本" |

#### 端到端测试场景

| 编号 | 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|------|----------|----------|----------|
| E2E-AI01-01 | 小学数学提问 | 小学三年级 | ① 输入"24×15怎么算" ② 发送 | 生活化语言，分步讲解，无跳步 |
| E2E-AI01-02 | 高中物理提问 | 高中物理 | ① 输入自由落体问题 ② 发送 | 列公式 v²=2gh，代入计算，给出结果和单位 |
| E2E-AI01-03 | 公式渲染 | 任意用户 | ① 输入含公式的问题 | LaTeX 公式正确渲染 |
| E2E-AI01-04 | 免费额度耗尽 | 已用 10 次 | ① 输入第 11 个问题 | 提示"今日次数已用完" |
| E2E-AI01-05 | 非学习问题 | 任意用户 | ① 输入"今天天气怎么样" | 引导回学习话题 |
| E2E-AI01-06 | AI 服务异常 | 模拟超时 | ① 输入问题 ② 等待 | 超时提示，可重试 |

#### 边界条件与异常处理

| 编号 | 场景 | 处理策略 |
|------|------|----------|
| B-AI01-01 | 空输入或纯空格 | 发送按钮不可点击 |
| B-AI01-02 | 超长文本（>2000字） | 提示字数限制 |
| B-AI01-03 | AI 输出不当内容 | 安全过滤拦截，记录审核日志 |
| B-AI01-04 | AI 幻觉/事实错误 | 提供"内容有误"反馈按钮 |
| B-AI01-05 | 快速连续发送 | 前一回答未完成时发送按钮置灰 |

#### 性能要求

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 首 token 延迟 | ≤ 3s（P90） | 发送到首个 token 到达 |
| 完整回答 | ≤ 30s（P90） | 发送到最后 token 完成 |
| AI 调用成功率 | ≥ 98% | 成功返回非空回答比例 |

## 10. 核心跨模块端到端场景

以下场景验证多个 P0 功能的串联闭环，是 MVP 发布前必须全部通过的关键路径。

注册 → 设置档案 → AI 提问 → 查看回答 → 收录错题 → 查看错题本 → 查看学情统计
```

| 步骤 | 操作 | 验证点 |
|------|------|--------|

| 3 | AI 提问一道数学题 | 流式回答，公式渲染正常 |

| 5 | 点击"加入错题本" | 收录成功提示 |
| 6 | 进入错题本查看 | 刚收录的错题可见 |
| 7 | 返回首页查看统计 | 问答数+1，错题数+1 |

### 10.2 拍题完整流程

```
拍题 → 识别 → 确认 → 查看解析 → 加入错题 → 查看错题 → 查看学情
```

| 步骤 | 操作 | 验证点 |
|------|------|--------|
| 1 | 点击拍题按钮 | 相机启动 |
| 2 | 拍摄一道数学题 | 识别结果可编辑 |
| 3 | 确认识别文本 | 开始生成解析 |
| 4 | 查看分步解析 | 思路→步骤→答案，公式渲染 |
| 5 | 点击"加入错题本" | 收录成功 |
| 6 | 错题本查看 | 题目+解析完整展示 |
| 7 | 首页统计 | 拍题数+1，错题数+1 |

### 10.3 同步课堂学习闭环

```
进入同步课堂 → 选择教材章节 → 学习知识点 → 问 AI 深入 → 学习记录更新
```

| 步骤 | 操作 | 验证点 |
|------|------|--------|
| 1 | 进入同步课堂 | 目录树正确匹配教材版本 |
| 2 | 展开章节，进入某课时 | 知识点讲解页加载 |

| 5 | 返回首页查看统计 | 学习时长+1，章节学习记录更新 |

### 10.4 会员转化闭环

```
免费用户学习 → 额度耗尽 → 提示开通 → 购买会员 → 权益生效 → 继续学习
