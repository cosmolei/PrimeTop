## 1. 概述

### 1.1 模块定位

考点专题突破训练服务（Topic Breakthrough Training Service）是 PrimeTop **考点梳理**模块下的核心训练子系统。它围绕“函数、古诗文、力学、电学、语法”等考试专题，将分散的考点、题目、错题、知识讲解聚合成可执行的**专题训练单元**，帮助学生在中考/高考备考阶段进行集中突破。

本服务不直接生产题目或考点元数据，而是：
- 消费 **考点梳理** 的考点树、专题定义、高频考点、易错点；
- 消费 **题库系统** 的题目元数据与解析；
- 消费 **用户学习画像** 的考点掌握度、历史错题、薄弱点；
- 输出 **专题训练会话**、逐题练习、阶段报告、复习建议。

### 1.2 核心目标

1. **专题聚合**：将同一知识领域的考点聚合成主题训练包。
2. **分层训练**：根据学生当前掌握度，生成基础巩固→变式提升→综合突破三阶练习。
3. **薄弱点优先**：优先训练高频考点中的薄弱项，提升备考效率。
4. **即时反馈**：每题提交后即时判分、解析、知识点关联、错题收录。
5. **闭环沉淀**：训练结果自动回流到学情分析、错题本、学习规划。

### 1.3 适用学段与场景

| 学段 | 典型专题 | 使用场景 |
|------|----------|----------|
| 初中 | 函数综合、几何证明、文言文阅读、英语语法 | 中考复习、期末冲刺 |
| 高中 | 圆锥曲线、导数与极值、电磁感应、古诗文鉴赏 | 高考一轮/二轮复习 |

### 1.4 依赖关系

```text
考点专题突破训练服务
  ├─ 依赖：考点梳理服务（考点树、专题、高频考点、易错点）
  ├─ 依赖：题目服务（题库、题目元数据、解析）
  ├─ 依赖：用户学习画像（考点掌握度、错题数据）
  ├─ 依赖：练习测评服务（答题流程、判分、记录）
  ├─ 依赖：AI 服务（专题讲解、变式生成、薄弱点分析）
  ├─ 依赖：学习记录服务（训练时长、进度同步）
  ├─ 被依赖：学情分析（专题训练报告、能力画像）
  └─ 被依赖：学习规划（生成冲刺任务、每日训练计划）
```

## 2. 核心概念

| 概念 | 英文 | 说明 |
|------|------|------|
| 专题 | ExamTopic | 围绕某个知识领域聚合的考点群，例如“二次函数综合专题” |
| 专题考点 | TopicExamPoint | 专题内的考点条目，含推荐训练顺序、权重、阶段划分 |
| 训练会话 | TopicTrainingSession | 学生针对某专题的一次训练实例 |
| 训练阶段 | TrainingStage | 同一专题内的分层：基础巩固 / 变式提升 / 综合突破 |
| 阶段题目 | StageQuestion | 某阶段内的一道训练题及其状态 |
| 训练记录 | TopicTrainingRecord | 一次训练会话的作答明细、得分、耗时 |
| 专题报告 | TopicBreakthroughReport | 训练完成后生成的能力评估与下一步建议 |
| 用户专题进度 | UserTopicProgress | 学生对某专题的整体掌握进度 |

## 3. 数据结构设计

### 3.1 专题表 `exam_topic`

该表由考点梳理/管理后台维护，本服务只读。

```sql
CREATE TABLE `exam_topic` (
    `id`              BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT COMMENT '专题ID',
    `code`            VARCHAR(64)  NOT NULL UNIQUE COMMENT '专题编码，如 MATH-JHS-FUNC-001',
    `name`            VARCHAR(128) NOT NULL COMMENT '专题名称',
    `description`     TEXT         COMMENT '专题描述',
    `subject_code`    VARCHAR(16)  NOT NULL COMMENT '学科编码 MATH/CHINESE/PHYSICS...',
    `stage`           VARCHAR(16)  NOT NULL COMMENT '学段 junior_high / senior_high',
    `grade_range`     VARCHAR(32)  COMMENT '适用年级，如 "8-9"',
    `difficulty_min`  TINYINT      NOT NULL DEFAULT 1 COMMENT '难度下限 1-5',
    `difficulty_max`  TINYINT      NOT NULL DEFAULT 5 COMMENT '难度上限 1-5',
    `exam_type`       VARCHAR(16)  NOT NULL COMMENT '考试类型：zhongkao/gaokao/final/midterm',
    `cover_image_url` VARCHAR(512) COMMENT '封面图',
    `icon_url`        VARCHAR(512) COMMENT '图标',
    `sort_order`      INT          NOT NULL DEFAULT 0 COMMENT '排序',
    `status`          VARCHAR(16)  NOT NULL DEFAULT 'draft' COMMENT 'draft/active/archived',
    `created_at`      DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at`      DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    INDEX `idx_subject_stage` (`subject_code`, `stage`, `status`),
    INDEX `idx_exam_type` (`exam_type`, `subject_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='专题表';
```

### 3.2 专题考点表 `exam_topic_point`

定义专题包含的考点及训练顺序。

```sql
CREATE TABLE `exam_topic_point` (
    `id`                BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    `topic_id`          BIGINT UNSIGNED NOT NULL COMMENT '专题ID',
    `exam_point_id`     BIGINT UNSIGNED NOT NULL COMMENT '考点ID',
    `sequence`          INT NOT NULL DEFAULT 0 COMMENT '训练顺序',
    `stage_number`      TINYINT NOT NULL DEFAULT 1 COMMENT '所属阶段 1/2/3',
    `weight`            DECIMAL(3,2) NOT NULL DEFAULT 1.00 COMMENT '权重 0-1',
    `required_mastery`  VARCHAR(16) NOT NULL DEFAULT 'weak' COMMENT '准入掌握度 unknown/weak/basic/proficient',
    `target_mastery`    VARCHAR(16) NOT NULL DEFAULT 'proficient' COMMENT '目标掌握度',
    `question_count`    INT NOT NULL DEFAULT 3 COMMENT '推荐题目数',
    `created_at`        DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    UNIQUE KEY `uk_topic_point` (`topic_id`, `exam_point_id`),
    INDEX `idx_topic_seq` (`topic_id`, `stage_number`, `sequence`),
    FOREIGN KEY (`topic_id`) REFERENCES `exam_topic`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='专题考点表';
```

### 3.3 训练会话表 `topic_training_session`

```sql
CREATE TABLE `topic_training_session` (
    `id`                BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    `session_code`      VARCHAR(64)  NOT NULL UNIQUE COMMENT '会话编号 TTS-{user_id}-{topic_id}-{timestamp}',
    `user_id`           BIGINT UNSIGNED NOT NULL COMMENT '学生ID',
    `topic_id`          BIGINT UNSIGNED NOT NULL COMMENT '专题ID',
    `subject_code`      VARCHAR(16)  NOT NULL,
    `status`            VARCHAR(16)  NOT NULL DEFAULT 'preparing' COMMENT 'preparing/ongoing/paused/completed/aborted',
    `current_stage`     TINYINT      NOT NULL DEFAULT 1 COMMENT '当前阶段 1/2/3',
    `current_point_seq` INT          NOT NULL DEFAULT 0 COMMENT '当前考点顺序号',
    `total_questions`   INT          NOT NULL DEFAULT 0 COMMENT '总题数',
    `answered_questions` INT         NOT NULL DEFAULT 0 COMMENT '已答题数',
    `correct_count`     INT          NOT NULL DEFAULT 0 COMMENT '正确题数',
    `total_score`       DECIMAL(6,2) NOT NULL DEFAULT 0.00 COMMENT '总得分',
    `max_score`         DECIMAL(6,2) NOT NULL DEFAULT 0.00 COMMENT '总分',
    `started_at`        DATETIME(3)  COMMENT '开始时间',
    `completed_at`      DATETIME(3)  COMMENT '完成时间',
    `duration_seconds`  INT          NOT NULL DEFAULT 0 COMMENT '训练时长（秒）',
    `generation_params` JSON         COMMENT '生成参数快照',
    `created_at`        DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at`        DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    INDEX `idx_user_topic` (`user_id`, `topic_id`, `status`),
    INDEX `idx_user_status` (`user_id`, `status`, `created_at DESC`),
    FOREIGN KEY (`topic_id`) REFERENCES `exam_topic`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='专题训练会话表';
```

### 3.4 训练题目表 `topic_training_question`

记录会话中的每一道训练题目及其状态。

```sql
CREATE TABLE `topic_training_question` (
    `id`                BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    `session_id`        BIGINT UNSIGNED NOT NULL COMMENT '会话ID',
    `topic_point_id`    BIGINT UNSIGNED NOT NULL COMMENT '专题考点ID',
    `question_id`       BIGINT UNSIGNED NOT NULL COMMENT '题目ID',
    `stage_number`      TINYINT NOT NULL COMMENT '阶段',
    `sequence`          INT NOT NULL DEFAULT 0 COMMENT '题号',
    `question_snapshot` JSON NOT NULL COMMENT '题目快照（题干、选项、答案、解析）',
    `status`            VARCHAR(16) NOT NULL DEFAULT 'pending' COMMENT 'pending/answering/answered/corrected/skipped',
    `user_answer`       JSON COMMENT '用户答案',
    `is_correct`        TINYINT(1) DEFAULT NULL COMMENT '是否正确 0/1',
    `earned_score`      DECIMAL(5,2) DEFAULT 0.00 COMMENT '得分',
    `max_score`         DECIMAL(5,2) NOT NULL DEFAULT 1.00 COMMENT '满分',
    `answer_duration_seconds` INT DEFAULT 0 COMMENT '答题耗时',
    `answer_time`       DATETIME(3) COMMENT '作答时间',
    `created_at`        DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at`        DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    UNIQUE KEY `uk_session_seq` (`session_id`, `sequence`),
    INDEX `idx_session_point` (`session_id`, `topic_point_id`),
    INDEX `idx_session_status` (`session_id`, `status`),
    FOREIGN KEY (`session_id`) REFERENCES `topic_training_session`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='专题训练题目表';
```

### 3.5 训练记录表 `topic_training_record`

汇总一次会话的整体结果，用于统计与报告。

```sql
CREATE TABLE `topic_training_record` (
    `id`                BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    `session_id`        BIGINT UNSIGNED NOT NULL UNIQUE,
    `user_id`           BIGINT UNSIGNED NOT NULL,
    `topic_id`          BIGINT UNSIGNED NOT NULL,
    `total_questions`   INT NOT NULL DEFAULT 0,
    `correct_count`     INT NOT NULL DEFAULT 0,
    `accuracy_rate`     DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT '正确率 %',
    `total_score`       DECIMAL(6,2) NOT NULL DEFAULT 0.00,
    `max_score`         DECIMAL(6,2) NOT NULL DEFAULT 0.00,
    `duration_seconds`  INT NOT NULL DEFAULT 0,
    `stage_stats`       JSON NOT NULL COMMENT '各阶段统计 [{stage,total,correct,score}]',
    `weak_point_ids`    JSON COMMENT '本次训练薄弱考点ID',
    `mastered_point_ids` JSON COMMENT '本次训练已掌握考点ID',
    `generated_report`  TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否已生成报告',
    `created_at`        DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    INDEX `idx_user_topic` (`user_id`, `topic_id`, `created_at DESC`),
    FOREIGN KEY (`session_id`) REFERENCES `topic_training_session`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='专题训练记录表';
```

### 3.6 用户专题进度表 `user_topic_progress`

记录学生在每个专题的长期进度。

```sql
CREATE TABLE `user_topic_progress` (
    `id`                BIGINT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    `user_id`           BIGINT UNSIGNED NOT NULL,
    `topic_id`          BIGINT UNSIGNED NOT NULL,
    `total_sessions`    INT NOT NULL DEFAULT 0 COMMENT '训练次数',

    `overall_mastery`   VARCHAR(16) NOT NULL DEFAULT 'unknown' COMMENT 'unknown/weak/basic/proficient/strong',
    `weak_point_ids`    JSON COMMENT '持续薄弱考点',
    `mastered_point_ids` JSON COMMENT '已掌握考点',
    `last_trained_at`   DATETIME(3) COMMENT '最近训练时间',
    `created_at`        DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    `updated_at`        DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    UNIQUE KEY `uk_user_topic` (`user_id`, `topic_id`),
    INDEX `idx_user_mastery` (`user_id`, `overall_mastery`),
    FOREIGN KEY (`topic_id`) REFERENCES `exam_topic`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户专题进度表';
```

### 3.7 核心实体 TypeScript 定义

```typescript
interface ExamTopic {
  id: number;
  code: string;
  name: string;
  description?: string;
  subjectCode: string;
  stage: 'junior_high' | 'senior_high';
  gradeRange?: string;
  difficultyMin: number;
  difficultyMax: number;
  examType: 'zhongkao' | 'gaokao' | 'midterm' | 'final';
  coverImageUrl?: string;
  iconUrl?: string;
  status: 'draft' | 'active' | 'archived';
}

interface ExamTopicPoint {
  id: number;
  topicId: number;
  examPointId: number;
  sequence: number;
  stageNumber: number;
  weight: number;
  requiredMastery: MasteryLevel;
  targetMastery: MasteryLevel;
  questionCount: number;
}

type MasteryLevel = 'unknown' | 'weak' | 'basic' | 'proficient' | 'strong';

interface TopicTrainingSession {
  id: number;
  sessionCode: string;
  userId: number;
  topicId: number;
  subjectCode: string;
  status: 'preparing' | 'ongoing' | 'paused' | 'completed' | 'aborted';
  currentStage: number;
  currentPointSeq: number;
  totalQuestions: number;
  answeredQuestions: number;
  correctCount: number;
  totalScore: number;
  maxScore: number;
  startedAt?: string;
  completedAt?: string;
  durationSeconds: number;
}

interface TopicTrainingQuestion {
  id: number;
  sessionId: number;
  topicPointId: number;
  questionId: number;
  stageNumber: number;
  sequence: number;
  questionSnapshot: QuestionSnapshot;
  status: 'pending' | 'answering' | 'answered' | 'corrected' | 'skipped';
  userAnswer?: any;
  isCorrect?: boolean;
  earnedScore: number;
  maxScore: number;
  answerDurationSeconds?: number;
}

interface QuestionSnapshot {
  id: number;
  title: string;
  content: string;
  type: string;
  options?: Array<{ label: string; text: string }>;
  correctAnswer: any;
  explanation: string;
  difficulty: number;
  knowledgePointIds: number[];
  examPointId: number;
  score: number;
}
```

### 5.2 题目编排算法（Python 示例）

```python
from dataclasses import dataclass
from typing import List, Dict, Optional
import random

@dataclass
class TopicPoint:
    exam_point_id: int
    stage_number: int
    sequence: int
    weight: float
    required_mastery: str
    target_mastery: str
    question_count: int

@dataclass
class UserMastery:
    exam_point_id: int
    level: str  # unknown/weak/basic/proficient/strong
    correct_count: int
    total_count: int

MASTERY_SCORE = {
    'unknown': 0,
    'weak': 1,
    'basic': 2,
    'proficient': 3,
    'strong': 4
}

def select_points_for_session(
    topic_points: List[TopicPoint],
    user_mastery_map: Dict[int, UserMastery],
    focus_mode: str = 'adaptive',
    max_questions: int = 20
) -> List[TopicPoint]:
    """
    根据训练模式筛选考点。
    """
    if focus_mode == 'full':
        return topic_points

    if focus_mode == 'weak_only':
        return [p for p in topic_points
                if MASTERY_SCORE.get(user_mastery_map.get(p.exam_point_id, UserMastery(0, 'unknown', 0, 0)).level, 0) < 2]

    # adaptive: 优先薄弱 & 高频，已掌握考点减少题量
    scored = []
    for p in topic_points:
        mastery = user_mastery_map.get(p.exam_point_id, UserMastery(p.exam_point_id, 'unknown', 0, 0))
        # 掌握度越低、权重越高，越优先
        priority = (5 - MASTERY_SCORE.get(mastery.level, 0)) * p.weight
        scored.append((priority, p))

    scored.sort(key=lambda x: x[0], reverse=True)
    selected = [p for _, p in scored]

    # 在 adaptive 模式下，对 strong 考点可降采样题目数
    for p in selected:
        mastery = user_mastery_map.get(p.exam_point_id, UserMastery(p.exam_point_id, 'unknown', 0, 0))
        if mastery.level == 'strong':
            p.question_count = max(1, p.question_count // 2)

    return selected


def distribute_difficulty(
    stage_number: int,
    user_mastery: str,
    base_difficulty: tuple
) -> List[int]:
    """
    根据阶段和用户掌握度生成题目难度分布。
    """
    min_d, max_d = base_difficulty
    mastery = MASTERY_SCORE.get(user_mastery, 0)

    if stage_number == 1:
        # 基础巩固：低难度为主
        return [max(min_d, min(max_d, mastery + 1))] * 3
    elif stage_number == 2:
        # 变式提升：中等难度，略高于掌握度
        return [max(min_d, min(max_d, mastery + 2))] * 3
    else:
        # 综合突破：高难度
        return [max(min_d, min(max_d, max_d - 1))] * 3


def build_session_questions(
    topic_points: List[TopicPoint],
    user_mastery_map: Dict[int, UserMastery],
    question_pool: Dict[int, List[dict]],
    topic_difficulty_range: tuple,
    focus_mode: str = 'adaptive',
    max_questions: int = 20
) -> List[dict]:
    """
    编排训练会话题目列表。
    """
    selected_points = select_points_for_session(topic_points, user_mastery_map, focus_mode, max_questions)
    questions = []
    sequence = 1

    for point in selected_points:
        mastery = user_mastery_map.get(point.exam_point_id, UserMastery(point.exam_point_id, 'unknown', 0, 0))
        difficulties = distribute_difficulty(point.stage_number, mastery.level, topic_difficulty_range)

        pool = question_pool.get(point.exam_point_id, [])
        if not pool:
            continue

        # 按难度过滤，优先未做过的题目（去重）
        for diff in difficulties[:point.question_count]:
            candidates = [q for q in pool if abs(q['difficulty'] - diff) <= 1]
            if not candidates:
                candidates = pool
            chosen = random.choice(candidates)
            questions.append({
                'topic_point_id': point.id,
                'question_id': chosen['id'],
                'stage_number': point.stage_number,
                'sequence': sequence,
                'question_snapshot': chosen,
                'max_score': chosen.get('score', 1)
            })
            sequence += 1

            if len(questions) >= max_questions:
                break
        if len(questions) >= max_questions:
            break

    return questions
```

### 5.3 掌握度更新算法（Python 示例）

```python
def mastery_to_score(level: str) -> int:
    return MASTERY_SCORE.get(level, 0)

def score_to_mastery(score: int) -> str:
    if score <= 0:
        return 'unknown'
    if score == 1:
        return 'weak'
    if score == 2:
        return 'basic'
    if score == 3:
        return 'proficient'
    return 'strong'

def update_point_mastery(
    current_level: str,
    total_count: int,
    correct_count: int,
    new_is_correct: bool
) -> str:
    """
    基于最近答题表现更新考点掌握度。
    """
    new_total = total_count + 1
    new_correct = correct_count + (1 if new_is_correct else 0)
    accuracy = new_correct / new_total if new_total > 0 else 0

    # 至少需要 3 次作答才能稳定判定
    if new_total < 3:
        if accuracy >= 0.8:
            return 'basic'
        if accuracy < 0.4:
            return 'weak'
        return current_level

    if accuracy >= 0.85:
        return 'strong'
    if accuracy >= 0.65:
        return 'proficient'
    if accuracy >= 0.45:
        return 'basic'
    return 'weak'


def update_topic_progress(
    progress: dict,
    point_results: List[dict]
) -> dict:
    """
    根据一次训练结果更新用户专题进度。
    progress: { weak_point_ids, mastered_point_ids, total_sessions, ... }
    point_results: [{ exam_point_id, total, correct, new_mastery }]
    """
    weak_set = set(progress.get('weak_point_ids', []))
    mastered_set = set(progress.get('mastered_point_ids', []))

    for r in point_results:
        pid = r['exam_point_id']
        if r['new_mastery'] in ('strong', 'proficient'):
            mastered_set.add(pid)
            weak_set.discard(pid)
        elif r['new_mastery'] in ('weak', 'unknown'):
            weak_set.add(pid)
            mastered_set.discard(pid)
        else:
            weak_set.discard(pid)
            mastered_set.discard(pid)

    # 整体进度 = 已掌握考点 / 专题考点总数
    total_points = len(point_results)  # 简化示例，实际应取专题考点总数
    progress_value = len(mastered_set) / max(total_points, 1) * 100

    progress['weak_point_ids'] = list(weak_set)
    progress['mastered_point_ids'] = list(mastered_set)
    progress['overall_progress'] = round(progress_value, 2)
    progress['overall_mastery'] = score_to_mastery(
        int(round(progress_value / 25))  # 0-100 映射到 0-4
    )
    progress['total_sessions'] = progress.get('total_sessions', 0) + 1
    return progress
```

### 5.5 提交答案核心服务（Java 示例）

```java
package com.primetop.topictraining.application.service;

import com.primetop.topictraining.domain.entity.*;
import com.primetop.topictraining.domain.enums.*;
import com.primetop.topictraining.domain.repository.*;
import com.primetop.topictraining.infrastructure.event.*;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.math.BigDecimal;
import java.time.LocalDateTime;

@Service
@RequiredArgsConstructor
public class TopicTrainingService {

    private final TopicTrainingSessionRepository sessionRepo;
    private final TopicTrainingQuestionRepository questionRepo;
    private final TopicTrainingRecordRepository recordRepo;
    private final UserTopicProgressRepository progressRepo;
    private final TopicGradingService gradingService;
    private final EventPublisher eventPublisher;

    @Transactional
    public AnswerResultVO submitAnswer(Long sessionId, Long userId, Integer sequence, SubmitAnswerRequest request) {
        TopicTrainingSession session = sessionRepo.findById(sessionId)
            .orElseThrow(() -> new TopicTrainingException(TopicErrorCode.SESSION_NOT_FOUND));

        if (!session.getUserId().equals(userId)) {
            throw new TopicTrainingException(TopicErrorCode.SESSION_FORBIDDEN);
        }
        if (!session.getStatus().equals(TrainingSessionStatus.ONGOING)) {
            throw new TopicTrainingException(TopicErrorCode.SESSION_NOT_ONGOING);
        }

        TopicTrainingQuestion question = questionRepo.findBySessionIdAndSequence(sessionId, sequence)
            .orElseThrow(() -> new TopicTrainingException(TopicErrorCode.QUESTION_NOT_FOUND));
        if (!question.getStatus().equals(QuestionStatus.PENDING)) {
            throw new TopicTrainingException(TopicErrorCode.QUESTION_ALREADY_ANSWERED);
        }

        // 1. 判分
        GradingResult grading = gradingService.grade(
            question.getQuestionSnapshot(),
            request.getAnswer()
        );

        // 2. 更新题目状态
        question.setUserAnswer(JsonUtils.toJson(request.getAnswer()));
        question.setIsCorrect(grading.isCorrect());
        question.setEarnedScore(grading.getEarnedScore());
        question.setAnswerDurationSeconds(request.getDurationSeconds());
        question.setAnswerTime(LocalDateTime.now());
        question.setStatus(grading.isCorrect() ? QuestionStatus.ANSWERED_CORRECT : QuestionStatus.ANSWERED_WRONG);
        questionRepo.save(question);

        // 3. 更新会话统计
        session.setAnsweredQuestions(session.getAnsweredQuestions() + 1);
        session.setTotalScore(session.getTotalScore().add(grading.getEarnedScore()));
        if (grading.isCorrect()) {
            session.setCorrectCount(session.getCorrectCount() + 1);
        }
        sessionRepo.save(session);

        // 4. 发布事件：更新考点掌握度、错题收录、学习记录
        eventPublisher.publish(new TopicAnswerSubmittedEvent(
            sessionId, userId, question.getExamPointId(), question.getQuestionId(),
            grading.isCorrect(), request.getDurationSeconds()
        ));

        // 5. 返回结果 + 下一题
        TopicTrainingQuestion nextQuestion = questionRepo
            .findFirstBySessionIdAndStatusOrderBySequenceAsc(sessionId, QuestionStatus.PENDING)
            .orElse(null);

        return AnswerResultVO.builder()
            .sequence(sequence)
            .isCorrect(grading.isCorrect())
            .earnedScore(grading.getEarnedScore())
            .maxScore(question.getMaxScore())
            .correctAnswer(grading.getCorrectAnswer())
            .explanation(grading.getExplanation())
            .nextQuestion(nextQuestion == null ? null : QuestionBriefVO.from(nextQuestion))
            .build();
    }
}
```

## 6. 状态流转

### 6.1 训练会话状态机

```text
               ┌─────────────────────────────────────────┐
               │                                         │
               ▼                                         │
          ┌─────────┐   创建失败/专题下架            ┌─────────┐
          │preparing│───────────────────────────────▶│ aborted │
          └────┬────┘                                └─────────┘
               │ 创建成功
               ▼
          ┌─────────┐   用户暂停/家长控制/超时        ┌─────────┐
          │ ongoing │───────────────────────────────▶│ paused  │
          └────┬────┘                                └────┬────┘
               │                                          │ 恢复
               │ 全部完成                                  ▼
               │                                     ┌─────────┐
               │                                     │ ongoing │
               │                                     └─────────┘
               ▼
          ┌──────────┐   报告生成中                   ┌─────────┐
          │completed │──────────────────────────────▶│reported │
          └──────────┘                               └─────────┘
               │
               │ 超过保留时间/用户主动放弃
               ▼
          ┌─────────┐
          │ aborted │
          └─────────┘
```

**状态说明**

| 状态 | 含义 | 允许操作 |
|------|------|----------|
| `preparing` | 会话创建中，题目尚未就绪 | 可取消 |
| `ongoing` | 训练中 | 答题、跳过、暂停、结束 |
| `paused` | 暂停（用户/家长/超时） | 恢复、结束 |
| `completed` | 用户主动完成或全部题目已答 | 查看报告 |
| `reported` | 报告已生成 | 查看报告、重练 |
| `aborted` | 异常终止或会话过期 | 只读 |

```text
        pending
           │
           │ 开始展示
           ▼
       answering
           │
      ┌────┴────┐
      │         │
      ▼         ▼
  answered   skipped
```

### 6.3 阶段推进规则

```text
阶段 1 基础巩固：完成率 >= 80% 且 正确率 >= 60% → 进入阶段 2
阶段 2 变式提升：完成率 >= 80% 且 正确率 >= 50% → 进入阶段 3
阶段 3 综合突破：全部完成 → 训练完成

未达门槛：追加同阶段同考点题目 2-3 道，或进入下一阶段但标记为薄弱
```

## 7. 错误处理

### 7.1 错误码定义

| 错误码 | HTTP 状态 | 含义 | 客户端处理建议 |
|--------|-----------|------|----------------|
| `TOPIC_001` | 404 | 专题不存在 | 返回专题列表 |
| `TOPIC_002` | 403 | 无权限访问该专题（学段/年级/会员限制） | 提示权限不足 |
| `TOPIC_003` | 400 | 专题已下架或归档 | 提示专题不可用 |
| `TOPIC_101` | 404 | 训练会话不存在 | 返回专题详情 |
| `TOPIC_102` | 403 | 会话不属于当前用户 | 提示无权访问 |
| `TOPIC_103` | 409 | 会话状态非 ongoing | 按当前状态跳转 |
| `TOPIC_104` | 404 | 题目不存在或序号非法 | 获取当前题目 |
| `TOPIC_105` | 409 | 题目已作答或已跳过 | 展示下一题 |
| `TOPIC_106` | 400 | 答案格式非法 | 提示按题型作答 |
| `TOPIC_107` | 429 | 提交过于频繁 | 稍后重试 |
| `TOPIC_201` | 503 | 题目服务不可用 | 提示网络异常，重试 |
| `TOPIC_202` | 503 | 判分服务不可用 | 降级保存答案，异步判分 |
| `TOPIC_203` | 503 | 报告生成服务繁忙 | 提示报告稍后生成 |
| `TOPIC_301` | 500 | 内部错误 | 记录日志，提示稍后重试 |

### 7.2 降级策略

| 场景 | 降级方案 |
|------|----------|
| 题目服务不可用 | 返回已缓存的推荐题目；无缓存时返回预置兜底题库 |
| 掌握度数据缺失 | 按 `unknown` 处理，题目难度取中等，不跳过基础阶段 |
| AI 报告生成失败 | 返回规则生成的统计报告（正确率、阶段分布、薄弱点） |
| 高频考点数据过期 | 使用专题考点权重替代考试频率进行排序 |
| 网络中断 | 客户端本地保存答案，恢复后批量提交；提交带 request_id 幂等 |
| 用户端时间篡改 | 服务端以接收时间为准，记录请求时间戳与 duration 合理性校验 |

### 7.3 幂等与并发控制

- 创建会话：使用 `request_id` + Redis `SETNX` 30 秒去重，避免重复创建。
- 提交答案：以 `{session_id}:{sequence}:{request_id}` 为幂等 key，已处理直接返回上次结果。
- 并发更新会话统计：使用数据库乐观锁（`version` 字段）或 `UPDATE ... WHERE status='ongoing'` 保证状态正确。
- 完成会话：分布式锁 `topic:session:{session_id}:complete` 防止重复完成。

## 8. 性能优化

### 8.1 缓存策略

| 缓存 | Key | TTL | 说明 |
|------|-----|-----|------|
| 专题列表 | `topic:list:{subject}:{stage}:{exam_type}` | 1h | 按学科+学段+考试类型缓存 |
| 专题详情 | `topic:detail:{topic_id}` | 2h | 含考点列表、权重 |
| 用户专题进度 | `topic:progress:{user_id}:{topic_id}` | 30min | 写时更新 |
| 当前会话 | `topic:session:{session_id}` | 24h | 会话状态与当前题 |
| 会话题目 | `topic:questions:{session_id}` | 24h | 题目快照列表 |
| 高频题目 | `topic:hot_questions:{exam_point_id}:{difficulty}` | 6h | 热门考点题目池 |

### 8.2 数据库优化

- `topic_training_session` 按 `user_id + topic_id` 建复合索引。
- `topic_training_question` 按 `session_id + sequence` 建唯一索引。
- `user_topic_progress` 按 `user_id + overall_mastery` 建索引，用于首页推荐。
- 避免在答题链路中实时聚合统计，会话统计字段随每次提交增量更新。
- 报告生成采用异步任务，避免阻塞完成接口。

### 8.3 异步化

- 提交答案后，考点掌握度更新、错题收录、学习记录写入通过消息队列异步处理。
- 训练报告在会话完成事件触发后异步生成，生成完成后通过 WebSocket/推送通知用户。
- 大题量专题（>30 题）采用分页加载，避免一次性返回过多题目。

### 8.4 性能目标

| 接口 | 目标 P95 |
|------|----------|
| 专题列表 | < 200ms |
| 专题详情 | < 300ms |
| 创建会话 | < 500ms |
| 获取当前题目 | < 100ms |
| 提交答案 | < 300ms |
| 完成会话 | < 300ms |
| 报告生成 | < 5s（异步） |

## 9. 安全与合规

### 9.1 权限控制

- 所有接口必须校验 JWT，并验证 `user_id` 与请求参数一致。
- 学生只能查看/操作自己的训练会话与报告。
- 家长可查看绑定学生的专题进度（通过家长中心接口透传）。
- 管理后台可查看所有会话，但修改操作需记录审计日志。

### 9.2 数据隔离

- 专题与考点元数据按 `subject_code` + `stage` 隔离。
- 用户训练数据严格按 `user_id` 隔离，查询必须带 `user_id` 条件。
- 跨租户场景下需附加 `tenant_id` 过滤（如 B 端学校版本）。

### 9.3 未成年人保护

- 训练时长超过家长设定上限时，自动暂停会话并提示。
- 训练内容经过内容审核，确保不含敏感/不当信息。
- 错题自动收录需符合家长对错题本的可见性设置。

### 9.4 审计日志

记录以下操作：
- 创建会话（用户、专题、时间、IP、设备）。
- 完成会话（得分、正确率、耗时、薄弱点）。
- 提交答案（题目、结果、耗时）。
- 报告生成（生成方式、AI 摘要、推荐动作）。

## 10. 测试策略

### 10.1 单元测试

- 考点筛选算法（adaptive / full / weak_only）。
- 难度分布算法（阶段与掌握度映射）。
- 掌握度更新算法（边界：3 次以下、准确率为 0/0.5/1）。
- 状态机转换（completed 不可回退到 ongoing）。
- 幂等 key 生成与重复提交处理。

### 10.2 集成测试

- 创建会话 → 获取首题 → 提交答案 → 完成会话 → 查看报告。
- 断网重连后批量提交答案的幂等性。
- 题目服务不可用时降级到兜底题库。
- 完成会话后异步事件是否触发错题收录、学习记录。

### 10.3 性能测试

- 并发创建 100 个会话，验证题库抽题不重复、无锁冲突。
- 提交答案 1000 TPS，验证 P99 < 300ms。
- 缓存命中率目标 > 80%。

### 10.4 关键测试用例

| 用例编号 | 场景 | 预期结果 |
|----------|------|----------|
| TC-TBT-001 | 初中学生创建函数专题训练，掌握度为 basic | 生成阶段 1 和阶段 2 题目 |
| TC-TBT-002 | 全部答对阶段 1，进入阶段 2 | 返回阶段 2 更高难度题目 |
| TC-TBT-003 | 同一题重复提交（带相同 request_id） | 返回相同结果，不重复计分 |
| TC-TBT-004 | 网络中断后恢复，批量提交答案 | 答案顺序正确，幂等无误 |
| TC-TBT-005 | 题目服务不可用时创建会话 | 返回兜底题库题目，提示降级 |
| TC-TBT-006 | 完成训练后查看报告 | 报告包含阶段统计、薄弱点、AI 建议 |
| TC-TBT-007 | 超过家长设定时长 | 会话自动暂停，提示休息 |
