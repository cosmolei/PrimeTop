# 服务端-学生学习投入度多维量化与学习效能综合评估引擎-详细设计

> **模块定位**：将散落在各业务模块中的学习行为数据，统一提炼为「投入度」和「学习效能」两个多维指标体系，为学情报告、干预策略、家长端展示和运营分析提供量化基础。

---

## 1. 模块概述

### 1.1 背景与问题

现有系统中已有「学习时长统计」「学习状态实时感知」「学习动力量化」等模块，但各自聚焦单一维度：

| 现有模块 | 聚焦点 | 局限 |
|---------|--------|------|
| 学习时长统计 | 时间维度 | 只有"花了多少时间"，无法区分"高效学习"与"磨洋工" |
| 学习状态实时感知 | 会话级质量 | 只在单次答题/对话内有效，无法跨天聚合 |
| 学习动力量化 | 动机与倦怠 | 偏向心理状态，未结合行为表现 |
| 用户活跃度统计 | DAU/MAU | 仅反映是否打开App，不反映学习深度 |

**本引擎要解决的核心问题**：构建一套多维度的投入度量化模型和学习效能评估体系，回答：
- 这个学生到底有多"投入"？
- 他的学习时间中有多少是"有效时间"？
- 相比自身历史和同龄群体，他的学习效能处于什么水平？
- 哪些信号表明投入度正在下降，需要干预？

### 1.2 核心目标

1. **行为投入度（Behavioral Engagement）**：量化学习行为的频率、时长、连续性和多样性
2. **认知投入度（Cognitive Engagement）**：量化学习过程中的思维深度、策略使用和自我挑战
3. **情感投入度（Emotional Engagement）**：量化学习过程中的兴趣、满足感和积极情绪信号
4. **学习效能（Learning Efficiency）**：综合评估单位时间内的学习产出，形成"投入-产出"比率
5. **趋势与预警**：跟踪投入度变化趋势，在显著下降时触发干预

## 2. 核心概念与定义

### 2.1 三维投入度模型

| 维度 | 英文 | 衡量内容 | 数据来源 |
|------|------|---------|---------|
| 行为投入度 | Behavioral Engagement | 学习行为频率、持续时间、连续性、多样性 | 学习时长、答题、内容浏览、打卡 |
| 认知投入度 | Cognitive Engagement | 学习深度、策略运用、自我挑战意愿 | 答题正确率变化、追问深度、难题尝试率、笔记质量 |
| 情感投入度 | Emotional Engagement | 学习兴趣、积极情绪、归属感 | 主动学习比例、反馈评分、重访频率、社交互动 |

### 2.2 学习效能

学习效能 = 学习产出 / 学习投入，具体定义为：

```
学习效能指数(LEI) = f(知识掌握度增量, 有效学习时间, 目标达成率)
```

| 概念 | 定义 | 计算方式 |
|------|------|---------|
| 有效学习时间 | 排除空闲、走神后的真实学习时间 | 总时长 - 空闲段 - 低活跃段 |
| 学习产出 | 单位时间内的知识掌握度提升 | Δ掌握度 / 单位时间 |
| 目标达成率 | 实际完成任务数 / 计划任务数 | 完成任务数 / 计划任务数 |
| 效能指数 LEI | 综合产出投入比 | 加权公式（见 4.4 节） |

## 4. 核心算法设计

### 4.1 行为投入度计算

```python
import math
from datetime import datetime, timedelta
from typing import List, Dict

class BehavioralEngagementCalculator:
    """行为投入度计算器"""

    # 子维度权重（总和=1.0）
    WEIGHTS = {
        "frequency":   0.25,  # 学习行为频率
        "duration":    0.30,  # 学习时长
        "consistency": 0.25,  # 学习连续性
        "diversity":   0.20,  # 学科/功能多样性
    }

    # 行为频率评分基准（次/天）
    FREQUENCY_BASELINE = {
        "min_actions": 5,      # 低于5次 → 0分
        "full_actions": 80,    # 80次以上 → 满分
    }

    # 学习时长评分基准（分钟/天）
    DURATION_BASELINE = {
        "min_minutes": 10,     # 低于10分钟 → 0分
        # 满分阈值按学段动态调整
        "full_minutes_by_grade": {
            "preschool":  30,   # 幼儿 30min
            "primary":    60,   # 小学 60min
            "junior":     90,   # 初中 90min
            "senior":    120,   # 高中 120min
        },
    }

    def calculate(
        self,
        user_id: int,
        events: List[Dict],
        grade_category: str,
        study_date: datetime,
    ) -> Dict:
        """计算行为投入度各子维度得分"""

        freq_score = self._calc_frequency(events)
        dur_score = self._calc_duration(events, grade_category)
        cons_score = self._calc_consistency(user_id, events, study_date)
        div_score = self._calc_diversity(events)

        overall = (
            self.WEIGHTS["frequency"]   * freq_score
            + self.WEIGHTS["duration"]  * dur_score
            + self.WEIGHTS["consistency"] * cons_score
            + self.WEIGHTS["diversity"] * div_score
        )

        return {
            "score": round(overall, 2),
            "frequency": round(freq_score, 2),
            "duration": round(dur_score, 2),
            "consistency": round(cons_score, 2),
            "diversity": round(div_score, 2),
        }

    def _calc_frequency(self, events: List[Dict]) -> float:
        """行为频率得分：统计当日有效学习动作数"""
        # 有效动作：答题、提问、浏览内容、记笔记、打卡等
        valid_types = {"answer", "ai_chat", "browse", "note", "checkin", "practice"}
        action_count = sum(1 for e in events if e["event_type"] in valid_types)

        lo = self.FREQUENCY_BASELINE["min_actions"]
        hi = self.FREQUENCY_BASELINE["full_actions"]
        return self._normalize(action_count, lo, hi)

    def _calc_duration(self, events: List[Dict], grade: str) -> float:
        """学习时长得分：基于学段动态调整满分阈值"""
        total_minutes = sum(e.get("features", {}).get("active_duration", 0) for e in events) / 60

        full_key = self.DURATION_BASELINE["full_minutes_by_grade"].get(grade, 60)
        return self._normalize(total_minutes,
                               self.DURATION_BASELINE["min_minutes"],
                               full_key)

    def _calc_consistency(self, user_id: int, events: List[Dict], study_date: datetime) -> float:
        """学习连续性得分：基于最近7天学习天数的连续性"""
        # 从 Redis 获取最近7天的学习天数
        # consistency = 连续学习天数 / 7
        recent_days = self._get_recent_study_days(user_id, study_date, days=7)
        consecutive = self._max_consecutive_days(recent_days, study_date)

        # 7天中有5天以上连续学习 → 满分区间
        # 但也要避免过度学习（每天学7天也可能不健康）
        if consecutive >= 6:
            return 95.0  # 连续学习但不给满分，保留空间
        elif consecutive >= 5:
            return 90.0
        elif consecutive >= 4:
            return 75.0
        elif consecutive >= 3:
            return 60.0
        elif consecutive >= 2:
            return 40.0
        elif len(recent_days) >= 1:
            return 20.0
        else:
            return 0.0

    def _calc_diversity(self, events: List[Dict]) -> float:
        """学科/功能多样性得分：使用Shannon熵衡量多样性"""
        from collections import Counter
        import math

        subject_counts = Counter(e.get("features", {}).get("subject", "unknown") for e in events)
        total = sum(subject_counts.values())
        if total == 0:
            return 0.0

        entropy = -sum(
            (count / total) * math.log2(count / total)
            for count in subject_counts.values()
        )
        max_entropy = math.log2(max(len(subject_counts), 1))
        if max_entropy == 0:
            return 50.0  # 只有单一学科也给基础分

        # Shannon均匀度（evenness）× 100
        evenness = entropy / max_entropy
        return round(evenness * 100, 2)

    @staticmethod
    def _normalize(value: float, lo: float, hi: float) -> float:
        """线性归一化到 [0, 100]"""
        if value <= lo:
            return 0.0
        if value >= hi:
            return 100.0
        return round((value - lo) / (hi - lo) * 100, 2)
```

### 4.2 认知投入度计算

```python
class CognitiveEngagementCalculator:
    """认知投入度计算器"""

    WEIGHTS = {
        "depth":     0.40,  # 学习深度
        "strategy":  0.35,  # 策略运用
        "challenge": 0.25,  # 自我挑战
    }

    def calculate(self, events: List[Dict], knowledge_state: Dict) -> Dict:
        depth_score = self._calc_depth(events)
        strategy_score = self._calc_strategy(events)
        challenge_score = self._calc_challenge(events, knowledge_state)

        overall = (
            self.WEIGHTS["depth"]     * depth_score
            + self.WEIGHTS["strategy"]  * strategy_score
            + self.WEIGHTS["challenge"] * challenge_score
        )
        return {
            "score": round(overall, 2),
            "depth": round(depth_score, 2),
            "strategy": round(strategy_score, 2),
            "challenge": round(challenge_score, 2),
        }

    def _calc_depth(self, events: List[Dict]) -> float:
        """学习深度得分：综合追问次数、笔记质量、内容停留时间"""
        score = 0.0

        # 1. AI对话追问深度（多轮追问体现深度思考）
        chat_events = [e for e in events if e["event_type"] == "ai_chat"]
        avg_followup = self._avg_followup_depth(chat_events)  # 平均追问轮数
        score += self._normalize(avg_followup, 0, 4) * 35     # 最多35分

        # 2. 答题后的反思行为（查看解析、标记错因、添加笔记）
        reflection_events = sum(
            1 for e in events
            if e.get("features", {}).get("has_reflection", False)
        )
        score += self._normalize(reflection_events, 0, 5) * 35  # 最多35分

        # 3. 内容深度阅读（非快速滑屏，在内容页停留超过阈值）
        deep_reads = sum(
            1 for e in events
            if e["event_type"] == "browse"
            and e.get("features", {}).get("active_duration", 0) > 180  # 3分钟以上
        )
        score += self._normalize(deep_reads, 0, 3) * 30  # 最多30分

        return min(score, 100.0)

    def _calc_strategy(self, events: List[Dict]) -> float:
        """策略运用得分：错题复习策略、知识关联使用、计划遵循度"""
        score = 0.0

        # 1. 主动复习错题（体现元认知策略）
        review_events = sum(1 for e in events if e.get("features", {}).get("is_review", False))
        score += self._normalize(review_events, 0, 3) * 35

        # 2. 使用知识图谱/关联学习
        graph_events = sum(1 for e in events if e.get("features", {}).get("uses_knowledge_graph", False))
        score += self._normalize(graph_events, 0, 2) * 25

        # 3. 学习计划遵循度
        plan_completion = self._get_plan_completion(events)  # 0-1
        score += plan_completion * 100 * 0.40

        return min(score, 100.0)

    def _calc_challenge(self, events: List[Dict], knowledge_state: Dict) -> float:
        """自我挑战得分：尝试难题、超出当前水平、主动选择高难度"""
        answer_events = [e for e in events if e["event_type"] == "answer"]

        if not answer_events:
            return 0.0

        # 难题尝试率
        hard_attempts = sum(
            1 for e in answer_events
            if e.get("features", {}).get("difficulty_level") in ("hard", "challenge")
        )
        hard_ratio = hard_attempts / len(answer_events)

        # 是否尝试超出当前掌握度的内容
        user_level = knowledge_state.get("overall_mastery", 0.5)
        above_level = sum(
            1 for e in answer_events
            if e.get("features", {}).get("difficulty_score", 0.5) > user_level + 0.15
        )
        above_ratio = above_level / len(answer_events)

        # 综合挑战得分
        challenge = hard_ratio * 60 + above_ratio * 40
        return round(min(challenge * 100, 100), 2)

    @staticmethod
    def _avg_followup_depth(chat_events: List[Dict]) -> float:
        if not chat_events:
            return 0.0
        depths = [e.get("features", {}).get("followup_count", 0) for e in chat_events]
        return sum(depths) / len(depths)

    @staticmethod
    def _get_plan_completion(events: List[Dict]) -> float:
        plan_events = [e for e in events if e["event_type"] == "plan"]
        if not plan_events:
            return 0.0
        completions = [e.get("features", {}).get("completion_rate", 0) for e in plan_events]
        return sum(completions) / len(completions)

    @staticmethod
    def _normalize(value: float, lo: float, hi: float) -> float:
        if value <= lo:
            return 0.0
        if value >= hi:
            return 100.0
        return (value - lo) / (hi - lo) * 100
```

```python
class EmotionalEngagementCalculator:
    """情感投入度计算器"""

    WEIGHTS = {
        "interest":      0.40,
        "satisfaction":  0.35,
        "belonging":     0.25,
    }

    def calculate(self, events: List[Dict], feedback_data: Dict) -> Dict:
        interest = self._calc_interest(events)
        satisfaction = self._calc_satisfaction(events, feedback_data)
        belonging = self._calc_belonging(events)

        overall = (
            self.WEIGHTS["interest"]     * interest
            + self.WEIGHTS["satisfaction"] * satisfaction
            + self.WEIGHTS["belonging"]    * belonging
        )
        return {
            "score": round(overall, 2),
            "interest": round(interest, 2),
            "satisfaction": round(satisfaction, 2),
            "belonging": round(belonging, 2),
        }

    def _calc_interest(self, events: List[Dict]) -> float:
        """学习兴趣得分：主动发起学习占比、非必做任务完成率"""
        total_sessions = len({e.get("features", {}).get("session_id") for e in events})
        self_initiated = sum(
            1 for e in events
            if e.get("features", {}).get("is_self_initiated", False)
        )

        if total_sessions == 0:
            return 0.0

        # 主动发起学习比例
        init_ratio = self_initiated / total_sessions
        return round(init_ratio * 100, 2)

    def _calc_satisfaction(self, events: List[Dict], feedback_data: Dict) -> float:
        """满足感得分：AI回答满意度评分 + 学习成就感"""
        score = 0.0

        # 1. AI回答满意度（用户反馈评分加权）
        avg_rating = feedback_data.get("avg_ai_rating", 0)  # 1-5 分
        if avg_rating > 0:
            score += (avg_rating / 5.0) * 50  # 最多50分

        # 2. 答题正确率提升带来的成就感
        answer_events = [e for e in events if e["event_type"] == "answer"]
        if answer_events:
            correct = sum(1 for e in answer_events if e.get("features", {}).get("is_correct", False))
            accuracy = correct / len(answer_events)
            # 正确率在 60-90% 区间最能产生心流体验
            if 0.6 <= accuracy <= 0.9:
                score += 35
            elif accuracy > 0.9:
                score += 25  # 太容易也降低兴趣
            elif accuracy > 0.4:
                score += 20
        else:
            score += 15  # 无答题也给基础分

        # 3. 内容重访率（回来继续学习说明有满足感）
        revisit_rate = feedback_data.get("content_revisit_rate", 0)
        score += min(revisit_rate * 100, 15)

        return min(score, 100.0)

    def _calc_belonging(self, events: List[Dict]) -> float:
        """参与感得分：社交互动、打卡分享、同伴协作"""
        social_events = sum(1 for e in events if e["event_type"] == "social")
        share_events = sum(1 for e in events if e.get("features", {}).get("has_shared", False))
        challenge_events = sum(
            1 for e in events
            if e.get("features", {}).get("is_challenge_participated", False)
        )

        score = 0.0
        score += min(social_events * 15, 40)
        score += min(share_events * 20, 30)
        score += min(challenge_events * 30, 30)

        return min(score, 100.0)
```

### 4.4 学习效能指数（LEI）计算

```python
class LearningEfficiencyCalculator:
    """学习效能指数计算器"""

    def calculate(
        self,
        effective_minutes: int,
        total_minutes: int,
        knowledge_gain: float,      # 当日知识掌握度增量 (Δmastery 0-1)
        plan_completion_rate: float, # 计划完成率 0-1
        benchmark_efficiency: float, # 同年级群体基准效率
    ) -> Dict:
        """
        计算学习效能指数 LEI (Learning Efficiency Index)
        返回 0-100 分数
        """

        # 1. 有效学习时间占比
        if total_minutes == 0:
            return {"lei_score": 0.0, "efficiency_ratio": 0.0, "components": {}}

        efficiency_ratio = effective_minutes / total_minutes  # 0-1

        # 2. 单位时间知识获取率（产出密度）
        # knowledge_gain_per_hour = knowledge_gain / (effective_minutes / 60)
        # 归一化：假设每小时掌握度增加 0.05 为良好水平
        gain_per_hour = knowledge_gain / max(effective_minutes / 60, 0.1)
        gain_normalized = self._normalize(gain_per_hour, 0, 0.08)

        # 3. 目标达成率
        goal_factor = plan_completion_rate  # 0-1

        # 4. 相对群体基准
        if benchmark_efficiency > 0:
            relative_factor = min(gain_normalized / benchmark_efficiency, 1.5)
        else:
            relative_factor = 1.0

        # 加权合成
        lei = (
            efficiency_ratio   * 25 +   # 有效时间占比 25%
            gain_normalized     * 35 +   # 知识获取率 35%
            goal_factor * 100  * 25 +   # 目标达成率 25%
            min(relative_factor * 100, 100) * 0.15  # 相对基准 15%
        )

        return {
            "lei_score": round(min(lei, 100), 2),
            "efficiency_ratio": round(efficiency_ratio * 100, 2),
            "components": {
                "effective_ratio_score": round(efficiency_ratio * 25, 2),
                "knowledge_gain_score": round(gain_normalized * 35, 2),
                "goal_completion_score": round(goal_factor * 100 * 25, 2),
                "relative_benchmark_score": round(min(relative_factor * 100, 100) * 0.15, 2),
            },
        }

    @staticmethod
    def _normalize(value: float, lo: float, hi: float) -> float:
        if value <= lo:
            return 0.0
        if value >= hi:
            return 1.0
        return (value - lo) / (hi - lo)
```

### 5.1 空闲段检测

```python
from datetime import datetime, timedelta

class EffectiveTimeCalculator:
    """有效学习时间计算器"""

    IDLE_THRESHOLD_SECONDS = 120     # 超过2分钟无操作视为空闲
    MICRO_IDLE_THRESHOLD = 30        # 30秒以内的间隙忽略
    MIN_SESSION_DURATION = 60        # 不足60秒的会话不计入有效时间

    def calculate_effective_time(
        self,
        session_events: List[Dict],
        session_start: datetime,
        session_end: datetime,
    ) -> Dict:
        """
        基于事件时间戳计算有效学习时间
        策略：将连续事件之间的间隔分类为"活跃段"或"空闲段"
        """
        if not session_events:
            return {"effective_seconds": 0, "total_seconds": 0, "idle_periods": 0}

        # 按时间排序事件
        sorted_events = sorted(session_events, key=lambda e: e["timestamp"])

        total_seconds = (session_end - session_start).total_seconds()
        effective_seconds = 0.0
        idle_count = 0
        last_ts = session_start

        for event in sorted_events:
            current_ts = event["timestamp"]
            gap = (current_ts - last_ts).total_seconds()

            if gap > self.IDLE_THRESHOLD_SECONDS:
                # 空闲段：不计入有效时间
                idle_count += 1
                # 但上一段活跃时间仍然计入
                active_segment = (last_ts - session_start).total_seconds()
                # 注：这里简化处理，实际应分段累加
            else:
                # 活跃段
                effective_seconds += gap

            last_ts = current_ts

        # 处理最后一段
        final_gap = (session_end - last_ts).total_seconds()
        if final_gap <= self.IDLE_THRESHOLD_SECONDS:
            effective_seconds += final_gap

        # 有效时间不超过总时间
        effective_seconds = min(effective_seconds, total_seconds)

        return {
            "effective_seconds": int(effective_seconds),
            "total_seconds": int(total_seconds),
            "effective_ratio": round(effective_seconds / max(total_seconds, 1), 4),
            "idle_periods": idle_count,
        }
```

```python
class EngagementAlertEngine:

    ALERT_RULES = [

            "description": "学习脱钩（连续多天极少学习）",

            "type": "burnout_risk",
            "description": "过度学习且效能下降",
            "condition": lambda ctx: (
                ctx["study_minutes_7d"] > 1200  # 每周超20小时
                and ctx["lei_trend"] == "down"
                and ctx["emotional_score"] < 40
            ),
            "severity": lambda ctx: "warning",
            "threshold_key": "emotional_threshold",
        },
    ]

    COOLDOWN_HOURS = {
        "engagement_drop": 24,
        "low_efficiency": 48,
        "disengaged": 72,
        "behavioral_only": 24,
        "burnout_risk": 48,
    }

    def evaluate(self, user_id: int, context: Dict) -> List[Dict]:
        """评估用户是否触发预警规则"""
        alerts = []

        for rule in self.ALERT_RULES:
            if not rule["condition"](context):
                continue

            # 冷却检查
            cooldown_key = f"engagement:alert:cooldown:{user_id}:{rule['type']}"
            if self._is_in_cooldown(cooldown_key):
                continue

            severity = rule["severity"](context)
            alert = {
                "user_id": user_id,
                "alert_type": rule["type"],
                "severity": severity,
                "trigger_value": context.get("current_engagement", 0),
                "threshold_value": context.get(rule["threshold_key"], 0),
                "context": self._build_alert_context(rule["type"], context),
                "status": "active",
                "triggered_at": datetime.utcnow(),
            }

            alerts.append(alert)
            self._set_cooldown(cooldown_key, self.COOLDOWN_HOURS[rule["type"]])

        return alerts
```

```python
class EngagementDailyPipeline:
    """日快照计算管道"""

    def run(self, target_date: date):
        """执行某天的全量投入度计算"""
        # 1. 获取当天有学习行为的所有用户
        active_users = self._get_active_users(target_date)
        logger.info(f"Processing {len(active_users)} users for {target_date}")

        # 2. 分批处理
        batch_size = 200
        for batch in chunked(active_users, batch_size):
            self._process_batch(batch, target_date)

    def _process_batch(self, user_ids: List[int], target_date: date):
        snapshots = []

        for user_id in user_ids:
            try:
                # 3. 获取用户当天所有学习事件
                events = self.event_store.query_events(
                    user_id=user_id,
                    date=target_date,
                )

                if not events:
                    continue

                # 4. 获取用户信息
                user_meta = self.user_service.get_user_meta(user_id)
                grade_category = user_meta.grade_category  # preschool/primary/junior/senior

                # 5. 计算有效学习时间
                effective_time = self.eff_time_calc.calculate_effective_time(
                    events=events,
                    session_start=events[0]["timestamp"],
                    session_end=events[-1]["timestamp"],
                )

                # 6. 计算三维投入度
                behavioral = self.behavioral_calc.calculate(
                    user_id, events, grade_category, target_date
                )
                cognitive = self.cognitive_calc.calculate(
                    events, user_meta.knowledge_state
                )
                emotional = self.emotional_calc.calculate(
                    events, self._get_feedback_data(user_id, target_date)
                )

                # 7. 合成综合投入度
                composed = self.composer.compose(
                    behavioral, cognitive, emotional, grade_category
                )

                # 8. 计算学习效能
                knowledge_gain = self.knowledge_service.get_daily_gain(
                    user_id, target_date
                )
                plan_completion = self.plan_service.get_completion_rate(
                    user_id, target_date
                )
                benchmark = self.benchmark_service.get_benchmark(
                    grade_category, target_date
                )
                lei = self.efficiency_calc.calculate(
                    effective_time["effective_seconds"] // 60,
                    effective_time["total_seconds"] // 60,
                    knowledge_gain,
                    plan_completion,
                    benchmark,
                )

                # 9. 构建快照记录
                snapshot = EngagementDailySnapshot(
                    user_id=user_id,
                    snapshot_date=target_date,
                    behavioral_score=behavioral["score"],
                    behavioral_frequency=behavioral["frequency"],
                    behavioral_duration=behavioral["duration"],
                    behavioral_consistency=behavioral["consistency"],
                    behavioral_diversity=behavioral["diversity"],
                    cognitive_score=cognitive["score"],
                    cognitive_depth=cognitive["depth"],
                    cognitive_strategy=cognitive["strategy"],
                    cognitive_challenge=cognitive["challenge"],
                    emotional_score=emotional["score"],
                    emotional_interest=emotional["interest"],
                    emotional_satisfaction=emotional["satisfaction"],
                    emotional_belonging=emotional["belonging"],
                    overall_engagement=composed["overall_engagement"],
                    effective_study_minutes=effective_time["effective_seconds"] // 60,
                    total_study_minutes=effective_time["total_seconds"] // 60,
                    efficiency_ratio=lei["efficiency_ratio"],
                    knowledge_gain=knowledge_gain,
                    lei_score=lei["lei_score"],
                    data_completeness=self._calc_data_completeness(events),
                    model_version="v1.0",
                )
                snapshots.append(snapshot)

            except Exception as e:
                logger.error(f"Failed to process user {user_id}: {e}", exc_info=True)
                continue

        # 10. 批量写入数据库
        self.snapshot_repo.bulk_upsert(snapshots)
```

```python
class EngagementInterventionHandler:
    """投入度预警 → 干预策略联动"""

    def handle_alert(self, alert: Dict):
        """根据预警类型触发相应干预"""

        if alert["alert_type"] == "engagement_drop":
            # 投入度下降 → 发送学习提醒
            self.intervention_service.trigger(
                user_id=alert["user_id"],
                intervention_type="study_reminder",
                priority="high",
                context=alert["context"],
                channel="push_notification",
            )

        elif alert["alert_type"] == "low_efficiency":
            # 效能偏低 → 推荐高效学习方法
            self.intervention_service.trigger(
                user_id=alert["user_id"],
                intervention_type="efficiency_tip",
                priority="medium",
                content_key="efficiency_improvement_tips",
                channel="in_app_message",
            )

        elif alert["alert_type"] == "disengaged":
            # 学习脱钩 → 通知家长 + 关怀推送
            self.intervention_service.trigger(
                user_id=alert["user_id"],
                intervention_type="parent_notification",
                priority="critical",
                channel="parent_push",
            )
            self.intervention_service.trigger(
                user_id=alert["user_id"],
                intervention_type="care_message",
                priority="high",
                content_key="we_miss_you",
                channel="push_notification",
            )

        elif alert["alert_type"] == "burnout_risk":
            # 过度学习 → 建议休息
            self.intervention_service.trigger(
                user_id=alert["user_id"],
                intervention_type="rest_suggestion",
                priority="warning",
                content_key="take_a_break",
                channel="in_app_popup",
            )

        elif alert["alert_type"] == "behavioral_only":
            # 磨洋工 → 推送互动式练习提高参与度
            self.intervention_service.trigger(
                user_id=alert["user_id"],
                intervention_type="interactive_content",
                priority="info",
                content_key="try_interactive_exercise",
                channel="in_app_banner",
            )
```

## 10. 错误处理与降级策略

### 10.1 错误处理矩阵

| 场景 | 处理方式 | 降级方案 |
|------|---------|---------|
| 事件数据缺失 | 数据完整度标记 < 0.5 时不生成快照 | 使用前一天的快照填充，标记 `data_completeness` |
| 知识掌握度服务不可用 | knowledge_gain 默认为 0 | LEI 分数仅基于时间效率和计划完成率 |
| 群体基准未计算 | relative_factor 设为 1.0 | 跳过群体对比维度 |
| Redis 缓存不可用 | 直接查询数据库 | 请求量增加时自动降级为粗粒度查询 |
| 单用户计算超时（>5s） | 跳过该用户，记录日志 | 在下次补算任务中重试 |
| Kafka 消息积压 | 丢弃超过24小时的事件 | 在日快照计算时标注 `data_completeness` 降低 |

### 10.2 异常码定义

| 错误码 | 含义 | HTTP 状态 |
|--------|------|-----------|
| ENG_001 | 用户不存在 | 404 |
| ENG_002 | 查询日期超出范围（未来/过早） | 400 |
| ENG_003 | 数据不完整（completeness < 0.3） | 200（返回数据但带警告标记） |
| ENG_004 | 预警ID不存在 | 404 |
| ENG_005 | 预警状态非法转换 | 400 |
| ENG_006 | 基准数据不存在（新学段/新月份） | 200（返回 null 基准） |
| ENG_999 | 内部错误 | 500 |

### 12.1 单元测试

```python
import pytest

class TestBehavioralEngagementCalculator:

    def test_frequency_zero_actions(self):
        """无学习行为时频率得分为0"""
        calc = BehavioralEngagementCalculator()
        score = calc._calc_frequency([])
        assert score == 0.0

    def test_frequency_full_actions(self):
        """80+次行为得满分"""
        calc = BehavioralEngagementCalculator()
        events = [{"event_type": "answer"} for _ in range(80)]
        score = calc._calc_frequency(events)
        assert score == 100.0

    def test_duration_by_grade(self):
        """不同学段满分阈值不同"""
        calc = BehavioralEngagementCalculator()
        events = [{"features": {"active_duration": 3600}}]  # 60分钟

        primary_score = calc._calc_duration(events, "primary")
        senior_score = calc._calc_duration(events, "senior")
        # 高中满分120分钟，60分钟只有50分
        assert primary_score == 100.0
        assert senior_score == pytest.approx(45.45, rel=0.01)

    def test_diversity_single_subject(self):
        """单一学科得基础分"""
        calc = BehavioralEngagementCalculator()
        events = [{"features": {"subject": "math"}} for _ in range(10)]
        score = calc._calc_diversity(events)
        assert score == 50.0  # 单一学科

    def test_diversity_balanced(self):
        """均匀多学科接近满分"""
        calc = BehavioralEngagementCalculator()
        events = [
            {"features": {"subject": "math"}},
            {"features": {"subject": "chinese"}},
            {"features": {"subject": "english"}},
            {"features": {"subject": "physics"}},
        ]
        score = calc._calc_diversity(events)
        assert score > 95.0
```
