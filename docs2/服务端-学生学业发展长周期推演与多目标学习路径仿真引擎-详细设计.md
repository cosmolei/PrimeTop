# 服务端-学生学业发展长周期推演与多目标学习路径仿真引擎 详细设计

## 1. 概述

### 1.1 模块定位

学生学业发展长周期推演与多目标学习路径仿真引擎（Academic Trajectory Simulation & Multi-Objective Path Optimization Engine，简称 ATLAS）是 PrimeTop 学情分析体系中的**战略层**服务。与"学习成绩预测与考试分数预估引擎"（预测单次考试分数）、"学习计划动态调整与智能重排服务"（短期任务重排）不同，ATLAS 聚焦于**学期到学年跨度的长周期学业发展建模**，提供趋势推演、场景仿真、多目标优化和路径对比分析能力。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 长周期趋势建模 | 基于历史学习数据构建知识掌握度、学习投入度、学业成绩的时间序列模型 |
| 学业轨迹推演 | 预测未来 3-12 个月各学科、各知识维度的掌握度演化曲线 |
| 场景仿真 | 支持"What-If"参数调节（每日学习时长、学科侧重、新增辅导等），推演不同策略下的学业发展 |
| 多目标优化 | 在考试提分、知识深度、学习效率、心理负荷等多目标间寻找帕累托最优学习方案 |
| 季节性模式检测 | 识别暑假滑坡、考前冲刺、开学适应期等周期性规律 |
| 同伴轨迹对比 | 与匿名化群体轨迹进行对比分析，定位学生相对位置 |

### 1.4 用户场景

**场景 1：学期规划辅助**
> 初二学生家长想知道：如果孩子每天多花 30 分钟在物理上，期末物理成绩能提升多少？对其他学科有什么影响？

**场景 2：升学路径选择**
> 高一学生面临选科，想了解：选择"物理+化学+生物"vs"物理+化学+地理"，哪个路径更匹配当前学业基础和高考目标？

**场景 3：暑期滑坡预警**
> 小学四年级学生暑期完全没有学习，系统预测开学后数学计算能力将下降 15%，推荐暑期复习方案。

**场景 4：同伴基准对比**
> 家长想了解：孩子在同年级学生中处于什么水平？如果按目前趋势发展，中考能上什么梯队的学校？

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 学业轨迹快照 (AcademicTrajectorySnapshot)

记录某个时间点的学生学业状态全貌，是推演的起点和校验基准。

```java
/**
 * 学业轨迹快照 - 某时刻学生学业状态的完整横截面
 */
@Data
@TableName("atlas_trajectory_snapshot")
public class TrajectorySnapshot {
    /** 主键 */
    private Long id;
    
    /** 学生用户ID */
    private Long studentId;
    
    /** 快照日期（精确到天） */
    private LocalDate snapshotDate;
    
    /** 快照类型：WEEKLY / MONTHLY / TERM_START / TERM_END / EXAM / MANUAL */
    private String snapshotType;
    
    /** 学期标识，如 2025-2026-1 */
    private String semesterId;
    
    /** 学段 */
    private String stage; // PRIMARY / JUNIOR / SENIOR
    
    /** 年级 */
    private Integer gradeLevel;
    
    /** 多维掌握度摘要（JSON） */
    /** 结构：{"math": {"overall": 0.72, "dimensions": {"calculation": 0.85, "geometry": 0.65, ...}}, ...} */
    private String masterySummary;
    
    /** 学习投入度指标（JSON） */
    /** 结构：{"avgDailyMinutes": 95, "subjectDistribution": {"math": 30, "chinese": 25, ...}, "consistency": 0.78} */
    private String engagementMetrics;
    
    /** 最近考试成绩（JSON） */
    /** 结构：{"math": {"score": 85, "fullScore": 100, "rank": "top30%", "date": "2025-09-30"}, ...} */
    private String recentScores;
    
    /** 学习状态指标（JSON） */
    /** 结构：{"motivation": 0.72, "burnoutRisk": 0.15, "confidenceLevel": 0.68} */
    private String wellbeingIndex;
    
    /** 关联的考试ID列表 */
    private String relatedExamIds;
    
    /** 创建时间 */
    private LocalDateTime createdAt;
    
    /** 快照版本号，用于数据回溯 */
    private Integer version;
}
```

#### 2.1.2 推演任务 (SimulationTask)

```java
/**
 * 推演任务 - 一次场景仿真请求
 */
@Data
@TableName("atlas_simulation_task")
public class SimulationTask {
    /** 主键 */
    private Long id;
    
    /** 学生用户ID */
    private Long studentId;
    
    /** 推演类型 */
    private SimulationType type;
    // STANDARD_FORECAST: 标准趋势预测（按当前轨迹外推）
    // WHAT_IF: What-If场景仿真（修改参数后预测）
    // MULTI_OBJECTIVE: 多目标优化（寻找最优学习方案）
    // PEER_COMPARISON: 同伴轨迹对比
    // SEASONAL_ANALYSIS: 季节性模式分析
    
    /** 推演配置参数（JSON） */
    private String config;
    // WHAT_IF 示例:
    // {
    //   "baseSnapshotId": 12345,
    //   "timeHorizon": "6 months",
    //   "parameterOverrides": {
    //     "dailyStudyTime": { "math": +30, "physics": -15 },
    //     "newActivities": ["weekly_math_tutoring"],
    //     "removedActivities": ["gaming_time"]
    //   },
    //   "targetMetrics": ["math_score", "physics_score", "overall_rank"]
    // }
    
    /** 基准快照ID */
    private Long baseSnapshotId;
    
    /** 推演时间跨度（天） */
    private Integer horizonDays;
    
    /** 状态 */
    private SimulationStatus status;
    // PENDING → RUNNING → COMPLETED / FAILED / CANCELLED
    
    /** 优先级（1-10，10最高） */
    private Integer priority;
    
    /** 创建者 */
    private Long createdBy; // studentId 或 parentId
    
    /** 创建时间 */
    private LocalDateTime createdAt;
    
    /** 完成时间 */
    private LocalDateTime completedAt;
    
    /** 推演结果（JSON，结果较大时存对象存储） */
    private String resultRef; // OSS key 或内联 JSON
    
    /** 错误信息 */
    private String errorMessage;
    
    /** 计算耗时（毫秒） */
    private Long computeTimeMs;
}

public enum SimulationType {
    STANDARD_FORECAST,
    WHAT_IF,
    MULTI_OBJECTIVE,
    PEER_COMPARISON,
    SEASONAL_ANALYSIS
}

public enum SimulationStatus {
    PENDING,
    RUNNING,
    COMPLETED,
    FAILED,
    CANCELLED
}
```

#### 2.1.3 推演结果 (SimulationResult)

```java
/**
 * 推演结果 - 仿真计算的输出
 */
@Data
public class SimulationResult {
    
    /** 推演ID */
    private Long simulationId;
    
    /** 学生ID */
    private Long studentId;
    
    /** 基准日期 */
    private LocalDate baseDate;
    
    /** 预测终止日期 */
    private LocalDate endDate;
    
    /** 时间序列预测数据 */
    private List<TrajectoryPoint> trajectory;
    
    /** 关键指标预测汇总 */
    private MetricSummary metricSummary;
    
    /** 预测置信区间 */
    private ConfidenceBand confidenceBand;
    
    /** 季节性模式检测结果 */
    private SeasonalPattern seasonalPattern;
    
    /** 优化建议（多目标优化场景） */
    private List<OptimizationSuggestion> suggestions;
    
    /** 对比分析结果（同伴对比场景） */
    private PeerComparisonResult peerComparison;
    
    /** 风险预警 */
    private List<RiskAlert> riskAlerts;
}

/**
 * 轨迹点 - 某一时间步的预测状态
 */
@Data
public class TrajectoryPoint {
    /** 预测日期 */
    private LocalDate date;
    
    /** 距基准日的天数 */
    private Integer dayOffset;
    
    /** 各学科预测掌握度 */
    private Map<String, SubjectPrediction> subjectPredictions;
    
    /** 总体预测指标 */
    private OverallMetrics overall;
}

@Data
public class SubjectPrediction {
    /** 学科编码 */
    private String subjectCode;
    
    /** 预测掌握度 [0, 1] */
    private Double mastery;
    
    /** 预测分数（如有考试） */
    private Double predictedScore;
    
    /** 置信区间下限 */
    private Double confidenceLower;
    
    /** 置信区间上限 */
    private Double confidenceUpper;
    
    /** 各知识维度掌握度 */
    private Map<String, Double> dimensionMastery;
}

@Data
public class OverallMetrics {
    /** 综合学业指数（加权平均掌握度） */
    private Double academicIndex;
    
    /** 学习效率指数 */
    private Double efficiencyIndex;
    
    /** 预估年级排名百分位 */
    private Double rankPercentile;
    
    /** 学习负荷评分 [0, 1]，1 表示过载 */
    private Double loadIndex;
}
```

### 2.3 缓存策略

| 缓存层 | Key 格式 | TTL | 说明 |
|--------|----------|-----|------|
| 最新快照 | `atlas:snapshot:latest:{studentId}` | 24h | 最新一次快照数据 |
| 推演结果 | `atlas:sim:result:{simId}` | 7d | 完整推演结果 |
| 标准预测 | `atlas:forecast:std:{studentId}:{endDate}` | 6h | 标准趋势预测（按当前轨迹） |
| 季节模式 | `atlas:seasonal:{patternKey}` | 7d | 季节性模式数据 |
| 群体统计 | `atlas:peer:stats:{cohortKey}:{semesterId}` | 12h | 群体轨迹统计 |
| 推演锁 | `atlas:lock:sim:{studentId}` | 5min | 防止并发推演 |

### 4.2 时间序列预测模型

采用 **STL分解 + ARIMA + 指数平滑** 组合模型，兼顾趋势性、季节性和随机性。

#### 4.2.1 模型架构

```python
# 推演模型核心逻辑（伪代码 / 参考实现）

import numpy as np
import pandas as pd
from statsmodels.tsa.seasonal import STL
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.holtwinters import ExponentialSmoothing

class TrajectoryForecaster:
    """
    学业轨迹时间序列预测器
    输入：历史快照序列 + 未来事件日历
    输出：未来N天的掌握度/成绩预测
    """
    
    def __init__(self, config: ForecastConfig):
        self.config = config
        self.min_history_days = 30
        self.max_forecast_days = 365
        self.confidence_level = 0.90
    
    def forecast(self, snapshots: List[TrajectorySnapshot],
                 event_calendar: EventCalendar,
                 param_overrides: dict = None) -> ForecastResult:
        """
        主预测入口
        """
        # 1. 数据预处理：将快照转为等间隔时间序列
        ts_data = self._build_time_series(snapshots)
        
        if len(ts_data) < self.min_history_days:
            raise InsufficientDataError(
                f"历史数据不足，至少需要{self.min_history_days}天，当前{len(ts_data)}天"
            )
        
        # 2. STL分解：趋势 + 季节 + 残差
        stl = STL(ts_data['mastery'], period=7, robust=True)  # 周周期
        decomposed = stl.fit()
        
        trend_component = decomposed.trend
        seasonal_component = decomposed.seasonal
        residual_component = decomposed.resid
        
        # 3. 趋势预测：ARIMA
        # 自动选择(p,d,q)参数
        trend_model = self._auto_fit_arima(trend_component.dropna())
        trend_forecast = trend_model.forecast(steps=self.config.horizon_days)
        
        # 4. 季节性预测：根据历史季节模式 + 事件调整
        seasonal_forecast = self._forecast_seasonal(
            seasonal_component, 
            event_calendar,
            self.config.horizon_days
        )
        
        # 5. 应用参数覆盖（What-If场景）
        if param_overrides:
            adjustment_factor = self._compute_override_impact(
                ts_data, param_overrides, event_calendar
            )
            trend_forecast *= adjustment_factor
        
        # 6. 合成预测
        combined_forecast = trend_forecast + seasonal_forecast[:len(trend_forecast)]
        combined_forecast = np.clip(combined_forecast, 0, 1)  # 掌握度限制在[0,1]
        
        # 7. 计算置信区间
        residual_std = np.std(residual_component)
        lower_bound, upper_bound = self._compute_confidence_band(
            combined_forecast, residual_std, self.config.horizon_days
        )
        
        return ForecastResult(
            predicted=combined_forecast,
            lower_bound=lower_bound,
            upper_bound=upper_bound,
            trend=trend_forecast,
            seasonal=seasonal_forecast[:len(trend_forecast)],
            confidence_level=self.confidence_level
        )
    
    def _build_time_series(self, snapshots: List[TrajectorySnapshot]) -> pd.DataFrame:
        """将快照序列转换为等间隔时间序列"""
        records = []
        for snap in snapshots:
            mastery = json.loads(snap.mastery_summary)
            records.append({
                'date': snap.snapshot_date,
                'math_mastery': mastery.get('math', {}).get('overall', None),
                'physics_mastery': mastery.get('physics', {}).get('overall', None),
                # ... 其他学科
            })
        
        df = pd.DataFrame(records).set_index('date')
        df = df.asfreq('D')  # 转为日频
        df = df.interpolate(method='time')  # 时间插值填补缺失
        
        return df
    
    def _auto_fit_arima(self, series: pd.Series) -> ARIMA:
        """自动选择最优ARIMA参数"""
        best_aic = float('inf')
        best_model = None
        
        for p in range(0, 4):
            for d in range(0, 3):
                for q in range(0, 4):
                    try:
                        model = ARIMA(series, order=(p, d, q))
                        fitted = model.fit()
                        if fitted.aic < best_aic:
                            best_aic = fitted.aic
                            best_model = fitted
                    except:
                        continue
        
        return best_model
    
    def _forecast_seasonal(self, seasonal: pd.Series, 
                           calendar: EventCalendar,
                           horizon: int) -> np.ndarray:
        """季节性预测，结合事件日历调整"""
        # 基于历史季节模式外推
        last_period = seasonal.values[-7:]  # 最近一个周期
        seasonal_forecast = np.tile(last_period, horizon // 7 + 1)[:horizon]
        
        # 事件调整
        for event in calendar.get_events_in_range(horizon):
            if event.type == 'EXAM':
                # 考前冲刺效应
                for i in range(event.days_before, 0, -1):
                    idx = event.start_offset - i
                    if 0 <= idx < horizon:
                        seasonal_forecast[idx] *= (1 + 0.02 * (event.days_before - i) / event.days_before)
            
            elif event.type == 'HOLIDAY':
                # 假期滑坡效应
                for i in range(event.duration_days):
                    idx = event.start_offset + i
                    if 0 <= idx < horizon:
                        decay = 1 - 0.003 * i  # 每天衰减0.3%
                        seasonal_forecast[idx] *= decay
        
        return seasonal_forecast
    
    def _compute_override_impact(self, ts_data: pd.DataFrame,
                                  overrides: dict,
                                  calendar: EventCalendar) -> np.ndarray:
        """
        计算参数变更对学业轨迹的影响因子
        基于历史弹性分析：学习时间变化 → 掌握度变化的传递系数
        """
        # 估算弹性系数（历史数据中学习时间→掌握度的关系）
        elasticity = self._estimate_elasticity(ts_data)
        
        # 生成调整因子序列
        horizon = self.config.horizon_days
        factor = np.ones(horizon)
        
        if 'dailyStudyTime' in overrides:
            for subject, new_time in overrides['dailyStudyTime'].items():
                old_time = ts_data[f'{subject}_daily_minutes'].mean()
                delta_ratio = (new_time - old_time) / old_time
                
                # 弹性影响：时间增加10% → 掌握度提升 elasticity * 10%
                # 但有递减效应（边际效用递减）
                subject_elasticity = elasticity.get(subject, 0.15)
                diminishing_factor = 1 / (1 + abs(delta_ratio) * 2)  # 递减
                
                raw_impact = subject_elasticity * delta_ratio * diminishing_factor
                
                # 影响随时间累积（学习是渐进过程）
                for t in range(horizon):
                    cumulative = 1 - np.exp(-t / 30)  # 30天时间常数
                    factor[t] += raw_impact * cumulative
        
        if 'newActivities' in overrides:
            for activity in overrides['newActivities']:
                # 新增活动的预估影响
                impact_per_week = self._estimate_activity_impact(activity)
                for t in range(horizon):
                    cumulative = 1 - np.exp(-t / 14)  # 14天见效
                    factor[t] += impact_per_week * cumulative
        
        return factor
    
    def _estimate_elasticity(self, ts_data: pd.DataFrame) -> dict:
        """估算各学科学习时间→掌握度的弹性系数"""
        elasticity = {}
        for subject in ['math', 'physics', 'chinese', 'english']:
            time_col = f'{subject}_daily_minutes'
            mastery_col = f'{subject}_mastery'
            
            if time_col in ts_data and mastery_col in ts_data:
                # 简单的回归估算
                valid = ts_data[[time_col, mastery_col]].dropna()
                if len(valid) > 10:
                    # 对数回归：ln(mastery) = a + b * ln(time)
                    log_time = np.log(valid[time_col].clip(lower=1))
                    log_mastery = np.log(valid[mastery_col].clip(lower=0.01))
                    slope = np.polyfit(log_time, log_mastery, 1)[0]
                    elasticity[subject] = np.clip(slope, 0.05, 0.40)
        
        return elasticity
    
    def _compute_confidence_band(self, forecast: np.ndarray,
                                  residual_std: float,
                                  horizon: int) -> tuple:
        """计算置信区间，随预测距离加宽"""
        lower = np.zeros(horizon)
        upper = np.zeros(horizon)
        
        for t in range(horizon):
            # 置信区间随时间扩大
            widening = residual_std * np.sqrt(1 + t * 0.05)
            z_score = 1.645  # 90%置信
            
            lower[t] = max(0, forecast[t] - z_score * widening)
            upper[t] = min(1, forecast[t] + z_score * widening)
        
        return lower, upper
```

### 4.3 多目标优化器

采用 **NSGA-II**（Non-dominated Sorting Genetic Algorithm II）算法。

#### 4.3.1 优化问题建模

```
决策变量：
  x = (t_math, t_physics, t_chinese, t_english, t_break, activities...)
  其中 t_i 为每日各学科学习时间（分钟），满足 sum(t_i) + t_break ≤ T_max

目标函数：
  f1(x) = maximize_math_score(x)        → 预测数学成绩
  f2(x) = maximize_physics_score(x)     → 预测物理成绩
  f3(x) = maintain_chinese_score(x)     → 维持语文成绩在目标区间
  f4(x) = minimize_overload(x)          → 最小化学习负荷

约束：
  sum(t_i) ≤ T_max (每日总学习时间上限)
  t_i ≥ t_min_i (各学科最低学习时间)
  t_i ≤ t_max_i (各学科最高学习时间)
  exam readiness constraints (考前重点覆盖)
```

#### 4.3.2 核心实现

```java
/**
 * 多目标学习方案优化器 - NSGA-II 实现
 */
@Service
public class MultiObjectiveOptimizer {
    
    private static final int POPULATION_SIZE = 100;
    private static final int MAX_GENERATIONS = 200;
    private static final double MUTATION_RATE = 0.1;
    private static final double CROSSOVER_RATE = 0.9;
    
    /**
     * 执行多目标优化
     */
    public ParetoSolution optimize(OptimizationRequest request) {
        // 1. 初始化种群
        List<Solution> population = initializePopulation(request);
        
        // 2. 快速非支配排序
        rankPopulation(population);
        
        // 3. 计算拥挤度
        computeCrowdingDistance(population);
        
        // 4. 进化循环
        for (int gen = 0; gen < MAX_GENERATIONS; gen++) {
            // 选择
            List<Solution> offspring = tournamentSelect(population);
            
            // 交叉
            crossover(offspring, request);
            
            // 变异
            mutate(offspring, request);
            
            // 评估目标值
            evaluateObjectives(offspring, request);
            
            // 合并父子种群
            List<Solution> combined = new ArrayList<>();
            combined.addAll(population);
            combined.addAll(offspring);
            
            // 环境选择（精英保留）
            population = environmentalSelection(combined, POPULATION_SIZE);
            
            // 检查收敛
            if (hasConverged(population, gen)) {
                break;
            }
        }
        
        // 5. 提取帕累托前沿
        List<Solution> paretoFront = getFirstFront(population);
        
        // 6. 聚类缩减到指定数量
        List<Solution> selected = clusterReduce(paretoFront, request.getParetoFrontSize());
        
        return buildResult(selected, request);
    }
    
    /**
     * 评估单个解的目标值
     */
    private void evaluateObjectives(List<Solution> solutions, OptimizationRequest request) {
        for (Solution sol : solutions) {
            // 将决策变量转为推演参数
            ForecastConfig config = translateToForecastConfig(sol, request);
            
            // 调用预测模型评估
            ForecastResult result = forecaster.forecast(
                request.getBaseSnapshots(),
                request.getEventCalendar(),
                config.getParameterOverrides()
            );
            
            // 计算各目标值
            sol.setObjectiveValue("math_score", result.getPredictedScore("math"));
            sol.setObjectiveValue("physics_score", result.getPredictedScore("physics"));
            sol.setObjectiveValue("chinese_score", result.getPredictedScore("chinese"));
            sol.setObjectiveValue("load_index", result.getLoadIndex());
        }
    }
    
    /**
     * 初始化种群 - 在可行域内均匀采样
     */
    private List<Solution> initializePopulation(OptimizationRequest request) {
        List<Solution> population = new ArrayList<>();
        Constraints constraints = request.getConstraints();
        
        for (int i = 0; i < POPULATION_SIZE; i++) {
            Solution sol = new Solution();
            
            // 在约束范围内随机分配各学科时间
            int remaining = constraints.getMaxDailyStudyMinutes();
            List<String> subjects = request.getSubjects();
            
            // 均匀分布 + 随机扰动
            int baseTime = remaining / subjects.size();
            for (String subject : subjects) {
                int minTime = constraints.getMinTime(subject);
                int maxTime = constraints.getMaxTime(subject);
                int time = minTime + (int)(Math.random() * (Math.min(maxTime, baseTime * 2) - minTime));
                sol.setDecisionVariable(subject + "_time", time);
                remaining -= time;
            }
            
            // 余量分配
            distributeRemaining(sol, remaining, subjects);
            
            population.add(sol);
        }
        
        return population;
    }
}

            }
```
```java
        }

                                           examPatterns, termPatterns);
    }

/**
```
```java
 * 推演任务执行器

@Service
@Slf4j
public class SimulationExecutor {
    
    @Autowired private TrajectoryForecaster forecaster;
    @Autowired private MultiObjectiveOptimizer optimizer;
    @Autowired private SeasonalPatternDetector seasonalDetector;
    @Autowired private PeerComparisonService peerComparisonService;
    @Autowired private SnapshotRepository snapshotRepository;
    @Autowired private SimulationTaskRepository taskRepository;
    @Autowired private ResultInterpreter interpreter;
    @Autowired private RiskAssessor riskAssessor;
    @Autowired private OssService ossService;
    @Autowired private RedisTemplate<String, String> redisTemplate;
    
    private static final int MAX_CONCURRENT_SIMULATIONS = 10;
    private final Semaphore semaphore = new Semaphore(MAX_CONCURRENT_SIMULATIONS);
    
    /**
     * 执行推演任务
     */
    @Async("atlasExecutor")
    public void execute(SimulationTask task) {
        long startTime = System.currentTimeMillis();
        
        try {
            // 获取并发许可
            if (!semaphore.tryAcquire(5, TimeUnit.SECONDS)) {
                task.setStatus(SimulationStatus.PENDING); // 回到队列
                taskRepository.save(task);
                return;
            }
            
            task.setStatus(SimulationStatus.RUNNING);
            taskRepository.save(task);
            
            // 加载基准数据
            Long studentId = task.getStudentId();
            List<TrajectorySnapshot> history = snapshotRepository
                .findByStudentIdOrderByDate(studentId);
            
            if (history.size() < 4) { // 至少需要4个快照（约一个月）
                throw new InsufficientDataException(
                    String.format("历史快照不足，需要至少4个，当前%d个", history.size())
                );
            }
            
            SimulationConfig config = JsonUtils.fromJson(task.getConfig(), SimulationConfig.class);
            
            SimulationResult result;
            
            // 按类型分发
            switch (task.getType()) {
                case STANDARD_FORECAST:
                    result = executeStandardForecast(studentId, history, config);
                    break;
                    
                case WHAT_IF:
                    result = executeWhatIf(studentId, history, config);
                    break;
                    
                case MULTI_OBJECTIVE:
                    result = executeMultiObjective(studentId, history, config);
                    break;
                    
                case PEER_COMPARISON:
                    result = executePeerComparison(studentId, history, config);
                    break;
                    
                case SEASONAL_ANALYSIS:
                    result = executeSeasonalAnalysis(studentId, history);
                    break;
                    
                default:
                    throw new IllegalArgumentException("未知推演类型: " + task.getType());
            }
            
            // 风险评估
            List<RiskAlert> risks = riskAssessor.assess(result, history);
            result.setRiskAlerts(risks);
            
            // 生成自然语言解读
            String interpretation = interpreter.generateInterpretation(result, task.getType());
            result.setInterpretation(interpretation);
            
            // 持久化结果
            String resultJson = JsonUtils.toJson(result);
            String ossKey;
            if (resultJson.length() > 50000) {
                // 大结果存OSS
                ossKey = ossService.upload(
                    "atlas/results/" + studentId + "/" + task.getId() + ".json",
                    resultJson
                );
                task.setResultRef(ossKey);
            } else {
                task.setResultRef("inline:" + resultJson);
            }
            
            task.setStatus(SimulationStatus.COMPLETED);
            task.setCompletedAt(LocalDateTime.now());
            task.setComputeTimeMs(System.currentTimeMillis() - startTime);
            taskRepository.save(task);
            
            // 缓存
            redisTemplate.opsForValue().set(
                "atlas:sim:result:" + task.getId(),
                resultJson.length() > 50000 ? resultJson.substring(0, 50000) : resultJson,
                Duration.ofDays(7)
            );
            
            // 发送完成通知
            eventPublisher.publishEvent(new SimulationCompletedEvent(task));
            
        } catch (InsufficientDataException e) {
            log.warn("推演数据不足: taskId={}, studentId={}", task.getId(), task.getStudentId(), e);
            task.setStatus(SimulationStatus.FAILED);
            task.setErrorMessage("DATA_INSUFFICIENT: " + e.getMessage());
            taskRepository.save(task);
            
        } catch (Exception e) {
            log.error("推演执行失败: taskId={}", task.getId(), e);
            task.setStatus(SimulationStatus.FAILED);
            task.setErrorMessage("INTERNAL_ERROR: " + e.getMessage());
            taskRepository.save(task);
            
        } finally {
            semaphore.release();
        }
    }
    
    /**
     * 标准趋势预测
     */
    private SimulationResult executeStandardForecast(
            Long studentId, 
            List<TrajectorySnapshot> history,
            SimulationConfig config) {
        
        // 获取事件日历（考试日期、假期等）
        EventCalendar calendar = eventCalendarService.getCalendar(
            studentId, 
            LocalDate.now(), 
            LocalDate.now().plusDays(config.getHorizonDays())
        );
        
        // 调用预测模型
        ForecastResult forecast = forecaster.forecast(history, calendar);
        
        // 构建轨迹点
        List<TrajectoryPoint> trajectory = buildTrajectoryFromForecast(forecast, config);
        
        // 季节性模式检测
        SeasonalPattern seasonal = seasonalDetector.detectForStudent(studentId, history);
        
        // 构建结果
        SimulationResult result = new SimulationResult();
        result.setTrajectory(trajectory);
        result.setSeasonalPattern(seasonal);
        result.setConfidenceBand(forecast.getConfidenceBand());
        
        return result;
    }
    
    /**
     * What-If 场景仿真
     */
    private SimulationResult executeWhatIf(
            Long studentId,
            List<TrajectorySnapshot> history,
            SimulationConfig config) {
        
        WhatIfConfig whatIf = config.getWhatIfConfig();
        
        // 1. 先计算基准预测（当前轨迹）
        ForecastResult baseline = forecaster.forecast(
            history, 
            eventCalendarService.getCalendar(studentId),
            null  // 无参数覆盖
        );
        
        // 2. 计算场景预测（修改参数后）
        ForecastResult scenario = forecaster.forecast(
            history,
            eventCalendarService.getCalendar(studentId),
            whatIf.getParameterOverrides()
        );
        
        // 3. 对比分析
        ComparisonResult comparison = new ComparisonResult();
        comparison.setBaseline(toSummary(baseline));
        comparison.setScenario(toSummary(scenario));
        comparison.setDelta(calculateDelta(baseline, scenario));
        comparison.setConfidenceScore(calculateConfidence(baseline, scenario, history));
        comparison.setSideEffects(analyzeSideEffects(whatIf.getParameterOverrides()));
        comparison.setInterpretation(
            interpreter.generateComparisonInterpretation(comparison)
        );
        
        SimulationResult result = new SimulationResult();
        result.setTrajectory(buildTrajectoryFromForecast(scenario, config));
        result.setComparisonResult(comparison);
        
        return result;
    }
    
    /**
     * 多目标优化
     */
    private SimulationResult executeMultiObjective(
            Long studentId,
            List<TrajectorySnapshot> history,
            SimulationConfig config) {
        
        OptimizationRequest optRequest = OptimizationRequest.from(config, history);
        
        // 调用NSGA-II优化器
        ParetoSolution pareto = optimizer.optimize(optRequest);
        
        // 为每个帕累托解生成详细推演
        List<OptimizationSuggestion> suggestions = new ArrayList<>();
        for (Solution sol : pareto.getSelectedSolutions()) {
            ForecastConfig fc = translateToForecastConfig(sol, config);
            ForecastResult forecast = forecaster.forecast(
                history, 
                eventCalendarService.getCalendar(studentId),
                fc.getParameterOverrides()
            );
            
            OptimizationSuggestion suggestion = new OptimizationSuggestion();
            suggestion.setRank(sol.getRank());
            suggestion.setDescription(sol.getDescription());
            suggestion.setDailyAllocation(sol.getDecisionVariables());
            suggestion.setProjectedOutcomes(toSummary(forecast));
            suggestions.add(suggestion);
        }
        
        // 选择推荐方案
        OptimizationSuggestion recommended = selectRecommendation(suggestions, config);
        
        SimulationResult result = new SimulationResult();
        result.setSuggestions(suggestions);
        result.setRecommendation(recommended);
        
        return result;
    }
}
```

```java
/**
 * 推演结果风险评估器
 */
@Service
public class RiskAssessor {
    
    @Autowired private SeasonalPatternRepository seasonalRepo;
    
    private static final double HIGH_RISK_THRESHOLD = 0.7;
    private static final double MEDIUM_RISK_THRESHOLD = 0.4;
    
    /**
     * 基于推演结果评估风险
     */
    public List<RiskAlert> assess(SimulationResult result, List<TrajectorySnapshot> history) {
        List<RiskAlert> alerts = new ArrayList<>();
        
        // 1. 学科下滑风险
        alerts.addAll(detectSubjectDeclineRisk(result));
        
        // 2. 暑假/寒假滑坡风险
        alerts.addAll(detectSeasonalLossRisk(result));
        
        // 3. 学习过载风险
        alerts.addAll(detectOverloadRisk(result));
        
        // 4. 考试准备不足风险
        alerts.addAll(detectExamReadinessRisk(result, history));
        
        // 5. 动机衰退风险
        alerts.addAll(detectMotivationDeclineRisk(result));
        
        // 按严重程度排序
        alerts.sort(Comparator.comparing(RiskAlert::getSeverity).reversed());
        
        return alerts;
    }
    
    private List<RiskAlert> detectSubjectDeclineRisk(SimulationResult result) {
        List<RiskAlert> alerts = new ArrayList<>();
        
        TrajectoryPoint start = result.getTrajectory().get(0);
        TrajectoryPoint end = result.getTrajectory().get(result.getTrajectory().size() - 1);
        
        for (Map.Entry<String, SubjectPrediction> entry : start.getSubjectPredictions().entrySet()) {
            String subject = entry.getKey();
            double startMastery = entry.getValue().getMastery();
            double endMastery = end.getSubjectPredictions().get(subject).getMastery();
            double change = endMastery - startMastery;
            
            if (change < -0.05) {  // 下降超过5%
                RiskAlert alert = new RiskAlert();
                alert.setLevel(change < -0.10 ? "HIGH" : "MEDIUM");
                alert.setType("SUBJECT_DECLINE");
                alert.setSubject(subject);
                alert.setDescription(String.format(
                    "%s学科掌握度预计下降%.0f%%（从%.0f%%降至%.0f%%）",
                    subjectToChinese(subject), 
                    Math.abs(change * 100),
                    startMastery * 100, 
                    endMastery * 100
                ));
                alert.setSuggestion(String.format(
                    "建议增加%s学科学习时间，重点关注薄弱知识维度",
                    subjectToChinese(subject)
                ));
                alert.setSeverity(Math.abs(change));
                alerts.add(alert);
            }
        }
        
        return alerts;
    }
    
    private List<RiskAlert> detectSeasonalLossRisk(SimulationResult result) {
        List<RiskAlert> alerts = new ArrayList<>();
        
        if (result.getSeasonalPattern() == null) return alerts;
        
        for (SeasonalPatternInfo pattern : result.getSeasonalPattern().getDetectedPatterns()) {
            if ("SUMMER_LOSS".equals(pattern.getType()) || "HOLIDAY_DECLINE".equals(pattern.getType())) {
                RiskAlert alert = new RiskAlert();
                alert.setLevel("MEDIUM");
                alert.setType(pattern.getType());
                alert.setDescription(pattern.getDescription());
                alert.setSuggestion("建议假期期间保持每周2-3次复习，重点巩固错题和高频考点");
                alert.setSeverity(pattern.getAvgImpact());
                alerts.add(alert);
            }
        }
        
        return alerts;
    }
    
    private List<RiskAlert> detectOverloadRisk(SimulationResult result) {
        List<RiskAlert> alerts = new ArrayList<>();
        
        // 检查预测期间负荷指数是否超过阈值
        for (TrajectoryPoint point : result.getTrajectory()) {
            double load = point.getOverall().getLoadIndex();
            if (load > HIGH_RISK_THRESHOLD) {
                RiskAlert alert = new RiskAlert();
                alert.setLevel("HIGH");
                alert.setType("COGNITIVE_OVERLOAD");
                alert.setDescription(String.format(
                    "预测在%s前后学习负荷指数达到%.0f%%，存在过载风险",
                    point.getDate(), load * 100
                ));
                alert.setSuggestion("建议适当减少单日学习任务量，增加休息和运动时间");
                alert.setSeverity(load);
                alerts.add(alert);
                break;  // 只报一次
            }
        }
        
        return alerts;
    }
```

```java
public class SimulationFallbackHandler {
    
    /**
     * 根据异常类型选择降级策略
     */
    public SimulationResult handleFallback(SimulationTask task, Exception ex) {
        if (ex instanceof ForecastTimeoutException) {
            // 降级1：简单线性回归外推
            log.warn("预测超时，降级为线性外推: taskId={}", task.getId());
            return linearExtrapolation(task);
        }
        
        if (ex instanceof ModelLoadException) {
            // 降级2：使用缓存的最近一次预测
            log.warn("模型加载失败，使用缓存预测: taskId={}", task.getId());
            return useCachedForecast(task);
        }
        
        if (ex instanceof NoFeasibleSolutionException) {
            // 降级3：放松约束后重试
            log.warn("无可行解，放松约束重试: taskId={}", task.getId());
            return relaxAndRetry(task);
        }
        
        // 其他异常：返回兜底结果
        return buildMinimalResult(task, ex);
    }
    
    /**
     * 线性外推降级
     */
    private SimulationResult linearExtrapolation(SimulationTask task) {
        // 获取最近4个快照
        List<TrajectorySnapshot> recent = snapshotRepository
            .findTop4ByStudentIdOrderByDateDesc(task.getStudentId());
        
        // 简单线性回归
        List<TrajectoryPoint> trajectory = new ArrayList<>();
        
        // 计算最近4个快照的日均变化率
        double dailyRate = computeDailyRate(recent);
        
        // 外推
        for (int t = 7; t <= task.getHorizonDays(); t += 7) {
            TrajectoryPoint point = new TrajectoryPoint();
            point.setDayOffset(t);
            point.setDate(LocalDate.now().plusDays(t));
            
            // 线性外推（截断在[0, 1]）
            double projected = getLatestMastery(recent) + dailyRate * t;
            point.setOverall(new OverallMetrics(
                Math.max(0, Math.min(1, projected)), 
                null, null, null
            ));
            trajectory.add(point);
        }
        
        SimulationResult result = new SimulationResult();
        result.setTrajectory(trajectory);
        result.setInterpretation("⚠️ 因计算超时，使用简化模型预测，精度可能较低。");
        return result;
    }
    
    /**
     * 放松约束重试
     */
    private SimulationResult relaxAndRetry(SimulationTask task) {
        SimulationConfig config = JsonUtils.fromJson(task.getConfig(), SimulationConfig.class);
        
        // 放松约束：增加20%时间预算，放宽负荷限制
        if (config.getConstraints() != null) {
            config.getConstraints().setMaxDailyStudyMinutes(
                (int)(config.getConstraints().getMaxDailyStudyMinutes() * 1.2)
            );
            config.getConstraints().setMaxLoadIndex(
                Math.min(0.85, config.getConstraints().getMaxLoadIndex() + 0.1)
            );
        }
        
        // 放松目标：降低目标值10%
        if (config.getObjectives() != null) {
            for (Objective obj : config.getObjectives()) {
                if (obj.getTarget() != null && "MAXIMIZE".equals(obj.getType())) {
                    obj.setTarget(obj.getTarget() * 0.9);
                }
            }
        }
        
        task.setConfig(JsonUtils.toJson(config));
        return simulationExecutor.executeOptimization(task);
    }
}
```

```java
@Component
public class SimulationRateLimiter {
    
    @Autowired private RedisTemplate<String, String> redisTemplate;
    
    private static final Map<SimulationType, String> LIMIT_KEY_MAP = Map.of(
        SimulationType.STANDARD_FORECAST, "atlas:rl:forecast",
        SimulationType.WHAT_IF, "atlas:rl:whatif",
        SimulationType.MULTI_OBJECTIVE, "atlas:rl:optimize"
    );

        String key = LIMIT_KEY_MAP.get(type) + ":" + studentId + ":" + LocalDate.now();
        
        RateLimitConfig config = getLimitConfig(type, level);
        if (config == null) {
            throw new QuotaExceededException("当前会员等级不支持此功能");
        }
        
        Long current = redisTemplate.opsForValue().increment(key);
        if (current == 1) {
            redisTemplate.expire(key, config.getPeriodSeconds(), TimeUnit.SECONDS);
        }
        
        if (current > config.getMaxCount()) {
            throw new QuotaExceededException(
                String.format("今日%s次数已达上限（%d次/%s）",
                    typeToChinese(type), config.getMaxCount(), config.getPeriodDesc())
            );
        }
        
        return true;
    }
}
```

```java
            .currentPosition(locateStudent(raw))

            "P75", percentile(data, 0.75),
```
