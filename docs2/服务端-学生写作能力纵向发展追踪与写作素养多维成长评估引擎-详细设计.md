# 服务端 - 学生写作能力纵向发展追踪与写作素养多维成长评估引擎

> **文档版本**：v1.0  
> **创建日期**：2026-08-05  
> **模块定位**：服务端 · 写作能力评估 · 纵向发展追踪  
> **依赖模块**：作文批改评分引擎、学生画像特征工程平台、学习数据仓库、统一指标中心

---

## 1. 模块概述

### 1.1 功能定位

本引擎负责**跨时间、跨年级、跨文体**地追踪学生写作能力的纵向发展轨迹，对写作素养进行多维度量化评估，生成写作成长报告，并输出个性化的写作发展建议。

与现有写作模块的分工：

| 现有模块 | 关注维度 | 本模块差异 |
| --- | --- | --- |
| 作文批改评分引擎 | 单篇作文评分 | 聚合多篇评分，追踪趋势变化 |
| 写作技法识别与修辞手法分析 | 单篇技法标注 | 纵向追踪技法使用频率与质量演变 |
| 写作过程行为分析 | 单次写作过程行为 | 不涉及写作过程，关注成品质量成长 |
| 写作思维启发与创作辅助 | 单次创作引导 | 关注长期发展建议而非即时辅助 |
| 学习成长曲线建模 | 通用学科能力 | 写作维度特有的指标体系与分析方法 |

### 1.2 核心目标

1. **建立写作素养多维指标体系**：覆盖词汇丰富度、句式复杂度、结构逻辑性、论据充分性、创意表达力、语言规范性六大维度
2. **纵向追踪写作成长轨迹**：按月/学期/学年维度聚合写作表现，识别进步/停滞/退步趋势
3. **同龄基准对比**：与同年级、同学段学生群体写作水平进行基准参照
4. **写作发展预测**：基于历史趋势预测未来写作水平发展
5. **个性化发展建议**：识别写作短板，生成长期写作提升路径

### 1.3 适用范围

| 适用学段 | 小学三年级 ~ 高中三年级 |
| --- | --- |
| 适用文体 | 记叙文、议论文、说明文、应用文、散文 |
| 数据来源 | 平台内作文批改记录、考试作文成绩、教师评分 |
| 触发方式 | 定时批量计算 + 新作文提交后增量更新 + 手动查询 |

## 2. 数据结构定义

### 2.1 写作能力维度模型

定义写作能力的六大核心维度，每个维度包含若干子指标：

```typescript
enum WritingDimension {
  VOCABULARY_RICHNESS   = 'vocabulary_richness',   // 词汇丰富度
  SYNTACTIC_COMPLEXITY  = 'syntactic_complexity',   // 句式复杂度
  STRUCTURAL_LOGIC      = 'structural_logic',       // 结构逻辑性
  ARGUMENT_SUFFICIENCY  = 'argument_sufficiency',   // 论据充分性
  CREATIVE_EXPRESSION   = 'creative_expression',    // 创意表达力
  LANGUAGE_ACCURACY     = 'language_accuracy',      // 语言规范性
}

interface DimensionDefinition {
  dimension: WritingDimension;
  dimensionName: string;
  subMetrics: SubMetric[];
  applicableGenres: string[];     // 适用文体
  gradeRange: [number, number];   // 适用年级范围 [起始年级, 结束年级]
  maxScore: number;               // 单维度满分
}

interface SubMetric {
  code: string;
  name: string;
  description: string;
  extractionSource: 'auto' | 'ai' | 'teacher';  // 数据提取来源
  weight: number;      // 在维度内的权重 (0~1)
}
```

**维度子指标明细：**

| 维度 | 子指标代码 | 子指标名称 | 提取来源 |
| --- | --- | --- | --- |
| 词汇丰富度 | `vocab_size` | 词汇总量 | auto |
| 词汇丰富度 | `unique_word_ratio` | 不重复词汇占比 | auto |
| 词汇丰富度 | `advanced_vocab_count` | 高级词汇使用数 | auto |
| 词汇丰富度 | `idiom_usage` | 成语/惯用语使用 | ai |
| 句式复杂度 | `avg_sentence_length` | 平均句长 | auto |
| 句式复杂度 | `complex_sentence_ratio` | 复句占比 | auto |
| 句式复杂度 | `sentence_pattern_diversity` | 句式多样性指数 | auto |
| 句式复杂度 | `rhetorical_device_usage` | 修辞手法使用密度 | ai |
| 结构逻辑性 | `paragraph_coherence` | 段落连贯性 | ai |
| 结构逻辑性 | `logical_progression` | 逻辑递进性 | ai |
| 结构逻辑性 | `beginning_ending_quality` | 首尾呼应度 | ai |
| 结构逻辑性 | `transition_usage` | 过渡手法运用 | ai |
| 论据充分性 | `evidence_count` | 论据数量 | ai |
| 论据充分性 | `evidence_relevance` | 论据相关性 | ai |
| 论据充分性 | `example_diversity` | 举例多样性 | ai |
| 论据充分性 | `argument_depth` | 论证深度 | ai |
| 创意表达力 | `novelty_score` | 立意新颖度 | ai |
| 创意表达力 | `perspective_originality` | 视角独特性 | ai |
| 创意表达力 | `imagination_richness` | 想象力丰富度 | ai |
| 创意表达力 | `emotional_expressiveness` | 情感表达力 | ai |
| 语言规范性 | `error_count` | 病句数量 | auto |
| 语言规范性 | `typo_count` | 错别字数量 | auto |
| 语言规范性 | `punctuation_accuracy` | 标点准确率 | auto |
| 语言规范性 | `formatting_compliance` | 格式规范度 | ai |

### 2.2 数据库表设计

#### 2.2.1 `writing_ability_snapshot` - 写作能力快照表

每次作文批改完成后生成的多维能力快照。

```sql
CREATE TABLE writing_ability_snapshot (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    snapshot_id     VARCHAR(36) NOT NULL COMMENT '快照唯一ID (UUID)',
    student_id      BIGINT NOT NULL COMMENT '学生ID',
    essay_id        BIGINT NOT NULL COMMENT '关联作文ID',
    genre           VARCHAR(32) NOT NULL COMMENT '文体: narrative/argumentative/expository/practical/prose',
    grade_level     INT NOT NULL COMMENT '提交时学生年级: 1~12',
    submit_time     DATETIME NOT NULL COMMENT '作文提交时间',
    
    -- 六大维度得分 (0~100)
    vocab_richness_score       DECIMAL(5,2) NOT NULL COMMENT '词汇丰富度得分',
    syntactic_complexity_score DECIMAL(5,2) NOT NULL COMMENT '句式复杂度得分',
    structural_logic_score     DECIMAL(5,2) NOT NULL COMMENT '结构逻辑性得分',
    argument_sufficiency_score DECIMAL(5,2) NOT NULL COMMENT '论据充分性得分',
    creative_expression_score  DECIMAL(5,2) NOT NULL COMMENT '创意表达力得分',
    language_accuracy_score    DECIMAL(5,2) NOT NULL COMMENT '语言规范性得分',
    
    -- 总分
    overall_score   DECIMAL(5,2) NOT NULL COMMENT '写作综合得分 (加权)',
    
    -- 子指标明细 (JSON)
    sub_metrics_detail JSON NOT NULL COMMENT '子指标原始值明细',
    
    -- 元数据
    word_count      INT NOT NULL COMMENT '作文字数',
    ai_model_version VARCHAR(64) COMMENT '评分使用的AI模型版本',
    teacher_score   DECIMAL(5,2) COMMENT '教师评分(如有)',
    
    -- 状态
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '1=有效 0=已废弃',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_snapshot_id (snapshot_id),
    INDEX idx_student_time (student_id, submit_time),
    INDEX idx_student_genre (student_id, genre, submit_time),
    INDEX idx_grade_level (grade_level, submit_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作能力快照表';
```

#### 2.2.2 `writing_growth_trajectory` - 写作成长轨迹表

按月聚合的学生写作成长轨迹，每月一条记录。

```sql
CREATE TABLE writing_growth_trajectory (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    trajectory_id       VARCHAR(36) NOT NULL COMMENT '轨迹记录ID',
    student_id          BIGINT NOT NULL COMMENT '学生ID',
    period_type         VARCHAR(16) NOT NULL COMMENT '聚合周期: monthly/termly/yearly',
    period_start        DATE NOT NULL COMMENT '周期起始日期',
    period_end          DATE NOT NULL COMMENT '周期结束日期',
    grade_level         INT NOT NULL COMMENT '周期内主要年级',
    
    -- 周期内聚合数据
    essay_count         INT NOT NULL COMMENT '周期内作文数量',
    valid_essay_count   INT NOT NULL COMMENT '有效作文数量(排除异常)',
    genre_distribution  JSON NOT NULL COMMENT '文体分布 {"narrative": 3, "argumentative": 2}',
    
    -- 六维度周期均值
    avg_vocab_richness       DECIMAL(5,2) COMMENT '词汇丰富度均值',
    avg_syntactic_complexity DECIMAL(5,2) COMMENT '句式复杂度均值',
    avg_structural_logic     DECIMAL(5,2) COMMENT '结构逻辑性均值',
    avg_argument_sufficiency DECIMAL(5,2) COMMENT '论据充分性均值',
    avg_creative_expression  DECIMAL(5,2) COMMENT '创意表达力均值',
    avg_language_accuracy    DECIMAL(5,2) COMMENT '语言规范性均值',
    avg_overall              DECIMAL(5,2) COMMENT '综合得分均值',
    
    -- 趋势数据
    trend_direction    VARCHAR(8) COMMENT '趋势方向: up/flat/down',
    trend_change_rate  DECIMAL(5,2) COMMENT '环比变化率 (%)',
    consecutive_up_count INT DEFAULT 0 COMMENT '连续进步次数',
    consecutive_down_count INT DEFAULT 0 COMMENT '连续退步次数',
    
    -- 对比数据
    grade_percentile   DECIMAL(5,2) COMMENT '年级百分位',
    improvement_rank   INT COMMENT '进步排名(年级内)',
    
    -- AI洞察
    ai_insight         TEXT COMMENT 'AI生成的发展洞察摘要',
    bottleneck_dimension VARCHAR(32) COMMENT '瓶颈维度',
    
    created_at         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_trajectory (student_id, period_type, period_start),
    INDEX idx_period_grade (period_start, grade_level),
    INDEX idx_student_periods (student_id, period_type, period_start)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='写作成长轨迹表';
```

### 2.3 Redis 缓存结构

```
# 学生写作能力最新快照（写入后缓存，TTL 24h）
WRITING_SNAPSHOT:LASTEST:{student_id} → JSON

# 学生写作成长轨迹列表（TTL 6h）
WRITING_TRAJECTORY:{student_id}:{period_type} → JSON List

# 年级基准数据（TTL 7d，基准计算后缓存）
WRITING_BENCHMARK:{grade_level}:{genre}:{period} → JSON

# 学生写作能力雷达图数据（TTL 12h）
WRITING_RADAR:{student_id} → JSON

# 写作能力趋势预测缓存（TTL 24h）
WRITING_PREDICTION:{student_id} → JSON

# 分布式锁：月度轨迹计算
LOCK:WRITING_TRAJECTORY_COMPUTE:{student_id}:{period} → string (NX, TTL 300s)
```

```python
        },
        "narrative": {
            "vocabulary_richness": 0.15,
            "syntactic_complexity": 0.20,

            "argument_sufficiency": 0.10,
            "creative_expression": 0.20,
            "language_accuracy": 0.15,
        },
        "prose": {
            "vocabulary_richness": 0.20,
            "syntactic_complexity": 0.20,
            "structural_logic": 0.15,
            "argument_sufficiency": 0.05,
            "creative_expression": 0.30,
            "language_accuracy": 0.10,
        },
    },
}


def get_stage(grade_level: int) -> str:
    if grade_level <= 6:
        return "primary"
    elif grade_level <= 9:
        return "middle"
    else:
        return "high"


def calculate_overall_score(
    dimension_scores: dict[str, float],
    genre: str,
    grade_level: int,
) -> float:
    """计算加权综合得分"""
    stage = get_stage(grade_level)
    weights = DIMENSION_WEIGHTS.get(stage, {}).get(genre)

    if weights is None:
        # 回退到默认均匀权重
        weights = {dim: 1.0 / len(dimension_scores) for dim in dimension_scores}

    overall = sum(
        dimension_scores.get(dim, 0) * weight
        for dim, weight in weights.items()
    )
    return round(overall, 2)
```

### 5.2 趋势方向与变化率计算

```python
from enum import Enum
from dataclasses import dataclass


class TrendDirection(str, Enum):
    UP = "up"
    FLAT = "flat"
    DOWN = "down"


@dataclass
class TrendResult:
    direction: TrendDirection
    change_rate: float  # 环比变化百分比 (%)
    consecutive_up: int
    consecutive_down: int


# 趋势判定阈值
TREND_THRESHOLD_UP = 2.0     # 上升超过2%判定为 up
TREND_THRESHOLD_DOWN = -2.0  # 下降超过-2%判定为 down
TREND_WINDOW_MIN_SAMPLES = 2  # 最少需要2个数据点


def calculate_trend(
    current_avg: float,
    previous_avg: float | None,
    previous_consecutive_up: int = 0,
    previous_consecutive_down: int = 0,
) -> TrendResult:
    """计算月度趋势方向与变化率"""

    if previous_avg is None:
        return TrendResult(
            direction=TrendDirection.FLAT,
            change_rate=0.0,
            consecutive_up=0,
            consecutive_down=0,
        )

    change_rate = round(
        ((current_avg - previous_avg) / previous_avg) * 100, 2
    )

    if change_rate >= TREND_THRESHOLD_UP:
        direction = TrendDirection.UP
        consecutive_up = previous_consecutive_up + 1
        consecutive_down = 0
    elif change_rate <= TREND_THRESHOLD_DOWN:
        direction = TrendDirection.DOWN
        consecutive_down = previous_consecutive_down + 1
        consecutive_up = 0
    else:
        direction = TrendDirection.FLAT
        consecutive_up = 0
        consecutive_down = 0

    return TrendResult(
        direction=direction,
        change_rate=change_rate,
        consecutive_up=consecutive_up,
        consecutive_down=consecutive_down,
    )
```

```python
) -> list[PredictionPoint]:
    """
    基于历史月度得分序列，使用线性回归 + 置信区间衰减
    预测未来写作得分
    """
    if len(historical_scores) < 3:
        # 数据不足，返回基于年级基准的保守估计
        return [
            PredictionPoint(
                target_date="insufficient_data",
                target_label="数据不足",
                projected_score=historical_scores[-1] if historical_scores else 0,
                confidence=0.3,
                assumptions="历史数据不足，需至少3个月数据",
            )
        ]

    # 将月份转为序号 (0, 1, 2, ...)
    x = np.arange(len(historical_scores))
    y = np.array(historical_scores)

    # 最小二乘线性回归
    coefficients = np.polyfit(x, y, deg=1)
    slope, intercept = coefficients

    # 计算残差标准差（用于置信度估计）
    predicted = slope * x + intercept
    residuals = y - predicted
    residual_std = np.std(residuals) if len(residuals) > 2 else 5.0

    predictions: list[PredictionPoint] = []

    for months_ahead in target_months_ahead if isinstance(target_months_ahead, list) else [target_months_ahead]:
        future_x = len(historical_scores) - 1 + months_ahead
        projected = slope * future_x + intercept

        # 得分不超边界
        projected = max(0, min(100, projected))

        # 置信度随预测距离衰减
        # 基础置信度 0.9，每个月衰减 0.05，练习频率正向修正
        freq_bonus = min(0.1, (practice_frequency_per_week - 1) * 0.05)
        confidence = max(0.3, 0.9 + freq_bonus - months_ahead * 0.05)

        # 残差越大，置信度越低
        confidence *= max(0.5, 1 - residual_std / 20)

        target_date = _add_months(historical_months[-1], months_ahead)

        predictions.append(PredictionPoint(
            target_date=target_date,
            target_label=_get_label(months_ahead),
            projected_score=round(projected, 1),
            confidence=round(confidence, 2),
            assumptions=f"维持当前练习频率（每周{practice_frequency_per_week}篇）",
        ))

    return predictions


def _add_months(month_str: str, months: int) -> str:
    """月份字符串加N个月"""
    year, m = map(int, month_str.split("-"))
    total = year * 12 + (m - 1) + months
    new_year = total // 12
    new_month = total % 12 + 1
    return f"{new_year}-{new_month:02d}"


def _get_label(months_ahead: int) -> str:
    if months_ahead <= 1:
        return "下个月"
    elif months_ahead <= 4:
        return "本学期末"
    elif months_ahead <= 10:
        return "本学年末"
    else:
        return "下学年"
```

### 5.4 百分位计算

```python
def calculate_percentile(
    student_score: float,
    benchmark_p25: float,
    benchmark_p50: float,
    benchmark_p75: float,
) -> float:
    """
    基于年级基准的P25/P50/P75插值计算学生百分位
    """
    if student_score <= benchmark_p25:
        # 在P25以下，线性映射到 0~25
        ratio = student_score / benchmark_p25 if benchmark_p25 > 0 else 0
        return round(max(0, ratio * 25), 1)

    elif student_score <= benchmark_p50:
        # 在P25~P50之间，映射到 25~50
        span = benchmark_p50 - benchmark_p25
        if span == 0:
            return 25.0
        ratio = (student_score - benchmark_p25) / span
        return round(25 + ratio * 25, 1)

    elif student_score <= benchmark_p75:
        # 在P50~P75之间，映射到 50~75
        span = benchmark_p75 - benchmark_p50
        if span == 0:
            return 50.0
        ratio = (student_score - benchmark_p50) / span
        return round(50 + ratio * 25, 1)

    else:
        # 在P75以上，映射到 75~99
        excess = student_score - benchmark_p75
        # 使用对数衰减避免无限增长
        bonus = min(24, excess * 0.8)
        return round(min(99, 75 + bonus), 1)
```

### 5.5 月度轨迹聚合（核心 Service 方法）

```java
/**
 * 写作成长轨迹计算服务
 */
@Service
@Slf4j
public class WritingTrajectoryService {

    @Autowired
    private WritingAbilitySnapshotRepository snapshotRepository;

    @Autowired
    private WritingGrowthTrajectoryRepository trajectoryRepository;

    @Autowired
    private WritingGradeBenchmarkRepository benchmarkRepository;

    @Autowired
    private RedissonClient redissonClient;

    @Autowired
    private AiInsightClient aiInsightClient;

    /**
     * 计算指定学生在指定月份的写作成长轨迹
     */
    @Async("writingTrajectoryExecutor")
    public void computeMonthlyTrajectory(Long studentId, YearMonth period) {
        String lockKey = String.format(
            "LOCK:WRITING_TRAJECTORY_COMPUTE:%d:%s",
            studentId, period.toString()
        );
        RLock lock = redissonClient.getLock(lockKey);

        if (!lock.tryLock()) {
            log.info("轨迹计算已在进行中: studentId={}, period={}", studentId, period);
            return;
        }

        try {
            // 1. 查询当月所有有效快照
            LocalDate periodStart = period.atDay(1);
            LocalDate periodEnd = period.atEndOfMonth();

            List<WritingAbilitySnapshot> snapshots = snapshotRepository
                .findValidByStudentAndPeriod(studentId, periodStart, periodEnd);

            if (snapshots.isEmpty()) {
                log.info("当月无写作数据: studentId={}, period={}", studentId, period);
                return;
            }

            // 2. 异常值过滤
            List<WritingAbilitySnapshot> validSnapshots = snapshots.stream()
                .filter(s -> s.getWordCount() >= 100)  // 排除字数过少的练习
                .sorted(Comparator.comparing(WritingAbilitySnapshot::getSubmitTime))
                .collect(Collectors.toList());

            if (validSnapshots.isEmpty()) {
                log.info("过滤后无有效数据: studentId={}, period={}", studentId, period);
                return;
            }

            // 3. 维度均值聚合
            TrajectoryAggregation agg = aggregateSnapshots(validSnapshots);

            // 4. 查询上一周期轨迹（环比计算）
            WritingGrowthTrajectory previousTrajectory = trajectoryRepository
                .findPreviousMonthly(studentId, period.minusMonths(1));

            // 5. 计算趋势
            TrendResult trend = calculateTrend(
                agg.getAvgOverall(),
                previousTrajectory != null ? previousTrajectory.getAvgOverall() : null,
                previousTrajectory != null ? previousTrajectory.getConsecutiveUpCount() : 0,
                previousTrajectory != null ? previousTrajectory.getConsecutiveDownCount() : 0
            );

            // 6. 查询年级基准计算百分位
            int gradeLevel = validSnapshots.get(0).getGradeLevel();
            String benchmarkPeriod = period.toString();

            WritingGradeBenchmark benchmark = benchmarkRepository
                .findByGradeAndPeriod(gradeLevel, benchmarkPeriod, "all");

            Double percentile = null;
            if (benchmark != null && benchmark.getSampleSize() >= 30) {
                percentile = calculatePercentile(
                    agg.getAvgOverall(),
                    benchmark.getP25Overall(),
                    benchmark.getP50Overall(),
                    benchmark.getP75Overall()
                );
            }

            // 7. AI洞察生成
            AiInsightRequest insightReq = buildInsightRequest(
                studentId, agg, trend, percentile, validSnapshots
            );
            AiInsightResponse insight = aiInsightClient.generateWritingInsight(insightReq);

            // 8. 瓶颈维度识别（得分最低的维度）
            String bottleneck = identifyBottleneckDimension(agg);

            // 9. 构建并持久化轨迹记录
            WritingGrowthTrajectory trajectory = buildTrajectory(
                studentId, period, agg, trend, percentile, insight, bottleneck
            );

            trajectoryRepository.upsertMonthly(trajectory);

            // 10. 更新缓存
            updateTrajectoryCache(studentId, trajectory);

            log.info(
                "轨迹计算完成: studentId={}, period={}, avgOverall={}, trend={}",
                studentId, period, agg.getAvgOverall(), trend.getDirection()
            );

        } finally {
            lock.unlock();
        }
    }

    /**
     * 识别瓶颈维度（得分最低的维度）
     */
    private String identifyBottleneckDimension(TrajectoryAggregation agg) {
        Map<String, Double> dimensions = new LinkedHashMap<>();
        dimensions.put("vocabulary_richness", agg.getAvgVocabRichness());
        dimensions.put("syntactic_complexity", agg.getAvgSyntacticComplexity());
        dimensions.put("structural_logic", agg.getAvgStructuralLogic());
        dimensions.put("argument_sufficiency", agg.getAvgArgumentSufficiency());
        dimensions.put("creative_expression", agg.getAvgCreativeExpression());
        dimensions.put("language_accuracy", agg.getAvgLanguageAccuracy());

        return dimensions.entrySet().stream()
            .min(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElse("argument_sufficiency");
    }

    // ... 其他私有方法省略
}
```

```java
/**
 * 月度轨迹批量计算 - 分片并行

@Component
@Slf4j
public class MonthlyTrajectoryJob {

    @Autowired
    private WritingAbilitySnapshotRepository snapshotRepository;

    @Autowired
    private WritingTrajectoryService trajectoryService;

    /**
     * 分片执行：按 studentId % shardCount 分片
     * 每片独立执行，避免单次处理量过大
     */
    @Scheduled(cron = "0 0 2 3 * ?")
    public void executeMonthlyCompute() {
        YearMonth targetPeriod = YearMonth.now().minusMonths(1);
        int shardCount = 8;
        int currentShard = ShardContext.getCurrentShard(); // 从调度框架获取

        // 查询该分片下所有有写作活动的学生
        List<Long> studentIds = snapshotRepository
            .findDistinctStudentIdsByPeriod(targetPeriod, currentShard, shardCount);

        log.info(
            "月度轨迹计算启动: period={}, shard={}/{}, studentCount={}",
            targetPeriod, currentShard, shardCount, studentIds.size()
        );

        for (Long studentId : studentIds) {
            try {
                trajectoryService.computeMonthlyTrajectory(studentId, targetPeriod);
            } catch (Exception e) {
                log.error(

                    studentId, targetPeriod, e
                );
                // 发送到死信队列，人工介入
                ErrorHandler.report(e, "monthly_trajectory", studentId, targetPeriod);
            }
        }

        log.info("月度轨迹计算完成: period={}, shard={}", targetPeriod, currentShard);
```

```java
/**
 * 写作成长报告 - 多级降级策略
 */
@Service
public class WritingGrowthReportService {

    public WritingGrowthReport generateReport(Long studentId, String term) {

        try {
            // 优先：完整报告（含AI洞察、预测、教师评语）
            return generateFullReport(studentId, term);

        } catch (AiServiceException e) {
            // 降级1：跳过AI洞察，使用规则引擎生成
            log.warn("AI洞察生成失败，降级为规则引擎: {}", e.getMessage());
            return generateReportWithRuleInsight(studentId, term);

        } catch (PredictionException e) {
            // 降级2：跳过预测，仅展示历史数据
            log.warn("趋势预测失败，跳过预测: {}", e.getMessage());
            return generateReportWithoutPrediction(studentId, term);

        } catch (BenchmarkNotFoundException e) {
            // 降级3：跳过同龄对比，仅展示个人趋势
            log.warn("基准数据不可用，跳过对比: {}", e.getMessage());
            return generateReportWithoutBenchmark(studentId, term);

        } catch (Exception e) {
            // 兜底：返回最小可用报告
            log.error("报告生成严重错误，返回最小报告: {}", e.getMessage());
            return generateMinimalReport(studentId, term);
        }
    }

    /**
     * 规则引擎兜底洞察（AI不可用时）
     */
    private String generateRuleBasedInsight(TrajectoryAggregation agg, TrendResult trend) {
        StringBuilder sb = new StringBuilder();

        // 规则1：趋势判断
        if (trend.getDirection() == TrendDirection.UP) {
            sb.append("本月写作水平稳步提升，综合得分环比增长")
              .append(trend.getChangeRate())
              .append("%。");
        } else if (trend.getDirection() == TrendDirection.DOWN) {
            sb.append("本月写作综合得分有所下降，环比降低")
              .append(Math.abs(trend.getChangeRate()))
              .append("%，建议关注。");
        } else {
            sb.append("本月写作水平保持稳定。");
        }

        // 规则2：短板维度
        String bottleneck = identifyBottleneckDimension(agg);
        sb.append("当前写作短板维度为「")
          .append(DIMENSION_NAMES.get(bottleneck))
          .append("」，建议针对性加强练习。");

        // 规则3：优势维度
        String strongest = identifyStrongestDimension(agg);
        sb.append("优势维度为「")
          .append(DIMENSION_NAMES.get(strongest))
          .append("」，继续保持。");

        return sb.toString();
    }
```

## 13. 部署与配置

### 13.1 服务配置

```yaml
# application.yml
writing:
  ability:
    # 快照配置
    snapshot:
      min-word-count: 100        # 最小有效字数
      max-snapshots-per-student: 500  # 单学生最大快照保留数

    # 轨迹配置
    trajectory:
      monthly-compute-day: 3      # 月度计算日
      shard-count: 8              # 并行分片数
      async-pool-size: 16         # 异步线程池大小

    # 基准配置
    benchmark:
      min-sample-size: 30         # 最小样本量
      compute-schedule: "0 0 3 ? * SUN"  # 每周日3点

    # 预测配置
    prediction:
      min-history-months: 3       # 最少历史月份
      max-prediction-months: 12   # 最远预测月份
      confidence-floor: 0.3       # 置信度下限

    # 预警配置
    alert:
      soft-alert-months: 2        # 连续低于P25的月数触发软预警
      hard-alert-months: 3        # 触发硬预警
      critical-alert-months: 6    # 触发严重预警
      max-alerts-per-month: 2     # 每月每维度最大预警次数

    # AI洞察配置
    ai-insight:
      model: "gpt-4-edu-v2.3"
      max-tokens: 500
      timeout-ms: 10000
      fallback-to-rule: true      # 失败时降级为规则引擎
```
