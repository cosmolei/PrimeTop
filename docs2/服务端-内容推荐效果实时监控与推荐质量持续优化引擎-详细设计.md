# 服务端-内容推荐效果实时监控与推荐质量持续优化引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 教育平台推荐系统的**质量保障核心**，负责对平台所有推荐场景（首页卡片、练习题目、学习路径、知识点关联等）的推荐效果进行实时监控、归因分析与策略参数自动调优，形成"推荐→曝光→消费→学习成效→反馈→调优"的完整闭环。

### 1.2 设计目标

| 目标 | 描述 |
| --- | --- |
| 实时可观测 | 推荐上线后 5 分钟内可见效果指标，支持分钟级粒度监控 |
| 归因可解释 | 当推荐效果下降时，自动定位原因（候选集质量、排序权重、冷启动、疲劳等） |
| 闭环自优化 | 基于学习成效反馈，自动调整推荐策略参数，无需人工干预 |
| 实验驱动 | 所有参数调整通过 A/B 实验验证，避免盲目调参 |
| 降级安全 | 监控引擎本身异常时不影响推荐主链路 |

### 1.3 适用范围

覆盖以下推荐场景：

| 场景编号 | 场景名称 | 候选源 | 说明 |
| --- | --- | --- | --- |
| S01 | 首页学习卡片推荐 | 内容服务 | 个性化学习内容卡片 |
| S02 | 练习题目推荐 | 题库服务 | 基于薄弱点的题目推荐 |
| S03 | 同步课堂章节推荐 | 内容服务 | 继续学习、相关章节 |
| S04 | 错题复习推荐 | 错题服务 | 今日复习错题推荐 |
| S05 | 知识图谱关联推荐 | 知识图谱服务 | 关联知识点推荐 |
| S06 | 学习路径推荐 | 规划服务 | 个性化学习路径推荐 |
| S07 | 作文素材推荐 | 内容服务 | 主题相关写作素材 |

### 2.2 数据流说明

```
1. 推荐服务产生推荐结果 → 记录推荐日志(RecommendationLog)
2. 客户端展示推荐内容 → 上报曝光事件(ImpressionEvent)
3. 学生点击/消费内容 → 上报消费事件(ConsumptionEvent)
4. 学习完成产生成效 → 上报成效数据(OutcomeEvent)
5. 监控引擎实时聚合事件 → 计算效果指标(MetricsSnapshot)
6. 效果评估引擎比对阈值 → 触发告警或调优
7. 归因分析定位问题根因 → 生成归因报告
8. 参数调优决策中心计算新参数 → 通过A/B实验验证
9. 配置中心推送新参数 → 推荐服务热加载
```

## 3. 数据结构定义

### 3.1 推荐日志表 `rec_recommendation_log`

记录每次推荐请求的完整信息。

```sql
CREATE TABLE rec_recommendation_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '自增ID',
    log_id          VARCHAR(64) NOT NULL COMMENT '日志唯一ID (雪花算法)',
    trace_id        VARCHAR(64) NOT NULL COMMENT '链路追踪ID',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    student_id      BIGINT NOT NULL COMMENT '学生ID',
    scene_code      VARCHAR(16) NOT NULL COMMENT '场景编号 S01-S07',
    request_id      VARCHAR(64) NOT NULL COMMENT '推荐请求ID',
    strategy_version VARCHAR(32) NOT NULL COMMENT '推荐策略版本号',
    experiment_id   VARCHAR(64) DEFAULT NULL COMMENT 'A/B实验ID',
    experiment_group VARCHAR(16) DEFAULT NULL COMMENT '实验分组 control/treatment',
    
    -- 推荐结果
    candidate_count INT NOT NULL COMMENT '候选集数量',
    final_count     INT NOT NULL COMMENT '最终展示数量',
    item_ids        JSON NOT NULL COMMENT '推荐项ID列表 ["item_1","item_2"]',
    item_scores     JSON NOT NULL COMMENT '推荐项得分列表 [{"id":"item_1","score":0.95}]',
    item_sources    JSON NOT NULL COMMENT '候选来源标记 [{"id":"item_1","source":"cf"}]',
    
    -- 请求上下文
    context         JSON NOT NULL COMMENT '推荐上下文(年级/学科/时段/设备等)',
    
    -- 性能
    latency_ms      INT NOT NULL COMMENT '推荐耗时(毫秒)',
    fallback_used   TINYINT DEFAULT 0 COMMENT '是否降级 0=否 1=是',
    
    created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '记录时间',
    
    INDEX idx_user_scene (user_id, scene_code, created_at),
    INDEX idx_experiment (experiment_id, created_at),
    INDEX idx_trace (trace_id),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='推荐日志表';
```

**分表策略**：按月分表 `rec_recommendation_log_YYYYMM`，保留 3 个月热数据，历史数据归档至 ClickHouse。

```java
    private double qualityScore;        // [0, 100]
```

## 5. 核心算法设计

### 5.1 推荐质量综合评分算法

质量综合分采用漏斗模型加权计算：

```java
/**
 * 推荐质量综合评分计算
 *
 * 评分模型：Q = w1*CTR_norm + w2*ConsumeRate_norm + w3*CompleteRate_norm
 *              + w4*OutcomeScore_norm + w5*FeedbackScore_norm - w6*DismissRate_norm
 *
 * 各指标归一化到 [0, 1] 区间后加权求和，最终映射到 [0, 100] 分制
 */
public class QualityScoreCalculator {

    // 场景相关权重（不同场景的关注点不同）
    private static final Map<String, QualityWeights> SCENE_WEIGHTS = Map.of(
        "S01", new QualityWeights(0.15, 0.25, 0.20, 0.25, 0.10, 0.05),
        "S02", new QualityWeights(0.10, 0.15, 0.30, 0.35, 0.05, 0.05),
        "S04", new QualityWeights(0.20, 0.30, 0.15, 0.20, 0.10, 0.05),
        "S05", new QualityWeights(0.25, 0.25, 0.15, 0.15, 0.15, 0.05)
    );

    public QualityResult calculate(RecommendationMetrics metrics) {
        QualityWeights weights = SCENE_WEIGHTS.getOrDefault(
            metrics.getSceneCode(),
            new QualityWeights(0.20, 0.20, 0.20, 0.20, 0.10, 0.10)
        );

        double ctrNorm = normalize(metrics.getClickThroughRate(), 0.0, 0.50);
        double consumeNorm = normalize(metrics.getConsumeRate(), 0.0, 0.30);
        double completeNorm = normalize(metrics.getCompleteRate(), 0.0, 1.0);
        double outcomeNorm = (metrics.getOutcomeScore() + 1.0) / 2.0;
        double feedbackNorm = calcFeedbackScore(
            metrics.getFeedbackPositive(), metrics.getFeedbackNegative());
        double dismissRate = (double) metrics.getDismissCount() / Math.max(1, metrics.getImpressionCount());
        double dismissNorm = normalize(dismissRate, 0.0, 0.80);

        double rawScore = weights.w1 * ctrNorm
                        + weights.w2 * consumeNorm
                        + weights.w3 * completeNorm
                        + weights.w4 * outcomeNorm
                        + weights.w5 * feedbackNorm
                        - weights.w6 * dismissNorm;

        double qualityScore = Math.max(0, Math.min(100, rawScore * 100));

        return QualityResult.builder()
            .qualityScore(qualityScore)
            .qualityGrade(scoreToGrade(qualityScore))
            .build();
    }

    private String scoreToGrade(double score) {
        if (score >= 90) return "S";
        if (score >= 80) return "A";
        if (score >= 70) return "B+";
        if (score >= 60) return "B";
        if (score >= 50) return "C";
        return "D";
    }

    private double normalize(double value, double min, double max) {
        if (max <= min) return 0;
        return Math.max(0, Math.min(1, (value - min) / (max - min)));
    }

    private static class QualityWeights {
        double w1, w2, w3, w4, w5, w6;
        QualityWeights(double... vals) {
            w1 = vals[0]; w2 = vals[1]; w3 = vals[2];
            w4 = vals[3]; w5 = vals[4]; w6 = vals[5];
        }
    }
}
```

```java
/**
 * 指标聚合函数 - 在5分钟滚动窗口内聚合事件
 */
public class MetricsAggregator
    implements AggregateFunction<RecEvent, MetricsAccumulator, MetricsSnapshot> {

    @Override
    public MetricsAccumulator createAccumulator() { return new MetricsAccumulator(); }

    @Override
    public MetricsAccumulator add(RecEvent event, MetricsAccumulator acc) {
        acc.sceneCode = event.getSceneCode();
        acc.totalRecommend++;
        acc.uniqueUsers.add(event.getUserId());

        switch (event.getEventType()) {
            case IMPRESSION: acc.impressionCount++; break;
            case CLICK: acc.clickCount++; break;
            case CONSUME:
                acc.consumeCount++;
                acc.consumeTimeSum += event.getDurationSec();
                break;
            case COMPLETE: acc.completeCount++; break;
            case OUTCOME:
                if (event.getOutcomeScore() > 0) acc.outcomePositive++;
                else if (event.getOutcomeScore() < 0) acc.outcomeNegative++;
                else acc.outcomeNeutral++;
                break;
            case FEEDBACK:
                if (event.getFeedbackType() == FeedbackType.POSITIVE) acc.feedbackPositive++;
                else acc.feedbackNegative++;
                break;
            case DISMISS: acc.dismissCount++; break;
        }
        return acc;
    }

    @Override
    public MetricsSnapshot getResult(MetricsAccumulator acc) {
        MetricsSnapshot m = new MetricsSnapshot();
        m.setSceneCode(acc.sceneCode);
        m.setTotalRecommend(acc.totalRecommend);
        m.setUniqueUsers(acc.uniqueUsers.size());
        m.setImpressionCount(acc.impressionCount);
        m.setClickCount(acc.clickCount);
        m.setClickThroughRate(safeDiv(acc.clickCount, acc.impressionCount));
        m.setConsumeCount(acc.consumeCount);
        m.setConsumeRate(safeDiv(acc.consumeCount, acc.impressionCount));
        m.setCompleteRate(safeDiv(acc.completeCount, Math.max(1, acc.consumeCount)));
        m.setOutcomeScore(computeOutcomeScore(acc));
        m.setDismissCount(acc.dismissCount);
        return m;
    }

    @Override
    public MetricsAccumulator merge(MetricsAccumulator a, MetricsAccumulator b) {
        a.totalRecommend += b.totalRecommend;
        a.uniqueUsers.addAll(b.uniqueUsers);
        a.impressionCount += b.impressionCount;
        a.clickCount += b.clickCount;
        a.consumeCount += b.consumeCount;
        a.completeCount += b.completeCount;
        a.consumeTimeSum += b.consumeTimeSum;
        a.outcomePositive += b.outcomePositive;
        a.outcomeNeutral += b.outcomeNeutral;
        a.outcomeNegative += b.outcomeNegative;
        a.feedbackPositive += b.feedbackPositive;
        a.feedbackNegative += b.feedbackNegative;
        a.dismissCount += b.dismissCount;
        return a;
    }

    private double safeDiv(long a, long b) { return b == 0 ? 0 : (double) a / b; }

    private double computeOutcomeScore(MetricsAccumulator acc) {
        double total = acc.outcomePositive + acc.outcomeNeutral + acc.outcomeNegative;
        return total > 0 ? (acc.outcomePositive - acc.outcomeNegative) / total : 0;
    }
}
```

### 5.3 异常检测引擎

采用双重检测策略——阈值检测 + 趋势检测：

```java
public class RecommendationAnomalyDetector {

    private static final double DEVIATION_THRESHOLD_PCT = 15.0;

    // 各场景各指标的绝对阈值
    private static final Map<String, Map<String, Double>> THRESHOLDS = Map.of(
        "S01", Map.of("click_through_rate", 0.08, "consume_rate", 0.05, "quality_score", 60.0),
        "S02", Map.of("click_through_rate", 0.15, "complete_rate", 0.40, "quality_score", 65.0),
        "S04", Map.of("click_through_rate", 0.20, "consume_rate", 0.10, "quality_score", 60.0)
    );

    public List<AnomalyResult> detect(RecommendationMetrics current,
                                       RecommendationMetrics baseline) {
        List<AnomalyResult> anomalies = new ArrayList<>();
        String scene = current.getSceneCode();

        // 1. 阈值检测：绝对值低于下限
        Map<String, Double> thresholds = THRESHOLDS.getOrDefault(scene, Map.of());
        thresholds.forEach((metric, threshold) -> {
            double value = getMetricValue(current, metric);
            if (value < threshold) {
                anomalies.add(AnomalyResult.builder()
                    .sceneCode(scene).metricName(metric)
                    .metricValue(value).baselineValue(threshold)
                    .anomalyType("THRESHOLD_BREACH")
                    .severity(value < threshold * 0.5 ? "P0" : "P1")
                    .description(metric + " 低于阈值 " + threshold)
                    .build());
            }
        });

        // 2. 趋势检测：相比7天基线偏离
        checkDeviation(anomalies, scene, "click_through_rate",
            current.getClickThroughRate(), baseline.getClickThroughRate(), false);
        checkDeviation(anomalies, scene, "consume_rate",
            current.getConsumeRate(), baseline.getConsumeRate(), false);
        checkDeviation(anomalies, scene, "outcome_score",
            current.getOutcomeScore(), baseline.getOutcomeScore(), false);
        checkDeviation(anomalies, scene, "dismiss_count",
            current.getDismissCount(), baseline.getDismissCount(), true);

        return anomalies;
    }

    private void checkDeviation(List<AnomalyResult> result, String scene,
            String metric, double current, double baseline, boolean inverted) {
        if (baseline == 0) return;
        double pct = ((current - baseline) / baseline) * 100;
        boolean isAnomaly = inverted ? pct > DEVIATION_THRESHOLD_PCT : pct < -DEVIATION_THRESHOLD_PCT;
        if (isAnomaly) {
            result.add(AnomalyResult.builder()
                .sceneCode(scene).metricName(metric)
                .deviationPct(pct).anomalyType("TREND_DEVIATION")
                .severity(Math.abs(pct) > 30 ? "P1" : "P2")
                .build());
        }
    }
}
```

### 5.4 多目标参数自动调优（贝叶斯优化）

```java
/**
 * 推荐参数自动调优引擎
 *
 * 1. 收集 (参数 -> 指标) 历史数据
 * 2. 训练高斯过程代理模型
 * 3. 使用 EI 采集函数搜索最优参数
 * 4. 通过 A/B 实验验证后全量切换
 */
public class BayesianParamOptimizer {

    private final GaussianProcessRegressor gpModel;

    // 参数搜索空间
    private static final Map<String, double[]> BOUNDS = Map.of(
        "relevance_weight",  new double[]{0.15, 0.40},
        "difficulty_weight", new double[]{0.10, 0.30},
        "freshness_weight",  new double[]{0.05, 0.20},
        "engagement_weight", new double[]{0.10, 0.25},
        "learning_weight",   new double[]{0.15, 0.35},
        "diversity_weight",  new double[]{0.03, 0.15}
    );

    public TuneResult autoTune(String sceneCode,
            List<ParamOutcomePair> history, List<String> targets) {

        // 准备训练数据
        double[][] X = history.stream()
            .map(p -> paramToVector(p.getParams()))
            .toArray(double[][]::new);
        double[] y = history.stream()
            .mapToDouble(p -> computeObjective(p.getMetrics(), targets))
            .toArray();

        // 训练代理模型
        gpModel.fit(X, y);

        // EI采集函数搜索
        double currentBest = Arrays.stream(y).max().orElse(0);
        double[] bestParams = null;
        double bestEI = Double.NEGATIVE_INFINITY;

        for (int i = 0; i < 1000; i++) {
            double[] candidate = sampleRandomParams();
            double[] ms = gpModel.predictWithStd(candidate);
            double z = ms[1] > 0 ? (ms[0] - currentBest) / ms[1] : 0;
            double ei = (ms[0] - currentBest) * normalCdf(z) + ms[1] * normalPdf(z);
            if (ei > bestEI) { bestEI = ei; bestParams = candidate; }
        }

        normalizeWeights(bestParams);

        return TuneResult.builder()
            .proposedParams(vectorToParam(bestParams))
            .expectedLift(gpModel.predict(bestParams) - currentBest)
            .confidence(gpModel.predictStd(bestParams))
            .build();
    }

    private double computeObjective(Map<String, Double> metrics, List<String> targets) {
        double sum = 0;
        for (String t : targets) {
            sum += normalizeMetric(t, metrics.getOrDefault(t, 0.0)) / targets.size();
        }
        return sum;
    }
}
```

```java
public class RecommendationDiagnosisEngine {

    public DiagnosisReport diagnose(String sceneCode, String targetMetric,

            .targetMetric(targetMetric)
            .currentMetrics(current)
            .baselineMetrics(baseline)
            .factors(factors.subList(0, Math.min(5, factors.size())))

            .build();
    }

    private List<DiagnosisFactor> diagnoseFreshness(

            RecommendationMetrics baseline, TimeRange range) {
        List<DiagnosisFactor> results = new ArrayList<>();

        double avgAgeNow = contentAgeStats(scene, range);
        double avgAgeBefore = contentAgeStats(scene, range.shift(-7, TimeUnit.DAYS));

        if (avgAgeNow > avgAgeBefore * 1.5) {
            double impact = Math.min(0.5,
                (avgAgeNow - avgAgeBefore) / avgAgeBefore * 0.3);
            results.add(DiagnosisFactor.builder()
                .factor("content_freshness")
                .impactScore(impact)
                .description(String.format("推荐内容平均年龄 %.1f -> %.1f 天",
                    avgAgeBefore, avgAgeNow))
                .evidence(Map.of("before", avgAgeBefore, "after", avgAgeNow))
                .suggestion("提高 freshness_weight")
                .build());
        }
        return results;
    }
}
```

## 6. 状态流转

### 6.1 推荐质量状态机

| 状态 | 触发条件 | 自动操作 |
| --- | --- | --- |
| HEALTHY | quality_score >= 75 且无P0/P1告警 | 正常运行 |
| WARNING | quality_score 60-74 或指标偏离>15% | 触发归因分析，准备调优方案 |
| DEGRADED | quality_score 50-59 或偏离>25% | 启动A/B实验验证新参数，增加监控频率 |
| CRITICAL | quality_score < 50 或偏离>40% | 立即切换降级策略，P0告警 |
| FALLBACK | CRITICAL后自动进入 | 使用热门推荐/缓存结果，暂停个性化 |
| RECOVERING | 降级后指标恢复到70+ | 灰度恢复个性化推荐 |

状态流转路径：
- HEALTHY -> WARNING (质量下降)
- WARNING -> DEGRADED (持续下降)
- DEGRADED -> CRITICAL (进一步恶化)
- CRITICAL -> FALLBACK (自动降级)
- FALLBACK -> RECOVERING (指标恢复)
- RECOVERING -> HEALTHY (全面恢复)
- 任意状态 -> HEALTHY (快速恢复时)

### 6.2 参数调优状态流转

| 状态 | 说明 |
| --- | --- |
| DRAFT | 系统或人工创建的新参数方案 |
| TESTING | 关联A/B实验，部分流量验证中 |
| ACTIVE | 实验胜出，全量生效 |
| REJECTED | 实验未胜出，废弃 |
| ROLLBACK | 曾生效但被回滚，保留历史 |

```java
    private static final int TIMEOUT_SEC = 60;

    public enum State { CLOSED, OPEN, HALF_OPEN }

    public <T> T withCircuit(Supplier<T> action, T fallback) {
        if (getState() == State.OPEN) {
            log.warn("Monitor circuit open, using fallback");
            return fallback;
        }
        try {
            T result = action.get();
            errorCount.set(0);
            return result;
        } catch (Exception e) {
            if (errorCount.incrementAndGet() >= THRESHOLD) {
                circuitOpenTime = System.currentTimeMillis();
                log.error("Monitor circuit opened", e);
            }
            return fallback;
        }
    }

    public State getState() {
        if (errorCount.get() < THRESHOLD) return State.CLOSED;
        if (System.currentTimeMillis() - circuitOpenTime > TIMEOUT_SEC * 1000)
            return State.HALF_OPEN;
        return State.OPEN;
    }
}
```

### 7.2 数据缺失处理

| 场景 | 处理策略 |
| --- | --- |
| 曝光事件丢失 | 使用推荐日志估算，标记 confidence=low |

### 8.2 多级缓存

- **L1 本地缓存（Caffeine）**：最新5分钟数据，60秒TTL，10,000条上限
- **L2 Redis缓存**：最近7天分钟级 + 90天小时级，5分钟TTL
- **查询穿透保护**：同一Key并发回源加锁，避免缓存击穿

```java
/**
 * 每小时将5分钟级数据聚合为小时级
 */
@Scheduled(cron = "0 5 * * * ?")
public void aggregateHourlyMetrics() {
    LocalDateTime hour = LocalDateTime.now().truncatedTo(HOURS).minusHours(1);

    for (String scene : ALL_SCENES) {
        List<RecommendationMetrics> snapshots = metricsRepository
            .findBySceneAndWindow(scene, "5m", hour, hour.plusHours(1));

        if (snapshots.isEmpty()) continue;

        RecommendationMetrics hourly = aggregate(snapshots, "1h", hour);
        QualityResult quality = qualityCalculator.calculate(hourly);
        hourly.setQualityScore(quality.getQualityScore());
        hourly.setQualityGrade(quality.getQualityGrade());

        metricsRepository.save(hourly);
    }
}
```

## 11. 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 流处理引擎 | Flink | 低延迟、窗口支持好、CEP能力强 |
| 代理模型 | 高斯过程回归 | 小样本效果好、提供不确定度估计 |
| 调优策略 | 贝叶斯优化 | 样本效率高、适合低维参数空间 |
| 基线计算 | 7天均值 | 平衡稳定性和时效性 |
| 质量评分模型 | 漏斗加权 | 可解释性强、初始阶段足够 |
| 降级策略 | 分场景配置 | 不同场景适合不同降级方式 |
