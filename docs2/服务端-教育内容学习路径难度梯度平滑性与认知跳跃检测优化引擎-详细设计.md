# 服务端-教育内容学习路径难度梯度平滑性与认知跳跃检测优化引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责对学习路径中的内容序列进行**宏观难度梯度分析**，检测存在"认知跳跃"的序列断点，并自动生成平滑化建议（插入过渡内容、调整排列顺序、生成分步引导等），确保学生在沿学习路径推进时，难度递进符合最近发展区（ZPD）原则，避免因难度骤升导致的挫败感和流失。

### 1.2 与现有模块的边界

| 现有模块 | 侧重点 | 本引擎差异 |
|---------|--------|-----------|
| 练习答题实时自适应难度调节引擎 | 微观：单次答题中动态选下一题 | 宏观：整条学习路径的序列规划 |
| 教育内容难度智能分级引擎 | 内容侧：给单个内容打难度标签 | 序列侧：分析内容之间的难度跃迁关系 |
| 学生认知负荷监测引擎 | 实时：答题过程中监测负荷 | 离线：路径设计阶段预判负荷峰值 |
| 知识点前置依赖检测与学习路径推荐 | 结构：知识点先后依赖 | 平滑：依赖满足后的难度曲线优化 |

### 1.3 适用范围

- 同步课堂章节内容排序校验
- 自适应学习路径生成后质量检查
- 教师自定义学习流发布前审核
- 课程内容编排团队内容排序辅助
- 考点专题复习序列优化

## 2. 核心概念定义

### 2.1 难度梯度 (Difficulty Gradient)

学习路径中相邻两个内容项之间的难度差值：

```
Δd = d(content_{i+1}) - d(content_i)
```

其中 `d()` 为内容难度分数，取值范围 `[0, 1]`。

### 2.2 认知跳跃 (Cognitive Jump)

当相邻内容难度差值超过**学生当前能力对应的容忍阈值**时，称为认知跳跃：

```
Δd > threshold(ability_level, content_type, knowledge_point_similarity)
```

阈值不是固定的，取决于：
- 学生能力水平（高能力学生容忍更大跳跃）
- 内容类型（纯理论→应用题跳跃容忍度低；练习→练习容忍度高）
- 知识点相似度（跨知识点跳跃容忍度低于同知识点）

### 2.3 难度曲线理想模型

```
理想难度曲线 = ZPD上界渐进线

   1.0 ┤                          ╱──────  目标难度
       │                        ╱
  0.8 ┤                     ╱
       │                  ╱
  0.6 ┤              ╱
       │          ╱         ← ZPD区间
  0.4 ┤       ╱
       │   ╱
  0.2 ┤ ╱
       │
  0.0 ┼──────────────────────────────
       内容1  内容2  ...  内容N
```

理想曲线特征：
- 单调递增（允许短期平台期）
- 无突增（Δd ≤ 当前阈值）
- 允许间歇性微降（复习巩固）
- 终点对齐目标难度

## 4. 核心算法设计

### 4.1 难度梯度分析算法

```python
class DifficultyGradientAnalyzer:
    """学习路径难度梯度分析器"""

    def analyze_path(self, path_sequence: list[dict], student_ability: float = 0.5) -> dict:
        """
        分析学习路径的难度梯度
        
        Args:
            path_sequence: 内容序列，每个元素包含 content_id, difficulty_score, 
                           content_type, knowledge_point_id
            student_ability: 学生能力值 [0, 1]
        
        Returns:
            分析结果，包含跳跃列表、平滑度评分、梯度曲线
        """
        if len(path_sequence) < 2:
            return self._empty_result()

        # 1. 计算相邻内容的难度差
        gradients = self._calculate_gradients(path_sequence)

        # 2. 根据学生能力确定容忍阈值
        ability_band = self._classify_ability(student_ability)
        thresholds = self._get_thresholds(ability_band)

        # 3. 检测认知跳跃
        jumps = self._detect_jumps(path_sequence, gradients, thresholds)

        # 4. 计算平滑度评分
        smoothness = self._calculate_smoothness(gradients, jumps, len(path_sequence))

        # 5. 计算梯度效率
        gradient_efficiency = self._calculate_gradient_efficiency(
            path_sequence, gradients
        )

        # 6. 分析平台期和回退
        plateaus = self._detect_plateaus(gradients)
        regressions = self._detect_regressions(gradients)

        return {
            "total_items": len(path_sequence),
            "gradients": gradients,
            "jumps": jumps,
            "severe_jump_count": sum(1 for j in jumps if j["severity"] == "SEVERE"),
            "moderate_jump_count": sum(1 for j in jumps if j["severity"] == "MODERATE"),
            "mild_jump_count": sum(1 for j in jumps if j["severity"] == "MILD"),
            "smoothness_score": smoothness,
            "gradient_efficiency": gradient_efficiency,
            "plateau_ratio": len(plateaus) / len(gradients),
            "regression_ratio": len(regressions) / len(gradients),
            "difficulty_curve": [item["difficulty_score"] for item in path_sequence],
        }

    def _calculate_gradients(self, sequence: list[dict]) -> list[dict]:
        """计算每对相邻内容的难度梯度"""
        gradients = []
        for i in range(len(sequence) - 1):
            current = sequence[i]
            nxt = sequence[i + 1]
            delta = nxt["difficulty_score"] - current["difficulty_score"]
            cross_kp = current["knowledge_point_id"] != nxt["knowledge_point_id"]
            gradients.append({
                "from_order": i + 1,
                "to_order": i + 2,
                "from_content_id": current["content_id"],
                "to_content_id": nxt["content_id"],
                "delta": round(delta, 4),
                "abs_delta": abs(delta),
                "direction": "UP" if delta > 0.005 else ("DOWN" if delta < -0.005 else "FLAT"),
                "cross_knowledge_point": cross_kp,
                "content_type_transition": f"{current['content_type']}->{nxt['content_type']}",
            })
        return gradients

    def _detect_jumps(
        self, sequence: list[dict], gradients: list[dict], thresholds: dict
    ) -> list[dict]:
        """检测认知跳跃"""
        jumps = []
        for g in gradients:
            if g["direction"] != "UP":
                continue

            # 获取对应的容忍阈值
            to_content = sequence[g["to_order"] - 1]
            threshold = thresholds.get(
                (to_content["content_type"], g["cross_knowledge_point"]),
                thresholds.get(("DEFAULT", False), 0.15)
            )

            if g["abs_delta"] <= threshold:
                continue

            # 分级
            ratio = g["abs_delta"] / threshold
            if ratio >= 2.0:
                severity = "SEVERE"
            elif ratio >= 1.5:
                severity = "MODERATE"
            else:
                severity = "MILD"

            jumps.append({
                **g,
                "severity": severity,
                "threshold": threshold,
                "exceed_ratio": round(ratio, 2),
                "suggested_action": self._suggest_action(severity, g, sequence),
            })
        return jumps

    def _suggest_action(self, severity: str, gradient: dict, sequence: list[dict]) -> str:
        """根据跳跃严重程度建议处理策略"""
        if severity == "SEVERE":
            # 严重跳跃：必须插入桥接内容或拆分
            if gradient["abs_delta"] > 0.35:
                return "SPLIT"
            return "INSERT_BRIDGE"
        elif severity == "MODERATE":
            # 中度跳跃：建议插入桥接或调整顺序
            return "INSERT_BRIDGE"
        else:
            # 轻微跳跃：可接受或插入简短过渡
            return "ACCEPT"

    def _calculate_smoothness(
        self, gradients: list[dict], jumps: list[dict], total: int
    ) -> float:
        """
        计算平滑度评分 [0, 1]
        
        评分逻辑:
        - 基础分 1.0
        - 每个SEVERE跳跃扣 0.15
        - 每个MODERATE跳跃扣 0.08
        - 每个MILD跳跃扣 0.03
        - 超长平台期（连续3+个FLAT）扣 0.05
        - 过度回退（连续2+个DOWN）扣 0.05
        """
        score = 1.0
        for jump in jumps:
            if jump["severity"] == "SEVERE":
                score -= 0.15
            elif jump["severity"] == "MODERATE":
                score -= 0.08
            else:
                score -= 0.03

        # 检测连续平台和回退
        consecutive_flat = 0
        consecutive_down = 0
        for g in gradients:
            if g["direction"] == "FLAT":
                consecutive_flat += 1
                if consecutive_flat >= 3:
                    score -= 0.05
                    consecutive_flat = 0
            else:
                consecutive_flat = 0

            if g["direction"] == "DOWN":
                consecutive_down += 1
                if consecutive_down >= 2:
                    score -= 0.03
                    consecutive_down = 0
            else:
                consecutive_down = 0

        return max(0.0, min(1.0, round(score, 4)))

    def _classify_ability(self, ability: float) -> str:
        """将能力值映射到能力区间"""
        if ability < 0.2:
            return "LOW"
        elif ability < 0.4:
            return "BELOW_AVG"
        elif ability < 0.6:
            return "AVERAGE"
        elif ability < 0.8:
            return "ABOVE_AVG"
        else:
            return "HIGH"

    def _calculate_gradient_efficiency(
        self, sequence: list[dict], gradients: list[dict]
    ) -> float:
        """
        梯度效率：实际难度进步 / 理想线性进步
        
        - 1.0 = 完美线性递进
        - < 1.0 = 递进效率低（太多平台/回退）
        - > 1.0 = 递进效率高（但可能过快）
        """
        total_progress = sequence[-1]["difficulty_score"] - sequence[0]["difficulty_score"]
        up_progress = sum(g["abs_delta"] for g in gradients if g["direction"] == "UP")
        if up_progress == 0:
            return 0.0
        return round(total_progress / up_progress, 4)
```

### 4.2 桥接内容推荐算法

```python
class BridgeContentRecommender:
    """桥接内容推荐器：为认知跳跃生成过渡内容推荐"""

    def find_bridge_contents(
        self,
        from_content: dict,
        to_content: dict,
        difficulty_delta: float,
        max_bridges: int = 3,
    ) -> list[list[dict]]:
        """
        查找合适的桥接内容序列
        
        Returns:
            多组桥接方案，每组是一个有序的内容序列
        """
        target_difficulty = from_content["difficulty_score"]
        end_difficulty = to_content["difficulty_score"]
        kp_ids = {from_content["knowledge_point_id"], to_content["knowledge_point_id"]}

        # 1. 计算理想的中间难度点
        num_bridges_needed = self._estimate_bridge_count(difficulty_delta)
        if num_bridges_needed == 0:
            return []

        ideal_difficulties = self._calculate_ideal_midpoints(
            target_difficulty, end_difficulty, num_bridges_needed
        )

        # 2. 在内容库中搜索候选
        candidates = self._search_candidates(
            kp_ids=kp_ids,
            difficulty_range=(target_difficulty + 0.02, end_difficulty - 0.02),
            content_types=["VIDEO", "ARTICLE", "INTERACTIVE"],
        )

        # 3. 构建桥接路径（动态规划：找到最接近理想难度曲线的组合）
        bridge_paths = self._dp_select_bridges(
            candidates, ideal_difficulties, from_content, to_content
        )

        return bridge_paths[:max_bridges]

    def _estimate_bridge_count(self, delta: float) -> int:
        """根据难度差估算需要的桥接内容数量"""
        if delta < 0.15:
            return 0
        elif delta < 0.25:
            return 1
        elif delta < 0.40:
            return 2
        else:
            return 3

    def _calculate_ideal_midpoints(
        self, start: float, end: float, n: int
    ) -> list[float]:
        """计算理想中间难度点（等间距）"""
        step = (end - start) / (n + 1)
        return [round(start + step * (i + 1), 3) for i in range(n)]

    def _dp_select_bridges(
        self,
        candidates: list[dict],
        ideal_points: list[float],
        from_content: dict,
        to_content: dict,
    ) -> list[list[dict]]:
        """
        动态规划选择最优桥接序列
        
        目标：最小化 |实际难度 - 理想难度| 的累积误差
        """
        n = len(ideal_points)
        if n == 0:
            return []

        # 按难度排序候选内容
        candidates.sort(key=lambda c: c["difficulty_score"])

        results = []

        # DP: dp[i] = (最小累积误差, 对应的路径)
        # 初始化：第一个桥接
        dp = {}
        for c in candidates:
            error = abs(c["difficulty_score"] - ideal_points[0])
            if c["difficulty_score"] > ideal_points[0] + 0.1:
                break  # 超出范围
            if c["difficulty_score"] < from_content["difficulty_score"]:
                continue
            dp[c["content_id"]] = {
                "error": error,
                "path": [c],
                "last_difficulty": c["difficulty_score"],
            }

        # 逐步扩展
        for i in range(1, n):
            new_dp = {}
            for c in candidates:
                if c["difficulty_score"] > ideal_points[i] + 0.1:
                    break
                if c["difficulty_score"] < ideal_points[i] - 0.15:
                    continue

                error = abs(c["difficulty_score"] - ideal_points[i])

                # 找到最优前驱
                best_prev = None
                best_total_error = float("inf")
                for prev_id, prev_state in dp.items():
                    # 桥接内容必须严格递增
                    if prev_state["last_difficulty"] >= c["difficulty_score"]:
                        continue
                    total = prev_state["error"] + error
                    if total < best_total_error:
                        best_total_error = total
                        best_prev = prev_id

                if best_prev is not None:
                    prev_state = dp[best_prev]
                    new_dp[c["content_id"]] = {
                        "error": best_total_error,
                        "path": prev_state["path"] + [c],
                        "last_difficulty": c["difficulty_score"],
                    }

            dp = new_dp

        # 排序并返回top方案
        sorted_results = sorted(dp.values(), key=lambda x: x["error"])
        for result in sorted_results[:3]:
            path = result["path"]
            # 验证最后一个桥接到目标内容的跳跃是否可接受
            final_delta = to_content["difficulty_score"] - path[-1]["difficulty_score"]
            if final_delta <= 0.15:  # 可接受
                results.append(path)

        return results
```

### 4.3 路径重排优化算法

```python
class PathReorderOptimizer:
    """路径重排优化器：在满足前置依赖约束下寻找最平滑的内容排列"""

    def optimize(
        self,
        contents: list[dict],
        dependencies: list[tuple[int, int]],
        constraints: dict = None,
    ) -> dict:
        """
        在依赖约束下寻找难度梯度最平滑的排列
        
        Args:
            contents: 内容列表
            dependencies: 依赖列表 [(前置content_id, 后续content_id), ...]
            constraints: 约束条件（固定位置等）
        
        Returns:
            最优排列方案及平滑度评分
        """
        constraints = constraints or {}
        n = len(contents)

        # 构建依赖图
        graph = self._build_dependency_graph(contents, dependencies)

        # 拓扑排序获取所有合法序列
        # 对于大序列，使用贪心+回溯代替全排列
        if n <= 10:
            best_order = self._brute_force_optimal(contents, graph, constraints)
        else:
            best_order = self._greedy_optimal(contents, graph, constraints)

        # 计算优化后的平滑度
        gradients = self._compute_gradients(best_order)
        smoothness = self._compute_smoothness(gradients)

        return {
            "optimized_sequence": best_order,
            "smoothness_score": smoothness,
            "gradients": gradients,
            "improvement": smoothness,  # 对比原始可在外部计算
        }

    def _greedy_optimal(
        self, contents: list[dict], graph: dict, constraints: dict
    ) -> list[dict]:
        """
        贪心算法：每步选择使难度梯度最优的下一个内容
        
        策略：优先选择难度最接近"理想下一难度"的可选内容
        理想下一难度 = 当前难度 + 目标步长
        """
        content_map = {c["content_id"]: c for c in contents}
        in_degree = {c["content_id"]: 0 for c in contents}
        dependents = {c["content_id"]: [] for c in contents}

        for pre_id, post_id in graph["edges"]:
            in_degree[post_id] += 1
            dependents[pre_id].append(post_id)

        # 可选集合（入度为0的内容）
        available = [cid for cid, deg in in_degree.items() if deg == 0]
        result = []
        current_difficulty = 0.0
        target_step = 0.10  # 目标步长

        fixed_positions = constraints.get("fixed_positions", {})

        while available:
            position = len(result) + 1

            # 检查是否有固定位置约束
            if position in fixed_positions:
                forced_id = fixed_positions[position]
                if forced_id in available:
                    chosen = forced_id
                else:
                    # 约束冲突，跳过
                    available.remove(forced_id)
                    continue
            else:
                # 选择最接近理想难度的内容
                ideal_next = current_difficulty + target_step
                available.sort(
                    key=lambda cid: (
                        abs(content_map[cid]["difficulty_score"] - ideal_next),
                        content_map[cid]["difficulty_score"],
                    )
                )
                chosen = available[0]

            chosen_content = content_map[chosen]
            result.append(chosen_content)
            current_difficulty = chosen_content["difficulty_score"]

            available.remove(chosen)
            for dep_id in dependents[chosen]:
                in_degree[dep_id] -= 1
                if in_degree[dep_id] == 0:
                    available.append(dep_id)

        return result
```

### 7.1 全量路径扫描任务

对于定期批量扫描所有活跃路径的需求，采用异步任务：

```python
class FullPathScanJob:
    """全量学习路径难度扫描任务"""

    async def execute(self, scan_config: dict):
        """
        定时扫描所有活跃路径
        
        scan_config:
          - subject_codes: 学科过滤
          - grade_levels: 年级过滤
          - min_path_length: 最小路径长度（默认3）
          - notify_threshold: 通知阈值（平滑度低于此值发通知）
        """
        # 1. 分批查询所有活跃路径
        async for path_batch in self.path_repo.iter_active_paths(
            subject_codes=scan_config.get("subject_codes"),
            grade_levels=scan_config.get("grade_levels"),
            batch_size=50,
        ):
            tasks = []
            for path in path_batch:
                if path["total_items"] < scan_config.get("min_path_length", 3):
                    continue
                task = self.scan_single_path(path["id"])
                tasks.append(task)

            # 并发处理（控制并发度）
            results = await asyncio.gather(*tasks, return_exceptions=True)

            # 处理结果
            for path, result in zip(path_batch, results):
                if isinstance(result, Exception):
                    logger.error(f"路径 {path['id']} 扫描失败: {result}")
                    continue

                if result["smoothness_score"] < scan_config.get("notify_threshold", 0.7):
                    await self.notification_service.notify_content_team(
                        path_id=path["id"],
                        path_name=path["path_name"],
                        smoothness=result["smoothness_score"],
                        jump_count=result["severe_jump_count"],
                    )

    async def scan_single_path(self, path_id: int) -> dict:
        """扫描单条路径"""
        sequence = await self.path_repo.get_path_sequence(path_id)
        analysis = self.analyzer.analyze_path(sequence)

        # 保存快照
        await self.snapshot_repo.save(
            path_id=path_id,
            **analysis,
        )

        # 保存跳跃检测结果
        if analysis["jumps"]:
            await self.jump_repo.batch_insert(
                path_id=path_id,
                jumps=analysis["jumps"],
            )

        return analysis
```

class DifficultyAnalysisFallback:
    """难度分析降级策略"""

    async def analyze_with_fallback(self, path_id: int, student_id: int = None):
        try:
            # 正常流程：获取精确分析
            return await self.full_analysis(path_id, student_id)
        except ContentDifficultyMissing:
            # 降级1：使用同类型内容平均难度
            sequence = await self.get_path_sequence(path_id)
            for item in sequence:
                if item["difficulty_score"] is None:
                    item["difficulty_score"] = await self.get_avg_difficulty_by_type(
                        item["content_type"]
                    )
            return await self.full_analysis_with_data(path_id, sequence)

        except StudentAbilityNotFound:
            # 降级2：使用年级平均能力
            grade = await self.get_student_grade(student_id)
            avg_ability = await self.get_grade_avg_ability(grade)
            return await self.full_analysis(path_id, ability_override=avg_ability)

        except Exception as e:
            # 降级3：返回基础评估
            logger.error(f"难度分析失败 path={path_id}: {e}")
            return self.basic_assessment(path_id)

### 11.1 批量路径扫描性能

```python
# 批量扫描使用Pipeline减少网络往返
async def batch_analyze_paths(self, path_ids: list[int]) -> list[dict]:
    pipe = redis.pipeline()
    for pid in path_ids:
        pipe.lrange(f"path:sequence:{pid}", 0, -1)
    sequences_raw = await pipe.execute()

    # 批量获取难度数据
    all_content_ids = set()
    for seq in sequences_raw:
        all_content_ids.update(int(cid) for cid in seq)

    pipe = redis.pipeline()
    for cid in all_content_ids:
        pipe.hgetall(f"content:difficulty:{cid}")
    difficulties_raw = await pipe.execute()

    # 内存中组装分析
    results = []
    for pid, seq in zip(path_ids, sequences_raw):
        sequence = self._assemble_sequence(seq, difficulties_raw)
        analysis = self.analyzer.analyze_path(sequence)
        results.append({"path_id": pid, **analysis})

    return results
```

### 11.2 增量检测

路径内容变更时，只分析变更点附近的梯度：

```python
async def incremental_check(self, path_id: int, changed_orders: list[int]):
    """
    增量检测：仅分析变更位置前后的梯度
    
    changed_orders: 发生变更的序列位置列表
    """
    check_range = 2  # 前后各检查2个位置
    affected_orders = set()
    for order in changed_orders:
        for delta in range(-check_range, check_range + 1):
            affected_orders.add(max(1, order + delta))

    # 仅获取受影响的内容
    sequence = await self.path_repo.get_path_items(path_id, sorted(affected_orders))

    # 局部分析
    return self.analyzer.analyze_path(sequence)
```

        next_content = await self.path_service.peek_next(path_id, student_id)
        current_content = await self.path_service.get_current(path_id, student_id)

## 15. 扩展性设计

### 15.1 自定义难度评估器

支持注册自定义难度评估策略：

```java
public interface DifficultyEvaluator {
    String getName();
    double evaluate(Content content, StudentContext context);
}

// 注册自定义评估器
@Component
public class CustomDifficultyEvaluator implements DifficultyEvaluator {
    @Override
    public String getName() {
        return "WRITING_TASK_DIFFICULTY";
    }
    
    @Override
    public double evaluate(Content content, StudentContext context) {
        // 作文类内容使用自定义难度计算逻辑
        // 基于题目要求字数、文体复杂度、立意深度等维度
        WritingTask task = (WritingTask) content;
        double baseScore = task.getRequiredWords() / 1000.0 * 0.3;
        double typeScore = task.getGenreComplexity() * 0.3;
        double topicScore = task.getTopicAbstractionLevel() * 0.4;
        return Math.min(1.0, baseScore + typeScore + topicScore);
    }
}
```

### 15.2 插件化跳跃检测规则

```java
public interface JumpDetectionRule {
    boolean supports(GradientContext context);
    JumpDetectionResult detect(GradientContext context);
}

// 示例：跨学段跳跃检测
@Component
@Order(1)
public class CrossPhaseJumpRule implements JumpDetectionRule {
    @Override
    public boolean supports(GradientContext context) {
        return context.getFromPhase() != context.getToPhase();
    }
    
    @Override
    public JumpDetectionResult detect(GradientContext context) {
        // 跨学段（小学→初中）的内容跳跃自动标记为SEVERE
        return JumpDetectionResult.severe(
            "跨学段内容跳跃",
            "建议在学段衔接课程中完成过渡"
        );
    }
}
```
