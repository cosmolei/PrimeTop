# 服务端-学生用户跨学科复习计划智能编排与复习负载动态均衡引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 学习闭环中的核心调度中间件，负责将来自错题本、薄弱知识点、考点清单、间隔重复算法等多个来源的复习需求，统一汇聚、智能排序、跨学科均衡编排为可执行的每日复习计划。

与现有模块的协作关系：

| 模块 | 职责 | 与本引擎的关系 |
| --- | --- | --- |
| 间隔重复算法与遗忘曲线调度引擎 | 单个复习项的下次复习时间计算 | 本引擎的消费方，提供基础复习时间建议 |
| 课后复习与知识巩固服务 | 课后即时复习内容生成 | 本引擎的输入源之一 |
| 错题订正效果评估与复习成效追踪服务 | 错题复习效果评估 | 本引擎的输入源之一（错题复习需求） |
| 多源学习任务统一调度与优先级仲裁引擎 | 所有学习任务的统一调度 | 本引擎的协同方，本引擎专注复习领域 |
| 每日任务智能生成服务 | 每日学习任务生成 | 本引擎的输出消费方，将复习任务注入每日计划 |

### 1.2 核心目标

1. **跨学科统筹**：当学生有 6 门学科、500+ 待复习项时，智能选出今天最该复习的 30-50 项。
2. **遗忘曲线适配**：在最优记忆窗口期触发复习，不超前、不滞后。
3. **复习负载均衡**：避免某天复习量爆炸、某天无复习内容，保证可持续性。
4. **考试驱动优先**：距离考试越近的学科，复习权重越高。
5. **动态适应**：根据当天实际完成情况、正确率波动实时调整后续计划。
6. **防止过载**：当复习积压严重时，自动执行降级策略，优先保证核心知识点。

### 1.3 适用范围

| 维度 | 范围 |
| --- | --- |
| 学段 | 小学、初中、高中 |
| 学科 | 语文、数学、英语、物理、化学、生物、历史、地理、政治 |
| 复习来源 | 错题、薄弱知识点、考点清单、课后巩固、间隔重复提醒、用户自建复习 |
| 触发方式 | 每日定时生成、实时增量更新、用户手动刷新 |

## 3. 核心算法设计

### 3.1 复习优先级计算引擎

复习优先级是多因子加权综合计算的结果，核心公式如下：

```
AdjustedPriority = w1 * ExamUrgencyScore
                 + w2 * ForgettingRiskScore
                 + w3 * MasteryGapScore
                 + w4 * SourceWeightScore
                 + w5 * DifficultyMatchScore
                 + w6 * RecencyPenalty
```

#### 3.1.1 因子定义与计算

```java
/**
 * 复习优先级计算器
 * 负责为每个复习项计算动态优先级
 */
@Component
public class ReviewPriorityCalculator {
    
    // 默认权重配置（可通过配置中心动态调整）
    private static final BigDecimal W_EXAM_URGENCY    = new BigDecimal("0.30");
    private static final BigDecimal W_FORGETTING_RISK = new BigDecimal("0.25");
    private static final BigDecimal W_MASTERY_GAP     = new BigDecimal("0.20");
    private static final BigDecimal W_SOURCE_WEIGHT   = new BigDecimal("0.10");
    private static final BigDecimal W_DIFFICULTY_MATCH= new BigDecimal("0.10");
    private static final BigDecimal W_RECENCY_PENALTY = new BigDecimal("0.05");
    
    /**
     * 计算单个复习项的调整后优先级
     */
    public int calculate(ReviewItem item, ReviewLoadProfile profile) {
        BigDecimal examUrgency = calculateExamUrgency(item, profile);
        BigDecimal forgettingRisk = calculateForgettingRisk(item);
        BigDecimal masteryGap = calculateMasteryGap(item);
        BigDecimal sourceWeight = calculateSourceWeight(item);
        BigDecimal difficultyMatch = calculateDifficultyMatch(item, profile);
        BigDecimal recencyPenalty = calculateRecencyPenalty(item);
        
        BigDecimal priority = examUrgency.multiply(W_EXAM_URGENCY)
            .add(forgettingRisk.multiply(W_FORGETTING_RISK))
            .add(masteryGap.multiply(W_MASTERY_GAP))
            .add(sourceWeight.multiply(W_SOURCE_WEIGHT))
            .add(difficultyMatch.multiply(W_DIFFICULTY_MATCH))
            .subtract(recencyPenalty.multiply(W_RECENCY_PENALTY))
            .multiply(new BigDecimal("100"))
            .setScale(0, RoundingMode.HALF_UP);
        
        // 限制在 0-100 范围
        int result = Math.max(0, Math.min(100, priority.intValue()));
        return result;
    }
    
    /**
     * 考试紧迫度：距离考试越近，权重越高
     * 计算逻辑：
     *   - 有考试日程：基于剩余天数指数衰减
     *   - 无考试日程：使用学科默认频率
     */
    private BigDecimal calculateExamUrgency(ReviewItem item, ReviewLoadProfile profile) {
        List<ExamInfo> exams = profile.getUpcomingExams() != null 
            ? profile.getUpcomingExams() 
            : Collections.emptyList();
        
        Optional<ExamInfo> nearestExam = exams.stream()
            .filter(e -> e.getSubject() == item.getSubjectCode())
            .filter(e -> e.getDaysLeft() > 0)
            .min(Comparator.comparingInt(ExamInfo::getDaysLeft));
        
        if (nearestExam.isEmpty()) {
            return BigDecimal.ZERO;
        }
        
        int daysLeft = nearestExam.get().getDaysLeft();
        // 指数衰减：考试当天=1.0, 7天=0.7, 30天=0.3, 90天=0.1
        double urgency = Math.exp(-daysLeft / 30.0);
        return BigDecimal.valueOf(urgency).setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 遗忘风险：基于遗忘曲线和最后复习时间
     * 如果已经过了理想复习日期，风险随天数增长
     */
    private BigDecimal calculateForgettingRisk(ReviewItem item) {
        LocalDate today = LocalDate.now();
        LocalDate ideal = item.getIdealReviewDate();
        
        long daysOverdue = ChronoUnit.DAYS.between(ideal, today);
        
        if (daysOverdue <= 0) {
            // 还未到期，风险较低
            return BigDecimal.ZERO;
        }
        
        // 基于艾宾浩斯遗忘曲线的简化模型
        // 过期1天=0.3, 3天=0.5, 7天=0.75, 14天=0.9, 30天+=1.0
        double risk = 1.0 - Math.exp(-daysOverdue / 5.0);
        return BigDecimal.valueOf(Math.min(1.0, risk))
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 掌握度差距：掌握度越低，越需要优先复习
     */
    private BigDecimal calculateMasteryGap(ReviewItem item) {
        // masteryLevel 0-1, gap = 1 - mastery
        return BigDecimal.ONE.subtract(item.getMasteryLevel())
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 来源权重：不同来源的复习项有不同的重要性
     */
    private BigDecimal calculateSourceWeight(ReviewItem item) {
        return switch (item.getSourceType()) {
            case MISTAKE             -> new BigDecimal("1.00");  // 错题最重要
            case WEAK_POINT          -> new BigDecimal("0.85");  // 薄弱点
            case EXAM_POINT          -> new BigDecimal("0.90");  // 考点
            case POST_CLASS          -> new BigDecimal("0.60");  // 课后巩固
            case SPACED_REPETITION   -> new BigDecimal("0.70");  // 间隔重复
            case MANUAL              -> new BigDecimal("0.50");  // 手动添加
        };
    }
    
    /**
     * 难度匹配度：难度与学生当前能力匹配的项优先级更高
     * 处于"最近发展区"的内容最优
     */
    private BigDecimal calculateDifficultyMatch(ReviewItem item, ReviewLoadProfile profile) {
        int difficulty = item.getDifficultyScore();
        // 简化模型：难度在40-70区间的最值得复习（既不太简单也不太难）
        if (difficulty >= 40 && difficulty <= 70) {
            return BigDecimal.ONE;
        } else if (difficulty < 40) {
            return new BigDecimal("0.50"); // 太简单，降级
        } else {
            return new BigDecimal("0.70"); // 较难，仍需复习但优先级稍降
        }
    }
    
    /**
     * 最近复习惩罚：如果刚刚复习过，降低优先级（避免重复）
     */
    private BigDecimal calculateRecencyPenalty(ReviewItem item) {
        if (item.getLastReviewedAt() == null) {
            return BigDecimal.ZERO;
        }
        
        long hoursSinceReview = ChronoUnit.HOURS.between(
            item.getLastReviewedAt(), LocalDateTime.now());
        
        if (hoursSinceReview < 6) {
            return BigDecimal.ONE;        // 6小时内刚复习过，强惩罚
        } else if (hoursSinceReview < 24) {
            return new BigDecimal("0.50"); // 当天复习过，中等惩罚
        } else {
            return BigDecimal.ZERO;        // 超过1天，不惩罚
        }
    }
}
```

### 3.2 跨学科负载均衡算法

这是本引擎的核心算法——在有限的复习时间内，将复习任务在多个学科之间进行最优分配。

```java
/**
 * 跨学科复习负载均衡器
 * 
 * 核心思路：
 * 1. 计算每个学科的"复习需求强度"（基于到期项数、考试紧迫度、历史薄弱度）
 * 2. 使用加权比例分配法将每日可用复习时间分配给各学科
 * 3. 在每个学科的时间配额内，按优先级选取复习项
 * 4. 执行溢出回收：未被使用的学科配额重新分配给其他学科
 */
@Component
public class CrossSubjectLoadBalancer {
    
    /**
     * 为学生生成今日跨学科复习分配方案
     *
     * @param candidateItems 各学科候选复习项（已按优先级排序）
     * @param profile 学生复习负载画像
     * @return 今日推荐的复习项列表
     */
    public List<ReviewItem> balance(
            Map<SubjectCode, List<ReviewItem>> candidateItems,
            ReviewLoadProfile profile) {
        
        int availableReviewSec = profile.getAvailableReviewSec();
        int maxItems = profile.getMaxReviewItemsPerDay();
        
        // Step 1: 计算各学科权重
        Map<SubjectCode, BigDecimal> subjectWeights = calculateSubjectWeights(
            candidateItems, profile);
        
        // Step 2: 按权重分配时间配额和数量配额
        Map<SubjectCode, SubjectQuota> quotas = allocateQuotas(
            subjectWeights, availableReviewSec, maxItems);
        
        // Step 3: 在每个学科配额内选取复习项
        List<ReviewItem> selectedItems = new ArrayList<>();
        int remainingSec = availableReviewSec;
        int remainingSlots = maxItems;
        
        for (Map.Entry<SubjectCode, SubjectQuota> entry : quotas.entrySet()) {
            SubjectCode subject = entry.getKey();
            SubjectQuota quota = entry.getValue();
            
            List<ReviewItem> subjectItems = candidateItems
                .getOrDefault(subject, Collections.emptyList());
            
            List<ReviewItem> picked = pickItemsWithinQuota(
                subjectItems, quota, remainingSec, remainingSlots);
            
            selectedItems.addAll(picked);
            remainingSec -= picked.stream()
                .mapToInt(ReviewItem::getEstimatedDurationSec).sum();
            remainingSlots -= picked.size();
        }
        
        // Step 4: 溢出回收——将未用完的配额重新分配
        if (remainingSec > 0 && remainingSlots > 0) {
            List<ReviewItem> overflow = pickOverflowItems(
                candidateItems, selectedItems, remainingSec, remainingSlots);
            selectedItems.addAll(overflow);
        }
        
        // Step 5: 全局排序——按时间段最优顺序排列
        return orderItemsForOptimalFlow(selectedItems, profile);
    }
    
    /**
     * 计算各学科权重
     * 权重 = 学科到期复习需求量 × 考试紧迫度 × 历史薄弱度
     */
    private Map<SubjectCode, BigDecimal> calculateSubjectWeights(
            Map<SubjectCode, List<ReviewItem>> candidates,
            ReviewLoadProfile profile) {
        
        Map<SubjectCode, BigDecimal> weights = new EnumMap<>(SubjectCode.class);
        
        for (Map.Entry<SubjectCode, List<ReviewItem>> entry : candidates.entrySet()) {
            SubjectCode subject = entry.getKey();
            List<ReviewItem> items = entry.getValue();
            
            // 因子1: 到期复习项数量（越多权重越高）
            long dueCount = items.stream()
                .filter(i -> !i.getIdealReviewDate().isAfter(LocalDate.now()))
                .count();
            BigDecimal demandFactor = BigDecimal.valueOf(Math.log1p(dueCount));
            
            // 因子2: 考试紧迫度（最近的考试）
            BigDecimal examFactor = profile.getUpcomingExams().stream()
                .filter(e -> e.getSubject() == subject)
                .map(ExamInfo::getUrgencyScore)
                .max(BigDecimal::compareTo)
                .orElse(new BigDecimal("0.3")); // 无考试的学科给默认值
            
            // 因子3: 历史薄弱度（近30天该学科正确率越低权重越高）
            BigDecimal weaknessFactor = profile.getSubjectWeakness(subject);
            
            BigDecimal weight = demandFactor
                .multiply(examFactor)
                .multiply(weaknessFactor);
            
            weights.put(subject, weight);
        }
        
        // 归一化
        BigDecimal total = weights.values().stream()
            .reduce(BigDecimal.ZERO, BigDecimal::add);
        
        if (total.compareTo(BigDecimal.ZERO) > 0) {
            weights.replaceAll((k, v) -> v.divide(total, 4, RoundingMode.HALF_UP));
        }
        
        return weights;
    }
    
    /**
     * 按权重分配时间配额和数量配额
     */
    private Map<SubjectCode, SubjectQuota> allocateQuotas(
            Map<SubjectCode, BigDecimal> weights,
            int totalSec, int totalItems) {
        
        Map<SubjectCode, SubjectQuota> quotas = new EnumMap<>(SubjectCode.class);
        
        // 保底：每个有复习需求的学科至少分配 5 个位置和 15 分钟
        int subjectsWithDemand = (int) weights.entrySet().stream()
            .filter(e -> e.getValue().compareTo(BigDecimal.ZERO) > 0)
            .count();
        
        int minItemsPerSubject = Math.max(2, Math.min(5, totalItems / Math.max(1, subjectsWithDemand)));
        int minSecPerSubject = Math.max(300, totalSec / Math.max(1, subjectsWithDemand));
        
        for (Map.Entry<SubjectCode, BigDecimal> entry : weights.entrySet()) {
            SubjectCode subject = entry.getKey();
            BigDecimal weight = entry.getValue();
            
            int quotaItems = Math.max(minItemsPerSubject, 
                (int) (totalItems * weight.doubleValue()));
            int quotaSec = Math.max(minSecPerSubject,
                (int) (totalSec * weight.doubleValue()));
            
            quotas.put(subject, new SubjectQuota(subject, quotaItems, quotaSec));
        }
        
        return quotas;
    }
    
    /**
     * 在学科配额内按优先级选取复习项
     */
    private List<ReviewItem> pickItemsWithinQuota(
            List<ReviewItem> sortedItems,
            SubjectQuota quota,
            int remainingSec,
            int remainingSlots) {
        
        List<ReviewItem> picked = new ArrayList<>();
        int usedSec = 0;
        
        for (ReviewItem item : sortedItems) {
            if (picked.size() >= quota.getMaxItems()) break;
            if (picked.size() >= remainingSlots) break;
            if (usedSec + item.getEstimatedDurationSec() > remainingSec) break;
            if (usedSec + item.getEstimatedDurationSec() > quota.getMaxSec()) break;
            
            picked.add(item);
            usedSec += item.getEstimatedDurationSec();
        }
        
        return picked;
    }
    
    /**
     * 全局排序：将选中的复习项按最优学习流排列
     * 
     * 策略：
     * - 先易后难（热身）
     * - 中间穿插高难度项（精力高峰期）
     * - 最后中等难度（收尾）
     * - 相同学科的项尽量不连续（降低认知疲劳）
     */
    private List<ReviewItem> orderItemsForOptimalFlow(
            List<ReviewItem> items, ReviewLoadProfile profile) {
        
        if (items.size() <= 1) return items;
        
        // 按难度分三档
        List<ReviewItem> easy = items.stream()
            .filter(i -> i.getDifficultyScore() < 40)
            .sorted(Comparator.comparing(ReviewItem::getAdjustedPriority).reversed())
            .collect(Collectors.toList());
        
        List<ReviewItem> medium = items.stream()
            .filter(i -> i.getDifficultyScore() >= 40 && i.getDifficultyScore() <= 70)
            .sorted(Comparator.comparing(ReviewItem::getAdjustedPriority).reversed())
            .collect(Collectors.toList());
        
        List<ReviewItem> hard = items.stream()
            .filter(i -> i.getDifficultyScore() > 70)
            .sorted(Comparator.comparing(ReviewItem::getAdjustedPriority).reversed())
            .collect(Collectors.toList());
        
        // 交替排列：1 easy → 1 hard → 2 medium → 1 hard → 1 easy → ...
        List<ReviewItem> result = new ArrayList<>();
        int ei = 0, mi = 0, hi = 0;
        SubjectCode lastSubject = null;
        
        while (result.size() < items.size()) {
            // 尝试添加一个中等难度项（避免同学科连续）
            if (mi < medium.size()) {
                ReviewItem next = findNonConsecutive(medium, mi, lastSubject);
                if (next != null) {
                    result.add(next);
                    lastSubject = next.getSubjectCode();
                    medium.remove(next);
                    continue;
                }
            }
            // 尝试添加一个简单项
            if (ei < easy.size() && result.size() % 3 == 0) {
                ReviewItem next = easy.get(ei++);
                result.add(next);
                lastSubject = next.getSubjectCode();
                continue;
            }
            // 尝试添加一个困难项
            if (hi < hard.size()) {
                ReviewItem next = hard.get(hi++);
                result.add(next);
                lastSubject = next.getSubjectCode();
                continue;
            }
            // 兜底：添加剩余的中等项
            if (mi < medium.size()) {
                ReviewItem next = medium.get(mi++);
                result.add(next);
                lastSubject = next.getSubjectCode();
                continue;
            }
            // 添加剩余的简单项
            while (ei < easy.size()) {
                result.add(easy.get(ei++));
            }
        }
        
        return result;
    }
    
    private ReviewItem findNonConsecutive(
            List<ReviewItem> items, int startIdx, SubjectCode exclude) {
        for (int i = startIdx; i < items.size(); i++) {
            if (items.get(i).getSubjectCode() != exclude) {
                return items.get(i);
            }
        }
        return null;
    }
    
    /**
     * 学科配额定义
     */
    @Data
    @AllArgsConstructor
    private static class SubjectQuota {
        private SubjectCode subject;
        private int maxItems;
        private int maxSec;
    }
}
```

### 3.3 过载降级策略

当复习积压严重时（待复习项远超每日可承受量），系统自动执行降级：

```java
/**
 * 复习过载降级处理器
 */
@Component
public class ReviewOverloadHandler {
    
    private static final int OVERLOAD_THRESHOLD_RATIO = 3; // 待复习项 > 日容量 × 3 = 过载
    
    /**
     * 检测是否处于过载状态并执行降级
     */
    public OverloadDecision evaluate(ReviewLoadProfile profile) {
        int pendingCount = profile.getPendingCount();
        int dailyCapacity = profile.getMaxReviewItemsPerDay();
        
        boolean isOverloaded = pendingCount > dailyCapacity * OVERLOAD_THRESHOLD_RATIO;
        
        if (!isOverloaded) {
            return OverloadDecision.normal();
        }
        
        // 过载降级策略
        int overloadLevel = calculateOverloadLevel(pendingCount, dailyCapacity);
        
        return OverloadDecision.builder()
            .overloaded(true)
            .overloadLevel(overloadLevel)
            .strategy(determineStrategy(overloadLevel))
            .build();
    }
    
    /**
     * 根据过载级别确定降级策略
     */
    private DegradationStrategy determineStrategy(int level) {
        return switch (level) {
            case 1 -> DegradationStrategy.builder()
                .name("LEVEL_1_LIGHT")
                .description("轻度过载：跳过已掌握(>0.85)且低遗忘风险的项")
                .skipMasteryAbove(0.85)
                .skipForgetRiskBelow(0.2)
                .maxItemsReduceRatio(0.8)
                .build();
                
            case 2 -> DegradationStrategy.builder()
                .name("LEVEL_2_MODERATE")
                .description("中度过载：仅保留掌握度<0.7或遗忘风险>0.5的项")
                .skipMasteryAbove(0.70)
                .skipForgetRiskBelow(0.5)
                .maxItemsReduceRatio(0.6)
                .mergeSimilarItems(true)
                .build();
                
            case 3 -> DegradationStrategy.builder()
                .name("LEVEL_3_SEVERE")
                .description("重度过载：仅保留核心错题和高频考点")
                .onlySourceTypes(List.of(SourceType.MISTAKE, SourceType.EXAM_POINT))
                .skipMasteryAbove(0.50)
                .maxItemsReduceRatio(0.4)
                .mergeSimilarItems(true)
                .groupReviewMode(true)  // 启用分组复习模式（多个相似项合并为一组）
                .build();
                
            default -> DegradationStrategy.builder()
                .name("LEVEL_4_CRITICAL")
                .description("紧急过载：仅保留最近7天的错题和考试高危项")
                .onlySourceTypes(List.of(SourceType.MISTAKE))
                .maxAgeDays(7)
                .maxItemsReduceRatio(0.3)
                .groupReviewMode(true)
                .emergencyMessage("您的复习积压较多，系统已自动筛选最重要项优先复习")
                .build();
        };
    }
    
    private int calculateOverloadLevel(int pending, int capacity) {
        double ratio = (double) pending / capacity;
        if (ratio < 5) return 1;
        if (ratio < 10) return 2;
        if (ratio < 20) return 3;
        return 4;
    }
}
```

### 5.2 每日定时生成流程

```java
/**
 * 每日复习计划生成调度器
 * 定时任务：每天 06:00 自动为所有活跃学生生成当日复习计划
 */
@Component
public class DailyReviewPlanScheduler {
    
    @Autowired private ReviewItemRepository reviewItemRepo;
    @Autowired private ReviewLoadProfileService profileService;
    @Autowired private ReviewPriorityCalculator priorityCalculator;
    @Autowired private CrossSubjectLoadBalancer loadBalancer;
    @Autowired private ReviewOverloadHandler overloadHandler;
    @Autowired private DailyReviewPlanRepository planRepo;
    
    /**
     * 定时任务入口：每天06:00执行
     * 分批处理所有活跃学生
     */
    @Scheduled(cron = "0 0 6 * * ?")
    public void generateDailyPlansForAllStudents() {
        int pageSize = 200;
        int pageNum = 0;
        
        while (true) {
            List<Long> userIds = getActiveStudentIds(pageNum, pageSize);
            if (userIds.isEmpty()) break;
            
            // 并发生成（控制并发度避免DB压力）
            userIds.parallelStream().forEach(this::generatePlanForUser);
            
            pageNum++;
        }
    }
    
    /**
     * 为单个学生生成当日复习计划
     */
    @Transactional
    public DailyReviewPlan generatePlanForUser(Long userId) {
        LocalDate today = LocalDate.now();
        
        // 1. 检查是否已生成
        Optional<DailyReviewPlan> existing = planRepo.findByUserIdAndPlanDate(userId, today);
        if (existing.isPresent() && existing.get().getStatus() != PlanStatus.DRAFT) {
            return existing.get();
        }
        
        // 2. 构建负载画像
        ReviewLoadProfile profile = profileService.buildProfile(userId, today);
        
        // 3. 采集所有候选复习项
        List<ReviewItem> allItems = reviewItemRepo.findPendingItemsForReview(userId, today);
        
        if (allItems.isEmpty()) {
            return createEmptyPlan(userId, today);
        }
        
        // 4. 检测过载并执行降级
        OverloadDecision overloadDecision = overloadHandler.evaluate(profile);
        if (overloadDecision.isOverloaded()) {
            allItems = applyDegradation(allItems, overloadDecision.getStrategy());
            profile.setMaxReviewItemsPerDay(
                (int)(profile.getMaxReviewItemsPerDay() * 
                      overloadDecision.getStrategy().getMaxItemsReduceRatio()));
        }
        
        // 5. 计算每项的调整后优先级
        for (ReviewItem item : allItems) {
            int priority = priorityCalculator.calculate(item, profile);
            item.setAdjustedPriority(priority);
        }
        
        // 6. 按学科分组
        Map<SubjectCode, List<ReviewItem>> bySubject = allItems.stream()
            .collect(Collectors.groupingBy(ReviewItem::getSubjectCode));
        
        // 每个学科内按优先级降序排列
        bySubject.values().forEach(list -> 
            list.sort(Comparator.comparingInt(ReviewItem::getAdjustedPriority).reversed()));
        
        // 7. 跨学科负载均衡
        List<ReviewItem> selectedItems = loadBalancer.balance(bySubject, profile);
        
        // 8. 持久化计划
        DailyReviewPlan plan = DailyReviewPlan.builder()
            .userId(userId)
            .planDate(today)
            .totalItems(selectedItems.size())
            .totalEstimatedSec(selectedItems.stream()
                .mapToInt(ReviewItem::getEstimatedDurationSec).sum())
            .subjectDistribution(buildSubjectDist(selectedItems))
            .targetDurationSec(profile.getAvailableReviewSec())
            .overloadFlag(overloadDecision.isOverloaded())
            .status(PlanStatus.CONFIRMED)
            .build();
        
        plan = planRepo.save(plan);
        
        // 9. 更新复习项状态为 SCHEDULED
        List<Long> itemIds = selectedItems.stream()
            .map(ReviewItem::getId).collect(Collectors.toList());
        reviewItemRepo.updateStatus(itemIds, ReviewStatus.SCHEDULED, today);
        
        // 10. 发送通知
        if (!selectedItems.isEmpty()) {
            sendReviewReadyNotification(userId, plan);
        }
        
        return plan;
    }
    
    private List<Long> getActiveStudentIds(int pageNum, int pageSize) {
        // 查询过去7天有活跃记录的学生
        return reviewItemRepo.findActiveUserIds(pageNum * pageSize, pageSize);
    }
    
    /**
     * 应用降级策略过滤复习项
     */
    private List<ReviewItem> applyDegradation(
            List<ReviewItem> items, DegradationStrategy strategy) {
        
        Stream<ReviewItem> stream = items.stream();
        
        // 按来源过滤
        if (strategy.getOnlySourceTypes() != null) {
            stream = stream.filter(i -> 
                strategy.getOnlySourceTypes().contains(i.getSourceType()));
        }
        
        // 按掌握度过滤
        if (strategy.getSkipMasteryAbove() != null) {
            stream = stream.filter(i -> 
                i.getMasteryLevel().compareTo(
                    BigDecimal.valueOf(strategy.getSkipMasteryAbove())) < 0);
        }
        
        // 按遗忘风险过滤
        if (strategy.getSkipForgetRiskBelow() != null) {
            stream = stream.filter(i -> 
                i.getForgettingRisk().compareTo(
                    BigDecimal.valueOf(strategy.getSkipForgetRiskBelow())) >= 0);
        }
        
        return stream.collect(Collectors.toList());
    }
}
```

### 5.3 实时增量更新流程

当学生完成一个复习项后，系统实时调整剩余计划：

```java
/**
 * 复习计划实时调整处理器
 */
@Component
public class ReviewPlanAdjustmentHandler {
    
    /**
     * 处理复习项完成事件，实时调整后续计划
     */
    @EventListener
    public void onReviewItemCompleted(ReviewItemCompletedEvent event) {
        Long userId = event.getUserId();
        LocalDate today = LocalDate.now();
        
        DailyReviewPlan plan = planRepo.findByUserIdAndPlanDate(userId, today)
            .orElseThrow();
        
        // 更新计划进度
        plan.setCompletedCount(plan.getCompletedCount() + 1);
        plan.setActualDurationSec(
            plan.getActualDurationSec() + event.getDurationSec());
        
        if ("CORRECT".equals(event.getResult())) {
            plan.setCorrectCount(plan.getCorrectCount() + 1);
        } else if ("INCORRECT".equals(event.getResult())) {
            plan.setIncorrectCount(plan.getIncorrectCount() + 1);
        }
        
        plan.setCompletionRate(
            (double) plan.getCompletedCount() / plan.getTotalItems());
        
        // 动态调整逻辑
        ReviewLoadProfile profile = profileService.buildProfile(userId, today);
        int remainingTime = plan.getTargetDurationSec() - plan.getActualDurationSec();
        int remainingItems = plan.getTotalItems() - plan.getCompletedCount();
        
        // 场景1: 当前正确率很低（<50%），减少后续新增量，避免疲劳
        double currentAccuracy = plan.getCorrectCount() > 0 
            ? (double) plan.getCorrectCount() / plan.getCompletedCount() 
            : 0;
        
        if (currentAccuracy < 0.5 && plan.getCompletedCount() >= 5) {
            // 标记后续困难项为SKIP，建议学生先复习基础知识
            flagHardItemsAsOptional(plan, profile);
            notifyAccuracyDrop(userId, currentAccuracy);
        }
        
        // 场景2: 提前完成，可补充额外复习项
        if (remainingItems == 0 && remainingTime > 600) {
            addBonusItems(plan, userId, remainingTime, profile);
        }
        
        // 场景3: 时间不够了，优先保留高优先级项
        if (remainingItems > 0) {
            int projectedTime = estimateRemainingTime(plan);
            if (projectedTime > remainingTime * 1.5) {
                trimLowPriorityItems(plan, remainingTime);
            }
        }
        
        planRepo.save(plan);
        
        // 发布计划更新事件（供客户端刷新）
        eventBus.publish(new ReviewPlanUpdatedEvent(userId, plan.getId()));
    }
    
    /**
     * 从剩余计划中裁剪低优先级项
     */
    private void trimLowPriorityItems(DailyReviewPlan plan, int availableTime) {
        List<ReviewItem> remaining = reviewItemRepo
            .findScheduledItemsByPlan(plan.getUserId(), plan.getPlanDate());
        
        // 按优先级排序
        remaining.sort(Comparator.comparingInt(ReviewItem::getAdjustedPriority));
        
        int accumulated = 0;
        int trimmed = 0;
        
        // 从最低优先级开始裁剪
        for (ReviewItem item : remaining) {
            if (accumulated < availableTime) {
                accumulated += item.getEstimatedDurationSec();
            } else {
                // 转为SKIPPED
                item.setStatus(ReviewStatus.SKIPPED);
                item.setActualReviewDate(null);
                reviewItemRepo.save(item);
                trimmed++;
            }
        }
        
        plan.setSkippedCount(plan.getSkippedCount() + trimmed);
        plan.setTotalItems(plan.getTotalItems() - trimmed);
    }
}
```

```java
            userId, targetDate);

            // 查询该错题关联知识点的掌握度

                userId, m.getKnowledgePointIds());
            
            // 基于上次复习时间和复习次数计算理想复习日期
            LocalDate idealDate = calculateNextReviewDate(
                m.getLastReviewedAt(), m.getReviewCount(), m.getLastResult());
            
            return ReviewItem.builder()
                .userId(userId)
                .sourceType(SourceType.MISTAKE)
                .sourceId(m.getId())
                .subjectCode(m.getSubjectCode())
                .knowledgePointIds(m.getKnowledgePointIds())
                .contentType(ContentType.QUESTION)
                .contentId(m.getQuestionId())
                .idealReviewDate(idealDate)
                .earliestReviewDate(targetDate)
                .latestReviewDate(idealDate.plusDays(7))
                .masteryLevel(mastery)
                .difficultyScore(m.getDifficultyScore())
                .status(ReviewStatus.PENDING)
                .reviewCount(m.getReviewCount())
                .lastReviewedAt(m.getLastReviewedAt())
                .lastResult(mapResult(m.getLastResult()))
                .estimatedDurationSec(estimateDuration(m))
                .tags(Map.of(
                    "errorType", m.getErrorType(),
                    "chapter", m.getChapterName()))
                .build();
        }).collect(Collectors.toList());
    }
    
    /**
     * 基于简化版SM-2算法计算下次复习日期
     */
    private LocalDate calculateNextReviewDate(
            LocalDateTime lastReviewed, int reviewCount, String lastResult) {
        if (lastReviewed == null) {
            return LocalDate.now(); // 从未复习过，立即可复习
        }
        
        // 根据复习次数和上次结果决定间隔（天数）
        int[] intervals = switch (lastResult) {
            case "CORRECT" -> new int[]{1, 3, 7, 14, 30, 60};
            case "PARTIALLY_CORRECT" -> new int[]{1, 2, 4, 8, 15, 30};
            default -> new int[]{1, 1, 2, 4, 7, 14}; // INCORRECT: 更频繁
        };
        
        int idx = Math.min(reviewCount, intervals.length - 1);
        int intervalDays = intervals[idx];
        
        return lastReviewed.toLocalDate().plusDays(intervalDays);
    }
}

    public List<ReviewItem> fetchReviewCandidates(Long userId, LocalDate targetDate) {
        // 获取学生的考试日程
        List<ExamSchedule> upcomingExams = examScheduleService
            .getUpcomingExams(userId, targetDate, 60); // 未来60天内
        
        List<ReviewItem> items = new ArrayList<>();
        
        for (ExamSchedule exam : upcomingExams) {
            int daysLeft = (int) ChronoUnit.DAYS.between(targetDate, exam.getExamDate());
            
            // 考前30天开始推送考点复习
            if (daysLeft > 30 || daysLeft < 0) continue;
            
            // 获取该学科该年级的高频考点
            List<ExamPoint> points = examPointService
                .getHighFrequencyPoints(exam.getSubjectCode(), 
                    exam.getGradeLevel(), exam.getExamType());
            
            for (ExamPoint point : points) {
                // 检查是否已经掌握
                BigDecimal mastery = examPointService
                    .getPointMastery(userId, point.getId());
                
                if (mastery.compareTo(new BigDecimal("0.85")) > 0) {
                    continue; // 已掌握，跳过
                }
                
                items.add(ReviewItem.builder()
                    .userId(userId)
                    .sourceType(SourceType.EXAM_POINT)
                    .sourceId(point.getId())
                    .subjectCode(exam.getSubjectCode())
                    .knowledgePointIds(point.getKnowledgePointIds())
                    .contentType(ContentType.CONCEPT)
                    .contentId(point.getContentId())
                    .idealReviewDate(targetDate)
                    .earliestReviewDate(targetDate)
                    .latestReviewDate(exam.getExamDate().minusDays(1))
                    .masteryLevel(mastery)
                    .difficultyScore(point.getDifficultyScore())
                    .examUrgency(calculateExamUrgency(daysLeft))
                    .status(ReviewStatus.PENDING)
                    .estimatedDurationSec(180)
                    .tags(Map.of(
                        "examType", exam.getExamType(),
                        "frequency", point.getFrequencyLevel()))
                    .build());
            }
        }
        
        return items;
    }
    
    private BigDecimal calculateExamUrgency(int daysLeft) {
        double urgency = Math.exp(-daysLeft / 20.0);
        return BigDecimal.valueOf(Math.min(1.0, urgency))
            .setScale(2, RoundingMode.HALF_UP);
    }
}
```

```dart
class ReviewPlanRepository {
  final ApiClient _api;
  final Box<ReviewItemCache> _localBox; // Hive本地缓存
  
  /// 获取今日复习计划（支持离线）
  Future<DailyReviewPlan?> getTodayPlan(String userId) async {
    try {
      // 优先从API获取
      final plan = await _api.get('/api/v1/review-plan/today?userId=$userId');
      
      // 缓存到本地（支持离线复习）
      await _cachePlanLocally(plan);
      
      return DailyReviewPlan.fromJson(plan['data']);
    } catch (e) {
      // 网络失败时使用本地缓存
      return _getLocalPlan();
    }
  }
  
  /// 提交复习结果（支持离线队列）
  Future<void> completeReviewItem(
      String itemId, ReviewResult result) async {
    final payload = {
      'result': result.name,
      'durationSec': result.durationSec,
      'completedAt': DateTime.now().toIso8601String(),
    };
    
    try {
      await _api.post(
        '/api/v1/review-plan/items/$itemId/complete',
        body: payload,
      );
    } catch (e) {
      // 离线时存入待同步队列
      await _pendingSyncBox.put(itemId, {
        ...payload,
        'type': 'complete',
        'itemId': itemId,
      });
    }
  }
  
  /// 网络恢复后批量同步离线提交
  Future<void> syncPendingResults() async {
    final pending = _pendingSyncBox.values.toList();
    if (pending.isEmpty) return;
    
    for (final item in pending) {
      try {
        await _api.post(
          '/api/v1/review-plan/items/${item['itemId']}/complete',
          body: item,
        );
        await _pendingSyncBox.delete(item['itemId']);
      } catch (_) {
        break; // 网络仍然不可用，稍后重试
      }
    }
  }
}
```

```java
public abstract class ReviewPlanEvent {
    private final Long userId;
    private final Long planId;
    private final LocalDate planDate;
    private final Instant occurredAt;
}

public class ReviewPlanGeneratedEvent extends ReviewPlanEvent {
    private final int totalItems;
    private final int totalEstimatedSec;
    private final boolean overloaded;
    private final Map<String, Integer> subjectDistribution;
    // 当计划生成时发布 → 触发推送通知
}

public class ReviewItemCompletedEvent extends ReviewPlanEvent {
    private final Long reviewItemId;
    private final String result;
    private final int durationSec;
    private final BigDecimal masteryDelta;
    // 当复习项完成时发布 → 触发知识追踪更新、成就检查
}

public class ReviewPlanOverloadedEvent extends ReviewPlanEvent {
    private final int overloadLevel;
    private final String strategy;
    // 当检测到过载时发布 → 触发家长通知、学习计划调整
}

public class ReviewPlanCompletedEvent extends ReviewPlanEvent {
    private final int completedCount;
    private final int totalCount;
    private final double accuracyRate;
    private final int totalDurationSec;
    // 当计划全部完成时发布 → 触发学习报告、积分发放
}
```

### 12.2 独立部署 vs 嵌入式部署

本引擎支持两种部署模式：

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| 独立服务 | 作为独立的微服务部署，通过 API/事件与其他服务通信 | 大规模用户（>50万DAU），需要独立伸缩 |

```java
        assertThat(result).hasSizeLessThanOrEqualTo(30);
        
        // 验证：预估总时长不超过上限

        assertThat(totalSec).isLessThanOrEqualTo(1800);
```

## 附录：术语表

| 术语 | 定义 |
| --- | --- |
| 复习项 | 一个可独立完成的最小复习单元，如一道错题、一张知识卡片 |
| 复习负载画像 | 学生在特定日期的复习需求、可用时间和历史模式的综合描述 |
| 过载 | 待复习项数量远超每日可承受量的状态 |
| 降级 | 在过载状态下，通过过滤、合并等手段减少复习项的策略 |
| 跨学科均衡 | 在多个学科之间合理分配复习资源，避免某学科独占 |
| 溢出回收 | 某学科配额未被用完时，将剩余配额重新分配给其他学科 |
| 最近发展区 (ZPD) | 维果茨基理论中"学生当前能力与潜在能力之间的差距"，对应"跳一跳能够到"的难度 |
