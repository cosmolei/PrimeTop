# 客户端 - 地理学科工具与交互地图学习组件 详细设计

## 1. 模块概述

### 1.1 模块定位

地理学科工具与交互地图学习组件是 PrimeTop 客户端学科工具箱体系下的地理学科专用模块，面向小学高年级、初中和高中学生，提供可视化地图交互、区域地理知识浏览、地形气候图示、人文地理数据展示和地理专项练习等功能。

### 1.2 设计目标

1. 将抽象的地理知识可视化，通过交互式地图降低理解门槛
2. 覆盖自然地理（地形、气候、水文）和人文地理（人口、城市、产业）核心知识点
3. 适配不同学段的深度需求：小学以认知为主、初中侧重区域分析、高中强调综合思维
4. 离线可用：核心地图数据支持本地缓存，弱网环境下基本功能不受影响

### 1.3 覆盖学段与场景

| 学段 | 学习重点 | 典型场景 |
|------|---------|---------|
| 小学高年级（4-6年级） | 认识中国省份、首都、大洲大洋 | 拼图练习、拖拽定位 |
| 初中 | 区域地理、中国地理、世界地理 | 地图标注、气候类型判断、经纬网练习 |
| 高中 | 自然地理原理、人文地理分析、区域可持续发展 | 地形剖面绘制、农业区位分析、城市功能分区 |

### 7.1 地图图层控制器

```dart
class GeoLayerController extends ChangeNotifier {
  final List<GeoLayerData> _availableLayers;
  final Set<String> _activeLayerIds = {};
  final Map<String, double> _layerOpacity = {};

  GeoLayerController(this._availableLayers);

  void activateLayer(String layerId, {double opacity = 1.0}) {
    if (_availableLayers.any((l) => l.layerId == layerId)) {
      _activeLayerIds.add(layerId);
      _layerOpacity[layerId] = opacity;
      notifyListeners();
    }
  }

  void deactivateLayer(String layerId) {
    _activeLayerIds.remove(layerId);
    _layerOpacity.remove(layerId);
    notifyListeners();
  }

  void toggleLayer(String layerId) {
    if (_activeLayerIds.contains(layerId)) {
      deactivateLayer(layerId);
    } else {
      activateLayer(layerId);
    }
  }

  void setLayerOpacity(String layerId, double opacity) {
    if (_activeLayerIds.contains(layerId)) {
      _layerOpacity[layerId] = opacity.clamp(0.0, 1.0);
      notifyListeners();
    }
  }

  Set<String> get activeLayerIds => Set.unmodifiable(_activeLayerIds);
  double getLayerOpacity(String layerId) => _layerOpacity[layerId] ?? 1.0;
  List<GeoLayerData> get activeLayers =>
    _availableLayers.where((l) => _activeLayerIds.contains(l.layerId)).toList();
}
```

```dart
  int get hoursDiff {
    if (_selectedTimezone == null || _compareTimezone == null) return 0;
    return _selectedTimezone!.utcOffset - _compareTimezone!.utcOffset;
  }

  DateTime get targetTime {
    if (_selectedTimezone == null) return _referenceTime;
    return _referenceTime.add(Duration(hours: hoursDiff));
  }
}

class TimezoneData {
  final String timezoneId;    // "Asia/Shanghai"
  final String cityName;      // "北京"
  final int utcOffset;        // +8
  final GeoCoordinate location;
}
```

## 11. 性能优化

### 11.1 地图渲染优化

1. **瓦片按需加载**：仅加载当前视口范围内的瓦片，预加载相邻区域
2. **多级缓存**：内存缓存（当前视口）→ 磁盘缓存（已浏览区域）→ 网络获取
3. **矢量简化**：根据缩放级别动态简化矢量路径，减少绘制开销
4. **图层合并**：多个静态图层预合成为单一纹理，减少绘制调用
5. **异步解码**：瓦片图片在后台线程解码，不阻塞UI

### 11.2 数据加载优化

```dart
/// 地理数据加载策略
class GeoDataLoader {
  /// 区域树：启动时预加载到内存
  Future<void> preloadRegionTree();

  /// 知识卡片：按需加载 + LRU缓存（最多50张）
  final _cardCache = LruCache<String, GeoKnowledgeCard>(maxSize: 50);

  /// 练习题：批量预加载当前学段题目列表
  Future<void> prefetchExerciseList(String phase, String type);

  /// 瓦片：优先使用磁盘缓存
  Future<Uint8List> loadTile(String layerId, int z, int x, int y) async {
    final cacheKey = '${layerId}_${z}_${x}_${y}';
    // L1: 内存缓存
    if (_memoryCache.containsKey(cacheKey)) return _memoryCache[cacheKey]!;
    // L2: 磁盘缓存
    final disk = await _readFromDisk(cacheKey);
    if (disk != null) {
      _memoryCache[cacheKey] = disk;
      return disk;
    }
    // L3: 网络获取
    final network = await _fetchFromNetwork(layerId, z, x, y);
    await _writeToDisk(cacheKey, network);
    _memoryCache[cacheKey] = network;
    return network;
  }
}
```

### 13.1 错误码定义

| 错误码 | 说明 | 处理策略 |
|--------|------|---------|
| GEO_001 | 地图资源加载失败 | 降级为简化矢量底图 |
| GEO_002 | 瓦片加载超时 | 显示加载中占位，重试3次 |
| GEO_003 | 区域数据不存在 | 提示"暂无该区域数据"，返回上级 |
| GEO_004 | 知识卡片未找到 | 显示基础信息 + "更多内容加载中" |
| GEO_005 | 练习提交失败 | 本地暂存答案，提示稍后重试 |
| GEO_006 | 离线数据不可用 | 引导用户连接网络或下载离线包 |
| GEO_007 | 图层渲染异常 | 关闭异常图层，显示错误提示 |
| GEO_008 | 地理位置权限被拒 | 不影响使用，禁用定位功能 |

### 13.2 异常恢复流程

```
地图渲染异常
    │
    ▼
捕获渲染错误 → 记录日志
    │
    ▼
尝试关闭最近激活的图层
    │
    ├── 成功 → 恢复渲染，提示用户
    │
    └── 失败 → 回退到基础底图
    │

上报异常（非阻塞）
```
