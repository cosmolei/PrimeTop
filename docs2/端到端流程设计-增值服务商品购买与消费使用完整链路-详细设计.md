> 版本：v1.0 · 日期：2026-06-05 · 状态：初稿

## 1. 概述

### 1.1 范围

本文档覆盖用户从**浏览增值服务商品** → **下单支付** → **权益开通** → **功能消费** → **额度耗尽/续购**的完整端到端链路，涵盖客户端交互、服务端编排、支付集成、权益校验和异常处理。

增值服务是与会员订阅并行的第二条商业化产品线，定位为：

| 维度 | 会员订阅 | 增值服务 |
| --- | --- | --- |
| 购买模式 | 周期性订阅（月/季/年） | 一次性购买或用量包 |
| 权益形态 | 全功能解锁 + 通用额度提升 | 特定功能深度使用或次数包 |
| 生命周期 | 订阅期生效，到期降级 | 按用量消耗，用完即止 |
| 目标用户 | 高频持续学习用户 | 有特定需求的临时/增量用户 |

### 1.2 核心商品类型

| 商品类型 | 示例 | 计量方式 | 生命周期 |
| --- | --- | --- | --- |
| **次数包** | AI 问答次数包、拍题识别次数包、作文批改次数包 | 按次扣减 | 永不过期或N天有效 |
| **时间包** | 考前冲刺学习包（30天）、假期专题包（45天） | 按天计费 | 固定有效期 |
| **内容包** | 专项题库训练包、精品课程包、名师解析包 | 解锁访问 | 永久或随版本更新 |
| **增强服务** | 高级学情诊断报告、深度错题分析报告 | 按次生成 | 单次消费 |

### 1.3 关联文档

| 文档 | 关系 |

| 用户额度与API调用管控系统-详细设计 | 额度扣减与校验引擎 |

| 服务端-退款与订单售后处理服务-详细设计 | 售后退回与额度回收 |

## 2. 端到端流程总览

### 2.1 主流程

```
用户浏览商城 → 选择商品 → 查看详情 → 确认下单 → 选择支付方式
    → 发起支付 → 支付回调 → 权益开通 → 功能消费 → 额度扣减
    → (额度耗尽) → 提醒续购 → 循环
```

```
    │                   │                    │                    │

                                          [成功]─→ 权益开通
```

### 5.4 支付回调处理（服务端内部）

```java
/**
 * 支付回调处理器
 * 处理微信/支付宝/Apple IAP 的异步通知
 */
@Service
public class AddonPaymentCallbackHandler {

    /**
     * 处理支付成功回调
     * 整体流程：验签 → 幂等检查 → 更新订单 → 开通权益 → 发送通知
     */
    @Transactional
    public void handlePaymentSuccess(PaymentCallbackMessage message) {
        // 1. 验证签名（防伪造）
        verifySignature(message);

        // 2. 查询订单
        AddonOrder order = orderRepository.findByOutTradeNo(message.getOutTradeNo())
            .orElseThrow(() -> new BusinessException("ORDER_NOT_FOUND"));

        // 3. 幂等检查：如果已经是终态成功，直接返回
        if (order.getStatus() == OrderStatus.ENTITLEMENT_ACTIVATED) {
            log.info("订单已处理，跳过: orderId={}", order.getOrderId());
            return;
        }

        // 4. 验证金额一致性
        if (order.getPayAmount() != message.getTotalFee()) {
            log.error("金额不一致: orderId={}, expected={}, actual={}",
                order.getOrderId(), order.getPayAmount(), message.getTotalFee());
            throw new BusinessException("AMOUNT_MISMATCH");
        }

        // 5. 更新订单状态
        order.setStatus(OrderStatus.PAYMENT_SUCCESS);
        order.setTransactionId(message.getTransactionId());
        order.setPaidAt(LocalDateTime.now());
        orderRepository.save(order);

        // 6. 开通权益（核心步骤）
        activateEntitlement(order);

        // 7. 发送通知
        notificationService.sendPurchaseSuccessNotification(order);

        // 8. 埋点上报
        analyticsService.trackEvent(AnalyticsEvent.ADDON_PURCHASE_SUCCESS, Map.of(
            "orderId", order.getOrderId(),
            "productId", order.getProductId(),
            "payAmount", order.getPayAmount(),
            "paymentChannel", order.getPaymentChannel()
        ));
    }
}
```

```java
        // 2. 计算有效期
        LocalDateTime now = LocalDateTime.now();
        LocalDateTime expiresAt = config.getValidityDays() != null
            ? now.plusDays(config.getValidityDays())
            : null; // null表示永不过期

        // 3. 创建权益记录

            .entitlementId(generateEntitlementId())
            .userId(order.getUserId())
            .orderId(order.getOrderId())
            .productId(order.getProductId())
            .productName(order.getProductNameSnapshot())
            .productType(order.getProductType())
            .productConfig(config.toJson())
            .totalQuota(config.getTotalQuota())
            .usedQuota(0)
            .remainingQuota(config.getTotalQuota())
            .activatedAt(now)
            .expiresAt(expiresAt)
            .status(EntitlementStatus.ACTIVE)
            .source(EntitlementSource.PURCHASE)
            .build();
        entitlementRepository.save(entitlement);

        // 4. 根据类型开通
        switch (order.getProductType()) {
            case COUNT_PACK:
                // 额度写入用户额度表（复用额度管控引擎）
                quotaService.grantQuota(
                    order.getUserId(),
                    config.getQuotaType(),  // AI_CHAT, PHOTO_SEARCH, ESSAY_REVIEW 等
                    config.getTotalQuota(),
                    entitlement.getEntitlementId(),
                    expiresAt
                );
                break;

            case TIME_PACK:
                // 时间包：设置功能解锁标记
                contentAccessService.unlockTimedContent(
                    order.getUserId(),
                    config.getContentIds(),
                    now,
                    expiresAt
                );
                break;

            case CONTENT_PACK:
                // 内容包：解锁内容权限
                contentAccessService.unlockPermanentContent(
                    order.getUserId(),
                    config.getContentIds()
                );
                break;

            case ENHANCED_SERVICE:
                // 增强服务：标记可用
                enhancedServiceFeatureService.enable(
                    order.getUserId(),
                    config.getServiceCode(),
                    config.getTotalQuota(),
                    expiresAt
                );
                break;
        }

        // 5. 记录额度变更日志
        quotaChangeLogService.log(
            entitlement.getEntitlementId(),
            order.getUserId(),
            QuotaChangeType.ACTIVATE,
            config.getTotalQuota(),
            0,
            config.getTotalQu(),
            "购买增值服务: " + order.getProductNameSnapshot()
        );

        // 6. 更新订单状态
        order.setStatus(OrderStatus.ENTITLEMENT_ACTIVATED);
        order.setEntitlementId(entitlement.getEntitlementId());
        orderRepository.save(order);

        return entitlement;
    }

```

```
    │
    ▼
[1] 额度校验拦截器（AOP切面）
    │
    ├─ 检查是否为会员（会员优先消费会员额度）
```

### 7.3 额度校验注解与切面

```java
/**
 * 额度校验注解
 * 标注在需要消费增值服务额度的接口上
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface QuotaRequired {
    /** 额度类型 */
    QuotaType value();
    /** 每次消耗量 */
    int cost() default 1;
    /** 额度不足时是否阻塞（false=仅记录，允许透支） */
    boolean blockIfInsufficient() default true;
    /** 自定义提示商品ID（引导购买特定商品） */
    String hintProductId() default "";
}

/**
 * 额度校验切面
 */
@Aspect
@Component
public class QuotaCheckAspect {

    @Around("@annotation(quotaRequired)")
    public Object checkQuota(ProceedingJoinPoint pjp, QuotaRequired quotaRequired)
            throws Throwable {

        Long userId = UserContext.getCurrentUserId();
        QuotaType quotaType = quotaRequired.value();
        int cost = quotaRequired.cost();

        // 1. 尝试扣减会员额度
        QuotaCheckResult memberResult = quotaService
            .tryDeductFromMembership(userId, quotaType, cost);
        if (memberResult.isSuccess()) {
            // 会员额度扣减成功，放行
            Object result = pjp.proceed();
            // 业务成功后确认扣减（异步）
            quotaService.confirmDeduction(memberResult.getDeductionId());
            return result;
        }

        // 2. 尝试扣减增值服务额度
        QuotaCheckResult addonResult = quotaService
            .tryDeductFromAddon(userId, quotaType, cost);
        if (addonResult.isSuccess()) {
            Object result = pjp.proceed();
            quotaService.confirmDeduction(addonResult.getDeductionId());
            return result;
        }

        // 3. 两边都没额度
        if (quotaRequired.blockIfInsufficient()) {
            // 返回额度不足 + 引导信息
            ProductHint hint = quotaService.getProductHint(
                userId, quotaType, quotaRequired.hintProductId());
            throw new QuotaInsufficientException(
                "额度不足",
                hint.getProductId(),
                hint.getProductName(),
                hint.getCurrentPrice(),
                hint.getPurchaseUrl()
            );
        }

        // 不阻塞，透支放行
        return pjp.proceed();
    }
}
```

### 9.3 预扣减模式实现

```java
/**
 * 预扣减服务
 * 解决"扣减成功但业务失败"导致额度浪费的问题
 */
@Service
public class PreDeductionService {

    /**
     * 预扣减额度
     * @return deductionId 用于后续确认或回滚
     */
    public String preDeduct(Long userId, QuotaType quotaType, int cost) {
        String deductionId = generateDeductionId();

        // Redis原子扣减（高性能）
        String redisKey = "quota:addon:" + userId + ":" + quotaType.name();
        Long remaining = redisTemplate.opsForValue().decrement(redisKey, cost);

        if (remaining == null || remaining < 0) {
            // 额度不足，回滚Redis
            redisTemplate.opsForValue().increment(redisKey, cost);
            throw new QuotaInsufficientException(quotaType);
        }

        // 记录预扣减（TTL 5分钟，超时自动回滚）
        String freezeKey = "deduction:freeze:" + deductionId;
        redisTemplate.opsForValue().set(freezeKey,
            String.valueOf(cost), 5, TimeUnit.MINUTES);

        return deductionId;
    }

    /**
     * 确认扣减
     */
    public void confirm(String deductionId, Long userId,
                        QuotaType quotaType, int cost, String bizId) {
        String freezeKey = "deduction:freeze:" + deductionId;

        // 检查预扣减是否还存在（可能已超时回滚）
        String frozenCost = redisTemplate.opsForValue().getAndDelete(freezeKey);
        if (frozenCost == null) {
            log.warn("预扣减已过期，尝试重新扣减: deductionId={}", deductionId);
            // 重新扣减
            preDeduct(userId, quotaType, cost);
        }

        // 异步写入DB变更日志
        quotaChangeLogService.logAsync(userId, quotaType, cost, bizId);
    }

    /**
     * 回滚预扣减
     */
    public void rollback(String deductionId, Long userId,
                         QuotaType quotaType, int cost) {
        String freezeKey = "deduction:freeze:" + deductionId;
        redisTemplate.delete(freezeKey);

        // Redis归还额度
        String redisKey = "quota:addon:" + userId + ":" + quotaType.name();
        redisTemplate.opsForValue().increment(redisKey, cost);
    }
}
```

```java
@Scheduled(fixedDelay = 60000) // 每分钟执行
public void paymentReconciliation() {

    List<AddonOrder> pendingOrders = orderRepository
        .findByStatusAndCreatedAtBefore(
            OrderStatus.PAYMENT_PROCESSING,

                .getChannel(order.getPaymentChannel())
                .queryPayment(order.getOrderNo());

                    break;

                            .isBefore(LocalDateTime.now().minusMinutes(30))) {
                        order.setStatus(OrderStatus.PAYMENT_TIMEOUT);
                        orderRepository.save(order);
                    }
                    break;
            }
        } catch (Exception e) {
            log.error("补单查询异常: orderId={}", order.getOrderId(), e);
        }
    }
}
```

```dart
  static const _cacheTTL = Duration(minutes: 5);

  Future<int> getRemainingQuota(QuotaType type) async {
    final cache = _getCache(type);

    if (cache != null && !cache.isExpired &&
        DateTime.now().difference(cache.cachedAt) < _cacheTTL) {
      return cache.remainingQuota;
    }

    // 刷新缓存
    await refreshCache();
    return _getCache(type)?.remainingQuota ?? 0;
  }

  }

  /// 本地预估扣减（避免频繁请求服务端）
  void localDeduct(QuotaType type, int cost) {
    final cache = _getCache(type);
    if (cache != null) {
```
