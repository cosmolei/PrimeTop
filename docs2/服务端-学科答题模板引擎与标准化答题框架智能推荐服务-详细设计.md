## 1. 模块概述

### 1.1 功能定位

学科答题模板引擎是 PrimeTop 平台针对中国中小学考试场景中的**标准化答题需求**而设计的核心服务。在中国教育体系中，不同学科、不同题型的考试答题存在公认的**答题框架与规范格式**（如数学证明题的"因为…所以…"三段论格式、物理实验题的"目的-原理-步骤-结论"结构、政治材料分析题的"原理+材料分析+结论"模板等）。

本引擎负责：

1. **模板库管理**：建立覆盖全学科、全题型的标准化答题模板库
2. **智能匹配**：根据学生当前练习的题目类型、学科、考点，自动推荐最合适的答题模板
3. **模板辅助答题**：在 AI 辅导解题过程中，将答题模板融入解析步骤，引导学生按规范格式组织答案
4. **掌握度追踪**：追踪学生对各类答题模板的熟练程度，针对性推荐薄弱模板进行专项训练
5. **模板与考点关联**：将答题模板与考纲考点建立映射，帮助学生在复习时快速定位所需模板

### 1.2 核心价值

| 维度 | 价值 |
|------|------|
| 学生端 | 提供可学习的标准化答题框架，减少考试中因格式不规范、步骤缺失导致的失分 |
| AI辅导端 | 为 AI 解题提供结构化输出模板，使 AI 生成的解析更规范、更贴近考试要求 |
| 教研端 | 沉淀优秀答题方法论，形成可复用的教学资产 |
| 数据端 | 通过模板掌握度分析，补全学情画像中"答题规范性"维度 |

### 2.2 模块在系统中的位置

答题模板引擎作为**跨模块的基础能力服务**，不直接面向 C 端用户暴露独立入口，而是通过以下模块间接调用：

| 调用方 | 调用场景 | 调用方式 |
|--------|---------|---------|
| AI辅导引擎 | 解题时注入答题模板结构 | `getTemplateForQuestion()` |
| 拍题答疑 | 生成结构化解析时使用对应模板 | `matchTemplate()` |
| 考试模拟 | 模拟考试评分参照模板步骤 | `getScoringTemplate()` |
| 考点梳理 | 展示考点关联的答题模板 | `getTemplatesByKnowledgePoint()` |
| 学情分析 | 统计答题规范性得分 | `getTemplateMastery()` |
| 客户端 | 展示答题模板学习卡片 | `listTemplates()` |
| 内容后台 | 教研人员管理模板库 | CRUD API |

## 3. 数据结构设计

### 3.1 核心表结构

#### 3.1.1 `answer_template` - 答题模板主表

```sql
CREATE TABLE `answer_template` (
  `id` BIGINT NOT NULL COMMENT '模板ID',
  `template_code` VARCHAR(64) NOT NULL COMMENT '模板编码，如 MATH-GEO-PROOF-001',
  `template_name` VARCHAR(128) NOT NULL COMMENT '模板名称，如"几何证明题三段论格式"',
  `subject_code` VARCHAR(16) NOT NULL COMMENT '学科编码: MATH/PHYS/CHEM/BIO/CHINESE/ENGLISH/HISTORY/GEO/POLITICS',
  `stage_code` VARCHAR(16) NOT NULL COMMENT '学段: PRIMARY/JUNIOR/SENIOR',
  `grade_codes` JSON NOT NULL COMMENT '适用年级列表: ["G7","G8","G9"]',
  `question_type_code` VARCHAR(32) NOT NULL COMMENT '题型编码，如 PROOF/CALCULATION/EXPERIMENT/ANALYSIS/ESSAY',
  `knowledge_point_ids` JSON NOT NULL COMMENT '关联知识点ID列表',
  `exam_point_ids` JSON NULL COMMENT '关联考点ID列表',
  `textbook_edition_codes` JSON NULL COMMENT '适用教材版本: ["PEP","SUJIAO"]',
  `template_structure` JSON NOT NULL COMMENT '模板结构定义（核心，见3.2）',
  `scoring_rubric` JSON NULL COMMENT '评分细则，每步对应分值',
  `difficulty_level` TINYINT NOT NULL DEFAULT 3 COMMENT '模板掌握难度 1-5',
  `priority` INT NOT NULL DEFAULT 0 COMMENT '优先级（数字越大越优先推荐）',
  `example_content` TEXT NULL COMMENT '标准示例（LaTeX/Markdown格式）',
  `counter_example` TEXT NULL COMMENT '常见错误示例',
  `status` VARCHAR(16) NOT NULL DEFAULT 'DRAFT' COMMENT '状态: DRAFT/REVIEWING/PUBLISHED/OFFLINE',
  `version` INT NOT NULL DEFAULT 1 COMMENT '版本号',
  `creator_id` BIGINT NOT NULL COMMENT '创建人ID',
  `reviewer_id` BIGINT NULL COMMENT '审核人ID',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  `published_at` DATETIME NULL COMMENT '发布时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_template_code` (`template_code`),
  KEY `idx_subject_stage` (`subject_code`, `stage_code`),
  KEY `idx_question_type` (`question_type_code`),
  KEY `idx_status_priority` (`status`, `priority`),
  KEY `idx_created_at` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='答题模板主表';
```

### 3.2 模板结构定义 (template_structure)

模板采用 JSON 结构化定义，支持变量占位、条件分支和循环步骤。

#### 3.2.1 基础结构

```json
{
  "templateId": "MATH-GEO-PROOF-001",
  "templateName": "几何证明题三段论格式",
  "version": "1.0",
  "variables": [
    {
      "name": "given_conditions",
      "type": "list[text]",
      "description": "题目已知条件列表",
      "required": true
    },
    {
      "name": "to_prove",
      "type": "text",
      "description": "需要证明的结论",
      "required": true
    },
    {
      "name": "theorem_chain",
      "type": "list[object]",
      "description": "定理推导链",
      "itemSchema": {
        "step": "text",
        "reason": "text",
        "fromSteps": "list[int]"
      },
      "required": true
    }
  ],
  "steps": [
    {
      "order": 1,
      "code": "GIVEN",
      "title": "写出已知条件",
      "template": "已知：{{given_conditions | join('；')}}",
      "tips": "将题目中所有已知条件完整列出，不要遗漏隐含条件",
      "scoringWeight": 0.15,
      "optional": false
    },
    {
      "order": 2,
      "code": "TO_PROVE",
      "title": "写出求证结论",
      "template": "求证：{{to_prove}}",
      "tips": "明确写出要证明的结论",
      "scoringWeight": 0.05,
      "optional": false
    },
    {
      "order": 3,
      "code": "PROOF",
      "title": "证明过程",
      "template": "证明：\n{{#each theorem_chain}}\n步骤{{@index}}：{{this.step}}\n理由：{{this.reason}}\n{{#if this.fromSteps}}（由{{#each this.fromSteps}}步骤{{this}}{{#unless @last}}、{{/unless}}{{/each}}得出）{{/if}}\n{{/each}}",
      "tips": "每一步推理都需标注依据的定理或已知条件",
      "scoringWeight": 0.65,
      "optional": false
    },
    {
      "order": 4,
      "code": "CONCLUSION",
      "title": "结论",
      "template": "∴ {{to_prove}}",
      "tips": "使用∴符号标注最终结论",
      "scoringWeight": 0.15,
      "optional": false
    }
  ],
  "constraints": {
    "minSteps": 3,
    "maxSteps": 20,
    "requiredSymbols": ["∵", "∴"],
    "formatRules": [
      "推理链条不得跳步",
      "每一步必须标注理由"
    ]
  }
}
```

### 5.1 匹配流程

```text
└─────────────────────────────┘
```

### 5.2 匹配评分公式

```
finalScore = w1 * typeScore + w2 * knowledgeScore + w3 * semanticScore + w4 * personalScore

其中:
  typeScore:      题型完全匹配=1.0, 相关题型=0.5, 不匹配=0   权重 w1=0.35
  knowledgeScore: Jaccard(题目知识点, 模板知识点)              权重 w2=0.30
  semanticScore:  Cosine(题目向量, 模板描述向量)               权重 w3=0.15
  personalScore:  f(掌握度, 使用频率, 教材匹配)                 权重 w4=0.20
```

### 5.3 匹配引擎核心代码

```java
@Service
public class TemplateMatchEngine {

    @Autowired
    private AnswerTemplateRepository templateRepo;
    
    @Autowired
    private EmbeddingService embeddingService;
    
    @Autowired
    private TemplateMasteryRepository masteryRepo;
    
    private static final double MIN_MATCH_SCORE = 0.30;
    private static final int MAX_RECOMMENDATIONS = 5;
    
    // 权重配置
    private static final double W_TYPE = 0.35;
    private static final double W_KNOWLEDGE = 0.30;
    private static final double W_SEMANTIC = 0.15;
    private static final double W_PERSONAL = 0.20;
    
    /**
     * 智能匹配答题模板
     */
    public MatchResult matchTemplate(TemplateMatchRequest request) {
        // Step 1: 基础过滤
        List<AnswerTemplate> candidates = templateRepo.findPublishedByCriteria(
            request.getSubjectCode(),
            request.getStageCode(),
            request.getGradeCode(),
            request.getQuestionTypeCode(),
            request.getKnowledgePointIds()
        );
        
        if (candidates.isEmpty()) {
            return MatchResult.empty();
        }
        
        // 获取学生掌握度
        Map<Long, AnswerTemplateMastery> masteryMap = getStudentMasteryMap(
            request.getStudentId(), 
            candidates.stream().map(AnswerTemplate::getId).toList()
        );
        
        // 计算题目语义向量
        float[] questionVector = embeddingService.embed(
            request.getQuestionText() != null ? request.getQuestionText() : ""
        );
        
        // Step 2-4: 逐模板评分
        List<TemplateScore> scores = candidates.stream()
            .map(tpl -> calculateScore(tpl, request, masteryMap.get(tpl.getId()), questionVector))
            .filter(s -> s.getFinalScore() >= MIN_MATCH_SCORE)
            .sorted(Comparator.comparingDouble(TemplateScore::getFinalScore).reversed())
            .limit(MAX_RECOMMENDATIONS)
            .collect(Collectors.toList());
        
        // 生成推荐理由
        scores.forEach(this::enrichWithReason);
        
        // 选择最佳推荐
        Long recommendedId = scores.isEmpty() ? null : scores.get(0).getTemplateId();
        
        return MatchResult.builder()
            .matchedTemplates(scores)
            .recommendedTemplateId(recommendedId)
            .build();
    }
    
    private TemplateScore calculateScore(
            AnswerTemplate template,
            TemplateMatchRequest request,
            AnswerTemplateMastery mastery,
            float[] questionVector) {
        
        // 题型分
        double typeScore = calculateTypeScore(
            request.getQuestionTypeCode(), 
            template.getQuestionTypeCode()
        );
        
        // 知识点覆盖分
        double knowledgeScore = calculateKnowledgeScore(
            request.getKnowledgePointIds(),
            template.getKnowledgePointIds()
        );
        
        // 语义相似度
        double semanticScore = calculateSemanticScore(template, questionVector);
        
        // 个性化分
        double personalScore = calculatePersonalScore(template, mastery, request);
        
        double finalScore = W_TYPE * typeScore 
                          + W_KNOWLEDGE * knowledgeScore 
                          + W_SEMANTIC * semanticScore 
                          + W_PERSONAL * personalScore;
        
        return TemplateScore.builder()
            .templateId(template.getId())
            .templateName(template.getTemplateName())
            .typeScore(typeScore)
            .knowledgeScore(knowledgeScore)
            .semanticScore(semanticScore)
            .personalScore(personalScore)
            .finalScore(finalScore)
            .studentMastery(mastery != null ? mastery.getMasteryLevel() : null)
            .build();
    }
    
    /**
     * 知识点覆盖率 - Jaccard相似度
     */
    private double calculateKnowledgeScore(
            List<Long> questionKpIds, 
            List<Long> templateKpIds) {
        if (questionKpIds == null || questionKpIds.isEmpty() 
            || templateKpIds == null || templateKpIds.isEmpty()) {
            return 0.0;
        }
        Set<Long> intersection = new HashSet<>(questionKpIds);
        intersection.retainAll(templateKpIds);
        
        Set<Long> union = new HashSet<>(questionKpIds);
        union.addAll(templateKpIds);
        
        return (double) intersection.size() / union.size();
    }
    
    /**
     * 个性化评分
     */
    private double calculatePersonalScore(
            AnswerTemplate template,
            AnswerTemplateMastery mastery,
            TemplateMatchRequest request) {
        double score = 0.5; // 基础分
        
        // 掌握度因子：掌握度低但模板匹配 → 推荐学习
        if (mastery != null) {
            double masteryLevel = mastery.getMasteryLevel().doubleValue();
            if (masteryLevel < 0.6) {
                score += 0.3 * (1 - masteryLevel); // 越不熟练越推荐
            } else if (masteryLevel > 0.9) {
                score -= 0.1; // 已掌握的不优先推荐
            }
        } else {
            // 未使用过的模板适度加权
            score += 0.15;
        }
        
        // 教材版本匹配
        if (request.getTextbookEditionCode() != null 
            && template.getTextbookEditionCodes() != null
            && template.getTextbookEditionCodes().contains(request.getTextbookEditionCode())) {
            score += 0.2;
        }
        
        // 模板优先级
        score += template.getPriority() * 0.001;
        
        return Math.min(score, 1.0);
    }
    
    /**
     * 推荐理由生成
     */
    private void enrichWithReason(TemplateScore score) {
        StringBuilder reason = new StringBuilder();
        
        if (score.getTypeScore() == 1.0) {
            reason.append("题型完全匹配");
        } else if (score.getTypeScore() > 0) {
            reason.append("题型相关");
        }
        
        if (score.getKnowledgeScore() > 0.7) {
            reason.append(reason.length() > 0 ? "，" : "")
                  .append("知识点覆盖率")
                  .append(Math.round(score.getKnowledgeScore() * 100))
                  .append("%");
        }
        
        if (score.getStudentMastery() != null) {
            double m = score.getStudentMastery();
            if (m < 0.4) {
                reason.append("。当前掌握度偏低，强烈建议使用模板练习");
            } else if (m < 0.7) {
                reason.append("。掌握度中等，建议继续使用模板巩固");
            }
        } else {
            reason.append("。尚未学习此模板，建议了解");
        }
        
        score.setMatchReason(reason.toString());
    }
}
```

### 6.2 渲染服务核心代码

```java
@Service
public class TemplateRenderService {

    private static final Pattern VAR_PATTERN = Pattern.compile("\\{\\{([^}]+)\\}\\}");
    private static final Pattern EACH_PATTERN = Pattern.compile(
        "\\{\\{#each\\s+(\\w+)\\}\\}(.*?)\\{\\{/each\\}\\}", Pattern.DOTALL
    );
    private static final Pattern IF_PATTERN = Pattern.compile(
        "\\{\\{#if\\s+(\\w+)\\}\\}(.*?)(?:\\{\\{else\\}\\}(.*?))?\\{\\{/if\\}\\}", Pattern.DOTALL
    );
    
    /**
     * 渲染答题模板
     */
    public RenderResult render(
            AnswerTemplate template,
            Map<String, Object> variables,
            RenderFormat format,
            RenderOptions options) {
        
        // 1. 变量校验
        List<String> errors = validateVariables(template, variables);
        if (!errors.isEmpty()) {
            throw new TemplateRenderException("变量校验失败: " + String.join("; ", errors));
        }
        
        // 2. 逐步骤渲染
        StringBuilder rendered = new StringBuilder();
        List<RenderWarning> warnings = new ArrayList<>();
        
        for (TemplateStep step : template.getSteps()) {
            try {
                String stepContent = renderStep(step, variables);
                if (options.isIncludeTips() && step.getTips() != null) {
                    stepContent += "\n> 💡 " + step.getTips();
                }
                rendered.append(stepContent).append("\n\n");
            } catch (Exception e) {
                warnings.add(new RenderWarning(
                    step.getOrder(), 
                    "步骤渲染异常: " + e.getMessage()
                ));
                // 可选步骤渲染失败时使用占位符
                rendered.append("[步骤").append(step.getOrder()).append("渲染失败]\n\n");
            }
        }
        
        // 3. 格式化处理
        String formatted = formatOutput(rendered.toString(), format);
        
        // 4. 符号规范化
        formatted = normalizeSymbols(formatted);
        
        return RenderResult.builder()
            .renderedContent(formatted)
            .format(format)
            .formatVersion("1.0")
            .warnings(warnings)
            .build();
    }
    
    /**
     * 渲染单个步骤
     */
    private String renderStep(TemplateStep step, Map<String, Object> variables) {
        String template = step.getTemplateText();
        
        // 处理循环 {{#each}}
        template = processEach(template, variables);
        
        // 处理条件 {{#if}}
        template = processIf(template, variables);
        
        // 处理变量 {{var}} 和过滤器
        template = processVariables(template, variables);
        
        return template;
    }
    
    private String processEach(String template, Map<String, Object> variables) {
        Matcher matcher = EACH_PATTERN.matcher(template);
        StringBuffer result = new StringBuffer();
        
        while (matcher.find()) {
            String listName = matcher.group(1);
            String body = matcher.group(2);
            Object listObj = variables.get(listName);
            
            if (listObj instanceof List<?> list && !list.isEmpty()) {
                StringBuilder replacement = new StringBuilder();
                for (int i = 0; i < list.size(); i++) {
                    String itemBody = body;
                    // 替换 @index
                    itemBody = itemBody.replace("{{@index}}", String.valueOf(i + 1));
                    // 替换 this.xxx
                    if (list.get(i) instanceof Map<?, ?> itemMap) {
                        for (Map.Entry<?, ?> entry : itemMap.entrySet()) {
                            itemBody = itemBody.replace(
                                "{{this." + entry.getKey() + "}}",
                                String.valueOf(entry.getValue())
                            );
                        }
                    } else {
                        itemBody = itemBody.replace("{{this}}", String.valueOf(list.get(i)));
                    }
                    replacement.append(itemBody);
                }
                matcher.appendReplacement(result, Matcher.quoteReplacement(replacement.toString()));
            }
        }
        matcher.appendTail(result);
        return result.toString();
    }
    
    /**
     * 数学符号规范化
     */
    private String normalizeSymbols(String content) {
        return content
            .replace("因为", "∵")
            .replace("所以", "∴")
            .replace("角", "∠")
            .replace("三角形", "△")
            .replace("垂直于", "⊥")
            .replace("平行于", "∥")
            .replace("全等", "≅")
            .replace("相似", "∽");
    }
}
```

## 7. 掌握度计算引擎

### 7.1 掌握度模型

掌握度采用**加权移动平均**模型，综合考虑正确率、得分率、步骤完整度和时间衰减。

```
mastery = w_correct * correctnessRate 
        + w_score * avgScoreRate 
        + w_step * stepCompleteness
        * timeDecayFactor

参数:
  w_correct = 0.35   (按模板答题的正确率)
  w_score   = 0.35   (平均得分率)
  w_step    = 0.30   (步骤完成度)
  
  timeDecayFactor = max(0.5, exp(-daysSinceLastUse / 30))
  (30天未使用衰减到约37%，60天约14%，下限0.5保留基础值)
```

### 7.2 步骤级掌握度

```java
@Service
public class TemplateMasteryEngine {

    private static final double W_CORRECT = 0.35;
    private static final double W_SCORE = 0.35;
    private static final double W_STEP = 0.30;
    private static final double DECAY_HALF_LIFE_DAYS = 30.0;
    private static final double DECAY_FLOOR = 0.5;
    
    private static final double MASTERY_THRESHOLD_HIGH = 0.85;
    private static final double MASTERY_THRESHOLD_LOW = 0.50;
    
    /**
     * 更新学生模板掌握度
     */
    @Transactional
    public void updateMastery(TemplateUsageRecord record) {
        AnswerTemplateMastery mastery = masteryRepo
            .findByStudentIdAndTemplateId(record.getStudentId(), record.getTemplateId())
            .orElseGet(() -> createNewMastery(record));
        
        // 更新计数
        mastery.setUsageCount(mastery.getUsageCount() + 1);
        if (record.getScore() != null) {
            BigDecimal scoreRate = record.getScore().divide(
                record.getMaxScore(), 4, RoundingMode.HALF_UP
            );
            if (scoreRate.compareTo(new BigDecimal("0.8")) >= 0) {
                mastery.setCorrectCount(mastery.getCorrectCount() + 1);
            } else if (scoreRate.compareTo(new BigDecimal("0.5")) >= 0) {
                mastery.setPartialCorrectCount(mastery.getPartialCorrectCount() + 1);
            } else {
                mastery.setIncorrectCount(mastery.getIncorrectCount() + 1);
            }
            // 更新得分
            updateAvgScore(mastery, record.getScore());
            mastery.setLastScore(record.getScore());
        }
        mastery.setLastUsedAt(LocalDateTime.now());
        
        // 更新步骤级掌握度
        updateStepMastery(mastery, record);
        
        // 重新计算整体掌握度
        double newMastery = calculateMastery(mastery);
        mastery.setMasteryLevel(BigDecimal.valueOf(newMastery));
        
        // 识别薄弱步骤
        mastery.setWeakSteps(identifyWeakSteps(mastery));
        
        masteryRepo.save(mastery);
        
        // 发送掌握度变更事件
        eventPublisher.publishEvent(new TemplateMasteryUpdatedEvent(
            record.getStudentId(), record.getTemplateId(), newMastery
        ));
    }
    
    /**
     * 计算掌握度
     */
    private double calculateMastery(AnswerTemplateMastery mastery) {
        int total = mastery.getCorrectCount() 
                  + mastery.getPartialCorrectCount() 
                  + mastery.getIncorrectCount();
        
        if (total == 0) return 0.0;
        
        // 正确率 (正确算1.0, 部分正确算0.5, 错误算0)
        double correctnessRate = (
            mastery.getCorrectCount() * 1.0 
          + mastery.getPartialCorrectCount() * 0.5
        ) / total;
        
        // 得分率
        double scoreRate = mastery.getAvgScore() != null 
            ? mastery.getAvgScore().doubleValue() / 10.0 
            : 0.0;
        
        // 步骤完成度
        double stepCompleteness = calculateStepCompleteness(mastery);
        
        // 时间衰减因子
        double decayFactor = calculateTimeDecay(mastery.getLastUsedAt());
        
        double masteryValue = (
            W_CORRECT * correctnessRate 
          + W_SCORE * scoreRate 
          + W_STEP * stepCompleteness
        ) * decayFactor;
        
        // 与历史值做平滑 (防止抖动)
        double historical = mastery.getMasteryLevel().doubleValue();
        double smoothed = historical * 0.3 + masteryValue * 0.7;
        
        return Math.max(0.0, Math.min(1.0, smoothed));
    }
    
    /**
     * 时间衰减
     */
    private double calculateTimeDecay(LocalDateTime lastUsed) {
        if (lastUsed == null) return DECAY_FLOOR;
        long daysSince = Duration.between(lastUsed, LocalDateTime.now()).toDays();
        double decay = Math.exp(-daysSince / DECAY_HALF_LIFE_DAYS);
        return Math.max(DECAY_FLOOR, decay);
    }
    
    /**
     * 步骤完成度
     */
    private double calculateStepCompleteness(AnswerTemplateMastery mastery) {
        if (mastery.getStepMastery() == null) return 0.5;
        Map<String, Double> stepMap = mastery.getStepMastery();
        if (stepMap.isEmpty()) return 0.5;
        
        double avg = stepMap.values().stream()
            .mapToDouble(Double::doubleValue)
            .average()
            .orElse(0.5);
        return avg;
    }
    
    /**
     * 识别薄弱步骤
     */
    private List<Integer> identifyWeakSteps(AnswerTemplateMastery mastery) {
        if (mastery.getStepMastery() == null) return Collections.emptyList();
        
        return mastery.getStepMastery().entrySet().stream()
            .filter(e -> e.getValue() < MASTERY_THRESHOLD_LOW)
            .map(e -> Integer.parseInt(e.getKey().replace("step", "")))
            .sorted()
            .collect(Collectors.toList());
    }
    
    private void updateStepMastery(AnswerTemplateMastery mastery, TemplateUsageRecord record) {
        Map<String, Double> stepMastery = mastery.getStepMastery();
        if (stepMastery == null) {
            stepMastery = new HashMap<>();
            mastery.setStepMastery(stepMastery);
        }
        
        if (record.getStepScores() == null) return;
        
        for (Map.Entry<Integer, BigDecimal> entry : record.getStepScores().entrySet()) {
            String key = "step" + entry.getKey();
            BigDecimal stepMax = record.getStepMaxScores().get(entry.getKey());
            if (stepMax == null || stepMax.compareTo(BigDecimal.ZERO) == 0) continue;
            
            double rate = entry.getValue().divide(stepMax, 4, RoundingMode.HALF_UP).doubleValue();
            
            // 指数移动平均
            double oldVal = stepMastery.getOrDefault(key, 0.5);
            double newVal = oldVal * 0.4 + rate * 0.6;
            stepMastery.put(key, newVal);
        }
    }
    
    private void updateAvgScore(AnswerTemplateMastery mastery, BigDecimal score) {
        if (mastery.getAvgScore() == null) {
            mastery.setAvgScore(score);
        } else {
            // 增量平均
            int n = mastery.getUsageCount();
            BigDecimal newAvg = mastery.getAvgScore()
                .multiply(BigDecimal.valueOf(n - 1))
                .add(score)
                .divide(BigDecimal.valueOf(n), 2, RoundingMode.HALF_UP);
            mastery.setAvgScore(newAvg);
        }
    }
    
    private AnswerTemplateMastery createNewMastery(TemplateUsageRecord record) {
        AnswerTemplateMastery m = new AnswerTemplateMastery();
        m.setStudentId(record.getStudentId());
        m.setTemplateId(record.getTemplateId());
        m.setMasteryLevel(BigDecimal.ZERO);
        m.setUsageCount(0);
        m.setCorrectCount(0);
        m.setPartialCorrectCount(0);
        m.setIncorrectCount(0);
        m.setStepMastery(new HashMap<>());
        return m;
    }
}
```

### 9.3 模板合规性校验

AI 生成内容后，需要校验其是否符合模板结构：

```java
@Service
public class TemplateComplianceChecker {
    
    /**
     * 校验AI输出是否符合模板结构
     */
    public ComplianceResult check(String aiOutput, AnswerTemplate template) {
        List<ComplianceIssue> issues = new ArrayList<>();
        
        // 1. 检查必需步骤是否都存在
        for (TemplateStep step : template.getRequiredSteps()) {
            if (!containsStep(aiOutput, step)) {
                issues.add(new ComplianceIssue(
                    ComplianceLevel.ERROR,
                    step.getOrder(),
                    "缺少必需步骤：" + step.getTitle()
                ));
            }
        }
        
        // 2. 检查步骤顺序
        List<Integer> foundOrders = extractStepOrders(aiOutput, template);
        if (!isAscending(foundOrders)) {
            issues.add(new ComplianceIssue(
                ComplianceLevel.WARN,
                null,
                "步骤顺序不符合模板要求"
            ));
        }
        
        // 3. 检查必需符号
        if (template.getConstraints() != null) {
            for (String symbol : template.getConstraints().getRequiredSymbols()) {
                if (!aiOutput.contains(symbol)) {
                    issues.add(new ComplianceIssue(
                        ComplianceLevel.WARN,
                        null,
                        "缺少必需符号：" + symbol
                    ));
                }
            }
        }
        
        // 4. 检查步骤间逻辑连贯性 (简单规则)
        checkLogicalCoherence(aiOutput, template, issues);
        
        boolean isCompliant = issues.stream()
            .noneMatch(i -> i.getLevel() == ComplianceLevel.ERROR);
        
        return new ComplianceResult(isCompliant, issues);
    }
    
    private boolean containsStep(String output, TemplateStep step) {
        // 基于关键词匹配
        String lowerOutput = output.toLowerCase();
        return lowerOutput.contains(step.getTitle().toLowerCase())
            || lowerOutput.contains("步骤" + step.getOrder())
            || lowerOutput.contains(step.getCode().toLowerCase());
    }
}
```

## 10. 错误处理与降级策略

### 10.1 错误码定义

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|-----------|------|----------|
| `TEMPLATE_NOT_FOUND` | 404 | 模板不存在 | 返回空列表，AI走通用解析流程 |
| `TEMPLATE_OFFLINE` | 410 | 模板已下线 | 清除缓存，重新匹配 |
| `TEMPLATE_RENDER_FAILED` | 500 | 模板渲染异常 | 返回模板原文，记录异常日志 |
| `TEMPLATE_VAR_MISSING` | 422 | 必填变量缺失 | 返回缺失字段列表 |
| `TEMPLATE_MATCH_EMPTY` | 200 | 无匹配模板 | 正常情况，调用方降级处理 |
| `MASTERY_CALC_ERROR` | 500 | 掌握度计算异常 | 使用上次值，记录日志 |
| `TEMPLATE_VERSION_CONFLICT` | 409 | 版本冲突 | 提示刷新后重试 |

```java
@Service
public class TemplateServiceFallback {
    
    /**
     * 模板匹配降级：当匹配引擎不可用时
     */
    public MatchResult fallbackMatch(TemplateMatchRequest request) {
        // 降级为简单规则匹配：仅按学科+题型
        List<AnswerTemplate> basic = templateRepo.findBasicMatch(
            request.getSubjectCode(),
            request.getQuestionTypeCode()
        );
        
        if (basic.isEmpty()) {
            // 完全无匹配：返回空，AI使用通用Prompt
            return MatchResult.empty();
        }
        
        // 返回第一个，不计算分数
        return MatchResult.simple(basic.get(0));
    }
    
    /**
     * 模板渲染降级：当渲染引擎异常时
     */
    public String fallbackRender(AnswerTemplate template) {
        // 返回模板的纯文本步骤列表
        StringBuilder sb = new StringBuilder();
        sb.append("答题参考框架：\n");
        for (TemplateStep step : template.getSteps()) {
            sb.append(step.getOrder())
              .append(". ")
              .append(step.getTitle())
              .append("\n");
        }
        return sb.toString();
    }
    
    /**
     * 掌握度降级：当计算异常时
     */
    public double fallbackMastery(AnswerTemplateMastery mastery) {
        // 使用历史值或默认值
        if (mastery != null && mastery.getMasteryLevel() != null) {
            return mastery.getMasteryLevel().doubleValue();
        }
        return 0.5; // 默认中等
    }
}
```
