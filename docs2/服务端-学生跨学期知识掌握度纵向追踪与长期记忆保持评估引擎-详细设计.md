# 服务端-学生跨学期知识掌握度纵向追踪与长期记忆保持评估引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责在**月、学期、学年**等中长期时间尺度上，持续追踪学生各知识点/章节/学科层面的掌握度变化趋势，量化评估长期记忆保持效果，检测知识衰变模式与级联风险，并自动触发主动补强干预。

与现有模块的职责边界：

| 现有模块 | 职责 | 时间尺度 | 与本引擎的关系 |
| --- | --- | --- | --- |
| 间隔重复算法与遗忘曲线复习调度 | 单题/单卡片的复习时间安排 | 小时~天 | 微观调度，不关注章节级宏观趋势 |
| 练习答题实时批改与知识点掌握度增量更新 | 答题后实时更新掌握度 | 秒级 | 本引擎的数据生产者 |
| 多渠道学习数据融合与统一知识掌握度计算 | 融合多源数据计算当前掌握度 | 当前快照 | 本引擎的数据源 |
| 学生假期学习衰减评估与开学前唤醒 | 寒暑假特定场景的衰减评估 | 假期窗口 | 场景特定的衰减处理，本引擎提供通用基座 |
| 学习效果量化追踪与教育价值归因分析 | 产品功能效果归因 | 阶段性 | 关注"产品是否有效"，本引擎关注"学生记忆是否持久" |
| 学生知识掌握度数据可信度评估 | 掌握度数据的可信度 | 当前快照 | 本引擎的置信度校准来源 |

**本引擎填补的空白：** 从"当前掌握度快照"到"长期记忆健康度"之间的纵向追踪与分析能力。

### 1.2 核心问题

教育实践表明，学生知识掌握存在显著的"时间衰减效应"：

1. **自然遗忘**：无复习干预下，知识点掌握度约 30 天后衰减 15%-30%，90 天后衰减 30%-50%
2. **级联衰变**：前置知识衰减会导致后续知识掌握度连锁下降（如：分数运算衰减→分式方程连带下降）
3. **虚假掌握**：短期突击学习产生的掌握度衰减速度远快于渐进式学习
4. **学科差异**：程序性知识（解题步骤）比陈述性知识（概念定义）衰减更快
5. **个体差异**：不同学生的遗忘曲线参数差异可达 2-3 倍

现有系统只维护"当前掌握度"，无法回答：
- "这个学生 3 个月前学的分数运算现在还记得多少？"
- "哪些章节的知识点正在悄然衰减但尚未暴露？"
- "当前教学内容中，哪些前置知识已经不可靠了？"

### 1.3 设计目标

| 目标 | 衡量指标 | 优先级 |
| --- | --- | --- |
| 纵向追踪 | 每个知识点维护 ≥ 3 个月的历史掌握度时间序列 | P0 |
| 衰变检测 | 衰变异常知识点识别准确率 ≥ 85% | P0 |
| 级联预警 | 前置知识衰变 → 后续知识风险预测覆盖率 ≥ 80% | P1 |
| 主动干预 | 衰变触发自动推荐复习任务的及时率 ≥ 90% | P1 |
| 长效评估 | 学期末知识保持率报告生成覆盖所有活跃用户 | P2 |

### 1.4 适用范围

- **学段**：小学三年级至高中三年级（低年级以兴趣维持为主，知识衰变追踪意义有限）
- **学科**：全部学科（程序性知识优先）
- **前提条件**：学生在追踪起始时间点之前至少有 30 天学习记录和 ≥ 30 条有效答题数据
- **数据回溯**：支持基于历史答题记录的回溯建模，首次启用时可利用历史数据初始化

## 4. 核心算法与处理逻辑

### 4.1 掌握度时序快照采集

### 4.1.1 快照调度策略

每日凌晨执行全量快照，对活跃用户的知识点掌握度进行采样存储。

```python
"""
每日掌握度快照采集任务
执行时间：每日 02:00
执行频率：每日一次
"""

import asyncio
from datetime import date, timedelta
from typing import List

class MasterySnapshotJob:
    """掌握度快照采集定时任务"""

    BATCH_SIZE = 500  # 每批处理学生数
    STALE_THRESHOLD_DAYS = 7  # 超过此天数未活跃的用户降低快照频率

    def __init__(
        self,
        mastery_store: "MasteryStore",       # 掌握度存储（Redis/DB）
        snapshot_repo: "SnapshotRepository",  # 快照写入仓储
        user_service: "UserService",
    ):
        self._mastery = mastery_store
        self._snapshots = snapshot_repo
        self._users = user_service

    async def run_daily(self, target_date: date | None = None):
        """每日快照主流程"""
        target_date = target_date or date.today()
        stats = {"total": 0, "snapshots": 0, "skipped": 0, "errors": 0}

        async for batch in self._users.iter_active_students(batch_size=self.BATCH_SIZE):
            tasks = [self._snapshot_one(uid, target_date) for uid in batch]
            results = await asyncio.gather(*tasks, return_exceptions=True)

            for uid, result in zip(batch, results):
                stats["total"] += 1
                if isinstance(result, Exception):
                    stats["errors"] += 1
                    logger.error("快照失败 student=%s: %s", uid, result)
                elif result is True:
                    stats["snapshots"] += 1
                else:
                    stats["skipped"] += 1

        logger.info("掌握度快照完成 date=%s stats=%s", target_date, stats)
        return stats

    async def _snapshot_one(self, student_id: str, target_date: date) -> bool:
        """为单个学生创建当日掌握度快照"""
        # 1. 检查是否已有当日快照（幂等）
        if await self._snapshots.exists(student_id, target_date):
            return False

        # 2. 获取学生当前所有追踪知识点的掌握度
        mastery_map = await self._mastery.get_all_kp_mastery(student_id)
        if not mastery_map:
            return False  # 无追踪数据，跳过

        # 3. 获取上次快照（用于计算 delta）
        prev_date = target_date - timedelta(days=1)
        prev_map = await self._snapshots.get_batch(student_id, prev_date)

        # 4. 批量写入快照
        records = []
        for kp_id, mastery in mastery_map.items():
            prev_mastery = prev_map.get(kp_id)
            delta = None
            if prev_mastery is not None:
                delta = round(mastery.value - prev_mastery, 4)

            records.append(MasterySnapshot(
                student_id=student_id,
                knowledge_point_id=kp_id,
                snapshot_date=target_date,
                mastery_value=round(mastery.value, 4),
                confidence=mastery.confidence,
                data_source="practice",
                practice_count_7d=mastery.practice_7d,
                practice_count_30d=mastery.practice_30d,
                correct_rate_30d=mastery.correct_rate_30d,
                last_practice_at=mastery.last_practice,
                mastery_delta=delta,
            ))

        await self._snapshots.batch_insert(records)
        return True
```

### 4.2 衰变检测与量化

### 4.2.1 衰变检测算法

核心思路：对每个知识点的掌握度时序数据进行分析，检测是否存在统计显著的下降趋势。

```python
from dataclasses import dataclass
from enum import Enum
import numpy as np
from scipy import stats

class DecaySeverity(str, Enum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    CRITICAL = "critical"

class AlertType(str, Enum):
    NATURAL_DECAY = "natural_decay"        # 自然遗忘
    CASCADE_RISK = "cascade_risk"          # 级联风险
    FALSE_MASTERY = "false_mastery"        # 虚假掌握暴露
    STAGNATION = "stagnation"              # 停滞不前

@dataclass
class DecayDetectionResult:
    knowledge_point_id: str
    is_decaying: bool
    alert_type: AlertType | None
    severity: DecaySeverity | None
    mastery_peak: float
    peak_date: date
    mastery_current: float
    mastery_drop: float
    days_since_peak: int
    decay_rate_per_day: float
    predicted_mastery_30d: float
    confidence: float


class DecayDetector:
    """
    知识点衰变检测器

    算法流程：
    1. 提取最近 90 天的掌握度时序
    2. 识别历史峰值及峰值时间
    3. 计算峰值到当前的衰变量和衰变速率
    4. 使用线性回归斜率判定趋势显著性
    5. 基于衰变量+衰变速率+时间跨度分类严重度
    6. 使用个体遗忘参数预测 30 天后掌握度
    """

    PEAK_LOOKBACK_DAYS = 90        # 峰值回溯窗口
    MIN_DATA_POINTS = 5            # 最少数据点数
    TREND_P_VALUE_THRESHOLD = 0.05 # 趋势显著性阈值
    NATURAL_DECAY_THRESHOLD = 0.10 # 自然衰变触发阈值（10%）
    FALSE_MASTERY_DROP = 0.25      # 虚假掌握暴露阈值（25%急剧下降）

    async def detect(
        self,
        student_id: str,
        knowledge_point_id: str,
        forgetting_params: "StudentForgettingParams | None" = None,
    ) -> DecayDetectionResult:
        """执行衰变检测"""
        # 1. 获取时序数据
        series = await self._get_mastery_series(
            student_id, knowledge_point_id, days=self.PEAK_LOOKBACK_DAYS
        )
        if len(series) < self.MIN_DATA_POINTS:
            return self._no_decay_result(knowledge_point_id)

        dates = np.array([s.snapshot_date.toordinal() for s in series])
        values = np.array([float(s.mastery_value) for s in series])

        # 2. 识别峰值
        peak_idx = np.argmax(values)
        mastery_peak = float(values[peak_idx])
        peak_date_ordinal = int(dates[peak_idx])
        peak_date = date.fromordinal(peak_date_ordinal)

        # 只分析峰值之后的数据
        post_peak_mask = dates >= dates[peak_idx]
        post_peak_dates = dates[post_peak_mask]
        post_peak_values = values[post_peak_mask]

        if len(post_peak_values) < 3:
            return self._no_decay_result(knowledge_point_id, mastery_peak, peak_date)

        # 3. 计算衰变量
        mastery_current = float(post_peak_values[-1])
        mastery_drop = mastery_peak - mastery_current
        days_since_peak = int(dates[-1] - dates[peak_idx])

        # 4. 线性回归趋势检测（峰值后）
        slope, _, r_value, p_value, _ = stats.linregress(
            post_peak_dates - post_peak_dates[0], post_peak_values
        )

        decay_rate_per_day = float(slope)  # 负值表示衰变

        # 5. 判定是否衰变
        is_decaying = (
            mastery_drop >= self.NATURAL_DECAY_THRESHOLD
            and decay_rate_per_day < 0
            and p_value < self.TREND_P_VALUE_THRESHOLD
        )

        if not is_decaying:
            return self._no_decay_result(
                knowledge_point_id, mastery_peak, peak_date,
                mastery_current, mastery_drop, days_since_peak,
                decay_rate_per_day
            )

        # 6. 分类衰变类型
        alert_type = self._classify_alert_type(
            mastery_peak, mastery_drop, days_since_peak,
            decay_rate_per_day, series
        )

        # 7. 评估严重度
        severity = self._assess_severity(
            mastery_drop, decay_rate_per_day, days_since_peak, mastery_current
        )

        # 8. 预测 30 天后掌握度
        predicted_30d = self._predict_future_mastery(
            mastery_current, decay_rate_per_day, forgetting_params
        )

        return DecayDetectionResult(
            knowledge_point_id=knowledge_point_id,
            is_decaying=True,
            alert_type=alert_type,
            severity=severity,
            mastery_peak=mastery_peak,
            peak_date=peak_date,
            mastery_current=mastery_current,
            mastery_drop=round(mastery_drop, 4),
            days_since_peak=days_since_peak,
            decay_rate_per_day=round(decay_rate_per_day, 6),
            predicted_mastery_30d=round(predicted_30d, 4),
            confidence=round(1 - p_value, 3),
        )

    def _classify_alert_type(
        self, peak: float, drop: float, days: int,
        rate: float, series: list
    ) -> AlertType:
        """分类衰变类型"""
        # 虚假掌握：短期内急剧下降（高峰值 + 快速跌落）
        if peak >= 0.8 and drop >= self.FALSE_MASTERY_DROP and days <= 21:
            return AlertType.FALSE_MASTERY

        # 停滞：长期低水平波动，无明显提升
        if peak < 0.5 and abs(rate) < 0.002:
            return AlertType.STAGNATION

        # 自然衰变：正常的渐进式遗忘
        return AlertType.NATURAL_DECAY

    def _assess_severity(
        self, drop: float, rate: float, days: int, current: float
    ) -> DecaySeverity:
        """评估衰变严重度"""
        score = 0
        # 下降幅度
        if drop >= 0.40: score += 3
        elif drop >= 0.25: score += 2
        elif drop >= 0.15: score += 1

        # 衰变速率
        abs_rate = abs(rate)
        if abs_rate >= 0.008: score += 3
        elif abs_rate >= 0.005: score += 2
        elif abs_rate >= 0.003: score += 1

        # 当前掌握度水平
        if current < 0.3: score += 2
        elif current < 0.5: score += 1

        if score >= 7: return DecaySeverity.CRITICAL
        if score >= 5: return DecaySeverity.HIGH
        if score >= 3: return DecaySeverity.MEDIUM
        return DecaySeverity.LOW

    def _predict_future_mastery(
        self, current: float, rate: float,
        params: "StudentForgettingParams | None"
    ) -> float:
        """预测30天后的掌握度"""
        if params and params.lambda_ > 0:
            # 使用个体化遗忘曲线：M(t) = current * exp(-lambda * t)
            return max(0.0, current * np.exp(-params.lambda_ * 30))
        else:
            # 使用线性外推
            return max(0.0, current + rate * 30)
```

### 4.3 个体遗忘参数建模

### 4.3.1 遗忘曲线拟合

基于学生历史答题和掌握度数据，为每个学生拟合个体化的遗忘曲线参数。

```python
from scipy.optimize import curve_fit

class ForgettingModelFitter:
    """
    学生个体遗忘参数拟合器

    使用简化的指数遗忘模型：
        R(t) = exp(-t / S)
    其中：
        R(t) = t 时间后的记忆保持比例
        S    = 记忆稳定性参数（越大越不容易忘记）

    扩展模型（含复习增强）：
        R(t) = exp(-t / S) * (1 + β * n)
    其中：
        β    = 每次复习对稳定性的增强系数
        n    = 复习次数
    """

    MIN_FIT_SAMPLES = 20  # 最少拟合样本数

    async def fit_student_params(
        self, student_id: str
    ) -> "ForgettingFitResult | None":
        """为学生拟合遗忘参数"""
        # 1. 收集训练数据：(初始掌握度, 经过天数, 当前掌握度, 复习次数)
        samples = await self._collect_training_data(student_id)
        if len(samples) < self.MIN_FIT_SAMPLES:
            return None

        # 2. 按认知类型分组拟合
        results = {}
        for cog_type, group_samples in self._group_by_cognitive_type(samples).items():
            fit = self._fit_exponential_decay(group_samples)
            if fit:
                results[cog_type] = fit

        return ForgettingFitResult(
            student_id=student_id,
            params_by_type=results,
            total_samples=len(samples),
        )

    def _fit_exponential_decay(
        self, samples: list["FitSample"]
    ) -> "ForgettingParams | None":
        """
        拟合指数遗忘曲线

        样本格式：FitSample(initial_mastery, days_elapsed, current_mastery, review_count)
        """
        try:
            # 准备数据
            t_data = np.array([s.days_elapsed for s in samples], dtype=float)
            r_data = np.array([
                s.current_mastery / max(s.initial_mastery, 0.01)
                for s in samples
            ], dtype=float)
            n_data = np.array([s.review_count for s in samples], dtype=float)

            # 初始猜测
            p0 = [30.0, 0.1]  # S=30天, beta=0.1

            # 带权重的拟合（近期数据权重更高）
            weights = np.exp(-t_data / 180)  # 180天半衰期权重

            def model(t, S, beta):
                n_avg = np.interp(t, t_data, n_data)
                return np.exp(-t / max(S, 1.0)) * (1 + beta * n_avg)

            popt, pcov = curve_fit(
                model, t_data, r_data, p0=p0,
                sigma=1.0 / weights, absolute_sigma=False,
                bounds=([1.0, 0.0], [365.0, 1.0]),
                maxfev=5000,
            )

            S, beta = popt
            lambda_ = 1.0 / S

            # 计算拟合优度
            r_squared = self._calc_r_squared(
                r_data, model(t_data, *popt)
            )

            return ForgettingParams(
                lambda_=round(lambda_, 4),
                s0=round(S, 2),
                beta=round(beta, 4),
                sample_size=len(samples),
                r_squared=round(r_squared, 4),
            )
        except (RuntimeError, ValueError):
            return None

    def _calc_r_squared(self, y_actual: np.ndarray, y_pred: np.ndarray) -> float:
        ss_res = np.sum((y_actual - y_pred) ** 2)
        ss_tot = np.sum((y_actual - np.mean(y_actual)) ** 2)
        return 1 - ss_res / max(ss_tot, 1e-10)
```

### 4.3.2 认知类型分类

```python
class CognitiveTypeClassifier:
```

### 4.4 级联影响分析

### 4.4.1 知识图谱驱动的风险传播

当某个知识点发生衰变时，通过知识图谱分析其对后续知识点的级联影响。

```python
from collections import deque

class CascadeAnalyzer:
    """
    级联衰变风险分析器

    基于知识图谱的前置依赖关系，分析衰变知识点的风险传播路径。
    使用改进的PageRank式传播模型量化影响。
    """

    MAX_CASCADE_DEPTH = 3      # 最大传播深度
    MIN_EDGE_WEIGHT = 0.15     # 最小依赖权重（低于此值不传播）
    RISK_DECAY_PER_HOP = 0.6   # 每跳风险衰减系数

    def __init__(
        self,
        graph_service: "KnowledgeGraphService",
        mastery_service: "MasteryService",
    ):
        self._graph = graph_service
        self._mastery = mastery_service

    async def analyze_cascade(
        self,
        student_id: str,
        decay_alert: "DecayAlert",
    ) -> list["CascadeRisk"]:
        """
        分析衰变预警的级联影响

        返回所有受影响的后续知识点及其风险评估。
        """
        risks = []

        # BFS 遍历知识图谱的后续依赖节点
        visited = {decay_alert.knowledge_point_id}
        queue = deque()

        # 初始层：衰变知识点的直接后续
        direct_successors = await self._graph.get_successors(
            decay_alert.knowledge_point_id,
            min_weight=self.MIN_EDGE_WEIGHT,
        )

        for edge in direct_successors:
            queue.append((edge.target_id, edge.weight, 1))

        while queue:
            kp_id, edge_weight, depth = queue.popleft()

            if kp_id in visited or depth > self.MAX_CASCADE_DEPTH:
                continue
            visited.add(kp_id)

            # 获取当前掌握度
            current_mastery = await self._mastery.get(student_id, kp_id)

            # 计算风险传播衰减
            hop_factor = self.RISK_DECAY_PER_HOP ** (depth - 1)
            predicted_impact = (
                decay_alert.mastery_drop
                * edge_weight
                * hop_factor
            )

            # 风险等级
            risk_level = self._assess_risk_level(
                current_mastery, predicted_impact
            )

            if risk_level != "negligible":
                risks.append(CascadeRisk(
                    source_kp_id=decay_alert.knowledge_point_id,
                    target_kp_id=kp_id,
                    target_kp_current_mastery=current_mastery,
                    edge_weight=edge_weight,
                    predicted_impact=round(predicted_impact, 4),
                    risk_level=risk_level,
                ))

            # 继续向下一层传播
            if depth < self.MAX_CASCADE_DEPTH:
                successors = await self._graph.get_successors(
                    kp_id, min_weight=self.MIN_EDGE_WEIGHT
                )
                for edge in successors:
                    if edge.target_id not in visited:
                        queue.append((edge.target_id, edge.weight, depth + 1))

        return risks

    def _assess_risk_level(
        self, current_mastery: float, predicted_impact: float
    ) -> str:
        """评估风险等级"""
        predicted_after = current_mastery - predicted_impact

        if predicted_after < 0.2:
            return "high"
        if predicted_after < 0.4 or predicted_impact >= 0.15:
            return "medium"
        if predicted_impact >= 0.05:
            return "low"
        return "negligible"
```

### 4.5 干预策略编排

### 4.5.1 干预决策规则引擎

```python
            "priority": "low",
            "max_tasks": 3,

            "notify_parent": False,
        },
        # 严重度 low：低风险，标记观察
        {
            "conditions": {
                "severity": [DecaySeverity.LOW],
            },
            "strategy": "monitor_only",
            "priority": "low",
            "max_tasks": 0,
            "task_types": [],
            "notify_parent": False,
        },
    ]

    async def decide_intervention(
        self,
        alert: "DecayAlert",
        cascade_risks: list["CascadeRisk"],
        student_context: "StudentContext",
    ) -> list["InterventionPlan"]:
        """决策干预方案"""
        matched = []

        for rule in self.STRATEGY_RULES:
            if self._match_rule(rule["conditions"], alert, cascade_risks):
                plan = self._build_plan(rule, alert, cascade_risks, student_context)
                matched.append(plan)

        # 按优先级排序
        priority_order = {"urgent": 0, "normal": 1, "low": 2}
        matched.sort(key=lambda p: priority_order.get(p.priority, 99))

        return matched

    def _build_plan(
        self, rule: dict, alert: "DecayAlert",
        risks: list, ctx: "StudentContext"
    ) -> "InterventionPlan":
        """构建干预方案"""
        tasks = []

        if rule["max_tasks"] > 0:
            # 生成复习任务
            for i, task_type in enumerate(rule["task_types"][: rule["max_tasks"]]):
                tasks.append(InterventionTask(
                    task_type=task_type,
                    knowledge_point_id=alert.knowledge_point_id,
                    subject_code=alert.subject_code,
                    estimated_minutes=self._estimate_time(task_type),
                    difficulty=self._pick_difficulty(alert, ctx),
                ))

            # 为级联风险知识点生成桥接练习
            high_risks = [r for r in risks if r.risk_level in ("high", "medium")]
            for risk in high_risks[:2]:
                tasks.append(InterventionTask(
                    task_type="bridge_practice",
                    knowledge_point_id=risk.target_kp_id,
                    subject_code=alert.subject_code,
                    estimated_minutes=10,
                    difficulty="medium",
                    depends_on=alert.knowledge_point_id,
                ))

        return InterventionPlan(
            strategy=rule["strategy"],
            priority=rule["priority"],
            tasks=tasks,
            notify_parent=rule["notify_parent"],
            alert_id=alert.id,
        )
```

```python
        self, intervention_id: int

        if record.status != "completed":
            return InterventionEffect(status="pending")

        after = await self._mastery.get_current(
            record.student_id, self._get_kp_id(record)

            status = "inconclusive"
        elif delta >= 0.15:
            status = "effective"
        elif delta >= 0.05:
            status = "partial"
        else:
            status = "insufficient"

        await self._repo.update(record)

            status=status,
            mastery_before=before,
            mastery_after=after,
            delta=delta,
```

```python
class MemoryHealthEvaluator:
    """
    学生长期记忆健康度综合评估器

    综合考量：保持率、衰变面、级联风险、干预效果
    生成 0-100 的记忆健康度评分。
    """

    async def evaluate_student(
        self, student_id: str, as_of_date: date | None = None
    ) -> "MemoryHealthReport":
        """生成学生记忆健康度报告"""
        as_of = as_of_date or date.today()

        # 1. 获取所有追踪知识点当前状态
        all_kps = await self._snapshot_repo.get_latest_for_student(student_id)
        if not all_kps:
            return self._empty_report(student_id)

        total_kps = len(all_kps)

        # 2. 计算保持率（与历史峰值对比）
        retention_rates = []
        for kp in all_kps:
            peak = await self._get_peak_mastery(student_id, kp.knowledge_point_id)
            if peak and peak > 0.1:
                retention_rates.append(kp.mastery_value / peak)

        avg_retention = (
            sum(retention_rates) / len(retention_rates)
            if retention_rates else 1.0
        )

        # 3. 统计衰变分布
        active_alerts = await self._alert_repo.get_active(student_id)
        severity_counts = {"critical": 0, "high": 0, "medium": 0, "low": 0}
        for alert in active_alerts:
            severity_counts[alert.severity] += 1

        # 4. 计算健康度评分
        health_score = self._calc_health_score(
            avg_retention=avg_retention,
            severity_counts=severity_counts,
            total_kps=total_kps,
            active_alerts_ratio=len(active_alerts) / max(total_kps, 1),
        )

        # 5. 识别学习模式
        learning_pattern = await self._detect_learning_pattern(student_id)

        # 6. 生成建议
        recommendations = self._generate_recommendations(
            avg_retention, severity_counts, learning_pattern, total_kps
        )

        return MemoryHealthReport(
            student_id=student_id,
            as_of_date=as_of,
            health_score=round(health_score, 2),
            avg_retention_rate=round(avg_retention, 4),
            total_tracked_kps=total_kps,
            active_alerts=len(active_alerts),
            severity_distribution=severity_counts,
            learning_pattern=learning_pattern,
            recommendations=recommendations,
        )

    def _calc_health_score(
        self, avg_retention: float, severity_counts: dict,
        total_kps: int, active_alerts_ratio: float,
    ) -> float:
        """
        健康度评分计算

        维度权重：
        - 保持率 (40%): 平均保持率 * 40
        - 无衰变面 (30%): (1 - active_alerts_ratio) * 30
        - 严重度惩罚 (30%): 根据 critical/high 数量扣分
        """
        # 保持率得分
        retention_score = avg_retention * 40

        # 无衰变面得分
        no_decay_score = (1 - min(active_alerts_ratio, 1.0)) * 30

        # 严重度惩罚
        severity_penalty = (
            severity_counts["critical"] * 5
            + severity_counts["high"] * 3
            + severity_counts["medium"] * 1
        )
        severity_score = max(0, 30 - severity_penalty)

        total = retention_score + no_decay_score + severity_score
        return min(100, max(0, total))

    async def _detect_learning_pattern(self, student_id: str) -> str:
        """检测学生学习模式"""
        # 获取最近 90 天的学习行为序列
        sessions = await self._session_repo.get_recent(student_id, days=90)
        if not sessions:
            return "irregular"

        # 分析学习间隔分布
        gaps = self._calc_session_gaps(sessions)

        # 分析单次学习强度分布
        intensities = [s.total_questions for s in sessions]

        # 判定模式
        avg_gap = sum(gaps) / len(gaps)
        gap_variance = np.var(gaps)
        avg_intensity = sum(intensities) / len(intensities)
        intensity_variance = np.var(intensities)

        if avg_gap <= 2 and gap_variance <= 4:
            return "steady"  # 稳定型：间隔短且规律
        elif avg_intensity > 50 and intensity_variance > 500:
            return "cramming"  # 突击型：单次量大但波动大
        else:
            return "irregular"  # 不规律型
```

## 7. 错误处理与异常恢复

### 7.1 错误码定义

| --- | --- | --- | --- |
| MH-001 | 404 | 学生掌握度档案不存在 | 引导先完成初始学习数据采集 |
| MH-002 | 400 | 追踪数据不足（< 最少数据点） | 返回提示，不中断服务 |
| MH-003 | 500 | 遗忘参数拟合失败 | 使用默认参数兜底 |
| MH-004 | 500 | 快照写入失败 | 重试3次，失败后记录告警日志 |
| MH-005 | 500 | 级联分析超时 | 降级为仅处理直接依赖（depth=1） |
| MH-006 | 429 | 并发快照写入冲突 | 幂等处理，忽略重复写入 |
| MH-007 | 500 | 干预下发失败 | 重试，失败后降级为站内消息 |

### 7.2 降级策略

```python
class MemoryHealthDegradationHandler:
    """记忆健康引擎降级处理器"""

    async def safe_get_health(self, student_id: str) -> dict:
        """安全获取健康度（带降级）"""
        try:
            # 尝试获取实时计算结果
            return await self._evaluator.evaluate_student(student_id)
        except ServiceUnavailableError:
            # 降级1：使用缓存的上次评估结果
            cached = await self._cache.get(f"mh:{student_id}")
            if cached:
                cached["degraded"] = True
                cached["degraded_reason"] = "evaluation_service_unavailable"
                return cached

            # 降级2：返回基础信息
            return {
                "student_id": student_id,
                "health_score": None,
                "degraded": True,
                "message": "记忆健康评估暂时不可用，请稍后重试"
            }

    async def safe_detect_decay(
        self, student_id: str, kp_id: str
    ) -> DecayDetectionResult | None:
        """安全执行衰变检测（带降级）"""
        try:
            return await self._detector.detect(student_id, kp_id)
        except Exception as e:
            logger.warning("衰变检测失败，使用简化逻辑: %s", e)
            # 降级：简单比较当前值与30天前快照
            return await self._simple_decay_check(student_id, kp_id)

    async def _simple_decay_check(
        self, student_id: str, kp_id: str
    ) -> DecayDetectionResult | None:
        """简化版衰变检测（无回归分析，仅比较差值）"""
        current = await self._mastery.get_current(student_id, kp_id)
        past = await self._snapshot.get_30d_ago(student_id, kp_id)

        if current is None or past is None:
            return None

        drop = past - current
        if drop < 0.10:
            return None

        return DecayDetectionResult(
            knowledge_point_id=kp_id,
            is_decaying=True,
            alert_type=AlertType.NATURAL_DECAY,
            severity=DecaySeverity.HIGH if drop > 0.25 else DecaySeverity.MEDIUM,
            mastery_peak=past,
            peak_date=date.today() - timedelta(days=30),
            mastery_current=current,
            mastery_drop=round(drop, 4),
            days_since_peak=30,
            decay_rate_per_day=round(-drop / 30, 6),
            predicted_mastery_30d=round(current - drop, 4),
            confidence=0.5,
        )
```

```python
class MemoryHealthOptimizer:
    """记忆健康引擎性能优化"""

    # 1. 批量快照写入（减少 DB roundtrip）
    BATCH_INSERT_SIZE = 1000

    async def batch_insert_snapshots(
        self, records: list[MasterySnapshot]
    ):
        """批量写入快照数据"""
        values_sql = """
            INSERT INTO kp_mastery_snapshot
            (student_id, knowledge_point_id, snapshot_date,
             mastery_value, confidence, data_source,
             practice_count_7d, practice_count_30d,
             correct_rate_30d, last_practice_at, mastery_delta)
            VALUES %s
            ON CONFLICT (student_id, knowledge_point_id, snapshot_date)
            DO NOTHING
        """
        await self._db.execute_values(values_sql, records, page_size=self.BATCH_INSERT_SIZE)

    # 2. 增量检测（只检测近期有学习活动的知识点）
    async def get_kps_to_check(self, student_id: str) -> list[str]:
        """获取需要检测的知识点（活跃的或有近期学习记录的）"""
        # 策略：7天内有练习的知识点全部检测
        # 7-30天无练习的知识点抽检50%
        # 30天以上无练习的知识点抽检20%
        pass

    # 3. 时序数据使用 TimescaleDB
    TIMESCALE_HYPERTABLE = """
        SELECT create_hypertable(
            'kp_mastery_snapshot',
            'snapshot_date',
            chunk_time_interval => INTERVAL '7 days'
        );
    """

    # 4. 衰变检测结果缓存
    async def cache_detection_result(
        self, student_id: str, kp_id: str, result: DecayDetectionResult
    ):
        """缓存检测结果，避免短时间内重复计算"""
        key = f"decay:{student_id}:{kp_id}"
        await self._redis.setex(key, time=3600, value=result.to_json())

    # 5. 级联分析使用知识图谱缓存
    async def get_cached_successors(
        self, kp_id: str
    ) -> list["KnowledgeEdge"]:
        """从缓存获取知识图谱后继节点"""
        key = f"kg:succ:{kp_id}"
        cached = await self._redis.get(key)
        if cached:
            return cached
        result = await self._graph.get_successors(kp_id)
        await self._redis.setex(key, time=86400, value=result)  # 24小时
        return result
```

### 9.2 隐私保护

```python
class MemoryHealthPrivacyFilter:
    """记忆健康数据隐私过滤"""

    # 家长可见字段
    PARENT_VISIBLE_FIELDS = {
        "health_score", "avg_retention_rate", "severity_distribution",
        "subject_breakdown", "learning_pattern", "recommendations"
    }

    # 教师聚合脱敏
    def anonymize_for_teacher(self, reports: list) -> dict:
        """教师端聚合脱敏处理"""
        return {
            "class_avg_health": np.mean([r.health_score for r in reports]),
            "class_avg_retention": np.mean([r.avg_retention_rate for r in reports]),
            "alert_count_distribution": self._count_by_severity(reports),
            "students_needing_attention": [
                {"student_ref": self._hash_id(r.student_id), "health_score": r.health_score}
                for r in reports if r.health_score < 50
            ],
        }
```

### 9.3 未成年人保护

- 衰变预警通知不包含具体知识点名称（避免焦虑），仅在点开后展示详情
- 干预推荐任务量有上限（每日 ≤ 3 个衰变修复任务），避免过载
- 严重度标签（critical 等）不对学生展示，仅对家长和教师展示为"需要关注"
- 健康度评分不对学生排名或比较
