# 服务端-教育数据标准化与跨平台学习数据交换引擎-详细设计

## 1. 模块概述

### 1.1 设计目标

构建统一的教育数据标准化与跨平台数据交换引擎，使 PrimeTop 能够：

1. **标准化输出**：将内部学习行为数据转换为国际通用的教育数据标准格式（xAPI/CALIPER/OneRoster），支持与第三方教育平台、学校 SIS 系统、政府教育数据平台的数据互通。
2. **标准化输入**：从外部系统（学校学生信息系统、教务系统、其他教育产品）导入学生、班级、课程、成绩等数据，并自动映射为 PrimeTop 内部实体。
3. **B 端数据服务**：为合作学校、教育机构、区域教育平台提供标准化数据接口，支撑 B 端商业合作场景。
4. **合规性保障**：在数据交换全链路中落实 PIPL（个人信息保护法）、《未成年人保护法》、教育部《教育移动互联网应用程序备案管理办法》等法规要求。

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 最小化披露 | 仅交换必要字段，敏感信息脱敏后输出 |
| 双向可审计 | 所有数据交换操作留存完整审计日志 |
| 格式可扩展 | 标准适配器模式，支持后续新增数据标准 |
| 异步解耦 | 数据导出/导入通过消息队列异步处理，不影响主链路 |
| 版本兼容 | 标准格式版本变更时保持向后兼容 |

```java
/**
```

```java
public interface StandardAdapter<T> {
    
    /**
     * 获取支持的标准的编码
     */
    String getStandardCode();
    
    /**
     * 获取支持的实体类型列表
     */
    List<String> getSupportedEntityTypes();
    
    /**
     * 将内部实体转换为目标标准格式
     */
    List<T> toStandard(List<InternalEntity> internalEntities, MappingContext context);
    
    /**
     * 将标准格式数据转换为内部实体
     */
    List<InternalEntity> fromStandard(List<T> standardEntities, MappingContext context);
    
    /**
     * 校验标准格式数据是否符合规范
     */
    ValidationResult validate(T standardEntity);
    
    /**
     * 获取标准格式的 JSON Schema
     */
    JsonSchema getJsonSchema(String entityType);
}
```

```java
     */
    @Override
    public List<OneRosterEntity> toStandard(List<InternalEntity> internalEntities,
                                             MappingContext context) {
        List<OneRosterEntity> results = new ArrayList<>();
        
        for (InternalEntity internal : internalEntities) {
            String entityType = internal.getEntityType();
            List<StandardMappingRule> rules = mappingRuleService
                .getRules(STANDARD_CODE, entityType, context.getPartnerId());
            
            OneRosterEntity standardEntity = new OneRosterEntity();
            standardEntity.setEntityType(entityType);
            
            for (StandardMappingRule rule : rules) {
                Object internalValue = extractFieldValue(internal, rule.getInternalFieldPath());
                
                // 应用转换器
                if (rule.getTransformerClass() != null) {
                    FieldTransformer transformer = transformerRegistry
                        .getTransformer(rule.getTransformerClass());
                    internalValue = transformer.transform(internalValue, 
                        rule.getTransformerParams());
                }
                
                // 敏感字段脱敏
                if (Boolean.TRUE.equals(rule.getSensitive()) 
                    && Boolean.TRUE.equals(context.getRedactSensitive())) {
                    internalValue = redactor.redact(internalValue, 
                        RedactStrategy.valueOf(rule.getRedactStrategy()));
                }
                
                // 设置默认值
                if (internalValue == null && rule.getDefaultValue() != null) {
                    internalValue = rule.getDefaultValue();
                }
                
                standardEntity.setField(rule.getStandardFieldPath(), internalValue);
            }
            
            // 设置元数据
            standardEntity.setSourcedId(internal.getEntityId());
            standardEntity.setStatus(StatusType.ACTIVE);
            standardEntity.setDateLastModified(internal.getUpdatedAt());
            
            results.add(standardEntity);
        }
        
        return results;
    }
    
    /**
     * OneRoster 标准格式 → 内部实体
     */
    @Override
    public List<InternalEntity> fromStandard(List<OneRosterEntity> standardEntities,
                                              MappingContext context) {
        List<InternalEntity> results = new ArrayList<>();
        
        for (OneRosterEntity stdEntity : standardEntities) {
            String entityType = stdEntity.getEntityType();
            List<StandardMappingRule> rules = mappingRuleService
                .getRules(STANDARD_CODE, entityType, context.getPartnerId());
            
            InternalEntity internal = new InternalEntity();
            internal.setEntityType(mapToInternalEntityType(entityType));
            
            for (StandardMappingRule rule : rules) {
                Object standardValue = stdEntity.getField(rule.getStandardFieldPath());
                
                // 反向转换
                if (rule.getTransformerClass() != null) {
                    FieldTransformer transformer = transformerRegistry
                        .getTransformer(rule.getTransformerClass());
                    standardValue = transformer.reverse(standardValue,
                        rule.getTransformerParams());
                }
                
                internal.setField(rule.getInternalFieldPath(), standardValue);
            }
            
            // 保留外部 sourcedId 用于去重和关联
            internal.setExternalId(stdEntity.getSourcedId());
            internal.setSourceSystem(context.getSourceSystem());
            
            results.add(internal);
        }
        
        return results;
    }
    
    /**
     * 校验 OneRoster 实体是否符合规范
     */
    @Override
    public ValidationResult validate(OneRosterEntity entity) {
        ValidationResult result = new ValidationResult();
        
        // sourcedId 必填且为 UUID 格式
        if (StringUtils.isBlank(entity.getSourcedId())) {
            result.addError("sourcedId", "sourcedId is required");
        } else if (!isValidUUID(entity.getSourcedId())) {
            result.addError("sourcedId", "sourcedId must be a valid UUID");
        }
        
        // status 必填
        if (entity.getStatus() == null) {
            result.addError("status", "status is required (active|tobedeleted)");
        }
        
        // 按实体类型校验必填字段
        switch (entity.getEntityType()) {
            case "USER":
                validateUser(entity, result);
                break;
            case "CLASS":
                validateClass(entity, result);
                break;
            case "ENROLLMENT":
                validateEnrollment(entity, result);
                break;
            case "RESULT":
                validateResult(entity, result);
                break;
        }
        
        return result;
    }
    
    private void validateUser(OneRosterEntity entity, ValidationResult result) {
        requireField(entity, "username", result);
        requireField(entity, "givenName", result);
        requireField(entity, "familyName", result);
        requireField(entity, "role", result);
        
        String role = (String) entity.getField("role");
        if (role != null && !Set.of("student", "teacher", "parent", "aide")
            .contains(role.toLowerCase())) {
            result.addError("role", "Invalid role: " + role);
        }
    }
    
    private void validateClass(OneRosterEntity entity, ValidationResult result) {
        requireField(entity, "title", result);
        requireField(entity, "classType", result);
        requireField(entity, "schoolSourcedId", result);
        requireField(entity, "courseSourcedId", result);
        
        String classType = (String) entity.getField("classType");
        if (classType != null && !Set.of("homeroom", "scheduled").contains(classType)) {
            result.addError("classType", "Invalid classType: " + classType);
        }
    }
    
    private void validateEnrollment(OneRosterEntity entity, ValidationResult result) {
        requireField(entity, "userSourcedId", result);
        requireField(entity, "classSourcedId", result);
        requireField(entity, "role", result);
    }
    
    private void validateResult(OneRosterEntity entity, ValidationResult result) {
        requireField(entity, "lineItemSourcedId", result);
        requireField(entity, "studentSourcedId", result);
        requireField(entity, "scoreStatus", result);
        
        String scoreStatus = (String) entity.getField("scoreStatus");
        if (scoreStatus != null && !Set.of("submitted", "graded", "pending", 
            "incomplete", "exempt").contains(scoreStatus)) {
            result.addError("scoreStatus", "Invalid scoreStatus: " + scoreStatus);
        }
    }
    
    private void requireField(OneRosterEntity entity, String field, 
                               ValidationResult result) {
        if (entity.getField(field) == null) {
            result.addError(field, field + " is required");
        }
    }
    
    @Override
    public JsonSchema getJsonSchema(String entityType) {
        // 返回 OneRoster 官方 JSON Schema
        return OneRosterSchemaRegistry.getSchema(entityType);
    }
    
    private Object extractFieldValue(InternalEntity entity, String fieldPath) {
        return BeanUtils.getProperty(entity, fieldPath);
    }
    
    private boolean isValidUUID(String value) {
        try {
            UUID.fromString(value);
            return true;
        } catch (IllegalArgumentException e) {
            return false;
        }
    }
}
```

```java
public class XApi103Adapter implements StandardAdapter<XApiStatement> {

     */
    private static final Map<String, VerbMapping> VERB_MAP = Map.ofEntries(

    /**
     * 将内部学习行为事件转为 xAPI Statement
     */
    @Override
    public List<XApiStatement> toStandard(List<InternalEntity> events,
                                          MappingContext context) {
        List<XApiStatement> statements = new ArrayList<>();
        
        for (InternalEntity event : events) {
            String eventType = event.getEntityType();
            VerbMapping verbMapping = VERB_MAP.get(eventType);
            
            if (verbMapping == null) {
                log.warn("No xAPI verb mapping for event type: {}, skipping", eventType);
                continue;

            XApiStatement statement = buildStatement(event, verbMapping, context);
            statements.add(statement);
        }

    private XApiStatement buildStatement(InternalEntity event,
                                          VerbMapping verbMapping,
                                          MappingContext context) {
        XApiStatement stmt = new XApiStatement();
        
        // Statement ID
        stmt.setId(UUID.randomUUID());
        
        // Timestamp (ISO 8601)
        stmt.setTimestamp(event.getCreatedAt().atZone(ZoneId.of("Asia/Shanghai"))
            .toOffsetDateTime().toString());
        
        // Actor (学生)
        XApiActor actor = XApiActor.builder()
            .objectType("Agent")
            .name(event.get("userName"))
            .account(XApiAccount.builder()
                .homePage("https://primetop.cn")
                .name(event.getUserId())
                .build())
            .build();
        stmt.setActor(actor);
        
        // Verb
        XApiVerb verb = XApiVerb.builder()
            .id(verbMapping.getVerbId())
            .display(Map.of("zh-CN", verbMapping.getVerbDisplay(), 
                            "en-US", verbMapping.getVerbDisplay()))
            .build();
        stmt.setVerb(verb);
        
        // Object
        XApiObject obj = XApiObject.builder()
            .objectType("Activity")
            .id(verbMapping.getActivityBase() + "/" + event.getEntityId())
            .definition(XApiDefinition.builder()
                .name(Map.of("zh-CN", (String) event.getOrDefault("title", event.getEntityId())))
                .description(Map.of("zh-CN", (String) event.getOrDefault("description", "")))
                .type(verbMapping.getActivityType())
                .build())
            .build();
        stmt.setObject(obj);
        
        // Result (答题类事件包含结果)
        if (event.hasField("score") || event.hasField("correct")) {
            XApiResult result = XApiResult.builder()
                .success((Boolean) event.get("correct"))
                .score(XApiScore.builder()
                    .raw(((Number) event.getOrDefault("score", 0)).doubleValue())
                    .min(0.0)
                    .max(((Number) event.getOrDefault("maxScore", 100)).doubleValue())
                    .scaled(((Number) event.getOrDefault("score", 0)).doubleValue() /
                            ((Number) event.getOrDefault("maxScore", 100)).doubleValue())
                    .build())
                .completion(true)
                .duration(formatDuration(event.get("durationMs")))
                .response((String) event.get("studentAnswer"))
                .build();
            stmt.setResult(result);
        }
        
        // Context (附加上下文信息)
        XApiContext xContext = XApiContext.builder()
            .registration(UUID.randomUUID())
            .contextActivities(XApiContextActivities.builder()
                .parent(buildParentActivities(event))
                .category(buildCategoryActivities(event))
                .build())
            .extensions(Map.of(
                "https://primetop.cn/xapi/extensions/grade",
                event.getOrDefault("grade", ""),
                "https://primetop.cn/xapi/extensions/subject",
                event.getOrDefault("subject", ""),
                "https://primetop.cn/xapi/extensions/textbook-version",
                event.getOrDefault("textbookVersion", ""),
                "https://primetop.cn/xapi/extensions/knowledge-points",
                event.getOrDefault("knowledgePoints", List.of())
            ))
            .build();
        stmt.setContext(xContext);
        
        // Authority
        stmt.setAuthority(XApiActor.builder()
            .objectType("Agent")
            .name("PrimeTop Learning Platform")
            .account(XApiAccount.builder()
                .homePage("https://primetop.cn")
                .name("system")
                .build())
            .build());
        
        return stmt;
    }
    
    /**
     * 构建父级活动（章节→单元→学科层级）
     */
    private List<XApiActivityRef> buildParentActivities(InternalEntity event) {
        List<XApiActivityRef> parents = new ArrayList<>();
        
        String chapterId = (String) event.get("chapterId");
        if (chapterId != null) {
            parents.add(XApiActivityRef.builder()
                .objectType("Activity")
                .id(ACTIVITY_BASE + "chapter/" + chapterId)
                .build());
        }
        
        String subjectId = (String) event.get("subjectId");
        if (subjectId != null) {
            parents.add(XApiActivityRef.builder()
                .objectType("Activity")
                .id(ACTIVITY_BASE + "subject/" + subjectId)
                .build());
        }
        
        return parents;
    }
    
    private String formatDuration(Object durationMs) {
        if (durationMs == null) return null;
        long ms = ((Number) durationMs).longValue();
        return "PT" + (ms / 1000) + "S";
    }
    
    @Override
    public List<InternalEntity> fromStandard(List<XApiStatement> statements,
                                              MappingContext context) {
        // xAPI 主要用于输出（导出学习行为给外部系统）
        // 导入场景较少，支持从 LRS 导入历史学习记录
        List<InternalEntity> results = new ArrayList<>();
        
        for (XApiStatement stmt : statements) {
            InternalEntity entity = new InternalEntity();
            entity.setEntityType("LEARNING_EVENT");
            entity.setEntityId(stmt.getId().toString());
            entity.setExternalId(stmt.getId().toString());
            entity.setSourceSystem(context.getSourceSystem());
            
            // 反向解析 Verb
            String verbId = stmt.getVerb().getId();
            String eventType = reverseMapVerb(verbId);
            entity.set("eventType", eventType);
            entity.set("userId", stmt.getActor().getAccount().getName());
            entity.set("timestamp", stmt.getTimestamp());
            
            // 解析 Result
            if (stmt.getResult() != null) {
                XApiScore score = stmt.getResult().getScore();
                if (score != null) {
                    entity.set("score", score.getRaw());
                    entity.set("maxScore", score.getMax());
                }
                entity.set("correct", stmt.getResult().getSuccess());
                entity.set("studentAnswer", stmt.getResult().getResponse());
            }
            
            results.add(entity);
        }
        
        return results;
    }
    
    private String reverseMapVerb(String verbId) {
        return VERB_MAP.entrySet().stream()
            .filter(e -> e.getValue().getVerbId().equals(verbId))
            .map(Map.Entry::getKey)
            .findFirst()
            .orElse("UNKNOWN_EVENT");
    }

        }
        if (statement.getTimestamp() == null) {
            result.addError("timestamp", "Timestamp is required");
        }
        
        return result;
    }
```

```java
/**
 * 年级编码转换器
 * 内部: "7" (七年级) ↔ OneRoster grade: "G07"
 */
public class GradeLevelTransformer implements FieldTransformer {
    
    private static final Map<String, String> INTERNAL_TO_STANDARD = Map.of(
        "1", "G01", "2", "G02", "3", "G03",
        "4", "G04", "5", "G05", "6", "G06",
        "7", "G07", "8", "G08", "9", "G09",
        "10", "G10", "11", "G11", "12", "G12"
    );
    
    @Override
    public Object transform(Object value, String params) {
        if (value == null) return null;
        return INTERNAL_TO_STANDARD.getOrDefault(value.toString(), value);
    }
    
    @Override
    public Object reverse(Object value, String params) {
        if (value == null) return null;
        for (Map.Entry<String, String> e : INTERNAL_TO_STANDARD.entrySet()) {
            if (e.getValue().equals(value.toString())) {
                return e.getKey();
            }
        }
        return value;
    }
}

/**
 * 日期时间 ISO 8601 转换器
 */
public class DateTimeISO8601Transformer implements FieldTransformer {
    
    private static final DateTimeFormatter ISO_FORMATTER =
        DateTimeFormatter.ISO_OFFSET_DATE_TIME;
    private static final ZoneId DEFAULT_ZONE = ZoneId.of("Asia/Shanghai");
    
    @Override
    public Object transform(Object value, String params) {
        if (value == null) return null;
        if (value instanceof LocalDateTime) {
            return ((LocalDateTime) value).atZone(DEFAULT_ZONE)
                .format(ISO_FORMATTER);
        }
        if (value instanceof LocalDate) {
            return ((LocalDate) value).format(DateTimeFormatter.ISO_DATE);
        }
        return value;
    }
    
    @Override
    public Object reverse(Object value, String params) {
        if (value == null) return null;
        String str = value.toString();
        try {
            return OffsetDateTime.parse(str, ISO_FORMATTER)
                .atZoneSameInstant(DEFAULT_ZONE)
                .toLocalDateTime();
        } catch (DateTimeParseException e) {
            try {
                return LocalDate.parse(str);
            } catch (DateTimeParseException e2) {
                return null;
            }
        }
    }
}

public class PhoneRedactTransformer implements FieldTransformer {

    public Object transform(Object value, String params) {
        if (value == null) return null;
        String phone = value.toString();
        if (phone.length() >= 11) {
            return phone.substring(0, 3) + "****" + phone.substring(7);

        return "***";
    }

        // 脱敏不可逆
        return value;

    public Object transform(Object value, String params) {
        if (value == null) return null;
        return CODE_MAP.getOrDefault(value.toString(), value);
    }
    
    @Override
    public Object reverse(Object value, String params) {
        if (value == null) return null;
        return CODE_MAP.entrySet().stream()
            .filter(e -> e.getValue().equals(value.toString()))
            .map(Map.Entry::getKey)
            .findFirst()
            .orElse(value);
    }
}
```

```java
            "BIDIRECTIONAL".equals(job.getDirection())) {
            
            String consentId = job.getConsentId();
            if (consentId == null) {
                context.getErrors().add("No consent ID provided for export job");
                return context;
            }
            
            DataUsageConsent consent = consentService.getById(consentId);
            if (consent == null) {
                context.getErrors().add("Consent not found: " + consentId);
                return context;
            }
            
            if (!"GRANTED".equals(consent.getStatus())) {
                context.getErrors().add(
                    "Consent is not active, current status: " + consent.getStatus());
                return context;
            }
            
            if (consent.getExpiresAt() != null && 
                consent.getExpiresAt().isBefore(LocalDateTime.now())) {
                context.getErrors().add("Consent has expired");
                return context;
            }
            
            // 校验授权范围是否覆盖请求的数据类型
            List<String> consentScopes = JsonUtils.parseArray(consent.getConsentScopes());
            List<String> requestedScopes = extractRequestedScopes(job);
            
            for (String scope : requestedScopes) {
                if (!consentScopes.contains(scope)) {
                    context.getErrors().add(
                        "Consent does not cover scope: " + scope);
                }
            }
            
            context.getMappingContext().setConsentId(consentId);
            context.getMappingContext().setRedactSensitive(
                Boolean.TRUE.equals(job.getRedactSensitive()));
        }
        
        context.recordStageTime(getStageName(), 
            System.currentTimeMillis() - start);
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return true; // 所有任务都需要经过授权校验
    }

/**
 * 格式转换处理器
 * 加载映射规则，逐条应用字段转换器，敏感字段脱敏，生成标准格式实体
 */
@Component
@Slf4j
public class TransformHandler implements PipelineHandler {
    
    /** 超过该记录数时启用暂存盘溢写，避免大任务 OOM */
    private static final int STAGING_THRESHOLD = 10_000;
    
    @Autowired
    private StandardMappingRuleService mappingRuleService;
    
    @Autowired
    private FieldTransformerRegistry transformerRegistry;
    
    @Autowired
    private SensitiveDataRedactor redactor;
    
    @Override
    public String getStageName() {
        return "TRANSFORM";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        DataExchangeJob job = context.getJob();
        MappingContext mc = context.getMappingContext();
        
        try (StagingStore staging = StagingStore.open(job.getJobNo())) {
            
            // 按内部实体类型分组，分别加载映射规则（规则缓存双缓冲，5 分钟刷新）
            Map<String, List<InternalEntity>> grouped = context.getInternalEntities()
                .stream()
                .collect(Collectors.groupingBy(InternalEntity::getEntityType));
            
            for (Map.Entry<String, List<InternalEntity>> entry : grouped.entrySet()) {
                String internalType = entry.getKey();
                String standardType = mc.resolveStandardType(internalType);
                List<StandardMappingRule> rules = mappingRuleService
                    .getEnabledRules(job.getStandardCode(), standardType);
                
                if (rules.isEmpty()) {
                    // 无映射规则 → 全部记为 UNMAPPED，不阻断任务
                    entry.getValue().forEach(e -> context.appendRecord(
                        RecordOutcome.unmapped(internalType, e.getId())));
                    continue;
                }
                
                for (InternalEntity entity : entry.getValue()) {
                    try {
                        Object standard = transformOne(entity, rules, mc);
                        staging.write(standardType, standard);
                        context.appendRecord(RecordOutcome.mapped(
                            standardType, extractSourcedId(standard, rules),
                            internalType, entity.getId()));
                    } catch (ConflictException ce) {
                        // 同一 sourcedId 批内重复或类型冲突 → 记 CONFLICT，跳过
                        context.appendRecord(RecordOutcome.conflict(
                            internalType, entity.getId(), ce.getMessage()));
                    } catch (Exception ex) {
                        // 单条失败不阻断任务，记 ERROR
                        context.appendRecord(RecordOutcome.error(
                            internalType, entity.getId(), ex.getMessage()));
                    }
                }
            }
            
            context.setStagingRef(staging.getDescriptor());
        } catch (IOException e) {
            context.getErrors().add("Staging write failed: " + e.getMessage());
        }
        
        context.recordStageTime(getStageName(),
            System.currentTimeMillis() - start);
        return context;
    }
    
    /** 单条实体转换：规则逐字段执行 → 转换器 → 脱敏 → 默认值 → 必填检查 */
    private Object transformOne(InternalEntity entity,
                                List<StandardMappingRule> rules,
                                MappingContext mc) {
        Map<String, Object> node = new LinkedHashMap<>();
        
        for (StandardMappingRule rule : rules) {
            Object value = extractFieldValue(entity, rule.getInternalFieldPath());
            
            if (rule.getTransformerClass() != null && value != null) {
                FieldTransformer transformer = transformerRegistry
                    .getTransformer(rule.getTransformerClass());
                value = transformer.transform(value, rule.getTransformerParams());
            }
            
            // 敏感字段脱敏（redactSensitive 为任务级总开关，规则级策略决定方式）
            if (Boolean.TRUE.equals(rule.getSensitive())
                && Boolean.TRUE.equals(mc.getRedactSensitive())
                && value != null) {
                value = redactor.redact(value, rule.getRedactStrategy());
            }
            
            if (value == null && rule.getDefaultValue() != null) {
                value = rule.getDefaultValue();
            }
            
            if (value == null && Boolean.TRUE.equals(rule.getRequired())) {
                throw new ConflictException(
                    "Required field missing: " + rule.getStandardFieldPath());
            }
            
            setPath(node, rule.getStandardFieldPath(), value);
        }
        return node;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return "EXPORT".equals(job.getJobType()) || "SYNC".equals(job.getJobType());
    }
}
```

```java
/**
 * 数据校验处理器
 * JSON Schema 校验 / 枚举合法性 / 批内引用完整性
 */
@Component
@Order(4)
@Slf4j
public class SchemaValidationHandler implements PipelineHandler {
    
    /** 有效率低于该阈值时任务整体失败，防止带病输出 */
    private static final double MIN_VALID_RATIO = 0.95;
    
    @Autowired
    private StandardAdapterFactory adapterFactory;
    
    @Override
    public String getStageName() {
        return "VALIDATION";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        StandardAdapter<?> adapter = context.getAdapter();
        
        try (StagingStore staging = StagingStore.open(context.getStagingRef())) {
            ValidationResult vr = new ValidationResult();
            
            staging.forEach((standardType, record) -> {
                ValidationResult r = adapter.validate(record);
                if (!r.isValid()) {
                    vr.addInvalid(standardType, r.getErrors());
                    staging.markExcluded(record);   // 无效记录不进入输出
                    context.incrFailed();
                } else if (r.hasWarnings()) {
                    vr.addWarning(standardType, r.getWarnings());
                }
            });
            
            // 批内引用完整性：Enrollment 引用的 userSourcedId / classSourcedId 必须在本批
            // 输出或外部实体映射表中存在
            checkReferentialIntegrity(staging, vr);
            
            context.setValidationResult(vr);
            
            long total = staging.totalCount();
            long valid = staging.validCount();
            if (total > 0 && (double) valid / total < MIN_VALID_RATIO) {
                context.getErrors().add(String.format(
                    "Valid ratio %.2f%% below threshold %.2f%%",
                    100.0 * valid / total, 100.0 * MIN_VALID_RATIO));
            }
        } catch (IOException e) {
            context.getErrors().add("Validation staging read failed: " + e.getMessage());
        }
        
        context.recordStageTime(getStageName(),
            System.currentTimeMillis() - start);
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return "EXPORT".equals(job.getJobType()) || "IMPORT".equals(job.getJobType())
            || "SYNC".equals(job.getJobType());   // 导入链同样复用本处理器（见 §5.3）
    }
}

/**
 * 合规审查处理器（fail-secure：任何依赖不可用时宁可失败也不放行）
 */
@Component
@Order(5)
@Slf4j
public class ComplianceAuditHandler implements PipelineHandler {
    
    /** 单任务导出记录数硬上限（防批量泄露），超过拒绝 */
    private static final long MAX_EXPORT_RECORDS = 500_000;
    
    @Autowired
    private SensitiveDataRedactor redactor;          // 委托《数据脱敏规则引擎》
    
    @Autowired
    private DataUsageConsentService consentService;
    
    @Autowired
    private ComplianceAuditWriter auditWriter;        // ClickHouse 审计宽表
    
    @Override
    public String getStageName() {
        return "COMPLIANCE";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        DataExchangeJob job = context.getJob();
        
        // 1. 数据量阈值检查
        if ("EXPORT".equals(job.getJobType())
            && context.getJob().getTotalRecords() > MAX_EXPORT_RECORDS) {
            context.getErrors().add("Export volume exceeds limit: "
                + job.getTotalRecords() + " > " + MAX_EXPORT_RECORDS);
            return context;
        }
        
        try (StagingStore staging = StagingStore.open(context.getStagingRef())) {
            // 2. 敏感信息二次扫描（防转换器遗漏，正则 + 脱敏引擎云端复检）
            staging.forEach((type, record) -> {
                List<String> leaks = redactor.scanResidual(record);
                if (!leaks.isEmpty()) {
                    context.getErrors().add("Residual sensitive data in "
                        + type + ": " + leaks.get(0));   // fail-secure 中止
                    return;
                }
            });
            
            // 3. 未成年人实体批量授权复核：
            //    导出中每个未成年用户必须存在 GRANTED 状态的 PARENT/GUARDIAN 授权
            if ("EXPORT".equals(job.getJobType())) {
                List<String> minors = staging.collectMinorUserIds(
                    context.getMappingContext());
                Map<String, Boolean> covered = consentService
                    .batchCheckGuardianConsent(minors, job.getPartnerId());
                List<String> uncovered = minors.stream()
                    .filter(id -> !Boolean.TRUE.equals(covered.get(id)))
                    .collect(Collectors.toList());
                if (!uncovered.isEmpty()) {
                    // 缺家长授权的未成年人记录直接剔除，不让整任务失败
                    staging.excludeUsers(uncovered);
                    context.incrSkipped(uncovered.size());
                    auditWriter.write(AuditEvent.minorConsentSkipped(
                        job.getJobNo(), uncovered.size()));
                }
            }
            
            // 4. 合规审计日志（谁、何时、对谁、导出什么、多少条、脱敏方式）
            auditWriter.write(AuditEvent.exchangeCompliancePass(
                job, staging.validCount(), job.getRedactSensitive()));
        } catch (IOException e) {
            context.getErrors().add("Compliance staging read failed: " + e.getMessage());
        }
        
        context.recordStageTime(getStageName(),
            System.currentTimeMillis() - start);
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return true;   // 导入导出都需要合规审查
    }
}

/**
 * 打包输出处理器
 * 序列化 → 压缩 → SHA-256 → 上传对象存储 → 签名下载链接
 */
@Component
@Order(6)
public class OutputPackagingHandler implements PipelineHandler {
    
    @Autowired
    private ObjectStorageService objectStorage;       // 《文件与资源存储服务》
    
    @Override
    public String getStageName() {
        return "PACKAGING";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        DataExchangeJob job = context.getJob();
        
        String fileKey = String.format("dex/%s/%s/%s.%s%s",
            job.getPartnerId(), job.getJobNo(), "payload",
            job.getFileFormat().toLowerCase(),
            "GZIP".equals(job.getCompression()) ? ".gz" : "");
        
        try (StagingStore staging = StagingStore.open(context.getStagingRef());
             RecordStreamWriter writer = RecordStreamWriter.create(
                 job.getFileFormat(), job.getCompression(), fileKey)) {
            
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            staging.forEachValid((type, record) -> {
                byte[] line = writer.write(type, record);
                digest.update(line);
            });
            
            writer.finish();
            
            // 上传对象存储（分片，5MB/片）
            objectStorage.multipartUpload(fileKey, writer.getTempFile());
            
            context.setObjectStorageKey(fileKey);
            context.setChecksum(Hex.encodeHexString(digest.digest()));
            job.setFileSize(writer.getBytesWritten());
            
            // 签名下载链接，默认 24h；每次调用下载网关时还会复查授权状态（见 G7）
            context.setDownloadUrl(objectStorage.presignGet(
                fileKey, Duration.ofHours(24)));
            
        } catch (Exception e) {
            context.getErrors().add("Packaging failed: " + e.getMessage());
        }
        
        context.recordStageTime(getStageName(),
            System.currentTimeMillis() - start);
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return "EXPORT".equals(job.getJobType()) || "SYNC".equals(job.getJobType());
    }
}

/**
 * 传输投递处理器
 * 按合作方数据源配置选择通道：REST 回调 / Webhook / SFTP / 消息队列
 */
@Component
@Order(7)
@Slf4j
public class DeliveryHandler implements PipelineHandler {
    
    /** 投递重试退避：1m / 5m / 30m / 2h / 6h，共 5 次 */
    private static final long[] BACKOFF_MINUTES = {1, 5, 30, 120, 360};
    
    @Autowired
    private PartnerDataSourceService dataSourceService;
    
    @Autowired
    private DeliveryClient deliveryClient;
    
    @Autowired
    private DataExchangeDeliveryMapper deliveryMapper;
    
    @Override
    public String getStageName() {
        return "DELIVERY";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        DataExchangeJob job = context.getJob();
        PartnerDataSource ds = dataSourceService
            .getEnabled(job.getPartnerId(), job.getStandardCode());
        
        // 组装投递通知载荷（不含数据本体，只含下载链接 + 校验和 + 统计）
        DeliveryNotification notification = DeliveryNotification.of(
            job.getJobNo(), context.getDownloadUrl(), context.getChecksum(),
            job.getTotalRecords(), job.getSuccessRecords(), job.getFailedRecords());
        
        DeliveryChannel channel = DeliveryChannel.from(ds.getAccessMethod());
        int attempt = 0;
        
        while (attempt <= BACKOFF_MINUTES.length) {
            DeliveryResult result = deliveryClient.send(
                channel, ds, notification);
            
            deliveryMapper.insert(DeliveryLog.of(
                job.getId(), channel, ds.primaryTarget(),
                attempt, result));
            
            if (result.isSuccess()) {
                context.recordStageTime(getStageName(),
                    System.currentTimeMillis() - start);
                return context;      // 2xx 即确认，结束
            }
            
            if (attempt == BACKOFF_MINUTES.length) break;
            
            try {
                Thread.sleep(BACKOFF_MINUTES[attempt] * 60_000L);
            } catch (InterruptedException ie) {
                Thread.currentThread().interrupt();
                break;
            }
            attempt++;
        }
        
        // 重试耗尽 → 投递转 DEAD，任务仍可 COMPLETED（数据已生成），走死信告警
        context.getErrors().add("Delivery exhausted retries, moved to DEAD");
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return "EXPORT".equals(job.getJobType())
            && "API_CALL".equals(job.getTriggerType());   // 拉取式任务由合作方自行下载
    }
}
```

> 说明：同步阻塞式退避仅用于小任务；大批量任务由 `DeliveryRetryScheduler`（§5.4）异步执行退避重试，`DeliveryHandler` 仅投递首次并登记重试计划。

### 5.3 导入管道处理器链

导入任务（IMPORT / BIDIRECTIONAL 的入站方向）复用管道框架，但处理器链不同。链路由编排器按 jobType 装配：

```
导入链: FileIngestHandler → SchemaValidationHandler → ReverseTransformHandler
         → ComplianceAuditHandler → InternalUpsertHandler → ImportReportHandler
```

```java
/**
 * 导入链专属标记接口：编排器据此将实现类从导出链中排除
 */
public interface ImportOnlyHandler {}

/**
 * 文件摄取处理器
 * 校验和验证 → 解压 → 流式解析（NDJSON 按行 / JSON 数组分块 / CSV 逐行）
 */
@Component
@Slf4j
public class FileIngestHandler implements PipelineHandler, ImportOnlyHandler {
    
    @Autowired
    private ObjectStorageService objectStorage;
    
    @Override
    public String getStageName() {
        return "FILE_INGEST";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        DataExchangeJob job = context.getJob();
        
        try (InputStream raw = objectStorage.getStream(job.getInputFileKey())) {
            
            // 1. SHA-256 校验（合作方上传时随 metadata 提供，不匹配直接拒绝）
            String actual = IoUtils.sha256(raw);
            if (job.getChecksum() != null && !job.getChecksum().equals(actual)) {
                context.getErrors().add("Checksum mismatch: expected "
                    + job.getChecksum() + " actual " + actual);
                return context;
            }
            
            // 2. 解压 + 流式解析入暂存区（避免整文件载入内存）
            try (InputStream in = DecompressStream.wrap(raw, job.getCompression());
                 StagingStore staging = StagingStore.open(job.getJobNo())) {
                
                RecordStreamParser parser = RecordStreamParser.of(job.getFileFormat());
                parser.parse(in, (standardType, record) -> {
                    staging.write(standardType, record);
                    context.incrTotal();
                });
                context.setStagingRef(staging.getDescriptor());
            }
            
        } catch (Exception e) {
            context.getErrors().add("File ingest failed: " + e.getMessage());
        }
        
        context.recordStageTime(getStageName(),
            System.currentTimeMillis() - start);
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return "IMPORT".equals(job.getJobType());
    }
}

/**
 * 逆向转换处理器：标准实体 → 内部实体（fromStandard + reverse 转换器）
 */
@Component
@Slf4j
public class ReverseTransformHandler implements PipelineHandler {
    
    @Autowired
    private StandardAdapterFactory adapterFactory;
    
    @Override
    public String getStageName() {
        return "REVERSE_TRANSFORM";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        StandardAdapter<?> adapter = context.getAdapter();
        
        try (StagingStore staging = StagingStore.open(context.getStagingRef())) {
            List<InternalEntity> converted = adapter.fromStandard(
                staging.readAll(), context.getMappingContext());
            
            // fromStandard 内部逐条 try/catch：UNMAPPED/CONFLICT 落记录表不计失败率
            staging.writeInternal(converted);
        } catch (Exception e) {
            context.getErrors().add("Reverse transform failed: " + e.getMessage());
        }
        
        context.recordStageTime(getStageName(),
            System.currentTimeMillis() - start);
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return "IMPORT".equals(job.getJobType());
    }
}

/**
 * 内部落库处理器
 * 幂等 upsert：外部实体映射表 + 内容指纹比对，无变化跳过
 */
@Component
@Slf4j
public class InternalUpsertHandler implements PipelineHandler {
    
    @Autowired
    private ExternalEntityMappingService mappingService;
    
    @Autowired
    private InternalEntityWriter entityWriter;   // 委托各内部领域服务的写接口
    
    @Override
    public String getStageName() {
        return "INTERNAL_UPSERT";
    }
    
    @Override
    public PipelineContext handle(PipelineContext context) {
        long start = System.currentTimeMillis();
        DataExchangeJob job = context.getJob();
        
        try (StagingStore staging = StagingStore.open(context.getStagingRef())) {
            staging.forEachInternal((internalType, entity) -> {
                String standardEntityId = entity.getSourceSyncId()
                    .split(":", 3)[2];   // standardCode:entityType:standardEntityId
                String contentHash = entity.contentHash();
                
                ExternalEntityMapping mapping = mappingService.find(
                    job.getStandardCode(), internalType, standardEntityId);
                
                if (mapping != null
                    && mapping.getContentHash().equals(contentHash)) {
                    context.incrSkipped();      // 内容无变化，跳过
                    return;
                }
                
                UpsertResult r = entityWriter.upsert(
                    internalType, entity,
                    mapping == null ? null : mapping.getInternalEntityId());
                
                mappingService.upsert(ExternalEntityMapping.of(
                    job.getStandardCode(), internalType, standardEntityId,
                    r.getInternalId(), contentHash, job.getId()));
                
                if (r.isCreated()) context.incrSuccess();
                else context.incrSuccess();     // CREATE/UPDATE 均计成功
            });
            
            // DELETE 操作：外部 deleted 标记 → 软删除内部实体（经内部领域服务）
        } catch (Exception e) {
            context.getErrors().add("Internal upsert failed: " + e.getMessage());
        }
        
        context.recordStageTime(getStageName(),
            System.currentTimeMillis() - start);
        return context;
    }
    
    @Override
    public boolean supports(DataExchangeJob job) {
        return "IMPORT".equals(job.getJobType());
    }
}
/**
 * 导入报告处理器（链尾）
```

### 5.4 管道编排器、进度与取消

```java
/**
 * 数据交换管道编排器
 */
@Service
@Slf4j
public class DataExchangePipelineOrchestrator {
    
    /** 导出链（@Order 决定默认顺序） */
    private final List<PipelineHandler> exportChain;
    
    /** 导入链：显式装配 */
    private final List<PipelineHandler> importChain;
    
    public DataExchangePipelineOrchestrator(List<PipelineHandler> handlers,
                                            @Qualifier("importChain") List<PipelineHandler> importChain) {
        this.exportChain = handlers.stream()
            .filter(h -> !(h instanceof ImportOnlyHandler))
            .sorted(OrderComparator.INSTANCE)
            .collect(Collectors.toList());
        this.importChain = importChain;
    }
    
    /**
     * 执行任务。幂等：同 jobNo 已终态直接返回；阶段游标支持断点续跑。
     */
    public void execute(DataExchangeJob job) {
        List<PipelineHandler> chain = "IMPORT".equals(job.getJobType())
            ? importChain : exportChain;
        
        job.setStatus(JobStatusEnum.RUNNING);
        job.setStartedAt(LocalDateTime.now());
        
        PipelineContext context = new PipelineContext();
        context.setJob(job);
        context.setAdapter(adapterFactory.get(job.getStandardCode()));
        
        for (PipelineHandler handler : chain) {
            if (!handler.supports(job)) continue;
            
            // 取消检查：管理端取消 / 授权撤回均会置位 Redis 取消标记
            if (cancelFlagService.isCancelled(job.getJobNo())) {
                job.setStatus(JobStatusEnum.CANCELLED);
                return;
            }
            
            // 断点续跑：已完成的阶段直接跳过（checkpoint 表）
            if (checkpointService.isStageDone(job.getId(), handler.getStageName())) {
                continue;
            }
            
            syncStatus(job, handler.getStageName());   // RUNNING → TRANSFORMING/VALIDATING
            
            try {
                context = handler.handle(context);
                checkpointService.markStageDone(
                    job.getId(), handler.getStageName(), context.stageCursor(handler));
            } catch (Exception e) {
                log.error("Pipeline stage {} failed, job {}",
                    handler.getStageName(), job.getJobNo(), e);
                context.getErrors().add(handler.getStageName() + ": " + e.getMessage());
            }
            
            if (context.hasErrors()) break;   // fail-secure：任一阶段致命错误即中止
            
            job.setProgress(calcProgress(chain, handler));
            jobService.updateProgress(job);
        }
        
        finalizeJob(job, context);   // COMPLETED / FAILED + Outbox 事件
    }
}
```

进度上报：每阶段完成刷新一次 `progress`；数据量大的阶段（EXTRACTION/TRANSFORM/UPSERT）每 2000 条追加刷新一次。取消路径两条：管理端 `POST /jobs/{jobNo}/cancel` 与授权撤回事件（G5），均通过 Redis `dex:cancel:{jobNo}` 标记，编排器在阶段边界与每 500 条记录处检查。

```
         ┌────────────┐    ┌────────────┐     │  ┌─────────┘
         │ VALIDATING │───▶│ COMPLETED  │◀────┘  └──▶ RUNNING(从checkpoint)
         └────────────┘    └────────────┘
```

### 8.2 守卫总表

| 编号 | 守卫规则 | 违反结果 |
| --- | --- | --- |
| G1 | 任务启动仅允许 PENDING，或 FAILED 且 retryCount<maxRetry 的重试入口 | 56302 |
| G2 | 同一 (partnerId, standardCode, jobType) 存在非终态任务时，新任务创建被拒 | 56304 |
| G3 | 状态只能沿 PENDING→RUNNING→TRANSFORMING→VALIDATING→终态推进；TRANSFORMING/VALIDATING 可直达 FAILED | 56302 |
| G4 | EXPORT/BIDIRECTIONAL 任务 consent 必须 GRANTED、未过期、范围覆盖 | 56310~56313 |
| G5 | consent→REVOKED 事件到达时，该 partner 涉及该用户的在途任务立即 CANCELLED | - |
| G6 | COMPLETED 要求 success+skipped+failed=total 且 failed/total≤5%；超限转 FAILED 并保留计数 | - |
| G7 | 下载链接签发与访问前提：job=COMPLETED 且 consent 仍 GRANTED；网关复查撤回名单 | 56311 |
| G8 | 可重试失败仅限 PACKAGING/DELIVERY/系统异常；CONSENT/COMPLIANCE 拒绝不可重试 | 56302 |
| G9 | 导入 upsert 以 uk(standard_code,entity_type,standard_entity_id) 幂等；content_hash 相同跳过 | - |
| G10 | 合作方回调非 2xx 按 1m/5m/30m/2h/6h 退避 5 次，耗尽转 DEAD 并 P1 告警 | 56352 |
| G11 | 撤回后 retentionDays 内必须收到合作方删除回执，到期未收自动升级人工 + 日终核查 | - |
| G12 | 单任务导出记录 ≤ 50 万；超出建议按时间窗拆分 | 56305 |

### 8.3 授权状态机（edu_data_usage_consent）

```
PENDING ──家长/学生确认──▶ GRANTED ──到期──▶ EXPIRED
   │                        │  │                │
   │ 超时7天未确认→EXPIRED    │  └─撤回──▶ REVOKED(不可逆,重授权走新记录)
   └────────────────────────┘                  │
                                    到期审计(删除回执核查 G11)
```

撤回不可逆：重新授权生成新 consentNo；历史 REVOKED 记录永久保留（审计要求，逻辑删除仅作用于 PENDING）。

### 8.4 记录映射状态（edu_data_exchange_record.mappingStatus）

MAPPED →（导入链）→ UPSERTED；UNMAPPED/CONFLICT/ERROR 均为终态，CONFLICT 支持人工在管理端修正映射后重跑单条（`POST /jobs/{jobNo}/records/{seqNo}/remap`）。

## 9. 幂等与并发控制

| 场景 | 机制 |
| --- | --- |
| 任务创建 | jobNo=DEX+日期+E/ I+序列；管理端 Idempotency-Key 唯一索引 30 天窗口；合作方 API 以 (partnerId, requestId) 唯一 |
| 任务执行 | 编排器抢 Redis 锁 `dex:exec:{jobNo}` 120s 续期；锁丢失即自杀退出（checkpoint 保证不重复执行阶段） |
| 阶段断点 | edu_data_exchange_checkpoint 按 (job_id, stage) 记录完成游标；重试从最后 checkpoint 继续 |
| 提取分页 | 游标 (lastId, updatedAt) 双条件，避免增量窗口内数据变更导致的漏拉/重拉；重拉由 upsert 幂等兜底 |
| 导入落库 | uk_external 撞键 + content_hash 比对（G9）；DELETE 操作幂等（内部实体软删除天然幂等） |
| 投递重试 | delivery 表 uk(job_id, channel, attempt)；回调载荷带 jobNo+checksum，合作方按 jobNo 去重 |
| 游标拉取 | (partnerId, entityType) 维度游标单调推进；ack 之前 nextCursor 可重放（响应缓存 10 分钟） |
| xAPI 入站 | Statement ID 服务端生成幂等存储 uk(statement_id)；同 ID 重复提交返回原 ID 不重复入库 |

```sql
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='投递记录与重试计划';

CREATE TABLE edu_external_entity_mapping (
    id                 BIGINT PRIMARY KEY AUTO_INCREMENT,
    standard_code      VARCHAR(30) NOT NULL,
    entity_type        VARCHAR(40) NOT NULL,
    standard_entity_id VARCHAR(128) NOT NULL,
    internal_entity_id VARCHAR(64) NOT NULL,

    last_seen_job_id   BIGINT,
    updated_at         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_external (standard_code, entity_type, standard_entity_id),
    INDEX idx_internal (internal_entity_id)

```

事件主题 `exchange.domain.events`：

| 事件 | 触发时机 | 关键字段 | 消费方（幂等键） |
| --- | --- | --- | --- |
| exchange.job.started | RUNNING 置位 | jobNo, partnerId | 数据仓库（event_id）、B端门户（event_id） |
| exchange.job.completed | COMPLETED | jobNo, counts, checksum, outputFileKey | 数据仓库、B端门户、监控（event_id） |
| exchange.job.failed / .cancelled | 终态 | jobNo, reason, stage | B端门户、告警（event_id） |
| exchange.consumed | 合作方 ack | jobNo, cursor | 对账 Job（event_id+jobNo） |
| exchange.consent.revoked | 授权撤回 | consentNo, userId, partnerId | 本引擎取消器、脱敏引擎、审计（event_id） |
| exchange.delivery.dead | 投递死信 | jobNo, channel, attempts | 告警、B端门户（event_id） |
| exchange.partner.health_changed | 健康检查状态迁移 | partnerId, from, to | B端门户、监控（event_id） |
| exchange.record.quarantined | CONFLICT 隔离 | jobNo, seqNo, reason | 内容运营工作台（event_id+seqNo） |

Relay 线程每 500ms 批量拉取 published=0 事件投递 MQ，失败退避；日终对账 published=1 但 MQ 无回执的差异补投。

| 编号 | 故障 | 降级行为 |

## 13. 合规红线

| 编号 | 红线 |
| --- | --- |
| C1 | 最小必要：仅交换 allowedEntityTypes ∩ consentScopes 内的实体与字段；批量导出必须逐字段映射规则显式声明，禁止 SELECT * 直出 |
