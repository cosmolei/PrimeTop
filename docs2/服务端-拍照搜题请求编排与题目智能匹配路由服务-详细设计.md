# 服务端 - 拍照搜题请求编排与题目智能匹配路由服务 - 详细设计文档

## 1. 模块概述

### 1.1 定位

拍照搜题请求编排与题目智能匹配路由服务是 PrimeTop 拍照搜题功能的 **服务端核心编排层**。它承接客户端上传的题目图片，协调图片预处理、OCR 识别、题库匹配、AI 解析等多个下游子系统，完成从"原始图片"到"结构化解答"的端到端流程。

本服务不直接实现 OCR 或 AI 解析能力，而是作为 **编排器 (Orchestrator)** 统一管理请求生命周期、路由策略、降级策略和结果聚合。

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 端到端 P95 延迟 | 单题 ≤ 5s，多题 (≤5) ≤ 10s |
| 题库命中率 | 印刷体 ≥ 70%，手写体 ≥ 40% |
| AI 回退成功率 | ≥ 98% |
| 服务可用性 | ≥ 99.9% |
| 峰值吞吐 | 200 RPS（请求级），1000 QPS（题目级） |
| 请求超时率 | ≤ 0.5% |

### 1.3 功能边界

**本服务负责：**
- 接收客户端拍照搜题请求（单图 / 多图 / 多题框选）
- 请求参数校验与预检（额度、频率、图片格式）
- 编排调用：图片预处理 → OCR → 题目提取 → 题库匹配 / AI 解析
- 多题并行处理与结果聚合
- 请求状态管理与超时控制
- 结果缓存与热门题预取
- 异步落库与行为事件推送

**本服务不负责：**
- 图片预处理算法实现（由图片处理服务提供）
- OCR 识别引擎（由 OCR 服务提供）
- AI 解答生成（由 AI 辅导服务提供）
- 题库索引构建与维护（由题库服务提供）
- 客户端 UI 交互与图片裁剪

### 4.2 请求处理编排（核心伪代码）

```java
@Service
@Slf4j
public class PhotoSearchOrchestrator {

    @Autowired private QuotaService quotaService;
    @Autowired private ImagePreprocessService imageService;
    @Autowired private OcrService ocrService;
    @Autowired private QuestionSplitter questionSplitter;
    @Autowired private QuestionMatchRouter matchRouter;
    @Autowired private AiParseService aiParseService;
    @Autowired private PhotoSearchCacheService cacheService;
    @Autowired private EventPublisher eventPublisher;

    /**
     * 主编排方法
     * 超时控制：整请求 12s，单题匹配 2s，AI解析 8s
     */
    @Timeout(value = 12, unit = TimeUnit.SECONDS)
    @Transactional
    public PhotoSearchResponse process(PhotoSearchRequest request) {
        String traceId = MDC.get("traceId");
        long startTime = System.currentTimeMillis();

        // 1. 幂等检查
        PhotoSearchResponse cached = checkIdempotent(request.getRequestId());
        if (cached != null) {
            return cached;
        }

        // 2. 额度预检与预扣
        QuotaCheckResult quotaResult = quotaService.checkAndDeduct(
            request.getUserId(), 
            QuotaType.PHOTO_SEARCH,
            request.getImages().stream()
                .mapToInt(i -> Optional.ofNullable(i.getSelectedRegions())
                    .map(List::size).orElse(1))
                .sum()
        );
        if (!quotaResult.isAllowed()) {
            throw new QuotaExceededException(quotaResult.getMessage());
        }

        // 3. 创建请求记录
        PhotoSearchRequestEntity requestEntity = saveRequest(request);

        try {
            // 4. 并行处理每张图片
            List<CompletableFuture<List<RecognizedQuestion>>> ocrFutures = 
                request.getImages().stream()
                    .map(img -> CompletableFuture.supplyAsync(
                        () -> processImage(img, request), 
                        ocrExecutor
                    ))
                    .collect(Collectors.toList());

            // 5. 等待所有OCR完成（超时4s）
            List<RecognizedQuestion> allQuestions = ocrFutures.stream()
                .map(f -> f.get(4, TimeUnit.SECONDS))
                .flatMap(List::stream)
                .collect(Collectors.toList());

            if (allQuestions.isEmpty()) {
                return buildErrorResponse(request, ProcessStatus.FAILED, 
                    "未能识别到题目内容");
            }

            // 6. 并行处理每道题：匹配 → 解析
            List<CompletableFuture<QuestionResult>> questionFutures = 
                allQuestions.stream()
                    .map(q -> CompletableFuture.supplyAsync(
                        () -> processQuestion(q, request), 
                        questionExecutor
                    ))
                    .collect(Collectors.toList());

            // 7. 聚合结果（超时8s）
            List<QuestionResult> results = new ArrayList<>();
            for (int i = 0; i < questionFutures.size(); i++) {
                try {
                    results.add(questionFutures.get(i).get(8, TimeUnit.SECONDS));
                } catch (TimeoutException e) {
                    results.add(buildTimeoutResult(allQuestions.get(i)));
                    log.warn("题目处理超时, index={}, traceId={}", 
                        allQuestions.get(i).getIndex(), traceId);
                } catch (Exception e) {
                    results.add(buildErrorResult(allQuestions.get(i), e));
                }
            }

            // 8. 构建响应
            PhotoSearchResponse response = buildResponse(
                request, results, startTime);

            // 9. 异步落库 + 事件推送
            asyncSaveAndPublish(requestEntity, results, response);

            // 10. 额度实际扣减（根据成功处理的题目数）
            quotaService.confirmDeduction(
                request.getUserId(), 
                QuotaType.PHOTO_SEARCH,
                (int) results.stream().filter(r -> r.getStatus() == QuestionStatus.SUCCESS).count()
            );

            return response;

        } catch (Exception e) {
            // 异常时回退额度
            quotaService.rollbackDeduction(
                request.getUserId(), QuotaType.PHOTO_SEARCH);
            throw e;
        }
    }

    /**
     * 单张图片处理：预处理 → OCR → 多题分割
     */
    private List<RecognizedQuestion> processImage(
            ImageInput image, PhotoSearchRequest request) {
        
        // 4a. 图片预处理
        PreprocessResult preprocessResult = imageService.preprocess(
            image.getImageKey(),
            PreprocessOptions.builder()
                .enableDenoise(true)
                .enableDeskew(true)
                .enableContrastEnhance(true)
                .build()
        );

        // 4b. OCR 识别
        OcrResult ocrResult = ocrService.recognize(
            preprocessResult.getProcessedKey(),
            OcrOptions.builder()
                .enableFormula(true)
                .enableFigureDetection(true)
                .build()
        );

        // 4c. 多题分割（如果用户未框选）
        if (image.getSelectedRegions() != null && !image.getSelectedRegions().isEmpty()) {
            return questionSplitter.splitByRegions(
                ocrResult, image.getSelectedRegions());
        } else {
            return questionSplitter.autoSplit(ocrResult);
        }
    }

    /**
     * 单题处理：缓存查询 → 题库匹配 → AI回退
     */
    private QuestionResult processQuestion(
            RecognizedQuestion recognized, PhotoSearchRequest request) {
        
        // 6a. 缓存查询（SimHash 快速匹配）
        String textHash = SimHashUtil.hash(recognized.getStemText());
        PhotoSearchCacheEntity cacheHit = cacheService.findByHash(textHash);
        if (cacheHit != null && cacheHit.getExpiresAt().isAfter(LocalDateTime.now())) {
            return buildCachedResult(recognized, cacheHit);
        }

        // 6b. 题库匹配（向量+全文混合检索）
        MatchResult match = matchRouter.match(
            MatchRequest.builder()
                .stemText(recognized.getStemText())
                .options(recognized.getOptions())
                .formulas(recognized.getFormulas())
                .subjectCode(request.getSubjectCode())
                .gradeCode(request.getGradeCode())
                .timeoutMs(2000L)
                .build()
        );

        if (match.getStatus() != MatchStatus.NOT_FOUND) {
            // 命中题库 → 获取已有解析
            AnswerContent answer = matchRouter.getAnswer(match.getAnswerId());
            
            // 写入缓存
            cacheService.put(textHash, match.getQuestionId(), match.getAnswerId());
            
            return buildMatchedResult(recognized, match, answer);
        }

        // 6c. 题库未命中 → AI 实时解析
        AnswerContent aiAnswer = aiParseService.parseAndAnswer(
            AiParseRequest.builder()
                .question(recognized)
                .gradeCode(request.getGradeCode())
                .subjectCode(request.getSubjectCode())
                .textbookVersionId(request.getTextbookVersionId())
                .timeoutMs(6000L)
                .build()
        );

        return buildAiGeneratedResult(recognized, aiAnswer);
    }
}
```

### 4.3 题库匹配路由策略

```java
@Service
public class QuestionMatchRouter {

    /**
     * 三级匹配策略
     * 
     * L1: SimHash 精确匹配（O(1)，用于高频热门题）
     * L2: 向量语义匹配（ES knn / Milvus，用于变式题）
     * L3: 全文检索匹配（ES match，兜底）
     * 
     * 任意一级命中且分数达标即返回
     */
    public MatchResult match(MatchRequest request) {
        String normalizedText = TextNormalizer.normalize(request.getStemText());

        // L1: SimHash 精确匹配（海明距离 ≤ 3）
        MatchResult l1 = simHashMatch(normalizedText);
        if (l1 != null && l1.getSimilarityScore() >= 0.95) {
            log.info("L1 SimHash精确匹配命中, score={}", l1.getSimilarityScore());
            return l1;
        }

        // L2: 向量语义匹配（Top-5 重排）
        MatchResult l2 = vectorMatch(normalizedText, request);
        if (l2 != null && l2.getSimilarityScore() >= 0.75) {
            log.info("L2 向量语义匹配命中, score={}", l2.getSimilarityScore());
            return l2;
        }

        // L3: 全文检索
        MatchResult l3 = fulltextMatch(normalizedText, request);
        if (l3 != null && l3.getSimilarityScore() >= 0.75) {
            log.info("L3 全文检索匹配命中, score={}", l3.getSimilarityScore());
            return l3;
        }

        return MatchResult.notFound();
    }

    /**
     * L1: SimHash 匹配
     * - 对题干文本计算 SimHash（64bit）
     * - 在 Redis 有序集合中查找海明距离 ≤ 3 的记录
     * - 复杂度 O(1)，适合高频热门题
     */
    private MatchResult simHashMatch(String text) {
        long simHash = SimHashUtil.computeSimHash64(text);
        // 查 Redis: key=photo:search:simhash:{前缀}
        // 对 64bit SimHash 分 4 段建前缀索引
        for (int segment = 0; segment < 4; segment++) {
            String prefix = SimHashUtil.extractPrefix(simHash, segment, 16);
            Set<String> candidates = redisTemplate.opsForSet()
                .members("photo:simhash:" + segment + ":" + prefix);
            if (candidates != null) {
                for (String candidate : candidates) {
                    long candidateHash = Long.parseLong(candidate.split(":")[0]);
                    if (SimHashUtil.hammingDistance(simHash, candidateHash) <= 3) {
                        Long questionId = Long.parseLong(candidate.split(":")[1]);
                        return MatchResult.exact(questionId, 0.98);
                    }
                }
            }
        }
        return null;
    }

    /**
     * L2: 向量语义匹配
     * - 题干 → Embedding 向量（dimension=768）
     * - ES knn 搜索 Top-20
     * - 使用 Cross-Encoder 重排 Top-5
     * - 取最高分
     */
    private MatchResult vectorMatch(String text, MatchRequest request) {
        float[] embedding = embeddingService.embed(text);
        
        // ES knn 搜索
        SearchResponse response = elasticsearchClient.search(s -> s
            .index("questions")
            .knn(k -> k
                .field("embedding")
                .queryVector(embedding)
                .k(20)
                .numCandidates(100)
            )
            .query(q -> q.bool(b -> b
                .filter(f -> f.term(t -> t
                    .field("subject_code")
                    .value(request.getSubjectCode())
                ))
            ))
            .size(5),
            QuestionDocument.class
        );

        if (response.hits().hits().isEmpty()) return null;

        // Cross-Encoder 重排
        List<ScoredQuestion> reranked = crossEncoder.rerank(
            text,
            response.hits().hits().stream()
                .map(h -> h.source().getStemText())
                .collect(Collectors.toList())
        );

        ScoredQuestion best = reranked.get(0);
        if (best.getScore() >= 0.75) {
            return new MatchResult(
                best.getScore() >= 0.95 ? MatchStatus.EXACT : MatchStatus.SIMILAR,
                best.getQuestionId(),
                best.getScore(),
                best.getAnswerId(),
                null
            );
        }
        return null;
    }
```

### 5.1 热门题缓存

```
层级: 本地 Caffeine (L1) → Redis (L2) → MySQL (持久化)

  - AI 解析完成时，若命中次数 > 3，写入缓存

  - 题目ID查询: photo:search:answer:{questionId}

  - 热门题缓存: 7天
  - 匹配结果缓存: 24小时
```

```java
@Service
public class PhotoSearchCacheService {

    // L1: 本地 Caffeine 缓存（热门题，容量 10000）
    private final Cache<String, Long> localCache = Caffeine.newBuilder()
        .maximumSize(10_000)
        .expireAfterWrite(Duration.ofHours(6))
        .recordStats()
        .build();

     * 写入缓存

            "photo:search:hash:" + textHash,
            questionId + ":" + answerId,
            Duration.ofHours(24)

        photoSearchCacheRepository.save(
            new PhotoSearchCacheEntity(textHash, questionId, answerId,
                LocalDateTime.now().plusDays(7))
        );
```

### 6.1 额度管控

```java
/**
 * 拍照搜题额度预扣 → 执行 → 确认/回退 模型
 * 
 * 为什么用预扣：防止并发超额
 * 为什么需要确认：部分题目失败时只扣成功部分
 */
@Service
public class PhotoSearchQuotaManager {

    /**
     * 预扣额度
     * @param estimatedCount 预估题目数
     */
    public QuotaTicket preDeduct(Long userId, int estimatedCount) {
        // 查用户剩余次数
        int remaining = quotaService.getRemaining(userId, QuotaType.PHOTO_SEARCH);
        if (remaining < estimatedCount) {
            // 允许扣减到0，但不允许超额
            estimatedCount = Math.max(remaining, 0);
        }
        if (estimatedCount == 0) {
            throw new QuotaExceededException("今日拍照搜题次数已用完");
        }

        // Redis 原子预扣
        String ticketKey = "quota:ticket:" + UUID.randomUUID();
        redisTemplate.opsForValue().set(ticketKey, estimatedCount, 
            Duration.ofMinutes(5));
        quotaService.deduct(userId, QuotaType.PHOTO_SEARCH, estimatedCount);

        return new QuotaTicket(ticketKey, estimatedCount);
    }

    /**
     * 确认实际消耗并退还差额
     */
    public void confirm(QuotaTicket ticket, int actualUsed) {
        int diff = ticket.getEstimatedCount() - actualUsed;
        if (diff > 0) {
            quotaService.refund(ticket.getUserId(), QuotaType.PHOTO_SEARCH, diff);
        }
        redisTemplate.delete(ticket.getTicketKey());
    }
}
```

```java
@Service
public class PhotoSearchDegradationManager {

    @Autowired private CircuitBreakerFactory circuitBreakerFactory;

    /**
     * 带降级的图片预处理调用
     */
    public PreprocessResult preprocessWithFallback(String imageKey) {
        CircuitBreaker cb = circuitBreakerFactory.create("image-preprocess");
        return cb.run(
            () -> imageService.preprocess(imageKey),
            throwable -> {
                log.warn("图片预处理降级，使用原图, error={}", throwable.getMessage());
                return PreprocessResult.original(imageKey);
            }
        );
    }

    /**
     * 带降级的题库匹配调用
     */
    public MatchResult matchWithFallback(MatchRequest request) {
        CircuitBreaker cb = circuitBreakerFactory.create("question-match");
        return cb.run(
            () -> matchRouter.match(request),
            throwable -> {
                log.warn("题库匹配降级，跳过匹配, error={}", throwable.getMessage());
                return MatchResult.notFound();
            }
        );
    }

    /**
     * AI 服务降级：模型降级链
     * 
     * 正常: GPT-4o → 失败 → DeepSeek-R1 → 失败 → GLM-4 → 失败 → 返回通用提示
     */
    public AnswerContent aiParseWithFallback(AiParseRequest request) {
        String[] modelChain = {"gpt-4o", "deepseek-r1", "glm-4"};
        
        for (String model : modelChain) {
            try {
                return aiParseService.parseWithModel(request, model);
            } catch (AiServiceException e) {
                log.warn("模型 {} 调用失败，尝试下一个, error={}", 
                    model, e.getMessage());
            }
        }

        // 全部失败 → 返回通用提示
        return AnswerContent.degraded(
            "抱歉，暂时无法为您解析这道题目。请稍后重试或换一张清晰的照片重新拍摄。"
        );
    }
}
```

## 附录 A：SimHash 工具类

```java
public class SimHashUtil {

    private static final int HASH_BITS = 64;
    private static final Pattern TOKENIZER = Pattern.compile("[\\u4e00-\\u9fa5]+|[a-zA-Z]+|\\d+");

    /**
     * 计算64位 SimHash
     */
    public static long computeSimHash64(String text) {
        int[] vector = new int[HASH_BITS];
        
        // 分词
        List<String> tokens = tokenize(text);
        
        for (String token : tokens) {
            long hash = MurmurHash.hash64(token);
            for (int i = 0; i < HASH_BITS; i++) {
                if ((hash & (1L << i)) != 0) {
                    vector[i]++;
                } else {
                    vector[i]--;
                }
            }
        }

        long simHash = 0;
        for (int i = 0; i < HASH_BITS; i++) {
            if (vector[i] > 0) {
                simHash |= (1L << i);
            }
        }
        return simHash;
    }

    /**
     * 海明距离
     */
    public static int hammingDistance(long hash1, long hash2) {
        return Long.bitCount(hash1 ^ hash2);
    }

    /**
     * 提取前缀（用于分段索引）
     */
    public static String extractPrefix(long simHash, int segment, int bits) {
        int shift = segment * bits;
        long mask = (1L << bits) - 1;
        return String.valueOf((simHash >>> shift) & mask);
    }

    private static List<String> tokenize(String text) {
        List<String> tokens = new ArrayList<>();
        Matcher m = TOKENIZER.matcher(text);
        while (m.find()) {
            String group = m.group();
            if (group.matches("[\\u4e00-\\u9fa5]+") && group.length() >= 2) {
                // 中文：bigram
                for (int i = 0; i < group.length() - 1; i++) {
                    tokens.add(group.substring(i, i + 2));
                }
            } else {
                tokens.add(group.toLowerCase());
            }
        }
        return tokens;
    }
}
```

## 附录 B：文本标准化器

```java
public class TextNormalizer {

    /**
     * 标准化题干文本，用于匹配前处理
     * - 全角 → 半角
     * - 去除多余空格
     * - 统一数学符号
     * - 去除题号前缀
     */
    public static String normalize(String text) {
        if (text == null) return "";

        String result = text;

        // 1. 全角转半角
        result = fullWidthToHalfWidth(result);

        // 2. 去题号前缀 (如 "1.", "（1）", "第1题", "1、")
        result = result.replaceAll("^[\\d一二三四五六七八九十]+[.、)）]\\s*", "");
        result = result.replaceAll("^第[\\d一二三四五六七八九十]+题[.、)）]?\\s*", "");

        // 3. 统一数学符号
        result = result.replace("×", "*")
                       .replace("÷", "/")
                       .replace("≈", "≈")  // 保留
                       .replace("≠", "≠")  // 保留
                       .replace("≤", "<=")
                       .replace("≥", ">=");

        // 4. 多空格合并
        result = result.replaceAll("\\s+", " ").trim();

        // 5. 去除首尾标点
        result = result.replaceAll("^[\\s，。、：；]+|[\\s，。、：；]+$", "");

        return result;
    }

    private static String fullWidthToHalfWidth(String text) {
        StringBuilder sb = new StringBuilder();
        for (char c : text.toCharArray()) {
            if (c >= 0xFF01 && c <= 0xFF5E) {
                sb.append((char) (c - 0xFEE0));
            } else if (c == 0x3000) {
                sb.append(' ');
            } else {
                sb.append(c);
            }
        }
        return sb.toString();
    }
}
```
