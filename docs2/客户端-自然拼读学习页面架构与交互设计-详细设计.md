## 1. 设计目标

| 目标 | 说明 | 度量 |
| --- | --- | --- |
| 听说先行 | L1-L7 阶段语音类练习占比 ≥ 60%，首屏默认播放标准发音 | 练习类型投放符合服务端编排 |
| 零文字门槛 | 3-6 岁用户无需阅读即可完成核心交互，全部指令带语音播报 | 用户任务完成率 |
| 短平快会话 | 单次会话 6-10 题、3-8 分钟，超时自动收束 | 服务端 `expireAt` 约束 |
| 防挫败 | 一次错误不判负，二次通过折算 0.6；TRY_AGAIN 永不出现 ✗ 图标 | 反馈动效规范 |
| 分龄硬规则 | 3-6 岁默认仅点选/语音练习，无拖拽精度要求、无计时压力 | 题型投放矩阵（§4.3.2） |
| 防沉迷联动 | 单会话 ≤ 10 分钟，全局时长硬顶不可绕过（红线） | 全局事件收束 |
| 离线可用 | L1-L3 音频随安装包内置，核心学习断网可续 | 离线包内置清单 |

**本模块不做的事：**

1. 不做单词中文释义/拼写听写闯关（归属英语词汇模块，本模块只通过事件向其输出"已解码词"）。
2. 不做 IPA 音标教学（内容包 `phonetic` 字段仅供家长端展示）。
3. 不做整句情景对话（归属英语口语模块）。
4. 不做字母书写教学（L8+ 的 `letter_trace` 为描红组件，书写系统教学归属英语书写专项，后续批次）。

## 4. 核心页面设计

### 4.1 拼读学习主页 (PhonicsHomePage)

**数据源**：`GET /api/v1/phonics/path`（BFF 裁剪版响应，契约见服务端 §4.2）。

**布局**（竖屏、单手可触、顶部 1/3 为视觉区）：

```
┌─────────────────────────────┐
│   ★ 自然拼读  Phonics        │ ← 标题栏（无返回键时隐藏）
│ ┌─────────────────────────┐ │
│ │   阶段地图（横向缩略）     │ │ ← 当前阶段大卡片 + 前后各 1 阶段
│ │   L3 ●●●○○  CVC Blending │ │ ← progress "6/18" 星星进度
│ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │
│ │ 🌞 今日计划               │ │
│ │ 新学 3 项 · 复习 2 项     │ │
│ │ [ 开始今日学习 ]（大按钮） │ │ ← 主 CTA，高 64dp
│ └─────────────────────────┘ │
│ [ 🔄 只练复习 ] [ ⚡ 趣味快测 ]│ ← 次级入口，高 56dp │
│ ┌─────────────────────────┐ │
│ │ 📊 我的能力（雷达缩略图）  │ │ ← 仅家长绑定后展示明细
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

**交互规则：**

1. **首次进入**（本地无 `phonics_path_initialized` 标记）：自动调用 `PUT /api/v1/phonics/path/init`，成功后置标记；若用户 ≥ 7 岁且未完成定级，主 CTA 替换为"先做 8 题小测试，从适合的阶段开始"（可跳过）。
2. **下拉刷新**：重拉 path；失败时保留旧数据 + 顶部气泡提示（幼儿端文案："网络有点慢，先看看之前的吧"）。
3. **防沉迷联动**：进入页面前先查全局时长余额；余额 < 单次预估时长（`todayPlan.estimatedMin`）时主 CTA 置灰并引导休息（文案归属防沉迷模块，本模块不自证）。

### 4.2 入门定级快测 (PlacementQuizFlow)

**数据源**：`POST /api/v1/phonics/placement`（8 题，服务端 §4.9）。

**流程**：引导页（可跳过）→ 逐题作答（4 题型：字母名选择/字母音听辨/CVC 拼读/高频词闪认）→ 提交（`clientRequestId` 幂等）→ 结果页动画 → 跳主页。

**规则**：

| 规则 | 说明 |
| --- | --- |
| 中途退出 | 不保存进度，下次重新全量作答（快测仅 8 题，无断点必要） |
| 重复提交 | 服务端 58415 幂等返回首次定级，客户端静默接受 |
| 跳过语义 | 跳过 = 默认 L1 起步，本地记录 `placement_skipped=true` 不再强制弹窗（家长可手动重测） |
| 题型渲染 | 完全复用练习会话渲染器（§4.3.2），只是无进度星星、无复习混排 |

### 4.3 练习会话 (PhonicsSessionPage)

#### 4.3.1 会话生命周期

```
创建会话 ──→ 逐题作答（含语音跟读异步回填）──→ 全部答完 ──→ 结算页
   │                                            │
   │←── 58408 进行中重复建会话：恢复原会话 ────────┤
   │←── 58404 会话过期：静默建新会话 ─────────────┤
   │←── 防沉迷硬顶：全局收束，服务端置 ABANDONED ─┤
```

**创建**：`POST /api/v1/phonics/sessions`，body `{stageCode, sessionType, clientRequestId}`；`clientRequestId = uuid v4`（每次新建生成一次，重试复用同一值，15 分钟幂等窗口）。

**收束**：全部题目 `progress.answered == total` 后自动调 `POST /api/v1/phonics/sessions/{id}/complete`，报告到达后跳结算页。重复 complete（58407 语义）幂等返回首份报告，客户端直接使用。

**中途退出**：幼儿端不设"确认退出"弹窗（防误触叠加挫败感），直接退后台；服务端 10 分钟无心跳置 ABANDONED，已答部分照常计掌握度。家长面板可见中断记录。

#### 4.3.2 练习渲染器矩阵（16 类）

会话容器按 `exercise.type` 分发到渲染器。所有渲染器共享：顶部进度条、底部反馈层、≥88dp 触达区域、300ms 防误触抖动（《客户端-全局防误触与儿童安全交互保护机制》）。

| # | type | 渲染器组件 | 核心交互 | 分龄投放 |
| --- | --- | --- | --- | --- |
| 1 | letter_name_match | `LetterNameMatchBoard` | 看字母选发音：3 个发音按钮（服务端下发乱序） | 3岁+ |
| 2 | letter_sound_match | `LetterSoundMatchBoard` | 听音选字母：3 个大字母卡片，点击后震动+音 | 3岁+ |
| 3 | letter_trace | `LetterTraceBoard` | 字母描红：端侧笔画判定（L8+） | **7岁+ 或家长开启** |
| 4 | initial_sound | `InitialSoundBoard` | 听词选首音/首字母（cat → c） | 3岁+ |
| 5 | blending_tap | `BlendingTapBoard` | 依序点读音素→合成整词（§4.3.3） | 3岁+ |
| 6 | blending_slide | `BlendingSlideBoard` | 滑读条拖动连续发音 | 3岁+ |
| 7 | word_build | `WordBuildBoard` | 拖拽/点选字母组词（3-6 岁点选模式，7岁+ 拖拽模式） | 3岁+（模式分龄） |
| 8 | word_to_picture | `WordToPictureBoard` | 看词选图，词义锚定 | 3岁+ |
| 9 | word_family_sort | `WordFamilySortBoard` | 词族归类拖拽分箱 | **7岁+ 或家长开启** |
| 10 | minimal_pair_listen | `MinimalPairBoard` | 最小对立对听辨（ship/sheep 两键选择） | 5岁+ |
| 11 | rhyme_match | `RhymeMatchBoard` | 押韵配对（cat/hat 连线或点选） | 5岁+ |
| 12 | digraph_spot | `DigraphSpotBoard` | 圈出二合音字母组合（sh/ch/th 高亮点击） | 5岁+ |
| 13 | sight_word_flash | `SightWordFlashBoard` | 高频词闪认（限时应答——**3-6 岁隐藏计时器，仅服务端计时**） | 3岁+ |
| 14 | sight_word_spell | `SightWordSpellBoard` | 高频词字母排序拼写 | **7岁+ 或家长开启** |
| 15 | sentence_decode | `SentenceDecodeBoard` | 可解码句朗读（录音条 + 句级 GOP） | 6岁+ |

#### 4.3.3 Blending 三步教学法（核心交互）

服务端编排数据（`interaction.steps` / `blendAudioKeys` / `wholeAudioKey` / `tempo`），客户端固定编排：

```
[第 1 步 单音] c ── a ── t        每字母独立卡片，依序点读（顺序敏感，
                                   只能点当前步；读错字母无惩罚，原地重读）
      ↓ 全部点完
[第 2 步 滑读] ca → at            自动连播 blendAudioKeys，滑读条动画
      ↓
[第 3 步 整词] cat!               wholeAudioKey + 图片弹出 + 烟花动效
      ↓
[可选] 跟读一次                    VoiceRecorderBar，结果只加成不计负
```

- `tempo=SLOW` 时字母间距 800ms、`NORMAL` 时 450ms，随该项掌握度由服务端下发，客户端不做本地推导。
- 跟读可选：跳过不扣分；完成跟读且 band=GOOD 时结算页星星 +1（展示层激励，权威计分在服务端）。

#### 4.3.4 反馈层（三档，永不判负文案）

| 结果 | 动效 | 语音（EN 主） | 规则 |
| --- | --- | --- | --- |
| GOOD（一次对 / band ≥ 0.80） | 超级星星 + 烟花 | `Super!` / `You got it!` / `Wonderful!` | 动效 ≤ 1.2s 自动进入下题 |
| OK（二次通过 / band 0.60-0.79） | 小星星 | `Nice try! One more time.` | 停顿 1.5s 进入下题 |
| TRY_AGAIN（二次仍错 / band < 0.60） | 无 ✗，示范重播按钮呼吸 | `Let's try together!` + 标准音重播 | 停顿 2s 进入下题 |

**红线**：任何路径不得出现红色 ✗、"错误"、"失败"字样；TRY_AGAIN 文案与动效由反馈文案库（服务端 §13.3）统一下发，客户端不本地造句。

### 4.4 语音跟读 (VoiceRecorderBar)

**组件职责**：录音采集 → 上传 → 等待回填 → 三档反馈。评分异步：提交录音后 `progress.answered` 不递增，最长等待 1.5s；超时转"先继续，稍后告诉你"（进入下一题，结果由 WS/下题反馈捎带，对齐《客户端-AI对话状态管理与消息流编排引擎》异步回填模式）。

```dart
// lib/phonics/widgets/voice_recorder_bar.dart
enum VoiceBarState { idle, recording, uploading, waiting, done, degraded }

class VoiceRecorderBar extends StatefulWidget {
  final String exerciseId;
  final int maxDurationSec;         // 服务端 maxDurationSec（默认 10s）
  final void Function(VoiceResult result) onResult;
  final VoidCallback onTimeout;     // 1.5s 未回填 → 跳过继续
}

class _VoiceRecorderBarState extends State<VoiceRecorderBar> {
  VoiceBarState _state = VoiceBarState.idle;
  int _attemptNo = 1;               // 第 2 次录音由服务端 attemptNo=2 语义承接

  Future<void> _start() async {
    // 长按 300ms 防误触后开始录音（对齐全局防误触规范）
    await AudioRecorder.start(sampleRate: 16000, channel: Mono);
    setState(() => _state = VoiceBarState.recording);
  }

  Future<void> _stopAndUpload() async {
    final file = await AudioRecorder.stop();
    setState(() => _state = VoiceBarState.uploading);
    try {
      final res = await PhonicsApi.submitVoice(
        exerciseId: widget.exerciseId,
        audio: file,
        attemptNo: _attemptNo,
      ); // POST /api/v1/phonics/exercises/{exerciseId}/voice (multipart)
      setState(() { _state = VoiceBarState.done; _attemptNo = 1; });
      widget.onResult(res);          // {band: GOOD|OK|TRY_AGAIN, feedback}
    } on PhonicsError catch (e) {
      if (e.code == 03612) {          // 额度不足：提示家长端文案，转点读模式
        _degradeToTapMode('read_quota_exhausted');
      } else if (e.code == 03613) {   // 评测不可用 → 服务端 D2 已中性放行，本地仅提示
        setState(() => _state = VoiceBarState.degraded);
        widget.onResult(const VoiceResult(band: 'OK', degraded: true));
      }
    }
  }
}
```

**红线**：幼儿端不出数字分、不出音素级明细；`weakestPhonemeHint` 不透出（仅家长端报告）。录音文件上传后本地即删（对齐幼儿语音不留存红线）。

### 4.5 会话结算页 (SessionReportPage)

### 4.6 阶段地图与内容包 (StageMapPage)

- L1-L10 纵向路径，节点三态：COMPLETED（金星）/ ACTIVE（呼吸光效）/ LOCKED（锁 + `unlockHint` 文案）。

## 5. 状态管理架构

### 5.1 BLoC/Cubit 依赖关系

```
PhonicsFeature
│
├── PhonicsHomeBloc（主页）
│   ├── 依赖 → PhonicsRepository（path/stats）
│   └── 输出 → todayPlan / stageMap / abilityRadar
│
├── PlacementCubit（定级快测）
│   ├── 依赖 → PhonicsRepository（placement）
│   └── 管理 → 8 题本地快照 → 提交 → 定级结果
│
├── PhonicsSessionBloc（会话，核心状态机）
│   ├── 依赖 → PhonicsRepository（sessions/responses/complete）
│   ├── 依赖 → PhonicsAudioService（音频播放）
│   ├── 依赖 → VoiceRecorderBar（录音）
│   └── 管理 → CREATED/IN_PROGRESS/COMPLETED 会话状态机（镜像服务端 §7.3）
│
├── StageMapCubit（阶段地图 + 内容包版本管理）
│   └── 依赖 → ContentBundleManager（ETag/304/预加载）
│
└── PhonicsParentCubit（家长面板，只读聚合）
```

### 5.2 会话状态机（客户端镜像）

```
Idle ──创建成功──→ Active(exercises, currentSeq)
   │                     │
   │                     ├── 全部答完 + complete 成功 ──→ Reported ──→ Idle
   │                     ├── 58404 过期 ──→ 静默重建 ──→ Active(新会话)
   │                     ├── 58408 进行中冲突 ──→ 恢复既有会话
   │                     └── 防沉迷全局事件 ──→ ForcedClose ──→ Idle
```

**守卫（客户端侧）：**

- **G1**：同一时刻最多一个活跃会话，重复进入 `/phonics/session` 先查本地活跃会话缓存。
- **G2**：作答提交携带 `Idempotency-Key = clientEventId`（`{sessionId}-{exerciseId}-{attemptNo}-{uuid8}`），网络重试复用同一键，防重复计分。
- **G3**：进入 COMPLETED 后渲染层锁定作答区（双保险，服务端 58405 为权威）。
- **G4**：防沉迷收束**无条件优先**于一切本地状态，不弹任何挽留弹窗（红线）。

## 7. 错误处理

### 7.1 错误码映射（03600-03699）

| 客户端码 | 服务端码 | 场景 | 幼儿端处理 |
| --- | --- | --- | --- |
| 03600 | 58400 | 通用 | 气泡"稍后再试一次吧" + 自动重试 1 次 |
| 03601 | 58401 | 阶段未发布 | 空态"内容准备中" |
| 03602 | 58402 | 阶段未解锁 | 锁态节点展示 unlockHint（点击播语音说明） |
| 03603 | 58403 | 会话不存在 | 重建会话 |
| 03604 | 58404 | 会话过期 | 静默自动建新会话，无感知 |
| 03605 | 58405 | 终态提交 | 静默丢弃 + 埋点（客户端不应出现，出现即 bug） |
| 03606 | 58406 | 未完成 complete | 静默补 complete |
| 03607 | 58407 | 终态 complete | 直接使用幂等报告 |
| 03608 | 58408 | 进行中重复建会话 | 恢复本地活跃会话 |
| 03609 | 58409 | 每日新学上限 | "今天的新知识学完啦，明天见！" + 引导复习入口 |
| 03610 | 58410 | 防沉迷硬顶 | 转防沉迷全局页（本模块零自证文案） |
| 03611 | 58411 | 幂等冲突 | 静默以首次结果渲染 |
| 03612 | 58412 | 语音额度不足 | 转点读模式 + 家长端提示 |
| 03613 | 58413 | 评测不可用 | 中性 band 放行 + "我们先练点读" |
| 03614 | 58414 | 录音非法 | 本地预检拦截（客户端不应出现） |
| 03615 | 58415 | 快测重复提交 | 幂等接受首次定级 |
| 03616 | 58416 | 路径版本冲突 | 静默重拉 path 后重试 |
| 03617 | 58417 | 内容包版本不存在 | 拉最新版本 |
| 03618 | 58418 | 年龄门控 | 提示家长端可开启进阶练习 |
| 03619 | 58419 | 复习注册失败 | 静默补偿队列，不阻断 |

### 7.2 弱网与重试

- 作答提交：指数退避 1s/2s/4s 共 3 次，最终失败本地持久化（Hive），网络恢复按 `clientEventId` 重放（对齐《客户端网络请求治理与弱网适配方案》与 D10 约定）。
- 语音上传：单次重试 1 次；仍失败按 03613 语义中性放行。
- 内容包：断点续传 + ETag；音频 404 时回退内置包（D3）。

## 10. 防误触与儿童安全（专项）

| 规则 | 实现 |
| --- | --- |
| 触达区域 | 所有可点元素 ≥ 88dp |
| 防误触 | 录音键长按 300ms 生效；连续点击抖动过滤 300ms |
| 退出保护 | 无返回手势直达系统桌面外的任何"退出"入口；系统返回键呼出呼吸暂停层（防沉迷模块接管） |
| 无第三方内容 | 模块内无任何外链/广告/UGC 入口 |
| 无负面标签 | 全链路无 ✗/红错/分数排名（能力雷达仅家长端） |
| 语音隐私 | 录音文件上传后即删本地副本；UI 隐私说明常驻家长面板 |
