# 理科解题 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

理科解题模块面向初中、高中学生，覆盖数学、物理、化学、生物四大学科，提供从题目条件提取、解题模型匹配、分步推导到方法总结的完整解题链路。该模块不是独立的交互入口，而是以**解题引擎**的形式嵌入 AI 辅导、拍照搜题、同步课堂等场景中，在检测到理科学科问题时自动激活。

### 1.2 目标用户

| 学段 | 学科 | 典型场景 |
| --- | --- | --- |
| 初中 | 数学、物理、化学 | 作业解题、单元复习、中考备考 |
| 高中 | 数学、物理、化学、生物 | 专题突破、高考冲刺、竞赛入门 |

### 1.3 核心原则

1. **启发优先**：先给思路提示，再逐步展开，避免直接给答案
2. **过程透明**：每一步推导必须说明依据（公式来源、定理名称）
3. **易错提醒**：在关键步骤标注常见错误点
4. **方法沉淀**：解题结束后总结通用方法论和同类题策略

### 4.2 渐进式获取步骤

**GET** `/api/v1/science/solve/{solveId}/steps`

查询参数：
| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `fromStep` | int | 从第几步开始获取（默认1） |
| `toStep` | int | 到第几步（含） |
| `revealAnswer` | boolean | 是否展示最终答案（默认false） |

响应体：
```json
{
  "code": 0,
  "data": {
    "solveId": "solve_20260519_abc123",
    "steps": [ ... ],
    "answerRevealed": false,
    "totalSteps": 5,
    "hasMore": true
  }
}
```

{

| 值 | 含义 |

## 5. Prompt 编排设计

### 5.1 理科解题 Prompt 模板

````
你是一位专业的{subject}教师，正在给{gradeLevel}学生讲解一道题。

## 学生题目
{question_text}

## 结构化条件
{structured_conditions}

## 教材章节上下文
{chapter_context}

## 相关知识点
{knowledge_points}

## 解题要求
1. 先分析题目类型和考查的知识点
2. 提取所有已知条件（包括隐含条件）
3. 选择合适的解题方法，说明选择理由
4. 严格分步推导，每一步必须：
   - 说明这一步在做什么
   - 写出使用的公式或定理（标注名称）
   - 代入数值计算（注意单位）
   - 标注可能的易错点（如果有）
5. 最后总结：
   - 答案（带单位）
   - 解题方法归纳
   - 同类题解题策略
   - 常见错误提醒

## 输出格式
严格按以下 JSON 结构输出：
{response_schema}

## 注意事项
- 讲解深度适合{gradeLevel}学生
- 计算过程保留合理有效数字
- 公式用 LaTeX 格式
- 如果有多种解法，优先选择最通用的方法
- 不要跳步，每一步都要写清楚
````

### 5.2 分学科 Prompt 变体

#### 数学专用补充

````
## 数学解题特别要求
- 几何题：先描述图形关系，标注已知和待求
- 函数题：先确定定义域，注意特殊点
- 证明题：明确已知→求证，逐步推导
- 计算题：列出详细计算过程，每步标注依据
- 注意区分"充分条件"和"必要条件"
````

#### 物理专用补充

````
## 物理解题特别要求
- 先画受力分析图/运动过程图（文字描述）
- 明确参考系和正方向
- 写出原始公式，再代入数值
- 必须带单位运算
- 注意矢量的方向性
- 多过程问题要分段处理，明确每段的初始条件
````

#### 化学专用补充

````
## 化学解题特别要求
- 先写出化学方程式（配平）
- 标注物质状态和反应条件
- 计算题要写清楚物质的量关系
- 有机题要写结构简式，标注官能团
- 注意反应是否完全、是否可逆
````

#### 生物专用补充

````
## 生物解题特别要求
- 遗传题先判断显隐性，再画遗传图解
- 实验设计题写清自变量、因变量、无关变量
- 注意专业术语的准确性
- 生理过程要描述完整途径
````

### 6.2 条件提取器

```python
import re
from dataclasses import dataclass, field

@dataclass
class Condition:
    symbol: str            # 如 "v₀"
    value: str             # 如 "20"
    unit: str              # 如 "m/s"
    description: str       # 如 "初速度"
    is_implicit: bool = False  # 是否为隐含条件

@dataclass
class StructuredConditions:
    explicit: list[Condition] = field(default_factory=list)
    implicit: list[Condition] = field(default_factory=list)
    given_target: str = ""
    constraints: list[str] = field(default_factory=list)

# 常见隐含条件库
IMPLICIT_CONDITIONS = {
    "physics": {
        "default": [Condition("g", "9.8", "m/s²", "重力加速度", True)],
        "free_fall": [Condition("g", "9.8", "m/s²", "重力加速度", True)],
        "vacuum": [Condition("air_resistance", "0", "N", "忽略空气阻力", True)],
        "earth_surface": [Condition("g", "9.8", "m/s²", "重力加速度", True)],
    },
    "chemistry": {
        "standard_condition": [
            Condition("T", "25", "°C", "标准温度", True),
            Condition("P", "101.325", "kPa", "标准大气压", True),
        ],
    },
}

async def extract_conditions(
    question_text: str,
    classification: ProblemClassification,
    ocr_structured: Optional[dict] = None,
) -> StructuredConditions:
    """
    从题目文本中提取显式条件，并补充隐含条件。
    """
    prompt = f"""从以下题目中提取所有已知条件和求解目标。

题目：{question_text}
学科：{classification.subject.value}
题型：{classification.problem_type}

按以下 JSON 格式输出：
{{
  "explicit_conditions": [
    {{"symbol": "符号", "value": "值", "unit": "单位", "description": "描述"}}
  ],
  "given_target": "要求解的目标",
  "constraints": ["约束条件，如'忽略空气阻力'"]
}}"""
    
    result = await llm_client.chat(
        model=get_fast_model(),
        messages=[{"role": "user", "content": prompt}],
        response_format="json",
        temperature=0.05,
    )
    
    data = parse_json(result)
    
    conditions = StructuredConditions(
        explicit=[Condition(**c) for c in data.get("explicit_conditions", [])],
        given_target=data.get("given_target", ""),
        constraints=data.get("constraints", []),
    )
    
    # 自动补充隐含条件
    subject = classification.subject.value
    for pattern, implicits in IMPLICIT_CONDITIONS.get(subject, {}).items():
        if pattern == "default" or pattern in classification.sub_types:
            for impl in implicits:
                if not any(e.symbol == impl.symbol for e in conditions.explicit):
                    conditions.implicit.append(impl)
    
    return conditions
```

```python
from enum import Enum
from dataclasses import dataclass

class RevealLevel(str, Enum):
    IDEA_ONLY = "idea"           # 仅展示思路
    STEPS_PARTIAL = "partial"    # 部分步骤
    STEPS_ALL = "full"           # 所有步骤
    ANSWER = "answer"            # 展示最终答案

@dataclass
class RevealPolicy:
    """控制解题内容的渐进展示策略"""
    
    # 默认策略：先展示思路，学生可以点击查看下一步
    default_sequence: list[RevealLevel] = [
        RevealLevel.IDEA_ONLY,
        RevealLevel.STEPS_PARTIAL,
        RevealLevel.STEPS_ALL,
        RevealLevel.ANSWER,
    ]
    
    # 高中数学/物理难题可以逐步展示更多提示
    hard_problem_sequence: list[RevealLevel] = [
        RevealLevel.IDEA_ONLY,
        RevealLevel.STEPS_PARTIAL,   # 第一步
        RevealLevel.STEPS_PARTIAL,   # 前两步
        RevealLevel.STEPS_PARTIAL,   # 前三步
        RevealLevel.STEPS_ALL,
        RevealLevel.ANSWER,
    ]

    def get_reveal_content(
        self,
        solution: dict,
        current_level: RevealLevel,
        step_offset: int = 0,
    ) -> dict:
        """
        根据当前展示级别返回对应内容。
        """
        result = {
            "solveId": solution["solveId"],
            "revealLevel": current_level.value,
        }
        
        if current_level == RevealLevel.IDEA_ONLY:
            result["content"] = {
                "hint": solution["solutionPreview"]["ideaHint"],
                "knowledgePoints": solution["knowledgePoints"],
            }
        
        elif current_level == RevealLevel.STEPS_PARTIAL:
            steps = solution["solutionSteps"]
            visible = steps[:step_offset + 1]
            result["content"] = {
                "steps": visible,
                "currentStep": step_offset + 1,
                "totalSteps": len(steps),
                "hasMore": step_offset + 1 < len(steps),
            }
        
        elif current_level == RevealLevel.STEPS_ALL:
            steps = solution["solutionSteps"]
            result["content"] = {
                "steps": steps,
                "totalSteps": len(steps),
                "answerRevealed": False,
            }
        
        elif current_level == RevealLevel.ANSWER:
            result["content"] = {
                "steps": solution["solutionSteps"],
                "answer": solution["solutionPreview"]["answerPreview"],
                "methodSummary": solution["methodSummary"],
                "answerRevealed": True,
            }
        
        return result
```

### 6.4 解题结果校验器

```python
import re
from typing import Optional

@dataclass
class ValidationResult:
    is_valid: bool
    issues: list[str]
    warnings: list[str]
    corrected_answer: Optional[str] = None

async def validate_solution(
    question_text: str,
    solution_steps: list[dict],
    final_answer: str,
    subject: str,
) -> ValidationResult:
    """
    对模型输出的解题过程进行基本校验。
    """
    issues = []
    warnings = []
    
    # 1. 检查步骤完整性
    step_types = [s["type"] for s in solution_steps]
    if "summary" not in step_types:
        warnings.append("解题过程缺少总结步骤")
    
    # 2. 检查公式格式（LaTeX）
    for step in solution_steps:
        for formula in step.get("formulas", []):
            latex = formula.get("latex", "")
            if latex and not _is_valid_latex(latex):
                issues.append(f"步骤{step['stepIndex']}的公式格式可能有误: {latex}")
    
    # 3. 检查单位一致性（物理/化学）
    if subject in ("physics", "chemistry"):
        unit_issues = _check_unit_consistency(solution_steps)
        issues.extend(unit_issues)
    
    # 4. 检查答案格式
    if not final_answer or final_answer.strip() == "":
        issues.append("缺少最终答案")
    
    # 5. 数值合理性检查（使用第二个模型快速验证）
    if subject == "math" and _contains_calculation(final_answer):
        verify_prompt = f"""验证以下数学题的答案是否合理。
题目：{question_text}
给出的答案：{final_answer}

只回答 YES 或 NO，以及简短理由。"""
        
        verify_result = await llm_client.chat(
            model=get_fast_model(),
            messages=[{"role": "user", "content": verify_prompt}],
            temperature=0.0,
            max_tokens=100,
        )
        
        if "NO" in verify_result.upper():
            warnings.append(f"答案验证存疑：{verify_result}")
    
    return ValidationResult(
        is_valid=len(issues) == 0,
        issues=issues,
        warnings=warnings,
    )


def _is_valid_latex(latex: str) -> bool:
    """检查 LaTeX 公式基本格式是否合理"""
    # 检查括号匹配
    open_count = latex.count("{")
    close_count = latex.count("}")
    if open_count != close_count:
        return False
    return True


def _contains_calculation(text: str) -> bool:
    """判断文本是否包含数值计算结果"""
    return bool(re.search(r'\d+\.?\d*', text))


def _check_unit_consistency(steps: list[dict]) -> list[str]:
    """检查物理/化学解题过程中的单位一致性"""
    issues = []
    for step in steps:
        for formula in step.get("formulas", []):
            latex = formula.get("latex", "")
            # 简化检查：如果公式中有数值运算，检查是否有单位
            if re.search(r'=\s*\d+\.?\d*', latex):
                if not re.search(r'\\text\{|\\mathrm\{', latex):
                    issues.append(
                        f"步骤{step['stepIndex']}的计算结果可能缺少单位"
                    )
    return issues
```

### 8.2 降级策略

```python
# 模型降级链
MODEL_FALLBACK_CHAIN = {
    "reasoning": [
        "deepseek-r1",          # 首选：强推理
        "qwen-qwq-32b",        # 备选：推理模型
        "gpt-4o",               # 兜底：通用模型
    ],
    "classification": [
        "gpt-4o-mini",          # 轻量快速
        "claude-3.5-haiku",
    ],
    "validation": [
        "gpt-4o-mini",          # 校验用轻量模型
        "qwen-turbo",
    ],
}

async def call_with_fallback(
    task: str,
    prompt: str,
    primary_model: str,
    **kwargs,
) -> str:
    """带降级的模型调用"""
    chain = MODEL_FALLBACK_CHAIN.get(task, [primary_model])
    
    # 确保 primary_model 在链首
    models = [primary_model] + [m for m in chain if m != primary_model]
    
    last_error = None
    for model in models:
        try:
            result = await llm_client.chat(
                model=model,
                messages=[{"role": "user", "content": prompt}],
                **kwargs,
            )
            return result
        except (ModelTimeoutError, ModelServerError) as e:
            last_error = e
            log.warning(f"模型 {model} 调用失败，尝试降级", error=str(e))
            continue
    
    raise ScienceSolveError(
        "SCIENCE_SOLVE_FAILED",
        f"所有模型均调用失败: {last_error}",
    )
```
