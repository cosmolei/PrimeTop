## 7. 功能细分清单

### 7.1 学生端功能清单

| 一级功能 | 二级功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| 账号体系 | 注册登录 | 手机号、验证码、第三方登录 | P0 |
| 账号体系 | 年级学段选择 | 设置学段、年级、教材版本 | P0 |
| AI 辅导 | 文字问答 | 输入问题获取讲解 | P0 |
| AI 辅导 | 语音提问 | 语音转文字后 AI 解答 | P1 |
| AI 辅导 | 连续追问 | 多轮上下文问答 | P0 |
| 拍题答疑 | 拍照识别 | OCR 识别题目 | P0 |
| 拍题答疑 | 分步解析 | 生成解题过程 | P0 |
| 拍题答疑 | 类题练习 | 推荐或生成同类题 | P1 |
| 同步课堂 | 教材目录 | 展示版本、年级、章节 | P0 |
| 同步课堂 | 章节学习 | 预习、复习、知识总结 | P0 |
| 错题本 | 错题收录 | 自动或手动加入错题 | P0 |
| 错题本 | 错因标签 | 归类错误原因 | P1 |
| 学情分析 | 学习记录 | 展示学习数据 | P0 |
| 学情分析 | 薄弱点分析 | 输出薄弱知识点 | P1 |
| 学习规划 | 每日任务 | 生成学习任务清单 | P1 |
| 作文辅导 | 作文批改 | 上传作文获取建议 | P1 |
| 文科背诵 | 背诵检测 | 文本或语音背诵练习 | P2 |
| 启蒙学习 | 拼音识字 | 低龄学习内容 | P1 |
| 个人中心 | 会员状态 | 订阅、权益、订单 | P0 |

### 7.2 家长端功能清单

| 一级功能 | 二级功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| 家长绑定 | 绑定学生账号 | 管理孩子账号 | P1 |
| 学情报告 | 周报/月报 | 查看学习时长、薄弱点、进步趋势 | P1 |
| 使用管理 | 时长控制 | 设置每日使用时长 | P1 |
| 使用管理 | 内容范围 | 设置可用学科和功能 | P2 |
| 消息提醒 | 学习提醒 | 接收计划完成情况 | P2 |
| 会员管理 | 订阅管理 | 家庭套餐、续费、发票 | P1 |

### 7.3 管理后台功能清单

| 一级功能 | 二级功能 | 说明 | 优先级 |
| --- | --- | --- | --- |
| 用户管理 | 用户查询 | 学生、家长、管理员账号管理 | P0 |
| 内容管理 | 教材管理 | 教材版本、章节、知识点维护 | P0 |
| 内容管理 | 题库管理 | 题目、解析、标签维护 | P1 |
| AI 管理 | Prompt 配置 | 按场景配置提示词模板 | P0 |
| AI 管理 | 模型配置 | 大模型供应商、参数、调用策略 | P0 |
| 审核管理 | 内容审核 | AI 输出、用户上传内容审核 | P1 |
| 数据看板 | 运营数据 | 活跃、留存、转化、调用成本 | P1 |
| 权限管理 | 角色权限 | 管理员、运营、内容编辑权限 | P0 |
