# 服务端-教师智能备课辅助与教学资源智能组装引擎 详细设计

## 1. 概述

### 1.1 模块定位

教师智能备课辅助与教学资源智能组装引擎是 PrimeTop 教师端的核心服务端模块之一。该模块面向 K12 全学段教师用户，提供 AI 驱动的备课辅助能力，包括：

- **教学设计自动生成**：基于课程进度、教材章节和教学目标，自动生成结构化教案
- **教学资源智能组装**：从题库、知识库、多媒体资源中智能匹配并组装教学素材包
- **课件内容辅助生成**：生成课堂讲解大纲、板书设计、PPT 内容框架
- **分层教学方案编排**：针对不同学情的学生群体生成差异化教学策略
- **教研协同与资源共享**：备课组成果共享与协作编辑

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 教案生成 | 根据教材章节、课标要求和教学目标生成完整教案 |
| 资源匹配 | 从全局题库、知识库、多媒体库中检索并推荐适配资源 |
| 课件组装 | 将文字、图片、公式、互动练习等组装为可用的课件包 |
| 教学策略推荐 | 基于班级学情数据生成分层教学建议 |
| 备课协作 | 支持备课组多人协同编辑与版本管理 |
| 备课成果分发 | 将备课成果一键分发至班级作业、课堂互动等场景 |

### 1.4 设计原则

1. **课标先行**：所有 AI 生成内容必须对齐课程标准和教材章节
2. **教师主导**：AI 辅助而非替代，教师可审核、修改、覆盖所有生成内容
3. **学情驱动**：备课内容需适配班级实际学情，避免"一刀切"
4. **资源复用**：备课成果可沉淀为校本资源库，支持跨学期复用
5. **渐进增强**：教师可从简单模板开始，逐步使用 AI 生成和智能组装

```typescript
interface LessonPlanProject {
  id: string;                    // 备课项目ID，UUID
  teacherId: string;             // 创建教师ID
  schoolId?: string;             // 所属学校ID
  subject: Subject;              // 学科
  stage: EduStage;               // 学段: PRIMARY|JUNIOR|SENIOR
  grade: Grade;                  // 年级
  textbookId: string;            // 教材版本ID
  chapterId: string;             // 章节ID
  lessonTitle: string;           // 课时标题
  lessonType: LessonType;        // 课型
  teachingObjectives: string[];  // 教学目标
  keyPoints: string[];           // 教学重点
  difficultPoints: string[];     // 教学难点
  durationMin: number;           // 预计课时时长（分钟）
  status: PlanStatus;            // 项目状态
  version: number;               // 当前版本号
  collaborators: string[];       // 协作教师ID列表
  sourceProjectId?: string;      // 引用来源项目ID（用于校本资源克隆）
  createdAt: string;             // 创建时间
  updatedAt: string;             // 更新时间
  publishedAt?: string;          // 发布时间
}

type LessonType = 
  | 'NEW_KNOWLEDGE'    // 新授课
  | 'REVIEW'            // 复习课
  | 'EXERCISE'          // 练习课
  | 'EXPERIMENT'        // 实验课
  | 'PROJECT'           // 项目/活动课
  | 'EXAM_ANALYSIS';    // 考试讲评课

type PlanStatus =
  | 'DRAFT'             // 草稿
  | 'AI_GENERATING'     // AI生成中
  | 'UNDER_REVIEW'      // 审核中
  | 'REVISION'          // 修订中
  | 'PUBLISHED'         // 已发布
  | 'ARCHIVED';         // 已归档
```

```typescript
  };

  differentiatedStrategies?: DifferentiatedStrategy[];
  
  // 教学反思（课后填写）
  reflection?: {
    effectiveness: number;        // 教学效果评分 1-5
    studentEngagement: number;    // 学生参与度 1-5
    adjustments: string;          // 改进建议

  };
  
  // AI生成元信息
  aiMeta?: {
    model: string;                // 生成所用模型
    promptVersion: string;        // Prompt模板版本
    generatedAt: string;          // 生成时间
    humanModified: boolean;       // 是否被人工修改
    modificationRatio: number;    // 修改比例（0-1）
```

### 4.3 教学资源智能组装算法

```python
"""
教学资源智能组装算法伪代码
目标：为备课项目自动匹配最优教学资源组合
"""

def assemble_resources(
    project: LessonPlanProject,
    content: LessonPlanContent,
    constraints: AssemblyConstraints,
    class_profile: Optional[ClassProfile] = None
) -> TeachingResourcePack:
    
    # Step 1: 提取资源需求清单
    resource_needs = extract_resource_needs(content)
    # 返回: [{usage: "INTRODUCTION", kp_ids: [...], difficulty: 2, type_pref: ["VIDEO", "IMAGE"]}, ...]
    
    # Step 2: 并行检索各来源
    candidates = parallel_search(
        needs=resource_needs,
        sources=[
            GlobalBankSearcher(),   # 全局题库+知识库+多媒体
            SchoolBankSearcher(school_id=project.school_id),
            AIGenerator(),          # AI实时生成（如生成针对性例题）
        ],
        constraints=constraints
    )
    
    # Step 3: 多维度评分
    scored = []
    for need, candidates_list in zip(resource_needs, candidates):
        for res in candidates_list:
            score = compute_assembly_score(
                resource=res,
                need=need,
                project=project,
                class_profile=class_profile
            )
            scored.append((need, res, score))
    
    # Step 4: 全局优化选择（避免重复、保证多样性）
    selected = greedy_select_with_diversity(
        scored_candidates=scored,
        constraints=constraints,
        diversity_rules={
            "max_same_source": 3,    # 同一来源最多3个
            "max_same_type": 4,      # 同一类型最多4个
            "require_media_variety": True,  # 必须包含至少2种媒体类型
        }
    )
    
    # Step 5: 差缺检测与补全
    gaps = detect_coverage_gaps(selected, resource_needs)
    for gap in gaps:
        # 使用AI生成补全缺失内容
        ai_resource = generate_supplementary_resource(gap, project)
        selected.append(ai_resource)
    
    # Step 6: 生成组装报告
    report = generate_assembly_report(selected, gaps, constraints)
    
    return TeachingResourcePack(
        resources=selected,
        assembly_strategy=constraints.strategy,
        assembly_report=report
    )


def compute_assembly_score(resource, need, project, class_profile):
    """计算资源-需求匹配度评分（0-1）"""
    
    # 知识点覆盖度（权重 0.30）
    kp_coverage = jaccard_similarity(
        resource.metadata.knowledge_point_ids,
        need.kp_ids
    )
    
    # 难度适配度（权重 0.20）
    if class_profile:
        target_difficulty = class_profile.average_ability_level
    else:
        target_difficulty = need.difficulty
    difficulty_match = 1.0 - abs(resource.metadata.difficulty - target_difficulty) / 5.0
    
    # 类型偏好匹配（权重 0.15）
    type_match = 1.0 if resource.type in need.type_pref else 0.5
    
    # 资源质量评分（权重 0.15）
    quality = resource.quality_score or 0.7
    
    # 学段年级匹配（权重 0.10）
    stage_match = 1.0 if resource.metadata.stage == project.stage else 0.3
    
    # 新鲜度（权重 0.05）
    freshness = compute_freshness(resource.created_at)
    
    # 校本优先加成（权重 0.05）
    source_bonus = 0.1 if resource.source_type == 'SCHOOL_BANK' else 0.0
    
    weights = {
        'kp_coverage': 0.30,
        'difficulty_match': 0.20,
        'type_match': 0.15,
        'quality': 0.15,
        'stage_match': 0.10,
        'freshness': 0.05,
        'source_bonus': 0.05
    }
    
    score = (
        kp_coverage * weights['kp_coverage'] +
        difficulty_match * weights['difficulty_match'] +
        type_match * weights['type_match'] +
        quality * weights['quality'] +
        stage_match * weights['stage_match'] +
        freshness * weights['freshness'] +
        source_bonus * weights['source_bonus']
    )
    
    return score
```

```python
def generate_differentiated_strategies(
    project: LessonPlanProject,

    for tier in ['ADVANCED', 'AVERAGE', 'STRUGGLING']:
        tier_students = class_profile.get_students_by_tier(tier)
        tier_mastery = chapter_mastery.get_tier_avg(tier)
        
        if tier == 'ADVANCED':
            strategy = generate_advanced_strategy(
                content, tier_mastery, tier_students
            )
            # 策略方向：拓展深度、引入竞赛/跨学科内容、自主探究
        
        elif tier == 'AVERAGE':
            strategy = generate_average_strategy(
                content, tier_mastery, tier_students
            )
            # 策略方向：巩固核心方法、适度提升、强化薄弱环节
        
        else:  # STRUGGLING
            strategy = generate_struggling_strategy(
                content, tier_mastery, tier_students
            )
            # 策略方向：降低难度、增加直观演示、课前预习指导
        
        strategies.append(strategy)
    
    # 4. 识别班级共性薄弱点
    weak_points = identify_class_weak_points(chapter_mastery)
    for wp in weak_points:

    return strategies, weak_points
```

### 4.5 协作编辑冲突解决策略

采用 **乐观锁 + 操作变换(OT) + 三态合并** 策略：

```
冲突场景：教师A和教师B同时编辑同一教案的不同段落

解决流程：
1. 每次编辑操作基于最新版本号 + 操作日志
2. 服务端维护操作序列化队列
3. 同一段落的编辑 → OT算法自动合并
4. 不同段落的编辑 → 直接合并，无冲突
5. 同一段落的矛盾修改 → 标记冲突，提示教师手动解决

冲突状态：
- AUTO_MERGED: 系统自动合并成功
- CONFLICT_DETECTED: 检测到冲突，需手动解决
- RESOLVED: 冲突已解决
```

```java
@RestController

    @PostMapping("/{id}/ai-generate")
    public SseEmitter aiGenerate(
            @PathVariable String id,
            @RequestBody @Valid AIGenerateRequest req,
            @AuthUser TeacherUser teacher
    ) {
        // SSE流式返回生成进度
        SseEmitter emitter = new SseEmitter(120_000L); // 2分钟超时
        
        LessonPlanProject project = lessonPlanService.getByIdAndCheckPermission(id, teacher);
        
        aiGenerator.streamGenerate(project, req, new ProgressCallback() {

            public void onProgress(GeneratePhase phase, double progress, String message) {
                try {
                    emitter.send(SseEmitter.event()
                            .name("progress")
                            .data(Map.of(
                                    "phase", phase,
                                    "progress", progress,
                                    "message", message
                            )));
                } catch (IOException e) {
                    emitter.completeWithError(e);
                }
            }
            
            @Override
            public void onCompleted(GenerateResult result) {
                try {
                    emitter.send(SseEmitter.event()
                            .name("completed")
                            .data(result));
                    emitter.complete();
                } catch (IOException e) {
                    emitter.completeWithError(e);
                }
            }
            
            @Override
            public void onError(GenerateException ex) {
                try {
                    emitter.send(SseEmitter.event()
                            .name("failed")
                            .data(Map.of(
                                    "errorCode", ex.getCode(),
                                    "message", ex.getMessage(),

@Service
@RequiredArgsConstructor
@Slf4j
public class AIPlanGenerator {
    
    private final ModelDispatchService modelDispatch;      // 多模型调度
    private final PromptOrchestrator promptOrchestrator;    // Prompt编排
    private final TextbookContentService textbookService;   // 教材内容

    private final ContentSafetyService contentSafety;       // 内容安全
    private final RedisTemplate<String, String> redis;
    
    private static final int MAX_RETRY = 2;
    private static final long GENERATE_TIMEOUT_MS = 90_000;
    
    /**
     * 流式生成教案
     */
    @Async("aiGenerateExecutor")
    public void streamGenerate(
            LessonPlanProject project,
            AIGenerateRequest req,
            ProgressCallback callback
    ) {
        String taskId = UUID.randomUUID().toString();
        MDC.put("taskId", taskId);
        MDC.put("projectId", project.getId());
        
        try {
            // Phase 1: 分析教学目标
            callback.onProgress(GeneratePhase.ANALYZING_OBJECTIVES, 0.15, "分析教学目标...");
            List<KnowledgePoint> kps = knowledgeGraph.getPointsByIds(
                    extractKnowledgePointIds(project)
            );
            CurriculumStandard cs = textbookService.getCurriculumStandard(
                    project.getTextbookId(), project.getChapterId()
            );
            
            // Phase 2: 检索教材资源
            callback.onProgress(GeneratePhase.RETRIEVING_RESOURCES, 0.35, "检索教材资源和知识点...");
            TextbookChapter chapter = textbookService.getChapter(project.getChapterId());
            List<KnowledgeDoc> docs = knowledgeGraph.getDocsByPoints(kps);
            List<SchoolResourceItem> schoolRefs = schoolResource.searchByChapter(
                    project.getSchoolId(), project.getChapterId(), 5
            );
            
            // Phase 3: 匹配练习题
            callback.onProgress(GeneratePhase.MATCHING_QUESTIONS, 0.55, "匹配适合的练习题...");
            ClassProfile profile = null;
            if (req.isAdaptToClassAbility() && req.getClassId() != null) {
                profile = classAnalysis.getClassProfile(req.getClassId());
            }
            
            QuestionSearchParams qParams = buildQuestionSearchParams(
                    kps, req.getPreferredDifficulty(), profile
            );
            List<Question> guidedQuestions = questionBank.search(
                    qParams.toBuilder().difficultyMax(3).limit(5).build()
            );
            List<Question> independentQuestions = questionBank.search(
                    qParams.toBuilder().difficultyMin(3).difficultyMax(4).limit(5).build()
            );
            List<Question> extensionQuestions = questionBank.search(
                    qParams.toBuilder().difficultyMin(4).limit(3).build()
            );
            
            // Phase 4: 组装Prompt并调用模型
            callback.onProgress(GeneratePhase.GENERATING_CONTENT, 0.75, "生成教案内容...");
            
            PromptContext context = PromptContext.builder()
                    .project(project)
                    .chapter(chapter)
                    .knowledgePoints(kps)
                    .curriculumStandard(cs)
                    .knowledgeDocs(docs)
                    .schoolResources(schoolRefs)
                    .guidedQuestions(guidedQuestions)
                    .independentQuestions(independentQuestions)
                    .extensionQuestions(extensionQuestions)
                    .classProfile(profile)
                    .additionalRequirements(req.getAdditionalRequirements())
                    .build();
            
            String prompt = promptOrchestrator.buildPrompt(
                    getSceneKey(project, req), context
            );
            
            ModelCallConfig config = ModelCallConfig.builder()
                    .scene("LESSON_PLAN_GENERATION")
                    .stage(project.getStage())
                    .subject(project.getSubject())
                    .temperature(0.7)
                    .maxTokens(8000)
                    .timeoutMs(GENERATE_TIMEOUT_MS)
                    .build();
            
            // 分段调用（避免单次token过长）
            LessonPlanContent newContent = new LessonPlanContent();
            
            for (String scope : req.getGenerateScope()) {
                String sectionPrompt = promptOrchestrator.buildSectionPrompt(
                        getSceneKey(project, req), context, scope
                );
                
                String sectionResult = modelDispatch.callWithRetry(
                        sectionPrompt, config, MAX_RETRY
                );
                
                // 安全校验
                SafetyCheckResult safety = contentSafety.check(sectionResult);
                if (!safety.isSafe()) {
                    log.warn("AI生成内容安全检查未通过: {}", safety.getReason());
                    sectionResult = contentSafety.sanitize(sectionResult);
                }
                
                mergeSectionToContent(newContent, scope, sectionResult, kps, 
                        guidedQuestions, independentQuestions, extensionQuestions);
            }
            
            // Phase 5: 后处理
            callback.onProgress(GeneratePhase.ASSEMBLING_RESOURCES, 0.90, "组装教学资源包...");
            newContent.setAiMeta(AiMeta.builder()
                    .model(config.getUsedModel())
                    .promptVersion(promptOrchestrator.getCurrentVersion())
                    .generatedAt(LocalDateTime.now())
                    .humanModified(false)
                    .modificationRatio(0.0)
                    .build()
            );
            
            // Phase 6: 保存新版本
            int newVersion = lessonPlanContentService.saveNewVersion(
                    project.getId(), newContent
            );
            
            // 更新项目状态
            lessonPlanService.updateStatus(project.getId(), PlanStatus.UNDER_REVIEW);
            
            GenerateResult result = GenerateResult.builder()
                    .contentVersion(newVersion)
                    .sectionsGenerated(req.getGenerateScope())
                    .resourceCount(countResources(newContent))
                    .differentiatedStrategies(
                            profile != null ? 3 : 0
                    )
                    .aiMeta(newContent.getAiMeta())
                    .build();
            
            callback.onCompleted(result);
            
        } catch (ModelCallException e) {
            log.error("AI模型调用失败", e);
            callback.onError(new GenerateException(
                    "AI_TIMEOUT", "AI生成超时，请重试", true, e
            ));
        } catch (Exception e) {
            log.error("AI教案生成失败", e);
            callback.onError(new GenerateException(
                    "INTERNAL_ERROR", "AI生成内部错误", false, e
            ));
        } finally {
            MDC.clear();
        }
    }

                project.getStage(),
                project.getSubject(),
                project.getLessonType()
        );

@Service
@RequiredArgsConstructor
public class ResourceAssembler {
    
    private final QuestionBankService questionBank;
    private final KnowledgeDocService knowledgeDocService;
    private final MultimediaResourceService mediaService;
    private final SchoolResourceService schoolResource;
    private final AIResourceGenerator aiResourceGen;
    
    /**
     * 智能组装教学资源包
     */
    public TeachingResourcePack assemble(
            LessonPlanProject project,
            LessonPlanContent content,
            AssemblyConstraints constraints,
            ClassProfile classProfile
    ) {
        // 1. 提取需求清单
        List<ResourceNeed> needs = extractResourceNeeds(content);
        
        // 2. 并行检索
        Map<ResourceNeed, List<ResourceItem>> candidates = parallelSearch(
                needs, project, constraints
        );
        
        // 3. 评分 + 选择
        List<ResourceItem> selected = new ArrayList<>();
        AssemblyReport.AssemblyReportBuilder reportBuilder = AssemblyReport.builder();
        
        for (ResourceNeed need : needs) {
            List<ScoredResource> scored = candidates.get(need).stream()
                    .map(r -> new ScoredResource(r, computeScore(r, need, project, classProfile)))
                    .sorted(Comparator.comparingDouble(ScoredResource::getScore).reversed())
                    .collect(Collectors.toList());
            
            // 应用约束过滤
            scored = applyConstraints(scored, constraints);
            
            // 选择最高分资源
            if (!scored.isEmpty()) {
                selected.add(scored.get(0).getResource());
            } else {
                // AI补全
                ResourceItem aiRes = aiResourceGen.generateForGap(need, project);
                selected.add(aiRes);
                reportBuilder.aiGeneratedCount(reportBuilder.aiGeneratedCount + 1);
            }
        }
        
        // 4. 多样性约束检查
        selected = enforceDiversity(selected, constraints);
        
        // 5. 生成报告
        AssemblyReport report = buildReport(selected, needs, constraints);
        
        return TeachingResourcePack.builder()
                .projectId(project.getId())
                .resources(selected)
                .assemblyStrategy(constraints.getStrategy())
                .assemblyReport(report)
                .build();
    }
    
    @Transactional(propagation = Propagation.REQUIRED, rollbackFor = Exception.class)
    public TeachingResourcePack assembleWithPersistence(
            LessonPlanProject project,
            LessonPlanContent content,
            AssemblyConstraints constraints,
            ClassProfile classProfile
    ) {
        TeachingResourcePack pack = assemble(project, content, constraints, classProfile);
        resourcePackRepository.save(pack);
        return pack;
    }
    
    private double computeScore(
            ResourceItem resource,
            ResourceNeed need,
            LessonPlanProject project,
            ClassProfile classProfile
    ) {
        // 实现同 4.3 中的评分逻辑
        double kpCoverage = computeKpCoverage(resource, need);
        double difficultyMatch = computeDifficultyMatch(resource, need, classProfile);
        double typeMatch = computeTypeMatch(resource, need);
        double quality = resource.getQualityScore() != null ? resource.getQualityScore() / 5.0 : 0.7;
        double stageMatch = resource.getMetadata().getStage().equals(project.getStage()) ? 1.0 : 0.3;
        double sourceBonus = resource.getSourceType() == ResourceSourceType.SCHOOL_BANK ? 0.1 : 0.0;
        
        return kpCoverage * 0.30 + difficultyMatch * 0.20 + typeMatch * 0.15 
             + quality * 0.15 + stageMatch * 0.10 + 0.05 + sourceBonus * 0.05;
    }
}

        ClassProfile profile = classAnalysis.getClassProfile(classId);
        
        // 2. 获取本章知识点掌握度
        List<StudentMastery> masteries = classAnalysis.getChapterMastery(
                classId, project.getChapterId()
        );

        List<DifferentiatedStrategy> strategies = new ArrayList<>();
        
        for (StudentTier tier : StudentTier.values()) {
            List<String> tierStudents = profile.getStudentsByTier(tier);
            double tierAvgMastery = getTierAvgMastery(masteries, tierStudents);
            
            DifferentiatedStrategy strategy = generateStrategyForTier(
                    project, tier, tierAvgMastery, tierStudents.size()
            );
            strategies.add(strategy);
        }
        
        // 4. 识别班级共性薄弱点
        List<ClassWeakPoint> weakPoints = identifyWeakPoints(masteries, project);
        
        return DifferentiationResponse.builder()
                .classAbilityDistribution(profile.getTierDistribution())
                .strategies(strategies)
                .classWeakPoints(weakPoints)
                .build();
    }

            LessonPlanProject project,
            StudentTier tier,
```

```java
@Service
@RequiredArgsConstructor
public class CollaborationLockService {
    
    private final StringRedisTemplate redis;
    
    private static final String LOCK_PREFIX = "plan:lock:";
    private static final long LOCK_TTL_SECONDS = 30;
    private static final long LOCK_WAIT_MS = 3000;
    
    private static final String LOCK_SCRIPT = """
        if redis.call('setnx', KEYS[1], ARGV[1]) == 1 then
            redis.call('expire', KEYS[1], ARGV[2])
            return 1
        else
            local current = redis.call('get', KEYS[1])
            if current == ARGV[1] then
                redis.call('expire', KEYS[1], ARGV[2])
                return 1
            end
            return 0
        end
        """;
    
    private static final String UNLOCK_SCRIPT = """
        if redis.call('get', KEYS[1]) == ARGV[1] then
            return redis.call('del', KEYS[1])
        else
            return 0
        end
        """;
    
    /**
     * 获取段落编辑锁（细粒度：projectId + jsonPath）
     */
    public boolean tryLockSection(String projectId, String jsonPath, String teacherId) {
        String lockKey = LOCK_PREFIX + projectId + ":" + jsonPath;
        DefaultRedisScript<Long> script = new DefaultRedisScript<>(LOCK_SCRIPT, Long.class);
        
        Long result = redis.execute(script,
                Collections.singletonList(lockKey),
                teacherId, String.valueOf(LOCK_TTL_SECONDS));
        
        return result != null && result == 1L;
    }
    
    /**
     * 释放段落锁
     */
    public boolean unlockSection(String projectId, String jsonPath, String teacherId) {
        String lockKey = LOCK_PREFIX + projectId + ":" + jsonPath;
        DefaultRedisScript<Long> script = new DefaultRedisScript<>(UNLOCK_SCRIPT, Long.class);
        
        Long result = redis.execute(script,
                Collections.singletonList(lockKey),
                teacherId);
        
        return result != null && result == 1L;
    }
    
    /**
     * 心跳续期（客户端每20秒调用一次）
     */
    public boolean heartbeat(String projectId, String jsonPath, String teacherId) {
        String lockKey = LOCK_PREFIX + projectId + ":" + jsonPath;
        String owner = redis.opsForValue().get(lockKey);
        
        if (teacherId.equals(owner)) {
            redis.expire(lockKey, LOCK_TTL_SECONDS, TimeUnit.SECONDS);
            return true;
        }
        return false;
    }
}
```

```java
                if (autoMerged.isPresent()) {
                    merged.add(autoMerged.get());
                } else {
                    conflicts.add(new ConflictItem(remote, conflictLocal));
                }
            }
        }
        
        return MergeResult.builder()
                .mergedOps(merged)
                .conflicts(conflicts)
                .autoResolved(conflicts.isEmpty())
                .build();
    }
}
```
