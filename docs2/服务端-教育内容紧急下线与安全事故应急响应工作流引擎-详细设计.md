# 服务端 - 教育内容紧急下线与安全事故应急响应工作流引擎 详细设计

## 1. 概述

### 1.1 模块定位

教育内容紧急下线与安全事故应急响应工作流引擎是 PrimeTop 平台内容安全体系的**最后一道防线**。当平台发现严重内容错误、知识性误导、违规内容、版权纠纷或监管要求下线等紧急情况时，本引擎负责以最快速度、最小影响范围完成内容下线、用户通知、问题追溯和事后复盘。

与常规内容审核管线（事前审核）和版权到期下线（计划性下线）不同，本模块专注于**突发性、紧急性、高影响面**的内容安全事故处理。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 紧急下线 | 一键将指定内容从所有渠道立即下线（APP、Web、小程序、API） |
| 多级缓存清理 | 清除 CDN 缓存、Redis 缓存、客户端本地缓存、搜索引擎索引 |
| 级联内容处理 | 识别并处理依赖该内容的题目、课程章节、学习路径、推荐列表等 |
| 用户通知 | 通知已学习/已收藏该内容的用户，告知内容存在问题 |
| 事故定级 | 根据内容严重程度和影响范围自动定级（P0~P3） |
| 应急响应编排 | 触发应急响应流程，通知相关人员（内容审核、教研、法务、管理层） |
| 数据追溯 | 完整记录事故发现、决策、执行、恢复的全链路操作日志 |
| 替代内容推荐 | 为已下线内容推荐替代学习资源 |
| 事后复盘 | 生成事故复盘报告，跟踪整改措施 |

### 1.3 触发场景

| 场景 | 示例 | 典型严重度 |
| --- | --- | --- |
| 知识性错误 | 数学题目解析步骤错误、历史事件年份错误 | P1 |
| 严重误导 | 物理公式使用错误导致结论相反、化学方程式配平错误 | P0 |
| 违规内容 | AI 生成内容含不当言论、题目含敏感政治表述 | P0 |
| 版权纠纷 | 收到出版社/作者投诉，要求立即下线 | P1 |
| 监管要求 | 教育主管部门要求下线某类内容 | P0 |
| 安全漏洞 | 内容渲染组件存在 XSS 漏洞、图片含恶意代码 | P0 |
| 用户大量投诉 | 短时间内收到大量关于某内容的用户投诉 | P1 |
| 关联事故 | 第三方供应商内容被曝存在问题 | P2 |
| 教材修订 | 教材版本更新导致内容不再适用（非紧急但需快速处理） | P2 |

**上游触发源：**
- 内容审核系统：自动化检测发现严重问题
- 用户反馈系统：用户举报/投诉触发
- 运营后台：人工发现并手动触发
- 监管通知：外部合规要求
- AI 质量监控：AI 输出质量异常告警

**下游执行目标：**
- CDN 边缘节点：缓存失效
- Redis 集群：缓存清除
- Elasticsearch：索引删除/更新
- 客户端：本地缓存清理标记
- 推送服务：用户通知下发

### 2.2 数据库表结构

#### 2.2.1 content_incident（内容安全事故）

```sql
CREATE TABLE content_incident (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    incident_no         VARCHAR(32) NOT NULL UNIQUE COMMENT '事故编号，如 INC-20260801-001',
    title               VARCHAR(500) NOT NULL COMMENT '事故标题',
    description         TEXT NOT NULL COMMENT '事故描述',
    
    -- 事故分类
    incident_type       TINYINT NOT NULL COMMENT '类型: 1=知识性错误 2=违规内容 3=版权纠纷 4=监管要求 5=安全漏洞 6=用户投诉 7=关联事故 8=教材修订',
    severity            TINYINT NOT NULL COMMENT '严重度: 0=P0(紧急) 1=P1(严重) 2=P2(一般) 3=P3(轻微)',
    
    -- 触发信息
    trigger_source      TINYINT NOT NULL COMMENT '触发来源: 1=自动检测 2=用户举报 3=人工发现 4=监管通知 5=供应商通知',
    trigger_user_id     BIGINT COMMENT '触发用户ID（用户举报时）',
    trigger_report_id   VARCHAR(64) COMMENT '关联的用户举报单号',
    
    -- 状态管理
    status              TINYINT NOT NULL DEFAULT 0 COMMENT '状态: 0=待处理 1=处理中 2=已下线 3=已恢复 4=已关闭 5=已复盘',
    assigned_to         BIGINT COMMENT '当前处理人ID',
    assigned_team       VARCHAR(100) COMMENT '当前处理团队',
    
    -- 时间线
    detected_at         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '发现时间',
    acknowledged_at     DATETIME COMMENT '响应确认时间',
    takedown_started_at DATETIME COMMENT '下线开始时间',
    takedown_completed_at DATETIME COMMENT '下线完成时间',
    resolved_at         DATETIME COMMENT '问题解决时间',
    closed_at           DATETIME COMMENT '事故关闭时间',
    
    -- 影响评估
    affected_content_count INT DEFAULT 0 COMMENT '受影响内容数量',
    affected_user_count    INT DEFAULT 0 COMMENT '受影响用户数量',
    
    -- SLA 管理
    response_sla_min    INT NOT NULL DEFAULT 15 COMMENT '响应SLA（分钟）',
    resolution_sla_min  INT NOT NULL DEFAULT 240 COMMENT '解决SLA（分钟）',
    sla_breached        TINYINT DEFAULT 0 COMMENT 'SLA是否违约: 0=否 1=是',
    
    -- 扩展信息
    root_cause          TEXT COMMENT '根本原因分析',
    resolution_summary  TEXT COMMENT '处理总结',
    prevention_measures TEXT COMMENT '预防措施',
    
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_status (status),
    INDEX idx_severity (severity),
    INDEX idx_type (incident_type),
    INDEX idx_detected (detected_at),
    INDEX idx_assigned (assigned_to)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容安全事故表';
```

## 3. 事故状态机设计

### 3.1 事故主状态机

```
                           ┌──────────────┐
                    创建    │   PENDING    │
                 ─────────▶ │   (待处理)    │
                           └──────┬───────┘
                                  │
                    ┌─────────────┼─────────────┐
                    │             │              │
                    ▼             ▼              ▼
           ┌────────────┐ ┌────────────┐ ┌────────────┐
           │ ESCALATED  │ │PROCESSING  │ │  CLOSED    │
           │ (已升级)    │ │ (处理中)    │ │ (已关闭)   │
           └─────┬──────┘ └─────┬──────┘ └────────────┘
                 │              │              ▲
                 │              │              │
                 └──────►──────┤              │
                                │              │
                    ┌───────────┤              │
                    │           │              │
                    ▼           ▼              │
           ┌────────────┐ ┌────────────┐      │
           │ TAKEDOWN   │ │TAKEDOWN    │      │
           │ _STARTED   │ │_COMPLETED  │      │
           │ (下线中)    │ │(已下线)     │      │
           └─────┬──────┘ └─────┬──────┘      │
                 │              │              │
                 └───►─────────┘              │
                                │              │
                    ┌───────────┤              │
                    │           │              │
                    ▼           ▼              │
           ┌────────────┐ ┌────────────┐      │
           │  RESOLVED  │ │RESTORED    │      │
           │ (已解决)    │ │(已恢复)     │      │
           └─────┬──────┘ └─────┬──────┘      │
                 │              │              │
                 └───►──────────┘              │
                        │                      │
                        ▼                      │
                 ┌────────────┐                │
                 │  REVIEWED  │───────────────►│
                 │ (已复盘)    │                │
                 └────────────┘                │
```

### 3.2 状态定义与转换规则

| 当前状态 | 允许的下一状态 | 触发条件 | 操作权限 |
| --- | --- | --- | --- |
| PENDING(0) | PROCESSING(1) | 处理人确认接手 | incident_handler |
| PENDING(0) | ESCALATED(1→特殊) | 超过响应SLA未确认 | 系统自动 |
| PENDING(0) | CLOSED(4) | 误报，直接关闭 | incident_manager |
| PROCESSING(1) | TAKEDOWN_STARTED(2) | 审批通过，开始执行下线 | incident_handler |
| TAKEDOWN_STARTED(2) | TAKEDOWN_COMPLETED(2→完成) | 所有内容下线执行完毕 | 系统自动 |
| TAKEDOWN_COMPLETED | RESOLVED(3) | 问题已修复或替代内容已上线 | incident_handler |
| TAKEDOWN_COMPLETED | RESTORED(3→恢复) | 内容修正后重新上线 | incident_handler |
| RESOLVED(3) | REVIEWED(5) | 复盘完成 | incident_manager |
| RESTORED | REVIEWED(5) | 复盘完成 | incident_manager |
| REVIEWED(5) | CLOSED(4) | 管理员确认关闭 | incident_admin |
| 任意状态 | CLOSED(4) | 管理员强制关闭 | incident_admin |

### 3.3 下线执行子状态机

单个内容的下线执行过程：

```
┌─────────┐     ┌─────────┐     ┌──────────┐     ┌──────────┐
│ PENDING │────▶│ PURGING │────▶│REMOVING  │────▶│COMPLETED │
 │ (待下线)│     │(清理缓存)│     │_FROM_DB  │     │ (已下线)  │
 └─────────┘     └────┬────┘     │(更新数据库)│     └──────────┘
                      │           └──────────┘
                      │ 失败
                      ▼
                ┌──────────┐
                │  FAILED  │─────▶ 重试 (最多3次)
                │ (下线失败) │
                └──────────┘
```

### 5.3 级联影响处理策略

| 级联类型 | 处理策略 | 说明 |
| --- | --- | --- |
| 关联题目 | `takedown` | 使用了该解析的题目一并下线 |
| 课程章节 | `mark_unavailable` | 章节标记为"内容更新中"，不可访问 |
| 学习路径 | `reroute` | 学习路径中该节点标记为"维护中"，提供绕过路径 |
| 推荐列表 | `remove_from_list` | 从所有推荐列表中移除该内容 |
| 错题本记录 | `keep_with_warning` | 保留用户错题记录，但添加"内容存疑"标记 |
| 收藏记录 | `keep_with_warning` | 保留收藏，添加"内容已更新"提示 |
| AI 对话历史 | `keep` | 对话历史保留不变，不做处理 |
| 知识图谱节点 | `mark_warning` | 知识点节点添加临时警告标记 |
| 试卷 | `takedown_if_unpublished` | 未发布试卷移除该题，已发布试卷标记异常题 |

```java
@Service
public class IncidentService {

    @Autowired
    private IncidentRepository incidentRepo;
    @Autowired
    private AffectedContentRepository affectedContentRepo;
    @Autowired
    private NotificationService notificationService;
    @Autowired
    private CascadeAnalyzer cascadeAnalyzer;

    /**
     * 创建内容安全事故
     */
    @Transactional
    public IncidentDTO createIncident(CreateIncidentRequest request) {
        // 1. 生成事故编号
        String incidentNo = generateIncidentNo();

        // 2. 自动定级（如果未指定严重度）
        int severity = request.getSeverity();
        if (severity < 0) {
            severity = autoAssessSeverity(request);
        }

        // 3. 确定 SLA
        int[] sla = getSlaBySeverity(severity);
        int responseSla = sla[0];
        int resolutionSla = sla[1];

        // 4. 创建事故记录
        ContentIncident incident = ContentIncident.builder()
            .incidentNo(incidentNo)
            .title(request.getTitle())
            .description(request.getDescription())
            .incidentType(request.getIncidentType())
            .severity(severity)
            .triggerSource(request.getTriggerSource())
            .triggerReportId(request.getTriggerReportId())
            .status(IncidentStatus.PENDING.getCode())
            .assignedTo(request.getAssignedTo())
            .assignedTeam(request.getAssignedTeam())
            .responseSlaMin(responseSla)
            .resolutionSlaMin(resolutionSla)
            .build();

        incident = incidentRepo.save(incident);

        // 5. 记录受影响内容
        List<IncidentAffectedContent> affectedContents = request.getAffectedContents()
            .stream()
            .map(item -> IncidentAffectedContent.builder()
                .incidentId(incident.getId())
                .contentType(item.getContentType())
                .contentId(item.getContentId())
                .takedownReason(item.getTakedownReason())
                .takedownStatus(TakedownStatus.PENDING.getCode())
                .build())
            .collect(Collectors.toList());
        affectedContentRepo.saveAll(affectedContents);

        // 6. 异步执行级联分析
        cascadeAnalyzer.analyzeCascadeImpactAsync(incident.getId());

        // 7. 记录操作日志
        logAction(incident.getId(), ActionType.CREATE, "系统", 
            "事故创建，严重度: " + severity);

        // 8. 发送紧急通知给值班人员
        notificationService.notifyOnCallStaff(incident);

        return IncidentDTO.fromEntity(incident);
    }

    /**
     * 自动定级算法
     */
    private int autoAssessSeverity(CreateIncidentRequest request) {
        int score = 0;

        // 内容类型权重
        if (request.getIncidentType() == IncidentType.SAFETY_VULNERABILITY.getCode()) {
            return Severity.P0.getCode(); // 安全漏洞直接 P0
        }
        if (request.getIncidentType() == IncidentType.REGULATORY_REQUIREMENT.getCode()) {
            return Severity.P0.getCode(); // 监管要求直接 P0
        }
        if (request.getIncidentType() == IncidentType.VIOLATION_CONTENT.getCode()) {
            score += 30;
        }
        if (request.getIncidentType() == IncidentType.KNOWLEDGE_ERROR.getCode()) {
            score += 15;
        }

        // 影响内容数量权重
        int contentCount = request.getAffectedContents().size();
        if (contentCount > 50) score += 30;
        else if (contentCount > 10) score += 20;
        else if (contentCount > 1) score += 10;
        else score += 5;

        // 触发来源权重
        if (request.getTriggerSource() == TriggerSource.REGULATORY.getCode()) {
            score += 40;
        } else if (request.getTriggerSource() == TriggerSource.USER_REPORT.getCode()) {
            score += 10;
        }

        // 综合评级
        if (score >= 60) return Severity.P0.getCode();
        if (score >= 40) return Severity.P1.getCode();
        if (score >= 20) return Severity.P2.getCode();
        return Severity.P3.getCode();
    }

    private int[] getSlaBySeverity(int severity) {
        switch (severity) {
            case 0: return new int[]{5, 60};      // P0: 响应5分钟，解决60分钟
            case 1: return new int[]{15, 240};     // P1: 响应15分钟，解决4小时
            case 2: return new int[]{30, 720};     // P2: 响应30分钟，解决12小时
            default: return new int[]{120, 2880};  // P3: 响应2小时，解决48小时
        }
    }
}
```

### 6.2 多级缓存清理执行器

```java
@Service
public class TakedownExecutor {

    @Autowired
    private CdnPurgeService cdnPurgeService;
    @Autowired
    private RedisCacheService redisCacheService;
    @Autowired
    private ElasticsearchService esService;
    @Autowired
    private ContentRepository contentRepo;
    @Autowired
    private CacheVersionService cacheVersionService;

    private final ExecutorService takedownPool = Executors.newFixedThreadPool(20);

    /**
     * 执行紧急下线（并行清理多级缓存）
     */
    public TakedownResult executeTakedown(Long incidentId, List<IncidentAffectedContent> contents) {
        List<CompletableFuture<ContentTakedownResult>> futures = contents.stream()
            .map(content -> CompletableFuture.supplyAsync(
                () -> takedownSingleContent(incidentId, content),
                takedownPool
            ))
            .collect(Collectors.toList());

        // 等待所有下线完成，最长等待30秒
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0]))
            .orTimeout(30, TimeUnit.SECONDS)
            .join();

        List<ContentTakedownResult> results = futures.stream()
            .map(CompletableFuture::join)
            .collect(Collectors.toList());

        // 递增客户端缓存版本号
        cacheVersionService.incrementGlobalCacheVersion();

        return TakedownResult.builder()
            .totalContents(contents.size())
            .successCount((int) results.stream().filter(r -> r.isSuccess()).count())
            .failedCount((int) results.stream().filter(r -> !r.isSuccess()).count())
            .results(results)
            .build();
    }

    /**
     * 单个内容的多级缓存清理
     */
    private ContentTakedownResult takedownSingleContent(
            Long incidentId, IncidentAffectedContent content) {
        
        ContentTakedownResult result = new ContentTakedownResult(
            content.getContentType(), content.getContentId());

        try {
            // Step 1: CDN 缓存清除
            boolean cdnPurged = retryWithBackoff(
                () -> cdnPurgeService.purgeContent(content.getContentType(), content.getContentId()),
                3, 500
            );
            result.setCdnPurged(cdnPurged);

            // Step 2: Redis 缓存清除
            Set<String> cacheKeys = buildCacheKeyPatterns(content);
            redisCacheService.deleteByPatterns(cacheKeys);
            result.setRedisPurged(true);

            // Step 3: ES 索引更新
            esService.updateContentStatus(
                content.getContentType(), 
                content.getContentId(), 
                "takedown"
            );
            result.setEsUpdated(true);

            // Step 4: 数据库状态更新
            contentRepo.updateStatus(
                content.getContentType(),
                content.getContentId(),
                ContentStatus.TAKEDOWN
            );

            // Step 5: 更新受影响内容记录状态
            content.setTakedownStatus(TakedownStatus.COMPLETED.getCode());
            content.setTakedownCompletedAt(LocalDateTime.now());
            content.setCdnPurged(cdnPurged);
            content.setRedisPurged(true);
            content.setEsIndexUpdated(true);
            content.setClientCacheInvalidated(true);

            result.setSuccess(true);

        } catch (Exception e) {
            log.error("内容下线失败 incidentId={} contentType={} contentId={}", 
                incidentId, content.getContentType(), content.getContentId(), e);
            content.setTakedownStatus(TakedownStatus.FAILED.getCode());
            result.setSuccess(false);
            result.setError(e.getMessage());
        }

        return result;
    }

    /**
     * 构建 Redis 缓存 key 匹配模式
     */
    private Set<String> buildCacheKeyPatterns(IncidentAffectedContent content) {
        Set<String> keys = new HashSet<>();
        String typePrefix = ContentType.fromCode(content.getContentType()).getPrefix();
        Long contentId = content.getContentId();

        // 内容详情缓存
        keys.add(String.format("content:%s:%d:*", typePrefix, contentId));

        // 内容列表缓存（推荐列表、搜索结果等）
        keys.add(String.format("recommend:*:%s:%d", typePrefix, contentId));
        keys.add(String.format("search:*:%s:%d", typePrefix, contentId));

        // 关联缓存（知识点关联、章节关联等）
        keys.add(String.format("related:%s:%d:*", typePrefix, contentId));

        // 题目特定缓存
        if (content.getContentType() == ContentType.QUESTION.getCode()) {
            keys.add(String.format("question:%d:*", contentId));
            keys.add(String.format("answer:%d:*", contentId));
            keys.add(String.format("question_detail:%d", contentId));
        }

        // 解析特定缓存
        if (content.getContentType() == ContentType.EXPLANATION.getCode()) {
            keys.add(String.format("explanation:%d:*", contentId));
        }

        return keys;
    }

    /**
     * 带退避的重试
     */
    private <T> T retryWithBackoff(Supplier<T> action, int maxRetries, long initialDelayMs) {
        Exception lastException = null;
        for (int i = 0; i < maxRetries; i++) {
            try {
                return action.get();
            } catch (Exception e) {
                lastException = e;
                if (i < maxRetries - 1) {
                    try {
                        Thread.sleep(initialDelayMs * (1L << i));
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }
        }
        throw new RuntimeException("操作失败，已重试" + maxRetries + "次", lastException);
    }
}
```

### 6.3 级联影响分析器

```java
@Service
public class CascadeAnalyzer {

    @Autowired
    private QuestionRepository questionRepo;
    @Autowired
    private LearningPathRepository learningPathRepo;
    @Autowired
    private RecommendationService recommendationService;
    @Autowired
    private CascadeImpactRepository cascadeRepo;

    @Async
    public void analyzeCascadeImpactAsync(Long incidentId) {
        List<IncidentAffectedContent> affectedContents = 
            getAffectedContents(incidentId);

        for (IncidentAffectedContent content : affectedContents) {
            List<CascadeImpact> impacts = analyzeSingleContent(content);
            cascadeRepo.saveAll(impacts);
        }
    }

    private List<CascadeImpact> analyzeSingleContent(IncidentAffectedContent content) {
        List<CascadeImpact> impacts = new ArrayList<>();
        Long contentId = content.getContentId();
        int contentType = content.getContentType();

        // 1. 查找关联题目
        if (contentType == ContentType.EXPLANATION.getCode()) {
            List<Long> relatedQuestionIds = questionRepo.findIdsByExplanationId(contentId);
            for (Long qId : relatedQuestionIds) {
                impacts.add(buildImpact(content, CascadeType.RELATED_QUESTION, qId,
                    "关联题目 ID=" + qId));
            }
        }

        // 2. 查找包含该内容的学习路径
        List<LearningPathNode> pathNodes = learningPathRepo
            .findByContentId(contentType, contentId);
        for (LearningPathNode node : pathNodes) {
            impacts.add(buildImpact(content, CascadeType.LEARNING_PATH, 
                node.getPathId(),
                "学习路径节点: " + node.getPathName()));
        }

        // 3. 查找推荐列表中的引用
        List<RecommendationRef> refs = recommendationService
            .findContentInRecommendations(contentType, contentId);
        for (RecommendationRef ref : refs) {
            impacts.add(buildImpact(content, CascadeType.RECOMMENDATION_LIST,
                ref.getListId(),
                "推荐列表: " + ref.getListName()));
        }

        // 4. 查找包含该内容的试卷
        if (contentType == ContentType.QUESTION.getCode()) {
            List<ExamPaperRef> examRefs = questionRepo.findExamsContainingQuestion(contentId);
            for (ExamPaperRef ref : examRefs) {
                impacts.add(buildImpact(content, CascadeType.EXAM_PAPER,
                    ref.getExamId(),
                    "试卷: " + ref.getExamName()));
            }
        }

        return impacts;
    }

    private CascadeImpact buildImpact(IncidentAffectedContent content, 
            CascadeType type, Long targetId, String desc) {
        return CascadeImpact.builder()
            .incidentId(content.getIncidentId())
            .affectedContentId(content.getId())
            .cascadeType(type.getCode())
            .cascadeTargetId(targetId)
            .cascadeTargetDesc(desc)
            .handleStatus(0)
            .build();
    }
}
```

### 6.4 SLA 监控与超时升级

```java
@Service
public class IncidentSlaMonitor {

    @Autowired
    private IncidentRepository incidentRepo;
    @Autowired
    private NotificationService notificationService;

    /**
     * 每30秒检查一次SLA状态
     */
    @Scheduled(fixedRate = 30000)
    public void checkSlaCompliance() {
        List<ContentIncident> activeIncidents = incidentRepo
            .findByStatusIn(Arrays.asList(
                IncidentStatus.PENDING.getCode(),
                IncidentStatus.PROCESSING.getCode(),
                IncidentStatus.TAKEDOWN_STARTED.getCode()
            ));

        for (ContentIncident incident : activeIncidents) {
            checkResponseSla(incident);
            checkResolutionSla(incident);
        }
    }

    private void checkResponseSla(ContentIncident incident) {
        if (incident.getAcknowledgedAt() != null) return;

        long elapsedMin = Duration.between(
            incident.getDetectedAt(), 
            LocalDateTime.now()
        ).toMinutes();

        if (elapsedMin >= incident.getResponseSlaMin()) {
            // SLA 违约
            if (incident.getSlaBreached() == 0) {
                incident.setSlaBreached((byte) 1);
                incidentRepo.save(incident);
            }

            // 自动升级
            if (elapsedMin >= incident.getResponseSlaMin() * 2) {
                escalateIncident(incident, "响应SLA超时2倍，自动升级");
            } else {
                // 发送告警
                notificationService.sendSlaWarning(incident, "response", elapsedMin);
            }
        }
    }

    private void checkResolutionSla(ContentIncident incident) {
        if (incident.getResolvedAt() != null) return;
        if (incident.getAcknowledgedAt() == null) return;

        long elapsedMin = Duration.between(
            incident.getAcknowledgedAt(),
            LocalDateTime.now()
        ).toMinutes();

        if (elapsedMin >= incident.getResolutionSlaMin()) {
            if (incident.getSlaBreached() == 0) {
                incident.setSlaBreached((byte) 1);
                incidentRepo.save(incident);
            }

            if (elapsedMin >= incident.getResolutionSlaMin() * 2) {
                escalateIncident(incident, "解决SLA超时2倍，自动升级");
            } else {
                notificationService.sendSlaWarning(incident, "resolution", elapsedMin);
            }
        }
    }

    private void escalateIncident(ContentIncident incident, String reason) {
        // P0 不再升级
        if (incident.getSeverity() == 0) {
            // P0 超时，通知更高层级管理人员
            notificationService.notifyManagementChain(incident, reason);
            return;
        }

        // 降低严重度数字（即提升优先级）
        int newSeverity = incident.getSeverity() - 1;
        incident.setSeverity(newSeverity);

        // 重新计算 SLA
        int[] sla = getSlaBySeverity(newSeverity);
        incident.setResponseSlaMin(sla[0]);
        incident.setResolutionSlaMin(sla[1]);

        incidentRepo.save(incident);

        // 通知升级
        notificationService.notifyEscalation(incident, reason);

        logAction(incident.getId(), ActionType.ESCALATE, "系统", reason);
    }
}
```

```java
public interface CdnPurgeProvider {
    boolean purge(String url);
    boolean batchPurge(List<String> urls);
    String getProviderName();
}

@Component("aliyunCdn")
public class AliyunCdnPurgeProvider implements CdnPurgeProvider {
    
    @Autowired
    private AliyunCdnClient cdnClient;

    @Override
    public boolean purge(String url) {
        PurgeRequest request = PurgeRequest.builder()
            .objectPath(url)
            .type("File")
            .build();
        PurgeResult result = cdnClient.purgeObjectCaches(request);
        return result.getPurgeId() != null;
    }

    @Override
    public boolean batchPurge(List<String> urls) {
        // 阿里云每次最多1000条
        Lists.partition(urls, 1000).forEach(batch -> {
            PurgeRequest request = PurgeRequest.builder()
                .objectPath(String.join("\n", batch))
                .type("File")
                .build();
            cdnClient.purgeObjectCaches(request);
        });
        return true;
    }

    @Override
    public String getProviderName() {
        return "aliyun";
    }
}

@Service
public class CdnPurgeService {

    @Autowired
    private List<CdnPurgeProvider> providers;
    @Autowired
    private ContentUrlBuilder urlBuilder;

    @Value("${cdn.primary-provider:aliyun}")
    private String primaryProvider;

    public boolean purgeContent(int contentType, Long contentId) {
        // 构建需要清除的URL列表
        List<String> urls = urlBuilder.buildContentUrls(contentType, contentId);

        // 使用主CDN供应商清除
        CdnPurgeProvider provider = getProvider(primaryProvider);
        boolean success = provider.batchPurge(urls);

        // 如果主供应商失败，尝试备用供应商
        if (!success) {
            for (CdnPurgeProvider fallback : providers) {
                if (!fallback.getProviderName().equals(primaryProvider)) {
                    success = fallback.batchPurge(urls);
                    if (success) break;
                }
            }
        }

        return success;
    }

    private CdnPurgeProvider getProvider(String name) {
        return providers.stream()
            .filter(p -> p.getProviderName().equals(name))
            .findFirst()
            .orElseThrow(() -> new IllegalStateException("CDN供应商未找到: " + name));
    }
}
```

```dart
class CacheVersionManager {
  static const String _cacheVersionKey = 'global_cache_version';
  
  /// 检查缓存版本是否更新
  static Future<void> checkCacheVersion() async {
    final response = await ApiClient.get('/api/v1/system/cache-version');
    final serverVersion = response['globalCacheVersion'] as int;
    
    final prefs = await SharedPreferences.getInstance();
    final localVersion = prefs.getInt(_cacheVersionKey) ?? 0;
    
    if (serverVersion > localVersion) {
      // 版本号变化，清除本地缓存
      await clearLocalCache();
      await prefs.setInt(_cacheVersionKey, serverVersion);
      
      // 刷新当前页面数据
      EventBus.instance.emit(CacheInvalidatedEvent());
    }
  }
  
  /// 清除本地缓存
  static Future<void> clearLocalCache() async {
    // 清除图片缓存
    await PaintingBinding.instance.imageCache.clear();
    
    // 清除 API 响应缓存
    await ApiCache.clearAll();
    
    // 清除学习内容本地缓存
    await ContentCache.clear();
    
    // 注意：不清除用户离线下载的学习资源包
    // 这些资源有自己的版本管理机制
  }
}
```

```java
// 限制单事故的并发下线操作数
@Component
public class TakedownConcurrencyLimiter {
    
    private final Semaphore globalSemaphore = new Semaphore(50); // 全局并发限制
    private final Map<Long, Semaphore> incidentLimiters = new ConcurrentHashMap<>();
    
    public boolean acquire(Long incidentId) {
        Semaphore incidentSem = incidentLimiters.computeIfAbsent(
            incidentId, k -> new Semaphore(20) // 单事故最多20并发
        );
        return globalSemaphore.tryAcquire() && incidentSem.tryAcquire();
    }
    
    public void release(Long incidentId) {
        Semaphore incidentSem = incidentLimiters.get(incidentId);
        if (incidentSem != null) incidentSem.release();
        globalSemaphore.release();
    }
}
```
