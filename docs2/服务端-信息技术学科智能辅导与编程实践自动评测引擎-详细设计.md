# 服务端-信息技术学科智能辅导与编程实践自动评测引擎 详细设计

## 1. 概述

### 1.1 模块定位

信息技术学科智能辅导与编程实践自动评测引擎（IT-Engine）是 PrimeTop 平台面向**信息技术学科**（小学Scratch图形化编程 -> 初中信息技术 -> 高中信息技术 -> 信息学竞赛NOI/CSP）的专业学科辅导引擎。

与通用的"教育AI代码执行沙箱"（ECS）不同，IT-Engine 聚焦于：
- **学科知识体系**：围绕国家课标的信息技术知识点（算法、数据结构、网络基础、数据库、人工智能初步等）
- **编程实践评测**：对学生提交的代码进行自动批改、质量评估和个性化反馈
- **算法思维培养**：通过可视化、分步推导帮助学生理解算法执行过程
- **分层适配**：从小学Scratch到高中算法竞赛，覆盖全学段编程能力培养

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 知识体系管理 | 信息技术学科知识点、考点、能力维度的结构化管理 |
| 编程题目管理 | 编程练习题库（含测试用例、评分标准、难度标签） |
| 代码自动评测 | 提交代码 -> 编译运行 -> 测试用例验证 -> 评分 -> 反馈 |
| 算法可视化 | 将算法执行过程分解为可视化步骤序列 |
| AI智能辅导 | 结合课标知识库的编程问题答疑与思路引导 |
| 代码质量分析 | 代码风格、时间/空间复杂度、可读性评估 |
| 个性化推荐 | 基于学生能力画像推荐适合的编程练习 |
| 抄袭检测 | 代码相似度检测与学术诚信度评估 |

### 1.3 依赖关系

```
                 学生端 / 教师端
    编程练习答题 | 代码提交 | 算法学习 | 信息技术同步课堂
                         |

                         |
          信息技术智能辅导与评测引擎 (IT-Engine)
          +---------------+---------------+
          |               |               |
   编程评测核心     学科辅导核心    算法可视化服务
          |               |               |
          +-------+-------+-------+-------+
                  |               |
          知识体系&题库管理    代码质量&查重
                  |
    +-------+-----+-----+--------+
    |       |           |        |
  ECS    AI模型     对象存储   数据库
 (沙箱)  (多模型)    (OSS)    (MySQL)
```

**上游调用方：**
- 学生端编程练习模块（代码提交、评测请求）
- AI 辅导对话引擎（编程相关问题路由到 IT-Engine）
- 同步课堂学习服务（信息技术章节内容）
- 教师端作业批改服务（编程作业自动评测）
- 学情分析服务（编程能力维度数据）

**下游依赖：**
- 教育AI代码执行沙箱 ECS（隔离代码执行环境）
- AI 大模型服务（编程辅导对话、代码分析）
- 题库管理服务（题目存储与检索）
- 知识图谱服务（知识点关联与前置依赖）
- 对象存储 OSS（代码文件、可视化结果）
- Redis（评测结果缓存、防重复提交）

### 1.4 设计原则

1. **安全第一**：学生代码在沙箱中执行，严格隔离，禁止网络访问和文件系统越权
2. **渐进式引导**：不直接给答案，先给思路提示、伪代码框架，再逐步展开
3. **课标对齐**：知识点体系严格对齐《义务教育信息科技课程标准》和《高中信息技术课程标准》
4. **多语言支持**：Scratch -> Python -> C++ -> Java，按学段递进
5. **可扩展评测**：评测器插件化，支持不同题型（函数题、完整程序题、OJ风格题、项目题）

## 2. 数据模型

### 2.1 数据库表结构

#### 2.1.1 it_knowledge_points（信息技术知识点）

```sql
CREATE TABLE it_knowledge_points (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    code            VARCHAR(64) NOT NULL UNIQUE COMMENT '知识点编码 如 IT-MS-ALGO-01',
    name            VARCHAR(128) NOT NULL COMMENT '知识点名称',
    category        VARCHAR(32) NOT NULL COMMENT '分类: algorithm/data_structure/programming/network/database/ai_basic',
    sub_category    VARCHAR(64) COMMENT '子分类: sorting/recursion/graph/tree',
    stage           VARCHAR(16) NOT NULL COMMENT '学段: primary/middle/high/competition',
    grade_level     VARCHAR(32) NOT NULL COMMENT '年级: g3-g6/g7-g9/g10-g12',
    bloom_level     VARCHAR(32) NOT NULL COMMENT '布鲁姆层级: remember/understand/apply/analyze/evaluate/create',
    prerequisites   JSON COMMENT '前置知识点ID列表',
    description     TEXT COMMENT '知识点详细描述',
    key_points      JSON COMMENT '要点列表',
    common_errors   JSON COMMENT '常见错误列表',
    exam_frequency  DECIMAL(3,2) DEFAULT 0.00 COMMENT '考试出现频率 0.00-1.00',
    difficulty      TINYINT DEFAULT 3 COMMENT '难度 1-5',
    status          TINYINT DEFAULT 1 COMMENT '1=启用 0=禁用',
    sort_order      INT DEFAULT 0,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category_stage (category, stage),
    INDEX idx_grade_level (grade_level)
```


#### 3.2.4 AI编程辅导

```
POST /api/v1/it/tutor
```

**请求体：**
```json
{
  "taskId": 10042,
  "question": "我的代码在TC09报错了，提示wrong_answer，但我本地测试没问题",
  "context": {
    "submissionId": "sub_20260707_a1b2c3d4",
    "conversationId": "conv_88001"
  },
  "hintLevel": 1
}
```

**响应（200 OK，SSE流式）：**
```
event: start
data: {"messageId":"msg_001"}

event: delta
data: {"content":"让我看看你在 TC09 这个测试用例的情况。\n\n"}

event: delta
data: {"content":"TC09 的期望输出是 `[3, 5]`，但你的代码输出的是 `[5, 3]`。\n\n"}

event: delta
data: {"content":"这说明你的算法逻辑是正确的——确实找到了两个数之和等于目标值。\n\n问题出在**返回顺序**上。\n\n"}
```

```python
class CodeEvaluator:
    """编程代码评测器核心"""

    def __init__(
        self,
        sandbox_client: SandboxClient,
        task_repository: TaskRepository,
        result_publisher: ResultPublisher,
    ):
        self._sandbox = sandbox_client
        self._tasks = task_repository
        self._publisher = result_publisher

    async def evaluate(
        self, submission: CodeSubmission, feedback_level: str = "standard"
    ) -> EvaluationResult:
        """评测主流程"""
        task = await self._tasks.get_by_id(submission.task_id)
        test_cases = await self._tasks.get_test_cases(task.id)

        # 1. 预检查：代码大小、禁止语法
        self._validate_code(submission.source_code, submission.language)

        # 2. 调用沙箱编译
        compile_result = await self._sandbox.compile(
            language=submission.language,
            source_code=submission.source_code,
            time_limit_ms=10000,
        )
        if not compile_result.success:
            return self._build_compile_error(submission, compile_result)

        # 3. 逐个执行测试用例
        case_results: list[CaseResult] = []
        for tc in test_cases:
            result = await self._run_single_case(
                submission, compile_result.executable_id, tc
            )
            case_results.append(result)
            # 若配置了 fail-fast，首个失败即停止
            if task.fail_fast and result.status != CaseStatus.PASSED:
                break

        # 4. 计算得分
        total_score = sum(
            cr.score for cr in case_results
        )
        passed = sum(
            1 for cr in case_results if cr.status == CaseStatus.PASSED
        )

        # 5. 复杂度推断
        complexity = self._infer_time_complexity(case_results, task.input_sizes)

        # 6. 代码质量分析
        quality = await self._analyze_code_quality(
            submission.source_code, submission.language
        )

        # 7. AI 生成反馈
        feedback = await self._generate_feedback(
            submission, task, case_results, quality, complexity, feedback_level
        )

        # 8. 抄袭检测（异步，不阻塞返回）
        asyncio.create_task(
            self._check_plagiarism(submission)
        )

        result = EvaluationResult(
            submission_id=submission.id,
            total_score=total_score,
            max_score=sum(tc.score_weight for tc in test_cases),
            passed_count=passed,
            total_count=len(test_cases),
            execute_time_ms=max(cr.time_ms for cr in case_results),
            peak_memory_kb=max(cr.memory_kb for cr in case_results),
            time_complexity=complexity,
            code_quality_score=quality.overall_score,
            quality_details=quality.to_dict(),
            feedback=feedback.text,
            detailed_results=[cr.to_dict() for cr in case_results],
            suggestions=feedback.suggestions,
        )

        # 9. 发布结果事件
        await self._publisher.publish(
            event="evaluation.completed",
            data=result.to_dict(),
        )
        return result

    async def _run_single_case(
        self, submission: CodeSubmission, executable_id: str, tc: TestCase
    ) -> CaseResult:
        """执行单个测试用例"""
        run_result = await self._sandbox.run(
            executable_id=executable_id,
            stdin=tc.input,
            time_limit_ms=tc.time_limit_ms or 2000,
            memory_limit_kb=tc.memory_limit_kb or 256_000,
        )

        if run_result.status == SandboxStatus.TIMEOUT:
            return CaseResult(
                case_code=tc.case_code,
                status=CaseStatus.TIME_LIMIT_EXCEEDED,
                score=0,
                time_ms=run_result.time_ms,
                explanation=f"运行超时 (限制 {tc.time_limit_ms}ms)",
            )

        if run_result.status == SandboxStatus.MEMORY_EXCEEDED:
            return CaseResult(
                case_code=tc.case_code,
                status=CaseStatus.MEMORY_LIMIT_EXCEEDED,
                score=0,
                memory_kb=run_result.memory_kb,
                explanation=f"内存超限 (限制 {tc.memory_limit_kb}KB)",
            )

        if run_result.status != SandboxStatus.SUCCESS:
            return CaseResult(
                case_code=tc.case_code,
                status=CaseStatus.RUNTIME_ERROR,
                score=0,
                explanation=run_result.stderr[:500],
            )

        # 比较输出（忽略行末空格和文末换行）
        actual = self._normalize_output(run_result.stdout)
        expected = self._normalize_output(tc.expected_output)

        if actual == expected:
            return CaseResult(
                case_code=tc.case_code,
                status=CaseStatus.PASSED,
                score=tc.score_weight,
                time_ms=run_result.time_ms,
                memory_kb=run_result.memory_kb,
            )
        else:
            return CaseResult(
                case_code=tc.case_code,
                status=CaseStatus.WRONG_ANSWER,
                score=0,
                expected_output=tc.expected_output if not tc.is_hidden else None,
                actual_output=run_result.stdout if not tc.is_hidden else None,
                explanation=tc.explanation,
            )
```

```python
class AlgorithmVisualizer:
    """算法执行过程可视化引擎"""

    # 可视化支持的算法模式
    SUPPORTED_PATTERNS = {
        "sorting": ["bubble_sort", "selection_sort", "insertion_sort",
                     "merge_sort", "quick_sort", "heap_sort"],
        "searching": ["linear_search", "binary_search", "dfs", "bfs"],
        "tree": ["bst_insert", "bst_delete", "bst_search",
                  "preorder", "inorder", "postorder"],
        "graph": ["dijkstra", "prim", "kruskal", "topological_sort"],
        "dp": ["knapsack", "lcs", "edit_distance"],
    }

    async def visualize(
        self,
        source_code: str,
        language: str,
        input_data: str,
        max_steps: int = 200,
    ) -> VisualizationSession:
        """生成算法执行的可视化步骤序列"""
        # 1. 静态分析：识别算法类型
        algo_pattern = self._detect_algorithm(source_code)

        # 2. 使用插桩方式在沙箱中执行代码
        instrumented = self._instrument_code(source_code, algo_pattern, language)
        trace = await self._sandbox.run_with_trace(
            source_code=instrumented,
            language=language,
            stdin=input_data,
            max_steps=max_steps,
        )

        # 3. 将原始 trace 转换为可视化步骤
        steps = self._convert_trace_to_steps(trace, algo_pattern)

        # 4. 如果步骤超限，进行关键步骤采样
        if len(steps) > max_steps:
            steps = self._sample_key_steps(steps, max_steps)

        return VisualizationSession(
            session_uuid=generate_uuid(),
            total_steps=len(steps),
            steps=steps,
            algorithm_pattern=algo_pattern,
        )

    def _instrument_code(self, code: str, pattern: str, language: str) -> str:
        """在代码中插桩以捕获执行状态"""
        if language == "python3":
            return self._instrument_python(code, pattern)
        elif language == "cpp":
            return self._instrument_cpp(code, pattern)
        else:
            raise UnsupportedLanguageError(language)

    def _instrument_python(self, code: str, pattern: str) -> str:
        """Python 代码插桩：通过 AST 改写注入状态记录"""
        tree = ast.parse(code)
        transformer = VisualizationTransformer(pattern)
        instrumented_tree = transformer.visit(tree)
        return ast.unparse(instrumented_tree)


class VisualizationTransformer(ast.NodeTransformer):
    """AST 改写器：在关键节点注入 trace 记录"""

    def visit_Compare(self, node: ast.Compare) -> ast.Compare:
        """在比较操作处注入比较记录"""
        self.generic_visit(node)
        return self._wrap_with_trace(node, "compare")

    def visit_Assign(self, node: ast.Assign) -> ast.Assign:
        """在赋值操作处注入变量状态记录"""
        self.generic_visit(node)
        return self._wrap_with_trace(node, "assign")

    def visit_For(self, node: ast.For) -> ast.For:
        """在循环迭代处注入步骤记录"""
        self.generic_visit(node)
        return self._wrap_with_trace(node, "loop_iter")
```

```python
class PlagiarismChecker:
    """代码抄袭检测引擎"""

    async def check(self, submission: CodeSubmission) -> PlagiarismResult:
        """对学生提交进行查重"""
        # 1. 获取候选集：同题目近期提交
        candidates = await self._get_candidates(
            task_id=submission.task_id,
            exclude_user_id=submission.user_id,
            days=30,
            limit=200,
        )

        if not candidates:
            return PlagiarismResult(similarity_score=0, matched_submissions=[])

        # 2. AST + Token 序列相似度比对
        target_ast = self._parse_to_ast(submission.source_code, submission.language)

        matches = []
        for candidate in candidates:
            cand_ast = self._parse_to_ast(
                candidate.source_code, candidate.language
            )
            similarity = self._ast_similarity(target_ast, cand_ast)

            if similarity > 0.60:  # 阈值60%
                matches.append(
                    MatchDetail(
                        submission_id=candidate.id,
                        user_id=candidate.user_id,
                        similarity=similarity,
                        segments=self._find_similar_segments(target_ast, cand_ast),
                    )
                )

        # 3. 排序取最高相似度
        matches.sort(key=lambda m: m.similarity, reverse=True)
        top_matches = matches[:10]

        max_sim = top_matches[0].similarity if top_matches else 0
        is_flagged = max_sim > 0.80  # 80%以上标记为疑似抄袭

        result = PlagiarismResult(
            submission_id=submission.id,
            similarity_score=max_sim * 100,
            matched_count=len(top_matches),
            matched_submissions=[m.to_dict() for m in top_matches],
            is_flagged=is_flagged,
            algorithm="ast_token",
        )

        # 4. 持久化查重记录
        await self._repository.save(result)

        # 5. 如果疑似抄袭，触发通知
        if is_flagged:
            await self._event_bus.publish(
                "plagiarism.flagged",
                {"submissionId": submission.id, "similarity": max_sim},
            )

        return result

    def _ast_similarity(self, ast1, ast2) -> float:
        """基于 AST token 序列的相似度计算"""
        tokens1 = self._ast_to_token_sequence(ast1)
        tokens2 = self._ast_to_token_sequence(ast2)
        # 使用改进的 RATCLIFF-OBERSHELP 算法
        return self._ratcliff_obershelp(tokens1, tokens2)
```

```python
class CodeQualityAnalyzer:
    """代码质量静态分析器"""

    async def analyze(
        self, source_code: str, language: str
    ) -> CodeQualityReport:
        """分析代码质量（不执行代码）"""
        if language == "python3":
            return await self._analyze_python(source_code)
        elif language == "cpp":
            return await self._analyze_cpp(source_code)
        elif language == "java":
            return await self._analyze_java(source_code)
        else:
            return CodeQualityReport(overall_score=0, details={}, reason="unsupported")

    async def _analyze_python(self, code: str) -> CodeQualityReport:
        """Python 代码质量分析"""
        scores = {}

        # AST 分析
        tree = ast.parse(code)

        # 1. 可读性分析
        scores["readability"] = self._score_readability(tree, code)

        # 2. 命名规范分析
        scores["naming"] = self._score_naming(tree)

        # 3. 模块化分析
        scores["modularity"] = self._score_modularity(tree)

        # 4. 代码风格分析（集成 pycodestyle）
        scores["style"] = await self._score_style(code)

        # 5. 安全性分析
        scores["safety"] = self._score_safety(tree)

        # 加权综合
        weights = {
            "readability": 0.30,
            "naming": 0.20,
            "modularity": 0.25,
            "style": 0.15,
            "safety": 0.10,
        }
        overall = sum(scores[k] * weights[k] for k in scores)

        return CodeQualityReport(
            overall_score=round(overall, 2),
            details=scores,
            issues=self._collect_issues(tree, code),
        )

    def _score_readability(self, tree: ast.AST, code: str) -> float:
        """可读性评分"""
        score = 100.0
        lines = code.strip().split("\n")

        # 长行扣分（>80字符）
        long_lines = sum(1 for l in lines if len(l) > 80)
        score -= long_lines * 2

        # 嵌套深度扣分（>4层）
        for node in ast.walk(tree):
            if isinstance(node, (ast.For, ast.While, ast.If)):
                depth = self._get_nesting_depth(node)
                if depth > 4:
                    score -= (depth - 4) * 5

        # 注释覆盖率
        comment_lines = sum(1 for l in lines if l.strip().startswith("#"))
        code_lines = len([l for l in lines if l.strip() and not l.strip().startswith("#")])
        if code_lines > 0:
            comment_ratio = comment_lines / code_lines
            if comment_ratio < 0.10:
                score -= 10

        return max(0, min(100, score))
```

## 8. 安全设计

### 8.1 代码安全过滤

```python
class CodeSecurityFilter:
    """提交代码安全过滤器"""

    # 禁止的 Python 模块/函数
    PYTHON_FORBIDDEN = {
        "import": ["os", "sys", "subprocess", "socket", "http",
                    "urllib", "requests", "shutil", "pickle",
                    "ctypes", "multiprocessing"],
        "functions": ["eval", "exec", "compile", "globals",
                       "locals", "vars", "__import__",
                       "open", "input"],  # input/open 在沙箱内被重定向
    }

    # 禁止的 C++ 头文件
    CPP_FORBIDDEN = {
        "includes": ["<cstdlib>", "<cstdio>", "<system>",
                      "<windows.h>", "<unistd.h>", "<pthread.h>"],
    }

    def validate(self, code: str, language: str) -> ValidationResult:
        """校验代码安全性"""
        if language == "python3":
            return self._validate_python(code)
        elif language == "cpp":
            return self._validate_cpp(code)
        elif language == "java":
            return self._validate_java(code)
        return ValidationResult(ok=False, reason="unsupported_language")

    def _validate_python(self, code: str) -> ValidationResult:
        """Python 代码安全校验"""
        tree = ast.parse(code)

        for node in ast.walk(tree):
            # 检查 import 语句
            if isinstance(node, ast.Import):
                for alias in node.names:
                    if alias.name in self.PYTHON_FORBIDDEN["import"]:
                        return ValidationResult(
                            ok=False,
                            reason=f"forbidden_import:{alias.name}",
                            message=f"不允许导入模块 {alias.name}",
                        )

            # 检查 from...import
            if isinstance(node, ast.ImportFrom):
                if node.module in self.PYTHON_FORBIDDEN["import"]:
                    return ValidationResult(
                        ok=False,
                        reason=f"forbidden_import:{node.module}",
                    )

            # 检查危险函数调用
            if isinstance(node, ast.Call):
                func_name = self._get_func_name(node.func)
                if func_name in self.PYTHON_FORBIDDEN["functions"]:
                    return ValidationResult(
                        ok=False,
                        reason=f"forbidden_function:{func_name}",
                    )

        return ValidationResult(ok=True)
```

### 9.2 编译缓存

```python
class CompileCache:
    """编译结果缓存，相同代码不重复编译"""

    async def get_or_compile(
        self, code_hash: str, language: str
    ) -> CompileResult:
        cache_key = f"it:compile:{language}:{code_hash}"
        cached = await self._redis.get(cache_key)
        if cached:
            return CompileResult.from_cache(cached)

        result = await self._sandbox.compile(code, language)
        if result.success:
            await self._redis.setex(
                cache_key, 3600, result.to_cache()
            )
        return result
```

### 10.1 降级策略

| 场景 | 降级方案 | 用户体验 |

| Redis不可用 | 直接查库，跳过缓存 | 响应稍慢但功能正常 |
