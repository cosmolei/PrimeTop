# 盈利模式与定价策略 - 详细设计文档

## 1. 模块概述

### 1.1 定位

盈利模式与定价策略（Monetization & Pricing Strategy）是 PrimeTop 商业化的顶层设计文档，定义整体收费模型、定价层级、转化漏斗、单位经济模型和成本治理策略。本文档不涉及支付通道、订单管理等基础设施实现（详见《支付与会员订阅-详细设计》和《增值服务与商品系统-详细设计》），而是聚焦于"怎么收钱、收多少、如何平衡体验与收益"的商业决策。

### 1.2 与其他模块的关系

| 关联模块 | 关系 |
|----------|------|
| 支付与会员订阅系统 | 本文档定义的定价方案由该系统执行 |
| 增值服务与商品系统 | 本文档定义的商品类型和定价由该系统承载 |
| 用户额度与API调用管控 | 本文档定义的用量配额由该模块限流 |
| 多模型调度与成本治理 | 本文档引用的成本数据由该模块提供 |
| 运营活动与成长激励体系 | 定价促销和优惠活动由该模块执行 |
| 数据埋点与关键指标系统 | 本文档定义的商业指标由该模块采集 |

### 1.3 设计原则

1. **教育优先**：不利用学习焦虑做营销，不在学生端展示价格信息（价格展示仅限家长端）
2. **透明公平**：权益说明清晰，无隐藏消费，无自动勾选附加项
3. **未成年人保护**：所有支付必须经过家长验证（密码/生物识别），符合《未成年人网络保护条例》
4. **成本可控**：AI 调用成本必须低于用户 ARPU，建立单位经济模型监控
5. **渐进付费**：先体验价值，再引导付费，避免前置高墙

## 2. 整体商业模式

### 2.1 Freemium + 订阅 + 增值 三层模型

```
┌─────────────────────────────────────────────────────────┐
│                     收入来源构成                          │
├──────────────┬──────────────┬──────────────┬─────────────┤
│  C端订阅收入  │  C端增值收入  │  B端合作收入  │  广告收入    │
│   (60-70%)   │   (15-20%)   │   (10-15%)   │  (0-5%)     │
└──────────────┴──────────────┴──────────────┴─────────────┘
```

> **注：** 广告收入为可选项，仅在家长端以非侵入方式展示教育类内容。学生端**绝不**展示任何广告。

### 2.2 用户分层与付费路径

```
免费用户 ──→ 体验核心功能 ──→ 触达用量限制 ──→ 引导订阅
  │                                                        │
  │          ┌──────────────────────────────┐               │
  └──→ 非活跃 ──→ 唤醒运营 ──→ 回流 ─────────┘               │
                                                           │
订阅用户 ──→ 月度会员 ──→ 引导年度（优惠）──→ 长期会员        │
  │                                                        │
  ├──→ 增值服务购买（次数包/专项包）──→ 提升ARPU              │
  │                                                        │
  └──→ 到期/取消 ──→ 挽留策略 ──→ 降级免费 ──→ 再次转化       │
```

### 3.3 免费用户限制策略

限制设计遵循"**足够体验价值，明确付费动力**"原则：

```
用户行为 ──→ 触达免费额度 ──→ 软提示（不阻断）
                │
                ├── 第1次触达：底部Toast提示"升级解锁更多"
                ├── 第2次触达：弹窗展示权益对比（可关闭）
                └── 第3次触达：当日该功能暂停，展示升级引导
                    │
                    └── 家长端同步推送"孩子学习热情高，建议解锁完整功能"
```

**关键规则：**
- 每日额度在 00:00（用户时区）重置
- 免费用户可观看 15 秒激励视频获得 +2 次AI问答（每日限 1 次，仅家长端操作）
- 学习规划等"规划类"功能对免费用户完全不可用（非用量限制），作为核心付费钩子

## 5. 单位经济模型（Unit Economics）

### 5.1 核心公式

```
毛利率 = (ARPU - 变动成本) / ARPU
目标毛利率 ≥ 60%

ARPU（月均）= 总订阅收入 / 月活付费用户
变动成本 = AI调用成本 + 存储成本 + 带宽成本 + 第三方服务费
```

### 5.2 AI 调用成本估算

| 场景 | 模型 | 单次Token估算 | 单次成本估算 | 日均调用量/活跃用户 |
|------|------|--------------|-------------|-------------------|
| AI问答 | GPT-4o-mini 级 | ~2000 token | ¥0.01 | 8次 |
| 解题推理 | GPT-4o 级 | ~4000 token | ¥0.08 | 3次 |
| 作文批改 | GPT-4o 级 | ~6000 token | ¥0.12 | 0.3次 |
| OCR识别 | 专用OCR | 1次/图 | ¥0.02 | 2次 |
| TTS语音 | 语音合成 | ~500字符 | ¥0.005 | 5次 |
| ASR语音 | 语音识别 | ~10秒 | ¥0.01 | 3次 |

**单日 AI 成本估算（付费用户）：**
```
问答: 8 × ¥0.01 = ¥0.08
解题: 3 × ¥0.08 = ¥0.24
作文: 0.3 × ¥0.12 = ¥0.036
OCR:  2 × ¥0.02 = ¥0.04
TTS:  5 × ¥0.005 = ¥0.025
ASR:  3 × ¥0.01 = ¥0.03

日成本 ≈ ¥0.45/付费用户
月成本 ≈ ¥13.5/付费用户
```

### 5.3 月度单位经济模型

| 指标 | 月度会员 | 年度会员(月均) | 免费用户 |
|------|---------|--------------|---------|
| 收入(ARPU) | ¥38 | ¥24.8 | ¥0 |
| AI调用成本 | -¥13.5 | -¥13.5 | -¥2.7 |
| 存储/带宽成本 | -¥1.5 | -¥1.5 | -¥0.5 |
| 支付通道费(0.6%) | -¥0.23 | -¥0.15 | ¥0 |
| **毛利润** | **¥22.77** | **¥9.65** | **-¥3.2** |
| **毛利率** | **59.9%** | **38.9%** | **N/A** |

> **⚠️ 关键风险：** 年度会员月均毛利仅 ¥9.65，如果 AI 成本上升 50%，毛利率将降至 20% 以下。必须建立模型降级和缓存策略来控制成本。

### 5.4 成本治理策略

```
用户请求 ──→ 权益校验 ──→ 用量检查 ──→ 模型路由
                                          │
                        ┌─────────────────┼─────────────────┐
                        │                 │                 │
                    简单问答          中等推理           复杂推理
                  GPT-4o-mini       GPT-4o-mini         GPT-4o
                   ¥0.01/次          ¥0.02/次          ¥0.08/次
                        │                 │                 │
                        └─────────────────┴─────────────────┘
                                          │
                                    缓存命中？
                                    ├── 是 → 直接返回（成本≈0）
                                    └── 否 → 调用模型 → 缓存结果
```

**成本控制措施：**

| 策略 | 说明 | 预期节省 |
|------|------|---------|
| 相似题缓存 | 题目相似度>95%直接返回缓存答案 | 30-40% |
| 模型分层路由 | 简单问题用小模型，复杂问题用大模型 | 20-30% |
| 答案预生成 | 高频题目预生成解析存入知识库 | 10-15% |
| 免费用户降级 | 免费用户仅使用最小模型 | 15-20% |
| 非高峰批量 | 深夜批量预生成热门内容 | 5-10% |
| 国产模型混用 | 非核心场景使用国产模型（成本更低） | 10-20% |

## 6. 转化漏斗与增长策略

### 6.1 付费转化漏斗

```
总下载量 (100%)
    │
    ▼ 注册激活 (70%) ──→ 优化注册流程，减少步骤
    │
    ▼ 首日使用 (50%) ──→ 新手引导，快速展示核心价值
    │
    ▼ 3日留存 (30%) ──→ 推送学习提醒，培养使用习惯
    │
    ▼ 7日活跃 (20%) ──→ 学情报告 teaser，展示付费功能价值
    │
    ▼ 触达免费限制 (12%) ──→ 合理限制设计，制造付费动力
    │
    ▼ 查看定价页 (8%) ──→ 清晰权益对比，限时优惠
    │
    ▼ 发起支付 (4%) ──→ 多种支付方式，家长端确认
    │
    ▼ 支付成功 (3.5%) ──→ 立即展示增值，强化获得感
    │
    ▼ 首月续费 (1.8%) ──→ 7天使用提醒，续费优惠推送
```

### 6.2 关键转化节点设计

#### 6.2.1 首次付费引导时机

| 同步课堂点击锁定的章节 | "升级解锁完整课程内容" | P1 |

#### 6.2.2 年度会员转化策略

```
月度会员（付费后第7天）──→ 推送"年费立省¥158"对比卡片
    │
    ├── 不转化（第25天）──→ 推送"续费前升级年费，额外赠送1个月"
    │
    └── 不转化（到期前3天）──→ 最终推送"最后机会：年费¥298 限时再减¥30"
```

#### 6.2.3 流失挽留策略

```
用户取消订阅 ──→ 原因调查弹窗
    │
    ├── "太贵了" ──→ 提供3个月半价优惠
    ├── "用得不多" ──→ 展示使用报告 + 1个月免费
    ├── "孩子不需要" ──→ 降级为免费，保留数据
    └── "其他原因" ──→ 转人工客服
```

### 6.3 增长飞轮

```
         内容质量 ──→ 学习效果
            ↑               │
            │               ▼
      AI 能力提升 ←── 用户口碑 ←── 家长推荐
            ↑               │
            │               ▼

## 9. 未成年人支付保护

### 9.1 家长验证流程

```
学生端点击"升级" ──→ 弹出"请家长协助操作"
    │
    ▼ 跳转家长验证页（或家长端推送）
    │
    ├── 方式1：家长密码验证
    ├── 方式2：家长指纹/面部识别
    └── 方式3：短信验证（家长预留手机号）
    │
    ▼ 验证通过 ──→ 展示定价页（仅此时展示价格）
    │
    ▼ 选择套餐 ──→ 支付确认（家长操作）

## 11. 定价调整机制

### 11.1 定价调整触发条件

| 触发条件 | 调整方向 | 决策流程 |
|----------|---------|---------|
| AI 模型成本大幅下降 | 降价或增加权益 | 产品 + 财务审批 |
| 竞品大幅调价 | 跟进或差异化 | 竞品分析 + CEO审批 |
| 付费转化率 < 2% | 降价/增加免费额度/优化限制 | 产品决策 |
| 毛利率 < 40% | 提价/收紧额度/降本 | 财务 + 产品审批 |
| 用户规模达新量级 | 阶梯定价调整 | 年度定价评审 |

### 11.2 老用户保护策略

- 价格上调时，现有订阅用户在当前周期内维持原价
- 续费时给予老用户专属折扣（年度续费9折）
- 连续订阅超12个月用户永久享受"创始会员价"

### 11.3 定价变更通知

- 价格调整前 30 天通知所有用户（APP内弹窗 + 家长端推送）
- 上调价格需在订阅到期前给用户 15 天"原价续费窗口"
- 所有通知使用中性语言，不施压
