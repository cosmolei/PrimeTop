## 1. 模块概述

### 1.1 背景与目标

PrimeTop 产品中大量业务场景依赖二维码作为线下/线上的信息传递媒介：

| 场景 | 说明 | 使用方 |
|------|------|--------|
| 家长绑定 | 学生端展示二维码，家长扫码绑定 | 学生→家长 |
| 加入班级 | 教师生成班级二维码，学生扫码加入 | 教师→学生 |
| 邀请好友 | 用户分享个人邀请二维码 | 学生→好友 |
| 学习报告分享 | 生成报告二维码嵌入分享图片 | 学生→社交圈 |
| 运营活动入口 | 线下物料/公众号引导扫码进入活动 | 运营→用户 |
| 支付收款 | 会员购买订单二维码（对接微信/支付宝） | 系统→用户 |
| 教师认证 | 教师身份认证二维码（学校扫码确认） | 教师→学校 |
| 设备登录 | Web 端扫码登录 App 扫码授权 | Web→App |

当前各业务模块各自实现二维码逻辑，存在 **类型混乱、安全控制不一致、无法统一追踪、重复开发** 等问题。本模块的目标是建设 **统一的二维码生成与扫码解析服务**，提供：

1. **统一生成**：标准化的二维码生成接口，支持多种业务类型与自定义参数
2. **统一解析**：扫码后的服务端 payload 验签、业务路由与数据返回
3. **安全管控**：防伪造、限时过期、一次性使用、访问频率限制
4. **全生命周期管理**：创建 → 使用 → 过期/撤销的完整状态机
5. **数据追踪**：扫码次数、转化率、来源分析等统计数据

### 1.2 功能范围

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 二维码生成 | 根据业务类型与参数生成带签名的二维码 payload | P0 |
| 二维码解析 | 扫码后服务端验签并返回业务数据 | P0 |
| 二维码过期与撤销 | 支持时间过期、次数用尽、手动撤销 | P0 |
| 一次性二维码 | 特定业务（如支付）支持使用后即失效 | P1 |
| 动态刷新二维码 | 高安全场景（如登录授权）支持定期刷新 payload | P1 |
| 扫码频率限制 | 防止恶意扫描与暴力枚举 | P0 |
| 扫码统计 | PV/UV、转化率、来源设备等 | P1 |
| 批量生成 | 运营场景批量生成活动二维码 | P2 |
| 二维码样式定制 | 支持嵌入 Logo、自定义颜色（返回渲染参数） | P2 |

### 2.3 二维码 Payload 规范

二维码编码内容（即实际写入 QR 图片的文本）使用 **签名 URL 格式**：

```
https://qr.primetop.com/s/{payload_encrypted}
```

- `payload_encrypted`：Base64URL 编码的加密 payload + HMAC 签名
- 客户端扫描后直接请求该 URL，由服务端统一解析处理

**Payload 明文结构（JSON）：**

```json
{
  "cid": "QC202608140001",       // 二维码唯一标识
  "bt": "class_join",             // 业务类型
  "bi": "CLS12345678",            // 业务ID
  "ts": 1723593600,               // 生成时间戳（Unix秒）
  "exp": 1723593900,              // 过期时间戳（Unix秒），0=不过期
  "nonce": "a1b2c3d4e5f6",       // 随机数（防重放）
  "data": {                       // 业务自定义数据
    "class_id": "CLS12345678",
    "class_name": "初三(2)班",
    "teacher_name": "王老师"
  }
}
```

**加密签名方案：**

```
payload_encrypted = Base64URL(AES-256-GCM(
    key = QR_ENCRYPTION_KEY,      // 全局密钥（密钥管理服务获取）
    plaintext = JSON.stringify(payload),
    aad = cid + ":" + bt           // 附加认证数据
))

signature = HMAC-SHA256(
    key = QR_SIGNING_KEY,
    message = payload_encrypted + cid + ts
)
```

最终编码进二维码的完整内容：

```
https://qr.primetop.com/s/{payload_encrypted}?sig={signature}
```

## 3. API 接口设计

### 3.1 生成二维码

#### POST /api/v1/qrcode/generate

**描述：** 根据业务类型和参数生成二维码，返回 payload 字符串和渲染信息。

**请求：**

```json
{
  "biz_type": "class_join",
  "biz_id": "CLS12345678",
  "source_user_id": 10086,
  "payload_data": {
    "class_id": "CLS12345678",
    "class_name": "初三(2)班",
    "teacher_name": "王老师"
  },
  "expire_type": "duration",
  "duration_seconds": 0,
  "max_scan_count": -1,
  "is_single_use": false,
  "is_dynamic": false,
  "render_options": {
    "size": 320,
    "logo_url": "https://cdn.primetop.com/logo/128.png",
    "color_dark": "#333333",
    "color_light": "#FFFFFF",
    "margin": 2
  }
}
```

**响应：**

```json
{
  "code": 0,
  "data": {
    "code_id": "QC202608140001",
    "qr_url": "https://qr.primetop.com/s/eyJjaWQiOiJRQzIwMjYwODE0MDAwMSIs...",
    "payload": {
      "cid": "QC202608140001",
      "bt": "class_join",
      "bi": "CLS12345678",
      "ts": 1723593600,
      "exp": 0,
      "data": {
        "class_id": "CLS12345678",
        "class_name": "初三(2)班",
        "teacher_name": "王老师"
      }
    },
    "render_config": {
      "size": 320,
      "logo_url": "https://cdn.primetop.com/logo/128.png",
      "color_dark": "#333333",
      "color_light": "#FFFFFF",
      "margin": 2
    },
    "expire_at": null,
    "status": "active"
  }
}
```

**说明：**
- `expire_type` 不传时，使用业务类型默认值（如 `PARENT_BIND` 默认 5 分钟）
- `render_options` 可选，客户端可自行使用 `qr_url` 渲染二维码图片
- 服务端不生成图片，只返回 `qr_url`；图片渲染由客户端完成（减少服务端 CPU 开销）

### 3.2 扫码解析

#### POST /api/v1/qrcode/scan

**描述：** 客户端扫描二维码后调用，服务端验签、校验状态、返回业务数据。

**请求：**

```json
{
  "qr_url": "https://qr.primetop.com/s/eyJjaWQiOiJRQzIwMjYwODE0MDAwMSIs...?sig=abc123def456",
  "scanner_user_id": 20088,
  "device_info": {
    "device_id": "dev_a1b2c3d4",
    "platform": "android",
    "app_version": "1.0.0"
  }
}
```

**成功响应（class_join 示例）：**

```json
{
  "code": 0,
  "data": {
    "code_id": "QC202608140001",
    "biz_type": "class_join",
    "biz_data": {
      "class_id": "CLS12345678",
      "class_name": "初三(2)班",
      "teacher_name": "王老师",
      "subject": "数学",
      "student_count": 42
    },
    "action": {
      "type": "navigate",
      "route": "/class/join/confirm",
      "params": {
        "class_id": "CLS12345678"
      }
    },
    "scan_count_remaining": -1,
    "expire_at": null
  }
}
```

**失败响应（已过期）：**

```json
{
  "code": 4002,
  "message": "二维码已过期",
  "data": {
    "code_id": "QC202608140001",
    "biz_type": "parent_bind",
    "expire_at": "2026-08-14T01:05:00Z"
  }
}
```

**action.type 枚举：**

| type | 说明 | 示例场景 |
|------|------|---------|
| `navigate` | 客户端跳转到指定页面 | 加入班级、查看报告 |
| `confirm` | 需要用户确认后执行操作 | 家长绑定、设备授权 |
| `external_link` | 打开外部链接 | 运营活动 H5 |
| `payment` | 拉起支付 | 会员购买 |
| `error` | 不可用，展示错误信息 | 已撤销、已使用 |

## 4. 业务路由处理器

### 4.1 处理器架构

每种业务类型对应一个 `QrCodeHandler`，负责在扫码成功后组装返回给客户端的业务数据。

```java
public interface QrCodeHandler {
```

```java
@Service
public class QrCodeGenerationService {
    
    @Autowired
    private QrCodeRepository qrCodeRepo;
    @Autowired
    private QrCodeCryptoService cryptoService;
    @Autowired
    private QrCodeIdGenerator idGenerator;
    @Autowired
    private DynamicTokenService dynamicTokenService;
    
    /**
     * 生成二维码
     */
    @Transactional
    public QrCodeGenerateResult generate(QrCodeGenerateRequest request) {
        // 1. 应用业务类型默认配置
        QrCodeBizType bizType = QrCodeBizType.fromCode(request.getBizType());
        applyDefaults(bizType, request);
        
        // 2. 生成唯一 code_id
        String codeId = idGenerator.nextId(bizType);
        
        // 3. 构建 payload
        long now = Instant.now().getEpochSecond();
        long exp = calculateExpiry(request, now);
        
        QrCodePayload payload = QrCodePayload.builder()
            .cid(codeId)
            .bt(bizType.getCode())
            .bi(request.getBizId())
            .ts(now)
            .exp(exp)
            .nonce(secureRandomHex(6))
            .data(request.getPayloadData())
            .build();
        
        // 4. 加密 + 签名
        String payloadJson = JsonUtils.toJson(payload);
        String encrypted = cryptoService.encrypt(payloadJson, codeId, bizType.getCode());
        String signature = cryptoService.sign(encrypted, codeId, now);
        
        String qrUrl = buildQrUrl(encrypted, signature);
        
        // 5. 持久化
        QrCode entity = QrCode.builder()
            .codeId(codeId)
            .bizType(bizType.getCode())
            .bizId(request.getBizId())
            .sourceUserId(request.getSourceUserIdId())
            .payload(payloadJson)
            .payloadEncrypted(encrypted)
            .signature(signature)
            .expireType(request.getExpireType())
            .expireAt(exp > 0 ? Instant.ofEpochSecond(exp).atZone(ZoneId.systemDefault()).toLocalDateTime() : null)
            .durationSeconds(request.getDurationSeconds())
            .maxScanCount(request.getMaxScanCount())
            .scanCount(0)
            .isSingleUse(request.isSingleUse())
            .isDynamic(request.isDynamic())
            .refreshInterval(request.getRefreshInterval())
            .status("active")
            .sourceChannel(request.getSourceChannel())
            .build();
        qrCodeRepo.save(entity);
        
        // 6. 动态二维码：创建首个令牌
        if (request.isDynamic()) {
            dynamicTokenService.createToken(codeId, request.getRefreshInterval());
        }
        
        // 7. 异步统计
        eventPublisher.publish(new QrCodeGeneratedEvent(codeId, bizType.getCode(), request.getSourceUserIdId()));
        
        return QrCodeGenerateResult.builder()
            .codeId(codeId)
            .qrUrl(qrUrl)
            .payload(payload)
            .expireAt(entity.getExpireAt())
            .status("active")
            .build();
    }
    
    private String buildQrUrl(String encrypted, String signature) {
        return String.format("%s/s/%s?sig=%s", 
            qrDomain, encrypted, signature);
    }
    
    private void applyDefaults(QrCodeBizType bizType, QrCodeGenerateRequest request) {
        if (request.getExpireType() == null) {
            request.setExpireType(bizType.isDefaultExpirable() ? "duration" : "never");
            request.setDurationSeconds(bizType.getDefaultDurationSeconds());
        }
        // 如果业务类型默认一次性，且请求未指定，则使用默认值
        // isSingleUse 不覆盖请求中明确设置的值
    }
}
```

### 5.2 二维码扫码解析服务

```java
@Service
public class QrCodeScanService {
    
    @Autowired
    private QrCodeRepository qrCodeRepo;
    @Autowired
    private QrCodeCryptoService cryptoService;
    @Autowired
    private QrCodeHandlerRegistry handlerRegistry;
    @Autowired
    private ScanLogService scanLogService;
    @Autowired
    private RateLimiter rateLimiter;
    @Autowired
    private DynamicTokenService dynamicTokenService;
    
    /**
     * 扫码解析主流程
     */
    public QrCodeScanResponse scan(QrCodeScanRequest request, HttpServletRequest httpRequest) {
        String scannerIp = IpUtils.getClientIp(httpRequest);
        Long scannerId = request.getScannerUserId();
        
        // 1. 频率限制（防暴力枚举）
        String rateLimitKey = "qr_scan:" + (scannerId != null ? scannerId : scannerIp);
        if (!rateLimiter.tryAcquire(rateLimitKey, 30, 60)) {
            return buildErrorResponse(ErrorCode.RATE_LIMIT_EXCEEDED, "扫码过于频繁，请稍后再试");
        }
        
        // 2. 解析 URL，提取 payload_encrypted 和 signature
        UrlPayloadExtractResult extract = extractFromUrl(request.getQrUrl());
        if (extract == null) {
            scanLogService.logFailed(request, scannerIp, "invalid_url", "无法解析二维码内容");
            return buildErrorResponse(ErrorCode.QR_CODE_INVALID, "无效的二维码");
        }
        
        // 3. 验签
        boolean signatureValid = cryptoService.verifySignature(
            extract.getEncrypted(), extract.getSignature());
        if (!signatureValid) {
            scanLogService.logFailed(request, scannerIp, "invalid_signature", "签名校验失败");
            return buildErrorResponse(ErrorCode.QR_CODE_SIGNATURE_INVALID, "二维码签名校验失败，可能已被篡改");
        }
        
        // 4. 解密 payload
        QrCodePayload payload;
        try {
            String json = cryptoService.decrypt(extract.getEncrypted());
            payload = JsonUtils.fromJson(json, QrCodePayload.class);
        } catch (Exception e) {
            scanLogService.logFailed(request, scannerIp, "decrypt_error", "解密失败");
            return buildErrorResponse(ErrorCode.QR_CODE_DECRYPT_FAILED, "二维码内容无法解析");
        }
        
        // 5. 查询数据库记录
        QrCode qrCode = qrCodeRepo.findByCodeId(payload.getCid());
        if (qrCode == null) {
            scanLogService.logFailed(request, scannerIp, "not_found", "二维码记录不存在");
            return buildErrorResponse(ErrorCode.QR_CODE_NOT_FOUND, "二维码不存在或已被删除");
        }
        
        // 6. 状态校验
        QrCodeStatusCheckResult statusCheck = checkStatus(qrCode, payload);
        if (!statusCheck.isPass()) {
            scanLogService.logFailed(request, scannerIp, statusCheck.getFailReason(), statusCheck.getFailMessage());
            return buildErrorResponse(statusCheck.getErrorCode(), statusCheck.getFailMessage(), qrCode);
        }
        
        // 7. 动态令牌校验
        if (qrCode.isDynamic()) {
            boolean tokenValid = dynamicTokenService.validateToken(
                qrCode.getCodeId(), extract.getEncrypted());
            if (!tokenValid) {
                scanLogService.logFailed(request, scannerIp, "token_expired", "动态令牌已过期");
                return buildErrorResponse(ErrorCode.QR_TOKEN_EXPIRED, "二维码已刷新，请重新扫描");
            }
        }
        
        // 8. 构建上下文，调用业务处理器
        QrCodeBizType bizType = QrCodeBizType.fromCode(qrCode.getBizType());
        QrCodeContext context = QrCodeContext.builder()
            .codeId(qrCode.getCodeId())
            .bizType(bizType)
            .bizId(qrCode.getBizId())
            .sourceUserId(qrCode.getSourceUserId())
            .scannerUserId(scannerId)
            .scannerIp(scannerIp)
            .payload(payload)
            .deviceInfo(request.getDeviceInfo())
            .build();
        
        QrCodeHandler handler = handlerRegistry.getHandler(bizType);
        
        try {
            // 8a. 权限校验
            handler.checkPermission(context);
            
            // 8b. 组装业务数据
            QrCodeScanResponse.BizData bizData = handler.handleScan(context);
            
            // 9. 更新扫码计数
            qrCodeRepo.incrementScanCount(qrCode.getCodeId());
            
            // 10. 一次性二维码：标记为已使用
            if (qrCode.isSingleUse()) {
                qrCodeRepo.updateStatus(qrCode.getCodeId(), "used");
            }
            
            // 11. 记录扫码日志
            scanLogService.logSuccess(qrCode, scannerId, scannerIp, request.getDeviceInfo());
            
            // 12. 发布扫码事件
            eventPublisher.publish(new QrCodeScannedEvent(
                qrCode.getCodeId(), bizType.getCode(), scannerId, true));
            
            return QrCodeScanResponse.success(qrCode.getCodeId(), bizType.getCode(), bizData);
            
        } catch (BizException e) {
            scanLogService.logFailed(request, scannerIp, "biz_error", e.getMessage());
            return buildErrorResponse(e.getCode(), e.getMessage(), qrCode);
        }
    }
    
    /**
     * 状态检查
     */
    private QrCodeStatusCheckResult checkStatus(QrCode qrCode, QrCodePayload payload) {
        // 已撤销
        if ("revoked".equals(qrCode.getStatus())) {
            return QrCodeStatusCheckResult.fail("revoked", "二维码已被撤销", 
                ErrorCode.QR_CODE_REVOKED);
        }
        
        // 已使用（一次性二维码）
        if ("used".equals(qrCode.getStatus())) {
            return QrCodeStatusCheckResult.fail("used", "二维码已被使用", 
                ErrorCode.QR_CODE_ALREADY_USED);
        }
        
        // 已过期
        if ("expired".equals(qrCode.getStatus())) {
            return QrCodeStatusCheckResult.fail("expired", "二维码已过期", 
                ErrorCode.QR_CODE_EXPIRED);
        }
        
        // 时间过期检查
        if (payload.getExp() > 0) {
            long now = Instant.now().getEpochSecond();
            if (now > payload.getExp()) {
                // 异步更新状态
                asyncUpdateService.markExpired(qrCode.getCodeId());
                return QrCodeStatusCheckResult.fail("expired", "二维码已过期", 
                    ErrorCode.QR_CODE_EXPIRED);
            }
        }
        
        // 扫码次数检查
        if (qrCode.getMaxScanCount() > 0 && qrCode.getScanCount() >= qrCode.getMaxScanCount()) {
            return QrCodeStatusCheckResult.fail("limit_exceeded", "扫码次数已用尽", 
                ErrorCode.QR_CODE_LIMIT_EXCEEDED);
        }
        
        return QrCodeStatusCheckResult.pass();
    }
}
```

### 5.3 加密与签名服务

```java
@Service
public class QrCodeCryptoService {
    
    @Value("${qrcode.encryption-key}")
    private String encryptionKey;     // AES-256 key (Base64)
    
    @Value("${qrcode.signing-key}")
    private String signingKey;        // HMAC-SHA256 key (Base64)
    
    /**
     * AES-256-GCM 加密
     */
    public String encrypt(String plaintext, String cid, String bizType) {
        try {
            SecretKey key = new SecretKeySpec(Base64.decode(encryptionKey), "AES");
            byte[] iv = secureRandomBytes(12);  // GCM 推荐 12 字节 IV
            
            Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
            GCMParameterSpec spec = new GCMParameterSpec(128, iv);
            cipher.init(Cipher.ENCRYPT_MODE, key, spec);
            
            // AAD = cid:bizType
            cipher.updateAAD((cid + ":" + bizType).getBytes(StandardCharsets.UTF_8));
            
            byte[] ciphertext = cipher.doFinal(plaintext.getBytes(StandardCharsets.UTF_8));
            
            // 拼接 iv + ciphertext
            byte[] combined = new byte[iv.length + ciphertext.length];
            System.arraycopy(iv, 0, combined, 0, iv.length);
            System.arraycopy(ciphertext, 0, combined, iv.length, ciphertext.length);
            
            return Base64.getUrlEncoder().withoutPadding().encodeToString(combined);
        } catch (Exception e) {
            throw new RuntimeException("QR code encryption failed", e);
        }
    }
    
    /**
     * AES-256-GCM 解密
     */
    public String decrypt(String encrypted) {
        try {
            byte[] combined = Base64.getUrlDecoder().decode(encrypted);
            byte[] iv = Arrays.copyOfRange(combined, 0, 12);
            byte[] ciphertext = Arrays.copyOfRange(combined, 12, combined.length);
            
            // 先解密获取 payload，再从中提取 cid 和 bt 作为 AAD
            // 注意：需要先尝试解密，AAD 校验在 GCM 模式下是认证的一部分
            // 实际实现中 cid 和 bt 可以从 payload 明文中获取后再做 AAD 校验
            // 或者将 AAD 固定为 cid（从 payload 前缀解析）
            
            SecretKey key = new SecretKeySpec(Base64.decode(encryptionKey), "AES");
            Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
            GCMParameterSpec spec = new GCMParameterSpec(128, iv);
            cipher.init(Cipher.DECRYPT_MODE, key, spec);
            
            // AAD 需要在解密前设置——实际上我们需要一个两阶段方案
            // 方案：不使用 AAD（简化），或使用固定 AAD = "primetop:qrcode"
            cipher.updateAAD("primetop:qrcode:v1".getBytes(StandardCharsets.UTF_8));
            
            byte[] plaintext = cipher.doFinal(ciphertext);
            return new String(plaintext, StandardCharsets.UTF_8);
        } catch (Exception e) {
            throw new RuntimeException("QR code decryption failed", e);
        }
    }
    
    /**
     * HMAC-SHA256 签名
     */
    public String sign(String payload, String cid, long timestamp) {
        String message = payload + ":" + cid + ":" + timestamp;
        byte[] hmac = HmacUtils.hmacSha256(Base64.decode(signingKey), 
            message.getBytes(StandardCharsets.UTF_8));
        return Base64.getUrlEncoder().withoutPadding().encodeToString(hmac);
    }
    
    /**
     * 签名验证
     */
    public boolean verifySignature(String payload, String signature) {
        // 从 payload 关联记录中获取 cid 和 timestamp
        // 实际实现中，sign 方法中的 timestamp 也编码在 URL 参数里
        // 这里简化为对比签名
        // 完整实现需要重新计算签名并做常量时间比较
        try {
            String expectedSignature = recomputeSignature(payload);
            return MessageDigest.isEqual(
                signature.getBytes(StandardCharsets.UTF_8),
                expectedSignature.getBytes(StandardCharsets.UTF_8)
            );
        } catch (Exception e) {
            return false;
        }
    }
}
```

```
            │       └─────────┘      │
            │                         │
            │       ┌─────────┐      │
            │       │ expired │◄─────┤
            │       └─────────┘      │
            │                         │
            │       ┌─────────┐      │
            └──────►│ revoked │◄─────┘
                    └─────────┘
```

**状态定义：**

| 状态 | 说明 | 可流转到 |
|------|------|---------|
| `active` | 活跃，可正常扫码 | `used`、`expired`、`revoked` |
| `used` | 已使用（仅一次性二维码） | 终态 |
| `expired` | 已过期（时间到期或次数用尽） | 终态 |
| `revoked` | 已撤销（手动操作） | 终态 |

### 6.2 状态流转事件

```java
@Getter
public class QrCodeStatusChangedEvent {
    private final String codeId;
    private final String bizType;
    private final String fromStatus;
    private final String toStatus;
    private final Long operatorId;
    private final String reason;
    private final Instant timestamp;
}

// 状态机编码实现
public class QrCodeStateMachine {
    
    private static final Map<String, Set<String>> TRANSITIONS = Map.of(
        "active", Set.of("used", "expired", "revoked"),
        "used", Set.of(),       // 终态
        "expired", Set.of(),    // 终态
        "revoked", Set.of()     // 终态
    );
    
    public static boolean canTransition(String from, String to) {
        return TRANSITIONS.getOrDefault(from, Set.of()).contains(to);
    }
    
    public static void transition(QrCode qrCode, String target, Long operatorId, String reason) {
        String current = qrCode.getStatus();
        if (!canTransition(current, target)) {
            throw new IllegalStateException(
                String.format("非法状态流转: %s -> %s", current, target));
        }
        String oldStatus = current;
        qrCode.setStatus(target);
        
        // 发布事件
        ApplicationEventPublisherHolder.publish(
            new QrCodeStatusChangedEvent(
                qrCode.getCodeId(), qrCode.getBizType(),
                oldStatus, target, operatorId, reason, Instant.now()
            )
        );
    }
}
```

## 7. 安全设计

### 7.1 威胁模型与防护

| 威胁 | 场景 | 防护措施 |
|------|------|---------|
| 伪造二维码 | 恶意用户构造虚假 payload | HMAC-SHA256 签名 + AES-256-GCM 加密 |
| 重放攻击 | 截获有效二维码内容重复使用 | nonce 随机数 + 时间戳 + 一次性标记 |
| 暴力枚举 | 枚举 payload_encrypted 尝试命中 | 频率限制（IP+用户维度）+ 短码空间足够大 |
| 截图分享 | 二维码被截图传播给非目标用户 | 业务层权限校验（如家长绑定需扫码方手机号匹配） |
| 中间人篡改 | 网络层篡改扫码请求内容 | HTTPS + API 签名 + payload 不可篡改（GCM 认证） |
| 敏感信息泄露 | 二维码内容包含用户隐私数据 | AES 加密 payload，数据库明文仅存于可控环境 |

### 7.3 密钥轮换

```java
@Component
public class QrCodeKeyRotationService {
    
    @Autowired
    private KeyManagementService kms;
    
    // 当前活跃密钥版本
    private volatile KeyVersion currentKey;
    
    // 历史密钥（用于验证旧二维码）
    private final Map<Integer, KeyVersion> historicalKeys = new ConcurrentHashMap<>();
    
    /**
     * 密钥轮换（每90天执行一次）
     */
    @Scheduled(fixedRate = 90 * 24 * 3600_000L)
    public void rotateKeys() {
        int newVersion = currentKey.getVersion() + 1;
        KeyVersion newKey = kms.generateQrCodeKey(newVersion);
        
        // 旧密钥移入历史，保留180天用于验证旧二维码
        historicalKeys.put(currentKey.getVersion(), currentKey);
        currentKey = newKey;
        
        log.info("QR code keys rotated to version {}", newVersion);
        
        // 清理超过180天的历史密钥
        historicalKeys.entrySet().removeIf(e -> 
            e.getKey() < newVersion - 2);
    }
    
    /**
     * 加密时使用当前密钥
     */
    public EncryptResult encrypt(String plaintext, String aad) {
        return new EncryptResult(
            cryptoService.encrypt(plaintext, currentKey.getEncryptionKey(), aad),
            currentKey.getVersion()
        );
    }
    
    /**
     * 解密时先尝试当前密钥，再回退到历史密钥
     */
    public String decrypt(String ciphertext, int keyVersion, String aad) {
        KeyVersion key = keyVersion == currentKey.getVersion() 
            ? currentKey 
            : historicalKeys.get(keyVersion);
        
        if (key == null) {
            throw new BizException(ErrorCode.QR_KEY_NOT_FOUND, 
                "密钥版本不存在，二维码可能已过期");
        }
        
        return cryptoService.decrypt(ciphertext, key.getEncryptionKey(), aad);
    }
}
```

**缓存读取顺序：**

1. Redis 缓存 → 命中则直接使用
2. MySQL 数据库 → 命中后回写 Redis
3. 不存在 → 返回 NOT_FOUND

**缓存失效场景：**
- 扫码成功后更新状态时，同步删除缓存
- 撤销操作时删除缓存
- 动态刷新时更新缓存中的令牌

### 10.2 批量生成优化

```java
@Service
public class QrCodeBatchService {
    
    /**
     * 批量生成使用 pipeline + 异步写入
     */
    @Async
    public void batchGenerateAsync(String batchId, List<QrCodeGenerateRequest> items) {
        try (Connection conn = dataSource.getConnection()) {
            // 使用 JDBC Batch 插入
            PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO qr_code (code_id, biz_type, ...) VALUES (?, ?, ...)");
            
            int count = 0;
            for (QrCodeGenerateRequest item : items) {
                QrCodeGenerateResult result = generateSingle(item);
                // 记录到批量结果表
                batchResultRepo.save(BatchResultItem.builder()
                    .batchId(batchId)
                    .codeId(result.getCodeId())
                    .qrUrl(result.getQrUrl())
                    .bizId(item.getBizId())
                    .build());
                
                if (++count % 100 == 0) {
                    log.info("批量生成进度: {}/{}", count, items.size());
                }
            }
            
            // 发布批量完成事件
            eventPublisher.publish(new QrCodeBatchCompletedEvent(batchId, items.size()));
        } catch (SQLException e) {
            log.error("批量生成失败: batchId={}", batchId, e);
        }
    }
}
```

```java
@Component
public class QrCodeArchiveScheduler {
    
    @Scheduled(cron = "0 0 3 * * ?")  // 每天凌晨3点
    @Transactional
    public void archiveOldQrCodes() {
        LocalDate cutoff = LocalDate.now().minusDays(180);
        int batchSize = 500;
        int total = 0;
        
        do {
            List<QrCode> batch = qrCodeRepo.findTerminatedBefore(cutoff, PageRequest.of(0, batchSize));
            if (batch.isEmpty()) break;
            
            // 写入归档表
            archiveRepo.batchInsert(batch);
            
            // 从主表删除
            qrCodeRepo.deleteAll(batch);
            
            total += batch.size();
        } while (total % batchSize == 0);
        
        log.info("归档 {} 条二维码记录", total);
    }
    
    @Scheduled(cron = "0 30 3 * * ?")
    public void cleanupExpiredTokens() {
        int deleted = dynamicTokenRepo.deleteExpired(LocalDateTime.now().minusDays(7));
        log.info("清理 {} 条过期动态令牌", deleted);
    }
}
```

### 15.2 FAQ

**Q: 为什么不在服务端生成二维码图片？**
A: 服务端生成图片会消耗大量 CPU 资源，且二维码图片渲染逻辑简单，客户端有成熟的库（如 Flutter 的 `qr_flutter`、iOS 的 `CoreImage`、Android 的 `ZXing`）。服务端只返回 `qr_url` 字符串，由客户端渲染，这样服务端 QPS 能力可提升 5-10 倍。

**Q: 为什么使用 AES 加密而不是直接明文 + 签名？**
A: 签名只能防篡改，不能防信息泄露。二维码内容可能包含学生姓名、班级名称等隐私信息。加密后即使二维码被截图传播，也无法从中提取明文信息。

**Q: 二维码 URL 为什么用独立域名 `qr.primetop.com`？**
A: 1) 便于区分和过滤；2) 可以独立配置 CDN 和解析服务；3) 不影响主 API 域名的 CORS 和安全策略；4) 未来可支持自定义短码如 `q.pt/s/xxx`。

**Q: 动态刷新二维码和静态二维码有什么区别？**
A: 静态二维码生成后内容固定不变，直到过期。动态二维码（如 Web 扫码登录）每隔几秒到几十秒刷新一次内容（新令牌），旧内容立即失效。这样即使二维码被截图，几秒后就无法使用，极大提升安全性。
