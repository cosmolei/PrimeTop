# 客户端 - 分屏多窗学习模式与跨窗学习素材联动交互引擎

> **模块定位**：PrimeTop 客户端多窗口学习体验核心引擎，面向平板、折叠屏及大屏设备，提供 OS 级分屏集成、应用内双窗学习模式、跨窗素材拖拽联动、铰链感知布局及多窗口状态同步能力。
>
> **区别于《横屏模式与大屏设备适配设计》**：前者解决"单窗口内响应式布局如何适配不同屏幕尺寸"；本文档解决"多窗口/多窗格并行学习场景下的交互编排、数据联动、状态同步与生命周期管理"。
>
> **覆盖学段**：全学段（初中/高中为重点受益群体） **优先级**：P1.5 **技术栈**：Flutter 3.x + Dart 3.x + Riverpod

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| OS 分屏集成 | 支持 Android Split-Screen / Samsung DeX / iPad Stage Manager |
| 应用内双窗学习 | 用户可同时打开两个学习模块（如教材+AI对话） |
| 跨窗素材联动 | 拖拽题目/公式/文本从一个窗格到另一个窗格触发对应功能 |
| 铰链感知布局 | 折叠屏设备利用铰链区域作为天然分隔线 |
| 窗口状态同步 | 两个窗格的学习上下文实时同步 |
| 生命周期管理 | 分屏进入/退出时学习会话不中断 |

---

## 2. 核心概念

| 术语 | 定义 |
|------|------|
| **WindowPane（窗格）** | 分屏模式下独立运行的学习视图单元，拥有独立路由栈 |
| **SplitSession（分屏会话）** | 一次分屏学习过程的完整生命周期 |
| **DragPayload（拖拽载荷）** | 跨窗拖拽时传递的结构化数据包 |
| **PaneLinkage（窗格联动）** | 两个窗格之间的数据绑定关系 |
| **HingeSensor（铰链传感器）** | 折叠屏铰链角度传感器数据（0-180度） |
| **SplitPreset（分屏预设）** | 预定义的分屏组合（如"教材+AI"） |

```dart
/// lib/features/split_mode/domain/pane_linkage.dart

enum LinkageType {
  textbookToAiSolve,      // 教材到AI：拖拽题目触发解题
  textbookToNote,         // 教材到笔记：拖拽内容创建笔记
  aiToTextbookNavigate,   // AI到教材：知识点点击跳转教材
  mistakeToPractice,      // 错题到练习：生成同类题
  searchToTextbook,       // 搜索到教材：结果在教材打开
  aiToMistake,            // AI到错题：一键加入错题本
  none,
}

class PaneLinkage {
  final LinkageType type;
  final String sourcePaneId;
  final String targetPaneId;
  final bool enabled;
  final Map<String, dynamic> params;

  const PaneLinkage({
    required this.type, required this.sourcePaneId,
    required this.targetPaneId, this.enabled = true, this.params = const {},
  });

  /// 根据窗格角色组合自动推断联动类型
  factory PaneLinkage.infer({
    required PaneRole source, required PaneRole target,
    required String sourceId, required String targetId,
  }) {
    final typeMap = <(PaneRole, PaneRole), LinkageType>{
      (PaneRole.textbook, PaneRole.aiTutor): LinkageType.textbookToAiSolve,
      (PaneRole.textbook, PaneRole.notes): LinkageType.textbookToNote,
      (PaneRole.aiTutor, PaneRole.textbook): LinkageType.aiToTextbookNavigate,
      (PaneRole.mistakeBook, PaneRole.practice): LinkageType.mistakeToPractice,
      (PaneRole.search, PaneRole.textbook): LinkageType.searchToTextbook,
      (PaneRole.aiTutor, PaneRole.mistakeBook): LinkageType.aiToMistake,
    };
    return PaneLinkage(
      type: typeMap[(source, target)] ?? LinkageType.none,
      sourcePaneId: sourceId, targetPaneId: targetId,
    );
  }
}
```

## 5. 分屏会话状态机

```
SingleMode --> EnteringSplit --> SplitActive <--> Resizing/Dragging
                                  |
                                  v
                              ExitingSplit --> SingleMode
```

```dart
/// lib/features/split_mode/state/split_state_machine.dart

enum SplitModeState { single, entering, active, resizing, dragging, exiting }

class SplitModeNotifier extends StateNotifier<SplitModeState> {
  final Ref _ref;
  SplitModeNotifier(this._ref) : super(SplitModeState.single);

  Future<void> enterSplit({SplitPreset? preset}) async {
    if (state != SplitModeState.single) return;
    state = SplitModeState.entering;
    try {
      final session = await _createSession(preset);
      _ref.read(currentSplitSessionProvider.notifier).state = session;
      await _persistSession(session);
      state = SplitModeState.active;
    } catch (e) {
      state = SplitModeState.single;
    }
  }

  Future<void> exitSplit() async {
    if (state != SplitModeState.active && state != SplitModeState.dragging) return;
    state = SplitModeState.exiting;
    final session = _ref.read(currentSplitSessionProvider);
    if (session != null) {
      await _persistSession(session.copyWith(isActive: false));
    }
    _ref.read(currentSplitSessionProvider.notifier).state = null;
    state = SplitModeState.single;
  }

  void startResizing() { if (state == SplitModeState.active) state = SplitModeState.resizing; }
  void endResizing()   { if (state == SplitModeState.resizing) state = SplitModeState.active; }
  void startDrag()     { if (state == SplitModeState.active) state = SplitModeState.dragging; }
  void endDrag()       { if (state == SplitModeState.dragging) state = SplitModeState.active; }
  void swapPanes()     { /* 交换主副窗格 */ }
}
```

### 7.1 分屏布局容器

```dart
/// lib/features/split_mode/presentation/split_view_container.dart

class SplitViewContainer extends ConsumerStatefulWidget {
  final Widget primaryPane;
  final Widget secondaryPane;
  final double initialWeight;

  const SplitViewContainer({super.key, required this.primaryPane,
    required this.secondaryPane, this.initialWeight = 0.5});

  @override
  ConsumerState<SplitViewContainer> createState() => _SplitViewContainerState();
}

class _SplitViewContainerState extends ConsumerState<SplitViewContainer> {
  late double _weight;

  @override
  void initState() { super.initState(); _weight = widget.initialWeight; }

  @override
  Widget build(BuildContext context) {
    final screenW = MediaQuery.sizeOf(context).width;
    final screenH = MediaQuery.sizeOf(context).height;
    final isFoldable = ref.watch(isFoldableDeviceProvider);
    final hingeInfo = ref.watch(hingeInfoProvider);

    if (isFoldable && hingeInfo != null) {
      _weight = hingeInfo.hingeStart / screenW;
    }
    final dividerX = screenW * _weight;

    return Stack(children: [
      Positioned(left: 0, top: 0, width: dividerX, height: screenH,
        child: PaneDropTarget(paneId: 'pane_left', child: widget.primaryPane)),
      Positioned(left: dividerX, top: 0, width: screenW - dividerX, height: screenH,
        child: PaneDropTarget(paneId: 'pane_right', child: widget.secondaryPane)),
      if (!isFoldable) Positioned(
        left: dividerX - 12, top: 0, width: 24, height: screenH,
        child: GestureDetector(
          onHorizontalDragUpdate: (d) => setState(() =>
            _weight = ((_weight * screenW + d.delta.dx) / screenW).clamp(0.3, 0.7)),
          onHorizontalDragEnd: (_) =>
            ref.read(splitModeProvider.notifier).endResizing(),
          child: Center(child: Container(width: 4, height: 40,
            decoration: BoxDecoration(
              color: Theme.of(context).dividerColor,
              borderRadius: BorderRadius.circular(2)))),
        )),
      Positioned(left: dividerX - 16, top: 8,
        child: IconButton.filled(onPressed: () =>
          ref.read(splitModeProvider.notifier).swapPanes(),
          icon: const Icon(Icons.swap_horiz, size: 16))),
    ]);
  }
}

/// 窗格拖拽接收器
class PaneDropTarget extends StatelessWidget {
  final String paneId;
  final Widget child;
  const PaneDropTarget({super.key, required this.paneId, required this.child});

  @override
  Widget build(BuildContext context) {
    return DragTarget<DragPayload>(
      onAcceptWithDetails: (d) => ProviderScope.containerOf(context)
          .read(paneDropHandlerProvider(paneId).notifier).handleDrop(d.data),
      onWillAcceptWithDetails: (d) => d.data.sourcePaneId != paneId,
      builder: (context, candidate, rejected) => AnimatedContainer(
        duration: const Duration(milliseconds: 150),
        decoration: candidate.isNotEmpty ? BoxDecoration(
          border: Border.all(
            color: Theme.of(context).colorScheme.primary.withOpacity(0.5),
            width: 2),
          borderRadius: BorderRadius.circular(8)) : null,
        child: ClipRect(child: child),
      ),
    );
  }
}
```

### 7.2 联动解析器

```dart
/// lib/features/split_mode/services/linkage_resolver.dart

enum ActionType {
  startAiSolve,         // AI窗格发起解题
  startAiQuery,         // AI窗格发起提问
  createNote,           // 创建笔记
  navigateToChapter,    // 跳转教材章节
  startSimilarPractice, // 同类题练习
  addToMistakeBook,     // 加入错题本
  openInTextbook,       // 在教材中打开
  none,
}

class LinkageAction {
  final ActionType type;
  final String targetRoute;
  final Map<String, dynamic> data;
  const LinkageAction({required this.type, required this.targetRoute,
    required this.data});
  factory LinkageAction.none() => const LinkageAction(
    type: ActionType.none, targetRoute: '', data: {});
}

class LinkageResolver {
  LinkageAction resolve({
    required LinkageType linkageType,
    required DragPayload payload,
  }) => switch (linkageType) {
    LinkageType.textbookToAiSolve => payload.type == DragPayloadType.question
      ? LinkageAction(type: ActionType.startAiSolve,
          targetRoute: '/ai-tutor/solving/${payload.data['questionId']}',
          data: payload.data)
      : LinkageAction(type: ActionType.startAiQuery,
          targetRoute: '/ai-tutor',
          data: {'query': payload.data['text'] ?? ''}),
    LinkageType.textbookToNote => LinkageAction(
      type: ActionType.createNote, targetRoute: '/notes/new',
      data: {'content': payload.data['text'] ?? payload.data['content'] ?? '',
             'source': payload.sourceModule}),
    LinkageType.aiToTextbookNavigate => LinkageAction(
      type: ActionType.navigateToChapter,
      targetRoute: '/sync-classroom/kp/${payload.data['kpId']}',
      data: payload.data),
    LinkageType.mistakeToPractice => LinkageAction(
      type: ActionType.startSimilarPractice,
      targetRoute: '/practice/similar/${payload.data['questionId']}',
      data: payload.data),
    LinkageType.aiToMistake => LinkageAction(
      type: ActionType.addToMistakeBook,
      targetRoute: '/mistake-book/add', data: payload.data),
    LinkageType.searchToTextbook => LinkageAction(
      type: ActionType.openInTextbook,
      targetRoute: '/sync-classroom/search-result', data: payload.data),
    LinkageType.none => LinkageAction.none(),
  };
}
```

### 7.3 Riverpod Providers

```dart

final currentSplitSessionProvider = StateProvider<SplitSession?>((ref) => null);

class PaneDropHandler extends StateNotifier<AsyncValue<void>> {
  final Ref _ref;
  final String _paneId;
  PaneDropHandler(this._ref, this._paneId) : super(const AsyncValue.data(null));

  Future<void> handleDrop(DragPayload payload) async {
    final session = _ref.read(currentSplitSessionProvider);
    if (session == null) return;

    final action = _ref.read(linkageResolverProvider).resolve(
      linkageType: session.linkage.type, payload: payload);

    if (action.type == ActionType.none) return;

    _ref.read(paneNavigationProvider(_paneId).notifier)
        .navigateTo(action.targetRoute, arguments: action.data);

    await HapticFeedback.mediumImpact();
  }
}
```

## 10. 错误处理与降级策略

| 错误场景 | 处理策略 |
|----------|---------|
| 设备不支持分屏 | 隐藏"分屏学习"入口，Toast 提示"当前设备不支持分屏" |
| 窗格模块加载失败 | 显示错误占位页 + 重试按钮，另一窗格不受影响 |
| 拖拽载荷解析失败 | Toast 提示"无法处理此内容"，不影响目标窗格状态 |
| 分屏会话恢复失败 | 清理损坏的会话数据，回退到单窗模式并提示用户 |
| OS 级分屏冲突 | 检测 Android multi-window 模式，应用内分屏自动禁用 |
| 内存不足 | 低端设备自动降级为单栏模式，释放副窗格资源 |
| 跨窗拖拽超时 | 拖拽超过 5 秒未释放自动取消，恢复原状态 |
| 状态同步冲突 | 最后写入优先 (LWW)，记录冲突日志供后续审计 |

### 错误码定义

| 错误码 | 含义 | 处理建议 |
|--------|------|----------|
| SPLIT_001 | 设备不支持分屏 | 隐藏分屏入口 |
| SPLIT_002 | 进入分屏失败 | 重试或检查内存 |
| SPLIT_003 | 会话恢复数据损坏 | 清除历史会话，回退单窗 |
| SPLIT_004 | 拖拽载荷类型不匹配 | Toast 提示用户 |
| SPLIT_005 | 窗格模块加载超时 | 显示占位页 + 重试 |
| SPLIT_006 | OS分屏模式冲突 | 禁用应用内分屏 |

### 11.3 内存阈值监控

```dart
/// 分屏模式内存监控
/// 目标：总内存占用 < 350MB
/// 阈值告警：> 300MB 时开始释放缓存
/// 紧急降级：> 400MB 时自动退出分屏

class MemoryGuard {
  static const _warningMB = 300;
  static const _criticalMB = 400;

  void monitor() {
    Timer.periodic(const Duration(seconds: 5), (_) {
      final usedMB = ProcessInfo.currentRss / (1024 * 1024);
      if (usedMB > _criticalMB) {
        _forceExitSplit('内存不足，已自动退出分屏模式');
      } else if (usedMB > _warningMB) {
        _releaseCaches();
      }
    });
  }
}
```
