# 客户端-历史时间轴交互组件与历史事件关联学习组件-详细设计

> 版本：v1.0 | 日期：2026-06-13 | 模块归属：客户端 → 学科工具箱 → 历史学科

## 1. 模块概述

### 1.1 功能定位

为初高中学生提供可交互的历史时间轴可视化组件，将历史事件、人物、朝代、战争、改革等要素沿时间线组织展示，支持缩放、平移、筛选、事件关联跳转和 AI 辅助讲解。帮助学生建立历史时间感知，理解事件间的因果、并列、继承关系。

### 1.2 目标用户

| 用户 | 场景 |
|------|------|
| 初中生 | 中国古代史、中国近现代史、世界史时间线梳理与复习 |
| 高中生 | 高考历史专题复习、中外历史对比、因果链条分析 |

### 1.3 核心价值

1. **时间感知**：直观展示事件先后顺序、时代跨度，解决学生"时间混乱"痛点
2. **关联理解**：可视化事件间的因果、影响、对比关系，辅助建立历史思维
3. **触达学习**：点击任意事件节点可触发 AI 讲解、知识点关联、同类题推荐
4. **对比分析**：支持中外历史并行时间轴，培养全球史观

## 3. 数据结构定义

### 3.1 核心模型

```dart
/// 历史事件节点
class TimelineEvent {
  final String id;                    // 唯一ID，格式：hist_evt_{uuid}
  final String title;                 // 事件标题，如"贞观之治"
  final int startYear;               // 起始年份（负数表示公元前，-221 = 公元前221年）
  final int? endYear;                 // 结束年份（null 表示瞬时事件）
  final String eraId;                // 所属时代/朝代ID
  final String region;               // 地区：china / europe / asia / america / africa / global
  final List<String> categories;     // 分类标签：war / reform / culture / economy / diplomacy / person / technology
  final String? summary;             // 简短描述（1-2句话）
  final String? detailDocId;         // 关联的详细文档ID
  final List<String> knowledgePointIds; // 关联知识点ID列表
  final int importance;              // 重要度 1-5（影响节点视觉权重）
  final String? imageUrl;            // 配图URL
  final List<String> relatedEventIds; // 关联事件ID列表
  final String? textbookChapterId;   // 关联教材章节ID
}

/// 时代/朝代区间
class TimelineEra {
  final String id;                    // 唯一ID，格式：hist_era_{uuid}
  final String name;                  // 名称，如"唐朝"、"春秋战国"
  final int startYear;
  final int endYear;
  final String region;
  final int colorValue;              // 主题色 ARGB
  final String? description;         // 时代简介
}

/// 事件关联关系
class EventRelation {
  final String id;
  final String sourceEventId;
  final String targetEventId;
  final EventRelationType type;      // 关联类型
  final String? description;         // 关系描述
}

enum EventRelationType {
  cause,          // 因果：A导致B
  influence,      // 影响：A影响B
  contrast,       // 对比：A与B对比
  parallel,       // 并列：A与B同时期发生
  succession,     // 继承：A是B的前身/后续
  comparison,     // 中外对比
}

/// 视口状态
class ViewportState {
  final double centerYear;           // 视口中心年份
  final double yearsPerPixel;        // 缩放级别（每像素代表的年数）
  final double minYear;              // 视口左边界年份
  final double maxYear;              // 视口右边界年份
  final bool isAnimating;            // 是否正在动画过渡中
}
```

## 4. API 接口设计

### 4.1 获取时间轴事件数据

```
GET /api/v1/history/timeline/events
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| region | string | 否 | 地区筛选：china/world/europe/asia/america，默认返回全部 |
| startYear | int | 否 | 起始年份范围，用于按需加载 |
| endYear | int | 否 | 结束年份范围 |
| categories | string[] | 否 | 事件分类筛选，逗号分隔：war,reform,culture... |
| eraId | string | 否 | 指定朝代/时代ID |
| gradeRange | string | 否 | 学段：middle/middle_high/high |
| importanceMin | int | 否 | 最低重要度筛选，1-5 |

**响应体：** `TimelineEventsResponse`（见 3.2）

**错误码：**

| 错误码 | 说明 |
|--------|------|
| 4001001 | 无效的年份范围参数 |
| 4001002 | 无效的 region 值 |

### 4.2 获取事件详情

```
GET /api/v1/history/timeline/events/{eventId}
```

**响应体：**

```
GET /api/v1/history/timeline/events/{eventId}/relation-path
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|

#### 5.1.2 事件节点视觉规范

| 属性 | 规则 |
|------|------|
| 节点大小 | 根据 importance 缩放：importance=5 时直径 16dp，每级递减 2dp |
| 节点颜色 | 继承所属 era 的主题色；瞬时事件用实心圆，持续事件用胶囊形 |
| 标签文字 | importance ≥ 3 显示标题；importance < 3 仅在缩放到一定级别后显示 |
| 关联线 | 因果关系用实线箭头，并列关系用虚线，对比关系用双向箭头 |
| 选中态 | 放大 1.3 倍 + 外发光 + 弹出摘要卡片 |

#### 5.1.3 手势交互

| 手势 | 行为 |
|------|------|
| 水平拖拽 | 平移时间轴 |
| 双指捏合 | 缩放（调整 yearsPerPixel） |
| 单击事件节点 | 弹出 EventDetailSheet |
| 长按事件节点 | 进入多选模式，可选中多个事件进行对比 |
| 双击空白区域 | 快速定位到当前用户正在学习的教材章节对应时期 |
| 双击事件节点 | 跳转到该事件的关联路径视图 |

#### 5.1.4 缩放级别与信息密度

```
yearsPerPixel      可见范围         显示内容
─────────────────────────────────────────────────
> 5               百年级别         仅显示 importance=5 的大事件 + 时代色块
1 ~ 5             十年级别         importance ≥ 3 的事件 + 简要标题
0.2 ~ 1           年级别           全部事件 + 完整标题 + 关联线
< 0.2             月级别           精确日期标注（如事件有月份数据）
```

- AI 讲解支持"对比分析"模式

```dart
/// 时间轴事件数据 Provider
@riverpod
Future<List<TimelineEvent>> timelineEvents(
  TimelineEventsRef ref, {
  required String region,
  String? eraId,
  List<String>? categories,
}) async {
  final repository = ref.watch(timelineRepositoryProvider);
  // 先查本地缓存，缓存未命中再请求网络
  final cached = await repository.getCachedEvents(
    region: region, eraId: eraId, categories: categories,
  );
  if (cached != null) return cached;

  final remote = await repository.fetchEvents(
    region: region, eraId: eraId, categories: categories,
  );
  await repository.cacheEvents(remote, region: region);
  return remote;
}
```

### 7.1 时间轴画布 CustomPainter

```dart
class TimelineCanvasPainter extends CustomPainter {
  final List<TimelineEvent> visibleEvents;
  final List<TimelineEra> visibleEras;
  final List<EventRelation> visibleRelations;
  final ViewportState viewport;
  final String? selectedEventId;
  final Set<String> multiSelectedIds;

  TimelineCanvasPainter({
    required this.visibleEvents,
    required this.visibleEras,
    required this.viewport,
    required this.visibleRelations,
    this.selectedEventId,
    this.multiSelectedIds = const {},
  });

  @override
  void paint(Canvas canvas, Size size) {
    final axisY = size.height * 0.55;  // 时间轴主线Y坐标

    // 1. 绘制时代色块背景
    _drawEraBlocks(canvas, size, axisY);

    // 2. 绘制时间轴主线和年份刻度
    _drawTimeAxis(canvas, size, axisY);

    // 3. 绘制关联线
    _drawRelationLines(canvas, size, axisY);

    // 4. 绘制事件节点
    _drawEventNodes(canvas, size, axisY);

    // 5. 绘制选中态
    _drawSelectionHighlight(canvas, size, axisY);
  }

  void _drawEraBlocks(Canvas canvas, Size size, double axisY) {
    for (final era in visibleEras) {
      final startX = _yearToPixel(era.startYear, size.width);
      final endX = _yearToPixel(era.endYear, size.width);
      if (endX < 0 || startX > size.width) continue; // 视口裁剪

      final paint = Paint()
        ..color = Color(era.colorValue).withOpacity(0.12)
        ..style = PaintingStyle.fill;
      final rect = Rect.fromLTRB(
        max(startX, 0), axisY - 80, min(endX, size.width), axisY + 40,
      );
      canvas.drawRect(rect, paint);

      // 绘制时代名称（如果宽度足够）
      final eraWidth = endX - startX;
      if (eraWidth > 60) {
        _textPainter.text = TextSpan(
          text: era.name,
          style: TextStyle(
            color: Color(era.colorValue).withOpacity(0.6),
            fontSize: 12,
            fontWeight: FontWeight.w500,
          ),
        );
        _textPainter.layout(maxWidth: eraWidth - 8);
        _textPainter.paint(
          canvas,
          Offset(startX + (eraWidth - _textPainter.width) / 2, axisY - 76),
        );
      }
    }
  }

  void _drawEventNodes(Canvas canvas, Size size, double axisY) {
    for (final event in visibleEvents) {
      final x = _yearToPixel(
        event.endYear ?? event.startYear.toDouble(), size.width,
      );
      if (x < -20 || x > size.width + 20) continue;

      final isSelected = event.id == selectedEventId ||
          multiSelectedIds.contains(event.id);
      final baseRadius = _getEventRadius(event.importance);
      final radius = isSelected ? baseRadius * 1.3 : baseRadius;

      final paint = Paint()
        ..color = isSelected
            ? Color(_getEraColor(event.eraId)).withOpacity(1.0)
            : Color(_getEraColor(event.eraId)).withOpacity(0.85)
        ..style = PaintingStyle.fill;

      if (isSelected) {
        // 外发光效果
        canvas.drawCircle(
          Offset(x, axisY),
          radius + 6,
          Paint()
            ..color = Color(_getEraColor(event.eraId)).withOpacity(0.25)
            ..maskFilter = const MaskFilter.blur(BlurStyle.normal, 8),
        );
      }

      // 持续事件用胶囊形，瞬时事件用圆形
      if (event.endYear != null) {
        final endX = _yearToPixel(event.endYear!.toDouble(), size.width);
        final capsuleRect = RRect.fromRectAndRadius(
          Rect.fromLTRB(min(x, endX), axisY - radius, max(x, endX), axisY + radius),
          Radius.circular(radius),
        );
        canvas.drawRRect(capsuleRect, paint);
      } else {
        canvas.drawCircle(Offset(x, axisY), radius, paint);
      }

      // 绘制标题（根据缩放级别和重要度决定是否显示）
      if (_shouldShowTitle(event, viewport.yearsPerPixel)) {
        _textPainter.text = TextSpan(
          text: event.title,
          style: TextStyle(
            color: isSelected ? Colors.black87 : Colors.black54,
            fontSize: isSelected ? 13 : 11,
            fontWeight: isSelected ? FontWeight.w600 : FontWeight.w400,
          ),
        );
        _textPainter.layout(maxWidth: 120);
        _textPainter.paint(
          canvas,
          Offset(x - _textPainter.width / 2, axisY - radius - 18),
        );
      }
    }
  }

  void _drawRelationLines(Canvas canvas, Size size, double axisY) {
    for (final rel in visibleRelations) {
      final source = _findEvent(rel.sourceEventId);
      final target = _findEvent(rel.targetEventId);
      if (source == null || target == null) continue;

      final sx = _yearToPixel(source.startYear.toDouble(), size.width);
      final tx = _yearToPixel(target.startYear.toDouble(), size.width);
      if (sx < -50 || sx > size.width + 50 || tx < -50 || tx > size.width + 50) continue;

      final paint = Paint()
        ..strokeWidth = 1.5
        ..style = PaintingStyle.stroke;

      switch (rel.type) {
        case EventRelationType.cause:
        case EventRelationType.succession:
          paint.color = Colors.blue.shade300;
          // 实线箭头
          break;
        case EventRelationType.parallel:
          paint.color = Colors.grey.shade400;
          // 虚线
          paint.pathEffect = const DashPathEffect([4, 4]);
          break;
        case EventRelationType.contrast:
        case EventRelationType.comparison:
          paint.color = Colors.orange.shade300;
          // 双向箭头
          break;
        case EventRelationType.influence:
          paint.color = Colors.green.shade300;
          break;
      }

      // 绘制贝塞尔曲线（避免直线遮挡节点）
      final midX = (sx + tx) / 2;
      final midY = axisY + 50;
      final path = Path()
        ..moveTo(sx, axisY)
        ..quadraticBezierTo(midX, midY, tx, axisY);
      canvas.drawPath(path, paint);

      // 绘制箭头头部
      _drawArrowHead(canvas, path, paint);
    }
  }

  void _drawTimeAxis(Canvas canvas, Size size, double axisY) {
    // 主线
    canvas.drawLine(
      Offset(0, axisY),
      Offset(size.width, axisY),
      Paint()..color = Colors.grey.shade300..strokeWidth = 1.5,
    );

    // 年份刻度
    final tickInterval = _calculateTickInterval(viewport.yearsPerPixel);
    final startTick = (viewport.minYear / tickInterval).floor() * tickInterval;
    final endTick = (viewport.maxYear / tickInterval).ceil() * tickInterval;

    for (var year = startTick; year <= endTick; year += tickInterval) {
      final x = _yearToPixel(year.toDouble(), size.width);
      if (x < 0 || x > size.width) continue;

      // 刻度线
      canvas.drawLine(
        Offset(x, axisY - 4), Offset(x, axisY + 4),
        Paint()..color = Colors.grey.shade400..strokeWidth = 1,
      );

      // 年份文字
      final yearText = year < 0 ? '公元前${-year}年' : '${year}年';
      _textPainter.text = TextSpan(
        text: yearText,
        style: TextStyle(color: Colors.grey.shade600, fontSize: 10),
      );
      _textPainter.layout();
      _textPainter.paint(canvas, Offset(x - _textPainter.width / 2, axisY + 8));
    }
  }

  // ── 辅助方法 ──

  double _yearToPixel(double year, double canvasWidth) {
    return (year - viewport.centerYear) / viewport.yearsPerPixel + canvasWidth / 2;
  }

  double _getEventRadius(int importance) {
    return 4.0 + (importance - 1) * 2.5; // importance 1=4dp, 5=14dp
  }

  int _getEraColor(String eraId) {
    final era = visibleEras.firstWhere(
      (e) => e.id == eraId,
      orElse: () => TimelineEra(
        id: '', name: '', startYear: 0, endYear: 0,
        region: '', colorValue: 0xFF9E9E9E,
      ),
    );
    return era.colorValue;
  }

  bool _shouldShowTitle(TimelineEvent event, double ypp) {
    if (event.importance >= 4) return true;
    if (event.importance >= 3 && ypp <= 5) return true;
    if (ypp <= 1) return true;
    return false;
  }

  int _calculateTickInterval(double ypp) {
    if (ypp > 10) return 500;
    if (ypp > 5) return 200;
    if (ypp > 2) return 100;
    if (ypp > 0.5) return 50;
    if (ypp > 0.2) return 10;
    return 1;
  }

  @override
  bool shouldRepaint(covariant TimelineCanvasPainter oldDelegate) {
    return oldDelegate.viewport != viewport ||
        oldDelegate.visibleEvents != visibleEvents ||
        oldDelegate.selectedEventId != selectedEventId ||
        oldDelegate.multiSelectedIds != multiSelectedIds;
  }
}
```

```dart
  final void Function(double pixelX, double canvasWidth) onLongPress;

    required this.child,
    required this.onPan,
    required this.onZoom,
    required this.onTap,

  });

  @override
  State<TimelineGestureHandler> createState() => _TimelineGestureHandlerState();
}

class _TimelineGestureHandlerState extends State<TimelineGestureHandler> {
  Offset _lastFocalPoint = Offset.zero;
  double _initialScale = 1.0;
  bool _isLongPressing = false;

  @override
  Widget build(BuildContext context) {
    return RawGestureDetector(
      gestures: {
        PanGestureRecognizer: GestureRecognizerFactoryWithHandlers<PanGestureRecognizer>(
          () => PanGestureRecognizer(),
          (recognizer) {
            recognizer
              ..onStart = (details) {
                _lastFocalPoint = details.globalPosition;
              }
              ..onUpdate = (details) {
                final delta = details.globalPosition - _lastFocalPoint;
                _lastFocalPoint = details.globalPosition;
                // 水平拖拽 → 年份偏移（通过 pixelsPerYear 反算）
                widget.onPan(delta.dx);
              };
          },
        ),
        ScaleGestureRecognizer: GestureRecognizerFactoryWithHandlers<ScaleGestureRecognizer>(
          () => ScaleGestureRecognizer(),
          (recognizer) {
            recognizer
              ..onStart = (details) {
                _initialScale = details.scale;
                _lastFocalPoint = details.focalPoint;
              }
              ..onUpdate = (details) {
                if (details.pointerCount >= 2) {
                  // 双指缩放
                  final factor = _initialScale / details.scale;
                  _initialScale = details.scale;
                  widget.onZoom(factor, details.focalPoint);
                }
              };
          },
        ),
      },
      child: GestureDetector(
        onTapUp: (details) {
          widget.onTap(details.localPosition.dx, context.size!.width);
        },
        onLongPressStart: (details) {
          _isLongPressing = true;
          HapticFeedback.mediumImpact();
          widget.onLongPress(details.localPosition.dx, context.size!.width);
        },
        onDoubleTap: widget.onDoubleTapEmpty,
        child: widget.child,
      ),
    );
  }
}
```

```dart
class MiniMapPainter extends CustomPainter {
  final List<TimelineEra> eras;
  final double totalYearSpan;
  final int globalMinYear;
  final double viewportCenterYear;
  final double viewportRange;

  // ... (绘制压缩版时代色块 + 视口指示器矩形)

  @override
  void paint(Canvas canvas, Size size) {
    // 绘制时代色块（压缩版）
    for (final era in eras) {
      final startX = (era.startYear - globalMinYear) / totalYearSpan * size.width;
      final endX = (era.endYear - globalMinYear) / totalYearSpan * size.width;
      canvas.drawRect(
        Rect.fromLTRB(startX, 0, endX, size.height),
        Paint()..color = Color(era.colorValue).withOpacity(0.3),
      );
    }

    // 绘制视口指示器
    final vpStartX = (viewportCenterYear - viewportRange / 2 - globalMinYear) /
        totalYearSpan * size.width;
    final vpEndX = (viewportCenterYear + viewportRange / 2 - globalMinYear) /
        totalYearSpan * size.width;
    final vpRect = RRect.fromRectAndRadius(
      Rect.fromLTRB(vpStartX, 2, vpEndX, size.height - 2),
      const Radius.circular(3),
    );
    canvas.drawRRect(
      vpRect,
      Paint()
        ..color = Colors.blue.withOpacity(0.3)
        ..style = PaintingStyle.fill,
    );
    canvas.drawRRect(
      vpRect,
      Paint()
        ..color = Colors.blue.withOpacity(0.6)
        ..style = PaintingStyle.stroke
        ..strokeWidth = 1.5,
    );
  }

  @override
  bool shouldRepaint(covariant MiniMapPainter oldDelegate) =>
      oldDelegate.viewportCenterYear != viewportCenterYear;
}
```

## 8. 性能优化策略

### 8.1 视口裁剪

只渲染当前视口范围内的事件节点和关联线，避免全量绘制。

```dart
List<TimelineEvent> _filterVisibleEvents(
  List<TimelineEvent> allEvents,
  ViewportState viewport,
) {
  final buffer = (viewport.maxYear - viewport.minYear) * 0.1; // 10% 缓冲区
  return allEvents.where((e) {
    final eventStart = e.startYear.toDouble();
    final eventEnd = (e.endYear ?? e.startYear).toDouble();
    return eventEnd >= viewport.minYear - buffer &&
           eventStart <= viewport.maxYear + buffer;
  }).toList();
}
```

### 8.2 数据分片加载

中国史和世界史数据量大（可能超过 2000 个事件节点），采用按朝代/时代分片加载策略：

1. **首屏加载**：仅加载用户当前学段对应的 2-3 个朝代的数据
2. **预加载**：用户缩放/平移接近边界时，提前加载相邻朝代
3. **缓存策略**：已加载的朝代数据缓存在本地 SQLite，7天过期

### 8.3 渲染优化

| 策略 | 说明 |
|------|------|
| RepaintBoundary | 时间轴画布用 RepaintBoundary 隔离，避免底部弹窗变化触发重绘 |
| LayerCache | 缩放停止 300ms 后，将当前视口内容缓存为图片层 |
| 事件节点复用 | 节点绘制使用预计算的 Path 对象池 |
| 文字布局缓存 | TextPainter 结果按事件ID缓存，避免每帧重复计算 |

## 9. 错误处理

### 9.1 错误场景

| 场景 | 处理策略 |
|------|----------|
| 网络请求失败 | 优先使用本地缓存；缓存不可用时显示错误态 + 重试按钮 |
| 数据解析异常 | 跳过异常事件，只渲染有效数据；上报错误日志 |
| AI 讲解 SSE 断开 | 显示已接收内容 + "讲解中断"提示 + 重试按钮 |
| 关联事件数据缺失 | 关联线只绘制两端数据均存在的关联 |
| 极端缩放（yearsPerPixel < 0.01 或 > 50） | 限制缩放范围，到达边界时提供触觉反馈 |
| 内存不足（大量事件） | 触发 GC + 自动扩大 yearsPerPixel（缩小到更宏观视角） |

### 9.2 错误码映射

```dart
extension TimelineErrorCode on int {
  String get userMessage {
    switch (this) {
      case 4001001: return '年份范围无效，请重新选择';
      case 4001002: return '地区参数无效';
      case 4041001: return '未找到该历史事件';
      case 4291001: return '请求过于频繁，请稍后再试';
      case 5001001: return '时间轴数据服务暂时不可用';
      default: return '加载失败，请重试';
    }
  }
}
```
