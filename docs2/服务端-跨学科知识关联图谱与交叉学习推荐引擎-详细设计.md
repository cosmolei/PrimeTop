## 1. 模块概述

### 1.1 功能定位

跨学科知识关联图谱与交叉学习推荐引擎（以下简称"跨学科引擎"，CrossSubjectEngine）是 PrimeTop 平台级的知识关联分析与推荐服务，负责：

1. **跨学科知识关联建模**：建立数学↔物理、化学↔生物、历史↔政治↔地理、语文↔历史等学科间的知识关联图谱，标注关联类型、关联强度和方向性。
2. **交叉前置知识检测**：识别"学习B学科某知识点，需要A学科某知识点作为前置基础"的跨学科依赖关系（如：理解化学反应平衡需要数学中的对数运算基础）。
3. **跨学科主题推荐**：基于新课标"跨学科主题学习"要求，为学生的跨学科项目式学习提供主题推荐和资源编排。
4. **交叉考点强化练习**：在新高考/中考综合题场景下，推送跨学科综合题和关联知识点练习。
5. **学科能力迁移分析**：分析学生在A学科的能力是否有效迁移到B学科关联知识点，识别"迁移障碍"。
6. **跨学科综合素质画像**：为综合素质评价提供跨学科维度数据支撑。

### 1.2 核心价值

| 价值维度 | 说明 |
|----------|------|
| 学生侧 | 帮助学生理解学科间联系，提升综合解题能力，应对新高考跨学科题型 |
| 教师侧 | 为教师提供跨学科教学建议，发现学生的学科迁移障碍 |
| 内容侧 | 指导跨学科综合题的生产和标签体系建设 |
| 产品侧 | 增强知识图谱的深度，形成差异化竞争壁垒 |
| 合规侧 | 响应新课标"跨学科主题学习"要求，贴合教育改革方向 |

## 3. 核心概念与领域模型

### 3.1 关联类型定义

跨学科关联并非简单的"相关"，需要精确分类以支撑不同业务场景：

```java
public enum CrossLinkType {
    /**
     * 前置依赖：学习B学科知识点需要A学科知识点作为基础
     * 例：数学-对数运算 → 化学-pH计算
     */
    PREREQUISITE("前置依赖"),

    /**
     * 方法迁移：A学科的解题方法可迁移到B学科
     * 例：数学-配方法 → 化学-配平化学方程式
     */
    METHOD_TRANSFER("方法迁移"),

    /**
     * 概念同构：不同学科中本质相似的底层概念
     * 例：物理-平衡态 ↔ 化学-化学平衡 ↔ 数学-稳态方程
     */
    CONCEPT_HOMOLOGY("概念同构"),

    /**
     * 工具应用：A学科的工具/技术在B学科中有应用场景
     * 例：数学-坐标系 → 地理-经纬度定位
     */
    TOOL_APPLICATION("工具应用"),

    /**
     * 主题关联：多个学科共同涉及的交叉主题
     * 例：环境保护（化学污染物 + 生物生态系统 + 地理环境）
     */
    THEME_OVERLAP("主题关联"),

    /**
     * 考试关联：中考/高考中常以跨学科综合题形式出现的关联
     * 例：物理-电路 + 数学-函数图像分析
     */
    EXAM_CROSS("考试综合");
}
```

### 3.2 关联强度模型

```java
/**
 * 关联强度多维度评分，最终通过加权求和得到 0~100 的强度分。
 */
public class CrossLinkStrength implements Serializable {
    private Integer conceptualCloseness;   // 概念相似度 0-100（教研标注）
    private Integer frequencyCoOccurrence;  // 共现频率 0-100（数据驱动）
    private Integer studentTransferRate;    // 学生迁移成功率 0-100（数据统计）
    private Integer examCoOccurrence;       // 考试共现频率 0-100（真题分析）
    private Integer difficultyGap;           // 难度梯度差 0-100（差异越大，迁移越难）

    /**
     * 计算综合强度分
     */
    public int computeOverallScore() {
        return Math.round(
            conceptualCloseness * 0.30f +
            frequencyCoOccurrence * 0.25f +
            studentTransferRate * 0.20f +
            examCoOccurrence * 0.15f +
            (100 - difficultyGap) * 0.10f
        );
    }
}
```

## 4. 数据库设计

### 4.1 PostgreSQL 表结构

#### 4.1.1 `cross_subject_link` — 跨学科知识关联表

```sql
CREATE TABLE cross_subject_link (
    id                  BIGSERIAL PRIMARY KEY,
    source_kp_id        BIGINT       NOT NULL,
    target_kp_id        BIGINT       NOT NULL,
    source_subject      VARCHAR(20)  NOT NULL,
    target_subject      VARCHAR(20)  NOT NULL,
    link_type           VARCHAR(30)  NOT NULL,

    -- 关联强度各维度评分
    strength_conceptual     SMALLINT DEFAULT 50,
    strength_cooccurrence   SMALLINT DEFAULT 50,
    strength_transfer_rate  SMALLINT DEFAULT 50,
    strength_exam_cross     SMALLINT DEFAULT 50,
    strength_difficulty_gap SMALLINT DEFAULT 50,
    strength_overall        SMALLINT GENERATED ALWAYS AS (
        ROUND(
            strength_conceptual     * 0.30 +
            strength_cooccurrence   * 0.25 +
            strength_transfer_rate  * 0.20 +
            strength_exam_cross     * 0.15 +
            (100 - strength_difficulty_gap) * 0.10
        )
    ) STORED,

    description         TEXT,
    example_text        TEXT,
    cross_grade_min     SMALLINT,
    cross_grade_max     SMALLINT,

    status              VARCHAR(20)  NOT NULL DEFAULT 'DRAFT',
    created_by          BIGINT       NOT NULL,
    reviewed_by         BIGINT,
    created_at          TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    reviewed_at         TIMESTAMPTZ,
    updated_at          TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    version             INTEGER      NOT NULL DEFAULT 1,

    -- 确保不重复创建相同关联（同源、同目标、同类型）
    CONSTRAINT uk_cross_link UNIQUE (source_kp_id, target_kp_id, link_type),

    -- 源和目标不能属于同一学科
    CONSTRAINT chk_different_subject CHECK (source_subject <> target_subject),

    -- 评分范围约束
    CONSTRAINT chk_strength_range CHECK (
        strength_conceptual     BETWEEN 0 AND 100 AND
        strength_cooccurrence   BETWEEN 0 AND 100 AND
        strength_transfer_rate  BETWEEN 0 AND 100 AND
        strength_exam_cross     BETWEEN 0 AND 100 AND
        strength_difficulty_gap BETWEEN 0 AND 100
    )
);

-- 关键索引
CREATE INDEX idx_csl_source_kp  ON cross_subject_link (source_kp_id) WHERE status = 'ACTIVE';
CREATE INDEX idx_csl_target_kp  ON cross_subject_link (target_kp_id) WHERE status = 'ACTIVE';
CREATE INDEX idx_csl_source_subj ON cross_subject_link (source_subject, link_type) WHERE status = 'ACTIVE';
CREATE INDEX idx_csl_subjects   ON cross_subject_link (source_subject, target_subject) WHERE status = 'ACTIVE';
CREATE INDEX idx_csl_type       ON cross_subject_link (link_type, status);
CREATE INDEX idx_csl_grade      ON cross_subject_link (cross_grade_min, cross_grade_max) WHERE status = 'ACTIVE';
CREATE INDEX idx_csl_strength   ON cross_subject_link (strength_overall DESC) WHERE status = 'ACTIVE';

COMMENT ON TABLE cross_subject_link IS '跨学科知识关联表';
```

```sql
CREATE TABLE ability_migration_record (
    id                  BIGSERIAL PRIMARY KEY,
    student_id          BIGINT       NOT NULL,
    cross_link_id       BIGINT       NOT NULL,
    source_kp_id        BIGINT       NOT NULL,
    target_kp_id        BIGINT       NOT NULL,
    source_mastery      NUMERIC(4,3) NOT NULL,   -- 0.000 ~ 1.000
    target_mastery      NUMERIC(4,3) NOT NULL,
    transfer_efficiency NUMERIC(5,3) GENERATED ALWAYS AS (
        CASE
            WHEN source_mastery < 0.01 THEN 0
            ELSE LEAST(target_mastery / source_mastery, 9.999)
        END
    ) STORED,
    transfer_status     VARCHAR(20)  NOT NULL,   -- POSITIVE, BLOCKED, NEGATIVE, PENDING
    evaluated_at        TIMESTAMPTZ  NOT NULL DEFAULT NOW(),

    CONSTRAINT chk_mastery_range CHECK (
        source_mastery BETWEEN 0 AND 1 AND target_mastery BETWEEN 0 AND 1
    )
);

CREATE INDEX idx_amr_student   ON ability_migration_record (student_id);
CREATE INDEX idx_amr_link      ON ability_migration_record (cross_link_id);
CREATE INDEX idx_amr_status    ON ability_migration_record (transfer_status);
CREATE INDEX idx_amr_evaluated ON ability_migration_record (evaluated_at DESC);
```

### 4.2 Redis 缓存结构

```
# 跨学科关联缓存（按知识点ID索引）
# Key: cross_link:kp:{kpId}
# Value: Hash → list of JSON objects
# TTL: 24h, 主动失效
cross_link:kp:10234 → [
    {"targetKpId":10567,"targetSubject":"CHEMISTRY","linkType":"PREREQUISITE","strength":85,"description":"对数运算→pH计算"},
    {"targetKpId":10890,"targetSubject":"PHYSICS","linkType":"METHOD_TRANSFER","strength":72,"description":"配方法→方程求解"}
]

# 跨学科推荐结果缓存（按学生+场景索引）
# Key: cross_rec:{studentId}:{scene}
# Value: JSON string
# TTL: 2h
cross_rec:10086:EXAM_PREP → [
    {"kpId":10234,"subject":"MATH","reason":"你在化学pH计算中出错，建议复习对数运算基础","priority":1},
    ...
]

# 热门跨学科关联（全平台Top-N）
# Key: cross_link:hot:{gradeRange}
# Value: Sorted Set → crossLinkId → score
# TTL: 6h, 定时刷新
cross_link:hot:G7-G9 → ZSET entries

# 跨学科主题缓存
# Key: cross_theme:{gradeLevel}
# Value: JSON string
# TTL: 1h
cross_theme:G8 → [{"id":1,"title":"环境保护与可持续发展","subjects":["CHEM","BIO","GEO"],...}]
```

```cypher
    link_type: "PREREQUISITE",
    strength: 85,
    description: "对数运算是理解pH值对数关系的基础",
    grade_min: 8,
    grade_max: 12,
    status: "ACTIVE"
}]->(kp2);

// 查询示例：获取某知识点的所有跨学科关联
MATCH (kp:KnowledgePoint {id: $kpId})-[r:CROSSES_SUBJECT]->(cross:KnowledgePoint)
WHERE r.status = 'ACTIVE'
  AND $grade >= r.grade_min AND $grade <= r.grade_max
RETURN cross.id, cross.name, cross.subject, r.link_type, r.strength
ORDER BY r.strength DESC;

MATCH path = (kp1:KnowledgePoint {subject: $subject1})-[:CROSSES_SUBJECT*1..2]->(kp2:KnowledgePoint {subject: $subject2})
WHERE ALL(r IN relationships(path) WHERE r.status = 'ACTIVE')
RETURN path
LIMIT 10;

// 查询示例：某主题涉及的所有知识点及其跨学科关联
MATCH (kp:KnowledgePoint)-[r:CROSSES_SUBJECT]->(cross:KnowledgePoint)
WHERE kp.id IN $themeKpIds AND r.status = 'ACTIVE'
RETURN kp, r, cross
ORDER BY r.strength DESC;
```

## 6. 核心算法设计

### 6.1 跨学科推荐引擎

```java
/**
 * 跨学科推荐引擎核心算法
 */
@Service
public class CrossSubjectRecommender {

    @Autowired
    private CrossLinkRepository linkRepository;

    @Autowired
    private MasteryService masteryService;

    @Autowired
    private MistakeService mistakeService;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /**
     * 生成交叉学习推荐
     *
     * @param context 推荐上下文
     * @return 推荐结果列表
     */
    public List<CrossRecommendation> recommend(CrossRecommendContext context) {
        List<CrossRecommendation> results = new ArrayList<>();

        // 策略1：前置依赖补弱 — 发现学生当前薄弱知识点的跨学科前置根因
        results.addAll(recommendByPrerequisiteGap(context));

        // 策略2：正向迁移拓展 — 学生在某学科掌握好，推荐关联学科的拓展学习
        results.addAll(recommendByPositiveTransfer(context));

        // 策略3：跨学科主题探索 — 根据学生兴趣和水平推荐交叉主题
        results.addAll(recommendCrossTheme(context));

        // 策略4：考试综合题推荐 — 考试场景下推荐跨学科综合题练习
        if (context.getScene() == RecommendationScene.EXAM_PREP) {
            results.addAll(recommendExamCrossQuestions(context));
        }

        // 合并、去重、排序
        return rankAndDedup(results, context.getMaxRecommendations());
    }

    /**
     * 策略1：前置依赖补弱
     * 逻辑：遍历学生薄弱的B学科知识点，查找其A学科前置知识，
     *      如果A学科前置也薄弱，则推荐先复习A学科前置。
     */
    private List<CrossRecommendation> recommendByPrerequisiteGap(CrossRecommendContext ctx) {
        List<CrossRecommendation> recs = new ArrayList<>();

        // 获取学生当前学科中掌握度 < 0.6 的知识点
        List<KpMastery> weakKps = masteryService.getWeakKnowledgePoints(
            ctx.getStudentId(), ctx.getCurrentSubject(), 0.6, 20);

        for (KpMastery weakKp : weakKps) {
            // 查找该弱项知识点的前置依赖跨学科关联
            List<CrossSubjectLink> prereqLinks = linkRepository.findActiveLinks(
                weakKp.getKpId(),
                CrossLinkType.PREREQUISITE,
                LinkDirection.TARGET,  // 弱项是"目标"，找其"源"前置
                ctx.getGradeLevel()
            );

            for (CrossSubjectLink link : prereqLinks) {
                BigDecimal sourceMastery = masteryService.getMastery(
                    ctx.getStudentId(), link.getSourceKpId());

                // 如果前置知识点也薄弱，这是"迁移障碍"
                if (sourceMastery.compareTo(BigDecimal.valueOf(0.6)) < 0) {
                    CrossRecommendation rec = CrossRecommendation.builder()
                        .type(RecommendType.KNOWLEDGE_REVIEW)
                        .sourceKp(KpRef.of(link.getSourceKpId(), link.getSourceSubject()))
                        .targetKp(KpRef.of(link.getTargetKpId(), link.getTargetSubject()))
                        .linkType(CrossLinkType.PREREQUISITE)
                        .strength(link.getStrengthOverall())
                        .priority(computePriority(sourceMastery, weakKp.getMastery(), link))
                        .reason(String.format(
                            "你在%s中频繁出错，根源可能是%s的%s基础薄弱",
                            weakKp.getKpName(),
                            link.getSourceSubject(),
                            link.getSourceKpName()
                        ))
                        .actions(buildReviewActions(link))
                        .build();
                    recs.add(rec);
                }
            }
        }

        return recs;
    }

    /**
     * 策略2：正向迁移拓展
     * 逻辑：学生A学科掌握好（>0.8），推荐B学科中与A有关联的拓展内容
     */
    private List<CrossRecommendation> recommendByPositiveTransfer(CrossRecommendContext ctx) {
        List<CrossRecommendation> recs = new ArrayList<>();

        // 获取学生掌握度 > 0.8 的知识点
        List<KpMastery> strongKps = masteryService.getStrongKnowledgePoints(
            ctx.getStudentId(), ctx.getCurrentSubject(), 0.8, 15);

        for (KpMastery strongKp : strongKps) {
            List<CrossSubjectLink> links = linkRepository.findActiveLinks(
                strongKp.getKpId(),
                null,  // 所有关联类型
                LinkDirection.SOURCE,
                ctx.getGradeLevel()
            );

            for (CrossSubjectLink link : links) {
                // 过滤目标学科
                if (ctx.getTargetSubjects() != null &&
                    !ctx.getTargetSubjects().contains(link.getTargetSubject())) {
                    continue;
                }

                BigDecimal targetMastery = masteryService.getMastery(
                    ctx.getStudentId(), link.getTargetKpId());

                // 目标知识点尚未学习或掌握度低 → 推荐拓展
                if (targetMastery.compareTo(BigDecimal.valueOf(0.4)) < 0) {
                    CrossRecommendation rec = CrossRecommendation.builder()
                        .type(RecommendType.EXTEND_LEARNING)
                        .sourceKp(KpRef.of(link.getSourceKpId(), link.getSourceSubject()))
                        .targetKp(KpRef.of(link.getTargetKpId(), link.getTargetSubject()))
                        .linkType(link.getLinkType())
                        .strength(link.getStrengthOverall())
                        .priority(computeExtendPriority(strongKp.getMastery(), targetMastery, link))
                        .reason(String.format(
                            "你对%s掌握很好，可以尝试学习%s中的%s",
                            strongKp.getKpName(),
                            link.getTargetSubject(),
                            link.getTargetKpName()
                        ))
                        .build();
                    recs.add(rec);
                }
            }
        }

        return recs;
    }

    /**
     * 推荐优先级计算
     * 综合考虑：源掌握度（越低越紧急）× 目标掌握度（越低越紧急）× 关联强度
     */
    private int computePriority(BigDecimal sourceMastery, BigDecimal targetMastery,
                                CrossSubjectLink link) {
        double urgencyScore = (1.0 - sourceMastery.doubleValue()) * 0.35
                            + (1.0 - targetMastery.doubleValue()) * 0.35;
        double strengthScore = link.getStrengthOverall() / 100.0 * 0.30;
        return (int) Math.round(urgencyScore * 100 + strengthScore * 100);
    }

    /**
     * 推荐排序与去重
     */
    private List<CrossRecommendation> rankAndDedup(List<CrossRecommendation> recs, int limit) {
        // 按 targetKpId 去重，保留优先级更高的
        Map<Long, CrossRecommendation> deduped = new LinkedHashMap<>();
        for (CrossRecommendation rec : recs) {
            Long targetKpId = rec.getTargetKp().getKpId();
            CrossRecommendation existing = deduped.get(targetKpId);
            if (existing == null || rec.getPriority() > existing.getPriority()) {
                deduped.put(targetKpId, rec);
            }
        }

        return deduped.values().stream()
            .sorted(Comparator.comparing(CrossRecommendation::getPriority).reversed())
            .limit(limit)
            .collect(Collectors.toList());
    }
}
```

### 6.2 能力迁移分析算法

```java
/**
 * 学科能力迁移分析器
 */
@Service
public class AbilityMigrationAnalyzer {

    private static final double POSITIVE_THRESHOLD = 0.6;   // 迁移效率 >= 0.6 视为正向
    private static final double BLOCKED_THRESHOLD = 0.3;    // 迁移效率 < 0.3 视为障碍
    private static final double SOURCE_THRESHOLD = 0.5;     // 源掌握度 >= 0.5 才评估迁移

    /**
     * 批量评估学生的跨学科能力迁移
     * 定时任务调用，每日凌晨执行
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void batchEvaluateMigration() {
        int pageSize = 200;
        int pageNum = 0;

        while (true) {
            List<Long> studentIds = studentService.getActiveStudentIds(pageNum, pageSize);
            if (studentIds.isEmpty()) break;

            for (Long studentId : studentIds) {
                evaluateMigrationForStudent(studentId);
            }

            pageNum++;
        }
    }

    /**
     * 评估单个学生的迁移状态
     */
    @Transactional
    public void evaluateMigrationForStudent(Long studentId) {
        // 获取所有活跃的跨学科关联
        List<CrossSubjectLink> activeLinks = linkRepository.findAllActive();

        for (CrossSubjectLink link : activeLinks) {
            BigDecimal sourceMastery = masteryService.getMastery(studentId, link.getSourceKpId());
            BigDecimal targetMastery = masteryService.getMastery(studentId, link.getTargetKpId());

            // 源知识点未学习到一定程度，跳过
            if (sourceMastery.compareTo(BigDecimal.valueOf(SOURCE_THRESHOLD)) < 0) {
                continue;
            }

            MigrationStatus status = classifyMigration(sourceMastery, targetMastery);

            // 更新或创建迁移记录
            AbilityMigrationRecord record = migrationRepository
                .findByStudentAndLink(studentId, link.getId())
                .orElse(new AbilityMigrationRecord());

            record.setStudentId(studentId);
            record.setCrossLinkId(link.getId());
            record.setSourceKpId(link.getSourceKpId());
            record.setTargetKpId(link.getTargetKpId());
            record.setSourceMastery(sourceMastery);
            record.setTargetMastery(targetMastery);
            record.setTransferStatus(status.name());
            record.setEvaluatedAt(LocalDateTime.now());

            migrationRepository.save(record);
        }
    }

    /**
     * 迁移状态分类
     */
    private MigrationStatus classifyMigration(BigDecimal source, BigDecimal target) {
        double efficiency = source.doubleValue() > 0.01
            ? target.doubleValue() / source.doubleValue()
            : 0;

        if (efficiency >= POSITIVE_THRESHOLD) {
            return MigrationStatus.POSITIVE;
        } else if (efficiency < BLOCKED_THRESHOLD && source.doubleValue() >= 0.7) {
            // 源掌握高但目标掌握很低 → 迁移障碍
            return MigrationStatus.BLOCKED;
        } else if (target.compareTo(BigDecimal.valueOf(0.3)) < 0) {
            return MigrationStatus.NEGATIVE;
        }
        return MigrationStatus.PENDING;
    }

    /**
     * 生成迁移分析报告
     */
    public MigrationAnalysisReport generateReport(Long studentId, String subjectPair, TimeRange range) {
        List<AbilityMigrationRecord> records = migrationRepository
            .findByStudentAndTimeRange(studentId, range.getStart(), range.getEnd());

        // 按学科对分组统计
        Map<String, List<AbilityMigrationRecord>> grouped = records.stream()
            .collect(Collectors.groupingBy(r ->
                r.getSourceKp().getSubject() + " → " + r.getTargetKp().getSubject()));

        List<SubjectPairAnalysis> pairAnalyses = grouped.entrySet().stream()
            .filter(e -> subjectPair == null || subjectPair.equals(e.getKey()))
            .map(e -> buildPairAnalysis(e.getKey(), e.getValue()))
            .sorted(Comparator.comparing(SubjectPairAnalysis::getAvgTransferEfficiency))
            .collect(Collectors.toList());

        // 整体迁移分数
        double overallScore = records.stream()
            .mapToDouble(r -> {
                double src = r.getSourceMastery().doubleValue();
                double tgt = r.getTargetMastery().doubleValue();
                return src > 0.01 ? Math.min(tgt / src, 1.0) : 0;
            })
            .average()
            .orElse(0);

        // 生成建议
        List<String> suggestions = generateSuggestions(pairAnalyses);

        return MigrationAnalysisReport.builder()
            .studentId(studentId)
            .overallTransferScore(BigDecimal.valueOf(overallScore))
            .analysis(pairAnalyses)
            .recommendations(suggestions)
            .build();
    }

    /**
     * 生成个性化建议
     */
    private List<String> generateSuggestions(List<SubjectPairAnalysis> pairs) {
        List<String> suggestions = new ArrayList<>();

        // 找到迁移效率最低的学科对
        Optional<SubjectPairAnalysis> worst = pairs.stream()
            .filter(p -> p.getAvgTransferEfficiency() < 0.5)
            .min(Comparator.comparing(SubjectPairAnalysis::getAvgTransferEfficiency));

        worst.ifPresent(w -> {
            suggestions.add(String.format(
                "%s的迁移效率偏低（%.0f%%），建议优先强化%s的薄弱前置知识点",
                w.getSubjectPair(),
                w.getAvgTransferEfficiency() * 100,
                w.getSubjectPair().split(" → ")[0]
            ));
        });

        // 找到迁移效率最好的学科对
        Optional<SubjectPairAnalysis> best = pairs.stream()
            .filter(p -> p.getAvgTransferEfficiency() > 0.75)
            .max(Comparator.comparing(SubjectPairAnalysis::getAvgTransferEfficiency));

        best.ifPresent(b -> {
            suggestions.add(String.format(
                "%s的迁移表现优秀，可以尝试更高难度的%s综合题",
                b.getSubjectPair(),
                b.getSubjectPair().split(" → ")[1]
            ));
        });

        return suggestions;
    }
}
```

### 6.3 AI 辅助关联发现

```java
/**
 * AI 辅助跨学科关联发现服务
 * 利用大模型分析知识点描述，自动发现潜在跨学科关联
 */
@Service
public class AICrossLinkDiscoveryService {

    @Autowired
    private LlmClient llmClient;

    @Autowired
    private KnowledgePointService kpService;

    @Autowired
    private EmbeddingService embeddingService;

    /**
     * 自动发现两个学科之间的潜在跨学科关联
     *
     * @param subjectPair 学科对，如 "MATH-PHYSICS"
     * @param maxResults  最大返回数
     * @param minConfidence 最低置信度
     */
    public List<ProposedCrossLink> autoDiscover(String subjectPair, int maxResults, double minConfidence) {
        String[] subjects = subjectPair.split("-");
        String sourceSubject = subjects[0];
        String targetSubject = subjects[1];

        // Step 1: 获取两学科的知识点列表
        List<KnowledgePoint> sourceKps = kpService.getBySubject(sourceSubject);
        List<KnowledgePoint> targetKps = kpService.getBySubject(targetSubject);

        // Step 2: 语义相似度预筛 — 使用嵌入向量召回Top候选对
        List<CandidatePair> candidates = semanticRecall(sourceKps, targetKps, maxResults * 3);

        // Step 3: 对候选对使用大模型深度分析
        List<ProposedCrossLink> proposals = new ArrayList<>();
        for (CandidatePair candidate : candidates) {
            ProposedCrossLink proposal = analyzeWithLLM(candidate);
            if (proposal != null && proposal.getConfidence() >= minConfidence) {
                proposals.add(proposal);
            }
        }

        // Step 4: 按置信度排序，截取top N
        return proposals.stream()
            .sorted(Comparator.comparing(ProposedCrossLink::getConfidence).reversed())
            .limit(maxResults)
            .collect(Collectors.toList());
    }

    /**
     * 语义相似度预筛
     */
    private List<CandidatePair> semanticRecall(List<KnowledgePoint> sourceKps,
                                                List<KnowledgePoint> targetKps,
                                                int topK) {
        // 计算所有知识点对的余弦相似度
        List<CandidatePair> pairs = new ArrayList<>();

        for (KnowledgePoint src : sourceKps) {
            float[] srcEmbedding = embeddingService.getEmbedding(src.getDescription());

            for (KnowledgePoint tgt : targetKps) {
                float[] tgtEmbedding = embeddingService.getEmbedding(tgt.getDescription());
                double similarity = CosineSimilarity.compute(srcEmbedding, tgtEmbedding);

                if (similarity > 0.6) {  // 初筛阈值
                    pairs.add(new CandidatePair(src, tgt, similarity));
                }
            }
        }

        return pairs.stream()
            .sorted(Comparator.comparing(CandidatePair::getSimilarity).reversed())
            .limit(topK)
            .collect(Collectors.toList());
    }

    /**
     * 使用大模型分析候选对的跨学科关系
     */
    private ProposedCrossLink analyzeWithLLM(CandidatePair candidate) {
        String prompt = buildAnalysisPrompt(candidate.getSource(), candidate.getTarget());

        LlmResponse response = llmClient.chat(prompt, ModelType.GPT4_EQUIVALENT);

        // 解析模型输出
        return parseProposal(response, candidate);
    }

    private String buildAnalysisPrompt(KnowledgePoint src, KnowledgePoint tgt) {
        return String.format("""
            你是一位资深教育教研专家。请分析以下两个不同学科的知识点之间是否存在有意义的关联。

            知识点A（%s）：%s
            课标要求：%s

            知识点B（%s）：%s
            课标要求：%s

            请分析：
            1. 这两个知识点是否存在关联？如果不存在，请直接返回 {"related": false}
            2. 如果存在，关联类型是什么？（PREREQUISITE/METHOD_TRANSFER/CONCEPT_HOMOLOGY/TOOL_APPLICATION/THEME_OVERLAP/EXAM_CROSS）
            3. 关联方向（A→B 还是 B→A 还是双向）
            4. 概念相似度评分（0-100）
            5. 关联描述和具体示例
            6. 置信度评分（0.0-1.0）

            请以JSON格式返回：
            {"related": true, "linkType": "...", "direction": "A_TO_B", "conceptualCloseness": 85, "description": "...", "example": "...", "confidence": 0.85}
            """,
            src.getSubject(), src.getName() + " - " + src.getDescription(), src.getCurriculumStandard(),
            tgt.getSubject(), tgt.getName() + " - " + tgt.getDescription(), tgt.getCurriculumStandard()
        );
    }
}
```

## 8. 错误处理策略

### 8.1 错误码定义

| 错误码 | HTTP | 说明 | 处理策略 |
|--------|------|------|----------|
| CROSS_LINK_NOT_FOUND | 404 | 跨学科关联不存在 | 返回空结果而非报错 |
| CROSS_LINK_DUPLICATE | 409 | 关联已存在（同源同目标同类型） | 返回已有关联信息 |
| CROSS_LINK_REVIEW_DENIED | 403 | 无审核权限 | 提示角色要求 |
| CROSS_SUBJECT_MISMATCH | 400 | 源和目标属于同一学科 | 参数校验拦截 |
| MIGRATION_DATA_INSUFFICIENT | 422 | 迁移分析数据不足 | 返回部分结果 + 提示 |
| THEME_NOT_PUBLISHED | 403 | 主题未发布 | 返回预览版（如有权限） |
| GRAPH_QUERY_TIMEOUT | 504 | 图数据库查询超时 | 降级为缓存/关系库查询 |
| AI_DISCOVERY_RATE_LIMIT | 429 | AI发现服务限流 | 排队重试 |

### 8.2 降级策略

```java
    /**
     * 推荐引擎不可用时，返回缓存结果
     */
    public List<CrossRecommendation> fallbackRecommendation(Long studentId) {
        String cached = redisTemplate.opsForValue()
            .get("cross_rec:" + studentId + ":last_good");

        if (cached != null) {
            log.info("推荐引擎不可用，返回上次缓存结果, studentId={}", studentId);
            return JSON.parseArray(cached, CrossRecommendation.class);
        }

        // 最终降级：返回空列表（不影响主学习流程）
        log.warn("跨学科推荐完全不可用，返回空列表");
        return Collections.emptyList();
    }

    public MigrationAnalysisReport fallbackMigrationReport(Long studentId) {

            .overallTransferScore(BigDecimal.ZERO)
            .analysis(Collections.emptyList())
            .recommendations(List.of(
                "当前学习数据不足以进行跨学科迁移分析，建议继续学习后再查看"

            .insufficientData(true)
```

### 8.3 异常场景与保护

| 异常场景 | 影响 | 保护措施 |
|----------|------|----------|
