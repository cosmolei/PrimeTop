# 英语语法专项训练系统 - 详细设计

> 模块定位：面向小学高年级至高中学生，提供英语语法知识体系化学习、专项练习、AI 智能讲解与语法错误诊断的一体化训练系统。
> 优先级：P1（V1.5 阶段上线）
> 依赖模块：题目与题库服务、AI 对话引擎、用户学习画像、知识点体系与教材映射、自适应推荐引擎、间隔重复复习调度

---

## 1. 模块概述

### 1.1 背景

语法是英语学习的骨架。在中考英语中，语法相关题型（完形填空、语法填空、短文改错）合计占比约 25%-35%；高考英语中语法填空和短文改错合计占 20-30 分。当前产品已有词汇记忆、听力模拟、阅读理解专项模块，但缺少系统化的语法专项训练能力。

学生在语法学习中普遍存在的问题：
1. 语法规则零散，缺乏体系化认知
2. 相似语法结构易混淆（如现在完成时 vs 一般过去时）
3. 知道规则但不会在语境中灵活运用
4. 缺少针对性的错因诊断和复习闭环

### 1.2 目标

1. 建立覆盖小学至高中的英语语法知识图谱，按教材章节和考纲考点组织
2. 支持多种语法题型（单选、填空、改错、翻译、语法填空、完形填空）
3. 提供 AI 智能讲解，结合语境分析语法规则的应用逻辑
4. 基于答题数据构建语法掌握度多维度评估模型
5. 生成个性化语法复习计划，与间隔重复引擎联动

### 1.3 覆盖学段

| 学段 | 目标 | 语法重点 | CEFR |
| --- | --- | --- | --- |
| 小学 5-6 年级 | 建立基本语法意识 | be 动词、一般现在时、名词复数、简单句型 | A1-A2 |
| 初中 7-9 年级 | 构建语法体系框架 | 8 大时态、被动语态、从句基础、非谓语入门 | A2-B1 |
| 高中 10-12 年级 | 高考语法全掌握 | 16 大时态、虚拟语气、复杂从句、非谓语动词、倒装 | B1-B2 |

### 1.4 与其他模块的关系

| 关联模块 | 关系 |
| --- | --- |
| 英语专项学习与口语陪练 | 上层入口模块，本系统为其语法子模块的详细展开 |
| 英语词汇记忆与单词本 | 共享词性标注，语法题中的生词可加入单词本 |
| 英语阅读理解专项训练 | 共享长难句解析能力，语法知识为阅读理解基础 |

| 题目与题库服务 | 消费题库的语法题目，生成 AI 语法题 |
| AI 对话引擎 | 调用 Prompt 编排生成语法讲解和例句 |
| 间隔重复复习调度 | 语法错题推送至复习引擎，按遗忘曲线调度 |

| 用户学习画像 | 输出语法掌握度数据，消费学段年级信息 |

### 2.2 知识点关联关系

语法知识点之间存在多种关联类型：

```text
PREREQUISITE  (前置依赖): 一般现在时 → 现在进行时
CONTRAST      (易混对比): 现在完成时 ↔ 一般过去时
EXTENSION     (进阶扩展): 简单句 → 并列句 → 复合句
APPLICATION   (应用关联): 被动语态 → 时态(组合运用)
PARENT_CHILD  (父子层级): 时态 → 一般现在时
```

### 3.2 用户旅程

```text
[入口] → 首页英语卡片 → 语法专项 / 学习规划推送 / 错题复习入口
    ↓
[知识图谱] → 浏览或搜索语法知识点 → 查看掌握度色块
    ↓
[知识点精讲] → 规则讲解 → 典型例句 → 易错提醒 → 记忆技巧
    ↓
[专项练习] → 选择题型和知识点 → 逐题作答
    ↓                                  ↓
[答对] → 巩固下一题              [答错] → AI 语法讲解
                                       ↓
                               [错误归因] → 标记错因类型
                                       ↓
                               [错题收录] → 加入错题本
                                       ↓
                               [关联知识点] → 推荐相关知识点复习
    ↓
[练习完成] → 正确率统计 → 掌握度更新 → 推荐下一步
```

## 4. 数据模型设计

### 4.1 语法知识点表 `grammar_knowledge_points`

```sql
CREATE TABLE grammar_knowledge_points (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    code                VARCHAR(50) NOT NULL UNIQUE COMMENT '知识点编码: GRAM-TENSE-001',
    name                VARCHAR(100) NOT NULL COMMENT '知识点名称: 一般现在时',
    category            VARCHAR(50) NOT NULL COMMENT '一级分类: 词法/时态/语态/句法/非谓语/特殊句式',
    sub_category        VARCHAR(50) COMMENT '二级分类: 时态 > 过去时态',
    parent_id           BIGINT COMMENT '父知识点ID',
    level               TINYINT NOT NULL COMMENT '层级深度: 1-5',
    path                VARCHAR(500) COMMENT '层级路径: 英语语法,时态,一般现在时',
    sort_order          INT DEFAULT 0 COMMENT '同级排序',

    -- 内容字段
    summary             TEXT COMMENT '一句话概述',
    explanation         TEXT NOT NULL COMMENT '详细规则讲解 (Markdown)',
    key_rules           JSON COMMENT '核心规则列表: ["主语+V(s/es)","时间标志词: always/usually"]',
    examples            JSON NOT NULL COMMENT '例句数组: [{"en":"...","zh":"...","highlight":"..."}]',
    common_mistakes     JSON COMMENT '易错点: [{"mistake":"...","correct":"...","explain":"..."}]',
    memory_tips         JSON COMMENT '记忆口诀/技巧',
    contrast_with       JSON COMMENT '易混对比知识点ID列表及对比说明',

    -- 适用范围
    grade_range         JSON NOT NULL COMMENT '适用学段: ["primary5","primary6","junior1",...]',
    cefr_level          VARCHAR(10) COMMENT '对应CEFR等级',
    exam_weight         JSON COMMENT '考试权重: {"mid_exam":0.3,"college_exam":0.2}',

    -- 关联
    prerequisite_ids    JSON COMMENT '前置知识点ID列表',
    related_point_ids   JSON COMMENT '关联知识点ID列表',

    status              TINYINT DEFAULT 1 COMMENT '1-有效 0-禁用',
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_category (category),
    INDEX idx_parent (parent_id),
    INDEX idx_grade (grade_range(100)),
    INDEX idx_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='英语语法知识点';
```

### 4.2 语法练习题目表 `grammar_questions`

```sql
CREATE TABLE grammar_questions (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    knowledge_point_id  BIGINT NOT NULL COMMENT '关联知识点ID',
    question_type       TINYINT NOT NULL COMMENT '题型: 1=单选 2=语法填空 3=短文改错 4=翻译 5=完形填空 6=判断正误',
    difficulty          TINYINT NOT NULL COMMENT '难度: 1-5',
    source_type         TINYINT COMMENT '来源: 1=真题 2=模拟题 3=AI生成 4=人工编写',
    source_year         SMALLINT COMMENT '真题年份',
    source_region       VARCHAR(50) COMMENT '真题地区',

    -- 题目内容
    stem                TEXT NOT NULL COMMENT '题干',
    context_passage     TEXT COMMENT '上下文语篇（语法填空/改错/完形用）',
    blank_positions     JSON COMMENT '填空位置: [{"index":5,"answer":"has_been","alternatives":...}]',
    options             JSON COMMENT '选项: [{"label":"A","content":"..."},{"label":"B",...}]',
    correct_answer      VARCHAR(200) NOT NULL COMMENT '正确答案',
    answer_explanation  TEXT COMMENT '答案解析',
    grammar_analysis    TEXT COMMENT '语法分析（AI生成）',

    -- 标注
    error_type          VARCHAR(50) COMMENT '改错题的错误类型标签',
    tags                JSON COMMENT '标签: ["中考高频","易错","主谓一致"]',

    status              TINYINT DEFAULT 1 COMMENT '1-有效 0-禁用',
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_kp (knowledge_point_id),
    INDEX idx_type_diff (question_type, difficulty),
    INDEX idx_source (source_type, source_year)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='语法练习题目';
```


## 6. AI 讲解引擎设计

### 6.1 架构定位与委托边界

本模块**不自建 LLM 调用链路**，全部委托平台既有基建：

| 能力 | 委托方 | 边界裁决 |
| --- | --- | --- |
| Prompt 模板管理/版本化 | AI-Prompt编排与场景模板系统 | 本模块仅注册 `scene=GRAMMAR_EXPLAIN` 模板 |
| 模型调用/多供应商容灾 | 服务端-大模型推理统一适配层 | 本模块经其 `chatStream` 接口调用 |
| 输出后处理（适龄化/格式/AIGC 标识） | AI回答后处理与智能优化管线(ARPP) | 讲解全文必经 ARPP |
| 质量校验/事实校验 | AI输出质量校验与多模型复核引擎(VQ) | 考试类真题讲解强制走 VQ |
| 安全审计（非流式） | 服务端-AI对话安全审计与敏感内容自动上报服务 | 落库前审计 |
| 内容安全（流式） | 大模型流式输出实时安全过滤中间件(SOSF) | 流式输出在线过滤 |

### 6.2 Prompt 模板（scene=GRAMMAR_EXPLAIN）

模板变量与版本化要求（模板内容以 Prompt 系统为准，此处为变量契约）：

| 变量 | 来源 | 说明 |
| --- | --- | --- |
| `grade_band` | 用户档案 | `primary_upper`/`junior`/`senior`，决定术语深度与例句题材 |
| `kp_context` | grammar_knowledge_points | 考点讲解/规则/易错点注入 |
| `question` | grammar_questions | 题干/选项/正确答案/用户答案 |
| `depth` | 请求参数 | brief（≤150 词）/detailed（≤400 词）/deep（≤800 词） |
| `contrast_pack` | grammar_knowledge_points.contrast_with | 易混对比包（`include_contrast=true` 时注入） |
| `tone_rules` | 话术白名单 | 成长型话术红线，禁止人格否定 |

输出协议（VQ 校验协议 V1-V5 对齐）：必须为 Markdown，且包含固定小节锚点 `## 题干分析` / `## 考点定位` / `## 规则应用` / `## 易错提醒`，缺失小节由 ARPP 结构化增强层补齐并记 `sections_missing` 负反馈。

### 6.3 讲解缓存

缓存键：`gramexp:v1:{question_id}:{answer_class}:{depth}:{grade_band}:{prompt_version}`，其中 `answer_class` 为 `user_answer` 归一化分桶（`CORRECT`/`BLANK`/答案文本 SimHash 前 8 位），TTL 7 天，Redis LRU 容量 200 万条。

- 缓存内容为**已过 ARPP+VQ 的成品 Markdown + content_hash**，按 Prompt 版本隔离，版本升级即全量失效（防跨版本污染，合规 C4）；
- 命中缓存仍重新走 SOSF 非流式快扫（<50ms，词库热更需生效）；快扫拦截即整缓存条目逻辑删除并落审计；
- 低质评分（ARPP 质量分 < 阈值）禁写缓存。

### 6.4 降级路径

AI 链路任何一环超时/故障（适配层 59810、ARPP/VQ 降级、SOSF 熔断），统一降级为**静态解析兜底**：返回 `grammar_questions.answer_explanation` + `grammar_analysis` + 知识点 `explanation` 摘要拼接，`degraded=true`，`aigc_labeled=false`。降级时 `follow_up` 仅保留知识点跳转，不生成新题推荐。

## 7. 核心业务流程

### 7.1 练习会话状态机

```text
            generate                submit(首题)                 最后一题submit
  CREATED ──────────────▶ IN_PROGRESS ─────────────────────────────────────▶ COMPLETED
     │                        │   ▲                                        │
     │ 24h未首答               │   └──── 断线重连（session_id+last_seq 恢复） │
     ▼                        ▼                                            ▼
  EXPIRED ◀──────────── 24h无心跳且无提交 ────────────────▶ (COMPLETED 终态，不可回退)
```

| 状态 | 含义 | 允许操作 |
| --- | --- | --- |
| CREATED | 题组已生成未作答 | submit（转 IN_PROGRESS）、放弃 |
| IN_PROGRESS | 作答中 | submit、查询 result |
| COMPLETED | 全部题目已提交或用户主动结束 | 仅查询 result（幂等回放） |
| EXPIRED | 超时未答完 | 仅查询已答部分统计 |

守卫：
- G1 同用户同时只允许 1 个 `IN_PROGRESS` 会话（Redis `SETNX grammar:session:active:{user_id}`，TTL 24h，新会话创建即覆盖旧标记但旧会话状态不迁移，读时按 updated_at 仲裁）；
- G2 `is_correct` 一律服务端判分，客户端回传字段忽略；
- G3 重复 submit 相同 `client_request_id` 返回首次结果回放，不重复计分（幂等键见 §10）；
- G7 会话超时不自动判错未答题，仅不计入口径（防伤害性默认，合规 C2）；
- G8 同一题 `attempt_number > 3` 的作答不更新掌握度（防刷分）。

### 7.3 掌握度更新算法

`user_grammar_mastery.mastery_score` 更新（单事务内，行锁 `SELECT ... FOR UPDATE`）：

```java
public double updateScore(double prev, boolean correct, int difficulty,
                          int attempts, Instant lastCorrectAt, Instant now) {
    // 1. 时间衰减（幂等重放时因 now 相同而天然无影响）
    double decayed = prev * Math.exp(-hoursBetween(lastCorrectAt, now) / (60 * 24 * Math.log(2)));
    // 2. 学习率：练习越多单次影响越小，钳制 [0.04, 0.30]
    double alpha = Math.min(0.30, Math.max(0.04, 12.0 / (attempts + 8)));
    // 3. 目标分：答对难题收益更高；答错按当前分 70% 回拉（惩罚也随难度加权）
    double target = correct ? 60 + 10 * difficulty : decayed * (0.70 + 0.04 * difficulty);
    // 4. EMA 更新 + 地板 5
    return Math.max(5.0, decayed + alpha * (target - decayed));
}
```

等级映射（迟滞带 8 分，防边界抖动）：升级需 `score ≥ 阈值`，降级需 `score < 阈值 - 8`：

| level | 名称 | 升级阈值 | 降级阈值 |
| --- | --- | --- | --- |
| 0 | 未学 | —（首练即 1） | — |
| 1 | 了解 | 30 | 22 |
| 2 | 基本掌握 | 50 | 42 |
| 3 | 熟练 | 70 | 62 |
| 4 | 精通 | 85 | 77 |

`next_review_at` 与 `review_interval_days` **本模块不写**，由间隔重复引擎消费 `grammar.mastery.updated` 事件后回写（契约 R3），本模块仅初始化首练时的默认值 interval=1。

### 7.4 错因归因规则

`grammar_practice_logs.error_category` 判定优先级（先规则后 AI，AI 仅在规则未命中且本题为错题时调用轻量分类模型，超时 500ms 即放弃，置 `null` 不影响主链路）：

| 优先级 | 规则 | 归类 |
| --- | --- | --- |
| 1 | 答案为空/时长 < 3s | `CARELESS`（存疑，抽样复核） |
| 2 | 正确答案与用户答案仅形态差异（大小写/单复数/时态词形）且该 KP 的 `common_mistakes` 命中 | `RULE_CONFUSED` |
| 3 | 用户答案为同 KP 下其他难度题的已收录高频错误样本 | `RULE_UNKNOWN` |
| 4 | 用户答案语义通顺但语境不合（AI 判定） | `APPLY_FAIL` |
| 5 | 均未命中 | `null`（不计错误模式） |

错误模式累计 `error_count ≥ 3` 且 `last_error_at` 在 14 天内 → upsert `grammar_error_patterns`（`uk_user_kp_cat` 幂等），`remediation_status=0`，触发矫正推荐（§5.5 裁决 2）。

### 8.1 Outbox 表

```sql

    id              BIGINT PRIMARY KEY AUTO_INCREMENT,

    event_type      VARCHAR(64)  NOT NULL COMMENT '见 8.2',

    UNIQUE KEY uk_event_id (event_id),
    INDEX idx_status_retry (status, next_retry_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='语法模块事件Outbox';
```

事件与业务写入**同事务**插入（本地消息表模式），Relay 轮询投递，指数退避 1m/5m/30m/2h，6 次后转死信并告警（D9）。

## 10. 幂等与并发

| 场景 | 幂等键 | 机制 |
| --- | --- | --- |
| submit 提交 | `(session_id, question_id, client_request_id)` | `grammar_practice_logs` 增列 `client_request_id VARCHAR(64)` + 唯一索引 `uk_session_q_req`；重放返回首次结果（含首次判分），不重复计分 |
| generate 生成题组 | `X-Idempotency-Key`（48h） | 同键重放返回同 session_id；Redis SETNX 先行，PG 对 `idempotency_keys` 表唯一兜底 |
| ai/explain | `X-Idempotency-Key`（48h） | 命中返回缓存的 explanation 记录；流式请求断开重连用 `Last-Event-ID` 续传，超出 60s 窗口整单重生成 |
| diagnose | `X-Idempotency-Key`（24h） | 命中返回首次诊断结果（诊断不落掌握度，幂等仅防重复计费与重复记录） |
| 掌握度更新 | 行级 `SELECT FOR UPDATE` | 单写者（本模块为 user_grammar_mastery 唯一写方，R2/R4） |

DDL 增补：

```sql
ALTER TABLE grammar_practice_logs
    ADD COLUMN client_request_id VARCHAR(64) NULL COMMENT '客户端幂等键' AFTER attempt_number,
    ADD UNIQUE KEY uk_session_q_req (session_id, question_id, client_request_id);

CREATE TABLE grammar_explanations (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL,
    question_id     BIGINT NULL,
    kp_id           BIGINT NULL,
    prompt_version  VARCHAR(32) NOT NULL,
    content_hash    CHAR(64) NOT NULL,
    content_markdown TEXT NOT NULL,
    model           VARCHAR(64) COMMENT '实际出文模型',
    token_usage     JSON,
    safety_status   TINYINT DEFAULT 1 COMMENT '1-通过 2-拦截',
    degraded        TINYINT DEFAULT 0,
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (user_id, created_at),
    INDEX idx_hash (content_hash)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='AI语法讲解记录';
```

并发裁决：
- 多端同时 submit 同题不同 `client_request_id` → 以先到达者为准，后者正常判分但 `attempt_number` 递增；G8 生效后第 4 次起不再更新掌握度；
- 多端同时 generate → G1 活跃会话冲突，返回 59806 并附当前活跃 session_id 供客户端恢复；
- 会话 EXPIRED 与最后 submit 竞态 → **提交优先**，EXPIRED 仅由延迟任务设置且条件为 `updated_at < now-24h AND status=IN_PROGRESS`（CAS），已 COMPLETED 的会话永不回退。

## 11. 降级策略（D1-D10）

| 编号 | 触发 | 降级行为 | 红线 |
| --- | --- | --- | --- |
| D1 | AI 讲解超时/故障 | 静态解析兜底（degraded=true） | 不返回半截生成内容 |
| D2 | 讲解缓存 Redis 故障 | 直查 DB，不重建缓存 | 59830 语义成功 |
| D3 | 目标 KP 题量不足（< count） | 难度 ±1 放宽 + 邻近 KP 同类别补齐，响应带 `degraded=true` 与 `fill_note` | 不出纲（grade_range 硬过滤不可放宽） |
| D4 | 统一掌握度引擎不可达 | 本地照常更新 + Outbox 重投 | 不双写对方表 |
| D5 | diagnose AI 不可达 | 同步规则快检（主谓一致/时态标志词/名词复数 12 条规则）+ 异步补全推送站内信 | 规则快检结果 confidence ≤ 0.8 必须标注 |
| D6 | Redis 全宕 | 会话活跃标记退化 PG 唯一约束 + DB 锁 | 判分主链路可用性优先 |
| D7 | Prompt 新版本异常（错误率 > 5%） | 版本回滚至上一稳定版（Prompt 系统权威执行） | 不回滚已生成内容 |
| D8 | 额度服务故障 | 学习主链路 fail-open（后置补扣）；AI 讲解 fail-closed 排队 30s 重试一次后降级静态解析 | 防沉迷/时长硬顶 fail-secure，**任何降级不得突破** |
| D9 | 事件 MQ 堆积 | Outbox 本地 spool，退避重投 | 事件不丢（本地表持久化） |
| D10 | — | 总红线 | 未成年人保护与防沉迷约束全链路 fail-secure，无降级通道 |

## 13. 合规红线（C1-C8）

- C1 **不超纲**：generate/explain/diagnose 全部以 `grade_range` 硬过滤，深度参数 `deep` 仅对 senior 学段开放；
- C2 **成长型话术**：错因/讲解文案走话术白名单，禁人格否定与羞辱性表述；未答题不判错（G7）；
- C3 **安全拦截不暴露细节**：59811/blocked 帧不带拦截原因与命中词；
- C4 **缓存版本隔离**：讲解缓存按 prompt_version 隔离，防跨版本内容污染；
- C5 **数据留存**：practice_logs 180 天在线后归档；explanations 内容留存 90 天（content_hash 保留 1 年供去重）；
- C6 **不直接给整卷答案**：讲解按题粒度，不得聚合输出整张试卷答案（与答案管控引擎 ACPH 对齐）；
- C7 **PII 最小化**：diagnose 输入仅作即时处理，原始文本不落长期存储（结果表仅存 span 与纠错项，原文 7 天抹除）；
- C8 **家长可见度分级**：家长端仅展示聚合掌握度与错误模式计数，单题作答原文默认 L2 不可见（委托家庭共享可见度引擎）。

## 14. 契约对齐（R1-R10）

- R1 判分权威：本模块只判**语法域题目**（question_type ∈ 1,2,4,6）；题型 3（短文改错）与 5（完形填空）判分归对应专项引擎；
- R2 掌握度 SSOT：`user_grammar_mastery` 为语法域 SSOT，统一掌握度引擎仅消费 `grammar.mastery.updated` 信号，**禁止双写**；
- R3 复习调度：`next_review_at`/`review_interval_days` 写权归间隔重复引擎，本模块只初始化 interval=1；
- R4 AI 链路委托：Prompt/适配层/ARPP/VQ/SOSF 边界见 §6.1，本模块不重复实现；
- R5 错题收录：错题入错题本由错题服务消费事件完成，本模块不直写；
- R6 作文边界：diagnose 限 ≤2000 字符片段，整篇作文归作文批改引擎；
- R7 入口权威：页面导航与入口配置归「英语专项学习」模块，本模块提供能力接口；
- R8 埋点：事件 schema 注册于统一埋点平台，module=`grammar`；
- R9 额度：额度查扣委托统一额度管控引擎，本模块仅消费额度结果；
- R10 学段词汇：`grade_band` 枚举（primary_upper/junior/senior）与分龄 UI 规范对齐。

## 15. 验收场景

1. 按 KP 生成 10 题题组 → 返回 session_id 与题目列表，estimated_minutes 合理；
2. 相同 Idempotency-Key 重复 generate → 返回同一会话；
3. 断网恢复后以 session_id 继续 submit → G1 不冲突，历史已答题不丢；
4. 同题同 client_request_id 重放 submit → 返回首次判分结果，practice_logs 仅 1 行，掌握度只更新 1 次；
5. 同题不同 client_request_id 第 4 次提交 → G8 生效，掌握度不变，attempt_number=4；
6. 答错 now 完成时 vs 一般过去时混淆题 → error_category=RULE_CONFUSED，错误模式 count 累计；
7. 同 KP 同类错误 14 天内 3 次 → grammar_error_patterns 落表且 remediation_status=0，recommend 接口返回该 KP 矫正练习；
8. AI 讲解流式输出中途断连 → Last-Event-ID 60s 内重连续传，seq 无重复无跳号；
9. AI 讲解适配层超时 → 59810 上游记录告警，客户端收到静态解析兜底 degraded=true；
10. 讲解内容触发安全词库 → blocked 帧不带原因，审计落库，缓存条目删除；
11. Prompt 版本升级后旧缓存全部失效（M4 窗口豁免内）；
12. 小学学段请求 deep 深度 → 按 brief 处理（C1）；
13. 会话 24h 未动 → EXPIRED，未答题不计错（G7）；
14. 多端同时 generate → 59806 + 活跃 session_id，客户端可恢复；
15. diagnose 输入 2500 字符 → 59821；输入中文 → 59822；
16. Redis 全宕演练（D6）→ 判分主链路可用，会话冲突改由 DB 约束裁决。
