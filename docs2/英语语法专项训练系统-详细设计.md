# 英语语法专项训练系统 - 详细设计

> 模块定位：面向小学高年级至高中学生，提供英语语法知识体系化学习、专项练习、AI 智能讲解与语法错误诊断的一体化训练系统。
> 优先级：P1（V1.5 阶段上线）
> 依赖模块：题目与题库服务、AI 对话引擎、用户学习画像、知识点体系与教材映射、自适应推荐引擎、间隔重复复习调度

---

## 1. 模块概述

### 1.1 背景

语法是英语学习的骨架。在中考英语中，语法相关题型（完形填空、语法填空、短文改错）合计占比约 25%-35%；高考英语中语法填空和短文改错合计占 20-30 分。当前产品已有词汇记忆、听力模拟、阅读理解专项模块，但缺少系统化的语法专项训练能力。

学生在语法学习中普遍存在的问题：
1. 语法规则零散，缺乏体系化认知
2. 相似语法结构易混淆（如现在完成时 vs 一般过去时）
3. 知道规则但不会在语境中灵活运用
4. 缺少针对性的错因诊断和复习闭环

### 1.2 目标

1. 建立覆盖小学至高中的英语语法知识图谱，按教材章节和考纲考点组织
2. 支持多种语法题型（单选、填空、改错、翻译、语法填空、完形填空）
3. 提供 AI 智能讲解，结合语境分析语法规则的应用逻辑
4. 基于答题数据构建语法掌握度多维度评估模型
5. 生成个性化语法复习计划，与间隔重复引擎联动

### 1.3 覆盖学段

| 学段 | 目标 | 语法重点 | CEFR |
| --- | --- | --- | --- |
| 小学 5-6 年级 | 建立基本语法意识 | be 动词、一般现在时、名词复数、简单句型 | A1-A2 |
| 初中 7-9 年级 | 构建语法体系框架 | 8 大时态、被动语态、从句基础、非谓语入门 | A2-B1 |
| 高中 10-12 年级 | 高考语法全掌握 | 16 大时态、虚拟语气、复杂从句、非谓语动词、倒装 | B1-B2 |

### 1.4 与其他模块的关系

| 关联模块 | 关系 |
| --- | --- |
| 英语专项学习与口语陪练 | 上层入口模块，本系统为其语法子模块的详细展开 |
| 英语词汇记忆与单词本 | 共享词性标注，语法题中的生词可加入单词本 |
| 英语阅读理解专项训练 | 共享长难句解析能力，语法知识为阅读理解基础 |

| 题目与题库服务 | 消费题库的语法题目，生成 AI 语法题 |
| AI 对话引擎 | 调用 Prompt 编排生成语法讲解和例句 |
| 间隔重复复习调度 | 语法错题推送至复习引擎，按遗忘曲线调度 |

| 用户学习画像 | 输出语法掌握度数据，消费学段年级信息 |

### 2.2 知识点关联关系

语法知识点之间存在多种关联类型：

```text
PREREQUISITE  (前置依赖): 一般现在时 → 现在进行时
CONTRAST      (易混对比): 现在完成时 ↔ 一般过去时
EXTENSION     (进阶扩展): 简单句 → 并列句 → 复合句
APPLICATION   (应用关联): 被动语态 → 时态(组合运用)
PARENT_CHILD  (父子层级): 时态 → 一般现在时
```

### 3.2 用户旅程

```text
[入口] → 首页英语卡片 → 语法专项 / 学习规划推送 / 错题复习入口
    ↓
[知识图谱] → 浏览或搜索语法知识点 → 查看掌握度色块
    ↓
[知识点精讲] → 规则讲解 → 典型例句 → 易错提醒 → 记忆技巧
    ↓
[专项练习] → 选择题型和知识点 → 逐题作答
    ↓                                  ↓
[答对] → 巩固下一题              [答错] → AI 语法讲解
                                       ↓
                               [错误归因] → 标记错因类型
                                       ↓
                               [错题收录] → 加入错题本
                                       ↓
                               [关联知识点] → 推荐相关知识点复习
    ↓
[练习完成] → 正确率统计 → 掌握度更新 → 推荐下一步
```

## 4. 数据模型设计

### 4.1 语法知识点表 `grammar_knowledge_points`

```sql
CREATE TABLE grammar_knowledge_points (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    code                VARCHAR(50) NOT NULL UNIQUE COMMENT '知识点编码: GRAM-TENSE-001',
    name                VARCHAR(100) NOT NULL COMMENT '知识点名称: 一般现在时',
    category            VARCHAR(50) NOT NULL COMMENT '一级分类: 词法/时态/语态/句法/非谓语/特殊句式',
    sub_category        VARCHAR(50) COMMENT '二级分类: 时态 > 过去时态',
    parent_id           BIGINT COMMENT '父知识点ID',
    level               TINYINT NOT NULL COMMENT '层级深度: 1-5',
    path                VARCHAR(500) COMMENT '层级路径: 英语语法,时态,一般现在时',
    sort_order          INT DEFAULT 0 COMMENT '同级排序',

    -- 内容字段
    summary             TEXT COMMENT '一句话概述',
    explanation         TEXT NOT NULL COMMENT '详细规则讲解 (Markdown)',
    key_rules           JSON COMMENT '核心规则列表: ["主语+V(s/es)","时间标志词: always/usually"]',
    examples            JSON NOT NULL COMMENT '例句数组: [{"en":"...","zh":"...","highlight":"..."}]',
    common_mistakes     JSON COMMENT '易错点: [{"mistake":"...","correct":"...","explain":"..."}]',
    memory_tips         JSON COMMENT '记忆口诀/技巧',
    contrast_with       JSON COMMENT '易混对比知识点ID列表及对比说明',

    -- 适用范围
    grade_range         JSON NOT NULL COMMENT '适用学段: ["primary5","primary6","junior1",...]',
    cefr_level          VARCHAR(10) COMMENT '对应CEFR等级',
    exam_weight         JSON COMMENT '考试权重: {"mid_exam":0.3,"college_exam":0.2}',

    -- 关联
    prerequisite_ids    JSON COMMENT '前置知识点ID列表',
    related_point_ids   JSON COMMENT '关联知识点ID列表',

    status              TINYINT DEFAULT 1 COMMENT '1-有效 0-禁用',
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_category (category),
    INDEX idx_parent (parent_id),
    INDEX idx_grade (grade_range(100)),
    INDEX idx_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='英语语法知识点';
```

### 4.2 语法练习题目表 `grammar_questions`

```sql
CREATE TABLE grammar_questions (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    knowledge_point_id  BIGINT NOT NULL COMMENT '关联知识点ID',
    question_type       TINYINT NOT NULL COMMENT '题型: 1=单选 2=语法填空 3=短文改错 4=翻译 5=完形填空 6=判断正误',
    difficulty          TINYINT NOT NULL COMMENT '难度: 1-5',
    source_type         TINYINT COMMENT '来源: 1=真题 2=模拟题 3=AI生成 4=人工编写',
    source_year         SMALLINT COMMENT '真题年份',
    source_region       VARCHAR(50) COMMENT '真题地区',

    -- 题目内容
    stem                TEXT NOT NULL COMMENT '题干',
    context_passage     TEXT COMMENT '上下文语篇（语法填空/改错/完形用）',
    blank_positions     JSON COMMENT '填空位置: [{"index":5,"answer":"has_been","alternatives":...}]',
    options             JSON COMMENT '选项: [{"label":"A","content":"..."},{"label":"B",...}]',
    correct_answer      VARCHAR(200) NOT NULL COMMENT '正确答案',
    answer_explanation  TEXT COMMENT '答案解析',
    grammar_analysis    TEXT COMMENT '语法分析（AI生成）',

    -- 标注
    error_type          VARCHAR(50) COMMENT '改错题的错误类型标签',
    tags                JSON COMMENT '标签: ["中考高频","易错","主谓一致"]',

    status              TINYINT DEFAULT 1 COMMENT '1-有效 0-禁用',
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_kp (knowledge_point_id),
    INDEX idx_type_diff (question_type, difficulty),
    INDEX idx_source (source_type, source_year)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='语法练习题目';
```

```

### 5.2 语法练习接口

**请求：**
```json
{
  "knowledge_point_ids": [101, 102],  // 知识点（可选，不传则系统推荐）

### 5.3 AI 语法讲解接口

#### POST `/api/v1/grammar/ai/explain

请求 AI 对某题/某语法点进行详细讲解。

**请求：**
```json
{
  "question_id": 2001,                // 题目ID（与kp_id二选一）

  "include_contrast": true            // 是否包含易混对比
