# 服务端-统一兑换码与激活码生命周期管理引擎-详细设计

## 1. 概述

### 1.1 模块定位

统一兑换码与激活码生命周期管理引擎是 PrimeTop 平台的通用基础服务之一，负责管理各类预付费兑换码、激活码、礼品码的生成、分发、核销与生命周期追踪。该模块为平台提供灵活的离线渠道变现能力，支持通过书店、学校、代理商、线上活动等渠道发放码品，用户在 APP 内兑换后获取对应权益（会员、积分、内容解锁、增值服务等）。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 高并发兑换 | 支持高峰期（如开学季、促销活动）每秒 1000+ 笔兑换请求 |
| 防欺诈 | 多维度风控，防止刷码、撞码、批量恶意兑换 |
| 多类型支持 | 会员激活码、积分充值码、内容解锁码、增值服务码、通用礼品码 |
| 批量管理 | 支持百万级码品批量生成、导入、导出、状态追踪 |
| 可追溯 | 全链路审计，从生成到核销每个环节可查 |
| 高可用 | 兑换服务 99.95% 可用性，核心流程支持降级 |

### 1.3 适用范围

- 会员订阅激活码（月卡、季卡、年卡等）
- 积分充值码（固定面值积分包）
- 内容/课程解锁码（特定教材、专题课程访问权限）
- 增值服务码（作文批改包、AI 高级功能体验券等）
- 活动礼品码（营销活动赠品、合作方引流码）
- 家庭套装激活码（多孩共享会员激活）

## 4. 兑换码生成算法

### 4.1 码格式设计

```
格式：[前缀][段1]-[段2]-[段3]-[校验位]

示例：PT 7K3M-A9BX-2QF4-5

组成部分：
- 前缀（2字符）：PT = PrimeTop，标识平台
- 段1（4字符）：随机字符
- 段2（4字符）：随机字符  
- 段3（4字符）：随机字符
- 校验位（1字符）：Luhn变体校验

字符集：23456789ABCDEFGHJKLMNPQRSTUVWXYZ（去除易混淆字符 0/O/1/I/l）
总长度：15字符（含分隔符）
组合空间：32^12 ≈ 7.3×10^17，足够使用
```

### 4.2 生成核心逻辑

```java
@Service
public class CodeGenerationService {

    private static final char[] CHARSET = "23456789ABCDEFGHJKLMNPQRSTUVWXYZ".toCharArray();
    private static final int CHARSET_SIZE = CHARSET.length; // 32
    private static final int SEGMENT_LENGTH = 4;
    private static final String PREFIX = "PT";

    /**
     * 批量生成兑换码
     * @param batchId 批次ID
     * @param count 生成数量
     * @param validityPeriod 有效期配置
     * @return 生成的码列表
     */
    @Async("codeGenerationExecutor")
    public void generateCodesAsync(String batchId, int count, ValidityPeriod validityPeriod) {
        // 1. 更新批次状态为生成中
        batchRepository.updateStatus(batchId, BatchStatus.GENERATING);
        
        // 2. 分批生成，每批 5000 条
        int batchSize = 5000;
        int batches = (count + batchSize - 1) / batchSize;
        LocalDateTime expiredAt = calculateExpiredAt(validityPeriod);
        
        for (int i = 0; i < batches; i++) {
            int currentBatchSize = Math.min(batchSize, count - i * batchSize);
            List<RedemptionCode> codes = new ArrayList<>(currentBatchSize);
            
            for (int j = 0; j < currentBatchSize; j++) {
                String rawCode = generateSingleCode();
                String codeHash = sha256(rawCode);
                String maskedCode = maskCode(rawCode);
                
                RedemptionCode code = RedemptionCode.builder()
                    .codeId(IdGenerator.nextId())
                    .batchId(batchId)
                    .codeHash(codeHash)
                    .codeMasked(maskedCode)
                    .status(CodeStatus.GENERATED)
                    .expiredAt(expiredAt)
                    .createdAt(LocalDateTime.now())
                    .build();
                codes.add(code);
                
                // 将明文码存入临时存储（Redis），供后续导出
                codePlainTextStore.store(codeHash, rawCode, Duration.ofHours(24));
            }
            
            // 批量插入
            codeRepository.batchInsert(codes);
            
            // 更新批次进度
            batchRepository.incrementGeneratedCount(batchId, currentBatchSize);
        }
        
        // 3. 更新批次状态为生效
        batchRepository.updateStatus(batchId, BatchStatus.ACTIVE);
        
        // 4. 记录审计日志
        auditLogService.logGeneration(batchId, count);
    }

    /**
     * 生成单个兑换码
     */
    private String generateSingleCode() {
        StringBuilder sb = new StringBuilder(PREFIX);
        
        for (int seg = 0; seg < 3; seg++) {
            sb.append('-');
            for (int i = 0; i < SEGMENT_LENGTH; i++) {
                sb.append(CHARSET[ThreadLocalRandom.current().nextInt(CHARSET_SIZE)]);
            }
        }
        
        // 计算校验位
        char checksum = calculateChecksum(sb.toString());
        sb.append('-').append(checksum);
        
        return sb.toString();
    }

    /**
     * Luhn变体校验位算法
     */
    private char calculateChecksum(String input) {
        int sum = 0;
        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (c == '-') continue;
            int index = new String(CHARSET).indexOf(c);
            if (index < 0) continue;
            // 奇数位权重2，偶数位权重1
            int weight = (i % 2 == 0) ? 2 : 1;
            sum += index * weight;
        }
        return CHARSET[sum % CHARSET_SIZE];
    }

    /**
     * 脱敏处理：保留前2位和后2位
     */
    private String maskCode(String rawCode) {
        // 去除分隔符后取前2后2
        String compact = rawCode.replace("-", "");
        return compact.substring(0, 2) + "****" + compact.substring(compact.length() - 2);
    }

    private String sha256(String input) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            byte[] hash = digest.digest(input.toUpperCase().getBytes(StandardCharsets.UTF_8));
            return HexFormat.of().formatHex(hash);
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException("SHA-256 not available", e);
        }
    }
}
```

### 4.3 码明文安全存储

兑换码明文仅在生成时短暂存在，导出后即清除：

```
明文生命周期：
1. 生成 → 暂存 Redis（TTL 24h，key: code:plaintext:{codeHash}）
2. 导出 → 写入临时文件（加密），生成下载链接
3. 下载 → 用户下载后，Redis 中的明文标记为已导出
4. 清除 → 24h 后或确认下载后自动删除 Redis 明文
5. 长期存储 → 仅存储 SHA-256 哈希，不可逆
```

## 5. 兑换流程详细设计

### 5.1 状态流转图

```
                    ┌──────────────┐
                    │  GENERATED   │ ← 初始状态
                    │   (已生成)    │
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │ DISTRIBUTED  │ ← 分配给渠道（可选）
                    │   (已分发)    │
                    └──────┬───────┘
                           │ 用户输入兑换码
                    ┌──────▼───────┐
                    │   LOCKED     │ ← 乐观锁中间态（3分钟超时）
                    │   (兑换中)    │
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
       ┌──────▼─────┐ ┌───▼────┐ ┌────▼─────┐
       │  REDEEMED  │ │FROZEN  │ │  错误    │
       │  (已兑换)   │ │(已冻结) │ │  回退    │
       └────────────┘ └───┬────┘ └────┬─────┘
                           │          │
                    ┌──────▼──────┐   │ 回到 GENERATED
                    │ 管理员解冻   │   │ 或 DISTRIBUTED
                    └─────────────┘   │
               
    超时/过期:    GENERATED/DISTRIBUTED → EXPIRED
    管理员作废:   任意非REDEEMED状态 → REVOKED
```

### 5.2 兑换核心流程

```java
@Service
@Slf4j
public class RedemptionService {

    @Autowired private RedemptionCodeRepository codeRepository;
    @Autowired private RedemptionBatchRepository batchRepository;
    @Autowired private BenefitGrantService benefitGrantService;
    @Autowired private RedemptionRiskService riskService;
    @Autowired private RedemptionAuditService auditService;
    @Autowired private RedissonClient redisson;

    private static final String LOCK_PREFIX = "lock:redeem:";
    private static final String RATE_LIMIT_PREFIX = "rate:redeem:";
    private static final Duration LOCK_TIMEOUT = Duration.ofMinutes(3);

    /**
     * 兑换码兑换核心方法
     */
    @Transactional(isolation = Isolation.READ_COMMITTED)
    public RedemptionResult redeem(String rawCode, Long userId, RedeemContext context) {
        String normalizedCode = rawCode.trim().toUpperCase();
        String codeHash = sha256(normalizedCode);

        // Step 1: 频率限制（防暴力撞码）
        riskService.checkRateLimit(userId, context.getIp(), context.getDeviceFingerprint());

        // Step 2: 分布式锁（防并发兑换同一码）
        RLock lock = redisson.getLock(LOCK_PREFIX + codeHash);
        boolean locked = false;
        try {
            locked = lock.tryLock(0, LOCK_TIMEOUT.toSeconds(), TimeUnit.SECONDS);
            if (!locked) {
                throw new BusinessException(ErrorCode.CODE_BEING_REDEEMED, 
                    "该兑换码正在处理中，请稍后再试");
            }

            // Step 3: 查询码记录
            RedemptionCode code = codeRepository.findByCodeHash(codeHash)
                .orElseThrow(() -> new BusinessException(ErrorCode.CODE_NOT_FOUND, 
                    "兑换码不存在，请检查后重新输入"));

            // Step 4: 状态校验
            validateCodeStatus(code);

            // Step 5: 批次状态校验
            RedemptionBatch batch = batchRepository.findByBatchId(code.getBatchId())
                .orElseThrow(() -> new BusinessException(ErrorCode.BATCH_NOT_FOUND));
            validateBatchStatus(batch);

            // Step 6: 风控校验
            riskService.validateRedemption(code, batch, userId, context);

            // Step 7: 锁定码状态（乐观锁中间态）
            int updated = codeRepository.updateStatusWithOptimisticLock(
                code.getCodeId(), 
                code.getStatus(),      // expected: GENERATED or DISTRIBUTED
                CodeStatus.LOCKED,
                LocalDateTime.now().plusMinutes(LOCK_TIMEOUT.toMinutes())
            );
            if (updated == 0) {
                throw new BusinessException(ErrorCode.CODE_STATUS_CHANGED, 
                    "兑换码状态已变更，请重试");
            }

            // Step 8: 发放权益
            RedemptionGrantResult grantResult;
            try {
                grantResult = benefitGrantService.grantBenefits(
                    batch.getBenefitConfig(), 
                    userId, 
                    code.getCodeId(),
                    context
                );
            } catch (Exception e) {
                // 权益发放失败，回滚码状态
                codeRepository.updateStatus(code.getCodeId(), 
                    CodeStatus.GENERATED, null);
                log.error("权益发放失败，回滚码状态, codeId={}", code.getCodeId(), e);
                throw new BusinessException(ErrorCode.BENEFIT_GRANT_FAILED, 
                    "权益发放失败，请稍后重试或联系客服");
            }

            // Step 9: 更新码状态为已兑换
            codeRepository.updateRedeemSuccess(
                code.getCodeId(),
                CodeStatus.REDEEMED,
                userId,
                LocalDateTime.now(),
                context.getIp(),
                context.getDeviceFingerprint(),
                context.getUserAgent()
            );

            // Step 10: 更新批次统计
            batchRepository.incrementRedeemedCount(batch.getBatchId());

            // Step 11: 审计日志
            auditService.logRedemption(code, batch, userId, context);

            // Step 12: 返回结果
            return RedemptionResult.success(
                code.getCodeId(),
                batch.getCodeType(),
                grantResult
            );

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new BusinessException(ErrorCode.REDEEM_INTERRUPTED);
        } finally {
            if (locked && lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    private void validateCodeStatus(RedemptionCode code) {
        switch (code.getStatus()) {
            case GENERATED:
            case DISTRIBUTED:
                // 正常可兑换状态
                break;
            case LOCKED:
                // 检查是否超时
                if (code.getExpiredAt() != null && 
                    code.getExpiredAt().isAfter(LocalDateTime.now())) {
                    throw new BusinessException(ErrorCode.CODE_BEING_REDEEMED);
                }
                break;
            case REDEEMED:
                throw new BusinessException(ErrorCode.CODE_ALREADY_REDEEMED, 
                    "该兑换码已被使用");
            case EXPIRED:
                throw new BusinessException(ErrorCode.CODE_EXPIRED, 
                    "该兑换码已过期");
            case REVOKED:
                throw new BusinessException(ErrorCode.CODE_REVOKED, 
                    "该兑换码已作废");
            case FROZEN:
                throw new BusinessException(ErrorCode.CODE_FROZEN, 
                    "该兑换码已被冻结，请联系客服");
            default:
                throw new BusinessException(ErrorCode.CODE_INVALID_STATUS);
        }
    }
}
```

```java
                    break;

            record.setGrantStatus(GrantStatus.SUCCESS);
            record.setCompletedAt(LocalDateTime.now());
            grantRecordRepository.updateById(record);

            return RedemptionGrantResult.success(grantId, detail);

        } catch (Exception e) {

            record.setGrantStatus(GrantStatus.FAILED);
            record.setErrorDetail(e.getMessage());
            record.setCompletedAt(LocalDateTime.now());
            grantRecordRepository.updateById(record);
            throw e;
        }
    }

    private GrantResultDetail grantMembership(BenefitConfig config,

            config.getPointsAmount(),

        ContentGrantResult result = contentAccessService.unlockByRedemptionCode(
            userId, contentIds, grantId);

                // 标记为部分成功
            }
        }
        return GrantResultDetail.composite(details);
    }
```

### 7.3 风控校验实现

```java
@Service
@Slf4j
public class RedemptionRiskService {

    @Autowired private StringRedisTemplate redis;
    @Autowired private RiskConfigRepository riskConfigRepository;

    private static final String RATE_USER = "rate:redeem:user:";
    private static final String RATE_IP = "rate:redeem:ip:";
    private static final String RATE_DEVICE = "rate:redeem:device:";
    private static final String FAIL_COUNT = "fail:redeem:";

    /**
     * 频率限制检查（滑动窗口）
     */
    public void checkRateLimit(Long userId, String ip, String deviceFp) {
        RiskConfig config = getActiveRiskConfig();

        // 用户维度
        checkSlidingWindow(RATE_USER + userId, 
            Duration.ofMinutes(5), config.getMaxRedeemPerIp());

        // IP维度
        checkSlidingWindow(RATE_IP + ip, 
            Duration.ofMinutes(10), 10);

        // 设备维度
        if (StringUtils.isNotBlank(deviceFp)) {
            checkSlidingWindow(RATE_DEVICE + deviceFp, 
                Duration.ofMinutes(10), 5);
        }
    }

    /**
     * 滑动窗口频率检查
     */
    private void checkSlidingWindow(String key, Duration window, int maxCount) {
        long now = System.currentTimeMillis();
        long windowStart = now - window.toMillis();

        // 使用 Redis ZSET 实现滑动窗口
        redis.opsForZSet().removeRangeByScore(key, 0, windowStart);
        Long count = redis.opsForZSet().zCard(key);
        
        if (count != null && count >= maxCount) {
            throw new BusinessException(ErrorCode.RATE_LIMIT_EXCEEDED,
                String.format("操作过于频繁，请在%d分钟后再试", window.toMinutes()));
        }
        
        redis.opsForZSet().add(key, String.valueOf(now), now);
        redis.expire(key, window);
    }

    /**
     * 兑换行为校验
     */
    public void validateRedemption(RedemptionCode code, RedemptionBatch batch,
            Long userId, RedeemContext context) {
        RiskConfig config = batch.getRiskConfig();

        // 1. 同批次同用户兑换次数限制
        int userRedeemCount = codeRepository.countByBatchAndUser(
            batch.getBatchId(), userId);
        if (userRedeemCount >= config.getMaxRedeemPerUser()) {
            log.warn("用户{}在批次{}中已兑换{}次，超过限制", 
                userId, batch.getBatchId(), userRedeemCount);
            throw new BusinessException(ErrorCode.USER_REDEEM_LIMIT_EXCEEDED);
        }

        // 2. IP限制
        int ipRedeemCount = codeRepository.countByBatchAndIp(
            batch.getBatchId(), context.getIp());
        if (ipRedeemCount >= config.getMaxRedeemPerIp()) {
            log.warn("IP{}在批次{}中已兑换{}次", 
                context.getIp(), batch.getBatchId(), ipRedeemCount);
            throw new BusinessException(ErrorCode.IP_REDEEM_LIMIT_EXCEEDED);
        }

        // 3. 设备限制
        if (config.isDeviceFingerprintRequired() && 
            StringUtils.isNotBlank(context.getDeviceFingerprint())) {
            int deviceRedeemCount = codeRepository.countByBatchAndDevice(
                batch.getBatchId(), context.getDeviceFingerprint());
            if (deviceRedeemCount >= config.getMaxRedeemPerDevice()) {
                throw new BusinessException(ErrorCode.DEVICE_REDEEM_LIMIT_EXCEEDED);
            }
        }

        // 4. IP黑名单检查
        if (config.isIpBlacklistEnabled()) {
            if (riskBlacklistService.isIpBlacklisted(context.getIp())) {
                throw new BusinessException(ErrorCode.IP_BLACKLISTED);
            }
        }

        // 5. 异常行为检测
        detectAbnormalBehavior(code, batch, userId, context);
    }

    /**
     * 异常行为检测
     */
    private void detectAbnormalBehavior(RedemptionCode code, RedemptionBatch batch,
            Long userId, RedeemContext context) {
        // 连续失败检测
        String failKey = FAIL_COUNT + userId;
        String failCount = redis.opsForValue().get(failKey);
        if (failCount != null && Integer.parseInt(failCount) >= 5) {
            // 触发安全告警
            securityAlertService.alert(AbnormalRedeemAttempt.builder()
                .userId(userId)
                .ip(context.getIp())
                .deviceFp(context.getDeviceFingerprint())
                .failCount(Integer.parseInt(failCount))
                .batchId(batch.getBatchId())
                .build());
            
            // 临时冻结用户兑换功能 30 分钟
            redis.opsForValue().set("freeze:redeem:" + userId, "1", 
                Duration.ofMinutes(30));
            throw new BusinessException(ErrorCode.ABNORMAL_BEHAVIOR_DETECTED,
                "检测到异常兑换行为，账户已被临时冻结30分钟");
        }
    }
}
```

## 8. 过期处理与定时任务

### 8.1 定时任务设计

```java
@Component
@Slf4j
public class RedemptionScheduledTask {

    /**
     * 任务1：码过期处理（每小时执行）
     * 将超过有效期但仍为 GENERATED/DISTRIBUTED 状态的码标记为 EXPIRED
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void expireCodes() {
        int pageSize = 1000;
        int offset = 0;
        int totalExpired = 0;
        
        do {
            List<RedemptionCode> codes = codeRepository
                .findExpirableCodes(LocalDateTime.now(), offset, pageSize);
            
            if (codes.isEmpty()) break;
            
            List<String> codeIds = codes.stream()
                .map(RedemptionCode::getCodeId)
                .collect(Collectors.toList());
            
            int updated = codeRepository.batchUpdateStatus(
                codeIds, CodeStatus.EXPIRED);
            
            // 更新批次过期计数
            Map<String, Long> batchCounts = codes.stream()
                .collect(Collectors.groupingBy(
                    RedemptionCode::getBatchId, Collectors.counting()));
            batchCounts.forEach(batchRepository::incrementExpiredCount);
            
            totalExpired += updated;
            offset += pageSize;
            
        } while (true);
        
        if (totalExpired > 0) {
            log.info("码过期处理完成，共处理{}条", totalExpired);
        }
    }

    /**
     * 任务2：锁定超时恢复（每5分钟执行）
     * 将 LOCKED 状态超过3分钟的码恢复为原状态
     */
    @Scheduled(cron = "0 */5 * * * ?")
    public void recoverLockedCodes() {
        LocalDateTime timeoutThreshold = LocalDateTime.now().minusMinutes(3);
        List<RedemptionCode> lockedCodes = codeRepository
            .findByStatusAndUpdateTimeBefore(CodeStatus.LOCKED, timeoutThreshold);
        
        for (RedemptionCode code : lockedCodes) {
            // 恢复为生成状态
            codeRepository.updateStatus(code.getCodeId(), 
                CodeStatus.GENERATED, null);
            log.warn("恢复超时锁定码: {}", code.getCodeId());
        }
    }

    /**
     * 任务3：批次状态自动更新（每天凌晨执行）
     * 检查批次是否已用尽或已全部过期
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void updateBatchStatus() {
        List<RedemptionBatch> activeBatches = batchRepository
            .findByStatus(BatchStatus.ACTIVE);
        
        for (RedemptionBatch batch : activeBatches) {
            int totalDisposed = batch.getRedeemedCount() + 
                batch.getExpiredCount() + batch.getRevokedCount();
            
            if (totalDisposed >= batch.getTotalCount()) {
                batch.setStatus(BatchStatus.EXHAUSTED);
                batchRepository.updateById(batch);
                log.info("批次{}已用尽", batch.getBatchId());
            }
        }
    }

    /**
     * 任务4：权益发放补偿（每10分钟执行）
     * 检查发放失败的记录并重试
     */
    @Scheduled(cron = "0 */10 * * * ?")
    public void retryFailedGrants() {
        List<RedemptionGrantRecord> failedRecords = grantRecordRepository
            .findByGrantStatusAndCreatedAtAfter(
                GrantStatus.FAILED,
                LocalDateTime.now().minusHours(24)
            );
        
        for (RedemptionGrantRecord record : failedRecords) {
            if (record.getRetryCount() >= 3) {
                // 超过重试次数，标记为需要人工处理
                record.setGrantStatus(GrantStatus.MANUAL_REQUIRED);
                grantRecordRepository.updateById(record);
                
                // 通知运营
                notificationService.notifyOpsTeam(record);
                continue;
            }
            
            // 异步重试
            compensationService.retryGrant(record);
        }
    }
}
```

## 10. 性能优化

### 10.1 兑换热点优化

```yaml
兑换流程性能目标:
  单笔兑换延迟: < 200ms (P99)
  批量查询延迟: < 500ms
  高峰期QPS: 1000+

优化策略:
  1. Redis 缓存:
     - code_hash → code_id 映射缓存（TTL 与码有效期一致）
     - batch 配置信息缓存
     - 用户风控计数（滑动窗口）
  
  2. 数据库优化:
     - code_hash 使用 SHA-256 固定长度(64字符)，建唯一索引
     - batch_id 冗余到 code 表，避免 JOIN
     - 读写分离：兑换走主库，查询走从库
  
  3. 异步化:
     - 批次生成异步执行
     - 权益发放使用本地消息表 + 补偿机制
     - 审计日志异步写入
     - 统计计数使用 Redis INCR + 定时同步 DB
  
  4. 分库分表（远期）:
     - code 表按 batch_id 取模分表
     - 超大规模批次（百万+）按段分库
```

### 10.2 缓存策略

```java
@Service
public class CodeCacheService {

    @Autowired private StringRedisTemplate redis;

    private static final String CODE_HASH_CACHE = "code:hash:";
    private static final String BATCH_CACHE = "batch:config:";
    private static final Duration CODE_CACHE_TTL = Duration.ofDays(1);
    private static final Duration BATCH_CACHE_TTL = Duration.ofHours(1);

    /**
     * 获取码信息（带缓存）
     * 缓存空值防止缓存穿透
     */
    public Optional<RedemptionCode> getCodeByHash(String codeHash) {
        String cacheKey = CODE_HASH_CACHE + codeHash;
        String cached = redis.opsForValue().get(cacheKey);
        
        if (cached != null) {
            if ("NULL".equals(cached)) {
                return Optional.empty(); // 防穿透空值
            }
            return Optional.of(JsonUtils.fromJson(cached, RedemptionCode.class));
        }
        
        // 回源查询
        Optional<RedemptionCode> code = codeRepository.findByCodeHash(codeHash);
        
        if (code.isPresent()) {
            // 仅缓存未兑换的码
            if (code.get().getStatus() != CodeStatus.REDEEMED) {
                redis.opsForValue().set(cacheKey, 
                    JsonUtils.toJson(code.get()), CODE_CACHE_TTL);
            }
        } else {
            // 缓存空值，短TTL防穿透
            redis.opsForValue().set(cacheKey, "NULL", Duration.ofMinutes(5));
        }
        
        return code;
    }

    /**
     * 兑换成功后失效缓存
     */
    public void evictCodeCache(String codeHash) {
        redis.delete(CODE_HASH_CACHE + codeHash);
    }

    /**
     * 批次配置缓存
     */
    public RedemptionBatch getBatchConfig(String batchId) {
        String cacheKey = BATCH_CACHE + batchId;
        String cached = redis.opsForValue().get(cacheKey);
        
        if (cached != null) {
            return JsonUtils.fromJson(cached, RedemptionBatch.class);
        }
        
        RedemptionBatch batch = batchRepository.findByBatchId(batchId)
            .orElseThrow(() -> new BusinessException(ErrorCode.BATCH_NOT_FOUND));
        
        redis.opsForValue().set(cacheKey, JsonUtils.toJson(batch), BATCH_CACHE_TTL);
        return batch;
    }
}
```

## 12. 安全设计

### 12.1 码品安全

| 安全措施 | 说明 |
| --- | --- |
| 哈希存储 | 码明文仅在生成时和导出时存在，数据库仅存 SHA-256 哈希 |
| 传输加密 | 兑换请求使用 HTTPS，码值在请求体中传输（非URL参数） |
| 防暴力枚举 | 频率限制 + 连续失败冻结 + IP 封禁 |
| 校验位验证 | 生成时加入 Luhn 变体校验位，快速过滤无效格式 |
| 分布式锁 | 兑换时对同一码加分布式锁，防止并发兑换 |
| 乐观锁 | 码状态更新使用 CAS（Compare-And-Swap）机制 |
| 导出加密 | 批量导出文件使用 AES-256 加密，下载链接时效 30 分钟 |
| 审计全链路 | 从创建到兑换每个操作记录审计日志 |

### 12.2 导出文件安全

```java
@Service
public class CodeExportService {

    /**
     * 加密导出兑换码
     */
    public ExportTaskResult exportEncryptedCodes(String batchId, String operatorId) {
        // 1. 权限校验
        permissionService.checkExportPermission(operatorId);
        
        // 2. 创建导出任务
        ExportTask task = exportTaskRepository.create(ExportTask.builder()
            .taskId(IdGenerator.nextId())
            .batchId(batchId)
            .operatorId(operatorId)
            .status(ExportStatus.PROCESSING)
            .createdAt(LocalDateTime.now())
            .build());
        
        // 3. 异步执行导出
        CompletableFuture.runAsync(() -> {
            try {
                List<RedemptionCode> codes = codeRepository.findByBatchId(batchId);
                
                // 生成 CSV 内容
                StringBuilder csv = new StringBuilder();
                csv.append("序号,兑换码,状态,生成时间,过期时间\n");
                
                for (RedemptionCode code : codes) {
                    // 从临时存储获取明文
                    String plainCode = codePlainTextStore.get(code.getCodeHash());
                    if (plainCode == null) {
                        // 明文已过期，跳过
                        continue;
                    }
                    csv.append(String.format("%d,%s,%s,%s,%s\n",
                        codes.indexOf(code) + 1,
                        plainCode,
                        code.getStatus(),
                        code.getCreatedAt(),
                        code.getExpiredAt()
                    ));
                }
                
                // AES-256 加密
                String encryptedContent = encrypt(csv.toString(), 
                    exportConfig.getEncryptionKey());
                
                // 上传到 OSS
                String fileKey = String.format("exports/redemption/%s/%s.enc",
                    batchId, task.getTaskId());
                String downloadUrl = ossService.uploadEncrypted(
                    fileKey, encryptedContent.getBytes(StandardCharsets.UTF_8));
                
                // 更新任务状态
                task.setStatus(ExportStatus.COMPLETED);
                task.setDownloadUrl(downloadUrl);
                task.setExpiredAt(LocalDateTime.now().plusMinutes(30));
                task.setCompletedAt(LocalDateTime.now());
                exportTaskRepository.updateById(task);
                
                // 清除 Redis 中的明文
                for (RedemptionCode code : codes) {
                    codePlainTextStore.delete(code.getCodeHash());
                }
                
                // 审计日志
                auditService.log(ExportAction.builder()
                    .batchId(batchId)
                    .operatorId(operatorId)
                    .codeCount(codes.size())
                    .build());
                
            } catch (Exception e) {
                task.setStatus(ExportStatus.FAILED);
                task.setErrorDetail(e.getMessage());
                exportTaskRepository.updateById(task);
                log.error("导出失败, taskId={}", task.getTaskId(), e);
            }
        }, exportExecutor);
        
        return ExportTaskResult.of(task);
    }
}
```

## 14. 降级与容灾策略

| 故障场景 | 降级策略 |
| --- | --- |
| Redis 不可用 | 频率限制降级为 DB 计数（限流阈值降低 50%）；缓存穿透到 DB |
| 会员服务不可用 | 兑换请求返回"系统繁忙"，码状态回滚；设置重试队列，3次后通知客服 |
| 积分服务不可用 | 同上，权益发放标记为 PENDING，异步补偿 |
| 主库不可用 | 切换只读模式，拒绝兑换请求，返回友好提示；写请求排队 |
| 权益发放部分成功 | 记录 PARTIAL 状态，补偿任务自动重试失败部分 |
| 批量生成任务失败 | 支持断点续传，从已生成位置继续 |
| 导出任务超时 | 任务超时自动标记为 FAILED，支持重试 |
