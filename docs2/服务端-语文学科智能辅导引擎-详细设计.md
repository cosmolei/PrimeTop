# 服务端-语文学科智能辅导引擎 详细设计

## 1. 概述

### 1.1 模块定位

语文学科智能辅导引擎是 PrimeTop 全学科智能辅导体系的核心子引擎之一，负责统筹协调语文学科从启蒙到高考全学段的智能辅导能力。与其他学科辅导引擎（数学、英语、物理等）平行，但在内部架构上更为复杂——因为语文学科的能力维度最为多元，涵盖识字写字、阅读理解、古诗文鉴赏、文言文翻译、写作表达、口语交际、听写默写等多个子领域。

本引擎作为**统一调度入口和编排层**，将各子领域的能力聚合为一体化的语文学习体验，而非替代各子领域已有的独立服务（如古诗文鉴赏解析服务、作文批改评分引擎、中文朗读能力评估等）。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| **统一辅导入口** | 接收学生语文学习请求，智能识别子领域并路由至对应子模块 |
| **能力综合评估** | 跨子领域聚合学生语文能力数据，形成语文学科综合能力画像 |
| **学习内容编排** | 根据学段、教材版本、学习进度编排个性化语文学习路径 |
| **知识点关联推理** | 建立语文知识点网络，实现跨子领域知识关联与迁移推荐 |
| **Prompt 统一管理** | 为语文辅导场景维护分学段、分子领域的 Prompt 模板体系 |
| **辅导质量保障** | 对语文 AI 辅导输出的准确性、适龄性、启发性进行质量校验 |

### 1.3 依赖关系

```
语文学科智能辅导引擎
├── 依赖的上游服务
│   ├── 用户服务（学生学段、年级、教材版本、学习目标）

│   ├── AI 模型服务（大模型调用、Prompt 编排）
│   ├── RAG 检索服务（语文知识库检索增强）
│   └── 会员权益服务（功能权限、调用额度校验）

    └── 推荐系统（语文内容推荐信号）
```

### 1.4 设计原则

1. **子领域自治、引擎统筹**：各子领域服务保持独立可用，引擎层负责调度编排，避免紧耦合。
2. **分学段差异化**：同一辅导能力在不同学段（幼儿/小学/初中/高中）下有显著差异，引擎层统一管理学段适配策略。
3. **启发优于给答案**：语文辅导强调思维引导和素养培养，默认采用启发式引导策略。
4. **文化敏感性**：文言文、古诗文等内容涉及文化传承，辅导策略需兼顾准确性与文化尊重。

### 3.2 路由策略

```typescript
interface SubDomainRouteResult {
  primaryDomain: ChineseSubDomain;
  secondaryDomains: ChineseSubDomain[];  // 辅助领域（跨领域请求时）
  confidence: number;                    // 分类置信度
  fallbackToGeneral: boolean;            // 是否降级为通用问答
  routeTarget: string;                   // 目标服务标识
}

/**
 * 子领域路由器 — 基于规则 + AI 意图识别双重判定
 */
class ChineseSubDomainRouter {
  
  /**
   * 第一阶段：基于关键词和上下文的规则匹配
   * 覆盖 80%+ 的高频场景，延迟 < 5ms
   */
  ruleBasedClassify(
    query: string,
    context: StudentContext,
  ): SubDomainRouteResult | null {
    const rules = this.getRulesForStage(context.stage);
    
    for (const rule of rules) {
      if (rule.pattern.test(query)) {
        return {
          primaryDomain: rule.domain,
          secondaryDomains: rule.secondary ?? [],
          confidence: rule.confidence,
          fallbackToGeneral: false,
          routeTarget: rule.targetService,
        };
      }
    }
    return null;
  }
  
  /**
   * 第二阶段：AI 意图识别（规则未命中时）
   * 使用轻量分类模型，延迟 < 100ms
   */
  async aiBasedClassify(
    query: string,
    context: StudentContext,
  ): Promise<SubDomainRouteResult> {
    const prompt = this.buildClassificationPrompt(query, context);
    const result = await this.llmClient.classify(prompt, {
      model: 'lightweight',   // 使用轻量模型降低成本和延迟
      temperature: 0.1,       // 低温度保证分类稳定性
      maxTokens: 100,
    });
    
    return this.parseClassificationResult(result, query);
  }
  
  /**
   * 规则表示例
   */
  private getRulesForStage(stage: StudyStage): RoutingRule[] {
    return [
      {
        domain: ChineseSubDomain.CLASSICAL_CHINESE,
        pattern: /翻译|文言文|古诗|默写.*诗|诗句|诗人|词牌|绝句|律诗|楚辞|诗经/,
        targetService: 'classical-chinese-service',
        confidence: 0.9,
      },
      {
        domain: ChineseSubDomain.WRITING,
        pattern: /作文|写作|议论文|记叙文|说明文|读后感|润色|提纲|素材|范文/,
        targetService: 'writing-tutor-service',
        confidence: 0.9,
      },
      {
        domain: ChineseSubDomain.READING_COMPREHENSION,
        pattern: /阅读理解|本文主旨|作者.*感情|段落.*作用|标题.*含义|赏析.*句子/,
        targetService: 'reading-comprehension-service',
        confidence: 0.85,
      },
      {
        domain: ChineseSubDomain.PINYIN_LITERACY,
        pattern: /拼音|声母|韵母|整体认读|声调|拼读|识字|认字/,
        targetService: 'pinyin-literacy-service',
        confidence: 0.9,
        stageFilter: [StudyStage.KINDERGARTEN, StudyStage.PRIMARY],
      },
      {
        domain: ChineseSubDomain.DICTATION,
        pattern: /听写|默写|听.*写|默.*写/,
        targetService: 'dictation-service',
        confidence: 0.9,
      },
      {
        domain: ChineseSubDomain.ORAL_EXPRESSION,
        pattern: /朗读|背诵.*检查|口语|发音|读.*课文/,
        targetService: 'oral-assessment-service',
        confidence: 0.85,
      },
    ];
  }
}
```

### 3.3 子领域服务适配层

每个子领域服务通过统一的适配接口接入：

```typescript
/**
 * 子领域服务统一接口
 */
interface ChineseSubDomainService {
  /** 子领域标识 */
  readonly domain: ChineseSubDomain;
  
  /** 处理辅导请求 */
  handleRequest(request: ChineseTutoringRequest): Promise<ChineseTutoringResponse>;
  
  /** 获取该子领域的能力评估数据 */
  getAbilityAssessment(studentId: string): Promise<AbilityAssessment[]>;
  
  /** 生成个性化练习推荐 */
  generateRecommendations(
    studentId: string,
    context: RecommendationContext,
  ): Promise<ContentRecommendation[]>;
}

/**
 * 语文辅导统一请求
 */
interface ChineseTutoringRequest {
  requestId: string;
  studentId: string;
  stage: StudyStage;
  grade: number;
  textbookVersion: string;
  subDomain: ChineseSubDomain;
  
  /** 用户输入（文本/语音/图片） */
  input: {
    type: 'text' | 'voice' | 'image';
    content: string;         // 文本内容或语音转写结果或图片URL
    audioUrl?: string;       // 原始语音文件（朗读/口语场景）
    imageUrl?: string;       // 原始图片文件（拍题场景）
  };
  
  /** 请求上下文 */
  context: {
    chapterId?: string;       // 关联教材章节
    knowledgePointIds?: string[]; // 关联知识点
    conversationId?: string;  // 对话会话ID（追问场景）
    previousMessages?: ConversationMessage[]; // 历史消息
    learningGoal?: string;    // 学习目标（如"期中考试复习"）
  };
  
  /** 辅导策略偏好 */
  strategy?: {
    hintLevel: 'hint' | 'guidance' | 'detailed'; // 提示程度
    answerReveal: boolean;   // 是否允许直接展示答案
    languageStyle?: 'simple' | 'standard' | 'literary'; // 语言风格
  };
}

/**
 * 语文辅导统一响应
 */
interface ChineseTutoringResponse {
  requestId: string;
  subDomain: ChineseSubDomain;
  
  /** 辅导内容（分段卡片式） */
  segments: TutoringSegment[];
  
  /** 知识点映射 */
  knowledgePoints: KnowledgePointRef[];
  
  /** 推荐的后续行动 */
  suggestions: NextActionSuggestion[];
  
  /** 能力评估信号（写入学情系统） */
  assessmentSignals: AssessmentSignal[];
  
  /** 元数据 */
  metadata: {
    modelUsed: string;
    tokensConsumed: number;
    responseTimeMs: number;
    confidenceScore: number;
  };
}

interface TutoringSegment {
  type: 'understanding'    // 题意/内容理解
      | 'hint'             // 思路提示
      | 'analysis'         // 详细分析
      | 'summary'          // 总结归纳
      | 'example'          // 示例/范句
      | 'exercise'         // 练习题
      | 'encouragement';   // 鼓励反馈
  content: string;          // Markdown 格式内容
  renderHints?: RenderHints; // 渲染提示（公式、古文注音等）
}
```

```typescript
    const traceId = request.requestId;
    
    try {
      // 1. 获取学生上下文
      const studentContext = await this.getStudentContext(request.studentId);
      
      // 2. 子领域路由
      const routeResult = await this.router.route(
        request.input.content,
        studentContext,
      );

        traceId,
        domain: routeResult.primaryDomain,
        confidence: routeResult.confidence,
      });

      const strategy = this.strategyProvider.getStrategy(
        studentContext.stage,
        routeResult.primaryDomain,
        request.strategy,
      );

        ...request,
        subDomain: routeResult.primaryDomain,
        strategy,
      };

      const subDomainService = this.subDomainServices.get(routeResult.primaryDomain);
      let response: ChineseTutoringResponse;
      
      if (subDomainService) {
        response = await subDomainService.handleRequest(enrichedRequest);
      } else {
        // 降级：使用通用语文辅导
        response = await this.handleGeneralChinese(enrichedRequest);
      }
      
      // 6. 质量校验
      const qualityResult = await this.qualityChecker.check(response, {
        stage: studentContext.stage,
        subDomain: routeResult.primaryDomain,
      });
      
      if (qualityResult.needsRevision) {
        response = await this.applyQualityRevision(response, qualityResult);
      }
      
      // 7. 异步：写入能力评估信号
      this.abilityCalculator
        .recordAssessmentSignals(request.studentId, response.assessmentSignals)
        .catch(err => logger.error('Failed to record assessment signals', { traceId, err }));
      
      // 8. 填充元数据
      response.metadata = {
        ...response.metadata,
        responseTimeMs: Date.now() - startTime,
      };
      
      return response;
      
    } catch (error) {

      logger.error('Chinese tutoring failed, falling back', {
        traceId,
        error: error.message,
        stack: error.stack,

      return JSON.parse(cached);
    }

    const allAssessments: AbilityAssessment[] = [];
    
    for (const [domain, service] of this.subDomainServices) {

      goal,

    });
    
    return path;
```

```typescript
/**
 * 语文能力评估计算器
 * 融合多源数据，计算学生语文综合能力
 */
class ChineseAbilityCalculator {
  
  /**
   * 计算综合能力画像
   */
  async computeProfile(
    studentId: string,
    assessments: AbilityAssessment[],
  ): Promise<ChineseAbilityProfile> {
    
    // 1. 按能力维度分组
    const groupedByAbility = this.groupBy(assessments, a => a.abilityCode);
    
    // 2. 对每个能力维度进行加权融合
    const abilityScores: ChineseAbilityMastery[] = [];
    
    for (const [abilityCode, records] of groupedByAbility) {
      const score = this.computeWeightedScore(records);
      const confidence = this.computeConfidence(records);
      const trend = await this.computeTrend(studentId, abilityCode, score);
      
      abilityScores.push({
        studentId,
        dimension: this.getDimensionForAbility(abilityCode),
        abilityCode,
        masteryScore: score,
        confidence,
        evidenceCount: records.length,
        lastUpdated: new Date().toISOString(),
        trend,
      });
    }
    
    // 3. 计算维度级总分
    const dimensionScores = this.aggregateToDimensions(abilityScores);
    
    // 4. 计算学科总分
    const overallScore = this.computeOverallScore(dimensionScores);
    
    return {
      studentId,
      overallScore,
      dimensions: dimensionScores,
      weaknesses: this.identifyWeaknesses(dimensionScores),
      lastUpdated: new Date().toISOString(),
    };
  }
  
  /**
   * 加权融合计算（Bayesian估计 + 数据源权重）
   */
  private computeWeightedScore(records: AbilityAssessment[]): number {
    // 使用 Beta分布的贝叶斯估计
    // prior: Beta(α=2, β=2) — 弱先验，期望值 0.5
    let alpha = 2;  // 先验"成功"次数
    let beta = 2;   // 先验"失败"次数
    
    for (const record of records) {
      const weight = this.getSourceWeight(record.source);
      const weightedSuccess = record.score * weight * record.evidenceCount;
      const weightedFailure = (1 - record.score) * weight * record.evidenceCount;
      alpha += weightedSuccess;
      beta += weightedFailure;
    }
    
    // 后验期望
    return alpha / (alpha + beta);
  }
  
  private getSourceWeight(source: string): number {
    const weights: Record<string, number> = {
      'answer': 0.35,
      'essay': 0.20,
      'ai_conversation': 0.15,
      'dictation': 0.10,
      'oral_assessment': 0.10,
      'reading_practice': 0.10,
    };
    return weights[source] ?? 0.10;
  }
  
  /**
   * 置信度计算 — 基于数据量和数据源多样性
   */
  private computeConfidence(records: AbilityAssessment[]): number {
    const totalEvidence = records.reduce((sum, r) => sum + r.evidenceCount, 0);
    const uniqueSources = new Set(records.map(r => r.source)).size;
    
    // 数据量因子：10条→0.5, 50条→0.8, 100条→0.95
    const volumeFactor = Math.min(1, Math.log10(totalEvidence + 1) / 2);
    
    // 多样性因子：1源→0.5, 2源→0.7, 3+源→0.9
    const diversityFactor = Math.min(0.9, 0.3 + uniqueSources * 0.2);
    
    return Math.round(volumeFactor * diversityFactor * 100) / 100;
  }
}
```

```typescript
 * 基于知识关联图的跨领域推荐

class ChineseKnowledgeLinker {
  
  /**
   * 当学生在某个子领域表现出薄弱时，
   * 推荐相关的其他子领域学习内容
   */
  async recommendCrossDomain(
    studentId: string,
    weakAbility: ChineseAbilityMastery,
  ): Promise<CrossDomainRecommendation[]> {
    
    // 1. 获取该能力关联的知识点
    const knowledgePoints = await this.kpService.getByAbilityCode(
      weakAbility.abilityCode,
    );
    
    // 2. 在知识关联图中查找跨领域关联
    const recommendations: CrossDomainRecommendation[] = [];
    
    for (const kp of knowledgePoints) {
      const relations = await this.relationService.findRelations(
        kp.id,
        [ChineseKnowledgeRelationType.APPLIED_IN, 
         ChineseKnowledgeRelationType.RELATED],
      );
      
      for (const rel of relations) {
        const targetKP = await this.kpService.getById(rel.targetKpId);
        const targetDomain = this.classifyKPToDomain(targetKP);
        
        // 跳过同领域推荐
        if (targetDomain === weakAbility.dimension) continue;
        
        recommendations.push({
          sourceAbility: weakAbility.abilityCode,
          targetDomain,
          targetKnowledgePoint: targetKP,
          relationType: rel.relationType,
          reason: this.buildRecommendationReason(rel, kp, targetKP),
          priority: rel.weight * (1 - weakAbility.masteryScore),
        });
      }
    }
    
    // 3. 按优先级排序，取Top N
    return recommendations
      .sort((a, b) => b.priority - a.priority)
      .slice(0, 5);
  }
  
  private buildRecommendationReason(
    relation: KnowledgeRelation,
    sourceKP: KnowledgePoint,
    targetKP: KnowledgePoint,
  ): string {
    const reasonTemplates: Record<string, string> = {
      [ChineseKnowledgeRelationType.APPLIED_IN]: 
        `"${sourceKP.name}"的知识在"${targetKP.name}"中也会用到，掌握好前者有助于后者学习`,
      [ChineseKnowledgeRelationType.RELATED]: 
        `"${sourceKP.name}"和"${targetKP.name}"属于关联知识，建议一起复习`,
      [ChineseKnowledgeRelationType.EVOLVES_TO]: 
        `"${sourceKP.name}"是"${targetKP.name}"的基础，建议先巩固基础`,
    };
    return reasonTemplates[relation.relationType] ?? '相关知识推荐';
```

```typescript
/**
 * 语文辅导输出质量校验器
 */
class ChineseQualityChecker {
  
  async check(
    response: ChineseTutoringResponse,
    context: { stage: StudyStage; subDomain: ChineseSubDomain },
  ): Promise<QualityCheckResult> {
    const checks = await Promise.allSettled([
      this.checkAccuracy(response, context),      // 准确性校验
      this.checkAgeAppropriate(response, context), // 适龄性校验
      this.checkCompleteness(response, context),   // 完整性校验
      this.checkSafety(response, context),         // 安全性校验
      this.checkFormat(response, context),         // 格式校验
    ]);
    
    const issues: QualityIssue[] = [];
    for (const result of checks) {
      if (result.status === 'fulfilled' && result.value.issues.length > 0) {
        issues.push(...result.value.issues);
      }
    }
    
    return {
      passed: issues.filter(i => i.severity === 'critical').length === 0,
      needsRevision: issues.some(i => i.severity === 'high'),
      issues,
    };
  }
  
  /**
   * 准确性校验 — 重点检查语文特有内容
   */
  private async checkAccuracy(
    response: ChineseTutoringResponse,
    context: { stage: StudyStage; subDomain: ChineseSubDomain },
  ): Promise<{ issues: QualityIssue[] }> {
    const issues: QualityIssue[] = [];
    
    // 合并所有文本内容
    const fullText = response.segments.map(s => s.content).join('\n');
    
    // 1. 古诗文原文准确性校验
    if (context.subDomain === ChineseSubDomain.CLASSICAL_CHINESE) {
      const quotes = this.extractClassicalQuotes(fullText);
      for (const quote of quotes) {
        const isAccurate = await this.classicalTextService.verifyQuote(quote.text);
        if (!isAccurate) {
          issues.push({
            severity: 'critical',
            type: 'quote_inaccuracy',
            message: `古诗文引用可能有误："${quote.text}"`,
            location: quote.position,
          });
        }
      }
    }
    
    // 2. 拼音标注准确性校验
    const pinyinAnnotations = this.extractPinyin(fullText);
    for (const pinyin of pinyinAnnotations) {
      const correct = await this.pinyinService.verify(pinyin.char, pinyin.pinyin);
      if (!correct) {
        issues.push({
          severity: 'high',
          type: 'pinyin_error',
          message: `拼音标注可能有误：${pinyin.char} → ${pinyin.pinyin}`,
        });
      }
    }
    
    // 3. 文学常识准确性校验
    const literaryClaims = this.extractLiteraryClaims(fullText);
    for (const claim of literaryClaims) {
      const verified = await this.knowledgeService.verifyClaim(claim);
      if (!verified) {
        issues.push({
          severity: 'high',
          type: 'literary_fact_error',
          message: `文学常识可能有误：${claim}`,
        });
      }
    }
    
    return { issues };
  }
  
  /**
   * 适龄性校验
   */
  private async checkAgeAppropriate(
    response: ChineseTutoringResponse,
    context: { stage: StudyStage; subDomain: ChineseSubDomain },
  ): Promise<{ issues: QualityIssue[] }> {
    const issues: QualityIssue[] = [];
    const fullText = response.segments.map(s => s.content).join('\n');
    
    // 检查是否使用了超出该学段认知水平的表达
    const stageCheck = this.checkVocabularyLevel(fullText, context.stage);
    if (stageCheck.tooAdvanced.length > 0) {
      issues.push({
        severity: 'medium',
        type: 'vocabulary_too_advanced',
        message: `以下词汇可能超出该学段水平：${stageCheck.tooAdvanced.join('、')}`,
      });
    }
    
    // 检查分析深度是否匹配
    const depthCheck = this.checkAnalysisDepth(fullText, context.stage);
    if (depthCheck.tooDeep) {
      issues.push({
        severity: 'low',
        type: 'analysis_too_deep',
        message: '分析深度可能超出该学段学生的理解能力',
      });
    }
    
    return { issues };
  }
}
```

### 11.3 预计算策略

```typescript
/**
 * 异步预计算任务
 */
class ChinesePreComputeScheduler {
  
  /**
   * 每日凌晨 2:00 执行
   * - 刷新活跃学生能力画像
   * - 预生成当日学习路径
   * - 更新知识点推荐列表
   */
  @Cron('0 2 * * *')
  async dailyPreCompute() {
    // 1. 获取近7天活跃学生
    const activeStudents = await this.getActiveStudents(7);
    
    // 2. 批量刷新能力画像
    await this.batchRefreshProfiles(activeStudents);
    
    // 3. 为每个学生预生成当日推荐
    for (const studentId of activeStudents) {
      try {
        const path = await this.engine.generateLearningPath(
          studentId,
          'daily_practice',
        );
        await redis.setex(
          CacheKeys.recommendations(studentId),
          86400, // 24h
          JSON.stringify(path),
        );
      } catch (err) {
        logger.warn('Pre-compute failed for student', { studentId, err });
      }
    }
  }
}
```
