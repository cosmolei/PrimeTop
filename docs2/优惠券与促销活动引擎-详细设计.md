# 优惠券与促销活动引擎 - 详细设计

## 1. 模块概述

### 1.1 定位

优惠券与促销活动引擎负责管理 PrimeTop 平台中所有优惠凭证的创建、发放、领取、核销和统计分析。它是连接"定价策略"与"用户转化"的关键基础设施，支持运营团队灵活配置限时折扣、定向发放、新人礼包、裂变奖励等促销手段。

### 1.2 与其他模块的关系

| 关联模块 | 交互方式 | 说明 |
|---------|---------|------|
| 支付与会员订阅 | 支付时核销优惠券 | 结算时调用本模块验证并扣减优惠金额 |
| 增值服务与商品系统 | 商品绑定优惠券适用范围 | 优惠券可限定特定商品（次数包、内容包等） |
| 积分与虚拟经济体系 | 积分兑换优惠券 | 用户可用积分兑换特定优惠券 |
| 用户服务 | 根据用户标签定向发券 | 查询用户所属分群（新用户、流失用户等） |
| 运营活动与成长激励体系 | 活动页发放优惠券 | 裂变活动、签到活动等奖励发券 |
| 邀请裂变与用户增长服务 | 邀请奖励发券 | 邀请成功后自动发券 |
| 内容与运营后台 | 运营人员管理优惠券 | 后台 CRUD、数据看板 |
| 消息与推送服务 | 发券通知 | 用户收到优惠券时推送消息 |

### 1.3 设计原则

1. **规则引擎化**：优惠券的使用条件、叠加规则、互斥规则通过可配置的规则引擎判定，避免硬编码。
2. **幂等核销**：同一优惠券在同一笔订单中只能核销一次，通过唯一约束和分布式锁保障。
3. **库存安全**：限量优惠券的发放采用 Redis 原子操作扣减，防止超发。
4. **审计完整**：每一张优惠券从创建到核销的完整生命周期均有日志记录。
5. **未成年人保护**：教育类产品的优惠券需避免诱导消费，设置合理折扣上限。

## 2. 核心概念与数据模型

### 2.1 优惠券类型

| 类型 | 枚举值 | 说明 | 示例 |
|------|--------|------|------|
| 满减券 | `FIXED_DISCOUNT` | 满足最低消费后减固定金额 | 满 50 减 10 |
| 折扣券 | `PERCENTAGE_DISCOUNT` | 按比例折扣 | 年费 8 折 |
| 兑换券 | `EXCHANGE` | 直接兑换指定商品，不涉及金额计算 | 免费体验 3 天会员 |
| 运费券 | `SHIPPING` | （预留）实体商品运费减免 | — |

### 2.2 优惠券模板（CouponTemplate）

优惠券模板定义一张"券种"，可批量发行多张实例。

```sql
CREATE TABLE coupon_template (
    id                  BIGSERIAL PRIMARY KEY,
    code                VARCHAR(64) NOT NULL UNIQUE,       -- 模板编码，如 NEW_USER_2026
    name                VARCHAR(128) NOT NULL,              -- 展示名称，如 "新人专享8折券"
    description         TEXT,                               -- 详细说明
    
    -- 类型与面值
    type                VARCHAR(32) NOT NULL,               -- FIXED_DISCOUNT / PERCENTAGE_DISCOUNT / EXCHANGE
    discount_value      INTEGER NOT NULL,                   -- 折扣值：满减券为金额(分)，折扣券为百分比*100（80=8折），兑换券为天数
    min_purchase_amount INTEGER NOT NULL DEFAULT 0,         -- 最低消费金额（分），兑换券为0
    max_discount_amount INTEGER NOT NULL DEFAULT 0,         -- 最大优惠金额上限（分），0=无上限；折扣券专用
    
    -- 适用范围
    scope_type          VARCHAR(32) NOT NULL DEFAULT 'ALL', -- ALL / PRODUCT / CATEGORY / PLAN
    scope_ids           JSONB DEFAULT '[]',                 -- 适用商品/品类/套餐ID列表，'["*"]'表示全部
    
    -- 有效期策略
    validity_type       VARCHAR(32) NOT NULL,               -- FIXED_RANGE(固定时间段) / RELATIVE(领取后N天有效)
    valid_from          TIMESTAMPTZ,                        -- 固定有效期起（validity_type=FIXED_RANGE）
    valid_until         TIMESTAMPTZ,                        -- 固定有效期止
    valid_days_after_claim INTEGER,                         -- 领取后有效天数（validity_type=RELATIVE）
    
    -- 发放控制
    total_quantity      INTEGER NOT NULL,                   -- 总发放量，-1=不限量
    per_user_limit      INTEGER NOT NULL DEFAULT 1,         -- 每人限领张数
    daily_claim_limit   INTEGER NOT NULL DEFAULT 0,         -- 每日领取上限（0=不限）
    
    -- 叠加规则
    stackable           BOOLEAN NOT NULL DEFAULT FALSE,     -- 是否可与其他优惠券叠加
    stack_group         VARCHAR(64),                        -- 叠加分组：同组内最多用1张，不同组可叠加
    
    -- 发放方式
    distribute_type     VARCHAR(32) NOT NULL DEFAULT 'USER_CLAIM', -- USER_CLAIM(用户主动领取) / SYSTEM_GRANT(系统自动发放) / CODE_REDEEM(兑换码)
    target_user_type    VARCHAR(32) DEFAULT 'ALL',          -- ALL / NEW / EXPIRING / CHURNED / VIP / TAG_BASED
    target_user_tags    JSONB DEFAULT '[]',                 -- 目标用户标签（target_user_type=TAG_BASED时使用）
    
    -- 兑换码配置（distribute_type=CODE_REDEEM）
    code_pattern        VARCHAR(64),                        -- 兑换码前缀，如 PRIME-
    code_quantity        INTEGER DEFAULT 0,                  -- 生成兑换码数量
    
    -- 关联商品（EXCHANGE类型专用）
    exchange_product_id VARCHAR(64),                        -- 兑换的商品ID（如会员套餐ID）
    exchange_product_type VARCHAR(32),                      -- MEMBERSHIP / CREDIT_PACK / CONTENT_PACK
    
    -- 状态
    status              VARCHAR(16) NOT NULL DEFAULT 'DRAFT', -- DRAFT / ACTIVE / PAUSED / EXPIRED / ARCHIVED
    
    -- 审计
    created_by          VARCHAR(64) NOT NULL,               -- 创建人（运营后台用户ID）
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    CONSTRAINT chk_discount_value CHECK (discount_value > 0),
    CONSTRAINT chk_validity_type CHECK (
        (validity_type = 'FIXED_RANGE' AND valid_from IS NOT NULL AND valid_until IS NOT NULL) OR
        (validity_type = 'RELATIVE' AND valid_days_after_claim IS NOT NULL)
    )
);

COMMENT ON TABLE coupon_template IS '优惠券模板/券种定义';
CREATE INDEX idx_coupon_template_code ON coupon_template(code);
CREATE INDEX idx_coupon_template_status ON coupon_template(status);
CREATE INDEX idx_coupon_template_valid ON coupon_template(valid_from, valid_until) WHERE status = 'ACTIVE';
```

### 2.3 用户优惠券实例（UserCoupon）

每张实际发放到用户的优惠券记录。

```sql
CREATE TABLE user_coupon (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL,                    -- 用户ID
    template_id         BIGINT NOT NULL REFERENCES coupon_template(id),
    
    -- 优惠券码（兑换码场景）
    coupon_code         VARCHAR(128),                       -- 用户持有的兑换码（CODE_REDEEM场景）
    
    -- 有效期（实际计算后的）
    valid_from          TIMESTAMPTZ NOT NULL,
    valid_until         TIMESTAMPTZ NOT NULL,
    
    -- 状态
    status              VARCHAR(16) NOT NULL DEFAULT 'CLAIMED', -- CLAIMED / USED / EXPIRED / REVOKED
    claimed_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(), -- 领取时间
    used_at             TIMESTAMPTZ,                        -- 使用时间
    expired_at          TIMESTAMPTZ,                        -- 过期时间（实际标记时间）
    
    -- 核销信息（使用后填充）
    order_id            VARCHAR(64),                        -- 关联订单号
    discount_amount     INTEGER,                            -- 实际优惠金额（分）
    original_amount     INTEGER,                            -- 原价金额（分）
    
    -- 来源追踪
    source              VARCHAR(32) NOT NULL DEFAULT 'MANUAL_CLAIM', -- MANUAL_CLAIM / SYSTEM_GRANT / CODE_REDEEM / POINTS_EXCHANGE / REFERRAL_REWARD / ACTIVITY_REWARD
    source_id           VARCHAR(64),                        -- 来源关联ID（活动ID、邀请记录ID等）
    
    -- 撤销
    revoked_at          TIMESTAMPTZ,
    revoke_reason       VARCHAR(256),
    
    -- 审计
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    CONSTRAINT uk_user_coupon_claim UNIQUE (user_id, template_id, coupon_code)
);

COMMENT ON TABLE user_coupon IS '用户持有的优惠券实例';
CREATE INDEX idx_user_coupon_user_status ON user_coupon(user_id, status);
CREATE INDEX idx_user_coupon_template ON user_coupon(template_id);
CREATE INDEX idx_user_coupon_valid ON user_coupon(valid_until) WHERE status = 'CLAIMED';
CREATE INDEX idx_user_coupon_order ON user_coupon(order_id) WHERE order_id IS NOT NULL;
```

### 2.5 核销记录（CouponUsageLog）

每次核销的完整快照，用于对账与统计。

```sql
CREATE TABLE coupon_usage_log (
    id                  BIGSERIAL PRIMARY KEY,
    user_coupon_id      BIGINT NOT NULL REFERENCES user_coupon(id),
    user_id             BIGINT NOT NULL,
    template_id         BIGINT NOT NULL,
    order_id            VARCHAR(64) NOT NULL,
    
    -- 快照
    coupon_type         VARCHAR(32) NOT NULL,
    discount_value      INTEGER NOT NULL,
    original_amount     INTEGER NOT NULL,                   -- 订单原价（分）
    discount_amount     INTEGER NOT NULL,                   -- 实际优惠金额（分）
    final_amount        INTEGER NOT NULL,                   -- 实付金额（分）
    
    -- 叠加信息
    stacked_coupons     JSONB DEFAULT '[]',                 -- 同订单其他叠加优惠券ID
    
    used_at             TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_coupon_usage_log_user ON coupon_usage_log(user_id);
CREATE INDEX idx_coupon_usage_log_template ON coupon_usage_log(template_id);
CREATE INDEX idx_coupon_usage_log_time ON coupon_usage_log(used_at);
```

## 3. 状态流转

### 3.1 优惠券模板状态机

```
         ┌────────────────────────────────────────┐
         │                                        │
         ▼                                        │
  ┌──────┐  创建  ┌───────┐  上线  ┌────────┐     │
  │ DRAFT├──────►│ REVIEW├──────►│ ACTIVE │◄────┘
  └──────┘       └───────┘       └───┬────┘  恢复
                                   │       ┌───────┐
                                   │ 暂停  │       │
                                   ▼       │ PAUSED │
                               ┌────────┐◄─┤       │
                               │        │  └───────┘
                               │        │
                               │        │
                            手动过期/到期
                               │        │
                               ▼        │
                               ┌────────┐
                               │EXPIRED │
                               └───┬────┘
                                   │ 归档
                                   ▼
                               ┌────────┐
                               │ARCHIVED│
                               └────────┘
```

**关键规则**：
- `ACTIVE` 状态才允许领取和核销
- `PAUSED` 状态暂停领取，已领取的券仍可使用
- 模板到期后由定时任务自动转为 `EXPIRED`

### 3.2 用户优惠券状态机

```
  ┌─────────┐  使用  ┌──────┐
  │ CLAIMED ├──────►│ USED │
  └────┬────┘       └──────┘
       │
       │ 过期（定时任务扫描）
       ▼
  ┌─────────┐
  │ EXPIRED │
  └────┬────┘
       │
       │ 运营手动撤销 / 订单退款
       ▼
  ┌─────────┐
  │ REVOKED │
  └─────────┘
```

**关键规则**：
- 核销必须是 `CLAIMED` 状态，且当前时间在 `valid_from` 和 `valid_until` 之间
- `EXPIRED` 不可逆转为 `CLAIMED`
- `REVOKED` 仅限运营后台操作或订单退款触发，且优惠券必须尚未核销
- 退款场景：订单全额退款时，已核销的优惠券退回为 `CLAIMED` 状态并延长有效期

#### 4.2.2 结算时查询可用优惠券

```
GET /api/v1/coupons/available?productId=annual_premium&productType=PLAN&amount=19800
```

响应 `200 OK`：
```json
{
  "coupons": [
    {
      "userCouponId": 50001,
      "name": "新人专享8折券",
      "type": "PERCENTAGE_DISCOUNT",
      "discountAmount": 3960,
      "finalAmount": 15840,
      "discountLabel": "省¥39.60",
      "stackable": false,
      "stackGroup": "new_user_promo"
    },
    {
      "userCouponId": 50008,
      "name": "满100减20",
      "type": "FIXED_DISCOUNT",
      "discountAmount": 2000,
      "finalAmount": 17800,
      "discountLabel": "省¥20.00",
      "stackable": false,
      "stackGroup": "general_discount"
    }
  ],
  "bestCouponId": 50001,
  "bestDiscount": 3960
}
```

**计算逻辑**：
- 折扣券：`discountAmount = min(amount * discountValue / 100, maxDiscountAmount)`（discountValue=80 → 8折 → 减20%）
- 满减券：`discountAmount = min(discountValue, amount - minPurchaseAmount)`，需先满足 `amount >= minPurchaseAmount`
- 兑换券：`discountAmount = amount`（全额抵扣指定商品）

### 5.3 叠加规则判定

当一笔订单可用多张优惠券时，叠加判定逻辑：

```typescript
interface StackCheckResult {
  usable: UserCoupon[];       // 本单可用优惠券
  bestCombination: {          // 最优组合（最大优惠）
    coupons: UserCoupon[];
    totalDiscount: number;
  };
  groups: Map<string, UserCoupon[]>;  // 按stackGroup分组
}

function evaluateStacking(
  availableCoupons: UserCoupon[],
  orderAmount: number
): StackCheckResult {
  // 1. 按 stackGroup 分组
  const groups = groupBy(availableCoupons, c => c.stackGroup ?? c.id.toString());
  
  // 2. 每组内选出最优券
  const groupBest = [];
  for (const [group, coupons] of groups) {
    if (!coupons[0].stackable) {
      // 同组不可叠加，选最大优惠
      groupBest.push(maxBy(coupons, c => calcDiscount(c, orderAmount)));
    } else {
      // 可叠加，全部纳入
      groupBest.push(...coupons);
    }
  }
  
  // 3. 不同 stackGroup 之间不可叠加（默认行为）
  // 只有 stackable=true 且 stackGroup 不同才可叠加
  // 返回最优组合
  return {
    usable: availableCoupons,
    bestCombination: selectBestCombination(groupBest, orderAmount),
    groups
  };
}
```

## 6. 关键代码实现

### 6.1 Redis 原子扣减库存

```typescript
/**
 * 原子扣减优惠券库存
 * 使用 Lua 脚本保证 check-then-decr 的原子性
 */
const DECR_STOCK_LUA = `
local stock = redis.call('GET', KEYS[1])
if stock == false then
  return -1  -- 库存key不存在，需要初始化
end
if tonumber(stock) <= 0 then
  return 0   -- 库存不足
end
return redis.call('DECR', KEYS[1])
`;

async function claimWithStockCheck(
  templateId: number,
  userId: number
): Promise<{ success: boolean; remaining?: number }> {
  const stockKey = `coupon:stock:${templateId}`;
  
  // 原子扣减
  const result = await redis.eval(DECR_STOCK_LUA, 1, stockKey);
  
  if (result === -1) {
    // Redis 中没有库存计数，从 DB 初始化
    await initStockCache(templateId);
    // 重试
    const retry = await redis.eval(DECR_STOCK_LUA, 1, stockKey);
    if (retry <= 0) {
      return { success: false };
    }
    return { success: true, remaining: retry };
  }
  
  if (result === 0) {
    return { success: false }; // 库存不足
  }
  
  return { success: true, remaining: result };
}

/** 从 DB 初始化库存到 Redis */
async function initStockCache(templateId: number): Promise<void> {
  const template = await db.query(
    'SELECT total_quantity, (SELECT COUNT(*) FROM user_coupon WHERE template_id = $1) as claimed ' +
    'FROM coupon_template WHERE id = $1',
    [templateId]
  );
  const remaining = template.total_quantity - template.claimed;
  await redis.set(`coupon:stock:${templateId}`, Math.max(0, remaining));
}
```

### 6.2 优惠金额计算

```typescript
interface DiscountCalc {
  discountAmount: number;   // 优惠金额（分）
  finalAmount: number;      // 实付金额（分）
  label: string;            // 展示文案
}

function calculateDiscount(
  coupon: CouponTemplate,
  originalAmount: number   // 原价（分）
): DiscountCalc {
  // 1. 检查最低消费
  if (originalAmount < coupon.minPurchaseAmount) {
    return { discountAmount: 0, finalAmount: originalAmount, label: '未满足最低消费' };
  }
  
  switch (coupon.type) {
    case 'FIXED_DISCOUNT': {
      const discount = Math.min(coupon.discountValue, originalAmount - coupon.minPurchaseAmount);
      return {
        discountAmount: discount,
        finalAmount: originalAmount - discount,
        label: `省¥${(discount / 100).toFixed(2)}`
      };
    }
    
    case 'PERCENTAGE_DISCOUNT': {
      // discountValue=80 表示8折，即减20%
      const discountPercent = (100 - coupon.discountValue) / 100;
      let discount = Math.floor(originalAmount * discountPercent);
      // 最大优惠上限
      if (coupon.maxDiscountAmount > 0) {
        discount = Math.min(discount, coupon.maxDiscountAmount);
      }
      return {
        discountAmount: discount,
        finalAmount: originalAmount - discount,
        label: `省¥${(discount / 100).toFixed(2)}`
      };
    }
    
    case 'EXCHANGE': {
      // 兑换券直接全额抵扣指定商品
      return {
        discountAmount: originalAmount,
        finalAmount: 0,
        label: '免费兑换'
      };
    }
    
    default:
      throw new Error(`Unknown coupon type: ${coupon.type}`);
  }
}
```

### 6.3 用户资格校验

```typescript
async function checkEligibility(
  userId: number,
  template: CouponTemplate
): Promise<{ eligible: boolean; reason?: string }> {
  
  // 1. 每人限领次数
  const claimedCount = await db.query(
    'SELECT COUNT(*) FROM user_coupon WHERE user_id = $1 AND template_id = $2',
    [userId, template.id]
  );
  if (claimedCount >= template.perUserLimit) {
    return { eligible: false, reason: 'COUPON_LIMIT_EXCEEDED' };
  }
  
  // 2. 目标用户群校验
  switch (template.targetUserType) {
    case 'NEW': {
      const daysSinceReg = await getUserDaysSinceRegistration(userId);
      if (daysSinceReg > 7) return { eligible: false, reason: 'COUPON_TARGET_MISMATCH' };
      break;
    }
    case 'EXPIRING': {
      const daysToExpiry = await getUserMembershipDaysToExpiry(userId);
      if (daysToExpiry > 14 || daysToExpiry < 0) {
        return { eligible: false, reason: 'COUPON_TARGET_MISMATCH' };
      }
      break;
    }
    case 'CHURNED': {
      const isActive = await isUserActiveRecently(userId, 30);
      if (isActive) return { eligible: false, reason: 'COUPON_TARGET_MISMATCH' };
      break;
    }
    case 'TAG_BASED': {
      const userTags = await getUserTags(userId);
      const hasMatch = template.targetUserTags.some(t => userTags.includes(t));
      if (!hasMatch) return { eligible: false, reason: 'COUPON_TARGET_MISMATCH' };
      break;
    }
    case 'ALL':
    default:
      break;
  }
  
  // 3. 每日领取上限
  if (template.dailyClaimLimit > 0) {
    const todayClaims = await redis.get(`coupon:daily:${template.id}:${todayStr()}`);
    if (todayClaims && parseInt(todayClaims) >= template.dailyClaimLimit) {
      return { eligible: false, reason: 'COUPON_DAILY_LIMIT' };
    }
  }
  
  return { eligible: true };
}
```

### 7.2 并发安全

| 场景 | 风险 | 解决方案 |
|------|------|---------|
| 多用户同时领取最后一张券 | 超发 | Redis Lua 原子扣减 |
| 同一用户并发领取 | 重复领取 | `uk_user_coupon_claim` 唯一约束 + 应用层幂等 |
| 同一张券被多个订单核销 | 重复核销 | Redis 分布式锁 `coupon:lock:{id}` + DB 状态检查 |
| 兑换码并发兑换 | 重复使用 | `UPDATE coupon_redeem_code SET status='CLAIMED' WHERE code=? AND status='AVAILABLE'` 行级锁 |

### 7.3 降级策略

| 故障场景 | 影响 | 降级方案 |
|---------|------|---------|
| Redis 不可用 | 库存扣减失败 | 降级为纯 DB 行级锁（`SELECT ... FOR UPDATE`），性能下降但功能可用 |
| 消息服务不可用 | 发券通知丢失 | 优惠券仍正常发放，通知进入重试队列 |
| DB 主库故障 | 无法领取/核销 | 只读模式展示已有优惠券，领取和核销返回 503 |

## 10. 安全与合规

### 10.1 防刷策略

1. **领取接口限流**：同一用户每分钟最多 5 次领取请求
2. **设备指纹**：兑换码场景限制同一设备每日兑换次数
3. **异常检测**：单个 IP/设备短时间内大量领取不同优惠券触发风控
4. **兑换码暴力破解防护**：同一 IP 连续 10 次无效兑换码触发验证码 + 临时封禁

### 10.2 未成年人保护

1. 优惠券折扣力度上限：最高不超过 **5折**（避免"1元购"等过度诱导）
2. 优惠券不可用于自动续费抵扣（需家长明确操作）
3. 运营后台创建优惠券时校验折扣合规性，超过阈值需审批

### 10.3 审计

- 所有运营后台操作（创建、修改、发放、撤销）记录审计日志
- 核销记录保留 5 年，支持按订单号、用户ID、时间范围查询

## 11. MVP 分期计划

### 11.1 MVP 阶段（第 1 期）

**范围**：
- 满减券 + 折扣券两种类型
- 固定时间段有效期
- 运营后台创建/上线/暂停模板
- 客户端领取 + 支付核销
- 系统自动发放（新用户注册自动发券）
- 基础数据看板

**不包含**：兑换券、兑换码、叠加规则、积分兑换

### 11.2 V1.0 阶段（第 2 期）

**新增**：
- 兑换券 + 兑换码系统
- 叠加规则引擎
- 领取后相对有效期（`RELATIVE`）
- 目标用户群定向发放
- 过期提醒推送
- 完整统计看板

### 11.3 V1.5 阶段（第 3 期）

**新增**：
- 积分兑换优惠券
- 分享裂变自动发券
- 优惠券中心页面
- A/B 测试不同券面额的转化效果
- 智能发券（基于用户行为预测最佳发券时机和面额）
