# 客户端 - 数字内容防截屏与用户溯源水印系统 - 详细设计

## 1. 概述

### 1.1 功能定位

PrimeTop 作为付费教育产品，承载了大量版权教材内容、精品题库解析、AI 辅导对话记录和学生个人数据。数字内容防截屏与用户溯源水印系统是客户端安全防护体系的核心子模块，负责：

1. **截屏/录屏检测与拦截**：在敏感内容页面检测并阻止截屏和屏幕录制行为。
2. **用户溯源水印**：在内容渲染层叠加用户身份信息水印（可见 + 隐形），实现泄露内容到用户的精确追溯。
3. **内容复制保护**：限制付费内容的文本复制、图片保存行为。
4. **泄露追溯管线**：当内容在第三方平台出现时，通过水印信息定位泄露源头。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 截屏检测覆盖率 | 敏感页面 100% 覆盖（iOS/Android） |
| 水印渲染性能开销 | < 2ms / 帧（隐形水印） |
| 水印提取准确率 | 截图经压缩/裁剪后 ≥ 90% |
| 误拦截率 | < 0.1%（非敏感场景不拦截） |
| 水印不可见性 | 不影响用户正常阅读体验 |

### 1.3 适用范围

| 场景 | 是否启用防护 |
| --- | --- |
| AI 辅导对话页（付费解析内容） | ✅ 全部启用 |
| 同步课堂教材阅读器（付费内容） | ✅ 全部启用 |
| 拍题答疑解析结果页 | ✅ 启用隐形水印 + 录屏检测 |
| 考试模拟答题页 | ✅ 全部启用（防作弊） |
| 作文批改结果页 | ✅ 启用隐形水印 |
| 错题本页面 | ⚪ 仅启用隐形水印 |
| 学情分析报告 | ⚪ 仅启用隐形水印 |
| 用户个人头像/昵称页 | ❌ 不启用 |
| 设置/帮助/关于页 | ❌ 不启用 |

### 3.4 隐形水印载荷

```dart
/// 隐形水印载荷（编码到图像像素中）
class InvisibleWatermarkPayload {
  /// 用户 ID 短哈希（10 位字母数字）
  final String userIdHash;

  /// 会话 ID 短哈希（6 位）
  final String sessionIdHash;

  /// 时间戳编码（10 位：年后2位+月2位+日2位+时2位+分2位）
  final String timestampCode;

  /// 校验位
  final int checksum;

  /// 完整载荷字符串
  String get payload => 'U$userIdHash-S$sessionIdHash-T$timestampCode-C$checksum';

  InvisibleWatermarkPayload({
    required this.userIdHash,
    required this.sessionIdHash,
    required this.timestampCode,
    required this.checksum,
  });

  factory InvisibleWatermarkPayload.fromContext({
    required String userId,
    required String sessionId,
    required DateTime timestamp,
  }) {
    final userIdHash = _hashShort(userId, 10);
    final sessionIdHash = _hashShort(sessionId, 6);
    final yy = (timestamp.year % 100).toString().padLeft(2, '0');
    final mm = timestamp.month.toString().padLeft(2, '0');
    final dd = timestamp.day.toString().padLeft(2, '0');
    final hh = timestamp.hour.toString().padLeft(2, '0');
    final mi = timestamp.minute.toString().padLeft(2, '0');
    final tsCode = '$yy$mm$dd$hh$mi';
    final rawChecksum = (userIdHash.codeUnits.fold(0, (a, b) => a + b) +
        sessionIdHash.codeUnits.fold(0, (a, b) => a + b) +
        tsCode.codeUnits.fold(0, (a, b) => a + b)) % 10;
    return InvisibleWatermarkPayload(
      userIdHash: userIdHash,
      sessionIdHash: sessionIdHash,
      timestampCode: tsCode,
      checksum: rawChecksum,
    );
  }

  /// 短哈希：将任意字符串映射为指定长度的字母数字
  static String _hashShort(String input, int length) {
    var hash = 5381;
    for (final c in input.codeUnits) {
      hash = ((hash << 5) + hash + c) & 0xFFFFFFFF;
    }
    const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789';
    final sb = StringBuffer();
    var h = hash;
    for (var i = 0; i < length; i++) {
      sb.write(chars[h % chars.length]);
      h = (h >> 5) ^ (h * 33);
    }
    return sb.toString();
  }
}
```

```kotlin
// AndroidSecurityBridge.kt
package com.primetop.security

import android.app.Activity
import android.view.WindowManager
import android.os.Build
import io.flutter.plugin.common.MethodChannel

class AndroidSecurityBridge(private val activity: Activity) {

    companion object {
        const val CHANNEL = "com.primetop/security"
    }

    private var isSecureMode = false
    private var screenshotObserver: ScreenshotObserver? = null

    /**
     * 设置 FLAG_SECURE
     * 启用后截屏和录屏均显示黑屏
     */
    fun setSecureMode(enabled: Boolean) {
        if (enabled) {
            activity.window.setFlags(
                WindowManager.LayoutParams.FLAG_SECURE,
                WindowManager.LayoutParams.FLAG_SECURE
            )
        } else {
            activity.window.clearFlags(
                WindowManager.LayoutParams.FLAG_SECURE
            )
        }
        isSecureMode = enabled
    }

    /**
     * 注册截屏监听：通过 ContentResolver 监听 MediaStore 图片新增
     */
    fun registerScreenshotListener(callback: (Map<String, Any>) -> Unit) {
        val handler = android.os.Handler(android.os.Looper.getMainLooper())
        screenshotObserver = ScreenshotObserver(activity, handler) { uri ->
            if (isScreenshotUri(uri)) {
                callback(mapOf(
                    "type" to "screenshot",
                    "timestamp" to System.currentTimeMillis(),
                    "uri" to uri.toString()
                ))
            }
        }
        activity.contentResolver.registerContentObserver(
            android.provider.MediaStore.Images.Media.EXTERNAL_CONTENT_URI,
            true,
            screenshotObserver!!
        )
    }

    private fun isScreenshotUri(uri: android.net.Uri): Boolean {
        activity.contentResolver.query(
            uri,
            arrayOf(
                android.provider.MediaStore.Images.Media.DISPLAY_NAME,
                android.provider.MediaStore.Images.Media.RELATIVE_PATH
            ),
            null, null, null
        )?.use { cursor ->
            if (cursor.moveToFirst()) {
                val name = cursor.getString(0)?.lowercase() ?: ""
                val path = cursor.getString(1)?.lowercase() ?: ""
                return name.contains("screenshot") || path.contains("screenshots")
            }
        }
        return false
    }

    fun unregisterScreenshotListener() {
        screenshotObserver?.let {
            activity.contentResolver.unregisterContentObserver(it)
            screenshotObserver = null
        }
    }
}

class ScreenshotObserver(
    private val activity: Activity,
    handler: android.os.Handler,
    private val onScreenshot: (android.net.Uri) -> Unit
) : android.database.ContentObserver(handler) {
    override fun onChange(selfChange: Boolean, uri: android.net.Uri?) {
        super.onChange(selfChange, uri)
        uri?.let { onScreenshot(it) }
    }
}
```

### 4.2 iOS 实现

#### 4.2.1 UIScreen 录屏检测 + UITextField 保护

```swift
// IOSSecurityBridge.swift
import Flutter
import UIKit

class IOSSecurityBridge: NSObject, FlutterPlugin {

    static let channelName = "com.primetop/security"
    private var channel: FlutterMethodChannel?
    private var blurOverlayView: UIVisualEffectView?
    private var secureTextFields: [UITextField] = []

    static func register(with registrar: FlutterPluginRegistrar) {
        let ch = FlutterMethodChannel(name: channelName, binaryMessenger: registrar.messenger())
        let instance = IOSSecurityBridge()
        instance.channel = ch
        registrar.addMethodCallDelegate(instance, channel: ch)
    }

    func handle(_ call: FlutterMethodCall, result: @escaping FlutterResult) {
        switch call.method {
        case "setSecureMode":
            let enabled = call.arguments as? Bool ?? false
            updateSecureTextFields(enabled: enabled)
            result(nil)
        case "startMonitoring":
            startCaptureMonitoring()
            result(nil)
        case "stopMonitoring":
            stopCaptureMonitoring()
            result(nil)
        default:
            result(FlutterMethodNotImplemented)
        }
    }

    // MARK: - 录屏检测

    private func startCaptureMonitoring() {
        if #available(iOS 14.0, *) {
            NotificationCenter.default.addObserver(
                self,
                selector: #selector(capturedDidChange(_:)),
                name: UIScreen.capturedDidChangeNotification,
                object: nil
            )
            if UIScreen.main.isCaptured { onCaptureStarted() }
        }
    }

    private func stopCaptureMonitoring() {
        NotificationCenter.default.removeObserver(
            self, name: UIScreen.capturedDidChangeNotification, object: nil)
        removeBlurOverlay()
    }

    @available(iOS 14.0, *)
    @objc private func capturedDidChange(_ n: Notification) {
        guard let screen = n.object as? UIScreen else { return }
        if screen.isCaptured { onCaptureStarted() } else { onCaptureEnded() }
    }

    private func onCaptureStarted() {
        DispatchQueue.main.async { [weak self] in
            self?.channel?.invokeMethod("onScreenCapture", arguments: [
                "isCaptured": true,
                "timestamp": Date().timeIntervalSince1970
            ])
            self?.showBlurOverlay()
        }
    }

    private func onCaptureEnded() {
        DispatchQueue.main.async { [weak self] in
            self?.channel?.invokeMethod("onScreenCapture", arguments: [
                "isCaptured": false,
                "timestamp": Date().timeIntervalSince1970
            ])
            self?.removeBlurOverlay()
        }
    }

    // MARK: - UITextField 截屏保护

    /// isSecureTextEntry 的 textField 被系统在截屏时隐藏
    /// 利用此特性覆盖敏感区域
    private func updateSecureTextFields(enabled: Bool) {
        guard let window = UIApplication.shared.connectedScenes
            .compactMap({ $0 as? UIWindowScene })
            .first?.windows.first else { return }

        if enabled {
            let field = UITextField()
            field.isSecureTextEntry = true
            field.isUserInteractionEnabled = false
            field.translatesAutoresizingMaskIntoConstraints = false
            // 覆盖全屏，但保持透明
            window.addSubview(field)
            NSLayoutConstraint.activate([
                field.topAnchor.constraint(equalTo: window.topAnchor),
                field.bottomAnchor.constraint(equalTo: window.bottomAnchor),
                field.leadingAnchor.constraint(equalTo: window.leadingAnchor),
                field.trailingAnchor.constraint(equalTo: window.trailingAnchor)
            ])
            // 设为隐藏但参与渲染管线
            field.isHidden = false
            field.alpha = 0.01
            secureTextFields.append(field)
        } else {
            secureTextFields.forEach { $0.removeFromSuperview() }
            secureTextFields.removeAll()
        }
    }

    // MARK: - 模糊遮罩

    private func showBlurOverlay() {
        guard blurOverlayView == nil else { return }
        guard let window = UIApplication.shared.connectedScenes
            .compactMap({ $0 as? UIWindowScene })
            .first?.windows.first else { return }

        let blur = UIVisualEffectView(effect: UIBlurEffect(style: .systemUltraThinMaterial))
        blur.frame = window.bounds
        blur.autoresizingMask = [.flexibleWidth, .flexibleHeight]

        let label = UILabel()
        label.text = "内容保护中\n检测到屏幕录制，内容已隐藏"
        label.numberOfLines = 0
        label.textAlignment = .center
        label.font = .systemFont(ofSize: 18, weight: .semibold)
        label.translatesAutoresizingMaskIntoConstraints = false
        blur.contentView.addSubview(label)
        NSLayoutConstraint.activate([
            label.centerXAnchor.constraint(equalTo: blur.contentView.centerXAnchor),
            label.centerYAnchor.constraint(equalTo: blur.contentView.centerYAnchor)
        ])
        window.addSubview(blur)
        blurOverlayView = blur
    }

    private func removeBlurOverlay() {
        blurOverlayView?.removeFromSuperview()
        blurOverlayView = nil
    }
}
```

### 4.3 Flutter 层统一调度

```dart
// content_security_controller.dart

class ContentSecurityController with ChangeNotifier {
  static final ContentSecurityController _instance = ContentSecurityController._();
  static ContentSecurityController get instance => _instance;
  ContentSecurityController._();

  static const _channel = MethodChannel('com.primetop/security');

  WatermarkConfig? _currentConfig;
  ContentSecurityLevel _currentLevel = ContentSecurityLevel.none;
  String _currentRoute = '';

  WatermarkConfig? get currentConfig => _currentConfig;
  ContentSecurityLevel get currentLevel => _currentLevel;

  /// 页面进入时调用
  Future<void> onPageEnter({
    required String route,
    required ContentSecurityLevel level,
    required UserContext userCtx,
  }) async {
    _currentRoute = route;
    _currentLevel = level;

    if (level == ContentSecurityLevel.none) {
      _currentConfig = null;
      await _disableAllProtection();
      return;
    }

    final config = WatermarkConfig.fromUserContext(userCtx);
    _currentConfig = config;

    // 根据等级启用原生防护
    final useFlagSecure = level == ContentSecurityLevel.fullProtection;
    await _channel.invokeMethod('setSecureMode', useFlagSecure);
    await _channel.invokeMethod('startMonitoring');

    // 设置截屏回调
    _channel.setMethodCallHandler((call) async {
      switch call.method {
        case 'onScreenCapture':
          final isCaptured = call.arguments['isCaptured'] as bool;
          if isCaptured {
            _handleCaptureDetected();
          }
          break;
        default:
          break;
      }
      return null;
    });
  }

  /// 页面离开时调用
  Future<void> onPageLeave() async {
    await _channel.invokeMethod('setSecureMode', false);
    await _channel.invokeMethod('stopMonitoring');
    _currentLevel = ContentSecurityLevel.none;
    _currentConfig = null;
    _channel.setMethodCallHandler(null);
  }

  void _handleCaptureDetected() {
    final config = _currentConfig;
    if config == null return;

    // 上报截屏/录屏事件
    final event = ScreenshotEvent(
      eventId: UUID.v4().toString(),
      userId: config.userId,
      deviceId: config.deviceId,
      occurredAt: DateTime.now(),
      pageRoute: _currentRoute,
      pageSecurityLevel: _currentLevel,
      result: _currentLevel == ContentSecurityLevel.fullProtection
          ? ScreenshotResult.screenRecordingBlurred
          : ScreenshotResult.allowedWithWatermark,
      platform: Platform.operatingSystem,
      appVersion: PackageInfo.appVersion,
    );

    SecurityLogService.instance.reportScreenshot(event);
  }

  Future<void> _disableAllProtection() async {
    await _channel.invokeMethod('setSecureMode', false);
    await _channel.invokeMethod('stopMonitoring');
  }
}
```

### 5.1 可见水印

可见水印为半透明文字层，平铺覆盖在敏感内容之上，不影响交互。

```dart
/// 可见水印 Widget - 平铺重复的文字层
class VisibleWatermarkOverlay extends StatelessWidget {
  final WatermarkConfig config;

  const VisibleWatermarkOverlay({super.key, required this.config});

  @override
  Widget build(BuildContext context) {
    if (config.visibleText == null) return const SizedBox.shrink();

    return IgnorePointer(
      child: ClipRect(
        child: CustomPaint(
          painter: _WatermarkPainter(config),
          size: Size.infinite,
        ),
      ),
    );
  }
}

class _WatermarkPainter extends CustomPainter {
  final WatermarkConfig config;
  _WatermarkPainter(this.config);

  @override
  void paint(Canvas canvas, Size size) {
    final text = config.visibleText!;
    final spacing = 200.0; // 水印间距
    final angle = config.rotation * pi / 180;

    final textStyle = TextStyle(
      color: Colors.black.withOpacity(config.opacity),
      fontSize: config.fontSize,
    );
    final textSpan = TextSpan(text: text, style: textStyle);
    final textPainter = TextPainter(
      text: textSpan,
      textDirection: TextDirection.ltr,
    );
    textPainter.layout();

    canvas.save();
    canvas.rotate(angle);

    // 平铺水印
    for (double y = -size.height; y < size.height * 2; y += spacing) {
      for (double x = -size.width; x < size.width * 2; x += spacing) {
        textPainter.paint(canvas, Offset(x, y));
      }
    }
    canvas.restore();
  }

  @override
  bool shouldRepaint(covariant _WatermarkPainter old) =>
      old.config.visibleText != config.visibleText ||
      old.config.opacity != config.opacity;
}
```

### 5.2 隐形水印（DCT 频域嵌入）

隐形水印将用户标识编码到内容的渲染像素中，人眼不可见但可通过算法提取。采用 **DCT（离散余弦变换）频域嵌入方案**。

#### 5.2.1 算法原理

1. 将目标图像划分为 8×8 像素块。
2. 对每个块执行 DCT 变换。
3. 在中频系数中嵌入水印比特位（修改特定系数的相对大小）。
4. 执行逆 DCT 变换还原图像。
5. 提取时重新分块 DCT，读取中频系数关系恢复比特序列。

#### 5.2.2 Android 原生实现（Kotlin）

```kotlin
// InvisibleWatermarkEngine.kt
package com.primetop.security.watermark

import android.graphics.Bitmap
import android.graphics.Canvas
import android.graphics.Color
import kotlin.math.cos
import kotlin.math.roundToInt
import kotlin.math.sqrt

class InvisibleWatermarkEngine {

    companion object {
        private const val BLOCK_SIZE = 8
        // DCT 中频位置对（嵌入位置）
        private val EMBED_POS_1 = Pair(3, 4)
        private val EMBED_POS_2 = Pair(4, 3)
        private const val EMBED_STRENGTH = 3.0 // 嵌入强度（越大越鲁棒但越可见）
    }

    /**
     * 在 Bitmap 中嵌入隐形水印
     * @param bitmap 待嵌入的目标图像（ARGB_8888）
     * @param payload 水印载荷比特序列
     * @return 嵌入水印后的新 Bitmap
     */
    fun embed(bitmap: Bitmap, payload: BooleanArray): Bitmap {
        val width = bitmap.width
        val height = bitmap.height
        val result = bitmap.copy(Bitmap.Config.ARGB_8888, true)

        val pixels = IntArray(width * height)
        result.getPixels(pixels, 0, width, 0, 0, width, height)

        // 提取蓝色通道（人眼对蓝色最不敏感）
        val blueChannel = IntArray(width * height) { Color.blue(pixels[it]) }

        // 分块处理
        val blocksX = width / BLOCK_SIZE
        val blocksY = height / BLOCK_SIZE
        var bitIndex = 0

        for (by in 0 until blocksY) {
            for (bx in 0 until blocksX) {
                if (bitIndex >= payload.size) break

                val block = extractBlock(blueChannel, bx, by, width)
                val dctBlock = forwardDCT(block)

                // 嵌入一个比特
                val bit = payload[bitIndex]
                val p1 = dctBlock[EMBED_POS_1.first][EMBED_POS_1.second]
                val p2 = dctBlock[EMBED_POS_2.first][EMBED_POS_2.second]

                if (bit) {
                    // bit=1: 确保 p1 > p2 + strength
                    if (p1 <= p2 + EMBED_STRENGTH) {
                        val mid = (p1 + p2) / 2
                        dctBlock[EMBED_POS_1.first][EMBED_POS_1.second] = mid + EMBED_STRENGTH / 2
                        dctBlock[EMBED_POS_2.first][EMBED_POS_2.second] = mid - EMBED_STRENGTH / 2
                    }
                } else {
                    // bit=0: 确保 p2 > p1 + strength
                    if (p2 <= p1 + EMBED_STRENGTH) {
                        val mid = (p1 + p2) / 2
                        dctBlock[EMBED_POS_1.first][EMBED_POS_1.second] = mid - EMBED_STRENGTH / 2
                        dctBlock[EMBED_POS_2.first][EMBED_POS_2.second] = mid + EMBED_STRENGTH / 2
                    }
                }

                val modifiedBlock = inverseDCT(dctBlock)
                writeBlock(blueChannel, modifiedBlock, bx, by, width)
                bitIndex++
            }
        }

        // 写回蓝色通道
        for (i in pixels.indices) {
            val orig = pixels[i]
            val b = blueChannel[i].coerceIn(0, 255)
            pixels[i] = (orig and 0xFFFF00) or b  // 保持 R、G 不变，替换 B
        }

        result.setPixels(pixels, 0, width, 0, 0, width, height)
        return result
    }

    /**
     * 从 Bitmap 中提取水印载荷
     */
    fun extract(bitmap: Bitmap, payloadLength: Int): BooleanArray {
        val width = bitmap.width
        val height = bitmap.height
        val pixels = IntArray(width * height)
        bitmap.getPixels(pixels, 0, width, 0, 0, width, height)
        val blueChannel = IntArray(width * height) { Color.blue(pixels[it]) }

        val blocksX = width / BLOCK_SIZE
        val blocksY = height / BLOCK_SIZE
        val result = BooleanArray(payloadLength)
        var bitIndex = 0

        for (by in 0 until blocksY) {
            for (bx in 0 until blocksX) {
                if (bitIndex >= payloadLength) break

                val block = extractBlock(blueChannel, bx, by, width)
                val dctBlock = forwardDCT(block)
                val p1 = dctBlock[EMBED_POS_1.first][EMBED_POS_1.second]
                val p2 = dctBlock[EMBED_POS_2.first][EMBED_POS_2.second]

                result[bitIndex] = p1 > p2
                bitIndex++
            }
        }
        return result
    }

    // 8x8 DCT
    private fun forwardDCT(block: IntArray): Array<DoubleArray> {
        val result = Array(BLOCK_SIZE) { DoubleArray(BLOCK_SIZE) }
        for (u in 0 until BLOCK_SIZE) {
            for (v in 0 until BLOCK_SIZE) {
                var sum = 0.0
                for (x in 0 until BLOCK_SIZE) {
                    for (y in 0 until BLOCK_SIZE) {
                        sum += block[x * BLOCK_SIZE + y] *
                            cos((2 * x + 1) * u * Math.PI / (2 * BLOCK_SIZE)) *
                            cos((2 * y + 1) * v * Math.PI / (2 * BLOCK_SIZE))
                    }
                }
                val cu = if (u == 0) 1.0 / sqrt(2.0) else 1.0
                val cv = if (v == 0) 1.0 / sqrt(2.0) else 1.0
                result[u][v] = 0.25 * cu * cv * sum
            }
        }
        return result
    }

    // 8x8 逆DCT
    private fun inverseDCT(block: Array<DoubleArray>): IntArray {
        val result = IntArray(BLOCK_SIZE * BLOCK_SIZE)
        for (x in 0 until BLOCK_SIZE) {
            for (y in 0 until BLOCK_SIZE) {
                var sum = 0.0
                for (u in 0 until BLOCK_SIZE) {
                    for (v in 0 until BLOCK_SIZE) {
                        val cu = if (u == 0) 1.0 / sqrt(2.0) else 1.0
                        val cv = if (v == 0) 1.0 / sqrt(2.0) else 1.0
                        sum += cu * cv * block[u][v] *
                            cos((2 * x + 1) * u * Math.PI / (2 * BLOCK_SIZE)) *
                            cos((2 * y + 1) * v * Math.PI / (2 * BLOCK_SIZE))
                    }
                }
                result[x * BLOCK_SIZE + y] = (sum * 0.25).roundToInt()
            }
        }
        return result
    }

    private fun extractBlock(channel: IntArray, bx: Int, by: Int, width: Int): IntArray {
        val block = IntArray(BLOCK_SIZE * BLOCK_SIZE)
        for (y in 0 until BLOCK_SIZE) {
            for (x in 0 until BLOCK_SIZE) {
                block[y * BLOCK_SIZE + x] = channel[(by * BLOCK_SIZE + y) * width + (bx * BLOCK_SIZE + x)]
            }
        }
        return block
    }

    private fun writeBlock(channel: IntArray, block: IntArray, bx: Int, by: Int, width: Int) {
        for (y in 0 until BLOCK_SIZE) {
            for (x in 0 until BLOCK_SIZE) {
                channel[(by * BLOCK_SIZE + y) * width + (bx * BLOCK_SIZE + x)] = block[y * BLOCK_SIZE + x]
            }
        }
    }
}
```

#### 5.2.3 水印渲染时机

| 时机 | 说明 |
| --- | --- |
| 页面截图（`RepaintBoundary.toImage()`） | 敏感页面截图时自动嵌入 |
| 内容卡片渲染完成后 | 通过 `CustomPainter` 后处理 |
| 服务端图片下载到本地时 | 在原生层对 Bitmap 嵌入后缓存 |

> **注意**：隐形水印不直接作用于屏幕实时渲染帧（性能开销过大），而是作用于：
> 1. 服务端返回的图片资源在客户端本地缓存时嵌入。
> 2. 用户主动保存图片时嵌入。
> 3. 长按可复制的富文本截图时嵌入。

```dart
/// 水印载荷工具：字符串 ↔ 布尔数组
class WatermarkPayloadCodec {
  /// 字符串 → 布尔数组（每字符 8 bit ASCII）
  static BooleanArray stringToBits(String text) {
    final bytes = text.codeUnits;
    final bits = <bool>[];
    for (final byte in bytes) {
      for (var i = 7; i >= 0; i--) {
        bits.add((byte >> i) & 1 == 1);
      }
    }
    return bits;
  }

  /// 布尔数组 → 字符串
  static String bitsToString(BooleanArray bits) {
    final sb = StringBuffer();
    for (var i = 0; i < bits.length; i += 8) {
      var byte = 0;
      for (var j = 0; j < 8 && (i + j) < bits.length; j++) {
        byte = (byte << 1) | (bits[i + j] ? 1 : 0);
      }
      sb.writeCharCode(byte);
    }
    return sb.toString();
  }
}
```

## 7. 页面安全策略混入

### 7.1 SecurePageMixin

```dart
/// 敏感页面混入 - 自动管理安全策略生命周期
mixin SecurePageMixin<T extends StatefulWidget> on State<T> {
  ContentSecurityLevel get securityLevel;
  String get routeName;

  @override
  void initState() {
    super.initState();
    // 延迟到首帧后执行，确保 UserContext 已就绪
    WidgetsBinding.instance.addPostFrameCallback((_) {
      _applySecurity();
    });
  }

  void _applySecurity() {
    final userCtx = UserContextProvider.current;
    ContentSecurityController.instance.onPageEnter(
      route: routeName,
      level: securityLevel,
      userCtx: userCtx,
    );
  }

  @override
  void dispose() {
    ContentSecurityController.instance.onPageLeave();
    super.dispose();
  }

  /// 构建带水印的内容区域
  Widget buildSecureContent(Widget child) {
    final config = ContentSecurityController.instance.currentConfig;
    if (config == null || securityLevel == ContentSecurityLevel.none) {
      return child;
    }

    return Stack(
      children: [
        // 内容层
        child,
        // 可见水印层（仅 fullProtection 时显示）
        if (securityLevel == ContentSecurityLevel.fullProtection)
          VisibleWatermarkOverlay(config: config),
      ],
    );
  }
}
```

## 10. 错误处理与降级

### 10.1 异常场景处理

| 异常场景 | 处理策略 |
| --- | --- |
| 平台通道调用失败 | 降级为仅 Dart 层水印（隐形水印不可用） |
| FLAG_SECURE 设置失败 | 记录错误日志，仍启用可见水印 |
| 水印渲染 OOM | 跳过隐形水印，保留可见水印 |
| 截屏监听注册失败 | 静默降级，依赖服务端日志做事后追溯 |
| iOS 录屏检测不可用（<iOS14） | 仅使用 UITextField 保护方案 |

### 10.3 降级逻辑

```dart
class SecurityErrorHandler {
  /// 处理安全模块异常，执行降级
  static void handleError(SecurityErrorCode code, StackTrace? stack) {
    switch (code) {
      case SecurityErrorCode.platformChannelUnavailable:
        // 降级：仅 Dart 层水印
        ContentSecurityController.instance.disableNativeProtection();
        break;

      case SecurityErrorCode.flagSecureFailed:
        // 降级：FLAG_SECURE 不可用，加强可见水印
        ContentSecurityController.instance.enhanceVisibleWatermark();
        break;

      case SecurityErrorCode.invisibleWatermarkEmbedFailed:
        // 降级：隐形水印不可用，增加可见水印频率
        ContentSecurityController.instance.increaseWatermarkDensity();
        break;

      case SecurityErrorCode.screenshotListenerFailed:
        // 降级：静默，依赖事后追溯
        break;

      default:
        SecurityLogService.instance.reportError(code, stack);
    }
  }
}
```

## 11. 性能优化

### 11.1 水印渲染优化

| 策略 | 说明 |
| --- | --- |
| 可见水印缓存 | `CustomPainter.shouldRepaint` 返回 false，仅在配置变化时重绘 |

| 按需嵌入 | 仅对服务端下发的付费内容图片嵌入，用户头像/系统图标不处理 |

```kotlin
// Android: 使用 debounce 避免短时间多次回调
class DebouncedScreenshotObserver(
    private val handler: Handler,
    private val delayMs: Long = 500,
    private val callback: () -> Unit
) : ContentObserver(handler) {
    private var lastTriggerTime = 0L

    override fun onChange(selfChange: Boolean, uri: Uri?) {
        val now = System.currentTimeMillis()
        if (now - lastTriggerTime > delayMs) {
            lastTriggerTime = now
            callback()
        }
    }
}
```

```sql
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    event_id VARCHAR(64) NOT NULL UNIQUE COMMENT '事件唯一ID',
    user_id VARCHAR(64) NOT NULL COMMENT '用户ID',
    device_id VARCHAR(128) NOT NULL COMMENT '设备ID',
    occurred_at DATETIME NOT NULL COMMENT '发生时间',
    page_route VARCHAR(256) NOT NULL COMMENT '页面路由',
    security_level VARCHAR(32) NOT NULL COMMENT '页面安全等级',
    result VARCHAR(32) NOT NULL COMMENT '处理结果',
    platform VARCHAR(16) NOT NULL COMMENT 'iOS/Android',
    app_version VARCHAR(32) NOT NULL COMMENT 'App版本',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (user_id, occurred_at),
    INDEX idx_occurred (occurred_at)
) COMMENT='截屏事件日志';

-- 泄露追溯记录表
CREATE TABLE content_leak_trace (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    leak_trace_id VARCHAR(64) NOT NULL UNIQUE COMMENT '追溯单号',
    reported_image_url VARCHAR(512) NOT NULL COMMENT '举报图片URL',
    decoded_user_id_hash VARCHAR(32) COMMENT '解码出的用户哈希',
    matched_user_id VARCHAR(64) COMMENT '匹配到的用户ID',
    confidence DECIMAL(4,3) DEFAULT 0 COMMENT '匹配置信度',
    report_source VARCHAR(32) NOT NULL COMMENT '举报来源',
    external_url VARCHAR(512) COMMENT '外部链接',
    status ENUM('pending', 'investigating', 'confirmed', 'dismissed')
        DEFAULT 'pending' COMMENT '处理状态',
    handled_by VARCHAR(64) COMMENT '处理人',
    handled_at DATETIME COMMENT '处理时间',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_user (matched_user_id),
    INDEX idx_status (status)
) COMMENT='内容泄露追溯记录';
```

### 12.2 追溯流程

```
外部平台发现泄露内容
          │
          ▼
  运营人员上传截图
  POST /api/security/leak-report
          │
          ▼
  ┌───────────────────────┐
  │ 服务端水印解码服务     │
  │ 1. 下载图片预处理     │
  │ 2. 裁剪/压缩还原      │
  │ 3. DCT 提取水印位     │
  │ 4. 载荷字符串解码     │
  │ 5. 用户哈希匹配      │
  └───────────┬───────────┘
              │
              ▼
     匹配结果（用户ID + 置信度）
              │
              ▼
  ┌───────────────────────┐
  │ 人工审核确认          │
  │ - 高置信度(>0.9): 自动关联 │
  │ - 中置信度(0.6-0.9): 人工 │
  │ - 低置信度(<0.6): 标记无法追溯│
  └───────────────────────┘
```

## 14. 与其他模块的集成关系

```
┌─────────────────┐    水印配置     ┌─────────────────┐
│  用户服务        │ ──────────→   │ 本系统            │
│ (UserContext)   │               │ (ContentSecurity)│
└─────────────────┘               └────────┬────────┘
                                           │ 截屏日志
                                           ▼
┌─────────────────┐  页面安全等级   ┌─────────────────┐
│  各业务页面      │ ──────────→   │ 服务端追溯服务    │
│ (AI对话/教材等) │               │ (/api/security)  │
└─────────────────┘               └─────────────────┘
                                           ▲
┌─────────────────┐   运营举报      │
│  运营后台        │ ──────────────┘
│ (内容安全审核)   │
└─────────────────┘
```

| 集成点 | 说明 |
| --- | --- |
| 用户服务 | 获取 userId / displayName / deviceId 生成水印配置 |
| AI 对话页 | 默认 `fullProtection`，防止付费解析内容被截屏传播 |
| 同步课堂阅读器 | 默认 `fullProtection`，保护版权教材内容 |
| 考试模拟答题 | 默认 `fullProtection`，防作弊 |
| 错题本 | 默认 `watermarkOnly`，允许用户截图但可追溯 |
| 内容管理后台 | 运营人员可查看泄露追溯记录并处理 |
| 客户端安全防护体系 | 本系统作为子模块，与反调试、代码混淆共同构成客户端安全方案 |
