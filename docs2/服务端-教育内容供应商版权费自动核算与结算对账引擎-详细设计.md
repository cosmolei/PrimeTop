## 1. 概述

### 1.1 模块定位

PrimeTop 平台需要从外部内容供应商（教材出版社、教辅机构、独立教研团队、名师作者等）获取大量教育内容——包括题库、知识点解析、视频微课、试卷真题、作文范文等。这些内容并非一次性买断，而是基于 **使用量分成 / 按次计费 / 订阅收入分成** 等多种商业条款进行结算。

本引擎负责 **自动化追踪内容使用量 → 按合同规则计算版权费 → 生成结算单 → 对账确认 → 触发付款流程**，是平台内容采购成本管理的核心后端服务。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 内容使用量采集 | 追踪每条供应商内容在平台上的实际使用情况（播放、查看、答题引用等）|
| 版权费计算 | 根据供应商合同条款（固定费、按次、分成、阶梯价）自动计算应付金额 |
| 结算周期管理 | 按月/季/年生成结算单，支持账期管理与审批流 |
| 对账确认 | 供应商在线核对结算明细，确认或发起争议 |
| 付款集成 | 确认后对接财务付款流程，记录付款凭证 |
| 成本分析与预测 | 按供应商、内容类型、学科等维度分析内容采购成本趋势 |

## 2. 数据模型

### 2.1 核心实体关系

```
supplier (供应商)
  ├── 1:N ── supplier_contract (合同)
  │             ├── 1:N ── contract_pricing_rule (计费规则)
  │             └── 1:N ── contract_content_scope (内容范围)
  ├── 1:N ── supplier_content_item (供应商内容映射)
  └── 1:N ── settlement_order (结算单)
                ├── 1:N ── settlement_detail (结算明细)
                └── 1:N ── settlement_dispute (争议记录)

content_usage_daily (日使用量聚合)
  └── N:1 ── supplier_content_item

payment_record (付款记录)
  └── N:1 ── settlement_order
```

### 2.3 供应商合同表 `supplier_contract`

```sql
CREATE TABLE supplier_contract (
    id                  BIGSERIAL PRIMARY KEY,
    contract_no         VARCHAR(64) NOT NULL UNIQUE,       -- 合同编号：HT-2026-PUB001-001
    supplier_id         BIGINT NOT NULL REFERENCES content_supplier(id),
    contract_name       VARCHAR(256) NOT NULL,             -- 合同名称
    contract_type       VARCHAR(20) NOT NULL,              -- EXCLUSIVE/NON_EXCLUSIVE 授权类型
    sign_date           DATE NOT NULL,                     -- 签订日期
    effective_date      DATE NOT NULL,                     -- 生效日期
    expire_date         DATE NOT NULL,                     -- 到期日期
    settlement_cycle    VARCHAR(20) NOT NULL DEFAULT 'MONTHLY', -- MONTHLY/QUARTERLY/YEARLY/PER_USE
    settlement_day      INT DEFAULT 10,                    -- 结算日出账日（每月第N日）
    currency            VARCHAR(8) DEFAULT 'CNY',
    status              VARCHAR(20) NOT NULL DEFAULT 'EFFECTIVE', -- DRAFT/EFFECTIVE/EXPIRED/TERMINATED
    auto_renew          BOOLEAN DEFAULT FALSE,             -- 到期自动续约
    auto_renew_years    INT DEFAULT 1,                     -- 自动续约年限
    minimum_guarantee   DECIMAL(12,2) DEFAULT 0,           -- 保底金额（每结算周期）
    cap_amount          DECIMAL(12,2),                     -- 封顶金额（每结算周期，NULL不限）
    notify_email        VARCHAR(256),                      -- 结算单通知邮箱
    notify_phone        VARCHAR(32),                       -- 结算单通知手机
    contract_file_url   VARCHAR(512),                      -- 合同扫描件URL
    remark              TEXT,
    created_at          TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    
    CONSTRAINT chk_date_range CHECK (effective_date < expire_date),
    CONSTRAINT chk_settlement_cycle CHECK (settlement_cycle IN ('MONTHLY','QUARTERLY','YEARLY','PER_USE'))
);

CREATE INDEX idx_contract_supplier ON supplier_contract(supplier_id);
CREATE INDEX idx_contract_status ON supplier_contract(status);
CREATE INDEX idx_contract_expire ON supplier_contract(expire_date);
```

### 2.4 计费规则表 `contract_pricing_rule`

```sql
CREATE TABLE contract_pricing_rule (
    id                  BIGSERIAL PRIMARY KEY,
    contract_id         BIGINT NOT NULL REFERENCES supplier_contract(id),
    rule_code           VARCHAR(32) NOT NULL,              -- 规则编码
    rule_name           VARCHAR(128) NOT NULL,             -- 规则名称
    billing_model       VARCHAR(20) NOT NULL,              -- 计费模式，见下方枚举
    content_type        VARCHAR(32),                       -- 适用内容类型，NULL=全部
    subject             VARCHAR(32),                       -- 适用学科，NULL=全部
    unit_price          DECIMAL(10,4) DEFAULT 0,           -- 单价（按次/按量模式）
    revenue_share_rate  DECIMAL(6,4) DEFAULT 0,            -- 分成比例（0~1）
    -- 阶梯定价
    tier_config         JSONB,                             -- 阶梯定价配置
    /*
     * tier_config 示例（按使用量阶梯）:
     * [
     *   {"min": 0,     "max": 1000,  "unit_price": 0.50},
     *   {"min": 1001,  "max": 5000,  "unit_price": 0.40},
     *   {"min": 5001,  "max": null,  "unit_price": 0.30}
     * ]
     *
     * tier_config 示例（按收入阶梯分成）:
     * [
     *   {"min": 0,      "max": 10000,  "rate": 0.15},
     *   {"min": 10001,  "max": 50000,  "rate": 0.20},
     *   {"min": 50001,  "max": null,   "rate": 0.25}
     * ]
     */
    usage_metric        VARCHAR(32) NOT NULL DEFAULT 'VIEW', -- VIEW/PLAY/DOWNLOAD/ANSWER_REF/CITE/SUB_ACTIVE
    dedup_window_minutes INT DEFAULT 60,                    -- 去重窗口（同一用户N分钟内重复使用计一次）
    effective_from      DATE NOT NULL,                      -- 规则生效日
    effective_to        DATE,                               -- 规则失效日（NULL=长期有效）
    priority            INT DEFAULT 0,                      -- 优先级（多条规则匹配时取最高）
    status              VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',
    created_at          TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_pricing_contract ON contract_pricing_rule(contract_id);
CREATE INDEX idx_pricing_model ON contract_pricing_rule(billing_model);
CREATE INDEX idx_pricing_content_type ON contract_pricing_rule(content_type);

COMMENT ON COLUMN contract_pricing_rule.billing_model IS
'FIXED_ANNUAL=年度固定授权费, PER_USE=按次计费, REVENUE_SHARE=收入分成, TIERED_PER_USE=阶梯按次, TIERED_SHARE=阶梯分成, HYBRID_FIXED_PLUS_OVERFLOW=保底+超额按次';
```

### 2.8 结算单主表 `settlement_order`

```sql
CREATE TABLE settlement_order (
    id                      BIGSERIAL PRIMARY KEY,
    settlement_no           VARCHAR(32) NOT NULL UNIQUE,   -- 结算单号 STL-202607-PUB001-001
    supplier_id             BIGINT NOT NULL REFERENCES content_supplier(id),
    contract_id             BIGINT NOT NULL REFERENCES supplier_contract(id),
    period_start            DATE NOT NULL,                 -- 结算周期开始日
    period_end              DATE NOT NULL,                 -- 结算周期结束日
    billing_cycle           VARCHAR(20) NOT NULL,          -- MONTHLY/QUARTERLY/YEARLY
    
    -- 金额汇总
    total_usage_count       INT NOT NULL DEFAULT 0,        -- 总有效使用次数
    total_content_items     INT NOT NULL DEFAULT 0,        -- 涉及内容条数
    gross_amount            DECIMAL(12,2) NOT NULL DEFAULT 0, -- 税前应付总额
    tax_amount              DECIMAL(12,2) NOT NULL DEFAULT 0, -- 税额
    net_amount              DECIMAL(12,2) NOT NULL DEFAULT 0, -- 税后应付净额
    minimum_guarantee       DECIMAL(12,2) DEFAULT 0,       -- 本期保底金额
    cap_amount              DECIMAL(12,2),                 -- 本期封顶金额
    final_amount            DECIMAL(12,2) NOT NULL DEFAULT 0, -- 最终应付（保底/封顶调整后）
    currency                VARCHAR(8) DEFAULT 'CNY',
    
    -- 状态管理
    status                  VARCHAR(20) NOT NULL DEFAULT 'DRAFT',
    /* DRAFT → PENDING_CONFIRM → CONFIRMED → PAYMENT_PENDING → PAID → COMPLETED
       DRAFT → PENDING_CONFIRM → DISPUTED → RESOLVED → CONFIRMED
       Any → CANCELLED */
    generated_at            TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    sent_at                 TIMESTAMP WITH TIME ZONE,      -- 发送给供应商时间
    confirmed_at            TIMESTAMP WITH TIME ZONE,      -- 供应商确认时间
    confirmed_by            VARCHAR(64),                   -- 确认人（供应商账号）
    dispute_deadline        DATE NOT NULL,                 -- 争议截止日（发送后N个工作日）
    remark                  TEXT,
    created_at              TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    updated_at              TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_settle_supplier ON settlement_order(supplier_id);
CREATE INDEX idx_settle_contract ON settlement_order(contract_id);
CREATE INDEX idx_settle_status ON settlement_order(status);
CREATE INDEX idx_settle_period ON settlement_order(period_start, period_end);
```
