# 用户学习目标管理服务 - 详细设计文档

## 1. 概述

### 1.1 模块定位

用户学习目标管理服务（User Learning Goal Management Service，简称 Goal Service）是 PrimeTop 学习规划体系的数据源头与生命周期管理中心。它负责为学生提供学习目标的创建、维护、归档、达成追踪等功能，并向下游的**学习计划生成服务**、**学习提醒服务**、**学情分析服务**输出结构化目标数据。

该服务定位是"目标管理"而非"计划编排"：

- **目标管理**：回答"学生想达成什么"（What）。
- **计划编排**：回答"怎么分步骤达成"（How），由独立的学习规划服务负责。

### 1.2 覆盖学段

小学至高中。幼儿启蒙阶段暂不支持自主目标设定，由系统或家长代为设置习惯类目标（本设计暂不做重点覆盖）。

### 1.3 优先级

P1 — V1.0 阶段核心功能。

### 1.4 核心职责

| 职责 | 说明 |
|------|------|
| 目标 CRUD | 支持学生/家长创建、修改、删除、查询学习目标 |
| 目标模板 | 内置常见目标模板（单元测、期中期末、中考、高考等） |
| 目标状态机 | 管理目标从草稿、进行中、已完成、已放弃、已过期等状态流转 |
| 目标关联 | 关联学科、章节、知识点、考试类型、薄弱点 |
| 达成追踪 | 接收学习记录、答题记录、计划完成事件，计算目标达成进度 |
| 目标推荐 | 基于学情数据为学生推荐合理目标 |
| 归档与审计 | 支持历史目标查询、家长查看、运营分析 |

### 1.5 依赖关系

```text
用户学习目标管理服务
├── 依赖：用户账号体系（User Service）          — 获取用户学段、年级、教材版本
├── 依赖：学科基础数据服务（Subject Service）    — 获取学科、章节、知识点元数据
├── 依赖：学情分析服务（Learning Analytics）    — 获取能力画像、薄弱点、掌握度
├── 依赖：学习计划服务（Study Plan Service）    — 目标确认后触发计划生成
├── 依赖：AI 服务（AI Service）                — 目标合理性评估、推荐生成
├── 依赖：消息服务（Notification Service）     — 目标达成/到期提醒
└── 被依赖：家长中心 App / 学生端 App / 管理后台 / 数据看板
```

## 2. 术语与概念

| 术语 | 说明 |
|------|------|
| 目标（Goal） | 学生期望达成的学习结果，包含目标类型、截止时间、关联学科等 |
| 目标模板（Goal Template） | 系统预置的目标结构，降低创建成本 |
| 里程碑（Milestone） | 目标内部的关键检查点，如"完成第三章复习" |
| 目标状态（Goal Status） | 目标生命周期状态：draft / active / paused / completed / abandoned / expired |
| 目标进度（Progress） | 基于关联任务/学习记录计算出的完成百分比 |
| 目标达成度（Achievement） | 基于目标类型-specific 指标计算的实际达成评估 |

## 5. 关键代码示例

### 5.1 目标创建与校验

```java
@Service
@RequiredArgsConstructor
public class GoalCreateService {

    private final GoalRepository goalRepository;
    private final GoalTemplateRepository templateRepository;
    private final SubjectServiceClient subjectService;
    private final GoalValidationService validationService;
    private final GoalEventPublisher eventPublisher;

    @Transactional
    public LearningGoal createGoal(CreateGoalRequest request, String operatorId) {
        // 1. 校验用户权限与学段
        UserProfile profile = subjectService.getStudentProfile(request.getUserId());
        if (profile == null) {
            throw new BizException(ErrorCode.USER_NOT_FOUND);
        }

        // 2. 目标数量上限校验
        long activeCount = goalRepository.countActiveGoals(request.getUserId());
        if (activeCount >= 20) {
            throw new BizException(ErrorCode.GOAL_ACTIVE_LIMIT_EXCEEDED,
                    "同时进行中目标不能超过20个");
        }

        // 3. 业务规则校验
        validationService.validate(request, profile);

        // 4. 生成目标实体
        LearningGoal goal = new LearningGoal();
        goal.setId(IdGenerator.generate("goal"));
        goal.setUserId(request.getUserId());
        goal.setTitle(request.getTitle());
        goal.setGoalType(request.getGoalType());
        goal.setSubjectId(request.getSubjectId());
        goal.setTargetExam(request.getTargetExam());
        goal.setTargetDate(request.getTargetDate());
        goal.setCurrentLevel(request.getCurrentLevel());
        goal.setTargetLevel(request.getTargetLevel());
        goal.setStatus(GoalStatus.DRAFT); // 默认草稿，需激活才生效
        goal.setSource(GoalSource.MANUAL);
        goal.setProgressPercent(0);
        goal.setPriority(request.getPriority());
        goal.setVisibleToParent(request.getIsVisibleToParent());
        goal.setTimezone(request.getTimezone());
        goal.setExtraConfig(request.getExtraConfig());

        // 5. 保存主表与关联表
        goalRepository.save(goal);
        saveKnowledgePointRelations(goal, request.getExtraConfig());

        // 6. 生成默认里程碑（可选）
        List<GoalMilestone> milestones = generateDefaultMilestones(goal);
        goal.setMilestones(milestones);

        // 7. 发送创建事件
        eventPublisher.publish(new GoalCreatedEvent(goal.getId(), goal.getUserId(), operatorId));

        return goal;
    }

    private List<GoalMilestone> generateDefaultMilestones(LearningGoal goal) {
        List<GoalMilestone> list = new ArrayList<>();
        if (goal.getGoalType() == GoalType.EXAM_PREPARATION) {
            list.add(buildMilestone(goal, 1, "诊断薄弱知识点", 0));
            list.add(buildMilestone(goal, 2, "完成专项练习", 40));
            list.add(buildMilestone(goal, 3, "完成模拟测试", 70));
            list.add(buildMilestone(goal, 4, "考前复习冲刺", 90));
        }
        return list;
    }

    private GoalMilestone buildMilestone(LearningGoal goal, int seq, String title, int progress) {
        GoalMilestone m = new GoalMilestone();
        m.setId(IdGenerator.generate("ms"));
        m.setGoalId(goal.getId());
        m.setTitle(title);
        m.setSeqNo(seq);
        m.setStatus(MilestoneStatus.PENDING);
        m.setProgressPercent(progress);
        return m;
    }
}
```

```java
    private static final Map<GoalStatus, Set<GoalStatus>> TRANSITIONS = Map.of(
            GoalStatus.DRAFT, Set.of(GoalStatus.ACTIVE, GoalStatus.ABANDONED),
            GoalStatus.ACTIVE, Set.of(GoalStatus.PAUSED, GoalStatus.COMPLETED, GoalStatus.ABANDONED, GoalStatus.EXPIRED),
            GoalStatus.PAUSED, Set.of(GoalStatus.ACTIVE, GoalStatus.ABANDONED, GoalStatus.EXPIRED),
            GoalStatus.COMPLETED, Set.of(), // 终态
            GoalStatus.ABANDONED, Set.of(), // 终态
            GoalStatus.EXPIRED, Set.of()    // 终态
    );

    public boolean canTransition(GoalStatus from, GoalStatus to) {
        return TRANSITIONS.getOrDefault(from, Set.of()).contains(to);
    }

    public void transition(LearningGoal goal, GoalStatus targetStatus, String operatorId) {
        if (!canTransition(goal.getStatus(), targetStatus)) {
            throw new BizException(ErrorCode.GOAL_INVALID_STATE_TRANSITION,
                    String.format("无法从 %s 转换到 %s", goal.getStatus(), targetStatus));
        }
        goal.setStatus(targetStatus);
        if (targetStatus == GoalStatus.COMPLETED) {
            goal.setCompletedAt(LocalDateTime.now());
        }
    }
}
```

### 5.3 进度计算

```java
@Service
@RequiredArgsConstructor
public class GoalProgressCalculator {

    private final GoalKnowledgePointRepository kpRepository;
    private final LearningRecordClient learningRecordClient;

    public ProgressResult calculate(String goalId) {
        LearningGoal goal = goalRepository.findById(goalId)
                .orElseThrow(() -> new BizException(ErrorCode.GOAL_NOT_FOUND));

        List<GoalKnowledgePoint> kps = kpRepository.findByGoalId(goalId);

        // 策略1：基于知识点掌握度平均变化
        double masteryProgress = calculateMasteryProgress(kps);

        // 策略2：基于关联任务完成率
        double taskProgress = calculateTaskProgress(goalId);

        // 策略3：基于学习时长达成率
        double timeProgress = calculateTimeProgress(goal);

        // 加权综合
        int overallProgress = (int) Math.round(
                masteryProgress * 0.4 + taskProgress * 0.4 + timeProgress * 0.2
        );
        overallProgress = Math.min(100, Math.max(0, overallProgress));

        return new ProgressResult(overallProgress, masteryProgress, taskProgress, timeProgress);
    }

    private double calculateMasteryProgress(List<GoalKnowledgePoint> kps) {
        if (kps.isEmpty()) return 0.0;
        double total = 0;
        int count = 0;
        for (GoalKnowledgePoint kp : kps) {
            if (kp.getExpectedMastery() != null && kp.getExpectedMastery() > 0) {
                double current = learningRecordClient.getCurrentMastery(kp.getKnowledgePointId());
                total += Math.min(current / kp.getExpectedMastery(), 1.0);
                count++;
            }
        }
        return count == 0 ? 0.0 : (total / count) * 100;
    }

    private double calculateTaskProgress(String goalId) {
        TaskSummary summary = learningRecordClient.getGoalTaskSummary(goalId);
        if (summary.getTotal() == 0) return 0.0;
        return (double) summary.getCompleted() / summary.getTotal() * 100;
    }

    private double calculateTimeProgress(LearningGoal goal) {
        if (goal.getExtraConfig() == null || goal.getExtraConfig().getMetrics() == null) {
            return 0.0;
        }
        Integer targetMinutes = (Integer) goal.getExtraConfig().getMetrics().get("targetMinutes");
        if (targetMinutes == null || targetMinutes == 0) return 0.0;
        int actualMinutes = learningRecordClient.getActualMinutesForGoal(goal.getId());
        return Math.min((double) actualMinutes / targetMinutes, 1.0) * 100;
    }
}
```

### 5.4 目标过期检查定时任务

```java
@Component
@RequiredArgsConstructor
public class GoalExpireCheckJob {

    private final GoalRepository goalRepository;
    private final GoalStateMachine stateMachine;
    private final GoalEventPublisher eventPublisher;

    /**
     * 每天凌晨 02:00 执行
     */
    @Scheduled(cron = "0 0 2 * * ?")
    @Transactional(rollbackFor = Exception.class)
    public void checkExpiredGoals() {
        LocalDate today = LocalDate.now();
        List<LearningGoal> expiredGoals = goalRepository.findActiveGoalsWithTargetDateBefore(today);

        for (LearningGoal goal : expiredGoals) {
            try {
                stateMachine.transition(goal, GoalStatus.EXPIRED, "system");
                goal.setExpiredAt(LocalDateTime.now());
                goalRepository.save(goal);
                eventPublisher.publish(new GoalExpiredEvent(goal.getId(), goal.getUserId()));
            } catch (Exception e) {
                log.error("目标过期处理失败 goalId={}", goal.getId(), e);
            }
        }
    }
}
```

### 5.5 基于模板的推荐生成

```java
@Service
@RequiredArgsConstructor
public class GoalRecommendationService {

    private final GoalTemplateRepository templateRepository;
    private final LearningAnalyticsClient analyticsClient;
    private final GoalRepository goalRepository;

    public List<GoalRecommendation> recommend(String userId, int limit) {
        UserProfile profile = analyticsClient.getProfile(userId);
        List<WeakPoint> weakPoints = analyticsClient.getWeakPoints(userId, 5);

        // 过滤适用模板
        List<GoalTemplate> templates = templateRepository.findActiveByGrade(profile.getGrade());

        List<GoalRecommendation> recommendations = new ArrayList<>();
        for (GoalTemplate template : templates) {
            if (!isApplicable(template, profile, weakPoints)) continue;

            GoalRecommendation rec = new GoalRecommendation();
            rec.setTitle(formatTitle(template, weakPoints));
            rec.setGoalType(template.getGoalType());
            rec.setSubjectId(pickSubject(template, weakPoints));
            rec.setTemplateId(template.getId());
            rec.setReason(generateReason(template, weakPoints));
            rec.setExpectedDifficulty(template.getExtraConfig().getExpectedDifficulty());
            recommendations.add(rec);

            if (recommendations.size() >= limit) break;
        }
        return recommendations;
    }

    private boolean isApplicable(GoalTemplate template, UserProfile profile, List<WeakPoint> weakPoints) {
        if (template.getApplicableGrades() != null
                && !template.getApplicableGrades().contains(profile.getGrade())) {
            return false;
        }
        // 避免重复推荐同类型目标
        boolean hasSimilarActive = goalRepository.existsActiveGoalByTypeAndSubject(
                profile.getUserId(), template.getGoalType(), null);
        return !hasSimilarActive;
    }
}
```

## 6. 状态流转

### 6.1 目标状态机

```text
                    ┌─────────────────────────────────────────────┐
                    │                                             │
                    ▼                                             │
    [DRAFT] ──activate──▶ [ACTIVE] ──complete──▶ [COMPLETED]      │
        │                    │    ──abandon──▶ [ABANDONED]       │
        │                    │    ──expire──▶  [EXPIRED]        │
        │               pause│                                      │
        │                    ▼                                      │
        └──abandon────▶ [PAUSED] ──resume──▶ [ACTIVE] ◀───────────┘
```

### 6.2 状态说明

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| DRAFT | 草稿，未生效 | 创建目标后默认状态 |
| ACTIVE | 进行中 | 用户激活目标 |
| PAUSED | 已暂停 | 用户手动暂停，期间不计入进度 |
| COMPLETED | 已完成 | 用户主动标记完成或系统判定达成 |
| ABANDONED | 已放弃 | 用户主动放弃 |
| EXPIRED | 已过期 | 到达 target_date 且未完成 |

### 6.3 状态转换规则

| 源状态 | 目标状态 | 触发动作 | 是否允许 | 副作用 |
|--------|----------|----------|----------|--------|
| DRAFT | ACTIVE | activate | ✅ | 触发学习计划生成（如选择） |
| DRAFT | ABANDONED | abandon | ✅ | 无 |
| ACTIVE | PAUSED | pause | ✅ | 暂停进度累计 |
| ACTIVE | COMPLETED | complete | ✅ | 触发成就、家长通知 |
| ACTIVE | ABANDONED | abandon | ✅ | 无 |
| ACTIVE | EXPIRED | expire (系统) | ✅ | 发送过期提醒 |
| PAUSED | ACTIVE | resume | ✅ | 恢复进度累计 |
| PAUSED | ABANDONED | abandon | ✅ | 无 |
| PAUSED | EXPIRED | expire (系统) | ✅ | 发送过期提醒 |
| COMPLETED | * | any | ❌ | 终态 |
| ABANDONED | * | any | ❌ | 终态 |
| EXPIRED | * | any | ❌ | 终态 |

## 7. 业务规则与约束

### 7.1 创建规则

1. **目标时间约束**：
   - `target_date` 必须 >= 当前日期
   - `target_date` 与当前日期差值建议不超过 180 天（考试备考类可放宽至 365 天）
2. **数量约束**：
   - 同一用户同时 `ACTIVE` 状态目标不超过 20 个
   - 同一用户同一学科同时 `ACTIVE` 目标不超过 5 个
3. **学段适配**：
   - 目标类型 `exam_preparation` 在小学阶段仅支持"期末考试"，不支持"中考/高考"
   - `target_exam` 需符合学生当前学段
4. **内容安全**：
   - 标题、备注需经过敏感词过滤
   - 禁止设置与学科学习无关的目标

### 7.2 进度更新规则

1. 进度每日最多更新一次快照，避免高频写入
2. 进度只增不减（除非发现数据异常需要回滚）
3. 当进度达到 100% 时，不自动标记完成，需用户确认或满足完成条件
4. 暂停期间不上报进度事件

### 7.3 完成判定规则

| 目标类型 | 完成条件 |
|----------|----------|
| DAILY | 当日关联任务全部完成 |
| WEEKLY | 本周完成率 >= 80% 且用户确认 |
| MONTHLY | 本月完成率 >= 80% 且用户确认 |
| EXAM_PREPARATION | target_date 到达且用户确认，或关联考试成绩达标 |
| SEMESTER | 学期结束且达成度评分 >= 80 |
| CUSTOM | 用户手动标记完成 |

```java
@RestControllerAdvice
public class GoalExceptionHandler {

    @ExceptionHandler(BizException.class)
    public ResponseEntity<ApiResponse<Void>> handleBizException(BizException e) {
        ErrorCode code = e.getErrorCode();
        return ResponseEntity.status(code.getHttpStatus())
                .body(ApiResponse.fail(code.getCode(), e.getMessage()));
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ApiResponse<Void>> handleValidation(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
                .map(err -> err.getField() + ": " + err.getDefaultMessage())
                .collect(Collectors.joining("; "));
        return ResponseEntity.badRequest()
                .body(ApiResponse.fail(400100, msg));
    }
}
```

## 9. 性能优化

### 9.1 缓存策略

```text
1. 用户活跃目标列表：Redis 缓存 5 分钟，Key = goal:active:{userId}
2. 目标模板列表：本地缓存 Caffeine + Redis，TTL 10 分钟
3. 目标详情：Redis 缓存 10 分钟，Key = goal:detail:{goalId}
4. 进度快照：只保留最近 30 天明细，历史数据归档到对象存储
```

### 9.2 数据库优化

1. 索引：`idx_user_status(user_id, status, target_date)` 覆盖列表查询
2. 分表：按 `user_id` 后两位分 64 张表（当单表超过 5000 万时）
3. 冷热分离：`learning_goals` 保留近 2 年活跃数据，历史归档到 `learning_goals_history`

### 9.3 并发控制

1. 目标状态转换使用数据库乐观锁（version 字段）
2. 进度更新采用"事件驱动 + 异步聚合"，避免并发写冲突
3. 同一目标同一日的快照使用 `INSERT ... ON DUPLICATE KEY UPDATE`

## 10. 安全与合规

### 10.1 权限控制

1. 学生只能操作自己的学习目标
2. 家长可查看绑定孩子的目标，但只有孩子或主管理员可修改
3. 管理后台可查看所有目标但不可修改个人目标内容
4. 接口鉴权基于 OAuth2 / JWT，结合 RBAC

### 10.2 数据脱敏

1. 标题中如包含真实学校、教师姓名等敏感信息需脱敏展示
2. 家长端查看时遵循孩子设置的 `is_visible_to_parent` 开关
3. 运营分析使用聚合数据，不暴露单个学生详细目标

### 10.3 未成年人保护

1. 低龄学生（<8 岁）创建目标需家长确认后才生效
2. 目标内容需经过敏感词过滤
3. 目标截止日期不得超出学期/学段合理范围，避免给孩子过大压力
