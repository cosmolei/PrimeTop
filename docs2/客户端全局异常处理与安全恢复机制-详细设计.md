# 客户端全局异常处理与安全恢复机制 - 详细设计

> **模块定位**：本文档定义 PrimeTop Flutter 客户端的全局异常捕获、Error Boundary 组件框架、崩溃安全恢复和安全模式机制。区别于「错误处理与服务降级策略」（聚焦服务端错误码、HTTP异常、服务降级链路）和「客户端性能监控与用户体验度量系统」（聚焦性能指标采集与上报），本文档聚焦 **Flutter 运行时异常的捕获、隔离、恢复和用户沟通**。

## 1. 概述

### 1.1 设计目标

| 目标 | 说明 | 指标 |
|------|------|------|
| **不漏捕获** | 所有未处理异常均被全局处理器捕获，无白屏/闪退遗漏 | 捕获率 > 99.9% |
| **不扩散** | 单个页面/组件异常不影响其他页面和全局状态 | 零级联崩溃 |
| **可恢复** | 绝大多数异常场景用户可原地重试或自动恢复 | 恢复成功率 > 95% |
| **有反馈** | 异常发生时用户收到友好、分龄的错误提示 | 零技术术语暴露 |
| **可诊断** | 异常上下文（用户操作路径、状态快照）完整上报 | 有效复现率 > 60% |
| **自保护** | 连续崩溃时进入安全模式，保证基本可用 | 安全模式启动 < 3次崩溃 |

### 1.2 异常分类矩阵

| 异常来源 | Flutter 层级 | 典型场景 | 严重程度 | 恢复策略 |
|----------|-------------|---------|---------|---------|
| **Framework 异常** | `FlutterError.onError` | 布局溢出、渲染失败、Widget 生命周期违规 | P2-P3 | ErrorBoundary 隔离 |
| **Dart 未捕获异常** | `Zone` + `PlatformDispatcher.onError` | 空指针、类型错误、网络解析失败 | P1-P2 | 页面级降级 + 重试 |
| **Async 未捕获异常** | `Zone` | Future 链未 `.catchError` | P1-P2 | 自动重试 + 提示 |
| **Isolate 异常** | `Isolate.current.addErrorListener` | 后台计算 Isolate 崩溃 | P1 | 重启 Isolate |
| **Platform 异常** | `MethodChannel` 回调 | 原生插件崩溃、权限拒绝 | P1 | 功能降级 |
| **Native 崩溃** | Android `UncaughtExceptionHandler` / iOS `NSException` | SIGSEGV、SIGABRT、OOM | P0 | 安全模式重启 |
| **OOM** | 系统 Signal / `WidgetsBindingObserver.didHaveMemoryPressure` | 图片加载过多、大列表 | P0 | 释放缓存 + 降级 |

## 2. 全局异常捕获层

### 2.1 异常捕获注册

```dart
// lib/core/error/global_exception_handler.dart

class GlobalExceptionHandler {
  static GlobalExceptionHandler? _instance;
  static GlobalExceptionHandler get instance => _instance ??= GlobalExceptionHandler._();
  GlobalExceptionHandler._();

  late final ExceptionRouter _router;
  late final CrashLoopDetector _crashLoopDetector;
  late final SafeModeManager _safeModeManager;

  /// 初始化全局异常捕获 —— 在 main() 中最先调用
  void initialize() {
    _router = ExceptionRouter();
    _crashLoopDetector = CrashLoopDetector();
    _safeModeManager = SafeModeManager();

    // 1. Flutter Framework 异常（渲染、布局等）
    FlutterError.onError = _handleFlutterError;

    // 2. Dart 未捕获异步异常
    PlatformDispatcher.instance.onError = _handlePlatformError;

    // 3. 后台 Isolate 异常
    Isolate.current.addErrorListener(
      RawReceivePort((dynamic error) {
        _handleIsolateError(error);
      }).sendPort,
    );

    // 4. MethodChannel 异常
    ServicesBinding.instance.defaultBinaryMessenger
        .setMessageHandler(null, _handlePlatformMessage);
  }

  /// 在 Zone 中包裹整个 App
  static void runInErrorZone(Widget Function() appBuilder) {
    runZonedGuarded<Future<void>>(
      () async {
        // 初始化全局处理器
        GlobalExceptionHandler.instance.initialize();

        // 检查是否需要进入安全模式
        final safeMode = await SafeModeManager.shouldEnterSafeMode();
        if (safeMode) {
          GlobalExceptionHandler.instance._safeModeManager.activate();
        }

        runApp(GlobalErrorOverlay(child: appBuilder()));
      },
      _zoneErrorHandler,
      zoneSpecification: ZoneSpecification(
        // 拦截未处理的 print 以防止日志泄露敏感信息
        print: (_, __, ___, String line) {
          if (kDebugMode) {
            developer.log(line, name: 'App');
          }
        },
      ),
    );
  }

  // ---- 各层异常处理 ----

  void _handleFlutterError(FlutterErrorDetails details) {
    // 过滤已知的非致命异常
    if (_isNonFatal(details)) {
      _router.route(
        AppException(
          type: ExceptionType.flutterFramework,
          severity: Severity.low,
          source: 'FlutterError.onError',
          error: details.exceptionAsString(),
          stackTrace: details.stack,
          context: {
            'library': details.library,
            'context': details.context?.toString(),
          },
        ),
      );
      // 非致命异常仍然交给 Flutter 默认处理（红屏/日志）
      if (kDebugMode) {
        FlutterError.dumpErrorToConsole(details);
      }
      return;
    }

    // 致命异常
    _router.route(
      AppException(
        type: ExceptionType.flutterFramework,
        severity: Severity.high,
        source: 'FlutterError.onError',
        error: details.exceptionAsString(),
        stackTrace: details.stack,
        context: {
          'library': details.library,
          'context': details.context?.toString(),
        },
      ),
    );
  }

  bool _handlePlatformError(Object error, StackTrace stack) {
    _router.route(
      AppException(
        type: ExceptionType.dartUncaught,
        severity: _classifySeverity(error),
        source: 'PlatformDispatcher.onError',
        error: error,
        stackTrace: stack,
      ),
    );
    return true; // 已处理，阻止继续传播
  }

  static void _zoneErrorHandler(Object error, StackTrace stack) {
    GlobalExceptionHandler.instance._router.route(
      AppException(
        type: ExceptionType.zoneUncaught,
        severity: _classifySeverityStatic(error),
        source: 'runZonedGuarded',
        error: error,
        stackTrace: stack,
      ),
    );
  }

  void _handleIsolateError(dynamic error) {
    _router.route(
      AppException(
        type: ExceptionType.isolate,
        severity: Severity.critical,
        source: 'Isolate.errorListener',
        error: error,
        stackTrace: StackTrace.empty,
      ),
    );
  }

  // ---- 非致命异常过滤 ----

  static const _nonFatalPatterns = [
    'A RenderFlex overflowed by',
    'Image provider exception',
    'HandshakeException',
    'SocketException',
    'Looking up a deactivated widget\'s ancestor',
  ];

  bool _isNonFatal(FlutterErrorDetails details) {
    final message = details.exceptionAsString();
    return _nonFatalPatterns.any((p) => message.contains(p));
  }

  static Severity _classifySeverityStatic(Object error) {
    if (error is TypeError) return Severity.high;
    if (error is StateError) return Severity.medium;
    if (error is ArgumentError) return Severity.low;
    if (error is IOException || error is SocketException) return Severity.low;
    return Severity.medium;
  }

  Severity _classifySeverity(Object error) =>
      _classifySeverityStatic(error);
}
```

## 3. 异常路由与分类

### 3.1 异常模型

```dart
// lib/core/error/app_exception.dart

enum ExceptionType {
  flutterFramework,  // Flutter 渲染/布局异常
  dartUncaught,      // Dart 同步未捕获异常
  zoneUncaught,      // Dart 异步未捕获异常（Zone）
  isolate,           // Isolate 异常
  platformChannel,   // MethodChannel 异常
  network,           // 网络异常（已在网络层处理，此处为兜底）
  storage,           // 本地存储异常
  renderError,       // 内容渲染异常（LaTeX/公式/富文本）
  oom,               // 内存不足
  native,            // 原生层崩溃（由 Native 桥接上报）
}

enum Severity {
  critical,  // P0：应用不可用，需要安全模式/重启
  high,      // P1：当前页面不可用，需要降级/重试
  medium,    // P2：部分功能异常，可继续使用
  low,       // P3：非致命异常，不影响主流程
}

class AppException {
  final ExceptionType type;
  final Severity severity;
  final String source;
  final Object error;
  final StackTrace stackTrace;
  final Map<String, dynamic>? context;
  final DateTime timestamp;

  AppException({
    required this.type,
    required this.severity,
    required this.source,
    required this.error,
    required this.stackTrace,
    this.context,
    DateTime? timestamp,
  }) : timestamp = timestamp ?? DateTime.now();

  /// 生成用户可见的友好消息（分龄）
  String userMessage(AgeGroup ageGroup) {
    return Error MessageFactory.create(type, severity, ageGroup);
  }

  /// 生成技术摘要（用于上报）
  Map<String, dynamic> toReportJson() => {
    'type': type.name,
    'severity': severity.name,
    'source': source,
    'error': error.toString().substring(0, min(error.toString().length, 4000)),
    'stack_hash': _stackTraceHash,
    'timestamp': timestamp.toUtc().toIso8601String(),
    'context': context,
  };

  /// 堆栈哈希（用于去重和聚合）
  String get _stackTraceHash {
    final frames = stackTrace.toString().split('\n').take(5).join('\n');
    return sha256.convert(utf8.encode(frames)).toString().substring(0, 16);
  }
}
```

### 3.2 异常路由器

```dart
// lib/core/error/exception_router.dart

class ExceptionRouter {
  final List<ExceptionHandler> _handlers = [];

  void registerHandler(ExceptionHandler handler) {
    _handlers.add(handler);
  }

  void route(AppException exception) {
    // 1. 按优先级调用处理器链
    for (final handler in _handlers) {
      if (handler.canHandle(exception)) {
        handler.handle(exception);
      }
    }

    // 2. 始终上报（即使已处理）
    ErrorReporter.instance.report(exception);

    // 3. 检查崩溃循环
    CrashLoopDetector.instance.record(exception);
  }
}

abstract class ExceptionHandler {
  bool canHandle(AppException exception);
  void handle(AppException exception);
}
```

## 4. Error Boundary 组件框架

### 4.1 设计理念

Flutter 没有原生的 Error Boundary（React 有），需自行实现。核心思路：

1. **页面级 ErrorBoundary**：包裹每个页面/路由，捕获页面内的 Widget 构建异常
2. **功能级 ErrorBoundary**：包裹独立功能模块（AI对话、拍题、练习等），功能异常不影响其他功能
3. **组件级 ErrorBoundary**：包裹高风险渲染组件（LaTeX、公式、图表、富文本）

### 4.2 ErrorBoundary Widget

```dart
// lib/core/widgets/error_boundary.dart

class ErrorBoundary extends StatefulWidget {
  final Widget child;
  final Widget Function(BuildContext, AppException)? errorBuilder;
  final String? zone;              // 错误区域标识（用于路由和日志）
  final bool showRetry;            // 是否显示重试按钮
  final VoidCallback? onRetry;     // 重试回调
  final Widget? fallback;          // 降级 Widget（不依赖 errorBuilder）

  const ErrorBoundary({
    super.key,
    required this.child,
    this.errorBuilder,
    this.zone,
    this.showRetry = true,
    this.onRetry,
    this.fallback,
  });

  @override
  State<ErrorBoundary> createState() => _ErrorBoundaryState();
}

class _ErrorBoundaryState extends State<ErrorBoundary> {
  Object? _error;
  StackTrace? _stackTrace;
  int _retryCount = 0;

  static const _maxRetries = 3;

  @override
  Widget build(BuildContext context) {
    if (_error != null) {
      final exception = AppException(
        type: ExceptionType.renderError,
        severity: Severity.medium,
        source: 'ErrorBoundary[${widget.zone ?? "unnamed"}]',
        error: _error!,
        stackTrace: _stackTrace ?? StackTrace.empty,
      );

      // 优先使用自定义 errorBuilder
      if (widget.errorBuilder != null) {
        return widget.errorBuilder!(context, exception);
      }

      // 使用默认的错误展示
      return _DefaultErrorView(
        exception: exception,
        onRetry: widget.showRetry && _retryCount < _maxRetries ? _retry : null,
        zone: widget.zone,
      );
    }

    return widget.child;
  }

  void _retry() {
    setState(() {
      _error = null;
      _stackTrace = null;
      _retryCount++;
    });
    widget.onRetry?.call();
  }

  // 通过 ErrorBoundary.of(context).capture 捕获手动异常
  static void capture(BuildContext context, Object error, StackTrace stack) {
    final state = context.findAncestorStateOfType<_ErrorBoundaryState>();
    if (state != null && state.mounted) {
      state.setState(() {
        state._error = error;
        state._stackTrace = stack;
      });
    }
  }
}
```

```dart
  void initState() {
    super.initState();
    // 注册全局异常监听
    GlobalErrorHandlerRegistry.instance.addListener(_onGlobalError);
  }

  @override
  void dispose() {
    GlobalErrorHandlerRegistry.instance.removeListener(_onGlobalError);
    super.dispose();

    if (exception.severity == Severity.critical && mounted) {
      setState(() => _unhandledException = exception);
    }

    return Stack(
      children: [
        widget.child,

          _CriticalErrorOverlay(
            exception: _unhandledException!,

          ),
      ],
    );
  }
```

## 5. 崩溃安全恢复引擎

### 5.1 状态快照机制

```dart
// lib/core/recovery/state_snapshot.dart

/// 页面状态快照，用于崩溃后恢复
class StateSnapshot {
  final String route;
  final Map<String, dynamic> stateData;
  final DateTime timestamp;
  final String? restorationId;

  StateSnapshot({
    required this.route,
    required this.stateData,
    DateTime? timestamp,
    this.restorationId,
  }) : timestamp = timestamp ?? DateTime.now();

  Map<String, dynamic> toJson() => {
    'route': route,
    'state': stateData,
    'ts': timestamp.toUtc().millisecondsSinceEpoch,
    'rid': restorationId,
  };

  factory StateSnapshot.fromJson(Map<String, dynamic> json) => StateSnapshot(
    route: json['route'] as String,
    stateData: json['state'] as Map<String, dynamic>,
    restorationId: json['rid'] as String?,
  );
}

/// 状态快照管理器
class StateSnapshotManager {
  static const _boxName = 'state_snapshots';
  static const _maxSnapshots = 10;
  static const _currentRouteKey = 'current_route';

  late Box _box;

  Future<void> init() async {
    _box = await Hive.openBox(_boxName);
  }

  /// 保存当前页面状态快照
  Future<void> saveSnapshot(StateSnapshot snapshot) async {
    try {
      // 使用 route 作为 key，自动覆盖同路由旧快照
      await _box.put(snapshot.route, snapshot.toJson());

      // 保存当前路由（用于恢复时导航）
      await _box.put(_currentRouteKey, snapshot.route);

      // 清理过多的快照
      if (_box.length > _maxSnapshots + 1) {
        final keys = _box.keys
            .where((k) => k != _currentRouteKey)
            .toList();
        // 按时间排序，删除最旧的
        keys.sort((a, b) {
          final aTs = (_box.get(a) as Map)?['ts'] as int? ?? 0;
          final bTs = (_box.get(b) as Map)?['ts'] as int? ?? 0;
          return aTs.compareTo(bTs);
        });
        for (var i = 0; i < keys.length - _maxSnapshots; i++) {
          await _box.delete(keys[i]);
        }
      }
    } catch (e) {
      // 快照保存失败不应阻塞主流程
      debugPrint('StateSnapshot save failed: $e');
    }
  }

  /// 获取上次崩溃前的路由
  String? getLastRoute() {
    try {
      return _box.get(_currentRouteKey) as String?;
    } catch (_) {
      return null;
    }
  }

  /// 获取指定路由的状态快照
  StateSnapshot? getSnapshot(String route) {
    try {
      final json = _box.get(route) as Map<String, dynamic>?;
      if (json == null) return null;
      return StateSnapshot.fromJson(json);
    } catch (_) {
      return null;
    }
  }

  /// 标记已成功恢复（清除快照）
  Future<void> markRecovered(String route) async {
    await _box.delete(route);
  }
}
```

### 5.2 崩溃恢复流程

```dart
// lib/core/recovery/crash_recovery.dart

class CrashRecoveryManager {
  static CrashRecoveryManager? _instance;
  static CrashRecoveryManager get instance => _instance ??= CrashRecoveryManager._();
  CrashRecoveryManager._();

  final StateSnapshotManager _snapshotManager = StateSnapshotManager();
  final CrashLoopDetector _crashLoopDetector = CrashLoopDetector();

  /// 应用启动时检查是否需要恢复
  Future<RecoveryDecision> checkRecovery() async {
    await _snapshotManager.init();

    final crashCount = await _crashLoopDetector.getRecentCrashCount();

    // 1. 连续崩溃 >= 3 次 → 安全模式
    if (crashCount >= 3) {
      return RecoveryDecision.enterSafeMode;
    }

    // 2. 连续崩溃 1-2 次 → 恢复到首页 + 提示
    if (crashCount >= 1) {
      final lastRoute = _snapshotManager.getLastRoute();
      if (lastRoute != null && lastRoute != '/' && lastRoute != '/home') {
        return RecoveryDecision.recoverToHome(
          lastRoute: lastRoute,
          message: '应用上次意外退出，已为您恢复到首页',
        );
      }
    }

    return RecoveryDecision.normalStartup;
  }

  /// 恢复完成后调用
  Future<void> onRecoveryComplete() async {
    await _crashLoopDetector.clearCrashCount();
  }
}

enum RecoveryDecision {
  normalStartup,
  enterSafeMode,
  ;

  // 带参数的恢复决策
  static RecoveryDecision recoverToHome({
    required String lastRoute,
    required String message,
  }) => _RecoverToHome(lastRoute, message);
}

class _RecoverToHome implements RecoveryDecision {
  final String lastRoute;
  final String message;
  _RecoverToHome(this.lastRoute, this.message);
}
```

```dart
// lib/core/recovery/crash_loop_detector.dart

class CrashLoopDetector {
  static CrashLoopDetector? _instance;
  static CrashLoopDetector get instance => _instance ??= CrashLoopDetector._();
  CrashLoopDetector._();

  static const _boxName = 'crash_loop_detector';
  static const _crashTimestampsKey = 'crash_timestamps';
  static const _crashWindowMinutes = 5;  // 5 分钟内的崩溃计数
  static const _safeModeThreshold = 3;    // 3 次崩溃进入安全模式

  late Box _box;

  Future<void> init() async {
    _box = await Hive.openBox(_boxName);
  }

  /// 记录一次崩溃
  Future<void> recordCrash() async {
    final timestamps = _getTimestamps();
    timestamps.add(DateTime.now().millisecondsSinceEpoch);
    // 只保留最近 10 条
    if (timestamps.length > 10) {
      timestamps.removeRange(0, timestamps.length - 10);
    }
    await _box.put(_crashTimestampsKey, timestamps);
  }

  /// 记录一次异常（非崩溃，用于降级决策）
  void record(AppException exception) {
    if (exception.severity == Severity.critical ||
        exception.severity == Severity.high) {
      // 高严重度异常计入崩溃循环检测
      _scheduleCrashRecord();
    }
  }

  void _scheduleCrashRecord() {
    // 异步记录，避免阻塞异常处理链路
    Future.microtask(() => recordCrash());
  }

  /// 获取最近窗口内的崩溃次数
  Future<int> getRecentCrashCount() async {
    await init();
    final timestamps = _getTimestamps();
    final windowStart = DateTime.now()
        .subtract(Duration(minutes: _crashWindowMinutes))
        .millisecondsSinceEpoch;
    return timestamps.where((ts) => ts > windowStart).length;
  }

  /// 清除崩溃计数（成功恢复后调用）
  Future<void> clearCrashCount() async {
    await _box.put(_crashTimestampsKey, <int>[]);
  }

  List<int> _getTimestamps() {
    try {
      final raw = _box.get(_crashTimestampsKey) as List?;
      return raw?.cast<int>() ?? <int>[];
    } catch (_) {
      return <int>[];
    }
  }
}
```

```dart
enum SafeModeLevel {
  none,       // 正常模式
  light,      // 轻度安全模式：禁用非核心功能、关闭动画、降级图片质量
  strict,     // 严格安全模式：仅保留AI问答+教材学习，禁用所有高级功能
}

class SafeModeManager {
  static SafeModeManager? _instance;
  static SafeModeManager get instance => _instance ??= SafeModeManager._();
  SafeModeManager._();

  static const _boxName = 'safe_mode';
  static const _levelKey = 'level';
  static const _activatedAtKey = 'activated_at';

  late Box _box;
  SafeModeLevel _currentLevel = SafeModeLevel.none;

  SafeModeLevel get currentLevel => _currentLevel;
  bool get isActive => _currentLevel != SafeModeLevel.none;

  Future<void> init() async {
    _box = await Hive.openBox(_boxName);
    _currentLevel = _loadLevel();
  }

  /// 检查是否应该进入安全模式（启动时调用）
  static Future<bool> shouldEnterSafeMode() async {
    final crashCount = await CrashLoopDetector.instance.getRecentCrashCount();
    return crashCount >= 3;
  }

  /// 激活安全模式
  Future<void> activate({SafeModeLevel? level}) async {
    final crashCount = await CrashLoopDetector.instance.getRecentCrashCount();
    _currentLevel = level ?? (
      crashCount >= 5 ? SafeModeLevel.strict : SafeModeLevel.light
    );
    await _box.put(_levelKey, _currentLevel.name);
    await _box.put(_activatedAtKey, DateTime.now().toIso8601String());
  }

  /// 退出安全模式（用户手动或成功使用一段时间后）
  Future<void> deactivate() async {
    _currentLevel = SafeModeLevel.none;
    await _box.put(_levelKey, SafeModeLevel.none.name);
    await _box.delete(_activatedAtKey);
    await CrashLoopDetector.instance.clearCrashCount();
  }

  /// 功能可用性检查
  bool isFeatureAvailable(SafeModeFeature feature) {
    if (_currentLevel == SafeModeLevel.none) return true;
    if (_currentLevel == SafeModeLevel.light) {
      return _lightModeAllowed.contains(feature);
    }
    return _strictModeAllowed.contains(feature);
  }

  SafeModeLevel _loadLevel() {
    try {
      final name = _box.get(_levelKey) as String?;
      if (name == null) return SafeModeLevel.none;

      // 自动退出：安全模式激活超过 24 小时且无新崩溃
      final activatedAt = _box.get(_activatedAtKey) as String?;
      if (activatedAt != null) {
        final dt = DateTime.parse(activatedAt);
        if (DateTime.now().difference(dt).inHours >= 24) {
          return SafeModeLevel.none;
        }
      }

      return SafeModeLevel.values.firstWhere(
        (l) => l.name == name,
        orElse: () => SafeModeLevel.none,
      );
    } catch (_) {
      return SafeModeLevel.none;
    }
  }
}

enum SafeModeFeature {
  // 核心功能（严格模式可用）
  aiChat,           // AI 问答
  textbookBrowse,   // 教材浏览
  textbookSearch,   // 教材搜索

  // 扩展功能（轻度模式可用）
  photoSearch,      // 拍题搜题
  mistakeBook,      // 错题本
  exercise,         // 练习
  studyReport,      // 学习报告
  profile,          // 个人中心

  // 高级功能（仅正常模式）
  knowledgeGraph,   // 知识图谱
  voiceChat,        // 语音对话
  richAnimation,    // 动画效果
  darkTheme,        // 深色主题
  widgetDesktop,    // 桌面小组件
  liveActivity,     // 实时活动
}

const _strictModeAllowed = {
  SafeModeFeature.aiChat,
  SafeModeFeature.textbookBrowse,
  SafeModeFeature.textbookSearch,
};

const _lightModeAllowed = {
  ..._strictModeAllowed,
```

### 9.1 上报流程

```dart
// lib/core/error/error_reporter.dart

class ErrorReporter {
  static ErrorReporter? _instance;
  static ErrorReporter get instance => _instance ??= ErrorReporter._();
  ErrorReporter._();

  static const _maxQueueSize = 50;
  static const _flushInterval = Duration(seconds: 30);
  static const _maxFlushBatch = 10;

  final List<Map<String, dynamic>> _queue = [];
  Timer? _flushTimer;

  void init() {
    _flushTimer = Timer.periodic(_flushInterval, (_) => _flush());

    // 应用从后台恢复时立即上报
    WidgetsBinding.instance.addObserver(_AppLifecycleObserver(_flush));
  }

  void report(AppException exception) {
    final report = _enrich(exception);

    // 采样：同一种错误 1 分钟内只上报 1 次
    if (_isSampled(report)) return;

    _queue.add(report);

    // 崩溃级异常立即上报
    if (exception.severity == Severity.critical) {
      _flush();
    } else if (_queue.length >= _maxQueueSize) {
      _flush();
    }
  }

  Map<String, dynamic> _enrich(AppException exception) {
    return {
      ...exception.toReportJson(),
      // 设备信息
      'device': {
        'model': DeviceInfo.model,
        'os': DeviceInfo.osVersion,
        'app_version': DeviceInfo.appVersion,
        'build_number': DeviceInfo.buildNumber,
      },
      // 用户上下文
      'user': {
        'age_group': UserProfile.current?.ageGroup.name,
        'grade': UserProfile.current?.gradeCode,
        'is_safe_mode': SafeModeManager.instance.isActive,
      },
      // 内存状态
      'memory': {
        'total': ProcessInfo.currentRss,
        'peak': ProcessInfo.maxRss,
      },
      // 网络状态
      'network': ConnectivityService.instance.currentStatus.name,
    };
  }

  bool _isSampled(Map<String, dynamic> report) {
    final stackHash = report['stack_hash'] as String?;
    if (stackHash == null) return false;

    // 内存中记录最近 1 分钟已上报的 stack_hash
    final now = DateTime.now();
    _reportedHashes.removeWhere(
      (ts, hash) => now.difference(ts).inMinutes >= 1,
    );
    if (_reportedHashes.containsValue(stackHash)) return true;

    _reportedHashes[now] = stackHash;
    return false;
  }

  final Map<DateTime, String> _reportedHashes = {};

  Future<void> _flush() async {
    if (_queue.isEmpty) return;

    final batch = _queue.take(_maxFlushBatch).toList();
    _queue.removeRange(0, batch.length);

    try {
      await _apiService.batchReportErrors(batch);
    } catch (e) {
      // 上报失败，放回队列（不超过上限）
      if (_queue.length + batch.length <= _maxQueueSize) {
        _queue.insertAll(0, batch);
      }
    }
  }
}
```

### 10.2 AI 对话场景专项处理

```dart
// lib/features/ai_chat/chat_error_handler.dart

class ChatErrorHandler {
  /// 处理 SSE 流式响应中的异常
  static StreamingErrorAction handleStreamError(
    Object error,
    ChatSessionState state,
  ) {
    // 1. 网络中断 → 自动重连
    if (error is SocketException || error is TimeoutException) {
      if (state.partialAnswer.length > 50) {
        // 已有足够内容，显示已获取部分
        return StreamingErrorAction.showPartial(
          partial: state.partialAnswer,
          canResume: true,
        );
      }
      return StreamingErrorAction.retry(
        maxAttempts: 2,
        delayMs: 1000,
      );
    }

    // 2. 内容过滤 → 替换响应
    if (error is ContentFilterException) {
      return StreamingErrorAction.replace(
        message: '这个问题我暂时无法回答，换个方式试试？',
      );
    }

    // 3. JSON 解析失败 → 忽略该 chunk
    if (error is FormatException && error.toString().contains('JSON')) {
      return StreamingErrorAction.skipChunk;
    }

    // 4. 配额超限 → 提示升级
    if (error is QuotaExceededException) {
      return StreamingErrorAction.showQuotaExceeded(
        remainingSeconds: error.resetAfterSeconds,
      );
    }

    // 5. 其他 → 通用错误
    return StreamingErrorAction.showGeneric(retryable: true);
  }
}

sealed class StreamingErrorAction {
  static StreamingErrorAction retry({
    required int maxAttempts,
    required int delayMs,
  }) => _Retry(maxAttempts, delayMs);

  static StreamingErrorAction showPartial({
    required String partial,
    required bool canResume,
  }) => _ShowPartial(partial, canResume);

  static StreamingErrorAction replace({required String message}) =>
      _Replace(message);

  static StreamingErrorAction skipChunk = _SkipChunk();

  static StreamingErrorAction showQuotaExceeded({
    required int remainingSeconds,
  }) => _QuotaExceeded(remainingSeconds);

  static StreamingErrorAction showGeneric({required bool retryable}) =>
      _Generic(retryable);
}
```

```dart
// lib/core/error/memory_pressure_handler.dart

class MemoryPressureHandler extends WidgetsBindingObserver {
  static MemoryPressureHandler? _instance;
  static MemoryPressureHandler get instance =>
      _instance ??= MemoryPressureHandler._();
  MemoryPressureHandler._();

  /// 内存压力等级阈值（字节）
  static const _warningThreshold = 300 * 1024 * 1024;  // 300MB
  static const _criticalThreshold = 500 * 1024 * 1024; // 500MB

  Timer? _monitorTimer;

  void startMonitoring() {
    _monitorTimer = Timer.periodic(Duration(seconds: 30), (_) => _check());
  }

  void _check() {
    final currentRss = ProcessInfo.currentRss;

    if (currentRss > _criticalThreshold) {
      _handleCriticalPressure();
    } else if (currentRss > _warningThreshold) {
      _handleWarningPressure();
    }
  }

  @override
  void didHaveMemoryPressure() {
    // 系统级内存警告
    _handleCriticalPressure();
  }

  void _handleWarningPressure() {
    // 轻度清理
    PaintingBinding.instance.imageCache.clearLiveImages();
    PriorityQueue.instance.dropLowPriority();
  }

  void _handleCriticalPressure() {
    // 激进清理
    PaintingBinding.instance.imageCache.clear();
    PaintingBinding.instance.imageCache.clearLiveImages();
    PriorityQueue.instance.dropAllNonCritical();
    LocalSearchEngine.instance?.closeIdleIndexes();
    RenderCache.instance.clear();

    ErrorReporter.instance.report(AppException(
      type: ExceptionType.oom,
      severity: Severity.high,
      source: 'MemoryPressureHandler',
      error: 'RSS: ${ProcessInfo.currentRss}',
      stackTrace: StackTrace.current,
      context: {'action': 'critical_cleanup'},
    ));
  }
}
```

### 12.1 AsyncValue 错误统一处理

```dart
// lib/core/error/provider_error_handler.dart

/// 全局 Provider 错误观察者
/// 注册到 ProviderScope，捕获所有 Provider 异步异常
final globalErrorObserverProvider = Provider<ProviderObserver>((ref) {
  return ProviderErrorObserver();
});

class ProviderErrorObserver extends ProviderObserver {
  @override
  void providerDidFailUpdate(
    ProviderBase provider,
    Object error,
    StackTrace stackTrace,
    Ref ref,
  ) {
    // 不处理网络层的已处理异常（ApiResult模式已处理）
    if (error is ApiException) return;

    GlobalExceptionHandler.instance._router.route(
      AppException(
        type: _mapProviderError(error),
        severity: _classifyProviderError(provider, error),
        source: 'Provider[${provider.name ?? provider.runtimeType}]',
        error: error,
        stackTrace: stackTrace,
        context: {
          'provider': provider.name ?? provider.runtimeType.toString(),
        },
      ),
    );
  }

  ExceptionType _mapProviderError(Object error) {
    if (error is HiveError || error is BoxError) return ExceptionType.storage;
    if (error is SocketException) return ExceptionType.network;
    if (error is PlatformException) return ExceptionType.platformChannel;
    return ExceptionType.dartUncaught;
  }

  Severity _classifyProviderError(ProviderBase provider, Object error) {
    // 核心数据 Provider 失败 = high
    final criticalProviders = {
      userProfileProvider,
      authStateProvider,
      homeDashboardProvider,
    };
    if (criticalProviders.any((p) => p == provider)) {
      return Severity.high;
    }
    return Severity.medium;
  }
}
```

### 12.2 UI 层 AsyncValue 统一模式

```dart
// lib/core/widgets/async_value_builder.dart

class AsyncValueBuilder<T> extends StatelessWidget {
  final AsyncValue<T> value;
  final Widget Function(T data) builder;
  final Widget Function(String message, VoidCallback retry)? errorBuilder;
  final Widget? loadingWidget;
  final AgeGroup? ageGroup;

  const AsyncValueBuilder({
    super.key,
    required this.value,
    required this.builder,
    this.errorBuilder,
    this.loadingWidget,
    this.ageGroup,
  });

  @override
  Widget build(BuildContext context) {
    return value.when(
      data: builder,
      loading: () => loadingWidget ?? const Center(
        child: CircularProgressIndicator(),
      ),
      error: (error, stack) {
        final exception = AppException(
          type: ExceptionType.dartUncaught,
          severity: Severity.medium,
          source: 'AsyncValueBuilder',
          error: error,
          stackTrace: stack,
        );

        if (errorBuilder != null) {
          return errorBuilder!(
            exception.userMessage(ageGroup ?? AgeGroup.middleSchool),
            () => /* ref.invalidate */ null!,
          );
        }

        return ErrorStateWidget(
          exception: exception,
          onRetry: null, // AsyncValueBuilder 不提供重试，由父级处理
        );
      },
    );
  }
}
```
