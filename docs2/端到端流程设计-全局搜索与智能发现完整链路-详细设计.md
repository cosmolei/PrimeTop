# 端到端流程设计 - 全局搜索与智能发现完整链路

## 1. 文档概述

### 1.1 文档定位

本文档描述 PrimeTop 用户从**任意页面发起搜索 → 获取搜索建议 → 查看搜索结果 → 执行后续操作**的完整端到端链路。它将客户端搜索 UI（`客户端全局搜索与智能发现引擎`）、服务端搜索服务（`搜索服务与全文检索`）和下游业务模块（题目详情、知识点讲解、错题本等）串联为可落地的完整流程。

### 1.2 关联文档

| 文档 | 关系 |
|------|------|
| `客户端全局搜索与智能发现引擎-详细设计` | 客户端搜索 UI/UX、本地索引、搜索建议 |
| `搜索服务与全文检索-详细设计` | 服务端 ES 索引、搜索 API、分词排序 |
| `客户端本地搜索与离线内容检索引擎-详细设计` | 端侧离线全文检索 |
| `知识点体系与教材映射引擎-详细设计` | 知识点搜索结果的数据来源 |
| `题目与题库服务-详细设计` | 题目搜索结果的数据来源 |
| `错题整理-详细设计` | 错题搜索结果与后续操作 |

### 1.3 适用读者

- 客户端开发工程师（Flutter）
- 服务端开发工程师
- 测试工程师
- 产品经理

## 2. 用户旅程总览

### 2.1 主流程

```
用户点击搜索入口
    │
    ▼
搜索页面打开 → 加载搜索历史 + 热门推荐 + 智能发现
    │
    ▼
用户输入关键词
    │
    ├─ 输入中（每个字符变化）→ 实时搜索建议（本地优先 + 远程补充）
    │
    ▼
用户提交搜索 / 点击建议
    │
    ├─ 本地索引优先查询（<100ms）
    │   └─ 本地有足够结果 → 直接展示
    │
    ├─ 远程搜索服务查询（<500ms）
    │   └─ 聚合多源结果 → 分 Tab 展示
    │
    ▼
搜索结果页展示（题目 / 知识点 / 章节 / 错题 / 笔记）
    │
    ├─ 点击题目 → 进入题目详情/解析页
    ├─ 点击知识点 → 进入知识点讲解页
    ├─ 点击章节 → 进入同步课堂章节页
    ├─ 点击错题 → 进入错题详情页
    ├─ 点击笔记 → 进入笔记详情页
    └─ 空结果 → 推荐相关内容 / 引导 AI 提问
    │
    ▼
后续操作（加入错题本 / 收藏 / 开始练习 / 问 AI）
```

### 2.2 触发入口矩阵

| 入口位置 | 触发方式 | 搜索范围 | 备注 |
|----------|----------|----------|------|
| 首页搜索栏 | 点击 | 全局 | 固定顶部，输入框占位文字动态变化 |
| 底部导航搜索 Tab | 点击 | 全局 | 独立搜索 Tab（按设计配置） |
| AI 对话页搜索按钮 | 点击 | 全局 | 搜索结果可发送给 AI |
| 错题本页搜索图标 | 点击 | 错题 | 预设搜索范围为错题 |
| 同步课堂页搜索 | 点击 | 章节/知识点 | 预设搜索范围为教材内容 |
| 知识图谱页搜索 | 点击 | 知识点 | 预设搜索范围为知识点 |
| 系统搜索（iOS Spotlight / Android App Actions） | 系统唤起 | 全局 | 深链接跳转 |
| 桌面小组件搜索 | 点击 | 全局 | 跳转 APP 搜索页 |

## 3. 数据结构定义

### 3.1 搜索请求统一模型

```dart
/// 客户端搜索请求模型
class SearchRequest {
  /// 搜索关键词
  final String keyword;

  /// 搜索范围过滤（为空表示全局搜索）
  final List<SearchScope> scopes;

  /// 学段过滤
  final GradeLevel? gradeLevel;

  /// 学科过滤
  final Subject? subject;

  /// 教材版本过滤
  final String? textbookVersion;

  /// 分页参数
  final int page;
  final int pageSize;

  /// 排序方式
  final SearchSortType sort;

  /// 是否仅搜索本地
  final bool localOnly;

  /// 搜索上下文（来自哪个页面）
  final SearchContext context;
}

/// 搜索范围枚举
enum SearchScope {
  question,      // 题目
  knowledgePoint, // 知识点
  chapter,       // 教材章节
  mistake,       // 错题
  note,          // 笔记
  course,        // 课程资源
}

/// 搜索排序类型
enum SearchSortType {
  relevance,    // 相关度（默认）
  difficulty,   // 难度
  updateTime,   // 更新时间
  popularity,   // 热度
}

/// 搜索上下文
enum SearchContext {
  home,         // 首页
  aiChat,       // AI 对话
  mistakeBook,  // 错题本
  syncClass,    // 同步课堂
  knowledgeMap, // 知识图谱
  general,      // 通用
}
```

### 3.2 搜索结果统一模型

```dart
/// 搜索结果聚合模型
class SearchResponse {
  /// 搜索请求 ID（用于追踪）
  final String requestId;

  /// 总结果数
  final int totalCount;

  /// 是否有更多结果
  final bool hasMore;

  /// 按类型分组的结果
  final Map<SearchScope, List<SearchResultItem>> groupedResults;

  /// 搜索纠错建议（如果关键词有误）
  final String? correctedKeyword;

  /// 相关搜索推荐
  final List<String> relatedSearches;

  /// 搜索耗时（ms）
  final int searchTimeMs;

  /// 数据来源（local / remote / mixed）
  final SearchDataSource dataSource;
}

/// 搜索结果条目
class SearchResultItem {
  /// 唯一标识
  final String id;

  /// 结果类型
  final SearchScope type;

  /// 标题（高亮片段）
  final HighlightText title;

  /// 摘要（高亮片段）
  final HighlightText summary;

  /// 附属信息（按类型不同）
  final SearchResultMeta meta;

  /// 匹配得分（0-1）
  final double score;

  /// 是否已收藏
  final bool isFavorited;

  /// 是否在错题本中
  final bool isInMistakeBook;

  /// 后续可用操作列表
  final List<SearchItemAction> availableActions;
}

/// 高亮文本
class HighlightText {
  /// 原始文本
  final String plainText;

  /// 高亮片段列表（起始位置、结束位置）
  final List<TextHighlight> highlights;
}

class TextHighlight {
  final int start;
  final int end;
}

/// 搜索结果附属元数据（按类型区分）
sealed class SearchResultMeta {}

class QuestionMeta extends SearchResultMeta {
  final Subject subject;
  final DifficultyLevel difficulty;
  final List<String> knowledgePointNames;
  final QuestionType questionType;
  final String? textbookChapter;
}

class KnowledgePointMeta extends SearchResultMeta {
  final Subject subject;
  final String gradeRange;
  final String chapterName;
  final int relatedQuestionCount;
  final MasteryLevel? masteryLevel; // 如果用户学过
}

class ChapterMeta extends SearchResultMeta {
  final String textbookName;
  final String subjectName;
  final String gradeName;
  final String semesterName;
  final int totalKnowledgePoints;
  final double? progress; // 学习进度 0-1
}

class MistakeMeta extends SearchResultMeta {
  final Subject subject;
  final DateTime mistakeDate;
  final ErrorType errorType;
  final int reviewCount;
  final bool isMastered;
}

class NoteMeta extends SearchResultMeta {
  final DateTime createdAt;
  final DateTime updatedAt;
  final String? relatedQuestionId;
  final String? relatedKnowledgePointId;
}

/// 搜索结果可执行操作
enum SearchItemAction {
  viewDetail,       // 查看详情
  addToMistakeBook, // 加入错题本
  startPractice,    // 开始练习
  askAI,            // 问 AI
  addToFavorite,    // 收藏
  share,            // 分享
  startLearn,       // 开始学习（章节）
  viewNote,         // 查看笔记
}
```

### 5.2 搜索会话生命周期

```dart
/// 搜索会话管理器
class SearchSessionManager {
  /// 当前搜索会话 ID
  String? _currentSessionId;

  /// 本次会话搜索历史（内存）
  final List<SearchRecord> _sessionHistory = [];

  /// 开始新搜索会话
  void startSession(SearchContext context) {
    _currentSessionId = 'search_${DateTime.now().millisecondsSinceEpoch}';
    _sessionHistory.clear();
    _analytics.startSearchSession(_currentSessionId!, context);
  }

  /// 记录搜索行为
  void recordSearch(String keyword, SearchResponse response) {
    _sessionHistory.add(SearchRecord(
      sessionId: _currentSessionId!,
      keyword: keyword,
      timestamp: DateTime.now(),
      resultCount: response.totalCount,
      searchTimeMs: response.searchTimeMs,
      dataSource: response.dataSource,
    ));
  }

  /// 记录结果点击
  void recordClick(SearchResultItem item, int position) {
    _analytics.recordSearchResultClick(
      sessionId: _currentSessionId!,
      itemId: item.id,
      itemType: item.type.name,
      position: position,
    );
  }

  /// 结束搜索会话
  void endSession() {
    _analytics.endSearchSession(
      sessionId: _currentSessionId!,
      searchCount: _sessionHistory.length,
    );
    _persistSearchHistory();
  }
}
```

```dart
class GlobalSearchPage extends StatefulWidget {
  final SearchScope? initialScope;
  final SearchContext context;

  const GlobalSearchPage({
    super.key,
    this.initialScope,
    this.context = SearchContext.general,
  });

  @override
  State<GlobalSearchPage> createState() => _GlobalSearchPageState();
}

class _GlobalSearchPageState extends State<GlobalSearchPage> {
  final SearchSessionManager _sessionManager = SearchSessionManager();
  final SearchController _searchController = SearchController();
  final Debouncer _debouncer = Debouncer(milliseconds: 300);

  SearchPageState _pageState = SearchPageState.idle;
  List<SuggestionItem> _suggestions = [];
  SearchResponse? _searchResponse;
  String? _errorMessage;

  // 搜索范围 Tab
  SearchScope? _selectedScope;
  final List<SearchScope> _availableScopes = [
    SearchScope.question,
    SearchScope.knowledgePoint,
    SearchScope.chapter,
    SearchScope.mistake,
    SearchScope.note,
  ];

  @override
  void initState() {
    super.initState();
    _selectedScope = widget.initialScope;
    _sessionManager.startSession(widget.context);
    _searchController.addListener(_onSearchChanged);
    _loadIdleContent();
  }

  @override
  void dispose() {
    _sessionManager.endSession();
    _searchController.dispose();
    _debouncer.dispose();
    super.dispose();
  }

  /// 加载空闲页内容（搜索历史 + 热门搜索）
  Future<void> _loadIdleContent() async {
    final history = await _sessionManager.getLocalHistory();
    final hotWords = await _searchService.getHotSearches(
      gradeLevel: _userProfile.gradeLevel,
      limit: 10,
    );
    if (mounted) {
      setState(() {
        _idleHistory = history;
        _hotSearches = hotWords;
      });
    }
  }

  /// 搜索输入变化
  void _onSearchChanged() {
    final keyword = _searchController.text.trim();
    if (keyword.isEmpty) {
      setState(() => _pageState = SearchPageState.idle);
      return;
    }

    _debouncer.run(() => _fetchSuggestions(keyword));
  }

  /// 获取搜索建议（本地优先 + 远程补充）
  Future<void> _fetchSuggestions(String keyword) async {
    // 第一步：本地索引查询
    final localSuggestions = await _localSearchService.getSuggestions(
      keyword: keyword,
      limit: 5,
    );

    if (mounted) {
      setState(() {
        _suggestions = localSuggestions;
        _pageState = SearchPageState.typing;
      });
    }

    // 第二步：远程补充（异步，不阻塞本地展示）
    try {
      final remoteSuggestions = await _searchService.getSuggestions(
        keyword: keyword,
        limit: 10,
      );

      final merged = _mergeSuggestions(localSuggestions, remoteSuggestions);
      if (mounted) {
        setState(() => _suggestions = merged);
      }
    } catch (e) {
      // 远程失败不影响本地建议展示
      debugPrint('Remote suggestions failed: $e');
    }
  }

  /// 执行搜索
  Future<void> _executeSearch(String keyword) async {
    if (keyword.trim().isEmpty) return;

    setState(() {
      _pageState = SearchPageState.loading;
      _errorMessage = null;
    });

    // 本地搜索先出结果
    final localResults = await _localSearchService.search(
      keyword: keyword,
      scopes: _selectedScope != null ? [_selectedScope!] : null,
    );

    if (mounted && localResults.totalCount > 0) {
      setState(() {
        _searchResponse = localResults;
        _pageState = SearchPageState.results;
      });
    }

    // 远程搜索获取完整结果
    try {
      final remoteResults = await _searchService.search(
        SearchRequest(
          keyword: keyword,
          scopes: _selectedScope != null ? [_selectedScope!] : null,
          gradeLevel: _userProfile.gradeLevel,
          subject: _currentSubject,
          page: 1,
          pageSize: 20,
          sort: SearchSortType.relevance,
          context: widget.context,
        ),
      );

      final merged = _mergeResults(localResults, remoteResults);

      if (mounted) {
        setState(() {
          _searchResponse = merged;
          _pageState = SearchPageState.results;
        });
        _sessionManager.recordSearch(keyword, merged);
      }
    } catch (e) {
      if (mounted) {
        if (localResults.totalCount > 0) {
          // 远程失败但本地有结果，降级展示
          setState(() {
            _pageState = SearchPageState.results;
          });
        } else {
          setState(() {
            _pageState = SearchPageState.error;
            _errorMessage = _mapErrorMessage(e);
          });
        }
      }
    }
  }

  /// 处理结果点击
  void _onResultTap(SearchResultItem item, int position) {
    _sessionManager.recordClick(item, position);

    switch (item.type) {
      case SearchScope.question:
        context.push('/question/${item.id}');
      case SearchScope.knowledgePoint:
        context.push('/knowledge-point/${item.id}');
      case SearchScope.chapter:
        context.push('/chapter/${item.id}');
      case SearchScope.mistake:
        context.push('/mistake/${item.id}');
      case SearchScope.note:
        context.push('/note/${item.id}');
      case SearchScope.course:
        context.push('/course/${item.id}');
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: _buildSearchAppBar(),
      body: _buildBody(),
    );
  }

  Widget _buildBody() {
    return switch (_pageState) {
      SearchPageState.idle => _buildIdleContent(),
      SearchPageState.typing => _buildSuggestions(),
      SearchPageState.loading => _buildLoadingSkeleton(),
      SearchPageState.results => _buildSearchResults(),
      SearchPageState.empty => _buildEmptyResult(),
      SearchPageState.error => _buildErrorState(),
    };
  }

  /// 搜索结果页面：Tab + 列表
  Widget _buildSearchResults() {
    final response = _searchResponse!;
    return Column(
      children: [
        // 范围过滤 Tab
        _buildScopeTabs(response),
        // 搜索结果列表
        Expanded(
          child: _buildResultList(response),
        ),
      ],
    );
  }

  /// 范围 Tab（展示各类型数量）
  Widget _buildScopeTabs(SearchResponse response) {
    return SingleChildScrollView(
      scrollDirection: Axis.horizontal,
      child: Row(
        children: [
          _buildScopeTab('全部', null, response.totalCount),
          for (final scope in _availableScopes)
            if (response.groupedResults[scope]?.isNotEmpty ?? false)
              _buildScopeTab(
                _scopeLabel(scope),
                scope,
                response.groupedResults[scope]!.length,
              ),
        ],
      ),
    );
  }

  Widget _buildScopeTab(String label, SearchScope? scope, int count) {
    final isSelected = _selectedScope == scope;
    return ChoiceChip(
      label: Text('$label($count)'),
      selected: isSelected,
      onSelected: (_) {
        setState(() => _selectedScope = scope);
        _executeSearch(_searchController.text);
      },
    );
  }

  /// 搜索结果列表
  Widget _buildResultList(SearchResponse response) {
    final items = _getFilteredItems(response);

    return ListView.builder(

          return const Center(child: CircularProgressIndicator());

        return SearchResultCard(
          item: item,
          onTap: () => _onResultTap(item, index),
          onAction: (action) => _handleAction(item, action),
        );
      },
    );
  }
}
```

### 7.2 搜索服务客户端封装

```dart
class SearchService {
  final ApiClient _apiClient;
  final SearchLocalCache _localCache;

  /// 全局搜索
  Future<SearchResponse> search(SearchRequest request) async {
    final response = await _apiClient.post(
      '/api/v1/search',
      body: _buildSearchBody(request),
      timeout: const Duration(seconds: 5),
    );

    return SearchResponse.fromJson(response);
  }

  /// 获取搜索建议
  Future<List<SuggestionItem>> getSuggestions({
    required String keyword,
    int limit = 10,
  }) async {
    final response = await _apiClient.get(
      '/api/v1/search/suggest',
      queryParameters: {'keyword': keyword, 'limit': limit},
      timeout: const Duration(milliseconds: 500),
    );

    final suggest = SearchSuggestion.fromJson(response);
    return suggest.suggestions;
  }

  /// 获取热门搜索
  Future<List<HotSearchItem>> getHotSearches({
    GradeLevel? gradeLevel,
    Subject? subject,
    int limit = 10,
  }) async {
    // 优先使用本地缓存（5分钟过期）
    final cached = await _localCache.getHotSearches(gradeLevel, subject);
    if (cached != null) return cached;

    final response = await _apiClient.get(
      '/api/v1/search/hot',
      queryParameters: {
        if (gradeLevel != null) 'gradeLevel': gradeLevel.name,
        if (subject != null) 'subject': subject.name,
        'limit': limit,
      },
    );

    final items = (response['items'] as List)
        .map((e) => HotSearchItem.fromJson(e))
        .toList();

    await _localCache.setHotSearches(gradeLevel, subject, items);
    return items;
  }

  Map<String, dynamic> _buildSearchBody(SearchRequest request) {
    return {
      'keyword': request.keyword,
      if (request.scopes.isNotEmpty)
        'scopes': request.scopes.map((s) => s.name).toList(),
      'filters': {
        if (request.gradeLevel != null)
          'gradeLevel': request.gradeLevel!.name,
        if (request.subject != null)
          'subject': request.subject!.name,
        if (request.textbookVersion != null)
          'textbookVersion': request.textbookVersion,
      },
      'pagination': {
        'page': request.page,
        'pageSize': request.pageSize,
      },
      'sort': request.sort.name,
      'context': {
        'source': request.context.name,
      },
    };
  }
}
```

```dart
class AgeAdaptiveSearchHandler {
  final GradeLevel _gradeLevel;

  /// 对关键词进行学段适配预处理
  String preprocessKeyword(String rawKeyword) {
    var keyword = rawKeyword.trim();

    if (_gradeLevel.isKindergarten) {
      // 幼儿：不做拼音纠错，支持模糊匹配
      return keyword;
    }

    if (_gradeLevel.isPrimary) {
      // 小学：支持拼音搜索
      return _expandWithPinyin(keyword);
    }

    // 初高中：标准处理
    return keyword;
  }

  /// 拼音扩展（小学适用）
  String _expandWithPinyin(String keyword) {
    // 如果输入是纯拼音，尝试转换为汉字
    // 例："erci" → "二次"
    // 例："erci hanshu" → "二次函数"
    final pinyinResult = PinyinConverter.toChinese(keyword);
    return pinyinResult ?? keyword;
  }
}
```

## 9. 错误处理与降级策略

### 9.1 错误分类

| 错误场景 | 错误码 | 处理策略 |
|----------|--------|----------|
| 关键词为空 | `SEARCH_001` | 前端拦截，不发送请求 |
| 搜索频率过高 | `SEARCH_002` | 提示用户稍后重试，本地历史仍可查看 |
| 服务端超时 | `SEARCH_003` | 展示本地结果 + 超时提示 |
| 服务端不可用 | `SEARCH_004` | 降级到纯本地搜索 |
| ES 索引异常 | `SEARCH_005` | 降级到数据库 LIKE 查询 |
| 本地索引损坏 | `SEARCH_006` | 重建本地索引 + 仅远程搜索 |

### 9.2 降级链路

```
正常流程：本地索引 + 远程 ES 搜索 → 聚合结果
    │
    ├─ 远程超时 → 仅本地结果 + 提示
    │
    ├─ 远程不可用 → 仅本地结果 + "无网络时仅展示本地内容"
    │
    ├─ ES 索引异常 → 服务端降级到 DB LIKE 查询（慢但可用）
    │
    └─ 本地索引损坏 → 重建索引 + 仅远程结果
```
