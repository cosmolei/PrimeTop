# 知识点体系与教材映射引擎 - 详细设计

> **模块定位**：跨模块基础设施，为同步课堂、考点梳理、错题整理、学情分析、学习规划、RAG检索等模块提供统一的知识点树、教材映射和掌握度计算能力。

## 1. 模块概述

### 1.1 核心职责

| 职责 | 说明 |
|------|------|
| 知识点树管理 | 维护学科→大类→专题→具体知识点的层级结构 |
| 教材版本映射 | 将知识点关联到不同教材版本的章节目录 |
| 前置关系图 | 管理知识点之间的 prerequisite/related/extension 关系 |
| 掌握度计算 | 聚合答题记录、错题数据，输出知识点掌握度 |
| 跨模块查询 | 为其他模块提供统一的查询 API（按章节/按考点/按薄弱点） |
| 知识点搜索 | 支持全文检索 + 向量检索的知识点搜索 |

### 1.2 依赖关系

```
┌─────────────────────────────────────────────────┐
│           调用方（业务模块）                      │
├────────┬────────┬────────┬──────────┬───────────┤
│同步课堂│考点梳理│错题整理│学情分析  │学习规划   │
│RAG检索 │AI辅导  │拍题答疑│首页工作台│理科解题   │
├────────┴────────┴────────┴──────────┴───────────┤
│         知识点体系与教材映射引擎（本模块）         │
├─────────────────────────────────────────────────┤
│  MySQL(knowledge_points, kp_*, chapters)         │
│  Redis(知识点树缓存, 掌握度缓存)                  │
│  Milvus(知识点向量)                               │
│  Elasticsearch(知识点全文索引)                    │
└─────────────────────────────────────────────────┘
```

## 4. 核心业务逻辑

### 4.1 知识点树构建算法

知识点使用物化路径（Materialized Path）模式存储层级关系，支持高效的子树查询。

```python
class KnowledgePointService:
    """
    知识点树管理服务
    """

    def get_tree(self, subject_id: int, stage: str,
                 parent_id: int = None, depth: int = 2) -> list[dict]:
        """
        获取知识点子树

        策略：优先从 Redis 缓存获取，miss 时从 DB 加载并构建树。
        缓存 key: kp:tree:{subject_id}:{stage}:{parent_id or 'root'}
        TTL: 1小时（知识点树变更不频繁）
        """
        cache_key = f"kp:tree:{subject_id}:{stage}:{parent_id or 'root'}"
        cached = redis.get(cache_key)
        if cached:
            return json.loads(cached)

        # 查询所有匹配的知识点
        if parent_id:
            parent = self._get_kp(parent_id)
            prefix = parent['path']
            max_level = parent['level'] + depth
            rows = db.query("""
                SELECT * FROM knowledge_points
                WHERE subject_id = %s AND stage = %s
                  AND path LIKE CONCAT(%s, '%%')
                  AND level <= %s
                  AND status = 1
                ORDER BY path, id
            """, [subject_id, stage, prefix, max_level])
        else:
            max_level = depth
            rows = db.query("""
                SELECT * FROM knowledge_points
                WHERE subject_id = %s AND stage = %s
                  AND level <= %s
                  AND status = 1
                ORDER BY path, id
            """, [subject_id, stage, max_level])

        tree = self._build_tree(rows)
        redis.setex(cache_key, 3600, json.dumps(tree, ensure_ascii=False))
        return tree

    def _build_tree(self, rows: list[dict]) -> list[dict]:
        """将扁平列表构建为嵌套树结构"""
        node_map = {}
        roots = []
        for row in rows:
            node = {**row, 'children': []}
            node_map[row['id']] = node
            if row['parent_id'] and row['parent_id'] in node_map:
                node_map[row['parent_id']]['children'].append(node)
            else:
                roots.append(node)
        return roots
```

### 4.2 掌握度计算引擎

```python
class MasteryEngine:
    """
    知识点掌握度计算引擎

    综合考虑：正确率、练习量、时间衰减、错误严重度
    """

    # 掌握度等级阈值
    LEVEL_THRESHOLDS = {
        0: 0,      # 未接触
        1: 20,     # 了解
        2: 45,     # 理解
        3: 70,     # 掌握
        4: 90,     # 精通
    }

    # 遗忘曲线参数（Ebbinghaus）
    FORGETTING_RATE = 0.3        # 基础遗忘速率
    REVIEW_STRENGTH_FACTOR = 0.5 # 每次复习对记忆强度的增强

    def calculate_mastery_score(self, user_id: int, kp_id: int) -> dict:
        """
        计算某用户某知识点的掌握度

        公式: score = base_score * time_decay * difficulty_modifier

        - base_score = weighted_accuracy * quantity_bonus
        - time_decay = e^(-FORGETTING_RATE * days_since_last_practice / retention_strength)
        - difficulty_modifier = f(kp.difficulty, kp.importance)
        """
        # 获取原始数据
        stats = db.query_one("""
            SELECT ukp.*, kp.difficulty, kp.importance, kp.frequency
            FROM user_kp_mastery ukp
            JOIN knowledge_points kp ON kp.id = ukp.kp_id
            WHERE ukp.user_id = %s AND ukp.kp_id = %s
        """, [user_id, kp_id])

        if not stats or stats['total_attempts'] == 0:
            return {
                'mastery_level': 0,
                'mastery_score': 0.0,
                'needs_review': False,
            }

        # 1. 正确率（加权：近期答对权重更高）
        accuracy = stats['correct_count'] / stats['total_attempts']

        # 2. 练习量加成（鼓励多练习，但有上限）
        quantity_bonus = min(1.0, 1.0 + math.log1p(stats['total_attempts']) * 0.05)

        # 3. 基础分数
        base_score = accuracy * quantity_bonus * 100

        # 4. 时间衰减
        if stats['last_practiced']:
            days_since = (datetime.utcnow() - stats['last_practiced']).days
            # 记忆强度：练习次数越多，遗忘越慢
            retention = 1.0 + math.log1p(stats['total_attempts']) * 0.2
            time_decay = math.exp(-self.FORGETTING_RATE * days_since / retention)
        else:
            time_decay = 0.5  # 从未练习过

        # 5. 难度修正（高难度知识点，掌握门槛稍低）
        difficulty_modifier = 1.0 + (3 - stats['difficulty']) * 0.02

        # 6. 最终分数
        final_score = round(base_score * time_decay * difficulty_modifier, 2)
        final_score = max(0.0, min(100.0, final_score))

        # 7. 确定等级
        mastery_level = 0
        for level, threshold in sorted(self.LEVEL_THRESHOLDS.items(), reverse=True):
            if final_score >= threshold:
                mastery_level = level
                break

        # 8. 是否需要复习（基于遗忘曲线预测）
        needs_review, next_review = self._calculate_review_schedule(
            final_score, stats['total_attempts'], stats['last_practiced']
        )

        # 9. 写回
        db.execute("""
            INSERT INTO user_kp_mastery (user_id, kp_id, mastery_level, mastery_score,
                total_attempts, correct_count, mistake_count, last_practiced,
                needs_review, next_review_at)
            VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
            ON DUPLICATE KEY UPDATE
                mastery_level = VALUES(mastery_level),
                mastery_score = VALUES(mastery_score),
                needs_review = VALUES(needs_review),
                next_review_at = VALUES(next_review_at)
        """, [user_id, kp_id, mastery_level, final_score,
              stats['total_attempts'], stats['correct_count'], stats['mistake_count'],
              stats['last_practiced'], needs_review, next_review])

        # 清除缓存
        self._invalidate_mastery_cache(user_id, kp_id)

        return {
            'mastery_level': mastery_level,
            'mastery_score': final_score,
            'needs_review': needs_review,
            'next_review_at': next_review,
        }

    def _calculate_review_schedule(self, score: float, attempts: int,
                                    last_practiced: datetime) -> tuple[bool, datetime]:
        """
        基于SM-2变体算法计算复习计划

        interval = base_interval * ease_factor
        ease_factor 根据掌握度和练习次数动态调整
        """
        if score >= 90:
            # 精通：长间隔
            interval_days = min(30, 7 * (1 + math.log1p(attempts) * 0.5))
            return False, None
        elif score >= 70:
            interval_days = min(14, 3 * (1 + math.log1p(attempts) * 0.3))
            next_review = last_practiced + timedelta(days=interval_days)
            return datetime.utcnow() >= next_review, next_review
        elif score >= 45:
            interval_days = min(7, 2 * (1 + math.log1p(attempts) * 0.2))
            next_review = last_practiced + timedelta(days=interval_days)
            return datetime.utcnow() >= next_review, next_review
        else:
            # 低掌握度：建议尽快复习
            return True, datetime.utcnow() + timedelta(hours=12)
```

### 4.4 前置链回溯（薄弱点归因）

```python
class PrerequisiteChainService:
    """
    知识点前置链回溯服务

    用途：当某知识点掌握度低时，回溯找前置薄弱点
    场景：学习规划生成、薄弱点诊断
    """

    def trace_weak_prerequisites(self, user_id: int, kp_id: int,
                                  max_depth: int = 5) -> list[dict]:
        """
        BFS回溯前置链，找出掌握度不达标的前置知识点
        """
        result = []
        visited = {kp_id}
        queue = deque([(kp_id, 0)])  # (当前kp_id, 深度)

        while queue:
            current_kp, depth = queue.popleft()
            if depth >= max_depth:
                continue

            # 查找直接前置知识点
            prereqs = db.query("""
                SELECT kp2.*, kp_rel.relation_type, kp_rel.strength
                FROM kp_prerequisites kp_rel
                JOIN knowledge_points kp2 ON kp2.id = kp_rel.prereq_kp_id
                WHERE kp_rel.kp_id = %s AND kp2.status = 1
                ORDER BY kp_rel.strength DESC
            """, [current_kp])

            for prereq in prereqs:
                if prereq['id'] in visited:
                    continue
                visited.add(prereq['id'])

                # 获取用户对该前置知识点的掌握度
                mastery = self._get_user_mastery(user_id, prereq['id'])

                chain_item = {
                    'depth': depth + 1,
                    'kp_id': prereq['id'],
                    'name': prereq['name'],
                    'relation_type': prereq['relation_type'],
                    'strength': prereq['strength'],
                    'mastery': mastery,
                    'is_weak': mastery['mastery_level'] < 3 if mastery else True,
                }
                result.append(chain_item)

                # 如果前置知识点也薄弱，继续回溯
                if chain_item['is_weak']:
                    queue.append((prereq['id'], depth + 1))

        return result
```

```python
def invalidate_kp_cache(kp_id: int, subject_id: int, stage: str):
    """知识点数据变更时，批量失效相关缓存"""
    pipe = redis.pipeline()

    # 1. 详情缓存
    pipe.delete(f"kp:detail:{kp_id}")

    # 2. 树缓存（可能影响多个parent）
    kp = db.query_one("SELECT parent_id, path FROM knowledge_points WHERE id = %s", [kp_id])
    if kp:
        # 当前节点的子树缓存
        pipe.delete(f"kp:tree:{subject_id}:{stage}:{kp_id}")
        # 父节点的子树缓存
        if kp['parent_id']:
            pipe.delete(f"kp:tree:{subject_id}:{stage}:{kp['parent_id']}")
        # 根节点缓存
        pipe.delete(f"kp:tree:{subject_id}:{stage}:root")

    # 3. 前置链缓存
    pipe.delete(f"kp:prereq-chain:{kp_id}")

    pipe.execute()

def invalidate_mastery_cache(user_id: int, kp_id: int = None):
    """掌握度数据变更时，失效相关缓存"""
    pipe = redis.pipeline()
    if kp_id:
        pipe.delete(f"kp:mastery:{user_id}:{kp_id}")
    pipe.delete(f"kp:mastery:summary:{user_id}")
    pipe.execute()
```

### 7.2 循环依赖检测

```python
def validate_prerequisite(kp_id: int, prereq_kp_id: int) -> bool:
    """
    检测是否会产生循环前置关系

    方法：从 prereq_kp_id 出发，BFS遍历其所有前置知识点，
    如果经过 kp_id，则会产生循环。
    """
    if kp_id == prereq_kp_id:
        return False  # 不能自引用

    visited = set()
    queue = deque([prereq_kp_id])

    while queue:
        current = queue.popleft()
        if current == kp_id:
            return False  # 发现循环

        if current in visited:
            continue
        visited.add(current)

        # 查找 current 的所有前置
        parents = db.query("""
            SELECT prereq_kp_id FROM kp_prerequisites WHERE kp_id = %s
        """, [current])
        for p in parents:
            queue.append(p['prereq_kp_id'])

    return True  # 无循环，可以创建
```

## 8. 性能考虑

### 8.1 数据量预估

| 数据 | 预估量 | 增长速度 |
|------|--------|---------|
| knowledge_points | ~50,000 | 缓慢（每学期新增学科内容） |
| kp_chapter_mapping | ~200,000 | 缓慢 |
| kp_prerequisites | ~100,000 | 缓慢 |
| user_kp_mastery | 亿级（用户数 × 活跃知识点） | 随用户量线性增长 |

### 8.2 优化策略

1. **知识点树**：数据量小（~5万），全量缓存到 Redis，后台编辑时主动失效
2. **掌握度查询**：高频读低频写，使用 Redis 缓存热点用户数据，批量查询使用 `MGET`
3. **掌握度计算**：异步计算（Celery），答题后不阻塞主流程
4. **user_kp_mastery 大表**：按 user_id 分表（或使用 TiDB），避免单表过大
5. **知识点搜索**：Elasticsearch 索引，知识点变更时同步更新
6. **物化路径索引**：`path` 字段建立索引，支持 `LIKE '/1/5/%'` 高效子树查询

### 8.3 掌握度批量计算（定时任务）

```python
@celery_app.task
def daily_mastery_recalculation():
    """
    每日凌晨执行：
    1. 扫描所有 needs_review=true 但 next_review_at 已过期的记录
    2. 重新计算时间衰减后的掌握度
    3. 更新 needs_review 状态
    """
    # 分页处理，避免一次性加载过多数据
    page = 0
    batch_size = 1000

    while True:
        records = db.query("""
            SELECT user_id, kp_id FROM user_kp_mastery
            WHERE needs_review = 1
               OR (mastery_score > 0 AND last_practiced < DATE_SUB(NOW(), INTERVAL 7 DAY))
            ORDER BY last_practiced ASC
            LIMIT %s OFFSET %s
        """, [batch_size, page * batch_size])

        if not records:
            break

        for record in records:
            try:
                MasteryEngine().calculate_mastery_score(
                    record['user_id'], record['kp_id']
                )
            except Exception as e:
                logger.warning(f"掌握度重算失败: user={record['user_id']}, kp={record['kp_id']}: {e}")

        page += 1
        time.sleep(0.1)  # 限流
```
