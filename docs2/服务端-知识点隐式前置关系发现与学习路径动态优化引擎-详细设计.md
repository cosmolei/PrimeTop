# 知识点隐式前置关系发现与学习路径动态优化引擎 - 详细设计

## 1. 概述

### 1.1 模块定位

本引擎负责通过大规模学生答题行为数据和学习轨迹分析，**自动发现知识点之间的隐式前置依赖关系**（即未被课程大纲和知识图谱显式标注、但在实际学习中确实存在的先修关系），并基于发现结果持续优化个性化学习路径推荐。

### 1.2 与现有模块的区别

| 现有模块 | 职责 | 本模块差异 |
|---------|------|-----------|
| 教育知识点前置依赖检测与学习路径推荐服务 | 基于知识图谱中**已标注**的前置关系做路径推荐 | 本模块**发现未标注的隐式**前置关系 |
| 全知识图谱学习路径智能规划与全局最优寻路引擎 | 在已知图结构上做全局寻路 | 本模块**补全图结构**中缺失的边 |
| 学习路径效果分析与学习行为序列模式挖掘引擎 | 分析现有路径的教学效果 | 本模块从效果数据**反推**结构缺失 |
| 知识图谱数据版本控制与知识点全生命周期管理引擎 | 管理知识图谱的版本和生命周期 | 本模块是知识图谱**边的数据驱动补全源** |
| 知识追踪模型引擎与学生能力动态评估服务 | 追踪学生在各知识点上的掌握度 | 本模块消费掌握度数据做**跨知识点关联分析** |

### 1.3 设计目标

1. **隐式前置发现**：从学生答题数据中挖掘 "先学 A 再学 B 效果显著优于反过来" 的模式
2. **置信度评估**：对发现的隐式关系进行统计显著性检验和置信度评分
3. **人工审核闭环**：将高置信度发现推送给教研团队审核，审核通过后写入知识图谱
4. **学习路径优化**：利用补全后的前置关系图重新规划学习路径
5. **效果回溯验证**：对比采用新前置关系前后学生的学习效果，形成闭环验证

### 1.4 适用范围

- 学段：小学至高中全学段
- 学科：全部学科（数学、物理、化学、生物、语文、英语、历史、地理、政治）
- 数据源：练习答题记录、AI 辅导对话、章节学习序列、错题数据

## 2. 核心概念定义

### 2.1 显式前置关系（Explicit Prerequisite）

知识图谱中由教研团队手动标注的前置关系，表示为有向边 `A → B`（A 是 B 的前置知识点）。

### 2.2 隐式前置关系（Implicit Prerequisite）

通过数据分析发现的、具有统计学显著性的前置关系，但尚未被教研团队确认。表示为虚线边 `A ⇢ B`。

### 2.3 前置关系强度（Prerequisite Strength）

衡量一个隐式前置关系可靠程度的综合评分，范围 `[0, 1]`，综合考虑以下因素：
- 统计显著性（p-value）
- 效应量（Cohen's d / odds ratio）
- 样本量充足度
- 跨学段/学科/教材版本的一致性
- 时间衰减因子

### 2.4 学习序列效能（Sequence Efficacy）

衡量 "先学 A 再学 B" 相对于 "先学 B 再学 A" 或 "同时学" 的学习效果差异，用 B 的掌握度提升量来量化。

## 4. 核心算法设计

### 4.1 隐式前置关系发现算法

#### 4.1.1 算法总体流程

```
┌──────────────────────────────────────────────────────┐
│                  数据采集与预处理                       │
│  (答题记录 + 学习序列 + 时间戳 + 掌握度评分)             │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│              知识点对共现频率统计                       │
│  (筛选出现在同一学生轨迹中频次 ≥ N 的知识点对)           │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│              学习序列效能计算                           │
│  (对比 "先A后B" vs "先B后A" vs "同时学" 的掌握度差异)    │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│              统计显著性检验                            │
│  (Mann-Whitney U 检验 + 效应量计算 + Bootstrap)        │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│              置信度综合评分                            │
│  (p-value + effect_size + sample_size + consistency)  │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│              过滤与去噪                               │
│  (排除已显式标注的关系 + 移除反向重复 + 阈值过滤)         │
└──────────────────┬───────────────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────────────┐
│              写入候选表 + 推送审核                      │
└──────────────────────────────────────────────────────┘
```

#### 4.1.2 核心算法实现

```python
import numpy as np
from scipy import stats
from typing import List, Dict, Tuple, Optional
from dataclasses import dataclass
from datetime import datetime, timedelta
import asyncio

@dataclass
class LearningTrace:
    """单个学生的知识点学习轨迹"""
    student_id: int
    knowledge_points: List[Dict]  # [{"kp_id": 101, "timestamp": ..., "mastery": 0.85, "source": "PRACTICE"}, ...]

@dataclass
class KPPairEfficacy:
    """知识点对学习效能"""
    kp_id_a: int
    kp_id_b: int
    a_first_b_mastery: List[float]   # 先学A后学B的学生在B上的掌握度分布
    b_first_a_mastery: List[float]   # 先学B后学A的学生在A上的掌握度分布
    simultaneous_mastery: List[float]  # 同时学习的掌握度分布
    a_first_count: int
    b_first_count: int
    simul_count: int

@dataclass
class PrerequisiteCandidate:
    """隐式前置关系候选"""
    kp_id_a: int           # 推定的前置知识点
    kp_id_b: int           # 推定的后续知识点
    confidence_score: float
    effect_size: float
    p_value: float
    sample_size: int
    a_first_b_mean: float
    b_first_a_mean: float


class ImplicitPrerequisiteDiscoveryEngine:
    """隐式前置关系发现引擎"""

    # 配置参数
    MIN_CO_occURRENCE = 50       # 最小共现次数（知识点对至少出现在N个学生轨迹中）
    MIN_GROUP_SIZE = 30          # 每个学习序列组的最小样本量
    MIN_EFFECT_SIZE = 0.2        # 最小效应量阈值（Cohen's d）
    MAX_P_VALUE = 0.01           # 最大 p-value 阈值
    MIN_CONFIDENCE = 0.65        # 最小综合置信度
    MASTERY_THRESHOLD = 0.7      # 掌握度阈值（用于判定"学会"）
    TIME_WINDOW_DAYS = 90        # 学习序列时间窗口（天）
    LEARNING_GAP_THRESHOLD = 14  # 两个知识点的学习间隔超过此天数才算"先后学"而非"同时学"

    def __init__(self, db_pool, redis_client, kp_graph_service):
        self.db = db_pool
        self.redis = redis_client
        self.kp_graph = kp_graph_service  # 已有知识图谱服务

    async def run_discovery_pipeline(
        self,
        subject: str,
        grade_range: str,
        lookback_days: int = 180
    ) -> List[PrerequisiteCandidate]:
        """运行完整的隐式前置关系发现流水线"""

        # Step 1: 采集学习轨迹数据
        traces = await self._collect_learning_traces(subject, grade_range, lookback_days)
        if len(traces) < 100:
            return []  # 样本不足

        # Step 2: 提取知识点对共现
        kp_pairs = self._extract_co_occurrence_pairs(traces)
        kp_pairs = {pair: data for pair, data in kp_pairs.items()
                    if data.a_first_count + data.b_first_count + data.simul_count >= self.MIN_CO_occURRENCE}

        # Step 3: 获取已知显式前置关系（用于过滤）
        explicit_edges = await self.kp_graph.get_all_prerequisite_edges(subject)

        # Step 4: 对每个知识点对执行统计分析
        candidates = []
        for (kp_a, kp_b), efficacy in kp_pairs.items():
            # 跳过已显式标注的关系（任一方向）
            if (kp_a, kp_b) in explicit_edges or (kp_b, kp_a) in explicit_edges:
                continue

            candidate = self._analyze_pair(efficacy, subject, grade_range)
            if candidate and candidate.confidence_score >= self.MIN_CONFIDENCE:
                candidates.append(candidate)

        # Step 5: 去重和排序
        candidates = self._deduplicate(candidates)
        candidates.sort(key=lambda c: c.confidence_score, reverse=True)

        # Step 6: 持久化
        await self._persist_candidates(candidates, subject, grade_range)

        # Step 7: 为高置信度候选创建审核任务
        high_conf = [c for c in candidates if c.confidence_score >= 0.8]
        await self._create_review_tasks(high_conf)

        return candidates

    async def _collect_learning_traces(
        self,
        subject: str,
        grade_range: str,
        lookback_days: int
    ) -> List[LearningTrace]:
        """采集学生学习轨迹数据"""

        cutoff_date = datetime.now() - timedelta(days=lookback_days)

        # 从答题记录表、AI辅导对话、同步课堂进度等数据源聚合
        query = """
            SELECT
                student_id,
                kp_id,
                first_learned_at,
                latest_mastery_score,
                source
            FROM (
                -- 答题记录中的知识点首次学习和掌握度
                SELECT
                    ar.student_id,
                    q.kp_id,
                    MIN(ar.created_at) as first_learned_at,
                    MAX(ar.mastery_after) as latest_mastery_score,
                    'PRACTICE' as source
                FROM answer_record ar
                JOIN question q ON ar.question_id = q.id
                JOIN knowledge_point kp ON q.kp_id = kp.id
                WHERE kp.subject = %s
                  AND ar.created_at >= %s
                  AND ar.mastery_after IS NOT NULL
                GROUP BY ar.student_id, q.kp_id

                UNION ALL

                -- AI辅导对话中的知识点学习
                SELECT
                    ac.student_id,
                    akp.kp_id,
                    MIN(ac.created_at) as first_learned_at,
                    MAX(akp.mastery_delta + COALESCE(ac.prior_mastery, 0)) as latest_mastery_score,
                    'AI_TUTOR' as source
                FROM ai_conversation ac
                JOIN ai_conversation_kp akp ON ac.id = akp.conversation_id
                JOIN knowledge_point kp ON akp.kp_id = kp.id
                WHERE kp.subject = %s
                  AND ac.created_at >= %s
                GROUP BY ac.student_id, akp.kp_id

                UNION ALL

                -- 同步课堂学习中的知识点
                SELECT
                    slp.student_id,
                    ckp.kp_id,
                    MIN(slp.started_at) as first_learned_at,
                    slp.mastery_score as latest_mastery_score,
                    'TEXTBOOK' as source
                FROM sync_lesson_progress slp
                JOIN chapter_kp ckp ON slp.chapter_id = ckp.chapter_id
                JOIN knowledge_point kp ON ckp.kp_id = kp.id
                WHERE kp.subject = %s
                  AND slp.started_at >= %s
                  AND slp.mastery_score IS NOT NULL
                GROUP BY slp.student_id, ckp.kp_id
            ) combined
            WHERE latest_mastery_score IS NOT NULL
              AND latest_mastery_score BETWEEN 0 AND 1
            ORDER BY student_id, first_learned_at
        """

        rows = await self.db.fetch(query, subject, cutoff_date, subject, cutoff_date, subject, cutoff_date)

        # 按学生分组
        from collections import defaultdict
        student_traces = defaultdict(list)
        for row in rows:
            student_traces[row['student_id']].append({
                'kp_id': row['kp_id'],
                'timestamp': row['first_learned_at'],
                'mastery': float(row['latest_mastery_score']),
                'source': row['source']
            })

        # 过滤学段范围
        student_ids = list(student_traces.keys())
        valid_students = await self._filter_by_grade_range(student_ids, grade_range)

        traces = []
        for sid in valid_students:
            if sid in student_traces:
                traces.append(LearningTrace(
                    student_id=sid,
                    knowledge_points=sorted(student_traces[sid], key=lambda x: x['timestamp'])
                ))

        return traces

    def _extract_co_occurrence_pairs(self, traces: List[LearningTrace]) -> Dict[Tuple[int, int], KPPairEfficacy]:
        """从学习轨迹中提取知识点共现对并计算序列效能"""

        from collections import defaultdict
        pair_data = defaultdict(lambda: {
            'a_first_b': [], 'b_first_a': [], 'simultaneous': [],
            'a_first_count': 0, 'b_first_count': 0, 'simul_count': 0
        })

        for trace in traces:
            kps = trace.knowledge_points
            # 对每对知识点，判断学习顺序
            for i in range(len(kps)):
                for j in range(i + 1, len(kps)):
                    kp_a_data = kps[i]
                    kp_b_data = kps[j]
                    kp_a, kp_b = kp_a_data['kp_id'], kp_b_data['kp_id']
                    time_gap = (kp_b_data['timestamp'] - kp_a_data['timestamp']).days

                    # 确保 kp_a < kp_b 以避免重复
                    pair_key = (min(kp_a, kp_b), max(kp_a, kp_b))
                    actual_a, actual_b = pair_key

                    if time_gap <= self.LEARNING_GAP_THRESHOLD:
                        # 同时学习
                        pair_data[pair_key]['simultaneous'].append(kp_b_data['mastery'])
                        pair_data[pair_key]['simul_count'] += 1
                    else:
                        if kp_a == actual_a:
                            # 先学小的ID，后学大的ID
                            pair_data[pair_key]['a_first_b'].append(kp_b_data['mastery'])
                            pair_data[pair_key]['a_first_count'] += 1
                        else:
                            # 先学大的ID，后学小的ID
                            pair_data[pair_key]['b_first_a'].append(kp_a_data['mastery'])
                            pair_data[pair_key]['b_first_count'] += 1

        # 构造 KPPairEfficacy
        result = {}
        for pair, data in pair_data.items():
            total = data['a_first_count'] + data['b_first_count'] + data['simul_count']
            if total < self.MIN_CO_occURRENCE:
                continue
            result[pair] = KPPairEfficacy(
                kp_id_a=pair[0],
                kp_id_b=pair[1],
                a_first_b_mastery=data['a_first_b'],
                b_first_a_mastery=data['b_first_a'],
                simultaneous_mastery=data['simultaneous'],
                a_first_count=data['a_first_count'],
                b_first_count=data['b_first_count'],
                simul_count=data['simul_count']
            )

        return result

    def _analyze_pair(
        self,
        efficacy: KPPairEfficacy,
        subject: str,
        grade_range: str
    ) -> Optional[PrerequisiteCandidate]:
        """对单个知识点对执行统计分析"""

        # 需要两个方向都有足够的样本，或至少一个方向有充足样本
        if (efficacy.a_first_count < self.MIN_GROUP_SIZE and
            efficacy.b_first_count < self.MIN_GROUP_SIZE):
            return None

        # 取样本量充足的方向做分析
        if efficacy.a_first_count >= self.MIN_GROUP_SIZE and efficacy.b_first_count >= self.MIN_GROUP_SIZE:
            # 双向都有足够样本：直接比较
            a_first = np.array(efficacy.a_first_b_mastery)
            b_first = np.array(efficacy.b_first_a_mastery)

            # Mann-Whitney U 检验（非参数检验，不假设正态分布）
            statistic, p_value = stats.mannwhitneyu(a_first, b_first, alternative='greater')

            # Cohen's d 效应量
            pooled_std = np.sqrt((a_first.std()**2 + b_first.std()**2) / 2)
            if pooled_std == 0:
                return None
            effect_size = (a_first.mean() - b_first.mean()) / pooled_std

            a_first_mean = float(a_first.mean())
            b_first_mean = float(b_first.mean())

        elif efficacy.a_first_count >= self.MIN_GROUP_SIZE:
            # 只有 A→B 方向有足够样本，与同时学习组对比
            a_first = np.array(efficacy.a_first_b_mastery)
            if len(efficacy.simultaneous_mastery) >= self.MIN_GROUP_SIZE:
                control = np.array(efficacy.simultaneous_mastery)
            else:
                return None  # 无法比较

            statistic, p_value = stats.mannwhitneyu(a_first, control, alternative='greater')
            pooled_std = np.sqrt((a_first.std()**2 + control.std()**2) / 2)
            if pooled_std == 0:
                return None
            effect_size = (a_first.mean() - control.mean()) / pooled_std
            a_first_mean = float(a_first.mean())
            b_first_mean = float(control.mean())
        else:
            return None

        # 阈值过滤
        if p_value > self.MAX_P_VALUE:
            return None
        if abs(effect_size) < self.MIN_EFFECT_SIZE:
            return None

        # 确定方向：如果先A后B效果更好，则A是B的前置
        if effect_size > 0:
            prereq_kp, target_kp = efficacy.kp_id_a, efficacy.kp_id_b
        else:
            prereq_kp, target_kp = efficacy.kp_id_b, efficacy.kp_id_a
            effect_size = abs(effect_size)

        # 计算综合置信度
        confidence = self._compute_confidence(
            p_value=p_value,
            effect_size=effect_size,
            sample_size=efficacy.a_first_count + efficacy.b_first_count,
            a_first_mean=a_first_mean,
            b_first_mean=b_first_mean
        )

        return PrerequisiteCandidate(
            kp_id_a=prereq_kp,
            kp_id_b=target_kp,
            confidence_score=confidence,
            effect_size=round(effect_size, 4),
            p_value=round(p_value, 8),
            sample_size=efficacy.a_first_count + efficacy.b_first_count + efficacy.simul_count,
            a_first_b_mean=round(a_first_mean, 4),
            b_first_a_mean=round(b_first_mean, 4)
        )

    def _compute_confidence(
        self,
        p_value: float,
        effect_size: float,
        sample_size: int,
        a_first_mean: float,
        b_first_mean: float
    ) -> float:
        """计算综合置信度评分"""

        # 维度1: p-value 贡献 (越小越好)
        # 使用 -log10(p_value) 归一化到 [0, 1]
        p_score = min(1.0, -np.log10(max(p_value, 1e-10)) / 4.0)  # p=0.0001 → 1.0

        # 维度2: 效应量贡献 (越大越好)
        # Cohen's d: 0.2=小, 0.5=中, 0.8=大
        e_score = min(1.0, effect_size / 0.8)

        # 维度3: 样本量充足度
        s_score = min(1.0, sample_size / 500.0)  # 500个样本 → 满分

        # 维度4: 掌握度差异显著度
        mastery_diff = abs(a_first_mean - b_first_mean)
        m_score = min(1.0, mastery_diff / 0.15)  # 15%差异 → 满分

        # 加权综合
        weights = {
            'p_value': 0.25,
            'effect_size': 0.30,
            'sample_size': 0.20,
            'mastery_diff': 0.25
        }

        confidence = (
            weights['p_value'] * p_score +
            weights['effect_size'] * e_score +
            weights['sample_size'] * s_score +
            weights['mastery_diff'] * m_score
        )

        return round(confidence, 4)

    def _deduplicate(self, candidates: List[PrerequisiteCandidate]) -> List[PrerequisiteCandidate]:
        """去重：同一知识点对只保留置信度最高的方向"""
        seen = {}
        for c in candidates:
            key = (min(c.kp_id_a, c.kp_id_b), max(c.kp_id_a, c.kp_id_b))
            if key not in seen or c.confidence_score > seen[key].confidence_score:
                seen[key] = c
        return list(seen.values())

    async def _persist_candidates(
        self,
        candidates: List[PrerequisiteCandidate],
        subject: str,
        grade_range: str
    ):
        """将候选关系写入数据库"""
        if not candidates:
            return

        values = []
        for c in candidates:
            values.append((
                c.kp_id_a, c.kp_id_b, subject, grade_range,
                c.sample_size, c.a_first_b_mean, c.b_first_a_mean,
                c.effect_size, c.p_value, c.confidence_score,
                'DISCOVERED', 'v1.0'
            ))

        insert_sql = """
            INSERT INTO implicit_prerequisite_candidate
                (kp_id_a, kp_id_b, subject, grade_range, sample_size,
                 avg_mastery_a_first, avg_mastery_b_first, effect_size,
                 p_value, confidence_score, status, discoverer_version)
            VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
            ON DUPLICATE KEY UPDATE
                sample_size = VALUES(sample_size),
                avg_mastery_a_first = VALUES(avg_mastery_a_first),
                avg_mastery_b_first = VALUES(avg_mastery_b_first),
                effect_size = VALUES(effect_size),
                p_value = VALUES(p_value),
                confidence_score = VALUES(confidence_score),
                updated_at = NOW()
        """
        await self.db.executemany(insert_sql, values)

        # 更新缓存
        await self._update_cache(candidates, subject, grade_range)

    async def _update_cache(self, candidates: List[PrerequisiteCandidate], subject: str, grade_range: str):
        """更新Redis缓存"""
        cache_key = f"implicit_prereq:{subject}:{grade_range}"
        pipe = self.redis.pipeline()
        pipe.delete(cache_key)
        for c in candidates:
            member = f"{c.kp_id_a}->{c.kp_id_b}"
            pipe.zadd(cache_key, {member: c.confidence_score})
        pipe.expire(cache_key, 21600)  # 6小时
        await pipe.execute()

    async def _create_review_tasks(self, candidates: List[PrerequisiteCandidate]):
        """为高置信度候选创建人工审核任务"""
        for c in candidates:
            # 检查是否已有待审核任务
            existing = await self.db.fetchval(
                "SELECT COUNT(*) FROM prerequisite_review_task WHERE candidate_id = %s AND task_status IN ('PENDING', 'IN_PROGRESS')",
                c.kp_id_a  # 注意：这里应该用候选记录的ID
            )
            if existing > 0:
                continue

            # 生成审核证据摘要
            evidence = {
                "summary": f"先学知识点{c.kp_id_a}后再学{c.kp_id_b}，掌握度从{c.b_first_a_mean:.1%}提升至{c.a_first_b_mean:.1%}",
                "improvement": round((c.a_first_b_mean - c.b_first_a_mean) * 100, 1),
                "effect_size_interpretation": self._interpret_effect_size(c.effect_size),
                "sample_size": c.sample_size,
                "confidence": c.confidence_score
            }

            await self.db.execute(
                """INSERT INTO prerequisite_review_task
                   (candidate_id, assigned_to, task_status, priority, evidence_summary)
                   VALUES (%s, %s, 'PENDING', %s, %s)""",
                c.kp_id_a,  # 实际应使用候选记录ID
                await self._pick_reviewer(c.kp_id_a, c.kp_id_b),
                min(10, int(c.confidence_score * 10)),
                __import__('json').dumps(evidence, ensure_ascii=False)
            )

    def _interpret_effect_size(self, d: float) -> str:
        if d < 0.2: return "可忽略"
        if d < 0.5: return "小效应"
        if d < 0.8: return "中等效应"
        return "大效应"

    async def _pick_reviewer(self, kp_a: int, kp_b: int) -> int:
        """选择审核人：优先分配给负责该学科知识点的教研人员"""
        # 简化实现：轮询分配给有该学科审核权限的教研人员
        return await self.db.fetchval(
            """SELECT u.id FROM users u
               JOIN user_role ur ON u.id = ur.user_id
               JOIN knowledge_point kp ON kp.id IN (%s, %s)
               WHERE ur.role = 'CONTENT_REVIEWER'
                 AND u.subject = kp.subject
               ORDER BY RAND() LIMIT 1""",
            kp_a, kp_b
        )

    async def _filter_by_grade_range(self, student_ids: List[int], grade_range: str) -> List[int]:
        """按学段范围过滤学生"""
        if not student_ids:
            return []
        min_grade, max_grade = map(int, grade_range.split('-'))
        placeholders = ','.join(['%s'] * len(student_ids))
        rows = await self.db.fetch(
            f"""SELECT user_id FROM student_profile
                WHERE user_id IN ({placeholders})
                  AND grade BETWEEN %s AND %s""",
            *student_ids, min_grade, max_grade
        )
        return [r['user_id'] for r in rows]
```

### 4.2 学习路径动态优化算法

```python
class LearningPathOptimizer:
    """基于隐式前置关系的学习路径优化器"""

    def __init__(self, db_pool, redis_client, kp_graph_service):
        self.db = db_pool
        self.redis = redis_client
        self.kp_graph = kp_graph_service

    async def optimize_learning_path(
        self,
        student_id: int,
        target_kp_ids: List[int],
        subject: str,
        grade_range: str
    ) -> List[Dict]:
        """
        为学生优化学习路径，融入隐式前置关系

        Args:
            student_id: 学生ID
            target_kp_ids: 目标知识点列表
            subject: 学科
            grade_range: 学段范围

        Returns:
            优化后的学习路径，每步包含知识点、推荐学习顺序、前置关系标注
        """
        # 1. 获取学生的当前掌握度
        mastered_kps = await self._get_student_masteries(student_id, subject)

        # 2. 获取显式前置关系图
        explicit_graph = await self.kp_graph.get_prerequisite_subgraph(
            target_kp_ids, subject, depth=3
        )

        # 3. 获取隐式前置关系
        implicit_edges = await self._get_implicit_edges(subject, grade_range)

        # 4. 合并图结构
        merged_graph = self._merge_graphs(explicit_graph, implicit_edges)

        # 5. 过滤已掌握的知识点
        pending_kps = set(target_kp_ids) - mastered_kps
        # 加入路径中需要但尚未掌握的前置知识点
        required_kps = self._find_required_precursors(pending_kps, merged_graph, mastered_kps)

        # 6. 拓扑排序 + 贪心优化
        optimized_path = self._topological_sort_with_optimization(
            required_kps, merged_graph, mastered_kps, student_id
        )

        # 7. 标注路径中每步的前置关系来源
        annotated_path = self._annotate_path(optimized_path, explicit_graph, implicit_edges)

        return annotated_path

    async def _get_implicit_edges(self, subject: str, grade_range: str) -> Dict[Tuple[int, int], float]:
        """从缓存获取高置信度隐式前置关系"""
        cache_key = f"implicit_prereq:{subject}:{grade_range}"
        raw = await self.redis.zrange(cache_key, 0, -1, withscores=True)
        edges = {}
        for member, score in raw:
            parts = member.decode().split('->')
            if len(parts) == 2:
                edges[(int(parts[0]), int(parts[1]))] = score
        return edges

    def _merge_graphs(
        self,
        explicit_graph: Dict[int, List[int]],
        implicit_edges: Dict[Tuple[int, int], float]
    ) -> Dict[int, List[Tuple[int, str, float]]]:
        """
        合并显式和隐式图

        Returns:
            adjacency_list[kp_id] = [(successor_kp_id, edge_type, confidence), ...]
        """
        merged = {}
        # 加入显式边
        for kp_id, successors in explicit_graph.items():
            if kp_id not in merged:
                merged[kp_id] = []
            for succ in successors:
                merged[kp_id].append((succ, 'EXPLICIT', 1.0))

        # 加入隐式边
        for (a, b), confidence in implicit_edges.items():
            if a not in merged:
                merged[a] = []
            # 避免重复
            if not any(s == b for s, _, _ in merged[a]):
                merged[a].append((b, 'IMPLICIT', confidence))

        return merged

    def _find_required_precursors(
        self,
        target_kps: set,
        graph: Dict,
        mastered: set
    ) -> set:
        """找到所有需要学习的前置知识点（BFS向上遍历）"""
        required = set()
        queue = list(target_kps)
        visited = set()

        while queue:
            kp = queue.pop(0)
            if kp in visited or kp in mastered:
                continue
            visited.add(kp)
            required.add(kp)

            # 找该知识点的前置
            for src, successors in graph.items():
                for succ, _, _ in successors:
                    if succ == kp and src not in mastered and src not in visited:
                        queue.append(src)

        return required

    def _topological_sort_with_optimization(
        self,
        kp_set: set,
        graph: Dict,
        mastered: set,
        student_id: int
    ) -> List[int]:
        """拓扑排序 + 置信度优先的贪心优化"""
        from collections import defaultdict, deque

        # 构建子图（只包含需要的知识点）
        in_degree = defaultdict(int)
        adj = defaultdict(list)
        for kp in kp_set:
            in_degree.setdefault(kp, 0)

        for src, successors in graph.items():
            if src not in kp_set:
                continue
            for succ, edge_type, confidence in successors:
                if succ in kp_set:
                    adj[src].append((succ, edge_type, confidence))
                    in_degree[succ] = in_degree.get(succ, 0) + 1

        # Kahn 算法 + 优先队列
        # 入度为0的节点中，优先选择：1) 有更多后续依赖的 2) 隐式前置置信度高的
        import heapq
        result = []
        heap = []
        available = deque()

        for kp in kp_set:
            if in_degree.get(kp, 0) == 0:
                available.append(kp)

        while available or heap:
            if not available:
                break

            # 从可用节点中选择最优的
            current = available.popleft()
            result.append(current)

            # 更新后续节点的入度
            for succ, edge_type, confidence in sorted(adj[current], key=lambda x: -x[2]):
                in_degree[succ] -= 1
                if in_degree[succ] == 0:
                    available.append(succ)

        return result

    def _annotate_path(
        self,
        path: List[int],
        explicit_graph: Dict,
        implicit_edges: Dict[Tuple[int, int], float]
    ) -> List[Dict]:
        """为路径中每一步标注前置关系来源"""
        annotated = []
        path_set = set(path)
        for i, kp_id in enumerate(path):
            # 查找此知识点在路径中的前置
            prereqs = []
            for src, successors in explicit_graph.items():
                if src in path_set:
                    for succ in successors:
                        if succ == kp_id:
                            prereqs.append({
                                'kp_id': src,
                                'type': 'EXPLICIT',
                                'confidence': 1.0
                            })

            for (a, b), confidence in implicit_edges.items():
                if b == kp_id and a in path_set:
                    prereqs.append({
                        'kp_id': a,
                        'type': 'IMPLICIT',
                        'confidence': round(confidence, 3)
                    })

            annotated.append({
                'step': i + 1,
                'kp_id': kp_id,
                'prerequisites': prereqs,
                'is_discovered_prereq': any(p['type'] == 'IMPLICIT' for p in prereqs)
            })

        return annotated
```

### 7.2 定时任务实现

```python
class ImplicitPrereqScheduler:
    """隐式前置关系相关定时任务"""

    async def weekly_discovery_job(self):
        """每周全量发现任务"""
        subjects = ['数学', '物理', '化学', '生物', '语文', '英语', '历史', '地理', '政治']
        grade_ranges = ['1-6', '7-9', '10-12']

        engine = ImplicitPrerequisiteDiscoveryEngine(self.db, self.redis, self.kp_graph)

        for subject in subjects:
            for grade_range in grade_ranges:
                try:
                    candidates = await engine.run_discovery_pipeline(
                        subject=subject,
                        grade_range=grade_range,
                        lookback_days=180
                    )
                    logger.info(f"Discovery {subject} {grade_range}: found {len(candidates)} candidates")
                except Exception as e:
                    logger.error(f"Discovery failed for {subject} {grade_range}: {e}")
                    continue

            # 学科间间隔，避免资源峰值
            await asyncio.sleep(60)

    async def evaluate_approved_relations_job(self):
        """评估已批准关系的效果"""
        # 查询30天前批准的关系
        relations = await self.db.fetch(
            """SELECT * FROM implicit_prerequisite_candidate
               WHERE status = 'APPROVED'
                 AND reviewed_at <= DATE_SUB(NOW(), INTERVAL 30 DAY)
                 AND id NOT IN (
                     SELECT candidate_id FROM prerequisite_effect_retrospect
                 )"""
        )

        for rel in relations:
            try:
                await self._evaluate_single_relation(rel)
            except Exception as e:
                logger.error(f"Evaluation failed for candidate {rel['id']}: {e}")

    async def _evaluate_single_relation(self, relation):
        """评估单个已批准关系的效果"""
        # 获取使用优化路径的学生组（实验组）
        treatment = await self.db.fetch(
            """SELECT mastery_score FROM answer_record
               WHERE student_id IN (
                   SELECT student_id FROM learning_path_usage
                   WHERE implicit_prereq_applied = 1
                     AND target_kp_id = %s
               )
                 AND kp_id = %s
                 AND created_at >= %s""",
            relation['kp_id_b'], relation['kp_id_b'],
            relation['reviewed_at']
        )

        # 获取未使用优化路径的学生组（对照组）
        control = await self.db.fetch(
            """SELECT mastery_score FROM answer_record
               WHERE student_id IN (
                   SELECT student_id FROM learning_path_usage
                   WHERE implicit_prereq_applied = 0
                     AND target_kp_id = %s
               )
                 AND kp_id = %s
                 AND created_at >= %s""",
            relation['kp_id_b'], relation['kp_id_b'],
            relation['reviewed_at']
        )

        if len(treatment) < 30 or len(control) < 30:
            return  # 样本不足

        treat_scores = np.array([r['mastery_score'] for r in treatment])
        control_scores = np.array([r['mastery_score'] for r in control])

        statistic, p_value = stats.mannwhitneyu(treat_scores, control_scores, alternative='greater')
        pooled_std = np.sqrt((treat_scores.std()**2 + control_scores.std()**2) / 2)
        effect = (treat_scores.mean() - control_scores.mean()) / pooled_std if pooled_std > 0 else 0

        improvement = (treat_scores.mean() - control_scores.mean()) / control_scores.mean() * 100 if control_scores.mean() > 0 else 0

        significance = 'SIGNIFICANT' if p_value < 0.05 and effect > 0.2 else ('NOT_SIGNIFICANT' if p_value >= 0.05 else 'INCONCLUSIVE')

        # 写入回溯表
        await self.db.execute(
            """INSERT INTO prerequisite_effect_retrospect
               (candidate_id, experiment_type, control_group_size, treat_group_size,
                control_mastery_mean, control_mastery_std,
                treat_mastery_mean, treat_mastery_std,
                improvement_pct, significance, evaluation_period_days)
               VALUES (%s, 'AB_TEST', %s, %s, %s, %s, %s, %s, %s, %s, 30)""",
            relation['id'],
            len(control), len(treatment),
            float(control_scores.mean()), float(control_scores.std()),
            float(treat_scores.mean()), float(treat_scores.std()),
            round(improvement, 2),
            significance
        )

        # 如果效果不显著，标记为废弃
        if significance == 'NOT_SIGNIFICANT':
            await self.db.execute(
                "UPDATE implicit_prerequisite_candidate SET status = 'DEPRECATED' WHERE id = %s",
                relation['id']
            )
            # 从知识图谱中移除
            await self.kp_graph.remove_implicit_edge(relation['kp_id_a'], relation['kp_id_b'])
```

## 8. 错误处理与降级策略

### 8.1 错误码定义

| 错误码 | 说明 | 处理方式 |
|-------|------|---------|
| `48001` | 数据源不可用（答题记录/AI对话数据） | 延迟执行，等待数据恢复 |
| `48002` | 样本量不足 | 正常返回空结果，记录日志 |
| `48003` | 知识图谱服务不可用 | 跳过去重步骤，标记候选为 `UNVERIFIED` |
| `48004` | Redis缓存写入失败 | 降级为直接查询数据库 |
| `48005` | 统计计算异常（如全零数据） | 跳过该知识点对，记录警告日志 |
| `48006` | 审核任务分配失败（无可用审核人） | 任务保持 `PENDING`，通知管理员 |
| `48007` | 回溯评估数据不完整 | 推迟评估，等待更多数据积累 |

### 8.2 降级策略

```python
class DiscoveryFallbackHandler:
    """发现流程降级处理器"""

    async def safe_run_discovery(self, subject: str, grade_range: str):
        try:
            # 正常流程
            engine = ImplicitPrerequisiteDiscoveryEngine(self.db, self.redis, self.kp_graph)
            return await engine.run_discovery_pipeline(subject, grade_range)
        except DataSourceUnavailableError:
            # 降级1: 数据源不可用，使用缓存的上次结果
            logger.warning(f"Data source unavailable, using cached results for {subject}")
            return await self._get_cached_candidates(subject, grade_range)
        except GraphServiceUnavailableError:
            # 降级2: 知识图谱不可用，跳过去重
            logger.warning("Knowledge graph unavailable, skipping dedup")
            engine = ImplicitPrerequisiteDiscoveryEngine(self.db, self.redis, None)
            return await engine.run_discovery_pipeline(subject, grade_range)
        except InsufficientDataError as e:
            # 降级3: 数据不足，正常跳过
            logger.info(f"Insufficient data for {subject} {grade_range}: {e}")
            return []
        except Exception as e:
            # 兜底: 未知异常，告警并返回空
            logger.error(f"Discovery pipeline failed: {e}", exc_info=True)
            await self._send_alert(subject, grade_range, str(e))
            return []
```

### 8.3 数据质量保障

```python
class DataQualityChecker:
    """数据质量检查器"""

    @staticmethod
    def validate_trace(trace: LearningTrace) -> bool:
        """验证学习轨迹数据质量"""
        if len(trace.knowledge_points) < 2:
            return False
        # 检查时间顺序合理性
        for i in range(len(trace.knowledge_points) - 1):
            if trace.knowledge_points[i]['timestamp'] > trace.knowledge_points[i + 1]['timestamp']:
                return False
        # 检查掌握度范围
        for kp in trace.knowledge_points:
            if not (0 <= kp['mastery'] <= 1):
                return False
        return True

    @staticmethod
    def detect_outliers(mastery_scores: List[float]) -> List[float]:
        """IQR方法检测异常值"""
        if len(mastery_scores) < 4:
            return mastery_scores
        q1 = np.percentile(mastery_scores, 25)
        q3 = np.percentile(mastery_scores, 75)
        iqr = q3 - q1
        lower = q1 - 1.5 * iqr
        upper = q3 + 1.5 * iqr
        return [s for s in mastery_scores if lower <= s <= upper]
```

## 14. 附录

### 14.1 统计学方法说明

| 方法 | 用途 | 假设条件 |
|-----|------|---------|
| Mann-Whitney U 检验 | 比较两组掌握度分布差异 | 独立样本，连续变量 |
| Cohen's d | 效应量计算 | 两组均值和标准差 |
| Bootstrap 重采样 | 小样本置信区间估计 | 有放回采样 ≥ 1000 次 |
| Bonferroni 校正 | 多重比较 p 值校正 | 知识点对数量较多时 |

### 14.2 术语表

| 术语 | 定义 |
|-----|------|
| 隐式前置关系 | 数据分析发现但未被课程大纲显式标注的知识点先修关系 |
| 学习序列效能 | 不同知识点学习顺序对学生掌握度的影响差异 |
| 置信度评分 | 综合统计指标计算的隐式前置关系可信程度 |
| 序列模式 | 学生学习多个知识点的时间顺序模式 |
| 共现 | 两个知识点出现在同一学生的学习轨迹中 |
| 效应量 | 量化学习顺序对掌握度影响的大小（与样本量无关） |
