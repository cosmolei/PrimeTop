# 服务端-教育平台学生用户学习内容曝光统一管控与推荐疲劳智能防护引擎-详细设计

## 1. 概述

### 1.1 功能定位

PrimeTop 作为全学段 AI 辅助学习平台，存在大量向学生推送学习内容的触达渠道：首页推荐卡片、每日任务流、AI 对话建议、错题复习提醒、考点推送、运营弹窗、推送通知等。多渠道并行推荐时极易出现 **内容过载（Content Overload）** 与 **推荐疲劳（Recommendation Fatigue）** 问题——同一内容反复曝光、同类推荐扎堆涌入、学生注意力被过度消耗，最终导致推荐点击率和内容消费完成率持续下降。

本引擎作为 **跨渠道内容曝光统一管控层**，负责：

1. **全链路曝光追踪**：记录每条学习内容在各个触达渠道上的曝光事件，构建学生维度的内容曝光时间线。
2. **频控规则管理**：支持内容级、知识点级、学科级、推荐来源级的多粒度频率上限配置，自动拦截超频曝光。
3. **推荐疲劳检测**：基于学生近期推荐交互信号（曝光→点击→完成），实时计算推荐疲劳指数，触发降级策略。
4. **多渠道曝光协调**：当多个推荐源（首页推荐服务、学习计划引擎、错题复习引擎、运营活动引擎等）同时产出推荐候选时，进行统一的去重、合并、排序和配额分配。
5. **内容推荐生命周期管理**：管理每条推荐内容从"冷启动→上升期→稳定期→衰退期→下线"的全生命周期，避免过期推荐持续占用推荐位。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 曝光追踪延迟 | P99 < 50ms（异步写入） |
| 频控判定延迟 | P99 < 20ms（缓存命中） |
| 推荐疲劳指数计算 | 准实时，每 5 分钟刷新 |
| 多渠道推荐合并去重 | 跨渠道重复率 < 2% |
| 推荐点击率（CTR） | 疲劳防护启用后 7 日内 CTR 提升 ≥ 10% |
| 推荐完成率 | 内容消费完成率提升 ≥ 8% |

### 1.3 适用范围

- 学生端 APP 所有内容推荐触达渠道。
- 不涉及消息推送通道本身的技术实现（由统一通知服务负责）。
- 不涉及推荐算法本身的召回和排序逻辑（由各推荐服务负责）。
- 本引擎在各推荐服务产出候选后、实际投放前进行拦截、合并、频控和疲劳防护处理。

## 4. 曝光频控规则引擎

### 4.1 频控粒度

| 粒度 | 说明 | 示例 |
| --- | --- | --- |
| CONTENT | 同一内容对同一学生的曝光频次 | 同一题目 24h 内最多曝光 2 次 |
| KNOWLEDGE_POINT | 同一知识点下的内容曝光总量控制 | 同一知识点 6h 内最多推荐 5 条内容 |
| SUBJECT | 单学科推荐内容密度控制 | 数学学科每日推荐不超过 15 条 |
| CHANNEL | 单渠道投放量控制 | 首页推荐卡片每日不超过 20 张 |
| GLOBAL | 全局推荐总量控制 | 每日全部渠道推荐内容不超过 40 条 |

### 4.2 规则匹配流程

```text
推荐候选 → [规则加载] → [规则匹配] → [窗口检查] → [判定]
                                              │
                                    ┌─────────┴─────────┐
                                    │                    │
                                 通过(BLOCK)         超频处理
                                    │              ┌─────┼─────┐
                                    │           拦截    降权   仅记录
                                    │          (BLOCK) (DEPRIORITIZE) (NOTIFY)
                                    ▼
                              放行到下游
```

### 4.3 核心代码：频控规则引擎

```java
/**
 * 频控规则引擎 - 对推荐候选执行频率上限检查
 */
@Service
public class FrequencyControlEngine {

    @Autowired
    private FrequencyRuleRepository ruleRepository;

    @Autowired
    private RedisSlideWindowCounter windowCounter;

    /**
     * 对推荐候选列表执行频控过滤
     *
     * @param studentId  学生ID
     * @param candidates 推荐候选列表
     * @param channel    投放渠道
     * @return 过滤结果（含通过列表和被拦截列表）
     */
    public FrequencyFilterResult filter(
            Long studentId,
            List<RecommendationCandidate> candidates,
            String channel) {

        // 1. 加载当前生效的频控规则（按优先级排序）
        List<FrequencyRule> activeRules = ruleRepository.findActiveRules(channel);

        List<RecommendationCandidate> passed = new ArrayList<>();
        List<BlockedCandidate> blocked = new ArrayList<>();

        for (RecommendationCandidate candidate : candidates) {
            boolean isBlocked = false;
            String blockReason = null;

            for (FrequencyRule rule : activeRules) {
                FrequencyCheckResult result = checkRule(studentId, candidate, rule);
                if (result.isOverLimit()) {
                    if ("BLOCK".equals(rule.getAction())) {
                        isBlocked = true;
                        blockReason = result.getReason();
                        break;
                    } else if ("DEPRIORITIZE".equals(rule.getAction())) {
                        // 降低推荐排序分数
                        candidate.setScore(candidate.getScore() * (1 - result.getPenaltyRatio()));
                    }
                    // NOTIFY 类型仅记录不处理
                }
            }

            if (isBlocked) {
                blocked.add(new BlockedCandidate(candidate, blockReason));
            } else {
                passed.add(candidate);
            }
        }

        return new FrequencyFilterResult(passed, blocked);
    }

    /**
     * 单条规则检查
     */
    private FrequencyCheckResult checkRule(
            Long studentId,
            RecommendationCandidate candidate,
            FrequencyRule rule) {

        String targetKey = buildTargetKey(studentId, candidate, rule);
        int currentCount = windowCounter.getCount(targetKey, rule.getWindowSize());
        int maxAllowed = rule.getMaxExposures();

        if (currentCount >= maxAllowed) {
            return FrequencyCheckResult.overLimit(
                String.format("频控规则[%s]超限: %s 当前=%d 上限=%d 窗口=%dmin",
                    rule.getRuleCode(), targetKey,
                    currentCount, maxAllowed, rule.getWindowSize())
            );
        }

        return FrequencyCheckResult.pass();
    }

    /**
     * 构建频控目标Key
     */
    private String buildTargetKey(
            Long studentId,
            RecommendationCandidate candidate,
            FrequencyRule rule) {

        switch (rule.getRuleType()) {
            case "CONTENT":
                return String.format("exposure:cnt:%d:CONTENT:%s",
                    studentId, candidate.getContentId());
            case "KNOWLEDGE_POINT":
                return String.format("exposure:cnt:%d:KP:%s",
                    studentId, candidate.getPrimaryKnowledgePointId());
            case "SUBJECT":
                return String.format("exposure:cnt:%d:SUBJECT:%s",
                    studentId, candidate.getSubject());
            case "CHANNEL":
                return String.format("exposure:cnt:%d:CHANNEL:%s",
                    studentId, candidate.getChannel());
            case "GLOBAL":
                return String.format("exposure:cnt:%d:GLOBAL:ALL", studentId);
            default:
                return String.format("exposure:cnt:%d:DEFAULT", studentId);
        }
    }
}
```

### 4.4 Redis 滑动窗口计数器实现

```java
/**
 * 基于 Redis ZSet 的滑动窗口计数器
 * 在窗口时间范围内统计事件发生次数
 */
@Component
public class RedisSlideWindowCounter {

    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 获取滑动窗口内的事件计数
     *
     * @param key        计数键
     * @param windowSize 窗口大小（分钟）
     * @return 窗口内事件数
     */
    public int getCount(String key, int windowSize) {
        String zsetKey = "sw:" + key;
        long now = System.currentTimeMillis();
        long windowStart = now - (long) windowSize * 60 * 1000;

        // 移除窗口外的过期记录
        redisTemplate.opsForZSet().removeRangeByScore(zsetKey, 0, windowStart);

        // 统计窗口内记录数
        Long count = redisTemplate.opsForZSet().count(zsetKey, windowStart, now);
        return count != null ? count.intValue() : 0;
    }

    /**
     * 记录一次事件（在候选通过频控后调用）
     *
     * @param key        计数键
     * @param windowSize 窗口大小（分钟），用于设置 TTL
     */
    public void record(String key, int windowSize) {
        String zsetKey = "sw:" + key;
        long now = System.currentTimeMillis();

        // 使用时间戳+随机后缀作为 member，避免同一毫秒事件合并
        String member = now + ":" + UUID.randomUUID().toString().substring(0, 8);

        redisTemplate.opsForZSet().add(zsetKey, member, now);

        // 设置 TTL 为窗口大小的 2 倍，确保窗口数据不会过早过期
        redisTemplate.expire(zsetKey, windowSize * 2L, TimeUnit.MINUTES);
    }

    /**
     * 批量记录事件
     */
    public void recordBatch(String key, int count, int windowSize) {
        String zsetKey = "sw:" + key;
        long now = System.currentTimeMillis();

        Set<ZSetOperations.TypedTuple<String>> tuples = new HashSet<>();
        for (int i = 0; i < count; i++) {
            tuples.add(new DefaultTypedTuple<>(
                now + ":" + i + ":" + UUID.randomUUID().toString().substring(0, 4),
                (double) now
            ));
        }
        redisTemplate.opsForZSet().add(zsetKey, tuples);
        redisTemplate.expire(zsetKey, windowSize * 2L, TimeUnit.MINUTES);
    }
}
```

## 5. 推荐疲劳检测算法

### 5.1 疲劳指数模型

推荐疲劳指数（Recommendation Fatigue Index, RFI）是一个 0-100 的连续值，反映学生当前对推荐内容的疲劳程度。值越高代表越疲劳。

**计算公式：**

```
RFI = w1 × E(t) + w2 × S(t) + w3 × D(t) + w4 × C(t)

其中：
E(t)  = 曝光密度分（近1小时曝光数 / 阈值） × 100，截断到 [0, 100]
S(t)  = 连续跳过分（连续未点击次数 / 阈值） × 100，截断到 [0, 100]
D(t)  = 点击率衰减分（1 - 近1小时CTR / 历史平均CTR） × 100，截断到 [0, 100]
C(t)  = 完成率衰减分（1 - 近24小时完成率 / 历史平均完成率） × 100，截断到 [0, 100]

默认权重：w1=0.30, w2=0.25, w3=0.25, w4=0.20
```

### 5.2 疲劳等级划分

| 疲劳等级 | RFI 范围 | 表现 | 策略 |
| --- | --- | --- | --- |
| NORMAL | [0, 30) | 正常推荐 | 全量投放，不做额外限制 |
| MILD | [30, 50) | 轻度疲劳 | 推荐量降低 30%，优先高质量内容 |
| MODERATE | [50, 75) | 中度疲劳 | 推荐量降低 60%，仅保留高优先级推荐，设置 30min 冷却期 |
| SEVERE | [75, 100] | 严重疲劳 | 暂停所有推荐 1-2 小时，仅保留学习任务必需项 |

### 5.3 核心代码：疲劳指数计算

```java
/**
 * 推荐疲劳检测引擎
 * 基于多维信号计算学生推荐疲劳指数
 */
@Service
public class FatigueDetectionEngine {

    // 疲劳指数权重
    private static final double W_EXPOSURE_DENSITY = 0.30;
    private static final double W_CONSECUTIVE_SKIP = 0.25;
    private static final double W_CTR_DECAY = 0.25;
    private static final double W_COMPLETE_DECAY = 0.20;

    // 阈值参数（可从配置中心动态加载）
    private static final int EXPOSURE_THRESHOLD_1H = 20;      // 1小时曝光阈值
    private static final int SKIP_THRESHOLD = 5;               // 连续跳过阈值
    private static final double MIN_CTR = 0.05;                // 最低可接受CTR
    private static final double MIN_COMPLETE_RATE = 0.30;      // 最低完成率

    @Autowired
    private ExposureQueryService exposureQueryService;

    @Autowired
    private FatigueStateRepository fatigueStateRepository;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /**
     * 计算并更新学生推荐疲劳指数
     * 由定时任务每5分钟调用一次
     */
    @Scheduled(fixedDelay = 300_000) // 5分钟
    public void batchCalculateFatigueIndex() {
        // 获取最近活跃的学生（近30分钟有曝光事件）
        List<Long> activeStudentIds = exposureQueryService.getRecentlyActiveStudents(30);

        for (Long studentId : activeStudentIds) {
            try {
                calculateAndUpdate(studentId);
            } catch (Exception e) {
                log.error("计算学生疲劳指数失败 studentId={}", studentId, e);
            }
        }
    }

    /**
     * 单学生疲劳指数计算
     */
    public FatigueState calculateAndUpdate(Long studentId) {
        // 1. 获取信号
        int recentExposureCnt = exposureQueryService.countExposures(studentId, 60); // 近1小时
        int consecutiveSkips = getConsecutiveSkips(studentId);
        double recentCtr = exposureQueryService.calculateCtr(studentId, 60);
        double recentCompleteRate = exposureQueryService.calculateCompleteRate(studentId, 1440); // 近24h

        // 获取历史基线
        FatigueBaseline baseline = getBaseline(studentId);
        double avgCtr = Math.max(baseline.getAvgCtr(), MIN_CTR);
        double avgCompleteRate = Math.max(baseline.getAvgCompleteRate(), MIN_COMPLETE_RATE);

        // 2. 计算各维度得分
        double exposureScore = Math.min(100.0 * recentExposureCnt / EXPOSURE_THRESHOLD_1H, 100);
        double skipScore = Math.min(100.0 * consecutiveSkips / SKIP_THRESHOLD, 100);
        double ctrDecayScore = Math.min((1.0 - recentCtr / avgCtr) * 100, 100);
        ctrDecayScore = Math.max(ctrDecayScore, 0);
        double completeDecayScore = Math.min((1.0 - recentCompleteRate / avgCompleteRate) * 100, 100);
        completeDecayScore = Math.max(completeDecayScore, 0);

        // 3. 加权求和
        double fatigueIndex = W_EXPOSURE_DENSITY * exposureScore
                           + W_CONSECUTIVE_SKIP * skipScore
                           + W_CTR_DECAY * ctrDecayScore
                           + W_COMPLETE_DECAY * completeDecayScore;

        fatigueIndex = Math.round(fatigueIndex * 100.0) / 100.0;
        fatigueIndex = Math.min(Math.max(fatigueIndex, 0), 100);

        // 4. 确定疲劳等级
        String fatigueLevel = classifyFatigueLevel(fatigueIndex);

        // 5. 计算冷却期
        LocalDateTime cooldownUntil = calculateCooldown(fatigueLevel, fatigueIndex);

        // 6. 持久化
        FatigueState state = new FatigueState();
        state.setStudentId(studentId);
        state.setFatigueIndex(BigDecimal.valueOf(fatigueIndex));
        state.setFatigueLevel(fatigueLevel);
        state.setRecentExposureCnt(recentExposureCnt);
        state.setRecentClickRate(BigDecimal.valueOf(recentCtr));
        state.setRecentSkipRate(BigDecimal.valueOf(1.0 - recentCtr));
        state.setRecentCompleteRate(BigDecimal.valueOf(recentCompleteRate));
        state.setConsecutiveSkipCnt(consecutiveSkips);
        state.setLastCalcTime(LocalDateTime.now());
        state.setCooldownUntil(cooldownUntil);

        fatigueStateRepository.upsert(state);

        // 写入 Redis 缓存
        updateFatigueCache(studentId, state);

        return state;
    }

    /**
     * 疲劳等级分类
     */
    private String classifyFatigueLevel(double index) {
        if (index >= 75) return "SEVERE";
        if (index >= 50) return "MODERATE";
        if (index >= 30) return "MILD";
        return "NORMAL";
    }

    /**
     * 根据疲劳等级计算冷却期截止时间
     */
    private LocalDateTime calculateCooldown(String level, double index) {
        LocalDateTime now = LocalDateTime.now();
        switch (level) {
            case "SEVERE":
                // 严重疲劳：冷却 1-2 小时（指数越高冷却越久）
                int coolMinutes = (int) (60 + (index - 75) * 2.4); // 60~120min
                return now.plusMinutes(coolMinutes);
            case "MODERATE":
                // 中度疲劳：冷却 30 分钟
                return now.plusMinutes(30);
            default:
                return null; // 无冷却
        }
    }

    /**
     * 获取连续未点击次数
     */
    private int getConsecutiveSkips(Long studentId) {
        String key = "fatigue:skips:" + studentId;
        String val = redisTemplate.opsForValue().get(key);
        return val != null ? Integer.parseInt(val) : 0;
    }

    /**
     * 更新疲劳状态缓存
     */
    private void updateFatigueCache(Long studentId, FatigueState state) {
        String key = "fatigue:" + studentId;
        Map<String, String> fields = new HashMap<>();
        fields.put("index", state.getFatigueIndex().toString());
        fields.put("level", state.getFatigueLevel());
        fields.put("consecutive_skips", String.valueOf(state.getConsecutiveSkipCnt()));
        fields.put("last_calc_time", state.getLastCalcTime().toString());
        fields.put("cooldown_until",
            state.getCooldownUntil() != null ? state.getCooldownUntil().toString() : "");
        redisTemplate.opsForHash().putAll(key, fields);
        redisTemplate.expire(key, 5, TimeUnit.MINUTES);
    }
}
```

### 6.2 配额分配算法

各推荐源在共享推荐位时按权重分配：

| 推荐源 | 默认权重 | 说明 |
| --- | --- | --- |

### 6.3 核心代码：推荐合并器

```java
/**
 * 多渠道推荐合并器
 * 将来自不同推荐源的候选列表统一合并、去重、排序
 */
@Service
public class RecommendationMerger {

    @Autowired
    private FrequencyControlEngine frequencyEngine;

    @Autowired
    private FatigueQueryService fatigueQueryService;

    @Autowired
    private ContentLifecycleService lifecycleService;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /**
     * 合并多渠道推荐候选
     *
     * @param studentId   学生ID
     * @param channel     目标投放渠道
     * @param sourceCandidates 各推荐源产出的候选集
     * @param maxSlots    最大推荐位数
     * @return 合并后的最终推荐列表
     */
    public MergeResult merge(
            Long studentId,
            String channel,
            Map<String, List<RecommendationCandidate>> sourceCandidates,
            int maxSlots) {

        // 1. 展平所有候选
        List<RecommendationCandidate> allCandidates = flattenAndTag(sourceCandidates);

        // 2. 内容级去重（同一 content_id 只保留最高分）
        List<RecommendationCandidate> deduped = deduplicate(studentId, allCandidates);

        // 3. 过滤近期已曝光内容
        deduped = filterRecentlyExposed(studentId, deduped);

        // 4. 频控过滤
        FrequencyFilterResult freqResult = frequencyEngine.filter(studentId, deduped, channel);
        List<RecommendationCandidate> freqPassed = freqResult.getPassed();

        // 5. 疲劳检查与投放量调整
        FatigueState fatigue = fatigueQueryService.getLatestState(studentId);
        int adjustedMaxSlots = adjustMaxSlots(maxSlots, fatigue);
        if (isInCooldown(fatigue)) {
            // 冷却期内仅保留高优先级必需项
            freqPassed = filterHighPriorityOnly(freqPassed);
        }

        // 6. 渠道配额分配
        Map<String, Integer> quotas = calculateQuotas(adjustedMaxSlots);

        // 7. 按配额选取候选
        List<RecommendationCandidate> selected = selectByQuota(freqPassed, quotas, adjustedMaxSlots);

        // 8. 应用生命周期衰减因子并重新排序
        selected = applyLifecycleDecay(studentId, selected);
        selected = diversityAwareSort(selected);

        // 9. 截取最终列表
        List<RecommendationCandidate> finalList = selected.subList(
            0, Math.min(selected.size(), adjustedMaxSlots));

        // 10. 记录合并日志
        logMergeResult(studentId, channel, allCandidates, finalList, freqResult.getBlocked());

        return new MergeResult(finalList, freqResult.getBlocked(), adjustedMaxSlots);
    }

    /**
     * 根据疲劳等级调整推荐位上限
     */
    private int adjustMaxSlots(int maxSlots, FatigueState fatigue) {
        if (fatigue == null) return maxSlots;

        switch (fatigue.getFatigueLevel()) {
            case "MILD":
                return (int) (maxSlots * 0.7);  // 减少30%
            case "MODERATE":
                return (int) (maxSlots * 0.4);  // 减少60%
            case "SEVERE":
                return (int) (maxSlots * 0.2);  // 仅保留20%
            default:
                return maxSlots;
        }
    }

    /**
     * 计算各推荐源的配额
     */
    private Map<String, Integer> calculateQuotas(int totalSlots) {
        Map<String, Double> weights = getQuotaWeights();
        Map<String, Integer> quotas = new LinkedHashMap<>();

        int allocated = 0;
        for (Map.Entry<String, Double> entry : weights.entrySet()) {
            int quota = (int) Math.ceil(totalSlots * entry.getValue());
            quotas.put(entry.getKey(), quota);
            allocated += quota;
        }

        // 修正舍入误差
        if (allocated > totalSlots) {
            // 从权重最大的源中扣减
            String maxSource = weights.entrySet().stream()
                .max(Map.Entry.comparingByValue())
                .map(Map.Entry::getKey)
                .orElse("STUDY_PLAN");
            quotas.put(maxSource, quotas.get(maxSource) - (allocated - totalSlots));
        }

        return quotas;
    }

    /**
     * 按配额选取候选
     */
    private List<RecommendationCandidate> selectByQuota(
            List<RecommendationCandidate> candidates,
            Map<String, Integer> quotas,
            int totalSlots) {

        // 按来源分组
        Map<String, List<RecommendationCandidate>> bySource = candidates.stream()
            .collect(Collectors.groupingBy(RecommendationCandidate::getSourceService));

        List<RecommendationCandidate> selected = new ArrayList<>();

        // 第一轮：各源按配额选取
        for (Map.Entry<String, Integer> quota : quotas.entrySet()) {
            List<RecommendationCandidate> sourceList = bySource.getOrDefault(
                quota.getKey(), Collections.emptyList());
            int take = Math.min(sourceList.size(), quota.getValue());
            selected.addAll(sourceList.subList(0, take));
        }

        // 第二轮：如果还有空位，从剩余候选中按分数补齐
        if (selected.size() < totalSlots) {
            Set<String> selectedIds = selected.stream()
                .map(RecommendationCandidate::getContentId)
                .collect(Collectors.toSet());

            List<RecommendationCandidate> remaining = candidates.stream()
                .filter(c -> !selectedIds.contains(c.getContentId()))
                .sorted(Comparator.comparing(RecommendationCandidate::getScore).reversed())
                .collect(Collectors.toList());

            for (RecommendationCandidate c : remaining) {
                if (selected.size() >= totalSlots) break;
                selected.add(c);
            }
        }

        return selected;
    }

    /**
     * 应用生命周期衰减因子
     */
    private List<RecommendationCandidate> applyLifecycleDecay(
            Long studentId,
            List<RecommendationCandidate> candidates) {

        for (RecommendationCandidate c : candidates) {
            double decayFactor = lifecycleService.getDecayFactor(studentId, c.getContentId());
            c.setAdjustedScore(c.getScore() * decayFactor);
        }

        return candidates;
    }

    /**
     * 多样性感知排序
     * 避免相邻推荐为同一学科或同一内容类型
     */
    private List<RecommendationCandidate> diversityAwareSort(
            List<RecommendationCandidate> candidates) {

        if (candidates.size() <= 1) return candidates;

        List<RecommendationCandidate> sorted = new ArrayList<>();
        // 按调整后分数降序排列
        candidates.sort(Comparator.comparing(RecommendationCandidate::getAdjustedScore).reversed());

        Set<String> usedSubjects = new HashSet<>();
        Set<String> usedTypes = new HashSet<>();

        // 贪心选取：优先选高分且不重复学科/类型的候选
        List<RecommendationCandidate> remaining = new ArrayList<>(candidates);
        while (!remaining.isEmpty()) {
            RecommendationCandidate picked = null;

            // 优先选取不同学科和类型的
            for (Iterator<RecommendationCandidate> it = remaining.iterator(); it.hasNext();) {
                RecommendationCandidate c = it.next();
                if (!usedSubjects.contains(c.getSubject()) && !usedTypes.contains(c.getContentType())) {
                    picked = c;
                    it.remove();
                    break;
                }
            }

            // 如果没有满足多样性条件的，选最高分的
            if (picked == null) {
                picked = remaining.remove(0);
            }

            sorted.add(picked);
            usedSubjects.add(picked.getSubject());
            usedTypes.add(picked.getContentType());

            // 每隔 3 个位置重置多样性约束，避免过度影响排序质量
            if (sorted.size() % 3 == 0) {
                usedSubjects.clear();
                usedTypes.clear();
            }
        }

        return sorted;
    }

    /**
     * 过滤近期已曝光内容（Redis去重集合）
     */
    private List<RecommendationCandidate> filterRecentlyExposed(
            Long studentId,
            List<RecommendationCandidate> candidates) {

        String dedupKey = "exposure:dedup:" + studentId + ":ALL";
        long now = System.currentTimeMillis();
        long cutoff = now - 6 * 3600 * 1000L; // 6小时内已曝光的过滤掉

        // 获取近期已曝光的内容ID集合
        Set<String> exposed = redisTemplate.opsForZSet()
            .rangeByScore(dedupKey, cutoff, now);

        if (exposed == null || exposed.isEmpty()) {
            return candidates;
        }

        return candidates.stream()
            .filter(c -> !exposed.contains(c.getContentId()))
            .collect(Collectors.toList());
    }
}
```

## 7. 内容推荐生命周期管理

### 7.1 生命周期状态机

```text
                     首次曝光
                        │
                        ▼
                 ┌──────────────┐
                 │  COLD_START  │  首次推荐，曝光少，数据不足
                 │  (冷启动期)   │  持续：前3次曝光或前24h
                 └──────┬───────┘
                        │ 曝光≥3次 且 CTR>0
                        ▼
                 ┌──────────────┐
                 │   RISING     │  曝光增加，CTR良好
                 │  (上升期)     │  持续：CTR ≥ 基线 80%
                 └──────┬───────┘
                        │ CTR 连续下降 或 曝光次数 > 阈值
                        ▼
                 ┌──────────────┐
                 │   STABLE     │  曝光充分，CTR稳定
                 │  (稳定期)     │  持续：曝光量趋于稳定
                 └──────┬───────┘
                        │ CTR < 基线 50% 或 曝光次数 > 上限
                        ▼
                 ┌──────────────┐
                 │  DECLINING   │  CTR显著下降，推荐效果衰退
                 │  (衰退期)     │  降低曝光频次，设置退避时间
                 └──────┬───────┘
                        │ 连续 N 天 CTR < 阈值 或 手动下线
                        ▼
                 ┌──────────────┐
                 │   RETIRED    │  停止推荐
                 │  (已下线)     │  进入冷却期，N天后可重新评估
                 └──────────────┘
```

### 7.2 衰减因子计算

衰减因子（decay_score）用于调整推荐排序分数，使得过度曝光的内容自然降权：

```text
decay_score = max(0, 1 - α × log(1 + total_exposures) × ctr_penalty)

其中：
α = 0.15（衰减速率，可配置）
total_exposures = 该内容对该学生的累计曝光次数
ctr_penalty = max(0.5, 1 - (1 - current_ctr / historical_ctr)) （CTR下降越多惩罚越大）
```

### 7.3 生命周期定时巡检

```java
/**
 * 内容推荐生命周期管理器
 * 定时巡检推荐内容的生命周期状态
 */
@Service
public class ContentLifecycleManager {

    @Autowired
    private ContentExposureLifecycleRepository lifecycleRepository;

    @Autowired
    private ExposureQueryService exposureQueryService;

    /**
     * 每小时巡检一次，更新内容推荐生命周期状态
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void lifecyclePatrol() {
        // 1. 检查 COLD_START → RISING 转换
        promoteColdStartToRising();

        // 2. 检查 RISING/STABLE → DECLINING 转换
        checkDecliningTransition();

        // 3. 检查 DECLINING → RETIRED 转换
        checkRetirementTransition();

        // 4. 检查 RETIRED 重新评估
        reassessRetiredContent();

        // 5. 更新衰减因子
        updateDecayScores();
    }

    /**
     * COLD_START → RISING 转换
     * 条件：曝光≥3次 且 CTR > 0
     */
    private void promoteColdStartToRising() {
        List<ContentExposureLifecycle> coldStartItems =
            lifecycleRepository.findByState("COLD_START");

        for (ContentExposureLifecycle item : coldStartItems) {
            if (item.getTotalExposures() >= 3 && item.getCtr().compareTo(BigDecimal.ZERO) > 0) {
                item.setLifecycleState("RISING");
                item.setStateUpdatedTime(LocalDateTime.now());
                lifecycleRepository.save(item);
            }
        }
    }

    /**
     * 检查衰退转换
     * 条件：CTR 连续下降超过基线 50%，或总曝光超过上限
     */
    private void checkDecliningTransition() {
        int maxExposures = 20; // 可配置

        List<ContentExposureLifecycle> items = lifecycleRepository
            .findByStateIn(Arrays.asList("RISING", "STABLE"));

        for (ContentExposureLifecycle item : items) {
            boolean ctrDeclining = isCtrDeclining(item);
            boolean overExposed = item.getTotalExposures() > maxExposures;

            if (ctrDeclining || overExposed) {
                item.setLifecycleState("DECLINING");
                item.setStateUpdatedTime(LocalDateTime.now());
                // 设置退避时间：下次可曝光时间为 24h 后
                item.setNextEligibleTime(LocalDateTime.now().plusHours(24));
                lifecycleRepository.save(item);
            }
        }
    }

    /**
     * 更新所有活跃内容的衰减因子
     */
    private void updateDecayScores() {
        double alpha = 0.15; // 衰减速率

        List<ContentExposureLifecycle> items = lifecycleRepository
            .findByStateIn(Arrays.asList("RISING", "STABLE", "DECLINING"));

        for (ContentExposureLifecycle item : items) {
            double exposureFactor = Math.log(1 + item.getTotalExposures());
            double ctrRatio = item.getCtr().doubleValue();
            double ctrPenalty = Math.max(0.5, 1.0 - (1.0 - ctrRatio));
            double decay = Math.max(0, 1.0 - alpha * exposureFactor * ctrPenalty);

            item.setDecayScore(BigDecimal.valueOf(decay).setScale(4, RoundingMode.HALF_UP));
            lifecycleRepository.save(item);
        }
    }

    private boolean isCtrDeclining(ContentExposureLifecycle item) {
        // 比较最近3天的CTR与历史平均CTR
        double recentCtr = exposureQueryService.getRecentCtr(
            item.getStudentId(), item.getContentId(), 3);
        double historicalCtr = item.getCtr().doubleValue();

        return recentCtr < historicalCtr * 0.5;
    }
}
```

## 10. 错误处理与降级策略

### 10.1 错误码定义

| 错误码 | 含义 | 处理建议 |
| --- | --- | --- |
| EXPOSURE_001 | 曝光事件写入失败（Redis不可用） | 降级写入本地队列，异步补偿 |
| EXPOSURE_002 | 曝光事件写入失败（ClickHouse不可用） | 降级写入MySQL，记录告警 |
| EXPOSURE_003 | 频控检查失败（Redis超时） | 放行候选，记录日志（fail-open策略） |
| FATIGUE_001 | 疲劳指数计算异常 | 使用上一次缓存值 |
| FATIGUE_002 | 疲劳状态查询超时 | 默认返回 NORMAL 等级 |
| MERGE_001 | 推荐合并超时 | 降级返回最高分候选（跳过合并） |
| MERGE_002 | 候选去重失败 | 跳过去重直接排序 |
| LIFECYCLE_001 | 生命周期状态更新失败 | 保留原状态，下次巡检补偿 |

### 10.2 降级策略

```java
/**
 * 推荐合并降级处理器
 */
@Component
public class MergeFallbackHandler {

    /**
     * 当频控引擎不可用时的降级策略
     * 策略：fail-open，放行所有候选但标记降级
     */
    public MergeResult fallbackWhenFrequencyDown(
            List<RecommendationCandidate> candidates,
            int maxSlots) {

        log.warn("频控引擎不可用，执行降级策略：fail-open");

        // 简单按分数排序截取
        candidates.sort(Comparator.comparing(
            RecommendationCandidate::getScore).reversed());

        List<RecommendationCandidate> result =
            candidates.subList(0, Math.min(candidates.size(), maxSlots));

        return MergeResult.degraded(result, "FREQUENCY_ENGINE_DOWN");
    }

    /**
     * 当疲劳检测不可用时的降级策略
     * 策略：使用保守的默认配额
     */
    public int fallbackMaxSlots(int originalMaxSlots) {
        log.warn("疲劳检测不可用，使用保守配额：减少50%");
        return Math.max(3, originalMaxSlots / 2);
    }
}
```

### 10.3 熔断策略

| 触发条件 | 熔断动作 | 恢复条件 |
| --- | --- | --- |
| Redis 连续超时 5 次 | 暂停频控检查 30s，降级放行 | 30s 后半开探测 |
| ClickHouse 写入失败率 > 10% | 切换写入 MySQL 临时表 | ClickHouse 恢复后补偿 |
| 疲劳计算任务连续失败 3 次 | 使用缓存值，暂停计算 | 手动触发重算 |
| 合并接口 P99 > 500ms | 跳过生命周期衰减，简化合并 | 延迟恢复 |

### 11.2 查询优化

```java
/**
 * 曝光查询服务 - 优化版
 * 优先走缓存，减少 DB 查询
 */
@Service
public class ExposureQueryService {

    @Autowired
    private CaffeineCacheManager cacheManager;

    @Autowired
    private ExposureEventRepository eventRepository;

    /**
     * 获取学生近N分钟曝光数（走Redis）
     */
    public int countExposures(Long studentId, int minutes) {
        String key = "exposure:cnt:" + studentId + ":GLOBAL:ALL";
        // 使用 ZSet 统计时间窗口内的事件数
        String zsetKey = "sw:" + key;
        long now = System.currentTimeMillis();
        long windowStart = now - (long) minutes * 60 * 1000;

        Long count = redisTemplate.opsForZSet().count(zsetKey, windowStart, now);
        return count != null ? count.intValue() : 0;
    }

    /**
     * 计算学生近期CTR
     * 使用本地缓存避免频繁查库
     */
    @Cacheable(value = "ctr_cache", key = "#studentId + '_' + #minutes",
               unless = "#result == 0.0")
    public double calculateCtr(Long studentId, int minutes) {
        return eventRepository.calculateCtr(studentId,
            LocalDateTime.now().minusMinutes(minutes));
    }

    /**
     * 获取最近活跃学生列表
     * 使用 Bloom Filter + Redis Set 快速过滤
     */
    public List<Long> getRecentlyActiveStudents(int minutes) {
        String activeKey = "active:students:" + (System.currentTimeMillis() / (minutes * 60 * 1000));
        Set<String> members = redisTemplate.opsForSet().members(activeKey);
        if (members == null || members.isEmpty()) {
            return Collections.emptyList();
        }
        return members.stream()
            .map(Long::parseLong)
            .collect(Collectors.toList());
    }
}
```

## 13. 安全与合规

### 13.1 数据安全

- 曝光事件中的 `student_id` 在日志和监控中脱敏显示（仅末4位）。
- ClickHouse 中的曝光数据按月自动清理，保留期 6 个月。
- 推荐合并日志仅保留 7 天，用于排查问题后自动删除。

### 13.2 隐私合规

- 曝光数据属于学生行为数据，纳入未成年人数据保护范围。
- 家长可通过数据导出功能查看孩子的曝光记录。
- 账号注销时，曝光事件表中的关联数据在 30 天内清除。

### 13.3 防滥用

- 频控规则可防止恶意刷推荐（如自动化脚本批量曝光）。
- 异常曝光速率检测：单学生 1 分钟内曝光 > 50 次触发风控告警。
- 推荐投放接口限流：单学生 QPS 上限 5。

### 16.2 疲劳指数计算示例

**场景：** 初二学生，近 1 小时内收到了 12 条推荐，点击了 3 条，连续 4 条未点击后点击了 1 条，近 24h 内容完成率 50%（历史平均 65%）。

```
E(t) = min(100 × 12 / 20, 100) = 60
S(t) = min(100 × 4 / 5, 100) = 80
  (连续跳过4次，因为第5次点击了，当前consecutive_skips=0)
  实际 S(t) = min(100 × 0 / 5, 100) = 0
  （注意：如果第5次点击了，连续跳过计数重置）
  但如果第5次也跳过了：S(t) = min(100 × 5/5, 100) = 100

假设当前连续跳过=2（点击后又跳过了2次）：
S(t) = min(100 × 2 / 5, 100) = 40

CTR = 3/12 = 0.25, 历史平均CTR = 0.30
D(t) = min((1 - 0.25/0.30) × 100, 100) = min(16.67, 100) = 16.67

完成率 = 0.50, 历史平均 = 0.65
C(t) = min((1 - 0.50/0.65) × 100, 100) = min(23.08, 100) = 23.08

RFI = 0.30 × 60 + 0.25 × 40 + 0.25 × 16.67 + 0.20 × 23.08
    = 18.0 + 10.0 + 4.17 + 4.62
    = 36.79

等级：MILD（轻度疲劳）
策略：推荐量降低30%，优先投放高质量内容
```

### 16.3 术语表

| 术语 | 说明 |
| --- | --- |
| 曝光（Exposure/Impression） | 内容在界面上呈现给学生，无论是否被点击 |
| 频控（Frequency Control） | 对内容曝光频率施加上限控制 |
| 推荐疲劳（Recommendation Fatigue） | 学生因推荐过多或重复而对推荐内容产生厌倦 |
| 推荐位（Slot） | 界面上用于展示推荐内容的位置 |
| 配额（Quota） | 各推荐源在推荐位分配中的份额 |
| 衰减因子（Decay Factor） | 随曝光次数增加而对推荐分数施加的惩罚系数 |
| 冷却期（Cooldown） | 学生严重疲劳时暂停推荐的时间段 |
| CTR（Click-Through Rate） | 推荐内容点击率 = 点击数 / 曝光数 |
| 完成率（Complete Rate） | 被点击的内容中学生完整消费的比例 |
