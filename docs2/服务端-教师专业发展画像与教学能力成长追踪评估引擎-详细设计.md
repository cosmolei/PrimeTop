# 教师专业发展画像与教学能力成长追踪评估引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本模块为 PrimeTop 教育平台提供教师端专业能力评估与成长追踪的基础设施。通过对教师教学行为数据、教学效果数据、班级学情数据、教研参与数据等多维度数据的持续采集与建模，构建动态更新的教师专业发展画像，为教师自我提升、平台教研资源推荐、教师激励机制和 B 端合作场景提供数据支撑。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 能力量化 | 将教师教学能力拆解为可量化的多维度指标，建立客观评估体系 |
| 成长追踪 | 记录教师能力变化轨迹，识别成长趋势和停滞信号 |
| 差距诊断 | 识别教师能力短板，推荐针对性提升资源 |
| 横向对标 | 在匿名化前提下提供同类教师群体横向对比基线 |
| 发展规划 | 基于评估结果自动生成个性化专业发展建议 |

### 1.3 适用范围

| 使用者 | 用途 |
| --- | --- |
| 教师本人 | 查看个人能力画像、成长趋势、提升建议 |
| 学校管理员（B端） | 了解教师团队整体水平、识别培训需求 |
| 平台运营 | 教师分级管理、优质教师识别、资源分配 |
| 教研系统 | 基于教师能力推荐教研内容和培训课程 |

### 1.4 设计原则

1. **数据驱动为主，主观评价为辅**：核心评估依赖客观行为数据和效果数据，减少主观偏差。
2. **成长导向而非考核导向**：强调持续改进和发展，避免简单的排名淘汰逻辑。
3. **隐私保护**：横向对比数据做匿名化和群体聚合处理，不暴露个体敏感信息。
4. **渐进式建模**：初期使用规则+权重模型，后续逐步引入 ML 模型提升评估精度。

## 3. 能力评估模型

### 3.1 评分计算架构

### 3.2 综合评分计算公式

```
OverallScore = Σ ( DimScore_i × Weight_i × StageModifier_i )

其中:
- DimScore_i: 第 i 个维度的得分（0-100）
- Weight_i: 第 i 个维度的权重（来自 teacher_capability_dimension）
- StageModifier_i: 阶段调节系数（新教师 vs 资深教师权重微调）
```

**阶段调节系数表：**

| 教师阶段 | student_outcome 类权重调节 | professional_dev 类权重调节 | 说明 |
| --- | --- | --- | --- |
| onboarding（0-3月） | ×0.5 | ×1.5 | 新教师不急于考核学生成绩，侧重学习成长 |
| growing（3-12月） | ×0.8 | ×1.2 | 过渡期，逐步提升教学效果权重 |
| stable（1-3年） | ×1.0 | ×1.0 | 标准权重 |
| advanced（3-5年） | ×1.1 | ×0.9 | 强化教学效果导向 |
| expert（5年+） | ×1.2 | ×0.8 | 资深教师以学生成效为核心 |

> 调节系数降低的权重部分等比例分配给同分类的其他维度，确保总权重归一。

### 3.3 维度评分规则引擎

每个维度的评分通过 `score_rule_json` 中定义的规则进行计算。支持以下规则类型：

```java
public enum ScoreRuleType {
    COMPOSITE,       // 复合指标：多个子指标加权求和
    RATIO,           // 比率型：实际值/目标值
    TIME_BASED,      // 时间阈值型：不同响应时间区间对应不同分数
    COUNT_BASED,     // 数量阈值型：不同数量区间对应不同分数
    AGGREGATE,       // 聚合型：从底层数据聚合计算
    SURVEY_BASED,    // 问卷型：基于调查问卷结果
    FEATURE_USAGE    // 功能使用型：统计功能采纳情况
}
```

**规则解析与执行示例（Java 伪代码）：**

```java
@Service
public class TeacherCapabilityScorer {

    /**
     * 计算教师某维度在指定周期的得分
     */
    public DimensionScoreResult score(String dimCode, Long teacherId, String period) {
        TeacherCapabilityDimension dim = dimensionService.getByCode(dimCode);
        ScoreRule rule = ScoreRuleParser.parse(dim.getScoreRuleJson());

        // 获取原始指标数据
        Map<String, BigDecimal> rawData = metricCollector.collect(
            rule.getRequiredMetrics(), teacherId, period
        );

        // 执行评分规则
        BigDecimal score = switch (rule.getType()) {
            case COMPOSITE -> scoreComposite(rule, rawData);
            case RATIO -> scoreRatio(rule, rawData);
            case TIME_BASED -> scoreTimeBased(rule, rawData);
            case COUNT_BASED -> scoreCountBased(rule, rawData);
            case AGGREGATE -> scoreAggregate(rule, teacherId, period);
            case SURVEY_BASED -> scoreSurvey(rule, teacherId, period);
            case FEATURE_USAGE -> scoreFeatureUsage(rule, teacherId, period);
        };

        // 归一化到 0-100
        score = normalizeScore(score);

        return DimensionScoreResult.builder()
            .dimCode(dimCode)
            .score(score)
            .rawData(rawData)
            .period(period)
            .build();
    }

    /**
     * 复合指标评分
     */
    private BigDecimal scoreComposite(ScoreRule rule, Map<String, BigDecimal> rawData) {
        BigDecimal weightedSum = BigDecimal.ZERO;
        BigDecimal totalWeight = BigDecimal.ZERO;

        for (SubMetric sub : rule.getSubMetrics()) {
            BigDecimal value = rawData.getOrDefault(sub.getCode(), BigDecimal.ZERO);
            BigDecimal weight = sub.getWeight();
            weightedSum = weightedSum.add(value.multiply(weight));
            totalWeight = totalWeight.add(weight);
        }

        return totalWeight.compareTo(BigDecimal.ZERO) > 0
            ? weightedSum.divide(totalWeight, 2, RoundingMode.HALF_UP)
            : BigDecimal.ZERO;
    }

    /**
     * 时间阈值型评分（如反馈及时性）
     */
    private BigDecimal scoreTimeBased(ScoreRule rule, Map<String, BigDecimal> rawData) {
        BigDecimal value = rawData.get(rule.getMetric());
        if (value == null) return BigDecimal.ZERO;

        for (TimeRule tr : rule.getRules()) {
            if (RuleConditionMatcher.match(value, tr.getCondition())) {
                return tr.getScore();
            }
        }
        return BigDecimal.ZERO;
    }
}
```

### 3.4 趋势分析算法

```java
@Service
public class TeacherGrowthAnalyzer {

    private static final int TREND_WINDOW = 4; // 最近4个周期

    /**
     * 分析教师某维度（或综合）的趋势
     */
    public TrendResult analyzeTrend(Long teacherId, String dimCode) {
        List<TeacherCapabilityScore> scores = scoreRepository.findRecentScores(
            teacherId, dimCode, TREND_WINDOW
        );

        if (scores.size() < 2) {
            return TrendResult.insufficient();
        }

        // 计算线性回归斜率
        double[] x = IntStream.range(0, scores.size()).asDoubleStream().toArray();
        double[] y = scores.stream()
            .mapToDouble(s -> s.getScore().doubleValue())
            .toArray();

        SimpleRegression regression = new SimpleRegression();
        for (int i = 0; i < x.length; i++) {
            regression.addData(x[i], y[i]);
        }

        double slope = regression.getSlope();
        double rSquared = regression.getRSquared();

        // 判定方向
        TrendDirection direction;
        if (Math.abs(slope) < 0.5) {
            direction = Math.abs(y[y.length - 1] - y[0]) < 2.0
                ? TrendDirection.STAGNANT   // 分值极低波动 → 停滞
                : TrendDirection.STABLE;     // 分值稳定 → 平稳
        } else if (slope > 0) {
            direction = TrendDirection.RISING;
        } else {
            direction = TrendDirection.DECLINING;
        }

        return TrendResult.builder()
            .direction(direction)
            .slope(BigDecimal.valueOf(slope))
            .rSquared(BigDecimal.valueOf(rSquared))
            .currentScore(scores.get(scores.size() - 1).getScore())
            .previousScore(scores.get(0).getScore())
            .delta(scores.get(scores.size() - 1).getScore()
                .subtract(scores.get(0).getScore()))
            .build();
    }
}
```

```java
@Service
public class TeacherGrowthStageEvaluator {

    public GrowthStage evaluate(Long teacherId) {
        TeacherProfile profile = profileService.get(teacherId);
        int teachMonths = Months.monthsBetween(
            new DateTime(profile.getTeachSince()),
            DateTime.now()
        ).getMonths();

        // 基础阶段（按教龄）
        GrowthStage baseStage;
        if (teachMonths < 3) {
            baseStage = GrowthStage.ONBOARDING;
        } else if (teachMonths < 12) {
            baseStage = GrowthStage.GROWING;
        } else if (teachYears < 3) {
            baseStage = GrowthStage.STABLE;
        } else if (teachYears < 5) {
            baseStage = GrowthStage.ADVANCED;
        } else {
            baseStage = GrowthStage.EXPERT;
        }

        // 综合评分修正：高分可越级，低分需降级
        BigDecimal score = profile.getOverallScore();
        if (score.compareTo(new BigDecimal("90")) >= 0 && baseStage == GrowthStage.STABLE) {
            return GrowthStage.ADVANCED;
        }
        if (score.compareTo(new BigDecimal("95")) >= 0 && baseStage == GrowthStage.ADVANCED) {
            return GrowthStage.EXPERT;
        }
        if (score.compareTo(new BigDecimal("40")) < 0 && baseStage != GrowthStage.ONBOARDING) {
            log.warn("Teacher {} score {} below threshold, consider stage review",
                teacherId, score);
        }

        return baseStage;
    }
}
```

```java
@Component
@KafkaListener(topics = "teacher.behavior.events", groupId = "teacher-capability-consumer")
public class TeacherEventConsumer {

    @Autowired
    private MetricCollector metricCollector;

    @Autowired
    private ScoreUpdateTrigger scoreUpdateTrigger;

    @Autowired
    private GrowthTrajectoryService trajectoryService;

    @KafkaHandler
    public void handle(TeacherBehaviorEvent event) {
        log.debug("Received teacher event: type={}, teacherId={}",
            event.getEventType(), event.getTeacherId());

        try {
            // 1. 提取原始指标数据
            Map<String, BigDecimal> metrics = metricCollector.extractMetrics(event);

            // 2. 更新指标存储（时序数据）
            metricCollector.saveMetrics(event.getTeacherId(), event.getEventType(),
                metrics, event.getTimestamp());

            // 3. 判断是否触发评分重算
            Set<String> affectedDims = DimensionEventMapper.getAffectedDimensions(
                event.getEventType()
            );

            if (ScoreUpdatePolicy.shouldRecompute(affectedDims, event)) {
                scoreUpdateTrigger.triggerAsync(
                    event.getTeacherId(),
                    affectedDims,
                    ScorePeriod.current()
                );
            }

            // 4. 记录成长轨迹事件（如果是里程碑事件）
            Optional<GrowthMilestone> milestone = milestoneDetector.detect(event);
            milestone.ifPresent(m -> {
                trajectoryService.recordMilestone(event.getTeacherId(), m);
                notificationService.notifyMilestone(event.getTeacherId(), m);
            });

        } catch (Exception e) {
            log.error("Failed to process teacher event: {}", event.getEventId(), e);
            // 发送到死信队列
            deadLetterQueue.send(event, e);
        }
    }
}
```

### 5.5 评分重算策略

不是每次事件都触发评分重算，避免高频事件导致计算风暴：

```java
public class ScoreUpdatePolicy {

    // 每个维度每天最多重算一次
    private static final Duration MIN_RECOMPUTE_INTERVAL = Duration.ofHours(6);

    // 高优事件立即触发
    private static final Set<String> HIGH_PRIORITY_EVENTS = Set.of(
        "CLASS_SCORE_UPDATED", "SURVEY_SUBMITTED"
    );

    public static boolean shouldRecompute(Set<String> affectedDims,
                                          TeacherBehaviorEvent event) {
        if (affectedDims == null || affectedDims.isEmpty()) {
            return false;
        }

        // 高优事件直接触发
        if (HIGH_PRIORITY_EVENTS.contains(event.getEventType())) {
            return true;
        }

        // 检查距上次重算的时间间隔
        String cacheKey = String.format("score:recompute:lock:%d:%s",
            event.getTeacherId(), String.join(",", affectedDims));
        return RedisLock.tryAcquire(cacheKey, MIN_RECOMPUTE_INTERVAL);
    }
}
```

```java
@Service
public class WeeklyScoreComputeJob {

    @Scheduled(cron = "0 0 2 ? * MON")
    public void executeWeeklyScoring() {
        String period = ScorePeriod.currentWeek();
        log.info("Starting weekly score computation for period: {}", period);

        // 1. 获取所有活跃教师
        List<Long> teacherIds = teacherService.getActiveTeacherIds();
        int total = teacherIds.size();

        // 2. 分批并行计算
        int batchSize = 50;
        List<List<Long>> batches = Lists.partition(teacherIds, batchSize);

        AtomicInteger completed = new AtomicInteger(0);
        batches.parallelStream().forEach(batch -> {
            for (Long teacherId : batch) {
                try {
                    computeTeacherScores(teacherId, period);
                    completed.incrementAndGet();
                } catch (Exception e) {
                    log.error("Failed to compute scores for teacher: {}", teacherId, e);
                    failedRecords.add(teacherId);
                }
            }
            // 进度上报
            log.info("Progress: {}/{} ({:.1f}%)",
                completed.get(), total, completed.get() * 100.0 / total);
        });

        // 3. 触发后置任务
        eventPublisher.publishEvent(new ScoreComputationCompletedEvent(period, completed.get()));

        log.info("Weekly scoring completed. Success: {}, Failed: {}",
            completed.get(), total - completed.get());
    }

    private void computeTeacherScores(Long teacherId, String period) {
        // 获取该教师所有活跃维度
        List<TeacherCapabilityDimension> dims = dimensionService.getActiveDimensions();

        List<TeacherCapabilityScore> scores = new ArrayList<>();
        for (TeacherCapabilityDimension dim : dims) {
            DimensionScoreResult result = scorer.score(dim.getDimCode(), teacherId, period);

            // 计算百分位排名
            BigDecimal percentile = percentileCalculator.calculate(
                result.getScore(), dim.getDimCode(), period
            );

            // 计算趋势
            TrendResult trend = trendAnalyzer.analyzeTrend(teacherId, dim.getDimCode());

            TeacherCapabilityScore score = TeacherCapabilityScore.builder()
                .teacherId(teacherId)
                .dimCode(dim.getDimCode())
                .score(result.getScore())
                .scorePeriod(period)
                .periodType("week")
                .rawDataJson(JsonUtil.toJson(result.getRawData()))
                .percentileRank(percentile)
                .trendDirection(trend.getDirection().name())
                .trendDelta(trend.getDelta())
                .computedAt(LocalDateTime.now())
                .build();

            scores.add(score);
        }

        // 批量保存
        scoreRepository.batchUpsert(scores);

        // 更新综合评分
        BigDecimal overallScore = aggregator.aggregate(scores, teacherId);
        profileService.updateOverallScore(teacherId, overallScore);

        // 清除缓存
        cacheService.evictTeacherScoreCache(teacherId);
    }
}
```

```java
@Service
public class SuggestionQualityValidator {

    /**
     * 对 AI 生成的发展建议进行质量校验
     */
    public ValidationResult validate(DevelopmentSuggestion suggestion) {
        List<String> errors = new ArrayList<>();

        // 1. 结构校验
        if (suggestion.getSuggestions() == null || suggestion.getSuggestions().isEmpty()) {
            errors.add("建议列表不能为空");
        }

        for (SuggestionItem item : suggestion.getSuggestions()) {
            // 2. 目标分数合理性
            if (item.getTargetScore() - item.getCurrentScore() > 30) {
                errors.add(String.format("维度 %s 的目标提升幅度过大（%.1f > 30）",
                    item.getDimCode(), item.getTargetScore() - item.getCurrentScore()));
            }
            if (item.getTargetScore() > 100) {
                errors.add("目标分数不能超过100");
            }

            // 3. 行动建议数量
            if (item.getActions() == null || item.getActions().size() < 2) {
                errors.add(String.format("维度 %s 的行动建议不足", item.getDimCode()));
            }

            // 4. 行动建议具体性检查
            for (Action action : item.getActions()) {
                if (action.getTitle().length() < 10) {
                    errors.add(String.format("行动标题过短：%s", action.getTitle()));
                }
                if (action.getDescription() == null || action.getDescription().length() < 20) {
                    errors.add(String.format("行动描述过短：%s", action.getTitle()));
                }
            }
        }

        return new ValidationResult(errors);
    }
}
```

```java
@Service
public class MilestoneDetector {

    @Autowired
    private MilestoneRuleRepository ruleRepository;

    @Autowired
    private TeacherMetricService metricService;

    /**
     * 检测教师是否达成新的里程碑
     */
    public List<GrowthMilestone> detectNewMilestones(Long teacherId) {
        // 获取已达成里程碑列表
        Set<String> achievedCodes = trajectoryService.getAchievedMilestoneCodes(teacherId);

        // 获取最新指标数据
        Map<String, BigDecimal> currentMetrics = metricService.getAllMetrics(teacherId);
        BigDecimal overallScore = profileService.getOverallScore(teacherId);

        List<GrowthMilestone> newMilestones = new ArrayList<>();

        for (MilestoneRule rule : ruleRepository.getActiveRules()) {
            if (achievedCodes.contains(rule.getCode())) {
                continue; // 已达成
            }

            boolean achieved = evaluateRule(rule, currentMetrics, overallScore);
            if (achieved) {
                GrowthMilestone milestone = GrowthMilestone.fromRule(rule, teacherId);
                newMilestones.add(milestone);
            }
        }

        // 按优先级排序
        newMilestones.sort(Comparator.comparing(GrowthMilestone::getPoints).reversed());

        return newMilestones;
    }

    private boolean evaluateRule(MilestoneRule rule,
                                  Map<String, BigDecimal> metrics,
                                  BigDecimal overallScore) {
        return switch (rule.getType()) {
            case COUNT_BASED -> {
                BigDecimal value = metrics.get(rule.getMetricKey());
                yield value != null && RuleConditionMatcher.match(value, rule.getCondition());
            }
            case SCORE_THRESHOLD ->
                RuleConditionMatcher.match(overallScore, rule.getCondition());
            case STREAK_BASED -> {
                BigDecimal value = metrics.get(rule.getMetricKey());
                yield value != null && RuleConditionMatcher.match(value, rule.getCondition());
            }
            case STAGE_CHANGE -> {
                // 阶段变更由 GrowthStageEvaluator 直接触发
                yield false;
            }
            case FEATURE_BASED -> {
                BigDecimal count = metrics.getOrDefault(rule.getMetricKey(), BigDecimal.ZERO);
                yield RuleConditionMatcher.match(count, rule.getCondition());
            }
        };
    }
}
```

### 10.3 大规模计算优化

```java
@Service
public class BatchScoreComputeOptimizer {

    // 教师分批并行计算
    private static final int BATCH_SIZE = 50;
    private static final int PARALLELISM = 4; // 并行度

    public void batchCompute(List<Long> teacherIds, String period) {
        // 按教师ID hash 分片，避免数据倾斜
        List<List<Long>> shards = ShardingUtils.hashShard(teacherIds, BATCH_SIZE);

        ExecutorService executor = Executors.newFixedThreadPool(PARALLELISM);
        List<Future<BatchResult>> futures = shards.stream()
            .map(shard -> executor.submit(() -> computeShard(shard, period)))
            .toList();

        // 等待所有完成，收集失败项
        List<Long> allFailed = new ArrayList<>();
        for (Future<BatchResult> future : futures) {
            try {
                BatchResult result = future.get(10, TimeUnit.MINUTES);
                allFailed.addAll(result.getFailed());
            } catch (TimeoutException e) {
                log.error("Batch computation timeout");
            }
        }

        // 失败重试（最多1次）
        if (!allFailed.isEmpty()) {
            log.warn("Retrying {} failed teachers", allFailed.size());
            retryFailed(allFailed, period);
        }
    }
}
```
