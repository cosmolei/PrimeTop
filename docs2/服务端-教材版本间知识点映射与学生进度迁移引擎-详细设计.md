# 服务端 - 教材版本间知识点映射与学生进度迁移引擎 详细设计

> 细化日期：2026-06-08
> 原始需求来源：`docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` §6.4 同步课堂、§8.6 数据架构、§10 开发优先级

## 1. 概述

### 1.1 背景

国内中小学教材版本众多（人教版、苏教版、北师大版、外研版等），且同一版本每隔数年会进行修订。学生在以下场景需要切换教材版本：

1. **转学**：新学校使用不同教材版本
2. **教材改版**：教育部统一修订，学校更换新版教材
3. **用户自行修正**：注册时选错版本，后续更正
4. **学段升迁**：小学升初中，初中升高中，不同学段教材体系完全不同

切换版本后，学生已有的学习进度、错题记录、知识掌握度等数据不能直接丢弃，需要通过**知识点映射引擎**将旧版本的学习数据映射到新版本的知识点体系上。

### 1.2 设计目标

1. 建立**跨教材版本的知识点映射表**，支持同一学科不同版本间知识点的对应关系
2. 在学生切换教材版本时，**自动迁移**学习进度、错题、知识掌握度等核心数据
3. 迁移过程**可追溯、可回滚**，保障数据安全
4. 支持**部分映射**（并非所有版本间的知识点都完全对应），合理处理无法映射的知识点
5. 为运营人员提供**映射管理后台**，支持手动配置和批量导入映射关系

### 1.3 核心概念

| 概念 | 说明 |
|------|------|
| 知识点（KnowledgePoint） | 最小不可分割的教学单元，如"一元二次方程的判别式" |
| 课程标准知识点（CurriculumKP） | 基于国家课标的标准化知识点，跨版本通用 |
| 版本专属知识点（TextbookKP） | 特定教材版本中按章节组织的知识点 |
| 映射关系（Mapping） | 两个版本知识点之间的对应关系（1:1、1:N、N:1） |
| 映射置信度 | 映射的可靠程度（高/中/低/需人工确认） |
| 迁移任务（MigrationTask） | 一次版本切换触发的数据迁移作业 |
| 迁移快照（MigrationSnapshot） | 迁移前的数据快照，用于回滚 |

## 2. 数据模型

### 2.1 课程标准知识点表 `curriculum_knowledge_points`

课标级知识点是全国统一的教学要求，作为跨版本映射的"桥梁"。

```sql
CREATE TABLE curriculum_knowledge_points (
    id                  BIGSERIAL PRIMARY KEY,
    curriculum_code     VARCHAR(32) NOT NULL,       -- 课标编号，如 "GB2022-MATH-J3-ALG-001"
    subject_code        VARCHAR(16) NOT NULL,       -- 学科代码：MATH/CHIN/ENG/PHY/CHE/BIO/HIS/GEO/POL
    stage               VARCHAR(16) NOT NULL,       -- 学段：PRIMARY/JUNIOR/SENIOR
    grade_range         VARCHAR(32),                -- 适用年级范围："7-9"
    name                VARCHAR(128) NOT NULL,      -- 知识点名称
    description         TEXT,                       -- 知识点描述
    parent_id           BIGINT REFERENCES curriculum_knowledge_points(id),
    level               SMALLINT NOT NULL DEFAULT 1, -- 层级：1=一级, 2=二级, 3=三级
    sort_order          INT NOT NULL DEFAULT 0,
    prerequisite_ids    BIGINT[],                   -- 前置知识点ID数组
    cognitive_level     VARCHAR(32),                -- 认知要求：KNOW/UNDERSTAND/APPLY/ANALYZE/SYNTHESIZE
    status              VARCHAR(16) NOT NULL DEFAULT 'ACTIVE', -- ACTIVE/DEPRECATED
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (curriculum_code)
);

CREATE INDEX idx_ckp_subject_stage ON curriculum_knowledge_points(subject_code, stage);
CREATE INDEX idx_ckp_parent ON curriculum_knowledge_points(parent_id);
```

### 2.2 版本知识点与课标映射表 `textbook_kp_curriculum_mapping`

每个教材版本的知识点都映射到课标知识点，作为跨版本映射的桥梁。

```sql
CREATE TABLE textbook_kp_curriculum_mapping (
    id                  BIGSERIAL PRIMARY KEY,
    textbook_id         BIGINT NOT NULL,            -- 关联教材版本
    chapter_kp_id       BIGINT NOT NULL,            -- 关联教材章节知识点（textbook_chapter_kps.id）
    curriculum_kp_id    BIGINT NOT NULL REFERENCES curriculum_knowledge_points(id),
    coverage            DECIMAL(3,2) NOT NULL DEFAULT 1.00, -- 覆盖度：该版本KP覆盖课标KP的程度 0.00-1.00
    confidence          VARCHAR(16) NOT NULL DEFAULT 'HIGH', -- HIGH/MEDIUM/LOW/MANUAL_REVIEW
    mapping_source      VARCHAR(32) NOT NULL DEFAULT 'AUTO', -- AUTO/MANUAL/IMPORT
    mapped_by           BIGINT,                     -- 手动映射时的操作人ID
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (textbook_id, chapter_kp_id, curriculum_kp_id)
);

CREATE INDEX idx_tkcm_textbook ON textbook_kp_curriculum_mapping(textbook_id);
CREATE INDEX idx_tkcm_curriculum ON textbook_kp_curriculum_mapping(curriculum_kp_id);
CREATE INDEX idx_tkcm_confidence ON textbook_kp_curriculum_mapping(confidence);
```

### 2.3 跨版本直接映射表 `cross_textbook_kp_mapping`

对于高频切换的版本对（如人教版↔苏教版），可直接建立映射关系，避免通过课标中转的精度损失。

```sql
CREATE TABLE cross_textbook_kp_mapping (
    id                  BIGSERIAL PRIMARY KEY,
    source_textbook_id  BIGINT NOT NULL,
    target_textbook_id  BIGINT NOT NULL,
    source_kp_id        BIGINT NOT NULL,
    target_kp_id        BIGINT NOT NULL,
    mapping_type        VARCHAR(16) NOT NULL DEFAULT 'ONE_TO_ONE', -- ONE_TO_ONE/ONE_TO_MANY/MANY_TO_ONE/PARTIAL
    similarity          DECIMAL(3,2) NOT NULL,       -- 相似度 0.00-1.00
    confidence          VARCHAR(16) NOT NULL DEFAULT 'HIGH',
    mapping_source      VARCHAR(32) NOT NULL DEFAULT 'AUTO',
    note                TEXT,                        -- 映射备注（如"新版新增，无对应"）
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (source_textbook_id, target_textbook_id, source_kp_id, target_kp_id)
);

CREATE INDEX idx_ctkm_pair ON cross_textbook_kp_mapping(source_textbook_id, target_textbook_id);
CREATE INDEX idx_ctkm_source_kp ON cross_textbook_kp_mapping(source_textbook_id, source_kp_id);
CREATE INDEX idx_ctkm_similar ON cross_textbook_kp_mapping(similarity);
```

## 4. 核心流程设计

### 4.1 迁移主流程状态机

```
PENDING ──→ SNAPSHOTTING ──→ MAPPING ──→ MIGRATING ──→ COMPLETED
  │              │               │            │              │
  │              │               │            │              └──→ (可回滚)
  │              │               │            └──→ FAILED ──→ ROLLBACK
  │              │               └──→ FAILED (映射覆盖率不足)
  │              └──→ FAILED (快照失败)
  └──→ CANCELLED
```

### 4.2 映射查询策略

查找源知识点在目标版本中的映射时，按以下优先级：

1. **直接映射**（`cross_textbook_kp_mapping`）：精确的版本对映射，优先级最高
2. **课标桥接映射**：源版本KP → 课标KP → 目标版本KP，通过 `textbook_kp_curriculum_mapping` 两次 JOIN
3. **AI 辅助映射**：对于无预设映射的知识点，调用 AI 基于知识点名称和描述进行相似度匹配，生成临时映射（需人工确认）

```python
async def find_mapping(source_kp_id: int, source_tb_id: int, target_tb_id: int) -> MappingResult:
    """三级映射查询策略"""
    
    # Level 1: 直接映射
    direct = await db.fetch_one(
        """SELECT target_kp_id, similarity, confidence, mapping_type
           FROM cross_textbook_kp_mapping
           WHERE source_textbook_id = %s AND target_textbook_id = %s
             AND source_kp_id = %s AND confidence != 'MANUAL_REVIEW'
           ORDER BY similarity DESC LIMIT 1""",
        source_tb_id, target_tb_id, source_kp_id
    )
    if direct and direct['similarity'] >= 0.7:
        return MappingResult(method='DIRECT', **direct)
    
    # Level 2: 课标桥接
    bridge = await db.fetch_one(
        """SELECT t2.chapter_kp_id AS target_kp_id, 
                  LEAST(t1.coverage, t2.coverage) AS similarity,
                  CASE 
                    WHEN LEAST(t1.confidence, t2.confidence) = 'HIGH' THEN 'HIGH'
                    WHEN LEAST(t1.confidence, t2.confidence) = 'MEDIUM' THEN 'MEDIUM'
                    ELSE 'LOW'
                  END AS confidence
           FROM textbook_kp_curriculum_mapping t1
           JOIN textbook_kp_curriculum_mapping t2 
             ON t1.curriculum_kp_id = t2.curriculum_kp_id
           WHERE t1.textbook_id = %s AND t1.chapter_kp_id = %s
             AND t2.textbook_id = %s
           ORDER BY similarity DESC LIMIT 1""",
        source_tb_id, source_kp_id, target_tb_id
    )
    if bridge:
        return MappingResult(method='CURRICULUM_BRIDGE', **bridge)
    
    # Level 3: AI辅助映射（异步，标记为待确认）
    ai_mapping = await ai_assisted_mapping(source_kp_id, source_tb_id, target_tb_id)
    if ai_mapping:
        return MappingResult(method='AI_ASSISTED', confidence='LOW', **ai_mapping)
    
    return MappingResult(method='NONE', target_kp_id=None, similarity=0)
```

### 4.3 迁移执行流程（伪代码）

```python
async def execute_migration(task: MigrationTask):
    """迁移主流程"""
    try:
        # Phase 1: 快照
        await update_task_status(task.id, 'SNAPSHOTTING')
        snapshot = await create_snapshot(task)
        await update_task(task.id, snapshot_id=snapshot.id)
        
        # Phase 2: 映射分析
        await update_task_status(task.id, 'MAPPING')
        mapping_plan = await build_migration_plan(
            task.source_textbook_id, 
            task.target_textbook_id,
            task.subject_code
        )
        
        # 检查覆盖率
        if mapping_plan.coverage < 0.3:
            raise MigrationError(
                f"映射覆盖率 {mapping_plan.coverage:.0%} 低于最低阈值 30%，请先补充映射关系"
            )
        
        # Phase 3: 数据迁移
        await update_task_status(task.id, 'MIGRATING')
        
        # 3a: 迁移学习进度
        progress_records = await fetch_learning_progress(
            task.student_profile_id, task.source_textbook_id
        )
        for record in progress_records:
            mapping = await find_mapping(
                record.kp_id, task.source_textbook_id, task.target_textbook_id
            )
            if mapping.target_kp_id:
                await migrate_progress_record(record, mapping, task.target_textbook_id)
                await increment_migrated(task.id)
            else:
                await log_skip(task.id, record, 'PROGRESS', 'NO_MAPPING')
                await increment_skipped(task.id)
        
        # 3b: 迁移知识掌握度
        mastery_records = await fetch_mastery_levels(
            task.student_profile_id, task.source_textbook_id
        )
        for record in mastery_records:
            mapping = await find_mapping(
                record.kp_id, task.source_textbook_id, task.target_textbook_id
            )
            if mapping.target_kp_id:
                # 掌握度需要聚合：多个源KP映射到同一目标KP时取加权平均
                await migrate_mastery_record(record, mapping, task.target_textbook_id)
                await increment_migrated(task.id)
            else:
                await log_skip(task.id, record, 'MASTERY', 'NO_MAPPING')
                await increment_skipped(task.id)
        
        # 3c: 迁移错题记录
        mistake_records = await fetch_mistake_records(
            task.student_profile_id, task.source_textbook_id
        )
        for record in mistake_records:
            mapping = await find_mapping(
                record.kp_id, task.source_textbook_id, task.target_textbook_id
            )
            if mapping.target_kp_id:
                await migrate_mistake_record(record, mapping, task.target_textbook_id)
                await increment_migrated(task.id)
            else:
                # 无映射的错题不丢弃，保留在"未分类"区域
                await migrate_mistake_to_unclassified(record, task.target_textbook_id)
                await log_skip(task.id, record, 'MISTAKE', 'MAPPED_TO_UNCLASSIFIED')
                await increment_migrated(task.id)  # 仍然算迁移成功
        
        # Phase 4: 完成
        await update_task_status(task.id, 'COMPLETED', completed_at=NOW())
        
        # 发送通知
        await notify_migration_complete(task.user_id, task.id, mapping_plan.coverage)
        
    except Exception as e:
        await update_task_status(task.id, 'FAILED', error_message=str(e))
        # 自动回滚
        await rollback_migration(task.id)
```

### 4.4 回滚流程

```python
async def rollback_migration(task_id: int):
    """基于快照回滚迁移"""
    task = await get_task(task_id)
    
    if task.status not in ('COMPLETED', 'FAILED'):
        raise MigrationError("只能回滚已完成或失败的任务")
    
    # 检查回滚有效期
    if task.completed_at and (NOW() - task.completed_at).days > 7:
        raise MigrationError("超过7天回滚有效期")
    
    snapshot = await get_snapshot(task.snapshot_id)
    
    # 验证快照完整性
    if not verify_checksum(snapshot):
        raise MigrationError("快照数据损坏，无法回滚")
    
    # 逐类型恢复
    for snapshot_type in ['PROGRESS', 'MASTERY', 'MISTAKE']:
        data = snapshot.snapshot_data.get(snapshot_type, [])
        await restore_from_snapshot(task.student_profile_id, task.target_textbook_id, data)
    
    await update_task_status(task_id, 'ROLLBACK')
```

### 4.5 掌握度聚合算法

当多个源知识点映射到同一个目标知识点时，需要聚合掌握度：

```python
def aggregate_mastery(source_masteries: list[MasteryRecord]) -> float:
    """
    聚合多个源知识点的掌握度到目标知识点。
    
    策略：按映射覆盖率加权平均，但偏向保守（取较低值）
    最终值 = 0.6 * 加权平均 + 0.4 * 最小值
    """
    if not source_masteries:
        return 0.0
    
    if len(source_masteries) == 1:
        return source_masteries[0].mastery_level
    
    total_weight = sum(m.coverage for m in source_masteries)
    if total_weight == 0:
        return 0.0
    
    weighted_avg = sum(m.mastery_level * m.coverage for m in source_masteries) / total_weight
    min_level = min(m.mastery_level for m in source_masteries)
    
    # 保守聚合：偏向低估而非高估掌握度
    return round(0.6 * weighted_avg + 0.4 * min_level, 2)
```

## 9. 性能考量

### 9.1 数据量估算

| 数据类型 | 单学科年均量 | 迁移扫描量 |
|---------|------------|-----------|
| 学习进度记录 | ~200 条 | 小 |
| 知识掌握度 | ~150 条 | 小 |
| 错题记录 | ~500 条 | 中 |
| 答题记录 | ~2000 条 | 大（仅迁移关联的） |

**预期迁移时间**：单学科 < 60 秒

### 9.2 优化策略

1. **批量查询映射关系**：预先加载所有映射到内存，避免逐条查询
2. **批量写入**：按类型分组，使用批量 INSERT
3. **异步执行**：不阻塞 API 响应，后台 Worker 处理
4. **缓存热点映射**：高频版本对映射关系缓存在 Redis，TTL 1小时

```python
async def preload_mappings(source_tb_id: int, target_tb_id: int) -> dict[int, MappingResult]:
    """预加载所有映射关系到内存"""
    cache_key = f"kp_mapping:{source_tb_id}:{target_tb_id}"
    
    cached = await redis.get(cache_key)
    if cached:
        return deserialize_mappings(cached)
    
    # 查询直接映射
    direct_mappings = await db.fetch_all(
        """SELECT source_kp_id, target_kp_id, similarity, confidence, mapping_type
           FROM cross_textbook_kp_mapping
           WHERE source_textbook_id = %s AND target_textbook_id = %s""",
        source_tb_id, target_tb_id
    )
    
    # 查询课标桥接映射
    bridge_mappings = await db.fetch_all(
        """SELECT t1.chapter_kp_id AS source_kp_id,
                  t2.chapter_kp_id AS target_kp_id,
                  LEAST(t1.coverage, t2.coverage) AS similarity
           FROM textbook_kp_curriculum_mapping t1
           JOIN textbook_kp_curriculum_mapping t2 ON t1.curriculum_kp_id = t2.curriculum_kp_id
           WHERE t1.textbook_id = %s AND t2.textbook_id = %s""",
        source_tb_id, target_tb_id
    )
    
    mappings = merge_mapping_sources(direct_mappings, bridge_mappings)
    await redis.setex(cache_key, 3600, serialize_mappings(mappings))
    
    return mappings
```

## 10. 安全与合规

1. **数据隔离**：迁移只影响当前学生的数据，不涉及其他用户
2. **操作审计**：所有迁移操作记录审计日志，包含操作人、时间、原因
3. **快照加密**：快照数据使用 AES-256 加密存储，包含完整性校验
4. **权限控制**：迁移 API 需验证用户身份，只有学生本人或绑定的家长可触发
5. **频率限制**：同一学生同一学科 24 小时内最多触发 3 次迁移
6. **数据最小化**：快照在保留期后自动删除
