# 服务端 - 用户提问质量评估与低质提问智能引导优化引擎 - 详细设计

> **文档版本**: v1.0
> **创建日期**: 2026-06-20
> **所属模块**: AI 智能辅导
> **优先级**: P1
> **依赖模块**: AI对话引擎、Prompt编排系统、学科上下文管理、学习画像服务

---

## 1. 模块概述

### 1.1 设计目标

构建一套**前置提问质量评估 + 智能引导优化**管线，在用户提交问题给 AI 辅导引擎之前，对提问内容进行质量诊断。当检测到模糊、残缺、过于宽泛或表述不清的问题时，系统不会直接调用大模型（避免浪费 Token 和产生低质回答），而是：

1. 向用户反馈问题质量诊断结果
2. 提供针对性的问题优化建议和改写模板
3. 引导用户补充关键信息（学科、年级上下文、具体疑问点）
4. 在用户确认后，将优化后的问题提交给 AI 引擎

### 1.2 核心价值

| 维度 | 收益 |
|------|------|
| **用户体验** | 低质提问会导致 AI 回答泛泛、答非所问，引导用户改出好问题能显著提升回答满意度（预计提升 25-40% 的"有帮助"反馈率） |
| **API 成本** | 拦截低质问题，避免无效的大模型调用，预估节省 15-20% 的日均 Token 消耗 |
| **教学效果** | "学会提问"本身就是核心学习能力，系统化的引导可培养元认知能力 |
| **数据质量** | 高质量的提问记录有助于后续学情分析和内容推荐 |

### 1.3 适用场景

| 场景 | 入口 | 示例 |
|------|------|------|
| AI 文字对话 | 用户在 AI 辅导页输入框提交问题 | "这个怎么做" |
| 拍照搜题补充描述 | 用户拍照后补充文字说明 | "不会" |
| 语音提问转文字 | ASR 结果作为问题输入 | "嗯...那个...就是老师讲的那个" |
| 追问场景 | 多轮对话中的后续提问 | "再说说"（缺少上下文指代） |


**与已有模块的关系：**

| 已有模块 | 关系 |
|---------|------|
| `AI输入安全与教育对话护栏引擎` | **上游**：安全过滤先执行，通过后再进入本模块做质量评估 |
| `AI辅导全链路请求处理与编排` | **下游**：质量评估通过的问题进入全链路编排 |
| `AI-Prompt编排与场景模板系统` | **协作**：本模块使用场景模板识别学科和年级上下文 |
| `学习场景意图识别与智能路由引擎` | **协作**：意图识别结果作为质量评估的上下文输入 |
| `用户学习画像与能力维度模型` | **依赖**：获取用户年级、学科、近期学习内容作为评估上下文 |

## 3. 核心数据结构

### 3.1 提问质量评估请求

```java
public class QuestionEvaluationRequest {

    /** 用户ID */
    private Long userId;

    /** 原始问题文本 */
    private String rawQuestion;

    /** 输入方式: TEXT / VOICE / PHOTO_SUPPLEMENT */
    private InputType inputType;

    /** 输入方式枚举 */
    public enum InputType {
        TEXT,               // 文字输入
        VOICE_ASR,          // 语音转文字
        PHOTO_SUPPLEMENT,   // 拍照补充描述
        FOLLOW_UP           // 追问
    }

    /** 当前会话ID（追问场景） */
    private String sessionId;

    /** 当前学科上下文（可选，客户端可能已知） */
    private String subject;

    /** 当前年级 */
    private Integer gradeLevel;

    /** 用户选择的学段 */
    private String stageLevel; // KINDERGARTEN / PRIMARY / JUNIOR / SENIOR

    /** 客户端预处理信息 */
    private ClientPreprocessInfo clientInfo;

    /** 拍照场景下的图片URL（如有） */
    private String imageUrl;

    /** 设备信息 */
    private String deviceId;

    /** 时间戳 */
    private Long timestamp;

    public static class ClientPreprocessInfo {
        /** 客户端本地规则检测结果 */
        private boolean tooShort;       // 长度过短
        private boolean onlyPunctuation; // 仅标点
        private boolean onlyEmoji;      // 仅表情
        private int charCount;          // 字符数
        private boolean hasImage;       // 是否附带图片
    }
}
```

### 3.2 提问质量评估结果

```java
public class QuestionEvaluationResult {

    /** 评估唯一ID */
    private String evaluationId;

    /** 质量等级 */
    private QualityLevel qualityLevel;

    /** 质量等级枚举 */
    public enum QualityLevel {
        HIGH,       // 高质量：清晰、具体、上下文充分
        MEDIUM,     // 中等：基本可理解但可优化
        LOW,        // 低质量：模糊、残缺、过于宽泛
        REJECT      // 拒绝：空内容、纯噪声、非学习相关
    }

    /** 总质量分 (0-100) */
    private Integer qualityScore;

    /** 分维度评分 */
    private DimensionScores dimensionScores;

    /** 检测到的问题标签列表 */
    private List<QualityIssue> issues;

    /** 学科识别结果 */
    private String detectedSubject;

    /** 推荐的优化方案 */
    private OptimizationSuggestion suggestion;

    /** 决策动作 */
    private Action action;

    public enum Action {
        PASS_TO_AI,        // 直接转交AI引擎
        GUIDE_USER,        // 引导用户优化
        REJECT,            // 拒绝（安全或空内容）
        CLARIFY_NEEDED     // 需要用户澄清
    }

    /** 评估耗时(ms) */
    private Long evaluationDurationMs;

    /** 评估模型版本 */
    private String modelVersion;
}
```

### 3.3 分维度评分

```java
public class DimensionScores {

    /** 清晰度 (0-100): 问题是否表述清楚 */
    private Integer clarity;

    /** 具体性 (0-100): 是否有具体的知识点/题目/章节指向 */
    private Integer specificity;

    /** 完整性 (0-100): 是否包含足够上下文让AI理解 */
    private Integer completeness;

    /** 学术相关性 (0-100): 是否是学习相关问题 */
    private Integer academicRelevance;

    /** 年级适配性 (0-100): 表述方式是否符合年级水平 */
    private Integer gradeAlignment;

    /** 各维度权重 (用于计算总分) */
    public static final double[] WEIGHTS = {
        0.25,  // clarity
        0.20,  // specificity
        0.20,  // completeness
        0.20,  // academicRelevance
        0.15   // gradeAlignment
    };
}
```

### 3.4 质量问题标签

```java
public class QualityIssue {

    /** 问题类型 */
    private IssueType type;

    /** 问题严重程度 */
    private Severity severity;

    /** 具体描述 */
    private String description;

    /** 涉及的原文片段 */
    private String textSegment;

    public enum IssueType {
        TOO_SHORT,              // 过于简短
        TOO_BROAD,              // 过于宽泛 ("数学怎么学")
        MISSING_CONTEXT,        // 缺少上下文 ("这道题怎么做" 但无图片)
        VAGUE_REFERENCE,        // 指代不明 ("那个公式"、"老师讲的")
        AMBIGUOUS_SUBJECT,      // 学科不明 ("这个怎么算" — 算什么？)
        NO_QUESTION_MARK,       // 无明确问题（陈述而非提问）
        OFF_TOPIC,              // 非学习相关
        INAPPROPRIATE_GRADE,    // 表述与年级不匹配
        GIBBERISH,              // 无意义内容
        EXAM_ANSWER_FISHING,    // 疑似直接套答案
        DUPLICATE_QUESTION,     // 重复提问（短时间内多次相同问题）
        VOICE_TRANSCRIPTION_ERR // 疑似语音转写错误
    }

    public enum Severity {
        INFO,       // 提示
        WARNING,    // 警告
        CRITICAL    // 严重（影响AI能否回答）
    }
}
```

```java
public class OptimizationSuggestion {

    /** 建议类型 */

    public enum SuggestionType {

    /** 改写后的问题示例（1-3条） */
    private List<RewriteOption> rewriteOptions;

    /** 需要用户补充的信息项 */
    private List<SupplementItem> supplementItems;

    /** 推荐的提问模板 */
    private List<QuestionTemplate> templates;

    /** 引导弹窗标题 */
    private String guideTitle;

    /** 引导弹窗描述 */
    private String guideDescription;

    /** 引导操作按钮配置 */
    private List<GuideAction> actions;

    public static class RewriteOption {
        private String text;                // 改写后的问题
        private String explanation;         // 改写说明
        private boolean autoFillOnSelect;   // 用户选择后是否自动填入输入框
    }

    public static class SupplementItem {
        private String label;           // "请选择学科"
        private SupplementType type;    // 选择/输入/拍照
        private List<String> options;   // 选项列表
        private boolean required;       // 是否必填
        private String placeholder;

        public enum SupplementType {
            SUBJECT_SELECT,     // 学科选择
            GRADE_CONFIRM,      // 年级确认
            CHAPTER_SELECT,     // 章节选择
            PHOTO_ATTACH,       // 拍照补充
            TEXT_SUPPLEMENT,    // 文字补充
            KNOWLEDGE_POINT     // 知识点选择
        }
    }

    public static class QuestionTemplate {
        private String template;        // "如何用{方法}解决{知识点}问题？"
        private String filledExample;   // "如何用配方法解一元二次方程？"
        private String subject;
        private String category;        // 模板分类
    }

    public static class GuideAction {
        private String label;       // "使用建议改写"
        private String action;      // APPLY_REWRITE / IGNORE / EDIT_MANUALLY
        private Map<String, Object> params;
    }
}
```

## 4. 核心流程设计

### 4.1 提问质量评估主流程

```
┌──────────────┐
│  用户提交问题  │
└──────┬───────┘
       │
       ▼
┌──────────────────────┐
│ Step 1: 基础预处理     │  ← 文本清洗、长度检查、特殊字符过滤
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ Step 2: 规则引擎评估   │  ← 快速模式匹配，检测明显问题
│ (同步, <10ms)        │
└──────┬───────────────┘
       │
       ├─ REJECT (空内容/纯噪声/非学习) → 返回拒绝
       │
       ▼
┌──────────────────────┐
│ Step 3: NLP 轻量分析  │  ← 分词、句法、关键词提取、学科识别
│ (同步, <50ms)        │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ Step 4: 上下文增强检查  │  ← 结合用户画像、会话历史、学科上下文
│ (同步, <30ms)        │
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ Step 5: 综合评分与决策  │  ← 加权计算总分，判定质量等级
└──────┬───────────────┘
       │
       ├─ HIGH (≥70): PASS_TO_AI → 转交AI引擎
       ├─ MEDIUM (40-69): GUIDE_USER (轻量提示) → 转交AI引擎（带优化标记）
       ├─ LOW (10-39): GUIDE_USER → 返回引导建议
       └─ REJECT (<10): REJECT → 返回拒绝原因
```

### 4.3 规则引擎评估流程

规则引擎是质量评估的第一道关卡，使用纯规则进行快速过滤（<10ms）。

```java
/**
 * 规则链示调器 — 责任链模式
 */
public class RuleEngineEvaluator {

    private final List<QualityRule> ruleChain;

    public RuleChainResult evaluate(EvaluationContext ctx) {
        RuleChainResult result = new RuleChainResult();

        for (QualityRule rule : ruleChain) {
            if (!rule.applies(ctx)) {
                continue;
            }

            RuleMatch match = rule.check(ctx);
            if (match.isHit()) {
                result.addIssue(match.getIssue());
                result.addPenalty(match.getPenalty());

                // 短路规则：命中即直接返回（如空内容、纯噪声）
                if (match.isShortCircuit()) {
                    result.setShortCircuited(true);
                    break;
                }
            }
        }

        return result;
    }
}
```

### 4.4 NLP 轻量分析流程

在规则引擎之后执行，使用轻量NLP模型（不调用大模型API）进行深度分析。

```java
public class LightNlpAnalyzer {

    /**
     * 执行NLP分析
     * 目标延迟: < 50ms
     * 使用本地模型/规则库，不调用外部API
     */
    public NlpAnalysisResult analyze(String text, EvaluationContext ctx) {
        NlpAnalysisResult result = new NlpAnalysisResult();

        // 1. 中文分词 + 词性标注
        List<Token> tokens = tokenizer.segment(text);
        result.setTokens(tokens);

        // 2. 关键词提取 (TF-IDF + 教育领域词典)
        List<String> keywords = keywordExtractor.extract(tokens, EDU_DICT);
        result.setKeywords(keywords);

        // 3. 学科识别 (基于关键词 + 术语词典匹配)
        SubjectDetectionResult subjectResult = subjectDetector.detect(keywords, tokens);
        result.setSubjectDetection(subjectResult);

        // 4. 句法简化分析 (是否含问句结构、条件从句等)
        SyntaxAnalysis syntax = syntaxAnalyzer.analyze(tokens);
        result.setSyntax(syntax);

        // 5. 指代消解检测 (是否存在未解决的指代)
        List<Coreference> corefs = coreferenceDetector.detect(tokens, ctx.getSessionHistory());
        result.setCoreferences(corefs);

        // 6. 信息密度计算
        double density = informationDensityCalculator.calculate(tokens, keywords);
        result.setInformationDensity(density);

        return result;
    }
}
```

### 4.5 学科识别子流程

学科识别是质量评估的关键前置步骤，直接影响后续评分和模板推荐。

```java
public class SubjectDetector {

    // 学科关键词词典 (维护在配置中心，可热更新)
    private volatile Map<String, SubjectScore> subjectKeywordDict;

    /**
     * 基于多信号融合的学科检测
     */
    public SubjectDetectionResult detect(List<String> keywords, List<Token> tokens) {
        Map<String, Double> scores = new HashMap<>();

        // 信号1: 关键词直接匹配
        for (String kw : keywords) {
            SubjectScore ss = subjectKeywordDict.get(kw);
            if (ss != null) {
                ss.getSubjectScores().forEach((subj, score) ->
                    scores.merge(subj, score, Double::sum));
            }
        }

        // 信号2: 学科特有符号检测
        // 数学: ±, ≈, ∠, ∑, ∀, ∃, ⊥, ∥, f(x), sin, cos
        // 化学: Fe, Cu, H₂SO₄, →, ↑, ↓
        // 物理: N, m/s, kg, J, W, V, Ω, F₁, F₂
        SymbolSubject symbolSubject = detectSymbols(tokens);
        if (symbolSubject != null) {
            scores.merge(symbolSubject.getSubject(), 15.0, Double::sum);
        }

        // 信号3: 题型模式匹配
        // "翻译" → 英语/语文
        // "求证" → 数学/几何
        // "解释...原因" → 文科综合
        PatternSubject patternSubject = detectPatterns(tokens);
        if (patternSubject != null) {
            scores.merge(patternSubject.getSubject(), 10.0, Double::sum);
        }

        // 归一化 & 判定
        String topSubject = scores.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElse("UNKNOWN");

        double confidence = scores.getOrDefault(topSubject, 0.0);

        return SubjectDetectionResult.builder()
            .subject(topSubject)
            .confidence(confidence)
            .allScores(scores)
            .isAmbiguous(confidence < 20.0 && scores.size() > 1)
            .build();
    }
}
```

### 4.6 上下文增强检查

```java
public class ContextEnhancer {

    /**
     * 结合用户上下文进行增强评估
     */
    public ContextEvaluation evaluate(EvaluationContext ctx, NlpAnalysisResult nlp) {
        ContextEvaluation result = new ContextEvaluation();

        // 1. 会话历史检查（追问场景）
        if (ctx.getSessionId() != null) {
            List<ChatMessage> history = sessionCache.getRecentMessages(
                ctx.getSessionId(), 10);

            // 检查指代是否能在历史中消解
            for (Coreference coref : nlp.getCoreferences()) {
                boolean resolvable = checkCoreferenceResolution(coref, history);
                if (!resolvable) {
                    result.addIssue(QualityIssue.builder()
                        .type(IssueType.VAGUE_REFERENCE)
                        .severity(Severity.WARNING)
                        .description("指代「" + coref.getText() + "」无法确定指向")
                        .build());
                    result.addPenalty(15);
                }
            }

            // 检查追问是否与上文关联
            if (!hasContextRelation(nlp, history)) {
                result.addIssue(QualityIssue.builder()
                    .type(IssueType.MISSING_CONTEXT)
                    .severity(Severity.WARNING)
                    .description("当前问题与上文关联不明确")
                    .build());
                result.addPenalty(10);
            }
        }

        // 2. 拍照上下文检查
        if (ctx.hasImage()) {
            // 有图片时，文字描述简短是合理的
            // 但纯空白/无意义仍需引导
            if (nlp.getInformationDensity() < 0.1 && !ctx.hasImage()) {
                result.addIssue(QualityIssue.builder()
                    .type(IssueType.MISSING_CONTEXT)
                    .severity(Severity.CRITICAL)
                    .description("请提供更多细节，或拍照上传题目")
                    .build());
                result.addPenalty(25);
            }
        } else {
            // 无图片时，"这道题"/"这"等指示词需要额外上下文
            if (containsDemonstrative(nlp.getTokens())) {
                result.addIssue(QualityIssue.builder()
                    .type(IssueType.MISSING_CONTEXT)
                    .severity(Severity.WARNING)
                    .description("您提到的内容需要拍照或补充更多信息")
                    .build());
                result.addPenalty(20);
            }
        }

        // 3. 年级适配检查
        int userGrade = ctx.getUserContext().getGradeLevel();
        GradeComplexity complexity = estimateComplexity(nlp);
        if (complexity.isMismatched(userGrade)) {
            result.addIssue(QualityIssue.builder()
                .type(IssueType.INAPPROPRIATE_GRADE)
                .severity(Severity.INFO)
                .description("问题复杂度与年级水平可能有差异")
                .build());
            result.addPenalty(5);
        }

        return result;
    }
}
```

### 5.1 改写建议生成算法

当质量问题被检测到后，系统需要生成具体、可操作的改写建议。改写**不调用大模型**，而是使用基于规则和模板的快速生成方案。

```java
public class RewriteSuggestionGenerator {

    /**
     * 基于问题类型和上下文生成改写建议
     */
    public List<RewriteOption> generate(
            String rawQuestion,
            List<QualityIssue> issues,
            NlpAnalysisResult nlp,
            EvaluationContext ctx) {

        List<RewriteOption> options = new ArrayList<>();

        // 策略1: 补充学科和知识点上下文
        if (hasIssue(issues, IssueType.TOO_BROAD) ||
            hasIssue(issues, IssueType.MISSING_CONTEXT)) {

            String subject = nlp.getSubjectDetection().getSubject();
            if (!"UNKNOWN".equals(subject)) {
                RewriteOption opt = generateContextEnrichedRewrite(
                    rawQuestion, subject, nlp.getKeywords(), ctx);
                options.add(opt);
            }
        }

        // 策略2: 具体化模糊指代
        if (hasIssue(issues, IssueType.VAGUE_REFERENCE)) {
            RewriteOption opt = generateSpecificReferenceRewrite(
                rawQuestion, nlp.getCoreferences(), ctx);
            if (opt != null) {
                options.add(opt);
            }
        }

        // 策略3: 转换为提问句式
        if (hasIssue(issues, IssueType.NO_QUESTION)) {
            RewriteOption opt = generateQuestionFormRewrite(
                rawQuestion, nlp.getKeywords());
            options.add(opt);
        }

        // 策略4: 分解宽泛问题为具体子问题
        if (hasIssue(issues, IssueType.TOO_BROAD)) {
            List<RewriteOption> subQuestions = decomposeBroadQuestion(
                rawQuestion, nlp, ctx);
            options.addAll(subQuestions);
        }

        // 策略5: 基于学习进度的个性化改写
        RewriteOption personalized = generatePersonalizedRewrite(
            rawQuestion, nlp, ctx.getUserContext());
        if (personalized != null) {
            options.add(personalized);
        }

        // 去重 + 限流（最多3条）
        return options.stream()
            .distinct()
            .limit(3)
            .collect(Collectors.toList());
    }

    /**
     * 示例：将"数学怎么学"改写为具体问题
     */
    private RewriteOption generateContextEnrichedRewrite(
            String raw, String subject,
            List<String> keywords, EvaluationContext ctx) {

        // 获取用户当前正在学习的章节
        String currentChapter = ctx.getUserContext().getCurrentChapter(subject);

        if (currentChapter != null) {
            String rewritten = String.format(
                "我在学%s的%s，有些地方不太懂，能帮我讲讲%s的主要知识点吗？",
                subject, currentChapter, currentChapter);

            return RewriteOption.builder()
                .text(rewritten)
                .explanation("结合您当前的学习进度，建议围绕「" + currentChapter + "」提问")
                .autoFillOnSelect(true)
                .build();
        }

        // 退化为知识点级别的建议
        return RewriteOption.builder()
            .text(subject + "的哪个知识点您最想了解？比如可以问：" +
                  getExampleQuestion(subject, ctx.getUserContext().getGradeLevel()))
            .explanation("将宽泛问题聚焦到具体知识点效果更好")
            .autoFillOnSelect(false)
            .build();
    }

    /**
     * 分解宽泛问题
     * "英语怎么提高" → [
     *   "英语听力怎么训练？",
     *   "英语阅读理解总是错怎么办？",
     *   "英语语法有哪些重点？"
     * ]
     */
    private List<RewriteOption> decomposeBroadQuestion(
            String raw, NlpAnalysisResult nlp, EvaluationContext ctx) {

        String subject = nlp.getSubjectDetection().getSubject();
        List<RewriteOption> results = new ArrayList<>();

        // 从模板库获取该学科的分解模板
        List<QuestionTemplate> templates = templateService
            .findBySubjectAndCategory(subject, "decompose");

        for (QuestionTemplate t : templates) {
            RewriteOption opt = RewriteOption.builder()
                .text(t.getFilledExample())
                .explanation("这是" + subject + "学习中常见的核心问题")
                .autoFillOnSelect(true)
                .build();
            results.add(opt);
        }

        return results;
    }
}
```

```java
public class TemplateRecommender {

    /**
     * 基于学科、年级、问题类型推荐提问模板
     */
    public List<QuestionTemplate> recommend(
            String subject,
            Integer gradeLevel,
            String issueType,
            int limit) {

        // 多级查询策略
        // 1. 精确匹配：学科 + 年级 + 问题类型
        List<QuestionTemplate> templates = templateService.find(
            TemplateQuery.builder()
                .subject(subject)
                .stageLevel(toStage(gradeLevel))
                .category(issueType)
                .status("ACTIVE")
                .orderByPriority()
                .build());

        // 2. 放宽年级约束
        if (templates.size() < limit) {
            templates.addAll(templateService.find(
                TemplateQuery.builder()
                    .subject(subject)
                    .category(issueType)
                    .status("ACTIVE")
                    .orderByPriority()
                    .build()));
        }

        // 3. 放宽学科约束（通用模板）
        if (templates.size() < limit) {
            templates.addAll(templateService.find(
                TemplateQuery.builder()
                    .subject("GENERAL")
                    .category(issueType)
                    .status("ACTIVE")
                    .orderByPriority()
                    .build()));
        }

        return templates.stream()
            .distinct()
            .limit(limit)
            .collect(Collectors.toList());
    }
}
```

### 8.1 客户端本地预检SDK

为了减少不必要的网络请求，客户端先进行本地快速预检。约 60% 的低质问题可以在客户端被拦截或预判。

```dart
/// 客户端提问预检器 (Flutter/Dart)
class QuestionPreChecker {

  /// 本地预检规则
  PreCheckResult preCheck(String input, {bool hasImage}) {
    var result = PreCheckResult();

    // 1. 空内容检查
    if (input.trim().isEmpty && !hasImage) {
      return result
        ..action = PreCheckAction.BLOCK
        ..message = '请输入您的问题';
    }

    // 2. 长度检查
    int charCount = input.trim().length;
    if (charCount < 4 && !hasImage) {
      result.flags.add(PreCheckFlag.tooShort);
      result.charCount = charCount;
    }

    // 3. 纯标点/表情检查
    if (_isOnlyPunctuation(input)) {
      return result
        ..action = PreCheckAction.BLOCK
        ..message = '请输入具体的问题内容';
    }
    if (_isOnlyEmoji(input)) {
      return result
        ..action = PreCheckAction.BLOCK
        ..message = '请输入文字问题';
    }

    // 4. 重复字符检查
    if (_isGibberish(input)) {
      return result
        ..action = PreCheckAction.BLOCK
        ..message = '请输入有意义的问题';
    }

    // 5. 宽泛问题关键词检测
    if (_isTooBroad(input)) {
      result.flags.add(PreCheckFlag.tooBroad);
    }

    // 6. 有无问句意图
    if (!_hasQuestionIntent(input) && !hasImage) {
      result.flags.add(PreCheckFlag.noQuestionIntent);
    }

    // 判断是否需要服务端深度评估
    if (result.flags.isNotEmpty) {
      result.action = PreCheckAction.SUGGEST_IMPROVE;
    } else {
      result.action = PreCheckAction.PROCEED;
    }

    return result;
  }

  /// 客户端轻量提示（不上报服务端）
  /// 仅在用户输入过程中给出实时反馈
  String getInlineHint(String input, bool hasImage) {
    if (input.trim().isEmpty) return '';

    // 实时宽泛问题提示
    if (_isTooBroad(input)) {
      return '💡 尝试更具体地描述，例如具体到某个知识点或题目';
    }

    // 实时指代不明提示
    if (_hasVagueReference(input) && !hasImage) {
      return '💡 "这个"/"那道题"需要更多上下文，可以拍照或补充学科';
    }

    return '';
  }
}
```

```java
                return QuestionEvaluationResult.pass(req, "DEGRADED_PASS");
```

## 10. 关键代码示例 - 完整评估流水线

```java
/**
 * 提问质量评估服务 - 核心入口
 */
@Service
@Slf4j
public class QuestionQualityService {

    @Autowired private RuleEngineEvaluator ruleEngine;
    @Autowired private LightNlpAnalyzer nlpAnalyzer;
    @Autowired private ContextEnhancer contextEnhancer;
    @Autowired private RewriteSuggestionGenerator suggestionGenerator;
    @Autowired private TemplateRecommender templateRecommender;
    @Autowired private UserContextService userContextService;
    @Autowired private QuestionQualityLogMapper logMapper;
    @Autowired private EvaluationDegradationManager degradationManager;
    @Autowired private RedisTemplate<String, Object> redis;

    /** 近期重复提交检测窗口(秒) */
    private static final int DUP_WINDOW_SECONDS = 60;
    /** 近期提交缓存key前缀 */
    private static final String RECENT_KEY = "qeval:recent:";

    /**
     * 评估提问质量 - 主入口
     */
    public QuestionEvaluationResult evaluate(QuestionEvaluationRequest request) {
        long start = System.currentTimeMillis();
        String evalId = generateEvalId(request.getUserId());

        try {
            // 0. 降级检查
            if (degradationManager.isDegraded()) {
                return degradationManager.degradedEvaluate(request);
            }

            // 1. 构建评估上下文
            EvaluationContext ctx = buildContext(request);

            // 2. 重复提交检测
            if (isDuplicate(request)) {
                return buildDuplicateResult(evalId, request);
            }

            // 3. 规则引擎评估
            RuleChainResult ruleResult = ruleEngine.evaluate(ctx);
            if (ruleResult.isShortCircuited()) {
                // 短路规则命中 → 直接拒绝
                return buildRejectResult(evalId, request, ruleResult);
            }

            // 4. NLP 轻量分析
            NlpAnalysisResult nlpResult = nlpAnalyzer.analyze(
                request.getRawQuestion(), ctx);

            // 5. 上下文增强检查
            ContextEvaluation contextResult = contextEnhancer.evaluate(ctx, nlpResult);

            // 6. 综合评分
            QualityScoring scoring = calculateScore(ruleResult, nlpResult, contextResult);

            // 7. 判定质量等级和动作
            QualityLevel level = determineLevel(scoring.getTotalScore());
            Action action = determineAction(level, ruleResult, request);

            // 8. 生成优化建议 (仅GUIDE场景)
            OptimizationSuggestion suggestion = null;
            if (action == Action.GUIDE_USER || action == Action.CLARIFY_NEEDED) {
                List<QualityIssue> allIssues = mergeIssues(ruleResult, contextResult);
                suggestion = buildSuggestion(allIssues, nlpResult, ctx, request);
            }

            // 9. 构建结果
            QuestionEvaluationResult result = QuestionEvaluationResult.builder()
                .evaluationId(evalId)
                .qualityLevel(level)
                .qualityScore(scoring.getTotalScore())
                .dimensionScores(scoring.getDimensions())
                .issues(mergeIssues(ruleResult, contextResult))
                .detectedSubject(nlpResult.getSubjectDetection().getSubject())
                .action(action)
                .suggestion(suggestion)
                .modelVersion("1.0.0")
                .evaluationDurationMs(System.currentTimeMillis() - start)
                .build();

            // 10. 异步记录日志
            asyncLog(request, result);

            // 11. 缓存近期提交（防重复）
            cacheRecentSubmission(request);

            return result;

        } catch (Exception e) {
            log.error("Question evaluation failed, userId={}, question={}",
                request.getUserId(), request.getRawQuestion(), e);
            // 异常时降级放行
            return QuestionEvaluationResult.builder()
                .evaluationId(evalId)
                .qualityLevel(QualityLevel.HIGH)
                .qualityScore(80)
                .action(Action.PASS_TO_AI)
                .modelVersion("1.0.0-FALLBACK")
                .build();
        }
    }

    /**
     * 综合评分计算
     */
    private QualityScoring calculateScore(
            RuleChainResult ruleResult,
            NlpAnalysisResult nlp,
            ContextEvaluation contextEval) {

        DimensionScores dims = new DimensionScores();

        // 清晰度: 基于句法完整性、问句结构、信息密度
        dims.setClarity(calculateClarity(nlp));

        // 具体性: 基于关键词数量、学科术语密度、知识点覆盖
        dims.setSpecificity(calculateSpecificity(nlp));

        // 完整性: 基于上下文检查结果、指代消解、信息项完整度
        dims.setCompleteness(calculateCompleteness(nlp, contextEval));

        // 学术相关性: 基于学科识别置信度、教育关键词覆盖
        dims.setAcademicRelevance(calculateRelevance(nlp));

        // 年级适配: 基于问题复杂度与年级匹配度
        dims.setGradeAlignment(calculateGradeAlignment(nlp));

        // 计算总分 = 加权平均 - 规则扣分
        double weighted = 0;
        int[] scores = {dims.getClarity(), dims.getSpecificity(),
                        dims.getCompleteness(), dims.getAcademicRelevance(),
                        dims.getGradeAlignment()};
        for (int i = 0; i < DimensionScores.WEIGHTS.length; i++) {
            weighted += scores[i] * DimensionScores.WEIGHTS[i];
        }

        int totalScore = (int) Math.max(0, weighted - ruleResult.getTotalPenalty());

        return new QualityScoring(dims, Math.min(100, totalScore));
    }

    /**
     * 质量等级判定
     */
    private QualityLevel determineLevel(int score) {
        if (score >= 70) return QualityLevel.HIGH;
        if (score >= 40) return QualityLevel.MEDIUM;
        if (score >= 10) return QualityLevel.LOW;
        return QualityLevel.REJECT;
    }

    /**
     * 决策动作
     * MIDDLE等级在有图片时也放行，避免阻断正常使用
     */
    private Action determineAction(QualityLevel level, RuleChainResult ruleResult,
                                    QuestionEvaluationRequest req) {
        switch (level) {
            case HIGH:
                return Action.PASS_TO_AI;
            case MEDIUM:
                // MEDIUM等级仍然转交AI，但在回答中附带轻量提示
                return Action.PASS_TO_AI;
            case LOW:
                return Action.GUIDE_USER;
            case REJECT:
                return Action.REJECT;
            default:
                return Action.PASS_TO_AI;
        }
    }

    /**
     * 构建评估上下文
     */
    private EvaluationContext buildContext(QuestionEvaluationRequest req) {
        EvaluationContext.EvaluationContextBuilder ctx = EvaluationContext.builder()
            .rawQuestion(req.getRawQuestion())
            .inputType(req.getInputType())
            .sessionId(req.getSessionId())
            .hasImage(req.getImageUrl() != null)
            .gradeLevel(req.getGradeLevel());

        // 获取用户上下文
        UserLearnContext userCtx = userContextService.getUserContext(req.getUserId());
        ctx.userContext(userCtx);

        // 获取会话历史（追问场景）
        if (req.getSessionId() != null) {
            List<ChatMessage> history = getRecentHistory(req.getSessionId());
            ctx.sessionHistory(history);
        }

        return ctx.build();
    }

    /**
     * 重复提交检测
     */
    private boolean isDuplicate(QuestionEvaluationRequest req) {
        String key = RECENT_KEY + req.getUserId();
        String normalized = normalize(req.getRawQuestion());

        @SuppressWarnings("unchecked")
        List<String> recent = (List<String>) redis.opsForValue().get(key);
        if (recent == null) return false;

        return recent.stream()
            .anyMatch(prev -> similarity(prev, normalized) > 0.85);
    }

    private void cacheRecentSubmission(QuestionEvaluationRequest req) {
        String key = RECENT_KEY + req.getUserId();
        String normalized = normalize(req.getRawQuestion());

        redis.opsForValue().set(key,
            List.of(normalized),
            Duration.ofSeconds(DUP_WINDOW_SECONDS));
    }

    /**
     * 异步日志记录
     */
    @Async("qualityLogExecutor")
    public void asyncLog(QuestionEvaluationRequest req, QuestionEvaluationResult result) {
        try {
            QuestionQualityLog log = QuestionQualityLog.builder()
                .evaluationId(result.getEvaluationId())
                .userId(req.getUserId())
                .rawQuestion(req.getRawQuestion())
                .inputType(req.getInputType().name())
                .qualityLevel(result.getQualityLevel().name())
                .qualityScore(result.getQualityScore())
                .clarityScore(result.getDimensionScores().getClarity())
                .specificityScore(result.getDimensionScores().getSpecificity())
                .completenessScore(result.getDimensionScores().getCompleteness())
                .relevanceScore(result.getDimensionScores().getAcademicRelevance())
                .gradeAlignmentScore(result.getDimensionScores().getGradeAlignment())
                .issuesJson(toJson(result.getIssues()))
                .detectedSubject(result.getDetectedSubject())
                .actionTaken(result.getAction().name())
                .suggestionJson(result.getSuggestion() != null ? toJson(result.getSuggestion()) : null)
                .sessionId(req.getSessionId())
                .gradeLevel(req.getGradeLevel())
                .stageLevel(req.getStageLevel())
                .hasImage(req.getImageUrl() != null ? 1 : 0)
                .modelVersion(result.getModelVersion())
                .evaluationMs(result.getEvaluationDurationMs())
                .build();

            logMapper.insert(log);

            // 更新日统计（可使用定时任务批量更新）
            updateDailyStats(req.getUserId(), result);

        } catch (Exception e) {
            log.error("Failed to log question quality", e);
        }
    }
}
```

```dart
class QuestionRepository {
  final QualityApi qualityApi;

  Future<QuestionResult> submitQuestion(String question) async {
    try {
      // 1. 先做质量评估
      final evalResult = await qualityApi.evaluate(question);

        // 展示引导弹窗，等待用户选择
        final userChoice = await showGuideDialog(evalResult);
        if (userChoice == GuideChoice.ignore) {
          // 用户忽略引导，直接提交
          return _submitToAI(question, bypassGuide: true);
        } else if (userChoice is GuideChoiceRewrite) {
          return _submitToAI(userChoice.text, isRewritten: true);
        }
        return QuestionResult.cancelled();
      }

      // 2. 通过评估，提交给AI
      return _submitToAI(question, evaluationId: evalResult.evaluationId);

    } on DioException catch (e) {
      // 网络错误 → 跳过评估直接提交
      if (e.type == DioExceptionType.connectionTimeout ||
          e.type == DioExceptionType.receiveTimeout) {
        return _submitToAI(question);
      }
      rethrow;
    } catch (e) {
      // 其他异常 → 跳过评估直接提交
      return _submitToAI(question);
    }
  }
}
```
