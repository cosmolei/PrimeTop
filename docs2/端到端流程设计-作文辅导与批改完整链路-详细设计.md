## 3. 阶段一：入口与题目输入

### 3.1 流程说明

用户通过三种方式进入作文辅导：

| 入口方式 | 触发路径 | 说明 |
|---------|---------|------|
| 手动输入 | 首页快捷入口 / 作文页"新建" | 用户手动键入作文题目 |
| 拍照识别 | 作文页"拍照输入" | OCR 识别试卷/练习册上的作文题 |
| 题库选题 | 同步课堂 → 单元写作任务 / 作文页"题库选题" | 从系统题库中选择对应年级教材的写作题 |

### 3.2 拍照输入子流程

```
用户点击"拍照输入"
     │
     ▼
调用相机/相册选择图片
     │
     ▼
客户端预处理（裁剪/旋转/压缩）
     │
     ▼
POST /api/v1/essay/ocr-topic
     │ (multipart: image + stage + grade)
     ▼
服务端调 OCR 服务 → 提取文本
     │
     ▼
AI 提取作文题结构（题目 + 要求 + 字数限制）
     │
     ▼
返回结构化题目 → 客户端展示供用户确认/修改
```

### 3.3 数据结构

#### 3.3.1 作文任务创建请求

```typescript

  grade: number;                    // 年级快照
```

### 3.4 错误处理

| 错误场景 | 错误码 | 处理策略 |
|---------|--------|---------|
| 拍照图片无法识别 | `ESSAY_OCR_FAILED` | 提示用户重新拍照或手动输入 |
| 图片中无作文题 | `ESSAY_NO_TOPIC_FOUND` | 提示"未检测到作文题目，请手动输入" |
| 额度不足（免费用户） | `QUOTA_EXCEEDED` | 弹窗引导开通会员 |
| AI 服务暂时不可用 | `AI_SERVICE_UNAVAILABLE` | 提示稍后重试，任务状态保持 `created` |

## 4. 阶段二：审题分析

### 4.1 流程说明

审题分析是作文辅导的第一步 AI 交互。系统通过大模型对题目进行深度分析，输出：

1. **文体判断**：记叙文 / 议论文 / 说明文 / 散文 / 应用文等
2. **关键词提取**：核心概念和限制条件
3. **立意方向建议**：2-3 个可选立意方向（标注适配度）
4. **写作提示**：针对该学段的写作技巧提醒
5. **字数要求**：自动识别或使用学段默认值

### 4.2 服务端处理流程

```
收到审题请求
     │
     ▼
① 额度预检（检查 essay_analysis 额度）
     │
     ▼
② 构建审题 Prompt
   ├── 系统角色：作文审题专家
   ├── 学段/年级上下文
   ├── 评分量表（对应学段）
   ├── 输出格式约束（JSON Schema）
   └── 示例（Few-shot: 1-2 个审题样例）
     │
     ▼
③ 调用大模型（通用问答模型，GPT-4o 级别）
     │
     ▼
④ 解析模型输出 → 结构化审题结果
     │
     ▼
⑤ 创建 essay_tasks 记录（status='analyzing'）
     │
     ▼
⑥ SSE 流式返回审题结果
     │
     ▼
⑦ 更新 task status → 'topic_analyzed'
     │
     ▼
⑧ 发布事件 EssayTopicAnalyzed
```

### 4.4 关键代码示例

```java
// EssayAnalysisService.java
@Service
@Slf4j
public class EssayAnalysisService {

    @Autowired
    private PromptTemplateManager promptManager;
    
    @Autowired
    private LlmClient llmClient;
    
    @Autowired
    private QuotaService quotaService;
    
    @Autowired
    private EventPublisher eventPublisher;

    /**
     * 审题分析 - SSE 流式返回
     */
    public Flux<ServerSentEvent<String>> analyzeTopic(
            AnalyzeTopicRequest request, UserContext userCtx) {
        
        // 1. 额度预检
        QuotaCheckResult quota = quotaService.checkAndReserve(
            userCtx.getUserId(), "essay_analysis", 1);
        if (!quota.isAllowed()) {
            return Flux.just(ServerSentEvent.<String>builder()
                .event("error")
                .data("{\"code\":\"QUOTA_EXCEEDED\",\"message\":\"今日审题次数已用完\"}")
                .build());
        }

        // 2. 构建 Prompt
        Map<String, Object> variables = Map.of(
            "stage", userCtx.getStage(),
            "grade", userCtx.getGrade(),
            "subject", request.getSubject(),
            "title", request.getTitle(),
            "additional_requirements", 
                StringUtils.defaultString(request.getAdditionalRequirements())
        );
        
        PromptConfig promptConfig = promptManager.render(
            "essay_topic_analysis", variables);
        
        // 3. 调用大模型 - SSE 流式
        Flux<ChatChunk> chunks = llmClient.streamChat(
            promptConfig, LlmModelCategory.GENERAL);
        
        // 4. 流式转发 + 尾部解析结构化结果
        StringBuilder fullResponse = new StringBuilder();
        
        return chunks.map(chunk -> {
            fullResponse.append(chunk.getContent());
            return ServerSentEvent.<String>builder()
                .event("chunk")
                .data(chunk.getContent())
                .build();
        }).concatWith(Flux.defer(() -> {
            // 流结束：解析结果、更新任务、发布事件
            TopicAnalysisResult result = parseTopicAnalysis(fullResponse.toString());
            Long taskId = createOrUpdateTask(request, userCtx, result);
            
            eventPublisher.publishAsync(new EssayTopicAnalyzedEvent(
                taskId, userCtx.getUserId(), result));
            
            return Flux.just(
                ServerSentEvent.<String>builder()
                    .event("done")
                    .data("{\"task_id\":" + taskId + ",\"analysis\":" 
                          + JsonUtils.toJson(result) + "}")
                    .build()
            );
        }));
    }
}
```

## 5. 阶段三：提纲生成与素材推荐

### 5.1 流程说明

用户选定立意方向后，系统生成结构化写作提纲，并推荐匹配的素材（名言/事例/句式）。

### 5.2 服务端处理流程

```
收到提纲生成请求（task_id + chosen_direction）
     │
     ▼
① 读取审题分析结果（从 essay_tasks 表）
     │
     ▼
② 并行执行：
   ├── [A] 生成写作提纲（AI 调用）
   └── [B] 检索素材库（ES/MySQL 查询）
     │
     ▼
③ 合并结果 → 返回提纲 + 素材
     │
     ▼
④ 创建首个草稿记录（essay_drafts, version=1）
   └── outline 字段写入提纲 JSON
     │
     ▼
⑤ 更新 task status → 'outlining'
```

### 5.3 并行调用设计

```java
// EssayOutlineService.java
public OutlineResult generateOutline(OutlineRequest request) {
    EssayTask task = taskRepository.findById(request.getTaskId());
    TopicAnalysisResult analysis = task.getAnalysisResult();
    
    String chosenDirection = analysis.getThemeDirections()
        .get(request.getChosenDirection()).getDirection();
    
    // 并行：提纲生成 + 素材检索
    CompletableFuture<OutlineStructure> outlineFuture = 
        CompletableFuture.supplyAsync(() -> 
            generateOutlineViaAi(task, chosenDirection, request.getStylePreference()),
            aiExecutor);
    
    CompletableFuture<List<MaterialItem>> materialsFuture = 
        CompletableFuture.supplyAsync(() -> 
            searchMaterials(task.getStage(), chosenDirection, analysis.getGenre()),
            dbExecutor);
    
    // 等待两者完成（超时 15s，素材可降级为空列表）
    OutlineStructure outline;
    List<MaterialItem> materials;
    try {
        outline = outlineFuture.get(15, TimeUnit.SECONDS);
    } catch (TimeoutException e) {
        log.warn("提纲生成超时，降级为基础模板");
        outline = generateBasicOutline(analysis, chosenDirection);
    }
    
    try {
        materials = materialsFuture.get(5, TimeUnit.SECONDS);
    } catch (TimeoutException e) {
        materials = Collections.emptyList();
    }
    
    // 保存草稿
    saveDraftOutline(request.getTaskId(), outline);
    
    return OutlineResult.builder()
        .outline(outline)
        .materials(materials)
        .build();
}

private List<MaterialItem> searchMaterials(String stage, String theme, String genre) {
    // ES 检索：主题匹配 + 学段过滤 + 热度排序
    BoolQueryBuilder query = BoolQueryBuilder.newInstance()
        .must(matchQuery("theme", theme))
        .filter(termsQuery("stage_scope", stage))
        .filter(termQuery("status", 1));
    
    // 按类型分组各取 Top3
    return materialSearchService.search(query, 12)
        .stream()
        .collect(Collectors.groupingBy(MaterialItem::getCategory))
        .values().stream()
        .flatMap(list -> list.stream().limit(3))
        .collect(Collectors.toList());
}
```

### 5.4 提纲结构定义

```typescript
interface OutlineStructure {
  sections: OutlineSection[];
  total_word_estimate: number;
  suggested_materials: SuggestedMaterial[];
}

interface OutlineSection {
  section: string;          // "开头" | "正文一" | "正文二" | "结尾"
  heading: string;          // 小标题
  content: string;          // 写什么（引导描述）
  word_estimate: number;    // 建议字数
  technique: string;        // 推荐写作手法
}

interface SuggestedMaterial {
  type: 'quote' | 'story' | 'example' | 'sentence';
  content: string;          // 素材内容
  usage: string;            // 使用建议
  material_id?: number;     // 可收藏的素材ID
}
```

## 6. 阶段四：起草写作

### 6.1 流程说明

用户基于提纲进入富文本编辑器起草作文。客户端负责实时辅助，服务端负责草稿持久化。

### 6.2 客户端写作交互流程

```
用户进入写作页面
     │
     ▼
加载提纲 → 显示为侧边引导面板
     │
     ▼
用户开始写作
     │
     ├── [实时] 字数统计（客户端本地）
     │   └── 进度条：当前字数 / 目标字数
     │
     ├── [定时] 自动保存（每 30s 或暂停输入 5s）
     │   └── POST /api/v1/essay/draft/auto-save
     │
     ├── [手动] AI 写作辅助
```

### 6.3 自动保存机制

```dart
// essay_write_page.dart - 自动保存逻辑
class EssayWriteController extends GetxController {
  Timer? _autoSaveTimer;
  String _lastSavedContent = '';
  final RxBool isSaving = false.obs;
  final Rx<DateTime?> lastSavedAt = Rx(null);

  void startAutoSave() {
    _autoSaveTimer = Timer.periodic(
      Duration(seconds: 30), 
      (_) => _autoSave(),
    );
  }

  Future<void> _autoSave() async {
    final content = editorController.document.toPlainText();
    
    // 内容未变化则跳过
    if (content == _lastSavedContent) return;
    
    isSaving.value = true;
    try {
      await essayApi.autoSaveDraft(
        taskId: taskId,
        content: content,
        wordCount: content.length,
        currentSection: currentSection.value,
      );
      _lastSavedContent = content;
      lastSavedAt.value = DateTime.now();
    } catch (e) {
      // 静默失败，下次继续尝试
      debugPrint('自动保存失败: $e');
    } finally {
      isSaving.value = false;
    }
  }

  @override
  void onClose() {
    _autoSaveTimer?.cancel();
    _autoSave(); // 退出前保存
    super.onClose();
  }
}
```

### 7.3 批改流水线编排

批改是作文辅导最核心的后端流程，采用**流水线模式**并行执行多个评分维度：

```
批改流水线启动
     │
     ▼
① 预处理阶段（串行）
   ├── 字数统计、段落数统计
   ├── 格式清洗（去除多余空行/特殊字符）
   ├── 分词与句子切分
   └── 提纲对照（如果有提纲，对比实际写作是否跟随）
     │
     ▼
② 并行评分阶段（多维度并行调用 AI）
   ├── [A] 内容立意评分（theme_score）     ──┐
   ├── [B] 结构组织评分（structure_score）   │
   ├── [C] 语言表达评分（language_score）    │  并行
   ├── [D] 内容充实度评分（content_score）   │
   ├── [E] 错别字与标点检测                 │
   └── [F] 好词好句提取                    ──┘
     │
     ▼
③ 汇总阶段
   ├── 综合评分计算（加权平均）
   ├── 总评语生成
   └── 润色建议生成（局部修改建议）
     │
     ▼
④ 匹配阶段
   ├── 范文匹配（基于主题/文体/难度）
   └── 相似问题文推荐
     │
     ▼
⑤ 写入阶段
   ├── 更新 essay_drafts.review_result
   ├── 更新 task status → 'evaluated'
   └── 发布事件 EssayEvaluated
     │
     ▼
⑥ 下游事件消费
   ├── 写作能力画像更新
   ├── 学习记录追加
   ├── 掌握度更新（写作相关知识点）
   └── 通知推送（批改完成通知）
```

### 7.4 流水线编排代码

```java
// EssayEvaluationPipeline.java
@Service
@Slf4j
public class EssayEvaluationPipeline {

    @Autowired private List<DimensionScorer> dimensionScorers;
    @Autowired private TypoDetector typoDetector;
    @Autowired private GoodPhraseExtractor phraseExtractor;
    @Autowired private ReferenceEssayMatcher referenceMatcher;
    @Autowired private WritingProfileTracker profileTracker;
    @Autowired private EventPublisher eventPublisher;

    private static final int PIPELINE_TIMEOUT_SECONDS = 45;

    /**
     * 执行完整批改流水线
     */
    @Async("essayEvaluationExecutor")
    public void evaluate(Long taskId, Long userId, EssayDraft draft) {
        StopWatch stopWatch = new StopWatch("essay-evaluation");
        
        try {
            // ── ① 预处理 ──
            stopWatch.start("preprocess");
            EssayPreprocessResult preprocessed = preprocess(draft);
            stopWatch.stop();
            
            // ── ② 并行评分 ──
            stopWatch.start("parallel_scoring");
            Map<String, CompletableFuture<DimensionScore>> futures = new HashMap<>();
            
            for (DimensionScorer scorer : dimensionScorers) {
                futures.put(scorer.getDimension(), 
                    CompletableFuture.supplyAsync(
                        () -> scorer.score(preprocessed, draft.getContext()),
                        scoringExecutor));
            }
            
            // 错别字检测
            CompletableFuture<TypoResult> typoFuture = 
                CompletableFuture.supplyAsync(
                    () -> typoDetector.detect(preprocessed.getCleanText()),
                    scoringExecutor);
            
            // 好词好句提取
            CompletableFuture<List<GoodPhrase>> phraseFuture = 
                CompletableFuture.supplyAsync(
                    () -> phraseExtractor.extract(preprocessed),
                    scoringExecutor);
            
            // 等待所有并行任务完成
            CompletableFuture.allOf(
                Stream.concat(futures.values().stream(), 
                    Stream.of(typoFuture, phraseFuture))
                    .toArray(CompletableFuture[]::new)
            ).get(PIPELINE_TIMEOUT_SECONDS, TimeUnit.SECONDS);
            stopWatch.stop();
            
            // ── ③ 汇总 ──
            stopWatch.start("aggregate");
            Map<String, DimensionScore> scores = futures.entrySet().stream()
                .collect(Collectors.toMap(
                    Map.Entry::getKey, 
                    e -> e.getValue().getNow(DimensionScore.failed(e.getKey()))));
            
            EvaluationResult result = aggregateScores(
                scores, 
                typoFuture.getNow(TypoResult.empty()),
                phraseFuture.getNow(Collections.emptyList()),
                preprocessed
            );
            stopWatch.stop();
            
            // ── ④ 范文匹配 ──
            stopWatch.start("reference_matching");
            List<ReferenceEssayMatch> references = referenceMatcher.match(
                draft.getTheme(), 
                draft.getGenre(), 
                draft.getStage(),
                result.getOverallScore()
            );
            result.setReferenceEssays(references);
            stopWatch.stop();
            
            // ── ⑤ 写入 ──
            stopWatch.start("persist");
            persistEvaluationResult(taskId, draft.getVersion(), result);
            updateTaskStatus(taskId, EssayTaskStatus.EVALUATED);
            stopWatch.stop();
            
            // ── ⑥ 发布事件 ──
            eventPublisher.publishAsync(new EssayEvaluatedEvent(
                taskId, userId, result, draft.getContext()));
            
            log.info("作文批改完成 taskId={} score={} cost={}", 
                taskId, result.getOverallScore(), stopWatch.getTotalTimeMillis());
                
        } catch (TimeoutException e) {
            log.error("批改流水线超时 taskId={}", taskId, e);
            handlePipelineFailure(taskId, "EVALUATION_TIMEOUT", "批改超时，请稍后重试");
        } catch (Exception e) {
            log.error("批改流水线异常 taskId={}", taskId, e);
            handlePipelineFailure(taskId, "EVALUATION_ERROR", "批改异常，请稍后重试");
        }
    }
    
    /**
     * 评分汇总与总评生成
     */
    private EvaluationResult aggregateScores(
            Map<String, DimensionScore> scores,
            TypoResult typos,
            List<GoodPhrase> phrases,
            EssayPreprocessResult preprocessed) {
        
        // 加权计算总分（权重按学段不同）
        double totalScore = scores.values().stream()
            .mapToDouble(s -> s.getScore() * getWeight(s.getDimension(), preprocessed.getStage()))
            .sum();
        
        // 生成总评语（再调一次 AI）
        String overallComment = generateOverallComment(scores, typos, preprocessed);
        
        return EvaluationResult.builder()
            .overallScore((int) Math.round(totalScore))
            .scoreBreakdown(scores)
            .typos(typos.getTypos())
            .highlights(convertPhrases(phrases))
            .polishSuggestions(generatePolishSuggestions(scores, preprocessed))
            .overallComment(overallComment)
            .outlineComparison(preprocessed.getOutlineComparison())
            .build();
    }
}
```

```java
// WritingProfileConsumer.java
@Component
@Slf4j
public class WritingProfileConsumer implements DomainEventConsumer<EssayEvaluatedEvent> {

    @Autowired private WritingProfileRepository profileRepo;
    @Autowired private UserAbilityDimensionRepository abilityRepo;

    @Override
    public void handle(EssayEvaluatedEvent event) {
        Long userId = event.getUserId();
        EvaluationResult result = event.getResult();
        EssayContext ctx = event.getContext();
        
        // 1. 获取或创建写作能力画像
        WritingProfile profile = profileRepo.findByUserId(userId)
            .orElseGet(() -> WritingProfile.init(userId, ctx.getStage()));
        
        // 2. 更新各维度分数（滑动平均）
        profile.updateDimensionScore("theme", 
            result.getScoreBreakdown().get("theme").getScore());
        profile.updateDimensionScore("structure", 
            result.getScoreBreakdown().get("structure").getScore());
        profile.updateDimensionScore("language", 
            result.getScoreBreakdown().get("language").getScore());
        profile.updateDimensionScore("content", 
            result.getScoreBreakdown().get("content").getScore());
        
        // 3. 更新趋势数据
        profile.addScoreRecord(result.getOverallScore(), LocalDate.now());
        
        // 4. 识别薄弱维度
        profile.recalculateWeakDimensions();
        
        // 5. 更新写作统计数据
        profile.incrementEssayCount();
        profile.addTotalWordCount(event.getContext().getWordCount());
        
        profileRepo.save(profile);
        
        // 6. 同步到统一能力维度表（供学情分析雷达图使用）
        abilityRepo.updateDimension(userId, "writing_ability", 
            profile.getOverallWritingScore(), ctx.getStage());
```

## 13. 错误处理与降级策略

### 13.1 关键故障场景

| 故障点 | 影响 | 降级策略 |
|-------|------|---------|
| 大模型服务超时 | 审题/批改无法完成 | 1) 超时重试（2次） 2) 降级到低配模型 3) 提示稍后重试 |
| 部分评分维度失败 | 评分不完整 | 标记该维度为 `skipped`，其余维度正常评分，总分按已评分维度加权 |
| 范文匹配服务故障 | 无法推荐范文 | 跳过范文推荐，批改结果正常返回 |
| 素材库检索超时 | 提纲无素材推荐 | 返回提纲，素材列表为空 |
| 自动保存失败 | 草稿丢失 | 客户端本地缓存兜底 + 重试 |
| 事件消费延迟 | 能力画像未及时更新 | 最终一致性，延迟 1-5 分钟可接受 |

### 13.2 重试策略

```java
// 批改流水线重试配置
@Bean
public RetryTemplate evaluationRetryTemplate() {
    return RetryTemplate.builder()
        .maxAttempts(3)
        .exponentialBackoff(1000, 2.0, 10000)
        .retryOn(List.of(
            LlmServiceException.class,
            TimeoutException.class))
        .build();
}
```

## 15. 安全与合规

### 15.1 内容安全

| 环节 | 安全检查 |
|------|---------|
| 作文题目输入 | 过滤敏感词、暴力/色情内容 |
| 作文正文提交 | 内容安全审核（涉黄/涉暴/涉政） |
| AI 续写输出 | 输出安全护栏（不生成不当内容） |
| AI 批改输出 | 评分客观性校验（不包含歧视性评价） |
| 范文内容 | 后台审核通过才能上架 |

### 15.2 防滥用机制

- **代写检测**：检测作文内容是否由 AI 批量生成（与续写输出比对）
- **频率限制**：单用户批改提交间隔 ≥ 3 分钟
- **字数异常检测**：字数远超/远低于学段要求时发出提醒
- **内容去重**：同一篇作文不允许重复提交批改
