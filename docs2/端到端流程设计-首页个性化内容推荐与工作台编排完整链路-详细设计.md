### 2.2 关键代码：启动管线中的首页预请求

```dart
// lib/app/init/app_init_pipeline.dart

class AppInitPipeline {
  final UserRepository _userRepo;
  final HomeRepository _homeRepo;
  final LocalCache _cache;
  final AnalyticsService _analytics;

  /// 应用初始化
  Future<InitResult> initialize() async {
    final stopwatch = Stopwatch()..start();

    // ① 并行执行无依赖的初始化
    final results = await Future.wait([
      _initSDKs(),
      _userRepo.loadCachedProfile(),
    ]);

    // ② 检查登录态
    final authResult = await _checkAuth();
    if (!authResult.isAuthenticated) {
      return InitResult.needLogin();
    }

    // ③ 预请求首页数据（不等待完成，fire-and-forget）
    final user = results[1] as UserProfile;
    _prefetchHomeData(user);

    stopwatch.stop();
    _analytics.logAppInit(
      durationMs: stopwatch.elapsedMilliseconds,
      source: 'cold_start',
    );

    return InitResult.ready(
      userProfile: user,
      isFirstLaunch: authResult.isFirstLaunch,
    );
  }

  /// 预请求首页数据 —— 不阻塞启动流程
  void _prefetchHomeData(UserProfile user) {
    // 将请求结果存入内存缓存，首页加载时优先读取
    _homeRepo.getSummary().then((data) {
      _cache.setJson('_prefetch_home', data.toJson(), ttl: Duration(minutes: 5));
    }).catchError((_) {
      // 预请求失败不影响启动
    });
  }
}
```

### 2.3 冷启动 vs 热启动策略

| 场景 | 数据来源 | 缓存策略 | 渲染策略 |
|------|----------|----------|----------|
| **冷启动**（进程不存在） | 本地SQLite缓存 → 网络请求 | 先读本地缓存，立即渲染骨架屏，网络到达后合并 | 骨架屏 → 缓存数据 → 网络数据 |
| **热启动**（后台恢复） | 内存缓存 → 增量刷新 | 直接用内存缓存，后台增量刷新 | 立即渲染缓存，后台静默更新 |
| **强退重启** | 无缓存 | 直接网络请求 | 骨架屏 → 网络数据 |

### 3.2 BFF 聚合逻辑

BFF 层在编排服务返回的卡片列表基础上，补充客户端需要的额外数据：

```python
class HomeBFService:
    """首页 BFF 聚合层"""

    async def get_home_summary(self, user_id: str, platform: str, app_version: str) -> dict:
        """获取首页完整数据"""

        # 1. 获取编排后的卡片列表
        card_response = await self.card_orchestrator.get_cards(
            user_id=user_id,
            limit=10,
            platform=platform,
            app_version=app_version,
        )

        # 2. 从卡片中提取结构化数据，适配前端数据模型
        result = {
            "user_brief": await self._get_user_brief(user_id),
            "quick_actions": self._extract_quick_actions(card_response.cards),
            "today_tasks": self._extract_today_tasks(card_response.cards),
            "continue_learning": self._extract_continue_learning(card_response.cards),
            "weak_points": self._extract_weak_points(card_response.cards),
            "daily_summary": await self._get_daily_summary(user_id),
            "messages": await self._get_messages_summary(user_id),
            "age_config": await self._get_age_config(user_id),
            "_meta": {
                "refresh_token": card_response.refresh_token,
                "generated_at": card_response.generated_at.isoformat(),
                "ttl_seconds": card_response.ttl_seconds,
            },
        }

        # 3. BFF 层缓存（60秒，短于编排服务的300秒）
        await self.cache.set(f"home:bff:{user_id}", result, ttl=60)

        return result
```

### 4.2 渲染优先级策略

首页渲染遵循 **"先有内容，再求准确"** 的原则，确保用户在任何情况下都能看到内容：

```
时间线：0ms        200ms       1000ms      2000ms      3000ms
        │           │            │           │           │
        ▼           ▼            ▼           ▼           ▼
    引擎初始化   骨架屏出现    缓存渲染    网络数据到达  编排完成渲染
        │           │            │           │           │
        │       (固定结构)   (可能过时)    (可能不完整)  (最终态)
        │           │            │           │           │
        └───────────┴────────────┴───────────┴───────────┘
                      ↑            ↑           ↑
                 体验目标：    体验目标：   体验目标：
                 <2s 可见      <1s 有内容   <3s 数据准确
```

## 6. 阶段五：跨模块事件驱动的首页刷新

### 6.1 事件驱动刷新架构

```
子模块操作事件                     首页响应
─────────────                    ─────────

完成一道练习题 ──→ EventBus ──→  标记 areas: ['tasks', 'summary']
                                → 如果在后台，触发服务端缓存失效

完成错题复习 ───→ EventBus ──→  标记 areas: ['mistakes', 'tasks', 'summary']

学段/年级切换 ──→ EventBus ──→  全量刷新（所有 areas）

会员购买完成 ──→ EventBus ──→   标记 areas: ['user_brief', 'quick_actions']

教材版本变更 ──→ EventBus ──→   全量刷新

收到推送通知 ──→ PushService ──→ 标记 areas: ['messages']

后台长时间未活跃 → onResume ──→  全量刷新（超过30分钟）

每日零点跨天 ──→ DateChange ──→  全量刷新（重置今日任务和统计）
```

### 6.2 服务端缓存失效事件

```python
# 事件定义
class HomeCacheRefreshEvent:
    """首页缓存刷新事件"""
    user_id: str
    reason: str         # task_completed / review_done / mastery_changed / plan_updated / new_day
    urgency: str        # immediate / normal / lazy
    source_event: str   # 原始事件名
    affected_areas: list[str]  # 影响的区域

# 事件触发方 → 编排服务 → 缓存失效
class HomeCacheInvalidator:
    """首页缓存失效处理器"""

    async def handle_event(self, event: HomeCacheRefreshEvent):
        if event.urgency == "immediate":
            # 立即删除缓存，下次请求重新生成
            await self.cache_repo.delete(event.user_id)
            await self.bff_cache.delete(f"home:bff:{event.user_id}")
        else:
            # 标记为需要刷新，下次请求时重新生成
            await self.cache_repo.mark_stale(event.user_id)
```

### 6.3 客户端事件订阅

```dart
// lib/pages/home/bloc/home_event_subscriptions.dart

class HomeEventSubscriptions {
  final HomeBloc _bloc;
  final EventBus _eventBus;
  DateTime? _lastResumeTime;

  void subscribe() {
    // 订阅学习事件
    _eventBus.on<TaskCompletedEvent>().listen((e) {
      _bloc.add(HomePartialRefresh({'tasks', 'summary'}));
    });

    _eventBus.on<MistakeReviewCompletedEvent>().listen((e) {
      _bloc.add(HomePartialRefresh({'mistakes', 'tasks', 'summary'}));
    });

    _eventBus.on<MembershipPurchasedEvent>().listen((e) {
      _bloc.add(HomePartialRefresh({'user_brief', 'quick_actions'}));
    });

    _eventBus.on<GradeChangedEvent>().listen((e) {
      // 年级变更需要全量刷新
      _bloc.add(const HomeRefreshRequested(reason: 'grade_changed'));
    });

    _eventBus.on<TextbookChangedEvent>().listen((e) {
      _bloc.add(const HomeRefreshRequested(reason: 'textbook_changed'));
    });

    // 跨天刷新
    _eventBus.on<DateChangedEvent>().listen((e) {
      _bloc.add(const HomeRefreshRequested(reason: 'new_day'));
    });
  }

  /// 处理页面可见性变化
  void onPageVisible() {
    final now = DateTime.now();
    if (_lastResumeTime != null) {
      final diff = now.difference(_lastResumeTime!);
      if (diff.inMinutes > 30) {
        // 超过30分钟未活跃，全量刷新
        _bloc.add(const HomeRefreshRequested(reason: 'long_inactive'));
      }
    }
    _lastResumeTime = now;
  }
}
```

### 8.1 客户端缓存分层

```
┌─────────────────────────────────────────┐
│           首页数据缓存分层               │
├─────────────────────────────────────────┤
│                                         │
│  Layer 1: 内存缓存 (BLoC State)         │
│  - 当前首页数据                         │
│  - 生命周期：页面存活期间               │
│  - 读取速度：~0ms                       │
│  │                                      │

│  │ 未命中 ↓                             │
│  │                                      │
│  Layer 2: 预请求缓存 (Prefetch Cache)   │
│  - App启动时预请求结果                  │
│  - 生命周期：5分钟                      │
│  - 读取速度：~1ms                       │
│  │                                      │
│  │ 命中 → 直接使用                      │
│  │ 未命中 ↓                             │
│  │                                      │
│  Layer 3: 本地持久化 (SQLite/Hive)      │
│  - 上次成功加载的数据                   │
│  - 生命周期：2小时（超时降级）          │
│  - 读取速度：~10ms                      │
│  │                                      │
│  │ 命中 → 先展示 + 后台刷新             │
│  │ 未命中 ↓                             │
│  │                                      │
│  Layer 4: 网络请求                     │
│  - 请求 BFF 接口                       │
│  - 超时：5秒                           │
│  - 读取速度：100ms~3s                   │
│                                         │
└─────────────────────────────────────────┘
```

## 10. 错误处理全链路

### 10.1 错误分类与处理策略

| 错误类型 | 发生环节 | 客户端表现 | 恢复策略 |
|----------|----------|------------|----------|
| **网络超时** | 数据请求 | 骨架屏/缓存数据 + "加载超时"提示 | 下拉刷新 / 自动重试(1次) |
| **服务端5xx** | BFF/编排服务 | 错误态或缓存数据 + "服务异常" | 自动重试(2次, 指数退避) |
| **上游服务部分不可用** | 编排服务拉取 | 正常渲染可用卡片，缺失卡片静默跳过 | 无需用户操作 |
| **全部上游不可用** | 编排服务 | 返回空卡片列表 | BFF层返回兜底数据 |
| **Token过期** | BFF鉴权 | 跳转登录页 | 重新登录 |
| **用户被封禁** | BFF鉴权 | 显示封禁提示页 | 联系客服 |
| **客户端解析失败** | 数据解析 | 缓存数据 + 静默上报 | 下次刷新自动修复 |
| **缓存损坏** | 本地缓存 | 清除缓存 + 网络请求 | 重新加载 |

### 10.3 客户端错误恢复代码示例

```dart
// lib/pages/home/bloc/home_bloc.dart — 错误恢复扩展

extension HomeBlocRecovery on HomeBloc {
  /// 智能重试：根据错误类型决定重试策略
  Future<void> smartRetry(Object error) async {
    if (error is NetworkException) {
      // 网络错误：延迟3秒后重试
      await Future.delayed(const Duration(seconds: 3));
      add(const HomeLoadRequested());
    } else if (error is TimeoutException) {
      // 超时：立即重试一次
      add(const HomeLoadRequested());
    } else if (error is AuthException) {
      // 鉴权失败：跳转登录
      _navigationService.pushReplacement('/login');
    } else if (error is ServerException && error.statusCode == 503) {
      // 服务维护：显示维护页面
      _navigationService.pushReplacement('/maintenance');
    }
  }
}
```
