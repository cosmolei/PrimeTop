# 支付服务与订单管理-详细设计

## 1. 概述

### 1.1 模块定位
支付服务是PrimeTop项目的基础设施模块，负责管理用户支付订单的全生命周期（创建、支付、退款、对账、风控）、对接多支付渠道、提供统一的支付回调处理与对账核对，并确保交易的安全、可靠与可追溯。本模块服务于会员订阅、增值服务购买等所有收费场景。

### 1.2 核心职责
- 订单创建与状态流转（Pending → Paid → Completed/Refunded/Cancelled 等）
- 支付渠道接入与适配（微信支付、支付宝等，预留扩展）
- 支付回调验签、幂等处理与订单状态更新
- 退款申请、审批与渠道退款执行
- 对账任务、差异处理与财务对账报表
- 支付风控（金额校验、设备指纹、限流、防重复）
- 异常降级与重试策略

### 1.3 依赖关系
- 依赖用户服务（获取用户ID、家长绑定、会员权益查询）
- 依赖会员服务（创建/更新会员、权益下发）
- 依赖配置中心（读取渠道配置、密钥）
- 依赖消息队列（异步对账、风控告警）
- 依赖日志与监控（记录支付流水、监控SLA）

### 2.2 缓存策略
- 订单创建时缓存订单号到幂等键（Redis，TTL 15分钟）
- 订单状态变更时发布到消息队列（消费时自动去重）
- 渠道配置热缓存（本地缓存 + Redis 缓存，更新通知）
- 对账结果短缓存（Redis，TTL 24小时）

## 4. 业务逻辑

### 4.1 核心流程

#### 4.1.1 订单创建流程
1. 参数校验：product_type、product_id、amount、channel 等
2. 商品校验：查询商品服务，确保商品有效、在售
3. 防重校验：检查用户在短时间是否有重复订单（Redis 幂等键）
4. 风控规则：金额超限、设备指纹黑名单等
5. 生成订单号：PO{YYYYMMDD}{16位随机数}
6. 插入订单表（PENDING 状态）
7. 调用对应渠道预支付接口，获取支付参数
8. 返回支付参数给客户端
9. 设置订单过期时间（默认15分钟）

#### 4.1.2 支付回调处理流程
1. 验证签名（使用渠道公钥/密钥）
2. 幂等性检查：根据订单号或交易号查重
3. 更新订单状态：PENDING → PAID/COMPLETED（注意事务与并发）
4. 调用会员服务（或商品服务）发放权益
5. 记录回调原始载荷
6. 发送对账消息（异步）
7. 返回渠道要求格式（如微信的SUCCESS XML）

#### 4.1.3 退款流程
1. 校验订单状态：仅允许 PAID/COMPLETED 订单退款
2. 校验退款金额：不超过可退金额
3. 插入退款记录表
4. 调用渠道退款接口
5. 等待渠道回调
6. 更新订单状态：REFUNDING → REFUNDED
7. 回收权益（调用会员服务降级）

#### 4.1.4 对账任务（定时）
1. 按渠道和日期下载对账文件（T+1或实时）
2. 解析对账文件，与订单表比对
3. 生成对账单（成功/差异）
4. 差异处理：人工补单或自动补单（配置化）
5. 生成财务报表
6. 通知相关人员

#### 4.1.5 风控检查
- 金额校验：单笔订单金额不超过阈值
- 频率校验：同用户1分钟内订单创建次数
- 设备指纹黑名单
- IP黑名单
- 行为特征：短时间内多次退款申请

### 4.2 状态机
```text
PENDING
   → PAYING (调用支付渠道获取支付参数时)
   → CANCELLED (超时未支付，或用户取消)
   → PAID (支付回调成功)
   → FAILED (支付回调失败或超时)

PAID
   → COMPLETED (权益下发成功)
   → REFUNDING (用户发起退款)
   → FAILED (权益下发失败，重试或人工处理)

REFUNDING
   → REFUNDED (退款成功)
   → FAILED (退款失败，重试或人工)

COMPLETED
   → REFUNDING (退款)

FAILED
   → CANCELLED (人工取消)
```

```go
func GenerateOrderNo() string {
    now := time.Now()
    prefix := "PO" + now.Format("20060102")
    randomPart := randString(16) // 从安全随机源获取
    return prefix + randomPart
}
```

#### 4.3.3 签名验证（微信支付示例）
```go
func VerifyWechatSign(notify map[string]string) bool {
    params := make(map[string]string)
    for k, v := range notify {
        if k != "sign" {
            params[k] = v
        }
    }
    sortedKeys := make([]string, 0, len(params))
    for k := range params {
        sortedKeys = append(sortedKeys, k)
    }
    sort.Strings(sortedKeys)

    var builder strings.Builder
    for _, k := range sortedKeys {
        builder.WriteString(k)
        builder.WriteByte('=')
        builder.WriteString(params[k])
        builder.WriteByte('&')
    }
    builder.WriteString("key=" + config.WeChatMchKey)

    sign := strings.ToUpper(md5Hex(builder.String()))
    return sign == notify["sign"]
}
```

### 5.2 订单创建服务实现

```go
// CreatePaymentOrder 创建支付订单
func (s *PaymentService) CreatePaymentOrder(ctx context.Context, req *CreateOrderRequest) (*CreateOrderResponse, error) {
    // 1. 参数校验
    if err := s.validateCreateRequest(req); err != nil {
        return nil, err
    }

    // 2. 商品校验
    product, err := s.productService.GetProduct(ctx, req.ProductType, req.ProductID)
    if err != nil {
        return nil, err
    }

    // 3. 防重校验（幂等）
    idempotentKey := fmt.Sprintf("payment:create:%d:%d:%d", req.UserID, req.ProductID, time.Now().Unix()/60)
    idem := s.redis.Get(ctx, idempotentKey)
    if idem != "" {
        return nil, ErrDuplicateOrder
    }
    s.redis.Set(ctx, idempotentKey, "1", 15*time.Minute)

    // 4. 风控检查
    risk := s.fraudService.CheckRisk(ctx, req.UserID, req.ClientIP, req.DeviceID, product.Price)
    if risk.Action == RiskActionReject {
        return nil, ErrFraudRejected
    }

    // 5. 生成订单号
    orderNo := GenerateOrderNo()

    // 6. 插入订单
    order := &PaymentOrder{
        UserID:           req.UserID,
        StudentProfileID: req.StudentProfileID,
        OrderNo:          orderNo,
        Channel:          req.Channel,
        ProductType:      req.ProductType,
        ProductID:        req.ProductID,
        SKUID:            req.SKUID,
        Amount:           product.Price,
        Currency:         "CNY",
        Status:           OrderStatusPending,
        PaymentStatus:    PaymentStatusUnpaid,
        NotifyURL:        req.NotifyURL,
        ReturnURL:        req.ReturnURL,
        Subject:          req.Subject,
        Body:             req.Body,
        Attach:           req.Attach,
        ClientIP:         req.ClientIP,
        DeviceID:         req.DeviceID,
        ExpireTime:       timePtr(time.Now().Add(15 * time.Minute)),
    }
    if err := s.db.Create(order).Error; err != nil {
        return nil, err
    }

    // 7. 调用渠道预支付
    channelParams, err := s.channelAdapter.PrePay(ctx, req.Channel, order)
    if err != nil {
        s.log.Error("预支付失败", zap.Error(err), zap.String("order_no", orderNo))
        return nil, ErrPrePayFailed
    }

    // 8. 更新订单状态为 PAYING
    order.Status = OrderStatusPaying
    if err := s.db.Save(order).Error; err != nil {
        s.log.Warn("更新订单状态失败", zap.Error(err), zap.String("order_no", orderNo))
        // 不影响返回支付参数，后续回调会纠正状态
    }

    return &CreateOrderResponse{
        OrderNo:     orderNo,
        Status:      order.Status,
        Amount:      order.Amount.String(),
        ExpireTime:  order.ExpireTime,
        PaymentParams: channelParams,
        PayURL:      s.buildPayURL(req.Channel, channelParams),
    }, nil
}
```

### 5.3 支付回调处理

```go
// HandleCallback 处理支付回调
func (s *PaymentService) HandleCallback(ctx context.Context, channel string, rawPayload []byte) error {
    // 1. 解析渠道回调数据
    notify, err := s.channelAdapter.ParseCallback(ctx, channel, rawPayload)
    if err != nil {
        s.log.Error("解析回调失败", zap.Error(err), zap.String("channel", channel))
        return err
    }

    // 2. 验签
    if !s.channelAdapter.VerifySign(ctx, channel, notify) {
        s.log.Error("签名验证失败", zap.String("channel", channel))
        return ErrInvalidSign
    }

    // 3. 幂等处理
    orderNo := notify.OrderNo
    tradeNo := notify.TradeNo
    idempotentKey := fmt.Sprintf("payment:callback:%s:%s", orderNo, tradeNo)
    if !s.redis.SetNX(ctx, idempotentKey, "1", 5*time.Minute) {
        s.log.Info("回调已处理过，跳过", zap.String("order_no", orderNo))
        return nil
    }

    // 4. 查询订单
    var order PaymentOrder
    if err := s.db.Where("order_no = ?", orderNo).First(&order).Error; err != nil {
        s.log.Error("订单不存在", zap.Error(err), zap.String("order_no", orderNo))
        return ErrOrderNotFound
    }

    // 5. 状态校验
    if order.Status == OrderStatusCompleted || order.Status == OrderStatusRefunded {
        s.log.Info("订单已完结，忽略回调", zap.String("order_no", orderNo), zap.String("status", order.Status))
        return nil
    }

    // 6. 事务更新订单与发放权益
    err = s.db.Transaction(func(tx *gorm.DB) error {
        // 更新订单状态
        order.Status = OrderStatusPaid
        order.PaymentStatus = PaymentStatusSuccess
        order.TradeNo = tradeNo
        order.PaidAt = timePtr(time.Now())
        order.CallbackPayload = json.RawMessage(rawPayload)
        if err := tx.Save(&order).Error; err != nil {
            return err
        }

        // 发放权益（调用会员服务）
        if err := s.membershipService.GrantMembership(ctx, order.UserID, order.ProductID, order.OrderNo); err != nil {
            s.log.Error("发放权益失败", zap.Error(err), zap.String("order_no", orderNo))
            return err
        }

        // 更新订单为 COMPLETED
        order.Status = OrderStatusCompleted
        order.CompletedAt = timePtr(time.Now())
        if err := tx.Save(&order).Error; err != nil {
            return err
        }

        return nil
    })

    if err != nil {
        s.log.Error("处理回调失败", zap.Error(err), zap.String("order_no", orderNo))
        return err
    }

    // 7. 发送对账消息
    s.messageQueue.Publish(ctx, "payment.reconciliation", map[string]interface{}{
        "order_no": orderNo,
        "channel":  channel,
        "status":   order.Status,
    })

    return nil
}
```

## 6. 错误处理

### 6.1 异常类型
```go
var (
    ErrOrderNotFound        = errors.New("订单不存在")
    ErrDuplicateOrder       = errors.New("订单号重复")
    ErrInvalidSign          = errors.New("签名验证失败")
    ErrPrePayFailed         = errors.New("预支付失败")
    ErrRefundAmountInvalid  = errors.New("退款金额不合法")
    ErrFraudRejected        = errors.New("风控拦截")
    ErrProductNotFound      = errors.New("商品不存在")
    ErrProductNotOnSale     = errors.New("商品未上架")
)
```

### 6.2 重试策略
- 预支付失败：立即重试1次，失败则返回错误
- 权益下发失败：重试3次（指数退避），仍失败则标记订单状态为 FAILED，发送告警
- 对账失败：按重试规则重试，最大5次
- 退款失败：根据渠道规则重试，最终人工处理

### 6.3 降级方案
- 渠道不可用：切换到备用渠道（按 priority 顺序）
- 对账任务延迟：允许滞后，不影响用户侧
- 权益下发失败：人工后台补发
