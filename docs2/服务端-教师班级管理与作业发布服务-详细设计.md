## 1. 模块概述

### 1.1 背景与目标

教师端是 PrimeTop V2.0 阶段核心扩展方向，面向学校教师提供班级管理、作业发布、AI 辅助批改和班级学情分析能力。本服务是教师端的核心后端，负责：

1. **教师身份认证**：教师资格证核验、快速体验模式
2. **班级生命周期管理**：创建、配置、归档、解散
3. **学生-班级关联**：邀请码加入、审批、批量导入、移除
4. **作业发布与分发**：题库选题 / AI 生成 / 自定义题目、定时发布、差异化分发
5. **答题与提交**：学生答题实时保存、限时控制、批量提交
6. **AI 辅助批改**：按题型策略批改、步骤分评估、置信度标记
7. **教师批改确认**：逐份批改 / 批量确认、评语、错题标记
8. **班级学情聚合**：班级维度 / 学生维度的作业统计、知识点热力图

### 1.2 服务边界

| 本服务负责 | 不负责（依赖其他服务） |
| --- | --- |
| 教师 Profile CRUD、认证状态管理 | 统一认证登录（依赖认证服务） |
| 班级 CRUD、邀请码生成 | 文件上传 OSS（依赖存储服务） |
| 作业 CRUD、发布流水线 | AI 出题（依赖 AI 服务） |
| 学生作业实例管理、答题保存 | 题库查询、题目校验（依赖题目服务） |
| AI 批改编排与结果存储 | AI 模型调用（依赖 AI 服务） |
| 教师批改确认、分数计算 | 消息推送投递（依赖消息服务） |
| 班级学情统计聚合 | 错题写入（依赖错题服务） |
| 班级通知公告 | 学情报告生成（依赖学情服务） |

### 1.3 核心约束

| 约束 | 值 | 说明 |
| --- | --- | --- |
| 单教师最大班级数 | 10（认证教师）/ 1（快速体验） | 防止资源滥用 |
| 单班级最大学生数 | 200（认证教师）/ 30（快速体验） | 保证批改效率 |
| 作业最大题数 | 50 | 控制批改耗时和学生负担 |
| 单作业最大附件 | 10 张图片 / 20MB | 存储成本控制 |
| 邀请码有效期 | 30 天 | 安全控制 |
| 快速体验有效期 | 90 天 | 促进认证转化 |
| 限时作业最大时长 | 180 分钟 | 合理考试时长 |
| 作业发布异步流水线超时 | 60 秒 | 防止长时间阻塞 |

#### 2.5.1 `content` JSON 结构定义

```typescript
interface AssignmentContent {
  sections: Section[];
}

interface Section {
  index: number;           // 节序号，从0开始
  title: string;           // 节标题，如"一、选择题"
  description?: string;    // 节说明
  items: Item[];
}

interface Item {
  index: number;           // 题序号，节内从0开始
  question_id?: number;    // 题库题ID（题库选题时存在）
  type: string;            // 题型: choice/fill/short_answer/essay/calculation
  content: string;         // 题干内容
  options?: string[];      // 选项（选择题）
  images?: string[];       // 题目配图URL
  answer: string;          // 标准答案
  explanation: string;     // 解析
  score: number;           // 分值
  difficulty?: number;     // 难度1-5
  knowledge_point_ids?: number[];  // 关联知识点
  auto_gradable: boolean;  // 是否可自动判分
  source: string;          // 来源: pool/ai/custom
  metadata?: object;       // 扩展字段（如计算题的步骤分配置）
}
```

### 5.2 AI 批改策略路由

| 题型 | 批改方式 | 置信度 | 是否需人工复核 |
| --- | --- | --- | --- |
| choice（选择题） | 精确匹配标准答案 | 1.0 | 否 |
| fill（填空题） | 去空格/标点后精确匹配 + AI 校验语义等价 | 0.9 | 否 |
| calculation（计算题） | AI 分步评分 + 最终结果精确匹配 | 0.7-0.9 | 结果不一致时是 |
| short_answer（简答题） | AI 评分 + 参考答案语义比对 | 0.5-0.8 | confidence < 0.7 时是 |
| essay（作文题） | AI 写作评估引擎（立意/结构/语言/标点） | 0.3-0.6 | 始终标记为需复核 |

### 5.3 分数计算规则

```
最终分数计算优先级：
1. 教师手动评定的分数（teacherGradeRequest.items[].score 之和） → 以此为准
2. 如教师未手动评定某题，该题使用 AI 自动判分
3. 如 AI 也未判分（批改失败），该题分数为 0，标记需人工复核

最终 score = Σ(每题 final_score)
auto_score = Σ(AI批改每题得分)
manual_score = Σ(教师手动评定的题目得分，未手动评定的用 auto_score 补)
```

### 5.4 作业统计更新策略

采用 **事件驱动 + 定时对账** 双保障：

| 触发点 | 更新内容 | 一致性 |
| --- | --- | --- |
| 学生提交作业 | submitted_count++ | 最终一致（异步） |
| 教师批改完成 | graded_count++、重算 avg_score | 最终一致（异步） |
| 定时任务（每5分钟） | 完整重算 submitted_count、graded_count、avg_score、completion_rate | 强一致（对账） |

## 8. 安全设计

### 8.1 数据隔离

## 10. 关键代码示例

### 10.1 邀请码生成（防碰撞）

```java
@Component
public class ClassCodeGenerator {
    
    private static final String CHARS = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"; // 去除易混淆字符
    private static final int CODE_LENGTH = 6;
    
    @Autowired
    private ClassMapper classMapper;
    @Autowired
    private RedissonClient redissonClient;
    
    /**
     * 生成唯一班级邀请码
     * 策略：随机生成 → DB 唯一索引兜底 → 重试（最多10次）
     */
    public String generateUniqueCode() {
        for (int attempt = 0; attempt < 10; attempt++) {
            String code = randomCode();
            if (classMapper.selectByClassCode(code) == null) {
                return code;
            }
            log.warn("邀请码碰撞，重试: {} (第{}次)", code, attempt + 1);
        }
        throw new ServiceException("邀请码生成失败，请重试");
    }
    
    private String randomCode() {
        StringBuilder sb = new StringBuilder(CODE_LENGTH);
        ThreadLocalRandom random = ThreadLocalRandom.current();
        for (int i = 0; i < CODE_LENGTH; i++) {
            sb.append(CHARS.charAt(random.nextInt(CHARS.length())));
        }
        return sb.toString();
    }
}
```

### 10.2 作业统计更新（事件驱动）

```java
@Component
public class AssignmentStatsUpdateListener {
    
    @Autowired
    private AssignmentTaskMapper assignmentTaskMapper;
    @Autowired
    private AssignmentMapper assignmentMapper;
    
    /**
     * 学生提交事件 → 更新作业统计
     */
    @Async
    @EventListener
    public void onTaskSubmitted(AssignmentTaskSubmittedEvent event) {
        updateStats(event.getAssignmentId());
    }
    
    /**
     * 教师批改完成事件 → 更新作业统计
     */
    @Async
    @EventListener
    public void onTaskGraded(AssignmentTaskGradedEvent event) {
        updateStats(event.getAssignmentId());
    }
    
    private void updateStats(Long assignmentId) {
        AssignmentStats stats = assignmentTaskMapper.calculateStats(assignmentId);
        assignmentMapper.updateStats(assignmentId, stats);
    }
}
```

```sql
SELECT 
    COUNT(CASE WHEN status >= 2 THEN 1 END) AS submitted_count,
    COUNT(CASE WHEN status >= 3 THEN 1 END) AS graded_count,
    AVG(CASE WHEN status >= 3 THEN score ELSE NULL END) AS avg_score,
    COUNT(CASE WHEN status >= 2 THEN 1 END) * 1.0 / 
        NULLIF(COUNT(*), 0) AS completion_rate
FROM assignment_task
WHERE assignment_id = #{assignmentId}
```

```java
 * 为学生生成乱序映射
 * 返回 Map<sectionIndex, List<newItemIndex>> 表示原始 itemIndex → 新位置

private List<Integer> generateShuffleOrder(int itemCount) {
    List<Integer> order = IntStream.range(0, itemCount)
        .boxed()
        .collect(Collectors.toList());
    Collections.shuffle(order, ThreadLocalRandom.current());
    return order;
}
```

### 10.4 限时作业服务端校验

```java
/**
 * 校验限时作业是否超时
 */
public void validateTimeLimit(AssignmentTask task, Assignment assignment) {
    if (assignment.getTimeLimitMin() == null) return;
    if (task.getStartedAt() == null) return;
    
    LocalDateTime deadline = task.getStartedAt()
        .plusMinutes(assignment.getTimeLimitMin());
    
    if (LocalDateTime.now().isAfter(deadline)) {
        // 标记为超时自动提交
        task.setSubmitMethod((byte) 2);
        task.setStatus(TaskStatus.SUBMITTED);
        task.setSubmittedAt(LocalDateTime.now());
        // 不抛异常，允许提交（系统自动行为）
    }
}
```
