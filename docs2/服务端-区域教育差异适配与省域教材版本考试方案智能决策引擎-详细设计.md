# 服务端-区域教育差异适配与省域教材版本考试方案智能决策引擎-详细设计

## 1. 模块概述

### 1.1 功能定位

中国 K-12 教育实行省级统筹，各省（直辖市/自治区）在教材版本选用、中高考考试方案、课程计划、学科组合等方面存在显著差异。本引擎作为 PrimeTop 平台的**区域教育政策适配中枢**，负责：

1. **区域识别**：根据用户所在省份/城市，自动判定其所属的教育政策区划。
2. **教材版本决策**：智能推荐该区域当前使用的教材版本（人教版、苏教版、北师大版等），并支持多版本并存场景。
3. **考试方案适配**：判定用户所在区域的中考方案、高考方案（传统文理分科、新高考3+3、新高考3+1+2、新高考3+2+1等），驱动系统生成对应的学科组合、选科指引和备考策略。
4. **课标版本映射**：对接课改过渡期（旧课标 → 新课标）的内容映射，确保学习内容与当地教学要求一致。
5. **跨区域迁移处理**：学生在省际转学时，自动处理教材版本切换、知识点映射、进度对齐。
6. **政策变更传播**：当省份发布新政策（如新高考改革落地），驱动全链路内容适配与用户通知。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 区域识别准确率 | ≥ 99.5%（基于 IP + 用户手动选择双重确认） |
| 教材版本推荐命中率 | ≥ 95%（用户无需手动修改） |
| 政策变更生效延迟 | 运营配置后 ≤ 2 小时全平台生效 |
| 跨区域迁移计算耗时 | P95 ≤ 3 秒 |
| 支持省级行政区 | 34 个（含港澳台预留扩展） |

## 2. 核心领域模型

### 2.1 区域教育区划模型

```java
/**
 * 区域教育区划
 * 一个 Province 包含多个 City，每个 City 可归属一个 EducationZone
 * EducationZone 是"教育政策一致区"的抽象
 */
public class EducationZone {
    private String zoneId;              // 区域ID，如 "ZONE_HUbei_NEW_GAOKAO_3_1_2"
    private String zoneName;            // 区域名称，如 "湖北省-新高考3+1+2区"
    private String provinceCode;        // 省份行政区划代码，如 "420000"
    private List<String> cityCodes;     // 覆盖城市代码列表
    private GaokaoSchemeType gaokaoScheme;  // 高考方案类型
    private ZhongkaoSchemeType zhongkaoScheme; // 中考方案类型
    private CurriculumStandardType curriculumStandard; // 课标版本
    private LocalDate effectiveFrom;    // 生效日期
    private LocalDate effectiveUntil;   // 失效日期（null = 当前有效）
    private ZoneStatus status;          // ACTIVE / TRANSITIONING / DEPRECATED
}

public enum GaokaoSchemeType {
    TRADITIONAL_ARTS_SCIENCE,   // 传统文理分科
    NEW_GAOKAO_3_PLUS_3,        // 新高考3+3（浙沪模式）
    NEW_GAOKAO_3_PLUS_1_PLUS_2, // 新高考3+1+2（冀辽苏鄂湘粤闽等）
    NEW_GAOKAO_3_PLUS_2_PLUS_1, // 新高考3+2+1（部分省份过渡方案）
    COMPREHENSIVE_REFORM,       // 综合改革（北京特色方案）
    TRANSITION_PERIOD           // 改革过渡期（新旧并行）
}

public enum ZhongkaoSchemeType {
    GENERAL_5_SUBJECTS,         // 普通五科统考
    GENERAL_7_SUBJECTS,         // 七科统考（含生物地理）
    GENERAL_8_SUBJECTS,         // 八科统考（全科目）
    SELECTIVE_3_PLUS_3,         // 选考3+3模式
    PROVINCE_SPECIFIC           // 省级特殊方案
}

public enum CurriculumStandardType {
    OLD_STANDARD_2003,    // 2003版课标（旧课标，逐步淘汰）
    NEW_STANDARD_2017,    // 2017版新课标（2020修订）
    NEW_STANDARD_2022,    // 2022版义务教育课标
    TRANSITIONAL          // 过渡期混合
}
```

### 2.3 考试方案配置模型

```java
/**
 * 高考方案详细配置
 */
public class GaokaoScheme {
    private String schemeId;
    private GaokaoSchemeType schemeType;
    private String provinceCode;
    private Integer firstEffectiveYear;  // 首次生效年份
    private Integer lastEffectiveYear;   // 最后生效年份（null = 持续有效）

    // 必考科目
    private List<String> compulsorySubjects;  // 通常为 ["CHINESE", "MATH", "ENGLISH"]

    // 选考科目配置
    private SelectiveSubjectConfig selectiveConfig;

    // 总分计算方式
    private ScoreCalculationRule scoreRule;

    // 志愿填报规则
    private CollegeApplicationRule applicationRule;

    private List<PolicyTransition> transitions;  // 政策过渡配置
}

/**
 * 选考科目配置
 */
public class SelectiveSubjectConfig {
    // 3+3模式：从6科（物理/化学/生物/历史/地理/政治）中选3科
    // 3+1+2模式：1科首选（物理/历史二选一）+ 2科再选（化/生/地/政四选二）
    private SelectiveMode mode;

    private List<String> firstChoiceSubjects;   // 首选科目范围（3+1+2模式）
    private Integer firstChoiceCount;           // 首选科目数量

    private List<String> secondChoiceSubjects;  // 再选科目范围
    private Integer secondChoiceCount;          // 再选科目数量

    private List<String> freeChoiceSubjects;    // 自由选择范围（3+3模式）
    private Integer freeChoiceCount;

    // 赋分制配置
    private AssignmentScoringRule scoringRule;
}

/**
 * 赋分制规则（新高考选考科目赋分）
 */
public class AssignmentScoringRule {
    private AssignmentMethod method;    // 等级赋分 / 比例赋分
    private Integer rawScoreMin;        // 原始分下限
    private Integer rawScoreMax;        // 原始分上限
    private List<AssignmentLevel> levels; // 赋分等级表
}

public class AssignmentLevel {
    private Integer rankPercentileFrom; // 排名百分比区间起
    private Integer rankPercentileTo;   // 排名百分比区间止
    private Integer assignedScoreMin;   // 赋分区间下限
    private Integer assignedScoreMax;   // 赋分区间上限
}
```

### 3.2 缓存结构（Redis）

```
# 区域信息缓存（TTL: 24h）
region:zone:{zoneId}                         → EducationZone JSON
region:province:{provinceCode}:zones         → List<zoneId>
region:user:{userId}:zone                    → zoneId（用户当前区域）
region:user:{userId}:textbookBindings        → List<RegionTextbookBinding> JSON

# 教材版本缓存（TTL: 12h）
region:textbook:{versionId}                  → TextbookVersion JSON
region:zone:{zoneId}:textbooks:{subject}:{phase}:{grade} → List<versionId>

# 考试方案缓存（TTL: 24h）
region:gaokao:{provinceCode}:current         → GaokaoScheme JSON
region:zhongkao:{provinceCode}:{cityCode}:current → ZhongkaoScheme JSON

# 知识点映射缓存（TTL: 7d，低频变更）
region:mapping:{fromVersionId}:{toVersionId} → Map<kpCode, MappingResult> JSON

# 区域决策缓存（用户级，TTL: 1h）
region:decision:{userId}:{subject}:{grade}   → RegionDecisionResult JSON
```

### 5.2 教材版本决策算法

```java
/**
 * 教材版本决策核心算法
 */
public class TextbookDecisionService {

    /**
     * 为指定区域+学科+年级推荐教材版本
     * 决策优先级：
     * 1. 区域默认绑定版本（isDefault=true）
     * 2. 用户所在城市的主流版本
     * 3. 省级统一版本
     * 4. 用户手动选择的版本
     */
    public TextbookDecisionResult decideTextbook(
            String zoneId, String subjectCode,
            PhaseType phase, Integer grade, Integer enrollmentYear) {

        // 1. 查询区域绑定关系
        List<RegionTextbookBinding> bindings = bindingRepository
            .findByZoneAndSubjectAndPhaseAndGrade(zoneId, subjectCode, phase, grade);

        if (bindings.isEmpty()) {
            // 降级：使用省级默认
            bindings = bindingRepository
                .findByProvinceAndSubjectAndPhaseAndGrade(zoneId, subjectCode, phase, grade);
        }

        // 2. 按入学年份过滤有效版本
        bindings = bindings.stream()
            .filter(b -> b.getStartYear() <= enrollmentYear)
            .filter(b -> b.getEndYear() == null || b.getEndYear() >= enrollmentYear)
            .collect(Collectors.toList());

        // 3. 优先返回默认版本
        RegionTextbookBinding defaultBinding = bindings.stream()
            .filter(RegionTextbookBinding::getIsDefault)
            .findFirst()
            .orElse(bindings.get(0));

        // 4. 构建结果
        TextbookDecisionResult result = new TextbookDecisionResult();
        result.setRecommended(mapToTextbookInfo(defaultBinding));
        result.setAlternatives(buildAlternatives(bindings, defaultBinding));
        result.setConfidence(calculateConfidence(defaultBinding, bindings));

        return result;
    }

    /**
     * 置信度计算
     */
    private double calculateConfidence(
            RegionTextbookBinding selected,
            List<RegionTextbookBinding> all) {
        if (selected.getIsDefault() && all.size() == 1) {
            return 0.98;  // 唯一默认版本，高置信
        }
        if (selected.getIsDefault()) {
            return 0.90;  // 默认版本但有多版本并存
        }
        return 0.75;  // 非默认版本
    }
}
```

### 5.5 选科推荐算法

```java
/**
 * 新高考选科推荐服务
 */
public class SubjectSelectionService {

    /**
     * 多维度选科推荐
     * 综合考虑：学科能力、专业覆盖、竞争烈度、用户意向
     */
    public List<SubjectRecommendation> recommend(
            String userId, String zoneId,
            List<String> targetMajors, List<String> excludeSubjects) {

        // 1. 获取区域高考方案
        GaokaoScheme scheme = schemeService.getCurrentGaokaoScheme(zoneId);
        SelectiveSubjectConfig config = scheme.getSelectiveConfig();

        // 2. 生成所有合法组合
        List<List<String>> combinations = generateValidCombinations(config, excludeSubjects);

        // 3. 获取用户学科能力数据
        Map<String, SubjectAbility> abilities = abilityService
            .getSubjectAbilities(userId);

        // 4. 查询专业覆盖率
        Map<List<String>, Double> coverageRates = majorService
            .calculateMajorCoverage(combinations, targetMajors);

        // 5. 查询历史选科竞争度
        Map<List<String>, CompetitionStats> competition = statsService
            .getCompetitionStats(zoneId, combinations);

        // 6. 综合评分
        List<SubjectRecommendation> results = combinations.stream()
            .map(combo -> {
                double abilityScore = evaluateAbilityMatch(combo, abilities);
                double coverageScore = coverageRates.getOrDefault(combo, 0.5);
                double competitionScore = 1.0 - competition.get(combo).getCompetitorRatio();
                double interestScore = evaluateInterestMatch(combo, targetMajors);

                // 加权综合
                double totalScore = abilityScore * 0.35
                                  + coverageScore * 0.30
                                  + interestScore * 0.20
                                  + competitionScore * 0.15;

                SubjectRecommendation rec = new SubjectRecommendation();
                rec.setCombination(combo);
                rec.setMatchScore(totalScore);
                rec.setMajorCoverage(coverageScore);
                rec.setReasons(generateReasons(combo, abilities, coverageRates, competition));
                rec.setWarnings(generateWarnings(combo, competition));
                return rec;
            })
            .sorted(Comparator.comparingDouble(SubjectRecommendation::getMatchScore).reversed())
            .limit(5)  // 返回 Top 5
            .collect(Collectors.toList());

        return results;
    }
}
```

## 7. 错误处理与降级策略

### 7.1 错误码定义

| 错误码 | HTTP | 含义 | 处理方式 |
| --- | --- | --- | --- |
| REGION_ZONE_NOT_FOUND | 404 | 教育区域不存在 | 返回全国默认配置 |
| REGION_ZONE_AMBIGUOUS | 409 | 区域识别结果不唯一 | 返回候选列表，要求用户确认 |
| REGION_TEXTBOOK_NO_BINDING | 404 | 区域无教材版本绑定 | 降级到人教版默认版本 |
| REGION_TRANSFER_IN_PROGRESS | 409 | 迁移正在进行中 | 返回当前迁移进度 |
| REGION_TRANSFER_FAILED | 500 | 迁移失败 | 返回失败原因，支持重试 |
| REGION_POLICY_NOT_EFFECTIVE | 422 | 政策尚未生效 | 返回生效日期提示 |
| REGION_SCHEME_NOT_CONFIGURED | 500 | 考试方案未配置 | 降级到全国通用方案 |

### 7.2 降级策略

/**
 * 区域服务降级处理器
 */
@Component
public class RegionServiceFallbackHandler {

    /**
     * 区域识别失败 → 降级为手动选择
     */
    public RegionDetectResult fallbackDetect(RegionDetectContext ctx) {
        RegionDetectResult result = new RegionDetectResult();
        result.setDetectedZone(getNationalDefaultZone());
        result.setNeedUserConfirm(true);
        result.setMessage("无法自动识别您的区域，请手动选择所在省份");
        result.setAllZones(zoneRepository.findAllActiveZones());
        return result;
    }

    /**
     * 教材版本查询失败 → 降级为人教版
     */
    public TextbookDecisionResult fallbackTextbook(String subject, PhaseType phase, Integer grade) {
        TextbookVersion defaultVersion = textbookService
            .getOrCreateDefaultVersion("PEP", subject, phase, grade);
        TextbookDecisionResult result = new TextbookDecisionResult();
        result.setRecommended(defaultVersion);
        result.setConfidence(0.5);
        result.setFallback(true);
        result.setMessage("使用全国默认教材版本（人教版），您可在设置中修改");
        return result;
    }

    /**
     * 考试方案查询失败 → 降级为通用方案
     */
    public GaokaoScheme fallbackGaokao(String provinceCode) {
        GaokaoScheme generic = schemeRepository
            .findBySchemeType(GaokaoSchemeType.TRADITIONAL_ARTS_SCIENCE);
        generic.setProvinceCode(provinceCode);
        generic.setNote("降级使用通用方案，请联系客服确认本地考试政策");
        return generic;
    }

    /**
     * 迁移失败 → 保留原配置，通知运营
     */
    public void handleTransferFailure(String transferId, Exception e) {
        TransferRecord record = transferRepository.findById(transferId);
        record.setStatus(TransferStatus.FAILED);
        record.setErrorMessage(e.getMessage());
        transferRepository.save(record);

        // 发送告警
        alertService.sendAlert("REGION_TRANSFER_FAILED",
            String.format("用户 %s 区域迁移失败: %s", record.getUserId(), e.getMessage()));

        // 保留用户原有配置不变，仅通知用户
        notificationService.sendToUser(record.getUserId(),
            "区域切换遇到问题",
            "您的教材版本配置暂时保持不变，客服将在24小时内联系您协助处理。");
    }
}

### 7.3 一致性保障

```java
/**
 * 教材版本切换的事务性保障
 * 确保切换不丢数据
 */
@Transactional(isolation = Isolation.SERIALIZABLE, timeout = 30)
public void switchTextbookVersionWithConsistency(
        Long userId, String subject,
        String fromVersionId, String toVersionId) {

    // 1. 锁定用户配置行
    UserTextbookConfig config = configRepository
        .findByUserIdAndSubjectForUpdate(userId, subject);
    if (config == null) {
        throw new BusinessException("CONFIG_NOT_FOUND");
    }

    // 2. 验证源版本一致
    if (!config.getVersionId().equals(fromVersionId)) {
        throw new BusinessException("VERSION_MISMATCH",
            "当前版本已变更，请刷新后重试");
    }

    // 3. 执行切换
    config.setVersionId(toVersionId);
    config.setUpdatedAt(LocalDateTime.now());
    configRepository.save(config);

    // 4. 异步触发知识点重映射（失败不阻塞主流程）
    eventPublisher.publishEvent(new TextbookVersionChangedEvent(
        userId, subject, fromVersionId, toVersionId));

    // 5. 失效缓存
    cacheService.evictUserTextbookConfig(userId, subject);
}
```
