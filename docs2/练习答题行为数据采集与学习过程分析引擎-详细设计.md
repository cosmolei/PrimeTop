# 练习答题行为数据采集与学习过程分析引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

在学生练习、测评、考试模拟等答题场景中，实时采集细粒度行为数据（包括答题时长、犹豫停顿、答案修改轨迹、草稿使用、求助行为等），构建**答题过程数字画像**。该画像用于：

1. **学情诊断**：区分"粗心失误"与"概念不清"，精准定位薄弱根因
2. **难度感知**：通过行为特征推断学生对题目的主观难度感受
3. **知识掌握度校准**：结合答题结果 + 答题过程双维度评估知识掌握程度
4. **自适应推荐**：基于过程特征动态调整下一题难度和推荐策略
5. **学习报告增强**：在学情报告中呈现"不仅知道对错，还知道怎么答的"

### 1.2 与已有模块的边界

| 模块 | 关注点 | 本模块关系 |
|------|--------|-----------|
| 练习与测评系统 | 题目分发、答题流程、评分判对错 | 本模块是其**数据采集层**，嵌入答题流程 |
| 学习行为事件流 | 通用事件的采集、路由、级联处理 | 本模块产出的事件是事件流的**上游数据源之一** |
| 数据埋点与关键指标 | 产品级指标定义与采集规范 | 本模块聚焦**答题场景的深度行为数据**，粒度远超通用埋点 |
| 学情分析 | 学习数据汇总与画像输出 | 本模块产出的过程特征是学情画像的**输入维度** |
| 题目难度标定与能力评估 | 题目难度值、学生能力值估算 | 本模块提供**行为侧特征**辅助能力评估模型 |

### 1.3 设计原则

1. **无感采集**：不干扰正常答题体验，所有行为采集在后台静默进行
2. **本地优先**：行为数据先在客户端本地缓冲和预处理，批量上报服务端
3. **隐私合规**：行为数据仅用于学习分析，不采集输入法内容等敏感信息
4. **离线可用**：断网场景下行为数据不丢失，恢复后自动上报
5. **可解释性**：分析结果可追溯至原始行为事件，支持向家长/教师解释

## 2. 行为事件体系

### 2.1 事件分类总览

```
答题行为事件
├── 会话级事件（session-level）
│   ├── practice_started        练习会话开始
│   ├── practice_paused         练习暂停
│   ├── practice_resumed        练习恢复
│   ├── practice_submitted      练习提交
│   └── practice_abandoned      练习放弃
│
├── 题目级事件（question-level）
│   ├── question_entered        进入题目
│   ├── question_viewed         题目内容首次完整可见
│   ├── answer_option_hovered   选项悬停（选择题）
│   ├── answer_selected         选中答案
│   ├── answer_deselected       取消选中
│   ├── answer_changed          答案变更（含变更轨迹）
│   ├── answer_confirmed        确认提交答案
│   ├── answer_timed_out        答题超时
│   └── question_skipped        跳过此题
│
├── 辅助行为事件（auxiliary-level）
│   ├── hint_requested          请求提示
│   ├── hint_viewed             查看提示
│   ├── ai_asked                触发AI辅导
│   ├── reference_opened        打开参考资料/公式
│   ├── calculator_used         使用计算器
│   ├── draft_written           草稿书写（手写/文本）
│   ├── voice_input_used        使用语音输入
│   └── notepad_toggled         切换草稿板
│
└── 元行为事件（meta-level）
    ├── app_backgrounded        APP进入后台
    ├── app_foregrounded        APP回到前台
    ├── screen_rotated          屏幕旋转
    ├── interruption_detected   检测到中断（来电等）
    └── scroll_behavior         答题区内滚动行为
```

```typescript
interface BehaviorEvent {
  eventId: string;           // 唯一事件ID (UUID v7)
  eventType: string;         // 事件类型标识
```

### 2.3 行为聚合指标

原始事件在客户端进行一级聚合，生成以下维度指标随事件一起上报：

```typescript
interface QuestionBehaviorMetrics {
  questionId: string;
  sessionId: string;

  // 时间维度
  totalDuration: number;              // 总答题时长（ms）
  readingDuration: number;            // 阅读审题时长（ms，首次进入→首次操作）
  thinkingDuration: number;           // 思考时长（ms，阅读后→首次选中）
  confirmingDuration: number;         // 确认时长（ms，最终选中→确认提交）
  pauseDuration: number;              // 累计停顿时长（ms，>3s无操作视为停顿）
  pauseCount: number;                 // 停顿次数

  // 操作维度
  totalChanges: number;               // 答案变更次数
  uniqueOptionsConsidered: number;    // 考虑过的不同选项数（选择题）
  hoverSequence: string;              // 选项浏览序列（如 "A→B→C→A"）

  // 辅助行为维度
  hintUsed: boolean;                  // 是否使用提示
  hintCount: number;                  // 使用提示次数
  aiAsked: boolean;                   // 是否求助AI
  referenceUsed: boolean;             // 是否查阅参考资料
  draftUsed: boolean;                 // 是否使用草稿
  calculatorUsed: boolean;            // 是否使用计算器

  // 中断维度
  backgroundCount: number;            // 切到后台次数
  totalBackgroundDuration: number;    // 累计后台时长（ms）
  interruptionCount: number;          // 中断次数

  // 推断维度（客户端初步推断，服务端最终校正）
  inferredEngagement: 'high' | 'medium' | 'low';   // 投入度
  inferredConfidence: 'high' | 'medium' | 'low';   // 答题信心
  inferredStrategy: 'systematic' | 'random' | 'elimination' | 'guess'; // 答题策略
}
```

### 3.2 BehaviorCollector 核心实现

```dart
/// 行为采集器 - 嵌入答题页面的核心采集组件
class BehaviorCollector {
  final String sessionId;
  final String userId;
  int _sequenceNum = 0;

  // 当前题目的状态追踪
  final Map<String, _QuestionState> _questionStates = {};

  // 事件缓冲
  final List<BehaviorEvent> _buffer = [];
  final BehaviorBuffer _persistBuffer;

  // 计时器
  Timer? _batchTimer;
  DateTime _sessionStartTime;

  BehaviorCollector({
    required this.sessionId,
    required this.userId,
    required this.persistBuffer,
  }) : _sessionStartTime = DateTime.now();

  /// 题目进入
  void onQuestionEntered(String questionId, {
    required int questionIndex,
    required String questionType,
    String? previousQuestionId,
    String enterSource = 'sequential',
  }) {
    final state = _QuestionState(
      questionId: questionId,
      questionIndex: questionIndex,
      questionType: questionType,
      enterTime: DateTime.now(),
    );
    _questionStates[questionId] = state;

    _emit('question_entered', questionId, {
      'questionIndex': questionIndex,
      'questionType': questionType,
      'previousQuestionId': previousQuestionId,
      'enterSource': enterSource,
    });
  }

  /// 选项悬停（选择题）
  void onOptionHovered(String questionId, String optionId, int optionIndex) {
    final state = _questionStates[questionId];
    if (state == null) return;

    state.recordOptionHover(optionId, optionIndex);

    // 不立即上报悬停事件，而是在离开选项后批量上报
  }

  /// 选项悬停结束
  void onOptionHoverEnded(String questionId, String optionId) {
    final state = _questionStates[questionId];
    if (state == null) return;

    final hover = state.endOptionHover(optionId);
    if (hover == null) return;

    _emit('answer_option_hovered', questionId, {
      'optionId': optionId,
      'optionIndex': hover.optionIndex,
      'hoverDuration': hover.duration.inMilliseconds,
      'isFinalSelection': false, // 事后回填
      'sequenceInVisit': hover.sequence,
    });
  }

  /// 答案变更
  void onAnswerChanged(String questionId, {
    required String previousAnswer,
    required String currentAnswer,
    List<String>? previousOptionIds,
    List<String>? currentOptionIds,
  }) {
    final state = _questionStates[questionId];
    if (state == null) return;

    state.recordChange();

    final elapsed = DateTime.now().difference(state.enterTime);
    final timeSinceLast = state.lastChangeTime != null
        ? DateTime.now().difference(state.lastChangeTime!)
        : elapsed;

    state.lastChangeTime = DateTime.now();

    _emit('answer_changed', questionId, {
      'changeIndex': state.changeCount,
      'previousAnswer': previousAnswer,
      'currentAnswer': currentAnswer,
      'previousOptionIds': previousOptionIds,
      'currentOptionIds': currentOptionIds,
      'timeSinceQuestionEnter': elapsed.inMilliseconds,
      'timeSinceLastChange': timeSinceLast.inMilliseconds,
    });
  }

  /// 确认提交答案
  Future<void> onAnswerConfirmed(String questionId, {
    required String answer,
    List<String>? optionIds,
  }) async {
    final state = _questionStates[questionId];
    if (state == null) return;

    final elapsed = DateTime.now().difference(state.enterTime);

    // 计算聚合指标
    final metrics = _computeMetrics(state, answer, optionIds);

    _emit('answer_confirmed', questionId, {
      'answer': answer,
      'optionIds': optionIds,
      'timeSinceQuestionEnter': elapsed.inMilliseconds,
      'totalChanges': state.changeCount,
      'hintUsedCount': state.hintCount,
      'aiAskedCount': state.aiAskedCount,
      'referenceUsedCount': state.referenceCount,
    });

    // 同时上报聚合指标
    _persistBuffer.queueMetrics(metrics);
  }

  /// 检测停顿（由定时器驱动）
  void checkForPause(String questionId) {
    final state = _questionStates[questionId];
    if (state == null) return;

    final idleTime = DateTime.now().difference(state.lastActivityTime);
    if (idleTime.inSeconds >= 3 && !state.inPause) {
      state.inPause = true;
      state.pauseCount++;
    }
  }

  /// 发射事件
  void _emit(String eventType, String questionId, Map<String, dynamic> metadata) {
    final event = BehaviorEvent(
      eventId: _generateEventId(),
      eventType: eventType,
      sessionId: sessionId,
      questionId: questionId,
      userId: userId,
      timestamp: DateTime.now().millisecondsSinceEpoch,
      clientTime: DateTime.now().toIso8601String(),
      sequenceNum: _sequenceNum++,
      metadata: metadata,
    );

    _buffer.add(event);
    _persistBuffer.queueEvent(event);

    // 更新题目状态的活动时间
    _questionStates[questionId]?.lastActivityTime = DateTime.now();
  }

  /// 计算单题聚合指标
  QuestionBehaviorMetrics _computeMetrics(
    _QuestionState state,
    String answer,
    List<String>? optionIds,
  ) {
    final now = DateTime.now();
    final totalDuration = now.difference(state.enterTime).inMilliseconds;
    final readingDuration = state.firstActionTime != null
        ? state.firstActionTime!.difference(state.enterTime).inMilliseconds
        : totalDuration;

    // 推断投入度
    String engagement;
    if (state.pauseCount <= 1 && state.backgroundCount == 0) {
      engagement = totalDuration > 10000 ? 'high' : 'medium';
    } else if (state.backgroundCount > 2 || state.pauseCount > 5) {
      engagement = 'low';
    } else {
      engagement = 'medium';
    }

    // 推断信心
    String confidence;
    if (state.changeCount == 0 && readingDuration < 30000) {
      confidence = 'high';
    } else if (state.changeCount >= 3 || readingDuration > 120000) {
      confidence = 'low';
    } else {
      confidence = 'medium';
    }

    // 推断策略
    String strategy;
    if (state.optionHoverSequence.length >= 3 && state.changeCount <= 1) {
      strategy = 'elimination'; // 逐项排除
    } else if (state.changeCount == 0 && readingDuration < 5000) {
      strategy = 'guess'; // 快速猜测
    } else if (state.draftUsed || state.calculatorUsed) {
      strategy = 'systematic'; // 系统计算
    } else {
      strategy = 'random';
    }

    return QuestionBehaviorMetrics(
      questionId: state.questionId,
      sessionId: sessionId,
      totalDuration: totalDuration,
      readingDuration: readingDuration,
      thinkingDuration: state.firstSelectionTime != null
          ? state.firstSelectionTime!
              .difference(state.firstActionTime ?? state.enterTime)
              .inMilliseconds
          : 0,
      confirmingDuration: state.firstSelectionTime != null
          ? now.difference(state.firstSelectionTime!).inMilliseconds
          : 0,
      pauseDuration: state.totalPauseDuration.inMilliseconds,
      pauseCount: state.pauseCount,
      totalChanges: state.changeCount,
      uniqueOptionsConsidered: state.uniqueOptionsConsidered.length,
      hoverSequence: state.optionHoverSequence.join('→'),
      hintUsed: state.hintCount > 0,
      hintCount: state.hintCount,
      aiAsked: state.aiAskedCount > 0,
      referenceUsed: state.referenceCount > 0,
      draftUsed: state.draftUsed,
      calculatorUsed: state.calculatorUsed,
      backgroundCount: state.backgroundCount,
      totalBackgroundDuration: state.totalBackgroundDuration.inMilliseconds,
      interruptionCount: state.interruptionCount,
      inferredEngagement: engagement,
      inferredConfidence: confidence,
      inferredStrategy: strategy,
    );
  }

  String _generateEventId() {
    // UUID v7 时间排序 + 随机
    return '${DateTime.now().millisecondsSinceEpoch.toRadixString(36)}-'
           '${_sequenceNum.toRadixString(36)}-'
           '${Random().nextInt(0xFFFFFF).toRadixString(36)}';
  }
}
```

### 3.3 题目状态追踪器

```dart
/// 单题状态追踪 - 记录答题过程中所有关键时间点和行为
class _QuestionState {
  final String questionId;
  final int questionIndex;
  final String questionType;
  final DateTime enterTime;

  DateTime? firstActionTime;      // 首次操作时间（选择/输入等）
  DateTime? firstSelectionTime;   // 首次选中时间
  DateTime? lastChangeTime;       // 最近一次变更时间
  DateTime lastActivityTime;      // 最近活动时间

  int changeCount = 0;
  int pauseCount = 0;
  bool inPause = false;
  Duration totalPauseDuration = Duration.zero;

  // 选项悬停追踪
  final List<String> optionHoverSequence = [];
  final Set<String> uniqueOptionsConsidered = {};
  _OptionHover? _currentHover;
  int _hoverSequenceCounter = 0;

  // 辅助行为计数
  int hintCount = 0;
  int aiAskedCount = 0;
  int referenceCount = 0;
  bool draftUsed = false;
  bool calculatorUsed = false;

  // 中断追踪
  int backgroundCount = 0;
  Duration totalBackgroundDuration = Duration.zero;
  DateTime? _backgroundStartTime;
  int interruptionCount = 0;

  _QuestionState({
    required this.questionId,
    required this.questionIndex,
    required this.questionType,
    required this.enterTime,
  }) : lastActivityTime = enterTime;

  void recordOptionHover(String optionId, int optionIndex) {
    _currentHover = _OptionHover(
      optionId: optionId,
      optionIndex: optionIndex,
      startTime: DateTime.now(),
      sequence: _hoverSequenceCounter++,
    );
    uniqueOptionsConsidered.add(optionId);
    lastActivityTime = DateTime.now();
    if (firstActionTime == null) firstActionTime = lastActivityTime;
  }

  _OptionHover? endOptionHover(String optionId) {
    final hover = _currentHover;
    if (hover == null || hover.optionId != optionId) return null;
    _currentHover = null;
    optionHoverSequence.add(optionId);
    return hover;
  }

  void recordChange() {
    changeCount++;
    lastActivityTime = DateTime.now();
    if (firstActionTime == null) firstActionTime = lastActivityTime;
    if (firstSelectionTime == null) firstSelectionTime = lastActivityTime;
  }

  void recordBackground() {
    backgroundCount++;
    _backgroundStartTime = DateTime.now();
  }

  void recordForeground() {
    if (_backgroundStartTime != null) {
      totalBackgroundDuration += DateTime.now().difference(_backgroundStartTime!);
      _backgroundStartTime = null;
    }
  }
}

class _OptionHover {
  final String optionId;
  final int optionIndex;
  final DateTime startTime;
  final int sequence;

  Duration get duration => DateTime.now().difference(startTime);
}
```

```dart
class BatchReporter {
  final BehaviorBuffer _buffer;
  final ReportingConfig _config;
  final HttpClient _httpClient;

  Timer? _windowTimer;
  int _currentBatchSize = 0;

  BatchReporter(this._buffer, this._config, this._httpClient) {
    _startWindowTimer();
  }

  void _startWindowTimer() {
    _windowTimer?.cancel();
    _windowTimer = Timer.periodic(
      Duration(milliseconds: _config.timeWindowMs),
      (_) => _flush(),
    );
  }

  /// 外部触发：答案确认时
  Future<void> onAnswerConfirmed() async {
    if (_config.reportOnAnswerConfirmed) {
      await _flush();
    }
  }

  /// 外部触发：会话结束时
  Future<void> onSessionEnd() async {
    if (_config.reportOnSessionEnd) {
      _windowTimer?.cancel();
      await _flush();
    }
  }

  /// 外部触发：APP进入后台
  Future<void> onAppBackground() async {
    if (_config.reportOnAppBackground) {
      await _flush();
    }
  }

  Future<void> _flush() async {
    final events = await _buffer.getPendingEvents(
      limit: _config.maxBatchSize,
    );
    if (events.isEmpty) return;

    final payload = _buildPayload(events);
    final success = await _sendPayload(payload);

    if (success) {
      final ids = events.map((e) => e['eventId'] as String).toList();
      await _buffer.markReported(ids);
    }
  }

  Map<String, dynamic> _buildPayload(List<Map<String, dynamic>> events) {
    return {
      'batchId': '${DateTime.now().millisecondsSinceEpoch}-${Random().nextInt(9999)}',
      'events': events,
      'clientMeta': {
        'appId': 'com.primetop.app',
        'appVersion': '1.0.0',
        'platform': Platform.operatingSystem,
        'timestamp': DateTime.now().millisecondsSinceEpoch,
      },
    };
  }

  Future<bool> _sendPayload(Map<String, dynamic> payload) async {
    try {
      String body = jsonEncode(payload);

      // 可选压缩
      if (_config.compressionEnabled) {
        body = gzipEncode(body);
      }

      // 可选加密
      if (_config.encryptionEnabled) {
        body = aesEncrypt(body, _getEncryptionKey());
      }

      final response = await _httpClient.post(
        '/api/v1/behavior/batch',
        body: body,
        headers: {
          'Content-Type': 'application/json',
          'Content-Encoding': _config.compressionEnabled ? 'gzip' : 'identity',
        },
      );

      return response.statusCode == 200;
    } catch (e) {
      // 网络错误，不标记已上报，下次重试
      return false;
    }
  }

  String _getEncryptionKey() {
    // 从安全存储获取传输密钥
    // 该密钥在用户登录时由服务端下发，存储在 Keychain/Keystore
    return SecureStorage.get('behavior_transport_key');
  }
}
```

```java
@RestController
@RequestMapping("/api/v1/behavior")
public class BehaviorController {

    @Autowired
    private BehaviorIngestionService ingestionService;

    /**
     * 批量接收行为数据
     */
    @PostMapping("/batch")
    public ResponseEntity<ApiResponse<BatchResult>> receiveBatch(
            @RequestBody BehaviorBatchPayload payload,
            @RequestHeader("X-User-Id") Long userId) {

        // 1. 校验请求合法性
        validateBatch(payload, userId);

        // 2. 异步入库（不阻塞响应）
        ingestionService.ingestAsync(payload);

        // 3. 立即返回确认
        return ResponseEntity.ok(ApiResponse.success(
            new BatchResult(payload.getBatchId(), "accepted")
        ));
    }

    private void validateBatch(BehaviorBatchPayload payload, Long userId) {
        // 校验batchId唯一性（防重放）
        if (ingestionService.isBatchProcessed(payload.getBatchId())) {
            throw new BusinessException(BEHAVIOR_006, "重复的批次上报");
        }

        // 校验事件数不超限
        if (payload.getEvents().size() > 100) {
            throw new BusinessException(BEHAVIOR_007, "单批次事件数超限");
        }

        // 校验用户一致性
        for (var event : payload.getEvents()) {
            if (!event.getUserId().equals(userId.toString())) {
                throw new BusinessException(BEHAVIOR_008, "用户ID不一致");
            }
        }

        // 校验时间戳合理性（不允许未来时间，不允许超过7天前）
        long now = System.currentTimeMillis();
        for (var event : payload.getEvents()) {
            if (event.getTimestamp() > now + 60000) {
                throw new BusinessException(BEHAVIOR_009, "事件时间戳异常");
            }
            if (event.getTimestamp() < now - 7 * 86400000L) {
                throw new BusinessException(BEHAVIOR_010, "事件时间戳过期");
            }
        }
    }
}
```

### 5.4 实时特征计算服务

```java
@Service
public class BehaviorFeatureService {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Autowired
    private SessionBehaviorSummaryRepository summaryRepo;

    /**
     * 处理单题行为指标，更新会话汇总和实时特征
     */
    @KafkaListener(topics = "behavior-metrics", groupId = "realtime-feature")
    public void processMetrics(QuestionBehaviorMetrics metrics) {
        // 1. 更新会话汇总
        updateSessionSummary(metrics);

        // 2. 更新 Redis 实时特征（供自适应引擎查询）
        updateRealtimeFeatures(metrics);

        // 3. 检测异常行为模式
        detectAnomalies(metrics);
    }

    private void updateSessionSummary(QuestionBehaviorMetrics metrics) {
        SessionBehaviorSummary summary = summaryRepo
            .findBySessionId(metrics.getSessionId())
            .orElseGet(() -> createNewSummary(metrics));

        summary.setCompletedQuestions(summary.getCompletedQuestions() + 1);
        if (metrics.getIsCorrect()) {
            summary.setCorrectCount(summary.getCorrectCount() + 1);
        }

        // 重新计算平均指标
        int completed = summary.getCompletedQuestions();
        summary.setAvgDurationMs(
            (summary.getAvgDurationMs() * (completed - 1) + metrics.getTotalDuration()) / completed
        );
        summary.setAvgChanges(
            BigDecimal.valueOf(summary.getAvgChanges())
                .multiply(BigDecimal.valueOf(completed - 1))
                .add(BigDecimal.valueOf(metrics.getTotalChanges()))
                .divide(BigDecimal.valueOf(completed), 2, RoundingMode.HALF_UP)
                .doubleValue()
        );

        // 累计求助行为
        summary.setTotalHintsUsed(summary.getTotalHintsUsed() + metrics.getHintCount());
        summary.setTotalAiAsks(summary.getTotalAiAsks() + metrics.getAiAskedCount());

        // 计算综合评分
        summary.setEngagementScore(calculateEngagementScore(summary));
        summary.setConfidenceScore(calculateConfidenceScore(summary));
        summary.setPersistenceScore(calculatePersistenceScore(summary));
        summary.setHelpSeekingRate(
            (double) (summary.getTotalHintsUsed() + summary.getTotalAiAsks()) / completed
        );

        // 分析答题节奏
        summary.setPacePattern(analyzePacePattern(metrics.getSessionId()));

        summaryRepo.save(summary);
    }

    /**
     * 计算投入度评分
     * 考虑因素：停顿次数、后台切换、答题时长偏离均值
     */
    private BigDecimal calculateEngagementScore(SessionBehaviorSummary summary) {
        double score = 1.0;

        // 后台切换扣分
        double avgBackgroundPerQuestion = summary.getTotalDurationMs() > 0
            ? (double) summary.getCompletedQuestions() / Math.max(1, summary.getTotalDurationMs() / 60000.0)
            : 0;
        score -= Math.min(0.3, avgBackgroundPerQuestion * 0.1);

        // 极短答题扣分（<5秒/题 = 猜题）
        // 极长答题扣分（>5分钟/题 = 分心）
        double avgDurationSec = summary.getAvgDurationMs() / 1000.0;
        if (avgDurationSec < 5) {
            score -= 0.2;
        } else if (avgDurationSec > 300) {
            score -= 0.15;
        }

        // 变更次数适中加分（说明在认真思考）
        if (summary.getAvgChanges() >= 0.5 && summary.getAvgChanges() <= 2.0) {
            score += 0.1;
        }

        return BigDecimal.valueOf(Math.max(0, Math.min(1, score)))
            .setScale(4, RoundingMode.HALF_UP);
    }

    /**
     * 分析答题节奏模式
     */
    private String analyzePacePattern(String sessionId) {
        // 获取最近题目序列的答题时长
        List<Integer> durations = getRecentDurations(sessionId, 10);
        if (durations.size() < 3) return "steady";

        // 计算趋势
        double slope = linearRegressionSlope(durations);
        double variance = coefficientOfVariation(durations);

        if (Math.abs(slope) < 0.1 && variance < 0.3) return "steady";
        if (slope > 0.1) return "decelerating";  // 越做越慢 → 可能疲劳
        if (slope < -0.1) return "accelerating";  // 越做越快 → 可能着急/掌握良好
        return "irregular";                        // 不规律
    }

    /**
     * 更新 Redis 实时特征（供自适应引擎低延迟查询）
     */
    private void updateRealtimeFeatures(QuestionBehaviorMetrics metrics) {
        String key = "behavior:realtime:" + metrics.getUserId();

        Map<String, Object> features = Map.of(
            "lastDuration", metrics.getTotalDuration(),
            "lastEngagement", metrics.getInferredEngagement(),
            "lastConfidence", metrics.getInferredConfidence(),
            "lastStrategy", metrics.getInferredStrategy(),
            "lastChanges", metrics.getTotalChanges(),
            "timestamp", System.currentTimeMillis()
        );

        redisTemplate.opsForHash().putAll(key, features);
        redisTemplate.expire(key, Duration.ofHours(24));
    }
}
```

```java
@Service
public class BehaviorCorrectionService {

    /**
     * 校正行为推断维度
     * 使用历史基线 + 当前会话上下文 + 答题结果
     */
    public CorrectedBehavior correct(QuestionBehaviorMetrics metrics, UserBehaviorBaseline baseline) {
        CorrectedBehavior result = new CorrectedBehavior();

        // --- 投入度校正 ---
        String engagement = metrics.getInferredEngagement();

        // 基线对比：如果用户平均停顿次数就高（可能是有思考习惯），不扣分
        double pauseRatio = (double) metrics.getPauseCount() /
            Math.max(1, metrics.getTotalDuration() / 30000.0);
        if (pauseRatio > baseline.getAvgPauseRatio() * 1.5) {
            // 停顿显著高于个人基线 → 可能分心
            engagement = downgrade(engagement);
        }

        // 答题时长对比基线：该题难度下的预期时长
        double expectedDuration = baseline.getExpectedDuration(
            metrics.getQuestionId(), metrics.isCorrect());
        double durationRatio = (double) metrics.getTotalDuration() / expectedDuration;
        if (durationRatio < 0.3 && !"high".equals(engagement)) {
            // 远短于预期 → 可能没认真看题
            engagement = "low";
        }

        result.setEngagement(engagement);

        // --- 信心校正 ---
        String confidence = metrics.getInferredConfidence();

        // 结合答题结果：高信心但答错 → 过度自信；低信心但答对 → 不自信
        if ("high".equals(confidence) && !metrics.isCorrect()
                && metrics.getTotalChanges() == 0 && metrics.getHintCount() == 0) {
            confidence = "overconfident";  // 特殊标记：过度自信
        } else if ("low".equals(confidence) && metrics.isCorrect()
                && metrics.getTotalDuration() < expectedDuration * 0.8) {
            confidence = "underconfident"; // 特殊标记：不自信但实际掌握
        }

        result.setConfidence(confidence);

        // --- 策略校正 ---
        String strategy = metrics.getInferredStrategy();

        // 结合选项悬停序列和最终选择
        if ("elimination".equals(strategy) && metrics.getTotalChanges() == 0) {
            // 声称排除法但从未修改 → 可能是随机选的
            strategy = "random";
        }
        if ("systematic".equals(strategy) && metrics.isCorrect()
                && metrics.getTotalDuration() < expectedDuration * 0.5) {
            // 系统计算但远快于预期 → 可能是记住答案了
            strategy = "recall";  // 特殊标记：记忆回忆
        }

        result.setStrategy(strategy);
        return result;
    }

    private String downgrade(String level) {
        return switch (level) {
            case "high" -> "medium";
            case "medium" -> "low";
            default -> level;
        };
    }
}

@Data
class CorrectedBehavior {
    private String engagement;    // high/medium/low
    private String confidence;    // high/medium/low/overconfident/underconfident
    private String strategy;      // systematic/random/elimination/guess/recall
}
```

## 7. 错误处理

### 7.1 客户端错误处理

| 场景 | 处理策略 |
|------|----------|
| 缓冲区满（>10000条未上报） | 丢弃最旧的非关键事件，保留 question_entered 和 answer_confirmed |
| SQLite 写入失败 | 降级为纯内存模式，APP重启后丢失 |
| 上报失败（网络错误） | 指数退避重试，最多5次 |
| 上报失败（服务端错误） | 标记 retryCount+1，超限后丢弃 |
| APP 崩溃恢复 | 启动时扫描未上报事件，自动重新上报 |
| 设备时钟回拨 | 检测 timestamp < lastTimestamp，使用 serverTime 校正 |

### 7.2 服务端错误处理

| 场景 | 处理策略 |
|------|----------|
| 重复 batchId | 返回已接受状态，不重复处理 |
| 事件数超限（>100） | 拒绝整个批次，返回具体错误 |
| 用户ID不一致 | 拒绝，记录安全日志 |
| 时间戳异常 | 拒绝未来时间，接受过期时间但标记为延迟上报 |
| Kafka 发送失败 | 本地暂存，定时重试 |
| 数据库写入失败 | 降级写入 Redis 缓冲，后续补录 |
| 聚合计算失败 | 记录原始事件，标记 metrics 为 pending |

### 7.3 错误码

| 错误码 | HTTP状态 | 含义 |
|--------|----------|------|
| BEHAVIOR_001 | 400 | 请求体格式错误 |
| BEHAVIOR_002 | 400 | eventType 不合法 |
| BEHAVIOR_003 | 400 | sessionId 不存在 |
| BEHAVIOR_004 | 403 | 无权上报该用户数据 |
| BEHAVIOR_005 | 429 | 上报频率超限（>60次/分钟） |
| BEHAVIOR_006 | 409 | 重复的批次ID |
| BEHAVIOR_007 | 400 | 单批次事件数超限（>100） |
| BEHAVIOR_008 | 403 | 用户ID与token不一致 |
| BEHAVIOR_009 | 400 | 事件时间戳在未来 |
| BEHAVIOR_010 | 400 | 事件时间戳过期（>7天） |
| BEHAVIOR_011 | 500 | 内部处理异常 |
| BEHAVIOR_012 | 503 | 服务暂时不可用 |

## 8. 隐私与安全

### 8.1 数据最小化原则

| 采集项 | 是否采集 | 理由 |
|--------|----------|------|
| 答题时长 | ✅ | 核心行为指标 |
| 答案变更轨迹 | ✅ | 用于区分粗心/概念错误 |
| 选项悬停 | ✅ | 分析排除法策略 |
| 草稿笔画数 | ✅ | 分析思考深度 |
| 草稿内容 | ❌ | 可能含敏感信息 |
| 输入法内容 | ❌ | 隐私敏感 |
| 截屏行为 | ❌ | 不必要 |
| 剪贴板内容 | ❌ | 隐私敏感 |
| 位置信息 | ❌ | 与学习无关 |
| 通讯录 | ❌ | 隐私敏感 |

### 8.2 数据传输安全

1. **传输加密**：所有上报数据使用 HTTPS + 应用层 AES-256 加密
2. **密钥管理**：传输密钥由服务端在登录时下发，存储在系统 Keychain/Keystore
3. **数据脱敏**：metadata 中的 answer 字段仅存储选项标识（A/B/C/D），不存储文本内容

### 8.3 数据保留策略

| 数据类型 | 保留期限 | 到期处理 |
|----------|----------|----------|
| 行为事件明细 | 90天 | 聚合后删除明细 |
| 聚合指标 | 2年 | 归档到冷存储 |
| 会话汇总 | 2年 | 归档到冷存储 |
| 用户行为画像 | 账号存续期 | 账号注销后30天删除 |

### 8.4 用户知情与控制

1. 首次使用时展示《学习行为数据采集说明》，用户明确同意后启用
2. 设置页面提供"学习行为数据采集"开关，关闭后仅采集基础答题结果
3. 用户可查看自己的行为数据摘要（在学情报告中体现）
4. 账号注销时彻底删除所有行为数据

```java
public class AdaptiveQuestionSelector {

    @Autowired
    private BehaviorFeatureProvider behaviorProvider;

    public Question selectNext(Long userId, String sessionId, AdaptiveContext ctx) {
        RealtimeBehaviorFeatures features = behaviorProvider.getRealtimeFeatures(userId);

        // 规则1：投入度低 → 降低难度，选择更有趣的题型
        if ("low".equals(features.getEngagement())) {
            return selectEasierVisualQuestion(ctx);
        }

        // 规则2：信心低+已连续答错3题 → 插入一道简单题恢复信心

                && ctx.getConsecutiveWrongCount() >= 3) {
            return selectConfidenceBooster(ctx);
        }

        // 规则3：猜测率高 → 选择需要展示过程的题型
        if (features.getRecentGuessRate() > 0.3) {
            return selectProcessRequiredQuestion(ctx);
        }

        // 规则4：疲劳检测（答题节奏持续变慢）
        if ("decelerating".equals(features.getPacePattern())) {
            return suggestBreakOrEndSession();
        }

        // 正常选题流程
        return selectByStandardAlgorithm(ctx);
    }
```

### 9.4 与错题整理集成

行为数据帮助判断错因：

```java
@Service
public class MistakeCauseAnalyzer {

    /**
     * 结合行为数据判断错因
     */
    public MistakeDiagnosis diagnose(QuestionBehaviorMetrics metrics) {
        if (!metrics.getIsCorrect()) {
            // 猜测答错
            if ("guess".equals(metrics.getCorrectedStrategy())
                    && metrics.getTotalDuration() < 10000) {
                return new MistakeDiagnosis(
                    "random_guess",
                    "未认真审题就猜测答案",
                    "建议重新审题后独立作答"
                );
            }

            // 犹豫后答错 → 概念模糊
            if (metrics.getTotalChanges() >= 2
                    && metrics.getTotalDuration() > 60000) {
                return new MistakeDiagnosis(
                    "concept_confusion",
                    "在多个选项间犹豫，概念理解模糊",
                    "建议复习相关知识点，理清概念区别"
                );
            }

            // 求助后仍答错 → 知识盲区
            if (metrics.getHintCount() > 0 || metrics.getAiAsked()) {
                return new MistakeDiagnosis(
                    "knowledge_gap",
                    "使用提示/AI辅导后仍答错，存在知识盲区",
                    "建议从基础概念重新学习"
                );
            }

            // 快速作答但答错 → 粗心
            if (metrics.getTotalDuration() < 15000
                    && metrics.getTotalChanges() == 0) {
                return new MistakeDiagnosis(
                    "careless",
                    "快速作答但审题不仔细",
                    "建议认真读题，注意关键词和条件"
                );
            }
        }

        // 默认
        return new MistakeDiagnosis("unknown", "需要进一步分析", "");
    }
}
```

## 12. 监控与告警

### 12.1 关键监控指标

| 指标 | 告警阈值 | 说明 |
|------|----------|------|
| 上报成功率 | < 99% | 可能网络或服务端问题 |
| 事件丢失率 | > 0.1% | 客户端缓冲溢出 |
| 平均批次大小 | > 80 | 可能上报不及时 |
| Kafka 消费延迟 | > 60s | 影响实时特征计算 |
| 行为校正失败率 | > 1% | 影响分析准确性 |
| 异常行为检测率 | > 20% | 可能存在刷题/作弊 |

### 12.2 运营看板

1. **实时大屏**：当前在线用户的平均投入度、答题节奏分布
2. **日报**：各学段的行为特征分布、异常行为统计
3. **周报**：行为数据质量报告、采集覆盖率、上报延迟分布
