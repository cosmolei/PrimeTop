# 服务端 - 数据质量监控与异常数据自动检测修复引擎 详细设计

## 1. 模块概述

### 1.1 背景

PrimeTop 平台在运营过程中会产生海量学习行为数据，涵盖答题记录、错题记录、学习时长、知识点掌握度、AI 对话日志、学情报告等。这些数据直接驱动个性化推荐、学情分析、学习规划和运营决策。

当前系统虽已有数据血缘追踪和元数据治理（见 `数据血缘追踪与元数据治理平台-详细设计.md`），但缺少**主动式的数据质量监控与自修复能力**。数据质量问题（如字段缺失、数值越界、重复记录、跨服务不一致、ETT 延迟等）若未及时发现和处理，将导致：

- 学情报告数据偏差，误导家长和学生
- 知识点掌握度计算错误，推荐不相关内容
- 会员权益校验异常，影响用户体验
- 运营决策基于错误数据

本模块负责建立**全链路数据质量监控、异常检测、告警通知与自动修复**体系。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 实时感知 | 对核心数据表的关键字段进行秒级~分钟级质量巡检 |
| 自动诊断 | 基于规则引擎 + 统计模型自动识别异常数据 |
| 自动修复 | 对可安全修复的异常执行自动修复（如去重、补默认值、回填关联字段） |
| 告警触达 | 对不可自动修复的异常按严重级别触发告警 |
| 全程可追溯 | 所有检测、修复操作记录审计日志，支持回滚 |
| 低侵入 | 以旁路方式运行，不影响业务主流程性能 |

## 2. 核心概念定义

### 2.1 数据质量维度

| 维度 | 缩写 | 定义 | 示例 |
| --- | --- | --- | --- |
| 完整性 | COMPLETENESS | 必填字段非空率 | `AnswerRecord.user_id` 不应为 NULL |
| 准确性 | ACCURACY | 数据值在合理范围内 | 答题正确率应在 0~1 之间 |
| 一致性 | CONSISTENCY | 跨表/跨服务数据吻合 | 错题总数 = 各学科错题数之和 |
| 时效性 | TIMELINESS | 数据按时产生且无积压 | 答题记录在提交后 30s 内入库 |
| 唯一性 | UNIQUENESS | 无重复记录 | 同一题目同一会话不重复入库 |
| 合规性 | CONFORMANCE | 数据格式与类型符合 Schema | 手机号格式、学段编码合法 |
| 关联性 | REFERENTIAL | 外键引用有效 | `AnswerRecord.question_id` 在题库中存在 |

### 2.2 严重级别

| 级别 | 标识 | 含义 | 响应时效 |
| --- | --- | --- | --- |
| P0-CRITICAL | 🔴 | 核心业务数据大面积异常，影响用户使用 | 立即告警，5min 内响应 |
| P1-HIGH | 🟠 | 重要数据异常，影响部分功能准确性 | 30min 内响应 |
| P2-MEDIUM | 🟡 | 一般数据异常，不影响核心功能 | 当日处理 |
| P3-LOW | 🟢 | 轻微数据瑕疵，记录待后续治理 | 周度汇总 |

## 4. 规则引擎设计

### 4.1 规则类型体系

```
QualityRule (接口)
├── TableScanRule          — 表级扫描规则（SQL查询检测）
├── TopicMonitorRule       — Kafka Topic实时监控规则
├── CrossServiceCheckRule  — 跨服务数据一致性检查规则
├── StatisticalRule        — 统计学异常检测规则（3σ/Z-Score/IQR）
├── ReferentialRule        — 外键引用完整性检查规则
├── TimelinessRule         — 数据时效性检查规则
└── CompositeRule          — 组合规则（AND/OR组合多个子规则）
```

### 4.2 规则定义示例（Java 风格）

```java
/**
 * 数据质量规则接口
 */
public interface QualityRule {

    /**
     * 执行检测
     * @param context 检测上下文（含数据源连接、参数、时间窗口）
     * @return 检测结果
     */
    QualityCheckResult check(CheckContext context);

    /**
     * 规则元信息
     */
    RuleMeta getMeta();
}

/**
 * 表级扫描规则 — 通过SQL查询检测表中的异常数据
 */
@RuleMeta(
    code = "COMPLETENESS_ANSWER_USER_ID",
    name = "答题记录用户ID完整性检查",
    dimension = Dimension.COMPLETENESS,
    severity = Severity.P1_HIGH,
    frequency = Frequency.HOURLY
)
public class AnswerRecordUserIdCompletenessRule implements QualityRule {

    @Override
    public QualityCheckResult check(CheckContext ctx) {
        String sql = """
            SELECT
                COUNT(*) AS total_count,
                SUM(CASE WHEN user_id IS NULL OR user_id = 0 THEN 1 ELSE 0 END) AS anomaly_count
            FROM answer_record
            WHERE created_at BETWEEN ? AND ?
            """;

        Map<String, Object> row = ctx.jdbcTemplate().queryForMap(sql,
            ctx.windowStart(), ctx.windowEnd());

        long total = ((Number) row.get("total_count")).longValue();
        long anomaly = ((Number) row.get("anomaly_count")).longValue();
        double completenessRatio = total == 0 ? 1.0 : (double) (total - anomaly) / total;

        return QualityCheckResult.builder()
            .ruleCode(getMeta().code())
            .totalCount(total)
            .anomalyCount(anomaly)
            .anomalyRatio(total == 0 ? 0 : (double) anomaly / total)
            .metricValue(completenessRatio)
            .status(determineStatus(completenessRatio, ctx.thresholds()))
            .build();
    }
}

/**
 * 统计学异常检测规则 — 基于 Z-Score 检测指标突变
 */
@RuleMeta(
    code = "STATS_LEARNING_DURATION_ANOMALY",
    name = "学习时长突变异常检测",
    dimension = Dimension.ACCURACY,
    severity = Severity.P2_MEDIUM,
    frequency = Frequency.HOURLY
)
public class LearningDurationAnomalyRule implements QualityRule {

    private static final double Z_SCORE_THRESHOLD = 3.0; // 3σ

    @Override
    public QualityCheckResult check(CheckContext ctx) {
        // 获取过去7天同时段的学习时长均值和标准差
        String baselineSql = """
            SELECT
                AVG(daily_duration) AS mean,
                STDDEV(daily_duration) AS stddev
            FROM (
                SELECT DATE(created_at) AS dt, SUM(duration_sec) AS daily_duration
                FROM learning_session
                WHERE created_at >= DATE_SUB(NOW(), INTERVAL 7 DAY)
                  AND created_at < CURDATE()
                GROUP BY DATE(created_at)
            ) t
            """;

        Map<String, Object> baseline = ctx.jdbcTemplate().queryForMap(baselineSql);
        double mean = ((Number) baseline.get("mean")).doubleValue();
        double stddev = baseline.get("stddev") == null ? 0
            : ((Number) baseline.get("stddev")).doubleValue();

        // 今日当前时段学习时长
        String todaySql = """
            SELECT SUM(duration_sec) AS today_duration
            FROM learning_session
            WHERE created_at >= CURDATE()
              AND created_at < DATE_ADD(CURDATE(), INTERVAL 1 HOUR)
            """;

        Double todayDuration = ctx.jdbcTemplate().queryForObject(todaySql, Double.class);
        if (todayDuration == null) return QualityCheckResult.normal(ctx);

        double zScore = stddev == 0 ? 0 : Math.abs((todayDuration - mean) / stddev);
        boolean isAnomaly = zScore > Z_SCORE_THRESHOLD;

        return QualityCheckResult.builder()
            .ruleCode(getMeta().code())
            .metricValue(zScore)
            .thresholdValue(Z_SCORE_THRESHOLD)
            .status(isAnomaly ? CheckStatus.WARNING : CheckStatus.SUCCESS)
            .anomalySample(Map.of(
                "today_duration", todayDuration,
                "baseline_mean", mean,
                "baseline_stddev", stddev,
                "z_score", zScore
            ))
            .build();
    }
}

/**
 * 跨服务一致性检查规则
 */
@RuleMeta(
    code = "CONSISTENCY_MISTAKE_COUNT_CROSS_SERVICE",
    name = "错题总数跨服务一致性检查",
    dimension = Dimension.CONSISTENCY,
    severity = Severity.P1_HIGH,
    frequency = Frequency.HOURLY
)
public class MistakeCountConsistencyRule implements QualityRule {

    @Override
    public QualityCheckResult check(CheckContext ctx) {
        // 从错题服务统计
        Long mistakeSvcCount = ctx.serviceClient()
            .getForObject("/internal/mistakes/count?date={date}", Long.class,
                Map.of("date", LocalDate.now().toString()));

        // 从学情分析服务统计
        Long analyticsSvcCount = ctx.serviceClient()
            .getForObject("/internal/analytics/mistake-total?date={date}", Long.class,
                Map.of("date", LocalDate.now().toString()));

        long diff = Math.abs(
            (mistakeSvcCount != null ? mistakeSvcCount : 0)
            - (analyticsSvcCount != null ? analyticsSvcCount : 0)
        );

        double consistencyRatio = mistakeSvcCount == null || mistakeSvcCount == 0 ? 1.0
            : (double) (mistakeSvcCount - diff) / mistakeSvcCount;

        return QualityCheckResult.builder()
            .ruleCode(getMeta().code())
            .metricValue(consistencyRatio)
            .status(determineStatus(consistencyRatio, ctx.thresholds()))
            .anomalyCount(diff)
            .anomalySample(Map.of(
                "mistake_service_count", mistakeSvcCount,
                "analytics_service_count", analyticsSvcCount,
                "difference", diff
            ))
            .build();
    }
}
```

### 4.3 检测调度器

```java
/**
 * 数据质量检测调度器
 * 负责按频率调度规则检测任务
 */
@Component
public class QualityCheckScheduler {

    @Autowired private QualityRuleRegistry ruleRegistry;
    @Autowired private QualityCheckExecutor executor;
    @Autowired private DqCheckLogService checkLogService;
    @Autowired private AlertService alertService;

    /**
     * 实时检测（每30秒）— 处理REALTIME类型规则
     */
    @Scheduled(fixedDelay = 30_000)
    public void scheduleRealtimeChecks() {
        List<QualityRule> rules = ruleRegistry.getRulesByFrequency(Frequency.REALTIME);
        if (rules.isEmpty()) return;

        String batchId = generateBatchId("REALTIME");
        rules.forEach(rule -> executor.executeAsync(rule, batchId));
    }

    /**
     * 5分钟检测
     */
    @Scheduled(fixedDelay = 300_000)
    public void schedule5MinChecks() {
        List<QualityRule> rules = ruleRegistry.getRulesByFrequency(Frequency.FIVE_MIN);
        String batchId = generateBatchId("5MIN");
        rules.forEach(rule -> executor.executeAsync(rule, batchId));
    }

    /**
     * 整点检测
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void scheduleHourlyChecks() {
        List<QualityRule> rules = ruleRegistry.getRulesByFrequency(Frequency.HOURLY);
        String batchId = generateBatchId("HOURLY");
        rules.forEach(rule -> executor.executeAsync(rule, batchId));
    }

    /**
     * 每日凌晨2点全量检测
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void scheduleDailyChecks() {
        List<QualityRule> rules = ruleRegistry.getRulesByFrequency(Frequency.DAILY);
        String batchId = generateBatchId("DAILY");
        rules.forEach(rule -> executor.executeAsync(rule, batchId));

        // 每日检测后计算质量评分
        executor.afterCompletion(batchId, () -> {
            scoreCalculator.calculateDailyScore(LocalDate.now().minusDays(1));
        });
    }
}
```

```java
     * @return 修复结果

    RepairResult repair(RepairContext context);

    /**
     * 是否安全可自动执行（无需人工审批）

     * 创建回滚数据备份
```

| 策略代码 | 说明 | 适用场景 | 安全级别 |
| --- | --- | --- | --- |
| `FILL_DEFAULT` | 补充默认值 | 字段为NULL但应有默认值 | ✅ 安全 |

| `SYNC_CROSS_SERVICE` | 跨服务数据同步修复 | 跨服务数据不一致 | ⚠️ 需审核 |
| `TRUNCATE_STALE` | 清理过期脏数据 | 超期临时数据、无效快照 | ⚠️ 需审核 |
| `CORRECT_ENUM` | 枚举值纠正 | 非法枚举值映射为合法值 | ✅ 安全 |

```java
/**
 * 默认值补充策略
 */
@Component
public class FillDefaultRepairStrategy implements RepairStrategy {

    @Override
    public String getCode() { return "FILL_DEFAULT"; }

    @Override
    public boolean isAutoSafe() { return true; }

    @Override
    public String createRollupBackup(RepairContext ctx) {
        String backupTable = "backup_" + ctx.getTargetTable() + "_"
            + LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMddHHmmss"));

        String backupSql = """
            CREATE TABLE %s AS
            SELECT * FROM %s
            WHERE id IN (%s)
            """.formatted(backupTable, ctx.getTargetTable(),
                ctx.getAnomalyIds().stream()
                    .map(String::valueOf)
                    .collect(Collectors.joining(",")));

        ctx.jdbcTemplate().execute(backupSql);
        return backupTable;
    }

    @Override
    public RepairResult repair(RepairContext ctx) {
        String targetTable = ctx.getTargetTable();
        String targetColumn = (String) ctx.getParams().get("target_column");
        Object defaultValue = ctx.getParams().get("default_value");

        // 1. 创建备份
        String backupTable = createRollupBackup(ctx);

        // 2. 执行修复
        String repairSql = """
            UPDATE %s
            SET %s = ?, updated_at = NOW()
            WHERE id IN (%s) AND (%s IS NULL OR %s = '')
            """.formatted(targetTable, targetColumn,
                ctx.getAnomalyIds().stream().map(String::valueOf)
                    .collect(Collectors.joining(",")),
                targetColumn, targetColumn);

        int affected = ctx.jdbcTemplate().update(repairSql, defaultValue);

        return RepairResult.builder()
            .strategy(getCode())
            .targetTable(targetTable)
            .affectedCount(affected)
            .repairedCount(affected)
            .rollbackTable(backupTable)
            .status(RepairStatus.SUCCESS)
            .build();
    }
}

/**
 * 重新计算汇总值策略 — 用于修复统计表与明细不一致

@Component
public class RecomputeAggregateRepairStrategy implements RepairStrategy {

    @Override
    public String getCode() { return "RECOMPUTE_AGGREGATE"; }

    @Override
    public boolean isAutoSafe() { return true; }

    @Override
    public RepairResult repair(RepairContext ctx) {
        String aggregateTable = ctx.getTargetTable();
        String sourceTable = (String) ctx.getParams().get("source_table");
        String groupKey = (String) ctx.getParams().get("group_key");     // 如 user_id
        String sumColumn = (String) ctx.getParams().get("sum_column");   // 如 total_count

        // 1. 备份
        String backupTable = createRollupBackup(ctx);

        // 2. 使用 JOIN 重算并更新
        String repairSql = """
            UPDATE %s agg
            INNER JOIN (
                SELECT %s AS key, COUNT(*) AS cnt
                FROM %s
                WHERE deleted_at IS NULL
                GROUP BY %s
            ) src ON agg.%s = src.key
            SET agg.%s = src.cnt, agg.updated_at = NOW()
            WHERE DATE(agg.stat_date) = ?
            """.formatted(
                aggregateTable, groupKey, sourceTable, groupKey,
                groupKey, sumColumn
            );

        int affected = ctx.jdbcTemplate().update(repairSql, ctx.getWindowDate());

        return RepairResult.builder()
            .strategy(getCode())
            .targetTable(aggregateTable)
            .affectedCount(affected)
            .repairedCount(affected)
            .rollbackTable(backupTable)
            .status(RepairStatus.SUCCESS)
            .build();
    }
}
```

### 5.4 修复执行编排

```java
/**
 * 修复执行编排器
 */
@Service
public class RepairOrchestrator {

    @Autowired private Map<String, RepairStrategy> strategyMap;
    @Autowired private DqRepairLogService repairLogService;
    @Autowired private AlertService alertService;
    @Autowired private RepairApprovalService approvalService;

    private static final int MAX_AUTO_REPAIR_PER_RUN = 5000;

    /**
     * 处理检测结果，触发修复或告警
     */
    public void handleCheckResult(QualityCheckResult result, DqRule rule) {
        if (result.getStatus() == CheckStatus.SUCCESS) return;

        // 检查是否启用自动修复
        if (rule.getAutoRepairEnabled() == 1) {
            RepairStrategy strategy = strategyMap.get(rule.getRepairStrategy());

            if (strategy != null && strategy.isAutoSafe()) {
                executeAutoRepair(result, rule, strategy);
            } else if (strategy != null && !strategy.isAutoSafe()) {
                // 需要人工审批的修复
                requestManualApproval(result, rule, strategy);
            } else {
                // 无修复策略，触发告警
                alertService.createAlert(result, rule);
            }
        } else {
            // 未启用自动修复，触发告警
            alertService.createAlert(result, rule);
        }
    }

    /**
     * 执行自动修复
     */
    private void executeAutoRepair(QualityCheckResult result, DqRule rule,
                                    RepairStrategy strategy) {
        // 查询异常数据ID
        List<Long> anomalyIds = anomalyQueryService.queryAnomalyIds(result, rule);
        if (anomalyIds.isEmpty()) return;

        // 分批执行，避免大事务
        int batchSize = 500;
        String repairBatchId = generateRepairBatchId();

        for (int i = 0; i < anomalyIds.size() && i < MAX_AUTO_REPAIR_PER_RUN;
             i += batchSize) {
            List<Long> batch = anomalyIds.subList(i,
                Math.min(i + batchSize, anomalyIds.size()));

            RepairContext ctx = RepairContext.builder()
                .targetTable(rule.getTargetTable())
                .anomalyIds(batch)
                .params(rule.getRepairParams())
                .build();

            try {
                RepairResult repairResult = strategy.repair(ctx);
                repairResult.setRepairBatchId(repairBatchId);
                repairLogService.save(repairResult, rule);

            } catch (Exception e) {
                log.error("自动修复失败 rule={}, batch={}", rule.getRuleCode(),
                    repairBatchId, e);
                // 修复失败转为告警
                alertService.createRepairFailedAlert(result, rule, e.getMessage());
            }
        }

        // 修复后重检
        recheckAfterRepair(rule);
    }

    /**
     * 请求人工审批修复
     */
    private void requestManualApproval(QualityCheckResult result, DqRule rule,
                                        RepairStrategy strategy) {
        RepairApproval approval = RepairApproval.builder()
            .ruleCode(rule.getRuleCode())
            .repairStrategy(strategy.getCode())
            .severity(rule.getSeverity())
            .anomalyCount(result.getAnomalyCount())
            .anomalySample(result.getAnomalySample())
            .description("规则[" + rule.getRuleName() + "]检测到"
                + result.getAnomalyCount() + "条异常数据，需要人工审批修复")
            .status(ApprovalStatus.PENDING)
            .build();

        approvalService.createApproval(approval);
        // 同时创建P1告警
        alertService.createAlert(result, rule);
    }
}
```

```java
@Component
public class ConsumerLagTimelinessRule implements QualityRule {

    @Override
    public QualityCheckResult check(CheckContext ctx) {
        String topic = ctx.getParam("topic");      // 如 "answer-record-event"
        String consumerGroup = ctx.getParam("group"); // 如 "analytics-consumer"

        // 获取Kafka消费者组的lag
        Map<TopicPartition, Long> lags = ctx.kafkaAdmin()
            .getConsumerGroupLag(consumerGroup);

        long totalLag = lags.values().stream().mapToLong(Long::longValue).sum();
        long maxPartitionLag = lags.values().stream().max(Long::compare).orElse(0L);

        // lag > 10000 认为有时效性问题
        long threshold = ctx.getThreshold("max_lag", 10000L);
        boolean isAnomaly = totalLag > threshold;

        return QualityCheckResult.builder()
            .ruleCode(getMeta().code())
            .metricValue((double) totalLag)
            .thresholdValue((double) threshold)
            .status(isAnomaly ? CheckStatus.WARNING : CheckStatus.SUCCESS)
            .anomalyCount(isAnomaly ? totalLag : 0)
            .anomalySample(Map.of(
                "topic", topic,
                "consumer_group", consumerGroup,
                "total_lag", totalLag,
                "max_partition_lag", maxPartitionLag
            ))
            .build();
    }
}
```

## 7. 质量评分模型

### 7.1 评分算法

综合质量得分采用加权平均模型，不同数据域的维度权重可配置：

```java
/**
 * 数据质量评分计算器
 */
@Service
public class QualityScoreCalculator {

    // 各数据域默认权重
    private static final Map<String, Map<Dimension, Double>> DOMAIN_WEIGHTS = Map.of(
        "USER", Map.of(
            Dimension.COMPLETENESS, 0.30,
            Dimension.ACCURACY, 0.20,
            Dimension.CONSISTENCY, 0.15,
            Dimension.CONFORMANCE, 0.20,
            Dimension.UNIQUENESS, 0.15
        ),
        "LEARNING", Map.of(
            Dimension.COMPLETENESS, 0.25,
            Dimension.ACCURACY, 0.25,
            Dimension.CONSISTENCY, 0.20,
            Dimension.TIMELINESS, 0.15,
            Dimension.UNIQUENESS, 0.15
        ),
        "PAYMENT", Map.of(
            Dimension.COMPLETENESS, 0.25,
            Dimension.ACCURACY, 0.25,
            Dimension.CONSISTENCY, 0.30,
            Dimension.TIMELINESS, 0.20
        )
    );

    /**
     * 计算指定数据域在指定日期的质量评分
     */
    public DqScore calculate(String dataDomain, LocalDate scoreDate) {
        Map<Dimension, Double> weights = DOMAIN_WEIGHTS.getOrDefault(dataDomain,
            DOMAIN_WEIGHTS.get("LEARNING"));

        Map<Dimension, Double> dimensionScores = new EnumMap<>(Dimension.class);
        for (Dimension dim : weights.keySet()) {
            double score = calculateDimensionScore(dataDomain, dim, scoreDate);
            dimensionScores.put(dim, score);
        }

        double overall = dimensionScores.entrySet().stream()
            .mapToDouble(e -> e.getValue() * weights.getOrDefault(e.getKey(), 0.0))
            .sum();

        // 获取昨日得分计算趋势
        BigDecimal previous = scoreService.getPreviousScore(dataDomain, scoreDate);
        String trend = determineTrend(overall, previous.doubleValue());

        return DqScore.builder()
            .scoreDate(scoreDate)
            .dataDomain(dataDomain)
            .scores(dimensionScores)
            .overallScore(round4(overall))
            .trend(trend)
            .previousScore(previous)
            .weightConfig(weights)
            .build();
    }

    /**
     * 计算单个维度的得分（0~1）
     * 取该维度下所有规则检测结果的加权平均
     */
    private double calculateDimensionScore(String domain, Dimension dim, LocalDate date) {
        List<DqCheckLog> logs = checkLogService.findByDomainAndDimensionAndDate(
            domain, dim, date);

        if (logs.isEmpty()) return 1.0; // 无规则则满分

        double weightedSum = 0;
        double totalWeight = 0;
        for (DqCheckLog log : logs) {
            double severityWeight = switch (log.getSeverity()) {
                case P0_CRITICAL -> 4.0;
                case P1_HIGH -> 3.0;
                case P2_MEDIUM -> 2.0;
                case P3_LOW -> 1.0;
            };
            double ruleScore = log.getMetricValue(); // 检测指标值即为得分
            weightedSum += ruleScore * severityWeight;
            totalWeight += severityWeight;
        }

        return totalWeight == 0 ? 1.0 : weightedSum / totalWeight;
    }
}
```

```java
public enum DataDomain {
```

## 12. 时序数据存储（ClickHouse）

### 12.1 质量指标时序表

```sql
-- ClickHouse DDL
CREATE TABLE dq_metrics_time_series (
    `timestamp`    DateTime64(3) CODEC(Delta, ZSTD),
    `rule_code`    LowCardinality(String),
    `data_domain`  LowCardinality(String),
    `target_table` LowCardinality(String),
    `dimension`    LowCardinality(String),
    `severity`     LowCardinality(String),
    `metric_value` Float64,
    `threshold_value` Float64,
    `total_count`  UInt64,
    `anomaly_count` UInt64,
    `anomaly_ratio` Float64,
    `check_status` LowCardinality(String),
    `check_node`   LowCardinality(String),
    `date`         Date MATERIALIZED toDate(timestamp)
) ENGINE = MergeTree
PARTITION BY toYYYYMM(date)
ORDER BY (rule_code, timestamp)
TTL date + INTERVAL 90 DAY
SETTINGS index_granularity = 8192;
```

### 12.2 时序查询示例

```sql
-- 最近7天每日数据质量评分趋势
SELECT
    date,
    data_domain,
    avg(metric_value) AS avg_score,
    min(metric_value) AS min_score,
    max(metric_value) AS max_score,
    countIf(check_status != 'SUCCESS') AS anomaly_check_count
FROM dq_metrics_time_series
WHERE date >= today() - 7
GROUP BY date, data_domain
ORDER BY date, data_domain;

-- 某规则最近24小时指标变化
SELECT
    timestamp,
    metric_value,
    anomaly_count,
    check_status
FROM dq_metrics_time_series
WHERE rule_code = 'COMPLETENESS_ANSWER_USER_ID'
  AND timestamp >= now() - INTERVAL 24 HOUR
ORDER BY timestamp;
```

## 14. 错误处理与异常场景

### 14.1 引擎自身异常处理

| 异常场景 | 处理策略 |
| --- | --- |
| 检测SQL执行超时 | 超时30s自动kill，记录ERROR日志，不计入异常率 |
| 数据库连接失败 | 重试3次（间隔5s），仍失败则发送P0告警 |
| 修复SQL执行失败 | 立即停止该批次修复，保留已修复记录，发送告警 |
| Kafka消费者lag监控失败 | 降级为跳过该项检测，记录WARNING |
| ClickHouse写入失败 | 降级写入MySQL，后台补偿同步 |
| 规则配置语法错误 | 规则自动置为禁用，通知管理员修正 |

### 14.2 防护机制

```java
/**
 * 检测执行器 — 含熔断保护
 */
@Service
public class QualityCheckExecutor {

    private final CircuitBreaker circuitBreaker;

    @Autowired
    public QualityCheckExecutor(CircuitBreakerRegistry registry) {
        this.circuitBreaker = registry.circuitBreaker("dq-check",
            CircuitBreakerConfig.custom()
                .failureRateThreshold(50)          // 失败率50%熔断
                .waitDurationInOpenState(Duration.ofMinutes(5))
                .slidingWindowSize(20)             // 最近20次检测
                .minimumNumberOfCalls(10)
                .build());
    }

    public void executeAsync(QualityRule rule, String batchId) {
        Supplier<QualityCheckResult> supplier = CircuitBreaker
            .decorateSupplier(circuitBreaker, () -> doCheck(rule, batchId));

        CompletableFuture.supplyAsync(supplier, executorService)
            .orTimeout(120, TimeUnit.SECONDS)
            .whenComplete((result, error) -> {
                if (error != null) {
                    handleCheckError(rule, batchId, error);
                } else {
                    handleCheckResult(rule, batchId, result);
                }
            });
    }

    private QualityCheckResult doCheck(QualityRule rule, String batchId) {
        try {
            CheckContext context = buildContext(rule, batchId);
            QualityCheckResult result = rule.check(context);
            checkLogService.save(result, rule, batchId);
            postCheckHandler.handleCheckResult(result, rule);
            return result;
        } catch (Exception e) {
            // 检测引擎自身出错，区别于数据异常
            QualityCheckResult errorResult = QualityCheckResult.error(
                rule.getMeta().code(), e.getMessage());
            checkLogService.save(errorResult, rule, batchId);
            throw e;
        }
    }
}
```
