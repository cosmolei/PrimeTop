# 服务端-学生学习成长曲线建模与长期学习趋势预测引擎-详细设计

## 1. 概述

### 1.1 模块定位

学生学习成长曲线建模与长期学习趋势预测引擎是 PrimeTop 学情分析体系中的底层数据建模引擎。它负责对每个学生在各学科、各知识点维度上的历史学习数据进行纵向时间序列建模，构建数学意义上的"学习成长曲线"，并基于该曲线进行趋势预测、平台期检测和增长速率分析。

与现有模块的边界划分：

| 模块 | 职责边界 |
| --- | --- |
| **本引擎** | 长期成长曲线数学建模、趋势预测、平台期检测、增长速率量化 |
| 学习进度快照与历史趋势对比查询引擎 | 快照存储与时间点对比查询（不做预测建模） |
| 学习成绩预测与考试分数预估引擎 | 考试分数点预测（聚焦分数，非成长曲线） |
| 学生学业发展长周期推演与多目标学习路径仿真引擎 | 学习路径规划与仿真（从规划角度） |
| 知识追踪模型引擎与学生能力动态评估服务 | 单知识点掌握度实时评估（非跨时间曲线） |
| 多渠道学习数据融合与统一知识掌握度计算引擎 | 多源数据融合计算统一掌握度（不做时序建模） |

### 1.2 核心职责

1. **成长曲线拟合**：对学生历史学习表现数据（掌握度、正确率、效率等）进行时间序列拟合，生成参数化成长曲线模型。
2. **趋势预测**：基于拟合曲线，预测未来 N 周的学习状态走向。
3. **平台期（Plateau）检测**：识别学生学习停滞期，触发干预建议。
4. **增长速率分析**：计算各学科/知识点的学习增长速率（growth rate），量化"进步快慢"。
5. **曲线对比分析**：将学生实际曲线与同龄群体均值曲线、期望目标曲线进行差异分析。
6. **拐点检测**：识别学习状态发生显著改善或恶化的关键时间节点。

## 3. 核心算法

### 3.1 模型选择策略

引擎根据数据特征自动选择最佳拟合模型：

```python
class CurveModelSelector:
    """
    根据数据点数量和分布特征自动选择最优模型类型。
    选择优先级：Logistic > Exponential > Linear > Piecewise
    """

    MIN_POINTS_LOGISTIC = 12       # Logistic 至少需要 12 个数据点
    MIN_POINTS_EXPONENTIAL = 6     # Exponential 至少需要 6 个数据点
    MIN_POINTS_LINEAR = 3          # Linear 至少需要 3 个数据点
    MIN_POINTS_PIECEWISE = 20      # Piecewise 至少需要 20 个数据点

    @staticmethod
    def select(data_points: list, dimension: str) -> str:
        n = len(data_points)
        if n < CurveModelSelector.MIN_POINTS_LINEAR:
            return None  # 数据不足，无法建模

        # 计算数据特征
        values = [dp.value for dp in data_points]
        value_range = max(values) - min(values)
        has_saturation = values[-1] > 0.7 and value_range < 0.5
        is_monotonic = all(values[i] <= values[i+1] + 0.05 for i in range(len(values)-1))

        # 检测分段特征（存在明显变速）
        if n >= CurveModelSelector.MIN_POINTS_PIECEWISE:
            slopes = CurveModelSelector._compute_windowed_slopes(values, window=5)
            slope_variance = np.var(slopes)
            if slope_variance > 0.0001:  # 斜率变化显著
                return "PIECEWISE"

        # 优先尝试 Logistic（学习成长最常见模式）
        if n >= CurveModelSelector.MIN_POINTS_LOGISTIC and has_saturation:
            return "LOGISTIC"

        # 数据较少或处于成长初期
        if n >= CurveModelSelector.MIN_POINTS_EXPONENTIAL and is_monotonic:
            return "EXPONENTIAL"

        # 兜底使用线性
        return "LINEAR"

    @staticmethod
    def _compute_windowed_slopes(values, window=5):
        slopes = []
        for i in range(len(values) - window):
            x = np.arange(window)
            y = np.array(values[i:i+window])
            slope = np.polyfit(x, y, 1)[0]
            slopes.append(slope)
        return slopes
```

### 3.2 Logistic 曲线拟合（Levenberg-Marquardt 最小二乘法）

```python
import numpy as np
from scipy.optimize import curve_fit

class LogisticCurveFitter:

    @staticmethod
    def fit(x: np.ndarray, y: np.ndarray) -> dict:
        """
        Logistic 曲线拟合：y = L / (1 + exp(-k * (x - x0))) + b

        参数:
            x: 天数偏移（从第一个数据点起的天数）
            y: 对应的学习指标值

        返回:
            {
                "params": {"L": ..., "k": ..., "x0": ..., "b": ...},
                "r_squared": ...,
                "residual_std": ...
            }
        """
        # 初始参数估计
        L_init = min(max(y) * 1.05, 1.0)
        k_init = 0.05
        x0_init = float(np.median(x))
        b_init = float(min(y) * 0.5)

        def logistic_func(x, L, k, x0, b):
            return L / (1.0 + np.exp(-k * (x - x0))) + b

        try:
            popt, pcov = curve_fit(
                logistic_func, x, y,
                p0=[L_init, k_init, x0_init, b_init],
                bounds=(
                    [0.1, 0.001, 0.0, -0.1],      # 下界
                    [1.0, 0.5, max(x) * 2, 0.3]   # 上界
                ),
                maxfev=10000
            )
            L, k, x0, b = popt

            # 计算拟合优度
            y_pred = logistic_func(x, *popt)
            ss_res = np.sum((y - y_pred) ** 2)
            ss_tot = np.sum((y - np.mean(y)) ** 2)
            r_squared = 1 - ss_res / ss_tot if ss_tot > 0 else 0
            residual_std = float(np.sqrt(ss_res / len(y)))

            return {
                "params": {"L": float(L), "k": float(k), "x0": float(x0), "b": float(b)},
                "r_squared": float(r_squared),
                "residual_std": residual_std
            }

        except (RuntimeError, ValueError):
            # 拟合失败，降级为线性
            return None
```

### 3.3 平台期（Plateau）检测算法

平台期指学生虽然在持续学习，但学习指标长期无明显提升的时段。

```python
class PlateauDetector:
    """
    平台期检测器。
    核心思路：计算最近 N 周的增长速率（导数），若持续低于阈值，则判定为平台期。
    """

    # 检测参数
    PLATEAU_WINDOW_WEEKS = 4       # 检测窗口：最近 4 周
    PLATEAU_RATE_THRESHOLD = 0.002 # 周增长率低于 0.2% 视为停滞
    PLATEAU_MIN_CONFIDENCE = 0.6   # 最低数据置信度要求
    PLATEAU_ACCELERATION_CHECK = True  # 是否检查加速度（二阶导数接近0）

    @staticmethod
    def detect(model: GrowthCurveModel, recent_points: list) -> dict:
        """
        判断当前是否处于平台期。

        参数:
            model: 已拟合的成长曲线模型
            recent_points: 最近 N 周的原始数据点

        返回:
            {
                "is_plateau": bool,
                "plateau_start_date": str | None,
                "avg_rate": float,           # 近期平均增长速率
                "expected_rate": float,      # 期望增长速率（同龄人均值）
                "duration_days": int,        # 已持续天数
                "severity": "MILD" | "MODERATE" | "SEVERE"
            }
        """
        if len(recent_points) < PlateauDetector.PLATEAU_WINDOW_WEEKS:
            return {"is_plateau": False}

        # 计算最近窗口内的实际增长速率
        rates = []
        for i in range(1, len(recent_points)):
            delta_t = (recent_points[i].period_end - recent_points[i-1].period_end).days
            if delta_t == 0:
                continue
            delta_v = recent_points[i].value - recent_points[i-1].value
            rate = delta_v / delta_t
            rates.append(rate)

        avg_rate = np.mean(rates) if rates else 0

        # 基于模型导数计算当前理论增长率
        current_day = (recent_points[-1].period_end - model.data_start_date).days
        model_rate = CurveCalculus.first_derivative(model, current_day)
        model_accel = CurveCalculus.second_derivative(model, current_day)

        # 判定逻辑
        is_plateau = (
            avg_rate < PlateauDetector.PLATEAU_RATE_THRESHOLD
            and model_rate < PlateauDetector.PLATEAU_RATE_THRESHOLD
            and (not PlateauDetector.PLATEAU_ACCELERATION_CHECK
                 or abs(model_accel) < 0.0001)
        )

        if is_plateau:
            # 回溯平台期开始日期
            plateau_start = PlateauDetector._find_plateau_start(recent_points)
            duration = (recent_points[-1].period_end - plateau_start).days

            # 严重度评估
            if avg_rate < 0 and model_rate < 0:
                severity = "SEVERE"   # 实际在下降
            elif duration > 42:        # 超过 6 周
                severity = "SEVERE"
            elif duration > 21:        # 超过 3 周
                severity = "MODERATE"
            else:
                severity = "MILD"
        else:
            plateau_start = None
            duration = 0
            severity = None

        return {
            "is_plateau": is_plateau,
            "plateau_start_date": plateau_start.isoformat() if plateau_start else None,
            "avg_rate": float(avg_rate),
            "expected_rate": float(model_rate),
            "duration_days": duration,
            "severity": severity
        }

    @staticmethod
    def _find_plateau_start(points: list) -> date:
        """从数据点序列中回溯找到增长率开始低于阈值的时间点"""
        threshold = PlateauDetector.PLATEAU_RATE_THRESHOLD
        for i in range(len(points) - 1, 0, -1):
            delta_t = (points[i].period_end - points[i-1].period_end).days
            if delta_t == 0:
                continue
            delta_v = points[i].value - points[i-1].value
            rate = delta_v / delta_t
            if rate > threshold * 2:  # 之前增长明显更快
                return points[i].period_start
        return points[0].period_start
```

### 3.4 曲线导数计算（增长速率与加速度）

```python
class CurveCalculus:
    """
    成长曲线的微分计算，用于量化增长速率和加速度。
    """

    @staticmethod
    def first_derivative(model: GrowthCurveModel, x: float) -> float:
        """一阶导数 = 增长速率（单位：value/day）"""
        if model.model_type == "LOGISTIC":
            p = model.model_params["params"]
            L, k, x0 = p["L"], p["k"], p["x0"]
            # d/dx [L / (1 + e^(-k(x-x0)))] = L*k*e^(-k(x-x0)) / (1 + e^(-k(x-x0)))^2
            exponent = -k * (x - x0)
            exp_val = np.exp(exponent)
            denom = (1 + exp_val) ** 2
            return float(L * k * exp_val / denom)

        elif model.model_type == "EXPONENTIAL":
            p = model.model_params["params"]
            a, b, c = p["a"], p["b"], p["c"]
            # y = a * e^(bx) * e^(-cx²)
            # y' = a * e^(bx - cx²) * (b - 2cx)
            exponent = b * x - c * x ** 2
            return float(a * np.exp(exponent) * (b - 2 * c * x))

        elif model.model_type == "LINEAR":
            return float(model.model_params["params"]["slope"])

        return 0.0

    @staticmethod
    def second_derivative(model: GrowthCurveModel, x: float) -> float:
        """二阶导数 = 加速度（增长在加速还是减速）"""
        if model.model_type == "LOGISTIC":
            p = model.model_params["params"]
            L, k, x0 = p["L"], p["k"], p["x0"]
            # y'' = L * k² * e^(-k(x-x0)) * (e^(-k(x-x0)) - 1) / (1 + e^(-k(x-x0)))³
            exponent = -k * (x - x0)
            exp_val = np.exp(exponent)
            denom = (1 + exp_val) ** 3
            return float(L * k**2 * exp_val * (exp_val - 1) / denom)

        elif model.model_type == "EXPONENTIAL":
            p = model.model_params["params"]
            a, b, c = p["a"], p["b"], p["c"]
            exponent = b * x - c * x ** 2
            term1 = (b - 2*c*x) ** 2
            term2 = -2 * c
            return float(a * np.exp(exponent) * (term1 + term2))

        elif model.model_type == "LINEAR":
            return 0.0

        return 0.0
```

### 3.5 拐点检测算法

```python
class InflectionDetector:
    """
    检测学习成长曲线上的关键拐点：
    - BREAKTHROUGH: 增长率突然显著提升（突破期）
    - DECLINE: 增长率突然显著下降或转负（退步期）
    - PLATEAU_START: 进入平台期
    - PLATEAU_END: 平台期结束，重新开始增长
    """

    BREAKTHROUGH_RATE_RATIO = 2.0    # 当前速率 > 近期均值的 2 倍
    DECLINE_RATE_THRESHOLD = -0.001  # 速率转负
    SMOOTH_WINDOW = 3                # 平滑窗口

    @staticmethod
    def detect_inflections(
        student_id: int,
        subject_code: str,
        dimension: str,
        data_points: list,
        model: GrowthCurveModel
    ) -> list:
        """
        扫描历史数据，检测所有拐点事件。
        """
        if len(data_points) < InflectionDetector.SMOOTH_WINDOW + 2:
            return []

        events = []
        values = np.array([dp.value for dp in data_points])

        # 计算平滑后的逐点增长率
        smoothed = InflectionDetector._smooth(values, InflectionDetector.SMOOTH_WINDOW)
        rates = np.diff(smoothed)

        # 动态基准
        rolling_avg_rate = np.convolve(rates, np.ones(5)/5, mode='valid')
        rolling_avg_rate = np.pad(rolling_avg_rate, (2, 2), mode='edge')

        prev_plateau_state = False

        for i in range(2, len(rates)):
            current_rate = rates[i]
            baseline = rolling_avg_rate[i] if i < len(rolling_avg_rate) else 0

            # 检测突破
            if (baseline > 0
                and current_rate > baseline * InflectionDetector.BREAKTHROUGH_RATE_RATIO
                and current_rate > 0.005):
                events.append({
                    "event_type": "BREAKTHROUGH",
                    "event_date": data_points[i+1].period_start,
                    "pre_value": float(values[i]),
                    "post_value": float(values[i+1]),
                    "magnitude": float(current_rate - baseline)
                })

            # 检测退步
            elif current_rate < InflectionDetector.DECLINE_RATE_THRESHOLD:
                events.append({
                    "event_type": "DECLINE",
                    "event_date": data_points[i+1].period_start,
                    "pre_value": float(values[i]),
                    "post_value": float(values[i+1]),
                    "magnitude": float(abs(current_rate))
                })

            # 平台期状态转换
            is_plateau_now = current_rate < 0.001
            if is_plateau_now and not prev_plateau_state:
                events.append({
                    "event_type": "PLATEAU_START",
                    "event_date": data_points[i+1].period_start,
                    "pre_value": float(values[i]),
                    "post_value": float(values[i+1]),
                    "magnitude": 0.0
                })
            elif not is_plateau_now and prev_plateau_state:
                events.append({
                    "event_type": "PLATEAU_END",
                    "event_date": data_points[i+1].period_start,
                    "pre_value": float(values[i]),
                    "post_value": float(values[i+1]),
                    "magnitude": float(current_rate)
                })

            prev_plateau_state = is_plateau_now

        return events

    @staticmethod
    def _smooth(values: np.ndarray, window: int) -> np.ndarray:
        """移动平均平滑"""
        if len(values) < window:
            return values
        kernel = np.ones(window) / window
        smoothed = np.convolve(values, kernel, mode='same')
        # 修正边界效应
        smoothed[:window//2] = values[:window//2]
        smoothed[-(window//2):] = values[-(window//2):]
        return smoothed
```

### 3.6 预测置信区间计算

```python
class ForecastConfidenceBand:
    """
    基于模型残差和预测距离，计算预测值的置信区间。
    预测越远，不确定性越大（喇叭口扩张）。
    """

    @staticmethod
    def compute(
        model: GrowthCurveModel,
        target_day: int,
        last_data_day: int
    ) -> tuple:
        """
        返回 (lower_bound, upper_bound) 95% 置信区间。

        参数:
            model: 已拟合的模型
            target_day: 预测目标天数偏移
            last_data_day: 最后一个实际数据点的天数偏移
        """
        # 基础预测值
        predicted = ForecastConfidenceBand._predict(model, target_day)

        # 基础标准差（来自拟合残差）
        base_std = model.fit_quality  # 使用 residual_std

        # 时间衰减因子：预测距离越远，不确定性越大
        horizon_days = max(0, target_day - last_data_day)
        decay_factor = 1.0 + 0.02 * horizon_days  # 每天增加 2% 不确定性

        # 模型类型调整因子
        model_adjustment = {
            "LOGISTIC": 1.0,       # Logistic 模型自带饱和约束，长期预测更稳定
            "EXPONENTIAL": 1.5,    # 指数模型长期外推风险高
            "LINEAR": 1.2,         # 线性外推中等风险
            "PIECEWISE": 1.3       # 分段模型在段间过渡处有额外不确定性
        }.get(model.model_type, 1.5)

        adjusted_std = base_std * decay_factor * model_adjustment

        # 95% 置信区间 = predicted ± 1.96 * adjusted_std
        lower = max(0.0, predicted - 1.96 * adjusted_std)
        upper = min(1.0, predicted + 1.96 * adjusted_std)

        return (float(lower), float(upper))

    @staticmethod
    def _predict(model: GrowthCurveModel, x: float) -> float:
        """根据模型类型计算预测值"""
        if model.model_type == "LOGISTIC":
            p = model.model_params["params"]
            return p["L"] / (1 + np.exp(-p["k"] * (x - p["x0"]))) + p["b"]
        elif model.model_type == "EXPONENTIAL":
            p = model.model_params["params"]
            return p["a"] * np.exp(p["b"] * x) * np.exp(-p["c"] * x**2)
        elif model.model_type == "LINEAR":
            p = model.model_params["params"]
            return p["slope"] * x + p["intercept"]
        elif model.model_type == "PIECEWISE":
            for seg in model.model_params["segments"]:
                if seg["start_day"] <= x <= seg["end_day"]:
                    if seg["model"] == "LINEAR":
                        return seg["params"]["slope"] * x + seg["params"]["intercept"]
                    elif seg["model"] == "LOGISTIC":
                        sp = seg["params"]
                        return sp["L"] / (1 + np.exp(-sp["k"] * (x - sp["x0"]))) + sp.get("b", 0)
            # 超出最后一段：用最后一段的末尾值
            last_seg = model.model_params["segments"][-1]
            return ForecastConfidenceBand._predict_segment_end(last_seg)
        return 0.0
```

| `FAILED` | 无可用模型 | 需人工介入或等待更多数据积累 |

### 6.1 周维度数据聚合任务


```python
class WeeklyDataAggregationJob:

    async def execute(self):
        """每周执行：将 DAILY 数据点聚合为 WEEKLY"""
        last_week_start = self._get_last_week_start()

        # 分批获取有活跃数据的学生
        async for student_batch in self.student_repo.iter_active_students(
            active_since=last_week_start,
            batch_size=500
        ):
            for student in student_batch:
                await self._aggregate_student_week(student.id, last_week_start)

    async def _aggregate_student_week(self, student_id: int, week_start: date):
        """聚合单个学生一周的数据"""
        subjects = await self.subject_repo.get_student_subjects(student_id)

        for subject in subjects:
            # 获取该学科本周所有日维度数据
            daily_points = await self.data_point_repo.query(
                student_id=student_id,
                subject_code=subject,
                period_type="DAILY",
                start_date=week_start,
                end_date=week_start + timedelta(days=6)
            )

            if not daily_points:
                continue

            for dimension in ["MASTERY", "ACCURACY", "EFFICIENCY", "ENGAGEMENT"]:
                dim_points = [p for p in daily_points if p.dimension == dimension]
                if not dim_points:
                    continue

                # 加权平均（按 confidence 加权）
                total_weight = sum(p.confidence * p.sample_count for p in dim_points)
                if total_weight == 0:
                    continue

                weighted_value = sum(
                    p.value * p.confidence * p.sample_count
                    for p in dim_points
                ) / total_weight

                # 写入周维度数据点
                await self.data_point_repo.upsert({
                    "student_id": student_id,
                    "subject_code": subject,
                    "kp_id": None,  # 学科汇总
                    "dimension": dimension,
                    "period_type": "WEEKLY",
                    "period_start": week_start,
                    "period_end": week_start + timedelta(days=6),
                    "value": round(weighted_value, 4),
                    "sample_count": sum(p.sample_count for p in dim_points),
                    "confidence": min(1.0, total_weight / 20.0)  # 20次以上为满置信
                })
```

```java
/**
 * 成长曲线建模引擎核心服务
 */
@Service
@Slf4j
public class GrowthCurveService {

    @Autowired
    private LearningDataPointRepository dataPointRepo;

    @Autowired
    private GrowthCurveModelRepository modelRepo;

    @Autowired
    private GrowthInflectionEventRepository eventRepo;

    @Autowired
    private GrowthForecastSnapshotRepository forecastRepo;

    @Autowired
    private CohortReferenceCurveRepository cohortRepo;

    @Autowired
    private CurveModelSelector modelSelector;

    @Autowired
    private CurveFitterFactory fitterFactory;

    @Autowired
    private PlateauDetector plateauDetector;

    @Autowired
    private InflectionDetector inflectionDetector;

    @Autowired
    private ForecastGenerator forecastGenerator;

    @Autowired
    private KafkaEventPublisher eventPublisher;

    /**
     * 构建或重建学生的成长曲线模型
     */
    @Transactional
    public GrowthCurveModel buildModel(
            Long studentId,
            String subjectCode,
            Long kpId,
            String dimension) {

        // 1. 获取历史数据点
        List<LearningDataPoint> dataPoints = dataPointRepo.findWeeklyPoints(
            studentId, subjectCode, kpId, dimension
        );

        if (dataPoints.size() < 3) {
            log.warn("数据点不足: student={}, subject={}, points={}",
                studentId, subjectCode, dataPoints.size());
            throw new BusinessException("GROWTH_003", "数据点不足，无法建模");
        }

        // 2. 模型选择
        String modelType = modelSelector.select(dataPoints, dimension);

        // 3. 曲线拟合
        CurveFitResult fitResult;
        try {
            CurveFitter fitter = fitterFactory.getFitter(modelType);
            fitResult = fitter.fit(dataPoints);
        } catch (CurveFitException e) {
            log.warn("模型拟合失败，降级为线性: {}", e.getMessage());
            fitter = fitterFactory.getFitter("LINEAR");
            fitResult = fitter.fit(dataPoints);
            modelType = "LINEAR";
        }

        // 4. 计算当前状态
        int currentDay = ChronoUnit.DAYS.between(
            dataPoints.get(0).getPeriodStart(),
            dataPoints.get(dataPoints.size() - 1).getPeriodEnd()
        );
        double currentValue = fitter.predict(currentDay);
        double currentRate = fitter.firstDerivative(currentDay);
        double currentAccel = fitter.secondDerivative(currentDay);

        // 5. 平台期检测
        PlateauResult plateauResult = plateauDetector.detect(
            fitResult, dataPoints
        );

        // 6. 保存模型
        int newVersion = modelRepo.getMaxVersion(studentId, subjectCode, kpId, dimension) + 1;
        GrowthCurveModel model = GrowthCurveModel.builder()
            .studentId(studentId)
            .subjectCode(subjectCode)
            .kpId(kpId)
            .dimension(dimension)
            .modelType(modelType)
            .modelParams(fitResult.toJson())
            .fitQuality(fitResult.getRSquared())
            .dataPointCount(dataPoints.size())
            .dataStartDate(dataPoints.get(0).getPeriodStart())
            .dataEndDate(dataPoints.get(dataPoints.size() - 1).getPeriodEnd())
            .currentValue(BigDecimal.valueOf(currentValue))
            .currentRate(BigDecimal.valueOf(currentRate))
            .currentAcceleration(BigDecimal.valueOf(currentAccel))
            .plateauFlag(plateauResult.isPlateau() ? 1 : 0)
            .plateauStartDate(plateauResult.getPlateauStartDate())
            .modelVersion(newVersion)
            .build();

        modelRepo.save(model);

        // 7. 拐点检测
        List<InflectionEvent> newEvents = inflectionDetector.detect(
            studentId, subjectCode, dimension, dataPoints, model
        );
        for (InflectionEvent event : newEvents) {
            eventRepo.save(event);
        }

        // 8. 生成预测快照
        List<GrowthForecastSnapshot> forecasts = forecastGenerator.generate(
            model, 30  // 默认预测 30 天
        );
        forecastRepo.saveAll(forecasts);

        // 9. 发布事件
        eventPublisher.publishGrowthModelUpdated(model);

        if (plateauResult.isPlateau()) {
            eventPublisher.publishPlateauDetected(studentId, subjectCode, plateauResult);
        }

        for (InflectionEvent event : newEvents) {
            eventPublisher.publishInflectionDetected(event);
        }

        return model;
    }

    /**
     * 获取成长曲线（含预测）
     */
    public GrowthCurveResponse getGrowthCurve(
            Long studentId,
            String subjectCode,
            String dimension,
            boolean includeForecast,
            int forecastDays) {

        // 获取最新版本模型
        GrowthCurveModel model = modelRepo.findLatest(
            studentId, subjectCode, null, dimension
        );

        if (model == null) {
            throw new BusinessException("GROWTH_005", "未找到成长模型");
        }

        // 获取实际数据点
        List<LearningDataPoint> actualPoints = dataPointRepo.findWeeklyPoints(
            studentId, subjectCode, null, dimension
        );

        // 构建响应
        GrowthCurveResponse.GrowthCurveResponseBuilder builder = GrowthCurveResponse.builder()
            .studentId(studentId)
            .subjectCode(subjectCode)
            .dimension(dimension)
            .model(GrowthCurveResponse.ModelInfo.from(model))
            .actualPoints(actualPoints.stream()
                .map(GrowthCurveResponse.DataPointInfo::from)
                .collect(Collectors.toList()));

        // 生成预测数据
        if (includeForecast) {
            List<GrowthForecastSnapshot> forecasts = forecastGenerator.generate(
                model, Math.min(forecastDays, 180)
            );
            builder.forecastPoints(forecasts.stream()
                .map(GrowthCurveResponse.ForecastPointInfo::from)
                .collect(Collectors.toList()));
        }

        // 平台期信息
        builder.plateau(plateauDetector.getCurrentPlateauStatus(model));

        // 拐点事件
        List<GrowthInflectionEvent> events = eventRepo.findByStudentAndSubject(
            studentId, subjectCode, dimension
        );
        builder.inflectionEvents(events.stream()
            .map(GrowthCurveResponse.EventInfo::from)
            .collect(Collectors.toList()));

        return builder.build();
    }
}
```

### 7.2 模型选择器实现

```java
/**
 * 模型自动选择器
 */
@Component
@Slf4j
public class CurveModelSelector {

    private static final int MIN_POINTS_LOGISTIC = 12;
    private static final int MIN_POINTS_EXPONENTIAL = 6;
    private static final int MIN_POINTS_LINEAR = 3;
    private static final int MIN_POINTS_PIECEWISE = 20;

    public String select(List<LearningDataPoint> dataPoints, String dimension) {
        int n = dataPoints.size();

        if (n < MIN_POINTS_LINEAR) {
            return null;
        }

        // 计算数据特征
        double[] values = dataPoints.stream()
            .mapToDouble(p -> p.getValue().doubleValue())
            .toArray();

        double maxValue = Arrays.stream(values).max().orElse(0);
        double minValue = Arrays.stream(values).min().orElse(0);
        double valueRange = maxValue - minValue;
        double lastValue = values[values.length - 1];

        boolean hasSaturation = lastValue > 0.7 && valueRange < 0.5;
        boolean isMonotonic = checkMonotonic(values, 0.05);

        // 检测分段特征
        if (n >= MIN_POINTS_PIECEWISE) {
            double slopeVariance = computeSlopeVariance(values, 5);
            if (slopeVariance > 0.0001) {
                log.debug("选择 PIECEWISE 模型: slopeVariance={}", slopeVariance);
                return "PIECEWISE";
            }
        }

        // 优先 Logistic
        if (n >= MIN_POINTS_LOGISTIC && hasSaturation) {
            log.debug("选择 LOGISTIC 模型: saturation detected");
            return "LOGISTIC";
        }

        // Exponential（成长初期）
        if (n >= MIN_POINTS_EXPONENTIAL && isMonotonic) {
            log.debug("选择 EXPONENTIAL 模型: monotonic growth");
            return "EXPONENTIAL";
        }

        // 线性兜底
        log.debug("选择 LINEAR 模型: fallback");
        return "LINEAR";
    }

    private boolean checkMonotonic(double[] values, double tolerance) {
        for (int i = 1; i < values.length; i++) {
            if (values[i] > values[i - 1] + tolerance) {
                continue; // 上升
            }
            if (values[i] < values[i - 1] - tolerance) {
                return false; // 显著下降
            }
        }
        return true;
    }

    private double computeSlopeVariance(double[] values, int window) {
        if (values.length < window + 1) {
            return 0;
        }

        List<Double> slopes = new ArrayList<>();
        for (int i = 0; i <= values.length - window; i++) {
            // 简单线性回归斜率
            double sumX = 0, sumY = 0, sumXY = 0, sumX2 = 0;
            for (int j = 0; j < window; j++) {
                sumX += j;
                sumY += values[i + j];
                sumXY += j * values[i + j];
                sumX2 += j * j;
            }
            double n = window;
            double slope = (n * sumXY - sumX * sumY) / (n * sumX2 - sumX * sumX);
            slopes.add(slope);
        }

        double mean = slopes.stream().mapToDouble(d -> d).average().orElse(0);
        double variance = slopes.stream()
            .mapToDouble(d -> Math.pow(d - mean, 2))
            .average().orElse(0);

        return variance;
    }
}
```

### 8.2 缓存失效策略

| 场景 | 失效操作 |
| --- | --- |
| 每周模型重建 | 删除该学生所有学科的 Redis 缓存 key |
| 增量数据点写入 | 不主动失效，依赖 TTL 自然过期 |
| 拐点事件新增 | 更新 Redis 中的 events 列表 |
| 手动触发重建 | 删除指定 key 并发布 Redis DEL 事件 |

```java
@Component
public class GrowthCurveCacheManager {

    private static final String KEY_PREFIX = "growth:curve:";
    private static final Duration REDIS_TTL = Duration.ofMinutes(30);

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Autowired
    private Cache<String, GrowthCurveResponse> localCache;

    public GrowthCurveResponse get(Long studentId, String subject, String dimension) {
        String cacheKey = buildKey(studentId, subject, dimension);

        // L1 本地缓存
        GrowthCurveResponse cached = localCache.getIfPresent(cacheKey);
        if (cached != null) {
            return cached;
        }

        // L2 Redis
        cached = (GrowthCurveResponse) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            localCache.put(cacheKey, cached);
            return cached;
        }

        return null; // Cache miss
    }

    public void put(Long studentId, String subject, String dimension,
                    GrowthCurveResponse data) {
        String cacheKey = buildKey(studentId, subject, dimension);
        localCache.put(cacheKey, data);
        redisTemplate.opsForValue().set(cacheKey, data, REDIS_TTL);
    }

    public void evictStudent(Long studentId) {
        // 删除该学生所有缓存
        Set<String> keys = redisTemplate.keys(KEY_PREFIX + studentId + ":*");
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }
        // 本地缓存通过 key 模式匹配清理
        localCache.invalidateAll(
            localCache.asMap().keySet().stream()
                .filter(k -> k.startsWith(KEY_PREFIX + studentId + ":"))
                .collect(Collectors.toSet())
        );
    }

    private String buildKey(Long studentId, String subject, String dimension) {
        return KEY_PREFIX + studentId + ":" + subject + ":" + dimension;
    }
}
```

## 10. 错误处理与降级策略

### 10.1 错误分级

| 级别 | 场景 | 处理方式 |
| --- | --- | --- |
| P0 - 致命 | 数据库连接失败 | 返回 503，触发告警，上游使用上次缓存结果 |
| P1 - 严重 | 模型拟合失败 | 降级为线性回归，记录日志但返回结果 |
| P2 - 警告 | 数据点不足 | 返回已有数据点的原始折线，不构建模型 |
| P3 - 信息 | 预测置信度过低 | 仍返回预测值，但在响应中标注 `low_confidence: true` |

### 10.2 降级链路

```text
正常链路：
  数据采集 → 模型选择 → Logistic拟合 → 预测生成

第一级降级（Logistic拟合失败）：
  数据采集 → 模型选择 → 线性回归 → 预测生成

第二级降级（线性拟合也失败）：
  数据采集 → 原始数据点直接返回 → 不生成预测

第三级降级（数据库不可用）：
  Redis 缓存命中 → 返回缓存数据（标注 stale=true）
  Redis 不可用 → 返回 503 + 重试提示
```

### 12.3 集成测试场景

| 场景 | 测试步骤 | 预期结果 |
| --- | --- | --- |
| 端到端模型构建 | 注入 12 周数据 → 触发重建 → 查询曲线 | 返回 Logistic 模型 + 预测 + 拐点 |
| 增量更新 | 已有模型 + 3 周新数据 → 触发增量重建 | 模型版本 +1，拟合优度更新 |
| 平台期预警 | 持续 4 周低增长 → 定时检测 | 产生 PLATEAU 事件并推送到下游 |
| 缓存失效与刷新 | 手动触发重建 → 查询 | 缓存被清除，返回新模型数据 |
| 并发安全 | 同时触发两个重建请求 | 只执行一次，返回相同结果 |
| 降级链路 | 模拟拟合异常 → 自动降级线性 | 返回线性模型，标注 degraded=true |

## 14. 附录

### 14.1 术语表

| 术语 | 说明 |
| --- | --- |
| 成长曲线 | 学生学习指标随时间变化的参数化数学函数 |
| 数据采集点 | 按日/周聚合的学习指标值，作为曲线拟合输入 |
| 平台期（Plateau） | 学习指标长期无明显提升的时段 |
| 拐点（Inflection） | 学习状态发生显著变化的时间节点 |
| 拟合优度（R²） | 模型对数据的拟合程度，越接近 1 越好 |
| 置信区间 | 预测值的不确定性范围 |
| 群体参考曲线 | 同年级同学科学生的中位数/Top25% 曲线 |

### 14.2 数学模型公式汇总

| 模型类型 | 公式 | 一阶导数 | 二阶导数 |
| --- | --- | --- | --- |
| Logistic | $y = \frac{L}{1+e^{-k(x-x_0)}} + b$ | $y' = \frac{Lke^{-k(x-x_0)}}{(1+e^{-k(x-x_0)})^2}$ | $y'' = \frac{Lk^2 e^{-k(x-x_0)}(e^{-k(x-x_0)}-1)}{(1+e^{-k(x-x_0)})^3}$ |
| Exponential | $y = ae^{bx-cx^2}$ | $y' = ae^{bx-cx^2}(b-2cx)$ | $y'' = ae^{bx-cx^2}((b-2cx)^2-2c)$ |
| Linear | $y = ax + b$ | $y' = a$ | $y'' = 0$ |
