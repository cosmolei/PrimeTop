## 1. 概述

### 1.1 背景

启硕 PrimeTop 作为面向未成年人的教育产品，需严格遵守《个人信息保护法》《儿童个人信息网络保护规定》等法规要求。用户（含家长代理）拥有数据可携带权和删除权，产品必须提供完整的数据导出和账户注销能力。

### 1.2 目标

1. **合规**：满足个保法第45条（数据可携带权）和第47条（删除权）的法定要求。
2. **用户体验**：提供清晰、易用的数据导出和注销流程，减少用户操作负担。
3. **数据安全**：导出过程加密传输，注销后数据不可恢复。
4. **审计合规**：全流程可追溯，满足监管审计要求。

### 1.3 范围

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 个人数据打包导出 | 用户主动请求导出全部个人数据 | P0 |
| 学习数据专项导出 | 导出错题本、学习记录、学情报告等 | P1 |
| 账户注销 | 注销账户并清理关联数据 | P0 |
| 家长代理操作 | 家长代为操作子女数据导出/注销 | P0 |
| 数据保留策略 | 定义注销后哪些数据依法保留、保留多久 | P0 |
| 注销冷静期 | 注销后提供冷静期可撤回 | P1 |

## 2. 数据资产清单

### 2.1 用户维度数据分类

```
┌─────────────────────────────────────────────────────────────┐
│                     用户数据全景图                            │
├──────────────┬──────────────────────────────────────────────┤
│ 身份数据     │ 手机号、昵称、头像、年级、教材版本            │
│ 认证数据     │ 登录凭证、第三方绑定(OAuth)、设备Token        │
│ 学习数据     │ 学习会话、对话记录、章节进度、答题记录         │
│ 错题数据     │ 错题记录、错因标签、订正记录、复习计划         │
│ 画像数据     │ 能力维度、学情报告、知识掌握度、薄弱点分析      │
│ 规划数据     │ 学习计划、任务列表、目标设定、完成记录         │
│ 内容数据     │ 收藏、笔记、自定义素材、上传的图片/语音         │
│ 交易数据     │ 订单、会员订阅、支付记录、发票信息             │
│ 关系数据     │ 家长绑定关系、教师关联、班级关系               │
│ 行为日志     │ 埋点事件、操作日志、异常日志                   │
│ 推送数据     │ 设备注册、推送记录、消息偏好                   │
└──────────────┴──────────────────────────────────────────────┘
```

### 2.2 数据分类标记

每类数据标记以下属性，决定导出/注销行为：

| 标记 | 含义 | 导出 | 注销删除 | 依法保留 |
|------|------|------|----------|----------|
| `PII` | 个人可识别信息 | ✅ | ✅（脱敏后保留统计） | ❌ |
| `LEARNING` | 学习行为数据 | ✅ | ✅ | ❌ |
| `CONTENT` | 用户生成内容 | ✅ | ✅ | ❌ |
| `TRANSACTION` | 交易流水 | ✅ | 伪匿名化 | ✅（5年，税法要求） |
| `SECURITY_LOG` | 安全审计日志 | ❌ | 伪匿名化 | ✅（6个月，网络安全法） |
| `AGGREGATE` | 聚合统计数据 | ❌ | 保留（不可逆） | ✅ |
| `CONSENT` | 授权记录 | ✅ | 保留（不可逆） | ✅（3年，个保法要求） |

## 3. 数据结构定义

### 3.1 核心数据模型

```sql
-- 数据导出请求表
CREATE TABLE data_export_requests (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '请求用户ID',
    operator_id     BIGINT NOT NULL COMMENT '操作人ID（本人或家长代理）',
    operator_type   ENUM('self', 'parent', 'admin') NOT NULL DEFAULT 'self',
    export_type     ENUM('full', 'learning', 'mistake_book', 'conversation', 'transaction') NOT NULL,
    status          ENUM('pending', 'processing', 'completed', 'failed', 'expired') NOT NULL DEFAULT 'pending',
    
    -- 导出范围
    date_range_start DATE COMMENT '数据范围-起始日期（可选）',
    date_range_end   DATE COMMENT '数据范围-截止日期（可选）',
    data_categories  JSON COMMENT '包含的数据类别列表',
    
    -- 导出结果
    file_format     ENUM('json', 'csv', 'zip_json', 'zip_csv') NOT NULL DEFAULT 'zip_json',
    file_url        VARCHAR(512) COMMENT '导出文件下载地址',
    file_size_bytes BIGINT COMMENT '文件大小',
    file_hash_sha256 VARCHAR(64) COMMENT '文件SHA256校验',
    
    -- 加密
    encrypt_method  ENUM('aes-256', 'zip_password', 'none') NOT NULL DEFAULT 'aes-256',
    encryption_key  VARCHAR(256) COMMENT '加密密钥（RSA加密存储）',
    
    -- 时间
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    processing_at   DATETIME COMMENT '开始处理时间',
    completed_at    DATETIME COMMENT '完成时间',
    expires_at      DATETIME COMMENT '下载链接过期时间',
    
    -- 审计
    client_ip       VARCHAR(45) NOT NULL,
    user_agent      VARCHAR(512),
    device_id       VARCHAR(64),
    
    INDEX idx_user_id (user_id),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 账户注销请求表
CREATE TABLE account_deletion_requests (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id             BIGINT NOT NULL COMMENT '待注销用户ID',
    operator_id         BIGINT NOT NULL COMMENT '操作人ID',
    operator_type       ENUM('self', 'parent', 'admin') NOT NULL DEFAULT 'self',
    
    -- 注销原因
    reason_type         ENUM('no_longer_needed', 'privacy_concern', 'switch_to_competitor', 
                             'account_compromised', 'parent_decision', 'other') NOT NULL,
    reason_detail       VARCHAR(500) COMMENT '详细原因（可选）',
    
    -- 状态流转
    status              ENUM('pending', 'cooling_off', 'processing', 'completed', 
                             'cancelled', 'rejected') NOT NULL DEFAULT 'pending',
    
    -- 冷静期
    cooling_off_hours   INT NOT NULL DEFAULT 72 COMMENT '冷静期时长（小时）',
    cooling_off_until   DATETIME COMMENT '冷静期截止时间',
    cancelled_at        DATETIME COMMENT '用户撤回时间',
    cancelled_reason    VARCHAR(200) COMMENT '撤回原因',
    
    -- 数据处理
    data_cleanup_plan   JSON COMMENT '数据清理计划',
    cleanup_completed_at DATETIME COMMENT '数据清理完成时间',
    
    -- 关联检查
    has_active_subscription BOOLEAN DEFAULT FALSE COMMENT '是否有有效订阅',
    has_pending_order      BOOLEAN DEFAULT FALSE COMMENT '是否有待处理订单',
    has_bound_children     BOOLEAN DEFAULT FALSE COMMENT '是否绑定了子账号（家长）',
    pre_check_passed       BOOLEAN DEFAULT FALSE COMMENT '前置检查是否通过',
    
    -- 时间与审计
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    processed_at        DATETIME COMMENT '开始处理时间',
    completed_at        DATETIME COMMENT '注销完成时间',
    client_ip           VARCHAR(45) NOT NULL,
    user_agent          VARCHAR(512),
    
    INDEX idx_user_id (user_id),
    INDEX idx_status (status),
    INDEX idx_cooling_off (cooling_off_until)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 数据清理日志表（审计用途）
CREATE TABLE data_cleanup_audit_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    deletion_id     BIGINT NOT NULL COMMENT '关联注销请求ID',
    user_id         BIGINT NOT NULL COMMENT '被清理的用户ID',
    
    -- 清理明细
    data_category   VARCHAR(50) NOT NULL COMMENT '数据类别',
    table_name      VARCHAR(100) NOT NULL COMMENT '表名',
    record_count    INT NOT NULL COMMENT '清理记录数',
    cleanup_action  ENUM('hard_delete', 'pseudonymize', 'retain') NOT NULL,
    cleanup_detail  JSON COMMENT '清理详情',
    
    -- 审计
    performed_by    VARCHAR(50) NOT NULL COMMENT 'system / admin_id',
    performed_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    checksum_before VARCHAR(64) COMMENT '清理前数据校验',
    
    INDEX idx_deletion_id (deletion_id),
    INDEX idx_user_id (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 4. API 接口设计

### 4.1 数据导出接口

#### 4.1.1 创建导出请求

```
POST /api/v1/user/data-export
```

**请求体：**
```json
{
  "export_type": "full",
  "date_range": {
    "start": "2025-01-01",
    "end": "2026-05-23"
  },
  "data_categories": ["identity", "learning_records", "mistake_book", "ai_conversations", "transactions"],
  "file_format": "zip_json",
  "encrypt": true
}
```

**响应（202 Accepted）：**
```json
{
  "request_id": "expr_20260523_abc123",
  "status": "pending",
  "estimated_completion_minutes": 15,
  "message": "数据导出请求已提交，完成后将通过站内消息通知您"
}
```

#### 4.1.2 查询导出状态

```
GET /api/v1/user/data-export/{request_id}
```

**响应：**
```json
{

```

```

```

## 5. 核心流程设计

### 5.1 数据导出流程

```

 │──请求导出──────────▶│                       │                          │
 │                     │──POST /data-export───▶│                          │
 │                     │                       │──创建请求记录(pending)──▶│
 │                     │◀──202 Accepted────────│                          │
 │                     │                       │                          │
 │                     │◀──WebSocket推送进度───│◀──开始处理──────────────│
 │                     │                       │                          │
 │                     │                       │        ┌─────────────────┤
 │                     │                       │        │ 1.查询各类数据   │
 │                     │                       │        │ 2.脱敏PII字段    │
 │                     │                       │        │ 3.序列化为JSON   │
 │                     │                       │        │ 4.打包为ZIP      │
 │                     │                       │        │ 5.AES-256加密    │
 │                     │                       │        │ 6.上传到对象存储  │
 │                     │                       │        │ 7.生成下载链接    │
 │                     │                       │        └─────────────────┤
 │                     │                       │                          │
 │                     │◀──推送完成通知────────│◀──更新状态(completed)───│
 │──下载加密文件──────▶│                       │                          │
 │                     │──GET /download───────▶│                          │
 │                     │◀──302 重定向到CDN─────│                          │
 │                     │                       │                          │
 │                     │──本地派生密钥解密──────│                          │
 │◀──展示导出数据──────│                       │                          │
```

### 5.2 账户注销流程（完整状态机）

```go
    FileFormat     string

// ProcessExport 处理数据导出（异步Worker调用）
func (s *DataExportService) ProcessExport(ctx context.Context, reqID string) error {
    // 1. 加载请求
    var req DataExportRequest
    if err := s.db.Where("id = ?", reqID).First(&req).Error; err != nil {
        return fmt.Errorf("加载导出请求失败: %w", err)
    }

    // 2. 更新状态为处理中
    s.db.Model(&req).Updates(map[string]interface{}{
        "status":        "processing",
        "processing_at": time.Now(),
    })

    // 3. 收集各类数据
    exportData := &UserDataExport{
        ExportMeta: ExportMeta{
            ExportID:   reqID,
            UserID:     req.UserID,
            ExportType: req.ExportType,
            ExportTime: time.Now(),
        },
    }

    collectors := s.getCollectors(req.ExportType, req.Categories)
    for _, collector := range collectors {
        data, count, err := collector.Collect(ctx, req.UserID, req.DateRangeStart, req.DateRangeEnd)
        if err != nil {
            s.notifyService.NotifyExportFailed(req.UserID, reqID, err.Error())
            return fmt.Errorf("收集%s数据失败: %w", collector.Name(), err)
        }
        collector.SetData(exportData, data)
        // 推送进度
        s.pushProgress(ctx, reqID, collector.Name(), count)
    }

    // 4. 序列化为JSON
    jsonData, err := json.MarshalIndent(exportData, "", "  ")
    if err != nil {
        return fmt.Errorf("序列化失败: %w", err)
    }

    // 5. AES-256加密
    fileKey := deriveFileKey(req.UserID, reqID)
    encryptedData, err := aesEncrypt(jsonData, fileKey)
    if err != nil {
        return fmt.Errorf("加密失败: %w", err)
    }

    // 6. 上传到对象存储
    fileHash := sha256.Sum256(encryptedData)
    filePath := fmt.Sprintf("exports/%s/%s.enc", req.UserID, reqID)
    downloadURL, err := s.storage.Upload(ctx, filePath, encryptedData)
    if err != nil {
        return fmt.Errorf("上传失败: %w", err)
    }

    // 7. 更新请求记录
    expiresAt := time.Now().Add(72 * time.Hour) // 下载链接72小时有效
    s.db.Model(&req).Updates(map[string]interface{}{
        "status":          "completed",
        "completed_at":    time.Now(),
        "file_url":        downloadURL,
        "file_size_bytes": len(encryptedData),
        "file_hash_sha256": fmt.Sprintf("%x", fileHash),
        "encrypt_method":  "aes-256",
        "expires_at":      expiresAt,
    })

    // 8. 通知用户
    s.notifyService.NotifyExportReady(req.UserID, reqID, expiresAt)

    return nil
}

// DataCollector 数据收集器接口
type DataCollector interface {
    Name() string
    Collect(ctx context.Context, userID string, start, end *time.Time) (interface{}, int, error)
    SetData(export *UserDataExport, data interface{})
}

// LearningRecordCollector 学习记录收集器
type LearningRecordCollector struct {
    db *gorm.DB
}

func (c *LearningRecordCollector) Name() string { return "learning_records" }

func (c *LearningRecordCollector) Collect(ctx context.Context, userID string, start, end *time.Time) (interface{}, int, error) {
    query := c.db.WithContext(ctx).Where("user_id = ?", userID)
    if start != nil {
        query = query.Where("created_at >= ?", start)
    }
    if end != nil {
        query = query.Where("created_at <= ?", end)
    }

    var records []LearningRecord
    if err := query.Find(&records).Error; err != nil {
        return nil, 0, err
    }

    // 脱敏处理：移除IP地址等敏感字段
    result := make([]map[string]interface{}, len(records))
    for i, r := range records {
        result[i] = map[string]interface{}{
            "session_id":        r.SessionID,
            "subject":          r.Subject,
            "chapter":          r.Chapter,
            "start_time":       r.StartTime,
            "duration_seconds": r.DurationSeconds,
            "activity_type":    r.ActivityType,
        }
    }
    return result, len(records), nil
}

func (c *LearningRecordCollector) SetData(export *UserDataExport, data interface{}) {
    export.LearningRecords = data.([]map[string]interface{})
}

// deriveFileKey 从用户ID和请求ID派生文件加密密钥
func deriveFileKey(userID, reqID string) []byte {
    h := sha256.New()
    h.Write([]byte(userID + ":" + reqID))
    return h.Sum(nil)[:32] // AES-256
}

// aesEncrypt AES-256-GCM加密
func aesEncrypt(plaintext, key []byte) ([]byte, error) {
    block, err := aes.NewCipher(key)
    if err != nil {
        return nil, err
    }
    gcm, err := cipher.NewGCM(block)
    if err != nil {
        return nil, err
    }
    nonce := make([]byte, gcm.NonceSize())
    if _, err := io.ReadFull(rand.Reader, nonce); err != nil {
        return nil, err
    }
    return gcm.Seal(nonce, nonce, plaintext, nil), nil
}
```

```go
package deletion

import (
    "context"
    "fmt"
    "time"
)

// AccountDeletionService 账户注销服务
type AccountDeletionService struct {
    db            *gorm.DB
    redis         *redis.Client
    subscription  SubscriptionService
    payment       PaymentService
    pushService   PushService
    vectorDB      VectorDB
    searchEngine  SearchEngine
    auditLogger   AuditLogger
}

// DeletionPlan 注销数据清理计划
type DeletionPlan struct {
    UserID     string
    Steps      []DeletionStep
}

type DeletionStep struct {
    Category      string
    TableName     string
    ActionType    string // hard_delete | pseudonymize | retain
    Query         string
    Pseudonymize  *PseudonymizeConfig
}

type PseudonymizeConfig struct {
    FieldsToReplace map[string]string // 字段名 → 替换值
    AnonymizeID     string
}

// ProcessDeletion 处理账户注销
func (s *AccountDeletionService) ProcessDeletion(ctx context.Context, deletionID string) error {
    var req AccountDeletionRequest
    if err := s.db.Where("id = ?", deletionID).First(&req).Error; err != nil {
        return err
    }

    // 标记处理中
    s.db.Model(&req).Updates(map[string]interface{}{
        "status":       "processing",
        "processed_at": time.Now(),
    })

    // 禁止登录
    s.redis.Set(ctx, fmt.Sprintf("user:deleted:%s", req.UserID), "1", 0)
    s.redis.Del(ctx, fmt.Sprintf("user:sessions:%s", req.UserID))

    // 生成清理计划
    plan := s.generateDeletionPlan(req.UserID)

    // 逐步执行清理
    for _, step := range plan.Steps {
        recordCount, err := s.executeStep(ctx, req.UserID, step)
        if err != nil {
            s.auditLogger.LogError(req.UserID, step.Category, err)
            // 非致命错误继续执行
            continue
        }

        // 记录审计日志
        s.auditLogger.LogCleanup(DataCleanupAuditLog{
            DeletionID:    deletionID,
            UserID:        req.UserID,
            DataCategory:  step.Category,
            TableName:     step.TableName,
            RecordCount:   recordCount,
            CleanupAction: step.ActionType,
            PerformedBy:   "system",
        })
    }

    // 清理向量数据库
    s.vectorDB.DeleteByUserID(ctx, req.UserID)

    // 清理搜索引擎
    s.searchEngine.DeleteByUserID(ctx, req.UserID)

    // 最终标记
    s.db.Model(&req).Updates(map[string]interface{}{
        "status":              "completed",
        "completed_at":        time.Now(),
        "cleanup_completed_at": time.Now(),
    })

    // 用户表标记删除
    s.db.Model(&User{}).Where("id = ?", req.UserID).Updates(map[string]interface{}{
        "status":     "deleted",
        "deleted_at": time.Now(),
        "phone":      "", // 清除手机号
        "nickname":   fmt.Sprintf("已注销用户_%s", req.UserID[:8]),
    })

    return nil
}

// generateDeletionPlan 生成数据清理计划
func (s *AccountDeletionService) generateDeletionPlan(userID string) *DeletionPlan {
    return &DeletionPlan{
        UserID: userID,
        Steps: []DeletionStep{
            // 硬删除类
            {Category: "learning_records", TableName: "learning_records", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "mistake_records", TableName: "mistake_records", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "ai_conversations", TableName: "ai_conversations", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "ai_conversation_messages", TableName: "conversation_messages", ActionType: "hard_delete", Query: "conversation_id IN (SELECT id FROM ai_conversations WHERE user_id = ?)"},
            {Category: "learning_plans", TableName: "study_plans", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "favorites", TableName: "favorites", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "notes", TableName: "notes", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "user_uploads", TableName: "user_uploads", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "student_profile", TableName: "student_profiles", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "ability_profile", TableName: "ability_profiles", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "push_tokens", TableName: "push_tokens", ActionType: "hard_delete", Query: "user_id = ?"},
            {Category: "parent_binding", TableName: "parent_bindings", ActionType: "hard_delete", Query: "parent_user_id = ? OR child_user_id = ?"},

            // 伪匿名化类
            {Category: "transactions", TableName: "orders", ActionType: "pseudonymize",
                Query: "user_id = ?",
                Pseudonymize: &PseudonymizeConfig{
                    FieldsToReplace: map[string]string{"phone": "", "address": "", "real_name": ""},
                    AnonymizeID:     fmt.Sprintf("anon_%s", userID[:8]),
                }},

            // 保留类（仅记录审计）
            {Category: "audit_log", TableName: "security_audit_logs", ActionType: "retain", Query: "user_id = ?"},
            {Category: "consent_log", TableName: "user_consent_records", ActionType: "retain", Query: "user_id = ?"},
            {Category: "deletion_record", TableName: "account_deletion_requests", ActionType: "retain", Query: "user_id = ?"},
        },
    }
}

// executeStep 执行单步清理
func (s *AccountDeletionService) executeStep(ctx context.Context, userID string, step DeletionStep) (int, error) {
    switch step.ActionType {
    case "hard_delete":
        result := s.db.Exec(fmt.Sprintf("DELETE FROM %s WHERE %s", step.TableName, step.Query), userID)
        return int(result.RowsAffected), result.Error

    case "pseudonymize":
        if step.Pseudonymize == nil {
            return 0, fmt.Errorf("伪匿名化配置缺失")
        }
        updates := step.Pseudonymize.FieldsToReplace
        updates["user_id"] = step.Pseudonymize.AnonymizeID
        result := s.db.Table(step.TableName).Where(step.Query, userID).Updates(updates)
        return int(result.RowsAffected), result.Error

    case "retain":
        var count int64
        s.db.Table(step.TableName).Where(step.Query, userID).Count(&count)
        return int(count), nil

    default:
        return 0, fmt.Errorf("未知操作类型: %s", step.ActionType)
    }
}
```

## 7. 状态流转定义

### 7.1 导出请求状态

| 状态 | 含义 | 可流转到 | 触发条件 |
|------|------|----------|----------|
| `pending` | 已提交，等待处理 | `processing`, `failed` | Worker拉取 |
| `processing` | 正在收集和打包数据 | `completed`, `failed` | Worker开始处理 |
| `completed` | 导出完成，可下载 | `expired` | 数据打包成功 |
| `failed` | 处理失败 | `processing`（重试） | 异常 |
| `expired` | 下载链接已过期 | — | 超过72小时 |

### 7.2 注销请求状态

| 状态 | 含义 | 可流转到 | 触发条件 |
|------|------|----------|----------|
| `pending` | 已提交，待前置检查 | `cooling_off`, `rejected` | 提交注销 |
| `cooling_off` | 冷静期中 | `processing`, `cancelled` | 检查通过，72小时等待 |
| `cancelled` | 用户撤回 | — | 用户主动撤回 |
| `rejected` | 前置检查不通过 | `pending`（重新提交） | 有阻塞项 |
| `processing` | 正在清理数据 | `completed`, `failed` | 冷静期结束 |
| `completed` | 注销完成 | — | 数据清理完成 |
| `failed` | 处理异常 | `processing`（重试） | 清理失败 |

### 8.1 错误码定义

| 错误码 | HTTP状态码 | 含义 | 处理建议 |
|--------|-----------|------|----------|
| `EXPORT_QUOTA_EXCEEDED` | 429 | 当月导出次数超限（每月3次） | 升级会员或下月再试 |
| `EXPORT_ALREADY_RUNNING` | 409 | 已有一个导出任务进行中 | 等待当前任务完成 |
| `EXPORT_DATA_TOO_LARGE` | 413 | 数据量超过导出上限（5GB） | 缩小日期范围或分类导出 |
| `EXPORT_EXPIRED` | 410 | 下载链接已过期 | 重新发起导出 |
| `DELETE_BLOCKED_SUBSCRIPTION` | 409 | 有有效订阅 | 先取消订阅 |
| `DELETE_BLOCKED_ORDER` | 409 | 有待处理订单 | 等待订单完成 |
| `DELETE_NOT_IN_COOLING_OFF` | 400 | 不在冷静期内，无法撤回 | — |
| `DELETE_VERIFICATION_FAILED` | 403 | 身份验证失败 | 重新验证 |
| `DELETE_PERMISSION_DENIED` | 403 | 无权操作此账号 | 确认操作权限 |

## 12. 安全考虑

1. **导出文件加密**：所有导出文件必须AES-256加密，密钥在客户端派生，服务端不存储明文密钥
2. **下载链接签名**：CDN下载链接使用签名URL，设置过期时间，绑定用户IP
3. **操作验证**：注销操作需二次身份验证（短信验证码）
4. **操作日志**：所有数据访问/删除操作记入审计日志
5. **权限隔离**：只有用户本人或绑定的家长可以发起导出/注销
6. **防暴力操作**：同一用户每天最多发起1次注销请求
7. **数据残留检查**：注销完成后执行数据残留扫描，确保无遗漏
