# 学习复习材料智能生成与个性化记忆辅助内容制作引擎 - 详细设计

> **模块定位**：服务端核心引擎  
> **优先级**：P1（V1.0 阶段）  
> **依赖模块**：知识点体系、间隔重复调度引擎、学习记录服务、AI对话引擎、RAG知识库  
> **文档版本**：1.0  
> **最后更新**：2026-06-18

---

## 1. 文档概述

### 1.1 文档目的

本设计详细阐述"学习复习材料智能生成引擎"（以下简称"复习材料引擎"或"Review Material Engine, RME"）的完整技术方案。该引擎负责根据学生的学习历史、当前知识掌握度、遗忘曲线模型和学科特性，**自动生成个性化的复习材料**（记忆卡片、填空练习、知识问答、概念导图、速记口诀等），为间隔重复调度引擎提供"复习内容"，形成完整的"学—练—记—复习"闭环。

### 1.2 核心问题

当前系统已有：
- **间隔重复算法与遗忘曲线复习调度引擎**：解决"**什么时候**复习"的问题
- **英语词汇记忆与单词本系统**：解决英语单词的专项记忆管理

但缺少一个**跨学科通用**的中间层服务，解决"**复习什么内容、以什么形式呈现**"的问题：

| 痛点 | 表现 |
|------|------|
| 学生不知道怎么复习 | 只会重看课本、重做题目，效率低下 |
| 复习材料无法自动产出 | 依赖教研团队手工制作卡片，覆盖面有限 |
| 不同学科需要不同复习形式 | 古诗文需要填空背诵、数学需要公式推导回忆、历史需要时间线、英语需要单词卡 |
| 个性化程度不足 | 所有学生用同样的复习材料，没有针对性 |
| 与遗忘曲线脱节 | 调度引擎知道该复习了，但没有合适的材料推送 |

### 1.3 设计目标

1. **全学科覆盖**：支持语文（古诗文、文言文、字词）、数学（公式、定理、解题模型）、英语（单词、语法、句型）、物理/化学/生物（概念、实验流程、方程式）、历史/地理/政治（事件、地名、政策）等学科的复习材料自动生成。
2. **多形态材料**：支持生成记忆卡片、填空题、知识问答题、概念关联图、速记口诀、错因回顾卡等不少于 6 种复习材料形态。
3. **个性化适配**：基于学生知识掌握度、学习风格偏好和历史复习表现，动态调整材料难度、信息密度和呈现形式。
4. **AI 驱动 + 模板兜底**：优先使用 AI 大模型生成高质量材料，同时维护学科模板库确保基础覆盖和成本可控。
5. **与间隔重复无缝衔接**：为调度引擎提供标准化的复习任务包，支持 SM-2、FSRS 等算法的物模型接入。

## 3. 核心概念与领域模型

### 3.1 关键概念

| 概念 | 说明 | 示例 |
|------|------|------|
| 复习材料（ReviewItem） | 一条可独立复习的内容单元 | 一张古诗填空卡、一道知识问答题 |
| 材料形态（MaterialType） | 复习材料的呈现形式 | FLASHCARD / FILL_BLANK / QA / CONCEPT_MAP / MNEMONIC / ERROR_REVIEW |
| 内容锚点（ContentAnchor） | 复习材料关联的原始内容来源 | 教材课文段落、知识点定义、题目解析 |
| 复习任务包（ReviewPack） | 一组材料 + 调度元数据 | "本周 10 张记忆卡片 + 3 道知识问答" |
| 生成策略（GenerationStrategy） | 材料生成的规则集 | "新学章节→生成记忆卡+填空；错题→生成错因回顾卡" |
| 记忆难度值（MemoryDifficulty） | 预估记忆难度 0-1 | 0.9 表示该知识点对大多数学生较难记忆 |

### 3.2 材料形态枚举

```typescript
enum MaterialType {
  // 记忆卡片：正面提示，背面答案
  FLASHCARD = 'FLASHCARD',
  // 填空练习：挖空关键信息
  FILL_BLANK = 'FILL_BLANK',
  // 知识问答：Q&A 形式
  QA = 'QA',
  // 概念关联图：知识点之间的关系图
  CONCEPT_MAP = 'CONCEPT_MAP',
  // 速记口诀/记忆方法
  MNEMONIC = 'MNEMONIC',
  // 错因回顾卡：基于错题的反思卡
  ERROR_REVIEW = 'ERROR_REVIEW',
  // 听写卡片：语音输入作答
  DICTATION = 'DICTATION',
  // 序列排序题：按正确顺序排列
  SEQUENCE = 'SEQUENCE',
}
```

### 3.3 学科-形态推荐矩阵

不同学科优先使用不同的材料形态：

| 学科 | 推荐形态组合 | 说明 |
|------|-------------|------|
| 语文-古诗文 | FILL_BLANK + DICTATION + QA | 填空背诵 + 语音背诵 + 意境问答 |
| 语文-文言文 | FLASHCARD + QA + MNEMONIC | 实词虚词卡 + 翻译问答 + 背诵口诀 |
| 数学 | FLASHCARD + QA + SEQUENCE | 公式定理卡 + 推导问答 + 证明步骤排序 |
| 英语-词汇 | FLASHCARD + FILL_BLANK | 单词卡（英→中/中→英）+ 句子填空 |
| 英语-语法 | QA + FILL_BLANK + SEQUENCE | 语法选择问答 + 填空 + 词序排列 |
| 物理 | FLASHCARD + CONCEPT_MAP + QA | 概念定义卡 + 知识结构图 + 原理问答 |
| 化学 | FLASHCARD + QA + SEQUENCE | 方程式卡 + 反应原理问答 + 实验步骤排序 |
| 历史 | SEQUENCE + QA + FLASHCARD | 时间线排序 + 史实问答 + 事件卡 |
| 地理 | FLASHCARD + CONCEPT_MAP + QA | 地名特征卡 + 区域关系图 + 成因问答 |
| 政治 | QA + FLASHCARD + MNEMONIC | 观点论述问答 + 概念卡 + 记忆框架 |

## 4. 数据模型设计

### 4.1 PostgreSQL 表结构

#### 4.1.1 review_item（复习材料主表）

```sql
CREATE TABLE review_item (
    id              BIGSERIAL PRIMARY KEY,
    item_code       VARCHAR(64) NOT NULL UNIQUE,      -- 业务编码: RVI_{YYYYMMDD}_{seq}
    
    -- 关联信息
    student_id      BIGINT NOT NULL,                   -- 所属学生(0=通用模板)
    subject_code    VARCHAR(16) NOT NULL,              -- 学科编码
    grade_id        SMALLINT NOT NULL,                 -- 年级ID
    knowledge_point_ids JSONB NOT NULL DEFAULT '[]',   -- 关联知识点ID列表
    content_anchor  JSONB NOT NULL,                    -- 内容锚点(来源信息)
    
    -- 材料内容
    material_type   VARCHAR(32) NOT NULL,              -- 材料形态(MaterialType枚举)
    front_content   JSONB NOT NULL,                    -- 正面内容(题目/提示)
    back_content    JSONB NOT NULL DEFAULT '{}',       -- 背面内容(答案/解析)
    hint_content    JSONB,                             -- 提示信息
    explanation     TEXT,                              -- 详细解析
    
    -- 元数据
    difficulty      SMALLINT NOT NULL DEFAULT 3,       -- 难度 1-5
    memory_difficulty DECIMAL(3,2) NOT NULL DEFAULT 0.5, -- 记忆难度 0.00-1.00
    estimated_time_sec INT NOT NULL DEFAULT 30,        -- 预计复习用时(秒)
    tags            JSONB NOT NULL DEFAULT '[]',       -- 标签
    
    -- 生成信息
    source_type     VARCHAR(16) NOT NULL DEFAULT 'AI',  -- TEMPLATE / AI / HYBRID / USER
    source_model    VARCHAR(64),                        -- AI模型名称
    generation_meta JSONB NOT NULL DEFAULT '{}',        -- 生成元数据(Prompt版本等)
    
    -- 状态
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE', -- ACTIVE / ARCHIVED / DEPRECATED
    quality_score   DECIMAL(3,2),                       -- 质量评分 0-1
    review_count    INT NOT NULL DEFAULT 0,             -- 被复习次数
    correct_rate    DECIMAL(3,2) NOT NULL DEFAULT 0.0,  -- 正确率
    
    -- 时间
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    expires_at      TIMESTAMPTZ,                        -- 过期时间(可选)
    
    CONSTRAINT ck_material_type CHECK (
        material_type IN ('FLASHCARD','FILL_BLANK','QA','CONCEPT_MAP',
                         'MNEMONIC','ERROR_REVIEW','DICTATION','SEQUENCE')
    ),
    CONSTRAINT ck_difficulty CHECK (difficulty BETWEEN 1 AND 5),
    CONSTRAINT ck_memory_diff CHECK (memory_difficulty BETWEEN 0 AND 1)
);

-- 索引
CREATE INDEX idx_review_item_student ON review_item(student_id, status);
CREATE INDEX idx_review_item_kp ON review_item USING GIN (knowledge_point_ids);
CREATE INDEX idx_review_item_subject_grade ON review_item(subject_code, grade_id, status);
CREATE INDEX idx_review_item_type ON review_item(material_type, status);
CREATE INDEX idx_review_item_expires ON review_item(expires_at) WHERE expires_at IS NOT NULL;
```

#### 4.1.2 review_pack（复习任务包表）

```sql
CREATE TABLE review_pack (
    id              BIGSERIAL PRIMARY KEY,
    pack_code       VARCHAR(64) NOT NULL UNIQUE,
    student_id      BIGINT NOT NULL,
    
    -- 包信息
    title           VARCHAR(128) NOT NULL,
    description     TEXT,
    subject_code    VARCHAR(16),                       -- NULL=跨学科混合
    pack_type       VARCHAR(32) NOT NULL,              -- DAILY / WEEKLY / EXAM_PREP / ERROR_REVIEW / CHAPTER
    
    -- 调度信息
    scheduled_date  DATE NOT NULL,                     -- 计划复习日期
    srs_algorithm    VARCHAR(16) NOT NULL DEFAULT 'FSRS', -- SM-2 / FSRS
    srs_metadata     JSONB NOT NULL DEFAULT '{}',      -- 调度算法元数据
    
    -- 内容
    item_ids        JSONB NOT NULL DEFAULT '[]',       -- 包含的ReviewItem ID列表
    total_items     INT NOT NULL DEFAULT 0,
    estimated_total_time_sec INT NOT NULL DEFAULT 0,    -- 预计总用时
    
    -- 完成状态
    status          VARCHAR(16) NOT NULL DEFAULT 'PENDING', -- PENDING / IN_PROGRESS / COMPLETED / EXPIRED
    started_at      TIMESTAMPTZ,
    completed_at    TIMESTAMPTZ,
    result_summary  JSONB,                             -- 完成结果摘要
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    CONSTRAINT ck_pack_type CHECK (
        pack_type IN ('DAILY','WEEKLY','EXAM_PREP','ERROR_REVIEW','CHAPTER')
    ),
    CONSTRAINT ck_pack_status CHECK (
        status IN ('PENDING','IN_PROGRESS','COMPLETED','EXPIRED')
    )
);

CREATE INDEX idx_review_pack_student_date ON review_pack(student_id, scheduled_date, status);
CREATE INDEX idx_review_pack_status ON review_pack(status, scheduled_date);
```

### 4.2 Redis 数据结构

```redis
# 学生复习队列 (Sorted Set, score=优先级)
RME:queue:{studentId}  →  {itemId: priorityScore}

# 学生今日复习包缓存 (Hash, TTL=当天结束)
RME:pack:today:{studentId}  →  {packId, totalItems, completedItems, ...}

# 材料内容缓存 (String/JSON, TTL=7d)
RME:item:{itemId}  →  JSON(front_content, back_content, ...)

# 生成任务去重 (Set, TTL=1h)
RME:gen:dedup:{studentId}:{contentHash}  →  "1"

# 学科形态偏好缓存 (Hash, TTL=24h)
RME:pref:{studentId}  →  {CHINESE: "FILL_BLANK,DICTATION", MATH: "FLASHCARD,QA", ...}

# 全局材料计数器 (用于生成item_code)
RME:seq:daily:{YYYYMMDD}  →  counter
```

```java
     * 基于学习事件分析材料需求
     * @return 需求清单(知识点ID × 材料形态 × 优先级)

    fun analyzeDemand(event: LearningEvent): List<MaterialDemand> {
        val demands = mutableListOf<MaterialDemand>()
        
        when (event.eventType) {
            // 章节学习完成 → 为该章节核心知识点生成记忆卡片+填空
            CHAPTER_COMPLETED -> {
                val coreKPs = knowledgePointService.getCorePoints(event.chapterId)

                coreKPs.forEach { kp ->
                    preferredTypes.forEach { type ->
                        demands.add(MaterialDemand(
                            knowledgePointId = kp.id,
                            materialType = type,
                            priority = 80,
                            reason = "CHAPTER_COMPLETED",
                            deadline = LocalDate.now().plusDays(1)
                        ))
                    }
                }
            }
            
            // 练习完成 → 为错误题目的知识点生成错因回顾卡+知识问答
            EXERCISE_COMPLETED -> {
                event.wrongQuestions.forEach { q ->
                    demands.add(MaterialDemand(
                        knowledgePointId = q.knowledgePointId,
                        materialType = MaterialType.ERROR_REVIEW,
                        priority = 95,
                        reason = "WRONG_ANSWER",
                        contentAnchor = ContentAnchor(type="QUESTION", id=q.questionId),
                        deadline = LocalDate.now()
                    ))
                }
            }
            
            // 错题订正完成 → 生成变体验证卡
            MISTAKE_CORRECTED -> {
                demands.add(MaterialDemand(
                    knowledgePointId = event.knowledgePointId,
                    materialType = MaterialType.QA,
                    priority = 70,
                    reason = "VERIFICATION_NEEDED",
                    deadline = LocalDate.now().plusDays(3)
                ))
            }
        }
        
        return demands.sortedByDescending { it.priority }
    }
    
    /**
```

```java
class GenerationStrategySelector {
    
    fun selectStrategy(demand: MaterialDemand, context: ContentContext): Strategy {
        // 1. 优先查找匹配模板
        val template = templateService.findBestMatch(
            subjectCode = context.knowledgePoint.subjectCode,
            gradeRange = context.knowledgePoint.gradeId,

            studentId = demand.studentId,
            knowledgePointId = demand.knowledgePointId,
            materialType = demand.materialType
        )

            return Strategy.REUSE(existing.id)
        }
        
        // 3. 模板优先: 如果有高优先级模板且内容上下文充分
        if (template != null && template.reviewPriority >= 70 
            && context.textbookSegments.isNotEmpty()) {
            return Strategy.TEMPLATE(template)
        }

        val aiBudget = costGuard.checkBudget(studentId, "REVIEW_GEN")
        if (aiBudget.remainingTokens > MIN_GEN_TOKENS) {
            return Strategy.AI(model = selectModel(demand, context))
        }
        
        // 5. 降级: 使用通用模板兜底
        return Strategy.FALLBACK(demand.materialType)
    }
```

#### 5.5.3 质量校验通道

```java
class QualityChecker {
    
    fun check(
        content: ParsedContent,
        knowledgePoint: KnowledgePoint,
        materialType: MaterialType
    ): QualityResult {
        val issues = mutableListOf<QualityIssue>()
        
        // 1. 结构完整性检查
        if (!validateStructure(content, materialType)) {
            issues.add(QualityIssue("STRUCTURE_INVALID", Severity.ERROR))
        }
        
        // 2. 术语准确性检查 (与知识点定义比对)
        val termErrors = termValidator.validate(content.text, knowledgePoint)
        if (termErrors.isNotEmpty()) {
            issues.add(QualityIssue("TERM_ERROR", Severity.WARNING, termErrors))
        }
        
        // 3. 难度匹配检查
        val estimatedDifficulty = estimateDifficulty(content)
        if (abs(estimatedDifficulty - knowledgePoint.expectedDifficulty) > 2) {
            issues.add(QualityIssue("DIFFICULTY_MISMATCH", Severity.INFO))
        }
        
        // 4. AI幻觉检测 (与教材原文交叉验证)
        val hallucinationRisk = hallucinationDetector.check(
            content.text, 
            knowledgePoint.authoritativeSources
        )
        if (hallucinationRisk.score > 0.3) {
            issues.add(QualityIssue("HALLUCINATION_RISK", Severity.ERROR))
        }
        
        // 5. 适龄性检查
        val ageAppropriate = ageChecker.check(content.text, knowledgePoint.gradeId)
        if (!ageAppropriate) {
            issues.add(QualityIssue("AGE_INAPPROPRIATE", Severity.WARNING))
        }
        
        val score = calculateScore(issues)
        return QualityResult(score = score, issues = issues)
    }
    
    private fun calculateScore(issues: List<QualityIssue>): Double {
        var score = 1.0
        issues.forEach {
            score -= when (it.severity) {
                Severity.ERROR -> 0.3
                Severity.WARNING -> 0.1
                Severity.INFO -> 0.05
            }
        }
        return max(0.0, score)
    }
}
```

```java
class ReviewPackAssembler {
    
    /**
     * 组装每日复习包
     */
    fun assembleDailyPack(studentId: Long, date: LocalDate): ReviewPack {
        // 1. 从调度引擎获取今日待复习清单
        val srsItems = srsEngine.getDueItems(studentId, date)
        
        // 2. 从RME获取/生成对应材料
        val reviewItems = srsItems.map { srsItem ->
            reviewItemService.getBySrsItem(srsItem) 
                ?: generateOnDemand(studentId, srsItem)
        }
        
        // 3. 内容编排: 交错不同学科和形态, 避免疲劳
        val arranged = interleave(reviewItems)
        
        // 4. 控制总量: 每日不超过15-20项, 总时间不超过20分钟
        val capped = applyCapacity(arranged, maxItems = 20, maxTimeSec = 1200)
        
        // 5. 构建包
        val pack = ReviewPack(
            packCode = generatePackCode(studentId, date),
            studentId = studentId,
            title = "${date} 每日复习",
            packType = PackType.DAILY,
            scheduledDate = date,
            srsAlgorithm = srsConfig.algorithm,
            srsMetadata = mapOf("source" to "FSRS_ENGINE"),
            itemIds = capped.map { it.id },
            totalItems = capped.size,
            estimatedTotalTimeSec = capped.sumOf { it.estimatedTimeSec }
        )
        
        // 6. 持久化 + 缓存
        reviewPackRepository.save(pack)
        cacheTodayPack(studentId, pack)
        
        return pack
    }
    
    /**
     * 交错编排策略: Smith & Cohen 交错效应
     * 规则: 相同学科不连续超过3题, 相同形态不连续超过2题
     */
    private fun interleave(items: List<ReviewItem>): List<ReviewItem> {
        val bySubject = items.groupBy { it.subjectCode }
        val result = mutableListOf<ReviewItem>()
        val queues = bySubject.mapValues { (_, v) -> ArrayDeque(v) }
        
        while (queues.values.any { it.isNotEmpty() }) {
            // 按学科轮转取题
            queues.entries.shuffled().forEach { (_, queue) ->
                repeat(min(3, queue.size)) {
                    if (queue.isNotEmpty()) {
                        val item = queue.removeFirst()
                        // 检查形态连续性
                        if (!wouldBreakTypeStreak(result, item)) {
                            result.add(item)
                        } else {
                            queue.addFirst(item) // 放回, 下轮再试
                        }
                    }
                }
            }
        }
        
        return result.ifEmpty { items } // fallback
    }
    
    private fun wouldBreakTypeStreak(current: List<ReviewItem>, next: ReviewItem): Boolean {
        if (current.size < 2) return false
        val lastTwo = current.takeLast(2)
        return lastTwo.all { it.materialType == next.materialType }
    }
}
```

## 7. 关键算法设计

### 7.1 记忆难度值计算算法

```python
def calculate_memory_difficulty(knowledge_point, historical_data):
    """
    计算知识点的记忆难度 (0.0-1.0)
    综合考虑: 知识点复杂度、历史遗忘率、平均错误率
    """
    # 1. 知识点内在复杂度 (基于文本长度、术语密度)
    complexity = 0.3 * (
        len(knowledge_point.definition) / 200  # 定义长度
        + count_technical_terms(knowledge_point) / 10  # 术语数量
        + count_prerequisites(knowledge_point) / 5  # 前置依赖数
    )
    complexity = min(complexity, 1.0)
    
    # 2. 历史遗忘率 (过去30天该知识点的平均遗忘比例)
    if historical_data:
        forget_rate = sum(
            1 for r in historical_data
            if r.result == 'WRONG' and r.days_since_last < 7
        ) / len(historical_data)
    else:
        forget_rate = 0.3  # 默认值
    
    # 3. 加权综合
    difficulty = 0.4 * complexity + 0.6 * forget_rate
    return round(min(max(difficulty, 0.0), 1.0), 2)
```

### 7.2 复习材料筛选与排序算法

```python
def select_and_rank_items(candidates, student_id, capacity):
    """
    从候选材料池中选择最优子集
    考虑: 紧急度、重要度、多样性、疲劳均衡
    """
    scored = []
    for item in candidates:
        # 1. 紧急度 (越接近截止日期越高)
        urgency = calculate_urgency(item.next_review_date)
        
        # 2. 记忆稳定性收益 (越不稳定, 复习收益越高)
        stability_gain = 1.0 - item.memory_stability
        
        # 3. 难度匹配度 (与当前学生状态匹配)
        difficulty_match = 1.0 - abs(item.difficulty - student.current_level) / 5
        
        # 4. 历史正确率权重 (正确率低的优先)
        accuracy_weight = 1.0 - item.correct_rate if item.review_count > 0 else 0.5
        
        # 5. 综合Score
        score = (
            0.35 * urgency
            + 0.25 * stability_gain
            + 0.20 * difficulty_match
            + 0.15 * accuracy_weight
            + 0.05 * random_jitter()  # 避免完全确定性
        )
        scored.append((item, score))
    
    # 排序
    scored.sort(key=lambda x: x[1], reverse=True)
    
    # 贪心选择 + 多样性约束
    selected = []
    subject_counts = {}
    type_counts = {}
    
    for item, score in scored:
        if len(selected) >= capacity:
            break
        
        subj = item.subject_code
        mtype = item.material_type
        
        # 学科配额: 单学科不超过40%
        if subject_counts.get(subj, 0) >= capacity * 0.4:
            continue
        
        # 形态配额: 单形态不超过50%
        if type_counts.get(mtype, 0) >= capacity * 0.5:
            continue
        
        selected.append(item)
        subject_counts[subj] = subject_counts.get(subj, 0) + 1
        type_counts[mtype] = type_counts.get(mtype, 0) + 1
    
    return selected
```

## 10. 错误处理策略

### 10.1 错误分类与处理

| 错误类型 | 场景 | 处理策略 |
|----------|------|----------|
| AI调用超时 | LLM 响应超 15s | 切换轻量模型重试 → 模板生成 → 兜底 |
| AI调用失败 | API 错误/限流 | 3次指数退避重试 → 降级模板 → 兜底 |
| 内容解析失败 | LLM 输出格式错误 | JSON修复尝试 → 简化Prompt重试 → 降级 |
| 质量校验不通过 | 幻觉/术语错误 | 重试1次 → 降级模板 → 记录质量问题 |
| 内容源检索为空 | 知识点无教材内容 | 使用知识点定义生成基础卡 |
| 调度引擎不可用 | SRS服务宕机 | 使用本地缓存的待复习列表 |
| 数据库写入失败 | PostgreSQL 异常 | 重试3次 → 写入降级队列 → 告警 |
| Redis 不可用 | 缓存失效 | 直接查DB, 降级容忍 |

```java
class CostGuard {
    // 每学生每日AI生成Token上限
    val DAILY_TOKEN_LIMIT = 10_000
    
    // 每学生每周AI生成次数上限
    val WEEKLY_GEN_LIMIT = 50
    
    fun checkBudget(studentId: Long, operation: String): BudgetResult {
        val dailyUsed = tokenCounter.getDaily(studentId)
        val weeklyUsed = tokenCounter.getWeekly(studentId)
        
        val remainingTokens = DAILY_TOKEN_LIMIT - dailyUsed

        return when {

                BudgetResult(allowed = false, reason = "DAILY_TOKEN_EXCEEDED")
            remainingCount <= 0 -> 
                BudgetResult(allowed = false, reason = "WEEKLY_LIMIT_EXCEEDED")
            else -> 
                BudgetResult(allowed = true, remainingTokens = remainingTokens)
        }
    }
}
```

```java
        demandAnalyzer.analyzeDemand(event)
            .forEach { demand ->
                generationQueue.submit(event.studentId, listOf(demand))
            }
    }
}
```

## 16. 安全与合规

### 16.1 数据安全

- 复习材料中不存储完整的教材原文（仅存储锚点引用）
- 学生复习记录中的 `student_answer` 字段在 90 天后自动脱敏
- AI 生成请求中不传递学生个人身份信息（仅传递 studentId 的哈希）
- 管理后台查看材料内容时进行操作审计

### 16.2 内容安全

- AI 生成的所有内容必须经过质量校验通道
- 生成内容如涉及政治、历史等敏感学科，需通过敏感词过滤
- 未成年人相关合规：材料中不包含外部链接、不包含广告

### 16.3 权限控制

| 角色 | 权限 |
|------|------|
| 学生 | 查看自己的材料、提交反馈 |
| 家长 | 查看孩子复习统计（不含具体材料内容选项） |
| 教师 | 查看班级学生复习完成率统计 |
| 内容管理员 | 管理模板、审核低质量材料 |
| 系统管理员 | 全部权限 |

### 18.2 难度评估规则

```python
def estimate_difficulty(content, knowledge_point):
    """评估材料的预估难度 (1-5)"""
    base = knowledge_point.inherent_difficulty  # 知识点本身难度
    
    # 根据材料类型调整
    adjustments = {
        'FLASHCARD': 0,      # 卡片难度≈知识点难度
        'FILL_BLANK': -0.5,  # 填空稍简单(有上下文)
        'QA': +0.5,          # 问答稍难(需主动回忆)
        'CONCEPT_MAP': +1,   # 概念图最难(需理解结构)
        'MNEMONIC': -1,      # 口诀最简单(辅助记忆)
        'ERROR_REVIEW': +0.5 # 错题回顾稍难(已犯过错)
    }
    
    adjusted = base + adjustments.get(content.type, 0)
    return max(1, min(5, round(adjusted)))
```
