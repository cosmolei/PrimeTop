# 服务端-学生备考策略智能规划与考点优先级动态排序引擎-详细设计

## 1. 概述

### 1.1 模块定位

备考策略智能规划引擎是 PrimeTop 学习规划体系的核心子模块，专门针对**考试备考场景**，解决"有限时间内如何最优分配复习精力"的问题。与通用学习规划不同，备考策略强调：

- **时间紧迫性驱动**：以考试倒计时为核心约束，反推复习节奏
- **考点权重 × 掌握程度**：双维度交叉排序，聚焦"高频且薄弱"的考点
- **动态自适应**：随模拟练习结果实时调整考点优先级
- **多科目协调**：在多门考试密集排期下平衡时间投入

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 考试信息解析 | 解析考试类型、范围、日期、学科权重等输入 |
| 考点优先级计算 | 综合考点权重、出现频率、学生掌握度、时间成本计算优先级 |
| 备考路径生成 | 基于优先级和约束条件生成阶段性复习计划 |
| 动态重排 | 根据练习反馈、模拟考试成绩实时调整考点排序 |
| 多考试排期协调 | 多门考试时间冲突下的全局最优时间分配 |
| 备考效果预测 | 基于当前进度预估备考完成度和预期提分空间 |

### 1.4 与已有模块的边界

| 模块 | 关注点 | 本引擎差异 |
|------|--------|-----------|
| 学习规划服务 | 日常学习计划生成与跟踪 | 本引擎专注于**考试倒计时驱动**的策略规划 |
| 考点梳理 | 考点清单整理与呈现 | 本引擎做**算法决策**：考点的优先排序与时间分配 |
| 考试答题策略分析 | 考场上的答题顺序与时间分配 | 本引擎关注**考前复习阶段**的策略 |
| 学习计划动态调整 | 通用计划的调整逻辑 | 本引擎提供**备考专用**的重排算法 |
| 知识追踪模型 | 学生能力评估 | 本引擎消费追踪结果做**决策**而非评估 |

```java
/**
 * 考试任务 - 一次具体的备考目标
 */
@Data
@Entity
@Table(name = "exam_task")
public class ExamTask {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    /** 学生ID */
    @Column(nullable = false)
    private Long studentId;
    
    /** 考试名称，如 "2026年期末考试-数学" */
    @Column(nullable = false, length = 128)
    private String examName;
    
    /** 学科ID */
    @Column(nullable = false)
    private Long subjectId;
    
    /** 考试类型 */
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private ExamType examType;  // UNIT_TEST, MIDTERM, FINAL, MOCK, ENTRANCE_EXAM
    
    /** 考试日期 */
    @Column(nullable = false)
    private LocalDate examDate;
    
    /** 备考开始日期 */
    @Column(nullable = false)
    private LocalDate startDate;
    
    /** 考试范围：章节ID列表（JSON数组） */
    @Column(columnDefinition = "JSON")
    private String scopeChapterIds;  // [101, 102, 205, 301, ...]
    
    /** 考点ID列表（JSON数组） */
    @Column(columnDefinition = "JSON")
    private String scopeKnowledgePointIds;
    
    /** 考试满分 */
    private Integer fullScore;
    
    /** 目标分数（学生期望） */
    private Integer targetScore;
    
    /** 上次同类型考试得分（用于参考） */
    private Integer lastExamScore;
    
    /** 每日可用备考时长（分钟） */
    private Integer dailyAvailableMinutes;
    
    /** 优先级（多考试时排序用） */
    private Integer priority;
    
    /** 状态 */
    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private ExamTaskStatus status;  // PLANNING, IN_PROGRESS, COMPLETED, CANCELLED
    
    /** 创建时间 */
    private LocalDateTime createdAt;
    
    /** 更新时间 */
    private LocalDateTime updatedAt;
}
```

**可行性校验逻辑：**
```java
/**
 * 备考可行性检查
 */
public class FeasibilityChecker {
    
    private static final int MIN_DAYS_PER_PHASE = 2;  // 每阶段最少2天
    
    /**
     * @return null=可行, 非null=警告信息
     */
    public static String checkFeasibility(ExamTask task, int totalKP, int estimatedMinutes) {
        int totalDays = (int) ChronoUnit.DAYS.between(task.getStartDate(), task.getExamDate());
        int totalAvailable = totalDays * task.getDailyAvailableMinutes();
        
        // 1. 时间总量检查
        if (estimatedMinutes > totalAvailable) {
            double gap = (estimatedMinutes - totalAvailable) / 60.0;
            return String.format("预计需要%.1f小时，可用时间不足，建议增加每日时长或缩小范围", gap);
        }
        
        // 2. 阶段完整性检查（至少4个阶段各2天）
        if (totalDays < MIN_DAYS_PER_PHASE * 4) {
            return "备考时间过短，建议至少提前8天开始，否则策略效果有限";
        }
        
        // 3. 考点数 vs 时间
        if (totalKP > 0 && totalAvailable / totalKP < 30) {
            return String.format("共%d个考点，平均每个考点不足30分钟，建议聚焦高频考点", totalKP);
        }
        
        return null;
    }
}
```

### 4.2 考点优先级计算算法（核心）

```java
/**
 * 考点优先级计算引擎
 * 
 * 核心公式：
 * Priority = w1 × WeightFactor + w2 × UrgencyFactor + w3 × MasteryGap + w4 × ROIFactor
 * 
 * 其中：
 * - WeightFactor: 考点重要性（来自考纲权重 × 历年频率）
 * - UrgencyFactor: 紧迫度（距考试天数递减函数）
 * - MasteryGap: 掌握度缺口（1 - 当前掌握度）
 * - ROIFactor: 投入产出比（预计提分 / 预计耗时）
 */
public class PriorityCalculator {
    
    // 权重配置（可按学段调整）
    private static final double W_WEIGHT = 0.30;
    private static final double W_URGENCY = 0.15;
    private static final double W_MASTERY_GAP = 0.30;
    private static final double W_ROI = 0.25;
    
    /**
     * 计算单个考点的综合优先级
     */
    public KnowledgePointPriority calculate(KnowledgePoint kp, 
                                             ExamTask task,
                                             MasteryData mastery,
                                             KPExamStatistics stats) {
        
        // === 因子1: 考点重要性 (0-1) ===
        double weightFactor = calculateWeightFactor(kp, stats);
        
        // === 因子2: 紧迫度 (0-1) ===
        double urgencyFactor = calculateUrgencyFactor(task);
        
        // === 因子3: 掌握度缺口 (0-1) ===
        double masteryGap = 1.0 - mastery.getMasteryScore();
        // 掌握度已很高的考点，缺口因子快速衰减
        if (mastery.getMasteryScore() > 0.85) {
            masteryGap *= 0.3;  // 已掌握的考点大幅降权
        }
        
        // === 因子4: 投入产出比 (0-1) ===
        double roiFactor = calculateROIFactor(kp, mastery, stats);
        
        // === 综合优先级 ===
        double priorityScore = (
            W_WEIGHT * weightFactor +
            W_URGENCY * urgencyFactor +
            W_MASTERY_GAP * masteryGap +
            W_ROI * roiFactor
        ) * 100;
        
        // 归一化到 0-100
        priorityScore = Math.min(100, Math.max(0, priorityScore));
        
        // 确定优先级等级
        PriorityLevel level = classifyPriority(priorityScore, mastery.getMasteryScore());
        
        // 确定建议复习阶段
        ReviewPhase phase = recommendPhase(level, mastery.getMasteryScore(), urgencyFactor);
        
        // 构建优先级因子（可解释性）
        Map<String, Object> factors = Map.of(
            "weightFactor", round(weightFactor, 2),
            "urgencyFactor", round(urgencyFactor, 2),
            "masteryGap", round(masteryGap, 2),
            "roiFactor", round(roiFactor, 2),
            "explanation", buildExplanation(weightFactor, urgencyFactor, masteryGap, roiFactor, kp, mastery)
        );
        
        return KnowledgePointPriority.builder()
            .knowledgePointId(kp.getId())
            .knowledgePointName(kp.getName())
            .weightScore(kp.getExamWeight())
            .frequencyScore(stats.getFrequency())
            .masteryScore(mastery.getMasteryScore())
            .estimatedStudyMinutes(estimateStudyMinutes(kp, mastery))
            .expectedScoreGain(calculateExpectedGain(kp, mastery, stats))
            .priorityScore(priorityScore)
            .priorityLevel(level)
            .recommendedPhase(phase)
            .priorityFactors(JsonUtils.toJson(factors))
            .build();
    }
    
    /**
     * 考点重要性因子
     */
    private double calculateWeightFactor(KnowledgePoint kp, KPExamStatistics stats) {
        // 权重分（0-100）归一化
        double normalizedWeight = kp.getExamWeight() / 100.0;
        // 历年频率（0-1）
        double frequency = stats.getFrequency();
        
        // 加权平均：权重60% + 频率40%
        return normalizedWeight * 0.6 + frequency * 0.4;
    }
    
    /**
     * 紧迫度因子 - 使用Sigmoid曲线
     * 距考试越近，低掌握度考点的紧迫度越高
     */
    private double calculateUrgencyFactor(ExamTask task) {
        long daysRemaining = ChronoUnit.DAYS.between(LocalDate.now(), task.getExamDate());
        
        if (daysRemaining <= 0) return 1.0;        // 考试当天
        if (daysRemaining >= 60) return 0.2;       // 两个月以上
        
        // Sigmoid曲线：days=30 → 0.5, days=7 → 0.88, days=14 → 0.73
        double x = (30 - daysRemaining) / 10.0;
        return 1.0 / (1.0 + Math.exp(-x));
    }
    
    /**
     * 投入产出比因子
     */
    private double calculateROIFactor(KnowledgePoint kp, 
                                       MasteryData mastery, 
                                       KPExamStatistics stats) {
        int minutes = estimateStudyMinutes(kp, mastery);
        double scoreGain = calculateExpectedGain(kp, mastery, stats);
        
        if (minutes <= 0 || scoreGain <= 0) return 0;
        
        // ROI = 提分 / 每小时耗时
        double roi = scoreGain / (minutes / 60.0);
        
        // 归一化：ROI > 20分/小时 → 1.0
        return Math.min(1.0, roi / 20.0);
    }
    
    /**
     * 预估学习耗时（分钟）
     */
    private int estimateStudyMinutes(KnowledgePoint kp, MasteryData mastery) {
        // 基础耗时由知识点的复杂度和题型决定
        int baseMinutes = kp.getEstimatedLearnMinutes();  // 通常15-60分钟
        
        // 掌握度越低，需要的复习时间越多
        double multiplier = switch ((int)(mastery.getMasteryScore() * 4)) {
            case 0 -> 2.5;   // 0-25%: 从头学
            case 1 -> 1.8;   // 25-50%: 大量复习
            case 2 -> 1.2;   // 50-75%: 巩固复习
            default -> 0.5;  // 75-100%: 快速回顾
        };
        
        return (int) Math.ceil(baseMinutes * multiplier);
    }
    
    /**
     * 预计提分空间
     */
    private double calculateExpectedGain(KnowledgePoint kp, 
                                          MasteryData mastery,
                                          KPExamStatistics stats) {
        // 该考点在考试中的平均分值
        double avgScore = stats.getAverageScoreInExam();  // 如：8分
        
        // 掌握度对应的得分率
        double currentGainRate = mastery.getMasteryScore();
        double potentialGainRate = 1.0 - currentGainRate;
        
        return avgScore * potentialGainRate;
    }
    
    /**
     * 优先级等级分类
     */
    private PriorityLevel classifyPriority(double score, double mastery) {
        // 已高度掌握的考点最高只到 P2
        if (mastery > 0.85) return PriorityLevel.P3_LOW;
        if (mastery > 0.70) return PriorityLevel.P2_MEDIUM;
        
        if (score >= 80) return PriorityLevel.P0_CRITICAL;
        if (score >= 65) return PriorityLevel.P1_HIGH;
        if (score >= 45) return PriorityLevel.P2_MEDIUM;
        return PriorityLevel.P3_LOW;
    }
    
    /**
     * 阶段推荐
     */
    private ReviewPhase recommendPhase(PriorityLevel level, double mastery, double urgency) {
        // P0 + 低掌握度 → 基础阶段
        if (level == PriorityLevel.P0_CRITICAL && mastery < 0.4) {
            return ReviewPhase.FOUNDATION;
        }
        // P0/P1 → 强化阶段
        if (level == PriorityLevel.P0_CRITICAL || level == PriorityLevel.P1_HIGH) {
            return ReviewPhase.REINFORCEMENT;
        }
        // P2 + 紧迫度高 → 冲刺阶段
        if (level == PriorityLevel.P2_MEDIUM && urgency > 0.6) {
            return ReviewPhase.SPRINT;
        }
        // 已掌握或低优先级 → 考前回顾
        if (mastery > 0.7 || level == PriorityLevel.P3_LOW) {
            return ReviewPhase.FINAL_REVIEW;
        }
        return ReviewPhase.REINFORCEMENT;
    }
    
    private String buildExplanation(double w, double u, double m, double r, 
                                     KnowledgePoint kp, MasteryData mastery) {
        StringBuilder sb = new StringBuilder();
        if (w > 0.7) sb.append("高频考点(权重").append(kp.getExamWeight()).append(") ");
        if (m > 0.5) sb.append("掌握度偏低(").append(fmt(mastery.getMasteryScore())).append(") ");
        if (r > 0.6) sb.append("投入产出比高 ");
        if (u > 0.7) sb.append("时间紧迫 ");
        return sb.toString().trim();
    }
    
    private double round(double v, int scale) {
        double f = Math.pow(10, scale);
        return Math.round(v * f) / f;
    }
    
    private String fmt(double v) {
        return String.format("%.0f%%", v * 100);
    }
}
```

### 4.3 备考阶段划分算法

```java
/**
 * 备考阶段划分器
 * 
 * 将总备考天数按比例划分为4个阶段：
 * - 基础巩固(FOUNDATION): 25-30%
 * - 强化提升(REINFORCEMENT): 35-40%
 * - 冲刺突破(SPRINT): 20-25%
 * - 考前回顾(FINAL_REVIEW): 5-10%
 */
public class PhaseDivider {
    
    // 默认阶段比例
    private static final double R_FOUNDATION = 0.28;
    private static final double R_REINFORCEMENT = 0.38;
    private static final double R_SPRINT = 0.24;
    private static final double R_FINAL_REVIEW = 0.10;
    
    // 最小天数约束
    private static final int MIN_DAYS_FOUNDATION = 2;
    private static final int MIN_DAYS_REINFORCEMENT = 3;
    private static final int MIN_DAYS_SPRINT = 2;
    private static final int MIN_DAYS_FINAL_REVIEW = 1;
    
    public List<ExamPrepPhase> divide(ExamTask task, 
                                       List<KnowledgePointPriority> priorities) {
        int totalDays = (int) ChronoUnit.DAYS.between(task.getStartDate(), task.getExamDate()) + 1;
        
        // 如果时间不足，自适应压缩
        PhaseRatio ratio = adaptiveRatio(totalDays);
        
        // 计算各阶段天数
        int foundationDays = Math.max(MIN_DAYS_FOUNDATION, (int)(totalDays * ratio.foundation));
        int reinforcementDays = Math.max(MIN_DAYS_REINFORCEMENT, (int)(totalDays * ratio.reinforcement));
        int sprintDays = Math.max(MIN_DAYS_SPRINT, (int)(totalDays * ratio.sprint));
        int finalReviewDays = Math.max(MIN_DAYS_FINAL_REVIEW, (int)(totalDays * ratio.finalReview));
        
        // 如果总天数超出，从最长阶段中扣减
        int allocated = foundationDays + reinforcementDays + sprintDays + finalReviewDays;
        while (allocated > totalDays && reinforcementDays > MIN_DAYS_REINFORCEMENT) {
            reinforcementDays--;
            allocated--;
        }
        while (allocated > totalDays && foundationDays > MIN_DAYS_FOUNDATION) {
            foundationDays--;
            allocated--;
        }
        
        // 分配考点到阶段
        Map<ReviewPhase, List<KnowledgePointPriority>> kpByPhase = priorities.stream()
            .collect(Collectors.groupingBy(KnowledgePointPriority::getRecommendedPhase));
        
        // 构建阶段
        List<ExamPrepPhase> phases = new ArrayList<>();
        LocalDate cursor = task.getStartDate();
        
        phases.add(buildPhase(task, 1, ReviewPhase.FOUNDATION, "基础巩固", 
            cursor, cursor.plusDays(foundationDays - 1), kpByPhase.get(ReviewPhase.FOUNDATION)));
        cursor = cursor.plusDays(foundationDays);
        
        phases.add(buildPhase(task, 2, ReviewPhase.REINFORCEMENT, "强化提升",
            cursor, cursor.plusDays(reinforcementDays - 1), kpByPhase.get(ReviewPhase.REINFORCEMENT)));
        cursor = cursor.plusDays(reinforcementDays);
        
        phases.add(buildPhase(task, 3, ReviewPhase.SPRINT, "冲刺突破",
            cursor, cursor.plusDays(sprintDays - 1), kpByPhase.get(ReviewPhase.SPRINT)));
        cursor = cursor.plusDays(sprintDays);
        
        phases.add(buildPhase(task, 4, ReviewPhase.FINAL_REVIEW, "考前回顾",
            cursor, task.getExamDate().minusDays(1), priorities));  // 全部考点
        
        return phases;
    }
    
    /**
     * 自适应比例 - 时间紧张时压缩基础阶段，增加冲刺比例
     */
    private PhaseRatio adaptiveRatio(int totalDays) {
        if (totalDays >= 21) {
            return new PhaseRatio(R_FOUNDATION, R_REINFORCEMENT, R_SPRINT, R_FINAL_REVIEW);
        } else if (totalDays >= 14) {
            return new PhaseRatio(0.20, 0.35, 0.30, 0.15);
        } else if (totalDays >= 7) {
            return new PhaseRatio(0.15, 0.30, 0.40, 0.15);
        } else {
            // 极短备考：直接冲刺
            return new PhaseRatio(0.0, 0.20, 0.60, 0.20);
        }
    }
    
    private record PhaseRatio(double foundation, double reinforcement, 
                               double sprint, double finalReview) {}
}
```

### 4.4 每日任务编排算法

```java
/**
 * 每日备考任务编排器
 * 
 * 在阶段内，将考点按优先级分配到每一天，生成具体可执行的任务
 */
public class DailyTaskAllocator {
    
    /**
     * 为某个阶段生成每日任务
     */
    public List<DailyPrepTask> allocate(ExamTask task, 
                                         ExamPrepPhase phase,
                                         List<KnowledgePointPriority> kps,
                                         Map<Long, List<Question>> practiceBank) {
        
        List<DailyPrepTask> tasks = new ArrayList<>();
        
        int phaseDays = (int) ChronoUnit.DAYS.between(phase.getStartDate(), phase.getEndDate()) + 1;
        int dailyMinutes = task.getDailyAvailableMinutes();
        int phaseTotalMinutes = phaseDays * dailyMinutes;
        
        // 按优先级降序排列
        kps.sort(Comparator.comparingDouble(KnowledgePointPriority::getPriorityScore).reversed());
        
        LocalDate cursor = phase.getStartDate();
        int dayIndex = 0;
        int dayUsedMinutes = 0;
        
        for (KnowledgePointPriority kp : kps) {
            int kpRemaining = kp.getEstimatedStudyMinutes();
            
            while (kpRemaining > 0) {
                // 当天剩余时间不足时，推到下一天
                if (dayUsedMinutes + 15 > dailyMinutes) {
                    dayIndex++;
                    cursor = phase.getStartDate().plusDays(dayIndex);
                    dayUsedMinutes = 0;
                    if (dayIndex >= phaseDays) break;  // 阶段天数用完
                }
                
                // 本次分配的时间
                int slot = Math.min(kpRemaining, dailyMinutes - dayUsedMinutes);
                // 单次学习时间不超过45分钟（番茄钟原理）
                slot = Math.min(slot, 45);
                
                // 生成任务
                PrepTaskType taskType = determineTaskType(kp, phase.getPhaseType());
                List<Question> practices = selectPracticeQuestions(kp, practiceBank, taskType, slot);
                
                tasks.add(DailyPrepTask.builder()
                    .examTaskId(task.getId())
                    .phaseId(phase.getId())
                    .taskDate(cursor)
                    .knowledgePointId(kp.getKnowledgePointId())
                    .taskType(taskType)
                    .plannedMinutes(slot)
                    .resourceRefs(JsonUtils.toJson(buildResourceRefs(practices, kp)))
                    .intraDayPriority(tasks.stream()
                        .filter(t -> t.getTaskDate().equals(cursor))
                        .toList().size())
                    .status(TaskStatus.PENDING)
                    .build());
                
                kpRemaining -= slot;
                dayUsedMinutes += slot;
            }
            
            if (dayIndex >= phaseDays) break;  // 阶段已满
        }
        
        return tasks;
    }
    
    /**
     * 根据阶段和掌握度确定任务类型
     */
    private PrepTaskType determineTaskType(KnowledgePointPriority kp, ReviewPhase phase) {
        return switch (phase) {
            case FOUNDATION -> kp.getMasteryScore() < 0.3 ? 
                PrepTaskType.REVIEW_CONCEPT : PrepTaskType.PRACTICE;
            case REINFORCEMENT -> PrepTaskType.PRACTICE;
            case SPRINT -> PrepTaskType.MOCK_TEST;
            case FINAL_REVIEW -> PrepTaskType.FLASHCARD;
        };
    }
    
    /**
     * 选题策略：基于阶段和考点选择合适的练习题
     */
    private List<Question> selectPracticeQuestions(KnowledgePointPriority kp,
                                                    Map<Long, List<Question>> bank,
                                                    PrepTaskType type,
                                                    int targetMinutes) {
        List<Question> available = bank.getOrDefault(kp.getKnowledgePointId(), List.of());
        if (available.isEmpty()) return List.of();
        
        // 按难度过滤
        Difficulty target = switch (type) {
            case REVIEW_CONCEPT -> Difficulty.EASY;
            case PRACTICE -> Difficulty.MEDIUM;
            case MOCK_TEST -> Difficulty.HARD;
            case ERROR_CORRECTION -> Difficulty.MEDIUM;
            case FLASHCARD -> Difficulty.EASY;
        };
        
        List<Question> filtered = available.stream()
            .filter(q -> q.getDifficulty() == target || 
                        (type == PrepTaskType.PRACTICE && 
                         Math.abs(q.getDifficulty().ordinal() - target.ordinal()) <= 1))
            .collect(Collectors.toList());
        
        // 按预计每题时间填充
        List<Question> selected = new ArrayList<>();
        int accumulated = 0;
        for (Question q : filtered) {
            if (accumulated + q.getEstimatedMinutes() <= targetMinutes) {
                selected.add(q);
                accumulated += q.getEstimatedMinutes();
            }
        }
        
        return selected;
    }
}
```

### 4.5 动态重排算法

```java
/**
 * 考点优先级动态重排引擎
 * 
 * 触发条件：
 * 1. 模拟考试成绩回流
 * 2. 每日学习完成度报告
 * 3. 定时调度（每日凌晨重算）
 */
public class PriorityRebalancer {
    
    /**
     * 基于模拟考试结果重排
     */
    public RebalanceResult rebalanceAfterMock(ExamTask task, MockExamResult mockResult) {
        // 1. 获取当前优先级快照
        List<KnowledgePointPriority> currentPriorities = priorityService.getSnapshot(task.getId());
        
        // 2. 根据模考结果更新掌握度
        Map<Long, Double> masteryUpdates = new HashMap<>();
        for (SectionScore section : mockResult.getSectionScores()) {
            double rate = (double) section.getStudentScore() / section.getMaxScore();
            masteryUpdates.put(section.getKnowledgePointId(), rate);
        }
        
        // 3. 重新计算优先级
        List<KnowledgePointPriority> newPriorities = new ArrayList<>();
        List<RebalanceChange> changes = new ArrayList<>();
        
        for (KnowledgePointPriority old : currentPriorities) {
            KnowledgePointPriority updated = old.toBuilder().build();
            
            // 更新掌握度
            if (masteryUpdates.containsKey(old.getKnowledgePointId())) {
                double newMastery = masteryUpdates.get(old.getKnowledgePointId());
                double oldMastery = old.getMasteryScore();
                // 平滑更新：新掌握度 = 60%旧 + 40%模考（避免单次波动过大）
                double smoothed = oldMastery * 0.6 + newMastery * 0.4;
                updated.setMasteryScore(smoothed);
            }
            
            // 重新计算优先级
            PriorityCalculator calculator = new PriorityCalculator();
            KnowledgePointPriority recalculated = calculator.calculate(
                kpService.getById(updated.getKnowledgePointId()),
                task,
                MasteryData.of(updated.getMasteryScore()),
                statsService.getStats(updated.getKnowledgePointId(), task.getSubjectId())
            );
            
            // 保留ID等字段
            recalculated.setId(updated.getId());
            recalculated.setExamTaskId(task.getId());
            recalculated.setSnapshotAt(LocalDateTime.now());
            
            newPriorities.add(recalculated);
            
            // 记录变更
            if (Math.abs(recalculated.getPriorityScore() - old.getPriorityScore()) > 1.0) {
                changes.add(buildChange(old, recalculated));
            }
        }
        
        // 4. 批量保存新快照
        priorityService.batchUpsert(task.getId(), newPriorities);
        
        // 5. 如果有重大变化，触发计划调整
        boolean planAdjusted = false;
        if (hasSignificantChanges(changes)) {
            planAdjusted = adjustPlanAfterRebalance(task, changes);
        }
        
        // 6. 重新预测
        ForecastResult forecast = forecastService.forecast(task, newPriorities);
        
        return RebalanceResult.builder()
            .rebalanced(!changes.isEmpty())
            .changes(changes)
            .planAdjusted(planAdjusted)
            .newForecastScore(forecast.getPredictedScore())
            .build();
    }
    
    /**
     * 判断是否有重大变化需要调整计划
     */
    private boolean hasSignificantChanges(List<RebalanceChange> changes) {
        // P0考点数变化 或 优先级变化超过20
        boolean hasLevelChange = changes.stream()
            .anyMatch(c -> !c.getOldLevel().equals(c.getNewLevel()) 
                        && (c.getOldLevel() == PriorityLevel.P0_CRITICAL 
                            || c.getNewLevel() == PriorityLevel.P0_CRITICAL));
        
        boolean hasBigShift = changes.stream()
            .anyMatch(c -> Math.abs(c.getNewPriority() - c.getOldPriority()) > 20);
        
        return hasLevelChange || hasBigShift;
    }
    
    /**
     * 计划调整：将新P0考点插入冲刺阶段，已掌握考点降级
     */
    private boolean adjustPlanAfterRebalance(ExamTask task, List<RebalanceChange> changes) {
        ExamPrepPhase sprintPhase = phaseService.findByType(task.getId(), ReviewPhase.SPRINT);
        ExamPrepPhase finalPhase = phaseService.findByType(task.getId(), ReviewPhase.FINAL_REVIEW);
        
        boolean adjusted = false;
        
        for (RebalanceChange change : changes) {
            // 新升为P0的考点 → 加入冲刺阶段
            if (change.getNewLevel() == PriorityLevel.P0_CRITICAL 
                && change.getOldLevel() != PriorityLevel.P0_CRITICAL) {
                addKPToPhase(sprintPhase, change.getKnowledgePointId());
                adjusted = true;
            }
            
            // 降为P3的考点 → 移到考前回顾
            if (change.getNewLevel() == PriorityLevel.P3_LOW
                && change.getOldLevel() != PriorityLevel.P3_LOW) {
                removeKPFromPhase(sprintPhase, change.getKnowledgePointId());
                removeKPFromPhase(phaseService.findByType(task.getId(), ReviewPhase.REINFORCEMENT), 
                                  change.getKnowledgePointId());
                addKPToPhase(finalPhase, change.getKnowledgePointId());
                adjusted = true;
            }
        }
        
        if (adjusted) {
            // 重新编排受影响阶段的每日任务
            dailyTaskService.reallocatePhase(task.getId(), sprintPhase.getId());
        }
        
        return adjusted;
    }
}
```

```java
/**
 * 备考效果预测器

public class PrepForecastService {
    
    /**
     * 预测当前备考进度下的预期考试分数
     */
    public ForecastResult forecast(ExamTask task, 
                                    List<KnowledgePointPriority> priorities) {
        double totalExpectedScore = 0;
        double totalMaxScore = 0;
        int completedKP = 0;
        int totalKP = priorities.size();
        
        for (KnowledgePointPriority kp : priorities) {
            double avgExamScore = statsService.getAverageScoreInExam(
                kp.getKnowledgePointId(), task.getExamType());
            
            // 预测掌握度：当前掌握度 + 按计划复习后的预期提升
            double currentMastery = kp.getMasteryScore();
            double expectedImprovement = estimateImprovement(task, kp);
            double predictedMastery = Math.min(1.0, currentMastery + expectedImprovement);
            
            // 预测得分
            double predictedScore = avgExamScore * predictedMastery;
            totalExpectedScore += predictedScore;
            totalMaxScore += avgExamScore;
            
            // 检查是否已有完成记录
            if (hasCompletionRecord(task.getId(), kp.getKnowledgePointId())) {
                completedKP++;
            }
        }
        
        // 计算完成度
        double completionRate = (double) completedKP / totalKP;
        
        // 预测分数（按满分比例缩放）
        int predictedExamScore = (int) Math.round(
            totalExpectedScore / totalMaxScore * task.getFullScore());
        
        // 目标差距
        int targetGap = task.getTargetScore() - predictedExamScore;
        
        // 给出建议
        String advice = generateAdvice(predictedExamScore, task.getTargetScore(), 
                                        completionRate, targetGap);
        
        return ForecastResult.builder()
            .predictedScore(predictedExamScore)
            .targetScore(task.getTargetScore())
            .targetGap(targetGap)
            .completionRate(completionRate)
            .kpCompletionRate((double) completedKP / totalKP)
            .confidence(calculateConfidence(task, priorities))
            .advice(advice)
            .build();
    }
    
    /**
     * 预估通过复习能达到的提升量
     */
    private double estimateImprovement(ExamTask task, KnowledgePointPriority kp) {
        // 基础提升量：从当前掌握度到目标掌握度(0.85)的空间
        double targetMastery = 0.85;
        double gap = targetMastery - kp.getMasteryScore();
        
        if (gap <= 0) return 0;
        
        // 基于剩余时间和该考点的分配时间
        long daysRemaining = ChronoUnit.DAYS.between(LocalDate.now(), task.getExamDate());
        double timeFactor = Math.min(1.0, daysRemaining / 14.0); // 14天可达满效率
        
        // 基于考点难度
        double difficultyFactor = 1.0 - (kp.getWeightScore() / 200.0); // 权重越高越难提升
        
        return gap * 0.7 * timeFactor * difficultyFactor;
    }
    
    private double calculateConfidence(ExamTask task, List<KnowledgePointPriority> priorities) {
        long daysRemaining = ChronoUnit.DAYS.between(LocalDate.now(), task.getExamDate());
        
        // 数据量：掌握度数据越多越自信
        double dataConfidence = Math.min(1.0, priorities.size() / 30.0);
        
        // 时间充足度
        double timeConfidence = Math.min(1.0, daysRemaining / 14.0);
        
        return (dataConfidence + timeConfidence) / 2;
    }
    
    private String generateAdvice(int predicted, int target, 
                                   double completion, int gap) {
        if (predicted >= target) {
            return "按当前进度，预计可达目标分数。建议保持节奏，注意查漏补缺。";
        }
        if (gap <= 5) {
            return "距离目标仅差" + gap + "分，建议聚焦最薄弱的2-3个考点重点突破。";
        }
        if (gap <= 15) {
            return "距离目标差" + gap + "分，建议增加每日备考时长，优先攻克P0级考点。";
        }
        return "距离目标差" + gap + "分，建议适当调整目标或大幅增加备考投入。";
    }
}
```

```java
/**
 * 多考试时间冲突协调器
 * 
 * 当学生同时备考多门考试时，在各考试间合理分配每日时间
 */
public class MultiExamCoordinator {
    
    /**
     * 全局时间分配
     */
    public MultiExamSchedule coordinate(Long studentId, List<ExamTask> activeExams) {
        // 1. 按考试日期排序（最近的优先）
        activeExams.sort(Comparator.comparing(ExamTask::getExamDate));
        
        // 2. 计算每个考试的"紧迫权重"
        Map<Long, Double> urgencyWeights = new HashMap<>();
        double totalUrgency = 0;
        
        for (ExamTask exam : activeExams) {
            long days = ChronoUnit.DAYS.between(LocalDate.now(), exam.getExamDate());
            // 紧迫度 = 1/days × 考试优先级
            double urgency = (1.0 / Math.max(days, 1)) * (exam.getPriority() + 1);
            urgencyWeights.put(exam.getId(), urgency);
            totalUrgency += urgency;
        }
        
        // 3. 按紧迫度权重分配每日总学习时间
        Map<Long, Integer> dailyAllocation = new HashMap<>();
        int totalDailyMinutes = activeExams.stream()
            .mapToInt(ExamTask::getDailyAvailableMinutes)
            .max().orElse(90);
        
        for (ExamTask exam : activeExams) {
            double share = urgencyWeights.get(exam.getId()) / totalUrgency;
            int allocated = (int)(totalDailyMinutes * share);
            dailyAllocation.put(exam.getId(), allocated);
        }
        
        // 4. 生成每日时间表
        return MultiExamSchedule.builder()
            .studentId(studentId)
            .totalDailyMinutes(totalDailyMinutes)
            .examAllocations(dailyAllocation)
            .timeline(buildTimeline(activeExams, dailyAllocation))
            .build();
    }
    
    /**
     * 构建时间线：按日期展示各考试的每日时间分配
     */
    private List<DailyAllocation> buildTimeline(List<ExamTask> exams, 
                                                  Map<Long, Integer> allocations) {
        List<DailyAllocation> timeline = new ArrayList<>();
        
        LocalDate start = LocalDate.now();
        LocalDate end = exams.stream()
            .map(ExamTask::getExamDate)
            .max(Comparator.naturalOrder())
            .orElse(start.plusDays(7));
        
        for (LocalDate date = start; !date.isAfter(end); date = date.plusDays(1)) {
            DailyAllocation dayAlloc = new DailyAllocation();
            dayAlloc.setDate(date);
            
            Map<Long, Integer> examMinutes = new HashMap<>();
            for (ExamTask exam : exams) {
                // 跳过已考完的
                if (date.isAfter(exam.getExamDate())) continue;
                
                // 考试当天不分配备考时间
                if (date.equals(exam.getExamDate())) continue;
                
                examMinutes.put(exam.getId(), allocations.get(exam.getId()));
            }
            
            dayAlloc.setExamMinutes(examMinutes);
            timeline.add(dayAlloc);
        }
        
        return timeline;
    }
}
```

```java
public class FallbackStrategyService {
    
    /**
     * 线性降级计划：按章节顺序均匀分配，不使用复杂优先级算法
     */
    public void generateLinearPlan(Long examTaskId) {
        ExamTask task = examTaskRepo.findById(examTaskId).orElseThrow();
        List<Long> chapterIds = JsonUtils.parseList(task.getScopeChapterIds(), Long.class);
        
        int totalDays = (int) ChronoUnit.DAYS.between(task.getStartDate(), task.getExamDate()) + 1;
        int chaptersPerDay = Math.max(1, (int) Math.ceil(chapterIds.size() / (double) totalDays));
        
        // 简单均分，不做优先级排序
        LocalDate cursor = task.getStartDate();
        for (int i = 0; i < chapterIds.size(); i += chaptersPerDay) {
            int end = Math.min(i + chaptersPerDay, chapterIds.size());
            List<Long> dayChapters = chapterIds.subList(i, end);
            
            for (Long chId : dayChapters) {
                // 为每个章节生成基础复习任务
                createBasicReviewTask(task, cursor, chId);
            }
            cursor = cursor.plusDays(1);
        }
    }
    
    /**
     * 使用过时掌握度数据（当追踪服务不可用时）
     */
    public void generateWithStaleMastery(Long examTaskId) {
        // 使用7天内的最近一次掌握度快照
        MasterySnapshot lastSnapshot = masteryService.getLatestSnapshot(examTaskId, 7);
        if (lastSnapshot != null) {
            priorityService.generateWithGivenMastery(examTaskId, lastSnapshot);
        } else {
            // 完全没有数据 → 假设所有考点掌握度为0.5
            priorityService.generateWithDefaultMastery(examTaskId, 0.5);
        }
    }
}
```

```java
public class BatchPriorityCalculator {
    
    /**
     * 批量获取掌握度 + 批量计算优先级
     * N+1 查询问题 → 2次查询
     */
    @Transactional(readOnly = true)
    public List<KnowledgePointPriority> batchCalculate(Long examTaskId) {
        ExamTask task = examTaskRepo.findById(examTaskId).orElseThrow();
        List<Long> kpIds = JsonUtils.parseList(task.getScopeKnowledgePointIds(), Long.class);

        Map<Long, KPExamStatistics> statsMap = statsService.batchGet(kpIds, task.getSubjectId());
        
        // 批量查询2: 一次性获取所有考点的掌握度
        Map<Long, MasteryData> masteryMap = tracingService.batchGetMastery(
            task.getStudentId(), kpIds);
        
        // 批量查询3: 获取所有考点基础信息
        Map<Long, KnowledgePoint> kpMap = kpService.batchGet(kpIds);
        
        // 本地计算（无IO）
        return kpIds.parallelStream()
            .map(kpId -> {
                KnowledgePoint kp = kpMap.get(kpId);
                MasteryData mastery = masteryMap.getOrDefault(kpId, MasteryData.defaultZero());
                KPExamStatistics stats = statsMap.getOrDefault(kpId, KPExamStatistics.empty());
                
                return calculator.calculate(kp, task, mastery, stats);
            })
            .sorted(Comparator.comparingDouble(KnowledgePointPriority::getPriorityScore).reversed())
            .collect(Collectors.toList());
    }
```

```java
/**
 * 优先级增量更新 - 每日刷新时只更新有变化的考点
 */
public class IncrementalPriorityUpdater {
    
    public void refreshSnapshot(Long examTaskId) {
        // 获取上次快照时间
        LocalDateTime lastSnapshot = priorityService.getLastSnapshotTime(examTaskId);
        
        // 只查询有新答题记录的考点（有数据更新的才需要重算）
        Set<Long> dirtyKpIds = answerRecordRepo.findKpIdsWithRecordsAfter(
            examTaskId, lastSnapshot);
        
        if (dirtyKpIds.isEmpty()) {
            // 没有新数据，仅更新紧迫度因子（因为时间在流逝）
            updateUrgencyFactorOnly(examTaskId);
            return;
        }
        
        // 只重算受影响的考点
        List<KnowledgePointPriority> toUpdate = dirtyKpIds.stream()
            .map(kpId -> recalculateSingle(examTaskId, kpId))
            .collect(Collectors.toList());
        
        priorityService.batchUpsert(examTaskId, toUpdate);
    }
    
    /**
     * 仅更新紧迫度因子（无需查DB，直接内存计算）
     */
    private void updateUrgencyFactorOnly(Long examTaskId) {
        List<KnowledgePointPriority> all = priorityService.getSnapshot(examTaskId);
        ExamTask task = examTaskRepo.findById(examTaskId).orElseThrow();
        
        double newUrgency = new PriorityCalculator().calculateUrgencyFactor(task);
        double oldUrgency = new PriorityCalculator().calculateUrgencyFactor(
            task.toBuilder().examDate(task.getExamDate()).build());
        
        if (Math.abs(newUrgency - oldUrgency) < 0.01) return;  // 变化太小，跳过
        
        // 批量微调优先级分
        double delta = (newUrgency - oldUrgency) * PriorityCalculator.W_URGENCY * 100;
        priorityService.batchAdjustPriority(examTaskId, delta);
    }
}
```

```java
/**
 * 备考引擎权限控制
 */
public class ExamPrepSecurity {
    
    // 权限矩阵
    private static final Map<UserRole, Set<String>> PERMISSIONS = Map.of(
        UserRole.STUDENT, Set.of("CREATE", "VIEW_OWN", "UPDATE_OWN", "GENERATE", "VIEW_TODAY"),
        UserRole.PARENT, Set.of("VIEW_CHILD", "VIEW_DASHBOARD"),
        UserRole.TEACHER, Set.of("VIEW_CLASS", "ADJUST_PRIORITY", "VIEW_DASHBOARD"),
        UserRole.ADMIN, Set.of("*")
    );
    
    public void checkPermission(Long operatorId, UserRole role, 
                                 String action, Long targetStudentId) {
        Set<String> perms = PERMISSIONS.get(role);
        if (perms == null || (!perms.contains(action) && !perms.contains("*"))) {
            throw new ForbiddenException(40301, "无权执行此操作");
        }
        
        // 家长只能查看绑定孩子的数据
        if (role == UserRole.PARENT && action.startsWith("VIEW_CHILD")) {
            if (!parentBindingService.isBound(operatorId, targetStudentId)) {
                throw new ForbiddenException(40301, "未绑定该学生，无法查看");
            }
        }
        
        // 学生只能操作自己的数据
        if (role == UserRole.STUDENT && action.endsWith("_OWN")) {
            if (!operatorId.equals(targetStudentId)) {
                throw new ForbiddenException(40301, "只能操作自己的备考任务");
            }
        }
    }
}
```

### 14.2 遗忘曲线在掌握度衰减中的应用

```java
/**
 * 基于艾宾浩斯遗忘曲线的掌握度衰减模型
 * 
 * 当学生一段时间未练习某考点时，系统自动降低其掌握度
 */
public class ForgettingCurveDecay {
    
    // 艾宾浩斯遗忘曲线参数
    private static final double MEMORY_STABILITY = 0.3;  // s值，越大忘得越快
    
    /**
     * 计算考虑遗忘的当前掌握度
     * @param originalMastery 上次练习时的掌握度
     * @param daysSinceLastPractice 距上次练习天数
     * @return 衰减后的掌握度
     */
    public static double decayedMastery(double originalMastery, int daysSinceLastPractice) {
        if (daysSinceLastPractice <= 0) return originalMastery;
        
        // R = e^(-t/s)，保留率随时间指数衰减
        double retentionRate = Math.exp(-daysSinceLastPractice / 
            (MEMORY_STABILITY * 10 * (0.5 + originalMastery)));
        
        // 掌握度不会低于基线0.1
        return Math.max(0.1, originalMastery * retentionRate);
    }
}
```
