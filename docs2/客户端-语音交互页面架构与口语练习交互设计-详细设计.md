# 客户端-语音交互页面架构与口语练习交互设计

> 版本：v1.0 | 日期：2026-05-28 | 模块负责人：待定

## 1. 概述

### 1.1 模块定位

本文档定义 PrimeTop 客户端语音交互的页面架构、组件设计、交互流程与状态管理。语音交互横跨多个业务场景，是客户端最复杂的交互形态之一。

**上游服务依赖**（已细化，本文不做展开）：
- 语音服务（ASR/TTS）→ 提供识别、合成、发音评测 API
- 英语专项学习与口语陪练 → 提供英语学科业务逻辑
- 文科背诵 → 提供背诵检测业务逻辑
- AI对话引擎 → 提供多轮对话能力

**本文聚焦**：客户端如何将这些后端能力封装为统一的语音交互页面、组件与交互流程。

### 1.2 语音交互场景矩阵

| 场景 | 入口 | 输入方式 | 输出方式 | 学段 | 优先级 |
|------|------|---------|---------|------|--------|
| AI对话语音提问 | AI辅导页 | 语音→ASR→文字 | TTS播报AI回答 | 全学段 | P0 |
| 拍题口述提问 | 拍题页 | 语音→ASR→补充描述 | 文字解析 | 小学+ | P1 |
| 英语口语陪练 | 英语专区/AI辅导 | 实时语音对话 | TTS+发音评测 | 小学+ | P0 |
| 英语单词跟读 | 词汇学习页 | 录音→发音评测 | 评分+纠错反馈 | 小学+ | P0 |
| 背诵检测 | 文科背诵页 | 录音→ASR→对比 | 标注对比结果 | 初中+ | P1 |
| 拼音发音练习 | 拼音识字页 | 录音→发音评测 | 声调/发音评分 | 幼儿 | P1 |
| 课文朗读 | 同步课堂页 | 录音→发音评测 | 流畅度+准确度 | 小学+ | P2 |

### 1.3 设计目标

1. **统一组件化**：所有语音交互场景复用同一套底层组件（录音器、波形条、评分指示器）
2. **适龄适配**：幼儿大按钮+语音引导，高中精准数据展示
3. **低延迟感知**：录音开始 ≤100ms 反馈，ASR 实时回显 ≤300ms
4. **弱网容错**：离线录音+本地缓存+网络恢复后上传
5. **隐私安全**：录音文件不持久化到磁盘（仅内存缓存），上传后即删

#### 4.1.4 波纹扩散动画

录音状态时，按钮外围绘制 3 层波纹，波纹半径与当前音量成正比：

```dart
class _RipplePainter extends CustomPainter {
  final double volume;       // 当前音量 0.0-1.0
  final Color color;
  final List<double> phases; // 3 个波纹的动画相位 0.0-1.0

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final baseRadius = size.width / 2;

    for (int i = 0; i < 3; i++) {
      final phase = phases[i];
      final radius = baseRadius + (baseRadius * 0.8 * phase) * (0.5 + volume * 0.5);
      final opacity = (1.0 - phase) * 0.3 * volume;
      final paint = Paint()
        ..color = color.withOpacity(opacity)
        ..style = PaintingStyle.stroke
        ..strokeWidth = 2.0;
      canvas.drawCircle(center, radius, paint);
    }
  }
}
```

### 4.2 WaveformPainter — 波形可视化

#### 4.2.1 组件说明

实时绘制录音/播放音频的波形条。采用柱状频谱风格（非连续波形），每帧从录音器获取 16 或 32 个频段的振幅数据。

#### 4.2.2 组件属性

```dart
class WaveformPainter extends StatelessWidget {
  /// 频段振幅数据 0.0-1.0，长度通常为 16/32
  final List<double> amplitudes;

  /// 波形方向
  final WaveformDirection direction;

  /// 柱状条数量（默认取 amplitudes.length）
  final int? barCount;

  /// 柱状条宽度
  final double barWidth;

  /// 柱状条间距
  final double barGap;

  /// 颜色（支持渐变）
  final Color activeColor;
  final Color inactiveColor;

  /// 是否显示镜像（上下对称）
  final bool mirror;

  /// 圆角半径
  final double borderRadius;

  /// 适配的年龄主题
  final AgeGroupTheme? ageTheme;
}

enum WaveformDirection {
  horizontal,  // 从左到右（聊天输入条）
  vertical,    // 从下到上（口语练习页）
  radial,      // 中心向外扩散（大按钮环绕）
}
```

#### 4.2.3 分龄波形样式

| 学段 | 样式 | 说明 |
|------|------|------|
| 幼儿 | 宽柱条(6px)、大间距(4px)、高圆角(8px)、鲜艳色 | 简洁直观 |
| 小学 | 中柱条(4px)、中间距(3px)、中圆角(4px)、彩色渐变 | 活泼有趣 |
