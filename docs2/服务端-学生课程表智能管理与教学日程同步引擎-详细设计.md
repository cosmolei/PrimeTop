# 服务端 - 学生课程表智能管理与教学日程同步引擎 详细设计

> 版本: v1.0 | 创建日期: 2026-06-20 | 状态: 初稿

---

## 1. 模块概述

### 1.1 功能定位

学生课程表智能管理与教学日程同步引擎是 PrimeTop **日常学习节奏的基础设施**，负责管理学生的周课程表（timetable），包括课时段定义、具体课程项安排、临时调课/代课处理、课程表图片 OCR 导入、教务系统对接等功能，并向其他模块输出结构化的"此刻正在上的课"和"接下来要上的课"等上下文信息。

**核心职责：**

| 能力 | 说明 |
|------|------|
| 周课表管理 | 学生个人每周课程表 CRUD，支持固定课表和轮转课表 |
| 课时段配置 | 按学校定义每日节次时间（早读、上午 N 节、午休、下午 N 节、晚自习） |
| 课程项管理 | 具体每一节课的学科、教师、教室、班级信息 |
| 调课/代课 | 支持临时调课、代课、停课通知处理 |
| 多维度课表 | 支持走班制（不同学科不同班级）、分层教学等高中场景 |
| 图片导入 | 学生拍摄课程表照片，OCR + LLM 解析自动生成结构化课表 |
| 教务系统对接 | 支持通过学校授权或教师端推送导入班级课表 |
| 课表查询服务 | 对外提供"当前课""下一节课""今日课程列表""本周课程"等查询 API |
| 联动输出 | 为学习推荐、学习提醒、学情分析等模块提供课表上下文 |

**不在本服务范围内：**

| 事项 | 归属模块 |
|------|----------|
| 教学进度管理（第几章第几节） | `服务端-学校教学进度同步与课堂学习内容智能预对齐引擎` |
| 日历事件（考试、活动、假期） | `服务端-学习日历事件与考试日程管理服务` |
| 推送消息发送执行 | `消息与推送服务` |
| 学习内容推荐编排 | `服务端-首页内容卡片推荐与聚合编排服务` |
| 学期起止时间管理 | `学期与学年管理服务` |

### 1.3 术语定义

| 术语 | 含义 |
|------|------|
| Timetable | 课程表，一个学生某学期的完整周课表 |
| Period | 课时段，一天中的一个上课时间段，如"第一节 08:00-08:45" |
| Slot | 课程项，课时段上具体安排的课程，如"周一第二节·数学·王老师·三班" |
| Rotation | 轮转规则，支持单周/双周轮转、AB 日轮转等 |
| Substitution | 调课/代课记录，对原定 Slot 的临时变更 |
| CurrentContext | 当前课程上下文，包含"正在上的课"和"下一节课"信息 |

## 2. 数据结构

### 2.1 课时段模板表 `period_templates`

定义一个学校或学生自定义的每日课时间段配置。

```sql
CREATE TABLE period_templates (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '所属用户（自定义模板）或 NULL（系统默认模板）',
    school_id       BIGINT COMMENT '学校ID（学校统一模板）',
    name            VARCHAR(50) NOT NULL COMMENT '模板名称，如"高中标准作息"',
    academic_level  VARCHAR(20) NOT NULL COMMENT '学段：kindergarten/primary/middle/high',
    is_default      TINYINT DEFAULT 0 COMMENT '是否默认模板',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_user (user_id),
    INDEX idx_school (school_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课时段模板';
```

### 2.2 课时段定义表 `period_definitions`

每个模板下的具体节次定义。

```sql
CREATE TABLE period_definitions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_id     BIGINT NOT NULL COMMENT '所属模板ID',
    period_index    INT NOT NULL COMMENT '节次序号，从1开始（1=第一节）',
    period_type     VARCHAR(20) NOT NULL COMMENT '类型：morning_read/morning/noon_break/afternoon/evening_study/recess',
    name            VARCHAR(50) NOT NULL COMMENT '显示名称，如"第一节"',
    start_time      TIME NOT NULL COMMENT '开始时间 HH:MM:SS',
    end_time        TIME NOT NULL COMMENT '结束时间 HH:MM:SS',
    allow_attendance TINYINT DEFAULT 1 COMMENT '该时段是否排课（课间=0）',

    UNIQUE KEY uk_template_period (template_id, period_index),
    INDEX idx_template (template_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课时段定义';
```

### 2.3 学生课程表主表 `student_timetables`

```sql
CREATE TABLE student_timetables (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    semester_id     BIGINT NOT NULL COMMENT '学期ID',
    template_id     BIGINT NOT NULL COMMENT '关联课时段模板ID',
    name            VARCHAR(100) DEFAULT NULL COMMENT '课表自定义名称',
    rotation_type   VARCHAR(20) DEFAULT 'weekly' COMMENT '轮转类型：weekly/biweekly/ab_day/custom',
    rotation_config JSON DEFAULT NULL COMMENT '轮转配置，详见 2.5 节',
    source          VARCHAR(20) DEFAULT 'manual' COMMENT '创建来源：manual/ocr_import/teacher_push/school_sync',
    status          VARCHAR(20) DEFAULT 'active' COMMENT '状态：draft/active/archived',
    effective_from  DATE NOT NULL COMMENT '生效开始日期',
    effective_to    DATE COMMENT '生效结束日期（NULL表示学期结束）',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_user_semester (user_id, semester_id),
    INDEX idx_user (user_id),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生课程表主表';
```

### 2.4 课程项表 `timetable_slots`

每节课的具体安排，按"周几+第几节"定位。

```sql
CREATE TABLE timetable_slots (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    timetable_id    BIGINT NOT NULL COMMENT '所属课表ID',
    day_of_week     INT NOT NULL COMMENT '星期几：1=周一 ... 7=周日',
    period_index    INT NOT NULL COMMENT '节次序号（对应 period_definitions.period_index）',
    subject_id      BIGINT COMMENT '学科ID',
    subject_name    VARCHAR(50) NOT NULL COMMENT '学科名称（冗余，便于展示）',
    teacher_name    VARCHAR(50) COMMENT '授课教师姓名',
    classroom       VARCHAR(50) COMMENT '教室/场地',
    class_group     VARCHAR(50) COMMENT '班级/教学班组（走班制场景）',
    week_pattern    VARCHAR(20) DEFAULT 'all' COMMENT '适用周次：all/odd/even/a/b (配合轮转类型)',
    is_persistent   TINYINT DEFAULT 1 COMMENT '1=固定排课 0=临时插入',
    note            VARCHAR(200) COMMENT '备注',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_tt_day_period_week (timetable_id, day_of_week, period_index, week_pattern),
    INDEX idx_timetable (timetable_id),
    INDEX idx_day_period (timetable_id, day_of_week, period_index)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='课程项';
```

### 2.5 轮转配置 `rotation_config`（JSON 字段）

支持多种排课轮转模式，存储在 `student_timetables.rotation_config` 中。

#### 单周轮转（weekly）

```json
{
  "type": "weekly",
  "description": "每周重复相同课表"
}
```

#### 单双周轮转（biweekly）

```json
{
  "type": "biweekly",
  "oddWeekSlots": [
    {"dayOfWeek": 1, "periodIndex": 5, "subjectName": "体育", "teacherName": "刘老师"}
  ],
  "evenWeekSlots": [
    {"dayOfWeek": 1, "periodIndex": 5, "subjectName": "音乐", "teacherName": "陈老师"}
  ]
}
```

#### AB 日轮转（ab_day）

```json
{
  "type": "ab_day",
  "pattern": "ABABBA",
  "weekStart": "2026-09-01",
  "dayASlots": [
    {"dayOfWeek": 1, "periodIndex": 1, "subjectName": "物理"},
    {"dayOfWeek": 1, "periodIndex": 2, "subjectName": "物理"}
  ],
  "dayBSlots": [
    {"dayOfWeek": 1, "periodIndex": 1, "subjectName": "化学"},
    {"dayOfWeek": 1, "periodIndex": 2, "subjectName": "化学"}
  ]
}
```

### 2.6 调课/代课记录表 `timetable_substitutions`

```sql
CREATE TABLE timetable_substitutions (
    id                 BIGINT PRIMARY KEY AUTO_INCREMENT,

    new_subject_name   VARCHAR(50) COMMENT '新学科（调课时使用）',
    new_classroom      VARCHAR(50) COMMENT '新教室',
    new_period_index   INT COMMENT '新节次（调时段时使用）',
    new_day_of_week    INT COMMENT '新星期（调日时使用）',
    reason             VARCHAR(200) COMMENT '调课原因',
    source             VARCHAR(20) DEFAULT 'manual' COMMENT '来源：manual/teacher_push/school_sync',
    status             VARCHAR(20) DEFAULT 'pending' COMMENT 'pending/confirmed/rejected',
    created_at         DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at         DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_tt_date (timetable_id, effective_date),
    INDEX idx_original_slot (original_slot_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='调课/代课记录';
```

```
PUT /api/v1/timetable/{timetableId}/slots
```

**Request Body:**

```json
    {
      "dayOfWeek": 1,
      "periodIndex": 2,
      "subjectName": "数学",
      "subjectId": 10,
      "teacherName": "王老师",

      "teacherName": "赵老师",
```

| mergeMode | 说明 |

| `upsert` | 逐条 upsert，按 (dayOfWeek, periodIndex, weekPattern) 唯一键合并 |

### 3.2 课时段模板 API

#### 3.2.1 获取推荐模板列表

```
GET /api/v1/timetable/templates/recommended?academic_level=high
```

返回系统预设的课时段模板，供学生初始化时选择。

#### 3.2.2 自定义课时段

```
POST /api/v1/timetable/templates
PUT /api/v1/timetable/templates/{templateId}/periods
```

学生可基于推荐模板修改，添加/删除节次，调整时间。

### 3.3 课表导入 API

#### 3.3.1 OCR 图片导入

```
POST /api/v1/timetable/import/ocr
Content-Type: multipart/form-data
```

**Parameters:**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| image | File | 是 | 课程表照片 |
| semester_id | Long | 是 | 导入到哪个学期 |
| academic_level | String | 否 | 学段提示（提升 OCR 准确率） |

**Response（异步，返回任务ID）:**

```json
{
  "code": 0,
  "data": {
    "taskId": "imp_20260620_001",
    "status": "processing",
    "estimatedSeconds": 8
  }
}
```

```
GET /api/v1/timetable/import/{taskId}
```

```json
{
  "code": 0,
  "data": {
```

### 4.1 周课表解析引擎

根据日期、轮转规则和调课记录，计算出任意一天的实际课程安排。

```java
/**
 * 周课表解析引擎
 * 核心：给定日期 -> 计算出当天的课程列表（含轮转、调课）
 */
@Service
public class TimetableResolver {

    @Autowired
    private TimetableSlotMapper slotMapper;
    @Autowired
    private TimetableSubstitutionMapper substitutionMapper;
    @Autowired
    private SemesterService semesterService;

    /**
     * 解析某天的实际课程列表
     *
     * @param userId 用户ID
     * @param date   目标日期
     * @return 当天按节次排序的课程列表
     */
    public List<ResolvedSlot> resolveDaySlots(Long userId, LocalDate date) {
        // 1. 获取当前生效的课表
        StudentTimetable timetable = getActiveTimetable(userId, date);
        if (timetable == null) {
            return Collections.emptyList();
        }

        // 2. 计算星期几和轮转周次
        int dayOfWeek = date.getDayOfWeek().getValue();
        WeekPattern effectivePattern = resolveWeekPattern(timetable, date);

        // 3. 查询基础课程项
        List<TimetableSlot> baseSlots = slotMapper.findByDayAndPattern(
            timetable.getId(), dayOfWeek, effectivePattern
        );

        // 4. 查询当日调课记录
        List<TimetableSubstitution> subs = substitutionMapper.findByDateAndStatus(
            timetable.getId(), date, "confirmed"
        );

        // 5. 合并调课到基础课表
        return mergeSubstitutions(baseSlots, subs, date);
    }

    /**
     * 解析轮转周次模式
     */
    private WeekPattern resolveWeekPattern(StudentTimetable tt, LocalDate date) {
        if ("weekly".equals(tt.getRotationType())) {
            return WeekPattern.ALL;

        } else if ("biweekly".equals(tt.getRotationType())) {
            int weekOfYear = date.get(WeekFields.ISO.weekOfYear());
            int semesterWeek = semesterService.getSemesterWeekNumber(
                tt.getSemesterId(), date
            );
            return semesterWeek % 2 == 1 ? WeekPattern.ODD : WeekPattern.EVEN;

        } else if ("ab_day".equals(tt.getRotationType())) {
            // AB日轮转：根据 pattern 字符串计算当天是 A 日还是 B 日
            RotationConfig config = parseConfig(tt.getRotationConfig());
            int dayOffset = (int) ChronoUnit.DAYS.between(
                config.getWeekStart(), date
            );
            if (dayOffset < 0) return WeekPattern.ALL;
            int patternIndex = dayOffset % config.getPattern().length();
            char dayType = config.getPattern().charAt(patternIndex);
            return dayType == 'A' ? WeekPattern.A : WeekPattern.B;
        }
        return WeekPattern.ALL;
    }

    /**
     * 合并调课记录
     */
    private List<ResolvedSlot> mergeSubstitutions(
            List<TimetableSlot> baseSlots,
            List<TimetableSubstitution> subs,
            LocalDate date) {

        // 构建调课索引：originalSlotId -> substitution
        Map<Long, TimetableSubstitution> subBySlotId = subs.stream()
            .collect(Collectors.toMap(
                TimetableSubstitution::getOriginalSlotId,
                s -> s,
                (a, b) -> b // 重复取最后一条
            ));

        List<ResolvedSlot> result = new ArrayList<>();
        Set<Long> processedSlotIds = new HashSet<>();

        // 处理基础课表中的课程项
        for (TimetableSlot slot : baseSlots) {
            TimetableSubstitution sub = subBySlotId.get(slot.getId());
            if (sub != null) {
                switch (sub.getChangeType()) {
                    case "cancel":
                        processedSlotIds.add(slot.getId());
                        continue; // 跳过（停课）
                    case "substitute_teacher":
                        result.add(toResolved(slot, sub.getNewTeacherName(), date));
                        break;
                    case "change_subject":
                        result.add(toResolvedWithSubject(slot, sub.getNewSubjectName(),
                            sub.getNewClassroom(), date));
                        break;
                    case "change_time":
                        // 时间调整的课项放到新位置
                        result.add(toResolvedAtNewTime(slot, sub, date));
                        break;
                }
                processedSlotIds.add(slot.getId());
            } else {
                result.add(toResolved(slot, date));
            }
        }

        // 处理临时插入的课程（add_temp 类型，不对应原 slot）
        subs.stream()
            .filter(s -> "add_temp".equals(s.getChangeType()))
            .forEach(s -> result.add(ResolvedSlot.tempFrom(s, date)));

        // 按节次排序
        result.sort(Comparator.comparingInt(ResolvedSlot::getPeriodIndex));
        return result;
    }
}
```

```java
/**
 * 当前课程上下文计算服务
 * 缓存优先，过期后重新计算
 */
@Service
public class CurrentContextService {

    private static final String CACHE_KEY_PREFIX = "timetable:current_ctx:";
    private static final int CACHE_TTL_SECONDS = 300; // 5分钟兜底，实际按下课时间动态设置

    @Autowired
    private TimetableResolver resolver;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private PeriodDefinitionMapper periodMapper;

    /**
     * 获取当前课程上下文（带缓存）
     */
    public CurrentClassContext getCurrentContext(Long userId) {
        String key = CACHE_KEY_PREFIX + userId;
        String cached = redisTemplate.opsForValue().get(key);
        if (cached != null) {
            CurrentClassContext ctx = JSON.parseObject(cached, CurrentClassContext.class);
            // 检查缓存是否仍然有效
            if (ctx.getAsOf().isAfter(LocalDateTime.now().minusMinutes(1))) {
                return ctx;
            }
        }
        return computeAndCache(userId);
    }

    private CurrentClassContext computeAndCache(Long userId) {
        LocalDate today = LocalDate.now();
        List<ResolvedSlot> daySlots = resolver.resolveDaySlots(userId, today);
        if (daySlots.isEmpty()) {
            return CurrentClassContext.noClassToday();
        }

        LocalTime now = LocalTime.now();

        // 获取今日节次时间定义
        List<PeriodDefinition> periods = periodMapper.findByTemplate(
            resolver.getTemplateId(userId, today)
        );
        Map<Integer, PeriodDefinition> periodMap = periods.stream()
            .collect(Collectors.toMap(PeriodDefinition::getPeriodIndex, p -> p));

        // 查找当前正在上的课
        ResolvedSlot currentSlot = null;
        PeriodDefinition currentPeriod = null;
        for (ResolvedSlot slot : daySlots) {
            PeriodDefinition pd = periodMap.get(slot.getPeriodIndex());
            if (pd == null) continue;
            if (!now.isBefore(pd.getStartTime()) && now.isBefore(pd.getEndTime())) {
                currentSlot = slot;
                currentPeriod = pd;
                break;
            }
        }

        // 查找下一节课
        ResolvedSlot nextSlot = null;
        PeriodDefinition nextPeriod = null;
        if (currentSlot != null) {
            boolean foundCurrent = false;
            for (ResolvedSlot slot : daySlots) {
                if (foundCurrent) {
                    PeriodDefinition pd = periodMap.get(slot.getPeriodIndex());
                    if (pd != null && pd.getAllowAttendance() == 1) {
                        nextSlot = slot;
                        nextPeriod = pd;
                        break;
                    }
                }
                if (slot.equals(currentSlot)) {
                    foundCurrent = true;
                }
            }
        } else {
            // 不在上课时间，找今日接下来的第一节课
            for (ResolvedSlot slot : daySlots) {
                PeriodDefinition pd = periodMap.get(slot.getPeriodIndex());
                if (pd != null && now.isBefore(pd.getStartTime())) {
                    nextSlot = slot;
                    nextPeriod = pd;
                    break;
                }
            }
        }

        // 计算统计信息
        int completed = 0, upcoming = 0;
        for (ResolvedSlot slot : daySlots) {
            PeriodDefinition pd = periodMap.get(slot.getPeriodIndex());
            if (pd == null) continue;
            if (now.isAfter(pd.getEndTime())) completed++;
            else if (!now.isBefore(pd.getStartTime()) && now.isBefore(pd.getEndTime())) {
                // in progress, skip
            } else if (now.isBefore(pd.getStartTime())) upcoming++;
        }

        CurrentClassContext ctx = CurrentClassContext.builder()
            .currentSlot(toContextSlot(currentSlot, currentPeriod, now))
            .nextSlot(toContextSlot(nextSlot, nextPeriod, now))
            .todayCompletedCount(completed)
            .todayUpcomingCount(upcoming)
            .todayTotalCount(daySlots.size())
            .asOf(LocalDateTime.now())
            .build();

        // 动态设置 TTL：到当前课时段结束为止
        int ttl = computeTtlSeconds(currentPeriod, nextPeriod, now);
        redisTemplate.opsForValue().set(
            CACHE_KEY_PREFIX + userId,
            JSON.toJSONString(ctx),
            ttl,
            TimeUnit.SECONDS
        );

        return ctx;
    }

    private int computeTtlSeconds(PeriodDefinition current, PeriodDefinition next, LocalTime now) {
        if (current != null) {
            // 上课中：缓存到下课
            long secondsUntilEnd = Duration.between(now, current.getEndTime()).getSeconds();
            return (int) Math.max(30, Math.min(secondsUntilEnd + 5, CACHE_TTL_SECONDS));
        }
        if (next != null) {
            // 课间：缓存到下节课开始
            long secondsUntilStart = Duration.between(now, next.getStartTime()).getSeconds();
            return (int) Math.max(30, Math.min(secondsUntilStart + 5, CACHE_TTL_SECONDS));
        }
        // 无课：缓存 30 分钟
        return 1800;
    }
}
```

```java
        );

        Map<String, String> aliasMap = Map.of(
            "语", "语文", "数", "数学", "英", "英语", "外", "英语",
            "物", "物理", "化", "化学", "生", "生物",
            "政", "政治", "史", "历史", "地", "地理",
            "体", "体育", "音", "音乐", "美", "美术",

        );

        for (TimetableSlotDTO slot : result.getSlots()) {
            // 学科名标准化
            String subject = slot.getSubjectName();
            if (subject != null) {
                subject = subject.trim();
                if (aliasMap.containsKey(subject)) {
                    slot.setSubjectName(aliasMap.get(subject));
                }

        for (Map.Entry<String, List<TimetableSlotDTO>> entry : grouped.entrySet()) {
            if (entry.getValue().size() > 1) {
                entry.getValue().forEach(s -> s.setNeedsReview(true));
            }
        }
    }
```

```java
/**
 * 课程项冲突检测器
 */
@Service
public class SlotConflictDetector {

    /**
     * 检查新增/修改的课程项是否与现有课程冲突
     */
    public List<ConflictWarning> detectConflicts(
            Long timetableId,
            TimetableSlot newSlot,
            List<TimetableSlot> existingSlots) {

        List<ConflictWarning> warnings = new ArrayList<>();

        for (TimetableSlot existing : existingSlots) {
            if (Objects.equals(existing.getDayOfWeek(), newSlot.getDayOfWeek())
                    && Objects.equals(existing.getPeriodIndex(), newSlot.getPeriodIndex())
                    && weekPatternOverlaps(existing.getWeekPattern(), newSlot.getWeekPattern())) {

                if (Objects.equals(existing.getId(), newSlot.getId())) {
                    continue; // 同一条记录，跳过
                }

                ConflictWarning warning = ConflictWarning.builder()
                    .type("time_overlap")
                    .message(String.format(
                        "%s 第%d节 已排了 %s（%s），是否替换？",
                        getDayName(newSlot.getDayOfWeek()),
                        newSlot.getPeriodIndex(),
                        existing.getSubjectName(),
                        existing.getTeacherName()
                    ))
                    .conflictingSlotId(existing.getId())
                    .action("replace_or_cancel")
                    .build();
                warnings.add(warning);
            }
        }

        return warnings;
    }

    /**
     * 全局校验：检查课表完整性
     */
    public TimetableValidationResult validate(Long timetableId) {
        List<TimetableSlot> allSlots = slotMapper.findByTimetableId(timetableId);
        StudentTimetable tt = timetableMapper.selectById(timetableId);

        TimetableValidationResult result = new TimetableValidationResult();

        // 1. 检查是否有"空天"（某天完全没课）
        Set<Integer> daysWithSlots = allSlots.stream()
            .map(TimetableSlot::getDayOfWeek)
            .collect(Collectors.toSet());
        for (int d = 1; d <= 5; d++) {
            if (!daysWithSlots.contains(d)) {
                result.addWarning("day_empty", d, getDayName(d) + " 没有任何课程，确认是否正确？");
            }
        }

        // 2. 检查是否有长时间空堂
        List<PeriodDefinition> periods = periodMapper.findByTemplate(tt.getTemplateId());
        Map<Integer, PeriodDefinition> periodMap = periods.stream()
            .collect(Collectors.toMap(PeriodDefinition::getPeriodIndex, p -> p));

        Map<Integer, List<TimetableSlot>> byDay = allSlots.stream()
            .collect(Collectors.groupingBy(TimetableSlot::getDayOfWeek));

        for (Map.Entry<Integer, List<TimetableSlot>> entry : byDay.entrySet()) {
            List<TimetableSlot> daySlots = entry.getValue().stream()
                .sorted(Comparator.comparingInt(TimetableSlot::getPeriodIndex))
                .collect(Collectors.toList());

            for (int i = 0; i < daySlots.size() - 1; i++) {
                PeriodDefinition current = periodMap.get(daySlots.get(i).getPeriodIndex());
                PeriodDefinition next = periodMap.get(daySlots.get(i + 1).getPeriodIndex());
                if (current != null && next != null) {
                    long gapMinutes = Duration.between(
                        current.getEndTime(), next.getStartTime()
                    ).toMinutes();
                    // 排除午休等正常间隔
                    if (gapMinutes > 120 && current.getPeriodType().equals("morning")
                            && next.getPeriodType().equals("afternoon")) {
                        continue;
                    }
                    if (gapMinutes > 120) {
                        result.addWarning("long_gap",
                            entry.getKey(),
                            String.format("%s %s 后有 %d 分钟空堂",
                                getDayName(entry.getKey()),
                                current.getName(),
                                gapMinutes)
                        );
                    }
                }
            }
        }

        // 3. 检查每周总课时是否合理
        int totalPeriods = allSlots.size();
        String level = tt.getAcademicLevel();
        if ("primary".equals(level) && (totalPeriods < 20 || totalPeriods > 35)) {
            result.addWarning("total_count", null,
                "小学每周 " + totalPeriods + " 节课，请确认是否完整");
        } else if ("middle".equals(level) && (totalPeriods < 25 || totalPeriods > 40)) {
            result.addWarning("total_count", null,
                "初中每周 " + totalPeriods + " 节课，请确认是否完整");
        } else if ("high".equals(level) && (totalPeriods < 30 || totalPeriods > 45)) {
            result.addWarning("total_count", null,
                "高中每周 " + totalPeriods + " 节课，请确认是否完整");
        }

        return result;
    }

    private boolean weekPatternOverlaps(String a, String b) {
        if ("all".equals(a) || "all".equals(b)) return true;
        return Objects.equals(a, b);
    }
}
```

```java
                    .deeplink("primetop://subject/" + slot.getSubjectId())
```

```java
@RestControllerAdvice
public class TimetableExceptionHandler {

    @ExceptionHandler(SlotConflictException.class)
    public ResponseEntity<ApiResponse<ConflictResolution>> handleConflict(
            SlotConflictException ex) {
        return ResponseEntity.status(HttpStatus.CONFLICT)
            .body(ApiResponse.error("TT_003", ex.getMessage())
                .withData(ConflictResolution.builder()
                    .conflictingSlot(ex.getExistingSlot())
                    .newSlot(ex.getNewSlot())
                    .resolution("replace_or_cancel")
                    .build())
                .build());
    }

    @ExceptionHandler(OcrImportFailedException.class)
    public ResponseEntity<ApiResponse<Void>> handleOcrFailed(
            OcrImportFailedException ex) {
        log.error("OCR import failed", ex);
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
            .body(ApiResponse.error("TT_006",
                "课程表图片识别失败，请尝试重新拍照或手动录入"));
```

### 7.3 容错与降级策略

| 场景 | 策略 |
|------|------|
| Redis 缓存不可用 | 直接查 DB，日志告警，不影响正常功能 |
| OCR 服务超时 | 返回 processing 状态，前端轮询（最长等待 30s），超时提示用户手动录入 |
| LLM 解析失败 | 回退到纯 OCR 文本 + 规则匹配（正则提取学科关键词），标记低置信度 |
| 调课同步推送失败 | 本地重试 3 次（间隔 5s/30s/120s），失败后记录到补偿队列，用户端展示"部分调课可能未同步"提示 |
| RPC 查询超时 | 返回最近一次缓存结果（stale but available），TTL 放宽到 10 分钟 |

## 8. 性能优化

### 8.1 缓存策略

```
缓存层级：
1. Redis - 当前课程上下文缓存
   Key:  timetable:current_ctx:{userId}
   TTL:  动态（到下课/上课为止，最长 5 分钟兜底）

2. Redis - 周课表缓存
   Key:  timetable:week_slots:{userId}:{weekStart}
   TTL:  1 小时（调课变更时主动失效）

3. 本地缓存 (Caffeine) - 课时段模板
   Key:  template:{templateId}
   TTL:  30 分钟
   原因：模板数据变更极少，无需频繁查 DB
```

### 8.3 批量导入优化

教师端推送班级课表时，可能涉及 40-60 名学生同时更新。

```java
/**
 * 批量复制班级课表到学生个人课表
 */
@Transactional(rollbackFor = Exception.class)
public void batchPushClassTimetable(Long classId, Long sourceTimetableId, Long semesterId) {
    // 1. 查询班级内所有学生
    List<Long> studentIds = classService.getStudentUserIds(classId);

    // 2. 批量创建/更新学生课表
    List<StudentTimetable> timetables = studentIds.stream()
        .map(sid -> {
            StudentTimetable tt = new StudentTimetable();
            tt.setUserId(sid);
            tt.setSemesterId(semesterId);
            tt.setTemplateId(sourceTimetable.getTemplateId());
            tt.setSource("teacher_push");
            tt.setStatus("active");
            tt.setEffectiveFrom(semesterService.getStartDate(semesterId));
            return tt;
        })
        .collect(Collectors.toList());

    // 批量插入（冲突时更新）
    timetableMapper.batchUpsert(timetables);

    // 3. 批量复制课程项
    List<TimetableSlot> sourceSlots = slotMapper.findByTimetableId(sourceTimetableId);
    List<TimetableSlot> batchSlots = new ArrayList<>();

    for (StudentTimetable tt : timetables) {
        for (TimetableSlot src : sourceSlots) {
            TimetableSlot copy = src.copy();
            copy.setTimetableId(tt.getId());
            batchSlots.add(copy);
        }
    }

    // 分批插入（每批 500 条）
    batchInsert(batchSlots, 500);

    // 4. 批量失效缓存
    studentIds.forEach(sid ->
        redisTemplate.delete("timetable:current_ctx:" + sid)
    );
}
```
