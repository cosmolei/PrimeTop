# 管理后台 - 积分商城与虚拟经济运营管理工作台 详细设计

## 1. 概述

### 1.1 模块定位

积分商城与虚拟经济运营管理工作台是 PrimeTop 管理后台的核心运营模块之一，面向运营人员、内容运营和财务管理人员，提供积分获取规则配置、商城商品管理、实物奖品库存与发货、兑换订单处理、虚拟经济健康度监控、用户账户管理与纠纷处理等全链路后台能力。

本工作台是对后端「积分获取规则计算与虚拟资产交易结算服务」和「积分与虚拟经济体系」的前端编排层，将分散的服务端虚拟经济能力聚合为运营人员可直接操作的统一管理界面。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 全链路商品管理 | 虚拟道具、装扮、内容解锁、实物奖品的创建、定价、上下架全流程可视 |
| 经济健康可控 | 学币产出与消耗实时监控，通胀/通缩预警自动触发 |
| 实物履约闭环 | 实物奖品从库存管理→订单审核→发货→签收的完整履约链路 |
| 规则灵活配置 | 积分获取规则、等级体系、过期策略可视化配置，热更新生效 |
| 安全与防滥用 | 高危操作多级审批，异常账户自动识别，手动调账全程审计 |
| 纠纷处理高效 | 用户客诉→订单查询→退款/补发的一站式处理流程 |

### 1.3 适用范围

| 角色 | 使用场景 |
| --- | --- |
| 运营专员 | 日常商品上下架、价格调整、活动配置 |
| 运营主管 | 审核商品发布、审批大批量调账、监控经济健康度 |
| 仓储/物流对接人 | 实物奖品库存管理、发货信息确认、物流追踪 |
| 财务人员 | 积分经济对账、实物奖品成本核算、报表导出 |
| 客服人员 | 兑换订单查询、用户积分流水查询、退款补发处理 |

### 3.1 积分获取规则配置表 `points_earning_rule`

> 管理后台可视化的规则配置，对应后端规则引擎的规则定义。

```sql
CREATE TABLE points_earning_rule (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT,
    rule_code         VARCHAR(40) NOT NULL UNIQUE COMMENT '规则编码（行为编码）如 DAILY_LOGIN',
    rule_name         VARCHAR(80) NOT NULL COMMENT '规则名称',
    rule_group        VARCHAR(20) NOT NULL COMMENT '分组: DAILY/STUDY/PRACTICE/SOCIAL/SPECIAL',
    currency_type     VARCHAR(10) NOT NULL COMMENT '奖励货币: COIN/EXP/STAR',
    reward_amount     INT NOT NULL COMMENT '单次奖励数量',
    daily_cap         INT NOT NULL DEFAULT 0 COMMENT '每日上限（0=无限制）',
    weekly_cap        INT NOT NULL DEFAULT 0 COMMENT '每周上限（0=无限制）',
    monthly_cap       INT NOT NULL DEFAULT 0 COMMENT '每月上限（0=无限制）',
    target_segment    JSON COMMENT '适用人群: {"stage":["preschool","primary"],"member_only":false}',
    condition_config  JSON COMMENT '触发条件: {"min_duration_sec":10,"accuracy_threshold":0.8}',
    bonus_config      JSON COMMENT '连签/阶梯奖励: {"streak_bonus":{"7":50,"30":200}}',
    status            VARCHAR(10) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/DISABLED',
    effective_from    DATETIME DEFAULT NULL COMMENT '生效开始时间（NULL=立即）',
    effective_to      DATETIME DEFAULT NULL COMMENT '生效结束时间（NULL=永久）',
    priority          INT DEFAULT 50 COMMENT '优先级（多规则冲突时）',
    description       VARCHAR(256) DEFAULT NULL COMMENT '规则说明（运营内部）',
    version           INT NOT NULL DEFAULT 1 COMMENT '规则版本号',
    created_by        BIGINT NOT NULL COMMENT '创建人',
    updated_by        BIGINT DEFAULT NULL COMMENT '最后修改人',
    created_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_group_status (rule_group, status),
    INDEX idx_currency (currency_type, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='积分获取规则配置';
```

## 4. 页面与功能详细设计

### 4.1 经济概览仪表盘

#### 4.1.1 核心指标卡片

| 指标 | 说明 | 数据来源 |
| --- | --- | --- |
| 今日学币产出 | 全平台今日发放学币总量 | `currency_transaction` WHERE change_amount > 0 AND DATE(created_at) = TODAY |
| 今日学币消耗 | 全平台今日消耗学币总量 | `currency_transaction` WHERE change_amount < 0 AND DATE(created_at) = TODAY |
| 产出消耗比 | 今日产出 / 今日消耗 | 实时计算 |
| 活跃兑换用户数 | 今日完成兑换的独立用户数 | `redeem_order` WHERE DATE(created_at) = TODAY |
| 商城GMV(学币) | 今日兑换订单学币总价值 | SUM(price_coin) |
| 实物奖品待发货 | 待发货实物订单数 | `redeem_order_ext` WHERE delivery_status = 'PENDING' |
| 库存预警商品 | 低于安全库存的实物奖品数 | `prize_inventory` WHERE available_stock <= safety_stock |

#### 4.1.3 经济健康指数算法

```python
def calculate_economy_health_index(date_range_days: int = 7) -> dict:
    """
    计算虚拟经济健康度综合评分 (0-100)
    维度：产出消耗平衡、用户参与度、库存周转、异常率
    """
    metrics = fetch_metrics(date_range_days)

    # 维度1: 产出消耗比 (理想区间 1.0-1.5)
    ratio = metrics["total_earned"] / max(metrics["total_spent"], 1)
    if 1.0 <= ratio <= 1.5:
        balance_score = 100
    elif ratio < 0.8:  # 消耗过多，通货紧缩
        balance_score = max(0, int(ratio / 0.8 * 60))
    elif ratio > 2.0:  # 产出过多，通货膨胀
        balance_score = max(0, int(100 - (ratio - 2.0) * 30))
    else:
        balance_score = 80

    # 维度2: 用户参与度（活跃用户中参与兑换的比例）
    exchange_rate = metrics["exchange_users"] / max(metrics["active_users"], 1)
    participation_score = min(100, int(exchange_rate * 200))  # 50%参与率=满分

    # 维度3: 库存周转（实物奖品7天发货率）
    shipping_rate = metrics["shipped_in_7d"] / max(metrics["pending_physical_orders"], 1)
    turnover_score = min(100, int(shipping_rate * 100))

    # 维度4: 异常率（调账/退款/冻结占比）
    anomaly_rate = metrics["anomaly_count"] / max(metrics["total_transactions"], 1)
    anomaly_score = max(0, int(100 - anomaly_rate * 1000))

    # 综合评分（加权平均）
    overall = (
        balance_score * 0.35 +
        participation_score * 0.25 +
        turnover_score * 0.20 +
        anomaly_score * 0.20
    )

    return {
        "overall": round(overall, 1),
        "balance_score": balance_score,
        "participation_score": participation_score,
        "turnover_score": turnover_score,
        "anomaly_score": anomaly_score,
        "trend": "UP" if overall > last_week_overall else "DOWN",
        "alert": overall < 60
    }
```

```python
class PointsRuleService:
    """积分规则管理服务"""

    def update_rule(self, rule_id: int, updates: dict, operator_id: int) -> dict:
        """更新规则（支持热更新，无需重启服务）"""
        # 1. 保存变更前快照
        old_rule = self.get_rule(rule_id)
        old_snapshot = self._serialize(old_rule)

        # 2. 写入更新
        updates["version"] = old_rule.version + 1
        updates["updated_by"] = operator_id
        new_rule = self.repo.update(rule_id, updates)

        # 3. 写入变更历史
        self._save_history(rule_id, "UPDATE", old_snapshot, self._serialize(new_rule), operator_id)

        # 4. 推送规则到 Redis（热更新，规则引擎实时读取）
        cache_key = f"points:rule:{new_rule.rule_code}"
        self.redis.setex(cache_key, 86400, json.dumps({
            "rule_code": new_rule.rule_code,
            "reward_amount": new_rule.reward_amount,
            "daily_cap": new_rule.daily_cap,
            "weekly_cap": new_rule.weekly_cap,
            "monthly_cap": new_rule.monthly_cap,
            "condition_config": new_rule.condition_config,
            "bonus_config": new_rule.bonus_config,
            "target_segment": new_rule.target_segment,
            "version": new_rule.version,
            "effective_from": new_rule.effective_from.isoformat() if new_rule.effective_from else None,
            "effective_to": new_rule.effective_to.isoformat() if new_rule.effective_to else None,
        }))

        # 5. 发布规则变更事件（其他服务订阅）
        self.event_bus.publish("points.rule.updated", {
```

```python
class PhysicalOrderService:
    """实物兑换订单处理服务"""

    async def process_pending_order(self, order_id: int, operator_id: int) -> dict:
        """处理待审核的实物兑换订单"""
        order = await self.get_order_with_ext(order_id)

        # 1. 风控检查
        risk_check = await self.risk_engine.check_exchange_order(order)
        if risk_check["block"]:
            await self.reject_order(order_id, risk_check["reason"], operator_id)
            return {"status": "REJECTED", "reason": risk_check["reason"]}

        # 2. 库存确认
        inventory = await self.inventory_repo.get(order.goods_id)
        if inventory.available_stock <= 0:
            await self.mark_out_of_stock(order_id, operator_id)
            return {"status": "OUT_OF_STOCK"}

        # 3. 自动审核通过（低价值订单）或人工审核
        if order.price_coin <= 100:
            await self.approve_order(order_id, operator_id, auto=True)
            await self.lock_inventory(order.goods_id, 1, order.order_no)
            return {"status": "APPROVED", "auto": True}
        else:
            # 高价值订单进入人工审核队列
            await self.queue_for_manual_review(order_id)
            return {"status": "QUEUED_FOR_REVIEW"}

    async def ship_order(
        self,
        order_id: int,
        logistics_company: str,
        tracking_no: str,
        operator_id: int
    ) -> dict:
        """发货并更新物流信息"""
        # 1. 更新订单物流信息
        await self.order_ext_repo.update(order_id, {
            "logistics_company": logistics_company,
            "tracking_no": tracking_no,
            "shipped_at": datetime.now(),
            "delivery_status": "SHIPPED",
        })

        # 2. 扣减库存（从 locked 转为已出库）
        await self.inventory_repo.consume_locked(order.goods_id, 1, order.order_no)

        # 3. 记录库存流水
        await self.inventory_txn_repo.create({
            "goods_id": order.goods_id,
            "change_type": "OUTBOUND",
            "change_amount": -1,
            "ref_order_no": order.order_no,
            "reason": f"订单发货 {tracking_no}",
            "operator_id": operator_id,
        })

        # 4. 发送发货通知给用户
        await self.notification_service.send(order.user_id, {
            "template": "PRIZE_SHIPPED",
            "order_no": order.order_no,
            "logistics_company": logistics_company,
            "tracking_no": tracking_no,
        })

        return {"status": "SHIPPED"}

    async def batch_ship(
        self,
        order_ids: list[int],
        logistics_mappings: list[dict],
        operator_id: int
    ) -> dict:
        """批量发货（通过Excel导入物流信息）"""
        results = {"success": 0, "failed": 0, "errors": []}
        for mapping in logistics_mappings:
            try:
                order = next(
                    (o for o in await self.get_orders(order_ids)
                     if o.order_no == mapping["order_no"]),
                    None
                )
                if not order:
                    results["errors"].append(f"订单 {mapping['order_no']} 不存在")
                    results["failed"] += 1
                    continue

                await self.ship_order(
                    order.id, mapping["logistics_company"],
                    mapping["tracking_no"], operator_id
                )
                results["success"] += 1
            except Exception as e:
                results["errors"].append(f"订单 {mapping['order_no']}: {str(e)}")
                results["failed"] += 1
        return results
```

```python
async def refund_exchange_order(self, order_id: int, reason: str, operator_id: int) -> dict:
    """退还兑换订单，返还学币"""
    order = await self.get_order(order_id)

    if order.status not in ("COMPLETED", "DELIVERED", "PAID"):
        raise BizError("ORDER_STATUS_NOT_REFUNDABLE")

    # 1. 返还学币
    await self.currency_service.add_currency(
        user_id=order.user_id,
        currency_type="COIN",
        amount=order.price_coin,
        source_type="REFUND",
        source_id=str(order.id),
        description=f"兑换退款 {order.order_no}"
    )

    # 2. 回收已发放的虚拟权益
    if order.goods_category in ("TOOL", "CONTENT"):
        await self.inventory_service.revoke_user_item(order.user_id, order.goods_id, order.id)

    # 3. 实物订单需确认退回
    if order.goods_type == "PHYSICAL":
        if order.delivery_status == "DELIVERED":
            # 已签收需用户退回实物
            await self.create_return_ticket(order_id, reason, operator_id)
            return {"status": "RETURN_PENDING"}

    # 4. 更新订单状态
    await self.order_repo.update(order_id, {"status": "REFUNDED"})

    # 5. 释放锁定库存（实物）
    if order.goods_type == "PHYSICAL":
        await self.inventory_repo.release_locked(order.goods_id, 1, order.order_no)

    # 6. 审计日志
    await self.audit_log.record(
        operator_id=operator_id,
        action="ORDER_REFUND",
        target_type="redeem_order",
        target_id=order_id,
        detail={"order_no": order.order_no, "refund_amount": order.price_coin, "reason": reason}
    )

    return {"status": "REFUNDED"}
```

```python
async def execute_adjustment(self, ticket_id: int, approver_id: int) -> dict:
    """审批通过后执行调账"""
    ticket = await self.adjustment_repo.get(ticket_id)

    if ticket.status != "APPROVED":
        raise BizError("TICKET_NOT_APPROVED")

    user_id = ticket.user_id
    currency_type = ticket.currency_type
    amount = ticket.adjust_amount if ticket.adjust_type == "ADD" else -ticket.adjust_amount

    # 1. 检查账户冻结状态
    frozen = await self.frozen_repo.get_active(user_id, currency_type)
    if frozen and frozen.frozen_type == "FULL":
        raise BizError("ACCOUNT_FROZEN")

    # 2. 乐观锁更新余额
    txn_id = await self.currency_service.add_currency(
        user_id=user_id,
        currency_type=currency_type,
        amount=amount,
        source_type="ADMIN_ADJUST",
        source_id=str(ticket_id),
        description=f"后台调账-{ticket.reason_category}: {ticket.reason_detail[:50]}"
    )

    # 3. 更新工单状态
    await self.adjustment_repo.update(ticket_id, {
        "status": "EXECUTED",
        "executed_at": datetime.now(),
        "transaction_id": txn_id,
    })

    # 4. 通知用户
    await self.notification_service.send(user_id, {
        "template": "POINTS_ADJUSTMENT",
        "adjust_type": ticket.adjust_type,
        "amount": ticket.adjust_amount,
        "currency": currency_type,
        "reason": ticket.reason_detail,
    })

    # 5. 审计日志
    await self.audit_log.record(
        operator_id=approver_id,
        action="POINTS_ADJUSTMENT",
        target_type="user",
        target_id=user_id,
        detail={"ticket_no": ticket.ticket_no, "amount": amount}
    )

    return {"status": "EXECUTED", "transaction_id": txn_id}
```

```python
async def upsert_benefit(self, data: dict, operator_id: int) -> dict:
    """创建或更新等级权益配置"""
    # 验证等级范围不重叠（同一 benefit_type 下）
    existing = await self.benefit_repo.query(
        benefit_type=data["benefit_type"],
        status="ACTIVE"
    )
    for item in existing:
        if item.id != data.get("id"):
            if self._range_overlap(
                data["level_min"], data["level_max"],
                item.level_min, item.level_max
            ):
                raise BizError(
                    f"BENEFIT_RANGE_OVERLAP",
                    detail=f"与已有权益 '{item.benefit_name}' (Lv.{item.level_min}-{item.level_max}) 等级范围重叠"
                )

    # 写入配置
    result = await self.benefit_repo.upsert(data, operator_id)

    # 推送到缓存（客户端读取权益信息时使用）
    await self.refresh_benefit_cache()

    return result
```

### 9.2 关键交互设计

**Excel 批量发货导入组件：**

```typescript
// BatchShip.vue 核心逻辑
const handleFileUpload = async (file: File) => {
  loading.value = true;
  try {
    // 1. 前端预校验 Excel 格式
    const rows = await parseExcel(file);
    const required = ['orderNo', 'logisticsCompany', 'trackingNo'];
    if (!validateColumns(rows[0], required)) {
      message.error('Excel格式不正确，请下载模板');
      return;
    }

    // 2. 上传到服务端处理
    const formData = new FormData();
    formData.append('file', file);
    const result = await api.batchShip(formData);

    // 3. 展示结果
    if (result.failed > 0) {
      Modal.confirm({
        title: `${result.success}条成功，${result.failed}条失败`,
        content: '是否下载失败列表？',
        onOk: () => downloadFile(result.downloadFailedUrl)
      });
    } else {
      message.success(`全部${result.success}条发货成功`);
    }

    refreshList();
  } catch (e) {
    message.error('文件处理失败: ' + e.message);
  } finally {
    loading.value = false;
  }
};
```

### 9.3 实时数据更新

仪表盘核心数据通过 WebSocket 推送实现近实时更新：

```typescript
// dashboard/index.vue
const ws = useWebSocket('/admin/ws/points-dashboard');

ws.onMessage((data) => {
  switch (data.type) {
    case 'METRICS_UPDATE':
      metrics.value = data.metrics;
      break;
    case 'ALERT_TRIGGERED':
      alerts.value.unshift(data.alert);
      notification.warning({
        message: data.alert.title,
        description: data.alert.detail
      });
      break;
    case 'ORDER_CREATED':
      pendingCount.value++;
      break;
  }
});
```
