# 服务端-跨学科作业负载协同调控与学生作业总量智能管控引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 平台教师端与学生端之间的**作业负载治理中间件**，解决多学科教师各自独立布置作业导致学生日/周作业总量失控的问题。通过对班级维度作业总量进行实时聚合、智能评估、超载预警和协同调控，在保障各学科教学需求的前提下，将学生作业总负担控制在合理区间。

### 1.2 核心目标

| 目标 | 描述 |
| --- | --- |
| 总量可视 | 教师布置作业前，可查看目标班级当前时段已有作业量 |
| 超载预警 | 当预期作业总量超过年级建议上限时，系统主动预警并建议调整 |
| 智能推荐 | 基于学生学情、考试日程、学科优先级，推荐最优作业分配方案 |
| 协同调度 | 多学科教师通过协同看板进行作业量的隐式协商与退让 |
| 家长透明 | 家长可查看孩子各科作业总量与预估完成时间 |
| 合规落地 | 落实教育主管部门对作业总量的政策要求（如"双减"规定） |

### 1.3 适用范围

- **学段**：小学三年级至高中三年级（低年级以家长辅助为主，不纳入作业调控）
- **角色**：教师（布置端）、学生（执行端）、家长（监督端）、年级组长/教务（统筹端）
- **作业类型**：同步练习、章节复习、错题重做、背诵打卡、作文、实验报告、试卷模拟

### 1.4 设计原则

1. **非强制干预**：系统提供数据和建议，不硬性阻断教师布置作业，避免影响教学自主性
2. **年级差异化**：不同年级设定不同的作业总量上限标准
3. **动态弹性**：考试周、假期等特殊时段允许浮动调整
4. **公平优先**：调控时考虑各学科课时占比和考试权重，避免某一学科被持续挤压

## 2. 领域模型与核心概念

### 2.1 领域模型图

```
┌─────────────────────────────────────────────────────────┐
│                    作业负载治理域                         │
│                                                         │
│  ┌──────────────┐     ┌──────────────┐                │
│  │  HomeworkTask │     │ HomeworkLoad │                │
│  │  (作业任务)    │────→│  (作业负载)   │                │
│  └──────┬───────┘     └──────┬───────┘                │
│         │                    │                          │
│         ▼                    ▼                          │
│  ┌──────────────┐     ┌──────────────┐                │
│  │ ClassSubject  │     │ LoadPolicy   │                │
│  │ (班级学科)    │     │ (负载策略)    │                │
│  └──────┬───────┘     └──────┬───────┘                │
│         │                    │                          │
│         ▼                    ▼                          │
│  ┌──────────────┐     ┌──────────────┐                │
│  │  GradeLimit   │     │ Coordination │                │
│  │ (年级限额)    │     │ Event (协同   │                │
│  │               │     │  事件)        │                │
│  └──────────────┘     └──────────────┘                │
└─────────────────────────────────────────────────────────┘
```

### 2.2 核心概念定义

| 概念 | 说明 |
| --- | --- |
| 作业负载（HomeworkLoad） | 一个班级在一个时间维度（日/周）内所有学科作业的聚合度量 |
| 预估完成时长 | 基于题目数量、难度系数和学生历史作答速度计算的作业预计耗时（分钟） |
| 负载水位 | 当前作业总量占年级建议上限的百分比，分绿/黄/红三区 |
| 协同事件（CoordinationEvent） | 教师对作业量的调整操作产生的广播通知，用于驱动其他教师的决策 |
| 负载策略（LoadPolicy） | 可配置的年级作业量上限、学科分配比例、特殊时段豁免规则 |

## 3. 数据结构定义

### 3.1 核心表设计

#### 3.1.1 `homework_load_daily` — 班级每日作业负载汇总表

```sql
CREATE TABLE homework_load_daily (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    tenant_id       BIGINT       NOT NULL COMMENT '租户ID',
    class_id        BIGINT       NOT NULL COMMENT '班级ID',
    grade_level     TINYINT      NOT NULL COMMENT '年级编码: 3-12 对应 小学三年级~高三',
    school_date     DATE         NOT NULL COMMENT '教学日日期',

    total_tasks     INT          NOT NULL DEFAULT 0 COMMENT '当日作业任务总数',
    total_items     INT          NOT NULL DEFAULT 0 COMMENT '当日作业题目总数',
    estimated_minutes INT        NOT NULL DEFAULT 0 COMMENT '预估完成总时长(分钟)',
    grade_limit_minutes INT      NOT NULL DEFAULT 0 COMMENT '年级建议时长上限(分钟)',
    load_ratio      DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT '负载水位 = estimated/limit*100',

    zone            VARCHAR(10)  NOT NULL DEFAULT 'GREEN' COMMENT '水位区间: GREEN/YELLOW/RED',
    subject_count   INT          NOT NULL DEFAULT 0 COMMENT '有置作业的学科数',

    exam_mode       TINYINT      NOT NULL DEFAULT 0 COMMENT '是否考试周(0否 1是)',
    holiday_mode    TINYINT      NOT NULL DEFAULT 0 COMMENT '是否假期(0否 1是)',

    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    PRIMARY KEY (id),
    UNIQUE KEY uk_class_date (tenant_id, class_id, school_date),
    KEY idx_grade_date (tenant_id, grade_level, school_date),
    KEY idx_zone (tenant_id, zone, school_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='班级每日作业负载汇总';
```

#### 3.1.2 `homework_load_subject_daily` — 分学科每日作业负载表

```sql
CREATE TABLE homework_load_subject_daily (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    tenant_id       BIGINT       NOT NULL,
    class_id        BIGINT       NOT NULL,
    subject_id      BIGINT       NOT NULL COMMENT '学科ID',
    teacher_id      BIGINT       NOT NULL COMMENT '布置教师ID',
    school_date     DATE         NOT NULL,

    task_count      INT          NOT NULL DEFAULT 0 COMMENT '该学科当日作业任务数',
    item_count      INT          NOT NULL DEFAULT 0 COMMENT '该学科当日题目总数',
    estimated_minutes INT        NOT NULL DEFAULT 0 COMMENT '该学科预估完成时长',
    difficulty_avg  DECIMAL(3,2) NOT NULL DEFAULT 0.00 COMMENT '平均难度系数 0.1~1.0',

    task_ids        JSON         COMMENT '关联的作业任务ID列表',
    metadata        JSON         COMMENT '扩展元数据: {题型分布, 知识点数, ...}',

    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    PRIMARY KEY (id),
    UNIQUE KEY uk_class_subject_date (tenant_id, class_id, subject_id, school_date),
    KEY idx_teacher_date (tenant_id, teacher_id, school_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='分学科每日作业负载';
```

#### 3.1.3 `load_policy` — 作业负载策略配置表

```sql
CREATE TABLE load_policy (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    tenant_id       BIGINT       NOT NULL,
    grade_level     TINYINT      NOT NULL COMMENT '年级编码',

    daily_max_minutes INT        NOT NULL COMMENT '每日建议作业总时长上限(分钟)',
    weekly_max_minutes INT       NOT NULL COMMENT '每周建议作业总时长上限(分钟)',
    daily_max_subjects INT       NOT NULL COMMENT '每日最多布置作业的学科数',
    single_subject_max_minutes INT NOT NULL COMMENT '单学科单日作业时长上限',

    exam_week_daily_max INT      NOT NULL COMMENT '考试周每日上限(分钟)',
    friday_reduction_pct DECIMAL(5,2) NOT NULL DEFAULT 0.20 COMMENT '周五减负比例',
    weekend_max_minutes INT      NOT NULL COMMENT '周末作业总时长上限',

    subject_weights JSON         COMMENT '学科分配权重: {"math":1.5,"chinese":1.2,...}',

    effective_from  DATE         NOT NULL,
    effective_to    DATE         NULL COMMENT 'NULL=长期有效',
    status          TINYINT      NOT NULL DEFAULT 1 COMMENT '1=启用 0=停用',

    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    PRIMARY KEY (id),
    KEY uk_tenant_grade (tenant_id, grade_level, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作业负载策略配置';
```

#### 3.1.4 `coordination_event` — 作业协同事件表

```sql
CREATE TABLE coordination_event (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    tenant_id       BIGINT       NOT NULL,
    class_id        BIGINT       NOT NULL,
    event_type      VARCHAR(30)  NOT NULL COMMENT '事件类型: HOMEWORK_POSTED/HOMEWORK_REDUCED/HOMEWORK_DELAYED/OVERLOAD_ALERT/TEACHER_ACK',
    subject_id      BIGINT       NULL COMMENT '相关学科ID',
    teacher_id      BIGINT       NULL COMMENT '触发教师ID',
    school_date     DATE         NOT NULL COMMENT '影响日期',

    payload         JSON         NOT NULL COMMENT '事件详情: {task_id, minutes_change, current_load, ...}',
    ack_teachers    JSON         COMMENT '已确认教师列表: [{teacher_id, ack_time}]',

    severity        VARCHAR(10)  NOT NULL DEFAULT 'INFO' COMMENT 'INFO/WARN/URGENT',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,

    PRIMARY KEY (id),
    KEY idx_class_date (tenant_id, class_id, school_date),
    KEY idx_teacher (tenant_id, teacher_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作业协同事件';
```

#### 3.1.5 `student_workload_profile` — 学生作业负担画像表

```sql
CREATE TABLE student_workload_profile (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    tenant_id       BIGINT       NOT NULL,
    student_id      BIGINT       NOT NULL,
    class_id        BIGINT       NOT NULL,

    avg_daily_minutes DECIMAL(7,2) NOT NULL DEFAULT 0 COMMENT '近30天日均作业时长',
    avg_weekly_minutes DECIMAL(8,2) NOT NULL DEFAULT 0 COMMENT '近30天周均作业时长',
    overload_days   INT          NOT NULL DEFAULT 0 COMMENT '近30天超载天数',
    overload_subjects JSON       COMMENT '高频超载学科: ["math","physics"]',

    actual_vs_estimate_ratio DECIMAL(4,2) NOT NULL DEFAULT 1.00 COMMENT '实际/预估时长比，用于校准',
    last_calibrated_at DATETIME  NULL COMMENT '上次校准时间',

    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    PRIMARY KEY (id),
    UNIQUE KEY uk_student (tenant_id, student_id),
    KEY idx_class (tenant_id, class_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生作业负担画像';
```

### 3.2 缓存结构

#### 3.2.1 班级当日负载实时缓存（Redis Hash）

```
Key:  hw:load:realtime:{classId}:{date}
Type: HASH
Fields:
    total_minutes      (INT)       — 当日已布置作业预估总时长
    total_tasks        (INT)       — 当日作业任务数
    subjects           (STRING/JSON) — 学科明细: [{"subject":"math","minutes":35,"teacher":1001},...]
    zone               (STRING)    — GREEN/YELLOW/RED
    last_updated_by    (INT)       — 最后更新的教师ID
    last_updated_at    (TIMESTAMP)
TTL: 48h（跨日自动过期）
```

#### 3.2.2 年级负载策略缓存（Redis String + JSON）

```
Key:  hw:policy:{tenantId}:{gradeLevel}
Type: STRING (JSON serialized)
TTL:  1h（后台修改时主动刷新）
```

#### 3.2.3 教师待处理协同事件（Redis Sorted Set）

```
Key:  hw:coord:pending:{teacherId}
Type: ZSET
Score: 事件严重度时间戳（severity * 1e10 + unix_timestamp）
Member: eventId
TTL:  7d
```

```java
/**
 * 负载水位计算器
 */
public class LoadZoneCalculator {

    // 水位阈值常量
    private static final double GREEN_YELLOW_THRESHOLD = 70.0;  // 70% 以下为绿区
    private static final double YELLOW_RED_THRESHOLD = 100.0;   // 100% 以上为红区

    /**
     * 计算负载水位区间
     *
     * @param estimatedMinutes 预估完成总时长
     * @param gradeLimitMinutes 年级建议时长上限
     * @param isExamWeek 是否考试周
     * @return 水位区间枚举
     */
    public LoadZone calculate(int estimatedMinutes, int gradeLimitMinutes, boolean isExamWeek) {
        // 考试周上浮20%的容忍度
        double effectiveLimit = isExamWeek 
            ? gradeLimitMinutes * 1.2 
            : gradeLimitMinutes;
        
        double ratio = (estimatedMinutes / effectiveLimit) * 100.0;

        if (ratio <= GREEN_YELLOW_THRESHOLD) {
            return LoadZone.GREEN;
        } else if (ratio <= YELLOW_RED_THRESHOLD) {
            return LoadZone.YELLOW;
        } else {
            return LoadZone.RED;
        }
    }

    /**
     * 计算剩余可用作业时长
     */
    public int calculateRemainingCapacity(int currentMinutes, int gradeLimitMinutes, 
                                          boolean isExamWeek, boolean isFriday) {
        double effectiveLimit = gradeLimitMinutes;
        
        if (isExamWeek) {
            effectiveLimit *= 1.2;
        }
        if (isFriday) {
            // 周五按策略减负
            effectiveLimit *= (1 - loadPolicy.getFridayReductionPct());
        }
        
        return Math.max(0, (int) effectiveLimit - currentMinutes);
    }
}
```

### 5.3 作业预估时长计算引擎

```java
/**
 * 作业预估时长计算服务
 * 
 * 综合考虑题目数量、难度系数、题型和班级历史作答速度，
 * 输出该作业的预估完成时长（分钟）。
 */
@Service
public class HomeworkEstimationService {

    @Autowired
    private StudentWorkloadProfileRepository profileRepo;

    @Autowired
    private AnswerRecordRepository answerRecordRepo;

    // 题型基准时长（分钟/题），基于历史统计
    private static final Map<QuestionType, Double> BASE_TIME_PER_TYPE = Map.of(
        QuestionType.MULTIPLE_CHOICE, 1.5,     // 选择题 ~1.5分钟
        QuestionType.FILL_BLANK, 2.0,          // 填空题 ~2分钟
        QuestionType.SHORT_ANSWER, 4.0,        // 简答题 ~4分钟
        QuestionType.ESSAY, 15.0,              // 作文 ~15分钟
        QuestionType.CALCULATION, 6.0,         // 计算题 ~6分钟
        QuestionType.PROOF, 10.0,              // 证明题 ~10分钟
        QuestionType.EXPERIMENT, 12.0,         // 实验题 ~12分钟
        QuestionType.READING_COMPREHENSION, 8.0 // 阅读理解 ~8分钟
    );

    /**
     * 预估单个作业任务的完成时长
     *
     * @param task 作业任务信息
     * @param classId 目标班级
     * @return 预估时长（分钟）
     */
    public int estimate(HomeworkTask task, Long classId) {
        // 1. 基础时长 = Σ(题型基准时长 × 数量)
        double baseMinutes = 0;
        for (TaskItemGroup group : task.getItemGroups()) {
            double typeTime = BASE_TIME_PER_TYPE.getOrDefault(group.getQuestionType(), 3.0);
            baseMinutes += typeTime * group.getCount();
        }

        // 2. 难度系数调整（难度0.5为基准，每偏移0.1调整10%）
        double difficultyMultiplier = 1.0 + (task.getDifficultyAvg() - 0.5) * 2.0;
        difficultyMultiplier = Math.max(0.5, Math.min(2.0, difficultyMultiplier));

        double adjustedMinutes = baseMinutes * difficultyMultiplier;

        // 3. 班级历史作答速度校准
        double classSpeedFactor = getClassSpeedFactor(classId, task.getSubjectId());
        adjustedMinutes *= classSpeedFactor;

        // 4. 下取整到5分钟
        return Math.max(5, (int) Math.round(adjustedMinutes / 5.0) * 5);
    }

    /**
     * 获取班级作答速度因子
     * 
     * @return 速度因子，<1.0表示该班整体较快，>1.0表示较慢
     */
    private double getClassSpeedFactor(Long classId, Long subjectId) {
        // 查询该班级近30天该学科的实际作答时长与预估时长之比
        Double actualToEstimateRatio = answerRecordRepo
            .calculateClassSpeedFactor(classId, subjectId, 30);
        
        if (actualToEstimateRatio == null || actualToEstimateRatio < 0.1) {
            return 1.0; // 无历史数据时使用默认值
        }

        // 平滑处理，避免极端值
        return Math.max(0.6, Math.min(1.8, actualToEstimateRatio));
    }
}
```

```java
                    "trigger_subject", event.getSubjectName()
                ))
```

### 6.1 作业量调整建议算法

```python
"""
跨学科作业负载均衡推荐算法

输入: 当前班级各学科作业分布、年级限额、考试日程
输出: 调整建议列表（优先级排序）
"""

from dataclasses import dataclass
from typing import List, Optional
from enum import Enum

class SuggestionType(Enum):
    REDUCE_VOLUME = "减少题量"
    DEFER_DATE = "延后日期"
    REDUCE_DIFFICULTY = "降低难度"
    SPLIT_OPTIONAL = "拆分为选做"
    CONVERT_TO_CLASSWORK = "转为课堂练习"

@dataclass
class AdjustmentSuggestion:
    priority: int
    target_subject: str
    target_teacher: str
    suggestion_type: SuggestionType
    current_minutes: int
    recommended_minutes: Optional[int] = None
    recommended_date: Optional[str] = None
    reason: str = ""
    confidence: float = 0.0

def generate_suggestions(
    class_id: int,
    school_date: str,
    subject_loads: List[dict],  # [{"subject":"math","teacher":"王","minutes":50,"items":15,...}]
    grade_limit: int,
    exam_schedule: List[dict],   # [{"date":"2026-08-05","subject":"math","type":"unit_test"}]
    subject_weights: dict         # {"math":1.5,"chinese":1.3,...}
) -> List[AdjustmentSuggestion]:
    """
    生成作业负载调整建议
    
    策略:
    1. 如果总量未超限 → 返回空列表
    2. 识别超配学科 → 按权重计算各学科"应得"时长配额
    3. 对超配学科生成调整建议 → 优先减少非考试科目
    4. 考虑日期迁移 → 寻找余量充足的日期
    """
    total_minutes = sum(s["minutes"] for s in subject_loads)
    if total_minutes <= grade_limit:
        return []

    suggestions = []
    overload = total_minutes - grade_limit

    # 1. 计算各学科的理论配额
    total_weight = sum(subject_weights.get(s["subject"], 1.0) for s in subject_loads)
    for s in subject_loads:
        weight = subject_weights.get(s["subject"], 1.0)
        s["quota_minutes"] = int(grade_limit * weight / total_weight)
        s["over_quota"] = max(0, s["minutes"] - s["quota_minutes"])

    # 2. 按超配量降序排序
    sorted_subjects = sorted(subject_loads, key=lambda x: x["over_quota"], reverse=True)

    for subject in sorted_subjects:
        if overload <= 0:
            break
        if subject["over_quota"] <= 0:
            continue

        # 检查是否有近期该学科考试
        has_upcoming_exam = any(
            e["subject"] == subject["subject"] and e["date"] <= school_date_add(school_date, 3)
            for e in exam_schedule
        )

        if has_upcoming_exam:
            # 考试科目：建议减少难度或拆分选做，不延后
            reduce_amount = min(subject["over_quota"], overload)
            suggestions.append(AdjustmentSuggestion(
                priority=len(suggestions) + 1,
                target_subject=subject["subject"],
                target_teacher=subject["teacher"],
                suggestion_type=SuggestionType.REDUCE_DIFFICULTY,
                current_minutes=subject["minutes"],
                recommended_minutes=subject["minutes"] - reduce_amount,
                reason=f"{subject['subject']}近期有考试，建议保留核心题目，"
                       f"减少重复练习型题目{reduce_amount}分钟",
                confidence=0.85
            ))
        else:
            # 非考试科目：优先建议延后
            suggestions.append(AdjustmentSuggestion(
                priority=len(suggestions) + 1,
                target_subject=subject["subject"],
                target_teacher=subject["teacher"],
                suggestion_type=SuggestionType.DEFER_DATE,
                current_minutes=subject["minutes"],
                recommended_date=find_best_alternative_date(

                reason=f"{subject['subject']}近期无考试，"

                confidence=0.75
            ))

        overload -= subject["over_quota"]
```

```java
/**
 * 学生个人作业时长校准器
 * 
 * 持续追踪学生实际完成时长与预估时长的偏差，
 * 动态调整个人速度因子，提升后续预估准确度。
 */
@Service
public class WorkloadCalibrationService {

    private static final int CALIBRATION_WINDOW_DAYS = 30;
    private static final int MIN_SAMPLES_FOR_CALIBRATION = 10;
    private static final double ALPHA = 0.3; // 指数平滑系数

    /**
     * 当学生提交作业完成时，触发校准
     */
    public void onHomeworkCompleted(Long studentId, Long subjectId, 
                                     int estimatedMinutes, int actualMinutes) {
        StudentWorkloadProfile profile = profileRepo.findByStudent(studentId);
        
        // 计算本次偏差率
        double currentRatio = (double) actualMinutes / estimatedMinutes;

        if (profile.getActualVsEstimateRatio() == 1.0) {
            // 首次校准，直接使用
            profile.setActualVsEstimateRatio(currentRatio);
        } else {
            // 指数平滑更新
            double smoothed = (1 - ALPHA) * profile.getActualVsEstimateRatio() 
                            + ALPHA * currentRatio;
            // 限制在 [0.5, 2.5] 范围内
            smoothed = Math.max(0.5, Math.min(2.5, smoothed));
            profile.setActualVsEstimateRatio(smoothed);
        }

        profile.setLastCalibratedAt(LocalDateTime.now());
        profileRepo.save(profile);
    }
}
```

```java
/**
 * 分布式锁防止同一班级负载并发修改冲突

@Service
public class HomeworkLoadUpdateService {

    private static final String LOCK_KEY_PREFIX = "hw:load:lock:";

    @Autowired
    private RedissonClient redissonClient;

    /**
     * 安全更新班级负载（加锁）
     */
    public void safeUpdateLoad(Long classId, String date, LoadUpdateAction action) {
        String lockKey = LOCK_KEY_PREFIX + classId + ":" + date;
        RLock lock = redissonClient.getLock(lockKey);

        try {
            // 最多等待3秒，持锁10秒自动释放
            boolean acquired = lock.tryLock(3, 10, TimeUnit.SECONDS);
            if (!acquired) {
                throw new ConcurrentUpdateException("HW_LOAD_005", 
                    "班级负载正在被其他操作更新，请重试");
            }
            action.execute();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("Load update interrupted", e);
        } finally {
            if (lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    @FunctionalInterface
    public interface LoadUpdateAction {
        void execute();
    }
}
```

### 9.2 数据隔离

```java
/**
 * 数据权限拦截器
 */
@Component
public class HomeworkLoadDataGuard {

    /**
     * 教师只能查看自己任教的班级
     */
    public void checkTeacherClassAccess(Long teacherId, Long classId) {
        boolean hasAccess = classRepo.existsByTeacherAndClass(teacherId, classId);
        if (!hasAccess) {
            throw new AccessDeniedException("无权访问该班级的作业负载数据");
        }
    }

    /**
     * 家长只能查看绑定孩子的数据
     */
    public void checkParentStudentAccess(Long parentId, Long studentId) {
        boolean isBound = parentBindingRepo.existsByParentAndStudent(parentId, studentId);
        if (!isBound) {
            throw new AccessDeniedException("无权查看该学生的作业数据");
        }
    }

    /**
     * 学生作业负载数据中的其他学生信息需脱敏
     */
    public StudentLoadSummary desensitize(StudentLoadSummary summary) {
        // 不暴露同班其他同学的完成速度对比数据
        summary.setClassRank(null);
        summary.setClassAverage(null);
        return summary;
    }
}
```

```java
public class LoadCalcThreadPool {
```
