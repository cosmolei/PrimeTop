## 1. 模块概述

### 1.1 功能定位

知识图谱浏览页面是 PrimeTop 的核心差异化功能入口，通过力导向图（Force-Directed Graph）将知识点之间的前置关系、关联关系和掌握度状态可视化呈现。学生可以直观地发现知识脉络、定位薄弱环节、探索关联知识点，并一键进入学习。本文档聚焦 **Flutter 客户端**的页面架构、Canvas 渲染引擎、手势交互、状态管理和性能优化，让开发人员可直接编码。

### 1.2 目标用户与分龄策略

| 学段 | 信息密度 | 核心诉求 | 交互特点 |
|------|----------|----------|----------|
| 小学 (1-6年级) | 低 | 知识点连线、颜色卡通化、进度星星 | 大节点、圆角卡片、彩色渐变、动画丰富 |
| 初中 (7-9年级) | 中 | 考点关联、薄弱环节可视化、学科全景 | 中等节点、掌握度色阶、简洁布局 |
| 高中 (10-12年级) | 高 | 全考点拓扑、推荐路径、多维筛选 | 紧凑节点、热力叠加、路径高亮、统计面板 |

### 1.3 页面清单

| 页面 | 路由 | 优先级 | 说明 |
|------|------|--------|------|
| 图谱全景页 | `/knowledge-graph` | P1 | 学科/章节选择 + 力导向图渲染 + 掌握度叠加 |

## 3. 核心数据模型

### 3.1 图谱节点模型 (Graph Node)

```dart
// lib/features/knowledge_graph/models/graph_node.dart

import 'package:flutter/material.dart';

/// 图谱节点类型
enum GraphNodeType {
  knowledgePoint,  // 知识点
  chapter,         // 章节
  examPoint,       // 考点
  skill,           // 能力维度
}

/// 掌握度等级
enum MasteryLevel {
  unknown,   // 未学习 (灰色)
  weak,      // 薄弱 (红色)
  learning,  // 学习中 (橙色)
  fair,      // 一般 (黄色)
  good,      // 良好 (浅绿)
  mastered,  // 已掌握 (深绿)
}

/// 图谱节点
class GraphNode {
  final int id;
  final int kpId;           // 关联知识点ID
  final String name;         // 节点显示名称
  final GraphNodeType type;
  final int subjectId;
  final int? chapterId;
  final MasteryLevel mastery;
  final double masteryScore; // 0.0 ~ 1.0
  final bool isHighFreqExam; // 是否高频考点
  final bool isWeakPoint;    // 是否薄弱点
  final int relatedQuestionCount; // 关联题目数量
  final List<String> tags;   // 标签列表

  // 渲染属性 (由布局引擎计算)
  Offset position;           // 当前渲染位置
  double radius;             // 节点半径

  GraphNode({
    required this.id,
    required this.kpId,
    required this.name,
    required this.type,
    required this.subjectId,
    this.chapterId,
    this.mastery = MasteryLevel.unknown,
    this.masteryScore = 0.0,
    this.isHighFreqExam = false,
    this.isWeakPoint = false,
    this.relatedQuestionCount = 0,
    this.tags = const [],
    this.position = Offset.zero,
    this.radius = 24.0,
  });

  /// 获取掌握度对应颜色
  Color get masteryColor {
    switch (mastery) {
      case MasteryLevel.unknown:  return const Color(0xFFBDBDBD);
      case MasteryLevel.weak:     return const Color(0xFFEF5350);
      case MasteryLevel.learning: return const Color(0xFFFF9800);
      case MasteryLevel.fair:     return const Color(0xFFFFEB3B);
      case MasteryLevel.good:     return const Color(0xFF66BB6A);
      case MasteryLevel.mastered: return const Color(0xFF2E7D32);
    }
  }
}
```

### 3.3 图谱数据聚合模型

```dart
// lib/features/knowledge_graph/models/knowledge_graph_data.dart

/// 图谱数据 — 服务端单次返回的完整子图
class KnowledgeGraphData {
  final List<GraphNode> nodes;
  final List<GraphEdge> edges;
  final int subjectId;
  final int? chapterId;
  final String? chapterName;
  final int totalCount;     // 全图总节点数 (分页用)
  final double overallMastery; // 整体掌握度 0.0~1.0
  final List<GraphNode> weakNodes; // 薄弱节点TOP N

  KnowledgeGraphData({
    required this.nodes,
    required this.edges,
    required this.subjectId,
    this.chapterId,
    this.chapterName,
    this.totalCount = 0,
    this.overallMastery = 0.0,
    this.weakNodes = const [],
  });

  /// 根据节点ID获取节点
  GraphNode? nodeById(int id) {
    for (final n in nodes) {
      if (n.id == id) return n;
    }
    return null;
  }

  /// 获取指定节点的邻接节点
  List<GraphNode> neighborsOf(int nodeId) {
    final neighborIds = <int>{};
    for (final e in edges) {
      if (e.sourceId == nodeId) neighborIds.add(e.targetId);
      if (e.targetId == nodeId) neighborIds.add(e.sourceId);
    }
    return nodes.where((n) => neighborIds.contains(n.id)).toList();
  }
}
```

## 6. 力导向布局引擎

### 6.1 引擎核心

力导向布局是图谱渲染的核心，需在移动端保持 60fps 流畅度。

```dart
// lib/features/knowledge_graph/engine/force_layout_engine.dart

import 'dart:math';
import '../models/graph_node.dart';
import '../models/graph_edge.dart';

/// 力导向布局引擎 — 基于 Fruchterman-Reingold 算法简化版
class ForceLayoutEngine {
  final List<GraphNode> nodes;
  final List<GraphEdge> edges;

  /// 布局参数
  double area;              // 布局区域面积
  double gravity;           // 重力系数 (防止节点飞散)
  double repulsion;         // 斥力系数
  double attraction;        // 引力系数
  double damping;           // 衰减系数
  double cooling;           // 温度冷却率
  double temperature;       // 当前温度 (控制位移幅度)

  int _iteration = 0;
  static const int maxIterations = 300;
  static const double minTemperature = 0.01;
  static const double epsilon = 0.001;

  ForceLayoutEngine({
    required this.nodes,
    required this.edges,
    required this.area,
    this.gravity = 0.1,
    this.repulsion = 5000.0,
    this.attraction = 0.005,
    this.damping = 0.85,
    this.cooling = 0.95,
  }) : temperature = sqrt(area) / 10;

  /// 初始化节点位置 — 按章节/层级环形排布
  void initializePositions() {
    if (nodes.isEmpty) return;

    // 按章节分组，同章节节点聚簇
    final chapterGroups = <int?, List<GraphNode>>{};
    for (final node in nodes) {
      chapterGroups.putIfAbsent(node.chapterId, () => []).add(node);
    }

    final centerX = sqrt(area) / 2;
    final centerY = sqrt(area) / 2;
    final groupCount = chapterGroups.length;
    var groupIndex = 0;

    for (final entry in chapterGroups.entries) {
      final groupNodes = entry.value;
      final groupAngle = (2 * pi * groupIndex) / groupCount;
      final groupRadius = sqrt(area) * 0.3;
      final groupCenterX = centerX + groupRadius * cos(groupAngle);
      final groupCenterY = centerY + groupRadius * sin(groupAngle);

      // 组内节点绕组中心圆形分布
      final innerRadius = 30.0 * sqrt(groupNodes.length.toDouble());
      for (var i = 0; i < groupNodes.length; i++) {
        final angle = (2 * pi * i) / groupNodes.length;
        groupNodes[i].position = Offset(
          groupCenterX + innerRadius * cos(angle),
          groupCenterY + innerRadius * sin(angle),
        );
      }
      groupIndex++;
    }
  }

  /// 执行单步布局计算
  /// 返回 true 表示布局仍在收敛中，false 表示已稳定
  bool step() {
    if (temperature < minTemperature || _iteration >= maxIterations) {
      return false;
    }

    final displacements = List.generate(nodes.length, (_) => Offset.zero);

    // 1. 节点间斥力 (库仑力)
    for (var i = 0; i < nodes.length; i++) {
      for (var j = i + 1; j < nodes.length; j++) {
        final dx = nodes[i].position.dx - nodes[j].position.dx;
        final dy = nodes[i].position.dy - nodes[j].position.dy;
        final dist = max(sqrt(dx * dx + dy * dy), epsilon);
        final force = repulsion / (dist * dist);
        final fx = (dx / dist) * force;
        final fy = (dy / dist) * force;
        displacements[i] = displacements[i] + Offset(fx, fy);
        displacements[j] = displacements[j] - Offset(fx, fy);
      }
    }

    // 2. 边引力 (弹簧力)
    for (final edge in edges) {
      final sourceIdx = nodes.indexWhere((n) => n.id == edge.sourceId);
      final targetIdx = nodes.indexWhere((n) => n.id == edge.targetId);
      if (sourceIdx == -1 || targetIdx == -1) continue;

      final dx = nodes[targetIdx].position.dx - nodes[sourceIdx].position.dx;
      final dy = nodes[targetIdx].position.dy - nodes[sourceIdx].position.dy;
      final dist = max(sqrt(dx * dx + dy * dy), epsilon);
      final force = attraction * dist * edge.weight;
      final fx = (dx / dist) * force;
      final fy = (dy / dist) * force;
      displacements[sourceIdx] = displacements[sourceIdx] + Offset(fx, fy);
      displacements[targetIdx] = displacements[targetIdx] - Offset(fx, fy);
    }

    // 3. 重力 (向中心聚集)
    final centerX = sqrt(area) / 2;
    final centerY = sqrt(area) / 2;
    for (var i = 0; i < nodes.length; i++) {
      final dx = centerX - nodes[i].position.dx;
      final dy = centerY - nodes[i].position.dy;
      displacements[i] = displacements[i] + Offset(dx * gravity, dy * gravity);
    }

    // 4. 施加位移 (受温度限制)
    for (var i = 0; i < nodes.length; i++) {
      final dist = max(
        sqrt(displacements[i].dx * displacements[i].dx +
            displacements[i].dy * displacements[i].dy),
        epsilon,
      );
      final cappedDist = min(dist, temperature);
      nodes[i].position = Offset(
        nodes[i].position.dx + (displacements[i].dx / dist) * cappedDist,
        nodes[i].position.dy + (displacements[i].dy / dist) * cappedDist,
      );
    }

    // 5. 冷却
    temperature *= cooling;
    _iteration++;
    return true;
  }

  /// 计算总动能 (用于判断布局稳定)
  double kineticEnergy() {
    // 简化：返回当前温度即可
    return temperature;
  }

  /// 重置布局
  void reset() {
    _iteration = 0;
    temperature = sqrt(area) / 10;
    initializePositions();
  }
}
```

### 6.3 布局收敛调度器

力导向布局计算量 O(n²)（斥力对），在低端设备上 200 节点全量跑 300 迭代会阻塞 UI。采用 **分档调度策略**：

| 节点数 | 计算位置 | 迭代策略 | 首帧策略 |
|--------|----------|----------|----------|
| ≤ 60 | UI isolate（Ticker） | 每帧 1 次迭代，最多 300 次 | 预热 30 次迭代后上屏 |
| 61~120 | UI isolate（Ticker） | 每帧 1 次，最多 200 次 | 预热 15 次迭代后上屏 |
| > 120 | `compute()` 后台 isolate | 一次性跑到收敛（温度 < 0.01 或迭代上限） | 骨架屏等待，完成后一次上屏 |

```dart
// lib/features/knowledge_graph/engine/layout_scheduler.dart

import 'dart:ui';
import 'package:flutter/scheduler.dart';
import 'force_layout_engine.dart';
import '../models/graph_node.dart';
import '../models/graph_edge.dart';

/// 布局调度器 — 按节点数分档执行力导向布局
class LayoutScheduler {
  final ForceLayoutEngine engine;
  final void Function() onLayoutTick;   // 每次迭代后通知重绘
  final void Function() onLayoutStable; // 布局收敛回调

  Ticker? _ticker;
  int _warmupRemaining;
  bool _scheduled = false;

  static const int _warmupSmall = 30;
  static const int _warmupMedium = 15;

  LayoutScheduler({
    required this.engine,
    required this.onLayoutTick,
    required this.onLayoutStable,
  }) : _warmupRemaining = _warmupFor(engine.nodes.length);

  static int _warmupFor(int nodeCount) {
    if (nodeCount <= 60) return _warmupSmall;
    if (nodeCount <= 120) return _warmupMedium;
    return 0; // 大图走后台 isolate，无预热概念
  }

  /// 启动布局（UI isolate 路径）
  void start() {
    engine.reset();
    if (engine.nodes.length > 120) {
      _runInBackground();
      return;
    }
    _ticker = Ticker(_onTick)..start();
  }

  void _onTick(Duration elapsed) {
    final stillRunning = engine.step();
    if (_warmupRemaining > 0) {
      _warmupRemaining--;
      if (_warmupRemaining == 0) onLayoutTick(); // 预热完成，首帧上屏
      return;
    }
    onLayoutTick();
    if (!stillRunning) {
      stop();
      onLayoutStable();
    }
  }

  /// 大图后台布局：整图打包进 isolate，完成后整体替换位置
  Future<void> _runInBackground() async {
    final nodes = engine.nodes;
    final edges = engine.edges;
    final result = await compute(
      _layoutInIsolate,
      _LayoutPayload(nodes, edges, engine.area),
    );
    for (var i = 0; i < nodes.length; i++) {
      nodes[i].position = result[i];
    }
    onLayoutTick();
    onLayoutStable();
  }

  static List<Offset> _layoutInIsolate(_LayoutPayload payload) {
    final engine = ForceLayoutEngine(
      nodes: payload.nodes,
      edges: payload.edges,
      area: payload.area,
    );
    engine.reset();
    while (engine.step()) {}
    return payload.nodes.map((n) => n.position).toList();
  }

  /// 节点拖拽中：暂停自动布局，仅在被拖节点邻域做局部迭代
  void pauseForDrag() => _ticker?.muted = true;

  void resumeAfterDrag() => _ticker?.muted = false;

  void stop() {
    _ticker?.dispose();
    _ticker = null;
  }
}

class _LayoutPayload {
  final List<GraphNode> nodes;
  final List<GraphEdge> edges;
  final double area;
  _LayoutPayload(this.nodes, this.edges, this.area);
}
```

**收敛判定**：`step()` 返回 false（温度 < 0.01 或达最大迭代数）即视为收敛。额外加一条业务收敛规则——连续 20 次迭代中节点最大位移 < 0.5px 时提前停止，避免温度冷却后期的无效计算。

**拖拽联动**：用户拖拽节点时 `pauseForDrag()` 静音 Ticker（不再全局迭代），松手后 `resumeAfterDrag()`；拖拽期间被拖节点位置直接由手势更新，邻边实时跟随重绘。

## 7. Canvas 图谱渲染器

### 7.1 渲染管线

```
graphDataProvider 数据就绪
    │
    ▼
┌─────────────────────────────────────────────┐
│ GraphRenderer.paint (CustomPainter)          │
│  1. 坐标系变换 (缩放 scale / 平移 offset)      │
│  2. 绘制边 (贝塞尔曲线 + 箭头)                 │
│  3. 绘制节点 (圆形 + 边框 + 文字)              │
│  4. 绘制选中态 / 路径高亮 / 薄弱点脉冲          │
│  5. LOD 裁剪 (视口外节点/标签直接跳过)         │
└─────────────────────────────────────────────┘
    │
    ▼
RepaintBoundary 隔离重绘区域
```

渲染性能红线：单帧绘制预算 8ms（60fps 下 16ms 的一半），超过时触发 §14 降级 D7（简化渲染档）。

### 7.2 渲染器实现

```dart
// lib/features/knowledge_graph/engine/graph_renderer.dart

import 'dart:math';
import 'package:flutter/material.dart';
import '../models/graph_node.dart';
import '../models/graph_edge.dart';
import 'node_style_resolver.dart';

/// Canvas 图谱渲染器
class GraphRenderer extends CustomPainter {
  final List<GraphNode> nodes;
  final List<GraphEdge> edges;
  final NodeStyleResolver styleResolver;

  // 视图变换
  final double scale;       // 缩放系数 0.3 ~ 3.0
  final Offset offset;      // 平移量

  // 高亮状态
  final int? selectedNodeId;
  final Set<int> highlightedPath;   // 推荐路径/传播路径高亮节点
  final Set<int> highlightedEdges;
  final bool simpleMode;            // 降级简化渲染 (D7)

  // LOD 阈值
  static const double _labelMinScale = 0.55;   // 缩放小于此值不画文字
  static const double _arrowMinScale = 0.45;   // 缩放小于此值不画箭头
  static const double _edgeLabelMinScale = 0.8;

  GraphRenderer({
    required this.nodes,
    required this.edges,
    required this.styleResolver,
    this.scale = 1.0,
    this.offset = Offset.zero,
    this.selectedNodeId,
    this.highlightedPath = const {},
    this.highlightedEdges = const {},
    this.simpleMode = false,
  });

  @override
  void paint(Canvas canvas, Size size) {
    canvas.save();
    canvas.translate(offset.dx, offset.dy);
    canvas.scale(scale);

    final viewport = Rect.fromLTWH(
      -offset.dx / scale, -offset.dy / scale,
      size.width / scale, size.height / scale,
    ).inflate(60); // 视口外 60 逻辑像素即裁剪

    // 1. 边
    for (final edge in edges) {
      final source = _nodeById(edge.sourceId);
      final target = _nodeById(edge.targetId);
      if (source == null || target == null) continue;
      if (!_intersectsViewport(viewport, source, target)) continue;
      _paintEdge(canvas, edge, source, target);
    }

    // 2. 节点
    for (final node in nodes) {
      if (!viewport.contains(node.position)) continue;
      _paintNode(canvas, node);
    }

    canvas.restore();
  }

  void _paintEdge(Canvas canvas, GraphEdge edge, GraphNode source, GraphNode target) {
    final isHighlighted = highlightedEdges.contains(edge.id);
    final isPath = edge.type == GraphEdgeType.prerequisite;

    final paint = Paint()
      ..style = PaintingStyle.stroke
      ..strokeWidth = (isHighlighted ? 3.0 : isPath ? 1.8 : 1.2) / scale.clamp(0.5, 2.0)
      ..color = isHighlighted
          ? const Color(0xFF1565C0)
          : isPath
              ? const Color(0xFF90A4AE)
              : const Color(0xFFCFD8DC);

    // 贝塞尔曲线：控制点为两端点中点沿法向偏移
    final mid = (source.position + target.position) / 2;
    final delta = target.position - source.position;
    final normal = Offset(-delta.dy, delta.dx) * 0.12;
    final control = mid + normal;

    final path = Path()
      ..moveTo(source.position.dx, source.position.dy)
      ..quadraticBezierTo(control.dx, control.dy, target.position.dx, target.position.dy);
    canvas.drawPath(path, paint);

    // 箭头（前置关系 + 缩放足够时）
    if (edge.type == GraphEdgeType.prerequisite && scale > _arrowMinScale) {
      _paintArrow(canvas, control, target.position, paint.color);
    }
  }

  void _paintArrow(Canvas canvas, Offset from, Offset to, Color color) {
    final dir = (to - from);
    final len = sqrt(dir.dx * dir.dx + dir.dy * dir.dy);
    if (len < 1) return;
    final unit = dir / len;
    final tip = to - unit * 8; // 箭头起点距目标节点 8px
    final perp = Offset(-unit.dy, unit.dx) * 5;
    final arrowPath = Path()
      ..moveTo(tip.dx, tip.dy)
      ..lineTo((tip - unit * 8 + perp).dx, (tip - unit * 8 + perp).dy)
      ..lineTo((tip - unit * 8 - perp).dx, (tip - unit * 8 - perp).dy)
      ..close();
    canvas.drawPath(arrowPath, Paint()..color = color);
  }

  void _paintNode(Canvas canvas, GraphNode node) {
    final radius = node.radius;
    final isSelected = node.id == selectedNodeId;
    final inPath = highlightedPath.contains(node.id);

    // 简化渲染档：圆点代替圆形卡片
    if (simpleMode) {
      canvas.drawCircle(
        node.position,
        radius * 0.6,
        Paint()..color = styleResolver.resolveFillColor(node),
      );
      return;
    }

    // 薄弱点脉冲光环（仅选中节点为薄弱点时，避免全图闪烁）
    if (node.isWeakPoint && isSelected) {
      final pulsePaint = Paint()
        ..color = Colors.redAccent.withOpacity(0.25)
        ..style = PaintingStyle.stroke
        ..strokeWidth = 3;
      canvas.drawCircle(node.position, radius + 6, pulsePaint);
    }

    // 节点圆
    final fillPaint = Paint()
      ..color = styleResolver.resolveFillColor(node)
      ..style = PaintingStyle.fill;
    canvas.drawCircle(node.position, radius, fillPaint);

    // 边框
    final border = styleResolver.resolveBorder(node);
    if (border.width > 0 || isSelected || inPath) {
      final borderPaint = Paint()
        ..color = isSelected
            ? const Color(0xFF1565C0)
            : inPath
                ? const Color(0xFF1565C0).withOpacity(0.7)
                : border.color
        ..style = PaintingStyle.stroke
        ..strokeWidth = isSelected ? 3.0 : border.width.clamp(1.0, 3.0);
      canvas.drawCircle(node.position, radius, borderPaint);
    }

    // 高频考点星标
    if (node.isHighFreqExam && scale > _labelMinScale) {
      _paintStar(canvas, node.position + Offset(radius * 0.7, -radius * 0.7), 5.0);
    }

    // 文字（缩放足够 + 非简化档）
    if (scale > _labelMinScale) {
      _paintLabel(canvas, node, radius);
    }
  }

  void _paintLabel(Canvas canvas, GraphNode node, double radius) {
    final maxLen = styleResolver.maxLabelLength;
    var label = node.name;
    if (label.length > maxLen) {
      label = '${label.substring(0, maxLen)}…';
    }
    final textPainter = TextPainter(
      text: TextSpan(
        text: label,
        style: styleResolver.resolveTextStyle(node).copyWith(
          fontSize: styleResolver.resolveTextStyle(node).fontSize! / scale.clamp(0.7, 1.4),
        ),
      ),
      textDirection: TextDirection.ltr,
      maxLines: 2,
      ellipsis: '…',
    )..layout(maxWidth: radius * 2.4);

    textPainter.paint(
      canvas,
      node.position - Offset(textPainter.width / 2, textPainter.height / 2),
    );
  }

  void _paintStar(Canvas canvas, Offset center, double radius) {
    final path = Path();
    for (var i = 0; i < 10; i++) {
      final r = i.isEven ? radius : radius * 0.45;
      final angle = (pi / 5) * i - pi / 2;
      final pt = center + Offset(r * cos(angle), r * sin(angle));
      if (i == 0) {
        path.moveTo(pt.dx, pt.dy);
      } else {
        path.lineTo(pt.dx, pt.dy);
      }
    }
    path.close();
    canvas.drawPath(path, Paint()..color = Colors.amber.shade700);
  }

  GraphNode? _nodeById(int id) {
    for (final n in nodes) {
      if (n.id == id) return n;
    }
    return null;
  }

  bool _intersectsViewport(Rect viewport, GraphNode a, GraphNode b) {
    final minX = min(a.position.dx, b.position.dx);
    final maxX = max(a.position.dx, b.position.dx);
    final minY = min(a.position.dy, b.position.dy);
    final maxY = max(a.position.dy, b.position.dy);
    return viewport.overlaps(Rect.fromLTRB(minX, minY, maxX, maxY));
  }

  @override
  bool shouldRepaint(covariant GraphRenderer oldDelegate) {
    return oldDelegate.scale != scale ||
        oldDelegate.offset != offset ||
        oldDelegate.selectedNodeId != selectedNodeId ||
        oldDelegate.simpleMode != simpleMode ||
        oldDelegate.highlightedPath != highlightedPath ||
        oldDelegate.highlightedEdges != highlightedEdges ||
        !identical(oldDelegate.nodes, nodes);
  }
}
```

### 7.3 重绘触发规则

| 触发源 | 重绘范围 | 说明 |
|--------|----------|------|
| 手势缩放/平移 | 整画布 | 60fps 目标，绘制预算超 8ms 自动跳帧降级 |
| 布局迭代 tick | 整画布 | 收敛后自动停止 |
| 节点选中变化 | 整画布（节点数少）/ 脏区（节点数多） | 选中态仅边框与脉冲光环 |
| 掌握度更新 | 仅受影响的节点 + 图例 | SSE 推送或学习返回后局部刷新 |
| 主题/学段切换 | 整画布 | 样式解析器重算 |

掌握度局部刷新：数据层维护 `Map<nodeId, MasteryVersion>`，收到更新后仅对 version 变化的节点调用 `markNeedsPaint`，避免整图重绘（§15 指标 M3）。

### 8.2 手势处理器

```dart
/// 图谱手势处理器
class GraphGestureHandler {

  final double scale;
  final Offset offset;
  final void Function(Offset logicalPoint) onTapBlank;
  final void Function(GraphNode node) onTapNode;
  final void Function(GraphNode node) onLongPressNode;
  final void Function(Offset anchor) onDoubleTap;
  final void Function(Offset delta) onPanUpdate;
  final void Function(double newScale, Offset focalLogical) onScaleUpdate;
  final void Function(GraphNode node, Offset position) onNodeDrag;

  // 阈值
  final double tapSlop;       // 小学 16.0，其余 8.0
  final double longPressMs;   // 500

  Offset? _panStartLogical;
  GraphNode? _dragCandidate;
  bool _isDraggingNode = false;

  GraphGestureHandler({
    required this.nodes,
    required this.scale,
    required this.offset,
    required this.onTapBlank,
    required this.onTapNode,
    required this.onLongPressNode,
    required this.onDoubleTap,
    required this.onPanUpdate,
    required this.onScaleUpdate,
    required this.onNodeDrag,
    this.tapSlop = 8.0,
    this.longPressMs = 500,
  });

  /// 屏幕坐标 → 图谱逻辑坐标
  Offset toLogical(Offset screen) => (screen - offset) / scale;

  /// 命中测试：返回距点击位置最近的节点（需在节点半径 + 4px 容差内）
  GraphNode? hitTest(Offset screenPoint) {
    final logical = toLogical(screenPoint);
    GraphNode? best;
    var bestDist = double.infinity;
    for (final node in nodes) {
      final d = (node.position - logical).distance;
      if (d <= node.radius + 4 && d < bestDist) {
        best = node;
        bestDist = d;
      }
    }
    return best;
  }

  void onTapDown(TapDownDetails details) {
    _dragCandidate = hitTest(details.localPosition);
    _panStartLogical = details.localPosition;
    _isDraggingNode = false;
  }

  void onPanStart(DragStartDetails details) {
    _panStartLogical = details.localPosition;
    _dragCandidate = hitTest(details.localPosition);
    _isDraggingNode = false;
  }

  void onPanUpdate(DragUpdateDetails details) {
    final moved = (details.localPosition - _panStartLogical!).distance;
    if (!_isDraggingNode && _dragCandidate != null && moved > tapSlop) {
      _isDraggingNode = true; // 转为节点拖拽
    }
    if (_isDraggingNode && _dragCandidate != null) {
      _dragCandidate!.position = toLogical(details.localPosition);
      onNodeDrag(_dragCandidate!, _dragCandidate!.position);
    } else if (moved > tapSlop) {
      onPanUpdate(details.delta);
    }
  }

  void onPanEnd(DragEndDetails details) {
    _dragCandidate = null;
    _isDraggingNode = false;
    _panStartLogical = null;
  }

  void onTapUp(TapUpDetails details) {
    // 位移未超阈值才算 Tap
    if (_panStartLogical != null &&
        (details.localPosition - _panStartLogical!).distance <= tapSlop) {
      final node = hitTest(details.localPosition);
      if (node != null) {
        onTapNode(node);
      } else {
        onTapBlank(toLogical(details.localPosition));
      }
    }
  }

  /// 缩放：以双指焦点为锚点，保持焦点处图谱点不动
  void onScaleStart(ScaleStartDetails details) {
    // 记录锚点，更新时按 newScale 反推 offset
  }

  void applyScale(double newScale, Offset focalScreen, Size viewport) {
    final clamped = newScale.clamp(0.3, 3.0);
    final focalLogical = toLogical(focalScreen);
    // 保持 focalLogical 在缩放后仍位于 focalScreen：
    // offset' = focalScreen - focalLogical * clamped
    final newOffset = focalScreen - Offset(
      focalLogical.dx * clamped,
      focalLogical.dy * clamped,
    );
    onScaleUpdate(clamped, newOffset);
  }
}
```

**手势仲裁规则**:
- G-T1: Tap 与 Pan 以 `tapSlop`（小学 16px / 其他 8px）区分，未超阈值抬手才算 Tap，防"拖动误触发选中"。
- G-T2: 节点拖拽优先于画布平移——起始落点命中节点且位移超阈值后，该手势生命周期内不再触发画布平移。
- G-T3: 双指手势一旦识别，单指拖拽立即取消（`GestureDetector` 竞争胜出即回调 `onScaleStart`）。
- G-T4: 详情面板展开期间，画布手势正常可用（面板为底部 Sheet，不遮挡画布主区），但节点拖拽禁用，防止与面板滑动手势冲突。

### 10.2 图谱页面生命周期状态机

与 E2E §4.1 权威状态词汇对齐：

```
┌────────┐  进入页面   ┌─────────┐  数据就绪   ┌───────────┐  布局收敛   ┌───────┐
│  IDLE  │──────────▶│ LOADING │────────────▶│ RENDERING │────────────▶│ READY │
└────────┘           └─────────┘             └───────────┘             └───────┘
                        │ 缓存命中                              选中节点    │
                        ▼                                     ┌───────────┤
                   RENDERING(缓存)                            ▼           │
                                                   ┌──────────────┐  关闭面板  │
                                                   │ INTERACTING  │───────────┘
                                                   └──────────────┘
                        任意状态 ──退出页面──▶ DISPOSED（释放 Ticker/Bitmap/Provider）
```

**守卫（G1-G10）**:

| 守卫 | 规则 | 违反后果 |
|------|------|----------|
| G1 | `DISPOSED` 为终态，不可回流 | 内存泄漏（Ticker 未停） |
| G2 | `LOADING` 期间禁止布局计算（数据未到） | 空跑浪费电量 |
| G3 | `RENDERING` 期间用户手势可平移缩放，但禁止节点拖拽（位置未稳定） | 布局震荡 |
| G4 | 缓存先行渲染必须标注"数据可能不是最新"（GRAPH_004 语义） | 误导学生 |
| G5 | `INTERACTING` 状态收到掌握度 SSE 推送时，详情面板字段局部刷新，不收起面板 | 打断学习 |
| G6 | 学科/章节切换必须先回 `LOADING`，禁止在旧图上直接换数据 | 节点 ID 冲突 |
| G7 | 页面退后台 > 5 分钟回前台：若 `data.meta.lastUpdatedAt` 超过 10 分钟则静默刷新 | 数据陈旧 |
| G8 | 布局引擎单写者：仅 `LayoutScheduler` 可调用 `engine.step()` | 并发迭代崩溃 |
| G9 | `READY` 状态下收到 `GRAPH_003`（构建中）响应 → 保持当前图 + 顶部横幅"图谱更新中"，不整页报错 | 体验闪断 |
| G10 | 多孩子切换时销毁全部图谱 Provider 状态（命名空间见 R10） | 串号 |

### 10.3 掌握度状态适配（承载 F5）

v1.0 的 `MasteryLevel`（unknown/weak/learning/fair/good/mastered）与 E2E 权威 `MasteryStatus`（NOT_STARTED/WEAK/PARTIALLY_MASTERED/MOSTLY_MASTERED/MASTERED/NEEDS_REVIEW）词汇不一致。裁决：**E2E 为权威**，客户端内部统一使用 `MasteryStatus`，网络层解析时适配：

```dart
// lib/features/knowledge_graph/models/mastery_adapter.dart

/// E2E MasteryStatus 权威枚举
enum MasteryStatus {
  notStarted,         // NOT_STARTED
  weak,               // WEAK (正确率<30%)
  partiallyMastered,  // PARTIALLY_MASTERED (30%~60%)
  mostlyMastered,     // MOSTLY_MASTERED (60%~85%)
  mastered,           // MASTERED (>85%)
  needsReview,        // NEEDS_REVIEW (长期未复习)
}

class MasteryAdapter {
  static MasteryStatus fromApi(String status, double level) {
    switch (status) {
      case 'NOT_STARTED':       return MasteryStatus.notStarted;
      case 'WEAK':              return MasteryStatus.weak;
      case 'PARTIALLY_MASTERED':return MasteryStatus.partiallyMastered;
      case 'MOSTLY_MASTERED':   return MasteryStatus.mostlyMastered;
      case 'MASTERED':          return MasteryStatus.mastered;
      case 'NEEDS_REVIEW':      return MasteryStatus.needsReview;
      default:
        // 服务端未下发 status 时的降级推导（GRAPH_003 场景）
        if (level <= 0) return MasteryStatus.notStarted;
        if (level < 0.3) return MasteryStatus.weak;
        if (level < 0.6) return MasteryStatus.partiallyMastered;
        if (level < 0.85) return MasteryStatus.mostlyMastered;
        return MasteryStatus.mastered;
    }
  }

  /// 权威色值映射（与 E2E §4.2 完全一致；NEEDS_REVIEW 紫色为防"已掌握却变红"误解）
  static int toArgb(MasteryStatus s) {
    switch (s) {
      case MasteryStatus.notStarted:        return 0xFFE0E0E0;
      case MasteryStatus.weak:              return 0xFFE53935;
      case MasteryStatus.partiallyMastered: return 0xFFFF9800;
      case MasteryStatus.mostlyMastered:    return 0xFF4CAF50;
      case MasteryStatus.mastered:          return 0xFF1565C0;
      case MasteryStatus.needsReview:       return 0xFFAB47BC;
    }
  }

  static String label(MasteryStatus s) {
    switch (s) {
      case MasteryStatus.notStarted:        return '未学习';
      case MasteryStatus.weak:              return '薄弱';
      case MasteryStatus.partiallyMastered: return '部分掌握';
      case MasteryStatus.mostlyMastered:    return '基本掌握';
      case MasteryStatus.mastered:          return '已掌握';
      case MasteryStatus.needsReview:       return '需复习';
    }
  }
}
```

> v1.0 §3.1 的 `MasteryLevel` 与 §6.2 `_cartoonMasteryColor` 在实现时按上表替换（v1.0 代码标记 deprecated）。

## 11. 缓存策略

与 E2E §8.1 权威口径对齐：

| 数据 | 存储 | TTL | 失效触发 |
|------|------|-----|----------|
| 子图结构（节点+边） | SQLite 表 `kg_subgraph`（主键 subjectId+chapterId） | 24h | 进入页面后台静默刷新；学习完成事件 |
| 掌握度数据 | 内存 Map + 版本号 | 10min | 学习动作返回/SSE 推送即刷新 |
| 节点详情 | 内存 LRU（50 个，`LruCache<String, NodeDetail>`） | 10min | 点击时条件刷新（lastUpdatedAt 过期才请求） |
| 学习路径 | 内存 | 30min | 路径节点完成 |
| 渲染 Bitmap | 内存（MiniGraphCard 用） | 无 | 节点数据变化重绘 |
| 图谱搜索索引 | 本地缓存节点的名称倒排 | 随子图缓存 | 子图刷新时重建 |

**命名空间隔离**：SQLite 与内存缓存 Key 统一带 `profileId` 前缀（多孩子切换，承载 G10），格式 `kg:{profileId}:subgraph:{subjectId}:{chapterId}`。

**掌握度增量更新**：学习模块完成回调或 SSE 推送到达后，`graphDataProvider` 对更新节点执行局部 `copyWith`，bump `MasteryVersion`，渲染层仅重绘受影响节点（§7.3）。

| D7 | 单帧绘制 > 8ms | LOD 升档：砍标签→砍箭头→简化渲染，逐级降 | 手势静止 2s 后尝试回升 |
| D8 | 后台 isolate 布局失败 | 回退 UI isolate 每帧 1 迭代（慢但不崩） | — |
| D9 | SSE 推送中断 | 掌握度退化为进入页面时主动刷新（10min TTL） | SSE 重连 |
| D10 | 磁盘缓存损坏（SQLite 异常） | 清空 kg_* 表重建，降级为纯在线模式 | 自动 |
