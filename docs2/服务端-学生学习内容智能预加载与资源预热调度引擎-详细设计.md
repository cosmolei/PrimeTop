## 1. 概述

### 1.1 功能定位

学生学习内容智能预加载与资源预热调度引擎（以下简称"预加载引擎"或"PrefetchEngine"）是 PrimeTop 服务端的核心体验优化中间件，负责在学生当前学习活动进行期间，**预测学生下一步可能访问的内容**，并提前完成资源准备（包括 AI 推理预计算、CDN 边缘缓存预热、数据库预读取、个性化推荐预生成），从而实现学生切换学习内容时的"零等待"体验。

### 1.2 与客户端预加载的区别

| 维度 | 客户端预加载 | 本引擎（服务端预加载） |
|------|-------------|----------------------|
| **位置** | APP 内部 | 服务端 / 边缘节点 |
| **对象** | 已知 URL 的图片、视频、HTML | AI 推理结果、推荐列表、个性化内容 |
| **时机** | 页面跳转前的瞬间 | 学习会话进行中的持续预测 |
| **计算** | 简单 HTTP 预取 | 模型推理、RAG 检索、推荐生成 |
| **预算** | 用户流量 / 本地存储 | 服务器算力 / 缓存容量 |

### 1.3 适用场景

1. **同步课堂章节浏览**：学生学习第3节时，预加载第4节内容和练习题。
2. **AI 辅导对话**：学生提问后，预测可能的追问并预生成回答。
3. **练习答题**：学生完成当前题目后，预准备下一题的解析和知识点关联。
4. **错题复习**：学生复习错题时，预加载相关知识点讲解和同类题推荐。
5. **首页工作台**：学生打开 APP 时，根据时间/日期/学习计划预聚合首屏数据。

### 1.4 设计目标

| 指标 | 目标值 |
|------|--------|
| 预加载命中率 | ≥ 65%（即 65% 的预加载内容被学生实际访问） |
| 内容切换耗时 | P95 < 200ms（命中缓存时） |
| 预算利用率 | ≥ 80%（分配的预加载预算被有效使用） |
| 预加载错误率 | < 1%（预加载内容与学生实际访问内容不匹配） |
| 单用户预加载成本增量 | ≤ 原始 AI 调用成本的 30% |

### 2.2 核心组件

| 组件 | 职责 |
|------|------|
| **Predictor** | 基于学习路径、行为序列、时间模式预测学生下一步可能访问的内容 |
| **BudgetMgr** | 管理预加载资源预算，防止过度预加载浪费算力和存储 |
| **TaskQueue** | 预加载任务优先级队列，支持异步执行和去重 |
| **Scheduler** | 调度核心，协调各 Worker 执行预加载任务 |
| **AI PreCompute Worker** | 预执行 AI 推理（如常见追问的预回答） |
| **Recommend PreGen Worker** | 预生成个性化推荐列表 |
| **CDN PreWarmer** | 向 CDN 边缘节点推送即将被访问的多媒体资源 |
| **Data PreFetch Worker** | 预先查询和组装数据库中的学习内容数据 |
| **Analytics** | 追踪预加载命中率、成本、延迟等指标 |

## 4. 预测模型设计

### 4.1 预测策略总览

引擎采用**多策略融合**的预测方法，不同场景使用不同策略：

| 场景 | 策略 | 数据来源 | 预测准确率目标 |
|------|------|----------|---------------|
| 同步课堂章节浏览 | 路径序列预测 | 教材章节顺序 + 学习进度 | ≥ 80% |
| 练习答题 | 题序预测 | 组卷顺序 + 难度梯度 | ≥ 85% |
| AI 辅导追问 | 意图树预测 | 对话历史 + 意图分类 | ≥ 60% |
| 错题复习 | 复习队列预测 | 错题列表 + 间隔重复算法 | ≥ 75% |
| 首页推荐 | 时段模式预测 | 历史时段行为统计 | ≥ 50% |

### 4.2 路径序列预测

基于教材章节结构和学生当前学习进度，预测学生接下来最可能访问的章节。

```java
/**
 * 路径序列预测器
 * 基于马尔可夫链 + 教材结构先验
 */
public class PathSequencePredictor {
    
    // 状态转移概率 (从章节A跳转到章节B的概率)
    // 通过历史行为数据离线训练获得
    private Map<String, Map<String, Double>> transitionMatrix;
    
    // 教材章节顺序 (强先验)
    private Map<String, List<String>> chapterSequence;
    
    /**
     * 预测下一步可能访问的内容
     */
    public List<PredictedTarget> predict(PredictionRequest request) {
        LearningEvent current = request.getCurrentEvent();
        String currentChapterId = current.getChapterId();
        
        List<PredictedTarget> results = new ArrayList<>();
        
        // 策略1: 教材顺序 (下一节) — 高概率
        String nextChapter = getNextChapter(currentChapterId);
        if (nextChapter != null) {
            PredictedTarget t = new PredictedTarget();
            t.setTargetType("CONTENT_PAGE");
            t.setTargetId(nextChapter);
            t.setProbability(0.80);  // 学习下一节的概率很高
            t.setPriority(80);
            results.add(t);
        }
        
        // 策略2: 章节练习题 — 中概率
        String chapterExercises = getChapterExerciseId(currentChapterId);
        if (chapterExercises != null) {
            PredictedTarget t = new PredictedTarget();
            t.setTargetType("QUESTION_SET");
            t.setTargetId(chapterExercises);
            t.setProbability(0.55);
            t.setPriority(60);
            results.add(t);
        }
        
        // 策略3: 马尔可夫转移 (数据驱动)
        Map<String, Double> transitions = transitionMatrix.get(currentChapterId);
        if (transitions != null) {
            for (Map.Entry<String, Double> entry : transitions.entrySet()) {
                String targetChapter = entry.getKey();
                double prob = entry.getValue();
                if (prob > 0.05) {
                    PredictedTarget t = new PredictedTarget();
                    t.setTargetType("CONTENT_PAGE");
                    t.setTargetId(targetChapter);
                    t.setProbability(prob);
                    t.setPriority((int)(prob * 100));
                    results.add(t);
                }
            }
        }
        
        // 策略4: 知识点关联推荐 — 低概率但高价值
        List<String> relatedPoints = getRelatedKnowledgePoints(current.getKnowledgePointId());
        for (String kpId : relatedPoints) {
            PredictedTarget t = new PredictedTarget();
            t.setTargetType("CONTENT_PAGE");
            t.setTargetId(kpId);
            t.setProbability(0.15);
            t.setPriority(30);
            results.add(t);
        }
        
        // 按概率排序, 截断
        results.sort((a, b) -> Double.compare(b.getProbability(), a.getProbability()));
        return results.subList(0, Math.min(results.size(), 
            request.getBudget().getMaxLookaheadItems()));
    }
}
```

### 4.3 AI 追问意图树预测

在 AI 辅导对话中，学生提问后系统预测可能的追问方向：

```java
/**
 * 追问意图树预测器
 */
public class FollowupQuestionPredictor {
    
    // 意图树: 每种学生问题类型对应的常见追问方向
    private Map<String, List<FollowupPattern>> intentTree;
    
    /**
     * 示例意图树:
     * 
     * "概念讲解" → [
     *   (0.35, "再讲简单点"),
     *   (0.25, "举个例子"),
     *   (0.15, "这个知识点考试怎么考"),
     *   (0.10, "继续追问更深入内容"),
     *   (0.05, "生成同类题"),
     *   (0.05, "换个角度解释"),
     *   (0.05, "和之前学过的XXX有什么区别")
     * ]
     * 
     * "解题推导" → [
     *   (0.30, "第二步为什么这样做"),
     *   (0.20, "有没有更简单的方法"),
     *   (0.15, "如果条件变了怎么办"),
     *   (0.15, "这道题的易错点是什么"),
     *   (0.10, "生成同类题练习"),
     *   (0.05, "用到哪些公式"),
     *   (0.05, "考试中常见变式")
     * ]
     */
    
    public List<PredictedTarget> predict(PredictionRequest request) {
        // 1. 分类当前问题的意图
        String intent = classifyIntent(request.getCurrentEvent());
        
        // 2. 获取该意图的常见追问模式
        List<FollowupPattern> patterns = intentTree.getOrDefault(intent, Collections.emptyList());
        
        // 3. 生成预加载目标
        List<PredictedTarget> results = new ArrayList<>();
        for (FollowupPattern p : patterns) {
            // 只预加载概率 > 15% 的追问 (控制成本)
            if (p.probability > 0.15) {
                PredictedTarget t = new PredictedTarget();
                t.setTargetType("AI_RESPONSE");
                t.setTargetId(buildCacheKey(request, p));
                t.setParams(buildPrefetchPrompt(request, p));
                t.setProbability(p.probability);
                t.setPriority((int)(p.probability * 100));
                t.setEstimatedCostTokens(estimateTokens(request, p));
                results.add(t);
            }
        }
        
        return results;
    }
    
    /** 构建预加载用的 Prompt */
    private Map<String, Object> buildPrefetchPrompt(PredictionRequest req, FollowupPattern p) {
        Map<String, Object> params = new HashMap<>();
        params.put("originalQuestion", req.getCurrentEvent().getMetadata().get("question"));
        params.put("originalAnswer", req.getCurrentEvent().getMetadata().get("answer"));
        params.put("followupType", p.getType());
        params.put("studentGrade", req.getStudentContext().getGrade());
        params.put("subject", req.getCurrentEvent().getMetadata().get("subject"));
        return params;
    }
}
```

### 4.4 练习题序预测

```java
/**
 * 练习题序预测器
 * 基于组卷序列 + 自适应难度调节预测下一题
 */
public class QuestionSequencePredictor {
    
    public List<PredictedTarget> predict(PredictionRequest request) {
        List<PredictedTarget> results = new ArrayList<>();
        
        // 获取当前练习会话信息
        String sessionId = request.getSessionId();
        PracticeSession session = getPracticeSession(sessionId);
        
        if (session == null || session.isLastQuestion()) {
            return results;
        }
        
        // 策略1: 按顺序的下一题 (最可能) — 概率 0.90
        Question nextQ = session.getNextQuestion();
        if (nextQ != null) {
            results.add(buildQuestionTarget(nextQ, 0.90, 90));
            
            // 预加载下下题 — 概率 0.60
            Question nextNextQ = session.getQuestionAfter(nextQ.getId());
            if (nextNextQ != null) {
                results.add(buildQuestionTarget(nextNextQ, 0.60, 55));
            }
        }
        
        // 策略2: 自适应难度 — 如果当前题做错了, 可能需要更简单的同类题
        if (request.getCurrentEvent().isAnswerWrong()) {
            Question easierQ = questionBank.findSimilarQuestion(
                request.getCurrentEvent().getContentId(),
                DifficultyUtils.lower(session.getCurrentDifficulty())
            );
            if (easierQ != null) {
                results.add(buildQuestionTarget(easierQ, 0.40, 50));
            }
        }
        
        // 策略3: 当前题的解析内容预加载
        if (nextQ != null) {
            PredictedTarget analysis = new PredictedTarget();
            analysis.setTargetType("QUESTION_ANALYSIS");
            analysis.setTargetId(nextQ.getId() + ":analysis");
            analysis.setProbability(0.85);  // 学生很可能看解析
            analysis.setPriority(75);
            results.add(analysis);
```

### 6.1 调度器架构

```java
/**
 * 预加载调度核心
 */
public class PrefetchScheduler {
    
    private final PriorityTaskQueue taskQueue;
    private final BudgetManager budgetManager;
    private final List<PrefetchWorker> workers;
    private final PrefetchCache cache;
    private final PrefetchAnalytics analytics;
    
    // 每用户并发控制
    private final Map<Long, Semaphore> userConcurrencyLimits = new ConcurrentHashMap<>();
    
    /**
     * 提交预加载任务
     */
    public List<String> submitTasks(Long userId, String sessionId, 
                                     List<PredictionResult.PredictedTarget> targets,
                                     PredictionBudget budget) {
        List<String> taskIds = new ArrayList<>();
        
        for (PredictionResult.PredictedTarget target : targets) {
            // 1. 预算检查
            if (!budgetManager.canAfford(userId, target)) {
                continue;
            }
            
            // 2. 去重检查 (是否已有相同任务的缓存)
            String cacheKey = buildCacheKey(userId, target);
            if (cache.exists(cacheKey)) {
                continue;  // 已有缓存, 跳过
            }
            
            // 3. 创建任务
            PrefetchTask task = PrefetchTask.builder()
                .taskId(generateTaskId())
                .userId(userId)
                .sessionId(sessionId)
                .targetType(target.getTargetType())
                .targetId(target.getTargetId())
                .targetParams(target.getParams())
                .priority(target.getPriority())
                .estCostTokens(target.getEstimatedCost())
                .cacheKey(cacheKey)
                .cacheTtl(calculateTtl(target))
                .status("PENDING")
                .expiredAt(LocalDateTime.now().plusSeconds(budget.getPredictionWindowS() * 3))
                .build();
            
            // 4. 入队
            taskQueue.offer(task);
            taskIds.add(task.getTaskId());
            
            // 5. 预留预算
            budgetManager.reserve(userId, target.getEstimatedCost());
        }
        
        return taskIds;
    }
    
    /**
     * 任务执行循环 (Worker 线程)
     */
    @Scheduled(fixedDelay = 100)  // 每100ms轮询
    public void executeTasks() {
        while (!taskQueue.isEmpty()) {
            PrefetchTask task = taskQueue.poll();
            if (task == null) break;
            
            // 检查是否过期
            if (task.getExpiredAt().isBefore(LocalDateTime.now())) {
                task.setStatus("EXPIRED");
                analytics.recordExpired(task);
                budgetManager.release(task.getUserId(), task.getEstCostTokens());
                continue;
            }
            
            // 检查并发限制
            Semaphore sem = userConcurrencyLimits.computeIfAbsent(
                task.getUserId(), k -> new Semaphore(3));
            if (!sem.tryAcquire()) {
                // 放回队列, 稍后重试
                taskQueue.offerWithDelay(task, 200);
                continue;
            }
            
            // 异步执行
            CompletableFuture.runAsync(() -> {
                try {
                    executeTask(task);
                } finally {
                    sem.release();
                }
            }, prefetchExecutor);
        }
    }
    
    /**
     * 执行单个预加载任务
     */
    private void executeTask(PrefetchTask task) {
        long start = System.currentTimeMillis();
        task.setStatus("EXECUTING");
        
        try {
            Object result = null;
            
            // 根据目标类型分派到不同 Worker
            switch (task.getTargetType()) {
                case "AI_RESPONSE":
                    result = aiPreComputeWorker.preCompute(task);
                    break;
                case "CONTENT_PAGE":
                    result = dataPreFetchWorker.preFetch(task);
                    break;
                case "QUESTION":
                case "QUESTION_SET":
                    result = dataPreFetchWorker.preFetchQuestions(task);
                    break;
                case "QUESTION_ANALYSIS":
                    result = aiPreComputeWorker.preComputeAnalysis(task);
                    break;
                case "RECOMMENDATION_LIST":
                    result = recommendPreGenWorker.preGenerate(task);
                    break;
                case "MEDIA_FILE":
                    cdnPreWarmer.preWarm(task);
                    result = Map.of("warmed", true);
                    break;
                default:
                    log.warn("Unknown prefetch target type: {}", task.getTargetType());
                    return;
            }
            
            // 写入缓存
            if (result != null) {
                cache.put(task.getCacheKey(), result, task.getCacheTtl());
            }
            
            task.setStatus("COMPLETED");
            task.setCompletedAt(LocalDateTime.now());
            
        } catch (Exception e) {
            task.setStatus("FAILED");
            log.error("Prefetch task failed: {}", task.getTaskId(), e);
            budgetManager.refund(task.getUserId(), task.getEstCostTokens());
        } finally {
            long elapsed = System.currentTimeMillis() - start;
            metrics.recordPrefetchExecution(task.getTargetType(), elapsed);
        }
    }
}
```

### 6.2 任务优先级队列

```java
/**
 * 优先级任务队列 (基于 Redis ZSET)
 * - 优先级高的任务先执行
 * - 支持延迟重试
 * - 支持任务去重
 */
public class PriorityTaskQueue {
    
    private static final String QUEUE_KEY = "prefetch:task_queue";
    private static final String DEDUP_KEY = "prefetch:dedup";
    
    @Autowired
    private RedisTemplate<String, String> redis;
    
    /**
     * 入队
     */
    public void offer(PrefetchTask task) {
        // 去重: 同一用户+同一目标的任务不重复入队
        String dedupField = task.getUserId() + ":" + task.getTargetType() + ":" + task.getTargetId();
        if (redis.opsForHash().putIfAbsent(DEDUP_KEY, dedupField, task.getTaskId()) == null) {
            return;  // 已存在相同任务
        }
        
        // 设置去重键过期
        redis.expire(DEDEDUP_KEY + ":" + dedupField, task.getCacheTtl(), TimeUnit.SECONDS);
        
        // 入队 (score = priority)
        String taskJson = JsonUtils.toJson(task);
        redis.opsForZSet().add(QUEUE_KEY, taskJson, task.getPriority());
    }
    
    /**
     * 出队 (取优先级最高的)
     */
    public PrefetchTask poll() {
        Set<ZSetOperations.TypedTuple<String>> result = redis.opsForZSet()
            .reverseRangeWithScores(QUEUE_KEY, 0, 0);
        
        if (result == null || result.isEmpty()) return null;
        
        String taskJson = result.iterator().next().getValue();
        redis.opsForZSet().remove(QUEUE_KEY, taskJson);
        
        return JsonUtils.fromJson(taskJson, PrefetchTask.class);
    }
    
    /**
     * 延迟入队
     */
    public void offerWithDelay(PrefetchTask task, int delayMs) {
        CompletableFuture.runAsync(() -> {
            try { Thread.sleep(delayMs); } catch (InterruptedException ignored) {}
            offer(task);
        }, prefetchExecutor);
    }
    
    /**
     * 取消会话所有任务
     */
    public void cancelBySession(String sessionId) {
        // 扫描队列, 移除属于该 session 的任务
        Set<String> all = redis.opsForZSet().range(QUEUE_KEY, 0, -1);
        if (all != null) {
            for (String taskJson : all) {
                PrefetchTask t = JsonUtils.fromJson(taskJson, PrefetchTask.class);
                if (sessionId.equals(t.getSessionId())) {
                    redis.opsForZSet().remove(QUEUE_KEY, taskJson);
                }
            }
        }
    }
}
```

```java
/**
 * 预算管理器
 * 确保预加载不会过度消耗资源
 */
@Component
public class BudgetManager {
    
    @Autowired
    private RedisTemplate<String, String> redis;
    
    private static final String KEY_DAILY_TASKS = "prefetch:budget:tasks:";
    private static final String KEY_DAILY_TOKENS = "prefetch:budget:tokens:";
    private static final String KEY_CONCURRENT = "prefetch:budget:concurrent:";
    
    /**
     * 检查是否有足够预算
     */
    public boolean canAfford(Long userId, PredictionResult.PredictedTarget target) {
        PrefetchBudgetConfig config = getConfig(userId);
        
        // 1. 检查每日任务数
        int dailyTasks = getInt(KEY_DAILY_TASKS + userId + ":" + today());
        if (dailyTasks >= config.getMaxDailyTasks()) {
            return false;
        }
        
        // 2. 检查每日 Token 数
        if (target.getEstimatedCost() > 0) {
            int dailyTokens = getInt(KEY_DAILY_TOKENS + userId + ":" + today());
            if (dailyTokens + target.getEstimatedCost() > config.getMaxDailyTokens()) {
                return false;
            }
        }
        
        // 3. 检查并发任务数
        int concurrent = getInt(KEY_CONCURRENT + userId);
        if (concurrent >= config.getMaxConcurrentTasks()) {
            return false;
        }
        
        return true;
    }
    
    /**
     * 预留预算
     */
    public void reserve(Long userId, int estimatedCost) {
        redis.opsForValue().increment(KEY_DAILY_TASKS + userId + ":" + today(), 1);
        redis.opsForValue().increment(KEY_DAILY_TOKENS + userId + ":" + today(), estimatedCost);
        redis.opsForValue().increment(KEY_CONCURRENT + userId, 1);
        
        // 设置过期
        redis.expire(KEY_DAILY_TASKS + userId + ":" + today(), Duration.ofDays(2));
        redis.expire(KEY_DAILY_TOKENS + userId + ":" + today(), Duration.ofDays(2));
        redis.expire(KEY_CONCURRENT + userId, Duration.ofMinutes(5));  // 并发计数5分钟自动过期
    }
    
    /**
     * 释放预算 (任务取消或过期)
     */
    public void release(Long userId, int estimatedCost) {
        redis.opsForValue().decrement(KEY_DAILY_TASKS + userId + ":" + today());
        redis.opsForValue().decrement(KEY_DAILY_TOKENS + userId + ":" + today(), estimatedCost);
    }
    
    /**
     * 退还预算 (任务执行失败)
     */
    public void refund(Long userId, int estimatedCost) {
        redis.opsForValue().decrement(KEY_DAILY_TOKENS + userId + ":" + today(), estimatedCost);
    }
    
    /**
     * 完成任务 (减少并发计数)
     */
    public void complete(Long userId) {
        redis.opsForValue().decrement(KEY_CONCURRENT + userId);
    }
    
    private String today() {
        return LocalDate.now().toString();
    }
}
```

```java
/**

@Component
public class PrefetchCacheInterceptor implements HandlerInterceptor {
    
    @Autowired
    private PrefetchCache cache;
    
    @Autowired
    private PrefetchHitRepository hitRepo;
    
    @Override
    public boolean preHandle(HttpServletRequest req, HttpServletResponse resp, 
                             Object handler) {
        // 从请求中提取目标信息
        String userId = req.getHeader("X-User-Id");
        String targetType = extractTargetType(req);
        String targetId = extractTargetId(req);
        
        // 查询预加载缓存
        String cacheKey = String.format("prefetch:%s:%s:%s", userId, targetType, targetId);
        PrefetchResult cached = cache.get(cacheKey);
        
        if (cached != null) {
            // 命中! 直接返回缓存结果
            resp.setContentType("application/json;charset=UTF-8");
            resp.setHeader("X-Prefetch-Hit", "true");
            resp.setHeader("X-Prefetch-Saved-Ms", String.valueOf(cached.getEstimatedRealtimeMs()));
            resp.getWriter().write(JsonUtils.toJson(ApiResponse.success(cached.getContent())));
            
            // 异步记录命中
            recordHitAsync(cacheKey, userId, cached);
            
            return false;  // 短路, 不执行后续 Controller
        }
        
        return true;  // 未命中, 继续正常处理
    }
    
    private void recordHitAsync(String cacheKey, String userId, PrefetchResult result) {
        CompletableFuture.runAsync(() -> {
            // 找到对应的预加载任务, 标记为命中
            PrefetchTask task = taskRepo.findByCacheKey(cacheKey);
            if (task != null) {
                task.setHit(true);
                task.setHitAt(LocalDateTime.now());
                taskRepo.save(task);
            }
            
            // 写入命中日志
            PrefetchHitLog log = new PrefetchHitLog();
            log.setTaskId(task != null ? task.getTaskId() : "unknown");
            log.setUserId(Long.valueOf(userId));
            log.setTimeSavedMs(result.getEstimatedRealtimeMs());
            hitRepo.save(log);
            
            // 上报指标
            metrics.recordHit(userId, result.getEstimatedRealtimeMs());
        });
    }
}
```

```java
/**

public class PrefetchInvalidator {
    
    /**
     * 学习会话结束时, 失效所有相关预加载
     */
    public void invalidateSession(Long userId, String sessionId) {
        // 获取该会话所有未命中任务
        List<PrefetchTask> tasks = taskRepo.findActiveBySession(sessionId);
        
        for (PrefetchTask task : tasks) {
            // 取消任务
            task.setStatus("CANCELLED");
            taskRepo.save(task);
            
            // 删除缓存
            cache.delete(task.getCacheKey());
            
            // 释放预算
            budgetManager.release(task.getUserId(), task.getEstCostTokens());
        }
        
        log.info("Invalidated {} prefetch tasks for session {}", tasks.size(), sessionId);
    }
    
    /**
     * 教材版本切换时, 失效所有章节预加载
     */
    public void invalidateOnTextbookChange(Long userId, String oldVersion, String newVersion) {
        cache.deleteByPattern("prefetch:" + userId + ":CONTENT_PAGE:*");
        cache.deleteByPattern("prefetch:" + userId + ":QUESTION_SET:*");
        cache.deleteByPattern("prefetch:" + userId + ":QUESTION_ANALYSIS:*");
        
        log.info("Invalidated all content prefetch for user {} due to textbook change", userId);
    }
}
```

## 10. 状态流转

### 10.1 任务状态机

```
                    ┌──────────┐
                    │ PENDING  │
                    └────┬─────┘
                         │ Scheduler picks up
                         ▼
                    ┌──────────┐
         ┌───────── │EXECUTING │ ─────────┐
         │          └────┬─────┘          │
         │               │ Complete       │ Exception
         │               ▼                ▼
    ┌────┴─────┐   ┌──────────┐    ┌──────┴───┐
    │CANCELLED │   │COMPLETED │    │  FAILED  │
    └──────────┘   └────┬─────┘    └──────────┘
                        │
                        │ TTL expires / Session ends
                        ▼
                   ┌──────────┐
                   │ EXPIRED  │
                   └──────────┘
```

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| PENDING | 等待执行 | 任务创建 |
| EXECUTING | 正在执行 | Scheduler 取出任务 |
| COMPLETED | 执行完成 | Worker 成功返回 |
| FAILED | 执行失败 | Worker 抛异常 |
| CANCELLED | 被取消 | 会话结束 / 手动取消 / 预算回收 |
| EXPIRED | 过期失效 | 超过预测窗口未命中 |

### 10.2 状态转换代码

```java
public class PrefetchTaskStateMachine {
    
    private static final Map<String, Set<String>> TRANSITIONS = Map.of(
        "PENDING",    Set.of("EXECUTING", "CANCELLED", "EXPIRED"),
        "EXECUTING",  Set.of("COMPLETED", "FAILED", "CANCELLED"),
        "COMPLETED",  Set.of("EXPIRED"),
        "FAILED",     Set.of()  // 终态
        "CANCELLED",  Set.of(),  // 终态
        "EXPIRED",    Set.of()   // 终态
    );
    
    public static boolean canTransition(String from, String to) {
        Set<String> allowed = TRANSITIONS.get(from);
        return allowed != null && allowed.contains(to);
    }
    
    public static void transition(PrefetchTask task, String newStatus) {
        String oldStatus = task.getStatus();
        if (!canTransition(oldStatus, newStatus)) {
            throw new IllegalStateException(
                String.format("Cannot transition from %s to %s", oldStatus, newStatus));
        }
        task.setStatus(newStatus);
    }
}
```

```java
     * 计算成本效益比
     * = 节省的用户等待时间 / 预加载消耗的服务器资源
     */

        int tokensUsed = sumTokensUsed(date);
        double computeHours = calculateComputeHours(date);
        
        // 效益: 每万Token节省的用户等待秒数
        double savedPerTokenUnit = totalSavedMs / 1000.0 / (tokensUsed / 10000.0 + 1);
        
        return CostEfficiency.builder()
            .totalTimeSavedSeconds(totalSavedMs / 1000.0)
            .tokensConsumed(tokensUsed)
            .computeHoursUsed(computeHours)
            .savedSecondsPer10kTokens(savedPerTokenUnit)
            .build();
    }
    
    /**
     * 按场景分析命中率, 找出低效场景

    private Map<String, ScenarioStats> analyzeByScenario(LocalDate date) {
        return hitLogRepo.analyzeByScenario(date).stream()
            .collect(Collectors.toMap(
                ScenarioStats::getScenario,
                Function.identity()
            ));
    }
```

```java
/**
 * 预加载降级控制器
 */
@Component
public class PrefetchDegradationManager {
    
    private volatile boolean prefetchEnabled = true;
    private volatile int globalConcurrencyLimit = 50;
    
    /**
     * 根据系统负载动态调整预加载级别
     */
    @Scheduled(fixedRate = 30000)  // 每30秒检查
    public void adjustLevel() {
        SystemLoad load = systemMonitor.getCurrentLoad();
        
        if (load.getCpuUsage() > 0.85 || load.getMemoryUsage() > 0.90) {
            // 高负载: 完全禁用预加载
            prefetchEnabled = false;
            log.warn("System overloaded, prefetch disabled");
            
        } else if (load.getCpuUsage() > 0.70) {
            // 中负载: 减少并发, 只保留高优先级
            prefetchEnabled = true;
            globalConcurrencyLimit = 10;
            log.info("System under medium load, prefetch throttled");
            
        } else {
            // 正常负载: 完全开启
            prefetchEnabled = true;
            globalConcurrencyLimit = 50;
        }
    }
    
    public boolean isEnabled() {
        return prefetchEnabled;
    }
    
    public int getConcurrencyLimit() {
        return globalConcurrencyLimit;
    }
}
```

### 12.3 兜底处理

```java
/**
 * 兜底: 如果预加载全部失败, 用户请求正常实时处理
 * 预加载是"锦上添花", 永远不能阻塞正常请求
 */
@Aspect
@Component
public class PrefetchFallbackAspect {
    
    @Around("@annotation(Prefetchable)")
    public Object handlePrefetchable(ProceedingJoinPoint pjp) throws Throwable {
        // 1. 先查预加载缓存
        PrefetchResult cached = prefetchCache.get(buildKey(pjp));
        if (cached != null) {
            metrics.recordHit();
            return cached.getContent();
        }
        
        // 2. 未命中, 正常执行 (不受预加载状态影响)
        Object result = pjp.proceed();
        return result;
    }
}
```

### 13.1 数据隔离

- 预加载缓存严格按 `userId` 隔离, 绝不跨用户共享
- AI 预计算结果仅缓存个人上下文相关内容, 不包含其他学生数据

- 单用户每日 Token 消耗有硬上限, 防止恶意触发大量 AI 预计算
- 预加载接口需验证用户身份和会话有效性
- 预算配置可通过管理后台动态调整, 紧急情况下可一键禁用

### 13.3 内容安全

- AI 预计算结果需经过与实时请求相同的安全过滤管线
- 预加载的内容需验证学生是否有权限访问 (会员等级检查)

## 15. 性能优化

### 15.1 批量预加载

当检测到学生进入新的学习场景时，一次性批量提交多个预加载任务，减少多次请求的延迟：

```java
/**
 * 批量预加载入口
 */
public void batchPrefetchOnSceneEnter(Long userId, String sessionId, String sceneType) {
    PredictionRequest request = buildRequestFromContext(userId, sessionId, sceneType);
    
    // 一次性获取所有策略的预测结果
    List<PredictionResult.PredictedTarget> allTargets = new ArrayList<>();
    for (Predictor predictor : predictors) {
        List<PredictionResult.PredictedTarget> targets = predictor.predict(request);
        allTargets.addAll(targets);
    }
    
    // 合并去重, 按概率排序, 截断
    List<PredictionResult.PredictedTarget> merged = mergeAndRank(allTargets);
    
    // 批量提交
    scheduler.submitTasks(userId, sessionId, merged, request.getBudget());
}
```
