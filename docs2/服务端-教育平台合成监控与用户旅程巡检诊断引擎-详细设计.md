# 教育平台合成监控与用户旅程巡检诊断引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

合成监控与用户旅程巡检诊断引擎（Synthetic Monitor & User Journey Patrol Engine，简称 **SMUJP**）是 PrimeTop 教育平台的主动式可用性保障系统。它通过模拟真实用户的学习操作路径（如"学生登录→浏览首页→发起AI问答→完成一道练习题→查看错题本→查看学情报告"），在真实用户受到影响之前发现服务异常、性能退化和功能不可用问题。

### 1.2 与现有系统的区别

| 现有系统 | 关注点 | 局限性 |
|---------|--------|--------|
| 健康检查与服务就绪探针 | 单服务存活/就绪判定 | 仅检测服务是否启动，不验证业务流程是否真正可用 |
| 智能故障检测与自动恢复自愈引擎 | 基于指标/日志的被动异常检测 | 依赖用户真实流量触发，无法覆盖低频但关键的学习路径 |
| 日志与监控告警体系 | 指标采集、阈值告警 | 只能看到"已发生"的问题，无法主动发现"即将失败"的隐患 |
| 全链路压测方案 | 峰值容量验证 | 非常态化运行，无法持续保障日常可用性 |

**SMUJP 填补的空白：** 以真实用户视角，7×24 小时持续模拟端到端学习行为，覆盖从 UI 渲染到数据库写入的完整链路，在用户感知到问题之前发出预警。

### 1.3 设计目标

1. **提前发现**：在真实用户报告之前，自动检测到学习流程中的异常环节
2. **精准定位**：当某个用户旅程失败时，精确定位到具体服务、接口或依赖组件
3. **多角色覆盖**：支持学生（不同学段）、家长、教师三类角色的用户旅程模拟
4. **多区域探测**：支持从不同地理区域（华南、华东、华北）发起探测，监控区域可用性
5. **低干扰**：合成流量对生产环境影响最小化，避免干扰真实业务数据和监控指标
6. **快速告警**：从探测执行到告警发出，延迟不超过 60 秒

### 1.4 适用范围

- **生产环境**：常态化 7×24 小时巡检
- **预发布环境**：每次发布后自动执行回归巡检
- **灾备环境**：定期验证灾备链路可用性

## 2. 核心概念与领域模型

### 2.1 关键概念

| 概念 | 定义 |
|------|------|
| **用户旅程（Journey）** | 一组有序的操作步骤，模拟真实用户完成某个学习目标的完整过程 |
| **巡检探针（Probe）** | 执行用户旅程的独立运行单元，每个探针模拟一个虚拟用户 |
| **检查点（Checkpoint）** | 旅程中的关键验证节点，包含断言条件（如响应码、响应时间、业务字段值） |
| **巡检任务（Patrol Task）** | 调度配置，定义某个旅程在什么时间、以什么频率、从哪个区域执行 |
| **巡检快照（Patrol Snapshot）** | 单次巡检执行的完整记录，包含每步操作、响应、耗时、截图 |
| **健康度评分（Health Score）** | 基于多次巡检结果计算的综合健康指标，0-100 分 |
| **虚拟身份（Synthetic Identity）** | 专门用于合成监控的测试账号，与真实用户数据隔离 |

### 2.2 用户旅程分类

```
用户旅程
├── 核心学习路径 (P0 - 每5分钟巡检)
│   ├── 学生-首页加载与工作台渲染
│   ├── 学生-AI智能辅导对话完整流程
│   ├── 学生-拍照搜题完整流程
│   ├── 学生-同步课堂章节学习
│   ├── 学生-错题本查看与复习
│   ├── 学生-练习答题与提交
│   └── 学生-学情报告查看
├── 辅助学习路径 (P1 - 每15分钟巡检)
│   ├── 学生-学习计划生成与查看
│   ├── 学生-作文辅导提交与批改
│   ├── 学生-文科背诵检测
│   ├── 学生-考点梳理浏览
│   ├── 家长-学情报告查看
│   └── 教师-班级管理数据查看
├── 商业化路径 (P2 - 每30分钟巡检)
│   ├── 会员订阅页面加载与权益展示
│   ├── 商品购买流程
│   └── 优惠券领取与使用
└── 基础设施路径 (P0 - 每5分钟巡检)
    ├── 用户注册登录
    ├── APP启动配置拉取
    ├── 全局搜索
    └── 消息推送投递
```

## 3. 数据结构定义

### 3.1 用户旅程定义（Journey Definition）

```sql
CREATE TABLE `patrol_journey` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `journey_code` VARCHAR(64) NOT NULL UNIQUE COMMENT '旅程编码，如 STUDENT_AI_TUTOR',
    `journey_name` VARCHAR(128) NOT NULL COMMENT '旅程名称',
    `role_type` VARCHAR(32) NOT NULL COMMENT '角色类型: STUDENT/PARENT/TEACHER',
    `grade_stage` VARCHAR(32) COMMENT '学段: PRESCHOOL/PRIMARY/JUNIOR/SENIOR',
    `priority` VARCHAR(8) NOT NULL DEFAULT 'P1' COMMENT '优先级: P0/P1/P2',
    `description` TEXT COMMENT '旅程描述',
    `enabled` TINYINT NOT NULL DEFAULT 1 COMMENT '是否启用',
    `synthetic_user_id` BIGINT COMMENT '绑定的虚拟测试用户ID',
    `estimated_duration_ms` INT COMMENT '预估执行时长(毫秒)',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX `idx_priority_enabled` (`priority`, `enabled`),
    INDEX `idx_role_stage` (`role_type`, `grade_stage`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='巡检用户旅程定义';
```



### 4.2 探针执行架构

每个区域探针是一个独立的轻量级服务实例，负责执行旅程步骤：

```java
/**
 * 巡检探针执行器
 */
public class PatrolProbeExecutor {
    
    private final HttpClient httpClient;
    private final WebSocketClient wsClient;
    private final VariableContext variableContext;  // 步骤间变量传递
    private final TraceContext traceContext;         // 全链路追踪上下文
    
    /**
     * 执行单个用户旅程
     */
    public PatrolSnapshot execute(PatrolJourney journey, PatrolSchedule schedule) {
        String snapshotId = generateSnapshotId();
        PatrolSnapshot snapshot = PatrolSnapshot.start(snapshotId, journey, schedule);
        
        try {
            // 注入全链路追踪标记，标记为合成流量
            traceContext.setTag("synthetic", "true");
            traceContext.setTag("patrol.snapshot_id", snapshotId);
            traceContext.setTag("patrol.journey", journey.getJourneyCode());
            
            // 获取或刷新虚拟用户认证令牌
            String authToken = ensureAuthToken(journey.getSyntheticUserId());
            variableContext.set("auth_token", authToken);
            
            // 按序执行步骤
            List<PatrolJourneyStep> steps = journey.getSortedSteps();
            for (int i = 0; i < steps.size(); i++) {
                PatrolJourneyStep step = steps.get(i);
                
                // 检查前置步骤是否成功，未成功则跳过后续步骤
                if (snapshot.hasFailedStep() && step.getDependsOnStep() != null) {
                    recordSkippedStep(snapshot, step, i);
                    continue;
                }
                
                // 执行步骤（含重试）
                PatrolStepRecord record = executeStepWithRetry(step, snapshotId);
                snapshot.addStepRecord(record);
                
                if (record.isSuccess()) {
                    // 提取变量供后续步骤使用
                    extractVariables(record, step, variableContext);
                } else {
                    snapshot.markFailed(i, step, record);
                    break;  // 首个失败步骤后停止（除非配置了继续执行）
                }
            }
            
            snapshot.complete();
            
        } catch (Exception e) {
            snapshot.failWithError("UNEXPECTED", e.getMessage());
        }
        
        // 异步上报结果
        resultReporter.reportAsync(snapshot);
        
        return snapshot;
    }
    
    /**
     * 执行单个步骤（含重试逻辑）
     */
    private PatrolStepRecord executeStepWithRetry(PatrolJourneyStep step, String snapshotId) {
        int maxAttempts = step.getRetryCount() + 1;
        
        for (int attempt = 0; attempt < maxAttempts; attempt++) {
            try {
                Thread.sleep(attempt == 0 ? 0 : step.getRetryIntervalMs());
                
                PatrolStepRecord record = executeStep(step, snapshotId, attempt);
                if (record.isSuccess()) {
                    return record;
                }
                
                // 最后一次尝试仍然失败
                if (attempt == maxAttempts - 1) {
                    return record;
                }
                
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return PatrolStepRecord.timeout(step, snapshotId);
            }
        }
        
        return PatrolStepRecord.failed(step, snapshotId, "MAX_RETRY_EXCEEDED", 
            "Exceeded max retry count: " + maxAttempts);
    }
    
    /**
     * 执行单个步骤（单次尝试）
     */
    private PatrolStepRecord executeStep(PatrolJourneyStep step, String snapshotId, int attempt) {
        long startTime = System.currentTimeMillis();
        
        // 参数化模板替换
        String url = renderTemplate(step.getTargetUrl(), variableContext);
        String body = renderTemplate(step.getRequestBodyTemplate(), variableContext);
        
        // 构建请求，注入合成流量标记头
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(url))
            .header("Authorization", "Bearer " + variableContext.get("auth_token"))
            .header("X-Synthetic-Monitor", "true")
            .header("X-Patrol-Snapshot-Id", snapshotId)
            .header("X-Patrol-Attempt", String.valueOf(attempt))
            .header("X-Trace-Id", traceContext.getTraceId())
            .timeout(Duration.ofMillis(step.getMaxLatencyMs()))
            .build();
        
        try {
            // 执行请求
            HttpResponse<String> response = httpClient.send(request, 
                HttpResponse.BodyHandlers.ofString());
            
            long latency = System.currentTimeMillis() - startTime;
            
            // 评估断言
            List<AssertionResult> assertions = evaluateAssertions(
                response, step.getExpectedResponse());
            
            boolean success = response.statusCode() == step.getExpectedStatus()
                && assertions.stream().allMatch(AssertionResult::isPassed);
            
            return PatrolStepRecord.builder()
                .snapshotId(snapshotId)
                .stepIndex(step.getStepIndex())
                .stepName(step.getStepName())
                .requestUrl(url)
                .httpMethod(step.getHttpMethod())
                .responseStatus(response.statusCode())
                .responseBodySummary(truncate(response.body(), 1000))
                .latencyMs((int) latency)
                .status(success ? "SUCCESS" : "FAILED")
                .assertionResults(assertions)
                .attemptNumber(attempt)
                .spanId(traceContext.getCurrentSpanId())
                .build();
                
        } catch (HttpTimeoutException e) {
            return PatrolStepRecord.timeout(step, snapshotId, attempt);
        } catch (ConnectException e) {
            return PatrolStepRecord.connectionError(step, snapshotId, attempt, e.getMessage());
        } catch (Exception e) {
            return PatrolStepRecord.error(step, snapshotId, attempt, 
                "UNEXPECTED", e.getMessage());
        }
    }
}
```

## 7. 断言引擎设计

### 7.1 断言表达式语法

断言引擎支持 JSONPath + 操作符的断言表达式，格式为 `JSONPath:operator:value`：

| 操作符 | 说明 | 示例 |
|--------|------|------|
| `eq` | 等于 | `$.code:eq:0` |
| `ne` | 不等于 | `$.status:ne:ERROR` |
| `gt` | 大于 | `$.count:gt:0` |
| `gte` | 大于等于 | `$.total:gte:10` |
| `lt` | 小于 | `$.latency:lt:5000` |
| `lte` | 小于等于 | - |
| `contains` | 包含字符串 | `$.message:contains:成功` |
| `contains_any` | 包含任一（逗号分隔） | `$.content:contains_any:顶点,公式,坐标` |
| `not_contains` | 不包含 | - |
| `not_null` | 非空 | `$.data.token:not_null` |
| `not_empty` | 非空集合 | `$.data.tasks:not_empty` |
| `is_null` | 为空 | - |
| `matches` | 正则匹配 | `$.phone:matches:^1[3-9]\d{9}$` |
| `size_eq` | 集合大小等于 | `$.items:size_eq:10` |
| `size_gt` | 集合大小大于 | `$.items:size_gt:0` |
| `size_gte` | 集合大小大于等于 | `$.messages:size_gte:2` |

### 7.2 断言引擎实现

```java
/**
 * 断言引擎 - 评估响应是否符合预期
 */
public class AssertionEngine {
    
    private static final Pattern ASSERTION_PATTERN = 
        Pattern.compile("^(.+?):(eq|ne|gt|gte|lt|lte|contains|contains_any|" +
            "not_contains|not_null|not_empty|is_null|matches|size_eq|size_gt|size_gte):(.*)$");
    
    private final JsonPathEvaluator jsonPathEvaluator;
    
    /**
     * 评估所有断言
     */
    public List<AssertionResult> evaluate(HttpResponse<String> response, 
            Map<String, String> expectedAssertions) {
        
        List<AssertionResult> results = new ArrayList<>();
        String responseBody = response.body();
        
        for (Map.Entry<String, String> entry : expectedAssertions.entrySet()) {
            String expression = entry.getKey() + ":" + entry.getValue();
            AssertionResult result = evaluateSingle(expression, responseBody, response.statusCode());
            results.add(result);
        }
        
        return results;
    }
    
    /**
     * 评估单个断言表达式
     */
    private AssertionResult evaluateSingle(String expression, String jsonBody, int statusCode) {
        Matcher matcher = ASSERTION_PATTERN.matcher(expression);
        if (!matcher.matches()) {
            return AssertionResult.fail(expression, "INVALID_EXPRESSION", 
                "Expression does not match expected pattern");
        }
        
        String jsonPath = matcher.group(1);
        String operator = matcher.group(2);
        String expectedValue = matcher.group(3);
        
        // 提取实际值
        Object actualValue;
        try {
            actualValue = jsonPathEvaluator.evaluate(jsonBody, jsonPath);
        } catch (Exception e) {
            return AssertionResult.fail(expression, "JSONPATH_ERROR", 
                "Failed to evaluate JSONPath '" + jsonPath + "': " + e.getMessage());
        }
        
        // 执行比较
        return compare(actualValue, operator, expectedValue, jsonPath);
    }
    
    private AssertionResult compare(Object actual, String operator, 
            String expected, String jsonPath) {
        
        return switch (operator) {
            case "eq" -> compareEqual(actual, expected, jsonPath);
            case "ne" -> compareNotEqual(actual, expected, jsonPath);
            case "gt" -> compareNumeric(actual, expected, ">", jsonPath);
            case "gte" -> compareNumeric(actual, expected, ">=", jsonPath);
            case "lt" -> compareNumeric(actual, expected, "<", jsonPath);
            case "lte" -> compareNumeric(actual, expected, "<=", jsonPath);
            case "contains" -> compareContains(actual, expected, jsonPath, false);
            case "contains_any" -> compareContainsAny(actual, expected, jsonPath);
            case "not_contains" -> compareContains(actual, expected, jsonPath, true);
            case "not_null" -> checkNotNull(actual, jsonPath);
            case "not_empty" -> checkNotEmpty(actual, jsonPath);
            case "is_null" -> checkIsNull(actual, jsonPath);
            case "matches" -> compareRegex(actual, expected, jsonPath);
            case "size_eq" -> compareSize(actual, expected, "==", jsonPath);
            case "size_gt" -> compareSize(actual, expected, ">", jsonPath);
            case "size_gte" -> compareSize(actual, expected, ">=", jsonPath);
            default -> AssertionResult.fail(jsonPath + ":" + operator + ":" + expected,
                "UNSUPPORTED_OPERATOR", "Unknown operator: " + operator);
        };
    }
    
    private AssertionResult compareContainsAny(Object actual, String expected, String jsonPath) {
        if (actual == null) {
            return AssertionResult.fail(jsonPath, "ACTUAL_NULL", "Actual value is null");
        }
        String[] options = expected.split(",");
        String actualStr = actual.toString();
        for (String option : options) {
            if (actualStr.contains(option.trim())) {
                return AssertionResult.pass(jsonPath + ":contains_any:" + expected,
                    actualStr, "Matched option: " + option.trim());
            }
        }
        return AssertionResult.fail(jsonPath + ":contains_any:" + expected,
            "NO_MATCH", "None of the options found. Actual: " + truncate(actualStr, 200));
    }
}
```

## 8. 健康度评分算法

### 8.1 单旅程健康度计算

```java
/**
 * 健康度评分计算器
 * 综合成功率 + 延迟表现 + 连续失败惩罚
 */
public class HealthScoreCalculator {
    
    // 权重配置
    private static final double WEIGHT_SUCCESS_RATE = 0.6;
    private static final double WEIGHT_LATENCY = 0.3;
    private static final double WEIGHT_CONSECUTIVE_FAIL_PENALTY = 0.1;
    
    // 延迟基准线（每个旅程的基础期望延迟）
    private static final Map<String, Integer> LATENCY_BASELINE = Map.of(
        "STUDENT_AI_TUTOR", 10000,
        "STUDENT_PHOTO_SEARCH", 15000,
        "STUDENT_SYNC_CLASSROOM", 5000,
        "INFRA_AUTH_LOGIN", 2000
    );
    
    /**
     * 计算指定时间窗口内的健康度评分
     */
    public double calculate(String journeyCode, List<PatrolSnapshot> snapshots, 
            int consecutiveFailures) {
        
        if (snapshots.isEmpty()) {
            return 0.0;  // 无数据视为不健康
        }
        
        // 1. 成功率得分（0-100）
        long successCount = snapshots.stream()
            .filter(s -> s.getStatus() == PatrolStatus.SUCCESS)
            .count();
        double successRate = (double) successCount / snapshots.size();
        double successScore = successRate * 100;
        
        // 2. 延迟得分（0-100）
        double latencyScore = calculateLatencyScore(journeyCode, snapshots);
        
        // 3. 连续失败惩罚
        double consecutivePenalty = Math.min(consecutiveFailures * 10, 100);
        
        // 加权综合
        double score = (successScore * WEIGHT_SUCCESS_RATE)
            + (latencyScore * WEIGHT_LATENCY)
            - (consecutivePenalty * WEIGHT_CONSECUTIVE_FAIL_PENALTY);
        
        return Math.max(0, Math.min(100, Math.round(score * 100.0) / 100.0));
    }
    
    /**
     * 延迟评分计算
     * 基于P95延迟与基准线的比较
     */
    private double calculateLatencyScore(String journeyCode, List<PatrolSnapshot> snapshots) {
        int baseline = LATENCY_BASELINE.getOrDefault(journeyCode, 10000);
        
        List<Integer> latencies = snapshots.stream()
            .filter(s -> s.getOverallLatencyMs() != null)
            .map(PatrolSnapshot::getOverallLatencyMs)
            .sorted()
            .collect(Collectors.toList());
        
        if (latencies.isEmpty()) {
            return 50.0;  // 无延迟数据给中等分
        }
        
        // 计算P95
        int p95Index = (int) Math.ceil(latencies.size() * 0.95) - 1;
        int p95Latency = latencies.get(Math.max(0, p95Index));
        
        // 评分逻辑：
        // P95 <= 基准线 × 0.8 → 100分
        // P95 <= 基准线       → 90分
        // P95 <= 基准线 × 1.5 → 70分
        // P95 <= 基准线 × 2.0 → 50分
        // P95 <= 基准线 × 3.0 → 30分
        // P95 >  基准线 × 3.0 → 10分
        
        double ratio = (double) p95Latency / baseline;
        
        if (ratio <= 0.8) return 100.0;
        if (ratio <= 1.0) return 90.0 + (1.0 - ratio) * 50;  // 90-100
        if (ratio <= 1.5) return 70.0 + (1.5 - ratio) * 40;   // 70-90
        if (ratio <= 2.0) return 50.0 + (2.0 - ratio) * 40;   // 50-70
        if (ratio <= 3.0) return 30.0 + (3.0 - ratio) * 20;   // 30-50
        return Math.max(0, 30.0 - (ratio - 3.0) * 10);         // 0-30
    }
}
```

```java
/**
 * 平台全局健康度 = Σ(旅程健康度 × 旅程权重) / Σ(旅程权重)
 * 权重由优先级决定：P0=3, P1=2, P2=1
 */
public double calculatePlatformHealth(Map<String, Double> journeyScores, 
        Map<String, String> journeyPriorities) {
    
    double weightedSum = 0;
    double totalWeight = 0;
    
    for (Map.Entry<String, Double> entry : journeyScores.entrySet()) {
        String journeyCode = entry.getKey();
        double score = entry.getValue();
        String priority = journeyPriorities.getOrDefault(journeyCode, "P2");
        
        int weight = switch (priority) {
            case "P0" -> 3;
            case "P1" -> 2;
            default -> 1;
        };
        
        weightedSum += score * weight;
        totalWeight += weight;
    }
    
    return totalWeight > 0 ? weightedSum / totalWeight : 0;
}
```

### 9.2 告警引擎核心逻辑

```java
/**
 * 告警评估引擎
 * 每次巡检结果上报后触发评估
 */
public class AlertEvaluationEngine {
    
    private final PatrolAlertRuleRepository ruleRepository;
    private final PatrolAlertEventRepository alertEventRepository;
    private final NotificationService notificationService;
    private final HealthScoreRepository healthScoreRepository;
    
    /**
     * 评估巡检结果是否触发告警
     */
    @EventListener
    public void onPatrolSnapshotCompleted(PatrolSnapshotCompletedEvent event) {
        PatrolSnapshot snapshot = event.getSnapshot();
        String journeyCode = snapshot.getJourneyCode();
        String region = snapshot.getProbeRegion();
        
        // 获取该旅程关联的所有告警规则
        List<PatrolAlertRule> rules = ruleRepository.findActiveRules(journeyCode);
        
        for (PatrolAlertRule rule : rules) {
            boolean shouldFire = evaluateRule(rule, journeyCode, region, snapshot);
            
            if (shouldFire) {
                fireAlert(rule, snapshot);
            } else {
                // 检查是否需要自动恢复已有告警
                resolveAlertIfNeeded(rule, journeyCode, region);
            }
        }
    }
    
    /**
     * 评估单条告警规则
     */
    private boolean evaluateRule(PatrolAlertRule rule, String journeyCode, 
            String region, PatrolSnapshot currentSnapshot) {
        
        return switch (rule.getConditionType()) {
            case CONSECUTIVE_FAIL -> {
                int consecutiveFailures = healthScoreRepository
                    .getConsecutiveFailures(journeyCode, region);
                yield consecutiveFailures >= rule.getConditionValue().intValue();
            }
            
            case SUCCESS_RATE -> {
                int windowMin = rule.getTimeWindowMinutes();
                double successRate = healthScoreRepository
                    .calculateSuccessRate(journeyCode, region, windowMin);
                yield successRate < rule.getConditionValue().doubleValue();
            }
            
            case LATENCY_P95 -> {
                int windowMin = rule.getTimeWindowMinutes();
                int p95Latency = healthScoreRepository
                    .calculateP95Latency(journeyCode, region, windowMin);
                yield p95Latency > rule.getConditionValue().intValue();
            }
            
            case HEALTH_SCORE -> {
                double currentScore = healthScoreRepository
                    .getLatestHealthScore(journeyCode, region);
                yield currentScore < rule.getConditionValue().doubleValue();
            }
        };
    }
    
    /**
     * 触发告警
     */
    private void fireAlert(PatrolAlertRule rule, PatrolSnapshot snapshot) {
        // 检查是否已有FIRING状态的告警（在静默期内）
        Optional<PatrolAlertEvent> existingAlert = alertEventRepository
            .findFiringAlert(rule.getRuleCode(), snapshot.getJourneyCode(), 
                snapshot.getProbeRegion());
        
        if (existingAlert.isPresent()) {
            // 已在告警状态，不重复触发
            return;
        }
        
        // 检查静默期
        Optional<PatrolAlertEvent> recentResolved = alertEventRepository
            .findRecentlyResolvedAlert(rule.getRuleCode(), 
                snapshot.getJourneyCode(), 
                snapshot.getProbeRegion(),
                rule.getSilenceMinutes());
        
        if (recentResolved.isPresent()) {
            return;  // 在静默期内
        }
        
        // 创建告警事件
        PatrolAlertEvent alert = PatrolAlertEvent.builder()
            .alertId("alert-" + UUID.randomUUID().toString().substring(0, 8))
            .ruleId(rule.getId())
            .ruleCode(rule.getRuleCode())
            .journeyCode(snapshot.getJourneyCode())
            .probeRegion(snapshot.getProbeRegion())
            .severity(rule.getSeverity())
            .title(buildAlertTitle(rule, snapshot))
            .description(buildAlertDescription(rule, snapshot))
            .triggerValue(buildTriggerValue(snapshot))
            .thresholdValue(rule.getConditionValue().toString())
            .relatedSnapshotIds(Collections.singletonList(snapshot.getSnapshotId()))
            .status("FIRING")
            .firedAt(LocalDateTime.now())
            .build();
        
        alertEventRepository.save(alert);
        
        // 发送通知
        sendNotification(alert, rule);
        
        // 自动创建事件工单（如配置）
        if (rule.getAutoCreateIncident()) {
            incidentService.createIncident(alert);
        }
    }
    
    /**
     * 发送告警通知
     */
    private void sendNotification(PatrolAlertEvent alert, PatrolAlertRule rule) {
        Map<String, Object> templateVars = Map.of(
            "alert_id", alert.getAlertId(),
            "title", alert.getTitle(),
            "journey", alert.getJourneyCode(),
            "region", alert.getProbeRegion(),
            "severity", alert.getSeverity(),
            "description", alert.getDescription(),
            "fired_at", alert.getFiredAt().toString(),
            "snapshot_url", buildSnapshotUrl(alert.getRelatedSnapshotIds())
        );
        
        for (String channel : rule.getNotificationChannels()) {
            try {
                notificationService.send(channel, rule.getNotificationTargets(), 
                    "PATROL_ALERT", templateVars);
            } catch (Exception e) {
                log.error("Failed to send alert notification via {}: {}", channel, e.getMessage());
            }
        }
    }
    
    /**
     * 自动恢复告警（当旅程恢复正常时）
     */
    private void resolveAlertIfNeeded(PatrolAlertRule rule, 
            String journeyCode, String region) {
        
        List<PatrolAlertEvent> firingAlerts = alertEventRepository
            .findFiringAlerts(rule.getRuleCode(), journeyCode, region);
        
        for (PatrolAlertEvent alert : firingAlerts) {
            alert.resolve();
            alertEventRepository.save(alert);
            
            // 发送恢复通知
            sendRecoveryNotification(alert, rule);
        }
    }
}
```

### 13.2 步骤级重试与超时

```java
/**
 * 步骤执行重试策略
 */
public class StepRetryPolicy {
    
    /**
     * 计算重试延迟（指数退避 + 随机抖动）
     */
    public long calculateRetryDelay(int attempt, int baseDelayMs) {
        // 指数退避: base * 2^attempt
        long exponentialDelay = (long) (baseDelayMs * Math.pow(2, attempt));
        
        // 最大延迟限制: 10秒
        long cappedDelay = Math.min(exponentialDelay, 10_000);
        
        // 添加 ±20% 随机抖动，避免重试风暴
        double jitter = 0.8 + Math.random() * 0.4;  // 0.8 ~ 1.2
        return (long) (cappedDelay * jitter);
    }
    
    /**
     * 判断步骤是否可重试
     */
    public boolean isRetryable(PatrolStepRecord record) {
        // 4xx 客户端错误（除429）不可重试
        if (record.getResponseStatus() != null 
                && record.getResponseStatus() >= 400 
                && record.getResponseStatus() < 500
                && record.getResponseStatus() != 429) {
            return false;
        }
        
        // 断言失败不可重试（除非配置了断言失败重试）
        if ("ASSERTION".equals(record.getErrorType())) {
            return false;
        }
        
        // 网络错误、超时、5xx、429 可重试
        return true;
    }
}
```

## 14. 性能优化

### 14.1 探针并发控制

```java
/**
 * 探针并发执行控制器
 * 单探针实例最多同时执行 N 个旅程
 */
public class ProbeConcurrencyManager {
    
    private final Semaphore concurrencyLimit;
    private final ExecutorService journeyExecutor;
    
    public ProbeConcurrencyManager(int maxConcurrent) {
        this.concurrencyLimit = new Semaphore(maxConcurrent);
        this.journeyExecutor = Executors.newThreadPoolExecutor(
            maxConcurrent, maxConcurrent,
            60L, TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(100),
            new ThreadFactoryBuilder()
                .setNameFormat("patrol-journey-%d")
                .setDaemon(true)
                .build(),
            new ThreadPoolExecutor.CallerRunsPolicy()
        );
    }
    
    public CompletableFuture<PatrolSnapshot> submit(PatrolJourney journey, 
            PatrolSchedule schedule) {
        return CompletableFuture.supplyAsync(() -> {
            try {
                concurrencyLimit.acquire();
                return probeExecutor.execute(journey, schedule);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return PatrolSnapshot.skipped(journey, "INTERRUPTED");
            } finally {
                concurrencyLimit.release();
            }
        }, journeyExecutor);
    }
}
```

### 14.2 结果上报批量优化

```java
/**
 * 快照结果批量上报器
 * 减少对控制中心的请求次数
 */
public class SnapshotBatchReporter {
    
    private final BlockingQueue<PatrolSnapshot> pendingQueue = 
        new LinkedBlockingQueue<>(1000);
    private final ScheduledExecutorService scheduler = 
        Executors.newSingleThreadScheduledExecutor();
    
    @PostConstruct
    public void init() {
        // 每10秒或积累50条时批量上报
        scheduler.scheduleAtFixedRate(this::flushBatch, 10, 10, TimeUnit.SECONDS);
    }
    
    public void reportAsync(PatrolSnapshot snapshot) {
        if (!pendingQueue.offer(snapshot)) {
            log.warn("Snapshot queue full, dropping snapshot: {}", snapshot.getSnapshotId());
            // 降级：直接HTTP上报
            directReport(snapshot);
        }
    }
    
    private void flushBatch() {
        List<PatrolSnapshot> batch = new ArrayList<>(50);
        pendingQueue.drainTo(batch, 50);
        
        if (batch.isEmpty()) return;
        
        try {
            controlCenterClient.batchUploadSnapshots(batch);
        } catch (Exception e) {
            log.error("Batch upload failed, attempting individual uploads", e);
            // 降级：逐条上报
            batch.forEach(this::directReport);
        }
    }
}
```

## 17. 安全考虑

1. **虚拟用户数据隔离**：所有合成监控账号注册时绑定 `data_isolation_tag=SYNTHETIC`，业务统计自动过滤
2. **测试数据不写入生产统计**：AI对话、答题记录等写入时标记 `is_synthetic=1`
3. **凭证轮换**：虚拟用户Token定期自动刷新，密码定期轮换
4. **网络隔离**：探针服务部署在独立命名空间，仅允许出站到目标服务和控制中心
5. **权限控制**：巡检管理API仅限运维团队和SRE角色访问
6. **快照数据脱敏**：快照中的请求/响应摘要自动脱敏（手机号、Token等）

```java
/**
 * 快照数据脱敏处理器
 */
public class SnapshotSanitizer {
    
    private static final List<Pattern> SENSITIVE_PATTERNS = List.of(
        Pattern.compile("(1[3-9]\\d{9})"),                    // 手机号
        Pattern.compile("(eyJ[A-Za-z0-9_-]+\\.\\.[A-Za-z0-9_-]+)"), // JWT Token
        Pattern.compile("([a-f0-9]{32,64})"),                  // MD5/SHA256
        Pattern.compile("(sk-[A-Za-z0-9]{20,})")              // API Key
    );
    
    public String sanitize(String input) {
        if (input == null) return null;
        String result = input;
        for (Pattern pattern : SENSITIVE_PATTERNS) {
            result = pattern.matcher(result).replaceAll("***REDACTED***");
        }
        return result;
    }
}
```
