# 服务端-学生学科学习兴趣衰减早期检测与兴趣重建内容策略智能推荐引擎

## 1. 概述

### 1.1 功能定位

本引擎负责**持续监测学生在各学科上的学习兴趣变化趋势**，在兴趣出现早期衰减信号时及时预警，并自动生成个性化的兴趣重建策略——包括内容形式调整、生活化场景注入、成就体验工程、社交学习引导等多维度干预方案，帮助学生在兴趣消退的初期重新建立学科学习动力。

### 1.2 与已有模块的边界

| 已有模块 | 关注点 | 本引擎差异 |
|---------|--------|-----------|
| 用户学习兴趣探索与学科偏好动态建模引擎 | 兴趣的**发现与建模**，构建偏好画像 | 本引擎关注兴趣的**衰减检测与重建**，是建模后的持续跟踪 |
| 学习动力量化与学习倦怠预警引擎 | 整体学习倦怠（跨学科）的**宏观预警** | 本引擎聚焦**单学科**兴趣生命周期，粒度更细 |
| 学生心理状态建模与学习动机激励策略引擎 | 心理状态与动机的**通用激励策略** | 本引擎针对兴趣衰减提供**内容策略层面**的具体推荐 |
| 学习内容疲劳度检测与学习形式多样性自动调度引擎 | 学习内容**形式单一**导致的疲劳 | 本引擎关注**学科兴趣本身**的衰减，不仅限于形式疲劳 |
| 学生偏科智能诊断与学科均衡发展干预推荐引擎 | 学科间**水平差异**与均衡发展 | 本引擎关注学生对某学科的**情感兴趣变化**，不限于成绩 |

### 1.3 适用范围

- **学段**：小学至高中全学段（幼儿阶段学习兴趣逻辑不同，暂不纳入）
- **触发方式**：每日批处理计算 + 实时事件流订阅
- **消费方**：推荐系统、通知服务、学习规划引擎、首页工作台编排

## 2. 核心概念定义

### 2.1 学科学习兴趣（Subject Learning Interest）

本引擎将"学科学习兴趣"定义为学生在特定学科上表现出的**主动参与意愿、持续投入倾向和情感正向反馈的综合度量**，区别于客观能力水平。

兴趣不等于成绩：一个学生数学成绩可能很好，但对数学的兴趣正在下降（刷题驱动但热情减退）。

### 2.2 兴趣衰减（Interest Decay）

兴趣衰减是指学生在某一学科上的主动参与指标出现**持续性的、非偶发的下降趋势**，具体表现为以下信号的综合：

| 信号维度 | 指标 | 衰减表现 |
|---------|------|---------|
| 主动学习频率 | 该学科周均主动发起学习次数 | 连续2周以上环比下降 |
| 学习时长占比 | 该学科学习时长 / 总学习时长 | 持续低于历史均值 |
| 学习会话深度 | 单次平均会话时长、内容浏览深度 | 变短、变浅 |
| 互动意愿 | AI对话中该学科问题占比、追问次数 | 减少或消失 |
| 完成率 | 该学科任务完成率 vs 其他学科 | 显著低于其他学科 |
| 内容选择 | 主动选择该学科内容的频率 | 下降 |
| 情感信号 | AI对话中该学科相关的情绪词分析 | 负面情绪词增多 |
| 回避行为 | 该学科任务跳过率、延迟率 | 上升 |

### 2.3 兴趣重建（Interest Reconstruction）

兴趣重建是指通过**有针对性的内容策略和体验设计**，在学生兴趣尚未完全消失时进行干预，帮助其重新建立对该学科的正面情感和主动参与意愿。

## 4. 兴趣得分计算模型

### 4.1 多维兴趣得分算法

兴趣得分采用加权多维模型，将原始信号归一化后加权合成。

```python
class InterestScoreCalculator:
    """学科兴趣得分计算器"""
    
    # 各维度权重（可根据学段动态调整）
    WEIGHTS = {
        "active_participation": 0.20,   # 主动参与度
        "time_investment":      0.15,   # 时间投入占比
        "session_depth":        0.15,   # 会话深度
        "interaction":          0.15,   # 互动意愿
        "task_completion":      0.10,   # 任务完成率
        "content_proactivity":  0.10,   # 内容主动选择
        "emotion":              0.10,   # 情感信号
        "avoidance_penalty":    0.05,   # 回避行为惩罚
    }
    
    def calculate_interest_score(self, snapshot: dict, baselines: dict) -> float:
        """
        计算兴趣综合得分 (0-100)
        
        Args:
            snapshot: 当周指标快照
            baselines: 学生该学科历史基线
        Returns:
            兴趣得分 0-100
        """
        scores = {}
        
        # 1. 主动参与度：主动学习次数 / 基线主动次数
        expected_active = max(baselines["baseline_active_count"], 3)
        actual_active = snapshot["active_learn_count"]
        scores["active_participation"] = self._normalize_ratio(
            actual_active, expected_active, max_val=expected_active * 2
        )
        
        # 2. 时间投入占比：该学科时长占比 vs 合理预期占比
        # 合理预期 = 均分占比 * 学科权重系数
        expected_ratio = self._get_expected_subject_ratio(snapshot["subject_code"])
        scores["time_investment"] = self._normalize_ratio(
            snapshot["learn_duration_ratio"], expected_ratio, max_val=expected_ratio * 2
        )
        
        # 3. 会话深度：平均会话深度直接映射
        scores["session_depth"] = self._clamp(snapshot["avg_session_depth"] / 100)
        
        # 4. 互动意愿：AI问题占比 + 追问次数综合
        ai_score = self._normalize_ratio(
            snapshot["ai_question_ratio"], expected_ratio, max_val=expected_ratio * 2
        )
        followup_score = self._clamp(snapshot["ai_followup_count"] / 10)
        scores["interaction"] = ai_score * 0.6 + followup_score * 0.4
        
        # 5. 任务完成率
        scores["task_completion"] = self._clamp(snapshot["task_completion_rate"])
        
        # 6. 内容主动选择
        expected_choice = max(baselines["baseline_active_count"] * 0.5, 2)
        scores["content_proactivity"] = self._normalize_ratio(
            snapshot["content_choice_count"], expected_choice, max_val=expected_choice * 3
        )
        
        # 7. 情感信号
        pos = snapshot["positive_emotion_score"]
        neg = snapshot["negative_emotion_score"]
        scores["emotion"] = self._clamp((pos - neg + 100) / 2)
        
        # 8. 回避行为惩罚（跳过率+延迟率）
        avoidance = (snapshot["skip_rate"] + snapshot["delay_rate"]) / 2
        scores["avoidance_penalty"] = 1.0 - self._clamp(avoidance)
        
        # 加权合成
        total = sum(scores[k] * self.WEIGHTS[k] for k in self.WEIGHTS)
        return round(total * 100, 2)
    
    @staticmethod
    def _normalize_ratio(actual: float, expected: float, max_val: float) -> float:
        """将实际值/期望值映射到0-1"""
        if expected <= 0:
            return 0.5
        ratio = actual / expected
        return max(0.0, min(1.0, ratio))
    
    @staticmethod
    def _clamp(v: float, lo: float = 0.0, hi: float = 1.0) -> float:
        return max(lo, min(hi, v))
    
    @staticmethod
    def _get_expected_subject_ratio(subject_code: str) -> float:
        """各学科合理时长占比预期"""
        ratios = {
            "math": 0.22, "chinese": 0.18, "english": 0.18,
            "physics": 0.12, "chemistry": 0.10, "biology": 0.08,
            "history": 0.08, "geography": 0.06, "politics": 0.06,
        }
        return ratios.get(subject_code, 0.10)
```

### 4.2 趋势判定算法

基于最近4周的兴趣得分序列判定趋势方向。

```python
class InterestTrendAnalyzer:
    """兴趣趋势分析器"""
    
    def analyze_trend(self, weekly_scores: list[float]) -> tuple[str, float]:
        """
        判定兴趣趋势
        
        Args:
            weekly_scores: 最近4-8周的兴趣得分序列（时间升序）
        Returns:
            (趋势类型, 变化速率)
            趋势: UP / STABLE / DOWN / CRASH
        """
        if len(weekly_scores) < 3:
            return ("STABLE", 0.0)
        
        # 使用线性回归斜率
        slope = self._linear_regression_slope(weekly_scores)
        
        # 使用最近2周vs前2周的均值对比
        recent_avg = sum(weekly_scores[-2:]) / 2
        earlier_avg = sum(weekly_scores[:-2]) / max(len(weekly_scores) - 2, 1)
        delta = recent_avg - earlier_avg
        
        # 综合判定
        if slope < -3.0 and delta < -10:
            return ("CRASH", abs(slope))
        elif slope < -1.0 or delta < -5:
            return ("DOWN", abs(slope))
        elif slope > 1.0 or delta > 5:
            return ("UP", slope)
        else:
            return ("STABLE", 0.0)
    
    @staticmethod
    def _linear_regression_slope(values: list[float]) -> float:
        """简单线性回归斜率"""
        n = len(values)
        if n < 2:
            return 0.0
        x_mean = (n - 1) / 2
        y_mean = sum(values) / n
        numerator = sum((i - x_mean) * (values[i] - y_mean) for i in range(n))
        denominator = sum((i - x_mean) ** 2 for i in range(n))
        return numerator / denominator if denominator != 0 else 0.0
```

### 5.2 数据采集聚合器

每周一凌晨执行，采集上一周各学科的学习行为数据。

```python
class InterestDataAggregator:
    """兴趣指标数据采集器"""
    
    async def aggregate_weekly_data(
        self, student_id: int, week_start: date
    ) -> list[dict]:
        """
        聚合学生指定周的各学科兴趣指标
        
        数据来源：
        - 学习会话服务 → 主动/被动学习次数、时长、深度
        - AI对话服务 → 提问次数、追问次数、情绪分析
        - 任务服务 → 任务完成率、跳过率、延迟率
        - 内容服务 → 主动选择内容次数
        """
        subjects = await self._get_student_subjects(student_id)
        snapshots = []
        
        for subject in subjects:
            # 并行查询各数据源
            session_data, ai_data, task_data, content_data = await asyncio.gather(
                self._query_session_metrics(student_id, subject, week_start),
                self._query_ai_metrics(student_id, subject, week_start),
                self._query_task_metrics(student_id, subject, week_start),
                self._query_content_metrics(student_id, subject, week_start),
            )
            
            snapshot = {
                "student_id": student_id,
                "subject_code": subject,
                "week_start_date": week_start,
                **session_data,
                **ai_data,
                **task_data,
                **content_data,
                "is_abnormal_week": self._check_abnormal_week(week_start),
            }
            snapshots.append(snapshot)
        
        return snapshots
    
    async def _query_session_metrics(
        self, student_id: int, subject: str, week_start: date
    ) -> dict:
        """从学习会话服务获取指标"""
        week_end = week_start + timedelta(days=6)
        # 查询 learning_session 表
        sessions = await self.session_repo.find_by_student_subject_range(
            student_id, subject, week_start, week_end
        )
        
        total_sessions = len(sessions)
        active_sessions = sum(1 for s in sessions if s.initiative == "STUDENT")
        total_duration = sum(s.duration for s in sessions)
        
        # 计算所有学科的总时长作为分母
        all_subject_duration = await self.session_repo.sum_duration_by_student_range(
            student_id, week_start, week_end
        )
        
        # 会话深度：基于浏览页面数、交互次数、完成状态等加权
        depths = [self._calc_session_depth(s) for s in sessions if s.subject == subject]
        avg_depth = sum(depths) / len(depths) if depths else 0
        
        return {
            "active_learn_count": active_sessions,
            "total_learn_count": total_sessions,
            "learn_duration_ratio": total_duration / max(all_subject_duration, 1),
            "avg_session_depth": round(avg_depth, 2),
            "avg_session_duration": total_duration // max(total_sessions, 1),
        }
```

```python
class InterestDecayDetector:
    """兴趣衰减检测器"""
    
    # 衰减等级阈值
    DECAY_THRESHOLDS = {
        "EARLY": {      # 早期衰减
            "score_drop": 10,      # 得分下降≥10
            "trend": "DOWN",
            "min_weeks": 2,        # 至少持续2周
        },
        "MODERATE": {   # 中度衰减
            "score_drop": 20,
            "trend": "DOWN",
            "min_weeks": 3,
        },
        "SEVERE": {     # 严重衰减
            "score_drop": 30,
            "trend": "CRASH",
            "min_weeks": 2,
        },
    }
    
    async def detect_decay(
        self, student_id: int, subject_code: str
    ) -> Optional[dict]:
        """
        检测学生在指定学科的兴趣衰减
        
        Returns:
            衰减检测结果或None
        """
        # 1. 获取最近8周快照
        snapshots = await self.snapshot_repo.find_recent(
            student_id, subject_code, weeks=8
        )
        if len(snapshots) < 4:
            return None  # 数据不足
        
        # 2. 获取或计算基线
        baseline = await self._get_or_calc_baseline(student_id, subject_code)
        
        # 3. 趋势分析
        scores = [s.interest_score for s in snapshots]
        trend, slope = InterestTrendAnalyzer().analyze_trend(scores)
        
        if trend not in ("DOWN", "CRASH"):
            return None
        
        # 4. 判定衰减等级
        current_score = scores[-1]
        score_drop = baseline["baseline_score"] - current_score
        decline_weeks = self._count_decline_weeks(scores)
        
        decay_level = self._classify_decay_level(
            score_drop, trend, decline_weeks
        )
        
        if decay_level is None:
            return None
        
        # 5. 排除异常周干扰
        recent = snapshots[-decline_weeks:]
        if all(s.is_abnormal_week for s in recent):
            return None  # 全在异常周，不判定
        
        # 6. 检查是否已有活跃衰减事件
        existing = await self.event_repo.find_active(
            student_id, subject_code
        )
        if existing and existing.decay_level == decay_level:
            # 更新已有事件
            return await self._update_existing_event(
                existing, current_score, scores, baseline
            )
        
        # 7. 根因分析
        cause_analysis = await self.root_cause_analyzer.analyze(
            student_id, subject_code, snapshots, baseline
        )
        
        # 8. 生成衰减事件
        event = {
            "event_id": generate_uuid(),
            "student_id": student_id,
            "subject_code": subject_code,
            "decay_level": decay_level,
            "previous_score": baseline["baseline_score"],
            "current_score": current_score,
            "decline_weeks": decline_weeks,
            "decline_rate": round(slope, 2),
            "primary_cause": cause_analysis["primary_cause"],
            "cause_confidence": cause_analysis["confidence"],
            "cause_detail": cause_analysis["detail"],
            "trigger_signals": cause_analysis["signals"],
        }
        
        return event
    
    def _classify_decay_level(
        self, score_drop: float, trend: str, decline_weeks: int
    ) -> Optional[str]:
        """判定衰减等级"""
        for level in ["SEVERE", "MODERATE", "EARLY"]:
            threshold = self.DECAY_THRESHOLDS[level]
            if (score_drop >= threshold["score_drop"]
                and trend in (threshold["trend"], "CRASH")
                and decline_weeks >= threshold["min_weeks"]):
                return level
        return None
```

```python
class InterestDecayRootCauseAnalyzer:
    """兴趣衰减根因分析器"""
    
    async def analyze(
        self,
        student_id: int,
        subject_code: str,
        snapshots: list,
        baseline: dict,
    ) -> dict:
        """
        分析兴趣衰减的潜在原因
        
        返回主因和置信度
        """
        causes = []
        recent = snapshots[-3:]  # 最近3周
        earlier = snapshots[:-3] if len(snapshots) > 3 else snapshots[:1]
        
        # ======== 原因1: 内容难度跳跃 ========
        difficulty_change = await self._analyze_difficulty_change(
            student_id, subject_code, recent, earlier
        )
        if difficulty_change["is_cause"]:
            causes.append({
                "cause": "CONTENT_DIFFICULTY",
                "confidence": difficulty_change["confidence"],
                "detail": difficulty_change["detail"],
            })
        
        # ======== 原因2: 学习形式单调 ========
        format_monotony = await self._analyze_format_monotony(
            student_id, subject_code, recent
        )
        if format_monotony["is_cause"]:
            causes.append({
                "cause": "FORMAT_MONOTONY",
                "confidence": format_monotony["confidence"],
                "detail": format_monotony["detail"],
            })
        
        # ======== 原因3: 负面反馈积累 ========
        negative_feedback = await self._analyze_negative_feedback(
            student_id, subject_code, recent
        )
        if negative_feedback["is_cause"]:
            causes.append({
                "cause": "NEGATIVE_FEEDBACK",
                "confidence": negative_feedback["confidence"],
                "detail": negative_feedback["detail"],
            })
        
        # ======== 原因4: 知识断层积累 ========
        knowledge_gap = await self._analyze_knowledge_gap(
            student_id, subject_code, recent
        )
        if knowledge_gap["is_cause"]:
            causes.append({
                "cause": "KNOWLEDGE_GAP",
                "confidence": knowledge_gap["confidence"],
                "detail": knowledge_gap["detail"],
            })
        
        # ======== 原因5: 外部因素（考试结束、季节性等）======
        external = self._analyze_external_factors(
            student_id, subject_code, recent
        )
        if external["is_cause"]:
            causes.append({
                "cause": "EXTERNAL_FACTOR",
                "confidence": external["confidence"],
                "detail": external["detail"],
            })
        
        # 选择置信度最高的主因
        if not causes:
            return {
                "primary_cause": "UNKNOWN",
                "confidence": 0.3,
                "detail": {"message": "未能确定明确原因"},
                "signals": self._extract_all_signals(recent, baseline),
            }
        
        causes.sort(key=lambda x: x["confidence"], reverse=True)
        primary = causes[0]
        
        return {
            "primary_cause": primary["cause"],
            "confidence": primary["confidence"],
            "detail": primary["detail"],
            "signals": self._extract_all_signals(recent, baseline),
            "secondary_causes": [c for c in causes[1:]],
        }
    
    async def _analyze_difficulty_change(
        self, student_id, subject_code, recent, earlier
    ) -> dict:
        """分析是否存在内容难度突然上升"""
        # 查询最近做题的正确率变化
        recent_accuracy = await self.practice_repo.get_accuracy(
            student_id, subject_code,
            start=recent[0].week_start_date,
            end=recent[-1].week_start_date + timedelta(days=6),
        )
        earlier_accuracy = await self.practice_repo.get_accuracy(
            student_id, subject_code,
            start=earlier[0].week_start_date,
            end=earlier[-1].week_start_date + timedelta(days=6),
        )
        
        accuracy_drop = earlier_accuracy - recent_accuracy
        
        # 正确率下降 >15% 且会话深度同时下降 → 可能是难度跳跃
        depth_drop = (
            sum(s.avg_session_depth for s in earlier) / len(earlier)
            - sum(s.avg_session_depth for s in recent) / len(recent)
        )
        
        is_cause = accuracy_drop > 0.15 and depth_drop > 10
        confidence = min(0.9, accuracy_drop / 0.3) if is_cause else 0.0
        
        return {
            "is_cause": is_cause,
            "confidence": round(confidence, 2),
            "detail": {
                "accuracy_before": round(earlier_accuracy, 3),
                "accuracy_after": round(recent_accuracy, 3),
                "accuracy_drop": round(accuracy_drop, 3),
                "depth_drop": round(depth_drop, 2),
                "interpretation": "内容难度可能突然增加，导致挫败感积累",
            },
        }
    
    async def _analyze_format_monotony(
        self, student_id, subject_code, recent
    ) -> dict:
        """分析是否存在学习形式过于单一"""
        content_types = await self.content_repo.get_content_type_distribution(
            student_id, subject_code,
            start=recent[0].week_start_date,
            end=recent[-1].week_start_date + timedelta(days=6),
        )
        
        # 计算内容类型分布的熵（越低越单调）
        total = sum(content_types.values())
        if total == 0:
            return {"is_cause": False, "confidence": 0, "detail": {}}
        
        probs = [v / total for v in content_types.values()]
        entropy = -sum(p * math.log2(p) for p in probs if p > 0)
        max_entropy = math.log2(len(content_types)) if len(content_types) > 1 else 1
        normalized_entropy = entropy / max_entropy if max_entropy > 0 else 0
        
        is_cause = normalized_entropy < 0.3  # 熵低于最大熵的30%
        confidence = (1 - normalized_entropy) * 0.7 if is_cause else 0.0
        
        return {
            "is_cause": is_cause,
            "confidence": round(confidence, 2),
            "detail": {
                "content_type_distribution": content_types,
                "entropy": round(entropy, 3),
                "normalized_entropy": round(normalized_entropy, 3),
                "interpretation": "学习内容形式过于单一，缺乏变化",
            },
        }
    
    async def _analyze_negative_feedback(
        self, student_id, subject_code, recent
    ) -> dict:
        """分析是否存在持续的负面反馈（低分、错误、批评）"""
        recent_error_rate = await self.practice_repo.get_error_rate(
            student_id, subject_code,
            start=recent[0].week_start_date,
            end=recent[-1].week_start_date + timedelta(days=6),
        )
        
        negative_emotion = sum(s.negative_emotion_score for s in recent) / len(recent)
        
        is_cause = recent_error_rate > 0.5 and negative_emotion > 40
        confidence = min(0.85, (recent_error_rate - 0.4) * 2) if is_cause else 0.0
        
        return {
            "is_cause": is_cause,
            "confidence": round(confidence, 2),
            "detail": {
                "error_rate": round(recent_error_rate, 3),
                "negative_emotion_score": round(negative_emotion, 2),
                "interpretation": "持续的高错误率和负面情绪积累导致兴趣下降",
            },
        }
    
    async def _analyze_knowledge_gap(
        self, student_id, subject_code, recent
    ) -> dict:
        """分析是否存在前置知识不牢固导致的连锁挫败"""
        # 查询知识追踪数据
        mastery = await self.knowledge_repo.get_subject_mastery_distribution(
            student_id, subject_code
        )
        
        # 前置知识点掌握度低于阈值的比例
        prerequisites = await self.knowledge_repo.get_prerequisite_nodes(
            student_id, subject_code
        )
        
        weak_prereqs = [
            kp for kp in prerequisites
            if kp.mastery_level < 0.5
        ]
        
        weak_ratio = len(weak_prereqs) / max(len(prerequisites), 1)
        
        is_cause = weak_ratio > 0.4
        confidence = min(0.8, weak_ratio) if is_cause else 0.0
        
        return {
            "is_cause": is_cause,
            "confidence": round(confidence, 2),
            "detail": {
                "total_prerequisites": len(prerequisites),
                "weak_prerequisites": len(weak_prereqs),
                "weak_ratio": round(weak_ratio, 3),
                "weak_knowledge_points": [kp.node_id for kp in weak_prereqs[:10]],
                "interpretation": "前置知识点掌握不足，新内容学习困难导致兴趣下降",
            },
        }
    
    def _analyze_external_factors(
        self, student_id, subject_code, recent
    ) -> dict:
        """分析外部因素（考试结束、假期结束等）"""
        # 检查是否在考试周后/假期后
        last_week = recent[-1]
        
        # 简单规则：如果当前周不是异常周但前几周有考试周
        exam_weeks = sum(1 for s in recent if self._is_exam_week(s.week_start_date))
        
        is_cause = False
        detail = {}
        
        if exam_weeks > 0:
            is_cause = True
            detail = {
                "exam_weeks_in_period": exam_weeks,
                "interpretation": "考试周结束后学科紧迫感下降，属正常现象",
            }
        
        return {
            "is_cause": is_cause,
            "confidence": 0.4 if is_cause else 0.0,
            "detail": detail,
        }
```

### 6.2 策略选择算法

```python
class StrategySelector:
    """兴趣重建策略选择器"""
    
    def __init__(self):
        self.library = ReconstructionStrategyLibrary()
    
    def select_strategies(
        self,
        decay_event: dict,
        student_profile: dict,
        max_strategies: int = 3,
    ) -> list[dict]:
        """
        为衰减事件选择最佳重建策略组合
        
        Args:
            decay_event: 衰减事件
            student_profile: 学生画像
            max_strategies: 最多返回策略数
        Returns:
            排序后的策略列表
        """
        candidates = []
        
        for template in self.library.STRATEGIES:
            # 1. 检查衰减等级是否满足
            if not self._meets_decay_level(
                decay_event["decay_level"], template["min_decay_level"]
            ):
                continue
            
            # 2. 检查原因匹配度
            cause_match = self._cause_match_score(
                decay_event["primary_cause"],
                template["applicable_causes"],
            )
            if cause_match <= 0:
                continue
            
            # 3. 计算综合优先级
            priority = self._calculate_priority(
                template, cause_match, decay_event, student_profile
            )
            
            # 4. 构建策略参数
            params = self._build_strategy_params(
                template, decay_event, student_profile
            )
            
            candidates.append({
                "strategy_code": template["code"],
                "strategy_name": template["name"],
                "strategy_category": template["category"],
                "params": params,
                "priority": priority,
                "planned_duration": self._estimate_duration(
                    template, decay_event["decay_level"]
                ),
            })
        
        # 按优先级排序，取前N个
        candidates.sort(key=lambda x: x["priority"], reverse=True)
        
        # 确保策略多样性（不同category至少各一个）
        selected = self._ensure_diversity(candidates, max_strategies)
        
        return selected
    
    def _calculate_priority(
        self, template, cause_match, decay_event, student_profile
    ) -> int:
        """计算策略综合优先级"""
        base = 50
        boost = template.get("priority_boost", 0)
        
        # 衰减等级加权
        level_weight = {"EARLY": 1.0, "MODERATE": 1.2, "SEVERE": 1.5}
        level_multiplier = level_weight.get(decay_event["decay_level"], 1.0)
        
        # 学段适配
        stage_bonus = self._stage_alignment_bonus(
            template, student_profile.get("stage")
        )
        
        # 历史效果加权（如果该策略之前对该学生有效）
        history_bonus = self._history_effect_bonus(
            template["code"], student_profile["student_id"]
        )
        
        total = int(base + (boost * cause_match * level_multiplier) 
                    + stage_bonus + history_bonus)
        return min(100, total)
```

```python
class StrategyExecutionOrchestrator:
    """策略执行编排器"""
    
    async def apply_strategies(
        self,
        student_id: int,
        subject_code: str,
        strategies: list[dict],
    ) -> list[str]:
        """
        将策略转化为实际的推荐内容调整和系统行为
        
        Returns:
            已应用的策略ID列表
        """
        applied_ids = []
        
        for strategy in strategies:
            handler = self._get_handler(strategy["strategy_code"])
            if handler is None:
                continue
            
            try:
                await handler.execute(
                    student_id=student_id,
                    subject_code=subject_code,
                    params=strategy["params"],
                )
                applied_ids.append(strategy["strategy_code"])
                
                # 记录策略状态
                await self.strategy_repo.update_status(
                    strategy["id"], "APPLIED"
                )
            except Exception as e:
                logger.error(
                    f"策略执行失败: student={student_id}, "
                    f"strategy={strategy['strategy_code']}, error={e}"
                )
                await self.strategy_repo.update_status(
```

## 10. 错误处理与降级策略

### 10.1 异常场景处理

| 异常场景 | 处理策略 |
|---------|---------|
| 学习行为数据不完整 | `data_completeness < 0.5` 时跳过该周快照，不参与趋势判定 |
| 学生新注册（数据不足） | 快照数 < 4周时不执行衰减检测，仅积累数据 |
| 异常周（假期/考试周） | 标记 `is_abnormal_week`，趋势判定时排除 |
| 基线计算样本不足 | 使用学段学科平均兴趣分作为默认基线（保守值50） |
| 策略执行失败 | 记录失败日志，标记策略为 EXPIRED，不影响其他策略执行 |
| 推荐系统不可达 | 策略降级为仅发送通知消息，不调整推荐参数 |

## 11. 效果评估模型

### 11.1 策略效果评估指标

```python
class StrategyEffectivenessEvaluator:
    """策略效果评估器"""
    
    async def evaluate(
        self, strategy_id: int
    ) -> dict:
        """
        评估单个策略的执行效果
        
        在策略应用后2-4周进行评估
        """
        strategy = await self.strategy_repo.find_by_id(strategy_id)
        event = await self.event_repo.find_by_id(strategy.event_id)
        
        # 获取策略应用前后的兴趣得分变化
        before_scores = await self.snapshot_repo.find_before(
            event.student_id, event.subject_code,
            end_date=strategy.applied_at.date(),
            weeks=3,
        )
        after_scores = await self.snapshot_repo.find_after(
            event.student_id, event.subject_code,
            start_date=strategy.applied_at.date(),
            weeks=3,
        )
        
        before_avg = sum(s.interest_score for s in before_scores) / max(len(before_scores), 1)
        after_avg = sum(s.interest_score for s in after_scores) / max(len(after_scores), 1)
        
        score_change = after_avg - before_avg
        recovery_rate = score_change / max(event.previous_score - before_avg, 1)
        
        # 判定效果
        if score_change >= 15 or recovery_rate >= 0.5:
            effectiveness = "EFFECTIVE"
        elif score_change >= 5 or recovery_rate >= 0.2:
            effectiveness = "PARTIALLY_EFFECTIVE"
        else:
            effectiveness = "INEFFECTIVE"
        
        return {
            "strategy_code": strategy.strategy_code,
            "score_before": round(before_avg, 2),
            "score_after": round(after_avg, 2),
            "score_change": round(score_change, 2),
            "recovery_rate": round(recovery_rate, 3),
            "effectiveness": effectiveness,
            "evaluation_period_weeks": 3,
        }
```

## 12. 安全与合规

### 12.1 数据安全

- 兴趣衰减事件包含学生学习行为分析数据，属于学生隐私信息
- API 接口需要验证调用者身份，仅允许学生本人、绑定家长、授权教师查询
- 兴趣快照数据保留2年，超过后自动归档脱敏

### 12.2 策略伦理约束

- 兴趣重建策略不应包含**过度营销**或**付费墙引导**
- "成功体验工程"策略不应降低学术标准到无意义程度
- AI学伴关怀对话不应替代专业心理咨询
- 策略执行频率需受控，避免对学生造成信息轰炸

### 12.3 家长可见性

- 家长可查看孩子的学科兴趣状态概览
- 衰减事件和重建策略以**关怀性语言**呈现，避免标签化
- 不在家长端直接显示原始兴趣得分数字，而是使用"兴趣较高/一般/需要关注"等级

### 13.1 批量检测优化

```python
class BatchDecayDetector:
    """批量衰减检测器"""
    
    BATCH_SIZE = 500
    
    async def run_weekly_detection(self, week_start: date):
        """每周批量检测"""
        # 1. 获取所有活跃学生ID
        student_ids = await self.get_active_student_ids()
        
        # 2. 分批处理
        for batch in chunked(student_ids, self.BATCH_SIZE):
            tasks = []
            for student_id in batch:
                task = self._detect_student_all_subjects(student_id, week_start)
                tasks.append(task)
            
            results = await asyncio.gather(*tasks, return_exceptions=True)
            
            # 3. 处理异常
            for student_id, result in zip(batch, results):
                if isinstance(result, Exception):
                    logger.error(
                        f"兴趣检测失败 student={student_id}: {result}"
                    )
            
            # 4. 批次间短暂休眠，降低DB压力
            await asyncio.sleep(0.5)
    
    async def _detect_student_all_subjects(
        self, student_id: int, week_start: date
    ):
        """检测学生所有学科"""
        subjects = await self.get_student_subjects(student_id)
        
        for subject in subjects:
            try:
                await self.detector.detect_decay(student_id, subject)
            except Exception as e:
                logger.warning(
                    f"学科兴趣检测异常: student={student_id}, "
                    f"subject={subject}, error={e}"
                )
                continue
```

## 15. 关键代码示例

### 15.1 完整检测流程入口

```python
class InterestDecayDetectionService:
    """兴趣衰减检测服务 - 主入口"""
    
    def __init__(self):
        self.aggregator = InterestDataAggregator()
        self.calculator = InterestScoreCalculator()
        self.trend_analyzer = InterestTrendAnalyzer()
        self.detector = InterestDecayDetector()
        self.cause_analyzer = InterestDecayRootCauseAnalyzer()
        self.strategy_selector = StrategySelector()
        self.orchestrator = StrategyExecutionOrchestrator()
        self.snapshot_repo = InterestSnapshotRepository()
        self.baseline_repo = InterestBaselineRepository()
        self.event_repo = InterestDecayEventRepository()
    
    async def run_weekly_detection_for_student(
        self, student_id: int, week_start: date
    ) -> dict:
        """
        对单个学生执行完整的周度兴趣衰减检测流程
        """
        logger.info(f"开始兴趣检测: student={student_id}, week={week_start}")
        
        # Step 1: 数据采集
        snapshots_raw = await self.aggregator.aggregate_weekly_data(
            student_id, week_start
        )
        if not snapshots_raw:
            return {"status": "NO_DATA", "student_id": student_id}
        
        # Step 2: 计算兴趣得分
        for snap in snapshots_raw:
            baseline = await self.baseline_repo.find_or_create(
                student_id, snap["subject_code"]
            )
            score = self.calculator.calculate_interest_score(snap, baseline)
            snap["interest_score"] = score
            
            # 趋势判定
            history = await self.snapshot_repo.find_recent(
                student_id, snap["subject_code"], weeks=4
            )
            scores_seq = [h.interest_score for h in history] + [score]
            trend, slope = self.trend_analyzer.analyze_trend(scores_seq)
            snap["interest_trend"] = trend
            
            # 持久化快照
            await self.snapshot_repo.save(snap)
        
        # Step 3: 衰减检测
        decay_events = []
        for snap in snapshots_raw:
            event = await self.detector.detect_decay(
                student_id, snap["subject_code"]
            )
            if event:
                decay_events.append(event)
        
        if not decay_events:
            return {"status": "NO_DECAY", "student_id": student_id}
        
        # Step 4: 根因分析 & 策略生成
        for event in decay_events:
            # 根因分析已在检测中完成
            # 生成策略
            student_profile = await self.get_student_profile(student_id)
            strategies = self.strategy_selector.select_strategies(
                event, student_profile, max_strategies=3
            )
            
            # 持久化策略
            for s in strategies:
                s["event_id"] = event["event_id"]
                s["student_id"] = student_id
                s["subject_code"] = event["subject_code"]
                await self.event_repo.save_strategy(s)
            
            # 应用策略
            applied = await self.orchestrator.apply_strategies(
                student_id, event["subject_code"], strategies
            )
            
            logger.info(
                f"兴趣衰减干预: student={student_id}, "
                f"subject={event['subject_code']}, "
                f"level={event['decay_level']}, "
                f"strategies={applied}"
            )
        
        return {
            "status": "DETECTED",
            "student_id": student_id,
            "events": [
                {
                    "subject": e["subject_code"],
                    "level": e["decay_level"],
                    "cause": e["primary_cause"],
                }
                for e in decay_events
            ],
        }
```

### 16.2 集成测试

```python
class TestInterestDecayFlow(IntegrationTestCase):
    
    async def test_full_detection_to_intervention_flow(self):
        """测试从检测到干预的完整流程"""
        # 1. 模拟学生4周学习数据（兴趣逐周下降）
        student_id = await self.create_test_student(stage="JUNIOR_HIGH")
        await self.simulate_learning_data(
            student_id, "physics",
            weekly_scores=[75, 72, 60, 45],  # 持续下降
        )
        
        # 2. 触发检测
        result = await self.service.run_weekly_detection_for_student(
            student_id, date.today()
        )
        
        # 3. 验证衰减事件已生成
        assert result["status"] == "DETECTED"
        event = result["events"][0]
        assert event["subject"] == "physics"
        assert event["level"] in ("EARLY", "MODERATE", "SEVERE")
        
        # 4. 验证策略已生成和应用
        strategies = await self.strategy_repo.find_by_event(event["event_id"])
        assert len(strategies) > 0
        assert all(s["status"] == "APPLIED" for s in strategies)
    
    async def test_no_decay_normal_student(self):
        """测试兴趣稳定的学生不触发误报"""
        student_id = await self.create_test_student(stage="JUNIOR_HIGH")
        await self.simulate_learning_data(
            student_id, "math",
            weekly_scores=[70, 72, 71, 73],  # 稳定波动
        )
        
        result = await self.service.run_weekly_detection_for_student(
            student_id, date.today()
        )
        
        assert result["status"] == "NO_DECAY"
```

### 17.2 衰减等级应对策略矩阵

| 衰减等级 | 兴趣得分范围 | 推荐策略类别 | 通知级别 |
|---------|------------|------------|---------|
| EARLY | 基线下10-19分 | CONTENT + FEEDBACK | 学生端轻提醒 |
| MODERATE | 基线下20-29分 | CONTENT + GAMIFICATION + FEEDBACK | 学生端关怀 + 家长端概览更新 |
| SEVERE | 基线下30分以上 | 全类别策略 + AI学伴主动关怀 | 学生端 + 家长端 + 教师端通知 |

### 17.3 术语表

| 术语 | 定义 |
|------|------|
| 兴趣快照 | 学生某周在某学科上的兴趣指标综合快照 |
| 兴趣基线 | 基于历史数据计算的该学生该学科的正常兴趣水平 |

| 根因分析 | 分析兴趣衰减背后潜在原因的过程 |
| 效果评估 | 策略执行后对兴趣恢复效果的量化评估 |
