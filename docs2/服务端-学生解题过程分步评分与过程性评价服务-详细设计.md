# 服务端 - 学生解题过程分步评分与过程性评价服务

> 模块负责人：待定 | 版本：1.0 | 日期：2026-06-03

---

## 1. 模块概述

### 1.1 定位

学生解题过程分步评分与过程性评价服务（Stepwise Solution Evaluation Service, SSES）是 PrimeTop 面向初中、高中学生理科学习场景的核心 P1 服务。与"理科解题步骤推导服务"负责 **AI 生成标准解题过程** 不同，本服务负责 **评估学生自己书写/输入的解题过程**——逐步判断每一步的正确性、定位错误步骤、计算部分得分、生成分步反馈。

本服务的核心价值在于：**不仅判断对错，更要告诉学生在哪一步错了、为什么错了、怎么改**。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 解题步骤分割 | 将学生提交的解题过程（文本/手写识别文本）分割为独立逻辑步骤 |
| 步骤级正确性判定 | 逐步判定每一步是否正确，标注错误类型 |
| 错误步骤精确定位 | 定位第一个错误步骤，分析错误根因 |
| 部分得分计算 | 基于步骤完成度和正确度计算过程得分（非全对/全错） |
| 步骤级反馈生成 | 为每个步骤生成针对性反馈（正确肯定 / 错误纠正 / 优化建议） |
| 解题方法质量评估 | 评估学生所选方法是否最优、是否存在更简洁解法 |
| 过程性掌握度更新 | 基于过程评估结果更新知识点掌握度（区别于只看答案对错） |
| 规范性评分 | 评分维度覆盖：逻辑完整性、计算准确性、表达规范性、方法选择 |

### 1.3 适用场景

| 场景 | 触发方式 | 说明 |
|------|---------|------|
| 练习自由作答 | 学生在练习中输入解题过程后提交 | 主动评分 |
| 错题订正 | 学生对错题重新写出解题过程 | 订正效果评估 |
| 作业批改 | 上传作业图片，OCR 提取后评分 | 批量评分 |
| 拍题追问 | 学生对 AI 解答追问"我这样解为什么不对" | 按需评估 |
| 考试模拟 | 模拟考试中大题自由作答 | 按步骤给分 |

### 1.4 与其他模块的关系

| 关联模块 | 关系 | 交互方式 |
|---------|------|---------|
| 理科解题步骤推导与模型匹配解析服务 | 上游：获取标准解题过程作为参照 | RPC 同步调用 |
| 练习答题实时批改与知识点掌握度增量更新服务 | 互补：本服务提供过程级评分，批改服务消费评分结果 | 事件发布 |
| 答案管控与渐进式提示引擎 | 上游：在提示阶段可参考本服务的步骤评估 | RPC 同步调用 |
| AI教育辅导策略引擎 | 下游：基于步骤评估结果选择辅导策略 | 事件发布 |
| 拍照图像采集与预处理引擎 | 上游：手写解题过程的 OCR 文本输入 | 消息消费 |
| 错题整理模块 | 下游：消费错误步骤定位信息丰富错因标签 | 事件发布 |
| AI-Prompt编排与场景模板系统 | 本服务消费 Prompt 模板组装评估请求 | RPC 同步调用 |
| 多模型调度与成本治理 | 本服务消费模型路由，选择评估模型 | RPC 同步调用 |
| 知识点体系与教材映射引擎 | 本服务输出步骤级知识点映射 | RPC 同步调用 |

### 1.5 适用学科与题型

| 学科 | 适用题型 | 不适用 |
|------|---------|--------|
| 数学 | 解答题、证明题、计算题、应用题 | 选择题、填空题 |
| 物理 | 计算题、实验分析题、推导证明题 | 选择题 |
| 化学 | 方程式书写、计算题、实验推断题 | 选择题 |
| 生物 | 遗传推断题、实验设计题 | 选择题 |
| 英语/语文 | 不适用 | — |

> 英语作文的步骤评估由「作文批改评分引擎」负责，不在本服务范围内。

### 2.3 数据库表设计

#### 2.3.1 解题过程评估记录表（step_evaluation_record）

```sql
CREATE TABLE step_evaluation_record (
    id                  BIGSERIAL PRIMARY KEY,
    request_id          VARCHAR(64) NOT NULL UNIQUE,           -- 评估请求ID
    student_id          BIGINT NOT NULL,                       -- 学生ID
    question_id         BIGINT NOT NULL,                       -- 题目ID
    session_id          VARCHAR(64),                           -- 学习会话ID
    scene               VARCHAR(32) NOT NULL,                  -- 场景：practice_free_answer / mistake_correction / homework / exam_simulation
    
    -- 学生提交内容
    input_type          VARCHAR(16) NOT NULL,                  -- text / handwriting_ocr
    raw_content         TEXT NOT NULL,                          -- 原始解题过程文本
    step_count          INT NOT NULL,                           -- 步骤数
    
    -- 总体评分
    total_score         DECIMAL(5,2) NOT NULL,                  -- 总得分
    full_score          DECIMAL(5,2) NOT NULL,                  -- 满分
    correctness_level   VARCHAR(48) NOT NULL,                   -- 正确性级别
    
    -- 方法评估
    method_selected     VARCHAR(64),                            -- 学生使用的方法
    method_is_optimal   BOOLEAN,                                -- 方法是否最优
    efficiency_rating   VARCHAR(16),                            -- 效率评级：EXCELLENT / GOOD / FAIR / POOR
    
    -- 过程指标
    logic_completeness  DECIMAL(3,2),                           -- 逻辑完整性 0~1
    calculation_accuracy DECIMAL(3,2),                          -- 计算准确性 0~1
    expression_normative DECIMAL(3,2),                          -- 表达规范性 0~1
    method_selection    DECIMAL(3,2),                           -- 方法选择合理性 0~1
    
    -- AI 评估元数据
    ai_model_used       VARCHAR(64),                            -- 使用的AI模型
    ai_tokens_consumed  INT,                                    -- token消耗
    evaluation_latency_ms INT,                                  -- 评估耗时(ms)
    
    -- 审计
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_ser_student ON step_evaluation_record(student_id, created_at DESC);
CREATE INDEX idx_ser_question ON step_evaluation_record(question_id, created_at DESC);
CREATE INDEX idx_ser_session ON step_evaluation_record(session_id);
CREATE INDEX idx_ser_scene ON step_evaluation_record(scene, created_at DESC);
```

#### 2.3.2 步骤评估明细表（step_evaluation_detail）

```sql
CREATE TABLE step_evaluation_detail (
    id                  BIGSERIAL PRIMARY KEY,
    record_id           BIGINT NOT NULL REFERENCES step_evaluation_record(id),
    step_index          INT NOT NULL,                            -- 步骤序号（从1开始）
    content             TEXT NOT NULL,                           -- 步骤内容
    is_correct          BOOLEAN NOT NULL,                        -- 是否正确
    correctness_type    VARCHAR(48) NOT NULL,                    -- 正确性类型
    score               DECIMAL(5,2) NOT NULL,                   -- 本步得分
    max_score           DECIMAL(5,2) NOT NULL,                   -- 本步满分
    score_penalty       DECIMAL(5,2) DEFAULT 0,                  -- 扣分
    
    -- 错误详情（仅错误步骤有值）
    error_type          VARCHAR(48),                             -- 错误类型
    error_description   TEXT,                                    -- 错误描述
    correction_hint     TEXT,                                    -- 修正提示
    
    -- AI 生成
    feedback            TEXT,                                    -- 步骤反馈文本
    knowledge_points    JSONB,                                   -- 关联知识点ID列表
    
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    UNIQUE(record_id, step_index)
);

CREATE INDEX idx_sed_record ON step_evaluation_detail(record_id, step_index);
```

#### 2.3.3 步骤级知识点掌握度更新日志（step_kp_mastery_log）

```sql
CREATE TABLE step_kp_mastery_log (

    student_id          BIGINT NOT NULL NOT NULL,

    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()

CREATE INDEX idx_skml_student_kp ON step_kp_mastery_log(student_id, knowledge_point_id, created_at DESC);

```

请求体：

### 3.2 查询评估历史

**GET** `/api/v1/step-evaluation/records`

查询参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| studentId | long | 是 | 学生ID |
| questionId | long | 否 | 题目ID（查特定题目的评估记录） |
| scene | string | 否 | 场景过滤 |
| startDate | string | 否 | 起始日期 (ISO 8601) |
| endDate | string | 否 | 结束日期 (ISO 8601) |
| page | int | 否 | 页码（默认1） |
| pageSize | int | 否 | 每页数量（默认20，最大100） |

### 3.3 获取单次评估详情

**GET** `/api/v1/step-evaluation/records/{requestId}`

返回完整的评估记录，包含所有步骤明细和知识点掌握度更新日志。

### 3.4 获取题目评分模板

**GET** `/api/v1/step-evaluation/rubrics/{questionId}`

根据题目信息自动匹配评分模板并返回，用于客户端展示评分标准。
