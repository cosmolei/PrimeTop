# 学习提醒与智能通知调度系统 - 详细设计

## 1. 模块概述

### 1.1 定位

学习提醒与智能通知调度系统是横跨学习规划、错题复习、家长中心、会员运营等多个业务模块的**上层调度引擎**。它不负责消息的传输投递（由「消息与推送服务」负责），而是解决：**对谁、在什么时间、通过什么渠道、发送什么内容、以什么频率**的问题。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 提醒类型管理 | 支持学习计划、错题复习、打卡、家长周报等 20+ 种提醒类型 |
| 智能时间窗口 | 基于用户历史活跃时段动态计算最佳推送时间 |
| 频率管控 | 全局/类型/渠道三级频率上限，防打扰 |
| 渠道路由 | 根据提醒优先级与用户偏好选择 Push/端内/短信/邮件渠道 |
| 聚合与去重 | 同一用户的同类提醒在时间窗口内聚合为一条 |
| 生效期控制 | 支持一次性、周期性、条件触发三种模式 |
| 效果追踪 | 送达→点击→转化全链路归因 |

### 1.3 与其他模块的关系

```
学习规划 ──┐
错题整理 ──┤
练习与测评 ─┤  ┌──────────────────┐   ┌──────────────┐
家长中心 ──┼──▶│ 学习提醒调度引擎  │──▶│ 消息与推送服务 │
会员订阅 ──┤  └──────────────────┘   └──────────────┘
运营活动 ──┤         ▲
收藏/笔记 ─┘         │
              定时触发 / 事件触发
```

### 4.2 智能时段计算

```python
def compute_best_send_time(user_id: int, template_code: str) -> datetime:
    """
    为用户计算本次提醒的最佳发送时间。
    优先级：用户偏好时段 > 智能时段 > 模板默认时段
    """
    subscription = get_subscription(user_id, template_code)
    pattern = get_active_pattern(user_id)
    now = datetime.now(ZoneInfo("Asia/Shanghai"))
    
    # 1. 免打扰检查 (23:00 - 07:00)
    if is_quiet_hours(now):
        return next_available_after(now, hour=7)
    
    # 2. 用户自定义时段（最高优先级）
    if subscription and subscription.preferred_time_start:
        start = subscription.preferred_time_start
        end = subscription.preferred_time_end
        if start <= now.time() <= end:
            return now  # 在偏好时段内，立即发送
        elif now.time() < start:
            return now.replace(hour=start.hour, minute=start.minute)
        else:
            # 已过今日偏好时段，推到明日
            return (now + timedelta(days=1)).replace(
                hour=start.hour, minute=start.minute
            )
    
    # 3. 智能时段（基于活跃模型）
    if pattern and pattern.sample_sessions >= 10:
        # 在今日剩余时段中找权重最高的 slot
        best_hour = find_best_remaining_hour(pattern, now)
        if best_hour is not None:
            return now.replace(hour=best_hour, minute=0, second=0)
    
    # 4. 模板默认（由 cron 表达式决定）
    return now
```

### 4.3 频率管控算法

```python
class FrequencyGuard:
    """三级频率管控"""
    
    def check(self, user_id: int, template_code: str, channel: str) -> bool:
        template = get_template(template_code)
        today = date.today()
        
        # Level 1: 全局每日上限（按会员等级）
        budget = get_global_budget(user_id, today)
        membership = get_membership(user_id)
        daily_limit = self._get_daily_limit(membership)
        # free: 3/day, basic: 5/day, premium: 8/day
        
        if budget.total_count() >= daily_limit:
            return False  # 全局预算耗尽
        
        # Level 2: 模板类型级上限
        type_count = count_dispatched(user_id, template_code, today)
        if type_count >= template.max_per_day:
            return False
        
        # Level 3: 冷却期（同类型两次之间最短间隔）
        last_dispatch = get_last_dispatch(user_id, template_code)
        if last_dispatch:
            elapsed = (datetime.now() - last_dispatch.actual_at).total_seconds() / 60
            if elapsed < template.cooldown_minutes:
                return False
        
        return True
    
    def _get_daily_limit(self, membership) -> int:
        limits = {
            "free": 3,
            "basic_monthly": 5,
            "basic_annual": 5,
            "premium": 8,
        }
        return limits.get(membership.tier, 3)
```

### 4.4 聚合与去重

```python
class ReminderAggregator:
    """提醒聚合器"""
    
    def try_aggregate(
        self,
        user_id: int,
        template_code: str,
        content: str,
        window_minutes: int
    ) -> tuple[bool, str | None]:
        """
        尝试聚合。返回 (是否聚合成功, 聚合后内容)。
        如果窗口内有同类型待发送提醒，则聚合。
        """
        if window_minutes <= 0:
            return False, None
        
        cutoff = datetime.now() - timedelta(minutes=window_minutes)
        
        # 查找窗口内的同类型记录
        pending = get_pending_dispatches(
            user_id, template_code, since=cutoff
        )
        
        if not pending:
            return False, None
        
        template = get_template(template_code)
        
        # 使用聚合模板重写内容
        total_count = len(pending) + 1
        aggregated_body = render_template(
            template.aggregate_template,
            {"count": total_count, "nickname": get_nickname(user_id)}
        )
        
        # 标记旧记录为已聚合
        mark_aggregated([p.id for p in pending])
        
        return True, aggregated_body
```

### 5.2 路由决策

```python
def route_channels(
    template: ReminderTemplate,
    subscription: ReminderSubscription | None,
    membership_tier: str,
    budget: ReminderGlobalBudget
) -> list[str]:
    """决定使用哪些渠道"""
    
    # 用户偏好优先
    if subscription and subscription.preferred_channels:
        preferred = subscription.preferred_channels
    else:
        preferred = template.default_channels
    
    # 过滤掉预算耗尽的渠道
    result = []
    for ch in preferred:
        if ch == "push" and budget.push_count < budget.daily_limit:
            result.append("push")
        elif ch == "in_app":
            result.append("in_app")  # 端内无上限
        elif ch == "sms" and budget.sms_count < 1:  # 短信严格限制
            if membership_tier != "free":  # 免费用户不发短信
                result.append("sms")
        elif ch == "email":
            result.append("email")
    
    # 至少保证一个渠道
    if not result:
        result = ["in_app"]
    
    return result
```

### 6.2 遗忘曲线复习调度

```python
def compute_review_dates(created_at: datetime) -> list[datetime]:
    """
    基于艾宾浩斯遗忘曲线计算复习日期。
    间隔：1天、2天、4天、7天、15天、30天
    """
    intervals = [1, 2, 4, 7, 15, 30]  # 天
    return [created_at + timedelta(days=d) for d in intervals]


def schedule_mistake_reviews(user_id: int, mistake_id: int, created_at: datetime):
    """为错题创建定时复习提醒"""
    review_dates = compute_review_dates(created_at)
    
    for i, review_at in enumerate(review_dates):
        # 使用 Celery apply_on_schedule 延迟任务
        schedule_reminder(
            template_code="mistake.review_due",
            user_id=user_id,
            scheduled_at=review_at,
            context={
                "mistake_id": mistake_id,
                "round": i + 1,
                "total_rounds": len(review_dates),
            },
            # 如果用户已完成该轮复习则自动跳过
            skip_condition=f"mistake_reviewed:{mistake_id}:{i+1}",
        )
```

## 7. 活跃时段模型计算

### 7.1 数据来源

基于用户学习会话记录 (learning_session) 计算活跃时段：

```python
def compute_active_pattern(user_id: int, sample_days: int = 14) -> UserActivePattern:
    """
    基于最近 N 天的学习会话数据计算用户活跃时段模型。
    """
    since = datetime.now() - timedelta(days=sample_days)
    sessions = get_learning_sessions(user_id, since=since)
    
    if len(sessions) < 5:
        # 数据不足，返回默认模型
        return default_pattern()
    
    # 统计每小时的会话数
    hourly_counts = [0] * 24
    weekly_counts = [0] * 7
    
    for session in sessions:
        hour = session.started_at.hour
        weekday = session.started_at.weekday()  # 0=周一
        hourly_counts[hour] += 1
        weekly_counts[weekday] += 1
    
    # 归一化为权重 [0, 1]
    max_hourly = max(hourly_counts) or 1
    hourly_weights = [c / max_hourly for c in hourly_counts]
    
    max_weekly = max(weekly_counts) or 1
    weekly_weights = [c / max_weekly for c in weekly_counts]
    
    # 找 Top3 最佳推送时段（排除 23:00-07:00）
    candidates = [(h, hourly_weights[h]) for h in range(7, 23)]
    candidates.sort(key=lambda x: x[1], reverse=True)
    best_slots = [f"{h:02d}:00" for h, _ in candidates[:3]]
    
    return UserActivePattern(
        user_id=user_id,
        hourly_weights=hourly_weights,
        weekly_weights=weekly_weights,
        best_slots=best_slots,
        last_active_at=sessions[-1].ended_at or sessions[-1].started_at,
        sample_days=sample_days,
        sample_sessions=len(sessions),
        computed_at=datetime.now(),
    )
```

## 9. Celery 任务定义

### 9.1 定时调度任务

```python
# ============================================================
# 学习提醒调度 Celery 任务注册表
# ============================================================

from celery import shared_task
from datetime import datetime, timedelta
from django.utils import timezone


@shared_task(name="reminder.cron_dispatch")
def cron_dispatch(template_code: str):
    """
    定时提醒调度入口。
    由 Celery Beat 按 cron 表达式触发。
    """
    template = ReminderTemplate.objects.get(
        template_code=template_code, enabled=True
    )
    
    # 筛选目标用户
    user_ids = resolve_target_users(template)
    
    # 批量调度（分批处理，避免内存爆炸）
    for batch in chunked(user_ids, batch_size=200):
        dispatch_batch.delay(template_code, batch)


@shared_task(name="reminder.dispatch_batch")
def dispatch_batch(template_code: str, user_ids: list[int]):
    """批量发送提醒"""
    template = ReminderTemplate.objects.get(template_code=template_code)
    
    for uid in user_ids:
        try:
            dispatch_single(uid, template)
        except Exception as e:
            log_error(uid, template_code, str(e))


@shared_task(name="reminder.event_dispatch")
def event_dispatch(
    template_code: str,
    user_id: int,
    context: dict,
    delay_seconds: int = 0
):
    """事件触发的单用户提醒"""
    template = ReminderTemplate.objects.get(
        template_code=template_code, enabled=True
    )
    
    # 延迟发送（用于遗忘曲线等场景）
    scheduled_at = timezone.now() + timedelta(seconds=delay_seconds)
    
    # 跳过条件检查（如已复习则不发）
    skip_condition = context.get("skip_condition")
    if skip_condition and evaluate_skip_condition(skip_condition):
        return
    
    dispatch_single(user_id, template, context=context, scheduled_at=scheduled_at)


@shared_task(name="reminder.recompute_active_patterns")
def recompute_active_patterns():
    """每天 03:00 重算活跃时段模型"""
    active_user_ids = get_recent_active_user_ids(days=30)
    for uid in batched(active_user_ids, 500):
        compute_active_pattern.delay(uid)


@shared_task(name="reminder.cleanup_old_logs")
def cleanup_old_logs():
    """每月清理 90 天前的调度日志"""
    cutoff = timezone.now() - timedelta(days=90)
    ReminderDispatchLog.objects.filter(created_at__lt=cutoff).delete()
```

## 10. 状态流转

### 10.1 调度记录状态机

```
                    ┌──────────┐
                    │ pending  │  ← 创建调度记录
                    └────┬─────┘
                         │
              ┌──────────┼──────────┐
              │          │          │
        ┌─────▼──┐ ┌────▼───┐ ┌───▼──────┐
        │skipped │ │  sent  │ │  failed  │
        └────────┘ └────┬───┘ └──────────┘
                        │
                  ┌─────┼─────┐
                  │           │
            ┌─────▼──┐  ┌───▼───────┐
            │delivered│  │  clicked  │
            └─────┬───┘  └─────┬─────┘
                  │            │
                  └─────┬──────┘
                        │
                  ┌─────▼──────┐
                  │ converted  │
                  └────────────┘
```

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| `pending` | 已创建待发送 | 调度器创建 |
| `skipped` | 跳过发送 | 频率限制/免打扰/用户关闭/静音/已聚合 |
| `sent` | 已发送 | 消息推送服务返回成功 |
| `failed` | 发送失败 | 消息推送服务返回异常 |
| `delivered` | 已送达 | Push 回调确认送达 |
| `clicked` | 已点击 | 客户端上报点击事件 |
| `converted` | 已转化 | 用户完成目标行为（如完成复习、打开错题本） |

### 10.2 转化归因

```python
def track_conversion(dispatch_id: str, action: str):
    """
    追踪转化行为。
    
    转化窗口：提醒发送后 24 小时内的目标行为。
    
    各类型的转化行为定义：
    - plan.daily_remind → 完成任意学习任务
    - mistake.review_due → 完成错题复习
    - parent.weekly_report → 打开家长学情页
    - member.expiring → 续费/购买
    - op.checkin → 完成打卡
    """
    log = ReminderDispatchLog.objects.get(dispatch_id=dispatch_id)
    
    # 检查转化窗口
    if log.actual_at and (timezone.now() - log.actual_at).total_seconds() <= 86400:
        log.status = "converted"
        log.save(update_fields=["status"])
```

## 12. 错误处理

### 12.1 错误码

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| `REMINDER_001` | 模板不存在 | 日志告警，跳过 |
| `REMINDER_002` | 用户无订阅 | 静默跳过（使用默认设置） |
| `REMINDER_003` | 频率限制触发 | 标记 skipped，记录原因 |
| `REMINDER_004` | 免打扰时段 | 延迟到下一可用时段 |
| `REMINDER_005` | 模板渲染失败 | 降级使用默认文案 |
| `REMINDER_006` | 推送服务不可用 | 重试 3 次，间隔 5/30/120s，最终标记 failed |
| `REMINDER_007` | 用户已注销 | 清除该用户所有待发送提醒 |

### 12.2 降级策略

```python
class ReminderDispatchService:
    """
    调度降级策略：
    1. 推送服务不可用 → 降级为仅端内消息
    2. 活跃时段模型不可用 → 使用模板默认时间
    3. 数据库慢查询 → 减小批次大小，增加重试间隔
    4. 全量调度超时 → 按优先级裁剪低优先级提醒
    """
    
    def dispatch_single(self, user_id, template, **kwargs):
        try:
            channels = self.route_channels(template, user_id)
        except Exception:
            # 路由失败，降级为端内
            channels = ["in_app"]
        
        try:
            content = self.render_content(template, user_id, kwargs.get("context", {}))
        except Exception:
            # 渲染失败，降级为默认文案
            content = self.default_content(template)
        
        try:
            self.send(user_id, channels, content)
        except PushServiceUnavailable:
            # Push 不可用，降级为仅端内
            self.send(user_id, ["in_app"], content)
        except Exception as e:
            # 其他异常，记录并标记 failed
            self.mark_failed(user_id, template.template_code, str(e))
```

- dispatch_log：日均 85K 条 × ~500B = ~42MB/天
- 月增量：~1.3GB
- 保留 90 天：~3.8GB
- 建议按月分表或使用 ClickHouse 归档历史数据

## 16. 安全与合规

1. **隐私合规**：提醒内容不得在推送标题中暴露具体学习内容（如错题题目）
2. **家长通知**：涉及未成年人学习数据的通知仅发送至已绑定家长
3. **免打扰强制**：23:00-07:00 免打扰时段不可关闭（合规要求）
4. **退订机制**：所有提醒类型均支持用户关闭（合规要求的时长管控除外）
5. **内容审核**：自定义模板内容需经审核后方可启用
6. **数据脱敏**：推送日志中的用户信息在 90 天后自动脱敏
