# 题目难度标定与能力评估模型 - 详细设计

> 版本: 1.0 | 创建: 2026-05-23 | 状态: 初稿

## 1. 概述

### 1.1 文档目的

本文档详细定义 PrimeTop 系统中**题目难度标定**（标定每道题的难度、区分度等参数）和**学生能力评估**（基于答题数据实时估算学生知识掌握水平）两大核心算法引擎的设计。这是自适应学习推荐、个性化练习推送、学情分析和学习路径规划的技术基石。

### 1.2 设计原则

1. **渐进式标定**：新题目上线时允许参数不精确，通过实际答题数据持续校准
2. **学科差异化**：不同学科（数学/语文/英语）采用不同的难度模型和标定策略
3. **实时性**：学生每次答题后异步更新能力估值，延迟不超过 30 秒
4. **冷启动友好**：新用户和新题目都有合理的初始估算机制
5. **可解释性**：能力评估结果能转化为家长和学生可理解的"掌握度"指标

### 1.3 与其他模块的关系

| 关联模块 | 依赖方向 | 说明 |
|---------|---------|------|
| 题目与题库服务 | 读取 | 获取题目元数据、标签、知识点映射 |
| 练习与测评系统 | 双向 | 接收答题记录，输出推荐难度区间 |
| 自适应学习与个性化推荐引擎 | 输出 | 提供难度参数和能力值用于推荐 |
| 错题整理 | 输入 | 错题数据回流参与能力校准 |
| 学情分析 | 输出 | 提供知识点维度的掌握度数据 |
| AI题目智能生成引擎 | 双向 | AI生成题需初始标定，后续答题数据校准 |
| 学习记录与进度追踪服务 | 输入 | 答题行为数据来源 |

## 2. 核心概念与数据模型

### 2.1 题目参数模型（Item Parameters）

基于 Item Response Theory (IRT) 三参数逻辑斯蒂模型（3PL），每道题存储以下参数：

```typescript
interface ItemParameters {
  questionId: string;
  
  /**
   * 难度参数 (b参数)
   * 范围: [-3, 3]，对应实际难度等级 1-10
   * 含义: 能力值恰好等于b的学生，答对概率约为 c + (1-c) × 0.5
   */
  difficulty: number;
  
  /**
   * 区分度参数 (a参数)
   * 范围: (0, +∞)，实际通常 [0.3, 3.0]
   * 含义: 题目区分高低能力学生的效力
   */
  discrimination: number;
  
  /**
   * 猜测参数 (c参数)
   * 范围: [0, 0.5]
   * 含义: 完全不会的学生靠猜测答对的概率
   * 选择题通常 0.2-0.25，填空/解答题为 0
   */
  guessing: number;
  
  /** 参数估计标准误 */
  standardError: {
    difficultySE: number;
    discriminationSE: number;
  };
  
  /** 标定状态 */
  calibrationStatus: 'preliminary' | 'calibrated' | 'reviewed';
  
  /** 标定样本量 */
  responseCount: number;
  
  /** 最后标定时间 */
  lastCalibratedAt: Date;
  
  /** 标定方法 */
  calibrationMethod: 'expert' | 'ai' | 'statistical' | 'hybrid';
  
  /** 扩展难度描述 */
  extendedDifficulty: {
    computationalComplexity: number;  // 1-5
    conceptualAbstraction: number;    // 1-5
    estimatedSteps: number;
    hasVisualContent: boolean;
  };
}
```

```typescript
enum DifficultyLevel {
  Beginner = 1,       // 入门 - IRT b < -1.5
  Basic = 2,          // 基础 - IRT b [-1.5, -0.5)
  Consolidation = 3,  // 巩固 - IRT b [-0.5, 0.5)
  Improvement = 4,    // 提高 - IRT b [0.5, 1.5)
  Advanced = 5,       // 拔高 - IRT b [1.5, 2.5)
  Challenge = 6,      // 挑战 - IRT b >= 2.5
}

function mapIRTToDifficultyLevel(b: number): DifficultyLevel {
  if (b < -1.5) return DifficultyLevel.Beginner;
  if (b < -0.5) return DifficultyLevel.Basic;
  if (b < 0.5) return DifficultyLevel.Consolidation;
  if (b < 1.5) return DifficultyLevel.Improvement;
  if (b < 2.5) return DifficultyLevel.Advanced;
  return DifficultyLevel.Challenge;
}

/** 能力值 → 掌握度百分比（前端展示用） */
function abilityToMastery(theta: number): number {
  return 1 / (1 + Math.exp(-theta)); // sigmoid
}
```

### 3.2 Stage 1: 初始难度预估

新题目入库时尚无答题数据，采用多因素综合预估：

```python
class InitialDifficultyEstimator:
    """新题目初始难度预估器"""

    def estimate(self, question: Question) -> ItemParameters:
        # 因素1: AI 预估
        ai_estimate = self._ai_estimate_difficulty(question)
        # 因素2: 规则打分
        rule_score = self._rule_based_score(question)
        # 因素3: 同类题参考
        similar_params = self._find_similar_item_params(question)

        # 加权融合
        if similar_params:
            b = 0.3 * ai_estimate + 0.2 * rule_score + 0.5 * similar_params.difficulty
        else:
            b = 0.6 * ai_estimate + 0.4 * rule_score

        a, c = self._default_ac_params(question.question_type)
        return ItemParameters(
            difficulty=b, discrimination=a, guessing=c,
            calibration_status='preliminary',
            response_count=0, calibration_method='hybrid',
            standard_error={'difficulty_se': 0.8, 'discrimination_se': 0.5}
        )

    def _rule_based_score(self, question: Question) -> float:
        """基于题目结构特征的规则打分"""
        score = 0.0
        type_baseline = {
            'true_false': -2.0, 'fill_blank': -1.0, 'single_choice': -0.5,
            'multi_choice': 0.3, 'short_answer': 0.5, 'calculation': 1.0,
            'proof': 1.5, 'essay': 1.0, 'comprehensive': 1.8,
        }
        score += type_baseline.get(question.question_type, 0.0)
        score += min(self._estimate_steps(question) * 0.15, 1.0)
        if question.has_image or question.has_chart:
            score += 0.3
        kp_count = len(question.knowledge_point_ids)
        score += min((kp_count - 1) * 0.2, 0.6)
        return max(-3.0, min(3.0, score))

    def _default_ac_params(self, question_type: str) -> tuple[float, float]:
        """题型 → 默认区分度和猜测参数"""
        defaults = {
            'true_false': (0.8, 0.5), 'single_choice': (1.0, 0.25),
            'multi_choice': (1.1, 0.15), 'fill_blank': (1.0, 0.05),
            'short_answer': (0.9, 0.0), 'calculation': (1.2, 0.0),
            'proof': (1.3, 0.0), 'essay': (0.8, 0.0), 'comprehensive': (1.1, 0.0),
        }
        return defaults.get(question_type, (1.0, 0.1))
```

### 3.3 Stage 3: 统计标定（EM 算法）

当题目积累 ≥30 条有效作答后执行：

```python
import numpy as np

class IRTCalibrator:
    """IRT 参数标定器 - EM 算法"""

    def calibrate_item(
        self,
        responses: list[ResponseRecord],
        student_abilities: dict[str, float],
        max_iterations: int = 50,
        convergence_threshold: float = 0.01
    ) -> ItemParameters:
        n = len(responses)
        if n < 30:
            raise InsufficientDataError(f"需要至少30条，当前{n}条")

        theta = np.array([student_abilities.get(r.student_id, 0.0) for r in responses])
        u = np.array([1.0 if r.correct else 0.0 for r in responses])
        is_choice = responses[0].question_type in ('single_choice', 'multi_choice', 'true_false')

        b, a, c = 0.0, 1.0, (0.25 if is_choice else 0.0)
        prev_b = b + 10

        for _ in range(max_iterations):
            p = self._threepl_probability(theta, a, b, c)
            w = p * (1 - p)

            # Newton-Raphson 更新难度 b
            num_b = np.sum(a * (u - p))
            den_b = np.sum(a ** 2 * w)
            if abs(den_b) > 1e-10:
                b += 0.5 * num_b / den_b

            # Newton-Raphson 更新区分度 a
            num_a = np.sum((u - p) * (theta - b))
            den_a = np.sum(w * (theta - b) ** 2)
            if abs(den_a) > 1e-10:
                a += 0.3 * num_a / den_a
                a = max(0.2, min(3.0, a))

            # 更新猜测参数 c (仅选择题)
            if is_choice:
                low_mask = theta < b - 1
                if np.any(low_mask):
                    c = max(0.0, min(0.5, float(np.mean(u[low_mask]))))

            if abs(b - prev_b) < convergence_threshold:
                break
            prev_b = b

        # Fisher 信息量 → 标准误
        info = self._fisher_information(theta, a, b, c)
        se_b = 1.0 / np.sqrt(max(np.sum(info), 1e-10))
        se_a = np.sqrt(1.0 / max(np.sum(info * (theta - b) ** 2), 1e-10))

        return ItemParameters(
            difficulty=round(b, 4), discrimination=round(a, 4), guessing=round(c, 4),
            calibration_status='calibrated', response_count=n,
            calibration_method='statistical',
            standard_error={'difficulty_se': round(se_b, 4), 'discrimination_se': round(se_a, 4)}
        )

    @staticmethod
    def _threepl_probability(theta, a, b, c):
        exponent = np.clip(-a * (theta - b), -30, 30)
        return c + (1 - c) / (1 + np.exp(exponent))

    @staticmethod
    def _fisher_information(theta, a, b, c):
        p = np.clip(IRTCalibrator._threepl_probability(theta, a, b, c), 0.001, 0.999)
        return (a ** 2 * (p - c) ** 2) / ((1 - c) ** 2 * p * (1 - p))
```

### 3.4 Stage 4: 持续校准调度

```python
class CalibrationScheduler:
    """检测需要重新标定的题目"""

    def find_items_needing_calibration(self, db) -> list[str]:
        ids = []

        # 1. 首次标定：preliminary 且累计 ≥30 条
        rows = db.query("""
            SELECT q.id FROM questions q
            JOIN response_records r ON r.question_id = q.id
            WHERE q.calibration_status = 'preliminary'
            GROUP BY q.id HAVING COUNT(*) >= 30
        """)
        ids.extend(r['id'] for r in rows)

        # 2. 增量校准：calibrated 且上次标定后新增 ≥100 条
        rows = db.query("""
            SELECT q.id FROM questions q
            WHERE q.calibration_status = 'calibrated'
              AND (SELECT COUNT(*) FROM response_records r
                   WHERE r.question_id = q.id AND r.timestamp > q.last_calibrated_at) >= 100
        """)
        ids.extend(r['id'] for r in rows)

        # 3. 偏差检测：预期正确率与实际偏差 > 15%
        rows = db.query("""
            SELECT q.id FROM questions q
            JOIN response_records r ON r.question_id = q.id
            WHERE q.calibration_status IN ('calibrated','reviewed')
              AND r.timestamp > q.last_calibrated_at - INTERVAL 30 DAY
            GROUP BY q.id
            HAVING ABS(AVG(CASE WHEN r.correct THEN 1.0 ELSE 0.0 END) - q.expected_accuracy) > 0.15
        """)
        ids.extend(r['id'] for r in rows)

        return list(set(ids))
```

### 4.2 知识点掌握度增量更新（ELO-like）

采用类似国际象棋 ELO 评分的快速更新算法，每次答题后即时更新：

```python
class KnowledgePointAbilityUpdater:
    """知识点掌握度增量更新器"""

    # 更新系数 K - 控制每次更新的幅度
    # 数据少时大（快速收敛），数据多时小（稳定）
    def _get_k_factor(self, response_count: int) -> float:
        if response_count < 10:
            return 0.5   # 冷启动期：大幅调整
        elif response_count < 50:
            return 0.3   # 学习期：中幅调整
        else:
            return 0.15  # 稳定期：小幅微调

    def update(
        self,
        current_ability: float,
        item_difficulty: float,
        correct: bool,
        response_count: int,
        response_time_ms: int,
        used_hint: bool
    ) -> tuple[float, float]:
        """
        单次答题后更新知识点能力值
        
        Args:
            current_ability: 当前知识点能力值 θ
            item_difficulty: 题目难度 b
            correct: 是否答对
            response_count: 该知识点历史答题次数
            response_time_ms: 答题耗时
            used_hint: 是否使用了提示
        
        Returns:
            (new_ability, new_standard_error)
        """
        K = self._get_k_factor(response_count)
        
        # 3PL 期望正确率
        expected = self._probability(current_ability, item_difficulty)
        
        # 实际结果（考虑提示和答题时间的修正）
        actual = 1.0 if correct else 0.0
        
        # 修正因子：使用提示降低实际得分
        if correct and used_hint:
            hint_penalty = min(0.3, 0.1 * response_count)  # 提示越多扣越多
            actual -= hint_penalty
        
        # 修正因子：答题时间极短且正确 → 可能是猜对
        if correct and response_time_ms < 3000:  # 3秒内
            actual *= 0.7  # 降权
        
        # 修正因子：答题时间极长且错误 → 努力但不会，提升较少负向信号
        if not correct and response_time_ms > 120000:  # 超过2分钟
            actual = max(actual, -0.3)  # 限幅
        
        # ELO-like 更新
        new_ability = current_ability + K * (actual - expected)
        new_ability = max(-4.0, min(4.0, new_ability))  # 约束范围
        
        # 标准误缩小（更多数据 → 更精确）
        new_se = 1.0 / max(1.0, np.sqrt(response_count + 1))
        
        return round(new_ability, 4), round(new_se, 4)

    @staticmethod
    def _probability(theta: float, b: float, a: float = 1.0, c: float = 0.0) -> float:
        """简化的 3PL 概率（默认 a=1, c=0）"""
        exponent = max(-30, min(30, -a * (theta - b)))
        return c + (1 - c) / (1 + np.exp(exponent))
```

### 4.3 学科能力值聚合

```python
class SubjectAbilityAggregator:
    """从知识点掌握度聚合为学科能力值"""

    def aggregate(
        self,
        kp_abilities: dict[str, KnowledgePointAbility],
        knowledge_points: dict[str, KnowledgePoint],
        subject: str
    ) -> SubjectAbility:
        """
        将某学科下所有知识点掌握度聚合为学科能力值
        
        聚合策略:
        1. 按知识点权重加权平均（权重基于课标重要度和考试频率）
        2. 考虑知识点间的前置依赖关系（前置知识点掌握度影响更大）
        """
        total_weight = 0.0
        weighted_ability = 0.0
        total_responses = 0
        
        for kp_id, ability in kp_abilities.items():
            kp = knowledge_points[kp_id]
            
            # 权重 = 课标权重 × 考试频率权重 × 数据可信度
            curriculum_weight = kp.curriculum_importance  # 1-5
            exam_frequency = kp.exam_frequency            # 0-1
            data_reliability = min(1.0, ability.response_count / 30)  # 30条以上完全可信
            
            weight = curriculum_weight * (0.5 + 0.5 * exam_frequency) * data_reliability
            
            weighted_ability += weight * ability.ability
            total_weight += weight
            total_responses += ability.response_count
        
        if total_weight > 0:
            subject_ability = weighted_ability / total_weight
        else:
            subject_ability = 0.0  # 无数据时默认中间值
        
        return SubjectAbility(
            ability=round(subject_ability, 4),
            standard_error=round(1.0 / max(1.0, np.sqrt(total_responses)), 4),
            response_count=total_responses,
            last_updated_at=datetime.now()
        )
```

## 7. 自适应测试策略（CAT）

### 7.1 计算机自适应测试流程

当需要精确评估学生在某学科/知识点的能力时，采用 CAT 策略：

```
开始 CAT 测试
    │
    ▼
┌──────────────────────────┐
│ 选择初始题目              │
│ 难度 ≈ 当前估计能力值     │
└──────────────────────────┘
    │
    ▼
┌──────────────────────────┐
│ 学生作答                  │
└──────────────────────────┘
    │
    ▼
┌──────────────────────────┐
│ 更新能力估计 (EAP/MLE)   │
│ 计算测量标准误 SEM        │
└──────────────────────────┘
    │
    ▼
┌──────────┐  SEM > 阈值  ┌──────────────────────────┐
│ 继续出题  │────────────→│ 选择下一题 (最大信息量)   │
└──────────┘              └──────────────────────────┘
    │
    │ SEM ≤ 阈值 或 达到题数上限
    ▼
┌──────────────────────────┐
│ 输出最终能力估计 + 报告   │
└──────────────────────────┘
```

### 7.2 CAT 出题选择算法

```python
class CATItemSelector:
    """自适应测试 - 选题策略"""

    def select_next_item(
        self,
        current_theta: float,
        available_items: list[ItemParameters],
        administered_items: set[str],
        target_sem: float = 0.3,
        exposure_control: dict[str, float] = None
    ) -> ItemParameters | None:
        """
        选择下一道最优题目
        
        策略: 最大 Fisher 信息量原则
        在当前能力估计处提供最多信息的题目最优
        
        Args:
            current_theta: 当前能力估计
            available_items: 可用题目池
            administered_items: 已做过题目ID集合
            target_sem: 目标标准误
            exposure_control: 题目曝光率控制
        """
        candidates = [
            item for item in available_items
            if item.question_id not in administered_items
        ]
        
        if not candidates:
            return None
        
        best_item = None
        best_info = -1
        
        for item in candidates:
            # 计算该题在当前能力值处的 Fisher 信息量
            info = self._fisher_information(current_theta, item)
            
            # 曝光率惩罚（避免热门题过度使用）
            if exposure_control and item.question_id in exposure_control:
                rate = exposure_control[item.question_id]
                if rate > 0.2:  # 曝光率超过20%开始惩罚
                    info *= max(0.1, 1.0 - (rate - 0.2) * 2)
            
            # 难度偏差惩罚（避免太难或太简单）
            difficulty_gap = abs(item.difficulty - current_theta)
            if difficulty_gap > 2.0:
                info *= 0.1  # 难度差距过大严重降权
            
            if info > best_info:
                best_info = info
                best_item = item
        
        return best_item

    @staticmethod
    def _fisher_information(theta: float, item: ItemParameters) -> float:
        """3PL Fisher 信息量"""
        a, b, c = item.discrimination, item.difficulty, item.guessing
        exp_val = np.exp(np.clip(-a * (theta - b), -30, 30))
        p = c + (1 - c) / (1 + exp_val)
        p = max(0.001, min(0.999, p))
        return (a ** 2 * (p - c) ** 2) / ((1 - c) ** 2 * p * (1 - p))
```

### 7.3 能力估计更新（EAP 方法）

```python
class EAPAbilityEstimator:
    """Expected A Posteriori 能力估计"""

    # 数值积分节点
    QUADRATURE_POINTS = np.linspace(-4, 4, 41)
    # 标准正态先验
    QUADRATURE_WEIGHTS = np.exp(-QUADRATURE_POINTS**2 / 2) / np.sqrt(2 * np.pi)

    def estimate(
        self,
        responses: list[tuple[ItemParameters, bool]],  # [(题目参数, 是否正确)]
        prior_mean: float = 0.0,
        prior_sd: float = 1.0
    ) -> tuple[float, float]:
        """
        EAP 方法估计能力值
        
        Returns: (ability_estimate, standard_error)
        """
        theta = self.QUADRATURE_POINTS
        weights = self.QUADRATURE_WEIGHTS.copy()

        # 应用先验
        prior = np.exp(-((theta - prior_mean) ** 2) / (2 * prior_sd ** 2))
        weights *= prior

        # 计算后验
        posterior = weights.copy()
        for item, correct in responses:
            p = self._threepl(theta, item.discrimination, item.difficulty, item.guessing)
            if correct:
                likelihood = np.clip(p, 1e-10, 1.0)
            else:
                likelihood = np.clip(1 - p, 1e-10, 1.0)
            posterior *= likelihood

        # 归一化
        total = np.sum(posterior)
        if total < 1e-30:
            return prior_mean, prior_sd
        posterior /= total

        # EAP 估计 = 后验均值
        ability = np.sum(theta * posterior)
        # 标准误 = 后验标准差
        variance = np.sum((theta - ability) ** 2 * posterior)
        se = np.sqrt(max(variance, 0.01))

        return round(float(ability), 4), round(float(se), 4)

    @staticmethod
    def _threepl(theta, a, b, c):
        exp_val = np.exp(np.clip(-a * (theta - b), -30, 30))
        return c + (1 - c) / (1 + exp_val)
```

## 9. 错误处理与边界情况

### 9.1 异常场景处理

| 场景 | 处理策略 |
|-----|---------|
| 新用户无答题数据 | 返回默认能力值 0.0（中等水平），标准误 1.0 |
| 题目无标定数据 | 使用初始预估参数，标记为 preliminary |
| EM 算法不收敛 | 最多迭代50次，使用最后一次结果，标记低可信度 |
| 答题数据异常（全部对/全部错） | 不执行标定，等待更多多样本数据 |
| 学生短时间内大量答题 | 检测异常速度（<5秒/题），降权或忽略 |
| 知识点无答题记录 | 不纳入聚合计算，避免拉偏学科能力值 |
| IRT 概率计算溢出 | exponent 截断到 [-30, 30]，概率截断到 [0.001, 0.999] |

### 9.2 数据一致性保障

```python
class AbilityUpdateGuard:
    """能力更新的一致性守卫"""

    def safe_update(self, student_id: str, response: ResponseRecord):
        """带保护的能力更新"""
        try:
            # 1. 幂等检查：该答题记录是否已处理
            if self._is_processed(response.id):
                return

            # 2. 乐观锁：读取当前能力值（带版本号）
            kp_ability = self._load_with_version(student_id, response.knowledge_point_ids)

            # 3. 执行更新
            new_abilities = self._compute_updates(kp_ability, response)

            # 4. 乐观锁写回（版本不匹配则重试）
            max_retries = 3
            for attempt in range(max_retries):
                if self._try_commit(new_abilities):
                    break
                kp_ability = self._load_with_version(student_id, response.knowledge_point_ids)
                new_abilities = self._compute_updates(kp_ability, response)
            else:
                # 重试耗尽，记录日志，不阻塞
                logger.warning(f"能力更新冲突，student={student_id}, response={response.id}")

            # 5. 标记记录已处理
            self._mark_processed(response.id)

        except Exception as e:
            logger.error(f"能力更新失败: {e}", exc_info=True)
            # 不抛出异常，避免影响主流程
```

### 9.3 能力值异常检测

```python
class AbilityAnomalyDetector:
    """检测能力值异常变化"""

    def check_ability_drift(
        self, student_id: str, kp_id: str, old_ability: float, new_ability: float
    ) -> bool:
        """
        检查单次更新是否合理
        
        异常规则:
        1. 单次变动超过 ±2.0 → 标记异常
        2. 连续3次同方向变动且累计超过 ±1.5 → 可能系统偏差
        3. 能力值突然从正变负（或反之）且幅度 > 1.5 → 标记复核
        """
        delta = abs(new_ability - old_ability)
        
        if delta > 2.0:
            self._flag_anomaly(student_id, kp_id, 'single_large_delta', delta)
            return True
        
        # 检查近期趋势
        recent_changes = self._get_recent_changes(student_id, kp_id, limit=3)
        if len(recent_changes) >= 3:
            cumulative = sum(recent_changes)
            if abs(cumulative) > 1.5 and all(c * recent_changes[0] > 0 for c in recent_changes):
                self._flag_anomaly(student_id, kp_id, 'consistent_drift', cumulative)
                return True
        
        return False
```

### 11.3 预测准确率计算

```python
def compute_prediction_accuracy(db, date: str) -> float:
    """
    回测：用昨天的能力值预测今天的答题结果
    准确率 = 正确预测数 / 总预测数
    """
    rows = db.query("""
        SELECT
            r.correct AS actual,
            sa.ability AS student_ability,
            ic.difficulty_b AS item_difficulty
        FROM response_records r
        JOIN student_kp_ability sa ON sa.student_id = r.student_id
            AND sa.knowledge_point_id = r.knowledge_point_ids[0]
        JOIN item_calibration ic ON ic.question_id = r.question_id
        WHERE DATE(r.timestamp) = %s
          AND sa.last_updated_at < r.timestamp  -- 用答题前的能力值
    """, [date])

    correct_predictions = 0
    for row in rows:
        predicted_prob = threepl(row['student_ability'], row['item_difficulty'])
        predicted_correct = predicted_prob > 0.5
        if predicted_correct == row['actual']:
            correct_predictions += 1

    return correct_predictions / len(rows) if rows else 0.0
```
