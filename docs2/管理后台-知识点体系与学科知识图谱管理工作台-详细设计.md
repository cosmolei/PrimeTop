# 管理后台 - 知识点体系与学科知识图谱管理工作台 详细设计

## 1. 概述

### 1.1 功能定位

本工作台为 PrimeTop 平台内容运营团队提供**知识点体系的全生命周期管理能力**，覆盖知识点的创建、编辑、层级维护、关联关系管理、考点映射、难度标定、知识图谱可视化及质量校验等核心场景。

知识点体系是连接教材章节、题目、考点的核心枢纽——所有 AI 辅导、题目推荐、学情分析、学习路径规划都依赖知识点数据的准确性和完整性。本工作台确保运营团队可以高效、安全地维护这套体系。

### 1.2 适用范围

- 内容运营人员：日常知识点增删改查、考点维护
- 学科负责人：学科知识体系审核与发布
- 平台管理员：跨学科知识图谱一致性校验
- 技术运维：知识图谱数据导入导出与版本回滚

### 1.3 与其他工作台的关系

| 关联工作台 | 边界说明 |
|---|---|
| 教材版本与课程章节内容管理工作台 | 管理教材→章节→课时的目录结构；本工作台管理章节关联的知识点 |
| 题库内容管理与生产运维工作台 | 管理题目 CRUD；题目上的知识点标签由本工作台维护的体系决定 |
| AI模型与Prompt模板配置工作台 | Prompt 编排中引用的知识点上下文来自本体系 |
| 学情数据分析与教育运营驾驶舱 | 学情分析中的知识点掌握度依赖本体系的数据结构 |

## 3. 数据结构定义

### 3.1 知识点表 `edu_knowledge_point`

```sql
CREATE TABLE edu_knowledge_point (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '知识点ID',
    code            VARCHAR(64) NOT NULL UNIQUE COMMENT '知识点编码，如 MATH-HS-FN-EXP-001',
    name            VARCHAR(128) NOT NULL COMMENT '知识点名称',
    short_name      VARCHAR(64) COMMENT '简称',
    description     TEXT COMMENT '知识点详细描述',
    subject_code    VARCHAR(16) NOT NULL COMMENT '学科编码 MATH/CHN/ENG/PHY/CHE/BIO/HIS/GEO/POL',
    stage           VARCHAR(8) NOT NULL COMMENT '学段 PRI(小学)/JUN(初中)/SEN(高中)/KIN(幼儿)',
    parent_id       BIGINT COMMENT '父知识点ID，NULL表示根节点',
    level           TINYINT NOT NULL DEFAULT 1 COMMENT '层级深度 1-6',
    sort_order      INT NOT NULL DEFAULT 0 COMMENT '同级排序',
    status          VARCHAR(16) NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT/PENDING_REVIEW/PUBLISHED/ARCHIVED',
    
    -- 认知维度
    bloom_level     VARCHAR(16) COMMENT '布鲁姆认知层级 REMEMBER/UNDERSTAND/APPLY/ANALYZE/EVALUATE/CREATE',
    difficulty      DECIMAL(3,2) DEFAULT 0.50 COMMENT '基础难度系数 0.00-1.00',
    
    -- 标签
    tags            JSON COMMENT '标签数组，如["高考必考","易错点"]',
    keywords        JSON COMMENT '关键词数组，用于搜索',
    
    -- 版本控制
    version         INT NOT NULL DEFAULT 1 COMMENT '版本号',
    published_at    DATETIME COMMENT '发布时间',
    created_by      BIGINT NOT NULL COMMENT '创建人',
    updated_by      BIGINT NOT NULL COMMENT '最后修改人',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_subject_stage (subject_code, stage),
    INDEX idx_parent (parent_id),
    INDEX idx_status (status),
    INDEX idx_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识点表';
```

### 3.2 知识点关联关系表 `edu_knowledge_relation`

```sql
CREATE TABLE edu_knowledge_relation (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    source_kp_id        BIGINT NOT NULL COMMENT '源知识点ID',
    target_kp_id        BIGINT NOT NULL COMMENT '目标知识点ID',
    relation_type       VARCHAR(32) NOT NULL COMMENT '关系类型',
    weight              DECIMAL(3,2) DEFAULT 1.00 COMMENT '关联强度 0-1',
    description         VARCHAR(256) COMMENT '关系说明',
    created_by          BIGINT NOT NULL,
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_relation (source_kp_id, target_kp_id, relation_type),
    INDEX idx_source (source_kp_id),
    INDEX idx_target (target_kp_id),
    
    FOREIGN KEY (source_kp_id) REFERENCES edu_knowledge_point(id) ON DELETE CASCADE,
    FOREIGN KEY (target_kp_id) REFERENCES edu_knowledge_point(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识点关联关系表';
```

**关系类型枚举：**

| relation_type | 含义 | 说明 |
|---|---|---|
| `PREREQUISITE` | 前置依赖 | 学 B 之前必须先学 A |
| `RELATED` | 相关关联 | A 和 B 有知识上的联系但不构成依赖 |
| `SUBSUMES` | 包含 | A 知识点包含 B（父子关系的关系化表达） |
| `SIMILAR` | 相似/易混淆 | A 和 B 容易混淆，需要对比学习 |
| `DERIVED` | 推导 | A 可推导出 B |
| `CROSS_SUBJECT` | 跨学科 | A 与另一学科的某个知识点有联系 |

## 4. API 接口设计

### 4.1 知识点 CRUD

#### 4.1.1 创建知识点

```
POST /api/admin/knowledge-points
```

**请求体：**
```json
{
    "name": "指数函数的定义",
    "shortName": "指数函数定义",
    "description": "形如 y = a^x (a > 0 且 a ≠ 1) 的函数称为指数函数...",
    "subjectCode": "MATH",
    "stage": "SEN",
    "parentId": 1024,
    "bloomLevel": "UNDERSTAND",
    "difficulty": 0.35,
    "tags": ["高考必考", "基础概念"],
    "keywords": ["指数函数", "底数", "指数"]
}
```

**响应：**
```json
{
    "code": 0,
    "data": {
        "id": 2048,
        "code": "MATH-SEN-FN-EXP-001",
        "name": "指数函数的定义",
        "status": "DRAFT",
        "level": 4,
        "sortOrder": 1,
        "createdAt": "2026-07-23T06:20:00Z"
    }
}
```

**校验规则：**

| 字段 | 规则 |
|---|---|
| name | 必填，1-128字符，同一 parent_id 下唯一 |
| subjectCode | 必填，必须在枚举范围内 |
| stage | 必填，必须在枚举范围内 |
| parentId | 可空；提供时必须存在且 subject+stage 一致 |
| difficulty | 0.00-1.00，保留两位小数 |
| bloomLevel | 可空，必须在枚举范围内 |
| level | 自动计算：根节点=1，子节点=父节点+1，最大6 |
| code | 自动生成：`{学科}-{学段}-{学科路径缩写}-{序号}` |

#### 4.1.2 查询知识点树

```
GET /api/admin/knowledge-points/tree?subjectCode=MATH&stage=SEN&parentId=0&loadChildren=true
```

**参数：**

| 参数 | 类型 | 说明 |
|---|---|---|
| subjectCode | string | 学科编码 |
| stage | string | 学段 |
| parentId | long | 父节点ID，0表示从根开始 |
| loadChildren | boolean | 是否递归加载子节点（默认true，最多3层） |
| status | string | 状态过滤，逗号分隔 |
| keyword | string | 名称/关键词搜索 |

**响应：**
```json
{
    "code": 0,
    "data": [
        {
            "id": 100,
            "code": "MATH-SEN-FN",
            "name": "函数",
            "level": 1,
            "status": "PUBLISHED",
            "childrenCount": 12,
            "children": [
                {
                    "id": 101,
                    "code": "MATH-SEN-FN-EXP",
                    "name": "指数函数",
                    "level": 2,
                    "status": "PUBLISHED",
                    "childrenCount": 5,
                    "children": null
                }
            ]
        }
    ],
    "pagination": {
        "total": 48
    }
}
```

#### 4.1.3 更新知识点

```
PUT /api/admin/knowledge-points/{id}
```

**请求体（支持部分更新）：**
```json
{
    "name": "指数函数的概念与定义",
    "description": "更新后的描述...",
    "difficulty": 0.40,
    "tags": ["高考必考", "基础概念", "函数基础"],
    "status": "PENDING_REVIEW"
}
```

**关键逻辑：**
- 状态为 `PUBLISHED` 的知识点不能直接修改，需先创建 `DRAFT` 副本
- 修改后自动创建版本快照
- 如果修改了 `parentId`，需检查循环引用

#### 4.1.4 删除知识点

```
DELETE /api/admin/knowledge-points/{id}?cascade=false
```

**参数：**

| 参数 | 说明 |
|---|---|
| cascade | false（默认）：存在子节点/题目关联时拒绝删除；true：级联归档子节点并解除关联 |

**响应（删除失败）：**
```json
{
    "code": 40901,
    "message": "无法删除：知识点下存在 12 个子知识点和 48 道关联题目",
    "data": {
        "childrenCount": 12,
        "linkedQuestions": 48,
        "linkedChapters": 5,
        "suggestion": "请先将子知识点迁移到其他父节点，或使用 cascade=true 级联归档"
    }
}
```

#### 4.1.5 拖拽排序

```
POST /api/admin/knowledge-points/{id}/sort
```

```json
{
    "newParentId": 1024,
    "newSortOrder": 3
}
```

### 4.2 知识点关联关系管理

#### 4.2.1 添加关联关系

```
POST /api/admin/knowledge-points/{id}/relations
```

```json
{
    "targetKpId": 2050,
    "relationType": "PREREQUISITE",
    "weight": 0.9,
    "description": "掌握指数运算是指数函数学习的前提"
}
```

**校验规则：**
- 不能创建自引用关系（source = target）
- `PREREQUISITE` 类型不能形成环（需做 DAG 检测）
- 同一对知识点 + 同一关系类型不能重复

#### 4.2.2 批量设置前置依赖

```
POST /api/admin/knowledge-points/{id}/prerequisites/batch
```

```json
{
    "prerequisiteIds": [101, 102, 103],
    "mode": "REPLACE"
}
```

**mode 选项：** `ADD`（追加）、`REPLACE`（替换）、`REMOVE`（移除）

#### 4.2.3 环检测接口

```
POST /api/admin/knowledge-points/check-cycle
```

```json
{
    "sourceId": 2050,
    "targetId": 2048,
    "relationType": "PREREQUISITE"
}
```

**响应（存在环）：**
```json
{
    "code": 0,
    "data": {
        "hasCycle": true,
        "cyclePath": [2050, 2049, 2048, 2050],
        "cyclePathNames": ["对数运算", "对数函数", "指数函数", "对数运算"]
    }
}
```

#### 4.2.4 查询关联关系图

```
GET /api/admin/knowledge-points/{id}/relations?depth=2&direction=BOTH
```

**参数：**

| 参数 | 说明 |
|---|---|
| depth | 遍历深度，默认2，最大5 |
| direction | OUT（仅下游）、IN（仅上游）、BOTH（双向） |
| relationTypes | 过滤关系类型，逗号分隔 |

**响应：**
```json
{
    "code": 0,
    "data": {
        "nodes": [
            {"id": 2048, "name": "指数函数的定义", "level": 4},
            {"id": 2050, "name": "指数函数的图像", "level": 4},
            {"id": 1001, "name": "指数运算", "level": 3}
        ],
        "edges": [
            {"source": 1001, "target": 2048, "type": "PREREQUISITE", "weight": 0.9},
            {"source": 2048, "target": 2050, "type": "PREREQUISITE", "weight": 0.8}
        ]
    }
}
```

采用 **AntV G6** 作为图谱可视化引擎：

```typescript
// 图谱初始化核心代码示例
import G6, { Graph, IG6GraphEvent } from '@antv/g6';

interface KnowledgeNode {
    id: string;
    label: string;
    kpId: number;
    level: number;
    status: string;
    difficulty: number;
    childrenCount: number;
}

interface KnowledgeEdge {
    source: string;
    target: string;
    relationType: string;
    weight: number;
}

class KnowledgeGraphRenderer {
    private graph: Graph;
    private container: HTMLElement;

    constructor(container: HTMLElement) {
        this.container = container;
        this.graph = new G6.Graph({
            container,
            width: container.scrollWidth,
            height: container.scrollHeight,
            modes: {
                default: [
                    'drag-canvas',
                    'zoom-canvas',
                    'drag-node',
                    {
                        type: 'tooltip',
                        formatModel(model: KnowledgeNode) {
                            return `
                                <div class="kp-tooltip">
                                    <strong>${model.label}</strong><br/>
                                    层级: L${model.level}<br/>
                                    难度: ${model.difficulty}<br/>
                                    状态: ${model.status}<br/>
                                    子节点: ${model.childrenCount}
                                </div>
                            `;
                        },
                    },
                ],
            },
            layout: {
                type: 'force',
                preventOverlap: true,
                nodeStrength: -50,
                edgeStrength: 0.7,
                collideStrength: 0.8,
                nodeSize: 40,
                linkDistance: (edge: KnowledgeEdge) => {
                    // 前置依赖关系用短边，相关关系用长边
                    return edge.relationType === 'PREREQUISITE' ? 100 : 200;
                },
            },
            defaultNode: {
                type: 'circle',
                size: (model: KnowledgeNode) => 30 - model.level * 3, // 层级越高节点越小
                style: {
                    fill: (model: KnowledgeNode) => this.getStatusColor(model.status),
                    stroke: '#666',
                    lineWidth: 1,
                },
                labelCfg: {
                    position: 'bottom',
                    offset: 5,
                    style: { fontSize: 11 },
                },
            },
            defaultEdge: {
                type: 'line',
                style: {
                    stroke: (model: KnowledgeEdge) => this.getRelationColor(model.relationType),
                    lineWidth: (model: KnowledgeEdge) => model.weight * 3,
                    endArrow: (model: KnowledgeEdge) => 
                        model.relationType === 'PREREQUISITE' || model.relationType === 'DERIVED',
                },
            },
        });

        this.bindEvents();
    }

    private getStatusColor(status: string): string {
        const colorMap: Record<string, string> = {
            PUBLISHED: '#52c41a',
            DRAFT: '#faad14',
            PENDING_REVIEW: '#1890ff',
            ARCHIVED: '#d9d9d9',
        };
        return colorMap[status] || '#d9d9d9';
    }

    private getRelationColor(relationType: string): string {
        const colorMap: Record<string, string> = {
            PREREQUISITE: '#1890ff',
            RELATED: '#8c8c8c',
            SIMILAR: '#fa8c16',
            DERIVED: '#722ed1',
            CROSS_SUBJECT: '#13c2c2',
        };
        return colorMap[relationType] || '#8c8c8c';
    }

    private bindEvents(): void {
        // 双击节点展开/折叠子节点
        this.graph.on('node:dblclick', (e: IG6GraphEvent) => {
            const node = e.item;
            const model = node?.getModel() as KnowledgeNode;
            this.toggleExpand(model.kpId);
        });

        // 右键菜单
        this.graph.on('node:contextmenu', (e: IG6GraphEvent) => {
            const model = e.item?.getModel() as KnowledgeNode;
            this.showContextMenu(e.clientX, e.clientY, model);
        });

        // 点击节点更新右侧详情
        this.graph.on('node:click', (e: IG6GraphEvent) => {
            const model = e.item?.getModel() as KnowledgeNode;
            this.loadDetail(model.kpId);
        });
    }

    async loadData(subjectCode: string, stage: string): Promise<void> {
        const res = await fetch(
            `/api/admin/knowledge-graph?subjectCode=${subjectCode}&stage=${stage}&layout=FORCE`
        );
        const { data } = await res.json();

        const nodes = data.nodes.map((n: any) => ({
            id: `kp-${n.id}`,
            kpId: n.id,
            label: n.name,
            level: n.level,
            status: n.status,
            difficulty: n.difficulty,
            childrenCount: n.childrenCount ?? 0,
        }));

        const edges = data.edges.map((e: any) => ({
            source: `kp-${e.source}`,
            target: `kp-${e.target}`,
            relationType: e.type,
            weight: e.weight,
        }));

        this.graph.data({ nodes, edges });
        this.graph.render();
    }

    private async toggleExpand(kpId: number): Promise<void> {

    }

    private showContextMenu(x: number, y: number, model: KnowledgeNode): void {
        // 显示右键菜单：编辑、添加子节点、添加关联、删除...
    }

    }
}
```

## 6. 状态机设计

### 6.1 知识点状态流转

```
                   ┌──────────┐
                   │  DRAFT   │ ←──── 新建 / 驳回回退 / 回滚
                   └────┬─────┘
                        │ submit-review
                        ▼
                   ┌──────────┐
                   │PENDING_  │
                   │REVIEW    │
                   └────┬─────┘
                    ┌───┴───┐
              approve│       │reject
                    ▼       ▼
              ┌──────────┐  ┌──────────┐
              │PUBLISHED │  │  DRAFT   │
              └────┬─────┘  └──────────┘
                   │ archive
                   ▼
              ┌──────────┐
              │ ARCHIVED │
              └──────────┘
```

### 6.2 状态变更规则

| 当前状态 | 允许操作 | 目标状态 | 权限要求 |
|---|---|---|---|
| DRAFT | 编辑、删除、提交审核 | PENDING_REVIEW / 删除 | 内容编辑 |
| PENDING_REVIEW | 通过、驳回 | PUBLISHED / DRAFT | 学科负责人 |
| PUBLISHED | 编辑（创建副本）、归档 | DRAFT（副本）/ ARCHIVED | 学科负责人 |
| ARCHIVED | 恢复 | DRAFT | 平台管理员 |

### 6.3 批量操作状态规则

- 批量提交审核：将多个 DRAFT 知识点同时提交
- 批量审核通过：仅当知识点间无依赖冲突时允许
- 批量归档：级联归档所有子节点

```java
// 数据权限拦截器示例
@Intercepts({
    @Signature(type = KnowledgePointMapper.class, method = "selectById", args = {Long.class})
})
public class KnowledgeDataScopeInterceptor implements Interceptor {
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        Long currentUserId = SecurityUtils.getCurrentUserId();
        List<String> userSubjects = SecurityUtils.getCurrentUserSubjects();
        String userRole = SecurityUtils.getCurrentUserRole();
        
        // 平台管理员不做数据范围限制
        if ("PLATFORM_ADMIN".equals(userRole)) {
            return invocation.proceed();
        }
        
        // 学科负责人只能操作自己负责的学科
        KnowledgePoint kp = (KnowledgePoint) invocation.proceed();
        if (kp != null && !userSubjects.contains(kp.getSubjectCode())) {
            throw new ForbiddenException("无权操作学科 " + kp.getSubjectCode() + " 的知识点");
        }
        
        return kp;
    }
}
```

```typescript
            );
            const { data } = await res.json();
            setTreeData(convertToTreeNodes(data));
        } catch (err) {
            message.error('加载知识点树失败');
        } finally {
            setLoading(false);
        }
    }, [subjectCode, stage]);

    useEffect(() => {
        loadTree();
    }, [loadTree]);

    // 后端数据 → antd Tree 数据
    const convertToTreeNodes = (nodes: KnowledgePointNode[]): DataNode[] => {
        return nodes.map((node) => ({
            key: node.id,
            title: (
                <Space size={4}>
                    {node.level <= 2 ? <FolderOutlined /> : <FileOutlined />}
                    <span>{node.name}</span>
                    {node.status !== 'PUBLISHED' && (
                        <Tag {...STATUS_TAG_CONFIG[node.status]}>
                            {STATUS_TAG_CONFIG[node.status].text}
                        </Tag>
                    )}
                    {node.childrenCount > 0 && (
                        <span style={{ color: '#999', fontSize: 12 }}>
                            ({node.childrenCount})
                        </span>
                    )}
                </Space>
            ),
            children: node.children?.length
                ? convertToTreeNodes(node.children)
                : undefined,
            isLeaf: node.childrenCount === 0,
        }));
    };

    // 右键菜单
    const contextMenu = (node: any): Menu => (
        <Menu

                {
                    key: 'add-child',

                    label: '添加考点',
                    onClick: () => handleAddExamPoint(node.key),
                },
            ]}
        />
    );

    // 异步加载子节点
    const onLoadData = async (node: any): Promise<void> => {
        const kpId = node.key;
        const res = await fetch(
            `/api/admin/knowledge-points/tree?parentId=${kpId}&loadChildren=true`
        );
        const { data } = await res.json();
        const children = convertToTreeNodes(data);

        setTreeData((prev) => updateTreeNode(prev, kpId, children));
    };

    // 递归更新树节点
    const updateTreeNode = (
        nodes: DataNode[],
        targetKey: React.Key,
        children: DataNode[]
    ): DataNode[] => {
        return nodes.map((node) => {
            if (node.key === targetKey) {
                return { ...node, children };
            }
            if (node.children) {
                return { ...node, children: updateTreeNode(node.children, targetKey, children) };
            }
            return node;
        });
    };

    // 拖拽移动
    const onDrop = async (info: any) => {
        const dragKpId = info.dragNode.key;
        const dropKpId = info.node.key;
        const dropPosition = info.dropPosition;

        try {
            await fetch(`/api/admin/knowledge-points/${dragKpId}/sort`, {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({
                    newParentId: dropPosition === -1 ? 0 : dropKpId,
                    newSortOrder: dropPosition,
                }),
            });
            message.success('移动成功');
            loadTree();
        } catch (err) {
            message.error('移动失败');
        }
    };

    // 操作处理
    const handleAddChild = (parentId: any) => { /* 打开新增弹窗 */ };

                );
                const result = await res.json();
                if (result.code === 0) {
                    message.success('删除成功');
                    loadTree();
                } else if (result.code === 40901) {
                    message.warning(result.data.suggestion);
                }
            },
        });
    };
    const handleAddRelation = (kpId: any) => { /* 打开关联弹窗 */ };
    const handleAddExamPoint = (kpId: any) => { /* 打开考点弹窗 */ };

    return (
```

### 11.1 错误码定义

| 错误码 | HTTP状态 | 说明 | 处理建议 |
|---|---|---|---|
| 40001 | 400 | 参数校验失败 | 前端检查输入 |
| 40002 | 400 | 知识点名称在同一父节点下重复 | 修改名称 |
| 40003 | 400 | 学科与学段不匹配（如幼儿阶段选择物理） | 检查学科学段组合 |
| 40004 | 400 | 层级超过最大深度(6) | 调整知识点层级结构 |
| 40401 | 404 | 知识点不存在 | 检查ID或刷新数据 |
| 40901 | 409 | 删除时存在子节点或关联数据 | 先迁移子节点或使用级联删除 |
| 40902 | 409 | 前置依赖关系形成环 | 移除导致环的依赖 |
| 40903 | 409 | 状态不允许此操作（如直接修改已发布知识点） | 创建编辑副本 |
| 40301 | 403 | 无权操作该学科的知识点 | 联系管理员授权 |
| 40302 | 403 | 无审核权限 | 联系学科负责人审核 |

| 50001 | 500 | 服务器内部错误 | 查看服务日志 |

```sql
-- 知识点树查询优化：使用递归CTE (MySQL 8.0+)
WITH RECURSIVE kp_tree AS (
    -- 基础查询：从指定根节点开始
    SELECT kp.*, 1 AS depth
    FROM edu_knowledge_point kp
    WHERE kp.subject_code = 'MATH' AND kp.stage = 'SEN' AND kp.parent_id IS NULL
    
    UNION ALL
    
    -- 递归查询：加载子节点
    SELECT child.*, parent.depth + 1
    FROM edu_knowledge_point child
    INNER JOIN kp_tree parent ON child.parent_id = parent.id
    WHERE parent.depth < 5  -- 限制递归深度
)
SELECT * FROM kp_tree ORDER BY depth, sort_order;

-- 关联关系环检测：使用递归CTE
WITH RECURSIVE relation_chain AS (
    SELECT source_kp_id, target_kp_id, CAST(CONCAT(source_kp_id, '->', target_kp_id) AS CHAR(1000)) AS path
    FROM edu_knowledge_relation
    WHERE relation_type = 'PREREQUISITE' AND source_kp_id = ?
    
    UNION ALL
    
    SELECT r.source_kp_id, r.target_kp_id, CONCAT(rc.path, '->', r.target_kp_id)
    FROM edu_knowledge_relation r
    INNER JOIN relation_chain rc ON r.source_kp_id = rc.target_kp_id
    WHERE r.relation_type = 'PREREQUISITE'
      AND rc.path NOT LIKE CONCAT('%->', r.target_kp_id, '%')  -- 避免无限循环
)
SELECT * FROM relation_chain WHERE target_kp_id = ?;
-- 如果有结果，说明存在路径
```

```java
@Transactional(rollbackFor = Exception.class)
public ImportResult batchImport(MultipartFile file, String subjectCode, String stage) {
    List<KnowledgePoint> batch = new ArrayList<>(100);
    ImportResult result = new ImportResult();
    
    try (Reader reader = new InputStreamReader(file.getInputStream(), StandardCharsets.UTF_8);
         CSVParser parser = CSVFormat.DEFAULT.withFirstRecordAsHeader().parse(reader)) {
        
        for (CSVRecord record : parser) {
            try {
                KnowledgePoint kp = parseRecord(record, subjectCode, stage);
                batch.add(kp);
                
                if (batch.size() >= 100) {
                    kpMapper.batchInsert(batch);
                    batch.clear();
                }
                
                result.incrementSuccess();
            } catch (Exception e) {
                result.addError(record.getRecordNumber(), record.get("知识点名称"), e.getMessage());
            }
        }
        
        if (!batch.isEmpty()) {
            kpMapper.batchInsert(batch);
        }
        
        // 批量建立前置依赖关系
        batchProcessPrerequisites(result.getSuccessIds());
        
    } catch (IOException e) {
        throw new BusinessException(42201, "文件解析失败: " + e.getMessage());
    }
    
    return result;
}
```

## 15. 总结

本工作台为 PrimeTop 平台的知识点体系提供完整的管理入口，核心设计要点：

1. **树形结构 + 图关系**：知识点既有层级树（父子关系），又有网状关联（前置依赖、相似关联等），两者独立管理但统一展示
2. **审核流程保障质量**：DRAFT → PENDING_REVIEW → PUBLISHED 的三段式审核，防止未审核内容影响线上推荐和学情分析
3. **版本快照 + 回滚**：每次修改自动快照，支持任意版本对比和回滚，保障数据安全
4. **环检测机制**：前置依赖关系变更时自动进行 DAG 环检测，防止知识图谱中形成循环依赖
5. **批量操作 + 质量校验**：支持 Excel 批量导入提升效率，配套质量校验工具发现孤立知识点、缺失依赖等问题
6. **知识图谱可视化**：提供力导向布局的图谱视图，直观展示知识点间的关联拓扑
7. **编码规范统一**：`学科-学段-分类-序号` 的编码体系，确保知识点编码的全局唯一性和可读性
