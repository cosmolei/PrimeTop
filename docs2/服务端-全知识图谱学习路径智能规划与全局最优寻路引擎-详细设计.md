# 服务端 - 全知识图谱学习路径智能规划与全局最优寻路引擎

## 1. 模块概述

### 1.1 功能定位

本引擎是 PrimeTop 学习路径规划的"中枢大脑"。区别于"知识点前置依赖检测服务"（被动诊断某个知识缺口的前置链路）和"自适应推荐引擎"（局部推荐下一题/下一节），本引擎站在**全局视角**，以学生的完整知识掌握状态为起点、以学习目标为终点，在完整知识图谱 DAG 上计算一条**全局最优学习路径**。

核心解决的问题：

> 给定一个学生的当前能力状态和一段时间内的学习目标（如期中考试覆盖 50 个知识点、剩余 4 周），如何在知识图谱的拓扑约束下，找到一条**最大化预期掌握度、最小化总学习时间、兼顾认知负荷与学习兴趣**的最优学习序列？

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 全局路径规划 | 在知识图谱 DAG 上计算从当前状态到目标状态的最优学习序列 |
| 多目标优化 | 同时优化掌握度、学习时间、认知负荷、兴趣匹配四个维度 |
| 关键路径分析 | 识别阻碍目标达成的"瓶颈知识点"（最长依赖链上的节点） |
| 路径动态重计算 | 随着学习行为数据实时更新，自动触发路径调整 |
| 多粒度路径输出 | 支持输出知识点级、章节级、天级三种粒度的路径 |
| 冲突消解 | 当多个学科路径冲突时，进行跨学科时间分配仲裁 |
| What-If 模拟 | 给定不同学习时长/强度，模拟预期达成度 |

## 3. 核心算法设计

### 3.1 算法总体架构

```text
输入: KnowledgeDAG + MasterySnapshot + LearningGoal
  │
  ├─ Step 1: 图预处理 ── 子图提取、环检测、连通性校验
  │
  ├─ Step 2: 拓扑排序 ── 多种合法排序（拓扑序 + 难度递增 + 考频加权）
  │
  ├─ Step 3: 关键路径分析 ── 识别最长依赖链、瓶颈节点
  │
  ├─ Step 4: MDP 建模与求解 ── 将路径选择建模为马尔可夫决策过程
  │      ├─ 状态: (当前节点, 已掌握集合, 剩余时间)
  │      ├─ 动作: 选择下一个学习的知识点
  │      ├─ 转移: 学完后掌握(概率p) / 未掌握(概率1-p)
  │      └─ 奖励: 掌握度增量 × 考频权重 - 时间成本 - 认知负荷惩罚
  │
  ├─ Step 5: 约束求解 ── 时间约束、每日负荷约束、多学科平衡约束
  │
  ├─ Step 6: Pareto 多目标优化 ── 掌握度 vs 时间 vs 兴趣的 Pareto 前沿
  │
  └─ Step 7: 路径输出 ── 有序知识点序列 + 分阶段标注 + 预估指标
```

### 3.2 图预处理算法

```java
public class PathGraphPreprocessor {

    private final KnowledgeDAG fullDag;
    private final Set<String> targetNodeIds;

    /**
     * 从完整知识图谱中提取与目标相关的子图。
     * 包含：目标知识点 + 它们的所有（递归）前置知识点。
     */
    public KnowledgeDAG extractRelevantSubgraph() {
        // 1. 从目标节点出发，逆向 BFS 收集所有递归前置节点
        Set<String> relevantNodes = new HashSet<>();
        Deque<String> queue = new ArrayDeque<>(targetNodeIds);
        while (!queue.isEmpty()) {
            String nodeId = queue.poll();
            if (relevantNodes.contains(nodeId)) continue;
            relevantNodes.add(nodeId);
            // 获取该节点的所有前置节点
            List<String> prereqs = fullDag.getReverseAdjList().getOrDefault(nodeId, List.of());
            queue.addAll(prereqs);
        }

        // 2. 过滤已掌握的前置节点（mastery >= 0.85 且 confidence >= 0.8）
        relevantNodes.removeIf(nodeId -> {
            MasteryState ms = masterySnapshot.get(nodeId);
            return ms != null
                && ms.masteryLevel() >= MASTERY_THRESHOLD
                && ms.confidence() >= CONFIDENCE_THRESHOLD;
        });

        // 3. 构建子图的边集
        List<KnowledgeEdge> subEdges = fullDag.getEdges().stream()
            .filter(e -> relevantNodes.contains(e.fromNodeId())
                      && relevantNodes.contains(e.toNodeId()))
            .collect(Collectors.toList());

        // 4. 环检测（教学知识图谱理论上不应有环，但需防御）
        if (hasCycle(relevantNodes, subEdges)) {
            throw new CycleDetectedException("知识子图存在环路，请检查知识点依赖数据");
        }

        return buildSubDag(relevantNodes, subEdges);
    }

    /**
     * Kahn 算法检测环
     */
    private boolean hasCycle(Set<String> nodes, List<KnowledgeEdge> edges) {
        Map<String, Integer> inDegree = new HashMap<>();
        nodes.forEach(n -> inDegree.put(n, 0));
        edges.forEach(e -> inDegree.merge(e.toNodeId(), 1, Integer::sum));

        Deque<String> zeroInDegree = nodes.stream()
            .filter(n -> inDegree.get(n) == 0)
            .collect(Collectors.toCollection(ArrayDeque::new));

        int processedCount = 0;
        while (!zeroInDegree.isEmpty()) {
            String node = zeroInDegree.poll();
            processedCount++;
            for (String successor : fullDag.getAdjacencyList().getOrDefault(node, List.of())) {
                if (!nodes.contains(successor)) continue;
                int newDegree = inDegree.merge(successor, -1, Integer::sum);
                if (newDegree == 0) zeroInDegree.add(successor);
            }
        }
        return processedCount != nodes.size();
    }
}
```

### 3.3 拓扑排序与多策略排序

对于 DAG，合法的拓扑序不唯一。本引擎生成多种排序策略，供 MDP 求解器作为候选动作空间。

```java
public class TopologicalSorter {

    /**
     * 策略1：经典拓扑排序（Kahn算法），保证前置先于后继
     */
    public List<String> canonicalTopoSort(KnowledgeDAG dag) {
        Map<String, Integer> inDegree = computeInDegree(dag);
        // 使用优先队列：同层级节点按难度升序排列（先易后难）
        PriorityQueue<String> pq = new PriorityQueue<>(
            Comparator.comparingDouble(n -> dag.getNode(n).difficulty())
        );
        dag.getAllZeroInDegreeNodes().forEach(pq::offer);

        List<String> result = new ArrayList<>();
        while (!pq.isEmpty()) {
            String node = pq.poll();
            result.add(node);
            for (String succ : dag.getSuccessors(node)) {
                if (inDegree.merge(succ, -1, Integer::sum) == 0) {
                    pq.offer(succ);
                }
            }
        }
        return result;
    }

    /**
     * 策略2：考频加权排序 — 高频考点优先
     * 在拓扑约束内，尽可能把高频考点排在前面。
     */
    public List<String> examFrequencyWeightedSort(KnowledgeDAG dag) {
        Map<String, Integer> inDegree = computeInDegree(dag);
        // 优先队列：按 importanceWeight 降序
        PriorityQueue<String> pq = new PriorityQueue<>(
            Comparator.comparingDouble(
                (String n) -> dag.getNode(n).importanceWeight()
            ).reversed()
        );
        dag.getAllZeroInDegreeNodes().forEach(pq::offer);

        List<String> result = new ArrayList<>();
        while (!pq.isEmpty()) {
            String node = pq.poll();
            result.add(node);
            for (String succ : dag.getSuccessors(node)) {
                if (inDegree.merge(succ, -1, Integer::sum) == 0) {
                    pq.offer(succ);
                }
            }
        }
        return result;
    }

    /**
     * 策略3：薄弱优先排序 — 掌握度最低的知识点优先
     * 适用于"薄弱点突破"场景。
     */
    public List<String> weaknessFirstSort(KnowledgeDAG dag, MasterySnapshot snapshot) {
        Map<String, Integer> inDegree = computeInDegree(dag);
        // 优先队列：按掌握度升序（掌握度低的先学）
        PriorityQueue<String> pq = new PriorityQueue<>(
            Comparator.comparingDouble(n -> {
                MasteryState ms = snapshot.get(n);
                return ms != null ? ms.masteryLevel() : 0.0;
            })
        );
        dag.getAllZeroInDegreeNodes().forEach(pq::offer);

        List<String> result = new ArrayList<>();
        while (!pq.isEmpty()) {
            String node = pq.poll();
            result.add(node);
            for (String succ : dag.getSuccessors(node)) {
                if (inDegree.merge(succ, -1, Integer::sum) == 0) {
                    pq.offer(succ);
                }
            }
        }
        return result;
    }
}
```

### 3.4 关键路径分析

在知识 DAG 中，**关键路径**是从起点（无前置节点）到目标节点的最长依赖链。关键路径上的知识点如果延误，整个学习目标就无法按期完成。

```java
public class CriticalPathAnalyzer {

    /**
     * 在子图上计算关键路径。
     * 使用动态规划求最长路径（DAG最长路径问题）。
     *
     * @return CriticalPathResult 包含关键路径节点序列和总时长
     */
    public CriticalPathResult analyze(KnowledgeDAG subDag, Set<String> targetNodes) {
        // 1. 拓扑排序
        List<String> topoOrder = topologicalSort(subDag);

        // 2. 初始化距离表：所有节点到虚拟汇点的距离
        // dist[v] = 从v到任意目标节点的最长路径长度
        Map<String, Double> dist = new HashMap<>();
        Map<String, String> next = new HashMap<>();  // 用于回溯路径

        for (String node : topoOrder) {
            dist.put(node, 0.0);
        }

        // 3. 逆向处理：从拓扑序末尾向前
        Collections.reverse(topoOrder);
        for (String node : topoOrder) {
            if (targetNodes.contains(node)) {
                dist.put(node, Math.max(dist.get(node),
                    subDag.getNode(node).estimatedMinutes()));
            }
            for (String successor : subDag.getSuccessors(node)) {
                double pathLen = subDag.getNode(node).estimatedMinutes() + dist.get(successor);
                if (pathLen > dist.get(node)) {
                    dist.put(node, pathLen);
                    next.put(node, successor);
                }
            }
        }

        // 4. 找到最长路径起点
        String startNode = dist.entrySet().stream()
            .filter(e -> subDag.getPredecessors(e.getKey()).isEmpty())  // 入度为0的节点
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElseThrow();

        // 5. 回溯关键路径
        List<String> criticalPath = new ArrayList<>();
        String current = startNode;
        while (current != null) {
            criticalPath.add(current);
            current = next.get(current);
        }

        // 6. 识别瓶颈节点：关键路径上预估时间最长的 top-3 节点
        List<String> bottlenecks = criticalPath.stream()
            .sorted(Comparator.comparingDouble(
                (String n) -> subDag.getNode(n).estimatedMinutes()
            ).reversed())
            .limit(3)
            .collect(Collectors.toList());

        return new CriticalPathResult(
            criticalPath,
            dist.get(startNode),    // 关键路径总时长
            bottlenecks
        );
    }
}
```

### 3.5 MDP 路径优化器（核心）

将学习路径选择建模为**有限范围马尔可夫决策过程 (Finite-Horizon MDP)**。

#### 3.5.1 MDP 形式化定义

```
状态空间 S:
  s = (learned_set, remaining_budget, current_node)
  - learned_set: 已掌握的知识点集合
  - remaining_budget: 剩余可用学习时间（分钟）
  - current_node: 当前正在学习的知识点

动作空间 A:
  a ∈ {可学的知识点集合}
  - 条件: 该知识点的前置全部已掌握（硬约束），或前置依赖强度低（软约束）
  - 考虑: 不学（跳过当前知识点，但可能影响后续）

转移概率 T(s' | s, a):
  学习知识点 a 后:
  - P(掌握) = sigmoid(α × ability - β × difficulty)
    其中 ability 由学生历史学习效率估算
  - P(未掌握) = 1 - P(掌握)
  
  掌握时: s' = (learned_set ∪ {a}, budget - time_a, a)
  未掌握时: s' = (learned_set, budget - time_a, a) + 需要重学

奖励函数 R(s, a, s'):
  R = w1 × ΔMastery × ExamWeight   // 掌握度增量 × 考试权重
    + w2 × EngagementBonus          // 兴趣匹配奖励
    - w3 × TimeCost                 // 时间成本惩罚
    - w4 × CognitiveOverloadPenalty // 认知负荷超标惩罚
    - w5 × BacktrackPenalty         // 未掌握需要重学的惩罚

终止条件:
  - 所有目标知识点已掌握 → 成功终止
  - remaining_budget ≤ 0 → 超时终止
  - 达到最大迭代步数
```

#### 3.5.2 求解算法：值迭代 + 剪枝

```java
public class MDPPathOptimizer {

    // MDP 参数
    private static final double ALPHA = 2.5;      // 能力系数
    private static final double BETA = 2.0;       // 难度系数
    private static final double W_MASTERY = 1.0;   // 掌握度权重
    private static final double W_ENGAGEMENT = 0.2;// 兴趣权重
    private static final double W_TIME = 0.001;   // 时间惩罚权重
    private static final double W_COGNITIVE = 0.3; // 认知负荷权重
    private static final double W_BACKTRACK = 0.5; // 重学惩罚

    private static final int MAX_HORIZON = 200;    // 最大步数
    private static final int MAX_STATES = 500_000; // 状态空间上限

    /**
     * 求解最优学习路径
     *
     * @param subDag     目标子图
     * @param mastery    当前掌握度
     * @param goal       学习目标
     * @return 最优路径
     */
    public OptimalPathResult solve(KnowledgeDAG subDag,
                                    MasterySnapshot mastery,
                                    LearningGoal goal) {

        // 1. 初始状态
        Set<String> initialLearned = extractMasteredNodes(mastery);
        int totalBudget = calculateTotalBudget(goal);  // dailyMinutes × 可用天数

        MDPState initialState = new MDPState(
            BitSet.valueOf(initialLearned),   // 已掌握集合
            totalBudget,                      // 剩余预算
            null                               // 当前节点
        );

        // 2. 贪心策略生成初始路径（作为 baseline）
        List<String> greedyPath = greedyBaselinePath(subDag, mastery, goal);

        // 3. 有限范围值迭代（带剪枝）
        //    由于完整状态空间可能爆炸，采用 beam search 替代完整枚举
        BeamSearchResult beamResult = beamSearch(
            initialState,
            subDag,
            mastery,
            goal,
            beamWidth = 20,      // 每层保留20个最优状态
            maxHorizon = MAX_HORIZON
        );

        // 4. 比较 beam search 和 greedy 结果，取更优者
        double greedyScore = evaluatePath(greedyPath, subDag, mastery, goal);
        if (beamResult.getTotalReward() > greedyScore) {
            return beamResultToPath(beamResult);
        } else {
            return greedyResultToPath(greedyPath, subDag, goal);
        }
    }

    /**
     * Beam Search 求解器
     * 在每一步保留 beamWidth 个最优的部分路径。
     */
    private BeamSearchResult beamSearch(MDPState initial,
                                         KnowledgeDAG dag,
                                         MasterySnapshot mastery,
                                         LearningGoal goal,
                                         int beamWidth,
                                         int maxHorizon) {

        // 优先队列：按累积奖励排序
        PriorityQueue<PartialPath> beam = new PriorityQueue<>(
            Comparator.comparingDouble(PartialPath::accumulatedReward).reversed()
        );
        beam.offer(new PartialPath(initial, List.of(), 0.0));

        BeamSearchResult bestResult = null;

        for (int step = 0; step < maxHorizon && !beam.isEmpty(); step++) {
            PriorityQueue<PartialPath> nextBeam = new PriorityQueue<>(
                Comparator.comparingDouble(PartialPath::accumulatedReward).reversed()
            );

            for (PartialPath current : beam) {
                // 获取当前可执行的动作（可学的知识点）
                Set<String> availableActions = getAvailableActions(current, dag);

                // 如果所有目标节点都已掌握，记录为候选结果
                if (isGoalReached(current, goal)) {
                    if (bestResult == null || current.accumulatedReward() > bestResult.getTotalReward()) {
                        bestResult = new BeamSearchResult(
                            current.path(),
                            current.accumulatedReward(),
                            step
                        );
                    }
                    continue;
                }

                // 预算耗尽
                if (current.state().remainingBudget() <= 0) {
                    continue;
                }

                // 扩展每个动作
                for (String action : availableActions) {
                    PartialPath expanded = expandPath(current, action, dag, mastery, goal);
                    nextBeam.offer(expanded);
                }

                // 剪枝：保留 top-beamWidth
                while (nextBeam.size() > beamWidth) {
                    nextBeam.poll();  // 移除奖励最低的
                }
            }

            beam = nextBeam;

            // 状态空间爆炸保护
            if (beam.stream().mapToInt(p -> p.path().size()).sum() > MAX_STATES) {
                break;
            }
        }

        return bestResult != null ? bestResult :
            new BeamSearchResult(beam.peek().path(), beam.peek().accumulatedReward(), maxHorizon);
    }

    /**
     * 计算学习某知识点的掌握概率
     */
    private double computeMasteryProbability(String nodeId,
                                              KnowledgeDAG dag,
                                              MasterySnapshot mastery,
                                              double efficiency) {
        KnowledgeNode node = dag.getNode(nodeId);
        // sigmoid(α × ability - β × difficulty) × 学习效率系数
        double ability = estimateStudentAbility(mastery, dag);
        double rawProb = sigmoid(ALPHA * ability - BETA * node.difficulty());
        return Math.max(0.1, Math.min(0.95, rawProb * efficiency));  // 裁剪到 [0.1, 0.95]
    }

    /**
     * 计算奖励函数
     */
    private double computeReward(String nodeId,
                                  boolean mastered,
                                  KnowledgeDAG dag,
                                  MasterySnapshot snapshot,
                                  LearningGoal goal) {
        KnowledgeNode node = dag.getNode(nodeId);
        double reward = 0;

        if (mastered) {
            // 掌握度增量 × 考试权重
            double currentMastery = snapshot.getOrDefault(nodeId, 0).masteryLevel();
            double masteryDelta = 1.0 - currentMastery;
            reward += W_MASTERY * masteryDelta * node.importanceWeight();

            // 兴趣匹配奖励
            reward += W_ENGAGEMENT * getInterestScore(nodeId, goal);
        } else {
            // 未掌握的重学惩罚
            reward -= W_BACKTRACK;
        }

        // 时间成本惩罚
        reward -= W_TIME * node.estimatedMinutes();

        // 认知负荷惩罚（如果连续学习高难度知识点）
        double cognitiveLoad = node.difficulty();
        if (cognitiveLoad > COGNITIVE_THRESHOLD) {
            reward -= W_COGNITIVE * (cognitiveLoad - COGNITIVE_THRESHOLD);
        }

        return reward;
    }

    /**
     * 贪心基线路径：每步选择 (考频权重 × 掌握概率 / 时间) 最大的可学节点
     */
    private List<String> greedyBaselinePath(KnowledgeDAG dag,
                                             MasterySnapshot mastery,
                                             LearningGoal goal) {
        List<String> path = new ArrayList<>();
        Set<String> learned = new HashSet<>(extractMasteredNodes(mastery));
        Set<String> remaining = new HashSet<>(dag.getAllNodeIds());
        remaining.removeAll(learned);
        int budget = calculateTotalBudget(goal);

        while (!remaining.isEmpty() && budget > 0) {
            // 找到所有可学节点（前置已满足）
            List<String> available = remaining.stream()
                .filter(node -> isLearnable(node, learned, dag))
                .collect(Collectors.toList());

            if (available.isEmpty()) break;  // 死锁（不应发生，因为已做环检测）

            // 选择得分最高的节点
            String best = available.stream()
                .max(Comparator.comparingDouble(node -> {
                    KnowledgeNode kn = dag.getNode(node);
                    double prob = computeMasteryProbability(node, dag, mastery, 1.0);
                    return kn.importanceWeight() * prob / Math.max(1, kn.estimatedMinutes());
                }))
                .orElseThrow();

            path.add(best);
            remaining.remove(best);
            learned.add(best);
            budget -= dag.getNode(best).estimatedMinutes();
        }

        return path;
    }

    private double sigmoid(double x) {
        return 1.0 / (1.0 + Math.exp(-x));
    }
}
```

### 3.6 多目标 Pareto 优化

当用户有多个竞争性偏好时（如"既要覆盖面广，又要重点突破"），生成 Pareto 前沿供选择。

```java
public class ParetoOptimizer {

    /**
     * 三维目标：(预期掌握度, 总学习时间, 兴趣匹配度)
     * 生成 Pareto 前沿上的若干代表性路径。
     *
     * @return 3~5 条 Pareto 最优路径
     */
    public List<OptimalPathResult> generateParetoFront(
            KnowledgeDAG dag,
            MasterySnapshot mastery,
            LearningGoal goal,
            int numSolutions) {

        // 通过调整权重组合，生成多个非支配解
        double[][] weightPresets = {
            {1.0, 0.0, 0.0},   // 纯掌握度最大化
            {0.7, 0.2, 0.1},   // 掌握优先，兼顾兴趣
            {0.5, 0.3, 0.2},   // 均衡
            {0.3, 0.4, 0.3},   // 时间效率优先
            {0.2, 0.5, 0.3},   // 时间最短
        };

        List<OptimalPathResult> results = new ArrayList<>();
        MDPPathOptimizer optimizer = new MDPPathOptimizer();

        for (double[] weights : weightPresets) {
            // 更新 MDP 参数中的权重
            optimizer.updateWeights(weights[0], weights[1], weights[2]);
            OptimalPathResult result = optimizer.solve(dag, mastery, goal);
            results.add(result);
        }

        // 去除被支配的解
        return filterDominated(results);
    }

    private List<OptimalPathResult> filterDominated(List<OptimalPathResult> solutions) {
        return solutions.stream()
            .filter(s -> solutions.stream().noneMatch(other ->
                other != s && other.dominates(s)
            ))
            .collect(Collectors.toList());
    }
}
```

## 5. 路径分阶段标注策略

路径生成后，每个节点会被标注为以下阶段之一：

```java
public enum PathPhase {
    REMEDIAL,    // 前置补学阶段：学习目标范围外但作为前置的旧知识
    CORE,        // 核心学习阶段：目标范围内的核心知识点
    ADVANCED,    // 进阶综合阶段：难度较高、综合性强的知识点
    REVIEW       // 复习冲刺阶段：考前回顾已学知识点
}
```

### 5.1 阶段划分算法

```java
public class PhaseClassifier {

    /**
     * 将路径节点序列划分为4个阶段。
     *
     * 划分规则:
     * 1. REMEDIAL: 不在 targetNodeIds 中，但需要作为前置学习的节点
     * 2. CORE: 在 targetNodeIds 中，难度 <= 0.7
     * 3. ADVANCED: 在 targetNodeIds 中，难度 > 0.7，或为综合应用类节点
     * 4. REVIEW: 在 targetNodeIds 中，且之前已学过（mastery >= 0.5），安排在末尾巩固
     */
    public Map<PathPhase, List<String>> classify(List<String> pathSequence,
                                                   Set<String> targetNodeIds,
                                                   KnowledgeDAG dag,
                                                   MasterySnapshot snapshot) {

        Map<PathPhase, List<String>> phases = new EnumMap<>(PathPhase.class);

        // 第一遍：基础分类
        for (String nodeId : pathSequence) {
            PathPhase phase;
            if (!targetNodeIds.contains(nodeId)) {
                phase = PathPhase.REMEDIAL;
            } else {
                KnowledgeNode node = dag.getNode(nodeId);
                MasteryState ms = snapshot.get(nodeId);
                double currentMastery = ms != null ? ms.masteryLevel() : 0;

                if (currentMastery >= 0.5 && node.difficulty() <= 0.6) {
                    phase = PathPhase.REVIEW;
                } else if (node.difficulty() > 0.7) {
                    phase = PathPhase.ADVANCED;
                } else {
                    phase = PathPhase.CORE;
                }
            }
            phases.computeIfAbsent(phase, k -> new ArrayList<>()).add(nodeId);
        }

        // 第二遍：调整 REVIEW 节点的位置 — 移到序列末尾
        // （在 API 返回时重排序列，不影响内部存储）

        return phases;
    }
}
```

## 6. 路径动态重计算机制

### 6.1 重算触发条件

```java
public class PathRecalculator {

    /**
     * 判断是否需要触发路径重算
     */
    public RecalcDecision evaluate(LearningPath currentPath,
                                    PathEvent event) {
        return switch (event.type()) {
            case MASTERY_DROP -> {
                // 某知识点掌握度大幅下降（连续答错，掌握度降幅 > 0.3）
                if (affectsCriticalPath(currentPath, event.nodeId())) {
                    yield RecalcDecision.IMMEDIATE;
                } else {
                    yield RecalcDecision.DEFERRED;
                }
            }

            case MASTERY_RISE -> {
                // 某知识点被快速掌握（比预期快很多）
                if (currentPath.getPendingNodes().size() <= 3) {
                    yield RecalcDecision.SKIP;  // 剩余节点少，不需重算
                }
                yield RecalcDecision.DEFERRED;
            }

            case GOAL_DEADLINE_CHANGE -> {
                // 截止日期变更
                int dayDelta = ChronoUnit.DAYS.between(
                    currentPath.getDeadline(), event.newDeadline());
                if (Math.abs(dayDelta) >= 3) {
                    yield RecalcDecision.IMMEDIATE;
                }
                yield RecalcDecision.SKIP;
            }

            case DAILY_TIME_CHANGE -> {
                // 每日学习时长变更
                int oldMinutes = currentPath.getDailyMinutes();
                int newMinutes = event.newDailyMinutes();
                if (Math.abs(newMinutes - oldMinutes) / (double) oldMinutes > 0.3) {
                    yield RecalcDecision.IMMEDIATE;
                }
                yield RecalcDecision.SKIP;
            }

            case NEW_WEAK_AREA -> {
                // 测评发现新的薄弱区域
                yield RecalcDecision.DEFERRED;
            }

            case MANUAL -> {
                yield RecalcDecision.IMMEDIATE;
            }
        };
    }

    /**
     * 延迟重算：合并5分钟内的多个事件
     */
    @Scheduled(fixedDelay = 300_000)  // 每5分钟执行一次
    public void processDeferredRecalculations() {
        List<RecalcTask> pending = recalcQueue.drainAll();
        // 按学生分组，每个学生只做一次重算（使用最新状态）
        Map<Long, List<RecalcTask>> byStudent = pending.stream()
            .collect(Collectors.groupingBy(RecalcTask::studentId));

        for (var entry : byStudent.entrySet()) {
            Long studentId = entry.getKey();
            List<RecalcTask> tasks = entry.getValue();

            // 合并所有触发原因
            RecalcTask merged = mergeTasks(tasks);

            // 检查是否真正需要重算（避免无意义的重算）
            LearningPath currentPath = pathRepository.findActivePath(studentId, merged.subject());
            if (shouldRecalculate(currentPath, merged)) {
                doRecalculate(currentPath, merged);
            }
        }
    }

    /**
     * 增量重算：只重算受影响的部分，而非从头开始
     */
    private boolean doRecalculate(LearningPath oldPath, RecalcTask task) {
        // 1. 获取最新掌握度快照
        MasterySnapshot latest = masteryService.getSnapshot(task.studentId(), oldPath.getGraphId());

        // 2. 检查路径是否仍然有效（知识点依赖关系是否变化）
        KnowledgeDAG latestDag = knowledgeGraphService.getDag(oldPath.getGraphId());

        // 3. 增量重算：
        //    - 已完成(IN_PROGRESS之后)的节点保持不变
        //    - 从第一个 PENDING 节点开始重新规划
        int recalcStartIndex = findFirstPendingIndex(oldPath);

        //    - 提取从 recalcStartIndex 开始的子路径
        List<String> pendingNodes = oldPath.getNodesFrom(recalcStartIndex);

        //    - 重新规划这部分路径
        KnowledgeDAG remainingSubDag = extractRemainingSubgraph(pendingNodes, latestDag);
        OptimalPathResult newSegment = optimizer.solve(
            remainingSubDag, latest, adaptGoal(oldPath, task));

        //    - 拼接：已完成部分 + 新规划部分
        LearningPath newPath = mergePaths(oldPath, recalcStartIndex, newSegment);

        //    - 版本升级
        newPath.setPathVersion(oldPath.getPathVersion() + 1);

        //    - 旧路径标记为 SUPERSEDED
        oldPath.setPathStatus("SUPERSEDED");
        oldPath.setSupersededBy(newPath.getPathUuid());

        //    - 持久化
        pathRepository.save(oldPath);
        pathRepository.save(newPath);

        //    - 记录变更日志
        recalcLogRepository.save(buildChangeLog(oldPath, newPath, task));

        //    - 发布事件
        eventPublisher.publish(new PathRecalculatedEvent(newPath, oldPath));

        return true;
    }
}
```

```java
/**
 * 当知识点数量超过阈值（如 100 个）时，采用分层规划：
 * 1. 先在章节级别做粗粒度规划（节点数 ~10-20 个章节）
 * 2. 再在每个章节内部做细粒度规划（每章 ~5-15 个知识点）
 */
public class HierarchicalPathPlanner {

    public OptimalPathResult planLarge(KnowledgeDAG fullDag,
                                        MasterySnapshot mastery,
                                        LearningGoal goal) {
        // Phase 1: 章节级规划
        KnowledgeDAG chapterDag = collapseToChapterLevel(fullDag);
        OptimalPathResult chapterPath = optimizer.solve(chapterDag, mastery, goal);

        // Phase 2: 在每个章节内做节点级规划
        List<String> detailedPath = new ArrayList<>();
        for (String chapterId : chapterPath.getSequence()) {
            KnowledgeDAG chapterSubDag = extractChapter(fullDag, chapterId);
            MasterySnapshot chapterMastery = mastery.filterByChapter(chapterId);
            LearningGoal chapterGoal = adaptGoalToChapter(goal, chapterId);

            OptimalPathResult chapterResult = optimizer.solve(chapterSubDag, chapterMastery, chapterGoal);
            detailedPath.addAll(chapterResult.getSequence());
        }

        return new OptimalPathResult(detailedPath, ...);
    }
}
```

### 9.2 节点状态流转

```
    PENDING ──→ IN_PROGRESS ──→ MASTERED
         │            │
         │            └──→ FAILED ──→ IN_PROGRESS (重学)
         │                              │
         └──→ SKIPPED ◄─────────────────┘
```

```java
public class PathNodeStateMachine {

    private static final Map<String, Set<String>> TRANSITIONS = Map.of(
        "PENDING",      Set.of("IN_PROGRESS", "SKIPPED"),
        "IN_PROGRESS",  Set.of("MASTERED", "FAILED"),
        "FAILED",       Set.of("IN_PROGRESS", "SKIPPED"),
        "MASTERED",     Set.of(),                          // 终态
        "SKIPPED",      Set.of("PENDING")                  // 可重新激活
    );

    public void transition(LearningPathNode node, String targetStatus,
                           double actualMastery, int actualMinutes) {
        String currentStatus = node.getNodeStatus();
        if (!TRANSITIONS.get(currentStatus).contains(targetStatus)) {
            throw new IllegalStateTransitionException(
                currentStatus, targetStatus, node.getNodeId());
        }

        node.setNodeStatus(targetStatus);
        node.setActualMastery(actualMastery);
        node.setActualMinutes(actualMinutes);

        if ("MASTERED".equals(targetStatus)) {
            node.setCompletedAt(LocalDateTime.now());
        } else if ("IN_PROGRESS".equals(targetStatus) && node.getStartedAt() == null) {
            node.setStartedAt(LocalDateTime.now());
        }
    }
}
```

```java
@Component
public class PathEventListener {

    /**
     * 监听答题结果事件 → 更新掌握度 → 可能触发路径重算
     */
    @EventListener
    @Async
    public void onAnswerRecorded(AnswerRecordedEvent event) {
        if (!event.affectsActivePath()) return;

        // 检查是否需要路径重算
        RecalcDecision decision = recalculator.evaluate(
            activePath,
            PathEvent.masteryUpdate(event.nodeId(), event.masteryDelta())
        );

        if (decision == RecalcDecision.IMMEDIATE) {
            recalculator.doRecalculateAsync(activePath);
        } else if (decision == RecalcDecision.DEFERRED) {
            recalculator.enqueueDeferred(activePath.getStudentId(), event);
        }
    }

    /**
     * 监听测评完成事件 → 批量更新掌握度 → 触发路径重算
     */
    @EventListener
    @Async
    public void onAssessmentCompleted(AssessmentCompletedEvent event) {
        // 测评通常覆盖多个知识点，重算优先级更高
        recalculator.doRecalculateAsync(activePath);
    }

    /**
     * 监听学习目标变更事件
     */
    @EventListener
    public void onGoalUpdated(LearningGoalUpdatedEvent event) {
        // 目标变更必须触发路径重算
        recalculator.doRecalculateImmediately(activePath, PathEvent.goalChange(event));
    }
}
```

```yaml
      path-template-ttl-hours: 24    # 路径模板缓存TTL

    # 性能阈值
```

### 14.3 与"前置依赖检测服务"的协作示例

```
场景: 初二学生在做"二次函数图像"练习时连续答错

1. 自适应推荐引擎发现错误模式
2. → 调用"前置依赖检测服务"，检测到"函数概念"掌握度仅0.3
3. → 前置服务生成局部补学路径: [函数概念 → 一次函数 → 二次函数]
4. → 同时触发本引擎的全局路径重算
5. → 本引擎在全局路径中:
   a. 在"二次函数图像"前插入"函数概念"和"一次函数"两个 REMEDIAL 节点
   b. 重新计算后续节点的预期掌握度和时间预算
   c. 如果总时间超出预算，低权重节点标记为 SKIPPED
6. → 新版本路径推送给学习规划模块，更新每日任务
```
