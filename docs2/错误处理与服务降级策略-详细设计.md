# 错误处理与服务降级策略 - 详细设计

> 模块负责人：待定 | 版本：1.0 | 创建日期：2026-05-20

## 1. 概述

### 1.1 背景

PrimeTop 作为面向 K12 学生的 AI 辅助学习 APP，依赖多种外部服务（大模型 API、OCR、语音、支付、短信等）和内部微服务。任何环节故障都可能影响学习体验。需要一个统一的错误处理与降级框架，确保：

1. 用户侧体验平滑——不展示原始错误信息，提供友好提示和替代路径
2. 服务侧可观测——错误可追踪、可归因、可告警
3. 系统自愈——自动重试、熔断、降级，减少人工干预

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 错误可见性 | 100% 的 5xx / 超时 / 第三方异常产生告警 |
| 降级响应速度 | 检测到故障后 ≤ 10s 切换降级策略 |
| 用户体验 | 核心路径（AI 问答、拍题）故障时仍有替代方案 |
| 错误码覆盖率 | 所有 API 接口使用统一错误码体系 |
| 客户端恢复 | 断网重连后自动恢复进行中的操作，无需用户手动刷新 |

### 1.3 适用范围

- **服务端**：所有后端业务服务、AI 能力层、数据层
- **客户端**：Flutter APP 的网络层、UI 层错误展示
- **第三方服务**：大模型、OCR、ASR/TTS、SMS、支付网关、对象存储、推送

## 2. 统一错误码体系

### 2.1 错误码格式

```
[服务标识].[模块].[错误类型][序号]

示例：AI.MODEL.TIMEOUT01
     USER.AUTH.INVALID_TOKEN
```

| 段 | 说明 | 示例 |
|----|------|------|
| 服务标识 | 2-4 字母 | `AI` / `USER` / `QUESTION` / `MISTAKE` / `PAY` / `CONTENT` / `SEARCH` |
| 模块 | 具体子模块 | `MODEL` / `AUTH` / `OCR` / `CHAT` / `PLAN` / `SUB` |
| 错误类型 | 分类 | `TIMEOUT` / `INVALID` / `NOT_FOUND` / `RATE_LIMIT` / `INTERNAL` / `THIRD_PARTY` |
| 序号 | 同类型内编号 | `01` / `02` |

### 2.2 全局错误码分类

#### 2.2.1 通用错误码（所有服务共用）

| HTTP Status | 错误码 | 说明 | 客户端处理 |
|-------------|--------|------|------------|
| 400 | `COMMON.PARAM.INVALID_01` | 请求参数校验失败 | 弹出具体字段提示 |
| 401 | `COMMON.AUTH.TOKEN_EXPIRED` | Token 过期 | 自动刷新 Token 后重试 |
| 401 | `COMMON.AUTH.TOKEN_INVALID` | Token 无效/被撤销 | 跳转登录页 |
| 403 | `COMMON.AUTH.FORBIDDEN` | 无权访问（非会员访问付费功能） | 引导开通会员 |
| 403 | `COMMON.AUTH.AGE_RESTRICTED` | 年龄限制（幼儿访问高中内容） | 提示内容不适用 |
| 429 | `COMMON.RATE_LIMIT.EXCEEDED` | 请求频率超限 | 显示倒计时冷却提示 |
| 500 | `COMMON.INTERNAL.UNKNOWN` | 未知服务端错误 | Toast 提示"服务繁忙" |
| 503 | `COMMON.SERVICE.UNAVAILABLE` | 服务暂不可用（维护中） | 展示维护页面 |

#### 2.2.2 AI 服务错误码

| HTTP Status | 错误码 | 说明 | 降级策略 |
|-------------|--------|------|----------|
| 504 | `AI.MODEL.TIMEOUT_01` | 大模型调用超时 (>30s) | 降级到轻量模型重试 |
| 502 | `AI.MODEL.ERROR_01` | 大模型返回异常 | 降级到备用模型 |

| 500 | `AI.CONTEXT.OVERFLOW` | 上下文超长截断失败 | 自动压缩历史后重试 |
| 500 | `AI.RAG.RETRIEVE_FAIL` | RAG 检索服务异常 | 跳过 RAG 增强，直接问答 |

## 3. 服务端错误处理架构

### 3.1 分层异常模型

```
┌──────────────────────────────────────────────┐
│  Controller 层                                │
│  - 参数校验异常 → 400                          │
│  - 权限校验异常 → 401/403                      │
│  - 统一 @ExceptionHandler 捕获               │
├──────────────────────────────────────────────┤
│  Service 层                                   │
│  - 业务异常 (BusinessException)               │
│  - 第三方服务异常 (ThirdPartyException)        │
│  - 降级异常 (FallbackException)               │
├──────────────────────────────────────────────┤
│  Infrastructure 层                            │
│  - 网络超时 / 连接拒绝                         │
│  - 数据库异常                                 │
│  - 缓存异常                                   │
│  - 消息队列异常                                │
└──────────────────────────────────────────────┘
```

### 3.2 异常类定义（Python/FastAPI 示例）

```python

from typing import Optional, Any

    CHAPTER_NOT_FOUND = "CONTENT.CHAPTER.NOT_FOUND"
    MISTAKE_SYNC_CONFLICT = "MISTAKE.SYNC.CONFLICT"
    PLAN_GENERATE_TIMEOUT = "PLAN.GENERATE.TIMEOUT"
    SEARCH_INDEX_ERROR = "SEARCH.INDEX.ERROR"


class FallbackAction(str, Enum):
    """客户端可执行的降级动作"""
    RETRY = "retry"                        # 自动重试（相同参数）
    RETRY_WITH_FALLBACK = "retry_with_fallback"  # 降级重试（切换参数）
    RETRY_LATER = "retry_later"            # 提示用户稍后重试
    USE_CACHE = "use_cache"                # 使用本地缓存
    REDIRECT = "redirect"                  # 跳转其他页面
    MANUAL_INPUT = "manual_input"          # 引导手动输入替代


class AppException(Exception):
    """应用基础异常"""
    def __init__(
        self,
        code: ErrorCode,
        message: str,
        http_status: int = 500,
        detail: Optional[str] = None,
        fallback_action: Optional[FallbackAction] = None,
        fallback_params: Optional[dict] = None,
        retry_after_ms: Optional[int] = None,
    ):
        self.code = code
        self.message = message
        self.http_status = http_status
        self.detail = detail
        self.fallback_action = fallback_action
        self.fallback_params = fallback_params
        self.retry_after_ms = retry_after_ms
        super().__init__(message)

    def to_response(self, trace_id: str, debug: bool = False) -> dict:
        resp = {
            "success": False,
            "error": {
                "code": self.code.value,
                "message": self.message,
                "trace_id": trace_id,
                "timestamp": int(time.time()),
            }
        }
        if debug:
            resp["error"]["detail"] = self.detail
        if self.fallback_action:
            suggestion = {"action": self.fallback_action.value}
            if self.fallback_params:
                suggestion.update(self.fallback_params)
            if self.retry_after_ms:
                suggestion["retry_after_ms"] = self.retry_after_ms
            resp["error"]["suggestion"] = suggestion
        return resp


class BusinessException(AppException):
    """业务逻辑异常"""
    def __init__(self, code: ErrorCode, message: str, **kwargs):
        super().__init__(code=code, message=message, **kwargs)


class ThirdPartyException(AppException):
    """第三方服务异常"""
    def __init__(
        self, 
        code: ErrorCode, 
        message: str, 
        provider: str,
        original_error: Optional[str] = None,
        **kwargs
    ):
        self.provider = provider
        self.original_error = original_error
        kwargs.setdefault("detail", f"[{provider}] {original_error}")
        kwargs.setdefault("fallback_action", FallbackAction.RETRY_WITH_FALLBACK)
        super().__init__(code=code, message=message, **kwargs)
```

### 3.3 全局异常处理器

```python
from fastapi import Request
from fastapi.responses import JSONResponse
from fastapi.exception_handlers import http_exception_handler
import traceback
import structlog

logger = structlog.get_logger()


async def app_exception_handler(request: Request, exc: AppException) -> JSONResponse:
    """处理所有 AppException"""
    trace_id = getattr(request.state, "trace_id", "unknown")
    debug = request.headers.get("X-Debug") == "true"
    
    # 日志记录
    log_data = {
        "trace_id": trace_id,
        "error_code": exc.code.value,
        "http_status": exc.http_status,
        "path": str(request.url.path),
        "detail": exc.detail,
    }
    if isinstance(exc, ThirdPartyException):
        log_data["provider"] = exc.provider
        log_data["original_error"] = exc.original_error
    
    if exc.http_status >= 500:
        logger.error("service_error", **log_data)
    else:
        logger.warning("client_error", **log_data)
    
    return JSONResponse(
        status_code=exc.http_status,
        content=exc.to_response(trace_id=trace_id, debug=debug),
    )


async def unhandled_exception_handler(request: Request, exc: Exception) -> JSONResponse:
    """兜底：捕获所有未处理异常"""
    trace_id = getattr(request.state, "trace_id", "unknown")
    
    logger.error(
        "unhandled_exception",
        trace_id=trace_id,
        path=str(request.url.path),
        exception_type=type(exc).__name__,
        traceback=traceback.format_exc(),
    )
    
    return JSONResponse(
        status_code=500,
        content={
            "success": False,
            "error": {
                "code": "COMMON.INTERNAL.UNKNOWN",
                "message": "服务繁忙，请稍后再试",
                "trace_id": trace_id,
                "timestamp": int(time.time()),
            }
        },
    )

# 注册
app.add_exception_handler(AppException, app_exception_handler)
app.add_exception_handler(Exception, unhandled_exception_handler)
```

## 4. 重试策略

### 4.1 重试策略矩阵

| 场景 | 最大重试次数 | 退避策略 | 可重试条件 |
|------|-------------|---------|-----------|
| AI 模型调用超时 | 2 | 指数退避 (1s → 2s → 4s) | HTTP 504 / 超时 |
| AI 模型返回 5xx | 1 | 固定 2s | HTTP 500/502/503 |
| AI 限流 429 | 1 | 使用 Retry-After 头 | HTTP 429 |
| OCR 识别超时 | 2 | 指数退避 (2s → 4s) | HTTP 504 |
| OCR 服务不可用 | 1 | 固定 3s → 降级提示手动输入 | HTTP 502/503 |
| SMS 发送失败 | 2 | 指数退避 (1s → 3s) → 降级图形验证码 | 网络异常 |
| 支付网关超时 | 2 | 固定 3s → 主动查询订单状态 | HTTP 504 |
| 数据库写入失败 | 3 | 指数退避 (0.5s → 1s → 2s) | 连接异常 |
| Redis 操作失败 | 2 | 固定 0.5s → 跳过缓存直接查 DB | 连接异常 |
| 搜索引擎异常 | 1 | 固定 1s → 降级 DB LIKE 查询 | 连接异常 / 5xx |

### 4.2 通用重试装饰器

```python
import asyncio
import random
from functools import wraps
from typing import Callable, Type, Tuple

def with_retry(
    max_retries: int = 2,
    base_delay_ms: int = 1000,
    strategy: str = "exponential",  # "exponential" | "fixed" | "retry_after"
    retryable_exceptions: Tuple[Type[Exception], ...] = (TimeoutError, ConnectionError),
    on_exhausted: Optional[Callable] = None,
):
    """
    通用重试装饰器
    
    Args:
        max_retries: 最大重试次数
        base_delay_ms: 基础延迟毫秒数
        strategy: 退避策略
        retryable_exceptions: 可重试的异常类型
        on_exhausted: 重试耗尽后的回调（用于降级）
    """
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            last_exception = None
            for attempt in range(max_retries + 1):
                try:
                    return await func(*args, **kwargs)
                except retryable_exceptions as e:
                    last_exception = e
                    if attempt == max_retries:
                        break
                    
                    # 计算延迟
                    if strategy == "exponential":
                        delay = base_delay_ms * (2 ** attempt) / 1000
                        jitter = random.uniform(0, delay * 0.3)
                        delay += jitter
                    elif strategy == "fixed":
                        delay = base_delay_ms / 1000
                    else:
                        delay = base_delay_ms / 1000
                    
                    # 如果是 429，优先用 Retry-After
                    if hasattr(e, 'retry_after'):
                        delay = max(delay, e.retry_after)
                    
                    logger.warning(
                        "retry_attempt",
                        function=func.__name__,
                        attempt=attempt + 1,
                        max_retries=max_retries,
                        delay_ms=int(delay * 1000),
                        error=str(e),
                    )
                    await asyncio.sleep(delay)
            
            # 重试耗尽
            if on_exhausted:
                return await on_exhausted(*args, **kwargs, original_error=last_exception)
            raise last_exception
        
        return wrapper
    return decorator
```

## 5. 熔断器模式

### 5.1 熔断器状态机

```
         成功率恢复                    连续 N 次失败
   ┌──────────────────┐         ┌──────────────────┐
   │                  │         │                  │
   │    CLOSED        │─────────│    OPEN          │
   │  (正常放行请求)    │  失败≥阈值 │  (直接拒绝请求)   │
   │                  │         │                  │
   └──────────────────┘         └──────┬───────────┘
          ▲                            │
          │          探测成功            │ 超时后放行 1 个
          │     ┌──────────────────┐    │ 探测请求
          └─────│  HALF_OPEN       │◄───┘
                  │  (探测模式)      │
                  └──────────────────┘
                           │
                     探测失败 → 回到 OPEN
```

### 5.2 熔断器配置

```python
from dataclasses import dataclass
from datetime import datetime, timedelta
from enum import Enum
import threading

class CircuitState(str, Enum):
    CLOSED = "closed"
    OPEN = "open"
    HALF_OPEN = "half_open"


@dataclass
class CircuitConfig:
    """熔断器配置"""
    failure_threshold: int = 5          # 连续失败次数阈值
    success_threshold: int = 3          # 半开状态下连续成功恢复阈值
    timeout_seconds: int = 30           # 熔断开启后等待时间（进入半开）
    half_open_max_calls: int = 1        # 半开状态最大探测请求数
    window_seconds: int = 60            # 统计窗口（可选：滑动窗口模式）


class CircuitBreaker:
    """通用熔断器"""
    
    def __init__(self, name: str, config: CircuitConfig = None):
        self.name = name
        self.config = config or CircuitConfig()
        self.state = CircuitState.CLOSED
        self.failure_count = 0
        self.success_count = 0
        self.last_failure_time: Optional[datetime] = None
        self.half_open_calls = 0
        self._lock = threading.Lock()
    
    async def call(self, func, *args, fallback=None, **kwargs):
        """通过熔断器执行函数"""
        with self._lock:
            if self.state == CircuitState.OPEN:
                # 检查是否该进入半开状态
                if self._should_try_half_open():
                    self.state = CircuitState.HALF_OPEN
                    self.half_open_calls = 0
                else:
                    # 熔断中，执行降级
                    if fallback:
                        return await fallback(*args, **kwargs)
                    raise CircuitOpenError(
                        f"Circuit [{self.name}] is OPEN",
                        provider=self.name,
                    )
            
            if self.state == CircuitState.HALF_OPEN:
                if self.half_open_calls >= self.config.half_open_max_calls:
                    # 探测请求已发出，等待结果
                    if fallback:
                        return await fallback(*args, **kwargs)
                    raise CircuitOpenError(
                        f"Circuit [{self.name}] is HALF_OPEN (max probes reached)",
                        provider=self.name,
                    )
                self.half_open_calls += 1
        
        # 执行请求
        try:
            result = await func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            if fallback:
                return await fallback(*args, **kwargs)
            raise
    
    def _should_try_half_open(self) -> bool:
        if self.last_failure_time is None:
            return True
        elapsed = (datetime.now() - self.last_failure_time).total_seconds()
        return elapsed >= self.config.timeout_seconds
    
    def _on_success(self):
        with self._lock:
            if self.state == CircuitState.HALF_OPEN:
                self.success_count += 1
                if self.success_count >= self.config.success_threshold:
                    self.state = CircuitState.CLOSED
                    self.failure_count = 0
                    self.success_count = 0
                    logger.info("circuit_recovered", circuit=self.name)
            else:
                self.failure_count = 0
    
    def _on_failure(self):
        with self._lock:
            self.failure_count += 1
            self.last_failure_time = datetime.now()
            if self.state == CircuitState.HALF_OPEN:
                self.state = CircuitState.OPEN
                self.success_count = 0
                logger.warning("circuit_probe_failed", circuit=self.name)
            elif self.failure_count >= self.config.failure_threshold:
                self.state = CircuitState.OPEN
                logger.warning(
                    "circuit_opened",
                    circuit=self.name,
                    failure_count=self.failure_count,
                )
    
    def get_state(self) -> dict:
        return {
            "name": self.name,
            "state": self.state.value,
            "failure_count": self.failure_count,
            "success_count": self.success_count,
            "last_failure_time": self.last_failure_time.isoformat() if self.last_failure_time else None,
        }


class CircuitOpenError(AppException):
    """熔断器开启异常"""
    def __init__(self, message: str, provider: str):
        self.provider = provider
        super().__init__(
            code=ErrorCode.AI_MODEL_ERROR,
            message="服务暂时繁忙，请稍后再试",
            http_status=503,
            detail=message,
            fallback_action=FallbackAction.RETRY_LATER,
            retry_after_ms=30000,
        )
```

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class ModelTier:
    """模型层级定义"""
    name: str
    model_id: str
    max_tokens: int
    timeout_ms: int
    quality_level: str  # "high" / "standard" / "fast"
    cost_per_1k: float  # 每千 token 成本（元）


# 模型分层配置
MODEL_TIERS = {
    "high": [
        ModelTier("gpt-4o", "gpt-4o", 4096, 30000, "high", 0.03),
        ModelTier("deepseek-r1", "deepseek-reasoner", 4096, 45000, "high", 0.01),
    ],
    "standard": [
        ModelTier("glm-5", "glm-5", 4096, 25000, "standard", 0.005),
        ModelTier("qwen-plus", "qwen-plus", 4096, 25000, "standard", 0.008),
    ],
    "fast": [
        ModelTier("gpt-4o-mini", "gpt-4o-mini", 2048, 15000, "fast", 0.001),
        ModelTier("qwen-turbo", "qwen-turbo", 2048, 15000, "fast", 0.002),
    ],
}


class AIDegradationManager:
    """AI 服务降级管理器"""
    
    def __init__(self):
        self.circuits = {
            "llm_primary": circuit_registry["llm_primary"],
            "llm_fallback": circuit_registry["llm_fallback"],
        }
    
    async def chat(
        self,
        messages: list[dict],
        subject: str = None,
        use_rag: bool = True,
        stream: bool = True,
        **kwargs,
    ) -> AsyncGenerator:
        """
        执行 AI 对话，自动降级
        
        降级优先级：
        1. 主力模型（高质量）
        2. 备用模型（标准）
        3. 轻量模型（快速） + 跳过 RAG
        4. 缓存匹配
        5. 友好提示
        """
        # Tier 1: 高质量模型
        for tier in MODEL_TIERS["high"]:
            result = await self._try_model(
                tier, messages, use_rag=use_rag, stream=stream, **kwargs
            )
            if result is not None:
                return result
        
        # Tier 2: 标准模型
        for tier in MODEL_TIERS["standard"]:
            result = await self._try_model(
                tier, messages, use_rag=use_rag, stream=stream, **kwargs
            )
            if result is not None:
                return result
        
        # Tier 3: 轻量模型 + 跳过 RAG
        for tier in MODEL_TIERS["fast"]:
            result = await self._try_model(
                tier, messages, use_rag=False, stream=stream,
                notice="⚠️ 当前为简化模式，回答可能不够详细", **kwargs
            )
            if result is not None:
                return result
        
        # Tier 4: 缓存匹配
        cached = await self._search_similar_answer(messages[-1]["content"], subject)
        if cached:
            return self._wrap_cached_response(cached)
        
        # Tier 5: 无法回答
        raise AppException(
            code=ErrorCode.AI_MODEL_ERROR,
            message="AI 助手暂时忙碌，请稍等 1-2 分钟再试",
            http_status=503,
            fallback_action=FallbackAction.RETRY_LATER,
            retry_after_ms=60000,
        )
    
    async def _try_model(
        self,
        tier: ModelTier,
        messages: list[dict],
        use_rag: bool = True,
        stream: bool = True,
        notice: str = None,
        **kwargs,
    ) -> Optional[AsyncGenerator]:
        """尝试调用指定模型"""
        circuit = self.circuits.get("llm_primary")
        try:
            async def _call():
                return await llm_client.chat_stream(
                    model=tier.model_id,
                    messages=messages,
                    max_tokens=tier.max_tokens,
                    timeout_ms=tier.timeout_ms,
                    stream=stream,
                )
            
            result = await circuit.call(
                _call,
                fallback=None,  # 不在熔断器内降级，由上层管理器控制
            )
            
            if notice:
                # 注入降级提示
                yield {"type": "notice", "content": notice}
            async for chunk in result:
                yield chunk
            return
            
        except CircuitOpenError:
            logger.warning("model_circuit_open", model=tier.model_id)
            return None
        except (TimeoutError, ModelServerError) as e:
            logger.warning("model_call_failed", model=tier.model_id, error=str(e))
            return None
    
    async def _search_similar_answer(self, query: str, subject: str = None) -> Optional[dict]:
        """搜索历史高质量回答作为降级响应"""
        try:
            results = await search_service.search(
                query=query,
                index="ai_quality_answers",
                filters={"subject": subject, "user_rating": {"$gte": 3}},
                limit=1,
                min_score=0.85,
            )
            if results:
                return results[0]
        except Exception:
            pass
        return None
    
    def _wrap_cached_response(self, cached: dict) -> dict:
        """包装缓存回答"""
        return {
            "type": "cached",
            "content": cached["content"],
            "disclaimer": "这是一条参考回答，非实时生成",
            "source_message_id": cached["message_id"],
        }
```

```dart
class ApiFailure<T> extends ApiResult<T> {
  final String code;          // 错误码: AI.MODEL.TIMEOUT_01
  final String message;       // 用户可读消息
  final String? traceId;
  final FallbackSuggestion? suggestion;
  
  const ApiFailure({
    required this.code,
    required this.message,
    this.traceId,
    this.suggestion,
  });
  
  /// 是否可重试
  bool get canRetry => suggestion?.action == FallbackAction.retry 
                    || suggestion?.action == FallbackAction.retryWithFallback
                    || suggestion?.action == FallbackAction.retryLater;
  
  /// 是否需要重新登录
  bool get needsReLogin => code == 'COMMON.AUTH.TOKEN_INVALID';
  
  /// 是否需要升级会员
  bool get needsUpgrade => code == 'PAY.SUB.QUOTA_EXCEEDED' 
                        || code == 'COMMON.AUTH.FORBIDDEN';
}

class FallbackSuggestion {
  final FallbackAction action;
  final Map<String, dynamic>? params;
  final int? retryAfterMs;
  
  const FallbackSuggestion({
    required this.action,
    this.params,
    this.retryAfterMs,
  });
  
  factory FallbackSuggestion.fromJson(Map<String, dynamic> json) {
    return FallbackSuggestion(
      action: FallbackAction.values.firstWhere(
        (a) => a.value == json['action'],
        orElse: () => FallbackAction.retryLater,
      ),
      params: json['fallback_model'] != null 
          ? {'fallback_model': json['fallback_model']} 
          : null,
      retryAfterMs: json['retry_after_ms'],
    );
  }
}

enum FallbackAction {
  retry('retry'),
  retryWithFallback('retry_with_fallback'),
  retryLater('retry_later'),
  useCache('use_cache'),
  redirect('redirect'),
  manualInput('manual_input');
  
  const FallbackAction(this.value);
  final String value;
}
```

### 7.2 Dio 拦截器：自动错误处理

```dart
// lib/core/network/error_interceptor.dart

class ErrorInterceptor extends Interceptor {
  final TokenRefreshService _tokenRefresh;
  final ErrorReporter _errorReporter;
  
  ErrorInterceptor(this._tokenRefresh, this._errorReporter);

  @override
  void onError(DioException err, ErrorInterceptorHandler handler) async {
    final traceId = err.response?.headers.value('X-Trace-Id') ?? 'unknown';
    
    // 1. Token 过期自动刷新
    if (_isTokenExpired(err)) {
      try {
        final newToken = await _tokenRefresh.refresh();
        // 用新 Token 重试
        final options = err.requestOptions;
        options.headers['Authorization'] = 'Bearer $newToken';
        final response = await Dio().fetch(options);
        return handler.resolve(response);
      } catch (_) {
        // 刷新失败，跳转登录
        return handler.reject(_toAuthError(err, traceId));
      }
    }
    
    // 2. 解析服务端统一错误响应
    if (err.response?.data != null) {
      try {
        final errorData = err.response!.data['error'] as Map<String, dynamic>;
        final apiFailure = ApiFailure(
          code: errorData['code'] as String? ?? 'COMMON.INTERNAL.UNKNOWN',
          message: errorData['message'] as String? ?? '网络异常，请稍后重试',
          traceId: errorData['trace_id'] as String? ?? traceId,
          suggestion: errorData['suggestion'] != null
              ? FallbackSuggestion.fromJson(errorData['suggestion'] as Map<String, dynamic>)
              : null,
        );
        return handler.reject(_customDioError(err, apiFailure));
      } catch (_) {
        // 响应解析失败，走兜底逻辑
      }
    }
    
    // 3. 网络层错误映射
    final apiFailure = _mapNetworkError(err, traceId);
    _errorReporter.report(apiFailure);
    handler.reject(_customDioError(err, apiFailure));
  }
  
  ApiFailure _mapNetworkError(DioException err, String traceId) {
    switch (err.type) {
      case DioExceptionType.connectionTimeout:
      case DioExceptionType.sendTimeout:
      case DioExceptionType.receiveTimeout:
        return ApiFailure(
          code: 'COMMON.NETWORK.TIMEOUT',
          message: '网络连接超时，请检查网络后重试',
          traceId: traceId,
          suggestion: const FallbackSuggestion(action: FallbackAction.retry),
        );
      case DioExceptionType.connectionError:
        return ApiFailure(
          code: 'COMMON.NETWORK.NO_CONNECTION',
          message: '网络不可用，请检查网络设置',
          traceId: traceId,
          suggestion: const FallbackSuggestion(action: FallbackAction.useCache),
        );
      default:
        return ApiFailure(
          code: 'COMMON.NETWORK.UNKNOWN',
          message: '网络异常，请稍后重试',
          traceId: traceId,
          suggestion: const FallbackSuggestion(action: FallbackAction.retryLater),
        );
    }
  }
}
```

### 7.4 AI 对话场景的降级 UX

AI 对话场景是最核心的场景，需要特殊的降级交互设计：

| 降级级别 | UI 表现 | 用户感知 |
|----------|---------|----------|
| 主力模型正常 | 正常流式输出 | 无感知 |
| 降级到备用模型 | 正常输出，消息栏显示 `· 使用备用模型` | 几乎无感知 |

## 8. 错误监控与告警集成

### 8.1 错误分级与告警规则

| 级别 | 触发条件 | 通知方式 | 响应时间 |
|------|---------|---------|---------|
| **P0-Critical** | 核心服务全量不可用 > 2min | 电话 + 短信 + 飞书群 | ≤ 5min |
| **P1-High** | 单服务错误率 > 10% 持续 5min | 短信 + 飞书群 | ≤ 15min |
| **P2-Medium** | 第三方服务降级（非主力模型熔断） | 飞书群 | ≤ 30min |
| **P3-Low** | 客户端异常率上升 > 基线 50% | 飞书群（汇总） | 次工作日 |

## 9. 数据库错误处理

### 9.1 数据库异常分类与处理

| 异常类型 | 场景 | 处理策略 |
|----------|------|----------|
| 连接池耗尽 | 高并发时所有连接被占用 | 等待 3s + 重试，超限则 503 |
| 死锁 | 并发更新同一行 | 检测死锁 → 自动重试（最多 3 次） |
| 唯一键冲突 | 重复插入（如重复点赞、重复订单） | 捕获 → 返回幂等成功 |
| 外键约束失败 | 关联数据不存在 | 返回 400 + 具体字段提示 |
| 查询超时 | 慢查询（复杂学情统计） | 1. 添加超时限制 30s<br>2. 超时降级为预计算结果<br>3. 记录慢查询日志 |
| 主从延迟 | 读到旧数据 | 学习记录等强一致场景强制走主库 |

### 9.2 数据库操作模板

```python
from sqlalchemy.exc import OperationalError, IntegrityError
from contextlib import asynccontextmanager

@asynccontextmanager
async def db_operation(session, max_retries=3):
    """数据库操作上下文管理器，自动处理连接异常和重试"""
    retries = 0
    while True:
        try:
            yield session
            await session.commit()
            return
        except IntegrityError as e:
            await session.rollback()
            # 唯一键冲突 → 幂等处理
            if "Duplicate entry" in str(e):
                logger.info("duplicate_entry_ignored", error=str(e))
                return  # 视为成功
            raise BusinessException(
                code=ErrorCode.PARAM_INVALID,
                message="数据冲突，请刷新后重试",
                http_status=409,
            )
        except OperationalError as e:
            await session.rollback()
            retries += 1
            if retries >= max_retries:
                logger.error("db_operation_exhausted", retries=retries, error=str(e))
                raise AppException(
                    code=ErrorCode.INTERNAL_ERROR,
                    message="服务繁忙，请稍后重试",
                    http_status=503,
                    fallback_action=FallbackAction.RETRY_LATER,
                )
            logger.warning("db_operation_retry", retries=retries, error=str(e))
            await asyncio.sleep(0.5 * retries)
        except Exception as e:
            await session.rollback()
            logger.error("db_unexpected_error", error=str(e))
            raise
```
