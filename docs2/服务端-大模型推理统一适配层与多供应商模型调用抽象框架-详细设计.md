# 服务端-大模型推理统一适配层与多供应商模型调用抽象框架-详细设计

## 1. 概述

### 1.1 功能定位

大模型推理统一适配层（LLM Unified Adapter Layer，简称 **UAL**）是 PrimeTop AI 能力层的核心基础设施模块，位于上层 AI 业务服务（辅导对话、解题推理、作文批改等）与底层大模型供应商 API（OpenAI、Anthropic、Google、通义千问、DeepSeek 等）之间。

**核心职责：**
- 屏蔽不同 LLM 供应商 API 的协议差异，为上层业务提供统一调用接口
- 统一管理多供应商模型的请求路由、负载均衡与健康状态
- 标准化流式输出（SSE）与非流式响应的处理流程
- 统一 Token 计数、用量上报与成本追踪
- 提供供应商级别的限流、熔断与自动降级能力
- 支持灰度发布、A/B 测试与模型快速切换

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 新供应商接入耗时 | ≤ 2 人天（仅需实现 Adapter 接口） |
| 接口响应延迟开销 | 适配层自身耗时 < 5ms |
| 流式首 Token 透传延迟 | < 10ms |
| 供应商故障切换时间 | < 30s（含健康检测） |
| 统一接口向后兼容 | Minor 版本变更不影响已有调用方 |

### 1.3 适用范围

- 所有需要调用大语言模型的业务场景
- 包括但不限于：AI 辅导对话、解题步骤推导、作文批改、内容审核、RAG 检索生成、Prompt 编排系统
- 不包括：OCR 识别、ASR/TTS 语音服务（有独立适配层）

### 1.4 术语定义

| 术语 | 说明 |
| --- | --- |
| Provider | 大模型供应商（如 OpenAI、Anthropic） |
| Model | 供应商提供的具体模型（如 gpt-4o、claude-3.5-sonnet） |
| Adapter | 针对特定供应商的适配器实现 |
| Channel | 一个 Provider + Model + 配置（API Key、Endpoint）的组合 |
| Route | 请求从进入到选择 Channel 的路由决策过程 |

### 5.3 路由决策核心代码

```java
@Service
public class ModelRouter {

    @Autowired
    private ChannelConfigRepository channelConfigRepo;
    @Autowired
    private ModelRegistryRepository modelRegistryRepo;
    @Autowired
    private ChannelHealthManager healthManager;
    @Autowired
    private RateLimitChecker rateLimitChecker;
    @Autowired
    private SceneRouteConfigRepository sceneRouteConfigRepo;

    /**
     * 路由决策：根据请求选择最优 Channel
     */
    public Channel route(UnifiedChatRequest request) {
        // Step 1: 指定模型直接路由
        if (StringUtils.isNotBlank(request.get指定ModelId())) {
            Channel channel = channelConfigRepo.findByModelId(request.get指定ModelId())
                .stream()
                .filter(c -> c.isEnabled() && healthManager.isHealthy(c.getChannelId()))
                .filter(c -> rateLimitChecker.check(c.getChannelId()))
                .findFirst()
                .orElseThrow(() -> new ChannelUnavailableException(
                    "指定模型 " + request.get指定ModelId() + " 无可用 Channel"));
            return channel;
        }

        // Step 2: 场景匹配获取候选
        List<String> candidateModelIds = sceneRouteConfigRepo
            .findCandidateModels(request.getScene());

        // Step 3: 构建候选 Channel 列表
        List<Channel> candidates = candidateModelIds.stream()
            .flatMap(modelId -> channelConfigRepo.findByModelId(modelId).stream())
            .filter(Channel::isEnabled)
            .filter(c -> matchesUserGroup(c, request.getUserContext()))
            .filter(c -> matchesSceneFilter(c, request.getScene()))
            .filter(c -> matchesCapabilities(c, request))
            .filter(c -> healthManager.isHealthy(c.getChannelId()))
            .filter(c -> rateLimitChecker.check(c.getChannelId()))
            .collect(Collectors.toList());

        if (candidates.isEmpty()) {
            throw new NoAvailableChannelException(
                "场景 " + request.getScene() + " 无可用 Channel");
        }

        // Step 4: 按优先级分组，加权随机选择
        return selectByPriorityAndWeight(candidates);
    }

    private Channel selectByPriorityAndWeight(List<Channel> candidates) {
        // 按优先级分组
        Map<Integer, List<Channel>> byPriority = candidates.stream()
            .collect(Collectors.groupingBy(Channel::getPriority));

        // 从最高优先级（最小数字）开始
        List<Integer> priorities = new ArrayList<>(byPriority.keySet());
        Collections.sort(priorities);

        for (int priority : priorities) {
            List<Channel> group = byPriority.get(priority);
            // 加权随机选择
            Channel selected = weightedRandomSelect(group);
            if (selected != null) {
                return selected;
            }
        }

        throw new NoAvailableChannelException("所有候选 Channel 均不可用");
    }

    private Channel weightedRandomSelect(List<Channel> channels) {
        int totalWeight = channels.stream()
            .mapToInt(Channel::getWeight)
            .sum();
        if (totalWeight <= 0) return null;

        int random = ThreadLocalRandom.current().nextInt(totalWeight);
        int cumulative = 0;
        for (Channel ch : channels) {
            cumulative += ch.getWeight();
            if (random < cumulative) {
                return ch;
            }
        }
        return channels.get(channels.size() - 1);
    }

    private boolean matchesCapabilities(Channel channel, UnifiedChatRequest request) {
        ModelRegistry model = modelRegistryRepo.findByProviderAndModelId(
            channel.getProvider(), channel.getModelId());

        if (request.getMessages().stream()
            .flatMap(m -> m.getParts() == null ? Stream.empty() : m.getParts().stream())
            .anyMatch(p -> p.getType() == ContentType.IMAGE_URL
                        || p.getType() == ContentType.IMAGE_BASE64)) {
            if (model.getSupportsVision() != 1) return false;
        }

        if (request.getTools() != null && !request.getTools().isEmpty()) {
            if (model.getSupportsToolCalling() != 1) return false;
        }

        if (request.getParams() != null
            && request.getParams().getResponseFormat() == ResponseFormat.JSON_SCHEMA
            && model.getSupportsJsonMode() != 1) {
            return false;
        }

        return true;
    }

    // ... 其他辅助方法
}
```

### 6.2 抽象基类

```java
public abstract class AbstractProviderAdapter implements ProviderAdapter {

    @Autowired
    protected HttpClient httpClient;
    @Autowired
    protected ObjectMapper objectMapper;
    @Autowired
    protected UsageReporter usageReporter;
    @Autowired
    protected TokenCounter tokenCounter;

    /**
     * 构建供应商特定的 HTTP 请求
     */
    protected abstract HttpRequest buildHttpRequest(
        UnifiedChatRequest request, Channel channel) throws Exception;

    /**
     * 解析供应商响应为统一格式
     */
    protected abstract UnifiedChatResponse parseResponse(
        String rawResponse, UnifiedChatRequest request, Channel channel) throws Exception;

    /**
     * 解析供应商流式响应行为统一 StreamEvent
     */
    protected abstract UnifiedStreamEvent parseStreamLine(
        String line, StreamParseContext ctx) throws Exception;

    /**
     * 提取供应商返回的 Token 用量
     */
    protected abstract UnifiedUsage extractUsage(Object rawResponse) throws Exception;

    /**
     * 转换供应商错误码为统一错误
     */
    protected abstract UnifiedError translateError(
        int statusCode, String errorBody) throws Exception;

    /**
     * 通用同步调用实现（子类通常不需要重写）
     */
    @Override
    public UnifiedChatResponse invoke(UnifiedChatRequest request, Channel channel)
            throws ProviderException {

        long startTime = System.currentTimeMillis();
        String requestId = request.getRequestId();

        try {
            HttpRequest httpRequest = buildHttpRequest(request, channel);
            HttpResponse<String> response = httpClient.send(httpRequest,
                HttpResponse.BodyHandlers.ofString());

            int statusCode = response.statusCode();

            if (statusCode >= 200 && statusCode < 300) {
                UnifiedChatResponse unified = parseResponse(response.body(), request, channel);
                unified.setLatencyMs(System.currentTimeMillis() - startTime);

                // 异步上报用量
                usageReporter.reportAsync(requestId, channel, unified.getUsage());

                return unified;
            } else {
                UnifiedError error = translateError(statusCode, response.body());
                throw new ProviderException(error);
            }
        } catch (ProviderException e) {
            throw e;
        } catch (Exception e) {
            throw new ProviderException(
                UnifiedError.networkError(getProviderId(), e.getMessage(), requestId), e);
        }
    }

    /**
     * 通用流式调用实现
     */
    @Override
    public Flux<UnifiedStreamEvent> invokeStream(UnifiedChatRequest request, Channel channel)
            throws ProviderException {

        String requestId = request.getRequestId();
        StreamParseContext ctx = new StreamParseContext(requestId);

        return Flux.create(sink -> {
            CompletableFuture.runAsync(() -> {
                try {
                    HttpRequest httpRequest = buildHttpRequest(request, channel);
                    HttpResponse<java.io.InputStream> response = httpClient.send(
                        httpRequest, HttpResponse.BodyHandlers.ofInputStream());

                    if (response.statusCode() != 200) {
                        String errorBody = new String(response.body().readAllBytes());
                        UnifiedError error = translateError(response.statusCode(), errorBody);
                        sink.next(UnifiedStreamEvent.error(error));
                        sink.complete();
                        return;
                    }

                    try (BufferedReader reader = new BufferedReader(
                            new InputStreamReader(response.body()))) {
                        String line;
                        while ((line = reader.readLine()) != null) {
                            if (line.isEmpty()) continue;
                            UnifiedStreamEvent event = parseStreamLine(line, ctx);
                            if (event != null) {
                                sink.next(event);
                            }
                        }
                    }
                    sink.complete();
                } catch (Exception e) {
                    sink.next(UnifiedStreamEvent.networkError(
                        getProviderId(), e.getMessage(), requestId));
                    sink.complete();
                }
            });
        });
    }
}
```

```java
@Component
public class OpenAIAdapter extends AbstractProviderAdapter {

    private static final String PROVIDER_ID = "openai";
    private static final String DEFAULT_BASE_URL = "https://api.openai.com/v1";

    @Override
    public String getProviderId() {
        return PROVIDER_ID;
    }

    @Override
    protected HttpRequest buildHttpRequest(UnifiedChatRequest request, Channel channel)
            throws Exception {

        String url = channel.getBaseUrl() + "/chat/completions";

        // 构建请求体
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("model", channel.getModelId());

        // 消息转换
        List<Map<String, Object>> messages = request.getMessages().stream()
            .map(this::convertMessage)
            .collect(Collectors.toList());
        body.put("messages", messages);

        // 参数映射
        UnifiedModelParams params = request.getParams();
        if (params != null) {
            if (params.getTemperature() != null)
                body.put("temperature", params.getTemperature());
            if (params.getMaxTokens() != null)
                body.put("max_tokens", params.getMaxTokens());
            if (params.getTopP() != null)
                body.put("top_p", params.getTopP());
            if (params.getFrequencyPenalty() != null)
                body.put("frequency_penalty", params.getFrequencyPenalty());
            if (params.getPresencePenalty() != null)
                body.put("presence_penalty", params.getPresencePenalty());
            if (params.getStop() != null && !params.getStop().isEmpty())
                body.put("stop", params.getStop().size() == 1
                    ? params.getStop().get(0) : params.getStop());
            if (params.getSeed() != null)
                body.put("seed", params.getSeed());

            // 响应格式
            if (params.getResponseFormat() != null) {
                switch (params.getResponseFormat()) {
                    case JSON_OBJECT:
                        body.put("response_format",
                            Map.of("type", "json_object"));
                        break;
                    case JSON_SCHEMA:
                        body.put("response_format", Map.of(
                            "type", "json_schema",
                            "json_schema", Map.of(
                                "name", "response",
                                "schema", objectMapper.readTree(params.getJsonSchema()),
                                "strict", true
                            )
                        ));
                        break;
                    default:
                        break;
                }
            }
        }

        // 工具调用
        if (request.getTools() != null && !request.getTools().isEmpty()) {
            body.put("tools", request.getTools().stream()
                .map(this::convertTool)
                .collect(Collectors.toList()));
        }

        body.put("stream", request.isStream());

        String jsonBody = objectMapper.writeValueAsString(body);

        return HttpRequest.newBuilder()
            .uri(URI.create(url))
            .header("Content-Type", "application/json")
            .header("Authorization", "Bearer " + channel.getDecryptedApiKey())
            .header("X-Request-Id", request.getRequestId())
            .POST(HttpRequest.BodyPublishers.ofString(jsonBody))
            .timeout(Duration.ofSeconds(120))
            .build();
    }

    @Override
    protected UnifiedChatResponse parseResponse(String rawResponse,
            UnifiedChatRequest request, Channel channel) throws Exception {

        JsonNode root = objectMapper.readTree(rawResponse);
        JsonNode choices = root.path("choices").get(0);
        JsonNode message = choices.path("message");

        UnifiedChatResponse response = new UnifiedChatResponse();
        response.setRequestId(request.getRequestId());

        ChannelInfo channelInfo = new ChannelInfo();
        channelInfo.setChannelId(channel.getChannelId());
        channelInfo.setProvider(channel.getProvider());
        channelInfo.setModelId(channel.getModelId());
        response.setChannel(channelInfo);

        UnifiedMessage msg = new UnifiedMessage();
        msg.setRole(UnifiedRole.ASSISTANT);
        msg.setContent(message.path("content").asText(""));

        // 工具调用解析
        if (message.has("tool_calls")) {
            List<UnifiedToolCall> toolCalls = new ArrayList<>();
            for (JsonNode tc : message.path("tool_calls")) {
                UnifiedToolCall call = new UnifiedToolCall();
                call.setId(tc.path("id").asText());
                call.setName(tc.path("function").path("name").asText());
                call.setArguments(tc.path("function").path("arguments").asText());
                toolCalls.add(call);
            }
            msg.setToolCalls(toolCalls);
        }
        response.setChoices(msg);

        // 完成原因
        String finishReason = choices.path("finish_reason").asText("stop");
        response.setFinishReason(mapFinishReason(finishReason));

        // Token 用量
        response.setUsage(extractUsage(root));

        response.setProviderResponseId(root.path("id").asText());

        return response;
    }

    @Override
    protected UnifiedStreamEvent parseStreamLine(String line, StreamParseContext ctx)
            throws Exception {

        // OpenAI SSE 格式: data: {json}
        if (!line.startsWith("data: ")) return null;
        String data = line.substring(6);

        if ("[DONE]".equals(data)) {
            // 发送 USAGE 事件（如果有累积的用量）
            UnifiedStreamEvent event = new UnifiedStreamEvent();
            event.setType(StreamEventType.FINISH);
            event.setFinishReason(ctx.getLastFinishReason());
            return event;
        }

        JsonNode root = objectMapper.readTree(data);
        JsonNode choices = root.path("choices").get(0);
        JsonNode delta = choices.path("delta");

        // 文本增量
        if (delta.has("content") && !delta.path("content").asText("").isEmpty()) {
            UnifiedStreamEvent event = new UnifiedStreamEvent();
            event.setType(StreamEventType.DELTA_TEXT);
            event.setDeltaText(delta.path("content").asText());
            return event;
        }

        // 工具调用增量
        if (delta.has("tool_calls")) {
            UnifiedStreamEvent event = new UnifiedStreamEvent();
            event.setType(StreamEventType.DELTA_TOOL_CALL);
            JsonNode tc = delta.path("tool_calls").get(0);
            UnifiedToolCall call = new UnifiedToolCall();
            if (tc.has("id")) call.setId(tc.path("id").asText());
            if (tc.has("function")) {
                JsonNode fn = tc.path("function");
                if (fn.has("name")) call.setName(fn.path("name").asText());
                if (fn.has("arguments")) call.setArguments(fn.path("arguments").asText());
            }
            event.setDeltaToolCall(call);
            return event;
        }

        // 完成原因
        String finishReason = choices.path("finish_reason").asText(null);
        if (finishReason != null) {
            ctx.setLastFinishReason(mapFinishReason(finishReason));
        }

        return null;
    }

    @Override
    protected UnifiedUsage extractUsage(Object rawResponse) throws Exception {
        JsonNode root = (rawResponse instanceof JsonNode)
            ? (JsonNode) rawResponse
            : objectMapper.readTree((String) rawResponse);

        JsonNode usage = root.path("usage");
        UnifiedUsage result = new UnifiedUsage();
        result.setPromptTokens(usage.path("prompt_tokens").asInt(0));
        result.setCompletionTokens(usage.path("completion_tokens").asInt(0));
        result.setTotalTokens(usage.path("total_tokens").asInt(0));

        // Prompt caching (OpenAI specific)
        JsonNode cachedTokens = usage.path("prompt_tokens_details")
            .path("cached_tokens");
        if (!cachedTokens.isMissingNode()) {
            result.setCachedTokens(cachedTokens.asInt(0));
        }

        result.setSource(TokenCountSource.PROVIDER_RETURNED);
        return result;
    }

    @Override
    protected UnifiedError translateError(int statusCode, String errorBody) {
        try {
            JsonNode root = objectMapper.readTree(errorBody);
            JsonNode error = root.path("error");
            String errorCode = error.path("type").asText("unknown");
            String message = error.path("message").asText("Unknown OpenAI error");

            UnifiedError unified = new UnifiedError();
            unified.setProvider(PROVIDER_ID);
            unified.setProviderErrorCode(errorCode);
            unified.setMessage(message);

            switch (statusCode) {
                case 401:
                    unified.setErrorType(ErrorType.AUTH_INVALID);
                    unified.setRetryable(false);
                    break;
                case 429:
                    unified.setErrorType(ErrorType.RATE_LIMITED);
                    unified.setRetryable(true);
                    unified.setRetryAfterMs(5000);
                    break;
                case 500:
                case 502:
                case 503:
                    unified.setErrorType(ErrorType.PROVIDER_ERROR);
                    unified.setRetryable(true);
                    unified.setRetryAfterMs(2000);
                    break;
                case 400:
                    unified.setErrorType(ErrorType.INVALID_REQUEST);
                    unified.setRetryable(false);
                    break;
                default:
                    unified.setErrorType(ErrorType.UNKNOWN);
                    unified.setRetryable(false);
            }
            return unified;
        } catch (Exception e) {
            return UnifiedError.unknown(PROVIDER_ID, "Failed to parse error: " + errorBody);
        }
    }

    @Override
    public TokenEstimate estimateTokens(UnifiedChatRequest request, String modelId) {
        // OpenAI 使用 tiktoken 算法（通过本地 tiktoken 库或服务预估）
        int estimated = tokenCounter.estimateTiktoken(request.getMessages(), modelId);
        return TokenEstimate.estimated(estimated);
    }

    @Override
    public HealthStatus healthCheck(Channel channel) {
        try {
            // 轻量级 models 接口检查
            HttpRequest req = HttpRequest.newBuilder()
                .uri(URI.create(channel.getBaseUrl() + "/models"))
                .header("Authorization", "Bearer " + channel.getDecryptedApiKey())
                .timeout(Duration.ofSeconds(10))
                .GET().build();

                HttpResponse.BodyHandlers.ofString());
            return resp.statusCode() == 200
                ? HealthStatus.HEALTHY
                : HealthStatus.DEGRADED;
        } catch (Exception e) {
            return HealthStatus.UNHEALTHY;
        }
    }

    @Override
    public Set<ModelCapability> getCapabilities(String modelId) {
        // 从 model_registry 表查询，这里做内存缓存
        return CapabilityCache.get(PROVIDER_ID, modelId);
    }

    // ===== 内部转换方法 =====

    private Map<String, Object> convertMessage(UnifiedMessage msg) {
        Map<String, Object> map = new LinkedHashMap<>();
        map.put("role", msg.getRole().name().toLowerCase());

        if (msg.getParts() != null && !msg.getParts().isEmpty()) {
            // 多模态消息
            List<Map<String, Object>> contentParts = msg.getParts().stream()
                .map(this::convertContentPart)
                .collect(Collectors.toList());
            map.put("content", contentParts);
        } else {
            map.put("content", msg.getContent() != null ? msg.getContent() : "");
        }

        if (msg.getToolCalls() != null) {
            map.put("tool_calls", msg.getToolCalls().stream()
                .map(tc -> Map.of(
                    "id", tc.getId(),
                    "type", "function",
                    "function", Map.of(
                        "name", tc.getName(),
                        "arguments", tc.getArguments()
                    )
                ))
                .collect(Collectors.toList()));
        }

        if (msg.getToolCallId() != null) {
            map.put("tool_call_id", msg.getToolCallId());
        }

        return map;
    }

    private Map<String, Object> convertContentPart(UnifiedContentPart part) {
        Map<String, Object> map = new LinkedHashMap<>();
        switch (part.getType()) {
            case TEXT:
                map.put("type", "text");
                map.put("text", part.getText());
                break;
            case IMAGE_URL:
                map.put("type", "image_url");
                map.put("image_url", Map.of("url", part.getImageUrl()));
                break;
            case IMAGE_BASE64:
                String dataUrl = "data:" + part.getImageMimeType()
                    + ";base64," + part.getImageBase64();
                map.put("type", "image_url");
                map.put("image_url", Map.of("url", dataUrl));
                break;
            default:
                map.put("type", "text");
                map.put("text", "[Unsupported content type]");
        }
        return map;
    }

    private Map<String, Object> convertTool(UnifiedTool tool) {
        return Map.of(
            "type", "function",
            "function", Map.of(
                "name", tool.getName(),
                "description", tool.getDescription(),
                "parameters", tool.getParametersJson()
            )
        );
    }

    private FinishReason mapFinishReason(String openaiReason) {
        switch (openaiReason) {
            case "stop": return FinishReason.STOP;
            case "length": return FinishReason.LENGTH;
            case "tool_calls": return FinishReason.TOOL_CALLS;
            case "content_filter": return FinishReason.CONTENT_FILTER;
            default: return FinishReason.STOP;
        }
    }
```

### 6.4 Anthropic Claude 适配器实现要点

Claude 的 API 与 OpenAI 有显著差异，适配器需要处理以下差异：

```java
@Component
public class AnthropicAdapter extends AbstractProviderAdapter {

    private static final String PROVIDER_ID = "anthropic";
    private static final String DEFAULT_BASE_URL = "https://api.anthropic.com";
    private static final String API_VERSION = "2023-06-01";

    @Override
    protected HttpRequest buildHttpRequest(UnifiedChatRequest request, Channel channel)
            throws Exception {

        String url = channel.getBaseUrl() + "/v1/messages";

        Map<String, Object> body = new LinkedHashMap<>();
        body.put("model", channel.getModelId());
        body.put("max_tokens", request.getParams() != null
            && request.getParams().getMaxTokens() != null
            ? request.getParams().getMaxTokens() : 4096);

        if (request.getParams() != null) {
            if (request.getParams().getTemperature() != null)
                body.put("temperature", request.getParams().getTemperature());
            if (request.getParams().getTopP() != null)
                body.put("top_p", request.getParams().getTopP());
            if (request.getStop() != null && !request.getStop().isEmpty())
                body.put("stop_sequences", request.getStop());
        }

        // Claude 特殊处理：system message 提取到顶层
        List<Map<String, Object>> messages = new ArrayList<>();
        String systemContent = null;
        for (UnifiedMessage msg : request.getMessages()) {
            if (msg.getRole() == UnifiedRole.SYSTEM) {
                systemContent = msg.getContent();
            } else {
                messages.add(convertClaudeMessage(msg));
            }
        }
        if (systemContent != null) {
            body.put("system", systemContent);
        }
        body.put("messages", messages);

        body.put("stream", request.isStream());

        String jsonBody = objectMapper.writeValueAsString(body);

        return HttpRequest.newBuilder()
            .uri(URI.create(url))
            .header("Content-Type", "application/json")
            .header("x-api-key", channel.getDecryptedApiKey())
            .header("anthropic-version", API_VERSION)
            .header("X-Request-Id", request.getRequestId())
            .POST(HttpRequest.BodyPublishers.ofString(jsonBody))
            .timeout(Duration.ofSeconds(120))
            .build();
    }

    @Override
    protected UnifiedStreamEvent parseStreamLine(String line, StreamParseContext ctx)
            throws Exception {

        // Claude SSE 格式: event: xxx\ndata: {json}
        if (!line.startsWith("data: ")) return null;
        String data = line.substring(6);
        JsonNode root = objectMapper.readTree(data);
        String type = root.path("type").asText();

        switch (type) {
            case "content_block_delta":
                JsonNode delta = root.path("delta");
                if ("text_delta".equals(delta.path("type").asText())) {
                    UnifiedStreamEvent event = new UnifiedStreamEvent();
                    event.setType(StreamEventType.DELTA_TEXT);
                    event.setDeltaText(delta.path("text").asText());
                    return event;
                }
                break;

            case "message_delta":
                JsonNode usage = root.path("usage");
                if (!usage.isMissingNode()) {
                    ctx.setCompletionTokens(usage.path("output_tokens").asInt(0));
                }
                JsonNode stopReason = root.path("delta").path("stop_reason");
                if (!stopReason.isMissingNode() && !stopReason.asText("").isEmpty()) {
                    ctx.setLastFinishReason(mapClaudeFinishReason(stopReason.asText()));
                }
                break;

            case "message_start":
                JsonNode inputUsage = root.path("message").path("usage");
                ctx.setInputTokens(inputUsage.path("input_tokens").asInt(0));
                break;

            case "message_stop":
                UnifiedStreamEvent event = new UnifiedStreamEvent();
                event.setType(StreamEventType.FINISH);
                event.setFinishReason(ctx.getLastFinishReason());
                // 附加用量
                UnifiedUsage finalUsage = new UnifiedUsage();
                finalUsage.setPromptTokens(ctx.getInputTokens());
                finalUsage.setCompletionTokens(ctx.getCompletionTokens());
                finalUsage.setTotalTokens(
                    ctx.getInputTokens() + ctx.getCompletionTokens());
                finalUsage.setSource(TokenCountSource.PROVIDER_RETURNED);
                event.setUsage(finalUsage);
                return event;
        }

        return null;
    }

    // Claude 消息格式与 OpenAI 的关键差异：
    // 1. System 消息不在 messages 数组中，而是顶层 system 字段
    // 2. 不支持 role 名为 "system" 在 messages 数组中
    // 3. content 可以是字符串或 content_blocks 数组
    // 4. 图片格式使用 source.type: "base64" 而非 image_url
    // 5. 工具调用使用 content blocks 而非 tool_calls 字段
    // 6. 流式事件使用 named events (content_block_delta, message_delta 等)

    private Map<String, Object> convertClaudeMessage(UnifiedMessage msg) {
        Map<String, Object> map = new LinkedHashMap<>();
        map.put("role", msg.getRole().name().toLowerCase());

        if (msg.getParts() != null && !msg.getParts().isEmpty()) {
            List<Map<String, Object>> blocks = msg.getParts().stream()
                .map(part -> {
                    if (part.getType() == ContentType.TEXT) {
                        return Map.of("type", "text", "text", part.getText());
                    } else if (part.getType() == ContentType.IMAGE_BASE64) {
                        return Map.of("type", "image",
                            "source", Map.of(
                                "type", "base64",
                                "media_type", part.getImageMimeType(),
                                "data", part.getImageBase64()
                            ));
                    }
```

## 7. Channel 健康管理与容灾

### 7.1 健康状态机

```
                    ┌──────────────┐
    初始状态  ──→    │   HEALTHY    │ ←── 健康检查成功
                    │   (正常服务)  │
                    └──────┬───────┘
                           │ 错误率 > 阈值
                           │ 或连续失败 ≥ 3 次
                           ▼
                    ┌──────────────┐
                    │   DEGRADED   │ ←── 部分错误但未完全不可用
                    │  (降级服务)   │     降低权重到 10%
                    └──────┬───────┘
                           │ 错误率持续升高
                           │ 或连续失败 ≥ 5 次
                           ▼
                    ┌──────────────┐
                    │ CIRCUIT_OPEN │ ←── 熔断状态
                    │  (暂停服务)   │     请求不路由到此 Channel
                    └──────┬───────┘
                           │ 等待冷却时间 (60s)
                           │ 进行半开探测
                           ▼
                    ┌──────────────┐
                    │ HALF_OPEN    │ ←── 半开状态
                    │  (探测阶段)   │     放行少量请求探测
                    └──────┬───────┘
                      探测成功 │ 探测失败
                   ┌─────────┴─────────┐
                   ▼                   ▼
            ┌──────────┐       ┌──────────────┐
            │ HEALTHY  │       │ CIRCUIT_OPEN │
            └──────────┘       └──────────────┘
```

### 7.2 健康管理器实现

```java
@Service
public class ChannelHealthManager {

    // 每个 Channel 的健康状态
    private final ConcurrentHashMap<String, HealthState> healthStates = new ConcurrentHashMap<>();

    // 滑动窗口统计（最近 60 秒）
    private final ConcurrentHashMap<String, SlidingWindowCounter> errorCounters
        = new ConcurrentHashMap<>();

    // 配置参数
    @Value("${ual.health.error-rate-threshold:0.3}")
    private double errorRateThreshold;          // 错误率阈值 30%

    @Value("${ual.health.consecutive-failure-threshold:3}")
    private int consecutiveFailureThreshold;     // 连续失败阈值

    @Value("${ual.health.circuit-open-duration-ms:60000}")
    private long circuitOpenDurationMs;          // 熔断持续时间 60s

    @Value("${ual.health.half-open-probe-count:3}")
    private int halfOpenProbeCount;              // 半开探测请求数

    @Value("${ual.health.health-check-interval-ms:300000}")
    private long healthCheckIntervalMs;          // 主动健康检查间隔 5min

    /**
     * 记录请求成功
     */
    public void recordSuccess(String channelId) {
        HealthState state = healthStates.computeIfAbsent(channelId,
            k -> new HealthState(ChannelStatus.ACTIVE));
        state.incrementSuccess();

        // HALF_OPEN 状态下探测成功 → 恢复
        if (state.getStatus() == ChannelStatus.HALF_OPEN) {
            state.incrementHalfOpenSuccess();
            if (state.getHalfOpenSuccess() >= halfOpenProbeCount / 2) {
                state.setStatus(ChannelStatus.ACTIVE);
                state.resetCounters();
            }
        }

        // DEGRADED 状态下恢复
        if (state.getStatus() == ChannelStatus.DEGRADED) {
            if (state.getConsecutiveSuccess() >= 10) {
                state.setStatus(ChannelStatus.ACTIVE);
                state.resetCounters();
            }
        }
    }

    /**
     * 记录请求失败
     */
    public void recordFailure(String channelId, UnifiedError error) {
        HealthState state = healthStates.computeIfAbsent(channelId,
            k -> new HealthState(ChannelStatus.ACTIVE));
        state.incrementFailure();

        SlidingWindowCounter counter = errorCounters.computeIfAbsent(channelId,
            k -> new SlidingWindowCounter(60)); // 60秒窗口

        counter.increment();

        // 不可重试的错误不触发熔断（如认证失败）
        if (!error.isRetryable()) return;

        switch (state.getStatus()) {
            case ACTIVE:
                // 检查是否需要降级或熔断
                double errorRate = counter.getErrorRate();
                if (state.getConsecutiveFailure() >= consecutiveFailureThreshold + 2
                        || errorRate >= errorRateThreshold * 1.5) {
                    state.setStatus(ChannelStatus.CIRCUIT_OPEN);
                    state.setCircuitOpenedAt(System.currentTimeMillis());
                } else if (state.getConsecutiveFailure() >= consecutiveFailureThreshold
                        || errorRate >= errorRateThreshold) {
                    state.setStatus(ChannelStatus.DEGRADED);
                }
                break;

            case DEGRADED:
                if (state.getConsecutiveFailure() >= consecutiveFailureThreshold + 2) {
                    state.setStatus(ChannelStatus.CIRCUIT_OPEN);
                    state.setCircuitOpenedAt(System.currentTimeMillis());
                }
                break;

            case HALF_OPEN:
                state.incrementHalfOpenFailure();
                if (state.getHalfOpenFailure() >= halfOpenProbeCount / 2 + 1) {
                    state.setStatus(ChannelStatus.CIRCUIT_OPEN);
                    state.setCircuitOpenedAt(System.currentTimeMillis());
                }
                break;
        }
    }

    /**
     * 检查 Channel 是否可用
     */
    public boolean isHealthy(String channelId) {
        HealthState state = healthStates.get(channelId);
        if (state == null) return true;

        ChannelStatus status = state.getStatus();

        // 熔断状态：检查是否应该转入半开
        if (status == ChannelStatus.CIRCUIT_OPEN) {
            long elapsed = System.currentTimeMillis() - state.getCircuitOpenedAt();
            if (elapsed >= circuitOpenDurationMs) {
                state.setStatus(ChannelStatus.HALF_OPEN);
                state.resetHalfOpenCounters();
                return true; // 允许探测请求
            }
            return false;
        }

        return status == ChannelStatus.ACTIVE || status == ChannelStatus.DEGRADED
               || status == ChannelStatus.HALF_OPEN;
    }

    /**
     * 获取 Channel 健康状态（含延迟、错误率等）
     */
    public ChannelHealth getHealth(String channelId) {
        HealthState state = healthStates.get(channelId);
        SlidingWindowCounter counter = errorCounters.get(channelId);

        ChannelHealth health = new ChannelHealth();
        health.setChannelId(channelId);
        health.setStatus(state != null ? state.getStatus() : ChannelStatus.ACTIVE);
        health.setErrorRate(counter != null ? counter.getErrorRate() : 0.0);
        health.setConsecutiveFailures(state != null ? state.getConsecutiveFailure() : 0);
        return health;
    }
}
```

### 7.3 滑动窗口计数器

```java
public class SlidingWindowCounter {

    private final BoundedDeque<Long> timestamps;
    private final long windowMs;

    public SlidingWindowCounter(long windowSeconds) {
        this.windowMs = windowSeconds * 1000;
        this.timestamps = new BoundedDeque<>(1000);
    }

    public synchronized void increment() {
        long now = System.currentTimeMillis();
        timestamps.addLast(now);
        evictOld(now);
    }

    public synchronized double getErrorRate() {
        long now = System.currentTimeMillis();
        evictOld(now);
        // 注意：这只是错误计数，需要和总请求数比较
        // 实际实现中需要同时维护 total 计数器
        return timestamps.size() > 0 ? 1.0 : 0.0; // 简化示例
    }

    private void evictOld(long now) {
        while (!timestamps.isEmpty() && now - timestamps.peekFirst() > windowMs) {
            timestamps.pollFirst();
        }
    }
}
```

### 8.1 UnifiedLLMService 实现

```java
@Service
public class UnifiedLLMService {

    @Autowired
    private ModelRouter modelRouter;
    @Autowired
    private AdapterRegistry adapterRegistry;
    @Autowired
    private ChannelHealthManager healthManager;
    @Autowired
    private UnifiedLlmConfig config;

    /**
     * 同步推理调用
     */
    public UnifiedChatResponse chat(UnifiedChatRequest request) {
        request.setRequestId(generateRequestId());
        long startTime = System.currentTimeMillis();

        // 路由选择 Channel
        Channel channel = modelRouter.route(request);

        // 获取对应的 Adapter
        ProviderAdapter adapter = adapterRegistry.getAdapter(channel.getProvider());

        try {
            UnifiedChatResponse response = adapter.invoke(request, channel);
            healthManager.recordSuccess(channel.getChannelId());
            return response;
        } catch (ProviderException e) {
            healthManager.recordFailure(channel.getChannelId(), e.getError());

            // 判断是否可重试 / 降级
            if (e.getError().isRetryable() && request.getRetryCount() < config.getMaxRetry()) {
                return retryWithFallback(request, channel, e);
            }
            throw e;
        }
    }

    /**
     * 流式推理调用
     */
    public Flux<UnifiedStreamEvent> chatStream(UnifiedChatRequest request) {
        request.setRequestId(generateRequestId());
        request.setStream(true);

        // 路由选择 Channel
        Channel channel = modelRouter.route(request);

        // 获取对应的 Adapter
        ProviderAdapter adapter = adapterRegistry.getAdapter(channel.getProvider());

        long startTime = System.currentTimeMillis();
        final String channelId = channel.getChannelId();

        return adapter.invokeStream(request, channel)
            .doOnNext(event -> {
                if (event.getType() == StreamEventType.ERROR) {
                    healthManager.recordFailure(channelId, event.getError());
                }
            })
            .doOnComplete(() -> healthManager.recordSuccess(channelId))
            .doOnError(e -> healthManager.recordFailure(channelId,
                UnifiedError.networkError(channel.getProvider(), e.getMessage(),
                    request.getRequestId())))
            // 流式失败后自动降级到备选 Channel（可选）
            .onErrorResume(e -> {
                if (request.getRetryCount() < config.getMaxRetry()) {
                    log.warn("流式调用失败，降级重试: channel={}, error={}",
                        channelId, e.getMessage());
                    request.setRetryCount(request.getRetryCount() + 1);
                    request.addExcludedChannel(channelId);
                    return chatStream(request);
                }
                return Flux.just(UnifiedStreamEvent.fatalError(
                    "所有渠道流式调用失败: " + e.getMessage(), request.getRequestId()));
            });
    }

    /**
     * 带降级的重试逻辑
     */
    private UnifiedChatResponse retryWithFallback(UnifiedChatRequest request,
            Channel failedChannel, ProviderException e) {

        log.warn("Channel {} 调用失败，尝试降级: {}",
            failedChannel.getChannelId(), e.getMessage());

        request.setRetryCount(request.getRetryCount() + 1);
        request.addExcludedChannel(failedChannel.getChannelId());

        // 重新路由（排除已失败的 Channel）
        try {
            Channel fallbackChannel = modelRouter.route(request);
            ProviderAdapter adapter = adapterRegistry.getAdapter(fallbackChannel.getProvider());

            UnifiedChatResponse response = adapter.invoke(request, fallbackChannel);
            healthManager.recordSuccess(fallbackChannel.getChannelId());

            // 标记为降级响应
            response.setDowngraded(true);
            response.setOriginalChannel(failedChannel.getChannelId());

            return response;
        } catch (NoAvailableChannelException ex) {
            throw new ProviderException(UnifiedError.allChannelsExhausted(
                request.getRequestId(), e.getMessage()), ex);
        }
    }

    private String generateRequestId() {
        return "llm_" + IdUtil.fastSimpleUUID();
    }
}
```

### 9.2 TokenCounter 实现

```java
@Service
public class TokenCounter {

    private final ObjectMapper objectMapper = new ObjectMapper();

    /**
     * 预估消息列表的 Token 数量
     * 使用近似算法：中文约 1.5 字/Token，英文约 4 字符/Token
     */
    public int estimateTiktoken(List<UnifiedMessage> messages, String modelId) {
        int total = 0;
        for (UnifiedMessage msg : messages) {
            // 基础开销（角色标记等）
            total += 4;

            if (msg.getContent() != null) {
                total += estimateTextTokens(msg.getContent());
            }

            if (msg.getParts() != null) {
                for (UnifiedContentPart part : msg.getParts()) {
                    if (part.getType() == ContentType.TEXT && part.getText() != null) {
                        total += estimateTextTokens(part.getText());
                    } else if (part.getType() == ContentType.IMAGE_URL
                            || part.getType() == ContentType.IMAGE_BASE64) {
                        // 图片 Token 估算（取决于分辨率）
                        total += 765; // GPT-4V 低分辨率图片约 765 tokens
                    }
                }
            }

            if (msg.getToolCalls() != null) {
                for (UnifiedToolCall tc : msg.getToolCalls()) {
                    total += estimateTextTokens(tc.getName() + tc.getArguments());
                }
            }
        }
        total += 2; // 结束标记
        return total;
    }

    private int estimateTextTokens(String text) {
        int cjkChars = 0;
        int otherChars = 0;

        for (char c : text.toCharArray()) {
            if (isCJK(c)) {
                cjkChars++;
            } else {
                otherChars++;
            }
        }

        // CJK: ~1.5 字/token, 其他: ~4 字符/token
        return (int) Math.ceil(cjkChars / 1.5 + otherChars / 4.0);
    }

    private boolean isCJK(char c) {
        Character.UnicodeScript script = Character.UnicodeScript.of(c);
        return script == Character.UnicodeScript.HAN
            || script == Character.UnicodeScript.HIRAGANA
            || script == Character.UnicodeScript.KATAKANA
            || script == Character.UnicodeScript.HANGUL;
    }
}
```

### 11.3 降级策略矩阵

| 场景 | 主模型失败 | 降级方案 |
| --- | --- | --- |

### 11.4 上层业务错误处理示例

```java
@RestController
public classAITutorController {

    @Autowired
    private UnifiedLLMService llmService;

    @PostMapping("/tutor/chat")
    public ResponseEntity<?> chat(@RequestBody ChatRequest req) {
        try {
            UnifiedChatRequest llmReq = buildLlmRequest(req);
            UnifiedChatResponse response = llmService.chat(llmReq);
            return ResponseEntity.ok(convertToApiResponse(response));

        } catch (ProviderException e) {
            switch (e.getError().getErrorType()) {
                case RATE_LIMITED:
                    return ResponseEntity.status(429)
                        .body(Map.of("message", "AI 助手当前繁忙，请稍后重试",
                                     "retryAfter", e.getError().getRetryAfterMs()));
                case CONTENT_FILTERED:
                    return ResponseEntity.status(400)
                        .body(Map.of("message", "请调整问题内容后重试"));
                case ALL_CHANNELS_EXHAUSTED:
                case NO_AVAILABLE_CHANNEL:
                    return ResponseEntity.status(503)
                        .body(Map.of("message", "AI 服务暂时不可用，正在紧急恢复中"));
                default:
                    return ResponseEntity.status(500)
                        .body(Map.of("message", "AI 回答失败，请重试"));
            }
        }
    }
}
```

## 15. 安全考虑

### 15.1 API Key 管理

- 所有 API Key 使用 AES-256 加密存储在数据库中
- 运行时解缓存在内存中，定期轮换（90 天）
- 禁止将 API Key 写入日志或监控数据
- 通过密钥管理服务（KMS）统一管理加密密钥

### 15.2 请求安全

- 对用户输入进行内容安全预处理（对接安全过滤中间件）
- 设置每用户/每 IP 的调用频率限制
- 敏感参数（如学生年龄、年级）不传递给供应商
- 对供应商响应进行内容安全后处理

### 15.3 数据脱敏

- 请求日志中脱敏用户输入（手机号、邮箱等）
- 监控指标不包含用户请求内容
- 链路追踪中截断超长请求体
