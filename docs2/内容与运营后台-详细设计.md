# 内容与运营后台 - 详细设计文档

## 1. 模块概述

### 1.1 定位

内容与运营后台是 PrimeTop 的管理中枢，面向平台运营人员、内容编辑和管理员，提供教材管理、知识库维护、题库管理、AI Prompt 配置、模型管理、内容审核、数据看板、权限管理等功能。所有面向学生的内容与 AI 输出质量均依赖此后台的配置和管理。

### 1.2 目标用户

| 角色 | 职责 |
|------|------|
| 超级管理员 | 全部权限，系统配置、角色管理 |
| 运营管理员 | 运营活动、数据看板、会员管理 |
| 内容编辑 | 教材、知识点、题库、考点内容维护 |
| 审核专员 | AI 输出审核、用户上传内容审核 |
| AI 工程师 | Prompt 模板、模型配置、RAG 策略调优 |

### 1.3 优先级

| 功能 | 优先级 | 版本 |
|------|--------|------|
| 用户与权限管理 | P0 | MVP |
| 教材版本管理 | P0 | MVP |
| 章节/知识点管理 | P0 | MVP |
| Prompt 模板配置 | P0 | MVP |
| 模型供应商配置 | P0 | MVP |
| 题库管理 | P1 | V1.0 |
| 内容审核 | P1 | V1.0 |
| 数据看板 | P1 | V1.0 |
| 运营活动管理 | P2 | V1.5 |
| AI 质量评估 | P2 | V1.5 |

### 3.2 RBAC 权限模型

```
权限编码规则: {模块}:{资源}:{操作}

模块划分:
- user      → 用户管理
- content   → 内容管理(教材/知识点/考点)
- question  → 题库管理
- ai        → AI 配置(Prompt/模型)
- audit     → 审核管理
- ops       → 运营管理(活动/会员)
- dashboard → 数据看板
- system    → 系统设置(角色/权限/日志)

示例:
- content:textbook:create    → 创建教材版本
- content:textbook:read      → 查看教材
- content:textbook:update    → 编辑教材
- content:textbook:delete    → 删除教材
- content:chapter:update     → 编辑章节
- question:question:create   → 创建题目
- ai:prompt:update           → 修改 Prompt 模板
- ai:model:update            → 修改模型配置
```

GET    /api/admin/roles                   # 角色列表
POST   /api/admin/roles                   # 创建角色

GET    /api/admin/audit-logs              # 操作日志(分页、筛选)
```

### 3.4 认证流程

```
管理员登录:
1. POST /api/admin/auth/login { username, password }
2. 验证密码 (bcrypt compare)
3. 检查账号状态 (enabled/disabled)
4. 生成 JWT Token (payload: { userId, roles[] })
5. 记录登录日志 (IP、UA、时间)
6. 返回 { token, expiresIn, userInfo }

请求鉴权:
1. 前端请求头携带 Authorization: Bearer <token>
2. Gateway 校验 JWT 签名和过期时间
3. 从 token 提取 userId + roles
4. 查询角色对应的权限列表 (Redis 缓存)
5. 与请求的 API 路径进行权限匹配
6. 通过 → 转发; 拒绝 → 403
```

## 4. 教材与章节管理

### 4.1 数据模型

```sql
-- 教材版本表
CREATE TABLE textbook (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    name            VARCHAR(128) NOT NULL COMMENT '如: 人教版数学',
    publisher       VARCHAR(64) COMMENT '出版社',
    subject_code    VARCHAR(32) NOT NULL COMMENT '学科编码: MATH/CHINESE/ENGLISH/PHYSICS...',
    stage           VARCHAR(16) NOT NULL COMMENT 'PRIMARY/JUNIOR/SENIOR',
    grade_start     INT NOT NULL COMMENT '起始年级 1-12',
    grade_end       INT NOT NULL COMMENT '结束年级',
    semester_type   VARCHAR(16) COMMENT 'UPPER/LOWER/FULL',
    version_code    VARCHAR(64) NOT NULL UNIQUE COMMENT '如: PEP-MATH-PRIMARY',
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '0=草稿 1=已发布 2=已下线',
    cover_url       VARCHAR(512),
    description     TEXT,
    published_at    DATETIME,
    created_by      BIGINT,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_subject_stage (subject_code, stage),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 章节目录表（树形结构）
CREATE TABLE chapter (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    textbook_id     BIGINT NOT NULL,
    parent_id       BIGINT DEFAULT 0 COMMENT '0=顶级章节',
    level           TINYINT NOT NULL COMMENT '1=册 2=单元 3=课 4=知识点',
    sort_order      INT NOT NULL DEFAULT 0,
    name            VARCHAR(256) NOT NULL,
    code            VARCHAR(128) COMMENT '章节编码',
    description     TEXT,
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '0=草稿 1=已发布',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (textbook_id) REFERENCES textbook(id),
    INDEX idx_textbook_parent (textbook_id, parent_id, sort_order),
    INDEX idx_code (code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 章节资源关联表
CREATE TABLE chapter_resource (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    chapter_id      BIGINT NOT NULL,
    resource_type   VARCHAR(32) NOT NULL COMMENT 'VIDEO/DOC/AUDIO/IMAGE/PDF',
    title           VARCHAR(256),
    url             VARCHAR(1024) NOT NULL,
    file_size       BIGINT COMMENT '字节',
    format          VARCHAR(16) COMMENT 'mp4/pdf/mp3/png...',
    duration_sec    INT COMMENT '音视频时长',
    sort_order      INT NOT NULL DEFAULT 0,
    status          TINYINT NOT NULL DEFAULT 1,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (chapter_id) REFERENCES chapter(id),
    INDEX idx_chapter_type (chapter_id, resource_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 4.2 章节树形结构设计

```
教材版本: 人教版小学数学 (textbook_id=1)
│
├── 一年级上册 (level=1, parent_id=0, sort=1)
│   ├── 第一单元 准备课 (level=2, parent_id=101, sort=1)
│   │   ├── 1.1 数一数 (level=3, parent_id=201, sort=1)
│   │   ├── 1.2 比多少 (level=3, parent_id=201, sort=2)
│   │   └── ...
│   ├── 第二单元 位置 (level=2, parent_id=101, sort=2)
│   └── ...
├── 一年级下册 (level=1, parent_id=0, sort=2)
└── ...

约定:
- level 最多4层: 册 → 单元 → 课 → 知识点
- sort_order 同级排序，从小到大
- code 用于外部系统对接，如 "PEP-MATH-P1A-U1-L1"
```

```

### 4.4 教材导入流程

```json
// Excel 导入模板格式 (每行一个章节)
{
  "columns": ["册别", "单元", "课", "知识点", "章节编码"],
  "example": [
    ["一年级上册", "第一单元 准备课", "数一数", "", "PEP-MATH-P1A-U1-L1"],
    ["一年级上册", "第一单元 准备课", "比多少", "", "PEP-MATH-P1A-U1-L2"]
  ]
}
```

```
导入流程:
1. 内容编辑上传 Excel/JSON 文件
2. 后台解析 → 校验格式和必填字段
3. 构建 parent_id 关系 → 生成树形结构
4. 写入 chapter 表 (status=草稿)
5. 返回导入结果: 成功数/跳过数/错误列表
6. 编辑确认后批量发布
```

### 5.2 知识点树与关联关系

```
学科: 数学
├── 数与代数 (level=1, code=MATH-ALGEBRA)
│   ├── 有理数 (level=2, code=MATH-ALGEBRA-RATIONAL)

│   │   └── 绝对值 (level=3, code=MATH-ALGEBRA-RATIONAL-ABS)
│   ├── 方程与不等式 (level=2)
│   └── 函数 (level=2)
├── 图形与几何 (level=1)
├── 统计与概率 (level=1)
└── 综合与实践 (level=1)

关联关系:
- knowledge_chapter_mapping: 知识点 ↔ 章节多对多

### 6.3 核心接口

```
# 题目 CRUD
GET    /api/admin/questions                     # 题目列表(分页/筛选)
POST   /api/admin/questions                     # 创建题目
GET    /api/admin/questions/{id}                # 题目详情
PUT    /api/admin/questions/{id}                # 更新题目
DELETE /api/admin/questions/{id}                # 删除题目

# 批量操作
POST   /api/admin/questions/import              # 批量导入(Excel/JSON)
GET    /api/admin/questions/export              # 批量导出
PUT    /api/admin/questions/batch-status        # 批量上下线

# 审核
GET    /api/admin/questions/pending-audit       # 待审核列表
PUT    /api/admin/questions/{id}/audit          # 审核通过/驳回

# 统计
GET    /api/admin/questions/stats               # 题库统计(总数/学科/难度/类型分布)
```

### 6.4 题目导入流程

```
导入方式:
1. Excel 批量导入 → 解析 → 结构化校验 → 入库(草稿)
2. OCR 识别入库 → 拍题模块识别的题目 → 入库(待审核)
3. AI 生成题目 → 按知识点+难度要求 → AI 生成 → 人工审核入库
4. 手动录入 → 表单填写 → 入库(草稿)

导入校验规则:
- 必填: 题干、答案、题型、学科、学段
- 知识点ID 必须存在
- 选项数选择题必须 ≥ 2
- 难度 1-5 范围
- 去重: 对题干文本做相似度检测(>90% 判定为重复)
```

## 7. AI 配置管理

### 7.1 Prompt 模板管理

```sql
-- Prompt 模板表
CREATE TABLE prompt_template (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    scene_code      VARCHAR(64) NOT NULL COMMENT '场景编码',
    scene_name      VARCHAR(128) NOT NULL COMMENT '场景名称',
    version         INT NOT NULL DEFAULT 1 COMMENT '模板版本号',
    system_prompt   TEXT NOT NULL COMMENT '系统提示词',
    user_prompt_tpl TEXT COMMENT '用户消息模板(含变量占位符)',
    variables       JSON COMMENT '模板变量定义',
    model_hint      VARCHAR(64) COMMENT '推荐模型编码',
    temperature     DECIMAL(3,2) DEFAULT 0.70,
    max_tokens      INT DEFAULT 2048,
    stage_filter    JSON COMMENT '适用学段 ["PRIMARY","JUNIOR","SENIOR"]',
    is_active       TINYINT NOT NULL DEFAULT 1 COMMENT '当前激活版本',
    status          TINYINT NOT NULL DEFAULT 1,
    created_by      BIGINT,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_scene_version (scene_code, version),
    INDEX idx_scene_active (scene_code, is_active)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 模型供应商配置表
CREATE TABLE model_provider (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    provider_code   VARCHAR(64) NOT NULL UNIQUE COMMENT 'openai/zhipu/baidu/moonshot...',
    provider_name   VARCHAR(128) NOT NULL,
    api_endpoint    VARCHAR(512) NOT NULL,
    api_key_enc     VARCHAR(512) NOT NULL COMMENT '加密存储的 API Key',
    models          JSON NOT NULL COMMENT '支持的模型列表',
    weight          INT NOT NULL DEFAULT 100 COMMENT '负载权重',
    rate_limit      INT COMMENT '每分钟请求上限',
    cost_per_1k_tokens DECIMAL(10,6) COMMENT '每千 token 成本(元)',
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '1=启用 0=禁用',
    priority        INT NOT NULL DEFAULT 0 COMMENT '优先级，越大越优先',
    fallback_provider_code VARCHAR(64) COMMENT '降级备选供应商',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
