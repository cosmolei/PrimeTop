# 服务端-教育平台虚拟经济体系平衡调控与积分通胀智能预警防护引擎-详细设计

## 1. 模块概述

### 1.1 功能定位

本引擎是 PrimeTop 虚拟经济体系的"央行"，负责对学币（COIN）、经验值（EXP）、星光（STAR）三套虚拟货币进行宏观调控。与已有的积分获取规则计算服务和商城运营工作台不同，本模块专注于**经济系统的实时监控、趋势预测、异常预警和自动平衡调控**，确保虚拟经济长期健康运转，避免积分通胀（学币贬值、商城兑换枯竭）或通缩（学币囤积、用户失去获取动力）。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **实时经济感知** | 秒级采集全平台积分铸造（mint）与消耗（burn）事件，计算核心经济指标 |
| **通胀/通缩预警** | 基于多维指标自动识别经济失衡，分级告警通知运营团队 |
| **预测性调控** | 利用时间序列模型预测未来 7-30 天的经济趋势，提前干预 |
| **自动平衡机制** | 动态调整积分获取速率、限时商店商品、双倍消耗活动等杠杆，无需人工介入 |
| **经济仿真** | 提供蒙特卡洛模拟和 What-If 分析，支持运营决策前验证调控效果 |
| **防套利防护** | 检测异常积分获取模式，防止经济系统被恶意利用 |

## 3. 核心指标定义与计算

### 3.1 一级指标（实时计算，秒级更新）

#### 3.1.1 铸造消耗比 (Mint-Burn Ratio, MBR)

```
MBR = 当日累计铸造量 / 当日累计消耗量
```

| MBR 范围 | 含义 | 健康度影响 |
|----------|------|-----------|
| 0.8 – 1.5 | 健康平衡 | ✅ 正常 |
| 1.5 – 2.5 | 轻度通胀倾向 | ⚠️ 关注 |
| 2.5 – 4.0 | 中度通胀 | 🔶 预警 |
| > 4.0 | 严重通胀 | 🔴 告警 |
| < 0.8 | 通缩倾向（消耗过快） | ⚠️ 关注 |

#### 3.1.2 货币流速 (Velocity)

```
Velocity = 过去7日总消耗量 / 当前M1流通量
```

| Velocity 范围 | 含义 |
|--------------|------|
| > 0.5 | 活跃流转，经济健康 |
| 0.2 – 0.5 | 正常区间 |
| 0.1 – 0.2 | 流转缓慢，可能囤积 |
| < 0.1 | 停滞，严重通缩 |

#### 3.1.3 消耗率 (Burn Rate)

```
BurnRate = 当日消耗量 / (当日铸造量 + 日初余额)
```

#### 3.1.4 人均余额 (Average Balance)

```
AvgBalance = M1流通量 / 有余额用户数
```

### 3.2 二级指标（日级计算）

#### 3.2.1 基尼系数 (Gini Coefficient)

衡量学币分布均匀程度。计算方式基于 Lorenz 曲线：

```python
def calculate_gini(balances: list[int]) -> float:
    """
    计算学币余额分布的基尼系数
    :param balances: 所有用户的学币余额列表
    :return: 基尼系数 [0, 1]
    """
    if not balances:
        return 0.0
    sorted_balances = sorted(balances)
    n = len(sorted_balances)
    total = sum(sorted_balances)
    if total == 0:
        return 0.0

    # 累积计算
    cumsum = 0
    gini_sum = 0
    for i, bal in enumerate(sorted_balances):
        cumsum += bal
        gini_sum += (i + 1) * bal

    gini = (2 * gini_sum) / (n * total) - (n + 1) / n
    return round(gini, 4)
```

| Gini 范围 | 含义 | 建议操作 |
|----------|------|---------|
| < 0.3 | 过于均匀，积分获取缺乏差异化 | 调整奖励梯度，增加高价值行为奖励 |
| 0.3 – 0.5 | 合理范围 | 无需干预 |
| 0.5 – 0.7 | 财富集中度较高 | 增加普惠性获取渠道 |
| > 0.7 | 严重不均，少数用户囤积大量积分 | 检查是否存在刷分行为，增加消耗引导 |

#### 3.2.2 鲸鱼占比 (Whale Balance Percentage)

```
WhalePct = Top 5% 用户持有的学币余额总和 / M1流通量 × 100%
```

| WhalePct | 含义 |
|----------|------|
| < 30% | 分布健康 |
| 30% – 50% | 适度集中 |
| > 50% | 高度集中，存在经济风险 |

#### 3.2.3 过期销毁率 (Expiry Destruction Rate)

```
ExpiryRate = 当日过期学币量 / 日初M1流通量
```

过期是天然的经济通缩机制。合理的过期率应在 0.05% – 0.3%/日。

### 3.3 综合经济健康度评分

```python
def calculate_health_score(metrics: dict) -> tuple[float, str]:
    """
    综合经济健康度评分 (0-100)
    返回: (score, temperature)
    """
    score = 100.0

    # 1. Mint-Burn Ratio 偏离度 (权重 30%)
    mbr = metrics['mint_burn_ratio']
    if mbr > 0:
        mbr_deviation = abs(mbr - 1.0)  # 理想值为1.0
        mbr_score = max(0, 100 - mbr_deviation * 40)
    else:
        mbr_score = 0
    score -= (100 - mbr_score) * 0.30

    # 2. Velocity (权重 25%)
    velocity = metrics['velocity']
    if velocity >= 0.5:
        vel_score = 100
    elif velocity >= 0.2:
        vel_score = 60 + (velocity - 0.2) * 100  # 60-100
    elif velocity >= 0.1:
        vel_score = 30 + (velocity - 0.1) * 300  # 30-60
    else:
        vel_score = velocity * 300  # 0-30
    score -= (100 - vel_score) * 0.25

    # 3. Gini Coefficient (权重 20%)
    gini = metrics['gini_coefficient']
    if 0.3 <= gini <= 0.5:
        gini_score = 100
    elif gini < 0.3:
        gini_score = 70 + gini * 100  # 过于均匀
    elif gini <= 0.7:
        gini_score = 100 - (gini - 0.5) * 150  # 100->70
    else:
        gini_score = max(0, 40 - (gini - 0.7) * 100)
    score -= (100 - gini_score) * 0.20

    # 4. Burn Rate (权重 15%)
    burn_rate = metrics['burn_rate']
    if 0.05 <= burn_rate <= 0.20:
        br_score = 100
    elif burn_rate < 0.05:
        br_score = burn_rate * 1000  # 消耗不足
    else:
        br_score = max(0, 100 - (burn_rate - 0.20) * 200)
    score -= (100 - br_score) * 0.15

    # 5. Whale Percentage (权重 10%)
    whale_pct = metrics['whale_balance_pct']
    if whale_pct <= 30:
        whale_score = 100
    elif whale_pct <= 50:
        whale_score = 100 - (whale_pct - 30) * 2.5  # 100->50
    else:
        whale_score = max(0, 50 - (whale_pct - 50) * 2)
    score -= (100 - whale_score) * 0.10

    score = round(max(0, min(100, score)), 2)

    # 温度映射
    if score >= 80:
        temp = "NORMAL"
    elif score >= 65:
        temp = "WARM"
    elif score >= 50:
        temp = "COLD"  # 经济偏冷，需要刺激消耗
    elif score >= 35:
        temp = "HOT"   # 经济偏热，需要抑制铸造
    else:
        temp = "OVERHEATED"

    return score, temp
```

```java
@Component
@Slf4j
public class EconomyEventProcessor {

    @Autowired
    private RedisTemplate<String, String> redis;
    @Autowired
    private EconomyEventStreamMapper eventStreamMapper;
    @Autowired
    private EconomyRiskDetector riskDetector;
    @Autowired
    private RealtimeIndicatorCalculator indicatorCalculator;

    @KafkaListener(
        topics = "economy.events",
        groupId = "economy-engine",
        concurrency = "6"
    )
    public void onEvent(EconomyEventMessage msg) {
        // 1. 幂等校验
        if (isDuplicate(msg.getEventId())) {
            return;
        }

        // 2. 风控预检
        RiskCheckResult riskResult = riskDetector.check(msg);
        msg.setRiskFlag(riskResult.getFlag());
        msg.setRiskTags(riskResult.getTags());

        // 3. 更新实时计数器
        updateRealtimeCounters(msg);

        // 4. 持久化事件
        EconomyEventStream record = buildRecord(msg);
        eventStreamMapper.insert(record);

        // 5. 异步触发指标重算 (每5000事件或5分钟触发一次)
        indicatorCalculator.tryRecalculate();
    }

    private void updateRealtimeCounters(EconomyEventMessage msg) {
        String dateKey = LocalDate.now().format(ISO_DATE);
        String direction = msg.getDirection(); // IN or OUT

        if ("IN".equals(direction)) {
            String mintKey = "ECON:REALTIME:mint_total:" + dateKey;
            redis.opsForHash().increment(mintKey, msg.getSourceCode(), msg.getAmount());

            String userKey = "ECON:REALTIME:mint_users:" + dateKey;
            redis.opsForHyperLogLog().add(userKey, String.valueOf(msg.getUserId()));

            redis.opsForValue().increment("ECON:REALTIME:mint_tx_count:" + dateKey);
        } else {
            String burnKey = "ECON:REALTIME:burn_total:" + dateKey;
            redis.opsForHash().increment(burnKey, msg.getSourceCode(), msg.getAmount());

            String userKey = "ECON:REALTIME:burn_users:" + dateKey;
            redis.opsForHyperLogLog().add(userKey, String.valueOf(msg.getUserId()));

            redis.opsForValue().increment("ECON:REALTIME:burn_tx_count:" + dateKey);
        }
    }
}
```

### 4.4 实时指标计算器

```java
@Component
@Slf4j
public class RealtimeIndicatorCalculator {

    private final AtomicLong eventCounter = new AtomicLong(0);
    private final AtomicLong lastCalcTime = new AtomicLong(System.currentTimeMillis());
    private static final long RECALC_THRESHOLD_EVENTS = 5000;
    private static final long RECALC_THRESHOLD_TIME_MS = 5 * 60 * 1000; // 5分钟

    @Autowired
    private RedisTemplate<String, String> redis;
    @Autowired
    private EconomyAlertService alertService;

    public void tryRecalculate() {
        long events = eventCounter.incrementAndGet();
        long lastTime = lastCalcTime.get();
        long now = System.currentTimeMillis();

        if (events >= RECALC_THRESHOLD_EVENTS ||
            (now - lastTime) >= RECALC_THRESHOLD_TIME_MS) {

            synchronized (this) {
                if (eventCounter.get() >= RECALC_THRESHOLD_EVENTS ||
                    (System.currentTimeMillis() - lastCalcTime.get()) >= RECALC_THRESHOLD_TIME_MS) {

                    recalculateIndicators();
                    eventCounter.set(0);
                    lastCalcTime.set(now);
                }
            }
        }
    }

    private void recalculateIndicators() {
        String today = LocalDate.now().format(ISO_DATE);

        // 获取实时数据
        Map<Object, Object> mintMap = redis.opsForHash()
            .entries("ECON:REALTIME:mint_total:" + today);
        Map<Object, Object> burnMap = redis.opsForHash()
            .entries("ECON:REALTIME:burn_total:" + today);

        long mintTotal = sumHashValues(mintMap);
        long burnTotal = sumHashValues(burnMap);

        // 计算核心指标
        double mbr = burnTotal > 0 ? (double) mintTotal / burnTotal : mintTotal > 0 ? 999.0 : 0.0;

        // 获取7日滚动数据计算 Velocity
        Long m1Supply = getM1Supply(); // 从缓存或DB获取
        Long burn7d = get7DayBurnTotal();
        double velocity = m1Supply > 0 ? (double) burn7d / m1Supply : 0.0;

        double burnRate = (mintTotal + getDayStartBalance()) > 0
            ? (double) burnTotal / (mintTotal + getDayStartBalance()) : 0.0;

        // 更新Redis缓存
        redis.opsForValue().set("ECON:REALTIME:mint_burn_ratio",
            String.valueOf(round(mbr, 4)));
        redis.opsForValue().set("ECON:REALTIME:velocity",
            String.valueOf(round(velocity, 4)));

        // 检查预警阈值
        checkAlertThresholds(mbr, velocity, burnRate);
    }

    private void checkAlertThresholds(double mbr, double velocity, double burnRate) {
        // 通胀检测
        if (mbr > 2.5) {
            alertService.raiseAlert(AlertBuilder.builder()
                .type("INFLATION")
                .severity(mbr > 4.0 ? "CRITICAL" : "WARN")
                .title("积分通胀预警")
                .description(String.format(
                    "当日铸造消耗比 %.2f，超过预警阈值 2.5", mbr))
                .triggerMetric("mint_burn_ratio")
                .triggerValue(mbr)
                .thresholdValue(2.5)
                .recommendedActions(buildInflationActions(mbr))
                .build());
        }

        // 通缩检测
        if (velocity < 0.1 && m1Supply > 10000) {
            alertService.raiseAlert(AlertBuilder.builder()
                .type("DEFLATION")
                .severity(velocity < 0.05 ? "CRITICAL" : "WARN")
                .title("积分流通停滞预警")
                .description(String.format(
                    "货币流速 %.4f，低于停滞阈值 0.1，用户囤积严重", velocity))
                .triggerMetric("velocity")
                .triggerValue(velocity)
                .thresholdValue(0.1)
                .recommendedActions(buildDeflationActions(velocity))
                .build());
        }
    }
}
```

### 6.3 杠杆效果评估

每次杠杆执行结束后，自动计算效果评分：

```python
def evaluate_leverage_effectiveness(
    pre_snapshot: dict,
    post_snapshot: dict,
    leverage_type: str
) -> float:
    """
    评估调控杠杆效果 (-100 到 +100)
    正值表示改善, 负值表示恶化
    """
    score_delta = post_snapshot['health_score'] - pre_snapshot['health_score']

    if leverage_type in ('MINT_THROTTLE', 'SOURCE_THROTTLE'):
        # 抑制型: MBR应下降趋近1.0
        mbr_before = pre_snapshot['mint_burn_ratio']
        mbr_after = post_snapshot['mint_burn_ratio']
        if mbr_before > 1.5:
            mbr_improvement = max(0, (mbr_before - mbr_after) / (mbr_before - 1.0)) * 50
        else:
            mbr_improvement = 0
        return round(score_delta * 0.5 + mbr_improvement, 2)

    elif leverage_type in ('BURN_FESTIVAL', 'PREMIUM_SHOP', 'SINK_LOTTERY'):
        # 消耗刺激型: Velocity应上升
        vel_before = pre_snapshot['velocity']
        vel_after = post_snapshot['velocity']
        if vel_before > 0:
            vel_improvement = min(50, (vel_after - vel_before) / vel_before * 100)
        else:
            vel_improvement = 25
        return round(score_delta * 0.5 + vel_improvement, 2)

    else:
        return round(score_delta, 2)
```

### 7.1 ARIMA 时间序列预测

使用 7-30 天的历史日快照数据预测未来 7 天的核心指标。

```python
import numpy as np
from statsmodels.tsa.arima.model import ARIMA

class EconomyForecaster:

    def __init__(self, snapshot_history: list[dict]):
        """
        :param snapshot_history: 最近30天的日快照数据
        """
        self.history = snapshot_history

    def forecast_mbr(self, days: int = 7) -> list[float]:
        """预测未来N天的Mint-Burn Ratio"""
        mbr_series = np.array([
            s['mint_burn_ratio'] for s in self.history
        ], dtype=float)

        # 自动选择 (p, d, q) 参数
        model = ARIMA(mbr_series, order=(3, 1, 1))
        fitted = model.fit()
        forecast = fitted.forecast(steps=days)

        return [round(float(v), 4) for v in forecast]

    def forecast_velocity(self, days: int = 7) -> list[float]:
        """预测未来N天的货币流速"""
        vel_series = np.array([
            s['velocity'] for s in self.history
        ], dtype=float)

        model = ARIMA(vel_series, order=(2, 1, 2))
        fitted = model.fit()
        forecast = fitted.forecast(steps=days)

        return [round(max(0, float(v)), 4) for v in forecast]

    def forecast_health_score(self, days: int = 7) -> list[dict]:
        """
        综合预测: 基于MBR和Velocity预测推算健康度
        返回 [{date, mbr, velocity, estimated_score, estimated_temp}]
        """
        mbr_forecast = self.forecast_mbr(days)
        vel_forecast = self.forecast_velocity(days)

        results = []
        for i, (mbr, vel) in enumerate(zip(mbr_forecast, vel_forecast)):
            estimated_metrics = {
                'mint_burn_ratio': mbr,
                'velocity': vel,
                'gini_coefficient': self.history[-1]['gini_coefficient'],
                'burn_rate': self.history[-1]['burn_rate'],
                'whale_balance_pct': self.history[-1]['whale_balance_pct']
            }
            score, temp = calculate_health_score(estimated_metrics)
            forecast_date = (
                datetime.now() + timedelta(days=i + 1)
            ).strftime('%Y-%m-%d')
            results.append({
                'date': forecast_date,
                'mbr': mbr,
                'velocity': vel,
                'estimated_score': score,
                'estimated_temp': temp
            })

        return results
```

### 8.1 蒙特卡洛仿真

```python
import random

class EconomySimulator:

    def __init__(self, baseline_snapshot: dict, config: dict):
        """
        :param baseline_snapshot: 起始日的经济快照
        :param config: 仿真参数 (调控杠杆组合)
        """
        self.m1_supply = baseline_snapshot['m1_supply']
        self.dau = baseline_snapshot['dpu']
        self.avg_mint_per_user = baseline_snapshot['avg_mint_per_user']
        self.avg_burn_per_user = baseline_snapshot['avg_burn_per_user']
        self.config = config

    def simulate_days(self, days: int, runs: int = 1000) -> dict:
        """
        蒙特卡洛多次仿真
        :return: {percentile_5, percentile_50, percentile_95, worst_case, best_case}
        """
        all_final_scores = []

        for _ in range(runs):
            final_score = self._simulate_single_run(days)
            all_final_scores.append(final_score)

        all_final_scores.sort()
        n = len(all_final_scores)

        return {
            'percentile_5':  all_final_scores[int(n * 0.05)],
            'percentile_25': all_final_scores[int(n * 0.25)],
            'percentile_50': all_final_scores[int(n * 0.50)],
            'percentile_75': all_final_scores[int(n * 0.75)],
            'percentile_95': all_final_scores[int(n * 0.95)],
            'mean': round(sum(all_final_scores) / n, 2),
            'worst_case': min(all_final_scores),
            'best_case': max(all_final_scores),
            'prob_critical': sum(1 for s in all_final_scores if s < 35) / n,
            'prob_warning': sum(1 for s in all_final_scores if s < 50) / n
        }

    def _simulate_single_run(self, days: int) -> float:
        """单次仿真"""
        m1 = self.m1_supply
        mint_multiplier = self.config.get('mint_multiplier', 1.0)
        burn_multiplier = self.config.get('burn_multiplier', 1.0)

        for day in range(days):
            # 模拟当日铸造 (加入随机扰动 ±15%)
            daily_mint = self.dau * self.avg_mint_per_user * mint_multiplier \
                * random.uniform(0.85, 1.15)

            # 模拟当日消耗
            daily_burn = self.dau * self.avg_burn_per_user * burn_multiplier \
                * random.uniform(0.85, 1.15)

            # 更新M1
            m1 = m1 + daily_mint - daily_burn

            # DAU轻微波动
            dau_today = self.dau * random.uniform(0.92, 1.08)

        # 计算最终健康度
        mbr = daily_mint / max(daily_burn, 1)
        velocity = (daily_burn * 7) / max(m1, 1)

        metrics = {
            'mint_burn_ratio': mbr,
            'velocity': velocity,
            'gini_coefficient': 0.45,
            'burn_rate': daily_burn / max(m1, 1),
            'whale_balance_pct': 35.0
        }

        score, _ = calculate_health_score(metrics)
        return score
```

### 9.1 异常获取模式检测

```java
@Component
public class EconomyRiskDetector {

    @Autowired
    private RedisTemplate<String, String> redis;

    private static final int MAX_HOURLY_MINT_PER_USER = 200;
    private static final int MAX_HOURLY_MINT_PER_SOURCE = 100;
    private static final double ANOMALY_Z_SCORE_THRESHOLD = 3.0;

    public RiskCheckResult check(EconomyEventMessage event) {
        if (event.getDirection().equals("OUT")) {
            return RiskCheckResult.ok(); // 消耗暂不做风控预检
        }

        List<String> tags = new ArrayList<>();
        int flag = 0;

        // 规则1: 单用户小时铸造量超限
        String hourlyKey = "ECON:RISK:user_mint_hour:"
            + event.getUserId() + ":"
            + LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMddHH"));
        Long userHourly = redis.opsForValue().increment(
            hourlyKey, event.getAmount());
        redis.expire(hourlyKey, Duration.ofHours(2));
        if (userHourly > MAX_HOURLY_MINT_PER_USER) {
            tags.add("HOURLY_MINT_EXCEED");
            flag = Math.max(flag, 1);
        }

        // 规则2: 单一来源异常集中
        String sourceHourlyKey = "ECON:RISK:source_mint_hour:"
            + event.getSourceCode() + ":"
            + LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMddHH"));
        Long sourceHourly = redis.opsForValue().increment(
            sourceHourlyKey, event.getAmount());
        redis.expire(sourceHourlyKey, Duration.ofHours(2));
        if (sourceHourly > MAX_HOURLY_MINT_PER_SOURCE * 10) {
            tags.add("SOURCE_CONCENTRATION");
            flag = Math.max(flag, 2);
        }

        // 规则3: 设备指纹聚合异常
        String deviceKey = "ECON:RISK:device_mint_hour:"
            + event.getDeviceId() + ":"
            + LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMddHH"));
        Long deviceHourly = redis.opsForValue().increment(
            deviceKey, event.getAmount());
        redis.expire(deviceKey, Duration.ofHours(2));
        if (deviceHourly > MAX_HOURLY_MINT_PER_USER * 3) {
            tags.add("DEVICE_AGGREGATION");
            flag = Math.max(flag, 2);
        }

        return new RiskCheckResult(flag, tags);
    }
}
```

## 12. 错误处理与容灾

### 12.1 事件流处理容错

| 异常场景 | 处理策略 |
|---------|---------|
| Kafka消费失败 | 最多重试3次，间隔指数退避(1s/2s/4s)，超过后写入死信队列 |
| 死信队列处理 | 人工介入入口，支持重放 |
| Redis不可用 | 降级为本地缓存(Caffeine)，实时计数延迟到分钟级批量写DB |
| 快照计算失败 | 使用前一天的快照作为fallback，标记 `is_stale=true` |
| Python预测服务不可用 | 返回上一次缓存预测结果，标注 `cached=true` |

```java
 * 日快照一致性校验

@Scheduled(cron = "0 15 1 * * ?")
public void verifySnapshotConsistency() {
    EconomyDailySnapshot snapshot = snapshotMapper.selectByDate(
        LocalDate.now().minusDays(1));

    Long actualMint = eventStreamMapper.sumMintByDate(
        LocalDate.now().minusDays(1));
    Long actualBurn = eventStreamMapper.sumBurnByDate(
        LocalDate.now().minusDays(1));

    if (Math.abs(actualMint - snapshot.getTotalMinted()) > 100

        alertService.raiseAlert(AlertBuilder.builder()
            .type("ANOMALY")

            .description(String.format(
                "快照Mint=%d 实际=%d; 快照Burn=%d 实际=%d",
                snapshot.getTotalMinted(), actualMint,
                snapshot.getTotalBurned(), actualBurn))
            .build());

        // 自动修复
        snapshot.setTotalMinted(actualMint);
        snapshot.setTotalBurned(actualBurn);
        recalculateDerivedMetrics(snapshot);
        snapshotMapper.updateById(snapshot);
    }
}
```

```python
def calculate_gini_sampled(user_count: int) -> float:
```

### 18.2 关键SQL查询

```sql
-- 查询最近7天铸造消耗比趋势
SELECT
    snapshot_date,
    total_minted,
    total_burned,
    mint_burn_ratio,
    velocity,
    health_score,
    economy_temp
FROM economy_daily_snapshot
WHERE snapshot_date >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
ORDER BY snapshot_date;

-- 查询当日Top 10铸造来源
SELECT
    source_code,
    SUM(amount) as total_amount,
    COUNT(*) as tx_count,
    COUNT(DISTINCT user_id) as user_count
FROM economy_event_stream
WHERE event_type = 'MINT'
  AND occurred_at >= CURDATE()
GROUP BY source_code
ORDER BY total_amount DESC
LIMIT 10;

-- 查询余额Top 100用户(鲸鱼检测)
SELECT
    user_id,
    balance,
    ROUND(balance * 100.0 / (SELECT SUM(balance) FROM user_currency WHERE currency_type='COIN'), 4) as pct_of_total
FROM user_currency
WHERE currency_type = 'COIN'
ORDER BY balance DESC
LIMIT 100;

-- 查询纯获取不消耗的可疑用户(最近7天)
SELECT
    e.user_id,
    SUM(CASE WHEN e.direction='IN' THEN e.amount ELSE 0 END) as total_mint,
    SUM(CASE WHEN e.direction='OUT' THEN e.amount ELSE 0 END) as total_burn,
    COUNT(DISTINCT e.source_code) as source_variety
FROM economy_event_stream e
WHERE e.occurred_at >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
GROUP BY e.user_id
HAVING total_burn = 0 AND total_mint > 200
ORDER BY total_mint DESC;
```
