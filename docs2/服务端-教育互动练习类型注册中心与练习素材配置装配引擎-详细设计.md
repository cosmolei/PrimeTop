> **模块代号**: ITRC (Interactive Type Registry & Configuration Center)
> **优先级**: P1
> **关联模块**: 互动练习与即时反馈引擎、题目与题库服务、练习测评会话服务、拼音识字启蒙教学内容调度、客户端-题目展示与答题交互组件库
> **关联文档**: [互动练习与即时反馈引擎-详细设计](./互动练习与即时反馈引擎-详细设计.md)、[题目与题库服务-详细设计](./题目与题库服务-详细设计.md)、[服务端-练习测评会话服务与答题流程状态机-详细设计](./服务端-练习测评会话服务与答题流程状态机-详细设计.md)

## 1. 模块概述

### 1.1 背景与问题

当前 PrimeTop 的练习体系以**传统题型**为主（单选、多选、填空、判断、解答题），这些题型通过统一的 `Question` 实体和 `QuestionType` 枚举管理。但原始设计文档 6.5 节（拼音识字启蒙）和 9.6 节（分龄 UI 策略）明确提出：

- 幼儿/小学低年级需要**图像化、语音化、卡片化、拖拽式**交互
- 英语学科需要**连线匹配、单词拼写拖拽**等交互
- 理科学科需要**实验器材拖拽、几何图形标注、函数图像绘制**等交互
- 文科学科需要**时间轴排列、地图标注、古诗文填空拖拽**等交互

现有 `互动练习与即时反馈引擎`（IEE）负责**会话管理和即时反馈**，但它消费的题目数据仍然来自传统题库，**缺少一个统一的「互动练习类型注册 + 素材配置装配」层**来：

1. **定义**：什么是"拖拽排序题"？它的交互组件是什么？评分规则是什么？
2. **注册**：系统支持哪些互动题型？如何新增一种互动题型？
3. **装配**：如何将知识点数据 + 素材资源 + 交互模板 → 组装成一道可渲染的互动练习？
4. **分发**：客户端如何根据类型注册信息选择对应的渲染组件？

### 1.3 核心职责

| 职责 | 说明 |
|------|------|
| **互动题型注册** | 定义系统中所有互动练习类型的元信息（类型编码、交互模式、渲染规范、评分策略） |
| **练习模板管理** | 管理可复用的练习模板，支持按学段/学科/知识点筛选 |
| **素材装配** | 将题目数据、素材资源、交互配置组装成完整的互动练习实例 |
| **评分规则执行** | 根据题型注册的评分策略，执行客户端预校验和服务端终判 |
| **素材资源管理** | 管理互动练习专用的图片、音频、动画等素材资源 |
| **学段适配** | 根据用户学段自动选择适合的交互模式（如幼儿用拖拽，高中用点击） |

### 1.4 不包含

| 不包含 | 归属模块 |
|--------|----------|
| 练习会话生命周期管理 | 互动练习与即时反馈引擎 (IEE) |
| 传统题型（选择/填空/解答）的存储和检索 | 题目与题库服务 |
| 答题行为采集和分析 | 练习答题行为数据采集引擎 |
| 知识点掌握度更新 | 练习答题实时批改与知识点掌握度增量更新服务 |
| 客户端 UI 渲染组件实现 | 客户端-题目展示与答题交互组件库 |

## 2. 数据结构设计

### 2.1 PostgreSQL 表设计

#### 2.1.1 `interactive_type_registry` — 互动题型注册表

系统支持的所有互动练习类型的元信息定义。

```sql
CREATE TABLE interactive_type_registry (
    id              BIGSERIAL PRIMARY KEY,
    type_code       VARCHAR(64) NOT NULL UNIQUE,          -- 类型编码，如 'DRAG_SORT'
    type_name       VARCHAR(128) NOT NULL,                 -- 类型名称，如 '拖拽排序题'
    category        VARCHAR(32) NOT NULL,                  -- 分类：SELECTION / ARRANGEMENT / MATCHING / LABELING / CONSTRUCTION / DRAWING
    
    -- 交互规范
    interaction_mode VARCHAR(32) NOT NULL,                 -- 交互模式：DRAG_DROP / CLICK_SELECT / LINE_CONNECT / TEXT_INPUT / GESTURE / VOICE
    client_widget    VARCHAR(128) NOT NULL,                 -- 客户端渲染组件标识，如 'DragSortWidget'
    
    -- 评分策略
    scoring_strategy VARCHAR(32) NOT NULL,                 -- 评分策略：EXACT_MATCH / PARTIAL_CREDIT / SET_BASED / AI_JUDGE / CUSTOM
    scoring_config   JSONB NOT NULL DEFAULT '{}',          -- 评分策略配置（如部分得分规则）
    
    -- 适用范围
    applicable_subjects JSONB NOT NULL DEFAULT '[]',       -- 适用学科：['MATH','CHINESE','ENGLISH','PHYSICS',...]
    applicable_stages   JSONB NOT NULL DEFAULT '[]',       -- 适用学段：['KINDERGARTEN','PRIMARY','JUNIOR','SENIOR']
    
    -- 渲染配置
    layout_hint     VARCHAR(32) NOT NULL DEFAULT 'STACK',  -- 布局提示：STACK / GRID / HORIZONTAL / VERTICAL / CANVAS / TIMELINE
    media_support   JSONB NOT NULL DEFAULT '[]',           -- 支持的媒体类型：['IMAGE','AUDIO','ANIMATION']
    
    -- 状态
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE', -- ACTIVE / DEPRECATED / BETA
    min_app_version VARCHAR(32),                           -- 最低App版本要求
    
    -- 元信息
    description     TEXT,
    icon_url        VARCHAR(512),
    display_order   INT NOT NULL DEFAULT 0,
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_by      BIGINT NOT NULL,
    
    CONSTRAINT chk_type_status CHECK (status IN ('ACTIVE', 'DEPRECATED', 'BETA')),
    CONSTRAINT chk_interaction_mode CHECK (interaction_mode IN (
        'DRAG_DROP', 'CLICK_SELECT', 'LINE_CONNECT', 'TEXT_INPUT', 'GESTURE', 'VOICE', 'HYBRID'
    ))
);

CREATE INDEX idx_type_registry_category ON interactive_type_registry(category);
CREATE INDEX idx_type_registry_status ON interactive_type_registry(status) WHERE status = 'ACTIVE';
CREATE INDEX idx_type_registry_subjects ON interactive_type_registry USING GIN(applicable_subjects);
CREATE INDEX idx_type_registry_stages ON interactive_type_registry USING GIN(applicable_stages);

COMMENT ON TABLE interactive_type_registry IS '互动题型注册表 — 定义系统支持的所有互动练习类型';
```

#### 2.1.2 `interactive_template` — 互动练习模板表

可复用的练习模板，每个模板定义了一类互动练习的"骨架结构"。

```sql
CREATE TABLE interactive_template (
    id              BIGSERIAL PRIMARY KEY,
    template_code   VARCHAR(64) NOT NULL UNIQUE,           -- 模板编码，如 'PY_TONE_MATCH_v1'
    template_name   VARCHAR(200) NOT NULL,                  -- 模板名称，如 '拼音声调匹配练习'
    type_code       VARCHAR(64) NOT NULL,                   -- 关联互动题型编码
    
    -- 模板结构定义
    schema_config   JSONB NOT NULL,                         -- 模板结构Schema（定义槽位、素材类型、交互参数）
    default_config  JSONB NOT NULL DEFAULT '{}',            -- 默认配置（难度、题量、时间等）
    
    -- 适用范围
    subject         VARCHAR(16) NOT NULL,                   -- 学科
    stage           VARCHAR(16) NOT NULL,                   -- 学段
    grade_range     INT4RANGE,                              -- 年级范围，如 [1,3] 表示1-3年级
    
    -- 知识点关联
    knowledge_point_ids JSONB NOT NULL DEFAULT '[]',        -- 关联知识点ID列表
    
    -- 素材要求
    required_asset_types JSONB NOT NULL DEFAULT '[]',       -- 必需素材类型：['IMAGE','AUDIO']
    asset_slot_config     JSONB NOT NULL DEFAULT '{}',      -- 素材槽位配置
    
    -- 难度与计分
    difficulty      SMALLINT NOT NULL DEFAULT 3 CHECK (difficulty BETWEEN 1 AND 10),
    default_score   INT NOT NULL DEFAULT 10,                -- 默认每题分值
    
    -- 版本与状态
    version         VARCHAR(16) NOT NULL DEFAULT '1.0',
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',
    
    -- 创建信息
    description     TEXT,
    preview_image   VARCHAR(512),                           -- 预览图URL
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_by      BIGINT NOT NULL,
    
    FOREIGN KEY (type_code) REFERENCES interactive_type_registry(type_code),
    CONSTRAINT chk_template_status CHECK (status IN ('DRAFT', 'ACTIVE', 'ARCHIVED'))
);

CREATE INDEX idx_template_type_code ON interactive_template(type_code);
CREATE INDEX idx_template_subject_stage ON interactive_template(subject, stage);
CREATE INDEX idx_template_kp ON interactive_template USING GIN(knowledge_point_ids);
CREATE INDEX idx_template_status ON interactive_template(status) WHERE status = 'ACTIVE';

COMMENT ON TABLE interactive_template IS '互动练习模板表 — 定义可复用的练习骨架结构';
```

#### 2.1.3 `interactive_exercise` — 互动练习实例表

由模板 + 素材数据 + 配置参数组装而成的具体练习实例。

```sql
CREATE TABLE interactive_exercise (
    id              BIGSERIAL PRIMARY KEY,
    exercise_uuid   VARCHAR(36) NOT NULL UNIQUE,            -- UUID，供客户端引用
    template_id     BIGINT NOT NULL,                        -- 来源模板
    type_code       VARCHAR(64) NOT NULL,                   -- 冗余题型编码（便于查询）
    
    -- 练习内容
    title           VARCHAR(256) NOT NULL,                  -- 练习标题
    prompt          TEXT,                                   -- 题目引导语/题干
    stem_rich       JSONB,                                  -- 富文本题干（支持图片、音频、公式混排）
    
    -- 交互数据（核心）
    interaction_data JSONB NOT NULL,                        -- 交互数据体（按 type_code 的 schema 组织）
    
    -- 正确答案
    correct_answer  JSONB NOT NULL,                         -- 标准答案数据
    
    -- 评分配置
    scoring_override JSONB,                                 -- 覆盖模板默认评分规则的实例级配置
    max_score       INT NOT NULL,                           -- 本题满分
    
    -- 关联信息
    subject         VARCHAR(16) NOT NULL,
    knowledge_point_ids JSONB NOT NULL DEFAULT '[]',
    source_type     VARCHAR(32) NOT NULL DEFAULT 'TEMPLATE_INSTANTIATED', -- TEMPLATE_INSTANTIATED / AI_GENERATED / MANUAL / IMPORTED
    source_ref      VARCHAR(128),                           -- 来源引用（如题目ID、AI生成批次号）
    
    -- 适配信息
    stage           VARCHAR(16) NOT NULL,
    grade           SMALLINT,
    difficulty      SMALLINT NOT NULL DEFAULT 3 CHECK (difficulty BETWEEN 1 AND 10),
    
    -- 状态
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',  -- ACTIVE / DISABLED / REVIEWING
    
    -- 版本
    version         INT NOT NULL DEFAULT 1,
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_by      BIGINT,
    
    FOREIGN KEY (template_id) REFERENCES interactive_template(id),
    FOREIGN KEY (type_code) REFERENCES interactive_type_registry(type_code)
);

CREATE INDEX idx_exercise_template ON interactive_exercise(template_id);
CREATE INDEX idx_exercise_type ON interactive_exercise(type_code);
CREATE INDEX idx_exercise_subject ON interactive_exercise(subject);
CREATE INDEX idx_exercise_kp ON interactive_exercise USING GIN(knowledge_point_ids);
CREATE INDEX idx_exercise_status ON interactive_exercise(status) WHERE status = 'ACTIVE';
CREATE INDEX idx_exercise_uuid ON interactive_exercise(exercise_uuid);

COMMENT ON TABLE interactive_exercise IS '互动练习实例表 — 模板+素材组装后的具体练习';
```

### 2.2 核心枚举定义

```python
from enum import Enum

class ExerciseCategory(str, Enum):
    """互动练习大类"""
    SELECTION = "SELECTION"           # 选择类（增强版选择，如图片选择、语音选择）
    ARRANGEMENT = "ARRANGEMENT"       # 排列类（排序、拖拽排列）
    MATCHING = "MATCHING"             # 匹配类（连线匹配、配对）
    LABELING = "LABELING"             # 标注类（在图上标注、在地图上标点）
    CONSTRUCTION = "CONSTRUCTION"     # 构建类（拼字、构建方程、组装电路）
    DRAWING = "DRAWING"               # 绘制类（画图、连线、圈选）
    COMPOSITE = "COMPOSITE"           # 复合类（多种交互组合）

class InteractionMode(str, Enum):
    """交互模式"""
    DRAG_DROP = "DRAG_DROP"           # 拖拽放置
    CLICK_SELECT = "CLICK_SELECT"     # 点击选择
    LINE_CONNECT = "LINE_CONNECT"     # 连线
    TEXT_INPUT = "TEXT_INPUT"         # 文本输入
    GESTURE = "GESTURE"               # 手势（缩放、旋转、滑动）
    VOICE = "VOICE"                   # 语音交互
    HYBRID = "HYBRID"                 # 混合交互

class ScoringStrategy(str, Enum):
    """评分策略"""
    EXACT_MATCH = "EXACT_MATCH"       # 精确匹配（全对得分）
    PARTIAL_CREDIT = "PARTIAL_CREDIT" # 部分得分（按正确比例）
    SET_BASED = "SET_BASED"           # 集合匹配（不考虑顺序）
    AI_JUDGE = "AI_JUDGE"             # AI 判定
    CUSTOM = "CUSTOM"                 # 自定义评分函数

class LayoutHint(str, Enum):
    """布局提示"""
    STACK = "STACK"                   # 垂直堆叠
    GRID = "GRID"                     # 网格布局
    HORIZONTAL = "HORIZONTAL"         # 水平排列
    VERTICAL = "VERTICAL"             # 垂直排列
    CANVAS = "CANVAS"                 # 自由画布
    TIMELINE = "TIMELINE"             # 时间轴
    TWO_COLUMN = "TWO_COLUMN"         # 双列布局
```

## 5. 评分引擎设计

### 5.1 评分策略架构

```python
from abc import ABC, abstractmethod
from typing import Any

class ScoringEngine(ABC):
    """评分策略接口"""
    
    @abstractmethod
    def score(
        self,
        user_answer: dict,
        correct_answer: dict,
        interaction_data: dict,
        config: dict
    ) -> dict:
        """
        执行评分
        返回: {
            "earned_score": int,
            "max_score": int,
            "is_correct": bool,
            "details": dict,
            "feedback": dict
        }
        """
        pass


class ExactMatchScoring(ScoringEngine):
    """精确匹配评分"""
    
    def score(self, user_answer, correct_answer, interaction_data, config):
        is_correct = (user_answer == correct_answer)
        max_score = config.get("maxScore", 10)
        earned = max_score if is_correct else 0
        
        return {
            "earned_score": earned,
            "max_score": max_score,
            "is_correct": is_correct,
            "details": {"match_type": "exact"},
            "feedback": self._build_feedback(is_correct, interaction_data)
        }


class PartialCreditScoring(ScoringEngine):
    """部分得分评分（按正确比例）"""
    
    def score(self, user_answer, correct_answer, interaction_data, config):
        max_score = config.get("maxScore", 10)
        pass_threshold = config.get("passThreshold", 0.6)
        
        # 计算正确项数
        correct_items = self._count_correct_items(user_answer, correct_answer, interaction_data)
        total_items = self._count_total_items(correct_answer, interaction_data)
        
        ratio = correct_items / total_items if total_items > 0 else 0
        earned = round(max_score * ratio)
        is_correct = ratio >= pass_threshold
        
        return {
            "earned_score": earned,
            "max_score": max_score,
            "is_correct": is_correct,
            "details": {
                "correct_count": correct_items,
                "total_count": total_items,
                "ratio": round(ratio, 2),
                "incorrect": self._get_incorrect_details(user_answer, correct_answer, interaction_data)
            },
            "feedback": self._build_feedback(ratio, is_correct)
        }


class SetBasedScoring(ScoringEngine):
    """集合匹配评分（不考虑顺序）"""
    
    def score(self, user_answer, correct_answer, interaction_data):
        user_set = self._to_set(user_answer)
        correct_set = self._to_set(correct_answer)
        
        correct_count = len(user_set & correct_set)
        total_count = len(correct_set)
        ratio = correct_count / total_count if total_count > 0 else 0
        
        return {
            "earned_score": round(config["maxScore"] * ratio),
            "max_score": config["maxScore"],
            "is_correct": ratio == 1.0,
            "details": {
                "correct_in_set": correct_count,
                "total_in_set": total_count,
                "extra_in_user_set": len(user_set - correct_set)
            }
        }
```

### 5.2 评分策略路由

```python
class ScoringRouter:
    """评分策略路由器"""
    
    STRATEGY_MAP = {
        "EXACT_MATCH": ExactMatchScoring(),
        "PARTIAL_CREDIT": PartialCreditScoring(),
        "SET_BASED": SetBasedScoring(),
        # AI_JUDGE 和 CUSTOM 通过独立服务处理
    }
    
    def score_exercise(
        self,
        exercise: InteractiveExercise,
        user_answer: dict,
        session_id: str = None
    ) -> dict:
        type_registry = self._get_type_registry(exercise.type_code)
        strategy_code = type_registry.scoring_strategy
        
        # 合并评分配置：模板默认 < 实例覆盖
        config = {
            **type_registry.scoring_config,
            **(exercise.scoring_override or {}),
            "maxScore": exercise.max_score
        }
        
        if strategy_code in self.STRATEGY_MAP:
            engine = self.STRATEGY_MAP[strategy_code]
            result = engine.score(
                user_answer=user_answer,
                correct_answer=exercise.correct_answer,
                interaction_data=exercise.interaction_data,
                config=config
            )
        elif strategy_code == "AI_JUDGE":
            result = self._ai_judge(exercise, user_answer, config)
        else:
            raise ValueError(f"Unsupported scoring strategy: {strategy_code}")
        
        # 记录评分日志
        self._log_scoring(exercise.id, user_answer, result, session_id)
        
        return result
```

### 5.3 题型专属评分逻辑

#### 5.3.1 DRAG_SORT 评分

```python
class DragSortScoring(PartialCreditScoring):
    
    def _count_correct_items(self, user_answer, correct_answer, interaction_data):
        user_order = user_answer.get("orderedIds", [])
        correct_order = correct_answer.get("orderedIds", [])
        
        # 方法1：位置正确数
        correct_positions = sum(
            1 for i, (u, c) in enumerate(zip(user_order, correct_order))
            if u == c
        )
        
        # 方法2：逆序对计算（Kendall Tau 距离）
        # 可用于更精细的评分
        
        return correct_positions
    
    def _count_total_items(self, correct_answer, interaction_data):
        return len(correct_answer.get("orderedIds", []))
    
    def _get_incorrect_details(self, user_answer, correct_answer, interaction_data):
        user_order = user_answer.get("orderedIds", [])
        correct_order = correct_answer.get("orderedIds", [])
        
        return [
            {
                "position": i,
                "userItemId": user_order[i] if i < len(user_order) else None,
                "correctItemId": correct_order[i]
            }
            for i in range(len(correct_order))
            if i >= len(user_order) or user_order[i] != correct_order[i]
        ]
```

#### 5.3.2 MATCH_PAIR 评分

```python
class MatchPairScoring(PartialCreditScoring):
    
    def _count_correct_items(self, user_answer, correct_answer, interaction_data):
        user_connections = {
            (c["left"], c["right"]) for c in user_answer.get("connections", [])
        }
        correct_connections = {
            (c["left"], c["right"]) for c in correct_answer.get("connections", [])
        }
        
        return len(user_connections & correct_connections)
    
    def _count_total_items(self, correct_answer, interaction_data):
        return len(correct_answer.get("connections", []))
    
    def _get_incorrect_details(self, user_answer, correct_answer, interaction_data):
        user_conn = {c["left"]: c["right"] for c in user_answer.get("connections", [])}
        correct_conn = {c["left"]: c["right"] for c in correct_answer.get("connections", [])}
        
        details = []
        for left_id, correct_right in correct_conn.items():
            user_right = user_conn.get(left_id)
            if user_right != correct_right:
                details.append({
                    "left": left_id,
                    "userRight": user_right,
                    "correctRight": correct_right
                })
        return details
```

### 6.2 装配引擎核心代码

```python
class ExerciseAssembler:
    """互动练习装配引擎"""
    
    def __init__(
        self,
        template_repo: TemplateRepository,
        type_registry_repo: TypeRegistryRepository,
        asset_service: AssetService,
        db_session: AsyncSession
    ):
        self.template_repo = template_repo
        self.type_registry_repo = type_registry_repo
        self.asset_service = asset_service
        self.db_session = db_session
    
    async def assemble(
        self,
        template_code: str,
        title: str,
        prompt: str,
        content_data: dict,
        options: dict = None
    ) -> dict:
        """
        根据模板和内容数据装配一道互动练习
        """
        options = options or {}
        
        # Step 1: 加载模板
        template = await self.template_repo.get_by_code(template_code)
        if not template or template.status != 'ACTIVE':
            raise BusinessError("ITRC_001", f"模板不存在或未激活: {template_code}")
        
        type_reg = await self.type_registry_repo.get_by_code(template.type_code)
        if not type_reg or type_reg.status != 'ACTIVE':
            raise BusinessError("ITRC_002", f"题型未注册或已废弃: {template.type_code}")
        
        # Step 2: 校验素材并获取CDN URL
        asset_codes = self._extract_asset_codes(content_data, template)
        asset_map = await self.asset_service.batch_get(asset_codes)
        self._validate_assets(asset_codes, asset_map, template)
        
        # Step 3: 根据题型调用对应的转换器
        transformer = self._get_transformer(template.type_code)
        interaction_data = transformer.to_interaction_data(
            content_data, template.schema_config, asset_map
        )
        correct_answer = transformer.to_correct_answer(content_data)
        
        # Step 4: 打乱处理
        shuffle = options.get("shuffle", template.default_config.get("shuffle", True))
        if shuffle:
            interaction_data = transformer.shuffle(interaction_data)
        
        # Step 5: 持久化
        exercise = InteractiveExercise(
            template_id=template.id,
            type_code=template.type_code,
            title=title,
            prompt=prompt,
            interaction_data=interaction_data,
            correct_answer=correct_answer,
            max_score=options.get("maxScore", template.default_score),
            subject=template.subject,
            stage=template.stage,
            knowledge_point_ids=options.get(
                "knowledgePointIds", template.knowledge_point_ids
            ),
            difficulty=options.get("difficulty", template.difficulty),
            source_type="TEMPLATE_INSTANTIATED"
        )
        
        await self.db_session.save(exercise)
        
        # Step 6: 构建返回数据
        return self._build_response(exercise, type_reg, asset_map)
    
    def _get_transformer(self, type_code: str) -> 'InteractionTransformer':
        """根据题型获取数据转换器"""
        transformers = {
            "DRAG_SORT": DragSortTransformer(),
            "MATCH_PAIR": MatchPairTransformer(),
            "CLASSIFY_SORT": ClassifySortTransformer(),
            "LABEL_DIAGRAM": LabelDiagramTransformer(),
            "BUILD_WORD": BuildWordTransformer(),
            "BUILD_EQUATION": BuildEquationTransformer(),
            "VOICE_READ": VoiceReadTransformer(),
        }
        
        if type_code not in transformers:
            raise BusinessError("ITRC_003", f"不支持的题型转换: {type_code}")
        
        return transformers[type_code]
```

### 6.3 题型数据转换器接口

```python
from abc import ABC, abstractmethod

class InteractionTransformer(ABC):
    """互动题型数据转换器接口"""
    
    @abstractmethod
    def to_interaction_data(
        self,
        content_data: dict,
        schema_config: dict,
        asset_map: dict
    ) -> dict:
        """将原始内容数据转换为标准 interaction_data 结构"""
        pass
    
    @abstractmethod
    def to_correct_answer(self, content_data: dict) -> dict:
        """从内容数据中提取标准答案"""
        pass
    
    @abstractmethod
    def shuffle(self, interaction_data: dict) -> dict:
        """打乱题目顺序/选项"""
        pass


class DragSortTransformer(InteractionTransformer):
    """拖拽排序题转换器"""
    
    def to_interaction_data(self, content_data, schema_config, asset_map):
        items = []
        for i, item in enumerate(content_data.get("items", [])):
            asset_id = None
            if item.get("imageAssetCode"):
                asset = asset_map.get(item["imageAssetCode"])
                asset_id = asset.asset_code if asset else None
            
            items.append({
                "id": f"item_{i+1}",
                "content": {"type": "TEXT", "value": item["text"]},
                "imageAssetId": asset_id
            })
        
        return {
            "type": "DRAG_SORT",
            "version": "1.0",
            "items": items,
            "displayOrder": "RANDOM",
            "slotCount": len(items),
            "orientation": schema_config.get("orientation", "VERTICAL"),
            "placeholder": schema_config.get("placeholder", "拖拽到此处排列")
        }
    
    def to_correct_answer(self, content_data):
        return {
            "orderedIds": [f"item_{i+1}" for i in range(len(content_data.get("items", [])))]
        }
    
    def shuffle(self, interaction_data):
        import random
        items = interaction_data["items"][:]
        random.shuffle(items)
        # items 顺序被打乱，但 id 不变，correct_answer 中的 orderedIds 仍指向正确顺序
        interaction_data["items"] = items
        return interaction_data


class MatchPairTransformer(InteractionTransformer):
    """连线匹配题转换器"""
    
    def to_interaction_data(self, content_data, schema_config, asset_map):
        pairs = content_data.get("pairs", [])
        left_items = []
        right_items = []
        correct_connections = []
        
        for i, pair in enumerate(pairs):
            left_id = f"L{i+1}"
            right_id = f"R{i+1}"
            
            # 左侧项
            left_items.append({
                "id": left_id,
                "content": {"type": "TEXT", "value": pair["left"]},
                "assetId": None
            })
            
            # 右侧项（可能是图片）
            asset = asset_map.get(pair.get("rightAssetCode"))
            right_items.append({
                "id": right_id,
                "content": {"type": "IMAGE" if asset else "TEXT", "value": pair.get("right")},
                "assetId": pair.get("rightAssetCode"),
                "cdnUrl": asset.cdn_url if asset else None
            })
            
            correct_connections.append({"left": left_id, "right": right_id})
        
        return {
            "type": "MATCH_PAIR",
            "version": "1.0",
            "leftItems": left_items,
            "rightItems": right_items,
            "leftHeader": schema_config.get("leftHeader", ""),
            "rightHeader": schema_config.get("rightHeader", ""),
            "maxConnections": 1
        }
    
    def to_correct_answer(self, content_data):
        pairs = content_data.get("pairs", [])
        return {
            "connections": [
                {"left": f"L{i+1}", "right": f"R{i+1}"}
                for i in range(len(pairs))
            ]
        }
    
    def shuffle(self, interaction_data):
        import random
        # 打乱右侧项顺序（左侧保持不变）
        right_items = interaction_data["rightItems"][:]
        random.shuffle(right_items)
        interaction_data["rightItems"] = right_items
        return interaction_data
```

## 10. 错误处理

### 10.1 错误码定义

| 错误码 | HTTP状态 | 错误信息 | 处理建议 |
|--------|---------|---------|---------|
| ITRC_001 | 400 | 模板不存在或未激活 | 检查模板编码，确认状态 |
| ITRC_002 | 400 | 题型未注册或已废弃 | 检查题型编码，确认注册状态 |
| ITRC_003 | 400 | 不支持的题型转换 | 检查是否有对应的 Transformer 实现 |
| ITRC_004 | 400 | 素材缺失 | 补充必需的素材资源 |
| ITRC_005 | 400 | 素材格式无效 | 检查素材尺寸/格式要求 |
| ITRC_006 | 400 | 评分数据格式错误 | 检查 user_answer 结构 |
| ITRC_007 | 404 | 练习实例不存在 | 检查 exercise_uuid |
| ITRC_008 | 409 | 练习已被禁用 | 该练习已下线，请使用新练习 |
| ITRC_009 | 422 | 内容数据不满足模板schema | 按 schema_config 要求补充数据 |
| ITRC_010 | 500 | 评分引擎内部错误 | 降级为 EXACT_MATCH 策略重试 |
| ITRC_011 | 400 | 客户端版本不支持该题型 | 提示用户升级App |

### 10.2 降级策略

| 异常场景 | 降级方案 |
|---------|---------|
| 素材CDN不可用 | 使用本地缓存或占位图，练习功能不受影响 |
| 评分引擎超时(>2s) | 客户端预校验结果即视为有效，服务端异步修正 |
| AI评分不可用 | 降级为规则评分（EXACT_MATCH或PARTIAL_CREDIT） |
| 题型未注册(客户端) | 显示"当前版本不支持此题型，请升级"提示 |

### 15.2 内容数据 Schema 校验工具

```python
import jsonschema

SCHEMAS = {
    "DRAG_SORT": {
        "type": "object",
        "required": ["items"],
        "properties": {
            "items": {
                "type": "array",
                "minItems": 2,
                "maxItems": 10,
                "items": {
                    "type": "object",
                    "required": ["text"],
                    "properties": {
                        "text": {"type": "string", "maxLength": 200},
                        "imageAssetCode": {"type": "string"}
                    }
                }
            }
        }
    },
    "MATCH_PAIR": {
        "type": "object",
        "required": ["pairs"],
        "properties": {
            "pairs": {
                "type": "array",
                "minItems": 2,
                "maxItems": 8,
                "items": {
                    "type": "object",
                    "required": ["left"],
                    "properties": {
                        "left": {"type": "string", "maxLength": 100},
                        "right": {"type": "string", "maxLength": 100},
                        "rightAssetCode": {"type": "string"}
                    }
                }
            }
        }
    }
}

def validate_content_data(type_code: str, content_data: dict) -> bool:
    schema = SCHEMAS.get(type_code)
    if not schema:
        return True  # 未定义schema的题型暂不校验
    jsonschema.validate(content_data, schema)
    return True
```
