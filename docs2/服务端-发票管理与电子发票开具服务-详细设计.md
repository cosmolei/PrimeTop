# 服务端-发票管理与电子发票开具服务 - 详细设计文档

## 1. 模块概述

发票管理服务负责为用户（主要为家长）提供消费凭证的开具、查询、下载和冲红功能。对接微信/支付宝/Apple IAP 支付完成后生成的订单，按用户申请自动或手动开具增值税电子普通发票，并支持退款时的红字发票处理。

### 1.1 功能范围

| 功能 | 优先级 | MVP |
|------|--------|-----|
| 发票抬头管理（个人/企业） | P1 | ✅ |
| 订单申请开票 | P1 | ✅ |
| 电子发票自动生成（对接第三方税务平台） | P1 | ✅ |
| 发票查询与下载 | P1 | ✅ |
| 发票开具状态回调通知 | P1 | ✅ |
| 退款红字发票冲红 | P2 | ❌ |
| 企业发票资质审核 | P2 | ❌ |
| 批量开票（B端） | P3 | ❌ |
| 发票数据对账与税务报表 | P2 | ❌ |

### 1.2 依赖关系

```
┌──────────────┐     ┌──────────────┐     ┌───────────────────┐
│  支付服务     │────▶│  发票服务     │────▶│  第三方税务平台     │
│ (订单完成回调) │     │ (开票/冲红)   │     │ (航信/百望/税友)    │
└──────────────┘     └──────┬───────┘     └───────────────────┘
                           │
                     ┌─────▼──────┐
                     │  通知服务    │
                     │ (开票结果推送)│
                     └────────────┘
```

- **上游**：支付与会员订阅服务（订单完成）、退款与售后处理服务（退款触发冲红）
- **下游**：通知中心（开票完成推送）、文件与资源存储服务（发票PDF存储）
- **外部依赖**：第三方电子发票平台（航信、百望、税友等）

## 2. 数据结构设计

### 2.1 发票抬头表 `invoice_titles`

用户保存的发票抬头信息，支持多个抬头。

```sql
CREATE TABLE invoice_titles (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID（家长账号）',
    title_type      TINYINT NOT NULL COMMENT '抬头类型: 1=个人, 2=企业',

    tax_number      VARCHAR(32) COMMENT '纳税人识别号（企业必填）',
    company_address VARCHAR(256) COMMENT '企业注册地址',
    company_phone   VARCHAR(32) COMMENT '企业联系电话',
    bank_name       VARCHAR(128) COMMENT '开户银行',
    bank_account    VARCHAR(64) COMMENT '银行账号',
    email           VARCHAR(128) COMMENT '接收发票的邮箱',
    is_default      TINYINT NOT NULL DEFAULT 0 COMMENT '是否默认抬头: 0=否, 1=是',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
```

#### 3.2.2 提交开票申请

```
POST /api/v1/invoice/applications
```

**请求体：**

```json
{
    "titleId": 1001,
    "orderIds": [20001, 20002],
    "email": "finance@example.com"
}
```

**校验规则：**
- `titleId` 必须属于当前用户
- `orderIds` 中的订单必须属于当前用户且状态为已支付
- 每个订单只能开一次发票（`invoice_order_relations` 中无记录）
- `orderIds` 数量 ≤ `MERGE_MAX_ORDERS`（20）
- 总金额在限制范围内
- `email` 可选，覆盖抬头中的默认邮箱

**处理流程：**

```
1. 参数校验
2. 查询订单，校验所有权和状态
3. 检查订单是否已开票
4. 计算总金额、税额（按 6% 税率）
5. 创建 invoice_application 记录（状态=PENDING_REVIEW 或 ISSUING）
6. 创建 invoice_order_relations 记录
7. 个人发票 → 直接提交第三方平台开票（状态→ISSUING）
   企业发票 → 等待人工审核（状态→PENDING_REVIEW）
8. 返回申请编号
```

**响应：**

```json
{
    "code": 0,
    "data": {
        "applicationNo": "INV202606051430000001",
        "status": "issuing",
        "totalAmountCents": 56000,
        "totalTaxCents": 3170,
        "totalWithoutTax": 52830,
        "orderCount": 2,
        "message": "开票申请已提交，预计1-2个工作日内完成"
    }
}
```

### 4.3 金额计算规则

```typescript
/**
 * 发票金额计算
 * 税率按"信息技术服务"类目 6% 计算
 */
function calculateInvoiceAmount(totalAmountCents: number): {
    totalAmountCents: number;   // 含税总金额 = 订单实付总额
    totalWithoutTax: number;    // 不含税金额 = 总额 / 1.06（向下取整到分）
    totalTaxCents: number;      // 税额 = 总额 - 不含税金额
} {
    const TAX_RATE = 0.06;
    const withoutTax = Math.floor(totalAmountCents / (1 + TAX_RATE));
    const tax = totalAmountCents - withoutTax;
    return {
        totalAmountCents,
        totalWithoutTax: withoutTax,
        totalTaxCents: tax
    };
}

// 示例: 28.00 元月度会员
// 含税: 2800 分
// 不含税: floor(2800/1.06) = 2641 分
// 税额: 2800 - 2641 = 159 分
```

## 5. 第三方税务平台对接

### 5.1 平台选择与适配

采用适配器模式封装第三方平台差异，支持多平台切换。

```typescript
interface InvoicePlatformAdapter {
    /**
     * 提交蓝字发票（正常开票）
     */
    issueInvoice(params: IssueInvoiceParams): Promise<IssueInvoiceResult>;

    /**
     * 提交红字发票（冲红）
     */
    issueRedInvoice(params: RedInvoiceParams): Promise<IssueInvoiceResult>;

    /**
     * 查询发票状态
     */
    queryInvoice(thirdPartyId: string): Promise<InvoiceQueryResult>;

    /**
     * 验证回调签名
     */
    verifyCallback(rawBody: string, signature: string): boolean;

    /**
     * 解析回调数据
     */
    parseCallback(rawBody: string): CallbackData;
}

interface IssueInvoiceParams {
    applicationNo: string;
    titleType: InvoiceTitleType;
    titleName: string;
    taxNumber?: string;
    companyAddress?: string;
    companyPhone?: string;
    bankName?: string;
    bankAccount?: string;
    email?: string;
    totalAmountCents: number;
    totalWithoutTax: number;
    totalTaxCents: number;
    items: InvoiceItem[];   // 商品明细
}

interface InvoiceItem {
    name: string;           // 商品名称，如"PrimeTop月度会员"
    specification: string;  // 规格型号
    unit: string;           // 单位
    quantity: number;       // 数量
    unitPriceCents: number; // 单价（不含税，分）
    amountCents: number;    // 金额（不含税，分）
    taxRate: number;        // 税率
    taxCents: number;       // 税额（分）
}

interface IssueInvoiceResult {
    thirdPartyId: string;   // 第三方流水号
    success: boolean;
    errorMsg?: string;
}
```

```typescript
async function handleInvoiceCallback(rawBody: string, signature: string) {
    // 1. 验签
    if (!adapter.verifyCallback(rawBody, signature)) {
        throw new InvalidSignatureError();
    }

    // 2. 记录回调日志
    const callbackLog = await saveCallbackLog(rawBody);

    // 3. 幂等检查：同一 thirdPartyId 的成功回调不重复处理
    const existing = await findApplicationByThirdPartyId(callbackLog.thirdPartyId);
    if (existing?.status === InvoiceStatus.ISSUED) {
        return; // 已处理
    }

    // 4. 解析回调数据
    const data = adapter.parseCallback(rawBody);

    // 5. 更新发票申请
    if (data.success) {
        await updateApplicationIssued(existing.id, {
            invoiceCode: data.invoiceCode,
            invoiceNumber: data.invoiceNumber,
            checkCode: data.checkCode,
            invoiceDate: data.invoiceDate,
            invoicePdfUrl: data.pdfUrl,
            invoiceOfdUrl: data.ofdUrl,
        });
        // 6. 通知用户
        await notificationService.sendInvoiceIssuedNotification(
            existing.user_id,
            existing.application_no
        );
    } else {
        await updateApplicationFailed(existing.id, data.errorMsg);
    }

    // 7. 标记回调已处理
    await markCallbackProcessed(callbackLog.id);
}
```

### 5.3 超时补偿机制

提交第三方平台后，如果超过 **24 小时** 未收到回调，主动查询。

```typescript
/**
 * 定时任务：每 30 分钟扫描一次超时未回调的申请
 */
async function checkTimeoutInvoices() {
    const timeout = new Date(Date.now() - 24 * 60 * 60 * 1000);
    const pendingApps = await findIssuingBefore(timeout);

    for (const app of pendingApps) {
        try {
            const result = await adapter.queryInvoice(app.third_party_id);
            if (result.status === 'issued') {
                await updateApplicationIssued(app.id, result);
            } else if (result.status === 'failed') {
                await updateApplicationFailed(app.id, result.errorMsg);
            }
            // 如果第三方状态仍为 processing，不做处理，下次继续检查
        } catch (err) {
            logger.error(`查询发票状态失败: ${app.application_no}`, err);
        }
    }
}
```

```typescript
// src/services/invoice/application.service.ts

@Injectable()
export class InvoiceApplicationService {

    constructor(
        private readonly titleRepo: InvoiceTitleRepository,
        private readonly orderRepo: OrderRepository,
        private readonly relationRepo: InvoiceOrderRelationRepository,
        private readonly appRepo: InvoiceApplicationRepository,
        private readonly invoicePlatform: InvoicePlatformAdapter,
        private readonly eventBus: EventBus,
    ) {}

    /**
     * 提交开票申请
     */
    async submitApplication(
        userId: number,
        dto: SubmitInvoiceDto
    ): Promise<InvoiceApplicationResult> {
        // 1. 校验抬头
        const title = await this.titleRepo.findById(dto.titleId);
        if (!title || title.userId !== userId || title.deletedAt) {
            throw new BizError('INVOICE_TITLE_NOT_FOUND', '发票抬头不存在');
        }

        // 2. 校验企业抬头必须有纳税人识别号
        if (title.titleType === InvoiceTitleType.ENTERPRISE && !title.taxNumber) {
            throw new BizError('TAX_NUMBER_REQUIRED', '企业抬头必须填写纳税人识别号');
        }

        // 3. 查询并校验订单
        const orders = await this.orderRepo.findByIdsAndUser(dto.orderIds, userId);
        if (orders.length !== dto.orderIds.length) {
            throw new BizError('ORDER_NOT_FOUND', '部分订单不存在或不属于当前用户');
        }

        // 4. 校验订单状态和是否已开票
        for (const order of orders) {
            if (order.status !== OrderStatus.PAID) {
                throw new BizError('ORDER_NOT_PAID', `订单 ${order.orderNo} 未支付，无法开票`);
            }
            const existing = await this.relationRepo.findByOrderId(order.id);
            if (existing) {
                throw new BizError('ORDER_ALREADY_INVOICED', `订单 ${order.orderNo} 已开票`);
            }
        }

        // 5. 计算金额
        const totalAmountCents = orders.reduce((sum, o) => sum + o.amountCents, 0);
        const { totalWithoutTax, totalTaxCents } = calculateInvoiceAmount(totalAmountCents);

        if (totalAmountCents < INVOICE_LIMITS.SINGLE_MIN_CENTS) {
            throw new BizError('AMOUNT_TOO_SMALL', '开票金额不能低于1元');
        }

        // 6. 创建申请记录
        const applicationNo = generateApplicationNo(); // INV + 时间戳 + 随机数
        const isPersonal = title.titleType === InvoiceTitleType.PERSONAL;
        const status = isPersonal ? InvoiceStatus.ISSUING : InvoiceStatus.PENDING_REVIEW;

        const application = await this.appRepo.create({
            applicationNo,
            userId,
            titleId: title.id,
            invoiceType: InvoiceType.VAT_ELECTRONIC_NORMAL,
            totalAmountCents,
            totalTaxCents,
            totalWithoutTax,
            status,
        });

        // 7. 创建关联记录
        await this.relationRepo.bulkCreate(
            orders.map(order => ({
                applicationId: application.id,
                orderId: order.id,
                orderNo: order.orderNo,
                amountCents: order.amountCents,
            }))
        );

        // 8. 个人发票直接提交第三方
        if (isPersonal) {
            await this.submitToPlatform(application, title, orders);
        }

        return {
            applicationNo,
            status,
            totalAmountCents,
            totalTaxCents,
            totalWithoutTax,
            orderCount: orders.length,
            message: isPersonal
                ? '开票申请已提交，预计1-2个工作日内完成'
                : '企业发票需审核，预计2-3个工作日内完成',
        };
    }

    /**
     * 提交到第三方开票平台
     */
    private async submitToPlatform(
        application: InvoiceApplication,
        title: InvoiceTitle,
        orders: Order[]
    ) {
        const items = orders.map(order => ({
            name: this.getOrderItemName(order),
            specification: '-',
            unit: '次',
            quantity: 1,
            unitPriceCents: Math.floor(order.amountCents / 1.06),
            amountCents: Math.floor(order.amountCents / 1.06),
            taxRate: 0.06,
            taxCents: order.amountCents - Math.floor(order.amountCents / 1.06),
        }));

        try {
            const result = await this.invoicePlatform.issueInvoice({
                applicationNo: application.applicationNo,
                titleType: title.titleType,
                titleName: title.titleName,
                taxNumber: title.taxNumber,
                companyAddress: title.companyAddress,
                companyPhone: title.companyPhone,
                bankName: title.bankName,
                bankAccount: title.bankAccount,
                email: title.email,
                totalAmountCents: application.totalAmountCents,
                totalWithoutTax: application.totalWithoutTax,
                totalTaxCents: application.totalTaxCents,
                items,
            });

            if (result.success) {
                await this.appRepo.update(application.id, {
                    thirdPartyId: result.thirdPartyId,
                });
            } else {
                await this.appRepo.update(application.id, {
                    status: InvoiceStatus.FAILED,
                    failReason: result.errorMsg,
                });
            }
        } catch (err) {
            logger.error(`提交开票平台失败: ${application.applicationNo}`, err);
            await this.appRepo.update(application.id, {
                status: InvoiceStatus.FAILED,
                failReason: `系统异常: ${err.message}`,
            });
        }
    }

    private getOrderItemName(order: Order): string {
        const typeMap = {
            new: 'PrimeTop会员订阅',
            renew: 'PrimeTop会员续费',
            upgrade: 'PrimeTop会员升级',
            addon: 'PrimeTop增值服务',
        };
        return typeMap[order.orderType] || 'PrimeTop服务';
    }
}
```

```typescript
// src/services/invoice/red-invoice.service.ts

@Injectable()
export class RedInvoiceService {

    /**
     * 退款成功后触发冲红
     * 由退款服务的领域事件触发
     */
    @EventHandler('order.refunded')
    async handleOrderRefunded(event: OrderRefundedEvent) {
        const { orderId, refundAmountCents } = event;

        // 1. 查找原发票
        const relation = await this.relationRepo.findByOrderId(orderId);
        if (!relation) {
            logger.info(`订单 ${orderId} 无发票，无需冲红`);
            return;
        }

        const originalApp = await this.appRepo.findById(relation.applicationId);
        if (!originalApp || originalApp.status !== InvoiceStatus.ISSUED) {
            logger.warn(`订单 ${orderId} 发票状态异常: ${originalApp?.status}`);
            return;
        }

        // 2. 判断是全额退款还是部分退款
        const isFullRefund = refundAmountCents >= relation.amountCents;
        const redAmountCents = isFullRefund
            ? relation.amountCents
            : refundAmountCents;

        // 3. 提交红字发票
        const { totalWithoutTax, totalTaxCents } = calculateInvoiceAmount(redAmountCents);

        const result = await this.invoicePlatform.issueRedInvoice({
            applicationNo: `RED_${originalApp.applicationNo}`,
            originalInvoiceCode: originalApp.invoiceCode,
            originalInvoiceNumber: originalApp.invoiceNumber,
            titleType: /* 从抬头获取 */ 1,
            titleName: /* 从抬头获取 */ '',
            totalAmountCents: redAmountCents,
            totalWithoutTax,
            totalTaxCents,
            reason: `退款冲红: 退款金额 ${redAmountCents / 100} 元`,
        });

        if (result.success) {
            // 4. 创建红字发票记录
            const redApp = await this.appRepo.create({
                applicationNo: `RED_${originalApp.applicationNo}`,
                userId: originalApp.userId,
                titleId: originalApp.titleId,
                invoiceType: InvoiceType.VAT_ELECTRONIC_NORMAL,
                totalAmountCents: redAmountCents,
                totalTaxCents,
                totalWithoutTax,
                status: InvoiceStatus.ISSUED,
                invoiceCode: result.invoiceCode,
                invoiceNumber: result.invoiceNumber,
                invoicePdfUrl: result.pdfUrl,
                thirdPartyId: result.thirdPartyId,
            });

            // 5. 更新原发票状态
            await this.appRepo.update(originalApp.id, {
                status: isFullRefund
                    ? InvoiceStatus.RED_INVOICED
                    : InvoiceStatus.ISSUED, // 部分冲红保持原状态
                redInvoiceId: redApp.id,
            });
        } else {
            // 冲红失败，加入告警
            logger.error(`冲红失败: ${originalApp.applicationNo}`, result.errorMsg);
            await alertService.sendAlert('发票冲红失败', {
                applicationNo: originalApp.applicationNo,
                orderId,
                reason: result.errorMsg,
            });
        }
    }
}
```

### 7.1 业务异常码

| 错误码 | HTTP 状态码 | 说明 | 处理建议 |
|--------|------------|------|---------|
| `INVOICE_TITLE_NOT_FOUND` | 404 | 抬头不存在 | 检查抬头 ID |
| `TAX_NUMBER_REQUIRED` | 400 | 企业抬头缺少纳税人识别号 | 补充填写 |
| `TAX_NUMBER_INVALID` | 400 | 纳税人识别号格式错误 | 检查格式 |
| `ORDER_NOT_FOUND` | 404 | 订单不存在 | 检查订单号 |
| `ORDER_NOT_PAID` | 400 | 订单未支付 | 先完成支付 |
| `ORDER_ALREADY_INVOICED` | 409 | 订单已开票 | 查看已开发票 |
| `AMOUNT_TOO_SMALL` | 400 | 开票金额不足最低限额 | 合并更多订单 |
| `TITLE_IN_USE` | 409 | 抬头已关联发票，无法删除 | 先处理发票 |
| `APPLICATION_NOT_FOUND` | 404 | 申请不存在 | 检查申请编号 |
| `INVALID_STATUS_TRANSITION` | 409 | 状态流转不合法 | 刷新页面 |
| `PLATFORM_ERROR` | 502 | 第三方平台调用失败 | 稍后重试 |
| `CALLBACK_VERIFY_FAILED` | 400 | 回调验签失败 | 联系平台排查 |
| `RED_INVOICE_FAILED` | 500 | 冲红失败 | 人工介入处理 |

### 7.2 重试策略

| 场景 | 重试策略 | 最大重试次数 |
|------|---------|-------------|
| 提交第三方平台网络超时 | 指数退避：1s → 2s → 4s → 8s | 3 次 |
| 回调处理失败 | 立即重试 1 次，失败后等待下次定时补偿 | 3 次 |
| 超时补偿查询 | 每 30 分钟检查一次 | 持续 7 天 |
| 冲红失败 | 不自动重试，人工介入 | 0 次 |

## 8. 安全与合规

### 8.1 数据安全

- **纳税人识别号**：加密存储（AES-256），查询时脱敏显示（保留前 6 后 4 位）
- **发票 PDF**：存储到私有 OSS bucket，下载 URL 带签名+有效期
- **回调验签**：所有第三方回调必须验证 HMAC-SHA256 签名
- **接口鉴权**：用户接口需登录 token，管理端接口需 RBAC 权限

### 8.2 合规要求

- 发票数据保留 **5 年**以上（税务合规）
- 冲红发票必须与原蓝字发票关联
- 发票金额必须与订单实付金额一致（不含优惠券抵扣部分）
- 退款金额对应的开票金额需冲红

### 8.3 防刷策略

- 同一用户每天最多提交 **10 次**开票申请
- 同一订单只能关联一张发票（唯一索引保障）
- 企业抬头需验证纳税人识别号真实性（接入工商信息 API，P2 阶段实现）

```
用户提交 → 写DB → 发领域事件 → 返回申请号
                                ↓
              EventListener 接收 → 提交第三方平台 → 更新状态
                                                  ↓
                              回调/超时补偿 → 更新状态 → 推送通知
```
