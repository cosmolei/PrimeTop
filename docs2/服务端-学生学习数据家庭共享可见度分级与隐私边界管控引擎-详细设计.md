# 服务端-学生学习数据家庭共享可见度分级与隐私边界管控引擎 详细设计

## 1. 概述

### 1.1 模块定位

本引擎是 PrimeTop 平台**未成年人数据治理**的核心组件，负责在学生、家长、教师、平台运营等多角色之间建立**精细化的数据可见度边界**。

产品覆盖幼儿园至高中（3-18 岁），不同年龄段学生对隐私的需求差异极大：
- **低龄用户（3-12 岁）**：家长需要全面了解学习情况，学生隐私需求低
- **初中用户（12-15 岁）**：家长需要关键信息可见，但学生开始有隐私意识
- **高中用户（15-18 岁）**：学生需要独立学习空间，家长仅需关键节点摘要

本引擎解决的核心问题：**谁能在什么条件下看到学生的哪些学习数据**。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 数据分类分级 | 将学生学习数据按敏感度分为 5 个等级 |
| 可见度规则计算 | 根据学生年龄、学段、家长关系类型等动态计算可见度 |
| 隐私升级调度 | 学生年龄增长时自动执行隐私边界调整 |
| 同意权管理 | 学生（达到一定年龄后）对家长查看特定数据的授权与撤销 |
| 数据范围过滤 | 对家长/教师查询请求进行实时数据字段级过滤 |
| 访问审计 | 记录所有跨角色数据访问行为 |

### 1.3 依赖关系

```
┌─────────────────────────────────────────────────────┐
│              家庭共享可见度管控引擎                    │
├─────────┬──────────┬──────────┬─────────────────────┤
│  用户服务 │ 学情分析  │ 家长中心  │  AI 对话服务       │
│ (年龄/学段)│(数据源)  │ (消费方)  │ (数据源)          │
├─────────┴──────────┴──────────┴─────────────────────┤
│  数据脱敏引擎 │ 审计日志服务 │ 通知服务 │ 隐私合规引擎   │
└─────────────────────────────────────────────────────┘
```

**上游依赖：**
- 用户服务：提供学生年龄、学段、年级信息
- 家庭账户服务：提供家长-学生绑定关系与权限类型
- 各业务服务：提供原始学习数据

**下游消费方：**
- 家长中心（BFF 层）：查询家长可见的学生数据
- 教师端：查询教师可见的学生数据
- 学情报告服务：生成不同受众版本的报告
- 数据脱敏引擎：根据可见度规则执行字段级脱敏

## 2. 数据模型

### 2.1 学生数据分类体系

将学生产生的所有学习数据按敏感度分为 5 个等级：

| 等级 | 名称 | 说明 | 数据示例 |
| --- | --- | --- | --- |
| L1 | 公开级 | 学生本人和家长均可见，无限制 | 学习目标、学习计划名称、成就徽章 |
| L2 | 基础级 | 家长默认可见，无特殊限制 | 学习时长统计、学科掌握度、任务完成率 |
| L3 | 教育级 | 家长可见摘要，详情需视年龄策略 | 错题数量趋势、薄弱知识点、考试成绩 |
| L4 | 敏感级 | 家长仅可见聚合统计，不可见原始内容 | AI 对话关键词、具体答题内容、学习行为细节 |
| L5 | 隐私级 | 仅学生本人可见，家长不可见 | AI 对话原文、笔记内容、收藏列表、搜索历史 |

### 2.2 数据字段分类映射表

```sql
-- 学生数据分类注册表：注册每个数据字段的安全等级
CREATE TABLE data_visibility_catalog (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    field_key       VARCHAR(128) NOT NULL COMMENT '字段唯一标识，如 ai_conversation.content',
    field_name      VARCHAR(128) NOT NULL COMMENT '字段中文名称',
    module          VARCHAR(64)  NOT NULL COMMENT '所属模块：ai_dialogue/mistake/exam/plan/...',
    base_level      TINYINT      NOT NULL COMMENT '基础安全等级 L1-L5',
    description     VARCHAR(512) NULL COMMENT '字段描述',
    is_aggregated   BOOLEAN      NOT NULL DEFAULT FALSE COMMENT '是否为聚合数据',
    parent_visible_by_default BOOLEAN NOT NULL DEFAULT TRUE COMMENT '家长是否默认可见',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_field_key (field_key),
    INDEX idx_module (module),
    INDEX idx_base_level (base_level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生数据字段分类注册表';
```

### 2.3 可见度策略表

```sql
-- 可见度策略：定义不同年龄段/学段下各等级数据的家长可见性规则
CREATE TABLE visibility_policy (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    policy_name         VARCHAR(64)  NOT NULL COMMENT '策略名称',
    stage               VARCHAR(32)  NOT NULL COMMENT '适用学段：kindergarten/primary/middle/high',
    age_min             INT          NOT NULL COMMENT '适用最小年龄',
    age_max             INT          NOT NULL COMMENT '适用最大年龄',
    data_level          TINYINT      NOT NULL COMMENT '数据等级 L1-L5',
    parent_visibility   VARCHAR(32)  NOT NULL COMMENT '家长可见度：full/summary/aggregated_only/none',
    summary_rule        VARCHAR(512) NULL     COMMENT '摘要生成规则描述（JSON）',
    can_student_consent BOOLEAN      NOT NULL DEFAULT FALSE COMMENT '学生是否可以主动授权家长查看',
    description         VARCHAR(512) NULL     COMMENT '策略说明',
    priority            INT          NOT NULL DEFAULT 0 COMMENT '优先级，数字越大优先级越高',
    is_active           BOOLEAN      NOT NULL DEFAULT TRUE,
    created_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_stage_age (stage, age_min, age_max),
    INDEX idx_data_level (data_level),
    INDEX idx_active_priority (is_active, priority DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据可见度策略表';
```

### 2.4 学生授权记录表

```sql
-- 学生对家长的数据访问授权记录（用于 L4/L5 数据在可授权策略下）
CREATE TABLE student_consent (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id      BIGINT      NOT NULL COMMENT '学生用户ID',
    parent_id       BIGINT      NOT NULL COMMENT '家长用户ID',
    field_key       VARCHAR(128) NOT NULL COMMENT '授权字段标识（关联data_visibility_catalog）',
    consent_type    VARCHAR(32) NOT NULL COMMENT '授权类型：one_time/period/permanent',
    expires_at      DATETIME     NULL     COMMENT '过期时间（one_time/period类型）',
    granted_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '授权时间',
    revoked_at      DATETIME     NULL     COMMENT '撤销时间',
    consent_source  VARCHAR(32) NOT NULL COMMENT '授权来源：student_app/parent_request/system_default',
    status          VARCHAR(16) NOT NULL DEFAULT 'active' COMMENT '状态：active/expired/revoked',
    note            VARCHAR(256) NULL     COMMENT '备注',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_student_parent (student_id, parent_id),
    INDEX idx_field_status (field_key, status),
    INDEX idx_expires (expires_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生数据访问授权记录';
```

### 2.5 隐私升级事件日志

```sql
-- 记录因年龄变化触发的隐私边界升级事件

    event_type      VARCHAR(64) NOT NULL COMMENT '事件类型：stage_transition/age_birthday/policy_update',
    from_stage      VARCHAR(32) NULL     COMMENT '原学段',
    to_stage        VARCHAR(32) NULL     COMMENT '新学段',
    from_age        INT         NULL     COMMENT '原年龄',
    to_age          INT         NULL     COMMENT '新年龄',
    changes_summary JSON        NOT NULL COMMENT '变更摘要（哪些数据可见性发生变化）',
    notified_parent BOOLEAN     NOT NULL DEFAULT FALSE COMMENT '是否已通知家长',
    notified_student BOOLEAN    NOT NULL DEFAULT FALSE COMMENT '是否已通知学生',
    created_at      DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_student (student_id),
    INDEX idx_event_type (event_type),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='隐私边界升级事件日志';
```

### 3.5 错误码定义

| 错误码 | HTTP Status | 说明 |
| --- | --- | --- |

## 4. 业务逻辑

### 4.1 可见度计算核心流程

```text
请求进入 → 提取(accessor, student, context)
    ↓
查询学生基础信息(age, stage)
    ↓
查询 data_visibility_catalog 获取目标字段的 base_level
    ↓
查询 visibility_policy 匹配(stage, age, data_level) → 获取 parent_visibility
    ↓
┌─ parent_visibility = "full" → 字段完全可见
├─ parent_visibility = "summary" → 按 summary_rule 生成摘要
├─ parent_visibility = "aggregated_only" → 仅返回聚合统计
└─ parent_visibility = "none" → 检查 student_consent
    ├─ 有有效授权 → 按 consent_type 返回
    └─ 无授权 → 字段过滤，返回 null 或不返回
    ↓
记录审计日志
    ↓
返回过滤后数据
```

### 4.2 年龄变更触发的隐私升级状态机

```text
学生年龄变化（生日触发）
        │
        ▼
┌───────────────────┐
│ 检测学段/年龄是否   │──否──→ 不处理
│ 跨越策略边界        │
└───────┬───────────┘
        │是
        ▼
┌───────────────────┐
│ 计算新旧策略差异    │
│ affected_fields =  │
│   新策略 vs 旧策略   │
└───────┬───────────┘
        │
        ▼
┌───────────────────┐
│ 执行隐私升级       │
│ - 更新缓存策略     │
│ - 失效旧授权      │
│ - 生成升级日志     │
└───────┬───────────┘
        │
        ▼
┌───────────────────┐    自动
│ 发送通知          │────────→ 家长：「孩子已进入XX阶段，部分数据将不再可见」

└───────────────────┘
```

### 4.3 学段转换矩阵

| 转换 | 影响等级 | 变化 | 说明 |
| --- | --- | --- | --- |
| kindergarten → primary | L4 | summary → aggregated_only | 行为数据仅见聚合 |
| kindergarten → primary | L5 | none → none (可授权) | 开始允许学生主动分享 |
| primary → middle | L3 | full → summary | 成绩详情变为趋势摘要 |
| primary → middle | L4 | aggregated_only → aggregated_only(增强) | 聚合维度增加 |
| middle → high | L2 | full → summary | 学习时长变为周摘要 |
| middle → high | L3 | summary → aggregated_only | 成绩仅见月度聚合 |
| middle → high | L4 | aggregated_only → none | 行为数据完全不可见 |

```text
授权创建（学生主动）
    │
    ▼
┌─────────┐    到期    ┌─────────┐
│ active  │──────────→│ expired │
└────┬────┘           └─────────┘

     ▼
┌─────────┐

└─────────┘

- 隐私升级时，affected consents → 自动 revoked
```

### 5.2 可见度引擎核心实现

```java
/**
 * 可见度规则引擎核心服务
 */
@Service
@Slf4j
public class VisibilityEngineService {

    @Autowired
    private VisibilityPolicyRepository policyRepository;

    @Autowired
    private DataVisibilityCatalogRepository catalogRepository;

    @Autowired
    private StudentConsentRepository consentRepository;

    @Autowired
    private DataAccessAuditService auditService;

    @Autowired
    private RedisTemplate<String, VisibilityCacheEntry> visibilityRedis;

    private static final String CACHE_KEY_PREFIX = "visibility:";
    private static final Duration CACHE_TTL = Duration.ofMinutes(30);

    /**
     * 为指定访问者计算学生数据的可见度决策
     *
     * @param accessorId   访问者ID（家长/教师）
     * @param accessorRole 访问者角色
     * @param studentId    学生ID
     * @param fieldKeys    需要查询的字段列表
     * @return 每个字段的可见度决策
     */
    public Map<String, VisibilityDecision> evaluateVisibility(
            Long accessorId, String accessorRole, Long studentId,
            List<String> fieldKeys, String accessContext) {

        // 1. 获取学生信息（优先从缓存）
        StudentBasicInfo studentInfo = getStudentBasicInfo(studentId);

        // 2. 查找适用的可见度策略（优先从缓存）
        List<VisibilityPolicy> policies = getApplicablePolicies(
                studentInfo.getStage(), studentInfo.getAge());

        // 3. 逐字段计算可见度
        Map<String, VisibilityDecision> decisions = new LinkedHashMap<>();

        for (String fieldKey : fieldKeys) {
            DataVisibilityCatalog catalog = catalogRepository.findByFieldKey(fieldKey);
            if (catalog == null) {
                log.warn("未注册的数据字段: {}, 默认设为 L5 不可见", fieldKey);
                decisions.put(fieldKey, VisibilityDecision.builder()
                        .fieldKey(fieldKey)
                        .visibility(ParentVisibility.NONE)
                        .filtered(true)
                        .filterReason("unregistered_field")
                        .build());
                continue;
            }

            VisibilityDecision decision = computeDecision(
                    catalog, policies, accessorId, accessorRole, studentId);
            decisions.put(fieldKey, decision);
        }

        // 4. 异步记录审计日志
        auditService.logAccessAsync(AccessAuditRecord.builder()
                .accessorId(accessorId)
                .accessorRole(accessorRole)
                .targetStudent(studentId)
                .accessContext(accessContext)
                .fieldsRequested(fieldKeys)
                .fieldsFiltered(decisions.values().stream()
                        .filter(VisibilityDecision::isFiltered)
                        .map(VisibilityDecision::getFieldKey)
                        .collect(Collectors.toList()))
                .build());

        return decisions;
    }

    /**
     * 计算单个字段的可见度决策
     */
    private VisibilityDecision computeDecision(
            DataVisibilityCatalog catalog,
            List<VisibilityPolicy> policies,
            Long accessorId, String accessorRole, Long studentId) {

        // 教师角色走不同的策略路径
        if ("teacher".equals(accessorRole)) {
            return computeTeacherVisibility(catalog, studentId);
        }

        // 家长角色
        // 找到该等级对应的策略
        VisibilityPolicy matchedPolicy = policies.stream()
                .filter(p -> p.getDataLevel() == catalog.getBaseLevel())
                .max(Comparator.comparingInt(VisibilityPolicy::getPriority))
                .orElse(null);

        if (matchedPolicy == null) {
            // 回退到默认策略：L1-L2 完全可见，L3+ 不可见
            ParentVisibility fallback = catalog.getBaseLevel() <= 2
                    ? ParentVisibility.FULL : ParentVisibility.NONE;
            return VisibilityDecision.builder()
                    .fieldKey(catalog.getFieldKey())
                    .dataLevel(DataLevel.fromValue(catalog.getBaseLevel()))
                    .visibility(fallback)
                    .policyName("fallback_default")
                    .build();
        }

        ParentVisibility visibility = ParentVisibility.valueOf(matchedPolicy.getParentVisibility());

        // 如果不可见，检查是否有学生授权
        if (visibility == ParentVisibility.NONE && matchedPolicy.isCanStudentConsent()) {
            Optional<StudentConsent> consent = consentRepository
                    .findActiveConsent(studentId, accessorId, catalog.getFieldKey());

            if (consent.isPresent()) {
                return VisibilityDecision.builder()
                        .fieldKey(catalog.getFieldKey())
                        .dataLevel(DataLevel.fromValue(catalog.getBaseLevel()))
                        .visibility(ParentVisibility.FULL)
                        .policyName(matchedPolicy.getPolicyName())
                        .activeConsent(mapToConsentRecord(consent.get()))
                        .build();
            }
        }

        // 构建摘要规则
        SummaryRule summaryRule = null;
        if (visibility == ParentVisibility.SUMMARY || visibility == ParentVisibility.AGGREGATED_ONLY) {
            summaryRule = parseSummaryRule(matchedPolicy.getSummaryRule());
        }

        return VisibilityDecision.builder()
                .fieldKey(catalog.getFieldKey())
                .dataLevel(DataLevel.fromValue(catalog.getBaseLevel()))
                .visibility(visibility)
                .policyName(matchedPolicy.getPolicyName())
                .summaryRule(summaryRule)
                .filtered(visibility == ParentVisibility.NONE)
                .filterReason(visibility == ParentVisibility.NONE ? "policy_blocked" : null)
                .build();
    }

    /**
     * 批量过滤数据（供 BFF 层调用）
     */
    public Map<String, Object> filterData(
            Long accessorId, String accessorRole, Long studentId,
            String accessContext, Map<String, Object> rawData) {

        List<String> fieldKeys = new ArrayList<>(rawData.keySet());

        Map<String, VisibilityDecision> decisions = evaluateVisibility(
                accessorId, accessorRole, studentId, fieldKeys, accessContext);

        Map<String, Object> filtered = new LinkedHashMap<>();
        List<String> removedFields = new ArrayList<>();
        List<String> summarizedFields = new ArrayList<>();

        for (Map.Entry<String, Object> entry : rawData.entrySet()) {
            String key = entry.getKey();
            VisibilityDecision decision = decisions.get(key);

            if (decision == null || !decision.isVisible()) {
                removedFields.add(key);
                continue;
            }

            switch (decision.getVisibility()) {
                case FULL:
                    filtered.put(key, entry.getValue());
                    break;
                case SUMMARY:
                    filtered.put(key, applySummaryRule(entry.getValue(), decision.getSummaryRule()));
                    summarizedFields.add(key);
                    break;
                case AGGREGATED_ONLY:
                    filtered.put(key + "_aggregated",
                            applyAggregationRule(entry.getValue(), decision.getSummaryRule()));
                    summarizedFields.add(key);
                    break;
                case NONE:
                    removedFields.add(key);
                    break;
            }
        }

        // 添加元数据
        filtered.put("_meta", Map.of(
                "fieldsRemoved", removedFields,
                "fieldsSummarized", summarizedFields,
                "policyApplied", decisions.values().stream()
                        .map(VisibilityDecision::getPolicyName)
                        .distinct().findFirst().orElse("unknown"),
                "timestamp", Instant.now().toString()
        ));

        return filtered;
    }

    /**
     * 获取缓存 key
     */
    private String buildCacheKey(Long studentId) {
        return CACHE_KEY_PREFIX + "student:" + studentId + ":policies";
    }

    /**
     * 解析摘要规则 JSON
     */
    private SummaryRule parseSummaryRule(String json) {
        if (StringUtils.isBlank(json)) return null;
        try {
            return objectMapper.readValue(json, SummaryRule.class);
        } catch (Exception e) {
            log.error("解析摘要规则失败: {}", json, e);
            return null;
        }
    }
}
```

```java
/**
 * 隐私边界升级调度服务
 * 每日定时检查学生生日/学段变化，执行隐私边界调整
 */
@Service
@Slf4j
public class PrivacyEscalationScheduler {

    @Autowired
    private UserStudentService studentService;

    @Autowired
    private VisibilityPolicyRepository policyRepository;

    @Autowired
    private StudentConsentRepository consentRepository;

    @Autowired
    private PrivacyEscalationLogRepository escalationLogRepository;

    @Autowired
    private NotificationService notificationService;

    /**
     * 每日凌晨 1:00 执行隐私升级检查
     */
    @Scheduled(cron = "0 0 1 * * ?")
    public void checkPrivacyEscalation() {
        log.info("开始执行隐私边界升级检查...");

        // 1. 查询今天生日的学生（年龄+1）
        List<StudentBasicInfo> birthdayStudents = studentService
                .findStudentsWithBirthdayToday();

        int escalated = 0;
        for (StudentBasicInfo student : birthdayStudents) {
            try {
                boolean changed = processAgeTransition(student);
                if (changed) escalated++;
            } catch (Exception e) {
                log.error("隐私升级处理异常: studentId={}", student.getUserId(), e);
            }
        }

        // 2. 查询学段切换的学生（新学年）
        List<StudentBasicInfo> stageTransitionStudents = studentService
                .findStudentsWithStageTransitionToday();
        for (StudentBasicInfo student : stageTransitionStudents) {
            try {
                processStageTransition(student);
            } catch (Exception e) {
                log.error("学段切换隐私调整异常: studentId={}", student.getUserId(), e);
            }
        }

        log.info("隐私边界升级检查完成：{} 名学生执行了升级", escalated);
    }

    /**
     * 处理年龄变更导致的隐私升级
     */
    private boolean processAgeTransition(StudentBasicInfo student) {
        int newAge = student.getAge(); // 已更新为今天年龄
        int oldAge = newAge - 1;

        // 获取新旧年龄对应的策略
        List<VisibilityPolicy> oldPolicies = policyRepository
                .findActivePolicies(student.getStage(), oldAge);
        List<VisibilityPolicy> newPolicies = policyRepository
                .findActivePolicies(student.getStage(), newAge);

        // 比较策略差异
        List<PolicyChange> changes = diffPolicies(oldPolicies, newPolicies);

        if (changes.isEmpty()) {
            return false; // 无变化
        }

        // 处理策略变更
        List<String> affectedFields = new ArrayList<>();
        for (PolicyChange change : changes) {
            if (change.newVisibility == ParentVisibility.NONE
                    && change.oldVisibility != ParentVisibility.NONE) {
                // 可见 → 不可见：失效相关授权
                consentRepository.revokeByStudentAndLevel(
                        student.getUserId(), change.dataLevel, "privacy_escalation");
                affectedFields.addAll(change.affectedFieldKeys);
            }
        }

        // 清除可见度缓存
        visibilityRedis.delete(CACHE_KEY_PREFIX + "student:" + student.getUserId() + ":policies");

        // 记录升级日志
        PrivacyEscalationLog logEntry = PrivacyEscalationLog.builder()
                .studentId(student.getUserId())
                .eventType("age_birthday")
                .fromAge(oldAge)
                .toAge(newAge)
                .changesSummary(objectMapper.writeValueAsString(changes))
                .build();
        escalationLogRepository.save(logEntry);

        // 发送通知
        notificationService.sendPrivacyEscalationNotice(student, changes);

        return true;
    }

    /**
     * 策略差异计算
     */
    private List<PolicyChange> diffPolicies(
            List<VisibilityPolicy> oldPolicies,
            List<VisibilityPolicy> newPolicies) {

        List<PolicyChange> changes = new ArrayList<>();
        Map<Integer, VisibilityPolicy> oldMap = oldPolicies.stream()
                .collect(Collectors.toMap(VisibilityPolicy::getDataLevel, p -> p));
        Map<Integer, VisibilityPolicy> newMap = newPolicies.stream()
                .collect(Collectors.toMap(VisibilityPolicy::getDataLevel, p -> p));

        for (Integer level : newMap.keySet()) {
            VisibilityPolicy oldP = oldMap.get(level);
            VisibilityPolicy newP = newMap.get(level);

            if (oldP == null || !oldP.getParentVisibility().equals(newP.getParentVisibility())) {
                changes.add(PolicyChange.builder()
                        .dataLevel(level)
                        .oldVisibility(oldP != null
                                ? ParentVisibility.valueOf(oldP.getParentVisibility()) : null)
                        .newVisibility(ParentVisibility.valueOf(newP.getParentVisibility()))
                        .affectedFieldKeys(catalogRepository
                                .findFieldKeysByLevel(level))
                        .build());
            }
        }
        return changes;
    }
}
```

```java
/**
 * 学生授权管理服务

@Service
@Transactional
public class ConsentService {

    @Autowired
    private StudentConsentRepository consentRepository;

    @Autowired
    private VisibilityPolicyRepository policyRepository;

    @Autowired
    private DataVisibilityCatalogRepository catalogRepository;

    @Autowired
    private NotificationService notificationService;

    @Autowired
    private DataAccessAuditService auditService;

    // 最小授权年龄：12岁（小学高年级开始有自主授权能力）
    private static final int MIN_CONSENT_AGE = 12;
    // 单次授权最长有效期
    private static final int MAX_CONSENT_DAYS = 90;
    // 续期次数上限
    private static final int MAX_RENEWALS = 3;

    /**
     * 学生授权家长查看特定数据
     */
    public ConsentResult grantConsent(ConsentGrantRequest request, int studentAge) {
        // 1. 校验学生年龄
        if (studentAge < MIN_CONSENT_AGE) {
            throw new BizException(40002,
                "未达到自主授权年龄（需满" + MIN_CONSENT_AGE + "岁）");
        }

        // 2. 校验字段是否允许授权
        for (String fieldKey : request.getFieldKeys()) {
            DataVisibilityCatalog catalog = catalogRepository.findByFieldKey(fieldKey);
            if (catalog == null) {
                throw new BizException(40007, "未知字段: " + fieldKey);
            }

            VisibilityPolicy policy = policyRepository
                    .findActivePolicy(getStageByAge(studentAge), studentAge, catalog.getBaseLevel());

            if (policy == null || !policy.isCanStudentConsent()) {
                throw new BizException(40003,
                    "字段[" + catalog.getFieldName() + "]不在可授权范围内");
            }
        }

        // 3. 检查是否已有有效授权（避免重复）
        List<StudentConsent> existing = consentRepository
                .findActiveConsents(request.getStudentId(), request.getParentId(),
                        request.getFieldKeys());
        if (!existing.isEmpty()) {
            throw new BizException(40005, "已存在有效授权，请勿重复授权");
        }

        // 4. 计算过期时间
        LocalDateTime expiresAt = null;
        if (!"permanent".equals(request.getConsentType())) {
            int days = Math.min(request.getDurationDays() != null
                    ? request.getDurationDays() : 7, MAX_CONSENT_DAYS);
            expiresAt = LocalDateTime.now().plusDays(days);
        }

        // 5. 创建授权记录
        List<StudentConsent> consents = new ArrayList<>();
        for (String fieldKey : request.getFieldKeys()) {
            StudentConsent consent = new StudentConsent();
            consent.setStudentId(request.getStudentId());
            consent.setParentId(request.getParentId());
            consent.setFieldKey(fieldKey);
            consent.setConsentType(request.getConsentType());
            consent.setExpiresAt(expiresAt);
            consent.setConsentSource("student_app");
            consent.setStatus("active");
            consent.setNote(request.getNote());
            consents.add(consent);
        }
        consentRepository.batchInsert(consents);

        // 6. 通知家长
        notificationService.sendConsentGrantedNotice(
                request.getParentId(), request.getStudentId(),
                request.getFieldKeys(), expiresAt);

        // 7. 记录审计
        auditService.logConsentOperation(
                request.getStudentId(), "grant", request.getFieldKeys());

        return ConsentResult.builder()
                .consentIds(consents.stream().map(StudentConsent::getId).collect(Collectors.toList()))
                .expiresAt(expiresAt)
                .build();
    }

    /**
     * 学生撤销授权
     */
    public void revokeConsent(Long studentId, List<Long> consentIds) {
        int updated = consentRepository.revokeByIds(studentId, consentIds, LocalDateTime.now());
        log.info("学生{}撤销了{}条授权", studentId, updated);

        // 记录审计
        auditService.logConsentOperation(studentId, "revoke",
                consentRepository.findFieldKeysByIds(consentIds));
    }

    /**
     * 定时清理过期授权
     */
    @Scheduled(cron = "0 30 1 * * ?")
    public void expireOverdueConsents() {
        int count = consentRepository.expireOverdue(LocalDateTime.now());
        if (count > 0) {
            log.info("已自动过期{}条授权记录", count);
        }
    }
}
```

```java
/**
 * 方法级数据过滤注解：标注在 Controller 方法上，自动过滤响应数据
 */
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface VisibilityFilter {
    /** 学生ID参数名（SpEL表达式，默认从路径变量/请求参数取） */
    String studentIdExpr() default "#studentId";
    /** 访问者角色 */
    String accessorRole() default "parent";
    /** 访问上下文 */
    String accessContext() default "api_query";
}

/**
 * AOP 切面实现
 */
@Aspect
@Component
@Slf4j
public class VisibilityFilterAspect {

    @Autowired
    private VisibilityEngineService visibilityEngine;

    @Around("@annotation(filter)")
    public Object applyVisibilityFilter(ProceedingJoinPoint pjp, VisibilityFilter filter) throws Throwable {
        Object result = pjp.proceed();

        // 从方法参数中解析 studentId
        Long studentId = resolveStudentId(pjp, filter.studentIdExpr());
        // 从 SecurityContext 获取当前用户
        Long accessorId = SecurityContextHolder.getContext().getUserId();

        if (result instanceof Map) {
            @SuppressWarnings("unchecked")
            Map<String, Object> dataMap = (Map<String, Object>) result;
            return visibilityEngine.filterData(
                    accessorId, filter.accessorRole(), studentId,
                    filter.accessContext(), dataMap);
        }

        // 对于自定义对象，通过反射转为 Map 后过滤
        Map<String, Object> dataMap = objectMapper.convertValue(result,
                new TypeReference<Map<String, Object>>() {});
        return visibilityEngine.filterData(
                accessorId, filter.accessorRole(), studentId,
                filter.accessContext(), dataMap);
    }
}
```

## 6. 错误处理

### 6.1 异常分类与处理策略

| 异常类型 | 触发场景 | 处理策略 | HTTP Status |
| --- | --- | --- | --- |
| `PolicyNotFoundException` | 找不到匹配的可见度策略 | 回退到默认策略(L1-L2 full, L3+ none)，记录 WARN 日志 | 200(降级) |

### 6.2 降级策略

```java
/**
 * 可见度引擎降级处理器
 * 当引擎不可用时，使用本地缓存的最保守策略
 */
@Component
@Slf4j
public class VisibilityFallbackHandler {

    // 降级策略：保守模式
    // L1-L2 完全可见，L3+ 不可见（安全优先）
    private static final Map<Integer, ParentVisibility> FALLBACK_POLICY = Map.of(
            1, ParentVisibility.FULL,
            2, ParentVisibility.FULL,
            3, ParentVisibility.NONE,
            4, ParentVisibility.NONE,
            5, ParentVisibility.NONE
    );

    public Map<String, Object> fallbackFilter(Map<String, Object> rawData) {
        log.warn("可见度引擎不可用，使用降级保守策略");
        Map<String, Object> filtered = new LinkedHashMap<>();
        for (Map.Entry<String, Object> entry : rawData.entrySet()) {
            Integer level = estimateLevelFromKey(entry.getKey());
            if (level != null && FALLBACK_POLICY.get(level) == ParentVisibility.FULL) {
                filtered.put(entry.getKey(), entry.getValue());
            }
        }
        filtered.put("_meta", Map.of(
                "fallback", true,
                "message", "数据展示受限，完整数据稍后恢复"
        ));
        return filtered;
    }

    private Integer estimateLevelFromKey(String key) {
        if (key.contains("profile") || key.contains("achievement")) return 1;
        if (key.contains("stats") || key.contains("subject.mastery")) return 2;
        if (key.contains("exam") || key.contains("mistake") || key.contains("weak")) return 3;
        if (key.contains("behavior") || key.contains("ai_dialogue") && key.contains("topic")) return 4;
        if (key.contains("content") || key.contains("note") || key.contains("search")) return 5;
        return 5; // 未知字段默认 L5
    }
}
```

## 7. 性能优化

### 7.1 缓存策略

| 缓存层 | Key 格式 | TTL | 失效触发 |
| --- | --- | --- | --- |
| L1 本地缓存 (Caffeine) | `vis:local:{studentId}:policies` | 5 分钟 | 内存上限自动淘汰 |
| L2 Redis 缓存 | `visibility:student:{studentId}:policies` | 30 分钟 | 隐私升级/策略变更 |
| L3 数据库 | `visibility_policy` 表 | - | 管理后台操作 |

**缓存预热：** 每日凌晨 2:00 对活跃用户（7日内有登录）执行策略缓存预热。

**缓存失效：**
```java
/**
 * 缓存失效事件处理
 */
@EventListener
public void onPolicyChanged(PolicyChangeEvent event) {
    if (event.getScope() == PolicyChangeScope.GLOBAL) {
        // 全局策略变更：清除所有缓存
        visibilityRedis.scanAndDelete(CACHE_KEY_PREFIX + "*");
        localCache.invalidateAll();
    } else if (event.getScope() == PolicyChangeScope.STUDENT) {
        // 单学生变更（如隐私升级）
        visibilityRedis.delete(CACHE_KEY_PREFIX + "student:" + event.getStudentId() + ":policies");
        localCache.invalidate(event.getStudentId());
    }
}
```

### 7.2 并发控制

- **可见度计算**：无状态查询，支持高并发，无需加锁
- **授权操作**：基于 `student_id + parent_id + field_key` 唯一索引防止重复授权
- **隐私升级**：使用分布式锁 `privacy:escalation:{studentId}` 确保同一学生升级串行化

| 数据表 | 预估数据量(100万用户) | 优化措施 |
| --- | --- | --- |
| `data_visibility_catalog` | ~50 行（固定） | 全量加载内存 |

## 8. 安全考虑

### 8.1 权限控制

- 只有学生本人可以执行授权操作（grant/revoke），家长不能代替学生授权
- 后台管理员可以查看策略配置但不能修改单个学生的授权关系
- 教师/学校角色的数据可见度由独立的教师可见度策略管理（不在本引擎范围内，但走类似框架）

### 8.2 数据验证

- 所有 API 入参校验：studentId/parentId 必须为有效绑定关系
- fieldKey 必须在 `data_visibility_catalog` 中注册
- 策略变更操作需要管理员双因素认证

### 8.3 合规映射

| 法规要求 | 对应实现 |
| --- | --- |
| 《个人信息保护法》第31条（未成年人个人信息） | 分龄可见度策略，12岁以下需要监护人同意 |
| 《未成年人保护法》第72条（网络保护） | L4/L5 数据默认不可见，防沉迷联动 |
| 《未成年人网络保护条例》第23条 | 家长控制与学生隐私的平衡机制 |
| GB/T 41391-2022（个人信息安全规范） | 最小必要原则，数据分级分类 |

### 8.4 审计要求

所有跨角色数据访问必须记录审计日志，保留期≥3年。审计日志包含：
- 访问者身份与角色
- 被访问学生
- 请求字段与实际返回字段
- 应用的策略
- 时间戳与 IP

## 11. 与其他模块的协作

### 11.1 与家长中心的关系

家长中心 BFF 层在组装数据时，必须通过本引擎的 `filterData` 接口过滤后才返回前端。所有家长端 API 必须标注 `@VisibilityFilter` 注解。

### 11.2 与 AI 对话服务的关系

AI 对话内容（L5）默认不向家长开放。当家长请求查看孩子的 AI 对话时：
1. 先检查学生是否已授权
2. 如未授权，向学生发送授权请求通知
3. 学生同意后创建临时授权记录
4. 家长在授权有效期内可查看

### 11.3 与学情报告的关系

学情报告服务在生成家长版本报告时，调用本引擎获取可见字段列表，仅包含可见数据。学生版报告不受限制。

### 11.4 与通知服务的关系

本引擎在以下场景触发通知：
- 隐私升级（学段/年龄变更）→ 通知家长和学生
- 学生授权 → 通知家长
- 授权即将过期（提前24h）→ 通知学生
- 授权被撤销 → 通知家长

### 11.5 与防沉迷系统的关系

防沉迷系统触发的限制操作不需要通过本引擎（它是设备级/时间级的控制），但防沉迷事件本身对家长可见（属于 L2 数据）。
