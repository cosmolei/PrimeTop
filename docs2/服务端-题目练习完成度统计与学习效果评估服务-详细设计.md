# 服务端-题目练习完成度统计与学习效果评估服务 - 详细设计

## 1. 文档概述

### 1.1 文档目的

本文档详细设计"题目练习完成度统计与学习效果评估服务"（Practice Analytics & Effectiveness Evaluation Service，简称 PAEES），为开发人员提供可直接编码的详细设计。本服务负责：

1. 统计用户在各维度（学科、章节、知识点、题型、难度）的练习完成情况
2. 评估每次练习会话的学习效果（正确率变化、知识点掌握度提升）
3. 计算周期性（日/周/月）练习绩效指标
4. 生成知识点维度的改进度量和薄弱项动态列表
5. 为自适应推荐引擎和学习报告提供数据支撑

### 1.3 上游依赖

| 依赖服务 | 接口 | 说明 |
|----------|------|------|
| 练习会话服务 | `GET /practice/session/{id}` | 获取练习会话详情（题目列表、配置） |
| 答题事件服务 | Kafka Topic `answer-events` | 实时答题事件流 |
| 题目服务 | `GET /question/{id}` | 获取题目元信息（知识点、难度、题型） |
| 知识点掌握度服务 | `GET /mastery/{userId}/{kpId}` | 获取知识点实时掌握度 |
| 错题服务 | `GET /mistakes/stats/{userId}` | 获取错题统计数据 |

### 1.4 下游消费方

| 消费方 | 使用场景 |
|--------|----------|
| 自适应推荐引擎 | 根据完成度和效果指标调整推荐策略 |
| 学习报告服务 | 输出日/周/月练习报告 |
| 学情分析页面 | 展示学科/知识点练习分布 |
| 错题复习调度 | 根据效果评估安排复习计划 |
| 家长报告推送 | 向家长推送孩子练习情况摘要 |

## 2. 核心数据结构

### 2.1 练习完成度快照（practice_completion_snapshot）

存储用户在各维度的练习完成度聚合快照，每天凌晨定时刷新。

```sql
CREATE TABLE practice_completion_snapshot (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    snapshot_date   DATE NOT NULL COMMENT '快照日期',
    
    -- 维度标识
    dimension_type  VARCHAR(20) NOT NULL COMMENT '维度类型: SUBJECT/CHAPTER/KNOWLEDGE_POINT/QUESTION_TYPE/DIFFICULTY',
    dimension_id    VARCHAR(64) NOT NULL COMMENT '维度值ID（学科ID/章节ID/知识点ID等）',
    
    -- 统计周期
    period_type     VARCHAR(10) NOT NULL COMMENT '统计周期: DAILY/WEEKLY/MONTHLY/ALL_TIME',
    
    -- 完成度指标
    total_assigned  INT NOT NULL DEFAULT 0 COMMENT '被分配/推荐的题目总数',
    total_attempted INT NOT NULL DEFAULT 0 COMMENT '已作答题目数（含未提交）',
    total_submitted INT NOT NULL DEFAULT 0 COMMENT '已提交题目数',
    total_correct   INT NOT NULL DEFAULT 0 COMMENT '正确题目数',
    total_wrong     INT NOT NULL DEFAULT 0 COMMENT '错误题目数',
    total_skipped   INT NOT NULL DEFAULT 0 COMMENT '跳过题目数',
    total_timeout   INT NOT NULL DEFAULT 0 COMMENT '超时未答题目数',
    
    -- 比率指标（冗余存储，避免实时计算）
    completion_rate DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '完成率 = submitted / assigned',
    accuracy_rate   DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '正确率 = correct / submitted',
    attempt_rate    DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '尝试率 = attempted / assigned',
    
    -- 时长指标（秒）
    total_duration  INT NOT NULL DEFAULT 0 COMMENT '总答题耗时',
    avg_duration    INT NOT NULL DEFAULT 0 COMMENT '平均单题耗时',
    
    -- 元数据
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_user_dim_period (user_id, dimension_type, dimension_id, period_type, snapshot_date),
    INDEX idx_user_date (user_id, snapshot_date),
    INDEX idx_dim_period (dimension_type, dimension_id, period_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='练习完成度快照';
```

### 2.2 学习效果评估记录（learning_effect_record）

记录每次评估的结果，用于追踪效果趋势和驱动推荐。

```sql
CREATE TABLE learning_effect_record (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    
    -- 关联实体
    session_id      BIGINT COMMENT '关联的练习会话ID（会话级评估时有值）',
    knowledge_point_id VARCHAR(64) COMMENT '关联的知识点ID（知识点级评估时有值）',
    
    -- 评估粒度
    granularity     VARCHAR(20) NOT NULL COMMENT '评估粒度: SESSION/KNOWLEDGE_POINT/DAILY/WEEKLY',
    
    -- 前后对比指标
    accuracy_before DECIMAL(5,4) COMMENT '评估前正确率',
    accuracy_after  DECIMAL(5,4) COMMENT '评估后正确率',
    accuracy_delta  DECIMAL(5,4) COMMENT '正确率变化（正=提升）',
    
    mastery_before  DECIMAL(5,4) COMMENT '评估前掌握度(0~1)',
    mastery_after   DECIMAL(5,4) COMMENT '评估后掌握度(0~1)',
    mastery_delta   DECIMAL(5,4) COMMENT '掌握度变化',
    
    -- 练习量
    question_count  INT NOT NULL DEFAULT 0 COMMENT '本次评估涵盖的题目数',
    practice_duration INT NOT NULL DEFAULT 0 COMMENT '本次评估涵盖的练习时长(秒)',
    
    -- 效果等级（由评估算法计算）
    effect_level    VARCHAR(10) NOT NULL COMMENT '效果等级: SIGNIFICANT/MODERATE/MARGINAL/STAGNANT/DECLINED',
    effect_score    DECIMAL(5,2) NOT NULL DEFAULT 0 COMMENT '效果评分(0~100)',
    
    -- 诊断信息
    weak_sub_types  JSON COMMENT '薄弱题型列表 [{"type":"choice","accuracy":0.3}]',
    error_pattern   JSON COMMENT '错误模式摘要 [{"pattern":"calculation_error","count":5}]',
    improvement_hint TEXT COMMENT '改进建议',
    
    -- 元数据
    evaluated_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '评估时间',
    
    INDEX idx_user_gran (user_id, granularity),
    INDEX idx_user_kp (user_id, knowledge_point_id),
    INDEX idx_user_time (user_id, evaluated_at),
    INDEX idx_session (session_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习效果评估记录';
```

### 2.3 知识点练习进度（kp_practice_progress）

跟踪每个用户在每个知识点上的练习进度和状态。

```sql
CREATE TABLE kp_practice_progress (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id             BIGINT NOT NULL,
    knowledge_point_id  VARCHAR(64) NOT NULL COMMENT '知识点ID',
    subject_id          INT NOT NULL COMMENT '学科ID',
    
    -- 练习状态
    status              VARCHAR(20) NOT NULL DEFAULT 'NOT_STARTED' 
                        COMMENT '状态: NOT_STARTED/IN_PROGRESS/MASTERED/NEEDS_REVIEW/ABANDONED',
    
    -- 练习量
    total_practiced     INT NOT NULL DEFAULT 0 COMMENT '累计练习题数',
    total_correct       INT NOT NULL DEFAULT 0 COMMENT '累计正确题数',
    total_wrong         INT NOT NULL DEFAULT 0 COMMENT '累计错误题数',
    
    -- 当前正确率（滑动窗口：最近N题）
    recent_accuracy     DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '最近20题正确率',
    recent_window_size  INT NOT NULL DEFAULT 20 COMMENT '滑动窗口大小',
    
    -- 难度分布
    easy_count          INT NOT NULL DEFAULT 0 COMMENT '基础题已做数',
    medium_count        INT NOT NULL DEFAULT 0 COMMENT '中等题已做数',
    hard_count          INT NOT NULL DEFAULT 0 COMMENT '困难题已做数',
    easy_accuracy       DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '基础题正确率',
    medium_accuracy     DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '中等题正确率',
    hard_accuracy       DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '困难题正确率',
    
    -- 掌握度
    mastery_level       DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '综合掌握度(0~1)',
    
    -- 时间戳
    first_practice_at   DATETIME COMMENT '首次练习时间',
    last_practice_at    DATETIME COMMENT '最近一次练习时间',
    mastered_at         DATETIME COMMENT '达到掌握状态的时间',
    last_review_at      DATETIME COMMENT '最近一次复习时间',
    next_review_at      DATETIME COMMENT '下次建议复习时间',
    
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_user_kp (user_id, knowledge_point_id),
    INDEX idx_user_status (user_id, status),
    INDEX idx_review (user_id, next_review_at),
    INDEX idx_subject (user_id, subject_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识点练习进度';
```

### 2.4 练习会话效果摘要（session_effect_summary）

每次练习会话结束时生成的效果摘要。

```sql
CREATE TABLE session_effect_summary (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id          BIGINT NOT NULL COMMENT '练习会话ID',
    user_id             BIGINT NOT NULL COMMENT '用户ID',
    
    -- 会话基本信息
    session_type        VARCHAR(20) NOT NULL COMMENT '会话类型: DAILY_PRACTICE/EXAM_SIMULATION/WEAK_POINT/ERROR_REVIEW/CUSTOM',
    subject_id          INT NOT NULL COMMENT '学科',
    total_questions     INT NOT NULL COMMENT '题目总数',
    
    -- 完成情况
    completed_questions INT NOT NULL DEFAULT 0 COMMENT '已完成题目数',
    correct_count       INT NOT NULL DEFAULT 0 COMMENT '正确数',
    wrong_count         INT NOT NULL DEFAULT 0 COMMENT '错误数',
    skipped_count       INT NOT NULL DEFAULT 0 COMMENT '跳过数',
    
    -- 分数
    score               DECIMAL(5,2) NOT NULL DEFAULT 0 COMMENT '得分(0~100)',
    
    -- 时长
    total_time_sec      INT NOT NULL DEFAULT 0 COMMENT '总耗时(秒)',
    avg_time_per_q      INT NOT NULL DEFAULT 0 COMMENT '平均每题耗时(秒)',
    
    -- 知识点维度
    kp_covered          INT NOT NULL DEFAULT 0 COMMENT '涉及知识点数',
    kp_mastered_new     INT NOT NULL DEFAULT 0 COMMENT '新掌握的知识点数',
    kp_improved         INT NOT NULL DEFAULT 0 COMMENT '掌握度提升的知识点数',
    kp_declined         INT NOT NULL DEFAULT 0 COMMENT '掌握度下降的知识点数',
    
    -- 效果评级
    effect_level        VARCHAR(10) NOT NULL COMMENT '效果等级',
    effect_score        DECIMAL(5,2) NOT NULL DEFAULT 0 COMMENT '效果评分',
    
    -- 对比数据（与上一次同类型会话对比）
    prev_session_id     BIGINT COMMENT '上一次同类型会话ID',
    prev_score          DECIMAL(5,2) COMMENT '上次得分',
    score_delta         DECIMAL(5,2) COMMENT '分数变化',
    
    -- 元数据
    started_at          DATETIME NOT NULL COMMENT '会话开始时间',
    finished_at         DATETIME NOT NULL COMMENT '会话结束时间',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_session (session_id),
    INDEX idx_user_time (user_id, finished_at),
    INDEX idx_user_type (user_id, session_type, finished_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='练习会话效果摘要';
```

## 4. 核心算法设计

### 4.1 学习效果评分算法（Effect Score Calculation）

效果评分综合考虑正确率变化、掌握度提升、练习量充足性和时间效率。

```java
/**
 * 学习效果评分算法
 * 
 * 输入：
 *   - accuracyDelta: 正确率变化 [-1.0, 1.0]
 *   - masteryDelta: 掌握度变化 [-1.0, 1.0]
 *   - questionCount: 练习题目数
 *   - minSampleSize: 最小有效样本量（默认5题）
 * 
 * 输出：
 *   - effectScore: 效果评分 [0, 100]
 *   - effectLevel: 效果等级
 */
public class EffectScoreCalculator {
    
    // 权重配置（可通过配置中心动态调整）
    private static final double W_ACCURACY = 0.40;   // 正确率变化权重
    private static final double W_MASTERY = 0.35;    // 掌握度变化权重
    private static final double W_VOLUME = 0.15;     // 练习量权重
    private static final double W_EFFICIENCY = 0.10; // 时间效率权重
    
    // 效果等级阈值
    private static final double T_SIGNIFICANT = 75.0;  // 显著提升
    private static final double T_MODERATE = 55.0;     // 中等提升
    private static final double T_MARGINAL = 35.0;     // 轻微提升
    private static final double T_STAGNANT = 15.0;     // 停滞
    
    public EffectResult calculate(EffectInput input) {
        // 1. 样本量不足时降权处理
        double sampleFactor = Math.min(1.0, (double) input.questionCount / input.minSampleSize);
        
        // 2. 正确率变化得分 [0, 100]
        // accuracyDelta 范围 [-1, 1]，映射到 [0, 100]
        double accuracyScore = Math.max(0, (input.accuracyDelta + 1.0) * 50.0);
        
        // 3. 掌握度变化得分 [0, 100]
        double masteryScore = Math.max(0, (input.masteryDelta + 1.0) * 50.0);
        
        // 4. 练习量得分 [0, 100]
        // 使用对数曲线：做5题=50分，做20题=80分，做50题=95分
        double volumeScore = Math.min(100.0, 50.0 + 50.0 * Math.log10(input.questionCount + 1) / Math.log10(50));
        
        // 5. 时间效率得分 [0, 100]
        // 基于平均每题耗时与推荐耗时的比率
        double efficiencyScore = calculateEfficiencyScore(input.avgTimePerQ, input.recommendedTimePerQ);
        
        // 6. 加权计算总分
        double rawScore = W_ACCURACY * accuracyScore
                        + W_MASTERY * masteryScore
                        + W_VOLUME * volumeScore
                        + W_EFFICIENCY * efficiencyScore;
        
        // 7. 应用样本量衰减
        double effectScore = rawScore * (0.5 + 0.5 * sampleFactor);
        effectScore = Math.round(effectScore * 100.0) / 100.0;
        
        // 8. 确定效果等级
        String effectLevel = determineLevel(effectScore);
        
        return new EffectResult(effectScore, effectLevel);
    }
    
    private double calculateEfficiencyScore(int avgTime, int recommendedTime) {
        if (recommendedTime <= 0) return 50.0; // 无参考值时给中间分
        double ratio = (double) avgTime / recommendedTime;
        // ratio 0.5~1.5 为高效区间(80~100分)
        // ratio < 0.5 可能是敷衍(30分)
        // ratio > 2.0 效率过低(20分)
        if (ratio >= 0.5 && ratio <= 1.5) {
            return 80 + 20 * (1.0 - Math.abs(ratio - 1.0));
        } else if (ratio < 0.5) {
            return 30.0; // 过快，可能未认真思考
        } else {
            return Math.max(10.0, 80.0 - 40.0 * (ratio - 1.5));
        }
    }
    
    private String determineLevel(double score) {
        if (score >= T_SIGNIFICANT) return "SIGNIFICANT";
        if (score >= T_MODERATE) return "MODERATE";
        if (score >= T_MARGINAL) return "MARGINAL";
        if (score >= T_STAGNANT) return "STAGNANT";
        return "DECLINED";
    }
}
```

```java
public class KpStatusStateMachine {
    
    // 掌握阈值
    private static final double MASTERY_THRESHOLD = 0.80;
    private static final double MASTERY_ACCURACY_THRESHOLD = 0.75;
    private static final double DECLINE_THRESHOLD = 0.60;
    private static final int MASTERY_MIN_QUESTIONS = 10;
    private static final int REVIEW_THRESHOLD_DAYS = 30;
    
    public KpStatusTransition evaluate(
            KpPracticeProgress current, 
            AnswerEvent latestEvent) {
        
        String fromStatus = current.getStatus();
        String toStatus = fromStatus;
        
        // 更新掌握度
        double newMastery = recalculateMastery(current, latestEvent);
        double newAccuracy = current.getRecentAccuracy();
        int totalPracticed = current.getTotalPracticed();
        
        switch (fromStatus) {
            case "NOT_STARTED":
                toStatus = "IN_PROGRESS";
                break;
                
            case "IN_PROGRESS":
                if (newMastery >= MASTERY_THRESHOLD 
                    && newAccuracy >= MASTERY_ACCURACY_THRESHOLD
                    && totalPracticed >= MASTERY_MIN_QUESTIONS) {
                    toStatus = "MASTERED";
                }
                break;
                
            case "MASTERED":
                if (newMastery < DECLINE_THRESHOLD) {
                    toStatus = "NEEDS_REVIEW";
                }
                break;
                
            case "NEEDS_REVIEW":
                if (latestEvent != null) {
                    // 重新开始练习，回到IN_PROGRESS
                    toStatus = "IN_PROGRESS";
                }
                break;
        }
        
        return new KpStatusTransition(fromStatus, toStatus, newMastery);
    }
    
    /**
     * 重新计算掌握度
     * 综合考虑：历史正确率(40%) + 近期正确率(40%) + 难度系数(20%)
     */
    private double recalculateMastery(KpPracticeProgress current, AnswerEvent event) {
        // 历史正确率
        int totalQ = current.getTotalPracticed();
        int totalC = current.getTotalCorrect();
        double historicalAccuracy = totalQ > 0 ? (double) totalC / totalQ : 0;
        
        // 近期正确率（滑动窗口）
        double recentAccuracy = current.getRecentAccuracy();
        
        // 难度系数：做过的难题越多，掌握度越高
        double difficultyFactor = calculateDifficultyFactor(
            current.getEasyCount(), current.getMediumCount(), current.getHardCount(),
            current.getEasyAccuracy(), current.getMediumAccuracy(), current.getHardAccuracy()
        );
        
        double mastery = 0.40 * historicalAccuracy 
                       + 0.40 * recentAccuracy 
                       + 0.20 * difficultyFactor;
        
        return Math.round(mastery * 10000.0) / 10000.0; // 保留4位小数
    }
    
    private double calculateDifficultyFactor(
            int easy, int medium, int hard,
            double easyAcc, double medAcc, double hardAcc) {
        // 加权难度得分：基础题1分，中等题2分，困难题3分
        // 再乘以对应正确率
        double easyScore = easy * 1.0 * easyAcc;
        double medScore = medium * 2.0 * medAcc;
        double hardScore = hard * 3.0 * hardAcc;
        
        double totalWeight = easy * 1.0 + medium * 2.0 + hard * 3.0;
        if (totalWeight == 0) return 0;
        
        return (easyScore + medScore + hardScore) / totalWeight;
    }
}
```

### 4.3 滑动窗口正确率更新算法

使用 Redis List 实现高效的滑动窗口正确率计算：

```java
public class SlidingWindowAccuracyUpdater {
    
    private static final int WINDOW_SIZE = 20;
    private static final String KEY_PREFIX = "pae:kp_recent:";
    private static final long TTL_SECONDS = 7 * 24 * 3600; // 7天
    
    private final StringRedisTemplate redisTemplate;
    
    /**
     * 记录一次答题结果并返回新的滑动窗口正确率
     */
    public double recordAndUpdate(Long userId, String kpId, String questionId, boolean isCorrect) {
        String key = KEY_PREFIX + userId + ":" + kpId;
        String entry = questionId + ":" + (isCorrect ? "1" : "0") + ":" + System.currentTimeMillis();
        
        // 使用 Pipeline 保证原子性
        return redisTemplate.executePipelined(new RedisCallback<Object>() {
            @Override
            public Object doInRedis(RedisConnection conn) {
                byte[] rawKey = key.getBytes();
                
                // 1. LPUSH 新记录
                conn.lPush(rawKey, entry.getBytes());
                
                // 2. LTRIM 保留最新 WINDOW_SIZE 条
                conn.lTrim(rawKey, 0, WINDOW_SIZE - 1);
                
                // 3. 设置过期时间
                conn.expire(rawKey, TTL_SECONDS);
                
                return null;
            }
        }).isEmpty() ? 0 : computeAccuracy(key);
    }
    
    private double computeAccuracy(String key) {
        List<String> entries = redisTemplate.opsForList().range(key, 0, -1);
        if (entries == null || entries.isEmpty()) return 0;
        
        long correctCount = entries.stream()
            .map(e -> e.split(":"))
            .filter(parts -> "1".equals(parts[1]))
            .count();
        
        return (double) correctCount / entries.size();
    }
}
```

### 4.4 错误模式识别算法

```java
public class ErrorPatternAnalyzer {
    
    /**
     * 分析一组错误题目的错误模式
     * 
     * @param wrongAnswers 错误答题记录列表
     * @return 错误模式列表，按频率降序排列
     */
    public List<ErrorPattern> analyze(List<WrongAnswerDetail> wrongAnswers) {
        Map<String, Integer> patternCount = new LinkedHashMap<>();
        
        for (WrongAnswerDetail detail : wrongAnswers) {
            // 根据题目类型和错误特征识别模式
            Set<String> patterns = detectPatterns(detail);
            for (String pattern : patterns) {
                patternCount.merge(pattern, 1, Integer::sum);
            }
        }
        
        return patternCount.entrySet().stream()
            .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
            .map(e -> new ErrorPattern(e.getKey(), e.getValue()))
            .collect(Collectors.toList());
    }
    
    private Set<String> detectPatterns(WrongAnswerDetail detail) {
        Set<String> patterns = new LinkedHashSet<>();
        
        // 1. 审题错误：未用到题目中的关键条件
        if (detail.getUnusedConditions() != null && !detail.getUnusedConditions().isEmpty()) {
            patterns.add("reading_error");
        }
        
        // 2. 计算错误：思路正确但结果不对
        if (detail.isApproachCorrect() && !detail.isResultCorrect()) {
            patterns.add("calculation_error");
        }
        
        // 3. 概念错误：用了错误的知识点或公式
        if (detail.getWrongConcept() != null) {
            patterns.add("concept_error");
        }
        
        // 4. 符号错误：正负号、不等号方向等
        if (detail.hasSignError()) {
            patterns.add("sign_error");
        }
        
        // 5. 单位错误：单位换算或遗漏
        if (detail.hasUnitError()) {
            patterns.add("unit_error");
        }
        
        // 6. 跳步错误：中间步骤遗漏
        if (detail.getMissingSteps() > 0) {
            patterns.add("skip_step_error");
        }
        
        // 7. 方法错误：选错了解题方法
        if (detail.isWrongMethod()) {
            patterns.add("method_error");
        }
        
        return patterns;
    }
}
```

```java
            // 0. 幂等检查
            if (idempotentChecker.isProcessed(event.getEventId())) {
                log.debug("Duplicate event skipped: {}", event.getEventId());

                    event.getUserId(), kpId, event, newAccuracy
                );

                if (transition.isChanged()) {
                    eventPublisher.publishKpStatusChanged(
                        event.getUserId(), kpId, 
                        transition.getFrom(), transition.getTo()
                    );
                }
            }
            
            // 6. 维度缓存更新
            redisCounters.updateDimensionCounters(event);
            
            // 7. 标记事件已处理
            idempotentChecker.markProcessed(event.getEventId());
            
        } catch (Exception e) {
            log.error("Failed to process answer event: {}", event.getEventId(), e);
            throw e; // 触发 Kafka 重试
        }
    }
}
```

```java
@Service
@Slf4j
public class SessionEffectEvaluator {
    
    @Autowired private SessionAnswerRepository answerRepo;
    @Autowired private SessionEffectSummaryRepository summaryRepo;
    @Autowired private EffectScoreCalculator scoreCalculator;
    @Autowired private ErrorPatternAnalyzer patternAnalyzer;
    @Autowired private ImprovementHintGenerator hintGenerator;
    @Autowired private KpProgressRepository kpProgressRepo;

    @Transactional
    public SessionEffectSummary evaluate(SessionCompletedEvent event) {
        Long sessionId = event.getSessionId();
        Long userId = event.getUserId();
        
        // 1. 获取本次会话的所有答题记录
        List<AnswerRecord> answers = answerRepo.findBySessionId(sessionId);
        if (answers.isEmpty()) {
            log.warn("No answers found for session: {}", sessionId);
            return null;
        }
        
        // 2. 计算基础指标
        int total = answers.size();
        int correct = (int) answers.stream().filter(AnswerRecord::isCorrect).count();
        int wrong = (int) answers.stream().filter(a -> !a.isCorrect() && a.isSubmitted()).count();
        int skipped = (int) answers.stream().filter(AnswerRecord::isSkipped).count();
        int completed = total - skipped;
        double score = completed > 0 ? (double) correct / completed * 100 : 0;
        int totalTime = answers.stream().mapToInt(AnswerRecord::getTimeSpentSec).sum();
        int avgTime = total > 0 ? totalTime / total : 0;
        
        // 3. 查询上一次同类型会话
        SessionEffectSummary prevSummary = summaryRepo.findLatestByUserAndType(
            userId, event.getSessionType(), event.getSubjectId()
        );
        
        Double prevScore = prevSummary != null ? prevSummary.getScore() : null;
        Double scoreDelta = prevScore != null ? score - prevScore : null;
        
        // 4. 知识点维度分析
        List<String> kpIds = answers.stream()
            .flatMap(a -> a.getKnowledgePointIds().stream())
            .distinct().collect(Collectors.toList());
        
        int kpImproved = 0, kpDeclined = 0, kpMasteredNew = 0;
        for (String kpId : kpIds) {
            KpProgress progress = kpProgressRepo.findByUserAndKp(userId, kpId);
            if (progress != null) {
                if (progress.getMasteryDelta() != null) {
                    if (progress.getMasteryDelta() > 0.05) kpImproved++;
                    if (progress.getMasteryDelta() < -0.05) kpDeclined++;
                }
                if ("MASTERED".equals(progress.getStatus())) {
                    kpMasteredNew++;
                }
            }
        }
        
        // 5. 效果评分
        EffectInput input = EffectInput.builder()
            .accuracyDelta(prevScore != null ? (score - prevScore) / 100.0 : score / 100.0 - 0.5)
            .masteryDelta(kpImproved > 0 ? 0.1 * kpImproved / kpIds.size() : 0)
            .questionCount(total)
            .minSampleSize(5)
            .avgTimePerQ(avgTime)
            .recommendedTimePerQ(getRecommendedTime(event.getSubjectId(), event.getSessionType()))
            .build();
        
        EffectResult effect = scoreCalculator.calculate(input);
        
        // 6. 错误模式分析
        List<WrongAnswerDetail> wrongDetails = answers.stream()
            .filter(a -> !a.isCorrect())
            .map(this::toWrongDetail)
            .collect(Collectors.toList());
        
        List<ErrorPattern> patterns = patternAnalyzer.analyze(wrongDetails);
        
        // 7. 生成改进建议
        String hint = null;
        if (!wrongDetails.isEmpty()) {
            hint = hintGenerator.generate(
                patterns, event.getSubjectName(),
                (double) correct / Math.max(1, completed),
                computeDifficultyDist(answers)
            );
        }
        
        // 8. 构建并保存摘要
        SessionEffectSummary summary = SessionEffectSummary.builder()
            .sessionId(sessionId)
            .userId(userId)
            .sessionType(event.getSessionType())
            .subjectId(event.getSubjectId())
            .totalQuestions(total)
            .completedQuestions(completed)
            .correctCount(correct)
            .wrongCount(wrong)
            .skippedCount(skipped)
            .score(BigDecimal.valueOf(score).setScale(2, RoundingMode.HALF_UP))
            .totalTimeSec(totalTime)
            .avgTimePerQ(avgTime)
            .kpCovered(kpIds.size())
            .kpMasteredNew(kpMasteredNew)
            .kpImproved(kpImproved)
            .kpDeclined(kpDeclined)
            .effectLevel(effect.getEffectLevel())
            .effectScore(BigDecimal.valueOf(effect.getEffectScore()))
            .prevSessionId(prevSummary != null ? prevSummary.getSessionId() : null)
            .prevScore(prevScore != null ? BigDecimal.valueOf(prevScore) : null)
            .scoreDelta(scoreDelta != null ? BigDecimal.valueOf(scoreDelta) : null)
            .startedAt(event.getStartedAt())
            .finishedAt(event.getFinishedAt())
            .build();
        
        summaryRepo.save(summary);
        
        // 9. 发布效果评估完成事件
        eventPublisher.publishEffectEvaluated(
            userId, sessionId, effect.getEffectLevel(), effect.getEffectScore(), score
        );
        
        return summary;
    }
}
```

### 6.1 每日完成度快照刷新

每天凌晨 02:00 执行，刷新所有活跃用户的完成度快照。

```java
@Component
@Slf4j
public class DailyCompletionSnapshotJob {
    
    @Autowired private UserActiveRepository userActiveRepo;
    @Autowired private CompletionSnapshotRepository snapshotRepo;
    @Autowired private RedisCounters redisCounters;
    @Autowired private KpProgressRepository kpProgressRepo;
    
    /**
     * 每日 02:00 执行
     * 处理逻辑：
     * 1. 查询前一日活跃用户列表
     * 2. 按批次（每批100用户）处理
     * 3. 对每个用户，计算各维度完成度
     * 4. 合并写入 practice_completion_snapshot
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void execute() {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        log.info("Starting daily completion snapshot for {}", yesterday);
        
        // 1. 获取前一日活跃用户（从 Redis Set 或 ClickHouse 查询）
        List<Long> activeUsers = userActiveRepo.getActiveUsers(yesterday);
        log.info("Found {} active users for {}", activeUsers.size(), yesterday);
        
        // 2. 分批处理
        int batchSize = 100;
        for (int i = 0; i < activeUsers.size(); i += batchSize) {
            List<Long> batch = activeUsers.subList(i, Math.min(i + batchSize, activeUsers.size()));
            processBatch(batch, yesterday);
        }
        
        log.info("Completed daily completion snapshot for {}", yesterday);
    }
    
    private void processBatch(List<Long> userIds, LocalDate date) {
        for (Long userId : userIds) {
            try {
                // 从 Redis 获取当日实时统计
                DailyStats dailyStats = redisCounters.getDailyStats(userId, date);
                
                // 从数据库获取知识点维度数据
                List<KpProgress> kpProgress = kpProgressRepo.findByUser(userId);
                
                // 生成各维度快照
                List<PracticeCompletionSnapshot> snapshots = buildSnapshots(
                    userId, date, dailyStats, kpProgress
                );
                
                // 批量 upsert
                snapshotRepo.batchUpsert(snapshots);
                
            } catch (Exception e) {
                log.error("Failed to process snapshot for user {} on {}", userId, date, e);
                // 继续处理下一个用户
            }
        }
    }
    
    private List<PracticeCompletionSnapshot> buildSnapshots(
            Long userId, LocalDate date, 
            DailyStats daily, List<KpProgress> kpProgress) {
        
        List<PracticeCompletionSnapshot> snapshots = new ArrayList<>();
        
        // 学科维度
        buildSubjectSnapshots(snapshots, userId, date, daily);
        
        // 知识点维度（仅包含有练习的知识点）
        buildKpSnapshots(snapshots, userId, date, kpProgress);
        
        // 题型维度
        buildQuestionTypeSnapshots(snapshots, userId, date, daily);
        
        // 难度维度
        buildDifficultySnapshots(snapshots, userId, date, daily);
        
        return snapshots;
    }
}
```

```java
        aggregate("MONTHLY", monthStart, monthEnd);
    }
    
    private void aggregate(String period, LocalDate start, LocalDate end) {

                // 2. 获取知识点维度的变化

                // 3. 生成知识点级效果评估

                        .userId(userId)

                        .accuracyDelta(kp.getAccuracyDelta())
                        .masteryBefore(kp.getMasteryBefore())
                        .masteryAfter(kp.getMasteryAfter())
                        .masteryDelta(kp.getMasteryDelta())
                        .questionCount(kp.getPeriodQuestionCount())
                        .practiceDuration(kp.getPeriodDuration())
                        .effectLevel(kp.getMasteryDelta() >= 0.15 ? "SIGNIFICANT" :
                                     kp.getMasteryDelta() >= 0.05 ? "MODERATE" :
                                     kp.getMasteryDelta() >= 0 ? "MARGINAL" : "DECLINED")
                        .effectScore(computePeriodScore(kp, period))
```

### 6.3 知识点复习时间计算

每天 05:00 执行，基于遗忘曲线和掌握度计算每个用户的知识点下次复习时间。

```java
@Component
@Slf4j
public class KpReviewScheduleJob {
    
    @Autowired private KpProgressRepository kpProgressRepo;
    @Autowired private UserActiveRepository userActiveRepo;
    
    // 复习间隔策略（基于掌握度）
    // 掌握度 ≥ 0.9: 30天
    // 掌握度 ≥ 0.8: 14天
    // 掌握度 ≥ 0.6: 7天
    // 掌握度 < 0.6: 3天
    private static final double[] MASTERY_THRESHOLDS = {0.9, 0.8, 0.6, 0.0};
    private static final int[] REVIEW_DAYS = {30, 14, 7, 3};
    
    /**
     * 每日 05:00 执行
     */
    @Scheduled(cron = "0 0 5 * * ?")
    public void scheduleReviews() {
        log.info("Starting KP review schedule calculation");
        
        // 获取最近30天活跃的用户
        List<Long> activeUsers = userActiveRepo.getRecentlyActiveUsers(30);
        
        int updated = 0;
        for (Long userId : activeUsers) {
            List<KpProgress> inProgress = kpProgressRepo.findByUserAndStatusIn(
                userId, List.of("MASTERED", "IN_PROGRESS")
            );
            
            for (KpProgress kp : inProgress) {
                int reviewDays = getReviewDays(kp.getMasteryLevel());
                LocalDateTime nextReview = kp.getLastPracticeAt()
                    .plusDays(reviewDays);
                
                // 仅当计算出的复习时间与现有不同时才更新
                if (!nextReview.equals(kp.getNextReviewAt())) {
                    kp.setNextReviewAt(nextReview);
                    kpProgressRepo.save(kp);
                    updated++;
                }
            }
        }
        
        log.info("KP review schedule completed. Updated {} records.", updated);
    }
    
    private int getReviewDays(double mastery) {
        for (int i = 0; i < MASTERY_THRESHOLDS.length; i++) {
            if (mastery >= MASTERY_THRESHOLDS[i]) {
                return REVIEW_DAYS[i];
            }
        }
        return 3; // 默认
    }
}
```

```java
@Service
@Slf4j
public class DegradationHandler {
    
    /**
     * 查询完成度时的降级策略
     */
    public CompletionResponse getCompletionWithFallback(CompletionQuery query) {
        try {
            // 优先：Redis 实时缓存
            return queryFromRedis(query);
        } catch (RedisException e) {
            log.warn("Redis unavailable, falling back to DB snapshot", e);
            try {
                // 降级：数据库快照（可能有一天的延迟）
                return queryFromSnapshot(query);
            } catch (DataAccessException ex) {
                log.error("DB also unavailable", ex);
                // 最终降级：返回空数据
                return CompletionResponse.empty();
            }
        }
    }
    
    /**
     * 答题事件处理失败时的补偿策略
     */
    public void handleEventFailure(AnswerEvent event, Exception e) {
        if (e instanceof RedisException) {
            // Redis 不可用：仅写数据库，跳过实时计数器
            log.warn("Skipping Redis counter update for event: {}", event.getEventId());
            writeToDatabaseOnly(event);
        } else if (e instanceof DataAccessException) {
            // 数据库不可用：写入本地队列，定时补偿
            log.warn("Queueing event for retry: {}", event.getEventId());
            compensationQueue.offer(event);
        } else {
            // 未知错误：记录并告警
            log.error("Unexpected error processing event: {}", event.getEventId(), e);
            alertService.sendAlert("PAEES event processing error", e.getMessage());
        }
    }
}
```

```java
@Service
@Slf4j
public class ConsistencyChecker {
    
    /**
     * 每日凌晨 06:00 执行一致性校验
     * 对比 Redis 实时计数器与数据库聚合结果
     */
    @Scheduled(cron = "0 0 6 * * ?")
    public void dailyConsistencyCheck() {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        List<Long> activeUsers = getActiveUsers(yesterday);
        
        int inconsistencies = 0;
        for (Long userId : activeUsers) {
            // 对比 Redis 日统计与数据库 answer_record 聚合
            DailyStats redisStats = redisCounters.getDailyStats(userId, yesterday);
            DailyStats dbStats = answerRepo.aggregateDaily(userId, yesterday);
            
            if (!isConsistent(redisStats, dbStats)) {
                inconsistencies++;
                log.warn("Data inconsistency for user {} on {}: Redis={}, DB={}", 
                    userId, yesterday, redisStats, dbStats);
                
                // 以数据库为准修复 Redis
                redisCounters.repairDailyStats(userId, yesterday, dbStats);
            }
        }
        
        if (inconsistencies > activeUsers.size() * 0.01) {
            alertService.sendAlert(
                "PAEES consistency check",
                String.format("Inconsistency rate > 1%%: %d/%d", inconsistencies, activeUsers.size())
            );
        }
    }
    
    private boolean isConsistent(DailyStats a, DailyStats b) {
        // 允许 ±2 的误差（Redis 和 DB 之间可能有微小的时间差）
        return Math.abs(a.getAttempted() - b.getAttempted()) <= 2
            && Math.abs(a.getCorrect() - b.getCorrect()) <= 2
            && Math.abs(a.getWrong() - b.getWrong()) <= 2;
    }
}
```

```java
@Service
public class BatchEffectWriter {
    
    private final BlockingQueue<LearningEffectRecord> buffer = new LinkedBlockingQueue<>(10000);
    
    @Autowired private LearningEffectRecordRepository repo;
    
    /**
     * 异步批量写入效果评估记录
     * 每5秒或累积500条时批量flush
     */
    @Scheduled(fixedRate = 5000)
    public void flush() {
        List<LearningEffectRecord> batch = new ArrayList<>();
        buffer.drainTo(batch, 500);
        
        if (!batch.isEmpty()) {
            repo.batchInsert(batch);
            log.debug("Flushed {} effect records", batch.size());
        }
    }
    
    public void asyncWrite(LearningEffectRecord record) {
        if (!buffer.offer(record)) {
            log.warn("Effect record buffer full, dropping record for user: {}", 
                record.getUserId());
        }
    }
}
```

```java
        // 3. 获取最近的效果评估
        for (KpProgress kp : weakKps) {
            EffectResponse effect = paeClient.getLatestEffect(userId, kp.getKnowledgePointId());
            
            // 4. 根据效果评估确定推荐难度
            String targetDifficulty;
            if (effect.getEffectLevel().equals("DECLINED") || effect.getEffectLevel().equals("STAGNANT")) {
                targetDifficulty = "EASY"; // 退回基础题
            } else if (effect.getAccuracyAfter() >= 0.70) {
                targetDifficulty = "HARD";  // 可以挑战难题
            } else {
                targetDifficulty = "MEDIUM";
            }
            
            // 5. 调用题目服务推荐
            // ...
        }
        
        return recommendedQuestions;
    }
```

## 12. 总结

本服务作为练习数据与学习分析之间的桥梁，核心职责包括：

1. **实时统计**：通过 Kafka 消费答题事件，Redis 维护实时计数器和滑动窗口
2. **效果评估**：多维度评分算法量化学习效果，识别错误模式并生成改进建议
3. **进度追踪**：知识点练习进度的状态机管理，支持掌握度动态更新
4. **周期聚合**：定时任务生成日/周/月维度快照，支撑历史趋势分析
5. **数据服务**：通过 REST API 为自适应推荐、学习报告、学情页面提供数据

关键设计决策：
- **Redis + MySQL + ClickHouse 三层存储**：实时、快照、明细各取所长
- **滑动窗口正确率**：用最近20题的准确率代替历史全局正确率，更敏感地反映变化
- **效果评分算法**：四维加权（正确率变化40% + 掌握度变化35% + 练习量15% + 时间效率10%），可通过配置中心动态调整权重
- **状态机驱动**：知识点状态流转清晰，支持自动升级（掌握）和降级（需要复习）
- **幂等 + 补偿**：事件处理幂等校验 + 本地补偿队列，确保数据不丢失
