## 1. 概述

### 1.1 功能定位

本引擎负责为学生**主动设计并编排每日学习例程（Daily Learning Routine）**，在学生开始正式学习之前、学习过程中以及学习结束时，自动插入精心设计的**例程阶段（Routine Phase）**，通过持续的、有节奏的仪式感体验，帮助学生建立稳定的学习习惯锚点。

与现有模块的核心差异：

| 对比模块 | 关注点 | 本模块差异 |
|---------|--------|-----------|
| 学习会话内容编排与学习节奏智能控制引擎 | 单次会话**内部**的内容排列与节奏控制 | 本引擎关注会话**前后**的例程设计和跨会话的习惯形成 |
| 学习习惯模式分析与科学学习方法指导引擎 | **事后分析**学生学习习惯模式并给出建议 | 本引擎**主动设计**并**前置编排**习惯养成的例程流程 |
| 学习打卡记录与成就解锁计算引擎 | 记录打卡行为并发放奖励 | 本引擎设计触发打卡行为的心理机制，为打卡系统提供"触发器" |
| 每日任务智能生成与学习计划执行追踪服务 | 生成每日学习**任务清单** | 本引擎设计任务之间的**心理过渡**和**仪式包装** |
| 学习提醒与智能通知调度系统 | 调度通知的**时机和渠道** | 本引擎决定通知的**内容形式**和**心理触发设计** |

### 1.2 设计目标

1. **习惯形成加速**：通过设计科学的学习前/中/后例程，在 21~66 天内帮助学生形成稳定的学习习惯
2. **学习启动阻力降低**：通过低门槛的"预热活动"让学生更容易开始每天的学习
3. **知识巩固自动化**：通过例程化的复习和反思环节，将知识巩固嵌入日常流程
4. **学习体验节奏化**：让学习有明确的"开始—进行—结束"节奏感，避免无止境的学习疲劳
5. **个性化适配**：根据学生的年级、学习风格、时间偏好动态调整例程配置

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| **行为科学驱动** | 基于 Fogg 行为模型（B=MAP）、习惯回路（Cue-Routine-Reward）理论设计 |
| **最小阻力启动** | 例程的起步阶段应极低门槛（< 2 分钟），降低开始学习的心理障碍 |
| **渐进式深化** | 例程复杂度随习惯稳定度逐步提升，初期简单→后期丰富 |
| **感知不突兀** | 例程应自然融入学习流程，不让学生感觉在被"管理" |
| **数据驱动调优** | 持续追踪例程对习惯形成的实际效果，用数据指导例程配置优化 |

## 2. 核心概念定义

### 2.1 例程（Routine）

一次完整的学习例程是围绕一次学习会话的前中后三个阶段编排的结构化流程：

```
┌─────────────────────────────────────────────────────────────┐
│                    每日学习例程完整结构                        │
├──────────┬──────────────────┬──────────────┬────────────────┤
│  阶段一   │     阶段二        │    阶段三     │     阶段四      │
│  启动预热  │    主学习引导      │    学习中     │    结束巩固     │
│ (1~3min)  │   (2~5min)       │  (15~60min)  │   (2~5min)    │
├──────────┼──────────────────┼──────────────┼────────────────┤
│ 心理触发   │   今日目标对齐     │  例程不干预   │   知识收获清点   │
│ 情绪准备   │   昨日知识唤醒     │  (由会话引擎  │   明日预告      │
│ 环境确认   │   任务概览展示     │   接管内容)   │   成就确认      │
└──────────┴──────────────────┴──────────────┴────────────────┘
```

### 2.2 习惯锚点（Habit Anchor）

习惯锚点是绑定到特定**时间、场景或事件**上的心理触发器，用于自动激活学生的学习意图：

| 锚点类型 | 说明 | 示例 |
|---------|------|------|
| **时间锚点** | 绑定到每天的固定时间 | "每天 19:00 放学后" |
| **事件锚点** | 绑定到某个已有习惯之后 | "吃完晚饭后→开始学习" |
| **场景锚点** | 绑定到物理位置切换 | "坐到书桌前→打开APP" |
| **社交锚点** | 绑定到社交信号 | "学习伙伴上线→一起学习" |
| **情绪锚点** | 绑定到情绪状态检测 | "感到焦虑→深呼吸+复习" |

### 2.3 例程模板（Routine Template）

例程模板是可配置的例程结构定义，包含阶段序列、每阶段的内容类型、时长约束和触发条件。系统预置多套模板并支持个性化定制。

### 2.4 习惯稳定度评分（Habit Stability Score）

一个 0~100 的综合评分，衡量学生当前学习习惯的稳定程度。评分维度包括：

- **频率一致性**（30%）：实际学习天数 / 预期学习天数
- **时间稳定性**（25%）：学习开始时间的标准差（越小越稳定）
- **时长稳定性**（20%）：每日学习时长的波动程度
- **例程完成率**（15%）：预热和巩固阶段的完成比例
- **连续坚持度**（10%）：当前连续学习天数和历史最长记录

| 评分区间 | 习惯阶段 | 系统策略 |
|---------|---------|---------|
| 0~20 | 冷启动期 | 超简化例程，极致降低门槛 |
| 21~40 | 形成期 | 逐步丰富例程内容，引入更多互动 |
| 41~70 | 稳定期 | 标准例程，注重效果优化 |
| 71~100 | 巩固期 | 个性化深化，支持自主定制 |

### 3.2 核心组件职责

| 组件 | 职责 | 技术选型 |
|------|------|---------|
| **例程模板引擎** TemplateEngine | 管理例程模板的CRUD、版本控制、条件匹配 | Spring + JdbcTemplate |
| **锚点调度器** AnchorScheduler | 管理习惯锚点的注册、触发计算、通知联动 | Quartz + Redis Sorted Set |
| **内容选择器** ContentSelector | 为例程各阶段选择合适的学习内容 | 策略模式 + 内容推荐API |
| **例程编排核心** Orchestrator | 驱动例程状态机，协调阶段流转 | Spring State Machine + 事件驱动 |
| **习惯稳定度评估器** StabilityEvaluator | 计算习惯稳定度评分，输出习惯阶段 | 定时批处理 + Redis缓存 |
| **效果分析器** EffectAnalyzer | 追踪例程对学习行为的影响，输出分析报告 | Flink/批处理 + ClickHouse |
| **个性化推荐器** Personalizer | 基于用户画像推荐最优例程模板和参数 | 规则引擎 + 协同过滤 |

## 4. 数据模型设计

### 4.1 例程模板表 `routine_template`

```sql
CREATE TABLE routine_template (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_code   VARCHAR(64) NOT NULL COMMENT '模板编码，如 WARM_START_SIMPLE',
    template_name   VARCHAR(128) NOT NULL COMMENT '模板名称',
    description     TEXT COMMENT '模板描述',
    target_stage    VARCHAR(20) NOT NULL COMMENT '目标习惯阶段: COLD_START/FORMING/STABLE/CONSOLIDATION',
    target_grade    VARCHAR(20) COMMENT '目标年级范围: PRIMARY/JUNIOR/SENIOR/ALL',
    total_duration  INT NOT NULL COMMENT '例程总时长(秒)，不含主学习阶段',
    phase_count     INT NOT NULL COMMENT '阶段数量(不含主学习阶段)',
    is_active       TINYINT DEFAULT 1 COMMENT '是否启用',
    version         INT DEFAULT 1 COMMENT '模板版本号',
    creator         VARCHAR(64) COMMENT '创建者',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_code_version (template_code, version),
    KEY idx_stage_active (target_stage, is_active)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='例程模板定义表';
```

### 4.2 例程阶段定义表 `routine_phase_def`

```sql
CREATE TABLE routine_phase_def (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_id     BIGINT NOT NULL COMMENT '关联模板ID',
    phase_index     INT NOT NULL COMMENT '阶段序号(从1开始)',
    phase_type      VARCHAR(32) NOT NULL COMMENT '阶段类型: WARM_UP/TASK_BRIEFING/COOL_DOWN/REFLECTION',
    phase_name      VARCHAR(64) NOT NULL COMMENT '阶段展示名称',
    duration_sec    INT NOT NULL COMMENT '建议时长(秒)',
    min_duration    INT DEFAULT 10 COMMENT '最短时长(秒)',
    max_duration    INT DEFAULT 600 COMMENT '最长时长(秒)',
    content_type    VARCHAR(32) NOT NULL COMMENT '内容类型: QUIZ/FLASHCARD/TEXT/AUDIO/VIDEO/INTERACTIVE/EMPTY',
    content_config  JSON COMMENT '内容选择配置(JSON)',
    ui_template     VARCHAR(64) COMMENT '前端UI模板标识',
    skip_allowed    TINYINT DEFAULT 0 COMMENT '是否允许跳过',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (template_id) REFERENCES routine_template(id),
    KEY idx_template_phase (template_id, phase_index)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='例程阶段定义表';
```

### 4.6 例程效果追踪表 `routine_effect_log`

```sql
CREATE TABLE routine_effect_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id      BIGINT NOT NULL,
    routine_instance_id BIGINT NOT NULL COMMENT '关联例程实例ID',
    metric_type     VARCHAR(40) NOT NULL COMMENT '指标类型',
    metric_value    DECIMAL(10,4) COMMENT '指标值',
    metric_metadata JSON COMMENT '指标附加数据',
    measured_at     DATETIME DEFAULT CURRENT_TIMESTAMP,
    KEY idx_student_metric (student_id, metric_type),
    KEY idx_routine (routine_instance_id),
    FOREIGN KEY (routine_instance_id) REFERENCES student_routine_instance(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='例程效果追踪表';
```

**指标类型（metric_type）枚举**:

| metric_type | 说明 | 示例值 |
|------------|------|--------|
| `SESSION_START_LATENCY` | 从推送到实际开始的延迟(秒) | 45 |
| `WARM_UP_COMPLETION` | 预热阶段完成率 | 1.0 |
| `MAIN_SESSION_DURATION` | 主学习时长(秒) | 1800 |
| `COOL_DOWN_COMPLETION` | 巩固阶段完成率 | 0.8 |

```java
/**
 * 根据学生画像选择最合适的例程模板
 */
public RoutineTemplate selectTemplate(Long studentId) {
    // 1. 获取习惯稳定度评分
    HabitStabilityScore score = stabilityEvaluator.evaluate(studentId);
    
    // 2. 根据评分阶段选择模板池
    List<String> candidateCodes = switch (score.getStage()) {
        case COLD_START -> List.of("COLD_START_LITE");
        case FORMING -> List.of("FORMING_STANDARD", "COLD_START_LITE");
        case STABLE -> List.of("STABLE_RICH", "FORMING_STANDARD");
        case CONSOLIDATION -> List.of("CONSOLIDATION_CUSTOM", "STABLE_RICH");
    };
    
    // 3. 检查是否有A/B实验分配
    String experimentTemplate = abTestService.getAssignedVariant(
        studentId, "routine_template_v2", candidateCodes);
    if (experimentTemplate != null) {
        candidateCodes = List.of(experimentTemplate);
    }
    
    // 4. 按优先级查找可用模板
    for (String code : candidateCodes) {
        RoutineTemplate template = templateEngine
            .getActiveTemplate(code, score.getStage());
        if (template != null) {
            return template;
        }
    }
    
    // 5. 兜底: 返回最简模板
    return templateEngine.getActiveTemplate("COLD_START_LITE", null);
}
```

## 7. 习惯锚点心理模型与实现

### 7.1 Fogg 行为模型应用

基于 BJ Fogg 的行为模型 **B = MAP**（Behavior = Motivation × Ability × Prompt）：

```
行为发生 = 动机 × 能力 × 提示

对学习行为的映射:
├── Motivation (动机)
│   ├── 内在动机: 好奇心、成就感、自我提升
│   └── 外在动机: 奖励、排名、家长/老师认可
├── Ability (能力/阻力)
│   ├── 时间能力: 有足够的时间
│   ├── 认知能力: 内容难度可理解
│   └── 操作能力: 使用APP的便利性
├── Prompt (提示/触发)
│   ├── 锚点触发: 固定时间、事件绑定
│   ├── 社交触发: 学习伙伴在线
│   └── 系统触发: 智能推送
```

本引擎的核心策略是：**在学生动机较高时降低能力门槛，在能力门槛较高时提升动机，并通过锚点确保提示的有效触达。**

### 7.2 习惯回路实现

```
┌──────────────────────────────────────────────────────┐
│                习惯回路 (Habit Loop)                  │
│                                                      │
│   ┌─────────┐     ┌──────────┐     ┌─────────┐     │
│   │  Cue    │────▶│ Routine  │────▶│ Reward  │     │
│   │  触发器  │     │ 例程执行  │     │  奖励   │     │
│   └────┬────┘     └────┬─────┘     └────┬────┘     │
│        │               │                │           │
│        │          ┌────┴─────┐    ┌─────┴────┐     │
│        │          │ 投入度监测 │    │ 多巴胺   │     │
│        │          │ 动态调整  │    │ 触发设计 │     │
│        │          └──────────┘    └─────┬────┘     │
│        │                               │           │
│        └───────────────────────────────┘           │
│                    Craving (渴求)                    │
│              学生对奖励的期待驱动下次触发              │
└──────────────────────────────────────────────────────┘
```

**实现要点**:

1. **Cue（触发器）**: 通过习惯锚点表配置，支持时间、事件、场景等多维度触发
2. **Routine（例程）**: 由例程模板引擎编排，难度匹配当前习惯阶段
3. **Reward（奖励）**: 多层次奖励设计，确保即时正反馈
4. **Craving（渴求）**: 通过变换奖励内容和引入期待感（如盲盒式奖励）制造持续动力

## 8. 例程内容智能选择算法

### 8.1 预热阶段内容选择

预热阶段的核心目标是**唤醒记忆**和**降低启动阻力**，内容选择策略如下：

```python
def select_warmup_content(student_id: int, template_phase: PhaseDef) -> List[ContentItem]:
    """
    预热阶段内容选择算法
    
    策略优先级:
    1. 昨日学习内容的间隔复习卡片 (最高优先)
    2. 即将到期的错题复习题目
    3. 核心基础概念的快速闪卡
    4. 趣味学科知识(备用)
    """
    candidate_pool = []
    
    # 策略1: 昨日新学知识点的记忆闪卡
    yesterday_kps = learning_record_service
        .get_newly_learned_knowledge_points(
            student_id, 
            days_ago=1,
            limit=5
        )
    for kp in yesterday_kps:
        card = flashcard_service.get_or_create_card(student_id, kp.id)
        card.score = 100  # 最高优先级
        candidate_pool.append(card)
    
    # 策略2: 按遗忘曲线即将到期的复习项
    due_reviews = spaced_repetition_service
        .get_due_items(
            student_id,
            max_items=5,
            priority="HIGH"
        )
    for item in due_reviews:
        item.score = 80
        candidate_pool.append(item)
    
    # 策略3: 高频出错的核心概念
    weak_kps = knowledge_tracing_service
        .get_weak_knowledge_points(
            student_id,
            mastery_threshold=0.5,
            limit=3
        )
    for kp in weak_kps:
        card = flashcard_service.get_review_card(student_id, kp.id)
        card.score = 60
        candidate_pool.append(card)
    
    # 策略4: 兜底内容(趣味知识)
    if len(candidate_pool) < 3:
        fun_items = content_service.get_fun_facts(
            grade=student.grade,
            subject=student.preferred_subject,
            limit=3
        )
        for item in fun_items:
            item.score = 20
            candidate_pool.append(item)
    
    # 按分数排序，取前N项
    candidate_pool.sort(key=lambda x: x.score, reverse=True)
    
    # 根据模板配置决定数量
    count = template_phase.content_config.get("count", 3)
    
    # 多样性过滤: 同一知识点最多出现1次
    return diversity_filter(candidate_pool, max_per_kp=1)[:count]
```

### 8.2 巩固阶段内容选择

巩固阶段的核心目标是**检验今日所学**和**强化记忆留存**：

```python
def select_cooldown_content(student_id: int, routine_instance: RoutineInstance) -> List[ContentItem]:
    """
    巩固阶段内容选择算法
    
    策略:
    1. 今日主学习中涉及的知识点检测题
    2. 今日做错的题目变式
    3. 今日学习内容的总结填空
    """
    # 获取今日主学习中涉及的知识点
    today_kps = learning_session_service
        .get_session_knowledge_points(routine_instance.session_id)
    
    items = []
    
    for kp in today_kps:
        # 为每个知识点选择1道检测题
        question = question_service.select_question_by_knowledge_point(
            student_id=student_id,
            kp_id=kp.id,
            difficulty=kp.today_mastery * 1.1,  # 稍高于当前掌握度
            exclude_seen=True
        )
        if question:
            items.append(question)
    
    # 如果今日学习中做错了题目，生成变式题
    today_errors = mistake_service.get_today_mistakes(student_id)
    for error in today_errors[:2]:  # 最多取2道错题变式
        variant = question_service.generate_variant(error.question_id)
        if variant:
            items.append(variant)
    
    # 控制总题量
    return items[:template_phase.content_config.get("count", 3)]
```

```java
@Configuration
@EnableStateMachineFactory
public class RoutineStateMachineConfig 
        extends EnumStateMachineConfigurerAdapter<RoutineStatus, RoutineEvent> {
    
    @Override
    public void configure(StateMachineStateConfigurer<RoutineStatus, RoutineEvent> states) 
            throws Exception {
        states
            .withStates()
            .initial(RoutineStatus.PENDING)
            .states(EnumSet.allOf(RoutineStatus.class))
            .end(RoutineStatus.COMPLETED)
            .end(RoutineStatus.ABANDONED);
    }
    
    @Override
    public void configure(StateMachineTransitionConfigurer<RoutineStatus, RoutineEvent> transitions)
            throws Exception {
        transitions
            // PENDING → WARMING_UP
            .withExternal()
                .source(RoutineStatus.PENDING)
                .target(RoutineStatus.WARMING_UP)
                .event(RoutineEvent.START)
                .action(startWarmUpAction())
            .and()
            // WARMING_UP → BRIEFING
            .withExternal()
                .source(RoutineStatus.WARMING_UP)
                .target(RoutineStatus.BRIEFING)
                .event(RoutineEvent.PHASE_COMPLETE)
                .action(startBriefingAction())
            .and()
            // WARMING_UP → BRIEFING (跳过)
            .withExternal()
                .source(RoutineStatus.WARMING_UP)
                .target(RoutineStatus.BRIEFING)
                .event(RoutineEvent.PHASE_SKIP)
                .action(recordSkipAction())
            .and()
            // BRIEFING → IN_SESSION
            .withExternal()
                .source(RoutineStatus.BRIEFING)
                .target(RoutineStatus.IN_SESSION)
                .event(RoutineEvent.PHASE_COMPLETE)
                .action(startMainSessionAction())
            .and()
            // IN_SESSION → COOLING_DOWN
            .withExternal()
                .source(RoutineStatus.IN_SESSION)
                .target(RoutineStatus.COOLING_DOWN)
                .event(RoutineEvent.SESSION_END)
                .action(startCoolDownAction())
            .and()
            // COOLING_DOWN → REFLECTING
            .withExternal()
                .source(RoutineStatus.COOLING_DOWN)
                .target(RoutineStatus.REFLECTING)
                .event(RoutineEvent.PHASE_COMPLETE)
                .action(startReflectionAction())
            .and()
            // REFLECTING → COMPLETED
            .withExternal()
                .source(RoutineStatus.REFLECTING)
                .target(RoutineStatus.COMPLETED)
                .event(RoutineEvent.ROUTINE_COMPLETE)
                .action(finalizeRoutineAction())
            .and()
            // 任意状态 → ABANDONED (超时)
            .withExternal()
                .source(RoutineStatus.PENDING)
                .target(RoutineStatus.ABANDONED)
                .event(RoutineEvent.TIMEOUT)
                .action(recordAbandonAction());
    }
}
```

## 13. 关键代码示例

### 13.1 例程编排核心服务

```java
@Service
@Slf4j
public class RoutineOrchestrator {
    
    @Autowired private RoutineTemplateEngine templateEngine;
    @Autowired private StabilityEvaluator stabilityEvaluator;
    @Autowired private WarmupContentSelector warmupSelector;
    @Autowired private CooldownContentSelector cooldownSelector;
    @Autowired private StudentRoutineInstanceMapper instanceMapper;
    @Autowired private RoutineStateMachineService stateMachineService;
    @Autowired private EffectTracker effectTracker;
    @Autowired private RewardService rewardService;
    
    /**
     * 创建今日例程
     */
    @Transactional
    public RoutineInstanceDTO createTodayRoutine(Long studentId) {
        // 1. 检查今日是否已创建
        StudentRoutineInstance existing = instanceMapper.findByStudentAndDate(
            studentId, LocalDate.now());
        if (existing != null) {
            return toDTO(existing);
        }
        
        // 2. 评估习惯稳定度
        HabitStabilityScore score = stabilityEvaluator.evaluate(studentId);
        
        // 3. 选择例程模板
        RoutineTemplate template = templateEngine.selectTemplate(studentId, score);
        
        // 4. 创建例程实例
        StudentRoutineInstance instance = StudentRoutineInstance.builder()
            .studentId(studentId)
            .templateId(template.getId())
            .routineDate(LocalDate.now())
            .status(RoutineStatus.PENDING)
            .build();
        instanceMapper.insert(instance);
        
        // 5. 预加载各阶段内容(异步)
        asyncPreloadPhaseContent(instance, template);
        
        return toDTO(instance);
    }
    
    /**
     * 启动例程-进入预热阶段
     */
    @Transactional
    public RoutinePhaseDTO startRoutine(Long instanceId, String anchorTriggerId) {
        StudentRoutineInstance instance = instanceMapper.selectById(instanceId);
        if (instance == null || instance.getStatus() != RoutineStatus.PENDING) {
            throw new BusinessException("INVALID_ROUTINE_STATUS", 
                "例程状态不允许启动: " + instance.getStatus());
        }
        
        // 状态流转: PENDING → WARMING_UP
        stateMachineService.fireEvent(instanceId, RoutineEvent.START);
        
        // 记录启动时间和来源锚点
        instanceMapper.updateStartInfo(instanceId, LocalDateTime.now(), anchorTriggerId);
        
        // 效果追踪: 启动延迟
        effectTracker.recordMetric(instanceId, "SESSION_START_LATENCY", 
            calculateStartLatency(anchorTriggerId));
        
        // 获取并返回预热阶段内容
        return getPhaseContent(instanceId, 1);
    }
    
    /**
     * 完成当前阶段，推进到下一阶段
     */
    @Transactional
    public RoutinePhaseDTO completePhase(Long instanceId, int phaseIndex, 
            PhaseResultDTO result) {
        StudentRoutineInstance instance = instanceMapper.selectById(instanceId);
        validatePhaseTransition(instance, phaseIndex);
        
        // 保存阶段结果
        savePhaseResult(instance, phaseIndex, result);
        
        // 记录效果指标
        recordPhaseMetrics(instanceId, phaseIndex, result);
        
        // 发放微奖励
        rewardService.grantMicroReward(instance.getStudentId(), 
            "PHASE_COMPLETE", phaseIndex);
        
        // 状态流转
        int nextPhase = phaseIndex + 1;
        RoutinePhaseDef nextPhaseDef = getPhaseDef(instance.getTemplateId(), nextPhase);
        
        if (nextPhaseDef == null || nextPhaseDef.getPhaseType().equals("MAIN_SESSION")) {
            // 进入主学习阶段
            stateMachineService.fireEvent(instanceId, RoutineEvent.PHASE_COMPLETE);
            return RoutinePhaseDTO.builder()
                .phaseType("MAIN_SESSION")
                .action("START_LEARNING_SESSION")
                .build();
        }
        
        // 返回下一阶段内容
        return getPhaseContent(instanceId, nextPhase);
    }
    
    /**
     * 主学习结束，进入巩固阶段
     */
    @Transactional
    public RoutinePhaseDTO onMainSessionEnd(Long instanceId, String sessionId) {
        // 更新会话ID关联
        instanceMapper.updateSessionId(instanceId, sessionId);
        
        // 状态流转: IN_SESSION → COOLING_DOWN
        stateMachineService.fireEvent(instanceId, RoutineEvent.SESSION_END);
        
        // 选择巩固阶段内容(基于今日所学)
        StudentRoutineInstance instance = instanceMapper.selectById(instanceId);
        List<ContentItem> cooldownItems = cooldownSelector.select(instance, sessionId);
        
        saveCooldownData(instanceId, cooldownItems);
        
        return RoutinePhaseDTO.builder()
            .phaseType("COOL_DOWN")
            .items(cooldownItems)
            .build();
    }
    
    /**
     * 完成整个例程
     */
    @Transactional
    public void completeRoutine(Long instanceId, FeedbackDTO feedback) {
        // 状态流转 → COMPLETED
        stateMachineService.fireEvent(instanceId, RoutineEvent.ROUTINE_COMPLETE);
        
        // 更新结束信息
        instanceMapper.updateEndInfo(instanceId, LocalDateTime.now(), 
            calculateCompletionRate(instanceId), feedback);
        
        // 发放日常完成奖励
        StudentRoutineInstance instance = instanceMapper.selectById(instanceId);
        rewardService.grantDailyReward(instance.getStudentId(), 
            instance.getRoutineDate(), calculateBonusMultiplier(instance));
        
        // 触发习惯稳定度重算
        stabilityEvaluator.triggerRecalculation(instance.getStudentId());
        
        // 记录整体效果
        effectTracker.recordOverallMetrics(instanceId);
    }
    
    // ========== 私有方法 ==========
    
    private void asyncPreloadPhaseContent(StudentRoutineInstance instance, 
            RoutineTemplate template) {
        CompletableFuture.runAsync(() -> {
            try {
                // 预加载预热内容
                List<ContentItem> warmupItems = warmupSelector.select(
                    instance.getStudentId(), template.getWarmUpPhaseDef());
                instanceMapper.updateWarmUpData(instance.getId(), 
                    JsonUtils.toJson(warmupItems));
                
                // 预加载任务简报
                TaskBriefingDTO briefing = buildTaskBriefing(instance.getStudentId());
                instanceMapper.updateBriefingData(instance.getId(), 
                    JsonUtils.toJson(briefing));
                
                log.info("例程内容预加载完成: studentId={}, instanceId={}", 
                    instance.getStudentId(), instance.getId());
            } catch (Exception e) {
                log.warn("例程内容预加载失败，将在启动时懒加载", e);
            }
        });
    }
    
    private BigDecimal calculateBonusMultiplier(StudentRoutineInstance instance) {
        int streak = stabilityEvaluator.getCurrentStreak(instance.getStudentId());
        BigDecimal multiplier = BigDecimal.ONE;
        if (streak >= 21) multiplier = multiplier.multiply(new BigDecimal("1.5"));
        if (streak >= 66) multiplier = multiplier.multiply(new BigDecimal("2.0"));
        if (instance.getCompletionRate().compareTo(new BigDecimal("0.9")) >= 0) {
            multiplier = multiplier.multiply(new BigDecimal("1.2"));
        }
        return multiplier;
    }
}
```

### 13.2 习惯稳定度评估器

```java
@Service
public class StabilityEvaluator {
    
    @Autowired private HabitStabilityLogMapper stabilityLogMapper;
    @Autowired private LearningRecordService learningRecordService;
    @Autowired private RoutineInstanceMapper routineInstanceMapper;
    @Autowired private RedisTemplate<String, Object> redisTemplate;
    
    private static final int EVALUATION_WINDOW_DAYS = 30;
    private static final String CACHE_KEY_PREFIX = "habit:stability:";
    private static final Duration CACHE_TTL = Duration.ofHours(6);
    
    /**
     * 评估学生习惯稳定度
     */
    public HabitStabilityScore evaluate(Long studentId) {
        // 1. 先查缓存
        String cacheKey = CACHE_KEY_PREFIX + studentId;
        HabitStabilityScore cached = (HabitStabilityScore) redisTemplate
            .opsForValue().get(cacheKey);
        if (cached != null) {
            return cached;
        }
        
        // 2. 计算各维度得分
        LocalDate endDate = LocalDate.now();
        LocalDate startDate = endDate.minusDays(EVALUATION_WINDOW_DAYS);
        
        BigDecimal frequencyScore = calcFrequencyConsistency(studentId, startDate, endDate);
        BigDecimal timeScore = calcTimeStability(studentId, startDate, endDate);
        BigDecimal durationScore = calcDurationStability(studentId, startDate, endDate);
        BigDecimal routineScore = calcRoutineCompletion(studentId, startDate, endDate);
        BigDecimal streakScore = calcStreakScore(studentId);
        
        // 3. 加权计算总分
        BigDecimal totalScore = frequencyScore.multiply(new BigDecimal("0.30"))
            .add(timeScore.multiply(new BigDecimal("0.25")))
            .add(durationScore.multiply(new BigDecimal("0.20")))
            .add(routineScore.multiply(new BigDecimal("0.15")))
            .add(streakScore.multiply(new BigDecimal("0.10")))
            .setScale(2, RoundingMode.HALF_UP);
        
        // 4. 确定习惯阶段
        HabitStage stage = determineStage(totalScore);
        
        // 5. 持久化
        HabitStabilityScore result = HabitStabilityScore.builder()
            .studentId(studentId)
            .score(totalScore)
            .stage(stage)
            .frequencyConsistency(frequencyScore)
            .timeStability(timeScore)
            .durationStability(durationScore)
            .routineCompletion(routineScore)
            .streakScore(streakScore)
            .build();
        
        // 6. 缓存
        redisTemplate.opsForValue().set(cacheKey, result, CACHE_TTL);
        
        return result;
    }
    
    /**
     * 频率一致性: 实际学习天数 / 预期学习天数 * 100
     */
    private BigDecimal calcFrequencyConsistency(Long studentId, 
            LocalDate start, LocalDate end) {
        int expectedDays = calcExpectedDays(start, end); // 排除已知不学习的日期
        int actualDays = learningRecordService.countActiveDays(studentId, start, end);
        
        return BigDecimal.valueOf(actualDays)
            .divide(BigDecimal.valueOf(expectedDays), 2, RoundingMode.HALF_UP)
            .multiply(BigDecimal.valueOf(100))
            .min(BigDecimal.valueOf(100));
    }
    
    /**
     * 时间稳定性: 100 - min(100, start_time_stddev_minutes / max_stddev * 100)
     * 学习开始时间越稳定，得分越高
     */
    private BigDecimal calcTimeStability(Long studentId, 
            LocalDate start, LocalDate end) {
        List<LocalTime> startTimes = learningRecordService
            .getDailyStartTimes(studentId, start, end);
        
        if (startTimes.size() < 3) {
            return BigDecimal.ZERO; // 数据不足
        }
        
        // 转换为分钟数计算标准差
        double[] minutes = startTimes.stream()
            .mapToDouble(t -> t.getHour() * 60.0 + t.getMinute())
            .toArray();
        double mean = Arrays.stream(minutes).average().orElse(0);
        double variance = Arrays.stream(minutes)
            .map(m -> Math.pow(m - mean, 2))
            .average().orElse(0);
        double stddev = Math.sqrt(variance);
        
        // 标准差越小越好，120分钟(2小时)标准差=0分
        double score = Math.max(0, 100 - (stddev / 120.0 * 100));
        return BigDecimal.valueOf(score).setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 连续坚持度
     */
    private BigDecimal calcStreakScore(Long studentId) {
        int currentStreak = learningRecordService.getCurrentStreak(studentId);
        int longestStreak = learningRecordService.getLongestStreak(studentId);
        
        // 66天为满分基准
        double score = Math.min(100, (double) currentStreak / 66.0 * 100);
        
        // 历史最长记录加成(最多+10分)
        double bonus = Math.min(10, (double) longestStreak / 100.0 * 10);
        
        return BigDecimal.valueOf(score + bonus)
            .setScale(2, RoundingMode.HALF_UP)
            .min(BigDecimal.valueOf(100));
    }
    
    private HabitStage determineStage(BigDecimal score) {
        double s = score.doubleValue();
        if (s <= 20) return HabitStage.COLD_START;
        if (s <= 40) return HabitStage.FORMING;
        if (s <= 70) return HabitStage.STABLE;
        return HabitStage.CONSOLIDATION;
    }
    
    /**
     * 触发异步重算(在学习行为变化后调用)
     */
    public void triggerRecalculation(Long studentId) {
        String cacheKey = CACHE_KEY_PREFIX + studentId;
        redisTemplate.delete(cacheKey); // 清除缓存，下次查询时重新计算
        
        // 异步重新计算并持久化
        CompletableFuture.runAsync(() -> {
            HabitStabilityScore score = evaluate(studentId);
            persistDailyLog(studentId, score);
        });
    }
}
```

| `ROUTINE_NOT_FOUND` | 例程实例不存在 | 返回404，引导创建今日例程 |
| `ROUTINE_ALREADY_EXISTS` | 今日例程已创建 | 返回已有例程信息 |
| `INVALID_STATUS_TRANSITION` | 非法状态转换 | 返回当前状态和允许的操作列表 |
| `TEMPLATE_NOT_AVAILABLE` | 模板未启用或不存在 | 降级到 `COLD_START_LITE` 模板 |
| `PHASE_CONTENT_LOAD_FAILED` | 阶段内容加载失败 | 返回兜底内容(通用知识卡片) |
| `STABILITY_EVAL_TIMEOUT` | 稳定度评估超时 | 使用上次缓存结果 |
| `ANCHOR_TRIGGER_CONFLICT` | 多个锚点同时触发 | 取优先级最高的锚点，其余忽略 |
