# 服务端 - 管理后台数据分析看板与运营驾驶舱服务 - 详细设计

> 本文档详细设计管理后台数据分析看板与运营驾驶舱服务，为运营人员、管理者和 B 端合作方提供实时/准实时的数据可视化支持。

## 1. 模块概述

### 1.1 功能定位

管理后台数据分析看板是运营人员、产品经理和管理者的核心工作台，聚合平台用户、学习、商业、质量四大维度的关键指标，支持多粒度时间筛选、多维下钻和异常预警。运营驾驶舱作为首页概览，将最关键的 KPI 和异常信号一屏呈现。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 实时洞察 | 核心指标秒级/分钟级延迟，辅助快速决策 |
| 多维下钻 | 支持按学段/年级/学科/渠道/版本等维度拆解 |
| 异常预警 | 关键指标异动自动检测与告警推送 |
| B 端隔离 | 支持多租户数据隔离，B 端合作伙伴仅看本机构数据 |
| 导出灵活 | 支持数据导出 CSV/Excel，定时邮件报告 |

### 1.3 目标用户

| 角色 | 关注点 |
| --- | --- |
| 运营人员 | 日活、留存、转化漏斗、活动效果 |
| 产品经理 | 功能使用率、用户行为路径、A/B 测试结果 |
| 内容教研 | 题库覆盖率、解析质量、教材对齐度 |
| 财务管理 | 收入、成本、AI 调用花费、退款率 |
| 管理层 | 全局 KPI 概览、趋势、对比 |
| B 端合作方 | 本机构用户数据、学习效果、使用情况 |

### 2.2 数据流向

1. **采集层**：客户端埋点事件、服务端业务日志、数据库 Binlog 变更写入 Kafka
2. **计算层**：Flink/Spark 流式+批处理，将原始数据聚合为分钟级/小时级/天级指标，写入 ClickHouse
3. **服务层**：Dashboard API Service 从 ClickHouse 查询指标，Redis 缓存热点数据
4. **展示层**：管理后台前端通过 HTTP REST / WebSocket 获取数据并渲染图表

### 2.3 技术选型

| 组件 | 选型 | 说明 |
| --- | --- | --- |
| 指标存储 | ClickHouse | 列式存储，适合 OLAP 聚合查询 |
| 热点缓存 | Redis | 缓存高频看板数据，TTL 30s-5min |
| 元数据 | MySQL | 看板配置、用户权限、报告模板 |
| 流式计算 | Flink | 实时指标计算（DAU、在线人数等） |
| 批量计算 | Spark | T+1 聚合指标（留存、转化漏斗等） |
| 消息队列 | Kafka | 埋点事件、业务变更事件 |
| 报表导出 | Apache POI + 异步任务 | 大数据量异步生成 Excel |

## 3. 数据模型设计

### 3.1 指标定义表 (dashboard_metric_def)

```sql
CREATE TABLE dashboard_metric_def (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    metric_code     VARCHAR(64) NOT NULL UNIQUE COMMENT '指标编码，如 dau, revenue',
    metric_name     VARCHAR(128) NOT NULL COMMENT '指标名称',
    metric_category VARCHAR(32) NOT NULL COMMENT '指标分类: USER|LEARNING|BUSINESS|QUALITY',
    metric_type     VARCHAR(16) NOT NULL COMMENT '指标类型: COUNTER|GAUGE|RATE|DISTRIBUTION',
    unit            VARCHAR(16) COMMENT '单位: 人/次/元/分钟/%',
    description     TEXT COMMENT '指标说明',
    aggregation     VARCHAR(16) NOT NULL COMMENT '聚合方式: SUM|AVG|MAX|COUNT_DISTINCT',
    source_table    VARCHAR(128) NOT NULL COMMENT 'ClickHouse 源表',
    source_column   VARCHAR(128) COMMENT '源表字段',
    filter_expr     VARCHAR(512) COMMENT '默认过滤条件表达式',
    dimensions      JSON COMMENT '可用维度列表: ["grade","subject","channel","platform"]',
    granularity     VARCHAR(16) NOT NULL DEFAULT 'DAY' COMMENT '最小粒度: MINUTE|HOUR|DAY|WEEK|MONTH',
    is_realtime     TINYINT(1) DEFAULT 0 COMMENT '是否实时指标',
    alert_threshold JSON COMMENT '预警阈值配置',
    sort_order      INT DEFAULT 0 COMMENT '排序权重',
    status          TINYINT(1) DEFAULT 1 COMMENT '1-启用 0-停用',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category (metric_category),
    INDEX idx_code (metric_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='指标定义表';
```

```java
@Service
@Slf4j
public class MetricQueryService {

    @Autowired
    private ClickHouseTemplate clickHouseTemplate;

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    @Autowired
    private DashboardCardMapper cardMapper;

    /**
     * 查询卡片数据
     */
    public CardDataVO queryCardData(String cardCode, DashboardQueryDTO query) {
        DashboardCard card = cardMapper.selectByCode(cardCode);
        if (card == null) {
            throw new BusinessException(ErrorCode.CARD_NOT_FOUND);
        }

        // 1. 检查缓存
        String cacheKey = buildCacheKey(cardCode, query);
        CardDataVO cached = getFromCache(cacheKey);
        if (cached != null) {
            return cached;
        }

        // 2. 构建查询
        String sql = buildQuerySql(card, query);

        // 3. 执行查询
        List<Map<String, Object>> rows = clickHouseTemplate.queryForList(sql);

        // 4. 组装结果
        CardDataVO result = assembleCardData(card, rows, query);

        // 5. 写入缓存
        saveToCache(cacheKey, result, card.getCacheTtl());

        return result;
    }

    private String buildQuerySql(DashboardCard card, DashboardQueryDTO query) {
        String template = card.getQueryTemplate();
        Map<String, Object> params = new HashMap<>();
        params.put("startDate", query.getStartDate());
        params.put("endDate", query.getEndDate());
        params.put("granularity", query.getGranularity().getClickHouseExpr());

        if (query.getDimension() != null) {
            params.put("dimension", query.getDimension());
        }

        if (query.getDimensionFilter() != null) {
            String whereClause = query.getDimensionFilter().entrySet().stream()
                .map(e -> e.getKey() + " = '" + e.getValue() + "'")
                .collect(Collectors.joining(" AND "));
            params.put("dimensionFilter", " AND " + whereClause);
        } else {
            params.put("dimensionFilter", "");
        }

        // 租户隔离
        if (query.getTenantId() != null) {
            params.put("tenantFilter", " AND tenant_id = " + query.getTenantId());
        } else {
            params.put("tenantFilter", "");
        }

        return StrSubstitutor.replace(template, params, "${", "}");
    }
}
```

### 6.3 异常检测服务

```java
@Service
@Slf4j
public class AnomalyDetectionService {

    @Autowired
    private DashboardAlertRuleMapper alertRuleMapper;

    @Autowired
    private MetricQueryService metricQueryService;

    @Autowired
    private NotifyService notifyService;

    /**
     * 定时检测异常（每 15 分钟）
     */
    @Scheduled(cron = "0 */15 * * * *")
    public void detectAnomalies() {
        List<DashboardAlertRule> rules = alertRuleMapper.selectActiveRules();
        for (DashboardAlertRule rule : rules) {
            try {
                checkRule(rule);
            } catch (Exception e) {
                log.error("告警规则检测失败: ruleId={}, rule={}", rule.getId(), rule.getRuleName(), e);
            }
        }
    }

    private void checkRule(DashboardAlertRule rule) {
        // 检查冷却期
        if (rule.getLastTriggeredAt() != null) {
            long minutesSinceLast = Duration.between(rule.getLastTriggeredAt(), LocalDateTime.now()).toMinutes();
            if (minutesSinceLast < rule.getCooldownMin()) {
                return;
            }
        }

        JSONObject config = JSON.parseObject(rule.getConditionConfig());
        boolean triggered = false;
        String alertDetail = "";

        switch (rule.getConditionType()) {
            case "THRESHOLD":
                triggered = checkThreshold(rule, config);
                alertDetail = String.format("指标 %s 触发阈值告警", rule.getMetricCode());
                break;
            case "PERCENTAGE_CHANGE":
                triggered = checkPercentageChange(rule, config);
                alertDetail = String.format("指标 %s 触发变化率告警", rule.getMetricCode());
                break;
            case "TREND_ANOMALY":
                triggered = checkTrendAnomaly(rule, config);
                alertDetail = String.format("指标 %s 触发趋势异常告警", rule.getMetricCode());
                break;
        }

        if (triggered) {
            log.warn("告警触发: rule={}, detail={}", rule.getRuleName(), alertDetail);
            notifyService.sendAlert(rule, alertDetail);
            alertRuleMapper.updateLastTriggeredAt(rule.getId());
        }
    }

    /**
     * 阈值检测
     */
    private boolean checkThreshold(DashboardAlertRule rule, JSONObject config) {
        BigDecimal threshold = config.getBigDecimal("threshold");
        String operator = config.getString("operator"); // GT|LT|EQ

        // 查询当前值
        BigDecimal currentValue = getCurrentMetricValue(rule.getMetricCode());

        return switch (operator) {
            case "GT" -> currentValue.compareTo(threshold) > 0;
            case "LT" -> currentValue.compareTo(threshold) < 0;
            case "EQ" -> currentValue.compareTo(threshold) == 0;
            default -> false;
        };
    }

    /**
     * 变化率检测
     * 例：DAW 相比上周同日下降超过 20%
     */
    private boolean checkPercentageChange(DashboardAlertRule rule, JSONObject config) {
        String direction = config.getString("direction"); // UP|DOWN
        BigDecimal thresholdPct = config.getBigDecimal("threshold");
        int windowDays = config.getIntValue("windowDays");
        String baseline = config.getString("baseline"); // DAY_OVER_DAY|WOW

        BigDecimal currentValue = getCurrentMetricValue(rule.getMetricCode());
        BigDecimal baselineValue = getBaselineMetricValue(rule.getMetricCode(), baseline);

        if (baselineValue.compareTo(BigDecimal.ZERO) == 0) {
            return false;
        }

        BigDecimal changeRate = currentValue.subtract(baselineValue)
            .divide(baselineValue, 4, RoundingMode.HALF_UP);

        return switch (direction) {
            case "UP" -> changeRate.compareTo(thresholdPct.divide(BigDecimal.valueOf(100))) > 0;
            case "DOWN" -> changeRate.compareTo(thresholdPct.divide(BigDecimal.valueOf(100)).negate()) < 0;
            default -> false;
        };
    }

    /**
     * 趋势异常检测（基于 3-Sigma）
     * 取近 N 天数据，计算均值和标准差，当前值偏离超过 3 倍标准差视为异常
     */
    private boolean checkTrendAnomaly(DashboardAlertRule rule, JSONObject config) {
        int windowDays = config.getIntValue("windowDays", 14);
        double sigmaMultiplier = config.getDoubleValue("sigmaMultiplier", 3.0);

        List<BigDecimal> historyValues = getRecentMetricValues(rule.getMetricCode(), windowDays);
        if (historyValues.size() < windowDays) {
            return false;
        }

        BigDecimal currentValue = historyValues.get(historyValues.size() - 1);
        List<BigDecimal> trainData = historyValues.subList(0, historyValues.size() - 1);

        double mean = trainData.stream()
            .mapToDouble(BigDecimal::doubleValue).average().orElse(0);
        double stdDev = Math.sqrt(trainData.stream()
            .mapToDouble(v -> Math.pow(v.doubleValue() - mean, 2)).average().orElse(0));

        double deviation = Math.abs(currentValue.doubleValue() - mean);
        return stdDev > 0 && deviation > sigmaMultiplier * stdDev;
    }
}
```

```java
                asyncTaskManager.fail(taskId, e.getMessage());
            }
        });
```

```java
        KafkaSource<UserHeartbeatEvent> source = KafkaSource.<UserHeartbeatEvent>builder()
            .setBootstrapServers("kafka:9092")
            .setTopics("user-heartbeat")
            .setGroupId("dashboard-online-users")
            .setValueOnlyDeserializer(new JsonDeserializationSchema<>(UserHeartbeatEvent.class))
            .build();

        DataStream<UserHeartbeatEvent> heartbeats = env
            .fromSource(source, WatermarkStrategy.noWatermarks(), "heartbeat-source");

        // 2. 5 分钟窗口统计在线人数
        heartbeats
            .keyBy(event -> Optional.ofNullable(event.getTenantId()).orElse(0L))
            .window(TumblingProcessingTimeWindows.of(Time.minutes(5)))
            .aggregate(new DistinctUserIdAggregator())
            .addSink(new RedisSink<>("dashboard:realtime:global:online_users"));

        // 3. 按租户维度统计
        heartbeats
            .filter(e -> e.getTenantId() != null)
            .keyBy(UserHeartbeatEvent::getTenantId)
            .window(TumblingProcessingTimeWindows.of(Time.minutes(5)))
            .aggregate(new DistinctUserIdAggregator())
            .addSink(new RedisSink<>("dashboard:realtime:tenant:{tenantId}:online_users"));

        env.execute("Online Users Count");
    }
}
```

### 7.2 Spark T+1 聚合任务

```scala
/**
 * Spark 任务：每日用户指标聚合
 * 调度：每日凌晨 02:00
 */
object UserDailyMetricsJob {

  def main(args: Array[String]): Unit = {
    val spark = SparkSession.builder()
      .appName("UserDailyMetrics")
      .enableHiveSupport()
      .getOrCreate()

    import spark.implicits._

    val targetDate = args.headOption.getOrElse(
      LocalDate.now().minusDays(1).toString
    )

    // 1. 新增注册用户
    val newUsers = spark.sql(
      s"""
        SELECT '$targetDate' AS stat_date,
               channel, platform, grade_range, grade,
               COUNT(*) AS new_users
        FROM user_events
        WHERE event_type = 'register'
          AND DATE(event_time) = '$targetDate'
        GROUP BY channel, platform, grade_range, grade
      """
    )

    // 2. DAU（当天有学习/问答/浏览行为的独立用户）
    val dau = spark.sql(
      s"""
        SELECT '$targetDate' AS stat_date,
               channel, platform, grade_range, grade,
               COUNT(DISTINCT user_id) AS dau,
               AVG(session_duration_sec) AS online_avg_sec,
               SUM(session_duration_sec) AS online_total_sec
        FROM (
          SELECT user_id, channel, platform, grade_range, grade,
                 SUM(duration_sec) AS session_duration_sec
          FROM user_sessions
          WHERE DATE(session_start) = '$targetDate'
          GROUP BY user_id, channel, platform, grade_range, grade
        )
        GROUP BY channel, platform, grade_range, grade
      """
    )

    // 3. 留存率计算
    val retention = calculateRetention(spark, targetDate)

    // 4. 合并写入 ClickHouse
    val finalDF = newUsers
      .join(dau, Seq("stat_date", "channel", "platform", "grade_range", "grade"), "full")
      .na.fill(0)

    finalDF.write
      .format("jdbc")
      .option("url", "jdbc:clickhouse://clickhouse:8123/default")
      .option("dbtable", "metrics_user_daily")
      .option("isolationLevel", "NONE")
      .mode("append")
      .save()

    spark.stop()
  }

  private def calculateRetention(spark: SparkSession, date: String): DataFrame = {
    // 次日留存：N 日前注册 + 当日活跃
    spark.sql(
      s"""
        WITH registered_users AS (
          SELECT user_id, DATE(register_time) AS register_date,
                 channel, platform, grade_range
          FROM users
          WHERE DATE(register_time) BETWEEN DATE_SUB('$date', 30) AND '$date'
        ),
        active_users AS (
          SELECT DISTINCT user_id, DATE(event_time) AS active_date
          FROM user_events
          WHERE DATE(event_time) = '$date'
        )
        SELECT r.register_date AS stat_date,
               r.channel, r.platform, r.grade_range,
               COUNT(DISTINCT CASE WHEN DATEDIFF('$date', r.register_date) = 1
                    THEN a.user_id END) * 1.0 / COUNT(DISTINCT r.user_id) AS retention_d1,
               COUNT(DISTINCT CASE WHEN DATEDIFF('$date', r.register_date) = 7
                    THEN a.user_id END) * 1.0 / COUNT(DISTINCT r.user_id) AS retention_d7,
               COUNT(DISTINCT CASE WHEN DATEDIFF('$date', r.register_date) = 30
                    THEN a.user_id END) * 1.0 / COUNT(DISTINCT r.user_id) AS retention_d30
        FROM registered_users r
        LEFT JOIN active_users a ON r.user_id = a.user_id
        GROUP BY r.register_date, r.channel, r.platform, r.grade_range
      """
    )
  }
}
```

## 8. 缓存策略

### 8.1 缓存层级

| 层级 | 存储 | TTL | 适用场景 |
| --- | --- | --- | --- |
| L1 实时 | Redis | 10-30秒 | 在线人数、实时 DAU |
| L2 热点 | Redis | 1-5分钟 | 看板概览、数字卡片 |
| L3 预计算 | ClickHouse | 持久 | 历史趋势、下钻数据 |
| L4 冷数据 | ClickHouse | 持久+TTL | 超过 1 年的历史数据 |

### 8.2 缓存 Key 设计

```
dashboard:card:{boardCode}:{cardCode}:{startDate}:{endDate}:{granularity}:{dimensionHash}:{tenantHash}
dashboard:realtime:global:{metricCode}
dashboard:realtime:tenant:{tenantId}:{metricCode}
dashboard:export:{taskId}
```

### 8.3 缓存失效策略

| 场景 | 失效方式 |
| --- | --- |
| 实时指标 | Flink 定时覆盖写 |
| T+1 指标 | Spark 作业完成后主动清除对应缓存 |
| 配置变更 | 管理后台操作后发消息清缓存 |
| 手动刷新 | 前端提供"刷新"按钮，跳过缓存 |

```java
public class TenantDataPolicy {

    /**
     * 数据隔离策略：
     * 1. 平台管理员 (tenantId = null) → 查看全平台数据，可通过 tenantId 参数筛选
     * 2. B端用户 (tenantId != null) → SQL 层强制添加 WHERE tenant_id = ?
     *
     * ClickHouse 查询模板中必须包含 ${tenantFilter} 占位符
     */
    public static String applyTenantFilter(String sql, Long tenantId) {
        if (tenantId != null) {
            return sql.replace("${tenantFilter}",
                " AND tenant_id = " + tenantId);
        }
        return sql.replace("${tenantFilter}", "");
    }
}
```

## 10. 异常处理

### 10.1 错误码定义

| 错误码 | 说明 | 处理建议 |
| --- | --- | --- |
| DASHBOARD_001 | 看板不存在 | 检查 boardCode |
| DASHBOARD_002 | 卡片不存在 | 检查 cardCode |

| DASHBOARD_004 | 查询超时 (>30s) | 缩小时间范围或降低粒度 |

| DASHBOARD_006 | 导出任务不存在 | 检查 taskId |
| DASHBOARD_007 | 导出数据量过大 (>100万行) | 缩小时间范围 |
| DASHBOARD_008 | 告警规则配置无效 | 检查阈值和条件 |
| DASHBOARD_009 | 实时数据暂不可用 | 使用 T+1 数据 |

### 10.2 降级策略

| 异常场景 | 降级方案 |
| --- | --- |
| ClickHouse 不可用 | 返回 Redis 缓存的最近一次数据 + 标记"数据非最新" |
| Flink 任务延迟 | 实时指标使用上一周期数据，标注延迟时长 |
| Spark 作业失败 | T+1 指标显示前一日数据 + 告警通知 |
| Redis 不可用 | 直查 ClickHouse，增加超时和重试 |
| 导出文件过大 | 自动拆分为多个文件，或降低粒度 |
