# 作文辅导 - 详细设计文档

## 1. 模块概述

作文辅导为小学、初中、高中学生提供作文审题分析、素材推荐、提纲生成、语言润色和批改反馈服务。以"启发引导"为核心原则，避免替学生整篇代写，通过分步辅助帮助学生提升写作能力。

### 1.1 功能范围

| 功能 | 优先级 | V1.0 |
|------|--------|------|
| 作文题目审题分析 | P1 | ✅ |
| 写作提纲生成 | P1 | ✅ |
| 素材推荐（名言/事例/句式） | P1 | ✅ |
| 作文批改（立意/结构/语言/错别字） | P1 | ✅ |
| 局部润色建议 | P1 | ✅ |
| 范文学习与拆解 | P1 | ✅ |
| 语音输入（口述转文字） | P2 | ❌ |
| 作文历史与版本对比 | P2 | ❌ |
| 考场限时模拟写作 | P2 | ❌ |

### 1.2 依赖模块

| 模块 | 依赖说明 |
|------|----------|
| 用户账号体系 | 获取学段、年级、教材版本用于适龄化处理 |
| AI 智能辅导 | 复用对话基础设施（会话管理、模型调用） |
| 同步课堂 | 获取当前单元写作任务、作文题目来源 |
| 内容服务 | 素材库、范文库、评分标准库 |

## 2. 核心概念与数据结构

### 2.1 作文任务表 `essay_tasks`

```sql
CREATE TABLE essay_tasks (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '任务ID',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    conversation_id BIGINT COMMENT '关联AI对话会话ID（可选）',
    title           VARCHAR(200) NOT NULL COMMENT '作文题目',
    title_source    VARCHAR(20) COMMENT '题目来源: manual/textbook/exam/practice',
    -- 题目结构化信息
    genre           VARCHAR(30) COMMENT '文体: narrative/expository/argumentative/letter/speech/imaginative/practical',
    topic_keywords  JSON COMMENT '题目关键词 ["坚持","梦想","成长"]',
    word_limit_min  INT COMMENT '字数下限',
    word_limit_max  INT COMMENT '字数上限',
    requirements    TEXT COMMENT '题目要求描述（原题附加说明）',
    -- 上下文快照
    stage           VARCHAR(20) NOT NULL COMMENT '学段快照',
    grade           INT NOT NULL COMMENT '年级快照',
    subject         VARCHAR(20) NOT NULL DEFAULT 'chinese' COMMENT '学科: chinese/english',
    -- 状态
    status          TINYINT NOT NULL DEFAULT 0 COMMENT '状态: 0=审题中, 1=列提纲, 2=写作中, 3=已提交批改, 4=批改完成, 5=已归档',
    -- 统计
    draft_count     INT NOT NULL DEFAULT 0 COMMENT '草稿版本数',
    current_version INT NOT NULL DEFAULT 0 COMMENT '当前版本号',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_status (user_id, status),
    INDEX idx_user_created (user_id, created_at DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作文任务';
```

### 2.2 作文草稿表 `essay_drafts`

```sql
CREATE TABLE essay_drafts (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id         BIGINT NOT NULL COMMENT '任务ID',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    version         INT NOT NULL COMMENT '版本号（从1递增）',
    -- 内容
    outline         JSON COMMENT '写作提纲 [{"heading":"开头","content":"用名言引入..."},{"heading":"正文1","content":"..."}]',
    content         MEDIUMTEXT NOT NULL COMMENT '作文正文（Markdown/纯文本）',
    word_count      INT NOT NULL DEFAULT 0 COMMENT '正文字数',
    -- 提交方式
    input_mode      VARCHAR(20) NOT NULL DEFAULT 'text' COMMENT '输入方式: text/ocr/image',
    source_image    VARCHAR(500) COMMENT '手写稿图片URL（OCR输入时）',
    -- 批改结果（仅最终提交版本）
    review_status   TINYINT COMMENT '批改状态: null=未批改, 0=批改中, 1=已完成',
    review_result   JSON COMMENT '批改结果（详见 2.4 批改结果结构）',
    review_at       DATETIME COMMENT '批改完成时间',
    -- 元数据
    is_submitted    TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否为提交批改版本',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_task_version (task_id, version),
    INDEX idx_task (task_id),
    INDEX idx_user (user_id, created_at DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作文草稿';
```

### 2.3 素材库表 `essay_materials`

```sql
CREATE TABLE essay_materials (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    category        VARCHAR(20) NOT NULL COMMENT '素材类型: quote/story/example/sentence/technique',

    content         TEXT NOT NULL COMMENT '素材正文',
    source          VARCHAR(100) COMMENT '出处/作者',
    tags            JSON COMMENT '扩展标签 ["励志","古今中外","对比论证"]',
    usage_count     INT NOT NULL DEFAULT 0 COMMENT '被引用次数',
    status          TINYINT NOT NULL DEFAULT 1 COMMENT '0=下架, 1=上架',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_category_theme (category, theme),
    INDEX idx_stage (stage_scope)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作文素材库';
```

## 3. API 接口设计

### 3.1 审题分析

**POST** `/api/v1/essay/analyze-topic`

分析作文题目，输出文体判断、关键词提取、立意方向和写作建议。

请求：
```json
{

  "additional_requirements": "要求有细节描写，情感真实",

  "grade": 8
```
```json
}
```

### 3.4 提交作文批改

**POST** `/api/v1/essay/submit-review`

支持文本直接输入或图片 OCR 输入。

请求：
```json
{
  "task_id": 10001,
  "content": "（作文正文）",
  "input_mode": "text",
  "source_image": null
}
```

响应（异步，立即返回任务状态）：
```json
{
  "code": 0,
  "data": {
    "draft_id": 5001,
    "version": 2,
    "review_status": "processing",
    "estimated_wait_seconds": 15
  }
}
```

### 3.5 获取批改结果

**GET** `/api/v1/essay/review/{draft_id}`

响应：返回完整的批改结果 JSON（结构见 2.4），`review_status` 为 `processing` 时返回进度提示。

### 4.2 批改异步处理流程

```
用户提交作文
     │
     ▼
API 层创建草稿记录（review_status=0）
     │
     ▼
发送消息到批改队列（RabbitMQ/Redis Stream）
     │
     ├──→ 立即返回 draft_id + estimated_wait
     │
     ▼
批改 Worker 消费消息
     │
     ├── 1. 基础检查（字数、段落结构）
     ├── 2. 调用 AI 批改 Prompt（含评分标准）
     ├── 3. 解析 AI 返回，填充 score_breakdown
     ├── 4. 错别字/标点检测（可独立模型或规则引擎）
     ├── 5. 润色建议生成
     ├── 6. 匹配推荐范文
     │
     ▼
更新 essay_drafts.review_result + review_status=1
     │
     ▼
推送通知给用户（WebSocket / 消息推送）
```

## 5. Prompt 模板设计

### 5.1 审题分析 Prompt

```
你是一位专业的{stage}语文教师。请分析以下作文题目：

【题目】{title}
【附加要求】{requirements}
【学生年级】{grade}年级

请输出：
1. 文体判断（记叙文/议论文/说明文/应用文等）及判断依据
2. 题目关键词提取
3. 题目解读（出题意图分析）
4. 3个推荐立意方向（标注适用性：高/中）
5. 写作建议（3-5条具体可执行的建议）

注意：
- 根据学生年级调整建议深度
- 小学侧重"写什么"，初中侧重"怎么写好"，高中侧重"写得深刻"
- 立意方向应结合该年级学生的认知水平
```

### 5.2 作文批改 Prompt

```
你是一位经验丰富的{stage}语文教师，请对以下学生作文进行批改。

【题目】{title}
【文体要求】{genre}
【字数要求】{word_limit}
【学生年级】{grade}年级

【学生作文】
{content}

请按以下维度评分并给出详细反馈：

1. 立意（满分{theme_max}分）：是否切题、立意深度、思想积极
2. 结构（满分{structure_max}分）：段落清晰、过渡自然、首尾呼应
3. 语言（满分{language_max}分）：表达准确、修辞运用、句式变化
```

### 7.1 错误码定义

| 错误码 | HTTP | 说明 | 处理建议 |
|--------|------|------|----------|
| ESSAY_001 | 400 | 题目文本为空 | 前端校验，提示输入题目 |
| ESSAY_002 | 400 | 题目超长（>200字） | 提示精简题目 |
| ESSAY_003 | 400 | 作文正文为空 | 提示先写内容 |
| ESSAY_004 | 400 | 字数未达标 | 提示最低字数要求 |
| ESSAY_005 | 400 | 字数超出限制 | 提示精简内容 |
| ESSAY_006 | 404 | 任务不存在 | 刷新列表 |
| ESSAY_007 | 404 | 草稿不存在 | 检查版本号 |
| ESSAY_010 | 409 | 任务状态不允许此操作 | 刷新页面查看当前状态 |
| ESSAY_011 | 429 | 批改请求过于频繁 | 限流：每篇作文间隔 ≥ 60秒 |
| ESSAY_020 | 500 | AI 批改服务异常 | 提示稍后重试，后台告警 |
| ESSAY_021 | 500 | AI 批改超时 | 提示稍后查看结果 |
| ESSAY_022 | 500 | AI 返回格式异常 | 重试一次，失败则人工介入 |
| ESSAY_030 | 403 | 会员权益不足 | 引导开通会员 |

### 7.2 AI 批改容错策略

```
批改请求失败
     │
     ├── 网络超时（>30s）
     │     └── 重试 1 次，使用同一模型
     │
     ├── AI 返回格式错误（非 JSON）
     │     └── 重新调用 Prompt，强调 JSON 输出
     │
     ├── AI 返回部分缺失
     │     └── 补充调用缺失维度（如仅有总分缺分项）
     │
     ├── 连续 2 次失败
     │     └── 标记 review_status=-1，通知用户稍后重试
     │
     └── 模型整体不可用
           └── 降级到备用模型，日志记录告警
```

## 8. 关键代码示例

### 8.1 服务端 - 批改服务核心逻辑（Java/Spring）

```java
@Service
@Slf4j
public class EssayReviewService {

    @Autowired
    private AiModelClient aiClient;

    @Autowired
    private EssayDraftMapper draftMapper;

    @Autowired
    private EssayMaterialService materialService;

    @Autowired
    private ScoreStandardConfig scoreConfig;

    /**
     * 提交作文批改（异步）
     */
    @Async("reviewExecutor")
    public void submitReview(Long draftId) {
        EssayDraft draft = draftMapper.selectById(draftId);
        if (draft == null || draft.getReviewStatus() == null) {
            log.warn("草稿不存在或状态异常: {}", draftId);
            return;
        }

        // 更新状态为批改中
        draft.setReviewStatus((byte) 0);
        draftMapper.updateById(draft);

        try {
            EssayTask task = taskMapper.selectById(draft.getTaskId());
            ScoreStandard standard = scoreConfig.getStandard(task.getStage());

            // 构建 Prompt
            String prompt = buildReviewPrompt(task, draft, standard);

            // 调用 AI（带重试）
            String aiResponse = callWithRetry(prompt, 2);

            // 解析结果
            ReviewResult result = parseReviewResult(aiResponse, standard);

            // 错别字检测（可并行）
            List<Typo> typos = detectTypos(draft.getContent());
            result.setTypos(typos);

            // 匹配推荐范文
            List<Long> refEssayIds = materialService.matchExamples(
                task.getTheme(), task.getGenre(), task.getStage()
            );
            result.setReferenceEssays(refEssayIds);

            // 写入结果
            draft.setReviewResult(JsonUtils.toJson(result));
            draft.setReviewStatus((byte) 1);
            draft.setReviewAt(LocalDateTime.now());
            draftMapper.updateById(draft);

            // 推送通知
            notificationService.pushReviewDone(draft.getUserId(), draft.getTaskId());

        } catch (AiModelException e) {
            log.error("AI批改失败, draftId={}", draftId, e);
            draft.setReviewStatus((byte) -1);
            draftMapper.updateById(draft);
            notificationService.pushReviewFailed(draft.getUserId());
        }
    }

    private String callWithRetry(String prompt, int maxRetries) {
        AiModelException lastEx = null;
        for (int i = 0; i < maxRetries; i++) {
            try {
                String response = aiClient.chat(prompt, "essay-review");
                if (isValidJson(response)) return response;
                log.warn("AI返回非JSON, 重试 {}/{}", i + 1, maxRetries);
            } catch (AiModelException e) {
                lastEx = e;
                log.warn("AI调用失败, 重试 {}/{}: {}", i + 1, maxRetries, e.getMessage());
            }
        }
        throw lastEx != null ? lastEx : new AiModelException("批改服务异常");
    }
}
```

```java
@Service
public class EssayTopicAnalysisService {

    public TopicAnalysisResult analyzeTopic(AnalyzeTopicRequest req) {
        String prompt = String.format(
            EssayPromptTemplates.TOPIC_ANALYSIS,
            stageLabel(req.getStage()),
            req.getTitle(),
```

### 8.3 前端 - 自动保存 Hook（Flutter/Dart）

```dart
class EssayEditorController extends GetxController {
  final String taskId;
  final TextEditingController contentController = TextEditingController();
  final Rx<EssayTaskStatus> status = Rx(EssayTaskStatus.writing);
  Timer? _autoSaveTimer;
  String _lastSavedContent = '';

  @override
  void onInit() {
    super.onInit();
    // 每 30 秒检查是否需要自动保存
    _autoSaveTimer = Timer.periodic(Duration(seconds: 30), (_) => _autoSave());
  }

  Future<void> _autoSave() async {
    final content = contentController.text;
    if (content == _lastSavedContent || content.trim().isEmpty) return;

    try {
      await EssayApi.saveDraft(
        taskId: taskId,
        content: content,
        wordCount: content.length,
      );
      _lastSavedContent = content;
      debugPrint('草稿已自动保存');
    } catch (e) {
      debugPrint('自动保存失败: $e');
    }
  }

  Future<void> submitForReview() async {
    final content = contentController.text;
    if (content.trim().isEmpty) {
      showError('请先写入作文内容');
      return;
    }

    status.value = EssayTaskStatus.submitted;
    _autoSaveTimer?.cancel();

    try {
      final resp = await EssayApi.submitReview(taskId: taskId, content: content);
      showSuccess('已提交批改，预计 ${resp.estimatedWaitSeconds} 秒后完成');
      _pollReviewResult(resp.draftId);
    } catch (e) {
      status.value = EssayTaskStatus.writing;
      showError('提交失败，请重试');
      _autoSaveTimer = Timer.periodic(Duration(seconds: 30), (_) => _autoSave());
    }
  }

  void _pollReviewResult(int draftId) {
    // 轮询或 WebSocket 等待批改结果
    EssayApi.pollReview(draftId, interval: Duration(seconds: 3)).then((result) {
      status.value = EssayTaskStatus.reviewed;
      // 跳转到批改结果页
      Get.toNamed('/essay/review/$draftId');
    });
  }

  @override
  void onClose() {
    _autoSaveTimer?.cancel();
    contentController.dispose();
    super.onClose();
  }
}
```
