# 服务端-学生学习数据个人统计基线计算与异常波动智能检测预警引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎为平台每位学生建立**个人化学习行为统计基线**（Personal Learning Baseline），持续追踪关键学习指标（学习时长、答题正确率、学习频次、专注度、学科分布等），通过时序异常检测算法识别**显著偏离个人正常模式的波动**，自动生成预警并路由至相关模块（家长通知、学情报告、学习规划调整、人工关怀等）。

### 1.2 与已有模块的区别

| 已有模块 | 关注点 | 本引擎差异 |
|---------|--------|-----------|
| 学生学习行为异常检测与作弊行为识别服务 | 检测作弊行为（抄袭、秒答等） | 本引擎关注**正常学习行为的统计偏离**，而非作弊 |
| 学习动力量化与学习倦怠预警引擎 | 学习倦怠与动力衰退 | 本引擎覆盖**全维度学习指标**，不仅限于动力维度 |
| 学生学习状态建模与动态评估引擎 | 当前学习状态分类（专注/松懈等） | 本引擎做**纵向时间序列对比**，而非横向状态分类 |
| 学生学习成长曲线建模与长期学习趋势预测引擎 | 长期成长趋势预测 | 本引擎聚焦**短期突发性异常检测**（天/周级别） |
| 学生学习风险评估与早期预警系统 | 综合风险评估评分 | 本引擎提供**多维度独立基线**与细粒度异常归因 |

### 1.3 核心价值

1. **个性化基线**：每个学生有自己的"正常区间"，避免用统一阈值误判。
2. **早期发现**：在问题恶化为显性结果（成绩下降、辍学）前发现隐性信号。
3. **精准归因**：不仅能发现"异常"，还能指出是哪个维度、哪个时段、偏离程度。
4. **自动路由**：异常发现后自动触发对应干预策略，减少人工介入延迟。

### 1.4 适用范围

- **服务端**：作为学习数据分析中台的基础设施服务，供学情分析、家长报告、学习规划等上层业务调用。
- **触发频率**：每日批量计算 + 实时增量更新（流式）。
- **数据来源**：答题记录、学习会话记录、学习时长统计、APP行为日志。

## 4. 核心算法设计

### 4.1 基线计算模型

#### 4.1.1 滚动窗口基线（Rolling Window Baseline）

使用过去 30 天数据计算基线统计量，采用稳健统计方法减少异常值影响。

```python
import numpy as np
from decimal import Decimal
from typing import List, Optional, Tuple
from dataclasses import dataclass
from datetime import date, timedelta
import json

@dataclass
class BaselineParams:
    """基线参数"""
    mean: float
    std: float
    median: float
    p5: float       # 5th percentile
    p95: float      # 95th percentile
    iqr: float      # interquartile range
    trend_slope: float
    trend_direction: str
    weekday_means: dict
    weekend_means: dict
    sample_count: int
    confidence: float


class RollingBaselineCalculator:
    """
    滚动窗口基线计算器
    窗口大小默认30天，使用稳健统计（中位数 + MAD）减少异常值影响
    """

    def __init__(self, window_size: int = 30, min_samples: int = 14):
        self.window_size = window_size
        self.min_samples = min_samples  # 最少样本数

    def calculate(
        self,
        values: List[Tuple[date, float]],  # [(date, value), ...]
        metric_key: str,
        current_date: date
    ) -> Optional[BaselineParams]:
        """
        计算基线参数

        Args:
            values: 历史数据点列表 (日期, 值)
            metric_key: 指标键名
            current_date: 当前日期

        Returns:
            BaselineParams 或 None（数据不足时）
        """
        if len(values) < self.min_samples:
            return None

        # 按日期排序，截取窗口
        values.sort(key=lambda x: x[0])
        window_start = current_date - timedelta(days=self.window_size)
        window_data = [(d, v) for d, v in values if d >= window_start]

        if len(window_data) < self.min_samples:
            return None

        raw_values = np.array([v for _, v in window_data], dtype=float)

        # --- 稳健统计 ---
        median = float(np.median(raw_values))
        mean = float(np.mean(raw_values))
        std = float(np.std(raw_values, ddof=1))

        # MAD (Median Absolute Deviation) 作为稳健标准差
        mad = float(np.median(np.abs(raw_values - median)))
        robust_std = 1.4826 * mad if mad > 0 else std  # 1.4826是正态分布常数

        # 使用稳健标准差替换（如果std被异常值污染）
        if std > 2 * robust_std and robust_std > 0:
            std = robust_std

        # 百分位数
        p5 = float(np.percentile(raw_values, 5))
        p95 = float(np.percentile(raw_values, 95))
        q1 = float(np.percentile(raw_values, 25))
        q3 = float(np.percentile(raw_values, 75))
        iqr = q3 - q1

        # --- 趋势分析（简单线性回归）---
        x = np.arange(len(raw_values), dtype=float)
        slope = self._linear_regression_slope(x, raw_values)
        trend_direction = self._classify_trend(slope, metric_key)

        # --- 工作日/周末分组均值 ---
        weekday_means, weekend_means = self._compute_day_group_means(window_data)

        # --- 置信度 ---
        confidence = self._compute_confidence(len(window_data), self.window_size)

        return BaselineParams(
            mean=mean,
            std=std,
            median=median,
            p5=p5,
            p95=p95,
            iqr=iqr,
            trend_slope=slope,
            trend_direction=trend_direction,
            weekday_means=weekday_means,
            weekend_means=weekend_means,
            sample_count=len(window_data),
            confidence=confidence,
        )

    def _linear_regression_slope(self, x: np.ndarray, y: np.ndarray) -> float:
        """简单线性回归斜率"""
        n = len(x)
        if n < 2:
            return 0.0
        x_mean = x.mean()
        y_mean = y.mean()
        numerator = np.sum((x - x_mean) * (y - y_mean))
        denominator = np.sum((x - x_mean) ** 2)
        return float(numerator / denominator) if denominator != 0 else 0.0

    def _classify_trend(self, slope: float, metric_key: str) -> str:
        """分类趋势方向"""
        # 根据指标类型定义不同的趋势阈值
        trend_thresholds = {
            "study_duration_total": 0.5,    # 每天变化0.5分钟以上算趋势
            "correct_rate": 0.002,          # 每天变化0.2%以上算趋势
            "focus_score": 0.3,             # 每天变化0.3分以上算趋势
        }
        threshold = trend_thresholds.get(metric_key, 0.01)

        if slope > threshold:
            return "UP"
        elif slope < -threshold:
            return "DOWN"
        else:
            return "STABLE"

    def _compute_day_group_means(
        self, data: List[Tuple[date, float]]
    ) -> Tuple[dict, dict]:
        """按工作日/周末分组计算均值"""
        weekday_vals = {0: [], 1: [], 2: [], 3: [], 4: []}  # Mon-Fri
        weekend_vals = {5: [], 6: []}  # Sat-Sun

        for d, v in data:
            dow = d.weekday()
            if dow < 5:
                weekday_vals[dow].append(v)
            else:
                weekend_vals[dow].append(v)

        day_names = {0: "MON", 1: "TUE", 2: "WED", 3: "THU", 4: "FRI", 5: "SAT", 6: "SUN"}
        weekday_means = {
            day_names[d]: round(float(np.mean(vals)), 4) if vals else 0.0
            for d, vals in weekday_vals.items()
        }
        weekend_means = {
            day_names[d]: round(float(np.mean(vals)), 4) if vals else 0.0
            for d, vals in weekend_vals.items()
        }
        return weekday_means, weekend_means

    def _compute_confidence(self, sample_count: int, window_size: int) -> float:
        """计算基线置信度（样本覆盖度）"""
        coverage = sample_count / window_size
        # 置信度曲线：50%覆盖→0.5置信，80%覆盖→0.8置信，100%覆盖→1.0
        return round(min(coverage, 1.0), 4)
```

#### 4.1.2 贝叶斯在线变化点检测（Bayesian Online Change Point Detection）

用于检测学生学习模式的结构性变化点（如从"每天学1小时"变为"每天学30分钟"）。

```python
class BayesianChangePointDetector:
    """
    贝叶斯在线变化点检测
    参考: Adams & MacKay (2007) "Bayesian Online Changepoint Detection"
    简化实现：使用学生t分布作为预测模型（对异常值稳健）
    """

    def __init__(
        self,
        hazard_rate: float = 1 / 30,   # 默认变化点先验概率（每30天可能有一次变化）
        max_run_length: int = 90,      # 最大运行长度
    ):
        self.hazard_rate = hazard_rate
        self.max_run_length = max_run_length

    def detect(
        self,
        values: List[float],   # 时序数据
        threshold: float = 0.3  # 变化点概率阈值
    ) -> List[int]:
        """
        检测变化点

        Returns:
            变化点索引列表
        """
        n = len(values)
        if n < 10:
            return []

        # 初始化
        # R_t[i] = P(run_length = i at time t)
        R = np.zeros((n, self.max_run_length + 1))
        R[0, 0] = 1.0  # 初始：run_length = 0

        # 在线学生t分布参数（共轭先验）
        # 使用Normal-Inverse-Gamma共轭族
        mu0, kappa0, alpha0, beta0 = 0.0, 1.0, 1.0, 1.0

        change_points = []

        for t in range(1, n):
            # 预测概率（学生t分布）
            x_t = values[t]

            # 计算每个run_length的预测概率
            predictive_probs = np.zeros(min(t, self.max_run_length) + 1)
            for i in range(min(t, self.max_run_length) + 1):
                predictive_probs[i] = self._student_t_pdf(
                    x_t, mu0, kappa0, alpha0, beta0
                )

            # 更新运行长度概率
            growth_probs = R[t - 1, :t] * predictive_probs[:t] * (1 - self.hazard_rate)
            change_prob = np.sum(R[t - 1, :t] * predictive_probs[:t]) * self.hazard_rate

            R[t, 0] = change_prob
            R[t, 1:t + 1] = growth_probs

            # 归一化
            total = R[t, :t + 1].sum()
            if total > 0:
                R[t, :t + 1] /= total

            # 更新共轭参数（简化：使用最近窗口）
            if t >= 2:
                recent_vals = values[max(0, t - 30):t + 1]
                mu0 = np.mean(recent_vals)
                var = np.var(recent_vals, ddof=1) if len(recent_vals) > 1 else 1.0
                beta0 = max(var * alpha0 / (kappa0 + 1), 1e-6)

            # 检查变化点
            if R[t, 0] > threshold:
                change_points.append(t)

        return change_points

    def _student_t_pdf(
        self, x: float, mu: float, kappa: float, alpha: float, beta: float
    ) -> float:
        """学生t分布概率密度函数（简化版）"""
        from scipy.stats import t as t_dist
        scale = np.sqrt(beta * (kappa + 1) / (alpha * kappa))
        df = 2 * alpha
        return float(t_dist.pdf(x, df=df, loc=mu, scale=max(scale, 1e-6)))
```

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List, Dict, Optional
from datetime import date
import numpy as np

@dataclass
class AnomalyResult:

    anomaly_score: float    # 0-1

class AnomalyDetector(ABC):

class ZScoreDetector(AnomalyDetector):
    """
    Z-Score 检测器
    适用于近似正态分布的指标（学习时长、答题量等）
    """

    def detect(self, metric_key, observed_value, baseline, history, current_date):
        if baseline.std == 0 or baseline.confidence < 0.4:
            return None

        # 使用工作日/周末感知的期望值
        expected = self._seasonal_expected(baseline, current_date)

        z_score = (observed_value - expected) / baseline.std

        if abs(z_score) < 1.5:
            return None  # 正常范围

        direction = "LOWER" if z_score < 0 else "HIGHER"
        severity = self._classify_severity(abs(z_score), direction, history, metric_key)
        anomaly_score = self._compute_score(abs(z_score))

        return AnomalyResult(
            metric_key=metric_key,
            observed=observed_value,
            expected=expected,
            deviation=observed_value - expected,
            deviation_ratio=abs(z_score),
            z_score=z_score,
            anomaly_score=anomaly_score,
            direction=direction,
            severity=severity,
            method="ZSCORE",
        )

    def _seasonal_expected(self, baseline: BaselineParams, current_date: date) -> float:
        """根据星期几调整期望值"""
        dow = current_date.weekday()
        day_map = {0: "MON", 1: "TUE", 2: "WED", 3: "THU", 4: "FRI", 5: "SAT", 6: "SUN"}

        if dow < 5:
            day_means = baseline.weekday_means
        else:
            day_means = baseline.weekend_means

        day_key = day_map[dow]
        seasonal_mean = day_means.get(day_key, baseline.mean)

        # 加权融合全局均值和季节均值
        seasonal_weight = 0.6
        return seasonal_weight * seasonal_mean + (1 - seasonal_weight) * baseline.mean

    def _classify_severity(
        self, abs_z: float, direction: str, history: List[float], metric_key: str
    ) -> str:
        """分类严重度"""
        # 下降方向加权
        weight = 1.2 if direction == "LOWER" else 1.0
        adjusted_z = abs_z * weight

        if adjusted_z >= 3.0:
            return "SEVERE"
        elif adjusted_z >= 2.0:
            return "MODERATE"
        else:
            return "MILD"

    def _compute_score(self, abs_z: float) -> float:
        """将Z-Score映射为0-1的异常分数"""
        # 使用sigmoid映射
        score = 1.0 / (1.0 + np.exp(-(abs_z - 2.0)))
        return round(float(score), 4)


class EWMADetector(AnomalyDetector):
    """
    EWMA (指数加权移动平均) 控制图检测器
    适用于检测缓慢漂移（渐进性变化）
    """

    def __init__(self, lambda_param: float = 0.2, control_limit: float = 2.7):
        """
        Args:
            lambda_param: EWMA平滑参数 (0-1)，越小越敏感于历史
            control_limit: 控制限（L倍的sigma）
        """
        self.lambda_param = lambda_param
        self.control_limit = control_limit

    def detect(self, metric_key, observed_value, baseline, history, current_date):
        if len(history) < 10 or baseline.std == 0:
            return None

        # 计算 EWMA 序列
        ewma = self._compute_ewma(history + [observed_value])
        ewma_value = ewma[-1]

        # EWMA控制限
        n = len(history) + 1
        # EWMA方差因子
        lcl = baseline.mean - self.control_limit * baseline.std * np.sqrt(
            self.lambda_param / (2 - self.lambda_param) * (1 - (1 - self.lambda_param) ** (2 * n))
        )
        ucl = baseline.mean + self.control_limit * baseline.std * np.sqrt(
            self.lambda_param / (2 - self.lambda_param) * (1 - (1 - self.lambda_param) ** (2 * n))
        )

        if lcl <= ewma_value <= ucl:
            return None

        z_score = (ewma_value - baseline.mean) / (
            baseline.std * np.sqrt(
                self.lambda_param / (2 - self.lambda_param)
            )
        )

        direction = "LOWER" if ewma_value < baseline.mean else "HIGHER"
        severity = "SEVERE" if abs(z_score) >= 3 else ("MODERATE" if abs(z_score) >= 2 else "MILD")
        anomaly_score = round(float(1.0 / (1.0 + np.exp(-(abs(z_score) - 2.0)))), 4)

        return AnomalyResult(
            metric_key=metric_key,
            observed=observed_value,
            expected=baseline.mean,
            deviation=ewma_value - baseline.mean,
            deviation_ratio=abs(z_score),
            z_score=float(z_score),
            anomaly_score=anomaly_score,
            direction=direction,
            severity=severity,
            method="EWMA",
        )

    def _compute_ewma(self, values: List[float]) -> List[float]:
        """计算EWMA序列"""
        ewma = [values[0]]
        for i in range(1, len(values)):
            ewma.append(
                self.lambda_param * values[i] + (1 - self.lambda_param) * ewma[-1]
            )
        return ewma


class MultiMetricAnomalyDetector:
    """
    多维度联合异常检测器
    使用 Isolation Forest 检测多维度联合异常
    """

    def __init__(self):
        from sklearn.ensemble import IsolationForest
        self._model: Optional[IsolationForest] = None
        self._feature_keys: List[str] = []

    def detect_batch(
        self,
        student_id: int,
        current_metrics: Dict[str, float],
        history_data: List[Dict[str, float]],  # 最近30天每日指标字典
        current_date: date,
    ) -> List[AnomalyResult]:
        """
        多维度联合异常检测

        Args:
            current_metrics: 当日各维度指标值
            history_data: 历史每日各维度指标值列表

        Returns:
            异常结果列表（可能包含多个维度的异常）
        """
        if len(history_data) < 15:
            return []

        self._feature_keys = [
            k for k in current_metrics.keys()
            if k in [m.value for m in MetricKey]
        ]
        if len(self._feature_keys) < 3:
            return []

        # 构建特征矩阵
        X_history = np.array([
            [row.get(k, 0) for k in self._feature_keys]
            for row in history_data
        ])

        # 标准化
        from sklearn.preprocessing import StandardScaler
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X_history)

        # 训练 Isolation Forest
        self._model = IsolationForest(
            n_estimators=100,
            contamination=0.1,
            random_state=42,
        )
        self._model.fit(X_scaled)

        # 预测当前数据
        current_vector = np.array([[current_metrics.get(k, 0) for k in self._feature_keys]])
        current_scaled = scaler.transform(current_vector)

        is_anomaly = self._model.predict(current_scaled)[0] == -1
        anomaly_score = float(self._model.decision_function(current_scaled)[0])

        if not is_anomaly:
            return []

        # 分析哪个维度贡献最大
        results = []
        feature_scores = self._compute_feature_contribution(
            current_scaled, scaler, X_scaled
        )

        for i, feature_key in enumerate(self._feature_keys):
            if feature_scores[i] > 0.5:  # 该维度贡献较大
                contribution = feature_scores[i]
                deviation = current_metrics[feature_key] - np.mean(X_history[:, i])
                std = np.std(X_history[:, i])

                if std > 0:
                    z = deviation / std
                    severity = "SEVERE" if abs(z) >= 3 else ("MODERATE" if abs(z) >= 2 else "MILD")
                    results.append(AnomalyResult(
                        metric_key=feature_key,
                        observed=current_metrics[feature_key],
                        expected=float(np.mean(X_history[:, i])),
                        deviation=float(deviation),
                        deviation_ratio=abs(float(z)) if std > 0 else 0,
                        z_score=float(z) if std > 0 else 0,
                        anomaly_score=round(contribution, 4),
                        direction="LOWER" if deviation < 0 else "HIGHER",
                        severity=severity,
                        method="ISOLATION_FOREST",
                    ))

        return results

    def _compute_feature_contribution(
        self, current: np.ndarray, scaler: StandardScaler, X_train: np.ndarray
    ) -> np.ndarray:
        """
        计算各维度对异常的贡献度
        使用置换重要性方法
        """
        base_score = abs(self._model.decision_function(current)[0])
        contributions = np.zeros(len(self._feature_keys))

        for i in range(len(self._feature_keys)):
            # 将该维度替换为训练集均值
            perturbed = current.copy()
            perturbed[0, i] = 0  # 标准化后的均值即0
            perturbed_score = abs(self._model.decision_function(perturbed)[0])

            # 贡献度 = 恢复后异常分数减少比例
            if base_score > 0:
                contributions[i] = max(0, (base_score - perturbed_score) / base_score)

        # 归一化
        total = contributions.sum()
        if total > 0:
            contributions /= total

        return contributions
```

```python
        rule = self.ALERT_TYPE_RULES.get(alert_type, {})
        desc = rule.get("description", "学习状态异常")

        if severity == "SEVERE":
            prefix = "【严重】"
        elif severity == "MODERATE":
            prefix = "【关注】"
        else:
            prefix = "【提示】"

        return f"{prefix}{desc}"

    def _generate_summary(
        self, alert_type: str, anomalies: List[AnomalyResult]
    ) -> str:
        """生成预警摘要（可后续接入LLM生成自然语言）"""
        parts = []
        for a in anomalies:
            change_pct = abs(a.deviation / a.expected * 100) if a.expected != 0 else 0
            if a.direction == "LOWER":
                parts.append(
                    f"{a.metric_key} 下降至 {a.observed:.1f}"
                    f"（基线 {a.expected:.1f}，下降 {change_pct:.0f}%）"
                )
            else:
                parts.append(
                    f"{a.metric_key} 升至 {a.observed:.1f}"
                    f"（基线 {a.expected:.1f}，上升 {change_pct:.0f}%）"
                )

        return "；".join(parts) + "。"

    def _meets_severity(self, actual: str, required: str) -> bool:
        severity_order = {"MILD": 0, "MODERATE": 1, "SEVERE": 2}
        return severity_order[actual] >= severity_order[required]
```

```python
class StudentMetricBaselineService:
    """

    主服务类
    """

    def __init__(
        self,

        alert_repository: "AlertRepository",
        event_publisher: "EventPublisher",

        self.baseline_repo = baseline_repository

        self.alert_repo = alert_repository
        self.event_publisher = event_publisher

        # 初始化各组件
        self.baseline_calculator = RollingBaselineCalculator(window_size=30)
        self.cp_detector = BayesianChangePointDetector()
        self.zscore_detector = ZScoreDetector()
        self.ewma_detector = EWMADetector(lambda_param=0.2)
        self.multi_detector = MultiMetricAnomalyDetector()
        self.alert_orchestrator = AlertOrchestrator()

    # ===================== 每日批处理入口 =====================

    def run_daily_batch(self, target_date: date) -> dict:
        """
        每日批量处理入口
        1. 聚合前日数据
        2. 更新基线
        3. 检测异常
        4. 生成预警
        """
        logger.info(f"开始每日批量处理: {target_date}")

        stats = {
            "students_processed": 0,
            "baselines_updated": 0,
            "anomalies_detected": 0,
            "alerts_generated": 0,
            "errors": 0,
        }

        # 获取所有活跃学生
        active_students = self.metric_repo.get_active_students(target_date)

        for student_id in active_students:
            try:
                self._process_single_student(student_id, target_date)
                stats["students_processed"] += 1
            except Exception as e:
                logger.error(f"处理学生 {student_id} 失败: {e}")
                stats["errors"] += 1

        logger.info(f"每日批量处理完成: {stats}")
        return stats

    def _process_single_student(self, student_id: int, target_date: date) -> None:
        """处理单个学生的完整流程"""

        # 1. 获取前日指标（已由聚合任务写入）
        daily_metrics = self.metric_repo.get_daily_metrics(student_id, target_date)
        if not daily_metrics:
            return

        # 2. 获取历史数据（30天）
        history = self.metric_repo.get_metrics_history(
            student_id, target_date - timedelta(days=30), target_date - timedelta(days=1)
        )

        # 3. 更新基线
        for metric_key in MetricKey:
            metric_history = [
                (d, m.get(metric_key.value, 0)) for d, m in history
                if metric_key.value in m
            ]
            if len(metric_history) >= 14:
                baseline = self.baseline_calculator.calculate(
                    metric_history, metric_key.value, target_date
                )
                if baseline:
                    self.baseline_repo.upsert_baseline(
                        student_id, metric_key.value, baseline
                    )

        # 4. 异常检测
        anomalies = self._run_anomaly_detection(student_id, daily_metrics, history, target_date)

        # 5. 保存异常记录
        for anomaly in anomalies:
            self.anomaly_repo.save_anomaly(student_id, target_date, anomaly)

        # 6. 生成预警
        if anomalies:
            alerts = self.alert_orchestrator.process_anomalies(
                student_id, target_date, anomalies
            )
            for alert in alerts:
                self.alert_repo.save_alert(alert)
                # 发布预警事件，触发下游路由
                self.event_publisher.publish("student_anomaly_alert", alert)

    def _run_anomaly_detection(
        self,
        student_id: int,
        current_metrics: Dict[str, float],
        history: List[tuple],
        target_date: date,
    ) -> List[AnomalyResult]:
        """执行多策略异常检测"""
        anomalies = []
        history_values = {k: [] for k in current_metrics}
        for d, m in history:
            for k in m:
                if k in history_values:
                    history_values[k].append(m[k])

        # 策略1: Z-Score 逐维度检测
        for metric_key, observed_value in current_metrics.items():
            baseline = self.baseline_repo.get_baseline(student_id, metric_key)
            if baseline and len(history_values.get(metric_key, [])) >= 7:
                result = self.zscore_detector.detect(
                    metric_key, observed_value, baseline,
                    history_values[metric_key], target_date
                )
                if result:
                    anomalies.append(result)

        # 策略2: EWMA 漂移检测（对关键维度）
        for metric_key in ["study_duration_total", "correct_rate", "focus_score"]:
            if metric_key not in current_metrics:
                continue
            baseline = self.baseline_repo.get_baseline(student_id, metric_key)
            if baseline and len(history_values.get(metric_key, [])) >= 10:
                result = self.ewma_detector.detect(
                    metric_key, current_metrics[metric_key], baseline,
                    history_values[metric_key], target_date
                )
                if result:
                    # 去重：如果Z-Score已检测到同维度异常，跳过
                    if not any(a.metric_key == metric_key and a.method == "ZSCORE" for a in anomalies):
                        anomalies.append(result)

        # 策略3: 多维度联合检测
        history_dicts = [m for _, m in history]
        multi_results = self.multi_detector.detect_batch(
            student_id, current_metrics, history_dicts, target_date
        )
        # 补充未被单维度检测发现的异常
        existing_keys = {a.metric_key for a in anomalies}
        for result in multi_results:
            if result.metric_key not in existing_keys:
                anomalies.append(result)

        return anomalies

    # ===================== 实时增量入口 =====================

    def on_learning_session_ended(self, student_id: int, session_data: dict) -> None:
        """
        学习会话结束时实时增量触发
        更新当日指标，执行轻量级异常检测
        """
        target_date = session_data["end_time"].date()

        # 更新当日指标
        self.metric_repo.update_daily_metrics_incremental(
            student_id, target_date, session_data
        )

        # 获取当日当前指标
        current_metrics = self.metric_repo.get_daily_metrics(student_id, target_date)
        if not current_metrics:
            return

        # 轻量级实时检测：仅Z-Score检测关键维度
        for metric_key in ["study_duration_total", "correct_rate", "focus_score"]:
            if metric_key not in current_metrics:
                continue
            baseline = self.baseline_repo.get_baseline(student_id, metric_key)
            if not baseline:
                continue
            result = self.zscore_detector.detect(
                metric_key, current_metrics[metric_key], baseline,
                [],  # 实时模式不传历史（已在基线中）
                target_date,
            )
            if result and result.severity in ("MODERATE", "SEVERE"):
                # 发布实时异常事件
                self.event_publisher.publish("student_realtime_anomaly", {
                    "student_id": student_id,
                    "date": target_date.isoformat(),
                    "metric": metric_key,
                    "observed": result.observed,
                    "expected": result.expected,
                    "severity": result.severity,
                })
```

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Optional, Tuple
from datetime import date
import pymysql


class MetricRepository(ABC):
    """指标数据仓库接口"""

    @abstractmethod
    def get_daily_metrics(self, student_id: int, metric_date: date) -> Optional[Dict[str, float]]:
        pass

    @abstractmethod
    def get_metrics_history(
        self, student_id: int, start_date: date, end_date: date
    ) -> List[Tuple[date, Dict[str, float]]]:
        pass

    @abstractmethod
    def get_active_students(self, target_date: date) -> List[int]:
        pass

    @abstractmethod
    def update_daily_metrics_incremental(
        self, student_id: int, metric_date: date, session_data: dict
    ) -> None:
        pass


class MySQLMetricRepository(MetricRepository):
    """MySQL 实现"""

    def __init__(self, connection_pool: pymysql.ConnectionPool):
        self.pool = connection_pool

    def get_daily_metrics(self, student_id: int, metric_date: date) -> Optional[Dict[str, float]]:
        """获取学生某日所有指标"""
        conn = self.pool.connection()
        try:
            with conn.cursor(pymysql.cursors.DictCursor) as cursor:
                cursor.execute("""
                    SELECT 
                        study_duration_total, study_duration_effective,
                        correct_rate, question_count,
                        focus_score, avg_session_length, session_count,
                        interruption_count, subject_entropy,
                        ai_conversation_count, app_open_count,
                        avg_response_time_ms,
                        TIMESTAMPDIFF(MINUTE, first_active_time, last_active_time) as active_time_span
                    FROM student_daily_metrics
                    WHERE student_id = %s AND metric_date = %s
                """, (student_id, metric_date))
                row = cursor.fetchone()
                if not row:
                    return None
                # 过滤None值
                return {k: float(v) for k, v in row.items() if v is not None}
        finally:
            conn.close()

    def get_metrics_history(
        self, student_id: int, start_date: date, end_date: date
    ) -> List[Tuple[date, Dict[str, float]]]:
        """获取历史指标范围"""
        conn = self.pool.connection()
        try:
            with conn.cursor(pymysql.cursors.DictCursor) as cursor:
                cursor.execute("""
                    SELECT metric_date,
                           study_duration_total, study_duration_effective,
                           correct_rate, question_count,
                           focus_score, avg_session_length, session_count,
                           interruption_count, subject_entropy,
                           ai_conversation_count, app_open_count,
                           avg_response_time_ms,
                           TIMESTAMPDIFF(MINUTE, first_active_time, last_active_time) as active_time_span
                    FROM student_daily_metrics
                    WHERE student_id = %s AND metric_date BETWEEN %s AND %s
                    ORDER BY metric_date
                """, (student_id, start_date, end_date))
                rows = cursor.fetchall()
                result = []
                for row in rows:
                    d = row.pop("metric_date")
                    metrics = {k: float(v) for k, v in row.items() if v is not None}
                    result.append((d, metrics))
                return result
        finally:
            conn.close()

    def get_active_students(self, target_date: date) -> List[int]:
        """获取目标日期活跃的学生ID列表"""
        conn = self.pool.connection()
        try:
            with conn.cursor() as cursor:
                cursor.execute("""
                    SELECT DISTINCT student_id
                    FROM student_daily_metrics
                    WHERE metric_date >= DATE_SUB(%s, INTERVAL 3 DAY)
                    AND metric_date <= %s
                """, (target_date, target_date))
                return [row[0] for row in cursor.fetchall()]
        finally:
            conn.close()

    def update_daily_metrics_incremental(
        self, student_id: int, metric_date: date, session_data: dict
    ) -> None:
        """增量更新当日指标"""
        conn = self.pool.connection()
        try:
            with conn.cursor() as cursor:
                # UPSERT
                cursor.execute("""
                    INSERT INTO student_daily_metrics
                        (student_id, metric_date, study_duration_total,
                         study_duration_effective, question_count, correct_count,
                         focus_score, session_count, avg_session_length)
                    VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s)
                    ON DUPLICATE KEY UPDATE
                        study_duration_total = study_duration_total + VALUES(study_duration_total),
                        study_duration_effective = study_duration_effective + VALUES(study_duration_effective),
                        question_count = question_count + VALUES(question_count),
                        correct_count = correct_count + VALUES(correct_count),
                        session_count = session_count + VALUES(session_count),
                        updated_at = NOW()
                """, (
                    student_id, metric_date,
                    session_data.get("duration", 0),
                    session_data.get("effective_duration", 0),
                    session_data.get("question_count", 0),
                    session_data.get("correct_count", 0),
                    session_data.get("focus_score", 0),
                    1,  # session_count +1
                    session_data.get("duration", 0),
                ))
            conn.commit()
        finally:
            conn.close()
```

## 7. 每日指标聚合任务

### 7.1 指标聚合SQL（定时任务核心逻辑）

每日凌晨执行，从前一天的各业务表聚合数据到 `student_daily_metrics` 表。

```sql
-- 每日指标聚合存储过程
DELIMITER //
CREATE PROCEDURE sp_aggregate_daily_metrics(IN target_date DATE)
BEGIN
    -- 1. 学习时长 & 会话数据（从 learning_session 表聚合）
    INSERT INTO student_daily_metrics
        (student_id, metric_date, study_duration_total, study_duration_effective,
         session_count, avg_session_length, focus_score, interruption_count,
         first_active_time, last_active_time, app_open_count)
    SELECT
        ls.student_id,
        target_date,
        SUM(ls.duration_total),
        SUM(ls.duration_effective),
        COUNT(*),
        AVG(ls.duration_total),
        AVG(ls.focus_score),
        SUM(ls.interruption_count),
        MIN(ls.start_time),
        MAX(ls.end_time),
        COUNT(DISTINCT ls.app_session_id)
    FROM learning_session ls
    WHERE DATE(ls.start_time) = target_date
    GROUP BY ls.student_id
    ON DUPLICATE KEY UPDATE
        study_duration_total = VALUES(study_duration_total),
        study_duration_effective = VALUES(study_duration_effective),
        session_count = VALUES(session_count),
        avg_session_length = VALUES(avg_session_length),
        focus_score = VALUES(focus_score),
        interruption_count = VALUES(interruption_count),
        first_active_time = VALUES(first_active_time),
        last_active_time = VALUES(last_active_time),
        app_open_count = VALUES(app_open_count);

    -- 2. 答题数据（从 answer_record 表聚合）
    UPDATE student_daily_metrics sdm
    INNER JOIN (
        SELECT
            student_id,
            COUNT(*) as q_count,
            SUM(CASE WHEN is_correct = 1 THEN 1 ELSE 0 END) as c_count,
            AVG(response_time_ms) as avg_rt
        FROM answer_record
        WHERE DATE(created_at) = target_date
        GROUP BY student_id
    ) ar ON sdm.student_id = ar.student_id AND sdm.metric_date = target_date
    SET
        sdm.question_count = ar.q_count,
        sdm.correct_count = ar.c_count,
        sdm.correct_rate = ar.c_count / NULLIF(ar.q_count, 0),
        sdm.avg_response_time_ms = ar.avg_rt;

    -- 3. 学科分布熵计算
    UPDATE student_daily_metrics sdm
    INNER JOIN (
        SELECT
            student_id,
            -SUM(p * LN(p)) as entropy,  -- 香农熵
            COUNT(DISTINCT subject_id) as subj_count
        FROM (
            SELECT
                ar.student_id,
                ar.subject_id,
                COUNT(*) * 1.0 / SUM(COUNT(*)) OVER(PARTITION BY ar.student_id) as p
            FROM answer_record ar
            WHERE DATE(ar.created_at) = target_date
            GROUP BY ar.student_id, ar.subject_id
        ) subj_dist
        GROUP BY student_id
    ) se ON sdm.student_id = se.student_id AND sdm.metric_date = target_date
    SET
        sdm.subject_entropy = se.entropy,
        sdm.subject_count = se.subj_count;

    -- 4. AI对话 & 拍题数据
    UPDATE student_daily_metrics sdm
    INNER JOIN (
        SELECT
            student_id,
            SUM(CASE WHEN type = 'AI_CHAT' THEN 1 ELSE 0 END) as ai_count,
            SUM(CASE WHEN type = 'PHOTO_SEARCH' THEN 1 ELSE 0 END) as photo_count
        FROM user_interaction_log
        WHERE DATE(created_at) = target_date
        GROUP BY student_id
    ) ui ON sdm.student_id = ui.student_id AND sdm.metric_date = target_date
    SET
        sdm.ai_conversation_count = COALESCE(ui.ai_count, 0),
        sdm.photo_search_count = COALESCE(ui.photo_count, 0);

    -- 5. 深夜学习占比（22:00-06:00）
    UPDATE student_daily_metrics sdm
    INNER JOIN (
        SELECT
            student_id,
            SUM(CASE WHEN TIME(start_time) >= '22:00:00' OR TIME(start_time) < '06:00:00'
                     THEN duration_total ELSE 0 END) * 1.0 /
            NULLIF(SUM(duration_total), 0) as late_ratio
        FROM learning_session
        WHERE DATE(start_time) = target_date
        GROUP BY student_id
    ) ls ON sdm.student_id = ls.student_id AND sdm.metric_date = target_date
    SET sdm.study_duration_peak_slot = CASE
        WHEN ls.late_ratio > 0.3 THEN 'LATE_NIGHT'
        ELSE sdm.study_duration_peak_slot
    END;
END //
DELIMITER ;
```

```python
class AnomalyStatusMachine:
    """异常记录状态机"""

    TRANSITIONS = {
        "PENDING":     {"ROUTED"},          # 只能流转到ROUTED
        "ROUTED":      {"ACTED", "IGNORED", "FALSE_POSITIVE"},
        "ACTED":       set(),                # 终态
        "IGNORED":     set(),                # 终态
        "FALSE_POSITIVE": set(),             # 终态
    }

    @classmethod
    def can_transition(cls, from_status: str, to_status: str) -> bool:
        return to_status in cls.TRANSITIONS.get(from_status, set())

    @classmethod
    def transition(cls, current: str, target: str) -> str:
        if not cls.can_transition(current, target):
            raise ValueError(
                f"非法状态流转: {current} → {target}"
            )
        return target


class AlertStatusMachine:
    """预警事件状态机"""

    TRANSITIONS = {
        "CREATED":   {"ROUTED", "SUPPRESSED"},
        "ROUTED":    {"DELIVERED", "SUPPRESSED"},
        "DELIVERED": {"RESOLVED"},
        "RESOLVED":  set(),
        "SUPPRESSED": set(),
    }

    @classmethod
    def can_transition(cls, from_status: str, to_status: str) -> bool:
        return to_status in cls.TRANSITIONS.get(from_status, set())
```

## 11. 错误处理与降级策略

### 11.1 错误分级

| 错误类型 | 处理策略 |
|---------|---------|
| 数据源不完整（某天数据缺失） | 跳过该天，降低confidence，不中断流程 |
| 基线计算失败（std=0等） | 记录日志，使用中位数替代，继续处理 |
| 异常检测异常 | 单维度失败不影响其他维度，记录error日志 |
| 预警投递失败 | 重试3次（指数退避），失败后降级为站内消息 |
| 批处理超时 | 已处理的结果保留，未处理的标记为待重试 |

## 12. 数据质量保障

### 12.1 数据完整度检测

```python
class DataQualityChecker:
    """检测指标数据完整度"""

    @staticmethod
    def compute_completeness(
        student_id: int, metric_date: date
    ) -> float:
        """
        计算当日数据完整度
        """
        expected_fields = [
            "study_duration_total", "correct_rate", "focus_score",
            "question_count", "session_count"
        ]
        actual_fields = []

        # 查询当日数据
        metrics = metric_repo.get_daily_metrics(student_id, metric_date)
        if not metrics:
            return 0.0

        for field in expected_fields:
            if field in metrics and metrics[field] is not None:
                actual_fields.append(field)

        return len(actual_fields) / len(expected_fields)

    @staticmethod
    def should_trust_anomaly(
        anomaly: AnomalyResult,
        data_completeness: float
    ) -> bool:
        """判断异常结果是否可信"""
        if data_completeness < 0.5:
            return False
        if anomaly.severity == "SEVERE" and data_completeness < 0.8:
            return False
        return True
```

```python
class ColdStartHandler:
```

```python
class PrivacyProtector:
    """预警推送隐私保护"""

    # 家长推送内容脱敏
    PUSH_DESENSITIZE_RULES = {
        # 不暴露具体分数，只说"下降"
        "ACCURACY_DROP": {
            "hide_exact_value": True,
            "use_qualitative": True,  # "有明显下降" 而非 "从78%降到52%"
        },
        # 不暴露具体排名/对比
        "COMPOSITE_DECLINE": {
            "no_comparison": True,  # 不说"低于同班同学"
        }
    }

    @staticmethod
    def sanitize_push_content(content: str, alert_type: str) -> str:
        """脱敏推送内容"""
        rules = PrivacyProtector.PUSH_DESENSITIZE_RULES.get(alert_type, {})
        if rules.get("use_qualitative"):
            # 替换具体数值为定性描述
            import re
            content = re.sub(r'\d+\.?\d*%', '有明显变化', content)
        return content
```

## 15. 附录

### 15.1 指标计算口径说明

| 指标 | 计算口径 | 数据来源 |
|------|---------|---------|
| study_duration_total | 当日所有学习会话 duration_total 之和 | learning_session |
| study_duration_effective | 当日有效学习时长（排除空闲>3min的段） | learning_session |
| correct_rate | correct_count / question_count | answer_record |
| focus_score | 基于会话内行为计算（停留时长、切屏次数等）综合评分 | learning_session + behavior_log |
| subject_entropy | -Σ(p_i * ln(p_i))，p_i为各学科答题占比 | answer_record |
| late_night_ratio | 22:00-06:00时段学习时长 / 总时长 | learning_session |

### 15.2 关键名词解释

- **个人基线（Personal Baseline）**：基于学生过去N天的行为数据建立的统计正常区间
- **Z-Score**：标准分数，表示观测值偏离均值多少个标准差
- **EWMA**：指数加权移动平均，对近期数据赋予更高权重
- **Isolation Forest**：基于树的隔离异常检测算法，适合多维度联合检测
- **变化点（Change Point）**：时间序列中统计特性发生显著变化的时间点
- **MAD**：中位数绝对偏差，稳健的离散度度量
