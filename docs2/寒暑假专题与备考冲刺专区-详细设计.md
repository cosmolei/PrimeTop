## 1. 模块概述

### 1.1 功能定位

寒暑假专题与备考冲刺专区是 PrimeTop 的**时间敏感型学习产品模块**，在特定时间窗口（寒暑假、考前冲刺期）为学生提供结构化的专题学习内容、阶段性任务规划和激励体系。与通用学习功能不同，本模块强调：

- **时间限定**：在固定窗口期内开放，营造紧迫感
- **结构化路径**：预设学习天数和每日任务，降低学生自主规划负担
- **主题聚焦**：围绕特定主题（如"暑假数学提升营"、"中考30天冲刺"）集中突破
- **社交竞争**：排行榜、打卡可见性、学习PK等社交激励
- **独立商品化**：部分营地可作为增值商品单独售卖

### 1.2 核心目标

| 目标 | 衡量指标 |
|------|----------|
| 提升假期活跃 | 寒暑假期间 DAU 不低于学期中的 60% |
| 促进付费转化 | 专题营带来会员转化率 ≥ 8% |
| 学习效果可量化 | 完成营地的用户薄弱点改善率 ≥ 40% |
| 运营效率 | 运营人员创建一个专题营 ≤ 30 分钟 |

### 1.3 目标用户

| 用户类型 | 场景 | 需求 |
|----------|------|------|
| 小学生 | 暑假/寒假学习营 | 保持学习习惯，巩固上学期，预习下学期 |
| 初中生 | 暑假营 + 中考冲刺 | 薄弱点突破，考点专项训练 |
| 高中生 | 暑假营 + 高考冲刺 | 专题突破，真题训练，答题策略 |
| 家长 | 选择营地 + 查看进度 | 了解孩子假期学习情况，监督完成度 |

## 2. 核心概念与数据模型

### 2.1 专题营地（Camp）

营地是本模块的核心实体，代表一个有时间限定、有结构化内容的学习活动。

```python
class Camp(BaseModel):
    """专题营地"""
    id: str                          # 营地ID，如 camp-2026-summer-math-junior
    name: str                        # 营地名称，如 "2026暑假 · 初中数学提分营"
    subtitle: str                    # 副标题
    description: str                 # 详细介绍
    cover_image: str                 # 封面图URL
    banner_images: list[str]         # 轮播图URL列表

    # 分类维度
    camp_type: CampType              # 营地类型
    subject: str                     # 学科 code
    grade_range: list[str]           # 适用年级，如 ["G7","G8","G9"]
    difficulty_level: int            # 整体难度 1-5

    # 时间
    enroll_start: datetime           # 报名开始时间
    enroll_end: datetime             # 报名截止时间
    study_start: datetime            # 学习开始时间
    study_end: datetime              # 学习结束时间

    # 学习结构
    total_days: int                  # 总学习天数
    daily_study_minutes: int         # 建议每日学习分钟数
    chapters: list[CampChapter]      # 章节列表（有序）

    # 参与设置
    max_participants: int | None     # 最大参与人数，None=不限
    access_type: CampAccessType      # 访问类型
    price_cents: int                 # 价格（分），0=免费
    member_discount: float           # 会员折扣，如 0.8

    # 激励
    badge_id: str | None             # 完成徽章ID
    points_reward: int               # 完成奖励积分
    certificate_enabled: bool        # 是否颁发电子证书

    # 状态
    status: CampStatus               # 营地状态
    created_by: str                  # 创建人
    created_at: datetime
    updated_at: datetime
    published_at: datetime | None

class CampType(str, Enum):
    """营地类型"""
    SUMMER = "summer"               # 暑假专题营
    WINTER = "winter"               # 寒假专题营
    EXAM_SPRINT = "exam_sprint"     # 考试冲刺营（中考/高考）
    SUBJECT_BOOST = "subject_boost" # 学科专项突破营
    TOPIC_INTENSIVE = "topic_intensive" # 主题集训营（如"函数专题"）

class CampAccessType(str, Enum):
    """营地访问类型"""
    FREE = "free"                   # 免费
    MEMBER_ONLY = "member_only"     # 仅会员
    PAID = "paid"                   # 付费购买
    MEMBER_OR_PAID = "member_or_paid" # 会员免费或付费购买

class CampStatus(str, Enum):
    """营地状态"""
    DRAFT = "draft"                 # 草稿
    REVIEWING = "reviewing"         # 审核中
    PUBLISHED = "published"         # 已发布
    ENROLLING = "enrolling"         # 报名中
    IN_PROGRESS = "in_progress"     # 进行中
    ENDED = "ended"                 # 已结束
    ARCHIVED = "archived"           # 已归档
```

### 2.2 营地章节与每日任务

```python
class CampChapter(BaseModel):
    """营地章节 - 一周或一个主题阶段"""
    id: str
    camp_id: str
    title: str                      # 如 "第一周：函数基础"
    description: str
    order: int                      # 排序
    unlock_rule: ChapterUnlockRule  # 解锁规则
    days: list[CampDay]             # 该章节下的每日任务

class ChapterUnlockRule(BaseModel):
    """章节解锁规则"""
    rule_type: str                  # "date" | "sequential" | "complete_previous"
    unlock_date: date | None        # 按日期解锁
    require_previous_complete: bool # 需要完成前一章节

class CampDay(BaseModel):
    """营地每日任务"""
    id: str
    chapter_id: str
    camp_id: str
    day_number: int                 # 第几天（全局递增）
    title: str                      # 如 "Day 3：一次函数的图像与性质"
    description: str

    # 学习内容
    knowledge_point_ids: list[str]  # 涉及的知识点
    tasks: list[CampTask]           # 当日任务列表

    # 时间
    estimated_minutes: int          # 预计用时

class CampTaskType(str, Enum):
    """营地任务类型"""
    KNOWLEDGE_REVIEW = "knowledge_review"   # 知识点复习（AI讲解）
    VIDEO_LESSON = "video_lesson"           # 视频课程
    PRACTICE = "practice"                   # 练习题
    QUIZ = "quiz"                           # 小测验
    MISTAKE_REVIEW = "mistake_review"       # 错题复习
    ORAL_PRACTICE = "oral_practice"         # 口语/背诵练习
    ESSAY_WRITING = "essay_writing"         # 作文练习

class CampTask(BaseModel):
    """营地任务"""
    id: str
    day_id: str
    task_type: CampTaskType
    title: str                      # "一次函数练习"
    order: int

    # 任务内容配置（按 task_type 不同取不同字段）
    config: CampTaskConfig          # 任务配置（多态）

    # 完成条件
    completion_criteria: TaskCompletionCriteria

class TaskCompletionCriteria(BaseModel):
    """任务完成条件"""
    criteria_type: str              # "all_done" | "accuracy" | "time_spent"
    min_accuracy: float | None      # 最低正确率，如 0.6
    min_count: int | None           # 最少完成题数
    min_time_seconds: int | None    # 最少学习时长
```

### 2.3 用户营地参与

```python
class CampEnrollment(BaseModel):
    """用户营地报名"""
    id: str
    user_id: str
    camp_id: str
    enrolled_at: datetime
    enrolled_via: str               # 报名渠道：home_page | push | share_link | recommendation
    payment_order_id: str | None    # 付费营地的订单ID
    status: EnrollmentStatus

    # 进度
    current_day: int                # 当前所在天
    completed_days: list[int]       # 已完成的天数列表
    total_tasks: int                # 总任务数
    completed_tasks: int            # 已完成任务数
    total_study_minutes: float      # 累计学习时长

    # 诊断
    pre_test_score: float | None    # 入营测试分数
    post_test_score: float | None   # 结营测试分数

    # 社交
    invited_friends: int            # 邀请好友数

    created_at: datetime
    updated_at: datetime

class EnrollmentStatus(str, Enum):
    ENROLLED = "enrolled"           # 已报名
    IN_PROGRESS = "in_progress"     # 学习中
    COMPLETED = "completed"         # 已完成（结营）
    DROPPED = "dropped"             # 已退出
    EXPIRED = "expired"             # 已过期（未在规定时间内完成）
```

```sql
    INDEX idx_study_time (study_start, study_end),
```

## 4. 核心业务流程

### 4.1 营地状态流转

```
         ┌──────────────────────────────────────────────────────┐
         │                                                      │
  [草稿] ──→ [审核中] ──→ [已发布] ──→ [报名中] ──→ [进行中] ──→ [已结束] ──→ [已归档]
  DRAFT    REVIEWING  PUBLISHED  ENROLLING  IN_PROGRESS  ENDED    ARCHIVED
                      │                                      │
                      │         ← 返回修改 ←                   │
                      └────── [草稿] ←────────────────────────┘
```

**状态转换规则：**

| 当前状态 | 触发条件 | 目标状态 | 执行动作 |
|----------|----------|----------|----------|
| DRAFT | 运营提交审核 | REVIEWING | 校验营地内容完整性 |
| REVIEWING | 审核通过 | PUBLISHED | 设置 published_at |
| REVIEWING | 审核拒绝 | DRAFT | 记录拒绝原因 |
| PUBLISHED | 到达 enroll_start | ENROLLING | 开放报名入口 |
| ENROLLING | 到达 study_start | IN_PROGRESS | 生成排行榜，推送开营通知 |
| IN_PROGRESS | 到达 study_end | ENDED | 计算最终成绩，发放奖励 |
| ENDED | 运营操作 | ARCHIVED | 归档数据 |

**定时任务调度：**

```python
# celery 定时任务：检查营地状态转换
@app.task(name="camp.check_status_transitions")
def check_camp_status_transitions():
    """每5分钟检查一次营地状态"""
    now = datetime.utcnow()

    # PUBLISHED → ENROLLING
    camps = Camp.query.filter(
        Camp.status == 'published',
        Camp.enroll_start <= now
    ).all()
    for camp in camps:
        camp.status = 'enrolled'
        # 推送开报通知给目标用户
        notify_target_users.delay(camp.id, 'enroll_start')

    # ENROLLING → IN_PROGRESS
    camps = Camp.query.filter(
        Camp.status == 'enrolling',
        Camp.study_start <= now
    ).all()
    for camp in camps:
        camp.status = 'in_progress'
        # 为已报名用户发送开营通知
        notify_enrolled_users.delay(camp.id, 'camp_start')
        # 初始化排行榜
        init_leaderboard.delay(camp.id)

    # IN_PROGRESS → ENDED
    camps = Camp.query.filter(
        Camp.status == 'in_progress',
        Camp.study_end <= now
    ).all()
    for camp in camps:
        finalize_camp.delay(camp.id)
```

```python
class TaskCompletionHandler:
    """任务完成处理器（策略模式）"""

    handlers: dict[str, Callable] = {}

    @classmethod
    def register(cls, task_type: str):
        def decorator(fn):
            cls.handlers[task_type] = fn
            return fn
        return decorator

    @classmethod
    async def complete(cls, task: CampTask, enrollment: CampEnrollment,
                       submission: dict) -> CampTaskRecord:
        handler = cls.handlers.get(task.task_type)
        if not handler:
            raise ValueError(f"Unknown task type: {task.task_type}")
        return await handler(task, enrollment, submission)


@TaskCompletionHandler.register("practice")
async def complete_practice(task: CampTask, enrollment: CampEnrollment,
                            submission: dict) -> CampTaskRecord:
    """完成练习题"""
    config = PracticeConfig(**task.config)
    answers = submission.get("answers", {})
    time_spent = submission.get("time_spent_seconds", 0)

    # 获取题目正确答案
    questions = await get_questions_for_task(task.id)
    correct_count = sum(1 for q in questions if answers.get(q.id) == q.correct_answer)
    accuracy = correct_count / len(questions) if questions else 0

    # 识别错题
    wrong_ids = [q.id for q in questions if answers.get(q.id) != q.correct_answer]

    # 自动收录到错题本
    if wrong_ids:
        await add_to_mistake_book(enrollment.user_id, wrong_ids, source="camp")

    # 判断是否完成
    criteria = TaskCompletionCriteria(**task.completion_criteria)
    is_completed = evaluate_completion(criteria, {
        "accuracy": accuracy,
        "count": correct_count,
        "time_spent": time_spent
    })

    record = CampTaskRecord(
        id=generate_id(),
        enrollment_id=enrollment.id,
        task_id=task.id,
        day_id=task.day_id,
        user_id=enrollment.user_id,
        status="completed" if is_completed else "in_progress",
        time_spent_seconds=time_spent,
        accuracy=accuracy,
        total_questions=len(questions),
        correct_questions=correct_count,
        wrong_question_ids=wrong_ids,
    )

    if is_completed:
        await update_enrollment_progress(enrollment, task, record)

    return record


@TaskCompletionHandler.register("quiz")
async def complete_quiz(task: CampTask, enrollment: CampEnrollment,
                        submission: dict) -> CampTaskRecord:
    """完成小测验"""
    # 类似 practice，但额外计算测验分，记录到营地进度
    record = await complete_practice(task, enrollment, submission)

    # 更新排行榜
    if record.status == "completed":
        await update_leaderboard(enrollment.camp_id, enrollment.user_id, record)

    return record


@TaskCompletionHandler.register("knowledge_review")
async def complete_knowledge_review(task: CampTask, enrollment: CampEnrollment,

    """完成知识点复习"""
    time_spent = submission.get("time_spent_seconds", 0)

        task_id=task.id,
        day_id=task.day_id,
        user_id=enrollment.user_id,
        status="completed" if is_completed else "in_progress",
```

### 4.4 排行榜计算引擎

```python
class CampLeaderboardEngine:
    """营地排行榜引擎"""

    def __init__(self, redis: Redis, db: Session):
        self.redis = redis
        self.db = db

    def _score_key(self, camp_id: str, period: str, period_key: str) -> str:
        return f"camp:leaderboard:{camp_id}:{period}:{period_key}"

    async def update_score(self, camp_id: str, user_id: str,
                           task_record: CampTaskRecord):
        """更新用户在排行榜中的得分"""
        # 综合得分 = 任务完成加权 + 正确率加权 + 时间加权
        score = self._calculate_composite_score(task_record)

        # 更新总榜
        key = self._score_key(camp_id, "total", "total")
        await self.redis.zadd(key, {user_id: score})

        # 更新周榜
        week_num = (task_record.completed_at.day - 1) // 7 + 1
        week_key = self._score_key(camp_id, "weekly", f"W{week_num}")
        await self.redis.zadd(week_key, {user_id: score})

        # 更新日榜
        day_key = self._score_key(camp_id, "daily",
                                   task_record.completed_at.strftime("%Y-%m-%d"))
        await self.redis.zadd(day_key, {user_id: score})

    async def get_ranking(self, camp_id: str, period: str,
                          period_key: str, page: int = 1,
                          page_size: int = 20) -> dict:
        """获取排行榜"""
        key = self._score_key(camp_id, period, period_key)

        # 取前N名
        start = (page - 1) * page_size
        end = start + page_size - 1
        top_raw = await self.redis.zrevrange(key, start, end, withscores=True)

        # 批量获取用户信息
        user_ids = [uid.decode() for uid, _ in top_raw]
        users = await batch_get_users(user_ids)

        result = []
        for rank, (uid, score) in enumerate(top_raw, start + 1):
            user = users.get(uid.decode(), {})
            result.append({
                "rank": rank,
                "user_id": uid.decode(),
                "nickname": user.get("nickname", ""),
                "avatar": user.get("avatar", ""),
                "score": round(score, 2),
            })

        return {"items": result, "total": await self.redis.zcard(key)}

    def _calculate_composite_score(self, record: CampTaskRecord) -> float:
        """
        综合得分计算：
        score = 任务完成分(40%) + 正确率分(35%) + 效率分(25%)

        - 任务完成分：每完成一个任务得 10 分
        - 正确率分：accuracy * 100
        - 效率分：max(0, 100 - 超时分钟 * 5)
        """
        completion_score = 10  # 完成单个任务基础分
        accuracy_score = (record.accuracy or 0) * 100
        # 鼓励高效学习，不超过建议时间的 1.5 倍得满分
        efficiency = max(0, 100 - max(0, (record.time_spent_seconds / 60 - 15)) * 5)

        return completion_score * 0.4 + accuracy_score * 0.35 + efficiency * 0.25

    async def persist_leaderboard(self, camp_id: str):
        """定期持久化排行榜到 MySQL（营地结束时调用）"""
        key = self._score_key(camp_id, "total", "total")
        all_entries = await self.redis.zrevrange(key, 0, -1, withscores=True)

        for rank, (uid, score) in enumerate(all_entries, 1):
            uid = uid.decode()
            await self.db.execute(
                insert(CampLeaderboard).values(
                    id=generate_id(),
                    camp_id=camp_id,
                    period_type="total",
                    period_key="total",
                    user_id=uid,
                    score=score,
                    rank_position=rank,
                ).on_duplicate_key_update(score=score, rank_position=rank)
            )
```

```python
    async def generate_pre_test(self, camp: Camp, user_id: str) -> dict:

                count=4
            )
            questions.extend(q)

        return {
            "test_id": generate_id(),
            "camp_id": camp.id,
            "questions": questions,
            "time_limit_minutes": 15,
            "total_questions": len(questions)
        }

    async def evaluate_improvement(self, camp_id: str,
                                    enrollment_id: str) -> dict:
        """评估学习进步幅度"""
        enrollment = await get_enrollment(enrollment_id)

        # 入营前测试分数
        pre_score = enrollment.pre_test_score or 0

        # 根据营地内所有练习数据估算当前水平
        task_records = await get_camp_task_records(enrollment_id)
        practice_records = [r for r in task_records
                           if r.task_type in ("practice", "quiz") and r.accuracy]

        if not practice_records:
            return {"improvement": 0, "status": "insufficient_data"}

        # 加权平均：越近期的练习权重越高
        weighted_score = self._weighted_average(practice_records)
        improvement = weighted_score - pre_score

        return {
            "pre_test_score": pre_score,
            "current_estimated_score": round(weighted_score, 1),
            "improvement": round(improvement, 1),
            "status": "positive" if improvement > 0 else "needs_review",
            "weak_areas": await self._identify_weak_areas(practice_records)
        }

    def _weighted_average(self, records: list) -> float:
        """时间衰减加权平均"""
        if not records:
            return 0
        now = datetime.utcnow()
        weights = []
        scores = []
        for r in sorted(records, key=lambda x: x.completed_at):
            days_ago = (now - r.completed_at).days
            weight = max(0.1, 1 - days_ago * 0.03)  # 每天衰减3%
            weights.append(weight)
            scores.append(r.accuracy * 100)
        total_weight = sum(weights)
        return sum(w * s for w, s in zip(weights, scores)) / total_weight
```

```python
async def finalize_camp(camp_id: str):
    """营地结束处理"""
    camp = await get_camp(camp_id)

    # 1. 计算所有参与者的最终成绩
    enrollments = await get_active_enrollments(camp_id)
    for enrollment in enrollments:
        improvement = await assessment_service.evaluate_improvement(camp_id, enrollment.id)
        enrollment.post_test_score = improvement["current_estimated_score"]
        enrollment.status = 'completed' if is_camp_completed(enrollment, camp) else 'expired'

    # 3. 发放奖励
    for enrollment in enrollments:
        if enrollment.status == 'completed':
            await grant_camp_rewards(enrollment, camp)
            # 发送完成通知
            await send_camp_notification(
                enrollment.user_id, camp_id, 'camp_completed',

        else:

            await send_camp_notification(
                enrollment.user_id, camp_id, 'camp_ended',
                {"completed_days": len(enrollment.completed_days),
                 "total_days": camp.total_days}
            )

    # 4. 通知家长
    await notify_parents_camp_ended(camp_id, enrollments)

    # 5. 更新营地状态
    camp.status = 'ended'
```
