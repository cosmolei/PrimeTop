## 1. 模块概述

### 1.1 模块定位

学习打卡记录与成就解锁计算引擎是 PrimeTop 成长激励体系的核心后端服务，负责：

1. **打卡记录管理**：记录用户每日学习打卡行为（学习时长、完成任务、连续打卡等）
2. **连续打卡计算**：实时计算用户连续打卡天数、最长连续记录
3. **成就条件评估**：基于用户行为数据，评估是否满足成就解锁条件
4. **奖励发放**：解锁成就时自动发放对应奖励（积分、勋章、虚拟道具）
5. **数据查询 API**：为客户端提供打卡日历、成就墙、奖励记录等数据接口

### 1.2 模块边界

| 包含 | 不包含 |
|------|--------|
| 打卡行为记录与校验 | 打卡页面 UI 渲染（客户端） |
| 连续打卡天数计算 | 积分获取规则引擎（积分模块） |
| 成就条件定义与评估 | 运营活动配置管理（运营模块） |
| 勋章/奖励发放与记录 | 推送通知发送（消息模块） |
| 打卡/成就数据查询 API | 学习时长统计（学习统计模块） |

```sql
    id                  BIGSERIAL PRIMARY KEY,
    achievement_code    VARCHAR(64) NOT NULL UNIQUE,     -- 成就编码（唯一标识）
    name                VARCHAR(128) NOT NULL,            -- 成就名称
    description         TEXT NOT NULL,                    -- 成就描述
    category            VARCHAR(32) NOT NULL,             -- 分类: study=学习, streak=打卡, subject=学科, social=社交, special=特殊
    icon_url            VARCHAR(512),                     -- 勋章图标URL

    applicable_phases   VARCHAR(64)[],                    -- 适用学段: {kindergarten, primary, junior, senior}
    sort_order          INTEGER NOT NULL DEFAULT 0,       -- 排序权重
    is_active           BOOLEAN NOT NULL DEFAULT TRUE,    -- 是否启用
    effective_from      TIMESTAMPTZ,                      -- 生效时间
    effective_until     TIMESTAMPTZ,                      -- 失效时间
    tenant_id           BIGINT,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_achieve_def_category ON achievement_definitions(category, is_active);
CREATE INDEX idx_achieve_def_code ON achievement_definitions(achievement_code);
```

**`condition_config` JSON 结构定义**：

```typescript
// 阈值类型 (threshold)
interface ThresholdCondition {
    metric: string;          // 指标名: study_duration, questions_answered, accuracy_rate 等
    operator: '>=' | '>' | '==' | '<=' | '<';
    value: number;           // 阈值
    timeframe?: 'daily' | 'weekly' | 'monthly' | 'total'; // 时间窗口
}

// 累计类型 (cumulative)
interface CumulativeCondition {
    metric: string;          // 指标名
    target: number;          // 累计目标值
    since?: string;          // 起算时间（可选）
}

// 连续类型 (streak)
interface StreakCondition {
    metric: string;          // 连续指标: check_in, daily_study, task_complete
    min_days: number;        // 最少连续天数
}

// 一次性类型 (one_time)
interface OneTimeCondition {
    event: string;           // 事件名: first_login, first_photo_question, first_essay 等
}

// 复合类型 (composite) - 所有子条件需同时满足
interface CompositeCondition {
    operator: 'AND' | 'OR';
    conditions: Array<ThresholdCondition | CumulativeCondition | StreakCondition | OneTimeCondition>;
}
```

### 2.2 Redis 缓存结构

| Key 模式 | 类型 | TTL | 说明 |
|----------|------|-----|------|
| `checkin:streak:{userId}` | Hash | 48h | 当前连续打卡天数、最后打卡日期 |
| `checkin:daily:{userId}:{date}` | String | 72h | 当日是否已打卡标记 |
| `checkin:leaderboard:{phase}:{period}` | ZSet | 24h | 打卡排行榜（按学段+周期） |
| `achievement:progress:{userId}:{code}` | Hash | 1h | 成就进度缓存 |
| `achievement:recent:{userId}` | List | 24h | 最近解锁成就列表（最多20条） |
| `reward:pending:{userId}` | List | 24h | 待领取奖励列表 |

## 3. API 接口设计

### 3.1 打卡相关接口

#### 3.1.1 POST `/api/v1/check-in/record` — 提交打卡

学习达标或用户手动触发打卡。

**请求**：
```json
{
    "triggerSource": "study",
    "studyDuration": 1800,
    "tasksCompleted": 3,
    "timezone": "Asia/Shanghai"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| triggerSource | string | 是 | 触发来源: `study` / `task` / `manual` |
| studyDuration | int | 否 | 学习时长（秒） |
| tasksCompleted | int | 否 | 完成任务数 |
| timezone | string | 否 | 用户时区，默认 Asia/Shanghai |

**响应** `200 OK`：
```json
{
    "code": 0,
    "data": {
        "checkInId": 12345678,
        "checkInDate": "2026-06-07",
        "currentStreak": 16,
        "maxStreak": 23,
        "totalCheckIns": 89,
        "isNewStreakRecord": false,
        "unlockedAchievements": [
            {
                "achievementCode": "streak_15",
                "name": "坚持不懈·十五日",
                "tier": 2,
                "rarity": 2,
                "iconUrl": "https://cdn.primetop.app/badge/streak_15.png"
            }
        ],
        "dailyBonus": {
            "pointsEarned": 10,
            "multiplier": 1.0
        }
    }
}
```

**响应** `200 OK`（已打卡 — 幂等返回）：
```json
{
    "code": 10001,
    "message": "今日已完成打卡",
    "data": {
        "checkInDate": "2026-06-07",
        "currentStreak": 16
    }
}
```

**业务逻辑**：
1. 根据 `timezone` 计算用户本地日期
2. 查询当日是否已打卡（幂等）
3. 判断是否为连续打卡（`last_check_in_date == yesterday`）
4. 更新/创建打卡记录
5. 更新 `check_in_stats` 表
6. 更新 Redis 连续天数缓存
7. 触发成就评估（异步）
8. 检查连续打卡里程碑（异步）
9. 返回结果

### 4.2 连续打卡天数计算算法

```java
/**
 * 计算并更新连续打卡天数
 * 关键点：考虑时区、跨日边界、补签影响
 */
public StreakResult calculateStreak(Long userId, String timezone) {
    LocalDate today = LocalDate.now(ZoneId.of(timezone));
    LocalDate yesterday = today.minusDays(1);
    
    // 从缓存获取上次打卡信息
    CheckInStreakCache cache = getStreakCache(userId);
    
    if (cache != null && cache.getLastDate().equals(yesterday)) {
        // 连续打卡
        int newStreak = cache.getCurrentStreak() + 1;
        int maxStreak = Math.max(newStreak, cache.getMaxStreak());
        return new StreakResult(newStreak, maxStreak, false);
    } else if (cache != null && cache.getLastDate().equals(today)) {
        // 今日已打卡（幂等）
        return new StreakResult(cache.getCurrentStreak(), cache.getMaxStreak(), false);
    } else {
        // 不连续，重新计数
        int maxStreak = cache != null ? cache.getMaxStreak() : 0;
        return new StreakResult(1, maxStreak, false);
    }
}

/**
 * 补签后重算连续天数
 * 补签填补某天后，需要从该天开始往后扫描连续天数
 */
public StreakResult recalculateStreakAfterMakeUp(Long userId, LocalDate makeUpDate) {
    // 从补签日期开始，向后扫描连续的打卡记录
    int streak = 0;
    LocalDate date = makeUpDate;
    
    while (true) {
        if (existsCheckInRecord(userId, date)) {
            streak++;
            date = date.plusDays(1);
        } else {
            break;
        }
    }
    
    return new StreakResult(streak, getMaxStreak(userId), false);
}
```

```java
@Component
public class StreakAchievementEvaluator implements AchievementEvaluator {
    
    @Override
    public String getConditionType() {
        return "streak";
    }
    
    @Override
    public EvaluationResult evaluate(Long userId, ConditionConfig condition,
                                     UserAchievement userAchievement) {
        StreakCondition config = (StreakCondition) condition;
        
        // 从缓存获取当前连续天数
        int currentStreak = getStreakFromCache(userId);
        
        EvaluationResult result = new EvaluationResult();
        result.setCurrentValue(BigDecimal.valueOf(currentStreak));
        result.setTargetValue(BigDecimal.valueOf(config.getMinDays()));
        result.setProgress(Math.min(100.0, 
            (currentStreak * 100.0) / config.getMinDays()));
        result.setSatisfied(currentStreak >= config.getMinDays());
        
        return result;
    }
}
```

#### 4.3.4 成就评估调度器

```java
@Service
public class AchievementEvaluationService {
    
    @Autowired
    private Map<String, AchievementEvaluator> evaluatorMap;
    @Autowired
    private AchievementDefinitionRepository definitionRepo;
    @Autowired
    private UserAchievementRepository userAchievementRepo;
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    /**
     * 触发成就评估
     * 在用户行为事件发生时异步调用
     */
    @Async("achievementExecutor")
    @Transactional
    public void evaluateAchievements(Long userId, String eventCategory) {
        // 1. 查询与事件类别相关的活跃成就定义
        List<AchievementDefinition> definitions = definitionRepo
            .findActiveByCategory(eventCategory);
        
        for (AchievementDefinition def : definitions) {
            // 2. 跳过不适用的学段
            if (!isApplicablePhase(def, userId)) continue;
            
            // 3. 获取评估器
            AchievementEvaluator evaluator = evaluatorMap.get(def.getConditionType());
            if (evaluator == null) continue;
            
            // 4. 获取用户当前成就记录
            UserAchievement ua = userAchievementRepo
                .findByUserIdAndAchievementId(userId, def.getId())
                .orElseGet(() -> createUserAchievement(userId, def));
            
            if (ua.getStatus() == AchievementStatus.UNLOCKED && !def.isRepeatable()) {
                continue; // 已解锁且不可重复
            }
            
            // 5. 执行评估
            EvaluationResult result = evaluator.evaluate(
                userId, def.getConditionConfig(), ua);
            
            // 6. 更新进度
            ua.setProgress(result.getProgress());
            ua.setCurrentValue(result.getCurrentValue());
            ua.setTargetValue(result.getTargetValue());
            
            if (result.isSatisfied() && ua.getStatus() != AchievementStatus.UNLOCKED) {
                // 7. 解锁成就
                unlockAchievement(ua, def);
            }
            
            userAchievementRepo.save(ua);
        }
    }
    
    private void unlockAchievement(UserAchievement ua, AchievementDefinition def) {
        ua.setStatus(AchievementStatus.UNLOCKED);
        ua.setUnlockedAt(Instant.now());
        
        // 发布成就解锁事件 → 触发奖励发放 + 通知
        eventPublisher.publishEvent(new AchievementUnlockedEvent(
            ua.getUserId(), def.getAchievementCode(), def.getId(),
            parseRewards(def.getRewardConfig())
        ));
        
        // 更新 Redis 最近成就列表
        redisTemplate.opsForList().leftPush(
            "achievement:recent:" + ua.getUserId(),
            def.getAchievementCode()
        );
        redisTemplate.opsForList().trim(
            "achievement:recent:" + ua.getUserId(), 0, 19
        );
    }
}
```

### 4.4 奖励发放流程

```java
@Service
public class RewardIssuingService {
    
    @EventListener
    @Async("rewardExecutor")
    @Transactional
    public void handleAchievementUnlocked(AchievementUnlockedEvent event) {
        List<RewardRecord> records = new ArrayList<>();
        
        for (RewardItem item : event.getRewards()) {
            RewardRecord record = new RewardRecord();
            record.setUserId(event.getUserId());
            record.setSourceType("achievement");
            record.setSourceId(event.getAchievementId());
            record.setRewardType(item.getType());
            record.setRewardCode(item.getCode());
            record.setRewardAmount(item.getAmount());
            record.setStatus(RewardStatus.PENDING);
            records.add(record);
        }
        
        rewardRecordRepo.saveAll(records);
        
        // 添加到 Redis 待领取列表
        for (RewardRecord r : records) {
            redisTemplate.opsForList().rightPush(
                "reward:pending:" + event.getUserId(), 
                String.valueOf(r.getId())
            );
        }
    }
    
    @Transactional
    public BatchClaimResult batchClaim(Long userId, List<Long> rewardIds) {
        List<RewardRecord> records = rewardRecordRepo
            .findAllById(rewardIds).stream()
            .filter(r -> r.getUserId().equals(userId))
            .filter(r -> r.getStatus() == RewardStatus.PENDING)
            .collect(Collectors.toList());
        
        int totalPoints = 0;
        List<String> badges = new ArrayList<>();
        List<Long> failedIds = new ArrayList<>();
        
        for (RewardRecord r : records) {
            try {
                switch (r.getRewardType()) {
                    case "points":
                        pointsService.addPoints(userId, r.getRewardAmount().intValue(),
                            "ACHIEVEMENT_REWARD", r.getSourceType() + ":" + r.getSourceId());
                        totalPoints += r.getRewardAmount().intValue();
                        break;
                    case "badge":
                        badgeService.grantBadge(userId, r.getRewardCode());
                        badges.add(r.getRewardCode());
                        break;
                    case "title":
                        titleService.grantTitle(userId, r.getRewardCode());
                        break;
                }
                r.setStatus(RewardStatus.ISSUED);
                r.setIssuedAt(Instant.now());
            } catch (Exception e) {
                r.setStatus(RewardStatus.FAILED);
                failedIds.add(r.getId());
                log.error("奖励发放失败: userId={}, rewardId={}", userId, r.getId(), e);
            }
        }
        
        rewardRecordRepo.saveAll(records);
        
        // 清理 Redis 待领取列表
        redisTemplate.delete("reward:pending:" + userId);
        
        return new BatchClaimResult(records.size() - failedIds.size(), 
            totalPoints, badges, failedIds);
    }
}
```

```java
/**
 * 检测并标记昨日未打卡的用户的连续天数中断
 * 处理时区差异：按用户设置时区判断
 */
@Scheduled(cron = "0 5 2 * * ?")
public void detectStreakBreak() {
    // 分批查询所有有打卡记录的用户
    int offset = 0;
    int batchSize = 500;
    
    while (true) {
        List<CheckInStats> stats = checkInStatsRepo
            .findActiveUsers(offset, batchSize);
        if (stats.isEmpty()) break;
        
        for (CheckInStats stat : stats) {
            // 获取用户时区
            String tz = userService.getUserTimezone(stat.getUserId());
            LocalDate yesterday = LocalDate.now(ZoneId.of(tz)).minusDays(1);
            
            // 如果最后打卡日不是昨天，重置连续天数
            if (stat.getLastCheckInDate() != null 
                && stat.getLastCheckInDate().isBefore(yesterday)) {
                stat.setCurrentStreak(0);
                stat.setLastStreakReset(yesterday);
                checkInStatsRepo.save(stat);
                
                // 清除缓存
                redisTemplate.delete("checkin:streak:" + stat.getUserId());
            }
        }
        
        offset += batchSize;
    }
}
```

| 消息推送不可用 | 仅记录，不阻塞主流程 |
| 成就评估超时 | 异步重试，不影响打卡结果返回 |

## 8. 并发与一致性

### 8.1 打卡幂等性

打卡接口必须幂等，同一天同一用户只能打卡一次：

- **数据库层**：`UNIQUE (user_id, check_in_date)` 唯一约束
- **应用层**：打卡前先查 Redis 快速判断，再写数据库
- **乐观锁**：`check_in_stats` 表使用 `version` 字段防并发更新

```java
@Transactional
public CheckInResult doCheckIn(Long userId, CheckInRequest request) {
    LocalDate today = resolveDate(request.getTimezone());
    String dailyKey = "checkin:daily:" + userId + ":" + today;
    
    // 快速幂等检查（Redis）
    Boolean isNew = redisTemplate.opsForValue().setIfAbsent(
        dailyKey, "1", Duration.ofHours(72));
    if (Boolean.FALSE.equals(isNew)) {
        return CheckInResult.alreadyCheckedIn(today);
    }
    
    try {
        // 写入打卡记录（依赖数据库唯一约束兜底）
        CheckInRecord record = buildRecord(userId, today, request);
        checkInRecordRepo.save(record);
        
        // 更新统计（乐观锁）
        updateStatsWithOptimisticLock(userId, today);
        
        return CheckInResult.success(record);
    } catch (DataIntegrityViolationException e) {
        // 唯一约束冲突 → 幂等
        return CheckInResult.alreadyCheckedIn(today);
    }
}
```

### 8.2 成就解锁防重复

成就解锁使用数据库唯一约束 + 分布式锁双重保护：

```java
public boolean tryUnlock(Long userId, Long achievementId) {
    String lockKey = "achievement:unlock:" + userId + ":" + achievementId;
    
    return redisTemplate.execute(new RedisCallback<Boolean>() {
        @Override
        public Boolean doInRedis(RedisConnection conn) {
            // SETNX 获取锁
            boolean acquired = conn.setNX(
                lockKey.getBytes(), "1".getBytes());
            if (!acquired) return false;
            
            // 设置过期时间防死锁
            conn.expire(lockKey.getBytes(), 30);
            
            try {
                // 数据库唯一约束兜底
                int updated = userAchievementRepo.updateStatusToUnlocked(
                    userId, achievementId, AchievementStatus.IN_PROGRESS);
                return updated > 0;
            } finally {
                conn.del(lockKey.getBytes());
            }
        }
    });
}
```

## 9. 性能考量

### 9.1 热点数据缓存策略

| 数据 | 缓存策略 | 更新方式 |
|------|---------|---------|
| 连续打卡天数 | Redis Hash, 48h TTL | 打卡时主动更新 |
| 当日打卡标记 | Redis String, 72h TTL | 打卡时 SETNX |
| 成就进度 | Redis Hash, 1h TTL | 定时任务刷新 + 事件触发更新 |
| 最近解锁成就 | Redis List, 24h TTL | 解锁时 LPUSH |
| 排行榜 | Redis ZSet, 24h TTL | 打卡时 ZINCRBY |
