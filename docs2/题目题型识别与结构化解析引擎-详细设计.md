## 1. 模块概述

### 1.1 功能定位

题目题型识别与结构化解析引擎是拍照搜题、AI辅导、题库管理等多个上游模块的**核心中间件**。它将原始题目文本（OCR 输出或手动输入）转化为结构化的题目对象，自动识别题型、提取关键组成部分（题干、选项、公式、图形引用、条件、问题），并映射到对应的解题策略模板。

**一句话定位：** 把一段"毛坯题目文本"变成"机器可理解、AI可解题的结构化题目对象"。

### 1.2 在系统中的位置

```
┌─────────────┐     原始文本/图片     ┌──────────────────────────┐     结构化题目      ┌──────────────────┐
│  图片OCR管线  │ ─────────────────→  │                          │ ────────────────→  │  AI解题引擎       │
│  用户手动输入  │                     │  题目题型识别与结构化解析  │                    │  题库服务         │
│  题库批量导入  │                     │  引擎（本模块）            │                    │  同类题推荐       │
│  AI对话提取   │                     │                          │                    │  错题归因         │
└─────────────┘                      └──────────────────────────┘                    └──────────────────┘
```

### 1.3 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 题型自动分类 | 识别选择题、填空题、解答题、证明题等 15+ 种题型 | P0 |
| 题干提取 | 分离题干、选项、条件、问题 | P0 |
| 公式检测与 LaTeX 转换 | 识别行内/行间公式，转换为 LaTeX | P0 |
| 图形/表格引用检测 | 标记题目中引用的图形、表格、电路图等 | P1 |
| 多题分割 | 一张图片中识别多道题并逐一分割 | P0 |
| 学科自动识别 | 根据题目内容判断所属学科 | P1 |
| 解题策略路由 | 根据题型+学科映射到对应 Prompt 模板 | P0 |
| 置信度评估 | 输出每个字段的识别置信度 | P1 |

### 1.4 目标指标

| 指标 | 目标值 |
|------|--------|
| 题型分类准确率 | ≥ 95% |
| 题干提取完整率 | ≥ 92% |
| 公式识别准确率 | ≥ 90%（印刷体）/ ≥ 80%（手写体） |
| 单题解析耗时 | ≤ 500ms（不含 LLM 调用）/ ≤ 3s（含 LLM 调用） |
| 多题分割准确率 | ≥ 90% |

### 2.2 题型分类规则

题型分类采用**规则引擎 + LLM 辅助**的混合策略：

```
                    输入原始题目文本
                          │
                    ┌─────▼──────┐
                    │  规则预分类  │  ← 正则匹配 + 关键词检测
                    └─────┬──────┘
                          │
               ┌──────────┼──────────┐
               │          │          │
         置信度 ≥ 0.85  0.5~0.85   < 0.5
               │          │          │
          ┌────▼───┐ ┌───▼────┐ ┌──▼──────┐
          │ 直接采用 │ │LLM辅助  │ │LLM主导  │
          │ 分类结果 │ │分类确认 │ │全量解析 │
          └────────┘ └───┬────┘ └──┬──────┘
                         │         │
                    ┌────▼─────────▼────┐
                    │   分类结果输出      │
                    │   + 置信度分数     │
                    └───────────────────┘
```

**规则引擎关键词表（示例）：**

```typescript
interface TypeRule {
  type: QuestionType;
  patterns: RegExp[];
  negativePatterns?: RegExp[];  // 排除模式
  priority: number;              // 优先级，数字越小越优先
}

const TYPE_RULES: TypeRule[] = [
  {
    type: QuestionType.MULTI_CHOICE,
    patterns: [/下列.*正确的是/g, /下列.*正确的[有有几]/g, /可能[是的].*?选项/g],
    negativePatterns: [/只有一个.*正确/g],
    priority: 1,
  },
  {
    type: QuestionType.SINGLE_CHOICE,
    patterns: [/^[A-D][.．、)\s]/m, /选[出择].*?选项/g, /正确答案是/g],
    priority: 2,
  },
  {
    type: QuestionType.TRUE_FALSE,
    patterns: [/判断.*[对错正误]/g, /[（(]\s*[√×✓✗]\s*[)）]/g],
    priority: 3,
  },
  {
    type: QuestionType.FILL_BLANK,
    patterns: /[______]{3,}/g, /[───]{3,}/g, /\[\s*\]/g],
    priority: 4,
  },
  {
    type: QuestionType.PROOF],
    patterns: [/求证/g, /证明/g, /证明[:：]/g],
    negativePatterns: [/不需要证明/g],
    priority: 5,
  },
  {
    type: QuestionType.CALCULATION,

  },
  {
    type: QuestionType.CHEMISTRY_EQUATION,
    patterns: [/配平/g, /化学方程式/g, /离子方程式/g, /完成下列方程式/g],
    priority: 3,  // 高优先级，优先于通用计算
  },
  {
    type: QuestionType.CLOZE,
    patterns: [/完形填空/g],

  },

## 3. 结构化解析数据模型

### 3.1 核心数据结构

#### 结构化题目（StructuredQuestion）

```typescript
/**
 * 结构化题目 —— 本引擎的核心输出
 *
 * 设计原则：
 * 1. 所有字段可选，解析引擎尽力填充
 * 2. 每个字段带置信度，下游按需使用
 * 3. 保留原始文本，便于回溯和人工修正
 */
interface StructuredQuestion {
  /** 唯一标识（由引擎生成，格式：sq_{timestamp}_{hash8}） */
  id: string;

  // ──── 元信息 ────
  /** 原始文本（OCR 输出或手动输入的完整题目文本） */
  rawText: string;
  /** 来源 */
  source: 'ocr' | 'manual_input' | 'import' | 'ai_extract';
  /** OCR 图片 URL（如有） */
  sourceImageUrl?: string;
  /** 解析引擎版本 */
  parserVersion: string;
  /** 解析时间戳 */
  parsedAt: number;

  // ──── 题型分类 ────
  typeClassification: TypeClassificationResult;

  // ──── 学科信息 ────
  /** 检测到的学科 */
  detectedSubject?: SubjectCode;
  /** 学科置信度 */
  subjectConfidence?: number;

  // ──── 题目组成部分 ────
  /** 题干（不含选项、不含子题标记） */
  stem: StemSection;
  /** 选项（选择题/判断题） */
  options?: OptionSection;
  /** 填空位（填空题） */
  blanks?: BlankSection[];
  /** 条件（已知条件列表） */
  conditions?: ConditionSection;
  /** 提问部分（"求..." / "问..." / "证明..."） */
  questions: QuestionSection[];
  /** 图形/表格引用 */
  mediaRefs?: MediaRef[];

  // ──── 公式信息 ────
  /** 检测到的所有公式 */
  formulas: FormulaBlock[];

  // ──── 子题（复合题时） ────
  subQuestions?: StructuredQuestion[];

  // ──── 解析元数据 ────
  /** 解析置信度（整体，0~1） */
  overallConfidence: number;
  /** 解析过程中是否使用了 LLM */
  usedLLM: boolean;
  /** 解析耗时 ms */
  parseTimeMs: number;
  /** 人工修正记录 */
  manualCorrections?: ManualCorrection[];
}

type SubjectCode = 'math' | 'physics' | 'chemistry' | 'biology'
                 | 'chinese' | 'english' | 'history' | 'geography' | 'politics';
```

interface OptionSection {

  /** 选项文本（带公式格式） */
  formattedText: string;

  formulaIndices: number[];
  /** 是否包含图形引用 */
  hasMediaRef: boolean;

  endOffset: number;

#### 条件（ConditionSection）

```typescript
interface ConditionSection {
  /** 已知条件列表 */
  items: ConditionItem[];
  /** 置信度 */
  confidence: number;
}

interface ConditionItem {
  /** 条件文本 */
  text: string;
  /** 条件文本（带公式） */
  formattedText: string;
  /** 条件类型 */
  type: 'given' | 'constraint' | 'assumption' | 'definition';
  /**
   * 条件类型说明：
   * - given: 已知条件（"已知AB=5"）
   * - constraint: 约束条件（"且x>0"）
   * - assumption: 假设（"假设函数f(x)可导"）
   * - definition: 定义/设定（"设集合A={1,2,3}"）
   */
  formulaIndices: number[];
  /** 可提取的变量赋值（用于数值计算） */
  extractedValues?: ExtractedValue[];
}

interface ExtractedValue {
  variable: string;   // 变量名，如 "AB", "x"
  value: string;      // 值，如 "5", "3.14"
  unit?: string;      // 单位，如 "m", "kg"
  confidence: number;
}
```

```sql
-- 结构化题目解析结果表
CREATE TABLE parsed_questions (
    id                  VARCHAR(64) PRIMARY KEY COMMENT 'sq_{timestamp}_{hash8}',
    raw_text            TEXT NOT NULL COMMENT '原始题目文本',
    source              VARCHAR(32) NOT NULL COMMENT '来源: ocr/manual_input/import/ai_extract',
    source_image_url    VARCHAR(512) COMMENT 'OCR 图片 URL',
    subject_code        VARCHAR(16) COMMENT '检测到的学科',
    subject_confidence  DECIMAL(3,2) COMMENT '学科置信度',
    question_type       VARCHAR(32) NOT NULL COMMENT '题型枚举值',
    type_confidence     DECIMAL(3,2) NOT NULL COMMENT '题型置信度',
    type_source         VARCHAR(16) NOT NULL COMMENT 'rule/llm_assisted/llm_primary',
    is_composite        TINYINT DEFAULT 0,
    sub_question_count  INT DEFAULT 0,
    structured_data     JSON NOT NULL COMMENT '完整 StructuredQuestion JSON',
    overall_confidence  DECIMAL(3,2) NOT NULL COMMENT '整体解析置信度',
    used_llm            TINYINT DEFAULT 0,
    parse_time_ms       INT COMMENT '解析耗时',
    parser_version      VARCHAR(16) NOT NULL,
    has_manual_correction TINYINT DEFAULT 0,
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_type (question_type),
    INDEX idx_subject (subject_code),
    INDEX idx_confidence (overall_confidence),
    INDEX idx_source (source),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='结构化题目解析结果';

-- 解析结果与题库关联表
CREATE TABLE parsed_question_mapping (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,

    similarity_score    DECIMAL(5,4) COMMENT '与题库题目的相似度',

    UNIQUE KEY uk_parsed (parsed_question_id, question_id),
    INDEX idx_question (question_id)

    avg_confidence      DECIMAL(3,2),

    llm_usage_count     INT DEFAULT 0,
