## 1. 概述

### 1.1 模块定位

系统通知与公告管理配置工作台（Admin Notification & Announcement Console）是 PrimeTop 管理后台面向运营团队、客服团队和系统管理员的统一消息管理界面。

该工作台与「运营活动与营销推广配置工作台」的区别在于：

| 维度 | 系统通知与公告工作台 | 运营活动与营销推广工作台 |
| --- | --- | --- |
| **消息性质** | 系统级、服务级、合规级通知 | 营销级、活动级、推广级消息 |
| **触发方式** | 事件触发 / 定时触发 / 手动紧急广播 | 运营人员主动创建活动 |
| **典型场景** | 系统维护公告、隐私政策更新、安全预警、功能下线通知、考试日程提醒、未成年人保护合规通知 | 优惠券发放、学习挑战赛、裂变邀请、节日活动 |
| **发送权限** | 系统管理员、客服主管、合规专员 | 运营专员、市场推广 |
| **审批要求** | 紧急通道可免审批即时发送 | 必须经过审核 → 发布流程 |
| **退订规则** | 法定/合规通知不可退订，非必要通知尊重用户偏好 | 用户可在设置中关闭营销推送 |

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 统一消息出口 | 系统公告、服务通知、合规消息、紧急广播统一在此工作台管理 |
| 精准触达 | 基于用户标签、学段年级、地域、行为特征进行精细化人群圈选 |
| 多通道编排 | 一次编辑，自动适配 App 推送、站内信、短信、微信等多通道投递 |
| 智能频控 | 对接通知疲劳度管控引擎，避免短时间内对同一用户重复打扰 |
| 效果可追踪 | 推送到达率、点击率、已读率、退订率实时统计 |
| 合规可审计 | 所有发送记录留存审计日志，支持合规检查与事后追溯 |

### 1.3 适用范围与角色权限

| 角色 | 可用功能 | 权限范围 |
| --- | --- | --- |
| 系统管理员 | 全部功能 | 创建/编辑/审核/发布/撤回/紧急广播/模板管理/通道配置 |
| 运营主管 | 公告管理、通知模板、定时推送、数据查看 | 创建/编辑/审核/发布/撤回 |
| 运营专员 | 公告管理（草稿）、定时推送、数据查看 | 创建/编辑（不可发布） |
| 客服主管 | 服务通知发送、紧急通知（受限）、数据查看 | 创建/发送受限范围通知 |
| 合规专员 | 合规通知创建与发布、隐私政策推送 | 合规类通知全权限 |

### 1.4 依赖关系

```text
系统通知与公告管理配置工作台（前端）
    │
    ├── 通知中心与站内消息系统（站内信存储与查询）
    ├── 统一通知消息模板引擎（模板渲染与变量替换）
    ├── 多厂商推送通道适配层（APNs/FCM/华为/小米/VIVO/OPPO/魅族推送）

    ├── 微信生态全域集成与统一接入架构引擎（微信模板消息/订阅消息）
    ├── 多源通知智能合并与用户通知疲劳度管控引擎（频控去重）
    ├── 用户标签与智能分群引擎（目标人群圈选）
    ├── 统一审计日志与操作追溯系统（操作记录）
    └── 统一文件生成与异步报表导出中心服务（报表导出）
```

### 3.2 系统公告表 (sys_announcement)

```sql
CREATE TABLE sys_announcement (
    id                BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '公告ID',
    announcement_no   VARCHAR(32) NOT NULL UNIQUE COMMENT '公告编号 ANN+YYYYMMDD+NNNNN',
    title             VARCHAR(200) NOT NULL COMMENT '公告标题',
    category          VARCHAR(32) NOT NULL COMMENT '类别: SYSTEM_UPDATE|MAINTENANCE|POLICY_UPDATE|SECURITY_ALERT|FEATURE_RELEASE|EXAM_REMINDER|COMPLIANCE_NOTICE|HOLIDAY_NOTICE',
    priority          TINYINT NOT NULL DEFAULT 2 COMMENT '优先级: 1-紧急 2-重要 3-普通 4-低',
    status            VARCHAR(16) NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT|PENDING_REVIEW|APPROVED|SCHEDULED|SENT|CANCELED|ARCHIVED',

    -- 内容
    summary           VARCHAR(500) COMMENT '摘要（用于推送通知展示）',
    body_content      MEDIUMTEXT NOT NULL COMMENT '正文（富文本/Markdown）',
    body_format       VARCHAR(16) NOT NULL DEFAULT 'markdown' COMMENT 'markdown|richtext|plaintext',
    cover_image       VARCHAR(512) COMMENT '封面图URL（可选）',
    attachment_urls   JSON COMMENT '附件URL列表',

    -- 目标人群
    target_scope      VARCHAR(16) NOT NULL DEFAULT 'ALL' COMMENT 'ALL-全量 USER_SEGMENT-分群 GRADE_SPECIFIC-指定年级 INDIVIDUAL-指定用户',
    target_config     JSON COMMENT '目标配置: {stage:[], grade:[], subject:[], user_ids:[], segment_ids:[], exclude_ids:[]}',

    -- 通道配置
    channels          JSON NOT NULL COMMENT '投递通道: ["in_app","push","sms","wechat_template"]',
    channel_strategy  VARCHAR(16) DEFAULT 'PRIORITY' COMMENT 'PRIORITY-按优先级选首个可达 ALL-全通道下发 FALLBACK-逐通道降级',

    -- 调度
    send_type         VARCHAR(16) NOT NULL DEFAULT 'IMMEDIATE' COMMENT 'IMMEDIATE-立即 SCHEDULED-定时 RECURRING-循环',
    scheduled_at      DATETIME COMMENT '计划发送时间（SCHEDULED 类型必填）',
    recurring_cron    VARCHAR(64) COMMENT '循环规则（RECURRING 类型，cron 表达式）',
    recurring_end_at  DATETIME COMMENT '循环结束时间',
    expire_at         DATETIME COMMENT '公告过期时间（过期后不再展示）',

    -- 展示控制
    in_app_display    JSON COMMENT '站内信展示配置: {pin_to_top:Bool, banner_enabled:Bool, banner_until:DATETIME, dismissible:Bool, popup_on_open:Bool}',
    push_config       JSON COMMENT '推送配置: {sound:String, badge:Int, android_channel_id:String, ios_interruption_level:String}',

    -- 合规
    is_compliance     BOOLEAN DEFAULT FALSE COMMENT '是否合规通知（合规通知不可退订）',
    privacy_policy_ref VARCHAR(128) COMMENT '关联隐私政策版本号（如适用）',

    -- 审批
    created_by        BIGINT NOT NULL COMMENT '创建人ID',
    created_by_name   VARCHAR(50) COMMENT '创建人姓名',
    reviewed_by       BIGINT COMMENT '审核人ID',
    reviewed_by_name  VARCHAR(50) COMMENT '审核人姓名',
    reviewed_at       DATETIME COMMENT '审核时间',
    review_comment    VARCHAR(500) COMMENT '审核意见',
    published_by      BIGINT COMMENT '发布人ID',
    published_at      DATETIME COMMENT '实际发布时间',

    -- 统计（异步更新）
    target_count      INT DEFAULT 0 COMMENT '目标用户总数',
    sent_count        INT DEFAULT 0 COMMENT '已发送数',
    delivered_count   INT DEFAULT 0 COMMENT '已送达数',
    read_count        INT DEFAULT 0 COMMENT '已读数',
    clicked_count     INT DEFAULT 0 COMMENT '点击数',
    dismissed_count   INT DEFAULT 0 COMMENT '关闭/退订数',

    created_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at        DATETIME COMMENT '逻辑删除',

    INDEX idx_ann_no (announcement_no),
    INDEX idx_status_priority (status, priority),
    INDEX idx_category (category),
    INDEX idx_scheduled (send_type, scheduled_at),
    INDEX idx_created_by (created_by),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='系统公告表';
```
