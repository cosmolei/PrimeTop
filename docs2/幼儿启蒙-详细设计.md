# 幼儿启蒙模块详细设计

## 1. 概述

### 1.1 模块定位
幼儿启蒙模块是 PrimeTop 覆盖 3-6 岁学龄前儿童及幼小衔接阶段的核心学习场景。它承接产品定位中"全学段覆盖"的战略目标，在已有"拼音识字启蒙"专项能力之外，补齐**数字认知、基础表达、简单常识、趣味问答**等关键启蒙内容，构建完整的幼儿学习闭环。

本模块与"拼音识字启蒙"模块并行运行，共享学生画像、会话管理、练习记录和家长控制等基础能力，但在内容形态、交互方式、AI 能力和适龄性策略上有显著差异：

| 维度 | 拼音识字启蒙 | 幼儿启蒙（本模块） |
| --- | --- | --- |
| 核心内容 | 声母、韵母、汉字识记 | 数字认知、基础表达、简单常识、逻辑启蒙 |
| 交互方式 | 发音跟读、笔画书写、图文配对 | 拖拽排序、情境选择、语音回答、动画互动 |
| AI 能力 | 语音评测、笔顺反馈 | 数量推理、语义鼓励、常识问答、个性化推荐 |
| 学习时长 | 单次 5-10 分钟 | 单次 3-8 分钟 |
| 家长控制 | 内容范围、学习时长 | 内容范围、使用时段、护眼提醒 |

### 1.2 核心职责
1. **数字认知启蒙**：提供 1-20（K1-K2）、1-100（K3）数字认知、数数、数量比较、简单加减概念。
2. **基础表达启蒙**：通过看图说话、句子跟读、情景对话等方式培养低龄儿童口语表达能力。
3. **简单常识启蒙**：围绕安全、自然、生活、社会等主题，提供适龄的趣味问答和知识讲解。
4. **亲子共学支持**：支持家长主导的双人学习模式，家长可控制学习内容、节奏和时长。
5. **正向激励机制**：通过星星、徽章、成长记录等虚拟奖励，保持低龄儿童学习兴趣。

### 1.3 依赖关系
```
幼儿启蒙模块
    ├─ 依赖：用户服务（学生画像、家长控制）
    ├─ 依赖：内容服务（教材、知识点、题库）
    ├─ 依赖：AI 服务（语音评测、语义理解、内容生成）
    ├─ 依赖：学习记录服务（进度、统计、成就）
    ├─ 依赖：拼音识字启蒙（内容共享、会话互通）
    └─ 被依赖：首页工作台、家长中心、学情分析
```

## 2. 系统架构

### 2.1 整体分层
```
客户端层（Flutter + 原生能力）
    ├─ 幼儿启蒙首页 / 学习地图
    ├─ 数字认知练习页
    ├─ 基础表达练习页
    ├─ 简单常识问答页
    ├─ 亲子共学模式页
    └─ 本地缓存与离线包

BFF 层
    └─ 启蒙内容聚合 / 接口适配 / 压缩传输

服务层
    ├─ 幼儿启蒙内容服务：内容元数据、课程大纲、练习素材
    ├─ 幼儿启蒙练习服务：练习生成、结果判定、能力评估
    ├─ 幼儿启蒙会话服务：会话管理、进度跟踪、个性化推荐
    ├─ 语音交互服务：ASR/TTS 封装（复用通用语音服务）
    └─ 家长控制服务：时长控制、内容范围、使用时段

AI 能力层
    ├─ 语音评测（复用）
    ├─ 语义理解与鼓励生成
    └─ 常识问答生成

数据层
    ├─ PostgreSQL：用户、内容、会话、练习记录
    ├─ Redis：会话缓存、热数据
    ├─ 对象存储：图片、音频、动画资源
    └─ 向量库：常识内容语义检索（可选）
```

### 2.2 服务边界
- **幼儿启蒙内容服务**：管理数字认知、基础表达、简单常识的内容元数据，不处理个性化推荐。
- **幼儿启蒙练习服务**：生成练习、判定结果、记录练习数据，不管理会话状态。
- **幼儿启蒙会话服务**：编排学习会话、选择练习、更新进度、生成推荐，不直接生成内容。
- **语音交互服务**：复用通用语音服务，封装 ASR/TTS，提供文本-音频映射。
- **家长控制服务**：复用家长中心能力，提供幼儿启蒙专项控制策略。

## 5. 业务逻辑

### 5.1 练习生成算法

```python
# ece_practice_service.py

async def generate_number_practice(
    content_id: str,
    practice_type: str,
    stage: str,
    difficulty: str,
    count: int
) -> List[NumberPracticeItem]:
    """
    生成数字认知练习。
    """
    content = await ece_content_repo.get(content_id)
    number_range = content.metadata['number_range']
    
    items = []
    for _ in range(count):
        # 根据难度生成不同题型
        if practice_type == 'counting':
            target = random.randint(number_range['from'], number_range['to'])
            options = generate_distractors(target, number_range, count=3)
            items.append(NumberPracticeItem(
                question=f"数一数，有几个？",
                image_url=f"{ASSETS_BASE}/numbers/{target}.png",
                audio_url=f"{ASSETS_BASE}/audio/count_{target}.mp3",
                options=options,
                correct_answer=str(target),
                hint="用手指一个一个指着数"
            ))
        elif practice_type == 'comparison':
            a = random.randint(number_range['from'], number_range['to'])
            b = random.randint(number_range['from'], number_range['to'])
            items.append(NumberPracticeItem(
                question=f"哪边的数量多？",
                image_url=f"{ASSETS_BASE}/compare/{a}_{b}.png",
                audio_url=f"{ASSETS_BASE}/audio/compare_{a}_{b}.mp3",
                options=["左边", "右边", "一样多"],
                correct_answer=compare_answer(a, b),
                hint="先数一数两边各有多少"
            ))
    return items


def generate_distractors(target: int, number_range: dict, count: int) -> List[str]:
    """生成干扰项。"""
    candidates = [n for n in range(number_range['from'], number_range['to'] + 1) if n != target]
    selected = random.sample(candidates, min(count, len(candidates)))
    options = selected + [target]
    random.shuffle(options)
    return [str(o) for o in options]


def compare_answer(a: int, b: int) -> str:
    if a > b:
        return "左边"
    elif a < b:
        return "右边"
    return "一样多"
```

### 5.2 会话编排流程

```python
# ece_session_service.py

async def create_session(
    user_id: str,
    stage: str,
    session_type: str,
    mode: str,
    target_content_ids: Optional[List[str]] = None
) -> ECELearningSession:
    """
    创建幼儿启蒙学习会话。
    """
    # 1. 检查家长控制
    parent_control = await parent_control_service.get(user_id)
    if parent_control and not is_allowed(session_type, parent_control):
        raise ParentControlError("该内容类型不在家长允许的范围内")
    
    # 2. 获取目标内容
    if target_content_ids:
        contents = await ece_content_repo.find_by_ids(target_content_ids)
    else:
        # 从个性化学习路径获取
        path = await ece_learning_path_repo.get(user_id)
        contents = await get_next_path_contents(path, session_type, limit=5)
    
    # 3. 检查每日时长限制
    today_duration = await learning_record_service.get_today_duration(user_id)
    if parent_control and today_duration >= parent_control.daily_limit_min * 60000:
        raise TimeLimitExceededError("今日学习时间已到")
    
    # 4. 创建会话
    session_id = uuid4()
    session = await ece_session_repo.create(
        ECELearningSession(
            id=session_id,
            user_id=user_id,
            session_type=session_type,
            mode=mode,
            start_time=datetime.utcnow(),
            status='active',
            total_duration_ms=0,
            total_practices=0,
            correct_count=0,
            completed_items=[]
        )
    )
    
    # 5. 缓存会话状态
    await redis.setex(
        f"ece:session:{session_id}",
        86400,
        json.dumps({
            "current_step": 0,
            "start_time": session.start_time.isoformat(),
            "item_pool": [c.id for c in contents]
        })
    )
    
    return session
```

### 5.3 练习结果判定

```python
# ece_practice_service.py

async def submit_practice(
    session_id: str,
    content_id: str,
    practice_type: str,
    user_answer: dict,
    duration_ms: int
) -> PracticeResult:
    """
    提交并判定练习结果。
    """
    # 1. 获取正确答案和判定规则
    content = await ece_content_repo.get(content_id)
    correct_answer = content.metadata.get('correct_answer')
    evaluation_rule = content.metadata.get('evaluation_rule', 'exact_match')
    
    # 2. 判定
    is_correct = evaluate_answer(user_answer, correct_answer, evaluation_rule)
    
    # 3. 生成鼓励反馈
    feedback = generate_encouragement(is_correct, practice_type)
    
    # 4. 记录练习
    practice_record = await ece_practice_repo.create(
        ECEPracticeRecord(
            id=uuid4(),
            user_id=session.user_id,
            session_id=session_id,
            content_id=content_id,
            practice_type=practice_type,
            user_answer=user_answer,
            is_correct=is_correct,
            duration_ms=duration_ms,
            feedback=feedback
        )
    )
    
    # 5. 更新会话统计
    await update_session_stats(session_id, is_correct)
    
    # 6. 解锁里程碑（异步）
    await milestone_service.check_and_unlock(session.user_id, content_id)
    
    return PracticeResult(
        practice_id=practice_record.id,
        is_correct=is_correct,
        feedback=feedback,
        next_item=await get_next_item(session_id)
    )


def evaluate_answer(user_answer: dict, correct_answer: Any, rule: str) -> bool:
    """根据规则判定答案。"""
    if rule == 'exact_match':
        return user_answer.get('value') == correct_answer
    elif rule == 'keyword_match':
        user_text = user_answer.get('text', '')
        return any(kw in user_text for kw in correct_answer)
    elif rule == 'number_tolerance':
        return abs(user_answer.get('value') - correct_answer) <= 0
    return False


def generate_encouragement(is_correct: bool, practice_type: str) -> dict:
    """生成低龄化鼓励反馈。"""
    if is_correct:
        messages = ["真棒！", "答对啦！", "你真聪明！", "太厉害了！"]
    else:
        messages = ["没关系，再试一次！", "差一点就对啦！", "再想想~"]
    
    return {
        "text": random.choice(messages),
        "stars": 1 if is_correct else 0,
        "animation": "clap" if is_correct else "thinking"
    }
```

```python
async def update_learning_path(user_id: str, content_id: str, is_correct: bool):
    """
    根据练习结果更新学习路径。
    """
    path = await ece_learning_path_repo.get(user_id)
    if not path:
        path = await create_default_path(user_id)
    
    # 查找当前步骤
    current_step = path.steps[path.current_step_index]
    if current_step['content_id'] == content_id:
        # 更新掌握度
        current_step['attempts'] = current_step.get('attempts', 0) + 1
        current_step['correct_count'] = current_step.get('correct_count', 0) + (1 if is_correct else 0)
        current_step['mastery_rate'] = current_step['correct_count'] / current_step['attempts']
        
        # 如果掌握度达标，推进到下一步
        if current_step['mastery_rate'] >= path.target_mastery_rate and current_step['attempts'] >= 2:
            path.current_step_index = min(path.current_step_index + 1, len(path.steps) - 1)
    
    await ece_learning_path_repo.update(path)
    await redis.setex(
        f"ece:path:{user_id}",
        604800,
        json.dumps(path.to_dict())
    )
```

### 6.3 服务端 - 数字练习生成服务

```typescript
// services/eceNumberPracticeService.ts
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

interface NumberPracticeItem {
  id: string;
  question: string;
  imageUrl: string;
  audioUrl: string;
  options: string[];
  correctAnswer: string;
  hint: string;
}

export class ECENumberPracticeService {
  async generate(params: {
    contentId: string;
    practiceType: string;
    stage: string;
    difficulty: string;
    count: number;
  }): Promise<NumberPracticeItem[]> {
    const { contentId, practiceType, stage, difficulty, count } = params;
    
    const content = await prisma.eCEContent.findUnique({
      where: { id: contentId },
    });
    
    if (!content || content.status !== 'published') {
      throw new Error('Content not found or not published');
    }
    
    const numberRange = content.metadata?.numberRange as { from: number; to: number };
    if (!numberRange) {
      throw new Error('Invalid content metadata: numberRange missing');
    }
    
    const items: NumberPracticeItem[] = [];
    
    for (let i = 0; i < count; i++) {
      const target = randomInt(numberRange.from, numberRange.to);
      const options = generateDistractors(target, numberRange, 3);
      
      items.push({
        id: uuidv4(),
        question: '数一数，有几个？',
        imageUrl: `${ASSETS_BASE}/numbers/${target}.png`,
        audioUrl: `${ASSETS_BASE}/audio/count_${target}.mp3`,
        options,
        correctAnswer: String(target),
        hint: '用手指一个一个指着数',
      });
    }
    
    return items;
  }
}

function randomInt(min: number, max: number): number {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

function generateDistractors(
  target: number,
  range: { from: number; to: number },
  count: number
): string[] {
  const candidates: number[] = [];
  for (let n = range.from; n <= range.to; n++) {
    if (n !== target) candidates.push(n);
  }
  
  const selected = shuffle(candidates).slice(0, Math.min(count, candidates.length));
  const options = [...selected, target];
  return shuffle(options).map(String);
}

function shuffle<T>(array: T[]): T[] {
  return array.sort(() => Math.random() - 0.5);
}
```

```

  ↓ 创建会话

  ├─ 所有练习完成 → COMPLETED
  ├─ 超时无活动 → ABORTED
  └─ 达到家长设定时长 → ABORTED
  ↓ 用户恢复
PAUSED → ACTIVE
```

```
ANSWER_SUBMITTED
  ↓
EVALUATING
  ├─ 判定正确 → CORRECT → 奖励 + 推进
  └─ 判定错误 → INCORRECT → 提示 + 允许重试（最多 3 次）
```

```
LOCKED

UNLOCKED
```

## 8. 错误处理

### 8.1 错误码定义
| 错误码 | 场景 | HTTP 状态 | 客户端提示 |
| --- | --- | --- | --- |
| ECE_4001 | 参数校验失败 | 400 | "输入信息不完整，请重试" |
| ECE_4002 | 内容不存在或未发布 | 404 | "该学习内容暂时不可用" |
| ECE_4003 | 会话不存在或已失效 | 404 | "学习会话已过期，请重新开始" |
| ECE_4004 | 超出家长设定学习时长 | 403 | "今天学习时间到啦，明天继续吧" |
| ECE_4005 | 内容类型被家长禁用 | 403 | "这个内容需要在家长中心开启" |
| ECE_4006 | 语音评测服务不可用 | 503 | "语音服务开小差了，请再试一次" |
| ECE_4007 | 练习提交频率过快 | 429 | "操作太快啦，请慢一点" |
| ECE_5001 | 服务端内部错误 | 500 | "系统繁忙，请稍后再试" |

### 8.2 重试策略
- **练习提交失败**：客户端最多重试 3 次，指数退避（1s, 2s, 4s）。
- **语音评测失败**：回退到文本输入或按钮选择，避免阻塞学习流程。
- **资源加载失败**：使用本地缓存资源，无缓存时显示占位图并提示检查网络。
- **服务端内部错误**：记录日志并告警，返回降级内容（预置的静态练习）。

### 8.3 降级方案
- **AI 服务不可用**：使用预置的静态反馈文案（如"真棒！""再试一次"）。
- **内容服务不可用**：返回本地缓存的课程大纲，允许用户继续学习已缓存内容。
- **家长控制服务不可用**：采用上次有效的控制配置，或默认使用保守策略（限制时长）。

## 9. 安全与隐私

### 9.1 未成年人保护
- **家长控制**：所有幼儿启蒙功能必须在家长中心设置后方可使用，默认关闭。
- **时长限制**：单次学习时长不超过 15 分钟，每日累计不超过家长设定上限（默认 30 分钟）。
- **护眼提醒**：每学习 10 分钟提示休息，每次休息至少 30 秒。
- **内容安全**：所有常识问答内容经人工审核，避免恐怖、暴力、成人等不适内容。
- **无消费诱导**：启蒙阶段不展示会员、支付、广告等入口。

### 9.2 数据隐私
- **语音数据**：仅用于评测，匿名化存储，7 天后自动删除。
- **学习记录**：仅保留统计信息（时长、正确率），不存储原始语音内容。
- **本地缓存**：资源包加密存储，不跨设备同步。

### 9.3 API 安全
- **鉴权**：基于 JWT，Token 有效期 24 小时。
- **限流**：每用户每分钟最多 30 次练习提交，防止刷题。
- **防重放**：每次提交带唯一 `request_id`，服务端校验幂等。
- **数据隔离**：用户只能访问自己的学习会话和练习记录。

## 10. 性能优化

### 10.1 客户端优化
- **资源预加载**：进入首页时预加载最近学习的 5 个内容资源包。
- **图片压缩**：使用 WebP 格式，目标尺寸不超过 300x300。

- **本地缓存**：课程大纲缓存 24 小时，内容元数据缓存 7 天。

- 两个模块的里程碑系统互通，共同构成幼儿学习成长记录。
