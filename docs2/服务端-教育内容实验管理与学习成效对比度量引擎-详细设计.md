# 服务端-教育内容实验管理与学习成效对比度量引擎-详细设计

## 1. 概述

### 1.1 模块定位

教育内容实验管理与学习成效对比度量引擎（Educational Content Experiment & Learning Outcome Measurement Engine，简称 **ECEL**）是 PrimeTop 内容精细化运营的实验中枢。它打通了「内容变体管理 → 流量分配 → 学习成效采集 → 统计显著性判定 → 自动推广/回滚」的完整闭环，让内容团队可以用**科学实验**而非经验直觉来决策"哪种讲解方式更有效"。

### 1.2 与已有模块的边界

| 已有模块 | 关注点 | 本模块差异 |
| --- | --- | --- |
| AB测试与实验平台 | 通用实验基础设施（分流、指标聚合、显著性检验） | 本模块是面向**教育内容**的上层应用，定义教育领域专属指标、实验模板和效果归因逻辑 |
| 教育内容有效性数据驱动评估 | 基于**观察数据**评估内容投放效果 | 本模块基于**受控实验**对比内容变体的因果效果差异 |
| 教育内容质量自动评估 | AI 对内容进行静态质量评分 | 本模块衡量内容对学生的**实际学习效果**，而非内容本身的属性 |
| 教育内容用户评价体系 | 用户主观评分和口碑 | 本模块使用**客观学习数据**（正确率变化、留存率等）衡量效果 |
| 练习答题行为数据采集 | 答题行为数据采集 | 本模块消费答题数据作为实验效果指标 |

### 1.3 核心职责

1. **内容变体管理**：为同一知识点的讲解、例题、练习等创建多个内容变体并维护关联关系。
2. **实验设计与配置**：定义实验假设、目标指标、流量比例、实验周期和人群筛选条件。
3. **学习成效度量**：采集实验曝光后学生的答题正确率变化、知识掌握度增量、复习留存率等教育专属指标。
4. **统计显著性判定**：针对教育数据的特殊性（长尾效应、延迟效果、知识迁移）提供合适的统计检验方法。
5. **实验决策自动化**：根据预设规则自动推广胜出变体或回滚失败变体。
6. **实验知识沉淀**：将实验结论结构化存档，形成内容生产最佳实践知识库。

### 1.4 典型实验场景

| 场景 | 假设示例 |
| --- | --- |
| 讲解方式对比 | "对话式讲解" vs "推导式讲解"对二次函数理解的效果差异 |
| 例题选择对比 | "生活情境例题" vs "纯数学情境例题"对小学应用题正确率的影响 |
| 练习编排对比 | "先易后难梯度练习" vs "随机难度混合练习"对知识巩固的效果 |
| 视觉辅助对比 | "动画演示+文字" vs "纯图文"对物理力学概念理解的效果 |
| 提示策略对比 | "渐进式提示" vs "完整解答立即展示"对学生自主解题能力的影响 |
| 微课时长对比 | "3分钟精讲" vs "8分钟详讲"对知识点完播率和掌握度的效果 |
| 复习间隔对比 | "1天/3天/7天" vs "1天/2天/4天/8天"间隔重复方案对长期记忆的效果 |

## 2. 核心概念与领域模型

### 2.1 术语表

| 术语 | 说明 |
| --- | --- |
| Content Variant（内容变体） | 同一知识点的不同表述方式/呈现形式的特定版本 |
| Experiment Hypothesis（实验假设） | 对内容变体效果差异的预测性陈述 |
| Learning Outcome Metric（学习成效指标） | 衡量学习效果的量化指标（如掌握度增量、正确率变化） |
| Exposure Event（曝光事件） | 学生实际接触到实验内容变体的行为记录 |
| Outcome Window（效果观察窗口） | 从曝光到指标采集的时间区间 |
| Baseline Assessment（基线评估） | 实验前的学生知识水平快照 |
| Post-Assessment（后测评估） | 曝光后的学生知识水平快照 |
| Knowledge Transfer Effect（知识迁移效应） | 学习某内容对其他关联知识点掌握度的间接影响 |
| Confounding Guard（混淆防护） | 防止外部因素（如课堂教学）干扰实验结论的机制 |

## 3. 数据模型

### 3.1 核心表结构

#### 3.1.1 内容变体表 `ecel_content_variants`

```sql
CREATE TABLE ecel_content_variants (
    id                  BIGINT       PRIMARY KEY AUTO_INCREMENT,
    variant_id          VARCHAR(48)  NOT NULL UNIQUE COMMENT '变体唯一标识 ecv_开头',
    content_id          BIGINT       NOT NULL COMMENT '关联内容ID（内容管理系统中的内容）',
    content_type        VARCHAR(32)  NOT NULL COMMENT 'EXPLANATION/EXAMPLE/EXERCISE_SET/MICRO_COURSE/REVIEW_MATERIAL',
    variant_label       VARCHAR(128) NOT NULL COMMENT '变体标签，如"对话式讲解A"',
    variant_description TEXT         NULL     COMMENT '变体说明：与对照组的差异描述',
    subject_code        VARCHAR(16)  NOT NULL COMMENT '学科编码',
    knowledge_point_ids JSON         NOT NULL COMMENT '关联知识点ID列表',
    chapter_id          BIGINT       NULL     COMMENT '章节ID',
    grade_level         VARCHAR(16)  NOT NULL COMMENT '适用学段年级',
    content_snapshot_url VARCHAR(512) NOT NULL COMMENT '内容快照URL（用于实验复现）',
    is_control          TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否为对照组（0=实验组,1=对照组）',
    status              VARCHAR(16)  NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT/ACTIVE/ARCHIVED',
    created_by          BIGINT       NOT NULL,
    created_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_content (content_id),
    INDEX idx_knowledge (subject_code, chapter_id),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教育内容变体表';
```

#### 3.1.2 实验表 `ecel_experiments`

```sql
CREATE TABLE ecel_experiments (
    id                    BIGINT       PRIMARY KEY AUTO_INCREMENT,
    experiment_id         VARCHAR(48)  NOT NULL UNIQUE COMMENT '实验唯一标识 exp_开头',
    experiment_name       VARCHAR(200) NOT NULL COMMENT '实验名称',
    experiment_desc       TEXT         NULL     COMMENT '实验描述',
    hypothesis            TEXT         NOT NULL COMMENT '实验假设，如"对话式讲解比推导式讲解更能提升二次函数理解度"',
    
    layer_id              VARCHAR(48)  NOT NULL COMMENT '实验层ID（同层互斥）',
    
    target_metric_id      VARCHAR(48)  NOT NULL COMMENT '主要评价指标ID',
    secondary_metric_ids  JSON         NULL     COMMENT '次要评价指标ID列表',
    
    -- 人群筛选
    audience_filter       JSON         NOT NULL COMMENT '受众筛选条件JSON',
    -- 示例: {"gradeLevel":"GRADE_8","subject":"MATH","textbookVersion":"PEP","minBaselineMastery":0.3,"maxBaselineMastery":0.7}
    
    -- 流量配置
    traffic_percentage    DECIMAL(5,2) NOT NULL DEFAULT 100.00 COMMENT '总流量占比(%)',
    control_ratio         DECIMAL(5,2) NOT NULL DEFAULT 50.00 COMMENT '对照组流量占比(%)',
    
    -- 时间配置
    start_at              DATETIME     NULL     COMMENT '实验开始时间',
    end_at                DATETIME     NULL     COMMENT '实验预计结束时间',
    max_duration_days     INT          NOT NULL DEFAULT 30 COMMENT '最长实验天数',
    min_duration_days     INT          NOT NULL DEFAULT 7  COMMENT '最短实验天数',
    
    -- 统计参数
    min_sample_size_per_variant INT    NOT NULL DEFAULT 200 COMMENT '每组最小样本量',
    significance_level    DECIMAL(4,3) NOT NULL DEFAULT 0.050 COMMENT '显著性水平α',
    statistical_power     DECIMAL(4,3) NOT NULL DEFAULT 0.800 COMMENT '统计功效1-β',
    minimum_detectable_effect DECIMAL(6,3) NOT NULL DEFAULT 0.050 COMMENT '最小可检测效应量',
    
    -- 自动决策
    auto_promote_enabled  TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否启用自动推广',
    auto_promote_threshold JSON        NULL     COMMENT '自动推广触发条件JSON',
    -- 示例: {"pValueMax":0.01,"effectSizeMin":0.1,"minExposureDays":10,"metricDirection":"POSITIVE"}
    
    status                VARCHAR(20)  NOT NULL DEFAULT 'DRAFT' COMMENT 'DRAFT/REVIEWING/RUNNING/PAUSED/COMPLETED/PROMOTED/ROLLED_BACK',
    
    created_by            BIGINT       NOT NULL,
    created_at            DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at            DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_experiment_id (experiment_id),
    INDEX idx_layer (layer_id),
    INDEX idx_status (status),
    INDEX idx_time (start_at, end_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='教育内容实验表';
```

#### 3.1.5 学习成效指标定义表 `ecel_outcome_metrics`

```sql
CREATE TABLE ecel_outcome_metrics (
    id                  BIGINT       PRIMARY KEY AUTO_INCREMENT,
    metric_id           VARCHAR(48)  NOT NULL UNIQUE COMMENT '指标ID ocm_开头',
    metric_name         VARCHAR(100) NOT NULL COMMENT '指标名称',
    metric_type         VARCHAR(32)  NOT NULL COMMENT '指标类型',
    -- 类型枚举：
    -- MASTERY_DELTA      掌握度增量（曝光后-曝光前）
    -- CORRECT_RATE_DELTA  正确率变化
    -- RETENTION_RATE     知识留存率（N天后掌握度维持比例）
    -- COMPLETION_RATE    内容完播/完成率
    -- TIME_TO_MASTERY    达到掌握标准所需时间
    -- TRANSFER_EFFECT    知识迁移效应（关联知识点掌握度变化）
    -- ENGAGEMENT_SCORE   参与度综合评分
    -- ERROR_RATE_DROP    错误率下降幅度
    
    description         TEXT         NOT NULL COMMENT '指标说明',
    
    aggregation_func    VARCHAR(16)  NOT NULL COMMENT 'MEAN/MEDIAN/P75/P90',
    window_hours        INT          NOT NULL COMMENT '效果观察窗口（小时），如72=3天',
    window_type         VARCHAR(16)  NOT NULL COMMENT 'FIXED/ROLLING/STAGED',
    -- FIXED: 从曝光时刻起固定时间窗口
    -- ROLLING: 滑动窗口取最优
    -- STAGED: 分阶段采集（如24h/72h/7d/14d/30d）
    
    baseline_required   TINYINT(1)   NOT NULL DEFAULT 1 COMMENT '是否需要基线数据',
    higher_is_better    TINYINT(1)   NOT NULL DEFAULT 1 COMMENT '值越高是否代表效果越好',
    
    unit                VARCHAR(16)  NOT NULL DEFAULT 'PERCENTAGE' COMMENT 'PERCENTAGE/RATIO/SCORE/SECONDS',
    
    created_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_metric_id (metric_id),
    INDEX idx_type (metric_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习成效指标定义表';
```

### 5.1 一致性分流算法

```java
/**
 * 教育内容实验分流器
 * <p>
 * 保证同一用户在同一实验中始终分配到相同变体，
 * 且分流结果在用户群体中均匀分布。
 */
public class ContentExperimentHashSplitter {

    // 使用 MurmurHash3 保证分布均匀性
    private static final int HASH_SEED = 0x5F3759DF; // 质数种子

    /**
     * 分配变体
     *
     * @param experimentId  实验ID
     * @param userId        用户ID
     * @param trafficRatio  实验总流量占比 (0.0 ~ 1.0)
     * @param variants      变体列表（含权重）
     * @return 分配结果，或null表示用户不在实验流量内
     */
    public VariantAssignment assign(String experimentId,
                                     long userId,
                                     double trafficRatio,
                                     List<VariantWeight> variants) {

        // Step 1: 流量准入判断 — 决定用户是否进入实验
        long entryHash = murmurHash3(experimentId + "_entry", userId);
        double entryScore = (entryHash & 0xFFFFFFFFL) / (double) 0xFFFFFFFFL;

        if (entryScore >= trafficRatio) {
            return null; // 用户不在实验流量内
        }

        // Step 2: 变体分配 — 决定用户进入哪个变体
        long variantHash = murmurHash3(experimentId + "_variant", userId);
        double variantScore = (variantHash & 0xFFFFFFFFL) / (double) 0xFFFFFFFFL;

        // 加权分配
        int totalWeight = variants.stream().mapToInt(VariantWeight::getWeight).sum();
        double accumulated = variantScore * totalWeight;

        for (VariantWeight vw : variants) {
            accumulated -= vw.getWeight();
            if (accumulated < 0) {
                return new VariantAssignment(
                    experimentId, userId, vw.getVariantId()
                );
            }
        }

        // 兜底：返回最后一个变体
        return new VariantAssignment(
            experimentId, userId, variants.get(variants.size() - 1).getVariantId()
        );
    }

    /**
     * MurmurHash3 32位简化实现
     */
    private static int murmurHash3(String key, long seed) {
        int h = (int) (seed ^ (seed >>> 32));
        for (int i = 0; i < key.length(); i++) {
            h ^= key.charAt(i);
            h *= 0x5bd1e995;
            h ^= h >>> 15;
        }
        return h;
    }
}
```

### 5.2 样本量预估算法

```java
/**
 * 教育内容实验样本量计算器
 * <p>
 * 基于两样本t检验的功效分析，计算检测给定效应量所需的最小样本量。
 */
public class SampleSizeCalculator {

    /**
     * 计算每组所需最小样本量
     *
     * @param alpha      显著性水平 (通常 0.05)
     * @param power      统计功效 (通常 0.80)
     * @param mde        最小可检测效应量 (如 0.05 表示5个百分点差异)
     * @param baselineStd 基线指标的标准差 (历史数据估计)
     * @return 每组最小样本量
     */
    public int calculatePerVariant(double alpha, double power,
                                    double mde, double baselineStd) {
        // Z值查表（正态分布临界值）
        double zAlphaHalf = zScore(1 - alpha / 2); // 通常 1.96
        double zBeta = zScore(power);               // 通常 0.842

        // Cohen's d 效应量
        double cohenD = mde / baselineStd;

        // 两样本t检验样本量公式
        // n = 2 * ((z_α/2 + z_β) / d)²
        double n = 2 * Math.pow((zAlphaHalf + zBeta) / cohenD, 2);

        // 教育数据通常有约15%的无效样本（未完成曝光后评估）
        // 额外加上20%的buffer
        return (int) Math.ceil(n * 1.35);
    }

    /**
     * 估算实验需要运行的天数
     */
    public int estimateDurationDays(int requiredSampleSize,
                                     int dailyEligibleUsers,
                                     double trafficRatio) {
        int dailyAssigned = (int) (dailyEligibleUsers * trafficRatio);
        if (dailyAssigned < 10) {
            return Integer.MAX_VALUE; // 无法达到样本量
        }
        int days = (int) Math.ceil((double) requiredSampleSize * 2 / dailyAssigned);
        return Math.max(days, 7); // 至少运行7天
    }

    private double zScore(double cumulativeProb) {
        // 使用Apache Commons Math的NormalDistribution
        // new NormalDistribution().inverseCumulativeProbability(cumulativeProb)
        // 简化的查表实现
        if (cumulativeProb >= 0.975) return 1.96;
        if (cumulativeProb >= 0.95)  return 1.645;
        if (cumulativeProb >= 0.90)  return 1.282;
        if (cumulativeProb >= 0.80)  return 0.842;
        return 0.0;
    }
}
```

### 5.3 学习成效增量计算

```java
/**
 * 学习成效增量计算器
 * <p>
 * 计算曝光后相对于基线的掌握度变化，
 * 并与对照组进行对比统计检验。
 */
public class LearningOutcomeCalculator {

    /**
     * 计算单个用户的掌握度增量
     *
     * @param preExposureMastery  曝光前掌握度 [0, 1]
     * @param postExposureMastery 曝光后掌握度 [0, 1]
     * @param decayFactor         时间衰减因子（越久远越接近基线）
     * @return 调整后的掌握度增量
     */
    public double calculateMasteryDelta(double preExposureMastery,
                                         double postExposureMastery,
                                         double decayFactor) {
        // 原始增量
        double rawDelta = postExposureMastery - preExposureMastery;

        // 天花板效应修正：基线已很高的学生增量空间有限
        // 使用 floor-adjusted delta
        double ceiling = 1.0 - preExposureMastery;
        if (ceiling < 0.01) {
            // 基线已接近满分，增量意义不大
            return 0.0;
        }

        // 归一化增量（消除天花板效应）
        double normalizedDelta = rawDelta / ceiling;

        // 应用时间衰减（72小时内的效果更可信）
        return normalizedDelta * decayFactor;
    }

    /**
     * 两组对比的统计检验
     *
     * @param controlValues   对照组指标值列表
     * @param treatmentValues 实验组指标值列表
     * @return 统计检验结果
     */
    public StatisticalResult compareGroups(List<Double> controlValues,
                                            List<Double> treatmentValues) {

        int n1 = controlValues.size();
        int n2 = treatmentValues.size();

        double mean1 = mean(controlValues);
        double mean2 = mean(treatmentValues);

        double var1 = variance(controlValues, mean1);
        double var2 = variance(treatmentValues, mean2);

        // Welch's t-test（不假设等方差）
        double pooledSE = Math.sqrt(var1 / n1 + var2 / n2);
        double tStatistic = (mean2 - mean1) / pooledSE;

        // Welch-Satterthwaite 自由度近似
        double numerator = Math.pow(var1 / n1 + var2 / n2, 2);
        double denominator = Math.pow(var1 / n1, 2) / (n1 - 1)
                           + Math.pow(var2 / n2, 2) / (n2 - 1);
        int df = (int) (numerator / denominator);

        // p值计算（双侧检验）
        double pValue = 2 * (1 - tCDF(Math.abs(tStatistic), df));

        // Cohen's d 效应量（使用合并标准差）
        double pooledStd = Math.sqrt(((n1 - 1) * var1 + (n2 - 1) * var2) / (n1 + n2 - 2));
        double cohensD = (mean2 - mean1) / pooledStd;

        // 95% 置信区间
        double margin = 1.96 * pooledSE;
        double ciLower = (mean2 - mean1) - margin;
        double ciUpper = (mean2 - mean1) + margin;

        return new StatisticalResult(
            mean2 - mean1,   // absoluteEffect
            cohensD,          // effectSize
            pValue,           // pValue
            ciLower,          // confidenceLower
            ciUpper,          // confidenceUpper
            pValue < 0.05 && Math.abs(cohensD) >= 0.2 // isSignificant
        );
    }

    // ... 统计工具方法省略
    private double mean(List<Double> values) { /* ... */ return 0; }
    private double variance(List<Double> values, double mean) { /* ... */ return 0; }
    private double tCDF(double t, int df) { /* ... */ return 0; }
}
```

### 5.5 混淆因素防护

```java
/**
 * 实验混淆因素检测与防护
 * <p>
 * 教育实验面临的特殊混淆因素：
 * 1. 课堂教学干扰 — 学生可能在学校刚好学了同一知识点
 * 2. 课外辅导 — 学生可能在辅导班学了
 * 3. 季节性 — 考前突击期 vs 假期，效果差异大
 * 4. 知识点难度 — 难度不同，内容效果差异不可比
 * 5. 交互效应 — 用户同时参与多个实验
 */
public class ConfoundingGuard {

    /**
     * SRM（样本比偏差）检测
     * 确保实际分流比例与配置比例一致
     */
    public SRMCheckResult checkSampleRatioMismatch(String experimentId,
                                                     int expectedControlCount,
                                                     int expectedTreatmentCount,
                                                     int actualControlCount,
                                                     int actualTreatmentCount) {
        int totalExpected = expectedControlCount + expectedTreatmentCount;
        int totalActual = actualControlCount + actualTreatmentCount;

        double expectedControlRatio = (double) expectedControlCount / totalExpected;
        int expectedActualControl = (int) (totalActual * expectedControlRatio);

        // 卡方检验
        double chiSquare = Math.pow(actualControlCount - expectedActualControl, 2) 
                         / expectedActualControl
                         + Math.pow(actualTreatmentCount - (totalActual - expectedActualControl), 2)
                         / (totalActual - expectedActualControl);

        boolean hasSRM = chiSquare > 3.84; // p < 0.05 的卡方临界值

        return new SRMCheckResult(hasSRM, chiSquare,
            hasSRM ? "分流比例异常，实验结果不可信" : "分流比例正常");
    }

    /**
     * 时间均衡性检查
     * 确保两组用户的曝光时间分布一致
     * （避免一组集中在周末，另一组集中在工作日）
     */
    public boolean checkTemporalBalance(String experimentId) {
        // 获取对照组和实验组的曝光时间分布
        Map<String, Integer> controlHourly = getExposureDistribution(experimentId, "CONTROL");
        Map<String, Integer> treatmentHourly = getExposureDistribution(experimentId, "TREATMENT");

        // KS检验比较两个分布
        double ksStatistic = kolmogorovSmirnov(controlHourly, treatmentHourly);
        return ksStatistic < 0.1; // KS统计量小于0.1认为分布一致
    }

    /**
     * 多实验交互检测
     * 检查用户是否同时参与了可能相互影响的其他实验
     */
    public List<InteractionWarning> checkCrossExperimentInterference(long userId) {
        List<String> activeExperiments = getActiveExperimentsForUser(userId);
        List<InteractionWarning> warnings = new ArrayList<>();

        for (int i = 0; i < activeExperiments.size(); i++) {
            for (int j = i + 1; j < activeExperiments.size(); j++) {
                String exp1 = activeExperiments.get(i);
                String exp2 = activeExperiments.get(j);

                // 检查两个实验是否涉及相同或关联知识点
                if (hasOverlappingKnowledgePoints(exp1, exp2)) {
                    warnings.add(new InteractionWarning(
                        exp1, exp2,
                        "两个实验涉及相同知识点，可能存在交互效应"
                    ));
                }
            }
        }

        return warnings;
    }

    // ... 辅助方法省略
}
```

```python
# 自动决策定时任务（每小时执行）
def auto_decision_check():
    running_experiments = get_experiments_by_status("RUNNING")
    
    for exp in running_experiments:
        try:
            # 前置条件
            if exp.running_days < exp.min_duration_days:
                continue
            
            # SRM检查
            srm = check_srm(exp.experiment_id)
            if not srm.is_healthy:
                log_warning(exp.experiment_id, "SRM告警，跳过自动决策")
                continue
            
            # 获取主要指标结果
            results = get_metric_results(exp.experiment_id, exp.target_metric_id)
            if not results.has_sufficient_samples:
                continue
            
            # 检查显著性
            treatment = results.get_treatment()
            control = results.get_control()
            
            if treatment.p_value < exp.significance_level:
                if treatment.effect_direction == "POSITIVE":
                    # 检查次要指标安全性
                    if secondary_metrics_are_safe(exp):
                        if exp.auto_promote_enabled:
                            promote_variant(exp, treatment.variant_id)
                            log_action(exp, "AUTO_PROMOTED", 
                                       f"自动推广: p={treatment.p_value}, d={treatment.cohens_d}")
                        else:
                            notify_team(exp, "READY_TO_PROMOTE", 
                                        f"建议推广: p={treatment.p_value}")
                    else:
                        notify_team(exp, "CONFLICTING_RESULTS",
                                    "主要指标正面但次要指标有风险，需人工决策")
                else:
                    # 负面方向显著
                    if exp.auto_promote_enabled:
                        rollback_experiment(exp)
                        log_action(exp, "AUTO_ROLLED_BACK",
                                   f"自动回滚: 效果显著负面")
                    else:
                        notify_team(exp, "NEGATIVE_RESULT",
                                    f"实验组效果显著负面: p={treatment.p_value}")
            
            # 检查是否到期
            if exp.running_days >= exp.max_duration_days:
                if not results.is_significant:
                    complete_inconclusive(exp)
                    log_action(exp, "COMPLETED_INCONCLUSIVE",
                               "实验到期但未达到显著性")
                
        except Exception as e:
            log_error(exp.experiment_id, str(e))
            continue
```

## 10. 性能优化

### 10.1 关键性能指标

| 指标 | 目标 |
| --- | --- |
| 分流响应延迟（P99） | < 5ms |
| 曝光上报延迟 | < 50ms（异步） |
| 指标聚合任务执行时间 | < 5分钟 |
| 实验结果查询延迟 | < 2秒 |

### 10.2 优化策略

1. **分流热缓存**：高频访问用户的分配结果缓存在本地 LRU Cache（10万条），命中率 > 95%。
2. **批量曝光写入**：曝光事件先写入内存队列，每100条或每5秒批量落库。
3. **增量聚合**：指标统计使用 Redis Hash 增量更新（sum/sumSq/count），避免全量重算。
4. **预计算结果**：每小时预计算各实验的指标摘要，查询时直接读取预计算结果。
5. **读写分离**：变体分配查询走读库，实验配置变更走写库。

```python
def test_statistical_power():
    """验证在已知效应量下，统计检验的功效是否符合预期"""
    for _ in range(10000):
        # 生成合成数据：已知效应量 d=0.3
        control = np.random.normal(0.12, 0.09, 200)  # 对照组掌握度增量

    # 预期功效 ~0.80
    assert abs(observed_power - 0.80) < 0.03
```

### 14.2 教育内容实验检查清单

- [ ] 实验假设是否明确且可证伪
- [ ] 变体之间差异是否单一变量（除目标变量外其他条件一致）
- [ ] 变体是否已通过内容安全审核
- [ ] 知识点覆盖范围是否一致
- [ ] 主要指标是否能直接衡量假设
- [ ] 最小样本量是否可达
- [ ] 实验周期是否覆盖至少一个完整周末
- [ ] 是否与同层其他实验冲突
- [ ] 是否设置次要安全指标
- [ ] 自动推广条件是否合理（不过于激进）
- [ ] 是否有回滚预案
