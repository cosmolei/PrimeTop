# 教育高频问题智能问答库与预回答检索推荐引擎 - 详细设计

## 1. 概述

### 1.1 模块定位

教育高频问题智能问答库（EduFAQ）是 PrimeTop AI 辅导链路中的**前置拦截层**，位于用户输入与 LLM 调用之间。通过维护一套经教研审核的高质量教育问答对，对用户提问进行语义匹配，命中时直接返回预置优质回答，无需调用大模型 API。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 高频问题拦截 | 对学生常见问题（如"什么是勾股定理""please 的用法"）直接返回预置回答，跳过 LLM 调用 |
| 回答质量保障 | 预置回答由教研团队审核，确保知识准确性、适龄性、教材对齐 |
| API 成本节约 | 高频问题命中率预计 20%-40%，显著降低 LLM Token 消耗 |
| 响应速度提升 | 缓存命中响应 < 100ms，远优于 LLM 的 3-10s |
| 热点问题发现 | 从未命中的 AI 对话日志中挖掘高频问题，自动推荐候选 FAQ |
| 问答库自演化 | 根据用户反馈（👍/👎）与行为数据自动调整匹配策略与内容排序 |

### 1.3 与现有模块的边界

| 模块 | 区别 |
|------|------|
| AI 输出缓存与智能复用引擎 | AI 输出缓存是对**历史 LLM 响应**的缓存复用；EduFAQ 是**人工审核+自动挖掘**的预置知识库，回答质量更高、可控性更强 |
| RAG 检索增强生成系统 | RAG 是将检索片段注入 LLM Prompt 增强生成；EduFAQ 命中后**不调用 LLM**，直接返回完整回答 |
| AI 智能客服对话引擎 | 智能客服面向**产品使用问题**（充值、登录等）；EduFAQ 面向**学科知识问题** |
| 题库系统 | 题库存储的是**练习题目**（有标准答案供答题）；EduFAQ 存储的是**知识问答对**（概念解释、方法讲解） |

### 1.4 依赖关系

```
用户输入
  │
  ▼
┌─────────────┐    未命中    ┌──────────────┐
│  EduFAQ     │─────────────▶│  AI 对话引擎  │
│  匹配引擎    │              │  (LLM 调用)   │
└──────┬──────┘              └──────┬───────┘
       │ 命中                       │ 对话日志
       ▼                            ▼
┌─────────────┐              ┌──────────────┐
│  预置回答    │              │  热点挖掘     │
│  返回客户端   │              │  (候选FAQ生成) │
└─────────────┘              └──────────────┘
```

**上游依赖：**
- 用户服务：获取学生学段、年级、学科、教材版本
- 学科基础数据：学科枚举、知识点体系
- 内容审核服务：预置回答上架前安全审核

**下游消费：**
- AI 对话引擎：未命中时接收降级处理请求
- 管理后台：FAQ 内容管理、审核、数据分析
- 数据分析服务：命中率、成本节约、用户满意度

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 FAQ 问答条目（FaqItem）

```java
/**
 * FAQ 问答条目 - 核心实体
 */
@Data
@TableName("edu_faq_item")
public class FaqItem {
    @TableId(type = IdType.ASSIGN_ID)
    private Long id;
    
    /** 业务编号 */
    private String faqNo;
    
    /** 问题标题（简短概述，用于管理后台展示） */
    private String title;
    
    /** 标准问题文本（规范化后的完整问题） */
    private String canonicalQuestion;
    
    /** 问题别名/变体列表（同义问法的其他表述） */
    /** 存储为 JSON 数组 */
    private String questionVariantsJson;
    
    /** 回答内容（Markdown 格式，支持公式、图片引用） */
    private String answerContent;
    
    /** 回答纯文本（用于全文索引和摘要展示） */
    private String answerPlainText;
    
    /** 适用学段：KINDERGARTEN / PRIMARY / JUNIOR / SENIOR */
    private String stageLevel;
    
    /** 适用年级范围（JSON 数组，如 ["7","8","9"] 表示初一至初三） */
    private String gradeLevelsJson;
    
    /** 学科代码 */
    private String subjectCode;
    
    /** 关联知识点 ID 列表（JSON 数组） */
    private String knowledgePointIdsJson;
    
    /** 关联教材章节 ID 列表（JSON 数组） */
    private String chapterIdsJson;
    
    /** 教材版本代码（如 PEP 表示人教版） */
    private String textbookVersion;
    
    /** 问题类型：CONCEPT（概念解释）/ METHOD（方法讲解）/ DIFFERENCE（辨析比较）/ EXAMPLE（例题演示）/ COMMON_MISTAKE（常见错误） */
    private String questionType;
    
    /** 难度等级：1（基础）~ 5（拓展） */
    private Integer difficultyLevel;
    
    /** 语言版本：zh-CN / en-US */
    private String locale;
    
    /** 向量嵌入（Binary，用于语义检索） */
    private byte[] embeddingVector;
    
    /** 嵌入模型标识 */
    private String embeddingModel;
    
    /** 状态：DRAFT（草稿）/ PENDING_REVIEW（待审核）/ PUBLISHED（已发布）/ OFFLINE（已下架）/ ARCHIVED（归档） */
    private String status;
    
    /** 权重（排序因子，人工+算法调整，默认100） */
    private Integer weight;
    
    /** 命中次数（累计） */
    private Long hitCount;
    
    /** 用户反馈👍次数 */
    private Long likeCount;
    
    /** 用户反馈👎次数 */
    private Long dislikeCount;
    
    /** 创建人 */
    private String createdBy;
    
    /** 创建时间 */
    private LocalDateTime createdAt;
    
    /** 更新人 */
    private String updatedBy;
    
    /** 更新时间 */
    private LocalDateTime updatedAt;
    
    /** 审核人 */
    private String reviewedBy;
    
    /** 审核时间 */
    private LocalDateTime reviewedAt;
    
    /** 版本号（乐观锁） */
    private Integer version;
    
    /** 是否删除 */
    @TableLogic
    private Integer deleted;
}
```

### 2.3 缓存策略

| 缓存层 | 存储内容 | Key 格式 | TTL | 失效策略 |
|--------|---------|----------|-----|---------|
| L1 本地缓存 (Caffeine) | 热门 FAQ 全文（Top 5000） | `faq:hot:{faqId}` | 5min | 定时刷新 + 写入时广播失效 |
| L1 本地缓存 | 倒排索引（关键词→FAQ ID 列表） | `faq:inverted` | 10min | 定时重建 |
| L2 Redis | FAQ 全量元数据 | `faq:meta:{faqId}` | 30min | 发布/下架时主动清除 |
| L2 Redis | 向量索引分片（IVF） | `faq:vec:shard:{n}` | 60min | 内容变更时异步重建 |
| L2 Redis | 学科+学段维度 FAQ ID 列表 | `faq:list:{subject}:{stage}` | 15min | 发布/下架时更新 |
| L2 Redis | 用户当日已命中去重 | `faq:dedup:{userId}:{faqId}` | 到当日24点 | 自然过期 |
| L3 Milvus | FAQ 向量+变体向量（持久化） | Collection: edu_faq | - | 增量更新 |

## 3. API 接口设计

### 3.1 用户端接口

#### 3.1.1 FAQ 智能匹配（核心接口）

```
POST /api/v1/faq/match
```

**请求：**

```json
{
  "query": "什么是勾股定理怎么用",
  "subjectCode": "MATH",
  "stageLevel": "JUNIOR",
  "gradeLevel": "8",
  "textbookVersion": "PEP",
  "sessionId": "sess_abc123",
  "context": {
    "knowledgePointId": "kp_12345",
    "chapterId": "ch_678"
  }
}
```

**响应（命中）：**

```json
{
  "code": 0,
  "data": {
    "hit": true,

    "faqNo": "FAQ-MATH-001234",

    "answer": "## 勾股定理\n\n**勾股定理**指出：在直角三角形中...",

      {"faqId": "1002004568", "title": "勾股定理的逆定理"},
```

## 5. 关键算法与代码实现

### 5.1 匹配引擎核心实现

```java
/**
 * FAQ 匹配引擎 - 核心服务
 * 责责对用户提问进行多级匹配，返回最优 FAQ 回答或未命中标记
 */
@Service
@Slf4j
public class FaqMatchEngine {
    
    @Autowired
    private FaqItemMapper faqItemMapper;
    
    @Autowired
    private FaqQueryVariantMapper variantMapper;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private MilvusClient milvusClient;
    
    @Autowired
    private EmbeddingService embeddingService;
    
    @Autowired
    private FaqHitLogService hitLogService;
    
    @Autowired
    private FaqDedupService dedupService;
    
    // 匹配阈值配置
    @Value("${faq.match.strong-threshold:0.85}")
    private double strongThreshold;
    
    @Value("${faq.match.weak-threshold:0.70}")
    private double weakThreshold;
    
    /**
     * 执行 FAQ 匹配
     * @param request 匹配请求
     * @return 匹配结果
     */
    public FaqMatchResult match(FaqMatchRequest request) {
        long startTime = System.currentTimeMillis();
        String normalizedQuery = normalizeQuery(request.getQuery());
        
        // Step 1: 去重检查 - 短时间内同用户同问题不重复处理
        if (dedupService.isDuplicate(request.getUserId(), normalizedQuery)) {
            log.debug("Duplicate query detected, userId={}, query={}", 
                request.getUserId(), normalizedQuery);
            return FaqMatchResult.dedup();
        }
        
        // Step 2: 预过滤
        FaqPrefilterResult prefilter = prefilter(normalizedQuery, request);
        if (!prefilter.isShouldContinue()) {
            return recordMiss(request, normalizedQuery, prefilter.getReason(), 
                System.currentTimeMillis() - startTime);
        }
        
        // Step 3: 精确匹配
        FaqMatchResult exactMatch = exactMatch(normalizedQuery, request);
        if (exactMatch != null && exactMatch.isHit()) {
            exactMatch.setMatchType("EXACT");
            exactMatch.setMatchScore(1.0);
            return finalizeResult(exactMatch, request, startTime);
        }
        
        // Step 4: 关键词检索（候选集缩小）
        List<Long> keywordCandidates = keywordSearch(normalizedQuery, request, 100);
        
        // Step 5: 语义向量检索
        List<VectorSearchResult> vectorResults = vectorSearch(
            normalizedQuery, request, 50);
        
        // 合并候选集
        Set<Long> candidateIds = new HashSet<>();
        candidateIds.addAll(keywordCandidates);
        vectorResults.forEach(r -> candidateIds.add(r.getFaqItemId()));
        
        if (candidateIds.isEmpty()) {
            return recordMiss(request, normalizedQuery, "NO_CANDIDATES",
                System.currentTimeMillis() - startTime);
        }
        
        // Step 6: 多路归并与重排
        List<RankedFaq> ranked = rerank(
            candidateIds, vectorResults, keywordCandidates, request);
        
        // Step 7: 阈值决策
        if (!ranked.isEmpty() && ranked.get(0).getFinalScore() >= strongThreshold) {
            FaqMatchResult result = buildMatchResult(ranked.get(0), "SEMANTIC");
            return finalizeResult(result, request, startTime);
        } else if (!ranked.isEmpty() && ranked.get(0).getFinalScore() >= weakThreshold) {
            // 弱命中：返回推荐但同时也走 LLM
            FaqMatchResult result = buildWeakMatchResult(ranked.get(0));
            return finalizeResult(result, request, startTime);
        }
        
        return recordMiss(request, normalizedQuery, "BELOW_THRESHOLD",
            System.currentTimeMillis() - startTime);
    }
    
    /**
     * 文本归一化
     */
    private String normalizeQuery(String raw) {
        return raw.trim()
            .replaceAll("[\\s]+", " ")          // 压缩空白
            .replaceAll("[？?]+", "？")           // 统一问号
            .replaceAll("[！!]+", "！")           // 统一叹号
            .toLowerCase();                        // 小写化
    }
    
    /**
     * 预过滤：长度、意图、敏感词
     */
    private FaqPrefilterResult prefilter(String query, FaqMatchRequest req) {
        if (query.length() < 3) {
            return FaqPrefilterResult.skip("QUERY_TOO_SHORT");
        }
        if (query.length() > 500) {
            return FaqPrefilterResult.skip("QUERY_TOO_LONG");
        }
        // 非学习意图检测（如充值、密码等）
        if (isNonLearningIntent(query)) {
            return FaqPrefilterResult.skip("NON_LEARNING_INTENT");
        }
        return FaqPrefilterResult.continue_();
    }
    
    /**
     * 精确匹配：标准问题 + 已审核变体
     */
    private FaqMatchResult exactMatch(String query, FaqMatchRequest req) {
        // 先查 Redis 缓存的精确匹配表
        String cacheKey = String.format("faq:exact:%s:%s:%s",
            req.getSubjectCode(), req.getStageLevel(),
            DigestUtils.md5Hex(query));
        
        Long faqId = (Long) redisTemplate.opsForValue().get(cacheKey);
        if (faqId != null) {
            FaqItem item = faqItemMapper.selectPublishedById(faqId);
            if (item != null && isApplicable(item, req)) {
                return FaqMatchResult.hit(item);
            }
        }
        
        // 数据库精确匹配（标准问题 + 变体）
        FaqItem matched = faqItemMapper.matchExactQuery(
            query, req.getSubjectCode(), req.getStageLevel());
        
        if (matched != null) {
            // 写入缓存，5分钟有效
            redisTemplate.opsForValue().set(cacheKey, matched.getId(), 
                Duration.ofMinutes(5));
            return FaqMatchResult.hit(matched);
        }
        
        return null;
    }
    
    /**
     * 关键词倒排检索
     */
    private List<Long> keywordSearch(String query, FaqMatchRequest req, int topK) {
        // 中文分词
        List<String> tokens = tsjiebaSegment(query);
        
        // 过滤停用词
        tokens = tokens.stream()
            .filter(t -> !STOP_WORDS.contains(t))
            .filter(t -> t.length() > 1)
            .collect(Collectors.toList());
        
        if (tokens.isEmpty()) {
            return Collections.emptyList();
        }
        
        // 从 Redis 倒排索引检索
        Map<Long, Double> docScores = new HashMap<>();
        for (String token : tokens) {
            String indexKey = "faq:inverted:" + token;
            Map<Object, Object> entries = redisTemplate.opsForHash().entries(indexKey);
            for (Map.Entry<Object, Object> entry : entries.entrySet()) {
                Long faqId = Long.parseLong(entry.getKey().toString());
                double tfidf = Double.parseDouble(entry.getValue().toString());
                docScores.merge(faqId, tfidf, Double::sum);
            }
        }
        
        // 按得分排序取 TopK
        return docScores.entrySet().stream()
            .sorted(Map.Entry.<Long, Double>comparingByValue().reversed())
            .limit(topK)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());
    }
    
    /**
     * 语义向量检索
     */
    private List<VectorSearchResult> vectorSearch(
            String query, FaqMatchRequest req, int topK) {
        
        // 生成查询向量
        float[] queryVector = embeddingService.embed(query);
        
        // Milvus 向量检索
        SearchParam searchParam = SearchParam.newBuilder()
            .withCollectionName("edu_faq_vectors")
            .withVectors(List.of(new ListFloatBinaryData(queryVector)))
            .withVectorFieldName("embedding")
            .withTopK(topK)
            .withMetricType(MetricType.COSINE)
            .withExpr(String.format(
                "subject_code == '%s' && stage_level == '%s' && status == 'PUBLISHED'",
                req.getSubjectCode(), req.getStageLevel()))
            .withOutFields(List.of("faq_item_id", "variant_id"))
            .build();
        
        R<SearchResults> response = milvusClient.search(searchParam);
        
        if (response.getStatus() != R.Status.Success.getCode()) {
            log.error("Milvus search failed: {}", response.getMessage());
            return Collections.emptyList();
        }
        
        return parseSearchResults(response.getData());
    }
    
    /**
     * 多路归并与重排
     */
    private List<RankedFaq> rerank(
            Set<Long> candidateIds,
            List<VectorSearchResult> vectorResults,
            List<Long> keywordCandidates,
            FaqMatchRequest req) {
        
        // 批量加载 FAQ 元数据
        Map<Long, FaqItem> faqMap = faqItemMapper
            .selectBatchIds(candidateIds).stream()
            .collect(Collectors.toMap(FaqItem::getId, f -> f));
        
        // 向量得分映射
        Map<Long, Double> vectorScoreMap = vectorResults.stream()
            .collect(Collectors.toMap(
                VectorSearchResult::getFaqItemId,
                VectorSearchResult::getScore,
                Math::max));
        
        // 关键词得分映射（归一化）
        double maxKwScore = keywordCandidates.isEmpty() ? 1.0 : 
            (double) keywordCandidates.size();
        Map<Long, Double> keywordScoreMap = new HashMap<>();
        for (int i = 0; i < keywordCandidates.size(); i++) {
            keywordScoreMap.put(keywordCandidates.get(i),
                (keywordCandidates.size() - i) / maxKwScore);
        }
        
        // 综合打分
        List<RankedFaq> ranked = candidateIds.stream()
            .map(faqId -> {
                FaqItem item = faqMap.get(faqId);
                if (item == null || !isApplicable(item, req)) {
                    return null;
                }
                
                double vScore = vectorScoreMap.getOrDefault(faqId, 0.0);
                double kScore = keywordScoreMap.getOrDefault(faqId, 0.0);
                
                // 基础综合分
                double baseScore = vScore * 0.5 + kScore * 0.3;
                
                // 热度加成（命中越多权重越高，对数压缩）
                double popularityBoost = Math.log10(item.getHitCount() + 10) / 10.0;
                baseScore += popularityBoost * 0.1;
                
                // 教材版本匹配加成
                if (req.getTextbookVersion() != null && 
                    req.getTextbookVersion().equals(item.getTextbookVersion())) {
                    baseScore += 0.05;
                }
                
                // 年级匹配加成
                if (isGradeMatch(item, req.getGradeLevel())) {
                    baseScore += 0.03;
                }
                
                // 用户反馈惩罚（点踩率 > 20% 降权）
                long totalFeedback = item.getLikeCount() + item.getDislikeCount();
                if (totalFeedback > 10) {
                    double dislikeRate = (double) item.getDislikeCount() / totalFeedback;
                    if (dislikeRate > 0.2) {
                        baseScore *= (1.0 - dislikeRate * 0.5);
                    }
                }
                
                // 人工权重加成
                baseScore += (item.getWeight() - 100) * 0.0001;
                
                RankedFaq ranked = new RankedFaq();
                ranked.setFaqItem(item);
                ranked.setVectorScore(vScore);
                ranked.setKeywordScore(kScore);
                ranked.setFinalScore(Math.min(baseScore, 1.0));
                return ranked;
            })
            .filter(Objects::nonNull)
            .sorted(Comparator.comparingDouble(RankedFaq::getFinalScore).reversed())
            .collect(Collectors.toList());
        
        return ranked;
    }
    
    /**
     * 适用性检查：学段/学科/年级是否匹配
     */
    private boolean isApplicable(FaqItem item, FaqMatchRequest req) {
        if (!item.getSubjectCode().equals(req.getSubjectCode())) {
            return false;
        }
        if (!item.getStageLevel().equals(req.getStageLevel())) {
            return false;
        }
        return isGradeMatch(item, req.getGradeLevel());
    }
    
    private boolean isGradeMatch(FaqItem item, String userGrade) {
        if (item.getGradeLevelsJson() == null || item.getGradeLevelsJson().isEmpty()) {
            return true; // 未限制年级则默认适用
        }
        List<String> grades = JsonUtils.parseArray(item.getGradeLevelsJson(), String.class);
        return grades.contains(userGrade);
    }
    
    /**
     * 记录未命中并返回
     */
    private FaqMatchResult recordMiss(FaqMatchRequest req, String query,
            String reason, long latencyMs) {
        hitLogService.asyncLogMiss(req, query, reason, latencyMs);
        FaqMatchResult result = FaqMatchResult.miss(reason);
        result.setLatencyMs((int) latencyMs);
        return result;
    }
    
    /**
     * 最终化结果：写日志、更新去重、更新计数
     */
    private FaqMatchResult finalizeResult(FaqMatchResult result,
            FaqMatchRequest req, long startTimeMs) {
        int latency = (int) (System.currentTimeMillis() - startTimeMs);
        result.setLatencyMs(latency);
        
        // 异步写命中日志
        hitLogService.asyncLogHit(req, result, latency);
        
        // 更新去重缓存
        if (result.isHit()) {
            dedupService.recordHit(req.getUserId(), result.getFaqId());
            // 异步更新命中计数
```

### 5.2 向量嵌入服务

```java
/**
 * 向量嵌入服务 - 将文本转化为语义向量
 * 支持多模型切换，结果缓存
 */
@Service
@Slf4j
public class EmbeddingService {
    
    @Autowired
    private ModelAdapter modelAdapter;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Value("${faq.embedding.model:bge-large-zh-v1.5}")
    private String defaultModel;
    
    @Value("${faq.embedding.dim:1024}")
    private int embeddingDim;
    
    /**
     * 生成文本的嵌入向量（带缓存）
     */
    public float[] embed(String text) {
        return embed(text, defaultModel);
    }
    
    public float[] embed(String text, String model) {
        // 缓存检查
        String cacheKey = String.format("embed:%s:%s",
            model, DigestUtils.md5Hex(text));
        
        byte[] cached = (byte[]) redisTemplate.opsForValue().get(
            cacheKey.getBytes(StandardCharsets.UTF_8));
        if (cached != null) {
            return bytesToFloats(cached);
        }
        
        // 调用嵌入模型
        float[] vector = modelAdapter.embed(text, model);
        
        // L2 归一化
        vector = l2Normalize(vector);
        
        // 缓存（7天有效）
        redisTemplate.opsForValue().set(
            cacheKey, floatsToBytes(vector), Duration.ofDays(7));
        
        return vector;
    }
    
    /**
     * 批量嵌入
     */
    public List<float[]> embedBatch(List<String> texts) {
        // 按批次处理（模型批量大小限制）
        int batchSize = 32;
        List<float[]> results = new ArrayList<>(texts.size());
        
        for (int i = 0; i < texts.size(); i += batchSize) {
            int end = Math.min(i + batchSize, texts.size());
            List<String> batch = texts.subList(i, end);
            
            // 先检查缓存
            List<float[]> batchResults = new ArrayList<>(batch.size());
            List<Integer> missIndices = new ArrayList<>();
            List<String> missTexts = new ArrayList<>();
            
            for (int j = 0; j < batch.size(); j++) {
                String cacheKey = String.format("embed:%s:%s",
                    defaultModel, DigestUtils.md5Hex(batch.get(j)));
                byte[] cached = (byte[]) redisTemplate.opsForValue().get(
                    cacheKey.getBytes(StandardCharsets.UTF_8));
                if (cached != null) {
                    batchResults.add(bytesToFloats(cached));
                } else {
                    batchResults.add(null);
                    missIndices.add(j);
                    missTexts.add(batch.get(j));
                }
            }
            
            // 批量调用模型
            if (!missTexts.isEmpty()) {
                List<float[]> missVectors = modelAdapter.embedBatch(
                    missTexts, defaultModel);
                
                for (int k = 0; k < missVectors.size(); k++) {
                    float[] normalized = l2Normalize(missVectors.get(k));
                    batchResults.set(missIndices.get(k), normalized);
                    
                    // 写缓存
                    String cacheKey = String.format("embed:%s:%s",
                        defaultModel, DigestUtils.md5Hex(missTexts.get(k)));
                    redisTemplate.opsForValue().set(
                        cacheKey, floatsToBytes(normalized), Duration.ofDays(7));
                }
            }
            
            results.addAll(batchResults);
        }
        
        return results;
    }
    
    private float[] l2Normalize(float[] vector) {
        double norm = 0.0;
        for (float v : vector) {
            norm += v * v;
        }
        norm = Math.sqrt(norm);
        if (norm > 0) {
            for (int i = 0; i < vector.length; i++) {
                vector[i] = (float) (vector[i] / norm);
            }
        }
        return vector;
    }
}
```

```java
/**
 * 热点问题挖掘服务 - 定时任务，从未命中日志中发现高频问题
 */
@Service
@Slf4j
public class FaqCandidateMiningService {
    
    @Autowired
    private FaqHitLogMapper hitLogMapper;
    
    @Autowired
    private FaqCandidateMapper candidateMapper;
    
    @Autowired
    private FaqItemMapper faqItemMapper;
    
    @Autowired
    private EmbeddingService embeddingService;
    
    @Autowired
    private LlmAdapter llmAdapter;
    
    /**
     * 每日凌晨 2:00 执行挖掘任务
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void dailyMiningTask() {
        log.info("FAQ candidate mining task started");
        
        // 1. 获取昨日未命中的问题（按学科+学段分组）
        LocalDate yesterday = LocalDate.now().minusDays(1);
        List<MissQueryGroup> groups = hitLogMapper
            .selectMissQueriesByDate(yesterday);
        
        for (MissQueryGroup group : groups) {
            try {
                mineGroup(group);
            } catch (Exception e) {
                log.error("Mining failed for group: {}-{}", 
                    group.getSubjectCode(), group.getStageLevel(), e);
            }
        }
        
        log.info("FAQ candidate mining task completed");
    }
    
    /**
     * 对一个学科+学段分组执行挖掘
     */
    private void mineGroup(MissQueryGroup group) {
        List<String> queries = group.getQueries();
        if (queries.size() < 5) {
            return; // 样本不足，跳过
        }
        
        // 2. 文本向量化
        List<float[]> vectors = embeddingService.embedBatch(queries);
        
        // 3. DBSCAN 聚类
        List<List<Integer>> clusters = dbscanCluster(
            vectors, 0.75, 5); // eps=0.75, min_samples=5
        
        // 4. 对每个聚类生成候选
        for (List<Integer> cluster : clusters) {
            if (cluster.size() < 5) continue;
            
            // 找到聚类中心问题（离中心最近的样本）
            int centerIdx = findClusterCenter(vectors, cluster);
            String centerQuery = queries.get(centerIdx);
            
            // 去重：与已有候选比对
            if (isDuplicateCandidate(centerQuery, group.getSubjectCode())) {
                continue;
            }
            
            // 去重：与已发布 FAQ 比对
            if (isDuplicatePublished(centerQuery, group.getSubjectCode(),
                group.getStageLevel())) {
                continue;
            }
            
            // 创建候选
            FaqCandidate candidate = new FaqCandidate();
            candidate.setNormalizedQuestion(centerQuery);
            candidate.setSampleQuestionsJson(
                buildSampleJson(queries, cluster, 20));
            candidate.setFrequency(cluster.size());
            candidate.setSubjectCode(group.getSubjectCode());
            candidate.setStageLevel(group.getStageLevel());
            candidate.setCentroidVector(
                floatsToBytes(vectors.get(centerIdx)));
            candidate.setFirstSeenAt(group.getFirstSeenAt());
            candidate.setLastSeenAt(group.getLastSeenAt());
            candidate.setStatus("DISCOVERED");
            
            // AI 生成候选回答
            String aiAnswer = generateAiCandidateAnswer(
                centerQuery, group);
            candidate.setAiGeneratedAnswer(aiAnswer);
            
            candidateMapper.insert(candidate);
            
            log.info("New FAQ candidate discovered: freq={}, subject={}, question={}",
                cluster.size(), group.getSubjectCode(), centerQuery);
        }
    }
    
    /**
     * DBSCAN 聚类
     */
    private List<List<Integer>> dbscanCluster(
            List<float[]> vectors, double eps, int minSamples) {
        
        int n = vectors.size();
        boolean[] visited = new boolean[n];
        boolean[] noise = new boolean[n];
        List<List<Integer>> clusters = new ArrayList<>();
        
        for (int i = 0; i < n; i++) {
            if (visited[i]) continue;
            visited[i] = true;
            
            List<Integer> neighbors = getNeighbors(vectors, i, eps);
            if (neighbors.size() < minSamples) {
                noise[i] = true;
                continue;
            }
            
            List<Integer> cluster = new ArrayList<>();
            cluster.add(i);
            
            Queue<Integer> queue = new LinkedList<>(neighbors);
            while (!queue.isEmpty()) {
                int j = queue.poll();
                if (noise[j]) continue;
                if (!visited[j]) {
                    visited[j] = true;
                    List<Integer> jNeighbors = getNeighbors(vectors, j, eps);
                    if (jNeighbors.size() >= minSamples) {
                        queue.addAll(jNeighbors);
                    }
                }
                if (!cluster.contains(j)) {
                    cluster.add(j);
                }
            }
            clusters.add(cluster);
        }
        
        return clusters;
    }
    
    private List<Integer> getNeighbors(List<float[]> vectors,
            int idx, double eps) {
        List<Integer> neighbors = new ArrayList<>();
        float[] center = vectors.get(idx);
        for (int i = 0; i < vectors.size(); i++) {
            if (i == idx) continue;
            double sim = cosineSimilarity(center, vectors.get(i));
            if (sim >= 1.0 - eps) {
                neighbors.add(i);
            }
        }
        return neighbors;
    }
    
    /**
     * AI 候选回答生成
     */
    private String generateAiCandidateAnswer(
            String question, MissQueryGroup group) {
        String prompt = String.format(
            "你是教育内容专家。请为以下%s%s年级学生的问题生成一个准确、清晰、适龄的回答。\n" +
            "要求：\n" +
            "1. 使用 Markdown 格式\n" +
            "2. 包含公式时使用 LaTeX\n" +
            "3. 语言简洁，分步讲解\n" +
            "4. 这个回答将作为教研团队编写正式FAQ的参考\n\n" +
            "问题：%s",
            group.getStageLevelName(), group.getSubjectName(),
            question
        );
        
        return llmAdapter.chat(prompt, "gpt-4");
    }
}
```

### 6.2 熔断降级机制

```java
/**
 * FAQ 匹配服务熔断器
 * 当 FAQ 子系统连续失败时，自动短路，直接降级到 LLM
 */
@Component
@Slf4j
public class FaqCircuitBreaker {
    
    private final CircuitBreakerConfig config = CircuitBreakerConfig.custom()
        .failureRateThreshold(50)           // 失败率阈值 50%
        .slowCallRateThreshold(80)          // 慢调用率阈值 80%
        .slowCallDurationThreshold(Duration.ofMillis(2000))  // 慢调用阈值 2s
        .minimumNumberOfCalls(50)           // 最少调用次数
        .slidingWindowSize(100)             // 滑动窗口
        .slidingWindowType(CountBased)
        .waitDurationInOpenState(Duration.ofSeconds(30))     // 熔断恢复等待
        .permittedNumberOfCallsInHalfOpenState(10)           // 半开探测数
        .build();
    
    private final CircuitBreaker circuitBreaker = CircuitBreaker.of("faqMatch", config);
    
    public <T> T execute(Supplier<T> supplier, Supplier<T> fallback) {
        return CircuitBreaker.decorateSupplier(circuitBreaker, supplier)
            .get();
    }
    
    // 当熔断器开启时，直接返回未命中
    public FaqMatchResult executeMatch(
            Supplier<FaqMatchResult> matchSupplier) {
        if (circuitBreaker.getState() == CircuitBreaker.State.OPEN) {
            log.warn("FAQ circuit breaker is OPEN, fast-fail to miss");
            FaqMatchResult result = FaqMatchResult.miss("CIRCUIT_OPEN");
            result.setLatencyMs(0);
            return result;
        }
        
        try {
            return circuitBreaker.executeSupplier(matchSupplier);
        } catch (CallNotPermittedException e) {
            log.warn("FAQ circuit breaker rejected call");
            return FaqMatchResult.miss("CIRCUIT_OPEN");
        } catch (Exception e) {
            log.error("FAQ match failed, falling back to miss", e);
            return FaqMatchResult.miss("INTERNAL_ERROR");
        }
    }
}
```
