# 教育内容协同创作与审校发布生产线引擎 - 详细设计

> **文档版本**：v1.0  
> **创建日期**：2026-06-18  
> **模块定位**：服务端 · 内容生产管理  
> **优先级**：P1（V1.0 版本上线）

---

## 1. 概述

### 1.1 功能目标

为 PrimeTop 内容运营团队提供一站式的教育内容协同创作、审校、发布流水线，支撑以下核心场景：

1. **多人协作创作**：学科教研人员、内容编辑、审校专家围绕同一内容项目并行工作。
2. **结构化生产流程**：从选题立项 → 初稿撰写 → 多级审校 → 试排版 → 发布上线 → 上线后迭代，形成完整闭环。
3. **批量生产管理**：新教材版本上线、寒暑假专题内容生产等批量场景的任务编排与进度追踪。
4. **AI 辅助提效**：集成 AI 能力辅助内容生成、格式规范化、知识点标注预填、质量初筛。
5. **质量管控体系**：多维质量评分、内容一致性检查、课标对齐校验、适龄性评估等多道质量门控。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 协作优先 | 支持多人同时编辑、评论、批注，避免锁等待 |
| 质量门控 | 每个状态转换必须通过对应级别的质量检查 |
| 可追溯 | 所有变更留痕，支持任意版本回溯与对比 |
| 可扩展 | 生产流程节点可配置，适配不同内容类型的差异化流程 |
| AI 增强而非替代 | AI 辅助生成草稿和建议，人工审核做最终决策 |

### 1.3 与现有模块的关系

| 关联模块 | 关系说明 |
|----------|----------|
| `教育内容审核工作流与多级审核管线` | 审核管线是本生产线审校环节的执行引擎 |
| `教育内容版本管理与教材同步更新引擎` | 版本管理是本生产线发布管理的基础设施 |
| `教材内容数字化与结构化生产管线` | 数字化生产是内容输入源之一 |
| `题目与题库服务` | 题目类内容经生产线审校后入库 |
| `知识点体系与教材映射引擎` | 内容创作时的知识点标注依赖此模块 |
| `AI-Prompt编排与场景模板系统` | AI 辅助创作调用 Prompt 模板 |
| `服务端-业务状态机与通用工作流引擎` | 本模块的内容状态流转基于通用工作流引擎实现 |

## 2. 核心概念与角色

### 2.1 角色定义

| 角色标识 | 角色名称 | 权限范围 |
|----------|----------|----------|
| `PROJECT_MANAGER` | 内容项目经理 | 创建项目、分配任务、管理进度、调整流程 |
| `SUBJECT_EXPERT` | 学科教研专家 | 撰写初稿、回复审校意见、修改内容 |
| `CONTENT_WRITER` | 内容编辑 | 撰写与编辑内容、格式规范化 |
| `REVIEWER_L1` | 一级审校员 | 基础审校：格式、错别字、知识点对齐 |
| `REVIEWER_L2` | 二级审校员 | 专业审校：学科准确性、教学法合理性 |
| `REVIEWER_L3` | 终审专家 | 终审把关：课标合规、品牌一致性 |
| `PUBLISHER` | 发布管理员 | 执行发布操作、管理上下线时间 |
| `ADMIN` | 系统管理员 | 配置生产流程模板、权限管理 |

```
项目 (Project)
 └── 批次 (Batch)         — 如"人教版数学七年级上册第三章"
     ├── 任务 (Task)      — 如"3.1 一元一次方程 知识点讲解"
     │   └── 内容块 (ContentBlock) — 如"概念引入"、"公式推导"、"例题"
```

### 4.2 状态定义

```typescript
enum TaskStatus {
  PENDING         = 'PENDING',          // 任务已创建，待分配撰写人
  DRAFTING        = 'DRAFTING',         // 撰写中
  AI_DRAFT        = 'AI_DRAFT',         // AI草稿生成完成，待人工编辑
  L1_REVIEW       = 'L1_REVIEW',        // 一级审校中
  L2_REVIEW       = 'L2_REVIEW',        // 二级审校中
  L3_REVIEW       = 'L3_REVIEW',        // 终审中
  REJECTED        = 'REJECTED',         // 被驳回（附带驳回级别和退回节点）
  READY_PUBLISH   = 'READY_PUBLISH',    // 审校通过，待发布
  PUBLISHED       = 'PUBLISHED',        // 已发布
  SCHEDULED       = 'SCHEDULED',        // 定时发布中
  ARCHIVED        = 'ARCHIVED',         // 已归档
  WITHDRAWN       = 'WITHDRAWN',        // 已下架
}
```

### 4.3 状态流转规则

```typescript
interface TransitionRule {
  from: TaskStatus;
  to: TaskStatus;
  action: string;
  requiredRole: string;
  conditions?: string[];
  hooks?: string[];  // 触发的副作用
}

const transitionRules: TransitionRule[] = [
  {
    from: TaskStatus.PENDING,
    to: TaskStatus.DRAFTING,
    action: 'assign',
    requiredRole: 'PROJECT_MANAGER',
    hooks: ['notifyAssignee', 'startSlaTimer']
  },
  {
    from: TaskStatus.PENDING,
    to: TaskStatus.AI_DRAFT,
    action: 'ai_generate',
    requiredRole: 'PROJECT_MANAGER',
    conditions: ['aiAssistEnabled'],
    hooks: ['callAiDraftService', 'notifyAssignee']
  },
  {
    from: TaskStatus.AI_DRAFT,
    to: TaskStatus.DRAFTING,
    action: 'start_edit',
    requiredRole: 'CONTENT_WRITER',
    hooks: ['recordAiToHumanTransition']
  },
  {
    from: TaskStatus.DRAFTING,
    to: TaskStatus.L1_REVIEW,
    action: 'submit',
    requiredRole: 'CONTENT_WRITER',
    conditions: ['minWordCount', 'knowledgeTagComplete', 'passAutoFormatCheck'],
    hooks: ['createVersion', 'runAutoChecks', 'notifyReviewer']
  },
  {
    from: TaskStatus.L1_REVIEW,
    to: TaskStatus.L2_REVIEW,
    action: 'approve',
    requiredRole: 'REVIEWER_L1',
    hooks: ['recordReviewResult', 'notifyReviewer']
  },
  {
    from: TaskStatus.L1_REVIEW,
    to: TaskStatus.REJECTED,
    action: 'reject',
    requiredRole: 'REVIEWER_L1',
    hooks: ['recordReviewResult', 'notifyWriter', 'incrementRejectCount']
  },
  {
    from: TaskStatus.REJECTED,
    to: TaskStatus.DRAFTING,
    action: 'restart_edit',
    requiredRole: 'CONTENT_WRITER',
    hooks: ['carryOverReviewComments']
  },
  {
    from: TaskStatus.L2_REVIEW,
    to: TaskStatus.L3_REVIEW,
    action: 'approve',
    requiredRole: 'REVIEWER_L2',
    hooks: ['recordReviewResult', 'notifyReviewer']
  },
  {
    from: TaskStatus.L2_REVIEW,
    to: TaskStatus.REJECTED,
    action: 'reject',
    requiredRole: 'REVIEWER_L2',
    hooks: ['recordReviewResult', 'notifyWriter']
  },
  {
    from: TaskStatus.L3_REVIEW,
    to: TaskStatus.READY_PUBLISH,
    action: 'approve',
    requiredRole: 'REVIEWER_L3',
    hooks: ['recordReviewResult', 'notifyPublisher']
  },
  {
    from: TaskStatus.L3_REVIEW,
    to: TaskStatus.REJECTED,
    action: 'reject',
    requiredRole: 'REVIEWER_L3',
    hooks: ['recordReviewResult', 'escalateReject']
  },
  {
    from: TaskStatus.READY_PUBLISH,
    to: TaskStatus.PUBLISHED,
    action: 'publish',
    requiredRole: 'PUBLISHER',
    hooks: ['pushToContentSystem', 'updateSearchIndex', 'notifyStakeholders']
  },
  {
    from: TaskStatus.READY_PUBLISH,
    to: TaskStatus.SCHEDULED,
    action: 'schedule',
    requiredRole: 'PUBLISHER',
    hooks: ['createScheduleJob']
  },
  {
    from: TaskStatus.PUBLISHED,
    to: TaskStatus.ARCHIVED,
    action: 'archive',
    requiredRole: 'PUBLISHER',
    hooks: ['archiveContent', 'redirectIfNeeded']
  },
  {
    from: TaskStatus.PUBLISHED,
    to: TaskStatus.WITHDRAWN,
    action: 'withdraw',
```

### 5.2 操作同步协议（基于 OT 的简化方案）

采用简化的 Operational Transformation 模型，操作类型包括：

```typescript
interface EditorOperation {
  opId: string;           // 操作唯一ID
  sessionId: string;      // 协作会话ID
  userId: number;         // 操作用户ID
  seq: number;            // 客户端操作序号
  timestamp: number;      // 时间戳

  type: 'insert' | 'delete' | 'format' | 'block';
  
  // 定位
  path: number[];         // 内容块路径 如 [0, 2, 1] = 第0块第2段第1个span
  offset?: number;        // 文本偏移量
  length?: number;        // 影响长度

  // 数据
  content?: string;       // 插入内容
  format?: Record<string, any>; // 格式属性
  blockType?: string;     // 块类型 段落/标题/公式/代码等
  
  // 版本
  baseVersion: number;    // 基于的文档版本
}
```

**服务端处理流程：**

```java
@Service
public class CollaborationEngine {
    
    /**
     * 处理客户端操作
     * 1. 接收操作并验证
     * 2. 对后续操作做变换（OT Transform）
     * 3. 应用到文档状态
     * 4. 广播给其他在线用户
     * 5. 持久化到操作日志
     */
    public ProcessResult processOperation(String sessionId, EditorOperation op) {
        CollaborationSession session = sessionManager.get(sessionId);
        
        // 1. 验证操作合法性
        validateOperation(session, op);
        
        // 2. 获取并发操作并做OT变换
        List<EditorOperation> concurrentOps = session.getOpsAfter(op.getBaseVersion());
        for (EditorOperation concurrent : concurrentOps) {
            op = otTransform(op, concurrent);
        }
        
        // 3. 应用到文档
        DocumentState docState = session.getDocumentState();
        docState.apply(op);
        
        // 4. 分配服务端序号
        long serverSeq = session.nextOpSeq();
        op.setServerSeq(serverSeq);
        
        // 5. 广播
        broadcastToParticipants(sessionId, op, excludeUserId = op.getUserId());
        
        // 6. 异步持久化
        asyncPersistOperation(sessionId, op);
        
        // 7. 触发自动保存检测
        autoSaveChecker.checkAndSave(sessionId);
        
        return ProcessResult.success(serverSeq, docState.getVersion());
    }
    
    /**
     * OT 变换核心算法（简化版）
     * 将 op1 相对于 op2 进行变换，使两者在对方已执行的情况下都能正确应用
     */
    private EditorOperation otTransform(EditorOperation op1, EditorOperation op2) {
        if (!isOverlapping(op1, op2)) {
            return op1; // 无重叠，无需变换
        }
        
        switch (op1.getType() + ":" + op2.getType()) {
            case "insert:insert":
                // 都在同一位置插入，按 userId 大小决定顺序
                if (op1.getPath().equals(op2.getPath()) 
                    && op1.getOffset() == op2.getOffset()) {
                    if (op1.getUserId() < op2.getUserId()) {
                        return op1; // op1 优先，op2 后移
                    } else {
                        return op1.withOffset(op1.getOffset() + op2.getContent().length());
                    }
                }
                break;
                
            case "insert:delete":
                if (op1.getOffset() > op2.getOffset()) {
                    int shift = Math.min(op2.getLength(), 
                                        op1.getOffset() - op2.getOffset());
                    return op1.withOffset(op1.getOffset() - shift);
                }
                break;
                
            case "delete:insert":
                if (op1.getOffset() <= op2.getOffset() 
                    && op1.getOffset() + op1.getLength() > op2.getOffset()) {
                    // 插入点在被删除范围内，扩展删除范围
                    return op1.withLength(op1.getLength() + op2.getContent().length());
                }
                break;
                
            case "delete:delete":
                return transformDeleteDelete(op1, op2);
        }
        return op1;
    }
}
```

### 5.3 段落级锁机制

为避免复杂的实时冲突，在以下场景采用段落级锁：

```typescript
interface SectionLock {
  sectionId: string;      // 段落/内容块ID
  lockedBy: number;       // 锁持有者userId
  lockedAt: number;       // 加锁时间戳
  ttl: number;            // 锁TTL(ms)，默认 60 秒
  lockType: 'soft' | 'hard';  // soft=其他人编辑时警告，hard=阻止编辑
}

// 加锁逻辑（通过 WebSocket 消息）
// 客户端聚焦某段落时发送 LOCK_REQUEST
// 服务端检查并响应 LOCK_GRANTED 或 LOCK_DENIED
// 客户端失焦或心跳超时自动释放

// Redis 实现
async function acquireSectionLock(
  taskId: number, 
  sectionId: string, 
  userId: number
): Promise<boolean> {
  const key = `lock:task:${taskId}:section:${sectionId}`;
  const result = await redis.set(key, userId, 'NX', 'PX', 60000);
  if (result === 'OK') return true;
  
  // 检查锁持有者是否是自己（重入）
  const holder = await redis.get(key);
  return Number(holder) === userId;
}
```

```java
@Service
public class AiDraftBatchService {
    
    /**
     * 批量生成AI初稿
     * 场景：新教材版本上线，需要批量生成章节讲解内容
     */
    @Async("contentProductionExecutor")
    public void batchGenerateDrafts(
        Long projectId, 
        AiDraftConfig config
    ) {
        List<ContentTask> tasks = taskService.getProjectTasks(projectId);
        
        // 分批处理，每批 5 个任务（避免API限流）
        Lists.partition(tasks, 5).forEach(batch -> {
            List<CompletableFuture<AiDraftResult>> futures = batch.stream()
                .map(task -> generateSingleDraft(task, config))
                .toList();
            
            CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
            
            // 更新项目进度
            projectService.updateProgress(projectId);
        });
        
        // 通知项目经理
        notificationService.notifyProjectManager(
            projectId, 
            "AI草稿批量生成完成",
            Map.of("totalTasks", tasks.size(), 
                   "successCount", successCount,
                   "failedCount", failedCount)
        );
    }
    
    private CompletableFuture<AiDraftResult> generateSingleDraft(
        ContentTask task, 
        AiDraftConfig config
    ) {
        return CompletableFuture.supplyAsync(() -> {
            try {
                // 1. 构建Prompt
                Map<String, Object> promptVars = Map.of(
                    "subject", task.getSubjectName(),
                    "grade", task.getGradeRange(),
                    "chapter", task.getChapterTitle(),
                    "knowledgePoints", task.getKnowledgePoints(),
                    "contentType", task.getContentType(),
                    "textbookEdition", task.getTextbookEdition(),
                    "targetLength", config.getTargetWords(),
                    "style", config.getStylePreference()
                );
                
                // 2. RAG检索相关知识库内容
                List<KnowledgeContext> contexts = ragService.retrieve(
                    task.getKnowledgePoints(),
                    task.getSubjectId(),
                    task.getGradeRange(),
                    topK = 5
                );
                promptVars.put("referenceContexts", contexts);
                
                // 3. 调用模型生成
                String prompt = promptTemplateService.render(
                    "DRAFT_GENERATION_" + task.getContentType(),
                    promptVars
                );
                
                AiResponse response = modelRouter.call(
                    ModelRequest.builder()
                        .prompt(prompt)
                        .model(config.getModelPreference())
                        .temperature(0.7)
                        .maxTokens(config.getMaxTokens())
                        .build()
                );
                
                // 4. 后处理
                StructuredContent content = contentParser.parse(
                    response.getContent(),
                    task.getContentType()
                );
                
                // 5. 保存为AI草稿版本
                contentVersionService.saveVersion(ContentVersion.builder()
                    .taskId(task.getId())
                    .versionNum(0)  // AI草稿为版本0
                    .contentData(content.toJson())
                    .changeType("AI_DRAFT")
                    .aiGenerated(true)
                    .aiAssistType("DRAFT_GENERATION")
                    .changedBy(task.getAssignedWriter())
                    .build()
                );
                
                // 6. 更新任务状态
                taskService.updateStatus(task.getId(), TaskStatus.AI_DRAFT);
                
                return AiDraftResult.success(task.getId(), content);
                
            } catch (Exception e) {
                log.error("AI草稿生成失败 task={}", task.getId(), e);
                taskService.recordFailure(task.getId(), e.getMessage());
                return AiDraftResult.failed(task.getId(), e.getMessage());
            }
        }, contentProductionExecutor);
    }
}
```

```java
@Service
public class AiQualityPreCheckService {
    
    /**
     * 内容提交前的自动质量检查
     * 作为 DRAFTING → L1_REVIEW 的前置条件
     */
    public QualityCheckResult preCheck(Long taskId, Long versionId) {
        ContentVersion version = contentVersionService.getById(versionId);
        ContentTask task = taskService.getById(taskId);
        
        List<QualityCheckItem> checks = new ArrayList<>();
        
        // 1. 格式规范检查（规则引擎，非AI）
        checks.addAll(formatValidator.validate(version, task.getContentType()));
        
        // 2. 知识点标注完整性检查
        checks.addAll(knowledgeTagValidator.validate(version));
        
        // 3. AI 内容准确性检查
        AccuracyCheckResult accuracy = aiAccuracyCheck(version, task);
        checks.addAll(accuracy.getItems());
        
        // 4. AI 适龄性检查
        AgeAppropriatenessResult ageCheck = ageAppropriatenessCheck(version, task);
        checks.addAll(ageCheck.getItems());
        
        // 5. AI 课标对齐检查
        CurriculumAlignmentResult alignment = curriculumAlignmentCheck(version, task);
        checks.addAll(alignment.getItems());
        
        // 6. 抄袭/原创性检测
        OriginalityResult originality = originalityCheck(version);
        checks.addAll(originality.getItems());
        
        // 汇总
        boolean passed = checks.stream().noneMatch(c -> c.getSeverity() == Severity.BLOCK);
        double score = calculateScore(checks);
        
        return QualityCheckResult.builder()
            .taskId(taskId)
            .versionNum(version.getVersionNum())
            .passed(passed)
            .score(score)
            .items(checks)
            .summary(generateSummary(checks))
            .build();
    }
    
    /**
     * AI 准确性检查：调用模型验证内容中是否存在事实性错误
     */
    private AccuracyCheckResult aiAccuracyCheck(
        ContentVersion version, ContentTask task
    ) {
        String prompt = promptTemplateService.render("QUALITY_ACCURACY_CHECK", Map.of(
            "content", version.getContentData(),
            "subject", task.getSubjectName(),
            "knowledgePoints", task.getKnowledgePoints(),
            "gradeLevel", task.getGradeRange()
        ));
        
        AiResponse response = modelRouter.call(ModelRequest.builder()
            .prompt(prompt)
            .model("reasoning-enhanced")  // 使用推理增强模型
            .temperature(0.1)  // 低温度保证稳定性
            .maxTokens(2000)
            .build()
        );
        
        return accuracyCheckParser.parse(response.getContent());
    }
}
```

### 9.2 自动质量门控规则

```java
@Component
public class QualityGateChecker {
    
    /**
     * 内容提交时的自动门控检查
     * 决定是否允许进入审校环节
     */
    public GateCheckResult check(Long taskId, Long versionId) {
        ContentVersion version = versionService.getById(versionId);
        ContentTask task = taskService.getById(taskId);
        
        List<GateRule> rules = gateRuleEngine.getRules(task.getContentType());
        List<GateViolation> violations = new ArrayList<>();
        
        for (GateRule rule : rules) {
            GateViolation v = switch (rule.getType()) {
                case WORD_COUNT_MIN -> checkMinWords(version, rule);
                case WORD_COUNT_MAX -> checkMaxWords(version, rule);
                case KNOWLEDGE_TAG_REQUIRED -> checkKnowledgeTags(version, rule);
                case FORMULA_FORMAT -> checkFormulaFormat(version);
                case IMAGE_ALT_TEXT -> checkImageAltText(version);
                case DIFFICULTY_SET -> checkDifficultySet(version);
                case COGNITIVE_LEVEL_SET -> checkCognitiveLevel(version);
                case CURRICULUM_ALIGNED -> checkCurriculumAlignment(version, task);
                case PLAGIARISM -> checkOriginality(version, rule);
                case AI_HALLUCINATION -> checkAiHallucination(version, task);
            };
            if (v != null) violations.add(v);
        }
        
        // 判定
        boolean hasBlock = violations.stream()
            .anyMatch(v -> v.getSeverity() == Severity.BLOCK);
        
        return GateCheckResult.builder()
            .passed(!hasBlock)
            .violations(violations)
            .suggestions(generateSuggestions(violations))
            .build();
    }
}
```

### 10.1 新教材版本上线场景

```java
@Service
public class TextbookLaunchProductionService {
    
    /**
     * 新教材版本批量生产编排
     * 
     * 流程:
     * 1. 从教材知识图谱导入章节结构
     * 2. 自动生成任务清单（按模板拆分）
     * 3. AI批量生成草稿
     * 4. 分配给学科编辑团队
     * 5. 并行审校流水线
     * 6. 分批发布上线
     */
    public TextbookLaunchPlan planTextbookLaunch(
        Long textbookId, 
        List<Long> chapterIds,
        LocalDate targetDate
    ) {
        // 1. 获取章节-知识点结构
        List<ChapterStructure> structures = chapterService
            .getChapterStructures(textbookId, chapterIds);
        
        // 2. 按内容类型模板生成任务清单
        List<ContentTaskSpec> taskSpecs = new ArrayList<>();
        for (ChapterStructure chapter : structures) {
            // 每个知识点生成: 讲解 + 例题 + 基础练习
            for (KnowledgePoint kp : chapter.getKnowledgePoints()) {
                taskSpecs.add(createTaskSpec(chapter, kp, ContentType.KNOWLEDGE_EXPLANATION));
                taskSpecs.add(createTaskSpec(chapter, kp, ContentType.WORKED_EXAMPLE, count=2));
                taskSpecs.add(createTaskSpec(chapter, kp, ContentType.PRACTICE_ITEM, count=5));
            }
            // 每个章节额外生成: 总结 + 复习指南
            taskSpecs.add(createTaskSpec(chapter, null, ContentType.SUMMARY));
            taskSpecs.add(createTaskSpec(chapter, null, ContentType.REVIEW_GUIDE));
        }
        
        // 3. 计算工作量并分配
        WorkloadEstimate estimate = estimateWorkload(taskSpecs);
        List<TeamCapacity> capacities = teamService.getAvailableCapacity(
            textbookId.getSubjectId(), targetDate
        );
        
        AssignmentPlan assignment = assignTasks(taskSpecs, capacities, targetDate);
        
        // 4. 生成分批计划
        List<Batch> batches = planBatches(assignment, targetDate);
        
        return TextbookLaunchPlan.builder()
            .textbookId(textbookId)
            .totalTasks(taskSpecs.size())
            .estimatedWorkload(estimate)
            .batches(batches)
            .assignmentPlan(assignment)
            .build();
    }
}
```

### 10.2 并行审校调度

```java
@Service
public class ParallelReviewScheduler {
    
    /**
     * 多任务并行审校调度
     * 按审校人负载和优先级智能分配
     */
    public void scheduleReviews(List<Long> readyTaskIds) {
        // 获取所有可用审校人员
        Map<ReviewLevel, List<ReviewerCapacity>> reviewerPool = 
            getReviewerCapacities(ReviewLevel.values());
        
        // 按优先级排序任务
        List<ContentTask> tasks = taskService.listByIds(readyTaskIds).stream()
            .sorted(Comparator
                .comparing(ContentTask::getPriority)
                .thenComparing(ContentTask::getSubmitDeadline))
            .toList();
        
        for (ContentTask task : tasks) {
            ReviewLevel level = getCurrentReviewLevel(task);
            List<ReviewerCapacity> candidates = reviewerPool.get(level);
            
            // 选择负载最低且有对应学科能力的审校人
            ReviewerCapacity best = candidates.stream()
                .filter(r -> r.canReview(task.getSubjectId()))
                .min(Comparator.comparing(ReviewerCapacity::getCurrentLoad))
                .orElse(null);
            
            if (best != null) {
                assignReviewer(task.getId(), level, best.getUserId());
                best.incrementLoad();
            } else {
                // 无可用审校人，加入待分配队列
                pendingReviewQueue.offer(task.getId());
                alertService.alertReviewerShortage(level, task.getSubjectId());
            }
        }
    }
}
```

## 12. 性能考量

### 12.1 性能指标目标

| 指标 | 目标值 |
|------|--------|
| 协同编辑操作延迟（同会话内） | < 200ms (P95) |
| WebSocket消息广播延迟 | < 500ms (P95) |
| AI草稿单个任务生成时间 | < 30s |
| AI批量生成并发数 | 5 任务/批 |
| 质量预检耗时 | < 10s |
| 项目看板查询响应 | < 500ms |
| 内容版本保存响应 | < 1s |

### 12.2 关键优化点

**协同编辑性能：**
- Redis 存储实时操作日志，每 30 秒批量刷入 MySQL
- 操作日志保留最近 500 条在内存，超出部分走懒加载
- WebSocket 消息采用二帧压缩（Protobuf 编码）

**批量生成性能：**
- 使用有界线程池（core=5, max=10），防止模型 API 限流
- 批量结果写入使用 `INSERT ... VALUES (...), (...), ...` 批量 SQL

**查询优化：**
- 项目看板统计数据通过定时预计算（每 5 分钟刷新）
- 审校人负载查询使用 Redis 计数器实时维护

| SLA | Service Level Agreement，服务级别协议（此处指各环节的时限要求） |
| 质量门控 | Quality Gate，内容流转到下一环节前必须通过的自动检查点 |
| 段落锁 | Section Lock，协同编辑时对特定内容块的临时编辑排他控制 |
| AI草稿 | 由大模型自动生成的初始内容，需人工编辑修改后才能进入审校 |
