# 服务端-学生用户学习抗挫力评估与成长型思维培养辅助引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责对学生在学习过程中面对困难和挫折时的行为模式进行持续追踪、量化评估，并基于评估结果推荐针对性的成长型思维（Growth Mindset）培养策略与干预方案。

核心目标：帮助学生从"害怕失败、回避困难"转化为"接受挑战、从错误中学习"，最终提升学习韧性和长期学业表现。

### 1.2 设计背景

教育心理学研究表明（Carol Dweck, Angela Duckworth 等），学生的学习抗挫力（Academic Resilience）和成长型思维（Growth Mindset）是比智力更重要的学业成功预测因子。具体表现为：

- **固定型思维学生**：回避挑战、面对失败容易放弃、认为能力是天生的不可改变
- **成长型思维学生**：主动迎接挑战、将失败视为学习机会、相信努力能提升能力

PrimeTop 作为全学段 AI 辅助学习平台，拥有独特的数据优势：可以观察到学生在 AI 对话中的提问方式、在练习中的答题行为、在错题本中的复习习惯等微观学习行为，从而构建比传统问卷更客观、更及时的抗挫力画像。

### 1.3 与已有模块的边界

| 已有模块 | 关系 | 本模块差异 |
|---------|------|-----------|
| 学习动力量化与学习倦怠预警引擎 | 关注学习能量消耗与倦怠趋势 | 本模块关注面对困难时的行为反应模式 |
| 学生心理状态建模与学习动机激励策略引擎 | 关注整体心理与动机水平 | 本模块专注"挫折反应"这一垂直维度 |
| 学生学习投入度多维量化与学习效能综合评估引擎 | 从投入度与效能角度度量 | 本模块从"面对困难的坚持度"角度度量 |
| 学习行为异常检测与作弊行为识别服务 | 关注异常行为与作弊 | 本模块关注正常范围内的行为中的心理信号 |
| AI辅导对话情感感知与自适应回应策略引擎 | 实时感知情绪并调整回应 | 本模块做长周期评估与培养策略推荐 |

### 1.4 适用范围

- **适用学段**：小学三年级以上（需具备一定的独立答题行为数据量）
- **数据来源**：练习答题、AI对话、错题复习、学习计划执行等多模块行为日志
- **评估周期**：周级/月级/学期级
- **干预方式**：推荐给AI辅导引擎、学习规划引擎、内容推荐引擎执行

## 2. 核心概念定义

### 2.1 学习抗挫力（Academic Resilience）

学生在学业挫折情境中恢复并继续学习的能力，包含三个维度：

| 维度 | 定义 | 可观测指标 |
|------|------|-----------|
| **坚持度 (Persistence)** | 面对困难题目时的持续尝试时长和尝试次数 | 单题耗时、重试次数、放弃率 |
| **恢复力 (Recovery)** | 经历失败后的表现恢复速度 | 失败后下一题正确率变化、失败后学习时长变化 |
| **挑战接受度 (Challenge Acceptance)** | 主动选择困难任务的倾向 | 选题难度偏好、困难题目完成率 |

### 2.2 成长型思维（Growth Mindset）

学生关于智力与能力可塑性的内隐信念，通过行为信号间接度量：

| 信号类型 | 固定型思维表现 | 成长型思维表现 |
|---------|--------------|--------------|
| 归因方式 | "我就是数学不好" | "这道题我还没掌握方法" |
| 困难反应 | 直接放弃/要求看答案 | 追问解题思路/换种讲法 |
| 错误态度 | 做错后跳过不看解析 | 仔细看解析并加入错题本 |
| 努力信念 | "学了也没用" | "多练就能进步" |
| 反馈响应 | 忽略AI的建议 | 根据建议调整后续行为 |

### 2.3 抗挫力指数（Resilience Index, RI）

综合量化指标，范围 0-100，通过多维度信号融合计算。

## 3. 数据结构设计

### 3.1 核心数据表

#### 3.1.1 `student_resilience_profile` — 学生抗挫力画像

```sql
CREATE TABLE student_resilience_profile (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id          BIGINT NOT NULL COMMENT '学生ID',
    snapshot_date       DATE NOT NULL COMMENT '快照日期',

    -- 综合指数
    resilience_index    DECIMAL(5,2) NOT NULL DEFAULT 50.00 COMMENT '抗挫力指数 0-100',
    mindset_score       DECIMAL(5,2) NOT NULL DEFAULT 50.00 COMMENT '成长型思维得分 0-100 (越高越偏成长型)',

    -- 三维分项
    persistence_score   DECIMAL(5,2) NOT NULL DEFAULT 50.00 COMMENT '坚持度得分',
    recovery_score      DECIMAL(5,2) NOT NULL DEFAULT 50.00 COMMENT '恢复力得分',
    challenge_score     DECIMAL(5,2) NOT NULL DEFAULT 50.00 COMMENT '挑战接受度得分',

    -- 变化趋势
    ri_trend_7d         DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT '近7天RI变化量',
    ri_trend_30d        DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT '近30天RI变化量',
    ri_volatility       DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT 'RI波动率(标准差)',

    -- 标签
    mindset_type        ENUM('FIXED','MIXED','GROWTH') NOT NULL DEFAULT 'MIXED' COMMENT '思维类型分类',
    risk_level          ENUM('HEALTHY','WATCH','AT_RISK','CRITICAL') NOT NULL DEFAULT 'HEALTHY' COMMENT '风险等级',

    -- 上下文
    data_window_days    INT NOT NULL DEFAULT 30 COMMENT '本次评估的数据窗口(天)',
    evidence_count      INT NOT NULL DEFAULT 0 COMMENT '支撑评估的行为事件数',
    confidence          DECIMAL(3,2) NOT NULL DEFAULT 0.00 COMMENT '评估置信度 0-1',

    insight_summary     TEXT COMMENT 'AI生成的自然语言洞察摘要',
    recommended_actions JSON COMMENT '推荐干预策略列表',

    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE KEY uk_student_date (student_id, snapshot_date),
    INDEX idx_snapshot (snapshot_date),
    INDEX idx_risk (risk_level, snapshot_date),
    INDEX idx_mindset (mindset_type, snapshot_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生抗挫力画像快照表';
```

#### 3.1.2 `frustration_event` — 挫折事件记录

```sql
CREATE TABLE frustration_event (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    event_id            VARCHAR(32) NOT NULL UNIQUE COMMENT '事件唯一ID',
    student_id          BIGINT NOT NULL COMMENT '学生ID',
    session_id          VARCHAR(64) COMMENT '学习会话ID',

    -- 事件来源
    source_module       ENUM('PRACTICE','AI_DIALOG','MISTAKE_REVIEW','STUDY_PLAN','EXAM') NOT NULL COMMENT '来源模块',
    source_entity_id    BIGINT COMMENT '来源实体ID(题目ID/对话ID等)',

    -- 挫折情境
    frustration_type    ENUM('WRONG_ANSWER','TIMEOUT','GIVE_UP','HINT_REQUEST',
                            'ANSWER_PEEK','REPEATED_WRONG','SKIP','EMOTIONAL_SIGNAL',
                            'PLAN_ABANDON','DIFFICULTY_AVOIDANCE') NOT NULL COMMENT '挫折类型',
    subject             VARCHAR(20) COMMENT '学科',
    knowledge_point_id  BIGINT COMMENT '关联知识点ID',
    difficulty_level    DECIMAL(3,1) COMMENT '题目/内容难度',

    -- 挫折前行为
    attempts_before     INT DEFAULT 0 COMMENT '挫折前尝试次数',
    time_spent_seconds  INT DEFAULT 0 COMMENT '挫折前耗时(秒)',
    hints_used          INT DEFAULT 0 COMMENT '挫折前使用提示次数',

    -- 挫折后行为（关键指标）
    post_action         ENUM('PERSIST_RETRY','VIEW_EXPLANATION','ASK_AI_HELP',
                            'SKIP_AND_CONTINUE','ADD_TO_MISTAKE','GIVE_UP_SESSION',
                            'SWITCH_SUBJECT','EMOTIONAL_BREAKDOWN','CHEAT_ATTEMPT') COMMENT '挫折后行为',
    time_to_recovery    INT COMMENT '恢复耗时(秒), NULL表示未恢复',
    next_correct        BOOLEAN COMMENT '后续是否答对(若适用)',

    -- 行为信号强度
    signal_strength     DECIMAL(3,2) NOT NULL DEFAULT 0.50 COMMENT '信号强度 0-1',
    growth_signal       BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否为成长型思维信号',

    -- 上下文
    grade_level         VARCHAR(20) COMMENT '学生年级',
    study_time_of_day   VARCHAR(10) COMMENT '学习时段(MORNING/AFTERNOON/EVENING/NIGHT)',

    event_time          DATETIME NOT NULL COMMENT '事件发生时间',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_student_time (student_id, event_time),
    INDEX idx_type (frustration_type, event_time),
    INDEX idx_post_action (post_action),
    INDEX idx_growth (growth_signal, event_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生学习挫折事件记录表';
```

#### 3.1.3 `persistence_tracking` — 题目级坚持度追踪

```sql
CREATE TABLE persistence_tracking (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    student_id          BIGINT NOT NULL,
    question_id         BIGINT NOT NULL,
    practice_session_id VARCHAR(64) NOT NULL,

    -- 题目属性
    subject             VARCHAR(20) NOT NULL,
    difficulty          DECIMAL(3,1) NOT NULL COMMENT '题目难度 1-10',
    knowledge_point_ids JSON COMMENT '题目关联知识点',

    -- 行为数据
    attempt_count       INT NOT NULL DEFAULT 1 COMMENT '尝试次数',
    first_attempt_time  DATETIME NOT NULL COMMENT '首次尝试时间',
    final_outcome       ENUM('CORRECT','WRONG','GIVE_UP','TIMEOUT') NOT NULL COMMENT '最终结果',
    total_time_seconds  INT NOT NULL COMMENT '总耗时(秒)',

    -- 坚持度信号
    hint_usage_count    INT DEFAULT 0 COMMENT '使用提示次数',
    answer_peeked       BOOLEAN DEFAULT FALSE COMMENT '是否提前看了答案',
    explanation_read    BOOLEAN DEFAULT FALSE COMMENT '是否阅读了解析',
    explanation_read_time INT DEFAULT 0 COMMENT '解析阅读时长(秒)',

    -- AI交互
    asked_ai_for_help   BOOLEAN DEFAULT FALSE COMMENT '是否向AI求助',
    ai_interaction_id   VARCHAR(64) COMMENT 'AI对话ID',

    -- 计算字段
    persistence_score   DECIMAL(3,2) COMMENT '本题坚持度得分 0-1',
    is_challenge_question BOOLEAN DEFAULT FALSE COMMENT '是否为挑战题(难度≥学生能力+1.5)',

    answered_at         DATETIME COMMENT '最终答题时间',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_student_time (student_id, first_attempt_time),
    INDEX idx_outcome (final_outcome, difficulty),
    INDEX idx_challenge (is_challenge_question)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='题目级坚持度追踪表';
```

#### 3.1.5 `resilience_intervention` — 干预策略执行记录

```sql
CREATE TABLE resilience_intervention (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    intervention_id     VARCHAR(32) NOT NULL UNIQUE,
    student_id          BIGINT NOT NULL,

    -- 触发
    trigger_type        ENUM('LOW_RI','RI_DECLINE','FIXED_MINDSET_SPIKE',
                            'GIVE_UP_PATTERN','CHALLENGE_AVOIDANCE',
                            'POST_FAILURE_COLLAPSE','PROACTIVE','TEACHER_REQUEST') NOT NULL COMMENT '触发类型',
    trigger_data        JSON COMMENT '触发数据快照',

    -- 策略
    strategy_code       VARCHAR(50) NOT NULL COMMENT '策略编码',
    strategy_category   ENUM('CONTENT','INTERACTION','NOTIFICATION','PLAN_ADJUSTMENT','PARENT_REPORT') NOT NULL,
    strategy_detail     JSON NOT NULL COMMENT '策略具体内容',

    -- 执行
    target_module       VARCHAR(50) NOT NULL COMMENT '执行模块',
    execution_status    ENUM('PENDING','EXECUTED','FAILED','CANCELLED','EXPIRED') NOT NULL DEFAULT 'PENDING',
    executed_at         DATETIME,

    -- 效果追踪
    effectiveness_score DECIMAL(3,2) COMMENT '策略效果得分 0-1',
    measured_at         DATETIME COMMENT '效果测量时间',
    measurement_data    JSON COMMENT '效果测量数据',

    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_student_time (student_id, created_at),
    INDEX idx_status (execution_status),
    INDEX idx_strategy (strategy_code, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='抗挫力干预策略执行记录表';
```

### 5.1 题目级坚持度评分

```python
def calculate_question_persistence(
    difficulty: float,          # 题目难度 1-10
    student_ability: float,     # 学生该知识点能力 1-10
    attempt_count: int,         # 尝试次数
    total_time: int,            # 总耗时(秒)
    final_outcome: str,         # 最终结果
    hint_count: int,            # 提示使用次数
    answer_peeked: bool,        # 是否偷看答案
    explanation_read: bool,     # 是否读了解析
    asked_ai: bool,             # 是否向AI求助
    expected_time: int = 180    # 预期完成时间(秒)
) -> dict:
    """
    计算单道题目的坚持度得分。
    返回 {score: 0-1, is_challenge: bool, signals: [...]}
    """
    is_challenge = difficulty >= (student_ability + 1.5)

    # --- 1. 基础坚持分（基于尝试和时间投入） ---
    time_ratio = min(total_time / max(expected_time, 60), 3.0)  # 上限3倍

    if final_outcome == "CORRECT":
        if attempt_count == 1:
            base_score = 0.90  # 一次做对
        else:
            # 多次尝试后做对：尝试越多说明越坚持，但也可能说明能力不足
            attempt_bonus = min(attempt_count * 0.08, 0.24)
            base_score = 0.65 + attempt_bonus
            # 如果是挑战题，额外加分
            if is_challenge:
                base_score = min(base_score + 0.10, 1.0)

    elif final_outcome == "WRONG":
        if attempt_count >= 3 and total_time > expected_time:
            base_score = 0.55  # 努力尝试但没做对
        elif attempt_count >= 2:
            base_score = 0.40
        else:
            base_score = 0.20  # 很快放弃

    elif final_outcome == "GIVE_UP":
        if total_time > expected_time * 1.5 and attempt_count >= 2:
            base_score = 0.35  # 努力后放弃
        else:
            base_score = 0.10  # 快速放弃

    elif final_outcome == "TIMEOUT":
        base_score = 0.45  # 超时(至少没有主动放弃)

    # --- 2. 学习行为调节分 ---
    adjustments = []

    # 正向行为加分
    if explanation_read and not answer_peeked:
        adjustments.append(("read_explanation", +0.08))
    if asked_ai and not answer_peeked:
        adjustments.append(("asked_ai_help", +0.06))
    if hint_count > 0 and hint_count <= 3:
        adjustments.append(("used_hints_moderately", +0.04))

    # 负向行为减分
    if answer_peeked:
        adjustments.append(("peeked_answer", -0.15))
    if hint_count > 5:
        adjustments.append(("hint_overuse", -0.08))
    if attempt_count > 5 and final_outcome != "CORRECT":
        adjustments.append(("blind_guessing", -0.10))

    # --- 3. 难度调节 ---
    if is_challenge and final_outcome in ("CORRECT", "WRONG"):
        if attempt_count >= 2:
            adjustments.append(("challenge_persistence", +0.08))

    # --- 4. 综合得分 ---
    score = base_score + sum(adj for _, adj in adjustments)
    score = max(0.0, min(1.0, score))

    signals = [name for name, _ in adjustments]

    return {
        "score": round(score, 2),
        "is_challenge": is_challenge,
        "signals": signals,
        "base_score": round(base_score, 2)
    }
```

### 5.2 恢复力评分

```python
def calculate_recovery_score(
    failure_events: list[dict],   # 近期失败事件序列
    post_failure_results: list[dict]  # 每次失败后的表现数据
) -> dict:
    """
    计算学生的恢复力得分。
    分析失败事件后的学习行为表现变化。
    """
    if not failure_events:
        return {"score": 0.50, "confidence": 0.0, "detail": "insufficient_data"}

    recovery_scores = []

    for i, failure in enumerate(failure_events):
        post = post_failure_results[i] if i < len(post_failure_results) else {}

        # --- 维度1: 失败后下一题正确率变化 ---
        pre_accuracy = failure.get("pre_accuracy", 0.65)
        post_accuracy = post.get("next_accuracy", 0.50)
        accuracy_delta = post_accuracy - pre_accuracy

        if accuracy_delta >= 0:
            # 没有下降甚至提升 → 高恢复力
            acc_score = 0.80
        elif accuracy_delta >= -0.10:
            # 小幅下降 → 中等恢复力
            acc_score = 0.60
        elif accuracy_delta >= -0.25:
            # 明显下降但未崩溃
            acc_score = 0.40
        else:
            # 严重下降 → 低恢复力
            acc_score = 0.20

        # --- 维度2: 失败后行为选择 ---
        post_action = post.get("action", "SKIP_AND_CONTINUE")
        action_scores = {
            "VIEW_EXPLANATION": 0.90,    # 主动看解析
            "ASK_AI_HELP": 0.85,         # 主动求助
            "ADD_TO_MISTAKE": 0.80,      # 加入错题本
            "PERSIST_RETRY": 0.75,       # 再次尝试
            "SKIP_AND_CONTINUE": 0.50,   # 跳过继续
            "SWITCH_SUBJECT": 0.30,      # 换科目
            "GIVE_UP_SESSION": 0.15,     # 放弃整个会话
        }
        action_score = action_scores.get(post_action, 0.50)

        # --- 维度3: 恢复速度 ---
        recovery_time = post.get("time_to_recovery")  # 秒
        if recovery_time is None:
            time_score = 0.30  # 未恢复
        elif recovery_time < 60:
            time_score = 0.90
        elif recovery_time < 180:
            time_score = 0.70
        elif recovery_time < 600:
            time_score = 0.50
        else:
            time_score = 0.30

        # --- 维度4: 后续会话回归 ---
        next_session_resumed = post.get("next_session_resumed", True)
        next_session_accuracy = post.get("next_session_accuracy", pre_accuracy)
        if next_session_resumed and next_session_accuracy >= pre_accuracy * 0.9:
            comeback_score = 0.85
        else:
            comeback_score = 0.35

        # 加权综合
        event_recovery = (
            acc_score * 0.30 +
            action_score * 0.25 +
            time_score * 0.25 +
            comeback_score * 0.20
        )
        recovery_scores.append(event_recovery)

    avg_score = sum(recovery_scores) / len(recovery_scores)

    # 近期事件权重更高（指数衰减）
    if len(recovery_scores) > 1:
        weights = [0.9 ** (len(recovery_scores) - 1 - i) for i in range(len(recovery_scores))]
        weighted_score = sum(s * w for s, w in zip(recovery_scores, weights)) / sum(weights)
    else:
        weighted_score = avg_score

    confidence = min(len(failure_events) / 10.0, 1.0)

    return {
        "score": round(weighted_score, 2),
        "confidence": round(confidence, 2),
        "sample_size": len(failure_events),
        "trend": "improving" if recovery_scores[-1] > recovery_scores[0] else "declining" if recovery_scores[-1] < recovery_scores[0] else "stable"
    }
```

### 5.3 挑战接受度评分

```python
def calculate_challenge_acceptance(
    question_selection_logs: list[dict],  # 选题记录
    difficulty_preferences: dict,         # 难度偏好统计
    challenge_completion: dict             # 挑战题完成情况
) -> dict:
    """
    计算学生主动接受挑战的倾向。
    """
    # --- 维度1: 难度选择偏好 ---
    # 对比学生选题难度分布与同班平均水平
    avg_difficulty_chosen = difficulty_preferences.get("avg_difficulty", 5.0)
    peer_avg_difficulty = difficulty_preferences.get("peer_avg", 5.5)
    difficulty_appetite = avg_difficulty_chosen / max(peer_avg_difficulty, 1.0)

    if difficulty_appetite >= 1.1:
        diff_score = 0.85
    elif difficulty_appetite >= 1.0:
        diff_score = 0.70
    elif difficulty_appetite >= 0.9:
        diff_score = 0.50
    else:
        diff_score = 0.30

    # --- 维度2: 挑战题完成率 ---
    challenge_attempted = challenge_completion.get("attempted", 0)
    challenge_completed = challenge_completion.get("completed", 0)
    challenge_completion_rate = challenge_completed / max(challenge_attempted, 1)

    if challenge_completion_rate >= 0.7:
        completion_score = 0.85
    elif challenge_completion_rate >= 0.5:
        completion_score = 0.65
    elif challenge_completion_rate >= 0.3:
        completion_score = 0.45
    else:
        completion_score = 0.25

    # --- 维度3: "挑战题"按钮点击率（如果有此UI） ---
    challenge_button_clicks = question_selection_logs.count(
        lambda q: q.get("selection_type") == "CHALLENGE"
    )
    total_selections = max(len(question_selection_logs), 1)
    challenge_ratio = challenge_button_clicks / total_selections

    if challenge_ratio >= 0.20:
        selection_score = 0.85
    elif challenge_ratio >= 0.10:
        selection_score = 0.65
    elif challenge_ratio >= 0.05:
        selection_score = 0.50
    else:
        selection_score = 0.35

    # --- 综合得分 ---
    score = (
        diff_score * 0.40 +
        completion_score * 0.35 +
        selection_score * 0.25
    )

    return {
        "score": round(score, 2),
        "difficulty_appetite": round(difficulty_appetite, 2),
        "challenge_completion_rate": round(challenge_completion_rate, 2),
        "challenge_selection_ratio": round(challenge_ratio, 2)
    }
```

```python
def detect_mindset_signals_fast(text: str) -> list[dict]:
    """
    基于关键词的快速思维信号检测。
    用于实时场景（AI对话中流式检测）。
    """
    import re

    signals = []
    text_lower = text.lower()

    for polarity, categories in MINDSET_KEYWORDS.items():
        for category, patterns in categories.items():
            for pattern in patterns:
                match = re.search(pattern, text_lower)
                if match:
                    signals.append({
                        "polarity": polarity,
                        "category": category,
                        "matched_text": match.group(),
                        "signal_strength": 0.6 if polarity == "FIXED" else 0.7,
                        "detection_method": "KEYWORD"
                    })

    return signals
```

```python
class MindsetTextClassifier:
    """
    使用轻量级文本分类模型检测成长型/固定型思维信号。
    基于教育心理学语料微调的BERT分类器。
    """

    def __init__(self):
        # 模型路径：基于 chinese-roberta-wwm-ext 微调
        # 标签：GROWTH_POSITIVE / FIXED_NEGATIVE / NEUTRAL
        # 输入：学生AI对话消息文本
        # 输出：三分类概率 + 关键短语高亮
        self.model = None  # lazy load
        self.tokenizer = None
        self.confidence_threshold = 0.65
        self.min_text_length = 6

    def classify(self, text: str, context: dict = None) -> dict:
        """
        对学生文本进行思维倾向分类。

        Args:
            text: 学生输入的文本
            context: 上下文信息(学科、年级、对话历史等)

        Returns:
            {
                "polarity": "GROWTH" | "FIXED" | "NEUTRAL",
                "confidence": float,
                "scores": {"GROWTH": 0.7, "FIXED": 0.2, "NEUTRAL": 0.1},
                "key_phrases": [...]
            }
        """
        if len(text) < self.min_text_length:
            return self._default_result()

        # 先走关键词快速检测
        fast_signals = detect_mindset_signals_fast(text)
        if fast_signals and any(s["signal_strength"] > 0.8 for s in fast_signals):
            # 强信号直接返回，不需要走模型
            strongest = max(fast_signals, key=lambda s: s["signal_strength"])
            return {
                "polarity": strongest["polarity"],
                "confidence": strongest["signal_strength"],
                "scores": None,
                "key_phrases": [s["matched_text"] for s in fast_signals],
                "source": "KEYWORD_FAST_PATH"
            }

        # 走NLP模型
        result = self._run_model(text, context)
        return result

    def _run_model(self, text: str, context: dict) -> dict:
        """实际模型推理（省略模型加载和推理细节）"""
        # 输入编码：[CLS] 学科 SEP 年级 SEP 文本 [SEP]
        subject = context.get("subject", "GENERAL") if context else "GENERAL"
        grade = context.get("grade", "") if context else ""

        encoded = self.tokenizer(
            f"{subject} {grade} {text}",
            truncation=True,
            max_length=128,
            return_tensors="pt"
        )

        # 推理
        outputs = self.model(**encoded)
        probs = outputs.logits.softmax(dim=-1)[0]

        labels = ["FIXED_NEGATIVE", "NEUTRAL", "GROWTH_POSITIVE"]
        label_map = {"FIXED_NEGATIVE": "FIXED", "NEUTRAL": "NEUTRAL", "GROWTH_POSITIVE": "GROWTH"}

        max_idx = probs.argmax().item()
        confidence = probs[max_idx].item()

        if confidence < self.confidence_threshold:
            polarity = "NEUTRAL"
        else:
            polarity = label_map[labels[max_idx]]

        return {
            "polarity": polarity,
            "confidence": round(confidence, 3),
            "scores": {label_map[l]: round(p.item(), 3) for l, p in zip(labels, probs)},
            "key_phrases": self._extract_key_phrases(text),
            "source": "NLP_MODEL"
        }

    def _default_result(self) -> dict:
        return {
            "polarity": "NEUTRAL",
            "confidence": 0.0,
            "scores": None,
            "key_phrases": [],
            "source": "DEFAULT"
        }

    def _extract_key_phrases(self, text: str) -> list[str]:
        """提取文本中与思维倾向相关的关键短语"""
        # 简化实现：返回匹配到的关键词
        signals = detect_mindset_signals_fast(text)
        return list({s["matched_text"] for s in signals})
```

```python
class ResilienceIndexCalculator:
    """抗挫力综合指数计算引擎"""

    def calculate(
        self,
        student_id: int,
        data_window_days: int = 30
    ) -> dict:
        """
        从多维度数据源计算学生的综合抗挫力画像。
        每日定时执行，生成当日快照。
        """
        end_date = datetime.now().date()
        start_date = end_date - timedelta(days=data_window_days)

        # --- 1. 收集原始数据 ---
        persistence_records = self._get_persistence_records(
            student_id, start_date, end_date
        )
        frustration_events = self._get_frustration_events(
            student_id, start_date, end_date
        )
        mindset_signals = self._get_mindset_signals(
            student_id, start_date, end_date
        )
        failure_recovery_data = self._get_failure_recovery_data(
            student_id, start_date, end_date
        )
        challenge_data = self._get_challenge_selection_data(
            student_id, start_date, end_date
        )

        evidence_count = (
            len(persistence_records) +
            len(frustration_events) +
            len(mindset_signals)
        )

        # 数据量不足时返回低置信度结果
        if evidence_count < 10:
            return self._low_confidence_result(student_id, evidence_count)

        # --- 2. 计算三维分项 ---
        persistence_result = self._calc_persistence_dimension(
            persistence_records, frustration_events
        )
        recovery_result = self._calc_recovery_dimension(failure_recovery_data)
        challenge_result = self._calc_challenge_dimension(challenge_data)

        # --- 3. 计算成长型思维得分 ---
        mindset_result = self._calc_mindset_score(mindset_signals)

        # --- 4. 融合为综合指数 ---
        # 权重可根据学段调整
        weights = self._get_dimension_weights(student_id)
        ri_raw = (
            persistence_result["score"] * weights["persistence"] +
            recovery_result["score"] * weights["recovery"] +
            challenge_result["score"] * weights["challenge"]
        )

        # 融合思维得分作为调节因子
        mindset_modifier = (mindset_result["score"] - 0.5) * 0.2  # ±10%调节
        ri_adjusted = max(0, min(100, ri_raw * 100 + mindset_modifier * 100))

        # --- 5. 计算趋势 ---
        previous_profiles = self._get_previous_profiles(student_id, days=30)
        ri_trend_7d = self._calc_trend(previous_profiles, days=7)
        ri_trend_30d = self._calc_trend(previous_profiles, days=30)
        ri_volatility = self._calc_volatility(previous_profiles)

        # --- 6. 分类 ---
        mindset_type = self._classify_mindset(mindset_result["score"])
        risk_level = self._classify_risk(ri_adjusted, ri_trend_30d, mindset_result["score"])

        # --- 7. 生成洞察 ---
        insight = self._generate_insight(
            persistence_result, recovery_result, challenge_result,
            mindset_result, ri_trend_30d, risk_level
        )

        # --- 8. 推荐干预 ---
        recommendations = self._recommend_interventions(
            ri_adjusted, mindset_type, risk_level,
            persistence_result, recovery_result, challenge_result,
            mindset_result, ri_trend_30d
        )

        confidence = self._calc_confidence(evidence_count, data_window_days)

        return {
            "student_id": student_id,
            "snapshot_date": end_date,
            "resilience_index": round(ri_adjusted, 2),
            "mindset_score": round(mindset_result["score"] * 100, 2),
            "persistence_score": round(persistence_result["score"] * 100, 2),
            "recovery_score": round(recovery_result["score"] * 100, 2),
            "challenge_score": round(challenge_result["score"] * 100, 2),
            "ri_trend_7d": round(ri_trend_7d, 2),
            "ri_trend_30d": round(ri_trend_30d, 2),
            "ri_volatility": round(ri_volatility, 2),
            "mindset_type": mindset_type,
            "risk_level": risk_level,
            "data_window_days": data_window_days,
            "evidence_count": evidence_count,
            "confidence": confidence,
            "insight_summary": insight,
            "recommended_actions": recommendations
        }

    def _get_dimension_weights(self, student_id: int) -> dict:
        """根据学段调整维度权重"""
        grade = self._get_student_grade(student_id)

        if grade in ("小学三年级", "小学四年级", "小学五年级", "小学六年级"):
            # 小学：更看重坚持度和挑战接受
            return {"persistence": 0.40, "recovery": 0.25, "challenge": 0.35}
        elif grade in ("初一", "初二", "初三"):
            # 初中：均衡
            return {"persistence": 0.35, "recovery": 0.35, "challenge": 0.30}
        else:
            # 高中：恢复力更重要（考试压力大）
            return {"persistence": 0.30, "recovery": 0.40, "challenge": 0.30}

    def _classify_mindset(self, mindset_score: float) -> str:
        if mindset_score >= 0.65:
            return "GROWTH"
        elif mindset_score >= 0.40:
            return "MIXED"
        else:
            return "FIXED"

    def _classify_risk(
        self, ri: float, ri_trend_30d: float, mindset_score: float
    ) -> str:
        if ri < 30 or (ri < 40 and ri_trend_30d < -5):
            return "CRITICAL"
        elif ri < 45 or (ri < 55 and ri_trend_30d < -3) or mindset_score < 0.35:
            return "AT_RISK"
        elif ri < 60 or ri_trend_30d < -1 or mindset_score < 0.45:
            return "WATCH"
        else:
            return "HEALTHY"

    def _generate_insight(self, p, r, c, m, trend, risk) -> str:
        """基于多维度数据生成自然语言洞察"""
        parts = []

        # 优势
        dimensions = [
            ("坚持度", p["score"]), ("恢复力", r["score"]),
            ("挑战接受", c["score"])
        ]
        strongest = max(dimensions, key=lambda x: x[1])
        weakest = min(dimensions, key=lambda x: x[1])

        parts.append(f"该学生{strongest[0]}表现较好({strongest[1]:.0%})")

        if weakest[1] < 0.45:
            parts.append(f"{weakest[0]}偏弱({weakest[1]:.0%})，建议针对性加强")

        # 趋势
        if trend > 3:
            parts.append("近一个月抗挫力呈上升趋势，发展态势良好")
        elif trend < -3:
            parts.append("近一个月抗挫力下降明显，需关注近期是否遇到学业压力")

        # 思维类型
        if m["score"] < 0.40:
            parts.append("固定型思维倾向明显，常将失败归因于能力不足")
        elif m["score"] > 0.65:
            parts.append("成长型思维稳固，能将失败视为学习机会")

        return "。".join(parts) + "。"

    def _recommend_interventions(
        self, ri, mindset_type, risk_level,
        p, r, c, m, trend
    ) -> list[dict]:
        """基于评估结果推荐干预策略"""
        recommendations = []

        # --- 风险等级驱动 ---
        if risk_level == "CRITICAL":
            recommendations.append({
                "priority": 1,
                "strategy": "EMERGENCY_SUPPORT",
                "category": "INTERACTION",
                "detail": "立即降低任务难度至学生舒适区，推送鼓励性内容，通知家长关注"
            })
        elif risk_level == "AT_RISK":
            if r["score"] < 0.40:
                recommendations.append({
                    "priority": 1,
                    "strategy": "RECOVERY_SCAFFOLDING",
                    "category": "CONTENT",
                    "detail": "在失败后插入简短的成功体验题目，帮助快速恢复信心"
                })
            if mindset_type == "FIXED":
                recommendations.append({
                    "priority": 2,
                    "strategy": "GROWTH_LANGUAGE_NUDGE",
                    "category": "INTERACTION",
                    "detail": "AI辅导对话中使用成长型语言框架，将'不会'重构为'还没学会'"
                })
        elif risk_level == "WATCH":
            if c["score"] < 0.45:
                recommendations.append({
                    "priority": 1,
                    "strategy": "GRADUAL_CHALLENGE",
                    "category": "CONTENT",
                    "detail": "逐步增加挑战题比例(从5%开始)，确保挑战题后有正向反馈"
                })

        # --- 通用推荐 ---
        if p["score"] > 0.70 and c["score"] > 0.60:
            recommendations.append({
                "priority": 3,
                "strategy": "LEAD_BY_EXAMPLE",
                "category": "NOTIFICATION",
                "detail": "推荐参与同伴互助活动，让该学生帮助他人(巩固成长型思维)"
            })

        return recommendations
```

### 7.3 干预效果评估

```python
def evaluate_intervention_effectiveness(
    intervention_id: str,
    pre_ri: float,           # 干预前RI
    pre_mindset: float,      # 干预前思维得分
    post_ri: float,          # 干预后RI (通常2-4周后)
    post_mindset: float,     # 干预后思维得分
    behavioral_metrics: dict  # 行为指标变化
) -> dict:
    """
    评估干预策略的效果。
    """
    ri_improvement = post_ri - pre_ri
    mindset_improvement = post_mindset - pre_mindset

    # 行为指标变化
    give_up_rate_change = behavioral_metrics.get("give_up_rate_change", 0)
    challenge_acceptance_change = behavioral_metrics.get("challenge_acceptance_change", 0)
    recovery_speed_change = behavioral_metrics.get("recovery_speed_change", 0)
    explanation_read_rate_change = behavioral_metrics.get("explanation_read_rate_change", 0)

    # 综合效果得分
    effectiveness = (
        max(0, ri_improvement / 10) * 0.30 +          # RI每提升10分=0.3
        max(0, mindset_improvement / 0.1) * 0.25 +     # 思维每提升0.1=0.25
        max(0, -give_up_rate_change / 0.1) * 0.15 +    # 放弃率每降10%=0.15
        max(0, challenge_acceptance_change / 0.1) * 0.15 +  # 挑战接受度每提升10%=0.15
        max(0, recovery_speed_change / 60) * 0.15      # 恢复速度每快60秒=0.15
    )
    effectiveness = min(1.0, effectiveness)

    # 效果判定
    if effectiveness >= 0.7:
        verdict = "HIGHLY_EFFECTIVE"
    elif effectiveness >= 0.4:
        verdict = "MODERATELY_EFFECTIVE"
    elif effectiveness >= 0.2:
        verdict = "SLIGHTLY_EFFECTIVE"
    else:
        verdict = "INEFFECTIVE"

    return {
        "effectiveness_score": round(effectiveness, 2),
        "verdict": verdict,
        "ri_improvement": round(ri_improvement, 2),
        "mindset_improvement": round(mindset_improvement, 2),
        "behavioral_changes": behavioral_metrics
    }
```

## 10. 错误处理与降级策略

### 10.1 错误码定义

| 错误码 | 含义 | 处理方式 |
|-------|------|---------|
| `RES_001` | 数据量不足，无法计算画像 | 返回低置信度默认画像 |

| `RES_003` | NLP模型推理失败 | 降级为关键词检测 |
| `RES_004` | 干预策略分发失败(目标模块不可用) | 记录日志，重试3次后放弃 |
| `RES_005` | 实时预警Webhook推送失败 | 写入消息队列异步重试 |
| `RES_006` | Redis缓存异常 | 直接查询数据库，不阻塞 |
| `RES_007` | 干预冷却期检查失败 | 安全失败(允许执行干预) |

```python
            "level": "INFO",
            "code": "LOW_SUBJECT_COVERAGE",
            "message": f"仅覆盖{len(subjects)}个学科"
        })

    # 检查时间分布
    if persistence_records:
        dates = [r.get("first_attempt_time", datetime.now()).date()
                 for r in persistence_records]
        unique_dates = set(dates)
        if len(unique_dates) < 3:
            issues.append({
                "level": "INFO",
                "code": "LOW_TEMPORAL_COVERAGE",
                "message": f"数据仅覆盖{len(unique_dates)}天"
            })

    # 检查异常值
    times = [r.get("total_time_seconds", 0) for r in persistence_records]
    if times and max(times) > 3600:
        issues.append({
            "level": "WARNING",
            "code": "OUTLIER_TIME_DETECTED",
            "message": f"存在异常耗时记录: {max(times)}秒"
        })

    confidence = max(0.0, 1.0 - len(issues) * 0.15)

    return {
        "is_valid": len([i for i in issues if i["level"] == "ERROR"]) == 0,
        "confidence": confidence,
        "issues": issues
    }
```

## 12. 性能优化

### 12.1 查询优化

```sql
-- 画像查询：通过 uk_student_date 唯一索引保证快速定位
SELECT * FROM student_resilience_profile
WHERE student_id = ? AND snapshot_date = ?;

-- 历史趋势：利用 idx_student_time 覆盖索引
SELECT snapshot_date, resilience_index, mindset_score
FROM student_resilience_profile
WHERE student_id = ?
  AND snapshot_date >= DATE_SUB(CURDATE(), INTERVAL 90 DAY)
ORDER BY snapshot_date;

-- 风险列表：利用 idx_risk 复合索引
SELECT student_id, resilience_index, mindset_type, risk_level
FROM student_resilience_profile
WHERE risk_level IN ('AT_RISK', 'CRITICAL')
  AND snapshot_date = CURDATE()
LIMIT ?, ?;
```

### 12.2 批量计算优化

- **并行计算**：每日画像计算使用线程池（20线程），单学生计算耗时约 50-200ms
- **增量数据加载**：仅加载变化数据（CDC增量），而非全量重新扫描
- **Redis预聚合**：频繁使用的统计量（如近7天放弃次数）在写入时增量更新到Redis
- **物化视图**：在ClickHouse中预聚合周级/月级统计数据

### 12.3 实时检测优化

- **流式检测**：AI对话消息通过Kafka Streams实时消费，关键词检测延迟<10ms
- **NLP模型推理**：使用ONNX Runtime加速，单条推理<30ms
- **会话状态缓存**：实时挫折等级维护在Redis Hash中，O(1)读写

## 13. 安全与隐私

### 13.1 数据安全

- 挫折事件中的 `raw_content` 字段（学生对话原文）在写入前进行敏感信息脱敏
- 心理相关数据（mindset_score、risk_level）属于高敏数据，仅学生本人、绑定的家长、授权教师可查看
- 干预记录中的触发数据快照不包含具体对话内容，仅保留结构化信号

### 13.2 未成年人保护

- 向家长推送的信息需经过"积极表述"过滤：不传递"你的孩子抗挫力差"等负面表述，改为"孩子近期在遇到困难时的坚持表现可以进一步提升，建议..."
- CRITICAL级别预警通知家长前需检查家长通知偏好设置
- 不对小学低年级学生展示"抗挫力指数"数值（避免标签化），仅展示鼓励性内容

### 13.3 数据保留策略

| 数据类型 | 保留期限 | 归档方式 |
|---------|---------|---------|
| 挫折事件原始记录 | 180天 | 180天后迁移至冷存储 |
| 画像快照 | 3年 | 每学年归档一次 |
| 思维信号日志 | 365天 | 按月分区，过期自动清理 |
| 干预执行记录 | 2年 | 归档至数据仓库 |
| 会话级实时状态 | 7天 | Redis自动过期 |
