# 用户学习画像与能力维度模型 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

用户学习画像是 PrimeTop 的核心数据基础设施，负责将分散的学习行为数据（答题、提问、复习、练习等）转化为结构化的用户能力模型。它为自适应推荐、学习规划、学情报告、家长报告等上层模块提供统一的"用户当前学习状态"视图。

### 1.2 与学情分析模块的边界

| 维度 | 用户学习画像（本文档） | 学情分析 |
|------|----------------------|---------|
| 职责 | 定义和计算用户能力数据的底层模型 | 基于画像数据生成报表、趋势、报告 |
| 产出 | 结构化画像数据（掌握度、能力值、标签） | 面向用户/家长的展示和分析 |
| 调用方 | 自适应推荐、学习规划、错题复习等内部服务 | 学生端、家长端、教师端 UI |
| 类比 | 数据库/计算引擎 | BI 报表工具 |

### 1.3 优先级

P0 — MVP 阶段核心基础设施，学习闭环的基石

### 1.4 依赖关系

```
用户账号体系 ───→ 用户身份、学段、年级、教材版本
学习记录服务 ───→ 答题记录、学习时长、练习结果
错题整理     ───→ 错题数据、错因标签
题目与题库   ───→ 知识点标签、难度值、题型分类
知识点体系   ───→ 知识点层级结构、前置关系
```

下游消费方：
```
自适应推荐引擎 ──→ 消费画像做个性化推荐
学习规划       ──→ 消费薄弱点生成学习任务
学情分析       ──→ 消费画像生成报表
学习报告       ──→ 消费画像生成周报/月报
家长中心       ──→ 消费画像生成家长报告
间隔重复复习   ──→ 消费掌握度确定复习频率
```

## 2. 核心概念

### 2.1 能力维度体系

用户学习画像采用三级维度体系：

```
学科级（Subject Level）
├── 掌握度总评分 0-100
├── 学习时长统计
├── 章节覆盖率
│
└── 知识点级（Knowledge Point Level）
    ├── 掌握度 0-1.0（连续浮点）
    ├── 掌握状态：未学 | 学习中 | 已掌握 | 需复习
    ├── 最后学习时间
    ├── 正确率（近N次）
    │
    └── 能力维度级（Ability Dimension Level）
        ├── 计算能力、逻辑推理、阅读理解...
        ├── 维度分数 0-100
        └── 维度等级：薄弱 | 基础 | 良好 | 优秀
```

### 2.2 掌握度模型

采用 **基于贝叶斯知识追踪（BKT）简化版** 的掌握度计算模型：

```
P(掌握) = P(先验) × P(答对|掌握) / P(答对)

其中：
- P(先验)：初始掌握概率，由学段和知识点难度决定
- P(答对|掌握)：已掌握状态下答对的概率（考虑失误率，默认 0.95）
- P(答对|未掌握)：未掌握状态下猜对的概率（考虑猜测率，默认 0.2）
```

简化实现：采用 EMA（指数移动平均）作为 MVP 方案，后续可升级为完整 BKT/IRT：

```
mastery_new = α × mastery_old + (1 - α) × evidence

其中：
- evidence = 1.0（答对）或 0.0（答错）
- α = 0.7（平滑因子，越大越保守）
```

### 2.3 能力维度定义

每个学科定义一组能力维度，维度由知识点标签聚合：

| 学科 | 能力维度 | 数据来源 |
|------|---------|---------|
| 数学 | 计算能力、逻辑推理、空间想象、数据分析、应用建模 | 知识点标签 + 答题行为 |
| 语文 | 阅读理解、写作表达、古诗文鉴赏、语言基础、文学常识 | 知识点标签 + 作文评分 |
| 英语 | 听力理解、阅读理解、语法应用、词汇量、写作表达、口语表达 | 知识点标签 + 语音评分 |
| 物理 | 概念理解、公式推导、实验分析、综合应用 | 知识点标签 + 答题行为 |
| 化学 | 概念理解、方程式书写、实验操作、计算推理 | 知识点标签 + 答题行为 |
| 生物 | 概念记忆、实验分析、图表解读、综合应用 | 知识点标签 + 答题行为 |
| 历史 | 史实记忆、材料分析、因果推理、综合论述 | 知识点标签 + 答题行为 |

## 4. 掌握度计算引擎

### 4.1 事件驱动的实时更新

掌握度计算采用事件驱动架构，在用户产生学习行为时实时更新：

```
学习行为事件
    │
    ▼
事件路由（Event Router）
    │
    ├── 答题事件 → 更新知识点掌握度
    ├── 复习事件 → 更新复习时间 + 掌握度
    ├── AI问答事件 → 关联知识点 + 更新学习时长
    ├── 错题订正事件 → 更新掌握度（正向证据）
    └── 练习完成事件 → 批量更新相关知识点
        │
        ▼
知识点掌握度计算（KP Mastery Calculator）
    │
    ▼
学科画像聚合（Subject Profile Aggregator）
    │
    ▼
能力维度聚合（Dimension Aggregator）
    │
    ▼
画像变更事件发布 → 通知下游模块
```

### 4.2 知识点掌握度计算

```python
class KnowledgeMasteryCalculator:
    """知识点掌握度计算器"""
    
    def __init__(self):
        self.default_alpha = 0.70          # 默认EMA平滑因子
        self.min_confidence_samples = 3    # 最低置信度样本数
        self.recent_window = 10            # 近N次答题窗口
    
    def update_mastery(
        self, 
        current: MasteryRecord, 
        is_correct: bool, 
        difficulty: int  # 1-5
    ) -> MasteryUpdate:
        """单次答题后更新掌握度"""
        
        # 1. 计算证据值（考虑难度加权）
        difficulty_weight = 0.8 + (difficulty - 1) * 0.1  # 难度1→0.8, 难度5→1.2
        evidence = (1.0 if is_correct else 0.0) * difficulty_weight
        evidence = max(0.0, min(1.0, evidence))  # clamp
        
        # 2. EMA 更新
        alpha = current.ema_alpha
        new_mastery = alpha * current.mastery + (1 - alpha) * evidence
        
        # 3. 更新统计
        new_attempt = current.attempt_count + 1
        new_correct = current.correct_count + (1 if is_correct else 0)
        
        # 4. 更新近N次窗口
        recent_correct = self._update_recent_window(
            current.recent_correct_count, 
            current.recent_attempt_count,
            is_correct
        )
        
        # 5. 计算置信度
        confidence = min(1.0, new_attempt / 20)  # 20次答题后置信度达到1.0
        
        # 6. 确定掌握状态
        status = self._determine_status(new_mastery, new_attempt, confidence)
        
        # 7. 计算下次复习时间
        next_review = self._calculate_next_review(new_mastery, is_correct)
        
        return MasteryUpdate(
            mastery=round(new_mastery, 4),
            mastery_status=status,
            attempt_count=new_attempt,
            correct_count=new_correct,
            recent_attempt_count=min(new_attempt, self.recent_window),
            recent_correct_count=recent_correct,
            confidence=round(confidence, 2),
            last_practiced_at=datetime.utcnow(),
            next_review_at=next_review
        )
    
    def _determine_status(
        self, 
        mastery: float, 
        attempts: int, 
        confidence: float
    ) -> str:
        """确定掌握状态"""
        if attempts == 0:
            return 'NOT_STARTED'
        if confidence < 0.15:  # 少于3次答题
            return 'LEARNING'
        if mastery >= 0.80:
            return 'MASTERED'
        if mastery >= 0.40:
            return 'LEARNING'
        if attempts >= 5 and mastery < 0.40:
            return 'NEEDS_REVIEW'
        return 'LEARNING'
    
    def _calculate_next_review(
        self, 
        mastery: float, 
        was_correct: bool
    ) -> datetime:
        """基于掌握度计算下次复习时间（简化遗忘曲线）"""
        # 间隔天数：掌握度越高间隔越长
        base_intervals = {
            (0.0, 0.3): 1,    # 低掌握度：1天后复习
            (0.3, 0.5): 2,    # 中低：2天
            (0.5, 0.7): 4,    # 中等：4天
            (0.7, 0.85): 7,   # 较好：1周
            (0.85, 1.01): 14, # 高掌握度：2周
        }
        
        for (low, high), days in base_intervals.items():
            if low <= mastery < high:
                interval_days = days
                break
        else:
            interval_days = 1
        
        # 答错缩短间隔
        if not was_correct:
            interval_days = max(1, interval_days // 2)
        
        return datetime.utcnow() + timedelta(days=interval_days)
```

### 4.3 学科画像聚合

```python
class SubjectProfileAggregator:
    """学科画像聚合器"""
    
    def aggregate(self, user_id: int, subject_code: str) -> SubjectProfile:
        """聚合学科级画像"""
        
        # 1. 获取该学科所有知识点掌握度
        masteries = self.mastery_repo.list_by_user_subject(user_id, subject_code)
        
        if not masteries:
            return SubjectProfile.default(user_id, subject_code)
        
        # 2. 加权平均掌握度（高难度知识点权重更高）
        total_weight = 0
        weighted_mastery = 0
        for m in masteries:
            weight = m.confidence  # 高置信度的知识点权重更高
            weighted_mastery += m.mastery * weight
            total_weight += weight
        
        mastery_score = (weighted_mastery / total_weight * 100) if total_weight > 0 else 0
        
        # 3. 统计覆盖率
        kp_learned = sum(1 for m in masteries if m.mastery_status != 'NOT_STARTED')
        kp_total = self.kp_repo.count_by_subject(subject_code)
        
        # 4. 计算趋势
        # 从快照表获取上次数据对比
        
        return SubjectProfile(
            user_id=user_id,
            subject_code=subject_code,
            mastery_score=round(mastery_score, 2),
            kp_learned=kp_learned,
            kp_total=kp_total,
            total_questions=sum(m.attempt_count for m in masteries),
            total_correct=sum(m.correct_count for m in masteries),
        )
```

### 4.4 能力维度聚合

```python
class DimensionAggregator:
    """能力维度聚合器"""
    
    # 知识点 → 能力维度映射（由知识点表维护）
    # 每个知识点可以关联多个维度，有权重
    
    def aggregate_dimensions(
        self, 
        user_id: int, 
        subject_code: str
    ) -> List[DimensionScore]:
        """聚合能力维度分数"""
        
        # 1. 获取该学科维度定义
        dimensions = self.dimension_def_repo.list_by_subject(subject_code)
        
        results = []
        for dim in dimensions:
            # 2. 获取该维度关联的知识点掌握度
            kp_masteries = self.mastery_repo.list_by_dimension(
                user_id, subject_code, dim.dimension_code
            )
            
            if not kp_masteries:
                results.append(DimensionScore(
                    dimension_code=dim.dimension_code,
                    score=0,
                    level='WEAK',
                    kp_count=0,
                    kp_mastered=0
                ))
                continue
            
            # 3. 加权计算维度分数
            total_weight = 0
            weighted_score = 0
            for km in kp_masteries:
                w = km.dimension_weight  # 该知识点对该维度的权重
                weighted_score += km.mastery * w * 100
                total_weight += w
            
            score = (weighted_score / total_weight) if total_weight > 0 else 0
            kp_count = len(kp_masteries)
            kp_mastered = sum(1 for km in kp_masteries if km.mastery_status == 'MASTERED')
            
            results.append(DimensionScore(
                dimension_code=dim.dimension_code,
                score=round(score, 2),
                level=self._score_to_level(score),
                kp_count=kp_count,
                kp_mastered=kp_mastered
            ))
        
        return results
    
    def _score_to_level(self, score: float) -> str:
        if score >= 85:
            return 'EXCELLENT'
        elif score >= 65:
            return 'GOOD'
        elif score >= 40:
            return 'BASIC'
        else:
            return 'WEAK'
```

```python
class TagEngine:
    """用户标签计算引擎"""
    
    def compute_tags(self, user_id: int) -> List[UserTag]:
        """计算用户所有标签"""
        tags = []
        tags.extend(self._compute_behavior_tags(user_id))
        tags.extend(self._compute_ability_tags(user_id))
        tags.extend(self._compute_risk_tags(user_id))
        tags.extend(self._compute_preference_tags(user_id))
        return tags
    
    def _compute_risk_tags(self, user_id: int) -> List[UserTag]:
        risk_tags = []
        
        # LOW_ENGAGEMENT: 连续5天无学习
        active_days = self.activity_repo.get_recent_active_days(user_id, days=10)
        if len(active_days) >= 5:
            last_active = max(active_days)
            days_inactive = (datetime.utcnow().date() - last_active).days
            if days_inactive >= 5:
                risk_tags.append(UserTag(
                    tag_type='RISK',
                    tag_code='LOW_ENGAGEMENT',
                    tag_value=f'inactive_days:{days_inactive}',
                    confidence=min(1.0, days_inactive / 14),  # 14天达到1.0
                    source='ALGORITHM',
                    expires_at=datetime.utcnow() + timedelta(days=7)
                ))
        
        # DECREASING_TREND: 掌握度30日趋势下滑
        subjects = self.profile_repo.get_subject_profiles(user_id)
        for sp in subjects:
            if sp.trend_30d < -10:
                risk_tags.append(UserTag(
                    tag_type='RISK',
                    tag_code='DECREASING_TREND',
                    tag_value=f'{sp.subject_code}:change={sp.trend_30d}',
                    confidence=min(1.0, abs(sp.trend_30d) / 30),
                    source='ALGORITHM',
                    expires_at=datetime.utcnow() + timedelta(days=14)
                ))
        
        # HIGH_ERROR_RATE: 近7天正确率低于40%
        for sp in subjects:
            recent_stats = self.activity_repo.get_recent_accuracy(
                user_id, sp.subject_code, days=7
            )
            if recent_stats.attempt_count >= 10 and recent_stats.accuracy < 0.40:
                risk_tags.append(UserTag(
                    tag_type='RISK',
                    tag_code='HIGH_ERROR_RATE',
                    tag_value=f'{sp.subject_code}:accuracy={recent_stats.accuracy:.2f}',
                    confidence=min(1.0, (0.40 - recent_stats.accuracy) / 0.40 + 0.3),
                    source='ALGORITHM',
                    expires_at=datetime.utcnow() + timedelta(days=3)
                ))
        
        return risk_tags
```

```python
class ProfileSnapshotJob:
    """画像快照定时任务"""
    
    def run_weekly_snapshot(self):
        """每周日执行全量用户快照"""
        period_key = datetime.utcnow().strftime('%G-W%V')
        
        # 分页处理所有活跃用户（近30天有活动）
        page = 0
        while True:
            users = self.user_repo.get_active_users(
                active_days=30, 
                page=page, 
                page_size=500
            )
            if not users:
                break
            
            for user in users:
                try:
                    self._create_snapshot(user.user_id, 'WEEKLY', period_key)
                except Exception as e:
                    logger.error(f"Snapshot failed for user {user.user_id}: {e}")
            
            page += 1
        
        logger.info(f"Weekly snapshot completed: period={period_key}")
    
    def _create_snapshot(self, user_id: int, snapshot_type: str, period_key: str):
        """创建单个用户快照"""
        # 1. 收集当前画像
        subject_profiles = self.profile_service.get_subject_profiles(user_id)
        dimensions = {}
        for sp in subject_profiles:
            dims = self.dimension_service.get_dimensions(user_id, sp.subject_code)
            dimensions[sp.subject_code] = [d.to_dict() for d in dims]
        
        # 2. 计算综合评分
        overall = sum(sp.mastery_score for sp in subject_profiles) / len(subject_profiles)
        
        # 3. 提取Top薄弱/优势
        all_masteries = self.mastery_service.get_all_masteries(user_id)
        sorted_m = sorted(all_masteries, key=lambda x: x.mastery)
        weak_top5 = sorted_m[:5]
        strong_top5 = sorted(sorted_m, key=lambda x: -x.mastery)[:5]
        
        # 4. 存储快照
        snapshot = UserProfileSnapshot(
            user_id=user_id,
            snapshot_type=snapshot_type,
            period_key=period_key,
            snapshot_data={
                'subjects': {sp.subject_code: sp.to_dict() for sp in subject_profiles},
                'dimensions': dimensions,
            },
            overall_score=round(overall, 2),
            top_weak_kps=[{'kp_id': m.knowledge_point_id, 'kp_name': m.kp_name, 'mastery': float(m.mastery)} for m in weak_top5],
            top_strong_kps=[{'kp_id': m.knowledge_point_id, 'kp_name': m.kp_name, 'mastery': float(m.mastery)} for m in strong_top5],
        )
        self.snapshot_repo.save(snapshot)
```

## 10. 并发与一致性

### 10.1 掌握度更新的并发控制

掌握度更新是高频操作，需要处理并发：

```python
class MasteryUpdateService:
    
    def update_mastery(self, user_id: int, kp_id: int, evidence: MasteryEvidence) -> None:
        """带并发控制的掌握度更新"""
        
        # 1. 分布式锁（防止同一知识点并发更新）
        lock_key = f"lock:mastery:{user_id}:{kp_id}"
        lock = self.redis.lock(lock_key, timeout=5, retry_delay=50, retry_count=10)
        
        with lock:
            # 2. 读取当前值
            current = self.mastery_repo.get(user_id, kp_id)
            if current is None:
                current = self._init_mastery(user_id, kp_id)
            
            # 3. 计算新值
            updated = self.calculator.update_mastery(current, evidence)
            
            # 4. 写入DB
            self.mastery_repo.upsert(updated)
            
            # 5. 更新缓存（写穿透）
            cache_key = f"profile:mastery:{user_id}:{kp_id}"
            self.redis.setex(cache_key, 300, json.dumps(updated.to_dict()))
            
            # 6. 发布变更事件
            if current.mastery_status != updated.mastery_status:
                self.event_bus.publish('profile.status.changed', {
                    'user_id': user_id,
                    'kp_id': kp_id,
                    'old_status': current.mastery_status,
                    'new_status': updated.mastery_status,
                })
```

### 10.2 批量更新场景

练习完成时可能需要批量更新多个知识点：

```python
class BatchMasteryUpdateService:
    
    def batch_update(self, user_id: int, updates: List[MasteryEvidence]) -> BatchResult:
        """批量更新知识点掌握度"""
        
        # 1. 按知识点分组
        grouped = defaultdict(list)
        for u in updates:
            grouped[u.knowledge_point_id].append(u)
        
        # 2. 串行更新同一知识点（保证顺序），并行更新不同知识点
        results = []
        with ThreadPoolExecutor(max_workers=5) as executor:
            futures = {}
            for kp_id, evidences in grouped.items():
                future = executor.submit(
                    self._update_single_kp, user_id, kp_id, evidences
                )
                futures[future] = kp_id
            
            for future in as_completed(futures):
                try:
                    results.append(future.result())
                except Exception as e:
                    logger.error(f"Batch update failed for kp {futures[future]}: {e}")
                    results.append(BatchResultItem(error=str(e)))
        
        # 3. 异步触发学科画像聚合（不阻塞响应）
        affected_subjects = set(r.subject_code for r in results if r.subject_code)
        for subject_code in affected_subjects:
            self.event_bus.publish('profile.subject.need_reaggregate', {
                'user_id': user_id,
                'subject_code': subject_code,
            })
        
        return BatchResult(items=results, affected_subjects=list(affected_subjects))
```

## 11. 错误处理

### 11.1 错误码定义

| 错误码 | HTTP 状态码 | 说明 | 处理建议 |
|--------|-----------|------|---------|
| `PROFILE_NOT_FOUND` | 404 | 用户画像不存在 | 首次访问，触发初始化 |
| `KP_NOT_IN_SYLLABUS` | 400 | 知识点不在用户学段范围内 | 检查学段匹配 |
| `MASTERY_UPDATE_CONFLICT` | 409 | 掌握度更新冲突 | 客户端重试 |
| `MASTERY_UPDATE_TIMEOUT` | 504 | 掌握度更新超时 | 降级为异步更新 |
| `SNAPSHOT_IN_PROGRESS` | 409 | 快照正在生成中 | 稍后重试 |
| `INVALID_MASTERY_RANGE` | 400 | 掌握度值超出范围 | 检查计算逻辑 |
| `TAG_COMPUTATION_FAILED` | 500 | 标签计算失败 | 降级返回旧标签 |

### 11.2 降级策略

```
掌握度更新失败：
  → 写入本地队列（Redis List），延迟重试
  → 超过3次失败 → 记录错误日志，等待下次快照修复

学科画像聚合失败：
  → 返回缓存中的旧数据
  → 标记数据过期（stale=true），前端提示"数据可能有延迟"

标签计算失败：
  → 返回上次计算的标签（降低置信度）
  → 超过24小时 → 清除标签，返回空列表

快照任务失败：
  → 记录失败用户列表
  → 补偿任务在次日重试失败用户
```

## 13. 初始化与冷启动

### 13.1 新用户画像初始化

```python
class ProfileInitService:
    
    def init_profile(self, user_id: int, student_profile: StudentProfile) -> None:
        """新用户画像初始化"""
        
        # 1. 获取学段+学科对应的所有知识点
        subjects = self.get_subjects_for_grade(student_profile.grade_code)
        
        for subject_code in subjects:
            # 2. 创建学科画像（全零初始值）
            self.subject_profile_repo.create(UserSubjectProfile(
                user_id=user_id,
                subject_code=subject_code,
                mastery_score=0,
            ))
            
            # 3. 获取该学科所有知识点
            knowledge_points = self.kp_repo.list_by_subject_grade(
                subject_code, student_profile.grade_code
            )
            
            # 4. 批量初始化知识点掌握度
            masteries = [
                UserKnowledgeMastery(
                    user_id=user_id,
                    knowledge_point_id=kp.id,
                    mastery=0,
                    mastery_status='NOT_STARTED',
                )
                for kp in knowledge_points
            ]
            self.mastery_repo.batch_create(masteries)
            
            # 5. 初始化能力维度
            dimensions = self.dimension_def_repo.list_by_subject(subject_code)
            for dim in dimensions:
                self.dimension_repo.create(UserAbilityDimension(
                    user_id=user_id,
                    subject_code=subject_code,
                    dimension_code=dim.dimension_code,
                    score=0,
                    level='WEAK',
                ))
```

### 13.2 冷启动优化

知识点数量较多（单学科可能100+），批量初始化需要优化：

- 使用批量 INSERT（每批500行）
- 不立即计算标签和快照
- 初始化缓存（写入 Redis 空值标记）
- 首次查询时按需触发轻量聚合

## 15. 安全与隐私

### 15.1 数据访问控制

- 用户只能查看自己的画像数据
- 家长通过绑定关系查看子女画像
- 教师通过班级关系查看学生画像（脱敏处理）
- 后台运营人员查看画像需审计日志

### 15.2 数据脱敏

- 面向教师的画像展示隐藏具体答题记录，仅展示聚合指标
- 面向B端的数据导出使用匿名化ID
- 标签数据不包含原始行为明细

### 15.3 数据保留

- 活跃用户：保留全量画像数据
- 休眠用户（180天无活动）：保留最近12个月快照，清理细粒度掌握度数据
- 注销用户：30天内删除所有画像数据

## 16. 后续演进方向

1. **IRT模型升级**：从EMA简化模型升级为项目反应理论（IRT），提升掌握度评估精度
2. **知识前置图感知**：利用知识点前置关系，当前置知识点未掌握时，自动降低后续知识点的预期掌握度
3. **实时画像流**：引入流式计算（如 Flink），实现画像的毫秒级实时更新
4. **跨学段画像迁移**：学生升学时，画像数据如何平滑过渡到新学段
5. **群体画像**：基于个体画像聚合生成班级/学校/区域画像，服务于B端场景
6. **AI辅助画像解读**：用大模型生成自然语言的画像分析报告
