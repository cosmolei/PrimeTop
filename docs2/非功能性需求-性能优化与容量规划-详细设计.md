## 2. 性能基线指标（SLA）

### 2.1 客户端指标

| 指标 | 目标值 | 测量方式 | 告警阈值 |
|------|--------|---------|---------|
| 首屏加载时间（冷启动） | ≤ 2.0s | 客户端埋点 `app_cold_start` | P95 > 3.0s |
| 首屏加载时间（热启动） | ≤ 0.5s | 客户端埋点 `app_warm_start` | P95 > 1.0s |
| 页面切换时间 | ≤ 300ms | Flutter Navigator 埋点 | P95 > 500ms |
| AI 对话首 token 延迟 | ≤ 3.0s | 客户端 SSE 首 token 埋点 | P95 > 5.0s |
| 拍题 OCR 识别总耗时 | ≤ 5.0s | 客户端→服务端端到端 | P95 > 8.0s |
| 图片上传耗时（4MB 内） | ≤ 3.0s | 客户端埋点 `upload_duration` | P95 > 6.0s |
| 离线操作队列同步完成 | ≤ 10s | 网络恢复后触发 | P95 > 30s |
| APP 崩溃率 | < 0.1% | Firebase Crashlytics / Sentry | > 0.3% |
| ANR 率（Android） | < 0.05% | Google Play Console | > 0.2% |

### 2.2 服务端接口指标

| 接口类别 | 目标 RT (P50) | 目标 RT (P95) | 目标 RT (P99) | 错误率目标 |

| 首页聚合 API | ≤ 300ms | ≤ 600ms | ≤ 1.5s | < 0.1% |
| AI 对话（SSE 流式首 token） | ≤ 500ms | ≤ 3s | ≤ 5s | < 1% |
| 拍题识别（含 OCR + 结构化） | ≤ 2s | ≤ 5s | ≤ 8s | < 2% |
| 错题本查询（分页 20 条） | ≤ 100ms | ≤ 300ms | ≤ 500ms | < 0.1% |
| 同步课堂章节树 | ≤ 150ms | ≤ 400ms | ≤ 800ms | < 0.1% |
| 学情报告生成 | ≤ 500ms | ≤ 1.5s | ≤ 3s | < 0.5% |

### 2.3 可用性指标

| 指标 | 目标 | 计算方式 |
|------|------|---------|
| 核心学习功能可用性 | ≥ 99.9%（月度） | `1 - 核心接口5xx时间窗口 / 总时间` |
| 全站可用性 | ≥ 99.5%（月度） | `1 - 全部5xx时间窗口 / 总时间` |

```sql

(
    timestamp       DateTime64(3),
    metric_name     LowCardinality(String),     -- 指标名：app_cold_start, api_rt 等
    metric_value    Float64,                     -- 指标值（ms / 比率）
```

| 资源 | 瓶颈触发条件 | 应对策略 |
|------|-------------|---------|

| 对象存储带宽 | 上传排队超时 | 分片并发上传 + CDN 加速 + 就近节点 |
| 消息队列积压 | Lag > 10,000 | 消费者扩容 + 分区增加 |

### 4.2 多级降级策略

#### 4.2.1 AI 服务降级

```text
Level 0：正常 → 主模型（如 GPT-4o / DeepSeek-R1）
    ↓ 主模型连续失败 / RT > 10s
Level 1：降级 → 备用模型（如 GLM-4 / Qwen）
    ↓ 备用模型也失败
Level 2：缓存兜底 → 从历史高质量回答中检索相似问题
    ↓ 无缓存命中
Level 3：友好提示 → "暂时无法回答，请稍后重试" + 自动记录待回复
```

```python
class AIServiceDegradation:
    """AI 服务多级降级链"""

    def __init__(self):
        self.models = [
            {"name": "primary", "client": DeepSeekClient(), "timeout": 10},
            {"name": "secondary", "client": GLMClient(), "timeout": 8},
            {"name": "tertiary", "client": QwenClient(), "timeout": 8},
        ]
        self.cache = AnswerCache()  # Redis-based

    async def invoke(self, prompt: str, context: dict) -> AsyncIterator[str]:
        # Level 0/1: 尝试模型链
        for model in self.models:
            try:
                async for token in model["client"].stream(
                    prompt, timeout=model["timeout"]
                ):
                    yield token
                return  # 成功则返回
            except (ModelException, TimeoutError) as e:
                log.warning(f"Model {model['name']} failed: {e}")
                continue

        # Level 2: 缓存兜底
        cached = await self.cache.search_similar(prompt, context)
        if cached:
            yield f"[参考回答]\n{cached.content}"
            return

        # Level 3: 友好提示
        await self.queue_for_retry(prompt, context)
        yield "抱歉，AI 服务暂时繁忙，已记录您的问题，稍后将为您解答。"
```

### 4.3 灾备方案

#### 4.3.1 数据库灾备

```text
主库（可用区 A）
    │
    ├── 同步复制 ──→ 同城从库（可用区 B）    ← 故障自动切换（≤ 30s）
    │
    └── 异步复制 ──→ 异地从库（异地容灾）    ← 手动切换（≤ 15min）
```

**自动切换流程：**

```python
class DatabaseFailover:
    """数据库故障自动切换"""

    async def check_and_failover(self):
        primary = get_primary_db()
        secondary = get_secondary_db()

        # 健康检查
        if not await self._health_check(primary, timeout=3):
            log.critical("Primary DB unhealthy, initiating failover")

            # 1. 验证从库数据一致性（延迟 < 1s）
            lag = await self._get_replication_lag(secondary)
            if lag > 5:
                log.error(f"Replication lag too large: {lag}s, manual intervention needed")
                await self._notify_ops("DB failover blocked: replication lag")
                return

            # 2. 将从库提升为主库
            await self._promote_to_primary(secondary)

            # 3. 更新 DNS / 连接配置
            await self._update_db_config(new_primary=secondary)

            # 4. 重启应用连接池
            await self._reload_connection_pools()

            # 5. 验证服务恢复
            if await self._verify_service():
                log.info("Database failover completed successfully")
            else:
                await self._notify_ops("DB failover verification failed!")
```

### 5.3 AI 调用排队与限流

```python
class AIRateLimiter:
    """AI 调用排队限流器（基于 Redis 令牌桶 + 优先级队列）"""

    # 会员等级对应不同配额
    TIERS = {
        "free": {"rpm": 5, "daily": 20},
        "monthly": {"rpm": 30, "daily": 200},
        "annual": {"rpm": 60, "daily": 500},
        "exam_prep": {"rpm": 60, "daily": 500},
    }

    async def acquire(self, user_id: str, tier: str) -> dict:
        limits = self.TIERS[tier]

        # 检查每日配额
        daily_key = f"ai_limit:daily:{user_id}"
        daily_used = await self.redis.incr(daily_key)
        if daily_used == 1:
            await self.redis.expire(daily_key, 86400)
        if daily_used > limits["daily"]:
            return {"allowed": False, "reason": "daily_limit", "reset_at": await self.redis.ttl(daily_key)}

        # 令牌桶限流（RPM）
        bucket_key = f"ai_limit:rpm:{user_id}"
        tokens = await self.redis.incr(bucket_key)
        if tokens == 1:
            await self.redis.expire(bucket_key, 60)
        if tokens > limits["rpm"]:
            return {"allowed": False, "reason": "rate_limit", "retry_after": await self.redis.ttl(bucket_key)}

        return {"allowed": True}
```

#### 6.1.2 慢查询治理标准

| 级别 | RT 范围 | 处理方式 | SLA |
|------|--------|---------|-----|
| 正常 | < 100ms | 无需处理 | - |
| 偏慢 | 100-500ms | 加入观察列表，周报追踪 | 1 周内分析 |
| 慢查询 | 500ms-1s | 必须优化 | 3 天内优化 |
| 严重慢查询 | > 1s | 立即处理 | 当天修复 |

```python
# 慢查询自动捕获（中间件）
class SlowQueryMiddleware:
    def __init__(self, threshold_ms=500):
        self.threshold_ms = threshold_ms

    async def execute(self, query: str, params: dict):
        start = time.monotonic()
        try:
            result = await self.db.execute(query, params)
            return result
        finally:
            elapsed_ms = (time.monotonic() - start) * 1000
            if elapsed_ms > self.threshold_ms:
                await self.report_slow_query(query, params, elapsed_ms)
```

```python
class ReadWriteRouter:
    """数据库读写路由"""

    def __init__(self, primary: Database, replicas: list[Database]):
        self.primary = primary
        self.replicas = replicas
        self._round_robin = itertools.cycle(replicas)

    def get_db(self, *, write: bool = False) -> Database:
        if write:
            return self.primary
        return next(self._round_robin)

    # 装饰器简化使用
    @staticmethod
    def write_operation(func):
        """写操作自动路由到主库"""
        async def wrapper(self, *args, **kwargs):
            with override_db(ReadWriteRouter.get_db(write=True)):
                return await func(self, *args, **kwargs)
        return wrapper

    @staticmethod
    def read_operation(func):
        """读操作自动路由到从库"""
        async def wrapper(self, *args, **kwargs):
            with override_db(ReadWriteRouter.get_db(write=False)):
                return await func(self, *args, **kwargs)
        return wrapper
```

## 7. 缓存体系

### 7.1 多级缓存架构

```text
┌──────────────────────────────────────────┐
│  L1: 客户端本地缓存（SharedPreferences / SQLite）  │
│  TTL: 长期（版本化 key）                     │
│  适合：教材目录、知识点树、用户配置              │
├──────────────────────────────────────────┤
│  L2: 服务端进程缓存（LRU Cache / Caffeine）     │
│  TTL: 5-30min                              │
│  适合：热点配置、Prompt 模板、模型路由表          │
├──────────────────────────────────────────┤
│  L3: Redis 分布式缓存                        │
│  TTL: 按业务设定                              │
│  适合：会话数据、用户状态、限流计数、查询结果      │
├──────────────────────────────────────────┤
│  L4: 数据库                                  │
│  适合：持久化数据                              │
└──────────────────────────────────────────┘
```

### 7.2 缓存策略明细

| 数据类型 | 缓存层级 | TTL | 更新策略 | Key 格式 |
|---------|---------|-----|---------|---------|
| 教材章节树 | L1 + L2 + L3 | L1: 版本化, L2: 30min, L3: 1h | 版本变更时主动失效 | `textbook:tree:{version_id}` |
| 知识点详情 | L2 + L3 | 30min | 管理后台修改时失效 | `kp:detail:{kp_id}` |
| 用户当前会话 | L3 | 2h（滑动续期） | 每次对话时刷新 | `session:active:{user_id}` |
| 错题本查询结果 | L3 | 10min | 新增/删除错题时失效 | `mistake:list:{user_id}:{subject}:{page}` |
| 会员权益 | L3 | 5min | 支付成功/权益变更时失效 | `membership:perms:{user_id}` |
| AI 对话上下文 | L3 | 30min | 每轮对话追加 | `chat:ctx:{session_id}` |
| 首页聚合数据 | L3 | 3min | 实时性要求不高 | `home:agg:{user_id}` |
| 学情报告 | L3 | 1h | 新学习数据入库时重建 | `report:{user_id}:{period}` |
| Prompt 模板 | L2 | 10min | 后台修改时失效 | `prompt:tpl:{scene}:{age_level}` |

```python
class CacheManager:
    """缓存一致性管理"""

    async def invalidate_user_cache(self, user_id: str, patterns: list[str]):
        """用户数据变更时，批量失效相关缓存"""
        pipe = self.redis.pipeline()
        for pattern in patterns:
            keys = await self.redis.keys(f"{pattern}:{user_id}*")
            if keys:
                pipe.delete(*keys)
        await pipe.execute()

        # 发布失效事件，通知其他服务节点清理 L2 缓存
        await self.redis.publish(
            "cache:invalidate",
            json.dumps({"user_id": user_id, "patterns": patterns})
        )

    async def warm_up(self, user_id: str):
        """缓存预热：用户登录时预加载常用数据"""
        tasks = [
            self._load_membership(user_id),
            self._load_student_profile(user_id),
            self._load_home_aggregation(user_id),
            self._load_active_plan(user_id),
        ]
        await asyncio.gather(*tasks, return_exceptions=True)
```

### 7.4 缓存穿透/击穿/雪崩防护

```python
class CacheShield:
    """缓存防护"""

    # 1. 穿透防护：布隆过滤器 + 空值缓存
    async def get_with_bloom_filter(self, key: str, loader):
        # 先查布隆过滤器
        if not await self.bloom.exists(key):
            return None

        value = await self.redis.get(key)
        if value is not None:
            if value == "NULL_PLACEHOLDER":
                return None  # 空值缓存命中
            return json.loads(value)

        # 缓存未命中，回源
        result = await loader()
        if result is None:
            await self.redis.setex(key, 300, "NULL_PLACEHOLDER")  # 空值缓存 5 分钟
        else:
            await self.redis.setex(key, self.ttl, json.dumps(result))
        return result

    # 2. 击穿防护：互斥锁
    async def get_with_mutex(self, key: str, loader, lock_timeout=10):
        value = await self.redis.get(key)
        if value is not None:
            return json.loads(value)

        lock_key = f"lock:cache:{key}"
        # 尝试获取互斥锁
        if await self.redis.set(lock_key, "1", nx=True, ex=lock_timeout):
            try:
                result = await loader()
                await self.redis.setex(key, self.ttl, json.dumps(result))
                return result
            finally:
                await self.redis.delete(lock_key)
        else:
            # 等待其他线程加载完成
            await asyncio.sleep(0.1)
            return await self.get_with_mutex(key, loader, lock_timeout)

    # 3. 雪崩防护：TTL 随机偏移
    def get_ttl_with_jitter(self, base_ttl: int) -> int:
        jitter = random.randint(-60, 60)  # ±60s 抖动
        return base_ttl + jitter
```
