# 服务端 - 用户活跃度统计与留存分析引擎 详细设计

## 1. 模块概述

### 1.1 功能定位

用户活跃度统计与留存分析引擎负责对 PrimeTop 平台用户进行多维度活跃度度量、留存率计算、用户生命周期阶段划分及会话深度分析，为运营决策、增长策略、流失预警和产品迭代提供数据支撑。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 活跃度统计 | DAU / WAU / MAU 计算，支持按学段、年级、学科、渠道等维度拆分 |
| 留存分析 | 次日 / 7 日 / 30 日留存率，支持队列分析（Cohort） |
| 生命周期划分 | 新用户 → 活跃 → 沉默 → 流失 → 回流，自动标记阶段 |
| 会话分析 | 单次会话时长、页面深度、功能触达率 |
| 活跃趋势 | 日/周/月粒度的活跃趋势曲线与环比同比 |
| 运营 API | 为管理后台看板和 B 端合作方提供标准化查询接口 |

### 1.3 与其他模块的关系

```
┌──────────────────────┐
│  数据埋点与关键指标系统  │ ── 原始事件流入
└──────────┬───────────┘
           │ Kafka 事件流
           ▼
┌──────────────────────────┐
│ 用户活跃度统计与留存分析引擎 │ ← 本模块
└──────┬───────┬───────┬───┘
       │       │       │
       ▼       ▼       ▼
  管理后台   用户标签   流失预警
  数据看板   智能分群   与挽留引擎
```

| 上游模块 | 依赖方式 |
|---------|---------|
| 数据埋点与关键指标系统 | Kafka 消费行为事件 |
| 用户账号体系 | 读取用户注册信息、档案属性 |
| 客户端埋点事件体系 | 客户端上报的 app_launch / page_view / session_end 事件 |

| 下游模块 | 提供方式 |
|---------|---------|
| 用户标签与智能分群引擎 | 提供 lifecycle_stage 标签 |
| 服务端-用户流失预警与智能挽留策略引擎 | 提供沉默天数、活跃频次等特征 |
| 管理后台 / 运营看板 | REST API 查询 |
| B 端合作与机构接入方案 | 聚合数据接口（脱敏） |

| Key 模式 | 类型 | 用途 | TTL |

## 3. 核心算法与规则

### 3.1 活跃定义

用户满足以下**任一**条件即标记为当日活跃：

| 行为类型 | 事件名 | 说明 |
|---------|--------|------|
| APP 启动 | `app_launch` | 前台打开 APP |
| AI 对话 | `ai_query_submit` | 提交一次 AI 问答 |
| 拍题 | `photo_submit` | 提交一次拍题请求 |
| 练习 | `practice_answer_submit` | 提交一道练习题答案 |
| 错题操作 | `mistake_add` / `mistake_review` | 新增或复习错题 |
| 同步学习 | `chapter_study_start` | 开始章节学习 |
| 学习规划 | `plan_task_complete` | 完成学习任务 |

### 3.2 学习活跃定义

在"活跃"基础上，进一步满足以下**任一**条件为"学习活跃"：

- AI 提问 ≥ 1 次
- 拍题 ≥ 1 次
- 练习答题 ≥ 1 次
- 章节学习时长 ≥ 60 秒
- 错题复习 ≥ 1 次
- 背诵练习 ≥ 1 次
- 作文提交 ≥ 1 次

### 3.3 生命周期阶段定义与流转规则

```
                 ┌──────────┐
                 │   new    │  注册后未产生核心行为
                 └────┬─────┘
                      │ 首次产生核心行为
                      ▼
              ┌──────────────┐
         ┌───▶│    active     │◀──────────────────┐
         │    └──────┬───────┘                    │
         │           │ 连续 7 天未活跃             │ 回流: 活跃
         │           ▼                            │ (原为silent)
         │    ┌──────────────┐                    │
         │    │    silent     │────────────────────┤
         │    └──────┬───────┘                    │
         │           │ 连续 30 天未活跃            │ 回流: 活跃
         │           ▼                            │ (原为churned)
         │    ┌──────────────┐                    │
         │    │   churned    │────────────────────┘
         │    └──────────────┘
         │           │
         └───────────┘ 长期回流后再次沉默/流失
```

| 阶段 | 进入条件 | 退出条件 |
|------|---------|---------|
| `new` | 注册后，未完成首次核心行为 | 完成首次核心行为 → `active` |
| `active` | 产生核心行为 | 连续 7 天无活跃 → `silent` |
| `silent` | 连续 7 天无活跃 | 恢复活跃 → `active` |
| `churned` | 连续 30 天无活跃 | 恢复活跃 → `returned`（临时态，24h 后变为 `active`） |
| `returned` | 从 `churned` 恢复活跃 | 24h 后自动变为 `active` |

> **配置化**: 各阶段的天数阈值通过配置中心管理，支持按学段差异化配置。

### 3.4 留存率计算公式

```
N日留存率 = (第N日仍活跃的用户数 / 队列初始用户数) × 100%

队列类型:
- registration_cohort: 以注册日为队列日期
- first_active_cohort: 以首次活跃日为队列日期
- first_paid_cohort: 以首次付费日为队列日期
```

### 3.5 连续活跃天数（学习打卡联动）

```
今日活跃:
  if last_active_date == yesterday:
    consecutive_days += 1
  else if last_active_date == today:
    // 已更新过，跳过
  else:
    consecutive_days = 1

今日未活跃 (日终检查):
  if last_active_date == yesterday:
    // 还在连续中，等待今日结束
  else if last_active_date < yesterday:
    consecutive_days = 0  // 连续中断
```

## 4. 事件处理流程

### 4.1 实时活跃标记（Kafka Consumer）

```
用户行为事件
    │
    ▼
┌─────────────────────────────────────┐
│  ActivityEventConsumer              │
│  (Kafka consumer group)             │
│                                     │
│  1. 过滤: 只处理活跃相关事件          │
│  2. 提取 user_id + event_type       │
│  3. Redis PFADD activity:dau:{date} │
│  4. 维度 PFADD (grade/stage/...)    │
│  5. 更新 last_active (Redis SET)    │
│  6. 更新连续天数 (Redis INCR/SET)   │
│  7. 投递到日汇总 Kafka topic        │
└─────────────────────────────────────┘
```

### 4.2 日终聚合任务（Celery 定时任务）

```python
# tasks/activity_aggregation.py

from celery import shared_task
from datetime import date, timedelta
import logging

logger = logging.getLogger(__name__)


@shared_task(
    name="activity.aggregate_daily",
    max_retries=3,
    default_retry_delay=300,
    soft_time_limit=1800,
)
def aggregate_daily_activity(stat_date: str = None):
    """
    日终聚合任务 - 每天 01:00 执行，聚合前一天数据。
    
    流程:
    1. 从 Redis HyperLogLog 读取 DAU 基数
    2. 从 Kafka 日汇总 topic 回填 user_daily_activity
    3. 计算维度拆分指标写入 activity_metrics_daily
    4. 更新 user_lifecycle 表
    5. 计算留存数据写入 retention_cohort
    """
    target = date.fromisoformat(stat_date) if stat_date else date.today() - timedelta(days=1)
    
    try:
        # Step 1: 持久化 HLL → MySQL
        _persist_hll_counts(target)
        
        # Step 2: 批量回填日活跃明细 (从 Kafka 汇总表)
        _backfill_daily_activity(target)
        
        # Step 3: 维度指标聚合
        _aggregate_metrics(target)
        
        # Step 4: 生命周期更新
        _update_lifecycle(target)
        
        # Step 5: 留存计算
        _calculate_retention(target)
        
        logger.info(f"Daily activity aggregation completed for {target}")
        
    except Exception as e:
        logger.error(f"Daily activity aggregation failed for {target}: {e}")
        raise aggregate_daily_activity.retry(exc=e)


def _persist_hll_counts(target: date):
    """将 Redis HLL 结果持久化到 MySQL"""
    from core.redis import get_redis_client
    
    r = get_redis_client()
    
    # 总 DAU
    total_key = f"activity:dau:{target.isoformat()}"
    total_dau = r.pfcount(total_key)
    
    # 更新到 activity_metrics_daily
    from models.activity import ActivityMetricsDaily
    ActivityMetricsDaily.upsert(
        stat_date=target,
        dimension_type="total",
        dimension_value="all",
        dau=total_dau,
    )
    
    # 维度 DAU
    dimensions = _get_active_dimensions(target)
    for dim_type, dim_values in dimensions.items():
        for val in dim_values:
            dim_key = f"activity:dau:{target.isoformat()}:{dim_type}:{val}"
            dim_dau = r.pfcount(dim_key)
            ActivityMetricsDaily.upsert(
                stat_date=target,
                dimension_type=dim_type,
                dimension_value=val,
                dau=dim_dau,
            )


def _update_lifecycle(target: date):
    """批量更新用户生命周期状态"""
    from models.activity import UserLifecycle, UserDailyActivity
    from extensions.db import db
    
    # 查找当日活跃的用户
    active_users = (
        UserDailyActivity.query
        .filter(UserDailyActivity.stat_date == target, UserDailyActivity.is_active == 1)
        .with_entities(UserDailyActivity.user_id)
        .all()
    )
    active_user_ids = {u.user_id for u in active_users}
    
    # 批量 upsert 生命周期
    for uid in active_user_ids:
        lifecycle = UserLifecycle.query.filter_by(user_id=uid).first()
        if not lifecycle:
            # 新用户
            lifecycle = UserLifecycle(
                user_id=uid,
                current_stage="active",
                stage_updated_at=target,
                first_active_date=target,
                last_active_date=target,
                total_active_days=1,
                consecutive_days=1,
                max_consecutive_days=1,
                silent_days=0,
                last_7d_active_days=1,
                last_30d_active_days=1,
            )
            db.session.add(lifecycle)
        else:
            _advance_lifecycle_on_active(lifecycle, target)
    
    # 标记沉默/流失 (对昨日未活跃的用户)
    _mark_silent_and_churned(target)
    
    db.session.commit()


def _advance_lifecycle_on_active(lifecycle, target: date):
    """活跃用户生命周期推进"""
    prev = lifecycle.last_active_date
    
    if prev == target:
        return  # 当天已处理
    
    # 更新基础字段
    lifecycle.last_active_date = target
    lifecycle.total_active_days += 1
    lifecycle.silent_days = 0
    
    # 连续天数
    if prev == (target - timedelta(days=1)):
        lifecycle.consecutive_days += 1
    else:
        lifecycle.consecutive_days = 1
    
    lifecycle.max_consecutive_days = max(
        lifecycle.max_consecutive_days, lifecycle.consecutive_days
    )
    
    # 阶段流转
    old_stage = lifecycle.current_stage
    if old_stage == "new":
        lifecycle.current_stage = "active"
        lifecycle.stage_updated_at = target
    elif old_stage == "silent":
        lifecycle.current_stage = "active"
        lifecycle.stage_updated_at = target
    elif old_stage == "churned":
        lifecycle.current_stage = "returned"
        lifecycle.stage_updated_at = target
        lifecycle.returned_at = target
        lifecycle.return_count += 1
    
    # 滑动窗口更新
    lifecycle.last_7d_active_days = _count_active_in_window(
        lifecycle.user_id, target - timedelta(days=6), target
    )
    lifecycle.last_30d_active_days = _count_active_in_window(
        lifecycle.user_id, target - timedelta(days=29), target
    )


def _mark_silent_and_churned(target: date):
    """标记沉默和流失用户"""
    from models.activity import UserLifecycle
    from extensions.db import db
    from core.config import get_config
    
    cfg = get_config()
    silent_threshold = cfg.get("lifecycle.silent_days", 7)
    churned_threshold = cfg.get("lifecycle.churned_days", 30)
    
    # 沉默标记: last_active_date <= target - silent_threshold 且当前为 active
    silent_cutoff = target - timedelta(days=silent_threshold)
    newly_silent = UserLifecycle.query.filter(
        UserLifecycle.current_stage.in_(["active", "returned"]),
        UserLifecycle.last_active_date <= silent_cutoff,
        UserLifecycle.last_active_date.isnot(None),
    ).all()
    
    for lc in newly_silent:
        lc.silent_days = (target - lc.last_active_date).days
        if lc.silent_days >= churned_threshold:
            lc.current_stage = "churned"
            lc.churned_at = lc.churned_at or target
            lc.stage_updated_at = target
        else:
            lc.current_stage = "silent"
            lc.stage_updated_at = target
    
    # 已沉默但超过流失阈值的
    still_silent = UserLifecycle.query.filter(
        UserLifecycle.current_stage == "silent",
        UserLifecycle.last_active_date <= target - timedelta(days=churned_threshold),
    ).all()
    
    for lc in still_silent:
        lc.silent_days = (target - lc.last_active_date).days
        lc.current_stage = "churned"
        lc.churned_at = lc.churned_at or target
        lc.stage_updated_at = target
    
    db.session.flush()


def _calculate_retention(target: date):
    """计算留存队列"""
    from models.activity import RetentionCohort, UserDailyActivity
    from extensions.db import db
    
    # 需要计算的 day_offset 列表
    offsets = [0, 1, 2, 3, 4, 5, 6, 7, 14, 30, 60, 90]
    
    for offset in offsets:
        cohort_date = target - timedelta(days=offset)
        if cohort_date < date(2025, 1, 1):
            continue
        
        # 获取该队列的所有用户
        cohort_users = (
            UserDailyActivity.query
            .filter(
                UserDailyActivity.stat_date == cohort_date,
                UserDailyActivity.is_active == 1,
            )
            .with_entities(UserDailyActivity.user_id)
            .all()
        )
        cohort_user_ids = {u.user_id for u in cohort_users}
        cohort_size = len(cohort_user_ids)
        
        if cohort_size == 0:
            continue
        
        # 当日仍活跃的
        retained = (
            UserDailyActivity.query
            .filter(
                UserDailyActivity.stat_date == target,
                UserDailyActivity.is_active == 1,
                UserDailyActivity.user_id.in_(cohort_user_ids),
            )
            .count()
        )
        
        retained_rate = round(retained / cohort_size, 4)
        
        RetentionCohort.upsert(
            cohort_date=cohort_date,
            cohort_type="first_active",
            cohort_size=cohort_size,
            day_offset=offset,
            retained_count=retained,
            retained_rate=retained_rate,
            stat_date=target,
        )
    
    db.session.flush()
```

### 4.3 实时活跃标记处理器

```python
# services/activity_realtime.py

import json
from datetime import date
from core.kafka import get_kafka_producer
from core.redis import get_redis_client

# 活跃相关事件集合
ACTIVE_EVENTS = {
    "app_launch",
    "ai_query_submit",
    "photo_submit",
    "practice_answer_submit",
    "mistake_add",
    "mistake_review",
    "chapter_study_start",
    "plan_task_complete",
}

# 学习相关事件集合
LEARNING_EVENTS = {
    "ai_query_submit",
    "photo_submit",
    "practice_answer_submit",
    "chapter_study_start",
    "mistake_review",
    "recitation_practice",
    "essay_submit",
}


async def process_activity_event(event: dict):
    """
    处理单个行为事件，实时更新活跃状态。
    
    Args:
        event: 埋点事件，包含 user_id, event_name, properties, user_context 等
    """
    user_id = event.get("user_id")
    event_name = event.get("event_name")
    
    if not user_id or event_name not in ACTIVE_EVENTS:
        return
    
    today = date.today()
    today_str = today.isoformat()
    r = get_redis_client()
    
    # 1. DAU HyperLogLog
    r.pfadd(f"activity:dau:{today_str}", str(user_id))
    
    # 2. 维度 HLL
    user_ctx = event.get("user_context", {})
    grade = user_ctx.get("grade_code")
    stage = user_ctx.get("stage_code")
    channel = user_ctx.get("channel")
    member_level = user_ctx.get("member_level")
    
    if grade:
        r.pfadd(f"activity:dau:{today_str}:grade:{grade}", str(user_id))
    if stage:
        r.pfadd(f"activity:dau:{today_str}:stage:{stage}", str(user_id))
    if channel:
        r.pfadd(f"activity:dau:{today_str}:channel:{channel}", str(user_id))
    if member_level:
        r.pfadd(f"activity:dau:{today_str}:member:{member_level}", str(user_id))
    
    # 3. 最后活跃日 & 连续天数
    last_active_key = f"activity:user:{user_id}:last_active"
    streak_key = f"activity:user:{user_id}:streak"
    
    last_active = r.get(last_active_key)
    
    if last_active:
        last_active = date.fromisoformat(last_active.decode())
        if last_active == today:
            # 今天已标记过，跳过
            pass
        elif last_active == today - __import__("datetime").timedelta(days=1):
            # 昨天活跃过，连续+1
            r.incr(streak_key)
            r.set(last_active_key, today_str)
        else:
            # 中断了，重新从1开始
            r.set(streak_key, 1)
            r.set(last_active_key, today_str)
    else:
        # 首次
        r.set(streak_key, 1)
        r.set(last_active_key, today_str)
    
    # 4. 投递日汇总事件 (异步批量写入 MySQL)
    producer = get_kafka_producer()
    producer.send(
        topic="activity-daily-aggregate",
        key=str(user_id).encode(),
        value=json.dumps({
            "user_id": user_id,
            "stat_date": today_str,
            "event_name": event_name,
            "is_learning": event_name in LEARNING_EVENTS,
            "timestamp": event.get("timestamp"),
        }).encode(),
    )
```

```python
# services/activity_metrics_cache.py

from datetime import date
from core.redis import get_redis_client

class ActivityMetricsCache:
    """实时活跃指标缓存，为管理后台提供秒级查询"""
    
    METRIC_FIELDS = [
        "dau", "new_users", "learning_users",
        "avg_duration", "avg_ai_queries",
        "paid_users", "online_users",
    ]
    
    @staticmethod
    def get_realtime_metrics(stat_date: date = None) -> dict:
        """获取实时活跃指标"""
        target = stat_date or date.today()
        r = get_redis_client()
        key = f"activity:metrics:{target.isoformat()}"
        
        cached = r.hgetall(key)
        if cached:
            return {k.decode(): _safe_int(v) for k, v in cached.items()}
        
        # 缓存未命中 → 从 MySQL 加载并回填
        from models.activity import ActivityMetricsDaily
        row = ActivityMetricsDaily.query.filter_by(
            stat_date=target,
            dimension_type="total",
            dimension_value="all",
        ).first()
        
        metrics = {}
        if row:
            metrics = {
                "dau": row.dau,
                "new_users": row.new_users,
                "learning_users": row.learning_users,
                "avg_duration": row.avg_duration,
                "paid_users": row.paid_users,
            }
        
        # 叠加实时在线数
        online_count = r.scard("activity:online")
        metrics["online_users"] = online_count
        
        # 叠加 HLL 实时 DAU
        hll_dau = r.pfcount(f"activity:dau:{target.isoformat()}")
        if hll_dau > 0:
            metrics["realtime_dau"] = hll_dau
        
        # 写入缓存
        if metrics:
            r.hmset(key, {k: str(v) for k, v in metrics.items()})
            r.expire(key, 300)  # 5分钟缓存
        
        return metrics
```

## 8. 错误处理

### 8.1 错误码段

| 错误码段 | 说明 |
|---------|------|
| `560xxx` | 活跃度统计相关错误 |
| `560001` | 聚合任务执行失败 |
| `560002` | 留存计算数据缺失 |
| `560003` | HLL 持久化失败 |
| `560004` | 生命周期更新冲突 |
| `560005` | 导出任务超时 |
| `560006` | 查询日期范围超限(最大90天) |
| `560007` | 维度参数无效 |

### 8.2 异常场景处理

| 场景 | 处理策略 |
|------|---------|
| Kafka 消费延迟 | 实时标记靠 Redis，日终聚合有 1h 窗口容错 |
| Redis HLL 丢失 | 从 MySQL user_daily_activity 重建，提供 `backfill` 任务 |
| 日终聚合失败 | Celery 自动重试 3 次，间隔 5min；超过转 DLQ 告警 |
| 留存计算数据不完整 | `retained_count` 记 null，不影响其他 offset 计算 |
| 并发更新生命周期冲突 | 乐观锁 version 字段 + 重试 |
| 大规模用户批量更新 | 分批处理，每批 5000 用户，避免长事务 |

### 8.3 降级策略

| 等级 | 触发条件 | 降级行为 |
|------|---------|---------|
| L1 正常 | 所有服务正常 | 完整功能 |
| L2 延迟 | Kafka 积压 > 10min | 实时数据延迟展示，标注"数据更新延迟" |
| L3 缓存 | Redis 不可用 | 从 MySQL 直查，响应时间增加 |
| L4 精简 | MySQL 慢查询 > 5s | 停止维度拆分查询，仅返回 total 汇总 |
| L5 静态 | 全面故障 | 返回最近一次成功聚合的缓存数据 |

### 12.2 查询服务实现

```python
# services/activity_query.py

from datetime import date, timedelta
from typing import Optional, List
from sqlalchemy import func, and_, case
from extensions.db import db


class ActivityQueryService:
    """活跃度查询服务 - 封装所有查询逻辑"""

    async def get_overview(self, stat_date: date, tenant_id: int = None) -> dict:
        """活跃概览"""
        filters = [ActivityMetricsDaily.stat_date == stat_date]
        if tenant_id:
            filters.append(ActivityMetricsDaily.dimension_type == "tenant")
            filters.append(ActivityMetricsDaily.dimension_value == str(tenant_id))
        else:
            filters.append(ActivityMetricsDaily.dimension_type == "total")
            filters.append(ActivityMetricsDaily.dimension_value == "all")

        row = ActivityMetricsDaily.query.filter(*filters).first()
        if not row:
            return {"code": 404, "msg": "暂无数据"}

        # 环比数据
        prev_row = ActivityMetricsDaily.query.filter(
            ActivityMetricsDaily.stat_date == stat_date - timedelta(days=1),
            ActivityMetricsDaily.dimension_type == "total",
            ActivityMetricsDaily.dimension_value == "all",
        ).first()

        prev_week_row = ActivityMetricsDaily.query.filter(
            ActivityMetricsDaily.stat_date == stat_date - timedelta(days=7),
            ActivityMetricsDaily.dimension_type == "total",
            ActivityMetricsDaily.dimension_value == "all",
        ).first()

        # WAU / MAU (近7天/30天活跃去重)
        wau = self._count_active_users(stat_date - timedelta(days=6), stat_date)
        mau = self._count_active_users(stat_date - timedelta(days=29), stat_date)

        # 生命周期分布
        lifecycle_dist = self._get_lifecycle_distribution()

        return {
            "code": 0,
            "data": {
                "stat_date": stat_date.isoformat(),
                "dau": row.dau,
                "dau_wow": self._calc_pct_change(prev_week_row.dau if prev_week_row else None, row.dau),
                "dau_dod": self._calc_pct_change(prev_row.dau if prev_row else None, row.dau),
                "wau": wau,
                "mau": mau,
                "dau_mau_ratio": round(row.dau / mau, 4) if mau else None,
                "new_users": row.new_users,
                "new_users_wow": self._calc_pct_change(
                    prev_week_row.new_users if prev_week_row else None, row.new_users
                ),
                "new_activated": row.new_activated,
                "activation_rate": row.new_activated / row.new_users if row.new_users else None,
                "learning_users": row.learning_users,
                "learning_ratio": round(row.learning_users / row.dau, 4) if row.dau else None,
                "avg_duration_sec": row.avg_duration,
                "avg_sessions": row.avg_sessions,
                "paid_users": row.paid_users,
                "paid_ratio": round(row.paid_users / row.dau, 4) if row.dau else None,
                "online_users": self._get_online_count(),
                "lifecycle_distribution": lifecycle_dist,
            },
        }

    async def get_retention(
        self,
        cohort_type: str,
        start_date: date,
        end_date: date,
        offsets: List[int],
        grade_code: str = None,
        channel: str = None,
    ) -> dict:
        """留存队列查询"""
        filters = [
            RetentionCohort.cohort_type == cohort_type,
            RetentionCohort.cohort_date >= start_date,
            RetentionCohort.cohort_date <= end_date,
            RetentionCohort.day_offset.in_(offsets),
        ]
        if grade_code:
            filters.append(RetentionCohort.grade_code == grade_code)
        if channel:
            filters.append(RetentionCohort.channel == channel)
        else:
            filters.append(RetentionCohort.grade_code.is_(None))
            filters.append(RetentionCohort.channel.is_(None))

        rows = RetentionCohort.query.filter(*filters).order_by(
            RetentionCohort.cohort_date, RetentionCohort.day_offset
        ).all()

        # 组装成队列矩阵
        cohort_map = {}
        for row in rows:
            key = row.cohort_date.isoformat()
            if key not in cohort_map:
                cohort_map[key] = {
                    "cohort_date": key,
                    "cohort_size": row.cohort_size,
                    "retention": {},
                }
            cohort_map[key]["retention"][str(row.day_offset)] = {
                "count": row.retained_count,
                "rate": float(row.retained_rate) if row.retained_rate else None,
            }

        return {
            "code": 0,
            "data": {
                "cohort_type": cohort_type,
                "offsets": offsets,
                "rows": list(cohort_map.values()),
            },
        }

    def _count_active_users(self, start: date, end: date) -> int:
        """统计日期范围内去重活跃用户"""
        return (
            db.session.query(func.count(func.distinct(UserDailyActivity.user_id)))
            .filter(
                UserDailyActivity.stat_date >= start,
                UserDailyActivity.stat_date <= end,
                UserDailyActivity.is_active == 1,
            )
            .scalar()
        ) or 0

    def _get_lifecycle_distribution(self) -> dict:
        """获取生命周期分布"""
        from models.activity import UserLifecycle
        
        result = (
            db.session.query(
                UserLifecycle.current_stage,
                func.count(UserLifecycle.user_id),
            )
            .group_by(UserLifecycle.current_stage)
            .all()
        )
        return {stage: count for stage, count in result}

    def _get_online_count(self) -> int:
        from core.redis import get_redis_client
        return get_redis_client().scard("activity:online")

    @staticmethod
    def _calc_pct_change(old, new) -> Optional[float]:
        if old is None or old == 0:
            return None
        return round((new - old) / old * 100, 1)
```

### 12.3 回填任务

```python
# tasks/activity_backfill.py

from celery import shared_task
from datetime import date, timedelta
import logging

logger = logging.getLogger(__name__)


@shared_task(
    name="activity.backfill_activity",
    max_retries=2,
    soft_time_limit=3600,
)
def backfill_activity(start_date: str, end_date: str):
    """
    手动回填指定日期范围的活跃数据。
    用于修复数据缺失或数据迁移后的重建。
    
    Args:
        start_date: 起始日期 (YYYY-MM-DD)
        end_date: 结束日期 (YYYY-MM-DD)
    """
    start = date.fromisoformat(start_date)
    end = date.fromisoformat(end_date)
    
    if (end - start).days > 30:
        raise ValueError("单次回填范围不能超过30天")
    
    current = start
    while current <= end:
        logger.info(f"Backfilling activity for {current}")
        
        # 从原始事件重建 user_daily_activity
        _rebuild_daily_from_events(current)
        
        # 重跑聚合
        from tasks.activity_aggregation import (
            _persist_hll_counts,
            _backfill_daily_activity,
            _aggregate_metrics,
            _update_lifecycle,
            _calculate_retention,
        )
        
        _aggregate_metrics(current)
        _update_lifecycle(current)
        _calculate_retention(current)
        
        current += timedelta(days=1)
    
    logger.info(f"Backfill completed: {start_date} to {end_date}")


def _rebuild_daily_from_events(target: date):
    """从原始事件表重建 user_daily_activity"""
    from models.tracking import RawEvent
    from models.activity import UserDailyActivity
    from extensions.db import db
    
    # 查询当天所有活跃相关事件
    events = (
        RawEvent.query
        .filter(
            RawEvent.event_date == target,
            RawEvent.event_name.in_([
                "app_launch", "ai_query_submit", "photo_submit",
                "practice_answer_submit", "chapter_study_start",
                "mistake_add", "mistake_review", "plan_task_complete",
            ]),
        )
        .all()
    )
    
    # 按用户聚合
    user_stats = {}
    for evt in events:
        uid = evt.user_id
        if uid not in user_stats:
            user_stats[uid] = {
                "is_active": True,
                "is_learning": False,
                "session_count": 0,
                "ai_query_count": 0,
                "photo_count": 0,
                "practice_count": 0,
            }
        s = user_stats[uid]
        if evt.event_name in LEARNING_EVENTS:
            s["is_learning"] = True
        if evt.event_name == "ai_query_submit":
            s["ai_query_count"] += 1
        elif evt.event_name == "photo_submit":
            s["photo_count"] += 1
        elif evt.event_name == "practice_answer_submit":
            s["practice_count"] += 1
    
    # 批量 upsert
    for uid, stats in user_stats.items():
        UserDailyActivity.upsert(
            user_id=uid,
            stat_date=target,
            is_active=1 if stats["is_active"] else 0,
            is_learning=1 if stats["is_learning"] else 0,
            ai_query_count=stats["ai_query_count"],
            photo_count=stats["photo_count"],
            practice_count=stats["practice_count"],
        )
    
    db.session.commit()
```
