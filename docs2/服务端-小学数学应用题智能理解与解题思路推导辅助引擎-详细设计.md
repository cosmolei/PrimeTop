## 1. 模块概述

### 1.1 功能目标

面向小学 3-6 年级学生，对数学应用题进行自然语言理解、结构化分析、分步推导和适龄化讲解。不同于初高中理科解题侧重公式推导，小学应用题的核心难点在于：

1. **场景理解**：将自然语言描述的生活场景转化为数学关系
2. **隐含条件提取**：识别题目中未明说但必需的条件（如"来回"意味着距离 ×2）
3. **策略选择**：画图法、列表法、假设法、逆推法等小学数学策略
4. **适龄表达**：用小学生能理解的语言和思维方式讲解，避免代数表达

### 1.2 与已有模块的边界

| 已有模块 | 定位 | 本模块差异 |
|---------|------|-----------|
| 理科解题步骤推导服务 | 初高中数理化，公式推导、模型匹配 | 本模块面向小学，不用方程/代数式，侧重算术思维和画图策略 |
| 基础计算能力诊断引擎 | 口算、速算、竖式计算 | 本模块解决文字应用题的理解与推理，非纯计算 |
| AI 题目智能生成引擎 | 通用题目生成 | 本模块的同类题生成专注应用题场景变式 |
| AI 教育辅导策略引擎 | 通用辅导策略 | 本模块针对应用题提供特定的解题策略模板 |

### 1.3 核心用户场景

```
场景1：学生拍照/输入一道应用题 → 获得分步讲解 + 线段图
场景2：学生追问"为什么用除法" → 获得场景化解释
场景3：学生做完一道题 → 获得同类变式题练习
场景4：学生多次答错行程问题 → 系统识别薄弱类型并推荐专题训练
```

## 5. 自然语言理解管线

### 5.1 处理流程

```
原始题面文本
    │
    ▼
[1. 文本预处理] ──── 分句、去噪、标点规范
    │
    ▼
[2. 实体识别]   ──── 数值、人物、物品、单位、时间、路径
    │
    ▼
[3. 关系抽取]   ──── 数量关系建模（部分-整体、比例、变化等）
    │
    ▼
[4. 隐含条件推导] ── 推理隐含但必需的条件
    │
    ▼
[5. 题型分类]   ──── 匹配应用题类型和子类型
    │
    ▼
[6. 策略选择]   ──── 选择最优解题策略
    │
    ▼
[7. 结构化输出] ──── WordProblemDTO
```

```java
            "相对而行|相向而行|面对面",
            "两物体相向而行的接近速度等于两者速度之和",
            "接近速度 = 速度1 + 速度2"

        new HiddenConditionRule(

            "单独完成|各自完成",
            "工作效率 = 1 ÷ 工作时间",
            "工效 = 1/时间"
        )
    );
    
    /**
     * 执行实体识别
     */
    public ProblemEntities recognize(String text, int gradeLevel) {
        // 第一步：规则匹配快速提取
        ProblemEntities entities = ruleBasedExtract(text);

    }
```

```java
    @Override
    public SolveResult solve(WordProblemDTO problem, int gradeLevel) {

        steps.add(SolveStep.builder()

            .title("理解题意")
            .description(buildUnderstandingText(problem))
            .hint("读题时圈出关键数字和问题，想想它们之间有什么关系")
            .strategy("reading_comprehension")
            .build());
        
        // 步骤2：画线段图
        steps.add(SolveStep.builder()
            .stepNumber(2)
            .title("画线段图分析")
            .description("根据题意画线段图，帮助我们看清数量之间的关系")
            .hint("想一想：谁走得快？谁先出发？路程之间有什么关系？")
            .strategy("line_segment_diagram")
            .build());
        
        // 步骤3：根据线段图列出算式
        String expression = buildExpression(problem);
        steps.add(SolveStep.builder()
            .stepNumber(3)
            .title("列出算式")
            .description("看线段图，" + explainExpressionLogic(expression, gradeLevel))
            .expression(expression)
            .hint("从线段图上找找，要求的这部分对应的是哪段？")
            .strategy("arithmetic_reasoning")
            .build());
        
        // 步骤4：计算
        String result = calculate(expression);
        steps.add(SolveStep.builder()
            .stepNumber(4)
            .title("计算结果")
            .description(expression + " = " + result)
            .result(result)
            .strategy("calculation")
            .build());
        
        // 步骤5：检验并作答
        steps.add(SolveStep.builder()
            .stepNumber(5)
            .title("检验作答")
            .description(buildVerificationText(problem, result))
            .hint("把答案放回原题，看看说得通吗？")
            .strategy("verification")
            .build());
        
        return SolveResult.builder()
            .steps(steps)
            .finalAnswer(result)
            .diagram(generateTravelDiagram(problem))
            .build();
    }
    
    private String buildUnderstandingText(WordProblemDTO problem) {
        // 构建适龄化理解题意文本
        StringBuilder sb = new StringBuilder();
        sb.append("题目告诉我们：\n");
        
        for (NumericValue v : problem.getEntities().getValues()) {
            if (!v.getIsUnknown()) {
                sb.append("• ").append(v.getAttribute())
                  .append("是").append(formatNumber(v.getValue()))
                  .append(v.getUnit()).append("\n");
            }
        }
        
        sb.append("\n要我们求：\n");
        for (NumericValue v : problem.getEntities().getValues()) {
            if (v.getIsUnknown()) {
                sb.append("• ").append(v.getAttribute()).append("\n");
            }
        }
        
        return sb.toString();
    }
    
    /**
     * 数字格式化（适龄化）
     * 小学低年级避免小数表达
     */
    private String formatNumber(Double value) {
        if (value == value.longValue()) {
            return String.valueOf(value.longValue());
        }
        return String.valueOf(value);
    }
```

```java
        steps = ageAdaptPostProcess(steps, problem.getGradeLevel());

        return SolvePlan.builder()
            .problemId(problem.getProblemId())
            .strategy(strategy)
            .steps(steps)
            .diagram(diagram)
            .knowledgePoints(problem.getKnowledgePointIds())
            .build();
    }

     * 渐进式提示：只返回下一步提示
     */
    public SolveStep generateNextHint(WordProblemDTO problem, int currentStep, int hintLevel) {
        String prompt = NEXT_HINT_TEMPLATE
            .replace("{{TEXT}}", problem.getRawText())
            .replace("{{CURRENT_STEP}}", String.valueOf(currentStep))
            .replace("{{HINT_LEVEL}}", String.valueOf(hintLevel))

    /**
     * 适龄化后处理
     * 检查并修正不适合目标年级的表达
     */
    private List<SolveStep> ageAdaptPostProcess(List<SolveStep> steps, int gradeLevel) {
        for (SolveStep step : steps) {
            // 低年级（3-4年级）：避免使用"设未知数x"等代数表达
            if (gradeLevel <= 4) {
                step.setDescription(replaceAlgebraicExpressions(step.getDescription()));
                step.setExpression(replaceAlgebraicExpressions(step.getExpression()));
            }
            
            // 3年级：简化步骤描述，增加生活化比喻
            if (gradeLevel == 3) {
                step.setDescription(simplifyForGrade3(step.getDescription()));
            }
        }
        return steps;
    }
    
    /**
     * 替换代数表达为算术表达
     */
    private String replaceAlgebraicExpressions(String text) {
        if (text == null) return null;
        return text
            .replaceAll("设\\s*\\w+\\s*为\\s*[xX]", "我们要求的数")
            .replaceAll("[xX]\\s*=", "要求的数 = ")
            .replaceAll("方程", "算式")
            .replaceAll("解方程", "计算");
    }
```

```java
        List<DiagramElement> elements = new ArrayList<>();

        // 从实体中提取起点、终点、距离

        NumericValue speed = findValueByAttribute(problem, "速度|每.*行|每.*走");
        NumericValue time = findValueByAttribute(problem, "时间|小时|分钟");

        elements.add(DiagramElement.builder()
            .elementType("point")
            .properties(Map.of("position", "right", "label", "终点"))
            .label("乙地")
            .build());
        
        // 主线段
        elements.add(DiagramElement.builder()
            .elementType("line")
            .properties(Map.of(
                "direction", "right",
                "lengthRatio", 1.0,
                "style", "solid"
            ))

            "text", l.getText(),
            "position", l.getPosition()
        )).toList());
        
        return JsonUtils.toJson(spec);
    }
```

```java
            gradeLevel, AGE_PROFILES.get(6)

        }

        for (var entry : profile.termReplacements().entrySet()) {
            adapted = adapted.replace(entry.getKey(), entry.getValue());
        }
        
        return adapted;
    }
    
    private String getAlternative(String term, int grade) {
```

### 10.1 变式题生成策略

```java
/**
 * 应用题同类变式生成器
 */
@Service
public class WordProblemVariantGenerator {
    
    /**
     * 变式类型
     */
    public enum VariantType {
        SAME_STRUCTURE_DIFFERENT_DATA,   // 同结构换数据
        SAME_STRUCTURE_DIFFERENT_CONTEXT, // 同结构换场景
        REVERSE_PROBLEM,                  // 逆向问题
        ADDITIONAL_CONDITION,             // 增加条件
        MULTI_STEP_EXTENSION,             // 扩展为多步骤
        PARAMETER_GENERALIZATION          // 参数泛化
    }
    
    /**
     * 生成同类变式题
     */
    public VariantQuestion generateVariant(
            WordProblemDTO original,
            VariantType variantType,
            int gradeLevel) {
        
        String prompt = switch (variantType) {
            case SAME_STRUCTURE_DIFFERENT_DATA -> buildSameStructurePrompt(original, gradeLevel);
            case SAME_STRUCTURE_DIFFERENT_CONTEXT -> buildDiffContextPrompt(original, gradeLevel);
            case REVERSE_PROBLEM -> buildReversePrompt(original, gradeLevel);
            case ADDITIONAL_CONDITION -> buildAdditionalConditionPrompt(original, gradeLevel);
            case MULTI_STEP_EXTENSION -> buildMultiStepPrompt(original, gradeLevel);
            case PARAMETER_GENERALIZATION -> buildGeneralizationPrompt(original, gradeLevel);
        };
        
        LlmResponse response = aiModelAdapter.chat(
            ModelTaskType.QUESTION_GENERATION,
            prompt,
            ModelParam.builder()
                .temperature(0.7) // 较高温度确保多样性
                .responseFormat("json_object")
                .build()
        );
        
        VariantQuestion variant = parseVariant(response.getContent());
        
        // 校验题目正确性
        ValidationResult validation = validateVariant(variant, original);
        if (!validation.isValid()) {
            // 重新生成或修复
            variant = repairVariant(variant, validation);
        }
        
        return variant;
    }
    
    /**
     * 同结构换数据 Prompt
     */
    private String buildSameStructurePrompt(WordProblemDTO original, int gradeLevel) {
        return """
            请根据以下小学%d年级应用题，生成一道结构相同但数据不同的同类题。
            
            原题：%s
            
            题型：%s
            解题策略：%s
            
            要求：
            1. 保持题型结构不变（如：行程问题还是行程问题）
            2. 替换所有数值数据（不要用原题的数字）
            3. 数据要适合%d年级学生计算（避免过大或除不尽的数）
            4. 换一个生活场景
            5. 题目表述要清晰完整
            6. 提供标准答案和简要解题过程
            
            输出JSON格式：
            {
              "question": "新题目文本",
              "answer": "标准答案",
              "solveSteps": ["步骤1", "步骤2", "..."],
              "difficulty": "1-5的难度值",
              "problemType": "%s"
            }
            """.formatted(gradeLevel, original.getRawText(), 
                original.getProblemType(), original.getSolveStrategy(),
                gradeLevel, original.getProblemType());
    }
    
    /**
     * 变式题正确性校验
     */
    private ValidationResult validateVariant(VariantQuestion variant, 
                                              WordProblemDTO original) {
        List<String> errors = new ArrayList<>();
        
        // 1. 检查题目是否完整
        if (StringUtils.isBlank(variant.getQuestion())) {
            errors.add("题目文本为空");
        }
        
        // 2. 检查答案是否合理
        if (StringUtils.isBlank(variant.getAnswer())) {
            errors.add("答案为空");
        }
        
        // 3. 用LLM验算答案正确性
        String verificationPrompt = """
            请验算这道小学数学题的答案是否正确：
            
            题目：%s
            答案：%s
            解题过程：%s
            
            请只回答 "correct" 或 "incorrect: [原因]"
            """.formatted(variant.getQuestion(), variant.getAnswer(),
                         String.join("; ", variant.getSolveSteps()));
        
        LlmResponse verifyResponse = aiModelAdapter.chat(
            ModelTaskType.MATH_VERIFICATION,
            verificationPrompt,
            ModelParam.builder().temperature(0.0).build()
        );
        
        if (verifyResponse.getContent().startsWith("incorrect")) {
            errors.add("答案验算失败: " + verifyResponse.getContent());
        }
        
        return new ValidationResult(errors.isEmpty(), errors);
    }
}
```

### 13.2 状态机实现

```java
/**
 * 应用题解题会话状态机
 */
public class WordProblemSessionStateMachine {
    
    public enum State {
        IDLE, ANALYZING, SOLVING, STEP_BY_STEP, 
        SHOW_HINT, SHOW_ANSWER, ANSWERING, RETRY, 
        COMPLETED, PRACTICE, ERROR
    }
    
    public enum Event {
        SUBMIT_PROBLEM, ANALYSIS_DONE, ANALYSIS_FAILED,
        SOLVE_DONE, SOLVE_FAILED,
        NEXT_STEP, REQUEST_HINT, REQUEST_ANSWER,
        SUBMIT_ANSWER, ANSWER_CORRECT, ANSWER_WRONG,
        RETRY_EXHAUSTED, REQUEST_VARIANT,
        CANCEL, TIMEOUT
    }
    
    private static final Map<State, Map<Event, State>> TRANSITIONS = Map.of(
        State.IDLE, Map.of(Event.SUBMIT_PROBLEM, State.ANALYZING),
        
        State.ANALYZING, Map.of(
            Event.ANALYSIS_DONE, State.SOLVING,
            Event.ANALYSIS_FAILED, State.ERROR
        ),
        
        State.SOLVING, Map.of(
            Event.SOLVE_DONE, State.STEP_BY_STEP,
            Event.SOLVE_FAILED, State.ERROR
        ),
        
        State.STEP_BY_STEP, Map.of(
            Event.NEXT_STEP, State.STEP_BY_STEP,  // 循环展示步骤
            Event.REQUEST_HINT, State.SHOW_HINT,
            Event.REQUEST_ANSWER, State.SHOW_ANSWER,
            Event.SUBMIT_ANSWER, State.ANSWERING,
            Event.CANCEL, State.IDLE,
            Event.TIMEOUT, State.IDLE
        ),
        
        State.SHOW_HINT, Map.of(
            Event.NEXT_STEP, State.STEP_BY_STEP,
            Event.SUBMIT_ANSWER, State.ANSWERING
        ),
        
        State.SHOW_ANSWER, Map.of(
            Event.SUBMIT_ANSWER, State.ANSWERING,
            Event.REQUEST_VARIANT, State.PRACTICE
        ),
        
        State.ANSWERING, Map.of(
            Event.ANSWER_CORRECT, State.COMPLETED,
            Event.ANSWER_WRONG, State.RETRY
        ),
        
        State.RETRY, Map.of(
            Event.SUBMIT_ANSWER, State.ANSWERING,
            Event.RETRY_EXHAUSTED, State.SHOW_ANSWER,
            Event.REQUEST_HINT, State.SHOW_HINT
        ),
        
        State.COMPLETED, Map.of(
            Event.REQUEST_VARIANT, State.PRACTICE,
            Event.CANCEL, State.IDLE
        ),
        
        State.PRACTICE, Map.of(
            Event.SUBMIT_PROBLEM, State.ANALYZING,
            Event.CANCEL, State.IDLE
        ),
        
        State.ERROR, Map.of(
            Event.SUBMIT_PROBLEM, State.ANALYZING,
            Event.CANCEL, State.IDLE
        )
    );
    
    public State transition(State current, Event event) {
        Map<Event, State> stateMap = TRANSITIONS.get(current);
        if (stateMap == null || !stateMap.containsKey(event)) {
            throw new IllegalStateTransitionException(
                "Illegal transition: " + current + " + " + event
            );
        }
        return stateMap.get(event);
    }
}
```

```java
/**
 * 应用题解题服务 - 错误处理与降级

@Component
public class WordProblemFallbackHandler {
    
    /**
     * 解析失败降级链
     */
    public WordProblemDTO fallbackAnalyze(String text, int grade, Exception error) {
        
        // 降级1：使用简化规则解析
        try {
            return simpleRuleBasedAnalyze(text, grade);
        } catch (Exception e1) {
            log.warn("规则解析也失败，降级到基础模式", e1);
        }
        
        // 降级2：返回通用结构，不做精细分析
        return WordProblemDTO.builder()
            .rawText(text)
            .gradeLevel(grade)
            .problemType("unknown")
            .difficulty(3)
            .entities(new ProblemEntities())
            .relations(List.of())
            .solveStrategy("general_arithmetic")
            .build();
    }
    
    /**
     * 解题方案生成失败降级链
     */
    public SolvePlan fallbackSolve(WordProblemDTO problem, Exception error) {
        
        // 降级1：检查缓存是否有历史结果
        Optional<SolvePlan> cached = cacheService.getCachedSolvePlan(problem.getProblemId());
        if (cached.isPresent()) {
            return cached.get();
        }
        
        // 降级2：使用备选模型
        try {
            return solveWithFallbackModel(problem);
        } catch (Exception e2) {
            log.error("备选模型也失败", e2);
        }
        
        // 降级3：返回引导性提示，不做完整解析
        return SolvePlan.builder()
            .problemId(problem.getProblemId())
            .strategy(StrategyRecommendation.simple("general"))
            .steps(List.of(
                SolveStep.builder()
                    .stepNumber(1)
                    .title("暂无法自动解析")
                    .description("这道题暂时无法自动解析，建议你：\n" +
                        "1. 重新拍照或输入题目\n" +
                        "2. 试试问AI辅导老师来讲解\n" +
                        "3. 把题目加入错题本，稍后查看")
                    .build()
            ))
            .finalAnswer(null)
            .degraded(true)
            .build();
    }
    
    /**
     * 模型调用失败时的重试策略
     */
    public <T> T executeWithRetry(Supplier<T> action, int maxRetries) {
        int attempts = 0;
        while (attempts < maxRetries) {
            try {
                return action.get();
            } catch (ModelTimeoutException e) {
                attempts++;
                if (attempts >= maxRetries) throw e;
                sleep(calculateBackoff(attempts));
            } catch (ModelRateLimitException e) {
                attempts++;
                int waitSec = extractRetryAfter(e) != null ? 
                    extractRetryAfter(e) : calculateBackoff(attempts);
                sleep(waitSec * 1000);
            }
        }
        throw new RuntimeException("Max retries exceeded");
    }
    
    private int calculateBackoff(int attempt) {
        // 指数退避 + 抖动：1s, 2s, 4s, 8s + 随机抖动
        return (int) (Math.pow(2, attempt) * 1000 + Math.random() * 500);
    }
}
```

```java
@Component
public class WordProblemCacheManager {
    
    // 缓存键模板
    private static final String KEY_ANALYSIS = "wp:analyze:{hash}";     // 解析结果
    private static final String KEY_SOLVE = "wp:solve:{problemId}:{strategy}"; // 解题方案
    private static final String KEY_HINT = "wp:hint:{problemId}:{step}:{level}"; // 提示
    private static final String KEY_VARIANT = "wp:variant:{problemId}:{type}";   // 变式题
    private static final String KEY_WEAKNESS = "wp:weakness:{userId}";  // 薄弱统计
    
    /**
     * 获取或生成解析结果（缓存优先）
     */
    public WordProblemDTO getOrCreateAnalysis(String text, int grade) {
        String hash = DigestUtils.md5Hex(text + "|" + grade);
        String cacheKey = KEY_ANALYSIS.replace("{hash}", hash);
        
        // L1 本地缓存
        WordProblemDTO cached = localCache.getIfPresent(cacheKey);
        if (cached != null) return cached;
        
        // L2 Redis
        cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            localCache.put(cacheKey, cached);
            return cached;
        }
        
        // DB 查询
        WordProblemAnalysis record = analysisRepository.findByProblemHash(hash);
        if (record != null && record.getAnalysisStatus() == 2) {
            cached = parseFromRecord(record);
            cacheToRedis(cacheKey, cached, Duration.ofHours(1));
            return cached;
        }
        
        // LLM 解析
        cached = entityRecognizer.recognizeAndAnalyze(text, grade);
        
        // 异步入库 + 缓存
        cacheToRedis(cacheKey, cached, Duration.ofHours(1));
        asyncSaveAnalysis(record, cached, hash);
        
        return cached;
    }
}
```

```java
/**
 * 应用题解题质量评估器
 */
@Service
public class SolveQualityEvaluator {
    
    /**
     * 多维度质量评分
     */
    public QualityReport evaluate(SolvePlan plan, WordProblemDTO problem) {
        return QualityReport.builder()
            .correctnessScore(evaluateCorrectness(plan, problem))   // 答案正确性
            .ageAppropriateScore(evaluateAgeAppropriateness(plan, problem.getGradeLevel())) // 适龄性
            .stepClarityScore(evaluateStepClarity(plan))            // 步骤清晰度
            .strategyMatchScore(evaluateStrategyMatch(plan, problem)) // 策略匹配度
            .completenessScore(evaluateCompleteness(plan))          // 步骤完整性
            .build();
    }
    
    /**
     * 适龄性检查
     */
    private double evaluateAgeAppropriateness(SolvePlan plan, int grade) {
        double score = 100;
        for (SolveStep step : plan.getSteps()) {
            // 检查是否使用了禁用表达
            for (String forbidden : AgeAdaptiveAdapter.AGE_PROFILES.get(grade).forbiddenTerms()) {
                if (containsForbidden(step.getDescription(), forbidden)) {
                    score -= 20;
                }
            }
            
            // 检查步骤数量是否过多
            if (plan.getSteps().size() > getMaxSteps(grade)) {
                score -= 10;
            }
            
            // 检查语言复杂度（句子长度、生词量）
            double complexity = calculateLanguageComplexity(step.getDescription());
            if (complexity > getMaxComplexity(grade)) {
                score -= 15;
            }
        }
        return Math.max(0, score);
    }
    
    /**
     * 答案正确性交叉验证
     */
    private double evaluateCorrectness(SolvePlan plan, WordProblemDTO problem) {
        // 1. 算术验证：重新计算所有算式
        for (SolveStep step : plan.getSteps()) {
            if (step.getExpression() != null) {
                try {
                    double expected = ArithmeticEvaluator.evaluate(step.getExpression());
                    double actual = Double.parseDouble(step.getResult());
                    if (Math.abs(expected - actual) > 0.001) {
                        return 0; // 计算错误
                    }
                } catch (Exception ignored) {}
            }
        }
        
        // 2. LLM 交叉验证
        boolean verified = llmVerifyAnswer(problem.getRawText(), plan.getFinalAnswer());
        return verified ? 100 : 50;
    }
}
```

```json
  },
  "strategy": "correspondence",
  "estimatedSteps": 4
}
```

```
步骤1 - 理解题意
  小明看书：第一天看了 1/4，第二天看了 2/5，还剩 35 页。
  要我们求：全书多少页？
  💡提示：想想35页对应全书的几分之几？

步骤2 - 求剩余分率
  把全书看作单位"1"
  剩下的分率 = 1 - 1/4 - 2/5
  = 1 - 5/20 - 8/20
  = 7/20
  💡提示：先通分，再相减。1/4 = 5/20，2/5 = 8/20

步骤3 - 找对应关系
  剩下的 35 页 对应全书的 7/20
  也就是说：全书的 7/20 是 35 页
  那么全书 = 35 ÷ 7/20
  💡提示：知道部分的分率和具体的量，就能求总量啦

步骤4 - 计算
  35 ÷ 7/20
  = 35 × 20/7
  = 100（页）
  💡提示：除以一个分数等于乘以它的倒数

步骤5 - 验算
  第一天：100 × 1/4 = 25 页
  第二天：100 × 2/5 = 40 页
  剩余：100 - 25 - 40 = 35 页 ✓
  
答：这本书一共有 100 页。

🔑关键思路：找到"35页"对应的全书分率，用对应量÷对应分率=总量
```

```java
// 学习规划服务调用：获取薄弱题型，生成专项练习计划
public List<PracticeTask> generatePracticeTasks(Long userId, int dailyMinutes) {
    // 获取掌握度低于60%的题型
    List<WordProblemWeakness> weakTypes = weaknessRepository
        .findByUserIdAndMasteryLevelLessThan(userId, 60);
    
    // 按掌握度从低到高排序
    weakTypes.sort(Comparator.comparing(WordProblemWeakness::getMasteryLevel));
    
    // 每种题型分配练习时间
    int minutesPerType = dailyMinutes / Math.min(weakTypes.size(), 3);
    
    return weakTypes.stream()
        .limit(3) // 每天最多练3种薄弱题型
        .map(weak -> PracticeTask.builder()
            .userId(userId)
            .taskType("word_problem_practice")
            .problemType(weak.getProblemType())
            .targetMinutes(minutesPerType)
            .description("专项练习：" + weak.getProblemType() + "（当前掌握度" + 
                         weak.getMasteryLevel() + "%）")
            .build())
        .toList();
}
```
