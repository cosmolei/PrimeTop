# 服务端 - 学科竞赛拔尖人才培养与竞赛专项训练路径智能编排引擎 详细设计

## 1. 概述

### 1.1 模块定位

学科竞赛拔尖人才培养引擎是 PrimeTop 平台面向学有余力、有学科特长或竞赛需求的优秀学生提供的专项训练与培养路径管理服务。区别于同步课堂和常规考点梳理，本模块聚焦于**超纲拓展、竞赛真题、奥赛级思维训练和拔尖人才早期发现**，覆盖数学、物理、化学、生物、信息学五大学科竞赛及英语/语文能力竞赛。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 竞赛人才识别 | 基于日常学习数据、能力画像和测评结果，智能识别有竞赛潜力的学生 |
| 训练路径编排 | 根据竞赛类别、学生水平、备赛时间窗，生成个性化竞赛备考路径 |
| 竞赛内容管理 | 管理竞赛知识点体系、真题库、模拟题库和专项训练模块 |
| 训练过程追踪 | 追踪竞赛训练进度、能力成长和薄弱环节 |
| 竞赛模拟评估 | 提供全真模拟测试环境与成绩预测 |
| 教练匹配推荐 | 为有需要的学生匹配优质竞赛辅导资源（线上课程/推荐教练） |

### 1.3 依赖关系

```
┌─────────────────────────────────────────────────────────────────┐
│                  竞赛训练路径智能编排引擎                          │
├─────────────┬──────────────┬──────────────┬────────────────────┤
│  知识图谱服务 │  题目服务     │  学情分析    │  AI辅导服务         │
│  (竞赛知识树) │  (竞赛题库)   │  (能力画像)   │  (高难度推理)       │
├─────────────┼──────────────┼──────────────┼────────────────────┤
│  用户服务     │  学习规划服务 │  推荐服务     │  知识追踪引擎       │
│  (学生档案)   │  (备赛计划)   │  (课程推荐)   │  (能力动态评估)     │
└─────────────┴──────────────┴──────────────┴────────────────────┘
```

### 1.4 适用学段

| 学段 | 竞赛类型 | 说明 |
|------|----------|------|
| 小学4-6年级 | 华罗庚金杯、希望杯、走美杯等 | 数学启蒙竞赛，兴趣导向 |
| 初中7-9年级 | 全国初中数学/物理/化学联赛 | 竞赛入门，能力分化 |
| 高中10-12年级 | 全国高中数学/物理/化学/生物联赛、CSP-J/S、NOI | 核心竞赛阶段，强基/保送路径 |

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 竞赛信息表 `competition_info`

```sql
CREATE TABLE competition_info (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    competition_code VARCHAR(64) NOT NULL UNIQUE COMMENT '竞赛编码，如 CMOS_2025_JUNIOR',
    name VARCHAR(128) NOT NULL COMMENT '竞赛名称',
    subject ENUM('math','physics','chemistry','biology','informatics','english','chinese') NOT NULL,
    level ENUM('national','provincial','city','district') NOT NULL COMMENT '竞赛级别',
    target_stage ENUM('primary','junior_high','senior_high') NOT NULL,
    organizer VARCHAR(128) COMMENT '主办单位',
    registration_deadline DATE COMMENT '报名截止日期',
    competition_date DATE COMMENT '竞赛日期',
    season VARCHAR(16) COMMENT '赛季标识，如 2025秋',
    status ENUM('draft','announced','registration','ongoing','completed','archived') DEFAULT 'draft',
    difficulty_max INT DEFAULT 10 COMMENT '最高难度等级(1-10)',
    description TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_subject_level (subject, level),
    INDEX idx_date (competition_date),
    INDEX idx_season (season)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='竞赛信息表';
```

#### 2.1.2 竞赛知识体系表 `competition_knowledge_tree`

竞赛知识体系独立于课标知识体系，是超纲知识的结构化组织。

```sql
CREATE TABLE competition_knowledge_node (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    node_code VARCHAR(64) NOT NULL UNIQUE COMMENT '节点编码',
    name VARCHAR(128) NOT NULL COMMENT '知识点名称',
    subject ENUM('math','physics','chemistry','biology','informatics') NOT NULL,
    stage ENUM('primary','junior_high','senior_high') NOT NULL,
    competition_level ENUM('entry','regional','national','olympiad') NOT NULL 
        COMMENT '竞赛层级：入门→省赛→国赛→奥赛',
    parent_id BIGINT COMMENT '父节点ID，NULL为根节点',
    description TEXT COMMENT '知识点描述',
    difficulty INT DEFAULT 5 COMMENT '难度等级(1-10)',
    estimated_hours DECIMAL(5,1) COMMENT '预估学习时长(小时)',
    prerequisites JSON COMMENT '前置知识点ID列表',
    curriculum_overlap JSON COMMENT '与课标知识点的重叠映射',
    is_key_node TINYINT(1) DEFAULT 0 COMMENT '是否为核心考点',
    sort_order INT DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_subject_stage (subject, stage),
    INDEX idx_parent (parent_id),
    INDEX idx_level (competition_level)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='竞赛知识体系节点表';
```
