# 多厂商推送通道适配层与国内厂商推送平台集成引擎 - 详细设计

## 1. 模块概述

### 1.1 背景与问题

国内 Android 推送生态高度碎片化：华为、小米、OPPO、VIVO、魅族、荣耀各有独立推送 SDK 和服务端 API，通道能力、消息格式、内容审核规则、限频策略各不相同。若不做统一适配，业务代码需感知厂商差异，维护成本极高。

现有 `消息与推送服务` 模块定义了推送的宏观架构（模板、路由、统计），但在推送通道层仅提及 APNs / FCM / HMS 三个抽象通道，未展开国内厂商的具体集成细节。本模块作为推送服务层的**子模块**，聚焦于：

1. 国内 6 大厂商推送平台的服务端 API 集成
2. 设备厂商识别与推送通道智能路由
3. 推送 Token 全生命周期管理
4. 统一消息模型到各厂商消息格式的适配转换
5. 各厂商特有能力（如华为意图推送、小米重要性级别）的抽象利用
6. 推送可达性监控与降级策略

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 推送首屏到达率 | 华为 ≥ 85%，小米 ≥ 90%，OPPO ≥ 80%，VIVO ≥ 80% |
| 单条推送 API 调用延迟 | < 500ms（不含厂商内部投递） |
| 批量推送吞吐 | ≥ 500 条/秒/厂商通道 |
| Token 注册成功率 | ≥ 95% |
| 厂商通道切换对业务透明 | 业务层零感知 |

### 3.1 客户端厂商识别

客户端在 APP 启动时通过系统 API / Build 信息识别设备厂商，并注册对应厂商推送 SDK 获取 Token。

```kotlin
// Android (Kotlin) - 设备厂商识别
object DeviceBrandDetector {

    fun detectBrand(): String {
        val manufacturer = Build.MANUFACTURER.lowercase()
        val brand = Build.BRAND.lowercase()
        val model = Build.MODEL

        return when {
            manufacturer.contains("huawei") || brand.contains("honor") -> {
                // 荣耀已独立，2022年后设备走 Honor Push
                if (brand.contains("honor") && isHonorIndependent()) {
                    "honor"
                } else {
                    "huawei"
                }
            }
            manufacturer.contains("xiaomi") || brand.contains("redmi") -> "xiaomi"
            manufacturer.contains("oppo") || brand.contains("realme") || brand.contains("oneplus") -> "oppo"
            manufacturer.contains("vivo") || brand.contains("iqoo") -> "vivo"
            manufacturer.contains("meizu") -> "meizu"
            else -> "other_android"
        }
    }

    private fun isHonorIndependent(): Boolean {
        // 荣耀独立后(2020.11)的设备使用 Honor Push
        // 可通过 Build.MODEL 出厂日期或特定系统属性判断
        return true
    }

    /** 获取对应厂商SDK的初始化类 */
    fun getPushSdkClass(brand: String): Class<*>? {
        return when (brand) {
            "huawei" -> com.huawei.hms.push.HmsMessaging::class.java
            "honor" -> com.hihonor.push.HonorMessaging::class.java
            "xiaomi" -> com.xiaomi.mipush.sdk.MiPushClient::class.java
            "oppo" -> com.heytap.mspush.PushManager::class.java
            "vivo" -> com.vivo.push.PushClient::class.java
            "meizu" -> com.meizu.cloud.pushsdk.MzPushService::class.java
            else -> null
        }
    }
}
```

### 3.3 服务端推送通道路由策略

```java
/**
 * 推送通道路由决策引擎
 */
@Service
public class PushChannelRouter {

    @Autowired
    private PushDeviceRegMapper deviceRegMapper;

    @Autowired
    private PushVendorConfigMapper vendorConfigMapper;

    /**
     * 为消息选择最优推送通道
     */
    public List<PushTarget> resolveTargets(UnifiedPushMessage message) {
        // 1. 查询用户所有有效设备
        List<PushDeviceReg> devices = deviceRegMapper.findActiveByUserId(message.getUserId());

        if (CollectionUtils.isEmpty(devices)) {
            log.warn("用户 {} 无可用推送设备", message.getUserId());
            return Collections.emptyList();
        }

        // 2. 过滤目标设备
        List<PushDeviceReg> targetDevices = filterTargetDevices(devices, message);

        // 3. 为每个设备确定推送通道
        return targetDevices.stream()
            .map(device -> resolveSingleDevice(device, message))
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
    }

    private PushTarget resolveSingleDevice(PushDeviceReg device, UnifiedPushMessage message) {
        String channel = device.getPushChannel();

        // 通道可用性检查
        PushVendorConfig config = vendorConfigMapper.findByChannelCode(channel);
        if (config == null || !config.isEnabled()) {
            // 通道禁用，尝试降级
            channel = selectFallbackChannel(device);
            if (channel == null) {
                log.warn("设备 {} 无可用推送通道", device.getDeviceId());
                return null;
            }
        }

        // Token 有效性检查
        if (device.getTokenStatus() != 1) {
            log.warn("设备 {} Token 状态异常: {}", device.getDeviceId(), device.getTokenStatus());
            // 加入 Token 刷新队列
            tokenRefreshManager.enqueueRefresh(device);
            // 仍然尝试推送(可能是缓存过期)
        }

        return PushTarget.builder()
            .device(device)
            .channel(channel)
            .build();
    }

    /**
     * 降级通道选择策略
     *
     * 优先级:
     * 1. 厂商通道 → 极光推送(聚合通道)
     * 2. 极光推送 → FCM(如设备支持Google服务)
     * 3. 所有推送失败 → 站内消息 + 短信(高优先级消息)
     */
    private String selectFallbackChannel(PushDeviceReg device) {
        // 国内非华为设备可能支持FCM
        if (!"huawei".equals(device.getDeviceBrand())
                && !"honor".equals(device.getDeviceBrand())) {
            PushVendorConfig fcmConfig = vendorConfigMapper.findByChannelCode("fcm");
            if (fcmConfig != null && fcmConfig.isEnabled()) {
                return "fcm";
            }
        }

        // 兜底: 极光推送
        PushVendorConfig jpushConfig = vendorConfigMapper.findByChannelCode("jpush");
        if (jpushConfig != null && jpushConfig.isEnabled()) {
            return "jpush";
        }

        return null;
    }

    /**
     * 目标设备过滤
     */
    private List<PushDeviceReg> filterTargetDevices(
            List<PushDeviceReg> devices, UnifiedPushMessage message) {

        // 指定了目标设备
        if (CollectionUtils.isNotEmpty(message.getTargetDeviceIds())) {
            Set<String> targetIds = new HashSet<>(message.getTargetDeviceIds());
            return devices.stream()
                .filter(d -> targetIds.contains(d.getDeviceId()))
                .collect(Collectors.toList());
        }

        // 家长管控: 低龄学生只推送到家长设备
        if ("parent".equals(message.getCategory())) {
            return devices; // 家长消息推送到所有设备
        }

        // 默认: 推送到最近活跃的设备(7天内)
        LocalDateTime sevenDaysAgo = LocalDateTime.now().minusDays(7);
        List<PushDeviceReg> recent = devices.stream()
            .filter(d -> d.getLastActiveTime().toInstant()
                .isAfter(Date.from(sevenDaysAgo.atZone(ZoneId.systemDefault()).toInstant()).toInstant()))
            .collect(Collectors.toList());

        return CollectionUtils.isEmpty(recent) ? devices : recent;
    }
}
```

### 4.2 华为 HMS Push 集成

```java
/**
 * 华为 HMS Push 服务端实现
 * 文档: https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/service-introduction-0000001050040060
 */
@Service
public class HuaweiPushProvider implements PushVendorProvider {

    private static final String TOKEN_URL =
        "https://oauth2.cloud.huawei.com/token"; // OAuth2 获取Token
    private static final String PUSH_URL =
        "https://push-api.cloud.huawei.com/v2/%s/messages:send";

    @Value("${push.huawei.app-id}")
    private String appId;
    @Value("${push.huawei.app-secret}")
    private String appSecret;

    private final RedisTemplate<String, String> redisTemplate;

    /** OAuth2 Token 缓存 key */
    private static final String HMS_TOKEN_CACHE_KEY = "push:hms:access_token";

    /**
     * 获取华为 OAuth2 Access Token (缓存1小时)
     */
    private String getAccessToken() {
        String cached = redisTemplate.opsForValue().get(HMS_TOKEN_CACHE_KEY);
        if (StringUtils.isNotBlank(cached)) {
            return cached;
        }

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);

        MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
        params.add("grant_type", "client_credentials");
        params.add("client_secret", appSecret);
        params.add("client_id", appId);

        HttpEntity<MultiValueMap<String, String>> entity = new HttpEntity<>(params, headers);

        ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
            TOKEN_URL, entity, JsonNode.class);

        if (resp.getStatusCode().is2xxSuccessful() && resp.getBody() != null) {
            String accessToken = resp.getBody().get("access_token").asText();
            int expiresIn = resp.getBody().get("expires_in").asInt(3600);
            // 提前5分钟过期
            redisTemplate.opsForValue().set(HMS_TOKEN_CACHE_KEY,
                accessToken, expiresIn - 300, TimeUnit.SECONDS);
            return accessToken;
        }

        throw new PushException("获取华为AccessToken失败");
    }

    @Override
    public String getChannelCode() {
        return "hms";
    }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            String accessToken = getAccessToken();
            String url = String.format(PUSH_URL, appId);

            // 构建华为推送请求体
            Map<String, Object> payload = buildHmsPayload(message, device);

            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            headers.setBearerAuth(accessToken);

            HttpEntity<Map<String, Object>> entity = new HttpEntity<>(payload, headers);
            ResponseEntity<JsonNode> resp = restTemplate.postForEntity(url, entity, JsonNode.class);

            if (resp.getStatusCode().is2xxSuccessful() && resp.getBody() != null) {
                JsonNode body = resp.getBody();
                String code = body.path("code").asText();
                if ("80000000".equals(code)) {
                    // 成功
                    String msgId = body.path("msgId").asText();
                    return PushResult.success(msgId);
                } else {
                    // 华为具体错误码处理
                    return handleHmsError(code, body.path("msg").asText());
                }
            }

            return PushResult.fail("HMS_HTTP_ERROR", resp.getStatusCode().toString());

        } catch (Exception e) {
            log.error("华为推送异常: msgId={}, deviceId={}", message.getMsgId(),
                device.getDeviceId(), e);
            return PushResult.fail("HMS_EXCEPTION", e.getMessage());
        }
    }

    /**
     * 构建华为推送请求体
     *
     * 华为消息结构参考:
     * https://developer.huawei.com/consumer/cn/doc/HMSCore-References/https-api-0000001050986197
     */
    private Map<String, Object> buildHmsPayload(UnifiedPushMessage message, PushDeviceReg device) {
        Map<String, Object> payload = new HashMap<>();

        // 目标Token
        payload.put("token", Collections.singletonList(device.getPushToken()));

        // 消息体
        Map<String, Object> msg = new HashMap<>();

        // 通知栏消息
        if (message.getPushType() == PushType.NOTIFICATION) {
            Map<String, Object> notification = new HashMap<>();
            notification.put("title", message.getTitle());
            notification.put("body", message.getBody());
            notification.put("click_action", buildClickAction(message));

            // 华为重要性级别映射
            String importance = mapImportanceForHms(message.getImportance());
            if (importance != null) {
                notification.put("importance", importance);
            }

            // 大图模式
            if (StringUtils.isNotBlank(message.getImageUrl())) {
                notification.put("image", message.getImageUrl());
            }

            // 声音/振动
            if (message.getImportance() == Importance.HIGH) {
                notification.put("sound", "/raw/bell");
                notification.put("vibrate_config", Map.of("duration", 500));
            }

            msg.put("notification", notification);
        }

        // 透传消息
        if (message.getPushType() == PushType.PASS_THROUGH) {
            Map<String, Object> data = new HashMap<>();
            data.putAll(message.getExtras());
            data.put("msg_id", message.getMsgId());
            data.put("title", message.getTitle());
            data.put("body", message.getBody());
            msg.put("data", JsonUtils.toJson(data));
        }

        // Android 特定配置
        Map<String, Object> androidConfig = new HashMap<>();
        androidConfig.put("collapse_key", -1); // 不折叠
        if (message.getTtlSeconds() != null) {
            androidConfig.put("ttl", message.getTtlSeconds() + "s");
        }

        // 华为特性: 意图推送(直达指定页面)
        if (StringUtils.isNotBlank(message.getClickAction())) {
            Map<String, Object> intent = new HashMap<>();
            intent.put("url", message.getClickAction());
            androidConfig.put("notification", Map.of("click_action", intent));
        }

        msg.put("android", androidConfig);

        payload.put("message", msg);
        return payload;
    }

    /**
     * 华为重要性映射
     * 华为支持: LOW | NORMAL | HIGH
     */
    private String mapImportanceForHms(Importance importance) {
        return switch (importance) {
            case LOW -> "LOW";
            case NORMAL -> "NORMAL";
            case HIGH -> "HIGH";
        };
    }

    /**
     * 华为错误码处理
     * 参考: https://developer.huawei.com/consumer/cn/doc/HMSCore-References/api-errors-0000001050040082
     */
    private PushResult handleHmsError(String code, String msg) {
        return switch (code) {
            case "80000001" -> PushResult.fail("HMS_TOKEN_INVALID",
                "Token无效或已过期，需客户端重新注册", true);
            case "80000002" -> PushResult.fail("HMS_TOKEN_FREQ_LIMIT",
                "Token推送频率超限");
            case "80100000" -> PushResult.fail("HMS_SYSTEM_ERROR",
                "华为系统内部错误");
            case "80200001" -> PushResult.fail("HMS_OAUTH_TOKEN_INVALID",
                "OAuth Token无效", true);
            default -> PushResult.fail("HMS_ERROR_" + code, msg);
        };
    }

    @Override
    public BatchPushResult batchSend(List<UnifiedPushMessage> messages,
                                      List<PushDeviceReg> devices) {
        // 华为支持单次最多 500 个 token
        BatchPushResult result = new BatchPushResult();
        List<List<PushDeviceReg>> batches = Lists.partition(
            devices.stream().collect(Collectors.toList()), 500);

        for (List<PushDeviceReg> batch : batches) {
            // 每个batch共享同一条消息(群发场景)
            UnifiedPushMessage msg = messages.get(0);
            PushResult batchResult = send(msg, batch.get(0)); // 简化: 实际应批量
            result.merge(batchResult);
        }
        return result;
    }

    @Override
    public boolean validateToken(String token) {
        // 华为无直接校验Token的API，通过推送结果间接判断
        return StringUtils.isNotBlank(token) && token.startsWith("IQ");
    }

    @Override
    public void handleCallback(VendorCallback callback) {
        // 华为回执回调处理
        // body: {"statuscode":0,"message":"success","data":[{"appid":"xxx","msgid":"xxx","status":0}]}
        JsonNode body = callback.getBody();
        JsonNode dataArray = body.path("data");
        for (JsonNode item : dataArray) {
            String vendorMsgId = item.path("msgid").asText();
            int status = item.path("status").asInt(-1);
            // status: 0=成功 2=失败 6=Token无效 8=Token频率限制
            pushDeliveryService.updateStatus(vendorMsgId, mapHmsStatus(status));
        }
    }

    private DeliveryStatus mapHmsStatus(int status) {
        return switch (status) {
            case 0 -> DeliveryStatus.DELIVERED;
            case 2 -> DeliveryStatus.FAILED;
            case 6 -> DeliveryStatus.TOKEN_INVALID;
            default -> DeliveryStatus.UNKNOWN;
        };
    }

    private Map<String, Object> buildClickAction(UnifiedPushMessage message) {
        Map<String, Object> action = new HashMap<>();
        if (StringUtils.isNotBlank(message.getClickAction())) {
            action.put("type", 1); // 打开应用自定义页面
            action.put("intent", message.getClickAction());
        } else {
            action.put("type", 3); // 打开APP首页
        }
        return action;
    }
```

```java
/**
 * OPPO Push 服务端实现
 * 文档: https://push.oppo.com/
 * 注意: OPPO 个人开发者推送有严格限制
 *   - 日推送量限制: 每日累计推送不超过 threshold
 *   - 通知栏消息内容需符合审核规范
 *   - OPPO 系统对后台进程管控严格，强烈推荐使用系统级推送
 */
@Service
public class OppoPushProvider implements PushVendorProvider {

    @Value("${push.oppo.app-key}")
    private String appKey;
    @Value("${push.oppo.master-secret}")
    private String masterSecret;

    private static final String AUTH_URL =
        "https://api.push.oppo.com/server/v1/auth";
    private static final String PUSH_URL =
        "https://api.push.oppo.com/server/v1/message/notification/unicast";
    private static final String BATCH_PUSH_URL =
        "https://api.push.oppo.com/server/v1/message/notification/multicast";

    private static final String OPPO_AUTH_CACHE_KEY = "push:oppo:auth_token";

    /**
     * OPPO 认证Token获取(有效期24小时，需缓存)
     */
    private String getAuthToken() {
        String cached = redisTemplate.opsForValue().get(OPPO_AUTH_CACHE_KEY);
        if (StringUtils.isNotBlank(cached)) {
            return cached;
        }

        long timestamp = System.currentTimeMillis();
        String sign = DigestUtils.sha256Hex(appKey + timestamp + masterSecret);

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);

        MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
        params.add("app_key", appKey);
        params.add("sign", sign);
        params.add("timestamp", String.valueOf(timestamp));

        HttpEntity<MultiValueMap<String, String>> entity =
            new HttpEntity<>(params, headers);

        ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
            AUTH_URL, entity, JsonNode.class);

        if (resp.getStatusCode().is2xxSuccessful()
                && resp.getBody() != null
                && resp.getBody().path("code").asInt() == 0) {
            String token = resp.getBody().at("/data/auth_token").asText();
            redisTemplate.opsForValue().set(OPPO_AUTH_CACHE_KEY,
                token, 23, TimeUnit.HOURS); // 提前1小时刷新
            return token;
        }

        throw new PushException("获取OPPO认证Token失败");
    }

    @Override
    public String getChannelCode() {
        return "oppo";
    }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            String authToken = getAuthToken();

            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);
            headers.set("auth_token", authToken);

            MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
            params.add("registration_id", device.getPushToken());
            params.add("message_id", message.getMsgId());

            // OPPO 消息体(JSON字符串)
            Map<String, Object> notification = new HashMap<>();
            notification.put("title", message.getTitle());
            notification.put("content", message.getBody());
            notification.put("sub_title", ""); // 副标题

            // OPPO 通知级别
            // CALL_NOTIFICATION = 高优先级(响铃/振动)
            // NOTIFICATION = 普通通知
            // OTHER = 低优先级
            notification.put("notification_type", mapOppoChannelType(message));

            // 点击动作
            Map<String, Object> actionParams = new HashMap<>();
            if (StringUtils.isNotBlank(message.getClickAction())) {
                actionParams.put("off_line", true);
                actionParams.put("action_type", 1); // 打开APP内页
                actionParams.put("activity", message.getClickAction());
            } else {
                actionParams.put("off_line", true);
                actionParams.put("action_type", 0); // 打开APP首页
            }
            notification.put("action_parameters", actionParams);

            // 大图
            if (StringUtils.isNotBlank(message.getImageUrl())) {
                notification.put("big_picture", message.getImageUrl());
            }

            // 自定义参数
            Map<String, Object> appMessage = new HashMap<>();
            appMessage.put("extras", message.getExtras());
            params.add("app_message", JsonUtils.toJson(appMessage));

            params.add("notification", JsonUtils.toJson(notification));

            // TTL
            if (message.getTtlSeconds() != null) {
                params.add("expire_time",
                    String.valueOf(message.getTtlSeconds()));
            }

            HttpEntity<MultiValueMap<String, String>> entity =
                new HttpEntity<>(params, headers);

            ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
                PUSH_URL, entity, JsonNode.class);

            if (resp.getStatusCode().is2xxSuccessful()
                    && resp.getBody() != null) {
                JsonNode body = resp.getBody();
                int code = body.path("code").asInt(-1);
                if (code == 0) {
                    String msgId = body.at("/data/message_id").asText();
                    return PushResult.success(msgId);
                }
                return handleOppoError(code, body.path("message").asText());
            }

            return PushResult.fail("OPPO_HTTP_ERROR",
                resp.getStatusCode().toString());

        } catch (Exception e) {
            log.error("OPPO推送异常", e);
            return PushResult.fail("OPPO_EXCEPTION", e.getMessage());
        }
    }

    /**

     *
     * 注意: OPPO ColorOS 对通知渠道管控严格
     * - 高优先级消息会展示在"通知"渠道，用户可手动关闭
     * - 低优先级在"其他"渠道，可能被系统折叠
     */
    private int mapOppoChannelType(UnifiedPushMessage message) {
        if (message.getImportance() == Importance.HIGH) {
            return 2; // CALL_NOTIFICATION
        } else if (message.getImportance() == Importance.LOW) {
            return 3; // OTHER
        }
        return 1; // NOTIFICATION
    }

    private PushResult handleOppoError(int code, String msg) {
        return switch (code) {

            case 1001 -> PushResult.fail("OPPO_REGID_INVALID",
```

```java
/**

 * 注意:
 *   - VIVO 系统对推送管控最严格
 *   - 默认通知渠道为"运营消息"，量有限
 *   - 系统消息需要单独申请权限(审核严格)
 *   - VIVO 对内容审核有要求，标题/内容中不得包含特定敏感词
 */
@Service
public class VivoPushProvider implements PushVendorProvider {

    @Value("${push.vivo.app-id}")
    private String appId;
    @Value("${push.vivo.app-key}")
    private String appKey;
    @Value("${push.vivo.app-secret}")
    private String appSecret;

    private static final String AUTH_URL =
        "https://api-push.vivo.com.cn/message/auth";
    private static final String PUSH_URL =
        "https://api-push.vivo.com.cn/message/sendToList";

    private static final String VIVO_AUTH_CACHE_KEY = "push:vivo:auth_token";

    @Override
    public String getChannelCode() {
        return "vivo";
    }

    private String getAuthToken() {
        String cached = redisTemplate.opsForValue().get(VIVO_AUTH_CACHE_KEY);
        if (StringUtils.isNotBlank(cached)) {
            return cached;
        }

        long timestamp = System.currentTimeMillis();
        String sign = DigestUtils.md5Hex(appId + appKey + timestamp + appSecret);

        Map<String, Object> body = new HashMap<>();
        body.put("appId", appId);
        body.put("appKey", appKey);
        body.put("timestamp", timestamp);
        body.put("sign", sign);

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);

        HttpEntity<Map<String, Object>> entity = new HttpEntity<>(body, headers);
        ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
            AUTH_URL, entity, JsonNode.class);

        if (resp.getStatusCode().is2xxSuccessful()
                && resp.getBody() != null
                && "0".equals(resp.getBody().path("code").asText())) {
            String token = resp.getBody().at("/data/authToken").asText();
            redisTemplate.opsForValue().set(VIVO_AUTH_CACHE_KEY,
                token, 11, TimeUnit.HOURS);
            return token;
        }

        throw new PushException("获取VIVO认证Token失败");
    }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            String authToken = getAuthToken();

            Map<String, Object> body = new HashMap<>();
            body.put("authToken", authToken);
            body.put("notifyId", Math.abs(message.getMsgId().hashCode()));

            // VIVO 消息分类: 1=运营消息 2=系统消息
            // 系统消息需要额外资质审核，默认使用运营消息
            int classification = message.getImportance() == Importance.HIGH ? 2 : 1;
            body.put("classification", classification);

            // VIVO 消息内容
            Map<String, Object> content = new HashMap<>();
            content.put("title", message.getTitle());
            content.put("body", message.getBody());
            content.put("notifyType", mapVivoNotifyType(message.getImportance()));
            content.put("netType", 1); // 1=WiFi 2=移动网络 0=不限

            // 点击行为
            Map<String, Object> clientCustomMap = new HashMap<>();
            if (StringUtils.isNotBlank(message.getClickAction())) {
                clientCustomMap.put("fc", message.getClickAction()); // forward content
            }
            if (message.getExtras() != null) {
                clientCustomMap.putAll(message.getExtras());
            }
            content.put("clientCustomMap", clientCustomMap);

            // 大图
            if (StringUtils.isNotBlank(message.getImageUrl())) {
                content.put("bigPicture", message.getImageUrl());
            }

            body.put("content", content);
            body.put("regIdList", Collections.singletonList(device.getPushToken()));

            // TTL (VIVO 最长7天)
            if (message.getTtlSeconds() != null) {
                body.put("timeToLive",
                    Math.min(message.getTtlSeconds(), 604800));
            }

            // 请求时间
            body.put("requestTime", System.currentTimeMillis());

            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            HttpEntity<Map<String, Object>> entity = new HttpEntity<>(body, headers);

            ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
                PUSH_URL, entity, JsonNode.class);

            if (resp.getStatusCode().is2xxSuccessful()
                    && resp.getBody() != null) {
                JsonNode respBody = resp.getBody();
                String code = respBody.path("code").asText();
                if ("0".equals(code)) {
                    String taskId = respBody.at("/data/taskId").asText();
                    return PushResult.success(taskId);
                }
                return handleVivoError(code,
                    respBody.path("msg").asText());
            }

            return PushResult.fail("VIVO_HTTP_ERROR",
                resp.getStatusCode().toString());

        } catch (Exception e) {
            log.error("VIVO推送异常", e);
            return PushResult.fail("VIVO_EXCEPTION", e.getMessage());
        }
    }

    /**
     * VIVO 通知类型 (位运算)
     * 1=响铃 2=振动 4=呼吸灯 8=通知栏图标
     */
    private int mapVivoNotifyType(Importance importance) {
        return switch (importance) {
            case LOW -> 8;              // 仅图标
            case NORMAL -> 2 | 8;       // 振动+图标
            case HIGH -> 1 | 2 | 4 | 8; // 全部
        };
    }

    /**
     * VIVO 错误码
     * 参考: https://dev.vivo.com.cn/documentCenter/doc/323#w2
     */
    private PushResult handleVivoError(String code, String msg) {
        return switch (code) {
            case "10001" -> PushResult.fail("VIVO_PARAM_ERROR", "参数错误");
            case "10003" -> PushResult.fail("VIVO_AUTH_FAIL", "鉴权失败", true);
            case "10006" -> PushResult.fail("VIVO_REGID_INVALID",
                "regId无效", true);
            case "10011" -> PushResult.fail("VIVO_CONTENT_REJECTED",
                "消息内容含敏感词");
            case "10013" -> PushResult.fail("VIVO_FREQ_LIMIT",
                "推送频率超限");
            case "10015" -> PushResult.fail("VIVO_SYSTEM_MSG_LIMIT",
                "系统消息日量超限");
            case "10080" -> PushResult.fail("VIVO_OFFLINE",
```

### 4.6 魅族 Push 集成

```java
/**
 * 魅族 Push 服务端实现
 * 文档: http://open.res.flyme.cn/openfile/2.0/document.html
 * 特点:
 *   - 魅族推送市场份额较小但覆盖部分用户
 *   - API 风格类似 FCM，使用 Authorization Header
 *   - 魅族设备系统(Flyme)对推送管控相对宽松
 */
@Service
public class MeizuPushProvider implements PushVendorProvider {

    @Value("${push.meizu.app-id}")
    private String appId;
    @Value("${push.meizu.app-secret}")
    private String appSecret;

    private static final String PUSH_URL =
        "https://api-push.meizu.com/garcia/api/server/push/unvarnished/pushByPushId";

    @Override
    public String getChannelCode() {
        return "meizu";
    }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            // 魅族签名: sign = MD5(appId + appSecret + sortedParams)
            Map<String, String> params = new TreeMap<>(); // 排序
            params.put("appId", appId);
            params.put("pushIds", device.getPushToken());
            params.put("messageJson", buildMeizuMessageJson(message));
            params.put("taskId", message.getMsgId());
            params.put("strict", "0"); // 0=宽松模式

            // 生成签名
            String signStr = appId + appSecret +
                params.entrySet().stream()
                    .map(e -> e.getKey() + "=" + e.getValue())
                    .collect(Collectors.joining(""));
            String sign = DigestUtils.md5Hex(signStr);
            params.put("sign", sign);

            // POST 请求
            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);

            MultiValueMap<String, String> formData = new LinkedMultiValueMap<>();
            params.forEach(formData::add);

            HttpEntity<MultiValueMap<String, String>> entity =
                new HttpEntity<>(formData, headers);

            ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
                PUSH_URL, entity, JsonNode.class);

            if (resp.getStatusCode().is2xxSuccessful()
                    && resp.getBody() != null) {
                JsonNode body = resp.getBody();
                int code = body.path("code").asInt(-1);
                if (code == 0 || code == 200) {
                    return PushResult.success(
                        body.at("/data/msgId").asText());
                }
                return handleMeizuError(code,
                    body.path("message").asText());
            }

            return PushResult.fail("MEIZU_HTTP_ERROR",
                resp.getStatusCode().toString());

        } catch (Exception e) {
            log.error("魅族推送异常", e);
            return PushResult.fail("MEIZU_EXCEPTION", e.getMessage());
        }
    }

    private String buildMeizuMessageJson(UnifiedPushMessage message) {
        Map<String, Object> msg = new HashMap<>();
        msg.put("title", message.getTitle());
        msg.put("content", message.getBody());

        // 点击行为
        Map<String, Object> click = new HashMap<>();
        if (StringUtils.isNotBlank(message.getClickAction())) {
            click.put("webPage", message.getClickAction());
        } else {
            click.put("app", "com.primetop.app");
        }
        msg.put("click", click);

        // 通知样式
        Map<String, Object> notify = new HashMap<>();
        notify.put("sound",
            message.getImportance() != Importance.LOW);
        notify.put("vibrate",
            message.getImportance() == Importance.HIGH);

        msg.put("notify", notify);
        msg.put("extras", message.getExtras());

        return JsonUtils.toJson(msg);
    }

    private PushResult handleMeizuError(int code, String msg) {
        return switch (code) {
            case 110000 -> PushResult.fail("MEIZU_AUTH_FAIL", "签名验证失败");
            case 110010 -> PushResult.fail("MEIZU_PUSHID_INVALID",
                "pushId 无效", true);
            case 110020 -> PushResult.fail("MEIZU_CONTENT_REJECTED",
                "消息内容不合规");
            case 110030 -> PushResult.fail("MEIZU_FREQ_LIMIT",
                "推送频率超限");
            default -> PushResult.fail("MEIZU_ERROR_" + code, msg);
        };
    }

    @Override
    public void handleCallback(VendorCallback callback) {
        // 魅族送达回执
        // {"taskId":"xxx","pushId":"xxx","status":"delivered","time":123}
        JsonNode body = callback.getBody();
        String taskId = body.path("taskId").asText();
        String status = body.path("status").asText();
        pushDeliveryService.updateStatus(taskId,
            switch (status) {
                case "delivered" -> DeliveryStatus.DELIVERED;
                case "click" -> DeliveryStatus.CLICKED;
                case "failed" -> DeliveryStatus.FAILED;
                default -> DeliveryStatus.UNKNOWN;
            });
    }
}
```

### 4.7 荣耀 Push 集成

```java
/**
 * 荣耀 Push 服务端实现
 * 文档: https://developer.honor.com/cn/doc/guides/101105
 * 注意: 荣耀从华为独立后自建推送服务，API 风格类似 HMS Push
 *       2022年后的荣耀设备(如荣耀80系列及之后)使用 Honor Push
 *       之前的荣耀设备仍使用 HMS Push
 */
@Service
public class HonorPushProvider implements PushVendorProvider {

    @Value("${push.honor.app-id}")
    private String appId;
    @Value("${push.honor.app-secret}")
    private String appSecret;

    private static final String TOKEN_URL =
        "https://oauth2.cloud.honor.cn/token";
    private static final String PUSH_URL =
        "https://push-api.cloud.honor.cn/v2/%s/messages:send";

    private static final String HONOR_TOKEN_CACHE_KEY = "push:honor:access_token";

    private String getAccessToken() {
        String cached = redisTemplate.opsForValue().get(HONOR_TOKEN_CACHE_KEY);
        if (StringUtils.isNotBlank(cached)) {
            return cached;
        }

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_FORM_URLENCODED);

        MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
        params.add("grant_type", "client_credentials");
        params.add("client_secret", appSecret);
        params.add("client_id", appId);

        HttpEntity<MultiValueMap<String, String>> entity = new HttpEntity<>(params, headers);
        ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
            TOKEN_URL, entity, JsonNode.class);

        if (resp.getStatusCode().is2xxSuccessful() && resp.getBody() != null) {
            String accessToken = resp.getBody().get("access_token").asText();
            int expiresIn = resp.getBody().get("expires_in").asInt(3600);
            // 提前5分钟过期，避免临界失效
            redisTemplate.opsForValue().set(HONOR_TOKEN_CACHE_KEY,
                accessToken, expiresIn - 300, TimeUnit.SECONDS);
            return accessToken;
        }
        throw new PushException("获取荣耀AccessToken失败");
    }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            String accessToken = getAccessToken();
            String url = String.format(PUSH_URL, appId);

            Map<String, Object> payload = buildHonorPayload(message, device);

            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            headers.setBearerAuth(accessToken);

            HttpEntity<Map<String, Object>> entity = new HttpEntity<>(payload, headers);
            ResponseEntity<JsonNode> resp = restTemplate.postForEntity(url, entity, JsonNode.class);

            if (resp.getStatusCode().is2xxSuccessful() && resp.getBody() != null) {
                JsonNode body = resp.getBody();
                String code = body.path("code").asText();
                if ("80000000".equals(code)) {
                    // 荣耀成功码与华为一致
                    return PushResult.success(body.path("msgId").asText());
                }
                return handleHonorError(code, body.path("msg").asText());
            }
            return PushResult.fail("HONOR_HTTP_" + resp.getStatusCode().value(),
                "HTTP状态码异常", true);
        } catch (Exception e) {
            log.error("荣耀推送异常 deviceId={}", device.getDeviceId(), e);
            return PushResult.fail("HONOR_EXCEPTION", e.getMessage(), true);
        }
    }

    private Map<String, Object> buildHonorPayload(UnifiedPushMessage message,
                                                    PushDeviceReg device) {
        Map<String, Object> payload = new HashMap<>();
        Map<String, Object> msg = new HashMap<>();
        msg.put("token", List.of(device.getPushToken()));

        if (message.getPushType() == PushType.PASS_THROUGH) {
            // 透传消息（App 在线时自渲染，荣耀对透传有日配额限制，慎用）
            Map<String, Object> data = new HashMap<>();
            data.putAll(message.getExtras());
            data.put("msg_id", message.getMsgId());
            msg.put("data", JsonUtils.toJson(data));
        } else {
            Map<String, Object> notification = new HashMap<>();
            notification.put("title", message.getTitle());
            notification.put("body", message.getBody());

            // 点击行为: 1=intent 直达页面 3=打开应用首页
            Map<String, Object> clickAction = new HashMap<>();
            if (StringUtils.isNotBlank(message.getClickAction())) {
                clickAction.put("type", 1);
                clickAction.put("intent", message.getClickAction());
            } else {
                clickAction.put("type", 3);
            }
            notification.put("clickAction", clickAction);

            // 大图样式（荣耀通知栏支持大图，运营活动消息使用）
            if (StringUtils.isNotBlank(message.getImageUrl())) {
                notification.put("style", 1);
                notification.put("bigImage", message.getImageUrl());
            }
            msg.put("notification", notification);
        }

        Map<String, Object> android = new HashMap<>();
        android.put("importance", mapHonorImportance(message.getImportance()));
        android.put("collapse_key", -1); // 不折叠
        if (message.getTtlSeconds() != null) {
            android.put("ttl", message.getTtlSeconds() + "s");
        }
        msg.put("android", android);

        payload.put("message", msg);
        return payload;
    }

    private String mapHonorImportance(Importance importance) {
        return switch (importance) {
            case LOW -> "LOW";
            case NORMAL -> "NORMAL";
            case HIGH -> "HIGH";
        };
    }

    /**
     * 荣耀错误码处理（高频项，全量以官方错误码表为准）
     */
    private PushResult handleHonorError(String code, String msg) {
        return switch (code) {
            case "80100001" -> PushResult.fail("HONOR_TOKEN_INVALID",
                "Token无效或已过期", true);
            case "80100002" -> PushResult.fail("HONOR_TOKEN_FREQ_LIMIT",
                "Token推送频率超限");
            case "80200001" -> PushResult.fail("HONOR_OAUTH_TOKEN_INVALID",
                "OAuth Token无效", true);
            case "80300002" -> PushResult.fail("HONOR_PAYLOAD_INVALID",
                "消息体不合法");
            case "80300007" -> PushResult.fail("HONOR_CONTENT_REJECTED",
                "消息内容不合规");
            case "80400000" -> PushResult.fail("HONOR_SYSTEM_ERROR",
                "荣耀系统内部错误", true);
            default -> PushResult.fail("HONOR_ERROR_" + code, msg);
        };
    }

    @Override
    public BatchPushResult batchSend(List<UnifiedPushMessage> messages,
                                      List<PushDeviceReg> devices) {
        // 荣耀单请求最多 500 token，与华为同构
        BatchPushResult result = new BatchPushResult();
        UnifiedPushMessage msg = messages.get(0); // 群发场景共享同一消息体
        List<List<PushDeviceReg>> batches = Lists.partition(devices, 500);
        for (List<PushDeviceReg> batch : batches) {
            for (PushDeviceReg device : batch) {
                result.merge(send(msg, device));
            }
        }
        return result;
    }

    @Override
    public boolean validateToken(String token) {
        // 荣耀无独立校验 API，做形态校验
        return StringUtils.isNotBlank(token) && token.length() >= 32;
    }

    @Override
    public void handleCallback(VendorCallback callback) {
        // 荣耀送达回执（需在荣耀开放平台配置回执地址，报文风格与 HMS 通知回执一致）
        // {"statuscode":0,"data":[{"msgid":"xxx","status":0,"token":"xxx"}]}
        JsonNode body = callback.getBody();
        for (JsonNode item : body.path("data")) {
            String vendorMsgId = item.path("msgid").asText();
            int status = item.path("status").asInt(-1);
            pushDeliveryService.updateStatus(vendorMsgId, mapHonorStatus(status));
        }
    }

    private DeliveryStatus mapHonorStatus(int status) {
        return switch (status) {
            case 0 -> DeliveryStatus.DELIVERED;
            case 2 -> DeliveryStatus.FAILED;
            case 6 -> DeliveryStatus.TOKEN_INVALID;
            default -> DeliveryStatus.UNKNOWN;
        };
    }
}
```

### 4.8 Apple APNs 集成（iOS 通道）

```java
/**
 * Apple APNs 服务端实现（Token-Based JWT 认证 + HTTP/2）
 * 文档: https://developer.apple.com/documentation/usernotifications/
 *          establishing-a-token-based-connection-to-apns
 * 生产建议直接使用 Pushy（netty HTTP/2 连接池复用），
 * 本实现以 JDK HttpClient 演示单发语义与错误处理契约。
 */
@Service
public class ApnsPushProvider implements PushVendorProvider {

    @Value("${push.apns.topic}")           // com.primetop.app
    private String topic;
    @Value("${push.apns.key-id}")
    private String keyId;                  // p8 密钥 KeyID
    @Value("${push.apns.team-id}")
    private String teamId;
    @Value("${push.apns.sandbox:false}")
    private boolean sandbox;

    private static final String HOST_PROD = "https://api.push.apple.com";
    private static final String HOST_SANDBOX = "https://api.sandbox.push.apple.com";

    /** p8 私钥与 KeyID/TeamID 从密钥管理服务信封解密加载，禁止落盘明文（红线 C7） */
    private volatile ECPrivateKey privateKey;

    private static final String APNS_JWT_CACHE_KEY = "push:apns:jwt";

    /**
     * 生成 ES256 Provider Token（有效期 ≤1h，缓存 45 分钟）
     */
    private String buildProviderToken() {
        String cached = redisTemplate.opsForValue().get(APNS_JWT_CACHE_KEY);
        if (StringUtils.isNotBlank(cached)) {
            return cached;
        }
        String jwt = JWT.create()
            .withKeyId(keyId)
            .withIssuer(teamId)
            .withIssuedAt(Instant.now())
            .withExpiresAt(Instant.now().plus(45, ChronoUnit.MINUTES))
            .sign(new ECDSASigner(loadPrivateKey())); // ES256
        redisTemplate.opsForValue().set(APNS_JWT_CACHE_KEY, jwt,
            40, TimeUnit.MINUTES);
        return jwt;
    }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            String host = sandbox ? HOST_SANDBOX : HOST_PROD;
            boolean silent = message.getPushType() == PushType.SILENT;

            // apns-priority: HIGH→10(立即) NORMAL/LOW→5(省电随时)
            String priority = message.getImportance() == Importance.HIGH
                && !silent ? "10" : "5";
            // 静默推送必须 push-type=background 且 priority=5
            String pushType = silent ? "background" : "alert";

            HttpRequest request = HttpRequest.newBuilder(
                    URI.create(host + "/3/device/" + device.getPushToken()))
                .header("authorization", "bearer " + buildProviderToken())
                .header("apns-topic", topic)
                .header("apns-push-type", pushType)
                .header("apns-priority", priority)
                .header("apns-expiration",
                    String.valueOf(Instant.now().getEpochSecond()
                        + (message.getTtlSeconds() != null
                            ? message.getTtlSeconds() : 86400)))
                .header("apns-collapse-id",
                    // 同类消息折叠，≤64 字节
                    StringUtils.left(message.getCategory() + ":"
                        + message.getMsgId().hashCode(), 64))
                .timeout(Duration.ofSeconds(5))
                .POST(HttpRequest.BodyPublishers.ofString(
                    buildApsPayload(message, silent)))
                .build();

            HttpResponse<String> resp = httpClient.send(request,
                HttpResponse.BodyHandlers.ofString());

            return switch (resp.statusCode()) {
                case 200 -> PushResult.success(
                    resp.headers().firstValue("apns-unique-id").orElse(""));
                case 410 -> PushResult.fail("APNS_UNREGISTERED",
                    "设备已卸载或 Token 失效", true); // tokenInvalid 语义，见 §5.3
                case 400 -> handleApns400(resp.body());
                case 403 -> PushResult.fail("APNS_AUTH_REJECTED",
                    "Provider Token/Topic 被拒绝", true);
                case 429 -> PushResult.fail("APNS_RATE_LIMITED",
                    "APNs 限流", true);
                case 500, 503 -> PushResult.fail("APNS_SERVER_ERROR",
                    "APNs 服务端错误", true);
                default -> PushResult.fail("APNS_HTTP_" + resp.statusCode(),
                    resp.body(), true);
            };
        } catch (Exception e) {
            log.error("APNs推送异常 deviceId={}", device.getDeviceId(), e);
            return PushResult.fail("APNS_EXCEPTION", e.getMessage(), true);
        }
    }

    /**
     * 构建 APS 负载：
     * - 通知栏: alert/sound/badge + mutable-content(端侧通知服务扩展处理) + thread-id 分组
     * - 静默:   content-available=1，业务数据放自定义键
     */
    private String buildApsPayload(UnifiedPushMessage message, boolean silent) {
        Map<String, Object> payload = new HashMap<>();
        Map<String, Object> aps = new HashMap<>();

        if (silent) {
            aps.put("content-available", 1);
        } else {
            Map<String, Object> alert = new HashMap<>();
            alert.put("title", message.getTitle());
            alert.put("body", message.getBody());
            aps.put("alert", alert);
            aps.put("sound",
                message.getImportance() == Importance.LOW ? null : "default");
            aps.put("mutable-content", 1);
            aps.put("thread-id", message.getCategory()); // 通知中心按类别分组
        }
        payload.put("aps", aps);

        // 业务自定义键（与 extras 平铺合并，msg_id 必带用于回执关联）
        payload.put("msg_id", message.getMsgId());
        if (StringUtils.isNotBlank(message.getClickAction())) {
            payload.put("click_action", message.getClickAction());
        }
        if (message.getExtras() != null) {
            payload.putAll(message.getExtras());
        }
        return JsonUtils.toJson(payload);
    }

    private PushResult handleApns400(String body) {
        // {"reason":"BadDeviceToken"}
        String reason = JsonUtils.parse(body).path("reason").asText("UNKNOWN");
        return switch (reason) {
            case "BadDeviceToken", "ExpiredProviderToken" ->
                PushResult.fail("APNS_" + reason, "Token 无效/Provider Token 过期", true);
            case "PayloadEmpty", "PayloadTooLarge" ->
                PushResult.fail("APNS_" + reason, "消息体为空/超限(4KB)");
            case "BadCollapseField" ->
                PushResult.fail("APNS_BadCollapseField", "collapse-id 超 64 字节");
            default -> PushResult.fail("APNS_" + reason, "请求被拒绝");
        };
    }

    @Override
    public String getChannelCode() { return "apns"; }

    @Override
    public BatchPushResult batchSend(List<UnifiedPushMessage> messages,
                                      List<PushDeviceReg> devices) {
        // APNs 无批量接口，逐条发送（HTTP/2 单连接复用，Pushy 下吞吐足够）
        BatchPushResult result = new BatchPushResult();
        UnifiedPushMessage msg = messages.get(0);
        for (PushDeviceReg device : devices) {
            result.merge(send(msg, device));
        }
        return result;
    }

    @Override
    public boolean validateToken(String token) {
        // APNs Token 为 64 位十六进制串（新格式可更长）
        return StringUtils.isNotBlank(token) && token.matches("[0-9a-fA-F]{64,}");
    }

    @Override
    public void handleCallback(VendorCallback callback) {
        // APNs 无服务端送达回调：
        // 1) Token 失效通过发送响应 410 Unregistered 实时感知（send 内已处理）
        // 2) 送达/打开统计依赖端侧上报（见《客户端-埋点事件体系》push_received/push_clicked）
        throw new UnsupportedOperationException("APNs 无回调通道");
    }
}
```

> **APNs 到达口径说明**：APNs 不提供"已展示"回执，`SENT（已受理）` 即为服务端可见的到达下限，端侧 `push_received` 埋点用于修正展示率统计（对齐《端到端-系统通知投递》§4.3"部分厂商不回执不视为失败"）。

### 4.9 Google FCM 集成（海外/Google 服务可用设备）

```java
/**
 * Google FCM HTTP v1 实现
 * 定位: 海外 Android 主通道 + 国内可装 Google 服务设备的降级备选
 * 注意: 国内网络对 fcm.googleapis.com 不可达，通道整体可用性由
 *       push_vendor_config.enabled 控制（默认国内部署禁用）
 */
@Service
public class FcmPushProvider implements PushVendorProvider {

    @Value("${push.fcm.project-id}")
    private String projectId;

    private static final String PUSH_URL_TMPL =
        "https://fcm.googleapis.com/v1/projects/%s/messages:send";

    /** 服务账号凭据（密钥管理下发），OAuth2 access token 缓存 50 分钟 */
    private GoogleCredentials googleCredentials;
    private static final String FCM_TOKEN_CACHE_KEY = "push:fcm:access_token";

    private String getAccessToken() throws IOException {
        String cached = redisTemplate.opsForValue().get(FCM_TOKEN_CACHE_KEY);
        if (StringUtils.isNotBlank(cached)) {
            return cached;
        }
        googleCredentials.refreshIfExpired();
        String token = googleCredentials.getAccessToken().getTokenValue();
        redisTemplate.opsForValue().set(FCM_TOKEN_CACHE_KEY, token,
            50, TimeUnit.MINUTES);
        return token;
    }

    @Override
    public String getChannelCode() { return "fcm"; }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            String url = String.format(PUSH_URL_TMPL, projectId);

            Map<String, Object> payload = buildFcmPayload(message, device);

            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            headers.setBearerAuth(getAccessToken());

            HttpEntity<Map<String, Object>> entity = new HttpEntity<>(payload, headers);
            ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
                url, entity, JsonNode.class);

            if (resp.getStatusCode().is2xxSuccessful() && resp.getBody() != null) {
                // {"name":"projects/xx/messages/0:1234"} —— name 即消息ID
                return PushResult.success(resp.getBody().path("name").asText());
            }
            return handleFcmError(resp.getStatusCode().value(), resp.getBody());
        } catch (Exception e) {
            log.error("FCM推送异常 deviceId={}", device.getDeviceId(), e);
            return PushResult.fail("FCM_EXCEPTION", e.getMessage(), true);
        }
    }

    private Map<String, Object> buildFcmPayload(UnifiedPushMessage message,
                                                 PushDeviceReg device) {
        Map<String, Object> payload = new HashMap<>();
        payload.put("validate_only", false);

        Map<String, Object> msg = new HashMap<>();
        msg.put("token", device.getPushToken());

        if (message.getPushType() != PushType.PASS_THROUGH) {
            Map<String, Object> notification = new HashMap<>();
            notification.put("title", message.getTitle());
            notification.put("body", message.getBody());
            if (StringUtils.isNotBlank(message.getImageUrl())) {
                notification.put("image", message.getImageUrl());
            }
            msg.put("notification", notification);
        }

        Map<String, Object> android = new HashMap<>();
        android.put("priority",
            message.getImportance() == Importance.HIGH ? "HIGH" : "NORMAL");
        if (message.getTtlSeconds() != null) {
            android.put("ttl", message.getTtlSeconds() + "s");
        }
        android.put("collapse_key", message.getCategory());
        Map<String, Object> androidNotif = new HashMap<>();
        // Android 8+ 通知渠道（客户端注册的渠道 ID）
        androidNotif.put("channel_id", "primetop_" + message.getCategory());
        android.put("notification", androidNotif);
        msg.put("android", android);

        // 自定义数据（透传与点击参数统一放 data）
        Map<String, String> data = new HashMap<>();
        if (message.getExtras() != null) {
            data.putAll(message.getExtras());
        }
        data.put("msg_id", message.getMsgId());
        data.put("click_action", StringUtils.defaultString(message.getClickAction()));
        msg.put("data", data);

        payload.put("message", msg);
        return payload;
    }

    /**
     * FCM v1 错误（google.rpc.Status 风格）
     */
    private PushResult handleFcmError(int httpCode, JsonNode body) {
        String status = body == null ? "UNKNOWN"
            : body.path("error").path("status").asText("UNKNOWN");
        return switch (status) {
            case "UNREGISTERED" -> PushResult.fail("FCM_UNREGISTERED",
                "设备已卸载/Token 失效", true); // tokenInvalid 语义
            case "INVALID_ARGUMENT" -> PushResult.fail("FCM_INVALID_ARGUMENT",
                "请求参数非法");
            case "SENDER_ID_MISMATCH" -> PushResult.fail("FCM_SENDER_MISMATCH",
                "Token 与项目不匹配");
            case "QUOTA_EXCEEDED", "UNAVAILABLE", "INTERNAL" ->
                PushResult.fail("FCM_" + status, "配额/服务暂时不可用", true);
            default -> PushResult.fail("FCM_HTTP_" + httpCode, status, true);
        };
    }

    @Override
    public BatchPushResult batchSend(List<UnifiedPushMessage> messages,
                                      List<PushDeviceReg> devices) {
        // v1 接口单发；批量用 SendMulticast 语义（每请求≤500 token），此处复用逐条

        for (PushDeviceReg device : devices) {
            result.merge(send(msg, device));
        }
        return result;
```

### 4.10 极光推送 JPush 集成（聚合兜底通道）

```java
/**
 * 极光推送兜底通道实现
 * 定位:
 * 1) 无厂商通道设备（小众品牌/无谷歌服务的 other_android）
 * 2) 厂商通道熔断/配额超限时的降级目标（§3.3 fallback 链）
 * 说明: 极光自身也是聚合下发（内部再走各厂商通道），
 *       兜底送达率仍受各厂商通道限制，不承诺优于直连厂商。
 */
@Service
public class JPushProvider implements PushVendorProvider {

    @Value("${push.jpush.app-key}")
    private String appKey;
    @Value("${push.jpush.master-secret}")
    private String masterSecret;

    private static final String PUSH_URL = "https://api.jpush.cn/v3/push";
    private static final String REPORT_URL = "https://report.jpush.cn/v3/received";

    @Override
    public String getChannelCode() { return "jpush"; }

    @Override
    public PushResult send(UnifiedPushMessage message, PushDeviceReg device) {
        try {
            String auth = Base64.getEncoder()
                .encodeToString((appKey + ":" + masterSecret).getBytes(StandardCharsets.UTF_8));

            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            headers.set("Authorization", "Basic " + auth);

            Map<String, Object> body = buildJPushBody(message, device);

            HttpEntity<Map<String, Object>> entity = new HttpEntity<>(body, headers);
            ResponseEntity<JsonNode> resp = restTemplate.postForEntity(
                PUSH_URL, entity, JsonNode.class);

            if (resp.getStatusCode().is2xxSuccessful() && resp.getBody() != null) {
                // {"sendno":"1","msg_id":"123456"}
                return PushResult.success(resp.getBody().path("msg_id").asText());
            }
            return handleJPushError(resp.getStatusCode().value(), resp.getBody());
        } catch (Exception e) {
            log.error("JPush推送异常 deviceId={}", device.getDeviceId(), e);
            return PushResult.fail("JPUSH_EXCEPTION", e.getMessage(), true);
        }
    }

    private Map<String, Object> buildJPushBody(UnifiedPushMessage message,
                                                PushDeviceReg device) {
        Map<String, Object> body = new HashMap<>();
        body.put("platform", List.of("android"));
        body.put("audience", Map.of("registration_id",
            List.of(device.getPushToken()))); // push_token 存极光 registration_id

        Map<String, Object> notification = new HashMap<>();
        Map<String, Object> android = new HashMap<>();
        android.put("title", message.getTitle());
        android.put("alert", message.getBody());
        android.put("builder_id", 1);
        // Android 8+ 通知渠道
        android.put("channel_id", "primetop_" + message.getCategory());
        // 点击路由: 统一由端内 PushRouterActivity 解析 extras.click_action 分发
        android.put("uri_activity", "com.primetop.app.push.PushRouterActivity");

        Map<String, String> extras = new HashMap<>();
        if (message.getExtras() != null) {
            extras.putAll(message.getExtras());
        }
        extras.put("msg_id", message.getMsgId());
        extras.put("click_action", StringUtils.defaultString(message.getClickAction()));
        android.put("extras", extras);
        notification.put("android", android);
        body.put("notification", notification);

        Map<String, Object> options = new HashMap<>();
        options.put("time_to_live",
            message.getTtlSeconds() != null ? message.getTtlSeconds() : 86400);
        options.put("apns_production", true);
        body.put("options", options);
        return body;
    }

    /**
     * 极光 REST v3 错误码（高频项，全量以官方错误码表为准）
     */
    private PushResult handleJPushError(int httpCode, JsonNode body) {
        int code = body == null ? 0 : body.path("error").path("code").asInt(0);
        return switch (code) {
            case 1004 -> PushResult.fail("JPUSH_AUTH_FAIL", "AppKey/MasterSecret 鉴权失败");
            case 1011 -> PushResult.fail("JPUSH_NO_TARGET",
                "无有效目标设备（registration_id 无效）", true); // tokenInvalid 语义
            case 1005 -> PushResult.fail("JPUSH_PAYLOAD_TOO_LARGE", "消息体超限");
            case 2002 -> PushResult.fail("JPUSH_BUSY", "系统繁忙（限流）", true);
            case 2003 -> PushResult.fail("JPUSH_INTERNAL", "系统内部错误", true);
            default -> PushResult.fail("JPUSH_HTTP_" + httpCode,
                body == null ? "" : body.path("error").path("message").asText(), true);
        };
    }

    @Override
    public BatchPushResult batchSend(List<UnifiedPushMessage> messages,
                                      List<PushDeviceReg> devices) {
        // 极光单请求 audience.registration_id 上限 1000
        BatchPushResult result = new BatchPushResult();
        UnifiedPushMessage msg = messages.get(0);
        List<List<PushDeviceReg>> batches = Lists.partition(devices, 1000);
        for (List<PushDeviceReg> batch : batches) {
            for (PushDeviceReg device : batch) {
                result.merge(send(msg, device));
            }
        }
        return result;
    }

    @Override
    public boolean validateToken(String token) {
        // 极光 registration_id: 21 位数字+字母
        return StringUtils.isNotBlank(token) && token.length() >= 19;
    }

    @Override
    public void handleCallback(VendorCallback callback) {
        // 极光无服务端送达回调，到达统计走 Report API 定时拉取（§6.4）
        throw new UnsupportedOperationException("JPush 无回调通道，走 Report 查询");
    }

    /**
     * Report API 查询（由 §6.4 定时任务调用）：
     * POST /v3/received  {"msg_ids":"id1,id2,..."}  （单次 ≤100 个 msg_id）
     * 响应为聚合粒度（android_received 人数），无法回写单条投递记录，
     * 仅用于监控指标 jpush_arrival_rate 计算。
     */
    public JsonNode queryReceived(List<String> msgIds) {
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);
        headers.set("Authorization", "Basic " + Base64.getEncoder()
            .encodeToString((appKey + ":" + masterSecret).getBytes()));
        Map<String, Object> body = Map.of("msg_ids", String.join(",", msgIds));
        return restTemplate.postForEntity(REPORT_URL,
            new HttpEntity<>(body, headers), JsonNode.class).getBody();
    }
}
```

### 5.3 统一发送门面（PushSendFacade）

```java
/**
 * 推送发送唯一入口（上游=《消息与推送服务》§3.3 内部发送接口）
 * 职责: 路由 → 限流/配额/熔断 → 发送 → 结果分类 → 重试/降级 → 记录
 */
@Service
public class PushSendFacade {

    private static final int MAX_RETRY = 2;
    private static final long RETRY_BACKOFF_MS = 500;

    public BatchPushResult send(UnifiedPushMessage message) {
        List<PushTarget> targets = channelRouter.resolveTargets(message);
        BatchPushResult result = new BatchPushResult();
        if (targets.isEmpty()) {
            // 52401: 返回给上游，由上游决定站内兜底（§8 D9）
            result.merge(PushResult.fail("NO_AVAILABLE_TARGET", "无可用推送设备"));
            return result;
        }
        for (PushTarget target : targets) {
            result.merge(sendToTarget(message, target));
        }
        return result;
    }

    private PushResult sendToTarget(UnifiedPushMessage message, PushTarget target) {
        String channel = target.getChannel();
        PushDeliveryLog record = deliveryService.createRecord(
            message, target.getDevice(), channel);

        // ① 通道熔断检查（OPEN → 直接走降级，§8.3）
        if (circuitGuard.isOpen(channel)) {
            return degrade(message, target, record, "CIRCUIT_OPEN");
        }
        // ② 通道限流（Guava RateLimiter, §8.1）
        rateLimitGuard.acquire(channel);
        // ③ 日配额检查（§8.2）
        if (!quotaGuard.tryAcquire(channel)) {
            return degrade(message, target, record, "DAILY_QUOTA_EXCEEDED");
        }

        PushVendorProvider provider = providerRegistry.get(channel); // 52404
        if (provider == null) {
            return degrade(message, target, record, "PROVIDER_NOT_FOUND");
        }

        // ④ 发送 + 分类处理
        PushResult r = provider.send(message, target.getDevice());
        int attempts = 1;

        while (!r.isSuccess() && r.isRetryable()
                && !TokenInvalidClassifier.isTokenInvalid(r)
                && attempts <= MAX_RETRY) {
            // 退避 500ms → 1s → 2s
            sleep(RETRY_BACKOFF_MS * (1L << (attempts - 1)));
            r = provider.send(message, target.getDevice());
            attempts++;
        }

        if (r.isSuccess()) {
            deliveryService.markSent(message.getMsgId(),
                target.getDevice().getDeviceId(), r.getVendorMsgId());
            return r;
        }
        if (TokenInvalidClassifier.isTokenInvalid(r)) {
            // 设备 Token 失效: 标记 + 入刷新队列（§7），本条终态 FAILED
            tokenLifecycleManager.markInvalid(target.getDevice(), r.getErrorCode());
            deliveryService.updateStatusByMsg(r.getVendorMsgId(), DeliveryStatus.FAILED);
            return r;
        }
        // 仍失败 → 降级链（fallback 通道仅尝试一次，不递归）
        if (StringUtils.isNotBlank(target.getFallbackChannel())) {
            PushResult fallback = sendViaFallback(
                message, target, record);
            if (fallback.isSuccess()) {
                metrics.increment("push_fallback_total",
                    "from", channel, "to", target.getFallbackChannel());
                return fallback;
            }
        }
        deliveryService.updateStatusByMsgDevice(message.getMsgId(),
            target.getDevice().getDeviceId(), DeliveryStatus.FAILED);
        return r;
    }
}
```

**单设备发送时序**：

```
上游(消息与推送服务)      PushSendFacade         Router/Limiter/CB      Provider(厂商)      DeliveryService
      │ send(msg) ──────────▶ │                          │                    │                  │
      │                       │ resolveTargets ──────────▶│ (§3.3 路由)        │                  │
      │                       │ createRecord ────────────────────────────────────────────────────▶│ [PENDING]
      │                       │ CB/RateLimiter/Quota ────▶│                    │                  │
      │                       │ send ─────────────────────────────────────────▶│                  │
      │                       │◀─ PushResult ──────────────────────────────────│                  │
      │                       │  ├─ success → markSent ──────────────────────────────────────────▶│ [SENT]
      │                       │  ├─ tokenInvalid → TokenLifecycleManager.markInvalid(§7) + FAILED ▶│
      │                       │  ├─ retryable → backoff×2 重试 → 成功走 markSent                  │
      │                       │  └─ 仍失败 → fallback 通道一次 → 成功 markSent / 失败 FAILED        │
      │◀─ BatchPushResult ────│                                                                  │
厂商回执(异步) ─────────────────────────────────────────── /internal/push/callback/{channel} ─────▶│ [SENT→DELIVERED...]
```

**降级链语义**（对齐 §3.3）：`厂商直连通道 → jpush（聚合）→ fcm（仅 Google 服务可用设备）→ 返回失败由上游站内消息兜底`；`URGENT 账号安全类 → SMS 白名单`（由上游按《端到端-系统通知投递》§4.1 矩阵触发，本模块不直连短信网关）。

### 5.4 批量群发编排

```java
@Service
public class PushBatchOrchestrator {

    /**
     * 批量群发（上游: 管理后台公告发布/运营圈人推送，对齐《E2E-系统通知》§3.7）

    public BatchPushResult broadcast(UnifiedPushMessage message,
                                     List<Long> userIds) {
        Map<String, List<PushTarget>> byChannel = groupByChannel(userIds);
        BatchPushResult total = new BatchPushResult();

        byChannel.forEach((channel, targets) -> {
            List<List<PushTarget>> batches = Lists.partition(targets, 500);
            for (List<PushTarget> batch : batches) {
                BatchPushResult part = sendBatchWithRateLimit(message, batch);
                total.mergeAll(part);
                outbox.emit("push.batch.progress", Map.of(
                    "batchId", message.getMsgId(),
                    "channel", channel,
                    "processed", total.getTotal(),
                    "totalExpected", countAll(byChannel)));
                // 华为透传 429 → 切通知栏形态重发（对齐 E2E §4.4，D11）
            }
        });
        return total;
    }
}
```

```java
/**
 * 厂商回执回调入口（仅内网网关/厂商服务器白名单可达，不经公网 BFF）
 * 部署: /internal/** 网络段 + 网关层 IP 白名单（各厂商回执出口 IP 段）
 */
@RestController
@RequestMapping("/internal/push/callback")
public class VendorCallbackController {

    @PostMapping("/{channel}")
    public ResponseEntity<String> onCallback(
            @PathVariable("channel") String channel,
            @RequestHeader Map<String, String> headers,
            @RequestParam(required = false) Map<String, String> params,
            @RequestBody(required = false) String rawBody) {

        // ① 验签（fail-secure: 验签失败丢弃 + P2 告警，红线 C6）
        if (!callbackSignVerifier.verify(channel, headers, params, rawBody)) {
            metrics.increment("push_callback_sign_fail", "channel", channel);
            return ResponseEntity.status(403).body("sign invalid");
        }

        VendorCallback callback = buildCallback(channel, headers, params, rawBody);

        // ② 幂等：uk(channel_code, record_id)，重复回调直接应答成功
        if (!callbackStore.tryInsert(callback)) {
            return ack(channel);
        }

        // ③ 分发到对应 Provider（apns/fcm/jpush 声明不支持，理论不可达）
        try {
            providerRegistry.get(channel).handleCallback(callback);
        } catch (UnsupportedOperationException e) {
            log.warn("通道 {} 无回调语义却被调用", channel);
        } catch (Exception e) {
            log.error("回调处理失败 channel={} recordId={}",
                channel, callback.getRecordId(), e);
            // 应答 500 促使厂商重试；幂等记录已在 ② 保证不丢
            return ResponseEntity.status(500).body("retry later");
        }
        return ack(channel);
    }
}
```

### 6.2 各厂商验签规则与应答规范

| 厂商 | 回执开通方式 | 验签规则 | 成功应答 |
|------|--------------|----------|----------|
| 华为 HMS | AGC 开通"通知送达回执"并配置回调地址 | 回调 URL 携带配置的鉴权 token 参数比对（常量时间比较） | HTTP 200 |
| 荣耀 | 荣耀开放平台配置回执地址，风格同 HMS | 同 HMS（鉴权 token 比对） | HTTP 200 |
| 小米 | 小米开放平台配置回执 URL | 固定 secret 参数比对 + 出口 IP 白名单 | HTTP 200，body `error=0` |
| OPPO | OPPO 开放平台申请回执权限 | `sign = SHA1(body + appSecret)` 头字段校验 | HTTP 200，`{"code":0}` |
| VIVO | VIVO 开放平台配置回执 | `sign = MD5(taskId + userId + appSecret)` 校验 | HTTP 200，`{"code":0}` |
| 魅族 | 魅族开放平台配置回执 | `sign = MD5(appId + appSecret + sortedParams)`（与发送同法） | HTTP 200 |
| APNs / FCM / JPush | 无服务端回调 | ——（`UnsupportedOperationException`） | —— |

```java
@Component
public class CallbackSignVerifier {

    public boolean verify(String channel, Map<String, String> headers,
                          Map<String, String> params, String rawBody) {
        return switch (channel) {
            case "hms", "honor" -> constantTimeEquals(
                params.get("auth_token"), vendorConfig(channel).getCallbackToken());
            case "mipush" -> constantTimeEquals(
                params.get("secret"), vendorConfig(channel).getCallbackToken());
            case "oppo" -> sha1(rawBody + vendorConfig("oppo").getAppSecret())
                .equalsIgnoreCase(headers.getOrDefault("sign", ""));
            case "vivo" -> md5(params.getOrDefault("taskId", "") + ""
                + params.getOrDefault("userId", "")
                + vendorConfig("vivo").getAppSecret())
                .equalsIgnoreCase(headers.getOrDefault("sign", ""));
            case "meizu" -> verifyMeizuSign(params);
            default -> false; // 未知通道一律拒绝
        };
    }
}
```

> 验签规则字段名以各厂商当日文档为准，上表为集成时的基线实现；`vendorConfig(channel)` 读取 `push_vendor_config`（凭据信封解密，对齐《服务端-密钥管理与敏感配置安全策略》）。

```java
public class TokenLifecycleManager {

    private static final String REFRESH_QUEUE = "push:token:refresh:queue";

    /** 厂商侧确认失效: 状态置 0 + 入刷新队列 + Outbox 事件 */
    public void markInvalid(PushDeviceReg device, String vendorCode) {
        int rows = deviceRegMapper.casUpdateTokenStatus(
            device.getId(), 1, 0);   // CAS 防并发重复
        if (rows > 0) {
            redisTemplate.opsForList().leftPush(REFRESH_QUEUE,
                device.getDeviceId());
            outbox.emit("push.token.invalid", Map.of(
                "userId", device.getUserId(),
                "deviceId", device.getDeviceId(),
                "channel", device.getPushChannel(),
                "vendorCode", vendorCode));
            // 失效风暴检测: 5 分钟内同通道失效 > 1000 → P0 告警（D5，疑似证书/包名变更）
        }
    }

    /** 消费刷新队列（每分钟）: 生成轻量站内消息提示客户端重新注册 */
    @Scheduled(fixedDelay = 60_000)
    public void consumeRefreshQueue() {
        List<String> deviceIds = redisTemplate.opsForList()
```

```java
@Component
public class QuotaGuard {
    public boolean tryAcquire(String channel) {
        Integer quota = configOf(channel).getDailyQuota(); // null=无配额限制
        if (quota == null) return true;
        String key = "push:quota:" + channel + ":" + LocalDate.now();
        Long used = redisTemplate.opsForValue().increment(key);
        if (used == 1) redisTemplate.expire(key, Duration.ofDays(8));
        return used <= quota;   // 超限 → D2 降级（学习类走 fallback，营销类丢弃）
    }
}
```

### 8.4 降级矩阵

| 编号 | 场景 | 处置 |
|------|------|------|
| D1 | 通道 enabled=0（人工禁用） | 路由期即走 fallback 链；管理后台告警确认 |
| D2 | 日配额超限 | 学习/系统类走 fallback；营销类当日丢弃（RATE_LIMIT_DROP）；指标告警 |
| D3 | 厂商 429/频率限制错误 | 退避重试 ≤2 次 → fallback |
| D4 | 厂商宕机/熔断 OPEN | 直接 fallback；半开自动探活恢复 |
| D5 | token 失效风暴（5min 同通道 >1000） | 疑似证书/包名/厂商规则变更 → P0 告警人工介入；期间该通道仅发账号安全类 |
| D6 | 回调验签失败 | 丢弃 + 告警（疑似伪造/厂商规则变更，联系厂商确认后更新 §6.2 规则） |
| D7 | Redis 不可用 | access token 降级本地 Caffeine 缓存（TTL 5min）；限流降级本地令牌桶；投递记录照常写库 |
| D8 | MySQL 不可用 | 推送尽力而为继续发送；投递记录写本地队列（Kafka）恢复后补写；回调暂存 Redis |
| D9 | 全通道耗尽 | 返回上游失败 → 上游站内消息 + WS 长连接兜底；URGENT 账号安全类走 SMS 白名单（上游职责） |
| D10 | APNs 沙盒/生产混发 | 按 app 签名环境路由（测试包 sandbox），生产 token 发沙盒会持续 410 → 隔离测试设备注册表 |
| D11 | 华为透传频控 | 透传 429 → 切通知栏形态重发（对齐《E2E-系统通知》§4.4） |
| D12 | JPush 兜底也超限 | 群发任务降级为分批慢速（big_push_cycle 拉长 + 每批间隔 30s），进度事件通知上游 |

### 10.2 容量估算（DAU 50 万基线）

- 日均推送量：人均 3 条（学习提醒/作业/成就）≈ **150 万条/日**；公告群发峰值单任务 50 万条。
- 峰值 QPS：晚 19:00–21:00 占日量 25% ≈ 52 万条/小时 ≈ **145 QPS**，群发叠加后按 **500 QPS** 设计上限（qps_limit 默认值，单通道充足）。
- `push_delivery_log` 日增 150 万行 → 按月分区，保留 90 天后随分区清理（对齐《存储资源统一生命周期管理》）：

| C8 | 厂商回调原始报文仅存 body_hash（§6.3），全文不落库；对账明细写 ClickHouse 保留 30 天且不含 PII |

## 13. 验收场景

1. 华为设备注册 → 服务端按 brand=huawei 路由 hms 通道，收到 80000000 后 delivery_log 出现 SENT(7) 记录且含 vendor_msg_id。
2. 厂商回执到达 → 状态 SENT→DELIVERED→CLICKED 依序迁移；先到 CLICKED 后到 DELIVERED 的乱序回执被 CAS 拒绝。
3. HMS 回执 status=6（Token 无效）→ token_status 置 0、设备进入刷新队列、发出 push.token.invalid 事件；下次发送该设备被路由层跳过并提示。
4. APNs 发送返回 410 → 归类 tokenInvalid（不重试），与场景 3 同链路。
5. 厂商返回 429 → 按 500ms/1s/2s 退避重试 ≤2 次；仍失败走 fallbackChannel；fallback 成功记录 fallback 通道与指标。
6. 通道人工禁用（enabled=0）→ 发送时路由层直接降级到 jpush，原通道不产生任何厂商调用。
7. 日配额用尽 → 学习类走 fallback、营销类置 RATE_LIMIT_DROP(5)；`push_quota_usage_ratio` 告警在 85% 时提前触发。
8. 熔断开启（失败率>50%）→ 该通道新消息直接降级；1 分钟后半开放 3 条探活，全部成功后恢复 GREEN 并同步 notify_channel。
9. 小米回调 secret 参数错误 → 403 丢弃 + `push_callback_sign_fail` 计数；重放同一回调（record_id 相同）→ 幂等应答成功且状态不二次迁移。
10. 重复注册（换 token）：PUT /devices/token 以 uk_device_user 覆盖，旧 token 不再使用。
11. 账号注销事件 → 该用户全部设备注册记录解绑，后续发送返回 52401。
12. 静默推送（iOS）：aps.content-available=1 + push-type=background + priority=5，端侧无通知栏展示但收到数据回调。
13. 透传消息发华为遇透传频控 → 自动切通知栏形态重发成功（D11）。
14. 群发 50 万人公告 → 分通道并行、通道内 500/批、全局 ≤200/s；进度事件按批上报任务中心。
15. 学生设备收到 category=marketing 的请求 → 路由层过滤，无厂商调用、无记录（C2）。
16. req_payload 落库检查：extras 不出现、body 截断 100 字符（C3）。
17. Redis 宕机演练：access token 走本地缓存、限流本地令牌桶、发送主链路不中断（D7），恢复后回源。
18. 对账任务：制造 48h 无回执的 SENT 记录 >10% → P2 告警清单产出，含通道维度明细。
