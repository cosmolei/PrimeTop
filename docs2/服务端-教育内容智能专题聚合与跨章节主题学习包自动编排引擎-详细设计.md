# 服务端-教育内容智能专题聚合与跨章节主题学习包自动编排引擎-详细设计

## 1. 概述

### 1.1 功能定位

教育内容智能专题聚合与跨章节主题学习包自动编排引擎（以下简称"专题聚合引擎"）是 PrimeTop 平台内容服务层的核心编排组件。它负责将分散在不同教材章节、不同学科、不同内容类型（视频、图文、题目、知识卡片等）中的学习资源，围绕特定**学习主题**进行智能聚合，自动生成结构化、分难度层次的**主题学习包**，供学生在考试备考、假期专题学习、跨章节综合复习等场景下使用。

### 1.2 与现有模块的边界

| 现有模块 | 职责 | 与本引擎的区别 |
|---------|------|--------------|
| 同步课堂章节内容聚合服务 | 按教材版本·年级·章节组织学习流 | 线性章节编排，不跨章节/跨学科 |
| 学习单元动态组装与跨模块知识串联引擎 | 将知识点单元跨模块串联为学习路径 | 聚焦知识点粒度的路径串联，非主题维度聚合 |
| 教育内容结构化模板引擎与内容组装服务 | 内容组装的模板引擎和渲染管线 | 提供组装能力，不负责主题发现和内容筛选 |
| 教育游戏化学习关卡编排引擎 | 游戏化闯关形式的关卡编排 | 以游戏化为核心，非学习内容专题化 |
| 章节同步练习智能编排引擎 | 按章节生成分层练习题组 | 仅题目维度，按章节组织 |

**本引擎的核心差异**：以**学习主题**（如"函数综合应用"、"力学实验与计算"、"古诗文鉴赏与默写"）为中心，跨章节、跨学科地聚合多类型内容，生成可直接发布的主题学习包。

### 1.3 适用范围

- **考试备考专题**：中考/高考高频考点专题包（如"高考导数压轴题突破"）
- **假期专题学习营**：寒暑假主题学习包（如"初一数学有理数专题营"）
- **跨章节知识串讲**：围绕核心概念的综合复习包（如"化学方程式大全"）
- **学科专项强化**：特定题型的集中训练包（如"英语完形填空高频话题"）
- **跨学科综合专题**：结合多学科的主题包（如"数学物理交叉：矢量与力学"）

### 1.4 核心价值

1. **打破教材章节壁垒**：学生复习时需要的往往不是单章内容，而是跨章节的知识整合。
2. **自动化内容发现与聚合**：减少人工运营成本，基于知识图谱和学习效果数据智能编排。
3. **个性化难度适配**：同一主题可生成不同难度层次的包，适配不同水平学生。
4. **内容利用率提升**：优质内容被合理聚合后获得更多曝光，避免内容沉没。

## 3. 数据结构定义

### 3.1 核心表设计

#### 3.1.1 `topic_definition` - 主题定义表

```sql
CREATE TABLE topic_definition (
    id              BIGSERIAL PRIMARY KEY,
    topic_code      VARCHAR(64) NOT NULL UNIQUE,   -- 主题编码，如 GAOKAO_MATH_FUNC
    title           VARCHAR(200) NOT NULL,          -- 主题名称
    subtitle        VARCHAR(500),                   -- 副标题/简介
    topic_type      VARCHAR(32) NOT NULL,           -- EXAM_PREP / HOLIDAY_CAMP / CROSS_CHAPTER / SUBJECT_BOOST / CROSS_SUBJECT
    subject_codes   JSONB NOT NULL,                 -- 涉及学科 ["MATH","PHY"]
    grade_range     JSONB NOT NULL,                 -- 适用年级范围 ["G7","G8","G9"]
    knowledge_node_ids JSONB NOT NULL,              -- 关联知识图谱节点ID列表
    source_type     VARCHAR(32) NOT NULL,           -- AUTO_DISCOVERED / MANUAL_CREATED
    source_rule_id  BIGINT,                         -- 自动发现规则ID（若为自动发现）
    status          VARCHAR(32) NOT NULL DEFAULT 'DRAFT', -- DRAFT / PENDING_REVIEW / APPROVED / PUBLISHED / ARCHIVED
    priority        INT NOT NULL DEFAULT 50,        -- 优先级 0-100
    tags            JSONB DEFAULT '[]',             -- 标签 ["高考","函数","压轴题"]
    cover_image_url VARCHAR(500),                   -- 封面图
    estimated_hours DECIMAL(5,1),                   -- 预计学习时长（小时）
    difficulty_levels JSONB DEFAULT '[1,2,3]',      -- 支持的难度等级
    metadata        JSONB DEFAULT '{}',             -- 扩展元数据
    created_by      BIGINT,                         -- 创建人（管理员ID）
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    published_at    TIMESTAMPTZ,
    archived_at     TIMESTAMPTZ
);

CREATE INDEX idx_topic_status ON topic_definition(status);
CREATE INDEX idx_topic_type_subject ON topic_definition(topic_type, subject_codes);
CREATE INDEX idx_topic_grade ON topic_definition USING GIN(grade_range);
CREATE INDEX idx_topic_knowledge ON topic_definition USING GIN(knowledge_node_ids);
```

#### 3.1.2 `learning_package` - 主题学习包表

```sql
CREATE TABLE learning_package (
    id                  BIGSERIAL PRIMARY KEY,
    package_code        VARCHAR(64) NOT NULL UNIQUE,    -- 学习包编码
    topic_id            BIGINT NOT NULL REFERENCES topic_definition(id),
    title               VARCHAR(200) NOT NULL,
    description         TEXT,
    difficulty_level    INT NOT NULL,                   -- 1=基础 2=提升 3=挑战
    target_user_profile JSONB NOT NULL,                 -- 目标用户画像条件
    content_items       JSONB NOT NULL,                 -- 内容条目列表（见3.1.4）
    structure_config    JSONB NOT NULL,                 -- 包结构配置（见3.1.5）
    total_items         INT NOT NULL DEFAULT 0,         -- 内容条目总数
    estimated_minutes   INT NOT NULL DEFAULT 0,         -- 预计学习时长（分钟）
    version             INT NOT NULL DEFAULT 1,         -- 版本号
    version_hash        VARCHAR(64) NOT NULL,           -- 内容哈希（用于变更检测）
    status              VARCHAR(32) NOT NULL DEFAULT 'DRAFT',
    quality_score       DECIMAL(4,2),                   -- 质量评分 0-100
    auto_generated      BOOLEAN NOT NULL DEFAULT TRUE,  -- 是否自动生成
    generation_task_id  VARCHAR(64),                    -- 生成任务ID
    published_at        TIMESTAMPTZ,
    expires_at          TIMESTAMPTZ,                    -- 过期时间（如假期包）
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE UNIQUE INDEX idx_pkg_code ON learning_package(package_code);
CREATE INDEX idx_pkg_topic ON learning_package(topic_id, difficulty_level);
CREATE INDEX idx_pkg_status ON learning_package(status);
CREATE INDEX idx_pkg_version_hash ON learning_package(version_hash);
```

#### 3.1.3 `package_content_item` - 学习包内容条目表

```sql
CREATE TABLE package_content_item (
    id                  BIGSERIAL PRIMARY KEY,
    package_id          BIGINT NOT NULL REFERENCES learning_package(id) ON DELETE CASCADE,
    sequence_order      INT NOT NULL,                   -- 在包中的顺序位置
    section_id          VARCHAR(32) NOT NULL,           -- 所属段落ID（见结构配置）
    content_type        VARCHAR(32) NOT NULL,           -- VIDEO / ARTICLE / QUESTION / KNOWLEDGE_CARD / EXERCISE / INTERACTIVE
    content_id          BIGINT NOT NULL,                -- 对应内容表的ID
    content_source      VARCHAR(32) NOT NULL,           -- QUESTION_BANK / CONTENT_LIBRARY / KG / GENERATED
    title               VARCHAR(200),                   -- 条目标题
    knowledge_node_ids  JSONB DEFAULT '[]',             -- 关联知识点
    estimated_minutes   INT DEFAULT 5,                  -- 预计用时
    difficulty_level    INT DEFAULT 2,                  -- 难度等级
    is_required         BOOLEAN NOT NULL DEFAULT TRUE,  -- 是否必修（vs选修）
    selection_reason    VARCHAR(32),                    -- 选中原因：KG_LINKED / HIGH_QUALITY / HIGH_USAGE / EXAM_FREQUENCY / MANUAL
    selection_score     DECIMAL(6,3),                   -- 选中得分
    metadata            JSONB DEFAULT '{}',
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_pci_package ON package_content_item(package_id, sequence_order);
CREATE INDEX idx_pci_content ON package_content_item(content_type, content_id);
CREATE INDEX idx_pci_section ON package_content_item(package_id, section_id);
```

#### 3.1.6 `topic_discovery_rule` - 主题发现规则表

```sql
CREATE TABLE topic_discovery_rule (
    id                  BIGSERIAL PRIMARY KEY,
    rule_name           VARCHAR(100) NOT NULL,
    rule_type           VARCHAR(32) NOT NULL,           -- EXAM_FREQUENCY / KNOWLEDGE_CLUSTER / USER_DEMAND / SEASONAL
    subject_codes       JSONB NOT NULL,                 -- 适用学科
    grade_range         JSONB NOT NULL,                 -- 适用年级
    params              JSONB NOT NULL,                 -- 规则参数
    min_content_count   INT NOT NULL DEFAULT 10,        -- 最小可用内容数（低于此数不生成主题）
    quality_threshold   DECIMAL(4,2) DEFAULT 60.00,     -- 内容质量阈值
    enabled             BOOLEAN NOT NULL DEFAULT TRUE,
    last_executed_at    TIMESTAMPTZ,
    execution_interval_hours INT NOT NULL DEFAULT 168,   -- 执行间隔（小时），默认每周
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

## 4. API 接口设计

```
GET /api/v1/admin/topics
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认1 |
| pageSize | int | 否 | 每页条数，默认20 |
| status | string | 否 | 状态筛选 |
| topicType | string | 否 | 主题类型 |
| subjectCode | string | 否 | 学科筛选 |
| keyword | string | 否 | 标题关键词 |

### 5.1 主题自动发现流程

```text
                    ┌─────────────────┐
                    │  XXL-JOB 定时触发 │
```

### 5.2 学习包自动生成流程（核心）

```text
┌──────────────────────────────────────────────────────────────┐
│                  Phase 1: 内容召回 (Recall)                  │
│                                                              │
│  输入: topic_definition + difficulty_level + user_segment    │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ 1.1 知识节点展开                                       │ │
│  │   topic.knowledge_node_ids                             │ │
│  │   → 展开子节点，构建知识子图                            │ │
│  │   → 输出: expanded_kn_ids (Set<long>)                  │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 1.2 多源内容召回                                       │ │
│  │   Source A: 题库 (Question Bank)                       │ │
│  │     - 按 expanded_kn_ids 检索题目                       │ │
│  │     - 按 difficulty_level 过滤                           │ │
│  │     - 按质量分排序                                       │ │
│  │                                                        │ │
│  │   Source B: 内容库 (Content Library)                   │ │
│  │     - 视频、图文、知识卡片                              │ │
│  │     - 按 knowledge_node_ids 关联                        │ │
│  │                                                        │ │
│  │   Source C: 考频数据 (Exam Frequency)                  │ │
│  │     - 标注近3年考试频率                                  │ │
│  │                                                        │ │
│  │   Source D: AI生成内容 (Generated)                     │ │
│  │     - 知识点缺失时调用AI补充生成                        │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 1.3 召回结果汇总去重                                   │ │
│  │   - 同一 content_id 多源命中取最高分                     │ │
│  │   - 输出: recall_pool (List<RecallItem>)               │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
                             │
┌────────────────────────────▼───────────────────────────────┐
│               Phase 2: 质量筛选 (Filter)                    │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ 2.1 质量门控                                            │ │
│  │   - 过滤 quality_score < 阈值的内容                      │ │
│  │   - 过滤 status != APPROVED 的内容                       │ │
│  │   - 过滤过期/下线内容                                    │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 2.2 多样性保障                                          │ │
│  │   - 同一来源占比不超过 60%                               │ │
│  │   - 同一知识点条目不超过总量的 40%                       │ │
│  │   - 内容类型搭配（视频+图文+题目混合）                   │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 2.3 难度梯度校验                                        │ │
│  │   - 检查每个难度等级是否有足够的题目                     │ │
│  │   - 不足时标记需要AI补充生成                             │ │
│  └─────────────────────────┬──────────────────────────────┘ │
└────────────────────────────┬───────────────────────────────┘
                             │
┌────────────────────────────▼───────────────────────────────┐
│             Phase 3: 结构编排 (Arrange)                     │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ 3.1 加载结构模板                                       │ │
│  │   根据 topic_type 选择模板:                             │ │
│  │   EXAM_PREP → EXAM_PREP_STANDARD_v2                    │ │
│  │   HOLIDAY_CAMP → HOLIDAY_CAMP_v3                       │ │
│  │   CROSS_CHAPTER → REVIEW_SYNTHESIS_v1                  │ │
│  │   CUSTOM → 从 topic.metadata 读取                      │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 3.2 逐段落填充内容                                     │ │
│  │                                                        │ │
│  │   for each section in template:                        │ │
│  │     pool = recall_pool.filter(section.contentTypeRule) │ │
│  │     pool = pool.filter(section.difficultyRule)         │ │
│  │     pool = pool.sort(knowledge_coverage, quality,      │ │
│  │                       exam_frequency, usage)           │ │
│  │     selected = greedy_select(pool, section.target)     │ │
│  │     ensure_knowledge_coverage(selected, expanded_kns)  │ │
│  │     assign_sequence_order(selected)                    │ │
│  │     package.sections[section] = selected               │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 3.3 全局优化                                           │ │
│  │   - 检查知识点覆盖率：所有 expanded_kn_ids 至少出现1次   │ │
│  │   - 检查时长合理性：总时长在估算±20%范围                │ │
│  │   - 检查难度递进：段落间难度符合 GRADUAL_INCREASE 规则   │ │
│  │   - 补充缺失内容（触发AI生成）                         │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 3.4 质量评分                                           │ │
│  │   根据覆盖率、多样性、难度梯度、时长合理性               │ │
│  │   计算包质量分 (0-100)                                  │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
                             │
┌────────────────────────────▼───────────────────────────────┐
│           Phase 4: 发布与持久化 (Persist)                   │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐ │
│  │ 4.1 计算 version_hash                                  │ │
│  │   SHA256(sorted_content_ids + difficulty + version)     │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 4.2 版本对比                                           │ │
│  │   if hash == last_version.hash:                        │ │
│  │     skip (内容无变化)                                   │ │
│  │   else:                                                │ │
│  │     version = last_version + 1                         │ │
│  │     persist new version                                │ │
│  │     archive old version (保留历史)                      │ │
│  │     send MQ event: PACKAGE_UPDATED                     │ │
│  └─────────────────────────┬──────────────────────────────┘ │
│                            │                                 │
│  ┌─────────────────────────▼──────────────────────────────┐ │
│  │ 4.3 状态流转                                           │ │
│  │   auto_generated=true → status=DRAFT                   │ │
│  │   → 运营审核 → APPROVED → PUBLISHED                    │ │
│  │   OR                                                   │ │
│  │   auto_publish=true 且 quality_score ≥ 阈值            │ │
│  │   → status=PUBLISHED 直接发布                           │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

```java
public enum TopicType {

    DIAGNOSTIC_TEST,    // 摸底诊断
    CORE_LEARNING,      // 核心知识精讲

    CHALLENGE,          // 压轴挑战
    REVIEW_SUMMARY,     // 复习总结
    EXTENDED_READING    // 拓展阅读

public enum ContentType {
    VIDEO,           // 视频
    ARTICLE,         // 图文
    QUESTION,        // 题目

public enum PackageStatus {
    DRAFT,
    PENDING_AUTO_REVIEW,
    PENDING_REVIEW,
    AUTO_PUBLISHED,
    PUBLISHED,

    REJECTED,

@Data

    private List<Integer> difficultyLevels;

    private Long createdBy;

    private LocalDateTime publishedAt;
}

@Data
@Builder
public class LearningPackage {
    private Long id;
    private String packageCode;
    private Long topicId;
    private String title;
    private String description;
    private Integer difficultyLevel;

    private Integer totalItems;
```

```java
/**
 * 内容召回服务 - 从多数据源检索候选内容

@Service
@RequiredArgsConstructor
public class ContentRecallService {

    private final QuestionBankClient questionBankClient;
    private final ContentLibraryClient contentLibraryClient;
    private final KnowledgeGraphClient kgClient;
    private final ExamFrequencyService examFrequencyService;
    private final RedisTemplate<String, Object> redisTemplate;

    // 召回结果缓存key前缀
    private static final String RECALL_CACHE_PREFIX = "topic:recall:";

    /**
     * 执行内容召回
     *
     * @param topic          主题定义
     * @param difficultyLevel 目标难度等级
     * @return 召回内容池
     */
    public RecallPool recall(TopicDefinition topic, int difficultyLevel) {
        String cacheKey = RECALL_CACHE_PREFIX + topic.getId() + ":d" + difficultyLevel;

        // 尝试命中缓存（5分钟过期）
        RecallPool cached = (RecallPool) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null && cached.size() > 0) {
            return cached;
        }

        // Step 1: 展开知识节点
        Set<Long> expandedKnIds = expandKnowledgeNodes(topic.getKnowledgeNodeIds());

        // Step 2: 多源并行召回
        CompletableFuture<List<RecallItem>> questionFuture =
                recallFromQuestionBank(expandedKnIds, difficultyLevel, topic.getSubjectCodes());
        CompletableFuture<List<RecallItem>> contentFuture =
                recallFromContentLibrary(expandedKnIds, topic.getSubjectCodes());
        CompletableFuture<List<RecallItem>> generatedFuture =
                recallGeneratedContent(expandedKnIds, difficultyLevel, topic.getSubjectCodes());

        // 等待全部完成
        CompletableFuture.allOf(questionFuture, contentFuture, generatedFuture).join();

        List<RecallItem> allItems = new ArrayList<>();
        allItems.addAll(questionFuture.join());
        allItems.addAll(contentFuture.join());
        allItems.addAll(generatedFuture.join());

        // Step 3: 去重（同content_id取最高分）
        Map<String, RecallItem> deduped = allItems.stream()
                .collect(Collectors.toMap(
                        RecallItem::getDedupKey,
                        Function.identity(),
                        (a, b) -> a.getSelectionScore().compareTo(b.getSelectionScore()) >= 0 ? a : b
                ));

        RecallPool pool = new RecallPool(new ArrayList<>(deduped.values()), expandedKnIds);

        // 写入缓存
        redisTemplate.opsForValue().set(cacheKey, pool, Duration.ofMinutes(5));

        return pool;
    }

    /**
     * 展开知识节点 - 获取所有子节点
     */
    private Set<Long> expandKnowledgeNodes(Set<Long> rootKnIds) {
        if (rootKnIds == null || rootKnIds.isEmpty()) {
            return Collections.emptySet();
        }
        // 调用知识图谱服务获取子树
        Set<Long> expanded = new HashSet<>(rootKnIds);
        for (Long rootId : rootKnIds) {
            List<Long> descendants = kgClient.getDescendantNodeIds(rootId, 3); // 最多向下3层
            expanded.addAll(descendants);
        }
        return expanded;
    }

    /**
     * 从题库召回题目
     */
    private CompletableFuture<List<RecallItem>> recallFromQuestionBank(
            Set<Long> knIds, int difficultyLevel, Set<String> subjectCodes) {

        return CompletableFuture.supplyAsync(() -> {
            // ES 查询：知识点关联 + 难度匹配 + 质量过滤
            QuestionSearchRequest request = QuestionSearchRequest.builder()
                    .knowledgeNodeIds(knIds)
                    .difficultyRange(getDifficultyRange(difficultyLevel))
                    .subjectCodes(subjectCodes)
                    .minQualityScore(60)
                    .status("APPROVED")
                    .sort_by("quality_score desc, exam_frequency desc, usage_count desc")
                    .limit(500)  // 召回上限
                    .build();

            List<QuestionDTO> questions = questionBankClient.batchSearch(request);

            return questions.stream()
                    .map(q -> RecallItem.builder()
                            .contentType(ContentType.QUESTION)
                            .contentId(q.getId())
                            .title(q.getTitlePreview())
                            .knowledgeNodeIds(q.getKnowledgeNodeIds())
                            .difficultyLevel(q.getDifficultyLevel())
                            .estimatedMinutes(estimateQuestionMinutes(q))
                            .source("QUESTION_BANK")
                            .selectionScore(calculateQuestionScore(q))
                            .build())
                    .collect(Collectors.toList());
        });
    }

    /**
     * 从内容库召回视频/图文/知识卡片
     */
    private CompletableFuture<List<RecallItem>> recallFromContentLibrary(
            Set<Long> knIds, Set<String> subjectCodes) {

        return CompletableFuture.supplyAsync(() -> {
            ContentSearchRequest request = ContentSearchRequest.builder()
                    .knowledgeNodeIds(knIds)
                    .subjectCodes(subjectCodes)
                    .contentTypes(List.of("VIDEO", "ARTICLE", "KNOWLEDGE_CARD"))
                    .minQualityScore(65)
                    .status("PUBLISHED")
                    .sort_by("quality_score desc, view_count desc")
                    .limit(200)
                    .build();

            List<ContentDTO> contents = contentLibraryClient.search(request);

            return contents.stream()
                    .map(c -> RecallItem.builder()
                            .contentType(ContentType.valueOf(c.getType()))
                            .contentId(c.getId())
                            .title(c.getTitle())
                            .knowledgeNodeIds(c.getKnowledgeNodeIds())
                            .difficultyLevel(c.getDifficultyLevel())
                            .estimatedMinutes(c.getEstimatedMinutes())
                            .source("CONTENT_LIBRARY")
                            .selectionScore(calculateContentScore(c))
                            .build())
                    .collect(Collectors.toList());
        });
    }

    /**
     * 召回AI生成内容（仅在缺口时）
     */
    private CompletableFuture<List<RecallItem>> recallGeneratedContent(
            Set<Long> knIds, int difficultyLevel, Set<String> subjectCodes) {
        return CompletableFuture.supplyAsync(() -> {
            // 这里不做实际生成，只返回预生成的AI内容
            // 实际AI内容生成在编排阶段按需触发
            return Collections.<RecallItem>emptyList();
        });
    }

    /**
     * 计算题目选中得分
     * 综合考量：质量分(40%) + 考频(30%) + 使用量(15%) + 难度匹配度(15%)
     */
    private BigDecimal calculateQuestionScore(QuestionDTO q) {
        double qualityPart = q.getQualityScore() * 0.4;
        double freqPart = Math.min(q.getExamFrequencyScore(), 100) * 0.3;
        double usagePart = Math.min(Math.log10(q.getUsageCount() + 1) * 20, 100) * 0.15;
        double difficultyPart = (100 - Math.abs(q.getDifficultyLevel() - 2) * 30) * 0.15;
        return BigDecimal.valueOf(qualityPart + freqPart + usagePart + difficultyPart)
                .setScale(3, RoundingMode.HALF_UP);
    }

    private BigDecimal calculateContentScore(ContentDTO c) {
        double qualityPart = c.getQualityScore() * 0.4;
        double usagePart = Math.min(Math.log10(c.getViewCount() + 1) * 20, 100) * 0.25;
        double ratingPart = c.getAvgRating() * 20 * 0.2;
        double freshnessPart = Math.max(0, 100 - daysSince(c.getPublishedAt()) * 0.5) * 0.15;
        return BigDecimal.valueOf(qualityPart + usagePart + ratingPart + freshnessPart)
                .setScale(3, RoundingMode.HALF_UP);
    }

    private int[] getDifficultyRange(int targetLevel) {
        return switch (targetLevel) {
            case 1 -> new int[]{1, 2};   // 基础: 难度1-2
            case 2 -> new int[]{2, 3};   // 提升: 难度2-3
            case 3 -> new int[]{3, 4};   // 挑战: 难度3-4
            default -> new int[]{1, 4};
        };
    }

    private int estimateQuestionMinutes(QuestionDTO q) {
        int base = switch (q.getQuestionType()) {
            case "SINGLE_CHOICE" -> 2;
            case "MULTI_CHOICE" -> 3;
            case "FILL_BLANK" -> 3;
            case "SHORT_ANSWER" -> 5;
            case "ESSAY" -> 10;
            case "CALCULATION" -> 8;
            default -> 5;
        };
        // 难度系数加成
        return (int) (base * (1 + q.getDifficultyLevel() * 0.15));
    }

    private long daysSince(LocalDateTime dt) {
        return dt != null ? java.time.Duration.between(dt, LocalDateTime.now()).toDays() : 999;
    }
```

```java
/**

@Service
@RequiredArgsConstructor
public class PackageArrangementService {

    private final StructureTemplateRegistry templateRegistry;
    private final ContentRecallService recallService;

    /**
     * 编排生成学习包
     */
    @Transactional
    public LearningPackage arrange(TopicDefinition topic, int difficultyLevel,
                                    StructureTemplate template, UserProfileSegment userSegment) {

        // 1. 召回内容
        RecallPool pool = recallService.recall(topic, difficultyLevel);

        // 2. 质量筛选
        pool = pool.filter(item -> item.getSelectionScore()
                .compareTo(BigDecimal.valueOf(topic.getQualityThreshold())) >= 0);

        // 3. 逐段落填充
        ContentStructure structure = new ContentStructure();
        structure.setSections(new ArrayList<>());

        Set<Long> coveredKnowledgeNodes = new HashSet<>();
        int sequenceCounter = 0;

        for (StructureTemplate.Section sectionTemplate : template.getSections()) {
            ContentStructure.Section section = arrangeSection(
                    sectionTemplate, pool, difficultyLevel,
                    coveredKnowledgeNodes, topic.getKnowledgeNodeIds(),
                    sequenceCounter
            );
            structure.getSections().add(section);
            sequenceCounter += section.getItems().size();
        }

        // 4. 全局优化 - 检查知识点覆盖
        ensureKnowledgeCoverage(structure, topic.getKnowledgeNodeIds(),
                                 coveredKnowledgeNodes, pool, difficultyLevel);

        // 5. 计算包元数据
        int totalItems = structure.getSections().stream()
                .mapToInt(s -> s.getItems().size())
                .sum();
        int totalMinutes = structure.getSections().stream()
                .mapToInt(s -> s.getItems().stream()
                        .mapToInt(ContentStructure.ContentItem::getEstimatedMinutes)
                        .sum())
                .sum();

        // 6. 计算质量分
        BigDecimal qualityScore = calculatePackageQuality(structure, topic, coveredKnowledgeNodes);

        // 7. 构建实体
        String packageCode = generatePackageCode(topic, difficultyLevel);
        String versionHash = calculateVersionHash(structure, difficultyLevel);

        return LearningPackage.builder()
                .packageCode(packageCode)
                .topicId(topic.getId())
                .title(generatePackageTitle(topic, difficultyLevel))
                .description(generatePackageDescription(topic, difficultyLevel, userSegment))
                .difficultyLevel(difficultyLevel)
                .contentItems(structure)
                .structureConfig(template.toConfig())
                .totalItems(totalItems)
                .estimatedMinutes(totalMinutes)
                .version(1)
                .versionHash(versionHash)
                .status(PackageStatus.DRAFT.name())
                .qualityScore(qualityScore)
                .autoGenerated(true)
                .build();
    }

    /**
     * 编排单个段落
     */
    private ContentStructure.Section arrangeSection(
            StructureTemplate.Section template,
            RecallPool pool,
            int targetDifficulty,
            Set<Long> coveredKnIds,
            Set<Long> topicKnIds,
            int sequenceStart) {

        // 按段落规则过滤候选内容
        List<RecallItem> candidates = pool.getItems().stream()
                .filter(item -> matchesContentTypeRule(item, template.getContentTypeRule()))
                .filter(item -> matchesDifficultyRule(item, template.getDifficultyRule(), targetDifficulty))
                .filter(item -> !coveredKnIds.containsAll(item.getKnowledgeNodeIds())
                        || template.isAllowDuplicateKnowledge()) // 优先选择新知识点
                .sorted(getComparator(template.getDifficultyRule(), targetDifficulty,
                                      coveredKnIds))
                .collect(Collectors.toList());

        // 贪心选择
        int target = template.getTargetItemCount();
        List<ContentStructure.ContentItem> selected = new ArrayList<>();
        Set<Long> sectionCoveredKn = new HashSet<>();

        for (RecallItem candidate : candidates) {
            if (selected.size() >= target) break;

            // 多样性检查：同一来源不超过60%
            long sameSourceCount = selected.stream()
                    .filter(s -> s.getSelectionReason().startsWith(candidate.getSource()))
                    .count();
            if (sameSourceCount >= target * 0.6) continue;

            // 转换为ContentItem
            ContentStructure.ContentItem item = ContentStructure.ContentItem.builder()
                    .itemId("ci_" + String.format("%03d", sequenceStart + selected.size() + 1))
                    .contentType(candidate.getContentType())
                    .contentId(candidate.getContentId())
                    .title(candidate.getTitle())
                    .knowledgeNodeIds(candidate.getKnowledgeNodeIds())
                    .estimatedMinutes(candidate.getEstimatedMinutes())
                    .difficultyLevel(candidate.getDifficultyLevel())
                    .isRequired(true)
                    .selectionReason(candidate.getSource() + "_"
                            + (candidate.getSelectionScore().compareTo(BigDecimal.valueOf(80)) >= 0
                              ? "HIGH_QUALITY" : "KG_LINKED"))
                    .selectionScore(candidate.getSelectionScore())
                    .build();

            selected.add(item);
            sectionCoveredKn.addAll(candidate.getKnowledgeNodeIds());
        }

        coveredKnIds.addAll(sectionCoveredKn);

        // 构建段落
        ContentStructure.Section section = new ContentStructure.Section();
        section.setSectionId(template.getSectionId());
        section.setSectionType(template.getSectionType());
        section.setTitle(template.getTitle());
        section.setDescription(template.getDescription());
        section.setEstimatedMinutes(selected.stream()
                .mapToInt(ContentStructure.ContentItem::getEstimatedMinutes).sum());
        section.setItems(selected);

        return section;
    }

    /**
     * 确保知识点覆盖完整
     * 对未覆盖的知识点，从池中补充内容或触发AI生成
     */
    private void ensureKnowledgeCoverage(
            ContentStructure structure,
            Set<Long> topicKnIds,
            Set<Long> coveredKnIds,
            RecallPool pool,
            int difficultyLevel) {

        Set<Long> uncovered = new HashSet<>(topicKnIds);
        uncovered.removeAll(coveredKnIds);

        if (uncovered.isEmpty()) return;

        // 从池中找补充内容
        for (Long knId : uncovered) {
            Optional<RecallItem> supplement = pool.getItems().stream()
                    .filter(item -> item.getKnowledgeNodeIds().contains(knId))
                    .filter(item -> !structureContains(structure, item.getContentId(),
                                                        item.getContentType()))
                    .max(Comparator.comparing(RecallItem::getSelectionScore));

            if (supplement.isPresent()) {
                // 插入到核心学习段落
                addToSection(structure, "sec_learn", supplement.get());
                coveredKnIds.add(knId);
            } else {
                // 触发AI内容生成
                AiGeneratedContent generated = aiContentClient.generateKnowledgeCard(
                        knId, difficultyLevel);
                RecallItem generatedItem = RecallItem.builder()
                        .contentType(ContentType.KNOWLEDGE_CARD)
                        .contentId(generated.getContentId())
                        .title(generated.getTitle())
                        .knowledgeNodeIds(Set.of(knId))
                        .estimatedMinutes(5)
                        .difficultyLevel(difficultyLevel)
                        .source("AI_GENERATED")
                        .selectionScore(BigDecimal.valueOf(70.0))
                        .build();
                addToSection(structure, "sec_learn", generatedItem);
                coveredKnIds.add(knId);
            }
        }
    }

    /**
     * 计算包质量分
     */
    private BigDecimal calculatePackageQuality(ContentStructure structure,
                                                 TopicDefinition topic,
                                                 Set<Long> coveredKnIds) {
        // 知识点覆盖率 (35%)
        double coverageRate = topic.getKnowledgeNodeIds().isEmpty() ? 1.0 :
                (double) coveredKnIds.size() / topic.getKnowledgeNodeIds().size();
        double coverageScore = coverageRate * 100 * 0.35;

        // 平均内容质量分 (25%)
        double avgItemScore = structure.getSections().stream()
                .flatMap(s -> s.getItems().stream())
                .mapToDouble(item -> item.getSelectionScore().doubleValue())
                .average()
                .orElse(0);
        double qualityPart = avgItemScore * 0.25;

        // 内容多样性 (20%) - 来源、类型分散度
        double diversityScore = calculateDiversityScore(structure) * 0.20;

        // 结构合理性 (20%) - 段落完整度、难度递进
        double structureScore = calculateStructureScore(structure, topic) * 0.20;

        return BigDecimal.valueOf(coverageScore + qualityPart + diversityScore + structureScore)
                .setScale(2, RoundingMode.HALF_UP);
    }

    private double calculateDiversityScore(ContentStructure structure) {
        List<String> sources = structure.getSections().stream()
                .flatMap(s -> s.getItems().stream())
                .map(ContentStructure.ContentItem::getSelectionReason)
                .collect(Collectors.toList());

        List<String> types = structure.getSections().stream()
                .flatMap(s -> s.getItems().stream())
                .map(item -> item.getContentType().name())
                .collect(Collectors.toList());

        // Shannon熵计算多样性
        double sourceEntropy = shannonEntropy(sources);
        double typeEntropy = shannonEntropy(types);

        return Math.min((sourceEntropy + typeEntropy) / 2.0 * 20, 100);
    }

    private double calculateStructureScore(ContentStructure structure, TopicDefinition topic) {
        double score = 0;
        // 检查必要段落是否存在
        Set<SectionType> requiredTypes = Set.of(
                SectionType.DIAGNOSTIC_TEST,
                SectionType.CORE_LEARNING,
                SectionType.TARGETED_PRACTICE
        );
        Set<SectionType> actualTypes = structure.getSections().stream()
                .map(ContentStructure.Section::getSectionType)
                .collect(Collectors.toSet());

        for (SectionType required : requiredTypes) {
            if (actualTypes.contains(required)) score += 25;
        }

        // 检查难度递进
        boolean difficultyIncreasing = checkDifficultyProgression(structure);
        if (difficultyIncreasing) score += 25;

        return Math.min(score, 100);
    }

    private boolean checkDifficultyProgression(ContentStructure structure) {
        List<Double> sectionAvgDifficulty = structure.getSections().stream()
                .map(s -> s.getItems().stream()
                        .mapToInt(ContentStructure.ContentItem::getDifficultyLevel)
                        .average()
                        .orElse(0))
                .collect(Collectors.toList());

        for (int i = 1; i < sectionAvgDifficulty.size(); i++) {
            if (sectionAvgDifficulty.get(i) < sectionAvgDifficulty.get(i - 1)) {
                return false; // 后面段落难度不应低于前面
            }
        }
        return true;
    }

    private double shannonEntropy(List<String> values) {
        if (values.isEmpty()) return 0;
        Map<String, Long> freq = values.stream()
                .collect(Collectors.groupingBy(Function.identity(), Collectors.counting()));
        double entropy = 0;
        double total = values.size();
        for (long count : freq.values()) {
            double p = count / total;
            entropy -= p * (Math.log(p) / Math.log(2));
        }
        return entropy;
    }

    private String calculateVersionHash(ContentStructure structure, int difficulty) {
        String contentSig = structure.getSections().stream()
                .flatMap(s -> s.getItems().stream())
                .map(item -> item.getContentType() + ":" + item.getContentId())
                .sorted()
                .collect(Collectors.joining(","));
        return DigestUtils.sha256Hex(contentSig + "|d=" + difficulty);
    }
```

```java
@Service

    /**
     * 基于考试频率发现主题
     * 统计近3年题库中高频出现的知识点聚类
     */
    private List<TopicCandidate> discoverByExamFrequency(DiscoveryRule rule) {
        // 1. 获取高频知识点
        List<KnowledgeFrequencyDTO> hotKnodes = questionBankClient
                .getTopFrequentKnowledgeNodes(
                        rule.getSubjectCodes(),
                        rule.getGradeRange(),
                        yearsBack(3),
                        50  // top 50
                );

        // 2. 知识图谱聚类 - 将高频知识点按图谱邻接关系聚类
        List<Set<Long>> clusters = kgClient.clusterByProximity(
                hotKnodes.stream().map(KnowledgeFrequencyDTO::getKnId).collect(Collectors.toSet()),
                rule.getParams().getClusterThreshold()  // 默认0.7
        );

        // 3. 转换为候选主题
        List<TopicCandidate> candidates = new ArrayList<>();
        for (Set<Long> cluster : clusters) {
            // 检查内容是否充足
            int availableContent = questionBankClient.countByKnowledgeNodes(cluster);
            if (availableContent < rule.getMinContentCount()) continue;

            // 生成主题信息
            String title = generateClusterTitle(cluster, rule.getSubjectCodes());
            String topicCode = generateTopicCode("EXAM_FREQ", cluster);

            candidates.add(TopicCandidate.builder()
                    .topicCode(topicCode)
                    .title(title)
                    .topicType(TopicType.EXAM_PREP)
                    .subjectCodes(rule.getSubjectCodes())
                    .gradeRange(rule.getGradeRange())
                    .knowledgeNodeIds(cluster)
                    .sourceType("AUTO_DISCOVERED")
                    .sourceRuleId(rule.getId())
                    .estimatedHours(estimateHours(cluster))
                    .contentAvailability(availableContent)
                    .build());
        }

        return candidates;
    }

    /**
     * 基于用户需求发现主题
     * 从搜索日志和AI对话中挖掘高频学习需求
     */
    private List<TopicCandidate> discoverByUserDemand(DiscoveryRule rule) {
        // 1. 提取近30天高频搜索词
        List<SearchTermStat> hotTerms = searchLogRepository.findTopSearchTerms(
                rule.getSubjectCodes(),
                rule.getGradeRange(),
                30,  // days
                100  // limit
        );

        // 2. 将搜索词映射到知识点
        Map<Long, Integer> knDemandScore = new HashMap<>();
        for (SearchTermStat term : hotTerms) {
            List<Long> knIds = kgClient.findKnowledgeNodesByKeyword(term.getTerm());
            for (Long knId : knIds) {
                knDemandScore.merge(knId, term.getCount(), Integer::sum);
            }
        }

        // 3. 按需求分聚合为主题
        List<Map.Entry<Long, Integer>> topDemand = knDemandScore.entrySet().stream()
                .sorted(Map.Entry.<Long, Integer>comparingByValue().reversed())
                .limit(30)
                .collect(Collectors.toList());

        // 4. 聚类并生成候选
        List<TopicCandidate> candidates = new ArrayList<>();
        Set<Long> topKnIds = topDemand.stream()
                .map(Map.Entry::getKey)
                .collect(Collectors.toSet());

        List<Set<Long>> clusters = kgClient.clusterByProximity(topKnIds, 0.6);

        for (Set<Long> cluster : clusters) {
            if (cluster.size() < 2) continue;

            int availableContent = questionBankClient.countByKnowledgeNodes(cluster);
            if (availableContent < rule.getMinContentCount()) continue;

            int totalDemand = cluster.stream()
                    .mapToInt(kn -> knDemandScore.getOrDefault(kn, 0))
                    .sum();

            candidates.add(TopicCandidate.builder()
                    .topicCode(generateTopicCode("USER_DEMAND", cluster))
                    .title(generateClusterTitle(cluster, rule.getSubjectCodes()))
                    .topicType(TopicType.SUBJECT_BOOST)
                    .subjectCodes(rule.getSubjectCodes())
                    .gradeRange(rule.getGradeRange())
                    .knowledgeNodeIds(cluster)
                    .sourceType("AUTO_DISCOVERED")
                    .sourceRuleId(rule.getId())
                    .demandScore(totalDemand)
                    .contentAvailability(availableContent)
                    .estimatedHours(estimateHours(cluster))
                    .build());
        }

        return candidates;

    /**
     * 基于季节性发现主题

    private List<TopicCandidate> discoverBySeasonal(DiscoveryRule rule) {
        List<TopicCandidate> candidates = new ArrayList<>();
        int month = LocalDateTime.now().getMonthValue();

        // 寒假（1-2月）：上学期内容复习 + 下学期预习
        if (month == 12 || month <= 2) {
            candidates.addAll(createSeasonalCandidates(
                    rule, "寒假", TopicType.HOLIDAY_CAMP, "WINTER"));
        }
        // 暑假（7-8月）
        if (month >= 6 || month <= 8) {
            candidates.addAll(createSeasonalCandidates(
                    rule, "暑假", TopicType.HOLIDAY_CAMP, "SUMMER"));
        }
        // 期中考试（4月、10月）
        if (month == 4 || month == 10) {
            candidates.addAll(createSeasonalCandidates(
                    rule, "期中复习", TopicType.EXAM_PREP, "MIDTERM"));
        }
        // 期末考试（6月、12月）
        if (month == 6 || month == 12) {
            candidates.addAll(createSeasonalCandidates(
                    rule, "期末冲刺", TopicType.EXAM_PREP, "FINAL"));
        }
        // 中高考冲刺（3-6月）
        if (month >= 3 && month <= 6) {
            candidates.addAll(createExamSprintCandidates(rule));
        }

        return candidates;

    private List<TopicCandidate> discoverByKnowledgeCluster(DiscoveryRule rule) {
```

```java
/**
 * 学习包异步生成任务消费者

@Component
@RequiredArgsConstructor
@Slf4j
public class PackageGenerationConsumer implements RocketMQListener<PackageGenerationMessage> {

    private final TopicDefinitionRepository topicRepository;
    private final PackageArrangementService arrangementService;
    private final LearningPackageRepository packageRepository;
    private final StructureTemplateRegistry templateRegistry;
    private final GenerationTaskTracker taskTracker;

    @Override
    public void onMessage(PackageGenerationMessage msg) {
        Long topicId = msg.getTopicId();
        taskTracker.markRunning(msg.getTaskId());

        try {
            TopicDefinition topic = topicRepository.findById(topicId)
                    .orElseThrow(() -> new EntityNotFoundException("Topic not found: " + topicId));

            StructureTemplate template = templateRegistry.getTemplate(msg.getStructureTemplateCode());
            if (template == null) {
                template = templateRegistry.getDefaultTemplate(topic.getTopicType());
            }

            List<LearningPackage> generated = new ArrayList<>();

            for (int difficulty : msg.getDifficultyLevels()) {
                log.info("Generating package for topic={}, difficulty={}", topicId, difficulty);

                LearningPackage pkg = arrangementService.arrange(
                        topic, difficulty, template, msg.getTargetUserSegment());

                // 质量分检查
                if (pkg.getQualityScore().compareTo(msg.getQualityThreshold()) >= 0
                        && msg.isAutoPublish()) {
                    pkg.setStatus(PackageStatus.AUTO_PUBLISHED.name());
                    pkg.setPublishedAt(LocalDateTime.now());
                }

                packageRepository.save(pkg);
                generated.add(pkg);

                taskTracker.updateProgress(msg.getTaskId(),
                        (generated.size() * 100 / msg.getDifficultyLevels().size()));
            }

            taskTracker.markCompleted(msg.getTaskId(), generated);

        } catch (Exception e) {
            log.error("Package generation failed for topic={}", topicId, e);
            taskTracker.markFailed(msg.getTaskId(), e.getMessage());
        }
    }
}
```

### 7.2 降级策略

```java
/**
 * 学习包生成降级策略
 */
@Component
@RequiredArgsConstructor
public class PackageGenerationFallback {

    private final RedisTemplate<String, Object> redisTemplate;
    private final LearningPackageRepository packageRepository;

    private static final String FALLBACK_CACHE_KEY = "topic:package:fallback:";

    /**
     * 召回超时降级 - 使用上次缓存的学习包
     */
    public LearningPackage fallbackRecallTimeout(Long topicId, int difficultyLevel) {
        String cacheKey = FALLBACK_CACHE_KEY + topicId + ":d" + difficultyLevel;

        LearningPackage cached = (LearningPackage) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            // 标记为缓存降级
            cached.setMetadata(Map.of("fallbackReason", "RECALL_TIMEOUT",
                                       "fallbackTimestamp", LocalDateTime.now().toString()));
            return cached;
        }

        // 缓存也没有，查数据库上次发布版本
        return packageRepository.findLatestPublished(topicId, difficultyLevel)
                .orElseThrow(() -> new BusinessException(
                        "PACKAGE_GEN_FAILED",
                        "内容召回超时且无可用缓存数据"));
    }

    /**
     * AI生成失败降级 - 使用预置模板内容
     */
    public RecallItem fallbackAiGenerationFailed(Long knId, int difficultyLevel) {
        // 返回一个标准知识点卡片占位符，标记为需人工补充
        return RecallItem.builder()
                .contentType(ContentType.KNOWLEDGE_CARD)
                .contentId(-1)  // 占位ID
                .title("知识点讲解（待补充）")
                .knowledgeNodeIds(Set.of(knId))
                .estimatedMinutes(5)
                .difficultyLevel(difficultyLevel)
                .source("FALLBACK_TEMPLATE")
                .selectionScore(BigDecimal.ZERO)
                .metadata(Map.of("needsManualReview", true))
                .build();
    }

    /**
     * 内容不足降级 - 放宽质量阈值重新召回
     */
    public RecallPool fallbackInsufficientContent(RecallPool originalPool,
                                                   BigDecimal originalThreshold) {
        BigDecimal loweredThreshold = originalThreshold
                .multiply(BigDecimal.valueOf(0.7));  // 阈值降低30%

        RecallPool relaxedPool = originalPool.filter(
                item -> item.getSelectionScore().compareTo(loweredThreshold) >= 0);

        if (relaxedPool.size() < originalPool.size()) {
            log.warn("Content insufficient, lowered threshold from {} to {}, recovered {} items",
                    originalThreshold, loweredThreshold,
                    relaxedPool.size() - originalPool.size());
        }

        return relaxedPool;
    }
}
```

```java
                        .topicId(topic.getId())

                int delayLevel = 1 + (i / batchSize) % 10;
                mqTemplate.asyncSend("PACKAGE_GENERATION", msg,
                        MessageBuilder.buildDelayLevel(delayLevel));
            }
        }
    }
```

### 9.3 并发控制

```java
/**
 * 学习包生成分布式锁
 * 防止同一主题同一难度的包被重复生成
 */
@Component
@RequiredArgsConstructor
public class PackageGenerationLock {

    private final RedisTemplate<String, String> redisTemplate;

    private static final String LOCK_PREFIX = "lock:pkg:gen:";
    private static final Duration LOCK_TTL = Duration.ofMinutes(10);

    /**
     * 尝试获取生成锁
     */
    public boolean tryLock(Long topicId, int difficultyLevel, String requestId) {
        String key = LOCK_PREFIX + topicId + ":d" + difficultyLevel;
        Boolean acquired = redisTemplate.opsForValue()
                .setIfAbsent(key, requestId, LOCK_TTL);
        return Boolean.TRUE.equals(acquired);
    }

    /**
     * 释放生成锁
     */
    public boolean unlock(Long topicId, int difficultyLevel, String requestId) {
        String key = LOCK_PREFIX + topicId + ":d" + difficultyLevel;
        String value = redisTemplate.opsForValue().get(key);
        if (requestId.equals(value)) {
            redisTemplate.delete(key);
            return true;
        }
        return false; // 锁已被其他线程持有
    }
}
```

```java
/**
 * 学习包效果指标采集器
 * 每日凌晨1点执行，聚合前一天的数据

@Service
@RequiredArgsConstructor
public class PackageMetricCollector {

    private final LearningPackageRepository packageRepository;
    private final PackageEffectMetricRepository metricRepository;
    private final LearningEventRepository eventRepository;

    @XxlJob("dailyPackageMetricCollect")
    public void collect() {
        LocalDate yesterday = LocalDate.now().minusDays(1);
        List<Long> activePackageIds = packageRepository.findActivePackageIds(yesterday);

        for (Long packageId : activePackageIds) {
            PackageEffectMetric metric = collectSingle(packageId, yesterday);
            metricRepository.upsert(metric);
        }

        // 触发低效包预警
        triggerUnderperformAlerts(yesterday);
    }

    private PackageEffectMetric collectSingle(Long packageId, LocalDate date) {
        // 从学习事件表聚合数据
        List<LearningEvent> events = eventRepository.findByPackageIdAndDate(packageId, date);

        int enrollCount = (int) events.stream()
                .filter(e -> e.getEventType() == "PACKAGE_ENROLL")
                .map(LearningEvent::getUserId)
                .distinct()
                .count();

        int activeCount = (int) events.stream()
                .filter(e -> e.getEventType() == "ITEM_PROGRESS")
                .map(LearningEvent::getUserId)
                .distinct()
                .count();

        int completeCount = (int) events.stream()
                .filter(e -> e.getEventType() == "PACKAGE_COMPLETE")
                .map(LearningEvent::getUserId)
                .distinct()
                .count();

        double avgCompletionRate = events.stream()
                .filter(e -> e.getEventType() == "PACKAGE_PROGRESS")
                .mapToDouble(LearningEvent::getCompletionRate)
                .average()
                .orElse(0);

        // ... 其他指标

        return PackageEffectMetric.builder()
                .packageId(packageId)
                .metricDate(date)
                .enrollCount(enrollCount)
                .activeCount(activeCount)
                .completeCount(completeCount)
                .avgCompletionRate(BigDecimal.valueOf(avgCompletionRate))
                .build();
    }

    /**
     * 低效包预警
     */
    private void triggerUnderperformAlerts(LocalDate date) {
        // 完成率低于30% 且 加入人数超过100 的包触发预警
        List<PackageEffectMetric> underperform = metricRepository.findUnderperforming(
                date, new BigDecimal("30.00"), 100);

        for (PackageEffectMetric metric : underperform) {
            // 发送预警事件 → 运营工作台
            eventPublisher.publish(new PackageUnderperformEvent(
                    metric.getPackageId(),
                    metric.getAvgCompletionRate(),
                    metric.getEnrollCount(),
                    "LOW_COMPLETION_RATE"
            ));
        }
    }
}
```

### 12.2 Prometheus 指标埋点

```java
@Component
@RequiredArgsConstructor
public class PackageMetrics {

    private final MeterRegistry meterRegistry;

    public void recordGeneration(Long topicId, int difficultyLevel,
                                  long durationMs, boolean success) {
        Tags tags = Tags.of(
                "topic_id", String.valueOf(topicId),
                "difficulty", String.valueOf(difficultyLevel),
                "success", String.valueOf(success)
        );
        meterRegistry.timer("topic.package.generation", tags)
                .record(Duration.ofMillis(durationMs));
    }

    public void recordRecallPool(Long topicId, int poolSize) {
        meterRegistry.gauge("topic.package.recall_pool_size",
                Tags.of("topic_id", String.valueOf(topicId)),
                poolSize);
    }

    public void recordQualityScore(Long packageId, double score) {
        meterRegistry.gauge("topic.package.quality_score",
                Tags.of("package_id", String.valueOf(packageId)),
                score);
    }

    // Counter: 学习包发布事件
    public void recordPublish(Long packageId, boolean autoPublished) {
        meterRegistry.counter("topic.package.publish",
                Tags.of("auto_published", String.valueOf(autoPublished)))
                .increment();
    }
}
```
