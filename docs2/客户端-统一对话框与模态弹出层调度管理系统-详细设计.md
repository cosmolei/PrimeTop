# 客户端-统一对话框与模态弹出层调度管理系统 - 详细设计

> **模块定位**：PrimeTop 客户端全局 UI 基础设施，为所有业务页面提供统一的弹窗、对话框、底部抽屉、Toast 通知和自定义 Overlay 的创建、调度、队列管理和冲突仲裁能力。
> **技术栈**：Flutter 3.x + Dart 3.x + Riverpod
> **优先级**：P0（MVP 阶段基础设施，影响全产品交互一致性和用户体验）

---

## 1. 概述

### 1.1 背景与问题

PrimeTop 是一个多功能教育 APP，各业务模块（AI 对话、拍照搜题、错题本、学习规划等）都需要展示弹窗、对话框、底部面板等模态 UI。如果不做统一管理，会出现以下问题：

| 问题 | 表现 | 影响 |
|------|------|------|
| 弹窗叠加 | 多个弹窗同时弹出，互相遮挡 | 用户困惑，操作困难 |
| 动画冲突 | 多个弹窗动画互相干扰 | 视觉抖动，体验差 |
| 优先级混乱 | 系统升级弹窗被业务弹窗遮挡 | 关键信息无法触达 |
| 频率失控 | 短时间内连续弹出多个弹窗 | 弹窗疲劳，用户反感 |
| 返回键失效 | 弹窗未正确处理返回键 | APP 退出而非关闭弹窗 |
| 测试困难 | 弹窗状态难以 Mock | UI 测试不稳定 |

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 统一入口 | 所有弹窗通过统一 Manager 创建和调度 |
| 队列管理 | 同时只能展示一个弹窗（可配置为允许叠加） |
| 优先级仲裁 | 高优先级弹窗可打断低优先级弹窗 |
| 频率控制 | 内置防抖和冷却时间，防止弹窗轰炸 |
| 动画一致 | 统一进出场动画，可按类型自定义 |
| 可测试性 | 提供完整的 Mock 和测试工具 |
| 无障碍 | 正确的语义标签、焦点管理和屏幕阅读器支持 |

### 1.3 与其他模块的关系

| 模块 | 关系 |
|------|------|
| 客户端组件库与设计系统 | 提供基础视觉组件（Button、Input 等），本系统负责弹窗的调度管理 |
| 全局运营弹窗与消息浮窗调度系统 | 运营弹窗是本系统的一个**特殊调用方**，通过本系统展示 |
| 客户端状态管理架构 | 使用 Riverpod 管理弹窗全局状态 |
| 客户端路由与深链接系统 | 弹窗需与路由生命周期绑定 |
| 客户端无障碍访问 | 弹窗需满足无障碍标准 |
| 客户端埋点事件体系 | 弹窗展示/点击/关闭需埋点 |

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| Overlay | 所有覆盖在当前页面之上的 UI 层统称 |
| Dialog | 居中显示的模态对话框 |
| BottomSheet | 从底部滑出的面板 |
| Toast | 短暂出现的自动消失提示 |
| SnackBar | 底部持久化消息条（可带操作按钮） |
| Modal | 模态层，阻挡后方交互 |
| Barrier | 弹窗背景遮罩层 |
| Queue | 等待展示的弹窗队列 |
| Slot | 弹窗触发时机（如 APP 启动、页面进入、操作完成） |

### 2.2 按优先级分类

| 优先级 | 枚举值 | 说明 | 示例 |
|--------|--------|------|------|
| Critical | 100 | 必须立即展示，打断一切 | 强制升级、账号被封禁 |
| High | 80 | 高优先级，打断普通弹窗 | 系统权限请求、网络断开 |
| Normal | 50 | 默认优先级 | 确认删除、操作成功 |
| Low | 20 | 低优先级，可被任意打断 | 评分邀请、功能介绍 |
| Background | 10 | 仅在无其他弹窗时展示 | 运营活动推荐 |

### 2.3 按模态性分类

| 类型 | 是否阻挡后方交互 | 是否可点击外部关闭 | 典型场景 |
|------|------------------|---------------------|----------|
| Strong Modal | ✅ 是 | ❌ 否 | 加载中、强制升级、关键确认 |
| Modal | ✅ 是 | ✅ 是 | 删除确认、表单填写 |
| Non-Modal | ❌ 否 | — | Toast、SnackBar、Tooltip |

```dart
/// 弹窗类型
enum OverlayType {
  dialog,
  bottomSheet,
  toast,
  snackBar,
  customOverlay,
}

/// 弹窗优先级
enum OverlayPriority {
  background(10),
  low(20),
  normal(50),
  high(80),
  critical(100);

  final int value;
  const OverlayPriority(this.value);
}

/// 动画类型
enum AnimationType {
  /// 居中缩放淡入（标准 Dialog）
  scaleFade,
  /// 从底部滑入（BottomSheet）
  slideUp,
  /// 从顶部滑入
  slideDown,
  /// 从左侧滑入
  slideLeft,
  /// 从右侧滑入
  slideRight,
  /// 纯淡入淡出
  fade,
  /// 无动画
  none,
  /// 弹簧效果
  spring,
}

/// 关闭策略
enum DismissPolicy {
  /// 永不自动关闭
  manual,
  /// 点击 barrier 关闭
  tapBarrier,
  /// 点击 barrier 或按返回键关闭
  anyGesture,
  /// 定时自动关闭（Toast/SnackBar）
  timed,
}

/// 弹窗触发时机
enum DisplaySlot {
  appStartup,
  pageEnter,
  userAction,
  backgroundEvent,
  pushNotification,
}

/// 弹窗展示结果
enum OverlayResult {
  confirmed,    // 用户确认
  cancelled,    // 用户取消
  dismissed,    // 外部关闭（barrier/返回键）
  replaced,     // 被更高优先级替换
  skipped,      // 被策略拦截（频率/冷却）
  error,        // 异常关闭
}
```

```dart
/// lib/overlay/overlay_request.dart

class OverlayRequest {
  final String id;
  final OverlayType type;
  final OverlayPriority priority;
  final WidgetBuilder content;
  final bool barrierDismissible;
  final Color? barrierColor;
  final AnimationType animationType;
  final Duration? duration; // Toast/SnackBar 自动关闭时间
  final String? tag; // 埋点标识 & 频率控制 key
  final DismissPolicy dismissPolicy;
  final VoidCallback? onDismissed;
  final DateTime createdAt;
  final String? source; // 来源页面/模块
  final Map<String, dynamic>? metadata; // 扩展数据

  /// 完成器 — show() 返回的 Future 通过此 Completer 获取结果
  final Completer<OverlayResult> _completer = Completer();

  OverlayRequest._({
    required this.id,
    required this.type,
    required this.priority,
    required this.content,
    this.barrierDismissible = true,
    this.barrierColor,
    this.animationType = AnimationType.scaleFade,
    this.duration,
    this.tag,
    this.dismissPolicy = DismissPolicy.anyGesture,
    this.onDismissed,
    this.source,
    this.metadata,
  }) : createdAt = DateTime.now();

  /// 创建标准 Dialog
  factory OverlayRequest.dialog({
    required WidgetBuilder content,
    OverlayPriority priority = OverlayPriority.normal,
    bool barrierDismissible = true,
    AnimationType animationType = AnimationType.scaleFade,
    String? tag,
    String? source,
    VoidCallback? onDismissed,
  }) {
    return OverlayRequest._(
      id: _generateId(),
      type: OverlayType.dialog,
      priority: priority,
      content: content,
      barrierDismissible: barrierDismissible,
      animationType: animationType,
      tag: tag,
      source: source,
      onDismissed: onDismissed,
    );
  }

  /// 创建确认对话框
  factory OverlayRequest.confirm({
    required String title,
    required String message,
    String confirmText = '确认',
    String cancelText = '取消',
    OverlayPriority priority = OverlayPriority.normal,
    String? tag,
    String? source,
  }) {
    return OverlayRequest._(
      id: _generateId(),
      type: OverlayType.dialog,
      priority: priority,
      content: (context) => _ConfirmDialogView(
        title: title,
        message: message,
        confirmText: confirmText,
        cancelText: cancelText,
      ),
      barrierDismissible: true,
      tag: tag,
      source: source,
    );
  }

  /// 创建 BottomSheet
  factory OverlayRequest.bottomSheet({
    required WidgetBuilder content,
    OverlayPriority priority = OverlayPriority.normal,
    bool barrierDismissible = true,
    AnimationType animationType = AnimationType.slideUp,
    String? tag,
    String? source,
    VoidCallback? onDismissed,
  }) {
    return OverlayRequest._(
      id: _generateId(),
      type: OverlayType.bottomSheet,
      priority: priority,
      content: content,
      barrierDismissible: barrierDismissible,
      animationType: animationType,
      tag: tag,
      source: source,
      onDismissed: onDismissed,
    );
  }

  /// 创建 ActionSheet（操作菜单）
  factory OverlayRequest.actionSheet({
    required List<OverlayAction> actions,
    String? title,
    String? cancelText = '取消',
    OverlayPriority priority = OverlayPriority.normal,
    String? source,
  }) {
    return OverlayRequest._(
      id: _generateId(),
      type: OverlayType.bottomSheet,
      priority: priority,
      content: (context) => _ActionSheetView(
        actions: actions,
        title: title,
        cancelText: cancelText,
      ),
      barrierDismissible: true,
      animationType: AnimationType.slideUp,
      source: source,
    );
  }

  /// 创建 Toast
  factory OverlayRequest.toast({
    required String message,
    ToastLevel level = ToastLevel.info,
    Duration duration = const Duration(seconds: 2),
    OverlayPriority priority = OverlayPriority.normal,
    String? tag,
    String? source,
  }) {
    return OverlayRequest._(
      id: _generateId(),
      type: OverlayType.toast,
      priority: priority,
      content: (context) => _ToastView(
        message: message,
        level: level,
      ),
      duration: duration,
      dismissPolicy: DismissPolicy.timed,
      barrierDismissible: false,
      barrierColor: const Color(0x00000000),
      animationType: AnimationType.fade,
      tag: tag,
      source: source,
    );
  }

  /// 创建 SnackBar
  factory OverlayRequest.snackBar({
    required String message,
    String? actionLabel,
    VoidCallback? onAction,
    Duration duration = const Duration(seconds: 4),
    OverlayPriority priority = OverlayPriority.normal,
    String? tag,
    String? source,
  }) {
    return OverlayRequest._(
      id: _generateId(),
      type: OverlayType.snackBar,
      priority: priority,
      content: (context) => _SnackBarView(
        message: message,
        actionLabel: actionLabel,
        onAction: onAction,
      ),
      duration: duration,
      dismissPolicy: DismissPolicy.timed,
      barrierDismissible: false,
      barrierColor: const Color(0x00000000),
      animationType: AnimationType.slideUp,
      tag: tag,
      source: source,
    );
  }

  /// 创建加载中对话框
  factory OverlayRequest.loading({
    String? message,
    bool barrierDismissible = false,
    String? tag,
    String? source,
  }) {
    return OverlayRequest._(
      id: _generateId(),
      type: OverlayType.dialog,
      priority: OverlayPriority.high,
      content: (context) => _LoadingDialogView(message: message),
      barrierDismissible: barrierDismissible,
      dismissPolicy: DismissPolicy.manual,
      animationType: AnimationType.fade,
      tag: tag ?? 'loading',
      source: source,
    );
  }

  Future<OverlayResult> get result => _completer.future;
  void complete(OverlayResult result) {
    if (!_completer.isCompleted) {
      _completer.complete(result);
    }
  }

  static String _generateId() {
    return 'overlay_${DateTime.now().microsecondsSinceEpoch}_${_counter++}';
  }

  static int _counter = 0;
}
```

## 5. 核心实现

### 5.1 OverlayManager 完整实现

```dart
/// lib/overlay/overlay_manager.dart

class OverlayManager {
  final OverlayState _overlayState;
  final FrequencyLimiter _frequencyLimiter;
  final DisplayPolicy _displayPolicy;
  final OverlayAnalyticsReporter _analyticsReporter;

  /// 等待队列（按优先级排序）
  final PriorityQueue<OverlayRequest> _queue = PriorityQueue<OverlayRequest>(
    (a, b) => b.priority.value.compareTo(a.priority.value),
  );

  /// 当前活跃的 Dialog/BottomSheet（非 Toast）
  OverlayEntry? _activeModalEntry;
  OverlayRequest? _activeModalRequest;

  /// Toast 活跃队列（Toast 允许多个叠加，但限制数量）
  final List<_ActiveToast> _activeToasts = [];

  /// SnackBar 当前实例
  OverlayEntry? _activeSnackBarEntry;

  /// 是否已 disposed
  bool _disposed = false;

  OverlayManager({
    required OverlayState overlayState,
    FrequencyConfig? frequencyConfig,
    DisplayPolicy? displayPolicy,
    OverlayAnalyticsReporter? analyticsReporter,
  })  : _overlayState = overlayState,
        _frequencyLimiter = FrequencyLimiter(frequencyConfig ?? FrequencyConfig.defaultConfig),
        _displayPolicy = displayPolicy ?? DisplayPolicy.default,
        _analyticsReporter = analyticsReporter ?? OverlayAnalyticsReporter();

  // ==================== Public API ====================

  /// 展示弹窗 — 异步返回结果
  Future<OverlayResult> show(OverlayRequest request) async {
    if (_disposed) {
      return OverlayResult.error;
    }

    // 1. 频率控制检查
    if (request.tag != null && !_frequencyLimiter.canShow(request.tag!)) {
      _analyticsReporter.onSkipped(request, reason: 'frequency_limit');
      return OverlayResult.skipped;
    }

    // 2. 展示策略检查
    final policyDecision = _displayPolicy.shouldShow(request);
    if (!policyDecision.allowed) {
      _analyticsReporter.onSkipped(request, reason: policyDecision.reason);
      return OverlayResult.skipped;
    }

    // 3. 记录频率
    if (request.tag != null) {
      _frequencyLimiter.recordShow(request.tag!);
    }

    // 4. 根据类型分发
    switch (request.type) {
      case OverlayType.toast:
        return _showToast(request);
      case OverlayType.snackBar:
        return _showSnackBar(request);
      default:
        return _showModal(request);
    }
  }

  /// 展示确认对话框 — 便捷方法
  Future<bool> confirm({
    required String title,
    required String message,
    String confirmText = '确认',
    String cancelText = '取消',
    OverlayPriority priority = OverlayPriority.normal,
    String? source,
  }) async {
    final request = OverlayRequest.confirm(
      title: title,
      message: message,
      confirmText: confirmText,
      cancelText: cancelText,
      priority: priority,
      source: source,
    );
    final result = await show(request);
    return result == OverlayResult.confirmed;
  }

  /// 展示 Toast — 便捷方法
  Future<void> toast(
    String message, {
    ToastLevel level = ToastLevel.info,
    Duration duration = const Duration(seconds: 2),
    String? source,
  }) async {
    await show(OverlayRequest.toast(
      message: message,
      level: level,
      duration: duration,
      source: source,
    ));
  }

  /// 展示成功 Toast
  Future<void> toastSuccess(String message, {String? source}) {
    return toast(message, level: ToastLevel.success, source: source);
  }

  /// 展示错误 Toast
  Future<void> toastError(String message, {String? source}) {
    return toast(message, level: ToastLevel.error, source: source);
  }

  /// 展示加载中对话框
  Future<LoadingDialogHandle> showLoading({
    String? message,
    bool barrierDismissible = false,
    String? source,
  }) {
    final request = OverlayRequest.loading(
      message: message,
      barrierDismissible: barrierDismissible,
      source: source,
    );
    // 加载对话框需要返回 handle 用于手动关闭
    return _showLoadingDialog(request);
  }

  /// 关闭当前弹窗
  void dismiss([String? id]) {
    if (id == null) {
      // 关闭当前活跃的模态弹窗
      _dismissActiveModal(OverlayResult.dismissed);
    } else {
      // 按 ID 关闭（如果当前弹窗匹配）
      if (_activeModalRequest?.id == id) {
        _dismissActiveModal(OverlayResult.dismissed);
      }
      // 从队列中移除
      _queue.removeWhere((r) => r.id == id);
    }
  }

  /// 关闭所有弹窗（含队列）
  void dismissAll() {
    // 清空队列
    _queue.clear();
    // 关闭活跃弹窗
    _dismissActiveModal(OverlayResult.dismissed);
    // 关闭所有 Toast
    for (final toast in _activeToasts) {
      toast.entry.remove();
    }
    _activeToasts.clear();
    // 关闭 SnackBar
    _activeSnackBarEntry?.remove();
    _activeSnackBarEntry = null;
  }

  /// 获取当前活跃弹窗
  OverlayRequest? get activeOverlay => _activeModalRequest;

  /// 队列中等待的弹窗数量
  int get pendingCount => _queue.length;

  // ==================== Internal: Modal ====================

  Future<OverlayResult> _showModal(OverlayRequest request) async {
    // 如果当前有活跃弹窗，判断是否需要打断
    if (_activeModalRequest != null) {
      final shouldInterrupt = request.priority.value > _activeModalRequest!.priority.value;

      if (shouldInterrupt) {
        // 打断当前弹窗
        _dismissActiveModal(OverlayResult.replaced);
      } else {
        // 加入队列等待
        _queue.add(request);
        _analyticsReporter.onQueued(request, queuePosition: _queue.length);
        return request.result;
      }
    }

    _renderModal(request);
    return request.result;
  }

  void _renderModal(OverlayRequest request) {
    _activeModalRequest = request;
    _analyticsReporter.onShow(request);

    late OverlayEntry entry;

    entry = OverlayEntry(
      builder: (context) => _OverlayWidget(
        request: request,
        onDismiss: (result) {
          entry.remove();
          _onModalDismissed(request, result);
        },
      ),
    );

    _activeModalEntry = entry;
    _overlayState.insert(entry);
  }

  void _onModalDismissed(OverlayRequest request, OverlayResult result) {
    _analyticsReporter.onDismiss(request, result);
    request.complete(result);
    request.onDismissed?.call();

    if (_activeModalRequest?.id == request.id) {
      _activeModalRequest = null;
      _activeModalEntry = null;
    }

    // 处理队列中的下一个
    _processQueue();
  }

  void _dismissActiveModal(OverlayResult result) {
    if (_activeModalEntry != null) {
      final request = _activeModalRequest;
      _activeModalEntry!.remove();
      _activeModalEntry = null;
      if (request != null) {
        _onModalDismissed(request, result);
      }
    }
  }

  void _processQueue() {
    if (_disposed) return;
    if (_activeModalRequest != null) return; // 仍有活跃弹窗
    if (_queue.isEmpty) return;

    final next = _queue.removeFirst();
    _renderModal(next);
  }

  // ==================== Internal: Toast ====================

  Future<OverlayResult> _showToast(OverlayRequest request) async {
    // 检查 Toast 并发限制
    while (_activeToasts.length >= _frequencyLimiter.config.maxToastConcurrent) {
      final oldest = _activeToasts.first;
      oldest.entry.remove();
      _activeToasts.removeAt(0);
      oldest.request.complete(OverlayResult.dismissed);
    }

    _analyticsReporter.onShow(request);

    late OverlayEntry entry;
    late _ActiveToast activeToast;

    entry = OverlayEntry(
      builder: (context) => _ToastOverlayWidget(
        request: request,
        animationType: request.animationType,
      ),
    );

    activeToast = _ActiveToast(
      request: request,
      entry: entry,
    );

    _activeToasts.add(activeToast);
    _overlayState.insert(entry);

    // 定时自动关闭
    final duration = request.duration ?? const Duration(seconds: 2);
    Future.delayed(duration, () {
      if (_activeToasts.contains(activeToast)) {
        entry.remove();
        _activeToasts.remove(activeToast);
        _analyticsReporter.onDismiss(request, OverlayResult.dismissed);
        request.complete(OverlayResult.dismissed);
      }
    });

    return request.result;
  }

  // ==================== Internal: SnackBar ====================

  Future<OverlayResult> _showSnackBar(OverlayRequest request) async {
    // SnackBar 同一时间只展示一个
    if (_activeSnackBarEntry != null) {
      _activeSnackBarEntry!.remove();
      _activeSnackBarEntry = null;
    }

    _analyticsReporter.onShow(request);

    late OverlayEntry entry;
    entry = OverlayEntry(
      builder: (context) => _SnackBarOverlayWidget(request: request),
    );

    _activeSnackBarEntry = entry;
    _overlayState.insert(entry);

    final duration = request.duration ?? const Duration(seconds: 4);
    Future.delayed(duration, () {
      if (_activeSnackBarEntry == entry) {
        entry.remove();
        _activeSnackBarEntry = null;
        _analyticsReporter.onDismiss(request, OverlayResult.dismissed);
        request.complete(OverlayResult.dismissed);
      }
    });

    return request.result;
  }

  // ==================== Internal: Loading ====================

  Future<LoadingDialogHandle> _showLoadingDialog(OverlayRequest request) async {
    // Loading 对话框使用独立管理，不走队列
    _analyticsReporter.onShow(request);

    late OverlayEntry entry;
    entry = OverlayEntry(
      builder: (context) => _OverlayWidget(
        request: request,
        onDismiss: (result) {
          entry.remove();
          request.complete(result);
          _analyticsReporter.onDismiss(request, result);
        },
      ),
    );

    _overlayState.insert(entry);

    return LoadingDialogHandle._(
      close: ({OverlayResult result = OverlayResult.dismissed}) {
        entry.remove();
        request.complete(result);
        _analyticsReporter.onDismiss(request, result);
      },
    );
  }

  // ==================== Lifecycle ====================

  void dispose() {
    _disposed = true;
    _queue.clear();
    _activeModalEntry?.remove();
    for (final toast in _activeToasts) {
      toast.entry.remove();
    }
    _activeToasts.clear();
    _activeSnackBarEntry?.remove();
  }
}

/// 加载对话框句柄 — 用于手动关闭 Loading
class LoadingDialogHandle {
  final void Function({OverlayResult result}) close;

  LoadingDialogHandle._({required this.close});
}

/// 活跃 Toast 内部结构
class _ActiveToast {
  final OverlayRequest request;
  final OverlayEntry entry;

  _ActiveToast({required this.request, required this.entry});
}
```

```dart
class _OverlayWidget extends StatefulWidget {
  final OverlayRequest request;
  final void Function(OverlayResult) onDismiss;

  const _OverlayWidget({
    required this.request,
    required this.onDismiss,
  });

  @override
  State<_OverlayWidget> createState() => _OverlayWidgetState();
}

class _OverlayWidgetState extends State<_OverlayWidget>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _animation;

  @override
  void initState() {
    super.initState();
    _setupAnimation();
    _controller.forward();
  }

  void _setupAnimation() {
    final duration = _getAnimationDuration(widget.request.animationType);
    _controller = AnimationController(
      duration: duration,
      vsync: this,
    );

    _animation = switch (widget.request.animationType) {
      AnimationType.scaleFade => CurvedAnimation(
          parent: _controller,
          curve: Curves.easeOutBack,
        ),
      AnimationType.slideUp => CurvedAnimation(
          parent: _controller,
          curve: Curves.easeOutCubic,
        ),
      AnimationType.fade => CurvedAnimation(
          parent: _controller,
          curve: Curves.easeInOut,
        ),
      AnimationType.spring => CurvedAnimation(
          parent: _controller,
          curve: Curves.elasticOut,
        ),
      _ => CurvedAnimation(
          parent: _controller,
          curve: Curves.easeOut,
        ),
    };
  }

  Duration _getAnimationDuration(AnimationType type) {
    return switch (type) {
      AnimationType.scaleFade => const Duration(milliseconds: 250),
      AnimationType.slideUp => const Duration(milliseconds: 300),
      AnimationType.fade => const Duration(milliseconds: 200),
      AnimationType.spring => const Duration(milliseconds: 400),
      AnimationType.none => Duration.zero,
      _ => const Duration(milliseconds: 250),
    };
  }

  void _dismiss(OverlayResult result) async {
    await _controller.reverse();
    widget.onDismiss(result);
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _animation,
      builder: (context, child) {
        return _buildAnimatedOverlay();
      },
    );
  }

  Widget _buildAnimatedOverlay() {
    final isModal = widget.request.type == OverlayType.dialog ||
        widget.request.type == OverlayType.bottomSheet;

    // Barrier 层
    final barrier = widget.request.barrierColor ??
        (isModal ? Colors.black54 : Colors.transparent);

    final barrierWidget = GestureDetector(
      onTap: widget.request.dismissPolicy == DismissPolicy.tapBarrier ||
              widget.request.dismissPolicy == DismissPolicy.anyGesture
          ? () => _dismiss(OverlayResult.dismissed)
          : null,
      child: Container(
        color: barrier.withValues(alpha: barrier.a * _animation.value),
        constraints: BoxConstraints.expand(),
      ),
    );

    // 内容层
    final contentWidget = _buildAnimatedContent();

    return Stack(
      children: [
        // Barrier
        Positioned.fill(child: barrierWidget),
        // Content
        contentWidget,
      ],
    );
  }

  Widget _buildAnimatedContent() {
    final content = widget.request.content(context);

    return switch (widget.request.animationType) {
      AnimationType.scaleFade => Positioned(
          top: 0,
          bottom: 0,
          left: 0,
          right: 0,
          child: Center(
            child: Transform.scale(
              scale: 0.9 + 0.1 * _animation.value,
              child: Opacity(
                opacity: _animation.value,
                child: content,
              ),
            ),
          ),
        ),
      AnimationType.slideUp => Positioned(
          left: 0,
          right: 0,
          bottom: 0,
          child: FractionalTranslation(
            translation: Offset(0, 1 - _animation.value),
            child: content,
          ),
        ),
      AnimationType.fade => Positioned.fill(
          child: Center(
            child: Opacity(
              opacity: _animation.value,
              child: content,
            ),
          ),
        ),
      _ => Positioned.fill(child: Center(child: content)),
    };
  }
}
```

### 5.3 FrequencyLimiter 实现

```dart
/// lib/overlay/frequency_limiter.dart

class FrequencyLimiter {
  final FrequencyConfig config;

  /// tag -> 上次展示时间
  final Map<String, DateTime> _lastShowTime = {};

  /// tag -> 本会话展示次数
  final Map<String, int> _sessionCount = {};

  /// 上次任意弹窗展示时间（全局间隔控制）
  DateTime? _lastGlobalShow;

  /// 防抖记录：tag -> 待执行的请求
  final Map<String, Timer> _debounceTimers = {};

  FrequencyLimiter(this.config);

  /// 检查是否可以展示
  bool canShow(String tag) {
    final now = DateTime.now();

    // 1. 检查 tag 冷却时间
    final cooldown = config.tagCooldowns[tag];
    if (cooldown != null && _lastShowTime.containsKey(tag)) {
      final elapsed = now.difference(_lastShowTime[tag]!);
      if (elapsed < cooldown) {
        return false;
      }
    }

    // 2. 检查会话次数限制
    final maxSession = config.maxPerSession[tag];
    if (maxSession != null) {
      final count = _sessionCount[tag] ?? 0;
      if (count >= maxSession) {
        return false;
      }
    }

    // 3. 检查全局最小间隔
    if (_lastGlobalShow != null) {
      final elapsed = now.difference(_lastGlobalShow!);
      if (elapsed < config.globalMinInterval) {
        return false;
      }
    }

    return true;
  }

  /// 记录展示
  void recordShow(String tag) {
    final now = DateTime.now();
    _lastShowTime[tag] = now;
    _lastGlobalShow = now;
    _sessionCount[tag] = (_sessionCount[tag] ?? 0) + 1;
  }

  /// 重置某个 tag 的频率限制
  void resetTag(String tag) {
    _lastShowTime.remove(tag);
    _sessionCount.remove(tag);
  }

  /// 重置所有限制
  void resetAll() {
    _lastShowTime.clear();
    _sessionCount.clear();
    _lastGlobalShow = null;
  }
}
```

```dart
class DisplayPolicy {
  /// 最大同时活跃弹窗数（含当前展示的）
  final int maxConcurrent;

  /// 全局最小间隔
  final Duration minInterval;

  /// 被屏蔽的触发时机
  final Set<DisplaySlot> blockedSlots;

  /// 被屏蔽的来源页面
  final Set<String> blockedSources;

  const DisplayPolicy({
    this.maxConcurrent = 1,
    this.minInterval = const Duration(milliseconds: 200),
    this.blockedSlots = const {},
    this.blockedSources = const {},
  });

  static const DisplayPolicy default = DisplayPolicy();

  /// 检查是否应该展示
  PolicyDecision shouldShow(OverlayRequest request) {
    // 检查来源页面屏蔽
    if (request.source != null && blockedSources.contains(request.source)) {
      return PolicyDecision(
        allowed: false,
        reason: 'source_blocked: ${request.source}',
      );
    }

    // 其他策略检查可以在这里扩展
    // 例如：根据用户会员状态、学段、时间等决定是否展示

    return const PolicyDecision(allowed: true);
  }
}
```
