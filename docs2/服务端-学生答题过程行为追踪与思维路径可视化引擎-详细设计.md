# 服务端 - 学生答题过程行为追踪与思维路径可视化引擎

> **版本**: v1.0
> **创建日期**: 2026-06-23
> **关联模块**: 学情分析、练习测评、教师端、家长中心
> **优先级**: P2（V1.5 阶段）

---

## 1. 概述

### 1.1 功能目标

对学生在答题过程中的**细粒度行为信号**进行采集、存储、分析，并重建学生的**思维路径**，以可视化方式呈现给教师和家长，帮助他们理解学生"怎么想的"而不仅仅是"答对了没有"。

与已有系统的关系：

| 已有系统 | 定位 | 本文区别 |
| --- | --- | --- |
| 练习答题行为数据采集引擎 | 采集答题宏观事件（提交、耗时、正误） | 本文聚焦**微粒度**行为（按键节奏、犹豫、擦除、工具切换） |
| 学生解题过程分步评分服务 | 对最终解答步骤进行评分 | 本文关注**过程行为本身**，而非结果评判 |
| 学习行为事件流引擎 | 跨模块行为事件路由 | 本文是**答题场景内**的深度行为分析 |
| 学习状态实时感知引擎 | 整体学习状态评估 | 本文提供**具体题目级别**的行为洞察 |

### 1.2 核心价值

- **教师**：看到班级学生在一道题上的"典型路径"和"偏差路径"，精准定位教学盲区。
- **家长**：看到孩子解题时的思维过程，理解"卡在哪一步"而非"做对了没有"。
- **学生**：回顾自己的解题习惯，发现低效模式（如频繁擦除、长时间犹豫）。
- **系统**：为自适应推荐、认知诊断提供更丰富的行为特征输入。

### 1.3 设计原则

1. **隐私优先**：不采集具体按键内容（不构成"监控"），仅采集行为特征信号。
2. **端轻云重**：客户端负责轻量信号打包上报，服务端负责存储、分析、可视化。
3. **抽样可控**：支持按比例采样，避免全量采集带来的存储和带宽压力。
4. **渐进实现**：MVP 先做基础信号采集+时间轴展示，后续迭代认知分析能力。

### 2.2 服务定位

本引擎作为**学情分析服务域**下的子服务运行，不独立部署，与以下服务存在依赖关系：

| 依赖方向 | 服务 | 交互方式 |
| --- | --- | --- |
| 消费 ← | 练习测评会话服务 | 获取答题会话上下文（题目元数据、会话ID） |
| 消费 ← | 题目知识点标注引擎 | 获取题目关联的知识点，用于知识点级别的行为聚合 |
| 生产 → | 学情分析服务 | 输出行为洞察指标（犹豫指数、专注度等） |
| 生产 → | 自适应推荐引擎 | 输出学习行为特征向量 |
| 生产 → | 通知服务 | 卡点预警触发家长/教师通知 |

## 3. 数据结构定义

### 3.1 行为信号类型枚举

```java
public enum BehaviorSignalType {
    // ---- 输入类信号 ----
    INPUT_START,          // 开始输入（焦点进入答题区域）
    INPUT_PAUSE,          // 输入暂停（超过阈值无操作）
    INPUT_RESUME,         // 输入恢复
    INPUT_DELETE,         // 删除操作（退格/清空）
    INPUT_PASTE,          // 粘贴操作

    // ---- 浏览类信号 ----
    QUESTION_VIEW,        // 查看题目
    QUESTION_REREAD,      // 重复阅读题目（滚动回顶部/重新聚焦题目区）
    HINT_REQUEST,         // 请求提示
    FORMULA_REF,          // 查阅公式/参考资料
    KNOWLEDGE_LINK,       // 点击知识点链接

    // ---- 工具类信号 ----
    TOOL_SWITCH,          // 切换工具（如从画笔切换到文本输入）
    CALCULATOR_USE,       // 使用计算器
    SCRATCH_OPEN,         // 打开草稿纸
    SCRATCH_CLOSE,        // 关闭草稿纸

    // ---- 提交类信号 ----
    ANSWER_SUBMIT,        // 提交答案
    ANSWER_RETRACT,       // 撤回答案（提交后撤回重新作答）
    ANSWER_MODIFY,        // 修改已提交答案（如果允许）

    // ---- 环境类信号 ----
    APP_BACKGROUND,       // APP 切到后台
    APP_FOREGROUND,       // APP 切回前台
    TAB_SWITCH,           // 切换到其他页面
}
```

### 3.2 行为信号事件结构

客户端采集并上报的原始行为信号单元：

```java
public class BehaviorSignal {
    /** 信号唯一ID */
    private String signalId;

    /** 答题会话ID（关联 practice_session 表） */
    private String sessionId;

    /** 题目作答ID（关联 practice_answer 表） */
    private String answerId;

    /** 学生用户ID */
    private Long userId;

    /** 信号类型 */
    private BehaviorSignalType type;

    /** 信号发生时间戳（客户端时间，毫秒） */
    private Long clientTimestamp;

    /** 服务端接收时间戳（毫秒） */
    private Long serverTimestamp;

    /** 题目在会话中的序号（从1开始） */
    private Integer questionIndex;

    /** 信号附加数据（JSON，按信号类型不同） */
    private Map<String, Object> payload;

    /** 客户端设备ID */
    private String deviceId;
}
```

**payload 字段按信号类型的定义规范**：

| 信号类型 | payload 字段 | 说明 |
| --- | --- | --- |
| INPUT_PAUSE | `durationMs`: Long | 暂停持续毫秒数 |
| INPUT_DELETE | `deleteCount`: Integer, `inputLength`: Integer | 删除字符数 / 当前输入总长度 |
| QUESTION_REREAD | `readCount`: Integer | 第几次重读 |
| HINT_REQUEST | `hintLevel`: Integer, `hintType`: String | 提示层级 / 提示类型 |
| TOOL_SWITCH | `fromTool`: String, `toTool`: String | 源工具 / 目标工具 |
| CALCULATOR_USE | `expression`: String(脱敏), `result`: String | 计算表达式（仅保留运算符结构） |
| SCRATCH_OPEN/CLOSE | `scratchDurationMs`: Long | 草稿纸打开时长 |
| ANSWER_SUBMIT | `timeOnQuestionMs`: Long, `editCount`: Integer | 本题总用时 / 编辑次数 |
| APP_BACKGROUND | `bgDurationMs`: Long | 后台持续毫秒数 |

### 3.3 答题轨迹会话结构

一次答题会话的完整轨迹元数据：

```sql
CREATE TABLE behavior_trace_session (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    session_id      VARCHAR(64) NOT NULL UNIQUE COMMENT '答题会话ID（关联 practice_session）',
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    subject         VARCHAR(20) NOT NULL COMMENT '学科',
    grade_level     VARCHAR(20) NOT NULL COMMENT '年级',
    question_count  INT NOT NULL COMMENT '题目总数',
    total_duration_ms BIGINT NOT NULL COMMENT '会话总时长（毫秒）',
    signal_count    INT NOT NULL DEFAULT 0 COMMENT '信号总数',
    sample_rate     DECIMAL(4,3) NOT NULL DEFAULT 1.000 COMMENT '采样率',
    status          VARCHAR(20) NOT NULL DEFAULT 'ACTIVE' COMMENT 'ACTIVE/COMPLETED/ARCHIVED',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    completed_at    DATETIME,
    INDEX idx_user_time (user_id, created_at),
```

### 3.6 路径模式枚举

```java
public enum ThinkingPathPattern {
    FLUENT,         // 流畅型：快速直接作答，极少犹豫和修改
    STEADY,         // 稳健型：节奏均匀，有少量修改但不犹豫
    DELIBERATE,     // 深思型：思考时间长但操作果断（高分学生常见）
    HESITANT,       // 犹豫型：频繁暂停和删除，信心不足
    TRIAL_ERROR,    // 试错型：多次修改、频繁提交又撤回
    RUSHED,         // 急躁型：极短时间完成，几乎无停顿
    DISTRACTED,     // 分心型：频繁切后台、工具切换多
    STRUGGLING,     // 挣扎型：长暂停+多次提示请求+高删除率
}
```

## 5. 核心算法设计

### 5.1 犹豫指数计算

```java
/**
 * 犹豫指数计算器
 * 
 * 综合考虑：暂停次数、暂停时长占比、删除操作占比、答案修改次数
 * 输出范围 [0, 1]，值越高表示越犹豫不决
 */
public class HesitationIndexCalculator {

    // 权重配置（可通过配置中心动态调整）
    private static final double W_PAUSE_FREQ = 0.30;    // 暂停频率
    private static final double W_PAUSE_RATIO = 0.25;   // 暂停时长占比
    private static final double W_DELETE_RATIO = 0.20;  // 删除操作占比
    private static final double W_RETRACT = 0.15;       // 答案撤回次数
    private static final double W_REREAD = 0.10;        // 重读次数

    private static final long PAUSE_THRESHOLD_MS = 5000; // 5秒以上算作"暂停"

    public double calculate(ThinkingPathInput input) {
        // 1. 暂停频率：暂停次数 / 信号总数（归一化到0-1，上限0.3）
        double pauseFreq = Math.min(
            (double) input.getPauseCount(PAUSE_THRESHOLD_MS) / Math.max(input.getSignalCount(), 1),
            0.3
        ) / 0.3;

        // 2. 暂停时长占比：总暂停时长 / 总用时
        double pauseRatio = Math.min(
            (double) input.getTotalPauseMs() / Math.max(input.getTotalDurationMs(), 1),
            1.0
        );

        // 3. 删除操作占比：删除信号数 / 输入类信号总数
        double deleteRatio = Math.min(
            (double) input.getDeleteCount() / Math.max(input.getInputSignalCount(), 1),
            1.0
        );

        // 4. 答案撤回次数归一化（上限3次）
        double retractScore = Math.min(input.getRetractCount() / 3.0, 1.0);

        // 5. 重读次数归一化（上限5次）
        double rereadScore = Math.min(input.getRereadCount() / 5.0, 1.0);

        return clamp(
            W_PAUSE_FREQ * pauseFreq +
            W_PAUSE_RATIO * pauseRatio +
            W_DELETE_RATIO * deleteRatio +
            W_RETRACT * retractScore +
            W_REREAD * rereadScore,
            0.0, 1.0
        );
    }

    private double clamp(double v, double min, double max) {
        return Math.max(min, Math.min(max, v));
    }
}
```

### 5.2 路径模式分类器

```java
/**
 * 基于规则+阈值的路径模式分类器
 * 支持后续升级为基于聚类或小样本学习的分类方法
 */
public class PathPatternClassifier {

    public ThinkingPathPattern classify(PathMetrics m) {
        // RUSHED: 总用时极短 + 几乎无暂停
        if (m.getDurationSeconds() < 20 && m.getPauseCount() == 0) {
            return ThinkingPathPattern.RUSHED;
        }

        // STRUGGLING: 高犹豫 + 多次提示 + 低正确率
        if (m.getHesitationIndex() > 0.6 
            && m.getHintRequestCount() >= 2 
            && !m.isCorrect()) {
            return ThinkingPathPattern.STRUGGLING;
        }

        // DISTRACTED: 多次切后台 + 高工具切换
        if (m.getAppBgCount() >= 2 || m.getToolSwitchCount() >= 5) {
            return ThinkingPathPattern.DISTRACTED;
        }

        // TRIAL_ERROR: 多次答案修改/撤回
        if (m.getEditRevisionCount() >= 3 || m.getRetractCount() >= 2) {
            return ThinkingPathPattern.TRIAL_ERROR;
        }

        // HESITANT: 高犹豫指数但未到STRUGGLING
        if (m.getHesitationIndex() > 0.45) {
            return ThinkingPathPattern.HESITANT;
        }

        // FLUENT: 快速 + 低犹豫 + 正确
        if (m.getHesitationIndex() < 0.15 
            && m.getDurationSeconds() < 60 
            && m.isCorrect()) {
            return ThinkingPathPattern.FLUENT;
        }

        // DELIBERATE: 思考时间长但操作果断（低犹豫 + 长草稿使用）
        if (m.getDurationSeconds() > 90 
            && m.getHesitationIndex() < 0.25 
            && m.getScratchUseMs() > 20000) {
            return ThinkingPathPattern.DELIBERATE;
        }

        // STEADY: 默认分类 - 节奏适中
        return ThinkingPathPattern.STEADY;
    }
}
```

### 5.3 卡点检测算法

```java
/**
 * 卡点检测器
 * 识别学生答题过程中的关键困难时刻
 */
public class StuckPointDetector {

    /**
     * 检测单题答题过程中的卡点
     * @param signals 按时间排序的行为信号列表
     * @return 卡点列表
     */
    public List<StuckPoint> detect(List<BehaviorSignal> signals) {
        List<StuckPoint> stuckPoints = new ArrayList<>();

        for (int i = 0; i < signals.size(); i++) {
            BehaviorSignal current = signals.get(i);

            // 规则1: 长暂停 → 可能卡住
            if (current.getType() == BehaviorSignalType.INPUT_PAUSE) {
                long pauseMs = MapUtils.getLong(current.getPayload(), "durationMs", 0L);
                if (pauseMs > 15000) { // >15秒
                    stuckPoints.add(StuckPoint.builder()
                        .phase(detectPhase(current, signals, i))
                        .severity(pauseMs > 30000 ? "HIGH" : "MEDIUM")
                        .description(String.format("输入暂停%.0f秒", pauseMs / 1000.0))
                        .timestamp(current.getClientTimestamp())
                        .build());
                }
            }

            // 规则2: 连续删除（擦除大段内容）→ 可能方向错误
            if (current.getType() == BehaviorSignalType.INPUT_DELETE) {
                int deleteCount = MapUtils.getInt(current.getPayload(), "deleteCount", 0);
                int inputLength = MapUtils.getInt(current.getPayload(), "inputLength", 0);
                if (deleteCount > 10 || (inputLength > 0 && deleteCount > inputLength * 0.5)) {
                    stuckPoints.add(StuckPoint.builder()
                        .phase(detectPhase(current, signals, i))
                        .severity("MEDIUM")
                        .description("大量删除，可能解题方向有误")
                        .timestamp(current.getClientTimestamp())
                        .build());
                }
            }

            // 规则3: 请求提示 → 明确卡住
            if (current.getType() == BehaviorSignalType.HINT_REQUEST) {
                int hintLevel = MapUtils.getInt(current.getPayload(), "hintLevel", 1);
                stuckPoints.add(StuckPoint.builder()
                    .phase(detectPhase(current, signals, i))
                    .severity(hintLevel >= 2 ? "HIGH" : "LOW")
                    .description(String.format("请求第%d级提示", hintLevel))
                    .timestamp(current.getClientTimestamp())
                    .build());
            }

            // 规则4: 短时间内多次工具切换 → 慌乱信号
            int lookback = Math.min(i, 5); // 回看最近5个信号
            int recentToolSwitches = 0;
            for (int j = i - lookback; j <= i; j++) {
                if (signals.get(j).getType() == BehaviorSignalType.TOOL_SWITCH) {
                    recentToolSwitches++;
                }
            }
            if (recentToolSwitches >= 3 && current.getType() == BehaviorSignalType.TOOL_SWITCH) {
                stuckPoints.add(StuckPoint.builder()
                    .phase("TOOL_CONFUSION")
                    .severity("LOW")
                    .description("频繁切换工具，可能不知如何下手")
                    .timestamp(current.getClientTimestamp())
                    .build());
            }
        }

        // 合并相邻卡点（同一phase内，间隔<10秒的合并为一个）
        return mergeAdjacent(stuckPoints, 10_000);
    }

    /**
     * 根据信号在序列中的位置判断所处阶段
     */
    private String detectPhase(BehaviorSignal signal, List<BehaviorSignal> all, int index) {
        // 如果在第一个ANSWER_SUBMIT之前，根据信号类型判断
        int submitIdx = -1;
        for (int j = 0; j < all.size(); j++) {
            if (all.get(j).getType() == BehaviorSignalType.ANSWER_SUBMIT) {
                submitIdx = j;
                break;
            }
        }
        
        if (submitIdx < 0 || index < submitIdx) {
            // 提交前
            if (signal.getType() == BehaviorSignalType.QUESTION_VIEW 
                || signal.getType() == BehaviorSignalType.QUESTION_REREAD) {
                return "READING";
            }
            if (signal.getType() == BehaviorSignalType.SCRATCH_OPEN 
                || signal.getType() == BehaviorSignalType.SCRATCH_CLOSE) {
                return "SCRATCH_WORK";
            }
            return "ANSWERING";
        } else {
            return "REVIEW";
        }
    }

    private List<StuckPoint> mergeAdjacent(List<StuckPoint> points, long mergeWindowMs) {
        if (points.size() <= 1) return points;
        
        List<StuckPoint> merged = new ArrayList<>();
        StuckPoint current = points.get(0);
        
        for (int i = 1; i < points.size(); i++) {
            StuckPoint next = points.get(i);
            if (next.getTimestamp() - current.getTimestamp() < mergeWindowMs
                && next.getPhase().equals(current.getPhase())) {
                // 合并：取更高严重度
                current = current.toBuilder()
                    .severity(compareSeverity(current.getSeverity(), next.getSeverity()))
                    .description(current.getDescription() + "; " + next.getDescription())
                    .build();
            } else {
                merged.add(current);
                current = next;
            }
        }
        merged.add(current);
        return merged;
    }
}
```

### 5.4 阶段分割器

将连续的行为信号序列分割为语义化的阶段：

```java
/**
 * 答题行为阶段分割器
 * 将信号流分割为：READING → THINKING → SCRATCH_WORK → ANSWERING → REVIEW
 */
public class PhaseSegmenter {

    private static final Map<BehaviorSignalType, String> SIGNAL_TO_PHASE = Map.of(
        BehaviorSignalType.QUESTION_VIEW, "READING",
        BehaviorSignalType.QUESTION_REREAD, "READING",
        BehaviorSignalType.INPUT_START, "ANSWERING",
        BehaviorSignalType.INPUT_PAUSE, "THINKING",
        BehaviorSignalType.INPUT_RESUME, "ANSWERING",
        BehaviorSignalType.INPUT_DELETE, "ANSWERING",
        BehaviorSignalType.SCRATCH_OPEN, "SCRATCH_WORK",
        BehaviorSignalType.SCRATCH_CLOSE, "SCRATCH_WORK",
        BehaviorSignalType.HINT_REQUEST, "HINT_SEEKING",
        BehaviorSignalType.CALCULATOR_USE, "CALCULATION",
        BehaviorSignalType.FORMULA_REF, "REFERENCE",
        BehaviorSignalType.ANSWER_SUBMIT, "REVIEW",
        BehaviorSignalType.ANSWER_RETRACT, "REVISING"
    );

    public List<Phase> segment(List<BehaviorSignal> signals) {
        if (signals.isEmpty()) return Collections.emptyList();

        List<Phase> phases = new ArrayList<>();
        Phase current = null;
        long startTime = signals.get(0).getClientTimestamp();

        for (BehaviorSignal sig : signals) {
            String phaseName = SIGNAL_TO_PHASE.getOrDefault(sig.getType(), "OTHER");
            
            if (current == null || !current.getName().equals(phaseName)) {
                // 开始新阶段
                if (current != null) {
                    current.setEndMs(sig.getClientTimestamp() - startTime);
                    phases.add(current);
                }
                current = new Phase();
                current.setName(phaseName);
                current.setStartMs(sig.getClientTimestamp() - startTime);
                current.setSignalCount(1);
            } else {
                current.setSignalCount(current.getSignalCount() + 1);
            }
        }
        
        if (current != null) {
            long lastTs = signals.get(signals.size() - 1).getClientTimestamp();
            current.setEndMs(lastTs - startTime);
            phases.add(current);
        }

        // 合并过短的阶段（<2秒）到前一阶段
        return mergeShortPhases(phases, 2000);
    }

    private List<Phase> mergeShortPhases(List<Phase> phases, long thresholdMs) {
        if (phases.size() <= 1) return phases;
        List<Phase> result = new ArrayList<>();
        for (Phase p : phases) {
            if (result.isEmpty()) {
                result.add(p);
            } else {
                Phase last = result.get(result.size() - 1);
                long duration = p.getEndMs() - p.getStartMs();
                if (duration < thresholdMs) {
                    // 合并到上一阶段
                    last.setEndMs(p.getEndMs());
                    last.setSignalCount(last.getSignalCount() + p.getSignalCount());
                } else {
                    result.add(p);
                }
            }
        }
        return result;
    }
}
```

### 6.2 隐私保护规则

```java
public class SignalPrivacyFilter {

    // 不采集的内容（无论何种信号）
    // 1. 具体输入的文字/数字内容
    // 2. 草稿纸上的具体演算内容
    // 3. 粘贴的具体文本
    // 4. 截屏/录屏

    /**
     * 在信号打包前进行隐私过滤
     */
    public BehaviorSignal filter(BehaviorSignal signal) {
        // 对INPUT_DELETE信号：仅保留删除数量，不保留删除内容
        if (signal.getType() == BehaviorSignalType.INPUT_DELETE) {
            signal.getPayload().remove("deletedText");
        }
        
        // 对INPUT_PASTE信号：仅保留粘贴事件标记，不保留内容
        if (signal.getType() == BehaviorSignalType.INPUT_PASTE) {
            signal.getPayload().remove("pastedContent");
            signal.getPayload().put("pasteLength", 
                signal.getPayload().getOrDefault("originalLength", 0));
        }
        
        // 对CALCULATOR_USE信号：仅保留运算符结构
        if (signal.getType() == BehaviorSignalType.CALCULATOR_USE) {
            String expr = (String) signal.getPayload().get("expression");
            if (expr != null) {
                signal.getPayload().put("expression", sanitizeExpression(expr));
            }
        }
        
        return signal;
    }

    /**
     * 将计算表达式脱敏：仅保留运算符和操作数位数
     * "3.14 * (5 + 2)" → "N.NN * (N + N)"
     */
    private String sanitizeExpression(String expr) {
        return expr.replaceAll("\\d+\\.?\\d*", "N");
    }
}
```

### 6.3 客户端采集伪代码（Flutter）

```dart
class BehaviorTraceCollector {
  final List<BehaviorSignal> _buffer = [];
  Timer? _flushTimer;
  String? _currentSessionId;
  String? _currentAnswerId;
  int _questionIndex = 0;

  static const int _maxBufferSize = 500;
  static const Duration _flushInterval = Duration(seconds: 30);
  static const int _flushThreshold = 50;

  void startSession(String sessionId) {
    _currentSessionId = sessionId;
    _questionIndex = 0;
    _startFlushTimer();
  }

    _currentAnswerId = answerId;

    _emit(BehaviorSignalType.QUESTION_VIEW, {});
  }

  /// 监听答题输入框
  void onInputFocus() {
    _emit(BehaviorSignalType.INPUT_START, {});
  }

  void onInputIdle(Duration idleDuration) {
    _emit(BehaviorSignalType.INPUT_PAUSE, {'durationMs': idleDuration.inMilliseconds});
  }

  void onDelete(int deleteCount, int currentLength) {
    _emit(BehaviorSignalType.INPUT_DELETE, {
      'deleteCount': deleteCount,
      'inputLength': currentLength,
    });
  }

  void onHintRequest(int level, String hintType) {
    _emit(BehaviorSignalType.HINT_REQUEST, {
      'hintLevel': level,
      'hintType': hintType,
    });
  }

  void onScratchOpen() {
    _emit(BehaviorSignalType.SCRATCH_OPEN, {});
  }

  void onScratchClose(Duration duration) {
    _emit(BehaviorSignalType.SCRATCH_CLOSE, {
      'scratchDurationMs': duration.inMilliseconds,
    });
  }

  void onSubmit(int editCount, Duration totalTime) {
    _emit(BehaviorSignalType.ANSWER_SUBMIT, {
      'timeOnQuestionMs': totalTime.inMilliseconds,
      'editCount': editCount,
    });
  }

  void _emit(BehaviorSignalType type, Map<String, dynamic> payload) {
    if (_currentSessionId == null || _currentAnswerId == null) return;

    final signal = BehaviorSignal(
      signalId: '${_currentSessionId}_${DateTime.now().microsecondsSinceEpoch}',
      sessionId: _currentSessionId!,
      answerId: _currentAnswerId!,
      type: type,
      clientTimestamp: DateTime.now().millisecondsSinceEpoch,
      questionIndex: _questionIndex,
      payload: payload,
    );

    // 隐私过滤
    final filtered = SignalPrivacyFilter().filter(signal);
    
    // 入缓冲区
    if (_buffer.length >= _maxBufferSize) {
      // 丢弃最旧的非关键信号（保留QUESTION_VIEW和ANSWER_SUBMIT）
      _buffer.removeWhere((s) => 
          s.type != BehaviorSignalType.QUESTION_VIEW &&
          s.type != BehaviorSignalType.ANSWER_SUBMIT);
    }
    _buffer.add(filtered);

    // 达到阈值立即flush
    if (_buffer.length >= _flushThreshold) {
      _flush();
    }
  }

  void _startFlushTimer() {
    _flushTimer?.cancel();
    _flushTimer = Timer.periodic(_flushInterval, (_) => _flush());
  }

  Future<void> _flush() async {
    if (_buffer.isEmpty) return;
    
    final batch = List<BehaviorSignal>.from(_buffer);
    _buffer.clear();
    
    try {
      await _apiClient.postSignals(
        sessionId: _currentSessionId!,
        signals: batch,
      );
    } catch (e) {
      // 上报失败，重新放回缓冲区头部
      _buffer.insertAll(0, batch);
      // 写入离线缓存
      await _offlineCache.cacheSignals(batch);
    }
  }

  void endSession() {
    _flush();
    _flushTimer?.cancel();
    _currentSessionId = null;
  }
}
```

```java
public class BehaviorAnalysisPipeline {

    /**
     * 对一个完成的答题会话执行全量行为分析
     */
    public void analyzeSession(String sessionId) {
        // Step 1: 从ClickHouse拉取该会话全部信号
        List<BehaviorSignal> signals = signalRepository.findBySessionId(sessionId);
        if (signals.isEmpty()) return;

        // Step 2: 按 answerId 分组
        Map<String, List<BehaviorSignal>> signalsByAnswer = signals.stream()
            .collect(Collectors.groupingBy(BehaviorSignal::getAnswerId));

        // Step 3: 逐题分析
        List<ThinkingPathSnapshot> snapshots = new ArrayList<>();
        for (var entry : signalsByAnswer.entrySet()) {
            String answerId = entry.getKey();
            List<BehaviorSignal> answerSignals = entry.getValue();
            
            // 按时间排序
            answerSignals.sort(Comparator.comparingLong(BehaviorSignal::getClientTimestamp));

            // 阶段分割
            List<Phase> phases = phaseSegmenter.segment(answerSignals);
            
            // 指标计算
            PathMetrics metrics = metricsCalculator.calculate(answerSignals, phases);
            
            // 指数计算
            double hesitationIdx = hesitationCalculator.calculate(metrics);
            double confidenceIdx = confidenceCalculator.calculate(metrics);
            double efficiencyIdx = efficiencyCalculator.calculate(metrics);
            double focusIdx = focusCalculator.calculate(metrics);
            
            // 路径分类
            ThinkingPathPattern pattern = classifier.classify(metrics);
            
            // 卡点检测
            List<StuckPoint> stuckPoints = stuckDetector.detect(answerSignals);
            
            // 构建快照
            ThinkingPathSnapshot snapshot = ThinkingPathSnapshot.builder()
                .sessionId(sessionId)
                .answerId(answerId)
                .userId(metrics.getUserId())
                .questionId(metrics.getQuestionId())
                .timeToFirstActionMs(metrics.getTimeToFirstActionMs())
                .totalActiveTimeMs(metrics.getActiveTimeMs())
                .totalIdleTimeMs(metrics.getIdleTimeMs())
                .hesitationCount(metrics.getPauseCount())
                .deleteCount(metrics.getDeleteCount())
                .rerreadCount(metrics.getRereadCount())
                .hintRequestCount(metrics.getHintRequestCount())
                .toolSwitchCount(metrics.getToolSwitchCount())
                .scratchUseMs(metrics.getScratchUseMs())
                .calcUseCount(metrics.getCalcUseCount())
                .appBgCount(metrics.getAppBgCount())
                .editRevisionCount(metrics.getEditRevisionCount())
                .hesitationIndex(hesitationIdx)
                .confidenceIndex(confidenceIdx)
                .efficiencyIndex(efficiencyIdx)
                .focusIndex(focusIdx)
                .pathPattern(pattern.name())
                .stuckPointsJson(JsonUtils.toJson(stuckPoints))
                .isCorrect(metrics.isCorrect())
                .build();
            
            snapshots.add(snapshot);
            
            // 持久化
            snapshotRepository.upsert(snapshot);
        }

        // Step 4: 更新班级聚合（如果是作业/考试场景）
        if (signals.get(0).getMetadata("classId") != null) {
            updateClassAggregation(sessionId, snapshots);
        }

        // Step 5: 推送洞察事件（供学情分析服务消费）
        eventBus.publish(new ThinkingPathAnalyzedEvent(sessionId, snapshots));

        // Step 6: 检查是否需要触发家长通知（严重卡点）
        checkAndNotifyParents(snapshots);
    }
}
```

### 10.2 数据一致性保障

```java
/**
 * 信号上报幂等保障
 * 客户端每次flush生成唯一batchId，服务端基于batchId去重
 */
@PostMapping("/signals/batch")
public ApiResponse<BatchResult> receiveSignals(
        @RequestHeader("X-Batch-Id") String batchId,
        @RequestBody SignalBatchRequest request) {
    
    // 幂等检查
    if (idempotencyManager.exists(batchId)) {
        return ApiResponse.success(idempotencyManager.getResult(batchId));
    }
    
    try {
        BatchResult result = signalService.process(request, batchId);
        idempotencyManager.save(batchId, result, Duration.ofHours(24));
        return ApiResponse.success(result);
    } catch (Exception e) {
        log.error("处理信号批次失败, batchId={}", batchId, e);
        return ApiResponse.error(50001, "信号处理失败");
    }
}
```

### 10.3 分析任务容错

```java
/**
 * 分析任务重试策略
 */
@Component
public class AnalysisRetryStrategy {

    private static final int MAX_RETRY = 3;
    private static final long[] DELAYS = {60_000, 300_000, 1_800_000}; // 1min, 5min, 30min

    public void scheduleRetry(String sessionId, int attempt) {
        if (attempt >= MAX_RETRY) {
            // 进入死信队列，告警
            alertService.sendMinorAlert("行为分析任务失败超过重试上限", 
                Map.of("sessionId", sessionId, "attempts", attempt));
            deadLetterQueue.offer(new AnalysisDeadLetter(sessionId, attempt));
            return;
        }

        long delay = DELAYS[Math.min(attempt, DELAYS.length - 1)];
        retryScheduler.schedule(sessionId, attempt + 1, delay);
    }
}
```

## 11. 性能设计

### 11.1 性能目标

| 指标 | 目标 | 说明 |
| --- | --- | --- |
| 信号上报延迟 | P95 < 200ms | 不含网络传输时间 |
| 单会话分析耗时 | P95 < 3秒 | 30题以内的会话 |
| 思维路径查询 | P95 < 500ms | 含阶段分割+卡点+指标 |
| 班级分布查询 | P95 < 1秒 | 50人以内的班级 |
| 信号写入吞吐 | > 50,000 条/秒 | ClickHouse 批量写入 |

### 11.2 优化策略

1. **批量写入**：信号先入 Redis Stream 做缓冲，每 5 秒批量写入 ClickHouse。
2. **预计算**：班级聚合表在非高峰期（凌晨2-4点）批量预计算，查询时直接读结果。
3. **缓存**：思维路径查询结果缓存 1 小时（TTL），会话结束后缓存失效。
4. **降采样**：高并发期（晚间19-22点）自动将采样率从100%降至30%。
5. **列裁剪**：ClickHouse 查询只 SELECT 必要列，减少 IO。

```java
/**
 * 降采样控制器
 */
@Component
public class SamplingRateController {

    @Value("${behavior-trace.sampling.default-rate:1.0}")
    private double defaultRate;

    @Value("${behavior-trace.sampling.peak-rate:0.3}")
    private double peakRate;

    // 晚高峰时段
    private static final int PEAK_START_HOUR = 19;
    private static final int PEAK_END_HOUR = 22;

    /**
     * 获取当前采样率
     */
    public double getCurrentRate() {
        int hour = LocalTime.now().getHour();
        if (hour >= PEAK_START_HOUR && hour < PEAK_END_HOUR) {
            return peakRate;
        }
        return defaultRate;
    }

    /**
     * 判断该用户是否需要采集
     */
    public boolean shouldCollect(Long userId) {
        double rate = getCurrentRate();
        if (rate >= 1.0) return true;
        
        // 基于userId哈希采样，保证同一用户每次结果一致
        double hash = Math.abs(userId.hashCode() % 1000) / 1000.0;
        return hash < rate;
    }
}
```
