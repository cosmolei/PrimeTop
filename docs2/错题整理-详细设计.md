# 错题整理 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

错题整理模块帮助学生将错题从"零散记录"转化为"可复习、可分析、可提升"的长期学习资产。支持从拍题答疑、AI 练习、手动录入等多渠道自动收录，并提供错因标签、遗忘曲线复习、错题报告等能力。是 MVP 阶段 P0 核心功能。

### 1.2 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 错题收录 | 拍题答疑、练习错误、手动上传均可进入错题本 | P0 |
| 分类管理 | 按学科、年级、章节、知识点、错误原因归类 | P0 |
| 错因标签 | 概念不清、审题错误、计算失误、方法错误等标签 | P1 |
| 订正记录 | 记录学生订正过程和再次作答结果 | P1 |
| 复习提醒 | 基于遗忘曲线设置复习计划 | P1 |
| 错题报告 | 展示高频错点和阶段性改进情况 | P1 |

### 1.3 依赖关系

```
用户账号体系 → 学生档案（年级、学段、教材版本）
拍照搜题与习题答疑 → 拍题识别结果、解析、知识点映射
AI 智能辅导 → 错因分析 AI 能力、同类题生成
同步课堂学习 → 章节知识点、教材版本
```

## 2. 数据结构定义

### 2.1 错题记录 (MistakeRecord)

```sql
CREATE TABLE mistake_records (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    
    -- 来源信息
    source_type     VARCHAR(32)  NOT NULL COMMENT '来源类型: PHOTO|AI_PRACTICE|MANUAL|SYNC_EXERCISE',
    source_id       VARCHAR(128) NULL     COMMENT '来源ID（如拍题记录ID、练习会话ID）',
    
    -- 题目信息
    question_id     BIGINT       NULL     COMMENT '关联题库中的题目ID（如有）',
    question_text   TEXT         NOT NULL COMMENT '题目文本内容',
    question_images JSON         NULL     COMMENT '题目图片URL列表 ["url1","url2"]',
    question_type   VARCHAR(32)  NULL     COMMENT '题型: CHOICE|FILL|SHORT_ANSWER|CALCULATION|ESSAY',
    options         JSON         NULL     COMMENT '选项 JSON（选择题） [{"label":"A","text":"..."}]',
    
    -- 学科与教材定位
    subject_code    VARCHAR(16)  NOT NULL COMMENT '学科编码: MATH|CHINESE|ENGLISH|PHYSICS|...',
    grade_code      VARCHAR(16)  NOT NULL COMMENT '年级编码: G1~G12',
    textbook_id     BIGINT       NULL     COMMENT '教材版本ID',
    chapter_id      BIGINT       NULL     COMMENT '章节ID',
    knowledge_ids   JSON         NULL     COMMENT '关联知识点ID列表 [101, 205, 312]',
    
    -- 答题信息
    correct_answer  TEXT         NULL     COMMENT '正确答案',
    user_answer     TEXT         NULL     COMMENT '用户的错误答案',
    analysis        TEXT         NULL     COMMENT '解析内容（HTML）',
    analysis_images JSON         NULL     COMMENT '解析配图URL列表',
    
    -- 错因与状态
    error_tags      JSON         NULL     COMMENT '错因标签 ["CONCEPT_ERROR","CARELESS","..."]',
    mastery_level   TINYINT      NOT NULL DEFAULT 0 COMMENT '掌握程度 0=未掌握 1=部分掌握 2=已掌握',
    difficulty      TINYINT      NULL     COMMENT '题目难度 1~5',
    
    -- 复习相关
    review_count    INT          NOT NULL DEFAULT 0 COMMENT '已复习次数',
    next_review_at  DATETIME     NULL     COMMENT '下次复习时间（遗忘曲线）',
    last_reviewed_at DATETIME    NULL     COMMENT '上次复习时间',
    
    -- 订正记录
    correction_status VARCHAR(16) NOT NULL DEFAULT 'PENDING' COMMENT '订正状态: PENDING|CORRECTING|CORRECTED',
    
    -- 元数据
    note            TEXT         NULL     COMMENT '学生备注',
    is_archived     TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否归档 0=否 1=是',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_subject (user_id, subject_code),
    INDEX idx_user_chapter (user_id, chapter_id),
    INDEX idx_user_knowledge (user_id, (CAST(knowledge_ids AS CHAR(512)))),
    INDEX idx_user_review (user_id, next_review_at, is_archived),
    INDEX idx_user_created (user_id, created_at DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='错题记录表';
```

### 2.2 错因标签枚举 (ErrorTag)

```
CONCEPT_ERROR    — 概念不清：对知识点理解不透彻
MISREAD          — 审题错误：遗漏条件或理解偏差
CARELESS         — 计算失误：粗心导致的数值或符号错误
METHOD_ERROR     — 方法错误：解题方法选择不当
FORMULA_ERROR    — 公式错误：公式记忆错误或应用错误
LOGIC_ERROR      — 逻辑错误：推理过程有误
EXPRESSION_ERROR — 表达错误：书写不规范或语言表达问题
TIME_PRESSURE    — 时间不足：考试时间不够未完成
UNKNOWN          — 未分析：尚未判定原因
```

## 3. API 接口设计

### 3.1 错题收录

#### POST /api/v1/mistakes

创建一条错题记录（从拍题、练习等场景调用）。

**请求体：**
```json
{
  "sourceType": "PHOTO",
  "sourceId": "photo_20260519_001",
  "questionText": "已知函数 f(x) = x² - 4x + 3，求 f(x) 的最小值。",
  "questionImages": ["https://cdn.primetop.app/q/img_001.jpg"],
  "questionType": "CALCULATION",
  "options": null,
  "subjectCode": "MATH",
  "gradeCode": "G10",
  "textbookId": 3,
  "chapterId": 45,
  "knowledgeIds": [201, 205],
  "correctAnswer": "最小值为 -1，当 x = 2 时取得。",
  "userAnswer": "最小值为 0",
  "analysis": "<p>将 f(x) = x² - 4x + 3 配方得 f(x) = (x-2)² - 1，因此最小值为 -1。</p>",
  "errorTags": ["CARELESS"],
  "difficulty": 3
}
```

**响应 (201)：**
```json
{
  "id": 10234,
  "userId": 1001,
  "sourceType": "PHOTO",
  "subjectCode": "MATH",
  "chapterId": 45,
  "masteryLevel": 0,
```

2. 如果提供 `questionId`，从题库自动填充 `knowledgeIds`、`chapterId` 等字段
3. 调用遗忘曲线引擎计算首次复习时间（默认 +1 天）
4. 如果 `errorTags` 为空，异步调用 AI 进行错因分析

**请求体：**

```json
  "attemptNumber": 1,
```

   - `correctionStatus` → `CORRECTING`（允许继续订正）

   - 保持当前复习节奏
5. 插入 `correction_records` 记录

## 4. 遗忘曲线复习引擎

### 4.1 复习间隔策略

基于艾宾浩斯遗忘曲线，结合学生实际复习表现动态调整：

```
阶段1（首次）：  +1 天
阶段2：         +3 天
阶段3：         +7 天
阶段4：         +14 天
阶段5：         +30 天
```

**动态调整规则：**

| 复习结果 | 间隔调整 | 掌握度变化 |
|----------|----------|------------|
| CORRECT  | 按标准间隔推进到下一阶段 | +0 或 +1 |
| PARTIAL  | 间隔减半，不推进阶段 | 不变 |
| WRONG    | 回退到上一阶段，间隔重置 | -1（最低0） |
| SKIPPED  | 间隔不变，顺延1天 | 不变 |

### 4.2 核心计算逻辑

```python
import math
from datetime import datetime, timedelta

# 标准间隔表（天）
STANDARD_INTERVALS = [1, 3, 7, 14, 30]

def calculate_next_review(
    current_stage: int,
    result: str,
    mastery_level: int
) -> tuple[int, datetime, int]:
    """
    计算下次复习时间和更新后的掌握度。
    
    Returns: (new_stage, next_review_at, new_mastery_level)
    """
    now = datetime.now()
    
    if result == "CORRECT":
        new_stage = min(current_stage + 1, len(STANDARD_INTERVALS) - 1)
        interval_days = STANDARD_INTERVALS[new_stage]
        new_mastery = min(mastery_level + 1, 2)
        # 如果连续3次正确，直接标记已掌握
        if new_stage >= 4:
            new_mastery = 2
        
    elif result == "PARTIAL":
        new_stage = current_stage  # 不推进
        base_interval = STANDARD_INTERVALS[current_stage]
        interval_days = max(1, math.ceil(base_interval / 2))
        new_mastery = mastery_level
        
    elif result == "WRONG":
        new_stage = max(current_stage - 1, 0)
        interval_days = STANDARD_INTERVALS[new_stage]
        new_mastery = max(mastery_level - 1, 0)
        
    else:  # SKIPPED
        new_stage = current_stage
        interval_days = 1  # 顺延1天
        new_mastery = mastery_level
    
    next_review_at = now + timedelta(days=interval_days)
    return new_stage, next_review_at, new_mastery
```

### 4.3 每日复习任务生成

每日凌晨定时任务扫描：

```sql
-- 获取今日待复习的错题
SELECT mr.* 
FROM mistake_records mr
JOIN review_schedules rs ON rs.mistake_id = mr.id
WHERE mr.user_id = ?
  AND mr.is_archived = 0
  AND mr.mastery_level < 2
  AND rs.scheduled_date = CURDATE()
  AND rs.is_completed = 0
ORDER BY mr.subject_code, mr.chapter_id;
```

**每日复习上限：** 默认 20 道题/天（可在学习规划中调整），避免负担过重。

## 5. 状态流转

### 5.1 错题生命周期

```
                     ┌──────────────────────────────┐
                     │                              │
                     ▼                              │
  [创建] ──→ PENDING ──→ CORRECTING ──→ CORRECTED ─┤
               │              │                     │
               │              │ 再次做错             │ 掌握度=2
               │              ▼                     │
               │         CORRECTING                 ▼
               │          (继续)               [ARCHIVED]
               │
               │ 标记已掌握
               └────────────→ CORRECTED ──→ [ARCHIVED]
```

**状态说明：**

| 状态 | 含义 | 允许的操作 |
|------|------|------------|
| `PENDING` | 刚收录，未订正 | 查看详情、开始订正、编辑标签/备注、删除 |
| `CORRECTING` | 订正中（至少一次订正失败） | 继续订正、查看详情、编辑标签/备注 |
| `CORRECTED` | 已订正通过 | 查看详情、复习、归档 |
| `ARCHIVED` | 已归档（不再出现在日常列表） | 取消归档、查看详情 |

### 5.2 掌握度流转

```
0 (未掌握) ──→ 1 (部分掌握) ──→ 2 (已掌握)
    ▲                │
    │                │ 复习做错
    └────────────────┘
```

## 7. 错题统计与缓存策略

### 7.1 统计维度

错题报告需要聚合的数据量大，采用定时预计算 + 缓存策略：

| 统计维度 | 计算方式 | 缓存时间 |
|----------|----------|----------|
| 按学科分布 | 实时 COUNT + GROUP BY | 请求时计算，Redis 缓存 1h |
| 高频错因 | 实时聚合 | Redis 缓存 1h |
| 薄弱知识点 TOP10 | 实时聚合 | Redis 缓存 1h |
| 周报/月报 | 定时任务每日凌晨预计算 | 写入 mistake_reports 表 |
| 趋势数据 | 按天聚合写入 | Redis 缓存 1h |

### 7.2 Redis 缓存 Key 设计

```
mistake:stats:{userId}:subjects       → 学科分布统计（Hash）
mistake:stats:{userId}:error_tags     → 错因统计（Sorted Set）
mistake:stats:{userId}:knowledge      → 薄弱知识点（Sorted Set）
mistake:stats:{userId}:daily:{date}   → 当日新增/订正数（String）
mistake:review:{userId}:today         → 今日待复习列表（List，TTL 到当日结束）
```

## 8. 错误处理

### 8.1 错误码定义

| 错误码 | HTTP 状态码 | 说明 |
|--------|------------|------|
| `MISTAKE_NOT_FOUND` | 404 | 错题记录不存在 |
| `MISTAKE_FORBIDDEN` | 403 | 无权访问该错题（非本人） |
| `MISTAKE_ALREADY_EXISTS` | 409 | 同一题目已在错题本中（去重） |
| `CORRECTION_LIMIT_EXCEEDED` | 429 | 单题订正次数超过上限（最多 5 次/天） |
| `REVIEW_NOT_SCHEDULED` | 400 | 该题今日不在复习计划中 |
| `ANALYSIS_IN_PROGRESS` | 202 | AI 错因分析进行中，请稍后查询 |
| `ANALYSIS_FAILED` | 500 | AI 错因分析失败 |
| `INVALID_ERROR_TAG` | 400 | 无效的错因标签 |
| `BATCH_LIMIT_EXCEEDED` | 400 | 批量操作超过上限（最多 50 条） |

### 8.2 去重策略

同一用户 + 同一题目（`questionText` 相似度 > 90%）在 **7 天内** 不重复收录：

```python
def is_duplicate(user_id: int, question_text: str, subject_code: str) -> bool:
    """
    检查7天内是否已收录相同/相似的错题。
    使用 MinHash 或 SimHash 进行文本相似度判断。
    """
    cache_key = f"mistake:dedup:{user_id}:{subject_code}"
    # 简化实现：精确匹配 + 编辑距离
    recent_texts = redis.lrange(cache_key, 0, -1)
    for existing in recent_texts:
        similarity = compute_similarity(question_text, existing.decode())
        if similarity > 0.9:
            return True
    return False
```

### 8.3 AI 降级策略

当 AI 服务不可用时：

1. **错因分析：** 降级为手动选择标签（不自动推荐）
2. **订正判分：** 降级为精确字符串匹配 + 关键字匹配
3. **报告建议：** 跳过 AI 建议，只展示统计数据
4. **同类题推荐：** 缓存离线退化为无推荐

### 10.1 拍题答疑 → 错题收录

- 题目信息、AI 解析结果、知识点映射等

### 10.2 AI 练习 → 错题收录

同步课堂的同步练习结果中，答错的题目自动调用收录接口：
- `sourceType: "SYNC_EXERCISE"`
- `sourceId`: 练习会话 ID

### 10.3 错题 → 学情分析

错题数据是学情分析模块的核心数据源：
- 薄弱知识点 = 错题高频知识点
- 学科掌握度 = 基于 mastery_level 聚合
- 能力画像 = 基于 error_tags 聚合（如计算失误多 → 计算能力弱）

### 10.4 错题 → 学习规划

学习规划模块每日任务生成时：
- 检查 `review_schedules` 中今日待复习的错题
- 将错题复习纳入每日学习任务清单
- 复习优先级：掌握度低 + 临近复习时间的优先
