# 管理后台 - 会员订阅与财务运营工作台 详细设计

## 1. 概述

### 1.1 模块定位

会员订阅与财务运营工作台是 PrimeTop 管理后台的核心业务模块之一，面向平台运营人员、财务人员和管理员，提供会员体系管理、订阅生命周期监控、订单与支付管理、退款售后处理、发票管理、优惠券与促销配置、财务报表与数据看板等全链路后台能力。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 会员全生命周期可视 | 从注册→免费→付费→续费→退订→流失，全链路追踪与干预 |
| 财务数据实时透明 | 收入、退款、ARPU、续费率等核心指标实时可视 |
| 运营操作安全可控 | 退款、调账、会员变更等高危操作多级审批与审计 |
| 促销活动灵活配置 | 优惠券、折扣、限时活动等运营手段后台可配 |
| 合规与对账自动化 | 自动对账、电子发票开具、税务合规报表导出 |

### 1.3 适用范围

- 运营人员：会员查询、订阅管理、优惠券配置
- 财务人员：订单对账、退款审批、发票管理、报表导出
- 管理员：定价配置、高危操作审批、数据看板

### 1.4 依赖关系

```
┌─────────────────────────────────────────────────────┐
│           会员订阅与财务运营工作台 (本模块)            │
├─────────────────────────────────────────────────────┤
│ 用户服务 ─── 用户基础信息、身份认证、学生档案          │
│ 支付服务 ─── 订单创建、支付网关对接、交易回调          │
│ 会员服务 ─── 权益管理、订阅状态机、额度管控           │
│ 计费服务 ─── 实时用量核扣、账单生成                   │
│ 通知服务 ─── 续费提醒、退款通知、发票通知             │
│ 审计服务 ─── 操作日志、合规追溯                      │
└─────────────────────────────────────────────────────┘
```

## 2. 数据结构定义

### 2.1 会员计划配置表 `membership_plan`

```sql
CREATE TABLE membership_plan (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,

    plan_name       VARCHAR(128) NOT NULL COMMENT '计划名称',
    plan_type       TINYINT NOT NULL COMMENT '类型: 1=月度 2=季度 3=年度 4=中考专项 5=高考专项 6=家庭套餐',
    target_segment  VARCHAR(32) COMMENT '目标学段: preschool/primary/middle/high/all',

    selling_price   DECIMAL(10,2) NOT NULL COMMENT '售价（分）',
```

## 3. 核心业务状态机

### 3.1 订单状态流转

```
                         ┌──────────┐
                         │ created  │ ← 订单创建
                         └────┬─────┘
                              │ 用户发起支付
                              ▼
                         ┌──────────────┐
                  ┌──────│ pending_paid │
                  │      └──────┬───────┘
                  │             │
           超时未支付      支付成功
           (30min)           │
                  │             ▼
                  ▼      ┌──────┐
             ┌──────────┐│ paid │
             │ cancelled ││      │
             └──────────┘└──┬───┘
                              │ 用户申请退款
                              ▼
                        ┌───────────┐
                        │ refunding │
                        └─────┬─────┘
                              │
                    ┌─────────┼─────────┐
                    │         │         │
                 退款成功   退款拒绝   退款失败
                    │         │         │
                    ▼         │         ▼
             ┌──────────┐    │  ┌──────┐
             │ refunded │    │  │failed│
             └──────────┘    │  └──────┘
                             │  (可重试)
                             ▼
                        ┌──────┐
                        │ paid │ ← 回到已支付
                        └──────┘
```

### 3.2 会员订阅状态流转

```
                    ┌─────────┐
                    │ pending │ ← 订单已创建未支付
                    └────┬────┘
                         │ 支付成功
                         ▼
                    ┌────────┐
          ┌─────────│ active │
          │         └───┬────┘
          │             │
     手动取消      到期未续费
     (cancel)     (end_date过)
          │             │
          ▼             ▼
    ┌───────────┐ ┌─────────┐
    │ cancelled │ │ expired │
    └───────────┘ └─────────┘
          │
     退款成功
          │
          ▼
    ┌──────────┐
    │ refunded │ ← 会员权益撤销
    └──────────┘

    特殊状态:
    ┌──────────┐
    │suspended │ ← 风控冻结 / 支付异常
    └──────────┘
```

## 4. API 接口设计

### 4.1 接口规范

- 基础路径：`/api/admin/finance`
- 认证方式：Bearer Token + 角色权限校验
- 响应格式：统一 `{ code, message, data }`

### 4.2 会员计划管理

#### 4.2.1 获取会员计划列表

```
GET /api/admin/finance/plans
```

**Query 参数：**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| page | int | 页码，默认1 |
| pageSize | int | 每页条数，默认20 |
| planType | int | 计划类型筛选 |
| status | int | 状态筛选 |
| keyword | string | 名称模糊搜索 |

**响应示例：**

```json
{
  "code": 0,
  "data": {
    "total": 8,
    "list": [
      {
        "id": 1,
        "planCode": "monthly_premium",
        "planName": "月度会员",
        "planType": 1,
        "sellingPrice": 29.90,
        "originalPrice": 39.90,
        "durationDays": 30,
        "aiQuotaDaily": -1,
        "status": 1,
        "subscriberCount": 15234,
        "createdAt": "2026-05-01 10:00:00"
      }
    ]
  }
}
```

#### 4.2.2 创建/更新会员计划

```
POST /api/admin/finance/plans
PUT  /api/admin/finance/plans/{id}
```

**请求体：**

```json
{
  "planCode": "annual_premium",
  "planName": "年度会员",
  "planType": 3,
  "targetSegment": "all",
  "originalPrice": 359.00,
  "sellingPrice": 198.00,
  "discountPrice": null,
  "durationDays": 365,
  "aiQuotaDaily": -1,
  "photoQuotaDaily": -1,
  "features": ["full_analysis", "study_report", "ad_free", "priority_model", "offline_cache"],
  "sortOrder": 10,
  "status": 1,
  "isRecommended": 1
}
```

#### 4.2.3 上下架会员计划

```
PATCH /api/admin/finance/plans/{id}/status
```

```json
{
  "status": 0  // 1=上架, 0=下架
}
```

> **注意：** 下架不影响已订阅用户，仅影响新购买入口。
