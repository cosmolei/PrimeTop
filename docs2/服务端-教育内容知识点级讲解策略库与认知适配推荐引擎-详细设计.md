# 教育内容知识点级讲解策略库与认知适配推荐引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 AI 辅导对话系统与教学内容之间的**策略中间层**。当 AI 需要向学生讲解某个知识点时，本引擎负责回答一个关键问题：**对于这个特定的知识点、这个特定的学生，在当前的学习情境下，应该采用什么样的讲解策略？**

现有系统中：
- **Prompt 编排系统**按场景（学段、学科、题型）组织提示词模板，但不关心具体知识点的教学法差异。
- **AI 辅导策略引擎**关注的是交互层面的启发式引导模式（提问 vs 讲解 vs 练习），而非知识内容本身的呈现方式。
- **学习风格识别服务**识别学生的认知偏好（视觉型 / 听觉型 / 读写型 / 动觉型），但不提供知识点级的具体教学策略。

本引擎填补这一空白：为**每个知识点**维护多维度的讲解策略库，结合学生的认知画像和学习上下文，智能推荐最优讲解路径。

### 1.2 核心目标

| 目标 | 说明 |
| --- | --- |
| 策略多样性 | 每个知识点至少维护 3-5 种讲解策略，避免单一讲解方式 |
| 认知适配 | 根据学生认知画像、历史学习数据动态选择最优策略 |
| 策略切换 | 当学生反馈"听不懂"时，自动切换到替代策略 |
| 效果追踪 | 追踪每种策略对不同类型学生的实际效果，持续优化推荐 |
| 迷思概念干预 | 内置常见错误认知，在讲解时主动预防 |

### 1.3 适用范围

- AI 智能辅导对话中的知识点讲解
- 同步课堂学习中的知识点预习/复习
- 拍题答疑后的知识点拓展讲解
- 错题复习时的针对性知识点回顾
- 学习卡片和微学习的素材选择

## 2. 核心概念定义

### 2.1 讲解策略（Explanation Strategy）

讲解策略是针对单个知识点的**结构化教学方法**，包含：

| 属性 | 说明 | 示例 |
| --- | --- | --- |
| strategy_id | 唯一标识 | `ks_001_math_quadratic_visual` |
 | knowledge_point_id | 关联知识点 | `kp_math_0231` |
| strategy_type | 策略类型 | `visual_analogy` |
| cognitive_load | 认知负荷预估 | `medium` |
| applicable_stages | 适用学段 | `["初中", "高中"]` |
| prerequisite_clarity | 前置知识清晰度要求 | `high` |
| typical_duration_sec | 典型讲解耗时 | `120` |
| strategy_template | 策略结构模板 | 见下方数据结构 |
| effectiveness_score | 效果评分（动态） | `0.78` |
| status | 状态 | `active` |

### 2.2 策略类型体系

| 策略类型 | 标识 | 适用学科 | 描述 |
| --- | --- | --- | --- |
| 视觉类比 | `visual_analogy` | 全学科 | 用图形、动画、生活场景类比抽象概念 |
| 分步推导 | `step_by_step` | 数学、物理、化学 | 从已知条件逐步推导到结论 |
| 归纳发现 | `inductive_discovery` | 全学科 | 先给多个例子，引导学生发现规律 |
| 演绎证明 | `deductive_proof` | 数学、物理 | 从公理/定理出发严格证明 |
| 苏格拉底式提问 | `socratic_questioning` | 全学科 | 通过连续追问引导学生自己思考出答案 |
| 实验探究 | `experimental_inquiry` | 物理、化学、生物 | 通过虚拟实验引导观察和总结 |
| 对比辨析 | `comparative_analysis` | 全学科 | 对比易混淆概念，突出差异 |
| 故事情境 | `narrative_context` | 语文、历史、政治 | 用故事/历史情境承载知识点 |
| 口诀记忆 | `mnemonic_device` | 化学、生物、地理 | 用口诀/谐音辅助记忆 |
| 知识图谱关联 | `graph_traversal` | 全学科 | 通过已掌握知识点逐步引出新知识点 |

### 2.3 迷思概念（Misconception）

学生在学习某个知识点前**已存在的错误认知**，需要在讲解中主动纠正：

| 属性 | 说明 | 示例 |
| --- | --- | --- |
| misconception_id | 唯一标识 | `mis_001` |
| knowledge_point_id | 关联知识点 | `kp_phys_0042` |
| description | 迷思描述 | "力是维持物体运动的原因" |
| detection_pattern | 识别特征 | "学生提到'没有力就会停下来'" |
| correction_strategy | 纠正策略 | "展示无摩擦条件下的运动" |
| severity | 严重程度 | `high` / `medium` / `low` |
| prevalence | 普遍率（0-1） | `0.65`（65%的学生有此迷思） |

## 3. 数据结构设计

### 3.1 数据库表设计

#### 3.1.1 知识点讲解策略表 `kp_explanation_strategies`

```sql
CREATE TABLE kp_explanation_strategies (
    strategy_id          VARCHAR(64)   PRIMARY KEY COMMENT '策略唯一标识',
    knowledge_point_id   VARCHAR(64)   NOT NULL COMMENT '关联知识点ID',
    strategy_type        VARCHAR(32)   NOT NULL COMMENT '策略类型: visual_analogy/step_by_step/...',
    strategy_title       VARCHAR(128)  NOT NULL COMMENT '策略简短标题',
    strategy_description TEXT          NOT NULL COMMENT '策略详细描述',
    
    -- 适用条件
    applicable_stages    JSON          NOT NULL COMMENT '适用学段: ["初中","高中"]',
    applicable_subjects  JSON          NOT NULL COMMENT '适用学科: ["数学"]',
    min_grade_level      INT           DEFAULT 7 COMMENT '最低适用年级',
    max_grade_level      INT           DEFAULT 12 COMMENT '最高适用年级',
    
    -- 认知特征
    cognitive_load       ENUM('low','medium','high') NOT NULL DEFAULT 'medium' COMMENT '认知负荷预估',
    prerequisite_clarity ENUM('low','medium','high') NOT NULL DEFAULT 'medium' COMMENT '前置知识要求',
    typical_duration_sec INT           NOT NULL DEFAULT 120 COMMENT '典型讲解耗时(秒)',
    
    -- 策略内容
    strategy_template    JSON          NOT NULL COMMENT '策略结构模板(见3.2)',
    key_examples         JSON          DEFAULT NULL COMMENT '关键示例素材引用',
    visual_assets        JSON          DEFAULT NULL COMMENT '视觉素材引用列表',
    
    -- 运行时数据
    effectiveness_score  DECIMAL(4,3)  DEFAULT 0.500 COMMENT '效果评分(动态更新, 0-1)',
    usage_count          INT           DEFAULT 0 COMMENT '累计使用次数',
    positive_feedback_rate DECIMAL(4,3) DEFAULT 0.500 COMMENT '正面反馈率',
    avg_comprehension_score DECIMAL(4,3) DEFAULT 0.500 COMMENT '平均理解度评分',
    
    -- 管理字段
    status               ENUM('draft','active','deprecated') NOT NULL DEFAULT 'draft',
    version              INT           NOT NULL DEFAULT 1 COMMENT '策略版本号',
    created_by           VARCHAR(64)   NOT NULL COMMENT '创建者',
    created_at           DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at           DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    
    INDEX idx_kp_type (knowledge_point_id, strategy_type),
    INDEX idx_kp_active (knowledge_point_id, status),
    INDEX idx_effectiveness (effectiveness_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识点讲解策略表';
```

#### 3.1.2 知识点迷思概念表 `kp_misconceptions`

```sql
CREATE TABLE kp_misconceptions (
    misconception_id     VARCHAR(64)   PRIMARY KEY COMMENT '迷思概念唯一标识',
    knowledge_point_id   VARCHAR(64)   NOT NULL COMMENT '关联知识点ID',
    description          TEXT          NOT NULL COMMENT '迷思概念描述',
    detection_pattern    TEXT          DEFAULT NULL COMMENT '识别特征(自然语言模式)',
    detection_keywords   JSON          DEFAULT NULL COMMENT '识别关键词列表',
    correction_strategy  TEXT          NOT NULL COMMENT '纠正策略描述',
    correction_strategy_id VARCHAR(64) DEFAULT NULL COMMENT '关联的推荐纠正策略ID',
    severity             ENUM('low','medium','high') NOT NULL DEFAULT 'medium',
    prevalence           DECIMAL(4,3)  DEFAULT 0.000 COMMENT '普遍率(0-1)',
    applicable_stages    JSON          NOT NULL COMMENT '适用学段',
    
    created_at           DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at           DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    
    INDEX idx_kp (knowledge_point_id),
    INDEX idx_severity (knowledge_point_id, severity)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识点迷思概念表';
```

#### 3.1.3 策略推荐日志表 `strategy_recommendation_logs`

```sql
CREATE TABLE strategy_recommendation_logs (
    log_id               BIGINT        PRIMARY KEY AUTO_INCREMENT COMMENT '日志ID',
    student_id           VARCHAR(64)   NOT NULL COMMENT '学生ID',
    knowledge_point_id   VARCHAR(64)   NOT NULL COMMENT '知识点ID',
    session_id           VARCHAR(64)   NOT NULL COMMENT '学习会话ID',
    
    -- 推荐结果
    recommended_strategy_ids JSON      NOT NULL COMMENT '推荐策略ID列表(按优先级排序)',
    selected_strategy_id VARCHAR(64)   NOT NULL COMMENT '最终使用的策略ID',
    selection_reason     VARCHAR(256)  DEFAULT NULL COMMENT '选择原因',
    
    -- 学生认知画像快照
    student_profile_snapshot JSON     NOT NULL COMMENT '推荐时的学生画像快照',
    learning_context     JSON          NOT NULL COMMENT '学习上下文(模块/来源/时间)',
    
    -- 效果追踪
    student_feedback     ENUM('helpful','neutral','confusing','no_response') DEFAULT 'no_response',
    comprehension_score  DECIMAL(4,3)  DEFAULT NULL COMMENT '讲解后理解度评分',
    strategy_switched    TINYINT(1)    DEFAULT 0 COMMENT '是否触发了策略切换',
    switched_to_strategy_id VARCHAR(64) DEFAULT NULL COMMENT '切换后的策略ID',
    follow_up_correct_rate DECIMAL(4,3) DEFAULT NULL COMMENT '讲解后相关题目正确率',
    
    created_at           DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    
    INDEX idx_student_kp (student_id, knowledge_point_id),
    INDEX idx_kp_strategy (knowledge_point_id, selected_strategy_id),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='策略推荐日志表';
```

#### 3.1.4 策略效果统计表 `strategy_effectiveness_stats`

```sql
CREATE TABLE strategy_effectiveness_stats (
    stat_id              BIGINT        PRIMARY KEY AUTO_INCREMENT,
    strategy_id          VARCHAR(64)   NOT NULL COMMENT '策略ID',
    knowledge_point_id   VARCHAR(64)   NOT NULL COMMENT '知识点ID',
    
    -- 统计周期
    stat_period          DATE          NOT NULL COMMENT '统计日期',
    
    -- 聚合数据
    total_usage          INT           NOT NULL DEFAULT 0 COMMENT '周期内使用次数',
    positive_count       INT           NOT NULL DEFAULT 0 COMMENT '正面反馈次数',
    neutral_count        INT           NOT NULL DEFAULT 0 COMMENT '中性反馈次数',
    negative_count       INT           NOT NULL DEFAULT 0 COMMENT '负面反馈次数',
    switch_count         INT           NOT NULL DEFAULT 0 COMMENT '被切换次数',
    avg_comprehension    DECIMAL(4,3)  DEFAULT NULL COMMENT '平均理解度',
    avg_follow_up_correct DECIMAL(4,3) DEFAULT NULL COMMENT '讲解后题目平均正确率',
    
    -- 分维度统计
    by_stage_stats       JSON          DEFAULT NULL COMMENT '按学段分组效果统计',
    by_learning_style    JSON          DEFAULT NULL COMMENT '按学习风格分组效果统计',
    
    created_at           DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at           DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    
    UNIQUE KEY uk_strategy_period (strategy_id, stat_period),
    INDEX idx_kp_period (knowledge_point_id, stat_period)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='策略效果统计表';
```

#### 3.1.5 知识点策略关联矩阵 `kp_strategy_matrix`

```sql
CREATE TABLE kp_strategy_matrix (
    knowledge_point_id   VARCHAR(64)   NOT NULL COMMENT '知识点ID',
    strategy_id          VARCHAR(64)   NOT NULL COMMENT '策略ID',
    
    -- 该策略对此知识点的适用评分
    pedagogical_fit      DECIMAL(4,3)  DEFAULT 0.500 COMMENT '教学法契合度(专家评估, 0-1)',
    difficulty_alignment ENUM('below','at','above') NOT NULL DEFAULT 'at' COMMENT '难度对齐',
    
    -- 策略间关系
    is_default           TINYINT(1)    DEFAULT 0 COMMENT '是否为默认推荐策略',
    fallback_priority    INT           DEFAULT 100 COMMENT '回退优先级(越小越优先)',
    
    PRIMARY KEY (knowledge_point_id, strategy_id),
    INDEX idx_default (knowledge_point_id, is_default),
    INDEX idx_fallback (knowledge_point_id, fallback_priority)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='知识点策略关联矩阵';
```

## 4. API 接口设计

### 4.1 获取推荐讲解策略

**POST** `/api/v1/strategy/recommend`

**请求体：**

```json
{
  "knowledge_point_id": "kp_math_0231",
  "student_id": "stu_2024_00001",
  "learning_context": {
    "module": "ai_tutoring",
```

## 5. 策略推荐算法

### 5.1 推荐流程总览

```
输入: knowledge_point_id, student_id, learning_context, constraints
  │
  ▼
┌─────────────────────────┐
│ Step 1: 获取候选策略集合  │  从 kp_strategy_matrix 查询该知识点所有 active 策略
└───────────┬─────────────┘
            │ candidates[]
            ▼
┌─────────────────────────┐
│ Step 2: 硬约束过滤       │  学段/年级/认知负荷上限/排除策略类型
└───────────┬─────────────┘
            │ filtered[]
            ▼
┌─────────────────────────┐
│ Step 3: 特征工程         │  构建学生-策略匹配特征向量
└───────────┬─────────────┘
            │ features{}
            ▼
┌─────────────────────────┐
│ Step 4: 多因子评分       │  加权计算每个策略的置信度
```

### 5.3 多因子评分模型

```python
class StrategyScorer:
    """策略多因子评分器"""

    # 默认权重，可通过配置中心动态调整
    DEFAULT_WEIGHTS = {
        "learning_style_match":     0.18,
        "cognitive_load_fit":       0.12,
        "strategy_effectiveness":   0.20,
        "student_history_score":    0.15,
        "similar_student_score":    0.10,
        "pedagogical_fit":          0.08,
        "time_budget_fit":          0.05,
        "interaction_mode_fit":     0.05,
        "module_context_fit":       0.04,
        "misconception_risk":       0.03,  # 负向：风险越高分越低
    }

    def score(
        self,
        features: dict,
        custom_weights: dict = None,
    ) -> float:
        weights = {**self.DEFAULT_WEIGHTS, **(custom_weights or {})}
        
        # 计算加权总分
        total = 0.0
        for key, weight in weights.items():
            value = features.get(key, 0.5)
            # misconception_risk 是负向指标
            if key == "misconception_risk":
                value = 1.0 - value
            total += weight * value
        
        # 归一化
        weight_sum = sum(weights.values())
        return total / weight_sum if weight_sum > 0 else 0.5

    def rank_strategies(
        self,
        candidates: list[dict],
        student_profile: dict,
        knowledge_point: dict,
        learning_context: dict,
        feature_extractor: StrategyFeatureExtractor,
    ) -> list[tuple[str, float, dict]]:
        """对候选策略评分排序"""
        scored = []
        for strategy in candidates:
            features = feature_extractor.extract_features(
                strategy, student_profile, knowledge_point, learning_context
            )
            score = self.score(features)
            scored.append((strategy["strategy_id"], score, features))
        
        # 按分数降序排列
        scored.sort(key=lambda x: x[1], reverse=True)
        return scored
```

### 5.4 推荐结果构建

```python
class RecommendationBuilder:
    """构建策略推荐结果"""

    def build(
        self,
        scored_strategies: list[tuple[str, float, dict]],
        knowledge_point: dict,
        misconceptions: list[dict],
        top_n: int = 3,
        min_confidence: float = 0.3,
    ) -> dict:
        # 过滤低置信度策略
        qualified = [
            (sid, score, feat) for sid, score, feat in scored_strategies
            if score >= min_confidence
        ]
        
        if not qualified:
            # 全部低于阈值时回退到默认策略
            return self._build_fallback(knowledge_point)
        
        # 主推荐（前N个）
        primary = qualified[:top_n]
        
        # 回退策略（剩余的按 fallback_priority 排序）
        fallback_pool = qualified[top_n:]
        
        result = {
            "strategies": [
                {
                    "strategy_id": sid,
                    "confidence_score": round(score, 3),
                    "selection_reasons": self._generate_reasons(feat),
                }
                for sid, score, feat in primary
            ],
            "fallback_strategies": [
                {
                    "strategy_id": sid,
                    "fallback_priority": idx + 1,
                }
                for idx, (sid, _, _) in enumerate(fallback_pool)
            ],
            "misconception_alerts": self._build_misconception_alerts(
                misconceptions, knowledge_point
            ),
        }
        return result

    def _generate_reasons(self, features: dict) -> list[str]:
        """生成人类可读的选择原因"""
        reasons = []
        if features.get("learning_style_match", 0) > 0.8:
            reasons.append("学生认知画像偏好此策略类型")
        if features.get("strategy_effectiveness", 0) > 0.7:
            reasons.append(f"该策略整体效果评分 {features['strategy_effectiveness']:.2f}")
        if features.get("student_history_score", 0.5) > 0.7:
            reasons.append("学生历史使用此策略类型理解度高")
        if features.get("similar_student_score", 0.5) > 0.7:
            reasons.append("相似学生群体使用此策略效果良好")
        if not reasons:
            reasons.append("综合评分最优")
        return reasons
```

## 6. 策略切换机制

### 6.1 切换触发条件

| 触发类型 | 标识 | 检测方式 | 紧急度 |
| --- | --- | --- | --- |
| 学生明确请求 | `explicit_request` | "听不懂"/"换个方式"/"再讲讲" | 高 |
| 低理解度信号 | `low_comprehension` | 讲解后理解度评分 < 阈值 | 高 |
| 长时间停顿 | `long_pause` | 核心阶段后 > 30s 无学生回应 | 中 |
| 重复提问 | `repeated_question` | 学生重复问同一知识点 | 中 |
| 负面反馈 | `negative_feedback` | 学生点踩/反馈无用 | 高 |
| 迷思概念触发 | `misconception_detected` | 检测到典型迷思概念回答 | 中 |

### 6.2 切换决策逻辑

```python
class StrategySwitchEngine:
    """策略切换决策引擎"""

    SWITCH_RULES = {
        "explicit_request": {
            "target_type": "different_from_current",  # 必须切换到不同类型
            "max_switches_per_session": 3,
            "priority_boost": 0.2,  # 切换候选的优先级提升
        },
        "low_comprehension": {
            "target_type": "lower_cognitive_load",  # 优先切换到更低认知负荷
            "max_switches_per_session": 2,
            "threshold": 0.4,
        },
        "negative_feedback": {
            "target_type": "different_from_current",
            "max_switches_per_session": 1,
            "require_human_review": True,  # 触发人工审核
        },
        "misconception_detected": {
            "target_type": "misconception_correction",  # 切换到迷思概念纠正策略
            "max_switches_per_session": 2,
        },
    }

    def evaluate_switch(
        self,
        trigger_type: str,
        current_strategy: dict,
        session_context: dict,
        available_strategies: list[dict],
    ) -> dict | None:
        rule = self.SWITCH_RULES.get(trigger_type)
        if not rule:
            return None

        # 检查会话内切换次数限制
        switch_count = session_context.get("switch_count", 0)
        if switch_count >= rule["max_switches_per_session"]:
            return {
                "action": "no_switch_limit_reached",
                "fallback_action": "suggest_human_tutor",
                "message": "已尝试多种讲解策略，建议稍后复习或询问老师",
            }

        # 根据规则筛选目标策略
        candidates = self._filter_switch_candidates(
            current_strategy, available_strategies, rule["target_type"]
        )

        if not candidates:
            return {
                "action": "no_available_strategy",
                "message": "暂无更多讲解策略可用",
            }

        # 选择最佳切换目标
        best = candidates[0]  # 已按效果评分排序

        # 生成过渡指令
        transition = self._generate_transition(
            current_strategy, best, trigger_type, session_context
        )

        return {
            "action": "switch",
            "new_strategy_id": best["strategy_id"],
            "strategy_type": best["strategy_type"],
            "transition_directive": transition["directive"],
            "carry_over_context": transition["carry_over"],
            "reasoning": transition["reasoning"],
        }

    def _filter_switch_candidates(
        self,
        current: dict,
        available: list[dict],
        target_type: str,
    ) -> list[dict]:
        current_type = current["strategy_type"]

        filtered = [
            s for s in available
            if s["strategy_type"] != current_type and s["status"] == "active"
        ]

        if target_type == "lower_cognitive_load":
            LOAD_ORDER = {"low": 0, "medium": 1, "high": 2}
            current_load = LOAD_ORDER[current.get("cognitive_load", "medium")]
            filtered = [
                s for s in filtered
                if LOAD_ORDER.get(s.get("cognitive_load", "medium"), 1) < current_load
            ] or filtered  # 如果没有更低负荷的，保持全部候选

        elif target_type == "misconception_correction":
            filtered = [
                s for s in filtered
                if s["strategy_type"] in ("comparative_analysis", "inductive_discovery", "experimental_inquiry")
            ] or filtered

        # 按效果评分排序
        filtered.sort(key=lambda s: s.get("effectiveness_score", 0.5), reverse=True)
        return filtered

    def _generate_transition(
        self,
        from_strategy: dict,
        to_strategy: dict,
        trigger_type: str,
        session_context: dict,
    ) -> dict:
        """生成策略切换的过渡指令和上下文继承"""
        current_phase = session_context.get("current_phase", "unknown")
        elapsed = session_context.get("elapsed_sec", 0)

        TRANSITION_TEMPLATES = {
            "explicit_request": {
                "directive": f"学生表示当前讲解方式不太理解，切换到「{to_strategy['strategy_title']}」策略。"
                            f"不要重新从头讲，而是从学生已理解的部分继续，用新的方式解释还不清楚的部分。",
                "reasoning": "学生主动请求换一种方式",
            },
            "low_comprehension": {
                "directive": f"检测到学生对当前讲解理解度较低，切换到认知负荷更低的「{to_strategy['strategy_title']}」策略。"
                            f"先用更简单的例子引入，再逐步加深。",
                "reasoning": f"理解度评分 {session_context.get('comprehension_score', '?')} 低于阈值",
            },
```

```python
class MisconceptionIntervener:
    """迷思概念干预器"""

    async def intervene(
        self,
        misconception: dict,
        student_profile: dict,
        current_strategy: dict,
        dialogue_context: list[dict],
    ) -> dict:
        severity = misconception["severity"]
        prevalence = misconception.get("prevalence", 0.5)

        intervention = {
            "type": "misconception_intervention",
            "misconception_id": misconception["misconception_id"],
            "should_pause": severity == "high",
            "steps": [],
        }

        if severity == "high":
            # 高严重度：立即暂停，正面纠正
            intervention["steps"] = [
                {
                    "action": "acknowledge",
                    "directive": f"这是一个非常常见的理解误区！很多同学（约{prevalence:.0%}）都有同样的想法。",
                },
                {
                    "action": "challenge",
                    "directive": f"让我们用一个例子来检验这个想法...",
                    "example_type": misconception.get("correction_strategy", "counter_example"),
                },
                {
                    "action": "rebuild",
                    "directive": "现在我们用正确的方式来理解...",
                    "new_strategy_type": "comparative_analysis",
                },
                {
                    "action": "verify",
                    "directive": "让我出一道小测试确认一下...",
                    "check_question": None,  # 动态生成
                },
            ]
        elif severity == "medium":
            # 中等严重度：在当前讲解中自然嵌入纠正
            intervention["should_pause"] = False
            intervention["steps"] = [
                {
                    "action": "embedded_correction",
                    "directive": f"在接下来的讲解中，注意强调与 {misconception['description']} 的区别。",
                    "inject_at_phase": "core_concept",
                }
            ]
        else:
            # 低严重度：记录但不打断
            intervention["type"] = "misconception_note"
            intervention["steps"] = [
                {
                    "action": "log_only",
                    "directive": "记录迷思信号，在后续练习中针对性检测",
                }
            ]

        return intervention
```

```python
class EffectivenessUpdater:
    """策略效果评分动态更新器"""

    # 指数移动平均的衰减因子
    EMA_ALPHA = 0.15

    async def update_strategy_score(
        self,
        strategy_id: str,
        knowledge_point_id: str,
        feedback_event: dict,
    ) -> float:
        """更新策略效果评分（EMA方式）"""
        
        # 获取当前评分
        current_score = await self._get_current_score(strategy_id)
        
        # 计算本次事件得分
        event_score = self._calculate_event_score(feedback_event)
        
        # EMA 更新
        new_score = self.EMA_ALPHA * event_score + (1 - self.EMA_ALPHA) * current_score
        
        # 写入数据库
        await self._persist_score(strategy_id, new_score)
        
        # 更新使用计数
        await self._increment_usage(strategy_id)
        
        # 写入统计表
        await self._update_daily_stats(strategy_id, knowledge_point_id, feedback_event)
        
        return new_score

    def _calculate_event_score(self, event: dict) -> float:
        """将反馈事件转化为 0-1 分数"""
        score = 0.5  # 基础分

        # 学生反馈
        feedback_weights = {
            "helpful": 0.25,
            "neutral": 0.0,
            "confusing": -0.30,
            "no_response": -0.05,
        }
        score += feedback_weights.get(event.get("student_feedback"), 0.0)

        # 理解度
        if event.get("comprehension_score") is not None:
            score += (event["comprehension_score"] - 0.5) * 0.4

        # 后续正确率
        if event.get("follow_up_correct_rate") is not None:
            score += (event["follow_up_correct_rate"] - 0.5) * 0.3

        # 策略被切换（负面信号）
        if event.get("strategy_switched"):
            score -= 0.15

        # 实际耗时与预估偏差
        if event.get("actual_duration_sec") and event.get("estimated_duration_sec"):
            ratio = event["actual_duration_sec"] / event["estimated_duration_sec"]
            if ratio > 2.0:  # 实际耗时远超预估
                score -= 0.10

        return max(0.0, min(1.0, score))

    async def rebuild_stats_by_dimension(

            SELECT 
                s.applicable_stages,
                sp.dominant_learning_style,
                AVG(l.comprehension_score) as avg_comprehension,
```

```python
class ColdStartHandler:
    """冷启动处理器"""

    def get_strategy_for_new_knowledge_point(
        self,
        knowledge_point: dict,

        """新知识点的默认策略集"""
        
        # 1. 基于学科和知识类型推荐默认策略组合
        subject = knowledge_point["subject"]
        kp_type = knowledge_point.get("knowledge_type", "concept")

        DEFAULT_COMBOS = {
            "math_concept": ["visual_analogy", "step_by_step", "inductive_discovery"],
            "math_procedure": ["step_by_step", "inductive_discovery", "comparative_analysis"],
            "physics_concept": ["experimental_inquiry", "visual_analogy", "inductive_discovery"],

            "chemistry_concept": ["visual_analogy", "experimental_inquiry", "mnemonic_device"],
            "biology_concept": ["narrative_context", "comparative_analysis", "visual_analogy"],
            "language_grammar": ["inductive_discovery", "comparative_analysis", "mnemonic_device"],
            "literature_appreciation": ["narrative_context", "socratic_questioning", "graph_traversal"],
            "history_event": ["narrative_context", "graph_traversal", "comparative_analysis"],
            "geography_concept": ["visual_analogy", "graph_traversal", "comparative_analysis"],
        }

        key = f"{subject}_{kp_type}"
        default_types = DEFAULT_COMBOS.get(key, ["visual_analogy", "step_by_step", "inductive_discovery"])

        # 2. 生成骨架策略（效果评分初始 0.5）
        strategies = []
        for i, stype in enumerate(default_types):
            strategies.append({
                "strategy_id": f"ks_auto_{knowledge_point['knowledge_point_id']}_{i}",
                "strategy_type": stype,
                "effectiveness_score": 0.5,
                "is_default": i == 0,
                "status": "auto_generated",
            })

        return strategies

    def get_strategy_for_new_student(
        self,
        candidates: list[dict],
        student_profile: dict,
    ) -> list[dict]:
        """新学生的策略推荐（无历史数据时）"""
        # 使用全局效果评分 + 学段适用性
        # 不使用 student_history_score 和 similar_student_score
        scored = []
        for s in candidates:
            score = (
                s.get("effectiveness_score", 0.5) * 0.4 +
                s.get("pedagogical_fit", 0.5) * 0.3 +
                self._stage_match(s, student_profile) * 0.3
            )
            scored.append((s, score))
        
        scored.sort(key=lambda x: x[1], reverse=True)
        return [s for s, _ in scored]
```

### 10.1 错误码定义

### 10.2 降级链路

```
正常流程: 个性化推荐 → 基于历史效果 → 基于学习风格匹配 → 冷启动默认策略
                                                         ↓
```

```python
class StrategyFallbackChain:
    """策略降级链"""

    async def recommend_with_fallback(
        self,
        knowledge_point_id: str,
        student_id: str,
        context: dict,
    ) -> dict:
        try:
            # Level 1: 个性化推荐
            return await self._personalized_recommend(knowledge_point_id, student_id, context)

            try:
                # Level 2: 知识点默认策略
```

| 审计日志 | 策略创建/修改/下线操作记录审计日志 |
| 内容安全 | 策略模板中的素材引用需通过内容审核 |
| 防偏见 | 效果统计按学段/性别/地域分组监控，防止策略偏向特定群体 |
| 数据保留 | 推荐日志保留1年，效果统计保留3年，超期归档 |
