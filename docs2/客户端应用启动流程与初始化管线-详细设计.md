# 客户端应用启动流程与初始化管线 - 详细设计

## 1. 模块概述

### 1.1 功能定位

定义 PrimeTop Flutter 客户端从用户点击图标到首页完全可交互的完整启动流程，包括冷启动、热启动、预热恢复三种场景下的初始化编排、任务调度、错误处理和性能保障策略。

本模块是客户端所有功能的基础管线——启动过程决定用户体验第一印象，也决定了后续功能模块能否正确初始化。

### 1.2 性能目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 冷启动 → 首屏可交互 | ≤ 2000ms | 从进程创建到首页 FMP |
| 热启动 → 首屏可交互 | ≤ 500ms | 从 Activity/ViewController 恢复 |
| Splash 展示时间 | ≤ 1500ms | 品牌展示 + 初始化并行 |
| 关键服务就绪 | ≤ 3000ms | 用户数据、教材、Token 全部就绪 |
| 非关键服务就绪 | ≤ 5000ms | 推送注册、埋点、预加载完成 |

### 1.3 与其他模块的关系

| 关联模块 | 启动阶段依赖 |
|----------|-------------|
| 用户账号体系 | 启动时恢复登录态、刷新 Token |
| 客户端架构与前端框架 | Riverpod Provider 初始化、路由配置 |
| 客户端本地持久层 | 启动时读取本地缓存数据 |
| 客户端路由与深链接系统 | 冷启动时解析深链接跳转 |
| 灰度发布与特性开关 | 启动时拉取开关配置 |
| 配置中心与动态配置管理 | 启动时同步远程配置 |
| 数据埋点与关键指标系统 | 启动时初始化埋点 SDK |
| 消息与推送服务 | 启动时注册推送 Token |
| 客户端网络请求治理 | 启动时初始化网络层 |
| 分龄 UI 适配 | 启动时加载学段 UI 策略 |
| 客户端版本管理与升级 | 启动时检查版本更新 |

### 1.4 设计原则

1. **分层初始化**：关键路径优先，非关键路径异步延迟
2. **优雅降级**：任何初始化步骤失败不阻塞主流程
3. **可观测**：每个阶段打点计时，上报启动漏斗
4. **幂等安全**：重复初始化不产生副作用
5. **可配置**：初始化阶段可通过远程配置调整

### 3.4 Phase 3: 关键服务初始化（T+600 ~ T+1500ms）

**职责**：初始化用户身份、网络层、路由等关键服务。与 Splash 页并行展示。

```dart
/// 关键服务编排器
class CriticalServicesOrchestrator {
  final List<CriticalService> _services;
  
  CriticalServicesOrchestrator() : _services = [
    TokenService(),          // Token 恢复与刷新
    UserProfileService(),    // 用户档案加载
    NetworkService(),        // Dio 网络层初始化
    AppConfigService(),      // 远程配置拉取
    FeatureFlagService(),    // 特性开关
    ThemeService(),          // 主题与学段UI策略
  ];
  
  /// 执行关键服务初始化
  /// 返回 (成功列表, 失败列表)
  Future<InitResult> initialize() async {
    StartupTimeline.markBegin("critical_services");
    
    // 构建依赖图
    final dependencyGraph = _buildDependencyGraph();
    final results = await _executeWithDependencies(dependencyGraph);
    
    StartupTimeline.markEnd("critical_services");
    return results;
  }
  
  /// 按依赖拓扑排序并行执行
  Future<InitResult> _executeWithDependencies(
    Map<Type, List<Type>> graph,
  ) async {
    final completed = <Type, dynamic>{};
    final failed = <Type, ServiceInitError>{};
    
    // 拓扑层级执行
    for (final level in _topologicalLevels(graph)) {
      await Future.wait(
        level.map((serviceType) async {
          final service = _services.firstWhere((s) => s.runtimeType == serviceType);
          try {
            // 注入已完成的依赖
            final deps = graph[serviceType]!
                .map((t) => completed[t])
                .whereType<Dependency>()
                .toList();
            
            final result = await service.initialize(deps)
                .timeout(service.timeout);
            completed[serviceType] = result;
          } catch (e) {
            failed[serviceType] = ServiceInitError(
              service: serviceType,
              error: e,
              fallback: service.fallbackStrategy,
            );
            // 执行降级
            completed[serviceType] = service.fallback();
          }
        }),
      );
    }
    
    return InitResult(completed: completed, failed: failed);
  }
}
```

#### 3.4.1 Token 服务初始化

```dart
class TokenService extends CriticalService {
  @override
  Duration get timeout => const Duration(seconds: 2);
  
  @override
  Future<TokenData> initialize(List<Dependency> deps) async {
    StartupTimeline.markBegin("token_service");
    
    final storage = SecureStorage.instance;
    final storedRefreshToken = await storage.get('refresh_token');
    final storedAccessToken = await storage.get('access_token');
    final tokenExpiry = await storage.get('token_expiry');
    
    if (storedRefreshToken == null) {
      // 无 Token → 游客模式
      StartupTimeline.markEnd("token_service', status: 'no_token');
      return TokenData.guest();
    }
    
    // 检查 AccessToken 是否仍有效（留 5 分钟缓冲）
    final expiry = DateTime.tryParse(tokenExpiry ?? '');
    if (expiry != null && expiry.isAfter(DateTime.now().add(Duration(minutes: 5)))) {
      // AccessToken 有效，直接使用
      StartupTimeline.markEnd("token_service', status: 'cached');
      return TokenData(
        accessToken: storedAccessToken!,
        refreshToken: storedRefreshToken,
        expiry: expiry,
      );
    }
    
    // AccessToken 过期，用 RefreshToken 刷新
    try {
      final newToken = await _refreshToken(storedRefreshToken);
      await _persistToken(newToken);
      StartupTimeline.markEnd("token_service', status: 'refreshed');
      return newToken;
    } catch (e) {
      // RefreshToken 也过期 → 清除本地凭证
      await _clearTokens();
      StartupTimeline.markEnd("token_service', status: 'refresh_failed');
      return TokenData.guest();
    }
  }
  
  @override
  TokenData fallback() => TokenData.guest();
}
```

```dart
class AppInitialization extends _$AppInitialization {
  @override
  AppInitState build() {
    _runInitialization();
    return AppInitState.loading;
  }
  
  Future<void> _runInitialization() async {
    try {
      // Phase 3: 关键服务
      final result = await CriticalServicesOrchestrator().initialize();

      state = AppInitState.ready;

      StartupTimeline.report();
    } catch (e) {
      state = AppInitState.error;
    }
  }
```

### 3.6 Phase 5: 重要服务（T+2000 ~ T+3000ms）

**首屏渲染完成后，后台继续初始化重要但不阻塞 UI 的服务。**

```dart
class DeferredTasksScheduler {
  /// 重要服务：影响核心功能但用户尚未操作到
  Future<void> startImportantTasks(InitResult criticalResult) async {
    final futures = <Future<void>>[];
    
    // 1. 推送 Token 注册
    futures.add(_registerPushToken(criticalResult));
    
    // 2. 埋点 SDK 初始化
    futures.add(_initAnalytics(criticalResult));
    
    // 3. 远程配置全量同步（启动时只拉了关键配置）
    futures.add(_syncFullConfig(criticalResult));
    
    // 4. 用户学段 UI 策略加载
    futures.add(_loadAgeSpecificUI(criticalResult));
    
    // 5. 版本更新检查
    futures.add(_checkAppUpdate());
    
    await Future.wait(futures.map((f) => f.catchError((e) {
      AppLogger.warn('Deferred task failed: $e');
    })));
  }
}
```

### 4.2 状态定义

```dart
enum AppLifecyclePhase {
  splash,       // 启动画面展示中
  ready,        // 关键服务就绪，首页已渲染
  running,      // 正常运行态
  background,   // 应用进入后台
  foreground,   // 从后台恢复
  error,        // 启动失败
  terminated,   // 应用终止
}

@riverpod
class AppLifecycle extends _$AppLifecycle {
  @override
  AppLifecyclePhase build() {
    // 监听 WidgetsBinding 生命周期
    final binding = WidgetsBinding.instance;
    binding.addObserver(_AppLifecycleObserver(ref));
    return AppLifecyclePhase.splash;
  }
  
  void transitionTo(AppLifecyclePhase next) {
    final prev = state;
    if (!_isValidTransition(prev, next)) {
      AppLogger.warn('Invalid lifecycle transition: $prev → $next');
      return;
    }
    AppLogger.info('Lifecycle: $prev → $next');
    state = next;
  }
  
  bool _isValidTransition(AppLifecyclePhase from, AppLifecyclePhase to) {
    return const {
      AppLifecyclePhase.splash:      {AppLifecyclePhase.ready, AppLifecyclePhase.error},
      AppLifecyclePhase.ready:       {AppLifecyclePhase.running},
      AppLifecyclePhase.running:     {AppLifecyclePhase.background},
      AppLifecyclePhase.background:  {AppLifecyclePhase.foreground, AppLifecyclePhase.terminated},
      AppLifecyclePhase.foreground:  {AppLifecyclePhase.running, AppLifecyclePhase.background},
      AppLifecyclePhase.error:       {AppLifecyclePhase.splash, AppLifecyclePhase.terminated},
      AppLifecyclePhase.terminated:  {}, // 终态
    }[from]?.contains(to) ?? false;
  }
}
```

## 5. 后台恢复策略

### 5.1 恢复检查清单

当应用从后台恢复到前台时，根据后台时长执行不同策略：

```dart
class BackgroundRecoveryManager {
  static const _quickThreshold = Duration(minutes: 5);
  static const _fullThreshold = Duration(minutes: 30);
  
  DateTime? _backgroundTime;
  
  void onBackground() {
    _backgroundTime = DateTime.now();
  }
  
  Future<void> onForeground() async {
    if (_backgroundTime == null) return;
    
    final elapsed = DateTime.now().difference(_backgroundTime!);
    
    if (elapsed < _quickThreshold) {
      // 短时间：仅刷新 Token
      await _quickRecovery();
    } else if (elapsed < _fullThreshold) {
      // 中等时间：刷新数据
      await _standardRecovery();
    } else {
      // 长时间：全量验证
      await _fullRecovery();
    }
    
    _backgroundTime = null;
  }
  
  Future<void> _quickRecovery() async {
    // 1. 检查 Token 有效性
    await TokenService.instance.validateOrRefresh();
    // 2. 检查是否有未读消息
    await MessageService.instance.syncUnreadCount();
  }
  
  Future<void> _standardRecovery() async {
    await _quickRecovery();
    // 3. 刷新首页数据
    // 4. 同步远程配置
    await Future.wait([
      AppConfigService.instance.sync(),
      HomeDataProvider.instance.invalidate(),
    ]);
  }
  
  Future<void> _fullRecovery() async {
    await _standardRecovery();
    // 5. 全量用户数据验证
    // 6. 特性开关同步
    // 7. 版本更新检查
    await Future.wait([
      UserProfileService.instance.refresh(),
      FeatureFlagService.instance.sync(),
      VersionCheckService.instance.check(),
    ]);
  }
}
```

### 7.1 启动时间线打点

```dart
/// 启动时间线工具
class StartupTimeline {
  static final Map<String, _TimelineEvent> _events = {};
  static DateTime? _appStart;
  
  /// 标记应用启动起始
  static void markAppStart() {
    _appStart = DateTime.now();
    _events['app_start'] = _TimelineEvent(
      name: 'app_start',
      start: _appStart!,
    );
  }
  
  /// 标记阶段开始
  static void markBegin(String name) {
    _events[name] = _TimelineEvent(
      name: name,
      start: DateTime.now(),
    );
  }
  
  /// 标记阶段结束
  static void markEnd(String name, {String? status}) {
    final event = _events[name];
    if (event != null) {
      event.end = DateTime.now();
      event.status = status ?? 'success';
    }
  }
  
  /// 生成启动报告并上报
  static StartupReport report() {
    final now = DateTime.now();
    final totalMs = _appStart != null 
        ? now.difference(_appStart!).inMilliseconds 
        : 0;
    
    final phases = _events.map((name, event) {
      final duration = event.end != null
          ? event.end!.difference(event.start).inMilliseconds
          : null;
      return MapEntry(name, PhaseReport(
        name: name,
        startMs: _appStart != null
            ? event.start.difference(_appStart!).inMilliseconds
            : 0,
        durationMs: duration,
        status: event.status ?? 'unknown',
      ));
    });
    
    final report = StartupReport(
      totalMs: totalMs,
      phases: phases,
      timestamp: now,
    );
    
    // 上报到埋点系统
    AnalyticsService.reportStartup(report);
    
    return report;
  }
}

class _TimelineEvent {
  final String name;
  final DateTime start;
  DateTime? end;
  String? status;

}
```

### 8.2 降级决策器

```dart
class StartupDegradationManager {
  final Map<Type, DegradationLevel> _degradationLevels = {};
  
  /// 根据初始化结果决定降级策略
  StartupConfig buildConfig(InitResult result) {
    final config = StartupConfig.defaultConfig();
    
    for (final failure in result.failed.entries) {
      final level = _decideDegradation(failure.key, failure.value);
      _degradationLevels[failure.key] = level;
      
      switch (level) {
        case DegradationLevel.none:
          break;
        case DegradationLevel.cacheOnly:
          config.useCacheFor(failure.key);
        case DegradationLevel.defaultValues:
          config.useDefaultsFor(failure.key);
        case DegradationLevel.limited:
          config.enableLimitedMode(failure.key);
        case DegradationLevel.disabled:
          config.disable(failure.key);
      }
    }
    
    // 如果关键服务全部失败，进入安全模式
    if (_allCriticalServicesFailed(result)) {
      config.enableSafeMode();
    }
    
    return config;
  }
  
  DegradationLevel _decideDegradation(Type service, ServiceInitError error) {
    // Token 失败 → 游客模式（limited）
    if (service == TokenService) {
      return DegradationLevel.limited;
    }
    // 配置服务失败 → 默认配置（defaultValues）
    if (service == AppConfigService || service == FeatureFlagService) {
      return DegradationLevel.defaultValues;
    }
    // 用户数据失败 → 缓存优先（cacheOnly）
    if (service == UserProfileService) {
      return DegradationLevel.cacheOnly;
    }
    return DegradationLevel.defaultValues;
  }
}
```

```kotlin
// Android: EngineWarmupService.kt
class EngineWarmupService : JobIntentService() {
    companion object {
        fun scheduleWarmup(context: Context) {
            // 场景 1: 收到高优先级推送后 30s 预热
            // 场景 2: 用户设置的学习提醒时间前 2 分钟预热
            // 场景 3: 设备解锁后 10s 预热（需权限）

                context,
                EngineWarmupService::class.java,
                JOB_ID,
                Intent("ACTION_ENGINE_WARMUP"),
            )
        }
    }
    
    override fun onHandleWork(intent: Intent) {
        if (!FlutterEngineCache.getInstance().contains(ENGINE_ID)) {
            val engine = FlutterEngine(this)
            
            // 预执行 Dart 初始化
            engine.dartExecutor.executeDartEntrypoint(
                DartExecutor.DartEntrypoint.createDefault()
            )
            
            FlutterEngineCache.getInstance().put(ENGINE_ID, engine)
            StartupTimeline.markBegin("engine_warmup_completed")
        }
    }
}
```

### 16.2 启动配置项
