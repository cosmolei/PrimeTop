# 服务端-运营弹窗规则引擎与个性化消息卡片调度服务-详细设计

## 1. 模块概述

### 1.1 模块定位

运营弹窗规则引擎与个性化消息卡片调度服务（以下简称"弹窗调度服务"）负责管理 APP 内所有运营弹窗、公告卡片、活动浮窗的**服务端规则判定、投放调度和效果统计**。

该服务是客户端"全局运营弹窗与消息浮窗调度系统"的服务端对应模块，核心职责包括：

1. **弹窗活动管理**：运营人员在后台创建、编辑、上下架弹窗活动
2. **规则匹配引擎**：根据用户画像、标签、行为实时判定是否命中弹窗条件
3. **频次与优先级控制**：防止弹窗泛滥，控制单用户弹窗密度
4. **投放策略**：支持全量、分群、A/B 实验、渐进式灰度投放
5. **效果追踪**：曝光、点击、关闭、转化全链路数据采集与统计
6. **消息卡片编排**：首页、个人中心等位置的消息卡片内容调度

### 1.3 弹窗与卡片类型

| 类型 | 说明 | 展示位置 | 优先级权重 |
|------|------|----------|-----------|
| **全屏弹窗** (fullscreen) | 开屏弹窗、重要公告、版本更新强制弹窗 | App 启动后 | 100 |
| **底部弹窗** (bottom_sheet) | 活动、优惠、引导 | 页面内触发 | 50 |
| **对话框弹窗** (dialog) | 确认类、提醒类 | 页面内触发 | 60 |
| **浮窗** (float) | 悬浮小窗，可拖拽 | 全局覆盖 | 30 |
| **消息卡片** (card) | 首页卡片、个人中心卡片 | 指定页面区域 | 20 |
| **角标提示** (badge) | 红点、数字角标 | Tab/图标上 | 10 |
| **Toast** (toast) | 轻量提示 | 页面底部 | 5 |

### 1.4 设计原则

1. **用户优先**：保护学习体验，严格控制弹窗频率和打扰度
2. **规则驱动**：所有弹窗投放完全由规则引擎决定，无硬编码
3. **数据闭环**：从创建→投放→曝光→互动→转化→统计完整闭环
4. **安全合规**：未成年人弹窗有额外限制（无付费诱导、无外部链接）
5. **降级友好**：服务不可用时客户端有兜底策略

### 3.2 规则匹配引擎详细流程

```python
async def match_campaigns(
    user_id: int,
    scene: str,
    context: PopupRequestContext,
) -> List[MatchedCampaign]:
    """
    规则匹配主入口

    Args:
        user_id: 用户ID
        scene: 触发场景
        context: 请求上下文(设备信息/页面路径/会话状态等)
    """
    # Step 1: 获取场景下所有活跃活动
    campaigns = await get_active_campaigns(scene)
    if not campaigns:
        return []

    # Step 2: 批量加载用户数据（减少 N+1 查询）
    user_profile = await load_user_profile(user_id)
    user_tags = await load_user_tags(user_id)
    user_groups = await load_user_groups(user_id)
    user_behavior = await load_user_behavior_stats(user_id)

    # Step 3: 并行执行过滤
    matched = []
    for campaign in campaigns:
        result = await evaluate_campaign(
            campaign=campaign,
            user_id=user_id,
            user_profile=user_profile,
            user_tags=user_tags,
            user_groups=user_groups,
            user_behavior=user_behavior,
            context=context,
        )
        if result.passed:
            matched.append(result)

    # Step 4: 冲突解决
    resolved = resolve_conflicts(matched, scene)

    # Step 5: A/B 分流
    for item in resolved:
        if item.campaign.ab_experiment_id:
            group = await ab_assign_group(
                experiment_id=item.campaign.ab_experiment_id,
                user_id=user_id,
            )
            item.experiment_group = group

    return resolved


async def evaluate_campaign(
    campaign: PopupCampaign,
    user_id: int,
    user_profile: UserProfile,
    user_tags: List[str],
    user_groups: List[str],
    user_behavior: UserBehaviorStats,
    context: PopupRequestContext,
) -> CampaignMatchResult:
    """评估单个活动是否命中"""

    # 1. 未成年人保护检查
    if campaign.minor_restricted and user_profile.age < campaign.minor_age_threshold:
        return CampaignMatchResult(passed=False, reason="minor_restricted")

    # 2. 目标人群规则匹配
    if campaign.target_rule:
        rule_context = build_rule_context(
            user_profile, user_tags, user_groups, user_behavior, context
        )
        if not evaluate_rule_tree(campaign.target_rule, rule_context):
            return CampaignMatchResult(passed=False, reason="target_rule_mismatch")

    # 3. 频次控制检查
    freq_check = await check_frequency(
        user_id=user_id,
        campaign_id=campaign.id,
        freq_config=campaign.freq_config,
        scene=context.scene,
    )
    if not freq_check.passed:
        return CampaignMatchResult(passed=False, reason=f"freq:{freq_check.detail}")

    # 4. 配额检查
    quota_check = await check_quota(campaign)
    if not quota_check.passed:
        return CampaignMatchResult(passed=False, reason="quota_exceeded")

    # 5. 前置条件检查
    if campaign.trigger_config and campaign.trigger_config.preconditions:
        precond_check = evaluate_preconditions(
            campaign.trigger_config.preconditions,
            user_behavior=user_behavior,
            user_profile=user_profile,
        )
        if not precond_check:
            return CampaignMatchResult(passed=False, reason="precondition_failed")

    return CampaignMatchResult(passed=True, campaign=campaign)
```

### 3.3 规则树求值器

```python
def evaluate_rule_tree(
    rule: TargetRule,
    context: Dict[str, Any],
) -> bool:
    """
    递归求值规则树

    示例规则树:
    {
        "operator": "AND",
        "conditions": [
            {
                "dimension": "stage",
                "operator": "in",
                "value": ["junior", "senior"]
            },
            {
                "operator": "OR",
                "conditions": [
                    {"dimension": "membership_type", "operator": "eq", "value": "free"},
                    {"dimension": "membership_expired_days", "operator": "gt", "value": 7}
                ]
            }
        ]
    }
    """
    results = []
    for condition in rule.conditions:
        if isinstance(condition, TargetRule):
            # 嵌套子规则，递归求值
            results.append(evaluate_rule_tree(condition, context))
        else:
            # 叶子条件
            results.append(evaluate_condition(condition, context))

    if rule.operator == "AND":
        return all(results)
    elif rule.operator == "OR":
        return any(results)
    else:
        raise ValueError(f"Unknown operator: {rule.operator}")


def evaluate_condition(
    cond: TargetCondition,
    context: Dict[str, Any],
) -> bool:
    """评估单个条件"""
    field_value = context.get(cond.dimension)

    if field_value is None:
        # 字段不存在，默认不匹配（除非是空值判断）
        return cond.operator in ("is_null", "not_exists")

    ops = {
        "eq": lambda a, b: a == b,
        "neq": lambda a, b: a != b,
        "gt": lambda a, b: a > b,
        "gte": lambda a, b: a >= b,
        "lt": lambda a, b: a < b,
        "lte": lambda a, b: a <= b,
        "in": lambda a, b: a in b,
        "not_in": lambda a, b: a not in b,
        "contains": lambda a, b: b in a,
        "not_contains": lambda a, b: b not in a,
        "is_null": lambda a, b: a is None,
        "is_not_null": lambda a, b: a is not None,
        "regex": lambda a, b: bool(re.match(b, str(a))),
    }

    op_func = ops.get(cond.operator)
    if not op_func:
        raise ValueError(f"Unsupported operator: {cond.operator}")

    try:
        return op_func(field_value, cond.value)
    except (TypeError, ValueError):
        return False
```

### 3.4 频次控制检查

```python
async def check_frequency(
    user_id: int,
    campaign_id: int,
    freq_config: FreqConfig,
    scene: str,
) -> FreqCheckResult:
    """频次控制检查 - Redis 原子操作"""

    now = datetime.now()
    today_key = now.strftime("%Y-%m-%d")

    # 1. 终身上限
    if freq_config.per_user_max_lifetime is not None:
        lifetime_exceeded = await redis.sismember(
            f"popup:user:{user_id}:lifetime_exceeded",
            str(campaign_id)
        )
        if lifetime_exceeded:
            return FreqCheckResult(passed=False, detail="lifetime_exceeded")

    # 2. 每日上限
    if freq_config.per_user_max_daily is not None:
        daily_key = f"popup:user:{user_id}:daily:{today_key}"
        daily_count = await redis.hget(daily_key, str(campaign_id))
        if daily_count and int(daily_count) >= freq_config.per_user_max_daily:
            return FreqCheckResult(passed=False, detail="daily_exceeded")

    # 3. 每周上限
    if freq_config.per_user_max_weekly is not None:
        week_key = f"popup:user:{user_id}:weekly:{now.isocalendar()[1]}"
        weekly_count = await redis.hget(week_key, str(campaign_id))
        if weekly_count and int(weekly_count) >= freq_config.per_user_max_weekly:
            return FreqCheckResult(passed=False, detail="weekly_exceeded")

    # 4. 最小间隔
    if freq_config.per_user_min_interval_minutes is not None:
        last_show_key = f"popup:user:{user_id}:last_show:{campaign_id}"
        last_show = await redis.get(last_show_key)
        if last_show:
            elapsed = (now - datetime.fromtimestamp(float(last_show))).total_seconds() / 60
            if elapsed < freq_config.per_user_min_interval_minutes:
                return FreqCheckResult(passed=False, detail="interval_too_short")

    # 5. 冷却期
    # 先查最近一次曝光行为类型
    last_action = await get_last_popup_action(user_id, campaign_id)
    if last_action:
        cooldown = (
            freq_config.cooldown_after_click_minutes
            if last_action == "clicked"
            else freq_config.cooldown_after_close_minutes
        )
        if last_action.elapsed_minutes < cooldown:
            return FreqCheckResult(passed=False, detail="in_cooldown")

    # 6. 同场景每日弹窗上限
    if freq_config.scene_max_daily is not None:
        scene_key = f"popup:scene:{scene}:daily:{today_key}"
        scene_count = await redis.get(scene_key)
        if scene_count and int(scene_count) >= freq_config.scene_max_daily:
            return FreqCheckResult(passed=False, detail="scene_daily_exceeded")

    # 7. 全局弹窗密度
    global_lock_key = f"popup:user:{user_id}:global_lock"
    global_lock = await redis.get(global_lock_key)
    if global_lock:
        return FreqCheckResult(passed=False, detail="global_interval_lock")

    return FreqCheckResult(passed=True)
```

### 3.5 冲突解决策略

```python
def resolve_conflicts(
    matched: List[MatchedCampaign],
    scene: str,
) -> List[MatchedCampaign]:
    """
    当同场景有多个活动命中时，根据冲突策略选择最终展示列表

    限制: 同一场景最多返回 2 个弹窗(防止弹窗堆叠)
    """
    MAX_PER_SCENE = 2

    if len(matched) <= MAX_PER_SCENE:
        return sorted(matched, key=lambda x: x.campaign.priority, reverse=True)

    # 按优先级排序
    sorted_items = sorted(matched, key=lambda x: x.campaign.priority, reverse=True)

    # 检查同类型活动的冲突策略
    # 取第一个活动（最高优先级）的冲突策略
    primary = sorted_items[0]
    policy = primary.campaign.conflict_policy

    if policy == "priority":
        # 纯优先级：取前 N 个
        return sorted_items[:MAX_PER_SCENE]

    elif policy == "random":
        # 随机：从所有命中的中随机选取
        import random
        return random.sample(sorted_items, min(MAX_PER_SCENE, len(sorted_items)))

    elif policy == "sequential":
        # 轮流：按 campaign_id 的 hash 轮转
        # 确保同一用户不同次请求看到不同弹窗
        day_offset = datetime.now().timetuple().tm_yday
        start_idx = day_offset % len(sorted_items)
        result = []
        for i in range(MAX_PER_SCENE):
            idx = (start_idx + i) % len(sorted_items)
            result.append(sorted_items[idx])
        return result

    return sorted_items[:MAX_PER_SCENE]
```

```python
# service/query_service.py
class PopupQueryService:
    """弹窗查询服务"""

    SESSION_POPUP_MAX = 2
    GLOBAL_INTERVAL_MINUTES = 30

    async def query(self, context: PopupRequestContext) -> PopupQueryData:
        """查询弹窗和卡片"""
        # 1. 并行查询弹窗和卡片
        popups_task = self._query_popups(context)
        cards_task = self._query_cards(context)
        popups, cards = await asyncio.gather(popups_task, cards_task)

        return PopupQueryData(
            popups=popups,
            cards=cards,
            session_config=SessionConfig(
                max_popups_this_session=self.SESSION_POPUP_MAX,
                global_interval_minutes=self.GLOBAL_INTERVAL_MINUTES,
            ),
        )

    async def _query_popups(
        self, context: PopupRequestContext
    ) -> List[PopupItem]:
        """查询匹配的弹窗"""
        # 获取缓存中的活跃活动列表
        campaigns = await self._get_active_campaigns(context.scene)
        if not campaigns:
            return []

        # 批量加载用户上下文
        user_ctx = await self._load_user_context(context.user_id)

        # 规则匹配
        matched = await match_campaigns(
            user_id=context.user_id,
            scene=context.scene,
            context=context,
        )

        if not matched:
            return []

        # 预记录曝光 + 更新频次
        results = []
        for m in matched:
            # 原子配额扣减
            quota_ok = await self._consume_quota(m.campaign)
            if not quota_ok:
                continue

            # 预写入曝光记录
            exposure_id = await self._pre_record_exposure(m, context)

            # 更新频次计数
            await self._increment_frequency(context.user_id, m.campaign.id, context.scene)

            # 设置全局锁
            await self._set_global_lock(
                context.user_id,
                self.GLOBAL_INTERVAL_MINUTES,
            )

            results.append(self._build_popup_item(m, exposure_id, context))

        return results

    async def _get_active_campaigns(self, scene: str) -> List[PopupCampaign]:
        """获取活跃活动列表（带缓存）"""
        cache_key = f"popup:active_campaigns:{scene}"

        # L1: Redis 缓存
        cached = await redis.get(cache_key)
        if cached:
            return [PopupCampaign(**c) for c in json.loads(cached)]

        # L2: 数据库查询
        now = datetime.now()
        campaigns = await db.query(
            PopupCampaign
        ).filter(
            PopupCampaign.status == 3,  # 已上架
            PopupCampaign.trigger_scene == scene,
            PopupCampaign.start_time <= now,
            PopupCampaign.end_time >= now,
        ).all()

        # 写入缓存，30秒过期（保证上下架及时生效）
        await redis.setex(
            cache_key,
            30,
            json.dumps([c.to_dict() for c in campaigns]),
        )

        return campaigns

    async def _load_user_context(self, user_id: int) -> UserPopupContext:
        """批量加载用户上下文"""
        # 并行查询用户画像、标签、行为统计
        profile_task = get_user_profile(user_id)
        tags_task = get_user_tags(user_id)
        groups_task = get_user_groups(user_id)
        behavior_task = get_user_behavior_stats(user_id)

        profile, tags, groups, behavior = await asyncio.gather(
            profile_task, tags_task, groups_task, behavior_task
        )

        return UserPopupContext(
            profile=profile,
            tags=tags,
            groups=groups,
            behavior=behavior,
        )
```

```python
class PopupFeedbackService:
    """弹窗反馈处理服务"""

    async def process_feedback(
        self,
        user_id: int,
        feedback: PopupFeedbackRequest,
    ) -> None:
        """处理弹窗反馈"""
        for action in feedback.actions:
            # 更新曝光记录
            exposure = await self._get_exposure(
                request_id=feedback.request_id,
                campaign_id=feedback.campaign_id,
                user_id=user_id,
            )
            if not exposure:
                log.warning(
                    "Exposure not found",
                    extra={"request_id": feedback.request_id, "user_id": user_id}
                )
                continue

            if action.action == "exposed":
                exposure.display_at = action.timestamp
                # 设置关闭按钮延迟展示的定时器
                if exposure.close_delay_seconds > 0:
                    await self._schedule_close_button_delay(
                        user_id, feedback.campaign_id, exposure.close_delay_seconds
                    )

            elif action.action == "clicked":
                exposure.action = "clicked"
                exposure.action_button = action.action_button
                exposure.action_value = action.action_value
                exposure.close_at = action.timestamp

                # 如果点击了转化按钮，记录转化
                if self._is_conversion_button(action.action_button, exposure):
                    await self._record_conversion(user_id, feedback.campaign_id)

            elif action.action == "closed":
                exposure.action = "closed"
                exposure.close_at = action.timestamp

            elif action.action == "dismissed":
                exposure.action = "dismissed"
                exposure.close_at = action.timestamp

            # 计算展示时长
            if exposure.close_at and exposure.display_at:
                exposure.display_duration_ms = int(
                    (exposure.close_at - exposure.display_at).total_seconds() * 1000
                )

            await save_exposure(exposure)

        # 异步发送事件（供其他模块消费）
        await event_bus.emit(PopupActionEvent(
            user_id=user_id,
            campaign_id=feedback.campaign_id,
            actions=[a.action for a in feedback.actions],
```

```python
class MinorProtection:
    """未成年人弹窗保护策略"""

    # 未成年人完全禁止的弹窗类型
    BLOCKED_TYPES_FOR_MINOR = {"promotion"}

    # 未成年人弹窗额外频次限制
    MINOR_FREQ_OVERRIDE = {
        "per_user_max_daily": 1,          # 每日最多1次
        "global_max_per_session": 1,      # 每次启动最多1个
        "global_min_interval_minutes": 120, # 全局最小间隔2小时
    }

    # 未成年人弹窗内容限制
    CONTENT_RULES = {
        "no_payment_inducing": True,    # 禁止付费诱导
        "no_external_link": True,       # 禁止外部链接
        "no_social_share": True,        # 禁止社交分享引导
        "no_limited_time_pressure": True, # 禁止限时压力话术
    }

    @classmethod
    def check_minor_protection(
        cls,
        campaign: PopupCampaign,
        user_profile: UserProfile,
    ) -> MinorCheckResult:
        """检查未成年人保护规则"""
        if not user_profile.is_minor:
            return MinorCheckResult(passed=True)

        # 1. 活动级限制检查
        if campaign.minor_restricted:
            return MinorCheckResult(
                passed=False,
                reason="campaign_minor_restricted",
            )

        # 2. 类型限制
        if campaign.type in cls.BLOCKED_TYPES_FOR_MINOR:
            return MinorCheckResult(
                passed=False,
                reason="type_blocked_for_minor",
            )

        # 3. 内容安全检查（扫描按钮和文案）
        if campaign.body:
            if cls._has_payment_inducing(campaign):
                return MinorCheckResult(passed=False, reason="payment_inducing")
            if cls._has_external_link(campaign):
                return MinorCheckResult(passed=False, reason="external_link")
            if cls._has_limited_time_pressure(campaign):
                return MinorCheckResult(passed=False, reason="limited_time_pressure")

        return MinorCheckResult(passed=True)

    @classmethod
    def get_minor_freq_override(cls) -> dict:
        """获取未成年人频次覆盖配置"""
        return cls.MINOR_FREQ_OVERRIDE.copy()

    @staticmethod
    def _has_payment_inducing(campaign: PopupCampaign) -> bool:
        """检测付费诱导内容"""
        payment_keywords = ["立即购买", "限时优惠", "立省", "最低价", "抢购"]
        texts = [campaign.title, campaign.subtitle or ""]
        if campaign.body and campaign.body.buttons:
            texts.extend([b.text for b in campaign.body.buttons])
        combined = " ".join(texts)
        return any(kw in combined for kw in payment_keywords)

    @staticmethod
    def _has_external_link(campaign: PopupCampaign) -> bool:
        """检测外部链接"""
        if campaign.body and campaign.body.buttons:
            for btn in campaign.body.buttons:
                if btn.action_type == "external_url":
                    return True
        return False

    @staticmethod
    def _has_limited_time_pressure(campaign: PopupCampaign) -> bool:
        """检测限时压力话术"""
        pressure_keywords = ["仅剩", "最后", "倒计时", "马上结束", "即将涨价"]
        texts = [campaign.title, campaign.subtitle or ""]
        combined = " ".join(texts)
        return any(kw in combined for kw in pressure_keywords)
```

```
│              降级层级                         │

├─────────────────────────────────────────────┤

│   客户端兜底：返回空弹窗列表                   │
```

```python
class PopupDegradation:
    """弹窗服务降级管理"""

    @classmethod
    async def query_with_degradation(cls, context: PopupRequestContext):
        """带降级的弹窗查询"""
        try:
            # L0: 尝试正常服务
            return await cls._normal_query(context)
        except RedisError:
            log.warning("Redis unavailable, degrading to L1")
            try:
                return await cls._degraded_query_l1(context)
            except DatabaseError:
                log.warning("DB unavailable, degrading to L2")
                return await cls._degraded_query_l2(context)
        except DatabaseError:
            log.warning("DB unavailable, degrading to L2")
            return await cls._degraded_query_l2(context)
        except Exception as e:
            log.error(f"Popup service error: {e}", exc_info=True)
            return PopupQueryData(popups=[], cards=[])  # L3

    @classmethod
    async def _degraded_query_l1(cls, context):
        """L1: Redis 不可用，跳过频次检查"""
        campaigns = await db_get_active_campaigns(context.scene)
        # 仅做基础画像匹配
        matched = [c for c in campaigns if not c.target_rule]
        # 默认频次限制
        if len(matched) > 2:
            matched = matched[:2]
        return build_response(matched, [])

    @classmethod
    async def _degraded_query_l2(cls, context):
        """L2: 数据库也不可用，用缓存"""
        cached_campaigns = await redis.get(
            f"popup:fallback_cache:{context.scene}"
        )
        if cached_campaigns:
            campaigns = json.loads(cached_campaigns)
            # 仅返回无 target_rule 的活动
            return build_response(
                [c for c in campaigns if not c.get("target_rule")][:2],
                []
            )
        return PopupQueryData(popups=[], cards=[])
```

| 兜底活动列表 | Redis | 10min | 活动变更时更新 |

### 10.2 查询优化

1. **活动预筛选**：查询前先用 `trigger_scene` + `status` + 时间范围过滤，减少规则匹配数量
2. **用户数据批量加载**：并行加载画像、标签、行为数据，避免串行 N+1
3. **规则短路求值**：AND 规则中任一条件不满足立即返回 False
4. **轻量规则前置**：将设备类型、APP版本等轻量条件放前面，重量条件（标签匹配）放后面
5. **活动列表本地缓存**：单次请求内缓存活动列表，避免重复查询

## 14. 数据归档

曝光日志数据量较大，需要定期归档：

```sql
-- 日志表按月分区
ALTER TABLE popup_exposure_log
PARTITION BY RANGE (TO_DAYS(created_at)) (
    PARTITION p202605 VALUES LESS THAN (TO_DAYS('2026-06-01')),
    PARTITION p202606 VALUES LESS THAN (TO_DAYS('2026-07-01')),
    -- ...
    PARTITION pmax VALUES LESS THAN MAXVALUE
);

-- 归档策略:
-- 1. 超过 90 天的日志迁移至 ClickHouse (供长期分析)
-- 2. 超过 180 天的分区从 MySQL 删除
-- 3. 统计聚合数据永久保留
```
