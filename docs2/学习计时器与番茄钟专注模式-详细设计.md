# 学习计时器与番茄钟专注模式 - 详细设计

## 1. 模块概述

### 1.1 功能定位

为全学段学生提供结构化的学习计时与专注管理能力，结合番茄工作法（Pomodoro Technique）理念，帮助学生建立高效学习节奏，并通过游戏化激励保持专注动力。系统记录每次学习会话的时长、专注度、中断情况等数据，为学情分析和学习规划提供基础数据支撑。

### 1.2 目标用户与场景

| 用户 | 场景 | 核心诉求 |
|------|------|----------|
| 小学生（6-12岁） | 放学后作业时段 | 15-25分钟短时专注，频繁休息，趣味激励 |
| 初中生（12-15岁） | 晚自习/周末学习 | 25-40分钟标准番茄钟，错题复习计时 |
| 高中生（15-18岁） | 高强度备考冲刺 | 45-60分钟深度专注，自定义节奏 |
| 家长 | 监督孩子学习 | 查看孩子专注数据，设置最低学习时长 |

### 1.3 与其他模块的关系

```

│  学习记录与    │ │  学情分析     │  │  学习规划     │ │  护眼模式  │ │  运营活动与   │
```

- **学习记录与进度追踪**：计时器产生的学习会话数据写入学习记录
- **学情分析**：专注时长、中断率等数据用于学情画像
- **学习规划**：规划模块生成的每日任务可关联计时器
- **护眼模式**：专注期间自动触发护眼提醒
- **运营活动与成长激励**：专注成就、连续打卡、排行榜等激励

## 2. 核心概念与数据模型

### 2.1 核心概念

| 概念 | 说明 |
|------|------|
| 学习会话（StudySession） | 一次完整的计时学习过程，包含一个或多个番茄钟周期 |
| 番茄钟周期（PomodoroCycle） | 一个"专注+休息"的完整周期 |
| 专注时段（FocusPeriod） | 番茄钟中的专注阶段，如25分钟 |
| 休息时段（BreakPeriod） | 番茄钟中的休息阶段，如5分钟 |
| 计时模式（TimerMode） | 预设的计时参数模板（番茄模式/自定义模式/倒计时模式） |
| 专注目标（FocusGoal） | 用户设定的当日/本周学习专注目标 |
| 专注中断（Interruption） | 专注期间用户主动暂停或离开APP的事件 |

### 2.2 数据结构定义

#### 2.2.1 学习会话 StudySession

```typescript
interface StudySession {
  id: string;                     // 会话唯一ID，UUID v7
  userId: string;                 // 用户ID
  startTime: string;              // ISO 8601 开始时间
  endTime: string | null;         // ISO 8601 结束时间（进行中为null）
  status: SessionStatus;          // 会话状态
  mode: TimerMode;                // 使用的计时模式
  
  // 关联信息
  subjectId: string | null;       // 学习科目ID
  chapterId: string | null;       // 教材章节ID（可选）
  taskId: string | null;          // 关联的学习计划任务ID（可选）
  taskType: TaskType | null;      // 学习任务类型
  
  // 统计数据
  totalFocusSeconds: number;      // 总专注秒数
  totalBreakSeconds: number;      // 总休息秒数
  completedCycles: number;        // 完成的番茄钟周期数
  interruptionCount: number;      // 中断次数
  totalInterruptionSeconds: number; // 中断总秒数
  
  // 质量指标
  focusScore: number | null;      // 专注得分 0-100（会话结束后计算）
  
  // 客户端信息
  deviceType: 'ios' | 'android' | 'web' | 'miniapp';
  appVersion: string;
  
  createdAt: string;
  updatedAt: string;
}

enum SessionStatus {
  ACTIVE = 'active',              // 进行中
  PAUSED = 'paused',              // 已暂停
  COMPLETED = 'completed',        // 正常完成
  ABANDONED = 'abandoned',        // 放弃（专注时长不足一轮）
}

enum TimerMode {
  POMODORO = 'pomodoro',          // 番茄钟模式
  COUNTDOWN = 'countdown',        // 倒计时模式
  STOPWATCH = 'stopwatch',        // 正计时/自由模式
}

enum TaskType {
  HOMEWORK = 'homework',          // 作业
  REVIEW = 'review',              // 复习
  EXERCISE = 'exercise',          // 刷题
  READING = 'reading',            // 阅读预习
  ERROR_CORRECTION = 'error_correction', // 错题订正
  MEMORIZATION = 'memorization',  // 背诵记忆
  ESSAY = 'essay',                // 作文
  FREE_STUDY = 'free_study',      // 自由学习
}
```

```typescript
interface PomodoroCycle {
  id: string;                     // 周期ID
  sessionId: string;              // 所属会话ID
  cycleIndex: number;             // 在会话中的序号（从1开始）
  
  // 专注阶段
  focusDurationSeconds: number;   // 设定的专注时长（秒）
  focusStartTime: string;         // 专注开始时间
  focusEndTime: string | null;    // 专注结束时间
  focusStatus: PeriodStatus;      // 专注阶段状态
  
  // 休息阶段
  breakDurationSeconds: number;   // 设定的休息时长（秒）
  breakStartTime: string | null;  // 休息开始时间
  breakEndTime: string | null;    // 休息结束时间
  breakStatus: PeriodStatus;      // 休息阶段状态
  breakType: BreakType;           // 休息类型
  
  // 实际数据
  actualFocusSeconds: number;     // 实际专注秒数（扣除中断）
  interruptionCount: number;      // 本周期中断次数
}

enum PeriodStatus {
  PENDING = 'pending',            // 未开始
  ACTIVE = 'active',              // 进行中
  PAUSED = 'paused',              // 暂停
  COMPLETED = 'completed',        // 完成
  SKIPPED = 'skipped',            // 跳过
}

enum BreakType {
  SHORT_BREAK = 'short_break',    // 短休息（默认5分钟）
  LONG_BREAK = 'long_break',      // 长休息（默认15-30分钟）
  NO_BREAK = 'no_break',          // 无休息（用户选择跳过）
}
```

#### 2.2.3 专注中断记录 Interruption

```typescript
interface Interruption {
  id: string;
  sessionId: string;
  cycleId: string;
  
  startTime: string;              // 中断开始时间
  endTime: string | null;         // 中断结束时间（进行中为null）

  reason: InterruptionReason;     // 中断原因
  source: InterruptionSource;     // 中断来源
  
  // 自动检测数据
  appWentBackground: boolean;     // 是否因APP进入后台
  screenLocked: boolean;          // 是否因锁屏
}

enum InterruptionReason {
  USER_PAUSED = 'user_paused',            // 用户主动暂停
  APP_BACKGROUND = 'app_background',      // APP切到后台
  SCREEN_LOCK = 'screen_lock',            // 屏幕锁定
  PHONE_CALL = 'phone_call',              // 来电
  NOTIFICATION_TAP = 'notification_tap',  // 点击通知跳转
  SYSTEM_INTERRUPT = 'system_interrupt',  // 系统中断
}

enum InterruptionSource {
  CLIENT_AUTO = 'client_auto',    // 客户端自动检测
  USER_MANUAL = 'user_manual',    // 用户手动操作
}
```

**业务规则：**

## 5. 关键业务逻辑

### 5.1 专注得分计算

```typescript
/**
 * 计算单次学习会话的专注得分
 * 
 * 公式：focusScore = baseScore - interruptionPenalty - deviationPenalty
 * 
 * baseScore: 基于完成周期数的基准分
 *   每完成1个周期 +30分，最高100分
 * 
 * interruptionPenalty: 中断扣分
 *   每次中断 -5分（最多扣30分）
 *   中断总时长占比 > 20% 额外 -10分
 * 
 * deviationPenalty: 偏差扣分
 *   如果中断时长 > 0，且平均中断时长 > 2分钟，-5分
 */
function calculateFocusScore(session: StudySession, cycles: PomodoroCycle[]): number {
  // 基准分：完成周期数 * 30，上限100
  const baseScore = Math.min(100, session.completedCycles * 30);
  
  // 中断扣分
  let interruptionPenalty = Math.min(30, session.interruptionCount * 5);
  
  // 中断时长占比
  if (session.totalFocusSeconds > 0) {
    const interruptionRatio = session.totalInterruptionSeconds / 
      (session.totalFocusSeconds + session.totalInterruptionSeconds);
    if (interruptionRatio > 0.2) {
      interruptionPenalty += 10;
    }
  }
  
  // 平均中断时长
  if (session.interruptionCount > 0) {
    const avgInterruption = session.totalInterruptionSeconds / session.interruptionCount;
    if (avgInterruption > 120) { // 超过2分钟
      interruptionPenalty += 5;
    }
  }
  
  const score = Math.max(0, Math.round(baseScore - interruptionPenalty));
  return Math.min(100, score);
}
```

**得分等级：**

| 分数区间 | 等级 | 标签 |
|---------|------|------|
| 90-100 | S | 🔥 极致专注 |
| 75-89 | A | ⭐ 高度专注 |
| 60-74 | B | 👍 专注良好 |
| 40-59 | C | 😐 有待提升 |
| 0-39 | D | 😴 容易分心 |

```typescript
// APP 进入后台
function onAppBackground(timerState: TimerState): void {
  if (!timerState.activeSession || !timerState.isRunning) return;
  
  const now = Date.now();
  
  // 记录中断
  const interruption: Interruption = {
    id: generateId(),
    sessionId: timerState.activeSession.id,
    cycleId: timerState.currentCycle!.id,
    startTime: new Date(now).toISOString(),
    endTime: null,
    durationSeconds: 0,
    reason: 'app_background',
    source: 'client_auto',
    appWentBackground: true,
    screenLocked: false,
  };
  
  // 更新本地状态
  timerState.backgroundTimestamp = now;
  timerState.currentInterruption = interruption;
  timerState.isRunning = false; // 本地暂停计时显示
  
  // 发送本地通知提醒用户
  sendLocalNotification({
    title: '学习被打断了',
    body: '点击回到学习继续专注 💪',
    sound: 'gentle.wav',
  });
}

// APP 回到前台
function onAppForeground(timerState: TimerState): void {
  if (!timerState.activeSession || !timerState.backgroundTimestamp) return;
  
  const now = Date.now();
  const awaySeconds = Math.floor((now - timerState.backgroundTimestamp) / 1000);
  
  // 关闭中断记录
  if (timerState.currentInterruption) {
    timerState.currentInterruption.endTime = new Date(now).toISOString();
    timerState.currentInterruption.durationSeconds = awaySeconds;
    timerState.pendingInterruptions.push(timerState.currentInterruption);
    timerState.currentInterruption = null;
  }
  
  // 判断离开时长是否过长（超过当前专注阶段的30%视为自动放弃本轮）
  const focusDuration = timerState.currentCycle!.focusDurationSeconds;
  if (awaySeconds > focusDuration * 0.3) {
    // 弹出对话框：本轮专注已中断
    showInterruptionDialog({
      awaySeconds,
      options: [
        { label: '重新开始本轮', action: 'restart_cycle' },
        { label: '结束本次学习', action: 'end_session' },
      ],
    });
  } else {
    // 短暂离开，恢复计时
    timerState.isRunning = true;
  }
  
  timerState.backgroundTimestamp = null;
}
```

### 7.2 离线数据同步

```typescript
// 离线数据同步策略
class TimerSyncManager {
  private pendingQueue: SyncEvent[] = [];
  private isSyncing: boolean = false;
  
  // 离线时将事件加入队列
  enqueue(event: SyncEvent): void {
    this.pendingQueue.push({
      ...event,
      timestamp: Date.now(),
      retries: 0,
    });
    this.persistToLocal(); // 持久化到本地存储
  }
  
  // 恢复网络后批量同步
  async sync(): Promise<void> {
    if (this.isSyncing || this.pendingQueue.length === 0) return;
    this.isSyncing = true;
    
    try {
      // 按时间排序
      const sorted = [...this.pendingQueue].sort((a, b) => a.timestamp - b.timestamp);
      
      // 批量发送
      const response = await fetch('/api/v1/timer/sync/batch', {
        method: 'POST',
        body: JSON.stringify({ events: sorted }),
      });
      
      if (response.ok) {
        this.pendingQueue = [];
        this.persistToLocal();
      }
    } finally {
      this.isSyncing = false;
    }
  }
}

interface SyncEvent {
  type: 'session_start' | 'session_end' | 'cycle_complete' | 'interruption';
  payload: Record<string, unknown>;
  timestamp: number;
  retries: number;
}
```

### 7.3 时钟漂移修正

```typescript
/**
 * 客户端本地计时可能因系统时间被修改而产生偏差
 * 采用单调时钟（monotonic clock）避免系统时间修改的影响
 */

// Flutter: 使用 Stopwatch（单调时钟）
// iOS: 使用 CACurrentMediaTime()
// Android: 使用 SystemClock.elapsedRealtime()

class MonotonicTimer {
  private stopwatch = new Stopwatch();
  private startEpoch: number | null = null;
  
  start(): void {
    this.startEpoch = Date.now();
    this.stopwatch.reset();
    this.stopwatch.start();
  }
  
  // 获取经过的秒数（基于单调时钟，不受系统时间修改影响）
  getElapsedSeconds(): number {
    return Math.floor(this.stopwatch.elapsedMilliseconds / 1000);
  }
  
  // 获取服务器可理解的绝对时间
  getAbsoluteTime(): string {
    if (!this.startEpoch) return new Date().toISOString();
    // 开始时的epoch + 经过毫秒数
    const elapsedMs = this.stopwatch.elapsedMilliseconds;
    return new Date(this.startEpoch + elapsedMs).toISOString();
  }
}
```

### 9.2 经验值(XP)计算规则

```typescript
/**
 * 专注学习获得XP规则
 * 
 * 基础XP = 完成的专注分钟数 × 系数
 * 系数根据学段不同：
 *   小学低年级: 0.8（避免过度激励）
 *   小学高年级: 0.8
 *   初中: 1.0
 *   高中: 1.0
 * 
 * 加成：
 *   连续3天达标: ×1.2
 *   连续7天达标: ×1.5
 *   完美专注(100分): ×2.0
 *   周末学习: ×1.1
 */
function calculateXPReward(
  focusMinutes: number,
  focusScore: number,
  streakDays: number,
  schoolStage: SchoolStage,
  isWeekend: boolean
): number {
  const baseMultiplier = ['kindergarten', 'primary_lower', 'primary_upper'].includes(schoolStage) ? 0.8 : 1.0;
  let baseXP = Math.floor(focusMinutes * baseMultiplier);
  
  // 连续天数加成
  if (streakDays >= 7) baseXP = Math.floor(baseXP * 1.5);
  else if (streakDays >= 3) baseXP = Math.floor(baseXP * 1.2);
  
  // 完美专注加成
  if (focusScore === 100) baseXP *= 2;
  
  // 周末加成
  if (isWeekend) baseXP = Math.floor(baseXP * 1.1);
  
  // 上限保护：单次最多200XP
  return Math.min(200, baseXP);
}
```

### 10.1 关键性能指标

| 统计查询延迟 | <200ms | daily_focus_stats快照表 |

### 10.2 客户端性能优化

```typescript
/**
 * 计时器UI使用 requestAnimationFrame 或 60fps 定时器
 * 避免使用 setInterval 导致的漂移
 */
class TimerRenderer {
  private lastUpdateMs: number = 0;
  private animationFrameId: number | null = null;
  
  startRendering(onTick: (remainingMs: number) => void): void {
    const endTime = Date.now() + getRemainingSeconds() * 1000;
    
    const frame = () => {
      const now = Date.now();
      const remainingMs = Math.max(0, endTime - now);
      
      // 每100ms更新一次UI（避免过于频繁）
      if (now - this.lastUpdateMs >= 100) {
        onTick(remainingMs);
        this.lastUpdateMs = now;
      }
      
      if (remainingMs > 0) {
        this.animationFrameId = requestAnimationFrame(frame);
      } else {
        onTick(0); // 倒计时结束
      }
    };
    
    this.animationFrameId = requestAnimationFrame(frame);
  }
  
  stopRendering(): void {
    if (this.animationFrameId !== null) {
      cancelAnimationFrame(this.animationFrameId);
    }
  }
}
```

## 11. 错误处理

### 11.1 客户端错误场景

| 场景 | 处理方式 |
|------|---------|
| 网络断开，无法创建会话 | 本地乐观创建，缓存到 pendingQueue，恢复网络后同步 |
| 网络断开，无法结束会话 | 本地标记结束，数据加入 pendingQueue |
| APP被系统杀死 | 下次启动时恢复未完成会话，提示用户继续或结束 |
| 系统时间被修改 | 使用单调时钟，不受影响 |
| 设备重启 | 从本地持久化存储恢复会话状态 |
| 会话创建409冲突 | 提示用户已有进行中的会话，引导恢复或结束 |
| 同步数据冲突 | 以服务端数据为准，客户端本地数据合并（取较晚的endTime） |

## 12. 安全与合规

### 12.1 数据权限

- 用户只能访问自己的学习会话数据
- 家长通过家长中心绑定关系可查看孩子的专注统计数据（只读）
- 教师端可查看班级聚合数据，不可查看个别学生详细会话

### 12.2 防作弊

- 服务端校验：专注秒数不应超过实际经过时间
- 异常检测：单次会话专注时长 > 4小时触发审核
- 频率限制：同一用户每天最多创建 20 个会话
- 专注得分仅作为激励参考，不作为学业评价依据

### 12.3 未成年人保护

- 每日学习时长提醒（超过建议时长后温馨提示）
- 深夜时段（23:00-06:00）不建议开启长时专注，弹窗提醒
- 小学低年级单次专注上限30分钟，避免过度疲劳
