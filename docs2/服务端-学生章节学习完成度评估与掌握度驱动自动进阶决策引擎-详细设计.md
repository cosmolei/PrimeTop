# 服务端 - 学生章节学习完成度评估与掌握度驱动自动进阶决策引擎

## 1. 概述

### 1.1 模块定位

本引擎是同步课堂学习闭环中的**关键决策枢纽**，负责回答一个核心问题：**"这个学生是否已经充分掌握了当前章节，可以进入下一章的学习了？"**

与 `教育内容定时发布调度与课程章节解锁引擎` 的区别：
- **章节解锁引擎**：负责章节内容的**时间维度**控制（按日期解锁、定时发布）
- **本引擎**：负责章节进阶的**能力维度**决策（基于掌握度、练习正确率、知识覆盖度等多维评估）

两者协同工作：章节先被解锁引擎按时间/条件解锁为"可学习"状态，再由本引擎根据学习表现评估是否可"完成并进阶"。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 完成度评估 | 从多维度计算章节学习完成度分数 |
| 掌握度判定 | 基于知识追踪模型判定章节内各知识点的掌握水平 |
| 进阶决策 | 根据完成度+掌握度+策略配置做出进阶/复习/阻断决策 |
| 进度状态管理 | 管理学生在章节级别的学习状态流转 |
| 完成报告生成 | 章节学习完成时自动生成总结报告 |
| 异常处理 | 处理跳级请求、强制进阶、长期卡点等边界场景 |

### 2.2 数据库表结构

#### 2.2.1 chapter_completion_assessment 表

```sql
CREATE TABLE chapter_completion_assessment (
    id                  BIGINT       PRIMARY KEY AUTO_INCREMENT,
    assessment_id       VARCHAR(64)  NOT NULL UNIQUE COMMENT '评估记录唯一ID',
    student_id          BIGINT       NOT NULL COMMENT '学生ID',
    textbook_id         VARCHAR(64)  NOT NULL COMMENT '教材版本ID',
    chapter_id          VARCHAR(64)  NOT NULL COMMENT '章节ID',
    subject             VARCHAR(20)  NOT NULL COMMENT '学科',
    grade_level         INT          NOT NULL COMMENT '年级',

    assessment_status   VARCHAR(20)  NOT NULL DEFAULT 'pending'
        COMMENT 'pending/in_progress/completed/expired',
    overall_completion_rate  DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '总完成度 0-1',
    overall_mastery_level    DECIMAL(5,4) NOT NULL DEFAULT 0 COMMENT '总掌握度 0-1',

    -- 内容学习维度
    theory_read_rate    DECIMAL(5,4) DEFAULT 0 COMMENT '理论阅读完成率',
    video_watch_rate    DECIMAL(5,4) DEFAULT 0 COMMENT '视频观看完成率',
    example_study_rate  DECIMAL(5,4) DEFAULT 0 COMMENT '例题学习完成率',
    reading_time_minutes INT         DEFAULT 0  COMMENT '阅读时长(分钟)',
    required_reading_completed TINYINT(1) DEFAULT 0 COMMENT '必读内容是否完成',

    -- 练习表现维度
    total_questions     INT    DEFAULT 0 COMMENT '总题数',
    correct_count       INT    DEFAULT 0 COMMENT '正确数',
    correct_rate        DECIMAL(5,4) DEFAULT 0 COMMENT '正确率',
    first_attempt_correct_rate DECIMAL(5,4) DEFAULT 0 COMMENT '首次作答正确率',
    basic_correct_rate  DECIMAL(5,4) DEFAULT 0 COMMENT '基础题正确率',
    intermediate_correct_rate DECIMAL(5,4) DEFAULT 0 COMMENT '中档题正确率',
    advanced_correct_rate DECIMAL(5,4) DEFAULT 0 COMMENT '难题正确率',

    -- 知识掌握维度
    knowledge_point_details JSON DEFAULT NULL COMMENT '各知识点掌握详情',
    average_mastery      DECIMAL(5,4) DEFAULT 0 COMMENT '平均掌握度',
    mastered_kp_count   INT DEFAULT 0 COMMENT '已掌握知识点数',
    developing_kp_count INT DEFAULT 0 COMMENT '发展中知识点数',
    not_mastered_kp_count INT DEFAULT 0 COMMENT '未掌握知识点数',

    -- 学习投入维度
    study_session_count INT DEFAULT 0 COMMENT '学习会话数',
    total_study_minutes INT DEFAULT 0 COMMENT '总学习时长(分钟)',
    active_days         INT DEFAULT 0 COMMENT '活跃学习天数',
    continuity_score    DECIMAL(5,4) DEFAULT 0 COMMENT '学习连续性评分',

    -- 进阶决策
    advancement_decision VARCHAR(30) DEFAULT NULL COMMENT 'advance/advance_with_weakness/recommend_review/block',
    decision_reason     TEXT DEFAULT NULL COMMENT '决策理由',
    decided_at          DATETIME DEFAULT NULL COMMENT '决策时间',
    decided_by          VARCHAR(20) DEFAULT NULL COMMENT 'system/parent/teacher',

    -- 章节总结
    chapter_summary     JSON DEFAULT NULL COMMENT '章节学习总结(优势/弱项/建议)',

    assessed_at         DATETIME DEFAULT NULL,
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_student_chapter (student_id, chapter_id),
    INDEX idx_student_textbook (student_id, textbook_id),
    INDEX idx_status (assessment_status),
    INDEX idx_chapter_assessed (chapter_id, assessed_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='章节完成度评估记录';
```

### 2.3 缓存策略

| 缓存 Key | 内容 | TTL | 更新策略 |
| --- | --- | --- | --- |
| `css:{studentId}:{chapterId}` | 章节学习状态 | 24h | 写穿透 + 事件驱动失效 |
| `asm:latest:{studentId}:{chapterId}` | 最新评估记录 | 1h | 评估完成后刷新 |
| `policy:{subject}:{gradeLevel}` | 适用进阶策略 | 6h | 后台修改时主动刷新 |
| `progress:realtime:{studentId}:{chapterId}` | 实时进度快照 | 5min | 学习行为驱动增量更新 |

## 3. API 接口设计

### 3.1 接口总览

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 触发章节评估 | POST | `/api/v1/chapter-assessment/evaluate` | 手动或系统触发的章节完成度评估 |
| 查询评估结果 | GET | `/api/v1/chapter-assessment/result` | 获取章节完成度评估详情 |
| 查询章节状态 | GET | `/api/v1/chapter-assessment/state` | 获取学生在指定章节的学习状态 |
| 批量查询章节状态 | POST | `/api/v1/chapter-assessment/states/batch` | 批量查询多个章节状态 |
| 执行进阶决策 | POST | `/api/v1/chapter-assessment/advance` | 执行章节进阶（自动或手动） |
| 获取进阶预检 | GET | `/api/v1/chapter-assessment/precheck` | 预检是否满足进阶条件 |
| 跳级申请 | POST | `/api/v1/chapter-assessment/skip` | 申请跳过当前章节 |
| 强制进阶(家长) | POST | `/api/v1/chapter-assessment/override` | 家长/教师强制进阶操作 |
| 获取章节完成报告 | GET | `/api/v1/chapter-assessment/report` | 获取章节完成总结报告 |
| 配置进阶策略 | PUT | `/api/v1/chapter-assessment/policy` | 更新进阶策略配置 |

### 3.2 核心接口详细设计

#### 3.2.1 触发章节评估

```
POST /api/v1/chapter-assessment/evaluate
```

**Request:**
```json
{
  "studentId": "stu_100234",

  "triggerType": "auto",
  "triggerEvent": "exercise_session_completed",
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| studentId | string | ✅ | 学生ID |

#### 4.2.1 多维加权评分模型

```java
/**
 * 章节完成度评估核心算法
 */
public class ChapterCompletionCalculator {

    // 权重配置（可通过策略动态调整）
    private static final double W_CONTENT_STUDY    = 0.25; // 内容学习权重
    private static final double W_EXERCISE         = 0.35; // 练习表现权重
    private static final double W_KNOWLEDGE_MASTERY= 0.30; // 知识掌握权重
    private static final double W_STUDY_ENGAGEMENT = 0.10; // 学习投入权重

    /**
     * 计算章节综合完成度
     */
    public CompletionResult calculate(StudentChapterContext ctx) {
        // 1. 计算各维度得分
        DimensionScore contentScore     = calcContentStudyScore(ctx);
        DimensionScore exerciseScore    = calcExerciseScore(ctx);
        DimensionScore masteryScore     = calcKnowledgeMasteryScore(ctx);
        DimensionScore engagementScore  = calcEngagementScore(ctx);

        // 2. 加权综合
        double overallCompletion = W_CONTENT_STUDY    * contentScore.getScore()
                                 + W_EXERCISE         * exerciseScore.getScore()
                                 + W_KNOWLEDGE_MASTERY * masteryScore.getScore()
                                 + W_STUDY_ENGAGEMENT  * engagementScore.getScore();

        // 3. 计算掌握度（独立于完成度）
        double overallMastery = masteryScore.getScore(); // 掌握度直接使用知识追踪结果

        // 4. 识别弱项
        List<WeaknessItem> weaknesses = identifyWeaknesses(ctx, contentScore, 
                                                            exerciseScore, masteryScore);

        return CompletionResult.builder()
            .overallCompletionRate(round(overallCompletion, 4))
            .overallMasteryLevel(round(overallMastery, 4))
            .dimensionScores(contentScore, exerciseScore, masteryScore, engagementScore)
            .weaknesses(weaknesses)
            .build();
    }

    /**
     * 内容学习维度评分
     */
    private DimensionScore calcContentStudyScore(StudentChapterContext ctx) {
        ChapterContent content = ctx.getChapterContent();
        StudentStudyRecord record = ctx.getStudyRecord();

        // 各内容类型的完成率
        double theoryRate = calcCompletionRate(
            record.getTheoryReadList(), content.getRequiredTheoryIds());
        double videoRate = calcCompletionRate(
            record.getWatchedVideos(), content.getRequiredVideoIds());
        double exampleRate = calcCompletionRate(
            record.getStudiedExamples(), content.getRequiredExampleIds());

        // 必读内容检查（一票否决项）
        boolean requiredCompleted = record.getRequiredReadingCompleted();

        // 综合内容学习得分
        double score = (theoryRate * 0.4 + videoRate * 0.35 + exampleRate * 0.25);
        
        // 必读未完成则扣分
        if (!requiredCompleted) {
            score *= 0.7; // 惩罚因子
        }

        return DimensionScore.builder()
            .score(score)
            .detail("theoryReadRate", theoryRate)
            .detail("videoWatchRate", videoRate)
            .detail("exampleStudyRate", exampleRate)
            .detail("requiredReadingCompleted", requiredCompleted)
            .build();
    }

    /**
     * 练习表现维度评分
     */
    private DimensionScore calcExerciseScore(StudentChapterContext ctx) {
        List<AnswerRecord> records = ctx.getChapterExerciseRecords();
        if (records.isEmpty()) {
            return DimensionScore.zero("暂无练习记录");
        }

        int total = records.size();
        int correct = (int) records.stream().filter(AnswerRecord::isCorrect).count();
        double correctRate = (double) correct / total;

        // 首次作答正确率（更重视首次表现）
        long firstAttemptCorrect = records.stream()
            .filter(r -> r.getAttemptNumber() == 1 && r.isCorrect()).count();
        double firstAttemptRate = (double) firstAttemptCorrect / total;

        // 按难度分层统计
        DifficultyStats diffStats = calcDifficultyStats(records);

        // 综合练习得分：正确率50% + 首次正确率20% + 基础题正确率30%
        double score = correctRate * 0.50
                     + firstAttemptRate * 0.20
                     + diffStats.getBasicRate() * 0.30;

        return DimensionScore.builder()
            .score(score)
            .detail("totalQuestions", total)
            .detail("correctCount", correct)
            .detail("correctRate", correctRate)
            .detail("firstAttemptCorrectRate", firstAttemptRate)
            .detail("difficultyDistribution", diffStats)
            .build();
    }

    /**
     * 知识掌握维度评分（调用知识追踪模型服务）
     */
    private DimensionScore calcKnowledgeMasteryScore(StudentChapterContext ctx) {
        // 调用知识追踪模型引擎获取各知识点掌握度
        List<KnowledgeMastery> masteries = knowledgeTracingService
            .batchGetMastery(ctx.getStudentId(), ctx.getChapterKnowledgePointIds());

        double avgMastery = masteries.stream()
            .mapToDouble(KnowledgeMastery::getMasteryLevel)
            .average().orElse(0.0);

        // 分档统计
        long mastered = masteries.stream().filter(m -> m.getMasteryLevel() >= 0.75).count();
        long developing = masteries.stream()
            .filter(m -> m.getMasteryLevel() >= 0.50 && m.getMasteryLevel() < 0.75).count();
        long notMastered = masteries.stream().filter(m -> m.getMasteryLevel() < 0.50).count();

        return DimensionScore.builder()
            .score(avgMastery)
            .detail("knowledgePoints", masteries)
            .detail("averageMastery", avgMastery)
            .detail("masteredCount", mastered)
            .detail("developingCount", developing)
            .detail("notMasteredCount", notMastered)
            .build();
    }

    /**
     * 学习投入维度评分
     */
    private DimensionScore calcEngagementScore(StudentChapterContext ctx) {
        StudyEngagementStats stats = ctx.getEngagementStats();

        // 学习连续性：在多少天有学习行为 vs 章节解锁天数
        double continuity = Math.min(1.0, (double) stats.getActiveDays() 
            / Math.max(1, stats.getDaysSinceUnlock()));

        // 学习充分性：实际学习时长 vs 建议学习时长
        int recommendedMinutes = ctx.getChapterRecommendedMinutes();
        double sufficiency = Math.min(1.0, (double) stats.getTotalStudyMinutes() 
            / Math.max(1, recommendedMinutes));

        // 综合投入得分
        double score = continuity * 0.4 + sufficiency * 0.6;

        return DimensionScore.builder()
            .score(score)
            .detail("studySessionCount", stats.getSessionCount())
            .detail("totalStudyMinutes", stats.getTotalStudyMinutes())
            .detail("activeDays", stats.getActiveDays())
            .detail("continuityScore", continuity)
            .build();
    }
}
```

```java
/**
 * 识别章节学习中的薄弱环节

public class WeaknessIdentifier {

    public List<WeaknessItem> identify(StudentChapterContext ctx,
                                        DimensionScore content,
                                        DimensionScore exercise,
                                        DimensionScore mastery) {
        List<WeaknessItem> items = new ArrayList<>();

        // 1. 知识点弱项：掌握度 < 阈值的知识点
        mastery.getDetailList("knowledgePoints").forEach(kp -> {
            if (kp.getMasteryLevel() < masteryThreshold) {
                items.add(WeaknessItem.builder()
                    .type("knowledge_point")
                    .kpId(kp.getKpId())
                    .kpName(kp.getKpName())
                    .currentLevel(kp.getMasteryLevel())
                    .requiredLevel(masteryThreshold)
                    .gap(kp.getMasteryLevel() - masteryThreshold)
                    .severity(calcSeverity(kp.getMasteryLevel()))
                    .recommendation(generateKpRecommendation(kp))
                    .build());
            }
        });

        // 2. 难度层级弱项：某难度层正确率显著偏低
        DifficultyStats diffStats = exercise.getDetail("difficultyDistribution", DifficultyStats.class);
        if (diffStats.getAdvancedRate() < 0.40 && diffStats.getAdvancedTotal() >= 3) {
            items.add(WeaknessItem.builder()
                .type("difficulty_level")
                .level("advanced")
                .currentRate(diffStats.getAdvancedRate())
                .expectedRate(0.50)
                .recommendation("难题正确率偏低，建议加强综合应用能力训练")
                .build());
        }

        // 3. 内容学习缺口
        if (content.getDetailBoolean("requiredReadingCompleted") == false) {
            items.add(WeaknessItem.builder()
                .type("content_gap")
                .description("必读内容未完成")
                .severity("high")
                .recommendation("请先完成章节必读内容再进阶")
                .build());
        }

        // 按严重程度排序
        items.sort(Comparator.comparing(WeaknessItem::getSeverityRank));

        return items;
    }

    private String calcSeverity(double masteryLevel) {
        if (masteryLevel < 0.40) return "critical";
        if (masteryLevel < 0.55) return "high";
        if (masteryLevel < 0.65) return "medium";
        return "low";
    }
}
```

### 4.3 进阶决策引擎

```java
/**
 * 章节进阶决策引擎
 */
public class AdvancementDecisionEngine {

    /**
     * 执行进阶决策
     */
    public AdvancementDecision decide(CompletionResult result, 
                                       ChapterAdvancementPolicy policy,
                                       StudentChapterContext ctx) {
        
        // 1. 构建评估上下文
        EvaluationContext evalCtx = buildContext(result, ctx);

        // 2. 按优先级遍历规则
        for (AdvancementRule rule : policy.getSortedRules()) {
            if (ruleMatches(rule, evalCtx)) {
                return executeRule(rule, result, evalCtx);
            }
        }

        // 3. 默认决策（安全兜底）
        return AdvancementDecision.builder()
            .decision("recommend_review")
            .reason("未匹配任何规则，默认建议复习")
            .autoExecute(false)
            .build();
    }

    private boolean ruleMatches(AdvancementRule rule, EvaluationContext ctx) {
        Condition condition = rule.getCondition();
        
        if ("AND".equals(condition.getOperator())) {
            // 所有表达式必须满足
            return condition.getExpressions().stream()
                .allMatch(expr -> evaluateExpression(expr, ctx));
        } else if ("OR".equals(condition.getOperator())) {
            // 任一表达式满足即可
            return condition.getExpressions().stream()
                .anyMatch(expr -> evaluateExpression(expr, ctx));
        }
        return false;
    }

    /**
     * 表达式求值器
     * 支持: overallCompletionRate >= 0.85, basicCorrectRate < 0.50 等
     */
    private boolean evaluateExpression(String expression, EvaluationContext ctx) {
        // 解析: metric operator value
        Matcher m = Pattern.compile("(\\w+)\\s*(>=|<=|>|<|==|!=)\\s*([\\d.]+)")
                          .matcher(expression);
        if (!m.matches()) {
            throw new PolicyException("Invalid expression: " + expression);
        }

        String metric = m.group(1);
        String operator = m.group(2);
        double threshold = Double.parseDouble(m.group(3));
        double actual = ctx.getMetric(metric);

        return switch (operator) {
            case ">=" -> actual >= threshold;
            case "<=" -> actual <= threshold;
            case ">"  -> actual > threshold;
            case "<"  -> actual < threshold;
            case "==" -> Math.abs(actual - threshold) < 0.001;
            case "!=" -> Math.abs(actual - threshold) >= 0.001;
            default   -> false;
        };
    }

    private AdvancementDecision executeRule(AdvancementRule rule, 
                                             CompletionResult result,
                                             EvaluationContext ctx) {
        return switch (rule.getAction()) {
            case "advance" -> buildAdvanceDecision(rule, result, ctx, false);
            case "advance_with_weakness" -> buildAdvanceDecision(rule, result, ctx, true);
            case "recommend_review" -> buildReviewDecision(rule, result, ctx);
            case "block" -> buildBlockDecision(rule, result, ctx);
            default -> throw new PolicyException("Unknown action: " + rule.getAction());
        };
    }

    private AdvancementDecision buildAdvanceDecision(AdvancementRule rule,
                                                      CompletionResult result,
                                                      EvaluationContext ctx,
                                                      boolean hasWeakness) {
        List<GeneratedTask> tasks = new ArrayList<>();
        
        // 为弱项生成补偿学习任务
        if (hasWeakness) {
            tasks = generateCompensationTasks(result.getWeaknesses(), ctx);
        }

        return AdvancementDecision.builder()
            .decision(hasWeakness ? "advance_with_weakness" : "advance")
            .reason(buildDecisionReason(rule, result))
            .autoExecute(rule.isAutoExecute())
            .sideEffects(tasks)
            .nextChapterId(ctx.getNextChapterId())
            .build();
    }

    /**
     * 生成补偿学习任务（为弱项知识点创建针对性练习）
     */
    private List<GeneratedTask> generateCompensationTasks(List<WeaknessItem> weaknesses,
                                                           EvaluationContext ctx) {
        return weaknesses.stream()
            .filter(w -> "knowledge_point".equals(w.getType()))
            .filter(w -> w.getSeverity() != null && !"low".equals(w.getSeverity()))
            .map(w -> GeneratedTask.builder()
                .type("weakness_review")
                .knowledgePointId(w.getKpId())
                .description(w.getKpName() + " 专项练习")
                .estimatedMinutes(estimateMinutes(w))
                .priority("critical".equals(w.getSeverity()) ? "high" : "medium")
                .scheduledFor("next_study_session")
                .build())
            .collect(Collectors.toList());
    }
}
```

```java
/**

@Component
public class AssessmentTriggerHandler {

    /**
     * 评估触发条件与对应行动
     */
    private static final Map<TriggerEvent, TriggerStrategy> TRIGGERS = Map.of(
        // 练习会话完成 → 检查是否达到评估条件
        TriggerEvent.EXERCISE_SESSION_COMPLETED, new ExerciseSessionTrigger(),
        
        // 章节所有必读内容完成 → 触发预评估
        TriggerEvent.REQUIRED_CONTENT_COMPLETED, new ContentCompletionTrigger(),
        
        // 每日学习结束 → 定时检查
        TriggerEvent.DAILY_STUDY_END, new DailyCheckTrigger(),
        
        // 章节建议学习时长已满 → 触发评估
        TriggerEvent.STUDY_TIME_THRESHOLD, new TimeThresholdTrigger(),
        
        // 用户主动请求评估
        TriggerEvent.MANUAL_REQUEST, new ManualTrigger()
    );

    /**
     * 处理学习事件，判断是否需要触发评估
     */
    @EventListener
    public void onLearningEvent(LearningEvent event) {
        TriggerStrategy strategy = TRIGGERS.get(event.getTriggerEvent());
        if (strategy == null) return;

        AssessmentContext ctx = buildAssessmentContext(event);
        
        if (strategy.shouldTrigger(ctx)) {
            // 检查冷却期
            if (isInCooldown(ctx.getStudentId(), ctx.getChapterId()) 
                && !ctx.isForceReassess()) {
                log.debug("评估冷却期内，跳过: student={}, chapter={}", 
                          ctx.getStudentId(), ctx.getChapterId());
                return;
            }

            // 异步触发评估
            completionAssessmentService.assessAsync(ctx);
        }
    }

    /**
     * 练习会话完成触发策略
     */
    static class ExerciseSessionTrigger implements TriggerStrategy {
        @Override
        public boolean shouldTrigger(AssessmentContext ctx) {
            // 条件: 本章练习题数 >= 10 且完成率 >= 60%
            return ctx.getChapterExerciseCompleted() >= 10
                && ctx.getExerciseCompletionRate() >= 0.60;
        }
    }

    /**
     * 内容完成触发策略
     */
    static class ContentCompletionTrigger implements TriggerStrategy {
        @Override
        public boolean shouldTrigger(AssessmentContext ctx) {
            return ctx.getRequiredContentCompleted()
                && ctx.getStudyProgress() >= 0.80; // 内容学习至少80%
        }
    }

    /**
     * 每日检查触发策略
     */
    static class DailyCheckTrigger implements TriggerStrategy {
        @Override
        public boolean shouldTrigger(AssessmentContext ctx) {
            // 条件: 章节已学习但未完成，且距上次评估超过24h
            return ctx.getStatus() == ChapterStatus.IN_PROGRESS
                && ctx.getHoursSinceLastAssessment() >= 24;
        }
    }
}
```

```java
/**
 * 章节完成度评估服务
 */
@Service
@Slf4j
public class ChapterCompletionAssessmentService {

    @Autowired private KnowledgeTracingClient knowledgeTracingClient;
    @Autowired private ExerciseRecordClient exerciseRecordClient;
    @Autowired private StudyRecordClient studyRecordClient;
    @Autowired private ChapterContentClient chapterContentClient;
    @Autowired private AdvancementPolicyManager policyManager;
    @Autowired private AdvancementDecisionEngine decisionEngine;
    @Autowired private ChapterStudyStateService stateService;
    @Autowired private CompensationTaskGenerator taskGenerator;
    @Autowired private AssessmentEventPublisher eventPublisher;
    @Autowired private AssessmentCacheManager cacheManager;

    /**
     * 执行章节完成度评估
     */
    @Transactional
    public AssessmentResult assess(AssessmentRequest request) {
        log.info("开始章节评估: student={}, chapter={}, trigger={}", 
                 request.getStudentId(), request.getChapterId(), request.getTriggerType());

        // 1. 前置校验
        ChapterStudyState state = stateService.getState(request.getStudentId(), 
                                                         request.getChapterId());
        validateAssessable(state, request);

        // 2. 聚合评估数据
        StudentChapterContext ctx = aggregateContext(request.getStudentId(), 
                                                      request.getChapterId());

        // 3. 计算完成度
        CompletionCalculator calculator = new ChapterCompletionCalculator();
        CompletionResult completionResult = calculator.calculate(ctx);

        // 4. 获取适用的进阶策略
        ChapterAdvancementPolicy policy = policyManager.getPolicy(
            ctx.getSubject(), ctx.getGradeLevel(), ctx.getTextbookId());

        // 5. 执行进阶决策
        AdvancementDecision decision = decisionEngine.decide(completionResult, policy, ctx);

        // 6. 持久化评估结果
        ChapterCompletionAssessment assessment = buildAssessmentEntity(
            request, completionResult, decision, ctx);
        assessmentRepository.save(assessment);

        // 7. 执行决策动作
        if (decision.isAutoExecute()) {
            executeAdvancement(state, decision, ctx);
        }

        // 8. 发布评估完成事件
        eventPublisher.publishAssessmentCompleted(assessment);

        // 9. 更新缓存
        cacheManager.refreshAssessmentCache(request.getStudentId(), 
                                             request.getChapterId(), assessment);

        return AssessmentResult.from(assessment);
    }

    /**
     * 聚合评估所需的全部上下文数据
     */
    private StudentChapterContext aggregateContext(Long studentId, String chapterId) {
        // 并行获取数据
        CompletableFuture<ChapterContent> contentFuture = 
            chapterContentClient.getChapterContentAsync(chapterId);
        CompletableFuture<List<AnswerRecord>> exerciseFuture = 
            exerciseRecordClient.getChapterRecordsAsync(studentId, chapterId);
        CompletableFuture<StudyRecord> studyFuture = 
            studyRecordClient.getChapterStudyRecordAsync(studentId, chapterId);
        CompletableFuture<List<KnowledgeMastery>> masteryFuture =
            knowledgeTracingClient.batchGetMasteryAsync(studentId, 
                contentFuture.join().getKnowledgePointIds());

        return StudentChapterContext.builder()
            .studentId(studentId)
            .chapterId(chapterId)
            .chapterContent(contentFuture.join())
            .exerciseRecords(exerciseFuture.join())
            .studyRecord(studyFuture.join())
            .knowledgeMasteries(masteryFuture.join())
            .build();
    }

    /**
     * 执行进阶操作
     */
    private void executeAdvancement(ChapterStudyState state, 
                                     AdvancementDecision decision,
                                     StudentChapterContext ctx) {
        switch (decision.getDecision()) {
            case "advance", "advance_with_weakness" -> {
                // 更新当前章节状态
                stateService.updateStatus(ctx.getStudentId(), ctx.getChapterId(), 
                                          ChapterStatus.COMPLETED);
                
                // 解锁下一章
                if (decision.getNextChapterId() != null) {
                    stateService.updateStatus(ctx.getStudentId(), decision.getNextChapterId(),
                                              ChapterStatus.AVAILABLE);
                }

                // 生成补偿任务
                if (decision.hasSideEffects()) {
                    List<GeneratedTask> tasks = taskGenerator.generate(
                        decision.getSideEffects(), ctx);
                    taskGenerator.scheduleTasks(tasks);
                }

                // 发布进阶事件
                eventPublisher.publishChapterAdvanced(ctx.getStudentId(), 
                    ctx.getChapterId(), decision);
            }
            case "recommend_review" -> {
                // 更新状态为可完成但不自动进阶
                stateService.updateStatus(ctx.getStudentId(), ctx.getChapterId(),
                                          ChapterStatus.COMPLETABLE);
                
                // 生成复习任务
                List<GeneratedTask> reviewTasks = taskGenerator.generateReviewTasks(ctx);
                taskGenerator.scheduleTasks(reviewTasks);

                eventPublisher.publishReviewRecommended(ctx.getStudentId(), 
                    ctx.getChapterId(), reviewTasks);
            }
            case "block" -> {
                // 保持in_progress状态，生成强化练习计划
                List<GeneratedTask> intensiveTasks = taskGenerator.generateIntensivePractice(ctx);
                taskGenerator.scheduleTasks(intensiveTasks);

                eventPublisher.publishAdvancementBlocked(ctx.getStudentId(), 
                    ctx.getChapterId(), intensiveTasks);
            }
        }
    }
}
```

```java
/**
 * 进阶策略管理器 - 负责策略加载、匹配和缓存
 */
@Service
public class AdvancementPolicyManager {

    @Autowired private AdvancementPolicyRepository policyRepository;
    @Autowired private PolicyCache policyCache;

    /**
     * 获取适用的进阶策略
     * 匹配优先级: 精确教材版本 > 学科+年级 > 学科通用 > 全局默认
     */
    public ChapterAdvancementPolicy getPolicy(String subject, int gradeLevel, 
                                               String textbookId) {
        // 1. 尝试从缓存获取
        String cacheKey = buildCacheKey(subject, gradeLevel, textbookId);
        ChapterAdvancementPolicy cached = policyCache.get(cacheKey);
        if (cached != null) return cached;

        // 2. 按优先级查询
        List<ChapterAdvancementPolicy> candidates = policyRepository.findApplicable(
            subject, gradeLevel, textbookId);

        if (candidates.isEmpty()) {
            // 返回内置默认策略
            return getDefaultPolicy();
        }

        // 3. 选择最高优先级的策略
        ChapterAdvancementPolicy selected = candidates.get(0);

        // 4. 写入缓存
        policyCache.put(cacheKey, selected, Duration.ofHours(6));

        return selected;
    }

    private String buildCacheKey(String subject, int grade, String textbookId) {
        return String.format("policy:%s:%d:%s", subject, grade, textbookId);
    }

    /**
     * 内置默认策略（安全兜底）
     */
    private ChapterAdvancementPolicy getDefaultPolicy() {
        ChapterAdvancementPolicy policy = new ChapterAdvancementPolicy();
        policy.setName("内置默认策略");
        
        Map<String, Double> thresholds = new HashMap<>();
        thresholds.put("overallCompletionMin", 0.80);
        thresholds.put("overallMasteryMin", 0.65);
        thresholds.put("basicCorrectRateMin", 0.80);
        policy.setCompletionThresholds(thresholds);

        List<AdvancementRule> rules = List.of(
            AdvancementRule.builder()
                .ruleId("default_advance")
                .name("标准进阶")
                .priority(1)
                .condition(Condition.and(
                    "overallCompletionRate >= 0.85",
                    "overallMasteryLevel >= 0.70"
                ))
                .action("advance")
                .autoExecute(true)
                .build(),
            AdvancementRule.builder()
                .ruleId("default_review")
                .name("建议复习")
                .priority(2)
                .condition(Condition.and(
                    "overallCompletionRate >= 0.60",
                    "overallMasteryLevel < 0.65"
                ))
                .action("recommend_review")
                .autoExecute(false)
                .build(),
            AdvancementRule.builder()
                .ruleId("default_block")
                .name("阻断进阶")
                .priority(3)
                .condition(Condition.or(
                    "overallCompletionRate < 0.50",
                    "basicCorrectRate < 0.50"
                ))
                .action("block")
                .autoExecute(false)
                .build()
        );
        policy.setAdvancementRules(rules);

        return policy;
    }
}
```

```java
/**
 * 评估服务降级处理器

@Component
@Slf4j
public class AssessmentFallbackHandler {

    /**
     * 知识追踪服务不可用时的降级策略
     * 使用练习正确率近似估算掌握度
     */
    public CompletionResult fallbackKnowledgeTracing(StudentChapterContext ctx) {
        log.warn("知识追踪服务不可用，启用降级策略: student={}, chapter={}", 
                 ctx.getStudentId(), ctx.getChapterId());

        // 用练习正确率按知识点分组的平均值作为掌握度近似值
        Map<String, List<AnswerRecord>> kpRecords = ctx.getExerciseRecords().stream()
            .filter(r -> r.getKnowledgePointIds() != null)
            .flatMap(r -> r.getKnowledgePointIds().stream()
                .map(kp -> Map.entry(kp, r)))
            .collect(Collectors.groupingBy(Map.Entry::getKey, 
                     Collectors.mapping(Map.Entry::getValue, Collectors.toList())));

        List<KnowledgeMastery> approximated = kpRecords.entrySet().stream()
            .map(e -> {
                double rate = (double) e.getValue().stream()
                    .filter(AnswerRecord::isCorrect).count() / e.getValue().size();
                return KnowledgeMastery.builder()
                    .kpId(e.getKey())
                    .masteryLevel(rate)
                    .source("fallback_exercise_rate")
                    .build();
            })
            .collect(Collectors.toList());

        return CompletionResult.fallback(ctx, approximated);
    }

    /**
     * 练习记录服务不可用时的降级策略
     * 仅基于内容学习进度做基本判断
     */
    public CompletionResult fallbackExerciseRecords(StudentChapterContext ctx) {
        log.warn("练习记录服务不可用，启用降级策略");
        
        double contentProgress = ctx.getStudyRecord().getContentProgress();
        return CompletionResult.builder()
            .overallCompletionRate(contentProgress * 0.5) // 降低置信度
            .overallMasteryLevel(0) // 无法评估掌握度
            .degraded(true)
            .degradedReason("练习记录服务不可用，仅基于内容进度评估")
            .build();
    }

    /**
     * 策略服务不可用时的降级
     */
    public ChapterAdvancementPolicy fallbackPolicy() {
        log.warn("策略服务不可用，使用内置默认策略");
        return DefaultPolicies.builtIn();
    }
```

```java
/**
 * 使用Redis分布式锁防止并发评估冲突
 */
@Component
public class AssessmentLockManager {

    private static final String LOCK_KEY_PREFIX = "assessment:lock:";
    private static final Duration LOCK_TTL = Duration.ofMinutes(5);

    @Autowired private StringRedisTemplate redisTemplate;

    /**
     * 尝试获取评估锁
     */
    public boolean tryLock(Long studentId, String chapterId) {
        String key = LOCK_KEY_PREFIX + studentId + ":" + chapterId;
        String value = UUID.randomUUID().toString();
        
        Boolean acquired = redisTemplate.opsForValue()
            .setIfAbsent(key, value, LOCK_TTL);
        
        return Boolean.TRUE.equals(acquired);
    }

    /**
     * 释放评估锁（安全释放，防止误删）
     */
    public void unlock(Long studentId, String chapterId) {
        String key = LOCK_KEY_PREFIX + studentId + ":" + chapterId;
        String value = redisTemplate.opsForValue().get(key);
        
        // Lua脚本确保原子性：值匹配才删除
        String script = 
            "if redis.call('get', KEYS[1]) == ARGV[1] then " +
            "  return redis.call('del', KEYS[1]) " +
            "else " +
            "  return 0 " +
            "end";
        
        if (value != null) {
            redisTemplate.execute(
                new DefaultRedisScript<>(script, Long.class),
                Collections.singletonList(key),
                value);
        }
    }
}
```

### 8.1 评估数据预聚合

为了避免每次评估都实时查询大量数据，采用增量预聚合策略：

```java
/**
 * 学习数据增量预聚合服务
 * 监听学习行为事件，实时更新章节维度聚合数据
 */
@Component
public class ChapterProgressAggregator {

    /**
     * 练习完成事件 → 更新章节练习聚合
     */
    @EventListener
    @Async
    public void onExerciseCompleted(ExerciseCompletedEvent event) {
        String chapterId = event.getChapterId();
        Long studentId = event.getStudentId();

        // 增量更新Redis中的聚合计数器
        String key = String.format("chapter:agg:%d:%s", studentId, chapterId);
        
        redisTemplate.opsForHash().increment(key, "totalQuestions", 1);
        if (event.isCorrect()) {
            redisTemplate.opsForHash().increment(key, "correctCount", 1);
        }
        if (event.getDifficulty() != null) {
            redisTemplate.opsForHash().increment(key, 
                "diff_" + event.getDifficulty() + "_total", 1);
            if (event.isCorrect()) {
                redisTemplate.opsForHash().increment(key, 
                    "diff_" + event.getDifficulty() + "_correct", 1);
            }
        }
        
        // 设置过期时间（7天后自动清理）
        redisTemplate.expire(key, Duration.ofDays(7));
    }

    /**
     * 获取预聚合的章节练习统计（避免全量查询答题记录）
     */
    public ChapterExerciseAggregate getAggregate(Long studentId, String chapterId) {
        String key = String.format("chapter:agg:%d:%s", studentId, chapterId);
        Map<Object, Object> entries = redisTemplate.opsForHash().entries(key);

        return ChapterExerciseAggregate.fromRedisHash(entries);
    }
}
```

### 8.2 评估请求合并

当短时间内有多个触发条件命中时（如学生连续完成多道题），合并评估请求：

```java
/**
 * 使用debounce策略合并短时间内的多个评估请求
 */
@Component
public class AssessmentRequestDebouncer {

    private final Map<String, ScheduledAssessment> pendingRequests = 
        new ConcurrentHashMap<>();

    /**
     * 提交评估请求（带3秒debounce）
     */
    public void submit(AssessmentRequest request) {
        String key = request.getStudentId() + ":" + request.getChapterId();
        
        ScheduledAssessment existing = pendingRequests.get(key);
        if (existing != null && !existing.isExecuted()) {
            // 合并请求：更新触发信息但延迟执行
            existing.merge(request);
            return;
        }

        ScheduledAssessment scheduled = new ScheduledAssessment(request);
        pendingRequests.put(key, scheduled);
        
        // 3秒后执行
        scheduled.schedule(Duration.ofSeconds(3), () -> {
            pendingRequests.remove(key);
            assessmentService.assessAsync(scheduled.getMergedRequest());
        });
    }
}
```

### 9.2 防作弊考虑

```java
/**
 * 评估防作弊检查
 */
@Component
public class AssessmentAntiCheatChecker {

    /**
     * 检查是否有异常答题行为
     */
    public AntiCheatResult check(Long studentId, String chapterId, 
                                  List<AnswerRecord> records) {
        // 1. 答题速度异常：平均每题 < 5秒
        double avgSecondsPerQuestion = records.stream()
            .mapToInt(AnswerRecord::getTimeSpentSeconds)
            .average().orElse(0);
        if (avgSecondsPerQuestion < 5 && records.size() > 5) {
            return AntiCheatResult.warn("答题速度异常，可能存在抄答案行为");
        }

        // 2. 设备指纹一致性：答题过程中是否切换设备
        Set<String> deviceFingerprints = records.stream()
            .map(AnswerRecord::getDeviceFingerprint)
            .collect(Collectors.toSet());
        if (deviceFingerprints.size() > 2) {
            return AntiCheatResult.warn("答题设备异常，可能存在代答行为");
        }

        // 3. 时段异常：深夜连续答题
        long nightAnswers = records.stream()
            .filter(r -> {
                int hour = r.getAnsweredAt().getHour();
                return hour >= 0 && hour < 5;
            }).count();
        if (nightAnswers > records.size() * 0.5 && records.size() > 10) {
            return AntiCheatResult.info("深夜答题比例较高，评估结果可信度可能受影响");
        }

        return AntiCheatResult.pass();
    }
}
```
