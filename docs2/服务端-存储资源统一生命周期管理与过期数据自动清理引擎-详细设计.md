# 服务端-存储资源统一生命周期管理与过期数据自动清理引擎-详细设计

## 1. 概述

### 1.1 功能定位

PrimeTop 平台在运行过程中会产生和积累大量存储资源，包括但不限于：

- 用户上传的拍照图片、作文图片、语音 recordings
- AI 生成的回答内容缓存、图表图片
- 教材内容资源（图片、音频、视频、PDF）
- 系统产生的临时文件（OCR 中间结果、转码中间产物）
- 用户头像、手写笔记图片
- 运营素材（活动图片、推送素材）
- 日志归档文件、数据库备份快照

随着平台运行时间增长和用户规模扩大，存储资源呈现以下问题：

1. **孤儿资源堆积**：业务数据已删除，但对应的文件资源仍残留在对象存储中
2. **临时资源长期留存**：OCR 中间图片、转码临时文件等未被及时清理
3. **合规风险**：未成年人数据未按 PIPL 要求在指定期限内删除
4. **存储成本失控**：无法准确掌握资源分布和增长趋势
5. **资源引用断裂**：数据库记录指向已删除或不存在的文件

本引擎旨在建立 **统一的存储资源全生命周期管理体系**，实现资源的可追踪、可审计、可自动清理和合规管理。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 孤儿资源识别准确率 | ≥ 99% |
| 自动清理任务执行成功率 | ≥ 99.5% |
| 合规删除及时率 | 100%（PIPL 要求的数据不得超期） |
| 存储用量可观测性 | 误差 ≤ 2% |
| 清理任务对在线业务影响 | API 延迟增加 ≤ 50ms |

### 1.3 适用范围

- 所有写入对象存储（OSS/S3/MinIO）的文件资源
- CDN 缓存资源的过期刷新
- 数据库中的 BLOB 字段引用
- 本地临时文件和日志归档
- Redis 缓存中的大体积 Value（如序列化图片）

### 3.2 Redis 缓存结构

```
# 资源引用计数缓存（Hash）
storage:refcount:{resourceId} → { count: N, lastCheck: timestamp }

# 模块级存储用量缓存（String，5分钟 TTL）
storage:usage:{module}:{date} → JSON { totalFiles, totalSize }

# 清理任务分布式锁（String，30分钟 TTL）
storage:cleanup:lock:{taskType} → nodeId

# 孤儿资源待确认队列（Sorted Set，score=创建时间）
storage:orphan:pending → { resourceId: score }

# 合规删除紧急队列（List）
storage:compliance:urgent:queue → [ resourceId, ... ]
```

## 5. 核心流程设计

### 5.1 资源注册与引用追踪流程

```
业务服务创建文件
    │
    ├── 文件上传至对象存储 (OSS/S3)
    │
    ├── 调用 StorageLifecycleClient.register()
    │       │
    │       ├── 写入 storage_resource 表（含业务归属、保留策略）
    │       ├── 写入 storage_reference 表（引用关系）
    │       └── 更新 Redis 引用计数缓存
    │
    └── 返回 resourceId 给业务服务
         └── 业务服务在业务表中记录 resourceId 或 resourceUrl
```

```java

StorageRegisterRequest request = StorageRegisterRequest.builder()
```

**孤儿检测核心代码（Java）：**

```java
/**
 * 孤儿资源检测器
 * 采用多级检测策略，避免误删
 */
@Component
@Slf4j
public class OrphanResourceDetector {

    @Autowired
    private StorageResourceMapper resourceMapper;
    
    @Autowired
    private StorageReferenceMapper referenceMapper;
    
    @Autowired
    private OrphanDetectionRuleEngine ruleEngine;
    
    @Autowired
    private RedissonClient redisson;

    /**
     * 执行孤儿检测（分模块、分批次）
     */
    public OrphanScanResult scan(OrphanScanParam param) {
        String scanModule = param.getScanModule();
        LocalDateTime scanBefore = param.getScanBefore();
        int batchSize = param.getBatchSize();
        
        RLock lock = redisson.getLock("storage:cleanup:lock:ORPHAN_SCAN");
        if (!lock.tryLock()) {
            return OrphanScanResult.skipped("另一个扫描任务正在运行");
        }

        try {
            OrphanScanResult result = new OrphanScanResult();
            long lastId = 0;
            
            while (true) {
                // 分批查询
                List<StorageResource> resources = resourceMapper.selectBatchForScan(
                    scanModule, scanBefore, lastId, batchSize);
                
                if (resources.isEmpty()) break;
                
                for (StorageResource resource : resources) {
                    lastId = resource.getId();
                    result.incrementScanned();
                    
                    // 多级检测
                    OrphanDetectionResult detection = detectOrphan(resource);
                    
                    if (detection.isOrphan()) {
                        // 标记为孤儿，进入宽限期
                        markAsOrphaned(resource, detection);
                        result.incrementMarked();
                    }
                }
            }
            
            return result;
        } finally {
            lock.unlock();
        }
    }

    /**
     * 多级孤儿检测
     */
    private OrphanDetectionResult detectOrphan(StorageResource resource) {
        // Level 1: 引用关系表检查
        int refCount = referenceMapper.countActiveReferences(resource.getId());
        if (refCount > 0) {
            return OrphanDetectionResult.notOrphan("ACTIVE_REFERENCE", refCount);
        }

        // Level 2: 业务规则检查（模块特定规则）
        OrphanDetectionResult ruleResult = ruleEngine.check(resource);
        if (ruleResult != null && !ruleResult.isOrphan()) {
            return ruleResult;
        }

        // Level 3: 对象存储 HEAD 请求验证文件是否真实存在
        boolean fileExists = storageAdapter.headObject(
            resource.getStorageType(), 
            resource.getBucketName(), 
            resource.getResourceKey()
        );
        
        if (!fileExists) {
            return OrphanDetectionResult.orphan("FILE_NOT_FOUND");
        }

        // Level 4: 安全宽限期检查（已过宽限期才确认为孤儿）
        if (resource.getStatus().equals("ORPHANED")) {
            LocalDateTime orphanedAt = resource.getUpdatedAt();
            long daysSinceOrphaned = Duration.between(orphanedAt, LocalDateTime.now()).toDays();
            if (daysSinceOrphaned >= 7) {
                return OrphanDetectionResult.orphan("GRACE_PERIOD_EXPIRED");
            }
            return OrphanDetectionResult.pending("IN_GRACE_PERIOD", 7 - daysSinceOrphaned);
        }

        // 首次标记为孤儿候选
        return OrphanDetectionResult.candidate("NO_REFERENCE_FOUND");
    }

    private void markAsOrphaned(StorageResource resource, OrphanDetectionResult detection) {
        resourceMapper.updateStatus(resource.getId(), "ORPHANED", detection.getReason());
        
        // 加入待确认队列，设置宽限期到期 score
        double expireScore = LocalDateTime.now().plusDays(7)
            .toEpochSecond(ZoneOffset.UTC);
        redisson.getScoredSet("storage:orphan:pending")
            .add(expireScore, resource.getId());
        
        log.info("Resource marked as orphaned: id={}, key={}, reason={}", 
            resource.getId(), resource.getResourceKey(), detection.getReason());
    }
}
```

```java
/**
 * 存储成本归因计算
 */
public class StorageCostCalculator {

    // OSS 存储单价（元/GB/月）
    private static final BigDecimal STANDARD_STORAGE_PRICE = new BigDecimal("0.12");
    private static final BigDecimal INFREQUENT_ACCESS_PRICE = new BigDecimal("0.08");
    private static final BigDecimal ARCHIVE_PRICE = new BigDecimal("0.033");
    
    // CDN 流量单价（元/GB）
    private static final BigDecimal CDN_TRAFFIC_PRICE = new BigDecimal("0.24");

    /**
     * 计算模块级月度存储成本
     */
    public ModuleStorageCost calculate(String module, LocalDate month) {
        StorageUsageDaily usage = usageService.getMonthlyAggregate(module, month);
        
        BigDecimal storageCost = calculateStorageCost(usage.getTotalSize());
        BigDecimal trafficCost = calculateTrafficCost(module, month);
        
        return ModuleStorageCost.builder()
            .module(module)
            .month(month)
            .storageBytes(usage.getTotalSize())
            .storageCost(storageCost)
            .trafficCost(trafficCost)
            .totalCost(storageCost.add(trafficCost))
            .costPerUser(calculatePerUser(module, storageCost))
            .build();
    }
    
    /**
     * 分层存储成本计算
     */
    private BigDecimal calculateStorageCost(long totalBytes) {
        double totalGB = totalBytes / (1024.0 * 1024 * 1024);
        
        // 前 100GB: 标准存储
        BigDecimal standardCost = BigDecimal.valueOf(Math.min(totalGB, 100))
            .multiply(STANDARD_STORAGE_PRICE);
        
        // 100GB-1TB: 低频存储
        BigDecimal iaCost = BigDecimal.valueOf(Math.max(0, Math.min(totalGB - 100, 900)))
            .multiply(INFREQUENT_ACCESS_PRICE);
        
        // 1TB+: 归档存储
        BigDecimal archiveCost = BigDecimal.valueOf(Math.max(0, totalGB - 1000))
            .multiply(ARCHIVE_PRICE);
        
        return standardCost.add(iaCost).add(archiveCost);
    }
}
```

```java
/**
 * 清理执行器 — 分批处理，控制对在线业务影响
 */
@Component
@Slf4j
public class CleanupExecutor {

    @Value("${storage.cleanup.rate-limit-per-second:50}")
    private int rateLimitPerSecond;  // 每秒最多删除 50 个文件

    @Value("${storage.cleanup.batch-interval-ms:100}")
    private long batchIntervalMs;     // 批次间隔 100ms

    /**
     * 分批执行清理
     */
    public CleanupResult executeBatch(List<StorageResource> resources, 
                                       String taskType, Long taskId) {
        CleanupResult result = new CleanupResult();
        RateLimiter limiter = RateLimiter.create(rateLimitPerSecond);
        
        List<List<StorageResource>> batches = Lists.partition(resources, 100);
        
        for (List<StorageResource> batch : batches) {
            for (StorageResource resource : batch) {
                limiter.acquire(); // 限流
                
                try {
                    // 1. 删除对象存储文件
                    boolean ossDeleted = storageAdapter.deleteObject(
                        resource.getStorageType(),
                        resource.getBucketName(),
                        resource.getResourceKey()
                    );
                    
                    if (ossDeleted) {
                        // 2. 更新数据库状态
                        resourceMapper.markDeleted(resource.getId(), 
                            LocalDateTime.now(), taskType);
                        
                        // 3. 删除引用关系
                        referenceMapper.deleteByResourceId(resource.getId());
                        
                        // 4. 刷新 CDN 缓存
                        cdnService.purgeUrl(resource.getResourceUrl());
                        
                        // 5. 更新统计
                        result.addDeleted(resource.getFileSize());
                    } else {
                        result.addError(resource.getId(), "OSS_DELETE_FAILED");
                    }
                } catch (Exception e) {
                    log.error("Cleanup failed for resource: {}", resource.getId(), e);
                    result.addError(resource.getId(), e.getMessage());
                }
            }
            
            // 批次间隔，减轻对数据库的压力
            sleep(batchIntervalMs);
            
            // 更新任务进度
            taskService.updateProgress(taskId, result);
        }
        
        return result;
    }
}
```

### 9.3 对账核心代码

```java
/**
 * 对象存储深度对账任务
 * 每周日凌晨执行，对比桶内容与数据库记录
 */
@Component
@Slf4j
public class StorageReconciliationJob {

    @Scheduled(cron = "0 0 4 * * SUN")
    public void executeReconciliation() {
        for (String bucket : monitoredBuckets) {
            reconcileBucket(bucket);
        }
    }

    public ReconciliationReport reconcileBucket(String bucketName) {
        log.info("Starting reconciliation for bucket: {}", bucketName);
        
        // 流式遍历对象存储，避免内存溢出
        Stream<StorageObjectInfo> ossStream = storageAdapter
            .listObjectsStream(bucketName);
        
        // 流式查询数据库
        Stream<StorageResource> dbStream = resourceMapper
            .streamAllActiveByBucket(bucketName);
        
        // 合并流对比（按 resource_key 排序后双指针遍历）
        ReconciliationReport report = new ReconciliationReport();
        Iterator<StorageObjectInfo> ossIter = ossStream.iterator();
        Iterator<StorageResource> dbIter = dbStream.iterator();
        
        StorageObjectInfo ossObj = ossIter.hasNext() ? ossIter.next() : null;
        StorageResource dbObj = dbIter.hasNext() ? dbIter.next() : null;
        
        while (ossObj != null || dbObj != null) {
            int cmp = compareKeys(ossObj, dbObj);
            
            if (cmp == 0) {
                // 双方都有 → 检查一致性
                if (ossObj.getSize() != dbObj.getFileSize()) {
                    report.addInconsistent(dbObj.getId(), 
                        ossObj.getSize(), dbObj.getFileSize());
                }
                ossObj = ossIter.hasNext() ? ossIter.next() : null;
                dbObj = dbIter.hasNext() ? dbIter.next() : null;
            } else if (cmp < 0) {
                // OSS 有，DB 无 → 孤儿文件
                report.addOrphanInStorage(ossObj.getKey(), ossObj.getSize());
                ossObj = ossIter.hasNext() ? ossIter.next() : null;
            } else {
                // DB 有，OSS 无 → 悬空引用
                report.addMissingInStorage(dbObj.getId(), dbObj.getResourceKey());
                dbObj = dbIter.hasNext() ? dbIter.next() : null;
            }
        }
        
        // 处理结果
        processReconciliationResult(bucketName, report);
        return report;
    }
    
    private void processReconciliationResult(String bucket, ReconciliationReport report) {
        // 孤儿文件 → 自动注册并标记为 ORPHANED
        for (OrphanFile orphan : report.getOrphansInStorage()) {
            resourceMapper.insertOrphanRecord(bucket, orphan);
        }
        
        // 悬空引用 → 标记为 CORRUPTED，通知运维
        for (DanglingRef ref : report.getMissingInStorage()) {
            resourceMapper.updateStatus(ref.getResourceId(), "CORRUPTED", "FILE_MISSING_IN_STORAGE");
            alertService.sendAlert("DANGLING_STORAGE_REFERENCE",
                String.format("Resource %d (%s) missing in bucket %s", 
                    ref.getResourceId(), ref.getResourceKey(), bucket));
        }
        
        // 大小不一致 → 记录并告警
        if (!report.getInconsistencies().isEmpty()) {
            alertService.sendAlert("STORAGE_SIZE_INCONSISTENCY",
                report.getInconsistencies().size() + " resources have size mismatch");
        }
    }
}
```

| STORAGE_001 | 500 | 资源注册失败 | 检查对象存储连通性 |
| STORAGE_002 | 404 | 资源不存在 | 确认 resourceId 正确 |
| STORAGE_003 | 409 | 资源已被标记删除 | 不可重复操作 |
| STORAGE_004 | 403 | 无权限操作此资源 | 检查 ownerId 匹配 |
| STORAGE_005 | 423 | 资源处于宽限期，暂不可删除 | 等待宽限期结束 |
| STORAGE_006 | 500 | 对象存储删除失败 | 检查 OSS SDK 配置和权限 |
| STORAGE_007 | 500 | CDN 刷新失败 | 不影响主流程，记录日志 |
| STORAGE_008 | 429 | 清理任务并发数超限 | 等待当前任务完成 |
| STORAGE_009 | 500 | 合规删除失败 | 紧急告警，人工介入 |
| STORAGE_010 | 500 | 对账检测到数据不一致 | 人工核查并修复 |

### 10.2 降级策略

```java
@Component
public class StorageLifecycleFallbackHandler {

    /**
     * 对象存储不可用时的降级处理
     */
    public void handleStorageUnavailable(StorageResource resource) {
        // 1. 标记资源为待删除状态
        resourceMapper.updateStatus(resource.getId(), "PENDING_DELETE", "STORAGE_UNAVAILABLE");
        
        // 2. 加入重试队列
        retryQueue.offer(new DeleteRetryMessage(resource.getId(), 
            Instant.now().plus(Duration.ofHours(1))));
        
        // 3. 不影响业务主流程，仅记录日志
        log.warn("Storage temporarily unavailable, resource {} queued for retry", 
            resource.getId());
    }

    /**
     * 引用追踪服务不可用时的降级
     */
    public void handleReferenceServiceDown(Long resourceId, String action) {
        // 写入本地事件表，待服务恢复后补偿
        eventStore.save(new ReferenceEvent(resourceId, action, 
            LocalDateTime.now(), "PENDING_COMPENSATION"));
    }
}
```

### 12.2 业务接入示例

```java
// === 拍题服务接入示例 ===

@Service
public class PhotoQuestionService {

    @Autowired
    private OssClient ossClient;
    
    @Autowired
    private StorageLifecycleClient storageClient;

    public QuestionResult uploadAndProcess(MultipartFile file, Long userId) {
        // 1. 上传文件到 OSS
        String ossKey = generateOssKey("question/capture", userId);
        String ossUrl = ossClient.upload(file, ossKey);

        // 2. 注册到生命周期管理系统（关键步骤！）
        Long resourceId = storageClient.register(StorageRegisterRequest.builder()
            .resourceKey(ossKey)
            .resourceUrl(ossUrl)
            .storageType("OSS")
            .bucketName("primetop-private")
            .fileSize(file.getSize())
            .mimeType(file.getContentType())
            .md5Hash(DigestUtils.md5Hex(file.getInputStream()))
            .businessModule("QUESTION_IMAGE")
            .ownerType("USER")
            .ownerId(userId)
            .retentionPolicy("TTL")
            .expireAt(LocalDateTime.now().plusDays(90))
            .build());

        // 3. OCR 识别 + 题目匹配（业务逻辑）
        QuestionResult result = ocrAndMatch(ossUrl);

        // 4. 绑定资源引用
        storageClient.bindReference(resourceId, StorageReference.builder()
            .refEntityType("QUESTION_RECORD")
            .refEntityId(result.getQuestionId())
            .refField("capture_image_url")
            .build());

        return result;
    }
}
```

### 12.3 拦截器自动注册（推荐方案）

```java
/**
 * MyBatis 拦截器：自动追踪包含资源 URL 的字段变更
 * 当业务表 INSERT/UPDATE/DELETE 含 *_url 字段时，
 * 自动维护 storage_reference 关系
 */
@Intercepts({
    @Signature(type = Executor.class, method = "update", 
               args = {MappedStatement.class, Object.class})
})
@Component
public class StorageReferenceInterceptor implements Interceptor {

    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        MappedStatement ms = (MappedStatement) invocation.getArgs()[0];
        Object parameter = invocation.getArgs()[1];
        String sqlId = ms.getId();
        
        // 解析 SQL 类型
        SqlCommandType sqlType = ms.getSqlCommandType();
        
        // 检测字段中的 URL
        List<UrlFieldEntry> urlFields = extractUrlFields(parameter);
        
        Object result = invocation.proceed();
        
        // 异步维护引用关系
        if (!urlFields.isEmpty()) {
            eventPublisher.publishEvent(new UrlFieldChangeEvent(
                sqlType, sqlId, parameter, urlFields));
        }
        
        return result;
    }
}
```

### 17.3 名词解释

| --- | --- |
