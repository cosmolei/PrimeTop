# 客户端-学习内容阅读器内即时练习嵌入与上下文感知知识检测引擎-详细设计

## 1. 概述

### 1.1 功能定位

本模块为 PrimeTop 学习内容阅读器提供**内嵌即时练习**能力。当学生在阅读教材章节、知识点讲解、学习笔记等内容时，系统在内容流中智能插入微型练习题（选择题、填空题、判断题等），实现"边读边练"的沉浸式学习体验。

**与已有模块的区别：**

| 已有模块 | 覆盖范围 | 本模块差异 |
| --- | --- | --- |
| 互动练习与即时反馈引擎 | 独立练习页面的练习流程 | 专注于阅读器内嵌的流式微练习 |
| AI辅导对话嵌入式即时练习 | AI对话过程中的理解度检测 | 专注于非对话类学习内容（教材、讲解、笔记） |
| 互动课件编排引擎 | 可交互课件的编排与渲染 | 专注于普通阅读内容中的轻量级嵌入 |
| 题目展示与答题交互组件库 | 通用题目展示框架 | 专注于阅读器上下文中的嵌入式渲染与场景化触发 |

### 1.2 设计目标

1. **无缝嵌入**：练习组件作为内容流的一部分自然出现，不打断阅读节奏
2. **上下文感知**：根据当前阅读内容的知识点、难度和学生状态智能选题
3. **轻量交互**：每道嵌入练习控制在 30-90 秒内完成，避免认知过载
4. **即时反馈**：作答后立即给出解析，强化"阅读→理解→确认"的学习闭环
5. **数据驱动**：收集阅读过程中的理解度数据，反馈给推荐引擎和学情分析

### 1.3 适用场景

| 场景 | 示例 |
| --- | --- |
| 教材同步学习 | 阅读数学"二次函数"章节时，在关键概念后插入概念辨析选择题 |
| 知识点讲解 | AI 生成的物理"牛顿第二定律"讲解中，公式推导后插入计算填空题 |
| 考点复习 | 浏览化学"氧化还原反应"考点时，在重点结论后插入判断题 |
| 课文阅读 | 语文古诗文阅读中，在注释后插入词义理解选择题 |
| 错题订正回顾 | 查看错题解析时，在解析步骤后插入同类变式题 |

### 2.2 核心组件职责

| 组件 | 职责 |
| --- | --- |
| **练习插槽管理器** (ExerciseSlotManager) | 管理内容中练习插入点的注册、生命周期和可见性 |
| **上下文分析器** (ContextAnalyzer) | 分析当前阅读内容的知识点、难度、段落语义，确定最佳插入位置 |
| **练习渲染器** (ExerciseRenderer) | 将不同题型的练习组件渲染到内容流中 |
| **反馈与解析模块** (FeedbackModule) | 处理学生作答后的即时反馈、解析展示和后续动作 |
| **阅读进度管理器** (ReadingProgressTracker) | 追踪阅读位置、停留时长，触发上下文练习 |
| **数据采集层** (BehaviorCollector) | 收集练习作答行为数据并上报 |

## 3. 数据结构定义

### 3.1 练习插槽 (ExerciseSlot)

练习插槽是内容流中预留的练习插入点，由服务端在内容生产阶段标注，或由客户端上下文分析器动态创建。

```typescript
/**
 * 练习插槽定义
 */
interface ExerciseSlot {
  /** 插槽唯一ID */
  slotId: string;
  /** 所属内容ID（章节/讲解/笔记） */
  contentId: string;
  /** 在内容中的锚点位置 */
  anchor: ContentAnchor;
  /** 插槽类型：预置(服务端标注) | 动态(客户端生成) */
  slotType: 'preset' | 'dynamic';
  /** 关联知识点列表 */
  knowledgePointIds: string[];
  /** 推荐难度等级 1-5 */
  difficultyLevel: number;
  /** 插入策略 */
  insertStrategy: InsertStrategy;
  /** 插槽状态 */
  status: SlotStatus;
  /** 创建时间 */
  createdAt: string;
  /** 最后更新时间 */
  updatedAt: string;
}

/**
 * 内容锚点 - 定位练习在内容流中的位置
 */
interface ContentAnchor {
  /** 锚定方式 */
  type: 'paragraph' | 'section' | 'heading' | 'position';
  /** 目标段落/标题的索引或ID */
  targetId?: string;
  /** 段落序号（从0开始） */
  paragraphIndex?: number;
  /** 字符偏移量（精细定位） */
  charOffset?: number;
  /** 相对位置：段落前/段落后/段落中间 */
  position: 'before' | 'after' | 'inline';
}

/**
 * 插入策略
 */
interface InsertStrategy {
  /** 触发条件 */
  trigger: 'on_reach' | 'on_scroll' | 'on_time' | 'on_mark';
  /** 是否需要学生确认才显示题目 */
  requireUserGesture: boolean;
  /** 最小阅读停留时长（毫秒），达到后才触发 */
  minReadDurationMs?: number;
  /** 折叠状态：默认折叠还是展开 */
  defaultCollapsed: boolean;
  /** 出现动画类型 */
  animation: 'slide' | 'fade' | 'expand' | 'none';
}

type SlotStatus = 
  | 'pending'      // 待触发
  | 'active'       // 已激活，等待作答
  | 'answered'     // 已作答
  | 'skipped'      // 已跳过
  | 'collapsed';   // 已折叠
```

### 3.2 嵌入式练习 (InlineExercise)

```typescript
/**
 * 嵌入式练习定义
 */
interface InlineExercise {
  /** 练习唯一ID */
  exerciseId: string;
  /** 来源插槽ID */
  slotId: string;
  /** 题目内容 */
  question: QuestionContent;
  /** 题型 */
  questionType: InlineQuestionType;
  /** 解析内容 */
  explanation: ExplanationContent;
  /** 预计完成时长（秒） */
  estimatedDurationSec: number;
  /** 关联知识点 */
  knowledgePointIds: string[];
  /** 难度等级 1-5 */
  difficulty: number;
  /** 做错后的提示策略 */
  hintStrategy: HintStrategy;
  /** 后续动作 */
  followUpActions: FollowUpAction[];
}

/**
 * 支持的内嵌题型
 */
type InlineQuestionType = 
  | 'single_choice'    // 单选题（最常用）
  | 'true_false'       // 判断题
  | 'fill_blank'       // 填空题
  | 'multi_choice'     // 多选题
  | 'sort_order'       // 排序题
  | 'match_pairs';     // 连线匹配题

/**
 * 题目内容
 */
interface QuestionContent {
  /** 题干（支持富文本和LaTeX） */
  stem: string;
  /** 选项列表（选择题） */
  options?: QuestionOption[];
  /** 填空位（填空题） */
  blanks?: FillBlank[];
  /** 正确答案 */
  correctAnswer: Answer;
  /** 题目配图URL */
  imageUrl?: string;
  /** 题目附带的公式LaTeX */
  formulas?: string[];
}

interface QuestionOption {
  key: string;         // 'A', 'B', 'C', 'D'
  text: string;        // 选项文本
  imageUrl?: string;   // 选项配图
}

/**
 * 解析内容
 */
interface ExplanationContent {
  /** 简短解析（一句话，反馈时直接展示） */
  brief: string;
  /** 详细解析（分步骤） */
  detailed?: ExplanationStep[];
  /** 知识点回链 */
  relatedKnowledgePoints?: KnowledgePointRef[];
  /** 易错提醒 */
  commonMistake?: string;
}

interface ExplanationStep {
  stepIndex: number;
  text: string;
  formula?: string;
}

/**
 * 提示策略
 */
interface HintStrategy {
  /** 是否启用提示 */
  enabled: boolean;
  /** 提示内容列表（按顺序逐步展示） */
  hints: string[];
  /** 第一次提示触发：答错N次后 */
  triggerAfterWrongCount: number;
}

/**
 * 后续动作定义
 */
interface FollowUpAction {
  actionType: 'continue_reading'    // 继续阅读
    | 'show_similar'                // 展示同类题
    | 'review_knowledge'           // 回顾知识点
    | 'adjust_difficulty'          // 调整后续难度
    | 'add_to_mistake_book';       // 加入错题本
  /** 动作标签（展示给用户的文案） */
  label: string;
  /** 动作图标 */
  icon: string;
  /** 是否自动执行 */
  autoExecute: boolean;
}
```

**详细步骤：**

2. **解析插槽**：`ExerciseSlotManager` 遍历 `exerciseSlots`，为每个插槽：
   - 根据 `anchor` 信息定位内容中的对应位置
   - 创建 `IntersectionObserver` 监听该位置的可见性
   - 注册触发条件（滚动到达 / 停留时长 / 手动触发）
3. **初始化练习渲染器**：预加载题型组件模板，准备渲染
4. **注册阅读进度回调**：`ReadingProgressTracker` 开始追踪段落级阅读进度

```
│              │  - correctRate > 80% │──► 提升难度        │
│              │  - correctRate < 50% │──► 降低难度        │
│              │  - 连续3次错误       │──► 暂停插入        │
│              │  - 作答过快(<5s)    │──► 可能猜答案      │
│              └──────────────────────┘                   │
└─────────────────────────────────────────────────────────┘
```

**调节规则：**

| 条件 | 动作 | 说明 |
| --- | --- | --- |
| 连续答对 ≥ 3 题 | 难度 +1 | 最大不超过学生当前能力 +2 |
| 连续答错 ≥ 2 题 | 难度 -1 | 最小不低于学生当前能力 -2 |
| 单题作答 < 5 秒且答对 | 标记可能猜对 | 降低置信度，不提升难度 |
| 单题作答 > 120 秒 | 标记犹豫 | 可能题目过难，降低下一题难度 |
| 连续错误 ≥ 3 题 | 暂停插入练习 5 分钟 | 避免挫败感，让用户专注阅读 |
| 本次会话正确率 > 80% 且已答 ≥ 5 题 | 减少后续练习频率 | 避免过多打扰 |
| 本次会话正确率 < 40% 且已答 ≥ 5 题 | 增加基础概念题 | 回归基础巩固 |

### 6.1 Flutter 练习插槽管理器

```dart
/// 练习插槽管理器
/// 负责管理阅读器中所有练习插槽的注册、触发和生命周期
class ExerciseSlotManager {
  final Map<String, ExerciseSlot> _slots = {};
  final Map<String, InlineExerciseWidget> _activeWidgets = {};
  final ReadingProgressTracker _progressTracker;
  final ExerciseApiClient _apiClient;
  final AdaptiveDifficultyController _difficultyController;

  /// 插槽状态变更通知
  final StreamController<SlotEvent> _eventController =
      StreamController<SlotEvent>.broadcast();
  Stream<SlotEvent> get onSlotEvent => _eventController.stream;

  ExerciseSlotManager({
    required ReadingProgressTracker progressTracker,
    required ExerciseApiClient apiClient,
    required AdaptiveDifficultyController difficultyController,
  })  : _progressTracker = progressTracker,
        _apiClient = apiClient,
        _difficultyController = difficultyController;

  /// 注册练习插槽
  Future<void> registerSlots(
    String contentId,
    List<ExerciseSlot> slots,
    String studentId,
  ) async {
    for (final slot in slots) {
      _slots[slot.slotId] = slot;

      // 根据锚点类型设置触发监听
      _setupTrigger(contentId, slot, studentId);
    }
  }

  /// 设置插槽触发条件
  void _setupTrigger(
    String contentId,
    ExerciseSlot slot,
    String studentId,
  ) {
    final anchor = slot.anchor;
    final strategy = slot.insertStrategy;

    // 监听阅读器滚动到锚点位置
    _progressTracker.onParagraphVisible(
      contentId: contentId,
      paragraphId: anchor.targetId ?? '',
      paragraphIndex: anchor.paragraphIndex ?? 0,
      onVisible: (ReadContext context) {
        // 检查最小阅读停留时长
        if (strategy.minReadDurationMs != null &&
            context.readDurationMs < strategy.minReadDurationMs!) {
          // 延迟触发
          Future.delayed(
            Duration(milliseconds: strategy.minReadDurationMs! - context.readDurationMs),
            () => _tryActivate(slot, studentId),
          );
        } else {
          _tryActivate(slot, studentId);
        }
      },
    );
  }

  /// 尝试激活插槽
  Future<void> _tryActivate(
    ExerciseSlot slot,
    String studentId,
  ) async {
    if (slot.status != SlotStatus.pending) return;

    // 检查自适应控制器是否允许插入
    if (!_difficultyController.shouldInsertExercise()) {
      _difficultyController.scheduleRetry(slot);
      return;
    }

    // 检查频率限制（避免连续插入太多练习）
    if (_isRateLimited()) {
      debugPrint('[ExerciseSlot] Rate limited, deferring slot ${slot.slotId}');
      return;
    }

    _updateSlotStatus(slot, SlotStatus.active);
    _eventController.add(SlotEvent.activated(slot.slotId));
  }

  /// 用户作答完成
  Future<void> onExerciseAnswered(
    String slotId, {
    required String exerciseId,
    required Answer answer,
    required int durationMs,
    required bool usedHints,
  }) async {
    final slot = _slots[slotId];
    if (slot == null) return;

    // 提交到服务端
    final result = await _apiClient.submitAnswer(
      exerciseId: exerciseId,
      slotId: slotId,
      studentAnswer: answer,
      durationMs: durationMs,
      usedHints: usedHints,
      readingContext: _progressTracker.currentContext,
    );

    // 更新自适应难度
    _difficultyController.recordResult(
      isCorrect: result.isCorrect,
      durationMs: durationMs,
    );

    _updateSlotStatus(slot, SlotStatus.answered);
    _eventController.add(SlotEvent.answered(
      slot.slotId,
      result.isCorrect,
      result.explanation,
    ));
  }

  /// 用户跳过练习
  Future<void> onExerciseSkipped(
    String slotId, {
    required String reason,
  }) async {
    final slot = _slots[slotId];
    if (slot == null) return;

    await _apiClient.reportSkip(
      slotId: slotId,
      exerciseId: slot.exerciseId,
      reason: reason,
    );

    _difficultyController.recordSkip(reason);
    _updateSlotStatus(slot, SlotStatus.skipped);
    _eventController.add(SlotEvent.skipped(slot.slotId, reason));
  }

  bool _isRateLimited() {
    final now = DateTime.now();
    final recentActivations = _slots.values.where((s) =>
        s.status == SlotStatus.active &&
        now.difference(s.updatedAt).inSeconds < 60);
    // 每分钟最多激活 1 个练习
    return recentActivations.length >= 1;
  }

  void _updateSlotStatus(ExerciseSlot slot, SlotStatus status) {
    slot.status = status;
    slot.updatedAt = DateTime.now();
  }

  void dispose() {
    _eventController.close();
    _slots.clear();
    _activeWidgets.clear();
  }
}
```

```dart
/// 自适应难度控制器
/// 根据学生的实时作答表现动态调整后续练习的难度和频率
class AdaptiveDifficultyController {
  final AdaptiveConfig _config;
  final List<ExerciseResult> _recentResults = [];
  int _currentDifficulty;
  int _consecutiveCorrect = 0;
  int _consecutiveWrong = 0;
  bool _isPaused = false;
  DateTime? _pauseUntil;

  AdaptiveDifficultyController({
    required AdaptiveConfig config,
    required int initialDifficulty,
  })  : _config = config,
        _currentDifficulty = initialDifficulty;

  /// 记录一次作答结果
  void recordResult({
    required bool isCorrect,
    required int durationMs,
  }) {
    final result = ExerciseResult(
      isCorrect: isCorrect,
      durationMs: durationMs,
      timestamp: DateTime.now(),
    );
    _recentResults.add(result);

    // 更新连续计数
    if (isCorrect) {
      _consecutiveCorrect++;
      _consecutiveWrong = 0;
    } else {
      _consecutiveWrong++;
      _consecutiveCorrect = 0;
    }

    // 自适应调节
    _adjustDifficulty(isCorrect, durationMs);

    // 检查是否需要暂停
    _checkPauseCondition();
  }

  void _adjustDifficulty(bool isCorrect, int durationMs) {
    if (isCorrect) {
      // 连续答对提升难度
      if (_consecutiveCorrect >= 3) {
        _currentDifficulty = (_currentDifficulty + 1).clamp(1, 5);
        _consecutiveCorrect = 0;
      }

      // 答对但过快（可能猜的），不提升难度
      if (durationMs < 5000) {
        // 不重置连续计数，但不触发难度提升
        debugPrint('[Adaptive] Fast correct answer, not increasing difficulty');
      }
    } else {
      // 连续答错降低难度
      if (_consecutiveWrong >= 2) {
        _currentDifficulty = (_currentDifficulty - 1).clamp(1, 5);
        _consecutiveWrong = 0;
      }

      // 作答时间过长，额外降低难度
      if (durationMs > 120000) {
        _currentDifficulty = (_currentDifficulty - 1).clamp(1, 5);
      }
    }
  }

  void _checkPauseCondition() {
    // 连续错误超过阈值，暂停插入练习
    if (_consecutiveWrong >= _config.maxConsecutiveWrong) {
      _isPaused = true;
      _pauseUntil = DateTime.now().add(const Duration(minutes: 5));
      debugPrint('[Adaptive] Paused due to consecutive wrong answers');
    }

    // 会话内练习过多且正确率高，减少频率
    if (_recentResults.length >= 5) {
      final correctRate = _recentResults.lastN(5).where((r) => r.isCorrect).length / 5;
      if (correctRate > _config.targetCorrectRate + 0.2) {
        // 正确率过高，可能题目太简单，减少频率避免无效练习
        _isPaused = true;
        _pauseUntil = DateTime.now().add(const Duration(minutes: 3));
      }
    }
  }

  /// 是否应该插入新练习
  bool shouldInsertExercise() {
    if (_isPaused) {
      if (_pauseUntil != null && DateTime.now().isAfter(_pauseUntil!)) {
        _isPaused = false;
        _pauseUntil = null;
        _consecutiveWrong = 0; // 重置
      } else {
        return false;
      }
    }
    return true;
  }

  int get currentDifficulty => _currentDifficulty;

  /// 获取本次会话统计
  SessionStats getStats() {
    if (_recentResults.isEmpty) {
      return SessionStats(total: 0, correct: 0, correctRate: 0, avgDurationMs: 0);
    }
    final correct = _recentResults.where((r) => r.isCorrect).length;
    final avgDuration = _recentResults.map((r) => r.durationMs).reduce((a, b) => a + b) ~/
        _recentResults.length;
    return SessionStats(
      total: _recentResults.length,
      correct: correct,
      correctRate: correct / _recentResults.length,
      avgDurationMs: avgDuration,
    );
  }
}

@immutable
class AdaptiveConfig {
  final double targetCorrectRate;
  final int maxConsecutiveWrong;
  final double difficultyAdjustSensitivity;
  final int pauseInsertAfterNWrong;

  const AdaptiveConfig({
    this.targetCorrectRate = 0.7,
    this.maxConsecutiveWrong = 3,
    this.difficultyAdjustSensitivity = 0.15,
    this.pauseInsertAfterNWrong = 2,
  });
}
```

```dart
        widget.exercise.question.correctAnswer.selectedOption;

    setState(() {
      _hasAnswered = true;
      _isCorrect = isCorrect;
      _showExplanation = true;
    });

    if (!isCorrect) {
      _wrongCount++;
      // 检查是否可以重试或显示提示
      if (widget.exercise.hintStrategy.enabled &&
          _wrongCount >= widget.exercise.hintStrategy.triggerAfterWrongCount &&
          _hintIndex < widget.exercise.hintStrategy.hints.length) {
        setState(() {
          _showHint = true;
        });
        // 允许重试
        setState(() {
          _hasAnswered = false;
          _selectedAnswer = null;
        });
        _stopwatch.start();
        return;
      }
    }

    // 最终提交
    widget.onAnswered(answer, durationMs, _showHint);
  }
```

```dart
/// 内嵌练习 BLoC
/// 管理阅读器内嵌练习的整体状态和事件流转
class InlineExerciseBloc extends Bloc<InlineExerciseEvent, InlineExerciseState> {
  final ExerciseSlotManager _slotManager;
  final ExerciseApiClient _apiClient;
  final AdaptiveDifficultyController _difficultyController;
  final BehaviorCollector _behaviorCollector;

  InlineExerciseBloc({
    required ExerciseSlotManager slotManager,
    required ExerciseApiClient apiClient,
    required AdaptiveDifficultyController difficultyController,
    required BehaviorCollector behaviorCollector,
  })  : _slotManager = slotManager,
        _apiClient = apiClient,
        _difficultyController = difficultyController,
        _behaviorCollector = behaviorCollector,
        super(InlineExerciseInitial()) {
    on<LoadInlineExercises>(_onLoadExercises);
    on<SlotActivated>(_onSlotActivated);
    on<ExerciseAnswered>(_onExerciseAnswered);
    on<ExerciseSkipped>(_onExerciseSkipped);
    on<RequestSimilarExercise>(_onRequestSimilar);
    on<BatchReportEvents>(_onBatchReport);
    on<DisposeInlineExercises>(_onDispose);

    // 监听插槽事件
    _slotManager.onSlotEvent.listen((event) {
      switch (event.type) {
        case SlotEventType.activated:
          add(SlotActivated(event.slotId));
          break;
        case SlotEventType.answered:
          // 已在 onExerciseAnswered 中处理
          break;
        case SlotEventType.skipped:
          // 已在 onExerciseSkipped 中处理
          break;
      }
    });
  }

  /// 加载内容关联的练习
  Future<void> _onLoadExercises(
    LoadInlineExercises event,
    Emitter<InlineExerciseState> emit,
  ) async {
    emit(InlineExerciseLoading());

    try {
      final response = await _apiClient.fetchInlineExercises(
        contentId: event.contentId,
        studentId: event.studentId,
        grade: event.grade,
        subject: event.subject,
        maxExercises: event.maxExercises,
      );

      // 初始化自适应控制器
      _difficultyController.initialize(
        initialDifficulty: response.adaptiveConfig.initialDifficulty,
        config: AdaptiveConfig.fromJson(response.adaptiveConfig),
      );

      // 注册插槽
      await _slotManager.registerSlots(
        event.contentId,
        response.exercises.map((e) => ExerciseSlot.fromDto(e)).toList(),
        event.studentId,
      );

      emit(InlineExerciseReady(
        exercises: response.exercises,
        adaptiveConfig: response.adaptiveConfig,
      ));
    } catch (e) {
      emit(InlineExerciseError(message: '练习加载失败: $e'));
      // 降级：不阻塞阅读，仅记录日志
      _behaviorCollector.logError('inline_exercise_load_failed', e.toString());
    }
  }

  /// 插槽激活
  void _onSlotActivated(
    SlotActivated event,
    Emitter<InlineExerciseState> emit,
  ) {
    _behaviorCollector.collect(SlotTriggeredEvent(
      slotId: event.slotId,
      timestamp: DateTime.now(),
    ));
    emit(SlotActive(slotId: event.slotId));
  }

  /// 作答完成
  Future<void> _onExerciseAnswered(
    ExerciseAnswered event,
    Emitter<InlineExerciseState> emit,
  ) async {
    // 交给插槽管理器处理
    await _slotManager.onExerciseAnswered(
      event.slotId,
      exerciseId: event.exerciseId,
      answer: event.answer,
      durationMs: event.durationMs,
      usedHints: event.usedHints,
    );

    // 收集行为数据
    _behaviorCollector.collect(ExerciseAnsweredEvent(
      slotId: event.slotId,
      exerciseId: event.exerciseId,
      isCorrect: event.isCorrect,
      durationMs: event.durationMs,
      timestamp: DateTime.now(),
    ));

    emit(ExerciseCompleted(
      slotId: event.slotId,
      isCorrect: event.isCorrect,
      nextDifficulty: _difficultyController.currentDifficulty,
      stats: _difficultyController.getStats(),
    ));
  }

  /// 跳过练习
  Future<void> _onExerciseSkipped(
    ExerciseSkipped event,
    Emitter<InlineExerciseState> emit,
  ) async {
    await _slotManager.onExerciseSkipped(
      event.slotId,
      reason: event.reason,
    );

    _behaviorCollector.collect(ExerciseSkippedEvent(
      slotId: event.slotId,
      reason: event.reason,
      timestamp: DateTime.now(),
    ));

    emit(ExerciseSkippedState(slotId: event.slotId, reason: event.reason));
  }

  /// 请求同类替换题
  Future<void> _onRequestSimilar(
    RequestSimilarExercise event,
    Emitter<InlineExerciseState> emit,
  ) async {
    emit(SimilarExerciseLoading(slotId: event.slotId));

    try {
      final newExercise = await _apiClient.requestReplacement(
        contentId: event.contentId,
        previousExerciseId: event.previousExerciseId,
        targetDifficulty: _difficultyController.currentDifficulty,
        knowledgePointIds: event.knowledgePointIds,
        excludeIds: [event.previousExerciseId],
      );

      emit(SimilarExerciseReady(
        slotId: event.slotId,
        exercise: newExercise,
      ));
    } catch (e) {
      emit(SimilarExerciseError(slotId: event.slotId, message: e.toString()));
    }
  }

  /// 批量上报（弱网恢复后）
  Future<void> _onBatchReport(
    BatchReportEvents event,
    Emitter<InlineExerciseState> emit,
  ) async {
    try {
      await _apiClient.batchReport(event.events);
      _behaviorCollector.clearBuffer();
    } catch (e) {
      // 上报失败保留在本地缓冲区，下次重试
      debugPrint('[InlineExercise] Batch report failed: $e');
    }
  }

  Future<void> _onDispose(
    DisposeInlineExercises event,
    Emitter<InlineExerciseState> emit,
  ) async {
    // 批量上报剩余数据
    final buffered = _behaviorCollector.flushBuffer();
    if (buffered.isNotEmpty) {
      await _apiClient.batchReport(buffered);
    }
    _slotManager.dispose();
    emit(InlineExerciseInitial());
  }
}
```

在内容生产阶段，系统自动为学习内容标注练习插入点。

```python
"""
内容练习插槽预标注服务
在内容审核通过后自动运行，为内容生成练习插入位置建议
"""

class ContentExerciseSlotAnnotator:
    """自动标注内容中的练习插入点"""

    # 插入点识别规则
    SLOT_PATTERNS = {
        # 关键概念定义后插入概念辨析题
        'concept_definition': {
            'pattern': r'(定义|是指|表示|叫做|概念)[。：]',
            'exercise_type': 'single_choice',
            'position': 'after',
            'priority': 'high',
        },
        # 公式/定理后插入应用计算题
        'formula_theorem': {
            'pattern': r'(\$+[^$]+\$+|公式|定理|推论)[。.\n]',
            'exercise_type': 'fill_blank',
            'position': 'after',
            'priority': 'high',
        },
        # 重要结论后插入判断题
        'key_conclusion': {
            'pattern': r'(因此|所以|综上|结论|总结)[：:]',
            'exercise_type': 'true_false',
            'position': 'after',
            'priority': 'medium',
        },
        # 章节标题前插入回顾题
        'section_start': {
            'pattern': r'^#{2,3}\s',
            'exercise_type': 'single_choice',
            'position': 'before',
            'priority': 'low',
        },
    }

    # 插入密度控制
    MAX_SLOTS_PER_1000_CHARS = 3  # 每1000字最多3个练习
    MIN_DISTANCE_BETWEEN_SLOTS = 300  # 两个练习间最少300字
    MAX_SLOTS_PER_CONTENT = 10  # 单篇内容最多10个练习

    def annotate(self, content: LearningContent) -> List[ExerciseSlot]:
        """为内容生成练习插槽标注"""
        blocks = content.body
        slots = []
        last_slot_char_pos = -self.MIN_DISTANCE_BETWEEN_SLOTS
        char_count = 0

        for i, block in enumerate(blocks):
            if block.blockType not in ('paragraph', 'heading'):
                char_count += len(block.text or '')
                continue

            text = block.text or ''
            block_kp_ids = block.knowledgePointIds or []

            # 检查是否匹配插入模式
            for pattern_name, pattern_config in self.SLOT_PATTERNS.items():
                import re
                matches = list(re.finditer(pattern_config['pattern'], text))

                for match in matches:
                    slot_char_pos = char_count + match.end()

                    # 密度控制
                    if (slot_char_pos - last_slot_char_pos 
                            < self.MIN_DISTANCE_BETWEEN_SLOTS):
                        continue

                    if (len(slots) >= self.MAX_SLOTS_PER_CONTENT):
                        break

                    # 生成插槽
                    slot = ExerciseSlot(
                        slotId=f"slot_{content.contentId}_{len(slots)+1:03d}",
                        contentId=content.contentId,
                        anchor=ContentAnchor(
                            type='paragraph',
                            targetId=block.blockId,
                            paragraphIndex=i,
                            position=pattern_config['position'],
                        ),
                        slotType='preset',
                        knowledgePointIds=block_kp_ids,
                        difficultyLevel=self._estimate_difficulty(
                            block, content.targetGrade
                        ),
                        insertStrategy=InsertStrategy(
                            trigger='on_reach',
                            requireUserGesture=pattern_config['priority'] == 'low',
                            minReadDurationMs=10000 if pattern_config['priority'] == 'high' else 5000,
                            defaultCollapsed=pattern_config['priority'] == 'low',
                            animation='slide',
                        ),
                        status='pending',
                        createdAt=datetime.utcnow(),
                        updatedAt=datetime.utcnow(),
                    )
                    slots.append(slot)
                    last_slot_char_pos = slot_char_pos

            char_count += len(text)

        # 密度全局检查
        if len(slots) > self.MAX_SLOTS_PER_1000_CHARS * (char_count / 1000):
            # 按优先级裁剪
            slots = self._prune_by_priority(slots, char_count)

        return slots

    def _estimate_difficulty(self, block: ContentBlock, grade: str) -> int:
        """根据段落难度系数估算练习难度"""
        base_difficulty = block.difficultyScore or 0.5
        # 映射 0-1 到 1-5
        difficulty = max(1, min(5, round(base_difficulty * 5)))
        return difficulty

    def _prune_by_priority(self, slots: List[ExerciseSlot], 
                            total_chars: int) -> List[ExerciseSlot]:
        """按优先级裁剪插槽"""
        max_slots = int(self.MAX_SLOTS_PER_1000_CHARS * (total_chars / 1000))
        max_slots = min(max_slots, self.MAX_SLOTS_PER_CONTENT)

        # 高优先级保留，低优先级移除
        priority_order = {'high': 0, 'medium': 1, 'low': 2}
        slots.sort(key=lambda s: priority_order.get(
            'high' if not s.insertStrategy.requireUserGesture else 'low', 2))
        return slots[:max_slots]
```

```python
"""
内嵌练习题目匹配服务
根据插槽上下文和学生状态匹配最合适的练习题
"""

class InlineExerciseMatcher:
    """为学生匹配内嵌练习题"""

    def __init__(
        self,
        question_repo: QuestionRepository,
        knowledge_service: KnowledgePointService,
        student_profile: StudentProfileService,
    ):
        self.question_repo = question_repo
        self.knowledge_service = knowledge_service
        self.student_profile = student_profile

    async def match_exercises_for_content(
        self,
        content_id: str,
        slots: List[ExerciseSlot],
        student_id: str,
        config: AdaptiveConfig,
    ) -> List[InlineExercise]:
        """为每个插槽匹配练习题"""
        # 获取学生画像
        profile = await self.student_profile.get_profile(student_id)

        # 获取学生最近做过的题目（避免重复推荐）
        recent_question_ids = await self.question_repo.get_recent_answered(
            student_id, limit=100
        )

        exercises = []
        for slot in slots:
            # 根据插槽和上下文选题
            exercise = await self._match_single_slot(
                slot=slot,
                profile=profile,
                recent_ids=recent_question_ids,
                config=config,
            )
            if exercise:
                exercises.append(exercise)
                recent_question_ids.append(exercise.exerciseId)

        return exercises

    async def _match_single_slot(
        self,
        slot: ExerciseSlot,
        profile: StudentProfile,
        recent_ids: List[str],
        config: AdaptiveConfig,
    ) -> Optional[InlineExercise]:
        """为单个插槽匹配题目"""
        # 1. 计算目标难度
        target_difficulty = self._calc_target_difficulty(
            slot.difficultyLevel,
            profile.ability_level,
            config,
        )

        # 2. 多路召回候选题目
        candidates = await self._recall_candidates(
            knowledge_point_ids=slot.knowledgePointIds,
            difficulty=target_difficulty,
            exclude_ids=recent_ids,
            grade=profile.grade,
            subject=profile.subject,
            textbook_version=profile.textbook_version,
        )

        if not candidates:
            logger.warning(
                f"No candidates found for slot {slot.slotId}, "
                f"kp_ids={slot.knowledgePointIds}"
            )
            return None

        # 3. 精细排序
        ranked = self._rank_candidates(candidates, profile, slot)

        # 4. 选择最佳题目
        best = ranked[0]

        # 5. 构建内嵌练习对象
        return self._build_inline_exercise(best, slot)

    def _calc_target_difficulty(
        self, slot_difficulty: int, ability: float, config: AdaptiveConfig
    ) -> int:
        """基于插槽难度和学生能力计算目标难度"""
        # 能力值（0-5）映射到难度
        ability_difficulty = round(ability * 1.0)

        # 加权平均：插槽难度权重 0.4，学生能力权重 0.6
        weighted = slot_difficulty * 0.4 + ability_difficulty * 0.6
        return max(1, min(5, round(weighted)))

    async def _recall_candidates(
        self,
        knowledge_point_ids: List[str],
        difficulty: int,
        exclude_ids: List[str],
        grade: str,
        subject: str,
        textbook_version: str,
    ) -> List[Question]:
        """多路召回候选题目"""
        candidates = []

        # 路1：知识点精确匹配
        exact = await self.question_repo.search(
            knowledge_point_ids=knowledge_point_ids,
            difficulty_range=(difficulty - 1, difficulty + 1),
            grade=grade,
            subject=subject,
            textbook_version=textbook_version,
            exclude_ids=exclude_ids,
            limit=20,
        )
        candidates.extend(exact)

        # 路2：同章节题目扩展
        chapter_questions = await self.question_repo.search_by_chapter(
            knowledge_point_ids=knowledge_point_ids,
            difficulty=difficulty,
            limit=10,
        )
        candidates.extend(chapter_questions)

        # 去重
        seen = set()
        unique = []
        for q in candidates:
            if q.id not in seen:
                seen.add(q.id)
                unique.append(q)

        return unique

    def _rank_candidates(
        self,
        candidates: List[Question],
        profile: StudentProfile,
        slot: ExerciseSlot,
    ) -> List[Question]:
        """对候选题目排序"""
        def score(q: Question) -> float:
            s = 0.0
            # 难度匹配度
            diff_gap = abs(q.difficulty - slot.difficultyLevel)
            s += (1 - diff_gap / 5) * 40

            # 知识点覆盖度
            overlap = len(
                set(q.knowledge_point_ids) & set(slot.knowledgePointIds)
            )
            s += overlap * 15

            # 题型偏好（短题型更适合嵌入）
            if q.question_type in ('single_choice', 'true_false', 'fill_blank'):
                s += 10

            # 题目质量分
            s += q.quality_score * 20

            # 学生未做过的题目优先（已在recall阶段排除，这里加保护分）

            return s

        return sorted(candidates, key=score, reverse=True)

    def _build_inline_exercise(
        self, question: Question, slot: ExerciseSlot
    ) -> InlineExercise:
        """将题库题目转换为内嵌练习格式"""
        return InlineExercise(
            exerciseId=f"ie_{question.id}",
            slotId=slot.slotId,
            questionType=question.question_type,
            question=QuestionContent(
                stem=question.stem,
                options=question.options,
                correctAnswer=question.correct_answer,
                imageUrl=question.image_url,
            ),
            explanation=ExplanationContent(
                brief=question.brief_explanation,
                detailed=question.detailed_explanation,
                commonMistake=question.common_mistake,
            ),
            estimatedDurationSec=question.estimated_duration_sec or 45,
            difficulty=question.difficulty,
            knowledgePointIds=question.knowledge_point_ids,
            hintStrategy=HintStrategy(
                enabled=True,
                hints=question.hints or [],
                triggerAfterWrongCount=1,
            ),
            followUpActions=self._generate_follow_up_actions(question, slot),
        )

    def _generate_follow_up_actions(
        self, question: Question, slot: ExerciseSlot
    ) -> List[FollowUpAction]:
        """生成后续动作"""
        actions = [
            FollowUpAction(
                actionType='continue_reading',
                label='继续阅读',
                icon='arrow_forward',
                autoExecute=False,
            ),
        ]

        # 如果有同类题，添加"再来一题"
        if question.has_similar:
            actions.append(FollowUpAction(
                actionType='show_similar',
                label='再来一题',
                icon='refresh',
                autoExecute=False,
            ))

        return actions
```

### 8.1 错误码定义

| 错误码 | 场景 | 处理策略 |
| --- | --- | --- |
| `IE_001` | 练习加载失败（网络错误） | 静默降级，不展示内嵌练习，不影响阅读 |
| `IE_002` | 练习题目数据格式异常 | 跳过该插槽，记录异常日志 |
| `IE_003` | 作答提交失败 | 本地缓存，稍后重试上报 |
| `IE_004` | 服务端无匹配题目 | 该位置不展示练习，仅记录知识点空缺 |
| `IE_005` | 题目渲染异常（不支持的题型） | 降级为纯文本展示题干和选项 |
| `IE_006` | LaTeX/公式渲染失败 | 降级展示原始文本，附加"公式加载异常"标记 |

```dart
/// 内嵌练习错误处理器
class InlineExerciseErrorHandler {
  static const _maxRetries = 3;
  static const _retryDelay = Duration(seconds: 2);

  /// 安全执行练习相关操作，失败时降级
  static Future<T?> safeExecute<T>({
    required Future<T> Function() operation,
    required T? Function() fallback,
    int retryCount = 0,
  }) async {
    try {
      return await operation();
    } on NetworkException catch (e) {
      if (retryCount < _maxRetries) {
        await Future.delayed(_retryDelay * (retryCount + 1));
        return safeExecute(
          operation: operation,
          fallback: fallback,
          retryCount: retryCount + 1,
        );
      }
      debugPrint('[IE-Error] Network error after retries: $e');
      return fallback();
    } on DataFormatException catch (e) {
      debugPrint('[IE-Error] Data format error: $e');
      // 数据异常不可重试，直接降级
      return fallback();
    } catch (e) {
      debugPrint('[IE-Error] Unexpected error: $e');
      return fallback();
    }
  }

  /// 判断是否应该完全禁用内嵌练习
  static bool shouldDisableEntirely(InlineExerciseState state) {
    if (state is InlineExerciseError) {
      return state.consecutiveFailures >= 5;
    }
    return false;
  }
}
```

## 13. 版本演进规划

### V1（MVP）

- 支持单选题和判断题两种题型
- 仅在教材同步学习内容中嵌入
- 服务端预置插槽，不支持动态生成
- 基础自适应难度（仅升降级，无暂停）
- 答对/答错简单反馈

### V2

- 支持填空题和多选题
- 扩展到知识点讲解和考点复习场景
- 客户端动态插槽生成（基于上下文分析）
- 完整自适应难度控制（暂停、频率调节）
- 分步解析和提示策略
- 错题本联动

### V3

- 支持排序题和匹配题
- 支持动态生成练习题（AI生成，非纯题库匹配）
- 个性化插入策略（基于学生学习风格）
- 阅读理解度预测模型集成
- 亲子共学模式下的互动练习
