# 服务端 - 学生学习内容理解度检测与知识内化深度评估引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

本引擎负责在学生学习内容（课文讲解、知识点说明、视频课件、微课卡片等）消费完成后，**自动生成嵌入式理解度检测题**，收集学生的理解反馈信号，计算**多维度理解度评分**与**知识内化深度等级**，并将结果输出给知识追踪、推荐、学习规划等下游服务。

### 1.2 核心问题

当前平台的学习链路存在一个关键断点：

```
学生学习内容 → 记录"已完成" → 直接推进到下一节点
```

这个链路假设"看了/读完了 = 学会了"，但实际上学生可能只是快速划过、走马观花，并未真正理解。本引擎将上述链路升级为：

```
学生学习内容 → 嵌入式理解度检测 → 理解度评分 → 内化深度分级
  → 达标：自动推进 + 更新掌握度
  → 未达标：触发重学/补弱/降级内容推荐
  → 理解度衰减：触发主动复习提醒
```

### 1.3 与现有模块的边界

| 现有模块 | 关注点 | 本引擎差异 |
|---------|--------|-----------|
| 知识追踪模型引擎 | 从答题正确率估计知识点掌握度 | 本引擎关注**内容消费后的即时理解**，不依赖正式答题 |
| 互动练习与即时反馈引擎 | 正式练习题的判题与反馈 | 本引擎生成的是**轻量嵌入式检测**，非正式测试 |
| 练习答题行为数据采集 | 答题过程行为追踪 | 本引擎追踪的是**阅读/观看后的认知状态** |
| 教育内容布鲁姆认知层级标注 | 对内容本身的认知深度标注 | 本引擎用布鲁姆框架评估**学生的认知达成度** |
| 学习投入度多维量化 | 学生整体学习投入度 | 本引擎聚焦**单条内容的理解质量** |

### 1.4 设计目标

1. **自动化**：理解度检测题由 AI 自动生成，无需教研人员逐条配置
2. **轻量化**：每条内容 2-5 道检测题，单次检测 < 60 秒，不增加学习负担
3. **多维度**：覆盖布鲁姆认知层级（记忆→理解→应用→分析），而非简单的对错
4. **可演化**：理解度模型随学生数据积累持续校准
5. **低干扰**：嵌入式检测与学习内容自然衔接，避免"考试感"

### 2.3 技术选型

| 组件 | 选型 | 说明 |
|------|------|------|
| 检测题生成 | LLM API (通用模型即可) | Prompt 工程驱动，无需微调 |
| 评分引擎 | 规则引擎 + 轻量 ML 模型 | 初始规则驱动，逐步引入 ML |
| 衰减模型 | 指数衰减 + 个性化半衰期拟合 | 基于遗忘曲线理论 |
| 存储层 | MySQL (结构化) + Redis (缓存) | 检测记录持久化 + 热点缓存 |
| 消息通信 | Kafka / RabbitMQ | 异步事件驱动，解耦下游 |
| 缓存策略 | 内容检测题缓存 (Redis Hash) | 同一内容的多套检测题预生成缓存 |

## 4. 核心算法设计

### 4.1 理解度检测题自动生成

#### 4.1.1 生成策略

系统根据内容类型和知识点，自动生成多层次的检测题：

| 布鲁姆层级 | 检测题型 | 示例 |
|-----------|---------|------|
| L1 记忆 | 选择题 / 填空题 | "课文中提到的XX概念是什么？" |
| L2 理解 | 判断题 / 简答题 | "用自己的话解释XX的含义" |
| L3 应用 | 选择题 / 情境题 | "在以下情境中，应该如何运用XX？" |
| L4 分析 | 简答题 / 排序题 | "比较XX和YY的异同点" |

每条内容默认生成 3 道检测题，覆盖至少 2 个布鲁姆层级。

#### 4.1.2 Prompt 模板

```python
COMPREHENSION_CHECK_GENERATION_PROMPT = """

## 学习内容信息
- 内容ID: {content_id}
- 学科: {subject}
- 学段年级: {grade}
- 内容类型: {content_type}
- 内容摘要: {content_summary}
- 核心知识点: {knowledge_points}
- 内容难度: {difficulty_level}

## 生成要求

1. **题型分配**: 
   - 至少1道选择题(MULTIPLE_CHOICE) — 快速检测
   - 至少1道简答题(EXPLAIN) — 深度检测
   - 可选1道填空题(FILL_BLANK) 或 判断题(JUDGE)

2. **认知层级**: 
   - 必须覆盖"理解"(L2)层级
   - 根据内容难度适当覆盖"应用"(L3)或"分析"(L4)

4. **答案质量**: 
   - 选择题: 提供4个选项，干扰项需合理
   - 简答题: 提供标准答案要点和关键词
   - 填空题: 提供可接受的答案列表

#### 4.1.3 生成流程

```python
class ComprehensionCheckGenerator:
    """理解度检测题生成器"""
    
    async def generate_checks(
        self,
        content_id: int,
        content_meta: ContentMeta,
        force_regenerate: bool = False
    ) -> list[ComprehensionCheck]:
        """
        为指定内容生成理解度检测题。
        
        流程:
        1. 检查缓存 — 同内容的检测题只生成一次
        2. 提取内容摘要和知识点
        3. 调用LLM生成检测题
        4. 质量校验与过滤
        5. 持久化并缓存
        """
        # 1. 缓存检查
        if not force_regenerate:
            cached = await self.cache.get(f"checks:{content_id}")
            if cached:
                return cached
        
        # 2. 内容信息提取
        content_summary = await self.content_service.get_summary(content_id)
        knowledge_points = await self.kp_service.get_content_kps(content_id)
        
        # 3. 确定生成策略
        check_count = self._determine_check_count(content_meta)
        bloom_distribution = self._plan_bloom_distribution(
            content_meta.difficulty, 
            content_meta.grade_level
        )
        
        # 4. LLM 生成
        prompt = self._build_prompt(content_meta, content_summary, 
                                     knowledge_points, check_count, 
                                     bloom_distribution)
        raw_checks = await self.llm.generate(prompt, response_format="json")
        
        # 5. 质量校验
        validated = self._validate_checks(raw_checks, content_meta)
        
        # 6. 持久化
        saved = await self.repo.batch_save_checks(content_id, validated)
        
        # 7. 缓存 (TTL 24小时)
        await self.cache.set(f"checks:{content_id}", saved, ttl=86400)
        
        return saved
    
    def _determine_check_count(self, meta: ContentMeta) -> int:
        """根据内容类型和长度决定检测题数量"""
        base = {
            ContentType.VIDEO: 2,    # 视频内容2题
            ContentType.LESSON: 3,    # 课文讲解3题
            ContentType.CARD: 1,      # 学习卡片1题
            ContentType.INTERACTIVE: 2,
        }.get(meta.type, 3)
        
        # 长内容加题
        if meta.duration_seconds and meta.duration_seconds > 600:
            base += 1
        if meta.word_count and meta.word_count > 2000:
            base += 1
            
        return min(base, 5)  # 上限5题
    
    def _plan_bloom_distribution(
        self, difficulty: int, grade_level: int
    ) -> dict[int, int]:
        """
        根据内容难度和年级规划布鲁姆层级分布。
        
        高难度内容 → 更高的认知层级覆盖
        低年级 → 侧重记忆和理解
        高年级 → 增加应用和分析
        """
        if grade_level <= 6:  # 小学
            return {1: 1, 2: 2}  # 1记忆 + 2理解
        elif grade_level <= 9:  # 初中
            if difficulty >= 4:
                return {2: 1, 3: 1, 4: 1}  # 理解+应用+分析
            return {2: 2, 3: 1}
        else:  # 高中
            if difficulty >= 4:
                return {3: 1, 4: 1, 5: 1}  # 应用+分析+评价
            return {2: 1, 3: 2}
```

```python
class ComprehensionScorer:
    """理解度评分引擎"""
    
    # 各题型权重 (默认配置，可按学段调整)
    TYPE_WEIGHTS = {
        "MULTIPLE_CHOICE": 0.25,  # 快速但不深入
        "JUDGE": 0.15,            # 最快但区分度低
        "FILL_BLANK": 0.25,       # 中等深度
        "EXPLAIN": 0.35,          # 最深入但耗时
    }
    
    # 布鲁姆层级权重因子
    BLOOM_WEIGHTS = {
        1: 0.6,   # 记忆 — 基础分
        2: 0.8,   # 理解 — 核心分
        3: 1.0,   # 应用 — 加分
        4: 1.2,   # 分析 — 高阶加分
        5: 1.4,   # 评价 — 超纲加分
    }
    
    async def calculate_score(
        self,
        student_id: int,
        content_id: int,
        records: list[ComprehensionRecord]
    ) -> ComprehensionScore:
        """
        计算学生对某条内容的综合理解度评分。
        
        输入: 该学生在该内容上的所有检测记录
        输出: 0-100 的综合评分 + 各维度子分
        """
        if not records:
            return ComprehensionScore(score=0, level=InternalizationLevel.NONE)
        
        # Step 1: 计算每条检测题的得分
        check_scores = []
        for r in records:
            base_score = self._get_base_score(r)
            
            # 时间因子: 过快回答(秒选)降低权重，合理时间内加分
            time_factor = self._time_factor(r.response_time_ms, r.check_type)
            
            # 提示因子: 使用提示扣分
            hint_penalty = 0.85 if r.hint_used else 1.0
            
            # 尝试因子: 多次尝试扣分
            attempt_penalty = max(0.5, 1.0 - (r.attempt_count - 1) * 0.2)
            
            # 信心校准: 高信心+正确=bonus, 高信心+错误=penalty
            confidence_bonus = self._confidence_calibration(
                r.confidence_level, base_score
            )
            
            final = base_score * time_factor * hint_penalty * attempt_penalty + confidence_bonus
            final = max(0.0, min(1.0, final))
            
            check_scores.append(CheckScore(
                check_id=r.check_id,
                bloom_level=r.bloom_level,
                check_type=r.check_type,
                raw_score=base_score,
                final_score=final
            ))
        
        # Step 2: 按布鲁姆层级聚合
        bloom_scores = self._aggregate_by_bloom(check_scores)
        
        # Step 3: 加权综合评分
        overall = self._weighted_overall(bloom_scores)
        
        # Step 4: 确定内化深度等级
        level = self._determine_level(overall, bloom_scores)
        
        return ComprehensionScore(
            overall_score=round(overall * 100, 2),
            bloom_scores=bloom_scores,
            internalization_level=level,
            detail=check_scores
        )
    
    def _get_base_score(self, record: ComprehensionRecord) -> float:
        """获取检测题的基础得分 (0-1)"""
        if record.is_correct is not None:
            return float(record.is_correct)
        if record.correctness_score is not None:
            return record.correctness_score
        if record.ai_eval_score is not None:
            return record.ai_eval_score
        return 0.0
    
    def _time_factor(
        self, response_time_ms: int, check_type: str
    ) -> float:
        """
        作答时间因子。
        
        合理时间范围: 既不是秒选(猜的)，也不是超时(查的/发呆)
        """
        ranges = {
            "MULTIPLE_CHOICE": (3000, 30000),   # 3-30秒
            "JUDGE": (2000, 15000),              # 2-15秒
            "FILL_BLANK": (5000, 60000),          # 5-60秒
            "EXPLAIN": (10000, 180000),           # 10-180秒
        }
        min_ms, max_ms = ranges.get(check_type, (3000, 60000))
        
        if response_time_ms < min_ms:
            # 太快 — 可能乱猜
            ratio = response_time_ms / min_ms
            return 0.5 + 0.5 * ratio  # 最低0.5
        elif response_time_ms > max_ms:
            # 超时 — 可能查阅资料
            return 0.9  # 轻微扣分
        else:
            return 1.0  # 合理时间
    
    def _confidence_calibration(
        self, confidence: int | None, actual_score: float
    ) -> float:
        """
        信心校准奖励/惩罚。
        
        - 低信心+正确 → 学生低估自己，给予小奖励
        - 高信心+错误 → 学生高估自己，给予惩罚(元认知校准)
        - 信心与结果一致 → 不奖不罚
        """
        if confidence is None:
            return 0.0
        
        calibrated = confidence / 5.0  # 归一化到0-1
        diff = abs(calibrated - actual_score)
        
        if actual_score >= 0.8 and calibrated < 0.4:
            return 0.05  # 低信心但答对了 → 奖励
        elif actual_score < 0.4 and calibrated > 0.7:
            return -0.10  # 高信心但答错了 → 惩罚(元认知修复)
        else:
            return 0.0
    
    def _aggregate_by_bloom(
        self, scores: list[CheckScore]
    ) -> dict[int, float]:
        """按布鲁姆层级聚合得分"""
        bloom_groups = {}
        for s in scores:
            bloom_groups.setdefault(s.bloom_level, []).append(s.final_score)
        
        return {
            level: sum(vals) / len(vals)
            for level, vals in bloom_groups.items()
        }
    
    def _weighted_overall(
        self, bloom_scores: dict[int, float]
    ) -> float:
        """加权综合评分"""
        total_weight = 0
        weighted_sum = 0.0
        for level, score in bloom_scores.items():
            w = self.BLOOM_WEIGHTS.get(level, 1.0)
            weighted_sum += score * w
            total_weight += w
        
        return weighted_sum / total_weight if total_weight > 0 else 0.0
```

#### 4.2.2 简答题 AI 语义评估

```python
class ShortAnswerEvaluator:
    """简答题AI语义评估器"""
    
    async def evaluate(
        self,
        student_answer: str,
        correct_answer: str,
        keywords: list[str],
        bloom_level: int
    ) -> ShortAnswerEval:
        """
        对简答题进行语义级评估。
        
        策略:
        1. 关键词匹配 (快速路径) — 命中率 >= 80% 直接判定通过
        2. AI 语义评估 (深度路径) — LLM 判定语义等价度
        3. 综合评分
        """
        # 快速路径: 关键词匹配
        if keywords:
            kw_score = self._keyword_match(student_answer, keywords)
            if kw_score >= 0.8:
                return ShortAnswerEval(
                    score=kw_score, 
                    feedback="回答涵盖了主要要点",
                    method="KEYWORD_FAST"
                )
        
        # 深度路径: AI语义评估
        ai_result = await self._ai_semantic_eval(
            student_answer, correct_answer, bloom_level
        )
        
        # 综合: 关键词 + AI 取加权平均
        if keywords and kw_score is not None:
            final = 0.4 * kw_score + 0.6 * ai_result.score
        else:
            final = ai_result.score
            
        return ShortAnswerEval(
            score=final,
            feedback=ai_result.feedback,
            method="AI_HYBRID"
        )
    
    def _keyword_match(
        self, answer: str, keywords: list[str]
    ) -> float:
        """关键词匹配评分"""
        answer_lower = answer.lower()
        matched = sum(1 for kw in keywords if kw.lower() in answer_lower)
        return matched / len(keywords) if keywords else 0.0
    
    async def _ai_semantic_eval(
        self,
        student_answer: str,
        reference_answer: str,
        bloom_level: int
    ) -> AIEvalResult:
        """调用LLM进行语义级答案评估"""
        prompt = f"""
请评估学生回答与参考答案的语义等价度。

## 参考答案
{reference_answer}

## 学生回答
{student_answer}

## 评估要求
1. 评分范围: 0.0 - 1.0
2. 评分维度:
   - 核心概念覆盖度 (是否包含了主要知识点)
   - 语义正确性 (表述是否准确)
   - 认知深度 (是否展现了深层理解，对应布鲁姆层级{bloom_level})
3. 如果学生回答存在事实性错误，直接评分 <= 0.3

## 输出格式 (JSON)
{{
  "score": 0.85,
  "feedback": "回答基本正确，涵盖了XX要点，但对YY的理解不够深入",
  "missing_points": ["未提到的要点"]
}}
"""
        result = await self.llm.generate(prompt, response_format="json")
        return AIEvalResult(
            score=result["score"],
            feedback=result["feedback"],
            missing_points=result.get("missing_points", [])
        )
```

### 4.3 知识内化深度分级模型

```python
class InternalizationAssessor:
    """知识内化深度评估器"""
    
    # 内化深度等级定义
    LEVELS = {
        0: ("NONE",     "未检测",      "学生尚未完成理解度检测"),
        1: ("SURFACE",  "表层认知",    "仅能回忆基本信息，无法深入理解"),
        2: ("BASIC",    "基础理解",    "能理解核心概念，但应用能力有限"),
        3: ("SOLID",    "扎实掌握",    "能正确应用知识，具备分析能力"),
        4: ("DEEP",     "深度内化",    "能分析、评价并迁移应用，认知深度高"),
    }
    
    # 分级阈值 (可按学段/学科配置覆盖)
    THRESHOLDS = {
        1: {"overall_min": 20, "bloom_required": [1]},          # 至少能记忆
        2: {"overall_min": 50, "bloom_required": [1, 2]},       # 记忆+理解
        3: {"overall_min": 70, "bloom_required": [2, 3]},       # 理解+应用
        4: {"overall_min": 85, "bloom_required": [3, 4]},       # 应用+分析
    }
    
    def assess(
        self,
        overall_score: float,  # 0-1
        bloom_scores: dict[int, float]
    ) -> InternalizationResult:
        """
        根据综合得分和布鲁姆层级得分，确定内化深度等级。
        
        规则:
        1. 从高到低匹配
        2. 必须同时满足总分门槛和所需布鲁姆层级均有得分
        3. 如果高阶认知层级得分高，给予额外加权
        """
        for level in [4, 3, 2, 1]:
            threshold = self.THRESHOLDS[level]
            
            # 检查总分
            if overall_score * 100 < threshold["overall_min"]:
                continue
            
            # 检查所需布鲁姆层级是否有有效得分
            required_blooms = threshold["bloom_required"]
            bloom_satisfied = all(
                bloom_scores.get(bl, 0) > 0.4
                for bl in required_blooms
            )
            
            if not bloom_satisfied:
                continue
            
            # 检查通过 → 确定等级
            level_name, level_desc = self.LEVELS[level][0], self.LEVELS[level][1]
            
            # 附加信息
            strengths = self._identify_strengths(bloom_scores)
            gaps = self._identify_gaps(bloom_scores)
            
            return InternalizationResult(
                level=level,
                level_name=level_name,
                level_description=level_desc,
                overall_score=overall_score,
                strengths=strengths,
                gaps=gaps,
                recommendation=self._get_recommendation(level, gaps)
            )
        
        return InternalizationResult(
            level=0,
            level_name="NONE",
            level_description="未检测",
            overall_score=overall_score,
            recommendation="请完成本节内容的理解度检测"
        )
    
    def _identify_strengths(
        self, bloom_scores: dict[int, float]
    ) -> list[str]:
        """识别学生的认知强项"""
        names = {1: "记忆", 2: "理解", 3: "应用", 4: "分析", 5: "评价"}
        return [
            f"{names.get(bl, f'L{bl}')}能力突出 ({score:.0%})"
            for bl, score in sorted(bloom_scores.items())
            if score >= 0.8
        ]
    
    def _identify_gaps(
        self, bloom_scores: dict[int, float]
    ) -> list[str]:
        """识别认知薄弱点"""
        names = {1: "记忆", 2: "理解", 3: "应用", 4: "分析", 5: "评价"}
        return [
            f"{names.get(bl, f'L{bl}')}能力不足 ({score:.0%})"
            for bl, score in sorted(bloom_scores.items())
            if score < 0.5
        ]
    
    def _get_recommendation(
        self, level: int, gaps: list[str]
    ) -> str:
        """根据等级和薄弱点生成学习建议"""
        base = {
            1: "建议重新阅读本节内容，重点关注核心概念和定义",
            2: "建议复习关键知识点，并尝试做一些基础应用练习",
            3: "掌握良好！可以尝试更有挑战性的应用题和拓展内容",
            4: "掌握扎实！建议探索进阶内容和知识点间的关联分析",
        }
        rec = base.get(level, "请完成理解度检测")
        if gaps:
            rec += f"。需要加强: {'、'.join(gaps)}"
        return rec
```

### 4.4 理解度衰减模型

```python
class ComprehensionDecayTracker:
    """
    理解度衰减追踪器。
    
    基于艾宾浩斯遗忘曲线理论，但做个性化校准:
    - 初始半衰期: 7天 (默认)
    - 根据学生历史数据拟合个性化半衰期
    - 考虑内容难度、认知层级对衰减速率的影响
    """
    
    DEFAULT_HALF_LIFE_DAYS = 7.0
    MIN_HALF_LIFE = 2.0
    MAX_HALF_LIFE = 30.0
    
    async def predict_current_score(
        self,
        student_id: int,
        content_id: int
    ) -> DecayPrediction:
        """
        预测当前时间点的理解度衰减后得分。
        
        衰减模型: S(t) = S0 * exp(-λ * t)
        其中:
        - S0 = 初始检测得分
        - t = 距上次检测的天数  
        - λ = ln(2) / half_life
        """
        summary = await self.repo.get_summary(student_id, content_id)
        if not summary:
            return DecayPrediction(current_score=0.0, is_decayed=True)
        
        days_elapsed = (
            datetime.now() - summary.last_checked_at
        ).total_seconds() / 86400
        
        # 获取个性化半衰期
        half_life = summary.half_life_days or self.DEFAULT_HALF_LIFE_DAYS
        
        # 计算衰减
        decay_constant = math.log(2) / half_life
        predicted_score = summary.initial_score / 100 * math.exp(
            -decay_constant * days_elapsed
        )
        
        # 低于阈值 → 需要复习
        threshold = await self.config.get(
            "REVIEW_TRIGGER_THRESHOLD", default=0.4
        )
        needs_review = predicted_score < threshold
        
        # 预测复习到期日
        if not needs_review:
            remaining_days = self._days_until_threshold(
                summary.initial_score / 100, half_life, threshold
            )
            review_due = datetime.now() + timedelta(days=remaining_days)
        else:
            review_due = datetime.now()  # 已过期
        
        return DecayPrediction(
            current_score=predicted_score * 100,
            initial_score=summary.initial_score,
            days_elapsed=days_elapsed,
            half_life_days=half_life,
            needs_review=needs_review,
            predicted_review_due=review_due
        )
    
    async def update_half_life(
        self,
        student_id: int,
        content_id: int,
        new_record: ComprehensionRecord
    ) -> float:
        """
        根据复测结果更新个性化半衰期。
        
        如果学生复测得分高于预测 → 半衰期变长 (记忆更持久)
        如果低于预测 → 半衰期变短 (遗忘更快)
        """
        summary = await self.repo.get_summary(student_id, content_id)
        if not summary or summary.check_count < 2:
            return self.DEFAULT_HALF_LIFE_DAYS
        
        # 计算实际衰减
        days_elapsed = (
            new_record.triggered_at - summary.last_checked_at
        ).days
        
        if days_elapsed <= 0:
            return summary.half_life_days or self.DEFAULT_HALF_LIFE_DAYS
        
        s0 = summary.initial_score / 100
        s1 = new_record.correctness_score or (
            1.0 if new_record.is_correct else 0.0
        )
        
        if s1 <= 0 or s0 <= 0:
            # 快速遗忘
            estimated_half_life = self.MIN_HALF_LIFE
        else:
            # 反推半衰期: S1 = S0 * exp(-λ * t)
            # → λ = -ln(S1/S0) / t
            # → half_life = ln(2) / λ = ln(2) * t / -ln(S1/S0)
            ratio = s1 / s0
            if ratio >= 1.0:
                # 没有衰减，扩大半衰期
                estimated_half_life = min(
                    summary.half_life_days * 1.3 if summary.half_life_days 
                    else self.DEFAULT_HALF_LIFE_DAYS * 1.3,
                    self.MAX_HALF_LIFE
                )
            else:
                estimated_half_life = math.log(2) * days_elapsed / (
                    -math.log(ratio)
                )
                estimated_half_life = max(
                    self.MIN_HALF_LIFE,
                    min(estimated_half_life, self.MAX_HALF_LIFE)
                )
        
        # 指数移动平均平滑
        old_hl = summary.half_life_days or self.DEFAULT_HALF_LIFE_DAYS
        smoothed_hl = 0.3 * estimated_half_life + 0.7 * old_hl
        
        # 持久化
        await self.repo.update_half_life(
            student_id, content_id, round(smoothed_hl, 2)
        )
        
        # 记录衰减日志
        await self.repo.save_decay_log(DecayLog(
            student_id=student_id,
            content_id=content_id,
            recorded_score=s1 * 100,
            days_since_last_check=days_elapsed,
            expected_score=s0 * math.exp(
                -math.log(2) / old_hl * days_elapsed
            ) * 100,
            actual_score=s1 * 100,
            decay_rate=math.log(2) / smoothed_hl
        ))
        
        return round(smoothed_hl, 2)
    
    def _days_until_threshold(
        self, s0: float, half_life: float, threshold: float
    ) -> float:
        """计算到达阈值所需的剩余天数"""
        if s0 <= threshold:
            return 0.0
        decay_constant = math.log(2) / half_life
        return -math.log(threshold / s0) / decay_constant
```

## 8. 错误处理与降级策略

### 8.1 错误场景与处理

| 错误场景 | 处理策略 | 降级方案 |
|---------|---------|---------|
| LLM 检测题生成失败 | 重试3次，指数退避 | 使用预设通用检测题模板 |
| LLM 简答题评估超时 | 30秒超时，降级为关键词评估 | 仅返回关键词匹配得分 |
| LLM 评估结果格式异常 | JSON解析失败 → 重试1次 | 降级为关键词评估，记录异常 |
| 数据库写入失败 | 重试3次 | 降级为内存缓存，异步补偿写入 |
| Redis 缓存不可用 | 直接回源数据库 | 限制QPS，记录告警 |
| 检测题缓存过期且LLM不可用 | 返回预设基础检测题 | 记录降级日志 |
| 学生重复提交同一检测 | 幂等检查，返回已有结果 | — |

### 8.2 降级模式

```python
class ComprehensionService:
    """理解度检测服务 — 含降级逻辑"""
    
    async def get_checks_with_fallback(
        self, content_id: int, student_id: int
    ) -> list[ComprehensionCheck]:
        try:
            # 正常路径: LLM生成/缓存
            return await self.generator.generate_checks(content_id)
        except (LLMUnavailableError, LL MTimeoutError) as e:
            logger.warning(f"LLM unavailable, using fallback: {e}")
            # 降级: 使用通用模板
            return await self.fallback_generator.generate(
                content_id, 
                template="generic_understanding_check"
            )
    
    async def evaluate_short_answer_with_fallback(
        self, answer: str, reference: str, keywords: list[str]
    ) -> ShortAnswerEval:
        # 快速路径优先
        if keywords:
            kw_score = self._keyword_match(answer, keywords)
            if kw_score >= 0.8:
                return ShortAnswerEval(
                    score=kw_score,
                    feedback="回答涵盖了主要要点",
                    method="KEYWORD_FAST"
                )
        
        # AI 深度评估 (含超时降级)
        try:
            return await asyncio.wait_for(
                self.ai_evaluator.evaluate(answer, reference, keywords),
                timeout=30.0
            )
        except asyncio.TimeoutError:
            logger.warning("AI eval timeout, falling back to keyword-only")
            return ShortAnswerEval(
                score=kw_score or 0.0,
                feedback="基于关键词匹配的初步评估",
                method="KEYWORD_FALLBACK",
                degraded=True
            )
```

```python
class ComprehensionBatchProcessor:
    """批量处理器 — 优化高频场景"""
    
    async def batch_predict_decay(self):
        """
        每日定时批量预测所有学生的理解度衰减。
        
        优化: 避免逐条查询，使用批量SQL + Redis Pipeline
        """
        # 1. 批量查询待检查记录
        candidates = await self.repo.batch_get_due_for_decay_check(
            batch_size=5000
        )
        
        # 2. 批量预测
        predictions = []
        for record in candidates:
            pred = self.decay_tracker.fast_predict(record)
            predictions.append(pred)
        
        # 3. 批量更新 (SQL批量UPDATE)
        await self.repo.batch_update_decay_scores(predictions)
        
        # 4. 批量发布衰减告警事件
        warnings = [p for p in predictions if p.needs_review]
        if warnings:
            await self.event_bus.publish_batch(
                "comprehension.decay.warning",
                warnings
            )
```

## 10. 安全与合规

### 10.1 数据安全

- **学生答案内容**: 简答题答案可能包含个人信息，存储时进行脱敏处理
