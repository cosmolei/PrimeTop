# 教材内容数字化与结构化生产管线 - 详细设计

> **模块定位**：将纸质教材、教辅、试卷等原始教育资源，经过数字化采集、OCR识别、结构化解析、质量审核，最终转化为系统内可检索、可渲染、AI可理解的结构化数据的端到端生产管线。
>
> **关联模块**：图片处理与OCR识别管线、知识点体系与教材映射引擎、题目与题库服务、RAG与知识库系统、搜索服务与全文检索、富文本与学科内容渲染引擎、内容与运营后台、文件与资源存储服务

---

## 1. 整体架构

### 1.1 管线全景

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        内容生产管线 (Content Production Pipeline)             │
├─────────────┬──────────────┬──────────────┬──────────────┬──────────────────┤
│  1. 采集上传  │  2. 数字化处理 │  3. 结构化解析 │  4. 质量审核  │  5. 发布入库      │
│             │              │              │              │                  │
│ · 扫描/拍照  │ · 图像增强    │ · 章节提取    │ · 人工审核    │ · ES索引构建      │
│ · PDF导入   │ · OCR识别    │ · 题目结构化  │ · AI辅助校验  │ · 向量化嵌入      │
│ · 电子稿导入 │ · 版面分析    │ · 知识点标注  │ · 交叉比对    │ · 缓存预热       │
│ · 第三方对接 │ · 手写识别    │ · 公式解析    │ · 抽检机制    │ · CDN分发        │

└─────────────┴──────────────┴──────────────┴──────────────┴──────────────────┘
         │             │              │              │              │
         ▼             ▼              ▼              ▼              ▼
    [OSS 原始文件] [OCR 结果库]   [结构化数据]    [审核记录]   [生产就绪数据]
```

### 1.2 核心数据流向

```
原始资源 → 采集批次(Batch) → 页面(Page) → 内容块(Block) → 结构化实体(Entity)
                                                              ├─ Chapter（章节）
                                                              ├─ KnowledgePoint（知识点）
                                                              ├─ Question（题目）
                                                              ├─ Formula（公式）
                                                              └─ Illustration（插图）
```

### 3.2 阶段二：数字化处理

#### 3.2.1 图像增强

图像增强在 OCR 前执行，提升识别准确率：

```python
class ImageEnhancer:
    """图像增强处理器"""
    
    ENHANCE_PIPELINE = [
        "deskew",          # 纠偏倾斜
        "denoise",         # 降噪
        "binarize",        # 二值化（仅打印文本）
        "contrast_enhance", # 对比度增强
        "sharpen",         # 锐化
    ]
    
    def enhance(self, image_bytes: bytes, config: dict) -> EnhancedResult:
        img = Image.open(io.BytesIO(image_bytes))
        
        quality_score = self._assess_quality(img)
        
        # 跳过高质量图片的部分增强步骤
        if quality_score > 0.85:
            steps = ["deskew", "denoise"]
        else:
            steps = self.ENHANCE_PIPELINE
        
        for step in steps:
            img = self._apply_step(img, step, config.get(step, {}))
        
        # 保存增强结果
        enhanced_key = self._save_enhanced(img, config["batch_id"], config["page_no"])
        
        return EnhancedResult(
            enhanced_file_key=enhanced_key,
            quality_score_before=quality_score,
            quality_score_after=self._assess_quality(img),
            steps_applied=steps
        )
```

#### 3.2.2 OCR 处理

```python
class OCREngine:
    """OCR引擎适配器"""
    
    def __init__(self, engine_name: str, config: dict):
        self.engine = self._create_engine(engine_name, config)
    
    def recognize(self, image_url: str, options: OCROptions) -> OCRResult:
        """
        执行OCR识别
        
        Args:
            image_url: 增强后的图片URL
            options: 识别选项
        """
        raw_result = self.engine.recognize(image_url, options)
        
        # 后处理：公式区域标记、手写区域分离
        processed = self._post_process(raw_result)
        
        return OCRResult(
            full_text=processed.full_text,
            blocks=[
                OCRBlock(
                    text=b.text,
                    bbox=b.bbox,
                    confidence=b.confidence,
                    is_handwritten=b.is_handwritten,
                    is_formula=b.is_formula,
                )
                for b in processed.blocks
            ],
            avg_confidence=processed.avg_confidence,
            engine=self.engine.name,
            duration_ms=processed.duration_ms,
        )
```

**OCR 引擎策略**：

| 引擎 | 适用场景 | 精度 | 成本 |
|------|----------|------|------|
| PaddleOCR v4 | 印刷体中文（默认） | 高 | 低（自部署） |
| 百度OCR API | 复杂排版、表格 | 很高 | 中 |
| Google Vision | 英文/多语言混合 | 高 | 中 |
| Mathpix | 公式密集页面 | 很高（公式） | 高 |
| 手写识别引擎 | 手写作业/试卷 | 中 | 中 |

**引擎选择逻辑**：

```python
def select_ocr_engine(page: ContentPage, config: dict) -> str:
    """根据页面特征选择最优OCR引擎"""
    
    # 检测页面语言
    if page.detected_language == "en" and page.formula_density > 0.3:
        return "mathpix"
    
    # 表格密集页面
    if page.table_density > 0.3:
        return "baidu_ocr"
    
    # 手写内容
    if page.handwriting_ratio > 0.5:
        return "handwriting_engine"
    
    # 默认
    return config.get("default_engine", "paddleocr_v4")
```

#### 3.2.3 版面分析

```python
class LayoutAnalyzer:
    """版面分析：识别页面区域类型"""
    
    REGION_TYPES = [
        "title", "subtitle", "body", "question_area", "figure", "table",
        "header", "footer", "page_number", "sidebar", "annotation"
    ]
    
    def analyze(self, image_url: str, ocr_result: OCRResult) -> LayoutResult:
        """
        分析版面布局
        
        Returns:
            LayoutResult: 包含各区域的类型和边界框
        """
        # 使用版面分析模型（如 LayoutLMv3）
        regions = self.model.predict(image_url)
        
        # 与OCR结果对齐：将文字块映射到区域
        aligned_blocks = self._align_blocks_to_regions(ocr_result.blocks, regions)
        
        # 推断阅读顺序
        reading_order = self._infer_reading_order(aligned_blocks)
        
        return LayoutResult(
            regions=regions,
            blocks=aligned_blocks,
            reading_order=reading_order,
            detected_columns=self._detect_columns(regions)
        )
```

### 3.3 阶段三：结构化解析

#### 3.3.1 内容块提取

```python
class BlockExtractor:
    """从版面分析+OCR结果中提取结构化内容块"""
    
    def extract(self, page_id: int, layout: LayoutResult, ocr: OCRResult) -> List[ContentBlock]:
        blocks = []
        
        for idx, region in enumerate(layout.reading_order):
            # 合并该区域内的OCR文本行
            region_text = self._merge_region_text(region, ocr)
            
            # 分类内容块
            block_type = self._classify_block(region, region_text)
            
            # 提取子结构（如题目包含选项）
            sub_blocks = self._extract_sub_blocks(region, region_text, block_type)
            
            block = ContentBlock(
                page_id=page_id,
                block_order=idx,
                bbox=region.bbox.to_dict(),
                block_type=block_type,
                raw_text=region_text,
                final_text=region_text,
                ocr_confidence=region.avg_confidence,
                has_formula=self._detect_formulas(region_text),
                has_image=region.type == 'figure',
                has_table=region.type == 'table',
            )
            
            if sub_blocks:
                block.structured_data = {"sub_blocks": sub_blocks}
            
            blocks.append(block)
        
        return blocks
```

#### 3.3.2 题目结构化解析器

```python
class QuestionParser:
    """题目结构化解析"""
    
    def parse(self, block: ContentBlock) -> Optional[QuestionEntity]:
        """
        将原始文本块解析为结构化题目
        
        识别逻辑：
        1. 正则匹配题号：^\d+[\.、）)]\s*
        2. 识别题型：选择题(有选项)、填空题(有___)、解答题/证明题等
        3. 分离题干、选项、条件
        4. 提取公式
        5. 关联图片
        """
        text = block.final_text
        
        # 题号识别
        q_match = re.match(r'^(\d+)\s*[\.、）)]\s*', text)
        if not q_match:
            return None
        
        question_no = int(q_match.group(1))
        content = text[q_match.end():]
        
        # 题型判断
        q_type = self._detect_question_type(content, block.structured_data)
        
        # 按题型解析
        parser_map = {
            "choice": self._parse_choice,
            "fill": self._parse_fill,
            "true_false": self._parse_true_false,
            "short_answer": self._parse_short_answer,
            "proof": self._parse_proof,
            "calculation": self._parse_calculation,
            "essay": self._parse_essay,
        }
        
        parser = parser_map.get(q_type, self._parse_generic)
        parsed = parser(content, block)
        
        return QuestionEntity(
            question_type=q_type,
            question_no=question_no,
            stem=parsed.stem,
            options=parsed.options,
            answer_area=parsed.answer_area,
            formulas=self._extract_formulas(content),
            figures=self._extract_figure_refs(block),
            raw_block_id=block.id,
        )
    
    def _detect_question_type(self, content: str, structured: dict) -> str:
        """题型检测"""
        has_options = bool(re.search(r'[A-D][\.、）)]\s*\S', content))
        has_blank = '___' in content or '____' in content
        
        if has_options:
            return "choice"
        if has_blank:
            return "fill"
        if '证明' in content[:20]:
            return "proof"
        if '计算' in content[:20] or re.search(r'[=＝]\s*\?', content):
            return "calculation"
        if '判断' in content[:20] or '（  ）' in content:
            return "true_false"
        if '作文' in content or '写一篇' in content:
            return "essay"
        return "short_answer"
    
    def _parse_choice(self, content: str, block: ContentBlock) -> ParsedQuestion:
        """选择题解析"""
        # 分离题干和选项
        option_pattern = r'([A-D])\s*[\.、）)]\s*(.*?)(?=[A-D]\s*[\.、）)]|$)'
        options_matches = list(re.finditer(option_pattern, content, re.DOTALL))
        
        if options_matches:
            stem = content[:options_matches[0].start()].strip()
            options = [
                {"label": m.group(1), "text": m.group(2).strip()}
                for m in options_matches
            ]
        else:
            stem = content
            options = []
        
        return ParsedQuestion(stem=stem, options=options, answer_area=None)
```

```python
class FormulaParser:
    """数学/化学公式识别与LaTeX转换"""
    
    def parse(self, image_crop: bytes, context: str = "") -> FormulaResult:
        """
        从图片区域识别公式并转为LaTeX
        
        Args:
            image_crop: 公式区域图片裁剪
            context: 上下文文本，辅助识别
        """
        # 使用Mathpix或自研模型
        latex = self.engine.recognize_formula(image_crop)
        
        # LaTeX 校验
        is_valid = self._validate_latex(latex)
        
        # 渲染测试
        render_ok = self._test_render(latex)
        
        return FormulaResult(
            latex=latex,
            confidence=self.engine.last_confidence,
            is_valid=is_valid,
            render_ok=render_ok,
            context=context
        )
    
    def batch_parse_formulas(self, blocks: List[ContentBlock]) -> List[FormulaResult]:
        """批量解析页面内所有公式"""
        formula_blocks = [b for b in blocks if b.has_formula]
        
        results = []
        # 批量调用，减少API开销
        for batch in chunked(formula_blocks, size=5):
            crops = [self._crop_formula_area(b) for b in batch]
            batch_results = self.engine.batch_recognize(crops)
            results.extend(batch_results)
        
        return results
```

class KnowledgeAutoTagger:
    """基于内容自动关联知识点"""
    
    def tag(self, block: ContentBlock, context: BatchContext) -> List[KnowledgeTag]:
        """
        自动标注知识点标签
        
        策略：
        1. 基于章节位置的确定性映射（精确）
        2. 基于文本相似度的匹配（高准）
        3. 基于LLM的语义标注（兜底）
        """
        tags = []
        
        # 策略1：章节位置映射
        chapter_kps = self._map_by_chapter_position(block, context.textbook_id)
        if chapter_kps:
            tags.extend([KnowledgeTag(kp_id=kp.id, method="chapter_mapping", confidence=1.0) 
                        for kp in chapter_kps])
        
        # 策略2：文本相似度
        if len(tags) < 1:
            similar_kps = self.knowledge_repo.search_similar(
                text=block.final_text,
                subject_code=context.subject_code,
                grade_range=context.grade_range,
                top_k=3,
                threshold=0.75
            )
            tags.extend([KnowledgeTag(kp_id=kp.id, method="text_similarity", confidence=kp.score)
                        for kp in similar_kps])
        
        # 策略3：LLM标注
        if len(tags) < 1:
            llm_tags = self._llm_tag(block.final_text, context)
            tags.extend(llm_tags)
        
        return tags

```python
class SpotCheckManager:
    """抽检管理器"""
    
    SPOT_CHECK_RATE = 0.10          # 抽检比例 10%
    REJECTION_THRESHOLD = 0.05      # 不合格率阈值 5%
    
    def generate_spot_check(self, batch_id: int) -> List[int]:
        """生成抽检样本"""
        approved_blocks = ContentBlock.query(
            batch_id=batch_id,
            review_status='approved'
        ).all()
        
        sample_size = max(1, int(len(approved_blocks) * self.SPOT_CHECK_RATE))
        sample = random.sample(approved_blocks, min(sample_size, len(approved_blocks)))
        
        # 标记为抽检状态
        for block in sample:
            block.review_status = 'spot_check'
        
        return [b.id for b in sample]
    
    def evaluate_spot_check_result(self, batch_id: int) -> SpotCheckVerdict:
        """评估抽检结果"""
        spot_blocks = ContentBlock.query(
            batch_id=batch_id,
            review_status='spot_checked'
        ).all()
        
        if not spot_blocks:
            return SpotCheckVerdict.PASS
        
        rejected_ratio = sum(1 for b in spot_blocks if b.review_status == 'rejected') / len(spot_blocks)
        
        if rejected_ratio > self.REJECTION_THRESHOLD:
            # 打回整批重新审核
            self._rollback_batch_to_review(batch_id)
            return SpotCheckVerdict.BATCH_REJECTED
        
        return SpotCheckVerdict.PASS
```

    # 批量更新
    ContentBlock.bulk_update(blocks)
    
    # 自动质量校验
    for block in blocks:
        if block.ocr_confidence < 0.8:
            block.needs_manual_fix = True
    
    batch.update_pipeline_progress()

## 8. 错误处理

### 8.1 错误码体系

| 错误码 | HTTP | 说明 | 处理建议 |
|--------|------|------|----------|
| `BATCH_001` | 400 | 批次名称重复 | 修改名称 |
| `BATCH_002` | 400 | 文件格式不支持 | 支持 jpg/png/pdf |
| `BATCH_003` | 409 | 批次状态不允许此操作 | 检查状态机 |
| `BATCH_004` | 413 | 文件超出大小限制 | 单文件≤200MB |
| `OCR_001` | 500 | OCR引擎超时 | 自动重试3次，切换引擎 |
| `OCR_002` | 500 | OCR引擎不可用 | 降级到备用引擎 |
| `PARSE_001` | 422 | 题目解析失败 | 标记需人工修正 |
| `PARSE_002` | 422 | 公式解析失败 | 标记需人工修正 |
| `REVIEW_001` | 403 | 无审核权限 | 检查角色权限 |
| `PUBLISH_001` | 500 | ES索引构建失败 | 重试，不影响数据 |
| `PUBLISH_002` | 500 | 向量化失败 | 重试，不影响数据 |

### 8.2 重试与降级

```python
class PipelineErrorHandler:
    """管线错误处理"""
    
    def handle_ocr_failure(self, page: ContentPage, error: Exception):
        """OCR失败处理"""
        page.ocr_status = 'failed'
        
        # 尝试降级引擎
        current_engine = page.ocr_engine
        fallback = OCR_FALLBACK_CHAIN.get(current_engine)
        
        if fallback:
            page.ocr_engine = fallback
            enhance_and_ocr.delay(page.id)
        else:
            # 所有引擎都失败，标记需人工
            page.needs_manual_fix = True
            page.save()
    
    def handle_parse_failure(self, block: ContentBlock, error: Exception):
        """解析失败处理"""
        block.edit_status = 'needs_edit'
        block.review_status = 'pending'
        
        if block.structured_data:
            block.structured_data['parse_error'] = str(error)
        
        block.save()

# OCR引擎降级链
OCR_FALLBACK_CHAIN = {
    "paddleocr_v4": "baidu_ocr",
    "baidu_ocr": "google_vision",
    "google_vision": None,  # 最终降级为人工处理
    "mathpix": "paddleocr_v4",  # 公式降级为通用OCR
}
```
