# 教育内容版本管理与教材同步更新引擎 - 详细设计文档

## 1. 模块概述

### 1.1 功能定位

本引擎负责 PrimeTop 全平台教育内容的版本生命周期管理，确保教材、知识点、题目等核心教学资源在更新迭代过程中保持一致性、可追溯性和向后兼容性。当教材改版、课标调整、知识点修订或题目纠错时，引擎提供从内容变更、影响分析、进度兼容到灰度发布的完整管控流程。

### 1.2 核心能力

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 内容版本化 | 所有教育内容支持多版本共存与历史追溯 | P0 |
| 教材版本管理 | 教材改版的检测、录入、映射与同步上线 | P0 |
| 课标变更传播 | 课标调整后自动分析影响范围并触发关联更新 | P1 |
| 进度兼容引擎 | 内容更新后用户学习进度自动映射与迁移 | P0 |
| 灰度内容发布 | 新版内容按区域/用户群体灰度推送 | P1 |
| 内容生命周期 | 草稿→审核→发布→下线的完整状态流转 | P0 |
| 变更审计 | 所有内容变更留痕，支持回滚与对比 | P0 |

### 1.3 与其他模块的边界

| 模块 | 职责边界 |
|------|---------|
| 教材内容数字化与结构化生产管线 | 负责内容的 OCR 识别、结构化解析、入库；**不负责版本管理** |
| 知识点体系与教材映射引擎 | 负责知识点树结构和映射关系；**消费本引擎提供的版本化映射数据** |
| 题目与题库服务 | 负责题目 CRUD 和检索；**依赖本引擎的题目版本信息** |
| 学习记录与进度追踪服务 | 记录用户学习行为；**消费本引擎的进度迁移服务** |
| 数据迁移与 Schema 版本管理 | 负责 DB Schema 迁移；**本引擎负责业务数据层面的内容版本迁移** |
| 灰度发布与特性开关系统 | 通用灰度能力；**本引擎定义内容灰度规则并调用通用灰度能力** |

### 1.4 依赖关系

```
上游：
  教材内容数字化管线 ──→ 结构化内容写入
  内容与运营后台   ──→ 人工内容编辑/审核
  课标变更通知     ──→ 外部课标更新事件

下游消费者：
  知识点体系       ──→ 读取版本化映射
  同步课堂学习     ──→ 读取教材章节版本
  题目与题库服务   ──→ 读取题目版本与关联
  自适应推荐引擎   ──→ 读取内容版本状态
  学习记录服务     ──→ 进度迁移回调
```

## 2. 核心概念与数据模型

### 2.1 版本模型

采用 **语义化版本** + **内容指纹** 双标识体系：

```python
class ContentVersion:
    """内容版本号"""
    major: int     # 主版本：课标/教材大版本变更（如 2024 新课标）
    minor: int     # 次版本：章节级内容修订（如章节新增/删除）
    patch: int     # 修订号：错别字/公式修正等小改动

    def __str__(self):
        return f"v{self.major}.{self.minor}.{self.patch}"

class ContentFingerprint:
    """内容指纹，用于变更检测"""
    sha256: str          # 内容全文 SHA-256
    structure_hash: str  # 结构化数据哈希（知识点树/题目集合）
    metadata_hash: str   # 元数据哈希（标签/难度/关联关系）
```

### 3.2 自动映射分析算法

```python
class TextbookMappingAnalyzer:
    """教材版本自动映射分析器"""

    def __init__(self, llm_service, embedding_service, kp_engine):
        self.llm = llm_service
        self.embedding = embedding_service
        self.kp_engine = kp_engine

    async def analyze_mapping(
        self,
        source_edition_id: int,
        target_edition_id: int
    ) -> dict:
        """
        分析两个教材版本之间的章节/知识点映射关系。

        返回 mapping_json 结构。
        """
        source_chapters = await self._load_chapters(source_edition_id)
        target_chapters = await self._load_chapters(target_edition_id)

        # 阶段1：精确匹配（名称完全相同）
        exact_matches = self._exact_match(source_chapters, target_chapters)

        # 阶段2：语义匹配（embedding 相似度）
        unmatched_source = [c for c in source_chapters if c.id not in exact_matches]
        unmatched_target = [c for c in target_chapters if c.id not in exact_matches.values()]
        semantic_matches = await self._semantic_match(unmatched_source, unmatched_target)

        # 阶段3：AI 辅助映射（处理重组/合并/拆分场景）
        remaining_source = [c for c in unmatched_source
                           if c.id not in semantic_matches]
        remaining_target = [c for c in unmatched_target
                           if c.id not in semantic_matches.values()]
        ai_matches = await self._ai_assisted_match(
            remaining_source, remaining_target,
            source_edition_id, target_edition_id
        )

        # 阶段4：知识点级映射
        chapter_mappings = {**exact_matches, **semantic_matches, **ai_matches}
        kp_mappings = await self._map_knowledge_points(chapter_mappings)

        # 阶段5：生成 mapping_json
        return self._build_mapping_json(
            source_edition_id, target_edition_id,
            chapter_mappings, kp_mappings,
            exact_matches, semantic_matches, ai_matches
        )

    def _exact_match(self, source, target) -> dict:
        """精确名称匹配"""
        target_name_map = {self._normalize(c.name): c for c in target}
        matches = {}
        for s in source:
            norm = self._normalize(s.name)
            if norm in target_name_map:
                matches[s.id] = target_name_map[norm].id
        return matches

    @staticmethod
    def _normalize(name: str) -> str:
        """标准化章节名称用于匹配"""
        import re
        name = name.strip()
        # 移除序号前缀差异：第一章 ≈ 第1章 ≈ 1.
        name = re.sub(r'第[一二三四五六七八九十\d]+章\s*', '', name)
        name = re.sub(r'^\d+[\.\s、]+', '', name)
        return name.strip()

    async def _semantic_match(self, source, target) -> dict:
        """基于 embedding 的语义匹配"""
        SIMILARITY_THRESHOLD = 0.88

        source_embeddings = await self.embedding_service.batch_embed(
            [f"{c.name} {c.summary or ''}" for c in source]
        )
        target_embeddings = await self.embedding_service.batch_embed(
            [f"{c.name} {c.summary or ''}" for c in target]
        )

        matches = {}
        used_target = set()

        # 贪心最佳匹配
        for i, s_emb in enumerate(source_embeddings):
            best_score = 0
            best_j = None
            for j, t_emb in enumerate(target_embeddings):
                if j in used_target:
                    continue
                score = cosine_similarity(s_emb, t_emb)
                if score > best_score:
                    best_score = score
                    best_j = j
            if best_score >= SIMILARITY_THRESHOLD and best_j is not None:
                matches[source[i].id] = target[best_j].id
                used_target.add(best_j)

        return matches

    async def _ai_assisted_match(self, source, target, src_id, tgt_id) -> dict:
        """AI 辅助处理重组/合并/拆分场景"""
        if not source and not target:
            return {}

        prompt = f"""你是教材分析专家。请分析以下两个教材版本的章节列表，建立映射关系。

源版本章节（可能被删除/合并/重组）：
{self._format_chapters(source)}

目标版本章节（可能为新增/拆分/重组）：
{self._format_chapters(target)}

请以 JSON 格式输出映射关系：
- mapping_type: one_to_one | one_to_many | many_to_one | removed | added
- confidence: 0.0-1.0
- note: 映射说明

输出格式：
[{{"source_id": int|null, "target_id": int|null, "mapping_type": str, "confidence": float, "note": str}}]
"""
        response = await self.llm.chat(prompt=prompt, temperature=0.1)
        return self._parse_ai_mapping(response, source, target)
```

### 3.3 用户进度迁移流程

```python
class ProgressMigrationService:
    """用户学习进度迁移服务"""

    def __init__(self, db, event_bus, notification_service):
        self.db = db
        self.event_bus = event_bus
        self.notification = notification_service

    async def execute_migration(
        self,
        migration_id: int,
        user_ids: list[int] | None = None,
        dry_run: bool = False
    ) -> MigrationResult:
        """
        执行进度迁移。

        Args:
            migration_id: textbook_migration 记录ID
            user_ids: 指定用户列表（None=全量受影响用户）
            dry_run: 试运行模式，只输出迁移计划不实际执行
        """
        migration = await self._load_migration(migration_id)
        if not migration:
            raise MigrationNotFoundError(migration_id)

        # 获取受影响用户
        affected_users = user_ids or await self._find_affected_users(migration)

        result = MigrationResult(
            migration_id=migration_id,
            total_users=len(affected_users),
            dry_run=dry_run
        )

        # 批量处理，每批 100 用户
        for batch in chunked(affected_users, 100):
            batch_result = await self._migrate_batch(migration, batch, dry_run)
            result.merge(batch_result)

        # 发布迁移完成事件
        if not dry_run:
            await self.event_bus.publish(ContentMigrationCompleted(
                migration_id=migration_id,
                affected_users=result.migrated_users,
                failed_users=result.failed_users,
            ))

        return result

    async def _migrate_user(
        self,
        migration: TextbookMigration,
        user_id: int,
        dry_run: bool
    ) -> UserMigrationResult:
        """单个用户的进度迁移"""
        result = UserMigrationResult(user_id=user_id)
        mapping = migration.mapping_json

        for chapter_map in mapping["chapter_mappings"]:
            if chapter_map["mapping_type"] == "removed":
                # 章节被删除 → 标记进度为 deprecated，保留数据
                await self._handle_removed_chapter(
                    user_id, chapter_map, result, dry_run
                )
            elif chapter_map["mapping_type"] == "added":
                # 新增章节 → 无需迁移
                continue
            elif chapter_map["mapping_type"] == "one_to_one":
                # 一一映射 → 直接更新引用
                await self._handle_one_to_one(
                    user_id, chapter_map, result, dry_run
                )
                # 知识点级迁移
                for kp_map in chapter_map.get("kp_mappings", []):
                    await self._migrate_kp_progress(
                        user_id, kp_map, result, dry_run
                    )
            elif chapter_map["mapping_type"] in ("one_to_many", "many_to_one"):
                # 复杂映射 → 按比例拆分/合并进度
                await self._handle_complex_mapping(
                    user_id, chapter_map, result, dry_run
                )

        # 记录迁移日志
        if not dry_run:
            await self._record_migration(user_id, migration.id, result)

        return result

    async def _handle_one_to_one(
        self, user_id, chapter_map, result, dry_run
    ):
        """一一映射：直接更新进度中的章节引用"""
        source_id = chapter_map["source_chapter_id"]
        target_id = chapter_map["target_chapter_id"]

        # 更新章节进度
        progress = await self.db.execute(
            "SELECT * FROM chapter_progress "
            "WHERE user_id = ? AND chapter_id = ?",
            [user_id, source_id]
        )
        if progress and not dry_run:
            await self.db.execute(
                "UPDATE chapter_progress SET chapter_id = ?, "
                "edition_id = ? WHERE user_id = ? AND chapter_id = ?",
                [target_id, chapter_map["target_edition_id"], user_id, source_id]
            )
            result.migrated_items += 1

    async def _migrate_kp_progress(
        self, user_id, kp_map, result, dry_run
    ):
        """迁移知识点掌握度"""
        source_kp = kp_map["source_kp_id"]
        target_kp = kp_map["target_kp_id"]

        if kp_map.get("content_diff") == "minor_update":
            # 小改动 → 直接迁移，掌握度保留
            if not dry_run:
                await self.db.execute(
                    "UPDATE kp_mastery SET kp_id = ? "
                    "WHERE user_id = ? AND kp_id = ?",
                    [target_kp, user_id, source_kp]
                )
            result.migrated_items += 1
        elif kp_map.get("content_diff") == "major_restructure":
            # 大改动 → 掌握度打折（保守策略）
            if not dry_run:
                await self.db.execute(
                    "UPDATE kp_mastery SET kp_id = ?, "
                    "mastery_score = mastery_score * 0.6, "
                    "status = 'needs_review' "
                    "WHERE user_id = ? AND kp_id = ?",
                    [target_kp, user_id, source_kp]
                )
            result.migrated_items += 1
            result.degraded_items += 1

    async def _handle_complex_mapping(
        self, user_id, chapter_map, result, dry_run
    ):
        """处理一对多/多对一的复杂映射"""
        if chapter_map["mapping_type"] == "one_to_many":
            # 一个章节拆分为多个 → 按知识点覆盖率拆分进度
            source_progress = await self._get_chapter_progress(
                user_id, chapter_map["source_chapter_id"]
            )
            if not source_progress:
                return

            target_ids = chapter_map["target_chapter_ids"]
            split_ratio = 1.0 / len(target_ids)

            for target_id in target_ids:
                if not dry_run:
                    await self.db.execute(
                        "INSERT INTO chapter_progress "
                        "(user_id, chapter_id, progress_pct, edition_id) "
                        "VALUES (?, ?, ?, ?) "
                        "ON DUPLICATE KEY UPDATE "
                        "progress_pct = GREATEST(progress_pct, VALUES(progress_pct))",
                        [user_id, target_id,
                         source_progress.progress_pct * split_ratio,
                         chapter_map["target_edition_id"]]
                    )
            result.migrated_items += len(target_ids)

    async def _handle_removed_chapter(
        self, user_id, chapter_map, result, dry_run
    ):
        """标记已删除章节的进度为 deprecated"""
        if not dry_run:
            await self.db.execute(
                "UPDATE chapter_progress SET status = 'deprecated' "
                "WHERE user_id = ? AND chapter_id = ?",
                [user_id, chapter_map["source_chapter_id"]]
            )
        result.deprecated_items += 1
```

```python
class ContentChangeDetector:
    """检测内容变更并自动分级"""

    CHANGE_LEVELS = {
        "patch": {
            "triggers": ["typo_fix", "formula_correction", "image_replace"],
            "version_bump": "patch",
            "requires_review": False,
            "migration_needed": False,
        },
        "minor": {
            "triggers": ["new_example", "new_exercise", "explanation_rewrite",
                         "kp_description_update"],
            "version_bump": "minor",
            "requires_review": True,
            "migration_needed": False,
        },
        "major": {
            "triggers": ["chapter_restructure", "kp_tree_change",
                         "new_chapter", "chapter_removed", "curriculum_change"],
            "version_bump": "major",
            "requires_review": True,
            "migration_needed": True,
        },
    }

    def detect_change_level(
        self,
        content_type: str,
        old_snapshot: ContentVersionSnapshot,
        new_content: dict
    ) -> ChangeAnalysis:
        """分析变更级别"""
        changes = []

        if content_type == "chapter":
            changes = self._diff_chapter(old_snapshot.content_json, new_content)
        elif content_type == "knowledge_point":
            changes = self._diff_kp(old_snapshot.content_json, new_content)
        elif content_type == "question":
            changes = self._diff_question(old_snapshot.content_json, new_content)

        # 确定最高变更级别
        max_level = "patch"
        for change in changes:
            level = self._classify_change(content_type, change)
            if self._level_rank(level) > self._level_rank(max_level):
                max_level = level

        return ChangeAnalysis(
            level=max_level,
            changes=changes,
            config=self.CHANGE_LEVELS[max_level],
        )

    def _classify_change(self, content_type: str, change: dict) -> str:
        """将具体变更分类"""
        field = change.get("field", "")
        op = change.get("op", "")  # add/remove/replace

        # 章节级变更
        if content_type == "chapter":
            if field in ("title", "order") and op == "replace":
                return "major"  # 章节标题/顺序变更 = 重组
            if field == "children" and op in ("add", "remove"):
                return "major"  # 子章节增删

        # 知识点级变更
        if content_type == "knowledge_point":
            if field == "parent_id" and op == "replace":
                return "major"  # 知识点树结构变更
            if field in ("description", "explanation") and op == "replace":
                return "minor"

        # 题目级变更
        if content_type == "question":
            if field == "answer" and op == "replace":
                return "minor"  # 答案修正
            if field in ("stem", "options") and op == "replace":
                return "patch"  # 题干文字修正

        return "patch"
```

### 6.2 进度迁移影响评估

```python
class MigrationImpactAnalyzer:
    """迁移影响评估器"""

    async def analyze(self, migration: TextbookMigration) -> MigrationImpact:
        """
        评估迁移的影响范围，用于决定灰度策略。
        """
        mapping = migration.mapping_json
        source_edition = migration.source_edition_id

        # 统计受影响用户数
        affected_user_count = await self._count_affected_users(source_edition)

        # 统计各类映射的数量和占比
        mapping_stats = self._compute_mapping_stats(mapping)

        # 评估进度兼容性风险
        risk_level = self._assess_risk(mapping_stats)

        # 估算迁移耗时
        estimated_duration = self._estimate_duration(
            affected_user_count, mapping_stats
        )

        return MigrationImpact(
            affected_users=affected_user_count,
            mapping_stats=mapping_stats,
            risk_level=risk_level,         # low / medium / high
            estimated_duration=estimated_duration,
            recommended_strategy=self._recommend_strategy(risk_level),
        )

    def _assess_risk(self, stats: MappingStats) -> str:
        """
        风险评级规则：
        - 一一映射占比 > 95% → LOW
        - 复杂映射（多对多/拆分/合并）占比 > 10% → HIGH
        - 有知识点"重大内容变更" → 中风险
        """
        if stats.complex_ratio > 0.10:
            return "high"
        if stats.major_kp_changes > 0:
            return "medium"
        if stats.one_to_one_ratio > 0.95:
            return "low"
        return "medium"

    def _recommend_strategy(self, risk: str) -> dict:
        strategies = {
            "low": {
                "mode": "direct",
                "batch_size": 500,
                "notification": "silent",  # 静默迁移
                "review_required": False,
            },
            "medium": {
                "mode": "gradual",
                "batch_size": 100,
                "notification": "post_migration",  # 迁移后通知
                "review_required": True,
            },
            "high": {
                "mode": "gradual_with_consent",
                "batch_size": 50,
                "notification": "pre_migration",  # 迁移前通知
                "review_required": True,
                "user_consent": True,  # 需用户确认
            },
        }
        return strategies[risk]
```

/// 教材版本状态管理
class TextbookEditionProvider extends StateNotifier<TextbookEditionState> {
  final TextbookApi _api;
  final SharedPreferences _prefs;

  TextbookEditionProvider(this._api, this._prefs)
      : super(const TextbookEditionState.initial());

  /// 检查教材版本更新
  Future<void> checkForUpdates({
    required String subjectCode,
    required String gradeCode,
    required String semesterCode,
  }) async {
    final currentEditionId = _prefs.getInt('current_edition_$subjectCode');
    if (currentEditionId == null) return;

    state = const TextbookEditionState.checking();

    try {
      final result = await _api.checkUpdate(
        currentEditionId: currentEditionId,
      );

      if (result.hasUpdate) {
        state = TextbookEditionState.updateAvailable(
          newEdition: result.newEditionName!,
          summary: result.summary!,
          progressCompatible: result.progressCompatible!,
        );
      } else {
        state = const TextbookEditionState.upToDate();
      }
    } catch (e) {
      state = TextbookEditionState.error(e.toString());
    }
  }

  /// 接受版本更新（触发迁移）
  Future<void> acceptUpdate() async {
    state = const TextbookEditionState.migrating();
    try {
      await _api.acceptEditionUpdate();
      state = const TextbookEditionState.migrationComplete();
    } catch (e) {
      state = TextbookEditionState.error(e.toString());
    }
  }
}

  const factory TextbookEditionState.checking() = _Checking;

## 10. 容量估算

### 10.1 数据量估算

| 表 | 初始行数 | 年增长率 | 3年后预估 | 单行大小 |
|----|---------|---------|----------|---------|
| textbook_edition | ~500 | ~200 | ~1100 | ~1 KB |
| content_version_snapshot | ~10万 | ~5万 | ~25万 | ~5 KB (含 diff_json) |
| textbook_migration | ~50 | ~20 | ~110 | ~50 KB (含 mapping_json) |
| user_progress_migration | ~100万 | ~50万 | ~250万 | ~0.5 KB |

### 10.2 存储预估

- 内容版本快照（3年）：25万 × 5 KB ≈ **1.2 GB**
- 迁移映射数据（3年）：110 × 50 KB ≈ **5.5 MB**
- 用户迁移记录（3年）：250万 × 0.5 KB ≈ **1.2 GB**
- **总计约 2.5 GB**，均在 MySQL 可承受范围内

### 10.3 性能基线

| 操作 | 目标延迟 | QPS |
|------|---------|-----|
| 版本查询 | < 50ms (缓存命中) | 500 |
| 变更检测 | < 200ms | 50 |
| 映射分析 | < 60s (异步) | 1 |
| 单用户迁移 | < 500ms | 200 (并发) |
| 批量迁移 (1万用户) | < 5min | - |
