# 客户端 - 优惠券领取与使用页面架构与交互设计

## 1. 文档概述

### 1.1 文档目的

本文档为 PrimeTop（启硕）客户端优惠券领取与使用功能的详细设计，涵盖页面架构、交互流程、组件设计、状态管理和错误处理。开发人员可依据本文档直接进行编码实现。

### 1.2 适用范围

- Flutter 客户端（Android / iOS）
- 与服务端优惠券与促销活动引擎对接
- 与支付、会员订阅、增值服务商品购买等模块联动

### 1.3 依赖关系

| 依赖模块 | 说明 |
|----------|------|
| 优惠券与促销活动引擎（服务端） | 提供优惠券 CRUD、领取、核销、促销活动管理等 API |
| 支付与会员订阅模块 | 优惠券在订阅支付时的抵扣 |
| 增值服务与商品系统 | 优惠券在增值商品购买时的抵扣 |
| 积分商城 | 积分兑换优惠券 |
| 客户端-会员中心与订阅购买交互 | 订单确认页展示可用优惠券 |
| 客户端状态管理架构 | Riverpod/BLoC 状态管理 |

## 2. 页面架构总览

### 2.1 页面清单

| 页面 | 路由 | 入口 | 说明 |
|------|------|------|------|
| 优惠券中心 | `/coupon-center` | 我的页面、首页活动入口、推送跳转 | 展示可领取/已领取优惠券列表 |
| 优惠券详情弹窗 | —（BottomSheet） | 优惠券卡片点击 | 展示使用规则、有效期、适用范围 |

| 订单优惠券选择 | —（全屏弹窗） | 支付确认页"选择优惠券" | 订单可用优惠券列表 + 选择 |
| 我的优惠券列表 | `/my-coupons` | 优惠券中心 Tab、我的页面 | 按状态筛选已领取的优惠券 |

### 2.2 导航关系

```
首页 / 我的页面
  │
  ├─→ 优惠券中心 ──→ Tab: 可领取 / 未使用 / 已使用 / 已过期

  │                    └─→ [已使用/已过期] 点击 → 详情弹窗（只读）
  │
  ├─→ 领券活动页 ──→ 展示活动信息 + 可领券列表

```

## 3. 数据结构定义

### 3.1 优惠券数据模型

```dart
/// 优惠券类型枚举
enum CouponType {
  /// 满减券 - 满X元减Y元
  fullReduction,
  /// 折扣券 - X折
  discount,
  /// 立减券 - 直接减X元（无门槛）
  directReduction,
  /// 免费体验券 - 免费体验某功能N次/天
  freeTrial,
  /// 赠送券 - 赠送会员天数/功能权益
  gift,
}

/// 优惠券状态（客户端视角）
enum CouponStatus {
  /// 可领取（在领券中心展示，用户尚未领取）
  available,
  /// 已领取/未使用
  received,
  /// 已使用
  used,
  /// 已过期
  expired,
  /// 已失效（活动撤销等）
  invalidated,
}

/// 适用范围类型
enum CouponScopeType {
  /// 全场通用
  global,
  /// 指定商品/服务
  specificProduct,
  /// 指定分类（如"会员订阅"、"作文批改"）
  specificCategory,
  /// 指定学段
  specificGrade,
}

/// 优惠券模型
class CouponModel {
  /// 优惠券模板ID
  final String templateId;

  /// 优惠券实例ID（领取后分配）
  final String? instanceId;

  /// 券名称
  final String name;

  /// 券描述
  final String description;

  /// 优惠券类型
  final CouponType type;

  /// 优惠金额（满减券/立减券）
  final int? reductionAmount;

  /// 最低消费金额（满减券，单位：分）
  final int? minOrderAmount;

  /// 折扣率（折扣券，如 85 = 8.5折）
  final int? discountRate;

  /// 折扣上限（折扣券最大优惠金额，单位：分）
  final int? discountMaxAmount;

  /// 免费体验次数/天数（免费体验券）
  final int? freeTrialCount;

  /// 赠送天数（赠送券）
  final int? giftDays;

  /// 适用范围
  final CouponScopeType scopeType;

  /// 适用范围详情（商品ID列表/分类列表）
  final List<String> scopeDetails;

  /// 有效期类型：固定时间段 / 领取后N天
  final ValidityType validityType;

  /// 固定开始时间
  final DateTime? fixedStartTime;

  /// 固定结束时间
  final DateTime? fixedEndTime;

  /// 领取后有效天数
  final int? validDaysAfterReceive;

  /// 实际生效时间（领取后计算）
  final DateTime? effectiveStartTime;

  /// 实际失效时间
  final DateTime? effectiveEndTime;

  /// 库存总量（-1 表示不限量）
  final int totalStock;

  /// 剩余库存
  final int remainStock;

  /// 每人限领数量
  final int perUserLimit;

  /// 当前用户已领数量
  final int userReceivedCount;

  /// 优惠券状态
  final CouponStatus status;

  /// 使用规则说明（富文本/纯文本）
  final String usageRules;

  /// 背景图URL（用于活动页展示）
  final String? backgroundImageUrl;

  /// 关联活动ID
  final String? activityId;

  /// 创建时间
  final DateTime createdAt;

  /// 领取时间
  final DateTime? receivedAt;

  /// 使用时间
  final DateTime? usedAt;

  /// 使用的订单ID
  final String? usedOrderId;
}

enum ValidityType {
  /// 固定时间段
  fixedPeriod,
  /// 领取后N天有效
  afterReceive,
}
```

## 4. API 接口设计

### 4.1 优惠券中心接口

#### 4.1.1 获取可领取优惠券列表

```
GET /api/v1/coupons/available
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页数量，默认 20 |
| scopeType | string | 否 | 筛选适用范围类型 |

**响应：**

```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "templateId": "cpt_20260605_001",
        "name": "会员订阅8折券",
        "description": "全场会员订阅享8折优惠",
        "type": "discount",
        "discountRate": 80,
        "discountMaxAmount": 5000,
        "minOrderAmount": 1000,
        "scopeType": "specificCategory",
        "scopeDetails": ["membership"],
        "validityType": "fixedPeriod",
        "fixedEndTime": "2026-07-31T23:59:59+08:00",
        "totalStock": 10000,
        "remainStock": 3521,
        "perUserLimit": 1,
        "userReceivedCount": 0,
        "status": "available",
        "usageRules": "1. 仅限会员订阅使用\n2. 每人限领1张\n3. 不可与其他优惠叠加"
      }
    ],
    "total": 12,
    "page": 1,
    "pageSize": 20
  }
}
```

#### 4.1.2 领取优惠券

```
POST /api/v1/coupons/{templateId}/receive
```

**请求体（可选）：**

```json
{
  "activityId": "act_20260605_001"
}
```

**响应：**

```json
{
  "code": 0,
  "data": {
    "instanceId": "cpi_u123_20260605_001",
    "templateId": "cpt_20260605_001",
    "effectiveStartTime": "2026-06-05T09:00:00+08:00",
    "effectiveEndTime": "2026-07-05T23:59:59+08:00"
  }
}
```

**错误码：**

| 错误码 | 说明 |
|--------|------|
| COUPON_STOCK_EMPTY | 库存不足 |
| COUPON_LIMIT_EXCEEDED | 超过限领数量 |
| COUPON_EXPIRED | 优惠券已过期 |
| COUPON_ACTIVITY_NOT_STARTED | 活动未开始 |
| COUPON_ACTIVITY_ENDED | 活动已结束 |

#### 4.1.3 批量领取优惠券

```
POST /api/v1/coupons/batch-receive
```

**请求体：**

```json
{
  "templateIds": ["cpt_001", "cpt_002", "cpt_003"],
  "activityId": "act_20260605_001"
}
```

**响应：**

```json
{
  "code": 0,
  "data": {
    "results": [
      { "templateId": "cpt_001", "success": true, "instanceId": "cpi_001" },
      { "templateId": "cpt_002", "success": true, "instanceId": "cpi_002" },
      { "templateId": "cpt_003", "success": false, "errorCode": "COUPON_LIMIT_EXCEEDED", "errorMessage": "超过限领数量" }
    ]
  }
}
```

#### 5.1.2 优惠券卡片组件 `CouponCard`

```dart
/// 优惠券卡片组件
///
/// 展示优惠券核心信息，根据状态显示不同操作按钮
class CouponCard extends StatelessWidget {
  const CouponCard({
    super.key,
    required this.coupon,
    required this.onTap,
    this.onActionTap,
    this.compact = false,
  });

  final CouponModel coupon;
  final VoidCallback onTap;
  final VoidCallback? onActionTap;
  final bool compact;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: onTap,
      child: Container(
        margin: const EdgeInsets.symmetric(horizontal: 16, vertical: 6),
        decoration: BoxDecoration(
          color: _cardBackgroundColor(),
          borderRadius: BorderRadius.circular(12),
          border: Border.all(color: _cardBorderColor(), width: 1),
          boxShadow: [
            BoxShadow(
              color: Colors.black.withOpacity(0.05),
              blurRadius: 8,
              offset: const Offset(0, 2),
            ),
          ],
        ),
        child: IntrinsicHeight(
          child: Row(
            children: [
              // 左侧金额/折扣区域
              _buildLeftSection(context),
              // 分隔线（锯齿效果）
              _buildDivider(),
              // 右侧信息 + 操作区域
              Expanded(child: _buildRightSection(context)),
            ],
          ),
        ),
      ),
    );
  }

  Widget _buildLeftSection(BuildContext context) {
    return Container(
      width: 100,
      padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 16),
      alignment: Alignment.center,
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          _buildCouponValue(context),
          if (coupon.minOrderAmount != null && coupon.minOrderAmount! > 0)
            Padding(
              padding: const EdgeInsets.only(top: 4),
              child: Text(
                '满${(coupon.minOrderAmount! / 100).toStringAsFixed(0)}可用',
                style: TextStyle(fontSize: 10, color: Colors.grey[600]),
              ),
            ),
        ],
      ),
    );
  }

  Widget _buildCouponValue(BuildContext context) {
    switch (coupon.type) {
      case CouponType.fullReduction:
      case CouponType.directReduction:
        return Row(
          mainAxisAlignment: MainAxisAlignment.center,
          crossAxisAlignment: CrossAxisAlignment.baseline,
          textBaseline: TextBaseline.alphabetic,
          children: [
            Text('¥', style: TextStyle(fontSize: 14, color: _primaryColor())),
            Text(
              '${(coupon.reductionAmount! / 100).toStringAsFixed(0)}',
              style: TextStyle(fontSize: 36, fontWeight: FontWeight.bold, color: _primaryColor()),
            ),
          ],
        );
      case CouponType.discount:
        return Row(
          mainAxisAlignment: MainAxisAlignment.center,
          crossAxisAlignment: CrossAxisAlignment.baseline,
          textBaseline: TextBaseline.alphabetic,
          children: [
            Text(
              '${(coupon.discountRate! / 10).toStringAsFixed(1)}',
              style: TextStyle(fontSize: 36, fontWeight: FontWeight.bold, color: _primaryColor()),
            ),
            Text('折', style: TextStyle(fontSize: 14, color: _primaryColor())),
          ],
        );
      case CouponType.freeTrial:
        return Text(
          '免费体验\n${coupon.freeTrialCount}次',
          textAlign: TextAlign.center,
          style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold, color: _primaryColor()),
        );
      case CouponType.gift:
        return Text(
          '赠送\n${coupon.giftDays}天',
          textAlign: TextAlign.center,
          style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold, color: _primaryColor()),
        );
    }
  }

  Widget _buildRightSection(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 12),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(
            coupon.name,
            style: const TextStyle(fontSize: 15, fontWeight: FontWeight.w600),
            maxLines: 1,
            overflow: TextOverflow.ellipsis,
          ),
          const SizedBox(height: 4),
          Text(
            coupon.description,
            style: TextStyle(fontSize: 12, color: Colors.grey[600]),
            maxLines: 1,
            overflow: TextOverflow.ellipsis,
          ),
          const SizedBox(height: 4),
          Text(
            _validityText(),
            style: TextStyle(fontSize: 11, color: Colors.grey[500]),
          ),
          if (!compact) ...[
            const SizedBox(height: 8),
            Row(
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [
                // 库存/领取信息
                if (coupon.status == CouponStatus.available)
                  Text(
                    coupon.totalStock == -1 ? '' : '剩余 ${coupon.remainStock} 张',
                    style: TextStyle(fontSize: 11, color: Colors.orange),
                  ),
                // 操作按钮
                _buildActionButton(context),
              ],
            ),
          ],
        ],
      ),
    );
  }

  Widget _buildActionButton(BuildContext context) {
    switch (coupon.status) {
      case CouponStatus.available:
        final canReceive = coupon.userReceivedCount < coupon.perUserLimit &&
            coupon.remainStock > 0;
        return SizedBox(
          height: 28,
          child: ElevatedButton(
            onPressed: canReceive ? onActionTap : null,
            style: ElevatedButton.styleFrom(
              backgroundColor: canReceive ? _primaryColor() : Colors.grey[300],
              foregroundColor: Colors.white,
              padding: const EdgeInsets.symmetric(horizontal: 16),
              shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(14)),
              textStyle: const TextStyle(fontSize: 13),
            ),
            child: Text(coupon.userReceivedCount >= coupon.perUserLimit ? '已领取' : '立即领取'),
          ),
        );
      case CouponStatus.received:
        return SizedBox(
          height: 28,
          child: OutlinedButton(
            onPressed: onActionTap, // 跳转到使用页面
            style: OutlinedButton.styleFrom(
              foregroundColor: _primaryColor(),
              side: BorderSide(color: _primaryColor()),
              padding: const EdgeInsets.symmetric(horizontal: 16),
              shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(14)),
              textStyle: const TextStyle(fontSize: 13),
            ),

      case CouponStatus.invalidated:
        return Text('已失效', style: TextStyle(fontSize: 12, color: Colors.grey[400]));
    }

    if (coupon.status == CouponStatus.used ||
        coupon.status == CouponStatus.expired ||
        coupon.status == CouponStatus.invalidated) {
      return Colors.grey;
    }
    return const Color(0xFFEE4D2D); // 活动橙红色
  }

        coupon.status == CouponStatus.expired) {

    }
    return Colors.white;
  }

  Color _cardBorderColor() {
    if (coupon.status == CouponStatus.used ||
        coupon.status == CouponStatus.expired) {
      return Colors.grey[300]!;
    }
    return const Color(0xFFFFE0D9);

  String _validityText() {

      final fmt = DateFormat('yyyy.MM.dd');
      return '${fmt.format(coupon.effectiveStartTime!)} - ${fmt.format(coupon.effectiveEndTime!)}';
    }
    if (coupon.validityType == ValidityType.afterReceive && coupon.validDaysAfterReceive != null) {
      return '领取后${coupon.validDaysAfterReceive}天内有效';
```

```dart
class CouponRepository {
  CouponRepository(this._apiClient);
  final ApiClient _apiClient;

  Future<List<CouponModel>> getAvailableCoupons({int page = 1, int pageSize = 50}) async {

      queryParameters: {'page': page, 'pageSize': pageSize},

    final list = (response.data['list'] as List).cast<Map<String, dynamic>>();

  Future<List<CouponModel>> getMyCoupons({CouponStatus? status, int page = 1, int pageSize = 50}) async {

      },
    );
    final list = (response.data['list'] as List).cast<Map<String, dynamic>>();
    return list.map(CouponModel.fromJson).toList();
  }

  Future<ReceiveCouponResult> receiveCoupon({
    required String templateId,
    String? activityId,
  }) async {
    try {
      final response = await _apiClient.post(
        '/api/v1/coupons/$templateId/receive',
        body: {if (activityId != null) 'activityId': activityId},
      );
      return ReceiveCouponResult.fromJson(response.data);
    } on ApiException catch (e) {
      throw _mapCouponException(e);
    }
  }

  Future<BatchReceiveResult> batchReceive({
    required List<String> templateIds,
    String? activityId,
  }) async {
    try {
      final response = await _apiClient.post(
        '/api/v1/coupons/batch-receive',
        body: {
          'templateIds': templateIds,
          if (activityId != null) 'activityId': activityId,
        },
      );
      return BatchReceiveResult.fromJson(response.data);
    } on ApiException catch (e) {
      throw _mapCouponException(e);
    }
  }

  Future<OrderCouponMatchResult> matchOrderCoupons(OrderCouponMatchRequest request) async {
    final response = await _apiClient.post(
      '/api/v1/coupons/match-order',
      body: request.toJson(),
    );
    return OrderCouponMatchResult.fromJson(response.data);
  }

  Future<CouponActivityModel> getActivityDetail(String activityId) async {
    final response = await _apiClient.get('/api/v1/coupon-activities/$activityId');
    return CouponActivityModel.fromJson(response.data);
  }

  CouponException _mapCouponException(ApiException e) {
    switch (e.code) {
      case 'COUPON_STOCK_EMPTY':
        return const CouponException('优惠券已抢光，下次早点来~');
      case 'COUPON_LIMIT_EXCEEDED':
        return const CouponException('已达到领取上限');
      case 'COUPON_EXPIRED':
        return const CouponException('优惠券已过期');
      case 'COUPON_ACTIVITY_NOT_STARTED':
        return const CouponException('活动尚未开始');
      case 'COUPON_ACTIVITY_ENDED':
        return const CouponException('活动已结束');
      default:
        return CouponException(e.message ?? '操作失败，请稍后重试');
    }
  }
}

class CouponException implements Exception {
  const CouponException(this.message);
  final String message;
}
```

## 9. 错误处理

### 9.1 错误场景与处理策略

| 场景 | 错误码 | 客户端处理 |
|------|--------|-----------|
| 优惠券库存不足 | COUPON_STOCK_EMPTY | Toast 提示"已抢光" + 刷新列表 |
| 超过限领数量 | COUPON_LIMIT_EXCEEDED | 按钮置灰"已领取" + Toast 提示 |
| 优惠券已过期 | COUPON_EXPIRED | 移至"已过期"Tab + Toast 提示 |
| 活动未开始 | COUPON_ACTIVITY_NOT_STARTED | 展示倒计时 + 按钮禁用 |
| 活动已结束 | COUPON_ACTIVITY_ENDED | 展示"活动已结束" + 返回 |
| 网络超时 | NETWORK_TIMEOUT | 重试弹窗 + 自动重试1次 |
| 订单不满足使用条件 | —（本地判断） | 券卡片置灰 + 展示不可用原因 |
| 订单提交时券已被使用 | COUPON_ALREADY_REDEEMED | 弹窗提示 + 刷新券列表 + 重新计算价格 |
| 订单提交时券已过期 | COUPON_EXPIRED_AT_REDEEM | 弹窗提示 + 刷新券列表 + 回退到原价 |

```dart
/// 优惠券模块全局错误处理器
class CouponErrorHandler {
  static void handle(BuildContext context, Object error) {
    if (error is CouponException) {
      // 业务异常：直接展示错误信息
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text(error.message),
          behavior: SnackBarBehavior.floating,
        ),
      );
    } else if (error is TimeoutException) {
      // 超时：提示重试
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: const Text('网络超时，请检查网络后重试'),
          action: SnackBarAction(label: '重试', onPressed: () {
            // 触发重试逻辑
          }),
        ),
      );
    } else {
      // 未知错误
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('操作失败，请稍后重试')),
      );
    }
  }
}
```

```dart
/// 领取按钮防重复点击
class _ThrottleActionButton extends StatefulWidget {
  const _ThrottleActionButton({
    required this.onPressed,
    required this.label,
    this.enabled = true,
  });

  final Future<void> Function() onPressed;
  final String label;
  final bool enabled;

  @override
  State<_ThrottleActionButton> createState() => _ThrottleActionButtonState();
}

class _ThrottleActionButtonState extends State<_ThrottleActionButton> {
  bool _isProcessing = false;

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: (widget.enabled && !_isProcessing) ? _handleTap : null,
      child: _isProcessing
          ? const SizedBox(width: 16, height: 16, child: CircularProgressIndicator(strokeWidth: 2))
          : Text(widget.label),
    );
  }

  Future<void> _handleTap() async {
    setState(() => _isProcessing = true);
    try {
      await widget.onPressed();
    } finally {
      if (mounted) {
        setState(() => _isProcessing = false);
      }
    }
  }
}
```
