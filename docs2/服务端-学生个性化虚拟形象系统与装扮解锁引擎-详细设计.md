# 服务端-学生个性化虚拟形象系统与装扮解锁引擎-详细设计

## 1. 概述

### 1.1 功能定位

学生个性化虚拟形象系统是 PrimeTop 平台游戏化激励体系的核心组成部分。通过为每位学生用户提供可自定义的虚拟形象（Avatar），将学习成就、连续打卡、知识掌握等教育行为指标与形象装扮解锁机制联动，形成「学习→成就→装扮奖励→社交展示→学习动力增强」的正向激励闭环。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 个性化表达 | 让学生通过自定义虚拟形象获得身份认同感和归属感 |
| 成就可视化 | 将抽象的学习成就转化为具象的装扮物品，增强成就感 |
| 社交激励 | 在排行榜、学习圈、协作学习等场景展示形象，促进同伴互动 |
| 长期留存 | 通过装扮收集目标和限定物品发布，提升用户长期活跃度 |
| 分龄适配 | 不同学段采用不同视觉风格和装扮类型，满足年龄差异 |

### 1.3 适用范围

- **学段覆盖**：全学段（幼儿至高中），按学段差异化呈现
- **使用场景**：个人中心首页、排行榜、学习圈、协作学习、学习报告分享
- **集成模块**：成就系统、积分商城、学习打卡、运营活动、社交系统

### 1.4 名词定义

| 术语 | 定义 |
| --- | --- |
| Avatar | 学生用户的虚拟形象，由多个组件槽位组合而成 |
| 槽位 (Slot) | 形象的组成部分，如发型、面部、服装、配饰、背景、边框等 |
| 装扮物品 (Item) | 可装备到槽位的具体装扮资源 |
| 装扮方案 (Outfit) | 一套完整的装扮配置，用户可保存多套方案 |
| 解锁条件 (UnlockCondition) | 获取装扮物品所需满足的学习成就或行为指标 |
| 稀有度 (Rarity) | 装扮物品的珍贵等级，影响获取难度和展示效果 |
| 形象快照 (Snapshot) | 用户当前装扮配置的序列化数据，用于多端同步和社交展示 |

## 2. 数据结构设计

### 2.1 数据库表设计

#### 2.1.1 `avatar_slot` - 槽位定义表

```sql
CREATE TABLE `avatar_slot` (
  `slot_id`        VARCHAR(32)   NOT NULL COMMENT '槽位唯一标识，如 hair/face/outfit/accessory/background/frame',
  `slot_name`      VARCHAR(64)   NOT NULL COMMENT '槽位中文名称',
  `slot_category`  TINYINT       NOT NULL COMMENT '槽位分类：1=基础面部(不可更换)，2=发型，3=服装，4=配饰，5=背景，6=边框，7=特效',
  `sort_order`     INT           NOT NULL DEFAULT 0 COMMENT '显示排序',
  `is_required`    TINYINT(1)    NOT NULL DEFAULT 0 COMMENT '是否必选槽位（每个形象必须配置）',
  `is_exclusive`   TINYINT(1)    NOT NULL DEFAULT 1 COMMENT '是否互斥（同一槽位只能装备一个物品）',
  `stage_mask`     INT           NOT NULL DEFAULT 0x0F COMMENT '学段适用位掩码：bit0=幼儿, bit1=小学, bit2=初中, bit3=高中',
  `status`         TINYINT       NOT NULL DEFAULT 1 COMMENT '状态：0=禁用，1=启用',
  `created_at`     DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at`     DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`slot_id`),
  KEY `idx_category_sort` (`slot_category`, `sort_order`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='虚拟形象槽位定义表';
```

## 3. API 接口设计

### 3.1 API 总览

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 获取用户形象 | GET | `/api/v1/avatar/{userId}` | 获取用户当前虚拟形象配置 |
| 更新形象配置 | PUT | `/api/v1/avatar/config` | 更新当前用户形象装扮 |
| 获取物品商店 | GET | `/api/v1/avatar/shop` | 浏览可获取的装扮物品 |

| 装备/卸下物品 | POST | `/api/v1/avatar/equip` | 装备或卸下某个槽位的物品 |
| 获取解锁条件进度 | GET | `/api/v1/avatar/progress` | 获取未解锁物品的条件完成进度 |
| 保存装扮方案 | POST | `/api/v1/avatar/outfit` | 保存当前装扮为方案 |
| 切换装扮方案 | PUT | `/api/v1/avatar/outfit/{outfitId}/activate` | 切换到指定装扮方案 |
| 获取用户形象快照 | GET | `/api/v1/avatar/{userId}/snapshot` | 获取用户形象的公开快照（社交展示用） |
| 检查解锁触发 | POST | `/api/v1/avatar/check-unlock` | 检查指定行为是否触发新的物品解锁 |
| 获取季节限定物品 | GET | `/api/v1/avatar/seasonal` | 获取当前季节/节日限定装扮 |

#### 3.2.2 更新形象配置

```
PUT /api/v1/avatar/config
```

**请求体**

```json
{
  "equipped_slots": {
    "hair": {"item_id": 2010, "color_variant": "棕色"},
    "outfit": {"item_id": 3015, "color_variant": null},
    "accessory": {"item_id": null, "color_variant": null}
  },
  "background_color": "#FFF8E1"
}
```

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "updated_slots": ["hair", "outfit", "accessory"],
    "invalid_items": [],
    "render_preview_url": "https://cdn.primetop.com/avatar/preview/100001_1690936800.webp"
  }
}
```

**错误码**

| 错误码 | 说明 |
| --- | --- |
| 40001 | 物品不存在或已下架 |
| 40002 | 用户未拥有该物品 |
| 40003 | 物品不适用当前学段 |
| 40004 | 物品已过期 |
| 40005 | 槽位与物品类型不匹配 |

### 4.2 条件评估器实现

```java
/**
 * 解锁条件评估器
 * 负责评估用户是否满足某物品的所有解锁条件
 */
@Service
public class UnlockConditionEvaluator {

    @Resource
    private UserMetricsService userMetricsService;
    
    @Resource
    private AvatarUnlockConditionMapper conditionMapper;

    /**
     * 条件评估器策略注册表
     */
    private final Map<String, ConditionStrategy> strategyMap = new HashMap<>();

    @PostConstruct
    public void init() {
        strategyMap.put(UnlockConditionType.STREAK_DAYS, new StreakDaysStrategy());
        strategyMap.put(UnlockConditionType.TOTAL_STUDY_HOURS, new TotalStudyHoursStrategy());
        strategyMap.put(UnlockConditionType.KNOWLEDGE_POINTS_MASTERED, new KpMasteredStrategy());
        strategyMap.put(UnlockConditionType.QUESTIONS_ANSWERED, new QuestionsAnsweredStrategy());
        strategyMap.put(UnlockConditionType.ACHIEVEMENT_EARNED, new AchievementEarnedStrategy());
        strategyMap.put(UnlockConditionType.LEVEL_REACHED, new LevelReachedStrategy());
        strategyMap.put(UnlockConditionType.RANK_REACHED, new RankReachedStrategy());
        strategyMap.put(UnlockConditionType.STREAK_CORRECT, new StreakCorrectStrategy());
        strategyMap.put(UnlockConditionType.MISTAKES_REVIEWED, new MistakesReviewedStrategy());
        // ... 注册更多策略
    }

    /**
     * 评估指定物品的所有解锁条件
     * @param userId 用户ID
     * @param itemId 物品ID
     * @return 评估结果列表
     */
    public List<ConditionEvalResult> evaluateConditions(Long userId, Long itemId) {
        List<AvatarUnlockCondition> conditions = conditionMapper.findByItemId(itemId);
        
        return conditions.stream().map(condition -> {
            ConditionStrategy strategy = strategyMap.get(condition.getConditionType());
            if (strategy == null) {
                return ConditionEvalResult.unknown(condition);
            }
            
            // 查询用户当前指标值
            double currentValue = strategy.queryCurrentValue(userId, condition.getConditionParams());
            double threshold = strategy.extractThreshold(condition.getConditionParams());
            
            boolean isMet = strategy.compare(currentValue, condition.getConditionParams());
            
            return ConditionEvalResult.builder()
                .conditionId(condition.getConditionId())
                .conditionType(condition.getConditionType())
                .conditionDesc(condition.getConditionDesc())
                .currentValue(currentValue)
                .targetValue(threshold)
                .isMet(isMet)
                .progressPercent(Math.min(100.0, (currentValue / threshold) * 100))
                .build();
        }).collect(Collectors.toList());
    }

    /**
     * 检查物品是否满足所有解锁条件
     */
    public boolean isAllConditionsMet(Long userId, Long itemId) {
        List<ConditionEvalResult> results = evaluateConditions(userId, itemId);
        return results.stream().allMatch(ConditionEvalResult::isMet);
    }

    /**
     * 批量检查用户是否有新解锁的物品（由事件触发）
     */
    public List<Long> findNewlyUnlockedItems(Long userId, String triggerEventType, Map<String, Object> context) {
        // 1. 获取该事件类型关联的所有条件
        List<Long> candidateItemIds = conditionMapper.findItemIdsByConditionType(triggerEventType);
        
        // 2. 排除用户已拥有的物品
        List<Long> ownedItemIds = userAvatarItemMapper.findOwnedItemIds(userId);
        candidateItemIds.removeAll(ownedItemIds);
        
        if (candidateItemIds.isEmpty()) {
            return Collections.emptyList();
        }
        
        // 3. 批量评估条件
        return candidateItemIds.stream()
            .filter(itemId -> isAllConditionsMet(userId, itemId))
            .collect(Collectors.toList());
    }
}

/**
 * 条件策略接口
 */
public interface ConditionStrategy {
    /** 查询用户当前指标值 */
    double queryCurrentValue(Long userId, JSONObject params);
    
    /** 从条件参数中提取阈值 */
    double extractThreshold(JSONObject params);
    
    /** 比较当前值是否满足条件 */
    default boolean compare(double currentValue, JSONObject params) {
        String operator = params.getString("operator", ">=");
        double threshold = extractThreshold(params);
        return switch (operator) {
            case ">=" -> currentValue >= threshold;
            case ">" -> currentValue > threshold;
            case "==" -> currentValue == threshold;
            case "<=" -> currentValue <= threshold;
            default -> currentValue >= threshold;
        };
    }
}

/**
 * 连续学习天数策略
 */
@Component
public class StreakDaysStrategy implements ConditionStrategy {
    @Resource
    private StudyStreakService studyStreakService;
    
    @Override
    public double queryCurrentValue(Long userId, JSONObject params) {
        return studyStreakService.getCurrentStreakDays(userId);
    }
    
    @Override
    public double extractThreshold(JSONObject params) {
        return params.getIntValue("threshold");
    }
}
```

### 4.3 解锁执行器

```java
/**
 * 装扮物品解锁执行器
 */
@Service
public class AvatarUnlockExecutor {

    @Resource
    private UserAvatarItemMapper inventoryMapper;
    @Resource
    private AvatarUnlockLogMapper unlockLogMapper;
    @Resource
    private NotificationService notificationService;
    @Resource
    private PointsService pointsService;  // 积分扣减（兑换场景）
    @Resource
    private RedissonClient redisson;

    private static final String UNLOCK_LOCK_KEY = "avatar:unlock:lock:";

    /**
     * 条件触发自动解锁
     */
    @Transactional(rollbackFor = Exception.class)
    public UnlockResult unlockByCondition(Long userId, Long itemId, Long conditionId, 
                                          Map<String, Object> context) {
        // 分布式锁防止并发重复解锁
        RLock lock = redisson.getLock(UNLOCK_LOCK_KEY + userId + ":" + itemId);
        if (!lock.tryLock()) {
            return UnlockResult.skipped("正在处理中，跳过重复触发");
        }
        
        try {
            // 幂等检查：是否已拥有
            if (inventoryMapper.existsByUserIdAndItemId(userId, itemId)) {
                return UnlockResult.skipped("已拥有该物品");
            }
            
            // 写入库存
            UserAvatarItem record = new UserAvatarItem();
            record.setUserId(userId);
            record.setItemId(itemId);
            record.setAcquireSource((byte) 1); // 条件解锁
            record.setAcquireRef(String.valueOf(conditionId));
            record.setIsEquipped(false);
            inventoryMapper.insert(record);
            
            // 写解锁日志
            AvatarUnlockLog log = new AvatarUnlockLog();
            log.setUserId(userId);
            log.setItemId(itemId);
            log.setConditionId(conditionId);
            log.setUnlockType((byte) 1);
            log.setUnlockContext(JSON.toJSONString(context));
            unlockLogMapper.insert(log);
            
            // 发送通知
            AvatarItem item = avatarItemMapper.selectById(itemId);
            UnlockNotification notif = buildUnlockNotification(item);
            notificationService.sendUnlockNotification(userId, notif);
            
            return UnlockResult.success(item);
        } finally {
            lock.unlock();
        }
    }

    /**
     * 积分兑换解锁
     */
    @Transactional(rollbackFor = Exception.class)
    public UnlockResult redeemByPoints(Long userId, Long itemId) {
        AvatarItem item = avatarItemMapper.selectById(itemId);
        
        // 前置校验
        validateRedeemable(userId, item);
        
        // 扣减积分
        pointsService.deduct(userId, item.getPointsCost(), 
            PointsChangeType.AVATAR_PURCHASE, "兑换装扮：" + item.getItemName());
        
        // 写入库存
        UserAvatarItem record = new UserAvatarItem();
        record.setUserId(userId);
        record.setItemId(itemId);
        record.setAcquireSource((byte) 2); // 积分兑换
        record.setAcquireRef(OrderIdGenerator.next());
        record.setIsEquipped(false);
        inventoryMapper.insert(record);
        
        // 写解锁日志
        AvatarUnlockLog log = new AvatarUnlockLog();
        log.setUserId(userId);
        log.setItemId(itemId);
        log.setUnlockType((byte) 2);
        unlockLogMapper.insert(log);
        
        return UnlockResult.success(item);
    }

    private void validateRedeemable(Long userId, AvatarItem item) {
        if (item == null || item.getReleaseStatus() != 1) {
            throw new BizException(40011, "物品不可用");
        }
        if (item.getPointsCost() == null || item.getPointsCost() <= 0) {
            throw new BizException(40011, "该物品不可通过积分获取");
        }
        if (inventoryMapper.existsByUserIdAndItemId(userId, item.getItemId())) {
            throw new BizException(40012, "已拥有该物品");
        }
        if (item.getExpireAt() != null && item.getExpireAt().isBefore(LocalDateTime.now())) {
            throw new BizException(40013, "物品已下架");
        }
        // 学段校验
        UserDTO user = userService.getUser(userId);
        if (!StageMaskUtil.matches(item.getStageMask(), user.getStage())) {
            throw new BizException(40003, "物品不适用当前学段");
        }
    }

    private UnlockNotification buildUnlockNotification(AvatarItem item) {
        String rarityEmoji = switch (item.getRarity()) {
            case 1 -> "✨";
            case 2 -> "💎";
            case 3 -> "🌟";
            case 4 -> "👑";
            case 5 -> "🎁";
            default -> "🎉";
        };
        
        return UnlockNotification.builder()
            .title(rarityEmoji + " 新装扮解锁！")
            .body("恭喜获得「" + item.getItemName() + "」！" 
                  + ItemRarity.getByCode(item.getRarity()).getLabel() + "品质")
            .actionUrl("/avatar/inventory?new=" + item.getItemId())
            .thumbUrl(item.getAssetThumbUrl())
            .build();
    }
}
```

### 4.4 事件驱动解锁触发流程

```java
/**
 * 学习行为事件消费者
 * 监听各业务模块的学习行为事件，触发装扮解锁检查
 */
@Component
@RocketMQMessageListener(
    topic = "${avatar.unlock.topic:avatar-unlock-check}",
    consumerGroup = "${avatar.unlock.group:avatar-unlock-consumer}",
    consumeMode = ConsumeMode.CONCURRENTLY
)
public class AvatarUnlockConsumer implements RocketMQListener<UnlockCheckEvent> {

    @Resource
    private UnlockConditionEvaluator evaluator;
    @Resource
    private AvatarUnlockExecutor executor;

    @Override
    public void onMessage(UnlockCheckEvent event) {
        Long userId = event.getUserId();
        String triggerType = event.getTriggerEventType();
        
        log.info("装扮解锁检查触发: userId={}, triggerType={}", userId, triggerType);
        
        try {
            // 1. 查找可能新解锁的物品
            List<Long> newItemIds = evaluator.findNewlyUnlockedItems(userId, triggerType, event.getContext());
            
            if (newItemIds.isEmpty()) {
                return;
            }
            
            // 2. 逐个执行解锁
            for (Long itemId : newItemIds) {
                try {
                    UnlockResult result = executor.unlockByCondition(
                        userId, itemId, null, event.getContext());
                    if (result.isSuccess()) {
                        log.info("装扮解锁成功: userId={}, itemId={}", userId, itemId);
                    }
                } catch (Exception e) {
                    log.error("装扮解锁失败: userId={}, itemId={}", userId, itemId, e);
                }
            }
            
            // 3. 发送批量解锁通知
            if (!newItemIds.isEmpty()) {
                notificationService.batchNotifyUnlock(userId, newItemIds);
            }
        } catch (Exception e) {
            log.error("装扮解锁检查异常: userId={}", userId, e);
            // 不抛出异常，避免消息重试风暴
        }
    }
}

/**
```
```java
 * 虚拟形象缓存服务

@Service
public class AvatarCacheService {

    @Resource
    private RedisTemplate<String, String> redis;
    
    // 缓存Key定义
    private static final String KEY_USER_AVATAR = "avatar:config:";        // 用户形象配置
    private static final String KEY_USER_SNAPSHOT = "avatar:snapshot:";    // 用户形象公开快照
    private static final String KEY_ITEM_CATALOG = "avatar:catalog:";      // 物品目录
    private static final String KEY_SLOT_DEF = "avatar:slots";             // 槽位定义
    private static final String KEY_SEASONAL = "avatar:seasonal:";         // 季节限定
    
    // TTL配置
    private static final Duration TTL_AVATAR_CONFIG = Duration.ofMinutes(30);
    private static final Duration TTL_SNAPSHOT = Duration.ofHours(2);
    private static final Duration TTL_CATALOG = Duration.ofHours(6);
    private static final Duration TTL_SEASONAL = Duration.ofHours(12);

    /**
     * 获取用户形象配置（带缓存）
     */
    public UserAvatarConfig getUserAvatar(Long userId) {
        String key = KEY_USER_AVATAR + userId;
        String cached = redis.opsForValue().get(key);
        
        if (cached != null) {
            return JSON.parseObject(cached, UserAvatarConfig.class);
        }
        
        // 查DB
        UserAvatarConfig config = avatarMapper.selectConfig(userId);
        if (config != null) {
            redis.opsForValue().set(key, JSON.toJSONString(config), TTL_AVATAR_CONFIG);
        }
        return config;
    }

    /**
     * 更新形象配置后清除缓存
     */
    public void invalidateUserAvatar(Long userId) {
        redis.delete(KEY_USER_AVATAR + userId);
        redis.delete(KEY_USER_SNAPSHOT + userId);  // 同时清除快照
    }

    /**
     * 获取用户公开快照（用于社交展示，数据更精简）
     */
    public AvatarSnapshot getPublicSnapshot(Long userId) {
        String key = KEY_USER_SNAPSHOT + userId;
        String cached = redis.opsForValue().get(key);
        
        if (cached != null) {
            return JSON.parseObject(cached, AvatarSnapshot.class);
        }
        
        AvatarSnapshot snapshot = buildSnapshot(userId);
        redis.opsForValue().set(key, JSON.toJSONString(snapshot), TTL_SNAPSHOT);
        return snapshot;
    }

     * 获取物品目录（全局缓存）
     */
    public List<AvatarItem> getItemCatalog(String slotId, int rarity) {
        String key = KEY_ITEM_CATALOG + slotId + ":" + rarity;
        // ... 缓存逻辑
    }

    /**
     * 获取季节限定物品列表
     */
    public List<AvatarItem> getSeasonalItems(String seasonTag) {
        String key = KEY_SEASONAL + seasonTag;
        String cached = redis.opsForValue().get(key);
        if (cached != null) {
            return JSON.parseArray(cached, AvatarItem.class);
        }
        
        // 查询当前有效的季节物品
        List<AvatarItem> items = itemMapper.findSeasonalActive(seasonTag, LocalDateTime.now());
        redis.opsForValue().set(key, JSON.toJSONString(items), TTL_SEASONAL);
        return items;
    }
```

### 7.2 学段切换时的形象迁移

```java
/**
 * 学段升迁时的形象处理服务
 */
@Service
public class AvatarStageTransitionHandler {

    /**
     * 学生学段变更时，处理装扮物品的兼容性
     */
    @Transactional
    public void onStageChange(Long userId, String oldStage, String newStage) {
        UserAvatarConfig config = avatarService.getUserAvatar(userId);
        
        // 1. 检查当前装备的物品是否适用新学段
        Map<String, EquippedItem> validSlots = new HashMap<>();
        List<String> invalidSlots = new ArrayList<>();
        
        for (Map.Entry<String, EquippedItem> entry : config.getEquippedSlots().entrySet()) {
            String slotId = entry.getKey();
            EquippedItem equipped = entry.getValue();
            
            AvatarItem item = itemService.getById(equipped.getItemId());
            if (item != null && StageMaskUtil.matches(item.getStageMask(), newStage)) {
                validSlots.put(slotId, equipped);
            } else {
                invalidSlots.add(slotId);
            }
        }
        
        // 2. 对不适用的槽位，替换为新学段的默认物品
        StageAvatarConfig newStageConfig = getStageConfig(newStage);
        for (String slotId : invalidSlots) {
            String defaultItemCode = newStageConfig.getDefaultItems().get(slotId);
            AvatarItem defaultItem = itemService.getByCode(defaultItemCode);
            
            // 确保用户拥有默认物品
            if (!inventoryService.owns(userId, defaultItem.getItemId())) {
                inventoryService.grantDefaultItem(userId, defaultItem.getItemId());
            }
            
            EquippedItem equipped = new EquippedItem();
            equipped.setItemId(defaultItem.getItemId());
            equipped.setItemCode(defaultItem.getItemCode());
            validSlots.put(slotId, equipped);
        }
        
        // 3. 新学段新增的槽位（如初中新增effect），补充默认
        Set<String> newSlots = new HashSet<>(newStageConfig.getAvailableSlots());
        for (String newSlot : newSlots) {
            if (!validSlots.containsKey(newSlot)) {
                String defaultItemCode = newStageConfig.getDefaultItems().get(newSlot);
                if (defaultItemCode != null) {
                    AvatarItem defaultItem = itemService.getByCode(defaultItemCode);
                    inventoryService.grantDefaultItem(userId, defaultItem.getItemId());
                    // 装备默认物品
                    EquippedItem equipped = new EquippedItem();
                    equipped.setItemId(defaultItem.getItemId());
                    validSlots.put(newSlot, equipped);
                }
            }
        }
        
        // 4. 更新配置
        config.setEquippedSlots(validSlots);
        avatarService.updateConfig(userId, config);
        
        // 5. 通知用户
        if (!invalidSlots.isEmpty()) {
            notificationService.sendAvatarChangeNotice(userId, invalidSlots, newStage);
        }
    }
}
```

```java
@Service
public class AvatarDisplayAdapter {

     * 场景尺寸枚举
     */
    public enum DisplayScene {
        PROFILE_LARGE(400, 400),      // 个人中心大图
        PROFILE_MEDIUM(120, 120),     // 中等尺寸
        LEADERBOARD(64, 64),          // 排行榜头像
        STUDY_GROUP(48, 48),          // 学习圈小头像
        SHARE_CARD(200, 200),         // 分享卡片
        NOTIFICATION(32, 32);         // 通知栏图标

        DisplayScene(int w, int h) { this.size = w; }
    }

    /**
     * 根据场景获取适配的形象快照
     */
    public AvatarSnapshot getSnapshotForScene(Long userId, DisplayScene scene) {
        AvatarSnapshot snapshot = cacheService.getPublicSnapshot(userId);
        
        // 大图场景：返回完整图层列表
        if (scene.size >= 200) {
            return snapshot;
        }
        
        // 小图场景：仅保留关键图层（face + outfit + frame），丢弃细节
        List<LayerAsset> simplified = snapshot.getLayers().stream()
            .filter(layer -> Set.of("face", "outfit", "frame").contains(layer.getSlotId()))
            .collect(Collectors.toList());
        snapshot.setLayers(simplified);
        
        return snapshot;
    }

    /**
     * 批量获取排行榜用户形象（优化为批量查询）
     */
    public Map<Long, AvatarSnapshot> batchGetSnapshots(List<Long> userIds, DisplayScene scene) {
        // 批量从Redis获取
        List<String> keys = userIds.stream()
            .map(id -> "avatar:snapshot:" + id)
            .collect(Collectors.toList());
        List<String> values = redis.opsForValue().multiGet(keys);
        
        Map<Long, AvatarSnapshot> result = new HashMap<>();
        for (int i = 0; i < userIds.size(); i++) {
            String json = values.get(i);
            if (json != null) {
                AvatarSnapshot snapshot = JSON.parseObject(json, AvatarSnapshot.class);
                result.put(userIds.get(i), adaptForScene(snapshot, scene));
            }
        }
        
        // 未命中缓存的用户，批量查DB
        List<Long> missed = userIds.stream()
            .filter(id -> !result.containsKey(id))
            .collect(Collectors.toList());
        if (!missed.isEmpty()) {
            List<AvatarSnapshot> dbSnapshots = avatarMapper.batchSelectSnapshots(missed);
            for (AvatarSnapshot s : dbSnapshots) {
                result.put(s.getUserId(), adaptForScene(s, scene));
                cacheService.cacheSnapshot(s);
            }
        }
        
        return result;
    }
}
```

```java
@Service
public class ActivityAvatarGrantService {

    /**
     * 批量为活动参与者发放装扮奖励
     */
    @Transactional
    public GrantResult batchGrantFromActivity(Long activityId, List<Long> userIds, Long itemId) {
        AvatarItem item = itemMapper.selectById(itemId);

            throw new BizException("物品不支持活动发放");

                // 幂等检查
                if (inventoryMapper.existsByUserIdAndItemId(userId, itemId)) {
                    skipCount++;
                    continue;
                }
                
                // 发放物品
                UserAvatarItem record = new UserAvatarItem();
                record.setUserId(userId);
                record.setItemId(itemId);
                record.setAcquireSource((byte) 3); // 活动奖励

                record.setIsEquipped(false);
                inventoryMapper.insert(record);
                
                // 写日志
                unlockLogService.logActivityGrant(userId, itemId, activityId);
                
                successCount++;
            } catch (Exception e) {
                failedUserIds.add(userId);
                log.error("活动装扮发放失败: userId={}, itemId={}", userId, itemId, e);
            }
        }
        
        return GrantResult.builder()
            .totalUsers(userIds.size())
            .successCount(successCount)
            .skipCount(skipCount)
            .failedUserIds(failedUserIds)
            .build();
    }
```

### 11.2 批量操作优化

```java
/**
 * 批量获取多个用户的形象配置（用于排行榜、学习圈等场景）
 */
public Map<Long, UserAvatarConfig> batchGetAvatars(List<Long> userIds) {
    // 1. Redis pipeline 批量查询
    List<String> keys = userIds.stream()
        .map(id -> "avatar:config:" + id)
        .collect(Collectors.toList());
    List<String> cached = redis.opsForValue().multiGet(keys);
    
    Map<Long, UserAvatarConfig> result = new HashMap<>();
    List<Long> cacheMissIds = new ArrayList<>();
    
    for (int i = 0; i < userIds.size(); i++) {
        if (cached.get(i) != null) {
            result.put(userIds.get(i), JSON.parseObject(cached.get(i), UserAvatarConfig.class));
        } else {
            cacheMissIds.add(userIds.get(i));
        }
    }
    
    // 2. 未命中的批量查DB
    if (!cacheMissIds.isEmpty()) {
        // 分批查询，避免IN条件过长
        Lists.partition(cacheMissIds, 200).forEach(batch -> {
            List<UserAvatarConfig> dbConfigs = avatarMapper.batchSelectConfigs(batch);
            Map<Long, String> cacheMap = new HashMap<>();
            for (UserAvatarConfig config : dbConfigs) {
                result.put(config.getUserId(), config);
                cacheMap.put("avatar:config:" + config.getUserId(), JSON.toJSONString(config));
            }
            // 批量写入缓存
            if (!cacheMap.isEmpty()) {
                redis.opsForValue().multiSet(cacheMap);
                // 批量设置TTL
                cacheMap.keySet().forEach(k -> redis.expire(k, TTL_AVATAR_CONFIG));
            }
        });
    }
    
    return result;
}
```

```java
/**
 * 装扮变更的乐观锁控制
 * 防止多端同时修改导致的数据不一致
 */
@Transactional
public UpdateResult updateAvatarConfig(Long userId, AvatarUpdateRequest request, 
                                        int expectedVersion) {
    // 乐观锁校验
    int currentVersion = avatarMapper.selectVersion(userId);
    if (currentVersion != expectedVersion) {
        throw new BizException(40060, "形象配置已变更，请刷新后重试");
    }
    
    // 执行更新
    avatarMapper.updateConfig(userId, request.getEquippedSlots(), 
                              request.getBackgroundColor(), currentVersion + 1);
    
    // 清除缓存
    cacheService.invalidateUserAvatar(userId);
    
    return UpdateResult.success(currentVersion + 1);
}

/**
 * 积分兑换的防重复提交
 */
@Transactional
public UnlockResult redeemWithIdempotency(Long userId, Long itemId, String requestId) {
    // Redis 防重窗口（5分钟）
    String idempotentKey = "avatar:redeem:" + requestId;
    Boolean firstTime = redis.opsForValue().setIfAbsent(idempotentKey, "1", Duration.ofMinutes(5));
    
    if (Boolean.FALSE.equals(firstTime)) {
        // 检查是否已处理完成
        String result = redis.opsForValue().get(idempotentKey + ":result");
        if (result != null) {
            return JSON.parseObject(result, UnlockResult.class);
        }
        throw new BizException(40040, "操作正在处理中，请稍后");
    }
    
    try {
        UnlockResult result = executor.redeemByPoints(userId, itemId);
        redis.opsForValue().set(idempotentKey + ":result", JSON.toJSONString(result), 
                                Duration.ofMinutes(5));
        return result;
    } catch (Exception e) {
        redis.delete(idempotentKey);  // 失败时清除防重标记，允许重试
        throw e;
    }
}
```

### 16.3 用户注册时自动初始化

```java
/**
 * 用户注册成功后初始化虚拟形象
 */
@Service
public class AvatarInitializationService {

    @EventListener
    @Async
    public void onUserRegistered(UserRegisteredEvent event) {
        Long userId = event.getUserId();
        String stage = event.getStage(); // kindergarten / primary / junior_high / senior_high
        
        StageAvatarConfig stageConfig = getStageConfig(stage);
        
        // 1. 创建形象配置记录
        UserAvatarConfig config = new UserAvatarConfig();
        config.setUserId(userId);
        config.setEquippedSlots(new HashMap<>());
        config.setBackgroundColor(stageConfig.getDefaultBackgroundColor());
        
        // 2. 发放默认物品并装备
        for (Map.Entry<String, String> entry : stageConfig.getDefaultItems().entrySet()) {
            String slotId = entry.getKey();
            String itemCode = entry.getValue();
            
            AvatarItem item = itemService.getByCode(itemCode);
            
            // 写入库存
            UserAvatarItem inventory = new UserAvatarItem();
            inventory.setUserId(userId);
            inventory.setItemId(item.getItemId());
            inventory.setAcquireSource((byte) 4); // 系统默认
            inventory.setIsEquipped(true);
            inventoryMapper.insert(inventory);
            
            // 写入装备配置
            EquippedItem equipped = new EquippedItem();
            equipped.setItemId(item.getItemId());
            equipped.setItemCode(item.getItemCode());
            equipped.setAssetUrl(item.getAssetUrl());
            config.getEquippedSlots().put(slotId, equipped);
        }
        
        // 3. 保存配置
        avatarMapper.insertConfig(userId, config);
        
        // 4. 预生成快照缓存
        cacheService.cacheSnapshot(buildSnapshot(userId, config));
    }
}
```
