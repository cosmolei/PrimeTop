# 客户端-系统资源压力感知与智能降级调度引擎-详细设计

## 1. 概述

### 1.1 功能定位

PrimeTop 作为一款面向 K12 全学段学生的 AI 辅助学习 APP，运行在覆盖低中高端的各种 Android / iOS 设备上。学生用户群体中大量使用中低端 Android 机型，设备资源（电池、内存、CPU、存储、温度）参差不齐。本引擎负责**实时感知设备系统级资源压力**，并在资源紧张时**自动触发智能降级策略**，确保核心学习体验不中断、不卡顿、不过度消耗电量。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 核心学习场景（AI对话、拍题、错题本）在低端设备上不因资源压力崩溃 | 崩溃率 < 0.1% |
| 电池消耗在低电量时降低 40%+ | 降级生效后功耗下降 |
| 内存峰值在低端设备上控制在设备物理内存的 60% 以内 | OOM 崩溃率 < 0.05% |
| 温度过高时自动减少 CPU 密集操作 | 机身温度不再持续上升 |
| 存储空间不足时自动清理 | 可用空间恢复 ≥ 200MB |
| 降级过程用户无感知 | 无突兀 UI 变化、无功能完全不可用 |

### 1.3 适用范围

- **平台**：Flutter（Android + iOS）
- **场景**：全 APP 生命周期（前台学习 + 后台同步）
- **用户**：所有设备层级，重点优化低端设备体验

### 1.4 名词解释

| 术语 | 含义 |
| --- | --- |
| Device Tier | 设备能力分级（High / Medium / Low） |
| Pressure Level | 资源压力等级（Nominal / Warning / Critical / Emergency） |
| Degradation | 降级，指在资源压力下主动减少功能开销 |
| Graceful Degradation | 优雅降级，用户无感知地减少资源消耗 |
| Resource Monitor | 资源监控器，运行时采集设备资源状态 |
| Degradation Strategy | 降级策略，针对特定压力等级的具体行为调整 |

### 2.2 核心组件

| 组件 | 职责 |
| --- | --- |
| **ResourceMonitor**（资源监控器） | 采集单一维度（电池/内存/温度等）的设备状态 |
| **StateManager**（状态管理器） | 汇总各监控器数据，计算当前全局压力等级 |
| **DecisionEngine**（决策引擎） | 根据压力等级 + 用户上下文 + 设备分级，决定降级策略组合 |
| **StrategyRegistry**（策略注册表） | 预注册所有降级策略，支持动态查询和触发 |
| **EventBus**（事件总线） | 发布压力变化事件，供业务模块订阅响应 |
| **DegradationAwareMixin** | Flutter Widget / Service 混入，自动响应降级指令 |

### 3.2 资源压力等级

```dart
/// 资源维度
enum ResourceDimension {
  battery,
  memory,
  thermal,
  storage,
  cpu,
  network,
}

/// 压力等级（每个维度独立评估）
enum PressureLevel {
  /// 正常：资源充足，无限制
  nominal,
  /// 警告：资源开始紧张，执行轻微优化
  warning,
  /// 严重：资源明显不足，执行显著降级
  critical,
  /// 紧急：资源极度匮乏，只保留核心功能
  emergency,
}

/// 单维度资源状态快照
class ResourceSnapshot {
  final ResourceDimension dimension;
  final PressureLevel level;
  final double rawValue;        // 原始值（百分比/MB/温度等）
  final String unit;
  final DateTime timestamp;
  final Map<String, dynamic> metadata; // 维度附加数据

  ResourceSnapshot({
    required this.dimension,
    required this.level,
    required this.rawValue,
    required this.unit,
    required this.timestamp,
    this.metadata = const {},
  });
}

/// 全局资源压力状态
class GlobalPressureState {
  final Map<ResourceDimension, ResourceSnapshot> dimensions;
  final PressureLevel overallLevel;  // 取最高维度等级
  final DateTime timestamp;

  GlobalPressureState({
    required this.dimensions,
    required this.overallLevel,
    required this.timestamp,
  });

  /// 获取某维度当前等级
  PressureLevel levelOf(ResourceDimension dim) {
    return dimensions[dim]?.level ?? PressureLevel.nominal;
  }

  /// 是否需要降级
  bool get needsDegradation => overallLevel.index >= PressureLevel.warning.index;
}
```

```dart
/// 降级策略定义
class DegradationStrategy {

  final String name;
  final String description;

    required this.name,
    required this.description,
    required this.triggers,
    required this.priority,
    required this.onApply,
    required this.onRecover,
```

### 4.1 电池监控器（BatteryMonitor）

#### 4.1.1 监控指标

| 指标 | 采集方式 | 采集频率 |
| --- | --- | --- |
| 电量百分比 | 平台 API | 每 60s + 充电状态变化事件 |
| 充电状态 | 平台广播事件 | 事件驱动 |
| 省电模式状态 | 系统设置读取 | 每 30s |
| 预估剩余时间（iOS） | `UIDevice.batteryLevel` + ProcessInfo | 每 60s |
| 后台耗电 TOP 服务 | Android: BatteryStats | 每 5min |

#### 4.1.2 压力等级判定规则

```dart
class BatteryMonitor extends ResourceMonitor {
  @override
  PressureLevel calculateLevel(BatteryData data) {
    // 省电模式直接升一级
    int offset = data.isLowPowerMode ? 1 : 0;

    if (data.isCharging) {
      // 充电中：电量不是问题，但可能伴随发热
      return PressureLevel.nominal;
    }

    int baseLevel;
    if (data.percentage >= 50) {
      baseLevel = 0; // nominal
    } else if (data.percentage >= 25) {
      baseLevel = 1; // warning
    } else if (data.percentage >= 10) {
      baseLevel = 2; // critical
    } else {
      baseLevel = 3; // emergency
    }

    int finalLevel = (baseLevel + offset).clamp(0, 3);
    return PressureLevel.values[finalLevel];
  }
}
```

#### 4.1.3 平台实现

**Android（Kotlin）：**

```kotlin
class BatteryMonitorPlugin : EventChannel.StreamHandler {
    private var receiver: BroadcastReceiver? = null

    override fun onListen(arguments: Any?, events: EventChannel.EventSink) {
        // 注册电池状态广播接收器
        receiver = object : BroadcastReceiver() {
            override fun onReceive(context: Context?, intent: Intent?) {
                val level = intent?.getIntExtra(BatteryManager.EXTRA_LEVEL, -1) ?: -1
                val scale = intent?.getIntExtra(BatteryManager.EXTRA_SCALE, -1) ?: -1
                val percentage = (level.toFloat() / scale.toFloat() * 100).toInt()
                val status = intent?.getIntExtra(BatteryManager.EXTRA_STATUS, -1) ?: -1
                val isCharging = status == BatteryManager.BATTERY_STATUS_CHARGING ||
                                 status == BatteryManager.BATTERY_STATUS_FULL

                // 检查省电模式
        val powerManager = context?.getSystemService(Context.POWER_SERVICE) as PowerManager
        val isLowPower = powerManager.isPowerSaveMode

                events.success(mapOf(
                    "percentage" to percentage,
                    "isCharging" to isCharging,
                    "isLowPowerMode" to isLowPower
                ))
            }
        }

        appContext.registerReceiver(
            receiver,
            IntentFilter(Intent.ACTION_BATTERY_CHANGED)
        )

        // 定时轮询省电模式变化
        startPowerModePolling(events)
    }

    private fun startPowerModePolling(events: EventChannel.EventSink) {
        handler.postDelayed(object : Runnable {
            override fun run() {
                val pm = appContext.getSystemService(Context.POWER_SERVICE) as PowerManager
                events.success(mapOf(
                    "type" to "powerMode",
                    "isLowPowerMode" to pm.isPowerSaveMode
                ))
                handler.postDelayed(this, 30_000)
            }
        }, 30_000)
    }

    override fun onCancel(arguments: Any?) {
        appContext.unregisterReceiver(receiver)
        receiver = null
    }
}
```

```swift
class BatteryMonitorPlugin: NSObject, FlutterPlugin, FlutterStreamHandler {
    private var eventSink: FlutterEventSink?

    func register(with registrar: FlutterPluginRegistrar) {
        let channel = FlutterEventChannel(
            name: "primetop/battery_monitor",
            binaryMessenger: registrar.messenger()
        )
        channel.setStreamHandler(self)
    }

    func onListen(withArguments arguments: Any?, eventSink events: @escaping FlutterEventSink) -> FlutterError? {
        self.eventSink = events

        UIDevice.current.isBatteryMonitoringEnabled = true

        // 电池状态变化通知
        NotificationCenter.default.addObserver(
            self,
            selector: #selector(batteryLevelChanged),
            name: UIDevice.batteryLevelDidChangeNotification,
            object: nil
        )
        NotificationCenter.default.addObserver(
            self,
            selector: #selector(batteryStateChanged),
            name: UIDevice.batteryStateDidChangeNotification,
            object: nil
        )

        // 低电量模式通知（iOS 15+）
        if #available(iOS 15.0, *) {
            NotificationCenter.default.addObserver(
                self,
                selector: #selector(lowPowerModeChanged),
                name: Notification.Name.NSProcessInfoPowerStateDidChange,
                object: nil
            )
        }

        sendCurrentState()
        return nil
    }

    @objc private func batteryLevelChanged() {
        sendCurrentState()
    }

    @objc private func batteryStateChanged() {
        sendCurrentState()
    }

    @objc private func lowPowerModeChanged() {
        sendCurrentState()
    }

    private func sendCurrentState() {
        let level = UIDevice.current.batteryLevel
        let percentage = Int(level * 100)
        let state = UIDevice.current.batteryState
        let isCharging = (state == .charging || state == .full)
        let isLowPower = ProcessInfo.processInfo.isLowPowerModeEnabled

        DispatchQueue.main.async {
            self.eventSink?([
                "percentage": percentage,
                "isCharging": isCharging,
                "isLowPowerMode": isLowPower
            ])
        }
    }
}
```

### 4.2 内存监控器（MemoryMonitor）

#### 4.2.1 监控指标

| 指标 | 采集方式 | 频率 |
| --- | --- | --- |
| 可用内存（MB） | ActivityManager.MemoryInfo / NSProcessInfo | 每 15s |
| APP 已用堆内存 | Dart VM / Native | 每 15s |
| APP 内存限制（MB） | Android: getMemoryInfo / iOS: 进程限制 | 每 60s |
| 内存压力通知 | Android: onTrimMemory / iOS: didReceiveMemoryWarning | 事件驱动 |

#### 4.2.2 压力等级判定规则

```dart
class MemoryMonitor extends ResourceMonitor {
  @override
  PressureLevel calculateLevel(MemoryData data) {
    // 内存使用率 = 已用 / 限制
    double usageRatio = data.appMemoryUsedMB / data.appMemoryLimitMB;

    // 可用系统内存因子
    double availableRatio = data.systemAvailableMB / data.systemTotalMB;

    // 综合评分
    if (usageRatio >= 0.90 || availableRatio <= 0.05) {
      return PressureLevel.emergency;
    } else if (usageRatio >= 0.75 || availableRatio <= 0.10) {
      return PressureLevel.critical;
    } else if (usageRatio >= 0.60 || availableRatio <= 0.15) {
      return PressureLevel.warning;
    } else {
      return PressureLevel.nominal;
    }
    }
  }
}
```

#### 4.2.3 Android 内存回调

```kotlin
class MemoryMonitorPlugin : EventChannel.StreamHandler {
    private var trimCallback: AppComponentCallbacks? = null

    override fun onListen(arguments: Any?, events: EventChannel.EventSink) {
        trimCallback = AppComponentCallbacks(events)
        // 注册到 Application
        (appContext as Application).registerComponentCallbacks(trimCallback)
        startMemoryPolling(events)
    }

    private fun startMemoryPolling(events: EventChannel.EventSink) {
        val handler = Handler(Looper.getMainLooper())
        val runnable = object : Runnable {
            override fun run() {
                val memoryInfo = ActivityManager.MemoryInfo()
                val am = appContext.getSystemService(Context.ACTIVITY_SERVICE) as ActivityManager
                am.getMemoryInfo(memoryInfo)

                val runtime = Runtime.getRuntime()
                val usedMB = (runtime.totalMemory() - runtime.freeMemory()) / (1024 * 1024)
                val limitMB = runtime.maxMemory() / (1024 * 1024)

                events.success(mapOf(
                    "systemAvailableMB" to memoryInfo.availMem / (1024 * 1024),
                    "systemTotalMB" to memoryInfo.totalMem / (1024 * 1024),
                    "systemThresholdMB" to memoryInfo.threshold / (1024 * 1024),
                    "appMemoryUsedMB" to usedMB.toInt(),
                    "appMemoryLimitMB" to limitMB.toInt(),
                    "isLowMemory" to memoryInfo.lowMemory
                ))
                handler.postDelayed(this, 15_000)
            }
        }
        handler.post(runnable)
    }
}

class AppComponentCallbacks(
    private val events: EventChannel.EventSink
) : ComponentCallbacks2 {
    override fun onTrimMemory(level: Int) {
        val pressureLevel = when (level) {
            TRIM_MEMORY_COMPLETE,
            TRIM_MEMORY_RUNNING_CRITICAL -> "emergency"
            TRIM_MEMORY_RUNNING_LOW -> "critical"
            TRIM_MEMORY_RUNNING_MODERATE,
            TRIM_MEMORY_MODERATE -> "warning"
            else -> "nominal"
        }
        events.success(mapOf(
            "type" to "trimMemory",
            "level" to level,
            "pressureLevel" to pressureLevel
        ))
    }

    override fun onLowMemory() {
        events.success(mapOf(
            "type" to "lowMemory",
            "pressureLevel" to "emergency"
        ))
    }

    override fun onConfigurationChanged(newConfig: Configuration) {}
}
```

```dart
class ThermalMonitor extends ResourceMonitor {
  @override
  PressureLevel calculateLevel(ThermalData data) {
    // Android: thermalStatus (0-6)
    // iOS: ProcessInfo.thermalState (0-3)
    if (data.thermalStatus >= 4) {  // Android: OVERHEATED
      return PressureLevel.emergency;
    } else if (data.thermalStatus >= 3) {
      return PressureLevel.critical;
    } else if (data.thermalStatus >= 2) {
      return PressureLevel.warning;
    } else {
      return PressureLevel.nominal;
    }
  }
}
```

```kotlin
    private var receiver: BroadcastReceiver? = null

    override fun onListen(arguments: Any?, events: EventChannel.EventSink) {
        manager = appContext.getSystemService(Context.POWER_SERVICE) as PowerManager

        // Android 12+ 监听热状态广播
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) {
            receiver = object : BroadcastReceiver() {
                override fun onReceive(context: Context?, intent: Intent?) {
                    val status = manager?.currentThermalStatus ?: 0
                    events.success(mapOf(
                        "thermalStatus" to status,
                        "timestamp" to System.currentTimeMillis()
                    ))
                }
            }
            appContext.registerReceiver(
                receiver,
                IntentFilter(PowerManager.ACTION_THERMAL_STATUS_CHANGED)
            )
        }

        // 定时轮询（兼容旧版本）
        startThermalPolling(events)
    }

    private fun startThermalPolling(events: EventChannel.EventSink) {
        val handler = Handler(Looper.getMainLooper())
        handler.postDelayed(object : Runnable {
            override fun run() {
                val status = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
                    manager?.currentThermalStatus ?: 0
                } else {
                    estimateThermalFromCpuTemp()
                }
                events.success(mapOf("thermalStatus" to status))
                handler.postDelayed(this, 30_000)
            }
        }, 30_000)
    }

    /// 旧版本通过 CPU 温度文件估算
    private fun estimateThermalFromCpuTemp(): Int {
        return try {
            val tempFile = File("/sys/class/thermal/thermal_zone0/temp")
            if (tempFile.exists()) {
                val temp = tempFile.readText().trim().toInt() / 1000
                when {
                    temp >= 65 -> 5  // THROTTLING_EMERGENCY
                    temp >= 55 -> 3  // THROTTLING_SEVERE
                    temp >= 45 -> 2  // THROTTLING_MODERATE
                    else -> 0
                }
            } else 0
        } catch (e: Exception) { 0 }
    }
}
```

### 5.1 启动时分级行政

```dart
class DeviceProfiler {
  /// APP 首次启动时执行，结果缓存到 SharedPreferences
  Future<DeviceProfile> profile() async {
    final platformInfo = await _platformChannel.invokeMethod('getDeviceInfo');

    final totalRamMB = platformInfo['totalRamMB'] as int;
    final totalStorageGB = platformInfo['totalStorageGB'] as int;
    final cpuCoreCount = platformInfo['cpuCoreCount'] as int;
    final maxCpuFreqMHz = platformInfo['maxCpuFreqMHz'] as int;
    final refreshRate = platformInfo['screenRefreshRate'] as int;

    // 综合性能评分（加权计算）
    int score = 0;
    score += (totalRamMB * 0.3).round().clamp(0, 3000);      // RAM 权重 30%
    score += (maxCpuFreqMHz * 1.5).clamp(0, 3000);            // CPU 频率 权重 30%
    score += (cpuCoreCount * 300).clamp(0, 1800);             // 核心数 权重 15%
    score += (totalStorageGB * 10).clamp(0, 1000);            // 存储 权重 10%
    score += (refreshRate == 120 ? 1200 : refreshRate == 90 ? 600 : 300); // 屏幕 权重 15%

    final tier = _classifyTier(score);

    return DeviceProfile(
      tier: tier,
      totalRamMB: totalRamMB,
      totalStorageGB: totalStorageGB,
      cpuAbi: platformInfo['cpuAbi'],
      cpuCoreCount: cpuCoreCount,
      maxCpuFreqMHz: maxCpuFreqMHz,
      osVersion: platformInfo['osVersion'],
      deviceModel: platformInfo['deviceModel'],
      isLowPowerModeSupported: platformInfo['isLowPowerModeSupported'],
      isThermalMonitoringSupported: platformInfo['isThermalMonitoringSupported'],
      screenRefreshRate: refreshRate,
      performanceScore: score,
    );
  }

  DeviceTier _classifyTier(int score) {
    if (score >= 6500) return DeviceTier.high;
    if (score >= 4000) return DeviceTier.medium;
    return DeviceTier.low;
  }
}
```

## 6. 决策引擎设计

### 6.1 核心决策流程

```
输入：
  - GlobalPressureState（各维度当前压力）
  - DeviceProfile（设备分级）
  - UserContext（当前所在页面、正在执行的操作）
  - ActiveDegradations（已激活的降级策略列表）

输出：
  - List<DegradationAction>（需要执行的动作列表）
    = Apply(strategyId, level)
    | Recover(strategyId)
    | Escalate(strategyId, newLevel)
    | Deescalate(strategyId, newLevel)
```

### 6.2 决策算法

```dart
class DecisionEngine {
  final StrategyRegistry registry;
  final UserContextProvider contextProvider;

  /// 每次资源状态变化时调用
  List<DegradationAction> decide({
    required GlobalPressureState newState,
    required GlobalPressureState oldState,
    required DeviceProfile device,
    required List<ActiveDegradation> activeDegradations,
  }) {
    final actions = <DegradationAction>[];
    final context = contextProvider.currentContext;

    // 1. 检查每个维度的变化
    for (final dim in ResourceDimension.values) {
      final newLevel = newState.levelOf(dim);
      final oldLevel = oldState.levelOf(dim);

      if (newLevel == oldLevel) continue;

      // 等级上升 → 需要执行更多降级
      if (newLevel.index > oldLevel.index) {
        final strategies = registry.findStrategies(
          dimension: dim,
          minLevel: newLevel,
          deviceTier: device.tier,
        );
        for (final s in strategies) {
          // 排除已激活的
          if (activeDegradations.any((a) => a.strategyId == s.id)) {
            // 已激活但可能需要升级
            final active = activeDegradations.firstWhere((a) => a.strategyId == s.id);
            if (active.appliedLevel.index < newLevel.index) {
              actions.add(DegradationAction.escalate(s.id, newLevel));
            }
            continue;
          }
          // 核心功能保护：如果用户正在核心场景，跳过会中断体验的策略
          if (_isCoreContext(context) && s.disruptive) {
            continue;
          }
          actions.add(DegradationAction.apply(s.id, newLevel, dim));
        }
      }
      // 等级下降 → 恢复部分策略
      else if (newLevel.index < oldLevel.index) {
        for (final active in activeDegradations) {
          if (active.triggerDimension != dim) continue;
          if (active.appliedLevel.index <= newLevel.index) continue;

          // 判断是否还有其他维度维持高压力
          bool stillNeeded = false;
          for (final otherDim in ResourceDimension.values) {
            if (otherDim == dim) continue;
            if (newState.levelOf(otherDim).index >= active.appliedLevel.index) {
              final strategy = registry.get(active.strategyId);
              if (strategy.triggers.any((t) =>
                t.dimension == otherDim && t.minLevel.index <= newState.levelOf(otherDim).index
              )) {
                stillNeeded = true;
                break;
              }
            }
          }

          if (!stillNeeded) {
            actions.add(DegradationAction.recover(active.strategyId));
          } else {
            actions.add(DegradationAction.deescalate(active.strategyId, newLevel));
          }
        }
      }
    }

    // 按优先级排序
    actions.sort((a, b) {
      final sa = registry.get(a.strategyId);
      final sb = registry.get(b.strategyId);
      return sa.priority.compareTo(sb.priority);
    });

    return actions;
  }

  /// 判断是否为核心场景（不降级）
  bool _isCoreContext(UserContext context) {
    return switch (context.currentPage) {
      AppPage.aiConversation => true,
      AppPage.photoSearch => true,
      AppPage.examPractice => true,
      _ => false,
    };
  }
}
```

### 6.3 防抖与滞后机制

为避免在等级边界频繁切换策略，引入**滞后区间（Hysteresis）**：

```dart
class PressureHysteresis {
  /// 上升阈值和下降阈值之间的差值
  /// 例：电量 warning→critical 上升阈值 25%，critical→warning 下降阈值 30%
  /// 需要恢复到 30% 以上才退出 critical
  static const Map<ResourceDimension, Map<PressureLevel, double>> _upThresholds = {
    ResourceDimension.battery: {
      PressureLevel.warning: 50,
      PressureLevel.critical: 25,
      PressureLevel.emergency: 10,
    },
    ResourceDimension.memory: {
      PressureLevel.warning: 0.60,
      PressureLevel.critical: 0.75,
      PressureLevel.emergency: 0.90,
    },
    // ...其他维度
  };

  static const Map<ResourceDimension, Map<PressureLevel, double>> _downThresholds = {
    ResourceDimension.battery: {
      PressureLevel.warning: 55,    // 需要恢复到 55% 才降级为 nominal
      PressureLevel.critical: 30,   // 需要恢复到 30% 才降级为 warning
      PressureLevel.emergency: 15,  // 需要恢复到 15% 才降级为 critical
    },
    ResourceDimension.memory: {
      PressureLevel.warning: 0.55,
      PressureLevel.critical: 0.70,
      PressureLevel.emergency: 0.85,
    },
  };

  /// 判断是否应该升级压力等级
  static bool shouldEscalate(
    ResourceDimension dim,
    double currentValue,
    PressureLevel currentLevel,
  ) {
    final nextLevel = PressureLevel.values[currentLevel.index + 1];
    final threshold = _upThresholds[dim]?[nextLevel];
    if (threshold == null) return false;

    // 对于"越高越危险"的指标（如内存使用率）
    // 对于"越低越危险"的指标（如电量百分比）
    return dim == ResourceDimension.battery || dim == ResourceDimension.storage
      ? currentValue <= threshold
      : currentValue >= threshold;
  }

  /// 判断是否应该降级压力等级
  static bool shouldDeescalate(
    ResourceDimension dim,
    double currentValue,
    PressureLevel currentLevel,
  ) {
    final threshold = _downThresholds[dim]?[currentLevel];
    if (threshold == null) return false;

    return dim == ResourceDimension.battery || dim == ResourceDimension.storage
      ? currentValue >= threshold
      : currentValue <= threshold;
  }
}
```

### 7.1 策略注册表

```dart
class StrategyRegistry {
  final Map<DegradationStrategyId, DegradationStrategy> _strategies = {};

  void register(DegradationStrategy strategy) {
    _strategies[strategy.id] = strategy;
  }

  List<DegradationStrategy> findStrategies({
    required ResourceDimension dimension,
    required PressureLevel minLevel,
    required DeviceTier deviceTier,
  }) {
    return _strategies.values
      .where((s) => s.triggers.any((t) =>
        t.dimension == dimension &&
        t.minLevel.index <= minLevel.index &&
        (t.maxDeviceTier == null || t.maxDeviceTier!.index >= deviceTier.index)
      ))
      .toList()
      ..sort((a, b) => a.priority.compareTo(b.priority));
  }

  DegradationStrategy get(DegradationStrategyId id) => _strategies[id]!;
}
```

```dart
  final StrategyRegistry registry = StrategyRegistry();
  final DecisionEngine _decisionEngine;
  final List<ActiveDegradation> _activeDegradations = [];
  final List<DegradationLog> _logs = [];

  GlobalPressureState _currentState = GlobalPressureState(
    dimensions: {},
    overallLevel: PressureLevel.nominal,
    timestamp: DateTime.now(),
  );

  Stream<GlobalPressureState> get pressureStream => _stateController.stream;
  GlobalPressureState get currentGlobalState => _currentState;

  /// APP 启动时调用
  Future<void> initialize() async {
    // 1. 设备分级
    await DeviceProfiler.instance.profile();

    // 2. 注册降级策略
    registerDefaultStrategies(registry);

    // 3. 启动各维度监控器
    _monitors[ResourceDimension.battery] = BatteryMonitor();
    _monitors[ResourceDimension.memory] = MemoryMonitor();
    _monitors[ResourceDimension.thermal] = ThermalMonitor();
    _monitors[ResourceDimension.storage] = StorageMonitor();
    _monitors[ResourceDimension.cpu] = CPUMonitor();
    // 网络：复用已有弱网模块
    NetworkMonitor.instance.statusStream.listen((status) {
      _onDimensionUpdate(ResourceDimension.network, status);
    });

    for (final monitor in _monitors.values) {
      monitor.dataStream.listen((data) {
        _onDimensionUpdate(monitor.dimension, data);
      });
      await monitor.start();
    }

    // 4. 监听内存压力通知（即时响应）
    MemoryPressureChannel.instance.onMemoryPressure.listen((_) {
      _forceEscalate(ResourceDimension.memory, PressureLevel.emergency);
    });
  }

  /// 处理某维度数据更新
  void _onDimensionUpdate(ResourceDimension dim, MonitorData data) {
    // 计算新等级（含滞后机制）
    final oldLevel = _currentState.levelOf(dim);
    final newLevel = _applyHysteresis(dim, data, oldLevel);

    // 更新全局状态
    final newDimensions = Map.from(_currentState.dimensions);
    newDimensions[dim] = ResourceSnapshot(
      dimension: dim,
      level: newLevel,
      rawValue: data.rawValue,
      unit: data.unit,
      timestamp: DateTime.now(),
      metadata: data.metadata,
    );

    final overallLevel = newDimensions.values
      .map((s) => s.level)
      .reduce((a, b) => a.index > b.index ? a : b);

    final newState = GlobalPressureState(
      dimensions: newDimensions,
      overallLevel: overallLevel,
      timestamp: DateTime.now(),
    );

    // 决策
    final actions = _decisionEngine.decide(
      newState: newState,
      oldState: _currentState,
      device: DeviceProfiler.instance.profile,
      activeDegradations: List.from(_activeDegradations),
    );

    // 执行
    for (final action in actions) {
      _executeAction(action, dim);
    }

    _currentState = newState;
    _stateController.add(newState);
  }

  void _executeAction(DegradationAction action, ResourceDimension dim) {
    final strategy = registry.get(action.strategyId);

    switch (action.type) {
      case ActionType.apply:
        strategy.onApply(action.level);
        _activeDegradations.add(ActiveDegradation(
          strategyId: action.strategyId,
          appliedLevel: action.level,
          triggerDimension: dim,
          appliedAt: DateTime.now(),
        ));
        break;
      case ActionType.recover:
        strategy.onRecover();
        _activeDegradations.removeWhere((a) => a.strategyId == action.strategyId);
        break;
      case ActionType.escalate:
        strategy.onApply(action.level);
        final idx = _activeDegradations.indexWhere((a) => a.strategyId == action.strategyId);
        if (idx >= 0) {
          _activeDegradations[idx] = _activeDegradations[idx].copyWith(
            appliedLevel: action.level,
          );
        }
        break;
      case ActionType.deescalate:
        strategy.onApply(action.level);
        final idx = _activeDegradations.indexWhere((a) => a.strategyId == action.strategyId);
        if (idx >= 0) {
          _activeDegradations[idx] = _activeDegradations[idx].copyWith(
            appliedLevel: action.level,
          );
        }
        break;
    }

    // 记录日志
    _logs.add(DegradationLog(
      sessionId: SessionManager.instance.sessionId,
      strategyId: action.strategyId,
      action: action.type.name,
      fromLevel: action.fromLevel ?? PressureLevel.nominal,
      toLevel: action.toLevel ?? PressureLevel.nominal,
      dimension: dim,
      timestamp: DateTime.now(),
    ));

    // 上报埋点
    AnalyticsService.instance.track('resource_degradation', properties: {
      'strategy': strategy.name,
      'action': action.type.name,
      'dimension': dim.name,
      'level': action.toLevel?.name,
      'device_tier': DeviceProfiler.instance.profile.tier.name,
    });
  }

  /// 强制升级（如收到系统内存警告）
  void _forceEscalate(ResourceDimension dim, PressureLevel level) {
    _onDimensionUpdate(dim, RawMonitorData(
      rawValue: level.index.toDouble(),
      unit: 'force',
      metadata: {'forced': true},
    ));
  }

  /// APP 进入后台
  void onAppPaused() {
    // 降低监控频率
    for (final monitor in _monitors.values) {
      monitor.updateInterval(Duration(seconds: 60));
    }
  }

  /// APP 回到前台
  void onAppResumed() {
    // 恢复监控频率
    for (final monitor in _monitors.values) {
      monitor.restoreInterval();
    }
    // 立即采集一次
    for (final monitor in _monitors.values) {
      monitor.pollNow();
    }
  }

  /// 会话结束时上报日志
  void dispose() {
    if (_logs.isNotEmpty) {
      AnalyticsService.instance.batchTrack(
        'resource_degradation_logs',
        _logs.map((l) => l.toJson()).toList(),
      );
    }
    _stateController.close();
    for (final monitor in _monitors.values) {
      monitor.stop();
    }
  }
}
```

## 11. 错误处理与边界情况

### 11.1 监控器异常

| 异常场景 | 处理策略 |
| --- | --- |
| 平台 API 调用失败 | 返回上次缓存值，连续 3 次失败后上报错误日志 |
| 监控器线程崩溃 | 捕获异常，重启监控器，最长重试间隔 5min |
| iOS 某些 API 权限被拒 | 静默降级为不支持该维度监控 |
| Android 厂商定制 ROM 差异 | 读取失败时尝试备选方案（如 `/sys/class/thermal/` 读温度文件）|

```dart
abstract class ResourceMonitor {
  final _dataController = StreamController<MonitorData>.broadcast();
  final Duration _defaultInterval;
  Timer? _timer;
  MonitorData? _lastData;
  int _consecutiveErrors = 0;

  Stream<MonitorData> get dataStream => _dataController.stream;
  ResourceDimension get dimension;

  Future<void> start() async {
    _timer = Timer.periodic(_defaultInterval, (_) async {
      await _poll();
    });
    await _poll(); // 立即采集一次
  }

  Future<void> _poll() async {
    try {
      final data = await collect();
      _lastData = data;
      _consecutiveErrors = 0;
      _dataController.add(data);
    } catch (e, stack) {
      _consecutiveErrors++;
      Logger.warning('ResourceMonitor[$dimension] poll failed: $e');

      if (_consecutiveErrors >= 3) {
        // 上报错误
        Crashlytics.recordError(e, stack, reason: 'monitor_poll_failed_$dimension');
      }

      // 返回上次缓存值（如果有）
      if (_lastData != null && _consecutiveErrors < 5) {
        _dataController.add(_lastData!);
      }
      // 连续 5 次失败：暂停该维度监控
      if (_consecutiveErrors >= 5) {
        Logger.error('ResourceMonitor[$dimension] disabled after 5 consecutive errors');
        _timer?.cancel();
      }
    }
  }

  void updateInterval(Duration interval) {
    _timer?.cancel();
    _timer = Timer.periodic(interval, (_) async => await _poll());
  }

  void restoreInterval() {
    updateInterval(_defaultInterval);
  }

  Future<void> pollNow() async => await _poll();

  void stop() {
    _timer?.cancel();
    _dataController.close();
  }

  /// 子类实现具体采集逻辑
  Future<MonitorData> collect();
}
```

### 11.3 边界情况处理

| 场景 | 处理 |
| --- | --- |
| 设备刚启动，系统资源采集 API 未就绪 | 延迟 5s 后启动监控，期间使用设备分级默认配置 |
| 用户在 AI 对话进行中触发 emergency | 不中断当前请求，仅阻止新请求发起，显示"资源紧张"提示 |
| 短时间内压力等级频繁波动 | 滞后机制 + 最低保持时间（每个等级至少保持 30s）|
| 降级导致功能不可用 | 显示友好提示："当前设备资源紧张，部分功能暂时受限，[了解详情]" |
| APP 从后台恢复 | 立即重新采集所有维度，根据最新状态决定是否恢复/降级 |
| 用户手动覆盖省电策略 | 尊重用户选择，不覆盖手动配置 |

## 17. 安全与合规

### 17.1 数据安全

| 风险 | 措施 |
| --- | --- |
| 设备信息泄露 | 上报数据脱敏：deviceModel 只上报型号大类，不上报完整序列号 |
| 用户行为推断 | 资源压力日志不含用户内容信息，仅含策略 ID 和等级 |
| 本地缓存被篡改 | DeviceProfile 校验签名，防止伪造高端设备绕过降级 |

### 17.2 性能安全

| 风险 | 措施 |
| --- | --- |
| 降级导致功能完全不可用 | 所有策略必须保留核心功能可用，降级只影响体验质量 |
| 策略死循环 | 最少保持时间 + 降级操作幂等性保证 |
| 监控器占用过多资源 | 监控器自身 CPU < 1%，内存 < 2MB |

### 18.2 紧急关闭开关

通过配置中心下发 `resource_pressure.enabled = false` 可立即关闭整个引擎，恢复所有降级策略到默认状态。

```dart
void checkKillSwitch() {
  ConfigCenter.instance.listen('resource_pressure.enabled', (enabled) {
    if (enabled == false) {
      // 立即恢复所有降级
      for (final active in _activeDegradations.toList()) {
        final strategy = registry.get(active.strategyId);
        strategy.onRecover();
      }
      _activeDegradations.clear();
      // 停止所有监控
      for (final monitor in _monitors.values) {
        monitor.stop();
      }
    } else {
      // 重新启动
      initialize();
    }
  });
}
```
