# 服务端-学科核心素养评估与新高考选科推荐引擎 - 详细设计

> **文档版本**：v1.0  
> **创建日期**：2026-06-14  
> **所属模块**：学情分析 / 学习规划  
> **优先级**：P2（V1.5 阶段）  
> **依赖模块**：学情分析服务、学习记录服务、知识点体系服务、题目服务、用户画像服务

---

## 1. 模块概述

### 1.1 功能目标

基于中国《普通高中课程方案和语文等学科课程标准（2017年版2020年修订）》定义的学科核心素养体系，为高中生提供：

1. **学科核心素养量化评估**——从知识掌握、能力表现、思维品质、实践应用四个维度，对学生在各学科中的核心素养发展水平进行量化评分。
2. **新高考选科智能推荐**——根据学生的核心素养画像、学业成绩趋势、兴趣倾向和职业规划意向，为新高考"3+1+2"或"3+3"模式提供最优选科组合推荐。
3. **职业兴趣关联分析**——将学科核心素养与霍兰德职业兴趣理论（RIASEC模型）相结合，为学生提供专业方向和职业领域的参考建议。
4. **素养发展追踪**——持续追踪核心素养的变化趋势，生成阶段性发展报告。

### 1.2 业务背景

新高考改革后，选科组合直接影响学生的高考志愿填报范围和未来发展路径。目前主流选科方案包括：

| 模式 | 适用地区 | 组合规则 | 选科组合数 |
|------|----------|----------|------------|
| 3+1+2 | 河北、辽宁、江苏、福建、湖北、湖南、广东、重庆等 | 语文/数学/外语必考 + 物理/历史二选一 + 化学/生物/政治/地理四选二 | 12种 |
| 3+3 | 北京、天津、上海、浙江、山东、海南等 | 语文/数学/外语必考 + 物理/化学/生物/历史/地理/政治六选三 | 20种 |

不同组合对应不同的大学专业报考范围，例如：
- 物理+化学+生物：理工科覆盖率最高（约96%）
- 历史+政治+地理：文科类专业覆盖率高
- 物理+化学+政治：兼顾理工与军校/公安类专业

### 1.3 设计原则

1. **数据驱动**：所有评估基于学生的真实学习行为数据，避免主观偏见。
2. **可解释性**：推荐结果必须附带详细的决策依据和置信度，帮助学生和家长理解。
3. **渐进式精准**：随着数据积累，评估精度逐步提升；早期阶段给出区间而非精确值。
4. **人工兜底**：推荐结果仅供参学，最终决策由学生和家长共同做出。
5. **隐私保护**：职业兴趣测试结果属个人敏感信息，仅学生本人及绑定家长可见。

## 2. 核心概念定义

### 2.1 学科核心素养框架

依据国家课程标准，各学科核心素养定义如下：

| 学科 | 核心素养1 | 核心素养2 | 核心素养3 | 核心素养4 |
|------|-----------|-----------|-----------|-----------|
| 语文 | 语言建构与运用 | 思维发展与提升 | 审美鉴赏与创造 | 文化传承与理解 |
| 数学 | 数学抽象 | 逻辑推理 | 数学建模 | 直观想象 |
| 英语 | 语言能力 | 文化意识 | 思维品质 | 学习能力 |
| 物理 | 物理观念 | 科学思维 | 实验探究 | 科学态度与责任 |
| 化学 | 宏观辨识与微观探析 | 变化观念与平衡思想 | 证据推理与模型认知 | 科学探究与创新意识 |
| 生物 | 生命观念 | 科学思维 | 科学探究 | 社会责任 |
| 历史 | 唯物史观 | 时空观念 | 史料实证 | 历史解释 |
| 地理 | 人地协调观 | 综合思维 | 区域认知 | 地理实践力 |
| 政治 | 政治认同 | 科学精神 | 法治意识 | 公共参与 |

### 2.2 能力等级

每个核心素养分为 5 个发展水平：

| 等级 | 标签 | 描述 | 分值范围 |
|------|------|------|----------|
| L1 | 萌芽期 | 具备基础感知，尚不能独立运用 | 0-20 |
| L2 | 发展期 | 在简单情境中能识别和运用 | 21-40 |
| L3 | 合格期 | 在熟悉情境中能独立分析和解决问题 | 41-60 |
| L4 | 良好期 | 在复杂情境中能综合运用，具有一定创新性 | 61-80 |
| L5 | 优秀期 | 能在新情境中灵活迁移，具有创造性思维 | 81-100 |

### 2.3 霍兰德职业兴趣类型（RIASEC）

| 类型 | 代码 | 特征 | 关联学科 |
|------|------|------|----------|
| 现实型 | R | 喜欢动手操作、使用工具 | 物理、化学、地理 |
| 研究型 | I | 喜欢探索、分析、解决复杂问题 | 物理、化学、生物、数学 |
| 艺术型 | A | 喜欢创造、表达、审美 | 语文、英语、历史 |
| 社会型 | S | 喜欢帮助他人、教育、服务 | 政治、语文、英语 |
| 企业型 | E | 喜欢领导、说服、管理 | 政治、历史、地理 |
| 常规型 | C | 喜欢组织、规划、处理数据 | 地理、数学 |

## 3. 数据结构设计

### 3.1 PostgreSQL 数据库表定义

#### 3.1.1 核心素养维度定义表 `core_competency_dim`

```sql
CREATE TABLE core_competency_dim (
    id              BIGSERIAL PRIMARY KEY,
    subject_code    VARCHAR(10)  NOT NULL,         -- 学科代码: CHN/MATH/ENG/PHY/...
    competency_code VARCHAR(30)  NOT NULL,         -- 素养代码: e.g. MATH_ABSTRACT
    competency_name VARCHAR(50)  NOT NULL,         -- 素养名称: e.g. 数学抽象
    competency_desc TEXT         NOT NULL,         -- 素养描述
    display_order   INT          NOT NULL DEFAULT 0,
    is_active       BOOLEAN      NOT NULL DEFAULT TRUE,
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    UNIQUE (subject_code, competency_code)
);

-- 索引
CREATE INDEX idx_competency_dim_subject ON core_competency_dim (subject_code) WHERE is_active = TRUE;
```

#### 3.1.2 知识点-核心素养映射表 `knowledge_point_competency_map`

```sql
CREATE TABLE knowledge_point_competency_map (
    id               BIGSERIAL PRIMARY KEY,
    knowledge_point_id BIGINT NOT NULL,            -- 关联 knowledge_point 表
    competency_code  VARCHAR(30) NOT NULL,
    weight           DECIMAL(4,3) NOT NULL DEFAULT 0.5,  -- 该知识点对素养的贡献权重 0.000-1.000
    assessment_level VARCHAR(10) NOT NULL DEFAULT 'L3', -- 该知识点主要考察的素养等级
    created_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (knowledge_point_id, competency_code),
    FOREIGN KEY (knowledge_point_id) REFERENCES knowledge_point (id)
);

CREATE INDEX idx_kp_competency_code ON knowledge_point_competency_map (competency_code);
```

#### 3.1.3 学生核心素养评分表 `student_competency_score`

```sql
CREATE TABLE student_competency_score (
    id               BIGSERIAL PRIMARY KEY,
    user_id          BIGINT NOT NULL,
    subject_code     VARCHAR(10) NOT NULL,
    competency_code  VARCHAR(30) NOT NULL,
    score            DECIMAL(5,2) NOT NULL,        -- 0.00-100.00
    level_code       VARCHAR(5)  NOT NULL,         -- L1-L5
    confidence       DECIMAL(3,2) NOT NULL DEFAULT 0.0, -- 置信度 0.00-1.00
    sample_count     INT NOT NULL DEFAULT 0,       -- 评估样本量(答题数等)
    assessment_cycle VARCHAR(20) NOT NULL,         -- 评估周期: 2026-W24 / 2026-06 / 2026-S2
    snapshot_data    JSONB,                        -- 快照数据(详细子维度分)
    assessed_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_at       TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (user_id, subject_code, competency_code, assessment_cycle)
);

CREATE INDEX idx_competency_score_user ON student_competency_score (user_id, assessment_cycle);
CREATE INDEX idx_competency_score_subject ON student_competency_score (subject_code, competency_code);
```

#### 3.1.4 职业兴趣测试记录表 `career_interest_survey`

```sql
CREATE TABLE career_interest_survey (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT NOT NULL,
    survey_version  VARCHAR(10) NOT NULL DEFAULT '1.0',
    answers         JSONB NOT NULL,                -- [{"qId":1,"answer":"R"},...] 
    riasec_scores   JSONB NOT NULL,                -- {"R":28,"I":35,"A":20,"S":15,"E":12,"C":10}
    top_types       JSONB NOT NULL,                -- ["I","R"] (前2-3个类型)
    recommended_majors JSONB,                      -- 推荐专业方向列表
    taken_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_career_survey_user ON career_interest_survey (user_id, taken_at DESC);
```

#### 3.1.5 选科推荐记录表 `subject_selection_recommendation`

```sql
CREATE TABLE subject_selection_recommendation (
    id                  BIGSERIAL PRIMARY KEY,
    user_id             BIGINT NOT NULL,
    gaokao_mode         VARCHAR(10) NOT NULL,       -- '3+1+2' or '3+3'
    region              VARCHAR(20),                 -- 省份代码, 用于确定模式
    recommended_combo   VARCHAR(50) NOT NULL,        -- '物理+化学+生物'
    rank                INT NOT NULL,                -- 推荐排名 1-12/1-20
    match_score         DECIMAL(5,2) NOT NULL,       -- 匹配度 0-100
    competency_alignment JSONB NOT NULL,             -- 素养匹配分析
    career_alignment    JSONB NOT NULL,              -- 职业方向匹配
    major_coverage_rate DECIMAL(5,2),                -- 专业覆盖率%
    difficulty_estimate VARCHAR(10),                 -- 预估学习难度: EASY/MEDIUM/HARD
    rationale           TEXT NOT NULL,               -- 推荐理由文本
    pros                JSONB,                       -- 优势列表
    cons                JSONB,                       -- 劣势/风险列表
    generated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    is_current          BOOLEAN NOT NULL DEFAULT TRUE,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_selection_rec_user ON subject_selection_recommendation (user_id, is_current, rank);
```

#### 3.1.6 大学专业选科要求表 `major_subject_requirement`

```sql
CREATE TABLE major_subject_requirement (
    id                BIGSERIAL PRIMARY KEY,
    major_code        VARCHAR(20) NOT NULL,          -- 专业代码
    major_name        VARCHAR(100) NOT NULL,
    major_category    VARCHAR(50) NOT NULL,          -- 08工学/07理学/12管理学...
    university_tier   VARCHAR(20),                   -- 985/211/双一流/普通
    required_subjects VARCHAR(100) NOT NULL,         -- '物理' / '物理+化学' / '' (不限)
    preferred_subjects VARCHAR(100),                 -- 优先选择的科目
    gaokao_mode       VARCHAR(10) NOT NULL,          -- '3+1+2' or '3+3'
    is_active         BOOLEAN NOT NULL DEFAULT TRUE,
    data_source       VARCHAR(100),                  -- 数据来源
    academic_year     VARCHAR(10) NOT NULL,          -- '2026'
    created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_major_subject_req ON major_subject_requirement (required_subjects, major_category, gaokao_mode);
CREATE INDEX idx_major_category ON major_subject_requirement (major_category, is_active);
```

#### 3.1.7 选科组合统计表 `subject_combo_stats`

```sql
CREATE TABLE subject_combo_stats (
    id                BIGSERIAL PRIMARY KEY,
    combo_code        VARCHAR(50) NOT NULL,         -- '物理+化学+生物'
    gaokao_mode       VARCHAR(10) NOT NULL,
    major_coverage_count INT NOT NULL DEFAULT 0,    -- 可报考专业数
    major_coverage_rate  DECIMAL(5,2) NOT NULL,     -- 覆盖率%
    difficulty_score  DECIMAL(3,1) NOT NULL,        -- 综合学习难度评分 1-10
    popularity_rate   DECIMAL(5,2) DEFAULT 0,       -- 全省选考占比%
    is_active         BOOLEAN NOT NULL DEFAULT TRUE,
    academic_year     VARCHAR(10) NOT NULL,
    created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (combo_code, gaokao_mode, academic_year)
);
```

### 3.2 Redis 缓存结构

```
# 学生素养评分缓存 (TTL: 6小时)
competency:score:{user_id}:{subject_code} -> Hash {
    competency_code -> "score:level:confidence"
}

# 职业兴趣测试结果缓存 (TTL: 24小时)
career:survey:{user_id}:latest -> JSON string

# 选科推荐结果缓存 (TTL: 12小时)
selection:recommendation:{user_id}:latest -> JSON string

# 全局专业覆盖率统计缓存 (TTL: 7天)
major:coverage:{combo_code}:{gaokao_mode} -> "count:rate"

# 素养维度定义缓存 (TTL: 永久，通过版本号刷新)
competency:dimensions -> JSON string (全量维度定义)
```

## 5. 核心算法设计

### 5.1 核心素养评分计算引擎

#### 5.1.1 算法概述

核心素养评分采用**加权证据融合模型**，从多个数据源收集证据，通过贝叶斯加权更新计算最终分数。

数据源包括：
- 答题记录（题目难度 × 正确率 × 知识点-素养映射）
- AI 对话中的知识运用表现
- 学习行为数据（学习深度、探究时长等）
- 教师评价（如有，如班级排名、课堂表现等，为可选输入）

#### 5.1.2 答题证据计算

每条答题记录作为一条证据，其贡献值计算方式：

```python
# 伪代码：单条答题记录对特定素养的证据贡献
def compute_answer_evidence(answer_record, competency_code):
    """
    计算一条答题记录对某核心素养的证据值
    """
    # 获取知识点-素养映射权重
    kp_competency = get_kp_competency_map(
        answer_record.knowledge_point_id, 
        competency_code
    )
    if not kp_competency:
        return None
    
    # 题目难度因子 (难度越高，答对的证据越强；答错的证据也越强)
    difficulty_factor = answer_record.difficulty / 5.0  # 0.2-1.0
    
    # 答题结果因子
    if answer_record.is_correct:
        # 答对：难度越高，素养证据越强
        result_factor = 0.5 + 0.5 * difficulty_factor
    else:
        # 答错：难度越低（简单题都错），素养不足证据越强
        result_factor = -(0.5 + 0.5 * (1.0 - difficulty_factor))
    
    # 时间因子：超时答题降低证据权重
    if answer_record.time_spent > answer_record.avg_time * 2:
        time_penalty = 0.7  # 超时降权
    else:
        time_penalty = 1.0
    
    # 最终证据值: -1.0 到 +1.0
    evidence = result_factor * kp_competency.weight * time_penalty
    return {
        'evidence': evidence,
        'weight': kp_competency.weight * difficulty_factor * time_penalty,
        'source': 'answer',
        'timestamp': answer_record.answered_at
    }
```

#### 5.1.3 贝叶斯加权融合

将所有证据融合为最终素养分数：

```python
# 伪代码：贝叶斯加权融合计算
def compute_competency_score(user_id, subject_code, competency_code, cycle):
    """
    计算学生在特定周期内某学科某核心素养的综合评分
    """
    # 1. 收集所有证据
    evidences = []
    
    # 答题证据
    answers = get_answer_records(user_id, subject_code, cycle)
    for ans in answers:
        ev = compute_answer_evidence(ans, competency_code)
        if ev:
            evidences.append(ev)
    
    # AI对话证据 (学习深度分析)
    dialogue_evs = get_dialogue_evidences(user_id, subject_code, competency_code, cycle)
    evidences.extend(dialogue_evs)
    
    # 学习行为证据
    behavior_evs = get_behavior_evidences(user_id, subject_code, competency_code, cycle)
    evidences.extend(behavior_evs)
    
    # 2. 样本量检查
    if len(evidences) < MIN_SAMPLE_SIZE:  # MIN_SAMPLE_SIZE = 30
        return {
            'score': None,
            'level': None,
            'confidence': 0.0,
            'reason': 'INSUFFICIENT_DATA',
            'sample_count': len(evidences)
        }
    
    # 3. 时间衰减加权
    now = datetime.utcnow()
    weighted_sum = 0.0
    weight_sum = 0.0
    for ev in evidences:
        days_ago = (now - ev['timestamp']).days
        decay = math.exp(-days_ago / 90.0)  # 90天半衰期
        w = ev['weight'] * decay
        weighted_sum += ev['evidence'] * w
        weight_sum += w
    
    # 4. 先验融合 (以50分作为先验)
    PRIOR_SCORE = 50.0
    PRIOR_WEIGHT = 5.0  # 先验等价于5条证据
    
    # 将证据均值映射到0-100分
    avg_evidence = weighted_sum / weight_sum if weight_sum > 0 else 0
    raw_score = 50.0 + avg_evidence * 50.0  # 中心映射
    raw_score = max(0, min(100, raw_score))
    
    # 贝叶斯后验
    posterior_weight = weight_sum + PRIOR_WEIGHT
    posterior_score = (raw_score * weight_sum + PRIOR_SCORE * PRIOR_WEIGHT) / posterior_weight
    
    # 5. 置信度计算
    confidence = min(1.0, len(evidences) / 100.0) * (weight_sum / posterior_weight)
    
    # 6. 确定等级
    level = score_to_level(posterior_score)
    
    return {
        'score': round(posterior_score, 2),
        'level': level,
        'confidence': round(confidence, 2),
        'sample_count': len(evidences)
    }


def score_to_level(score):
    """分数转等级"""
    if score <= 20: return 'L1'
    elif score <= 40: return 'L2'
    elif score <= 60: return 'L3'
    elif score <= 80: return 'L4'
    else: return 'L5'
```

### 5.2 选科推荐算法

#### 5.2.1 多维度匹配评分模型

选科推荐综合考虑五个维度：

| 维度 | 权重 | 说明 |
|------|------|------|
| 学科核心素养匹配 | 35% | 学生在各科素养得分与组合要求的匹配度 |
| 职业兴趣匹配 | 20% | RIASEC类型与组合关联学科匹配 |
| 学业成绩趋势 | 20% | 近3个月各科成绩趋势与组合学习要求 |
| 专业覆盖率 | 15% | 组合可报考专业的广度 |
| 学习可行性 | 10% | 学生精力分配可行性、难度平衡 |

```python
# 伪代码：选科组合推荐计算
def recommend_subject_combos(user_id, region, target_majors=None):
    """
    为学生推荐选科组合
    """
    # 1. 确定高考模式
    gaokao_mode = get_gaokao_mode(region)  # '3+1+2' or '3+3'
    
    # 2. 获取全部可选组合
    all_combos = get_all_combos(gaokao_mode)  # 12种 or 20种
    
    # 3. 获取学生画像
    profile = build_student_profile(user_id)
    # profile = {
    #     'competency_scores': {subject: {competency: score}},
    #     'career_type': 'IR',
    #     'grade_trends': {subject: trend_data},
    #     'current_grade': '高一'
    # }
    
    # 4. 对每个组合计算匹配度
    scored_combos = []
    for combo in all_combos:
        score, detail = score_combo(combo, profile, target_majors, region)
        scored_combos.append({
            'combo': combo,
            'match_score': score,
            'detail': detail
        })
    
    # 5. 排序并取Top 5
    scored_combos.sort(key=lambda x: x['match_score'], reverse=True)
    top_5 = scored_combos[:5]
    
    # 6. 生成推荐理由文本
    for rec in top_5:
        rec['rationale'] = generate_rationale(rec, profile)
        rec['pros'] = generate_pros(rec, profile)
        rec['cons'] = generate_cons(rec, profile)
    
    return top_5


def score_combo(combo_code, profile, target_majors, region):
    """计算单个组合的多维度匹配分"""
    subjects = combo_code.split('+')  # ['物理', '化学', '生物']
    
    # 维度1: 学科核心素养匹配 (35%)
    competency_score = 0
    competency_detail = []
    for subject in subjects:
        subject_code = subject_name_to_code(subject)
        subject_scores = profile['competency_scores'].get(subject_code, {})
        if subject_scores:
            avg = sum(s for s in subject_scores.values()) / len(subject_scores)
            # L3(60分)以上为合格
            competency_score += min(100, avg * 1.2)  # 略微放大，鼓励选择有基础的科目
            competency_detail.append({
                'subject': subject,
                'avgScore': round(avg, 1),
                'strength': 'STRONG' if avg >= 60 else 'MODERATE' if avg >= 40 else 'WEAK'
            })
        else:
            competency_score += 40  # 无数据时给中等偏下分
            competency_detail.append({
                'subject': subject,
                'avgScore': None,
                'strength': 'UNKNOWN'
            })
    competency_score /= len(subjects)
    
    # 维度2: 职业兴趣匹配 (20%)
    riasec_subjects_map = {
        'R': ['物理', '化学', '地理'],
        'I': ['物理', '化学', '生物', '数学'],
        'A': ['语文', '英语', '历史'],
        'S': ['政治', '语文', '英语'],
        'E': ['政治', '历史', '地理'],
        'C': ['地理', '数学']
    }
    career_score = 0
    career_types = profile.get('career_type', 'IC')  # 默认IC型
    for t in career_types:
        matched = sum(1 for s in subjects if s in riasec_subjects_map.get(t, []))
        career_score += (matched / len(subjects)) * 100
    career_score /= len(career_types)
    
    # 维度3: 学业成绩趋势 (20%)
    trend_score = 0
    for subject in subjects:
        subject_code = subject_name_to_code(subject)
        trend = profile['grade_trends'].get(subject_code)
        if trend:
            if trend['direction'] == 'UP' and trend['avg_score'] > 60:
                trend_score += 85
            elif trend['direction'] == 'UP':
                trend_score += 70
            elif trend['direction'] == 'FLAT' and trend['avg_score'] > 65:
                trend_score += 65
            elif trend['direction'] == 'DOWN':
                trend_score += 40
            else:
                trend_score += 55
        else:
            trend_score += 50
    trend_score /= len(subjects)
    
    # 维度4: 专业覆盖率 (15%)
    combo_stats = get_combo_stats(combo_code, region)
    coverage_score = combo_stats.major_coverage_rate  # 直接使用覆盖率
    
    # 目标专业额外加成
    target_match = 100.0
    if target_majors:
        target_match = calculate_target_major_match(combo_code, target_majors)
    coverage_score = coverage_score * 0.7 + target_match * 0.3
    
    # 维度5: 学习可行性 (10%)
    difficulty = combo_stats.difficulty_score  # 1-10
    # 根据学生整体水平调整可行性
    overall_level = profile.get('overall_academic_level', 'AVERAGE')
    if overall_level == 'EXCELLENT':
        feasibility = 100 - difficulty * 3  # 优等生对难度不敏感
    elif overall_level == 'ABOVE_AVERAGE':
        feasibility = 100 - difficulty * 5
    elif overall_level == 'AVERAGE':
        feasibility = 100 - difficulty * 7
    else:
        feasibility = 100 - difficulty * 10
    feasibility = max(20, min(100, feasibility))
    
    # 综合加权
    total = (
        competency_score * 0.35 +
        career_score * 0.20 +
        trend_score * 0.20 +
        coverage_score * 0.15 +
        feasibility * 0.10
    )
    
    return total, {
        'competency_score': round(competency_score, 1),
        'career_score': round(career_score, 1),
        'trend_score': round(trend_score, 1),
        'coverage_score': round(coverage_score, 1),
        'feasibility_score': round(feasibility, 1),
        'difficulty': difficulty,
        'competency_detail': competency_detail
    }
```

def generate_rationale(rec, profile):
    """基于评估详情生成自然语言推荐理由"""
    combo = rec['combo']

@Service
public class CompetencyAssessmentService {
    
    @Autowired

     * 获取学生素养画像（缓存优先）

    public CompetencyProfile getProfile(Long userId, String subjectCode, String cycle) {
        String cacheKey = String.format("competency:score:%d:%s", userId, subjectCode);
        
        // 1. 尝试缓存

                .findLatestScore(userId, subjectCode, cycle);

            return latest.get();

                .countByUserAndSubject(userId, subjectCode, cycle);

        eventPublisher.publishEvent(
                new CompetencyRecalculateEvent(userId, subjectCode, cycle));
        
        throw new BusinessException("COMPETENCY_009",

### 8.3 计分规则

```python
def calculate_riasec(answers):
    """
    计算RIASEC得分
    每个类型满分约10-12分，总共60题
    """
    scores = {'R': 0, 'I': 0, 'A': 0, 'S': 0, 'E': 0, 'C': 0}
    
    for ans in answers:
        chosen_type = ans['answer']
        scores[chosen_type] += 1
    
    # 排序取前3个（霍兰德编码：如IAS）
    sorted_types = sorted(scores.items(), key=lambda x: x[1], reverse=True)
    top_3 = [t[0] for t in sorted_types[:3]]
    top_2 = [t[0] for t in sorted_types[:2]]
    
    # 转换为百分制
    total = sum(scores.values())
    normalized = {k: round(v / total * 100) for k, v in scores.items()}
    
    return {
        'scores': normalized,
        'top_2_code': ''.join(top_2),  # e.g. 'IR'
        'top_3_code': ''.join(top_3),  # e.g. 'IRA'
        'label': get_type_label(top_2)
    }


def get_type_label(top_2_code):
    labels = {
        'RI': '现实研究型', 'IR': '研究现实型',
        'IA': '艺术研究型', 'AI': '艺术研究型',
        'IS': '社会研究型', 'SI': '社会研究型',
        'IE': '企业研究型', 'EI': '企业研究型',
        'AS': '社会艺术型', 'SA': '社会艺术型',
        'SE': '企业社会型', 'ES': '企业社会型',
        # ... 完整映射
    }
    return labels.get(top_2_code, '综合型')
```

## 9. 错误处理与降级策略

### 9.1 错误处理矩阵

| 场景 | 错误 | 处理策略 |
|------|------|----------|
| 答题数据不足30条 | COMPETENCY_010 | 返回提示，引导用户多练习后再看评估 |
| 答题数据30-100条 | 正常计算 | 正常计算但标记置信度为 LOW (0.3-0.6) |
| 知识点-素养映射缺失 | 降级处理 | 跳过该条证据，记录日志通知内容团队补充映射 |
| 职业兴趣测试未做 | 降级处理 | 选科推荐时跳过职业匹配维度，权重重分配到其他4个维度 |
| 专业选科要求数据过期 | 降级处理 | 使用上一学年数据，标注数据年份 |
| 某学科无素养数据 | 使用先验 | 以50分(合格线)作为先验，置信度标记0.0 |
| 计算超时(>10s) | 超时降级 | 返回上次计算结果(如有)或返回"评估进行中" |
| Redis缓存不可用 | 直接查库 | 绕过缓存直接查询数据库，不影响功能 |

### 9.2 服务降级标记

```java
public class CompetencyServiceDegradator {
    
    /**
     * 根据数据完整度返回降级标记
     */
    public AssessmentQuality assessQuality(CompetencyProfile profile) {
        int totalCompetencies = profile.getTotalCompetencies();
        int assessedCompetencies = profile.getAssessedCompetencies();
        double avgConfidence = profile.getAvgConfidence();
        
        double coverage = (double) assessedCompetencies / totalCompetencies;
        
        if (coverage >= 0.8 && avgConfidence >= 0.7) {
            return AssessmentQuality.FULL;      // 完整评估
        } else if (coverage >= 0.5 && avgConfidence >= 0.4) {
            return AssessmentQuality.PARTIAL;    // 部分评估
        } else {
            return AssessmentQuality.PRELIMINARY; // 初步评估
        }
    }
}
```

- 测试数据仅用于学习规划，不用于商业广告推送

### 15.2 选科推荐核心服务

```java
@Service
@Slf4j
@RequiredArgsConstructor
public class SubjectSelectionService {

    private final CompetencyRepository competencyRepository;
    private final CareerSurveyRepository surveyRepository;
    private final ComboStatsRepository comboStatsRepository;
    private final MajorRequirementRepository majorRequirementRepository;
    private final AnswerRecordClient answerRecordClient;
    private final RationaleGenerator rationaleGenerator;
    
    private static final int TOP_N = 5;
    private static final int MIN_SAMPLE_SIZE = 30;
    
    /**
     * 生成选科推荐
     */
    public List<SubjectSelectionVO> recommend(
            Long userId, String region, 
            List<String> targetMajors, boolean forceRefresh) {
        
        // 1. 校验
        validateRegion(region);
        validateGrade(userId);  // 仅高一/高二可生成
        
        // 2. 确定模式
        String gaokaoMode = RegionConfig.getGaokaoMode(region);
        
        // 3. 构建学生画像
        StudentProfile profile = buildStudentProfile(userId, gaokaoMode);
        
        // 4. 遍历组合评分
        List<SubjectComboStats> allCombos = 
                comboStatsRepository.findByModeAndYear(gaokaoMode, currentAcademicYear());
        
        List<ScoredCombo> scoredCombos = allCombos.stream()
                .map(combo -> scoreCombo(combo, profile, targetMajors, region))
                .sorted(Comparator.comparing(ScoredCombo::getMatchScore).reversed())
                .limit(TOP_N)
                .collect(Collectors.toList());
        
        // 5. 生成推荐详情
        List<SubjectSelectionVO> recommendations = scoredCombos.stream()
                .map(sc -> buildVO(sc, profile))
                .collect(Collectors.toList());
        
        // 6. 持久化
        saveRecommendations(userId, recommendations, gaokaoMode, region);
        
        log.info("[Selection] userId={} region={} mode={} topCombo={} matchScore={}",
                userId, region, gaokaoMode, 
                recommendations.get(0).getComboCode(),
                recommendations.get(0).getMatchScore());
        
        return recommendations;
    }
    
    private StudentProfile buildStudentProfile(Long userId, String gaokaoMode) {
        // 获取素养评分
        Map<String, Map<String, CompetencyScoreVO>> competencyScores = 
                competencyRepository.findLatestScoresByUser(userId);
        
        // 获取职业兴趣
        Optional<CareerInterestSurvey> survey = 
                surveyRepository.findLatestByUser(userId);
        
        // 获取成绩趋势
        Map<String, GradeTrend> trends = 
                answerRecordClient.getGradeTrends(userId);
        
        return StudentProfile.builder()
                .userId(userId)
                .competencyScores(competencyScores)
                .careerType(survey.map(CareerInterestSurvey::getTop2Code).orElse(null))
                .careerFields(survey.map(CareerInterestSurvey::getRecommendedFields).orElse(List.of()))
                .gradeTrends(trends)
                .overallLevel(assessOverallLevel(competencyScores))
                .build();
    }
}
```
