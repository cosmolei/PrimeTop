> **文档版本**: v1.0

## 1. 概述

### 1.1 功能定位

本引擎负责对学生在**日常练习场景**中的逐题答题时间进行采集、建模、分析，输出多维度的答题节奏诊断结论，帮助学生建立科学的答题习惯，为考试时间管理奠定基础。

与现有模块的边界区分：

| 模块 | 关注点 | 场景 |
|------|--------|------|
| **考试答题策略分析与时间分配优化建议引擎** | 考试中各板块时间分配策略 | 模拟考试 / 正式考试 |
| **学习会话内容编排与学习节奏智能控制引擎** | 学习会话层面的内容编排与休息节奏 | 整体学习会话 |
| **学生答题犹豫度分析与知识点掌握信心度评估引擎** | 答题犹豫行为 → 信心度推断 | 单题微观行为 |
| **本引擎** | **逐题答题时间分布模式 → 节奏习惯诊断与优化** | **日常练习全过程** |

### 1.2 核心目标

1. **时间模式建模**：为每位学生构建各学科、各题型、各难度下的答题时间分布模型。
2. **节奏异常诊断**：识别"抢答型"（过快）、"拖沓型"（过慢）、"波动型"（不稳定）等不良答题节奏。
3. **效率量化评估**：计算学习效率指标（正确率/时间比），判断时间投入产出比。
4. **个性化优化建议**：基于学生个人特征输出节奏调整建议，并与备考策略模块联动。
5. **长期习惯追踪**：跟踪学生答题节奏习惯的长期变化趋势。

### 1.3 适用范围

- **学段**：小学三年级及以上（低年级交互方式不同，不纳入分析范围）
- **场景**：同步练习、错题重做、专项训练、模拟测试（日常练习态，非正式考试）
- **题型**：选择题、填空题、判断题、解答题、作文题

## 3. 核心算法设计

### 3.1 答题节奏类型分类算法

根据学生的时间分布特征，将其节奏归入四种类型之一。

```
输入：学生的 (subject_code, question_type) 维度下的所有答题时间记录
输出：pacing_type ∈ {balanced, rushed, sluggish, volatile} + pacing_score

算法：
1. 计算学生个人中位数时间 T_median 和基准中位数 B_median
2. 计算变异系数 CV = std_duration / mean_duration
3. 计算相对时间比 RT = T_median / B_median

决策树：
├── RT < 0.6 且 fast_accuracy < avg_accuracy - 0.15
│   └── → "rushed" (抢答型)
├── RT > 1.8
│   └── → "sluggish" (拖沓型)
├── CV > 0.7
│   └── → "volatile" (波动型)
└── otherwise
    └── → "balanced" (均衡型)

Pacing Score 计算（0-100）：
  base_score = 60
  + (正确率增益: avg_accuracy * 20)
  + (稳定性增益: max(0, (0.5 - CV)) * 20)
  - (偏离惩罚: |RT - 1.0| * 15)
  - (快答错误惩罚: max(0, fast_accuracy_gap) * 25)
  clamp(0, 100)
```

### 3.2 异常节奏检测算法（实时）

在学生答题过程中，**实时**检测当前题目的答题时间是否异常。

```python
class PacingAnomalyDetector:
    """答题节奏异常检测器"""
    
    # 异常类型常量
    RUSHING = "RUSHING"
    STALLING = "STALLING"
    VOLATILE = "VOLATILE"
    SCREEN_OFF = "SCREEN_OFF"
    
    def detect_realtime(
        self,
        user_id: int,
        question_meta: dict,
        current_duration: float,
        personal_profile: dict,
        baseline: dict
    ) -> Optional[PacingAnomaly]:
        """
        实时异常检测（答题过程中调用）
        
        Args:
            user_id: 学生ID
            question_meta: {subject_code, question_type, difficulty_level}
            current_duration: 当前已用时间（秒）
            personal_profile: 学生节奏画像
            baseline: 该年级/学科/题型/难度的基准数据
        """
        # 优先使用个人画像阈值，样本不足时降级为基准阈值
        if personal_profile and personal_profile['sample_count'] >= 20:
            fast_threshold = personal_profile['p25_duration'] * 0.5
            slow_threshold = personal_profile['p95_duration']
        else:
            fast_threshold = baseline['fast_threshold']
            slow_threshold = baseline['slow_threshold']
        
        # 抢答检测：时间远低于正常范围
        if current_duration < fast_threshold:
            deviation = fast_threshold - current_duration
            return PacingAnomaly(
                type=self.RUSHING,
                severity=self._calc_severity(deviation / fast_threshold),
                expected_duration=baseline['median_duration'],
                actual_duration=current_duration,
                deviation_ratio=current_duration / baseline['median_duration'],
                suggestion="这道题你答得很快，建议再检查一下题干中的关键条件。"
            )
        
        # 拖沓检测：时间远超正常范围
        if current_duration > slow_threshold:
            deviation = current_duration - slow_threshold
            return PacingAnomaly(
                type=self.STALLING,
                severity=self._calc_severity(deviation / slow_threshold),
                expected_duration=baseline['median_duration'],
                actual_duration=current_duration,
                deviation_ratio=current_duration / baseline['median_duration'],
                suggestion="这道题花了一些时间，如果卡住了可以尝试先跳过，回头再看。"
            )
        
        return None
    
    def detect_session_pattern(
        self,
        time_records: List[AnswerTimeRecord]
    ) -> Optional[PacingAnomaly]:
        """
        会话级波动检测：整个练习会话结束后分析
        """
        durations = [r.total_duration for r in time_records if r.total_duration]
        if len(durations) < 5:
            return None
        
        cv = np.std(durations) / np.mean(durations) if np.mean(durations) > 0 else 0
        if cv > 0.7:
            return PacingAnomaly(
                type=self.VOLATILE,
                severity="MEDIUM" if cv < 1.0 else "HIGH",
                deviation_ratio=cv,
                suggestion="本次练习答题节奏波动较大，尝试保持稳定 pace。"
            )
        return None
    
    @staticmethod
    def _calc_severity(ratio: float) -> str:
        if ratio > 0.5:
            return "HIGH"
        elif ratio > 0.3:
            return "MEDIUM"
        return "LOW"
```

### 3.3 时间-正确率相关性分析

分析答题时间与正确率之间的相关性，判断学生是否存在"快而不准"或"慢而仍错"的问题。

```python
class TimeAccuracyCorrelation:
    """时间-正确率相关性分析"""
    
    def analyze(self, records: List[AnswerTimeRecord]) -> TimeAccuracyResult:
        """
        分析答题时间与正确率的关系
        
        返回：
        - correlation: 皮尔逊相关系数 (-1 ~ 1)
        - pattern: 时间-正确率关系模式
        - fast_zone_accuracy: 快速区间正确率
        - normal_zone_accuracy: 正常区间正确率
        - slow_zone_accuracy: 慢速区间正确率
        """
        if len(records) < 10:
            return TimeAccuracyResult(insufficient_data=True)
        
        durations = np.array([r.total_duration for r in records])
        correct = np.array([r.is_correct == 1 for r in records], dtype=float)
        
        # 皮尔逊相关系数
        correlation = self._pearson(durations, correct)
        
        # 分区间正确率
        p33 = np.percentile(durations, 33)
        p67 = np.percentile(durations, 67)
        
        fast_mask = durations <= p33
        normal_mask = (durations > p33) & (durations <= p67)
        slow_mask = durations > p67
        
        fast_acc = correct[fast_mask].mean() if fast_mask.any() else 0
        normal_acc = correct[normal_mask].mean() if normal_mask.any() else 0
        slow_acc = correct[slow_mask].mean() if slow_mask.any() else 0
        
        # 模式判断
        if fast_acc > normal_acc + 0.1 and fast_acc > slow_acc + 0.1:
            pattern = "FAST_DOMINANT"  # 快答正确率高→题目简单，学生掌握好
        elif slow_acc > fast_acc + 0.15:
            pattern = "SLOW_REQUIRED"  # 慢答正确率高→需要时间思考，难度适配
        elif fast_acc < 0.5 and correlation < 0:
            pattern = "RUSH_ERROR"  # 快答错误多→抢答问题
        elif slow_acc < 0.4:
            pattern = "SLOW_CONFUSED"  # 慢答仍错→知识盲区
        else:
            pattern = "NORMAL"
        
        return TimeAccuracyResult(
            correlation=correlation,
            pattern=pattern,
            fast_zone_accuracy=fast_acc,
            normal_zone_accuracy=normal_acc,
            slow_zone_accuracy=slow_acc
        )
```

### 3.4 学习效率指数计算

```python
class EfficiencyCalculator:
    """学习效率指数计算器"""
    
    def calculate(
        self,
        records: List[AnswerTimeRecord],
        baseline_median: float
    ) -> float:
        """
        效率指数 = 加权正确率 / 相对时间比
        
        - 值 > 1.2：高效学习
        - 值 0.8~1.2：正常
        - 值 < 0.8：低效（太慢或错误太多）
        """
        if not records or baseline_median <= 0:
            return 50.0  # 默认中性分
        
        # 加权正确率（难题权重高）
        weights = {1: 0.5, 2: 0.75, 3: 1.0, 4: 1.25, 5: 1.5}
        weighted_correct = sum(
            (1 if r.is_correct == 1 else 0) * weights.get(r.difficulty_level, 1.0)
            for r in records
        )
        total_weight = sum(weights.get(r.difficulty_level, 1.0) for r in records)
        
        if total_weight == 0:
            return 50.0
        
        weighted_accuracy = weighted_correct / total_weight
        avg_time = np.mean([r.total_duration for r in records])
        relative_time = avg_time / baseline_median
        
        if relative_time == 0:
            return 50.0
        
        efficiency = weighted_accuracy / relative_time
        # 映射到 0-100 分
        score = min(100, max(0, efficiency * 60))
        return round(score, 2)
```

### 3.5 画像增量更新算法

每次有新答题记录时，增量更新学生节奏画像，避免全量重算。

```python
class PacingProfileUpdater:
    """学生节奏画像增量更新"""
    
    def incremental_update(
        self,
        user_id: int,
        subject_code: str,
        question_type: str,
        new_records: List[AnswerTimeRecord]
    ) -> StudentPacingProfile:
        """
        Welford 算法在线更新均值和方差
        避免每次全量重算
        """
        profile = self.repo.get_or_create(user_id, subject_code, question_type)
        
        for record in new_records:
            duration = record.total_duration
            if duration is None or duration <= 0:
                continue
            
            n = profile.sample_count
            n_new = n + 1
            
            # Welford 均值更新
            delta = duration - profile.mean_duration
            profile.mean_duration = profile.mean_duration + delta / n_new
            
            # Welford M2 更新（用于方差）
            delta2 = duration - profile.mean_duration
            profile._m2 = profile._m2 + delta * delta2
            
            # 方差
            if n_new > 1:
                profile.std_duration = math.sqrt(profile._m2 / (n_new - 1))
            
            profile.sample_count = n_new
            
            # 更新正确率
            if record.is_correct is not None:
                # 在线平均更新
                profile.avg_accuracy = (
                    profile.avg_accuracy * n + 
                    (1 if record.is_correct == 1 else 0)
                ) / n_new
        
        # 重新计算分位数（需要维护一个有界缓冲区）
        profile = self._update_percentiles(profile, new_records)
        
        # 重新分类节奏类型
        profile.pacing_type, profile.pacing_score = self._classify_pacing(profile)
        
        # 计算效率指数
        profile.efficiency_index = self._calc_efficiency(profile)
        
        # 趋势判断
        profile.recent_trend = self._calc_trend(user_id, subject_code)
        
        profile.last_updated_at = datetime.now()
        self.repo.save(profile)
        return profile
```

```python
# pacing_service.py
from dataclasses import dataclass
from typing import Optional, List
from datetime import datetime
import numpy as np


@dataclass
class PacingAnomaly:
    type: str
    severity: str
    expected_duration: float
    actual_duration: float
    deviation_ratio: float
    suggestion: str = ""


class PacingService:
    """答题节奏分析核心服务"""
    
    def __init__(
        self,
        time_record_repo: 'AnswerTimeRecordRepository',
        profile_repo: 'PacingProfileRepository',
        baseline_repo: 'PacingBaselineRepository',
        anomaly_repo: 'PacingAnomalyRepository',
        event_publisher: 'EventPublisher'
    ):
        self._time_repo = time_record_repo
        self._profile_repo = profile_repo
        self._baseline_repo = baseline_repo
        self._anomaly_repo = anomaly_repo
        self._event_publisher = event_publisher
        
        self._detector = PacingAnomalyDetector()
        self._correlation_analyzer = TimeAccuracyCorrelation()
        self._efficiency_calc = EfficiencyCalculator()
        self._profile_updater = PacingProfileUpdater(profile_repo)
    
    def record_answer_time(
        self,
        user_id: int,
        record_data: dict
    ) -> dict:
        """
        记录答题时间并执行实时异常检测
        核心入口方法
        """
        # 1. 持久化时间记录
        time_record = self._time_repo.save(
            AnswerTimeRecord.from_dict(user_id, record_data)
        )
        
        # 2. 获取基准数据
        baseline = self._baseline_repo.get(
            grade_level=record_data['grade_level'],
            subject_code=record_data['subjectCode'],
            question_type=record_data['questionType'],
            difficulty_level=record_data['difficultyLevel']
        )
        
        # 3. 获取学生个人画像
        profile = self._profile_repo.get(
            user_id=user_id,
            subject_code=record_data['subjectCode'],
            question_type=record_data['questionType']
        )
        
        # 4. 实时异常检测
        realtime_alert = None
        if baseline:
            anomaly = self._detector.detect_realtime(
                user_id=user_id,
                question_meta=record_data,
                current_duration=time_record.total_duration,
                personal_profile=profile,
                baseline=baseline
            )
            if anomaly:
                self._anomaly_repo.save(user_id, anomaly, record_data)
                realtime_alert = anomaly
                
                # 发布异常事件供其他模块消费
                self._event_publisher.publish(
                    'pacing.anomaly.detected',
                    {'user_id': user_id, 'anomaly': anomaly.__dict__}
                )
        
        # 5. 异步增量更新画像
        self._profile_updater.incremental_update(
            user_id=user_id,
            subject_code=record_data['subjectCode'],
            question_type=record_data['questionType'],
            new_records=[time_record]
        )
        
        return {
            'recordId': time_record.record_id,
            'realtimeAlert': realtime_alert.__dict__ if realtime_alert else None
        }
    
    def get_session_report(self, session_id: str) -> dict:
        """生成练习会话节奏报告"""
        records = self._time_repo.find_by_session(session_id)
        if not records:
            return {'error': 'SESSION_NOT_FOUND'}
        
        user_id = records[0].user_id
        subject_code = records[0].subject_code
        
        # 时间分布统计
        durations = [r.total_duration for r in records if r.total_duration]
        accuracy = [1 if r.is_correct == 1 else 0 for r in records if r.is_correct is not None]
        
        overall_accuracy = sum(accuracy) / len(accuracy) if accuracy else 0
        
        # 分区间统计
        zone_breakdown = self._calc_zone_breakdown(records)
        
        # 时间-正确率相关性
        ta_result = self._correlation_analyzer.analyze(records)
        
        # 会话级异常检测
        session_anomaly = self._detector.detect_session_pattern(records)
        
        # 基准对比
        baseline = self._baseline_repo.get_by_records(records[0])
        
        # 效率指数
        efficiency = self._efficiency_calc.calculate(
            records,
            baseline.median_duration if baseline else 60.0
        )
        
        # 生成建议
        suggestions = self._generate_suggestions(
            records, ta_result, session_anomaly, zone_breakdown
        )
        
        return {
            'sessionSummary': {
                'totalQuestions': len(records),
                'totalDuration': round(sum(durations), 1),
                'avgDurationPerQuestion': round(np.mean(durations), 1),
                'overallAccuracy': round(overall_accuracy, 4),
                'efficiencyIndex': efficiency
            },
            'pacingAnalysis': {
                'timeDistribution': {
                    'p25': round(np.percentile(durations, 25), 1),
                    'median': round(np.median(durations), 1),
                    'p75': round(np.percentile(durations, 75), 1),
                    'std': round(np.std(durations), 1)
                },
                'timeAccuracyPattern': ta_result.pattern,
                'correlation': round(ta_result.correlation, 4)
            },
            'zoneBreakdown': zone_breakdown,
            'anomalies': self._format_anomalies(session_anomaly, records),
            'suggestions': suggestions
        }
    
    def _calc_zone_breakdown(self, records: List) -> List[dict]:
        """计算快/中/慢三区间的正确率"""
        durations = np.array([r.total_duration for r in records if r.total_duration])
        if len(durations) < 3:
            return []
        
        p33, p67 = np.percentile(durations, [33, 67])
        zones = []
        
        for zone_name, lo, hi in [('fast', 0, p33), ('normal', p33, p67), ('slow', p67, float('inf'))]:
            zone_records = [r for r in records if r.total_duration and lo <= r.total_duration < hi]
            if not zone_records:
                continue
            
            zone_accuracy = sum(1 for r in zone_records if r.is_correct == 1) / len(zone_records)
            zones.append({
                'zone': zone_name,
                'count': len(zone_records),
                'accuracy': round(zone_accuracy, 4),
                'avgDuration': round(np.mean([r.total_duration for r in zone_records]), 1)
            })
        
        return zones
    
    def _generate_suggestions(self, records, ta_result, session_anomaly, zone_breakdown) -> List[str]:
        """基于分析结果生成个性化建议"""
        suggestions = []
        
        fast_zone = next((z for z in zone_breakdown if z['zone'] == 'fast'), None)
        slow_zone = next((z for z in zone_breakdown if z['zone'] == 'slow'), None)
        normal_zone = next((z for z in zone_breakdown if z['zone'] == 'normal'), None)
        
        if ta_result.pattern == 'RUSH_ERROR':
            suggestions.append('快速答题区间的正确率明显偏低，建议每道题至少花10秒审清题意。')
        
        if ta_result.pattern == 'SLOW_CONFUSED':
            suggestions.append('部分题目耗时较长但未答对，遇到卡壳的题目建议先跳过，完成其他题目后再回来思考。')
        
        if session_anomaly and session_anomaly.type == 'VOLATILE':
            suggestions.append('本次练习答题节奏波动较大，建议按题目难度合理分配时间。')
        
        if fast_zone and normal_zone and fast_zone['accuracy'] < normal_zone['accuracy'] - 0.15:
            gap = normal_zone['accuracy'] - fast_zone['accuracy']
            suggestions.append(
                f'快速答题区间正确率（{fast_zone["accuracy"]:.0%}）'
                f'明显低于正常节奏（{normal_zone["accuracy"]:.0%}），'
                f'建议适当放慢速度以提升准确度。'
            )
        
        if not suggestions:
            suggestions.append('本次练习节奏整体稳定，建议保持当前答题习惯。')
        
        return suggestions
```

```python
class PacingBaselineJob:
    """每周日凌晨2点统计更新全平台答题节奏基准"""
    
    def __init__(self, time_record_repo, baseline_repo):
        self._time_repo = time_record_repo

        scheduler = BackgroundScheduler()
        scheduler.add_job(
            self._update_baselines,
            'cron',
            day_of_week='sun',
            hour=2,
            minute=0,
            id='pacing_baseline_update'
        )
        scheduler.start()
    
    def _update_baselines(self):
        """按年级×学科×题型×难度维度统计近90天的基准数据"""
        # 获取所有维度组合
        dimensions = self._time_repo.get_dimensions()
        
        for dim in dimensions:
            records = self._time_repo.query_recent(
                grade_level=dim['grade_level'],
                subject_code=dim['subject_code'],
                question_type=dim['question_type'],
                difficulty_level=dim['difficulty_level'],
                days=90
            )
            
            if len(records) < 100:
                continue  # 样本不足，跳过
            
            durations = [r.total_duration for r in records if r.total_duration]
            accuracies = [1 if r.is_correct == 1 else 0 for r in records if r.is_correct is not None]
            
            median = float(np.median(durations))
            p25 = float(np.percentile(durations, 25))
            p75 = float(np.percentile(durations, 75))
            
            self._baseline_repo.upsert(
                grade_level=dim['grade_level'],
                subject_code=dim['subject_code'],
                question_type=dim['question_type'],
                difficulty_level=dim['difficulty_level'],
                sample_count=len(records),
                median_duration=median,
                p25_duration=p25,
                p75_duration=p75,
                fast_threshold=p25 * 0.5,  # 基准P25的一半作为抢答阈值
                slow_threshold=float(np.percentile(durations, 95)),  # P95作为拖沓阈值
                avg_accuracy=float(np.mean(accuracies))
            )
        
        logging.info(f'Pacing baseline update completed: {len(dimensions)} dimensions')
```

## 7. 错误处理

### 7.1 错误码定义

| 错误码 | 含义 | 处理策略 |
|--------|------|----------|
| `PACING_001` | 时间数据非法（提交时间早于查看时间） | 丢弃记录，返回参数错误 |
| `PACING_002` | 时间数据缺失（缺少必要时间戳） | 使用默认值填充，标记数据质量为LOW |
| `PACING_003` | 时间异常偏大（>3600秒） | 截断为3600秒上限，标记为SCREEN_OFF异常 |
| `PACING_004` | 时间为零或负数 | 丢弃记录，返回参数错误 |
| `PACING_005` | 基准数据不存在 | 降级使用默认阈值（选择题60秒，填空题90秒等）|
| `PACING_006` | 样本量不足 | 返回COLD_START状态，仅返回基准对比数据 |
| `PACING_007` | 重复提交（幂等冲突） | 返回已存在的recordId，不重复写入 |

### 7.2 异常场景处理

```python
# error_handler.py
class PacingErrorHandler:
    """答题节奏服务异常处理器"""
    
    DEFAULT_THRESHOLDS = {
        ('choice', 1): 30, ('choice', 3): 60, ('choice', 5): 120,
        ('fill', 1): 45, ('fill', 3): 90, ('fill', 5): 180,
        ('solve', 1): 120, ('solve', 3): 240, ('solve', 5): 480,
        ('essay', 1): 300, ('essay', 3): 600, ('essay', 5): 1200,
    }
    
    @staticmethod
    def validate_record(record_data: dict) -> tuple[bool, str]:
        """校验时间数据合法性"""
        fvt = record_data.get('firstViewTime', 0)
        sat = record_data.get('startAnswerTime', 0)
        smt = record_data.get('submitTime', 0)
        
        if not fvt or not sat or not smt:
            return False, 'PACING_002: Missing required timestamp'
        
        if smt <= fvt or sat < fvt or smt < sat:
            return False, 'PACING_001: Invalid timestamp sequence'
        
        total_duration = (smt - fvt) / 1000  # ms → s
        if total_duration <= 0:
            return False, 'PACING_004: Non-positive duration'
        
        if total_duration > 3600:
            record_data['_truncated'] = True
            record_data['_original_duration'] = total_duration
            # 截断处理在后续业务逻辑中执行
            
        return True, 'OK'
    
    @staticmethod
    def get_fallback_threshold(
        question_type: str,
        difficulty_level: int
    ) -> dict:
        """基准缺失时的降级阈值"""
        key = (question_type, difficulty_level)
        median = PacingErrorHandler.DEFAULT_THRESHOLDS.get(
            key,
            PacingErrorHandler.DEFAULT_THRESHOLDS.get((question_type, 3), 60)
        )
        return {
            'median_duration': median,
            'fast_threshold': median * 0.5,
            'slow_threshold': median * 3.0,
            'avg_accuracy': 0.70
        }
```

## 8. 性能优化

### 8.1 写入优化

**批量异步写入**：答题时间记录先写入内存缓冲区，每5秒或满100条批量落库。

```python
class AsyncTimeRecordBuffer:
    """异步批量写入缓冲区"""
    
    BUFFER_SIZE = 100
    FLUSH_INTERVAL = 5  # seconds
    
    def __init__(self, repo, flush_interval=FLUSH_INTERVAL):
        self._buffer = []
        self._repo = repo
        self._lock = threading.Lock()
        self._timer = threading.Timer(flush_interval, self._flush)
        self._timer.daemon = True
        self._timer.start()
    
    def add(self, record: AnswerTimeRecord):
        with self._lock:
            self._buffer.append(record)
            if len(self._buffer) >= self.BUFFER_SIZE:
                self._flush()
    
    def _flush(self):
        with self._lock:
            if not self._buffer:
                return
            batch = self._buffer[:]
            self._buffer.clear()
        
        try:
            self._repo.batch_insert(batch)
        except Exception as e:
            logging.error(f'Batch insert failed: {e}, falling back to single insert')
            for record in batch:
                try:
                    self._repo.save(record)
                except Exception:
                    logging.error(f'Single insert also failed for record {record.record_id}')
        finally:
            # 重置定时器
            self._timer = threading.Timer(self.FLUSH_INTERVAL, self._flush)
            self._timer.daemon = True
            self._timer.start()
```

### 8.2 查询优化

1. **画像缓存**：`student_pacing_profile` 通过 Redis 缓存，TTL=1小时，写入时双删。
2. **基准缓存**：`pacing_baseline` 全量加载到内存（数据量小，预计<5000行），启动时加载。
3. **时间记录冷热分离**：近30天数据在 MySQL 热表，历史数据按月归档到冷表。
4. **会话报告缓存**：同一 session 的报告生成后缓存，TTL=7天。

### 9.4 与知识追踪模块联动

```python
# 知识追踪模块消费节奏数据
class KnowledgeTrackerIntegration:
    def update_mastery_with_pacing(self, user_id, knowledge_point_id, answer_result):
        """结合答题时间校准知识掌握度"""
        # 基础掌握度（基于正确率）
        base_mastery = self._calc_base_mastery(answer_result)
        
        # 获取该题的时间分位
        pacing_profile = pacing_service.get_profile(user_id, answer_result.subject)
        if pacing_profile and pacing_profile.sample_count >= 20:
            # 快速且正确 → 掌握度高
            # 慢速但正确 → 掌握度中等（需要思考）
            # 慢速且错误 → 掌握度低（知识盲区）
            time_factor = self._calc_time_factor(
                answer_result.total_duration,
                pacing_profile.median_duration
            )
            
            if answer_result.is_correct and time_factor < 0.7:
                # 快速正确：增强掌握度信号
                adjusted_mastery = base_mastery + 0.05
            elif not answer_result.is_correct and time_factor > 1.5:
                # 慢速错误：减弱掌握度信号（确实不会）
                adjusted_mastery = base_mastery - 0.05
            else:
                adjusted_mastery = base_mastery
            
            return max(0, min(1, adjusted_mastery))
        
        return base_mastery
```

```python
class PacingDataQualityMonitor:
    """每日数据质量巡检"""
    
    def daily_check(self):
        report = {
            'date': datetime.now().strftime('%Y-%m-%d'),
            'total_records': 0,
            'invalid_records': 0,
            'truncated_records': 0,
            'missing_profile_count': 0,
            'stale_baseline_count': 0
        }
        
        # 检查昨日数据
        yesterday = datetime.now() - timedelta(days=1)
        records = self._time_repo.query_by_date(yesterday)
        report['total_records'] = len(records)
        
        for r in records:
            if r.total_duration is None or r.total_duration <= 0:
                report['invalid_records'] += 1
            elif getattr(r, '_truncated', False):
                report['truncated_records'] += 1
        
        # 检查画像覆盖率
        active_users = self._get_active_users(yesterday)
        for user_id in active_users[:1000]:  # 抽样
            for subject in ['math', 'chinese', 'english']:
                profile = self._profile_repo.get(user_id, subject, 'choice')
                if not profile or profile.sample_count < 10:
                    report['missing_profile_count'] += 1
        
        # 检查基准新鲜度
        baselines = self._baseline_repo.get_all()
        for b in baselines:
            if (datetime.now() - b.updated_at).days > 14:
                report['stale_baseline_count'] += 1
        
        # 发送告警
        if report['invalid_records'] / max(report['total_records'], 1) > 0.05:
            alert.send('PACING_DATA_QUALITY_ALERT', report)
        
        if report['stale_baseline_count'] > 0:
            alert.send('PACING_BASELINE_STALE', report)
        
        return report
```

### 12.2 术语表

|------|------|
| Pacing Type | 答题节奏类型：balanced/rushed/sluggish/volatile |
| Efficiency Index | 效率指数=加权正确率/相对时间比，映射到0-100 |

| Stalling | 拖沓行为，答题时间远超正常范围 |
| Volatile | 波动行为，答题时间标准差过大 |
| RT (Relative Time) | 相对时间比=个人中位数/基准中位数 |
| CV (Coefficient of Variation) | 变异系数=标准差/均值 |
