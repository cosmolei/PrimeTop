# 服务端-教育平台统一指标中心与数据语义查询引擎 详细设计

## 1. 概述

### 1.1 模块定位

统一指标中心（Unified Metrics Center，简称 UMC）是 PrimeTop 教育平台的数据语义基础设施层。其核心目标是解决"同一指标多处计算、定义不一致、口径混乱"的问题，为平台所有业务服务、管理后台、数据看板和自助分析提供统一的指标定义、计算和查询入口。

在 PrimeTop 这样的全学段 AI 辅助学习平台中，存在大量跨模块的数据指标需求：

- **学生端**需要展示个人学习时长、掌握度、进步趋势
- **家长端**需要查看孩子学情报告中的正确率、薄弱点分布
- **教师端**需要班级平均分、知识点通过率
- **运营后台**需要 DAU、留存率、转化漏斗、AI 调用成本
- **管理驾驶舱**需要实时业务指标大屏

如果每个消费方各自编写统计 SQL，势必导致指标口径不一致（如"学习时长"是否包含后台挂起时间、"正确率"是按题数还是按知识点加权），且修改指标定义需要逐个服务变更。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 指标定义管理 | 统一定义所有业务指标的名称、口径、计算公式、维度、粒度 |
| 指标目录服务 | 提供指标检索、分类、血缘追踪能力 |
| 指标查询引擎 | 接收指标查询请求，自动生成 SQL 并路由到合适数据源 |
| 自助分析服务 | 支持非技术人员通过维度拖拽、指标组合进行自助探索分析 |
| 指标版本管理 | 指标定义变更时保留历史版本，支持回溯查询历史口径数据 |
| 数据权限管控 | 按角色、数据范围控制可查询的指标和数据粒度 |

- 用户服务 → 用户注册、活跃、设备数据

- 题目服务 → 答题记录、正误结果、知识点映射
- 错题服务 → 错题收录、复习记录
- AI 服务 → 对话记录、Token 消耗、响应耗时

- 运营数据分析看板
- 管理后台驾驶舱
- 外部数据上报接口

### 1.4 设计目标

1. **口径统一**：同一指标在全平台任何消费场景下计算结果一致。
2. **配置驱动**：指标定义通过 YAML/JSON 配置，新增指标无需修改消费方代码。
3. **性能可控**：支持实时查询、预计算物化、多级缓存三种模式自动选择。
4. **安全合规**：未成年人数据自动脱敏，数据范围按角色严格隔离。
5. **可扩展**：支持新增数据源、自定义指标和自定义维度扩展。

## 2. 核心概念

### 2.1 指标（Metric）

指标是对业务现象的可量化度量，由以下要素定义：

```yaml
# 示例：学生日均有效学习时长
metric_id: "study_daily_avg_effective_duration"
name: "学生日均有效学习时长"
name_en: "DailyAvgEffectiveStudyDuration"
description: "学生在指定日期范围内，每天有效学习时长的平均值。有效学习时长排除了后台挂起、无操作空闲（>5分钟）等非学习时间。"
category: "LEARNING"
type: "DERIVED"           # ATOMIC | DERIVED | COMPOSITE | WINDOW
unit: "MINUTE"            # COUNT | MINUTE | SECOND | PERCENT | RATIO | CURRENCY
granularity: "DAILY"      # REALTIME | HOURLY | DAILY | WEEKLY | MONTHLY
owner: "learning-team"
version: "1.2.0"
status: "ACTIVE"          # DRAFT | ACTIVE | DEPRECATED

# 计算口径定义
expression:
  base_metric: "study_session_effective_duration"  # 原子指标
  aggregation: "SUM"                                # SUM | AVG | COUNT | MAX | MIN | MEDIAN | P95
  time_window: "DAY"                                # 计算窗口
  group_by: ["student_id"]                          # 分组维度

# 可用维度
dimensions:
  - "student_id"
  - "grade"
  - "subject"
  - "textbook_version"
  - "school_id"
  - "date"
  - "week"
  - "month"

# 过滤条件
filters:
  - field: "is_valid_session"
    operator: "="
    value: true

# 数据源
source:
  database: "analytics_db"
  table: "dw_study_session_fact"
  or_materialized_view: "mv_daily_study_summary"

# 缓存策略
cache:
  level: "L2"             # L1(进程内) | L2(Redis) | NONE
  ttl_seconds: 3600
  refresh_cron: "0 10 * * *"   # 每天10点刷新

# 敏感度
sensitivity: "INTERNAL"    # PUBLIC | INTERNAL | CONFIDENTIAL | RESTRICTED
```

### 2.2 维度（Dimension）

维度是观察指标的角度：

| 维度类别 | 维度名 | 说明 | 数据来源 |
| --- | --- | --- | --- |
| 时间 | date / week / month / quarter | 日/周/月/季 | 统一时间维度表 |
| 用户 | student_id / grade / stage | 学生ID/年级/学段 | dim_student |
| 学科 | subject / chapter_id / kp_id | 学科/章节/知识点 | dim_subject, dim_knowledge_point |
| 内容 | content_type / textbook_version | 内容类型/教材版本 | dim_content |
| 设备 | platform / device_type | 平台/设备类型 | dim_device |
| 组织 | school_id / class_id / region | 学校/班级/地区 | dim_organization |
| 商业 | membership_level / channel | 会员等级/渠道 | dim_membership |

### 2.3 指标分类

```text
┌─────────────────────────────────────────────────────────────┐
│                    指标分类体系                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  原子指标（Atomic）                                          │
│  ├── 学习会话数 session_count                               │
│  ├── 答题总数 answer_total_count                            │
│  ├── AI对话轮次 ai_conversation_turn_count                  │
│  └── 订单金额 order_amount_sum                              │
│                                                             │
│  派生指标（Derived）= 原子指标 + 聚合 + 维度过滤              │
│  ├── 日均学习时长 study_daily_avg_duration                   │
│  ├── 答题正确率 answer_accuracy_rate                         │
│  ├── 周活跃天数 weekly_active_days                           │
│  └── AI平均响应耗时 ai_avg_response_ms                       │
│                                                             │
│  复合指标（Composite）= 多个指标的数学运算                    │
│  ├── 学习效率指数 study_efficiency_index                     │
│  │   = 掌握度提升率 / 学习时长投入                            │
│  ├── 用户健康度 user_health_score                            │
│  │   = 留存得分×0.4 + 活跃得分×0.3 + 付费意愿×0.3            │
│  └── AI质量综合评分 ai_quality_composite_score               │
│      = 准确率×0.5 + 满意率×0.3 + 响应速度×0.2                │
│                                                             │
│  窗口指标（Window）= 指标在时间窗口上的聚合                   │
│  ├── 7日留存率 retention_d7                                  │
│  ├── 30日活跃趋势 active_trend_30d                           │
│  ├── 环比增长率 mom_growth_rate                              │
│  └── 同比增长率 yoy_growth_rate                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 时间粒度

| 粒度 | 标识 | 说明 | 查询延迟目标 |
| --- | --- | --- | --- |
| 实时 | REALTIME | 最近5分钟内的事件流聚合 | < 2s |
| 小时 | HOURLY | 按小时聚合 | < 1s |
| 日 | DAILY | 按自然日聚合（默认） | < 500ms |
| 周 | WEEKLY | 按自然周聚合（周一至周日） | < 500ms |
| 月 | MONTHLY | 按自然月聚合 | < 500ms |
| 学期 | SEMESTER | 按学期聚合（上/下学期） | < 1s |
| 自定义 | CUSTOM | 用户指定时间范围 | < 2s |

## 3. 数据模型

### 3.1 数据库表结构设计

#### 3.1.1 metric_definitions（指标定义表）

```sql
CREATE TABLE metric_definitions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    metric_id       VARCHAR(128) NOT NULL UNIQUE COMMENT '指标唯一标识，如 study_daily_avg_duration',
    name            VARCHAR(256) NOT NULL COMMENT '指标中文名称',
    name_en         VARCHAR(256) COMMENT '指标英文名称',
    description     TEXT COMMENT '指标口径详细说明',
    category        VARCHAR(64) NOT NULL COMMENT '指标分类: USER/LEARNING/CONTENT/AI_QUALITY/BUSINESS/OPERATION',
    type            VARCHAR(32) NOT NULL COMMENT '指标类型: ATOMIC/DERIVED/COMPOSITE/WINDOW',
    unit            VARCHAR(32) NOT NULL COMMENT '计量单位: COUNT/MINUTE/SECOND/PERCENT/RATIO/CURRENCY',
    default_granularity VARCHAR(32) NOT NULL DEFAULT 'DAILY' COMMENT '默认时间粒度',
    expression_json JSON NOT NULL COMMENT '计算表达式(JSON格式)',
    owner_team      VARCHAR(64) NOT NULL COMMENT '负责团队',
    sensitivity     VARCHAR(32) NOT NULL DEFAULT 'INTERNAL' COMMENT '敏感度级别: PUBLIC/INTERNAL/CONFIDENTIAL/RESTRICTED',
    status          VARCHAR(16) NOT NULL DEFAULT 'DRAFT' COMMENT '状态: DRAFT/ACTIVE/DEPRECATED',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category (category),
    INDEX idx_status (status),
    INDEX idx_owner (owner_team)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='指标定义表';
```

#### 3.1.2 dimension_definitions（维度定义表）

```sql
CREATE TABLE dimension_definitions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    dimension_id    VARCHAR(128) NOT NULL UNIQUE COMMENT '维度唯一标识，如 student_id',
    name            VARCHAR(128) NOT NULL COMMENT '维度中文名称',
    name_en         VARCHAR(128) COMMENT '维度英文名称',
    category        VARCHAR(64) NOT NULL COMMENT '维度类别: TIME/USER/SUBJECT/CONTENT/DEVICE/ORG/BUSINESS',
    field_name      VARCHAR(128) NOT NULL COMMENT '数据库字段名',
    field_type      VARCHAR(32) NOT NULL COMMENT '字段类型: STRING/INT/DATE/DATETIME/ENUM',
    source_table    VARCHAR(256) COMMENT '来源表/视图',
    description     VARCHAR(512) COMMENT '维度说明',
    enum_values     JSON COMMENT '枚举值列表(如适用)',
    parent_dimension VARCHAR(128) COMMENT '父维度(如month的父维度为year)',
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category (category),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='维度定义表';
```

#### 3.1.3 metric_dimension_bindings（指标-维度绑定表）

### 3.2 缓存策略

| 缓存层 | 存储 | TTL | 适用场景 |
| --- | --- | --- | --- |
| L1 进程内 | Caffeine/Guava Cache | 60s | 高频查询的热点指标，如管理驾驶舱 |
| L2 分布式 | Redis Cluster | 5-3600s | 日级聚合指标，多实例共享 |
| L3 物化视图 | MySQL 物化表 | 按天 | 历史数据，T+1 或定时刷新 |

缓存键格式：
```
umc:{metric_id}:{version}:{dim_signature}:{time_range_hash}
```

示例：
```
umc:study_daily_avg_duration:1.2.0:d41d8cd98f00b204e9800998ecf8427e:20250701-20250707
```

## 4. 指标定义规范

### 4.1 指标定义 DSL

采用 YAML 格式定义指标，存储于 `resources/metrics/` 目录或通过管理后台动态配置：

```yaml
# resources/metrics/learning-metrics.yaml

metrics:
  # ========== 原子指标 ==========
  - id: study_session_count
    name: "学习会话数"
    name_en: "StudySessionCount"
    description: "学生发起的有效学习会话总次数。一个学习会话定义为从进入学习场景到退出学习场景的连续时间段。"
    category: LEARNING
    type: ATOMIC
    unit: COUNT
    default_granularity: DAILY
    expression:
      table: dw_study_session_fact
      measure: "COUNT(DISTINCT session_id)"
      time_field: session_date
    dimensions:
      - student_id
      - grade
      - subject
      - stage
      - date
      - week
      - month
    source:
      database: analytics_db
      table: dw_study_session_fact
    cache:
      level: L2
      ttl_seconds: 1800

  - id: answer_total_count
    name: "答题总数"
    description: "学生在指定时间范围内提交的答题总数（含练习、考试、作业场景）。"
    category: LEARNING
    type: ATOMIC
    unit: COUNT
    default_granularity: DAILY
    expression:
      table: dw_answer_record_fact
      measure: "COUNT(*)"
      time_field: answer_date
    filters:
      - field: is_submitted
        op: "="
        value: true
    dimensions:
      - student_id
      - grade
      - subject
      - question_type
      - source_type    # PRACTICE/EXAM/HOMEWORK
      - date
    source:
      database: analytics_db
      table: dw_answer_record_fact
    cache:
      level: L2
      ttl_seconds: 1800

  # ========== 派生指标 ==========
  - id: answer_accuracy_rate
    name: "答题正确率"
    description: "学生在指定时间范围内答对题目数占总提交答题数的百分比。"
    category: LEARNING
    type: DERIVED
    unit: PERCENT
    default_granularity: DAILY
    expression:
      numerator:
        base_metric: answer_total_count
        additional_filter:
          - field: is_correct
            op: "="
            value: true
      denominator:
        base_metric: answer_total_count
      formula: "numerator / denominator * 100"
    dimensions:
      - student_id
      - grade
      - subject
      - question_type
      - source_type
      - date
      - week
      - month
    cache:
      level: L2
      ttl_seconds: 1800

  - id: study_effective_duration
    name: "有效学习时长"
    description: "学生在指定时间范围内有效学习时长（分钟），排除后台挂起、无操作空闲（>5分钟）等非学习时间。"
    category: LEARNING
    type: DERIVED
    unit: MINUTE
    default_granularity: DAILY
    expression:
      table: dw_study_session_fact
      measure: "SUM(effective_duration_minutes)"
      time_field: session_date
      row_filter:
        - field: is_valid_session
          op: "="
          value: true
    dimensions:
      - student_id
      - grade
      - subject
      - stage
      - date
      - week
      - month
    cache:
      level: L2
      ttl_seconds: 3600

  # ========== 复合指标 ==========
  - id: study_efficiency_index
    name: "学习效率指数"
    description: "学习效率指数 = 知识掌握度提升率 / 学习时长投入比。值越高表示单位时间学习产出越高。"
    category: LEARNING
    type: COMPOSITE
    unit: RATIO
    default_granularity: WEEKLY
    expression:
      formula: |
        (mastery_improvement_rate) / 
        (study_duration / peer_avg_study_duration)
      inputs:
        mastery_improvement_rate:
          metric_id: mastery_improvement_rate
          default_window: 7d
        study_duration:
          metric_id: study_effective_duration
          default_window: 7d
        peer_avg_study_duration:
          metric_id: study_effective_duration
          aggregation: AVG
          scope: GRADE_LEVEL
          default_window: 7d
    dimensions:
      - student_id
      - grade
      - subject
      - week
      - month
    sensitivity: CONFIDENTIAL
    cache:
      level: L2
      ttl_seconds: 7200

  # ========== 窗口指标 ==========
  - id: retention_rate
    name: "用户留存率"
    description: "注册后在第N天仍然活跃的用户占注册用户的百分比。N 可为 1/3/7/14/30。"
    category: USER
    type: WINDOW
    unit: PERCENT
    default_granularity: DAILY
    expression:
      numerator:
        table: dws_user_retention_di
        measure: "COUNT(DISTINCT user_id)"
        filter:
          - field: is_active_on_day_n
            op: "="
            value: true
      denominator:
        table: dws_user_retention_di
        measure: "COUNT(DISTINCT user_id)"
      formula: "numerator / denominator * 100"
    dimensions:
      - retention_day   # 1, 3, 7, 14, 30
      - register_channel
      - stage
      - grade
      - date
    cache:
      level: L2
      ttl_seconds: 3600
```

### 4.2 指标表达式语法

指标表达式支持以下元素：

```bnf
expression ::= base_query | derived_expr | composite_expr | window_expr

base_query ::=
    "table:" string
    "measure:" sql_aggregate_expr
    "time_field:" identifier
    ["row_filter:" filter_list]

derived_expr ::=
    "numerator:" base_query
    "denominator:" base_query
    "formula:" arithmetic_expr

composite_expr ::=
    "formula:" arithmetic_expr_with_inputs
    "inputs:" input_map

arithmetic_expr ::= 
    term (("+" | "-" | "*" | "/" | "||") term)*

term ::= number | identifier | function_call | "(" arithmetic_expr ")"

function_call ::= 
    "ABS(" expr ")"
    "ROUND(" expr "," digits ")"
    "COALESCE(" expr "," default ")"
    "CASE WHEN " condition " THEN " expr " ELSE " expr " END"
    "GREATEST(" expr_list ")"
    "LEAST(" expr_list ")"
```
