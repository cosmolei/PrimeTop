# 客户端-成就勋章与奖励展示组件 详细设计

## 1. 模块概述

### 1.1 功能定位

成就勋章与奖励展示组件是面向学生端的激励可视化层，负责将服务端的成就数据（徽章、等级、积分、连续天数、里程碑等）转化为富有吸引力的视觉呈现和交互体验，驱动学生的学习动力和持续活跃。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 即时反馈 | 成就解锁后 200ms 内触发视觉反馈 |
| 分龄适配 | 幼儿→卡通/大图标；高中→简洁/数据化 |
| 离线可用 | 本地缓存成就数据，弱网可展示 |
| 低侵入 | 不干扰学习流程，以弹窗/角标等轻量方式展示 |
| 可分享 | 关键成就可生成分享海报 |

### 1.3 依赖模块

| 依赖 | 说明 |
|------|------|
| 学生成就与学习里程碑追踪引擎 | 提供 achievement、milestone API |
| 积分与虚拟经济体系 | 提供 points、balance、transaction API |
| 运营活动与成长激励体系 | 提供 check-in、challenge、rank API |
| 客户端状态管理架构 | Riverpod Provider 体系 |
| 客户端主题引擎与动态外观系统 | 分龄主题适配 |
| 客户端本地持久层与数据管理 | Hive 本地缓存 |
| 客户端动画与手势交互系统 | 动画基础设施 |

/// ============ 成就数据 Provider ============

/// 成就徽章列表（按分类分组）
@riverpod
class AchievementBadges extends _$AchievementBadges {
  @override
  FutureOr<Map<String, List<AchievementBadge>>> build() async {
    // 先读本地缓存
    final cached = await _loadFromHive();
    if (cached != null) {
      // 后台刷新
      ref.read(achievementRefreshProvider.notifier).trigger();
      return cached;
    }
    return await _fetchFromServer();
  }

  Future<Map<String, List<AchievementBadge>>> _fetchFromServer() async {
    final api = ref.read(apiClientProvider);
    final response = await api.get('/api/v1/achievements/badges', 
      queryParameters: {'page_size': 200});
    
    final badges = (response.data['badges'] as List)
        .map((b) => AchievementBadge.fromJson(b))
        .toList();

    // 按分类分组
    final grouped = <String, List<AchievementBadge>>{};
    for (final badge in badges) {
      grouped.putIfAbsent(badge.category, () => []).add(badge);
    }

    // 写入 Hive 缓存
    await _saveToHive(grouped);
    return grouped;
  }

  /// 标记徽章已读
  Future<void> markAsRead(String badgeId) async {
    final api = ref.read(apiClientProvider);
    await api.post('/api/v1/achievements/badges/$badgeId/read');
    
    // 更新本地状态
    state = AsyncData(state.value!.map((category, badges) =>
      MapEntry(category, badges.map((b) => 
        b.badgeId == badgeId ? b.copyWith(isNew: false) : b
      ).toList())
    ));
  }
}

/// 用户等级信息
@riverpod
class UserLevel extends _$UserLevel {
  @override
  FutureOr<UserLevelInfo> build() async {
    final box = await Hive.openBox<UserLevelInfo>('achievement_cache');
    final cached = box.get('user_level');
    if (cached != null) {
      _backgroundRefresh();
      return cached;
    }
    return await _fetch();
  }

  Future<UserLevelInfo> _fetch() async {
    final api = ref.read(apiClientProvider);
    final response = await api.get('/api/v1/achievements/level');
    final info = UserLevelInfo.fromJson(response.data);
    final box = await Hive.openBox<UserLevelInfo>('achievement_cache');
    await box.put('user_level', info);
    return info;
  }

  void _backgroundRefresh() async {
    try {
      final fresh = await _fetch();
      state = AsyncData(fresh);
    } catch (_) {}
  }
}

/// 成就解锁弹窗队列
@riverpod
class AchievementPopupQueue extends _$AchievementPopupQueue {
  @override
  List<AchievementUnlockEvent> build() => [];

  void enqueue(AchievementUnlockEvent event) {
    state = [...state, event];
  }

  void dequeue() {
    if (state.isNotEmpty) {
      state = state.sublist(1);
    }
  }
}

/// 后台刷新触发器
@riverpod
class AchievementRefresh extends _$AchievementRefresh {
  @override
  bool build() => false;

  void trigger() {
    state = true;
    // 延迟执行，避免并发
    Future.delayed(const Duration(seconds: 2), () {
      ref.invalidate(achievementBadgesProvider);
      ref.invalidate(userLevelProvider);
      ref.invalidate(streakInfoProvider);
      state = false;
    });
  }
}

/// 成就相关 SSE 事件监听
class AchievementSSEHandler {
  final Ref _ref;

  void handleEvent(SSEEvent event) {
    switch (event.eventType) {
      case 'achievement.unlocked':
        final data = AchievementUnlockEvent.fromJson(event.data);
        // 加入弹窗队列
        _ref.read(achievementPopupQueueProvider.notifier).enqueue(data);
        // 刷新徽章列表
        _ref.invalidate(achievementBadgesProvider);
        _ref.invalidate(userLevelProvider);
        break;

      case 'level.up':
        final data = LevelUpEvent.fromJson(event.data);
        _showLevelUpAnimation(data);
        _ref.invalidate(userLevelProvider);
        break;

      case 'check_in.reminder':
        // 不在成就组件处理，由通知系统处理
        break;

      case 'milestone.reached':
        final milestone = event.data['milestone_id'] as String;
        _ref.invalidate(userLevelProvider);
        break;
    }
  }

  void _showLevelUpAnimation(LevelUpEvent event) {
    // 全屏升级动画，见 4.5 节
    _ref.read(overlayManagerProvider).show(
      LevelUpOverlay(event: event),
    );
  }
}

class BadgeCard extends ConsumerStatefulWidget {
  final AchievementBadge badge;
  final VoidCallback? onTap;
  final double size; // 基准尺寸，用于网格适配

  const BadgeCard({
    super.key,
    required this.badge,

  @override
  ConsumerState<BadgeCard> createState() => _BadgeCardState();
}

class _BadgeCardState extends ConsumerState<BadgeCard>
    with SingleTickerProviderStateMixin {
  late AnimationController _glowController;
  late Animation<double> _glowAnimation;

  @override
  void initState() {
    super.initState();
    _glowController = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1500),
    )..repeat(reverse: true);
    _glowAnimation = Tween<double>(begin: 0.3, end: 1.0).animate(
      CurvedAnimation(parent: _glowController, curve: Curves.easeInOut),
    );
  }

  @override
  void dispose() {
    _glowController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final theme = ref.watch(ageAppThemeProvider);
    final isUnlocked = widget.badge.isUnlocked;
    final isSecret = widget.badge.isSecret && !isUnlocked;

    return GestureDetector(
      onTap: widget.onTap ?? () => _showBadgeDetail(context),
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 300),
        width: widget.size,
        height: widget.size,
        decoration: BoxDecoration(
          borderRadius: BorderRadius.circular(theme.cornerRadiusMd),
          color: isUnlocked
              ? _tierColor(widget.badge.tier).withOpacity(0.1)
              : theme.colorScheme.surfaceVariant,
          border: Border.all(
            color: isUnlocked
                ? _tierColor(widget.badge.tier)
                : theme.colorScheme.outline.withOpacity(0.3),
            width: isUnlocked ? 2 : 1,
          ),
          boxShadow: isUnlocked && widget.badge.tier >= 4
              ? [
                  BoxShadow(
                    color: _tierColor(widget.badge.tier).withOpacity(0.3),
                    blurRadius: 12 * _glowAnimation.value,
                    spreadRadius: 2,
                  ),
                ]
              : null,
        ),
        child: Stack(
          clipBehavior: Clip.none,
          children: [
            // 图标区域
            Center(
              child: isSecret
                  ? Icon(Icons.lock_outline, size: widget.size * 0.35,
                      color: theme.colorScheme.outline)
                  : isUnlocked
                      ? _buildBadgeIcon(context)
                      : _buildLockedIcon(context),
            ),

            // 进度条（未解锁时）
            if (!isUnlocked && !isSecret)
              Positioned(
                left: 8,
                right: 8,
                bottom: 6,
                child: _buildProgressBar(context),
              ),

            // 新解锁红点
            if (widget.badge.isNew)
              Positioned(
                top: -2,
                right: -2,
                child: Container(
                  width: 12,
                  height: 12,
                  decoration: BoxDecoration(
                    color: theme.colorScheme.error,

### 4.4 解锁弹窗队列播放器（AchievementPopupPlayer）

多个成就同时解锁时排队播放，**不打断答题等学习场景**：

```dart
/// 挂载在 App Shell 层，全局监听弹窗队列
class AchievementPopupPlayer extends ConsumerStatefulWidget {
  const AchievementPopupPlayer({super.key, required this.child});
  final Widget child;

  @override
  ConsumerState<AchievementPopupPlayer> createState() =>
      _AchievementPopupPlayerState();
}

class _AchievementPopupPlayerState
    extends ConsumerState<AchievementPopupPlayer> {
  bool _playing = false;

  @override
  Widget build(BuildContext context) {
    // 队列非空且当前可展示时依次播放
    ref.listen(achievementPopupQueueProvider, (prev, next) {
      if (next.isNotEmpty && !_playing && _canShowNow()) {
        _playNext(next.first);
      }
    });
    return widget.child;
  }

  /// 展示时机裁决（守卫 G2）
  bool _canShowNow() {
    final route = ModalRoute.of(context);
    final routeName = route?.settings.name ?? '';
    // 答题/考试/测评页面不弹，延迟到离开后再播
    const blockedRoutes = {
      '/quiz', '/exam', '/assessment', '/homework/do',
    };
    return !blockedRoutes.contains(routeName);
  }

  Future<void> _playNext(AchievementUnlockEvent event) async {
    setState(() => _playing = true);
    final overlay = Overlay.of(context);
    final entry = OverlayEntry(
      builder: (_) => UnlockCelebrationOverlay(event: event),
    );
    overlay.insert(entry);

    // 播放时长：幼儿 3.5s / 其他 2.5s（分龄主题引擎提供）
    final theme = ref.read(ageAppThemeProvider);
    await Future.delayed(Duration(milliseconds: theme.celebrationDurationMs));
    entry.remove();

    ref.read(achievementPopupQueueProvider.notifier).dequeue();
    setState(() => _playing = false);

    // 连续播放下一个
    final queue = ref.read(achievementPopupQueueProvider);
    if (queue.isNotEmpty && _canShowNow()) {
      _playNext(queue.first);
    }
  }
}
```

## 5. 状态流转

### 5.1 徽章状态机

```
LOCKED(未解锁) --进度达成/服务端 achievement.unlocked 事件--> UNLOCKED_NEW(已解锁未读)
UNLOCKED_NEW --用户打开详情(read API 成功)--> UNLOCKED_READ(已解锁已读)
```

| 状态 | 判定 | 展示 |
|------|------|------|
| LOCKED | `unlocked_at == null` | 灰化 + 进度条（隐藏成就除外） |
| UNLOCKED_NEW | `unlocked_at != null && is_new == true` | 正常 + 红点 |
| UNLOCKED_READ | `unlocked_at != null && is_new == false` | 正常 |

**守卫规则：**

| 编号 | 规则 |
|------|------|
| G1 | `is_new` 的唯一权威是服务端；客户端本地置已读后，服务端刷新返回 `is_new=false` 时以服务端为准（防止多端红点不一致） |
| G2 | 解锁弹窗不在答题/考试路由播放，进入阻塞路由时清空 `_playing` 并保留队列 |
| G3 | 同一 badgeId 的弹窗事件按 `event_id` 去重（SSE 重连补推场景），重复事件直接丢弃 |
| G4 | 打卡按钮本地置灰（防连点），以服务端 `check-in` 响应为最终状态；失败恢复可点击 |

### 5.2 打卡事件流

```
用户点击打卡
  → 本地按钮置灰（乐观）
  → POST /check-in（携带 Idempotency-Key = deviceId+date）
  → 成功：刷新 StreakInfo、触发奖励弹窗（bonus_exp/bonus_points/new_badges）
  → 失败（已打卡）：本地恢复按钮，Toast「今日已打卡」（不视为错误）
  → 失败（网络）：本地恢复按钮，Toast 弱网提示，不预置状态
```

## 6. 错误处理

| 错误码 | 场景 | 客户端处理 |
|--------|------|-----------|
| 080401 | 未登录/令牌过期 | 跳转登录页，登录成功后回跳成就页 |
| 080429 | 打卡/已读接口限流 | 静默重试一次（1s 后），仍失败放弃本次上报，下次进入页面时 `invalidate` 刷新 |
| 080404 | badge_id 不存在 | 视为数据过期，强制刷新徽章列表并移除本地缓存 |
| 网络超时 | API 无响应 | 展示缓存数据 + 顶部弱网条；打卡/已读等写操作失败不写入本地缓存（避免与服务端状态分叉） |
| Hive 损坏 | 本地缓存读写异常 | 捕获后删除缓存 box，回退为纯网络加载 |

**降级策略 D1-D4：**

| 编号 | 降级 |
|------|------|
| D1 | SSE 断连：成就弹窗退化为「进入成就页时拉取增量」（服务端支持 `since` 游标），不阻塞功能 |
| D2 | Lottie/动画资源缺失：降级为静态图标（`errorBuilder` 已内置） |
| D3 | 排行榜接口失败：隐藏排行榜入口，不影响徽章/等级展示 |
| D4 | 分享海报生成失败：隐藏分享按钮，不报错 |

## 8. 性能与边界

| 项 | 指标/策略 |
|----|----------|
| 首屏 | 缓存直出 <100ms；骨架屏兜底 |
| 网格 | 每分组懒构建（Sliver），>500 徽章不一次性构建全部卡片 |
| 动画 | 页面离屏暂停发光动画；低端机（`systemInfo.isLowEnd`）关闭阴影发光 |
| 缓存 | Hive 缓存写入放在微任务，不阻塞 UI；缓存 TTL 24h，下拉刷新强制拉取 |
| 多端 | 红点状态以服务端为准（G1）；多端同时解锁事件按 event_id 幂等 |
| 国际化 | 徽章名称/描述走 i18n 文案表（服务端下发 `name_i18n` 键），图标资源不翻译 |

## 9. 验收场景

1. 未解锁徽章显示灰色 + 正确进度比例；隐藏成就显示锁形，不泄露名称。
2. 解锁后红点出现，打开详情即消失，且重新进入页面红点不回弹（服务端同步）。
3. 连续解锁 3 个徽章，弹窗依次播放不重叠，答题页不播放、离开后自动续播。
4. SSE 断开 10 分钟后恢复，期间解锁的成就进入页面时以 `since` 增量补出。
5. 打卡成功 streak+1 并触发奖励；重复打卡返回「今日已打卡」不增加 streak。
6. 断网打开成就页展示缓存数据与弱网条；打卡失败本地状态回滚。
7. 铂金/钻石徽章发光动画在页面滑动离屏时停止。
8. 分享海报生成成功后调起系统分享；生成失败时按钮隐藏无报错。
9. 排行榜接口 500 时隐藏入口，其余模块正常。
10. 多端（两台设备）同时解锁同一徽章，仅弹一次窗。
