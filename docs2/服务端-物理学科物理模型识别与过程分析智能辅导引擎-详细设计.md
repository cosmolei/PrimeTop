# 服务端 - 物理学科物理模型识别与过程分析智能辅导引擎 详细设计

## 1. 概述

### 1.1 模块定位

物理学科智能辅导引擎是 PrimeTop 理科解题体系中最核心的学科专项引擎之一。与通用的"理科解题步骤推导"引擎不同，本引擎专注于物理学科独有的难点：**物理模型的识别与构建**、**物理过程的分阶段分析**、**受力分析/运动分析/能量分析的方法论引导**，以及**物理图像与数学工具的结合应用**。

引擎服务覆盖初中物理（力学、热学、声光、电学基础）和高中物理（运动学、动力学、能量动量、静电场、恒定电流、磁场、电磁感应、交变电流、热学、光学、原子物理、近代物理）全内容体系。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 物理模型识别 | 从自然语言描述中提取物理条件，匹配标准物理模型（斜面模型、弹簧模型、碰撞模型、电磁场模型等） |
| 受力分析引导 | 引导学生完成规范的受力分析，绘制受力示意图，识别隐含力与约束条件 |
| 物理过程分段 | 将复杂问题拆分为多个物理过程（如"先加速后匀速再减速"），对每段独立列方程 |
| 状态/过程方程 | 根据物理定律（牛顿定律、动量守恒、能量守恒、运动学公式等）建立方程 |
| 运动过程可视化 | 生成运动过程参数化数据（v-t图、a-t图、轨迹图），驱动客户端渲染 |
| 易错点诊断 | 识别学生常见迷思概念（如"力是运动的原因"），给出针对性纠正 |
| 分步推导 | 按物理逻辑链逐步推导，展示公式选择理由、变量代换过程和量纲检查 |
| 方法归纳 | 解题后总结通用方法（整体法/隔离法、能量法/动量法等）和适用条件 |

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 物理模型库 (physics_model_library)

```sql
CREATE TABLE physics_model_library (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    model_code      VARCHAR(64) NOT NULL UNIQUE COMMENT '模型编码，如 SLOPE_SLIDE_001',
    model_name      VARCHAR(128) NOT NULL COMMENT '模型名称，如 斜面滑块模型',
    model_category  VARCHAR(32) NOT NULL COMMENT '分类: MECHANICS / ELECTROMAGNETISM / OPTICS / THERMODYNAMICS / MODERN',
    model_subcategory VARCHAR(32) NOT NULL COMMENT '子分类: KINEMATICS / DYNAMICS / ENERGY / CIRCUIT / FIELD / INDUCTION',
    applicable_stage VARCHAR(16) NOT NULL COMMENT '适用学段: JUNIOR / SENIOR / BOTH',
    knowledge_point_ids JSON NOT NULL COMMENT '关联知识点ID列表',
    description     TEXT COMMENT '模型描述',
    typical_conditions JSON NOT NULL COMMENT '模型典型条件特征列表',
    key_equations   JSON NOT NULL COMMENT '核心方程列表',
    solution_methods JSON NOT NULL COMMENT '解题方法列表',
    common_pitfalls JSON NOT NULL COMMENT '常见陷阱列表',
    difficulty_level TINYINT DEFAULT 3 COMMENT '难度等级 1-5',
    status          VARCHAR(16) DEFAULT 'ACTIVE',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_category (model_category, model_subcategory),
    INDEX idx_stage (applicable_stage)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物理模型库';
```

#### 2.1.2 物理过程分析结果 (physics_process_analysis)

```sql
CREATE TABLE physics_process_analysis (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    analysis_session_id VARCHAR(64) NOT NULL COMMENT '分析会话ID',
    question_id     BIGINT COMMENT '关联题目ID（如有）',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    model_codes     JSON NOT NULL COMMENT '识别到的物理模型编码列表',
    process_segments JSON NOT NULL COMMENT '物理过程分段结果',
    force_diagrams  JSON COMMENT '受力分析图数据',
    motion_data     JSON COMMENT '运动过程参数化数据',
    energy_analysis JSON COMMENT '能量分析数据',
    equations       JSON NOT NULL COMMENT '建立的物理方程列表',
    solution_steps  JSON NOT NULL COMMENT '解题步骤',
    misconceptions  JSON COMMENT '检测到的迷思概念',
    method_summary  TEXT COMMENT '方法归纳',
    ai_model_used   VARCHAR(64) COMMENT '使用的AI模型',
    ai_token_cost   INT DEFAULT 0 COMMENT 'Token消耗',
    processing_time_ms INT COMMENT '处理耗时',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_session (analysis_session_id),
    INDEX idx_user (user_id),
    INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物理过程分析结果';
```

#### 2.1.3 物理模型典型条件 (physics_model_condition)

```sql
CREATE TABLE physics_model_condition (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    model_id        BIGINT NOT NULL COMMENT '关联物理模型ID',
    condition_type  VARCHAR(32) NOT NULL COMMENT '条件类型: KEYWORD / PATTERN / FORMULA / DIAGRAM',
    condition_pattern TEXT NOT NULL COMMENT '条件匹配模式（正则/关键词/语义向量）',
    condition_weight DECIMAL(3,2) DEFAULT 0.50 COMMENT '条件权重',
    description     VARCHAR(256) COMMENT '条件描述',
    FOREIGN KEY (model_id) REFERENCES physics_model_library(id),
    INDEX idx_model (model_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物理模型典型条件';
```

## 3. API 接口设计

### 3.1 接口总览

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 提交物理分析请求 | POST | `/api/v1/physics/analyze` | 提交物理题目/描述，启动分析 |
| 获取分析结果 | GET | `/api/v1/physics/analyze/{sessionId}` | 获取分析结果（支持轮询） |
| 分步获取推导 | GET | `/api/v1/physics/analyze/{sessionId}/steps` | 按步骤获取推导详情 |

#### 3.2.3 SSE 流式推送

```
GET /api/v1/physics/analyze/{sessionId}/stream
Accept: text/event-stream
```

**事件类型：**

| event | 说明 | data 示例 |
| --- | --- | --- |
| `model_identified` | 模型识别完成 | `{"primaryModel": {"code": "SLOPE_SLIDE_001", "name": "斜面滑块模型"}}` |
| `force_analysis` | 受力分析完成 | `{"forces": [...], "notes": [...]}` |
| `process_segment` | 单个过程段分析完成 | `{"segmentIndex": 0, "name": "匀加速下滑过程", ...}` |
| `equation_built` | 方程建立 | `{"equation": "mg·sinθ - μmg·cosθ = ma", "law": "牛顿第二定律"}` |
| `solving_step` | 单步求解 | `{"stepIndex": 3, "content": "解得：a = 5 - √3 ≈ 3.27 m/s²"}` |
| `pitfall_detected` | 检测到易错点 | `{"type": "FORCE_DIRECTION", "description": "..."}` |
| `summary` | 方法归纳 | `{"generalMethod": "斜面问题通用解法", ...}` |
| `completed` | 分析完成 | `{"sessionId": "...", "totalSteps": 8}` |
| `error` | 错误 | `{"code": "ANALYSIS_FAILED", "message": "..."}` |

/**
 * 基于关键词和模式的物理模型快速匹配
 */
public class PhysicsModelMatcher {
    
    // 模型条件匹配规则缓存
    private final Map<String, List<ModelCondition>> modelConditionCache;
    
    /**
     * 快速匹配候选模型
     * @param extractedConditions 从题目中提取的物理条件
     * @return 匹配度排序的候选模型列表
     */
    public List<ModelMatchResult> matchModels(ExtractedConditions conditions) {
        List<ModelMatchResult> candidates = new ArrayList<>();
        
        for (Map.Entry<String, List<ModelCondition>> entry : modelConditionCache.entrySet()) {
            String modelCode = entry.getKey();
            List<ModelCondition> modelConditions = entry.getValue();
            
            double totalWeight = 0;
            double matchedWeight = 0;
            
            for (ModelCondition cond : modelConditions) {
                totalWeight += cond.getWeight();
                if (isConditionMatched(cond, conditions)) {
                    matchedWeight += cond.getWeight();
                }
            }
            
            double confidence = totalWeight > 0 ? matchedWeight / totalWeight : 0;
            
            if (confidence >= 0.4) {  // 置信度阈值
                candidates.add(new ModelMatchResult(modelCode, confidence));
            }
        }
        
        candidates.sort(Comparator.comparingDouble(ModelMatchResult::getConfidence).reversed());
        return candidates.size() > 5 ? candidates.subList(0, 5) : candidates;
    }
    
    private boolean isConditionMatched(ModelCondition cond, ExtractedConditions conditions) {
        switch (cond.getType()) {
            case KEYWORD:
                return conditions.getKeywords().stream()
                    .anyMatch(kw -> cond.getPattern().toLowerCase().contains(kw.toLowerCase()));
            case PATTERN:
                return conditions.getRawText().matches(cond.getPattern());
            case FORMULA:
                return conditions.getFormulas().stream()
                    .anyMatch(f -> f.contains(cond.getPattern()));
            case DIAGRAM:
                return conditions.getDiagramFeatures() != null && 
                       conditions.getDiagramFeatures().contains(cond.getPattern());
            default:
                return false;
        }
    }
}

/**
 * 受力分析引擎 - 自动分析物体受力情况
 */
public class ForceAnalysisEngine {
    
    /**
     * 执行完整的受力分析
     */
    public ForceAnalysisResult analyze(PhysicsAnalysisContext context) {
        ForceAnalysisResult result = new ForceAnalysisResult();
        
        // 1. 确定研究对象
        List<PhysicalObject> objects = identifyObjects(context);
        result.setObjects(objects);
        
        // 2. 对每个研究对象进行受力分析
        for (PhysicalObject obj : objects) {
            List<Force> forces = new ArrayList<>();
            
            // 2.1 场力（一定存在或根据条件判断）
            forces.addAll(analyzeFieldForces(obj, context));    // 重力、电场力、磁场力
            
            // 2.2 接触力（根据接触面判断）
            forces.addAll(analyzeContactForces(obj, context)); // 支持力、摩擦力、弹力
            
            // 2.3 其他力（根据题目条件）
            forces.addAll(analyzeOtherForces(obj, context));   // 外力、绳的拉力等
            
            // 2.4 力的分解（如需要）
            if (needsDecomposition(forces, context)) {
                Map<String, List<ForceComponent>> decomposition = decomposeForces(
                    forces, context.getCoordinateSystem()
                );
                result.addDecomposition(obj.getId(), decomposition);
            }
            
            result.addForces(obj.getId(), forces);
        }
        
        // 3. 生成受力分析注意事项
        result.setNotes(generateForceAnalysisNotes(forces, context));
        
        // 4. 生成受力示意图数据
        result.setDiagramData(generateDiagramData(result));
        
        return result;
    }
    
    /**
     * 分析接触力 - 这是最容易遗漏的部分
     */
    private List<Force> analyzeContactForces(PhysicalObject obj, PhysicsAnalysisContext context) {
        List<Force> forces = new ArrayList<>();
        
        // 检查接触面
        for (ContactSurface surface : context.getContactSurfaces()) {
            // 支持力/正压力 - 方向垂直于接触面，指向物体
            if (surface.hasNormalSupport()) {
                Force normalForce = Force.builder()
                    .name("支持力")
                    .symbol("N")
                    .direction(surface.getNormalDirection())
                    .source(surface.getSupportObject())
                    .type(ForceType.NORMAL)
                    .build();
                forces.add(normalForce);
            }
            
            // 摩擦力 - 需要判断是静摩擦还是滑动摩擦
            if (surface.hasFriction()) {
                Force frictionForce = determineFrictionForce(obj, surface, context);
                forces.add(frictionForce);
            }
            
            // 弹力（弹簧/绳索）
            if (surface.hasSpring()) {
                Force springForce = determineSpringForce(surface);
                forces.add(springForce);
            }
        }
        
        return forces;
    }
    
    /**
     * 判断摩擦力类型并计算
     */
    private Force determineFrictionForce(PhysicalObject obj, ContactSurface surface, 
                                         PhysicsAnalysisContext context) {
        // 判断物体相对运动状态
        if (context.isStatic()) {
            // 静摩擦力 - 大小由平衡条件或牛顿第二定律决定，方向与相对运动趋势相反
            return Force.builder()
                .name("静摩擦力")
                .symbol("f静")
                .magnitude("由方程决定（≤ f_max = μN）")
                .direction(oppositeToMotionTendency(obj, surface))
                .type(ForceType.STATIC_FRICTION)
                .note("静摩擦力是被动力，大小需要通过方程求解，不能直接用 f = μN")
                .build();
        } else {
            // 滑动摩擦力 - 大小 f = μN，方向与相对运动方向相反
            return Force.builder()
                .name("滑动摩擦力")
                .symbol("f")
                .magnitude("f = μN")
                .direction(oppositeToRelativeMotion(obj, surface))
                .type(ForceType.KINETIC_FRICTION)
                .note("滑动摩擦力大小恒为 f = μN，方向始终与相对运动方向相反")
                .build();
        }
    }
}

            }
            
            // 检查能量守恒
            EnergyValidator.validate(current.getFinalState(), next.getInitialState());
        }
    }

/**
 * 物理方程建立器
 * 根据物理模型和过程段，自动建立物理方程
 */
public class PhysicsEquationBuilder {
    
    /**
     * 为单个过程段建立方程
     */
    public List<PhysicsEquation> buildEquations(
            ProcessSegment segment, 
            ForceAnalysisResult forceAnalysis,
            PhysicsAnalysisContext context) {
        
        List<PhysicsEquation> equations = new ArrayList<>();
        String processType = segment.getProcessType();
        
        switch (processType) {
            case "UNIFORM_ACCELERATION":
                equations.addAll(buildNewtonEquations(segment, forceAnalysis));
                equations.addAll(buildKinematicsEquations(segment));
                break;
                
            case "IMPACT":
                equations.addAll(buildMomentumEquations(segment));
                equations.addAll(buildEnergyEquations(segment));
                break;
                
            case "CIRCULAR":
                equations.addAll(buildCircularMotionEquations(segment, forceAnalysis));
                break;
                
            case "HARMONIC":
                equations.addAll(buildSHMEquations(segment));
                break;
                
            case "CIRCUIT":
                equations.addAll(buildCircuitEquations(segment));
                break;
                
            case "INDUCTION":
                equations.addAll(buildElectromagneticInductionEquations(segment));
                break;
                
            default:
                equations.addAll(buildGeneralEquations(segment, forceAnalysis));
        }
        
        return equations;
    }
    
    /**
     * 建立牛顿第二定律方程
     */
    private List<PhysicsEquation> buildNewtonEquations(
            ProcessSegment segment, ForceAnalysisResult forceAnalysis) {
        List<PhysicsEquation> equations = new ArrayList<>();
        
        // F合 = ma  →  沿运动方向建立方程
        StringBuilder equation = new StringBuilder();
        equation.append("合外力：");
        
        List<Force> forces = forceAnalysis.getForcesForObject(segment.getObjectId());
        boolean first = true;
        
        for (Force f : forces) {
            String component = forceAnalysis.getForceComponentAlongMotion(f);
            if (component != null) {
                if (!first && !component.startsWith("-")) {
                    equation.append(" + ");
                } else if (!first && component.startsWith("-")) {
                    equation.append(" ");
                }
                equation.append(component);
                first = false;
            }
        }
        equation.append(" = ").append(segment.getMass()).append("a");
        
        equations.add(PhysicsEquation.builder()
            .equation(equation.toString())
            .law("牛顿第二定律")
            .explanation("沿运动方向（x轴）的合外力等于质量乘以加速度")
            .build());
        
        // 垂直运动方向平衡方程
        if (hasPerpendicularForces(forces)) {
            equations.add(PhysicsEquation.builder()
                .equation(buildPerpendicularBalanceEquation(forces))
                .law("平衡条件（垂直运动方向）")
                .explanation("垂直于运动方向的合外力为零")
                .build());
        }
        
        return equations;
    }
    
    /**
     * 建立运动学方程
     */
    private List<PhysicsEquation> buildKinematicsEquations(ProcessSegment segment) {
        List<PhysicsEquation> equations = new ArrayList<>();
        
        Map<String, String> vars = segment.getKeyVariables();
        
        // 根据已知/未知量选择最优运动学公式
        // 四大基本公式：
        // 1. v = v₀ + at        （知a,t求v）
        // 2. x = v₀t + ½at²     （知a,t求x）
        // 3. v² - v₀² = 2ax     （知a,x求v，不含时间）
        // 4. x = ½(v₀ + v)t     （知v,t求x，不含加速度）
        
        boolean hasTime = segment.hasKnownVariable("t");
        boolean hasAccel = segment.hasKnownVariable("a") || 
                          segment.canDeriveAcceleration();
        boolean solveForVelocity = segment.isSolvingFor("v");
        boolean solveForDisplacement = segment.isSolvingFor("x");
        
        if (solveForVelocity && !hasTime && hasAccel) {
            // 选用 v² - v₀² = 2ax
            equations.add(PhysicsEquation.builder()
                .equation("v² - v₀² = 2ax")
                .law("匀变速直线运动速度-位移公式")
                .explanation("已知加速度和位移求末速度，无需知道时间")
                .build());
        } else if (solveForVelocity && hasTime) {
            // 选用 v = v₀ + at
            equations.add(PhysicsEquation.builder()
                .equation("v = v₀ + at")
                .law("匀变速直线运动速度公式")
                .build());
        }
        
        return equations;
    }
}

### 5.1 分析会话状态机

```
                    ┌────────────┐
     POST /analyze  │            │
    ──────────────▶ │  PENDING   │
                    │            │
                    └─────┬──────┘
                          │ 开始处理
                    ┌─────▼──────┐
                    │            │
                    │ PROCESSING │──── AI超时/错误 ────┐
                    │            │                     │
                    └─────┬──────┘                     │
                          │                            │
              ┌───────────┼───────────┐                │
              │           │           │                │
        ┌─────▼──┐  ┌────▼────┐ ┌────▼─────┐    ┌────▼────┐
        │MODEL_  │  │FORCE_   │ │EQUATION_ │    │ FAILED  │
        │IDENTIFY│  │ANALYSIS │ │SOLVING   │    │         │
        └─────┬──┘  └────┬────┘ └────┬─────┘    └─────────┘
              │          │           │
              └───────────┼───────────┘
                          │ 全部完成
                    ┌─────▼──────┐
                    │            │
                    │ COMPLETED  │
                    │            │
                    └─────┬──────┘
                          │ 超过TTL(2h)
                    ┌─────▼──────┐
                    │            │
                    │  EXPIRED   │
                    │            │
                    └────────────┘
```

**状态定义：**

| 状态 | 说明 | 允许的操作 |
| --- | --- | --- |
| `PENDING` | 请求已接收，等待处理 | 取消 |
| `PROCESSING` | 正在分析中（含子状态 MODEL_IDENTIFY / FORCE_ANALYSIS / EQUATION_SOLVING） | 查询进度、SSE订阅 |
| `COMPLETED` | 分析完成 | 获取结果、重新分析、提交诊断 |
| `FAILED` | 分析失败 | 重试、查看错误 |
| `EXPIRED` | 会话过期（TTL 2小时） | 重新发起 |

/**
 * 物理学科智能辅导引擎 - 主入口
 */
@Service
@Slf4j
public class PhysicsTutoringEngine {
    
    @Autowired private InputPreprocessor inputPreprocessor;
    @Autowired private PhysicsModelMatcher modelMatcher;
    @Autowired private AIModelIdentifier aiModelIdentifier;
    @Autowired private ForceAnalysisEngine forceAnalysisEngine;
    @Autowired private PhysicsProcessSegmenter processSegmenter;
    @Autowired private PhysicsEquationBuilder equationBuilder;
    @Autowired private DimensionalChecker dimensionalChecker;
    @Autowired private PitfallDetector pitfallDetector;
    @Autowired private MethodSummarizer methodSummarizer;
    @Autowired private PhysicsAnalysisResultRepository resultRepository;
    @Autowired private RedisTemplate<String, Object> redisTemplate;
    @Autowired private AIModelClient aiModelClient;
    @Autowired private KnowledgePointService knowledgePointService;
    
    private static final long SESSION_TTL_HOURS = 2;
    private static final int MAX_PROCESSING_TIME_MS = 30000;
    
    /**
     * 执行物理分析（异步）
     */
    @Async("physicsAnalysisExecutor")
    public void executeAnalysis(String sessionId, PhysicsAnalysisRequest request) {
        long startTime = System.currentTimeMillis();
        String streamChannel = "phy:stream:" + sessionId;
        
        try {
            // 更新状态
            updateSessionStatus(sessionId, "PROCESSING", "MODEL_IDENTIFY");
            
            // 1. 输入预处理
            PhysicsAnalysisContext context = inputPreprocessor.preprocess(request);
            
            // 2. 物理模型识别
            // 2.1 规则快速匹配
            List<ModelMatchResult> candidates = modelMatcher.matchModels(context.getConditions());
            
            // 2.2 AI深度识别
            ModelIdentificationResult modelResult;
            if (candidates.isEmpty() || candidates.get(0).getConfidence() < 0.7) {
                modelResult = aiModelIdentifier.identifyWithAI(
                    context.getRawText(), context.getConditions(), candidates);
            } else {
                modelResult = ModelIdentificationResult.fromRuleMatch(candidates.get(0));
            }
            
            context.setIdentifiedModels(modelResult);
            
            // 推送模型识别结果
            publishStreamEvent(streamChannel, "model_identified", modelResult);
            
            // 更新进度
            updateSessionStatus(sessionId, "PROCESSING", "FORCE_ANALYSIS");
            
            // 3. 受力分析（仅力学类问题）
            ForceAnalysisResult forceAnalysis = null;
            if (isMechanicsProblem(modelResult)) {
                forceAnalysis = forceAnalysisEngine.analyze(context);
                publishStreamEvent(streamChannel, "force_analysis", forceAnalysis);
            }
            
            // 4. 物理过程分段
            updateSessionStatus(sessionId, "PROCESSING", "PROCESS_SEGMENTATION");
            ProcessSegmentationResult segments = processSegmenter.segment(context);
            context.setProcessSegments(segments);
            
            // 5. 逐段建立方程并求解
            updateSessionStatus(sessionId, "PROCESSING", "EQUATION_SOLVING");
            
            List<PhysicsEquation> allEquations = new ArrayList<>();
            List<SolvingStep> allSteps = new ArrayList<>();
            
            for (ProcessSegment segment : segments.getSegments()) {
                publishStreamEvent(streamChannel, "process_segment", segment);
                
                List<PhysicsEquation> segmentEquations = equationBuilder.buildEquations(
                    segment, forceAnalysis, context);
                
                for (PhysicsEquation eq : segmentEquations) {
                    // 量纲检查
                    DimensionalCheckResult dimCheck = dimensionalChecker.checkEquation(eq);
                    eq.setDimensionalCheck(dimCheck);
                    
                    publishStreamEvent(streamChannel, "equation_built", eq);
                    allEquations.add(eq);
                }
                
                // 求解方程组
                List<SolvingStep> segmentSteps = solveEquations(segmentEquations, segment, context);
                for (SolvingStep step : segmentSteps) {
                    publishStreamEvent(streamChannel, "solving_step", step);
                    allSteps.add(step);
                }
            }
            
            // 6. 量纲与合理性检查
            if (context.getFinalAnswer() != null) {
                RationalityCheck rationalityCheck = dimensionalChecker.checkRationality(
                    context.getPhysicalQuantity(),
                    context.getFinalAnswer().getNumericValue(),
                    context.getFinalAnswer().getUnit()
                );
                context.setRationalityCheck(rationalityCheck);
            }
            
            // 7. 易错点检测
            List<PhysicsPitfall> pitfalls = pitfallDetector.detect(context, modelResult);
            for (PhysicsPitfall p : pitfalls) {
                publishStreamEvent(streamChannel, "pitfall_detected", p);
            }
            
            // 8. 方法归纳
            MethodSummary summary = methodSummarizer.summarize(modelResult, segments, allEquations);
            publishStreamEvent(streamChannel, "summary", summary);
            
            // 9. 组装最终结果
            PhysicsProcessAnalysis result = PhysicsProcessAnalysis.builder()
                .analysisSessionId(sessionId)
                .userId(request.getUserId())
                .modelCodes(modelResult.getAllModelCodes())
                .processSegments(segments.toJson())
                .forceDiagrams(forceAnalysis != null ? forceAnalysis.toJson() : null)
                .equations(JSONUtil.toJsonStr(allEquations))
                .solutionSteps(JSONUtil.toJsonStr(allSteps))
                .misconceptions(JSONUtil.toJsonStr(pitfalls))
                .methodSummary(summary.toJson())
                .aiModelUsed(context.getAiModelUsed())
                .aiTokenCost(context.getTotalTokenCost())
                .processingTimeMs((int) (System.currentTimeMillis() - startTime))
                .build();
            
            resultRepository.save(result);
            
            // 缓存结果
            redisTemplate.opsForValue().set(
                "phy:result:" + sessionId, result, 
                SESSION_TTL_HOURS, TimeUnit.HOURS
            );
            
            // 更新状态
            updateSessionStatus(sessionId, "COMPLETED", null);
            publishStreamEvent(streamChannel, "completed", 
                Map.of("sessionId", sessionId, "totalSteps", allSteps.size()));
            
            // 更新知识点掌握度（异步）
            knowledgePointService.updateMasteryAsync(
                request.getUserId(), 
                modelResult.getKnowledgePointIds(),
                request.getConversationId()
            );
            
        } catch (AITimeoutException e) {
            log.error("AI model timeout for session {}", sessionId, e);
            updateSessionStatus(sessionId, "FAILED", "AI_MODEL_TIMEOUT");
            publishStreamEvent(streamChannel, "error", 
                Map.of("code", "PHY_AI_MODEL_TIMEOUT", "message", "AI模型分析超时，请稍后重试"));
            
        } catch (AnalysisTooComplexException e) {
            log.warn("Analysis too complex for session {}: {}", sessionId, e.getMessage());
            updateSessionStatus(sessionId, "FAILED", "TOO_COMPLEX");
            publishStreamEvent(streamChannel, "error",
                Map.of("code", "PHY_ANALYSIS_TOO_COMPLEX", 
                       "message", "该问题复杂度较高，建议拆分为多个小问题分别提问"));
            
        } catch (Exception e) {
            log.error("Unexpected error for session {}", sessionId, e);
            updateSessionStatus(sessionId, "FAILED", "INTERNAL_ERROR");
            publishStreamEvent(streamChannel, "error",
                Map.of("code", "INTERNAL_ERROR", "message", "分析过程中出现异常"));
        }
    }
    
    /**
     * 求解方程组 - 符号推导 + 数值计算
     */
    private List<SolvingStep> solveEquations(
            List<PhysicsEquation> equations, 
            ProcessSegment segment,
            PhysicsAnalysisContext context) {
        
        List<SolvingStep> steps = new ArrayList<>();
        
        // 构建AI求解提示词
        String solvePrompt = buildSolvePrompt(equations, segment, context);
        
        AIResponse response = aiModelClient.call(
            AIModelRequest.builder()
                .model(ModelTier.REASONING)
                .prompt(solvePrompt)
                .temperature(0.0)
                .maxTokens(2000)
                .build()
        );
        
        // 解析求解步骤
        steps.addAll(parseSolvingSteps(response.getContent()));
        
        return steps;
    }
    
    private String buildSolvePrompt(
            List<PhysicsEquation> equations, 
            ProcessSegment segment,
            PhysicsAnalysisContext context) {
        
        return String.format("""
            请逐步求解以下物理方程组。
            
            ## 物理过程
            %s
            
            ## 方程组
            %s
            
            ## 已知量
            %s
            
            ## 要求
            1. 每步只做一个操作（代入/化简/求解）
            2. 说明每步使用的数学方法
            3. 最终给出数值结果（保留2位小数）
            4. 如果中间有近似，标注清楚
            
            ## 输出格式（JSON数组）
            [
              {"stepIndex": 0, "operation": "代入数据", "content": "...", "result": "..."},
              {"stepIndex": 1, "operation": "化简", "content": "...", "result": "..."}
            ]
            """,
            segment.getName() + ": " + segment.getDescription(),
            equations.stream().map(PhysicsEquation::getEquation).collect(Collectors.joining("\n")),
            formatKnownVariables(segment.getKeyVariables())
        );
    }
}

    /**
     * 提取物理量 - 使用正则和语义匹配
     */
    private Map<String, PhysicalQuantity> extractPhysicalQuantities(String text) {
        Map<String, PhysicalQuantity> quantities = new LinkedHashMap<>();
        
        // 物理量提取正则模式
        List<Pattern> patterns = List.of(
            // "质量为m=2kg" / "质量m=2kg" / "m = 2kg"
            Pattern.compile("(质量|m|M)\\s*[=为是]\\s*(\\d+\\.?\\d*)\\s*(kg|千克)"),
            // "速度v=5m/s"
            Pattern.compile("(速度|v)\\s*[=为是]\\s*(\\d+\\.?\\d*)\\s*(m/s|米/秒|米每秒)"),
            // "角度θ=30°" / "倾角30°"
            Pattern.compile("(角度|倾角|θ|theta)\\s*[=为是]?(\\d+\\.?\\d*)\\s*(°|度)"),
            // "动摩擦因数μ=0.2"
            Pattern.compile("(动摩擦因数|摩擦系数|μ|mu)\\s*[=为是]\\s*(\\d+\\.?\\d*)"),
            // "距离/长度L=5m"
            Pattern.compile("(距离|长度|位移|L|l|s|d)\\s*[=为是]\\s*(\\d+\\.?\\d*)\\s*(m|米)"),
            // "时间t=3s"
            Pattern.compile("(时间|t|T)\\s*[=为是]\\s*(\\d+\\.?\\d*)\\s*(s|秒)"),
            // "电荷量q=1.6×10⁻¹⁹C"
            Pattern.compile("(电荷量?|电量|q|Q)\\s*[=为是]\\s*(\\d+\\.?\\d*[×x]?\\d*\\^?[\\d-]*)\\s*(C|库仑)"),
            // "电阻R=10Ω"
            Pattern.compile("(电阻|R)\\s*[=为是]\\s*(\\d+\\.?\\d*)\\s*(Ω|欧姆|欧)"),
            // "电压U=6V"
            Pattern.compile("(电压|电势差|U)\\s*[=为是]\\s*(\\d+\\.?\\d*)\\s*(V|伏特|伏)"),
            // "磁感应强度B=0.5T"
            Pattern.compile("(磁感应强度|磁场强度|B)\\s*[=为是]\\s*(\\d+\\.?\\d*)\\s*(T|特斯拉)")
        );
        
        for (Pattern p : patterns) {
            Matcher m = p.matcher(text);
            while (m.find()) {
                String name = m.group(1);
                String value = m.group(2);
                String unit = m.group(3);
                quantities.put(name, new PhysicalQuantity(name, value, unit));
            }
        }
        
        return quantities;
    }

/**
 * 物理易错点检测器
 * 基于规则和AI双重检测学生常见错误
 */
@Service
public class PhysicsPitfallDetector {
    
    // 物理学科常见迷思概念规则库
    private final List<PitfallRule> pitfallRules;
    
    @PostConstruct
    public void init() {
        pitfallRules = loadPitfallRules();
    }
    
    public List<PhysicsPitfall> detect(
            PhysicsAnalysisContext context, 
            ModelIdentificationResult modelResult) {
        
        List<PhysicsPitfall> pitfalls = new ArrayList<>();
        
        // 1. 基于模型类型检测特定易错点
        for (String modelCode : modelResult.getAllModelCodes()) {
            pitfalls.addAll(detectByModel(modelCode, context));
        }
        
        // 2. 基于物理类别检测通用易错点
        pitfalls.addAll(detectByCategory(context.getPhysicsCategory(), context));
        
        // 3. 受力分析常见错误
        if (context.getForceAnalysis() != null) {
            pitfalls.addAll(detectForceAnalysisErrors(context));
        }
        
        // 4. 单位与量纲常见错误
        pitfalls.addAll(detectUnitErrors(context));
        
        return pitfalls.stream()
            .distinct()
            .sorted(Comparator.comparing(PhysicsPitfall::getSeverity).reversed())
            .collect(Collectors.toList());
    }
    
    private List<PhysicsPitfall> detectByModel(String modelCode, PhysicsAnalysisContext context) {
        List<PhysicsPitfall> result = new ArrayList<>();
        
        switch (modelCode) {
            case "SLOPE_SLIDE_001":
                result.add(PhysicsPitfall.builder()
                    .type("FORCE_DECOMPOSITION")
                    .description("忘记分解重力")
                    .correctApproach("斜面问题中，重力必须沿斜面方向和垂直斜面方向分解")
                    .severity("CRITICAL")
                    .build());
                result.add(PhysicsPitfall.builder()
                    .type("FRICTION_DIRECTION")
                    .description("摩擦力方向判断错误")
                    .correctApproach("滑动摩擦力方向与相对运动方向相反。物体下滑时摩擦力沿斜面向上")
                    .severity("HIGH")
                    .build());
                result.add(PhysicsPitfall.builder()
                    .type("NORMAL_FORCE")
                    .description("支持力不等于重力")
                    .correctApproach("斜面上的支持力 N = mg·cosθ，不等于重力 mg")
                    .severity("HIGH")
                    .build());
                break;
                
            case "PROJECTILE_MOTION_001":
                result.add(PhysicsPitfall.builder()
                    .type("DECOMPOSITION")
                    .description("平抛运动需要分解为水平和竖直两个分运动")
                    .correctApproach("水平方向：匀速直线运动 v_x = v₀；竖直方向：自由落体 v_y = gt")
                    .severity("CRITICAL")
                    .build());
                result.add(PhysicsPitfall.builder()
                    .type("TIME_SYNC")
                    .description("两个分运动的时间必须相等")
                    .correctApproach("水平飞行时间和竖直下落时间是同一个t，是连接两个分运动的桥梁")
                    .severity("HIGH")
                    .build());
                break;
                
            case "COLLISION_001":
                result.add(PhysicsPitfall.builder()
                    .type("MOMENTUM_DIRECTION")
                    .description("动量是矢量，需要规定正方向")
                    .correctApproach("使用动量守恒前，必须先规定正方向，注意代入正负号")
                    .severity("CRITICAL")
                    .build());
                result.add(PhysicsPitfall.builder()
                    .type("ENERGY_MOMENTUM_CONFUSION")
                    .description("弹性碰撞和非弹性碰撞适用不同守恒律")
                    .correctApproach("弹性碰撞：动量守恒+动能守恒；非弹性碰撞：只有动量守恒，动能不守恒")
                    .severity("HIGH")
                    .build());
                break;
                
            case "EM_INDUCTION_001":
                result.add(PhysicsPitfall.builder()
                    .type("LENS_LAW")
                    .description("楞次定律判断方向时容易出错")
                    .correctApproach('"增反减同"：磁通量增加时感应电流方向与原方向相反，减小时相同')
                    .severity("HIGH")
                    .build());

```java
/**
 * 物理分析并发优化 - 多过程段并行分析
 */
@Service
public class ParallelProcessAnalyzer {
    
    @Autowired
    @Qualifier("physicsAnalysisExecutor") 
    private ThreadPoolTaskExecutor executor;
    
    /**
     * 并行分析多个过程段（段间无依赖时）
     */
    public CompletableFuture<List<SegmentAnalysisResult>> analyzeSegmentsParallel(
            List<ProcessSegment> segments, 
            PhysicsAnalysisContext context) {
        
        // 检查段间依赖关系
        DependencyGraph dependencyGraph = buildDependencyGraph(segments);
        List<List<ProcessSegment>> parallelGroups = dependencyGraph.getParallelGroups();
        
        List<CompletableFuture<List<SegmentAnalysisResult>>> futures = new ArrayList<>();
        
        for (List<ProcessSegment> group : parallelGroups) {
            // 同组内的段可以并行分析
            List<CompletableFuture<SegmentAnalysisResult>> groupFutures = group.stream()
                .map(segment -> CompletableFuture.supplyAsync(
                    () -> analyzeSegment(segment, context), executor))
                .collect(Collectors.toList());
            
            futures.add(CompletableFuture.allOf(
                groupFutures.toArray(new CompletableFuture[0])
            ).thenApply(v -> groupFutures.stream()
                .map(CompletableFuture::join)
                .collect(Collectors.toList())
            ));
        }
        
        // 串联各组结果
        return futures.stream()
            .reduce(CompletableFuture.completedFuture(new ArrayList<>()),
                (acc, future) -> acc.thenCombine(future, (list1, list2) -> {
                    list1.addAll(list2);
                    return list1;
                }));
    }
}
```
