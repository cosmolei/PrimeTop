# 客户端-每日任务与学习打卡页面架构与交互设计

## 1. 模块概述

### 1.1 功能定位

每日任务与学习打卡是用户学习工作台的核心延伸页面，承担以下职责：

1. **任务聚合**：将学习规划、复习计划、系统推荐等任务统一展示为当日待办清单
2. **打卡激励**：通过每日签到、连续天数、任务完成等机制形成学习习惯
3. **进度可视化**：直观展示当日/本周学习进展，驱动完成动机
4. **奖励反馈**：完成任务后即时给予积分、经验、徽章等正向激励

### 1.2 目标用户与分龄策略

| 学段 | 页面策略 | 打卡重点 |
|------|----------|----------|
| 幼儿 | 大图标、暖色调、星星奖励、家长陪伴提示 | 趣味签到、每日识字 |
| 小学 | 任务卡片化、进度条、卡通勋章 | 每日任务、连续打卡 |
| 初中 | 列表式、效率优先、数据驱动 | 作业辅导、错题复习 |
| 高中 | 紧凑布局、倒计时、冲刺氛围 | 考点复习、专题训练 |

### 1.3 页面入口

| 入口位置 | 触发方式 | 说明 |
|----------|----------|------|
| 首页 → 今日任务卡片 | 点击「查看全部」 | 首页展示今日任务摘要卡片 |
| 底部导航 → 学习 | Tab 切换 | 部分学段作为二级 Tab |
| 侧边栏 / 抽屉 | 快捷入口 | 全局可达 |
| 推送通知 | 深链接直达 | 学习提醒推送跳转 |
| 桌面小组件 | DeepLink | 今日任务 Widget 点击进入 |

## 3. 数据模型

### 3.1 服务端数据结构

#### 3.1.1 每日任务快照 (daily_task_snapshot)

```sql
CREATE TABLE daily_task_snapshot (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    snapshot_date   DATE NOT NULL COMMENT '快照日期',
    status          ENUM('active','completed','expired','skipped') 
                    NOT NULL DEFAULT 'active' COMMENT '快照状态',
    completion_rate DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT '完成率 0-100',
    total_tasks     INT NOT NULL DEFAULT 0 COMMENT '总任务数',
    completed_tasks INT NOT NULL DEFAULT 0 COMMENT '已完成数',
    earned_points   INT NOT NULL DEFAULT 0 COMMENT '已获积分',
    earned_exp      INT NOT NULL DEFAULT 0 COMMENT '已获经验',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_user_date (user_id, snapshot_date),
    INDEX idx_user_status (user_id, status),
    INDEX idx_date (snapshot_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='每日任务快照';
```

#### 3.1.2 任务项 (daily_task_item)

```sql
CREATE TABLE daily_task_item (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    snapshot_id     BIGINT NOT NULL COMMENT '关联快照ID',
    user_id         BIGINT NOT NULL COMMENT '用户ID(冗余)',
    task_type       ENUM(
        'ai_tutor',          -- AI辅导
        'photo_question',    -- 拍题答疑
        'mistake_review',    -- 错题复习
        'sync_chapter',      -- 同步课堂
        'exercise',          -- 练习测评
        '背诵检测',           -- 背诵
        'english_daily',     -- 英语每日
        'essay',             -- 作文
        'custom'             -- 自定义
    ) NOT NULL COMMENT '任务类型',
    priority        ENUM('required','recommended','challenge') 
                    NOT NULL DEFAULT 'recommended' COMMENT '优先级',
    title           VARCHAR(200) NOT NULL COMMENT '任务标题',
    subtitle        VARCHAR(500) DEFAULT NULL COMMENT '任务描述',
    source_type     ENUM('plan','system','review','custom') 
                    NOT NULL COMMENT '来源类型',
    source_id       BIGINT DEFAULT NULL COMMENT '来源ID(计划ID/复习ID等)',
    target_route    VARCHAR(200) DEFAULT NULL COMMENT '完成跳转路由',
    target_params   JSON DEFAULT NULL COMMENT '跳转参数',
    status          ENUM('pending','in_progress','completed','skipped','expired')
                    NOT NULL DEFAULT 'pending' COMMENT '任务状态',
    sort_order      INT NOT NULL DEFAULT 0 COMMENT '排序权重',
    points_reward   INT NOT NULL DEFAULT 0 COMMENT '完成奖励积分',
    exp_reward      INT NOT NULL DEFAULT 0 COMMENT '完成奖励经验',
    completed_at    DATETIME DEFAULT NULL COMMENT '完成时间',
    expired_at      DATETIME DEFAULT NULL COMMENT '过期时间',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_snapshot (snapshot_id),
    INDEX idx_user_date (user_id, created_at),
    INDEX idx_status (snapshot_id, status),
    CONSTRAINT fk_item_snapshot FOREIGN KEY (snapshot_id) 
        REFERENCES daily_task_snapshot(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='每日任务项';
```

### 4.7 任务生成（服务端内部接口）

```
POST /api/v1/daily-tasks/generate
```

**触发条件：**
- 每日凌晨定时任务 (Celery Beat)
- 用户首次打开 APP 检测到无当日快照
- 学习计划变更后重新生成

**请求体：**

```json
{
  "user_id": 10001,
  "date": "2026-05-29",
  "regenerate": false
}
```

**生成逻辑伪代码：**

```python
async def generate_daily_tasks(user_id: int, date: date, regenerate: bool = False):
    """
    每日任务生成引擎
    
    规则：
    1. 从学习计划中提取当日任务 → required
    2. 从错题复习队列中提取到期项 → required
    3. 从遗忘曲线中提取到期复习 → required
    4. 从同步课堂进度推断推荐内容 → recommended
    5. 从学科薄弱点生成挑战任务 → challenge
    6. 按优先级和学段适配排序
    """
    # 检查是否已存在
    existing = await get_snapshot(user_id, date)
    if existing and not regenerate:
        return existing
    
    tasks: list[TaskItem] = []
    
    # 1. 学习计划任务 (required)
    plan_tasks = await get_plan_tasks_for_date(user_id, date)
    for pt in plan_tasks:
        tasks.append(TaskItem(
            task_type=pt.task_type,
            priority='required',
            title=pt.title,
            source_type='plan',
            source_id=pt.plan_id,
            target_route=pt.target_route,
            points_reward=15,
            exp_reward=20,
        ))
    
    # 2. 错题复习 (required)
    due_mistakes = await get_due_mistakes(user_id, date, limit=5)
    if due_mistakes:
        subject_counts = group_by_subject(due_mistakes)
        for subject, count in subject_counts.items():
            tasks.append(TaskItem(
                task_type='mistake_review',
                priority='required',
                title=f'错题复习 - {subject.name}',
                subtitle=f'{count}道错题待复习',
                source_type='review',
                target_route='/mistake/review',
                target_params={'subject': subject.code, 'count': count},
                points_reward=15 * min(count, 3),
                exp_reward=20,
            ))
    
    # 3. 遗忘曲线复习 (required)
    due_reviews = await get_due_spaced_repetition(user_id, date, limit=3)
    if due_reviews:
        tasks.append(TaskItem(
            task_type='exercise',
            priority='required',
            title='间隔复习',
            subtitle=f'{len(due_reviews)}个知识点待复习',
            source_type='review',
            target_route='/exercise/review',
            target_params={'ids': [r.id for r in due_reviews]},
            points_reward=10,
            exp_reward=15,
        ))
    
    # 4. 同步课堂推荐 (recommended)
    sync_chapter = await get_current_chapter(user_id)
    if sync_chapter:
        tasks.append(TaskItem(
            task_type='sync_chapter',
            priority='recommended',
            title=f'同步学习 - {sync_chapter.name}',
            subtitle='预习/复习当前章节',
            source_type='system',
            target_route='/sync/chapter',
            target_params={'chapter_id': sync_chapter.id},
            points_reward=10,
            exp_reward=15,
        ))
    
    # 5. 英语每日任务 (recommended, 仅英语学科用户)
    if has_subject(user_id, 'english'):
        tasks.append(TaskItem(
            task_type='english_daily',
            priority='recommended',
            title='英语每日打卡',
            subtitle='今日单词 + 听力练习',
            source_type='system',
            target_route='/english/daily',
            points_reward=10,
            exp_reward=15,
        ))
    
    # 6. 学科挑战 (challenge, 基于薄弱点)
    weak_points = await get_weak_knowledge_points(user_id, limit=2)
    for wp in weak_points:
        tasks.append(TaskItem(
            task_type='exercise',
            priority='challenge',
            title=f'薄弱点挑战 - {wp.name}',
            subtitle=f'正确率{wp.accuracy_rate:.0f}%，需要加强',
            source_type='system',
            target_route='/exercise/practice',
            target_params={'kp_ids': [wp.id], 'difficulty': 'adaptive'},
            points_reward=20,
            exp_reward=25,
        ))
    
    # 限制总任务数 (分龄策略)
    grade_group = get_grade_group(user_id)
    max_tasks = MAX_TASKS_BY_GRADE[grade_group]  # 幼儿3, 小学5, 初中7, 高中8
    tasks = tasks[:max_tasks]
    
    # 排序: required > recommended > challenge, 同优先级按 sort_order
    tasks.sort(key=lambda t: (PRIORITY_ORDER[t.priority], -t.sort_order))
    
    # 保存快照
    snapshot = await save_snapshot(user_id, date, tasks)
    return snapshot
```

```dart
  @override
  Future<DailyTasksState> build() async {

    state = await AsyncValue.guard(() async {
      final result = await _repo.getToday(forceRefresh: forceRefresh);
      await _saveToCache(result);
      return result;
    });
  }

  /// 完成任务
  Future<CompleteTaskResult> completeTask(int itemId, {
    String completedVia = 'manual',
    Map<String, dynamic>? metadata,
  }) async {
    final result = await _repo.completeItem(itemId, completedVia: completedVia, metadata: metadata);
    
    // 更新本地状态
    state = AsyncData(state.value!.copyWith(
      snapshot: state.value!.snapshot.copyWith(
        completedTasks: state.value!.snapshot.completedTasks + 1,
        completionRate: _recalcRate(state.value!.snapshot),
        earnedPoints: state.value!.snapshot.earnedPoints + result.rewards.points,
        earnedExp: state.value!.snapshot.earnedExp + result.rewards.exp,
      ),
      tasks: state.value!.tasks.map((t) {
        if (t.id == itemId) {
          return t.copyWith(status: 'completed', completedAt: DateTime.now().toIso8601String());
        }
        return t;
      }).toList(),
    ));
    
    await _saveToCache(state.value!);
    return result;
  }

        checkedInToday: true,
        currentStreak: result.streak.current,
        longestStreak: result.streak.longest,
      ),
    ));
    
    await _saveToCache(state.value!);
    return result;
  }
```

### 6.1 每日快照生命周期

```
                    ┌──────────────────┐
                    │  每日凌晨生成      │
                    │  (Celery Beat)    │
                    └────────┬─────────┘
                             │
                             ▼
                    ┌──────────────────┐
                    │     active       │ ◄─── 用户首次打开APP
                    │  (任务进行中)     │      检测到无快照时
                    └────────┬─────────┘      也会触发生成
                             │
              ┌──────────────┼──────────────┐
              │              │              │
              ▼              ▼              ▼
     ┌──────────────┐ ┌────────────┐ ┌──────────────┐
     │   completed  │ │   expired  │ │   skipped    │
     │ (全部完成)    │ │ (过期未完成) │ │ (用户跳过)   │
     └──────────────┘ └────────────┘ └──────────────┘
```

```dart
/// 跨模块任务完成检测器
/// 监听其他模块的学习行为，自动匹配并完成关联任务
class TaskCompletionDetector {
  final DailyTasksNotifier _notifier;
  
  /// 监听答题完成事件
  void onExerciseCompleted(ExerciseCompletedEvent event) {
    final tasks = _notifier.state.value?.tasks ?? [];
    for (final task in tasks) {
      if (task.status != 'pending') continue;
      
      // 匹配逻辑
      if (_matchesTask(task, event)) {
        _notifier.completeTask(
          task.id,
          completedVia: 'auto_detect',
          metadata: {
            'source_event': 'exercise_completed',
            'exercise_id': event.exerciseId,
            'time_spent_seconds': event.timeSpentSeconds,
          },
        );
        break; // 一次只匹配一个任务
      }
    }
  }
  
  bool _matchesTask(TaskItem task, ExerciseCompletedEvent event) {
    // 按任务类型匹配
    switch (task.taskType) {
      case 'mistake_review':
        return event.source == 'mistake_review' &&
               event.subject == task.targetParams?['subject'];
      case 'exercise':
        if (task.targetParams?['kp_ids'] != null) {
          final kpIds = (task.targetParams!['kp_ids'] as List).cast<int>();
          return event.knowledgePointIds.any((id) => kpIds.contains(id));
        }
        return false;
      case 'sync_chapter':
        return event.source == 'sync_chapter' &&
               event.chapterId == task.targetParams?['chapter_id'];
      default:
        return false;
    }
  }
}
```

## 9. 错误处理与降级策略

### 9.1 错误码定义

| 错误码 | 说明 | 客户端处理 |
|--------|------|------------|
| 40001 | 无效任务ID | 忽略，刷新列表 |
| 40002 | 任务已过期 | 标记为 expired，刷新 |
| 40003 | 任务已完成(重复提交) | 幂等处理，返回成功 |
| 40004 | 今日已签到(重复提交) | 幂等处理，返回成功 |
| 40005 | 补签卡不足 | 提示「补签卡已用完」 |
| 40006 | 补签日期无效(>1天前) | 提示「只能补签昨天」 |
| 40007 | 任务生成失败 | 展示缓存数据 + 重试入口 |
| 40008 | 积分发放失败 | 任务标记完成，积分延迟补发 |
| 40101 | 未登录 | 跳转登录页 |
| 42901 | 请求频率过高 | 本地节流，展示缓存 |
| 50001 | 服务端内部错误 | 展示错误态 + 重试 |

### 9.2 降级策略矩阵

| 故障场景 | 降级方案 |
|----------|----------|
| 服务端不可达 | 展示本地缓存数据，隐藏签到按钮 |
| 任务生成失败 | 展示昨日任务模板(标记为「参考」)，保留手动添加 |
| 签到接口超时 | 本地乐观签到，后台异步重试(最多3次) |
| 热力图数据缺失 | 隐藏热力图区域，不影响核心功能 |
| 积分系统故障 | 任务照常完成，积分记入待补发队列 |
| 全局网络离线 | 展示离线提示，允许查看本地缓存 |

### 9.3 离线处理

```dart
/// 离线操作队列
class OfflineTaskQueue {
  final HiveBox _box;
  
  /// 添加离线操作
  Future<void> enqueue(TaskOperation op) async {
    await _box.add(op.toJson());
  }
  
  /// 网络恢复后批量同步
  Future<void> syncAll() async {
    final ops = _box.values.toList();
    for (final opJson in ops) {
      final op = TaskOperation.fromJson(opJson);
      try {
        switch (op.type) {
          case 'complete':
            await _api.completeItem(op.itemId!, metadata: op.metadata);
            break;
          case 'checkin':
            await _api.checkin();
            break;
          case 'skip':
            await _api.skipItem(op.itemId!, reason: op.reason ?? 'not_today');
            break;
        }
        await _box.deleteAt(ops.indexOf(opJson));
      } catch (e) {
        // 幂等重试，失败跳过
        if (e is ApiException && e.code == 40003 || e.code == 40004) {
          await _box.deleteAt(ops.indexOf(opJson)); // 幂等，直接删除
        }
      }
    }
  }
}
```
