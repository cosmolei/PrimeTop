# 服务端-学生隐私计算与学习数据安全分析引擎 详细设计

## 1. 概述

### 1.1 模块定位

学生隐私计算与学习数据安全分析引擎是 PrimeTop 平台的隐私保护基础设施层，为所有涉及学生个体或群体学习数据的分析、统计、模型训练场景提供**隐私安全**的计算能力保障。

在 PrimeTop 作为面向 K12 全学段的教育产品中，大量用户为未成年人。《个人信息保护法》(PIPL)、《未成年人保护法》对未成年人数据处理提出了严格要求——原则上不得进行自动化决策画像，且需要监护人同意。本引擎通过**隐私增强技术 (Privacy-Enhancing Technologies, PETs)** 使平台在不违反法规的前提下，仍能从群体学习数据中提取教育洞察。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| **匿名化与去标识化** | 对学生数据进行脱敏处理，使数据无法关联到特定自然人 |
| **差分隐私统计** | 在群体统计结果中加入噪声，防止通过统计结果反推个体信息 |
| **安全聚合查询** | 对学习行为数据的多维聚合查询进行隐私保护 |
| **重标识风险检测** | 评估数据集或查询结果的重识别风险 |
| **隐私预算管理** | 统一管理各数据域的隐私预算消耗，防止隐私透支 |
| **合规审计追踪** | 记录所有数据访问和分析操作的审计日志 |

## 3. 核心算法设计

### 3.1 差分隐私 (Differential Privacy) 实现

#### 3.1.1 核心概念

差分隐私保证：对于任意两条只差一个记录的数据集 D 和 D'，查询 M 在两者上的输出分布"几乎"相同。形式化定义：

```
Pr[M(D) ∈ S] ≤ exp(ε) × Pr[M(D') ∈ S] + δ
```

其中 ε 越小，隐私保护越强。

#### 3.1.2 Laplace 机制实现（数值型统计）

```java
/**
 * Laplace 机制 - 对数值型聚合结果添加拉普拉斯噪声
 * 适用场景：计数、求和、均值等数值统计
 */
@Component
public class LaplaceMechanism {

    private final SecureRandom random = new SecureRandom();

    /**
     * 对真实结果添加 Laplace 噪声
     *
     * @param trueValue     真实统计值
     * @param sensitivity   查询敏感度（单条记录对结果的最大影响）
     * @param epsilon       隐私预算消耗量
     * @return 加噪后的结果
     */
    public double addNoise(double trueValue, double sensitivity, double epsilon) {
        if (epsilon <= 0) {
            throw new IllegalArgumentException("epsilon must be positive");
        }
        // Laplace 分布的 scale 参数 = sensitivity / epsilon
        double scale = sensitivity / epsilon;
        double noise = sampleLaplace(0, scale);
        return trueValue + noise;
    }

    /**
     * 计数查询的差分隐私 (敏感度 = 1)
     */
    public long privateCount(long trueCount, double epsilon) {
        return Math.max(0, Math.round(addNoise(trueCount, 1.0, epsilon)));
    }

    /**
     * 求和查询的差分隐私
     * @param trueSum       真实求和
     * @param lowerBound    值域下界（用于裁剪计算敏感度）
     * @param upperBound    值域上界
     * @param epsilon       预算
     */
    public double privateSum(double trueSum, double lowerBound, 
                              double upperBound, double epsilon) {
        // 裁剪后的敏感度 = upperBound - lowerBound
        double sensitivity = upperBound - lowerBound;
        return addNoise(trueSum, sensitivity, epsilon);
    }

    /**
     * 均值查询的差分隐私
     */
    public double privateMean(double trueSum, long trueCount,
                               double lowerBound, double upperBound,
                               double epsilon) {
        // 先对计数和求和分别加噪
        double noisedCount = privateCount(trueCount, epsilon / 2);
        double noisedSum = privateSum(trueSum, lowerBound, upperBound, epsilon / 2);

        if (noisedCount < 1) {
            return (lowerBound + upperBound) / 2.0; // 回退到中值
        }
        double mean = noisedSum / noisedCount;
        // 裁剪到合理范围
        return Math.max(lowerBound, Math.min(upperBound, mean));
    }

    /**
     * 从 Laplace(μ, b) 分布中采样
     * 概率密度: f(x) = (1/2b) * exp(-|x-μ|/b)
     */
    private double sampleLaplace(double mu, double b) {
        double u = random.nextDouble() - 0.5; // Uniform(-0.5, 0.5)
        return mu - b * Math.signum(u) * Math.log(1 - 2 * Math.abs(u));
    }
}
```

#### 3.1.3 指数机制实现（离散选择）

```java
/**
 * 指数机制 - 对离散型输出添加隐私保护
 * 适用场景：热门知识点排名、学科分布Top-N等
 */
@Component
public class ExponentialMechanism {

    private final SecureRandom random = new SecureRandom();

    /**
     * 从候选集中按隐私保护方式选择一个输出
     *
     * @param candidates    候选项列表（含真实效用值）
     * @param sensitivity   效用函数敏感度
     * @param epsilon       隐私预算
     * @return 被选中的候选项
     */
    public <T> T choose(List<Candidate<T>> candidates, 
                        double sensitivity, double epsilon) {
        // 计算每个候选项的选择概率 ∝ exp(ε * utility / (2 * sensitivity))
        double[] probabilities = new double[candidates.size()];
        double maxUtility = candidates.stream()
                .mapToDouble(Candidate::getUtility)
                .max().orElse(0);

        double sumExp = 0;
        for (int i = 0; i < candidates.size(); i++) {
            double utility = candidates.get(i).getUtility();
            // 数值稳定：减去最大值
            probabilities[i] = Math.exp(
                epsilon * (utility - maxUtility) / (2 * sensitivity)
            );
            sumExp += probabilities[i];
        }

        // 归一化并按概率采样
        double r = random.nextDouble() * sumExp;
        double cumulative = 0;
        for (int i = 0; i < candidates.size(); i++) {
            cumulative += probabilities[i];
            if (r <= cumulative) {
                return candidates.get(i).getValue();
            }
        }
        return candidates.get(candidates.size() - 1).getValue();
    }

    @Data
    @AllArgsConstructor
    public static class Candidate<T> {
        private T value;
        /** 真实效用值（如真实计数、真实频率等） */
        private double utility;
    }
}
```

### 3.2 k-匿名模型实现

```java
/**
 * k-匿名检查器
 * 确保任意一条记录在指定的准标识符组合上，至少与 k-1 条其他记录不可区分
 */
@Component
public class KAnonymityChecker {

    /**
     * 检查查询结果的分组是否满足 k-匿名
     *
     * @param groups        按准标识符分组的结果
     * @param k             最小阈值，如 k=5 表示每组至少5人
     * @param dimensionSet  本次查询使用的维度组合
     * @return 检查结果，包含被抑制的分组
     */
    public KAnonymityResult check(Map<String, Integer> groups, 
                                   int k, 
                                   Set<String> dimensionSet) {
        List<String> suppressedGroups = new ArrayList<>();
        Map<String, Integer> safeGroups = new HashMap<>();
        int suppressedCount = 0;

        for (Map.Entry<String, Integer> entry : groups.entrySet()) {
            if (entry.getValue() < k) {
                suppressedGroups.add(entry.getKey());
                suppressedCount += entry.getValue();
            } else {
                safeGroups.put(entry.getKey(), entry.getValue());
            }
        }

        // 被抑制的计数合并到一个"其他"分组中，避免泄露
        boolean hasSuppressed = !suppressedGroups.isEmpty();
        
        return new KAnonymityResult(
            safeGroups,
            hasSuppressed ? suppressedCount : 0,
            suppressedGroups,
            dimensionSet,
            k,
            hasSuppressed
        );
    }

    @Data
    @AllArgsConstructor
    public static class KAnonymityResult {
        /** 满足 k-匿名的分组 */
        private Map<String, Integer> safeGroups;
        /** 被抑制的总记录数（合并显示为"其他"） */
        private int suppressedCount;
        /** 被抑制的分组 key（仅日志使用，不返回给前端） */
        private List<String> suppressedGroupKeys;
        /** 查询维度组合 */
        private Set<String> dimensionSet;
        /** k 值 */
        private int k;
        /** 是否有数据被抑制 */
        private boolean hasSuppression;
    }
}
```

### 3.3 重标识风险评估

```java
/**
 * 重标识风险评估器
 * 评估给定数据集或查询结果是否可能被关联到特定个人
 */
@Component
public class ReidentificationRiskAssessor {

    /**
     * 评估维度组合的重识别风险等级
     *
     * @param dimensionCombination  维度组合，如 [school, grade, gender]
     * @param datasetProfile        数据集概况
     * @return 风险等级
     */
    public ReidentificationRisk assess(
            List<String> dimensionCombination,
            DatasetProfile datasetProfile) {

        // 1. 计算等价类大小分布
        EquivalentClassDistribution dist = 
            calculateEquivalentClasses(dimensionCombination, datasetProfile);

        // 2. 计算风险指标
        double singularityRate = dist.getSingletonRate(); // 唯一记录比例
        double averageClassSize = dist.getAverageClassSize();
        int maxClassSize = dist.getMaxClassSize();

        // 3. 特殊维度降权：学校+年级+性别 这类组合极易重标识
        double riskMultiplier = calculateRiskMultiplier(dimensionCombination);

        // 4. 综合评分
        double riskScore = (singularityRate * 0.5 + 
                           (1.0 / Math.max(1, averageClassSize)) * 0.3 +
                           getCombinationPenalty(dimensionCombination) * 0.2) 
                           * riskMultiplier;

        RiskLevel level;
        if (riskScore >= 0.7) {
            level = RiskLevel.CRITICAL;
        } else if (riskScore >= 0.4) {
            level = RiskLevel.HIGH;
        } else if (riskScore >= 0.2) {
            level = RiskLevel.MEDIUM;
        } else {
            level = RiskLevel.LOW;
        }

        return new ReidentificationRisk(
            riskScore, level, singularityRate, 
            averageClassSize, dimensionCombination
        );
    }

    /**
     * 高风险维度组合的额外惩罚系数
     * 如 [学校, 年级, 班级] 基本能唯一确定一个学生
     */
    private double getCombinationPenalty(List<String> dims) {
        Set<String> dimSet = new HashSet<>(dims);
        
        // 学校 + 年级 + 班级 = 近乎唯一标识
        if (dimSet.containsAll(Set.of("school", "grade", "class"))) {
            return 1.0; // 最大惩罚
        }
        // 学校 + 年级 + 性别 + 科目
        if (dimSet.containsAll(Set.of("school", "grade", "gender"))) {
            return 0.7;
        }
        // 年级 + 班级 + 科目
        if (dimSet.containsAll(Set.of("grade", "class"))) {
            return 0.6;
        }
        return 0.1; // 默认低惩罚
    }
}
```

## 5. 业务逻辑

### 5.1 隐私安全查询处理流程

```text
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 分析请求  │ ──▶ │ 1.策略匹配   │ ──▶ │ 2.维度安全   │ ──▶ │ 3.预算检查   │
│ (上游)   │     │   加载策略    │     │   校验       │     │   计算消耗   │
└──────────┘     └──────────────┘     └──────────────┘     └──────┬───────┘
                                                                  │
                                            ┌───── 预算不足 ──────┘
                                            │
                                            ▼
┌──────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 返回结果  │ ◀── │ 7.结果封装   │ ◀── │ 6.差分隐私   │ ◀── │ 5.k-匿名     │
│ (响应)   │     │   隐私标注    │     │   噪声注入   │     │   分组抑制   │
└──────────┘     └──────────────┘     └──────────────┘     └──────────────┘
                                           ▲
                                           │
                                    ┌──────┴───────┐
                                    │ 4.执行真实   │
                                    │   聚合查询   │
                                    └──────────────┘
```

**详细步骤：**

1. **策略匹配：** 根据请求的 `dataDomain` 和 `purpose` 匹配对应的隐私策略
2. **维度安全校验：** 检查请求的维度组合是否在 `allowedDimensions` 范围内，是否命中 `forbiddenCombinations`
3. **预算检查：** 预估本次查询的隐私预算消耗 ε，检查预算余额
4. **执行真实查询：** 向底层数据仓库执行真实的聚合查询
5. **k-匿名抑制：** 对分组结果进行 k-匿名检查，低于阈值的分组被抑制合并
6. **差分隐私噪声：** 对每个统计指标注入 Laplace/指数机制噪声
7. **结果封装：** 附带隐私标注信息（算法、ε、k 值、噪声标记），记录审计日志

```java
/**
 * 隐私安全查询编排服务
 * 所有群体学习数据查询的统一入口
 */
@Service
@Slf4j
public class PrivacyQueryOrchestrator {

    @Autowired private PrivacyPolicyService policyService;
    @Autowired private PrivacyBudgetService budgetService;
    @Autowired private ReidentificationRiskAssessor riskAssessor;
    @Autowired private KAnonymityChecker kAnonChecker;
    @Autowired private LaplaceMechanism laplaceMechanism;
    @Autowired private ExponentialMechanism expMechanism;
    @Autowired private PrivacyAuditLogger auditLogger;
    @Autowired private DataWarehouseClient dwClient;

    /**
     * 执行隐私安全聚合查询
     */
    public PrivacyAggregateResponse executeQuery(PrivacyAggregateRequest request) {
        long startTime = System.currentTimeMillis();
        String traceId = MDC.get("traceId");

        // Step 1: 匹配隐私策略
        PrivacyPolicy policy = policyService.findActivePolicy(
            request.getDataDomain(), request.getPurpose()
        );
        if (policy == null) {
            throw new PrivacyException(ErrorCode.POLICY_NOT_FOUND,
                "No active privacy policy for domain: " + request.getDataDomain());
        }

        // Step 2: 维度安全校验
        validateDimensions(request.getDimensions(), policy);

        // Step 3: 预算预计算与检查
        double estimatedEpsilon = estimateEpsilon(request, policy);
        boolean budgetOk = budgetService.checkAndReserve(
            policy.getId(), estimatedEpsilon
        );
        if (!budgetOk) {
            auditLogger.logBlocked(request, policy, "BUDGET_EXHAUSTED", traceId);
            throw new PrivacyException(ErrorCode.BUDGET_EXHAUSTED,
                "Privacy budget exhausted for policy: " + policy.getPolicyCode());
        }

        try {
            // Step 4: 执行真实聚合查询
            List<AggregationRow> rawRows = dwClient.aggregate(
                request.getDataDomain(),
                request.getMetrics(),
                request.getDimensions(),
                request.getFilters()
            );

            // Step 5: k-匿名分组抑制
            int k = policy.getMinGroupSize();
            KAnonymityResult kAnonResult = applyKAnonymity(rawRows, k, 
                request.getDimensions());

            // Step 6: 差分隐私噪声注入
            List<PrivacyProtectedRow> protectedRows = applyDifferentialPrivacy(
                kAnonResult.getSafeGroups(),
                request.getMetrics(),
                estimatedEpsilon,
                policy
            );

            // Step 7: 封装结果
            PrivacyAggregateResponse response = buildResponse(
                request, protectedRows, kAnonResult, 
                estimatedEpsilon, policy
            );

            // 确认预算消耗
            budgetService.confirmConsumption(policy.getId(), estimatedEpsilon);

            // 审计日志
            auditLogger.logSuccess(request, policy, estimatedEpsilon, 
                protectedRows.size(), traceId);

            log.info("Privacy query completed: traceId={}, domain={}, epsilon={}, "
                + "rows={}, suppressed={}, duration={}ms",
                traceId, request.getDataDomain(), estimatedEpsilon,
                protectedRows.size(), kAnonResult.getSuppressedCount(),
                System.currentTimeMillis() - startTime);

            return response;

        } catch (Exception e) {
            // 释放预占预算
            budgetService.releaseReserved(policy.getId(), estimatedEpsilon);
            auditLogger.logError(request, policy, e, traceId);
            throw e;
        }
    }

    /**
     * 维度安全校验
     */
    private void validateDimensions(List<String> dimensions, PrivacyPolicy policy) {
        // 检查是否在允许范围内
        List<String> disallowed = dimensions.stream()
            .filter(d -> !policy.getAllowedDimensions().contains(d))
            .collect(Collectors.toList());
        if (!disallowed.isEmpty()) {
            throw new PrivacyException(ErrorCode.DIMENSION_NOT_ALLOWED,
                "Dimensions not allowed: " + disallowed);
        }

        // 检查是否命中禁止组合
        for (List<String> forbidden : policy.getForbiddenCombinations()) {
            if (dimensions.containsAll(forbidden)) {
                throw new PrivacyException(ErrorCode.DIMENSION_FORBIDDEN,
                    "Dimension combination is forbidden (re-identification risk): " 
                    + forbidden);
            }
        }

        // 实时重标识风险评估
        ReidentificationRisk risk = riskAssessor.assess(
            dimensions, DatasetProfile.DEFAULT
        );
        if (risk.getLevel() == RiskLevel.CRITICAL) {
            throw new PrivacyException(ErrorCode.REID_RISK_CRITICAL,
                "Re-identification risk is CRITICAL for dimensions: " + dimensions);
        }
    }

    /**
     * 应用差分隐私噪声
     */
    private List<PrivacyProtectedRow> applyDifferentialPrivacy(
            Map<String, Integer> safeGroups,
            List<MetricRequest> metrics,
            double epsilon,
            PrivacyPolicy policy) {

        double perMetricEpsilon = epsilon / metrics.size();
        List<PrivacyProtectedRow> result = new ArrayList<>();

        for (Map.Entry<String, Integer> entry : safeGroups.entrySet()) {
            String groupKey = entry.getKey();
            int count = entry.getValue();

            PrivacyProtectedRow row = new PrivacyProtectedRow();
            row.setGroupKey(groupKey);
            row.setRawCount(count);

            Map<String, Double> protectedMetrics = new HashMap<>();
            for (MetricRequest metric : metrics) {
                double rawValue = getMetricValue(groupKey, metric);
                double protectedValue;

                switch (metric.getType()) {
                    case COUNT:
                        protectedValue = laplaceMechanism.privateCount(
                            (long) rawValue, perMetricEpsilon);
                        break;
                    case SUM:
                        protectedValue = laplaceMechanism.privateSum(
                            rawValue, metric.getLowerBound(), 
                            metric.getUpperBound(), perMetricEpsilon);
                        break;
                    case AVG:
                        protectedValue = laplaceMechanism.privateMean(
                            rawValue * count, count,
                            metric.getLowerBound(), metric.getUpperBound(),
                            perMetricEpsilon);
                        break;
                    default:
                        protectedValue = laplaceMechanism.addNoise(
                            rawValue, metric.getSensitivity(), perMetricEpsilon);
                }
                protectedMetrics.put(metric.getField(), protectedValue);
            }
            row.setMetrics(protectedMetrics);
            result.add(row);
        }

        return result;
    }
}
```

```java
/**
 * 去标识化服务
 * 对学生数据进行假名化、泛化、脱敏处理

@Service
@Slf4j
public class DeidentificationService {

    @Autowired private KeyManagementService keyService;
    @Autowired private DeidPseudonymMapper pseudonymMapper;
    @Autowired private PrivacyAuditLogger auditLogger;

    private static final SecureRandom RANDOM = new SecureRandom();

    /**
     * 对学生ID进行假名化
     * 使用 HMAC-SHA256 + 周期性盐值
     */
    public String pseudonymizeUserId(String realUserId, String dataDomain) {
        // 获取当前周期盐值ID
        String saltId = keyService.getCurrentSaltId(dataDomain);
        byte[] salt = keyService.getSalt(saltId);

        // HMAC-SHA256(userId, salt)
        String pseudonymId = "PSN_" + hmacSha256(realUserId, salt);

        // 存储映射关系（不含真实ID，仅存哈希摘要用于反查）
        pseudonymMapper.storeMapping(pseudonymId, dataDomain, saltId);

        return pseudonymId;
    }

    /**
     * 对字段进行泛化处理
     * 将精确值替换为范围值，降低粒度
     */
    public String generalize(String field, String value) {
        switch (field) {
            case "age":
            case "birth_year":
                return generalizeAge(Integer.parseInt(value));
            case "zip_code":
                return generalizeZipCode(value);
            case "school_name":
                return generalizeSchool(value); // 只保留区/县级别
            case "exact_score":
                int score = Integer.parseInt(value);
                return generalizeScore(score);
            default:
                return value;
        }
    }

    private String generalizeAge(int age) {
        // 泛化到 5 岁区间
        int lower = (age / 5) * 5;
        return lower + "-" + (lower + 4);
    }

    private String generalizeZipCode(String zip) {
        if (zip.length() >= 6) {
            return zip.substring(0, 3) + "**"; // 保留前3位
        }
        return "***";
    }

    private String generalizeScore(int score) {
        // 泛化到 10 分区间
        int lower = (score / 10) * 10;
        return lower + "-" + (lower + 9);
    }

    /**
     * 假名轮换（定期更换盐值和假名，增强安全性）
     */
    @Scheduled(cron = "0 0 3 1 * ?") // 每月1日凌晨3点
    public void rotatePseudonyms() {
        log.info("Starting pseudonym rotation cycle");
        
        List<String> domains = Arrays.asList(
            "LEARNING_BEHAVIOR", "ANSWER_RECORD", "STUDY_TIME"
        );
        
        for (String domain : domains) {
            // 生成新周期盐值
            byte[] newSalt = new byte[32];
            RANDOM.nextBytes(newSalt);
            String newSaltId = keyService.registerNewSalt(domain, newSalt);
            
            // 标记旧映射过期
            pseudonymMapper.expireOldMappings(domain, 
                LocalDateTime.now().plusDays(7)); // 7天过渡期
            
            log.info("Rotated pseudonym salt for domain: {}, newSaltId: {}", 
                domain, newSaltId);
        }
        
        auditLogger.logSystemEvent("PSEUDONYM_ROTATION", 
            "Monthly pseudonym rotation completed");
    }

    private String hmacSha256(String data, byte[] salt) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(salt, "HmacSHA256"));
            byte[] hash = mac.doFinal(data.getBytes(StandardCharsets.UTF_8));
            return Base64.getUrlEncoder().withoutPadding()
                .encodeToString(hash).substring(0, 16);
        } catch (Exception e) {
            throw new RuntimeException("HMAC computation failed", e);
        }
    }
}
```

### 6.3 隐私预算管理服务

```java
/**
 * 隐私预算管理服务
 * 采用 Redis 原子操作确保预算扣减的并发安全
 */
@Service
@Slf4j
public class PrivacyBudgetService {

    @Autowired private RedisTemplate<String, String> redisTemplate;
    @Autowired private PrivacyBudgetAccountMapper budgetMapper;

    private static final long LOCK_WAIT_MS = 100;
    private static final long LOCK_LEASE_MS = 5000;

    /**
     * 检查并预占预算 (乐观锁 + Redis 原子操作)
     */
    public boolean checkAndReserve(Long policyId, double epsilon) {
        String budgetKey = buildBudgetKey(policyId);

        return redisTemplate.execute(new SessionCallback<Boolean>() {
            @Override
            @SuppressWarnings("unchecked")
            public Boolean execute(RedisOperations operations) {
                // WATCH key
                operations.watch(budgetKey);

                String remainingStr = (String) operations.opsForValue().get(budgetKey);
                double remaining = remainingStr != null 
                    ? Double.parseDouble(remainingStr) : 0;

                if (remaining < epsilon) {
                    operations.unwatch();
                    log.warn("Privacy budget insufficient: policy={}, need={}, remaining={}",
                        policyId, epsilon, remaining);
                    return false;
                }

                // MULTI
                operations.multi();
                operations.opsForValue().decrement(
                    budgetKey, String.valueOf(epsilon)); // 原子扣减
                List<Object> results = operations.exec();

                if (results == null || results.isEmpty()) {
                    // 事务被打断（其他线程已修改）
                    log.warn("Budget reservation retry needed: policy={}", policyId);
                    return checkAndReserve(policyId, epsilon); // 递归重试
                }
                return true;
            }
        });
    }

    /**
     * 确认预算消耗
     */
    public void confirmConsumption(Long policyId, double epsilon) {
        // Redis 中已扣减，这里只需更新数据库持久化
        String periodKey = currentPeriodKey();
        PrivacyBudgetAccount account = budgetMapper.findByPolicyAndPeriod(
            policyId, periodKey);
        
        if (account != null) {
            account.setSpentEpsilon(
                account.getSpentEpsilon().add(BigDecimal.valueOf(epsilon))
            );
            account.setRemainingEpsilon(
                account.getTotalEpsilon()
                    .subtract(account.getSpentEpsilon())
                    .subtract(account.getReservedEpsilon())
            );
            budgetMapper.updateById(account);

            // 检查预警阈值
            BigDecimal utilization = account.getSpentEpsilon()
                .divide(account.getTotalEpsilon(), 4, RoundingMode.HALF_UP);
            if (utilization.compareTo(account.getAlertThreshold()) >= 0) {
                log.warn("Privacy budget alert: policy={}, period={}, utilization={}%",
                    policyId, periodKey, utilization.multiply(BigDecimal.valueOf(100)));
                // TODO: 触发告警通知
            }
        }
    }

    /**
     * 释放预占预算（查询失败时回滚）
     */
    public void releaseReserved(Long policyId, double epsilon) {
        String budgetKey = buildBudgetKey(policyId);
        redisTemplate.opsForValue().increment(budgetKey, String.valueOf(epsilon));
        log.info("Released reserved budget: policy={}, epsilon={}", policyId, epsilon);
    }

    private String buildBudgetKey(Long policyId) {
        return String.format("privacy:budget:%d:%s", policyId, currentPeriodKey());
    }

    private String currentPeriodKey() {
        return LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy-MM"));
    }
}
```

### 7.2 降级策略

| 故障场景 | 降级策略 | 说明 |
|---------|---------|------|
| 隐私预算服务不可用 | **拒绝所有聚合查询** | 宁可不返回数据，也不在无保护下暴露 |
| k-匿名检查失败 | **返回安全默认值** | 只返回已知的粗粒度聚合数据 |
| 重标识风险评估超时 | **保守策略**：按 HIGH 风险处理 | 超时时宁可拒绝也不冒险 |
| Redis 不可用 | **降级到数据库锁** | 性能下降但功能不丢 |
| 数据仓库查询超时 | **返回缓存的上次安全结果** | 标注数据为缓存数据 |
| 密钥管理服务不可用 | **拒绝导出请求** | 无法安全去标识化时拒绝操作 |

```java
/**
 * 降级处理器
 */
@Component
@Slf4j
public class PrivacyFallbackHandler {

    @Autowired private RedisTemplate<String, Object> redisTemplate;

    /**
     * 预算服务降级：拒绝查询
     */
    public PrivacyAggregateResponse budgetServiceFallback(
            PrivacyAggregateRequest request, Throwable cause) {
        log.error("Budget service unavailable, rejecting query for safety: {}",
            request.getQueryId(), cause);
        throw new PrivacyException(ErrorCode.BUDGET_EXHAUSTED,
            "Privacy budget service unavailable. For safety, all queries are rejected.");
    }

    /**
     * 聚合查询超时降级：返回缓存
     */
    public PrivacyAggregateResponse queryTimeoutFallback(
            PrivacyAggregateRequest request, Throwable cause) {
        String cacheKey = "privacy:cache:safe:" + request.hashCode();
        PrivacyAggregateResponse cached = (PrivacyAggregateResponse) 
            redisTemplate.opsForValue().get(cacheKey);

        if (cached != null) {
            cached.setStale(true);
            cached.setStaleReason("DATA_WAREHOUSE_TIMEOUT");
            log.warn("Returning cached privacy result for query: {}", 
                request.getQueryId());
            return cached;
        }
        throw new PrivacyException(ErrorCode.INVALID_QUERY,
            "Data warehouse timeout and no cache available");
    }
}
```

```java
/**
 * 安全聚合预计算调度器
 * 每天凌晨预计算高频隐私查询结果
 */
@Component
@Slf4j
public class SafeAggregatePrecomputer {

    @Autowired private PrivacyQueryOrchestrator queryEngine;
    @Autowired private PrivacyPolicyService policyService;

    // 高频查询模式列表（由运营分析自动维护）
    private static final List<QueryPattern> HIGH_FREQ_PATTERNS = List.of(
        // 模式1: 各年级学科日均正确率
        new QueryPattern("ANSWER_RECORD", 
            List.of("grade", "subject"),
            List.of(MetricType.COUNT, MetricType.AVG),
            "DAILY_STATS"),
        // 模式2: 各章节知识点掌握分布
        new QueryPattern("ANSWER_RECORD",
            List.of("subject", "chapter"),
            List.of(MetricType.COUNT, MetricType.AVG),
            "CHAPTER_MASTERY"),
        // 模式3: 每日学习时长分布
        new QueryPattern("STUDY_TIME",
            List.of("grade"),
            List.of(MetricType.COUNT, MetricType.SUM, MetricType.AVG),
            "STUDY_TIME_STATS")
    );

    /**
     * 每天凌晨2点预计算安全聚合数据
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void precomputeDailySafeAggregates() {
        log.info("Starting daily safe aggregate precomputation");

        for (QueryPattern pattern : HIGH_FREQ_PATTERNS) {
            try {
                PrivacyPolicy policy = policyService.findActivePolicy(
                    pattern.getDomain(), pattern.getPurpose()
                );
                if (policy == null) continue;

                // 构造昨日查询
                PrivacyAggregateRequest request = buildYesterdayQuery(pattern);
                
                // 执行隐私查询
                PrivacyAggregateResponse response = queryEngine.executeQuery(request);

                // 缓存结果，TTL = 25小时
                cacheSafeAggregate(request, response, Duration.ofHours(25));

                log.info("Precomputed safe aggregate: domain={}, dimensions={}",
                    pattern.getDomain(), pattern.getDimensions());

            } catch (Exception e) {
                log.error("Failed to precompute pattern: {}", pattern, e);
            }
        }
    }
}
```

### 9.3 防御措施

1. **查询频率限制：** 每个调用服务每分钟最多 60 次隐私查询，防止通过大量查询绕过隐私保护
2. **结果关联检测：** 检测同一来源在短时间内使用不同维度查询的数据是否可以关联重标识
3. **审计日志防篡改：** 使用链式哈希（每条日志包含前一条的哈希），防止单条日志被篡改
4. **导出文件水印：** 去标识化导出文件中嵌入不可见标识，可追溯到具体导出操作

```java
/**
 * 审计日志链式哈希防篡改
 */
@Component
public class AuditLogChainHasher {

    private static final String PREV_HASH_REDIS_KEY = "privacy:audit:last_hash";

    /**
     * 计算当前日志条目的链式哈希
     */
    public String computeChainHash(PrivacyAuditLog logEntry, String previousHash) {
        String content = String.join("|",
            previousHash != null ? previousHash : "GENESIS",
            logEntry.getId().toString(),
            logEntry.getDataDomain(),
            logEntry.getOperationType(),
            logEntry.getEpsilonConsumed().toString(),
            logEntry.getCreatedAt().toString()
        );
        return sha256(content);
    }

    /**
     * 写入时自动追加链式哈希
     */
    public void appendChainHash(PrivacyAuditLog logEntry) {
        String prevHash = redisTemplate.opsForValue()
            .get(PREV_HASH_REDIS_KEY).toString();
        String currentHash = computeChainHash(logEntry, prevHash);
        logEntry.setChainHash(currentHash);
        redisTemplate.opsForValue().set(PREV_HASH_REDIS_KEY, currentHash);
    }
}
```

### 10.1 差分隐私正确性验证

```java
/**
 * 差分隐私机制单元测试
 */
@SpringBootTest
class LaplaceMechanismTest {

    @Autowired private LaplaceMechanism mechanism;

    @Test
    @DisplayName("加噪后的均值统计量应接近真实值（在允许误差范围内）")
    void testPrivateCountAccuracy() {
        long trueCount = 1000;
        double epsilon = 1.0;
        
        // 运行1000次取平均，验证无偏性
        double sum = 0;
        int iterations = 1000;
        for (int i = 0; i < iterations; i++) {
            sum += mechanism.privateCount(trueCount, epsilon);
        }
        double avgNoised = sum / iterations;

        // 均值误差应在 5% 以内（ε=1.0, count=1000 时）
        assertThat(Math.abs(avgNoised - trueCount) / trueCount)
            .isLessThan(0.05);
    }

    @Test
    @DisplayName("ε 越小，噪声越大（隐私保护越强）")
    void testEpsilonSensitivity() {
        long trueCount = 500;
        
        double varianceLarge = computeVariance(trueCount, 2.0);  // 大ε，小噪声
        double varianceSmall = computeVariance(trueCount, 0.1);  // 小ε，大噪声
        
        assertThat(varianceSmall).isGreaterThan(varianceLarge);
    }

    private double computeVariance(long trueValue, double epsilon) {
        double[] samples = new double[500];
        for (int i = 0; i < 500; i++) {
            samples[i] = mechanism.privateCount(trueValue, epsilon);
        }
        double mean = Arrays.stream(samples).average().orElse(0);
        return Arrays.stream(samples)
            .map(v -> (v - mean) * (v - mean))
            .average().orElse(0);
    }
}
```

### 10.3 预算管理并发测试

```java
@Test
@DisplayName("并发预算扣减不应超出总预算")
void testConcurrentBudgetDeduction() throws InterruptedException {
    Long policyId = 1L;
    double totalBudget = 10.0;
    double perQueryEpsilon = 1.0;
    int threadCount = 20;

    // 初始化预算
    budgetService.initializeBudget(policyId, totalBudget);

    CountDownLatch latch = new CountDownLatch(threadCount);
    AtomicInteger successCount = new AtomicInteger(0);
    AtomicInteger failCount = new AtomicInteger(0);

    ExecutorService executor = Executors.newFixedThreadPool(threadCount);
    for (int i = 0; i < threadCount; i++) {
        executor.submit(() -> {
            try {
                boolean ok = budgetService.checkAndReserve(policyId, perQueryEpsilon);
                if (ok) successCount.incrementAndGet();
                else failCount.incrementAndGet();
            } finally {
                latch.countDown();
            }
        });
    }
    latch.await();
    executor.shutdown();

    // 总预算10，每次消耗1，最多成功10次
    assertThat(successCount.get()).isLessThanOrEqualTo(10);
    assertThat(successCount.get() + failCount.get()).isEqualTo(threadCount);
}
```

| ε (epsilon) | Privacy Parameter | 差分隐私参数，控制隐私保护强度，越小保护越强 |
| δ (delta) | Privacy Parameter | 差分隐私松弛参数，允许极小概率违反纯差分隐私 |
| k-匿名 | k-Anonymity | 确保每条记录至少与 k-1 条其他记录在准标识符上不可区分 |
| 重标识 | Re-identification | 通过关联多份数据将匿名化数据重新关联到特定个人 |
| 假名化 | Pseudonymization | 用假名替换真实标识符，映射关系可逆（需授权） |
| 匿名化 | Anonymization | 不可逆地移除或修改标识信息 |
| 准标识符 | Quasi-Identifier | 非唯一但组合后可能唯一标识个人的属性（如邮编+生日+性别） |
| 隐私预算 | Privacy Budget | 有限的可消耗隐私保护"配额"，防止通过无限查询耗尽保护 |
| 敏感度 | Sensitivity | 单条记录的加入/退出对查询结果的最大影响 |
