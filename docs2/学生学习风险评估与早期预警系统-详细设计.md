# 学生学习风险评估与早期预警系统 - 详细设计

## 1. 模块概述

### 1.1 功能定位

基于学生历史学习行为、答题数据、活跃度趋势等多维特征，构建学生学习风险预测模型，对可能出现的学习退步、长期低活跃、知识点断层等风险进行早期识别，自动触发预警并生成干预建议，推送给家长和教师，实现"早发现、早干预"的学习保障闭环。

### 1.2 核心价值

1. **预测性**：不等成绩下滑才反应，提前 1-2 周识别风险信号
2. **可解释性**：每个风险预警附带具体原因和证据链，家长/教师能理解
3. **可操作性**：不只是报警，同时给出干预建议（如推荐复习某个知识点）
4. **隐私安全**：风险数据仅家长和绑定教师可见，学生端不直接展示风险标签

### 1.3 与现有模块的关系

| 关联模块 | 交互方式 |
|----------|----------|
| 学情分析 | 消费学情数据作为风险特征输入 |
| 学习记录与进度追踪 | 消费学习时长、完成率等行为数据 |
| 知识点体系与教材映射引擎 | 消费知识点掌握度数据 |
| 错题整理 | 消费错题数量、错因分布数据 |
| 家长中心 | 向家长推送预警通知和干预建议 |
| 教师端与班级管理 | 向教师推送班级风险概览和学生预警 |
| 学习提醒与智能通知调度系统 | 通过通知系统分发预警 |
| 练习与测评系统 | 消费答题正确率、用时等测评数据 |
| 用户标签与智能分群引擎 | 写入风险标签，供运营分群使用 |

## 2. 风险模型设计

### 2.1 风险维度定义

系统从 5 个维度评估学生学习风险：

```python
class RiskDimension(str, Enum):
    ENGAGEMENT = "engagement"       # 活跃度风险：使用频率下降、学习时长锐减
    MASTERY = "mastery"             # 掌握度风险：知识点掌握度持续走低
    MISTAKE = "mistake"             # 错误率风险：答题正确率下降、同类错题增多
```

### 2.4 风险评分模型

采用**加权评分 + 规则叠加**的混合模型，兼顾可解释性和预测准确性。

#### 2.4.1 维度评分函数

每个维度独立计算 0-100 的风险分：

```python
def compute_engagement_risk(features: EngagementFeatures) -> RiskScore:
    """活跃度风险评分"""
    score = 0.0
    
    # (1) 活跃天数衰减（权重 30%）
    if features.active_days_last_7d <= 1:
        score += 30
    elif features.active_days_last_7d <= 3:
        score += 15
    elif features.active_days_last_7d <= 5:
        score += 5
    
    # (2) 活跃度周环比下降（权重 25%）
    if features.active_days_week_over_week < -0.5:
        score += 25
    elif features.active_days_week_over_week < -0.3:
        score += 15
    elif features.active_days_week_over_week < -0.1:
        score += 5
    
    # (3) 学习时长趋势下降（权重 25%）
    if features.daily_time_trend_14d < -5:
        score += 25
    elif features.daily_time_trend_14d < -2:
        score += 15
    elif features.daily_time_trend_14d < 0:
        score += 5
    
    # (4) 连续中断天数（权重 20%）
    if features.max_gap_days_30d >= 7:
        score += 20
    elif features.max_gap_days_30d >= 5:
        score += 12
    elif features.max_gap_days_30d >= 3:
        score += 5
    
    return RiskScore(
        dimension=RiskDimension.ENGAGEMENT,
        score=min(score, 100),
        confidence=_compute_confidence(features),
        contributors=_get_top_contributors(features)
    )
```

其他维度的评分函数结构类似，每个维度定义独立的评分规则和阈值。

#### 2.4.2 综合风险评分

```python
# 分龄权重矩阵（不同学段关注点不同）
DIMENSION_WEIGHTS = {
    "primary": {  # 小学：更关注活跃度和连续性
        RiskDimension.ENGAGEMENT: 0.25,
        RiskDimension.MASTERY: 0.20,
        RiskDimension.MISTAKE: 0.15,
        RiskDimension.PROGRESS: 0.15,
        RiskDimension.CONSISTENCY: 0.25,
    },
    "junior": {  # 初中：更关注掌握度和错误率
        RiskDimension.ENGAGEMENT: 0.20,
        RiskDimension.MASTERY: 0.25,
        RiskDimension.MISTAKE: 0.25,
        RiskDimension.PROGRESS: 0.15,
        RiskDimension.CONSISTENCY: 0.15,
    },
    "senior": {  # 高中：更关注掌握度和进度
        RiskDimension.ENGAGEMENT: 0.15,
        RiskDimension.MASTERY: 0.30,
        RiskDimension.MISTAKE: 0.20,
        RiskDimension.PROGRESS: 0.25,
        RiskDimension.CONSISTENCY: 0.10,
    },
}

def compute_composite_risk(
    dimension_scores: dict[RiskDimension, RiskScore],
    stage: str
) -> CompositeRiskAssessment:
    """计算综合风险评分"""
    weights = DIMENSION_WEIGHTS.get(stage, DIMENSION_WEIGHTS["junior"])
    
    composite_score = sum(
        dimension_scores[dim].score * weights[dim]
        for dim in RiskDimension
    )
    
    # 规则叠加：关键风险因子额外加分
    bonus = 0.0
    # 多维度同时高风险：叠加效应
    high_risk_dims = sum(
        1 for s in dimension_scores.values() if s.score >= 60
    )
    if high_risk_dims >= 3:
        bonus += 15
    elif high_risk_dims >= 2:
        bonus += 8
    
    final_score = min(composite_score + bonus, 100)
    
    return CompositeRiskAssessment(
        overall_score=final_score,
        risk_level=_score_to_level(final_score),
        dimension_scores=dimension_scores,
        primary_risk_dimension=max(
            dimension_scores, key=lambda d: dimension_scores[d].score
        ),
        bonus_applied=bonus,
        bonus_reason=f"{high_risk_dims}个维度高风险叠加" if bonus > 0 else None,
    )
```

### 3.2 数据模型（Python）

```python
from datetime import date, datetime
from decimal import Decimal
from typing import Optional
from pydantic import BaseModel, Field
from enum import Enum


class RiskDimension(str, Enum):
    ENGAGEMENT = "engagement"
    MASTERY = "mastery"
    MISTAKE = "mistake"
    PROGRESS = "progress"
    CONSISTENCY = "consistency"


class RiskLevel(str, Enum):
    NORMAL = "normal"
    LOW_RISK = "low_risk"
    MEDIUM_RISK = "medium_risk"
    HIGH_RISK = "high_risk"


class AlertType(str, Enum):
    SCORE_THRESHOLD = "score_threshold"       # 风险分超过阈值
    LEVEL_CHANGE_UP = "level_change_up"       # 风险等级上升
    PROLONGED_RISK = "prolonged_risk"         # 持续处于风险状态
    SUDDEN_DROP = "sudden_drop"               # 指标骤降
    INACTIVITY = "inactivity"                 # 长时间不活跃
    MASTERY_COLLAPSE = "mastery_collapse"     # 掌握度崩塌


class InterventionType(str, Enum):
    REVIEW_PLAN = "review_plan"               # 推荐复习计划
    WEAK_KP_DRILL = "weak_kp_drill"           # 薄弱知识点专项练习
    STUDY_SCHEDULE = "study_schedule"          # 调整学习时间表
    PARENT_ENCOURAGE = "parent_encourage"      # 家长鼓励沟通
    TEACHER_CHECKIN = "teacher_checkin"        # 教师关怀跟进
    CONTENT_ADJUST = "content_adjust"          # 降低难度/调整内容


class RiskScore(BaseModel):
    """单维度风险评分"""
    dimension: RiskDimension
    score: Decimal = Field(ge=0, le=100)
    confidence: Decimal = Field(ge=0, le=1)
    contributors: list[str] = Field(default_factory=list)  # 主要贡献因子


class EvidenceItem(BaseModel):
    """预警证据项"""
    metric_name: str          # 指标名称
    current_value: float      # 当前值
    previous_value: float     # 之前值
    change_rate: float        # 变化率
    threshold: float          # 阈值
    severity: str             # 严重程度: mild/moderate/severe


class InterventionSuggestion(BaseModel):
    """干预建议"""
    type: InterventionType
    priority: int = Field(ge=1, le=10)
    title: str
    description: str
    action_url: Optional[str] = None
    target_kp_ids: list[int] = Field(default_factory=list)
    target_chapter_id: Optional[int] = None
    estimated_effort: str     # 预估投入: "10分钟"/"30分钟"/"1小时"/"每日15分钟×7天"


class RiskAlert(BaseModel):
    """风险预警"""
    id: Optional[int] = None
    student_id: int
    alert_type: AlertType
    risk_level: RiskLevel
    trigger_score: Decimal
    primary_dimension: RiskDimension
    title: str
    summary: Optional[str] = None
    evidence: list[EvidenceItem]
    interventions: list[InterventionSuggestion] = Field(default_factory=list)
    status: str = "pending"
    created_at: Optional[datetime] = None


class CompositeRiskAssessment(BaseModel):
    """综合风险评估"""
    student_id: int
    assessment_date: date
    overall_score: Decimal = Field(ge=0, le=100)
    risk_level: RiskLevel
    dimension_scores: dict[RiskDimension, RiskScore]
    primary_risk_dimension: RiskDimension
    trend_direction: Optional[str] = None      # improving/stable/worsening
    score_delta_7d: Optional[Decimal] = None
    confidence: Decimal = Field(ge=0, le=1)
    bonus_applied: Decimal = Decimal("0")
    bonus_reason: Optional[str] = None
```
