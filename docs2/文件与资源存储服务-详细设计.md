## 1. 模块概述

### 1.1 功能定位

文件与资源存储服务（File & Resource Storage Service, 简称 FRSS）是 PrimeTop 的**跨模块基础设施层**，负责统一管理所有文件资源的上传、存储、处理、分发和生命周期。该服务向上层业务模块提供标准化的文件操作接口，屏蔽底层存储实现细节。

### 1.2 覆盖的文件类型

| 文件类别 | 来源模块 | 格式 | 典型大小 |
|----------|----------|------|----------|
| 用户拍照图片 | 拍照搜题与习题答疑 | JPEG/PNG | 0.5-5 MB |
| 语音录音 | 语音服务、背诵检测、口语陪练 | WAV/OGG/OPUS | 0.1-2 MB |
| 作文文档 | 作文辅导 | 纯文本/图片 | 0.01-10 MB |
| 手写/绘画图片 | 拼音识字启蒙 | JPEG/PNG | 0.5-3 MB |
| 用户头像 | 用户账号体系 | JPEG/PNG | 0.1-2 MB |
| 教材资源图片 | 内容与运营后台 | JPEG/PNG/WebP | 0.1-5 MB |
| 课程音频 | 内容与运营后台 | MP3/OGG | 1-20 MB |
| 题目配图 | 题目与题库服务 | JPEG/PNG/SVG | 0.01-2 MB |
| 系统资源 | 运营活动、推送 | 各类 | 不定 |

### 1.3 核心目标

| 目标 | 指标 |
|------|------|
| 上传可靠性 | 分片上传成功率 ≥ 99.9% |
| 读取性能 | CDN 命中率 ≥ 95%，首字节时间 ≤ 100ms |
| 存储成本 | 冷热分层，月度存储成本增长 ≤ 用户增长 × 1.2 |
| 安全合规 | 所有上传文件 100% 过审，敏感内容拦截率 ≥ 99% |
| 可用性 | 服务可用性 ≥ 99.95% |

### 2.2 存储分层策略

```
热存储 (Hot)          ← 最近 30 天访问的文件
│   SSD/高性能对象存储
│   CDN 边缘缓存
│   响应时间: < 50ms
│
温存储 (Warm)         ← 30-180 天未访问的文件
│   标准对象存储
│   按需 CDN 回源
│   响应时间: < 200ms
│
冷存储 (Cold)         ← 180 天以上未访问的文件
    低频/归档对象存储
    需解冻后访问
    响应时间: 1-5s (解冻)
```

## 3. 数据结构设计

### 3.1 核心表：file_resource（文件资源表）

```sql
CREATE TABLE file_resource (
    id              BIGSERIAL PRIMARY KEY,
    file_key        VARCHAR(512) NOT NULL UNIQUE,    -- 对象存储中的唯一键
    file_name       VARCHAR(512) NOT NULL,            -- 原始文件名
    file_type       VARCHAR(32)  NOT NULL,            -- MIME 类型
    file_category   VARCHAR(32)  NOT NULL,            -- 文件分类 (见 3.3)
    file_size       BIGINT       NOT NULL DEFAULT 0,  -- 字节大小
    file_hash       VARCHAR(128) NOT NULL,            -- SHA-256 哈希 (去重)
    
    -- 图片特有字段
    image_width     INTEGER,                          -- 原始宽度
    image_height    INTEGER,                          -- 原始高度
    thumb_key       VARCHAR(512),                     -- 缩略图存储键
    
    -- 音频特有字段
    audio_duration  INTEGER,                          -- 时长（秒）
    audio_format    VARCHAR(16),                      -- 编码格式
    
    -- 归属信息
    owner_type      VARCHAR(32)  NOT NULL,            -- user / system / course
    owner_id        BIGINT       NOT NULL,            -- 用户ID 或 系统资源ID
    biz_type        VARCHAR(64),                      -- 业务类型 (见 3.4)
    biz_id          BIGINT,                           -- 业务ID (题目ID/对话ID等)
    
    -- 存储信息
    storage_tier    VARCHAR(16)  NOT NULL DEFAULT 'hot',  -- hot/warm/cold
    storage_backend VARCHAR(32)  NOT NULL DEFAULT 'oss',  -- oss/s3/local
    bucket          VARCHAR(128) NOT NULL,
    
    -- 审核状态
    audit_status    VARCHAR(16)  NOT NULL DEFAULT 'pending',  -- pending/approved/rejected
    audit_result    JSONB,                              -- 审核结果详情
    
    -- CDN 与访问
    cdn_url         VARCHAR(1024),                     -- CDN 加速地址
    access_count    INT          NOT NULL DEFAULT 0,
    last_accessed   TIMESTAMPTZ,                       -- 最后访问时间
    
    -- 时间戳
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    expires_at      TIMESTAMPTZ,                       -- 过期时间 (NULL = 永不过期)
    deleted_at      TIMESTAMPTZ                        -- 软删除
);

-- 索引
CREATE INDEX idx_file_resource_owner ON file_resource (owner_type, owner_id);
CREATE INDEX idx_file_resource_biz ON file_resource (biz_type, biz_id);
CREATE INDEX idx_file_resource_hash ON file_resource (file_hash);
CREATE INDEX idx_file_resource_audit ON file_resource (audit_status) WHERE audit_status = 'pending';
CREATE INDEX idx_file_resource_tier ON file_resource (storage_tier, last_accessed);
CREATE INDEX idx_file_resource_expires ON file_resource (expires_at) WHERE expires_at IS NOT NULL AND deleted_at IS NULL;
CREATE INDEX idx_file_resource_category ON file_resource (file_category, created_at DESC);
```

### 3.2 分片上传表：file_upload_session

```sql
CREATE TABLE file_upload_session (
    id              BIGSERIAL PRIMARY KEY,
    upload_id       VARCHAR(128) NOT NULL UNIQUE,      -- 客户端生成的上传会话ID
    user_id         BIGINT       NOT NULL,
    file_name       VARCHAR(512) NOT NULL,
    file_type       VARCHAR(32)  NOT NULL,
    file_size       BIGINT       NOT NULL DEFAULT 0,   -- 预期总大小
    file_hash       VARCHAR(128),                       -- 最终 SHA-256 (完成后填充)
    
    total_chunks    INTEGER      NOT NULL,
    uploaded_chunks INTEGER      NOT NULL DEFAULT 0,
    chunk_size      INTEGER      NOT NULL DEFAULT 4194304, -- 4MB per chunk
    
    status          VARCHAR(16)  NOT NULL DEFAULT 'uploading',  -- uploading/completing/completed/failed/expired
    file_resource_id BIGINT,                             -- 完成后关联 file_resource.id
    
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    expires_at      TIMESTAMPTZ  NOT NULL DEFAULT (NOW() + INTERVAL '24 hours')
);

CREATE INDEX idx_upload_session_user ON file_upload_session (user_id, status);
CREATE INDEX idx_upload_session_expire ON file_upload_session (expires_at) WHERE status = 'uploading';
```

### 5.2 文件名安全处理

```python
import re
import hashlib
from datetime import datetime

def generate_file_key(category: str, original_name: str, upload_id: str) -> str:
    """生成安全的存储路径"""
    now = datetime.utcnow()
    ext = get_safe_extension(original_name)  # 白名单校验
    date_path = now.strftime("%Y/%m/%d")
    
    # 使用 upload_id 作为文件名，避免路径遍历和特殊字符
    safe_name = f"{upload_id}{ext}"
    
    return f"{category}/{date_path}/{safe_name}"

def get_safe_extension(filename: str) -> str:
    """只允许白名单后缀"""
    ALLOWED_EXTENSIONS = {
        '.jpg', '.jpeg', '.png', '.gif', '.webp', '.svg',  # 图片
        '.mp3', '.ogg', '.opus', '.wav', '.m4a',           # 音频
        '.pdf', '.txt',                                      # 文档
    }
    ext = Path(filename).suffix.lower()
    if ext not in ALLOWED_EXTENSIONS:
        raise ValueError(f"不支持的文件类型: {ext}")
    return ext
```

### 6.3 图片处理核心代码

```python
from PIL import Image
import io
import struct

def validate_image(file_data: bytes) -> tuple[bool, str]:
    """通过 Magic Bytes 验证是否为真实图片"""
    SIGNATURES = {
        b'\xFF\xD8\xFF': 'jpeg',
        b'\x89PNG\r\n\x1a\n': 'png',
        b'GIF87a': 'gif',
        b'GIF89a': 'gif',
        b'RIFF': 'webp',      # RIFF....WEBP
    }
    for sig, fmt in SIGNATURES.items():
        if file_data[:len(sig)] == sig:
            if fmt == 'webp' and file_data[8:12] != b'WEBP':
                continue
            return True, fmt
    return False, ""


def process_image(
    file_data: bytes,
    profile: dict,
) -> tuple[bytes, int, int, bytes | None]:
    """
    处理上传图片
    返回: (处理后的图片数据, 宽, 高, 缩略图数据)
    """
    # 1. 验证
    valid, fmt = validate_image(file_data)
    if not valid:
        raise ValueError("无效的图片文件")
    
    # 2. 打开图片
    img = Image.open(io.BytesIO(file_data))
    
    # 3. 处理 EXIF 方向
    if profile.get("keep_orientation", True):
        from PIL import ImageOps
        img = ImageOps.exif_transpose(img)
    
    # 4. 去除 EXIF
    if profile.get("strip_exif", True):
        # 转为 RGB 去除 alpha 通道和 EXIF
        if img.mode in ('RGBA', 'P'):
            img = img.convert('RGB')
    
    # 5. 尺寸缩放
    max_w = profile.get("max_width", 2048)
    max_h = profile.get("max_height", 4096)
    if img.width > max_w or img.height > max_h:
        img.thumbnail((max_w, max_h), Image.LANCZOS)
    
    width, height = img.size
    
    # 6. 编码输出
    output_fmt = profile.get("output_format", "jpeg")
    if output_fmt == "original":
        output_fmt = fmt if fmt != "gif" else "png"
    
    quality = profile.get("jpeg_quality", 85)
    buffer = io.BytesIO()
    
    if output_fmt in ("jpeg", "jpg"):
        img.save(buffer, format="JPEG", quality=quality, optimize=True)
    elif output_fmt == "webp":
        img.save(buffer, format="WEBP", quality=quality)
    else:
        img.save(buffer, format="PNG", optimize=True)
    
    processed = buffer.getvalue()
    
    # 7. 生成缩略图
    thumb_data = None
    thumb_sizes = profile.get("thumbnails", [(200, 200)])
    if thumb_sizes:
        thumb_size = thumb_sizes[0]  # 最小缩略图
        thumb = img.copy()
        thumb.thumbnail(thumb_size, Image.LANCZOS)
        thumb_buf = io.BytesIO()
        thumb.save(thumb_buf, format="JPEG", quality=75)
        thumb_data = thumb_buf.getvalue()
    
    return processed, width, height, thumb_data
```

### 8.3 配额检查与扣减（Redis + DB 双写）

```python
import redis

class QuotaManager:
    """存储配额管理器"""
    
    def __init__(self, db_session, redis_client: redis.Redis):
        self.db = db_session
        self.r = redis_client
    
    async def check_and_reserve(
        self,
        user_id: int,
        file_size: int,
        membership_tier: str,
    ) -> tuple[bool, str]:
        """
        检查配额并预占空间
        返回: (是否允许, 原因)
        """
        tier = STORAGE_QUOTA_TIERS[membership_tier]
        
        # 1. 检查单文件大小
        if file_size > tier["max_file_size"]:
            return False, f"文件大小超过限制 ({tier['max_file_size'] // 1024 // 1024}MB)"
        
        # 2. Redis 原子检查日限制
        daily_key = f"upload:daily:{user_id}:{date.today()}"
        daily_used = self.r.incr(daily_key)
        if daily_used == 1:
            self.r.expire(daily_key, 86400 * 2)  # 2天过期
        
        if daily_used > tier["daily_upload_limit"]:
            self.r.decr(daily_key)
            return False, f"今日上传次数已达上限 ({tier['daily_upload_limit']}次)"
        
        # 3. Redis 检查总容量（乐观）
        used_key = f"storage:used:{user_id}"
        current_used = int(self.r.get(used_key) or 0)
        if current_used + file_size > tier["total_quota"]:
            self.r.decr(daily_key)
            # 从 DB 精确校验
            quota = await self._get_db_quota(user_id)
            if quota.used_bytes + file_size > tier["total_quota"]:
                return False, f"存储空间不足"
        
        # 4. 预占容量（Redis）
        self.r.incrby(used_key, file_size)
        
        return True, ""
    
    async def commit_usage(self, user_id: int, file_size: int):
        """上传成功后写入DB"""
        await self.db.execute(
            """UPDATE user_storage_quota 
               SET used_bytes = used_bytes + :size,
                   file_count = file_count + 1,
                   updated_at = NOW()
               WHERE user_id = :uid""",
            {"size": file_size, "uid": user_id}
        )
    
    async def rollback_reservation(self, user_id: int, file_size: int):
        """上传失败回滚预占"""
        self.r.decrby(f"storage:used:{user_id}", file_size)
        self.r.decr(f"upload:daily:{user_id}:{date.today()}")
```

### 9.2 URL 签名生成

```python
import hashlib
import time

def generate_signed_url(
    cdn_domain: str,
    file_key: str,
    auth_key: str,
    expire_seconds: int = 3600,
    process_params: dict | None = None,
) -> str:
    """生成 CDN 带鉴权的签名 URL"""
    expire_time = int(time.time()) + expire_seconds
    
    # 构建 URI
    uri = f"/{file_key}"
    
    # 阿里云 Type-A 鉴权
    # md5(uri-timestamp-rand-uid-key)
    rand = "0"
    uid = "0"
    sign_str = f"{uri}-{expire_time}-{rand}-{uid}-{auth_key}"
    sign = hashlib.md5(sign_str.encode()).hexdigest()
    
    base_url = f"https://{cdn_domain}{uri}"
    params = f"auth_key={expire_time}-{rand}-{uid}-{sign}"
    
    # 图片处理参数
    if process_params:
        process_str = build_oss_process(process_params)
        return f"{base_url}?{params}&{process_str}"
    
    return f"{base_url}?{params}"


def build_oss_process(params: dict) -> str:
    """构建 OSS 图片处理参数"""
    parts = []
    if "width" in params:
        parts.append(f"image/resize,w_{params['width']}")
    if "quality" in params:
        parts.append(f"image/quality,q_{params['quality']}")
    if "format" in params:
        parts.append(f"image/format,{params['format']}")
    
    return "x-oss-process=" + "/".join(parts) if parts else ""
```

```python
                file_size=existing_file.file_size,
                file_hash=request.file_hash,
                image_width=existing_file.image_width,
                image_height=existing_file.image_height,
                owner_type="user",
                owner_id=user_id,
                biz_type=request.biz_type,
                biz_id=request.biz_id,
                storage_tier=existing_file.storage_tier,
                storage_backend=existing_file.storage_backend,
                bucket=existing_file.bucket,
                audit_status="approved" if existing_file.audit_status == "approved" else "pending",
                cdn_url=existing_file.cdn_url,
            )
            session.add(new_file)
            await session.commit()
            
            return UploadInitResponse(
                upload_id=generate_upload_id(),
                file_id=new_file.id,
                status="dedup_hit",
                cdn_url=new_file.cdn_url,
                audit_status=new_file.audit_status,
            )
    
    # 3. 新上传
    upload_id = generate_upload_id()
    chunk_size = request.chunk_size or 4 * 1024 * 1024
    chunk_count = math.ceil(request.file_size / chunk_size)
    file_key = generate_file_key(request.file_category, request.file_name, upload_id)
    
    # 生成预签名 URL
    presigned_urls = []
    for i in range(chunk_count):
        url = oss_client.generate_presigned_upload_url(
            bucket=OSS_BUCKET,
            key=file_key,
            part_number=i + 1,
            expires=3600,
        )
        presigned_urls.append({
            "partNumber": i + 1,
            "uploadUrl": url,
            "expiresAt": (datetime.utcnow() + timedelta(hours=1)).isoformat(),
        })
    
    # 创建上传会话
    upload_session = FileUploadSession(
        upload_id=upload_id,
        user_id=user_id,
        file_name=request.file_name,
        file_type=request.file_type,
        file_size=request.file_size,
        file_hash=request.file_hash,
        total_chunks=chunk_count,
        chunk_size=chunk_size,
        status="uploading",
    )
    session.add(upload_session)
    await session.commit()
    
    return UploadInitResponse(
        upload_id=upload_id,
        file_id=None,
        status="new",
        chunk_count=chunk_count,
        presigned_urls=presigned_urls,
    )
```

### 12.1 Flutter Upload SDK

```dart
/// 文件上传 SDK
class FileUploadSDK {
  final Dio _dio;
  final String _baseUrl;
  
  FileUploadSDK({required String baseUrl, required Dio dio})
      : _baseUrl = baseUrl,
        _dio = dio;
  
  /// 上传文件（自动分片 + 断点续传）
  Future<FileUploadResult> upload(
    File file, {
    required String fileCategory,
    String? bizType,
    int? bizId,
    int chunkSize = 4 * 1024 * 1024, // 4MB
    ProgressCallback? onProgress,
  }) async {
    // 1. 计算文件哈希
    final fileHash = await _computeHash(file);
    final fileSize = await file.length();
    
    // 2. 初始化上传
    final initResp = await _dio.post('$_baseUrl/api/v1/files/upload/init', data: {
      'fileName': path.basename(file.path),
      'fileType': _getMimeType(file.path),
      'fileSize': fileSize,
      'fileHash': 'sha256:$fileHash',
      'fileCategory': fileCategory,
      'bizType': bizType,
      'bizId': bizId,
      'chunkSize': chunkSize,
    });
    
    final initData = initResp.data['data'];
    
    // 3. 秒传命中，直接返回
    if (initData['status'] == 'dedup_hit') {
      return FileUploadResult(
        fileId: initData['fileId'],
        cdnUrl: initData['cdnUrl'],
        auditStatus: initData['auditStatus'],
        isDedup: true,
      );
    }
    
    // 4. 分片上传
    final uploadId = initData['uploadId'] as String;
    final presignedUrls = (initData['presignedUrls'] as List).cast<Map<String, dynamic>>();
    final parts = <Map<String, dynamic>>[];
    
    // 检查本地断点续传记录
    final resumeState = await _loadResumeState(uploadId);
    final completedParts = resumeState?.completedParts ?? {};
    
    for (final urlInfo in presignedUrls) {
      final partNumber = urlInfo['partNumber'] as int;
      final uploadUrl = urlInfo['uploadUrl'] as String;
      
      // 跳过已完成的分片
      if (completedParts.containsKey(partNumber)) {
        parts.add({
          'partNumber': partNumber,
          'etag': completedParts[partNumber],
        });
        continue;
      }
      
      // 读取分片数据
      final chunkData = await _readChunk(file, partNumber - 1, chunkSize);
      
      // 直接上传到 OSS (不经过后端)
      final uploadResp = await Dio().put(
        uploadUrl,
        data: Stream.fromIterable([chunkData]),
        options: Options(
          headers: {'Content-Length': chunkData.length},
          sendTimeout: const Duration(seconds: 30),
        ),
        onSendProgress: (sent, total) {
          if (onProgress != null) {
            // 计算整体进度
            final completed = (partNumber - 1) * chunkSize;
            onProgress(completed + sent, fileSize);
          }
        },
      );
      
      final etag = uploadResp.headers.value('ETag') ?? '';
      parts.add({'partNumber': partNumber, 'etag': etag});
      
      // 保存断点
      completedParts[partNumber] = etag;
      await _saveResumeState(uploadId, completedParts);
    }
    
    // 5. 完成上传
    final completeResp = await _dio.post(
      '$_baseUrl/api/v1/files/upload/$uploadId/complete',
      data: {'parts': parts, 'fileHash': 'sha256:$fileHash'},
    );
    
    final completeData = completeResp.data['data'];
    
    // 6. 清除断点记录
    await _clearResumeState(uploadId);
    
    return FileUploadResult(
      fileId: completeData['fileId'],
      auditStatus: completeData['auditStatus'],
      isDedup: false,
    );
  }
  
  /// 轮询等待审核结果
  Future<FileUploadResult> waitForAudit(
    int fileId, {
    Duration timeout = const Duration(seconds: 30),
    Duration interval = const Duration(seconds: 2),
  }) async {
    final deadline = DateTime.now().add(timeout);
    
    while (DateTime.now().isBefore(deadline)) {
      final resp = await _dio.get('$_baseUrl/api/v1/files/$fileId');
      final data = resp.data['data'];
      final status = data['auditStatus'] as String;
      
      if (status == 'approved') {
        return FileUploadResult(
          fileId: fileId,
          cdnUrl: data['cdnUrl'],
          auditStatus: 'approved',
          isDedup: false,
        );
      } else if (status == 'rejected') {
        throw FileAuditRejectedException('文件审核未通过');
      }
      
      await Future.delayed(interval);
    }
    
    // 超时仍为 pending，返回当前状态（客户端可继续轮询）
    final resp = await _dio.get('$_baseUrl/api/v1/files/$fileId');
    final data = resp.data['data'];
    return FileUploadResult(
      fileId: fileId,
      auditStatus: data['auditStatus'],
      isDedup: false,
    );
  }
  
  Future<String> _computeHash(File file) async {
    final sha256 = crypto.Sha256();
    final stream = file.openRead();
    await for (final chunk in stream) {
      sha256.update(chunk);
    }
    return hex.encode(sha256.digest());
  }
  
  Future<Uint8List> _readChunk(File file, int index, int chunkSize) async {
    final raf = await file.open(mode: FileMode.read);
    try {
      await raf.setPosition(index * chunkSize);
      final remaining = await file.length() - (index * chunkSize);
      final readSize = min(chunkSize, remaining);
      return await raf.read(readSize);
    } finally {
      await raf.close();
    }
  }
}

class FileUploadResult {
  final int? fileId;
  final String? cdnUrl;
  final String auditStatus;
  final bool isDedup;
  
  FileUploadResult({
    required this.fileId,
    this.cdnUrl,
    required this.auditStatus,
    required this.isDedup,
  });
}
```

## 13. 错误处理

### 13.1 错误码定义

| 错误码 | HTTP 状态 | 含义 | 客户端处理 |
|--------|-----------|------|------------|
| FILE_001 | 400 | 不支持的文件类型 | 提示用户更换文件 |
| FILE_002 | 400 | 文件大小超限 | 提示压缩或更换 |
| FILE_003 | 413 | 文件超过最大限制 | 提示文件过大 |
| FILE_004 | 403 | 存储空间不足 | 引导升级会员或清理 |
| FILE_005 | 429 | 上传频率超限 | 提示稍后重试 |
| FILE_006 | 404 | 文件不存在 | 刷新页面或重新上传 |
| FILE_007 | 403 | 无权访问该文件 | 检查登录状态 |
| FILE_008 | 403 | 文件审核未通过 | 提示重新上传合规内容 |
| FILE_009 | 409 | 上传冲突 (重复提交) | 忽略，使用已有结果 |
| FILE_010 | 503 | 存储服务暂不可用 | 自动重试 (指数退避) |
| FILE_011 | 400 | 上传会话已过期 | 重新初始化上传 |
| FILE_012 | 400 | 分片校验失败 | 重新上传失败分片 |

```dart
/// 上传重试配置
class UploadRetryPolicy {
  /// 最大重试次数
  static const maxRetries = 3;
  
  /// 基础延迟 (毫秒)
  static const baseDelay = 1000;
  
  /// 最大延迟 (毫秒)
  static const maxDelay = 10000;
  
  /// 可重试的错误码
  static const retryableErrors = {
    'FILE_005', // 频率限制
    'FILE_010', // 服务不可用
    'FILE_012', // 分片校验失败
  };
  
  static Duration getDelay(int retryCount) {
    final delay = baseDelay * pow(2, retryCount);
    return Duration(milliseconds: min(delay.toInt(), maxDelay));
  }
}
```
