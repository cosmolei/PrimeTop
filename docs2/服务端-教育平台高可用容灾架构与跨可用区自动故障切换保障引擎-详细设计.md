# 服务端-教育平台高可用容灾架构与跨可用区自动故障切换保障引擎-详细设计

## 1. 概述

### 1.1 功能定位

本模块是 PrimeTop 教育平台的基础设施级高可用保障引擎，负责在可用区（AZ）故障、区域级灾难、服务节点异常等场景下，保障平台核心学习功能的连续性和数据完整性。

与现有文档的关系：
- **数据备份与容灾策略**：聚焦数据级备份（快照、归档、恢复），本设计聚焦服务级/平台级高可用与故障切换
- **AI模型调用多供应商容灾切换**：聚焦AI推理层的模型切换，本设计覆盖全平台所有核心服务
- **客户端功能模块容灾隔离**：聚焦客户端降级体验，本设计聚焦服务端架构设计
- **智能故障检测与自动恢复自愈引擎**：聚焦故障检测与自愈策略，本设计聚焦容灾架构与跨可用区切换

### 1.2 设计目标

| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 核心服务可用性 | ≥ 99.95% | 用户注册登录、AI辅导、错题本、学习记录 |
| 非核心服务可用性 | ≥ 99.5% | 学情报告、运营活动、积分商城 |
| RPO（恢复点目标） | ≤ 30s | 核心数据丢失窗口 |
| RTO（恢复时间目标） | ≤ 5min | 核心服务恢复时间 |
| 故障检测时间 | ≤ 10s | 从故障发生到告警触发 |
| 自动切换时间 | ≤ 60s | 从决策到流量切换完成 |
| 年度容灾演练 | ≥ 4次 | 季度级混沌演练 |

### 1.3 适用范围

覆盖 PrimeTop 平台全部核心服务：
- 用户服务（认证、档案、会员）
- AI 服务（大模型调用、Prompt 编排、RAG 检索）
- 学习服务（记录、进度、任务）
- 题目服务（题库、解析、组卷）
- 错题服务（收录、复习）
- 内容服务（教材、知识点、课程）
- 支付服务（订单、订阅、权益）
- 消息服务（通知、推送）

## 2. 整体容灾架构

### 2.1 部署架构总览

采用 **同城双活 + 异地灾备（Warm Standby）** 三级容灾架构：

```
                    ┌─────────────────────────────────────────┐
                    │           Global DNS / GSLB             │
                    │    (智能DNS解析 + 健康检查 + 流量路由)    │
                    └──────────────┬──────────────────────────┘
                                   │
                    ┌──────────────┴──────────────┐
                    │                              │
              ┌─────▼─────┐                ┌──────▼─────┐
              │  主机房(P)  │                │  备机房(S)  │
              │  同城AZ-A   │                │  同城AZ-B   │
              │  全量服务   │                │  全量服务   │
              │  读写流量   │                │  只读/灾备  │
              └─────┬─────┘                └──────┬─────┘
                    │                              │
              ┌─────┴──────────────────────────────┴─────┐
              │           同城低延迟专线互联               │
              │      (RTT ≤ 2ms, 带宽 ≥ 10Gbps)           │
              └────────────────────────────────────────────┘
                              │
                    ┌─────────▼─────────┐
                    │   异地灾备中心(DR)  │
                    │   跨区域 / 跨城市   │
                    │   Warm Standby    │
                    │   异步复制 + 按需激活│
                    └───────────────────┘
```

### 2.2 机房角色定义

| 机房 | 角色 | 日常状态 | 故障切换目标 |
| --- | --- | --- | --- |
| AZ-A（主） | Primary | 承接100%读写流量 | — |
| AZ-B（同备） | Secondary-Active | 承接只读查询、热备 | 接管100%读写流量（≤5min） |
| DR（异地） | Warm Standby | 异步复制、关键服务冷热混合 standby | 接管核心服务（≤30min） |

### 2.3 服务分级与容灾策略

| 服务等级 | 包含服务 | 容灾策略 | RPO | RTO |
| --- | --- | --- | --- | --- |
| **L1-核心** | 认证、支付、AI辅导、错题 | 同城双活同步复制 + 异地热备 | ≤ 1s | ≤ 1min |
| **L2-重要** | 学习记录、题目服务、内容服务 | 同城双活准同步 + 异地温备 | ≤ 10s | ≤ 5min |
| **L3-一般** | 学情报告、运营活动、积分商城 | 主备异步复制 + 异地冷备 | ≤ 60s | ≤ 15min |
| **L4-辅助** | 数据导出、日志查询、后台统计 | 单机房 + 定期备份 | ≤ 1h | ≤ 2h |

## 4. 核心引擎设计

### 4.1 健康检查管理器（HealthCheckManager）

负责对每个机房中的每个服务执行周期性健康检查，维护实时健康状态。

```java
/**
 * 健康检查管理器
 * 采用多维度检测策略：HTTP探针 + TCP探针 + 自定义业务探针
 */
@Component
@Singleton
public class HealthCheckManager {

    private final Map<String, ServiceHealth> healthMap = new ConcurrentHashMap<>();
    private final ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(8);
    
    @Value("${dr.healthcheck.globalInterval:5}")
    private int globalIntervalSeconds;
    
    /**
     * 启动所有服务的健康检查
     */
    public void start() {
        List<DrServiceConfig> configs = serviceConfigRepository.findAllActive();
        for (DrServiceConfig config : configs) {
            scheduleHealthCheck(config);
        }
    }
    
    private void scheduleHealthCheck(DrServiceConfig config) {
        scheduler.scheduleAtFixedRate(() -> {
            try {
                checkService(config);
            } catch (Exception e) {
                log.error("Health check error for service: {}", config.getServiceName(), e);
            }
        }, 0, config.getHealthCheckInterval(), TimeUnit.SECONDS);
    }
    
    /**
     * 执行单次服务健康检查（多机房并行）
     */
    private void checkService(DrServiceConfig config) {
        List<DataCenter> dcs = dataCenterRepository.findActiveByService(config.getServiceName());
        
        List<CompletableFuture<ServiceHealth>> futures = dcs.stream()
            .map(dc -> CompletableFuture.supplyAsync(() -> 
                performHealthCheck(config, dc)))
            .collect(Collectors.toList());
        
        for (int i = 0; i < dcs.size(); i++) {
            DataCenter dc = dcs.get(i);
            ServiceHealth health = futures.get(i).join();
            
            ServiceHealth previous = healthMap.get(buildKey(config.getServiceName(), dc.getDcCode()));
            ServiceHealth updated = updateHealthState(previous, health, config);
            
            healthMap.put(buildKey(config.getServiceName(), dc.getDcCode()), updated);
            
            // 触发故障检测逻辑
            if (updated.getStatus() == HealthStatus.UNHEALTHY && 
                (previous == null || previous.getStatus() != HealthStatus.UNHEALTHY)) {
                failoverEngine.evaluateFailover(config, dc, updated);
            }
        }
    }
    
    /**
     * 多层级健康检查
     */
    private ServiceHealth performHealthCheck(DrServiceConfig config, DataCenter dc) {
        String healthUrl = dc.getHealthEndpoint() + config.getHealthCheckPath();
        
        // Layer 1: HTTP 探针（轻量级，判断服务存活）
        HealthProbeResult httpResult = httpProbe(healthUrl, config.getHealthCheckTimeout());
        
        if (!httpResult.isSuccess()) {
            return ServiceHealth.builder()
                .serviceName(config.getServiceName())
                .dcCode(dc.getDcCode())
                .status(HealthStatus.UNHEALTHY)
                .consecutiveFailures(incrementFailures(config, dc))
                .lastCheckTime(LocalDateTime.now())
                .errorMessage(httpResult.getError())
                .build();
        }
        
        // Layer 2: 延迟检测（判断是否降级）
        long latency = httpResult.getLatencyMs();
        long latencyThreshold = calculateLatencyThreshold(config.getServiceLevel());
        
        HealthStatus status = latency > latencyThreshold 
            ? HealthStatus.DEGRADED 
            : HealthStatus.HEALTHY;
        
        return ServiceHealth.builder()
            .serviceName(config.getServiceName())
            .dcCode(dc.getDcCode())
            .status(status)
            .consecutiveFailures(0) // 成功则重置
            .latencyMs(latency)
            .lastCheckTime(LocalDateTime.now())
            .build();
    }
    
    /**
     * Layer 3: 深度业务探针（针对L1核心服务）
     * 检查数据库连接、缓存连接、下游依赖等
     */
    private HealthStatus deepBusinessProbe(String serviceName, String dcCode) {
        DeepHealthResponse response = restTemplate.getForObject(
            buildDeepHealthUrl(serviceName, dcCode),
            DeepHealthResponse.class
        );
        
        if (response == null) return HealthStatus.UNKNOWN;
        
        // 检查关键依赖
        boolean dbOk = response.getComponents().get("database") == ComponentStatus.UP;
        boolean cacheOk = response.getComponents().get("redis") == ComponentStatus.UP;
        boolean mqOk = response.getComponents().get("rabbitmq") == ComponentStatus.UP;
        
        if (dbOk && cacheOk && mqOk) return HealthStatus.HEALTHY;
        if (dbOk) return HealthStatus.DEGRADED;
        return HealthStatus.UNHEALTHY;
    }
    
    /**
     * 状态转换：连续失败计数 + 滞后窗口
     */
    private ServiceHealth updateHealthState(ServiceHealth previous, ServiceHealth current, 
                                            DrServiceConfig config) {
        if (previous == null) return current;
        
        // 状态滞后(hysteresis)：防止在健康/不健康边界频繁抖动
        // UP -> DOWN: 需要连续失败 ≥ unhealthyThreshold
        // DOWN -> UP: 需要连续成功 ≥ healthyThreshold（设为 unhealthyThreshold * 2）
        if (previous.getStatus() != HealthStatus.UNHEALTHY 
            && current.getStatus() == HealthStatus.UNHEALTHY) {
            int failures = previous.getConsecutiveFailures() + 1;
            if (failures < config.getUnhealthyThreshold()) {
                // 还没到阈值，保持非UNHEALTHY状态
                return ServiceHealth.builder()
                    .serviceName(current.getServiceName())
                    .dcCode(current.getDcCode())
                    .status(HealthStatus.DEGRADED)
                    .consecutiveFailures(failures)
                    .lastCheckTime(current.getLastCheckTime())
                    .errorMessage(current.getErrorMessage())
                    .build();
            }
        }
        
        if (previous.getStatus() == HealthStatus.UNHEALTHY 
            && current.getStatus() == HealthStatus.HEALTHY) {
            // 恢复也需要连续成功
            int recoveryThreshold = config.getUnhealthyThreshold() * 2;
            // 此处需要额外维护连续成功计数，简化处理
        }
        
        return current;
    }
    
    private long calculateLatencyThreshold(String serviceLevel) {
        return switch (serviceLevel) {
            case "L1" -> 500L;   // 核心服务：500ms
            case "L2" -> 1000L;  // 重要服务：1s
            case "L3" -> 2000L;  // 一般服务：2s
            default -> 5000L;    // 辅助服务：5s
        };
    }
}
```

### 4.2 故障切换决策引擎（FailoverDecisionEngine）

```java
/**
 * 故障切换决策引擎
 * 根据健康检查结果、服务等级、历史数据综合决策
 */
@Component
public class FailoverDecisionEngine {

    /**
     * 评估是否需要执行故障切换
     */
    public void evaluateFailover(DrServiceConfig config, DataCenter failedDC, 
                                  ServiceHealth health) {
        // 1. 检查冷却期（避免频繁切换）
        if (isInCooldown(config, failedDC)) {
            log.warn("Service {} in DC {} failover in cooldown, skip", 
                config.getServiceName(), failedDC.getDcCode());
            return;
        }
        
        // 2. 检查策略类型
        if (config.getFailoverStrategy().equals("MANUAL")) {
            // 仅告警，不自动切换
            alertService.sendUrgentAlert(
                AlertLevel.P1,
                String.format("服务 %s 在机房 %s 不可用，需人工介入切换", 
                    config.getServiceName(), failedDC.getDcCode()),
                buildAlertContext(config, failedDC, health)
            );
            return;
        }
        
        // 3. 判断目标机房是否可用
        Optional<DataCenter> targetDC = selectTargetDC(config, failedDC);
        if (targetDC.isEmpty()) {
            log.error("No available target DC for service {} failover!", config.getServiceName());
            alertService.sendUrgentAlert(
                AlertLevel.P0,
                String.format("服务 %s 故障且无可用备机房！", config.getServiceName()),
                buildAlertContext(config, failedDC, health)
            );
            return;
        }
        
        // 4. SEMI_AUTO 策略：等待人工确认
        if (config.getFailoverStrategy().equals("SEMI_AUTO")) {
            requestManualConfirmation(config, failedDC, targetDC.get(), health);
            return;
        }
        
        // 5. AUTO 策略：自动执行
        executeFailover(config, failedDC, targetDC.get(), 
            FailoverTriggerType.AUTO, health);
    }
    
    /**
     * 选择最佳目标机房
     * 优先级：同城备 > 异地灾备
     */
    private Optional<DataCenter> selectTargetDC(DrServiceConfig config, 
                                                 DataCenter failedDC) {
        // 先查同城备机房
        Optional<DataCenter> secondary = dataCenterRepository
            .findByRoleAndStatus(DCRole.SECONDARY, DCStatus.ACTIVE)
            .stream()
            .filter(dc -> isServiceHealthyIn(config.getServiceName(), dc.getDcCode()))
            .filter(dc -> hasCapacity(config, dc))
            .min(Comparator.comparingInt(DataCenter::getWeight).reversed());
        
        if (secondary.isPresent()) return secondary;
        
        // 再查异地灾备
        return dataCenterRepository
            .findByRoleAndStatus(DCRole.DISASTER_RECOVERY, DCStatus.STANDBY)
            .stream()
            .filter(dc -> isServiceHealthyIn(config.getServiceName(), dc.getDcCode()))
            .filter(dc -> hasCapacity(config, dc))
            .findFirst();
    }
    
    /**
     * 切换前置检查
     */
    private FailoverPrecheckResult precheck(DrServiceConfig config, 
                                             DataCenter source, DataCenter target) {
        FailoverPrecheckResult result = new FailoverPrecheckResult();
        
        // 检查1: 目标机房服务健康
        ServiceHealth targetHealth = healthCheckManager
            .getHealth(config.getServiceName(), target.getDcCode());
        if (targetHealth.getStatus() == HealthStatus.UNHEALTHY) {
            return result.fail("Target DC service unhealthy");
        }
        
        // 检查2: 数据同步延迟
        long replicationLag = replicationMonitor.getLagSeconds(
            config.getServiceName(), source.getDcCode(), target.getDcCode());
        long maxAcceptableLag = getMaxAcceptableLag(config.getServiceLevel());
        if (replicationLag > maxAcceptableLag) {
            log.warn("Replication lag {}s exceeds max {}s for {}", 
                replicationLag, maxAcceptableLag, config.getServiceName());
            // 对于L1服务，延迟过大需要警告但仍可切换；对于其他服务直接拒绝
            if (config.getServiceLevel().equals("L1")) {
                result.addWarning("Replication lag high: " + replicationLag + "s");
            } else {
                return result.fail("Replication lag too high: " + replicationLag + "s");
            }
        }
        
        // 检查3: 目标机房容量
        int targetLoad = loadMonitor.getCurrentLoad(target.getDcCode());
        int targetCapacity = loadMonitor.getCapacity(target.getDcCode());
        int sourceLoad = loadMonitor.getCurrentLoad(source.getDcCode());
        if (targetLoad + sourceLoad > targetCapacity * 0.9) {
            return result.fail("Target DC capacity insufficient: " 
                + (targetLoad + sourceLoad) + " > " + (targetCapacity * 0.9));
        }
        
        // 检查4: 正在进行的切换（避免并发切换）
        if (failoverEventRepository.hasActiveFailover(config.getServiceName())) {
            return result.fail("Another failover in progress for this service");
        }
        
        return result.pass();
    }
    
    private long getMaxAcceptableLag(String serviceLevel) {
        return switch (serviceLevel) {
            case "L1" -> 1L;
            case "L2" -> 10L;
            case "L3" -> 60L;
            default -> 300L;
        };
    }
}
```

### 4.3 故障切换执行器（FailoverExecutor）

```java
/**
 * 故障切换执行器
 * 按照预定义步骤序列执行切换操作
 */
@Component
public class FailoverExecutor {
    
    /**
     * 执行故障切换
     * 标准流程：记录事件 -> 排空源流量 -> 提升备库 -> 切换DNS -> 验证 -> 完成
     */
    @Transactional
    public FailoverResult executeFailover(DrServiceConfig config, 
                                          DataCenter source, DataCenter target,
                                          FailoverTriggerType trigger, 
                                          ServiceHealth health) {
        String eventId = UUID.randomUUID().toString();
        LocalDateTime detectionTime = health.getLastCheckTime();
        
        // 创建事件记录
        DrFailoverEvent event = createEvent(eventId, config, source, target, 
            trigger, detectionTime);
        
        try {
            // Step 1: 预检查
            event.setStatus("IN_PROGRESS");
            event.setStartTime(LocalDateTime.now());
            failoverEventRepository.save(event);
            
            FailoverPrecheckResult precheck = decisionEngine.precheck(config, source, target);
            if (!precheck.isPass()) {
                event.setStatus("FAILED");
                event.setDetail(buildDetail("precheck_failed", precheck.getReason()));
                failoverEventRepository.save(event);
                return FailoverResult.failed(precheck.getReason());
            }
            
            // Step 2: 源机房流量排空
            executeStep(event, "DRAIN_SOURCE", () -> {
                trafficManager.drainTraffic(source.getDcCode(), config.getServiceName());
                // 等待排空完成（最多30秒）
                awaitDrainComplete(source.getDcCode(), config.getServiceName(), Duration.ofSeconds(30));
            });
            
            // Step 3: 数据库角色切换（备库提升为主库）
            if (requiresDBPromotion(config.getServiceLevel())) {
                executeStep(event, "DB_PROMOTION", () -> {
                    databaseFailoverManager.promoteStandby(
                        config.getServiceName(), 
                        source.getDcCode(), 
                        target.getDcCode()
                    );
                    // 等待数据库切换完成
                    awaitDBReady(target.getDcCode(), Duration.ofSeconds(60));
                });
            }
            
            // Step 4: Redis 主从切换
            executeStep(event, "REDIS_FAILOVER", () -> {
                redisClusterManager.failover(
                    config.getServiceName(),
                    source.getDcCode(),
                    target.getDcCode()
                );
            });
            
            // Step 5: 消息队列切换
            executeStep(event, "MQ_FAILOVER", () -> {
                mqManager.switchMaster(
                    config.getServiceName(),
                    target.getDcCode()
                );
            });
            
            // Step 6: DNS/流量路由切换
            executeStep(event, "TRAFFIC_SWITCH", () -> {
                trafficManager.switchTraffic(
                    config.getServiceName(),
                    source.getDcCode(),
                    target.getDcCode(),
                    TrafficSwitchMode.GRADUAL  // 渐进式切换
                );
            });
            
            // Step 7: 服务验证
            executeStep(event, "SERVICE_VALIDATION", () -> {
                boolean healthy = validateService(config, target, Duration.ofSeconds(60));
                if (!healthy) {
                    throw new FailoverException("Service validation failed after failover");
                }
            });
            
            // Step 8: 更新机房角色
            executeStep(event, "ROLE_UPDATE", () -> {
                dataCenterRepository.updateRole(source.getDcCode(), DCRole.SECONDARY);
                dataCenterRepository.updateRole(target.getDcCode(), DCRole.PRIMARY);
            });
            
            // 完成
            event.setStatus("COMPLETED");
            event.setCompleteTime(LocalDateTime.now());
            event.setRtoActual((int) Duration.between(
                detectionTime, event.getCompleteTime()).getSeconds());
            event.setRpoActual(replicationMonitor.getFinalLag(
                config.getServiceName(), source.getDcCode()));
            failoverEventRepository.save(event);
            
            // 发送通知
            notificationService.notifyFailoverCompleted(event);
            
            // 触发回切预案生成
            rollbackPlanner.generateRollbackPlan(event);
            
            return FailoverResult.success(event);
            
        } catch (FailoverStepException e) {
            log.error("Failover step failed: {}", e.getStepName(), e);
            event.setStatus("FAILED");
            event.setDetail(buildDetail(e.getStepName(), e.getMessage()));
            failoverEventRepository.save(event);
            
            // 自动回滚已执行步骤
            rollback(event);
            
            alertService.sendUrgentAlert(AlertLevel.P0,
                String.format("故障切换失败！服务: %s, 步骤: %s", 
                    config.getServiceName(), e.getStepName()),
                Map.of("event", event, "error", e.getMessage()));
            
            return FailoverResult.failed(e.getMessage());
        }
    }
    
    /**
     * 步骤执行包装器：记录每步耗时和结果
     */
    private void executeStep(DrFailoverEvent event, String stepName, 
                             Runnable step) throws FailoverStepException {
        LocalDateTime start = LocalDateTime.now();
        try {
            log.info("[Failover {}] Executing step: {}", event.getEventId(), stepName);
            step.run();
            long durationMs = Duration.between(start, LocalDateTime.now()).toMillis();
            log.info("[Failover {}] Step {} completed in {}ms", 
                event.getEventId(), stepName, durationMs);
            
            appendStepLog(event, stepName, "SUCCESS", durationMs, null);
            
        } catch (Exception e) {
            long durationMs = Duration.between(start, LocalDateTime.now()).toMillis();
            appendStepLog(event, stepName, "FAILED", durationMs, e.getMessage());
            throw new FailoverStepException(stepName, e.getMessage(), e);
        }
    }
    
    /**
     * 服务验证：功能检查 + 烟雾测试
     */
    private boolean validateService(DrServiceConfig config, DataCenter target,
                                     Duration timeout) {
        long deadline = System.currentTimeMillis() + timeout.toMillis();
        int attempts = 0;
        
        while (System.currentTimeMillis() < deadline) {
            attempts++;
            try {
                // 基础健康检查
                ServiceHealth health = healthCheckManager
                    .getHealth(config.getServiceName(), target.getDcCode());
                if (health.getStatus() != HealthStatus.HEALTHY) {
                    Thread.sleep(2000);
                    continue;
                }
                
                // 烟雾测试：发送测试请求验证核心功能
                SmokeTestResult smoke = smokeTestRunner.run(
                    config.getServiceName(), target.getDcCode());
                if (smoke.isPass()) {
                    log.info("Service {} validation passed after {} attempts", 
                        config.getServiceName(), attempts);
                    return true;
                }
                
                Thread.sleep(2000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return false;
            } catch (Exception e) {
                log.warn("Validation attempt {} failed: {}", attempts, e.getMessage());
                Thread.sleep(2000);
            }
        }
        
        log.error("Service {} validation failed after {} attempts", 
            config.getServiceName(), attempts);
        return false;
    }
}
```

```java
/**
 * 流量编排管理器
 * 通过DNS、负载均衡、API网关三层控制流量路由
 */
@Component
public class TrafficOrchestrator {
    
    /**
     * 渐进式流量切换
     * 分3阶段：10% → 50% → 100%
     */
    public void switchTraffic(String serviceName, String fromDC, String toDC,
                              TrafficSwitchMode mode) {
        if (mode == TrafficSwitchMode.INSTANT) {
            // 瞬间切换（仅L1服务紧急场景）
            updateDNSWeights(serviceName, fromDC, 0, toDC, 100);
            updateGatewayWeights(serviceName, fromDC, 0, toDC, 100);
            return;
        }
        
        // 渐进式切换
        int[] stages = {10, 50, 100};
        int[] holdSeconds = {15, 15, 0}; // 每阶段保持时间
        
        for (int i = 0; i < stages.length; i++) {
            int targetWeight = stages[i];
            int sourceWeight = 100 - targetWeight;
            
            // 更新DNS权重
            updateDNSWeights(serviceName, fromDC, sourceWeight, toDC, targetWeight);
            
            // 更新API网关权重
            updateGatewayWeights(serviceName, fromDC, sourceWeight, toDC, targetWeight);
            
            // 等待DNS传播
            if (holdSeconds[i] > 0) {
                try {
                    Thread.sleep(holdSeconds[i] * 1000L);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    return;
                }
            }
            
            // 检查目标机房是否有错误率飙升
            double errorRate = metricsCollector.getErrorRate(serviceName, toDC);
            if (errorRate > 0.05) { // 5% 错误率
                log.error("Error rate {}% on target DC {}, aborting traffic switch!",
                    errorRate * 100, toDC);
                throw new TrafficSwitchException(
                    "Target DC error rate too high: " + (errorRate * 100) + "%");
            }
            
            log.info("Traffic switch stage {}/{}: {}% to target DC {}",
                i + 1, stages.length, targetWeight, toDC);
        }
    }
    
    /**
     * 排空某机房流量
     */
    public void drainTraffic(String dcCode, String serviceName) {
        // Step 1: 从服务发现中注销
        serviceRegistry.deregister(serviceName, dcCode);
        
        // Step 2: API网关权重设为0
        apiGateway.updateWeight(serviceName, dcCode, 0);
        
        // Step 3: 等待活跃连接排空
        // 由调用方 awaitDrainComplete 实现
    }
    
    /**
     * 更新DNS权重（通过DNS服务商API）
     */
    private void updateDNSWeights(String serviceName, 
                                  String dc1, int weight1,
                                  String dc2, int weight2) {
        // 使用DNS服务商API（如阿里云DNS、AWS Route53）
        // 对教育平台，建议使用阿里云云解析DNS
        DNSUpdateRequest request = DNSUpdateRequest.builder()
            .domain(buildServiceDomain(serviceName))
            .records(Arrays.asList(
                DNSRecord.builder().value(getDCIP(dc1)).weight(weight1).build(),
                DNSRecord.builder().value(getDCIP(dc2)).weight(weight2).build()
            ))
            .ttl(10) // 短TTL，确保快速生效
            .build();
        
        dnsProvider.update(request);
    }
}

public enum TrafficSwitchMode {
    INSTANT,     // 瞬间切换
    GRADUAL      // 渐进式切换（推荐）
}
```

```java
/**
 * 数据库故障切换管理器
 * 通过 MHA (Master High Availability) 或 Orchestrator 管理 MySQL 主从切换
 */
@Component
public class DatabaseFailoverManager {
    
    /**
     * 提升备库为新主库
     */
    public void promoteStandby(String serviceName, String fromDC, String toDC) {
        // 1. 确认源主库状态
        MySQLNode oldMaster = mysqlNodeRepository.findPrimary(serviceName, fromDC);
        MySQLNode newMaster = mysqlNodeRepository.findStandby(serviceName, toDC);
        
        // 2. 检查复制延迟
        long lagSeconds = replicationMonitor.getMySQLLag(oldMaster, newMaster);
        if (lagSeconds > 5) {
            log.warn("MySQL replication lag {}s before promotion", lagSeconds);
            // 等待延迟收敛
            waitForReplicationCatchUp(oldMaster, newMaster, Duration.ofSeconds(10));
        }
        
        // 3. 如果旧主库还活着，确保所有事务已同步
        if (isNodeReachable(oldMaster)) {
            ensureAllTransactionsReplicated(oldMaster, newMaster);
            // 设置旧主库为只读
            setReadOnly(oldMaster);
        }
        
        // 4. 提升新主库
        promoteToPrimary(newMaster);
        
        // 5. 更新连接池配置
        updateConnectionPool(serviceName, oldMaster, newMaster);
        
        // 6. 重新建立复制关系（旧主恢复后作为新主的备库）
        if (isNodeReachable(oldMaster)) {
            setupReplication(newMaster, oldMaster);
        }
        
        log.info("Database failover completed: {} -> {}", 
            oldMaster.getHost(), newMaster.getHost());
    }
    
    /**
     * 更新所有服务实例的数据库连接池
     */
    private void updateConnectionPool(String serviceName, 
                                      MySQLNode oldMaster, MySQLNode newMaster) {
        // 通过配置中心推送新连接信息
        ConfigChangeEvent event = ConfigChangeEvent.builder()
            .namespace("database." + serviceName)
            .key("datasource.url")
            .oldValue(buildJdbcUrl(oldMaster))
            .newValue(buildJdbcUrl(newMaster))
            .reason("DATABASE_FAILOVER")
            .build();
        
        configService.publishChange(event);
        
        // 等待所有实例刷新连接池
        awaitConnectionPoolRefresh(serviceName, Duration.ofSeconds(30));
    }
}
```

```java
@Component
public class RedisClusterFailoverManager {
    
    /**
     * Redis Cluster 跨AZ故障切换
     */
    public void failover(String serviceName, String fromDC, String toDC) {
        // 获取故障AZ中的master节点列表
        List<RedisNode> failedMasters = redisClusterRepository
            .findMastersByDC(serviceName, fromDC);
        
        for (RedisNode failed : failedMasters) {
            // 找到对应的replica（在目标AZ中）
            RedisNode replica = redisClusterRepository
                .findReplica(failed, toDC);
            
            if (replica == null) {
                log.error("No available replica for Redis node {} in DC {}", 
                    failed.getNodeId(), toDC);
                continue;
            }
            
            // 执行 CLUSTER FAILOVER
            redisTemplate.execute((RedisCallback<Object>) connection -> {
                connection.clusterFailover(
                    replica.getHost(), 
                    replica.getPort(),
                    ClusterFailoverOption.TAKEOVER  // 强制接管（源master不可达）
                );
                return null;
            });
            
            // 等待提升完成
            awaitRedisNodeBecomeMaster(replica, Duration.ofSeconds(30));
        }
        
        // 更新客户端连接配置
        updateRedisClientConfig(serviceName, toDC);
        
        // 验证集群状态
        ClusterInfo clusterInfo = getClusterInfo(serviceName, toDC);
        if (clusterInfo.getClusterState() != ClusterState.OK) {
            throw new FailoverException("Redis cluster state abnormal after failover: " 
                + clusterInfo.getClusterState());
        }
    }
}
```

### 8.2 演练执行器

```java
/**
 * 容灾演练执行器
 */
@Component
public class DrillExecutor {
    
    /**
     * 执行容灾演练
     */
    public DrillResult execute(DrDrillRecord drill) {
        DrillResult.DrillResultBuilder resultBuilder = DrillResult.builder()
            .drillName(drill.getDrillName())
            .executedAt(LocalDateTime.now());
        
        try {
            // Phase 1: 演练前快照
            SystemSnapshot beforeSnapshot = systemSnapshotCollector.collect();
            resultBuilder.beforeSnapshot(beforeSnapshot);
            
            // Phase 2: 注入故障
            FaultInjection injection = buildInjection(drill);
            faultInjector.inject(injection);
            
            // Phase 3: 等待自动切换
            LocalDateTime detectionStart = LocalDateTime.now();
            FailoverDetectionResult detection = waitForDetection(injection, 
                Duration.ofSeconds(30));
            resultBuilder.detectionTimeMs(Duration.between(
                detectionStart, detection.getDetectedAt()).toMillis());
            
            if (!detection.isDetected()) {
                return resultBuilder
                    .status(DrillStatus.FAILED)
                    .failureReason("Fault not detected within timeout")
                    .build();
            }
            
            // Phase 4: 等待切换完成
            LocalDateTime switchStart = LocalDateTime.now();
            FailoverCompleteResult completion = waitForFailoverComplete(
                injection.getServiceName(), Duration.ofMinutes(5));
            resultBuilder.rtoMeasured((int) Duration.between(
                detectionStart, completion.getCompletedAt()).getSeconds());
            
            // Phase 5: 验证服务恢复
            ValidationSummary validation = validateAllServices(
                injection.getServiceName(), Duration.ofMinutes(2));
            resultBuilder.validationResult(validation);
            
            // Phase 6: 检查数据一致性
            DataConsistencyResult consistency = dataConsistencyChecker.check(
                injection.getServiceName());
            resultBuilder.rpoMeasured(consistency.getMaxDataLossSeconds());
            
            // Phase 7: 自动回切（如果配置）
            if (drill.isAutoRollback()) {
                rollback(drill);
            }
            
            // Phase 8: 生成报告
            SystemSnapshot afterSnapshot = systemSnapshotCollector.collect();
            resultBuilder.afterSnapshot(afterSnapshot);
            
            return resultBuilder
                .status(DrillStatus.SUCCESS)
                .issuesFound(collectIssues(beforeSnapshot, afterSnapshot))
                .improvements(generateImprovements(drill, resultBuilder.build()))
                .build();
            
        } catch (Exception e) {
            log.error("Drill execution failed", e);
            // 确保清理故障注入
            faultInjector.cleanup(drill.getDrillName());
            return resultBuilder
                .status(DrillStatus.FAILED)
                .failureReason(e.getMessage())
                .build();
        }
    }
    
    /**
     * 故障注入器
     */
    private FaultInjector faultInjector;
    
    /**
     * 支持的故障注入方式
     */
    public class FaultInjector {
        
        /**
         * 通过iptables/network namespace 模拟网络分区
         */
        public void injectNetworkPartition(String dcCode, int port) {
            // Kubernetes: 使用 ChaosMesh NetworkChaos
            applyChaosMesh("
                apiVersion: chaos-mesh.org/v1alpha1
                kind: NetworkChaos
                metadata:
                  name: drill-net-partition-" + dcCode + "
                spec:
                  action: partition
                  mode: all
                  selector:
                    namespaces: [primetop]
                    labelSelectors:
                      "topology.kubernetes.io/zone": "

" + dcCode + `"
                  duration:
                    seconds: 300
                  direction: to
                  target:
                    selector:
                      namespaces: [primetop]
                      labelSelectors:
                        "topology.kubernetes.io/zone": "other"
                    mode: all
            ");
        }
        
        /**
         * 通过ChaosMesh PodChaos 模拟服务宕机
         */
        public void injectServiceDown(String namespace, String labelSelector) {
            applyChaosMesh("""
                apiVersion: chaos-mesh.org/v1alpha1
                kind: PodChaos
                metadata:
                  name: drill-service-down
                spec:
                  action: pod-kill
                  mode: all
                  selector:
                    namespaces: [""" + namespace + """]
                    labelSelectors:
                      app: """ + labelSelector + """
                  duration: "60s"
            """);
        }
        
        /**
         * 模拟数据库故障（通过停止MySQL进程）
         */
        public void injectDatabaseDown(String serviceName, String dcCode) {
            // 方式1: 通过systemctl停止MySQL服务
            executeRemoteCommand(dcCode, "sudo systemctl stop mysqld");
            
            // 方式2: 通过Kubernetes终止Pod
            kubernetesClient.pods()
                .inNamespace("primetop")
                .withLabel("app", "mysql-" + serviceName)
                .withLabel("topology.kubernetes.io/zone", dcCode)
                .delete();
        }
    }
```

## 10. 错误处理与降级策略

### 10.1 错误码定义

| 错误码 | 含义 | 处理策略 |
| --- | --- | --- |
| DR-001 | 健康检查超时 | 重试3次后标记UNHEALTHY |
| DR-002 | 故障切换预检查失败 | 记录原因，通知运维 |
| DR-003 | 数据库提升失败 | 自动回滚，升级为P0告警 |
| DR-004 | DNS切换失败 | 重试或使用备用DNS服务商 |
| DR-005 | 流量切换后错误率飙升 | 自动回滚流量 |
| DR-006 | Redis切换超时 | 等待集群自动重新分片 |
| DR-007 | 演练中断 | 立即清理注入的故障 |
| DR-008 | 冷却期内重复触发 | 忽略并记录日志 |
| DR-009 | 无可用目标机房 | 全量P0告警，通知值班SRE |
| DR-010 | 数据不一致检测失败 | 暂停切换，发起人工介入 |

### 10.2 降级策略矩阵

| 故障场景 | L1核心服务 | L2重要服务 | L3一般服务 | L4辅助服务 |
| --- | --- | --- | --- | --- |
| 单实例故障 | 自动重启/重调度 | 自动重启 | 自动重启 | 等待下次部署 |
| 单AZ故障 | 自动切换到备AZ | 自动切换 | 半自动确认 | 手动处理 |
| 双AZ故障 | 激活异地灾备 | 降级运行 | 暂停服务 | 暂停服务 |

```java
@ExtendWith(MockitoExtension.class)
class FailoverDecisionEngineTest {
    
    @Mock HealthCheckManager healthCheckManager;
    @Mock DataCenterRepository dcRepository;
    @Mock AlertService alertService;
    
    @InjectMocks FailoverDecisionEngine engine;
    
    @Test
    @DisplayName("L1服务不健康 → 自动选择备机房切换")
    void shouldAutoFailoverL1Service() {
        // Given
        DrServiceConfig config = DrServiceConfig.builder()
            .serviceName("user-service")
            .serviceLevel("L1")
            .failoverStrategy("AUTO")
            .unhealthyThreshold(3)
            .cooldownSeconds(300)
            .build();
        
        DataCenter failedDC = DataCenter.builder()
            .dcCode("AZ-A").role(DCRole.PRIMARY).build();
        
        ServiceHealth health = ServiceHealth.builder()
            .status(HealthStatus.UNHEALTHY)
            .consecutiveFailures(3)
            .build();
        
        DataCenter targetDC = DataCenter.builder()
            .dcCode("AZ-B").role(DCRole.SECONDARY)
            .status(DCStatus.ACTIVE).build();
        
        when(dcRepository.findByRoleAndStatus(DCRole.SECONDARY, DCStatus.ACTIVE))
            .thenReturn(List.of(targetDC));
        when(healthCheckManager.getHealth("user-service", "AZ-B"))
            .thenReturn(ServiceHealth.builder().status(HealthStatus.HEALTHY).build());
        
        // When
        engine.evaluateFailover(config, failedDC, health);
        
        // Then
        verify(failoverExecutor).executeFailover(
            eq(config), eq(failedDC), eq(targetDC),
            eq(FailoverTriggerType.AUTO), eq(health)
        );
    }
    
    @Test
    @DisplayName("冷却期内 → 不触发切换")
    void shouldNotFailoverDuringCooldown() {
        DrServiceConfig config = DrServiceConfig.builder()
            .serviceName("content-service")
            .serviceLevel("L2")
            .cooldownSeconds(300)
            .build();
        
        // 模拟5分钟前刚切换过
        when(failoverEventRepository.findLatestCompleted("content-service"))
            .thenReturn(DrFailoverEvent.builder()
                .completeTime(LocalDateTime.now().minusMinutes(3))
                .build());
        
        engine.evaluateFailover(config, failedDC, unhealthyHealth);
        
        verify(failoverExecutor, never()).executeFailover(any(), any(), any(), any(), any());
    }
    
    @Test
    @DisplayName("无可用目标机房 → 发P0告警")
    void shouldAlertP0WhenNoTargetAvailable() {
        when(dcRepository.findByRoleAndStatus(any(), any()))
            .thenReturn(Collections.emptyList());
        
        engine.evaluateFailover(config, failedDC, health);
        
        verify(alertService).sendUrgentAlert(eq(AlertLevel.P0), anyString(), any());
    }
}
```
