# 服务端 - 用户消息中心统一未读计数与多端实时同步引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

用户消息中心统一未读计数与多端实时同步引擎是 PrimeTop 消息体系的"数字管家"，负责为每位用户维护跨消息类型（系统通知、学习提醒、互动消息、家长报告等）的精确未读计数，并通过 WebSocket 长连接将计数变化实时推送到用户所有在线设备，确保多端角标一致性。

### 1.2 核心挑战

| 挑战 | 描述 |
|------|------|
| 高并发写入 | 日均百万级消息产生，高峰期每秒数千条消息写入触发计数变更 |
| 多端一致性 | 用户同时在手机和平板上在线，一端标记已读后另一端角标需同步更新 |
| 实时性要求 | 消息到达后 ≤500ms 内角标刷新，用户操作后 ≤200ms 内多端同步 |
| 分类计数 | 需按消息类型分别计数（系统、学习、社交等），同时维护总未读数 |
| 离线对账 | 设备离线期间积累的计数变更，重连后需快速同步而非逐条回放 |
| 角标上限 | iOS/Android 系统角标上限为 99+，需在端侧和服务端协同处理 |

### 1.3 设计目标

- **精确性**：任意时刻任意设备的未读计数与服务端权威值一致
- **实时性**：计数变更后 ≤500ms 推送到所有在线设备
- **可扩展**：支持水平扩展，单节点支撑 10 万并发连接 + 5 万 TPS 计数写入
- **幂等性**：重复消息投递或网络重连不导致计数错乱
- **降级容错**：Redis 故障时降级到 DB 查询，WebSocket 断连时靠推送通道兜底

```
│                  消息事件总线 (Event Bus)                       │

│  ┌────────────┐  ┌──────────────┐  ┌────────────────────┐   │

┌─────────────┐   ┌──────────────┐    ┌────────────────────┐
│ Redis 集群   │   │ MySQL (持久化) │    │ WebSocket 推送集群  │
│ (计数热存储) │   │ (计数快照表)   │    │ (实时连接管理)      │
└─────────────┘   └──────────────┘    └────────┬───────────┘
                                                │
                       ┌────────────────────────┼────────────────┐
                       ▼                        ▼                ▼
                  ┌─────────┐            ┌──────────┐     ┌──────────┐
                  │ 手机端   │            │ 平板端    │     │ Web端    │
                  │(primary)│            │(secondary)│    │(tertiary)│
                  └─────────┘            └──────────┘     └──────────┘
```

### 2.2 核心组件职责

| 组件 | 职责 |
|------|------|
| 计数累加器 (CounterAggregator) | 接收消息事件，执行原子增减操作，维护 Redis 中的实时计数 |
| 分类计数管理器 (CategoryManager) | 按消息类型分组维护独立计数，支持分类查询和批量重置 |
| 多端广播分发器 (BroadcastDispatcher) | 将计数变更事件推送到用户所有在线设备的 WebSocket 连接 |
| 离线补偿器 (OfflineSyncManager) | 记录用户每台设备的最后同步版本号，重连时计算差量并补发 |
| 版本快照管理器 (SnapshotManager) | 定期将 Redis 计数快照持久化到 MySQL，防止 Redis 故障丢数据 |
| 角标压缩与合并器 (BadgeCompactor) | 高频计数变更时合并为最终值，避免短时间内向客户端推送过多事件 |

## 3. 数据结构定义

### 3.1 Redis 数据模型

#### 3.1.1 用户总未读计数

```redis
# Key 格式: unread:total:{userId}
# Value: 整数（未读消息总数）
# TTL: 无（与用户生命周期一致）

SET   unread:total:100001  23
GET   unread:total:100001  → 23
INCR  unread:total:100001  → 24
DECR  unread:total:100001  → 23
```

#### 3.1.2 分类未读计数（Hash）

```redis
# Key 格式: unread:category:{userId}
# Field: 消息分类标识
# Value: 该分类未读数

HSET  unread:category:100001  system       5
HSET  unread:category:100001  study        12
HSET  unread:category:100001  social       3
HSET  unread:category:100001  parent       2
HSET  unread:category:100001  marketing    1

HGETALL  unread:category:100001
# system → 5, study → 12, social → 3, parent → 2, marketing → 1

HINCRBY  unread:category:100001  study  1   # 学习类未读+1
```

#### 3.1.3 设备同步版本号

```redis
# Key 格式: unread:device_sync:{userId}
# Field: 设备唯一标识 (deviceId)
# Value: 该设备最后一次成功同步的版本号 (全局递增)

HSET  unread:device_sync:100001  "android-a1b2c3"  15234
HSET  unread:device_sync:100001  "ipad-x9y8z7"     15230

# 全局版本号（每次计数变更递增）
SET   unread:version:100001  15234
INCR  unread:version:100001  → 15235
```

#### 3.1.4 计数变更事件队列（Stream）

```redis
# Key 格式: unread:events:{userId}
# Redis Stream，保留最近 500 条变更事件用于离线补偿

XADD  unread:events:100001  *
  version     15235
  type        "message_created"
  category    "study"
  delta       1
  total       24
  category_total  13
  timestamp   "2026-08-06T00:38:00+08:00"

XLEN  unread:events:100001  → 127
```

#### 3.1.5 用户在线设备连接表

```redis
# Key 格式: presence:online_devices:{userId}
# Field: deviceId
# Value: WebSocket 连接节点标识 (nodeId)

HSET  presence:online_devices:100001  "android-a1b2c3"  "ws-node-03"
HSET  presence:online_devices:100001  "ipad-x9y8z7"     "ws-node-07"

# Key 格式: presence:connection:{userId}:{deviceId}
# Value: 连接详情 JSON
# TTL: 120s（心跳续期）

SET   presence:conn:100001:android-a1b2c3  '{"nodeId":"ws-node-03","connectedAt":"2026-08-06T00:30:00","lastHeartbeat":"2026-08-06T00:37:55","platform":"android","appVersion":"1.2.0"}'  EX 120
```

### 3.2 MySQL 数据模型

#### 3.2.1 消息分类未读计数快照表

```sql
CREATE TABLE `msg_unread_count` (
    `id`             BIGINT       NOT NULL AUTO_INCREMENT,
    `user_id`        BIGINT       NOT NULL                    COMMENT '用户ID',
    `category`       VARCHAR(32)  NOT NULL DEFAULT 'system'   COMMENT '消息分类: system/study/social/parent/marketing',
    `unread_count`   INT          NOT NULL DEFAULT 0          COMMENT '未读计数',
    `last_msg_id`    BIGINT       DEFAULT NULL                COMMENT '最新一条未读消息ID',
    `last_sync_version` BIGINT    DEFAULT 0                   COMMENT '最后一次同步的Redis版本号',
    `created_at`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`     DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_category` (`user_id`, `category`),
    KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='消息未读计数快照';
```

#### 3.2.2 设备同步状态表

```sql
CREATE TABLE `msg_device_sync_state` (
    `id`               BIGINT      NOT NULL AUTO_INCREMENT,
    `user_id`          BIGINT      NOT NULL                COMMENT '用户ID',
    `device_id`        VARCHAR(64) NOT NULL                COMMENT '设备唯一标识',
    `device_type`      VARCHAR(16) NOT NULL                COMMENT 'android/ios/web/ipad',
    `last_sync_version` BIGINT     NOT NULL DEFAULT 0      COMMENT '最后同步版本号',
    `last_sync_at`     DATETIME    DEFAULT NULL            COMMENT '最后同步时间',
    `created_at`       DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`       DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_user_device` (`user_id`, `device_id`),
    KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='设备消息同步状态';
```

#### 3.2.3 计数变更审计日志表（可选，用于排查计数异常）

```sql
CREATE TABLE `msg_count_audit_log` (
    `id`           BIGINT      NOT NULL AUTO_INCREMENT,
    `user_id`      BIGINT      NOT NULL                COMMENT '用户ID',
    `category`     VARCHAR(32) NOT NULL                COMMENT '消息分类',
    `action`       VARCHAR(32) NOT NULL                COMMENT 'increment/decrement/reset/all_read',
    `delta`        INT         NOT NULL                COMMENT '变化量（正为增，负为减）',
    `before_value` INT         NOT NULL                COMMENT '变更前计数',
    `after_value`  INT         NOT NULL                COMMENT '变更后计数',
    `trigger_type` VARCHAR(32) NOT NULL                COMMENT '触发源: message_created/user_read/auto_expire/system_reset',
    `trigger_id`   BIGINT      DEFAULT NULL            COMMENT '触发源对象ID（消息ID/操作批次ID）',
    `version`      BIGINT      NOT NULL                COMMENT '全局版本号',
    `created_at`   DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    KEY `idx_user_version` (`user_id`, `version`),
    KEY `idx_user_category_created` (`user_id`, `category`, `created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='计数变更审计日志'
PARTITION BY RANGE (TO_DAYS(created_at)) (
    PARTITION p202608 VALUES LESS THAN (TO_DAYS('2026-09-01')),
    PARTITION p202609 VALUES LESS THAN (TO_DAYS('2026-10-01')),
    PARTITION pmax    VALUES LESS THAN MAXVALUE
);
```

```json

    "total": 24,
    "categories": {
```

## 5. 核心流程设计

### 5.1 消息产生 → 计数更新 → 多端推送

```
消息生产服务                      未读计数引擎                    WebSocket 集群
     │                                │                              │
     │ 1.发布消息事件                  │                              │
     ├───────────────────────────────→│                              │
     │   {event: message.created,     │                              │
     │    userId: 100001,             │                              │
     │    category: "study",          │                              │
     │    messageId: 8839201}         │                              │
     │                                │                              │
     │                                │ 2.Redis原子操作               │
     │                                │ INCR unread:total:100001     │
     │                                │ HINCRBY unread:category:     │
     │                                │   100001 study 1             │
     │                                │ INCR unread:version:100001   │
     │                                │                              │
     │                                │ 3.写入Stream事件队列          │
     │                                │ XADD unread:events:100001    │
     │                                │   version=15235              │
     │                                │   delta=1 category=study     │
     │                                │                              │
     │                                │ 4.查询在线设备列表            │
     │                                │ HGETALL presence:            │
     │                                │   online_devices:100001      │
     │                                │                              │
     │                                │ 5.构建推送消息                │
     │                                │ 遍历在线设备:                 │
     │                                │   deviceId → nodeId          │
     │                                ├─────────────────────────────→│
     │                                │   推送到 ws-node-03           │
     │                                │   推送到 ws-node-07           │
     │                                │                              │
     │                                │                              │ 6.转发到客户端
     │                                │                              │   device: android-a1b2c3
     │                                │                              │   device: ipad-x9y8z7
     │                                │                              │
     │                                │ 7.异步写入审计日志            │
     │                                │ INSERT msg_count_audit_log   │
```

### 5.3 设备离线重连增量同步

```
客户端 (离线设备重连)              服务端
     │                              │
     │ 1.WebSocket重连成功           │
     │                              │
     │ 2.POST /messages/sync        │
```

### 6.1 计数累加器核心实现（Python）

```python
import redis
import json
import time
from typing import Optional
from dataclasses import dataclass

@dataclass
class CountChangeEvent:
    """计数变更事件"""
    user_id: int
    category: str
    delta: int
    action: str            # message_created / message_read / reset
    total_after: int
    category_after: int
    version: int
    message_id: Optional[int] = None
    timestamp: str = ""

class UnreadCountEngine:
    """未读计数引擎核心"""

    def __init__(self, redis_cluster: redis.RedisCluster,
                 audit_repo, broadcast_dispatcher):
        self.redis = redis_cluster
        self.audit_repo = audit_repo
        self.broadcast = broadcast_dispatcher

    def _key_total(self, user_id: int) -> str:
        return f"unread:total:{user_id}"

    def _key_category(self, user_id: int) -> str:
        return f"unread:category:{user_id}"

    def _key_version(self, user_id: int) -> str:
        return f"unread:version:{user_id}"

    def _key_events(self, user_id: int) -> str:
        return f"unread:events:{user_id}"

    def _key_devices(self, user_id: int) -> str:
        return f"presence:online_devices:{user_id}"

    def increment(self, user_id: int, category: str,
                  message_id: int = None) -> CountChangeEvent:
        """
        消息产生时调用：未读数+1
        使用 Redis Pipeline 保证原子性
        """
        pipe = self.redis.pipeline()
        pipe.INCR(self._key_total(user_id))
        pipe.HINCRBY(self._key_category(user_id), category, 1)
        pipe.INCR(self._key_version(user_id))
        total, cat_total, version = pipe.execute()

        # 防御性校验：计数不应为负
        if total < 0:
            # 异常恢复
            self.redis.SET(self._key_total(user_id), max(0, total))
            total = max(0, total)

        event = CountChangeEvent(
            user_id=user_id,
            category=category,
            delta=1,
            action="message_created",
            total_after=total,
            category_after=cat_total,
            version=version,
            message_id=message_id,
            timestamp=time.strftime("%Y-%m-%dT%H:%M:%S+08:00")
        )

        # 写入事件队列（用于离线补偿）
        self._append_event(user_id, event)

        # 异步审计日志
        self.audit_repo.log_async(event)

        # 广播到在线设备
        self.broadcast.dispatch(user_id, event, exclude_device=None)

        return event

    def decrement(self, user_id: int, category: str,
                  count: int = 1, device_id: str = None) -> CountChangeEvent:
        """
        标记已读时调用：未读数-N
        """
        pipe = self.redis.pipeline()
        pipe.DECRBY(self._key_total(user_id), count)
        pipe.HINCRBY(self._key_category(user_id), category, -count)
        pipe.INCR(self._key_version(user_id))
        total, cat_total, version = pipe.execute()

        # 防御性兜底：计数不能为负
        if total < 0 or cat_total < 0:
            pipe = self.redis.pipeline()
            if total < 0:
                pipe.SET(self._key_total(user_id), 0)
                total = 0
            if cat_total < 0:
                pipe.HSET(self._key_category(user_id), category, 0)
                cat_total = 0
            pipe.execute()

        event = CountChangeEvent(
            user_id=user_id,
            category=category,
            delta=-count,
            action="message_read",
            total_after=total,
            category_after=cat_total,
            version=version,
            timestamp=time.strftime("%Y-%m-%dT%H:%M:%S+08:00")
        )

        self._append_event(user_id, event)
        self.audit_repo.log_async(event)

        # 推送到其他设备（排除操作设备）
        self.broadcast.dispatch(user_id, event, exclude_device=device_id)

        return event

    def reset_category(self, user_id: int, category: str,
                       device_id: str = None) -> CountChangeEvent:
        """
        分类全部已读
        """
        pipe = self.redis.pipeline()
        pipe.HGET(self._key_category(user_id), category)
        pipe.HSET(self._key_category(user_id), category, 0)
        pipe.INCR(self._key_version(user_id))
        old_cat_total, _, version = pipe.execute()

        count_delta = int(old_cat_total or 0)
        pipe = self.redis.pipeline()
        pipe.DECRBY(self._key_total(user_id), count_delta)
        total = pipe.execute()[0]

        if total < 0:
            self.redis.SET(self._key_total(user_id), 0)
            total = 0

        event = CountChangeEvent(
            user_id=user_id,
            category=category,
            delta=-count_delta,
            action="all_read",
            total_after=total,
            category_after=0,
            version=version,
            timestamp=time.strftime("%Y-%m-%dT%H:%M:%S+08:00")
        )

        self._append_event(user_id, event)
        self.broadcast.dispatch(user_id, event, exclude_device=device_id)
        return event

    def reset_all(self, user_id: int, device_id: str = None):
        """全部标记已读"""
        pipe = self.redis.pipeline()
        pipe.SET(self._key_total(user_id), 0)
        pipe.DELETE(self._key_category(user_id))
        pipe.INCR(self._key_version(user_id))
        version = pipe.execute()[2]

        event = CountChangeEvent(
            user_id=user_id,
            category="all",
            delta=0,
            action="system_reset",
            total_after=0,
            category_after=0,
            version=version,
            timestamp=time.strftime("%Y-%m-%dT%H:%M:%S+08:00")
        )

        self._append_event(user_id, event)
        self.broadcast.dispatch(user_id, event, exclude_device=device_id)

    def get_counts(self, user_id: int) -> dict:
        """获取完整未读计数快照"""
        pipe = self.redis.pipeline()
        pipe.GET(self._key_total(user_id))
        pipe.HGETALL(self._key_category(user_id))
        pipe.GET(self._key_version(user_id))
        total, categories, version = pipe.execute()

        return {
            "total": int(total or 0),
            "categories": {k: int(v) for k, v in (categories or {}).items()},
            "version": int(version or 0)
        }

    def _append_event(self, user_id: int, event: CountChangeEvent):
        """写入事件 Stream（保留最近 500 条）"""
        stream_key = self._key_events(user_id)
        self.redis.XADD(stream_key, {
            "version": event.version,
            "type": event.action,
            "category": event.category,
            "delta": event.delta,
            "total": event.total_after,
            "category_total": event.category_after,
            "timestamp": event.timestamp
        }, maxlen=500, approximate=True)

    def sync_from_version(self, user_id: int, device_id: str,
                          last_sync_version: int) -> dict:
        """设备重连增量同步"""
        current_version = int(self.redis.GET(self._key_version(user_id)) or 0)
        gap = current_version - last_sync_version

        if gap <= 0:
            # 已是最新
            return {
                "current_version": current_version,
                "missed_events": [],
                "full_sync_required": False,
                **self.get_counts(user_id)
            }

        if gap > 500:
            # 版本差距过大，返回全量快照
            return {
                "current_version": current_version,
                "missed_events": [],
                "full_sync_required": True,
                **self.get_counts(user_id)
            }

        # 增量：从 Stream 读取事件
        events = self.redis.XRANGE(
            self._key_events(user_id),
            min=f"({last_sync_version}",  # 排除已同步版本
            max=f"+"
        )

        missed_events = []
        for stream_id, fields in events:
            missed_events.append({
                "version": int(fields[b"version"]),
                "type": fields[b"type"].decode(),
                "category": fields[b"category"].decode(),
                "delta": int(fields[b"delta"]),
                "timestamp": fields[b"timestamp"].decode()
            })

        # 更新设备同步版本
        self.redis.HSET(
            f"unread:device_sync:{user_id}",
            device_id,
            current_version
        )

        return {
            "current_version": current_version,
            "missed_events": missed_events,
            "full_sync_required": False,
            **self.get_counts(user_id)
        }
```

```python
import json
from collections import defaultdict

class BroadcastDispatcher:
    """
    多端广播分发器
    负责将计数变更推送到用户所有在线设备的 WebSocket 连接
    """

    def __init__(self, redis_cluster, ws_node_router):
        """
        :param redis_cluster: Redis 连接
        :param ws_node_router: WebSocket 节点路由器
            - 通过 Redis Pub/Sub 将消息路由到正确的 WS 节点
        """
        self.redis = redis_cluster
        self.ws_router = ws_node_router

    def dispatch(self, user_id: int, event, exclude_device: str = None):
        """
        将计数变更事件推送到用户所有在线设备

        :param exclude_device: 排除的设备ID（操作发起设备，避免回环）
        """
        # 1.获取在线设备列表
        devices = self.redis.HGETALL(f"presence:online_devices:{user_id}")
        if not devices:
            return  # 用户不在线，无需推送

        # 2.构建推送消息
        message = self._build_push_message(event)

        # 3.按 WS 节点分组，减少 Pub/Sub 消息数
        node_device_map = defaultdict(list)
        for device_id_bytes, node_id_bytes in devices.items():
            device_id = device_id_bytes.decode() if isinstance(device_id_bytes, bytes) else device_id_bytes
            node_id = node_id_bytes.decode() if isinstance(node_id_bytes, bytes) else node_id_bytes

            if exclude_device and device_id == exclude_device:
                continue
            node_device_map[node_id].append(device_id)

        # 4.通过 Redis Pub/Sub 路由到对应 WS 节点
        for node_id, device_ids in node_device_map.items():
            payload = json.dumps({
                "node_id": node_id,
                "device_ids": device_ids,
                "user_id": user_id,
                "message": message
            })
            self.redis.PUBLISH(f"ws:route:{node_id}", payload)

    def _build_push_message(self, event) -> dict:
        return {
            "type": "unread_count_update",
            "version": event.version,
            "timestamp": event.timestamp,
            "data": {
                "total": event.total_after,
                "categories": {
                    event.category: event.category_after
                },
                "changes": [{
                    "category": event.category,
                    "delta": event.delta,
                    "action": event.action,
                    "message_id": event.message_id
                }]
            }
        }
```

```python
import asyncio
import json
import aioredis

class WebSocketNode:
    """
    WebSocket 节点服务
    每个节点维护本地连接表，接收来自计数引擎的推送并转发到客户端
    """

    NODE_ID = "ws-node-03"  # 从配置读取
    MAX_CONNECTIONS = 50000

    def __init__(self):
        # 本地连接表: {device_id: websocket_connection}
        self.connections = {}
        # 用户→设备映射: {user_id: set(device_ids)}
        self.user_devices = defaultdict(set)

    async def start(self):
        """启动 Redis 订阅监听"""
        redis = aioredis.from_url("redis://redis-cluster:6379")
        pubsub = redis.pubsub()
        await pubsub.subscribe(f"ws:route:{self.NODE_ID}")

        # 监听推送消息
        async for message in pubsub.listen():
            if message["type"] == "message":
                await self._handle_push(message["data"])

    async def _handle_push(self, raw_data: bytes):
        """处理来自计数引擎的推送"""
        data = json.loads(raw_data)
        device_ids = data["device_ids"]
        ws_message = data["message"]

        # 转发到每个设备
        for device_id in device_ids:
            ws = self.connections.get(device_id)
            if ws and not ws.closed:
                try:
                    await ws.send(json.dumps(ws_message))
                except Exception as e:
                    # 连接已断开，清理
                    self.connections.pop(device_id, None)
                    logger.warning(f"WS push failed for {device_id}: {e}")

    async def handle_connection(self, websocket, user_id: int, device_id: str):
        """处理新 WebSocket 连接"""
        if len(self.connections) >= self.MAX_CONNECTIONS:
            await websocket.close(code=503, reason="Server at capacity")
            return

        # 注册连接
        self.connections[device_id] = websocket
        self.user_devices[user_id].add(device_id)

        # 注册到 Redis（设备在线状态）
        pipe = redis.pipeline()
        pipe.HSET(f"presence:online_devices:{user_id}", device_id, self.NODE_ID)
        pipe.SET(
            f"presence:conn:{user_id}:{device_id}",
            json.dumps({"nodeId": self.NODE_ID,
                       "connectedAt": now_iso(),
                       "platform": "android"}),
            ex=120
        )
        pipe.execute()

        try:
            # 立即推送当前未读计数（全量快照）
            counts = unread_engine.get_counts(user_id)
            await websocket.send(json.dumps({
                "type": "unread_count_snapshot",
                "version": counts["version"],
                "data": counts
            }))

            # 进入消息循环（处理心跳）
            async for raw_msg in websocket:
                msg = json.loads(raw_msg)
                if msg.get("type") == "ping":
                    # 续期 TTL
                    redis.expire(
                        f"presence:conn:{user_id}:{device_id}", 120
                    )
                    await websocket.send(json.dumps({
                        "type": "pong",
                        "timestamp": now_iso()
                    }))

        except WebSocketDisconnect:
            pass
        finally:
            # 清理连接
            self.connections.pop(device_id, None)
            self.user_devices[user_id].discard(device_id)
            # 从 Redis 移除设备
            redis.HDEL(f"presence:online_devices:{user_id}", device_id)
            redis.DELETE(f"presence:conn:{user_id}:{device_id}")
```

### 6.4 角标压缩器（防止高频推送）

```python
import time
from collections import defaultdict, deque

class BadgeCompactor:
    """
    角标压缩器
    在高频消息场景下（如批量消息导入、系统广播），
    将短时间内多个计数变更合并为一条推送，避免客户端频繁刷新角标。

    策略：滑动窗口合并（50ms 窗口）
    """

    WINDOW_MS = 50  # 合并窗口
    MAX_WAIT_MS = 200  # 最大等待时间

    def __init__(self, broadcast_dispatcher):
        self.broadcast = broadcast_dispatcher
        self.pending = defaultdict(deque)  # {user_id: deque(events)}
        self.timers = {}  # {user_id: last_flush_time}

    def submit(self, user_id: int, event):
        """提交计数变更事件"""
        self.pending[user_id].append(event)

        now = time.monotonic()
        last_flush = self.timers.get(user_id, 0)

        if now - last_flush >= self.WINDOW_MS / 1000:
            # 窗口已过，立即刷新
            self._flush(user_id)
        else:
            # 在窗口内，等待合并
            # 由定时器或下次 submit 触发刷新
            pass

    def _flush(self, user_id: int):
        """合并并推送所有待发事件"""
        events = self.pending.get(user_id)
        if not events:
            return

        # 取最后一个事件作为最终状态
        latest = events[-1]

        # 合并所有 delta
        total_delta = sum(e.delta for e in events)
        categories_delta = defaultdict(int)
        for e in events:
            categories_delta[e.category] += e.delta

        # 构建合并推送消息
        message = {
            "type": "unread_count_update",
            "version": latest.version,
            "timestamp": latest.timestamp,
            "data": {
                "total": latest.total_after,
                "categories": {latest.category: latest.category_after},
                "changes": [{
                    "category": cat,
                    "delta": delta,
                    "action": "batch_update"
                } for cat, delta in categories_delta.items()]
            }
        }

        self.broadcast.dispatch(user_id, message)
        self.pending[user_id].clear()
        self.timers[user_id] = time.monotonic()
```

```python
from apscheduler.schedulers.asyncio import AsyncIOScheduler

class CountSnapshotJob:
```

### 7.3 防御性计数校验

```python
class CountValidator:
    """
    定期校验 Redis 计数与实际消息表的一致性
    修复因 Bug、Redis 故障等导致的计数漂移
    """

    async def validate_and_repair(self, user_id: int):
        """校验并修复单个用户计数"""
        # 从消息表统计实际未读数
        async with self.mysql.acquire() as conn:
            cursor = await conn.execute(
                """SELECT category, COUNT(*) as cnt
                   FROM messages
                   WHERE user_id = %s AND is_read = 0 AND deleted_at IS NULL
                   GROUP BY category""",
                (user_id,)
            )
            actual_counts = {row[0]: row[1] for row in await cursor.fetchall()}

        actual_total = sum(actual_counts.values())
        redis_counts = self.engine.get_counts(user_id)

        if redis_counts["total"] != actual_total:
            # 计数不一致，执行修复
            logger.warning(
                f"Count mismatch for user {user_id}: "
                f"Redis={redis_counts['total']} vs DB={actual_total}"
            )
            self._repair_counts(user_id, actual_counts)

            # 记录审计日志
            self.audit_repo.log_repair(user_id, redis_counts, actual_counts)

            # 通知客户端
            self.broadcast.dispatch(user_id, {
                "type": "unread_count_correction",
                "version": redis_counts["version"] + 1,
                "data": {"total": actual_total, "categories": actual_counts}
            })
```

## 8. 错误处理与异常场景

### 8.1 错误码定义

| 错误码 | HTTP | 描述 | 处理方式 |
|--------|------|------|---------|
| UNREAD_001 | 400 | 不合法的消息分类 | 返回支持的分类列表 |
| UNREAD_002 | 400 | 标记已读的消息不属于该用户 | 返回权限错误 |
| UNREAD_003 | 409 | 客户端版本号过期 | 客户端需执行全量同步 |
| UNREAD_004 | 429 | 同步请求频率超限 | 降级为最近缓存快照 |
| UNREAD_005 | 500 | Redis 计数操作失败 | 降级到 MySQL 快照查询 |
| UNREAD_006 | 503 | WebSocket 节点不可达 | 客户端依赖推送通道兜底 |
| UNREAD_007 | 500 | 计数为负（数据异常） | 自动修复为 0 并记录审计 |
