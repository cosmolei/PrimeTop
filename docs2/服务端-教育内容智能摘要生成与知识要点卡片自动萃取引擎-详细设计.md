# 服务端 - 教育内容智能摘要生成与知识要点卡片自动萃取引擎 详细设计

> 细化日期：2026-06-14
> 原始需求来源：`docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` §6.4 同步课堂学习（课前预习/课后复习）、§8.5 AI能力架构（RAG检索增强）、§9.3 首页交互设计（薄弱点提醒/继续学习）

## 1. 概述

### 1.1 背景

PrimeTop 平台拥有大量结构化教育内容——教材章节、知识点讲解、题目解析、考点说明等。这些内容以长文本 + 结构化数据的形态存储，直接面向学生展示时存在以下问题：

1. **预习/复习效率低**：学生在课前预习或课后快速复习时，面对完整章节内容（通常 2000-5000 字）难以快速抓住重点
2. **首页推荐缺乏素材**：首页"薄弱点提醒""今日学习"等卡片需要精简的知识摘要（50-150 字），但目前依赖人工编辑
3. **搜索结果可读性差**：知识点搜索结果仅展示标题，缺少摘要片段（snippet），用户无法快速判断相关性
4. **间隔复习缺少卡片**：遗忘曲线复习调度引擎需要以"知识卡片"为单元进行复习，但目前仅有题目级复习，缺少知识点级别的卡片
5. **离线包体积受限**：完整章节内容离线包体积大，如果能生成精简摘要，可作为轻量离线学习资源

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 自动生成章节摘要 | 为每个教材章节生成 100-300 字的结构化摘要，涵盖核心知识点、公式、结论 |
| 知识要点卡片萃取 | 从章节内容中自动提取知识要点卡片（定义、公式、定理、结论、易错点） |
| 多粒度复习材料 | 生成 1 分钟速览、5 分钟回顾、15 分钟精读三种粒度的复习材料 |
| 搜索摘要片段 | 为搜索结果提供 50-80 字的摘要 snippet |
| 学段自适应 | 摘要语言风格、深度随学段自动调整（小学/初中/高中） |
| 增量更新 | 当源内容更新时，自动检测并重新生成受影响的摘要和卡片 |
| 质量保障 | 对 AI 生成的摘要进行事实性校验，标注置信度 |

### 1.3 核心概念

| 概念 | 说明 |
|------|------|
| ContentSummary（内容摘要） | 对一个章节或知识点的结构化摘要 |
| KnowledgeCard（知识卡片） | 从内容中萃取的最小可复习知识单元，含正反面 |
| ReviewBundle（复习包） | 多张知识卡片的集合，按复习粒度组织 |
| SummaryGranularity（摘要粒度） | BRIEF(速览)/REVIEW(回顾)/DETAILED(精读) |
| CardType（卡片类型） | DEFINITION / FORMULA / THEOREM / CONCLUSION / COMMON_MISTAKE / EXAMPLE |
| ExtractionJob（萃取任务） | 一次内容摘要生成 + 卡片萃取的异步作业 |

### 1.4 与其他模块的边界

| 模块 | 边界说明 |
|------|---------|
| 教育内容版本管理与教材同步更新引擎 | 管理内容版本生命周期；**内容更新时通知本引擎重新生成摘要** |
| 知识点体系与教材映射引擎 | 管理知识点树结构；**本引擎消费知识点元数据，产出摘要反写到知识点的 summary 字段** |
| 同步课堂章节内容聚合与个性化学习流编排服务 | 编排章节学习流；**调用本引擎 API 获取预习摘要和复习卡片** |
| 间隔重复算法与遗忘曲线复习调度引擎 | 调度复习计划；**以本引擎产出的知识卡片作为复习单元** |
| 首页内容卡片推荐与聚合编排服务 | 首页卡片编排；**调用本引擎 API 获取薄弱点摘要** |
| 搜索服务与全文检索 | 全文检索；**从本引擎获取搜索 snippet** |
| RAG 与知识库系统 | 向量检索增强生成；**本引擎的摘要可作为 RAG 检索的补充上下文** |
| AI幻觉检测与教育事实校验引擎 | 检测 AI 输出幻觉；**本引擎调用其 API 对生成的摘要进行事实校验** |

### 1.5 依赖关系

```
上游输入：
  教材章节内容（结构化 HTML/Markdown + 公式 + 图表描述）
  知识点元数据（知识点树、认知层级、前置依赖）
  题目与解析（关联的典型题目和易错题）
  学段年级信息（用于自适应摘要深度）

本引擎产出：
  → 章节摘要（写入 content_summaries 表）
  → 知识卡片（写入 knowledge_cards 表）
  → 复习包（写入 review_bundles 表）
  → 搜索摘要（同步至 Elasticsearch 的 summary_snippet 字段）

下游消费：
  同步课堂服务 → 预习/复习摘要
  间隔重复引擎 → 知识卡片为复习单元
  首页推荐服务 → 薄弱点知识摘要
  搜索服务 → 知识点搜索 snippet
  离线内容分发 → 轻量摘要离线包
```

## 2. 数据模型

### 2.1 内容摘要表 `content_summaries`

```sql
CREATE TABLE content_summaries (
    id                  BIGSERIAL PRIMARY KEY,
    -- 关联源内容
    content_type        VARCHAR(32) NOT NULL,        -- CHAPTER / KNOWLEDGE_POINT / EXAM_POINT
    content_ref_id      BIGINT NOT NULL,             -- 章节 ID 或知识点 ID
    textbook_id         BIGINT,                      -- 所属教材版本
    subject_code        VARCHAR(16) NOT NULL,        -- 学科代码
    stage               VARCHAR(16) NOT NULL,        -- 学段
    grade               INT,                         -- 年级

    -- 摘要内容
    granularity         VARCHAR(16) NOT NULL,        -- BRIEF / REVIEW / DETAILED
    title               VARCHAR(256) NOT NULL,       -- 摘要标题
    summary_text        TEXT NOT NULL,               -- 摘要正文（Markdown）
    summary_plain       TEXT NOT NULL,               -- 纯文本版本（用于搜索 snippet）
    key_points          JSONB NOT NULL DEFAULT '[]', -- 核心要点列表 ["要点1", "要点2", ...]
    formulas            JSONB NOT NULL DEFAULT '[]', -- 关键公式 [{"name":"二次方程求根公式", "latex":"x=\\frac{-b\\pm\\sqrt{b^2-4ac}}{2a}"}]
    keywords            JSONB NOT NULL DEFAULT '[]', -- 关键词标签

    -- 质量与来源
    source              VARCHAR(16) NOT NULL,        -- AI_GENERATED / AI_GENERATED_VERIFIED / MANUAL_EDITED
    model_name          VARCHAR(64),                 -- 生成所用模型
    confidence_score    DECIMAL(3,2),                -- 置信度 0.00-1.00
    fact_check_status   VARCHAR(16) NOT NULL DEFAULT 'PENDING', -- PENDING / PASSED / FAILED / SKIPPED
    fact_check_issues   JSONB,                       -- 校验发现的问题

    -- 版本追踪
    source_content_hash VARCHAR(64) NOT NULL,        -- 源内容 SHA-256，用于变更检测
    version             INT NOT NULL DEFAULT 1,      -- 摘要版本号

    -- 时间
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    generated_at        TIMESTAMPTZ,                 -- AI 生成完成时间

    UNIQUE (content_type, content_ref_id, granularity, version)
);

CREATE INDEX idx_cs_content ON content_summaries(content_type, content_ref_id);
CREATE INDEX idx_cs_subject_stage ON content_summaries(subject_code, stage);
CREATE INDEX idx_cs_textbook ON content_summaries(textbook_id);
CREATE INDEX idx_cs_keywords ON content_summaries USING GIN(keywords);
```

### 2.2 知识卡片表 `knowledge_cards`

```sql
CREATE TABLE knowledge_cards (
    id                  BIGSERIAL PRIMARY KEY,
    -- 关联
    content_ref_id      BIGINT NOT NULL,             -- 所属章节/知识点 ID
    content_type        VARCHAR(32) NOT NULL,        -- CHAPTER / KNOWLEDGE_POINT
    textbook_id         BIGINT,
    subject_code        VARCHAR(16) NOT NULL,
    stage               VARCHAR(16) NOT NULL,
    grade               INT,
    knowledge_point_id  BIGINT,                      -- 关联的知识点 ID（可空）

    -- 卡片内容
    card_type           VARCHAR(32) NOT NULL,        -- DEFINITION / FORMULA / THEOREM / CONCLUSION / COMMON_MISTAKE / EXAMPLE
    front               TEXT NOT NULL,               -- 卡片正面（问题/术语/提示）
    back                TEXT NOT NULL,               -- 卡片背面（答案/定义/解释）
    back_rich           TEXT,                        -- 富文本背面（含公式、高亮，Markdown + LaTeX）
    hint                TEXT,                        -- 提示信息（可选）

    -- 元数据
    difficulty          SMALLINT NOT NULL DEFAULT 3, -- 难度 1-5
    importance          SMALLINT NOT NULL DEFAULT 3, -- 重要性 1-5（影响复习优先级）
    tags                JSONB NOT NULL DEFAULT '[]', -- 标签

    -- 来源与质量
    source              VARCHAR(16) NOT NULL DEFAULT 'AI_GENERATED',
    model_name          VARCHAR(64),
    confidence_score    DECIMAL(3,2),
    fact_check_status   VARCHAR(16) NOT NULL DEFAULT 'PENDING',

    -- 排序与状态
    sort_order          INT NOT NULL DEFAULT 0,
    status              VARCHAR(16) NOT NULL DEFAULT 'ACTIVE', -- ACTIVE / DEPRECATED / DRAFT

    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    UNIQUE (content_ref_id, content_type, card_type, front(200))
);

CREATE INDEX idx_kc_content ON knowledge_cards(content_ref_id, content_type);
CREATE INDEX idx_kc_kp ON knowledge_cards(knowledge_point_id);
CREATE INDEX idx_kc_subject_stage ON knowledge_cards(subject_code, stage);
CREATE INDEX idx_kc_type ON knowledge_cards(card_type);
```

### 3.3 卡片类型识别规则

```python
class ContentTypeRule:
    """内容块类型识别规则"""

    # 定义类：以"是"、"是指"、"定义为"开头的句子
    DEFINITION_PATTERNS = [
        r"^(.+?)是(?:指)?(.+)",
        r"定义[：:]\s*(.+)",
        r"(.+?)\s*叫做\s*(.+)",
    ]

    # 公式类：包含 LaTeX 公式块
    FORMULA_PATTERNS = [
        r"\$\$.+?\$\$",       # 块级公式
        r"公式[：:]\s*(.+)",
        r"计算公式[：:]\s*(.+)",
    ]

    # 定理类：以"定理"、"性质"、"推论"标记
    THEOREM_PATTERNS = [
        r"定理[：:]\s*(.+)",
        r"性质[：:]\s*(.+)",
        r"推论[：:]\s*(.+)",
    ]

    # 结论类：以"因此"、"所以"、"综上"、"结论"标记
    CONCLUSION_PATTERNS = [
        r"(?:因此|所以|综上)[，,]?\s*(.+)",
        r"结论[：:]\s*(.+)",
        r"总而言之[，,]?\s*(.+)",
    ]

    # 易错点：以"注意"、"易错"、"常见错误"标记
    MISTAKE_PATTERNS = [
        r"(?:注意|注意点)[：:]\s*(.+)",
        r"易错(?:点|地方)[：:]\s*(.+)",
        r"常见错误[：:]\s*(.+)",
        r"温馨提示[：:]\s*(.+)",
    ]

    # 例题类：以"例"、"例题"、"例如"标记
    EXAMPLE_PATTERNS = [
        r"例\d*[　 ]*(.+)",
        r"例如[：,]?\s*(.+)",
        r"比如[：,]?\s*(.+)",
    ]
```

### 3.4 变更检测与增量更新流程

```python
class ChangeDetectionFlow:
    """
    当教材内容更新时，自动检测变更并触发增量重新生成。
    """

    async def on_content_updated(self, event: ContentUpdatedEvent):
        # 1. 计算新内容 hash
        new_hash = compute_sha256(event.content)

        # 2. 查询已有摘要的最新 hash
        existing = await self.summary_repo.get_latest_summary(
            content_type=event.content_type,
            content_ref_id=event.content_ref_id
        )

        if existing and existing.source_content_hash == new_hash:
            logger.info(f"Content unchanged, skip: {event.content_ref_id}")
            return

        # 3. 计算变更级别
        if existing:
            change_level = await self.analyze_change_level(
                old_content=existing.raw_content,
                new_content=event.content
            )
        else:
            change_level = ChangeLevel.NEW  # 新内容

        # 4. 根据变更级别决定策略
        match change_level:
            case ChangeLevel.MINOR:    # 错别字/格式修正
                # 仅更新 BRIEF 摘要，保留卡片
                await self.create_job(
                    job_type=JobType.SUMMARY_ONLY,
                    granularities=[Granularity.BRIEF],
                    priority=7
                )
            case ChangeLevel.MODERATE: # 知识点修订
                # 重新生成所有摘要和卡片
                await self.create_job(
                    job_type=JobType.FULL_EXTRACTION,
                    granularities=ALL_GRANULARITIES,
                    priority=4
                )
            case ChangeLevel.MAJOR:    # 章节重构
                # 高优先级全量重新生成
                await self.create_job(
                    job_type=JobType.FULL_EXTRACTION,
                    granularities=ALL_GRANULARITIES,
                    priority=2
                )
            case ChangeLevel.NEW:
                # 新内容，正常优先级
                await self.create_job(
                    job_type=JobType.FULL_EXTRACTION,
                    granularities=ALL_GRANULARITIES,
                    priority=5
                )
```

## 6. 关键代码示例

### 6.1 摘要生成服务（Python）

```python
import hashlib
import json
from dataclasses import dataclass
from typing import Optional

from app.core.ai import LLMClient, LLMResponse
from app.core.fact_check import FactChecker
from app.modules.content_summary.models import (
    ContentSummary, Granularity, SummaryCreateInput
)
from app.modules.content_summary.prompts import (
    SUMMARY_PROMPT_TEMPLATE, GRANULARITY_CONFIG, STAGE_ADAPTATION
)


@dataclass
class SummaryGenerationResult:
    summary: ContentSummary
    fact_check_passed: bool
    fact_check_issues: Optional[list[dict]] = None


class SummaryGeneratorService:
    """内容摘要生成服务"""

    def __init__(
        self,
        llm_client: LLMClient,
        fact_checker: FactChecker,
        summary_repo: "SummaryRepository",
    ):
        self._llm = llm_client
        self._fact_checker = fact_checker
        self._repo = summary_repo

    async def generate_summary(
        self,
        content_ref_id: int,
        content_type: str,
        raw_content: str,
        textbook_info: dict,
        granularity: Granularity,
    ) -> SummaryGenerationResult:
        """生成单个粒度的摘要"""

        # 1. 组装 Prompt
        prompt = self._build_prompt(raw_content, textbook_info, granularity)

        # 2. 调用大模型
        llm_response: LLMResponse = await self._llm.chat(
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3,          # 低温度保证稳定性
            max_tokens=2000,
            response_format="json",   # 强制 JSON 输出
            model=self._select_model(granularity, textbook_info),
        )

        # 3. 解析响应
        parsed = self._parse_llm_response(llm_response)
        if not parsed:
            raise SummaryGenerationError(
                f"LLM response parsing failed for content {content_ref_id}"
            )

        # 4. 事实校验
        fact_result = await self._fact_checker.check_summary(
            summary=parsed,
            source_content=raw_content,
            subject=textbook_info["subject_code"],
        )

        # 5. 构建实体
        source_hash = hashlib.sha256(raw_content.encode()).hexdigest()
        summary = ContentSummary(
            content_type=content_type,
            content_ref_id=content_ref_id,
            textbook_id=textbook_info["textbook_id"],
            subject_code=textbook_info["subject_code"],
            stage=textbook_info["stage"],
            grade=textbook_info.get("grade"),
            granularity=granularity,
            title=parsed["title"],
            summary_text=parsed["summary_text"],
            summary_plain=parsed["summary_plain"],
            key_points=parsed.get("key_points", []),
            formulas=parsed.get("formulas", []),
            keywords=parsed.get("keywords", []),
            source="AI_GENERATED" if fact_result.passed else "AI_GENERATED",
            model_name=llm_response.model,
            confidence_score=self._calculate_confidence(
                llm_response, fact_result
            ),
            fact_check_status="PASSED" if fact_result.passed else "FAILED",
            fact_check_issues=fact_result.issues if not fact_result.passed else None,
            source_content_hash=source_hash,
        )

        # 6. 持久化
        saved = await self._repo.upsert(summary)
        return SummaryGenerationResult(
            summary=saved,
            fact_check_passed=fact_result.passed,
            fact_check_issues=fact_result.issues if not fact_result.passed else None,
        )

    def _build_prompt(
        self, raw_content: str, textbook_info: dict, granularity: Granularity
    ) -> str:
        config = GRANULARITY_CONFIG[granularity]
        return SUMMARY_PROMPT_TEMPLATE.format(
            subject=textbook_info["subject_name"],
            stage=textbook_info["stage_name"],
            grade=textbook_info.get("grade", ""),
            textbook_name=textbook_info.get("textbook_name", ""),
            chapter_title=textbook_info.get("chapter_title", ""),
            raw_content=raw_content[:8000],  # 截断保护
            granularity_desc=config["desc"],
            granularity_instruction=config["instruction"],
            key_point_count=config["key_point_count"],
            stage_adaptation=STAGE_ADAPTATION.get(
                textbook_info["stage"], STAGE_ADAPTATION["JUNIOR"]
            ),
        )

    def _select_model(self, granularity: Granularity, info: dict) -> str:
        """根据粒度和学科选择合适的模型"""
        # BRIEF 使用快速模型，DETAILED 使用更强模型
        if granularity == Granularity.BRIEF:
            return "qwen-plus"  # 快速、低成本
        elif info["subject_code"] in ("MATH", "PHY", "CHE"):
            return "deepseek-v3"  # 理科推理强
        else:
            return "qwen-max"    # 通用高质量

    def _calculate_confidence(
        self, llm_resp: LLMResponse, fact_result
    ) -> float:
        """综合置信度计算"""
        base = 0.9 if llm_resp.finish_reason == "stop" else 0.7
        if fact_result.passed:
            return min(base + 0.05, 0.99)
        else:
            penalty = len(fact_result.issues) * 0.1
            return max(base - penalty, 0.3)

    def _parse_llm_response(self, response: LLMResponse) -> Optional[dict]:
        """安全解析 LLM 返回的 JSON"""
        try:
            data = json.loads(response.content)
            required = ["title", "summary_text", "summary_plain"]
            for field in required:
                if field not in data:
                    return None
            return data
        except (json.JSONDecodeError, TypeError):
            return None
```

```python
class CardExtractionService:
    """知识卡片萃取服务"""

    def __init__(
        self,
        llm_client: LLMClient,
        card_repo: "CardRepository",
        bundle_repo: "BundleRepository",
        similarity_checker: "CardSimilarityChecker",
    ):
        self._llm = llm_client
        self._card_repo = card_repo
        self._bundle_repo = bundle_repo
        self._similarity = similarity_checker

    async def extract_cards(
        self,
        content_ref_id: int,
        content_type: str,
        summary_text: str,
        raw_content: str,
        textbook_info: dict,
    ) -> list["KnowledgeCard"]:
        """从章节内容中萃取知识卡片"""

        # 1. 使用摘要 + 原文片段作为输入（控制 token）
        combined_input = self._prepare_input(summary_text, raw_content)

        # 2. 调用 LLM 萃取卡片
        prompt = CARD_EXTRACTION_PROMPT.format(
            subject=textbook_info["subject_name"],
            stage=textbook_info["stage_name"],
            chapter_title=textbook_info.get("chapter_title", ""),
            summary_or_content=combined_input,
        )

        response = await self._llm.chat(
            messages=[{"role": "user", "content": prompt}],
            temperature=0.3,
            max_tokens=4000,
            response_format="json",
        )

        raw_cards = self._parse_cards(response.content)
        if not raw_cards:
            logger.warning(f"No cards extracted for content {content_ref_id}")
            return []

        # 3. 去重与合并
        existing_cards = await self._card_repo.get_by_content(
            content_ref_id, content_type, status="ACTIVE"
        )

        final_cards = []
        for raw_card in raw_cards:
            # 计算与已有卡片的相似度
            best_match = None
            best_score = 0.0
            for existing in existing_cards:
                score = await self._similarity.compute(
                    raw_card["front"], existing.front
                )
                if score > best_score:
                    best_score = score
                    best_match = existing

            if best_match and best_score > 0.85:
                # 更新已有卡片
                updated = self._merge_card(best_match, raw_card)
                await self._card_repo.update(updated)
                final_cards.append(updated)
            else:
                # 创建新卡片
                new_card = self._create_card_entity(
                    raw_card, content_ref_id, content_type, textbook_info
                )
                saved = await self._card_repo.create(new_card)
                final_cards.append(saved)

        # 4. 废弃不再出现的旧卡片
        new_fronts = {c.front[:200] for c in final_cards}
        for existing in existing_cards:
            if existing.front[:200] not in new_fronts:
                await self._card_repo.update_status(
                    existing.id, status="DEPRECATED"
                )

        # 5. 组装复习包
        await self._assemble_bundles(
            content_ref_id, content_type, final_cards, textbook_info
        )

        return final_cards

    async def _assemble_bundles(
        self,
        content_ref_id: int,
        content_type: str,
        cards: list,
        textbook_info: dict,
    ):
        """组装三种粒度的复习包"""

        # 按重要性和难度排序
        sorted_cards = sorted(
            cards,
            key=lambda c: (-c.importance, c.difficulty)
        )

        bundle_configs = [
            (Granularity.BRIEF_1MIN, sorted_cards[:5], 1),
            (Granularity.REVIEW_5MIN, sorted_cards[:15], 5),
            (Granularity.DETAILED_15MIN, sorted_cards[:40], 15),
        ]

        for granularity, selected, est_min in bundle_configs:
            if not selected:
                continue

            card_ids = [c.id for c in selected]
            bundle = ReviewBundle(
                content_ref_id=content_ref_id,
                content_type=content_type,
                textbook_id=textbook_info.get("textbook_id"),
                subject_code=textbook_info["subject_code"],
                granularity=granularity,
                bundle_name=self._generate_bundle_name(
                    textbook_info, granularity
                ),
                card_ids=card_ids,
                card_count=len(selected),
                estimated_minutes=est_min,
            )
            await self._bundle_repo.upsert(bundle)
```

### 6.3 事实校验器

```python
class SummaryFactChecker:
    """摘要事实校验器"""

    async def check_summary(
        self,
        summary: dict,
        source_content: str,
        subject: str,
    ) -> "FactCheckResult":
        """
        对生成的摘要进行多维事实校验
        """
        issues = []

        # 1. 公式 LaTeX 语法验证
        formula_issues = self._validate_formulas(summary.get("formulas", []))
        issues.extend(formula_issues)

        # 2. 关键术语覆盖率检查
        term_coverage = self._check_term_coverage(
            summary["summary_plain"], source_content
        )
        if term_coverage < 0.6:
            issues.append({
                "type": "LOW_TERM_COVERAGE",
                "message": f"摘要仅覆盖了 {term_coverage:.0%} 的源内容关键术语",
                "severity": "WARNING",
            })

        # 3. 数值一致性检查
        number_issues = self._check_number_consistency(
            summary["summary_text"], source_content
        )
        issues.extend(number_issues)

        # 4. 调用外部幻觉检测 API（对关键学科）
        if subject in ("MATH", "PHY", "CHE", "BIO"):
            hallucination_result = await self._call_hallucination_api(
                summary["summary_text"], source_content
            )
            if not hallucination_result["passed"]:
                issues.append({
                    "type": "HALLUCINATION_DETECTED",
                    "message": hallucination_result["detail"],
                    "severity": "ERROR",
                })

        # 5. 综合判定
        has_error = any(i["severity"] == "ERROR" for i in issues)
        return FactCheckResult(
            passed=not has_error,
            issues=issues,
        )

    def _validate_formulas(self, formulas: list[dict]) -> list[dict]:
        """验证 LaTeX 公式语法"""
        import re
        issues = []
        for f in formulas:
            latex = f.get("latex", "")
            # 检查括号匹配
            if latex.count("{") != latex.count("}"):
                issues.append({
                    "type": "FORMULA_SYNTAX_ERROR",
                    "message": f"公式 '{f.get('name')}' 的 LaTeX 括号不匹配",
                    "severity": "ERROR",
                })
            # 检查常见非法语法
            if re.search(r'\\\\[^a-zA-Z]', latex):
                issues.append({
                    "type": "FORMULA_SYNTAX_WARNING",
                    "message": f"公式 '{f.get('name')}' 可能存在 LaTeX 语法问题",
                    "severity": "WARNING",
                })
        return issues

    def _check_term_coverage(
        self, summary_plain: str, source_content: str
    ) -> float:
        """关键术语覆盖率"""
        import jieba
        # 提取源内容中的学科专业术语（简化版）
        source_terms = set(
            w for w in jieba.cut(source_content)
            if len(w) >= 2 and w.strip()
        )
        summary_terms = set(
            w for w in jieba.cut(summary_plain)
            if len(w) >= 2 and w.strip()
        )
        if not source_terms:
            return 1.0
        return len(source_terms & summary_terms) / len(source_terms)
```

```python
import asyncio
from datetime import datetime, timezone

class ExtractionJobScheduler:
    """萃取任务调度器"""

    def __init__(
        self,
        job_repo: "JobRepository",
        summary_generator: SummaryGeneratorService,
        card_extractor: CardExtractionService,
        content_service: "ContentService",
    ):
        self._job_repo = job_repo
        self._summary_gen = summary_generator
        self._card_ext = card_extractor
        self._content = content_service
        self._running = False

    async def start(self):
        """启动调度循环"""
        self._running = True
        while self._running:
            try:
                job = await self._job_repo.claim_next_pending_job()
                if not job:
                    await asyncio.sleep(5)
                    continue
                await self._process_job(job)
            except Exception as e:
                logger.error(f"Scheduler error: {e}", exc_info=True)
                await asyncio.sleep(10)

    async def _process_job(self, job: "ExtractionJob"):
        """处理单个萃取任务"""
        logger.info(f"Processing extraction job {job.id}")
        await self._job_repo.update_status(job.id, "PROCESSING")

        try:
            # 获取源内容
            content = await self._content.get_chapter_content(
                job.content_ref_id, job.content_type
            )
            if not content:
                raise ExtractionError(f"Source content not found: {job.content_ref_id}")

            textbook_info = await self._content.get_textbook_info(
                content.textbook_id
            )

            granularities = job.input_params.get(
                "granularities",
                ["BRIEF", "REVIEW", "DETAILED"]
            )

            summary_ids = []
            card_ids = []
            bundle_ids = []

            # 生成摘要
            if job.job_type in ("FULL_EXTRACTION", "SUMMARY_ONLY"):
                for g in granularities:
                    result = await self._summary_gen.generate_summary(
                        content_ref_id=job.content_ref_id,
                        content_type=job.content_type,
                        raw_content=content.markdown,
                        textbook_info=textbook_info,
                        granularity=Granularity(g),
                    )
                    summary_ids.append(result.summary.id)

            # 萃取卡片
            if job.job_type in ("FULL_EXTRACTION", "CARDS_ONLY"):
                # 使用 BRIEF 摘要 + 原文内容作为卡片萃取输入
                cards = await self._card_ext.extract_cards(
                    content_ref_id=job.content_ref_id,
                    content_type=job.content_type,
                    summary_text=content.markdown[:2000],
                    raw_content=content.markdown,
                    textbook_info=textbook_info,
                )
                card_ids = [c.id for c in cards]

            # 标记成功
            await self._job_repo.mark_success(
                job_id=job.id,
                summary_ids=summary_ids,
                card_ids=card_ids,
                bundle_ids=bundle_ids,
            )

            # 发送事件
            await self._publish_extraction_completed_event(
                job=job,
                summary_ids=summary_ids,
                card_ids=card_ids,
            )

        except Exception as e:
            logger.error(f"Job {job.id} failed: {e}", exc_info=True)
            await self._job_repo.mark_failed(job.id, str(e))
```

```python
class ExtractiveSummaryFallback:
    """基于规则的抽取式摘要降级方案"""

    def generate(self, raw_content: str, max_sentences: int = 5) -> dict:
        """不依赖 LLM，直接从原文抽取关键句"""

        sentences = self._split_sentences(raw_content)

        # 按位置 + 关键词加权评分
        scored = []
        for i, sent in enumerate(sentences):
            score = 0.0
            # 位置加权：开头和结尾的句子更重要
            if i < 3:
                score += 0.3
            if i >= len(sentences) - 2:
                score += 0.2
            # 关键词加权
            score += self._keyword_score(sent)
            # 长度过滤：太短或太长的句子降分
            if 15 <= len(sent) <= 100:
                score += 0.2
            scored.append((i, sent, score))

        # 取评分最高的 N 句，按原序排列
        top = sorted(scored, key=lambda x: -x[2])[:max_sentences]
        top_sorted = sorted(top, key=lambda x: x[0])
        summary_text = "\n".join(s[1] for s in top_sorted)

        return {
            "title": "（自动摘要 - 降级模式）",
            "summary_text": summary_text,
            "summary_plain": summary_text.replace("#", "").replace("*", ""),
            "key_points": [s[1][:50] for s in top_sorted[:5]],
            "formulas": [],   # 降级模式不提取公式
            "keywords": self._extract_top_keywords(raw_content),
            "source": "EXTRACTIVE_FALLBACK",
            "confidence_score": 0.5,
            "fact_check_status": "SKIPPED",
        }
```

```dart
class _KnowledgeCardFlipState extends State<KnowledgeCardFlip>

  late Animation<double> _animation;

  bool _isAnimating = false;
```

```dart
class ReviewBundleFlow extends StatefulWidget {
  final int bundleId;
  const ReviewBundleFlow({super.key, required this.bundleId});

  @override
  State<ReviewBundleFlow> createState() => _ReviewBundleFlowState();
}

class _ReviewBundleFlowState extends State<ReviewBundleFlow> {
  late PageController _pageController;
  int _currentIndex = 0;
  List<KnowledgeCard> _cards = [];
  final Map<int, ReviewResult> _results = {};

  @override
  void initState() {
    super.initState();
    _pageController = PageController();
    _loadBundle();
  }

  Future<void> _loadBundle() async {
    final api = context.read<ContentSummaryApi>();
    final bundle = await api.fetchBundle(widget.bundleId);
    setState(() => _cards = bundle.cards);
  }

  void _onCardReviewed(ReviewResult result) {
    _results[_currentIndex] = result;

    if (_currentIndex < _cards.length - 1) {
      _pageController.nextPage(
        duration: const Duration(milliseconds: 300),
        curve: Curves.easeInOut,
      );
    } else {
      _showCompletionScreen();
    }
  }

  void _showCompletionScreen() {
    // 提交所有复习结果
    context.read<ContentSummaryApi>().submitBatchReviews(
      cardIds: _cards.map((c) => c.id).toList(),
      results: _results,
    );

    Navigator.pushReplacement(
      context,
      MaterialPageRoute(
        builder: (_) => ReviewCompletionScreen(
          totalCards: _cards.length,
          results: _results,
        ),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    if (_cards.isEmpty) {
      return const Center(child: CircularProgressIndicator());
    }

    return Scaffold(
      appBar: AppBar(
        title: Text('${_currentIndex + 1} / ${_cards.length}'),
        leading: IconButton(
          icon: const Icon(Icons.close),
          onPressed: () => _showExitConfirm(context),
        ),
      ),
      body: PageView.builder(
        controller: _pageController,
        physics: const NeverScrollableScrollPhysics(), // 禁止滑动跳过
        itemCount: _cards.length,
        onPageChanged: (i) => setState(() => _currentIndex = i),
        itemBuilder: (context, index) {
          return Padding(
            padding: const EdgeInsets.all(16),
            child: KnowledgeCardFlipWidget(
              card: _cards[index],
              onReview: _onCardReviewed,
            ),
          );
        },
      ),
    );
  }
}
```
