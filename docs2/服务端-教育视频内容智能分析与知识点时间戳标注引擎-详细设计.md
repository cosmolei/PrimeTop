# 服务端 - 教育视频内容智能分析与知识点时间戳标注引擎 详细设计

## 1. 概述

### 1.1 模块定位

教育视频内容智能分析引擎是 PrimeTop 内容生产管线中的核心服务之一，负责对平台中的教学视频（名师讲座、知识点微课、实验演示、试卷讲评等）进行多模态 AI 分析，自动生成结构化的视频知识索引，使视频从"只能从头看到尾的线性媒体"变为"可搜索、可跳转、可交互的结构化学习资源"。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 语音转写 | 将教师讲解音频转录为带时间戳的文本 |
| 章节分割 | 自动检测话题边界，生成视频章节目录 |
| 知识点标注 | 识别视频中每个时间段讲解的知识点，并映射到知识图谱 |
| 关键帧提取 | 智能抽取包含重要板书、PPT、图表的画面帧 |
| OCR 识别 | 对关键帧中的文字、公式、图表进行结构化提取 |
| 内容摘要 | 为每个章节/片段生成知识要点摘要 |
| 交互式时间线 | 生成可在客户端渲染的知识点时间轴数据 |

### 1.3 依赖关系

```
                     ┌─────────────────────────────────┐
                     │   视频内容智能分析引擎           │
                     │   (Video Intelligence Engine)    │
                     └──────────┬──────────────────────┘
                                │
          ┌─────────────────────┼─────────────────────┐
          ▼                     ▼                     ▼
  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
  │ ASR 语音服务  │    │ OCR 视觉服务  │    │ LLM 大模型   │
  │ (语音转写)    │    │ (帧文字识别)  │    │ (摘要/标注)  │
  └──────────────┘    └──────────────┘    └──────────────┘
          │                     │                     │
          ▼                     ▼                     ▼
  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
  │ 知识图谱服务  │    │ 内容管理服务  │    │ 对象存储     │
  │ (知识点映射)  │    │ (视频元数据)  │    │ (视频/帧文件)│
  └──────────────┘    └──────────────┘    └──────────────┘
```

### 1.4 与现有模块的边界

| 已有模块 | 边界说明 |
|---------|---------|
| `多媒体内容播放与交互引擎` | 客户端播放器，消费本引擎产出的时间线数据进行交互式渲染 |
| `教育内容多媒体转码处理与自适应码率流媒体分发服务` | 负责视频转码（分辨率/码率适配）、CDN 分发；本引擎消费转码后的视频进行分析 |
| `教育内容知识切片与微课智能分段生成引擎` | 负责将长内容切分为微课片段（内容生产）；本引擎负责视频内容理解与知识标注（内容分析） |
| `知识点体系与教材映射引擎` | 提供知识点数据，本引擎将视频内容映射到知识点 |
| `RAG与知识库系统` | 本引擎的产出（视频知识索引）可作为 RAG 检索源被检索增强 |

### 2.2 数据库表结构

#### 2.2.1 video_analysis_task 表

```sql
CREATE TABLE video_analysis_task (
    task_id          VARCHAR(64)   PRIMARY KEY COMMENT '分析任务ID',
    video_id         VARCHAR(64)   NOT NULL COMMENT '视频资源ID',
    video_url        VARCHAR(512)  NOT NULL COMMENT '视频文件URL',
    video_duration   INT           NOT NULL DEFAULT 0 COMMENT '视频时长(秒)',
    subject          VARCHAR(20)   NOT NULL COMMENT '学科',
    grade            VARCHAR(20)   NOT NULL COMMENT '年级',
    textbook_version VARCHAR(50)   NOT NULL COMMENT '教材版本',
    chapter          VARCHAR(200)  NOT NULL COMMENT '章节信息',
    video_type       VARCHAR(30)   NOT NULL COMMENT '视频类型: lesson/micro/experiment/exam_review',
    status           VARCHAR(20)   NOT NULL DEFAULT 'pending' COMMENT 'pending/processing/completed/failed/cancelled',
    priority         INT           NOT NULL DEFAULT 5 COMMENT '优先级 1-10',
    pipeline_config  JSON          NOT NULL COMMENT '分析管线步骤配置',
    current_step     VARCHAR(30)   NULL COMMENT '当前执行步骤',
    progress         INT           NOT NULL DEFAULT 0 COMMENT '进度百分比 0-100',
    error_info       JSON          NULL COMMENT '错误信息',
    retry_count      INT           NOT NULL DEFAULT 0 COMMENT '重试次数',
    created_by       VARCHAR(64)   NOT NULL COMMENT '创建人',
    created_at       DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at       DATETIME(3)   NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    completed_at     DATETIME(3)   NULL,
    INDEX idx_status_priority (status, priority DESC),
    INDEX idx_video_id (video_id),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='视频分析任务表';
```

#### 2.2.6 video_timeline 表（Redis 缓存）

时间线数据采用 Redis Hash + Sorted Set 组合缓存，不需要 MySQL 持久化（从上述表实时构建）：

```
# 完整时间线 JSON（客户端消费）
HSET video:timeline:{videoId} data "{timelineJson}" version "{version}" updatedAt "{timestamp}"

# 知识点→视频时间区间索引（搜索服务消费）
ZADD video:kp:index:{kpCode} {startTime} {videoId}:{annotationId}

# 视频搜索全文索引（Elasticsearch）
# 索引名: video_search_index
# 字段: videoId, transcript (full text), kpNames[], kpCodes[], chapterTitles[], searchableLabels[]
```

### 3.3 获取视频交互式时间线

**这是客户端播放器消费的核心接口。**


**查询参数：**
| 参数 | 类型 | 说明 |

#### 4.2.1 ASR 语音转写

```java
public class AsrPipelineStep implements PipelineStep {

    private final AsrService asrService;
    private final TranscriptSegmentSplitter splitter;

    @Override
    public StepResult execute(VideoAnalysisContext ctx) {
        String audioTrackUrl = extractAudio(ctx.getVideoUrl());

        // 调用 ASR 服务进行语音识别
        AsrResult asrResult = asrService.transcribe(AsrRequest.builder()
            .audioUrl(audioTrackUrl)
            .language("zh-CN")
            .enableSpeakerDiarization(true)   // 说话人分离
            .enablePunctuation(true)           // 自动标点
            .enableTimestamp(true)             // 时间戳
            .customVocabulary(buildEduVocabulary(ctx))  // 教育领域热词
            .build());

        // 后处理：按语义边界切分长句为合理片段
        List<TranscriptSegment> segments = splitter.split(asrResult.getSentences(), maxSegmentDuration=15.0);

        // 持久化
        transcriptRepository.batchSave(ctx.getVideoId(), segments);

        // 将全文写入上下文供后续步骤使用
        ctx.setTranscript(segments);
        ctx.setFullTranscript(asrResult.getFullText());

        return StepResult.success("asr", Map.of("segmentCount", segments.size()));
    }

    /**
     * 构建教育领域热词表，提升 ASR 识别准确率
     */
    private List<String> buildEduVocabulary(VideoAnalysisContext ctx) {
        List<String> hotwords = new ArrayList<>();
        hotwords.addAll(kpService.getKpNamesByChapter(ctx.getSubject(), ctx.getGrade(),
                                                       ctx.getTextbookVersion(), ctx.getChapter()));
        hotwords.addAll(commonEduTerms.getTermsForSubject(ctx.getSubject()));
        // 例: ["一次函数", "斜率", "截距", "正比例函数", "自变量", "因变量", ...]
        return hotwords;
    }
}
```

#### 4.2.2 关键帧提取

采用"多策略融合"方式提取关键帧，避免单一策略漏检：

```java
public class KeyframePipelineStep implements PipelineStep {

    private final FrameSamplingService frameSamplingService;
    private final SceneDetectionService sceneDetectionService;
    private final OcrService ocrService;
    private final KeyframeQualityScorer qualityScorer;

    @Override
    public StepResult execute(VideoAnalysisContext ctx) {
        List<FrameCandidate> candidates = new ArrayList<>();

        // 策略1：场景变化检测 —— 画面发生显著变化的帧
        List<FrameCandidate> sceneChangeFrames = sceneDetectionService.detect(ctx.getVideoUrl(),
            SceneDetectionConfig.builder()
                .threshold(0.35)         // 变化阈值
                .minInterval(5.0)        // 最小间隔5秒
                .build());
        candidates.addAll(sceneChangeFrames);

        // 策略2：固定间隔采样 —— 确保覆盖度（每30秒一帧作为候选）
        List<FrameCandidate> sampledFrames = frameSamplingService.sample(ctx.getVideoUrl(),
            interval=30.0);
        candidates.addAll(sampledFrames);

        // 策略3：基于转录文本的内容关键帧 —— 转录文本中出现重要关键词时提取帧
        List<FrameCandidate> contentFrames = extractContentTriggeredFrames(ctx.getTranscript(),
            ctx.getVideoUrl());
        candidates.addAll(contentFrames);

        // 去重 + 质量评分
        List<FrameCandidate> merged = deduplicate(candidates, minInterval=3.0);
        for (FrameCandidate frame : merged) {
            frame.setQualityScore(qualityScorer.score(frame));  // 评估清晰度、亮度、信息量
        }

        // 过滤低质量帧，保留 Top-N
        List<KeyframeRecord> keyframes = merged.stream()
            .filter(f -> f.getQualityScore() > 0.5)
            .sorted(Comparator.comparing(FrameCandidate::getQualityScore).reversed())
            .limit(maxKeyframes(ctx.getVideoDuration()))  // 按视频时长限制帧数
            .sorted(Comparator.comparing(FrameCandidate::getTimestamp))
            .map(this::toKeyframeRecord)
            .collect(Collectors.toList());

        // 异步上传帧图片到对象存储
        keyframeStorageService.batchUpload(ctx.getVideoId(), keyframes);

        ctx.setKeyframes(keyframes);
        return StepResult.success("keyframe", Map.of("keyframeCount", keyframes.size()));
    }

    private int maxKeyframes(int videoDuration) {
        // 视频时长 → 最大帧数: 10分钟→30帧, 30分钟→60帧, 60分钟→100帧
        return Math.min(120, Math.max(15, videoDuration / 30));
    }
}
```

#### 4.2.3 OCR 文字识别与结构化

```java
public class OcrPipelineStep implements PipelineStep {

    private final OcrService ocrService;
    private final FormulaRecognitionService formulaService;
    private final ChartDetectionService chartService;

    @Override
    public StepResult execute(VideoAnalysisContext ctx) {
        for (KeyframeRecord frame : ctx.getKeyframes()) {
            // 通用 OCR 文字识别
            OcrResult ocrResult = ocrService.recognize(frame.getImageUrl(),
                OcrConfig.builder()
                    .languages(Arrays.asList("zh-Hans", "en"))
                    .enableHandwriting(true)    // 支持手写体
                    .build());

            // 数学公式专用识别（LaTeX 输出）
            List<FormulaBlock> formulas = formulaService.recognize(frame.getImageUrl());
            // 例: 检测到 "y=kx+b" → {"latex": "y=kx+b", "bbox": [...]}

            // 图表检测（坐标系、几何图、电路图等）
            List<ChartBlock> charts = chartService.detect(frame.getImageUrl());

            // 合并 OCR 结果
            List<OcrBlock> blocks = mergeOcrResults(ocrResult, formulas, charts);
            frame.setOcrBlocks(blocks);
            frame.setOcrText(extractPlainText(blocks));

            // 分类帧类型
            frame.setFrameType(classifyFrameType(blocks));
        }

        ctx.getKeyframes().forEach(keyframeRepository::updateOcr);
        return StepResult.success("ocr");
    }

    private String classifyFrameType(List<OcrBlock> blocks) {
        boolean hasFormula = blocks.stream().anyMatch(b -> b.getType().equals("formula"));
        boolean hasChart = blocks.stream().anyMatch(b -> b.getType().equals("chart"));
        long textBlocks = blocks.stream().filter(b -> b.getType().equals("text")).count();

        if (hasChart) return "chart";
        if (hasFormula && textBlocks < 3) return "blackboard";
        if (textBlocks > 10) return "ppt";
        return "unknown";
    }
}
```

#### 4.2.4 章节分割

章节分割采用"多信号融合"策略：结合转录文本的话题变化、画面场景变化、PPT翻页检测来判定章节边界。

```java
public class SegmentPipelineStep implements PipelineStep {

    private final LlmService llmService;
    private static final int MIN_CHAPTER_DURATION = 60;   // 最小章节60秒
    private static final int MAX_CHAPTER_DURATION = 600;  // 最大章节600秒

    @Override
    public StepResult execute(VideoAnalysisContext ctx) {
        // Step 1: 文本嵌入 + 话题聚类
        List<TranscriptSegment> segments = ctx.getTranscript();
        List<TextEmbedding> embeddings = segments.stream()
            .map(s -> embeddingService.embed(s.getText()))
            .collect(Collectors.toList());

        // Step 2: 计算相邻文本片段的语义相似度，检测语义断点
        List<Double> similarities = computeAdjacentSimilarities(embeddings);
        List<Double> breakpoints = detectSemanticBreakpoints(similarities, threshold=0.55);

        // Step 3: 结合场景变化点
        Set<Double> sceneChangePoints = ctx.getSceneChanges().stream()
            .map(SceneChange::getTimestamp)
            .collect(Collectors.toSet());

        // Step 4: 合并信号，生成候选边界点
        List<Double> candidateBoundaries = mergeBreakpoints(breakpoints, sceneChangePoints);

        // Step 5: 应用时长约束（合并过短的章节，拆分过长的章节）
        List<Double> finalBoundaries = applyDurationConstraints(
            candidateBoundaries, ctx.getVideoDuration(),
            MIN_CHAPTER_DURATION, MAX_CHAPTER_DURATION);

        // Step 6: LLM 生成章节标题和摘要
        List<VideoChapter> chapters = new ArrayList<>();
        for (int i = 0; i < finalBoundaries.size() - 1; i++) {
            double start = finalBoundaries.get(i);
            double end = finalBoundaries.get(i + 1);
            String chapterTranscript = extractTranscriptInRange(segments, start, end);

            ChapterMeta meta = llmService.generateChapterMeta(ChapterPrompt.builder()
                .subject(ctx.getSubject())
                .grade(ctx.getGrade())
                .chapter(ctx.getChapter())
                .transcript(chapterTranscript)
                .build());

            chapters.add(VideoChapter.builder()
                .chapterId("ch_" + String.format("%03d", i + 1))
                .title(meta.getTitle())
                .startTime(start)
                .endTime(end)
                .summary(meta.getSummary())
                .difficulty(meta.getDifficulty())
                .seqNo(i + 1)
                .build());
        }

        chapterRepository.batchSave(ctx.getVideoId(), chapters);
        ctx.setChapters(chapters);
        return StepResult.success("segment");
    }
}
```

#### 4.2.5 知识点标注

这是整个引擎的核心步骤，采用"多策略融合 + LLM 增强"方式：

```java
public class KpAnnotatePipelineStep implements PipelineStep {

    private final KnowledgePointService kpService;
    private final LlmService llmService;

    @Override
    public StepResult execute(VideoAnalysisContext ctx) {
        List<KnowledgePointAnnotation> annotations = new ArrayList<>();

        // 获取该视频对应的学科/年级/教材章节下的所有知识点
        List<KnowledgePoint> candidateKps = kpService.getKpsByChapter(
            ctx.getSubject(), ctx.getGrade(), ctx.getTextbookVersion(), ctx.getChapter());

        // 策略1: 基于转录文本的关键词匹配（高准确率，低召回率）
        List<KpAnnotationCandidate> keywordMatches = keywordBasedAnnotation(
            ctx.getTranscript(), candidateKps);
        annotations.addAll(toAnnotations(keywordMatches, "asr_keyword"));

        // 策略2: 基于关键帧 OCR 文本的关键词匹配
        List<KpAnnotationCandidate> ocrMatches = ocrBasedAnnotation(
            ctx.getKeyframes(), candidateKps);
        annotations.addAll(toAnnotations(ocrMatches, "ocr_keyword"));

        // 策略3: LLM 语义级知识点标注（高召回率，中等准确率）
        List<KpAnnotationCandidate> llmMatches = llmBasedAnnotation(
            ctx.getTranscript(), ctx.getKeyframes(), candidateKps, ctx);
        annotations.addAll(toAnnotations(llmMatches, "asr_llm"));

        // 去重 + 合并重叠区间
        List<KnowledgePointAnnotation> merged = mergeAndDeduplicate(annotations);

        // 过滤低置信度标注
        List<KnowledgePointAnnotation> filtered = merged.stream()
            .filter(a -> a.getConfidence() >= 0.6)
            .sorted(Comparator.comparing(KnowledgePointAnnotation::getStartTime))
            .collect(Collectors.toList());

        // 持久化
        kpAnnotationRepository.batchSave(ctx.getVideoId(), filtered);
        ctx.setKpAnnotations(filtered);
        return StepResult.success("kp_annotate");
    }

    /**
     * LLM 语义级知识点标注
     * 给 LLM 提供转录文本（分段）+ 知识点列表，让模型标注每个时间段讲了哪些知识点
     */
    private List<KpAnnotationCandidate> llmBasedAnnotation(
            List<TranscriptSegment> transcript,
            List<KeyframeRecord> keyframes,
            List<KnowledgePoint> candidateKps,
            VideoAnalysisContext ctx) {

        // 按章节处理，避免上下文过长
        List<KpAnnotationCandidate> results = new ArrayList<>();

        for (VideoChapter chapter : ctx.getChapters()) {
            String chapterTranscript = extractTranscriptInRange(transcript,
                chapter.getStartTime(), chapter.getEndTime());

            String keyframeContext = extractKeyframeOcrInRange(keyframes,
                chapter.getStartTime(), chapter.getEndTime());

            String prompt = buildKpAnnotationPrompt(chapter, chapterTranscript,
                keyframeContext, candidateKps);

            LlmResponse response = llmService.chat(LlmRequest.builder()
                .model("gpt-4o-mini")  // 使用轻量模型控制成本
                .messages(Arrays.asList(
                    Message.system(KP_ANNOTATION_SYSTEM_PROMPT),
                    Message.user(prompt)))
                .temperature(0.1)      // 低温度保证稳定性
                .responseFormat("json_object")
                .build());

            // 解析 LLM 返回的 JSON 标注结果
            List<KpAnnotationCandidate> chapterAnnotations = parseLlmAnnotations(
                response.getContent(), chapter);
            results.addAll(chapterAnnotations);
        }

        return results;
    }

    private static final String KP_ANNOTATION_SYSTEM_PROMPT = """
        你是教育内容分析专家。你的任务是分析教学视频的转录文本，标注其中讲解的知识点。

        注意事项：
        1. 只标注在对应时间段内**明确讲解**的知识点，不要过度推断。
        2. 精确给出知识点讲解的起止时间。
        3. 如果某知识点被"提及但未深入讲解"，标注为 mention 类型。
        4. confidence: 你对该标注的确信度 (0.0-1.0)。
        5. bloomLevel: 该知识点的认知层级 (remembering/understanding/applying/analyzing/evaluating/creating)。

        严格返回以下 JSON 格式：
        {"annotations": [{"kpCode": "...", "kpName": "...", "startTime": 0.0, "endTime": 0.0,
                           "confidence": 0.9, "annotationType": "primary", "bloomLevel": "understanding",
                           "contextSnippet": "..."}]}
        """;
}
```

#### 4.2.6 时间线组装器

```java
public class TimelineBuilder {

    public VideoTimelineData build(String videoId, VideoAnalysisContext ctx) {
        List<TimelineChapter> timelineChapters = new ArrayList<>();

        for (VideoChapter chapter : ctx.getChapters()) {
            // 收集该章节内的知识点标注
            List<KnowledgePointAnnotation> chapterKps = ctx.getKpAnnotations().stream()
                .filter(a -> a.getStartTime() >= chapter.getStartTime()
                          && a.getEndTime() <= chapter.getEndTime())
                .collect(Collectors.toList());

            // 收集该章节内的关键帧
            List<KeyframeRecord> chapterFrames = ctx.getKeyframes().stream()
                .filter(f -> f.getTimestamp() >= chapter.getStartTime()
                          && f.getTimestamp() <= chapter.getEndTime())
                .collect(Collectors.toList());

            // 组装时间线条目
            List<TimelineItem> items = new ArrayList<>();
            chapterKps.forEach(kp -> items.add(TimelineItem.ofKp(kp)));
            chapterFrames.forEach(frame -> items.add(TimelineItem.ofKeyframe(frame)));

            // 按时间排序
            items.sort(Comparator.comparing(TimelineItem::getStartTimestamp));

            timelineChapters.add(TimelineChapter.builder()
                .type("chapter")
                .start(chapter.getStartTime())
                .end(chapter.getEndTime())
                .title(chapter.getTitle())
                .icon(determineIcon(chapter))
                .items(items)
                .build());
        }

        // 生成搜索跳转点
        List<SearchablePoint> searchablePoints = generateSearchablePoints(ctx);

        return VideoTimelineData.builder()
            .videoId(videoId)
            .version(incrementVersion(videoId))
            .generatedAt(Instant.now())
            .timeline(timelineChapters)
            .searchablePoints(searchablePoints)
            .build();
    }

    /**
     * 生成搜索跳转点 —— 为每个知识点生成一个自然语言问题
     * 例: 知识点"一次函数的定义" → "什么是一次函数"
     */
    private List<SearchablePoint> generateSearchablePoints(VideoAnalysisContext ctx) {
        return ctx.getKpAnnotations().stream()
            .filter(a -> "primary".equals(a.getAnnotationType()))
            .map(a -> SearchablePoint.builder()
                .timestamp(a.getStartTime())
                .label(generateSearchLabel(a))
                .kpCode(a.getKpCode())
                .build())
            .collect(Collectors.toList());
    }

    private String generateSearchLabel(KnowledgePointAnnotation kp) {
        // 根据知识点名称生成自然语言问题
        // "一次函数的定义" → "什么是一次函数"
        // "二次根式的乘法" → "二次根式的乘法怎么算"
        if (kp.getKpName().contains("定义") || kp.getKpName().contains("概念")) {
            return "什么是" + kp.getKpName().replace("的定义", "").replace("的概念", "");
        }
        if (kp.getKpName().contains("性质")) {
            return kp.getKpName().replace("的性质", "") + "有什么性质";
        }
        return kp.getKpName();
    }
}
```

### 5.1 管线编排器

```java
/**
 * 视频分析管线编排器
 * 负责按配置的步骤顺序执行分析管线，支持步骤跳过、重试和断点续跑
 */
@Service
public class VideoAnalysisPipeline {

    private final Map<String, PipelineStep> stepRegistry;
    private final VideoAnalysisTaskRepository taskRepository;
    private final TimelineBuilder timelineBuilder;
    private final VideoTimelineCache timelineCache;
    private final VideoSearchIndexService searchIndexService;

    @Autowired
    public VideoAnalysisPipeline(List<PipelineStep> steps,
                                  VideoAnalysisTaskRepository taskRepository,
                                  TimelineBuilder timelineBuilder,
                                  VideoTimelineCache timelineCache,
                                  VideoSearchIndexService searchIndexService) {
        this.stepRegistry = steps.stream()
            .collect(Collectors.toMap(PipelineStep::getName, Function.identity()));
        this.taskRepository = taskRepository;
        this.timelineBuilder = timelineBuilder;
        this.timelineCache = timelineCache;
        this.searchIndexService = searchIndexService;
    }

    public void executeTask(String taskId) {
        VideoAnalysisTask task = taskRepository.findByTaskId(taskId);
        VideoAnalysisContext ctx = VideoAnalysisContext.from(task);

        try {
            taskRepository.updateStatus(taskId, "processing");

            for (String stepName : task.getPipelineConfig()) {
                if (ctx.isStepCompleted(stepName)) {
                    continue;  // 断点续跑：跳过已完成的步骤
                }

                PipelineStep step = stepRegistry.get(stepName);
                if (step == null) {
                    throw new IllegalStateException("未知的管线步骤: " + stepName);
                }

                taskRepository.updateCurrentStep(taskId, stepName);

                StepResult result = executeStepWithTimeout(step, ctx, task.getStepTimeoutMinutes(stepName));

                if (!result.isSuccess()) {
                    throw new PipelineStepException(stepName, result.getErrorMessage());
                }

                ctx.markStepCompleted(stepName);
                taskRepository.updateProgress(taskId, ctx.getOverallProgress());
            }

            // 所有步骤完成，组装时间线
            VideoTimelineData timeline = timelineBuilder.build(task.getVideoId(), ctx);
            timelineCache.save(task.getVideoId(), timeline);

            // 更新 Elasticsearch 搜索索引
            searchIndexService.indexVideo(task.getVideoId(), ctx);

            taskRepository.updateStatus(taskId, "completed");

        } catch (Exception e) {
            handleTaskFailure(task, e);
        }
    }

    private StepResult executeStepWithTimeout(PipelineStep step, VideoAnalysisContext ctx, int timeoutMinutes) {
        ExecutorService executor = Executors.newSingleThreadExecutor();
        try {
            Future<StepResult> future = executor.submit(() -> step.execute(ctx));
            return future.get(timeoutMinutes, TimeUnit.MINUTES);
        } catch (TimeoutException e) {
            future.cancel(true);
            return StepResult.failure("步骤超时: " + step.getName());
        } finally {
            executor.shutdownNow();
        }
    }

    private void handleTaskFailure(VideoAnalysisTask task, Exception e) {
        int retryCount = task.getRetryCount() + 1;
        if (retryCount <= task.getMaxRetries()) {
            // 指数退避重试
            long delaySeconds = (long) Math.pow(2, retryCount) * 60;
            taskRepository.scheduleRetry(task.getTaskId(), retryCount, delaySeconds);
        } else {
            taskRepository.updateStatusWithError(task.getTaskId(), "failed",
                Map.of("error", e.getMessage(), "retryCount", retryCount));
            // 发送告警
            alertService.send(AlertLevel.WARN,
                "视频分析任务失败",
                String.format("视频 %s 分析失败，已耗尽重试次数。最后错误: %s",
                    task.getVideoId(), e.getMessage()));
        }
    }
}
```

### 5.2 视频搜索索引服务

```java
@Service
public class VideoSearchIndexService {

    private final ElasticsearchClient esClient;
    private static final String INDEX_NAME = "video_search_index";

    /**
     * 将视频分析结果索引到 Elasticsearch，支持全文搜索和知识点搜索
     */
    public void indexVideo(String videoId, VideoAnalysisContext ctx) {
        VideoSearchDocument doc = VideoSearchDocument.builder()
            .videoId(videoId)
            .subject(ctx.getSubject())
            .grade(ctx.getGrade())
            .textbookVersion(ctx.getTextbookVersion())
            .chapter(ctx.getChapter())
            .videoType(ctx.getVideoType())
            .videoDuration(ctx.getVideoDuration())
            .transcript(ctx.getFullTranscript())                    // 全文转录
            .chapterTitles(ctx.getChapters().stream()               // 章节标题列表
                .map(VideoChapter::getTitle)
                .collect(Collectors.toList()))
            .kpNames(ctx.getKpAnnotations().stream()                // 知识点名称列表
                .map(KnowledgePointAnnotation::getKpName)
                .distinct()
                .collect(Collectors.toList()))
            .kpCodes(ctx.getKpAnnotations().stream()                // 知识点编码列表
                .map(KnowledgePointAnnotation::getKpCode)
                .distinct()
                .collect(Collectors.toList()))
            .searchableLabels(ctx.getSearchableLabels())            // 自然语言搜索标签
            .annotations(ctx.getKpAnnotations().stream()            // 标注详情
                .map(a -> SearchAnnotation.builder()
                    .kpCode(a.getKpCode())
                    .kpName(a.getKpName())
                    .startTime(a.getStartTime())
                    .endTime(a.getEndTime())
                    .snippet(a.getContextSnippet())
                    .build())
                .collect(Collectors.toList()))
            .build();

        IndexRequest<VideoSearchDocument> request = IndexRequest.of(i -> i
            .index(INDEX_NAME)
            .id(videoId)
            .document(doc));

        esClient.index(request);
    }

    /**
     * 按知识点编码搜索包含该知识点讲解的视频片段
     */
    public SearchResult searchByKpCode(String kpCode, String subject, String grade,
                                        int page, int size) {
        SearchRequest request = SearchRequest.of(s -> {
            s.index(INDEX_NAME)
             .from((page - 1) * size)
             .size(size)
             .query(Query.of(q -> q
                 .bool(b -> {
                     b.must(m -> m.term(t -> t.field("kpCodes").value(kpCode)));
                     if (subject != null) {
                         b.filter(f -> f.term(t -> t.field("subject").value(subject)));
                     }
                     if (grade != null) {
                         b.filter(f -> f.term(t -> t.field("grade").value(grade)));
                     }
                     return b;
                 })));
             return s;
        });

        SearchResponse<Map> response = esClient.search(request, Map.class);
        return toSearchResult(response, page, size);
    }
}
```

### 6.2 步骤级容错策略

```java
public class PipelineStepErrorHandler {

    /**
     * 根据步骤类型确定容错策略
     */
    public StepFallbackStrategy getFallbackStrategy(String stepName, Exception error) {
        return switch (stepName) {
            case "asr" -> StepFallbackStrategy.fatal();        // ASR 失败 = 无法继续，终止任务
            case "scene_detect" -> StepFallbackStrategy.skip(); // 场景检测失败可跳过
            case "keyframe" -> StepFallbackStrategy.skip();     // 关键帧提取失败可跳过（使用固定采样）
            case "ocr" -> StepFallbackStrategy.skip();          // OCR 失败可跳过（仅依赖转录文本）
            case "segment" -> StepFallbackStrategy.degrade(     // 章节分割失败 → 使用固定时长分割
                () -> fixedDurationSegments(300));
            case "kp_annotate" -> StepFallbackStrategy.degrade( // 知识点标注失败 → 仅保留关键词匹配结果
                () -> keywordOnlyAnnotations());
            case "summarize" -> StepFallbackStrategy.skip();    // 摘要生成失败可跳过
            default -> StepFallbackStrategy.fatal();
        };
    }
}
```

### 7.4 成本控制

```java
/**
 * 单任务成本估算与控制
 */
public class CostEstimator {

    // 各步骤单价（元/分钟视频）
    private static final Map<String, BigDecimal> STEP_UNIT_COST = Map.of(
        "asr",         new BigDecimal("0.06"),   // ASR: ~0.06元/分钟
        "scene_detect", new BigDecimal("0.02"),   // 场景检测: CPU 计算
        "keyframe",     new BigDecimal("0.01"),   // 帧提取: CPU 计算
        "ocr",          new BigDecimal("0.03"),   // OCR: ~0.03元/帧 × 帧数/分钟
        "segment",      new BigDecimal("0.005"),  // 章节分割: 轻量计算
        "kp_annotate",  new BigDecimal("0.04"),   // LLM 标注: ~0.04元/分钟(Token折算)
        "summarize",    new BigDecimal("0.02")    // 摘要: LLM 轻量调用
    );

    public BigDecimal estimateCost(int videoDurationMinutes, List<String> pipeline) {
        return pipeline.stream()
            .map(step -> STEP_UNIT_COST.getOrDefault(step, BigDecimal.ZERO)
                .multiply(BigDecimal.valueOf(videoDurationMinutes)))
            .reduce(BigDecimal.ZERO, BigDecimal::add);
    }

    // 示例: 15分钟视频完整管线 ≈ 15 × (0.06+0.02+0.01+0.03+0.005+0.04+0.02) = 15 × 0.185 ≈ 2.78元
}
```
