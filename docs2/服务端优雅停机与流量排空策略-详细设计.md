## 1. 设计目标

### 1.1 核心目标

| 目标 | 说明 | 指标 |
|------|------|------|
| 零请求丢失 | 停机期间所有在途请求完整处理 | 在途请求完成率 ≥ 99.99% |
| 零连接中断 | 长连接(SSE/WebSocket)平滑迁移 | 客户端感知中断率 < 0.1% |
| 有序释放 | 资源按依赖逆序释放 | 无资源泄露 |
| 快速收敛 | 停机过程在有限时间内完成 | 总停机时间 ≤ 30s |
| 可观测 | 停机全过程可追踪 | 停机事件 100% 记录 |

### 1.2 适用场景

```
┌─────────────────────────────────────────────────────────┐
│                    触发优雅停机的场景                      │
├──────────────────┬──────────────────────────────────────┤
│ K8s 滚动更新      │ Deployment 更新触发 Pod 终止          │
│ K8s 缩容          │ HPA/VPA 触发 Pod 数量减少            │
│ 手动缩容/重启      │ kubectl scale / rollout restart     │
│ OOM/Killed        │ 系统资源限制触发强制回收              │
│ 节点排空          │ kubectl drain 节点维护               │
│ 健康检查失败       │ Liveness 探针连续失败触发重启         │
│ 灰度切换          │ 灰度发布版本切换                      │
│ 紧急关停          │ 安全事件触发服务紧急下线               │
└──────────────────┴──────────────────────────────────────┘
```

### 1.3 设计约束

1. **K8s terminationGracePeriodSeconds** 默认 30s，最大可配置至 120s
2. **信号语义**：SIGTERM 触发优雅停机，SIGKILL 强制终止（不可捕获）
3. **FastAPI/uvicorn** 事件循环需在停机期间继续运行以完成在途请求
4. **Celery Worker** 有独立的停机信号处理机制（SIGTERM + warm shutdown）
5. **AI 模型调用** 单次推理可达 30s+，需考虑长尾请求处理
6. **数据库连接池** 关闭前需等待活跃事务完成或安全回滚

```python
@dataclass
class ShutdownContext:
    """停机上下文，贯穿整个停机流程"""
    # 触发信息
    reason: ShutdownReason
    signal_received_at: datetime
    phase: ShutdownPhase = ShutdownPhase.RUNNING

    # 配置参数
    drain_traffic_timeout: float = 5.0       # 流量排空超时 (s)
    drain_request_timeout: float = 20.0      # 请求排空超时 (s)
    release_resource_timeout: float = 3.0    # 资源释放超时 (s)
    total_deadline: float = 28.0             # 总停机截止时间 (s)

    # 运行时状态
    active_http_requests: int = 0
    active_sse_connections: int = 0
    active_ws_connections: int = 0
    active_ai_calls: int = 0
    active_db_transactions: int = 0
    active_celery_tasks: int = 0

    # 统计
    completed_requests: int = 0
    drained_connections: int = 0
    released_resources: int = 0
    force_killed_requests: int = 0

    # 日志
    phase_logs: list = field(default_factory=list)

    def remaining_time(self) -> float:
        """距离总截止时间剩余秒数"""
        elapsed = (datetime.now() - self.signal_received_at).total_seconds()
        return max(0, self.total_deadline - elapsed)

    def is_overall_timeout(self) -> bool:
        return self.remaining_time() <= 0

    def log_phase(self, message: str):
        entry = {
            "timestamp": datetime.now().isoformat(),
            "phase": self.phase.value,
            "message": message,
        }
        self.phase_logs.append(entry)
        logger.info(f"[Shutdown:{self.phase.value}] {message}")
```

### 3.3 在途请求追踪器

```python
class InFlightTracker:
    """
    在途请求追踪器
    使用 asyncio.Event + 计数器实现零请求时的即时通知
    """

    def __init__(self):
        self._counter: int = 0
        self._lock = asyncio.Lock()
        self._zero_event = asyncio.Event()
        self._zero_event.set()  # 初始为 0，标记为"已归零"
        self._request_details: dict[str, dict] = {}  # request_id -> 详情

    async def acquire(self, request_id: str, detail: dict = None) -> bool:
        """请求进入，计数器 +1"""
        async with self._lock:
            self._counter += 1
            self._zero_event.clear()
            self._request_details[request_id] = {
                "entered_at": time.time(),
                "detail": detail or {},
            }
        return True

    async def release(self, request_id: str):
        """请求完成，计数器 -1"""
        async with self._lock:
            self._counter -= 1
            self._request_details.pop(request_id, None)
            if self._counter <= 0:
                self._counter = 0
                self._zero_event.set()

    @property
    def count(self) -> int:
        return self._counter

    def get_stale_requests(self, threshold_seconds: float = 10.0) -> list[dict]:
        """返回超过阈值仍在处理的请求"""
        now = time.time()
        stale = []
        for req_id, info in self._request_details.items():
            elapsed = now - info["entered_at"]
            if elapsed > threshold_seconds:
                stale.append({
                    "request_id": req_id,
                    "elapsed_seconds": round(elapsed, 2),
                    **info["detail"],
                })
        return stale

    async def wait_for_zero(self, timeout: float) -> bool:
        """等待计数器归零，返回是否在超时内归零"""
        try:
            await asyncio.wait_for(self._zero_event.wait(), timeout=timeout)
            return True
        except asyncio.TimeoutError:
            return False
```

### 4.1 优雅停机管理器

```python
# app/core/shutdown.py

logger = logging.getLogger("shutdown")


class GracefulShutdownManager:
    """
    优雅停机管理器
    负责协调整个停机流程的各个阶段
    """

    _instance: Optional["GracefulShutdownManager"] = None

    def __init__(self, config: DrainConfig = None):
        self._config = config or DrainConfig()
        self._context: Optional[ShutdownContext] = None
        self._http_tracker = InFlightTracker()
        self._sse_tracker = InFlightTracker()
        self._ws_tracker = InFlightTracker()
        self._ai_tracker = InFlightTracker()
        self._shutdown_event = asyncio.Event()
        self._is_shutting_down = False

        # 资源释放回调注册表 (按优先级逆序)
        self._release_callbacks: list[tuple[int, str, callable]] = []
        # (priority, name, async_callback) — priority 越大越先执行

    @classmethod
    def get_instance(cls) -> "GracefulShutdownManager":
        if cls._instance is None:
            cls._instance = cls()
        return cls._instance

    @property
    def is_shutting_down(self) -> bool:
        return self._is_shutting_down

    @property
    def context(self) -> Optional[ShutdownContext]:
        return self._context

    # ---- 信号注册 ----

    def register_signal_handlers(self, loop: asyncio.AbstractEventLoop):
        """注册信号处理器"""
        for sig in (signal.SIGTERM, signal.SIGINT):
            loop.add_signal_handler(
                sig,
                lambda s=sig: asyncio.create_task(self._handle_signal(s))
            )
        logger.info("Shutdown signal handlers registered (SIGTERM, SIGINT)")

    async def _handle_signal(self, sig: signal.Signals):
        """信号处理入口"""
        if self._is_shutting_down:
            logger.warning(
                f"Signal {sig.name} received but shutdown already in progress"
            )
            return

        logger.info(f"Signal {sig.name} received, initiating graceful shutdown")
        self._is_shutting_down = True
        self._shutdown_event.set()

        self._context = ShutdownContext(
            reason=ShutdownReason.SIGTERM if sig == signal.SIGTERM else ShutdownReason.MANUAL,
            signal_received_at=datetime.now(),
            total_deadline=self._config.total_deadline,
        )

        await self._execute_shutdown()

    # ---- 请求追踪 API ----

    async def track_http_request(self, request_id: str, detail: dict = None):
        """追踪 HTTP 请求进入"""
        if self._is_shutting_down:
            # 停机期间拒绝新请求
            return False
        await self._http_tracker.acquire(request_id, detail)
        return True

    async def untrack_http_request(self, request_id: str):
        """追踪 HTTP 请求完成"""
        await self._http_tracker.release(request_id)

    async def track_sse(self, conn_id: str, detail: dict = None):
        await self._sse_tracker.acquire(conn_id, detail)
        return True

    async def untrack_sse(self, conn_id: str):
        await self._sse_tracker.release(conn_id)

    async def track_ws(self, conn_id: str, detail: dict = None):
        await self._ws_tracker.acquire(conn_id, detail)
        return True

    async def untrack_ws(self, conn_id: str):
        await self._ws_tracker.release(conn_id)

    async def track_ai_call(self, call_id: str, detail: dict = None):
        await self._ai_tracker.acquire(call_id, detail)
        return True

    async def untrack_ai_call(self, call_id: str):
        await self._ai_tracker.release(call_id)

    # ---- 资源释放回调注册 ----

    def register_release_callback(
        self,
        name: str,
        callback: callable,
        priority: int = 50,
    ):
        """
        注册资源释放回调
        priority: 0-100, 越大越先执行
        """
        self._release_callbacks.append((priority, name, callback))
        self._release_callbacks.sort(key=lambda x: x[0], reverse=True)
        logger.debug(f"Registered release callback: {name} (priority={priority})")

    # ---- 停机流程 ----

    async def _execute_shutdown(self):
        """执行完整停机流程"""
        ctx = self._context
        try:
            # Phase 1: 流量排空
            ctx.phase = ShutdownPhase.DRAINING_TRAFFIC
            ctx.log_phase("Phase 1: Traffic draining started")
            await self._phase_drain_traffic(ctx)

            # Phase 2: 请求排空
            ctx.phase = ShutdownPhase.DRAINING_REQUESTS
            ctx.log_phase("Phase 2: Request draining started")
            await self._phase_drain_requests(ctx)

            # Phase 3: 资源释放
            ctx.phase = ShutdownPhase.RELEASING_RESOURCES
            ctx.log_phase("Phase 3: Resource release started")
            await self._phase_release_resources(ctx)

            # Phase 4: 完成
            ctx.phase = ShutdownPhase.COMPLETED
            ctx.log_phase(
                f"Shutdown completed: "
                f"http_completed={ctx.completed_requests}, "
                f"connections_drained={ctx.drained_connections}, "
                f"resources_released={ctx.released_resources}"
            )

        except Exception as e:
            ctx.log_phase(f"Shutdown error: {e}")
            ctx.phase = ShutdownPhase.FORCE_KILLED
        finally:
            self._emit_shutdown_metrics(ctx)

    async def _phase_drain_traffic(self, ctx: ShutdownContext):
        """Phase 1: 流量排空"""
        timeout = min(
            self._config.drain_traffic_timeout,
            ctx.remaining_time() * 0.3,  # 最多用 30% 剩余时间
        )

        # 将 readiness probe 置为 NotReady
        # (通过 shutdown_manager.is_shutting_down 控制)
        ctx.log_phase("Readiness probe set to NotReady, stopping new traffic")

        # 等待短暂的流量排空窗口
        # K8s iptables/ipvs 规则更新需要时间
        await asyncio.sleep(min(timeout, 2.0))

        ctx.log_phase(
            f"Traffic drain phase complete, "
            f"remaining_inflight: http={self._http_tracker.count} "
            f"sse={self._sse_tracker.count} "
            f"ws={self._ws_tracker.count} "
            f"ai={self._ai_tracker.count}"
        )

    async def _phase_drain_requests(self, ctx: ShutdownContext):
        """Phase 2: 请求排空"""
        remaining = ctx.remaining_time()
        if remaining <= 0:
            ctx.log_phase("No time remaining for request drain, skipping")
            return

        # 并行等待各类型在途请求
        tasks = []

        # HTTP 请求排空
        if self._http_tracker.count > 0:
            http_timeout = min(self._config.http_drain_timeout, remaining * 0.6)
            tasks.append(self._drain_http_requests(ctx, http_timeout))

        # SSE 连接排空
        if self._sse_tracker.count > 0:
            sse_timeout = min(self._config.sse_drain_timeout, remaining * 0.5)
            tasks.append(self._drain_sse_connections(ctx, sse_timeout))

        # WebSocket 连接排空
        if self._ws_tracker.count > 0:
            ws_timeout = min(self._config.ws_drain_timeout, remaining * 0.5)
            tasks.append(self._drain_ws_connections(ctx, ws_timeout))

        # AI 推理请求排空
        if self._ai_tracker.count > 0:
            ai_timeout = min(self._config.ai_drain_timeout, remaining * 0.7)
            tasks.append(self._drain_ai_calls(ctx, ai_timeout))

        if tasks:
            # 使用剩余时间作为总超时
            total_timeout = max(remaining - self._config.release_resource_timeout, 1.0)
            try:
                await asyncio.wait_for(
                    asyncio.gather(*tasks, return_exceptions=True),
                    timeout=total_timeout,
                )
            except asyncio.TimeoutError:
                ctx.log_phase("Request drain timed out, some requests force-killed")
                ctx.force_killed_requests = (
                    self._http_tracker.count
                    + self._sse_tracker.count
                    + self._ws_tracker.count
                    + self._ai_tracker.count
                )

        # 定期输出排空进度日志
        ctx.log_phase(
            f"Request drain complete: "
            f"http_remaining={self._http_tracker.count}, "
            f"sse_remaining={self._sse_tracker.count}, "
            f"ws_remaining={self._ws_tracker.count}, "
            f"ai_remaining={self._ai_tracker.count}"
        )

    async def _drain_http_requests(self, ctx: ShutdownContext, timeout: float):
        """排空 HTTP 在途请求"""
        ctx.log_phase(
            f"Waiting for {self._http_tracker.count} HTTP requests to complete "
            f"(timeout={timeout:.1f}s)"
        )

        # 分阶段等待
        # 第一阶段：等待正常完成
        normal_timeout = timeout * 0.7
        all_done = await self._http_tracker.wait_for_zero(normal_timeout)

        if not all_done:
            # 第二阶段：报告长尾请求
            stale = self._http_tracker.get_stale_requests(self._config.http_stale_threshold)
            if stale:
                ctx.log_phase(
                    f"Stale HTTP requests ({len(stale)}): "
                    f"{[s['request_id'] for s in stale]}"
                )

            # 第三阶段：继续等待到超时
            remaining_timeout = timeout - normal_timeout
            all_done = await self._http_tracker.wait_for_zero(remaining_timeout)

        ctx.completed_requests += (
            self._http_tracker.count  # 不太对，应该是 total - remaining
        )

    async def _drain_sse_connections(self, ctx: ShutdownContext, timeout: float):
        """排空 SSE 长连接"""
        count = self._sse_tracker.count
        if count == 0:
            return

        ctx.log_phase(f"Draining {count} SSE connections (timeout={timeout:.1f}s)")

        # 发送关闭事件通知客户端
        if self._config.sse_send_close_event:
            # 通过 ConnectionManager 广播关闭事件
            # SSE ConnectionManager 会在收到 is_shutting_down 后
            # 向每个连接发送 server-close 事件
            pass  # 具体实现见 SSE 模块集成

        all_done = await self._sse_tracker.wait_for_zero(timeout)
        ctx.drained_connections += count - self._sse_tracker.count

        if not all_done:
            ctx.log_phase(
                f"SSE drain timeout, {self._sse_tracker.count} connections remaining"
            )

    async def _drain_ws_connections(self, ctx: ShutdownContext, timeout: float):
        """排空 WebSocket 长连接"""
        count = self._ws_tracker.count
        if count == 0:
            return

        ctx.log_phase(f"Draining {count} WebSocket connections (timeout={timeout:.1f}s)")

        # 发送 Close 帧
        if self._config.ws_send_close_frame:
            # 通过 WS ConnectionManager 广播关闭帧
            pass  # 具体实现见 WebSocket 模块集成

        all_done = await self._ws_tracker.wait_for_zero(timeout)
        ctx.drained_connections += count - self._ws_tracker.count

    async def _drain_ai_calls(self, ctx: ShutdownContext, timeout: float):
        """排空 AI 推理请求"""
        count = self._ai_tracker.count
        if count == 0:
            return

        ctx.log_phase(f"Draining {count} AI inference calls (timeout={timeout:.1f}s)")

        # AI 推理可能很长，设置独立的超时
        all_done = await self._ai_tracker.wait_for_zero(timeout)

        if not all_done and self._config.ai_cancel_after_timeout:
            stale = self._ai_tracker.get_stale_requests(0)
            ctx.log_phase(
                f"Cancelling {len(stale)} timed-out AI calls: "
                f"{[s['request_id'] for s in stale]}"
            )
            # 取消方式：通过 asyncio.Task.cancel()
            # AI 调用层需支持取消协议

    async def _phase_release_resources(self, ctx: ShutdownContext):
        """Phase 3: 资源释放"""
        timeout = min(
            self._config.release_resource_timeout,
            ctx.remaining_time() - 1.0,  # 至少留 1s 给进程退出
        )
        if timeout <= 0:
            ctx.log_phase("No time for resource release")
            return

        ctx.log_phase(f"Releasing resources (timeout={timeout:.1f}s)")

        for priority, name, callback in self._release_callbacks:
            if ctx.is_overall_timeout():
                ctx.log_phase(f"Skipping remaining releases due to overall timeout")
                break

            try:
                step_timeout = min(
                    2.0,  # 单个回调最多 2s
                    ctx.remaining_time() - 0.5,
                )
                if step_timeout <= 0:
                    break

                await asyncio.wait_for(callback(), timeout=step_timeout)
                ctx.released_resources += 1
                ctx.log_phase(f"Released: {name}")
            except asyncio.TimeoutError:
                ctx.log_phase(f"Release timed out: {name}")
            except Exception as e:
                ctx.log_phase(f"Release error for {name}: {e}")

    # ---- 可观测性 ----

    def _emit_shutdown_metrics(self, ctx: ShutdownContext):
        """输出停机指标"""
        duration = (datetime.now() - ctx.signal_received_at).total_seconds()
        logger.info(
            "Shutdown metrics: "
            f"reason={ctx.reason.value}, "
            f"final_phase={ctx.phase.value}, "
            f"duration={duration:.2f}s, "
            f"completed_requests={ctx.completed_requests}, "
            f"drained_connections={ctx.drained_connections}, "
            f"released_resources={ctx.released_resources}, "
            f"force_killed={ctx.force_killed_requests}"
        )

        # 上报到监控系统 (Prometheus / OpenTelemetry)
        # shutdown_duration_seconds.observe(duration)
        # shutdown_completed_total.inc()
        # shutdown_force_killed_total.inc(ctx.force_killed_requests)
```

```python
# app/core/shutdown_middleware.py

from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import JSONResponse
import uuid


class ShutdownAwareMiddleware(BaseHTTPMiddleware):
    """
    停机感知中间件
    - 停机期间拒绝新请求
    - 追踪在途请求生命周期
    """

    async def dispatch(self, request: Request, call_next):
        shutdown_mgr = GracefulShutdownManager.get_instance()

        # 健康检查路径放行（用于探针检测）
        if request.url.path in ("/health/live", "/health/ready"):
            return await call_next(request)

        # 停机期间拒绝新业务请求
        if shutdown_mgr.is_shutting_down:
            return JSONResponse(
                status_code=503,
                content={
                    "error": {
                        "code": "SERVICE_SHUTTING_DOWN",
                        "message": "服务正在关闭，请稍后重试",
                        "retry_after": 5,
                    }
                },
                headers={"Retry-After": "5"},
            )

        # 追踪在途请求
        request_id = request.headers.get("X-Request-ID", str(uuid.uuid4()))
        accepted = await shutdown_mgr.track_http_request(
            request_id,
            detail={
                "method": request.method,
                "path": request.url.path,
            },
        )

        if not accepted:
            return JSONResponse(
                status_code=503,
                content={
                    "error": {
                        "code": "SERVICE_SHUTTING_DOWN",
                        "message": "服务正在关闭，请稍后重试",
                    }
                },
                headers={"Retry-After": "5"},
            )

        try:
            response = await call_next(request)
            return response
        finally:
            await shutdown_mgr.untrack_http_request(request_id)
```

```python
class SSEConnectionManager:
    """SSE 连接管理器 — 停机排空集成"""

    def __init__(self):
        self._connections: dict[str, asyncio.Queue] = {}
        self._shutdown_mgr = GracefulShutdownManager.get_instance()

    async def create_connection(self, conn_id: str) -> asyncio.Queue:
        """创建 SSE 连接"""
        queue = asyncio.Queue()
        self._connections[conn_id] = queue
        await self._shutdown_mgr.track_sse(conn_id, {
            "type": "sse",
            "created_at": time.time(),
        })
        return queue

    async def close_connection(self, conn_id: str):
        """关闭 SSE 连接"""
        queue = self._connections.pop(conn_id, None)
        if queue:
            # 发送关闭事件
            await queue.put({
                "event": "server_close",
                "data": json.dumps({
                    "reason": "server_shutdown",
                    "reconnect": True,
                    "retry_ms": 3000,
                }),
            })
            await self._shutdown_mgr.untrack_sse(conn_id)

    async def drain_all(self):
        """排空所有 SSE 连接（停机时调用）"""
        conn_ids = list(self._connections.keys())
        logger.info(f"Draining {len(conn_ids)} SSE connections")

        for conn_id in conn_ids:
            await self.close_connection(conn_id)
```

```python
class WSConnectionManager:
    """WebSocket 连接管理器 — 停机排空集成"""

    CLOSE_CODE_SHUTDOWN = 1001  # Going Away
    CLOSE_CODE_RECONNECT = 1012  # Try Again Later (服务重启)

    def __init__(self):
        self._connections: dict[str, websockets.WebSocket] = {}
        self._shutdown_mgr = GracefulShutdownManager.get_instance()

    async def drain_all(self):
        """排空所有 WebSocket 连接"""
        conn_ids = list(self._connections.keys())
        logger.info(f"Draining {len(conn_ids)} WebSocket connections")

        for conn_id in conn_ids:
            ws = self._connections.get(conn_id)
            if ws and ws.open:
                try:
                    # 发送关闭帧，附带重连提示
                    await ws.close(
                        code=self.CLOSE_CODE_RECONNECT,
                        reason="server_rolling_update",
                    )
                except Exception:
                    pass
                finally:
                    await self._shutdown_mgr.untrack_ws(conn_id)
                    self._connections.pop(conn_id, None)
```

### 5.2 PreStop Hook 说明

```
时间线 (terminationGracePeriodSeconds = 35s):

T+0s    K8s 标记 Pod 为 Terminating
        ├─ K8s 从 Service Endpoints 移除 Pod
        ├─ K8s 异步更新 iptables/ipvs 规则
        └─ K8s 执行 PreStop Hook (sleep 5)

T+5s    PreStop Hook 完成
        └─ K8s 发送 SIGTERM 到容器 PID 1

T+5s    应用收到 SIGTERM
        ├─ Phase 1: Readiness → 503 (立即生效)
        ├─ Phase 2: 停止接受新连接
        ├─ Phase 2: 等待在途请求完成
        └─ Phase 3: 释放资源

T+33s   应用完成优雅停机 (deadline 28s + signal at 5s)
        └─ 进程退出 (exit 0)

T+35s   如果进程未退出
        └─ K8s 发送 SIGKILL (强制终止)
```

## 8. 错误处理

### 8.1 错误场景与处理策略

| 场景 | 检测方式 | 处理策略 |
|------|---------|---------|
| SIGTERM 后仍收到新请求 | ShutdownAwareMiddleware | 返回 503 + Retry-After |
| HTTP 请求超时未完成 | InFlightTracker.get_stale_requests() | 日志记录，等待到 deadline 后放弃 |
| SSE 客户端不响应 close 事件 | Queue.put() 超时 | 关闭连接，记录 metrics |
| WebSocket 客户端不响应 close 帧 | drain timeout | 强制关闭连接 |
| AI 推理请求超时 | ai_drain_timeout | 取消 asyncio Task |
| Celery 任务软超时 | SoftTimeLimitExceeded | 保存 checkpoint，重新投递 |
| 数据库事务未提交 | db_rollback_orphaned | 回滚事务 |
| 连接池关闭超时 | db_pool_close_timeout | 强制关闭 |
| 总停机超时 | total_deadline | 日志记录未完成项，等待 SIGKILL |
| PreStop Hook 失败 | K8s Event | 仍发送 SIGTERM，走正常停机流程 |

## 13. 多 Worker 模式特殊处理

### 13.1 uvicorn 多 Worker 架构

```
┌─────────────────────────────────────────────┐
│              uvicorn Master Process (PID 1)  │
│                                              │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│   │ Worker 1 │  │ Worker 2 │  │ Worker 3 │ │
│   │ (PID 10) │  │ (PID 11) │  │ (PID 12) │ │
│   └──────────┘  └──────────┘  └──────────┘ │
│                                              │
│   SIGTERM → Master 转发给所有 Worker          │
│   各 Worker 独立执行优雅停机                   │
└─────────────────────────────────────────────┘
```

**注意事项：**
1. K8s 的 SIGTERM 发送给容器 PID 1（uvicorn Master）
2. uvicorn Master 将 SIGTERM 转发给所有 Worker
3. 各 Worker 独立处理停机流程
4. `timeout_graceful_shutdown` 控制每个 Worker 的停机超时
5. 超时后 uvicorn 强制终止 Worker

```
├── HTTP 请求: 50-200 并发
├── SSE 连接: 100-500 长连接
├── WebSocket 连接: 50-200 长连接
└── AI 推理: 5-20 并发调用

停机排空最坏情况：
├── HTTP: 200 个请求，平均 2s → 排空 ~4s
├── SSE: 500 个连接，批量关闭 → 排空 ~5s
├── WebSocket: 200 个连接，批量关闭 → 排空 ~3s
└── AI: 20 个推理，最长 30s → 需设 ai_drain_timeout=25s

总计：~25s（在 28s deadline 内）
```

## 17. 运维手册

### 17.1 常见运维场景

```bash
# 1. 查看当前停机状态
kubectl exec -it primetop-api-xxxxx -- \
  curl -s http://localhost:8000/internal/shutdown/status | jq

# 2. 手动触发优雅停机（调试用）
kubectl exec -it primetop-api-xxxxx -- \
  curl -X POST http://localhost:8000/internal/shutdown?reason=debug

# 3. 查看停机相关日志
kubectl logs primetop-api-xxxxx | grep "\[Shutdown:"

# 4. 查看停机指标
curl -s http://primetop-api:8000/metrics | grep primetop_shutdown

# 5. 强制重启 Pod（不等待优雅停机）
kubectl delete pod primetop-api-xxxxx --grace-period=0 --force

# 6. 排空节点（触发 Pod 迁移）
kubectl drain node-name --grace-period=35 --timeout=120s

# 7. 滚动更新状态
kubectl rollout status deployment/primetop-api --timeout=300s

# 8. 查看滚动更新历史
kubectl rollout history deployment/primetop-api
```

### 17.2 故障排查

| 现象 | 可能原因 | 排查方式 |
|------|---------|---------|
| Pod 滚动更新很慢 | AI 推理请求长时间未完成 | 查看 shutdown status 中 ai_tracker.count |
| 频繁出现 FORCE_KILLED | drain_timeout 设置过短 | 适当增大 http_drain_timeout |
| 客户端大量重连失败 | readiness 探针配置不合理 | 检查 failureThreshold 和 periodSeconds |
| 停机期间数据库报错 | 连接池过早关闭 | 检查 release_callback 优先级 |
| PreStop Hook 超时 | sleep 时间过长 | 减小 prestop_sleep_seconds |
| 新 Pod 启动后仍收到旧请求 | iptables 规则未及时更新 | 增大 prestop_sleep_seconds |
