# 服务端-考后试卷深度分析与个性化讲评报告生成服务-详细设计

> **文档版本**: v1.0  
> **细化日期**: 2026-06-17  
> **关联模块**: 考试模拟与真题练习 / 学情分析  
> **优先级**: P1  
> **依赖服务**: 题目服务、练习测评会话服务、学情分析服务、知识追踪模型引擎、AI对话引擎

---

## 1. 模块概述

### 1.1 功能定位

当学生在 PrimeTop 中完成一套模拟试卷或真题练习后，系统需要对本次答题全过程进行**深度分析**，自动生成一份类似真实教师"试卷讲评"的个性化报告。报告涵盖：

- 逐题错误归因（知识缺失 / 审题失误 / 计算错误 / 时间不足 / 方法不当）
- 知识点掌握度增量更新
- 答题时间分配合理性评估
- 难度匹配度与区分度分析
- 同层次群体横向对比
- AI 生成逐题讲评（对错题给出"老师视角"的详细讲解）
- 下一步靶向练习推荐

### 1.2 与现有模块的边界

| 现有模块 | 职责 | 与本服务关系 |
|---------|------|-------------|
| `考试模拟与真题练习系统` | 试卷组卷、答题流程、计时 | **上游**：提供原始答题数据 |
| `练习测评会话服务与答题流程状态机` | 答题会话管理、状态流转 | **上游**：提供会话上下文 |
| `服务端-考试答题策略分析与时间分配优化建议引擎` | 考试中实时策略建议 | **互补**：实时 vs 考后 |
| `客户端-试卷回顾与答题复盘页面架构与交互设计` | 试卷回顾 UI | **下游**：消费本服务生成的报告 |
| `服务端-知识追踪模型引擎与学生能力动态评估服务` | 学生能力建模 | **双向**：读入能力基线，写回能力增量 |
| `服务端-练习答题实时批改与知识点掌握度增量更新服务` | 单题批改与知识点更新 | **上游**：提供逐题批改结果 |
| `学情分析-详细设计` | 整体学情分析 | **互补**：整体 vs 单次考试聚焦 |

### 1.3 核心价值

传统学情分析停留在"对了多少题、错了多少题"的统计层面，本服务解决三个痛点：

1. **错因不清晰**：学生只知道做错了，不知道为什么错
2. **讲评缺失**：自学场景没有老师讲解错题
3. **改进无方向**：不知道下一步应该练什么

### 2.2 核心处理流程

```
考试完成 → 答题数据聚合 → 错因诊断 → 时间分析 → 难度/群体对比
                                              ↓
                                    AI讲评生成（异步）
                                              ↓
                                    报告组装 & 持久化
                                              ↓
                              ┌───────────────┼───────────────┐
                              ▼               ▼               ▼
                        推送通知客户端    能力增量更新    练习推荐触发
```

### 2.3 同步 vs 异步拆分

| 阶段 | 模式 | 耗时预估 | 说明 |
|------|------|---------|------|
| 答题数据聚合 | 同步 | <500ms | 查询已有答题记录 |
| 错因诊断（规则部分） | 同步 | <1s | 基于规则匹配的快速分类 |
| 时间分配分析 | 同步 | <500ms | 纯计算 |
| 群体对比查询 | 同步 | <1s | 查预计算统计表 |
| **错因诊断（AI部分）** | **异步** | 5-15s | 调用大模型深度分析 |
| **AI逐题讲评生成** | **异步** | 10-30s | 大模型逐题生成讲解 |
| 报告组装与持久化 | 异步 | <2s | 汇总所有分析结果 |

> 同步部分快速返回"基础报告"（含统计与规则分析），异步部分完成后通过 SSE/WebSocket 推送"深度报告"更新。

## 3. 数据结构设计

### 3.1 核心表结构

#### 3.1.1 `exam_analysis_report` — 考后分析报告主表

```sql
CREATE TABLE exam_analysis_report (
    id              BIGSERIAL PRIMARY KEY,
    report_no       VARCHAR(64) NOT NULL UNIQUE,      -- 报告编号：EAR-{userId}-{timestamp}
    user_id         BIGINT NOT NULL,                   -- 学生ID
    exam_session_id BIGINT NOT NULL,                   -- 考试会话ID（关联 practice_session）
    paper_id        BIGINT NOT NULL,                   -- 试卷ID
    subject_code    VARCHAR(16) NOT NULL,              -- 学科代码
    grade_level     SMALLINT NOT NULL,                 -- 年级
    total_score     DECIMAL(6,2) NOT NULL,             -- 试卷总分
    user_score      DECIMAL(6,2) NOT NULL,             -- 得分
    total_questions SMALLINT NOT NULL,                 -- 总题数
    correct_count   SMALLINT NOT NULL,                 -- 正确数
    wrong_count     SMALLINT NOT NULL,                 -- 错误数
    skipped_count   SMALLINT NOT NULL DEFAULT 0,       -- 跳过数
    duration_sec    INT NOT NULL,                      -- 答题总时长（秒）
    time_limit_sec  INT,                               -- 考试限时（秒）
    
    -- 分析结果摘要
    score_rate      DECIMAL(5,2) NOT NULL,             -- 得分率%
    accuracy_rate   DECIMAL(5,2) NOT NULL,             -- 正确率%
    error_type_dist JSONB NOT NULL DEFAULT '{}',       -- 错因分布 {"knowledge_gap":3,"careless":2,...}
    knowledge_gaps  JSONB NOT NULL DEFAULT '[]',       -- 知识点缺口列表
    time_analysis   JSONB NOT NULL DEFAULT '{}',       -- 时间分配分析
    difficulty_dist JSONB NOT NULL DEFAULT '{}',       -- 难度分布分析
    cohort_rank     JSONB NOT NULL DEFAULT '{}',       -- 群体排名信息
    
    -- 报告状态
    status          VARCHAR(20) NOT NULL DEFAULT 'PROCESSING',
                    -- PROCESSING / PARTIAL_READY / READY / FAILED
    base_report_at  TIMESTAMPTZ,                       -- 基础报告完成时间
    full_report_at  TIMESTAMPTZ,                       -- 深度报告完成时间
    ai_tokens_used  INT NOT NULL DEFAULT 0,            -- AI消耗Token数
    
    -- 完整报告内容（Markdown）
    full_content    TEXT,                               -- 完整报告Markdown内容
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    CONSTRAINT chk_status CHECK (status IN ('PROCESSING','PARTIAL_READY','READY','FAILED'))
);

-- 索引
CREATE INDEX idx_ear_user_subject ON exam_analysis_report(user_id, subject_code, created_at DESC);
CREATE INDEX idx_ear_session ON exam_analysis_report(exam_session_id);
CREATE INDEX idx_ear_paper ON exam_analysis_report(paper_id, created_at DESC);
```

#### 3.1.2 `exam_question_analysis` — 逐题分析明细表

```sql
CREATE TABLE exam_question_analysis (
    id                  BIGSERIAL PRIMARY KEY,
    report_id           BIGINT NOT NULL REFERENCES exam_analysis_report(id),
    user_id             BIGINT NOT NULL,
    exam_session_id     BIGINT NOT NULL,
    question_id         BIGINT NOT NULL,
    question_no         SMALLINT NOT NULL,             -- 题号
    question_type       VARCHAR(20) NOT NULL,           -- 题型：choice/fill/short_answer/essay
    
    -- 答题结果
    is_correct          BOOLEAN NOT NULL,
    is_skipped          BOOLEAN NOT NULL DEFAULT FALSE,
    user_answer         TEXT,                           -- 学生答案
    correct_answer      TEXT,                           -- 正确答案
    user_score          DECIMAL(5,2) NOT NULL,          -- 该题得分
    full_score          DECIMAL(5,2) NOT NULL,          -- 该题满分
    
    -- 时间数据
    time_spent_sec      INT NOT NULL,                   -- 答题耗时（秒）
    avg_time_sec        INT,                            -- 群体平均耗时（秒）
    modify_count        SMALLINT NOT NULL DEFAULT 0,    -- 修改答案次数
    
    -- 错因诊断
    error_type          VARCHAR(30),                    -- 错误类型（仅错题）
    error_type_conf     DECIMAL(3,2),                   -- 错因置信度 0.00-1.00
    error_subtypes      JSONB DEFAULT '[]',             -- 错误子类型标签
    error_analysis      TEXT,                           -- 错因详细说明
    
    -- 知识点关联
    knowledge_point_ids BIGINT[] DEFAULT '{}',          -- 关联知识点ID列表
    weakness_tags       JSONB DEFAULT '[]',             -- 薄弱标签
    
    -- AI讲评
    ai_review           TEXT,                           -- AI生成的该题讲评
    review_status       VARCHAR(20) DEFAULT 'PENDING',  -- PENDING/GENERATING/DONE/SKIP
    
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    FOREIGN KEY (report_id) REFERENCES exam_analysis_report(id),
    CONSTRAINT chk_err_type CHECK (
        error_type IS NULL OR error_type IN (
            'KNOWLEDGE_GAP',        -- 知识点不会
            'CONCEPT_MISUNDERSTAND',-- 概念理解错误
            'CARELESS',             -- 粗心/计算错误
            'MISREAD',              -- 审题错误
            'METHOD_WRONG',         -- 方法/思路错误
            'TIMEOUT',              -- 时间不够未完成
            'PARTIAL_CREDIT',       -- 部分正确
            'GUESS_WRONG'           -- 猜答错误
        )
    ),
    CONSTRAINT chk_review_status CHECK (review_status IN ('PENDING','GENERATING','DONE','SKIP'))
);

CREATE INDEX idx_eqa_report ON exam_question_analysis(report_id);
CREATE INDEX idx_eqa_user_question ON exam_question_analysis(user_id, question_id, created_at DESC);
CREATE INDEX idx_eqa_error_type ON exam_question_analysis(error_type) WHERE error_type IS NOT NULL;
```

```sql
    paper_id        BIGINT NOT NULL,

    grade_level     SMALLINT NOT NULL,
    cohort_type     VARCHAR(20) NOT NULL,          -- ALL/GRADE/REGION/SCHOOL

    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
```

### 3.2 Redis 缓存结构

```
# 报告基础信息缓存（5分钟TTL）
exam:report:basic:{reportId} → JSON

# 用户最新报告列表（1小时TTL）
exam:report:list:{userId}:{subjectCode} → ZSET(reportId, createdAt)

# 报告生成进度（进程级状态）
exam:report:progress:{reportId} → HASH {
    phase: "aggregating|diagnosing|analyzing|generating|done"
    completed_questions: 5
    total_questions: 20
    estimated_wait_sec: 25
}

# 群体统计缓存（1小时TTL）
exam:cohort:stats:{paperId}:{cohortType} → JSON

# 错因诊断AI结果缓存（24小时TTL，按题目内容hash）
exam:errordiag:{questionContentHash}:{userAnswerHash} → JSON
```

### 3.3 核心枚举定义

```java
public enum ErrorType {
    KNOWLEDGE_GAP("知识点不会", "该题涉及的知识点尚未学习或完全不理解"),
    CONCEPT_MISUNDERSTAND("概念理解错误", "对知识点有理解偏差，混淆了相似概念"),
    CARELESS("粗心/计算错误", "思路正确但计算或书写过程中出错"),
    MISREAD("审题错误", "未仔细阅读题目条件或误解题意"),
    METHOD_WRONG("方法/思路错误", "选择了不恰当的解题方法"),
    TIMEOUT("时间不足", "考试时间分配不合理导致未完成"),
    PARTIAL_CREDIT("部分正确", "答案部分正确，存在遗漏或部分错误"),
    GUESS_WRONG("猜答错误", "不确定答案靠猜测，猜错");
}

public enum ReportStatus {
    PROCESSING,      // 报告生成中
    PARTIAL_READY,   // 基础报告就绪（统计+规则分析完成）
    READY,           // 完整报告就绪（含AI讲评）
    FAILED           // 生成失败
}

public enum ReviewStatus {
    PENDING,         // 等待生成
    GENERATING,      // 正在生成
    DONE,            // 已生成
    SKIP             // 跳过（正确题目无需讲评）
}
```

## 4. API 接口设计

### 4.1 触发考后分析

**POST** `/api/v1/exam-analysis/trigger`

> 考试完成后由练习测评服务自动调用，也可由用户主动触发重新分析。

**请求体：**

```json
{
  "examSessionId": 800123456,
  "userId": 100086,
  "paperId": 5000321,
  "priority": "NORMAL"
}
```

**响应（202 Accepted）：**

```json
{
  "code": 0,
  "data": {
    "reportId": 200001234,
    "reportNo": "EAR-100086-1718624180",
    "status": "PROCESSING",
    "estimatedWaitSec": 30,
    "pollIntervalSec": 5
  }
}
```

**错误码：**

| 错误码 | 含义 | HTTP状态 |
|--------|------|---------|
| `EXAM_ANALYSIS_001` | 考试会话不存在 | 404 |
| `EXAM_ANALYSIS_002` | 考试未完成，无法分析 | 400 |
| `EXAM_ANALYSIS_003` | 已有正在进行的分析任务 | 409 |
| `EXAM_ANALYSIS_004` | 试卷题目数据不完整 | 422 |

### 5.2 规则引擎诊断器

规则引擎基于可量化的信号进行快速分类：

```java
@Component
public class RuleBasedErrorDiagnoser {
    
    /**
     * 规则诊断结果
     */
    public DiagnosisResult diagnose(QuestionAnalysisInput input) {
        List<DiagnosisRule> rules = buildRules(input);
        
        for (DiagnosisRule rule : rules) {
            if (rule.matches(input)) {
                return rule.getResult();
            }
        }
        
        // 规则无法判定，返回NEED_AI
        return DiagnosisResult.needAi();
    }
    
    private List<DiagnosisRule> buildRules(QuestionAnalysisInput input) {
        return List.of(
            // 规则1: 未作答 + 时间不足 → TIMEOUT
            DiagnosisRule.builder()
                .name("TIMEOUT_DETECTION")
                .condition(ctx -> ctx.getUserAnswer() == null 
                    && ctx.getRemainingTimeSec() < 60)
                .result(ErrorType.TIMEOUT, 0.95, 
                    "考试时间不足，未能作答此题")
                .build(),
            
            // 规则2: 选填题答案相似度极高但个别字符不同 → CARELESS
            DiagnosisRule.builder()
                .name("CARELESS_DETECTION")
                .condition(ctx -> ctx.getQuestionType().isObjective()
                    && calculateSimilarity(ctx.getUserAnswer(), ctx.getCorrectAnswer()) > 0.8
                    && !ctx.getUserAnswer().equals(ctx.getCorrectAnswer()))
                .result(ErrorType.CARELESS, 0.85,
                    "答案与正确答案高度相似，判断为粗心导致的小错误")
                .build(),
            
            // 规则3: 修改答案次数≥3次 + 最终错误 → METHOD_WRONG
            DiagnosisRule.builder()
                .name("METHOD_WRONG_DETECTION")
                .condition(ctx -> ctx.getModifyCount() >= 3
                    && !ctx.getIsCorrect())
                .result(ErrorType.METHOD_WRONG, 0.75,
                    "多次修改答案仍未选对，解题方法可能存在偏差")
                .build(),
            
            // 规则4: 关联知识点历史掌握度<0.3 → KNOWLEDGE_GAP
            DiagnosisRule.builder()
                .name("KNOWLEDGE_GAP_DETECTION")
                .condition(ctx -> ctx.getRelatedKpMastery() != null
                    && ctx.getRelatedKpMastery() < 0.3)
                .result(ErrorType.KNOWLEDGE_GAP, 0.80,
                    String.format("关联知识点「%s」掌握度仅%.0f%%，判定为知识缺失", 
                        ctx.getRelatedKpName(), ctx.getRelatedKpMastery() * 100))
                .build(),
            
            // 规则5: 客观题耗时<平均的30%且错误 → MISREAD
            DiagnosisRule.builder()
                .name("MISREAD_DETECTION")
                .condition(ctx -> ctx.getTimeSpentSec() < ctx.getAvgTimeSec() * 0.3
                    && !ctx.getIsCorrect()
                    && ctx.getQuestionType().isObjective())
                .result(ErrorType.MISREAD, 0.70,
                    "答题速度远低于平均水平，可能未仔细审题")
                .build(),
            
            // 规则6: 客观题排除法猜答检测 → GUESS_WRONG
            DiagnosisRule.builder()
                .name("GUESS_DETECTION")
                .condition(ctx -> ctx.getTimeSpentSec() < ctx.getAvgTimeSec() * 0.2
                    && ctx.getModifyCount() == 0
                    && !ctx.getIsCorrect()
                    && ctx.getQuestionType().isChoice())
                .result(ErrorType.GUESS_WRONG, 0.65,
                    "答题极快且未修改，可能为猜答")
                .build()
        );
    }
}
```

```java
    public void generateReviewsBatch(Long reportId, List<QuestionAnalysis> wrongQuestions) {

            wrongQuestions.stream()
                .collect(Collectors.groupingBy(QuestionAnalysis::getErrorType));

            .filter(q -> q.getReviewStatus() == ReviewStatus.PENDING)

                    semaphore.acquire();
                    try {

                        semaphore.release();
```

## 7. 时间分配分析引擎

### 7.1 分析维度

```java
@Component
public class TimeAllocationAnalyzer {
    
    public TimeAnalysisResult analyze(ExamSessionData data) {
        return TimeAnalysisResult.builder()
            .perQuestion(analyzePerQuestion(data))
            .bySection(analyzeBySection(data))
            .utilization(analyzeUtilization(data))
            .pattern(analyzePattern(data))
            .advice(generateAdvice(data))
            .build();
    }
    
    /**
     * 逐题时间分析
     */
    private List<QuestionTimeVerdict> analyzePerQuestion(ExamSessionData data) {
        return data.getQuestionTimings().stream()
            .map(qt -> {
                double ratio = (double) qt.getSpentSec() / qt.getAvgTimeSec();
                TimeVerdict verdict;
                
                if (ratio < 0.3) {
                    verdict = TimeVerdict.TOO_FAST;    // 过快，可能草率
                } else if (ratio <= 1.5) {
                    verdict = TimeVerdict.REASONABLE;   // 合理
                } else if (ratio <= 2.5) {
                    verdict = TimeVerdict.SLOW;         // 偏慢
                } else {
                    verdict = TimeVerdict.OVERTIME;     // 严重超时
                }
                
                return QuestionTimeVerdict.builder()
                    .questionNo(qt.getQuestionNo())
                    .spent(qt.getSpentSec())
                    .avg(qt.getAvgTimeSec())
                    .ratio(ratio)
                    .verdict(verdict)
                    .isCorrect(qt.getIsCorrect())
                    .build();
            })
            .toList();
    }
    
    /**
     * 按题型段落分析（选择题/填空题/解答题）
     */
    private SectionTimeAnalysis analyzeBySection(ExamSessionData data) {
        Map<QuestionType, List<QuestionTiming>> byType = data.getQuestionTimings().stream()
            .collect(Collectors.groupingBy(QuestionTiming::getQuestionType));
        
        Map<QuestionType, SectionStat> stats = new LinkedHashMap<>();
        for (var entry : byType.entrySet()) {
            var timings = entry.getValue();
            int totalSpent = timings.stream().mapToInt(QuestionTiming::getSpentSec).sum();
            int totalAvg = timings.stream().mapToInt(QuestionTiming::getAvgTimeSec).sum();
            int correctCount = (int) timings.stream().filter(QuestionTiming::getIsCorrect).count();
            
            stats.put(entry.getKey(), SectionStat.builder()
                .questionCount(timings.size())
                .totalSpentSec(totalSpent)
                .expectedSec(totalAvg)
                .deviationRatio((double) totalSpent / totalAvg)
                .accuracyRate((double) correctCount / timings.size())
                .build());
        }
        return SectionTimeAnalysis.builder().sections(stats).build();
    }
    
    /**
     * 生成时间优化建议
     */
    private String generateAdvice(ExamSessionData data) {
        StringBuilder sb = new StringBuilder();
        
        // 整体时间使用情况
        double utilization = (double) data.getTotalUsedSec() / data.getTimeLimitSec();
        if (utilization > 0.95) {
            sb.append("考试时间几乎用尽，建议提升做题速度。\n");
        } else if (utilization < 0.6) {
            sb.append("剩余较多时间未利用，建议完成答卷后认真检查。\n");
        }
        
        // 找出超时最严重的题目
        data.getQuestionTimings().stream()
            .filter(qt -> (double) qt.getSpentSec() / qt.getAvgTimeSec() > 2.0)
            .findFirst()
            .ifPresent(qt -> sb.append(String.format(
                "第%d题耗时过长（%d秒，群体平均%d秒），建议针对性训练以提升速度。\n",
                qt.getQuestionNo(), qt.getSpentSec(), qt.getAvgTimeSec())));
        
        // 草率答题检测
        long fastWrongCount = data.getQuestionTimings().stream()
            .filter(qt -> (double) qt.getSpentSec() / qt.getAvgTimeSec() < 0.3 
                && !qt.getIsCorrect())
            .count();
        if (fastWrongCount >= 2) {
            sb.append(String.format(
                "有%d道题答题过快且错误，建议放慢速度仔细审题。\n", fastWrongCount));
        }
        
        return sb.toString().trim();
    }
}
```

```java
        md.append(generateScoreOverview(ctx));
        
        // 二、错题分析
        md.append(generateErrorAnalysis(ctx));
        
        // 三、时间分析
        md.append(generateTimeAnalysis(ctx));
        
        // 四、难度分析
        md.append(generateDifficultyAnalysis(ctx));
        
        // 五、群体对比
        md.append(generateCohortComparison(ctx));
        
        // 六、知识点缺口
        md.append(generateKnowledgeGaps(ctx));
        
        // 七、逐题讲评
        md.append(generateQuestionReviews(ctx));
        
        // 八、提升建议
        md.append(generateRecommendations(ctx));
        
        return md.toString();
    }
    
    private String generateErrorAnalysis(AnalysisContext ctx) {
        StringBuilder sb = new StringBuilder("\n## 二、错题分析\n\n");
        sb.append("| 错误类型 | 题数 | 占比 | 说明 |\n");
        sb.append("|---------|------|------|------|\n");
        
        ctx.getErrorTypeDist().forEach((type, info) -> {
            sb.append(String.format("| %s | %d | %.0f%% | %s |\n",
                info.getLabel(),
                info.getCount(),
                info.getRate() * 100,
                type.getDescription()
            ));
        });
        
        // 主要问题总结
        ErrorTypeInfo topError = ctx.getTopErrorType();
        sb.append(String.format("\n> 📊 **主要问题**：%s占比最高（%d题），",
            topError.getLabel(), topError.getCount()));
        sb.append(topError.getImprovementDirection()).append("\n");
        
        return sb.toString();
    }
    
    private String generateQuestionReviews(AnalysisContext ctx) {
        StringBuilder sb = new StringBuilder("\n## 七、逐题讲评\n\n");
        
        for (QuestionAnalysis qa : ctx.getWrongQuestionsWithReviews()) {
            sb.append(String.format("### 第%d题\n\n", qa.getQuestionNo()));
            sb.append(String.format("- **你的得分**：%.1f / %.1f\n", 
                qa.getUserScore(), qa.getFullScore()));
            sb.append(String.format("- **错误类型**：%s\n", 
                qa.getErrorType().getLabel()));
            sb.append(String.format("- **耗时**：%d秒\n\n", qa.getTimeSpentSec()));
            sb.append(qa.getAiReview()).append("\n\n---\n\n");
        }
        
        return sb.toString();
    }
}
```

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class PostExamAnalysisHandler {
    
    private final AnswerDataAggregator aggregator;
    private final ErrorDiagnosisEngine errorEngine;
    private final TimeAllocationAnalyzer timeAnalyzer;
    private final CohortComparisonEngine cohortEngine;
    private final ReviewGenerationEngine reviewEngine;
    private final ReportAssembler reportAssembler;
    private final KnowledgeTrackingService knowledgeService;
    private final EventBus eventBus;
    
    /**
     * 监听考试完成事件
     */
    @EventListener
    @Async("examAnalysisExecutor")
    public void onExamFinished(ExamSessionFinishedEvent event) {
        Long reportId = null;
        try {
            // 1. 创建报告记录
            reportId = createReportRecord(event);
            
            // 2. 聚合答题数据（同步）
            AnswerDataAggregate aggregate = aggregator.aggregate(event.getExamSessionId());
            
            // 3. 规则引擎错因诊断（同步）
            List<QuestionDiagnosis> diagnoses = errorEngine.diagnoseByRules(aggregate);
            
            // 4. 时间分析（同步）
            TimeAnalysisResult timeResult = timeAnalyzer.analyze(aggregate.getSessionData());
            
            // 5. 群体对比（同步）
            CohortComparison cohort = cohortEngine.compare(
                event.getPaperId(), event.getUserId(), 
                event.getUserScore(), event.getGradeLevel());
            
            // 6. 知识点缺口分析（同步）
            List<KnowledgeGap> gaps = analyzeKnowledgeGaps(diagnoses, event.getUserId());
            
            // 7. 保存基础分析结果，发布 PARTIAL_READY
            saveBaseAnalysis(reportId, diagnoses, timeResult, cohort, gaps);
            eventBus.publish(new ReportPartialReadyEvent(reportId, event.getUserId(), 
                generateReportNo(event)));
            
            // 8. 异步：AI错因深度诊断（对规则未判定的题目）
            errorEngine.diagnoseByAiAsync(reportId, diagnoses);
            
            // 9. 异步：AI逐题讲评生成
            reviewEngine.generateReviewsBatch(reportId, aggregate.getWrongQuestions());
            
            // 10. 推送能力增量到知识追踪服务
            knowledgeService.applyExamResult(event.getUserId(), 
                event.getSubjectCode(), diagnoses);
            
        } catch (Exception e) {
            log.error("考后分析失败, userId={}, sessionId={}", 
                event.getUserId(), event.getExamSessionId(), e);
            if (reportId != null) {
                markReportFailed(reportId, e.getMessage());
            }
        }
    }
    
    /**
     * 监听全部讲评生成完成
     */
    @EventListener
    @Async("examAnalysisExecutor")
    public void onAllReviewsDone(AllReviewsCompletedEvent event) {
        // 组装完整报告
        AnalysisContext ctx = loadFullContext(event.getReportId());
        String fullMarkdown = reportAssembler.assembleFullReport(ctx);
        
        // 更新报告状态为 READY
        reportMapper.updateFullReport(event.getReportId(), fullMarkdown, 
            ReportStatus.READY, Instant.now());
        
        // 发布就绪事件（触发推送通知）
        eventBus.publish(new ReportReadyEvent(
            event.getReportId(),
            ctx.getUserId(),
            ctx.getReportNo(),
            ctx.getSubjectCode(),
            ctx.getUserScore(),
            ctx.getScoreRate()
        ));
    }
}
```

## 12. 错误处理与降级策略

### 12.1 错误处理矩阵

| 场景 | 处理策略 | 用户感知 |
|------|---------|---------|
| 答题数据聚合失败 | 重试3次 → 标记FAILED | "报告生成失败，请稍后重试" |
| 规则引擎诊断异常 | 跳过规则直接进入AI诊断 | 无感知 |
| AI诊断调用超时/失败 | 降级为UNKNOWN错误类型，继续后续流程 | 讲评中部分题显示"诊断中" |
| AI讲评生成部分失败 | 成功的题正常展示，失败的题显示"讲评生成中" | 可手动重新生成 |
| 群体统计数据不足 | 降级为基于难度的估算对比 | 显示"样本量不足，仅供参考" |
| 知识追踪服务不可用 | 跳过能力增量更新，不影响报告生成 | 无感知 |
| AI限流(429) | 指数退避重试，最多3次 | 生成时间变长 |

```java
@Component
public class PostExamRecommendationEngine {
    
    public List<Recommendation> generate(Long userId, String subjectCode, 
                                          List<KnowledgeGap> gaps,
                                          ErrorTypeDistribution errorDist) {
        List<Recommendation> recs = new ArrayList<>();
        
        // 1. 基于知识点缺口的靶向练习
        for (KnowledgeGap gap : gaps) {
            if (gap.getMasteryAfter() < 0.4) {
                recs.add(Recommendation.builder()
                    .type(RecommendationType.PRACTICE)
                    .title(gap.getKnowledgePointName() + " 专项练习")
                    .knowledgePointId(gap.getKnowledgePointId())
                    .questionCount(15)
                    .estimatedMin(30)
                    .priority(gap.getMasteryAfter() < 0.25 ? "HIGH" : "MEDIUM")
                    .build());
            }
        }
        
        // 2. 基于高频错误类型的推荐
        if (errorDist.getRatio(ErrorType.CARELESS) > 0.3) {
            recs.add(Recommendation.builder()
                .type(RecommendationType.HABIT)
                .title("计算准确性训练")
                .description("建议每天完成10道计算专项练习，提升计算准确率")
                .priority("MEDIUM")
                .build());
        }
        
        // 3. 基于难度分析的推荐
        if (difficultyAnalysis.getHardRate() < 0.3) {
            recs.add(Recommendation.builder()
                .type(RecommendationType.CHALLENGE)
                .title("综合拔高训练")
                .description("建议挑战难度较高的综合题，提升解题能力")
                .priority("LOW")
                .build());
        }
        
        // 4. 复习建议（基于遗忘曲线）
        List<Long> reviewedKpIds = gaps.stream()
            .map(KnowledgeGap::getKnowledgePointId)
            .toList();
        recs.add(Recommendation.builder()
            .type(RecommendationType.REVIEW)
            .title("错题复习计划已生成")
            .description("基于本次考试错题，已为你安排了3天后的复习提醒")
            .knowledgePointIds(reviewedKpIds)
            .priority("HIGH")
            .build());
        
        // 5. 考试策略建议
        if (timeAnalysis.hasOvertimeQuestions()) {
            recs.add(Recommendation.builder()
                .type(RecommendationType.EXAM_STRATEGY)
                .title("答题节奏优化")
                .description("建议进行限时训练，合理分配各题型的答题时间")
                .priority("MEDIUM")
                .build());
        }
        
        return recs.stream()
            .sorted(Comparator.comparing(r -> Priority.valueOf(r.getPriority())))
            .limit(5)
            .toList();
    }
}
```

```java
@Component
public class ReviewCostController {
    
    /**
     * 智能跳过：非必要不调AI
     */
    public boolean shouldGenerateReview(QuestionAnalysis q) {
        // 跳过条件1：正确题目
        if (q.getIsCorrect()) return false;
        
        // 跳过条件2：跳过的题目（仅标注，不讲评）
        if (q.getIsSkipped()) return false;
        
        // 跳过条件3：同知识点已在本次报告中有≥2道讲评
        if (hasEnoughReviewsForKp(q.getReportId(), q.getKnowledgePointIds(), 2)) {
            return false;
        }
        
        // 跳过条件4：用户当日AI讲评次数超限
        if (exceedsDailyLimit(q.getUserId())) {
            log.info("用户{}今日AI讲评次数已达上限，跳过生成", q.getUserId());
            return false;
        }
        
        return true;
    }
    
    /**
     * 模型选择策略：简单题用小模型，难题用大模型
     */
    public String selectModel(QuestionAnalysis q) {
        if (q.getDifficulty() == Difficulty.EASY 
            && q.getQuestionType().isObjective()) {
            return "glm-4-flash"; // 轻量模型
        }
        if (q.getDifficulty() == Difficulty.HARD 
            || q.getQuestionType() == QuestionType.ESSAY) {
            return "deepseek-v3"; // 推理增强
        }
        return "glm-4"; // 标准模型
    }
}
```
