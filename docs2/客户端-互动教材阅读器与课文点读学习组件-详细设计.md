# 客户端 - 互动教材阅读器与课文点读学习组件 - 详细设计

> 版本：1.0 | 日期：2026-06-21 | 模块代号：`textbook-reader`

## 1. 文档概述

### 1.1 目的

本文档详细设计 PrimeTop 客户端"同步课堂学习"模块中的**互动教材阅读器组件**——学生用于阅读教材课文、点读发声、划线标注、做笔记、查看知识点讲解的核心交互组件。为 Flutter 客户端开发人员提供可直接落地的数据结构、组件 API、交互流程和关键代码实现。

### 1.2 模块定位

互动教材阅读器是"同步课堂学习"模块中**章节内容消费层**的核心组件，位于章节导航与学习内容展示的交叉点：

```
同步课堂 Tab
  └── 教材选择页
       └── 章节目录页
            └── 课时学习页 (LessonPage)
                 ├── 📖 互动教材阅读器 (本文档) ← 学生阅读教材内容
                 ├── 📝 同步练习组件
                 ├── 🧠 知识点讲解组件
                 └── 📊 学习进度组件
```

### 1.4 设计目标

| 目标 | 指标 |
| --- | --- |
| 内容首屏渲染 | ≤ 800ms（含富文本+公式） |
| 点读响应延迟 | ≤ 500ms（点击到开始播放） |
| 长文档滚动流畅度 | ≥ 55 FPS（Flutter 帧率） |
| 离线可用 | 已打开章节离线可读、可标注 |
| 多设备同步 | 标注/笔记跨设备同步延迟 ≤ 5s |
| 分龄适配 | 幼儿/小学/初中/高中四套阅读体验 |

### 1.5 技术选型

| 层次 | 技术方案 | 说明 |
| --- | --- | --- |
| 跨平台框架 | Flutter 3.x | 项目客户端主框架 |
| 富文本渲染 | `flutter_widget_from_html_core` + 自定义渲染 | 对接渲染引擎 |

| 手势识别 | `GestureDetector` + `SelectionArea` | 长按选词、划线标注 |
| 状态管理 | Riverpod (AsyncNotifier) | 阅读器状态管理 |

## 2. 数据结构设计

### 2.1 课时内容数据模型

阅读器消费的数据来自服务端"同步课堂章节内容聚合服务"，经 BFF 层组装后下发：

```dart
/// 课时内容根模型
class LessonContent {
  final String lessonId;              // 课时ID
  final String chapterId;             // 章节ID
  final String subject;               // 学科
  final String stage;                 // 学段: kindergarten/primary/junior/senior
  final String grade;                 // 年级
  final String textbookId;            // 教材版本ID
  final String title;                 // 课时标题
  final String subtitle;              // 副标题
  final List<ContentBlock> blocks;    // 内容块列表
  final List<KnowledgeRef> knowledgePoints; // 关联知识点
  final AudioAsset? audioAsset;       // 课文朗读音频
  final List<InteractiveElement> interactiveElements; // 交互元素
  final ReadingMeta meta;             // 元信息
  final int estimatedReadingTime;     // 预计阅读时长（秒）
}

/// 内容块 — 教材内容按语义分块
class ContentBlock {
  final String blockId;               // 块唯一ID
  final ContentBlockType type;        // 块类型
  final String content;               // 渲染内容（增强 Markdown）
  final AudioSegment? audioSegment;   // 对应音频片段（点读用）
  final List<KnowledgeRef>? linkedKnowledge; // 关联知识点
  final DifficultyLevel? difficulty;  // 难度层级
  final bool isKeyPoint;              // 是否为重点内容
  final String? illustration;         // 配图URL
}

enum ContentBlockType {
  text,           // 正文段落
  heading,        // 标题
  dialogue,       // 对话（英语课文场景）
  vocabulary,     // 词汇表
  example,        // 例题/例句
  formula,        // 公式块
  figure,         // 图片/图表
  table,          // 表格
  summary,        // 本课小结
  exercise,       // 随堂练习
  tips,           // 学习提示/注意事项
}

/// 音频资源
class AudioAsset {
  final String audioId;               // 音频ID
  final String url;                   // 音频URL（CDN）
  final String? localPath;            // 本地缓存路径
  final int durationMs;               // 总时长（毫秒）
  final AudioQuality quality;         // 音质
  final AudioNarrator narrator;       // 朗读者信息
  final List<AudioCue> cues;          // 音频时间戳标记（文本同步用）
}

/// 音频时间戳标记 — 用于点读和跟读高亮
class AudioCue {
  final String blockId;               // 对应内容块ID
  final int startMs;                  // 开始时间
  final int endMs;                    // 结束时间
  final String? textSegment;          // 对应文本片段（精确到句）
}

/// 音频片段 — 内容块级别的音频引用
class AudioSegment {
  final String audioId;               // 所属音频ID
  final int startMs;                  // 在音频中的开始时间
  final int endMs;                    // 在音频中的结束时间
}

/// 知识点引用
class KnowledgeRef {
  final String kpId;                  // 知识点ID
  final String name;                  // 知识点名称
  final String? definition;           // 简要释义（弹窗展示用）
  final String? detailUrl;            // 详情页路由
}

/// 交互元素
class InteractiveElement {
  final String elementId;
  final InteractiveType type;
  final String triggerText;           // 触发文本（如生词）
  final Map<String, dynamic> payload; // 交互负载数据
}

enum InteractiveType {
  vocabularyPopup,    // 生词弹窗（释义+发音）
  knowledgeTooltip,   // 知识点提示
  inlineExercise,     // 内嵌练习
  expandableDetail,   // 可展开详解
  characterStroke,    // 汉字笔顺动画（识字模块）
  imageZoom,          // 图片放大查看
}

/// 阅读元信息
class ReadingMeta {
  final String author;                // 作者（如语文课文）
  final String? source;               // 出处
  final int? wordCount;               // 词数（英语）
  final List<String> tags;            // 标签
  final DateTime publishedAt;         // 发布时间
  final int version;                  // 内容版本号
}
```

### 3.3 ReaderController — 业务逻辑控制器

```dart
/// 阅读器业务控制器
class ReaderController {
  ReaderController({
    required this.lessonId,
    required this.userId,
  });

  final String lessonId;
  final String userId;

  // === 状态流 ===
  final _contentState = AsyncValueNotifier<LessonContent?>(null);
  final _annotationsState = StateNotifier<List<TextAnnotation>>([]);
  final _notesState = StateNotifier<List<ReadingNote>>([]);
  final _readingSessionState = StateNotifier<ReadingSession?>(null);
  final _syncState = StateNotifier<SyncStatus>(SyncStatus.synced);

  AsyncValueNotifier<LessonContent?> get content => _contentState;
  StateNotifier<List<TextAnnotation>> get annotations => _annotationsState;

  // === 内容加载 ===
  Future<LessonContent> loadContent() async {
    _contentState.value = const AsyncValue.loading();

    try {
      // 1. 先检查本地缓存
      final cached = await _loadFromCache();
      if (cached != null) {
        _contentState.value = AsyncValue.data(cached);
        // 2. 后台检查服务端更新
        _checkContentUpdate(cached.meta.version);
        return cached;
      }

      // 3. 无缓存，请求服务端
      final remote = await _fetchFromServer();
      _contentState.value = AsyncValue.data(remote);

      // 4. 缓存到本地
      await _cacheContent(remote);

      // 5. 预加载音频
      _preloadAudio(remote.audioAsset);

      // 6. 加载已有标注
      await _loadAnnotations();

      return remote;
    } catch (e, st) {
      _contentState.value = AsyncValue.error(e, st);
      rethrow;
    }
  }

  // === 阅读会话 ===
  void startReadingSession(ReadingMode mode) {
    final session = ReadingSession(
      sessionId: _uuid(),
      userId: userId,
      lessonId: lessonId,
      startTime: DateTime.now(),
      durationSec: 0,
      scrollProgress: 0.0,
      mode: mode,
      metadata: {},
    );
    _readingSessionState.value = session;
    _startDurationTimer();
  }

  void endReadingSession() {
    final session = _readingSessionState.value;
    if (session == null) return;

    final ended = session.copyWith(
      endTime: DateTime.now(),
      durationSec: _accumulatedDuration,
    );
    _readingSessionState.value = ended;

    // 提交到服务端
    _submitReadingSession(ended);
  }

  // === 进度跟踪 ===
  void updateScrollProgress(double progress, String? visibleBlockId) {
    final session = _readingSessionState.value;
    if (session == null) return;

    _readingSessionState.value = session.copyWith(
      scrollProgress: progress,
      lastBlockId: visibleBlockId,
    );

    // 防抖同步
    _progressSyncDebouncer.run(() {
      _syncProgress(progress, visibleBlockId);
    });

    // 检查是否完成阅读
    if (progress >= 0.95 && !_completionTriggered) {
      _completionTriggered = true;
      onLessonCompleted?.call();
    }
  }

  // === 标注操作 ===
  Future<TextAnnotation> createAnnotation({
    required String blockId,
    required int startOffset,
    required int endOffset,
    required String selectedText,
    required AnnotationType type,
    String? note,
    String color = '#FFEB3B',
  }) async {
    final annotation = TextAnnotation(
      annotationId: _uuid(),
      userId: userId,
      lessonId: lessonId,
      blockId: blockId,
      startOffset: startOffset,
      endOffset: endOffset,
      selectedText: selectedText,
      type: type,
      note: note,
      color: color,
      createdAt: DateTime.now(),
      updatedAt: DateTime.now(),
      syncStatus: SyncStatus.pending,
    );

    // 1. 写入本地数据库
    await _localDB.insertAnnotation(annotation);

    // 2. 更新内存状态
    final current = _annotationsState.value;
    _annotationsState.value = [...current, annotation];

    // 3. 异步同步到服务端
    _syncAnnotation(annotation);

    return annotation;
  }

  Future<void> deleteAnnotation(String annotationId) async {
    await _localDB.softDeleteAnnotation(annotationId);
    final current = _annotationsState.value;
    _annotationsState.value = current
        .where((a) => a.annotationId != annotationId)
        .toList();
    _syncAnnotationDeletion(annotationId);
  }

  // === 生词收藏 ===
  Future<void> addToVocabulary({
    required String word,
    String? phonetic,
    String? definition,
    String? example,
    required String blockId,
  }) async {
    final item = VocabularyItem(
      itemId: _uuid(),
      userId: userId,
      word: word,
      phonetic: phonetic,
      definition: definition,
      example: example,
```

```dart
/// 音频-文本同步控制器
class AudioSyncController {
  final _audioPlayer = AudioPlayer();  // just_audio 实例
  final _currentCueNotifier = ValueNotifier<AudioCue?>(null);
  final _isPlayingNotifier = ValueNotifier<bool>(false);
  final _highlightColorNotifier = ValueNotifier<Color>(
    const Color(0x4D2196F3),  // 蓝色半透明
  );

  StreamSubscription<Duration>? _positionSub;
  List<AudioCue> _cues = [];
  int _currentCueIndex = -1;

  ValueListenable<AudioCue?> get currentCue => _currentCueNotifier;
  ValueListenable<bool> get isPlaying => _isPlayingNotifier;

  /// 播放指定内容块的音频片段
  Future<void> playBlock({
    required AudioSegment segment,
    required List<AudioCue> allCues,
    double speed = 1.0,
  }) async {
    _cues = allCues;

    // 设置播放区域
    await _audioPlayer.setClip(
      start: Duration(milliseconds: segment.startMs),
      end: Duration(milliseconds: segment.endMs),
    );

    await _audioPlayer.setSpeed(speed);

    // 监听播放进度，驱动高亮
    _positionSub?.cancel();
    _positionSub = _audioPlayer.positionStream.listen(_onPositionChanged);

    await _audioPlayer.play();
    _isPlayingNotifier.value = true;
  }

  void _onPositionChanged(Duration position) {
    final posMs = position.inMilliseconds;

    // 二分查找当前 cue
    final cueIndex = _binarySearchCue(posMs);
    if (cueIndex != _currentCueIndex) {
      _currentCueIndex = cueIndex;
      _currentCueNotifier.value =
          cueIndex >= 0 ? _cues[cueIndex] : null;
    }

    // 播放结束
    if (_audioPlayer.processingState == ProcessingState.completed) {
      _isPlayingNotifier.value = false;
      _currentCueNotifier.value = null;
      _currentCueIndex = -1;
    }
  }

  int _binarySearchCue(int posMs) {
    int lo = 0, hi = _cues.length - 1;
    while (lo <= hi) {
      final mid = (lo + hi) ~/ 2;
      final cue = _cues[mid];
      if (posMs >= cue.startMs && posMs <= cue.endMs) {
        return mid;
      } else if (posMs < cue.startMs) {
        hi = mid - 1;
      } else {
        lo = mid + 1;
      }
    }
    return -1;
  }

  Future<void> pause() async {
    await _audioPlayer.pause();
    _isPlayingNotifier.value = false;
  }

  Future<void> stop() async {
    await _audioPlayer.stop();
    _isPlayingNotifier.value = false;
    _currentCueNotifier.value = null;
    _currentCueIndex = -1;
  }

  void dispose() {
    _positionSub?.cancel();
    _audioPlayer.dispose();
    _currentCueNotifier.dispose();
    _isPlayingNotifier.dispose();
    _highlightColorNotifier.dispose();
  }
}
```

### 7.3 标注渲染性能优化

当标注较多时，直接在文本上渲染高亮会导致频繁的 Widget 重建。采用 `CustomPaint` + `TextPainter` 方案：

```dart
/// 高性能标注高亮渲染
class AnnotatedTextPainter extends CustomPainter {
  AnnotatedTextPainter({
    required this.text,
    required this.style,
    required this.annotations,
    required this.highlightColors,
  });

  final String text;
  final TextStyle style;
  final List<TextAnnotation> annotations;
  final Map<AnnotationType, Color> highlightColors;

  @override
  void paint(Canvas canvas, Size size) {
    // 1. 使用 TextPainter 布局文本
    final painter = TextPainter(
      text: TextSpan(text: text, style: style),
      textDirection: TextDirection.ltr,
      maxLines: null,
    )..layout(maxWidth: size.width);

    // 2. 绘制高亮背景
    for (final annotation in annotations) {
      final highlightColor =
          highlightColors[annotation.type] ??
          const Color(0x4DFFEB3B);

      // 计算选中文本的矩形区域
      final boxes = painter.getBoxesForSelection(
        TextSelection(
          baseOffset: annotation.startOffset,
          extentOffset: annotation.endOffset,
        ),
      );

      for (final box in boxes) {
        final paint = Paint()..color = highlightColor;
        canvas.drawRRect(
          RRect.fromRectAndRadius(
            box.toRect().inflate(1),
            const Radius.circular(2),
          ),
          paint,
        );
      }
    }

    // 3. 绘制文本
    painter.paint(canvas, Offset.zero);
  }

  @override
  bool shouldRepaint(covariant AnnotatedTextPainter oldDelegate) {
    return text != oldDelegate.text ||
        annotations.length != oldDelegate.annotations.length;
  }
}
```

### 8.2 标注位置偏移修复算法

当服务端内容版本更新导致文本变化时，需要重新映射标注位置：

```dart
/// 标注位置迁移器
class AnnotationMigrator {
  /// 将旧版本标注迁移到新内容版本
  List<MigrationResult> migrate({
    required List<TextAnnotation> annotations,
    required LessonContent oldContent,
    required LessonContent newContent,
  }) {
    final results = <MigrationResult>[];

    for (final annotation in annotations) {
      // 1. 找到标注在旧内容中的块
      final oldBlock = oldContent.blocks.firstWhereOrNull(
        (b) => b.blockId == annotation.blockId,
      );
      if (oldBlock == null) {
        results.add(MigrationResult.failed(annotation, 'block_missing'));
        continue;
      }

      // 2. 在新内容中查找同 ID 的块
      final newBlock = newContent.blocks.firstWhereOrNull(
        (b) => b.blockId == annotation.blockId,
      );
      if (newBlock == null) {
        // 块被删除，尝试文本模糊匹配
        final matchResult = _fuzzyMatchBlock(
          annotation.selectedText,
          newContent.blocks,
        );
        if (matchResult != null) {
          results.add(MigrationResult.migrated(
            annotation,
            newBlockId: matchResult.blockId,
            newStart: matchResult.startOffset,
            newEnd: matchResult.endOffset,
          ));
        } else {
          results.add(MigrationResult.failed(annotation, 'block_deleted'));
        }
        continue;
      }

      // 3. 块存在但内容可能变化
      if (oldBlock.content == newBlock.content) {
        // 内容完全一致，位置不变
        results.add(MigrationResult.unchanged(annotation));
      } else {
        // 内容有变化，尝试在块内重新定位选中文本
        final newOffset = _findTextInBlock(
          annotation.selectedText,
          newBlock.content,
        );
        if (newOffset != null) {
          results.add(MigrationResult.migrated(
            annotation,
            newBlockId: newBlock.blockId,
            newStart: newOffset.start,
            newEnd: newOffset.end,
          ));
        } else {
          // 文本不存在了，标记为过期
          results.add(MigrationResult.expired(annotation));
        }
      }
    }

    return results;
  }

  /// 在块内容中查找文本
  ({int start, int end})? _findTextInBlock(
    String searchText,
    String blockContent,
  ) {
    // 去除 Markdown 标记后做纯文本匹配
    final plainContent = _stripMarkdown(blockContent);
    final index = plainContent.indexOf(searchText);
    if (index == -1) return null;
    return (start: index, end: index + searchText.length);
  }

  /// 模糊匹配块
  ({String blockId, int startOffset, int endOffset})? _fuzzyMatchBlock(
    String searchText,
    List<ContentBlock> blocks,
  ) {
    for (final block in blocks) {
      final plain = _stripMarkdown(block.content);
      final index = plain.indexOf(searchText);
      if (index != -1) {
        return (
          blockId: block.blockId,
          startOffset: index,
          endOffset: index + searchText.length,
        );
      }
    }
    return null;
  }

  String _stripMarkdown(String content) {
    // 简化的 Markdown 标记去除
    return content
        .replaceAll(RegExp(r'#{1,6}\s'), '')
        .replaceAll(RegExp(r'\*\*([^*]+)\*\*'), r'$1')
        .replaceAll(RegExp(r'\*([^*]+)\*'), r'$1')
        .replaceAll(RegExp(r'\$([^$]+)\$'), r'$1')
        .replaceAll(RegExp(r'<br\s*/?>'), '\n')
        .trim();
  }
}

class MigrationResult {
  final TextAnnotation annotation;
  final MigrationStatus status;
  final String? newBlockId;
  final int? newStart;
  final int? newEnd;
  final String? reason;

  MigrationResult.unchanged(this.annotation)
      : status = MigrationStatus.unchanged,
        newBlockId = null, newStart = null, newEnd = null, reason = null;

  MigrationResult.migrated(
    this.annotation, {
    required this.newBlockId,
    required this.newStart,
    required this.newEnd,
  }) : status = MigrationStatus.migrated, reason = null;

  MigrationResult.failed(this.annotation, this.reason)
      : status = MigrationStatus.failed,
        newBlockId = null, newStart = null, newEnd = null;

  MigrationResult.expired(this.annotation)
      : status = MigrationStatus.expired,
        newBlockId = null, newStart = null, newEnd = null, reason = 'content_changed';
}

enum MigrationStatus { unchanged, migrated, failed, expired }
```

### 9.2 冲突解决策略

采用 **Last-Write-Wins (LWW)** + **手动解决** 混合策略：

```dart
class AnnotationSyncManager {
  /// 增量同步标注
  Future<void> syncIncremental({
    required String userId,
    required String lessonId,
  }) async {
    // 1. 获取本地待同步标注
    final pendingLocal = await _localDB.getPendingAnnotations(
      userId: userId,
      lessonId: lessonId,
    );

    // 2. 获取服务端最新更新
    final lastSyncTime = await _localDB.getLastSyncTime(
      userId: userId,
      key: 'annotations_$lessonId',
    );

    final remoteResponse = await _api.getAnnotations(
      lessonId: lessonId,
      since: lastSyncTime,
    );

    // 3. 检测冲突
    final conflicts = <AnnotationConflict>[];
    final remoteMap = {
      for (var a in remoteResponse.annotations) a.annotationId: a,
    };

    for (final local in pendingLocal) {
      final remote = remoteMap[local.annotationId];
      if (remote != null && remote.updatedAt != local.updatedAt) {
        // 冲突：本地和服务端都有修改
        conflicts.add(AnnotationConflict(
          local: local,
          remote: remote,
        ));
      }
    }

    // 4. 解决冲突
    for (final conflict in conflicts) {
      if (_shouldAutoResolve(conflict)) {
        // LWW 自动解决
        final winner = conflict.local.updatedAt
            .isAfter(conflict.remote.updatedAt)
            ? conflict.local
            : conflict.remote;
        await _localDB.upsertAnnotation(winner);
      } else {
        // 需要用户手动选择
        _pendingConflicts.add(conflict);
      }
    }

    // 5. 推送本地变更
    if (pendingLocal.isNotEmpty) {
      await _api.syncAnnotations(
        lessonId: lessonId,
        annotations: pendingLocal,
      );
    }

    // 6. 合并远端变更
    for (final remote in remoteResponse.annotations) {
      if (!pendingLocal.any((l) => l.annotationId == remote.annotationId)) {
        await _localDB.upsertAnnotation(remote);
      }
    }

    // 7. 处理删除
    for (final deletedId in remoteResponse.deleted) {
      await _localDB.hardDeleteAnnotation(deletedId);
    }

    // 8. 更新同步时间
    await _localDB.setLastSyncTime(
      userId: userId,
      key: 'annotations_$lessonId',
      time: remoteResponse.serverTime,
    );
  }
}
```

```dart
    });
```
