## 1. 模块概述

### 1.1 功能定位

学习闪卡（Flashcard）是 PrimeTop 中跨学科通用的记忆工具组件，基于间隔重复算法（SRS），将知识点、单词、公式、古诗文等学习内容组织为可翻转的卡片，通过"回忆→评级→复习调度"的闭环帮助学生高效记忆。

### 1.2 核心价值

| 维度 | 说明 |
|------|------|
| 统一记忆工具 | 一套卡片引擎，覆盖英语单词、语文古诗文、数理公式、历史事件等多场景 |
| 间隔重复集成 | 客户端渲染与服务端 SRS 调度算法无缝衔接 |
| 多来源卡片 | 错题、笔记、词汇本、AI 生成的知识要点均可一键转为闪卡 |
| 离线可用 | 卡组本地缓存，无网环境下仍可复习 |
| 游戏化体验 | 卡片翻转动画、连续答对特效、复习进度环 |

### 1.3 目标用户与学段适配

| 学段 | 典型场景 | 卡片风格 |
|------|---------|---------|
| 幼儿 | 识字卡、拼音卡、数字卡 | 图文并茂、大字号、语音播报 |
| 小学 | 英语单词、语文词语、数学概念 | 图文+文字、适中字号 |
| 初中 | 英语词汇、古诗文名句、物理公式、历史年代 | 文字为主、公式渲染 |
| 高中 | 高考核心词汇、化学方程式、政治原理、历史事件链 | 高密度文本、公式/方程式渲染 |

```text
         │                              │
         ▼                              ▼
   SRS调度API                      学习行为埋点
```

### 2.2 模块职责边界

| 模块 | 职责 | 不包含 |
|------|------|--------|
| CardRenderer | 卡片正反面渲染、学科内容排版 | 内容生产（由各业务模块提供） |
| StudySession | 复习会话流程控制、评级收集、进度追踪 | SRS 算法计算（由服务端执行） |
| DeckManager | 卡组 CRUD、卡片归类、排序、搜索 | 卡组推荐（由推荐引擎负责） |
| CardDataStore | 本地持久化、增量同步、离线队列 | 用户画像数据 |
| CardFactory | 从错题/笔记/词汇等多源创建卡片 | 卡片内容审核（由审核管线处理） |
| InteractionLayer | 手势、动画、触觉反馈 | 业务逻辑 |

## 3. 数据结构定义

### 3.1 核心数据模型

#### 3.1.1 Flashcard（闪卡实体）

```dart
/// 闪卡实体定义
class Flashcard {
  /// 唯一标识
  final String cardId;
  
  /// 所属卡组ID
  final String deckId;
  
  /// 卡片类型
  final CardType type;
  
  /// 正面内容（结构化）
  final CardContent front;
  
  /// 背面内容（结构化）
  final CardContent back;
  
  /// 提示内容（可选，翻转前展示的辅助信息）
  final CardContent? hint;
  
  /// 关联元数据
  final CardMetadata metadata;
  
  /// SRS 调度状态
  final SrsState srsState;
  
  /// 创建信息
  final String source;        // 来源：mistake / note / vocabulary / manual / ai_generated
  final DateTime createdAt;
  final DateTime updatedAt;
  
  /// 排序权重
  final int sortOrder;
  
  /// 是否置顶
  final bool isPinned;
  
  /// 是否归档
  final bool isArchived;
}

/// 卡片类型枚举
enum CardType {
  text,           // 纯文本
  imageText,      // 图文
  formula,        // 公式（LaTeX）
  audio,          // 音频（发音、朗读）
  bilingual,      // 双语（英语单词等）
  sequence,       // 序列（历史事件链）
  cloze,          // 填空
}

/// 卡片内容（结构化）
class CardContent {
  /// 主文本
  final String primary;
  
  /// 副文本（例句、释义、解释）
  final String? secondary;
  
  /// 图片URL
  final String? imageUrl;
  
  /// 音频URL
  final String? audioUrl;
  
  /// LaTeX 公式
  final String? latex;
  
  /// 附加标签（词性、单元等）
  final List<String> tags;
  
  /// 富文本段（用于复杂排版）
  final List<RichTextSegment>? richSegments;
}

/// 卡片元数据
class CardMetadata {
  /// 学科
  final String? subject;
  
  /// 知识点ID
  final String? knowledgePointId;
  
  /// 教材章节ID
  final String? chapterId;
  
  /// 年级
  final String? gradeLevel;
  
  /// 难度等级 1-5
  final int? difficulty;
  
  /// 关联题目ID（如果卡片来源于题目）
  final String? questionId;
  
  /// 关联错题ID
  final String? mistakeId;
}

/// SRS 调度状态（与服务端同步）
class SrsState {
  /// 当前间隔（天）
  final int interval;
  
  /// 简单度因子（1.3-2.5）
  final double easeFactor;
  
  /// 重复次数
  final int repetitions;
  
  /// 上次复习时间
  final DateTime? lastReviewedAt;
  
  /// 下次到期时间
  final DateTime dueDate;
  
  /// 本地状态（是否已学习、已评级）
  final bool isLearned;
  
  /// 本次会话评级（临时字段，会话结束后清空）
  final CardRating? sessionRating;
}
```

#### 3.1.3 StudySession（复习会话）

```dart
/// 复习会话
class StudySession {
  /// 会话ID
  final String sessionId;
  
  /// 卡组ID
  final String deckId;
  
  /// 会话类型
  final SessionType type;
  
  /// 会话卡片列表（有序）
  final List<SessionCard> cards;
  
  /// 当前卡片索引
  final int currentIndex;
  
  /// 已完成数量
  final int completedCount;
  
  /// 正确数量
  final int correctCount;
  
  /// 会话开始时间
  final DateTime startedAt;
  
  /// 会话结束时间
  final DateTime? endedAt;
  
  /// 学习时长（秒）
  final int? durationSeconds;
  
  /// 会话统计
  final SessionStats stats;
}

enum SessionType {
  review,      // 复习到期卡片
  newCards,    // 学习新卡片
  mixed,       // 混合模式（新卡+复习）
  cram,        // 强化练习（忽略SRS调度）
  quiz,        // 测试模式（不评级，仅答题）
}

/// 会话中的单张卡片包装
class SessionCard {
  final String cardId;
  final bool isNew;           // 是否新卡
  final bool isDue;           // 是否到期复习
  final CardRating? rating;   // 用户评级（null=未评级）
  final int timeSpentMs;      // 该卡耗时
  final int attempts;         // 翻转次数
}

/// 用户评级
enum CardRating {
  again,    // 忘了（重新学习）
  hard,     // 困难（勉强记住）
  good,     // 良好（正常回忆）
  easy,     // 简单（秒答）
}

/// 会话统计
class SessionStats {
  final int totalCards;
  final int reviewedCards;
  final int againCount;
  final int hardCount;
  final int goodCount;
  final int easyCount;
  final int totalTimeMs;
  final int maxStreak;        // 最长连续答对
  final int currentStreak;
}
```

```sql
-- 卡组表
CREATE TABLE flashcard_decks (
  deck_id          TEXT PRIMARY KEY,
  name             TEXT NOT NULL,
  description      TEXT,
  cover_image_url  TEXT,
  subject          TEXT,
  tags             TEXT NOT NULL DEFAULT '[]',  -- JSON array
  source           TEXT NOT NULL,
  is_system        INTEGER NOT NULL DEFAULT 0,
  is_favorite      INTEGER NOT NULL DEFAULT 0,
  total_count      INTEGER NOT NULL DEFAULT 0,
  new_count        INTEGER NOT NULL DEFAULT 0,

  mastered_count   INTEGER NOT NULL DEFAULT 0,
  created_at       INTEGER NOT NULL,
  updated_at       INTEGER NOT NULL,
  synced_at        INTEGER,
  is_deleted       INTEGER NOT NULL DEFAULT 0
);

-- 闪卡表
CREATE TABLE flashcards (
  card_id           TEXT PRIMARY KEY,
  deck_id           TEXT NOT NULL,
  type              TEXT NOT NULL,
  front_content     TEXT NOT NULL,   -- JSON
  back_content      TEXT NOT NULL,    -- JSON
  hint_content      TEXT,
  metadata          TEXT NOT NULL DEFAULT '{}',  -- JSON
  source            TEXT NOT NULL,
  srs_interval      INTEGER NOT NULL DEFAULT 0,
  srs_ease_factor   REAL NOT NULL DEFAULT 2.5,
  srs_repetitions   INTEGER NOT NULL DEFAULT 0,
  srs_last_reviewed INTEGER,
  srs_due_date      INTEGER NOT NULL,
  srs_is_learned    INTEGER NOT NULL DEFAULT 0,
  sort_order        INTEGER NOT NULL DEFAULT 0,
  is_pinned         INTEGER NOT NULL DEFAULT 0,
  is_archived       INTEGER NOT NULL DEFAULT 0,
  created_at        INTEGER NOT NULL,
  updated_at        INTEGER NOT NULL,
  synced_at         INTEGER,
  is_deleted        INTEGER NOT NULL DEFAULT 0,
  FOREIGN KEY (deck_id) REFERENCES flashcard_decks(deck_id)
);

-- 复习记录表（本地日志，用于会话恢复和统计）
CREATE TABLE review_logs (
  log_id          INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id      TEXT NOT NULL,
  card_id         TEXT NOT NULL,
  deck_id         TEXT NOT NULL,
  rating          TEXT NOT NULL,
  time_spent_ms   INTEGER NOT NULL,
  reviewed_at     INTEGER NOT NULL,
  synced          INTEGER NOT NULL DEFAULT 0,
  FOREIGN KEY (card_id) REFERENCES flashcards(card_id)
);

-- 会话表
CREATE TABLE study_sessions (
  session_id        TEXT PRIMARY KEY,
  deck_id           TEXT NOT NULL,
  type              TEXT NOT NULL,
  total_cards       INTEGER NOT NULL,
  completed_cards   INTEGER NOT NULL DEFAULT 0,
  current_index     INTEGER NOT NULL DEFAULT 0,
  stats             TEXT,  -- JSON
  started_at        INTEGER NOT NULL,
  ended_at          INTEGER,
  duration_seconds  INTEGER,
  synced            INTEGER NOT NULL DEFAULT 0
);

-- 索引
CREATE INDEX idx_flashcards_deck ON flashcards(deck_id, is_archived, is_deleted);
CREATE INDEX idx_flashcards_due ON flashcards(srs_due_date, srs_is_learned) 
  WHERE is_deleted = 0 AND is_archived = 0;
CREATE INDEX idx_review_logs_unsynced ON review_logs(synced) WHERE synced = 0;
CREATE INDEX idx_sessions_deck ON study_sessions(deck_id, started_at DESC);
```

```dart
/// 卡片渲染策略接口
abstract class CardRenderStrategy {
  Widget buildFront(BuildContext context, CardContent content);
  Widget buildBack(BuildContext context, CardContent content);
  Duration get flipDuration;
}

/// 卡片类型注册表
class CardRendererRegistry {
  static final Map<CardType, CardRenderStrategy> _strategies = {
    CardType.text: TextCardRenderer(),
    CardType.imageText: ImageTextCardRenderer(),
    CardType.formula: FormulaCardRenderer(),
    CardType.audio: AudioCardRenderer(),
    CardType.bilingual: BilingualCardRenderer(),
    CardType.sequence: SequenceCardRenderer(),
    CardType.cloze: ClozeCardRenderer(),
  };
  
  static Widget buildFront(BuildContext context, Flashcard card) {
    final strategy = _strategies[card.type] ?? TextCardRenderer();
    return strategy.buildFront(context, card.front);
  }
  
  static Widget buildBack(BuildContext context, Flashcard card) {
    final strategy = _strategies[card.type] ?? TextCardRenderer();
    return strategy.buildBack(context, card.back);
  }
}
```

```dart
/// 3D 翻转卡片容器
class FlipCard extends StatefulWidget {
  final Widget front;
  final Widget back;
  final Duration flipDuration;
  final VoidCallback? onFlip;
  final bool initialFlipState;
  
  const FlipCard({
    required this.front,
    required this.back,
    this.flipDuration = const Duration(milliseconds: 400),
    this.onFlip,
    this.initialFlipState = false,
  });
  
  @override
  State<FlipCard> createState() => _FlipCardState();
}

class _FlipCardState extends State<FlipCard>
    with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _frontRotation;
  late Animation<double> _backRotation;
  bool _showFront = true;
  bool _isFlipping = false;
  
  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: widget.flipDuration,
      vsync: this,
    );
    _setupAnimations();
    _showFront = !widget.initialFlipState;
    if (widget.initialFlipState) {
      _controller.value = 1.0;
    }
  }
  
  void _setupAnimations() {
    // 正面：0 → π/2（前半段可见）
    _frontRotation = Tween<double>(begin: 0, end: pi / 2)
        .animate(CurvedAnimation(
      parent: _controller,
      curve: Interval(0.0, 0.5, curve: Curves.easeIn),
    ));
    
    // 背面：π/2 → 0（后半段可见）
    _backRotation = Tween<double>(begin: -pi / 2, end: 0)
        .animate(CurvedAnimation(
      parent: _controller,
      curve: Interval(0.5, 1.0, curve: Curves.easeOut),
    ));
  }
  
  void toggleCard() {
    if (_isFlipping) return;
    _isFlipping = true;
    
    if (_showFront) {
      _controller.forward().then((_) {
        _showFront = false;
        _isFlipping = false;
        widget.onFlip?.call();
      });
    } else {
      _controller.reverse().then((_) {
        _showFront = true;
        _isFlipping = false;
        widget.onFlip?.call();
      });
    }
  }
  
  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }
  
  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: toggleCard,
      child: AnimatedBuilder(
        animation: _controller,
        builder: (context, child) {
          if (_showFront) {
            return Transform(
              alignment: Alignment.center,
              transform: Matrix4.identity()
                ..setEntry(3, 2, 0.001) // 透视效果
                ..rotateX(_frontRotation.value),
              child: _CardFace(
                child: widget.front,
                isFront: true,
              ),
            );
          } else {
            return Transform(
              alignment: Alignment.center,
              transform: Matrix4.identity()
                ..setEntry(3, 2, 0.001)
                ..rotateX(_backRotation.value),
              child: _CardFace(
                child: widget.back,
                isFront: false,
              ),
            );
          }
        },
      ),
    );
  }
}

/// 卡面包装（阴影、圆角、边框）
class _CardFace extends StatelessWidget {
  final Widget child;
  final bool isFront;
  
  const _CardFace({required this.child, required this.isFront});
  
  @override
  Widget build(BuildContext context) {
    return Container(
      decoration: BoxDecoration(
        color: Theme.of(context).colorScheme.surface,
        borderRadius: BorderRadius.circular(16),
        boxShadow: [
          BoxShadow(
            color: Colors.black.withOpacity(0.08),
            blurRadius: 12,
            offset: Offset(0, 4),
          ),
        ],
        border: isFront
            ? Border.all(color: Theme.of(context).colorScheme.outlineVariant)
            : Border.all(
                color: Theme.of(context).colorScheme.primary.withOpacity(0.3),
                width: 1.5,
              ),
      ),
      child: ClipRRect(
        borderRadius: BorderRadius.circular(16),
        child: child,
      ),
    );
  }
}
```

```dart
class MistakeCardFactory {
  /// 从错题创建闪卡
  Future<List<Flashcard>> createFromMistakes({
    required List<MistakeRecord> mistakes,
    required String deckId,
    bool autoGenerate = true,
  }) async {
    final cards = <Flashcard>[];
    
    for (final mistake in mistakes) {
      final card = _buildCard(mistake, deckId, autoGenerate);
      cards.add(card);
    }
    
    return cards;
  }
  
  Flashcard _buildCard(MistakeRecord mistake, String deckId, bool autoGen) {
    // 根据题目类型选择卡片类型
    final cardType = _detectCardType(mistake.question);
    
    final front = CardContent(
      primary: mistake.question.stem,
      latex: mistake.question.latex,
      imageUrl: mistake.question.imageUrl,
      tags: [mistake.subject, mistake.errorType ?? ''],
    );
    
    CardContent back;
    if (autoGen) {
      // AI 辅助生成更完善的背面
      back = CardContent(
        primary: mistake.correctAnswer,
        secondary: mistake.analysisSummary ?? '请参考完整解析',
        latex: mistake.answerLatex,
        tags: mistake.knowledgePoints.map((kp) => kp.name).toList(),
      );
    } else {
      back = CardContent(
        primary: mistake.correctAnswer,
        latex: mistake.answerLatex,
        tags: [],
      );
    }
    
    return Flashcard(
      cardId: _generateCardId(),
      deckId: deckId,
      type: cardType,
      front: front,
      back: back,
      hint: _buildHint(mistake),
      metadata: CardMetadata(
        subject: mistake.subject,
        knowledgePointId: mistake.primaryKnowledgePointId,
        chapterId: mistake.chapterId,
        difficulty: mistake.difficulty,
        questionId: mistake.questionId,
        mistakeId: mistake.id,
      ),
      srsState: SrsState.initial(),
      source: 'mistake',
      createdAt: DateTime.now(),
      updatedAt: DateTime.now(),
      sortOrder: 0,
      isPinned: false,
      isArchived: false,
    );
  }
  
  CardType _detectCardType(Question question) {
    if (question.latex != null && question.latex!.isNotEmpty) {
      return CardType.formula;
    }
    if (question.imageUrl != null) {
      return CardType.imageText;
    }
    return CardType.text;
  }
}
```

离线时使用 SM-2 算法的简化版本进行本地调度：

```dart
class LocalSrsScheduler {
  /// 离线 SRS 调度（SM-2 简化版）
  static SrsState schedule(SrsState current, CardRating rating) {
    int newInterval;
    double newEase = current.easeFactor;
    int newReps = current.repetitions;
    
    switch (rating) {
      case CardRating.again:
        newReps = 0;
        newInterval = 1; // 1分钟后再次出现（会话内）
        newEase = (newEase - 0.2).clamp(1.3, 2.5);
        break;
      case CardRating.hard:
        newInterval = (current.interval * 1.2).round().clamp(1, 365);
        newEase = (newEase - 0.15).clamp(1.3, 2.5);
        newReps++;
        break;
      case CardRating.good:
        if (current.repetitions == 0) {
          newInterval = 1;
        } else if (current.repetitions == 1) {
          newInterval = 3;
        } else {
          newInterval = (current.interval * newEase).round();
        }
        newReps++;
        break;
      case CardRating.easy:
        if (current.repetitions == 0) {
          newInterval = 4;
        } else if (current.repetitions == 1) {
          newInterval = 6;
        } else {
          newInterval = (current.interval * newEase * 1.3).round();
        }
        newEase = (newEase + 0.15).clamp(1.3, 2.5);
        newReps++;
        break;
    }
    
    return SrsState(
      interval: newInterval,
      easeFactor: newEase,
      repetitions: newReps,
      lastReviewedAt: DateTime.now(),
      dueDate: DateTime.now().add(Duration(days: newInterval)),
      isLearned: newReps > 0,
      sessionRating: null,
    );
  }
}
```

### 8.3 同步队列

```dart
class ReviewLogSyncQueue {
  final LocalDatabase _db;
  final ApiClient _api;
  
  /// 将离线评级加入同步队列
  Future<void> enqueue(ReviewLog log) async {
    await _db.insert('review_logs', {
      'session_id': log.sessionId,
      'card_id': log.cardId,
      'deck_id': log.deckId,
      'rating': log.rating.name,
      'time_spent_ms': log.timeSpentMs,
      'reviewed_at': log.reviewedAt.millisecondsSinceEpoch,
      'synced': 0,
    });
  }
  
  /// 执行同步
  Future<void> flush() async {
    final unsynced = await _db.query(
      'review_logs',
      where: 'synced = ?',
      whereArgs: [0],
      limit: 100,
    );
    
    if (unsynced.isEmpty) return;
    
    try {
      final response = await _api.post('/api/v1/flashcard/study/sync-logs', data: {
        'logs': unsynced.map((log) => {
          'card_id': log['card_id'],
          'rating': log['rating'],
          'time_spent_ms': log['time_spent_ms'],
          'reviewed_at': log['reviewed_at'],
        }).toList(),
      });
      
      // 服务端返回修正后的 SRS 状态
      final correctedStates = response['corrected_srs'] as Map<String, dynamic>;
      for (final entry in correctedStates.entries) {
        await _updateCardSrsState(entry.key, entry.value);
      }
      
      // 标记已同步
      final ids = unsynced.map((l) => l['log_id']).toList();
      await _db.update(
        'review_logs',
        {'synced': 1},
        where: 'log_id IN (${List.filled(ids.length, '?').join(',')})',
        whereArgs: ids,
      );
    } catch (e) {
      // 同步失败，下次重试
      logger.warning('Review log sync failed: $e');
    }
  }
}
```
