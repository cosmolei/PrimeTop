# 服务端-教育内容无障碍自动适配与辅助技术内容生成管线引擎-详细设计

## 1. 概述

### 1.1 功能定位

教育平台承载大量多媒体教学内容（图文、公式、图表、音视频、交互组件），不同学习需求的学生（视障、听障、色觉异常、阅读障碍、认知障碍等）在内容消费时面临显著障碍。本引擎负责在内容生产与分发链路中，**自动将教育内容转换为多种无障碍适配版本**，确保所有学生都能以适合自己的方式获取学习材料。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 图片替代文本覆盖率 | 平台公开内容 ≥ 95% |
| 数学公式语音可读率 | ≥ 90% |
| 视频字幕覆盖率 | 正式课程视频 100% |
| 内容可读性分级覆盖率 | 全部文本内容 100% |
| 色觉异常适配覆盖率 | 含颜色编码的图表 100% |
| 无障碍适配处理延迟 | 单内容项 ≤ 30s |

### 1.3 适用范围

- 同步课堂学习内容（教材正文、例题、练习）
- AI 辅导对话生成内容
- 题库题目与解析内容
- 教育视频与多媒体资源
- 用户生成内容（学生笔记、教师课件）

### 1.4 与现有模块的边界

| 现有模块 | 边界划分 |
| --- | --- |
| 客户端无障碍访问与辅助功能系统 | 负责客户端 UI 层面的无障碍（屏幕阅读器焦点、字体缩放、色彩对比），本引擎负责内容本身的无障碍转换 |
| 教育内容视频字幕自动生成管线 | 字幕生成是本引擎的一个上游输入源，本引擎负责将字幕整合为完整的无障碍音轨描述 |
| 服务端-教育内容认知适宜性评估 | 关注认知负载与信息密度，本引擎关注感官通道适配 |
| 服务端-学生用户学习困难模式智能识别 | 识别学习困难模式，本引擎基于识别结果执行内容适配 |

```
    │
    ▼
```

### 4.1 内容接入层 (ContentAccessLayer)

负责监听内容变更事件，将新创建或更新的内容接入无障碍适配管线。

#### 4.1.1 事件监听接入

```java
/**
 * 内容变更事件监听器
 * 监听来自各业务模块的内容创建/更新事件
 */
@Component
public class ContentAccessibilityEventListener {

    @Autowired
    private AccessibilityOrchestrator orchestrator;

    /**
     * 监听课程内容创建事件
     */
    @KafkaListener(topics = "content.course.created", groupId = "accessibility-group")
    public void onCourseContentCreated(CourseContentCreatedEvent event) {
        AccessibilityRequest request = AccessibilityRequest.builder()
            .contentId(event.getContentId())
            .contentType(detectContentType(event.getContentBody()))
            .sourceModule("COURSE")
            .sourceRef(buildSourceRef(event))
            .priority(calculatePriority(event))
            .build();
        orchestrator.enqueueAccessibilityAdaptation(request);
    }

    /**
     * 监听题目入库事件
     */
    @KafkaListener(topics = "question.published", groupId = "accessibility-group")
    public void onQuestionPublished(QuestionPublishedEvent event) {
        AccessibilityRequest request = AccessibilityRequest.builder()
            .contentId(event.getQuestionId())
            .contentType("QUESTION")
            .sourceModule("QUESTION")
            .sourceRef(Map.of("url", event.getResourceUrl(), "hash", event.getContentHash()))
            .priority(3) // 题库内容优先级较高
            .build();
        orchestrator.enqueueAccessibilityAdaptation(request);
    }

    /**
     * 监听AI对话内容生成完成事件（仅对被收藏或标记为重要的对话触发）
     */
    @KafkaListener(topics = "ai.dialog.bookmarked", groupId = "accessibility-group")
    public void onAIDialogBookmarked(AIDialogBookmarkedEvent event) {
        AccessibilityRequest request = AccessibilityRequest.builder()
            .contentId(event.getDialogId())
            .contentType("TEXT")
            .sourceModule("AI_DIALOG")
            .sourceRef(Map.of("dialogId", event.getDialogId(), "userId", event.getUserId()))
            .priority(7) // UGC内容优先级较低
            .build();
        orchestrator.enqueueAccessibilityAdaptation(request);
    }

    /**
     * 检测内容类型
     */
    private String detectContentType(ContentBody body) {
        if (body.getImages() != null && !body.getImages().isEmpty()) {
            return body.getText() != null ? "MIXED" : "IMAGE";
        }
        if (body.getFormulas() != null && !body.getFormulas().isEmpty()) {
            return body.getText() != null ? "MIXED" : "FORMULA";
        }
        if (body.getTables() != null && !body.getTables().isEmpty()) {
            return "TABLE";
        }
        return "TEXT";
    }
}
```

#### 4.1.2 批量回溯扫描

```java
/**
 * 批量无障碍适配扫描服务
 * 用于对存量内容进行回溯性适配处理
 */
@Service
public class BatchAccessibilityScanService {

    /**
     * 执行批量扫描（按分页处理）
     * @param scanCriteria 扫描条件（模块、类型、时间范围）
     * @param batchSize 每批数量
     */
    public void executeBatchScan(ScanCriteria scanCriteria, int batchSize) {
        String scanCursor = null;
        do {
            // 分页查询未适配内容
            List<ContentItem> items = contentService.findUnadaptedContent(
                scanCriteria, scanCursor, batchSize);
            
            if (items.isEmpty()) {
                break;
            }

            for (ContentItem item : items) {
                AccessibilityRequest request = buildRequest(item);
                orchestrator.enqueueAccessibilityAdaptation(request);
            }

            scanCursor = items.get(items.size() - 1).getCursor();
            
            // 批次间间隔，避免突发流量
            Thread.sleep(1000);
        } while (true);
    }

    /**
     * 定时增量扫描（每日凌晨执行）
     * 检查最近24小时内更新但未适配的内容
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void scheduledIncrementalScan() {
        ScanCriteria criteria = ScanCriteria.builder()
            .updatedAfter(LocalDateTime.now().minusDays(1))
            .build();
        executeBatchScan(criteria, 200);
    }
}
```

### 4.2 适配分析调度器 (AccessibilityOrchestrator)

分析内容结构，决定需要执行哪些适配操作，并调度到对应的处理管线。

#### 4.2.1 核心调度逻辑

```java
/**
 * 无障碍适配编排器
 */
@Service
public class AccessibilityOrchestrator {

    @Autowired
    private AdaptationPipelineFactory pipelineFactory;

    @Autowired
    private AccessibilityAdaptationRepository adaptationRepo;

    @Autowired
    private ContentAccessibilityManifestRepository manifestRepo;

    @Autowired
    private TaskQueueService taskQueueService;

    /**
     * 将内容接入适配管线
     */
    @Transactional
    public void enqueueAccessibilityAdaptation(AccessibilityRequest request) {
        // 1. 幂等检查 - 同一内容不重复创建适配任务
        Optional<AccessibilityAdaptation> existing = adaptationRepo
            .findLatestByContent(request.getContentId(), request.getContentType());
        if (existing.isPresent() && existing.get().isActive()) {
            log.info("内容 {} 的适配任务已存在且有效，跳过", request.getContentId());
            return;
        }

        // 2. 分析适配需求
        AdaptationPlan plan = analyzeAdaptationNeeds(request);

        // 3. 为每种适配类型创建独立的适配记录和任务
        for (AdaptationTaskSpec spec : plan.getTasks()) {
            AccessibilityAdaptation adaptation = buildAdaptation(request, spec);
            adaptationRepo.save(adaptation);

            AccessibilityTask task = taskQueueService.createTask(adaptation.getId(), spec);
            taskQueueService.enqueue(task);

            // 发送适配任务创建事件
            eventPublisher.publishEvent(new AdaptationTaskCreatedEvent(adaptation.getId()));
        }
    }

    /**
     * 分析内容的适配需求
     */
    private AdaptationPlan analyzeAdaptationNeeds(AccessibilityRequest request) {
        AdaptationPlan plan = new AdaptationPlan();
        ContentStructuralAnalysis analysis = analyzeContentStructure(request);

        // 文本内容 → 可读性评估 + 简化适配
        if (analysis.hasText()) {
            plan.addTask(AdaptationType.READABILITY_ASSESS);
            if (analysis.getTextComplexity() > THRESHOLD_COMPLEX) {
                plan.addTask(AdaptationType.SIMPLIFIED_TEXT);
            }
        }

        // 图片内容 → 替代文本生成
        if (analysis.hasImages()) {
            plan.addTask(AdaptationType.ALT_TEXT);
        }

        // 数学公式 → 语义描述生成
        if (analysis.hasFormulas()) {
            plan.addTask(AdaptationType.FORMULA_DESCRIPTION);
        }

        // 表格内容 → 线性化处理
        if (analysis.hasTables()) {
            plan.addTask(AdaptationType.TABLE_LINEARIZE);
        }

        // 视频内容 → 字幕验证 + 音频描述
        if (analysis.hasVideo()) {
            if (!analysis.hasCaption()) {
                plan.addTask(AdaptationType.CAPTION_GENERATE);
            }
            plan.addTask(AdaptationType.AUDIO_DESCRIPTION);
        }

        // 含颜色编码的图表 → 色觉友好版本
        if (analysis.hasColorCodedCharts()) {
            plan.addTask(AdaptationType.COLORBLIND_ADAPT);
        }

        // 交互式内容 → 替代方案
        if (analysis.hasInteractiveElements()) {
            plan.addTask(AdaptationType.INTERACTIVE_ALTERNATIVE);
        }

        // 首选音频通道 → TTS生成
        if (request.isAudioOutputNeeded()) {
            plan.addTask(AdaptationType.TTS_GENERATE);
        }

        return plan;
    }
}
```

### 4.3 图片替代文本生成模块 (AltTextGenerator)

使用多模态视觉模型为图片自动生成教育场景的替代文本描述。

```java
/**
 * 图片替代文本生成服务
 */
@Service
public class AltTextGenerator implements AdaptationHandler {

    @Autowired
    private MultiModalModelClient visionModel;

    @Autowired
    private PromptTemplateService promptService;

    private static final int MAX_ALT_TEXT_LENGTH = 300;
    private static final int MIN_ALT_TEXT_LENGTH = 10;

    @Override
    public AdaptationResult process(AccessibilityAdaptation adaptation) {
        ContentImage image = loadImage(adaptation.getSourceRef());
        
        // 1. 根据图片上下文选择Prompt
        String promptTemplate = selectPromptByContext(image.getContext());
        Map<String, Object> variables = Map.of(
            "subject", image.getSubject(),
            "gradeLevel", image.getGradeLevel(),
            "surroundingText", image.getSurroundingText(),
            "imageType", image.getImageType() // PHOTO/DIAGRAM/CHART/ILLUSTRATION
        );
        String prompt = promptService.render(promptTemplate, variables);

        // 2. 调用视觉模型生成描述
        VisionModelRequest request = VisionModelRequest.builder()
            .imageUrl(image.getUrl())
            .prompt(prompt)
            .maxTokens(200)
            .temperature(0.3) // 低温度保证描述准确性
            .build();
        
        VisionModelResponse response = visionModel.analyze(request);

        // 3. 后处理：长度控制、敏感内容过滤
        String altText = postProcessAltText(response.getText());

        // 4. 质量校验
        AltTextQuality quality = validateAltText(altText, image);

        return AdaptationResult.builder()
            .outputText(altText)
            .confidence(response.getConfidence())
            .qualityScore(quality.getScore())
            .qualityIssues(quality.getIssues())
            .modelInfo(response.getModelName(), response.getModelVersion())
            .build();
    }

    /**
     * 根据图片类型选择不同的Prompt策略
     */
    private String selectPromptByContext(ImageContext context) {
        return switch (context.getImageType()) {
            case CHART -> "alt_text.chart.template";  // "描述图表的数据趋势、坐标轴、关键数据点"
            case DIAGRAM -> "alt_text.diagram.template"; // "描述示意图的结构、组件关系、流程方向"
            case EQUATION -> "alt_text.equation.template"; // "用自然语言描述数学表达式"
            case ILLUSTRATION -> "alt_text.illustration.template"; // "描述插图中的场景、人物、动作"
            case GEOMETRY -> "alt_text.geometry.template"; // "描述几何图形的形状、尺寸、位置关系"
            default -> "alt_text.generic.template";
        };
    }

    /**
     * 替代文本质量校验
     */
    private AltTextQuality validateAltText(String altText, ContentImage image) {
        AltTextQuality quality = new AltTextQuality();
        List<String> issues = new ArrayList<>();

        // 长度检查
        if (altText.length() < MIN_ALT_TEXT_LENGTH) {
            issues.add("ALT_TEXT_TOO_SHORT");
            quality.setScore(quality.getScore() - 20);
        }
        if (altText.length() > MAX_ALT_TEXT_LENGTH) {
            issues.add("ALT_TEXT_TOO_LONG");
            quality.setScore(quality.getScore() - 10);
        }

        // 内容相关性检查（是否包含图片周围文本中的关键词）
        if (image.getSurroundingText() != null) {
            Set<String> surroundingKeywords = extractKeywords(image.getSurroundingText());
            Set<String> altKeywords = extractKeywords(altText);
            double overlap = calculateKeywordOverlap(surroundingKeywords, altKeywords);
            if (overlap < 0.1) {
                issues.add("LOW_CONTEXT_RELEVANCE");
                quality.setScore(quality.getScore() - 15);
            }
        }

        // 教育准确性检查（是否包含学科相关术语）
        if (image.getSubject() != null) {
            Set<String> subjectTerms = subjectTermDictionary.getTerms(image.getSubject());
            boolean hasRelevantTerms = subjectTerms.stream()
                .anyMatch(altText::contains);
            if (!hasRelevantTerms && isEducationalImage(image)) {
                issues.add("MISSING_SUBJECT_TERMINOLOGY");
                quality.setScore(quality.getScore() - 10);
            }
        }

        quality.setIssues(issues);
        return quality;
    }
}
```

### 4.4 数学公式无障碍转换模块 (FormulaAccessibilityConverter)

将 LaTeX / MathML 公式转换为语音可读的自然语言描述和结构化语义表示。

```java
/**
 * 数学公式无障碍转换服务
 */
@Service
public class FormulaAccessibilityConverter implements AdaptationHandler {

    @Autowired
    private LatexParser latexParser;

    @Autowired
    private LlmClient llmClient;

    @Override
    public AdaptationResult process(AccessibilityAdaptation adaptation) {
        String latex = extractLatex(adaptation.getSourceRef());

        // 1. 解析 LaTeX 为结构化 AST
        FormulaAST ast = latexParser.parse(latex);

        // 2. 规则驱动的初步描述（精确但机械）
        String ruleBasedDesc = generateRuleBasedDescription(ast);

        // 3. LLM 增强为自然语言（流畅但保留精确性）
        String naturalDesc = enhanceWithLLM(latex, ruleBasedDesc, ast.getContext());

        // 4. 生成逐符号朗读序列（供 TTS 使用）
        List<SpeechSegment> speechSegments = generateSpeechSegments(ast);

        // 5. 生成结构化语义表示（供屏幕阅读器使用）
        String semanticML = generateSemanticML(ast);

        FormulaAdaptationOutput output = FormulaAdaptationOutput.builder()
            .originalLatex(latex)
            .naturalDescription(naturalDesc)
            .speechSequence(speechSegments)
            .semanticMarkup(semanticML)
            .complexityLevel(ast.getComplexityLevel())
            .build();

        return AdaptationResult.builder()
            .outputText(naturalDesc)
            .outputMetadata(objectMapper.valueToTree(output))
            .confidence(0.92)
            .qualityScore(calculateFormulaAccuracy(latex, naturalDesc))
            .build();
    }

    /**
     * 规则驱动的公式描述
     * 通过 AST 遍历生成机械但精确的描述
     */
    private String generateRuleBasedDescription(FormulaAST ast) {
        StringBuilder sb = new StringBuilder();
        traverseForDescription(ast.getRoot(), sb);
        return sb.toString();
    }

    private void traverseForDescription(FormulaNode node, StringBuilder sb) {
        switch (node.getType()) {
            case FRACTION:
                sb.append("分子为");
                traverseForDescription(node.getChildren().get(0), sb);
                sb.append("，分母为");
                traverseForDescription(node.getChildren().get(1), sb);
                break;
            case SQRT:
                sb.append("根号下");
                traverseForDescription(node.getChildren().get(0), sb);
                break;
            case POWER:
                traverseForDescription(node.getChildren().get(0), sb);
                sb.append("的");
                traverseForDescription(node.getChildren().get(1), sb);
                sb.append("次方");
                break;
            case SUBSCRIPT:
                traverseForDescription(node.getChildren().get(0), sb);
                sb.append("的下标为");
                traverseForDescription(node.getChildren().get(1), sb);
                break;
            case INTEGRAL:
                sb.append("积分，从");
                traverseForDescription(node.getBounds().get(0), sb);
                sb.append("到");
                traverseForDescription(node.getBounds().get(1), sb);
                sb.append("，对");
                traverseForDescription(node.getIntegrand(), sb);
                sb.append("求");
                traverseForDescription(node.getVariable(), sb);
                sb.append("的积分");
                break;
            case SUMMATION:
                sb.append("求和，");
                sb.append(node.getSumIndex());
                sb.append("从");
                traverseForDescription(node.getBounds().get(0), sb);
                sb.append("到");
                traverseForDescription(node.getBounds().get(1), sb);
                sb.append("，求");
                traverseForDescription(node.getSumBody(), sb);
                sb.append("的和");
                break;
            case FUNCTION:
                sb.append(node.getFunctionName());
                sb.append("函数，自变量为");
                traverseForDescription(node.getArgument(), sb);
                break;
            case GREEK_LETTER:
                sb.append(GreekLetterDictionary.getChineseName(node.getValue()));
                break;
            case OPERATOR:
                sb.append(OperatorDictionary.getChineseName(node.getValue()));
                break;
            case CONSTANT:
                sb.append(ConstantDictionary.getChineseName(node.getValue()));
                break;
            default:
                sb.append(node.getValue());
        }
    }

    /**
     * 生成 MathML 语义增强版（供屏幕阅读器使用）
     */
    private String generateSemanticML(FormulaAST ast) {
        // 生成带有 aria-label 的 MathML
        MathMLBuilder builder = new MathMLBuilder();
        builder.setAriaLabel(ast.getNaturalDescription());
        return builder.build(ast);
    }
}
```

### 4.5 文本简化与可读性优化模块 (TextSimplifier)

针对阅读障碍学生和低年级学生，自动生成简化版文本。

```java
/**
 * 教育文本简化服务
 */
@Service
public class TextSimplifier implements AdaptationHandler {

    @Autowired
    private LlmClient llmClient;

    @Autowired
    private ReadabilityAnalyzer readabilityAnalyzer;

    @Override
    public AdaptationResult process(AccessibilityAdaptation adaptation) {
        String originalText = extractText(adaptation.getSourceRef());
        String targetLevel = adaptation.getMetadata().getTargetGradeLevel();

        // 1. 评估原文可读性
        ReadabilityAssessment original = readabilityAnalyzer.assess(originalText);

        // 2. 判断是否需要简化
        if (original.getGradeLevel() <= targetLevel) {
            return AdaptationResult.skip("原文已满足目标年级可读性要求");
        }

        // 3. 分段简化（保持知识点完整性）
        List<TextSegment> segments = segmentText(originalText);
        List<TextSegment> simplifiedSegments = new ArrayList<>();

        for (TextSegment segment : segments) {
            String simplified = simplifySegment(segment, original.getGradeLevel(), targetLevel);
            simplifiedSegments.add(new TextSegment(simplified, segment.getKnowledgePoints()));
        }

        // 4. 合并并确保知识点完整性
        String result = mergeAndVerify(simplifiedSegments, originalText);

        // 5. 简化后可读性再评估
        ReadabilityAssessment after = readabilityAnalyzer.assess(result);

        return AdaptationResult.builder()
            .outputText(result)
            .confidence(calculateSimplificationQuality(original, after))
            .qualityScore(after.getGradeLevel() <= targetLevel ? 90 : 60)
            .build();
    }

    /**
     * 文本简化 Prompt 编排
     */
    private String simplifySegment(TextSegment segment, String originalLevel, String targetLevel) {
        String prompt = """
            你是教育内容无障碍简化专家。请将以下教育文本简化，使其适合 %s 学生阅读。
            
            简化规则：
            1. 保留所有核心知识点和专业术语
            2. 将复杂长句拆分为简短句子（每句不超过20字）
            3. 用日常用语替换生僻词汇，但保留学科核心概念
            4. 增加过渡词使逻辑关系更明确
            5. 如有抽象概念，补充一个生活化例子
            6. 不删除原文的数学公式、化学方程式、专业定义
            7. 保持教育准确性，不引入错误信息
            8. 简化后文本长度不超过原文的1.5倍
            
            原始文本（当前可读性等级：%s）：
            %s
            
            请输出简化后的文本：
            """.formatted(targetLevel, originalLevel, segment.getText());

        LlmRequest request = LlmRequest.builder()
            .prompt(prompt)
            .model("gpt-4o-mini") // 简化任务使用轻量模型
            .temperature(0.2)
            .maxTokens(800)
            .build();

        return llmClient.complete(request).getText();
    }
}
```

```java
@Service
public class TableLinearizer implements AdaptationHandler {

    @Override
    public AdaptationResult process(AccessibilityAdaptation adaptation) {
        TableData table = parseTable(adaptation.getSourceRef());
        
        StringBuilder linear = new StringBuilder();
        
        // 1. 表格摘要
        linear.append(String.format("以下是一个%d行%d列的表格。", 
            table.getRowCount(), table.getColumnCount()));
        
        if (table.getTitle() != null) {
            linear.append("表格标题：").append(table.getTitle()).append("。");

        if (table.hasHeader()) {
            linear.append("表头依次为：");
            List<String> headers = table.getHeaders();
            for (int i = 0; i < headers.size(); i++) {
                linear.append(String.format("第%d列%s", i + 1, headers.get(i)));
                if (i < headers.size() - 1) linear.append("，");
            }
            linear.append("。");
        }

        for (int rowIdx = 0; rowIdx < table.getDataRowCount(); rowIdx++) {
            TableRow row = table.getDataRow(rowIdx);
            linear.append(String.format("第%d行：", rowIdx + 1));

                linear.append(String.format("%s是%s", header, row.getCell(colIdx)));
                if (colIdx < row.getCellCount() - 1) linear.append("，");
            }
            linear.append("。");
        }
        
        // 4. 数据趋势摘要（如果表格含数值数据）
        if (table.hasNumericData()) {
            String trendSummary = generateTrendSummary(table);

            .outputText(linear.toString())
```

### 4.7 视频音频描述补全模块 (AudioDescriptionGenerator)

为教育视频生成音频描述（Audio Description），让视障学生了解视频中的视觉信息。

```java
/**
 * 视频音频描述生成服务
 */
@Service
public class AudioDescriptionGenerator implements AdaptationHandler {

    @Autowired
    private VideoFrameExtractor frameExtractor;

    @Autowired
    private MultiModalModelClient visionModel;

    @Autowired
    private LlmClient llmClient;

    @Override
    public AdaptationResult process(AccessibilityAdaptation adaptation) {
        VideoMetadata video = loadVideoMetadata(adaptation.getSourceRef());
        
        // 1. 获取已有字幕（如果有）
        List<CaptionSegment> captions = video.getCaptions();
        
        // 2. 提取无声段落（有视觉内容但没有语音的时间段）
        List<TimeSlot> silentSlots = findSilentSlots(video, captions);
        
        // 3. 对无声段落提取关键帧并分析
        List<AudioDescriptionScript> scripts = new ArrayList<>();
        
        for (TimeSlot slot : silentSlots) {
            // 提取关键帧
            List<VideoFrame> keyFrames = frameExtractor.extractKeyFrames(
                video.getUrl(), slot.getStart(), slot.getEnd(), 2); // 每段最多2帧
            
            // 视觉模型分析画面
            String visualDescription = analyzeFrames(keyFrames, video.getSubject());
            
            // 判断是否需要音频描述（有些无声段落不需要描述）
            if (needsAudioDescription(visualDescription, slot)) {
                // 生成简洁的描述脚本
                String script = generateConciseDescription(visualDescription, slot.getDuration());
                
                scripts.add(new AudioDescriptionScript(
                    slot.getStart(), slot.getEnd(), script));
            }
        }
        
        // 4. 对已有字幕中的关键视觉信息进行补充标注
        List<VisualEnhancement> enhancements = identifyVisualEnhancements(video, captions);
        
        // 5. 合成完整音频描述方案
        AudioDescriptionPlan plan = AudioDescriptionPlan.builder()
            .scripts(scripts)
            .enhancements(enhancements)
            .totalDuration(scripts.stream().mapToDouble(s -> s.getEnd() - s.getStart()).sum())
            .build();
        
        return AdaptationResult.builder()
            .outputMetadata(objectMapper.valueToTree(plan))
            .confidence(0.85)
            .qualityScore(82)
            .build();
    }

    /**
     * 判断无声段落是否需要音频描述
     */
    private boolean needsAudioDescription(String description, TimeSlot slot) {
        // 如果描述为空或仅是静态画面，不需要
        if (description == null || description.isBlank()) return false;
        
        // 如果时间段太短（<1.5秒），来不及插入描述
        if (slot.getDuration() < 1.5) return false;
        
        // 如果描述中包含教育关键信息（公式、图表、操作步骤等），必须描述
        if (containsEducationalVisual(description)) return true;
        
        return true;
    }
}
```

## 7. 错误处理与降级策略

### 7.1 错误码定义

| 错误码 | 含义 | 处理策略 |
| --- | --- | --- |
| ACCESS_CONTENT_NOT_FOUND | 原始内容不存在 | 跳过适配，记录警告日志 |
| ACCESS_MODEL_TIMEOUT | AI模型调用超时 | 自动降级到轻量模型，或使用规则引擎兜底 |
| ACCESS_MODEL_RATE_LIMIT | AI模型限流 | 延迟重试，指数退避 |
| ACCESS_ALT_TEXT_LOW_CONFIDENCE | 替代文本置信度过低 | 转人工审核队列 |
| ACCESS_FORMULA_PARSE_ERROR | LaTeX解析失败 | 跳过公式描述，记录到内容质量监控 |
| ACCESS_VIDEO_PROCESS_ERROR | 视频处理失败 | 降级为仅输出文本摘要 |
| ACCESS_STORAGE_WRITE_FAIL | 适配结果存储失败 | 重试3次后告警，任务标记为FAILED |
| ACCESS_ADAPTATION_EXPIRED | 适配结果已过期(源内容已更新) | 重新触发适配 |

### 7.2 分级降级策略

```java
/**
 * 无障碍适配降级策略
 */
public class AccessibilityFallbackStrategy {

    /**
     * 根据失败场景选择降级方案
     */
    public AdaptationResult fallback(AdaptationContext context, Exception error) {
        // Level 1: 模型降级
        if (error instanceof ModelTimeoutException) {
            log.warn("模型超时，降级到轻量模型");
            return retryWithLightModel(context);
        }

        // Level 2: 规则引擎兜底
        if (error instanceof ModelUnavailableException) {
            log.warn("模型不可用，使用规则引擎生成基础描述");
            return generateRuleBasedDescription(context);
        }

        // Level 3: 部分适配（只输出已有信息）
        if (error instanceof ContentParseException) {
            log.warn("内容解析失败，输出部分适配结果");
            return partialAdaptation(context);
        }

        // Level 4: 占位 + 人工审核
        log.error("适配完全失败，转人工审核");
        return AdaptationResult.manualReview(
            "自动适配失败：" + error.getMessage());
    }

    /**
     * 规则引擎兜底（精确但机械）
     * 当AI模型不可用时，使用基于规则的基础描述
     */
    private AdaptationResult generateRuleBasedDescription(AdaptationContext context) {
        StringBuilder desc = new StringBuilder();
        
        // 图片：根据文件名和上下文生成基础描述
        if (context.getContentType() == ContentType.IMAGE) {
            desc.append("图片");
            if (context.getImageAlt() != null) {
                desc.append("：").append(context.getImageAlt());
            }
            if (context.getSurroundingText() != null) {
                desc.append("。相关文本：")
                   .append(truncate(context.getSurroundingText(), 100));
            }
        }
        
        // 公式：使用 LaTeX 原文
        if (context.getContentType() == ContentType.FORMULA) {
            desc.append("数学公式：")
               .append(context.getRawFormula());
        }
        
        return AdaptationResult.builder()
            .outputText(desc.toString())
            .confidence(0.5)
            .qualityScore(50)
            .metadata("fallback", "RULE_BASED")
            .build();
    }
}
```

### 8.1 批量处理优化

```java
/**
 * 批量图片替代文本生成（合并多次模型调用）
 */
@Service
public class BatchAltTextGenerator {
    
    private static final int BATCH_SIZE = 5;

    /**
     * 批量处理同一页面的多张图片
     * 利用上下文信息提高描述质量
     */
    @Async("accessibilityTaskExecutor")
    public CompletableFuture<List<AdaptationResult>> batchGenerate(
            List<AccessibilityAdaptation> adaptations) {
        
        // 按 source_content 分组（同一页面的图片放一批）
        Map<String, List<AccessibilityAdaptation>> groups = 
            adaptations.stream()
                .collect(Collectors.groupingBy(AccessibilityAdaptation::getContentId));

        List<AdaptationResult> results = new ArrayList<>();
        
        for (List<AccessibilityAdaptation> batch : groups.values()) {
            // 构建批量Prompt（一次调用处理多张图片）
            String batchPrompt = buildBatchPrompt(batch);
            List<String> imageUrls = batch.stream()
                .map(a -> extractImageUrl(a.getSourceRef()))
                .toList();
            
            VisionBatchRequest request = VisionBatchRequest.builder()
                .imageUrls(imageUrls)
                .prompt(batchPrompt)
                .build();
            
            List<VisionModelResponse> responses = visionModel.batchAnalyze(request);
            
            for (int i = 0; i < batch.size(); i++) {
                results.add(buildResult(batch.get(i), responses.get(i)));
            }
        }
        
        return CompletableFuture.completedFuture(results);
    }
}
```
