## 1. 概述

### 1.1 设计目标

为 PrimeTop 提供一个**自然语言到数据查询**的智能引擎，让家长、教师、学生三类用户无需理解复杂的数据看板，直接用自然语言提问即可获取学习数据洞察。

**典型场景**：

| 提问者 | 示例问题 | 系统返回 |
|--------|----------|----------|
| 家长 | "孩子这周数学学了多少时间？" | 本周数学学习时长 3小时24分钟，较上周+15% |
| 家长 | "孩子最近哪个知识点比较薄弱？" | 「一元二次方程」掌握度 42%，近7天错题6道 |
| 教师 | "这次作业全班的平均分是多少？" | 全班平均 78.5分，最高 95分，最低 52分 |
| 教师 | "哪些学生需要重点关注？" | 张某（正确率45%）、李某（连续3天未完成） |
| 学生 | "我上次英语测验错了几道题？" | 上次英语测验共错4道题，主要在「定语从句」 |
| 运营 | "本月活跃用户留存率怎么样？" | 30日留存 42.3%，环比+2.1pp |

### 1.2 与现有模块的边界

| 模块 | 职责 | 与本引擎的关系 |
|------|------|----------------|
| AI 智能辅导对话 | 回答学科知识问题 | **不重叠**：辅导回答"知识"，本引擎回答"数据" |
| 学情分析 | 结构化展示能力画像 | **互补**：学情分析是主动浏览，本引擎是被动问答 |
| 管理后台数据看板 | 运营人员查看 BI 报表 | **互补**：看板是固定图表，本引擎是即兴问答 |
| 全局搜索 | 搜索题目、知识点 | **不重叠**：搜索找"内容"，本引擎查"数据" |

### 1.3 设计原则

1. **安全优先**：严格的数据权限隔离，用户只能查到有权访问的数据
2. **准确为王**：宁可回答"我不理解"，不返回错误数据
3. **可解释**：每个回答都附带数据来源和查询逻辑说明
4. **渐进式**：支持追问细化，如先问"孩子学习情况"再追问"数学呢"
5. **低延迟**：简单查询 < 2秒，复杂查询 < 5秒

### 2.1 核心处理流程

```
用户提问
  │
  ├─ 1. 权限校验：该用户能查询哪些数据范围？
  ├─ 2. 意图分类：这是数据查询问题还是学科知识问题？
  ├─ 3. 实体抽取：提取时间范围、学科、学生、指标等实体
  ├─ 4. 上下文解析：是否有追问？沿用上文哪些条件？
  ├─ 5. 查询路由：
  │     ├─ 命中模板规则 → Simple Query Router（快速路径）
  │     ├─ 未命中但高置信 → LLM Query Generator（慢速路径）
  │     └─ 低置信 → Fallback Handler 引导用户
  ├─ 6. 查询执行：带权限范围执行，自动注入数据隔离条件
  ├─ 7. 结果校验：数据是否合理？是否泄露隐私？
  └─ 8. 自然语言生成：将结构化数据转化为人类可读回答
```

### 4.3 双层意图分类器

```python
import re
from dataclasses import dataclass, field

@dataclass
class NLUParseResult:
    intent: str
    confidence: float
    entities: dict = field(default_factory=dict)
    raw_text: str = ""
    is_data_query: bool = True


class RuleBasedIntentClassifier:
    """第一层：基于规则的快速分类（高精度低召回）"""
    
    def __init__(self):
        self.rules = [
            {
                'intent': 'query_study_time',
                'keywords': ['学了多久', '学习时长', '学习时间', '学了多少时间'],
                'threshold': 0.5,
            },
            {
                'intent': 'query_score',
                'keywords': ['考了多少分', '分数', '成绩', '得了多少分'],
                'threshold': 0.5,
            },
            {
                'intent': 'query_mistake_count',
                'keywords': ['错了几道', '错题', '错了多少', '做错'],
                'threshold': 0.5,
            },
            {
                'intent': 'query_weak_point',
                'keywords': ['薄弱', '不太好', '哪个知识点差', '弱项'],
                'threshold': 0.5,
            },
            {
                'intent': 'query_rank',
                'keywords': ['排名', '排行', '第几名', '名次'],
                'threshold': 0.5,
            },
            {
                'intent': 'query_compare',
                'keywords': ['比上周', '比上个', '相比', '对比', '环比'],
                'threshold': 0.5,
            },
        ]
    
    def classify(self, text: str) -> NLUParseResult | None:
        text_lower = text.lower().strip()
        
        best_match = None
        best_score = 0.0
        
        for rule in self.rules:
            matched = sum(1 for kw in rule['keywords'] if kw in text_lower)
            score = matched / len(rule['keywords']) if rule['keywords'] else 0.0
            
            if score >= rule['threshold'] and score > best_score:
                best_score = score
                best_match = rule
        
        if not best_match:
            return None
        
        entities = self._extract_entities(text_lower)
        
        return NLUParseResult(
            intent=best_match['intent'],
            confidence=best_score,
            entities=entities,
            raw_text=text,
        )
    
    def _extract_entities(self, text: str) -> dict:
        entities = {}
        
        for pattern, value in ENTITY_PATTERNS['time_range'].items():
            if pattern in text:
                entities['time_range'] = pattern
                entities['time_start'] = value['start']
                entities['time_end'] = value['end']
                break
        
        for name, code in ENTITY_PATTERNS['subject'].items():
            if name in text:
                entities['subject'] = code
                entities['subject_name'] = name
                break
        
        for name, code in ENTITY_PATTERNS['metric'].items():
            if name in text:
                entities.setdefault('metric', code)
                break
        
        return entities


class LLMIntentClassifier:
    """第二层：基于大模型的意图分类（处理规则无法覆盖的复杂表达）"""
    
    def __init__(self, model_adapter):
        self.model = model_adapter
        self.system_prompt = """你是一个教育数据查询意图分类器。
请判断用户的问题是否属于"数据查询"类，如果是，返回具体意图类型。
如果不是数据查询（如学科知识问题、闲聊），返回 NOT_DATA_QUERY。

意图类型：
- query_study_time: 查询学习时长
- query_score: 查询分数/成绩
- query_accuracy: 查询正确率
- query_mistake_count: 查询错题数量
- query_weak_point: 查询薄弱知识点
- query_progress: 查询学习进度
- query_mastery: 查询知识点掌握度
- query_rank: 查询排名
- query_compare: 对比查询
- query_trend: 趋势查询
- query_task_status: 任务完成情况
- query_overview: 综合概况
- NOT_DATA_QUERY: 非数据查询

请返回JSON: {"intent": "...", "entities": {...}, "confidence": 0.0-1.0}"""
    
    async def classify(self, text: str, context: dict) -> NLUParseResult:
        user_prompt = f"问题: {text}\n上下文: {context}"
        
        response = await self.model.complete(
            system=self.system_prompt,
            user=user_prompt,
            temperature=0.1,
            max_tokens=200,
        )
        
        import json
        try:
            result = json.loads(response)
            return NLUParseResult(
                intent=result['intent'],
                confidence=result.get('confidence', 0.8),
                entities=result.get('entities', {}),
                raw_text=text,
                is_data_query=result['intent'] != 'NOT_DATA_QUERY',
            )
        except (json.JSONDecodeError, KeyError):
            return NLUParseResult(
                intent='NOT_DATA_QUERY',
                confidence=0.5,
                raw_text=text,
                is_data_query=False,
            )
```

### 5.2 模板执行器

```python
class TemplateQueryExecutor:
    """模板查询执行器"""
    
    def __init__(self, db_pool, redis_client):
        self.db = db_pool
        self.redis = redis_client
    
    async def execute(
        self,
        template: dict,
        entities: dict,
        scope: 'DataScope',
    ) -> dict:
        """
        执行模板查询
        
        Args:
            template: 查询模板配置
            entities: 用户提取的实体
            scope: 数据权限范围
        """
        config = template['query_config']
        
        # 1. 参数绑定
        params = self._resolve_params(config['params'], entities, scope)
        
        # 2. 缓存检查
        cache_key = self._cache_key(template['id'], params)
        cached = await self.redis.get(cache_key)
        if cached:
            return json.loads(cached)
        
        # 3. 构建SQL
        sql = self._build_sql(config, params, scope)
        
        # 4. 执行查询
        import time
        start = time.time()
        rows = await self.db.fetch_all(sql, params)
        execution_ms = int((time.time() - start) * 1000)
        
        result = {
            'rows': rows,
            'row_count': len(rows),
            'execution_ms': execution_ms,
            'query_sql': sql,
        }
        
        # 5. 写缓存 (TTL 60秒)
        await self.redis.setex(cache_key, 60, json.dumps(result, default=str))
        
        return result
    
    def _resolve_params(
        self, param_defs: dict, entities: dict, scope: 'DataScope'
    ) -> dict:
        """解析参数值"""
        resolved = {}
        
        for param_name, spec in param_defs.items():
            source = spec['from']  # entity / scope / constant
            
            if source == 'entity':
                key = spec['key']
                value = entities.get(key)
                if value is None and spec.get('required'):
                    raise ParamMissingError(f"缺少必需参数: {key}")
                if value and 'transform' in spec:
                    value = self._apply_transform(spec['transform'], value)
                    
            elif source == 'scope':
                value = getattr(scope, spec.get('attr', 'ref_id'), None)
                if value is None and spec.get('required'):
                    raise ParamMissingError(f"缺少权限范围数据")
                    
            elif source == 'constant':
                value = spec['value']
            
            resolved[param_name] = value
        
        return resolved
    
    def _build_sql(self, config: dict, params: dict, scope: 'DataScope') -> str:
        """安全构建SQL（使用参数化查询，防止注入）"""
        select_parts = [f"{s['expr']} AS {s['alias']}" for s in config['select']]
        
        where_parts = []
        for w in config.get('where', []):
            if w['param'] in params and params[w['param']] is not None:
                where_parts.append(f"{w['field']} {w['op']} %({w['param']})s")
        
        # 注入权限过滤
        if scope.row_filter:
            where_parts.append(scope.row_filter)
        
        group_parts = [g['expr'] for g in config.get('groupBy', [])]
        order_parts = [f"{o['expr']} {o['direction']}" for o in config.get('orderBy', [])]
        
        sql = f"SELECT {', '.join(select_parts)} FROM {config['table']}"
        if where_parts:
            sql += f" WHERE {' AND '.join(where_parts)}"
        if group_parts:
            sql += f" GROUP BY {', '.join(group_parts)}"
        if order_parts:
            sql += f" ORDER BY {', '.join(order_parts)}"
        
        sql += f" LIMIT {scope.max_rows}"
        return sql
    
    def _cache_key(self, template_id: str, params: dict) -> str:
        import hashlib
        param_str = json.dumps(params, sort_keys=True, default=str)
        digest = hashlib.md5(param_str.encode()).hexdigest()[:8]
        return f"dqa:tpl:{template_id}:{digest}"
    
    def _apply_transform(self, transform: str, value: str):
        if transform == 'subject_to_code':
            return ENTITY_PATTERNS['subject'].get(value, value)
        elif transform == 'date_parse':
            return self._resolve_date_expression(value)
        return value
    
    def _resolve_date_expression(self, expr: str) -> str:
        """解析日期表达式"""
        from datetime import date, timedelta
        today = date.today()
        
        mapping = {
            'today': today,
            'yesterday': today - timedelta(days=1),
            'this_monday': today - timedelta(days=today.weekday()),
            'this_sunday': today - timedelta(days=today.weekday()) + timedelta(days=6),
            'last_monday': today - timedelta(days=today.weekday() + 7),
            'last_sunday': today - timedelta(days=today.weekday() + 1),
            'this_month_start': today.replace(day=1),
        }
        if expr.startswith('today-'):
            days = int(expr.replace('today-', '').replace('d', ''))
            return today - timedelta(days=days)
        
        result = mapping.get(expr)
        return result.isoformat() if result else expr
```

        # 时长：秒 → 可读格式
        if 'total_duration' in formatted:
            secs = int(formatted['total_duration'] or 0)
            hours = secs // 3600
            minutes = (secs % 3600) // 60

                f"{hours}小时{minutes}分钟" if hours > 0
                else f"{minutes}分钟"
            )
        
        # 百分比
        for key in ['accuracy_rate', 'completion_rate', 'mastery_level']:

@dataclass
class DataScope:
    """数据查询权限范围"""

class DataQARateLimiter:
    """数据问答频率限制"""
    
    LIMITS = {
        'STUDENT': {'per_minute': 5, 'per_day': 50},
        'PARENT':  {'per_minute': 10, 'per_day': 100},
        'TEACHER': {'per_minute': 20, 'per_day': 200},
        'ADMIN':   {'per_minute': 60, 'per_day': 1000},
    }
    
    async def check(self, user_id: int, role: str) -> bool:
        limits = self.LIMITS.get(role, self.LIMITS['STUDENT'])
        
        # 分钟级
        minute_key = f"dqa:rate:m:{user_id}:{int(time.time() // 60)}"
        minute_count = await self.redis.incr(minute_key)
        if minute_count == 1:
            await self.redis.expire(minute_key, 60)
        if minute_count > limits['per_minute']:
            return False
        
        # 日级
        today = date.today().isoformat()
        day_key = f"dqa:rate:d:{user_id}:{today}"
        day_count = await self.redis.incr(day_key)
        if day_count == 1:
            await self.redis.expire(day_key, 86400)
        if day_count > limits['per_day']:
            return False
        
        return True

## 16. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 意图分类错误 | 返回错误数据 | 双层分类+置信度阈值+回答附数据来源 |
| SQL注入 | 数据泄露 | 参数化查询+白名单表/字段+ORM层 |
| LLM生成错误查询 | 返回错误数据 | DSL Schema校验+执行前SQL审查+结果合理性检查 |
| LLM调用成本高 | 运营成本 | 模板优先(命中后不走LLM)+缓存+每日预算限制 |
| 隐私泄露 | 合规风险 | 行级权限隔离+字段脱敏+审计日志 |
| 用户期望过高 | 体验问题 | 引导提示+Fallback友好回复+建议查看详细报告 |
