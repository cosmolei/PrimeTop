# 大模型推理请求队列调度与高峰期用户体验保障引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 教育平台 AI 能力层的核心调度中间件，负责在多模型、多用户、多优先级的复杂场景下，对大模型推理请求进行统一的队列管理、智能调度和高峰期流量治理，保障高峰时段（如晚间作业高峰、考前冲刺期、寒暑假学习营）的系统稳定性和用户体验。

### 1.2 设计目标

| 目标 | 指标 |
| --- | --- |
| 请求排队感知延迟 | 用户感知排队位置更新 ≤ 500ms |
| 高峰期请求吞吐量 | 支持 10,000+ 并发推理请求 |
| 请求丢弃率 | 高峰期 ≤ 0.1%（P0 用户）/ ≤ 2%（免费用户） |
| 排队超时自动降级 | 排队 > 30s 自动触发降级策略 |
| 模型资源利用率 | GPU 利用率 ≥ 75%，无资源饥饿 |

### 1.3 适用范围

- AI 智能辅导对话（文字问答、语音提问）
- 拍照搜题解析生成
- 作文批改与评分
- 文科背诵检测与纠错
- AI 题目生成与变式推荐
- RAG 检索增强生成
- 所有依赖大模型推理的服务端能力

### 1.4 与已有模块的边界

| 已有模块 | 关注点 | 本引擎关注点 |
| --- | --- | --- |
| 多模型调度与成本治理 | 选择哪个模型、成本控制 | 请求如何排队、何时执行、用户体验 |
| AI 模型调用多供应商容灾切换 | 供应商故障切换 | 正常运营时的请求排队与调度 |
| 大模型推理流式输出全链路保障 | 流式数据传输与断线恢复 | 请求进入模型前的调度决策 |
| 统一限流熔断与流量防护体系 | 服务级流量过载保护 | AI 推理资源的精细化调度分配 |
| 用户额度管控与功能门控 | 用户是否有权调用 | 有权调用后的排队与资源分配 |

### 3.2 模型池定义

```python
@dataclass
class ModelSpec:
    """模型规格"""
    provider: str               # 供应商: openai/anthropic/zhipu/qwen/self-hosted
    model_name: str             # 模型名称
    model_tier: str             # 模型层级: flagship/standard/economy
    capabilities: list[str]     # 能力标签: [text, vision, code, math]
    max_context: int            # 最大上下文长度
    avg_latency_ms: int         # 平均推理延迟
    cost_per_1k_tokens: float   # 每1K Token成本
    preferred: bool = False     # 是否为首选


@dataclass
class ModelPool:
    """模型池"""
    pool_id: str                       # 池ID
    spec: ModelSpec                    # 模型规格
    capacity: int                      # 最大并发数
    current_load: int = 0              # 当前负载
    reserved_capacity: int = 0         # 预留容量（为高优先级请求保留）
    health_status: str = "healthy"     # healthy/degraded/unhealthy
    avg_queue_time_ms: int = 0         # 平均排队时间
    avg_execution_time_ms: int = 0     # 平均执行时间
    error_rate: float = 0.0            # 错误率
    last_updated: float = field(default_factory=time.time)
    
    @property
    def available_capacity(self) -> int:
        """可用并发数"""
        return max(0, self.capacity - self.current_load - self.reserved_capacity)
    
    @property
    def utilization_rate(self) -> float:
        """利用率"""
        if self.capacity == 0:
            return 0.0
        return self.current_load / self.capacity


@dataclass
class ModelPoolGroup:
    """模型池组（按能力分组）"""
    group_id: str                     # 组ID: reasoning/general/multimodal
    pools: list[ModelPool]            # 组内的模型池列表
    fallback_pool_id: str = ""        # 降级时使用的备选池
    
    def select_pool(self, request: 'InferenceRequest') -> Optional[ModelPool]:
        """选择最佳模型池"""
        healthy_pools = [p for p in self.pools if p.health_status == "healthy"]
        if not healthy_pools:
            healthy_pools = [p for p in self.pools if p.health_status != "unhealthy"]
        
        # 按优先级排序：可用容量 > 利用率 > 延迟
        sorted_pools = sorted(
            healthy_pools,
            key=lambda p: (
                -p.available_capacity,
                p.utilization_rate,
                p.avg_execution_time_ms
            )
        )
        
        for pool in sorted_pools:
            if pool.available_capacity > 0:
                return pool
        return None
```

### 3.3 队列项结构

```python
@dataclass
class QueueItem:
    """队列项"""
    request: InferenceRequest
    priority: PriorityLevel
    enqueue_time: float = field(default_factory=time.time)
    weight: float = 1.0                # 调度权重（影响出队顺序）
    skip_count: int = 0                # 跳过次数（被更高优先级插队）
    estimated_wait_ms: int = 0         # 预估等待时间
    
    def __lt__(self, other: 'QueueItem') -> bool:
        """优先队列比较：优先级 > 权重 > 等待时间"""
        if self.priority != other.priority:
            return self.priority < other.priority  # 数字越小优先级越高
        
        # 同优先级内，考虑权重和老化因子
        self_score = self.weight + self._aging_factor()
        other_score = other.weight + other._aging_factor()
        return self_score < other_score
    
    def _aging_factor(self) -> float:
        """老化因子：等待越久优先级越高，防止饥饿"""
        waited_seconds = time.time() - self.enqueue_time
        return min(waited_seconds * 0.01, 2.0)  # 最大加成 2.0
```

### 4.2 请求接入流程

```python
class InferenceRequestGateway:
    """推理请求网关"""
    
    def __init__(self, scheduler_core: 'InferenceSchedulerCore',
                 quota_service: 'QuotaService',
                 dedup_cache: 'DedupCache'):
        self.scheduler = scheduler_core
        self.quota = quota_service
        self.dedup = dedup_cache
    
    async def submit(self, request: InferenceRequest) -> 'GatewayResponse':
        """提交推理请求"""
        # 1. 请求验证
        if not self._validate_request(request):
            return GatewayResponse(
                success=False, 
                error_code="INVALID_REQUEST",
                message="请求参数无效"
            )
        
        # 2. 设置截止时间
        request.deadline = time.time() + (request.timeout_ms / 1000.0)
        
        # 3. 请求指纹去重检查
        if request.fingerprint:
            cached = await self.dedup.check(request.fingerprint)
            if cached:
                # 命中去重，返回已有请求的引用
                return GatewayResponse(
                    success=True,
                    request_id=cached.request_id,
                    status=cached.status,
                    is_duplicate=True,
                    message="已存在相同请求，正在处理中"
                )
        
        # 4. 用户配额检查
        quota_result = await self.quota.check_and_consume(
            user_id=request.user_id,
            user_tier=request.user_tier,
            request_type=request.request_type
        )
        if not quota_result.allowed:
            return GatewayResponse(
                success=False,
                error_code="QUOTA_EXCEEDED",
                message=f"今日调用次数已用完，{quota_result.reset_message}"
            )
        
        # 5. 动态优先级计算
        request.priority = self._calculate_priority(request)
        
        # 6. 确定目标模型池组
        pool_group = self._resolve_pool_group(request)
        if not pool_group:
            return GatewayResponse(
                success=False,
                error_code="NO_AVAILABLE_MODEL",
                message="暂无可用的AI模型，请稍后重试"
            )
        
        # 7. 提交到调度核心
        await self.scheduler.enqueue(request, pool_group)
        
        # 8. 记录去重指纹
        if request.fingerprint:
            await self.dedup.set(
                request.fingerprint, 
                request.request_id,
                ttl=300  # 5分钟去重窗口
            )
        
        # 9. 返回排队信息
        estimated_wait = await self.scheduler.estimate_wait_time(request)
        
        return GatewayResponse(
            success=True,
            request_id=request.request_id,
            status=RequestStatus.QUEUING,
            estimated_wait_ms=estimated_wait,
            queue_position=await self.scheduler.get_queue_position(request),
            message="请求已加入队列" if estimated_wait > 2000 else "正在处理中"
        )
    
    def _calculate_priority(self, request: InferenceRequest) -> PriorityLevel:
        """动态优先级计算"""
        score = 0
        
        # 用户层级加权
        tier_weights = {
            "vip": -2, "family": -1, "premium": 0, "free": 1
        }
        score += tier_weights.get(request.user_tier, 1)
        
        # 请求类型加权
        type_weights = {
            RequestType.PHOTO_SOLUTION: -1,    # 拍题优先（用户在等待）
            RequestType.AI_TUTORING: 0,         # 对话正常
            RequestType.ESSAY_GRADING: 0,       # 作文正常
            RequestType.QUESTION_GENERATION: 1, # 生成类可延后
            RequestType.CONTENT_SUMMARY: 2,     # 摘要可延后
        }
        score += type_weights.get(request.request_type, 0)
        
        # 场景加权：考试模式/课堂模式优先
        if request.scene in ("exam_practice", "in_class", "homework_urgent"):
            score -= 1
        
        # 转换为优先级等级
        if score <= -2:
            return PriorityLevel.P0_CRITICAL
        elif score <= 0:
            return PriorityLevel.P1_HIGH
        elif score <= 2:
            return PriorityLevel.P2_NORMAL
        else:
            return PriorityLevel.P3_LOW
    
    def _resolve_pool_group(self, request: InferenceRequest) -> Optional[ModelPoolGroup]:
        """确定模型池组"""
        # 根据请求类型和能力需求选择池组
        needs_vision = request.request_type == RequestType.PHOTO_SOLUTION
        needs_reasoning = request.request_type in (
            RequestType.PHOTO_SOLUTION,
            RequestType.AI_TUTORING
        ) and request.metadata.get("complexity") == "high"
        
        if needs_vision:
            return self.scheduler.get_pool_group("multimodal")
        elif needs_reasoning:
            return self.scheduler.get_pool_group("reasoning")
        else:
            return self.scheduler.get_pool_group("general")
    
    def _validate_request(self, request: InferenceRequest) -> bool:
        """请求基本验证"""
        if not request.request_id or not request.user_id:
            return False
        if request.max_tokens <= 0 or request.max_tokens > 8192:
            return False
        if request.timeout_ms < 5000 or request.timeout_ms > 120000:
            return False
        return True
```

```python
import asyncio
import heapq
from collections import defaultdict
from typing import Callable, Awaitable


class PriorityQueueManager:
    """多级优先队列管理器"""
    
    def __init__(self):
        # 四级优先队列
        self._queues: dict[PriorityLevel, list[QueueItem]] = {
            PriorityLevel.P0_CRITICAL: [],
            PriorityLevel.P1_HIGH: [],
            PriorityLevel.P2_NORMAL: [],
            PriorityLevel.P3_LOW: [],
        }
        self._lock = asyncio.Lock()
        self._item_count = 0
        self._enqueue_callbacks: list[Callable] = []
        self._dequeue_callbacks: list[Callable] = []
    
    async def enqueue(self, item: QueueItem) -> int:
        """入队"""
        async with self._lock:
            heapq.heappush(self._queues[item.priority], item)
            self._item_count += 1
            
            # 触发回调
            for cb in self._enqueue_callbacks:
                await cb(item)
            
            # 返回当前队列位置
            position = self._calculate_position(item)
            return position
    
    async def dequeue(self, max_priority: PriorityLevel = PriorityLevel.P3_LOW) -> Optional[QueueItem]:
        """
        出队：从最高优先级队列开始取
        max_priority: 限制出队的最低优先级
        """
        async with self._lock:
            for priority in PriorityLevel:
                if priority > max_priority:
                    break
                
                queue = self._queues[priority]
                if queue:
                    item = heapq.heappop(queue)
                    self._item_count -= 1
                    
                    for cb in self._dequeue_callbacks:
                        await cb(item)
                    
                    return item
            return None
    
    async def dequeue_batch(self, count: int, 
                            max_priority: PriorityLevel = PriorityLevel.P3_LOW) -> list[QueueItem]:
        """批量出队"""
        items = []
        for _ in range(count):
            item = await self.dequeue(max_priority)
            if item is None:
                break
            items.append(item)
        return items
    
    async def cancel(self, request_id: str) -> bool:
        """取消队列中的请求"""
        async with self._lock:
            for queue in self._queues.values():
                for i, item in enumerate(queue):
                    if item.request.request_id == request_id:
                        queue.pop(i)
                        heapq.heapify(queue)
                        self._item_count -= 1
                        return True
            return False
    
    def _calculate_position(self, item: QueueItem) -> int:
        """计算请求在队列中的总位置"""
        position = 1
        for priority in PriorityLevel:
            if priority < item.priority:
                position += len(self._queues[priority])
            elif priority == item.priority:
                # 同优先级内的位置
                for q_item in self._queues[priority]:
                    if q_item.enqueue_time < item.enqueue_time:
                        position += 1
                break
        return position
    
    @property
    def total_count(self) -> int:
        return self._item_count
    
    def get_queue_depths(self) -> dict[PriorityLevel, int]:
        """获取各级队列深度"""
        return {p: len(q) for p, q in self._queues.items()}


class QueueDispatcher:
    """出队分发器"""
    
    def __init__(self, queue_manager: PriorityQueueManager,
                 pool_registry: 'ModelPoolRegistry',
                 degradation_manager: 'DegradationManager',
                 monitor: 'QueueMonitor'):
        self.queue = queue_manager
        self.pools = pool_registry
        self.degradation = degradation_manager
        self.monitor = monitor
        self._running = False
        self._dispatch_task: Optional[asyncio.Task] = None
    
    async def start(self):
        """启动分发器"""
        self._running = True
        self._dispatch_task = asyncio.create_task(self._dispatch_loop())
    
    async def stop(self):
        """停止分发器"""
        self._running = False
        if self._dispatch_task:
            self._dispatch_task.cancel()
            try:
                await self._dispatch_task
            except asyncio.CancelledError:
                pass
    
    async def _dispatch_loop(self):
        """主分发循环"""
        while self._running:
            try:
                # 获取所有可用的模型池
                available_pools = self.pools.get_available_pools()
                
                if not available_pools:
                    await asyncio.sleep(0.1)  # 无可用池，短暂等待
                    continue
                
                # 计算当前总可用容量
                total_capacity = sum(p.available_capacity for p in available_pools)
                
                if total_capacity <= 0:
                    # 所有池满载，检查是否需要降级
                    await self._handle_capacity_exhausted()
                    await asyncio.sleep(0.05)
                    continue
                
                # 高峰期模式：限制低优先级出队
                max_priority = await self._get_peak_priority_limit()
                
                # 批量出队
                batch_size = min(total_capacity, 10)  # 每轮最多分发10个
                items = await self.queue.dequeue_batch(batch_size, max_priority)
                
                for item in items:
                    await self._dispatch_to_pool(item, available_pools)
                
                if not items:
                    await asyncio.sleep(0.02)  # 队列空，短暂等待
                    
            except Exception as e:
                # 记录异常，继续运行
                await self.monitor.record_dispatch_error(str(e))
                await asyncio.sleep(0.5)
    
    async def _dispatch_to_pool(self, item: QueueItem, pools: list[ModelPool]):
        """分发请求到具体模型池"""
        request = item.request
        
        # 检查请求是否已超时
        if time.time() > request.deadline:
            await self.degradation.handle_timeout(item)
            return
        
        # 选择最优模型池
        best_pool = None
        for pool in pools:
            if pool.available_capacity > 0 and self._can_serve(pool, request):
                best_pool = pool
                break
        
        if not best_pool:
            # 没有可用池，检查是否需要降级
            should_degrade = await self.degradation.should_degrade(item)
            if should_degrade:
                await self.degradation.apply_degradation(item)
            else:
                # 重新入队
                item.skip_count += 1
                if item.skip_count > 3:
                    await self.degradation.handle_timeout(item)
                else:
                    await self.queue.enqueue(item)
            return
        
        # 分发到模型池执行
        best_pool.current_load += 1
        request.status = RequestStatus.DISPATCHED
        request.dispatched_at = time.time()
        
        # 异步执行推理
        asyncio.create_task(self._execute_inference(item, best_pool))
    
    async def _execute_inference(self, item: QueueItem, pool: ModelPool):
        """执行推理（委托给模型池）"""
        request = item.request
        try:
            request.status = RequestStatus.EXECUTING
            # 实际推理调用由模型适配层完成
            result = await self.pools.execute(pool.pool_id, request)
            request.status = RequestStatus.COMPLETED
            request.completed_at = time.time()
            
            # 更新池统计
            pool.current_load = max(0, pool.current_load - 1)
            pool.avg_execution_time_ms = int(
                0.8 * pool.avg_execution_time_ms +
                0.2 * ((request.completed_at - request.dispatched_at) * 1000)
            )
            
            await self.monitor.record_completion(item)
            
        except Exception as e:
            pool.current_load = max(0, pool.current_load - 1)
            pool.error_rate = min(1.0, pool.error_rate + 0.01)
            await self.monitor.record_error(item, str(e))
    
    def _can_serve(self, pool: ModelPool, request: InferenceRequest) -> bool:
        """检查模型池是否可以服务该请求"""
        if pool.health_status == "unhealthy":
            return False
        # 检查能力匹配
        # 实际实现中会检查更细粒度的能力标签
        return True
    
    async def _get_peak_priority_limit(self) -> PriorityLevel:
        """获取高峰期优先级限制"""
        peak_manager = PeakPeriodManager.get_instance()
        if peak_manager.is_peak_now():
            config = peak_manager.get_current_config()
            # 高峰期限制低优先级请求
            if config.get("low_priority_ratio", 0.1) < 0.05:
                return PriorityLevel.P1_HIGH
        return PriorityLevel.P3_LOW
    
    async def _handle_capacity_exhausted(self):
        """所有容量耗尽时的处理"""
        queue_depths = self.queue.get_queue_depths()
        total = sum(queue_depths.values())
        
        if total > 100:
            # 队列积压严重，触发全局降级
            await self.degradation.trigger_global_degradation(
                reason="CAPACITY_EXHAUSTED",
                affected_count=total
            )
```

```python
class DegradationManager:
    """降级管理器"""
    
    def __init__(self, cache_store: 'CacheStore',
                 model_registry: 'ModelPoolRegistry',
                 notifier: 'UserExperienceNotifier'):
        self.cache = cache_store
        self.models = model_registry
        self.notifier = notifier
        self._degradation_stats = defaultdict(int)
    
    async def should_degrade(self, item: QueueItem) -> bool:
        """判断是否应该降级"""
        request = item.request
        waited_ms = (time.time() - item.enqueue_time) * 1000
        
        # 获取降级阈值配置
        threshold_ms = await self._get_degradation_threshold(request)
        
        return waited_ms > threshold_ms
    
    async def apply_degradation(self, item: QueueItem):
        """应用降级策略"""
        request = item.request
        waited_ms = int((time.time() - item.enqueue_time) * 1000)
        
        # 按优先级选择降级策略
        if request.priority <= PriorityLevel.P1_HIGH:
            # 高优先级请求：降级到更小但可用的模型
            await self._degrade_to_smaller_model(item)
        elif request.priority == PriorityLevel.P2_NORMAL:
            # 普通请求：尝试缓存或模板
            cached = await self._try_cache_response(item)
            if cached:
                await self._complete_from_cache(item, cached)
            else:
                await self._degrade_to_smaller_model(item)
        else:
            # 低优先级请求：转异步或拒绝
            await self._convert_to_async(item)
    
    async def handle_timeout(self, item: QueueItem):
        """处理超时请求"""
        request = item.request
        request.status = RequestStatus.TIMEOUT
        
        # 尝试缓存降级
        cached = await self._try_cache_response(item)
        if cached:
            await self._complete_from_cache(item, cached)
            return
        
        # 尝试模板回复
        template = await self._get_template_response(request)
        if template:
            request.status = RequestStatus.DEGRADED
            request.degradation = DegradationStrategy.USE_TEMPLATE_RESPONSE
            await self.notifier.notify_degradation(
                request, 
                message="当前排队人数较多，已为您生成简化回复，完整回复稍后送达"
            )
            self._degradation_stats["template_response"] += 1
            return
        
        # 无法降级，通知用户重试
        await self.notifier.notify_timeout(request)
        self._degradation_stats["timeout"] += 1
    
    async def trigger_global_degradation(self, reason: str, affected_count: int):
        """全局降级：系统严重过载时触发"""
        # 1. 暂停 P3 低优先级请求出队
        # 2. 对所有 P2 请求启用缓存优先
        # 3. 扩大模型池容量（调用弹性伸缩）
        # 4. 通知运营和运维团队
        
        await self.notifier.broadcast_system_degradation(
            message="系统当前负载较高，部分功能响应可能变慢"
        )
        
        # 记录降级事件用于后续分析
        await self._record_global_degradation(reason, affected_count)
    
    async def _degrade_to_smaller_model(self, item: QueueItem):
        """降级到更小的模型"""
        request = item.request
        original_model = request.model_spec.model_name
        
        # 查找同类型的更小模型
        smaller_model = await self.models.find_smaller_alternative(
            request.model_spec,
            required_capabilities=request.model_spec.capabilities
        )
        
        if smaller_model:
            request.original_model = original_model
            request.model_spec = smaller_model
            request.degradation = DegradationStrategy.USE_SMALLER_MODEL
            request.priority = min(request.priority, PriorityLevel.P1_HIGH)  # 提升优先级补偿
            
            # 通知用户
            await self.notifier.notify_degradation(
                request,
                message="当前AI模型较忙，已切换到快速模式为您解答"
            )
            
            # 重新入队
            await self.models.get_scheduler().enqueue(
                item, 
                self.models.get_pool_group_for(smaller_model)
            )
            self._degradation_stats["smaller_model"] += 1
        else:
            # 无更小模型可用，转异步
            await self._convert_to_async(item)
    
    async def _try_cache_response(self, item: QueueItem) -> Optional[dict]:
        """尝试从缓存获取相似结果"""
        request = item.request
        if not request.fingerprint:
            return None
        
        cached = await self.cache.get(f"inference:result:{request.fingerprint}")
        if cached and cached.get("quality_score", 0) > 0.7:
            return cached
        return None
    
    async def _complete_from_cache(self, item: QueueItem, cached: dict):
        """使用缓存结果完成请求"""
        request = item.request
        request.status = RequestStatus.DEGRADED
        request.degradation = DegradationStrategy.USE_CACHE
        
        await self.notifier.notify_cache_hit(
            request,
            message="已为您找到相同问题的解答"
        )
        self._degradation_stats["cache"] += 1
    
    async def _convert_to_async(self, item: QueueItem):
        """转为异步处理"""
        request = item.request
        request.status = RequestStatus.DEGRADED
        request.degradation = DegradationStrategy.ASYNC_PROCESSING
        
        await self.notifier.notify_async_processing(
            request,
            message="当前排队人数较多，您的请求将在稍后处理完成并通知您"
        )
        
        # 写入异步处理队列
        await self.cache.lpush(
            "inference:async_queue",
            {"request_id": request.request_id, "payload": request.prompt_payload}
        )
        self._degradation_stats["async"] += 1
    
    async def _get_template_response(self, request: InferenceRequest) -> Optional[dict]:
        """获取模板回复"""
        templates = {
            RequestType.AI_TUTORING: {
                "content": "这个问题很好！让我先给您一个思路方向：请先回顾相关知识点，然后尝试分解问题。详细解答正在生成中，请稍候。",
                "quality_score": 0.3
            },
            RequestType.PHOTO_SOLUTION: {
                "content": "题目已识别，正在生成详细解析步骤，请稍候片刻。",
                "quality_score": 0.2
            }
        }
        return templates.get(request.request_type)
    
    async def _get_degradation_threshold(self, request: InferenceRequest) -> int:
        """获取降级阈值"""
        # 基础阈值
        base_threshold = 15000  # 15秒
        
        # 用户层级调整
        tier_multipliers = {
            "vip": 2.0,      # VIP用户更晚降级
            "family": 1.5,
            "premium": 1.2,
            "free": 1.0
        }
        multiplier = tier_multipliers.get(request.user_tier, 1.0)
        
        # 高峰期调整
        peak_manager = PeakPeriodManager.get_instance()
        if peak_manager.is_peak_now():
            multiplier *= 0.8  # 高峰期更早降级
        
        return int(base_threshold * multiplier)
    
    def get_stats(self) -> dict:
        """获取降级统计"""
        return dict(self._degradation_stats)
```

```python
class PeakPeriodManager:
    """高峰期管理器（单例）"""
    
    _instance: Optional['PeakPeriodManager'] = None
    
    def __init__(self):
        self._rules: list[PeakPeriodRule] = []
        self._current_peak: Optional[PeakPeriodRule] = None
        self._last_check: float = 0
    
    @classmethod
    def get_instance(cls) -> 'PeakPeriodManager':
        if cls._instance is None:
            cls._instance = cls()
        return cls._instance
    
    def load_rules(self, rules: list['PeakPeriodRule']):
        """加载高峰期规则"""
        self._rules = [r for r in rules if r.status == "active"]
    
    def is_peak_now(self) -> bool:
        """当前是否处于高峰期"""
        now = time.localtime()
        current_time = now.tm_hour * 3600 + now.tm_min * 60 + now.tm_sec
        weekday = str(now.tm_wday + 1)  # 1=周一
        
        for rule in self._rules:
            if weekday not in rule.weekdays.split(","):
                continue
            
            if rule.rule_type == "daily":
                # 每日高峰（如晚间作业时间 19:00-22:00）
                start_sec = self._time_to_seconds(rule.start_time)
                end_sec = self._time_to_seconds(rule.end_time)
                if start_sec <= current_time <= end_sec:
                    self._current_peak = rule
                    return True
            
            elif rule.rule_type == "seasonal":
                # 季节性高峰（如期中考试周、中考冲刺月）
                today = time.strftime("%Y-%m-%d")
                if rule.start_date <= today <= rule.end_date:
                    self._current_peak = rule
                    return True
        
        self._current_peak = None
        return False
    
    def get_current_config(self) -> dict:
        """获取当前高峰期配置"""
        if not self._current_peak:
            return {}
        return {
            "rule_name": self._current_peak.rule_name,
            "free_user_ratio": self._current_peak.free_user_ratio,
            "low_priority_ratio": self._current_peak.low_priority_ratio,
            "max_queue_wait_ms": self._current_peak.max_queue_wait_ms,
            "reserved_capacity_pct": self._current_peak.reserved_capacity_pct,
            "degradation_threshold_ms": self._current_peak.degradation_threshold_ms,
        }
    
    @staticmethod
    def _time_to_seconds(t) -> int:
        """time 对象转秒数"""
        return t.hour * 3600 + t.minute * 60 + t.second
```

```python
class CapacityReservationManager:
    """容量预留管理器"""
    
    def __init__(self, pool_registry: 'ModelPoolRegistry'):
        self.pools = pool_registry
        self._reservation_rules = {
            # 为付费用户预留的容量百分比
            "premium_reserved_pct": 0.30,    # 30% 容量预留给会员
            "peak_premium_reserved_pct": 0.50,  # 高峰期 50% 预留
            # 紧急请求预留
            "emergency_reserved_pct": 0.05,  # 5% 容量留给 P0 紧急请求
        }
    
    async def apply_reservations(self, pool: ModelPool):
        """应用预留规则"""
        is_peak = PeakPeriodManager.get_instance().is_peak_now()
        
        premium_pct = (
            self._reservation_rules["peak_premium_reserved_pct"] 
            if is_peak 
            else self._reservation_rules["premium_reserved_pct"]
        )
        emergency_pct = self._reservation_rules["emergency_reserved_pct"]
        
        pool.reserved_capacity = int(pool.capacity * (premium_pct + emergency_pct))
    
    async def can_admit(self, pool: ModelPool, request: InferenceRequest) -> bool:
        """检查是否可以准入"""
        is_premium = request.user_tier in ("premium", "family", "vip")
        is_emergency = request.priority == PriorityLevel.P0_CRITICAL
        
        if is_emergency:
            # 紧急请求可以使用所有容量
            return pool.current_load < pool.capacity
        
        if is_premium:
            # 会员可以使用预留容量
            return pool.current_load < pool.capacity
        
        # 免费用户不能使用预留容量
        return pool.current_load < (pool.capacity - pool.reserved_capacity)
```

### 7.2 弹性伸缩集成

```python
class AutoScalerIntegration:
    """与弹性伸缩系统集成"""
    
    SCALE_UP_TRIGGERS = {
        "queue_depth_threshold": 50,       # 队列深度阈值
        "avg_wait_ms_threshold": 8000,     # 平均等待时间阈值
        "utilization_threshold": 0.90,     # 利用率阈值
        "consecutive_periods": 3,          # 连续触发次数
    }
    
    async def check_scale_needed(self, metrics: 'QueueMetrics') -> Optional[ScaleAction]:
        """检查是否需要伸缩"""
        # 检查是否连续 N 个周期超过阈值
        if (metrics.queue_depth > self.SCALE_UP_TRIGGERS["queue_depth_threshold"] and
            metrics.avg_wait_ms > self.SCALE_UP_TRIGGERS["avg_wait_ms_threshold"] and
            metrics.consecutive_high_periods >= self.SCALE_UP_TRIGGERS["consecutive_periods"]):
            
            return ScaleAction(
                action="scale_up",
                target_pool=metrics.pool_id,
                additional_capacity=self._calculate_scale_size(metrics),
                reason="QUEUE_PRESSURE"
            )
        
        # 缩容逻辑
        if (metrics.utilization < 0.3 and
            metrics.queue_depth < 5 and
            metrics.consecutive_low_periods >= 5):
            
            return ScaleAction(
                action="scale_down",
                target_pool=metrics.pool_id,
                reduce_capacity=self._calculate_scale_down_size(metrics),
                reason="UNDER_UTILIZED"
            )
        
        return None
    
    def _calculate_scale_size(self, metrics: 'QueueMetrics') -> int:
        """计算扩容数量"""
        # 基于当前队列深度和吞吐量计算需要的额外容量
        throughput_per_capacity = metrics.throughput_rps / max(metrics.capacity, 1)
        needed_capacity = int(metrics.queue_depth / max(throughput_per_capacity, 0.1) / 10)
        return min(max(needed_capacity, 5), 20)  # 每次扩容 5-20 个实例
```

```python
class RequestFingerprinter:
    """请求指纹生成器"""
    
    def generate(self, request: InferenceRequest) -> str:
        """生成请求指纹用于去重"""
        import hashlib
        import json
        
        # 提取关键信息（排除时间戳、请求ID等变量）
        key_components = {
            "type": request.request_type,
            "grade": request.metadata.get("grade", ""),
            "subject": request.metadata.get("subject", ""),
            "chapter": request.metadata.get("chapter_id", ""),
            "prompt_hash": self._hash_prompt(request.prompt_payload),
            "model": request.model_spec.model_name,
            "temperature": request.temperature,
        }
        
        serialized = json.dumps(key_components, sort_keys=True)
        return hashlib.sha256(serialized.encode()).hexdigest()[:32]
    
    def _hash_prompt(self, payload: dict) -> str:
        """对 Prompt 内容生成哈希"""
        import hashlib
        import json
        
        # 提取 messages 内容
        messages = payload.get("messages", [])
        content = "".join(m.get("content", "") for m in messages)
        
        # 标准化：去除多余空白
        normalized = " ".join(content.split())
        return hashlib.md5(normalized.encode()).hexdigest()
```

### 10.2 预估等待时间计算

```python
class WaitTimeEstimator:
    """等待时间估算器"""
    
    def __init__(self):
        self._recent_completions: list[float] = []  # 最近完成请求的处理时间
        self._throughput_samples: list[float] = []
    
    async def estimate(self, queue_manager: PriorityQueueManager,
                       pool_group: ModelPoolGroup,
                       item: QueueItem) -> int:
        """估算等待时间（毫秒）"""
        position = queue_manager._calculate_position(item)
        
        # 获取当前吞吐量
        throughput_rps = await self._get_current_throughput(pool_group)
        
        if throughput_rps <= 0:
            # 无吞吐量数据，使用模型平均延迟估算
            avg_latency_ms = self._get_avg_model_latency(pool_group)
            return position * avg_latency_ms
        
        # 基础估算：位置 / 吞吐量
        base_estimate_ms = int((position / throughput_rps) * 1000)
        
        # 高峰期调整
        if PeakPeriodManager.get_instance().is_peak_now():
            base_estimate_ms = int(base_estimate_ms * 1.3)
        
        # 加入保守缓冲
        base_estimate_ms = int(base_estimate_ms * 1.1)
        
        return min(base_estimate_ms, 60000)  # 最大 60 秒
```

| `REQUEST_CANCELLED` | 499 | 用户取消请求 | 正常行为 |
| `DEGRADATION_REJECTED` | 200 | 用户拒绝降级方案 | 继续排队等待 |
| `POOL_UNHEALTHY` | 503 | 目标模型池不健康 | 触发故障转移 |
| `FINGERPRINT_COLLISION` | 200 | 请求指纹碰撞 | 正常，返回已有请求引用 |

## 13. 安全与合规

1. **请求隔离**：不同用户的推理请求完全隔离，不允许跨用户访问结果。
2. **内容安全**：所有输入 Prompt 和输出结果经过内容安全过滤中间件处理。
3. **配额防刷**：基于用户+设备+IP 三维度的配额限制，防止单用户耗尽资源。
4. **审计日志**：所有降级决策、拒绝操作、全局降级事件记录完整审计日志。
5. **数据脱敏**：日志和监控指标中不记录 Prompt 明文内容，仅记录指纹哈希。
6. **优先级公平性审计**：定期审计优先级分配是否合理，避免付费墙导致的服务不可用。
