# 用户协议与法律文档管理服务 - 详细设计

> **版本**: v1.0 | **日期**: 2026-05-25 | **状态**: 初稿
> **关联文档**: 数据安全与隐私合规体系、用户账号体系、家长中心、权限管理与角色访问控制、客户端架构与前端框架、防沉迷与未成年人保护机制

---

## 1. 模块概述

### 1.1 功能定位

用户协议与法律文档管理服务负责管理 PrimeTop 产品中所有面向用户的法律文档（隐私政策、用户协议、儿童个人信息保护规则等），包括文档的版本管理、发布上线、用户同意记录追踪、强制更新机制和合规审计。本模块是产品合规运营的**基础设施层**，确保所有用户（特别是未成年人）在使用产品前完成必要的法律授权。

### 1.2 为什么需要这个模块

1. **法律合规要求**：《个人信息保护法》《儿童个人信息网络保护规定》《App违法违规收集使用个人信息行为认定方法》等法规要求 APP 在收集个人信息前获得用户（或监护人）同意
2. **未成年人保护**：14 周岁以下用户的个人信息处理需获得监护人同意，需要独立的同意管理机制
3. **版本更新管理**：隐私政策或用户协议更新时，需要告知用户并获取新版本同意
4. **审计追溯**：监管检查时需要提供完整的用户同意记录

### 1.3 文档类型清单

| 文档类型 | 枚举值 | 适用对象 | 是否必须同意 | 更新频率 |
|----------|--------|----------|-------------|----------|
| 用户服务协议 | `terms_of_service` | 全部用户 | 是 | 低（年均 1-2 次） |
| 隐私政策 | `privacy_policy` | 全部用户 | 是 | 中（季均 1-2 次） |
| 儿童个人信息保护规则 | `children_privacy` | <14 岁用户及其监护人 | 是 | 中 |
| 家长授权协议 | `parental_consent` | 监护人（绑定 <14 岁账号时） | 是 | 低 |
| 会员服务协议 | `membership_agreement` | 付费会员 | 是 | 低 |
| 第三方信息共享清单 | `third_party_sharing` | 全部用户 | 是（随隐私政策） | 中 |
| Cookie/SDK 声明 | `cookie_sdk_notice` | 全部用户 | 是（首次启动） | 低 |

### 1.4 目标指标

| 指标 | 目标值 |
|------|--------|
| 同意记录写入延迟 | ≤ 50ms |
| 文档加载延迟（CDN） | ≤ 200ms |
| 协议弹窗渲染时间 | ≤ 300ms |
| 合规审计报告生成 | ≤ 10s |
| 同意记录数据保留 | 账号存续期 + 注销后 3 年 |

    """文档变更类型"""
    MINOR = "minor"           # 小改动（措辞调整、错别字）→ 不强制重新同意

class ConsentAction(str, Enum):
    """同意动作"""
    ACCEPTED = "accepted"
    REJECTED = "rejected"
    WITHDRAWN = "withdrawn"

    """同意方式"""
    DIALOG_CLICK = "dialog_click"             # 弹窗点击同意
    SIGNUP_FLOW = "signup_flow"               # 注册流程中同意
    SETTINGS_PAGE = "settings_page"           # 设置页手动同意
    GUARDIAN_DELEGATE = "guardian_delegate"   # 监护人代为同意
    API_CONFIRM = "api_confirm"               # API 调用确认

    """同意场景"""

    LOGIN = "login"                 # 登录（有新协议时）

@dataclass
class LegalDocument:

    def requires_consent(self) -> bool:

### 3.3 用户同意状态模型

```python
@dataclass
class UserConsentState:
    """用户的法律文档同意状态"""
    user_id: int
    is_minor: bool                             # 是否 <14 岁
    has_guardian: bool                         # 是否有监护人绑定
    documents: Dict[LegalDocType, DocConsentStatus]

    @property
    def is_fully_compliant(self) -> bool:
        """是否所有必要文档都已同意"""
        required = self._get_required_docs()
        return all(
            self.documents.get(dt, DocConsentStatus()).is_accepted
            for dt in required
        )

    @property
    def blocking_docs(self) -> List[LegalDocType]:
        """需要立即同意的文档（阻断使用）"""
        return [
            dt for dt, status in self.documents.items()
            if status.needs_accept and status.is_blocking
        ]

    def _get_required_docs(self) -> List[LegalDocType]:
        """根据用户类型确定必须同意的文档"""
        required = [
            LegalDocType.TERMS_OF_SERVICE,
            LegalDocType.PRIVACY_POLICY,
        ]
        if self.is_minor:
            required.extend([
                LegalDocType.CHILDREN_PRIVACY,
            ])
        return required


@dataclass
class DocConsentStatus:
    """单个文档的同意状态"""
    doc_type: LegalDocType
    current_version: Optional[str]             # 当前生效版本
    accepted_version: Optional[str]            # 用户已同意版本
    is_accepted: bool                          # 是否已同意
    needs_accept: bool                         # 是否需要同意（版本更新等）
    is_blocking: bool                          # 是否阻断使用
    deadline: Optional[datetime]               # 同意截止时间
    pending_id: Optional[int]                  # pending_consent 记录 ID
```

## 4. 核心流程设计

### 4.1 注册流程中的同意收集

```
用户点击"注册"
    │
    ▼
[1] 检查注册必要文档列表
    ├── 用户服务协议 (terms_of_service)
    ├── 隐私政策 (privacy_policy)
    └── (若 <=14 岁) 儿童个人信息保护规则 (children_privacy)
    │
    ▼
[2] 获取各文档当前生效版本
    │
    ▼
[3] 渲染注册页 → 底部勾选框 "已阅读并同意《用户协议》《隐私政策》"
    │                                    (<=14岁额外勾选《儿童信息保护规则》)
    ▼
[4] 用户勾选 → 提交注册
    │
    ▼
[5] 后端批量写入 user_consent 记录
    ├── consent_method = signup_flow
    ├── scene = signup
    └── (<=14岁) 同时创建 pending_consent → 家长授权流程
    │
    ▼
[6] (<=14岁) 引导进入家长绑定流程
    ├── 家长扫码或输入手机号
    ├── 家长同意 parental_consent
    └── 写入 guardian_consent 记录
    │
    ▼
[7] 注册完成，进入 APP
```

### 4.2 APP 启动时的同意检查

```python
class ConsentCheckService:
    """APP 启动时的同意检查服务"""

    def __init__(
        self,
        doc_repo: LegalDocumentRepository,
        consent_repo: UserConsentRepository,
        pending_repo: PendingConsentRepository,
        audit_logger: ConsentAuditLogger,
    ):
        self._doc_repo = doc_repo
        self._consent_repo = consent_repo
        self._pending_repo = pending_repo
        self._audit = audit_logger

    async def check_on_launch(
        self,
        user_id: int,
        is_minor: bool,
        has_guardian: bool,
    ) -> ConsentCheckResult:
        """
        APP 启动时检查用户同意状态。
        
        Returns:
            ConsentCheckResult: 包含待同意文档列表和是否阻断使用
        """
        # Step 1: 确定用户需要同意的文档类型
        required_types = self._get_required_doc_types(is_minor, has_guardian)

        # Step 2: 获取各文档当前生效版本
        current_docs = await self._doc_repo.get_published_versions(required_types)

        # Step 3: 获取用户已有同意记录
        accepted_versions = await self._consent_repo.get_accepted_versions(
            user_id=user_id,
            doc_types=required_types,
        )

        # Step 4: 对比版本，确定需要更新的文档
        pending_items: List[PendingConsentItem] = []

        for doc_type, doc in current_docs.items():
            accepted_ver = accepted_versions.get(doc_type)

            if accepted_ver is None:
                # 从未同意 → 必须同意（阻断）
                pending_items.append(PendingConsentItem(
                    doc_type=doc_type,
                    doc_version=doc.version,
                    doc_id=doc.id,
                    priority=1,
                    block_access=True,
                    deadline=None,
                    reason="never_accepted",
                ))

            elif self._version_lt(accepted_ver, doc.version):
                # 版本低于当前版本
                if doc.is_major_change and doc.force_accept_before:
                    # 重大变更 → 阻断使用
                    pending_items.append(PendingConsentItem(
                        doc_type=doc_type,
                        doc_version=doc.version,
                        doc_id=doc.id,
                        priority=1,
                        block_access=True,
                        deadline=doc.force_accept_before,
                        reason="major_update",
                    ))
                elif doc.is_major_change:
                    # 重大变更但无强制截止日 → 高优先级提醒
                    pending_items.append(PendingConsentItem(
                        doc_type=doc_type,
                        doc_version=doc.version,
                        doc_id=doc.id,
                        priority=2,
                        block_access=False,
                        deadline=doc.effective_date + timedelta(days=30),
                        reason="major_update",
                    ))
                else:
                    # minor 改动 → 不强制，记录即可
                    await self._consent_repo.auto_accept_minor(
                        user_id=user_id,
                        doc_type=doc_type,
                        doc_version=doc.version,
                        doc_id=doc.id,
                    )

        # Step 5: 未成年人监护人同意检查
        if is_minor and not has_guardian:
            pending_items.append(PendingConsentItem(
                doc_type=LegalDocType.PARENTAL_CONSENT,
                doc_version="n/a",
                doc_id=0,
                priority=1,
                block_access=True,
                deadline=None,
                reason="no_guardian",
            ))

        # Step 6: 写入待同意队列
        for item in pending_items:
            await self._pending_repo.upsert(
                user_id=user_id,
                item=item,
            )

        # Step 7: 返回检查结果
        has_blocking = any(item.block_access for item in pending_items)

        result = ConsentCheckResult(
            user_id=user_id,
            is_compliant=not has_blocking,
            pending_items=pending_items,
            has_blocking=has_blocking,
        )

        # Step 8: 审计日志
        await self._audit.log(
            action="consent_check_on_launch",
            actor_id=user_id,
            actor_type="user",
            target_user_id=user_id,
            detail={
                "pending_count": len(pending_items),
                "has_blocking": has_blocking,
                "pending_types": [item.doc_type for item in pending_items],
            },
        )

        return result

    def _get_required_doc_types(
        self, is_minor: bool, has_guardian: bool
    ) -> List[LegalDocType]:
        """确定用户必须同意的文档类型"""
        types = [
            LegalDocType.TERMS_OF_SERVICE,
            LegalDocType.PRIVACY_POLICY,
        ]
        if is_minor:
            types.append(LegalDocType.CHILDREN_PRIVACY)
        return types

    @staticmethod
    def _version_lt(v1: str, v2: str) -> bool:
        """比较语义版本号 v1 < v2"""
        parts1 = [int(p) for p in v1.split('.')]
        parts2 = [int(p) for p in v2.split('.')]
        return parts1 < parts2


@dataclass
class ConsentCheckResult:
    """同意检查结果"""
    user_id: int
    is_compliant: bool                        # 是否合规（无阻断项）
    pending_items: List[PendingConsentItem]    # 待同意列表
    has_blocking: bool                        # 是否有阻断项


@dataclass
class PendingConsentItem:
    """待同意项"""
    doc_type: LegalDocType
    doc_version: str
    doc_id: int
    priority: int                             # 1=最高(阻断), 5=最低
    block_access: bool
    deadline: Optional[datetime]
    reason: str                               # never_accepted/major_update/no_guardian
```

        consent_method: ConsentMethod,
        scene: ConsentScene,
        client_info: ClientInfo,
    ) -> ConsentAcceptResult:
        """
        用户同意某个文档版本。
        
        流程：
        1. 校验文档版本是否存在且有效
        2. 创建同意快照（截屏/记录页面状态）
        3. 写入 user_consent 记录
        4. 更新 pending_consent 状态
        5. 写入审计日志
        6. 返回同意结果
        """
        # Step 1: 校验文档版本
        doc = await self._doc_repo.get_by_type_version(doc_type, doc_version)
        if not doc or doc.status != 'published':
            raise InvalidDocumentVersionError(
                f"文档 {doc_type} 版本 {doc_version} 不存在或未发布"
            )

        # Step 2: 创建同意快照
        snapshot_url = await self._snapshot.capture(
            user_id=user_id,
            doc_type=doc_type,
            doc_version=doc_version,
            client_info=client_info,
        )

        # Step 3: 写入同意记录
        consent_id = await self._consent_repo.create(
            user_id=user_id,
            doc_type=doc_type,
            doc_version=doc_version,
            doc_id=doc.id,
            consent_action=ConsentAction.ACCEPTED,
            consent_method=consent_method,
            scene=scene,
            client_platform=client_info.platform,
            client_version=client_info.app_version,
            device_id=client_info.device_id,
            ip_address=client_info.ip_address,
            user_agent=client_info.user_agent,
            snapshot_url=snapshot_url,
        )

        # Step 4: 更新待同意队列
        await self._pending_repo.mark_accepted(
            user_id=user_id,
            doc_type=doc_type,
            doc_version=doc_version,
        )

        # Step 5: 审计日志
        await self._audit.log(
            action="consent_accepted",
            actor_id=user_id,
            actor_type="user",
            target_user_id=user_id,
            doc_type=doc_type,
            doc_version=doc_version,
            detail={
                "consent_id": consent_id,
                "method": consent_method,
                "scene": scene,
                "has_snapshot": bool(snapshot_url),
            },
            ip_address=client_info.ip_address,
        )

        return ConsentAcceptResult(
            consent_id=consent_id,
            doc_type=doc_type,
            doc_version=doc_version,
            accepted_at=datetime.utcnow(),
        )
