# 客户端-小学科学探究式学习页面架构与交互设计

> **模块定位**：本文档定义 PrimeTop Flutter 客户端**小学科学**（1-6 年级《科学》课）探究式学习功能的完整页面架构与交互设计，覆盖科学学习首页（四大领域入口）、知识领域树、概念详情、AI 探究式辅导（SSE 流式）、虚拟实验引导（含观察项目与素养报告）共十个页面单元。服务端权威为《服务端-小学科学探究式学习智能辅导与虚拟实验引导引擎》（API/状态机/判定/错误码 53100-53199）；本文只做客户端呈现层与交互层，**不重复定义服务端语义**，与服务器契约 1:1 对齐（§12）。
>
> **对应原设计**：《启硕-PrimeTop-全学段AI辅助学习软件项目设计文档》§5.2（小学阶段"科学基础知识"）、§6.4（同步课堂学习）、§9.6（分龄 UI 策略）、§12.1（完善学科知识点标签）。
>
> **缺口说明**：服务端引擎（2026-09-28 就绪）在 §12 明确声明"客户端科学学习入口尚无独立页面文档，列为后续批次"；本文即补齐该缺口。经全目录关键词扫描"科学/探究/观察"确认：既有客户端实验组件文档仅覆盖物理/化学/生物单科虚拟实验交互控件，无科学学科入口页、探究式辅导页、观察项目页与素养报告页。

## 1. 概述

### 1.1 模块定位

- 本文档是**科学学科客户端呈现层与交互层唯一权威**；服务端判定、素养证据计算、防沉迷钳制、幂等语义全部归服务端引擎文档。
- 学段范围：**仅小学 1-6 年级**。初中及以上学段进入物理/化学/生物学科工具链，不进入本模块（§6.4 G1 学段闸 fail-closed）。
- 模块内嵌一个简单电路搭建器（`circuit_builder`），其余 `component_render` 类型委托既有学科实验组件库渲染（§4.6.2 委托矩阵）。

### 1.2 设计原则

1. **探究优先，答案后置**：辅导页默认 `inquiry` 模式，先呈现 acknowledge/life_connection/inquiry_guide 段，concept_explanation 允许流式渐显但不允许整段一次性倾倒（§4.4.3 渐进呈现规则）。
2. **安全 fail-secure**：实验页 fail_safe 判定（短路等）必须红色阻断 + 语音提醒，任何降级路径不得绕过（服务端 G4，客户端镜像 §6.4 G6）。
3. **客户端不判定对错**：实验步骤对错唯一权威在服务端，客户端组件只采集 action payload，禁止本地答案库预判定（服务端 G3，客户端镜像 §6.4 G4）。
4. **会话可恢复**：53103 冲突响应携带活跃 sessionId，客户端必须恢复而非强制新建（服务端 G2，客户端镜像 §6.4 G3）。
5. **复用优先**：SSE 渲染复用《客户端-AI对话消息Markdown流式渲染引擎》；拍照上传复用《客户端多媒体选取与处理服务》；页面状态规范复用《客户端-页面状态模式与骨架屏加载空态错误态设计规范》；路由/深链接复用《客户端路由与深链接系统》。

### 1.3 职责边界（客户端不做）

| 不做 | 归属 |
| --- | --- |
| 实验步骤对错/安全判定 | 服务端 §4.5 判定器 |
| 素养维度得分计算与证据落库 | 服务端 §4.4 |
| 防沉迷时段校验与钳制 | 服务端（G6 fail-secure），客户端只展示 53114 话术 |
| 观察记录 AI 反馈生成 | 服务端（异步，客户端轮询/推送召回） |
| 领域树/概念内容数据生产 | 服务端知识库与内容生产管线 |

全部页面复用《客户端-页面状态模式与骨架屏加载空态错误态设计规范》：

## 3. 数据模型与 API 契约

### 3.1 Dart 数据模型（与服务端 §3.2 响应 1:1）

```dart
/// 辅导回答段类型, 与服务端"回答段类型说明"表 1:1
enum ScienceSegmentType {
  acknowledge,          // 认可与鼓励
  lifeConnection,       // 生活现象关联
  inquiryGuide,         // 探究引导提问
  conceptExplanation,   // 核心概念讲解(可带 visualAid)
  experimentSuggestion, // 实验建议(带 experimentId)
  extension,            // 拓展思考(带 relatedKnowledgePoints)
  safetyWarning,        // 安全提示(红色横幅级渲染)
  misconceptionCheck,   // 误解检测(纠偏气泡)
}

class ScienceSegment {
  final ScienceSegmentType type;
  final String content;
  final VisualAid? visualAid;              // concept_explanation 专属
  final String? experimentId;              // experiment_suggestion 专属
  final List<String>? relatedKnowledgePoints; // extension 专属

  factory ScienceSegment.fromJson(Map<String, dynamic> j) => ScienceSegment(
    type: _typeFromWire(j['type']),          // wire: snake_case 枚举
    content: j['content'] as String,
    visualAid: j['visualAid'] == null ? null : VisualAid.fromJson(j['visualAid']),
    experimentId: j['experimentId'] as String?,
    relatedKnowledgePoints: (j['relatedKnowledgePoints'] as List?)?.cast<String>(),
  );
}

/// 实验阶段交互类型, 与服务端 stages[].interactiveType 1:1
enum StageInteractiveType {
  componentRender,     // 渲染虚拟实验组件(componentConfig.type 二级路由)
  freeForm,            // 自由操作(操作采集后整段提交)
  observationForm,     // 观察记录表单(fields 服务端下发)
  reflectionQuestions, // 思考题(逐题作答, 不上判定)
  summaryCard,         // 总结卡片(summaryPoints 陈列 + 分享/重玩)
}

class ExperimentStage {
  final int stageIndex;
  final String title;
  final String guidance;
  final StageInteractiveType interactiveType;
  final Map<String, dynamic>? componentConfig; // componentRender 专属
  final String? successCondition;              // 仅展示用; 判定解释执行在服务端(权威边界 R5)
  final List<ObservationField>? fields;        // observationForm 专属
  final List<String>? questions;               // reflectionQuestions 专属
  final List<String>? summaryPoints;           // summaryCard 专属
}

class ObservationField {
  final String key;
  final String label;
  final String type; // text / number / select / photo
}

/// 步骤判定结果, 与服务端"判定结果枚举"1:1; 客户端禁本地产生该枚举(G4)
enum StepResult { success, partial, failSafe, fail }

class StepFeedback {
  final StepResult result;
  final int attemptNumber;
  final FeedbackPayload? feedback; // {type, content}
  final HintPayload? hint;         // 苏格拉底式提示(第 1-2 次 fail)
  final bool nextStageAvailable;
  final LiteracyEvidence? literacyEvidence; // success 时携带
}

class LiteracyReport {
  final String studentId;
  final String semester;
  final Map<String, double> dimensionScores; // scientific_inquiry / scientific_knowledge / scientific_thinking / attitude_responsibility
  final List<EvidenceItem> recentEvidence;
}
```

### 3.3 幂等键生成策略

| 场景 | 幂等键 | 生成规则 | 重试语义 |
| --- | --- | --- | --- |
| 实验步骤提交 | `(sessionId, stageIndex, clientRequestId)` | clientRequestId = 每次"提交动作"生成一个 UUIDv4（长按/双击/重试均复用同一动作 id） | 同键重试返回首次判定结果；同 stage 新键按 attemptNumber 递增（§4.6.4） |
| 观察记录提交 | 服务端 uk（projectId, obsDate）；客户端携带 clientRequestId | 以"日历日"为语义键：同日二次进入提交页预填上次内容，覆盖需二次确认（53115 弹确认） | 弱网重试复用同一 clientRequestId |
| 观察项目创建 | 客户端 3s 防抖 + 按钮 loading 禁用；服务端并行上限 3（53111） | 不生成幂等键，依赖防抖与服务端上限 | 超限引导完成或退出已有项目 |
| 辅导提问 | conversationId 续会话；重发问不生成幂等键（问答天然幂等） | conversationId 首问由服务端响应下发，追问原样回传 | 断线重连按 SSE offset 续传（§7.1） |

## 4. 页面详细设计

### 4.1 科学学习首页（/science/home）

**布局**（纵向滚动，小学 1-2 年级大卡片版式，§5 参数矩阵）：

1. **顶部问候条**："科学乐园"+ 当日领域推荐语（服务端首页推荐卡片接口或本地按星期轮转，非权威展示数据）。
2. **四大领域宫格**（2×2）：物质科学（蓝色 #3B82F6）、生命科学（绿色 #22C55E）、地球与宇宙（紫色 #8B5CF6）、技术与工程（橙色 #F97316）。每格：领域图标 + 名称 + 已学知识点计数（来自本地缓存的 literacy 摘要，TTL 24h，不阻断首屏）。
3. **继续实验卡**（条件渲染）：存在活跃会话（本地 SessionStore 或接口返回）时置顶展示实验名 + 当前 stage 进度条 + "继续"按钮 → `/science/experiment/:sessionId`（恢复路径，G3）。
4. **观察任务横滑条**：进行中项目（≤3）卡片：项目名称 + 第 N 天 + 今日是否已记录（本地日历标记，服务端数据为准）。
5. **双主按钮**："问科学"（→ /science/tutor，麦克风图标强调语音输入）、"做实验"（→ /science/experiments）。
6. **素养雷达入口**：小型四维度雷达缩略图（无数据时展示"完成一次实验点亮雷达"引导）→ /science/literacy。

**交互**：下拉刷新只刷新 3/4/6 区块；领域宫格点击 → `/science/tree?domain=`。

### 4.2 知识领域树页（/science/tree?domain=）

- 数据源：`GET /api/v1/science/knowledge/tree?domain={domain}&grade={grade}`。
- 呈现：三级层级（领域 → 主题 → 知识点），节点状态三态（未学灰 / 学过蓝 / 薄弱橙，由服务端字段 `masteryStatus` 下发，客户端不计算）。
- 知识点节点点击 → 概念详情；长按 → 快捷"问 AI"（携 questionSeed="给我讲讲{知识点名}"进辅导页）。
- 树缓存：内存 + 磁盘各一份，磁盘 TTL 7 天；降级见 §8.2 D4。

### 4.3 概念详情页（/science/concept/:conceptId）

- 数据源：`GET /api/v1/science/concept/{conceptId}?studentId=`。
- 区块顺序：概念名称 + 适龄解释（富文本，LaTeX/公式走学科渲染管线）→ 生活实例（图文卡）→ 关联知识点 chips（→ 领域树锚点）→ 关联实验横滑（→ 实验列表带 kp 过滤）→ "向 AI 提问"固定底栏。
- 误解警示：服务端 `misconceptions` 字段非空时，解释区下方插入黄底"常见误解"卡（fail-safe 展示，不折叠）。

### 4.4 AI 探究式辅导页（/science/tutor）

#### 4.4.1 输入区

- 三种输入：文字（默认）、语音（按住说话，ASR 复用全局语音服务，inputType=voice）、图片（拍照/相册，inputType=image，图片上传走多媒体服务，成功后携 imageUrl 提问）。
- 上下文自动装配（客户端组装 `context`）：grade / textbookVersion / currentChapter（取学科上下文管理器当前值）、recentTopics（取最近 7 天辅导会话知识点，本地缓存，最多 5 条）。
- mode 默认 `inquiry`；"直接告诉我答案"长按切换 direct（小学 3 年级以下不展示该切换，防直接抄答案，§5）。

#### 4.4.2 会话区与流式渲染

- SSE 逐段到达，八种段类型渲染策略：

| type | 渲染组件 | 特殊规则 |
| --- | --- | --- |
| acknowledge | EncourageBubble（暖色气泡 + 轻动效） | 与首 token 同帧到达时合并展示，避免"空鼓励" |
| life_connection | LifeConnectionCard（生活图标 + 文字） | 末尾追加"你发现过吗？"轻交互点（埋点用） |
| inquiry_guide | InquiryGuideBlock（编号问题列表 + 逐条渐显） | 渐显节奏 600ms/条；全程不自动展开答案 |
| concept_explanation | MarkdownStreamView（复用 AI 对话渲染引擎，R8） | visualAid 非空时右侧插图位，插图失败降级文字描述（D6） |
| experiment_suggestion | ExperimentSuggestionCard（材料图标 + "试试这个实验"按钮） | 按钮携 experimentId → /science/experiments?highlight=；experimentId 失效点击时服务端 404 兜底话术 |
| extension | ExtensionCard（思考题 chips） | 点击 chip 即以该问题发起新追问 |
| safety_warning | SafetyBanner（红底白字横幅 + 语音朗读一遍） | fail-safe 级：朗读前检查全局静音策略，但不提供关闭本条的开关 |
| misconceptionCheck | MisconceptionBubble（蓝底"很多人以为…其实…"） | 不折叠、不 dismiss |

- 段间顺序固定按服务端下发顺序渲染，客户端不重排（R6）。
- 流式中状态：思考动效（烧瓶摇晃动画，小学 1-2 年级）/三点省略（3-6 年级）；首 token >2.5s 展示"正在查阅科学知识库…"安抚文案（与服务端 M1 阈值对齐）。

#### 4.4.3 渐进呈现与完成态

- concept_explanation 段流式渐显（按 SSE chunk），其余段整段到达后淡入。
- 完成后底部呈现：知识点 chips（→ 概念详情）、followUpSuggestions 三选一快捷追问、experiment_suggestion 卡（如有）。
- 追问：点击 suggestion 或继续输入，自动携带 conversationId；新会话按钮清空会话区并丢弃 conversationId。

#### 4.4.4 弱网与断线

- SSE 断线 3s 内自动重连（携带 lastEventId）；>3s 或 401/53130 展示可重试错误态，已渲染段保留（不重放）。
- 断线期间用户输入入本地队列（FIFO，最多 3 条），重连后按序补发（同 conversationId）。

### 4.5 实验列表页（/science/experiments）

- 数据源：`GET /api/v1/science/experiments?domain=&grade=&knowledgePointId=`；支持从辅导页带 kp 直达过滤。
- 卡片字段：缩略图（CDN，懒加载 + 磁盘缓存）、实验名、适用年级段、预计时长、安全级别徽标（low 绿 / medium 黄 / high 红，high 实验卡片额外挂"仅虚拟操作"角标）、素养维度 chips。
- 筛选项：领域 chips + 年级段 chips（默认当前年级）。
- 点击卡片 → 材料清单弹层（实验材料 + safetyWarnings 红色列表，medium/high 附"请在家长陪同下"提示条）→ "开始实验"才真正调 `POST /guide`（避免误创建会话）。
- 53102（年级不适用）：卡片仍可浏览但"开始实验"置灰，点击提示"这个实验适合 X 年级的同学"。

### 4.6 实验引导页（/science/experiment/:sessionId）

#### 4.6.1 页面结构

1. **顶栏**：实验名 + 退出按钮（二次确认弹层："进度会保留 30 分钟，回来可以继续哦"——对应服务端 G8 心跳 30min 转 ABANDONED 语义）。
2. **阶段进度条**：stage 圆点链（当前态放大 + 已完成打勾 + 未到达灰），点击仅可回看已完成阶段内容（不可跳前，G5）。
3. **引导区**：当前 stage 的 guidance 文案（服务端下发，适龄富文本）。
4. **交互区**：按 interactiveType 委托渲染（§4.6.2）。
5. **反馈区**：服务端判定反馈呈现（§4.6.4）。
6. **心跳**：前台每 5min 心跳（复用统一心跳通道，R7）；退后台暂停计时展示，回前台立即补发。

#### 4.6.2 五类交互委托矩阵

| interactiveType | 客户端实现 | 权威边界 |
| --- | --- | --- |
| componentRender | `componentConfig.type` 二级路由：`circuit_builder` → 本模块内嵌 CircuitBuilderWidget；其余 type（力学/电路进阶/化学/生物等）→ 委托既有学科实验组件库（物理/化学/生物实验组件文档） | 组件**只采集操作**（connections/switchClosed 等 payload），**禁本地判定**（G4）；组件内部自带的"演示动画"仅在收到服务端第 3 次 fail 反馈后由反馈区触发播放（G7 防挫败） |
| freeForm | 自由操作画布 + "我做好了"提交按钮 → action 整段提交 | 成功条件表达式由服务端解释（successCondition 字段仅服务端用，客户端不解析，R5） |
| observationForm | 按服务端 fields 动态生成表单（text/number/select/photo 四控件，photo 复用多媒体选取服务） | 字段校验服务端为准，客户端仅做非空前置校验 |
| reflectionQuestions | 逐题作答卡片（选择题式点选或语音回答），作答结果随最后一题合并提交 | 思考题不产生对错判定，仅展示服务端回执的参考表述 |
| summaryCard | summaryPoints 陈列 + "讲给家人听"分享卡（复用学习报告卡片渲染引擎）+ 重玩按钮（24h 内，G8） | 重玩标记 mode=free，不产生重复素养证据（服务端幂等） |

#### 4.6.3 component_render 内嵌：CircuitBuilderWidget

- 素材：电池/导线×2/灯泡/开关拖拽件（SVG，素材归客户端资源包管理器）。
- 交互：拖线连接端子（吸附 12dp）、开关开合 toggle、提交按钮。
- 采集 payload：`{"connections":[{"from","to"}...], "switchClosed": bool}`，原样装入 `action.payload`。
- **禁实现**：通断本地预判定、灯泡点亮本地动画（点亮动画只在收到服务端 success/partial 反馈后播放——失败时灯泡不亮是教学反馈的一部分，预亮会破坏探究性，G4）。
- 短路保护：电池正负极直接相连的组合**允许提交**（交由服务端 fail_safe 判定并返回红色安全警告），但组件在拖拽形成直连瞬间给出黄色预警抖动（纯交互提示，不构成判定）。

#### 4.6.4 步骤提交与反馈呈现

- 提交：生成 clientRequestId（§3.3）→ loading 遮罩（防连点）→ POST step。
- 四档反馈渲染：

| result | 渲染 | 后续 |
| --- | --- | --- |
| success | 绿色鼓励卡（feedback.content）+ 素养证据轻提示（"探究力 +8"动效，仅展示） | 自动进入下一 stage（1.2s 后） |
| partial | 蓝白卡：先列已正确部分，再列"再看看"部分 | 停留当前 stage |
| fail | 第 1-2 次：苏格拉底提示气泡（hint.content，浅黄，逐条可展开） | 停留；attemptNumber 角标展示 |
| fail | 第 3 次：服务端返回演示标记 → 播放正确接法演示动画，随后允许跳过本 stage（G7） | 可进入下一 stage |
| failSafe | **红色全幅阻断卡** + 语音朗读 safety 文案一遍 + 震动 200ms | 操作回滚到上一步状态（组件本地撤销），停留当前 stage，不计失败次数 |

- 53106（同键不同 payload）：Toast"操作已提交，请稍候"并回滚 UI 到提交前状态，以服务端首次结果为准。
- 53104（degraded）：引导区切换为静态步骤模板展示（服务端下发 degraded=true 时 stages 为静态模板），顶部细条"智能引导暂不可用，正在使用标准步骤"，静默重试一次。

#### 4.6.5 完成与评价

- 末 stage 完成 → 庆祝动效（低端机降级静态图，复用成就动效降级策略）→ 评价弹层（"今天好玩吗？"三星 + 一句语音/文字感想，可选）→ POST 评价 → 总结卡（summaryPoints + 素养维度获得 + 推荐观察项目）。
- 24h 内重玩入口在总结卡（G8）；超期后按钮消失（客户端按 completedAt 本地判断展示）。

### 4.7 观察项目列表页（/science/observation）

### 7.1 探究式辅导 SSE 控制器

```dart
class ScienceTutorController {
  static const _maxReconnectMs = 3000;

  final ScienceRepository _repo;
  StreamSubscription<ScienceSegment>? _sub;
  String? conversationId;
  final segments = <ScienceSegment>[].obs;      // 已渲染段, UI 按 type 分发
  final state = ScienceTutorState.idle.obs;

  Future<void> ask(ScienceTutorRequest req) async {
    if (state.value == ScienceTutorState.connecting ||
        state.value == ScienceTutorState.streaming) return;   // G9 防连点
    state.value = ScienceTutorState.connecting;
    try {
      _sub = _repo.askTutor(req.copyWith(conversationId: conversationId)).listen(
        (seg) {
          state.value = ScienceTutorState.streaming;
          segments.add(seg);                                 // 顺序渲染, 不重排(R6)
          if (seg is! ScienceSegment) return;
        },
        onError: (e) => _onError(e),
        onDone: () => state.value = ScienceTutorState.rendered,
        cancelOnError: false,
      );
    } catch (e) {
      _onError(e);
    }
  }

  void _onError(Object e) {
    if (e is AuthException) { state.value = ScienceTutorState.errorRetry; return; }
    final biz = e as BizException;
    if (biz.code == 53131) { showCooldown(biz.message); return; }  // 频率限制冷却提示
    if (biz.code == 53130) { state.value = ScienceTutorState.errorRetry; return; }
    ErrorMessageFactory.present(biz);                          // §8.1 话术
  }

  void newSession() {
    _sub?.cancel();
    conversationId = null;
    segments.clear();
    state.value = ScienceTutorState.idle;
  }
}
```

### 7.3 步骤提交（幂等 + 防重 + 四档反馈分发）

```dart
class StepSubmitController {
  String? _pendingClientRequestId;

  Future<void> submit({required String sessionId, required int stageIndex,
      required String actionType, required Map<String, dynamic> payload}) async {
    if (_pendingClientRequestId != null) return;               // G9 提交遮罩
    final clientRequestId = const Uuid().v4();                 // 一次提交动作一个键(§3.3)
    _pendingClientRequestId = clientRequestId;
    try {
      final fb = await _repo.submitStep(StepSubmitRequest(
        sessionId: sessionId, studentId: currentStudent.id,
        stageIndex: stageIndex,
        action: {'type': actionType, 'payload': payload},
        clientRequestId: clientRequestId,
      ));
      _dispatch(fb);
    } on BizException catch (e) {
      if (e.code == 53106) { toast('操作已提交，请稍候'); rollbackUi(); } // 以服务端首次结果为准
      else if (e.code == 53105) { refreshSession(); }           // stageIndex 越界
      else { ErrorMessageFactory.present(e); }
    } finally {
      _pendingClientRequestId = null;
    }
  }

  void _dispatch(StepFeedback fb) {
    switch (fb.result) {
      case StepResult.success:
        FeedbackView.showEncourage(fb.feedback!.content, evidence: fb.literacyEvidence);
        Future.delayed(const Duration(milliseconds: 1200), gotoNextStage); // §4.6.4
      case StepResult.partial:
        FeedbackView.showPartial(fb.feedback!.content);
      case StepResult.fail:
        fb.attemptNumber <= 2
          ? FeedbackView.showSocraticHint(fb.hint!.content, attempt: fb.attemptNumber)
          : FeedbackView.showDemoAndAllowSkip(onSkip: gotoNextStage);      // G7
      case StepResult.failSafe:
        FeedbackView.showFailSafeBlocking(fb.feedback!.content);           // G6 三通道
        rollbackLastOperation();                                           // 组件撤销一步
    }
  }
}
```

## 9. 合规红线（客户端侧 C1–C8）

1. C1：科学问答内容属 AI 生成，辅导页固定展示"AI 讲解，重要知识以课本为准"提示，禁隐藏。
2. C2：实验 safetyWarnings 与 failSafe 反馈不可关闭、不可折叠、不可被运营内容覆盖。
3. C3：家长端报告禁展示 AI 对话原文与逐字提问记录，仅展示主题级统计。
4. C4：观察项目照片仅本人与绑定家长可见；分享卡渲染前过全局脱敏规则（禁含 EXIF 定位）。
5. C5：素养报告对家长仅展示等级不展示分值，话术走成长型红线，禁"落后/差"等评判词。
6. C6：语音输入为幼儿/低年级默认能力，须符合《服务端-幼儿端儿童语音识别适配与语音交互安全引擎》的儿童语音不留存约定（本模块语音仅转写即弃）。
7. C7：high 安全级实验必须展示"仅虚拟操作，请勿模仿"常驻角标。
8. C8：深链接进入实验/观察页前必须完成学段闸与归属校验（G1/G2），禁借深链接绕过。

## 11. 性能设计

- 首屏：/science/home 仅领域宫格为阻塞渲染（本地静态资源），其余区块异步；首屏可交互 < 1.5s（中端机）。
- SSE：辅导页复用全局 SSE 连接池（与 AI 对话共用长连接调度器，R9），单连接上限沿用全局策略。
- 图片：实验缩略图统一走图片加载缓存框架（磁盘 LRU 200MB 科学分区内存 20MB）；观察照片上传前压缩至长边 1600px、单张 ≤800KB。
- 内存：实验组件 heavy 资源（SVG 素材）随 stage 切换释放； CircuitBuilderWidget 常驻内存 < 30MB。
- 电量：心跳严格前台 5min（G12），退后台即停；轮询全部设上限（§4.8 上限 3 次）。
