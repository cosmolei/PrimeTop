# 客户端文件上传服务与断点续传机制 - 详细设计

> 文档版本：v1.0 | 更新日期：2026-05-24 | 状态：初稿

## 1. 概述

### 1.1 背景

PrimeTop 的多个核心功能依赖文件上传：拍照搜题需要上传图片、语音提问需要上传音频、作文辅导需要上传作文照片、头像设置需要上传图片等。在移动端弱网、切换网络、App 后台被杀等复杂场景下，文件上传极易失败，直接影响用户体验。

原始设计文档（§13.2 可用性需求）明确要求：

> 用户上传图片、语音等资源应支持断点或失败重传策略。

本设计提供一套统一的客户端文件上传服务，覆盖所有业务场景的上传需求。

### 1.2 设计目标

| 目标 | 指标 |
|------|------|
| 上传成功率 | ≥ 99%（正常网络） |
| 断点续传 | 支持网络切换、App 后台恢复后续传 |
| 弱网适配 | 2G/3G 网络下不丢失已上传分片 |
| 并发管理 | 最多同时 3 个上传任务，队列有序 |
| 内存安全 | 单次上传内存占用 < 50MB |
| 进度感知 | 上传进度实时反馈，误差 < 5% |

### 1.3 适用场景

| 场景 | 文件类型 | 典型大小 | 频率 |
|------|----------|----------|------|
| 拍照搜题 | JPEG/PNG | 2-10 MB | 高频 |
| 语音提问 | AAC/PCM | 0.5-5 MB | 中频 |
| 作文拍照 | JPEG | 5-15 MB（高清） | 中频 |
| 头像上传 | JPEG/PNG | 0.5-3 MB | 低频 |
| 错题手动拍照 | JPEG/PNG | 2-10 MB | 中频 |
| 学习报告分享图 | PNG | 1-5 MB | 低频 |
| 手写笔记上传 | JPEG/PNG（多图） | 单张 2-10 MB | 低频 |

## 3. 数据结构定义

### 3.1 上传请求 (UploadRequest)

```typescript
interface UploadRequest {
  // 基本信息
  id: string;                    // UUID，任务唯一标识
  businessType: BusinessType;    // 业务场景
  localFilePath: string;         // 本地文件路径
  fileName: string;              // 原始文件名
  fileSize: number;              // 原始文件大小（bytes）
  mimeType: string;              // MIME 类型

  // 业务关联
  businessId: string;            // 关联业务 ID（如题目 ID、会话 ID）
  userId: string;                // 用户 ID
  deviceId: string;              // 设备标识

  // 上传选项
  priority: UploadPriority;      // 优先级
  preprocessOptions: PreprocessOptions;
  uploadOptions: UploadOptions;

  // 回调
  onProgress?: (progress: UploadProgress) => void;
  onComplete?: (result: UploadResult) => void;
  onError?: (error: UploadError) => void;

  // 时间戳
  createdAt: number;             // 创建时间（epoch ms）
}
```

```typescript
interface PreprocessOptions {
  // 图片选项
  image?: {
    maxWidth: number;           // 最大宽度（默认 2048px）
    maxHeight: number;          // 最大高度（默认 2048px）
    quality: number;            // JPEG 质量 0-100（默认 85）
    format: 'jpeg' | 'png' | 'webp';  // 输出格式
    stripExif: boolean;         // 是否移除 EXIF（默认 true，保护隐私）
  };

  // 音频选项
  audio?: {
    format: 'aac' | 'mp3';     // 输出格式（默认 aac）
    sampleRate: number;         // 采样率（默认 16000）
    bitrate: number;            // 比特率（默认 128kbps）
    channels: 1 | 2;           // 声道数（默认 1，单声道）
    maxDuration: number;        // 最大时长（秒，默认 60）
  };

  // 通用
  maxFileSize: number;          // 最大文件大小（bytes）
  failIfExceed: boolean;        // 超过大小是否直接失败（默认 false，尝试压缩）
}
```

## 4. API 接口设计

### 4.1 服务端接口

#### 4.1.1 申请上传凭证

```
POST /api/v1/upload/ticket
```

**请求体：**

```json
{
  "fileName": "photo_20260524_185801.jpg",
  "fileSize": 5242880,
  "mimeType": "image/jpeg",
  "businessType": "photo_question",
  "businessId": "q_12345",
  "chunkCount": 5,
  "chunkSize": 1048576,
  "fileChecksum": "e10adc3949ba59abbe56e057f20f883e"
}
```

**响应体：**

```json
{
  "code": 0,
  "data": {
    "fileId": "f_20260524_abc123",
    "uploadId": "upload_xyz789",
    "chunks": [
      {
        "index": 0,
        "uploadUrl": "https://cdn.primetop.com/upload-presigned/chunk?f=f_20260524_abc123&c=0&sign=xxx",
        "expiresAt": 1716550800000
      },
      {
        "index": 1,
        "uploadUrl": "https://cdn.primetop.com/upload-presigned/chunk?f=f_20260524_abc123&c=1&sign=xxx",
        "expiresAt": 1716550800000
      }
    ],
    "expiresAt": 1716550800000,
    "maxAge": 86400000
  }
}
```

**规则：**
- 文件大小 < 1MB 时，`chunkCount` 可为 1（单次上传）
- 每个预签名 URL 有效期 30 分钟
- 同一 `fileId` 可重复申请未上传分片的 URL（用于续传）

#### 4.1.2 上传分片

```
PUT {uploadUrl}
Content-Type: application/octet-stream
Content-MD5: {chunkChecksum}
X-Upload-Id: {uploadId}
X-Chunk-Index: {index}
X-Chunk-Size: {size}

<binary data>
```

**响应：**

```json
{
  "code": 0,
  "data": {
    "chunkIndex": 0,
    "received": true,
    "checksum": "abc123"
  }
}
```

### 4.2 客户端内部接口

```kotlin
// UploadFacade - 业务层调用的唯一入口
class UploadFacade {

    /**
     * 提交上传任务
     * @return UploadTask 可用于跟踪进度、暂停、取消
     */
    fun submit(request: UploadRequest): UploadTask

    /**
     * 批量提交（如多图错题拍照）
     */
    fun submitBatch(requests: List<UploadRequest>): List<UploadTask>

    /** 暂停任务 */
    fun pause(taskId: String)

    /** 恢复任务 */
    fun resume(taskId: String)

    /** 取消任务 */
    fun cancel(taskId: String)

    /** 重试失败任务 */
    fun retry(taskId: String)

    /** 获取任务进度 */
    fun getProgress(taskId: String): Flow<UploadProgress>

    /** 获取所有活跃任务 */
    fun getActiveTasks(): List<UploadTask>

    /** 重试所有失败任务（网络恢复时调用） */
    fun retryAllFailed()
}
```

```kotlin
fun calculateChunks(fileSize: Long, chunkSize: Int = DEFAULT_CHUNK_SIZE): List<ChunkInfo> {
    val chunks = mutableListOf<ChunkInfo>()
    val totalChunks = ceil(fileSize.toDouble() / chunkSize).toInt()
    // 限制最大分片数
    require(totalChunks <= MAX_CHUNK_COUNT) { "File too large: exceeds $MAX_CHUNK_COUNT chunks" }

    for (i in 0 until totalChunks) {
        val offset = i * chunkSize.toLong()
        val size = minOf(chunkSize.toLong(), fileSize - offset).toInt()
        chunks.add(ChunkInfo(
            index = i,
            offset = offset,
            size = size,
            checksum = "",  // 延迟计算，在读取分片时计算 MD5
            uploaded = false,
            uploadUrl = null
        ))
    }
    return chunks
}

companion object {
    const val DEFAULT_CHUNK_SIZE = 1 * 1024 * 1024  // 1MB
    const val MAX_CHUNK_COUNT = 1000
    const val MIN_CHUNK_SIZE = 256 * 1024           // 256KB
    const val MAX_CHUNK_SIZE = 4 * 1024 * 1024      // 4MB
}
```

```kotlin
class UploadRecoveryService {

    /**
     * App 启动时调用
     * 1. 加载所有未完成任务
     * 2. 清理过期任务（超过 24h）
     * 3. 对未完成任务按策略恢复
     */
    fun recoverOnAppStart() {
        val tasks = taskStore.loadPending()

        for (task in tasks) {
            when {
                // 已超过 24 小时 → 标记失败，通知业务层
                task.isExpired -> {
                    task.markFailed("UPLOAD_EXPIRED", "上传凭证已过期")
                    notifyBusiness(task)
                }

                // 正在上传 → 查询服务端状态后续传
                task.state == UPLOADING -> {
                    queryServerAndResume(task)
                }

                // 等待中 → 重新入队
                task.state == PENDING || task.state == PAUSED -> {
                    scheduler.enqueue(task)
                }

                // 失败且可重试 → 自动重试
                task.state == FAILED && task.isRetryable -> {
                    scheduler.enqueue(task)
                }
            }
        }
    }

    private fun queryServerAndResume(task: UploadTask) {
        // 1. 查询服务端已接收的分片
        val status = api.getUploadStatus(task.fileId, task.uploadId)

        if (status.status == "completed") {
            // 服务端已合并完成（App 被杀前合并请求已发出）
            task.markCompleted(status.remoteUrl)
            notifyBusiness(task)
            return
        }

        // 2. 更新已上传分片
        task.uploadedChunks = status.uploadedChunks.toSet()

        // 3. 检查凭证是否过期
        if (status.expiresAt < System.currentTimeMillis()) {
            // 重新申请凭证
            refreshUploadTicket(task)
        }

        // 4. 重新入队续传
        scheduler.enqueue(task)
    }
}
```

## 8. 错误处理与重试

### 8.1 重试策略

```kotlin
class RetryPolicy {

    companion object {
        const val MAX_RETRIES = 3
        val BACKOFF_DELAYS = listOf(1_000L, 3_000L, 10_000L)  // 指数退避（ms）
    }

    fun shouldRetry(error: UploadError): Boolean {
        if (error.retryCount >= MAX_RETRIES) return false
        return when (error.code) {
            // 可重试
            NETWORK_UNAVAILABLE,
            CONNECTION_TIMEOUT,
            CONNECTION_LOST,
            UPLOAD_URL_EXPIRED,
            CHUNK_UPLOAD_FAILED,
            SERVER_ERROR -> true

            // 不可重试
            FILE_NOT_FOUND,
            FILE_TOO_LARGE,
            FILE_CORRUPTED,
            INVALID_FORMAT,
            CONTENT_REJECTED,
            QUOTA_EXCEEDED -> false

            // 需特殊处理
            AUTH_EXPIRED -> false  // 需要刷新 token 后重试（不计入重试次数）
            MERGE_FAILED -> true   // 合并可重试
            PREPROCESS_FAILED -> false  // 预处理失败不可重试
        }
    }

    fun getBackoffDelay(retryCount: Int): Long {
        if (retryCount >= BACKOFF_DELAYS.size) return BACKOFF_DELAYS.last()
        return BACKOFF_DELAYS[retryCount]
    }
}
```

```kotlin
/**
 * 单个分片上传的容错逻辑
 */
suspend fun uploadChunkWithRetry(
    chunk: ChunkInfo,
    task: UploadTask,
    maxAttempt: Int = 3
): ChunkResult {
    var lastError: Exception? = null

    repeat(maxAttempt) { attempt ->
        try {
            // 读取分片数据（使用 RandomAccessFile 按 offset 读取）
            val data = readChunkData(task.localPath, chunk.offset, chunk.size)
            val checksum = md5(data)

            val response = httpClient.put(chunk.uploadUrl!!) {
                header("Content-Type", "application/octet-stream")
                header("Content-MD5", checksum)
                header("X-Upload-Id", task.uploadId)
                header("X-Chunk-Index", chunk.index)
                header("X-Chunk-Size", chunk.size)
                body = data
            }

            if (response.isSuccessful) {
                // 更新持久化状态
                taskStore.markChunkUploaded(task.taskId, chunk.index)
                return ChunkResult.success(chunk.index)
            }
        } catch (e: IOException) {
            lastError = e
            // 分片上传失败，等待退避
            delay(RetryPolicy.BACKOFF_DELAYS[min(attempt, RetryPolicy.BACKOFF_DELAYS.size - 1)])
        }
    }

    throw UploadException(CHUNK_UPLOAD_FAILED, "Chunk ${chunk.index} failed after $maxAttempt attempts", lastError)
}
```

```kotlin
class ImagePreprocessor {

    fun compress(
        filePath: String,
        options: PreprocessOptions.ImageOptions
    ): ProcessedFile {
        val bitmap = decodeSampledBitmap(filePath, options.maxWidth, options.maxHeight)

        // EXIF 脱敏
        if (options.stripExif) {
            stripExifData(filePath)
        }

        // 质量压缩
        val outputStream = ByteArrayOutputStream()
        val format = when (options.format) {
            "jpeg" -> Bitmap.CompressFormat.JPEG
            "png" -> Bitmap.CompressFormat.PNG
            "webp" -> Bitmap.CompressFormat.WEBP
            else -> Bitmap.CompressFormat.JPEG
        }

        bitmap.compress(format, options.quality, outputStream)

        // 检查压缩后大小
        val compressed = outputStream.toByteArray()
        if (compressed.size > options.maxFileSize && options.quality > 30) {
            // 递归降低质量
            return compress(filePath, options.copy(quality = options.quality - 15))
        }

        // 写入临时文件
        val tempFile = createTempFile("upload_", ".${options.format}")
        FileOutputStream(tempFile).use { it.write(compressed) }

        return ProcessedFile(
            path = tempFile.absolutePath,
            fileSize = compressed.size.toLong(),
            width = bitmap.width,
            height = bitmap.height,
            mimeType = "image/${options.format}"
        )
    }

    /**
     * 采样解码，避免大图 OOM
     */
    private fun decodeSampledBitmap(
        filePath: String,
        reqWidth: Int,
        reqHeight: Int
    ): Bitmap {
        val options = BitmapFactory.Options().apply {
            inJustDecodeBounds = true
        }
        BitmapFactory.decodeFile(filePath, options)

        options.inSampleSize = calculateInSampleSize(options, reqWidth, reqHeight)
        options.inJustDecodeBounds = false

        return BitmapFactory.decodeFile(filePath, options)
    }

    private fun calculateInSampleSize(
        options: BitmapFactory.Options,
        reqWidth: Int,
        reqHeight: Int
    ): Int {
        val (height, width) = options.outHeight to options.outWidth
        var inSampleSize = 1

        if (height > reqHeight || width > reqWidth) {
            val halfHeight = height / 2
            val halfWidth = width / 2

            while ((halfHeight / inSampleSize) >= reqHeight &&
                   (halfWidth / inSampleSize) >= reqWidth) {
                inSampleSize *= 2
            }
        }
        return inSampleSize
    }
}
```

### 10.1 优先级队列

```kotlin
class UploadScheduler(
    private val maxConcurrent: Int = 3,
    private val uploader: ChunkedUploader,
    private val taskStore: UploadTaskStore
) {
    // 按优先级排序的阻塞队列
    private val queue = PriorityBlockingQueue<UploadTask>(
        11, compareBy { it.priority.ordinal }.thenBy { it.createdAt }
    )

    // 当前活跃任务
    private val activeTasks = ConcurrentHashMap<String, Job>()

    // 可用信号量
    private val semaphore = Semaphore(maxConcurrent)

    fun enqueue(task: UploadTask) {
        task.state = PENDING
        taskStore.save(task)
        queue.put(task)
        scheduleNext()
    }

    private fun scheduleNext() {
        while (semaphore.tryAcquire() && queue.isNotEmpty()) {
            val task = queue.poll() ?: break
            val job = CoroutineScope(Dispatchers.IO).launch {
                try {
                    processTask(task)
                } finally {
                    semaphore.release()
                    activeTasks.remove(task.taskId)
                    scheduleNext()  // 处理下一个
                }
            }
            activeTasks[task.taskId] = job
        }
    }

    private suspend fun processTask(task: UploadTask) {
        try {
            task.state = UPLOADING
            taskStore.save(task)

            val result = uploader.upload(task)

            task.state = COMPLETED
            task.remoteUrl = result.remoteUrl
            taskStore.save(task)

            task.onComplete?.invoke(result)
        } catch (e: UploadException) {
            val retryPolicy = RetryPolicy()
            if (retryPolicy.shouldRetry(e.toUploadError())) {
                // 重试：重新入队
                task.retryCount++
                task.state = PENDING
                taskStore.save(task)
                delay(retryPolicy.getBackoffDelay(task.retryCount))
                queue.put(task)
            } else {
                task.state = FAILED
                task.errorCode = e.code
                task.errorMessage = e.message
                taskStore.save(task)
                task.onError?.invoke(e.toUploadError())
            }
        }
    }

    fun pause(taskId: String) {
        activeTasks[taskId]?.cancel()
        activeTasks.remove(taskId)
        semaphore.release()
        // task state update handled by cancel callback
    }

    fun prioritize(taskId: String) {
        // 将任务移到队列头部（提高优先级）
        val task = taskStore.load(taskId) ?: return
        task.priority = UploadPriority.CRITICAL
        taskStore.save(task)
        // 如果在队列中，PriorityBlockingQueue 会自动重新排序
    }
}
```

```kotlin
class FileValidator {

    /**
     * 文件头魔术字节校验，防止伪造扩展名
     */
    fun validateMimeType(filePath: String, expectedMime: String): Boolean {
        val magicBytes = readFileHeader(filePath, 16)
        val actualMime = detectMimeType(magicBytes)

        return when {
            expectedMime.startsWith("image/jpeg") -> actualMime in listOf("image/jpeg", "image/jpg")
            expectedMime.startsWith("image/png") -> actualMime == "image/png"
            expectedMime.startsWith("audio/") -> actualMime.startsWith("audio/")
            else -> actualMime == expectedMime
        }
    }

    /**
     * 防止路径穿越攻击
     */
    fun validatePath(filePath: String): Boolean {
        val canonical = File(filePath).canonicalPath
        val allowedDirs = listOf(
            context.cacheDir.canonicalPath,
            context.filesDir.canonicalPath,
            context.getExternalFilesDir(null)?.canonicalPath
        )
        return allowedDirs.any { canonical.startsWith(it) }
    }

    companion object {
        private val MAGIC_BYTES = mapOf(
            byteArrayOf(0xFF.toByte(), 0xD8.toByte(), 0xFF.toByte()) to "image/jpeg",
            byteArrayOf(0x89, 0x50, 0x4E, 0x47) to "image/png",
            byteArrayOf(0x52, 0x49, 0x46, 0x46) to "audio/wav",  // RIFF
            byteArrayOf(0xFF.toByte(), 0xF1.toByte()) to "audio/aac",  // AAC ADTS
        )

        fun detectMimeType(header: ByteArray): String? {
            return MAGIC_BYTES.entries.firstOrNull { (magic, _) ->
                header.take(magic.size).toByteArray().contentEquals(magic)
            }?.value
        }
    }
```

```kotlin
/**
 * 分片数据使用流式读取，避免一次性加载整个文件到内存

class ChunkFileReader {

    /**
     * 使用 RandomAccessFile 读取指定分片
     * 不会将整个文件加载到内存
     */
    fun readChunk(filePath: String, offset: Long, size: Int): ByteArray {
        val buffer = ByteArray(size)
        RandomAccessFile(filePath, "r").use { raf ->
            raf.seek(offset)
            raf.readFully(buffer, 0, size)
        }
        return buffer
    }

    /**
     * 使用内存映射（mmap）处理大文件
     * 适用于超大文件的分片读取
     */
    fun readChunkMapped(
        filePath: String,
        offset: Long,
        size: Int
    ): ByteBuffer {
        val raf = RandomAccessFile(filePath, "r")
        val channel = raf.channel
        val buffer = channel.map(
            FileChannel.MapMode.READ_ONLY,
            offset,
            size.toLong()
        )
        channel.close()
        raf.close()
        return buffer
    }
}
```

```kotlin
            localFilePath = photoPath,
            fileName = File(photoPath).name,
            fileSize = File(photoPath).length(),
            mimeType = "image/jpeg",
            businessId = "",  // 暂无关联，OCR 后关联题目
            userId = currentUser.id,
            deviceId = deviceInfo.id,
            priority = UploadPriority.CRITICAL,  // 用户等待中
            preprocessOptions = PreprocessOptions(
                image = PreprocessOptions.ImageOptions(
                    maxWidth = 2048,
                    maxHeight = 2048,
                    quality = 85,
                    format = "jpeg",
                    stripExif = true
                ),
                maxFileSize = 5 * 1024 * 1024,
                failIfExceed = false
            ),
            onProgress = { progress -> _uploadState.value = progress },
            onComplete = { result ->
                // 上传完成，进入 OCR 识别流程
                _uploadState.value = null
                startOCR(result.remoteUrl)
            },
            onError = { error ->
                _uploadState.value = _uploadState.value?.copy(state = UploadState.FAILED)
                showError(error)
            },
            createdAt = System.currentTimeMillis()
        )

        uploadFacade.submit(request)
    }

    fun cancelUpload() {
        _uploadState.value?.let { uploadFacade.cancel(it.taskId) }
    }
}
```

## 16. 临时文件清理

```kotlin
class TempFileCleaner(
    private val context: Context,
    private val taskStore: UploadTaskStore
) {
    /**
     * 定期清理（建议每次 App 启动和每 6 小时执行一次）
     */
    fun cleanup() {
        val uploadTempDir = File(context.cacheDir, "upload_temp")
        if (!uploadTempDir.exists()) return

        val now = System.currentTimeMillis()
        val maxAge = 24 * 60 * 60 * 1000L  // 24 小时

        uploadTempDir.listFiles()?.forEach { file ->
            if (now - file.lastModified() > maxAge) {
                // 检查是否有关联的活跃任务
                val hasActiveTask = taskStore.loadByLocalPath(file.absolutePath) != null
                if (!hasActiveTask) {
                    file.delete()
                }
            }
        }

        // 清理已完成任务的临时文件
        taskStore.loadCompleted(maxAge = maxAge).forEach { task ->
            val tempFile = File(task.localPath)
            if (tempFile.exists() && tempFile.absolutePath.contains("upload_temp")) {
                tempFile.delete()
            }
            taskStore.delete(task.taskId)
        }
    }
}
```
