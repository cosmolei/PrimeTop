# 服务端 - 教育内容供应商接入与外部资源标准化导入引擎 详细设计

## 1. 概述

### 1.1 模块定位

教育内容供应商接入引擎是 PrimeTop 平台与外部内容提供方（出版社、教辅机构、学校、独立教研团队等）之间的**统一技术桥梁**。它负责将外部教育资源以标准化方式接入平台，经过质量检测、格式转换、知识对齐后，注入题库、知识库和课程内容体系。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 供应商接入 | 合作方注册、资质审核、API 凭证管理 |
| 内容导入 | 多格式（JSON/XML/EPUB/Word/PDF/Excel）教育资源批量导入 |
| 格式标准化 | 将异构内容转换为平台统一内容模型 |
| 质量检测 | 自动化内容质量扫描（完整性、准确性、重复性） |
| 知识对齐 | 将外部知识点编码映射到平台知识图谱 |
| 版本同步 | 跟踪供应商内容更新，增量同步 |
| 版权管理 | 授权范围、有效期、使用次数追踪 |
| 供应商评估 | 基于内容使用数据和用户反馈评估供应商质量 |

### 1.3 依赖关系

```
┌─────────────────────────────────────────────────────┐
│              供应商接入引擎 (本模块)                    │
├─────────┬──────────┬──────────┬──────────┬───────────┤
│         │          │          │          │           │
▼         ▼          ▼          ▼          ▼           ▼
题库服务  知识图谱   内容审核   文件存储   用户权限    审计日志
         服务       服务       服务       服务        服务
```

**上游依赖：**
- 用户权限服务：供应商账号鉴权
- 文件存储服务：原始文件暂存
- 审计日志服务：操作追踪

**下游消费：**
- 题库服务：标准化题目写入
- 知识图谱服务：知识点映射写入
- 内容审核服务：触发审核流程
- 教材管理服务：教材章节关联

### 2.2 数据库表结构

#### 2.2.1 content_provider（内容供应商）

```sql
CREATE TABLE content_provider (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    provider_code       VARCHAR(64) NOT NULL UNIQUE COMMENT '供应商编码，如 PRESS_PEOPLE_EDU',
    provider_name       VARCHAR(200) NOT NULL COMMENT '供应商名称',
    provider_type       TINYINT NOT NULL COMMENT '类型: 1=出版社 2=教辅机构 3=学校 4=独立教研 5=题库厂商',
    contact_name        VARCHAR(100) COMMENT '联系人',
    contact_phone       VARCHAR(20) COMMENT '联系电话',
    contact_email       VARCHAR(200) COMMENT '联系邮箱',
    business_license    VARCHAR(500) COMMENT '营业执照文件URL',
    qualification_cert  VARCHAR(500) COMMENT '资质证书URL（出版社经营许可证等）',

    remark              TEXT COMMENT '备注',

    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_status (status),
    INDEX idx_type (provider_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容供应商信息表';
```

### 2.3 缓存策略

| `provider:{providerId}:contracts` | List | 15min | 有效合同列表缓存 |
| `provider:{providerId}:credentials` | Hash | 10min | API凭证缓存(仅access_key+rate_limit) |

#### 3.2.2 推送内容（题目）

这是供应商最常用的核心接口，采用批量推送模式。

```
POST /api/v1/provider/content/questions
Content-Type: application/json
Authorization: APIClient {access_key}:{signature}
X-Timestamp: 2026-07-05T06:18:00Z
X-Nonce: a1b2c3d4e5f6
```

**签名算法：**
```
signature = HMAC-SHA256(secret_key, method + "\n" + path + "\n" + timestamp + "\n" + nonce + "\n" + body_sha256)
```


| 字段 | 类型 | 必填 | 说明 |

**支持格式说明：**

| 格式 | 适用场景 | 模板说明 |
| --- | --- | --- |
| JSON | 结构化推送(API/文件) | 按平台JSON Schema组织 |

| CSV | 大批量简单题目 | 管道分隔格式 |
| XML | 兼容QTI等教育标准 | 支持IMS QTI 2.1/3.0 |
| ZIP | 含附件的打包资源 | 解压后按目录结构解析 |

```json
{
  "code": 0,
  "message": "success",

    "batch_no": "PIMP-20260705-0042",
    "file_size": 5242880,
```

```java
@Service
public class QuestionNormalizer implements ContentNormalizer {

    @Override
    public List<NormalizedContent> normalize(RawContent rawInput) 
            throws NormalizationException {
        
        JsonNode item = rawInput.getAsJson();
        String questionType = item.path("question_type").asText();
        
        // 构建标准化题目对象
        StandardQuestion.QuestionBuilder builder = StandardQuestion.builder()
            .questionType(mapQuestionType(questionType))
            .stem(normalizeStem(item.path("stem").asText()))
            .difficulty(item.path("difficulty").asInt())
            .source(extractSource(item));
        
        // 按题型填充特有字段
        switch (questionType) {
            case "single_choice":
            case "multiple_choice":
                builder.options(normalizeOptions(item.path("options")));
                builder.answer(normalizeChoiceAnswer(item));
                break;
            case "fill_blank":
                builder.answer(normalizeFillBlankAnswer(item));
                break;
            case "short_answer":
            case "essay":
                builder.answer(normalizeTextAnswer(item));
                builder.scoringRubric(normalizeRubric(item.path("rubric")));
                break;
            case "true_false":
                builder.answer(item.path("answer").asBoolean());
                break;
            default:
                throw new NormalizationException(
                    "UNSUPPORTED_QUESTION_TYPE", questionType);
        }
        
        // 标准化解析（公式LaTeX校验、图片URL签名等）
        if (item.has("analysis")) {
            builder.analysis(normalizeRichText(item.path("analysis").asText()));
        }
        
        // 标准化附件
        if (item.has("attachments")) {
            builder.attachments(normalizeAttachments(item.path("attachments")));
        }
        
        return List.of(builder.build());
    }
    
    /**
     * 将外部题型编码映射为平台统一题型
     */
    private QuestionType mapQuestionType(String externalType) {
        return switch (externalType) {
            case "single_choice", "choice", "SC" -> QuestionType.SINGLE_CHOICE;
            case "multiple_choice", "MC" -> QuestionType.MULTIPLE_CHOICE;
            case "fill_blank", "fill", "FB" -> QuestionType.FILL_BLANK;
            case "short_answer", "SA" -> QuestionType.SHORT_ANSWER;
            case "essay" -> QuestionType.ESSAY;
            case "true_false", "TF", "judgment" -> QuestionType.TRUE_FALSE;
            default -> throw new NormalizationException(
                "UNKNOWN_QUESTION_TYPE", externalType);
        };
    }
    
    /**
     * 富文本标准化：LaTeX公式统一、图片URL下载并转存CDN
     */
    private String normalizeRichText(String text) {
        // 1. 统一LaTeX分隔符：\[...\] → $$...$$, \(...\) → $...$
        text = text.replaceAll("\\\\\\[(.+?)\\\\\\]", "\\$\\$$1\\$\\$")
                   .replaceAll("\\\\\\((.+?)\\\\\\)", "\\$$1\\$");
        
        // 2. 提取外部图片URL，下载后转存到平台CDN
        Matcher imgMatcher = Pattern.compile(
            "!\\[([^\\]]*)\\]\\(([^\\)]+)\\)").matcher(text);
        StringBuffer sb = new StringBuffer();
        while (imgMatcher.find()) {
            String alt = imgMatcher.group(1);
            String externalUrl = imgMatcher.group(2);
            String cdnUrl = cdnTransferService.transferExternalImage(externalUrl);
            imgMatcher.appendReplacement(sb, 
                "![" + alt + "](" + cdnUrl + ")");
        }
        imgMatcher.appendTail(sb);
        
        return sb.toString();
    }
}
```

#### 阶段4：质量检测

```java
@Service
public class ContentQualityInspector {
    
    /**
     * 对标准化内容执行多维质量检测
     * @return 质量标记列表（空列表=通过所有检测）
     */
    public List<QualityFlag> inspect(NormalizedContent content, 
                                      ContentCategory category) {
        List<QualityFlag> flags = new ArrayList<>();
        
        // --- 基础完整性检测 ---
        if (category == ContentCategory.QUESTION) {
            StandardQuestion q = (StandardQuestion) content;
            
            // 答案缺失检测
            if (q.getAnswer() == null || isBlank(q.getAnswer())) {
                flags.add(QualityFlag.MISSING_ANSWER);
            }
            
            // 解析缺失检测
            if (isBlank(q.getAnalysis())) {
                flags.add(QualityFlag.MISSING_ANALYSIS);
            }
            
            // 题干长度异常检测
            int stemLen = q.getStem().length();
            if (stemLen < 5) {
                flags.add(QualityFlag.STEM_TOO_SHORT);
            } else if (stemLen > 5000) {
                flags.add(QualityFlag.STEM_TOO_LONG);
            }
            
            // 选项完整性检测（选择题）
            if (q.getQuestionType().isChoiceType() && q.getOptions() != null) {
                int optCount = q.getOptions().size();
                if (optCount < 2 || optCount > 6) {
                    flags.add(QualityFlag.ABNORMAL_OPTION_COUNT);
                }
            }
            
            // 难度值范围校验
            if (q.getDifficulty() < 1 || q.getDifficulty() > 5) {
                flags.add(QualityFlag.INVALID_DIFFICULTY);
            }
            
            // LaTeX公式语法检测
            List<String> formulaErrors = latexValidator.validate(q.getStem());
            if (!formulaErrors.isEmpty()) {
                flags.add(QualityFlag.FORMULA_SYNTAX_ERROR);
            }
            
            // 答案-选项一致性检测
            if (q.getQuestionType() == QuestionType.SINGLE_CHOICE) {
                if (!q.getOptions().containsKey(q.getAnswer())) {
                    flags.add(QualityFlag.ANSWER_OPTION_MISMATCH);
                }
            }
        }
        
        // --- 敏感内容预检 ---
        List<SensitiveHit> sensitiveHits = sensitiveWordDetector
            .quickScan(content.getAllTextFields());
        if (!sensitiveHits.isEmpty()) {
            flags.add(QualityFlag.SENSITIVE_CONTENT_DETECTED);
        }
        
        return flags;
    }
}
```

#### 阶段5：知识点映射

将供应商使用的知识点术语映射到平台统一知识图谱：

```java
@Service
public class KnowledgeAlignmentService {
    
    @Autowired
    private KnowledgeGraphClient knowledgeGraphClient;
    
    @Autowired
    private RedisTemplate<String, KnowledgeMappingCache> mappingCache;
    
    /**
     * 将外部知识点术语对齐到平台知识图谱节点
     * 
     * @param externalTerms 供应商提供的知识点名称列表
     * @param subjectCode 学科编码
     * @param gradeCode 年级编码
     * @return 映射结果列表
     */
    public List<KnowledgeMappingResult> alignKnowledgePoints(
            List<String> externalTerms, 
            String subjectCode, 
            String gradeCode) {
        
        List<KnowledgeMappingResult> results = new ArrayList<>();
        
        for (String term : externalTerms) {
            // 1. 先查缓存(同一术语在同一学科+年级的映射结果)
            String cacheKey = String.format("kp:map:%s:%s:%s", 
                subjectCode, gradeCode, DigestUtils.md5Hex(term));
            KnowledgeMappingCache cached = mappingCache.opsForValue().get(cacheKey);
            if (cached != null) {
                results.add(cached.toResult(term));
                continue;
            }
            
            // 2. 精确匹配
            Optional<KnowledgePoint> exact = knowledgeGraphClient
                .findByExactName(term, subjectCode, gradeCode);
            if (exact.isPresent()) {
                KnowledgeMappingResult r = KnowledgeMappingResult.exactMatch(
                    term, exact.get());
                cacheMapping(cacheKey, r);
                results.add(r);
                continue;
            }
            
            // 3. 模糊匹配（向量相似度 + 编辑距离组合）
            List<KnowledgePoint> candidates = knowledgeGraphClient
                .searchBySimilarity(term, subjectCode, 5);
            
            if (!candidates.isEmpty()) {
                // 取最佳匹配
                KnowledgePoint best = candidates.get(0);
                double confidence = calculateConfidence(term, best);
                
                KnowledgeMappingResult r = KnowledgeMappingResult.fuzzyMatch(
                    term, best, confidence);
                cacheMapping(cacheKey, r);
                results.add(r);
            } else {
                // 4. 无法映射 → 标记待人工处理
                results.add(KnowledgeMappingResult.unmapped(term));
            }
        }
        
        return results;
    }
    
    /**
     * 置信度计算：向量余弦相似度(0.7权重) + 编辑距离相似度(0.3权重)
     */
    private double calculateConfidence(String term, KnowledgePoint kp) {
        double vectorSim = embeddingService.cosineSimilarity(
            term, kp.getName() + " " + kp.getAliases());
        
        double editSim = 1.0 - (double) editDistance(term, kp.getName()) 
            / Math.max(term.length(), kp.getName().length());
        
        return 0.7 * vectorSim + 0.3 * editSim;
    }
}
```

#### 阶段6：去重检测

```java
@Service
public class ContentDeduplicationService {
    
    /**
     * 三级去重策略
     * Level 1: 精确校验和匹配 (SHA-256)
     * Level 2: 归一化文本SimHash (64位) 汉明距离 ≤3
     * Level 3: 向量相似度 > 0.92 (针对无重复但相似度极高的内容)
     */
    public DeduplicationResult check(NormalizedContent content) {
        // Level 1: 精确匹配
        String checksum = content.computeChecksum();
        if (importRecordMapper.existsByChecksum(checksum)) {
            return DeduplicationResult.exactDuplicate(checksum);
        }
        
        // Level 2: SimHash近似匹配
        long simHash = simHashEngine.compute(content.getKeyText());
        Optional<SimHashMatch> nearMatch = simHashIndexer.findNear(
            simHash, 
            content.getSubjectCode(), 
            hammingThreshold = 3
        );
        if (nearMatch.isPresent()) {
            return DeduplicationResult.nearDuplicate(
                simHash, nearMatch.get());
        }
        
        // Level 3: 向量相似度（仅对题目执行，成本较高）
        if (content instanceof StandardQuestion q) {
            float[] embedding = embeddingService.embed(q.getStemNormalized());
            Optional<VectorMatch> vecMatch = vectorIndexer.search(
                embedding, 
                q.getSubjectCode(),
                similarityThreshold = 0.92f,
                topK = 1
            );
            if (vecMatch.isPresent()) {
                return DeduplicationResult.semanticDuplicate(
                    embedding, vecMatch.get());
            }
        }
        
        return DeduplicationResult.unique();
    }
}
```

### 5.1 导入管道核心编排

```java
/**
 * 内容导入管道 - 主编排器
 * 
 * 负责：接收原始内容 → 经过多阶段处理 → 写入目标存储
 */
@Service
@Slf4j
public class ContentImportPipeline {
    
    @Autowired private ContentNormalizerRegistry normalizerRegistry;
    @Autowired private ContentQualityInspector qualityInspector;
    @Autowired private KnowledgeAlignmentService knowledgeAligner;
    @Autowired private ContentDeduplicationService dedupService;
    @Autowired private QuestionRepository questionRepository;
    @Autowired private ImportRecordMapper importRecordMapper;
    @Autowired private AuditEventPublisher auditPublisher;
    @Autowired private ProviderNotifyService providerNotifier;
    
    /**
     * 处理一个导入批次（异步执行）
     */
    @Async("importPipelineExecutor")
    public void processBatch(Long batchId) {
        ProviderContentBatch batch = batchMapper.selectById(batchId);
        List<ContentImportRecord> records = importRecordMapper
            .findByBatchId(batchId);
        
        batch.setStatus(BatchStatus.PROCESSING);
        batch.setStartedAt(LocalDateTime.now());
        batchMapper.updateById(batch);
        
        int success = 0, failed = 0;
        List<ErrorItem> errors = new ArrayList<>();
        
        try {
            for (ContentImportRecord record : records) {
                try {
                    processSingleRecord(record, batch);
                    success++;
                } catch (PipelineException e) {
                    failed++;
                    record.setStatus(RecordStatus.FAILED);
                    record.setRejectReason(e.getMessage());
                    importRecordMapper.updateById(record);
                    errors.add(new ErrorItem(e.getType(), 
                        record.getExternalId(), e.getMessage()));
                }
            }
            
            // 更新批次统计
            batch.setSuccessItems(success);
            batch.setFailedItems(failed);
            batch.setStatus(failed == 0 ? BatchStatus.COMPLETED 
                : (success == 0 ? BatchStatus.ALL_FAILED 
                : BatchStatus.PARTIAL_FAILED));
            batch.setCompletedAt(LocalDateTime.now());
            batch.setErrorSummary(aggregateErrors(errors));
            batchMapper.updateById(batch);
            
            // 通知供应商处理结果
            providerNotifier.notifyBatchResult(batch);
            
            // 发布审计事件
            auditPublisher.publish(new ImportBatchCompletedEvent(batch));
            
        } catch (Exception e) {
            log.error("批次处理异常 batchId={}", batchId, e);
            batch.setStatus(BatchStatus.ALL_FAILED);
            batchMapper.updateById(batch);
            throw e;
        }
    }
    
    /**
     * 处理单条记录 - 执行完整的7阶段管道
     */
    private void processSingleRecord(ContentImportRecord record, 
                                      ProviderContentBatch batch) 
            throws PipelineException {
        
        // ─── 阶段2: 格式校验 ───
        ContentNormalizer normalizer = normalizerRegistry
            .get(batch.getSourceFormat(), record.getTargetTable());
        
        // ─── 阶段3: 标准化转换 ───
        NormalizedContent normalized;
        try {
            RawContent raw = RawContent.of(record.getRawContent());
            normalized = normalizer.normalize(raw).get(0); // 单条→取第一条
        } catch (NormalizationException e) {
            throw new PipelineException("NORMALIZE_ERROR", 
                "标准化失败: " + e.getMessage(), e);
        }
        
        // 暂存标准化结果
        record.setNormalizedContent(JsonUtils.toJson(normalized));
        record.setStatus(RecordStatus.NORMALIZING);
        importRecordMapper.updateById(record);
        
        // ─── 阶段4: 质量检测 ───
        List<QualityFlag> flags = qualityInspector.inspect(
            normalized, batch.getCategoryEnum());
        
        List<QualityFlag> fatalFlags = flags.stream()
            .filter(QualityFlag::isFatal)
            .collect(Collectors.toList());
        
        if (!fatalFlags.isEmpty()) {
            record.setQualityFlags(flags.stream()
                .map(QualityFlag::name)
                .collect(Collectors.toList()));
            throw new PipelineException("QUALITY_CHECK_FAILED",
                "致命质量问题: " + fatalFlags);
        }
        
        // ─── 阶段5: 知识点映射 ───
        if (normalized.getKnowledgePoints() != null 
                && !normalized.getKnowledgePoints().isEmpty()) {
            List<KnowledgeMappingResult> mappings = knowledgeAligner
                .alignKnowledgePoints(
                    normalized.getKnowledgePoints(),
                    batch.getSubjectCode(),
                    batch.getGradeCodes().get(0)  // 取第一个年级
                );
            
            record.setKnowledgeMappings(mappings.stream()
                .map(KnowledgeMappingResult::toJson)
                .collect(Collectors.toList()));
            
            // 检查映射失败率
            long unmappedCount = mappings.stream()
                .filter(KnowledgeMappingResult::isUnmapped)
                .count();
            double failRate = (double) unmappedCount / mappings.size();
            if (failRate > 0.5) {
                flags.add(QualityFlag.KNOWLEDGE_MAPPING_FAIL);
            }
        }
        
        // ─── 阶段6: 去重检测 ───
        DeduplicationResult dedupResult = dedupService.check(normalized);
        if (dedupResult.isDuplicate()) {
            flags.add(QualityFlag.DUPLICATE_CONTENT);
            record.setExternalChecksum(dedupResult.getChecksum());
            throw new PipelineException("DUPLICATE",
                "内容重复: " + dedupResult.getReason());
        }
        
        record.setQualityFlags(flags.stream()
            .map(QualityFlag::name)
            .collect(Collectors.toList()));
        record.setExternalChecksum(normalized.computeChecksum());
        
        // ─── 阶段7: 入库 ───
        // 判断是否需要人工审核
        boolean needManualReview = !flags.isEmpty() 
            || batch.getProviderQualityScore() < 7.0;
        
        if (needManualReview) {
            record.setStatus(RecordStatus.UNDER_REVIEW);
            // 进入审核队列
            reviewQueueService.enqueue(record, flags);
        } else {
            // 自动入库
            Long targetId = persistToTarget(normalized, record, batch);
            record.setTargetId(targetId);
            record.setStatus(RecordStatus.IMPORTED);
        }
        
        importRecordMapper.updateById(record);
    }
    
    /**
     * 持久化到目标表
     */
    private Long persistToTarget(NormalizedContent content, 
                                  ContentImportRecord record,
                                  ProviderContentBatch batch) {
        
        if (content instanceof StandardQuestion sq) {
            Question question = Question.builder()
                .questionType(sq.getQuestionType())
                .stem(sq.getStem())
                .options(sq.getOptions())
                .answer(sq.getAnswer())
                .analysis(sq.getAnalysis())
                .difficulty(sq.getDifficulty())
                .subjectCode(batch.getSubjectCode())
                .gradeCodes(batch.getGradeCodes())
                .textbookVersion(batch.getTextbookVersion())
                .knowledgePointIds(extractKnowledgePointIds(record))
                .sourceType(SourceType.EXTERNAL_PROVIDER)
                .providerId(batch.getProviderId())
                .externalId(record.getExternalId())
                .qualityFlags(record.getQualityFlags())
                .status(QuestionStatus.ACTIVE)
                .build();
            
            Question saved = questionRepository.save(question);
            return saved.getId();
        }
        // 其他内容类型处理...
        throw new UnsupportedOperationException(
            "Unsupported content type: " + content.getClass());
    }

            .collect(Collectors.groupingBy(ErrorItem::getType))
```

### 5.3 API鉴权拦截器

```java
/**
 * 供应商API鉴权拦截器
 * 验证 APIClient access_key:signature 格式的认证
 */
@Component
@Slf4j
public class ProviderAuthInterceptor implements HandlerInterceptor {
    
    @Autowired private ProviderApiCredentialService credentialService;
    @Autowired private RateLimiter rateLimiter;
    
    private static final long MAX_SKEW_SECONDS = 300; // 5分钟时间偏移
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                              HttpServletResponse response, 
                              Object handler) throws Exception {
        
        String auth = request.getHeader("Authorization");
        if (auth == null || !auth.startsWith("APIClient ")) {
            sendError(response, 40001, "Missing or invalid Authorization header");
            return false;
        }
        
        // 解析 access_key:signature
        String[] parts = auth.substring("APIClient ".length()).split(":");
        if (parts.length != 2) {
            sendError(response, 40002, "Invalid auth format");
            return false;
        }
        String accessKey = parts[0];
        String signature = parts[1];
        
        // 获取凭证
        ProviderApiCredential cred = credentialService.getByAccessKey(accessKey);
        if (cred == null || cred.getStatus() != CredentialStatus.ACTIVE) {
            sendError(response, 40001, "Invalid or disabled credential");
            return false;
        }
        
        // IP白名单校验
        if (!cred.getAllowedIps().isEmpty()) {
            String clientIp = IpUtils.getClientIp(request);
            if (!cred.getAllowedIps().contains(clientIp)) {
                sendError(response, 40003, "IP not allowed: " + clientIp);
                return false;
            }
        }
        
        // 时间戳校验（防重放）
        String timestamp = request.getHeader("X-Timestamp");
        String nonce = request.getHeader("X-Nonce");
        if (Math.abs(Instant.now().getEpochSecond() 
                - Instant.parse(timestamp).getEpochSecond()) > MAX_SKEW_SECONDS) {
            sendError(response, 40002, "Request timestamp expired");
            return false;
        }
        
        // Nonce防重放（5分钟内不可重复）
        if (!rateLimiter.checkAndSetNonce(nonce, MAX_SKEW_SECONDS)) {
            sendError(response, 40002, "Duplicate request nonce");
            return false;
        }
        
        // 签名校验
        String expectedSig = computeSignature(
            cred.getSecretKey(), request.getMethod(), 
            request.getRequestURI(), timestamp, nonce, 
            readBody(request));
        if (!HmacUtils.hmacSha256Hex(cred.getSecretKey(), 
                buildSignString(request, timestamp, nonce))
                .equals(signature)) {
            sendError(response, 40002, "Signature mismatch");
            return false;
        }
        
        // 频率限制
        if (!rateLimiter.tryAcquire(accessKey, 
                cred.getRateLimitPerMin(), cred.getRateLimitPerDay())) {
            sendError(response, 40010, "Rate limit exceeded");
            return false;
        }
        
        // 合同有效性校验
        if (!credentialService.hasValidContract(cred.getProviderId())) {
            sendError(response, 40004, "Contract expired or terminated");
            return false;
        }
        
        // 写入请求上下文
        request.setAttribute("providerId", cred.getProviderId());
        return true;
    }
    
    private String buildSignString(HttpServletRequest req, 
                                    String timestamp, String nonce) {
        return String.join("\n",
            req.getMethod(),
            req.getRequestURI(),
            timestamp,
            nonce,
            req.getAttribute("bodySha256").toString()
        );
    }
}
```

### 5.4 XLSX 题目模板解析器

```java
/**
 * Excel模板导入解析器
 * 
 * 模板列定义：
 * A=external_id  B=question_type  C=difficulty  D=stem
 * E=option_A     F=option_B       G=option_C    H=option_D
 * I=answer       J=analysis       K=knowledge_points(分号分隔)
 * L=chapter      M=source         N=tags(逗号分隔)
 */
@Component
@Slf4j
public class ExcelQuestionParser implements FileContentParser {
    
    @Override
    public ParsedFileResult parse(MultipartFile file, 
                                   ImportMeta meta) throws ParseException {
        
        List<RawContent> items = new ArrayList<>();
        int errorCount = 0;
        
        try (Workbook wb = WorkbookFactory.create(file.getInputStream())) {
            Sheet sheet = wb.getSheetAt(0);
            
            // 验证表头
            Row header = sheet.getRow(0);
            if (!validateHeader(header)) {
                throw new ParseException("INVALID_TEMPLATE", 
                    "Excel模板表头不匹配，请下载最新模板");
            }
            
            for (int i = 1; i <= sheet.getLastRowNum(); i++) {
                Row row = sheet.getRow(i);
                if (row == null) continue;
                
                try {
                    RawContent item = parseRow(row, i);
                    items.add(item);
                } catch (RowParseException e) {
                    errorCount++;
                    log.warn("第{}行解析失败: {}", i + 1, e.getMessage());
                    items.add(RawContent.error(i + 1, e.getMessage()));
                }
            }
            
        } catch (IOException e) {
            throw new ParseException("FILE_READ_ERROR", 
                "Excel文件读取失败: " + e.getMessage());
        }
        
        return new ParsedFileResult(items, errorCount);
    }
    
    private RawContent parseRow(Row row, int rowIndex) 
            throws RowParseException {
        
        ObjectNode node = JsonUtils.createObjectNode();
        
        // 外部ID
        String externalId = getCellAsString(row, 0);
        if (isBlank(externalId)) {
            throw new RowParseException("external_id不能为空");
        }
        node.put("external_id", externalId);
        
        // 题型
        String typeStr = getCellAsString(row, 1);
        String questionType = mapExcelType(typeStr);
        if (questionType == null) {
            throw new RowParseException(
                "不支持的题型: " + typeStr + "，请填写：单选/多选/填空/判断/简答");
        }
        node.put("question_type", questionType);
        
        // 难度
        int difficulty = (int) getCellAsNumber(row, 2);
        if (difficulty < 1 || difficulty > 5) {
            throw new RowParseException("难度值需在1-5之间");
        }
        node.put("difficulty", difficulty);
        
        // 题干（支持富文本）
        String stem = getCellAsString(row, 3);
        if (isBlank(stem)) {
            throw new RowParseException("题干不能为空");
        }
        node.put("stem", stem);
        
        // 选项（选择题必填）
        if (isChoiceType(questionType)) {
            ObjectNode options = JsonUtils.createObjectNode();
            for (int col = 4; col <= 7; col++) {
                String opt = getCellAsString(row, col);
                if (!isBlank(opt)) {
                    char label = (char) ('A' + (col - 4));
                    options.put(String.valueOf(label), opt);
                }
            }
            if (options.size() < 2) {
                throw new RowParseException("选择题至少需要2个选项");
            }
            node.set("options", options);
        }
        
        // 答案
        String answer = getCellAsString(row, 8);
        if (isBlank(answer)) {
            throw new RowParseException("答案不能为空");
        }
        node.put("answer", answer);
        
        // 解析
        node.put("analysis", getCellAsString(row, 9));
        
        // 知识点（分号分隔）
        String kps = getCellAsString(row, 10);
        if (!isBlank(kps)) {
            node.set("knowledge_points_external", 
                JsonUtils.toArrayNode(kps.split("[;；]")));
        }
        
        // 章节
        node.put("chapter_external", getCellAsString(row, 11));
        
        return new RawContent(node.toString(), externalId);
    }
}
```

| --- | --- | --- |

```java
/**
 * 下游服务调用重试模板

@Component
public class DownstreamRetryTemplate {
    
    private static final int MAX_RETRY = 3;
    private static final long[] BACKOFF_MS = {1000, 3000, 10000};
    
    public <T> T executeWithRetry(Supplier<T> action, 
                                   String operationName) {
        Exception lastException = null;
        
        for (int attempt = 0; attempt < MAX_RETRY; attempt++) {
            try {
                return action.get();
            } catch (ServiceUnavailableException | TimeoutException e) {
                lastException = e;
                log.warn("{} 第{}次重试: {}", 
                    operationName, attempt + 1, e.getMessage());
                try {
                    Thread.sleep(BACKOFF_MS[attempt]);
                } catch (InterruptedException ie) {
                    Thread.currentThread().interrupt();
                    throw new PipelineException(
                        "INTERRUPTED", "处理被中断", ie);
                }
            }
        }
        
        throw new PipelineException("DOWNSTREAM_UNAVAILABLE",
            operationName + " 在" + MAX_RETRY + "次重试后仍失败",
            lastException);
    }
}
```

### 7.3 SimHash索引优化

```java
/**
 * SimHash分段索引（海明距离≤3时使用分4段×16位的索引策略）
 * 将64位SimHash分为4个16位段，至少有一段完全匹配时才进行精确比较
 */
@Component
public class SimHashSegmentIndex {
    
    private static final int SEGMENTS = 4;
    private static final int SEG_BITS = 16;
    
    @Autowired
    private RedisTemplate<String, String> redis;
    
    /**
     * 索引一个SimHash值
     */
    public void index(long simHash, String subjectCode, 
                       Long contentId, String contentType) {
        int[] segments = splitSegments(simHash);
        for (int i = 0; i < SEGMENTS; i++) {
            String key = String.format("simhash:%s:%d:%d", 
                subjectCode, i, segments[i]);
            // 使用Sorted Set，score=contentId
            redis.opsForZSet().add(key, 
                contentType + ":" + contentId, contentId);
        }
    }
    
    /**
     * 查找近似SimHash（海明距离≤3）
     * 先通过分段索引筛选候选，再精确计算汉明距离
     */
    public Optional<SimHashMatch> findNear(long simHash, 
                                            String subjectCode,
                                            int hammingThreshold) {
        int[] segments = splitSegments(simHash);
        Set<String> candidates = new HashSet<>();
        
        // 收集各段匹配的候选
        for (int i = 0; i < SEGMENTS; i++) {
            String key = String.format("simhash:%s:%d:%d", 
                subjectCode, i, segments[i]);
            Set<String> matches = redis.opsForZSet().range(key, 0, 100);
            if (matches != null) {
                candidates.addAll(matches);
            }
        }
        
        // 精确计算汉明距离
        for (String candidate : candidates) {
            long candidateHash = Long.parseLong(
                candidate.split(":")[0]); // 实际需存储hash值
            int distance = Long.bitCount(simHash ^ candidateHash);
            if (distance <= hammingThreshold) {
                return Optional.of(new SimHashMatch(candidate, distance));
            }
        }
        
        return Optional.empty();
    }
    
    private int[] splitSegments(long simHash) {
        int[] segments = new int[SEGMENTS];
        int mask = (1 << SEG_BITS) - 1;
        for (int i = 0; i < SEGMENTS; i++) {
            segments[i] = (int) ((simHash >>> (i * SEG_BITS)) & mask);
        }
        return segments;
    }
}
```
