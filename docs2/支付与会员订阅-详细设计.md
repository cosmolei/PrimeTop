# 支付与会员订阅系统 - 详细设计文档

## 1. 模块概述

支付与会员订阅系统是 PrimeTop 的商业化基础设施，负责会员等级管理、权益校验、订单生命周期、支付渠道对接、订阅续费、用量计量与降级处理。所有涉及 AI 调用、拍题、高级功能的业务模块均依赖此模块判断用户权益和用量配额。

### 1.1 功能范围

| 功能 | 优先级 | MVP |
|------|--------|-----|
| 会员等级定义（免费/月度/年度/专项） | P0 | ✅ |
| 权益矩阵与用量配额管理 | P0 | ✅ |
| 订单创建与支付（微信/支付宝/Apple IAP） | P0 | ✅ |
| 订阅自动续费与取消 | P0 | ✅ |
| 权益校验中间件 | P0 | ✅ |
| 用量计量与限流 | P0 | ✅ |
| 订阅降级与到期处理 | P1 | ✅ |
| 订单退款 | P1 | ❌ |
| 增值服务购买（次数包、专项包） | P1 | ❌ |
| 家庭套餐与多孩共享 | P2 | ❌ |
| 优惠券与促销活动 | P2 | ❌ |
| 后台订单管理与财务对账 | P0 | ✅ |

## 2. 会员等级与权益矩阵

### 2.1 会员等级定义

| 等级 | 标识 | 说明 |
|------|------|------|
| 免费用户 | `free` | 未订阅用户，基础功能受限 |
| 月度会员 | `monthly` | 按月订阅，全功能权益 |
| 年度会员 | `annual` | 按年订阅，全功能权益+优先模型+存储 |
| 中考专项会员 | `exam_zhongkao` | 阶段性中考备考专项包 |
| 高考专项会员 | `exam_gaokao` | 阶段性高考备考专项包 |

## 3. 数据结构定义

### 3.1 会员等级配置表 `membership_plans`

```sql
CREATE TABLE membership_plans (
    id              SMALLINT PRIMARY KEY AUTO_INCREMENT COMMENT '等级ID',
    plan_code       VARCHAR(30) NOT NULL UNIQUE COMMENT '等级编码: free/monthly/annual/exam_zhongkao/exam_gaokao',
    plan_name       VARCHAR(50) NOT NULL COMMENT '等级名称',
    price_cents     INT NOT NULL DEFAULT 0 COMMENT '价格（分），免费为0',
    duration_days   INT NOT NULL COMMENT '有效天数，免费用户为99999',
    quotas_json     JSON NOT NULL COMMENT '权益配额JSON（同2.3格式）',
    sort_order      SMALLINT NOT NULL DEFAULT 0 COMMENT '排序',
    is_active       TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否启用',
    description     VARCHAR(500) COMMENT '描述',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_active (is_active, sort_order)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会员等级配置';
```

### 3.2 用户会员状态表 `user_memberships`

```sql
CREATE TABLE user_memberships (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    plan_id         SMALLINT NOT NULL COMMENT '当前等级ID',
    plan_code       VARCHAR(30) NOT NULL COMMENT '等级编码（冗余，加速查询）',
    status          VARCHAR(20) NOT NULL DEFAULT 'active' COMMENT '状态: active/expired/cancelled/grace',
    started_at      DATETIME NOT NULL COMMENT '生效时间',
    expires_at      DATETIME NOT NULL COMMENT '到期时间',
    cancelled_at    DATETIME COMMENT '取消时间（用户主动取消）',
    cancel_reason   VARCHAR(200) COMMENT '取消原因',
    auto_renew      TINYINT(1) NOT NULL DEFAULT 1 COMMENT '是否自动续费',
    renew_order_id  BIGINT COMMENT '下一次续费的关联订单ID',
    grace_ends_at   DATETIME COMMENT '宽限期结束时间（到期后3天）',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE INDEX idx_user_active (user_id, status),
    INDEX idx_expires (status, expires_at),
    INDEX idx_plan (plan_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户会员状态';
```

### 3.3 订单表 `orders`

```sql
CREATE TABLE orders (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    order_no        VARCHAR(32) NOT NULL UNIQUE COMMENT '订单号（业务唯一，如 PT202605191234567890）',
    user_id         BIGINT NOT NULL COMMENT '用户ID',
    plan_id         SMALLINT NOT NULL COMMENT '购买的等级ID',
    plan_code       VARCHAR(30) NOT NULL COMMENT '等级编码',
    order_type      VARCHAR(20) NOT NULL COMMENT '订单类型: new/renew/upgrade/addon',
    amount_cents    INT NOT NULL COMMENT '订单金额（分）',
    original_amount INT COMMENT '原价（分，用于展示优惠）',
    discount_amount INT NOT NULL DEFAULT 0 COMMENT '优惠金额（分）',
    currency        VARCHAR(10) NOT NULL DEFAULT 'CNY' COMMENT '币种',
    status          VARCHAR(20) NOT NULL DEFAULT 'pending' COMMENT '状态: pending/paid/closed/refunded/refund_failed',
    payment_channel VARCHAR(20) COMMENT '支付渠道: wechat/alipay/apple_iap',
    payment_trade_no VARCHAR(64) COMMENT '第三方支付流水号',
    paid_at         DATETIME COMMENT '支付成功时间',
    expired_at      DATETIME COMMENT '订单过期时间（未支付自动关闭）',
    refunded_at     DATETIME COMMENT '退款时间',
    refund_reason   VARCHAR(200) COMMENT '退款原因',
    refund_amount   INT COMMENT '退款金额（分）',
    client_ip       VARCHAR(45) COMMENT '下单IP',
    user_agent      VARCHAR(500) COMMENT '客户端UA',
    remark          VARCHAR(500) COMMENT '备注',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_user (user_id, status),
    INDEX idx_status (status, created_at),
    INDEX idx_payment (payment_channel, payment_trade_no),
    INDEX idx_paid (paid_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='支付订单';
```

### 3.4 支付流水表 `payment_transactions`

```sql
CREATE TABLE payment_transactions (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    order_id        BIGINT NOT NULL COMMENT '关联订单ID',
    order_no        VARCHAR(32) NOT NULL COMMENT '订单号',
    channel         VARCHAR(20) NOT NULL COMMENT '支付渠道',
    trade_no        VARCHAR(64) COMMENT '第三方流水号',
    status          VARCHAR(20) NOT NULL DEFAULT 'init' COMMENT '状态: init/success/failed/callback_error',
    request_data    JSON COMMENT '请求参数（脱敏）',
    callback_data   JSON COMMENT '回调通知原始数据',
    callback_at     DATETIME COMMENT '回调时间',
    amount_cents    INT NOT NULL COMMENT '实际支付金额',
    error_code      VARCHAR(50) COMMENT '错误码',
    error_msg       VARCHAR(500) COMMENT '错误信息',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_order (order_id),
    INDEX idx_channel_trade (channel, trade_no),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='支付流水';
```

### 3.5 用户每日用量表 `user_daily_quotas`

```sql
CREATE TABLE user_daily_quotas (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT NOT NULL,
    quota_date      DATE NOT NULL COMMENT '日期',
    quota_key       VARCHAR(50) NOT NULL COMMENT '配额项: ai_qa/photo_question/essay_correction',
    used_count      INT NOT NULL DEFAULT 0 COMMENT '已使用次数',
    limit_count     INT NOT NULL DEFAULT 0 COMMENT '限额（-1=不限，0=不可用）',
    reset_at        DATETIME COMMENT '配额重置时间',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    UNIQUE INDEX idx_user_date_key (user_id, quota_date, quota_key),
    INDEX idx_date (quota_date)

```

### 3.6 会员变更日志表 `membership_change_log`

```sql
CREATE TABLE membership_change_log (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,

    old_plan_code   VARCHAR(30) COMMENT '变更前等级',

    new_expires_at  DATETIME COMMENT '变更后到期时间',
    remark          VARCHAR(500) COMMENT '备注',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_user (user_id, created_at),
    INDEX idx_type (change_type, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='会员变更日志';
```

## 4. 核心流程设计

### 4.1 订阅购买流程

```text
用户选择会员等级
       │
       ▼
┌─────────────┐
│ 创建订单     │ ──► 校验：用户当前等级是否可购买此等级
│ (pending)    │     校验：是否有未完成的同等级订单
└──────┬──────┘     计算价格与优惠
       │
       ▼
┌─────────────┐
│ 调用支付渠道 │ ──► 微信: 统一下单 → 返回 prepay_id → 拉起支付
│ 预下单       │     支付宝: trade.create → 返回 trade_no → 拉起支付
└──────┬──────┘     Apple IAP: 客户端发起 SKPayment → 服务端验证
       │
       ▼
┌─────────────┐
│ 客户端拉起   │
│ 支付界面     │
└──────┬──────┘
       │
       ▼
┌─────────────┐     ┌──────────────┐
│ 等待回调     │◄────│ 第三方支付回调 │
│ 或主动轮询   │     │ (异步通知)     │
└──────┬──────┘     └──────────────┘
       │
       ▼
┌─────────────┐
│ 验签 & 幂等  │ ──► 校验签名、金额、订单号一致性
│ 更新订单状态 │     防止重复处理（订单状态幂等）
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 激活会员权益 │ ──► 写入 user_memberships
│ 记录变更日志 │     写入 membership_change_log
│ 发送通知     │     更新缓存，发送订阅成功通知
└─────────────┘
```

### 4.2 订单状态流转

```text
                   ┌──────────┐
          创建订单  │ pending  │
                   └────┬─────┘
                        │
            ┌───────────┼───────────┐
            │ 支付成功   │           │ 超时/取消
            ▼           │           ▼
      ┌──────────┐      │     ┌──────────┐
      │   paid   │      │     │  closed  │
      └────┬─────┘      │     └──────────┘
           │            │
           │ 退款申请   │
           ▼            │
      ┌──────────┐      │
      │ refunded │      │
      └──────────┘      │
```

状态说明：
- `pending`: 已创建，等待支付
- `paid`: 支付成功，权益已激活
- `closed`: 超时未支付（30分钟）或用户取消
- `refunded`: 已退款
- `refund_failed`: 退款失败（需人工处理）

### 4.3 会员状态流转

```text
                    ┌──────────┐
         新用户      │   free   │
                    └────┬─────┘
                         │ 订阅
                         ▼
                    ┌──────────┐
         订阅生效   │  active  │ ◄── 续费成功
                    └────┬─────┘
                         │
              ┌──────────┼──────────┐
              │ 到期      │ 取消      │ 升级
              │           │ auto_renew=0
              ▼           ▼           ▼
        ┌──────────┐ ┌──────────┐ ┌──────────┐
        │ expired  │ │cancelled │ │ active   │
        │(宽限期中) │ │(到期后失效)│ │(新等级)   │
        └────┬─────┘ └────┬─────┘ └──────────┘
             │ 续费        │ 到期
             ▼             ▼
        ┌──────────┐ ┌──────────┐
        │  active  │ │ expired  │→ 降级为 free
        └──────────┘ └──────────┘
```

### 4.4 用量计量流程

```text
用户发起操作（如AI问答）
       │
       ▼
┌─────────────┐
│ 查询会员等级 │ ──► Redis 缓存 user_membership:{user_id}
└──────┬──────┘     缓存未命中 → 查 DB → 回填缓存（TTL=5min）
       │
       ▼
┌─────────────┐
│ 获取配额限制 │ ──► 从会员等级的 quotas_json 读取对应 quota_key 的 limit_count
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ limit == -1  │──► YES ──► 放行（不限量）
│ (不限量)?    │
└──────┬──────┘
       │ NO
       ▼
┌─────────────┐
│ limit == 0   │──► YES ──► 拒绝（该等级无此权益）
│ (不可用)?    │
└──────┬──────┘
       │ NO
       ▼
┌─────────────┐
│ 读取已用量   │ ──► Redis INCR user_quota:{user_id}:{date}:{key}
│ Redis 原子递增│     Key TTL = 到当日 23:59:59
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ used > limit │──► YES ──► 拒绝（配额用尽）→ 提示升级会员
│              │
│ used ≤ limit │──► 放行
└─────────────┘
```

```java
@Component
public class QuotaCheckInterceptor implements HandlerInterceptor {

    private QuotaService quotaService;
    
    @Autowired
    private MembershipService membershipService;
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                             HttpServletResponse response, 
                             Object handler) throws Exception {
        
        // 从注解获取需要检查的配额项
        QuotaRequired quotaRequired = ((HandlerMethod) handler)
            .getMethodAnnotation(QuotaRequired.class);
        if (quotaRequired == null) return true;
        
        Long userId = SecurityContext.getCurrentUserId();
        String quotaKey = quotaRequired.value();
        
        QuotaCheckResult result = quotaService.checkAndConsume(userId, quotaKey);

            response.setStatus(403);
            response.getWriter().write(JsonUtil.toJson(Map.of(
                "success", false,
                "errorCode", result.getReason(),
                "message", result.getMessage(),
                "upgradeHint", result.getUpgradeHint()
            )));
            return false;
        }
        
        // 将剩余配额信息放入请求属性，供响应使用
        request.setAttribute("quotaRemaining", result.getRemaining());
        return true;
    }
}
```

### 6.3 支付回调处理（以微信为例）

```java
@Service
@Slf4j
public class WechatPayCallbackHandler {
    
    @Autowired
    private OrderService orderService;
    
    @Autowired
    private MembershipService membershipService;
    
    @Autowired
    private PaymentTransactionService transactionService;
    
    @Transactional
    public CallbackResult handleCallback(WechatPayCallbackDTO callback) {
        // 1. 验签
        if (!WechatPayUtil.verifySign(callback)) {
            log.warn("微信支付回调验签失败: {}", callback);
            return CallbackResult.fail("验签失败");
        }
        
        // 2. 解密通知内容
        WechatPayDecryptData data = WechatPayUtil.decrypt(callback);
        String orderNo = data.getOutTradeNo();
        String transactionId = data.getTransactionId();
        int totalCents = data.getAmount().getTotal();
        
        // 3. 查询订单
        Order order = orderService.getByOrderNo(orderNo);
        if (order == null) {
            log.error("订单不存在: {}", orderNo);
            return CallbackResult.fail("订单不存在");
        }
        
        // 4. 幂等校验：已支付的直接返回成功
        if ("paid".equals(order.getStatus())) {
            log.info("订单已处理，忽略重复回调: {}", orderNo);
            return CallbackResult.success();
        }
        
        // 5. 金额校验
        if (order.getAmountCents() != totalCents) {
            log.error("金额不一致: 订单={}, 回调={}", order.getAmountCents(), totalCents);
            return CallbackResult.fail("金额不一致");
        }
        
        // 6. 记录支付流水
        transactionService.recordSuccess(order.getId(), orderNo, 
            "wechat", transactionId, totalCents, callback.getRawData());
        
        // 7. 更新订单状态
        orderService.markPaid(order.getId(), "wechat", transactionId);
        
        // 8. 激活会员权益
        membershipService.activateFromOrder(order);
        
        // 9. 发送通知
        // notificationService.sendSubscriptionSuccess(order.getUserId());
        
        return CallbackResult.success();
    }
}
```

### 6.4 会员激活逻辑

```java
@Service
@Slf4j
public class MembershipService {
    
    @Autowired
    private UserMembershipRepository membershipRepo;
    
    @Autowired
    private MembershipChangeLogRepository changeLogRepo;
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    /**
     * 根据订单激活会员
     */
    @Transactional
    public void activateFromOrder(Order order) {
        Long userId = order.getUserId();
        MembershipPlan plan = getPlanByCode(order.getPlanCode());
        
        // 查询当前会员状态
        UserMembership current = membershipRepo
            .findActiveByUserId(userId)
            .orElse(null);
        
        LocalDateTime now = LocalDateTime.now();
        
        if (current != null && "active".equals(current.getStatus())) {
            // 已有活跃会员：延长或升级
            if (plan.getPlanCode().equals(current.getPlanCode())) {
                // 同等级续费：在当前到期时间基础上延长
                extendMembership(current, plan.getDurationDays());
            } else if (isUpgrade(current.getPlanCode(), plan.getPlanCode())) {
                // 升级：立即切换，原剩余时间可折算或保留
                upgradeMembership(current, plan);
            } else {
                // 降级或其他：记录新订阅
                replaceMembership(current, plan, now);
            }
        } else {
            // 新用户或已过期：直接激活
            createNewMembership(userId, plan, now);
        }
        
        // 清除缓存，下次请求时重新加载
        redisTemplate.delete("user_membership:" + userId);
        
        log.info("会员激活成功: userId={}, planCode={}, orderNo={}", 
            userId, plan.getPlanCode(), order.getOrderNo());
    }
    
    private void createNewMembership(Long userId, MembershipPlan plan, LocalDateTime now) {
        UserMembership membership = new UserMembership();
        membership.setUserId(userId);
        membership.setPlanId(plan.getId());
        membership.setPlanCode(plan.getPlanCode());
        membership.setStatus("active");
        membership.setStartedAt(now);
        membership.setExpiresAt(now.plusDays(plan.getDurationDays()));
        membership.setAutoRenew(true);
        membershipRepo.save(membership);
        
        // 记录变更日志
        logChange(userId, null, plan.getPlanCode(), "subscribe", null, 
            membership.getExpiresAt());
    }
    
    private void extendMembership(UserMembership membership, int days) {
        LocalDateTime base = membership.getExpiresAt().isAfter(LocalDateTime.now())
            ? membership.getExpiresAt()
            : LocalDateTime.now();
        LocalDateTime newExpires = base.plusDays(days);
        membership.setExpiresAt(newExpires);
        membershipRepo.save(membership);
        
        logChange(membership.getUserId(), membership.getPlanCode(), 
            membership.getPlanCode(), "renew", membership.getExpiresAt(), newExpires);
    }
}
```

```java
public class MembershipExpireJob {

    @Autowired

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

     * 每小时执行一次，检查即将到期和已到期的会员
     * cron: 0 0 * * * ?
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void checkExpiredMemberships() {
        LocalDateTime now = LocalDateTime.now();
        
        // 1. 查找已过期但状态仍为 active 的记录
        List<UserMembership> expired = membershipRepo
            .findByStatusAndExpiresAtBefore("active", now);

            // 进入宽限期（3天）
            m.setStatus("grace");
            m.setGraceEndsAt(now.plusDays(3));
            membershipRepo.save(m);
            
            log.info("会员进入宽限期: userId={}, planCode={}", 
                m.getUserId(), m.getPlanCode());
```

### 6.6 Redis 配额计数器

```java
@Service
public class QuotaService {
    
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    
    @Autowired
    private MembershipService membershipService;
    
    /**
     * 检查配额并消耗一次（原子操作）
     */
    public QuotaCheckResult checkAndConsume(Long userId, String quotaKey) {
        // 1. 获取用户会员等级
        String planCode = membershipService.getCurrentPlanCode(userId);
        int limit = membershipService.getQuotaLimit(planCode, quotaKey);
        
        // 2. 不限量
        if (limit == -1) {
            return QuotaCheckResult.allowed(-1, -1, -1);
        }
        
        // 3. 不可用
        if (limit == 0) {
            return QuotaCheckResult.denied("QUOTA_NOT_AVAILABLE", 
                "当前等级无此权益", membershipService.getUpgradeHint(planCode, quotaKey));
        }
        
        // 4. Redis 原子递增
        String today = LocalDate.now().format(DateTimeFormatter.BASIC_ISO_DATE);
        String redisKey = String.format("user_quota:%d:%s:%s", userId, today, quotaKey);
        
        // 设置 key TTL 到当日结束
        Long ttl = Duration.between(LocalDateTime.now(), 
            LocalDate.now().plusDays(1).atStartOfDay()).getSeconds();
        
        Long used = redisTemplate.opsForValue().increment(redisKey);
        if (used != null && used == 1L) {
            redisTemplate.expire(redisKey, ttl, TimeUnit.SECONDS);
        }
        
        int usedInt = used != null ? used.intValue() : 1;
        int remaining = limit - usedInt;
        
        if (usedInt > limit) {
            return QuotaCheckResult.denied("QUOTA_EXCEEDED",
                String.format("今日%s次数已用完", getQuotaDisplayName(quotaKey)),
                membershipService.getUpgradeHint(planCode, quotaKey));
        }
        
        return QuotaCheckResult.allowed(usedInt, limit, remaining);
    }
}
```

## 9. 安全与合规

### 9.1 防刷与风控

1. **创建订单频率限制**：同一用户每分钟最多3次创建订单请求
2. **订单超时关闭**：未支付订单30分钟自动关闭，释放库存（如有）
3. **退款限制**：同一用户每月最多2次退款
4. **金额校验**：回调金额必须与订单金额完全一致
5. **签名验证**：所有支付回调必须验签通过

### 9.2 未成年人消费保护

1. 学生账号每次支付前弹窗确认（非免密）
2. 月累计消费超过 200 元需家长端确认
3. 订阅续费前24小时推送提醒通知
4. 家长中心可查看所有消费记录
5. 遵守《未成年人网络保护条例》相关要求

### 9.3 数据安全

1. 支付密钥、证书等服务端存储，不暴露给客户端
2. 敏感支付流水数据脱敏后才能通过 API 返回
3. 订单数据按用户隔离，禁止越权查询
4. 财务相关操作保留完整审计日志
