# 服务端-作文抄袭检测与学术诚信度评估引擎 - 详细设计

> 本文档基于 `docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` 第 6.10 节（作文辅导模块）和第 8.7 节（安全与合规架构）进行细化，聚焦服务端作文抄袭检测、AI 生成内容识别与学术诚信度评估引擎的实现细节，为开发人员提供可直接编码的设计方案。

---

## 1. 概述

### 1.1 文档目的

定义 PrimeTop 作文抄袭检测与学术诚信度评估引擎的服务端架构、数据模型、API 接口、检测流水线、相似度算法、AI 生成识别模型及与其他模块的集成方式，确保开发人员能够据此实现完整的作文原创性审查与学术诚信评估服务。

### 1.2 背景

随着 AI 写作工具普及，学生提交的作文可能存在以下学术不端行为：

1. **网络抄袭**：直接复制网络上的范文、博客、百科内容
2. **范文集抄写**：拼接、改写优秀范文段落
3. **AI 代写**：使用大语言模型生成整篇或部分作文
4. **同伴互抄**：同班/同校学生之间互相抄袭或共用模板
5. **模板套用**：机械套用万能开头、结尾模板，缺乏原创性

传统作文批改引擎仅关注语言质量和内容评分，无法识别上述不端行为。本引擎作为作文批改的前置关卡和并行检测模块，为教师、家长和平台提供学术诚信度参考。

### 1.3 范围

| 范围内 | 范围外 |
| --- | --- |
| 作文提交后的原创性检测 | 作文语言质量评分（见《服务端-作文批改评分引擎》） |
| 网络文本相似度比对 | 作文素材推荐（见《服务端-作文素材库管理》） |
| 平台内作文交叉比对 | 客户端作文编辑器（见《客户端-富文本编辑器》） |
| AI 生成内容检测 | AI 辅导对话安全（见《AI输入安全与教育对话护栏》） |
| 模板化写作检测 | 通用内容审核（见《安全与内容合规系统》） |
| 学术诚信度评分与报告 | 用户行为异常检测（见《用户学习行为异常检测》） |
| 抄袭历史追踪与趋势 | 消息推送通知 |
| 教师审核工作流 | 支付与会员权益 |

### 1.4 术语定义

| 术语 | 含义 |
| --- | --- |
| OriginalityCheck | 原创性检测，一次完整的抄袭+AI生成检测流程 |
| SimilarityReport | 相似度报告，包含与各来源的比对结果 |
| TextSegment | 文本片段，作文被切分后的最小比对单元 |
| SourceMatch | 来源匹配，与某个外部/内部来源的相似匹配结果 |
| AIScore | AI 生成概率分值（0-100），越高越可能为 AI 生成 |
| IntegrityScore | 学术诚信度综合评分（0-100），越高表示越诚信 |
| CorpusDB | 语料库，包含网络范文、范文集、平台历史作文等 |
| Fingerprint | 文本指纹，用于快速相似检索的 SimHash/MinHash 值 |
| Perplexity | 困惑度，衡量文本可预测性的指标，用于 AI 检测 |
| Burstiness | 突发性，衡量文本句式多样性的指标，用于 AI 检测 |

### 1.5 设计原则

1. **教育引导优先**：检测结果用于引导学生养成原创写作习惯，非惩罚性标注
2. **分龄差异化**：小学阶段容忍模板化程度更高，高中阶段执行更严格标准
3. **低误报率**：优先保证高置信度下的检测准确率，降低误报对学生的负面影响
4. **隐私安全**：学生作文数据仅在平台内部比对，不外泄给第三方
5. **透明可解释**：检测报告需明确指出相似来源和判定依据，支持人工复核
6. **与批改解耦**：抄袭检测独立于评分引擎运行，结果作为补充参考维度

## 2. 系统架构

### 2.1 服务定位

作文抄袭检测与学术诚信度评估引擎是内容安全域的子服务，在整体架构中的位置如下：

```
┌──────────────────────────────────────────────────────────────────┐
│                         API 网关层                                 │
├──────────────────────────────────────────────────────────────────┤
│  BFF 聚合层  ──→  作文批改服务                                     │
│                    │                                              │
│                    ├──→ 作文批改评分引擎 (并行)                    │
│                    │                                              │
│                    └──→ 抄袭检测与诚信评估引擎 (本服务)             │
│                           │                                       │
│                           ├─── 文本预处理与指纹提取模块              │
│                           │    (TextPreprocessor)                  │
│                           │                                       │
│                           ├─── 网络文本相似度检索模块               │
│                           │    (WebSimilaritySearcher)             │
│                           │                                       │
│                           ├─── 平台内部作文比对模块                 │
│                           │    (InternalCorpusMatcher)             │
│                           │                                       │
│                           ├─── AI生成内容检测模块                   │
│                           │    (AIGeneratedDetector)               │
│                           │                                       │
│                           ├─── 模板化写作检测模块                   │
│                           │    (TemplatePatternDetector)           │
│                           │                                       │
│                           ├─── 诚信度综合评分模块                   │
│                           │    (IntegrityScoringEngine)            │
│                           │                                       │
│                           ├─── 检测报告生成模块                     │
│                           │    (ReportGenerator)                   │
│                           │                                       │
│                           └─── 人工审核工作流模块                   │
│                                (ReviewWorkflow)                    │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤
│  AI 能力层  (LLM / Embedding / 分类模型)                          │
├──────────────────────────────────────────────────────────────────┤
│  数据层  (MySQL / Redis / ES / Milvus / OSS)                     │
└──────────────────────────────────────────────────────────────────┘
```

### 2.2 内部模块职责

| 模块 | 职责 | 关键类 |
| --- | --- | --- |
| TextPreprocessor | 文本预处理：分句、分段、清洗、指纹提取 | `TextPreprocessor` |
| WebSimilaritySearcher | 网络文本相似度搜索：调用搜索引擎API+爬取比对 | `WebSimilaritySearcher` |
| InternalCorpusMatcher | 平台内部比对：与历史作文库、范文库进行匹配 | `InternalCorpusMatcher` |
| AIGeneratedDetector | AI生成检测：基于统计特征+分类模型判断AI生成概率 | `AIGeneratedDetector` |
| TemplatePatternDetector | 模板化检测：识别万能模板、套路化结构 | `TemplatePatternDetector` |
| IntegrityScoringEngine | 诚信度评分：综合各检测结果计算整体诚信度 | `IntegrityScoringEngine` |
| ReportGenerator | 报告生成：生成结构化检测报告，含高亮标注 | `SimilarityReportGenerator` |
| ReviewWorkflow | 人工审核工作流：争议结果的人工复核流程 | `ReviewWorkflowManager` |

### 2.3 依赖关系

```
本服务依赖：
  ├── 对象存储服务 (OSS) ──── 存储作文原文、报告文件
  ├── 搜索引擎 (ES) ──────── 内部作文全文检索
  ├── 向量数据库 (Milvus) ── 语义相似检索
  ├── Redis ──────────────── 检测任务去重、限流、缓存
  ├── MySQL ──────────────── 检测记录、诚信档案
  ├── 消息队列 ────────────── 异步检测任务分发
  ├── 外部搜索API ─────────── 网络文本检索（需代理或国内搜索API）
  └── AI分类模型服务 ──────── AI生成检测推理

本服务被依赖（被调用方）：
  ├── 作文批改评分引擎 ────── 获取诚信度评分作为评分参考
  ├── 客户端作文辅导页面 ──── 展示检测报告（学生/家长视角）
  ├── 教师端 ──────────────── 展示班级作文诚信概览（教师视角）
  ├── 内容审核后台 ────────── 人工审核工作台
  └── 学习行为分析服务 ────── 诚信趋势纳入学习画像
```

#### 3.1.1 originality_checks（原创性检测记录表）

```sql
CREATE TABLE originality_checks (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '检测记录ID',
    check_no        VARCHAR(32) NOT NULL UNIQUE COMMENT '检测编号 ORM-YYYYMMDD-XXXXX',
    essay_id        BIGINT NOT NULL COMMENT '关联作文ID',
    user_id         BIGINT NOT NULL COMMENT '提交用户ID',
    student_name    VARCHAR(64) NOT NULL COMMENT '学生姓名（冗余）',
    grade_level     TINYINT NOT NULL COMMENT '年级段 1-幼 2-小 3-初 4-高',
    grade           SMALLINT NOT NULL COMMENT '具体年级',
    subject         VARCHAR(16) NOT NULL COMMENT '学科（通常为语文/英语）',
    essay_title     VARCHAR(256) NOT NULL COMMENT '作文题目',
    essay_content   TEXT NOT NULL COMMENT '作文全文',
    word_count      INT NOT NULL DEFAULT 0 COMMENT '字数',
    check_status    TINYINT NOT NULL DEFAULT 0 COMMENT '检测状态 0-待检 1-检测中 2-完成 3-失败 4-人工复核中',
    
    -- 综合结果
    integrity_score DECIMAL(5,2) NOT NULL DEFAULT 100.00 COMMENT '诚信度评分 0-100',

    template_score  DECIMAL(5,2) NOT NULL DEFAULT 0.00 COMMENT '模板化评分 0-100',
    risk_level      TINYINT NOT NULL DEFAULT 0 COMMENT '风险等级 0-低 1-中 2-高 3-极高',

    web_matches     JSON COMMENT '网络来源匹配明细列表',
    internal_matches JSON COMMENT '平台内部匹配明细列表',
    ai_analysis     JSON COMMENT 'AI生成检测分析详情',
    template_analysis JSON COMMENT '模板化分析详情',
    
    -- 时间信息
    submitted_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '提交时间',
    started_at      DATETIME NULL COMMENT '检测开始时间',
    completed_at    DATETIME NULL COMMENT '检测完成时间',
    duration_ms     INT NULL COMMENT '检测耗时（毫秒）',
    
    -- 人工审核
    review_status   TINYINT NOT NULL DEFAULT 0 COMMENT '审核状态 0-无需 1-待审核 2-审核中 3-已审核',

    check_version   VARCHAR(16) NOT NULL DEFAULT '1.0' COMMENT '检测引擎版本',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_essay (essay_id),
    INDEX idx_user (user_id),
    INDEX idx_status (check_status),
    INDEX idx_risk (risk_level),
    INDEX idx_review (review_status),
    INDEX idx_submitted (submitted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作文原创性检测记录表';
```

### 3.2 核心数据结构（Java 实体类示例）

```java
/**
 * 原创性检测结果

@Data
@Builder
public class OriginalityCheckResult {
    private Long checkId;
    private String checkNo;
    private Long essayId;
    private Long userId;
    
    /** 诚信度综合评分 0-100 */
    private BigDecimal integrityScore;
    /** 最大文本相似度 0-100 */
    private BigDecimal maxSimilarity;
    /** AI生成概率 0-100 */
    private BigDecimal aiProbability;
    /** 模板化评分 0-100 */
    private BigDecimal templateScore;
    /** 风险等级 */
    private RiskLevel riskLevel;
    
    /** 网络来源匹配列表 */
    private List<SourceMatchDetail> webMatches;
    /** 平台内部匹配列表 */
    private List<SourceMatchDetail> internalMatches;
    /** AI检测分析详情 */
    private AIDetectionDetail aiAnalysis;
    /** 模板化分析详情 */
    private TemplateDetectionDetail templateAnalysis;
    
    /** 检测耗时 */
    private Integer durationMs;
    /** 引擎版本 */
    private String engineVersion;
    
    public enum RiskLevel {
        LOW(0, "低风险"), 
        MEDIUM(1, "中风险"), 
        HIGH(2, "高风险"), 
        CRITICAL(3, "极高风险");
        
        private final int code;
        private final String desc;
    }
}

/**
 * 来源匹配详情

@Data
@Builder

    /** 来源名称/URL */
```

```java
/**
 * 文本预处理器：对提交的作文进行分句、分段、指纹提取
 */
@Service
@Slf4j
public class TextPreprocessor {

    private static final int MIN_PARAGRAPH_LENGTH = 20; // 最小段落长度（字）
    private static final int MAX_SEGMENT_LENGTH = 500;  // 最大分段长度（字）
    private static final int SIMHASH_BITS = 64;
    
    /**
     * 执行文本预处理
     */
    public PreprocessResult preprocess(String rawText, Long essayId, Long userId) {
        // 1. 文本清洗
        String cleanedText = cleanText(rawText);
        
        // 2. 段落分割
        List<TextSegment> paragraphs = splitParagraphs(cleanedText);
        
        // 3. 句子分割（用于AI检测）
        List<TextSegment> sentences = splitSentences(cleanedText);
        
        // 4. 提取全文指纹
        String fullSimHash = computeSimHash(cleanedText);
        String fullMinHash = computeMinHash(cleanedText, 128);
        
        // 5. 分段提取指纹
        List<SegmentFingerprint> segmentFingerprints = paragraphs.stream()
            .map(p -> SegmentFingerprint.builder()
                .essayId(essayId)
                .userId(userId)
                .segmentIndex(p.getIndex())
                .segmentHash(computeSimHash(p.getText()))
                .segmentText(truncate(p.getText(), 512))
                .minhashSig(computeMinHash(p.getText(), 128))
                .wordCount(p.getText().length())
                .build())
            .collect(Collectors.toList());
        
        // 6. 生成全文向量嵌入
        float[] embedding = embeddingService.embed(cleanedText);
        
        return PreprocessResult.builder()
            .cleanedText(cleanedText)
            .wordCount(cleanedText.length())
            .paragraphs(paragraphs)
            .sentences(sentences)
            .fullSimHash(fullSimHash)
            .fullMinHash(fullMinHash)
            .embedding(embedding)
            .segmentFingerprints(segmentFingerprints)
            .build();
    }
    
    /**
     * 计算SimHash指纹
     * 算法：分词 → 每个词Hash → 加权累加 → 二值化
     */
    public String computeSimHash(String text) {
        Map<String, Integer> wordFreqs = tokenizeAndCountFreq(text);
        
        int[] featureVector = new int[SIMHASH_BITS];
        
        for (Map.Entry<String, Integer> entry : wordFreqs.entrySet()) {
            long hash = MurmurHash3.hash64(entry.getKey());
            int weight = entry.getValue();
            
            for (int i = 0; i < SIMHASH_BITS; i++) {
                if ((hash >> i & 1) == 1) {
                    featureVector[i] += weight;
                } else {
                    featureVector[i] -= weight;
                }
            }
        }
        
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < SIMHASH_BITS; i++) {
            sb.append(featureVector[i] > 0 ? "1" : "0");
        }
        return sb.toString();
    }
    
    /**
     * 计算MinHash签名
     * 用于LHS（Locality-Sensitive Hashing）快速近似最近邻搜索
     */
    public String computeMinHash(String text, int numHash) {
        Set<String> shingles = generateShingles(text, 3); // 3-gram shingles
        int[] signature = new int[numHash];
        Arrays.fill(signature, Integer.MAX_VALUE);
        
        int seed = 0;
        for (int i = 0; i < numHash; i++) {
            int h = MurmurHash3.hash32(seed++);
            for (String shingle : shingles) {
                int hash = MurmurHash3.hash32(shingle, h);
                if (hash < signature[i]) {
                    signature[i] = hash;
                }
            }
        }
        
        // 编码为紧凑的Base64字符串
        return Base64.getEncoder().toString(intArrayToBytes(signature));
    }
    
    /**
     * 计算两个SimHash的海明距离
     */
    public int hammingDistance(String hash1, String hash2) {
        if (hash1.length() != hash2.length()) {
            return Integer.MAX_VALUE;
        }
        int distance = 0;
        for (int i = 0; i < hash1.length(); i++) {
            if (hash1.charAt(i) != hash2.charAt(i)) {
                distance++;
            }
        }
        return distance;
    }
    
    /**
     * 基于海明距离估算相似度
     * 经验：海明距离 ≤ 3 通常认为高度相似
     */
    public BigDecimal simHashSimilarity(String hash1, String hash2) {
        int distance = hammingDistance(hash1, hash2);
        // 距离越小相似度越高，使用指数衰减
        double similarity = Math.max(0, 1.0 - distance / 64.0);
        return BigDecimal.valueOf(similarity * 100).setScale(2, RoundingMode.HALF_UP);
    }
    
    private String cleanText(String rawText) {
        return rawText
            .replaceAll("\\r\\n", "\n")
            .replaceAll("[\\u200B-\\u200D\\uFEFF]", "") // 零宽字符
            .replaceAll("[\\x00-\\x08\\x0B\\x0C\\x0E-\\x1F]", "") // 控制字符
            .trim();
    }
    
    private Set<String> generateShingles(String text, int k) {
        Set<String> shingles = new HashSet<>();
        String normalized = text.replaceAll("\\s+", "");
        for (int i = 0; i <= normalized.length() - k; i++) {
            shingles.add(normalized.substring(i, i + k));
        }
        return shingles;
    }
}
```

```java
/**
 * 网络文本相似度搜索器
 * 策略：搜索引擎关键词提取 → 搜索 → 爬取候选页面 → 精确比对
 */
@Service
@Slf4j
public class WebSimilaritySearcher {

    @Autowired
    private SearchEngineApiClient searchEngineClient;
    
    @Autowired
    private WebPageCrawler pageCrawler;
    
    @Autowired
    private TextPreprocessor preprocessor;
    
    @Autowired
    private ReferenceCorpusRepository corpusRepository;
    
    /** 搜索候选数量 */
    private static final int MAX_SEARCH_CANDIDATES = 10;
    /** 爬取页面最大字数 */
    private static final int MAX_CRAWL_CHARS = 20000;
    /** 高亮匹配最小片段长度 */
    private static final int MIN_MATCH_LENGTH = 15;
    
    /**
     * 执行网络文本相似度搜索
     */
    public List<SourceMatchDetail> search(String essayText, List<TextSegment> paragraphs, 
                                          String subject, Integer gradeLevel) {
        
        // 1. 从作文中提取搜索关键词
        List<String> searchQueries = extractSearchQueries(essayText, paragraphs);
        
        // 2. 批量搜索
        Set<String> candidateUrls = new LinkedHashSet<>();
        for (String query : searchQueries) {
            List<SearchResult> results = searchEngineClient.search(query, MAX_SEARCH_CANDIDATES);
            results.stream()
                .filter(r -> isRelevantSource(r, subject))
                .forEach(r -> candidateUrls.add(r.getUrl()));
        }
        
        // 3. 限制候选数量
        if (candidateUrls.size() > 15) {
            candidateUrls = new LinkedHashSet<>(
                candidateUrls.stream().limit(15).collect(Collectors.toList())
            );
        }
        
        // 4. 并行爬取候选页面
        List<CompletableFuture<SourceMatchDetail>> futures = candidateUrls.stream()
            .map(url -> CompletableFuture.supplyAsync(() -> 
                matchAgainstUrl(url, essayText, paragraphs)))
            .collect(Collectors.toList());
        
        List<SourceMatchDetail> matches = futures.stream()
            .map(CompletableFuture::join)
            .filter(Objects::nonNull)
            .filter(m -> m.getSimilarity().compareTo(BigDecimal.valueOf(20)) >= 0)
            .sorted(Comparator.comparing(SourceMatchDetail::getSimilarity).reversed())
            .collect(Collectors.toList());
        
        // 5. 同时与本地语料库比对
        List<SourceMatchDetail> corpusMatches = matchAgainstCorpus(
            essayText, paragraphs, subject, gradeLevel);
        
        // 6. 合并去重
        return mergeAndDedup(matches, corpusMatches);
    }
    
    /**
     * 提取搜索查询词
     * 策略：从作文不同段落提取独特短语组合
     */
    private List<String> extractSearchQueries(String essayText, List<TextSegment> paragraphs) {
        List<String> queries = new ArrayList<>();
        
        // 从首段提取（标题+开头）
        if (!paragraphs.isEmpty()) {
            String firstPara = paragraphs.get(0).getText();
            queries.add(extractKeyPhrase(firstPara, 8));
        }
        
        // 从中间段提取有特征性的句子
        for (int i = 1; i < Math.min(paragraphs.size(), 4); i++) {
            String midPara = paragraphs.get(i).getText();
            if (midPara.length() > 30) {
                queries.add(extractKeyPhrase(midPara, 12));
            }
        }
        
        // 从结尾段提取
        if (paragraphs.size() > 1) {
            String lastPara = paragraphs.get(paragraphs.size() - 1).getText();
            queries.add(extractKeyPhrase(lastPara, 8));
        }
        
        return queries.stream().distinct().limit(5).collect(Collectors.toList());
    }
    
    /**
     * 提取关键短语
     */
    private String extractKeyPhrase(String text, int maxWords) {
        // 去除标点和常见停用词
        String cleaned = text.replaceAll("[，。！？；：""''（）【】《》、\\n\\r\\t]", " ");
        List<String> words = ChineseTokenizer.tokenize(cleaned).stream()
            .filter(w -> w.length() >= 2)
            .filter(w -> !StopWords.isStopWord(w))
            .limit(maxWords)
            .collect(Collectors.toList());
        return String.join(" ", words);
    }
    
    /**
     * 爬取页面并进行比对
     */
    private SourceMatchDetail matchAgainstUrl(String url, String essayText, 
                                               List<TextSegment> paragraphs) {
        try {
            String pageContent = pageCrawler.crawl(url, MAX_CRAWL_CHARS);
            if (pageContent == null || pageContent.length() < MIN_MATCH_LENGTH) {
                return null;
            }
            
            // 精确比对：使用KMP算法找最长公共子串
            List<MatchedSegment> matchedSegments = findLongestCommonSubstrings(
                essayText, pageContent, MIN_MATCH_LENGTH);
            
            if (matchedSegments.isEmpty()) {
                return null;
            }
            
            int matchedWords = matchedSegments.stream()
                .mapToInt(s -> s.getSubmitEnd() - s.getSubmitStart())
                .sum();
            
            BigDecimal similarity = BigDecimal.valueOf(
                (double) matchedWords / essayText.length() * 100
            ).setScale(2, RoundingMode.HALF_UP);
            
            return SourceMatchDetail.builder()
                .sourceType(SourceMatchDetail.SourceType.WEB_PAGE)
                .sourceName(url)
                .sourceTitle(extractTitle(pageContent))
                .similarity(similarity)
                .matchedSegments(matchedSegments)
                .matchedWordCount(matchedWords)
                .percentageOfTotal(similarity)
                .build();
            
        } catch (Exception e) {
            log.warn("Failed to crawl and match URL: {}", url, e);
            return null;
        }
    }
    
    /**
     * 查找最长公共子串（基于后缀自动机）
     */
    private List<MatchedSegment> findLongestCommonSubstrings(
            String text1, String text2, int minLength) {
        
        List<MatchedSegment> segments = new ArrayList<>();
        boolean[] used = new boolean[text1.length()];
        
        // 构建text2的后缀自动机
        SuffixAutomaton sam = new SuffixAutomaton(text2);
        
        // 在text1上滑动，找所有长度 >= minLength 的公共子串
        int pos = 0;
        int last = 0;
        
        while (pos < text1.length()) {
            // 贪心匹配
            int matchLen = 0;
            int startPos = pos;
            
            while (pos < text1.length() && sam.canExtend(text1.charAt(pos))) {
                sam.extend(text1.charAt(pos));
                matchLen++;
                pos++;
            }
            
            if (matchLen >= minLength) {
                // 标记已使用区域
                boolean alreadyUsed = false;
                for (int i = startPos; i < startPos + matchLen; i++) {
                    if (used[i]) {
                        alreadyUsed = true;
                        break;
                    }
                }
                
                if (!alreadyUsed) {
                    Arrays.fill(used, startPos, startPos + matchLen, true);
                    segments.add(MatchedSegment.builder()
                        .submitStart(startPos)
                        .submitEnd(startPos + matchLen)
                        .submitText(text1.substring(startPos, startPos + matchLen))
                        .segmentSimilarity(BigDecimal.valueOf(100))
                        .build());
                }
            }
            
            if (matchLen == 0) {
                pos++;
            }
            sam.reset();
        }
        
        return segments;
    }
    
    /**
     * 与本地语料库比对
     */
    private List<SourceMatchDetail> matchAgainstCorpus(
            String essayText, List<TextSegment> paragraphs,
            String subject, Integer gradeLevel) {
        
        // 1. 用全文SimHash在语料库中快速检索候选
        String essaySimHash = preprocessor.computeSimHash(essayText);
        
        List<ReferenceCorpus> candidates = corpusRepository.findCandidatesBySimHash(
            essaySimHash, subject, gradeLevel, 20);
        
        // 2. 对每个候选用MinHash Jaccard估算相似度
        Set<String> essayShingles = preprocessor.generateShingles(essayText, 3);
        
        List<SourceMatchDetail> matches = candidates.stream()
            .map(corpus -> {
                Set<String> corpusShingles = preprocessor.generateShingles(corpus.getContent(), 3);
                BigDecimal jaccardSim = computeJaccardSimilarity(essayShingles, corpusShingles);
                
                if (jaccardSim.compareTo(BigDecimal.valueOf(0.15)) > 0) {
                    List<MatchedSegment> segments = findLongestCommonSubstrings(
                        essayText, corpus.getContent(), MIN_MATCH_LENGTH);
                    
                    return SourceMatchDetail.builder()
                        .sourceType(mapCorpusType(corpus.getCorpusType()))
                        .sourceName(corpus.getSourceName())
                        .sourceTitle(corpus.getTitle())
                        .similarity(jaccardSim.multiply(BigDecimal.valueOf(100)))
                        .matchedSegments(segments)
                        .build();
                }
                return null;
            })
            .filter(Objects::nonNull)
            .sorted(Comparator.comparing(SourceMatchDetail::getSimilarity).reversed())
            .collect(Collectors.toList());
        
        return matches;
    }
    
    private BigDecimal computeJaccardSimilarity(Set<String> set1, Set<String> set2) {
        Set<String> intersection = new HashSet<>(set1);
        intersection.retainAll(set2);
        
        Set<String> union = new HashSet<>(set1);
        union.addAll(set2);
        
        if (union.isEmpty()) return BigDecimal.ZERO;
        return BigDecimal.valueOf((double) intersection.size() / union.size() * 100)
            .setScale(2, RoundingMode.HALF_UP);
    }
}
```

### 4.5 AI 生成内容检测模块

```java
/**
 * AI生成内容检测器
 * 基于统计特征 + 分类模型 + 大模型判定三层策略
 */
@Service
@Slf4j
public class AIGeneratedDetector {

    @Autowired
    private AIContentClassifier classifier; // 二分类模型（人类/AI）
    
    @Autowired
    private LlmJudgeClient llmJudgeClient; // LLM判定客户端
    
    private static final BigDecimal AI_THRESHOLD_HIGH = new BigDecimal("75.00");
    private static final BigDecimal AI_THRESHOLD_MEDIUM = new BigDecimal("50.00");
    
    /**
     * 执行AI生成检测
     */
    public AIDetectionDetail detect(String essayText, List<TextSegment> sentences, 
                                     Integer gradeLevel) {
        
        // 1. 统计特征提取
        StatisticalFeatures stats = extractStatisticalFeatures(essayText, sentences);
        
        // 2. 分类模型推理
        ModelPrediction modelPred = classifier.predict(essayText);
        
        // 3. 综合判定
        BigDecimal aiProbability = computeAIProbability(stats, modelPred);
        
        // 4. 识别可疑段落
        List<AISuspiciousSegment> suspiciousSegments = identifySuspiciousSegments(
            sentences, gradeLevel);
        
        // 5. 判定结论
        AIDetectionDetail.AIVerdict verdict = determineVerdict(aiProbability, suspiciousSegments);
        
        // 6. 高风险时使用LLM进行二次确认
        BigDecimal confidence = modelPred.getConfidence();
        if (aiProbability.compareTo(AI_THRESHOLD_MEDIUM) >= 0) {
            LlmJudgeResult llmResult = llmJudgeClient.judgeAIGenerated(essayText);
            aiProbability = weightedAverage(aiProbability, llmResult.getAiScore(), 0.6, 0.4);
            confidence = confidence.max(llmResult.getConfidence());
        }
        
        return AIDetectionDetail.builder()
            .aiProbability(aiProbability)
            .verdict(verdict)
            .perplexity(stats.getPerplexity())
            .burstiness(stats.getBurstiness())
            .sentenceDiversityScore(stats.getSentenceDiversityScore())
            .lexicalRichnessScore(stats.getLexicalRichnessScore())
            .suspiciousSegments(suspiciousSegments)
            .confidence(confidence)
            .build();
    }
    
    /**
     * 提取统计特征
     * 
     * AI生成文本的典型特征：
     * - 低困惑度（用词可预测，缺乏个性表达）
     * - 低突发性（句式规律，长度均匀）
     * - 词汇分布集中
     * - 标点使用过于规范统一
     * - 缺乏口语化表达和个人风格
     * - 逻辑过渡词使用过于一致
     */
    private StatisticalFeatures extractStatisticalFeatures(
            String text, List<TextSegment> sentences) {
        
        // 1. 困惑度（Perplexity）：使用轻量级语言模型计算
        //    AI文本困惑度通常在15-30之间，人类文本通常在40-120+
        double perplexity = languageModel.computePerplexity(text);
        
        // 2. 突发性（Burstiness）：句子长度的变异系数
        //    AI文本句长标准差小（~5-10），人类文本标准差大（~15-30+）
        double[] sentenceLengths = sentences.stream()
            .mapToDouble(s -> s.getText().length())
            .toArray();
        double meanLen = Arrays.stream(sentenceLengths).average().orElse(0);
        double stdLen = computeStd(sentenceLengths, meanLen);
        double burstiness = meanLen > 0 ? stdLen / meanLen : 0;
        
        // 3. 句式多样性：统计不同句式结构占比
        //    AI文本倾向于使用相似的句式结构
        double sentenceDiversity = computeSentenceDiversity(sentences);
        
        // 4. 词汇丰富度（Type-Token Ratio, TTR）
        //    AI文本TTR通常偏低，词汇分布集中
        double lexicalRichness = computeTTR(text);
        
        // 5. 标点使用分布
        //    AI文本标点使用高度规范
        Map<Character, Double> punctuationDist = computePunctuationDistribution(text);
        double punctuationRegularity = computePunctuationRegularity(punctuationDist);
        
        return StatisticalFeatures.builder()
            .perplexity(BigDecimal.valueOf(perplexity).setScale(2, RoundingMode.HALF_UP))
            .burstiness(BigDecimal.valueOf(burstiness).setScale(2, RoundingMode.HALF_UP))
            .sentenceDiversityScore(BigDecimal.valueOf(sentenceDiversity * 100)
                .setScale(2, RoundingMode.HALF_UP))
            .lexicalRichnessScore(BigDecimal.valueOf(lexicalRichness * 100)
                .setScale(2, RoundingMode.HALF_UP))
            .punctuationRegularity(BigDecimal.valueOf(punctuationRegularity)
                .setScale(2, RoundingMode.HALF_UP))
            .build();
    }
    
    /**
     * 计算AI生成概率
     * 加权综合统计特征和分类模型预测
     */
    private BigDecimal computeAIProbability(StatisticalFeatures stats, 
                                             ModelPrediction modelPred) {
        // 基于统计特征的启发式评分
        double statScore = 0;
        
        // 困惑度：越低越可能AI
        if (stats.getPerplexity().doubleValue() < 25) statScore += 30;
        else if (stats.getPerplexity().doubleValue() < 35) statScore += 20;
        else if (stats.getPerplexity().doubleValue() < 50) statScore += 10;
        else statScore += 0;
        
        // 突发性：越低越可能AI
        if (stats.getBurstiness().doubleValue() < 0.3) statScore += 25;
        else if (stats.getBurstiness().doubleValue() < 0.5) statScore += 15;
        else if (stats.getBurstiness().doubleValue() < 0.7) statScore += 5;
        else statScore += 0;
        
        // 句式多样性
        if (stats.getSentenceDiversityScore().doubleValue() < 30) statScore += 20;
        else if (stats.getSentenceDiversityScore().doubleValue() < 50) statScore += 10;
        else statScore += 0;
        
        // 词汇丰富度
        if (stats.getLexicalRichnessScore().doubleValue() < 40) statScore += 15;
        else if (stats.getLexicalRichnessScore().doubleValue() < 55) statScore += 8;
        else statScore += 0;
        
        // 标点规律性
        if (stats.getPunctuationRegularity().doubleValue() > 0.8) statScore += 10;
        else if (stats.getPunctuationRegularity().doubleValue() > 0.6) statScore += 5;
        else statScore += 0;
        
        // 综合统计特征评分（0-100）和模型预测概率
        double modelProb = modelPred.getAiProbability().doubleValue();
        double finalScore = statScore * 0.45 + modelProb * 0.55;
        
        return BigDecimal.valueOf(Math.min(100, finalScore))
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 识别可疑段落
     * 逐段检测AI特征
     */
    private List<AISuspiciousSegment> identifySuspiciousSegments(
            List<TextSegment> sentences, Integer gradeLevel) {
        
        List<AISuspiciousSegment> suspicious = new ArrayList<>();
        
        // 按段落（3-5句一组）检测
        int groupSize = 3;
        for (int i = 0; i < sentences.size(); i += groupSize) {
            int end = Math.min(i + groupSize, sentences.size());
            String segmentText = sentences.subList(i, end).stream()
                .map(TextSegment::getText)
                .collect(Collectors.joining());
            
            if (segmentText.length() < 30) continue;
            
            double segPerplexity = languageModel.computePerplexity(segmentText);
            ModelPrediction segPred = classifier.predict(segmentText);
            
            double segAiScore = segPred.getAiProbability().doubleValue() * 0.6 
                + (segPerplexity < 30 ? 40 : 0) * 0.4;
            
            if (segAiScore > 60) {
                suspicious.add(AISuspiciousSegment.builder()
                    .startSentence(i)
                    .endSentence(end)
                    .text(segmentText)
                    .aiScore(BigDecimal.valueOf(segAiScore).setScale(2, RoundingMode.HALF_UP))
                    .perplexity(BigDecimal.valueOf(segPerplexity)
                        .setScale(2, RoundingMode.HALF_UP))
                    .build());
            }
        }
        
        return suspicious;
    }
    
    private AIDetectionDetail.AIVerdict determineVerdict(
            BigDecimal aiProbability, List<AISuspiciousSegment> suspicious) {
        double prob = aiProbability.doubleValue();
        
        if (prob >= 75) return AIDetectionDetail.AIVerdict.LIKELY_AI;
        if (prob >= 50) {
            // 如果有多个可疑段落，判为MIXED
            if (suspicious.size() >= 2) return AIDetectionDetail.AIVerdict.MIXED_CONTENT;
            return AIDetectionDetail.AIVerdict.POSSIBLY_AI;
        }
        return AIDetectionDetail.AIVerdict.LIKELY_HUMAN;
    }
    
    private double computeStd(double[] values, double mean) {
        double variance = Arrays.stream(values)
            .map(v -> Math.pow(v - mean, 2))
            .average().orElse(0);
        return Math.sqrt(variance);
    }
    
    private double computeSentenceDiversity(List<TextSegment> sentences) {
        // 提取每句的句式模板（主谓宾/主谓/疑问/感叹...）
        // 计算不同模板种类 / 总句数
        Set<String> patterns = new HashSet<>();
        for (TextSegment s : sentences) {
            String pattern = extractSentencePattern(s.getText());
            patterns.add(pattern);
        }
        return sentences.isEmpty() ? 0 : (double) patterns.size() / sentences.size();
    }
    
    private double computeTTR(String text) {
        List<String> tokens = ChineseTokenizer.tokenize(text);
        if (tokens.isEmpty()) return 0;
        Set<String> unique = new HashSet<>(tokens);
        // 对文本长度进行标准化（使用Root TTR）
        return Math.min(1, unique.size() / Math.sqrt(tokens.size()) / 10);
    }
    
    private String extractSentencePattern(String sentence) {
        // 简化版句式提取：标注→模式字符串
        // 实际实现可使用依存句法分析
        return sentence.replaceAll("[^，。！？；：]+", "X");
    }
    
    private Map<Character, Double> computePunctuationDistribution(String text) {
        Map<Character, Integer> counts = new HashMap<>();
        int total = 0;
        for (char c : text.toCharArray()) {
            if ("，。！？；：、,.!?;:".indexOf(c) >= 0) {
                counts.merge(c, 1, Integer::sum);
                total++;
            }
        }
        Map<Character, Double> dist = new HashMap<>();
        final int finalTotal = total;
        counts.forEach((k, v) -> dist.put(k, (double) v / finalTotal));
        return dist;
    }
    
    private double computePunctuationRegularity(Map<Character, Double> dist) {
        // 计算标点分布的熵，熵越低越规律
        double entropy = dist.values().stream()
            .mapToDouble(p -> -p * Math.log(p) / Math.log(2))
            .sum();
        // 标准化到0-1
        return Math.max(0, 1 - entropy / 3.0);
    }
    
    private BigDecimal weightedAverage(BigDecimal a, BigDecimal b, double wa, double wb) {
        return a.multiply(BigDecimal.valueOf(wa))
            .add(b.multiply(BigDecimal.valueOf(wb)))
            .setScale(2, RoundingMode.HALF_UP);
    }
}
```

### 4.6 模板化写作检测模块

```java
/**
 * 模板化写作检测器
 * 检测作文中是否存在万能模板、套路化开头/结尾、固定过渡句
 */
@Service
@Slf4j
public class TemplatePatternDetector {

    @Autowired
    private TemplatePatternRepository templateRepository;
    
    @Autowired
    private TextPreprocessor preprocessor;
    
    /**
     * 执行模板化检测
     */
    public TemplateDetectionDetail detect(String essayText, List<TextSegment> paragraphs,
                                           Integer gradeLevel, String subject) {
        
        // 1. 加载适用模板库
        List<TemplatePattern> templates = templateRepository.findActiveTemplates(
            gradeLevel, subject);
        
        // 2. 逐段与模板比对
        List<TemplateHit> hits = new ArrayList<>();
        for (TextSegment para : paragraphs) {
            String paraText = para.getText();
            String paraSimHash = preprocessor.computeSimHash(paraText);
            
            for (TemplatePattern template : templates) {
                BigDecimal similarity = preprocessor.simHashSimilarity(
                    paraSimHash, template.getFingerprint());
                
                if (similarity.compareTo(template.getMatchThreshold()) >= 0) {
                    // 进一步使用编辑距离确认
                    BigDecimal editSimilarity = computeEditSimilarity(
                        paraText, template.getPatternText());
                    
                    if (editSimilarity.compareTo(BigDecimal.valueOf(70)) >= 0) {
                        hits.add(TemplateHit.builder()
                            .patternName(template.getPatternName())
                            .patternType(template.getPatternType())
                            .matchedText(paraText)
                            .matchScore(editSimilarity)
                            .severity(template.getSeverity())
                            .suggestion(generateSuggestion(template))
                            .build());
                    }
                }
            }
        }
        
        // 3. 检测结构模式化
        BigDecimal structuralScore = computeStructuralPatternScore(paragraphs);
        
        // 4. 检测语言套路化
        BigDecimal languageScore = computeLanguageFormulaScore(essayText);
        
        // 5. 综合模板化评分
        BigDecimal templateScore = computeOverallTemplateScore(
            hits, structuralScore, languageScore, gradeLevel);
        
        // 6. 生成原创性评价
        String comment = generateOriginalityComment(templateScore, hits, gradeLevel);
        
        return TemplateDetectionDetail.builder()
            .templateScore(templateScore)
            .templateHits(hits)
            .structuralPatternScore(structuralScore)
            .languageFormulaScore(languageScore)
            .originalityComment(comment)
            .build();
    }
    
    /**
     * 计算结构模式化评分
     * 检测是否存在固定的 "引-议-联-结" 四段式
     */
    private BigDecimal computeStructuralPatternScore(List<TextSegment> paragraphs) {
        if (paragraphs.size() < 3) return BigDecimal.ZERO;
        
        // 检查段落数量是否为典型模板数（3-5段）
        int paraCount = paragraphs.size();
        boolean isTypicalStructure = (paraCount >= 3 && paraCount <= 5);
        
        // 检查各段长度是否过于均匀
        double[] lengths = paragraphs.stream()
            .mapToDouble(p -> p.getText().length())
            .toArray();
        double mean = Arrays.stream(lengths).average().orElse(0);
        double cv = mean > 0 ? computeStd(lengths, mean) / mean : 0;
        
        // CV越低（段长越均匀），模板化程度越高
        double score = 0;
        if (isTypicalStructure) score += 30;
        if (cv < 0.15) score += 50;
        else if (cv < 0.25) score += 30;
        else if (cv < 0.4) score += 15;
        
        // 检测首段是否为典型 "引用名言/排比/设问" 开头
        String firstPara = paragraphs.get(0).getText();
        if (hasFormulaOpening(firstPara)) score += 20;
        
        return BigDecimal.valueOf(Math.min(100, score))
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    /**
     * 检测语言套路化
     */
    private BigDecimal computeLanguageFormulaScore(String text) {
        // 常见套话词典
        Set<String> formulaPhrases = Set.of(
            "在日常生活中", "随着社会的发展", "在这个快节奏的时代",
            "俗话说得好", "正所谓", "众所周知", 
            "总而言之", "综上所述", "通过这次经历",
            "让我明白了一个道理", "深受启发", "受益匪浅",
            "不禁陷入了沉思", "心中五味杂陈", "百感交集"
        );
        
        int formulaCount = 0;
        for (String phrase : formulaPhrases) {
            int idx = text.indexOf(phrase);
            while (idx >= 0) {
                formulaCount++;
                idx = text.indexOf(phrase, idx + 1);
            }
        }
        
        // 按文本长度标准化
        int textLen = text.length();
        double density = textLen > 0 ? (double) formulaCount * 100 / (textLen / 100.0) : 0;
        
        return BigDecimal.valueOf(Math.min(100, density * 20))
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    private boolean hasFormulaOpening(String firstParagraph) {
        // 检测引用式开头
        if (firstParagraph.contains("曾说") || firstParagraph.contains("曾言")
            || firstParagraph.contains("有言道") || firstParagraph.contains("说过")) {
            return true;
        }
        // 检测排比式开头
        if (firstParagraph.chars().filter(c -> c == '，').count() >= 3 
            && firstParagraph.length() < 100) {
            return true;
        }
        // 检测设问式开头
        if (firstParagraph.contains("？") && firstParagraph.indexOf("？") < 50) {
            return true;
        }
        return false;
    }
    
    private BigDecimal computeOverallTemplateScore(
            List<TemplateHit> hits, BigDecimal structuralScore,
            BigDecimal languageScore, Integer gradeLevel) {
        
        // 小学阶段对模板化的容忍度更高
        double templateWeight = gradeLevel <= 2 ? 0.5 : (gradeLevel == 3 ? 0.8 : 1.0);
        
        double hitsScore = hits.stream()
            .mapToDouble(h -> h.getSeverity() * 25 * h.getMatchScore().doubleValue() / 100)
            .sum();
        hitsScore = Math.min(100, hitsScore);
        
        double score = hitsScore * 0.4 * templateWeight
            + structuralScore.doubleValue() * 0.35
            + languageScore.doubleValue() * 0.25;
        
        return BigDecimal.valueOf(Math.min(100, score))
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    private String generateSuggestion(TemplatePattern template) {
        return switch (template.getPatternType()) {
            case 1 -> "开头过于模式化，建议结合自身经历或具体场景重新构思开头";
            case 2 -> "结尾套路化，建议回扣主题但避免使用万能结尾模板";
            case 3 -> "过渡句生硬，建议使用更自然的衔接方式";
            case 4 -> "整体结构过于固定，建议尝试更有变化的文章结构";
            case 5 -> "语言套话较多，建议使用更有个性和真实感的表达";
            default -> "建议增强原创性表达";
        };
    }
    
    private String generateOriginalityComment(BigDecimal templateScore, 
                                               List<TemplateHit> hits, Integer gradeLevel) {
        double score = templateScore.doubleValue();
        if (score < 20) {
            return "文章原创性良好，表达自然，结构有个人特色";
        } else if (score < 40) {
            return "文章存在一定程度的套路化表达，建议在保持框架的基础上增加个性化内容";
        } else if (score < 60) {
            return "文章模板化程度较高，开头/结尾或语言表达存在明显套路，建议大胆创新";
        } else {
            return "文章高度模板化，缺乏个人思考和真实表达，建议从自身经历出发重新写作";
        }
    }
    
    private BigDecimal computeEditSimilarity(String s1, String s2) {
        int maxLen = Math.max(s1.length(), s2.length());
        if (maxLen == 0) return BigDecimal.valueOf(100);
        int editDist = computeLevenshtein(s1, s2);
        return BigDecimal.valueOf((1 - (double) editDist / maxLen) * 100)
            .setScale(2, RoundingMode.HALF_UP);
    }
    
    private int computeLevenshtein(String s1, String s2) {
        int[][] dp = new int[s1.length() + 1][s2.length() + 1];
        for (int i = 0; i <= s1.length(); i++) dp[i][0] = i;
        for (int j = 0; j <= s2.length(); j++) dp[0][j] = j;
        for (int i = 1; i <= s1.length(); i++) {
            for (int j = 1; j <= s2.length(); j++) {
                int cost = s1.charAt(i-1) == s2.charAt(j-1) ? 0 : 1;
                dp[i][j] = Math.min(Math.min(dp[i-1][j] + 1, dp[i][j-1] + 1),
                                    dp[i-1][j-1] + cost);
            }
        }
        return dp[s1.length()][s2.length()];
    }
    
    private double computeStd(double[] values, double mean) {
        double variance = Arrays.stream(values)
            .map(v -> Math.pow(v - mean, 2))
            .average().orElse(0);
        return Math.sqrt(variance);
    }
```

```java
/**
 * 平台内部作文比对器
 * 与平台历史作文库进行交叉比对，检测同伴互抄
 */
@Service
@Slf4j
public class InternalCorpusMatcher {

    @Autowired
    private TextFingerprintRepository fingerprintRepository;
    
    @Autowired
    private VectorSearchClient vectorSearchClient; // Milvus客户端
    
    @Autowired
    private TextPreprocessor preprocessor;
    
    /** 相似度阈值 */
    private static final double SIMILARITY_THRESHOLD = 0.25;
    /** 最大比对数量 */
    private static final int MAX_COMPARE = 50;
    /** 班级内比对优先时间窗口（天） */
    private static final int CLASS_COMPARE_WINDOW_DAYS = 90;
    
    /**
     * 执行平台内部比对
     */
    public List<SourceMatchDetail> match(String essayText, Long userId, 
                                          Long schoolId, Long classId,
                                          Integer gradeLevel, String subject) {
        
        // 1. 段落级指纹提取
        List<TextSegment> paragraphs = preprocessor.splitParagraphs(essayText);
        List<String> segmentHashes = paragraphs.stream()
            .map(p -> preprocessor.computeSimHash(p.getText()))
            .collect(Collectors.toList());
        
        // 2. 粗筛：海明距离检索候选（分段级别）
        Set<Long> candidateEssayIds = new HashSet<>();
        for (String segHash : segmentHashes) {
            List<TextFingerprint> candidates = fingerprintRepository
                .findSimilarByHammingDistance(segHash, 10, gradeLevel);
            candidates.stream()
                .filter(fp -> !fp.getUserId().equals(userId)) // 排除自己的作文
                .forEach(fp -> candidateEssayIds.add(fp.getEssayId()));
        }
        
        // 3. 优先比对同班/同校的作文
        Set<Long> classmateEssayIds = candidateEssayIds.stream()
            .filter(eid -> isClassmateEssay(eid, schoolId, classId, 
                LocalDate.now().minusDays(CLASS_COMPARE_WINDOW_DAYS)))
            .limit(MAX_COMPARE / 2)
            .collect(Collectors.toSet());
        
        // 4. 语义向量检索补充候选
        float[] essayEmbedding = preprocessor.computeEmbedding(essayText);
        List<VectorSearchResult> vectorResults = vectorSearchClient.search(
            essayEmbedding, "essay_embeddings", MAX_COMPARE / 2);
        vectorResults.stream()
            .filter(r -> r.getUserId() != userId)
            .forEach(r -> candidateEssayIds.add(r.getEssayId()));
        
        // 5. 精确比对
        List<SourceMatchDetail> matches = candidateEssayIds.stream()
            .limit(MAX_COMPARE)
            .map(candidateId -> preciseMatch(essayText, paragraphs, candidateId))
            .filter(Objects::nonNull)
            .filter(m -> m.getSimilarity().compareTo(
                BigDecimal.valueOf(SIMILARITY_THRESHOLD * 100)) >= 0)
            .sorted(Comparator.comparing(SourceMatchDetail::getSimilarity).reversed())
            .collect(Collectors.toList());
        
        return matches;
    }
    
    /**
     * 精确比对单篇作文
     */
    private SourceMatchDetail preciseMatch(String essayText, 
                                           List<TextSegment> paragraphs,
                                           Long candidateEssayId) {
        // 获取候选作文全文
        Essay candidate = essayRepository.findById(candidateEssayId);
        if (candidate == null) return null;
        
        // 使用后缀自动机找公共子串
        List<MatchedSegment> segments = findLongestCommonSubstrings(
            essayText, candidate.getContent(), 20);
        
        if (segments.isEmpty()) return null;
        
        int matchedWords = segments.stream()
            .mapToInt(s -> s.getSubmitEnd() - s.getSubmitStart())
            .sum();
        
        BigDecimal similarity = BigDecimal.valueOf(
            (double) matchedWords / essayText.length() * 100
        ).setScale(2, RoundingMode.HALF_UP);
        
        // 隐去被匹配者个人信息
        return SourceMatchDetail.builder()
            .sourceType(SourceMatchDetail.SourceType.INTERNAL_ESSAY)
            .sourceName("平台用户作文") // 不暴露具体用户
            .sourceTitle(candidate.getEssayTitle())
            .similarity(similarity)
            .matchedSegments(segments)
            .matchedWordCount(matchedWords)
            .percentageOfTotal(similarity)
            .build();
    }
    
    private boolean isClassmateEssay(Long essayId, Long schoolId, Long classId, 
                                      LocalDate afterDate) {
        if (classId == null) return false;
        EssayMeta meta = essayRepository.findMetaById(essayId);
        return meta != null 
            && classId.equals(meta.getClassId())
            && meta.getSubmittedAt().toLocalDate().isAfter(afterDate);
    }

}
```

## 5. 诚信度综合评分引擎

### 5.1 评分模型

```java
/**
 * 诚信度综合评分引擎
 * 融合各维度检测结果，输出最终诚信度评分和风险等级
 */
@Service
@Slf4j
public class IntegrityScoringEngine {

    /**
     * 分龄权重配置
     * 年级越低，对模板化和AI检测的容忍度越高
     */
    private static final Map<Integer, ScoringWeights> GRADE_WEIGHTS = Map.of(
        1, new ScoringWeights(0.15, 0.20, 0.40, 0.25), // 幼儿：重抄袭，轻AI
        2, new ScoringWeights(0.20, 0.25, 0.35, 0.20), // 小学
        3, new ScoringWeights(0.30, 0.30, 0.25, 0.15), // 初中
        4, new ScoringWeights(0.35, 0.35, 0.20, 0.10)  // 高中：最严格
    );
    
    /**
     * 计算综合诚信度评分
     * 
     * @param webMaxSim    网络最大相似度 (0-100)
     * @param internalMaxSim 平台内最大相似度 (0-100)
     * @param aiProb       AI生成概率 (0-100)
     * @param templateScore 模板化评分 (0-100)
     * @param gradeLevel   年级段
     */
    public IntegrityScore compute(BigDecimal webMaxSim, BigDecimal internalMaxSim,
                                   BigDecimal aiProb, BigDecimal templateScore,
                                   Integer gradeLevel) {
        
        ScoringWeights weights = GRADE_WEIGHTS.getOrDefault(
            gradeLevel, GRADE_WEIGHTS.get(2));
        
        // 取网络和内部相似度的最大值作为抄袭分
        BigDecimal maxSimilarity = webMaxSim.max(internalMaxSim);
        
        // 抄袭扣分：相似度超过20%开始扣分，50%以上直接高风险
        double plagiarismDeduction = computePlagiarismDeduction(maxSimilarity.doubleValue());
        
        // AI扣分
        double aiDeduction = computeAIDeduction(
            aiProb.doubleValue(), weights.aiWeight);
        
        // 模板扣分
        double templateDeduction = computeTemplateDeduction(
            templateScore.doubleValue(), weights.templateWeight);
        
        // 基础诚信分100，减去各项扣分
        double integrityScore = Math.max(0, 100 
            - plagiarismDeduction * weights.plagiarismWeight * 3
            - aiDeduction
            - templateDeduction);
        
        // 确定风险等级
        OriginalityCheckResult.RiskLevel riskLevel = determineRiskLevel(
            maxSimilarity.doubleValue(), aiProb.doubleValue(), 
            templateScore.doubleValue(), integrityScore);
        
        return IntegrityScore.builder()
            .integrityScore(BigDecimal.valueOf(integrityScore)
                .setScale(2, RoundingMode.HALF_UP))
            .maxSimilarity(maxSimilarity)
            .aiProbability(aiProb)
            .templateScore(templateScore)
            .riskLevel(riskLevel)
            .build();
    }
    
    private double computePlagiarismDeduction(double similarity) {
        if (similarity < 15) return 0;
        if (similarity < 25) return (similarity - 15) * 1.5;
        if (similarity < 40) return 15 + (similarity - 25) * 2;
        if (similarity < 60) return 45 + (similarity - 40) * 3;
        return 100; // 60%以上直接满分扣分
    }
    
    private double computeAIDeduction(double aiProb, double weight) {
        if (aiProb < 30) return 0;
        if (aiProb < 50) return (aiProb - 30) * 0.5 * weight * 3;
        if (aiProb < 75) return 10 + (aiProb - 50) * 0.8 * weight * 3;
        return 30 + (aiProb - 75) * 1.2 * weight * 3;
    }
    
    private double computeTemplateDeduction(double templateScore, double weight) {
        if (templateScore < 20) return 0;
        if (templateScore < 40) return (templateScore - 20) * 0.3 * weight * 3;
        if (templateScore < 60) return 6 + (templateScore - 40) * 0.5 * weight * 3;
        return 16 + (templateScore - 60) * 0.7 * weight * 3;
    }
    
    private OriginalityCheckResult.RiskLevel determineRiskLevel(
            double similarity, double aiProb, double templateScore, 
            double integrityScore) {
        
        // 极高风险：明确抄袭
        if (similarity >= 50) return OriginalityCheckResult.RiskLevel.CRITICAL;
        // 高风险：高相似或高AI概率
        if (similarity >= 35 || aiProb >= 75 || integrityScore < 40) 
            return OriginalityCheckResult.RiskLevel.HIGH;
        // 中风险：中等相似或中等AI概率
        if (similarity >= 25 || aiProb >= 50 || integrityScore < 65) 
            return OriginalityCheckResult.RiskLevel.MEDIUM;
        // 低风险
        return OriginalityCheckResult.RiskLevel.LOW;
    }
    
    @Data
    @AllArgsConstructor
    private static class ScoringWeights {
        private final double plagiarismWeight;
        private final double aiWeight;
        private final double templateWeight;
        private final double originalityBonus; // 未使用，预留
    }
}
```

## 8. 异步任务调度

### 8.1 检测任务消费者

```java
/**
 * 原创性检测任务消费者
 */
@Component
@Slf4j
public class OriginalityCheckConsumer {

    @Autowired
    private TextPreprocessor preprocessor;
    @Autowired
    private WebSimilaritySearcher webSearcher;
    @Autowired
    private InternalCorpusMatcher internalMatcher;
    @Autowired
    private AIGeneratedDetector aiDetector;
    @Autowired
    private TemplatePatternDetector templateDetector;
    @Autowired
    private IntegrityScoringEngine scoringEngine;
    @Autowired
    private SimilarityReportGenerator reportGenerator;
    @Autowired
    private OriginalityCheckRepository checkRepository;
    @Autowired
    private IntegrityProfileRepository profileRepository;
    @Autowired
    private TextFingerprintRepository fingerprintRepository;
    
    @KafkaListener(topics = "essay-originality-check", groupId = "originality-check-group")
    public void onCheck(OriginalityCheckMessage msg) {
        Long checkId = msg.getCheckId();
        
        try {
            // 1. 更新状态
            checkRepository.updateStatus(checkId, CheckStatus.PREPROCESSING);
            
            OriginalityCheck check = checkRepository.findById(checkId);
            String essayText = check.getEssayContent();
            Long userId = check.getUserId();
            Integer gradeLevel = check.getGradeLevel();
            String subject = check.getSubject();
            
            // 2. 文本预处理
            PreprocessResult preprocessed = preprocessor.preprocess(
                essayText, check.getEssayId(), userId);
            
            // 3. 更新状态
            checkRepository.updateStatus(checkId, CheckStatus.DETECTING);
            
            // 4. 并行执行四维检测
            CompletableFuture<List<SourceMatchDetail>> webFuture = CompletableFuture
                .supplyAsync(() -> webSearcher.search(
                    essayText, preprocessed.getParagraphs(), subject, gradeLevel));
            
            CompletableFuture<List<SourceMatchDetail>> internalFuture = CompletableFuture
                .supplyAsync(() -> internalMatcher.match(
                    essayText, userId, check.getSchoolId(), 
                    check.getClassId(), gradeLevel, subject));
            
            CompletableFuture<AIDetectionDetail> aiFuture = CompletableFuture
                .supplyAsync(() -> aiDetector.detect(
                    essayText, preprocessed.getSentences(), gradeLevel));
            
            CompletableFuture<TemplateDetectionDetail> templateFuture = CompletableFuture
                .supplyAsync(() -> templateDetector.detect(
                    essayText, preprocessed.getParagraphs(), gradeLevel, subject));
            
            // 等待全部完成（超时60秒）
            CompletableFuture.allOf(webFuture, internalFuture, aiFuture, templateFuture)
                .get(60, TimeUnit.SECONDS);
            
            // 5. 聚合结果
            checkRepository.updateStatus(checkId, CheckStatus.SCORING);
            
            List<SourceMatchDetail> webMatches = webFuture.get();
            List<SourceMatchDetail> internalMatches = internalFuture.get();
            AIDetectionDetail aiDetail = aiFuture.get();
            TemplateDetectionDetail templateDetail = templateFuture.get();
            
            BigDecimal webMaxSim = webMatches.stream()
                .map(SourceMatchDetail::getSimilarity)
                .max(BigDecimal::compareTo)
                .orElse(BigDecimal.ZERO);
            BigDecimal internalMaxSim = internalMatches.stream()
                .map(SourceMatchDetail::getSimilarity)
                .max(BigDecimal::compareTo)
                .orElse(BigDecimal.ZERO);
            
            // 6. 计算综合诚信度
            IntegrityScore score = scoringEngine.compute(
                webMaxSim, internalMaxSim,
                aiDetail.getAiProbability(),
                templateDetail.getTemplateScore(),
                gradeLevel);
            
            // 7. 保存结果
            checkRepository.updateResults(checkId, score, webMatches, 
                internalMatches, aiDetail, templateDetail);
            
            // 8. 存储文本指纹（供后续比对使用）
            saveFingerprints(check.getEssayId(), userId, 
                preprocessed.getSegmentFingerprints(),
                check.getSchoolId(), check.getClassId(), gradeLevel);
            
            // 9. 更新用户诚信档案
            updateIntegrityProfile(userId, score);
            
            // 10. 风险分流：高风险自动进入人工审核队列
            if (score.getRiskLevel().getCode() >= 2) {
                checkRepository.updateReviewStatus(checkId, 1); // 待审核
                notifyReviewers(checkId, score);
            }
            
            // 11. 发送通知
            checkRepository.updateStatus(checkId, CheckStatus.COMPLETED);
            eventPublisher.publishEvent(new OriginalityCheckCompletedEvent(checkId, score));
            
        } catch (TimeoutException e) {
            log.error("Originality check timeout: {}", checkId, e);
            checkRepository.updateStatus(checkId, CheckStatus.FAILED);
            checkRepository.updateFailureReason(checkId, "检测超时");
        } catch (Exception e) {
            log.error("Originality check failed: {}", checkId, e);
            checkRepository.updateStatus(checkId, CheckStatus.FAILED);
            checkRepository.updateFailureReason(checkId, e.getMessage());
        }
    }
    
    private void updateIntegrityProfile(Long userId, IntegrityScore score) {
        IntegrityProfile profile = profileRepository.findByUserId(userId);
        if (profile == null) {
            profile = IntegrityProfile.builder()
                .userId(userId)
                .build();
        }
        
        // 更新统计
        profile.setTotalChecks(profile.getTotalChecks() + 1);
        
        // 使用增量平均
        int n = profile.getTotalChecks();
        profile.setAvgIntegrity(
            profile.getAvgIntegrity().multiply(BigDecimal.valueOf(n - 1))
                .add(score.getIntegrityScore())
                .divide(BigDecimal.valueOf(n), 2, RoundingMode.HALF_UP));
        
        // 更新风险计数
        switch (score.getRiskLevel()) {
            case HIGH, CRITICAL -> {
                profile.setHighRiskCount(profile.getHighRiskCount() + 1);
                profile.setConsecutiveClean(0);
                profile.setLastViolationDate(LocalDate.now());
            }
            case MEDIUM -> {
                profile.setMediumRiskCount(profile.getMediumRiskCount() + 1);
                profile.setConsecutiveClean(0);
            }
            case LOW -> profile.setConsecutiveClean(profile.getConsecutiveClean() + 1);
        }
        
        // 更新诚信等级
        profile.setIntegrityLevel(computeIntegrityLevel(profile));
        profile.setLevelUpdatedAt(LocalDateTime.now());
        
        // 更新趋势
        if (n >= 3) {
            profile.setIntegrityTrend(computeTrend(userId));
        }
        
        profileRepository.save(profile);
    }
    
    private IntegrityLevel computeIntegrityLevel(IntegrityProfile profile) {
        double avg = profile.getAvgIntegrity().doubleValue();
        if (avg >= 90 && profile.getHighRiskCount() == 0) return IntegrityLevel.EXCELLENT;
        if (avg >= 75) return IntegrityLevel.GOOD;
        if (avg >= 60) return IntegrityLevel.FAIR;
        if (avg >= 40) return IntegrityLevel.WARNING;
        return IntegrityLevel.CRITICAL;
    }
}
```

## 11. 语料库建设与维护

### 11.1 网络语料采集

```java
/**
 * 网络范文语料采集器
 * 定期从公开范文网站采集优秀作文，丰富比对库
 */
@Service
@Slf4j
public class WebCorpusCrawler {
    
    /**
     * 定时采集任务（每日凌晨执行）
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void scheduledCrawl() {
        List<CorpusSource> sources = sourceRepository.findActiveSources();
        for (CorpusSource source : sources) {
            try {
                List<ReferenceCorpus> documents = crawlSource(source);
                saveToCorpus(documents);
            } catch (Exception e) {
                log.warn("Failed to crawl source: {}", source.getName(), e);
            }
        }
    }
    
    private List<ReferenceCorpus> crawlSource(CorpusSource source) {
        // 1. 抓取页面列表
        List<String> urls = pageListCrawler.crawl(source.getUrl(), source.getLimit());
        
        // 2. 并行抓取正文
        return urls.parallelStream()
            .map(url -> {
                String content = pageCrawler.crawl(url, 10000);
                if (content == null || content.length() < 100) return null;
                
                String simHash = preprocessor.computeSimHash(content);
                String minHash = preprocessor.computeMinHash(content, 128);
                float[] embedding = embeddingService.embed(content);
                
                return ReferenceCorpus.builder()
                    .corpusType(source.getType())
                    .title(extractTitle(content))
                    .content(content)
                    .sourceUrl(url)
                    .sourceName(source.getName())
                    .simHash(simHash)
                    .minhashSig(minHash)
                    .embeddingVec(serializeEmbedding(embedding))
                    .crawledAt(LocalDateTime.now())
                    .build();
            })
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
    }
}
```

5. **分段并行**：长作文分段后并行检测
6. **CDN加速**：网页爬取通过国内 CDN 代理降低延迟

## 13. 隐私与安全考量

### 13.1 数据隐私

- 学生作文原文仅用于检测，不发送给第三方服务（搜索引擎仅发送关键词，不发送全文）
- 平台内部比对结果对被比对方匿名处理，不泄露具体学生信息
- 诚信档案数据仅对本人、绑定家长、任课教师可见

### 13.2 安全措施

- 检测 API 需鉴权，学生只能查询自己的检测结果
- 教师只能查询所带班级的概览数据
- 审核操作需双因素认证
- 检测日志保留 6 个月用于审计

### 13.3 教育伦理

- 对小学生以"原创性引导"代替"抄袭检测"的表述
- 首次违规以提醒和引导为主，不直接通知家长
- 连续高风险才升级为通知家长和教师
- 检测结果不作为评分的唯一依据，必须保留人工复核通道

## 17. 附录

### 17.1 SimHash 算法说明

SimHash 是一种局部敏感哈希算法，相似文本会产生相似的哈希值。通过计算两个 SimHash 的海明距离来估算文本相似度：

- 海明距离 ≤ 3：高度相似（~90%+）
- 海明距离 ≤ 6：中等相似（~70%+）
- 海明距离 ≤ 10：弱相似（~50%+）
- 海明距离 > 10：基本不相似

### 17.2 MinHash + LSH 说明

MinHash 用于估算 Jaccard 相似度，配合 LSH（Locality-Sensitive Hashing）可实现大规模文本的快速近似最近邻搜索。

### 17.3 Perplexity 说明

困惑度衡量语言模型对文本的"惊讶程度"。AI 生成文本的困惑度通常显著低于人类写作，因为 AI 倾向于选择高概率词汇。

### 17.4 Burstiness 说明

突发性衡量文本中句子长度的变化幅度。人类写作往往有明显的长短句交替（高突发性），而 AI 生成文本句长较为均匀（低突发性）。
